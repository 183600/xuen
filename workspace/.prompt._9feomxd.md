## 1. 三个灵感的第一性原理

### 灵感 1 ·「自主导航」→ 操作即导航：路标 + 伺服 + 重定位

导航问题的经典解构：**全局粗规划 + 局部闭环伺服 + 周期性重定位 + 到点确认**。投影到桌面操作域，正好命中上轮认定的断点（所有模型推进大半程、崩在最后对齐/插入/放置）：

- VLA 输出 chunk 的本质是「朝路标开环行驶」——语义与长程是强项，厘米级收敛无闭环责任；
- 而对齐/插入/放置需要的恰是**局部闭环伺服**：腕部相机、EE 位姿、夹爪标量全在观测里，PBVS/IBVS 的原料齐备；
- 导航的「到点确认」推广了上轮的「抓握确认」：不只是「抓住没有」，而是「每个路标通过没有」——**确认器从单一隐变量升级为路标断言序列**（IP-02 与新 IP-09 统一）；
- 导航的「重定位/重规划」对应失败恢复：路标断言失败 → 重抓 / 重对齐 / 换非抓取原语（上轮 U6 介入准则被统一为「路标级介入准则」）。

另一层转译：G1 是足式平台，「自主导航」在赛场还有字面机会——**基座自主移动（pivot/迈步）扩大工作空间**。目标摆到台面边缘、臂展够不到时，「把身体挪过去」比「把手伸过去」更根本；官方 WBT_SMPL 数据含 `Walk_To_Table` 系列任务，证明「移动-接近-操作」数据形态存在 → IP-05 从「姿态先验」升级为「可达性导航」。

**策略含义**：这是把经典机器人学「塞回」端到端范式的机会窗口——分层执行栈（VLA 管语义与长程、伺服管最后一厘米、断言管确认）数据效率最高、最不依赖算力、且真机标定的工程密度让对手短期难抄。

### 灵感 2 ·「持续学习」→ 三个时间尺度的学习环，和一个负样本困境

持续学习的本质：**在不遗忘旧技能的前提下吸收新信息**。赛制（单 checkpoint 冻结参赛 + 分布偏移评测 + 多 episode 会话）把学习压到三个时间尺度：

1. **训练期（离线尺）**：官方语料持续增长（F4）⇒ 「一次性混合训练」必然过时；应做**课程式持续训练**：全语料预训练 → 32 项微调 → 难例课程（插入/旋转类上采样，待榜单复核后定权重）+ 全任务 replay 回归（防遗忘）→ 新增 IP-12。
2. **会话期（跨 episode 尺）**：`reset()` 只承诺清空 episode 状态；跨 episode 的**非参数记忆**（场景指纹 → 校正缓存：光照标定、EE 跟踪偏置、干扰物抑制参数）字面上不违反「单模型」，但可能违反评测精神（上轮 Q4 悬置）⇒ 双形态：默认「episode 内热身版」（零合规风险），跨 episode 版仅书面确认后启用 → 新增 IP-11。
3. **回合内（episode 内尺）**：上轮 IP-04 已立（上下文调制 + 受限适配），本轮不变；其「在线权重更新」部分降级为条件项（会话尺度目标由 IP-11 覆盖）。

**负样本困境（本轮新识别，IP-02 的最大死穴）**：抓握确认器需要「失败」监督，而官方 32 个数据集全部是成功演示——**演示数据里没有它最需要的那种数据**。三个造负样本途径，按成本排序：
- ① **世界模型合成**（F5：WMA-0 明确支持生成交互合成数据）：对成功轨迹注入扰动（提前闭合 / 横向偏移 / 中途松爪），生成「失败的物理视频 + 状态序列」；
- ② **代理评测扰动回放**（IP-06 副产物）：在专家轨迹上叠加扰动、按评测器语义回放，产出「半真值」失败；
- ③ **真机失败日志**：runs.html 将来公开「完整评测视频」（页面原文），若允许查看**自己**的评测视频，即最珍贵的真值负样本；能否看**他人**的属灰色地带，默认不依赖（P5 红线）。

三者在 **IP-12（失败驱动的持续课程）** 中闭环：IP-06 诊断瓶颈因子 → IP-10 定向合成 → 课程重训 → 全任务 replay 回归。

## 3. 设计原则（新增 P7–P9，接上轮 P1–P6）

- **P7（操作即导航）**：一切任务拆成「路标序列 + 到点断言 + 局部伺服」；VLA 不再是唯一动作来源，而是「语义规划器 + 长程执行器」；任何「最后一厘米」的收敛责任交给闭环。
- **P8（负样本是一等公民）**：没有失败数据来源的确认/介入类组件一律不许上线；任何此类组件必须同时给出负样本来源与分布差证据（E622 门槛）。
- **P9（护城河优先）**：新 IP 立项前先过「护城河测试」——对手一周可抄的降级或并入基线；工程密度高的组件（伺服、缝合、评测栈）排清单前排。

## 5. 本轮最大风险（更新）

上轮风险「抓握误判的漏判不对称」依然成立；本轮叠加一条：

**合成负样本的「假安全」**：WMA-0 若在 G1+Dex1 桌面域保真不足，它生成的「失败」可能系统性偏离真实失败模式（例如模型预测「偏移 2cm 会滑脱」，真实世界却是「卡住但没掉」）；在最需要确认器的未见物品泛化场景里，判定器可能被合成分布「喂偏」——负样本工程不仅可能无效，还可能**有害**。对冲：E622 先测分布差（MMD + 判别器交叉验证），未过门槛则负样本只用于预训练、真实半真值用于微调（P8 强制流程）；且热身版记忆与断言器均带闸门回滚。

## 3. 新增 IP 详述

### IP-09 · WaypointServo 路标分解 + 视觉伺服 + 到点断言（P0，新）

- **动机**：teaser 榜（已下线、待复核）与 RoboDojo ▲ 一致显示失败崩在最后对齐/插入/放置；纯端到端 VLA 的 chunk 输出对厘米级收敛没有闭环责任。导航领域的成熟答案是「路标 + 伺服 + 到点确认」，其全部原料（腕部相机、EE 位姿、夹爪标量）已在观测内。
- **与现有方案差异**：teaser 8 模型皆为「VLA 吞观测吐动作块」的单一通路；我们把执行栈分层——VLA 是语义规划器与长程执行器，路标断言器是「导航电子围栏」，伺服器是最后一厘米的闭环。分层不改单模型合规（伺服器是策略内部组件，仍一个 checkpoint、一个 API）。
- **技术可行性**：高。伺服器（PBVS：EE 位姿误差 → 速度修正）+ 断言器（每路标的几何/视觉判据）均为小模型/规则，单卡小时级；阶段标注复用 IP-06 标注器。
- **资源**：数据=官方 32 集（阶段标注）；算力=小；接口=无新增字段。
- **落地步骤**：①用 IP-06 阶段标注建立「任务 → 路标序列」映射矩阵，验证覆盖率（E619）；②实现 PBVS 伺服器并用官方数据回归增益（以数据中的「专家修正行为」拟合 K）；③混合门控：相位 ∈ {align, insert, place} 且断言置信度高 → β 升，切换带滞回；④到点断言连续失败 → 触发 IP-02 介入准则（重抓/重对齐/换原语）；⑤难任务（插入/旋转类）专项 A/B（E620）。
- **风险**：①腕部相机标定误差致伺服发散 ⇒ 增益由数据回归 + 真机小步标定；②与 VLA 输出打架产生抖振 ⇒ 滞回门控（E621）；③断言器误报打断正常执行 ⇒ 同 IP-02 保守介入（高精度低召回）。

### IP-10 · WorldModel-Negatives 负样本合成 + rollout 预验证（P1，新）

- **动机**：断言器/确认器需要失败监督，而官方数据全是成功演示（想法区·负样本困境）；WMA-0 README 明示「Simulation Engine——生成交互合成数据」与「Policy Enhancement——预测未来交互以优化决策」。
- **差异**：把 WMA-0 从「又一个底座候选」转用为**数据引擎**（造负样本）与**前瞻验证器**（动作块发出前在潜空间 rollout 1–2 候选、选预测优者）——官方给了零件，teaser 榜（待复核）上无此描述。
- **可行性**：中。WMA-0 未在 G1+Dex1 桌面域验证 ⇒ 先做保真度评测（E622）；在线 rollout 的视频生成延迟不可行，在线只保留潜空间前瞻或完全离线。
- **资源**：WMA-0 权重（apache-2.0）+ 单机多卡推理；数据=注入扰动的成功轨迹。
- **步骤**：①G1+Dex1 域校准 WMA-0（adapter 微调）；②定义扰动谱（提前闭合 / 横向偏移 / 中途松爪 / 触碰干扰物）→ 批量生成失败样本；③分布差验收（MMD + 判别器交叉验证，E622）；④负样本预训练 + 官方成功数据微调断言器（E623）；⑤（可选）潜空间前瞻接入 `get_action`，受延迟预算约束（U12），默认离线。
- **风险**：合成失败系统性偏离真实失败（「假安全」）⇒ E622 未过门槛则只用于预训练（P8）；在线前瞻延迟超标 ⇒ 降级为纯数据引擎。

### IP-11 · SessionMemory 跨 episode 非参数记忆（P2·条件，新）

- **动机**：会话尺度持续学习；跨 episode 的光照标定 / EE 偏置 / 干扰物记忆，字面上是「自行部署的软件状态」而非模型权重。
- **差异**：不做参数更新，只做**非参数校准缓存**（场景指纹 → 小校正量 δ，≤3 维/场景），带每 episode 闸门回滚。
- **可行性**：高（工程）；**合规未决**（Q9）⇒ 默认交付「episode 内热身版」（前 N 步自估校准量、不跨 episode）。
- **步骤**：①定义指纹（头相机直方图 + EE 指令-实际偏置统计）；②热身版实现与 A/B（E625）；③书面确认后启用跨 episode 版。
- **风险**：违规风险（最高，P5 红线）；指纹混淆致跨场景串扰 ⇒ 缓存键加 task token 与端口隔离。

### IP-12 · FailureCurriculum 失败驱动持续课程（P1，新）

- **动机**：训练期持续学习；全语料持续增长（F4）+ 难任务集中（teaser 假设：插入/旋转最弱，待复核）⇒ 课程 + replay 是自然配方。
- **差异**：不是「把数据混一起训」，而是**失败驱动的课程闭环**：IP-06 诊断最弱因子 → IP-10 定向合成 → 课程重训（难因子上采样）→ 32 任务 replay 回归（防遗忘闸门）。
- **可行性**：高（纯训练配方）；资源=8×A100（与 IP-01 共享训练预算）。
- **步骤**：①课程调度器（因子权重 → 采样权重）；②replay 配比实验（E624）；③与 IP-01 联训（token + 课程）。
- **风险**：课程过拟合到代理评测的诊断偏差 ⇒ 回归闸门 + 禁止依据 teaser 调参（P1）。

## 4. 符号与定义（新增 U13–U15；U1–U12 沿用第 1 轮）

- **定义 U13（路标）**：任务 τ 的路标序列 `W(τ) = (w_1..w_K)`；每路标 = `(阶段标签 p_i, 几何锚 g_i, 通过断言 q_i)`，`q_i: obs → {0,1}` 为可验证函数（EE-目标位姿误差阈值、夹爪状态、腕部视觉判据）。
- **定义 U14（伺服律）**：`u_servo = K(q_i)·e`，`e` 为 EE 到当前路标锚的位姿误差，`K` 由官方数据中专家的修正行为回归；执行动作为 `a = (1−β)·a_VLA + β·u_servo`，`β(z_phase, conf_q) ∈ [0,1]`，切换带滞回（防抖振）。
- **定义 U15（会话记忆）**：`M: fingerprint(o) → δ`（校准偏置，≤3 维/场景）；热身版限定 `M` 生命周期 ≤ 1 episode；跨 episode 版须过合规确认，且带每 episode 闸门回滚。

## 5. 关键算法骨架（新增片段；主体沿第 1 轮 `UniBotSAGEPolicy`）

```python
# ===== IP-09: 路标断言 + 伺服混合（嵌入 get_action 主循环）=====
WAYPOINTS = load_task_waypoints()      # 任务token → 路标序列（IP-06 阶段标注生成）

def execute_step(self, s, obs):
    wp, i = WAYPOINTS[s.task_token], s.wp_idx
    q = self.assert_ok(wp[i], obs)             # U13: 到点断言
    if q:
        s.wp_idx += 1; s.assert_fail = 0
    else:
        s.assert_fail += 1
        if s.assert_fail >= self.assert_patience:   # 连续不过 → 介入
            return self.intervene(s, obs)           # 复用 IP-02: 重抓/重对齐/换原语
    a_vla = self.model.act(obs, s.task_token, s.phase, s.ctx,
                           T_a=self.chunk_len(s.phase))
    beta = self.gate(s.phase, q, wp[i])    # U14: align/insert 相位升 β，滞回防抖
    u = self.servo(wp[i], obs)             # PBVS: K(q)·e
    return (1 - beta) * a_vla + beta * u   # Level-1.5: servo 失效 ⇒ beta=0（纯 VLA）
```

```python
# ===== IP-10: 负样本合成（离线管线）=====
def synthesize_negatives(dataset, wma, perturbations):
    for ep in dataset.success_episodes:
        for pert in perturbations:   # 提前闭合/横向偏移/中途松爪/触碰干扰物
            sim = wma.rollout(ep.actions, perturb=pert)   # 仿真引擎（F5a）
            if sim.failure_detected:                      # 仿真判定失败=真值
                yield (obs=sim.frames, grasp_ok=False, mode=pert.name)

def accept_negatives(syn, holdout_real):          # E622 门槛
    mmd  = mmd_distance(feat(syn), feat(holdout_real))
    disc = discriminator_auc(syn, holdout_real)   # 越接近 0.5 越好
    return mmd < TAU_MMD and abs(disc - 0.5) < TAU_DISC
```

## 6. 推导（新增引理 L8–L10；L1–L7 沿用第 1 轮）

**引理 L8（路标分解的边际收益定位）** 设任务成功 ⇔ 依次通过路标 `w_1..w_K`，各路标通过率 `p_i`（伺服修正下），则 `P(success) = ∏ p_i`，且 `∂P/∂p_j = P / p_j ≥ P`（因 `p_j ≤ 1`）⇒ **对最弱路标（最小 p_j）的单位改进产生最大边际收益**。推论：伺服与断言资源应集中投向 align/insert 路标（与上轮 T3 断点假设一致，待榜单复核）。∎

**引理 L9（合成负样本的迁移损失）** 设真实失败分布 `D_r` 与合成失败分布 `D_s` 在判别特征空间 `φ` 上的总变差 `TV(φ(D_s), φ(D_r)) = ε`，则在 `D_s` 上训练、于 `D_r` 上评估的判定器满足 `AUROC_r ≥ AUROC_s − 2ε`（标准 TV–AUROC 不等式）⇒ **E622 的分布差验收是 IP-10 有效的工程充要条件**；ε 大时退化为「仅预训练 + 真实半真值微调」（P8 强制流程）。∎

**引理 L10（非参数记忆的最坏情形安全）** 若会话记忆仅输出有界校正 `‖δ‖ ≤ ρ_m` 且每 episode 末与无记忆分支做闸门比较（变差即回滚），则最坏情形退化为「无记忆基线」（与 L6 同构）⇒ 热身版在合规与性能两维都占优；跨 episode 版的唯一风险是合规而非性能。∎
