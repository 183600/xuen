## 1. 三个灵感的第一性原理

### 灵感 1 ·「SLAM」→ 操作域缺的是「状态层」，不是更多策略

SLAM 的三件套——**带不确定性的状态估计、持久地图、扰后重定位**——恰好是端到端 VLA 系统里被完全隐式化的三件事：

- **到点断言的升级**：第 2 轮 U13 的断言 `q_i: obs → {0,1}` 是固定几何阈值，直接吃原始观测；SLAM 的标准做法是**估计带协方差 + 卡方门限**（Mahalanobis 距离 ≤ χ² 阈值才「到点」）——误拒率先验可控且与量纲/各向异性无关（L11）。这是 IP-09 断言器的严格升级而非替换：同样的「通过/不通过」接口，误差率从「拍脑袋阈值」变成「设计参数 α」。
- **地图 = 场景图**：episode 内维护「目标物体档案 + 干扰物清单 + 工作台坐标系」的持久结构（U16）。直接价值：外观漂移（光照/遮挡/背景切换）不再冲击执行——所有路标引用档案而非原始像素；干扰物从「注意力的噪声」升级为「图中的实体」（可抑制、可避开、可计数）。
- **重定位 = 不重启**：人为干扰/位置变化后，SLAM 的答案是重锚定而不是重跑全程。L12 的步数经济学证明：只要等待时长短于已完成前缀的重做代价，保持-续跑严格优于重启。这给 IP-02 的介入家族补上最重要的一类——「重定位」。
- **环路检测的行为级推广**：VLA 已知的「复读」失败（同一失败抓握反复执行）本质是状态环；SLAM 用环路闭合修正漂移，我们用行为嵌入的滑窗相似度检测「我见过这个状态」→ 强制换策略（换抓取点/换原语）。
- **因子图 = 子模块协议**：VLA 的语义期望（先验因子）、检测器测量、本体感受、夹爪状态作为约束进同一个图，融合出「任务状态」最优估计。IP-07 的 joint↔ee 一致性检查恰好是图中的一个运动学残差 → **IP-07 正式吸收进状态层，修剪归档**。

**策略含义**：第 2 轮把「最后一厘米」交给了伺服；本轮把「最后一厘米之前的每一步该信什么」交给状态层。伺服解决「怎么动」，状态层解决「现在到底在哪、目标到底是谁、卡没卡住」——它是断言、伺服、介入三者的共同地基，也是 IP-04/IP-15 的特征源。

### 灵感 2 ·「物体泛化」→ 把未知物体从「像素问题」变成「档案问题」

泛化五轴中的「未见物品」轴，失败集中于三个来源：①抓取点几何不匹配（训练分布没见过的形状）；②物理属性意外（质量/摩擦与外观不符 → 运输中滑落——最隐蔽的失败：抓取瞬间看起来成功）；③身份混淆（目标与干扰物相似 → 绑错目标，与干扰物轴交叉）。

对应三个组件（IP-14）：
- **物体档案（Dossier）**：首次注视即建结构化记录——开词汇掩码、形状/尺寸估计、按**几何供抓性**（而非外观相似度）排序的抓取候选、属性先验（质量档位/刚性）；后续所有路标引用档案；
- **SlipGuard**：观测里没有力传感（头/腕相机 + EE 位姿 + 夹爪标量）⇒ 滑移只能视觉检测：运输相位对腕部相机物体区域做微位移监测（区域光流/掩码 IoU 漂移），超阈 → 三段响应（停 → 收紧/降速 → 重抓下移）。Q11 是本轮新悬置问题；
- **数据面**：DiverseManip（128/256 物体 × 单/双臂）就是官方给的「物体多样性语料」→ 按物体身份留出（holdout-by-object）训练与评测，直接对齐未见物品轴（E631），并作为 IP-12 课程的新「物体多样性段」。

### 灵感 3 ·「交互设计」→ 三个「对话协议」

- **与人对话（人为干扰轴）**：干扰分类状态机（IP-15）——{遮挡 → 保持；目标位移 → 重定位；新增干扰物 → 入图并抑制；接触机器人 → 让步}。核心设计原则「**保持而非重启**」（P11）：大多数 VLA 在干扰下要么盲跑旧 chunk、要么整个 episode 报废；一个近零成本的规则协议可以专项救回「人为干扰」这一轴（占五分之一的泛化评测面）。
- **与物体对话（主动感知）**：探测动作（预升力试探、轻推确认）以步数换信息；期望步数记账（P12 / L13）决定哪些路标允许探测——「高失败风险 + 高重试代价」的相位（insert/release）才在白名单内。与 IP-10 的潜空间前瞻合并为同一笔账：探测（真实交互测量）vs rollout（预测测量），按各自成本选。
- **与自身对话（子模块协议）**：状态层与执行层的接口本身就是最大的「交互设计」——断言/伺服/介入不再直接消费原始像素，而是消费融合状态；低频检测 + 事件触发重估的调度协议控制延迟预算（U12）。模块间协议的清晰度决定整个执行栈的可调试性，属于工程护城河的一部分。

## 2. 研究问题（新增 Q10–Q12，接第 1–2 轮 Q1–Q9）

## 3. 设计原则（新增 P10–P12，接第 1–2 轮 P1–P9）

- **P10（先估后动）**：任何断言/伺服/介入不得直接消费原始像素，必须经过状态层融合估计；状态层不可用时按退化链降级为固定阈值断言（Level-1.6），不得静默失效。
- **P11（保持而非重启）**：外部扰动默认触发「保持 + 重锚定」，只有重锚定失败才重启路标序列；重启是最后手段（L12）。
- **P12（交互即测量）**：一切信息收集动作（探测、rollout、额外推理）必须过期望步数账：预期挽回步数 > 消耗步数才许上线（L13）；账算不平的组件只许离线存在。

## 5. 本轮最大风险

**地图毒化（绑定错误）**：目标身份绑错（把干扰物当目标）会让整条路标链在错误锚点上「自信地失败」——比无地图更糟。对冲：①目标绑定需多帧一致（连续 N 帧同一身份且位置连续）；②夹爪接触确认（抓到物体的几何与档案一致才认）；③绑定置信度 < TAU_BIND 时退化为无地图模式（P10 退化链）。次要风险：感知延迟吃掉动作预算（U12）→ 低频调度 + 事件触发（E633 门槛）；合成干扰过拟合 → 协议只保留最保守动作集，代理评测仅做回归测试。

## 3. 新增 IP 详述

### IP-13 · SceneState 场景图 + 卡方断言 + 重定位 + 复读检测（P0，新）

- **动机**：五个泛化轴中的位置/干扰物/人为干扰三轴本质都是「世界变了而模型的世界模型没变」；VLA 无显式状态，第 2 轮断言器吃原始像素也无显式状态。SLAM 三件套（估计/地图/重定位）是几十年验证过的补丁，且全部原料（头/腕相机、EE 位姿、夹爪标量）已在观测内。
- **与现有方案差异**：teaser 榜（待复核假设）8 个模型全部是「观测→动作」单通路，无显式状态维护；本方案断言/伺服/介入统一消费一个带协方差的融合状态。组件全部现成件（开词汇检测 + 卡尔曼/匈牙利关联 + 卡方门限），无新模型。

```python
# ===== IP-13: 场景状态层（episode 内一张图；低频 + 事件触发）=====
class SceneState:
    def __init__(self, task_token):
        self.target = None        # U16: 档案 {id, mask_hist, pose, Sigma, geom, grasp_cands}
        self.distractors = []     # 干扰物档案列表
        self.frame = None         # 工作台参考系（首帧锚定）
        self.stale, self.tick = True, 0

    def update(self, obs, force=False):
        if not (force or self.stale or self.tick % N_LOWFREQ == 0):
            return                                   # 延迟预算：不每步跑检测器
        dets = self.detector(obs.head)               # 开词汇检测（低频）
        self.target, self.distractors = self.associate(dets)  # 多帧一致 + 匈牙利
        self.stale = False

    def relocalize(self, obs):                       # 扰后重锚（IP-02 触发）
        self.update(obs, force=True)
        ok = self.target is not None and self.target.conf >= TAU_BIND
        if not ok: self.degrade()                    # P10: 低置信 → 无地图模式
        return ok
```

```python
# ===== U17: 卡方到点断言（替换 U13 固定阈值；三区滞回）=====
def assert_waypoint(wp, state, obs):
    x, S = state.estimate_ee_object_rel(obs, wp)     # 融合估计 + 协方差
    d2 = x.T @ inv(S) @ x
    if d2 <= chi2_ppf(wp.dim, ALPHA):
        return True                                  # 误拒率 = ALPHA（先验可控）
    if d2 > chi2_ppf(wp.dim, ALPHA_FAIL):            # ALPHA_FAIL << ALPHA
        return False                                 # 高置信未到点 → 交介入准则
    return None                                      # 不确定区：维持现状（滞回）
```

## 7. 推导（新增引理 L11–L13；L1–L10 沿用第 1–2 轮）

**引理 L11（卡方门限的误差率先验可控）** 设到点时估计 `x̂ ~ N(g_i, Σ)` 且 Σ 已校准，则 `d² = (x̂−g_i)ᵀΣ⁻¹(x̂−g_i) ~ χ²_d`，故误拒率 `P(d² > χ²_{d,α}) = α` 恰为设计值，与 Σ 的各向异性和量纲无关；对真实偏移 δ 的检出功效由非中心参数 `δᵀΣ⁻¹δ` 单调决定。⇒ 断言质量 = 协方差校准质量；E628 只需验校准，无需逐任务调阈值（对比 U13 固定阈值必须逐任务标定）。∎

**引理 L12（保持-重启的步数经济学）** 设路标 i 的期望步数为 `s_i/p_i`（几何重试），干扰发生在完成前缀 1..j 后。重启代价 `C_r = Σ_{i≤K} s_i/p_i`（且干扰可能复现，代价只增）；保持代价 `C_h = h + Σ_{i>j} s_i/p'_i`（h=期望等待步数，p′ 为扰后续跑通过率）。保持占优 ⇔ `h < Σ_{i≤j} s_i/p_i + Σ_{i>j} s_i(1/p_i − 1/p'_i)`。⇒ **只要等待短于「已完成前缀的重做代价 + 性能退化补偿」，保持-续跑严格占优**；评估器按步数计分（F1：得分点满分 100）时，该差距是直接分数差。∎

**引理 L13（探测的盈亏平衡）** 探测消耗 s_p 步、以概率 q 避免一次后续失败（该失败代价 r 步介入+重试，且后续通过率折扣 γ），净收益 `Δ = q·(r + Σ s_i(1/γ−1)/p_i) − s_p > 0` ⇔ 盈亏平衡概率 `q* = s_p/(r + Σ s_i(1/γ−1)/p_i)`。⇒ s_p 小（≤2 步）、r 大（≥5 步）的相位（insert/release）探测收益高；其余相位探测默认关闭（P12 白名单）。∎
