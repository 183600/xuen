# 产物区 · v3.0：X-DUB/PACE-Π*

> PACE-Π = PACE with the **P**artition certificate（单机划分数证书）。
> 在 v2.0 的 `DHD`（tier 0.20）、`DCD`（tier 0.30）、`ODOM`、`HPACK`、`PACK-front`、`MINT`、`PACK-SET`、`SOP` 之上，本轮只加两层（外加一个明确关闭的神经提议接口）：
> **tier 0.10 `Π`**：若残余集 R 的单机划分数 `β(R)>m`，则状态 NO；以及 **tier 0.08 `CBC`**（可选）：机器不相容图的 `m+1` 团证书。
> 状态：设计稿 + 可运行 C/Python 实现 + 38 例 + deep 8 + held-out 50 + easy 60 + 2 组对抗 + planted n=17–24 + **7,500 随机对拍** + **106,021 穷举对拍** + **2,400 独立暴力验证 Π/CBC**，全部 0 不一致；未接 PSPLIB，未做 Coq/Lean 形式化验证。

## 0. 版本关系与本轮增量

v2.0 的资产全部保留：`DHD`、`DCD`、`ODOM`、`HPACK`、`PACK-front`、`LC-PACK` 的 0/0.5/1/2/3 层、`LC-DEC`、`CHECK-LC`、`PROFILE`、`(est,A)` Pareto 前沿 `G`、孪生机器商 `CANON`、`FRONT`/`FRONT-SUB`/`NO-INT` 证书、`MINT`、`PACK-SET`、`SOP`、carry 定理。

本轮增量：

1. **tier 0.10 `Π`（Partition certificate）**：对残余集 R 计算单机划分数 `β(R)`；`β(R)>m ⇒ NO`。核心 DP：
   ```text
   f[S] = 单机做完 S 的最早完工（Held-Karp 型）
   g[S] = 覆盖 S 所需的最少单机可行块数（集合划分 DP）
   β(R) = g[R]
   ```
2. **两段式见证**：n>15 时先算密度前 15 个任务的 `β(W)`；若 `β(W)>m` 直接剪；否则若 n≤16，再对完整 R 算一次精确 `β`。n>16 只算 15 点见证，选不中就退回 v2.0 搜索。
3. **tier 0.08 `CBC`（可选）**：机器不相容图 `G_inc` 的 `m+1` 团证书；O(n²) 建图 + 小团搜索。它在 38/deep/held-out 上没有让任何实例的节点数下降，但在 n>16 时可作为 Π 之前的便宜预筛。
4. **负结果 1（图证书分离）**：hard3#5 + deep 8 的根上 `ω(G_inc)≤3` 而 `β=4`；CBC 找不到 4 团，Π 能闭。图证书的团类型不够，装填是真正 obstruction。
5. **负结果 2（神经分支）**：无 frontier 截断时，NO 证明的节点数与子节点顺序无关（定理 7）。实测 46 个 NO 实例，slack/late/loss 三种顺序都是 66 节点；YES 上 loss 比 slack 少 20.7%（1,905→1,511），所以学习只能争找解时间，不能争 NO 证明大小。
6. **负结果 3（神经门）**：250 个随机紧状态（n=12–16，h=OPT−1，slack0≤4）的标签是 250 个 β>m、0 个 β≤m；负类为空，任何门都会退化成常数「跑」。默认保持确定性触发。
7. **实验**：38 例 88→**58**（1.517×）；deep 223→**8**（27.88×）；held-out 1,935→**357**（5.42×，39 胜 11 平 0 负）；easy 781→781（0 次 Π）；distinct-p 1,287→**894**（1.440×）；扇出 1,848→**1,753**（1.054×）；planted n=17–24 7,869→**21**。

退化关系：

```text
关 Π（保留 v2.0 的 DHD+DCD+HPACK）       → 逐字回到 88 / 223 / 1,935
只留 Π 的完整 R（关两段式）                → 同节点，deep 0.0985→0.1908 s
```

## 1. 符号

| 符号 | 含义 |

| `I=(n,m,p,E,≺,h)` | 实例：加工时间、机器数、资格、优先图、公共期限 |
| `σ=(R,A,est)` | DEC 状态：未调度集、机器可用时刻、最早开始 |

| `d` | `|Ready(R)|` |
| `c` | `|K(σ)|` |
| `ω_m` | 机器字长，64（C 内核用 64 位掩码） |

## 2. 形式定义

### 2.1 单机 profile `f[S]`

对 `S⊆R`，定义

```text
f[∅] = 0
f[S] = min_{ i∈sink(S) }  max(f[S\{i}], est_i) + p_i
       要求 f[S\{i}] < ∞  且  max(f[S\{i}], est_i) + p_i ≤ h − q_i .
```

`f[S]` 只描述一台机器：它可以在 `est_i` 之前空闲，可以按任意拓扑序，只要每个任务在 `h−q_i` 前完成。

**引理 1（f 正确性）**。`f[S]` 等于「一台机器、按 `≺` 排完 S」的最早完工时刻；若不存在这样的顺序，`f[S]=∞`。

**证明**。对 `|S|` 归纳。任一可行单机顺序的最后一个任务 i 必是 `sink(S)`（否则它有后继在 S 内，不可能最后）。删去 i 后，前缀是 S\{i} 的可行顺序，完工不早于 `f[S\{i}]`；把 i 放在 `max(f[S\{i}], est_i)` 开始不会更差。反过来，对每个 sink i，若 `f[S\{i}]<∞`，把 i 接在最优前缀后就是一个可行顺序。取 min 即得。∎

### 2.2 资格交集

**定义 1（feas）**。

```text
feas[S] = (f[S] < ∞)  ∧  (E(S) ≠ ∅) .
```

**引理 2**。`feas[S]` 为真当且仅当存在一台机器 k 和 S 的一个顺序，使 S 在窗口内按 `≺` 排完。

**证明**。若 `feas[S]`，取 `k∈E(S)`，由引理 1 的顺序在 k 上执行。反之，若某台 k 能做完 S，则 `k∈E(S)` 且该顺序给出 `f[S]<∞`。∎

### 2.3 单机划分数

**定义 2（β）**。

```text
β(R) = min { k : ∃ S_1,…,S_k ,  R = ⊔ S_j ,  feas[S_j] } .
```

等价 DP：

```text
g[∅] = 0
g[S] = 1 + min_{ T⊆S , low(S)∈T , feas[T] } g[S\T] .
```

`low(S)∈T` 只是固定「包含最低位的那一块」来消除划分的排列重复；不影响最优值。

**定理 1（Π 可靠性）**。若存在从 σ 出发的可行排程，则 `β(R)≤m`。因此 `β(R)>m ⇒ NO`。

**证明**。取任一可行排程，按机器把 R 分成 `S_1,…,S_k`（k≤m，空机器不计）。第 j 台机器上的任务按实际开始时间排序，满足优先、释放、期限和资格，故 `feas[S_j]`。于是 R 被分成 k≤m 个单机可行块，`β(R)≤k≤m`。∎

**注**：β 是**单机松弛**：它忽略了不同机器之间的时间耦合。所以 `β≤m` 只是「没有找到装填矛盾」，不是「一定可行」。这是它作为下界/证书的边界，也是 5 个 held-out 残例的来源。

### 2.4 见证

**定义 3（见证）**。对任意 `W⊆R`，`β(W)` 用同一 f/g 定义，只是把任务限制在 W。

**引理 3（单调性）**。若 `W⊆R`，则 `β(W)≤β(R)`。

**证明**。把 R 的任一划分与 W 相交，得到 W 的一个划分；每块是原来块的子集，`feas` 对子集封闭（同一台机器、同一顺序的前缀/子序列仍可行）。∎

**定理 2（见证可靠性）**。若 `W⊆R` 且 `β(W)>m`，则 σ 不可行。

**证明**。若 σ 可行，由定理 1 的证明，R 的按机器划分限制到 W 给出 W 的 ≤m 个单机可行块，故 `β(W)≤m`，矛盾。∎

**推论**。`W` 可以比 R 小得多；hard3#5 的 `W*` 只有 8 个任务。

### 2.5 机器不相容图与 CBC

**定义 4（不相容）**。对 `i,j∈R`，`i≠j`，令 `d_i=h−q_i`。若 `E_i∩E_j=∅`，或两种顺序都不满足

```text
c_i = est_i + p_i ≤ d_i ,
c_j = max(c_i, est_j) + p_j ≤ d_j
```

（且优先图不允许该顺序），则称 i、j **不相容**。

**定义 5（CBC）**。`G_inc=(R, {(i,j): i,j 不相容})`。若 `G_inc` 有 `m+1` 团 C，则 σ 不可行，证书就是 C。

**定理 3（CBC 可靠性）**。若 C 是 `G_inc` 的团且 `|C|>m`，则 σ 不可行。

**证明**。任一可行排程中，若 i、j 同机，则它们按某个顺序执行；把该顺序的最早开始版本与 i、j 的窗口比较，若连这个最松的版本都超期，真实版本更超期。因此同机 ⇒ 相容。团 C 中任两任务不相容 ⇒ 必须占不同机器 ⇒ 需要 |C| 台机器。|C|>m 矛盾。∎

**定理 4（CBC ⊆ Π）**。若 CBC 能闭，则 Π 也能闭；反之不然。

**证明**。C 是 m+1 团 ⇒ 每个单机可行块最多含 C 中一个任务 ⇒ 任何划分至少 m+1 块 ⇒ β≥m+1。反向分离见 7.1（hard3#5/deep：ω≤3，β=4；部分根 ω≤2）。∎

### 2.6 两段式触发

**定义 6（紧状态）**。

```text
lb0 = max( max_{i∈R}(est_i+p_i+q_i) , ceil(Σ_{i∈R}p_i / m) , max_i p_i )
slack0 = h − lb0 .
```

若 `slack0 ≤ pi_tau`（默认 4），称状态紧。Π 只在根节点（depth=0）且紧时调用。

**两段式**：

```text
if |R| ≤ w:        W = R
else:              W = top_w( p_i / max(1, h−q_i−est_i) )
βW = Π(W)
if βW > m:         NO
elif |R| ≤ ncap and W≠R:   βR = Π(R);  if βR>m: NO
```

`ncap=16`，`w=15`。对于 n=16，第一段是 15 点见证，第二段是完整 16 点精确；对于 n>16，只有第一段。

## 3. 算法

### 3.1 精确 Π 内核

```text
PI_EXACT(rem, est, q, h, m):
    if rem = ∅: return 0
    k ← |rem|;  idx ← 任务列表;  N ← 1<<k
    p,e,qq,succ,elig ← 限制到 idx 的局部数组
    f[0] ← 0;  inter[0] ← all-ones
    for S = 1..N-1:
        low ← S & -S;  j ← ctz(low)
        inter[S] ← inter[S^low] & elig[j]
        best ← ∞
        for i in sink_local(S):
            pm ← S ^ (1<<i)
            if f[pm] = ∞: continue
            st ← max(f[pm], e[i]);  en ← st + p[i]
            if en > h − qq[i]: continue
            best ← min(best, en)
        f[S] ← best
        feas[S] ← (best<∞) and (inter[S]≠0)
    g[0] ← 0
    for S = 1..N-1:
        low ← S & -S;  best ← m+2
        for T ⊆ S with low∈T and feas[T]:
            v ← (g[S^T] > m) ? m+1 : g[S^T] + 1   # 饱和加法
            best ← min(best, v)
        g[S] ← min(best, m+1)
    return g[N-1]
```

实现：`pi_fast.c` + `ctypes` 封装 `pi_fast.py`。C 内核只做局部 n≤20；调用方保证 k≤16（或 w=15）。`g` 在 `m+1` 处饱和：返回 `m+1` 表示「β>m」，不区分 4、5、…；证书只需要这个。

### 3.2 CBC（可选）

```text
CBC(rem, est, q, h, m):
    build G_inc by pairwise ONE(i,j) test
    C ← CLIQUE_AT_LEAST(G_inc, m+1)     # Tomita B&B + greedy coloring
    return C if |C|>m else None
```

`CLIQUE_AT_LEAST` 用贪心着色上界剪枝；命中 `m+1` 立即返回。若节点预算用完仍未找到，返回 None（不剪，安全）。

### 3.3 接进 PACE-Π 的搜索

```text
PACE-Π(σ,h):
  1  if R=∅: return YES([])
  2  if DEAD(σ): return NO
  3  σ←NORM(σ); A*←CANON(A); estt←est|R
  4  exact memo / F_sub / INT                            # v2.0，不变
  5  window 层: energy / clique / subset / HPACK          # v2.0，不变
  6  MINT / PACK-SET / SOP                                # v2.0，不变
  7  if ¬PACK(σ,h): F_pack.insert; return NO(PACK)        # v2.0，不变
  8  q ← tails(R)                                         # v2.0，不变
  9  if CBC and depth≤cbc_depth and |R|≤cbc_ncap:
         C ← CBC(...); if C: return NO(CBC(C))
 10  if Π and depth≤pi_depth and slack0≤pi_tau:
         β ← STAGED_PI(...); if β>m: return NO(Π(W,β))
 11  ready ← DHD(READY(R), R, p, est, q, h)               # tier 0.20
 12  K ← DCD(ready)                                       # tier 0.30
 13  for i in K:
         for k in machines(i):
             t ← max(A_k,est_i)
             if t+p_i+q_i(R\{i}) > h: continue
             r ← PACE-Π(child(i,k,t),h)
             if r=YES: return YES([(i,k,t)]+r)
 14  F_sub.insert(estt,A*); return NO(RESOLVE)
```

与 v2.0 的差异只有第 9–10 步；两者都在分支之前，只做**有证书的剪枝**。Π/CBC 返回 NO 时把 `bad[key]=h`，不插入 `F_pack`（`bad` 已足够）。

### 3.4 证书格式与检查

```text
Π 证书:  (kind='PI', W, beta)      beta>m
CBC 证书:(kind='CBC', C)           |C|>m, C 两两不相容
```

检查器：

```text
CHECK_PI(inst, σ, W, beta):
    recompute f/g on W with the same recurrence
    return g[W] == beta and beta > m
CHECK_CBC(inst, σ, C):
    for each pair (i,j) in C: check not COMPATIBLE(i,j)
    return |C| > m
```

Π 的检查是**重放计算**，不是短证明：它没有像 LP 对偶那样的 O(n) 证书。这是本轮明确交代的局限（见 9.7）。

## 4. 定理与证明

### 4.1 Π 可靠性

见定理 1。核心是「可行排程按机器分块 ⇒ 每块 feas ⇒ β≤m」。

### 4.2 见证可靠性

见定理 2。核心是「划分限制到子集仍是划分」。

### 4.3 CBC 可靠性

见定理 3。核心是「同机 ⇒ 相容」。

### 4.4 集成保持完备性

**定理 5（集成）**。PACE-Π 只可能比 v2.0 多剪「已证明 NO」的状态；未被剪的状态仍按 v2.0 的 DHD/DCD 分支。因此：
- 若 PACE-Π 返回 YES，排程可行；
- 若存在可行排程，PACE-Π 不会返回 NO（除非证书不可靠，而定理 1–3 排除了这一点）。

**证明**。第 9–10 步的剪枝都有定理 1–3 的证书；其余步骤逐字是 v2.0。对搜索树归纳：每个被剪子树确实无解；未被剪的分支覆盖 v2.0 的全部分支。∎

### 4.5 DHD 兼容

**定理 6（保守扩展）**。关掉 `pi`/`cbc` 后，PACE-Π 的 `decide` 与 v2.0 逐字相同（同一 `pace_v20.py` 的控制流）。

**证明**。第 9–10 步是新增的 `if`；关掉后不执行，其余代码未改。∎

### 4.6 顺序不变性（神经分支的边界）

**定理 7（NO 证明的顺序不变性）**。在没有 frontier 截断、没有 nodecap 的 DFS 中，对固定 h 的不可行实例，子节点顺序不改变被展开的状态集合，因此不改变证明节点数。

**证明**。`rec` 对每个状态穷举所有子节点；`bad` 记忆只抑制已经证明 NO 的状态。一个状态是否被证明与它第一次从哪个父状态到达无关。把所有子节点的排列看成同一棵 AND-OR 树的子节点置换，树的节点集合不变。∎

**注**：`F_sub` 的 K=48 截断和 `nodecap` 会破坏这个定理；本轮实测的 46 个 NO 实例没有触发截断差异（三种顺序都是 66 节点），但一般情形下不能把「节点数不变」当成定理之外的保证。

### 4.7 图证书分离

**定理 8（分离）**。存在实例使 `ω(G_inc)≤m` 但 `β(R)>m`。具体地，hard3#5 与 deep 8 的根上 `ω(G_inc)≤3`、`m=3`、`β=4`；其中 deep#0/#2/#4/#7 的 `ω≤2`。

**证明**。CBC 对 `m+1=4` 团返回 None（分支定界 + 着色上界验证）；Π 的 g 表在完整 R 上返回 4。两个计算都是可重放的。特别地，deep#0/#2/#4/#7 连 3 团都没有（`ω≤2`），仍然 β=4；这使分离比「ω=2 而 β=3」更强。∎

**意义**：CBC 不是「弱一点的 Π」，它是**不同类型**的证书；在装填型硬度上，团证书可以完全失效。

### 4.8 提议-验证的可靠性

**定理 9（提议-验证）**。设网络 `g_θ` 只做两件事之一：(a) 提议一个见证 `W⊆R`；(b) 提议一个子节点排列 π。若 (a) 的 W 被 Π/CBC 验证为 `β(W)>m`，则 σ 不可行；若 (b) 只改变子节点顺序、不删除任何子节点，则搜索的完备性与定理 5 相同。

**证明**。(a) 由定理 2；(b) 排序不改变子节点集合，归纳同定理 5。∎

**意义**：网络可以错，但错误只能让证书不命中或让搜索变慢，不能制造假 NO、也不能丢解。这是本轮把学习放在「提议层」而不是「判决层」的形式化依据。

## 5. 复杂度

设 `k=|W|`，`d=|Ready|`，`n=|R|`。

```text
f[S]:        O(n 2^k) 时间，O(2^k) 空间
g[S]:        O(3^k)   时间，O(2^k) 空间
Π 精确:      k≤16，3^16 = 43,046,721 次内层迭代
Π 15 点见证: 3^15 = 14,348,907 次内层迭代
CBC:         O(n²) 建图 + 团搜索（通常 10^-4 s，n≤40）
```

每节点成本：Π/CBC 只在 `depth=0` 且紧时调用，所以是**根上付一次**；搜索树内部仍用 v2.0 的 O(n) 层。若 Π 不剪，搜索复杂度与 v2.0 相同；若剪，整棵子树消失。

实测内核时间（C，单线程）：

| n | β 计算 | 时间 |
|---:|---|---:|
| 13 | 完整 | ~0.002 s |
| 14 | 完整 | ~0.005 s |
| 15 | 完整 | ~0.015 s |
| 16 | 完整 | ~0.045–0.061 s |
| 16 | 15 点见证 | ~0.015–0.017 s |

总时间：38 0.0317→0.0452 s（1.43×）；deep 0.0785→0.0985 s（1.25×）；held-out 0.5339→0.8698 s（1.63×）；easy 0.1592→0.1598 s（1.004×）。

**复杂度结论**：Π 没有改变最坏情况的指数性；它改变的是「指数花在哪里」——从搜索树的 `d!` 变成根上一次 `3^k`（k≤16）。对于 n>16，见证选择是启发式，最坏情况仍是 v2.0 的搜索。

## 7. 负结果与陷阱

### 7.1 图证书不够：ω≤3，β=4

见 6.9。CBC 在 hard3#5 + deep 8 上全部返回 None；Π 全部返回 NO。这不是「团搜索没调好」，是团证书的类型不够：装填型 obstruction 不需要一个大的两两不相容团，甚至不需要三角形（deep#0/#2/#4/#7 的 ω≤2）。

### 7.2 神经分支不能缩小 NO 证明

见定理 7 与 6.11。NO 证明节点数对子节点顺序不变；学习只能改变时间/找解顺序。任何声称「GNN 把 NO 节点数降了 X%」的说法，必须解释它是通过更强的剪枝（如 Π）还是通过 frontier 截断的副作用，否则与定理冲突。

### 7.3 神经门没有负类

250/250 正例，见 6.11。负类为空时，学习门只能退化成常数；held-out 的 5 个 β=3 例外太少，且误判代价不对称（漏一个 β=4 会回到 31–130 节点）。所以默认「紧就跑」是合理的，不是偷懒。

### 7.4 Π 是松弛：β≤m 不代表可行

5 个 held-out 残例（31/26/47/78/130）和 large_het#1（21）都是 β=3。它们需要的是**非装填**的推理（顺序、时间耦合、非抢占析取），不是更大的划分 DP。这是 Π 的边界，不是 bug。

### 7.5 15 点见证会漏

只用 15 点见证、关掉 n≤16 的 exact fallback 时，held-out 从 357 退化到 524。两段式是必要的：先便宜地试，失败再精确。对 n>16 没有 exact fallback，所以 n>16 的见证选择是**启发式**，选不中就退回 v2.0。

### 7.6 时间不是免费的

38 1.43×、deep 1.25×、held-out 1.63×。Π 的收益是节点数，代价是根上 0.005–0.06 s 的内核。对「根下界已经接近 OPT」的实例，Π 可能是纯开销；`pi_tau` 门就是为此存在的。

### 7.7 证书是重放，不是短证明

Π 证书 `(W,β)` 需要检查器重跑 f/g；它没有 LP 对偶那样的 O(n) 短证书。CBC 证书是短的（团 + 两两不相容），但 CBC 在硬例上不命中。想让 Π 证书变短，需要找一个「权重 y 使每个单机可行集权重 ≤1 且 Σy>m」的对偶证书；本轮没有做。

### 7.8 est/q 的侧条件

Π 的 f 用 `est_i` 作释放、`h−q_i` 作期限。安全方向是：

- `est_i` 可以**低估**（任务更早可开始，β 更小，剪得更少，但仍可靠）；
- `q_i` 可以**低估**（期限更松，β 更小，仍可靠）；
- `est_i` 高估或 `q_i` 高估会**收紧**窗口，可能把可行块判成不可行，从而假剪。

PACE 里 `est` 是精确最长头，`q` 是精确最长尾；任何对它们的调高/调低都要重证。CBC 的 ONE 测试同理。

### 7.9 NORM 与 Π 无关

Π/CBC 不需要 NORM：它们只用 `est` 的下界方向和 `q` 的上界方向。`DHD` 的 `v−1` 面仍需要 `normalize=True`；`dhd=True` 时强制打开，和 v2.0 一样。

### 7.10 frontier 截断破坏严格单调

`F_sub` 的 K=48 截断与访问顺序可能让个别实例的节点数不再严格单调；本轮 38/deep/held-out 没有观察到损失，但定理 7 的「顺序不变」只在无截断时成立。

### 7.11 没有形式化验证

7,500 随机 + 106,021 穷举 + 独立 YES 验证是很强的证据，但不是 Coq/Lean；定理 1–9 是纸面证明 + 可重放内核。

### 7.12 n>16 的自然紧实例未系统测试

planted 是合成的；natural n=18–22 的 9 个随机探针全部根闭（v2.0 的旧结论），没有给 Π 发挥的机会。PSPLIB 未接。

### 7.13 神经提议接口（未启用，但接口是明确的）

如果要把 GNN 接进来，本轮建议的接口是「提议-验证」，不是「学习一个下界」：

```text
x_i = [ p_i/h, est_i/h, q_i/h, slack_i/h,
        indeg_i/n, outdeg_i/n, |desc_i|/n, |anc_i|/n,
        |E_i|/m, 1[est_i+p_i+q_i=h] ]
h_i = ReLU(W1 x_i + b1)
z_i = ReLU(W2 [ h_i , mean_{j∈pred(i)} h_j , mean_{j∈succ(i)} h_j ] + b2)
s_i = w^T z_i
W   = top_k(s)          # 或按 s 排序子节点
```

用法只有两种：

1. `W = top_k(s)`，然后跑 `Π(W)`；`β(W)>m` 才剪，否则不剪。
2. 按 `s_i` 排序 `K(σ)` 的子节点；不删除任何子节点。

由定理 9，这两种用法都不会破坏可靠性。训练标签可以来自小实例的精确 oracle（哪个首任务能通向可行排程；或 leave-one-out 的 β 边际）。本轮没有训练它，原因是 6.7/6.11 的两个负结果：NO 证明节点数对顺序不变，且紧状态的 β 标签 250/250 为正；在这两个位置上，网络没有可观测的收益。**接口保留，默认关闭。**

## 9. 已知风险

1. **最坏复杂度没变**：Π 是 O(3^k) 的根上证书，不是多项式算法；n>16 的见证是启发式，选不中就退回 v2.0 的指数搜索。
2. **Π 只覆盖装填型硬度**：5 个 held-out 残例 + large_het#1 的 β=3；它们需要非装填推理，Π 不参与。
3. **收益集中**：38 例的 1.517× 全部来自 hard3#5；deep 的 27.88× 来自 6 个实例；large_* 与 easy 不变。
4. **时间开销**：38 1.43×、deep 1.25×、held-out 1.63×；对根下界接近 OPT 的实例，Π 可能是纯开销。
5. **15 点见证会漏**：held-out 上单独用 15 点见证从 357 退化到 524；两段式只对 n≤16 有 exact fallback。
6. **n>16 无完备装填剪枝**：见证选择是密度排序；planted 是松弛 decoy，不能代表自然紧实例。
7. **证书是重放，不是短证明**：Π 检查器要重跑 g 表；没有对偶证书。
8. **CBC 在硬例上完全失效**：ω≤3、β=4；CBC 只是 n>16 的便宜预筛，不是主层。
9. **est/q 的侧条件**：`est` 高估或 `q` 高估会造成假剪；当前 `est/q` 精确，但任何改动都要重证。
10. **frontier 截断**：K=48 与访问顺序可能破坏严格单调；定理 7 只在无截断时成立。
11. **NORM 仍是 DHD 的硬前提**：Π 不需要，但 `dhd=True` 仍强制 `normalize=True`。
12. **没有形式化验证**：7,500 随机 + 106,021 穷举 + YES 独立验证，不是 Coq/Lean。
13. **规模**：n≤16（精确 Π）/ n≤24（planted 见证）/ m=3；PSPLIB 未测，n≥25 的紧实例未系统测试。
14. **神经网络的负结果有边界**：它只说明「本任务、本分布、本证书接口」下学习没有位置；不说明 GNN 在别的 B&B 任务上无用。
15. **CBC 的团搜索有 nodecap**：预算用完返回 None（不剪，安全），但可能漏掉本可闭的状态。

---

## 10. 一句话最大风险

**Π 的 3^k 只在根上付一次，且 k 被 15 点见证截断；但 n>16 时见证是启发式，选不中硬核就退回 v2.0 的指数搜索，最坏情况仍是 n!。**
