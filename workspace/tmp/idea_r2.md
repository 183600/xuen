### 第 2 轮灵感驱动研究记录（承接 CADVS-v5）

**灵感词**：关节空间控制、无刷电机

**继承关系**：状态文件记录到 CADVS-v5（IP-493~496）：CGE 把提议从离散规则库换成条件流匹配，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29，七硬门不变，留下 R53（OOD 幻觉）、R57（固化自指博弈）等未解风险。本轮不推翻 v5，而是补 v5 一个被结构性忽视的缺口：**v5 的全部证书都定义在任务空间 (pose, wrench) 上，却默认这条任务轨迹可以被关节控制器与无刷电机「原样执行」**。真实执行链是 任务空间 → 逆运动学/逆动力学 → 关节空间 (q, q̇, τ) → FOC 电流环 → PMSM/BLDC 力矩。这条链上有奇异位形、关节限位、自碰撞、力矩-转速-电压-热包络、电流环跟踪滞后、齿槽/换相转矩脉动、编码器量化与回馈制动过压。两个灵感词统一为主题「**认证可实现执行**」（Certified Realizable Execution, CRE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍不增**（维持七门，继续偿还 R52 锚点维护负债），把「可实现性」折进物理门 MSRG、末点门 EEK 与平衡门 BCK 的评分谓词，而不是新增第八门；执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **关节空间控制 → 任务空间证书必须经过「提升算子」才算数，它是必要不充分条件**。直觉上，v5 说「这条末端轨迹通过七门」，但机械臂可能根本走不出来：高速直线运动需要超过关节速度上限；绕过障碍的逆解可能穿过奇异位形；冗余臂的某个逆解会撞到自身。关键不是再加一道门，而是承认 v5 的证书是**任务空间谓词**，而执行是**关节空间事件**。定义集合值提升关系 R(x) = {(q, q̇, τ)}：满足正运动学一致、逆动力学一致、关节限位/速度/力矩约束与自碰撞约束。**定理 9（提升必要性）**用构造性反例证明 ∃x ∈ Exec_v5 使 R(x) ∩ A = ∅——任务空间已认证但关节空间不可实现。于是把可实现性写成合取强化：kc_phys^v6 = kc_phys^v5 ∧ kc_real，仍只紧不松。冗余自由度不是负担而是资源：**边际最大化冗余消解（MMRR）**在所有逆解中选使「最坏时刻证书余额」最大者，把「多解」变成「选最安全的解」。

2. **无刷电机 → 力矩不是免费的，执行器包络把「证书边际」变成「可核算的误差预算」**。直觉上，v5 的 wrench 证书假设关节能精确输出任意力矩；真实 PMSM/BLDC 有力矩-转速-电压-热包络（高速时反电动势吃掉电流裕度、绕组温升触发降额、母线电压跌落、回馈制动过压），有电流环带宽导致的跟踪滞后，有齿槽/换相转矩脉动，有编码器量化、齿隙与无感低速观测误差。定义执行器可行集 A：存在 (i_d, i_q) 使 τ = (3/2)pλ_m i_q、|i| ≤ i_max(T_w)、|v| ≤ V_max(V_dc)、T_w ≤ T_max，且 |τ − τ_ref| ≤ ε_τ。核心理论增量是**证书传递定理（定理 10）**：任务空间边际 ρ 经雅可比传递到实际执行，姿态误差 ≤ σ_max(J)·ε_q + ε_kin，力/力矩误差 ≤ σ_min(J)^{-1}·ε_τ + ε_model；只要 ρ 大于对应传递误差，实际执行仍满足原门。注意 1/σ_min(J)：**奇异位形会把微小力矩误差放大成巨大 wrench 误差**——这是关节空间控制第一次把「接近奇异」的经典危险接进认证框架。工程上把它做成「边际台账」（margin ledger）：每个误差源借记边际，余额为负即 fail-closed。

3. **两者结合的关键洞见**：v5 问「任意生成器下证书边界是否不变」；v6 问「当证书必须穿过关节空间与电机才能落地时，证书还剩下多少、在哪一步失效」。答案由三件事拼成：集合值提升（把任务谓词变成关节可实现性）+ 误差预算传递（把边际按雅可比与执行器包络折算）+ 非对称收紧（热降额、电压跌落、奇异度只紧不松）。v5 的定理 6（提议无关）在此推广为**实现无关性（定理 11）**：换逆解分支、换冗余消解、换电机控制律都只改「尝试执行的分布」，不改门定义的信任边界；可实现性检查只缩小执行集，不扩大。

**形式化目标（增量）**：
1. 关节提升：R(x) = {(q, q̇, τ) : f(q)=pose(t), 逆动力学成立, q∈[q_min,q_max], |q̇|≤q̇_max, |τ|≤τ_max, 自碰撞=0}；因冗余而是集合值。
2. 执行器包络：τ_max(ω,T_w,V_dc) 由电流圆 ∩ 电压椭圆 ∩ 热降额给出；ε_τ = ε_foc + ε_ripple + ε_est；回馈制动另加 τ_min(ω,V_dc)。
3. 边际台账：ρ_i^real = ρ_i − L_i·(σ_max ε_q + ε_kin, σ_min^{-1} ε_τ + ε_model)；可实现当且仅当 min_i ρ_i^real ≥ 0 且 σ_min ≥ σ_floor 且包络可行。
4. 定理 9（提升必要性/任务空间不充分）、定理 10（证书传递/边际守恒）、定理 11（实现无关性与非对称收紧）、定理 12（七锚完备性保持）。
5. MMRR：q* = argmax_{q∈R(x)} min_t ledger_margin(q(t))，在关节限位/自碰撞约束下做轨迹级 max-min。
6. Exec_CADVS-v6 = {x ∈ Exec_CADVS-v5 : ∃(q,q̇,τ) ∈ R(x) ∩ A, min_i ρ_i^real ≥ 0} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**误差预算的不可观测放大**——ρ_i^real 依赖 σ_min(J)、力矩跟踪误差 ε_τ、热模型与摩擦模型，这些都是估计量；靠近奇异位形时 1/σ_min 把微小估计误差放大成证书失效，预算取保守则执行集塌缩到不可用、取乐观则已认证轨迹静默违例，而且这种失效发生在「证书看起来仍然成立」的关节空间里。
