# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「语义地图」×「面部表情识别」）

> 第 57 轮把安全的赌注从"模型置信"移到"证据质量"，再用元少样本、跨模态对账、个性化信任把证据质量本身做成可校准、可对账、可问责的对象。但它仍默认两件事：**(a) 证据是"就地"的**——每到一个区域几乎从零取证，地图只是信念的仓库，不记录"这条证据从哪来、能迁到哪、在哪被推翻"；**(b) 人是"有按钮的"**——人的状态只经标注/确认进入系统，而"提问"本身被当作免费、无偏、无副作用的动作。本轮两个灵感正好拆这两个默认。**语义地图**让证据第一次拥有"地址、邻居、谱系、撤销"——但地图同时是错误放大器：一次语义误标会沿拓扑边与相似边传染，别名区域会让同一个错误看起来像多个独立见证；**面部表情识别（FER）**让"人"从离散按钮变成连续侧信道——但表情是表达的观测，不是情绪、意图或同意的读数，把它当授权信号是 fail-dangerous。两者合流为一条克制的原则：**地图给证据一个"址"，表情给交互一个"度"，但两者都不给"权"**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"证据须有址可溯、同意须有界可续、表情只可降险不可授权"**。

核心矛盾：
- **H32（地图传染 vs 独立见证）**：语义地图让"相似区域共享先验"变得廉价，但共享先验不是共享证据。拓扑邻接、语义相似、同一云端版本、同一操作者批注都会让错误相关；"十个区域都同意"可能只是同一个误标走了十条迁移边。地图越有用，越容易把局部错误放大成全局共识。
- **H33（表情可读 vs 不可读/可博弈）**：FER 是文化、个体、遮挡、姿态与场景条件化的表达观测；同一张脸可以是疼痛、专注、困惑或礼貌性掩饰。把"没有反对的表情"读成同意，或把"皱眉"读成拒绝，都会在最需要保守时系统性误判。表情还带来隐私、群体公平与"被机器人反向塑造"的伦理风险。
- **H34（持久同意 vs 同意可变）**：地图的持久性可以成为同意的记忆，让"不"跨到访生效；但也会把一次"可以"冻结成永久授权，把拒绝变成可被反复询问消磨的软约束。人、任务、接触力与环境都会变，同意必须既能记住，也能过期。

## 0. 直觉与动机

**灵感 1（语义地图 → 从信念仓库到"证据地图 + 谱系图"）**
直觉：地图最被低估的不是"知道哪里是什么"，而是**知道一条证据属于哪里、从哪里来、还能去哪里**。给每个区域建三层地址：几何地址（在哪）、拓扑地址（与谁相连）、语义地址（像什么）；给每条证据建谱系父指针（哪次探针/到访/标注/云端先验产生了它，又被谁引用）。于是"跨区域迁移"不再是隐式的相似度加权，而是一张显式的、可审计的**迁移边**：从 r 迁到 r' 是一次有许可证的类比，不是一份新见证。地图还必须能表达"我不知道这里像不像那里"——别名关系 `r≈r'`（两个地方在感知上不可区分）与语义-证据矛盾 `C_𝓜(r)`（地图说 A、本地证据说 B）是两种必须显式登记的失败模式，而不是被平均掉的噪声。

**灵感 2（语义地图 → 有界传染的迁移图）**
直觉：地图传染像流行病。若允许"相似就迁移、邻居再迁移"，一条错误会沿传递闭包扩散；若只允许**一跳、带衰减、且每次迁移都要本地探针确认类比**，传染半径就被结构性地限制在 `1+outdeg` 个区域内。更进一步，迁移边不是永久真理：源证据一旦被事后证伪，沿谱系闭包把所有后代迁移证据一起隔离，直到重新取证。这把第 57 轮"坏证据长寿"升级为"**坏证据有地址，因此可以被精确召回**"。

**灵感 3（面部表情识别 → 表情是咨询信号，不是情绪/同意读数）**
直觉：把 FER 想成汽车仪表盘上的警告灯：灯亮不等于知道发动机哪里坏，但足以让你减速、靠边、打开引擎盖。表情能做的只有"让系统慢下来、问得更清楚、换一种解释、增加佐证、缩短超时"；它不能"让系统更敢赌"。因此本轮把 FER 放进**咨询通道**而非证据门：`a_t` 只能经保守动作集 `A_adv` 改变交互参数，绝不能成为 `EV-*` 证据类，更不能替代明示同意。关键契约是**表情非干涉**：在证据与同意固定时，把任何表情换成任何别的表情，不可逆承诺集合只能不变或变小。

**灵感 4（面部表情识别 → 用表情发现"没听懂"，而不是发现"同意了"）**
直觉：FER 最有价值的人机用途不是读情绪，而是检测**理解失败**：皱眉、凝视漂移、困惑性微表情、反复看向同一图块，往往意味着地图解释没被读懂，而不是任务被拒绝。于是表情触发的是**理解探询**（"你看到的是哪一块？要不要换触觉/语音？"），不是同意推断。理解探询可以改变渲染模态与节奏，却不改变证据与同意状态；它把第 57 轮 MXI 的"解释渲染"从开环升级为有反馈的闭环，同时明确拒绝"读心"。

**灵感 5（合流 → 同意地理：地图记住"不"，表情只把问题问得更好）**
直觉：把同意也画进地图：每个区域、每种接触级别、每个材料上下文版本都有一个同意状态（未知/已授权/已拒绝/已过期）。拒绝跨会话持久，授权有期限且遇材料变化即失效；表情与超时只能把状态推向更保守，显式人类动作才能放松。于是"地图说在哪、表情说何时问、人说明示是否"三者各司其职：**地图给址、表情给度、人给权**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（分层证据地图 SEA）** `𝓜=(G,T,S,E,L,ν)`：`G=(V,E_G)` 为度量-拓扑图；`T` 为拓扑关系（邻接/包含/连通分量）；`S(r)` 为语义标签与接触属性后验；`E={e_i}` 为证据账本，`e_i=(r_i,type,payload,src,t_i,w_i,ver_i,parent_ids)`，`parent_ids` 指向其派生证据；`L` 为证据谱系 DAG；`ν` 为边端/云端/操作者版本向量。区域信念 `b_r` 与语义 `S(r)` 分账。定义语义-证据矛盾 `C_𝓜(r)=D_KL(S(r)||b_r^{sem}) + λ·Σ_{r'∈N(r)} d(S(r),S(r'))`；别名关系 `r≈r'` ⇔ 地点识别嵌入距离 `≤θ_alias` 且结构签名差 `<θ_struct`；迁移边 `E_tr⊆V×V` 与 `E_G` 分离，深度 `ℓ(r→r')≤L_tr`（默认 1），权重 `w_tr(ℓ)≤w_max·γ^ℓ`。地图是**索引**而非真值：`S,E,ν` 都是可错的声明，必须带来源与版本。

**定义 140（迁移证据许可证 TEL 与 EV-map）** `TL(r→r')` 成立 ⇔ (i) 结构签名匹配 `≥θ_struct`；(ii) `S(r),S(r')` 对目标接触类型语义相容；(iii) `r≉r'`（非别名）；(iv) 两者均在覆盖域内且 `C_𝓜≤θ_c`；(v) 版本可兼容；(vi) 源区域未被隔离。迁移边只能由一次**本地探针确认类比**创建，云端先验不得直接建边。证据类 `EV-map(e,r→r')` 可入账 ⇔ `TL` 成立 ∧ 接触级别 `≤L1` ∧ 一跳 ∧ `w_tr≤w_max`；`EV-map` **不得进入不可逆接触的必要证据集**，在 L1 至多替代一次佐证。事后证伪源证据 `e` ⇒ 沿 `L` 的后代闭包与 `E_tr` 的迁移后代全体隔离，直至重新本地取证（`Q(L)` 闭包）。

**定义 141（表情咨询通道 AAC 与非干涉契约）** FER 输出 `a_t=(AU 向量, valence, arousal, uncertainty, engagement)`，带分组误差模型 `ε_face(g)`；但 `a_t` 是对**表达**的观测，不是对情绪、意图或同意的读数。定义保守动作集 `A_adv={slow_down, shorten_timeout, increase_corrob, switch_modality, notify, ask_explicit}` 与交互参数上的保守偏序 `⪯_c`（佐证数越大、超时越短、步态越低、同意级别越高越保守）。咨询映射 `g(a_t,s_o,ctx)∈A_adv` 只能把参数沿 `⪯_c` 向保守方向移动；禁止集 `{authorize, decrease_corrob, extend_timeout, treat_as_consent, supply_evidence}`。**表情非干涉**：固定证据与同意，任意替换 `a_t→a'_t`，不可逆承诺集合满足 `K(π;a)⊆K(π;a_0)`（`a_0` 为无表情基线）。隐私契约：端侧临时特征、原始帧不落盘、保留 `≤τ_face`、可退出；公平契约：worst-group `ECE_g≤ε_face,g`。

**定义 142（表情触发理解检查 AIC）** 理解失败分 `κ_comp(a_t,Exp,hist)`（困惑微表情、凝视漂移、重复查看同图块、确认时延异常）；`κ_comp>θ_comp` ⇒ 发起**理解探询**（"你看到的是哪块/是否换一种解释"），预算 `k_comp`/L2。AIC 只可改变解释渲染模态、重复解释、放慢节奏；不得改变证据门、同意状态或授权级别。误报代价计入交互成本，不得用"没困惑"反推"已同意"。

**定义 143（同意地理 CG）** 同意状态 `c(r,ℓ,κ)∈{⊥,granted,denied,expired}`，`ℓ` 为接触级别，`κ` 为材料上下文版本（力包络/任务/环境版本）。转移规则：只有**显式人类动作**可置 `granted`；`denied` 至少持久 `T_deny` 且跨会话保留；`granted` 在 `T_grant` 后或 `κ` 变化时自动 `expired`；超时只能落向 `denied/⊥`；表情只能把状态推向更保守。重问预算：同一会话同一 `(r,ℓ,κ)` 至多重问 1 次，除非出现**新材料事实**；日志不可删改。**同意单调性**：无显式人类动作时，所需同意级别不下降；禁止"问到同意为止"。

**定义 144（证书 J_q 与探-诺-演-问 PCX-MF）** 证据类为 `EV-probe*/visit/margin/xmodal/human/map`；`EV-face` 不存在。`EV-map` 仅限 L1；不可逆接触必要证据集 `={EV-probe*∨EV-margin}∪人类佐证`，不含 `EV-map` 与 `EV-xmodal`。`J_q=(J_p,map_ver,lineage_root,transfer_log,alias_audit,consent_geo_log,affect_log,fairness_audit,comprehension_log)`，继承 `J_p` 全检，并新增：迁移许可证完备、别名审计通过、同意地理无未决拒绝、表情日志只含咨询动作且通过非干涉回归测试。

## 2. 关键算法伪代码（完整版见产物区）

def sea_update(M, e):                                  # IP-139: 证据入图 + 谱系
    M.E.append(e.with_parents(M.lineage.parents_of(e)))
    M.L.add(e.id, e.parent_ids)
    M.S[e.r] = bayes_update(M.S[e.r], e.sem_like, w=e.w)
    M.C[e.r] = contradiction(M.S[e.r], M.b[e.r], M.G.neighbors(e.r))
    M.alias.audit(e.r); M.ver.bump(e.r)
    return M

def transfer_evidence(M, r, r2, level):                # IP-140: 一跳 + 衰减 + 仅 L1
    if not TL(M, r, r2) or M.alias.aliased(r, r2): return None
    w = min(W_MAX_TR, M.b[r].w * GAMMA_TR)
    return Evidence('EV-map', r2, like=M.b[r].like, w=w,
                    parents=[M.lineage.root(r)], level=level) if level <= 1 else None

def affect_advise(a_t, s_op, ctx, audit):              # IP-141: 只许降险
    adv = g(a_t, s_op, ctx)                            # 从 A_adv 中选
    params = apply_conservative(s_op.params, adv, order=PREC_CONSERVATIVE)
    audit.log(adv, only_demotions=True)                # 不记录原始面部帧
    return params                                      # 证据门与同意状态不可被改写

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SEA | O(\|ΔE\|·log\|V\|+d_s) 增量；谱系 O(\|E_L\|) | O(\|V\|·d_b+\|E_L\|) | 来源/版本诚实、矛盾与别名显式登记 |
| TEL | O(deg(r)·L_tr) | O(\|E_tr\|) | 一跳、衰减、仅 L1、证伪闭包完整 |
| AAC | O(1)/帧 + 摊还校准 | O(\|操作者\|) | 非干涉、分组校准、原始帧不落盘 |
| AIC | O(1)+O(k_comp) | O(\|Exp\|) | 只改渲染/节奏，不改证据/同意 |
| CG | O(1) 查表 | O(\|V\|·\|ℓ\|) | 显式动作才放松、拒绝持久、授权过期 |
| PCX-MF | O(\|CP\|·(k_p+k_c+k_r)·(C_VOI+d_φ+\|E_tr\|)) | O(\|V\|+\|σ\|) | 悲观 VOI、三预算终止、四态完备 |

**正确性定理（Place-indexed Affect-monotone Commitment Soundness, PACS）**：在 A33–A40 上加 **(A41)** 地图谱系与版本诚实、`TL` 充分、别名/矛盾检测召回满足声明、迁移深度 `≤L_tr`；(A42) 表情咨询只含 `A_adv`、非干涉回归测试通过、分组校准诚实、无原始帧留存；(A43) 同意地理持久且只有显式人类动作可放松。则：
(i) **有址承诺健全性**：ID 路径 `P(fail)≤δ_f+ε_meta(k)+δ_probe+ε_h+δ_tr·1[EV-map∧L1]+δ_ood·α_conf`；不可逆接触因禁用 `EV-map/EV-xmodal`，其界不含 `δ_tr/δ_xm`；
(ii) **表情非干涉**：固定证据与同意时，表情通道不改变不可逆承诺集合的上界，只可缩小；`δ_face` 只进入可用性/时延项，不进入 `P_fail` 的安全项；
(iii) **同意单调性**：无显式人类动作时所需同意级别不降，拒绝跨会话持久，授权遇材料变化自动过期，重问预算有限；
(iv) **传染有界**：`L_tr=1` 且 outdeg 有界 ⇒ 单条误标的迁移污染半径 `≤1+outdeg_max`；源证伪后谱系闭包隔离在一个版本周期内完成；
(v) PCX-MF 在 `k_probes+k_cons+k_comp+k_reask` 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是**地图把局部误标变成可迁移的共识、表情把"看见"误当成"理解"**——若迁移许可证与别名检测失守、且表情被误读为同意，系统会在证据没有增加、同意没有给出时显得更确定、更体贴，实际却把错误传播得更快、把拒绝绕过得更顺；必须以一跳迁移、谱系闭包隔离、表情只降险不授权、同意地理显式可续四重护栏，宁可让地图"少知道一点"、让人"多被问一句"，也不让地址变成谣言、表情变成授权。
