# 第 3 轮迭代（灵感循环 v3：「数据集」×「运动学」）—— 数据集是可逆的运动学语料，恢复数据不必等仿真

> **承接 v2（UIP-01′~15），但换一个更底层的问题：数据从哪来、动作凭什么可信。** v2 把「人为撤回」认定为最大数据空白，并打算用 Gazebo 造恢复数据（UIP-12）。本轮两个灵感词把答案拉回到选手已经拥有的东西：**32 个公开数据集本身就是一份带视频、带关节目标、带多坐标系冗余的运动学记录**。由此得到两个反直觉结论：
>
> 1. **时间反演就是最便宜的干扰发生器。** 对一条关节目标轨迹做「前缀 + 反向后缀 + 正向重做」，得到的仍是一条**运动学可行**的轨迹；若同时反向播放对应视频帧，就得到一条完整的「完成→被撤回→恢复」episode。它不需要仿真器、不需要新采数据，且天然对齐计分步。
> 2. **数据集的冗余不是噪声，是免费标签。** 同一时刻的 ee 位姿同时给了 base 系与 torso 系，腿部同时给了 `lower_body[15]` 与 `left_leg/right_leg[6]`，相机还给内参/外参；这些量之间的 SE(3) 复合关系可以逐帧校验，误差就是「数据/接口/关节顺序」是否对齐的硬证据。

**本轮新增的硬结论**：数据集的动作/状态键是接口的**超集**，且含多套可互相校验的运动学表示；接口只给 `[7]` 却不给关节名。因此「把数据集动作直接喂给接口」之前，必须做一次**运动学对齐审计**，否则一个静默的关节顺序错误就能让所有 IK/验证器失效。

## 1. 先给直觉，再给定义

### 1.1 直觉：三条不需要仿真的观察

1. **撤回是「倒放」，恢复是「重播」。** 人把拉链拉开，等价于把「拉上」这段视频倒放；你要恢复，只需把「拉上」再播一遍。数据集里本来就有这两段。把它们拼成 `前缀 → 倒放后缀 → 正向后缀`，就是一条「完成→被撤回→重做」的训练 episode。
2. **关节空间倒放永远可行。** 位置控制下，轨迹 `q_0…q_T` 是一串关节目标；倒放 `q_T…q_0` 访问的是同一组关节角，因而**关节限位与速度幅值都不变**。这是不需要 IK、不需要动力学、也不需要仿真器的可行性保证。
3. **冗余表示是免费考试。** 同一帧的 ee 位姿被给了两套坐标系、腿部被给了两套关节向量、相机被给了内参外参。它们必须满足固定的 SE(3) 复合关系；不满足的地方就是数据坏段、关节顺序错、坐标系标定错，或者 `recomputed_ee_valid=0`。

### 1.2 严谨定义

- **单臂构型空间**：`Q ⊂ R^7`，关节限位 `Q_lim`，速度上限 `v_max`。一条长度为 `T+1` 的关节轨迹 `q_{0:T}` 可行，若 `q_t ∈ Q_lim` 且 `‖q_{t+1}−q_t‖/Δt ≤ v_max`。
- **正运动学**：`F: Q → SE(3)`，把关节角映射到夹爪 ee 位姿；`F` 由 URDF 与关节顺序共同决定。
- **运动学残差**：对观测到的手臂关节 `q_t` 与 ee 位姿 `p_t`，定义
  `r_t = d_SE3(F(q_t), p_t)`，其中 `d_SE3` 取平移欧氏距离与旋转测地距离的加权和。
- **冗余残差**：`r_t^frame = d_SE3(T_base_torso · T_torso_ee, T_base_ee)`；`r_t^leg = ‖lower_body[0:15] − concat(left_leg, right_leg, waist_state_joint)‖`。
- **撤回算子**：给定轨迹 `A=(a_0…a_T)` 与撤回点 `p`、撤回跨度 `h`，定义
  `R_{p,h}(A) = (a_0…a_p, a_{p-1}…a_{p-h}, a_{p-h+1}…a_T)`。
  **命题**：若 `A` 在关节空间可行，则 `R_{p,h}(A)` 的手臂部分也可行（同一组构型反向遍历，限位不变、速度幅值不变）。证明只需注意反向段的相邻差分为原段差分的相反数。
- **撤回状态**：在 `R_{p,h}(A)` 中，`p` 时刻子目标为 `done`，`p+h` 时刻（倒放结束）为 `regressed`，`T` 时刻为 `done`。这给出无需人工标注的三态标签。
- **进度势**：对任务 `k` 定义 `Φ_k(o_t) ∈ R`，在成功推进时单调上升（例：ee 到目标 keypoint 的距离取负、插入深度、堆叠高度、拉链闭合长度）。`regressed` 事件定义为 `Φ_k` 在局部极大后下降超过阈值 `δ`，或关节速度在夹爪闭合时出现持续反向。
- **目标相对表示**：把动作表示为「相对当前 ee 位姿 / 相对被操作物关键点」的增量 `Δ ∈ SE(3)`，而不是绝对 base 系位姿；当物体整体平移 `G ∈ SE(3)` 时，目标动作按 `G·Δ` 协变。

> 直觉与定义的分工：直觉告诉我们「倒放可用」，定义告诉我们「倒放只在关节空间严格可行、在接触/液体/热过程中只是近似」。这条边界决定了下面每一项的适用范围。

## 2. v2 清单诊断：哪些该升级、哪些该降级

- **升级为「数据+运动学」双引擎**：
  - **UIP-01′（RHPV-D）**：保留「检测撤回→重做」的状态机，但把验证器从「外部 VLM / 大模型」换成 **UIP-19 KCV（解析运动学+进度势）**，既降延迟又规避单模型合规风险。
  - **UIP-09′（DCR-R）**：保留为行为策略，但其训练数据不再依赖 Gazebo，而由 **UIP-17 KRA** 从公开数据集直接合成。
- **降级/改写**：
  - **UIP-12 DRF（Gazebo 扰动-恢复数据工厂）**：从「主数据源」降为「接触级校验器」。理由：KRA 能免费造出关节/视觉都对齐的撤回数据；Gazebo 只用来检查倒放在接触丰富任务上是否物理可信。
  - **UIP-11 GSO（Gazebo 计分神谕）**：从「全任务裁判」降为「代表任务的抽查裁判」。理由：KDA 能用数据自身的冗余给出更强、更便宜的结构校验；GSO 仍保留用于最终校准。
  - **UIP-04 / UIP-10**：继续封存。运动学校验不需要在运行期切换 `joint/ee` 控制空间，因此不复活 UIP-10。
- **保留**：UIP-02′（计分步安全网）、UIP-05（语言→可供性）、UIP-08′（多端口延迟工程）、UIP-13（自适应块长）、UIP-14（模块化技能图）、UIP-15（可信度安全阀）。
- **新增（本轮命中「数据集×运动学」）**：UIP-16 KDA、UIP-17 KRA、UIP-18 KSS、UIP-19 KCV、UIP-20 KRT。

## 3. 瓶颈假设（本轮更新）

- **H1（最高杠杆）**：若「人为撤回」计入正式评测，则**数据集时间反演**能在零仿真、零新采数据的前提下，造出视觉与关节都自洽的撤回-恢复样本；其边际收益大于再训一个更大的策略。
- **H2**：数据集的多坐标系/多关节表示冗余足以检测出**关节顺序、坐标系、单位、帧率**四类静默错误；不做这次审计，后续 FK/IK/验证器全部建立在流沙上。
- **H3**：解析运动学验证器（FK 残差 + 进度势 + 速度反向）在「撤回检测」上的延迟比 VLM/Gazebo 低 2–4 个数量级，适合放进每次 `get_action` 的内环。
- **H4**：时间反演在**准静态、可逆接触**任务（拉链、开合、叠/翻、拧/回）上近似成立；在**液体、粉末、塑性变形、粘附**任务上不成立，必须由 KDA 的任务分类器排除或由 GSO 校验。
- **H5**：目标相对表示（KRT）能吸收「物体平移」这一最常出现的泛化轴，但它需要物体/关键点位姿；若感知误差大于增益，反而会把误差写进动作。

## 4. 候选发散与合并 → v3 清单

围绕「数据集」发散：数据审计、数据反演、数据重标注、数据配比、数据蒸馏；围绕「运动学」发散：FK 校验、IK 重定向、关节限位/速度可行性、SE(3) 等变表示、进度势分割。合并后得到 v3：

- **UIP-16 KDA**（Kinematic Data Audit）：审计 32 个数据集 + 对齐接口 + 发现关节顺序；
- **UIP-17 KRA**（Kinematic Reversal Augmentation）：旗舰，时间反演合成撤回-恢复 episode；
- **UIP-18 KSS**（Kinematic Subgoal Segmentation）：用进度势自动切分计分步；
- **UIP-19 KCV**（Kinematic Consistency Verifier）：内环解析验证器；
- **UIP-20 KRT**（Kinematic Relational Target）：物体相对的目标表示，吸收平移扰动。

旗舰从 v2 的「扰动恢复闭环」升级为 **KRA 造数据 × KCV 判状态 × KSS 对齐计分步** 的「数据-运动学闭环」；Gazebo 退居接触校验与最终锚点。

---

## 5. 本轮最大风险

**一句话**：时间反演只对「可逆的准静态接触」近似成立；若把倒放视频当成万能干扰数据，策略会学到一套不存在的物理（液体倒流、布料自动复原），在真机上以「自信地做错」的形式崩掉。
