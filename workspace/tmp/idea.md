# 想法区 · 第 10 轮（新循环 · 第 2 轮）：RHD 只用了盒子的一面

**灵感词**：下界分析 / 可扩展性 / 凸优化
**起点**：v1.9「X-DUB/PACE-R*」。38 例 95 节点 / 25 表，deep 236 / 120，held-out 2,332（44 胜 6 平 0 负），hard3#5 38 / 17 表。它的收官风险是一句话：

> RHD 的收益全部来自释放错峰；同步释放的层上 `Min_R = READY`，分支因子回到 d，最坏情况仍是 n!。

本轮不推倒 v1.9。我想把这句话再往前推一格：**先证明「再加一条顺序支配」这条路已经走到头，再说明唯一没被用掉的东西是什么。**

## 一、先堵三条看起来最诱人的路

### 1.1 集合插入会退化成单任务插入

RHD 的证明是「把 i 插进 j 释放之前的空闲前缀」。一个自然的加强是：不插一个任务，插一个集合 S。

**引理（集合插入坍缩）**。设 `S ⊆ Ready\{j}` 非空，且 S 能被完整排进 `[·, est_j)`（每个 i 在 `[est_i, est_j)` 内、用各自资格机器、互不重叠）。令 `i0` 是这个小排程里第一个开始的任务，则

```text
est_{i0} + p_{i0} ≤ est_j .
```

**证明**：`i0` 开始不早于 `est_{i0}`，完成不晚于 `est_j`。∎

也就是说：只要集合插入成立，单任务 RHD 判据就已经成立，j 早被删了。**集合插入这一族没有新东西。**

### 1.2 反向搜索是免费的，但没有收益

问题在时间反演下是自对偶的：`t ↦ h−t` 把释放变成期限、把前驱变成后继，makespan 不变；反转后的 `est` 恰好是原来的 `q`（最长尾）。v1.9 的 RHD 在反转实例上就是「谁不能最后」。

我实测了 38 例 + deep 8 例，把同一个 v1.9 直接跑在反转实例上：

| 集合 | 正向 | 反向 |
|---|---:|---:|
| 38 例 | **95** | 60,872 |
| deep 8 | **236** | 434 |

逐例看，反向从来没有严格更好（deep#1 32=32，#3 47/48，#5 61=61）。**方向对偶不产生收益**，因为我们的 `h = OPT−1` 探针本来就偏向「源少、汇多」的实例；反过来跑等于把容易的一端换成难的一端。

### 1.3 预流 LP 已经被 tier 1.25 包含

「凸优化」最自然的落点是时间索引 LP 的预流松弛：每个任务在自己窗口里可抢占，m 台机器每时隙容量 m，可行性由最大流判定。它看起来比区间能量强。

但它不强。对同质资格，预流可行性正好是 Horn 条件

```text
∀ a<b :  Σ_{i: [est_i, d_i] ⊆ [a,b]} p_i  ≤  m(b−a) ,
```

其中 `d_i = h − q_i`。而 tier 1.25 的 `energy` 对每个临界 (a,b) 算的是强制重叠

```text
mand_i = min(p_i, est_i+p_i−a, b−(d_i−p_i), b−a) ,
```

对 `[est_i,d_i] ⊆ [a,b]` 的任务，`mand_i = p_i`。所以 tier 1.25 的 `tot ≤ cap` 直接蕴含 Horn 条件；异质资格下 `subset` 层做的是同一件事（`E_i ⊆ S` 的任务对 `|S|·L`）。**预流 LP 能拒的状态，tier 1.25 已经拒了。**

这不是说 LP 没用，而是说：**在这台引擎上，凸松弛的「体积」已经被吃干；再搬一个更大的 LP 进来，只会更慢。**

## 二、转折：RHD 只用了盒子的一面

三条路堵死之后，剩下一条很小的缝。

状态 `σ` 给每个任务两个边界：

```text
est_i  ：最早开始（前向最长路）
lst_i  = h − p_i − q_i  ：最晚开始（后向最长路）
```

v1.9 的 RHD 只用 `est`：

```text
v = min_{i∈Ready} (est_i + p_i) ,     K_RHD = { i : est_i < v } .
```

它对偶的那一面从来没用过：

```text
λ = min_{i∈R} lst_i ,     j 若 est_j > λ，则 j 永远不是第一个 .
```

**直觉一句话**：如果某个任务最晚也得在 x 之前开始，那么任何在 x 之后才释放的任务都不可能是第一个。

把两面合起来：

```text
μ(σ) = min( v(σ) − 1 , λ(σ) )
K(σ) = { i ∈ Ready(R) : est_i ≤ μ(σ) } ,   再取 Max_DCD .
```

`μ ≤ v−1`，所以 `K ⊆ K_RHD`：**DHD 是 RHD 的严格细化，节点数只会更少。**

## 三、为什么这算「凸优化」，而不是又一条拍脑袋规则

单个 `est_i` 和 `lst_i` 不是孤立的数：它们是差分约束多面体

```text
P = { s :  s_i ≥ est_i ,   s_j ≥ s_i + p_i (i→j) ,   s_i + p_i + q_i ≤ h }
```

在坐标 i 上的**精确投影**：

- 前向最长路给出 `min_{s∈P} s_i = est_i`；
- 后向最长路给出 `max_{s∈P} s_i = lst_i`。

所以 `[est_i, lst_i]` 是凸多面体 P 的盒子投影，`est` 与 `lst` 是同一个 LP 的两个面。`μ` 又是下面这个两约束 LP 的最优值：

```text
max μ   s.t.  μ ≤ est_i + p_i − 1  (i∈Ready) ,
              μ ≤ h − p_i − q_i    (i∈R) .
```

「凸优化」在本题里的正确位置，不是搬一个巨型 LP 进来（1.3 已证明它被 tier 1.25 包含），而是**把已有的凸松弛用满**：v1.9 用了一个面，本轮用两个面。

## 四、形式化：三条要证的事

1. **可靠性**：任一可行排程里开始最早的任务 `e` 必在 K 中。若 `est_e > λ`，λ 的见证者严格早于 e；若 `est_e ≥ v`，插入引理给出一个更早开始的可行排程，与 e 的最小性矛盾。两条合起来 `est_e ≤ min(v−1, λ) = μ`。
2. **细化性**：`K_DHD ⊆ K_RHD`，因此无截断时搜索树是 v1.9 的子树。
3. **非空性**：`μ ≥ est_min`（因为 `v−1 ≥ est_min` 且 `lst_i ≥ est_i`），所以最小 est 的任务永远保留。

还有一个必须写进规格的前提：**RHD 那一面（`v−1`）依赖 NORM**。若 `est_i < ā_i`，插入引理不成立。所以 `dhd=True` 时强制 `normalize=True`；若只保留 `λ` 一面，则 NORM 可省，但会丢掉 `v−1` 的收益。

## 六、负结果：同步层仍然是恒等

**定理**。若所有 ready 任务的 `est` 都等于 e，则 `μ ≥ e`，于是 `K = Ready`。

证明：`v = e + min p ≥ e+1`；`λ ≥ min_R est_i = e`（因为 `lst_i ≥ est_i`）。∎

所以 RHD 和 DHD 在同步层**同时失效**。本轮没有打破 d 障碍；根层（所有 source 的 est=0）依然没有证书。20% 的 held-out 收益来自「错峰 + 紧」的实例，不来自同步层。

## 七、可扩展性：不是 n 的问题

我本来想用 n=18/20/22 做规模实验。9 个随机实例（每个 n 各 3 个，p∈[3,6]，ep∈{0.2,0.25,0.3}）在 `h=OPT−1` 上**全部 1 节点根闭**。这不是引擎突然变强，而是随机大实例的根下界几乎就是 OPT：硬度不随 n 增长，而随「根下界与 OPT 的差」增长。deep 那 8 例是筛出来的（base ≥ 200 节点），所以它们小而不易。

这给「可扩展性」一个更诚实的定义：**DHD 的代价是 O(n)，且永不增加节点，所以它随 n 免费扩展；但最坏情况的指数性不随 n 改变，也不被本轮的规则改变。**

## 八、一句话最大风险

**DHD 与 RHD 是同一个盒子的两个面：当一层 ready 任务同步释放时两个面同时失效，分支因子仍是 d，最坏情况仍是 n!，hard3#5 的根证书依然没有。**
