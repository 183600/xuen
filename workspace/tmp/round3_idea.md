## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（闭环控制 → 接口把控制器偷偷降频了）**
直觉：大家把 VLA 当 15Hz 策略，但接口是「返回一个 chunk、评测端盲执行完、再要下一个」。若 `T_a=16`，策略实际每秒只看世界 ~0.94 次；自由空间搬运无所谓，但插网线、拉拉链、拧瓶盖、倒药这类接触任务，相当于戴着 0.5s 眼罩开车。基线的 action chunking 本质是开环轨迹发生器，不是闭环控制器。于是最高杠杆的控制决策不是加模块，而是**把反馈预算花在哪**：在开环发散率高的任务上把 `T_a` 压小，同时让昂贵的感知慢跑（双率）。反直觉点：**比赛分数有一部分由一个大多数队伍保持默认的接口参数 `T_a` 决定。**

**灵感 2（抓取规划 → 抓取是唯一自带标签的闭环锚点）**
直觉：Dex1 是 1-DoF 平行夹爪（F21），抓取规划不是 6-DoF 灵巧问题，而是「把两指放到物体两侧、闭合」。示教里已有成千上万次成功抓取位姿；更关键的是，夹爪开口本身是免费传感器：闭合后稳定开口近 0 = 抓空，非 0 = 夹住（F24：1.47 vs 0.04）。这让抓取成为**唯一无需力/触觉就能自标注成败**的环节，也是闭环重抓最自然的锚点。反直觉点：**抓取规划在本赛的最大价值不是更优抓取位姿，而是可验证的抓取结局——它让闭环变得可学习。**

**灵感 3（两者是同一件事的两个尺度）**
闭环控制回答「多久反馈一次」（时间尺度），抓取规划回答「在哪里反馈」（空间尺度）。把环放在状态最可观测、失败最可恢复的位置，就是抓取。数据侧（I5）负责造出「偏离→修正」的失败示教，控制侧（I10/I12）负责在正确的时间点触发它。统一结论：**第 2 轮说中期胜负手是数据引擎；本轮修正为——数据告诉策略做什么，接口决定它能多频繁地纠错；胜负手是「数据 × 反馈预算」。**

## 2. 痛点修订

- 新增 **P9 反馈带宽盲区**：`T_a` 固定且 chunk 盲执行，接触任务的有效反馈率 `15/T_a` Hz 可能远低于所需；这是此前痛点账本没有的控制维度。
- 新增 **P10 抓取失败不可观测**：无 force/tactile（F20），抓空/滑落只能靠视觉或开口推断；失败在掉落前是「沉默」的。
- P5（时间压力）补充：小 `T_a` 增加调用次数，与 I6 的延迟/规律性门禁耦合，必须联合设计。
- P8（示教质量）补充：示教全成功，但 43% episode 有 ≥2 次闭合循环（F24）——重抓/多物体行为其实在分布内，不需要从零发明，只需要把它显式暴露给策略。

## 3. 研究问题（本轮立项 Q9–Q12）

- **Q9（反馈预算）**：每任务的开环发散率 λ 与容差 ε_max 如何从示教离线估计？在延迟约束 τ 下最优固定 `T_a` 是多少？双率推理能否在 p99<66ms 下支撑 `T_a=1–2`？
- **Q10（抓取验证）**：仅用 {夹爪开口、腕相机物体相对运动、EE 位姿} 能否在无力/触觉下可靠区分抓空/抓住/滑落？透明、反光、软物体上的标签噪声多大？
- **Q11（抓取位姿检索）**：示教导出的「物体相对抓取位姿库」在未见物体/未见位姿上是否优于端到端 VLA？何时应退回 VLA？
- **Q12（有界重抓）**：180s 预算下最多重抓几次？I5 合成的失败示教能否迁移到真实失败？

## 4. 设计原则（新增 PR6/PR7）

- **PR6 反馈带宽守恒律**：任何推理期组件引入延迟 τ，都会通过 `T_a ≥ ceil(τ/Δt)` 降低可达反馈带宽；测试期模块必须用闭环收益而非仅精度来证明其延迟成本。推论：I7 世界模型测试时前瞻被裁撤。
- **PR7 可观测失败律**：只在「失败可由现有传感器观测」的环节加闭环；抓取合格（开口/腕相机），力觉滑移检测不合格（无力通道）。
- PR1–PR5 保留（PR5 数据杠杆律继续约束 I5 合成数据）。

## 7. 本轮最大风险

**一句话**：本轮把分数押在「用 `T_a` 换闭环带宽、把反馈锚在抓取」上，最大风险是**接口的延迟与动作规律性门禁使小 `T_a` 不可用，而抓取成功信号在透明/反光/软物体上又恰好最不可靠**——两个前提同时失效时，I10/I12 会在最需要它的任务上退化。
