# 产物区 · v4.0：X-DUB/PACE-ΠA-LFP

> **LFP = Layered Frontier Prover**（分层前沿证明器）。v3.0 的 `ICC`、级联、`PACE`、`CPS`、`RSI`、forcing、word 编码全部保留；本轮只**新增**一个与 `WOS` 并列的 NO 证明内核，并把「节点」成本拆成「展开 / 命中」两个口径。
> 级联：`ICC → PROVE(LFP, 反向) / FIND(WOS, 前向) → PACE`；门不变（`full ∧ n≤16 ∧ 0≤S≤4`）。YES 仍走 WOS 的早停，NO 走 LFP 的逐层铺满。
> 状态：设计稿 + 可运行实现 + **50 held-out NO：调用 37,364（17,869 展开 + 19,495 命中）→ 15,466 展开；内核 0.1032→0.0895 s（1.153×）** + **逐例双峰驻留中位 2.50×、最大 18.2×（最大单例 2,109→670；1 例 0.75×）** + **1,260 组暴力（649 可行）0 不一致（双向）** + **50 NO + 50 YES 判决 0 不一致（双向）**。YES 侧 LFP 慢 11.5×，故只作证明器。未接 PSPLIB，未做 Coq/Lean，未在真实磁盘上跑外部排序（只给复杂度 + 峰值驻留实测）。

## 0. 版本关系与本轮增量

v3.0 的资产全部保留：

- `ICC`：区间容量证书；`icc-full` + `icc-mand`。
- `WOS`：word 状态 `(mask,CP,RP)`、无借位 `PLACE`、SWAR `AV`、倍增 `EARLIEST`、入口 forcing fixpoint、memo 前置；2.00× 内核。
- `PACE`：`n>16`、异资格、`S>4` 的后备。
- 级联：`ICC → OS(B=10k) → PACE`；门 `full ∧ n≤16 ∧ 0≤S≤4`。

本轮增量：

1. **成本口径**：把 v3.0 的 37,364 个「节点」拆成 `17,869 展开 + 19,495 命中`，并验证恒等式 `展开 = 分支 + RSI 死亡`。这是后面所有比较的基准。
2. **LFP 内核**：按「已排任务数」分层推进；第 k 层前沿 `F_k` 是完全由第 k−1 层生成的去重状态集；**没有 `seen` 表**；forcing 在同一次展开内闭合，forced 链不占层状态。
3. **方向对偶**：时间反演 `s_i ↦ h−s_i−p_i` 是精确对偶（优先图反向、`est↔q`、`h` 不变）。LFP 与 WOS 都可换向；本批数据上反向更小。
4. **外部存储设计**：`F_k` 是一个按 key 排序的外部 run；子状态流式产生、分块排序、归并去重；第 k 层读完即删。
5. **三条否证**：同 mask 支配只能合并 5.5%；1-极小核中位 n−1（20/50 就是全集）；方向不可用廉价特征预测（|corr|≤0.214），单次探测不划算。

退化关系：

```text
LFP 只跑一层 / 不换向              → 逐层 BFS（仍正确，但无内存优势）
forcing=False                      → 层状态数 +21.5%（50 例 19,117→23,234）
direction=forward                  → 19,117 展开，0.0971 s（层化单独 1.063×）
direction=backward                 → 15,466 展开，0.0895 s（层化+方向 1.153×）
n>16 ∨ ¬full ∨ S∉[0,4]            → PACE（与 v3.0 相同）
YES 路径                            → WOS（LFP 慢 11.5×，不进 YES）
```

本轮**没有**新增分布相关的门；`cw=bit_length(m)`、`rw=bit_length(max(h,max est))` 不变。

## 1. 符号

| 符号 | 含义 |
|---|---|
| `I=(n,m,p,E,≺,h)` | 实例：加工时间、机器数、资格、优先图、公共期限；本轮只用全资格 `E_i={0..m−1}`、`A=0` |
| `I^R` | 对偶实例：`pred^R=succ`、`succ^R=pred`、`est^R=q`、`q^R=est` |
| `σ=(R,CP,RP)` | 状态：未排集、容量剖面、释放向量；`|σ|=n−|R|` 为层号 |
| `r_i,d_i` | `r_i=RP_i`，`d_i=h−q_i(R)`；`q_i` 只依赖后继 |
| `es_σ(i)` | 最早可行起点；`⊥` 表示无 |
| `F_k` | 第 k 层前沿（已排 k 个任务的 raw 状态集） |
| `N(σ)` | 对 σ 施加 forcing fixpoint 到不动点的结果 |
| `Legal(σ)` | `{i∈RDY(σ) : es_σ(i)≠⊥ ∧ 子状态过后继期限}` |
| `Force(σ)` | `{i∈RDY(σ) : es_σ(i)=d_i−p_i}` |
| `E / H / V` | 展开数 / 命中数 / 调用数；`V=E+H` |
| `W / P` | 最宽层 `max_k |F_k|` / 双峰驻留 `max_k(|F_k|+|F_{k+1}|)` |
| `B,M` | 外部存储的块大小 / 内存字数 |
| `c0,ce,c1` | 每展开成本 / 剪枝额外 / 剪枝后 |

## 2. 形式定义

### 2.1 状态与转移

沿用 v3.0：

```text
CP  = Σ_t c(t)·2^{cw·t} ,  cw=max(1,bit_length(m))
RP  = Σ_i r_i·2^{rw·i} ,  rw=max(1,bit_length(max(h,max est)))
K   = CP | (RP << cw·h) | (mask << (cw·h+rw·n))
```

`PLACE` 是一次无借位减法，`AV` 是 SWAR 导出，`EARLIEST` 是倍增 run——全部逐字沿用 v3.0 §2.2/§4.1–4.3，不再重复证明。

对 `i∈Legal(σ)`，令 `t=es_σ(i)`，子状态

```text
σ·i = (R\{i},  CP − rep[p_i]<<(cw·t),  RP' )
RP'_j = max(RP_j, t+p_i)   (j∈succ(i)∩R) ;  否则 RP_j
```

`Legal` 还要求 `RP'_j + p_j ≤ d_j` 对所有 `j∈succ(i)∩R`。

### 2.2 forcing 闭包

```text
N(σ):
  while Force(σ) ≠ ∅:
      pick i ∈ Force(σ) ;  σ ← σ·i        # t = d_i − p_i
  return σ
```

若 `|Force(σ)|>1`，任选一个提交；由引理 2（§4.2）提交顺序不影响最终状态与可行性。

### 2.3 层与前沿

```text
F_0 = { (full, CP0, RP0) }
F_k = { σ'·i : σ'=N(σ) , σ∈F_{k'} , k'<k , i∈Legal(σ') , |σ'·i|=k }   （去重；RSI 死状态丢弃）
```

等价地：`F_k` 是「从根出发、每次先把 forced 任务闭合、再做一个非 forced 放置、恰好排了 k 个任务」的 raw 状态集。实现中层号直接取 `n − popcount(mask)`，所以 forced 链跳到哪一层都不会错。

### 2.4 RSI 与死状态

```text
Dead(σ) ⇔ ∃i∈RDY(σ): es_σ(i)=⊥
```

`Dead(σ)` 的状态不进任何 `F_k`；它的子状态也不生成。这就是 v3.0 的 RSI，作用位置从「节点入口」变成「层状态入口」。

### 2.5 成本口径

```text
V = E + H          # 调用 = 展开 + 命中
E = 分支 + RSI死亡  # 本批：17,869 = 10,805 + 7,064
```

v3.0 报的 `µs/节点` 是 `T/V`；本轮报 `µs/展开 = T/E`。两者不可直接比。

## 3. 算法

### 3.1 内存版 LFP

```text
LFP(σ0, h, dir):
  if dir = backward:  return LFP(σ0^R, h, forward)      # §4.1
  F[0] = {(full, CP0, RP0)}
  for k = 0 .. n−1:
      if F[k] = ∅: return NO
      G = {}                                             # 按 mask 分桶
      for (mask,CP,RP) in F[k]:
          while True:
              if mask = 0: return YES
              av ← AV(CP);  rdy ← RDY(mask)
              cand ← [];  fi ← ⊥
              for i ∈ bits(rdy):
                  t ← EARLIEST(CP, r_i, p_i, d_i)
                  if t = ⊥: goto DEAD                    # RSI
                  cand.append((i,t))
                  if t = d_i − p_i: fi ← i; break         # forced
              if fi ≠ ⊥:
                  (mask,CP,RP) ← COMMIT(mask,CP,RP,fi)   # 不进层
                  continue
              for (i,t) in ORDER(cand):                  # 只影响 YES 早停
                  child ← PLACE+ADVANCE
                  if child ok:
                      G[child.mask].add(child)          # 一个 (CP,RP)
              break
          DEAD: ;
      F[k] = ∅
      for (mask,bag) in G: F[n−popcount(mask)] ∪= bag   # forced 跳层
  return YES if any mask=0
```

关键点：`COMMIT` 不把中间状态写进 `F`；一个展开可以连续吃掉整条 forced 链。`G` 按目标层号分桶，因为 forced 链会让 `|σ·i|` 跳超过 1。

### 3.2 外部存储版

```text
EXTERNAL-LFP:
  bucket[0] = [root]
  for k = 0 .. n−1:
      k-way merge bucket[k] → sorted stream; dedup → F_k
      for each block b of F_k:                      # 顺序读
          expand b (同上), 子状态写入 target-layer buffer
          buffer 满 → sort(buffer) → write run to bucket[target]
      delete F_k, bucket[k]
  # 注意：F_j 要等所有 k<j 的贡献都写完后，在 j 开始时才归并
```

正确性只依赖「层号严格递增」：`target = |σ·i| > k`，所以 `F_j` 在被读之前一定已经归并完。峰值内存 `O(B + R)`，`R` 是归并路数；多趟归并可取 `R=O(M/B)`。

### 3.3 级联

```text
LFP-CASCADE(σ,h):
  1  if full(σ):
        v ← ICC(σ,h); if v=NO: return NO
  2  if os_gate(σ):
        v ← FIND(WOS, σ, h, B_f)        # YES 早停；小树也能直接 NO
        if v ≠ UNKNOWN: return v
        v ← PROVE(LFP, σ, h, dir=backward, B_p)   # 只证 NO
        if v = NO: return NO
  3  return PACE(σ,h)
```

`FIND` 与 `PROVE` 共用 `os_gate`、`ICC`、`cw/rw`、`d_i`、`succm`。`B_f` 是小预算（默认 64）；`B_p` 是证明预算（默认 10^6 层状态）。两者都不影响正确性：撞预算返回 `UNKNOWN`，交给下一级。

## 4. 定理与证明

### 4.1 定理 1（方向对偶）

**定理 1**。设 `I^R` 为 `I` 的时间反演：`pred^R=succ`、`succ^R=pred`、`p^R=p`、`est^R_i=q_i`、`q^R_i=est_i`、`h^R=h`、机器全资格且 `A=0`。则 `I` 在 `h` 下可行 ⇔ `I^R` 在 `h` 下可行。

**证明**。给定 `I` 的可行排程 `{s_i}`，令 `s'_i = h − s_i − p_i`。则

```text
s_i ≥ r_i                ⇔  s'_i + p_i ≤ h − r_i = d'_i
s_i + p_i ≤ d_i          ⇔  s'_i ≥ h − d_i = q_i = r'_i
i≺j ⇒ s_j ≥ s_i+p_i      ⇔  s'_i ≥ s'_j+p_j   （反向优先）
```

容量：`A=0` 时 `c(t)=m` 常数，`[s_i,s_i+p_i)` 与 `[s'_i,s'_i+p_i)` 是同一个区间在时间轴上的镜像，重叠数逐点相同。所以 `{s'_i}` 是 `I^R` 的可行排程；映射是对合，逆命题同理。∎

**推论**：换向永远合法；它改变的是状态数，不是判决。

### 4.2 引理 2（forcing 交换性）

**引理 2**。若 `i∈Force(σ)`，`t*=d_i−p_i`，则 `σ` 的每个可行完成都把 `i` 排在 `t*` 开工；且 `σ` 与 `σ·i` 的可行完成一一对应（固定 `i` 的这一步）。

**证明**。任何完成让 `i` 在 `t` 开工，`es_σ(i) ≤ t ≤ d_i−p_i`。而 `es_σ(i)=d_i−p_i`，故 `t=t*`。把该完成去掉 `i` 的这一步就是 `σ·i` 的完成；反向，任何 `σ·i` 的完成加上 `i` 在 `t*` 的放置就是 `σ` 的完成（容量与优先序由 `Legal` 保证）。∎

**推论（合流）**：若 `|Force(σ)|≥2`，任选顺序提交得到同一个 `N(σ)`。因为每个被强迫的 `i` 在任意完成里都固定在 `t*_i`，`CP` 的减法是逐区间可交换的，`RP` 的更新是 `max` 可交换的。

### 4.3 定理 3（层不变式）

**定理 3**。对每个 `k=0..n`，在算法处理完第 `k` 层后，

```text
F_k = { σ : |σ|=k , 根 →*_T σ , σ 非 Dead }
```

其中 `→_T` 是「先 `N(·)` 再做一个 `Legal` 放置」的收缩转移系统。

**证明**。对 k 归纳。

- 基：`F_0={根}`，根非 Dead（否则实例平凡不可行，`Legal(根)=∅`，算法在 k=0 返回 NO）。
- 归纳：设 `F_0..F_{k−1}` 都满足。`F_k` 只由某个 `k'<k` 的 `σ∈F_{k'}` 一步投递而来：先算 `N(σ)`（引理 2 保证可行集不变），再对 `Legal(N(σ))` 的每个 `i` 生成 `σ'·i`。`Legal` 与 `→_T` 的边逐一对应；`Dead` 的不投；`G` 去重只删重复。所以 `F_k` 恰好是 `→_T` 走一步、层号为 `k` 的全部状态。
- 去重只删重复的同一状态，不删可达性。
- `Dead` 的状态没有出边，删它与保留它对后继无影响。

所以不变式成立。∎

### 4.4 定理 4（soundness / completeness）

**定理 4**。`LFP(σ0,h)` 返回 YES 仅当 `σ0` 可行；返回 NO（未撞预算）仅当 `σ0` 不可行。

**证明**。

- YES：`F_n` 中出现 `mask=0`。由定理 3，它由 `→_T` 从根可达；`→_T` 的每一步是一个合法放置（容量、释放、期限、优先序），所以这些放置的序列就是一个可行排程。
- NO：某个 `F_k=∅`（`k≤n`）。由定理 3，`→_T` 从根到全掩码没有路径。`→_T` 与「所有 active 排程」等价：WOS 的定理 2 说串行 SGS 枚举所有 active 排程；forcing 只固定唯一位置（引理 2），不删可行解；RSI 只删不可行状态。所以没有 active 可行排程 ⇒ 不可行。∎

### 4.5 定理 5（内存界）

**定理 5**。内存版 LFP 的峰值常驻状态数为 `O(max_k |F_k|)`：第 k 层处理期间只持有 `F_k` 与正在累积的 `F_{k+1}`，故 `≤ |F_k|+|F_{k+1}|`；外加 `O(n + #mask)` 的每 mask 缓存。外部版为 `O(B + R)` 字，与 `E` 无关。

**证明**。算法在任一时刻只持有 `F_k` 与正在生成的 `G`；`F_{k-1}` 及更早的层在 `k` 完成后被删除（`F[k]=∅`）。`G` 里只有目标层为 `k+1` 的桶可能很大（forced 跳层只增加少量），故峰值 `≤ |F_k|+|F_{k+1}|`。外部版每个桶的 run 写盘后即释放，`F_k` 顺序读，故峰值 `O(B+R)`。∎

**实测**：最宽层 `max_k |F_k|` 前向最大 588、反向最大 365；双峰驻留 `|F_k|+|F_{k+1}|` 前向最大 1,098、反向最大 670。逐例 `memo/双峰` 中位 2.82 / 2.50，最大 4.30 / 18.19，**最小 1.31 / 0.75**（反向有 1 例比 DFS 更宽）。

### 4.6 定理 6（I/O 复杂度）

**定理 6**。外部版 LFP 处理 `E` 个状态、每状态 `O(d)` 个候选，总块传输

```text
O( (E/B) · log_{M/B}(E/B) + E·d/B )
```

第一项是外部排序/归并，第二项是顺序扫描。

**证明**。每个子状态写一次、在每一趟归并读一次写一次；`E/B` 个块、`log_{M/B}(E/B)` 趟。扫描 `F_k` 是 `E/B` 个块。∎

### 4.7 定理 7（终止与预算）

**定理 7**。LFP 对有限输入终止；层号每次严格增加（`target>k`），最多 `n` 层；每层展开数受 `B_p` 约束，撞预算返回 `UNKNOWN`。∎

### 4.8 命题 8（调用的加法分解）

**命题 8**。`V = E + H`；`H` 是可达状态图里被走过的非树边数。对 50 例：

```text
V = 37,364 , E = 17,869 , H = 19,495
H/V = 52.2% , V/E = 2.09
```

**证明**。每次 dfs 调用要么是首次进入该 key（计数进 E），要么命中 `seen`（计数进 H）；两者互斥且穷尽。∎

**读法**：v3.0 的 `2.65 µs/节点` 是 `T/V`；换成 `T/E` 是 `5.78 µs/展开`。DFS 的命中不是免费的，但也不是一次展开；把两者平均会同时低估展开成本、高估命中收益。

## 5. 三条否证

### 5.1 同 mask 支配：991/17,869 = 5.5%

解码 50 例的 17,869 个 NO key，按 mask 分桶，算 Pareto 反链（`CP` 逐点 ≥、`RP` 逐点 ≤）。

| 指标 | 值 |
|---|---:|
| 状态总数 | 17,869 |
| 被同 mask 支配 | 991（5.5%） |
| mask 数 | 7,097 |
| 反链均值 | 2.28 |
| 最大反链 | 1,020 |

v2.9 的 `os_dom.py` 在 tuple 核上实测 80,463→74,301 节点（−7.7%）、0.511→1.713 s（3.35×）。本轮的上界 5.5% 说明：即使支配检查免费、即使被支配状态的整棵子树都省掉，收益也不到 6 ms；而维护 1,020 的反链最坏情况下会把常数打回去。**不进生产路径。**

### 5.2 1-极小核：中位 n−1，20/50 是全集

对每个 NO 实例，从全集贪心删任务；删后子实例（优先图限制、`est/q` 重算、同 h）仍不可行就永久删。得到 1-极小核。

| 核大小 | 实例数 |
|---|---:|
| n | 20 |
| n−1 | 15 |
| n−2 | 9 |
| n−3 | 4 |
| n−4 | 1 |
| n−5 | 1 |

中位 n−1，最小 n−5。**这批 NO 没有小证书**：`h=OPT−1` 的不可行性是全局的，删掉任何一个任务剩下的就能塞进去。任何「先找小核、再用核结案」的算法族在这批数据上无效。

### 5.3 方向：真维度，但没有廉价预测器

DFS+forcing 逐例 `bwd/fwd`：最小 0.117（case 31，492→64），最大 4.21（case 15，57→240），28/50 < 1。对 `log(bwd/fwd)` 的相关系数：

| 特征 | corr |
|---|---:|
| `sum est` | −0.072 |
| `sum q` | +0.184 |
| `sum est − sum q` | −0.214 |
| `max est − max q` | +0.014 |
| `n` | −0.020 |

单次探测策略（先跑一个方向 C 个节点，失败换向）在 C=50..1200 上的总节点：33,850–45,245，全部劣于「直接反向」的 28,251。**方向不预测，只默认；默认反向，写成参数。**

## 6. 实验

### 6.1 设置

同一批数据、同一进程、单线程、Python 3.12、4 vCPU。v3.0 与 v4.0 交错 4 次取中位数。数据与 v3.0 逐字相同：

```text
exp/v13/hard3.pkl（12）
exp/v14/{large_a,large_b,large_het}.pkl（8+10+8）
exp/v18/deep.pkl（8）
exp/v20/holdout_cases50.pkl（50）
exp/v28/synth2_45.pkl（45）
```

### 6.2 内核消融（held-out 50，h=OPT−1，全 NO）

| 内核 | 调用 | 展开 | 时间 | µs/展开 |
|---|---:|---:|---:|---:|
| DFS 前向（v3.0） | 37,364 | 17,869 | 0.1032 s | 5.78 |
| DFS 反向 | 28,251 | 14,515 | 0.0964 s | 6.64 |
| **LFP 前向** | — | **19,117** | **0.0971 s** | **5.08** |
| **LFP 反向** | — | **15,466** | **0.0895 s** | **5.79** |

分解：

```text
层化单独（前向）  0.1032 → 0.0971 = 1.063×
方向单独（DFS）   0.1032 → 0.0964 = 1.071×
两者叠加          0.1032 → 0.0895 = 1.153×
                  1.063 × 1.071 = 1.138（实测 1.153，超加性 1.3%）
```

读数：

- **层化单独只值 5.7%**。它省掉的是 19,495 次命中的入场费（哈希 miss + 递归调用），但 LFP 前向多展开了 7%（19,117 vs 17,869），抵掉一部分。
- **每展开成本** LFP 比同向 DFS 低 0.70–0.85 µs（5.08 vs 5.78；5.79 vs 6.64），因为 LFP 入口没有 `seen` 查表。
- **方向单独值 7.4%**，但这是分布事实（见 §5.3），不是可证明的改进。

### 6.3 峰值常驻

| | DFS | LFP 前向 | LFP 反向 |
|---|---:|---:|---:|
| 最宽层 `max|F_k|`（最大单例） | — | 588 | 365 |
| 双峰驻留 `|F_k|+|F_{k+1}|`（最大单例） | 2,109 | 1,098 | 670 |
| 双峰驻留（中位） | 211 | 74.5 | 75.5 |
| 逐例 `memo/双峰` 中位 | 1 | 2.82 | 2.50 |
| 逐例 `memo/双峰` 最大 | 1 | 4.30 | 18.19 |
| 逐例 `memo/双峰` 最小 | 1 | 1.31 | **0.75** |

反向的尾巴很长：case 1 的 `memo=382`、双峰=21（18.2×），case 36 的 `memo=1,445`、双峰=87（16.6×）。但反向也有反例：case 15 的 `memo=44`、双峰=59（0.75×）——小实例上「铺满一层」比「记住一条路径」更贵。这就是「按层铺」的真实边界：证明的「高度」是 `n`，宽度可以远小于总面积，但不保证每一例都小于。

外部版的峰值与层的宽度无关（`O(B+R)`）；上表的双峰是内存版不落盘时的常驻上界，也是外部版「一层能一次读进内存」的充分条件。

### 6.4 YES 侧：LFP 是证明器，不是找解器

h=OPT，50 例：

| 内核 | 时间 | 节点/展开 |
|---|---:|---:|
| DFS 前向 | **0.0130 s** | 3,743 |
| LFP 前向 | 0.1499 s | 31,032 |
| LFP 反向 | 0.1518 s | ≈31k |

LFP 慢 11.5×。原因：DFS 找到一条路径就停；LFP 必须把 `F_0..F_{n−1}` 铺满才能确认 `F_n` 有没有状态。**所以级联里 YES 走 `FIND(WOS)`，NO 走 `PROVE(LFP)`。** 这不是折衷，是两种判定的不对称：找解是存在性，证明是全称性。

### 6.5 正确性

| 测试 | 规模 | 结果 |
|---|---|---:|
| LFP vs 暴力枚举（n=3–7、m≤4、h=3–12），前向+反向 | 1,260 组（649 可行） | **0 不一致** |
| LFP vs WOS，held-out 50 NO（h=OPT−1） | 50 × 2 向 | **0 不一致** |
| LFP vs WOS，held-out 50 YES（h=OPT） | 50 × 2 向 | **0 不一致** |
| 方向对偶（前向判决 = 反向判决） | 100 × 2 向 | **0 不一致** |

暴力枚举：枚举所有满足优先序的整数起点向量，再用容量计数判可行；专门检查「会不会把可行状态误判成 NO」。

### 6.6 端到端投影

141 集合（h=OPT−1，全 NO）：v3.0 实测 0.2318 s，其中 OS 内核 0.0990 s。按同进程 1.153× 折算，内核 ≈ 0.0859 s，端到端 ≈ 0.2187 s，对 v2.5 的 0.3406 s 约 **1.56×**（v3.0 是 1.47×）。这是投影，不是实测；扣掉 `large_het` 的 0.0695 s PACE 不变部分，OS 主导三集的收益更明显。

### 6.7 外部存储的工程参数

最大实例的 key 宽：`cw·h + rw·n + n = 2·41 + 7·16 + 16 = 210 bit ≈ 27 B`。50 例总展开 19,117 → 约 0.5 MB；即使 `E=10^9`，也是 27 GB 的顺序记录，正是外部排序的适用区间。块 `B=64 KB` 时 `E/B≈4×10^5` 块，两趟归并即可。

## 7. 与 v3.0 的差异

| 项 | v3.0 | **v4.0** |
|---|---|---|
| NO 内核 | DFS + 精确 memo | **LFP 分层前沿 + 方向对偶** |

| memo 命中 | 19,495 次（52.2%） | **0** |

| YES | 0.0130 s | 仍走 WOS（LFP 慢 11.5×） |

## 8. 已知风险

1. **时间收益小且分拆**：1.153× 里层化 1.063×、方向 1.071×；方向是分布事实，换一批数据可能反向。层化的收益被「多展开 7%」抵掉一部分。
2. **YES 侧不能用**：LFP 慢 11.5×；必须保留 WOS 作为找解器。级联因此有两条内核路径，代码与测试面积翻倍。
3. **父指针会吃掉内存优势**：本轮只做判决，不做排程重建。若要重建 YES 路径，需要 `O(E)` 父指针或分治重跑；前者把中位 2.50× 还回去，后者把时间乘上 `O(n)`。
4. **外部版未在真实磁盘上跑**：只给了复杂度与峰值驻留实测；Python 的排序/序列化常数没有测，落到 C++ 前不能把 I/O 界当成实际时间。
5. **`W` 是数据相关的**：最宽的一层可能接近 `E`（本批最小双峰比值 0.75，反向有 1 例比 DFS 更宽）；极端分布下分层退化为 BFS，内存优势消失。
6. **方向对偶依赖 `A=0`**：一般机器可用时刻 `A` 的时间反演需要把 `A` 镜像成 `h−A`，本轮未实现；`A≠0` 的中间状态（v2.5 的差分测试）不能直接换向。
7. **forcing 合流只在「同时 forced」时有证明**：若两个 forced 任务的区间重叠且容量恰好紧，提交顺序的可交换性依赖 `CP` 逐区间减法；本轮的 1,260 组暴力覆盖了 n≤7，但没有覆盖大 n 的并发 forced 链。
8. **层号跳层**：`COMMIT` 可能连吃多个 forced，`target` 可以 `>k+1`；实现里用 `n−popcount(mask)` 直接算，若未来加入「不减少 mask 的变换」会破坏这个单调性。
9. **预算语义**：`B_p` 是层状态数；撞预算返回 `UNKNOWN`，不是 NO。级联必须把 `UNKNOWN` 交给 PACE，不能当成 NO。
10. **没有形式化验证**：定理 1–7 是纸面证明 + 可重放内核；测试是 1,260 组暴力 + 100 个基准判决 + 方向对偶。
11. **时间测量单机**：Python 3.12、4 vCPU 单线程、交错 4 次中位数，±3%；节点数不能直接当时间。
12. **公共期限**：各自期限 `d_i` 的路径未实现；对偶与层不变式都依赖公共 `h`。

---

## 9. 一句话最大风险

**这一轮的 1.153× 时间收益里，方向单独贡献 1.071× 且只是本批数据的分布事实，层化单独只有 1.063×；峰值驻留的中位 2.50× 也不普适（反向有 1 例 0.75×），而它一旦要重建排程路径就会被 `O(E)` 父指针还回去——LFP 证明了「NO 可以流过去」，但还没有证明「YES 也能」或「换一批数据方向还站在我这边」。**
