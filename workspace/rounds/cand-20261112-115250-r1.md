# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 7 轮；本轮灵感：「故障诊断」×「动作空间」）

> 第 60 轮把「场景→意图→约束→阻抗→执行→证据」闭合成 SERC（IP-153~160）。但它仍留下三个结构性缺口：
> 1. **动作空间被当作静态可行域**：K_safe 一经 EEIS 编译就近似固定；电机增益衰减、关节摩擦上升、力传感器零偏、ROS 丢包等故障只作为「不确定性」进入 BUQ/ξ_exec，并未改变「哪些动作此刻还可执行」这一硬事实。执行层继续沿用标称动作空间 A_nom，直到实际失败。
> 2. **诊断与决策割裂**：经典 FDI 回答「哪里坏了、坏多少」，却不回答「还能做哪些动作、做到什么程度」。诊断结果无法直接投影为规划器的 action mask，也无法反馈给 EEIS 做阻抗重编译。
> 3. **诊断是被动的、任务动作可能「掩盖」故障**：若机器人长期慢速轻触，摩擦/增益故障的签名被淹没在噪声里；故障的**可观测性依赖动作分布**，而第 60 轮的动作选择从未为「可诊断性」负责。

## 0. 直觉与动机

**灵感 1（故障诊断 → 动作空间残差 ASR）**
直觉：故障最直接的征兆不是某个传感器读数异常，而是「我命令的动作」与「实际发生的动作」之间的差。命令 K_p=200、F_d=10N，实际只输出 7N → 执行器增益损失；命令匀速下压，实际出现与速度反号的力偏差 → 摩擦故障；测得力恒偏 0.5N → 力传感器零偏。关键洞见：把执行器、传感器、通信等异构故障**投影到同一个动作空间坐标系**，用 r_a = Ψ(a_cmd − a_real) 作统一残差；而第 59/60 轮的 EV-exec 天生提供 a_real。

**灵感 2（动作空间 → 可诊断动作子空间 DAS）**
直觉：诊断需要「激励」。若机器人永远慢速、轻触、单向运动，摩擦与零偏在回归子里共线，故障就藏在噪声中。所以「能不能诊断」不是故障的固有属性，而是**动作分布的属性**。定义可诊断动作子空间 A_diag(f)：在其中故障签名矩阵的信噪比与秩条件成立。未被任务动作分布覆盖的部分，就是**诊断盲区** D_diag(f)。

**灵感 3（动作空间 → 主动诊断探测 DAP）**
直觉：给机器人「做实验」的权利。当任务动作覆盖不到 A_diag 时，主动插入探针动作（小幅正负力切换、扫频、加减速），用最小风险/预算换取最大故障信息。这是带 dual effect 的主动故障诊断：探针既获取信息、又改变状态并产生磨损，因此必须前瞻约束风险。关键洞见：**探针不是「额外任务」，而是动作空间里新增的「诊断坐标轴」**。

**灵感 4（诊断 → 动作空间收缩 FTAC）**
直觉：诊断的价值必须落到「动作可行性」。给定故障可信集 F̂（而非点估计），计算 A_cert = {a ∈ A_nom : 对任意 f∈F̂ 都安全且可执行}。这是把「不确定性集合」经鲁棒可达性/区间传播，投影成「认证动作集」。故障越确定，A_cert 越大；故障越模糊，A_cert 越保守。第 60 轮的 K_safe 只是 A_nom 的一个切面，A_cert 才是「带故障证据的可行域」。

**灵感 5（合流 → 故障-动作双螺旋 FADE）**
直觉：诊断与动作互为因果——动作揭示故障，故障约束动作，二者螺旋收敛：执行任务动作 → 观测残差 → 诊断故障 → 收缩动作空间 → 在 A_cert 内重规划 → 诊断不足则插入探针 → 收缩/扩张。与第 60 轮合流：A_final = A_nom ∩ A_scene ∩ C_intent ∩ A_cert；任一为空，说明「场景/意图/故障」三者矛盾，必须降级或求助人类。

**灵感 6（PCE⁵ → 诊断-动作双预算）**
直觉：新增 B_diag（探针次数、故障推理算力）与 B_act（可行动作余量、空间利用率）。诊断的 VOI = 预期安全风险下降 + 任务收益 − 探针风险与成本。若 B_diag 耗尽 → 用最坏故障界收缩（保守但安全）；若 B_act 不足以覆盖任务需求 → 降级任务/请求人类，而不是「带病硬做」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（动作空间与动作残差 ASR）** 动作 a ∈ A ⊆ R^m，取 a = (K_p, K_d, F_d, v_d)。a_cmd ∈ A_nom 为命令动作；a_real 由 EV-exec 中的接触力/位姿/速度经逆阻抗模型反演。特征映射 Ψ: R^m→R^q，动作残差 r_a := Ψ(a_cmd − a_real)。故障 f ∈ F = {增益 η、摩擦 F_fric、传感器零偏 b、通信丢失 ⊥}。**线性签名模型**：
```
r_a = Φ(a_cmd, v) θ_f + ε,    ε ~ N(0, Ω)
Φ = [ diag(F_cmd) | I | diag(sign(v)) ],  θ_f = [1−η;  −b;  −F_fric]
```
增益故障的残差正比于命令力、零偏为常值、摩擦与速度符号相关——三者方向可分离。通信丢失时 r_a = ⊥（样本缺失），由第 60 轮 EPIR 的 seq_id/hash 检出，作为离散故障模式。

**定义 162（可诊断动作子空间 DAS）** Fisher 信息矩阵 J_f(a) = Φ(a)^T Ω^{-1} Φ(a)。
- **可诊断**：a 对 f 可诊断 ⇔ λ_min(J_f(a)) ≥ γ_exc（持续激励），等价于 Φ 在 a 附近满列秩且条件数 ≤ κ_max。
- **可检测/可隔离**：可检测 ⇔ ‖Σ_f f‖_{Ω^{-1}} ≥ δ_det；可隔离 ⇔ 不同故障签名子空间可分离 S(f_i,f_j) = ‖P_⊥(Σ_i)Σ_j‖ ≥ δ_iso。
- A_diag(f) = {a ∈ A : λ_min(J_f(a)) ≥ γ_exc}；**诊断盲区** D_diag(f) = 1 − μ(A_diag(f) ∩ supp π_task) / μ(A_diag(f))，π_task 为任务动作分布。

**定义 163（主动诊断探测 DAP）** 期望信息增益 I(a) = H(f|D) − E_{y|a}[H(f|D,y)]（D-最优实现：max ½logdet J_f(a)）。风险 R(a,F̂) = max_{f∈F̂}[F_wc(a,f) − F_safe]^+ + [τ_wc(a,f) − τ_max]^+。探针选择：
```
a_probe = argmax_{a∈A_safe}  I(a) / (λ_r·R(a,F̂) + λ_b·C(a) + ε),   s.t. R(a,F̂) ≤ R_max
```
含 dual effect：探针改变状态与磨损，故采集后须把 a_probe 计入下一轮 F̂ 的更新；可按一步或滚动前瞻求解。

**定义 164（容错动作空间收缩 FTAC）** 故障可信集 F̂ = {f : p(f|D) ≥ θ_f}（椭球/区间）。认证动作集：
```
A_cert = { a ∈ A_nom : ∀f∈F̂, g(a,f) ∈ S_safe  ∧  inf_{f∈F̂} P_exec(a|f) ≥ τ_exec }
```
阻抗-力域显式判据：F_wc(a,F̂) = (1+δ_g)|F_d| + F_fric^max + |b|^max + m_safe ≤ F_safe，且 τ_wc = ‖J^T F_wc + τ_fric‖ ≤ τ_max。收缩算子 C_fault 单调：F̂₁ ⊆ F̂₂ ⇒ A_cert(F̂₂) ⊆ A_cert(F̂₁)；无故障时 A_cert = A_nom ∩ A_safe。健康度 ρ = μ(A_cert)/μ(A_nom)；任务可行度 U = μ(A_final ∩ A_need)/μ(A_need)。

**定义 165（故障-动作双螺旋 FADE）** 算子 FADE(M, A_nom, task)：
```
① Dispatch : a_cmd ← task.next_action(A_nom)
② Execute  : a_real ← execute_impedance(a_cmd)          # EV-exec 采集
③ ASR      : r_a ← Ψ(a_cmd − a_real);  D ← D ∪ (Φ, r_a)
④ Diagnose : f̂, F̂, mode ← ASR.detect_isolate_identify(D)  # 检测/隔离/辨识
⑤ Contract : A_cert ← FTAC(A_nom; F̂)
⑥ Compose  : A_final ← A_nom ∩ A_scene ∩ C_intent ∩ A_cert
⑦ Probe    : if D_diag(f̂) > θ_d 且 B_diag>0: a_probe ← DAP(...); return ①
⑧ Certify  : J_fault ← make_certificate(f̂, F̂, A_cert, residual_digest)
⑨ Return   : (f̂, A_final, J_fault) ; if A_final=∅: degrade_or_escalate()
```

**定义 166（故障证书 J_fault）** J_fault = (f̂, F̂, A_cert, t_issue, t_valid, δ_safe, residual_digest, justification)。有效期 t_valid 内、且残差未违反签名模型（residual_digest 复验通过）时有效；过期或残差突变即撤销，A_cert 回退到最坏界。J_fault 是第 59 轮 J_exec 的「故障维度」扩展：J_exec 证明「此次执行合规」，J_fault 证明「该动作集在故障下仍可执行」。

**定义 167（PCE⁵ 六维预算与诊断 VOI）** B = (B_scene, B_intent, B_ros, B_exec, B_diag, B_act)。
```
voi_diag(a) = E[ΔRisk] + E[ΔTask] − λ_r·R(a,F̂) − λ_b·C(a)
```
若 B_diag 耗尽 ⇒ 以最坏故障界收缩（A_cert^worst）；若 B_act < B_need ⇒ 降级任务/求助；其余预算耗尽沿用第 60 轮策略。

**定义 168（诊断-动作安全保证 DSA）** 假设 A66–A70：A66 签名模型在某 A_diag 上满列秩；A67 可信集 F̂ 以概率 ≥ 1−α 覆盖真值；A68 安全函数 g 区间传播可靠（Lipschitz）；A69 窗口 T 内持续激励；A70 扩张必须携带新证据。则：
1. 检测时延 ≤ T_det，虚警率 ≤ β；
2. 激励条件成立时隔离误差 ≤ ε_iso，且不可隔离故障被降级为「可检测不可隔离」；
3. A_cert 对 F̂ 鲁棒安全（soundness），且对 F̂ 单调；
4. 无新证据不得扩张 A_cert（no unsafe expansion）；
5. 收缩-扩张带迟滞（ρ 变化率 ≤ ρ_max），FADE 不震荡终止。

## 2. 关键算法伪代码

### IP-161 ASR（动作空间残差诊断）

```python
class ActionSpaceResidualDiagnoser:
    def __init__(self, omega, modes=('gain', 'bias', 'friction', 'data_loss')):
        self.omega = omega
        self.modes = modes
        self.r_hist = deque(maxlen=50)
        self.phi_hist = deque(maxlen=50)

    def residual(self, a_cmd, a_real, psi=None):
        r = (a_cmd - a_real) if psi is None else psi @ (a_cmd - a_real)
        self.r_hist.append((time.time(), r))
        return r

    def regressor(self, F_cmd, v):
        return np.hstack([np.diag(F_cmd), np.eye(len(F_cmd)), np.diag(np.sign(v))])

    def detect_glr(self):
        # H0: r~N(0,Ω)  H1: r~N(Φθ,Ω); GLR = -2 log(L0/L1)
        phi = np.vstack(self.phi_hist); r = np.concatenate(self.r_hist)
        theta_hat = np.linalg.lstsq(phi, r, rcond=None)[0]
        r0 = r; r1 = r - phi @ theta_hat
        return 0.5 * (r0.T @ np.linalg.solve(self.omega, r0)
                      - r1.T @ np.linalg.solve(self.omega, r1))

    def identify(self):
        # 最小二乘点估计 + 卡方可信椭球：θ ∈ θ̂ ± χ²·J^{-1}
        phi = np.vstack(self.phi_hist); r = np.concatenate(self.r_hist)
        J = phi.T @ np.linalg.solve(self.omega, phi)
        theta_hat = np.linalg.solve(J, phi.T @ np.linalg.solve(self.omega, r))
        F_hat = ellipsoid(theta_hat, chi2.ppf(0.95, len(theta_hat)) * np.linalg.inv(J))
        return theta_hat, F_hat
```

### IP-162 DAS（可诊断动作子空间）

```python
def diagnosable_subspace(A_nom, regressor_fn, omega_inv, gamma_exc, kappa_max):
    A_diag = []
    for a in A_nom:
        phi = regressor_fn(a)
        J = phi.T @ omega_inv @ phi
        if np.linalg.eigvalsh(J).min() >= gamma_exc and np.linalg.cond(phi) <= kappa_max:
            A_diag.append(a)
    return A_diag

def diagnosability_deficit(A_diag, task_support, sampler):
    covered = [a for a in sampler(A_diag) if task_support(a) > 0]
    return 1.0 - len(covered) / max(1, len(A_diag))
```

### IP-163 DAP（主动诊断探测）

```python
def select_probe(A_safe, belief, omega_inv, regressor_fn, risk_fn, cost_fn, lam, R_max):
    best, best_val = None, -np.inf
    for a in A_safe:
        risk = risk_fn(a, belief)
        if risk > R_max:
            continue
        J = regressor_fn(a).T @ omega_inv @ regressor_fn(a)
        info = 0.5 * np.linalg.slogdet(J)[1]          # D-最优信息增益
        val = info / (lam['r'] * risk + lam['b'] * cost_fn(a) + 1e-9)
        if val > best_val:
            best, best_val = a, val
    return best
```

### IP-164 FTAC（容错动作空间收缩）

```python
def contract_action_space(A_nom, F_hat, bounds, tau_exec):
    A_cert = ActionSet()
    for a in A_nom:
        F_wc = bounds.worst_force(a, F_hat)           # 区间/椭球传播
        tau_wc = bounds.worst_torque(a, F_hat)
        if F_wc <= bounds.F_safe and tau_wc <= bounds.tau_max \
           and bounds.exec_prob(a, F_hat) >= tau_exec:
            A_cert.add(a, margin=bounds.F_safe - F_wc)
    return A_cert

def try_expand(A_cert, A_nom, asr, rate=0.2):
    if asr.residual_consistent(k=5) and asr.posterior_concentrated():
        return A_cert.expand(A_nom, max_rate=rate)    # 迟滞，防抖动
    return A_cert
```

### IP-165 FADE（故障-动作双螺旋）

```python
def fade_loop(M, A_nom, task):
    a = task.next_action(A_nom)
    a_real = execute_impedance(a)
    r = M.asr.residual(a, a_real, M.psi)
    M.asr.phi_hist.append(M.asr.regressor(a.F_d, a.v))

    if M.asr.detect_glr() > M.gamma_det:
        theta_hat, F_hat = M.asr.identify()
        A_cert = contract_action_space(A_nom, F_hat, M.bounds, M.tau_exec)
        M.fault_cert = make_certificate(theta_hat, F_hat, A_cert, M.asr)
    else:
        A_cert = A_nom

    A_final = intersect(A_nom, M.A_scene, M.C_intent, A_cert)

    if M.asr.diagnosability_deficit() > M.theta_d and M.budget.B_diag > 0:
        a_probe = select_probe(A_final, M.asr.belief, M.omega_inv,
                               M.asr.regressor, M.risk, M.cost,
                               M.lam, M.R_max)
        if a_probe is not None:
            execute_impedance(a_probe)                 # 诊断坐标轴
            M.budget.B_diag -= 1

    if A_final.is_empty():
        return degrade_or_escalate(M, task, M.fault_cert)
    return dispatch(A_final, M.fault_cert)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ASR | O(q²·m) / 步；GLR O(T·q²) | O(T·m) | 检测时延 ≤ T_det，虚警 ≤ β |
| DAS | O(m³) / 动作（增量 O(m²)） | O(m²) | λ_min(J) ≥ γ_exc 时满秩可诊断 |
| DAP | O(\|A_safe\|·m³)（风险预剪枝后近线性） | O(\|A_safe\|) | R(a) ≤ R_max 约束下 D-最优 |
| FTAC | O(\|A_nom\|·\|F̂\|)（区间传播） | O(\|A_nom\|) | 对 F̂ 鲁棒安全、单调 |
| FADE | 主项为 EEIS 编译 | 复用 | 无新证据不扩张；迟滞不震荡 |

**正确性定理（DSA）**：若 A66–A70 成立，则
1. **检测/隔离**：GLR 在 T_det 内以虚警 ≤ β 检出；激励条件成立时 θ 的隔离误差 ≤ ε_iso，秩亏故障仅可检测不可隔离且被显式标注。
2. **收缩安全性**：∀a∈A_cert，∀f∈F̂，g(a,f)∈S_safe ∧ P_exec ≥ τ_exec ⇒ A_cert 对真故障鲁棒安全。
3. **单调与可恢复性**：F̂ 缩小 ⇒ A_cert 单调扩大；扩张仅在残差一致 + 后验集中时发生，变化率 ≤ ρ_max。
4. **闭环可终止**：收缩-扩张带迟滞，无无限振荡。

## 5. 本轮最大风险

**一句话**：若故障签名模型被错误设定（例如把摩擦误当成传感器零偏、或区间传播低估了最坏力），诊断就会「自信地把动作空间收缩到错误方向」，产生「证书齐全、物理上却不可行」的**动作空间幻觉**；必须以可信集（而非点估计）+ 鲁棒区间收缩 + 残差复验 + 扩张迟滞 + 诊断歧义时求助人类五重护栏，确保「诊断置信」永远不等于「执行安全」。

# 第 61 轮产物 · 创新点清单 v2：FADE（故障-动作双螺旋：动作空间残差诊断 × 可诊断子空间 × 主动探测 × 容错收缩，ASR×DAS×DAP×FTAC×FADE×PCE⁵）

> 承接第 60 轮 IP-153~160（SSM×CIEC×EPIR×SERC×SIC×CESC）。本轮把第 60 轮「场景先验约束阻抗」升级为 **「故障诊断重塑动作空间」**：用动作空间残差 ASR 把异构故障统一到同一坐标系；用可诊断动作子空间 DAS 刻画「诊断能力依赖动作分布」；用主动探测 DAP 在任务不激励时插入诊断坐标轴；用容错收缩 FTAC 把故障可信集投影为认证动作集 A_cert；用 FADE 闭环把诊断与动作拧成双螺旋；PCE⁵ 增加诊断/动作双预算。核心命题：**诊断不只回答「哪里坏了」，还要回答「还能做什么」，并且这个回答必须被证据认证。**

> IP 编号：IP-161~IP-168（共 8 个），新增故障感知动作空间 5 项核心能力。

## 2. 关键算法伪代码

### IP-161 ASR（动作空间残差诊断）

```python
class ActionSpaceResidualDiagnoser:
    def __init__(self, omega):
        self.omega = omega
        self.r_hist, self.phi_hist = deque(maxlen=50), deque(maxlen=50)

    def residual(self, a_cmd, a_real, psi=None):
        return (a_cmd - a_real) if psi is None else psi @ (a_cmd - a_real)

    def regressor(self, F_cmd, v):
        return np.hstack([np.diag(F_cmd), np.eye(len(F_cmd)), np.diag(np.sign(v))])

    def detect_glr(self):
        phi = np.vstack(self.phi_hist); r = np.concatenate(self.r_hist)
        theta_hat = np.linalg.lstsq(phi, r, rcond=None)[0]
        r1 = r - phi @ theta_hat
        return 0.5 * (r.T @ np.linalg.solve(self.omega, r)
                      - r1.T @ np.linalg.solve(self.omega, r1))

    def identify(self):
        phi = np.vstack(self.phi_hist); r = np.concatenate(self.r_hist)
        J = phi.T @ np.linalg.solve(self.omega, phi)
        theta_hat = np.linalg.solve(J, phi.T @ np.linalg.solve(self.omega, r))
        return theta_hat, ellipsoid(theta_hat,
                                    chi2.ppf(0.95, len(theta_hat)) * np.linalg.inv(J))
```

### IP-162 DAS（可诊断动作子空间）

```python
def diagnosable_subspace(A_nom, regressor_fn, omega_inv, gamma_exc, kappa_max):
    out = []
    for a in A_nom:
        phi = regressor_fn(a)
        J = phi.T @ omega_inv @ phi
        if np.linalg.eigvalsh(J).min() >= gamma_exc and np.linalg.cond(phi) <= kappa_max:
            out.append(a)
    return out
```

### IP-163 DAP（主动诊断探测）

```python
def select_probe(A_safe, belief, omega_inv, regressor_fn, risk_fn, cost_fn, lam, R_max):
    best, best_val = None, -np.inf
    for a in A_safe:
        risk = risk_fn(a, belief)
        if risk > R_max:
            continue
        J = regressor_fn(a).T @ omega_inv @ regressor_fn(a)
        val = 0.5 * np.linalg.slogdet(J)[1] / (lam['r'] * risk + lam['b'] * cost_fn(a) + 1e-9)
        if val > best_val:
            best, best_val = a, val
    return best
```

### IP-164 FTAC（容错动作空间收缩）

```python
def contract_action_space(A_nom, F_hat, bounds, tau_exec):
    A_cert = ActionSet()
    for a in A_nom:
        F_wc = bounds.worst_force(a, F_hat)        # 区间/椭球传播
        tau_wc = bounds.worst_torque(a, F_hat)
        if F_wc <= bounds.F_safe and tau_wc <= bounds.tau_max \
           and bounds.exec_prob(a, F_hat) >= tau_exec:
            A_cert.add(a, margin=bounds.F_safe - F_wc)
    return A_cert

def try_expand(A_cert, A_nom, asr, rate=0.2):
    if asr.residual_consistent(k=5) and asr.posterior_concentrated():
        return A_cert.expand(A_nom, max_rate=rate)  # 迟滞，防抖动
    return A_cert
```

### IP-165 FADE（故障-动作双螺旋）

```python
def fade_loop(M, A_nom, task):
    a = task.next_action(A_nom)
    a_real = execute_impedance(a)
    r = M.asr.residual(a, a_real, M.psi)
    M.asr.phi_hist.append(M.asr.regressor(a.F_d, a.v))

    if M.asr.detect_glr() > M.gamma_det:
        theta_hat, F_hat = M.asr.identify()
        A_cert = contract_action_space(A_nom, F_hat, M.bounds, M.tau_exec)
        M.fault_cert = make_certificate(theta_hat, F_hat, A_cert, M.asr)
    else:
        A_cert = A_nom

    A_final = intersect(A_nom, M.A_scene, M.C_intent, A_cert)

    if M.asr.diagnosability_deficit() > M.theta_d and M.budget.B_diag > 0:
        a_probe = select_probe(A_final, M.asr.belief, M.omega_inv,
                               M.asr.regressor, M.risk, M.cost, M.lam, M.R_max)
        if a_probe is not None:
            execute_impedance(a_probe)              # 诊断坐标轴
            M.budget.B_diag -= 1

    if A_final.is_empty():
        return degrade_or_escalate(M, task, M.fault_cert)
    return dispatch(A_final, M.fault_cert)
```

### IP-167 PCE⁵（诊断-动作双预算）

```python
class PCE5Budget:
    def __init__(self, diag_ops=5, act_ratio=0.3, exec_budget=None):
        self.B_diag = diag_ops
        self.B_act = act_ratio              # A_need 允许的最小可行比例
        self.B_exec = exec_budget or ExecBudget()

    def fallback(self, A_cert, A_nom, A_need):
        if self.B_diag <= 0:
            return worst_case_contract(A_nom)          # 最坏界收缩
        if len(A_cert & A_need) / max(1, len(A_need)) < self.B_act:
            return 'DEGRADE_TASK_OR_ESCALATE'
        return 'NORMAL'

def voi_diag(a, belief, omega_inv, regressor, risk_fn, cost_fn, lam):
    J = regressor(a).T @ omega_inv @ regressor(a)
    return 0.5 * np.linalg.slogdet(J)[1] - lam['r'] * risk_fn(a, belief) - lam['b'] * cost_fn(a)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| ASR | O(q²m)/步；GLR O(Tq²) | O(Tm) | T_det ≤ 3 周期；虚警 ≤ β |
| DAS | O(m³)/动作（增量 O(m²)） | O(m²) | λ_min(J)≥γ_exc ⇒ 满秩可诊断 |
| DAP | O(\|A_safe\|m³)（预剪枝近似线性） | O(\|A_safe\|) | R≤R_max 下 D-最优 |
| FTAC | O(\|A_nom\|\|F̂\|) | O(\|A_nom\|) | 对 F̂ 鲁棒安全、单调 |
| FADE | 主项 EEIS 编译 | 复用 | 无证据不扩张、迟滞不震荡 |

**正确性定理（DSA）**：若 A66–A70 成立，则
1. 检测时延 ≤ T_det、虚警 ≤ β；激励成立时隔离误差 ≤ ε_iso，秩亏故障显式降级为「可检测不可隔离」。
2. ∀a∈A_cert，∀f∈F̂：g(a,f)∈S_safe ∧ P_exec ≥ τ_exec ⇒ A_cert 对真故障鲁棒安全。
3. F̂ 单调缩小 ⇒ A_cert 单调扩大；扩张仅在残差一致 + 后验集中时发生，变化率 ≤ ρ_max。
4. 收缩-扩张带迟滞 ⇒ FADE 不无限振荡。

## 5. 本轮最大风险

**一句话**：若故障签名模型被错误设定（例如把摩擦误当成传感器零偏、或区间传播低估最坏力），诊断会「自信地把动作空间收缩到错误方向」，产生「证书齐全、物理上却不可行」的动作空间幻觉；必须以可信集 + 鲁棒区间收缩 + 残差复验 + 扩张迟滞 + 诊断歧义时求助人类五重护栏，确保「诊断置信」永远不等于「执行安全」。
