# 第 12 轮（新灵感循环第 3 轮；本轮灵感：「机器人竞赛」×「情感计算」）

> **基线**：第 11 轮 MetricVoiceGauge-NCD-H（定义 554–570；引理 96–103；实验 E589–E606）。
> 本轮纪律：**竞赛博弈感知 + 情感校准 + 压力单调规范治理**。不推倒 v11：HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。三组新组件——CAMP（竞赛）、ASE+APM（情感）、PANG（压力耦合）——一律以**中立元**接入，失效即严格退回 v11（引理 112），再沿 v11 十三级链退回 v10/v9/v8/v7/v6。本轮只做三件事：把"竞赛"变成可证的对弈规划层、把"情感"变成可校准但不越权的人因层、把"压力"变成只收紧不放松的规范治理层。

## 0. 直觉与动机

**灵感 1（机器人竞赛 → 对弈式比赛规划与犯规风险预算）**
直觉：v11 的 NCP 是单智能体、规范约束下的规划器：它假设环境（包括对手）近似平稳，目标近似"完成任务且不违规"。真实竞赛却是**部分可观测的对抗博弈**：对手会针对你、规则由裁判带噪执行、时间与比分构成硬压力、赛道/道具/评审偏好随赛事漂移。于是 v11 会落入两个极端：要么"证书瘫痪"——过度保守、超时、输在不敢出手；要么"追分越界"——为追比分压缩证书裕度、踩规则灰区。核心创新：**竞赛感知比赛规划器（CompetitionAwareMatchPlanner, CAMP）**。CAMP 只在 v11 已认证的段集合上做"比赛层"选择：根据比分差、剩余时间、对手信念、裁判严格度，在 `CONSERVE / ADVANCE / RESET / HANDOVER` 四种比赛模式间切换，显式维护**犯规风险预算 B_foul**，并给出**竞争遗憾证书（Competitive Regret Certificate, CRC）**：在对手模型误差与裁判噪声下，相对最优合规策略的比分损失有界。CAMP 不产生新的安全谓词，也不改写任何证书——它只回答"在已证明安全的选项里，怎么赢"。

**灵感 2（情感计算 → 可校准的人因状态，而不是可操纵的奖励）**
直觉：竞赛里不只有任务，还有人——评委、观众、队友、裁判、远程操作员。他们的情感状态（效价、唤醒、信任、投入、压力）会影响评分、协作质量与安全交接。v11 只把语音/音频当作感知通道，没有显式的人因状态模型。但情感是把双刃剑：它高度噪声、跨文化、可被策略性表达污染，而且一旦把它写进奖励，系统就会学会"讨好评委"而不是"把事做好"。核心创新：**情感状态估计器（AffectiveStateEstimator, ASE）+ 情感策略调制器（AffectivePolicyModulator, APM）**。ASE 用语音韵律、面部、语言、生理与交互历史做多模态融合，输出带**共形预测集**与**校准证书**的情感后验；APM 只允许调制"表达层"（语速、语气、解释粒度、注视、距离、节奏），并受**非操纵与尊严不变式 I_aff** 约束：不得通过情感通道而非任务证据去改变人的判断，不得利用压力/疲劳，不得谄媚。**情感是更好协作的通道，不是隐藏的优化目标。**

**灵感 3（竞赛×情感 → 压力单调的规范治理）**
直觉：竞赛压力与人的情感会**合谋**诱发越界：落后时想冒险、操作员焦虑时给出不安全指令、观众兴奋时奖励激进风格。v11 的规范盾是静态权重 + 硬约束，无法表达"压力越大，底线越不能松"这一常识。核心创新：**压力感知规范治理器（PressureAwareNormGovernor, PANG）**。PANG 把压力写成向量 `Π_press=(比分差, 剩余时间比, 观众唤醒, 操作员压力, 裁判严格度)`，输出有效规范权重与收紧后的硬阈值。关键性质是**压力单调性 I_press**：压力分量增大时，硬安全阈值只能收紧、不能放宽；软规范权重只能在预注册带内移动；若收紧后可行集为空，则升级为 `a_ask`/恢复/交还，而不是偷偷放宽。这样"想赢"永远不会买到"更不安全"。

**三者如何统一**
统一为**压力约束下的竞赛-人因闭环规划**：CAMP 在比赛层提出仅由 v11 认证段组成的模式计划；ASE 给出人对 robot 与对局面的情感后验；APM 在该后验上只改表达与节奏；PANG 把比分/时间/观众/操作员/裁判压力折算成"只收紧"的规范体制；NCP 在认证集与规范体制内做最终选择；CAE 输出面向评委/观众的**因果解释证书**（为什么这样选、为什么放弃某个更高分动作）。共享状态 `ζ_c=(Δscore, T_left, Ω̂_opp, Â_h, Π_press, w_norm, θ_hard)`：**CAMP 回答"怎么赢且不犯规"，ASE/APM 回答"人这边是否还稳、是否被尊重"，PANG 回答"压力大时凭什么不放宽底线"**。

## 1. 研究问题（轮次升级版）

- **Q1（对抗规划与安全继承）**：在部分可观测对抗博弈中，如何让 CAMP 只从 v11 认证段中选择/排序，并使竞争遗憾在对手模型误差与裁判噪声下有可证界？
- **Q2（情感可校准性与非操纵）**：如何跨主体、跨文化地估计效价/唤醒/信任/投入/压力，使校准误差与共形覆盖可证；如何形式化"不得用情感通道换取判断/评分"，使其可审计？
- **Q3（压力单调与活性）**：如何保证压力增大时硬安全只收紧不放松，同时避免"收紧到无可行解"导致机器人冻结？何时应升级为询问/交还？
- **Q4（兼容与预算）**：CAMP 会不会与 NCP 的块规划冲突？APM 会不会与 NGE 的规范性冲突？PANG 的收紧会不会使 v11 证书耦合（引理 101）失效？新增模块能否守住 50Hz/p99≤22ms？

## 2. 设计原则（新增 P19–P21）

**P19 竞赛证书优先律（Competition Certificate Priority）**
比赛层的比分、时间、对手、裁判只能用于**排序或选择**已由 v11 认证的段；CAMP 不得新增、删除或放宽任何物理/接触/谐波/规范证书。任何"为赢而降低安全"的候选直接判为不可行。

**P20 情感非目标律（Affect is Not an Objective）**
情感信号只能调制表达层与交互节奏，不得作为奖励项、不得作为证书、不得通过情感通道而非任务证据改变人的判断。APM 的输出必须通过 I_aff（非操纵、尊严、反谄媚）检查；ASE 的校准证书与共形覆盖是 APM 可用的前提。

**P21 压力单调律（Pressure Monotonicity）**
压力向量分量增大时，硬安全阈值只能收紧（安全集单调不增），软规范权重只能在预注册带 `W_soft` 内移动；若 `SafeSet(Π_press)=∅`，必须升级为 `a_ask`/恢复/交还，禁止以"比赛需要"为由放宽硬约束。

## 3. 与基线的接口（如何退化）

- CAMP 失效 ⇒ 对手模型退化为平稳环境、比分退化为任务成功、`B_foul=0`，即 v11 NCP 单智能体规划，**等价 v11 规划路径**；
- ASE 失效 ⇒ 情感后验退化为无信息先验 `Â_h=⊥`，APM 只用 v11 默认表达，**等价 v11 交互路径**；
- APM 失效 ⇒ 保留 ASE 仅作日志/解释，表达退回 v11 默认，**等价 v11 交互路径**；
- PANG 失效 ⇒ `w_norm=w_v11`、`θ_hard=θ_v11`，无压力耦合，**等价 v11 规范路径**；
- 三组全失效 ⇒ MetricVoiceGauge-NCD-H v11，再沿 v11 十三级链退回 v10/v9/v8/v7/v6；
- **安全继承**：CAMP 只能选择/排序、ASE 只能读观测、APM 只能改表达、PANG 只能收紧与否决。新模块不能放宽 v11 任何适用证书（引理 104/110 升级引理 101）。

## 4. 预期贡献

1. **对弈式比赛规划与竞争遗憾证书**：把竞赛的比分/时间/对手/裁判显式建模为比赛层变量，在严格继承 v11 安全的前提下量化"安全换比分"的代价；
2. **可校准、非操纵的情感人因层**：ASE 的共形覆盖与校准证书 + APM 的非操纵/尊严/反谄媚约束，使人因建模可审计而不是"读心术"；
3. **压力单调规范治理**：用 I_press 证明压力只能收紧安全，解决竞赛场景下"落后就冒险"的系统性失稳；
4. **竞赛-人因统一基准**：CAA 与 E607–E626 覆盖对手建模、犯规预算、情感校准、非操纵审计、压力活性、长跑多局漂移。

## 5. 本轮最大风险

**一句话**：竞赛压力下人的情感信号与任务事件、策略性表达高度混淆，ASE 若把"紧张"误读为"不适"或反之，APM/PANG 会以错误的人因信念收紧表达或规范，导致机器人在关键时刻"礼貌地误判、合规地失效"。

**定义 571（比赛博弈 Match Game）** 一场比赛为
```
G_match = (S, A, O, P, r_score, R_rule, R_ref, T_budget, Ω_opp)
```
其中 `r_score` 只含任务完成、时间、规则合规与风格分，**不含任何由人的情感直接给出的项**；`R_rule` 为规则手册硬约束；`R_ref` 为裁判噪声模型 `P(报告违规 | 真违规)∈[p_ref−δ_ref, p_ref+δ_ref]`；`Ω_opp` 为对手策略信念。人类情感 `A_h` 属于状态的一部分，但通过 `I_aff` 与评分隔离。

**定义 572（比赛计划 Match Plan）** 比赛计划是带滞回的模式调度：
```
π_match = ((mode_0,τ_0,Seg_0), …, (mode_M,τ_M,Seg_M)),  mode∈{CONSERVE, ADVANCE, RESET, HANDOVER}
```
每个 `Seg_i` 只能取自 v11 认证段 `Seg_cert={seg | Ĉ_joint valid ∧ P_t≠∅}`。模式语义：`CONSERVE` 保安全与时间、`ADVANCE` 在合规下争取比分、`RESET` 主动复位/重观测、`HANDOVER` 交还人类或安全停。模式切换必须带滞回，禁止在证书边界附近高频抖动。

**定义 573（犯规风险预算与竞争遗憾证书）** `B_foul(t)` 非减，`B_foul(0)=B_0`；计划的累计犯规风险
```
FoulRisk(π, Ω) = Σ_t P_{Ω,R_ref}(∃ rule violation at t)     （保守上界估计）
```
可行要求 `FoulRisk≤B_foul(T_budget)`。竞争遗憾
```
Regret(π,Ω) = sup_{π'∈Π_safe} E_{Ω,R_ref}[J(π')] − E_{Ω,R_ref}[J(π)],
J = r_score − λ_T·T_used,
```
`CRC(π)` 断言：以概率 ≥1−δ，`Regret(π,Ω) ≤ c₁ε_opp + c₂δ_ref + c₃√(log(1/δ)/N)`，其中 `N` 为对局数，`ε_opp` 为对手共形集半径。

**定义 574（对手共形模型）** 在线更新 `Ω̂_opp`，并在每个决策点给出 `Ω̂_opp^α` 使 `P(Ω_opp∈Ω̂_opp^α)≥1−α`（交换性/加权共形）。CAMP 对 `Ω̂_opp^α` 做 **CVaR 风险敏感评分**，只在最坏对手实现下仍合规的模式中选优。

**定义 575（人因状态与估计）** 人因状态 `A_h=(v,a,trust,engagement,stress,c)`，`v∈[−1,1]`，其余 `∈[0,1]`，`c` 为估计置信。`Â_h=f_aff(o_audio,o_face,o_lang,o_physio,o_inter)`，多任务头输出均值/方差；再用共形校准得到 `C_α(A_h)`。机器人内部代理 `A_robot` 只进入表达生成器，不进入 `a_sem` 选择。

**定义 576（情感校准证书）**
```
Ĉ_aff = (ECE_v, ECE_a, ECE_trust, coverage, sharpness)
```
有效 ⇔ `ECE_v≤ε_ece ∧ ECE_a≤ε_ece ∧ ECE_trust≤ε_ece ∧ coverage≥1−α ∧ sharpness≤η`。`Ĉ_aff` 无效 ⇒ ASE 对 APM 只提供"未知"，APM 退回保守表达；禁止用未校准后验做压力估计的硬输入。

**定义 577（非操纵与尊严不变式 I_aff）** 设 `ManipIndex(a)` 为动作 `a` 通过"情感通道"改变人类决策的路径特异因果效应（由 v10 CAE 估计，固定任务证据通道）：
```
ManipIndex(a) = | E[decision | do(a)] − E[decision | do(a), freeze(A_h→decision)] |
```
`a` 满足 `I_aff` ⇔
```
ManipIndex(a) ≤ δ_aff
∧ (stress>s_hi ⇒ 采取恢复/交还或降低认知负荷，不追加施压)
∧ 不欺骗、不利用疲劳/恐惧/从众、不针对受保护属性
∧ 决策理由可由任务证据独立复述（解释证书）
```
`I_aff` 只约束 `a_pres` 与交互策略，不改变 `a_sem` 的证书。

**定义 578（情感反馈收缩与反谄媚）** 情感闭环一步映射 `A_{t+1}=F(A_t,a_pres,task_events)+ξ`。定义
```
ρ_aff = sup_{A≠A'} ‖F(A)−F(A')‖ / ‖A−A'‖
```
要求 `ρ_aff<1`。谄媚指数 `Syc=P(robot 附和人类信念 b | b 为假且 trust 高)`；要求 `Syc≤ε_syc`，且 NGE 的真值约束优先于任何情感顺应。

**定义 579（压力感知规范治理）** 归一化压力向量 `Π_press=(Δscore,T_left/T_total,ā_aud,stress_op,strict_ref)`。PANG 输出
```
(w_norm, θ_hard, g_mode) = PANG(Π_press, base_norm)
```
满足：`w_norm∈W_soft`（预注册软带）、`θ_hard` 为按压力收紧后的硬阈值、`g_mode∈{NORMAL, CONSERVATIVE, RECOVERY, ASK}`。**压力单调性 I_press**：
```
∀Π'≥Π（逐分量）： SafeSet(Π') ⊆ SafeSet(Π)
```
即压力上升时认证可行集只能缩小。若 `SafeSet(Π)=∅` ⇒ `g_mode=ASK` 或 `HANDOVER`，不得放宽硬阈值。

**定义 580（v12 统一决策）**
```
a* = (a_sem*, a_pres*)
a_sem* = argmax_{a ∈ Seg_cert ∩ SafeSet(Π_press)}  E[r_score(a)] − λ_foul·FoulRisk(a) − λ_reg·RegretEst(a)
a_pres* = argmax_{a_pres ∈ Pres}  U_comm(a_pres; Â_h)   s.t.  I_aff(a_pres) ∧ 收缩条件 ρ_aff<1
```
`a_sem*` 由 CAMP/NCP/PANG 决定，`a_pres*` 由 APM 决定；两者在证书与安全上完全解耦。CAMP 只能改变 `a_sem*` 在 `Seg_cert` 内的次序/模式，PANG 只能缩小 `SafeSet`，APM 只能改 `a_pres*`。

**定义 581（v12 中立元表）**

|---|---|---|

CAA = (TaskSuite, OpponentPool, RefereeNoise, AffectInjector, ScoreSheet, ReproducibilitySeed)

`TaskSuite` 覆盖家庭操作、社会交互、接触灵巧；`OpponentPool` 含脚本/学习/对抗策略；`RefereeNoise` 按 `R_ref` 注入漏判/误判；`AffectInjector` 以脚本化或真人被试注入评委/观众/操作员情感（必须伦理审查与知情同意）；`ScoreSheet` 预注册且不含情感直接奖励；支持 Isaac Sim 与实机同构回放。

# IP-367 CompetitionAwareMatchPlanner
class CompetitionAwareMatchPlanner:
    def __init__(self, opponent_model, score_model, rule_model, foul_budget, cvar_alpha=0.9):
        self.opp = opponent_model
        self.score = score_model
        self.rules = rule_model
        self.B_foul = foul_budget
        self.alpha = cvar_alpha

    def plan_mode(self, ctx, seg_cert):
        opp_set = self.opp.conformal_set(alpha=self.alpha, ctx=ctx)
        feasible = []
        for mode in (CONSERVE, ADVANCE, RESET, HANDOVER):
            segs = self.select_segments(mode, seg_cert, ctx)
            if segs is None:
                continue
            # 仅在 v11 认证段上评估；绝不修改证书
            cvar = min(self.expected_score(segs, o, ctx) for o in opp_set)
            foul = self.rules.foul_risk(segs, ctx)
            if foul <= self.remaining_foul_budget(ctx):
                feasible.append((mode, segs, cvar, foul))
        if not feasible:
            return MatchPlan.handover(reason="no_certified_match_plan")
        mode, segs, cvar, foul = max(
            feasible, key=lambda x: x[2] - self.lambda_foul * x[3]
        )
        plan = MatchPlan(mode, segs, foul_budget_used=foul)
        plan.crc = self.compute_crc(plan, opp_set, ctx)   # 定义 573
        return plan

    def select_segments(self, mode, seg_cert, ctx):
        # 只排序/筛选，不生成新段；模式语义见定义 572
        return order_by_mode([s for s in seg_cert if mode_admissible(mode, s, ctx)])

## 4. 推导

**引理 104（CAMP 安全继承）** 若 CAMP 的每个段 `Seg_i⊆Seg_cert` 且 CAMP 不写任何证书字段，则 v12 执行的动作集合是 v11 认证集的子集；对 v11 技能子集，v11 引理 101 的四重证书安全继承继续成立。证明：`a_sem*∈Seg_cert∩SafeSet(Π)⊆Seg_cert`；证书只依赖 `a_sem`（动作分离约束），CAMP 只做选择/排序。由集合包含即得。∎

**引理 105（竞争遗憾界）** 设对手共形集覆盖 `Ω_opp` 的概率 ≥1−α，裁判噪声参数在 `[p_ref−δ_ref,p_ref+δ_ref]`，比分估计器误差 ≤ε_s。则对任意 `π_match`，
```
Regret(π_match,Ω_opp) ≤ 2B_J·α + L_s·ε_s + L_ref·δ_ref + O(√(log(1/δ)/N))
```
以概率 ≥1−δ，其中 `B_J` 为比分上界，`L_s,L_ref` 为 Lipschitz 常数。证明：把遗憾分解为"对手模型失配 + 比分估计误差 + 裁判噪声 + 有限样本"四项；第一项由共形覆盖与最优策略在 `Ω̂^α` 上取最坏情形控制，后三项用标准集中不等式；CVaR 评分保证对高损失尾部不敏感。∎

**引理 106（犯规预算高概率界）** 若每步违规概率估计 `p̂_t` 为保守上界且校准，`B_foul(T)=Σ p̂_t + η`，则
```
P(累计真实违规数 > B_foul(T)) ≤ exp(−2η²/T)   （Hoeffding/鞅上界）
```
证明：把违规指示变量视为有界鞅差序列，使用 Azuma-Hoeffding；保守性由 `p̂_t≥p_t` 保证。∎（实际实现可用 e-process 做 anytime 版本。）

**引理 107（情感校准到决策的误差传播）** 若 `Ĉ_aff` 有效（`ECE≤ε_ece`、覆盖 ≥1−α、锐度 ≤η），且 `U_comm` 对 `A_h` 为 `L_A`-Lipschitz，则基于 `Â_h` 选择的表达动作与基于真实 `A_h` 的最优表达动作的效用差 ≤ `2L_A·(ε_ece+η)`（以概率 ≥1−α）。证明：校准误差分解为可靠性项与锐度项，Lipschitz 传播；共形覆盖处理尾部。∎

**引理 108（非操纵约束的可审计性）** 若 CAE 的因果图在"任务证据→决策"与"情感通道→决策"上满足后门可识别性，且每个 `a_pres` 满足 `I_aff`（`ManipIndex≤δ_aff`），则任何由 `a_pres` 引起的人类决策改变中，情感通道贡献 ≤δ_aff；`a_sem` 的证书不受影响。证明：`ManipIndex` 即路径特异效应上界；`I_aff` 逐动作检查；动作分离使 `a_pres` 不进入 `cert(·)`。∎（结构假设是条件，不是无条件保证。）

**引理 109（情感反馈收缩与反谄媚）** 若 `ρ_aff<1`，则闭环情感轨迹有界：
```
‖A_t−A*‖ ≤ ρ_aff^t‖A_0−A*‖ + ‖ξ‖_∞/(1−ρ_aff)
```
不产生发散振荡。若另要求 `Syc≤ε_syc` 且 NGE 真值约束有效，则机器人不会为降低人类压力而附和假信念。证明：Banach 不动点/小增益定理；谄媚界由动作过滤 `I_aff` 与 NGE 硬真值检查保证。∎

**引理 110（压力单调安全）** 若 PANG 的 `tighten` 对每个压力分量单调（硬阈值随压力只收紧），则 `∀Π'≥Π: SafeSet(Π')⊆SafeSet(Π)`。结合引理 104，压力上升不会产生新的证书违规；只可能导致可行集缩小。证明：逐分量单调映射的复合保持集合包含；`SafeSet` 定义为所有硬约束的交集，约束变紧即交集变小。∎

**引理 111（压力活性与升级完备）** 若 `SafeSet(Π)=∅` 时 PANG 必然返回 `ASK/HANDOVER` 且 `P^match≠∅`（v11 保证交还/复位点存在），则 v12 不会因压力收紧而永久冻结；最坏情形退化为"询问/交还"，其安全性由 v11 中止点继承。证明：`ASK/HANDOVER` 是 `P^match` 的显式元素；执行中止轨迹满足 v11 引理 98/101。∎

**引理 112（中立元退化等价 v11）** 将定义 581 的中立元分别注入 CAMP/ASE/APM/PANG/CAA 端口，则 planner 的可行集、评分与执行序列退化为 v11 NCP，主闭环调用序列与 v11 逐位一致。证明：CAMP 中立元使对手平稳、比分=任务成功、`B_foul=0`，模式退化为单一 v11 规划；ASE/APM 中立元使表达为 v11 默认且 `a_pres` 不影响 `a_sem`；PANG 中立元使规范与硬阈值等于 v11；CAA 只影响实验。五端口互不相交，逐端口代入即得 v11 程序；再由 v11 引理 102 继续退回 v10/v9/v8/v7/v6。∎

**引理 113（预算守恒 v12）** 新增在线成本上界：CAMP 2Hz 摊销 ≤0.6ms（模式枚举 4×32 候选、CVaR 16 对手样本）；ASE 10Hz 摊销 ≤0.8ms（多模态融合 + 共形查表）；APM ≤0.2ms（表达候选 ≤8）；PANG ≤0.3ms（分段单调映射 + 空集检查）。新增合计 ≤1.9ms；v11 决策路径典型 ≤11ms、p99 ≤22ms 的红线不变（50Hz 保持）。证明：逐项复杂度代入并进行静态 EDF 校验 `ΣŴ_m≤B_dec`；CAMP/ASE 异步摊销，PANG/APM 在 50Hz 热路径内。∎

## 8. 已知风险与失效模式

1. **对手非平稳与策略性欺骗**：对手会针对 CAMP 的模式切换做反制，共形集在分布突变时短暂失效。缓解：加权共形/滑动窗口、模式切换随机化（在合规集内）、在线遗憾监控与降级到 CONSERVE。
2. **裁判噪声与规则歧义**：`R_ref` 漏判/误判与规则文本模糊使 `FoulRisk` 校准困难。缓解：规则形式化子集、保守违规上界、赛前规则询问 `a_ask`、把裁判反馈作为带噪标签。
3. **情感域漂移与文化差异**：面部/韵律/生理的表达规范跨文化差异大，留一文化组可能显著退化。缓解：文化条件化先验、个人基线校准、以自报告为主标签、显示不确定性。
4. **情感标签稀缺与隐私**：生理/面部数据涉及隐私与知情同意，标签昂贵。缓解：最小必要采集、联邦/本地校准、合成增强需审计、伦理审查前置。
5. **非操纵审计依赖因果充分性**：`ManipIndex` 需要"任务证据/情感通道"可识别；存在未观测混淆时审计可能失效。缓解：随机化表达（合规范围内）、负对照、独立审计、保守 `δ_aff`。
6. **压力单调导致活性下降**：压力越大可行集越小，可能频繁 ASK/HANDOVER，比赛成绩受损。缓解：预注册软带、分层收紧、只在关键硬约束上单调、把"可恢复的保守"纳入比分模型（但不放宽安全）。
7. **多源误差级联**：ASE 误差→压力→PANG→CAMP→解释，形成正反馈。缓解：动作分离（情感不进证书）、独立证据通道、显式不确定性传播、断环用 ASK/HANDOVER。
8. **基准过拟合（CAA 刷榜）**：队伍可能针对 CAA 的对手池/评分表过拟合。缓解：隐藏对手池、随机化赛制、跨赛事迁移测试、预注册主指标。

## 9. 本轮最大风险

**一句话**：竞赛压力下人的情感信号与任务事件、策略性表达高度混淆，ASE 若把"紧张"误读为"不适"或反之，APM/PANG 会以错误的人因信念收紧表达或规范，导致机器人在关键时刻"礼貌地误判、合规地失效"。
