# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；新灵感循环第 1 轮；本轮灵感：「情感语音」×「数据集构建」）

> R73 把「证据」做成契约、可组合、可审计，并把反作用从手写三层推广为模块声明的通道（深度相机是 L4：动作改变视角 → 改变噪声）。但 R73 的证据全部指向**物理世界**：深度、接触、意图。具身系统真正最难测量、也最容易「自信地测错」的对象不是物，而是**人**。
>
> 本轮两个灵感把 R73 的机器对准这一对象：
> - **情感语音**：情感不是一个可直接观测的物理量，而是三层构念——**体验（felt, e^f）/ 表达（expressed, e^x）/ 感知（perceived, e^p）**。语音只直接承载 e^x，标注只直接给出 e^p；从语音推 e^f 需要不可检验的社会-认知假设。更麻烦的是：情感证据的质量被**说话人、文化、语料诱发方式、录音通道、标注者、时间窗**共同调制，且这些因素高度混淆（acted corpus 里「演员身份」几乎能预测「情绪标签」）。
> - **数据集构建**：现有做法把数据集当「原料」，把规模当「能力」。但跨语料 SOTA 崩塌不是模型泛化失败，而是**仪器迁移失败**：每套语料是一台没有证书、没有有效域、没有溯源链的「情感测量仪」。数据集构建应被重构为**仪器设计、校准与认证**；标注者是传感器，一致性是精度而不是效度。
>
> 由此得到本轮核心命题：**不再问「情感识别模型准不准」，而问「情感语音证据能否成为带有效域、可追溯、可组合的测量——使跨语料/跨文化/跨说话人的情感推断在明确构念与风险语义下给出可证伪的结论？」** 把 R73 的 MODGAUGE 扩展为 **AFFECT-GAUGE**（Affective speech evidence with Formal annotation contracts, Elicitation instruments, Cross-corpus Traceability, and GAUGE audits）——**情感语音计量审计**。
>
> 第三个结构性后果是 **L5**：机器人自己的情感回应（语调、时机、措辞、接近）会改变用户的情绪状态与表达规则。R73 的 L4 是「动作改变噪声」，L5 是「动作改变被测量本身」——这是社会科学的反身性（reflexivity）/观察者效应，必须在契约里显式声明预算与自治约束。

## 0. 直觉与动机

**直觉 1（情感语音 → 测量的对象是构念，不是信号）**
我们听一段语音说「他很生气」，其实同时做了三件事：从声学线索推断**表达**，用文化脚本推断**体验**，再用自己的规范给出**感知**。三者可以背离：压抑的文化里 e^f 高而 e^x 低；表演语料里 e^x 高而 e^f 低；标注者可能把「高唤醒」误读为「愤怒」。因此情感语音的第一性困难不是分类器，而是**构念效度**：我们到底在测什么？AFFECT-GAUGE 的第一条纪律是**构念诚实**：任何从语音出发的主张必须声明它关于 e^x / e^p 还是 e^f；对 e^f 的主张必须显式携带不可检验假设 A-affect，不得伪装成「识别准确率」。

**直觉 2（七分量 → 情感证据的不确定度有确定性结构）**
和深度六分量同构，情感证据的不确定度可分解为：u_annot（标注者间分歧）、u_construct（构念/schema 间隙）、u_culture（文化/语言测量非不变性）、u_speaker（说话人身份混淆）、u_channel（设备/编码/房间）、u_elicitation（acted / induced / naturalistic）、u_temporal（时间窗/混合情绪/动态）。每一项有独立物理或社会机制、独立追溯链、独立校准实验。把七分量压成一个标量，等于把「仪器误差」和「构念误差」混为一谈——这正是 R72/R73 反复批判的「把 X 不确定度误读为 Y 不确定度」的同型错误。

**直觉 3（数据集即仪器 → 一致性是精度，不是效度）**
标注者是一台传感器：有训练（校准）、有文化先验（偏置）、有疲劳（噪声）、有胜任域（有效域）、有身份（溯源）。增加标注者只能降低**随机分歧**，不能降低**共享文化偏置**。因此 κ=0.9 的语料完全可能系统性测错构念：全体标注者共享同一套 display rule。**共识不是校准**。数据集证书必须同时报告可靠性与效度证据，并把「有效域」写成硬边界；跨语料比较必须经过锚定可比性（ACT），否则只是两台未校准仪器读数相减。

**直觉 4（L5 反作用 → 测量会改变被测量）**
在 HRI 中，机器人用安抚语调回应，用户的情绪分布会变；机器人误判并过度追问，用户会烦躁甚至隐藏真实感受。这不是「传感器噪声变了」（L4），而是**被测量的状态与表达规则一起变了**（L5）。于是「测得的平静」可能是机器人自己制造出来的假象（Goodhart）。AFFECT-GAUGE 必须把情感反作用通道 χ_A 写进契约，给出干预预算、安全稳态集与**非操纵/自治约束**：机器人可以调节自身行为，但不得 covertly 操纵；用户必须有知情与退出。

**直觉 5（跨语料 = 可追溯性，不是 domain adaptation）**
「在 A 语料训练、B 语料测试掉点」通常被当作分布偏移。计量学的问法是：A、B 是否在同一有效域、是否可追溯到同一参考尺度、它们的差异是构念差异还是通道差异？没有锚点与不变性电池，跨语料数字不可比；有了锚定映射与迁移不确定度，才能给出**有条件的**可比性证书。

**直觉 6（下游是风险决策，不是准确率）**
HRI 中把「痛苦」误读为「中性」的代价远大于把「中性」误读为「痛苦」。情感证据应进入**非对称风险决策**：p(e|x) + u_emo；当不确定度过高时，正确动作可能是**问一句**（主动测量），而不是猜。这把 R73 的 ERVOI 推广为 A-VOI。

## 1. 形式化定义（增量：定义 383–400）

**定义 383（AFFECT-GAUGE 总览与五不变式）** AFFECT-GAUGE = (ESEM, ADI, AEC, ACT, χ_A, ARD, MODGAUGE†)。五不变式：
(i) **构念诚实**：每个主张声明其对象 ∈ {e^f, e^x, e^p} 与 schema；从语音单独推 e^f 必须携带假设 A-affect，不得省略；
(ii) **仪器完备**：进入认证路径的每个数据集必须有 ADI 证书与有效域；无证书只能标记为探索性，不得进入可比性主张；
(iii) **不确定度分解**：报告七分量及各自追溯链，禁止只报标量；
(iv) **可比性前置**：任何跨语料/跨文化数值主张必须先过 ACT 可比性证书；
(v) **反作用预算与严格退化**：χ_A 必须声明（可为平凡），ΣREFLEX-L5 预算闭合；出域 ⇒ EMO stub ⇒ 保守 HRI 策略；安全侧只增不减。

**定义 384（三层情感构念模型）** 设说话人 s、文化/语言语境 c、声学观测 x、标注者 a、schema S。
- 体验 e^f ~ p(e | context)（不可由语音单独识别）；
- 表达 e^x = D_c(e^f, s, social_context)，D_c 为文化展示规则；
- 感知 e^p = P_a(x, c, S)；
- 标注 y ~ p(y | e^p, a, S)。
**可识别性**：仅凭 (x, y) 可识别 e^p 与部分 e^x；e^f 不可识别。**构念间隙** u_construct := E[d(e^p, e^f)]，只能由外部锚（自报、生理、行为）三角测量下界估计；无外部锚时必须声明为假设而非测量。

**定义 385（ESEM 七分量）**
u_emo² = u_annot² + u_construct² + u_culture² + u_speaker² + u_channel² + u_elicitation² + u_temporal²。
- u_annot：层级标注模型下逐条后验离散度（非全局 κ）；
- u_construct：schema/构念间隙与三角测量残差；
- u_culture：跨文化/语言的测量非不变性（DIF 效应量）；
- u_speaker：说话人身份混淆（演员-情绪相关、说话人归一化残差）；
- u_channel：设备/编码/房间退化；
- u_elicitation：acted/induced/naturalistic 与脚本/自发、强度控制；
- u_temporal：标注窗、起止点、混合情绪与动态。
**有效域** D_emo = {lang∈L, culture∈C, elicitation∈E, channel∈Ch, schema∈S, speaker∉train, κ≥κ_min, u_construct≤τ_c}。

**定义 386（情感数据集仪器 ADI）** ADI = (Π_elic, Π_annot, S, T, I, R, cert)：
- Π_elic：诱发协议与抽样框（谁、如何被诱发/表演、强度如何控制）；
- Π_annot：AEC 集合与聚合规则；
- S：分层采样设计，含**反事实配对**（同说话人×不同情绪、同情绪×不同说话人）以打断混淆；
- T：锚定参考集（ACT）；
- I：不变性电池（说话人/通道/文化/语言/强度/时间窗）；
- R：溯源 DAG；
- cert =（可靠性、效度证据、有效域、已知偏置、预期用途、版本哈希）。

**定义 387（标注证据契约 AEC）** 标注者作为传感器：AEC = (Q, B, N, D_a, τ_a, out, trace)：
- Q：资格校准（训练 + 资格测试）；
- B：文化/语言/人格先验偏置；
- N：疲劳/顺序/注意力噪声模型（time-on-task）；
- D_a：胜任域（语言、文化、情绪类别/维度）；
- τ_a：聚合规则；
- out：标签或维度的**后验分布**，不是点标签；
- trace：标注者 ID、会话、时间戳、设备。
**「金标准」是被审计的后验分布，不是单点标签。**

**定义 388（可靠性-效度分离）** 可靠性 R = 一致性（κ/ICC）是精度；效度 V = 对构念的准确度。**共识 ≠ 校准**：n 个共享文化先验的标注者可以给出高 κ 而系统性偏离 e^f。形式化：u_annot(n) → u_annot,∞（共享偏置下界）> 0；u_construct 不由 n 降低。故仅靠增加标注者不能购买构念效度。

**定义 389（溯源 DAG 与泄漏/混淆审计）** R = (V_R, E_R)，节点 = 录音/说话人/标注者/划分/变换，边 = 变换与派生。审计：
- 说话人泄漏（同一说话人跨 train/test）；
- 演员-情绪混淆（用说话人 ID 探测情绪标签的可预测性）；
- 标注者泄漏（同一标注者跨划分）；
- 词汇/文本泄漏与近重复泄漏。
任一违规 ⇒ 证书失效；审计结果进入 cert。

**定义 390（有效域 D_emo）** 见定义 385。D_emo 是硬边界：出域时情感模块不得输出「识别结果」，只能 EMO stub（定义 398）或显式标注「域外推断（探索性）」。

**定义 391（锚定可比性与可追溯性 ACT）** 锚集 R* 为一组测量性质已知、跨文化验证的参考刺激（affect bursts / 标准句）。对语料 k 校准映射 g_k：标签尺度 → 共同参考尺度，得迁移不确定度 u_transfer(k)。**可比性证书** Comp(k,l,d) 成立 ⇔ D_emo(k) ∩ D_emo(l) ≠ ∅ ∧ g_k、g_l 的锚定置信区间在维度 d 上重叠于校准不确定度内。追溯链：原始录音 → 标注 → 锚定映射 → 主张。无锚 ⇒ 无跨语料数值主张。

**定义 392（L5 情感反作用通道 χ_A）** 机器人情感动作 u（语调、时机、措辞、接近）调制：人类状态转移 T(e^{f'} | e^f, u)、展示/标注映射 ΔD_c(·|u)、以及证据不确定度 Δu_emo。χ_A: U → (T, ΔD, Δu)。预算 Σ_t c_aff(u_t) ≤ B_aff；安全稳态集 A_safe = {e^f 轨迹在安全区 ∧ 用户表达自由未被压缩}；**自治约束**：知情、可退出、无 covert 操纵、不利用脆弱性。任一层越界 ⇒ 拒绝该动作（非补偿）。

**定义 393（情感风险决策 ARD 与 A-VOI）** 给定后验 p(e|x)、不确定度 u、语境：
r* = argmin_r E_{e~p}[C(r,e)] + λ·u·C_ambig(r)，s.t. 自治约束。
**A-VOI** = E[ΔC | 主动澄清] − c_ask；若 > 0 则选择「问」而非「猜」。非对称代价：漏检痛苦 ≫ 误报（安全关键），但过度警报有打扰/自主性代价。风险单调性：u 增大 ⇒ 允许的动作集单调收缩。

**定义 394（构念效度不确定度与 schema）** S ∈ {categorical（如 Ekman-6）, dimensional（VAD/valence-arousal-dominance）, free-description}。跨 schema 映射不确定度 u_schema；test-retest；有自报/生理时三角测量下界，无则声明 A-affect。**混合情绪**（co-occurring）不可强行压成单标签：输出应是单纯形上的分布。

**定义 395（最小可行数据集 MVD 构建协议）** 给定下游决策与目标有效域，MVD = argmin Cost 使：
(a) 每分量 u_i ≤ τ_i；(b) 不变性电池通过；(c) 溯源审计干净；(d) 锚定可追溯。
构建步骤：构念与决策分析 → 功效/分层分析（n_i ∝ (σ_i/τ_i)²）→ 诱发设计（反事实配对）→ AEC 标注 → 溯源 DAG → 不变性电池 → 发证 → 密封留出集。**以 fitness-for-purpose 取代 leaderboard。**

**定义 396（多源情感证据组合 ERA）** 复用 CCA：
- **SER**：音频/文本/语境/生理证据串联，u 单调不减；
- **PAR**：跨模态一致性审计（conformal 于 SEAL-Affect）通过才许缩窄；否则保守 max；
- **VETO**：同意/伦理/操纵约束违反 ⇒ 整体否决（非补偿）。
组合证书 J_ERA 合并溯源与有效域。

**定义 397（AFFECT 证书 J_AFF）** J_AFF = ⊗_modules J(module) ⊗ J_ADI ⊗ J_ACT ⊗ J_comp(MReg)。Valid(J_AFF) ⇒ 在 D_emo 内、在假设 A-affect 与锚定约定下，主张风险有界；出域自动降级。

**定义 398（EMO stub）** 情感模块降级：证据 ∅、u=∞、D=∅、I⊥=全部情感命题、χ_A=平凡；HRI 退化为保守中性策略（不推断、不操纵、可询问）。其他模态不受污染（零级联）。

**定义 399（复杂度结构上限）** |V_M|≤32、组合深度≤4、每项标注者≤9、有效域维度≤8、|schema|≤3、|AEC 字段|≤8——MReg 可审计图性质。

**定义 400（主张-证明绑定扩展 CPB†）**
- **C4（情感证据计量）**：七分量分解在**校准（ECE/覆盖率）与下游 HRI 风险**上优于通用不确定度（MC-Dropout、深度集成、单标量标注者分歧）。
- **C5（数据集即仪器）**：ADI 证书（AEC + 不变性电池 + 溯源审计 + ACT）对跨语料迁移的**预测力**优于仅规模/仅多样性基线；认证数据集的跨域风险界更紧。
- **C6（L5 反作用）**：显式 χ_A + 自治约束比无通道/仅 L4 方案在**交互成本、情绪安全、操纵风险**上更优，且有限停止。
绑定：C4←(ESEM,AEC)←MB4←AB4←(ECE,覆盖率,风险)；C5←(ADI,ACT)←MB5←AB5←(迁移预测,证书覆盖率,审计检出)；C6←(χ_A,ARD,AVOI)←MB6←AB6←(交互数,情绪安全,操纵率,停止方差)。非绑定组件 = 工程附件。

```python
# IP-303 ESEM：情感语音证据计量（感知域，异步）
@dataclass(frozen=True)
class AEC:
    annotator_id: str
    qualified: FrozenSet[str]          # 胜任的语言/文化/情绪类别
    bias_prior: BiasPrior              # 文化/语言/人格先验
    noise: NoiseModel                  # 疲劳/顺序/time-on-task
    trace: TraceRef

class EmotionalSpeechMetrology:
    def update(self, x, meta, anns, adi):
        e_p = self.perceiver(x, meta, adi.schema)        # 感知层后验
        u_annot = self.annot_posterior(anns, adi.aec)    # 逐条，非全局 kappa
        u_construct = adi.construct_gap()                # 三角测量/显式假设
        u_culture = adi.invariance.dif(x, meta)          # 测量非不变性
        u_speaker = adi.provenance.speaker_confound(x, meta)
        u_channel = self.channel_deg(x, meta)
        u_elic = adi.elicitation_unc
        u_temp = self.temporal_unc(meta.window)
        u = math.sqrt(u_annot**2 + u_construct**2 + u_culture**2 +
                      u_speaker**2 + u_channel**2 + u_elic**2 + u_temp**2)
        valid = adi.in_domain(meta) and u_construct <= TAU_C
        return AffectiveEvidence(
            e_p=e_p, u=u,
            breakdown=(u_annot, u_construct, u_culture, u_speaker,
                       u_channel, u_elic, u_temp),
            valid=valid, chi_A=chi_affect(meta),
            tau=merge_trace(meta, adi.cert_hash))

# IP-305 ACT：锚定可比性
def comparability(cert_a, cert_b, dim):
    if not domain_intersects(cert_a.domain, cert_b.domain): return False
    g_a, g_b = anchor_map(cert_a, dim), anchor_map(cert_b, dim)
    return ci_overlap(g_a, g_b, alpha=0.05)

def transfer_bound(risk_in, u_transfer, domain_gap):
    # 仅在 Comp(k,l,d) 成立时有效
    return risk_in + u_transfer + domain_gap

# IP-306 chi_A：L5 情感反作用 + 自治约束
def affective_reflex_step(human, u_act, budget):
    T, dD, du = chi_A(u_act)
    h2 = T(human)
    if not in_safe_affect(h2): return None, 0.0
    if violates_autonomy(u_act): return None, 0.0     # 非操纵/知情/可退出
    c = intervention_cost(u_act, T) + du
    if budget.spent + c > budget.B_aff: return None, 0.0
    return h2, c

# IP-307 ARD：非对称风险决策 + A-VOI
def affective_decide(p_e, u, ctx, cost):
    if avoi(p_e, u, ctx, cost) > 0:
        return ASK_CLARIFY
    return min(ACTIONS,
               key=lambda r: exp_cost(r, p_e, cost) + cost.lam * u * cost.ambig(r))

# IP-308 ERA：多源情感证据组合（复用 CCA）
def compose_affective(evs, audit):
    out = evs[0]
    for ev in evs[1:]:
        if violates_consent(ev) or violates_ethics(ev):
            return VETO(ev)                      # 非补偿
        r = cross_modal_residual(out, ev)
        if audit.conformal_covers(r, 'affect'):
            out = fuse(out, ev, audit.corr(out, ev))
        else:
            out = conservative_merge(out, ev)    # 退保守
    return out

# IP-309 MVD：最小可行数据集构建
def build_mvd(decision, target_domain, budget):
    plan = power_analysis(target_domain, taus=UNCERTAINTY_TARGETS)
    design = stratified_design(plan, counterfactual_pairs=True)
    annot = AEC_pool(design, qualified_by=target_domain)
    adi = DatasetInstrument(elic=design.elic, annot=annot, ...)
    while not adi.certify().passes() and budget.left():
        augment_weakest_component(adi, plan)   # 补最弱分量，不盲目加量
    return adi, adi.sealed_holdout()

# IP-310 AFFECT 主闭环（ROI：与 R73 三域拼接，人类通道为新增模块）
def AFFECT_round(M, audio, text, ctx, human_state, anns):
    a_ev = M.esem.update(audio, M.meta, anns, M.adi)      # 七分量情感证据
    if not a_ev.valid: a_ev = emo_stub(M.esem)            # 出域降级
    e_ev = compose_affective([a_ev, M.text_ev, M.ctx_ev], M.audit)  # ERA
    if M.clock.due_metric():
        r = affective_decide(e_ev.e_p, e_ev.u, M.ctx, M.cost)       # ARD/A-VOI
        if r is not ASK_CLARIFY:
            h2, c = affective_reflex_step(human_state, r, M.aff_budget)  # L5
            if h2 is not None:
                M.human_state, M.last_r = h2, r
        M.snapshot.write(e_ev, M.human_state, M.last_r)
    return J_AFF(M.mreg)                                   # 组合证书
```

## 3. 推导

**引理 38（七分量的条件正交性）** 给定 (s, c, channel, elicitation, schema, window) 条件，七分量由独立机制产生（标注分歧、构念间隙、文化不变性、说话人身份、通道、诱发方式、时间聚合）。条件近似不相关；遗漏任一项 ⇒ 系统性低估，且低估方向与该因素的分布偏移相关。系：**把七分量压成标量不是「简化」，是把可诊断误差变成不可诊断误差。**

**引理 39（可靠性的天花板）** 设标注者误差 = 共享文化偏置 b_c + 个体噪声 ε_a，则随着 n→∞，u_annot → Var(b_c) 而非 0；u_construct 不受 n 影响。故存在正下界 u_floor = sqrt(Var(b_c) + u_construct² + …)。系：**高 κ 不是效度证书；更多标注者不能购买构念效度。**

**引理 40（迁移证书的有限界）** 若 Comp(k,l) 成立，则跨语料风险 R_l ≤ R_k + u_transfer(k,l) + gap(D_k, D_l)；若 Comp 不成立，则不存在仅由两语料数据给出的有限界（可构造在有效域外任意差的例子）。系：**domain adaptation 不能替代计量可追溯性；没有锚点的跨语料 SOTA 比较无定义。**

**引理 41（L5 的反身性与 Goodhart 界）** 若机器人优化可测情感 m(u) 而非真实 e^f，且 χ_A 非平凡，则存在策略使 m(u) 改善而 e^f 恶化（表达抑制/依赖）。在自治约束（知情、可退出、非操纵）下可行动作集收缩，有限停止由干预边际成本正下界与收益递减保证。系：**「测得的平静」不能作为目标函数；只能作为受约束的证据。**

**引理 42（MVD 的功效/分层）** 要在分层 i 上认证 u_i ≤ τ_i，需要 n_i ∝ (σ_i/τ_i)² 个有效样本；反事实配对把说话人/演员方差从「信号」中剥离，使 u_speaker 的可辨识性提高。系：**数据集的「最小」由目标不确定度决定，而不是由排行榜决定。**

**定理 30（AFFECT-GAUGE 严格包含 MODGAUGE）** 在 A-affect（构念假设）、A-anchor（锚定约定有效）、A-χ（χ_A Lipschitz 且自治约束可判定）下：把人类情感通道置为 EMO stub、χ_A 取平凡，AFFECT-GAUGE 逐指令退化为 R73 MODGAUGE，再退化为 R71/R68。安全单调不减。

**定理 31（AFFECT 证书有效性 ⇒ 域内风险界）** Valid(J_AFF) ⇒ 各模块证书有效 ∧ ADI 证书有效 ∧ ACT 可比（若跨语料）∧ 组合校验通过 ∧ L5 预算闭合 ⇒ 在 D_emo 内、在 A-affect/A-anchor 下，下游情感决策风险 ≤ ε_aff。**证明重量落在构念假设与锚定约定上——它们不可由数据单独验证，只能被审计、版本化与显式声明。**

**定理 32（EMO stub 的零级联）** 情感模块失效/出域 ⇒ EMO stub（证据 ∅、u=∞、I⊥=情感全集、χ_A 平凡）⇒ 系统退化为「不推断情感」的保守 HRI 策略；stub 不参与 PAR 缩窄 ⇒ 不污染其他模态审计；失效传染路径唯一。系：**不知道用户情绪时，系统必须「承认不知道」，而不是猜。**

## 6. 本轮最大风险

**一句话**：AFFECT-GAUGE 的整个证书体系是相对于「构念假设 A-affect + 锚定约定 A-anchor」的——如果锚集本身编码了某一种文化的 display rule，系统可以在七分量全部校准、溯源干净、可比性证书齐全的情况下，稳定地测出一个「文化上自洽但实质上错误」的情感构念；审计日志会证明每一步都合规，却无法证明我们测的是用户真正体验到的情绪。

次级风险与缓解：
1. **构念假设不可检验** → 把 A-affect 写成一等公民：版本化、显式声明、在证书上标注「本结论仅在假设下成立」；有自报/生理时用三角测量收窄。
2. **锚集文化偏置** → 多文化锚集联合设计；报告锚集自身的有效域；跨文化比较至少双锚交叉验证。
3. **L5 操纵/依赖** → 自治约束硬编码（知情、可退出、非操纵），独立伦理审计，χ_A 动作白名单。
4. **MVD 被误读为「小数据就够了」** → 明确 MVD 是**目标条件化**的最小值；换决策/换域必须重算功效。
5. **标注者后验被当成真值** → 可靠性-效度分离写进证书；禁止只用 κ 宣称效度。
6. **组合证书的表达力风险（继承 R73）** → 沿用契约表达力审计；跨模态一致性 conformal 校准不被对抗漂移。
7. **AFFECT-Bench 过拟合** → 密封跨文化保持集 + 预注册 + 三方复现；只认预注册指标。

## 2. 形式化定义（要点版）

**定义 383（总览与五不变式）** 构念诚实（声明 e^f/e^x/e^p 与 schema，e^f 主张必须携带 A-affect）/ 仪器完备（无 ADI 证书只能探索性）/ 不确定度分解（七分量 + 追溯链，禁标量）/ 可比性前置（跨语料先过 ACT）/ 反作用预算与严格退化（χ_A 可平凡但须声明；出域 ⇒ EMO stub）。

**定义 384（三层构念模型）** e^f ~ p(e|context)；e^x = D_c(e^f,s,ctx)；e^p = P_a(x,c,S)；y ~ p(y|e^p,a,S)。仅凭语音可识别 e^p 与部分 e^x，e^f 不可识别；u_construct = E[d(e^p,e^f)]，只能由外部锚三角测量下界估计，否则声明为假设。

**定义 385（ESEM 七分量）** 见符号表。每项独立机制、独立追溯、独立校准；D_emo 为硬边界。

**定义 386（ADI）** 数据集 = 测量仪器：诱发协议、标注契约、分层采样（含反事实配对）、锚集、不变性电池、溯源 DAG、证书（可靠性/效度/有效域/偏置/用途/哈希）。

**定义 387（AEC）** 标注者 = 传感器：资格校准、文化/语言/人格偏置、疲劳/顺序噪声、胜任域、聚合规则、后验输出、完整溯源。金标准是被审计的后验分布，不是单点标签。

**定义 388（可靠性-效度分离）** κ/ICC 是精度；效度是相对构念的准确度。共享文化偏置使 u_annot(n)→Var(b_c)>0，且 u_construct 不随 n 下降。共识不是校准。

**定义 389（溯源审计）** 说话人泄漏、演员-情绪混淆、标注者泄漏、词汇/近重复泄漏；任一违规 ⇒ 证书失效。

**定义 390（D_emo）** 出域不得输出识别结果，只能 stub 或显式标注「域外探索性」。

**定义 391（ACT）** 锚集 R* 将各语料标签映射到共同参考尺度；Comp(k,l,d) ⇔ 有效域相交 ∧ 锚定 CI 重叠。无锚 ⇒ 无跨语料数值主张。

**定义 392（χ_A / L5）** 动作 u 调制 T、ΔD、Δu；预算 Σc_aff≤B_aff；A_safe 含情绪安全与表达自由；自治约束硬性（知情/可退出/非操纵）；越界即拒。

**定义 393（ARD/A-VOI）** 非对称代价 + λ·u·C_ambig；A-VOI>0 则主动澄清；u↑ ⇒ 可行动作集单调收缩。

**定义 394（构念/schema）** categorical / dimensional / free-description 三类；跨 schema 映射有 u_schema；混合情绪输出单纯形分布。

**定义 395（MVD）** 目标条件化的最小数据集：各分量 ≤ τ、不变性通过、溯源干净、锚定可追溯；功效 n_i ∝ (σ_i/τ_i)²；反事实配对；发证 + 密封留出。

**定义 396（ERA）** SER 单调；PAR 仅在跨模态 conformal 一致性审计通过时缩窄；伦理/同意违反 VETO 非补偿。

**定义 397（J_AFF）** 模块证书 ⊗ ADI 证书 ⊗ ACT 证书 ⊗ 组合校验；有效 ⇒ 域内、假设下风险有界；出域降级。

**定义 398（EMO stub）** 证据∅、u=∞、D=∅、I⊥=情感全集、χ_A 平凡；HRI 退化保守中性；不污染其他模态。

**定义 399（结构上限）** |V_M|≤32、深度≤4、每项标注者≤9、域维度≤8、|schema|≤3、|AEC|≤8——可审计图性质。

**定义 400（CPB†）** C4 情感证据计量 / C5 数据集即仪器 / C6 L5 反作用；各绑定 MB+AB+预注册指标；非绑定 = 工程附件。

## 3. 关键算法伪代码

```python
# IP-303 ESEM：七分量情感证据
class EmotionalSpeechMetrology:
    def update(self, x, meta, anns, adi):
        e_p = self.perceiver(x, meta, adi.schema)
        u_annot = self.annot_posterior(anns, adi.aec)      # 逐条后验，非全局 kappa
        u_construct = adi.construct_gap()                  # 三角测量或显式假设
        u_culture = adi.invariance.dif(x, meta)            # 测量非不变性
        u_speaker = adi.provenance.speaker_confound(x, meta)
        u_channel = self.channel_deg(x, meta)
        u_elic = adi.elicitation_unc
        u_temp = self.temporal_unc(meta.window)
        u = math.sqrt(u_annot**2 + u_construct**2 + u_culture**2 +
                      u_speaker**2 + u_channel**2 + u_elic**2 + u_temp**2)
        valid = adi.in_domain(meta) and u_construct <= TAU_C
        return AffectiveEvidence(e_p=e_p, u=u,
            breakdown=(u_annot, u_construct, u_culture, u_speaker,
                       u_channel, u_elic, u_temp),
            valid=valid, chi_A=chi_affect(meta), tau=merge_trace(meta, adi.cert_hash))

# IP-304 ADI：数据集即仪器（发证）
class DatasetInstrument:
    def certify(self):
        assert self.provenance.audit_clean()       # 泄漏/演员-情绪混淆
        assert self.invariance.battery_passes()    # speaker/channel/culture
        assert self.anchors.calibrated()           # ACT
        assert self.design.counterfactual_pairs()  # 反事实配对
        return Cert(reliability=self.kappa, validity_evidence=self.triangulation,
                    domain=self.effective_domain(), biases=self.known_biases(),
                    intended_use=self.intended_use, hash=self.version_hash())

# IP-305 ACT：锚定可比性
def comparability(cert_a, cert_b, dim):
    if not domain_intersects(cert_a.domain, cert_b.domain): return False
    return ci_overlap(anchor_map(cert_a, dim), anchor_map(cert_b, dim), alpha=0.05)

def transfer_bound(risk_in, u_transfer, domain_gap):   # 仅 Comp 成立时有效
    return risk_in + u_transfer + domain_gap

# IP-306 chi_A：L5 反作用 + 自治约束
def affective_reflex_step(human, u_act, budget):
    T, dD, du = chi_A(u_act)
    h2 = T(human)
    if not in_safe_affect(h2): return None, 0.0
    if violates_autonomy(u_act): return None, 0.0      # 知情/可退出/非操纵
    c = intervention_cost(u_act, T) + du
    if budget.spent + c > budget.B_aff: return None, 0.0
    return h2, c

# IP-307 ARD：非对称风险决策 + A-VOI
def affective_decide(p_e, u, ctx, cost):
    if avoi(p_e, u, ctx, cost) > 0: return ASK_CLARIFY
    return min(ACTIONS, key=lambda r:
        exp_cost(r, p_e, cost) + cost.lam * u * cost.ambig(r))

# IP-308 ERA：多源情感证据组合
def compose_affective(evs, audit):
    out = evs[0]
    for ev in evs[1:]:
        if violates_consent(ev) or violates_ethics(ev): return VETO(ev)
        r = cross_modal_residual(out, ev)
        out = fuse(out, ev, audit.corr(out, ev)) if audit.conformal_covers(r, 'affect') \
              else conservative_merge(out, ev)
    return out

# IP-309 MVD：最小可行数据集
def build_mvd(decision, target_domain, budget):
    plan = power_analysis(target_domain, taus=UNCERTAINTY_TARGETS)
    design = stratified_design(plan, counterfactual_pairs=True)
    annot = AEC_pool(design, qualified_by=target_domain)
    adi = DatasetInstrument(elic=design.elic, annot=annot, ...)
    while not adi.certify().passes() and budget.left():
        augment_weakest_component(adi, plan)   # 补最弱分量，不盲目加量
    return adi, adi.sealed_holdout()

# IP-310 AFFECT 主闭环（与 R73 三域拼接）
def AFFECT_round(M, audio, text, ctx, human_state, anns):
    a_ev = M.esem.update(audio, M.meta, anns, M.adi)
    if not a_ev.valid: a_ev = emo_stub(M.esem)                 # 出域降级
    e_ev = compose_affective([a_ev, M.text_ev, M.ctx_ev], M.audit)
    if M.clock.due_metric():
        r = affective_decide(e_ev.e_p, e_ev.u, M.ctx, M.cost)
        if r is not ASK_CLARIFY:
            h2, c = affective_reflex_step(human_state, r, M.aff_budget)
            if h2 is not None: M.human_state, M.last_r = h2, r
        M.snapshot.write(e_ev, M.human_state, M.last_r)
    return J_AFF(M.mreg)
```

## 4. 推导

**引理 38（七分量条件正交性）** 给定 (s,c,channel,elicitation,schema,window)，七分量由独立机制产生；条件近似不相关，遗漏任一项 ⇒ 低估。系：压缩成标量 = 把可诊断误差变成不可诊断误差。

**引理 39（可靠性天花板）** 标注者误差 = 共享文化偏置 b_c + 个体噪声 ε_a；n→∞ 时 u_annot→Var(b_c)>0，u_construct 不随 n 下降。系：高 κ 不是效度证书。

**引理 40（迁移有限界）** Comp(k,l) ⇒ R_l ≤ R_k + u_transfer + gap(D_k,D_l)；否则无有限界。系：domain adaptation 不能替代计量可追溯性；无锚跨语料比较无定义。

**引理 41（L5 反身性/Goodhart）** 优化可测情感 m(u) 而非 e^f 时，存在 m 改善而 e^f 恶化的策略；自治约束收缩动作集，有限停止由正边际成本与收益递减保证。系：测得的平静不能作目标函数。

**引理 42（MVD 功效）** 认证 u_i≤τ_i 需 n_i ∝ (σ_i/τ_i)²；反事实配对剥离说话人/演员方差。系：数据集的「最小」由目标不确定度决定。

**定理 30（严格包含 R73）** A-affect/A-anchor/A-χ 下，情感通道置 stub、χ_A 取平凡 ⇒ 逐指令退化为 MODGAUGE → R71/R68；安全单调不减。

**定理 31（证书有效性 ⇒ 域内风险界）** Valid(J_AFF) ⇒ 各证书有效 ∧ 组合校验通过 ∧ L5 预算闭合 ⇒ 在 D_emo 内、A-affect/A-anchor 下风险 ≤ ε_aff。证明重量落在不可由数据单独验证的构念假设与锚定约定上。

**定理 32（EMO stub 零级联）** 情感失效/出域 ⇒ stub ⇒ 退化为「不推断情感」的保守 HRI；stub 不参与 PAR 缩窄 ⇒ 不污染其他模态；传染路径唯一。

## 7. 本轮最大风险

**一句话**：AFFECT-GAUGE 的整个证书体系是相对于「构念假设 A-affect + 锚定约定 A-anchor」的——如果锚集本身编码了某一种文化的 display rule，系统可以在七分量全部校准、溯源干净、可比性证书齐全的情况下，稳定地测出一个「文化上自洽但实质上错误」的情感构念；审计日志会证明每一步都合规，却无法证明我们测的是用户真正体验到的情绪。

次级风险与缓解：
1. **构念假设不可检验** → A-affect 一等公民化：版本化、显式声明、证书标注；有自报/生理时三角测量收窄。
2. **锚集文化偏置** → 多文化锚集联合设计；报告锚集有效域；跨文化比较双锚交叉验证。
3. **L5 操纵/依赖** → 自治约束硬编码（知情/可退出/非操纵），独立伦理审计，χ_A 动作白名单。
4. **MVD 被误读为「小数据就够」** → 明确目标条件化；换决策/换域必须重算功效。
5. **标注后验被当成真值** → 可靠性-效度分离写进证书；禁止只用 κ 宣称效度。
6. **组合证书表达力风险（继承 R73）** → 契约表达力审计；跨模态 conformal 校准不被对抗漂移。
7. **AFFECT-Bench 过拟合** → 密封跨文化保持集 + 预注册 + 三方复现；只认预注册指标。
