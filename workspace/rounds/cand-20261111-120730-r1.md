# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「柔顺控制」×「面部表情识别」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S、组合图 G_S 与云边联合证书 J。本轮引入两个看似遥远的概念：**柔顺控制（compliant control）** 与 **面部表情识别（facial expression recognition）**。核心矛盾：H22：柔顺控制的刚度/阻尼是**连续、力安全相关**的控制量，而面部表情是**噪声大、延迟、文化相关**的人类状态观测，直接把表情映射成阻抗参数会形成一条不可审计的隐秘反馈回路；H23：第 54 轮的 ρ 只度量任务成功率，不度量“人的舒适/被动安全”，一个技能可以很鲁棒却很“粗暴”。

## 0. 直觉与动机

**灵感 1（柔顺 = 动作空间里的“软维度”）**
直觉：动作不只是一个位姿 `a`，还带一组阻抗参数 `θ=(K,D,M)`。技能的动作占用应从 `α_S(a)` 扩展为 `α_S(a,θ)`。于是硬动作空间之外多出一个**可连续调节的软维度**：组合时要问两次——“动作能不能做”以及“用多硬的姿态做”。这把第 54 轮的动作剖面补全为**动作×阻抗**的二维剖面。

**灵感 2（表情不是标签，而是带校准的不确定性证据）**
直觉：FER 的 one-hot 输出不可信。应把它升级为对潜在情感状态 `z` 的信念 `b_t(z)`，并用 conformal prediction 给出覆盖集 `C_α(f_t)` 与校准误差。只有当证据“足够可信”时才允许驱动控制；否则退回保守默认阻抗。**表情是传感器，不是真理。**

**灵感 3（表情只能“踩刹车”，不能“踩油门”）→ 单侧单调性**
直觉（本轮最关键的安全设计）：情感推断只允许使阻抗包络**收缩**（变软、限力、增阻尼），绝不能因“看起来很开心”而放宽安全边界。即 `p_dis` 上升 ⇒ `E(b)` 单调收缩，且 `E(b)⊆E_0`（基线安全包络）。这样即使表情完全误判，最坏后果也是任务变慢/失败，而不是力伤害。**安全性与 FER 精度被结构性解耦。**

**灵感 4（柔顺切换必须保无源）**
直觉：刚度/阻尼在线切换会注入或耗散能量。用 **能量罐（energy tank）** 与 bumpless transfer 保证切换过程无源，避免“越调越抖”。这为第 54 轮的 `δ_a` 增加一个能量维度的守卫。

**灵感 5（反向情感解释 ARE）**
直觉：检测到不适时，Explain 应定位是**哪个接触相位 / 哪个阻抗参数 / 哪段技能**导致的，并回传云端触发重规划。与第 54 轮的 `Explain_loop` 合流，形成“表情异常 → 反向解释 → 阻抗重剖分 → 云端重规划”的闭环。

**灵感 6（金字塔加一层 ℂ）**
直觉：在 𝕃（鲁棒）与 𝔸（动作）之上叠加 **ℂ 情感-柔顺层**：`ℂ_0` 硬件力上限，`ℂ_1` 技能阻抗剖面，`ℂ_2` 情感条件包络，`ℂ_3` 人机交互契约。跨层证书从“动作-鲁棒”双证书升级为 **`(ρ, A_cert, Affect_cert)` 三证书**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（情感信念与可信证据）**
潜在情感状态 `z∈Z={comfort, neutral, discomfort, pain}`，表情观测 `f_t`（embedding）与上下文 `c_t`。信念 `b_t(z)=P(z|f_{1:t},c_t)`。用 split conformal 得覆盖集 `C_α(f_t)`，满足 `P(z*∈C_α)≥1-α`。定义可信度 `trust(b_t)=1-H(b_t)/log|Z|` 与校准误差 `ECE≤ε_cal`。仅当 `|C_α(f_t)|=1` 且 `trust(b_t)≥θ_trust` 时称 **可信情感证据**，记 `trusted(b_t)=1`。

**定义 122（柔顺动作流形）**
阻抗参数 `θ=(K,D,M)∈Θ⊂(R^{3×3}_{≻0})^3`。技能 `S` 的柔顺剖面 `α_S:A×Θ→[0,1]`，`∫_{A×Θ} α_S = vol(S)`。无源性要求能量罐 `E_tank(t)≥0`，且 `dE_tank/dt = P_in - P_out`。

**定义 123（情感条件阻抗包络）**
`E(b_t) = { θ∈Θ | K⪯K_max(b_t), D⪰D_min(b_t), F_max(b_t)≤F_safe, E_tank≥0 }`，
其中 `K_max(b)=K_0·exp(-λ·p_dis(b))`，`F_max(b)=F_0·(1-μ·p_dis(b))`，`p_dis(b)=b(discomfort)+b(pain)`。
**单侧单调性**：若 `p_dis(b_t) ≥ p_dis(b'_t)`，则 `E(b_t)⊆E(b'_t)`，且恒有 `E(b)⊆E_0:=E(comfort)`。即包络只会因“更不适”而收缩，永不因“更舒适”而突破基线。

**定义 124（情感-柔顺时域证书）**
`C_aff=(τ_aff, TV(θ), h, N_sw, P_pass)`：`τ_aff` 为表情到控制的端到端延迟，`TV(θ)` 为阻抗轨迹总变差，`h` 为迟滞带，`N_sw` 为切换次数，`P_pass` 为无源裕度。**稳定条件**：`TV(θ)≤B_TV ∧ τ_aff≤τ_max ∧ N_sw≤N_max ∧ P_pass≥0`。

**定义 125（情感-柔顺技能兼容性）**
`compat_AC(S_i,S_j)=compat(S_i,S_j)·J(E_i,E_j)`，`J` 为两包络 Jaccard。组合可判定还需：
```
∃θ∈E_i(b)∩E_j(b) ∧ (TV_i+TV_j+TV_switch)≤B_TV ∧ P_pass≥0
```
即第 54 轮 `G_S` 的边要同时通过动作兼容、包络相交与切换能量预算三重检查。

**定义 126（情感-柔顺联合三证书）**
`J_AC=(ρ, A_cert, γ_ce, b_t, E(b_t), C_aff, δ_aff, evidence)`。部署判定：
```
dom_J(T)=in ∧ (∀d: ρ(d)≥ρ_min) ∧ A_core⊆A_T ∧ E(b_t)∩E_plan≠∅
            ∧ C_aff 稳定 ∧ δ_aff≤Θ_aff
```
其中 `evidence` 至少包含 conformal 覆盖记录、能量罐日志与边端接触力反例。

## 2. 关键算法 伪代码

### IP-121 ABI（Affective Belief Inference，校准情感信念）

```python
def affective_belief(fer_model, frames, context, calib):
    f = fer_model.embed(frames[-k:])              # 时序表情 embedding
    logits = fer_model.head(f, context)
    b = softmax(temperature_scale(logits, calib.T))
    C = conformal_set(b, calib.qhat, alpha=0.1)   # 覆盖集
    trust = 1.0 - entropy(b) / log(len(Z))
    return b, C, trust, (len(C) == 1 and trust >= THETA_TRUST)
```

### IP-122 ACIE（Affect-Conditioned Impedance Envelope）

```python
def impedance_envelope(b, theta_0, lambda_, mu):
    p_dis = b['discomfort'] + b['pain']
    K_max = theta_0.K * exp(-lambda_ * p_dis)     # 只收缩
    F_max = theta_0.F * (1 - mu * p_dis)
    D_min = theta_0.D * (1 + lambda_ * p_dis)     # 更不适 -> 更阻尼
    E = {theta for theta in Theta
         if theta.K <= K_max and theta.D >= D_min
         and contact_force_upper(theta) <= min(F_max, F_safe)
         and energy_tank_ok(theta)}
    return E                                  # 恒有 E ⊆ E_0
```

### IP-123 PPS（Passivity-Preserving Switching）

```python
def passivity_switch(theta_cur, theta_target, tank, dt):
    dE = switching_energy(theta_cur, theta_target)   # 解析估计
    if tank.E - dE < 0:                              # 能量不足
        theta_target = project_to_reachable(theta_target, tank, dE)
    theta_next = bumpless_blend(theta_cur, theta_target, h=H_HYST)
    tank.update(P_in=estimated_power(theta_next), P_out=dE / dt)
    return theta_next, tank
```

### IP-124 ACC（Affective-Compliant Composition）

```python
def build_composition_graph_AC(skills, b, theta_a, tau_e, K):
    G = build_composition_graph(skills, theta_a, tau_e, K)   # IP-116
    for (i, j, data) in list(G.edges(data=True)):
        Ei, Ej = skills[i].envelope(b), skills[j].envelope(b)
        jac = jaccard(Ei, Ej)
        tv = skills[i].TV + skills[j].TV + switch_cost(Ei, Ej)
        if jac <= 0 or tv > B_TV or not intersect_passy(Ei, Ej):
            G.remove_edge(i, j)
        else:
            data['compat_AC'] = data['compat'] * jac
    return G
```

### IP-125 ARE（Affective Reverse Explanation）

```python
def affective_explain(trace, b_t, E, sim_model):
    if b_t.discomfort < THETA_DIS:
        return None
    culprit = argmax_over_phases(trace, key=lambda ph: contact_force(ph) - E.F_max(b_t))
    return ExplainReport(
        phase=culprit.phase,
        impedance=trace.theta[culprit.phase],
        cause='force_above_affective_cap',
        suggestions=sim_model.suggest_softer(culprit, E),
        patch=('reprofile', culprit.skill, E))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ABI | O(k·d + |Z| log |Z|) | O(k·d) | conformal 覆盖 ≥ 1-α、校准 |
| ACIE | O(|Θ|·|Z|) | O(|Θ|) | 单侧单调、包络凸且收缩 |
| PPS | O(1) 每拍 | O(1) | 能量罐非负、切换无源 |
| ACC | O(|S|²·|Θ|) | O(|S|²+|E|) | 包络相交 sound、TV 预算 |
| ARE | O(|phases|·|𝔇|) | O(|phases|) | 根因定位可复现 |

**正确性定理（Affect-Compliant Safety Decoupling）**
假设第 53/54 轮 (A22)–(A28) 成立；新增 **(A29)** `b_t` 经 conformal 校准，`trusted` 判定可复现；**(A30)** 包络满足单侧单调 `E(b)⊆E_0` 且 `E_0` 已通过硬件限力认证；**(A31)** PPS 保证 `E_tank(t)≥0` 且切换能量有界；**(A32)** `τ_aff≤τ_max`、`N_sw≤N_max`。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(δ_aff>Θ_aff) - P(E(b)∩E_plan=∅)
P(contact_force > F_safe) ≤ P(hardware_cap_fail) + P(P_pass<0)
```
关键结论：**接触力安全界不依赖 FER 精度**。误判只会使包络“过度收缩”（任务失败），不会“过度放宽”（力伤害），因为 `E(b)⊆E_0` 由定义 123 结构性保证。

## 6. 本轮最大风险

**一句话**：柔顺控制×面部表情识别的真正威力在于用**单侧单调的情感阻抗包络**把“人的舒适”变成可验证的安全约束，从而让力安全与 FER 精度结构性解耦；但最大风险恰恰是这条“表情→阻抗”的闭环会被误当成可靠的意图通道——一旦团队放松单侧性、允许“舒适表情”扩张包络，或让表情绕过硬件限力，FER 的文化偏差与延迟就会重新变成力伤害与振荡的来源，故必须坚持 **表情只能踩刹车、包络永不越过 E_0、硬件限力独立兜底** 三条不可协商的红线。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim-Affect（ABI×ACIE×PPS×ACC×ARE×TAC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒双证书体系之上，引入 **柔顺控制** 与 **面部表情识别** 两条支线，形成 **情感-柔顺层 ℂ**：
> - **ABI（Affective Belief Inference）**：conformal 校准的表情→情感信念，输出可信证据而非硬标签；
> - **ACIE（Affect-Conditioned Impedance Envelope）**：单侧单调收缩的阻抗包络，表情只能“踩刹车”；
> - **PPS（Passivity-Preserving Switching）**：能量罐 + bumpless transfer 的无源阻抗切换；
> - **ACC（Affective-Compliant Composition）**：把包络相交与切换能量预算并入技能组合图；
> - **ARE（Affective Reverse Explanation）**：从不适反查接触相位/阻抗参数并回传云端；
> - **TAC（Triple Affect-Compliant Certificate）**：`(ρ, A_cert, Affect_cert)` 三证书。

> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入阻抗维度。
> 核心原则：**安全性与表情识别精度结构性解耦**——`E(b)⊆E_0`，误判只会过度柔顺，不会过度激进。

| ABI | O(k·d + |Z| log |Z|) | O(k·d) | conformal 覆盖 ≥ 1-α |

**正确性定理（Affect-Compliant Safety Decoupling）**
假设第 53/54 轮 (A22)–(A28) 成立；新增 **(A29)** `b_t` 经 conformal 校准、`trusted` 可复现；**(A30)** 包络单侧单调 `E(b)⊆E_0` 且 `E_0` 已通过硬件限力认证；**(A31)** PPS 保证 `E_tank(t)≥0` 且切换能量有界；**(A32)** `τ_aff≤τ_max` 且 `N_sw≤N_max`。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(δ_aff>Θ_aff) - P(E(b)∩E_plan=∅)
P(contact_force > F_safe) ≤ P(hardware_cap_fail) + P(P_pass<0)
```
**关键结论**：接触力安全界**不依赖 FER 精度**。误判只使包络过度收缩（任务失败），不可能过度放宽（力伤害），因为 `E(b)⊆E_0` 是定义 123 的结构性约束，且 `F_safe` 由独立硬件限力兜底。

## 5. 本轮最大风险

**一句话**：柔顺控制×面部表情识别的真正威力在于用**单侧单调的情感阻抗包络**把“人的舒适”变成可验证的安全约束，从而让力安全与 FER 精度结构性解耦；但最大风险恰恰是这条“表情→阻抗”的闭环会被误当成可靠的意图通道——一旦团队放松单侧性、允许“舒适表情”扩张包络，或让表情绕过硬件限力，FER 的文化偏差与延迟就会重新变成力伤害与振荡的来源，故必须坚持 **表情只能踩刹车、包络永不越过 E_0、硬件限力独立兜底** 三条不可协商的红线。
