# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「意图识别」×「关节空间控制」）

> 第 54 轮已把技能拆成动作空间剖面 `α_S`、组合图 `G_S`、云边映射 `γ_ce` 与动作-鲁棒性联合证书 `J`。本轮再向下钻一层，引入 **语义意图层 I** 与 **几何关节层 Q**，并显式承认二者不同构。核心矛盾：**H22**：意图识别输出的是语义后验 `β`，其后验置信度高并不意味着该意图在关节空间可执行（可达性、关节限位、奇异位形、力矩饱和）；**H23**：关节空间控制追求几何平滑与安全，但轨迹必须服务于意图——若两层各自优化，就会出现「意图正确但关节不可达」或「关节平滑但语义错位」的系统性断层。

## 0. 直觉与动机

**灵感 1（意图不是标签，而是带几何支撑的后验）**
直觉：意图识别不应只输出单标签 `î`，而应输出后验 `β_t(i|o_{1:t})`；每个意图 `i` 还绑定一个 **关节目标流形** `G_i ⊆ Q`（在关节空间中能实现该意图的位形集合）。于是识别同时回答两个问题：「用户想做什么」与「这个想法在关节空间里落在哪、可不可达、彼此分不分得开」。这把意图识别从纯分类任务变成 **语义-几何联合信念**。

**灵感 2（意图-关节可执行性鸿沟 → 高置信 ≠ 可执行）**
直觉：语义上最可能的意图，可能在关节空间里不可达或需穿越奇异区。定义可执行意图集 `Exec_t` 与可执行性鸿沟 `gap_t(i)`：当 `β_t(i)` 高但 `i ∉ Exec_t`，系统面临「听懂了却做不到」的断层。识别模块必须把 `gap` 上报，而不是把置信度当作可部署性。

**灵感 3（关节空间证书 → 给技能组合加第三约束）**
直觉：第 54 轮组合有 `ρ`（鲁棒）与 `A_cert`（动作占用）两约束，但缺几何可执行性。为轨迹 `τ` 定义关节空间证书 `Q_cert(τ) = (m_lim, m_sing, m_manip, m_torque)`：关节限位裕度、奇异裕度（最小奇异值）、可操作度、力矩裕度。技能组合必须同时满足 `ρ ≥ ρ_min`、`A_cert` 成立、`Q_cert ≥ Θ_Q`，否则只是「动作语义兼容、几何上跳不过去」。

**灵感 4（意图条件化组合 → 期望/极小极大而非最可能）**
直觉：组合规划若只对 `argmax_i β(i)` 优化，会把全部预算押在一个可能不可执行的意图上。正确目标是对 `β` 取 **期望代价**，并提供 **极小极大** 版本：对 `β(i) ≥ θ_β` 的意图都保证关节可行。意图不确定性直接进入目标函数，而不是事后补丁。

**灵感 5（主动消歧 → 用安全的关节探测换取意图熵下降）**
直觉：当 `H(β)` 高且意图在关节空间可分时，可以有意识地执行一个 **安全的探测动作** 降低意图熵：选择信息增益大、且 `Q_cert` 裕度足够的动作。这把「识别」与「控制」统一为一个带安全约束的主动推理问题：`a* = argmax [I(I;O_a|a) - λ_e c(a)]` s.t. `Q_cert(τ_a) ≥ Θ_Q` 且可回退。

**灵感 6（三层金字塔 𝕀 → 𝔸 → ℚ）**
直觉：在第 54 轮动作协同层 `𝔸` 之上叠加 **意图层 `𝕀`**、之下叠加 **关节层 `ℚ`**：`𝕀_0` 观测证据，`𝕀_1` 意图后验，`𝔸_2` 任务动作序列，`ℚ_3` 关节轨迹与证书。跨层证书必须同时携带 `(β, H(β), A_cert, Q_cert, ρ)`，缺一层即不可部署。这形成 **可解释的意图-动作-关节三证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（意图后验与可执行意图集）**
意图集合 `I`，后验递推 `β_t(i|o_{1:t}) ∝ P(o_t|i)·β_{t-1}(i)`，意图熵 `H(β_t) = -Σ_i β_t(i) log β_t(i)`。
每个意图 `i` 绑定关节目标流形 `G_i ⊆ Q` 与可行轨迹族 `Π_i`。可执行意图集
```
Exec_t = { i ∈ I | ∃ τ∈Π_i: τ⊆Q_free ∧ Q_cert(τ) ≥ Θ_Q }
```
可执行性鸿沟 `gap_t(i) = 1[β_t(i) ≥ θ_β ∧ i ∉ Exec_t]`（1 表示「高置信但不可执行」）。
意图可分离性 `sep(i,j) = d_Q(G_i,G_j) / (diam(G_i)+diam(G_j))`，其中 `d_Q(G_i,G_j)=min_{q∈G_i,q'∈G_j}‖q-q'‖`；`sep ≥ θ_sep` 且存在安全探测轨迹时称 `(i,j)` **关节可分**。

**定义 122（关节空间可执行性证书）**
对关节轨迹 `τ:[0,T]→Q`，定义
```
Q_cert(τ) = ( m_lim, m_sing, m_manip, m_torque )
m_lim    = min_t min_j min( q_j(t)-q_j^-, q_j^+ - q_j(t) )
m_sing   = min_t σ_min( J(q_t) )                     # 最小奇异值
m_manip  = min_t sqrt( det( J(q_t)J(q_t)^T ) )        # 可操作度
m_torque = min_t ( τ_max - |τ(t)| )
```
归一化标量 `Q(τ) = min_k (m_k - Θ_k)/(range_k)`；`Q_cert(τ) ≥ Θ_Q` 当且仅当各分量均越过阈值。该证书是 **几何可执行性** 的判据，与语义 `β` 正交。

**定义 123（意图条件化组合目标）**
在组合图 `G_S` 上，给定意图后验 `β`，路径 `π` 的代价
```
cost_β(π) = E_{i~β}[ cost_align(π, G_i) ] + λ_H·H(β) + λ_Q·P_τ( Q(τ)<Θ_Q )
```
鲁棒（极小极大）版本：
```
cost_β^rob(π) = max_{i: β(i) ≥ θ_β} cost_align(π, G_i)
s.t.  ∀i∈supp_θ(β), ∃τ_i⊆π: Q_cert(τ_i) ≥ Θ_Q
```
其中 `cost_align` 复用第 54 轮 IP-119。意图不确定性由此进入优化目标，而非事后过滤。

**定义 124（意图-动作-关节联合证书）**
```
T = ( β, H(β), A_cert, Q_cert, ρ, evidence )
```
其中 `evidence` 至少含意图标定日志、关节轨迹采样、限位/奇异反例。部署判定：
```
deploy(T) = (H(β) ≤ Θ_H ∨ pairwise-separable(supp_θ(β)))
            ∧ (∀i∈supp_θ(β): Q_cert(τ_i) ≥ Θ_Q)
            ∧ A_cert ∧ (ρ ≥ ρ_min)
```
任一不满足则输出 `disambiguate` 或 `reject`，**绝不以高置信度替代几何可行**。

**定义 125（关节空间消歧价值）**
候选探测动作 `a` 对应轨迹 `τ_a`：
```
VoI(a) = I(I; O_a | a) - λ_e·c(a),   s.t. Q_cert(τ_a) ≥ Θ_Q ∧ reversible(a)
a* = argmax_a VoI(a)
```
其中互信息 `I(I;O_a|a)` 用当前后验 `β` 估计。若 `max_a VoI(a) ≤ 0`，主动消歧不再值得，退回保守最小风险策略。

**定义 126（意图-几何断层监控）**
在线断层指标 `G_t = gap_t(argmax_i β_t(i))` 与 `D_t = 1[H(β_t)>Θ_H]`。当 `G_t ∨ D_t` 持续 `κ` 步，触发「重新识别 → 关节重规划 → 必要时探测」的闭环，并把根因（语义歧义 / 关节不可达 / 奇异 / 限位）写入 `evidence`。

## 2. 关键算法 伪代码

### IP-121 IBP（Intent Belief Profiling）

```python
def intent_belief(obs_seq, prior, likelihood, joint_goal_fn):
    beta = prior
    for o in obs_seq:
        beta = normalize({i: likelihood[o][i]*beta[i] for i in beta})
    H = entropy(beta)
    G = {i: joint_goal_fn(i) for i in beta}            # G_i ⊆ Q
    return beta, H, G

def executable_intents(beta, G, qcert_fn, theta_q, theta_beta=0.1):
    supp = {i for i,b in beta.items() if b >= theta_beta}
    exec_ = {i for i in supp if exists_traj(i, G[i], qcert_fn, theta_q)}
    gap = {i: (beta[i] >= theta_beta and i not in exec_) for i in supp}
    return exec_, gap
```

### IP-122 JEC（Joint-space Executability Certificate）

```python
def joint_cert(traj, limits, jac_fn, tau_fn, theta):
    m_lim = min(min(q_j-lim.lo, lim.hi-q_j) for q_j in traj)
    m_sing = min(min_singular_value(jac_fn(q)) for q in traj)
    m_manip = min(sqrt(det(jac_fn(q) @ jac_fn(q).T)) for q in traj)
    m_torque = min(limits.tau_max - abs(tau_fn(q)) for q in traj)
    return QCert(m_lim, m_sing, m_manip, m_torque,
                 ok=all(m >= theta[k] for k,m in enumerate(...)))
```

### IP-123 ICC（Intent-Conditioned Composition）

```python
def icc_plan(G_S, beta, G, qcert_fn, theta_q, theta_beta, lam_H, lam_Q):
    supp = {i for i,b in beta.items() if b >= theta_beta}
    best, best_cost = None, inf
    for pi in enumerate_paths(G_S):
        # 每个高概率意图都要有可行关节轨迹
        feasible = all(exists_traj(i, G[i], qcert_fn, theta_q) for i in supp)
        if not feasible:
            continue
        c = sum(beta[i]*align_cost(pi, G[i]) for i in supp) \
            + lam_H*entropy(beta) + lam_Q*infra_risk(pi)
        if c < best_cost:
            best, best_cost = pi, c
    return best  # None -> 触发主动消歧或拒绝
```

### IP-124 AID（Active Intent Disambiguation）

```python
def active_disambiguate(beta, probes, qcert_fn, theta_q, lam_e):
    best, best_voi = None, -inf
    for a in probes:
        tau_a = plan_probe(a)
        if not qcert_fn(tau_a, theta_q).ok or not reversible(a):
            continue
        voi = mutual_info(beta, a) - lam_e*cost(a)
        if voi > best_voi:
            best, best_voi = a, voi
    return best if best_voi > 0 else None
```

### IP-125 IJC（Intent-Joint Certificate）

```python
def intent_joint_certificate(beta, H, G, qcert_fn, A_cert, rho, theta):
    supp = {i for i,b in beta.items() if b >= theta.beta}
    sep_ok = pairwise_separable(supp, G, theta.sep)
    if H > theta.H and not sep_ok:
        return ('disambiguate', 'intent_ambiguous')
    for i in supp:
        qc = best_traj_cert(i, G[i], qcert_fn)
        if not qc.ok:
            return ('reject', 'joint_infeasible', i, qc)
    if not A_cert.ok or min(rho.values()) < theta.rho_min:
        return ('reject', 'action_or_robustness_fail')
    return ('ok', JointCertT(beta, H, A_cert, qcert_fn, rho))
```

### IP-126 IGM（Intent-Geometry Monitor）

```python
def intent_geometry_monitor(state, kappa):
    Gt = state.gap.get(argmax(state.beta), False)
    Dt = state.H > state.theta_H
    state.streak = state.streak+1 if (Gt or Dt) else 0
    if state.streak >= kappa:
        return ('reopen', {'intent': state.beta,
                           'cause': classify_cause(state)})
    return ('continue', None)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IBP | O(|O|·|I| + |I|·|G|) | O(|I|+|G|) | 后验标定、目标流形完备 |
| JEC | O(N_τ·n·c_J) | O(N_τ·n) | 采样覆盖限位/奇异区 |
| ICC | O(|I|·|S|²·|A| + |Π|·|I|) | O(|S|²+|I|) | `β` 阈值支撑、路径穷举可剪枝 |
| AID | O(|A_p|·|I|·H) | O(|A_p|) | 互信息估计、探测可回退 |
| IJC | O(|S|·|A| + |I|·|τ|·n) | O(|A|+|τ|) | 联合证书 sound、`Θ` 闭合 |
| IGM | O(|I|·|τ|) | O(1) | 断层分类可归因 |

**正确性定理（Intent–Joint Grounded Deployment Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** `β` 经结构化标定，`ECE ≤ ε_β`；**(A30)** `Q_cert` 在采样轨迹上对真实裕度给出 `1-δ_Q` 置信覆盖；**(A31)** 探针动作可逆且不越出 `Q_free`。
则当 `deploy(T)=ok` 时：
```
P_success ≥ 1 - ε_β - δ_Q - P(δ_a > Θ_a) - Σ_d (1-ρ_min(d)) - P(intent ambiguous ∧ ¬disambiguated)
```
关键：**部署前先要求「每个高概率意图都存在关节可行轨迹」，再要求动作/鲁棒证书成立**；语义置信只用于加权，不作为可行性证明。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图后验过自信（miscalibration） | 高 | 温度标定 + 保形预测 + 拒识阈值 |
| 关节证书采样漏掉薄奇异区 | 高 | 区间/可达性分析 + 主动采样 + 红队位形 |
| 主动探测造成不可逆动作 | 高 | 可逆性约束 + 安全包络 + 人在回路急停 |
| 意图目标流形 `G_i` 建模偏差 | 中 | 多假设流形 + 在线校正 + 反例回灌 |
| 三层证书过保守导致拒识过多 | 中 | 分层阈值 + 可解释降级 + 回退策略 |

## 6. 本轮最大风险

**一句话**：本轮把「意图识别」与「关节空间控制」用后验 `β`、关节证书 `Q_cert` 与三层联合证书强行缝合，其 soundness **同时依赖意图后验的标定质量、关节证书对薄奇异区/限位的采样覆盖、以及主动探测的可逆安全**；一旦后验过自信而关节证书又漏检薄奇异区，系统会用「语义上确信」掩盖「几何上不可达」，在真实机器人上表现为听懂了却撞限位/穿越奇异的高代价失败，故必须以 **保形标定 + 区间可达性验证 + 可逆探针急停** 三重护栏，宁可主动说「不确定」，也不把意图置信度当作关节可行的替代品。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（IBP×JEC×ICC×AID×IJC×IGM）

> 承接第 54 轮产物 v31。本轮在动作-协同层之下钻入 **语义意图层** 与 **几何关节层**，新增六算子：

```python
    return best        # None -> AID 消歧或拒识
```

### IP-124 AID

```python
def active_disambiguate(beta, probes, qcert_fn, theta_q, lam_e):
    best, best_voi = None, -inf
    for a in probes:
        tau_a = plan_probe(a)
        if not qcert_fn(tau_a, theta_q).ok or not reversible(a):
            continue
        voi = mutual_info(beta, a) - lam_e*cost(a)
        if voi > best_voi:
            best, best_voi = a, voi
    return best if best_voi > 0 else None
```

### IP-125 IJC

```python
def intent_joint_certificate(beta, H, G, qcert_fn, A_cert, rho, theta):
    supp = {i for i,b in beta.items() if b >= theta.beta}
    if H > theta.H and not pairwise_separable(supp, G, theta.sep):
        return ('disambiguate', 'intent_ambiguous')
    for i in supp:
        qc = best_traj_cert(i, G[i], qcert_fn)
        if not qc.ok:
            return ('reject', 'joint_infeasible', i, qc)
    if not A_cert.ok or min(rho.values()) < theta.rho_min:
        return ('reject', 'action_or_robustness_fail')
    return ('ok', JointCertT(beta, H, A_cert, qcert_fn, rho))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IBP | O(|O|·|I| + |I|·|G|) | O(|I|+|G|) | 后验标定、目标流形完备 |
| JEC | O(N_τ·n·c_J) | O(N_τ·n) | 采样覆盖限位/奇异区 |
| ICC | O(|I|·|S|²·|A| + |Π|·|I|) | O(|S|²+|I|) | `β` 阈值支撑、路径最优（剪枝） |
| AID | O(|A_p|·|I|·H) | O(|A_p|) | 互信息估计、探针可回退 |
| IJC | O(|S|·|A| + |I|·|τ|·n) | O(|A|+|τ|) | 三证书 sound、阈值闭合 |
| IGM | O(|I|·|τ|) | O(1) | 断层可归因 |

**正确性定理（Intent–Joint Grounded Deployment Soundness）**
承接第 54 轮 (A22)–(A28)，新增 **(A29)** `β` 标定 `ECE≤ε_β`；**(A30)** `Q_cert` 对真实裕度 `1-δ_Q` 置信覆盖；**(A31)** 探针可逆且不越 `Q_free`。当 `deploy(T)=ok`：
```
P_success ≥ 1 - ε_β - δ_Q - P(δ_a > Θ_a) - Σ_d(1-ρ_min(d))
              - P(intent ambiguous ∧ ¬disambiguated)
```
关键：**先要求每个高概率意图存在关节可行轨迹，再要求动作/鲁棒证书成立**；语义置信只用于加权，绝不作为可行性证明。

## 6. 本轮最大风险

**一句话**：本轮用后验 `β`、关节证书 `Q_cert` 与三证书 `T` 把意图识别与关节空间控制缝合，其 soundness **同时依赖意图后验标定、关节证书对薄奇异区/限位的覆盖、以及主动探测的可逆安全**；一旦后验过自信而关节证书漏检薄奇异区，系统会用「语义上确信」掩盖「几何上不可达」，在真实机器人上表现为听懂了却撞限位/穿越奇异的高代价失败，故必须以 **保形标定 + 区间可达性验证 + 可逆探针急停** 三重护栏，宁可主动说「不确定」，也不把意图置信度当作关节可行的替代品。
