# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「仿真训练」×「应用落地」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书 `J=(ρ,A_cert,γ_ce,δ_a)`，并在云边之间闭环。但这些证书**全部在仿真分布 `P_sim` 下计算**，隐含假设 `P_sim ≈ P_deploy`。本轮正面处理「仿真训练」与「应用落地」之间的鸿沟：训练如何被证书驱动、证书如何校准到真实部署分布、部署数据如何安全回流。核心矛盾：H22：仿真成功率 ≠ 落地成功率，证书在 `P_sim` 下 sound、在 `P_deploy` 下可能系统性失真（分布偏移）；H23：仿真预算与落地收益之间缺少可度量映射，算力被均匀浪费在低敏感维度；H24：部署回流数据若无门控地重训，会因幸存者偏差与分布坍缩引发负迁移。

## 0. 直觉与动机

**灵感 1（落地是校准问题，不是阈值问题）**
直觉：过去所有证书都是「点估计 + 阈值」——`ρ ≥ ρ_min` 就认为可部署。但 `ρ` 是在仿真里测的，真实部署分布 `P_deploy` 未知且会漂移。正确的问题不是「这个技能达不达标」，而是「在真实部署流上，失败率能不能被有限样本地界住」。因此把落地判据从确定性阈值改为 **分布无关的覆盖率保证**：用 conformal calibration 在部署相似校准集上把风险阈值校准成 `q̂_α`，使 `P_deploy(success) ≥ 1-α` 有有限样本保证。**落地门输出的是概率下界，而不是布尔值。**

**灵感 2（证书缺口驱动的仿真课程）**
直觉：仿真训练不该做无方向的 domain randomization。既然证书 `ρ_S(d)` 已指出技能在每个鲁棒性维度上的短板，缺口 `g_S(d)=ρ_min(d)-ρ_S(d)` 就是天然的课程信号。把仿真场景分布 `Q_train` 按「能暴露多大缺口」重加权，等价于对证书做 boosting：越弱的地方采样越多。这把「仿真训练」从随机覆盖变成 **证书定向的对抗课程**，直接压缩 sim-to-real gap 中「该训没训」的部分。

**灵感 3（仿真预算的价值分配）**
直觉：不是所有保真度都值钱。定义仿真边际价值 `V_sim(f_i)=ΔP_success/Δcost`——每单位算力换来的落地成功率增量。只在证书敏感（`∂P_success/∂f_i` 大）的子系统上提高保真度，其余维度用低保真代理。这让「仿真训练」从「全都高保真」变成 **保真度投资组合**，把预算花在落地门的刀刃上。

**灵感 4（现实回流的门控与去偏）**
直觉：部署现场数据是最贵的训练资源，但也是最偏的——它只包含「已经部署出去」的分布，存在幸存者偏差；若直接重训会形成回音室。因此回流必须过 **现实回流证书 `B=(novelty, shift, Δρ_est, absorbable)`**：只吸收既新颖又在偏移界内、且能带来可测 `Δρ` 的样本；其余进入隔离池等人工复核。训练-部署闭环由此变成 **带门控的数据飞轮**，而不是无条件重训。

**灵感 5（训练-部署一体层 𝔻）**
直觉：在第 54 轮动作协同层 `𝔸` 之上再叠一层 **落地层 `𝔻`**：`𝔻_0` 部署分布，`𝔻_1` 校准集，`𝔻_2` 落地门，`𝔻_3` 回流门控。跨层证书需同时携带 `J`、`B` 与校准记录 `q̂_α`，形成 **动作-鲁棒-落地三证书**。至此，「训练出来的能力」与「能落地的能力」被同一个可校准、可审计的证书体系串起来。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（部署分布与部署覆盖）**
部署分布 `P_deploy` 定义在任务-上下文-动作三元组 `(T, C, a)` 上。技能/组合 `S` 的 **部署覆盖** `Cov(S) = P_deploy( dom(S) ∩ A_core(S) )`，其中 `dom(S)` 为其在 `P_deploy` 下有效执行的支撑集。此前 `Cov` 被隐含取为均匀测度，本轮显式区分。

**定义 122（证书缺口）**
给定第 53 轮鲁棒性谱 `ρ_S(d)` 与门槛 `ρ_min(d)`，**证书缺口** `g_S(d) = max(0, ρ_min(d) - ρ_S(d))`；聚合缺口 `G(S) = Σ_d w_d·g_S(d)`，`w_d` 为部署分布下维度 d 的敏感权重（`∂P_success/∂ρ(d)`）。

**定义 123（证书驱动课程生成器）**
课程生成器 `Φ_cur` 把缺口映射为仿真场景分布：
```
Q_train = Φ_cur(G, Explain),
Φ_cur = argmax_Q E_{x~Q}[G(S_x)]  s.t.  cost(Q) ≤ B_sim
```
其不动点满足指数重加权形式 `Q_train(x) ∝ Q_base(x)·exp(η·G(S_x))`（boosting），即缺口越大的场景被采样越多。

**定义 124（仿真边际价值与保真度分配）**
对保真度维度 `f_i`，`V_sim(f_i) = ΔP_success(f_i) / Δcost(f_i)`。保真度分配解：
```
f* = argmax_{f} Σ_i V_sim(f_i)  s.t.  Σ_i cost(f_i) ≤ B_fid
```
一阶条件为等边际原则 `∂P_success/∂f_i / (∂cost/∂f_i) = λ`。

**定义 125（落地门）**
落地门 `Gate(S) = (Cov(S) ≥ Θ_cov) ∧ (q̂_α(S) ≤ q_max) ∧ (δ_a ≤ Θ_a) ∧ (cal_error ≤ ε_cal)`，其中 `q̂_α(S)` 为 conformal 校准阈值。`Gate=1` 表示：在部署分布上 `P_deploy(success) ≥ 1-α` 有有限样本保证，且动作对齐与覆盖同时达标。

**定义 126（现实回流证书）**
回流证书 `B = (nov(x), shift(x), Δρ_est(x), absorbable)`：
- `nov(x)`：样本相对训练集的新颖度；
- `shift(x)`：`x` 相对 `P_sim` 的分布偏移（MMD/密度比）；
- `Δρ_est(x)`：吸收后对 `ρ` 的估计增量；
- `absorbable = [nov ≥ ν_min] ∧ [shift ≤ ζ_max] ∧ [Δρ_est ≥ 0]`。
仅 `absorbable=1` 的样本可进入下一轮课程，其余进隔离池。

## 2. 关键算法伪代码

### IP-121 CDCG（Certificate-Driven Curriculum Generation）

```python
def certificate_curriculum(skill, rho_min, Explain, B_sim, eta=0.5, n=4096):
    gaps = {d: max(0.0, rho_min[d]-skill.rho[d]) for d in rho_min}
    base = sample_scenarios(skill, n)             # 基础域随机化
    weights = [exp(eta*aggregate_gap(gaps, s, Explain)) for s in base]
    Z = sum(weights)
    Q = [(s, w/Z) for s, w in zip(base, weights)]
    return prune_by_budget(Q, B_sim)              # 缺口大者优先保留
```

### IP-122 CCA（Conformal Certificate Calibration）

```python
def conformal_calibrate(scores_cal, alpha):
    # scores_cal: 部署相似校准集上的非一致性分数（越大越可能失败）
    n = len(scores_cal)
    k = ceil((n+1)*(1-alpha))
    if k > n:
        return float('inf')                        # 样本不足，无法保证
    return sorted(scores_cal)[k-1]                 # q_hat

def deploy_score(S, gamma_ce, rho_min):
    risk = max(0.0, max(rho_min[d]-S.rho[d] for d in rho_min))
    align = max_alignment_error(gamma_ce, S.A_core)
    return risk + LAM_ALIGN*align                  # 非一致性分数

def deployment_gate(S, cal_scores, alpha, delta_a_budget):
    q_hat = conformal_calibrate(cal_scores, alpha)
    if q_hat == float('inf'):
        return ('reject', 'insufficient_calibration')
    if deploy_score(S, S.gamma_ce, rho_min) > q_hat:
        return ('reject', 'risk_exceeds_qhat', q_hat)
    return ('ok', DeployCert(q_hat, alpha, n=len(cal_scores)))
```

### IP-123 SVA（Simulation Value Allocation）

```python
def allocate_fidelity(subsystems, P_success_fn, B_fid):
    values = {}
    for name, ss in subsystems.items():
        lo = P_success_fn(fidelity=ss.f_min)
        hi = P_success_fn(fidelity=ss.f_max)
        values[name] = (hi-lo) / max(1e-9, ss.cost_hi-ss.cost_lo)
    order = sorted(values, key=values.get, reverse=True)
    budget, alloc = B_fid, {}
    for name in order:                             # 等边际贪心
        f, spend = subsystems[name].next_step(alloc.get(name, subsystems[name].f_min))
        if spend <= budget:
            alloc[name] = f
            budget -= spend
        else:
            alloc[name] = subsystems[name].at_budget(budget)
            break
    return alloc, values
```

### IP-124 RBF（Reality Backflow Filter）

```python
def backflow_filter(field_batch, train_set, sim_model, nu_min, zeta_max):
    accepted, quarantine = [], []
    for x in field_batch:
        nov = novelty(x, train_set)
        shift = distribution_shift(x, sim_model)
        d_rho = estimated_rho_gain(x, sim_model)
        ok = (nov >= nu_min) and (shift <= zeta_max) and (d_rho >= 0)
        (accepted if ok else quarantine).append(x)
    return accepted, quarantine
```

### IP-125 TDL（Train-Deploy Loop）

```python
def train_deploy_loop(policy, P_deploy_stream, B_sim, B_fid, alpha):
    cal = collect_calibration(P_deploy_stream, n_cal)
    for round in range(max_rounds):
        Q = certificate_curriculum(policy, rho_min, Explain, B_sim)
        alloc = allocate_fidelity(policy.subsystems, policy.P_success, B_fid)
        policy = simulate_train(policy, Q, alloc)
        scores = [deploy_score(policy, policy.gamma_ce, rho_min) for x in cal]
        gate = deployment_gate(policy, scores, alpha, delta_a_budget)
        if gate.status != 'ok':
            Explain = explain_failure(policy, cal)  # 缺口回灌课程
            continue
        deploy(policy)
        field = collect_field_data(policy)
        accepted, quarantine = backflow_filter(
            field, policy.train_set, sim_model, nu_min, zeta_max)
        cal = update_calibration(cal, accepted)     # 在线/自适应 conformal
        policy = incorporate(policy, accepted)
    return policy, cal
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CDCG | O(n·|𝔇_ρ| + n log n) | O(n) | 缺口单调重加权，预算剪枝 sound |
| CCA | O(n log n) | O(n) | 交换性下边际覆盖 ≥ 1-α |
| SVA | O(|subsys|·log|subsys|) | O(|subsys|) | 等边际贪心在子模性下近似最优 |
| RBF | O(|batch|·(d_nov+d_shift)) | O(|batch|) | 三重门控条件可判定 |
| TDL | 每轮 O(train)+O(n log n) | O(n) | 校准集滚动更新，收敛到门内策略 |

**正确性定理（Calibrated Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 校准集 `D_cal ~ P_deploy` 与部署流可交换（exchangeable）；**(A30)** 非一致性分数 `s(S,x)` 对失败风险单调；**(A31)** 校准与部署间分布偏移有界（否则改用自适应 conformal 并放大 α）。
则落地门通过时：
```
P_deploy(success | Gate=1) ≥ 1 - α - β_E - P(δ_a > Θ_a) - ε_shift
```
其中 `β_E` 为仿真-现实建模误差，`ε_shift` 为交换性违反的松弛项。**关键：证书从「仿真内 sound」升级为「部署分布上有限样本 sound」，落地门给出可审计的失败率下界。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 交换性假设在分布漂移下失效 | 高 | 自适应 conformal（ACI）+ 漂移检测 + 放宽 α |
| 课程重加权过拟合仿真缺口 | 高 | 留出锚点集 + 缺口上限裁剪 + 真实回放混合 |
| 校准集与部署流不相似 | 高 | 分层采样 + 重要性加权 + 拒绝低覆盖校准 |
| 回流回音室/幸存者偏差 | 中 | 新颖度门控 + 隔离池人工复核 + 反事实补采 |
| 保真度估计 `V_sim` 噪声大 | 中 | 多臂 bandit 在线估计 + 置信上界 |

## 6. 本轮最大风险

**一句话**：把落地从阈值判断改为 conformal 校准、再用证书缺口驱动仿真课程与回流门控，理论上给出了部署分布上的有限样本失败率下界；但该下界的全部有效性押在 **校准集与真实部署流的可交换性** 上——而真实落地恰恰以分布漂移为常态，一旦漂移发生，`q̂_α` 会给出「已认证」的虚假安全感，且证书课程与回流飞轮会沿仿真缺口自我强化、进一步偏离真实分布，故必须以 **自适应 conformal + 漂移绊线 + 独立锚点集** 三重护栏，把「认证」降级为「可撤销的在线保证」，绝不把仿真里校准出的概率下界当成一次性的落地通行证。

```python
        gate = deployment_gate(policy, scores, alpha, delta_a_budget, cov_min)
        if gate.status != 'ok':
            Explain = explain_failure(policy, cal)
            continue
        deploy(policy)
        field = collect_field_data(policy)
        accepted, quarantine = backflow_filter(
            field, policy.train_set, sim_model, nu_min, zeta_max)
        cal = update_calibration(cal, accepted)     # adaptive conformal
        policy = incorporate(policy, accepted)
    return policy, cal
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CDCG | O(n·|𝔇_ρ| + n log n) | O(n) | 缺口单调重加权，预算剪枝 sound |
| CCA | O(n log n) | O(n) | 交换性下边际覆盖 ≥ 1-α |
| SVA | O(|subsys|·log|subsys|) | O(|subsys|) | 子模性下等边际贪心近似最优 |
| RBF | O(|batch|·(d_nov+d_shift)) | O(|batch|) | 三重门控条件可判定 |
| TDL | 每轮 O(train)+O(n log n) | O(n) | 校准集滚动更新，收敛到门内策略 |

**正确性定理（Calibrated Deployment Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** `D_cal ~ P_deploy` 与部署流可交换；**(A30)** 非一致性分数对失败风险单调；**(A31)** 校准与部署偏移有界（否则用自适应 conformal 并放大 α）。
则：
```
P_deploy(success | Gate=1) ≥ 1 - α - β_E - P(δ_a > Θ_a) - ε_shift
```
其中 `β_E` 为仿真-现实建模误差，`ε_shift` 为交换性违反松弛。关键：**证书从「仿真内 sound」升级为「部署分布上有限样本 sound」**。

## 5. 本轮最大风险

**一句话**：把落地从阈值判断改为 conformal 校准、再用证书缺口驱动仿真课程与回流门控，理论上给出了部署分布上的有限样本失败率下界；但该下界的全部有效性押在 **校准集与真实部署流的可交换性** 上——而真实落地恰恰以分布漂移为常态，一旦漂移发生，`q̂_α` 会给出「已认证」的虚假安全感，且证书课程与回流飞轮会沿仿真缺口自我强化、进一步偏离真实分布，故必须以 **自适应 conformal + 漂移绊线 + 独立锚点集** 三重护栏，把「认证」降级为「可撤销的在线保证」，绝不把仿真里校准出的概率下界当成一次性的落地通行证。
