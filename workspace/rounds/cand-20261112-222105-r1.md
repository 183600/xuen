# 第 3 轮迭代（新循环第 1 轮 · 灵感：「实时性」×「数字孪生」）—— 从离线 Gazebo 神谕升级为「块同步在线数字孪生」

> 承接上一版 v2（UIP-01′~15）。这一轮我不再问“还能加什么模块”，而是问一个更尖锐的问题：**在 `get_action(obs)` 只能一次返回 `T_a` 步、整块执行完才重新观测的协议下，“实时”到底还能从哪里挤出来？** 我的答案是：把数字孪生从赛前的 Gazebo 搬到赛中的每个 API 边界，用它填补两次观测之间的“盲区”，并把恢复计算提前到不挡返回的路径上。

---

## 0. 先给直觉：机器人是在“闭眼执行”

- 接口是**开环动作块**：看一眼 `obs`，返回 `T_a` 步，评测端把整块执行完才允许你再看一眼。
- 所以真正的实时性瓶颈不是“模型前向多快”，而是“**闭眼走完 `T_a` 步期间发生了什么，你只能等下一次睁眼才知道**”。
- 数字孪生在这里的直觉：在闭眼期间，用一个轻量的**对象级任务状态副本**持续推演——物体在哪、每个计分谓词是否成立、人手可能怎样把进度倒退；睁眼时用稀疏的**回溯帧**对齐，并立刻判断“进度是被自己搞砸了，还是被人倒退了”。
- 实时性在这里的直觉：不是把每件事做快，而是**把计算放到不挡 API 返回的路径上**；返回动作永远不等孪生，孪生用“上一拍”的快照工作，超时就降级。

一句话对比上一轮：**上一轮的 Gazebo 是考前模拟卷；这一轮的数字孪生是考场里的仪表盘和草稿纸。**

### 必须纠正的三点

1. **上轮 UIP-13 的“运行期自适应块长”不合规。** README §3 要求形状恒为 `(T_a,…)`，`T_a` 在 metadata 握手时确定。接触密集时就返回更短的块，会直接破坏接口契约。实时性的正确杠杆是：**固定 `T_a` 的离线选择（按握手语义推断为全局）+ 孪生在盲区内的预测/回溯**，而不是运行期改块长。
2. **负偏移不是“多堆几帧”，而是“块内信息回传通道”。** 上轮只把它当时间堆叠；实际上它让我们在下一次睁眼时看到刚执行块的稀疏历史。多帧=多张 JPEG，因此这是一个可优化的**带宽-信息**问题。
3. **`observation.language` 固定，任务路由可直接条件化。** 不必为路由引入多个模型，降低“单模型”合规风险。

## 2. 概念澄清：仿真 ≠ 数字孪生

**直觉**：一个和真机长得一样的 Gazebo 场景，如果从不与真机同步，它只是“数字模型/仿真器”；只有持续吃真机数据、持续纠偏、并能回答“下一步会怎样”的副本，才配叫数字孪生。

**严谨定义**：

- **仿真器**：离线、无同步，回答反事实“如果”。
- **数字孪生**：三元组 `(同构 I, 同步 S, 推演 P)`。`I` 是几何/运动学/任务语义同构；`S` 是在线状态更新；`P` 是给定动作后的可推演性。
- **块同步数字孪生（CS-DT）**：同步周期被接口锁死为 `H = T_a·τ`（`τ` 为单步控制周期）。它不是“更高保真的 Gazebo”，而是**对象级、任务级、可在线校准的轻量状态副本**。

---

## 3. 严谨定义与问题形式化

设第 `n` 个 API 边界为 `t_n = nH`。策略是映射

```
π: O → A^{T_a},   A_n = π(o_{t_n}),   o_{t_{n+1}} = O(x_{t_n + T_a})
```

隐藏任务状态为 `z_t`（物体位姿、关系、夹爪、底座、任务阶段），计分谓词为 `g_s(z_t) ∈ {0,1}`，`s=1..S`。进度定义为有序前缀：

```
p_t = max { k | g_1(z_t)=…=g_k(z_t)=1 }
```

人为干扰是一个算子 `D_d: z ↦ z'`，可使 `p` 下降 `d` 步（合上、拉开、翻开、拿走、挪底座）。

**计分语义必须显式分开**：

```
S_end  = Σ_{s≤p_T} w_s                 # 末态计分：倒退会真扣分
S_high = max_t Σ_{s≤p_t} w_s           # 高水位计分：已得步骤不因倒退消失
```

上一版把“人扰倒退会消耗步骤分”当成规则级事实；严格说它只在 `S_end` 下成立。本轮把它降级为工作假设 **H0**，并让孪生同时估计两种语义下的得分，避免把优化目标建错。

**数字孪生**定义为四元组 `T=(E,f,g,b)`：

- `E: o_t ↦ ẑ_t`：观测估计器（优先经典几何/立体匹配，不引入外部 VLM）；
- `f: ẑ_{t+1} = f(ẑ_t, a_t, θ)`：对象级动力学/运动学；
- `g: ẑ ↦ m ∈ R^S`：谓词裕度，`m_s>0` 判完成；
- `b_t(k)=P(p_t=k | o_{1:t})`：进度信念，转移中显式含“被人倒退”的概率。

**实时契约**：

```
T_resp = T_policy + T_twin_critical + T_io ≤ B
```

其中 `T_twin_critical` 在常规路径上应为 0：孪生异步更新，返回动作只读“上一拍已提交快照”；仅在预算内才把新快照转正，超时则降级。孪生采用 anytime 保真度阶梯 `L0/L1/L2`，在截止时间内返回当前最高可用估计。

**决策目标**：

```
A_n* = argmax_A  E_{干扰假设}[ S_final(ẑ, A) | b_n ] − λ·Latency(A) − μ·Risk(A)
```

## 4. 核心机制：RC-DT（Retrospective Chunk-synchronous Digital Twin）

RC-DT 把“块同步”拆成**后向回溯**与**前向影子**两条时间线，在边界汇合。

### 4.1 后向：回溯观测（把盲区变成可回放的历史）

- 用 `obs_delta_indices` 对刚执行完的块做稀疏采样：本体状态密集（每帧 7 维浮点，几乎免费），图像稀疏（例如 `[-T_a, -T_a/2, 0]`）。
- 孪生把这段稀疏轨迹对齐到对象级状态，估计**干扰发生的时刻、被作用的物体、倒退深度**，而不是只知道“现在退步了”。
- 这是接口内唯一合法的块内信息回传通道；代价是 JPEG 带宽，因此需要下一节的观测预算分配。

### 4.2 前向：影子推演（把恢复计算提前）

- 在下一块执行前，孪生对候选动作块做快速 roll-out，并注入“人手可能在任意时刻倒退”的假设。
- 对每种预测到的失败模式，预生成恢复块 `R_m` 放入缓存；边界命中即可直接返回，恢复决策延迟≈0。
- 注意：这不是运行期改 `T_a`，只是**提前准备下一块的内容**。

### 4.3 干扰残差分类（把“失败”拆开）

边界处同时看两个量：

```
innovation:  e_n = z_obs − ẑ_pred
progress:    Δp_n = p_obs − p_{n-1}
```

- `regressed`：`p_obs < p_{n-1}` → 人为倒退，重做被撤回的子目标；
- `stalled`：`p_obs = p_{n-1}` 但影子预测本应前进 → 策略失败或物件卡住；
- `drifted`：`e_n` 大但 `p` 不变 → 标定漂移/视觉误差，先校准不重做；
- `nominal`：其余。

用反事实残差归因：在“无干扰”假设下仿真同一动作块的预测，与观测比对；残差中无法由动作解释的部分归为外因。

### 4.4 防御性块组合（合规的“块内实时性”）

既然 `T_a` 不能改，就在块内做节奏控制：

```
A_n = [完成当前子目标所需的前 k 步] + [guard/hold 到第 T_a 步]
```

让每个盲区结束时机器人处于可预测的安全姿态，降低孪生预测误差、减少灾难性漂移；同时也让动作尾部更平滑，降低“统计规律性异常”的可信度风险。这是不改 `T_a` 前提下，接口内唯一能做的块内节奏设计。

## 5. 实时性：把块长从“运行期决策”改成“离线约束”

设单步周期 `τ`，块周期 `H=T_a·τ`，单次调用网络+排队延迟 `L`。三个关键量：

```
占空比/吞吐:     η = H / (H + L)
平均发现滞后:   δ ≈ H/2 + L
时间预算约束:   D·(1 + L/H) ≤ T_max   ⇒   H ≥ D·L/(T_max − D)
```

**直觉**：小 `H` 不是免费的反应性。它用吞吐和延迟暴露换反应性；当 `L` 与 `H` 同量级时，机器人有一半时间在等下一块。

若把孪生前向误差近似为 `ε(H)=ε_0+κH`，则

```
J(H) = α·H + β·L/H + γ·(ε_0 + κH)
H*   = sqrt( β·L / (α + γ·κ) )
```

在 `L=100ms, τ=50ms, D=40s` 下的示意（仅算术，不含经验参数）：

| `T_a` | `H` | 发现滞后 `δ` | 占空比 `η` | 40s 任务的调用次数 |
|---:|---:|---:|---:|---:|
| 2 | 0.1s | 0.15s | 50.0% | 400 |
| 4 | 0.2s | 0.20s | 66.7% | 200 |
| 8 | 0.4s | 0.30s | 80.0% | 100 |
| 16 | 0.8s | 0.50s | 88.9% | 50 |
| 32 | 1.6s | 0.90s | 94.1% | 25 |

结论：`T_a` 太小会把 episode 拖长甚至超时；太大则人扰发现滞后。孪生的价值不是消灭这个权衡，而是**让 `H*` 可以往大移，同时用回溯定位与预计算恢复把恢复质量补回来**。

## 6. 数字孪生的可行性边界

**直觉**：不要追求“像素级/接触力级”的真，孪生只需要在**结构谓词**上真——插多深、叠没叠上、拉链闭合多少、盖子开没开。

**关键假设与退路**：

1. **立体假设**：数据集里高位相机命名为 `head_stereo_left/right`，接口键为 `cam_left_high/right_high`，很可能是同一对立体相机。若外参可标定，经典立体匹配即可给度量深度，已知 CAD 的几何谓词可行。若并非标定立体对，则退化为单目+已知物体尺寸/类别先验，精度下降但结构判断仍可用。
2. **未见物品**：用类别级形状先验 + **同一主骨干**的分割/深度头，不引入外部 VLM；否则可能触发“单模型”合规风险。
3. **接触**：不建接触力模型，只建“插入深度、堆叠关系、闭合比例、目标区域包含”等几何关系。
4. **校准**：用公开成功演示拟合谓词阈值；用榜单步骤分做外部锚点；孪生只做**相对排序/结构判断**，不做“像素级成败裁判”。

## 8. 本轮瓶颈假设

- **H1（最高杠杆）**：在固定 `T_a` 下，块内信息缺失是恢复滞后的主因；稀疏回溯栈能显著降低“干扰发生时刻/对象/深度”的定位误差。
- **H2**：孪生的结构谓词比像素级成败更可靠；但若步骤分语义（末态 vs 高水位）判断错，系统会高效地优化错误目标。
- **H3**：小 `T_a` 的吞吐代价被低估；`L/H` 可能比模型前向延迟更致命，尤其在有时限的评测里。
- **H4**：孪生若引入第二个学习模型，可能触发“单模型”合规风险；必须走几何/确定性路线，或把学习部分蒸馏进同一骨干并明确记录。

---

## 9. 本轮最大风险

**一句话**：若孪生对“计分步谓词 + 计分语义（末态还是高水位）”的建模有偏，系统会非常高效地优化一个错误的分数，而且离线越自洽、越危险。

## 1. 旗舰深潜：RT-01 · RC-DT

### 1.1 孪生状态模式（对象级，非像素级）

```text
z_t = {
  robot:   { left_arm[7], right_arm[7], left_gripper, right_gripper, pivot[7] },
  objects: { id: { pose6D, vel6D, shape_prior, affordance_state } },
  relations:{ on(a,b), in(a,b), inserted(a,b,depth), closed(a,ratio), stacked(a,b) },
  stage:   { p_t, margins m[1..S], last_event_time, event_type }
}
```

设计原则：

- **只建结构**：位姿、关系、插入深度、闭合比例、目标区域包含；不建接触力/摩擦。
- **对象清单由任务给定**：32 任务的对象集合与 CAD/尺寸先验离线准备；未见物品用类别级形状先验。
- **机器人状态直接来自 obs**：关节/ee/夹爪/lower_body 都是接口字段，无需估计。

### 1.2 三级保真度（anytime）

| 级别 | 内容 | 典型计算 | 用途 |
|---|---|---|---|
| L0 | 运动学 + 对象位姿插值 | <5ms | 候选块粗筛、边界快速对齐 |
| L1 | 准静态接触 + 关系谓词 | 10–40ms | 计分谓词、进度信念、恢复选择 |
| L2 | 简化刚体/接触 roll-out | 50–200ms | 关键接触步的候选精排（仅预算内） |

调度规则：在 `B − T_policy − ε` 的剩余预算内选最高可用级别；超时立即返回上一拍快照。

### 1.3 五个部件

1. **同步器**：每边界吃 `obs`，做 L0/L1 级状态估计；异步写快照，不阻塞 `get_action` 返回。
2. **回溯器**：用 `obs_delta_indices` 的负偏移拿到上一块的稀疏轨迹，重建块内事件序列。
3. **谓词器**：对每个计分步计算裕度 `m_s(z)`，得到 `g_s=1[m_s>0]` 与置信度。
4. **判别器**：用 innovation + 进度差分把事件分为 `regressed/stalled/drifted/nominal`。
5. **预取器**：对预测到的干扰模式预生成恢复块，边界命中即取。

### 1.4 干扰判别状态机

```text
prev_p := p_{n-1}
p_obs  := max{k | g_1..g_k all true at boundary n}

if p_obs < prev_p:
    event = regressed(depth = prev_p − p_obs, target = argmin_s m_s)
elif p_obs == prev_p and p_pred > prev_p:
    event = stalled(target = first unfinished step)
elif innovation > τ_e and p_obs == prev_p:
    event = drifted
else:
    event = nominal

prev_p := p_obs
```

判据补充：

- `regressed` 必须有**方向性证据**：目标物体沿“撤回方向”移动，或闭合比例下降；仅谓词抖动不算。
- `stalled` 先做短重试；连续两次才升级为恢复。
- `drifted` 只触发孪生重标定，不触发重做，避免“反复擦桌子”。

### 1.5 恢复块选择

```text
候选集 C = {
  nominal_next,                 # 正常推进下一计分步
  redo(regressed_target),       # 重做被撤回的子目标
  guard(regressed_target),      # 先回到安全前置姿态
  hold                          # 保命/等待下一拍
}

A_n* = argmax_{A∈C}  E[ S_final | A, b_n ] − λ·T_est(A) − μ·Risk(A)
```

`S_final` 由 RT-02 的在线计分孪生给出；`Risk` 包含碰撞、超时、动作异常三类。

## 2. 关键推导

### 2.1 固定 `T_a` 下的实时性权衡

```
H = T_a·τ
η(H) = H/(H+L)                       # 有效占空比
δ(H) ≈ H/2 + L                       # 干扰平均发现滞后
J(H) = α·H + β·L/H + γ·(ε_0+κH)      # 反应性 + 吞吐 + 孪生误差
H* = sqrt(β·L/(α+γ·κ))
```

**推论 1**：当 `L` 与 `H` 同量级，小 `T_a` 会显著拉长 episode；若存在时限 `T_max`，则

```
H ≥ D·L/(T_max − D)
```

是硬下界，与模型多快无关。

**推论 2**：回溯观测把“发现滞后”从 `H+L` 降到约 `H/2+L`（平均而言能在块内定位事件），但不能把反应提前到下一个边界之前。因此孪生的收益在**定位精度与恢复决策**，不在“块内闭环”。

**推论 3**：按 README 的握手语义推断，`T_a` 是全局常量（同一提交跨任务复用 metadata），所以只能做**离线全局选择**；任务差异靠“防御性块组合 + 谓词/恢复模板”吸收，而不是运行期切块长。若评测端实际上每 episode 重新握手，则可放宽为按任务选择——这一点需先用一次真机/本地 stub 实验确认，不能默认。

### 2.2 回溯观测预算（ROP）

设键 `k` 的偏移集合为 `O_k`，图像缩放为 `r_k=(h_k,w_k)`，压缩率为 `c_jpeg`：

```
bytes_image(k) = |O_k| · h_k · w_k · 3 · c_jpeg
bytes_state(k) = |O_k| · d_k · 4

max Σ_k I_k(O_k, r_k)
s.t. Σ_k bytes_k ≤ B_max  且  估计传输时间 ≤ L_budget
```

贪心策略（按“单位字节的信息增益”排序）：

1. **本体状态全密采样**（7–15 维浮点，便宜），用于精确重建机器人轨迹；
2. **腕部相机稀疏历史**（接触发生在腕部视野），如 `[-T_a, -T_a/2, 0]`；
3. **高位相机当前帧 + 一帧历史**，用于全局物体位移/底座移动；
4. 若带宽紧，先降 `image_resize`，再减历史帧，最后才减当前帧。

经验配置（`T_a=8`，`τ=50ms`，`H=400ms`）：

## 3. 伪代码

### 3.1 策略主循环

```python
class RCDT_Policy:
    def __init__(self, policy, twin, T_a, deadline_ms, margin_ms=15):
        self.policy = policy
        self.twin = twin
        self.T_a = T_a
        self.deadline_ms = deadline_ms
        self.margin_ms = margin_ms
        self.snapshot = None
        self.recovery = {}
        self.prev_p = 0

    def reset(self):
        self.policy.reset()
        self.twin.reset()
        self.snapshot = None
        self.recovery.clear()
        self.prev_p = 0

    def get_action(self, obs):
        t0 = now_ms()

        # 1) 异步提交观测；不在关键路径等待
        self.twin.submit(obs)

        # 2) 用上一拍已提交快照做决策（若没有则用先验）
        snap = self.snapshot or self.twin.prior(obs)

        # 3) 事件判别 + 恢复选择
        event = self.detect(snap)
        self.prev_p = snap.p
        if event.kind == "regressed" and event.key in self.recovery:
            chunk = self.recovery[event.key]
        else:
            chunk = self.policy.get_action(obs, snap)

        # 4) 防御性块组合：不足 T_a 用 guard/hold 补齐
        chunk = self.compose_defensive(chunk, snap, self.T_a)

        # 5) 预算内尝试把新孪生结果转正；超时降级
        remaining = self.deadline_ms - (now_ms() - t0) - self.margin_ms
        fresh = self.twin.try_commit(remaining)
        if fresh is not None:
            self.snapshot = fresh

        # 6) 后台预取恢复块（不阻塞返回）
        self.twin.prefetch_recovery(self.recovery, snap)

        return chunk
```

### 3.2 孪生 anytime 提交

```python
class ChunkTwin:
    def submit(self, obs):
        self.queue.put_nowait(obs)          # 非阻塞

    def try_commit(self, budget_ms):
        if budget_ms <= 0:
            return None
        level = self.pick_level(budget_ms)  # L0/L1/L2
        try:
            with time_limit(budget_ms):
                z = self.estimate(level)     # 几何/立体匹配 + 关系
                b = self.update_belief(z)    # HMM/粒子滤波
                return Snapshot(z, b, level)
        except Timeout:
            return None                      # 保留旧快照

    def pick_level(self, budget_ms):
        # 以离线标定的 cost model 选最高可完成级别
        for level in ("L2", "L1", "L0"):
            if self.cost_est(level) <= budget_ms:
                return level
        return "L0"
```

### 3.3 计分孪生（RT-02）

```python
def step_score(z, task):
    # 每个任务一个谓词表；返回 (score, margins, confidence)
    margins = {s: predicate_s(z, task) for s in task.steps}
    done = {s: margins[s] > 0 for s in task.steps}
    p = max_prefix(done)
    score_end  = sum(w for s, w in task.weights if s <= p)
    # 高水位由调用方维护
    return score_end, margins, min_confidence(margins)
```

### 3.4 防御性块组合

```python
def compose_defensive(chunk, snap, T_a):
    chunk = list(chunk)[:T_a]
    if len(chunk) < T_a:
        guard = make_guard_target(snap)      # 当前安全姿态/微退让
        chunk += [guard] * (T_a - len(chunk))
    return clip_and_smooth(chunk)            # 关节限位 + 平滑，避免动作异常
```

## 8. 本轮贡献与最大风险

**贡献**：

1. 把数字孪生从“离线仿真神谕”改成“赛中块同步状态副本”，直接服务于步骤分与干扰恢复。
2. 发现并利用 `obs_delta_indices` 负偏移的**回溯观测**能力，把块内盲区变成可回放历史。
3. 纠正 v2 的运行期变块长错误，给出固定 `T_a` 下的实时性权衡与离线选择方法。
4. 用“回溯 + 前向影子 + 预取恢复”把检测、计分、延迟统一到一个截止时间感知的闭环里。

**最大风险（一句话）**：若孪生的计分谓词或计分语义（末态还是高水位）建模有偏，系统会高效地优化一个错误分数，且离线自洽会放大这种自信。
