# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「差异化定位」×「手眼标定」）

> **基线**：上一轮（灵感「大语言模型」×「机器人」×「智能体」）MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**标定是一张必须随每张空间证书一起搬运的证书，定位是按任务差异化分配的等级、不是全局常量**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v14 的 SCD/DSD/DCA/EDC、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。六个新组件——CHM（标定健康监控器）、UPE（不确定度传播引擎）、PCL（定位证书格）、DPA（差异化定位分配器）、XFA（跨帧一致性审计器）、CRS（标定刷新调度器）——一律以**中立元接入 v17 语言层与 v16 行为层之间的空间证书链**，失效即严格退回 v17（引理 148），再沿 v17→v16→v15→v14→v13→v12→v11→v10→v9→v8→v7→v6 退化链退回。本轮只做三件事：把"手眼标定"改写为**可传播的标定证书**、把"差异化定位"改写为**定位等级格与逐任务分配**、把"标定漂移"改写为**先损失活性、后损失安全**的收缩阶梯。

## 0. 直觉与动机

**灵感 1（手眼标定 → 证书链的地基本身从未被认证）**
直觉：v16 的节点证书 `NC_n=(Pre,Run,Post,Fallback)` 与 v17 的缝证书 `SC_i=Post_i∩Pre_{i+1}` 全部隐式假设"手眼变换 `T_HE` 是精确常量"。真实系统里 `T_HE` 会因热膨胀、碰撞回弹、换夹具、减速器磨损缓慢漂移。灾难之处在于：**标定误差不会让机器人说"我错了"，而是让它自信地错**——每个 `Pre/Post` 在其自己的坐标系里仍形式成立，每道缝仍"非空"，只是整套空间证书被系统性地平移/旋转了 δ。核心创新：**标定证书（Calibration Certificate, CalCert）**，把 `T_HE` 从常量升级为带不确定度的证书 `(T̂_HE, Σ_cal, t_cal, E_cal)`，并由**不确定度传播引擎（UPE）**把所有证书集合按 δ 膨胀：`Cert^δ = Cert ⊕ B(δ)`。关键反直觉点：**标定越差，系统应当"越保守地能做"，而不是"越安静地出错"**；膨胀使缝体积随 δ 单调收缩，长计划先变得不可行，而不是先变得不安全。

**灵感 2（差异化定位 → 定位不是越准越好，而是越匹配越好）**
直觉：机器人常把所有任务压给一个"最准"的定位源（如高精度视觉），结果是又贵又脆；或者反过来用本体感觉硬做精细插装。真实需求是分化的：抓杯要 5mm、插 USB 要 0.5mm、走廊巡航要 10cm；而视觉、触觉、本体感觉、基准标记、激光各有不同的误差结构、频率、鲁棒性、标定暴露。核心创新：**定位证书格（PCL）+ 差异化定位分配器（DPA）**：每个 BT 节点带定位等级需求 `p_n=(ε,τ,r,c)`（精度、延迟、冗余、帧一致），每个模态带供给向量 `π_m`；DPA 为每个任务/区域求解"需求—供给"匹配并给出当前可达等级 `p*`。关键反直觉点：**一个更准但标定过期的模态，可能严格劣于一个更粗但标定新鲜的模态**——有价值的不是瞬时精度，而是"能被 CalCert 覆盖的精度"；DPA 的目标是最小化"定位成本 + 标定暴露"，不是最大化瞬时精度。

**两者如何统一**
统一为 **v17 之上的空间可信层（spatially-trustworthy layer）**：v17 回答"哪些语言计划能被编译并在新鲜度阶梯下执行"（`Exec_v17`），v18 回答"这些执行所依赖的空间证书，在标定不再精确、定位源分化时，是否仍然诚实"（`Exec_v18`）。CHM 产出 CalCert，UPE 把标定不确定度灌进 NC/SC，PCL 把节点需求与模态供给排成偏序格，DPA 做逐任务差异化分配，XFA 在认证前强制跨帧一致，CRS 决定何时值得停下来刷新标定。共享状态 `ζ_cd=(CalCert, a_cal, p*, alloc, xfa_state, refresh_plan, mode_cd)`。**CHM 回答"地基现在多可信"，UPE 回答"这份不可信会怎样吃进证书"，PCL/DPA 回答"这个任务该用哪档定位"，XFA 回答"多个眼是否在说同一件事"，CRS 回答"何时值得停一条控制线去重标定"**。它们不是六个补丁，而是"标定—传播—分级—分配—仲裁—刷新"的实现链。

## 1. 研究问题（轮次升级版）

- **Q1（标定证书与膨胀传播）**：如何估计并界定 `δ_cal`，使其既满足 `δ_cal ≥ 真实误差`（不漏）又不把缝全部撑爆（不过度保守）？SE(3) 的平移+旋转协方差如何用统一半径 `δ = δ_t + r_max·δ_θ` 投影到工作空间集合的膨胀？`E_cal` 外的证书如何整段作废而非局部修补？非凸 `Pre/Post` 与球膨胀的交如何保持可计算？
- **Q2（定位等级格与差异化分配）**：定位等级的四元偏序 `(ε,τ,r,c)` 如何定义、如何比较"覆盖"？"精度—标定新鲜度—成本"如何统一成一个可解的分配代价？逐任务/逐区域分配是否会引入区域边界振荡，如何用迟滞与锁定窗抑制？需求等级高于可达等级时是拒绝还是降级，二者边界何在？
- **Q3（跨帧一致与均值禁止）**：多模态帧间差异的容许域如何随各自 `δ_i` 与传播项展开为 `D_ij`？不一致时如何确定性地映射为"等级下调"而非"融合出更准的假象"？为何在证书体系里"取平均"会制造无人背书的伪证书？
- **Q4（标定刷新、活性与正交退化）**：刷新收益（避免的证书失效损失）与刷新成本（主动激励运动、停机）如何权衡？标定阶梯 `FRESH→DEGRADED→SUSPEND→v17` 如何与 v17 的新鲜度阶梯 `FULL→PREFIX→V16→V15` 正交组合而不跨级拼接？标定年龄与计划年龄能否共用一个衰减函数？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P33）

**P31 标定即证书律（Calibration is a Certificate, Not a Constant）**
任何空间证书（`NC_n`、`SC_i`、v16 的 `spatial_cert`）都携带一张 CalCert `(T̂_HE, Σ_cal, t_cal, E_cal)`；证书仅在当前状态落入 `E_cal` 时有效，且所有集合必须按传播不确定度膨胀：`Cert^δ = Cert ⊕ B(δ)`，其中 `δ ≥` 标定误差上界估计。**膨胀只许放大、不许缩小**；`E_cal` 外或 CalCert 过期 ⇒ 整张证书作废（`⊥`），不得用局部补丁续命。

**P32 定位等级匹配律（Positioning Tier Must Match Task Demand）**
每个节点带需求等级 `p_n`，系统只允许执行满足 `p_n ≤ p*` 的节点，其中 `p*` 是 DPA 由当前 CalCert 有效的模态分配得到的可达等级。**等级不匹配只能拒绝或降级，绝不允许"用补偿算法硬做"**；定位资源按任务/区域差异化分配，禁止全局单一档位。

**P33 跨帧一致律（Cross-Frame Consistency Before Certification）**
认证前必须通过 XFA：对任意两模态 `i,j`，其公共帧下差异 `d_ij` 必须落入 `D_ij = B(δ_i + δ_j + δ_prop)`；任一配对不一致即禁止融合、禁止取均值，只能把 `p*` 下调到仍存在"单模态自洽"的最高档。**不一致帧的均值不产生新证书，只产生无人背书的伪证书**。

## 3. 与基线的接口（如何退化）

- CHM 失效（无法估计 `T_HE`）⇒ 按最坏情况 `Σ_cal=∞` 处理，所有空间证书作废 ⇒ 仅执行不依赖空间精度的反应式节点 ⇒ **等价 v17（更保守）**；
- UPE 失效（膨胀不可计算）⇒ 拒绝一切含 `Pre/Post` 空间约束的计划节点 ⇒ **等价 v17（单步/反应式）**；
- PCL/DPA 失效 ⇒ 退回单一定位源（历史最强模态）并取保守档 ⇒ **等价 v17（活性下降）**；
- XFA 失效 ⇒ 只允许单模态、且要求该模态自洽 ⇒ **等价 v17（无融合）**；
- CRS 失效 ⇒ 固定周期强制刷新 + 到龄停机 ⇒ **等价 v17（更多停机）**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v6 退化链退回；
- **安全继承**：CHM 只提供界、UPE 只膨胀、PCL 只分级、DPA 只降配、XFA 只拒绝、CRS 只提前刷新；六端口互不相交，均不能缩小 δ、提升等级、新增节点或放宽任何阈值；`Exec_v18⊆Exec_v17` 由引理 148 保证。

## 4. 预期贡献

1. **标定诚实性**：首次把"手眼标定"从一次性常量改写为随每张空间证书传播的 CalCert，证明标定误差在膨胀机制下**先损失活性、后损失安全**，填补"证书体系默认标定精确"的系统性盲区；
2. **不确定度传播到缝**：给出 `SC_i^δ=Post_i^δ∩Pre_{i+1}^δ` 的体积随 δ 单调收缩，使 v17 的"计划缝证书"在漂移下自动变严，而不是自动失真；
3. **差异化定位格**：把"定位精度"从标量升级为四元偏序等级，把"多传感器融合"改写为"按任务匹配"，并证明"更准但标定过期"可被严格支配；
4. **跨帧一致与均值禁止**：形式化"不一致帧取均值会生成无人背书的伪证书"，把融合从"提高精度"降格为"只在一致域内允许的证书合成"；
5. **标定刷新阶梯**：把"何时重标定"改写为收益/成本决策与四级单调阶梯，使标定维护与 v17 计划新鲜度正交解耦；
6. **空间层与语言/行为层分离**：v12 管"允许什么"，v13 管"时限内实现多少"，v15 管"技能扩散"，v16 管"全身行为"，v17 管"语言计划编译调度"，v18 管"空间证据是否诚实"，用 `Exec_v18⊆Exec_v17⊆Exec_v16⊆…⊆Exec_v12` 把空间、语言、行为、路线、动力学、实时、蒸馏全解耦；E711–E730 覆盖标定覆盖、膨胀正确、缝收缩、等级匹配、跨帧一致、刷新、消融与端到端。

## 5. 本轮最大风险

**一句话**：CalCert 的 `δ_cal` 界本身来自标定，而标定误差在**未激励的自由度方向**上可能被系统性低估（可观测性缺口、退化位形、激励不足），于是证书宣称 `δ` 很小、实际某方向误差很大，膨胀不足导致缝证书虚假非空——即"证书之所以自证诚实，恰恰因为它从未被能揭穿它的运动检验过"。

# IP-415 Calibration Health Monitor：标定证书
class CalibrationHealthMonitor:
    def __init__(self, init_cert, kappa, max_age):
        self.cert = init_cert          # (T_hat, Sigma, t_cal, E_cal)
        self.kappa = kappa             # chi2 分位
        self.max_age = max_age
        self.residuals = deque()

    def observe(self, obs, T_base_hand):
        # 基准标记/接触探针给出的 T_base_eye 观测；AX=XB 残差
        T_hat_eye, Sigma_obs = self.estimate_from_obs(obs)
        r = se3_residual(self.cert.T_hat, T_hat_eye)
        self.residuals.append(r)
        if cusum(self.residuals) > self.kappa:
            self.cert = self.refit(obs)          # 漂移：重拟合
        self.cert.Sigma = fuse(self.cert.Sigma, Sigma_obs)
        self.cert.E_cal = envelope(self.cert.T_hat, self.cert.Sigma, self.kappa)
        self.cert.t_cal = obs.t

    def cert_now(self):
        if now() - self.cert.t_cal > self.max_age:
            return STALE                          # 过期 ⇒ 整张作废
        if not self.cert.E_cal.contains(self.current_T()):
            return INVALID                        # 包络外 ⇒ 作废
        return self.cert


# IP-416 Uncertainty Propagation Engine：把 δ 灌进证书集合
class UncertaintyPropagationEngine:
    def __init__(self, r_max):
        self.r_max = r_max                        # 机械臂最大半径

    def delta(self, cal_cert, loc_sigma):
        d_t = 3.0 * sqrt(trace(cal_cert.Sigma[:3, :3]))
        d_r = 3.0 * sqrt(trace(cal_cert.Sigma[3:, 3:]))
        return d_t + self.r_max * d_r + 3.0 * sqrt(trace(loc_sigma))

    def inflate(self, cert_set, delta):
        return [inflate_point(x, delta) for x in cert_set]   # X ⊕ B(delta)

    def propagate(self, nc, cal_cert, loc_sigma):
        d = self.delta(cal_cert, loc_sigma)
        return NCTuple(
            Pre=self.inflate(nc.Pre, d), Run=self.inflate(nc.Run, d),
            Post=self.inflate(nc.Post, d), Fallback=self.inflate(nc.Fallback, d),
        ), d


# IP-417/IP-418 定位证书格与差异化分配
class PositioningCertificateLattice:
    LATTICE = {'fine': 0, 'standard': 1, 'coarse': 2}   # 越小越严

    def dominates(self, supply, demand):
        # supply 覆盖 demand：精度更小、延迟更低、冗余更多、帧一致更强
        return (supply.acc <= demand.acc and supply.lat <= demand.lat
                and supply.red >= demand.red and supply.frame >= demand.frame)

    def achievable(self, alloc_pairs):
        return lub([p_m for (p_m, _) in alloc_pairs])       # 上确界


class DifferentiatedPositioningAllocator:
    def __init__(self, modalities, lambda_exposure, budget):
        self.M = modalities
        self.lam = lambda_exposure
        self.budget = budget

    def allocate(self, demand, cal_cert, a_cal):
        feasible = []
        for m in self.M:
            cal = m.cal_cert
            if cal is STALE or cal is INVALID:
                continue                                # 过期/包络外直接禁用
            if not self.pcl.dominates(m.supply, demand):
                continue                                # 供给侧不覆盖需求侧
            cost = m.cost + self.lam * exposure(m.supply.cal, a_cal)
            if cost <= self.budget:
                feasible.append((m, cost))
        if not feasible:
            return None                                 # ⊥：拒绝或降级
        # 最小代价 + 冗余约束；故意可能选更粗但更新的模态
        return min_cost_matching(feasible, demand)


# IP-419 Cross-Frame Auditor：不一致禁止融合
class CrossFrameAuditor:
    def audit(self, measurements, cal_certs, loc_sigmas):
        # measurements: [(frame_id, x_m, Sigma_m)]
        for (i, xi, Si) in measurements:
            for (j, xj, Sj) in measurements:
                if i >= j:
                    continue
                dij = frame_distance(xi, xj)
                Dij = 3.0 * sqrt(trace(Si + Sj)) \
                    + self.upe.delta(cal_certs[i], loc_sigmas[i]) \
                    + self.upe.delta(cal_certs[j], loc_sigmas[j])
                if dij > Dij:
                    return DISAGREE, (i, j)             # 禁止融合、禁止均值
        return AGREE, fuse_only_within_intersection(measurements)


# IP-420 Calibration Refresh Scheduler：刷新收益/成本
class CalibrationRefreshScheduler:
    def __init__(self, cost_refresh, hazard):
        self.cost = cost_refresh
        self.hazard = hazard                       # 年龄→失效风险

    def decide(self, a_cal, task_value):
        expected_loss = self.hazard(a_cal) * task_value
        return 'refresh' if expected_loss > self.cost else 'continue'

    def ladder(self, a_cal, xfa_ok, drift):
        if drift or not xfa_ok:
            return 'SUSPEND'                       # 第 3 级：停定位依赖任务
        if a_cal > self.max_age * 0.7:
            return 'DEGRADED'                      # 第 2 级：仅高冗余模态
        return 'FRESH'                             # 第 1 级


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v18（空间可信层）
def metricvoicegauge_round_18_calibrated_positioning(M, s, obs, ...):
    # ---- CHM：标定证书（低频，但在每个关键路径前读取）----
    cal = ctx.chm.cert_now()
    if cal in (STALE, INVALID):
        cal = CalCert.worst_case()                 # 最坏情况：空间证书全作废

    # ---- XFA：多模态先一致，再谈定位 ----
    xfa_ok, fusion = ctx.xfa.audit(obs.multi, ctx.cal_certs, ctx.loc_sigmas)

    # ---- PCL/DPA：差异化定位分配 ⇒ p* ----
    alloc = ctx.dpa.allocate(ctx.demand, cal, now() - cal.t_cal)
    p_star = ctx.pcl.achievable(alloc) if alloc else MIN_TIER

    # ---- UPE：把 δ 灌进 v16/v17 的证书 ----
    nc_delta, delta = {}, 0.0
    for n, nc in ctx.v16_nc.items():
        nc_delta[n], delta = ctx.upe.propagate(nc, cal, ctx.loc_sigma)
    ctx.psv.use_inflated(nc_delta, margin_sc + delta)   # v17 缝证书改用膨胀集

    # ---- v17 原路径（CLP/S2C/HCG/PSV/APS），门控加上 p_n ≤ p* ----
    ctx.aps.poll(now(), obs, m_star, h_max, ctx.clp, ctx.hcg,
                 ctx.s2c.with_tier(p_star), ctx.psv)
    plan_nodes, rung = ctx.aps.current(now(), drift)

    # ---- P32：等级不匹配只能拒绝/降级，不许硬做 ----
    if plan_nodes is not None:
        plan_nodes = [n for n in plan_nodes if ctx.pcl.demand(n) <= p_star]
        if not plan_nodes:
            rung = 'V16_DEFAULT'

    action, ... = ctx.csc.schedule(x=obs, plan_nodes=plan_nodes, ...)
    tau_cmd = ctx.wbc.compute_control(obs, task_spec=action)
    execute(tau_cmd if h_exec > 0 else fb)

    # ---- CRS：刷新决策（不阻塞控制环），阶梯与 v17 正交 ----
    if ctx.crs.decide(now() - cal.t_cal, ctx.task_value) == 'refresh':
        ctx.crs.request_active_calibration()       # 后台激励序列
    ctx.cad_rung = ctx.crs.ladder(now() - cal.t_cal, xfa_ok, drift)

    C, spatial_cert, claims, metrics, rewards = M.inherited_v17_path(ctx)
    return C, spatial_cert, claims, metrics, rewards

## 3. 推导

**引理 143（标定膨胀的诚实性）** 设 `Cert^δ = Cert ⊕ B(δ)`，且 `δ ≥ δ_cal`（真实标定误差上界）。则对真实坐标系下任意可达状态 `x`，必有 `x ∈ Cert^δ`；且 `δ` 越大 `Cert^δ` 只增不减（`δ₁ ≤ δ₂ ⇒ Cert^{δ₁} ⊆ Cert^{δ₂}`）。反例：若令 `δ=0`（忽略标定误差），则存在标定误差 `T_HE ≠ T̂_HE` 使某 `SC_i = Post_i ∩ Pre_{i+1} = ∅` 却被误判为非空，从而计划被错误接受。证明：对任意 `x ∈ Cert`（真实坐标系），估计坐标系中其像与 `x` 的偏差 ≤ δ_cal ≤ δ（SE(3) 度量经 `r_max` 折算为工作空间欧氏上界），故 `x ∈ Cert ⊕ B(δ)`；单调性由膨胀算子的包含单调性直接得到。∎ 推论：**膨胀把"自信地错"转成"保守地少能做"；证书可以变笨，不能变错**。

**引理 144（差异化定位匹配的保守性）** 设 DPA 只分配 CalCert 有效且供给覆盖需求（`π_m ⊒ p_n`）的模态，系统只执行满足 `p_n ≤ p*` 的节点，且不匹配时只拒绝/降级、绝不用补偿算法硬做。则 `Exec_v18 ⊆ Exec_v17`，且等级替换不会放宽任何证书。证明：每个定位等级的证书集构成链（`fine ⊆ standard ⊆ coarse` 的执行许可意义下），DPA 的输出是各有效模态供给的下确界再取上确界，只可能缩小可执行节点集；"拒绝/降级"是集合减法。任何"补偿"（用高精度算法弥补低级模态）都会试图逆转这一包含关系，被 P32 明令禁止。∎ 推论：**差异化分配的收益只能来自"用对档位省钱/降暴露"，不能来自"用低档位冒充高档位"**。

**引理 145（跨帧一致性与均值伪证书）** 若 XFA 要求所有配对 `d_ij ≤ δ_i + δ_j + δ_prop` 才允许融合，则融合结果至少被一个真实帧的膨胀证书覆盖；若忽略该检查直接对不一致帧取加权均值，则存在实例使均值 `x̄ ∉ ⋃_i (x_i ⊕ B(δ_i))`，即均值证书不被任何单一帧背书。证明：一致时各 `x_i ⊕ B(δ_i)` 两两相交，其公共交集非空且被每个帧覆盖；不一致时（如两帧沿某轴相距超过各半径之和），两球的凸包中点可落在两球之外，而加权均值正落在该凸包内，故不属于任一球的并，产生"看起来更准、实则无背书"的伪证书。∎ 推论：**融合只能合成一致域内的证书；不一致时唯一诚实的操作是降级到单模态，而不是平均出更小的协方差**。

**引理 146（标定刷新阶梯的单调退化）** 设 `CAL_Ladder` 为 `FRESH→DEGRADED→SUSPEND→v17`，每级只移除模态/节点、从不新增，且刷新决策在 `U_refresh>0` 时触发。则在 Exec 集意义下 `Exec(第 j+1 级) ⊆ Exec(第 j 级)`，无跨级、无拼接，且刷新的期望损失不高于"永不刷新"。证明：DEGRADED 只保留 `red_m ≥ r_min` 的高冗余模态（模态集子集）；SUSPEND 停用一切依赖空间精度的任务（节点集子集）；v17 是上一轮已验证的退化路径。刷新决策由 `E[避免损失] > C_refresh` 给出，按定义在期望意义下不劣于不刷新；状态机禁止跨级，故不产生拼接。∎ 推论：**标定维护的代价被显式计入决策，不会以"秘密地降低证书质量"的方式隐性支付**。

**引理 147（漂移下缝证书的单调收缩）** 设 `SC_i^δ = Post_i^δ ∩ Pre_{i+1}^δ`，`δ` 随标定漂移单调不减。则 `vol(SC_i^δ)` 关于 δ 单调不增；一旦 `vol(SC_i^δ) < margin_sc^δ`，v17 的 `PC(π)` 预验失败，计划被截断。故漂移导致的第一个失效模式是**活性下降**，而非不安全执行。证明：`δ₁ ≤ δ₂ ⇒ SC_i^{δ₂} ⊆ SC_i^{δ₁}`（引理 143 的包含单调性），体积单调不增；`PC` 含 `vol(SC_i) ≥ margin_sc` 合取项，条件破坏即整条计划不被接受，v17 的 APS 退到 `PREFIX/V16_DEFAULT`（引理 140），只截短不新增。∎ 推论：**长计划是标定漂移的"金丝雀"：它先变得不可行，从而在变得危险之前提醒系统去重标定**。

**引理 148（空间可信层的不可扩性与总继承）** 若 CHM 只输出界、UPE 只膨胀、PCL 只分级、DPA 只降配、XFA 只拒绝、CRS 只提前刷新，且六者均不能缩小 δ、提升等级、新增节点或放宽阈值，则对任意标定误差、模态分化与对抗输入，`Exec_v18 ⊆ Exec_v17`，且空间层新增授权基数 `|NewAuth| = 0`。证明：UPE 膨胀使 `NC^δ ⊇ NC`、`SC^δ ⊆ SC`，故任何 v18 可接受计划在 v17 下也可接受（证书更紧或相等）；PCL/DPA 只做节点过滤与等级降配（集合减法）；XFA 只在不一致时拒绝（集合减法）；CRS 只提前或推迟刷新，不改变 v17 的接受规则。六端口无任何"写回证书/放宽阈值/新增锚"的通道。∎ 推论：**空间层失效的唯一方向是活性下降；v18 把"标定不可信"从安全问题降级为"可执行任务变少"的可用性问题**。

## 7. 已知风险与失效模式

1. **可观测性缺口导致 δ 低估**：标定只在被激励的自由度上准确，未激励方向误差大而 `Σ_cal` 小。缓解：主动激励位形、可观测性分析、按方向分别建界、保守先验。
2. **过度膨胀使计划不可行**：δ 保守化可能让缝体积长期低于 margin，系统退化为 v17。缓解：方向分解膨胀（各向异性）、任务子空间投影、按证书族分级 δ。
3. **模态供给标称值虚高**：`π_m` 的标称精度与真实不符，DPA 误配。缓解：供给等级也由实测证书给出、周期审计、与 XFA 交叉校验。
4. **区域边界振荡**：逐区域差异化分配在边界反复切换。缓解：迟滞、分配锁定窗、平滑代价、边界统一取严档。
5. **SE(3) 膨胀不可计算**：非凸集合与球膨胀的精确交代价高。缓解：凸包/区间包络、预计算查表、保守外近似。
6. **标定刷新打断任务**：主动标定需激励运动，可能与任务冲突。缓解：在无计划窗/低价值时段刷新、CRS 收益评估、可中断激励。
7. **跨帧一致的公共帧本身漂移**：`D_ij` 依赖各帧 CalCert，若公共帧未标定则一致域虚大。缓解：公共帧强制携带 CalCert、递归一致性检查。
8. **均值禁用导致保守**：不一致时拒绝融合会降低精度与活动性。缓解：优先修复一致性（更好标定/更近观测），而非放宽检查。
9. **标定年龄与任务价值耦合**：高价值任务可能诱使绕过刷新。缓解：刷新决策与任务价值分离的硬上限、包络外一律作废。
10. **CHM 被对抗观测污染**：伪造基准标记/诱导错误 AX=XB。缓解：观测签名、多源交叉、异常残差剔除、人工审计。
11. **与 v17 新鲜度阶梯的交互**：计划新鲜与标定新鲜是两个衰减，可能一个说 FULL 一个说 SUSPEND。缓解：取两者更严（`min` 语义），禁止两阶梯交叉拼接，显式状态机。
12. **计算/维护成本**：CHM 重拟合与主动标定占用算力与时间。缓解：低频、增量估计、隔离进程、按需触发。

## 8. 本轮最大风险

**一句话**：CalCert 的 `δ_cal` 界本身来自标定，而标定误差在**未激励的自由度方向**上可能被系统性低估（可观测性缺口、退化位形、激励不足），于是证书宣称 `δ` 很小、实际某方向误差很大，膨胀不足导致缝证书虚假非空——即"证书之所以自证诚实，恰恰因为它从未被能揭穿它的运动检验过"。
