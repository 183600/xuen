# 第 10 轮（新灵感循环；本轮灵感：「通信延迟」×「竞赛策略」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**时延年龄化 + 悲观退化 + 策略从属**。v9 把"模块失效"坍缩为聚合恒等元，隐含假设"没有证据 = 没有风险"；但通信延迟让输入变"旧"而非"缺席"，旧证据在安全方向上必须按最坏情况处理。v9 又假设单机同步、策略与安全未分层；竞赛场景下必须证明"策略即便恶意也害不了安全"。本轮以三条新律治理这两个盲点：**P13 失效不对称**、**P14 时延膨胀**、**P15 策略从属**。

## 0. 直觉与动机

**灵感 1（通信延迟 → 年龄化信息与悲观中立元）**
直觉：延迟不是丢包，而是信息变老。v9 的中立元 v^⊥ 是聚合恒等元，对性能模块合理，对安全模块却危险：DA-ML 超时注入 Δ_dom≡0 等于宣布"没有域偏移"，SPR 超时注入 risk≡0 等于"SLAM 很稳"——这是把"我不知道"误读成"一切正常"。严格的跨学科做法是把延迟当"证据时效"问题：每条输入携带时间戳与来源，定义年龄 a(t)；安全相关模块的失效/陈旧映射到**最坏方向**的悲观中立元 v^⊥_pess（DA→Δ_dom=1，SPR→risk=1，标定→最大不确定度），只有性能模块才允许恒等元。由此得到核心性质：**时延只会让可行选项集单调收缩，绝不会把不安全的选项放进来**（引理 87）。同时把 AC 的块证书与停车不变式按"观测时延 + 执行时延"膨胀（引理 88），并让分布式契约表用安全方向的 meet 联结（引理 89）。

**灵感 2（竞赛策略 → 策略是选择器，不是控制器）**
直觉：竞赛会诱导冒险——剩余时间少、比分落后时想"赌一把"。若策略与安全共享同一控制通道，一次糟糕的策略就可能直接变成碰撞。正确分层是：安全层定义**认证选项集 O_cert**（所有证书有效、停车不变式成立、硬安全边际不低于地板），策略层只能在 O_cert 内做选择/排序/预算分配；风险预算 ρ 只调"软阈值"（舒适度、效率），永远不能突破硬地板。于是有"策略不可害"定理（引理 90）：无论策略是学出来的、被污染的、还是对抗性的，投影 Π_cert 都保证执行 ∈ O_cert，策略错误只体现在分数上。再把"等新数据 vs 立即行动"形式化为**新鲜度价值**（VoF）：只有当等待带来的期望分数增益超过等待成本时才等，否则用当前年龄膨胀证书行动（定义 548、引理 91）。

**灵感 3（二者耦合 → 时延下的策略机会成本）**
直觉：通信延迟不只在感知层，也在"比分板、队友状态、裁判指令"上；更关键的是，延迟会收缩 O_cert，从而改变策略的最优选择。我们用**时延-分数机会成本**度量"安全护盾在坏网络下让出多少分"（定义 549）：它不是安全代价，而是可量化的性能代价，用来判断该投资通信冗余还是投资本地感知。竞赛策略因此从"拍脑袋的冒险"变成"在单调收缩的认证集合上做带时间预算的在线选择"。

## 1. 研究问题（轮次升级版）

- **Q1（单调退化）**：如何为每个模块定义安全极性与悲观中立元，使"陈旧/失效"在任意延迟分布下只收缩可行集、不产生虚假乐观？该单调性对时钟漂移与不可测时延是否鲁棒？
- **Q2（时延证书）**：在观测时延 L_obs、执行时延 L_act 有界（≤ L_max）时，块证书与停车不变式如何膨胀才能在数学上保持"中块突变零碰撞"？分布式契约表在分区/重排序下如何收敛到安全侧？
- **Q3（策略从属）**：如何把竞赛策略限制为 O_cert 上的选择器，使任意策略（含对抗策略）不破坏硬安全？护盾相对无约束最优的机会成本有多大，VoF 门限能否逼近一步最优？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 失效不对称律（Absence ≠ Optimism, SC）**
输入失效/陈旧 ≠ 该输入取聚合恒等元。对安全单调输入，失效必须映射到**悲观中立元** v^⊥_pess：在其年龄允许的可能取值域上取风险最大的值（DA→Δ_dom=1，SPR→risk=1，标定→最坏权重区间，OTL→收紧阈值）。只有 φ^perf=true 的性能模块才允许恒等元。由此，"不知道"一律向右（保守）偏，而不是向左（乐观）偏。

**P14 时延膨胀律（Delay-Inflated Certification, DCC）**
证书与停车不变式必须覆盖最坏时延：ĝ_min 扣除 β(a) 与 d_lat(L_obs,L_act)；停车不等式加入同一 d_lat。若 L_obs+L_act > L_max 或消息截止期被错过，立即 K_eff←1 并进入安全保持，不得"边猜边跑"。分布式契约表以安全 meet ⊓ 联结，分区期间只用各自最保守版本。

**P15 策略从属律（Strategy Subordination, SS）**
策略是 O_cert 上的选择器，不是控制器的替代品。策略动作 σ=(o,ρ,b) 先经护盾投影 Π_cert；ρ 只能缩放软阈值 τ_eff/舒适速度，硬地板 d_safe、M₀ 硬检查、SpatialCert、FaultCert 不受 ρ 影响。策略失效 ⇒ 固定选择"保证分数下界最高的安全选项"，而非放宽安全约束。

## 3. 与基线的接口（如何退化）

- SC 失效（年龄不可测）⇒ 所有输入按 age=∞ 处理 ⇒ 悲观中立元 ⇒ O_cert 仅剩安全保持/停驻；这比 v9 Level-1 更保守，属安全侧加细，非逐位等价；
- DCC 失效或时延不可测 ⇒ K_eff←1、L_max←保守上界、d_lat←最大，逐步执行并入停车；
- SS 失效 ⇒ 固定安全策略（O_cert 中保证分数下界最高者），不改变 O_cert；
- v9 的 AC/MW/ID 失效 ⇒ 沿 v9 五级链退回 v8；
- 全部失效 ⇒ 退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

> **与 v9 引理 83 的关系**：v9 要求"失效 ≡ v8 恒等中立元"；本轮明确指出该要求在安全输入上是**错误的等价目标**。P13 将其修正为"失效 ≡ 安全方向上最保守元"，这是 v9 退化链的**安全侧加细**：任何 v8 可接受的行为在新链中仍可接受，但旧链可能乐观放行的陈旧输入被新链拒绝。逐位等价只对性能模块保留，安全模块改为"保守支配"（引理 87）。

## 4. 预期贡献

1. **年龄化信息模型 + 悲观中立元**：把"通信延迟"从工程噪声升级为可证明的单调退化律，并诚实修正 v9 的"失效=恒等"盲点；
2. **时延膨胀证书与分布式契约安全联结**：有界时延下分块执行零碰撞，分区/重排序下契约收敛到安全侧；
3. **策略从属与竞赛护盾**：首次把"策略不可害"作为可证明性质，量化安全护盾的分数机会成本与 VoF 门限；
4. **实验覆盖 E571–E590**：时延扫描、抖动/重排序、时钟漂移、分区重连、对抗策略、时延攻击与 RoboCup@Home 竞赛模拟。

## 5. 本轮最大风险

**一句话**：整套"年龄单调性"证明依赖 age 被正确测量，而 age 又依赖跨机时钟同步——若时钟漂移或恶意篡改使 age 被系统性低估，护盾会把过期证书误判为新鲜，系统在最需要保守的时刻反而最乐观。

# 第 10 轮产物 · MetricVoiceGauge-LSCS（Latency-aware Staleness Contracts & Strategy Shield）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「通信延迟」×「竞赛策略」。
> **继承纪律**：MetricVoiceGauge 九不变式与 v9 的 AC / MW / ID 全部保留；本轮新增的三组件一律为**可选增强**。与 v9 不同的是：对**安全单调输入**，失效不再追求"逐位等价退回 v8"，而是追求"保守支配"（P13）——这是对 v9 退化链的安全侧加细，不是行为漂移。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 v9 MetricVoiceGauge-ACMD） |
|---|---|---|---|
| IP-357 | StalenessContractor 时延-陈旧契约器（SC） | 新增核心模块 | 为每个跨节点输入附着 (t_stamp, src, seq)；按安全极性注入**悲观中立元** v^⊥_pess；产出年龄画像；分布式契约以安全 meet ⊓ 联结 |
| IP-358 | DelayCompensatedCertifier 时延补偿证书器（DCC） | 新增核心模块 | 扩展 AC：证书按 β(a) 与 d_lat(L_obs,L_act) 膨胀；停车不变式含 d_lat；时延超界立即 K_eff←1 + 安全保持；有界时延下零碰撞 |
| IP-359 | StrategyShield 竞赛策略护盾（SS） | 新增核心模块 | 策略只能在 O_cert 上选择；Π_cert 投影；硬地板不随风险预算 ρ 移动；VoF 决定"等新数据 vs 立即行动" |

**退化链声明（v10 六级）：**
- Level-0：正常 LSCS（SC + DCC + SS 全部在线）；
- Level-1：DCC 证书失效 / 时延超界 ⇒ K_eff←1，逐步执行 + 时延补偿停车，等价 v9 决策粒度但更保守；
- Level-2：SC 判陈旧 ⇒ 悲观中立元注入，O_cert 收缩（DA→Δ_dom≡1、SPR→risk≡1、Calib→最坏权重区间），比 v9 Level-1 更保守；
- Level-3：SS 失效 ⇒ 固定选择 O_cert 中分数下界最高者，安全语义不变；
- Level-4：v9 的 AC/MW/ID 失效 ⇒ 沿 v9 五级链退回 v8；
- Level-5：全失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

| x̃_i(t) = (x_i, t_i^s, src_i, seq_i, prov_i) | 带年龄信息元：值、时间戳、来源、序号、来源链 |
| a_i(t) = t − t_i^s | 信息年龄（经有界时钟漂移修正） |
| D_fresh^m ≤ D_hard^m | 模块 m 的新鲜/硬陈旧阈值；a≤D_fresh 为 fresh，≤D_hard 为 aged，否则 stale |
| pol_m ∈ {safety, perf} | 安全极性：安全单调输入 vs 仅性能输入 |
| v_m^⊥,pess | 悲观中立元：年龄允许取值域上风险最大的值 |
| β(a) = β₀ + c_β·a | 年龄膨胀的模型误差余量，随外推时域单调增 |
| L_obs, L_act, L_max | 观测时延、执行时延及其上界 |
| d_lat | 时延位移裕量（见定义 543） |
| κ_m ⊓ κ_m' | 契约安全 meet（取更保守分量） |
| O_cert(t) | 当前年龄画像与契约下的认证选项集 |
| σ_t = (o_t, ρ_t, b_t) | 策略动作：选项、风险预算、时间/能量预算 |
| Π_cert(·) | 策略护盾投影 |
| VoF(Δ) | 新鲜度价值：等待 Δ 的期望分数增益减等待成本 |
| OC_L(t) | 时延-分数机会成本 |

**新增定义 540（带年龄信息元 AgedInfo）** 每个跨节点信号写作 x̃_i(t)=(x_i, t_i^s, src_i, seq_i, prov_i)。年龄 a_i(t)=max(0, t−t_i^s)+ε_clk，其中 ε_clk 为有界时钟漂移修正项。新鲜度：
```
fresh  ⇔ a_i ≤ D_fresh^m
aged   ⇔ D_fresh^m < a_i ≤ D_hard^m
stale  ⇔ a_i > D_hard^m
```
provenance 链 prov_i 记录数据经过的节点与变换，用于检测"旧数据被当作新数据转发"（time-travel 攻击）。

**新增定义 541（安全极性与悲观中立元 SafetyPolarity）** 对模块 m 的输出 y_m，若其取值越大（或越不确定）系统越不安全，则 pol_m=safety；否则 pol_m=perf。定义其在年龄 a 下的可能域 Y_m(a)，并要求 Y_m(a) 随 a 单调扩张。悲观中立元
```
v_m^⊥,pess(a) = argmax_{y ∈ Y_m(a)} risk(y)
```
默认赋值：DA-ML→Δ_dom=1（最大域偏移）；SPR→risk_SLAM=1；Calib-FI→最坏标定权重区间（等价收紧 τ_i）；OTL→阈值收紧 δ(a)；ID/ER/性能模块→恒等元（v9 语义保留）。

**新增定义 542（年龄膨胀证书 Age-Inflated Certificate）** 由冻结前向模型 F̂ 预测、并扣除年龄与网络时延的余量：
```
β(a)   = β₀ + c_β · min(1, a/L_max)
ĝ_min  = min_{k≤K} F̂_clearance(s, a^{1:k}) − β(a) − d_lat
ê_max  = max_{k≤K} F̂_effort(s, a^{1:k}) + β(a) + e_lat
```
证书有效 ⇔（所有安全输入非 stale）∧ ĝ_min ≥ d_safe ∧ ê_max ≤ τ_eff(a) ∧ γ̂_grasp=valid ∧ L_obs≤L_max ∧ L_act≤L_max。τ_eff(a) 随年龄单调收紧。β(a) 的单调性由"外推时域越长、模型误差上界越大"保证，E576 标定 c_β。

**新增定义 543（时延补偿停车不变式 Delay-Compensated Stop Invariant）** 前缀索引 p∈P_t 合法当且仅当
```
d_lat = (v_max + Δv)(L_obs + L_act) + ½·a_max·(L_obs + L_act)²
d_brake(v_p) + d_lat + d_safe ≤ dist(s_p, O) − |traj_{p:K}|
```
若 L_obs+L_act > L_max 或消息截止期已错过，则视为 L>L_max，禁止生成 K>1 块并立即执行安全保持（定义 544 的 Level-1）。

**新增定义 544（契约安全 meet Contract Safety Meet）** 两个契约版本的联结取"更保守"分量：
```
κ ⊓ κ' = (D=min, Ŵ=max, β=max, L_max=min, K_max=min, d_safe=max, uncertainty=max)
```
定义安全序 κ₁ ⪯_s κ₂ 表示 κ₁ 允许的行为集 ⊆ κ₂ 允许的行为集。⊓ 满足交换、结合、幂等，且 κ⊓κ' ⪯_s κ、κ⊓κ' ⪯_s κ'。节点以版本向量 gossip，收到即 κ←κ⊓κ'；最终所有节点收敛到全部版本的 meet。

**新增定义 545（认证选项集 Certified Option Set）**
```
O_cert(t) = { o ∈ O :
    cert_o 在当前年龄画像 a(t) 与契约 κ(t) 下有效（定义 542）
    ∧ ∀p ∈ P_o: 时延补偿停车不变式成立（定义 543）
    ∧ 硬安全边际 d_safe 与 M₀ 硬检查满足（与 ρ 无关） }
```

**新增定义 546（策略动作 StrategyAction）** σ_t=(o_t, ρ_t, b_t)：o_t 为候选技能/块，ρ_t∈[0,1] 为风险预算，b_t 为时间/能量分配。风险预算只作用软阈值：
```
τ_eff(ρ) = τ_min + ρ·(τ_max − τ_min),   v_comfort(ρ) = v_min + ρ·(v_max − v_min)
d_safe(ρ) ≡ d_safe⁰,   M₀ 硬检查 ≡ 不可调
```

**新增定义 547（策略护盾投影 Projection Shield）**
```
Π_cert(σ) = σ                         若 o_σ ∈ O_cert
          = argmax_{o ∈ O_cert} LB(score(o))   否则（安全回退，最大化保证分数下界）
```
同时把 ρ、b 投影到可行域；若 O_cert 为空，输出 hold（安全停驻）。

**新增定义 548（新鲜度价值 Value of Freshness）** 设等待 Δ 后可得新数据，o^fresh 为刷新后的最优认证选项：
```
VoF(Δ) = E[J(o^fresh)] − E[J(Π_cert(σ_t))] − c_wait(Δ)
```
仅当 VoF(Δ)>0 且剩余时间预算允许时等待；否则立即用当前年龄膨胀证书行动。

**新增定义 549（时延-分数机会成本 Delay-Score Opportunity Cost）**
```
OC_L(t) = J*(fresh, unconstrained) − J(Π_cert under a(t), L)
        = OC_safety + OC_stale
```
OC_safety 为被护盾剔除的不安全选项分数，OC_stale 为"安全但被陈旧收缩掉的选项"分数。OC_stale 是通信冗余投资的直接依据。

## 2. 形式化定义（要点与升级）

**定义 493/495/521/524（指标层级、MetaWeight、DA-OTL）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 与 5 维权重不变。
**升级定义 496（软证书，v10）**
```
δ_trigger = {σ < τ_safe(a) ∧ γ_grasp valid ∧ Δ_dom < τ_dom(a)
             ∧ risk_SLAM < τ_SLAM(a) ∧ Ĉ_t valid(定义542) ∧ a ≤ D_hard}
```
六个条件同尺度；任何输入 stale 直接使 δ_trigger 失败，等价于 M₀ 硬检查入口，杜绝"旧数据软通过、硬约束失效"的空洞。
**升级定义 531（软硬衔接，v10）** 中块守卫增加两项输入：输入年龄 a(t) 与实测 L_obs/L_act；若年龄或时延任一越界，立即切换 p* 或安全保持，不等块边界。
**升级定义 535（契约扩充）** κ_m 增加字段 (D_fresh^m, D_hard^m, pol_m, v_m^⊥,pess, provenance)。静态校验新增 Σ_m (Ŵ_m + a_m^max) ≤ B_dec 与 L_max 可行性。
**升级定义 537/538（ID 抗陈旧）** 归因只用 fresh 回合结果；若结果 age > D_fresh^outcome，则该回合不更新 c_m，避免"延迟奖励"污染蒸馏状态机；唤醒路径仍由 Δ_dom 越阈即时触发。

# IP-357 StalenessContractor：时延-陈旧契约器
@dataclass
class AgedInfo:
    value: object; t_stamp: float; src: str; seq: int; prov: tuple

    def age(self, now, skew_bound):
        return max(0.0, now - self.t_stamp) + skew_bound

class StalenessContractor:
    def __init__(self, contracts, clock):
        self.contracts = contracts
        self.clock = clock

    def sanitize(self, name, x_tilde, now):
        c = self.contracts[name]
        a = x_tilde.age(now, self.clock.skew_bound)
        if a <= c.d_fresh:
            return x_tilde.value, a, 'fresh'
        if a <= c.d_hard:
            # 年龄膨胀：性能模块恒等，安全模块向保守侧插值
            return c.inflate(x_tilde.value, a), a, 'aged'
        # P13：安全输入 -> 悲观中立元；性能输入 -> 恒等元
        if c.polarity == 'safety':
            return c.pessimistic_neutral(a), a, 'stale'
        return c.identity, a, 'stale'

    def safety_join(self, k1, k2):
        return Contract(
            deadline_ms=min(k1.deadline_ms, k2.deadline_ms),
            wcet_ms=max(k1.wcet_ms, k2.wcet_ms),
            beta=max(k1.beta, k2.beta),
            l_max=min(k1.l_max, k2.l_max),
            k_max=min(k1.k_max, k2.k_max),
            d_safe=max(k1.d_safe, k2.d_safe),
            version=max(k1.version, k2.version))

    def join_all(self, versions):
        k = versions[0]
        for v in versions[1:]:
            k = self.safety_join(k, v)
        return k


# IP-358 DelayCompensatedCertifier：时延补偿证书器（扩展 v9 AC）
class DelayCompensatedCertifier(ActionChunkCertifier):
    def __init__(self, forward_model, policy, K_max=10, beta0=0.02,
                 c_beta=0.03, l_max=0.08, a_max=2.0, v_max=1.0,
                 d_safe=0.15, dt=0.02):
        super().__init__(forward_model, policy, K_max, beta0, d_safe, dt=dt)
        self.beta0, self.c_beta = beta0, c_beta
        self.l_max, self.a_max, self.v_max = l_max, a_max, v_max

    def latency_margin(self, l_obs, l_act):
        l = min(l_obs + l_act, self.l_max)
        return (self.v_max * l) + 0.5 * self.a_max * l * l

    def beta_of_age(self, age):
        return self.beta0 + self.c_beta * min(1.0, age / self.l_max)

    def build_cert(self, state, cand, age, l_obs, l_act):
        beta = self.beta_of_age(age)
        d = self.latency_margin(l_obs, l_act)
        pred = self.F.rollout(state, cand)
        g_min = pred.min_clearance - beta - d            # 定义 542
        e_max = pred.max_effort + beta + d
        valid = (g_min >= self.d_safe
                 and e_max <= state.tau_eff
                 and l_obs <= self.l_max and l_act <= self.l_max)
        return Cert(g_min, e_max, d, valid)

    def _abort_points(self, state, actions, pred, d):
        pts = []
        for p in range(1, len(actions)):
            margin = (pred.clearance[p] - self.d_brake(pred.speed[p])
                      - d - self.d_safe)
            if margin >= pred.path_len[p:]:              # 定义 543
                pts.append(p)
        return pts

    def generate_chunk(self, state, age, l_obs, l_act, trust_ok):
        if (not trust_ok) or l_obs > self.l_max or l_act > self.l_max:
            return self._single_step_fallback(state)     # Level-1
        K = self.effective_K(age / self.l_max, 1.0, trust_ok)
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            cert = self.build_cert(state, cand, age, l_obs, l_act)
            if not cert.valid:
                continue
            pts = self._abort_points(state, cand, self.F.rollout(state, cand),
                                     cert.d_lat)
            if not pts:
                continue
            score = self.policy.score(cand)
            if best is None or score > best.score:
                best = Chunk(cand, cert, pts, score)
        return best or self._single_step_fallback(state)


# IP-359 StrategyShield：竞赛策略护盾
class StrategyShield:
    def __init__(self, certifier, objective):
        self.certifier = certifier
        self.objective = objective

    def certified_options(self, state, age, l_obs, l_act, contract):
        opts = []
        for o in self.objective.candidate_skills(state):
            cert = self.certifier.build_cert(state, o.actions, age, l_obs, l_act)
            if cert.valid and o.stop_invariant_ok(cert.d_lat):
                opts.append((o, cert))
        return opts

    def project(self, proposal, options):
        if not options:
            return ('hold', None)
        if any(proposal.option == o for o, _ in options):
            return ('act', proposal)
        # 安全回退：最大化保证分数下界，而非期望分数
        best = max(options, key=lambda oc: self.objective.lower_bound(oc[0]))
        return ('act', Action(option=best[0], rho=0.0, budget=proposal.budget))

    def value_of_freshness(self, state, delta, age, l_obs, l_act, contract):
        stale_opts = self.certified_options(state, age, l_obs, l_act, contract)
        fresh_opts = self.certified_options(state, 0.0, l_obs, l_act, contract)
        if not fresh_opts:
            return -float('inf')
        now = self.objective.expected_best(stale_opts)
        fresh = self.objective.expected_best(fresh_opts)
        return fresh - now - self.objective.wait_cost(delta)

    def decide(self, state, proposal, age, l_obs, l_act, contract, delta):
        if age > contract.d_hard or l_obs > contract.l_max or l_act > contract.l_max:
            return ('hold', None)                        # Level-1/2
        opts = self.certified_options(state, age, l_obs, l_act, contract)
        if self.objective.can_wait(delta) and \
           self.value_of_freshness(state, delta, age, l_obs, l_act, contract) > 0:
            return ('wait', delta)                       # 定义 548
        return self.project(proposal, opts)

## 4. 推导

**引理 87（年龄单调性 / 延迟不可增乐观）** 设年龄向量 a' ≥ a（分量不减），且 (i) β(a) 非减，(ii) d_lat(L) 非减，(iii) τ_eff(a) 非增，(iv) 安全输入的可能域 Y_m(a) 随 a 扩张。则认证选项集单调收缩：
```
a' ≥ a  ⇒  O_cert(a') ⊆ O_cert(a)
```
即通信延迟只能移除选项，不能新增不安全的选项。证明：定义 542 中 ĝ_min 随 β、d_lat 增大而减小，ê_max 随二者增大而增大，τ_eff 随年龄收紧；定义 543 左端随 d_lat 增大而增大，满足不等式的 p 集合收缩；定义 545 是这些条件的交，故 O_cert 单调收缩。定义 541 保证 stale 时注入的是风险最大元，而非恒等元，故不会出现"陈旧反而更乐观"。∎

**引理 88（有界时延下的分块安全性）** 设 L_obs,L_act ≤ L_max，前向模型在年龄膨胀域内一致误差 ‖F̂−F‖∞ ≤ β_true ≤ β(a)，且证书与停车不变式按定义 542/543 膨胀。则任何被执行的块要么安全完成，要么在 p*∈P_t 安全停驻且终点间隙 ≥ d_safe。证明：执行时刻真实间隙 ≥ F̂ 预测 − β_true − d_lat ≥ ĝ_min + β(a) − β_true ≥ ĝ_min ≥ d_safe（第一不等式由状态估计老化与执行延迟造成的最大位移 d_lat 界定）。停驻侧：刹车指令生效延迟 ≤ L_act，d_lat 已同时覆盖 L_obs 与 L_act 的位移，故 d_brake(v_p)+d_lat+d_safe ≤ 余量 ⇒ 刹车终点距障碍 ≥ d_safe。时延超界时定义 543 拒绝 K>1，退化为 v9 逐步语义。∎

**引理 89（契约安全 meet 的收敛与安全）** ⊓ 为交换、结合、幂等运算；在最终送达的 gossip 下，所有节点收敛到全部契约版本的 meet κ*。且 κ* ⪯_s κ_i（∀i），故任何在 κ* 下认证的选项 o∈O_cert(κ*) 也在每个 κ_i 下认证，分区期间各节点仅用自身 κ_i 的保守子集，重连后不会放行任何节点曾判定不安全的行为。证明：meet-semilattice 的有限收敛性；安全序对分量取 min/max 保序；由定义 544，κ* 的 d_safe 不小于任一 κ_i、K_max 不大于任一 κ_i，故 O_cert(κ*) ⊆ ⋂_i O_cert(κ_i)。∎

**引理 90（策略不可害 / Strategy Non-maleficence）** 对任意策略 π（含对抗、被污染、含 bug 的策略），执行动作 Π_cert(σ_t) ∈ O_cert(t) ∪ {hold}。由引理 88，O_cert 中每个选项在年龄与时延膨胀下满足硬安全不变式；hold 为安全停驻。风险预算 ρ 只改软阈值，d_safe 与 M₀ 硬检查与 ρ 无关。故策略只能改变分数，不能造成安全违背。∎

**引理 91（VoF 一步门限与机会成本）** 在单步决策、刷新后选项集只扩不缩、等待成本 c_wait(Δ) 已知的假设下，门限规则"VoF(Δ)>0 则等、否则行动"给出该步期望分数的最大值；护盾相对无约束最优的机会成本满足
```
0 ≤ OC_L(t) ≤ max_{o∈O\O_cert} J(o) − max_{o∈O_cert} J(o)
```
且当无约束最优不安全时，下界由最优安全选项给出。故机会成本可分解为 OC_safety + OC_stale，且 OC_stale 随年龄单调增（引理 87）。证明：单步下两个动作（等/不等）的期望分数可直接比较；VoF 正是两者之差减成本，故门限最优；机会成本不等式由"被剔除集合的分数上界减去保留集合的最优"直接得到。∎
