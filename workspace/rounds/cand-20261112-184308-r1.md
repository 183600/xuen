# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC；本轮灵感：「演示数据」×「仿真训练」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 建成了「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知闭环，但它默认了一个**未言明的前提**：场景-阻抗先验 π_scene(K|z) 与意图-约束映射 ϕ 已经存在，或可在线从遥测中即时学到。真实部署中这恰恰是最脆弱的环节——**冷启动时没有任何遥测**，先验只能来自离线数据：**人类演示（真实但稀疏、且几乎只有成功样本）**与**仿真训练（稠密但存在现实鸿沟）**。若把未经接地的先验直接用于收窄 K_safe，就会把第 60 轮的「认知先行」放大成「认知误导」。本轮的核心问题因此是：**如何在执行之前，用演示+仿真获得一个「可被信任、且信任度可证」的先验？**

> 三个承接缺口：
> 1. **先验冷启动**：π_scene 的来源缺失，SSM 无法在首次接触场景前收敛；
> 2. **演示的幸存者偏差**：人类演示几乎全是成功轨迹，缺少失败模式，先验会「只见安全、不见危险」；
> 3. **仿真的现实鸿沟**：域随机化给出覆盖，却可能在与真实不同的联合分布上过自信；仿真证据若混入安全证书，会污染证据链。

## 0. 直觉与动机

**灵感 1（演示数据 → 演示阻抗签名 DIS）**
直觉：人类演示传递的不是一条轨迹，而是「在某个场景、某个意图下，多大的刚度/阻尼让人感到安全」——即**阻抗签名**。同一条轨迹在「轻触」与「加紧」两种意图下对应不同的 K_p/K_d。关键洞见：**把演示视为对 π_scene(K|z) 的正样本观测**，用逆动力学/能量回归从 (轨迹, 力矩) 反解 K_demo；但必须扣除演示者自身手臂阻抗这一「演示混淆项」，否则学到的是「人+机器人」的复合阻抗。

**灵感 2（仿真训练 → 域随机化场景先验 SRSP）**
直觉：仿真能廉价生成海量 (场景参数 θ, 阻抗 K) 对：摩擦 μ、表面刚度、坡度、质量、传感噪声都在域随机化范围内。关键洞见：**仿真给的是「覆盖」，不是「真相」**——它保证先验支撑集足够宽，但不能保证支撑集上的概率质量与真实一致。因此仿真先验只能作为**层次先验**，必须由真实演示作似然来校准。

**灵感 3（双源融合 → 演示-仿真贝叶斯融合 DSBF）**
直觉：把 π_sim 当先验、把演示当似然，做共轭高斯更新；再用「仿真-真实差异 d(z)」膨胀演示似然的方差——差异越大，越不相信演示对仿真先验的修正，也越不相信仿真先验本身。融合后的 π_fused 才是可执行的场景先验。

**灵感 4（安全护栏 → 先验接地证书 PGC）**
直觉：**先验准确 ≠ 先验可信**。一个在仿真分布上很准的先验，可能在真实分布上系统性错误。因此需要一个「接地证书」：统计先验支撑被**真实证据**覆盖的比例 c_real、仿真覆盖 c_sim、以及差异 d，输出**权威度 Auth∈[0,1]**。K_safe 的收窄幅度不得超过 Auth：Auth=0 时先验无权收窄，退回第 60 轮的保守基线。这把第 60 轮的二值护栏（scene_conf>0.7）升级为**连续、可证、单调**的接地护栏。

**灵感 5（证据溯源 → 虚拟证据隔离 VE）**
直觉：仿真 rollout 会产生大量「虚拟 EV-exec」，它们对预训练、异常检测极有价值，但**绝不能进入安全证书 J_exec**。给每条证据打 provenance ∈ {real, virtual, hybrid}，证书只聚合 real。定义「证据污染」为虚拟证据混入真实链，并以构造性方式禁止。

**灵感 6（失败合成 → 失败模式合成 FMS）**
直觉：演示只有成功样本，先验会「把没见过的失败当作不可能」。用仿真做**对抗式域随机化**：优化 θ 使接触力/滑移风险最大，合成失败样本，补上演示的「负证据缺口」。这让 SSM 的场景识别器与 CESC 的决策规则在失败邻域不过度自信。

**灵感 7（课程 → 演示-仿真课程 CST）**
直觉：先易后难地组织「场景切换×意图组合」，让 κ_scene 与 ϕ 在分布偏移从小到大中逐步稳健；课程难度直接用 d(z) 与意图歧义度排序。

**灵感 8（合流 → 演示-仿真协同认知闭环 DSSC）**
直觉：演示→DIS→π_demo；仿真→SRSP→π_sim；DSBF→π_fused；PGC→权威度门控；SERC 执行；只有真实 EV-exec 回写 c_real；差异升高则触发「补演示/补辨识」。形成**先验接地闭环**：认知先验的每一次收窄，都可追溯到真实证据的覆盖。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（演示阻抗签名 DIS）** 演示集 D = {(ξ_i, w_i, I_i, z_i)}_{i=1}^n，其中 ξ_i 为轨迹 (q, q̇, q̈)，w_i 为测量 wrench，I_i 为配对语言意图，z_i 为场景标签。在阻抗控制律 w = Φ(ξ_i) K + ε 下，签名估计：
K̂_i = argmin_K ||w_i − Φ(ξ_i)K||² + λ||K − K_0(z_i)||²，再扣除演示者手臂阻抗 H_i：K̃_i = K̂_i − H_i（||H_i|| ≤ ε_h）。
场景-意图先验 π_demo(K|z,I) = N(K; μ_demo(z,I), Σ_demo(z,I))，由 {K̃_i} 的经验贝叶斯收缩得到。

**定义 162（域随机化场景先验 SRSP）** 仿真参数 θ ~ p(θ)（μ_friction, k_surface, slope, mass, sensor_noise, latency）。训练条件映射 g_ψ(z, θ) → K，仿真先验 π_sim(K|z) = ∫ δ(K − g_ψ(z,θ)) p(θ) dθ 的光滑化。SRSP 只保证覆盖 supp(p(θ))，不保证概率质量与真实一致。

**定义 163（演示-仿真贝叶斯融合 DSBF）** 以 π_sim 为先验、演示为似然，并令似然方差随差异膨胀：
Σ_eff(z) = Σ_demo(z) + d(z)·I，
Σ_post = (Σ_sim⁻¹ + n·Σ_eff⁻¹)⁻¹，
μ_post = Σ_post(Σ_sim⁻¹μ_sim + n·Σ_eff⁻¹μ_demo)。
π_fused(K|z,I) = N(μ_post, Σ_post)。当 d(z)→∞ 时 π_fused→π_sim（演示不可信）；当 d(z)→0 且 n 大时 π_fused→π_demo。

**定义 164（证据溯源与虚拟证据隔离 VE）** 每条 EV-exec 附带 provenance ∈ {real, virtual, hybrid} 与来源标识。安全证书只聚合 real：
J_exec = Cert({e ∈ Chain : e.provenance = real})。
污染谓词 Contam(Chain) = ∃ e ∈ J_exec.chain : e.provenance ≠ real，且要求 Contam ≡ false（构造性保证）。虚拟证据仅用于预训练、残差异常检测与课程。

**定义 165（先验接地证书 PGC）** PGC(z) = (c_real(z), c_sim(z), d(z), τ_prior(z), Auth(z))，其中：
- c_real(z) = 真实证据对 π_fused 支撑的覆盖比例（核密度/置信椭球覆盖）；
- c_sim(z) = 仿真样本对支撑的覆盖比例；
- d(z) = 真实-仿真特征分布的 MMD/Wasserstein 距离；
- τ_prior(z) = σ(α·c_real − β·d − γ·(1 − c_sim))；
- Auth(z) = 0 if τ_prior < τ_trust else min(1, τ_prior)。
**门控收窄**：K_safe = K_safe^base ⊖ Auth·(K_safe^base ⊖ K_safe^prior)，即安全裕度按 Auth 在基线与先验收窄之间线性插值；Auth=0 时先验零权威。

**定义 166（失败模式合成 FMS）** 失败样本合成：θ_adv = argmax_θ risk(rollout(z, θ))（投影梯度上升），F_syn(z) = {rollout(z, θ_adv)}。失败缺口 G_fail = supp(真实失败) \ supp(D ∪ F_syn)；G_fail 越大，SIC 的 scene_conf 上限越低（负证据缺口惩罚）。

**定义 167（演示-仿真课程 CST）** 课程难度 δ(z,I) = η₁·d(z) + η₂·Ambig(I) + η₃·|z_new − z_old|；课程按 δ 升序训练 κ_scene 与 ϕ，使模型在偏移从小到大中渐进稳健。

**定义 168（演示-仿真协同认知闭环 DSSC）** 算子 DSSC(M, D, z, I, δ_f^req)：
```
① π_demo ← DIS.prior(z, I)
② π_sim  ← SRSP.prior(z)
③ d      ← Discrepancy.estimate(z, D)
④ π_fused← DSBF(π_sim, π_demo, d)
⑤ pgc    ← PGC.evaluate(z, π_fused, c_real, c_sim, d)
⑥ K_prior← EEIS.compile_with_scene_prior(π_fused, δ_f^req)
⑦ K_base ← EEIS.compile(δ_f^req, fused, ξ_exec, Z_env)
⑧ K_safe ← PGC.gate(K_base, K_prior, pgc.Auth)
⑨ EV     ← SERC.execute(K_safe)      # 第 60 轮闭环
⑩ if EV.provenance = real: c_real.update(EV); M.ve.ingest(EV)
⑪ if d > θ_d or c_real < θ_c: trigger 补演示/系统辨识
⑫ return (K_safe, pgc, π_fused, EV)
```

**定义 169（学习预算 B_learn 与 PCE+++++）** B_learn = (B_demo, B_sim)：
- **B_demo** = (标注/采集人时, 覆盖场景数, 意图配对数)
- **B_sim** = (rollout 预算, 域随机化宽度, 保真度等级)
学习成本：cost_learn = λ_demo·HumanTime(D) + λ_sim·SimCompute(N_sim)。
**权威度预算耦合**：Auth_cap = min(1, B_demo.remaining_ratio) · (1 − 1[B_sim exhausted])。演示预算越少、仿真越先耗尽，先验权威度上限越低；任一预算耗尽只会降低 Auth，绝不会提高风险。若 B_demo 耗尽 ⇒ c_real 低 ⇒ Auth 低 ⇒ 回退保守基线；若 B_sim 耗尽 ⇒ 减小随机化宽度 ⇒ d 估计上升 ⇒ Auth 低。

### IP-161 DIS（演示阻抗签名）
```python
class DemonstrationImpedanceSignature:
    def __init__(self, lam=1e-2):
        self.lam = lam
        self.bank = defaultdict(list)

    def estimate(self, demo):
        Phi = self._regressor(demo)          # [Kp | Kd] 设计矩阵
        w = demo.wrench.flatten()
        K0 = self._nominal(demo.scene)
        A = Phi.T @ Phi + self.lam * np.eye(Phi.shape[1])
        K_hat = np.linalg.solve(A, Phi.T @ w + self.lam * K0)
        K_tilde = K_hat - self._human_arm_impedance(demo)   # 扣除演示混淆
        self.bank[(demo.scene, demo.intent)].append(K_tilde)
        return K_tilde

    def prior(self, scene, intent):
        S = np.asarray(self.bank[(scene, intent)])
        mu = S.mean(0)
        cov = np.cov(S.T) + 1e-6 * np.eye(S.shape[1])
        return GaussianPrior(mu, cov, n=len(S))
```

### IP-162 SRSP（域随机化场景先验）
```python
class SimRandomizedScenePrior:
    def __init__(self, simulator, theta_sampler, n_rollouts=1000):
        self.sim, self.sampler, self.n = simulator, theta_sampler, n_rollouts
        self.data = []

    def train(self):
        for _ in range(self.n):
            theta = self.sampler.sample()
            z, K = self.sim.rollout(theta)
            self.data.append((z, theta, K))
        self.g = fit_conditional_gaussian(self.data)   # g(z, theta) -> K

    def prior(self, z):
        return self.g.marginal_over_theta(z)            # ∫ p(K|z,theta)p(theta)dtheta
```

### IP-163 DSBF（演示-仿真贝叶斯融合）
```python
def demo_sim_bayesian_fusion(pi_sim, pi_demo, discrepancy, dim):
    Sigma_eff = pi_demo.cov + discrepancy.d * np.eye(dim)
    P_sim, P_eff = np.linalg.inv(pi_sim.cov), np.linalg.inv(Sigma_eff)
    Sigma_post = np.linalg.inv(P_sim + pi_demo.n * P_eff)
    mu_post = Sigma_post @ (P_sim @ pi_sim.mu + pi_demo.n * P_eff @ pi_demo.mu)
    return GaussianPrior(mu_post, Sigma_post, n=pi_demo.n)
```

### IP-165 PGC（先验接地证书与门控）
```python
class PriorGroundingCertificate:
    def __init__(self, tau_trust=0.75, alpha=1.0, beta=1.0, gamma=0.5):
        self.tau, self.a, self.b, self.g = tau_trust, alpha, beta, gamma

    def evaluate(self, z, pi_fused, c_real, c_sim, d):
        trust = sigmoid(self.a * c_real - self.b * d - self.g * (1 - c_sim))
        auth = 0.0 if trust < self.tau else min(1.0, trust)
        return PGC(z, c_real, c_sim, d, trust, auth)

    def gate(self, K_base, K_prior, auth):
        mb, mp = K_base.margin, K_prior.margin
        return K_base.with_margin(mb - auth * (mb - mp))
```

### IP-166 FMS（失败模式合成）

```python
class FailureModeSynthesizer:
    def synthesize(self, scene, steps=50, lr=0.05):
        theta = self.sampler.sample()
        for _ in range(steps):
            theta = project(theta + lr * grad_risk(self.sim, scene, theta))
        return self.sim.rollout(scene, theta)

    def failure_gap(self, real_fail, syn_fail):
        return coverage_distance(real_fail, syn_fail)   # 负证据缺口
```

### IP-168 DSSC（演示-仿真协同认知闭环）

```python
def demo_sim_synergistic_cognition(M, D, scene, intent, delta_f_req):
    pi_demo = M.dis.prior(scene, intent)
    pi_sim  = M.srsp.prior(scene)
    d       = M.discrepancy.estimate(scene, D)
    pi_fused = demo_sim_bayesian_fusion(pi_sim, pi_demo, d, M.k_dim)
    pgc = M.pgc.evaluate(scene, pi_fused,
                         M.real_support.coverage(scene),
                         M.sim_support.coverage(scene), d)

    K_base  = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.Z_env)
    K_safe  = M.pgc.gate(K_base, K_prior, pgc.auth)
    EV = scenario_perception_evolution_loop(M, scene, intent, delta_f_req)  # 第60轮SERC
    if EV.provenance == 'real':
        M.real_support.update(EV)
        M.ve.ingest(EV)
    if d > M.theta_d or M.real_support.coverage(scene) < M.theta_c:
        M.schedule_demo_or_sysid(scene)
    return K_safe, pgc, pi_fused, EV
```

### IP-169 PCE+++++（学习预算耦合）
```python
class LearningBudget:
    def __init__(self, demo_hours, sim_rollouts):
        self.B_demo = demo_hours
        self.B_sim = sim_rollouts
        self.used_demo = 0
        self.used_sim = 0

    def remaining_ratio(self):
        return max(0.0, (self.B_demo - self.used_demo) / self.B_demo)

    def sim_exhausted(self):
        return self.used_sim >= self.B_sim

    def authority_cap(self):
        return self.remaining_ratio() * (0.0 if self.sim_exhausted() else 1.0)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DIS | O(n_demo·d²) 估计 / O(d³) 先验 | O(n_demo·d) | 签名相对误差 ≤ 15%，演示混淆残差 ≤ ε_h |
| SRSP | 离线 O(N_sim·rollout) / 推理 O(d³) | O(N_sim·d) | 覆盖真实 θ 的概率 ≥ 1−α |
| DSBF | O(d³)/场景 | O(d²) | 后验校准 ECE ≤ 0.05 |
| PGC | O(1)（统计已缓存） | O(1) | Auth ≤ c_real+ε，Auth 单调 |
| FMS | 离线 O(N_adv·steps·rollout) | O(N_adv) | 失败缺口可测 |
| DSSC | SERC + O(d³) | 复用 | 冷启动收敛 ≤ 3 接触 |

**正确性定理（DSSC）**：
假设 **(A66)** DIS 可辨识：Φ 持续激励，人类混淆有界 ε_h，K̂ 误差 ≤ δ_demo；**(A67)** SRSP 覆盖：真实 θ 落在 supp(p(θ)) 的概率 ≥ 1−α；**(A68)** DSBF 校准：后验良定，差异估计一致；**(A69)** PGC 可靠性：Auth ≤ c_real+ε，且 Auth 关于 c_real 单调增、关于 d 单调减；**(A70)** 溯源隔离：虚拟证据按构造不进入 J_exec。

则：
1. **权威度上界**：Auth(z) ≤ c_real(z)+ε。故纯仿真先验（c_real=0）最多获得 ε 的收窄权威，无法把 K_safe 收窄到基线安全地板之外——从结构上防止「仿真过自信」直接变成执行风险。
2. **先验安全性**：若 c_real ≥ θ_c、d ≤ θ_d，则 π_fused 的 1−α 置信椭球包含真实 K 的概率 ≥ 1−α−δ_demo；K_safe 不排除真实安全解。
3. **证据完整性**：J_exec 链仅含 real 证据，Contam ≡ false。
4. **预算单调安全**：B_demo/B_sim 消耗只降低 Auth，不提高风险。

### IP-161 DIS（演示阻抗签名）
```python
class DemonstrationImpedanceSignature:
    def __init__(self, lam=1e-2):
        self.lam = lam
        self.bank = defaultdict(list)

    def estimate(self, demo):
        Phi = self._regressor(demo)          # [Kp | Kd] 设计矩阵
        w = demo.wrench.flatten()
        K0 = self._nominal(demo.scene)
        A = Phi.T @ Phi + self.lam * np.eye(Phi.shape[1])
        K_hat = np.linalg.solve(A, Phi.T @ w + self.lam * K0)
        K_tilde = K_hat - self._human_arm_impedance(demo)   # 扣除演示混淆
        self.bank[(demo.scene, demo.intent)].append(K_tilde)
        return K_tilde

    def prior(self, scene, intent):
        S = np.asarray(self.bank[(scene, intent)])
        mu = S.mean(0)
        cov = np.cov(S.T) + 1e-6 * np.eye(S.shape[1])
        return GaussianPrior(mu, cov, n=len(S))
```

### IP-162 SRSP（域随机化场景先验）
```python
class SimRandomizedScenePrior:
    def __init__(self, simulator, theta_sampler, n_rollouts=1000):
        self.sim, self.sampler, self.n = simulator, theta_sampler, n_rollouts
        self.data = []

    def train(self):
        for _ in range(self.n):
            theta = self.sampler.sample()
            z, K = self.sim.rollout(theta)
            self.data.append((z, theta, K))
        self.g = fit_conditional_gaussian(self.data)   # g(z, theta) -> K

    def prior(self, z):
        return self.g.marginal_over_theta(z)            # ∫ p(K|z,theta)p(theta)dtheta
```

### IP-163 DSBF（演示-仿真贝叶斯融合）
```python
def demo_sim_bayesian_fusion(pi_sim, pi_demo, discrepancy, dim):
    Sigma_eff = pi_demo.cov + discrepancy.d * np.eye(dim)
    P_sim, P_eff = np.linalg.inv(pi_sim.cov), np.linalg.inv(Sigma_eff)
    Sigma_post = np.linalg.inv(P_sim + pi_demo.n * P_eff)
    mu_post = Sigma_post @ (P_sim @ pi_sim.mu + pi_demo.n * P_eff @ pi_demo.mu)
    return GaussianPrior(mu_post, Sigma_post, n=pi_demo.n)
```

### IP-165 PGC（先验接地证书与门控）
```python
class PriorGroundingCertificate:
    def __init__(self, tau_trust=0.75, alpha=1.0, beta=1.0, gamma=0.5):
        self.tau, self.a, self.b, self.g = tau_trust, alpha, beta, gamma

    def evaluate(self, z, pi_fused, c_real, c_sim, d):
        trust = sigmoid(self.a * c_real - self.b * d - self.g * (1 - c_sim))
        auth = 0.0 if trust < self.tau else min(1.0, trust)
        return PGC(z, c_real, c_sim, d, trust, auth)

    def gate(self, K_base, K_prior, auth):
        mb, mp = K_base.margin, K_prior.margin
        return K_base.with_margin(mb - auth * (mb - mp))
```

### IP-169 PCE+++++（学习预算耦合）
```python
class LearningBudget:
    def __init__(self, demo_hours, sim_rollouts):
        self.B_demo = demo_hours
        self.B_sim = sim_rollouts
        self.used_demo = 0
        self.used_sim = 0

    def remaining_ratio(self):
        return max(0.0, (self.B_demo - self.used_demo) / self.B_demo)

    def sim_exhausted(self):
        return self.used_sim >= self.B_sim

    def authority_cap(self):
        return self.remaining_ratio() * (0.0 if self.sim_exhausted() else 1.0)
```

**正确性定理（DSSC）**：
若 A66–A70 成立，则：
1. **权威度上界**：Auth(z) ≤ c_real(z)+ε ⇒ 纯仿真先验（c_real=0）至多获得 ε 收窄权威，无法突破基线安全地板。
2. **先验安全性**：c_real ≥ θ_c 且 d ≤ θ_d ⇒ π_fused 的 1−α 置信椭球含真实 K 的概率 ≥ 1−α−δ_demo。
3. **证据完整性**：J_exec 链仅含 real 证据，Contam ≡ false。
4. **预算单调安全**：B_demo/B_sim 消耗只降低 Auth，不提高风险。
