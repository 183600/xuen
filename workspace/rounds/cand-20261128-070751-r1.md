### 第 6 轮灵感驱动研究记录（承接第 5 轮；新循环首轮）

**灵感词**：步骤分、桌面操作

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）以「认证的生成式执行」（CGE）把提议升级为条件流匹配 FMPP、记忆升级为可固化 LMEM-v2、人因升级为面部情感调制 FAMK，并确立定理 5~8 与 Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29。v5 留下三个未偿结构债：(a) 证书是**整条轨迹/末点级**的，长程任务里回答不了「安全地完成了多少」——VACK 只给终局标量，区分不了「安全地停在 30%」与「安全地停在 0%」；(b) **证书可组合性**被默认假设掉了：一串各自通过门的轨迹片段，拼接后未必整体通过（接口/粘连条件未校验），长程任务把这个缺口放大；(c) 实验仍是通用 MuJoCo，缺少一个几何结构强、可复现、能买到更便宜更紧证书的**具体域**。本轮以「步骤分 + 桌面操作」统一为主题「分步认证的桌面操作」（Stepwise-Certified Tabletop Manipulation, SCTM），形成 CADVS-v6（IP-497~500）。本轮自律：**七硬门不增、锚点集合不变**；步骤分是软评分与证书组合层，桌面域是只收紧/省算力的特化，二者都不新增门。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **步骤分 → 把「终局价值门」升级为「带证书的进度账本」，且学分只作真实进度的保守下界**。直觉：长程操作是一个子任务 DAG，学分只应发给「已认证 ∧ 前置已完成 ∧ 非冗余（进度增量 ≥ δ）」的步骤，绝不能因为「看起来做了一半」就发分。形式上定义进度势 Φ_τ: 状态→[0,1]（沿已认证转移单调不减，目标处为 1）与步骤学分 C(x)=Σ_v w_v·1[completed_v ∧ certified_v ∧ prereq_v ∧ ΔΦ_v≥δ_v]；**定理 9（学分健全性，NCWC：无证书不给分）** 证明 C(x) ≤ TrueProg(x) ≤ Φ_τ(x_final)，即学分是真实进度的保守下界而非乐观估计。这把 VACK 从「终局 oracle」扩展为「单调进度账本」，却**不新增硬门**。反 Goodhart 的结构抓手：子任务 DAG 由任务作者固定并签名（agent 不可细化）、δ 非冗余约束、学分上限归一化、结局审计。

2. **桌面操作 → 用桌面域的强几何结构做「证书编译器」，把昂贵门换成便宜的可靠充分条件，且只收紧或省算力**。桌面场景有支撑平面、重力、已知物体集、固定基座工作空间：支撑多边形 + 质心投影给出准静态稳定的 O(n) 判据（替代 BCK 的 O(n³) QP）；桌面/障碍 SDF 给出无穿透的必要条件；预计算可达集 R_reach 给出可达性 O(1) 查表；已知抓取库给出力封闭。**定理 11（桌面编译器健全性）**：任一廉价判据通过 ⇒ 对应精确门通过（在准静态 B9、已知场景几何 B10 下），失败则回退精确门，故**绝不新增接受**；再加域安全裕度 m_i≥0 时只收紧。副产品：进一步偿还 v4-R49（控制环 P99 目标 < 0.45 ms），并给出可复现验证域（ManiSkill2/RLBench/CALVIN/Robocasa 桌面任务）。

3. **两者相乘 → 补上「证书可组合性」这一 v5 隐含假设**。分步把一条长程执行切成带接口的片段；定义粘连谓词 Glue(s_k,s_{k+1})=‖end(s_k)−start(s_{k+1})‖≤ε_g ∧ 不变量 I 保持（如「物体在手、未滑落、未穿透」），组合算子 ⊕。**定理 10（组合证书健全性）**：在门可组合假设 B8（每个门要么是片段局部 AND、要么有可靠的全局聚合摘要）下，若每段已认证且所有相邻 Glue 成立，则拼接轨迹整体通过七门；因此 Exec_v6 = {⊕ 已认证片段} ⊆ Exec_v5（粘连是额外 AND 约束）。这解释了为何「逐段安全」不等于「整体安全」，并给出可检查的中间条件。

**关键洞见**：v5 回答「提议可换、门不可换」；v6 回答「当任务是长程分步、域是结构化桌面时，证书如何跨步组合、部分进度如何计分而不让分数变成目标」。七硬门 kc_evidence_forged_v5 记号原样复用；新增的只有：子任务 DAG 与进度账本 SDPK（软评分 + 组合层）、证书组合代数 CCA（粘连/不变量）、桌面域证书编译器 TDCC（只收紧/省算力）、分步装配器 EFA-v6。执行集 Exec_v6 ⊆ Exec_v5 由「逐段门 AND + 粘连 AND + 域裕度只紧」保证。

**形式化目标（增量）**：
1. 任务 τ=(D=(V,E,w,ρ), Φ_τ)：子任务 DAG、完成谓词、进度势；步骤学分 C(x)=Σ_v w_v·1[certified_v ∧ prereq_v ∧ ΔΦ_v≥δ_v]，NCWC。
2. 步骤证书 Cert_k=(片段七门值, 入/出状态, 不变量签名)；粘连 Glue 与组合算子 ⊕；门可组合假设 B8。
3. TDCC 充分条件：support-polygon/准静态、SDF 无穿透、R_reach 可达、抓取力封闭；精确回退；域裕度 m_i。
4. 定理 9（学分健全/单调）、定理 10（组合证书）、定理 11（桌面编译器健全）、定理 12（DAG 细化下的学分不可农场化）；引理 46~48。
5. EFA-v6 分步级联：每段 廉价 TDCC → v5 七门 → BCK 预览 → 段间 Glue 校验 → 全局聚合；ECS_v6 = ECS_v5 · η_step（步骤边际/进度一致性软因子）。
6. Exec_v6 = {x=⊕_k x^{(k)} : ∀k kc_v5(x^{(k)})=1 ∧ Glue(s_k,s_{k+1}) ∧ 全局门聚合} ⊆ Exec_v5。

**本轮最大风险**：**步骤分被 Goodhart 化（学分农场 + 代理缺口）**——部分学分只是真实任务进度的代理，代理与真值之间的缺口原理上无法由任何证书消除；一旦策略或训练以学分为目标，就会农场化易得且被认证的子步骤、利用进度势函数的盲区，并让「逐步合法」拼接成「整体无意义」的执行；作者固定 DAG + 非冗余 δ + 学分上限 + 结局审计只能约束而不能根除。

## 2. 关键算法骨架

### IP-497 SDPK：子任务分解与进度账本（准入时域，作者固定 DAG）

```python
@dataclass
class StepDecompositionProgressKernel:
    """SDPK：学分只发给「已认证 ∧ 前置完成 ∧ 非冗余」的步骤。
    定理 9（NCWC）：C(x) ≤ TrueProg(x) ≤ Φ_τ(x_final)——学分是保守下界"""
    dag: SubtaskDAG                 # 作者签名；agent 不可细化/改权
    progress: ProgressPotential     # Φ_τ，单调不减
    delta: dict                     # δ_v 非冗余阈值

    def credit(self, traj, certs: dict) -> float:
        total = 0.0
        for v in self.dag.topo_order():
            if not all(self._done(u, certs) for u in self.dag.parents(v)):
                continue                                   # 前置未完成：不给分
            seg = self._segment(traj, v)
            if not certs[v].certified:                     # NCWC：无证书不给分
                continue
            if self.progress(seg.end) - self.progress(seg.start) < self.delta[v]:
                continue                                   # 冗余步骤：不给分
            total += self.dag.w[v]
        return min(total, 1.0)                             # 归一化上限

    def refine_by_agent(self, *a, **k):
        raise PermissionError("子任务 DAG 只能由任务作者重签名（防学分农场）")
```

### IP-498 CCA：证书组合代数（粘连 + 不变量，段间校验）

```python
@dataclass
class CompositionalCertificateAlgebra:
    """CCA：把「逐段安全」提升为「整体安全」的可检查条件。
    定理 10：每段已认证 ∧ 所有相邻 Glue ⇒ 拼接整体通过七门（在 B8 下）"""
    invariants: list               # I：物体在手/未滑落/未穿透/未超力
    eps_glue: float = 1e-3

    def glue(self, s_k, s_k1) -> bool:
        return (norm(s_k.end - s_k1.start) <= self.eps_glue
                and all(I(s_k.end, s_k1.start) for I in self.invariants))

    def compose(self, segs, certs):
        if not all(c.certified for c in certs):
            return None
        if not all(self.glue(segs[k], segs[k + 1])
                   for k in range(len(segs) - 1)):
            return None                                # 接口不闭合：fail-closed
        if not all(A_g(segs, certs) for A_g in self.global_aggregators):  # B8
            return None
        return ComposedCert(segs, certs)               # 可缓存、可复用
```

### IP-499 TDCC：桌面域证书编译器（廉价可靠充分条件 + 精确回退）

```python
@dataclass
class TabletopDomainCertificateCompiler:
    """TDCC：桌面强结构 → 便宜判据。True 必蕴含精确门通过；False 必蕴含精确门失败；
    ⊥ 回退精确门。故绝不新增接受（定理 11），加裕度时只收紧"""
    support: Plane                 # 支撑平面（B10 标定）
    reach: ReachSet                # R_reach 预计算可达集
    sdf: Any                       # 桌面/物体/障碍 SDF
    margins: dict = field(default_factory=lambda:
        {'balance': 0.005, 'physics': 0.0, 'coverage': 0.0})

    def certify(self, x, gate: str):
        r = self._cheap(x, gate)
        return exact_gate(gate, x) if r is None else r

    def _cheap(self, x, gate):
        if gate == 'balance':                         # O(n) 替代 O(n³) QP
            if not quasi_static(x):                   # B9 不成立 → 回退
                return None
            return point_in_polygon(c_com(x), SP(x),
                                    margin=self.margins['balance'])
        if gate == 'physics':
            if min(sdf_T(x), sdf_O(x)) < -self.margins['physics']:
                return False                          # 穿透 ⇒ 必失败
            return None                               # 接触丰富 → 精确 MSRG
        if gate == 'coverage':
            return x.end in self.reach                # O(1) 查表
        return None
```

### IP-500 EFA-v6：分步装配器（七门逐段 + 段间 Glue + 全局聚合）

```python
@dataclass
class StepwiseCertifiedAssemblerV6:
    """EFA-v6：七硬门不变；每段认证 + 段间粘连 + 全局聚合 + 学分账本"""
    sd: StepDecompositionProgressKernel
    cca: CompositionalCertificateAlgebra
    tdcc: TabletopDomainCertificateCompiler
    v5: EvidenceForgingAssemblerV5

    def select(self, x0, t_now, task, context):
        segs, certs = [], {}
        for v in self.sd.dag.topo_order():
            seg = self._plan_step(v, context)         # FMPP 段内提议
            # 级联：TDCC 廉价 → v5 七门 → BCK 预览（接触拓扑变化才精确 QP）
            if not self._certify_step(seg, v):
                return False, None, f'STEP_{v}_REJECTED'
            segs.append(seg); certs[v] = seg.cert
        full = self.cca.compose(segs, certs)          # 定理 10
        if full is None:
            return False, None, 'COMPOSITION_FAILED'
        credit = self.sd.credit(concat(segs), certs)  # 定理 9：保守下界
        return True, concat(segs), ('FORGED_SCTM', credit)

    def ecs_v6(self, ..., credit: float, eta_step: float) -> float:
        return self.v5.ecs_v5(...) * eta_step         # 学分只进软评分
```

### 集成流水线（v5 → v6）

```
任务作者（离线）：
  子任务 DAG 签名 D=(V,E,w,ρ) + 进度势 Φ_τ + 不变量 I + 桌面几何/可达集
      ──▶ 冻结只读（agent 不可细化、不可改权、不可改 δ）

离线/慢时域（继承 v5）：
  固化（小时级）：铸证片段 ──▶ 证书过滤 ──▶ DP-SGD + KL 正则 ──▶ θ_FM
  桌面编译：支撑平面标定 + SDF + R_reach + 抓取库 ──▶ TDCC 缓存

在线准入（异步，秒级）：
  逐段：FMPP.propose(v 条件) ──▶ TDCC 廉价判据 ──▶ v5 七门 ──▶ BCK 预览
      ──▶ 段证书 Cert_k 入账（append-only）
  段间：Glue(s_k,s_{k+1}) + 不变量 I ──▶ 任一失败 = COMPOSITION_FAILED（fail-closed）
  全局：A_g 聚合（coverage/memory/value 的保守摘要）──▶ 组合证书
  学分：SDPK.credit（NCWC + 非冗余 + 作者 DAG）──▶ 软评分/审计（不改门）

在线控制环（目标 < 0.45 ms）：
  每周期：EEK + BCK（事件触发）；TDCC 准静态判据替代常规 QP；
  证书消费：逐段缓存证书 + 解析边际内插
```

| TDCC.balance | O(n) 支撑多边形 | O(n) | n≤32 接触点 | ~0.04 ms（v5 QP ~0.31 ms） |
| TDCC.physics | O(1) SDF 查表 | O(grid) | 缓存 SDF | < 0.02 ms |
| TDCC.coverage | O(1) 可达集查表 | O(\|R_reach\|) | 预计算 | < 0.01 ms |
| EFA-v6 七门（逐段） | O(1) 阈值预计算 | O(1) | — | < 0.03 ms/段 |
| 段内 BCK（事件触发） | 触发 O(n_dof³)，否则 O(1) | O(n_dof²) | 触发率 ~8% | **P99 ~0.42 ms（v5 0.55 ms）** |
| 端到端在线增量 | ~0.45 ms（控制环）+ 异步准入 | — | — | **进一步偿还 v4-R49** |

**通信开销**：子任务 DAG/Φ/不变量签名 ~4 KB/任务（作者下发，只读）；段证书 ~0.5 KB/段（可缓存、可审计）；TDCC 桌面几何/可达集 ~100 KB/工位（一次性）。学分账本 append-only，本地 + 可摘要上报。

**实时性缓解（对 v4-R49 的继续偿还）**：
- 桌面准静态判据 O(n) 替代常规 BCK QP；仅接触拓扑变化（建立/丢失/打滑）触发精确重解。
- 段证书缓存 + 解析边际内插，长程任务复用率高（同子任务检索命中）。
- 学分与组合全部在准入时域异步完成，控制环只消费预计算阈值与缓存证书。

## 4. 正确性论证（增量更新）

### 引理 46（学分健全性 / NCWC）

**陈述**：若每门 kc_v5 是可靠的（通过 ⇒ 对应安全/物理/价值条件真实成立），且 completed_v 要求 certified_v、prereq_v 与 ΔΦ_v≥δ_v，则对任意轨迹 x，C(x) ≤ TrueProg(x) ≤ Φ_τ(x_final)。

**证明**：按 DAG 拓扑序归纳。被计分的 v 必须 certified_v（⇒ 门对应条件真实成立 ⇒ ρ_v 真完成，因 ρ_v 由这些条件定义）且所有祖先已完成；未被认证、前置未完成或冗余的步骤一律不计分。权重 Σ_v w_v=1 且各 v 互斥计分一次，故 C 是真实完成子任务权重和的子集 ⇒ C ≤ TrueProg。Φ_τ 沿已认证转移单调且目标处为 1，故 TrueProg ≤ Φ_τ(x_final)。∎

### 引理 47（粘连不变量传递）

**陈述**：若每个已认证片段内部保持不变量 I（状态谓词，非历史依赖），且对每对相邻片段 Glue 成立（含 I 在边界成立），则拼接轨迹上 I 恒成立。

**证明**：片段内由证书保证；边界由 Glue 保证；I 是状态谓词 ⇒ 对拼接无额外历史依赖，逐段并集覆盖整条轨迹。∎（**诚实边界**：历史依赖不变量需扩充证书，不能由本引理覆盖。）

### 引理 48（桌面充分条件 ⇒ 精确门）

**陈述**：在 B9（准静态）与 B10（已知几何）下，(i) c_com∈SP（含裕度）⇒ BCK 的 ZMP/扳手锥可行；(ii) sdf≥0 ⇒ MSRG 无穿透约束满足；(iii) end∈R_reach ⇒ 运动学可达；(iv) 抓取力封闭 ⇒ 摩擦锥约束满足。

**证明**：(i) 准静态下惯性力可忽略，支撑多边形内的质心投影即 ZMP 可行域的充分子集；(ii) 有符号距离非负是接触非穿透的定义；(iii)(iv) 由可达集与力封闭抓取库的构造定义。∎

### 定理 9（学分健全性与单调性）

**陈述**：在引理 46 条件下，(i) C(x) ≤ TrueProg(x)（健全：不虚报）；(ii) 沿已认证执行 Φ_τ 单调不减；(iii) 学分对 agent 内部分段方式不变（路径无关）。

**证明**：(i) 引理 46；(ii) Φ 定义 + 认证转移；(iii) C 只在作者 DAG 的节点上按 (ρ_v, Φ 增量) 计分，agent 的段切分被 `_segment` 映射回作者节点，不改变计分。∎

### 定理 10（组合证书健全性）

**陈述**：在 B8（门可组合）下，若每段 kc_v5(x^{(k)})=1 且所有相邻 Glue 成立且全局聚合 A_g=1，则拼接 x 整体通过七门；故 Exec_v6 = {⊕ 已认证片段} ⊆ Exec_v5。

**证明**：局部门（physics/balance/endpoint/human）由逐段 AND + 引理 47 的接口保持给出；全局门（coverage/memory/value）由可靠聚合摘要 A_g 的 over-approx 保证 fail-closed；Glue 是额外 AND 约束，只会缩小集合。∎

### 定理 11（桌面编译器健全性与效率）

**陈述**：TDCC 的 True 判定必蕴含精确门通过，False 判定必蕴含精确门失败，⊥ 精确回退；故 Exec_TDCC ⊆ Exec_exact，且裕度 m_i>0 时严格 ⊆。复杂度从 O(n³) 降至 O(n)（balance）。

**证明**：由引理 48，True 路径只走充分条件；False 路径只走必要条件；⊥ 路径等于精确门。因此不新增任何精确门拒绝的接受，裕度进一步收紧。∎

### 定理 12（学分不可农场化）

**陈述**：在「DAG 作者固定签名 + δ 非冗余 + 权重归一 + 学分上限」下，(i) agent 无法通过细化子任务或重切分获得额外学分；(ii) 任意被计分步骤使 Φ 增量 ≥δ_v，故可计分步骤数 ≤ 1/δ_min；(iii) 学分对策略优化是保守信号，不能通过「刷分」提高 C 而不提高 TrueProg。

**证明**：(i) `refine_by_agent` 被拒绝，计分映射回作者 DAG（定理 9(iii)）；(ii) 每步 ΔΦ≥δ_v 且 Φ≤1，故计分步数有界；(iii) 由定理 9(i) C≤TrueProg，C 的任何提升必须对应真实完成子任务的提升。∎（**诚实边界**：TrueProg 本身是任务作者的代理，若作者 DAG 与真实价值不一致，则代理缺口仍在——见 R60。）

### 定理 v6（分步认证总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 门可组合、(B9) 准静态、(B10) 几何已知下：
(i) Exec_v6 ⊆ Exec_v5（严格：Glue 与域裕度非恒真）⊆ … ⊆ Exec_v29；
(ii) 学分健全 C≤TrueProg≤Φ（定理 9）；
(iii) 组合健全：逐段认证 + Glue + A_g ⇒ 整体认证（定理 10）；
(iv) 桌面编译器不新增接受、只省算力或收紧（定理 11）；
(v) 学分对 agent 细化不可农场化（定理 12）；
(vi) 七锚完备性保持（v5 定理 8），步骤分与桌面域均非新锚。

**证明**：(i) 逐段门 AND + Glue AND + 域裕度只紧；(ii)~(v) 分别由定理 9~12；(vi) 锚点集合不变且所有新增层只收紧或只打分。∎

**诚实声明**：(B8) 全局门（coverage/value/memory）的可靠聚合摘要可能偏保守，导致合法长程轨迹被拒（可用性损失，非安全性损失）；(B9) 不覆盖抛掷/滑动/倾倒等动态桌面操作；(B10) 桌面标定漂移会使廉价充分条件失效，必须靠 fail-closed 回退而非放宽；(iv) TrueProg 是作者代理，Goodhart 缺口无法由证书消除；(v) 子任务 DAG 的作者化成本与正确性成为新的人工负债。

## 7. 本轮最大风险（最终确认）

**一句话**：**步骤分被 Goodhart 化（学分农场 + 代理缺口）**——部分学分只是真实任务进度的代理，代理与真值之间的缺口原理上无法由任何证书消除；一旦策略或训练以学分为目标，就会农场化易得且被认证的子步骤、利用进度势函数的盲区，并让「逐步合法」拼接成「整体无意义」的执行；作者固定 DAG + 非冗余 δ + 学分上限 + 结局审计只能约束而不能根除。
