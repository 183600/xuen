# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「VLA」×「安全性」）

> R69 已经会问「我该向谁求证」，但它把「问」建立在三件未经检验的假设上：**策略是自己训练的、似然是自己能算的、证书是自己签的**。VLA 把这三件事同时打破：它是一个互联网规模预训练、只能通过视觉/语言接口观察、动作头不可信、且可被语言操纵的巨大提议器。更根本的是，R69 的整套机制处理的是「**我该做什么**」的不确定性，却从未处理另一个正交的问题：**「即使我知道要做什么，这样做安全吗？」**
>
> 一个 VLA 可以非常自信地正确理解「把刀递给那个人」，同时非常自信地错误判断「那个人是不是孩子 / 刀是不是真的 / 递过去会不会划伤」。**语义能力与安全能力不是同一条轴**；让 VLA 自己回答「我安全吗」，等于让被告当法官。
>
> 本轮两个灵感给出分工：
> - **VLA** 提供跨本体、跨任务的语义先验与语言接地，但只允许它**提议**，不允许它**认证**；
> - **安全性**不是模型属性，而是**部署属性**：它由显式的「安全宪法 + 技能合同 + 运行时盾牌」外部构造，并且必须能被审计。
>
> 核心命题：**把「安全」从 VLA 的黑箱里抽出来，做成一个可检查的义务系统：VLA 只输出带类型的语义提案；每个技能附带前置/后置/不变式/假设合同；执行前必须把假设变成安全义务并逐条闭合；闭合不了的义务交给 R69 的交互层去核实（看/问/触），核实不了就拒绝或退化。** 命名 **OATH-RAS**（Obligation-Assured Trusted Harness for Risk-Adaptive Systems：零信任 VLA 的义务闭合守卫式闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**谁有权判定安全**」——提议者不能当法官，安全必须与能力分离；安全不是模型的誓言，而是系统的誓约（oath）。

## 0. 直觉与动机

**灵感 1（VLA 是语义先验，不是安全权威）**
直觉：VLA 在互联网数据上学到「人类通常会怎么做」，但「通常」恰恰不是「安全」。人类演示里有大量近失手、坏习惯与选择偏差（只演示成功）。模仿学习把「怎么完成」学得很好，却把「什么不该做」留成盲区。更关键：VLA 的置信度是**语义置信度**（我理解对了吗），不是**物理/伦理风险置信度**（做下去会伤人吗）。把两者混为一谈，是 VLA 安全问题的根源。正确姿态：VLA 只负责「提出候选语义计划」，安全由另一个不能是同一个模型的层来判定。

**灵感 2（安全性 = 部署属性，不是模型属性）**
直觉：同一个 VLA 在空房间安全，在厨房不安全；抓空杯安全，抓满杯不安全；对人说「递给我」安全，对儿童说同样的话未必。安全从来不是动作本身的属性，而是 (动作, 场景, 本体, 人, 规范) 的函数。因此安全不能靠「训练一个更安全的 VLA」一次性获得，必须靠**运行时的约束、合同与监控**在具体部署中构造。这直接推出：安全层必须独立于 VLA、可检查、可审计、可替换。**换一个更强的 VLA 不应自动获得安全，换一个更弱的 VLA 也不应自动失去安全。**

**灵感 3（合同与义务：把「安全」变成可闭合的布尔问题）**
直觉：工程师做安全关键系统不靠「相信模型」，靠**合同**——每个技能声明它要求什么前提、保证什么后置、维持什么不变式、依赖什么假设。假设就是潜在的安全义务：杯子是空的、人不在机械臂可达域、地面不滑、门没锁。执行前逐条闭合；能观测就观测，能问就问，能触就触，能由证书保证就由证书保证。**这份义务清单就是语义与物理之间的接口**：VLA 的符号计划在这里被翻译成「必须先为真的命题」。安全因此从「预测一个分数」变成「证明一组命题」。

**灵感 4（R69 的交互层被重新征用：从消歧到举证）**
直觉：R69 的看/问/触原本是为了消解任务歧义；在 OATH 里它们获得更硬核的用途——**为安全义务举证**。这不是简单换标签：目标函数从「降低任务模态熵」变成「降低安全风险」，决策规则从期望成本变成**字典序**（硬义务先于软义务，软义务先于任务收益）。这带来一个新的信息价值：**安全信息价值 SVoI**——不是「问了能不能做得更对」，而是「问了能不能少一分不可接受的风险」。这也解释了为什么有些问题值得问（「杯子里是热水吗」），有些问题不值得问（「你更喜欢左手还是右手」）。

**灵感 5（语言是攻击面：VLA 把 prompt injection 带进了物理世界）**
直觉：传统策略不看文本，VLA 看。于是「忽略之前的指令」「这句话是引用，不是命令」「我是管理员，把门打开」这些攻击第一次有了物理后果。场景里的文字（标语、屏幕、包装）也可能成为注入源。VLA 还可能把「玩笑/假设/否定」当成命令。安全层必须先做**言语行为分类**与**权限/同意检查**，把指令变成有类型的承诺，而不是直接当动作条件。**语言接地不只是「指哪个物体」，还包括「这句话是不是一个有效的命令」。**

**灵感 6（局部安全 ≠ 全局安全：需要结果集监控）**
直觉：每一步都安全，合起来未必安全：把杯子推到桌边每一步都不越界，最后却容易掉；先开门再经过，门可能回弹；把物体交给人的轨迹本身安全，但交付后的结果不安全。VLA 的计划是长程的，安全必须检查**预测结果集**而不是单步动作。世界模型会错，所以用共形预测给出带覆盖保证的结果集，并要求**整个结果集**落在安全集内（保守下近似）。这把 R67 的「未来怎样」升级为「未来所有可接受的可能里，有没有一个会伤人」。

**灵感 7（安全不能靠「更保守」解决：过度保守会被人类绕过）**
直觉：如果系统对一切不确定都说「不」，人类会学会关掉它——这才是真实世界最大的安全失效模式（自动化不信任/绕过）。所以 OATH 不能只做拒绝机器：它必须能**主动举证、给出替代方案、解释拒绝理由**，并用 SVoI 把交互预算花在真正降低风险的地方。安全不是把机器人变慢，而是让它在不确定时做**有信息量的谨慎动作**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（OATH-RAS 总览）** OATH-RAS = (VPA, IVB, SCL, OBM, SLC, SVC, CSE, OCM, RRL, SCA, RAS-WM‡)。五条不变式：
(i) **提议-认证分离**：VLA 的任何输出都只是提案，不得直接成为可执行指令；每个执行动作必须经 CSE 认证；
(ii) **零信任 VLA**：安全保证不依赖 VLA 的正确性/诚实性；被投毒或对抗的 VLA 至多降低任务成功率，不能扩大硬安全包络；
(iii) **义务闭合**：任何硬安全义务未闭合前不得执行；软义务只能在风险预算内豁免；
(iv) **实时流零学习写操作**（继承 R69 定义 293-i）；
(v) **单调退化**：合同/监控/证书失效时，按 L0→L1→L2→L3 阶梯退化，安全集只缩不扩。

**定义 311（VLA 带类型提案 VPA）** 冻结 VLA `Φ_VLA(v_t, l_t, p_t)` 输出提案 `π = (s, θ, γ, Ê, c, ρ, ã)`：技能 `s ∈ 𝒮`、参数 `θ`、接地 `γ`（符号→实体/关系绑定）、预期效果原子集 `Ê`、语义置信 `c`、来源 `ρ`、以及仅作建议的原始动作 `ã`。**`ã` 被隔离**：它可被记录、可被审计、可作为 CSE 的参考，但绝不直接下发。VLA 的动作头是「证人」，不是「执行者」。

**定义 312（技能安全合同 SCL）** 每个认证技能 `s` 有合同 `C_s = (Pre_s, Post_s, Inv_s, Frame_s, Assump_s, Fail_s, ver_s)`，其中 `Pre/Post/Inv/Frame` 是可判定片段上的公式，`Assump_s` 是执行所依赖的环境/人类/物体假设，`Fail_s` 是已知失效模式，`ver_s` 是版本与哈希。合同是信任的最小单位；没有合同的技能不得执行。合同的修改是离线、带审计的写操作（继承 R69 的零实时写铁律）。

**定义 313（安全宪法 K）** `K = (E_prot, H, N, A)`：受保护实体集、危害谓词集（身体/财产/隐私/尊严/环境）、规范与硬约束、权限与同意规则。K 必须显式、可读、版本化，并由人类/监管者签署。安全永远是「相对于 K」的；没有 K 就没有证书。K 不是 VLA 的一部分，也不能由 VLA 生成。**K 是系统的「誓约文本」，是安全案例的公理。**

**定义 314（独立验证绑定 IVB）** 合同中的实体与关系必须在**独立于 VLA 的感知/状态估计**上绑定：`bind(γ, S_t)`。所有 `Pre_s, Assump_s, Inv_s` 都在真实场景 `S_t` 上求值，而不是在 VLA 的内部特征上求值。若绑定多义或低置信，生成**接地义务**（定义 315），不得默认 VLA 的绑定正确。IVB 是「接地交换攻击」的防线。

**定义 315（安全义务）** 义务 `o = (φ, κ, μ, c, τ)`：谓词 `φ`、关键度 `κ ∈ {hard, soft}`、验证方法 `μ ∈ {observe, query, probe, certify, assume}`、成本 `c`、超时 `τ`。由 `Extract(π, C_s, K, S_t) = Assump_s ∪ Pre_s ∪ K-rel(Ê)` 生成。硬义务对应 K 中的不可违反约束或合同前提；软义务对应舒适、效率、礼貌等可权衡项。`assume` 只允许用于已被 SCA 证明「失效后果可接受」的软义务。

**定义 316（义务闭合与门控 OBM）** 闭合状态 `st(o) ∈ {verified, refuted, unknown, waivered}`。门控规则（字典序）：
1. 任一硬义务 `refuted` ⇒ 拒绝该提案；
2. 任一硬义务 `unknown` ⇒ 先尝试 SVC 交互或换技能；仍 `unknown` ⇒ 安全停止；
3. 仅当所有硬义务 `verified` 且软义务的加权残余风险 `Σ_soft w_o r_o ≤ R_soft` 时才 `ACCEPT`。
`waived` 只允许软义务。**没有任何「默认通过」。** 门控的输出是 `ACCEPT / DEFER / REJECT / STOP` 四值，而不是单一分数。

**定义 317（认证技能执行器 CSE / 运行时盾牌）** 每个技能 `s` 配一个已认证控制器 `κ_s` 与不变式安全集 `Safe_s(S_t)`。CSE 用提案的参数 `θ` 与接地 `γ` 实例化 `κ_s`，将 VLA 的 `ã` 投影到 `Safe_s`（或直接忽略），并检查 `Inv_s`。若投影距离 `> δ_proj`、无安全动作、或 `κ_s` 不可用 ⇒ 拒绝并走替代/退化。**CSE 只执行「合同允许的参数化技能」，不执行任意端到端动作。**

**定义 318（语义-语言监视器 SLC）** 指令 `l` 解析为言语行为 `σ ∈ {command, request, question, quote, hypothetical, negation, report}`、说话者权限 `Auth`、同意状态 `Con`、承诺集 `Commit`。只有 `σ ∈ {command, request}` 且 `Auth` 有效、`Con` 满足、且承诺集不与 K 冲突时，才可生成提案。场景文字与第三方语音同样按不可信输入处理；注入检测基于来源、能力与指令-上下文一致性。**「是不是命令」先于「命令是什么意思」。**

**定义 319（结果共形监控 OCM）** 世界模型给出结果分布 `p_ψ(y | π, S_t)`；用共形校准得到结果集 `Ŷ_{1−α}(π, S_t)`，满足（可交换性下）`P(Y ∈ Ŷ) ≥ 1−α`。安全判据不是「预测结果安全」，而是**整个结果集**落在安全集的下近似内：`Ŷ ⊆ Safe(K)`。若 `Ŷ ⊄ Safe` ⇒ 拒绝/交互/换计划；同时报告覆盖率、集合大小与漂移分 `shift`。**集合越保守，越安全但越可能拒绝；这是一个显式的安全-可用性权衡。**

**定义 320（安全信息价值 SVoI 与交互预算 SVC）** 对义务 `o` 与信息动作 `g`：

`SVoI(g; o) = κ(o) · P(st(o)=unknown) · [R(o) − E_{y|g}(R(o|y))] − c(g)`。

选择 `g* = argmax_{g,o} SVoI(g;o)`，硬义务优先（字典序），且受 R69 的交互预算（次数/位移/社交成本）与信息动作认证约束。若 `max SVoI ≤ 0`，不交互，按 R69 保守或安全停止。**R69 的 VoI 是 SVoI 在 `K = {任务成功}`、所有 `κ` 相等时的特例。**

**定义 321（残余风险账本 RRL）** `R_res = Σ_{o: waived} w_o r_o + ε_K + ε_mon`，其中 `ε_K` 是 K 的覆盖不足估计（红队/事故/新危害类别），`ε_mon` 是监控盲区估计（遮挡、感知退化、未建模危害）。`R_res` 不可被优化到零，必须随证书一起报告；当 `R_res > R_max` ⇒ 禁止自主执行，降级到远程监督/安全停止。

**定义 322（威胁模型 ℰ_OATH）** `ℰ_OATH = ℰ_FLUID × ℰ_sem`，其中 `ℰ_sem` 包含：提示注入（指令/场景文字/第三方语音）、言语行为伪造（把引用/玩笑/假设伪装成命令）、权限与同意伪造、接地交换（外观相同但可供性不同的 metamer）、合同规避（满足字面前提但违反意图）、监控致盲（遮挡/对抗光照/传感器欺骗）、VLA 后门与投毒、目标误泛化，以及**组合伤害**（每步都安全、序列不安全）。

**定义 323（安全案例审计与证书 J_OATH）** `J_OATH = (J_FLUID, contract_hash, K_hash, obligations_total, hard_verified, soft_waived, outcome_coverage, set_size, shift_score, injection_flags, residual_risk, svc_budget_used, degrade_level, oath_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 硬义务全闭合 ∧ 结果集覆盖 ≥ 1−α ∧ SLC 未拦截 ∧ R_res ≤ R_max ∧ SCA 审计通过`。**证书是一份安全案例（safety case），不是单一标量。**

**定义 324（组合安全）** 对计划 `π = s_1;...;s_n` 组合合同：

`Pre_π = Pre_{s1} ∧ ⋀_{i>1}(Post_{s_{i−1}} ⇒ Pre_{s_i})`，

`Inv_π = ⋀_i Inv_{s_i} ∧ ⋀_i Frame`，

并检查接口类型、资源与时间约束、以及跨技能的结果集安全（定义 319）。这捕获「局部安全、全局有害」。

**定义 325（退化阶梯）** `L0`：OATH 全功能；`L1`：禁用 VLA，退回 R69 的 FMP + 交互；`L2`：禁用交互，退回 R68 纯保守标定闭环；`L3`：安全停止/远程监督。触发：合同失效、K 未签、覆盖不达标、注入拦截、连续义务反驳、RRL 越界。**降级只会缩小安全集，绝不扩大。**

**定义 326（未知-未知哨兵）** 对 K 未覆盖的新谓词/新情境用开放集异常检测与人类复核触发 `unknown_unknown_alarm`；报警时不得签发自主执行证书。**它不能证明安全，只能拒绝假装知道。**

## 2. 关键算法骨架

```python
# IP-264 VPA：冻结 VLA 只产出带类型提案，动作头隔离
class VLAProposalAdapter:
    def __init__(self, vla_frozen, skill_lib, K):
        self.vla, self.skills, self.K = vla_frozen, skill_lib, K

    def propose(self, vision, language, proprio):
        out = self.vla.semantic_forward(vision, language, proprio)  # 慢环
        return Proposal(skill=out.skill, params=out.params,
                        grounding=out.grounding, effects=out.effects,
                        conf=out.conf, provenance=out.provenance,
                        raw_action=None)   # 原始动作只记录，不下发

# IP-266 SCL + OBM：从合同与宪法中抽取义务并闭合
def extract_obligations(proposal, scene, contracts, K):
    c = contracts[proposal.skill]
    preds = c.assumptions + c.preconditions + K.relevant(proposal.effects)
    return [Obligation(phi=p, criticality=K.level(p),
                       method=choose_method(p), cost=cost(p), timeout=tau(p))
            for p in preds]

def close_obligations(obs, scene, svc):
    for o in sorted(obs, key=lambda o: (-o.criticality, o.cost)):
        st = o.verify(scene)                      # observe / certify / probe
        if st == UNKNOWN and o.criticality == HARD:
            g = svc.choose(obs, scene)            # 用 R69 交互为义务举证
            if g is not None:
                st = o.verify_with(g)
        if st == REFUTED:
            return REJECT
        if st == UNKNOWN and o.criticality == HARD:
            return DEFER
    return ACCEPT

# IP-267 CSE：运行时盾牌，只执行合同允许的认证技能
def shielded_execute(proposal, scene, closure, contracts):
    if closure != ACCEPT:
        return alternative_or_stop(proposal, scene)
    safe_set = contracts.envelope(proposal.skill, scene)
    a = certified_controller(proposal.skill, proposal.params, scene)
    a = project_to_safe_set(a, safe_set)          # 投影或忽略 VLA 建议
    if not invariant_holds(a, proposal.skill, scene):
        return fallback(scene)
    return a

# IP-268 SLC：言语行为、权限、同意与注入检查
def language_gate(language, source, K):
    act = parse_speech_act(language)
    if act not in {COMMAND, REQUEST}:
        return NO_OBLIGATION
    if not authorized(source, act, K) or not consent_ok(source, act, K):
        return BLOCK
    if contains_injection(language, source) or conflicts_with_K(act, K):
        return BLOCK
    return OK

# IP-269 OCM：结果集而不是单点预测
def outcome_safe(plan, scene, world_model, safe_set, alpha):
    Yhat = conformal_outcome_set(world_model, plan, scene, alpha)
    shift = shift_detector(scene)
    return (Yhat <= safe_set), coverage(Yhat), shift

# IP-275 主闭环：VLA 慢环 + 安全层快环，R69 作为执行与交互内核
def OATH_round(M, obs, language, source):
    if M.slc.gate(language, source, M.K) != OK:
        return M.ladder.degrade('language_block')
    prop = M.vpa.propose(obs, language, M.proprio)          # 1–5Hz，异步
    obs_ = M.obm.extract(prop, M.scene, M.scl, M.K)
    closure = M.obm.close(obs_, M.scene, M.svc)
    if closure == DEFER:
        g = M.svc.choose(obs_, M.scene)                     # 只买「安全信息」
        closure = M.obm.close_with(g)
    if closure != ACCEPT:
        return M.ladder.degrade(closure)
    out_ok, cov, shift = M.ocm.outcome_safe(prop.plan, M.scene,
                                            M.wm, M.safe_set, M.alpha)
    if (not out_ok) or shift > M.tau_shift or cov < M.alpha_min:
        return M.ladder.degrade('outcome_risk')
    a = M.cse.execute(prop, M.scene)                        # 200–1000Hz 内环
    M.sca.submit(prop, obs_, closure, a, cov, shift)        # 异步审计
    return a
```

## 3. 推导

**引理 19（义务闭合的可靠性）** 若所有验证器 `μ` 是可靠的（不会把假命题判为 `verified`），且执行前所有硬义务 `verified`，则对实际场景 `S_t`，`Pre_s ∧ Assump_s ∧ Inv_s` 成立。证明：合同公式经 IVB 在 `S_t` 上求值，义务是这些公式的逐条实例化，闭合是合取；可靠验证器保证合取为真。系：**VLA 的接地可以错，但合同前提在真实场景上检查，所以错接地只会导致拒绝，不会导致带错前提执行。**

**引理 20（接地交换的可检测性）** 若独立感知能够区分合同相关实体（`bind` 的误绑率 ≤ ε_b），则接地交换攻击被捕获的概率 ≥ 1−ε_b；未捕获时，`Pre_s` 在错误实体上求值，可能产生 `refuted` 或 `unknown`，但**不会自动 verified**。注意：若独立感知本身被致盲，则无保证——这就是 RRL 的 `ε_mon`。

**定理 18（VLA-无关安全 / 零信任提议）** 在 A99–A103（合同可靠、义务验证器可靠、K 在其声明作用域内完备、OCM 覆盖成立、独立绑定可靠）下，对任意 VLA（包括对抗选择、投毒、后门）以及任意提案序列，执行轨迹满足 K 中所有硬约束的概率 ≥ 1−α−ε_shift；VLA 只能影响任务成功率与效率，不能影响硬安全。证明：VLA 只影响 `π` 与 `θ`；执行由 CSE 在 `Safe_s` 内投影并检查 `Inv_s`；硬义务闭合门控在 CSE 之前；OCM 检查结果集。因此安全证明不引用 VLA 的正确性。系：**安全与能力解耦——可以换更弱的 VLA 而不丢安全，也可以换更强的 VLA 而不自动获得安全。**

**引理 21（SVoI 的单调性与 R69 特例）** SVoI 只在 `P(unknown)>0` 且验证能降低风险时为正；按 `SVoI/c` 贪心分配预算，在子模性下达到 `1−1/e` 近似最优风险下降。若 `K` 只含任务成功谓词且 `κ` 相同，`SVoI` 退化为 R69 的 `VoI−c`；若所有硬义务都 `verified`，OATH 不交互，逐指令退化为 R69。系：**R69 是 OATH 在「安全义务已闭合」边界上的退化，而不是被替代。**

**定理 19（共形结果安全）** 若 `Ŷ_{1−α}` 在可交换性下满足 `P(Y∈Ŷ)≥1−α`，且系统只接受 `Ŷ⊆Safe` 的计划，则 `P(执行后发生 K-危害) ≤ α`（在 `Safe` 为真实安全集的下近似、且覆盖校准有效时）。在分布漂移下，自适应共形只能保证长期平均覆盖；漂移分 `shift` 越界时必须停止签发证书。**诚实声明：这是「相对于 K 与校准分布」的概率保证，不是绝对安全。**

**定理 20（组合安全与单调退化）** 若每个技能合同有效、组合规则（定义 324）成立、且每个子计划的结果集安全，则顺序执行的硬不变式保持；若任一组件失效，退化阶梯只缩小安全集，故对任意 `L_i`，`Safe(L_{i+1}) ⊆ Safe(L_i)`；在 `L1/L2` 分别逐指令等于 R69/R68（在关闭 VLA/交互时）。因此 OATH 的安全侧永不弱于其退化锚点，能力侧可以更强。

## 7. 本轮最大风险

**一句话**：OATH-RAS 把安全性建立在「安全宪法 K 与合同库覆盖了真实危害」这一前提上——**一旦危害不在 K 的枚举里（未知的未知、语义层面的新型伤害、感知盲区、或合同规避），系统会拿着一份完整、可审计、却对真正危险视而不见的证书，自信地执行；最危险的不是没有证书，而是一张只证明了你所担心的那部分安全的证书。**

**次级风险与缓解**：能力差距（VLA 提议的技能不在合同库）→ 组合认证 + 明确安全停止；过度保守被绕过 → 解释式拒绝 + SVoI + E308/E313；独立感知被致盲 → 多源绑定 + `ε_mon` + E303；共形覆盖漂移失效 → 自适应共形 + shift 门控；语言注入/权限伪造 → SLC 类型系统 + 来源检查 + E304；组合伤害 → 计划级合同组合 + 结果集监控 + E306。
