# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「场景落地」×「小样本学习」）

> R69 教会闭环「问」，但有一个未言明的前提：**这套问法是在训练场景里标定好的**。换一间房、换一个人、换一只末端执行器、换一种光照与口音，R69 的模态先验、可靠图、交互成本都来自「另一个世界」。R69 自陈的最大风险——模态权重不可信则 VoI 在错误信念上计算——在部署时不是小概率，而是**默认状态**。
>
> 本轮两个灵感指向同一件事的两面：
> - **场景落地**：真问题不是 benchmark 上的渐近性能，而是「最后一公里」——一个新场景凭什么被允许上岗？上岗后怎么知道自己已偏离契约？
> - **小样本学习**：新场景不给你大数据，只给几段人类示范。这 K 段示范既是唯一的信息来源，也是唯一的污染入口。
>
> 核心命题：**部署不是一次迁移，而是一次少样本的认知定位 + 一份可以被拒绝的安全论证。** 把 R69 的「向谁求证」再上一层，变成「向场景求证的样本够不够、信不信得过、能不能上岗」。命名 **FIELD-RAS**（Few-shot Epistemic Localization & Deployment for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**到了新地方，我凭什么说自己会，又凭什么敢说自己不会**」。

## 0. 直觉与动机

**灵感 1（场景落地 → 部署是一份契约，不是一次迁移）**
直觉：我们习惯把「迁移」当成把权重搬过去再微调，但工程上真正决定生死的是一张**场景契约**：这个系统在什么环境、什么模态集合、什么交互预算下被验证过。R69 的所有保证（λ floor、VoI、证据纪律）都只在契约内成立。场景落地因此不是「把 FLUID-RAS 搬过去」，而是「为每个新场景签一份契约，并持续核对它没有被违反」。契约之外，系统的正确回答是**拒绝**，而不是外推。

**灵感 2（小样本学习 → K 段示范既是唯一信息，也是唯一污染）**
直觉：人类上岗靠「师傅带几遍」，这正是 few-shot。但 few-shot 的甜与毒是同一个机制：K 很小，所以每段示范的权重都很大；K 很小，所以一段坏示范、一次模态遗漏、一次投毒，就能把先验整体掰弯。R69 用来防投毒的是「k 个正交证据源一致」，但在部署阶段，这些证据源本身可能都由同一段带偏的示范生成——**一致，可能只是一起错**。所以少样本层必须回答一个 R69 没问的问题：**我这几段示范，凭什么代表这个场景？**

**灵感 3（元层级 VoI → 从「问哪个动作」到「要哪段示范」）**
直觉：R69 的 MINT 在运行期问「哪个信息动作最值钱」。部署期有一个完全同构的问题：**该向人类要哪一段示范**。示范要花人的时间，且信息量差异极大——演示一个罕见模态，比重复演示一个常见模态值钱得多。于是 VoI 被上提一层：运行期选动作，部署期选样本。这不是新算法，而是**同一台 VoI 机器换了输入**，这正是「层叠而非并列」的最好体现。

**灵感 4（严格的层叠 → R70 必须包含 R69）**
直觉：如果场景契约恰好等于训练分布、示范集覆盖全部模态、信任域收缩到零，FIELD-RAS 必须逐指令退化为 R69——就像 R69 在「永不交互」时退化为 R68。否则每加一层就多一个需要独立信任的黑箱。本轮把这条写成定理，而不是姿态：**安全侧只允许单调变强，绝不允许因为「加了部署层」而变弱**。

**灵感 5（拒绝的权利 → 安全论证的第一句话可以是「不」）**
直觉：R68 的保守是「慢一点」，R69 的保守是「问一句」，但两者都默认「必须行动」。真正落地的系统需要一个更强的选项：**在证据不足时拒绝上岗，或只在降级模式下上岗**。这不是逃避，而是把「不知道能不能行」显式化为三态决策（deploy / degrade / refuse）。一个只会说「我能」的系统不叫安全，叫自信。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FIELD-RAS 总览）** FIELD-RAS = (SCF, FSC, MEC, CTR, FGR, NMD, SDL, DCC, RAS-WM††)。三不变式：
(i) **实时零学习写**（继承 R68 定义 276-i 与 R69 定义 293-i）：运行期只推理与监控，不更新任何校准参数；
(ii) **上岗写入受限**：少样本校准只允许发生在离线「上岗窗口」，且只能落在信任域 CTR 内，必须可回滚、带样本溯源；
(iii) **三态部署**：deploy / degrade / refuse 必须由证书 DCC 显式给出，且 **refuse 永远合法**（安全论证允许说不）。

**定义 311（场景契约 SCF）** 契约 C = (E_env, M_ref, ℰ_ref, c_ref, B_int, A)，分别为环境包络、参考模态集、参考证据源集、交互成本先验、交互预算、显式假设集。场景指纹 φ(C) = (环境统计, 传感器签名, 模态签名, 交互可用性)。运行期观测 o_t 若出 E_env 或触发假设违例 ⇒ 契约失效。

**定义 312（少样本上岗集）** D_K = {(o_i, ξ_i, y_i)}_{i=1}^{K}，K ≤ K_max，为人类示范（观测、动作块、语义标签/意图）。假设示范可被选择性请求（定义 318），不必一次性给定。

**定义 313（少样本模态先验校准）** 由 D_K 估计模态集 M̂_K、权重 ŵ_K、原型 ξ̄_K 与模态内方差；用 Dirichlet/共轭先验平滑，并对未见模态保留质量 ε_u。校准输出 Θ_K = (M̂_K, ŵ_K, Σ̂_K, ℰ̂_K, ĉ_K)。

**定义 314（元认知覆盖 MEC）** 未覆盖质量 U_cov = P(m ∉ M̂_K | C) 的估计；用 Good–Turing/单例占比 + conformal p 值给出上界 Û_cov。若 Û_cov > τ_cov ⇒ 覆盖不足，不得以「已定位」上岗。

**定义 315（校准信任域 CTR）** 允许的校准参数变化限于球 B(Θ_0, ρ)：要求 (a) KL(π_K‖π_0) ≤ ρ；(b) 安全关键集上行为变化 ≤ ε_adapt；(c) λ_floor 不得低于 R69 基线；(d) ECE 不得升高。越界即投影回边界或拒绝该次校准。

**定义 316（少样本泛化守护 FGR）** 留一示范一致性：对每段示范做 leave-one-shot-out 重校准，若某模态的支持数 < m_min（默认 2）则为**单例模态**，不得单独驱动 VoI/部署决策；LOO 一致率 < τ_loo ⇒ 视为过拟合的少样本，退回 R69 保守。

**定义 317（新模态哨兵 NMD）** 运行期若 Δa（R69 定义 301）超阈、或动作落在 M̂_K 密度之外、或模态间距结构突变 ⇒ 置 U_novel；**禁止把新模态就近映射到已知模态**，直接进入 R69/R68 保守并请求人工复标定。

**定义 318（部署期元 VoI / 主动选样本）** 候选示范 d ∈ 𝒟，选择 d* = argmax_d [VoI_cal(d) − c_human(d)]，s.t. 人类时间预算与溯源多样性约束。VoI_cal(d) = E_{D_K∪{d}}[H(M|D_K) − H(M|D_K∪{d})]。停止条件：边际 VoI ≤ c_human 或预算耗尽。

**定义 319（场景漂移账本 SDL）** 以契约基线的 (r_res, Δa) 联合分布为零假设，运行期持续做漂移检验；漂移分 D_t 触发「重新标定 / 降级 / 拒绝继续」。这是 R69 定义 309 对偶判据在部署时间尺度上的累积版。

**定义 320（部署三态与证书 DCC）** 决策 δ ∈ {DEPLOY, DEGRADE, REFUSE}。DEPLOY：覆盖、ECE、信任域、LOO、漂移全部达标且安全论证通过；DEGRADE：移除交互/VoI 或用 R68 纯保守继续；REFUSE：不启用（或交还人类）。证书 J_FIELD 记录依据，任何一项失效都只能向更保守方向迁移。

**定义 321（少样本投毒干扰集 ℰ_shot）** 非代表性示范、对抗性选样、标签噪声、模态遗漏、单源共谋（所有示范来自同一偏见来源）。AIC-FIELD = AIC-FLUID × ℰ_shot。

**定义 322（证书 J_FIELD）** J_FIELD = (J_FLUID, Û_cov, ρ_used, LOO_rate, singleton_modes, shot_provenance_hash, drift_stat, δ, field_ver)。Valid ⇔ Valid(J_FLUID) ∧ Û_cov ≤ τ_cov ∧ CTR 未越界 ∧ (δ=REFUSE ∨ LOO ≥ τ_loo)。

**定义 323（安全自适应约束）** 任何 Θ_K 必须满足：在契约验证集上 risk(Θ_K) + L_λρ ≤ risk(Θ_0)（Θ_0 为 R69 基线）；不满足则拒绝该次校准并保留旧参数（单调不回退）。

**定义 324（实时预算与写隔离）** 运行期开销只含 NMD + SDL + 门控；FSC/MEC 的重计算被限制在上岗窗口或人工触发的维护窗口，保证 P99 实时预算不被部署层击穿。

**定义 325（场景族与元训练）** 场景族 𝒞 上元训练「快速定位器」Φ_meta，使新场景所需 K 与校准步数下降；元训练只在离线进行，且元先验本身受 CTR 约束，不得绕过契约。

**定义 326（保守阶梯）** FIELD-DEPLOY ⊃ FIELD-DEGRADE(R69) ⊃ R69-no-interaction ⊃ R68-pure-conservative。每一级都携带自己的证书，且向下退化时 λ 单调不降、动作连续。

## 2. 关键算法骨架

```python
# IP-270 Meta-VoI：部署期主动选示范（运行期 MINT 的「上一层」）
def select_shots(candidates, D_K, budget):
    while budget.left > 0:
        best = None
        for d in candidates:
            if not provenance_ok(d): continue
            voi = expected_mode_entropy(D_K) - expected_mode_entropy(D_K + [d])
            score = voi - human_cost(d)
            if best is None or score > best.score: best = (d, score)
        if best is None or best.score <= 0: break
        D_K.append(best.d); budget.spend(best.d)
    return D_K

# IP-265 FSC：少样本校准 + IP-267 CTR 信任域投影
def commission(D_K, theta0, ctr):
    theta = fit_mode_prior(D_K)                 # M̂_K, ŵ_K, Σ̂_K, ℰ̂_K, ĉ_K
    theta = ctr.project(theta0, theta)          # KL/行为/λ 安全 多重约束
    return theta

# IP-266 MEC：覆盖不足就说「不敢」
def coverage_bound(D_K, singleton_mass):
    return good_turing_upper(D_K) + conformal_slack(D_K, singleton_mass)

# IP-268 FGR：留一示范一致性，识别单例/过拟合
def loo_guard(D_K):
    rates, singles = [], []
    for i in range(len(D_K)):
        th = commission(D_K[:i] + D_K[i+1:], ...)
        rates.append(agree(th, D_K[i]))
        if support(D_K[i].mode) < M_MIN: singles.append(D_K[i].mode)
    return mean(rates), singles

# IP-269 NMD：新模态哨兵（绝不就近映射）
def novel_sentinel(policy, o, theta_K, r69):
    a = -policy.log_likelihood(r69.last_action, o)
    if a > TAU_FMA or density_outside(o, theta_K): return True
    return r69.last_r_res < TAU_RES and a > TAU_FMA   # 与 R69 对偶判据合流

# IP-272 DCC：三态部署证书
def deployment_decision(ucov, ece, loo, drift, ctr_ok):
    if ctr_ok and ucov <= TAU_COV and ece <= TAU_ECE and loo >= TAU_LOO and drift < TAU_DRIFT:
        return "DEPLOY"
    if ctr_ok and (ece <= TAU_ECE): return "DEGRADE"   # 退 R69 / R68，保命
    return "REFUSE"

# IP-274 主闭环：R69 外层加「部署闸 + 哨兵 + 漂移账本」
def FIELD_RAS_round(M, obs, cert):
    if cert.decision == "REFUSE":  return M.safe_hold()          # 合法地不动
    if cert.decision == "DEGRADE":
        return M.r68_round(obs) if cert.drop_interaction else M.fluid_round(obs)
    if M.nmd.novel_sentinel(M.fmp, obs, M.theta_K, M.r69):
        M.sdl.log(novel=True); return M.r69.conservative_round(obs)  # 不就近映射
    out = M.r69.round(obs)                                       # 复用 R69 全闭环
    M.sdl.update(out.r_res, out.delta_a)                         # 漂移账本
    if M.sdl.drift_exceeded():  cert.request_recommission()
    return out
```

## 3. 推导

**引理 19（少样本覆盖的硬下界）** 设某模态真实质量 p_min，K 段独立示范中完全漏掉该模态的概率为 (1−p_min)^K。要在置信 1−δ 下覆盖它，需 K ≥ ln δ / ln(1−p_min)。系：**任何有限 K 都无法认证长尾模态的覆盖**——所以「少样本上岗」的诚实输出不是「我已覆盖全部」，而是「我覆盖了高频部分 + 一个能报警的哨兵 + 一个可以说不会的拒绝权」。这把 R69 的「模态可信」从假设变成了**被度量、且可被证伪**的对象。

**引理 20（信任域保持安全）** 若 Θ_K ∈ B(Θ_0, ρ)、λ_floor 关于 Θ 是 L_λ-Lipschitz、且安全关键集上行为变化 ≤ ε_adapt，则部署后单步风险 ≤ R69 风险 + L_λρ + ε_task(ε_adapt)。令 ρ→0 即逐指令回到 R69。故 R70 在安全侧不弱于 R69，且「严格包含」由 ρ=0、契约=训练分布、Û_cov=0 三条件同时成立时精确取得。

**引理 21（少样本的自证陷阱）** 若示范与运行期证据源共享同一偏差 b（同一数据来源、同一标注者、同一演示风格），则即使 k 个证据源「一致」，其错误率也不随 k 下降，因为相关 ρ_b ≈ 1：错误率 ≤ δ_b·ρ_b^{k−1} + ε ≈ δ_b。**一致不等于独立**。系：部署期的证据纪律必须升级为「来源多样性纪律」（provenance diversity），否则 R69 的 k-一致只是把同一个偏见投了 k 次票。

**引理 22（元 VoI 的单调收益）** 在候选示范信息量有界、人类成本可加时，按 VoI_cal 贪心选样相对随机选样，在相同 K 下使 H(M|D_K) 的期望下降更快（次模性下的 (1−1/e) 近似）；边际 VoI ≤ c_human 时停止是成本最优的。系：R69 的 MINT 与 R70 的选样是同一台 VoI 机器的两个时间尺度，可共享打分器与校准器。

**定理 18（FIELD 严格包含 R69）** 在 A99–A101 下，FIELD 的期望风险 ≤ R69；当契约等于训练分布、K 覆盖充分、CTR 半径 ρ=0、NMD 静默时，两者逐指令相同；当覆盖不足或证书拒绝时，FIELD 输出 REFUSE/DEGRADE，其风险 ≤ R68 纯保守基线。故 R70 不是 R69 的替代，而是它的**部署轴泛化**。

**定理 19（三态部署的安全性）** 若 DCC 仅在 J_FIELD Valid 时判 DEPLOY，则任何被判 DEPLOY 的部署其单步风险 ≤ R69 + L_λρ + ε_task；DEGRADE 保证 λ 单调不降且动作连续（继承 R69 定理 17 / R68 定理 15）；REFUSE 不产生动作。因此最坏情形被 R68 基线兜住，部署层只可能「少干活」，不可能「多冒险」。

## 6. 本轮最大风险

**一句话**：FIELD-RAS 把「能不能上岗」交给少样本校准，而少样本既定义了「世界应该长什么样」，又被用来验证「世界是不是这样」——**若 K 段示范不具代表性或被同源污染，系统会得到一个自洽但错误的世界模型，然后用覆盖估计、留一一致、证据纪律一层层把它认证成「可部署」**；部署层的证书于是从安全护栏变成了偏见的公证人——**用几段示范自证清白，比不标定更危险**。

# IP-270 Meta-VoI：部署期主动选示范
def select_shots(candidates, D_K, budget):
    while budget.left > 0:
        best = None
        for d in candidates:
            if not provenance_ok(d): continue
            score = (expected_mode_entropy(D_K) - expected_mode_entropy(D_K + [d])) - human_cost(d)
            if best is None or score > best.score: best = (d, score)
        if best is None or best.score <= 0: break
        D_K.append(best.d); budget.spend(best.d)
    return D_K

# IP-265 FSC + IP-267 CTR：少样本校准与信任域投影
def commission(D_K, theta0, ctr):
    theta = fit_mode_prior(D_K)                 # M̂_K, ŵ_K, Σ̂_K, ℰ̂_K, ĉ_K
    return ctr.project(theta0, theta)           # KL/行为/λ 安全多重约束

# IP-266 MEC：覆盖不足就说「不敢」
def coverage_bound(D_K, singleton_mass):
    return good_turing_upper(D_K) + conformal_slack(D_K, singleton_mass)

# IP-268 FGR：留一示范一致性
def loo_guard(D_K):
    rates, singles = [], []
    for i in range(len(D_K)):
        th = commission(D_K[:i] + D_K[i+1:], ...)
        rates.append(agree(th, D_K[i]))
        if support(D_K[i].mode) < M_MIN: singles.append(D_K[i].mode)
    return mean(rates), singles

# IP-269 NMD：新模态哨兵（绝不就近映射）
def novel_sentinel(policy, o, theta_K, r69):
    a = -policy.log_likelihood(r69.last_action, o)
    if a > TAU_FMA or density_outside(o, theta_K): return True
    return r69.last_r_res < TAU_RES and a > TAU_FMA   # 与 R69 对偶判据合流

# IP-272 DCC：三态部署证书
def deployment_decision(ucov, ece, loo, drift, ctr_ok):
    if ctr_ok and ucov <= TAU_COV and ece <= TAU_ECE and loo >= TAU_LOO and drift < TAU_DRIFT:
        return "DEPLOY"
    if ctr_ok and (ece <= TAU_ECE): return "DEGRADE"
    return "REFUSE"

# IP-274 主闭环：R69 全闭环外层 + 部署闸 + 哨兵 + 漂移账本
def FIELD_RAS_round(M, obs, cert):
    if cert.decision == "REFUSE":  return M.safe_hold()
    if cert.decision == "DEGRADE":
        return M.r68_round(obs) if cert.drop_interaction else M.fluid_round(obs)
    if M.nmd.novel_sentinel(M.fmp, obs, M.theta_K, M.r69):
        M.sdl.log(novel=True); return M.r69.conservative_round(obs)
    out = M.r69.round(obs)
    M.sdl.update(out.r_res, out.delta_a)
    if M.sdl.drift_exceeded(): cert.request_recommission()
    return out

## 4. 推导

**引理 19（少样本覆盖硬下界）** 模态质量 `p_min` 时，K 段独立示范漏掉它的概率 `(1−p_min)^K`；置信 `1−δ` 覆盖需 `K ≥ lnδ/ln(1−p_min)`。系：任何有限 K 都无法认证长尾覆盖——诚实输出是「高频覆盖 + 哨兵 + 拒绝权」，把 R69 的「模态可信」从假设变成可证伪对象。

**引理 20（信任域保持安全）** `Θ_K∈B(Θ_0,ρ)` 且 `λ_floor` 为 `L_λ`-Lipschitz、安全关键行为变化 ≤ `ε_adapt`，则单步风险 ≤ R69 + `L_λρ` + `ε_task`；`ρ→0` 逐指令回 R69。故安全侧不弱于 R69，「严格包含」在 `ρ=0 ∧ 契约=训练 ∧ Û_cov=0` 时精确成立。

**引理 21（少样本自证陷阱）** 若示范与运行期证据源同源（偏差相关 `ρ_b≈1`），则 k 个「一致」证据的错误率 `≤ δ_b·ρ_b^{k−1}+ε ≈ δ_b`，不随 k 下降。**一致不等于独立**；部署期证据纪律须升级为来源多样性纪律（provenance diversity）。

**引理 22（元 VoI 单调收益）** 信息量有界、成本可加时，按 `VoI_cal` 贪心选样在相同 K 下比随机更快降低 `H(M|D_K)`（次模性下 ≈`1−1/e`）；边际 VoI ≤ `c_human` 时停止最优。系：R69 MINT 与 R70 选样是同一 VoI 机器的两个时间尺度。

**定理 18（FIELD 严格包含 R69）** A99–A101 下 FIELD 期望风险 ≤ R69；契约=训练、K 充分、`ρ=0`、NMD 静默时逐指令相同；覆盖不足/拒绝时输出 REFUSE/DEGRADE，风险 ≤ R68 基线。R70 是 R69 的部署轴泛化。

**定理 19（三态部署安全性）** 仅当 `J_FIELD` Valid 才判 DEPLOY，则其单步风险 ≤ R69 + `L_λρ` + `ε_task`；DEGRADE 保证 λ 单调不降、动作连续；REFUSE 不产生动作。最坏情形被 R68 基线兜住，部署层只可能「少干活」，不可能「多冒险」。
