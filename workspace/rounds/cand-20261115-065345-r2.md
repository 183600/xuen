# 第 4 轮（灵感循环第 4 轮；本轮灵感：「运动学」×「SLAM」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。运动学与 SLAM 各自只给 InstructGauge 增加一层「证书」，不替换任何原有闭环；任一证书缺失都必须能一键退回上一轮。

## 0. 直觉与动机

**灵感 1（运动学 → 从「动作可行」升级为「位姿可信」）**
前几轮一直在问「测什么、测多少、按什么顺序测」，却默认末端执行器总能到达并稳定在期望位姿。真实探测中，动作是关节空间轨迹：可达性、关节/速度限位、奇异点邻近度、可操作度都会改变「这一次测量到底发生在哪里」。运动学给出的不是又一个软偏好，而是**硬证书**：`q ∈ Q_adm`、奇异裕度 `d_sing > 0`、关节裕度、以及一条可退回的冗余构型。更重要的是，它给出可量化的灵巧度 `κ_J`：越接近奇异，同样的关节误差会被放大成更大的笛卡尔误差——所以**块长 K 必须随 κ_J 收紧**。这与第 3 轮「指令越含糊、块越短」同构，但换了物理轴：从语义不确定性换成运动学病态性。

**灵感 2（SLAM → 盲区不是绝对地点，而是带协方差与纪元的锚）**
盲区是地图里的区域，不是一个绝对坐标。修盲区的质量不只取决于「测到了什么」，还取决于「地图认为你在哪里测的」。SLAM 提供位姿、协方差、漂移与回环；一次回环可以把旧地图整体拉变形，让昨天「已修复」的契约静默失效。因此契约必须**带帧、带协方差、带纪元**，而不是只用一个区域 id 索引。另一个被低估的点：正运动学（关节编码器 + FK）与 SLAM 是两套**独立位姿证人**；二者不一致时，可能意味着打滑、绑架或地图投毒——这给了我们一个不依赖真值的交叉校验。

**灵感 3（耦合 → 运动学完美但空间锚错，是最危险的「自信地测错地方」）**
两者耦合时，位姿误差有两个来源：关节/标定误差经 `J` 放大，SLAM 误差经锚传播；两者在线性化下可合成一个总位姿协方差。最危险的失效不是动作越界，而是**动作完全合法、校准也覆盖，但契约锚在漂移后的错误帧上**——系统会「自信地测量错误的位置」。解法是三根结构支柱：**运动学证书**（不可达/近奇异不执行）、**帧-纪元锚**（回环后旧契约强制失效或重验）、**位姿一致性证人**（FK 与 SLAM 的马氏距离门控；不一致就降级为局部帧临时契约）。统计上再用**位姿自适应共形**处理异方差，而不是继续用单一全局阈值。

## 1. 研究问题（本轮要回答什么）

- **Q1（运动学证书）**：运动学能否把「动作可行」提升为「位姿可信」，并把奇异/不可达风险压到结构级零？
- **Q2（空间锚的时效）**：SLAM 漂移与回环下，计量契约如何保持「空间上可追溯」，而不是静默失效？
- **Q3（耦合放大）**：位姿不确定性是否沿「关节→任务空间→地图帧」被放大？能否用运动学证书、纪元失效与位姿自适应校准把它压回可界？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–463）

**P1 运动学证书（Kinematic Certificate）**
任何未通过可达性、关节/速度限位、奇异裕度与撤退路径检查的位姿不得执行；近奇异强制 `K=1`。形式化方向：`KinCert` 输出关节轨迹或 `⊥`，后者退回第 3 轮按指令目标逐步规划。

**P2 帧-纪元锚（Frame-Epoch Anchor）**
每个契约携带 `(frame, Σ_pose, epoch)`。回环使锚帧位移超过 `τ_anchor` 或协方差变化超过 `τ_Σ` ⇒ 旧纪元契约标记 stale，禁止进入校准与热替换，必须重探或重锚。纪元只增不减，确保失效可审计。

**P3 位姿一致性证人（Pose Consistency Witness）**
FK 位姿与 SLAM 位姿的马氏距离必须低于 `χ²` 门限；超限 ⇒ 局部帧临时契约 + 告警，禁止静默信任。这把「地图投毒 / 打滑 / 绑架」从不可观测故障变成可门控事件。

**P4 计量下限（Metrology Floor）**
主动 SLAM 的探索收益不得以牺牲契约精度为代价：联合目标中计量信息增益有硬下界 `ε_m`。探索只能在「计量可采纳集」内进行，避免「看得更多、测得更差」。

## 3. 与基线的接口（如何退化）

- SLAM 不可用 / `PCC` 超限 ⇒ 局部帧临时契约（anchor = 当前传感器帧），等价 InstructGauge；
- 运动学证书不可用 / 近奇异 ⇒ `K=1` + 保守限位，等价 ToolGauge 逐步执行；
- 位姿自适应分层样本不足 ⇒ 回退第 3 轮指令分层阈值 ⇒ 全局共形；
- 回环纪元失效且无法重验 ⇒ 标记 stale 并重探，不进入数值更新；
- 继续执行第 3 轮退化链：InstructGauge → ToolGauge → LeanGauge → MODGAUGE。

## 4. 预期贡献

1. 一个**运动学证书 + 灵巧度条件化块长**，把「近奇异时动作不可预测」变成可证的 K 收紧；
2. 一个**帧-纪元锚与回环失效**机制，让计量契约在 SLAM 地图修订下仍可审计、不可静默复用；
3. 一个 **FK–SLAM 交叉证人**，无需真值即可检测打滑、绑架与地图投毒；
4. 一个**位姿自适应共形校准**，修正位姿异方差导致的覆盖失效；
5. 一条完整可证伪路径：E457–E472 覆盖运动学、协方差、回环、运动补偿、对抗与 50Hz 时序。

## 5. 本轮最大风险

**一句话**：把 SLAM 位姿当成「足够准的真值」是最大风险——运动学证书会让动作看起来无懈可击，位姿自适应校准又会在错误帧上给出「覆盖成立」的假安全感，最终系统不是测错数值，而是**自信地测错了地方**。

## 2. 形式化定义（要点）

**定义 448（运动学可采纳集与证书）**
`Q_adm(s) = { q ∈ Q : q_min+δ_q ≤ q ≤ q_max−δ_q, |q̇| ≤ q̇_max, d_sing(q) ≥ d_min, w(q) ≥ w_min, Retreat(q) ≠ ∅ }`。
`KinCert(s) = (q_{1:K}, ξ_{1:K}, κ_J, d_sing, margin_q, Retreat, checker_version)`，其中 `ξ_i = FK(q_i)`。`KCC` 把笛卡尔探测 `probe` 编译为关节轨迹；若任一途径点不满足 `Q_adm` 或离散路径的 Lipschitz 管越界，则返回 `⊥`。

**定义 449（灵巧度指标）**
`κ_J(q) = σ_max(J(q)) / σ_min(J(q))`，`w(q) = sqrt(det(J(q)J(q)ᵀ))`，`d_sing(q) = σ_min(J(q))`。`κ_eff = max(κ_J, 1)`。条件数越大，任务空间某一方向对关节误差越敏感；因此 `κ_J` 不是软评分，而是块长与误差预算的硬约束输入。

**定义 450（运动学证书可靠性条件）**
若 `KinCert(s)` 被签发，则对所有 `i`：`q_i ∈ Q_adm` 且 `‖FK(q_i) ⊖ ξ_i^des‖ ≤ ε_kin`；且相邻途径点之间的连续插值轨迹保持在 `Q_adm` 内（用 `q` 的 Lipschitz 界与检查分辨率验证）。任一条件失败 ⇒ 不签发证书（`⊥`）。

**定义 451（灵巧度条件化块长）**
`K_dex(q_{1:K}) = max { K : Σ_{i=1}^K κ_J(q_i)·J_ref·δ_q + K·δ_cal + ε_int ≤ ε_pose }`，
`K_MAX^kin = min( K_MAX(ι), K_dex, K_ret )`，其中 `K_ret` 由撤退路径预算 `L_ret` 给出。近奇异时 `κ_J → ∞` ⇒ `K_dex → 1`；这与第 3 轮 `K_MAX(ι)` 的语义上限相乘，得到同时受「指令歧义 × 运动学病态」约束的块长。

**定义 452（位姿协方差合成）**
`Σ_pose^k = J(q) Σ_q J(q)ᵀ + Σ_cal + O(‖δ_q‖²)`（FK 位姿协方差，含标定误差）。当 FK 与 SLAM 误差独立时 `Σ_pose^⊕ = Σ_pose^k + Σ_pose^s`；存在相关项时 `Σ_pose^⊕ = Σ_pose^k + Σ_pose^s + 2Σ^{ks}`；无法估计相关项时使用保守膨胀 `Σ̃ = (1+γ)Σ_pose^⊕`。`Σ̃` 同时供 PCC 门控与 PAC-Cal 归一化使用。

**定义 453（帧-纪元锚）**
`a = (F, ξ_a, Σ_a, e)`：`F ∈ {map, local, sensor}` 为帧标签，`ξ_a` 为锚位姿，`Σ_a` 为锚协方差，`e ∈ N` 为地图纪元（回环/地图修订单调递增）。契约 `Contract(s)` 必须绑定 `FrameTag = a`。有效性：`a.e = e_current`，或 `disp(a, current) ≤ τ_anchor` 且 `‖Σ_a − Σ_current‖ ≤ τ_Σ`；否则标记 `stale`。

**定义 454（位姿一致性证书 PCC）**
`r = log( FK(q) ⊖ ξ_slam ) ∈ se(3)`（李代数残差），`d_M² = rᵀ (Σ_pose^k + Σ_pose^s)^{-1} r`。
`PCC = 1[ d_M² ≤ χ²_{6,1−β} ]`。失败 ⇒ 切换到局部帧临时契约（`anchor = (sensor, ξ_sensor, Σ_sensor, e_local)`），并要求独立重观测后才允许更新持久契约；绝不静默信任 SLAM 位姿。

**定义 455（连续时间运动补偿）**
设位姿轨迹 `T(t)` 为 `C²`，采样周期 `τ_s`，传感器与位姿时间差 `|τ_sensor − τ_pose| ≤ τ_sync`。分段线性插值 + slerp 的误差界：平移 `ε_int ≤ (1/8)·a_max·τ_s²`，旋转 `ε_rot ≤ (1/8)·α_max·τ_s²`。对杠杆臂为 `ℓ` 的测点，运动补偿后的地图点误差 `≤ ε_int + ℓ·ε_rot + v_max·τ_sync`。该误差直接计入 `ε_pose`，从而进入 `K_dex`。

**定义 456（位姿自适应共形校准 PAC-Cal）**
非一致性分数 `R_i = ‖y_i − ŷ_i‖_{(Σ_i^⊕)^{-1}}`（马氏残差），或 `R_i = |y_i − ŷ_i| / σ(Σ_i^⊕)`。按位姿不确定度（如 `tr(Σ_i^⊕)` 或 `κ(Σ_i^⊕)`）分箱 `B_j`，箱内取共形分位 `q_j`，使箱内覆盖 `P(y ∈ Ĉ | B_j) ≥ 1−α`。若 `|C_cal ∩ B_j| < n_min` ⇒ 回退第 3 轮指令分层阈值 ⇒ 全局阈值。归一化分数使校准对异方差局部自适应；分箱宽度 `δ` 与尺度 Lipschitz 常数 `L_σ` 共同控制跨箱覆盖偏差。

**定义 457（锚纪元失效 MAI）**
回环或地图修订使 `e → e+1`。对每个受影响的锚计算 `Δ_F = ‖ξ_F^{(e+1)} ⊖ ξ_F^{(e)}‖` 与 `Δ_Σ = ‖Σ_F^{(e+1)} − Σ_F^{(e)}‖`。若 `Δ_F > τ_anchor` 或 `Δ_Σ > τ_Σ`，则所有 `epoch = e` 的契约标记 `stale`；stale 契约禁止进入校准、跨验与热替换，必须重探或经共视关系重锚。未受影响的锚保留，行为退化为带额外元数据的 InstructGauge。

**定义 458（运动学-SLAM 联合目标与计量下限）**
`J(C) = ΔH_met(C) + w_slam·ΔH_slam(C) − λ_cost·c(C) − λ_risk·risk(C)`，
`s.t. ΔH_met(C) ≥ ε_m`（计量下限）、`KinCert`、`PCC`、`Barrier(C)`、`K ≤ K_MAX^kin`。
主动 SLAM 只能在「计量可采纳集」内选择下一最佳视角；计量信息增益的硬下界防止探索策略为了地图覆盖而牺牲契约精度。仲裁顺序为：安全 > 计量下限 > 地图信息 > 行程代价。

**定义 459（冗余撤退与运动学可逆性）**
`Retreat(q) = { 路径 q → q_safe : 全程 ∈ Q_adm，长度 ≤ L_ret，避开奇异 }`。若 `Retreat(q) ≠ ∅`，允许较大的 `K_ret`；若不存在（如锁死构型、狭窄空间），强制 `K=1` 且禁止不可逆动作。这把第 3 轮的「物理不可逆屏障」补上一条「运动学可撤退」条件：不可逆动作不仅不能与其它动作捆绑，还必须保留一条可行的运动学退路。

**定义 460（锚感知契约更新与双静默点）**
`Contract(s) → Contract(s, a, e)`。仅当 `AnchorCert` 有效且 `PCC` 通过时才允许持久更新；stale 或 provisional 契约只能作为候选，不能热替换。热替换需同时满足 `q_quiesce`（第 3 轮定义 439）与 `anchor_quiesce`（无在途块且无在途锚修订）。任一静默点不满足 ⇒ 延迟替换或按 `abort` 截断补偿。

**定义 461（主动 SLAM 仲裁）**
下一最佳视角 `v* = argmax_v [ I(map; z_v) + w_m·I(contract; z_v) − λ_travel·travel(v) ]`，`s.t.` 计量下限与 `Q_adm`。若地图信息高而契约信息低，可以探索，但不得使任何有效契约失效；若某视角会触发锚纪元失效，则必须先完成契约重验或显式降级。仲裁是字典序的，不是加权平均：安全与计量下限不可被地图收益补偿。

**定义 462（KinoGauge-9C 闭环）**
`K → I → H → C → E(chunk) → C → V → U`：`K` 为运动学证书与锚检查；`I/H/C` 沿用 InstructGauge 的接地、假设与分块；`E` 内做块执行；第二个 `C` 为 CVC 块复核 + PCC 锚复核；`V` 为 PAC-Cal 校准/跨验；`U` 为锚感知契约更新与双静默点热替换。

**定义 463（KinoCert 与 RepairCert″）**
`KinoCert(s) = (KinCert, AnchorCert, PCC, ChunkCert, receipts, claims, epoch)`；
`RepairCert″(s) = (ι, C, KinoCert, receipts, claims)`。
审计链为「指令 → 关节轨迹 → 锚/纪元 → 块证书 → 逐步回执 → 主张」六级证据链。任何一级缺失都只能降级为解释，不得进入数值更新。

## 3. 关键算法骨架

```python
# IP-328 KCC：把笛卡尔探测编译为关节轨迹并签发运动学证书
class KCC:
    def certify(self, probe, q0, model):
        qs = model.ik(probe, q0, redundancy="max_manipulability")
        if qs is None:
            return None                                  # ⊥：不可达
        for q in qs:
            if not in_joint_limits(q, model, margin=DQ):
                return None
            if velocity_ok(q, model) is False:
                return None
            if singularity_margin(q, model) < D_MIN:
                return None                              # 近奇异：拒绝
            if manipulability(q, model) < W_MIN:
                return None
        if not retreat_exists(qs[-1], model, L_RET):
            return None                                  # 无退路：拒绝
        return KinCert(qs, model.fk(qs), kappa_J(qs, model),
                       singularity_margin(qs[-1], model),
                       joint_margin(qs, model), model.version)

# IP-329 DAC：语义 × 运动学 × 撤退预算的联合块长
class DAC:
    def chunk_len(self, iota, kin, drift_bound):
        k_sem = self.chunk_len_upper(iota)               # 第 3 轮 K_MAX(ι)
        if kin is None:
            return 1                                     # 退化 ToolGauge
        k_dex = 1
        budget = EPS_POSE - EPS_INT
        for i, q in enumerate(kin.qs, start=1):
            budget -= kappa_J(q, self.model) * J_REF * DQ + D_CAL
            if budget < 0:
                break
            k_dex = i
        k_ret = retreat_budget(kin)                      # 由 L_ret 给出
        return max(1, min(k_sem, k_dex, k_ret))

# IP-330/IP-331 SAC + PCC：锚与位姿一致性
class SAC:
    def anchor(self, s, slam):
        return Anchor(frame="map", xi=slam.pose(s), Sigma=slam.cov(s),
                      epoch=slam.epoch)

    def pose_consistency(self, q, slam_pose, Sigma_q, Sigma_s, model):
        xi_fk = model.fk(q)
        Sigma_k = model.J(q) @ Sigma_q @ model.J(q).T + model.Sigma_cal
        r = se3_log(xi_fk.inverse() * slam_pose)
        S = Sigma_k + Sigma_s
        d2 = float(r.T @ inv(S) @ r)
        ok = d2 <= chi2.ppf(1 - BETA, df=6)
        return ok, d2, S

    def provisional(self, slam, s):
        return Anchor(frame="sensor", xi=slam.sensor_pose(s),
                      Sigma=slam.sensor_cov(s), epoch=slam.local_epoch)

# IP-332 PAC-Cal：位姿自适应共形
class PACCal:
    def threshold(self, iota, Sigma_pose, cal):
        b = bin_pose_uncertainty(Sigma_pose)             # 按 tr/条件数分箱
        if len(cal.get(b, [])) < N_MIN:
            return self.round3_scc.threshold(iota, cal)  # 回退指令分层
        scores = [mahalanobis_residual(y, yhat, S)
                  for (y, yhat, S) in cal[b]]
        return conformal_quantile(scores, alpha=ALPHA)

# IP-333 MAI：回环后的纪元失效
class MAI:
    def on_map_revision(self, e_new, changed_frames):
        for a in self.anchors.touching(changed_frames):
            if a.epoch < e_new:
                dF = frame_displacement(a, e_new)
                dS = frame_cov_change(a, e_new)
                if dF > TAU_ANCHOR or dS > TAU_SIGMA:
                    self.mark_stale(a)               # 禁止校准/热替换

# IP-334 9C 闭环
def kinogauge_9c(M, s, ell):
    out = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota        # 退化 InstructGauge 默认目标
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    probe = M.iac.design_probe(iota, H)

    kin = M.kcc.certify(probe, M.robot.q, M.kin_model)
    if kin is None:
        return M.instructgauge_7c(M, s, ell)        # 运动学不可用 ⇒ 第 3 轮

    anc = M.sac.anchor(s, M.slam)
    ok, d2, S = M.sac.pose_consistency(kin.qs[-1], M.slam.pose(s),
                                       M.Sigma_q, M.slam.cov(s), M.kin_model)
    if not ok:
        anc = M.sac.provisional(M.slam, s)          # 局部帧临时契约

    K = M.dac.chunk_len(iota, kin, M.drift_bound(s))
    C = M.iac.plan_chunk(iota, H, M.tools, K)
    if not prefix_closed(C) or crosses_irreversible(C, I_IRR):
        C = M.iac.per_step(iota, H, M.tools)        # 退化 K=1

    cert = M.cvc.commit(C, M.env, iota)
    receipts = cert.receipts
    if M.mai.is_stale(anc):
        return stub_and_reprobe(s, "anchor_stale")  # 回环失效：不更新
    if not M.pcc.recheck(anc, receipts, kin):
        anc = M.sac.provisional(M.slam, s)          # 执行中漂移：降级

    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.pac_cal.calibrate(receipts, H, s, anc)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s, anc)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")

    M.mreg.hot_replace_at_quiescence(
        M.dpe, new_ec, cert.boundary,
        need=[M.quiesce(s), M.anchor_quiesce(anc)])  # 双静默点
    bind_claims(cert, iota, receipts)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

# IP-335 主闭环（50Hz 路径不变）
def KinoGauge_round(M, obs, audio, tac, depth, det, ell=None):
    M.slam.update(obs, depth, det)
    M.mai.on_map_revision(M.slam.epoch, M.slam.changed_frames)
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(kinogauge_9c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 59（运动学证书的可靠性）** 若 `FK` 连续、`Q_adm` 为闭集且各裕度（关节、奇异、可操作度）有正下界，`KCC` 按足够细的分辨率检查途径点与其 Lipschitz 管，则 `KinCert(s) ≠ ⊥` ⇒ 执行轨迹的每个位姿都在 `Q_adm` 内；与第 3 轮安全盾复合后，`Inv` 逐步保持。
*证明骨架*：对途径点归纳。`q_i ∈ Q_adm` 给出关节/奇异/可操作度裕度；`q` 的连续性与 Lipschitz 管保证相邻途径点之间不越出 `Q_adm`。任一点失败即 `⊥`，故不存在未认证位姿被执行。盾归纳沿用引理 52。

**引理 60（灵巧度条件化的累积误差与 K_dex）** 设关节误差 `δ_q`、标定误差 `δ_cal`、插值误差 `ε_int`，则
`‖δξ_K‖ ≤ Σ_{i=1}^K ‖J(q_i)‖‖δ_q‖ + K‖δ_cal‖ + ε_int ≤ K·κ_J·J_ref·δ_q + K·δ_cal + ε_int`。
要求 `‖δξ_K‖ ≤ ε_pose` 得
`K ≤ (ε_pose − ε_int) / (κ_J·J_ref·δ_q + δ_cal) =: K_dex`。
故 `K_dex` 随 `κ_J`、`δ_q`、`δ_cal` 单调递减；结合第 3 轮 `K_MAX(ι)`，联合块长 `K*_kin = min(K*, K_dex, K_ret)`。这给出「越接近奇异、块越短」的可证伪定量形式，由 E458 检验。

**引理 61（位姿协方差传播与 NEES 一致性）** 一阶传播给出 `Σ_pose^k = JΣ_qJᵀ + Σ_cal + O(‖δ_q‖²)`。在残差近似高斯且线性化误差可忽略时，`rᵀ(Σ_pose^⊕)^{-1}r ~ χ²_6`，故经验 NEES 均值应接近 6 并落在 `χ²` 置信区间内。若经验 NEES 系统性偏大，则按 `Σ̃=(1+γ)Σ_pose^⊕` 膨胀直到一致；膨胀只降低灵敏度、不破坏安全性。该命题把「协方差是否可信」变成可测的统计检验（E460）。

**引理 62（PCC 门控的虚警与检测）** `H₀`（无打滑/无地图故障）且残差高斯时，`P(d_M² > χ²_{6,1−β}) = β`，故虚警率 ≤ `β`。若存在均值漂移 `μ`（打滑/绑架/投毒），`d_M² ~ χ²_6(λ)`，非中心参数 `λ = μᵀS^{-1}μ`，检测概率 `1 − F_{χ²_6(λ)}(χ²_{6,1−β})` 随 `λ` 单调递增。故该门控是虚警受控的 Neyman–Pearson 型检测器；失败只触发局部帧临时契约，而不是静默信任。

**引理 63（运动补偿误差界）** 若 `T(t)` 为 `C²`，平移/旋转加速度上界为 `a_max, α_max`，采样周期 `τ_s`，则分段线性 + slerp 的插值误差满足 `ε_int ≤ (1/8)a_maxτ_s²`、`ε_rot ≤ (1/8)α_maxτ_s²`。杠杆臂 `ℓ` 处测点的地图误差 `≤ ε_int + ℓε_rot + v_maxτ_sync`。因此运动模糊不是无界噪声，而是可预算进 `ε_pose` 的确定性上界；它直接收紧 `K_dex`（E462）。

**引理 64（位姿自适应共形覆盖）** 同一不确定度箱内若校准/测试分数可交换，则标准 split-conformal 给箱内覆盖 `≥ 1−α`。若分数用 Lipschitz 尺度 `σ(Σ)` 归一化、箱宽为 `δ`，则跨箱覆盖相对 `1−α` 的偏差由 `O(L_σδ)` 控制（局部自适应共形论证）。低样本箱回退第 3 轮指令分层 ⇒ 全局，覆盖按已知的 `−2η` 优雅降级，而不是在异方差下静默失效。由 E464 逐箱检验。

**引理 65（锚纪元失效的安全性与退化等价）** 纪元单调递增；`MAI` 在 `Δ_F > τ_anchor` 或 `Δ_Σ > τ_Σ` 时把所有旧纪元契约标记 stale，stale 契约被排除在校准、跨验与热替换之外，必须重探或重锚。因此不存在「用移动超过容差的帧去更新契约」的路径。对未受影响锚（`Δ_F ≤ τ_anchor`），新增的帧/纪元标签是纯元数据，数值路径与 InstructGauge 的指令/分块/校准逐指令等价（回到第 3 轮引理 57/58）；SLAM 整体缺失时退化为局部帧，同样等价。这给出严格的回退证明。

**引理 66（开销与 50Hz 保全）** `KCC` 在途径点率上 `O(K·n)`（IK 可缓存），`PCC` 每次 `O(6³)`，协方差传播 `O(n²)`，`MAI` 用空间索引后按受影响锚数摊销，`PAC-Cal` 为 `O(1)` 查表。全部位于异步探测路径；50Hz 热路径只增加一次带时间戳的位姿查找与一次纪元比较 `O(1)`。故新增热路径开销 `< 0.2ms`，继承 ToolGauge 引理 50 的硬实时结论。任一组件超预算即触发退化链。

## 8. 本轮最大风险

**一句话**：最大风险是把 SLAM 位姿当成「足够准的真值」——运动学证书会让动作看起来无懈可击，位姿自适应校准又会在漂移后的错误帧上给出「覆盖仍然成立」的假安全感，最终系统不是测错数值，而是**自信地测错了地方**；缓解只能依赖结构（PCC 双证人、帧-纪元失效、局部帧临时契约、计量下限），并以 E461/E463/E466/E468 主动证伪。
