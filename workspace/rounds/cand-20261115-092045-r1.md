# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「个性化交互」×「仿真到现实迁移」）

> R69 教会系统「不确定就去看、去问、去触」，并把不确定性拆成 aleatoric 与 epistemic。但它留了一处循环论证：**判断该不该问、问了值不值，用的是模型自己的熵与似然**。模型既是被告，又是法官。
>
> 具体说，R69 的 MINT 在算 VoI 时默认了两件事：
> (a) 响应模型 `p(y|g,o)` 对**眼前这个人**成立——但它是人群先验，不是个人；
> (b) 策略密度与模态权重在**眼前这个世界**成立——但它们来自仿真/训练分布。
> 本轮两个灵感词正好各戳一个：
> - **个性化交互**：同一句「您想让我绕左边还是右边？」对专家、儿童、失语症患者、赶时间的人、以及一个故意误导你的人，信息量、成本与风险完全不同。用人群平均算 VoI，等于对每个人说同一种语言。
> - **仿真到现实迁移**：仿真里的用户可以无限次被问、永远耐心、答案廉价且诚实；真实世界答案稀疏、带策略、带社交成本，而且**提问会改变被问者**。交互策略的 reality gap 比任务策略更大——因为「人」是最难仿真的部分。
>
> 两者叠加，产生一个 R69 无法自检的失效模式：**confident-but-wrong（自信地错）**。当世界偏移让策略稳定地收敛到一个错误模态，`H_mode` 很低、似然很高，R69 会判定「我很确定」，于是既不提问也不收紧；当个性化把某个人的一次误导性回答固化成「类型」，R69 的 k-源纪律也挡不住——因为同一个人的多个信号并不正交。
>
> 核心命题：**不要再给系统更多「自信」，而是把「可信」外部化**——用分布无关的 conformal/风险控制证书替代模型自评；用密度比 + 有效样本量 + 迁移有效域处理 sim2real；用分层 N-of-1 后验 + 信任域 + e-process 处理个性化；用机制设计让「诚实回答」成为用户的最优策略；个性化只做效率层，安全永远回落到 R68。
>
> 命名 **PERSONA-RAS**（Personalized Evidence via Reality-Shifted, N-of-1 Adaptation）。一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我所谓的可信，对这个人、这个世界还成立吗**」——置信度不是一种感觉，而是一张需要不断续签的通行证。

## 0. 直觉与动机

**灵感 1（个性化 = 条件化，但条件化必须防过拟合）**
直觉：人群先验 `p(θ)` 是一张「平均脸」。个性化要做的是把它条件化到个体 `p(θ|D_u)`，从而让「问什么、问谁、值多少」贴近这个人。但条件化的代价是方差：三个交互就敢宣布「他讨厌被问」，是过拟合；一个类型标签一旦写死，就成了刻板印象。所以个性化必须同时带三样东西：**分层收缩**（样本少时退向人群）、**信任域**（单次证据不许大幅改信念）、**可回滚**（慢环提交、版本化）。个性化不是给人贴标签，而是**在人群先验上加一个受约束的个人残差**。

**灵感 2（sim2real 的三重差距，最危险的是社会差距）**
直觉：仿真到现实的差距通常被分成观测差距与动力学差距，但交互场景还有第三重、也是本轮最关键的一重——**社会差距（social gap）**：仿真用户的合作度、耐心、诚实度、对提问的反应，与真人系统性不同。LLM 模拟用户尤其危险：它们太好说话、答案太廉价、几乎不撒谎。用这种仿真数据训练出的「提问策略」，到了现实会**高估提问收益、低估社交成本**。更糟的是，观测/动力学差距还能被残差与似然捕捉，社会差距不能——因为它改变的是「回答这个动作的收益」，而不是「传感器的读数」。

**灵感 3（自评置信的循环论证 → 必须外部认证）**
直觉：R69 的所有不确定性度量（模态熵、流似然）都由同一个模型产生。**用模型审计模型，审计的是「模型是否自洽」，不是「模型是否与现实一致」**。要打破循环，需要一种不依赖模型自我报告、只依赖数据可交换性的外部证书：conformal prediction / conformal risk control。它给的是有限样本、分布无关的覆盖率，而不是又一个分数。这是本轮的方法论核心：**内部置信只用来排序，外部证书才用来授权**。

**灵感 4（人不是分布，是策略主体 → 需要机制设计）**
直觉：R69 把回答 `y` 当作带噪观测，于是用贝叶斯更新。但真人会**策略性回答**：装不懂以逃避被问、夸大确定性以让你快点行动、用提问做社交工程。对策略主体做朴素贝叶斯更新，等价于把「操纵」当「噪声」；而 k 个正交证据源若都来自同一个人，就退化成 1 个源。所以交互必须被设计成**激励相容**（truthful elicitation / proper scoring），或者在无 IC 机制时把 `y` 当作最坏情况下的策略证据，而不是似然。

**灵感 5（个性化是效率层，不是安全层）**
直觉：任何依赖「这个人可以被正确建模」的安全论证都太脆。本轮的硬姿态是：**安全永远不由个性化承担**。降级链 `PERSONA → FLUID → R68`：世界不可迁移就退回 R68 纯保守；个体/同意/证书不成立就退回 R69 的人群交互；只有全部成立才启用个性化。每往上一级，只允许**效率与分辨率**增加，不允许安全包络缩小。

**灵感 6（个性化有伦理边界：persona 不是 person）**
直觉：个性化天然在推断「人」。它可以推断「这位用户需要更短的问句」，不应推断「这位用户不值得被认真对待」。因此需要三条硬约束：**任务因果相关**（只推断对当前任务真有因果作用的维度）、**同意分层**（默认只做任务副产品，主动画像需显式同意）、**最差组覆盖**（平均变好不许以某个子群变差为代价）。伦理在这里不是附录，而是可测的约束（定义 325）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PERSONA-RAS 总览）** PERSONA-RAS = (FLUID-RAS, SCM, PTB, WCP, MPC, N1B, XPG)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；一切个性化更新只发生在隔离的**慢环**，经提交门与版本化后方可被实时环读取；
(ii) **外部认证**：任何与安全相关的置信必须携带一个在声明的偏移下有效的、分布无关的证书；模型内部的熵/似然只可用于**排序**，不得单独**授权**；
(iii) **个性化最小性与同意**：只推断被同意且任务因果相关的类型坐标；否则对 `Θ` 取鲁棒（minimax / 分布鲁棒）决策。个性化永不出现在安全路径上。

**定义 311（两轴偏移分解）** 记部署联合分布 `P_real(o,a,y,θ)` 与训练/仿真 `P_sim`。**主体偏移**指 `p(θ)` 与 `p(y|g,b,θ)` 的变化；**世界偏移**指 `p(o'|o,a)`、动力学、成本模型的变化。联合密度比 `w(o,θ)=dP_real/dP_sim`。称偏移在区域 `V` 上**可迁移**，若 `sup_{V} w ≤ M_τ < ∞` 且加权校准集的有效样本量 `ESS ≥ n_min`。两轴正交：**问用户无法消除世界偏移**（人不知道自己所在的世界模型是否被仿真错了），这是本轮最重要的结构性区分。

**定义 312（类型化伙伴模型 SCM）** 类型 `θ ∈ Θ ⊂ ℝ^d`（d 小：能力 α、诚实 β、冗长/时延、偏好向量、被问反应 reactance），层次先验 `p(θ|φ_pop)`，响应模型 `p(y|g,b,θ)`，后验 `q_t(θ)=p(θ|D_u)`。**类型是先验不是判决**：最终信念必须保留一个个人残差项，直接证据可在单轮内覆盖类型先验（防止「刻板印象锁死」）。

**定义 313（三源不确定性，分通道）** `U_epi`（任务模态歧义，继承 R69）、`U_sub=H(Θ|D)`（这个人是谁）、`U_world`（迁移不确定度：密度比、ESS、覆盖缺口）。三者**不做简单加和**：
- `U_epi` 可由「问」在单轮消解；
- `U_sub` 只能由**随机化、被同意**的探询在慢环消解；
- `U_world` **不能通过问人来消解**，只能由真实校准数据消解。
这是对 R69「一切 epistemic 都可问」的直接修正：**有些无知不在对方脑子里，而在你与世界的接口上**。

**定义 314（元 VoI 与同意门控）** `VoI_task(g)=H(M|o)−E_{y|g,o}[H(M|o,y)]`；`VoI_meta(g)=H(Θ|D)−E[H(Θ|D∪{(g,y)})]`。可行动作 `g` 需满足：类型坐标与 `M` 任务因果相关、同意层级允许、安全已认证。默认 `γ=0`，即个性化只作为任务交互的**副产品**；`γ>0`（主动为画像而问）需要显式同意。评分 `score = VoI_task + γ·VoI_meta^⊥ − c(g)`，其中 `VoI_meta^⊥` 是在同意范围内与任务正交的分量。**不为画像而问**。

**定义 315（迁移有效域 PTB）** 训练判别器 `D_ψ` 区分 sim/real，`ŵ(o)=D_ψ/(1−D_ψ)`。有效域 `V_τ={o: ŵ(o)≤τ}`；`ESS(ŵ)=(Σŵ)²/Σŵ²`。称迁移证书有效当 `o∈V_τ ∧ ESS≥n_min ∧` 覆盖诊断通过；否则记 **transport void**，直接走定义 326 的降级。

**定义 316（加权 conformal 证书 WCP）** 非一致性分数 `s(o,a,ξ)`；在加权校准集上取加权分位数 `q`；预测集 `C(o)={ξ: s(o,a,ξ) ≤ q}`。在 A100（`V_τ` 上密度比有界 `M_τ`）、A101（同一 Mondrian 单元内可交换）下，`P_real(ξ∈C) ≥ 1−α−ε_w`，`ε_w = O(M_τ·ε_est + √(log(1/δ)/n_eff))`。若密度比无界，则**截断到 `V_τ` 并把域外一律视为「无证书」**。这就是替代「模型自评」的外部授权。

**定义 317（Mondrian 个性化 conformal MPC）** 按类型/上下文单元 `c`（聚类得到，非原始用户 id）分层，单元分位数带层次收缩 `q_c=(n_c q_c + n_0 q_0)/(n_c+n_0)`；`n_c` 过小自动退向人群分位数。目标是**条件覆盖**而非仅边际覆盖，同时避免「每人一个分位数」导致的覆盖崩塌与跨用户泄漏。

**定义 318（类型信任域 TRG）** 类型后验更新受 KL 预算约束：`KL(q_{t+1}‖φ_pop) ≤ ρ_t`，`ρ_t=min(ρ_max, κ√(n_eff,t))` 且被同意层级封顶；单次交互对类型信念的移动 `‖q_{t+1}−q_t‖_TV ≤ Δ_θ^max`。**一次误导性回答不得改写一个人的画像**；与 R69 的 k-源纪律互补（后者管跨模态，前者管时间轴）。

**定义 319（N-of-1 证据账本与 e-process 提交门 N1B）** 每次交互记账 `(g,b,y,预测信息增益,实现信息增益)`。个性化提交仅在 e-process `E_t=Π_s(1+λ_s Δ_s)` 越过 `1/α_n1` 时发生（Ville 不等式，任意停时有效）。它同时给「这个人确实不同于人群」一个 Type-I 受控的判据，抵抗「边看边决定何时停」的选择偏差。仅慢环、可回滚。

**定义 320（随机化探询与重叠）** 为**可识别**响应模型（而非仅观测其表现），以 ε-greedy / Thompson 在已认证候选 `g` 上做少量随机化，保证重叠 `P(g|b)>0`。但每个随机 `g` 仍须过 C-RAS-WM（定义 302）；不能认证则不探索。**为可识别性而探索，为安全而认证**；探索预算设硬上限。

**定义 321（仿真人保真门 SHF）** `δ_sim = d(P_sim(y|g,b), P_real(y|g,b))`（真实校准集上估计）。有效信息增益打折：`VoI_eff=(1−δ_sim)·VoI_sim − c`。若 `δ_sim>τ_sim`，则**仅由仿真用户验证过的交互策略不得授权安全相关决策**，必须引入真实校准或退回人群先验。这是对「LLM 模拟用户过度合作」的正面防御。

**定义 322（激励相容交互 IC）** 设用户效用 `u_U(y;truth,g,θ)`。设计问句/评分使真实回答最大化 `u_U`（proper scoring rule / peer prediction / Bayesian truth serum）。若不存在该 `g` 的 IC 机制，则把 `y` 视为**策略证据**并按最坏情况约束，**不得**直接贝叶斯更新。威胁模型由此从「噪声」升级为「主体」。

**定义 323（confident-but-shifted 检测 CBS）** 由于熵/似然是自评量，定义 `CBS = Φ( conformal 集大小/间隔, sim-real 判别分, 类型敏感度 max_{θ,θ'} d(π(·|θ),π(·|θ')), 跨源分歧 )`。当 `H_mode` 低而 `CBS` 高 ⇒ **自信但已偏移**：冻结交互并转保守。这是对 R69 最大风险的直接回答——**能发现「自信地错」，而不只是「不确定」**。

**定义 324（PERSONA 威胁模型 ℰ_persona）** 类型伪装（装懂/装不懂）、策略性回答、Sybil/跨用户污染、画像推断与隐私攻击、同意越界、反馈环投毒（教系统一个假类型）、sim-real 对抗性差距。`AIC-PERSONA = AIC-FLUID × ℰ_persona`；交互投毒不再只是「单次撒谎」，而是「长期养出一个错误的人」。

**定义 325（群体条件覆盖与公平）** 对声明的群体 `G` 要求 `min_{g∈G} Cov_g ≥ 1−α−ε_g`，且个性化不得以最差组退化换取平均提升（`Δ_worst ≤ ε_fair`）。Mondrian 单元需与受保护/声明群体足够对齐以便**审计**，但不得用于差别对待；群体标签只在审计聚合层可见（隐私与公平的张力显式化）。

**定义 326（两轴门控 XPG 与 J_PERSONA）** XPG 先判世界、再判主体（顺序不可交换：世界不可迁移时，问人没有意义）：
- 世界无效（transport void 或 `CBS>τ_cbs`）⇒ 关闭 FMP/FMA/MINT，`λ=λ_floor(U_ale+U_epi+U_sub)`，**逐指令退回 R68**；
- 世界有效但主体/同意/保真无效 ⇒ 关闭个性化，用人群响应模型，**退回 R69 FLUID**；
- 两者皆有效 ⇒ 启用 PERSONA。
证书 `J_PERSONA=(J_FLUID, transport_ess, w_max, conformal_coverage, group_gap, type_kl, n1_evalue, consent_tier, sim_fidelity, persona_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ o∈V_τ ∧ ESS≥n_min ∧ Cov≥1−α−ε ∧ Δ_worst≤ε_fair ∧` 同意与 e-process 条件满足。

# IP-264 SCM：层次类型后验（人 = 人群先验 + 受约束的个人残差）
def update_type(q_prev, D_u, phi_pop, consent):
    lik = [response_likelihood(theta, D_u) for theta in THETA]   # p(y|g,b,theta)
    q   = normalize([q_prev[i] * lik[i] for i in range(len(THETA))])
    q   = project_kl(q, phi_pop, rho=min(RHO_MAX, kappa*sqrt(n_eff(D_u))))  # 定义 318
    q   = cap_move(q_prev, q, d_max=DELTA_THETA_MAX)                         # 单次证据限幅
    if not consent.allows(TYPE_DIMS): q = phi_pop                             # 不同意→只用人群
    return q

# IP-265 PTB：迁移有效域 + 有效样本量（决定"世界的证书"还能不能用）
def transport_state(o, disc, cal_weights):
    w_hat = disc(o) / (1.0 - disc(o) + 1e-9)
    ess   = (cal_weights.sum()**2) / (cal_weights**2).sum()
    return dict(w=w_hat, ess=ess, valid=(w_hat <= TAU_W and ess >= N_MIN))

# IP-266/267 WCP + MPC：外部覆盖证书（内部熵只排序，不授权）
def conformal_set(o, a, calib, alpha, cell=None):
    scores = calib.weighted_scores(o, a)                 # 定义 316，权重已截断在 V_tau
    if cell is not None:                                 # Mondrian + 收缩
        q = shrink_quantile(calib[cell], calib.pop, alpha)   # 定义 317
    else:
        q = weighted_quantile(scores, 1 - alpha)
    return lambda xi: score(o, a, xi) <= q

# IP-269/270 MINT†：任务 VoI + 元 VoI（默认 gamma=0，同意才打开）
def choose_interaction(modes, q_type, o, budget, consent):
    best = None
    for g in certified_candidates(modes, o):             # 先过定义 302 安全认证
        if not budget.allow(g): continue
        vt = entropy(modes.w) - expected_entropy(modes.w, g, o)
        vm = entropy(q_type) - expected_entropy(q_type, g, o)
        gamma = 0.0 if not consent.meta else GAMMA_DEFAULT    # 不为画像而问
        s = vt + gamma * task_orthogonal(vm) - social_physical_cost(g, q_type)
        if best is None or s > best.score: best = (g, s, vt, vm)
    return best if best and best.score > 0 else None      # 无利可图→退 R69/R68

# IP-272/273 CBS + XPG：先世界后主体的两级降级
def persona_gate(o, calib, disc, q_type, consent, sim_fidelity):
    tr   = transport_state(o, disc, calib.weights)
    if not tr["valid"]:                                  # 世界不可迁移：问人无用
        return "R68", dict(U_world=INF, reason="transport_void")
    cset = conformal_set(o, last_action, calib, ALPHA)
    cbs  = cbs_score(cset, tr, q_type, cross_source_disagreement())
    if cbs > TAU_CBS:                                    # 自信但已偏移
        return "R68", dict(U_world=cbs, reason="confident_but_shifted")
    if (not consent.ok) or sim_fidelity > TAU_SIM or entropy(q_type) > TAU_SUB:
        return "FLUID", dict(U_sub=entropy(q_type), reason="subject_uncertified")
    return "PERSONA", dict(U_world=tr["w"], U_sub=entropy(q_type))

# IP-276 主闭环：个性化只改"问什么"，永不改安全包络
def PERSONA_round(M, obs):
    level, U = M.xpg.persona_gate(obs.o, M.calib, M.disc, M.q_type, M.consent, M.shf)
    if level == "R68":                                   # 逐指令 = R68
        return M.r68_round(obs)                          # 继承定理 15/16
    g = M.mint.choose_interaction(M.modes, M.q_type, obs.o, M.budget, M.consent)
    if level == "FLUID" or g is None:                    # 逐指令 = R69
        return M.fluid_round(obs, force_g=g)
    y   = M.scm.elicit_ic(g, obs)                        # 定义 322：诚实最优 / 否则按策略证据
    M.n1b.record(g, y); M.scm.stage_update(y)            # 只记账、只暂存，不写实时环
    return M.fluid_round(obs, force_g=g, evidence=y)     # 安全仍走 FLUID→R68
```

## 3. 推导

**引理 19（错误响应模型下的 VoI 变号）** 设真实响应模型 `p` 使回答与 `M` 条件独立（真实 `VoI_task(g)≤c(g)`），而由仿真先验得到的估计模型 `q` 以概率 `1−ε` 声称回答完全揭示 `M`。则估计 `VoI_q(g)=H(M)>c(g)`，真实 `VoI_p(g)≤c(g)`：**估计的 VoI 为正且看似划算，真实的 VoI 为负**。故任何缺少外部校验的 VoI 交互，其**符号本身**就不稳健。系：`τ_sim` 保真门（定义 321）不是保守补丁，而是 VoI 决策成立的必要条件。

**引理 20（加权 conformal 的可迁移覆盖）** 在 A100–A101 下，加权 split-conformal 的真实覆盖率满足 `≥1−α−ε_w`，`ε_w=O(M_τ ε_est + √(log(1/δ)/n_eff))`。因定义 315 把域外样本判为无证书、并把 `V_τ` 内密度比截断到 `M_τ<∞`，A100 由**构造**满足；代价是域外覆盖率为 0——这被显式转化为降级，而不是被平均掩盖。

**引理 21（个性化无免费午餐）** 在 `|Θ|=K`、类型可分的两点构造下，任何达到类型误差 `ε` 的个性化所需交互数 `n=Ω(d log K/ε²)`；若不随机化探询（定义 320），由于「只在不确定时才问」的选择偏差，响应模型参数的可识别性缺失，偏差可随 `n` 增长而不消失。系：**个性化必须付交互税与随机化税**；付不起时，人群先验是最优的保守选择。

**引理 22（策略性回答击穿 k-源）** 若用户的多个信号共享同一策略意图，则它们对 `M` 的欺骗相关 `ρ≈1`，R69 引理 18 的上界退化为 `δ_p·ρ^{k−1}+ε_σ → δ_p`。故 k-源正交纪律在「同一个人的多个回答」上失效；必须引入 IC 机制（定义 322）或**与被问者无关的独立证据源**。

**定理 18（两轴严格包含与降级链）** 在 A100–A103 下，`PERSONA → FLUID → R68` 的降级在定义 326 的触发条件下**逐指令相同**：世界无效 ⇒ 与 R68 相同；主体/同意/保真无效 ⇒ 与 R69 相同；仅在全部有效时才启用个性化。安全包络单调：`Risk(PERSONA) ⊇` 不成立，恰有 `Risk(PERSONA) ≤ Risk(FLUID) ≤ Risk(R68) + α_risk`（`α_risk` 为声明的证书风险预算，且 `α_risk ≤ ε_int`）。个性化只增加分辨率，不缩小包络。

**定理 19（闭环证书有效性边界）** 闭环中策略动作影响未来观测，静态 conformal 的 exchangeability 被**策略自身**破坏，逐步覆盖无保证。改用 ACI（自适应 conformal）可得长期平均覆盖 `≥1−α−o(1)`；用 e-process（定义 319）可对个性化提交给出任意停时有效的 Type-I 控制。但**逐状态条件覆盖仍不可保证**——因此证书只能用于监控与慢环授权，实时安全必须继续由 R68 承担。**证书是仪表，不是刹车。**

**定理 20（风险预算不劣于 R68）** 若证书有效，`PERSONA` 相对 `FLUID` 的额外违规概率 `≤α_risk`；若证书无效或越出 `V_τ`，`PERSONA` 与 `FLUID`/`R68` 逐指令一致。故以 `1−α` 置信度，`PERSONA` 的安全侧不劣于 R68 加一个显式、可审计、可调小的预算。

## 6. 本轮最大风险

**一句话**：PERSONA-RAS 把「模型自评的置信」替换成「外部证书」，但证书只在 A100–A103（密度比有界、单元内可交换、类型平稳可识别、响应模型族包含真值）下成立；**闭环中策略会自己破坏可交换性，策略用户会自己破坏响应模型假设**——一旦系统把「仿真里签发的证书」当成「现实中的通行证」，它就把一个不可迁移的置信度**洗白**成了看起来严谨的证书，而人对证书的信任会比对熵的信任更高：**问错，比不问更危险；盖章的问错，比问错更危险**。

**次级风险与缓解**：
1. **证书洗白 / 分布外误用** → 强制 `V_τ` 截断 + ESS 门 + 域外即降级（定义 315–316、326）；
2. **闭环破坏 exchangeability** → ACI 只用于监控、e-process 管提交，实时安全仍由 R68 承担（定理 19）；
3. **策略性回答与 k-源失效** → IC 机制（定义 322）+ 引理 22 + 非用户独立源；
4. **仿真人过度合作** → SHF 保真门与 VoI 打折（定义 321、引理 19）；
5. **个性化变刻板印象/隐私越界** → 信任域 + 同意分层 + 群体覆盖（定义 318、325），persona 是先验不是判决；
6. **反馈环养出错误的人** → N1B 慢环提交、版本化、可回滚（定义 319、326）。

**一句话收束**：当前方案的最大风险不是「个性化不够准」，而是**它会用形式化的证书为不可迁移的置信度背书**——证书越漂亮，越容易让人忘记它只是「在仿真与假设之下有效」。

def update_type(q, D_u, phi_pop, consent):
    q = normalize([q[i] * response_likelihood(t, D_u) for i, t in enumerate(THETA)])
    q = project_kl(q, phi_pop, rho=min(RHO_MAX, kappa*sqrt(n_eff(D_u))))  # TRG
    q = cap_move(q, q_prev, d_max=DELTA_THETA_MAX)                          # 单次限幅
    return q if consent.allows(TYPE_DIMS) else phi_pop                      # 不同意→人群

# IP-265 PTB：世界还能不能迁移
def transport_state(o, disc, weights):
    w   = disc(o) / (1 - disc(o) + 1e-9)
    ess = weights.sum()**2 / (weights**2).sum()
    return dict(w=w, ess=ess, valid=(w <= TAU_W and ess >= N_MIN))

# IP-266/267 WCP + MPC：外部覆盖证书（内部熵只排序）
def conformal_set(o, a, calib, alpha, cell=None):
    q = (shrink_quantile(calib[cell], calib.pop, alpha) if cell
         else weighted_quantile(calib.weighted_scores(o, a), 1 - alpha))
    return lambda xi: score(o, a, xi) <= q

# IP-269/270 MINT†：任务 + 元 VoI（默认 gamma=0）
def choose_interaction(modes, q_type, o, budget, consent):
    best = None
    for g in certified_candidates(modes, o):                  # 先过定义 302
        if not budget.allow(g): continue
        vt = entropy(modes.w) - expected_entropy(modes.w, g, o)
        vm = entropy(q_type) - expected_entropy(q_type, g, o)
        gamma = GAMMA_DEFAULT if consent.meta else 0.0       # 不为画像而问
        s = vt + gamma*task_orthogonal(vm) - social_physical_cost(g, q_type)
        if best is None or s > best.score: best = (g, s)
    return best if best and best.score > 0 else None         # 无利可图→R69/R68

# IP-272/273 CBS + XPG：先世界后主体
def persona_gate(o, calib, disc, q_type, consent, sim_fidelity):

    if not tr["valid"]:                       return "R68"          # 世界不可迁移
    if cbs_score(conformal_set(o, last_action, calib, ALPHA), tr,
                 q_type, disagreement()) > TAU_CBS: return "R68"    # 自信但偏移
    if not consent.ok or sim_fidelity > TAU_SIM or entropy(q_type) > TAU_SUB:
        return "FLUID"                                             # 主体不可认证
    return "PERSONA"

    if level == "R68":   return M.r68_round(obs)                   # 逐指令 = R68

    y = M.scm.elicit_ic(g, obs)                                    # IC：诚实最优
    M.n1b.record(g, y); M.scm.stage_update(y)                      # 只记账/暂存（慢环）
    return M.fluid_round(obs, force_g=g, evidence=y)               # 安全仍走 FLUID→R68
```

## 4. 推导

**引理 19（错误响应模型下的 VoI 变号）** 若真实 `p` 使回答与 `M` 条件独立（真实 `VoI≤c`），而仿真先验估计 `q` 以概率 `1−ε` 声称回答完全揭示 `M`，则 `VoI_q=H(M)>c`、`VoI_p≤c`：**估计为正、真实为负**。故无外部校验的 VoI 连符号都不稳健；`τ_sim` 保真门是 VoI 成立的必要条件，不是保守补丁。

**引理 20（加权 conformal 的可迁移覆盖）** A100–A101 下，加权 split-conformal 覆盖 `≥1−α−ε_w`，`ε_w=O(M_τ ε_est+√(log(1/δ)/n_eff))`。域外无证书、域内密度比由构造截断到 `M_τ<∞`；代价（域外覆盖为 0）被显式转成降级，而非被平均掩盖。

**引理 21（个性化无免费午餐）** `|Θ|=K` 下达到类型误差 `ε` 需 `n=Ω(d log K/ε²)` 次交互；不做随机化探询则选择偏差不可识别，且偏差不随 `n` 消失。系：**个性化必须付交互税与随机化税**，付不起则人群先验最优。

**引理 22（策略性回答击穿 k-源）** 同一用户的多个信号共享策略意图时 `ρ≈1`，R69 引理 18 退化为 `δ_p·ρ^{k−1}+ε_σ → δ_p`。故 k-源纪律在「同一个人的多个回答」上失效，必须 IC 或引入与被问者无关的独立源。

**定理 18（两轴严格包含与降级链）** A100–A103 下，世界无效 ⇒ 与 R68 逐指令相同；主体/同意/保真无效 ⇒ 与 R69 逐指令相同；仅全有效时启用个性化。安全单调：`Risk(PERSONA) ≤ Risk(FLUID) ≤ Risk(R68)+α_risk`，`α_risk≤ε_int`。个性化只增分辨率，不缩包络。

**定理 19（闭环证书有效性边界）** 闭环中动作影响未来观测，静态 conformal 的 exchangeability 被策略自身破坏，逐步覆盖无保证；ACI 给长期平均覆盖 `≥1−α−o(1)`，e-process 给任意停时有效的提交控制；但**逐状态条件覆盖仍不可保证**。故证书只用于监控与慢环授权，实时安全继续由 R68 承担——**证书是仪表，不是刹车**。

**定理 20（风险预算不劣于 R68）** 证书有效时 PERSONA 相对 FLUID 的额外违规 `≤α_risk`；证书无效/越出 `V_τ` 时逐指令退回 FLUID/R68。以 `1−α` 置信度，安全侧不劣于 R68 加一个显式、可审计、可调小的预算。

## 7. 本轮最大风险

**一句话**：PERSONA-RAS 用外部证书取代模型自评，但证书只在 A100–A103 下成立；**闭环会自己破坏可交换性、策略用户会自己破坏响应模型假设**——系统若把「仿真里签发的证书」当成「现实的通行证」，就是把不可迁移的置信度**洗白**成严谨证书，而人对证书的信任远高于对熵的信任：**盖章的问错，比问错更危险**。

**次级风险与缓解**：证书洗白/分布外误用（`V_τ` 截断 + ESS 门 + 域外降级）；闭环破坏 exchangeability（ACI 只监控、e-process 管提交、实时安全仍归 R68）；策略性回答击穿 k-源（IC 机制 + 引理 22 + 非用户独立源）；仿真人过度合作（SHF 门 + VoI 打折）；刻板印象/隐私越界（信任域 + 同意分层 + 群体覆盖，persona 是先验不是判决）；反馈环养出错误的人（N1B 慢环提交、版本化、可回滚）。
