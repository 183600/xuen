# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「虚实迁移」×「触觉感知」）

> 第 54 轮把技能组合从“能力匹配”升级为“动作-鲁棒性双证书”（α_S、γ_ce、J）。但整套体系有一个未言明的默认前提：**仿真中校准的 ρ、α_S、γ_ce 可以直接迁移到真实**。本轮把这个前提拉到台前：触觉是虚实迁移中**唯一不可被域随机化伪造的物理读出**（力/能量/接触守恒量的直接转导），因此它应当成为迁移的**校准基底**与**反证器**，而非又一路传感器。核心矛盾：H22：触觉虚实鸿沟无法用视觉式域随机化抹平，接触几何、摩擦柔顺、转导噪声三层误差在接触瞬间被放大；H23：第 53–54 轮的 ρ 谱与 α_S 都是任务/动作层抽象，缺少**接触层的可传递不变量**，导致“仿真里动作对了”≠“真实里接触对了”。

## 0. 直觉与动机

**灵感 1（触觉指纹 → 把虚实鸿沟变成一个可度量的三元组）**
直觉：视觉迁移靠“看起来像”，触觉迁移只能靠“**压起来像、滑起来像、读出来像**”。对一组标准化接触探针（轻压、滑移、敲击、抓握），分别采仿真与真实的触觉响应分布，其 Wasserstein 距离可正交分解为 **接触几何 Φ_geo、摩擦柔顺 Φ_comp、转导噪声 Φ_trans** 三量。鸿沟不再是玄学“gap”，而是一个**可复现、可比较、可设阈值的指纹向量**。最坏探针（max over probes）决定迁移的保守上界。

**灵感 2（触觉锚点 → 迁移的最小充分证据）**
直觉：不需要真实世界“全面像仿真”，只需要**策略将要占据的接触子空间被锚点覆盖**。一个锚点是语义对齐的接触事件对 `(e_sim, e_real)`（同物体、同相对位姿、同运动基元）。锚点覆盖 `cov_anchor(A_T) = |被对齐的动作 ∩ A_T| / |A_T|`。若覆盖不足，即便 ρ 再高也拒绝迁移——**没有接触证据的鲁棒只是仿真幻觉**。

**灵感 3（接触剖面 → 技能组合的第一性物理约束）**
直觉：第 54 轮的 compat 是动作空间 Jaccard，太“几何”。真实的组合冲突常发生在**接触状态跳变**处：前一技能以滑移结束、后一技能要求静摩擦抓握，动作空间交集很大但接触剖面不连续。于是给技能加 **接触签名 κ_S**（接触模式、法向力曲线、滑移量、接触时长），定义**接触兼容性** `compat_κ(S_i,S_j) = 1 - W_2(κ_{S_i}|边界, κ_{S_j}|边界)/Z`。组合必须同时满足动作兼容与接触兼容，这把“组合可判定”从运动学推进到**接触动力学**。

**灵感 4（主动可证伪探针 → 把真实采样花在最能推翻证书的接触上）**
直觉：真实接触采样昂贵（磨损、时间、安全）。应主动选择**仿真预测方差大 × 对指纹最敏感**的探针，最大化对 `Φ_t` 的信息增益；当证书置信区间收窄到 δ_t 以内即停。这是把“域随机化被动覆盖”换成“**主动反证**”：不是尽量像，而是尽快找到“哪里不像”。

**灵感 5（触觉触发重规划 → 真实接触作为在线反例回灌）**
直觉：部署时若观测到的接触违反 κ 的证书界（接触丢失、异常滑移、力超限），不应当只“拒绝”，而应触发**接触级局部重规划**并把反例回灌，更新指纹与锚点。这把第 54 轮的 Explain 回传从“云边”扩展到“**虚-实**”两条信道。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（触觉虚实指纹）**
设标准化探针集 `P = {p_1,…,p_m}`。对每个探针，仿真与真实的触觉响应分布为 `D_sim(p), D_real(p)`，各自分解为几何/柔顺/转导三通道。触觉指纹
`Φ_t(p) = (W_2(D_sim^{geo},D_real^{geo}), W_2(D_sim^{comp},D_real^{comp}), W_2(D_sim^{trans},D_real^{trans}))`，
总指纹 `||Φ_t||_∞ = max_{p∈P} ||Φ_t(p)||_2`。**指纹一致** 当且仅当 `||Φ_t||_∞ ≤ Θ_t`。

**定义 122（触觉锚点与覆盖）**
锚点 `a = (e_sim, e_real, ψ, ε)`，`ψ` 为共享接触语义（物体/位姿/运动基元），`ε` 为锚点处的指纹距离。锚点**有效** 当 `ε ≤ τ_anchor`。锚点覆盖 `cov_anchor(A_T) = |{x∈A_T : ∃ 有效锚点 a, action(a)=x}| / |A_T|`。

**定义 123（接触剖面与接触兼容性）**
技能 `S` 的接触剖面 `κ_S : C → 𝒫(ℝ^k)`，`C` 为接触事件空间（接触/滑移/抓握/释放），输出为特征分布（法向力、切向力、滑移速度、接触面积）。两技能在衔接边界 `∂` 上的接触兼容性
`compat_κ(S_i,S_j) = 1 - W_2(κ_{S_i}|_∂, κ_{S_j}|_∂)/Z`，
**接触兼容** 当且仅当 `compat_κ ≥ θ_κ` 且接触模式转移属于物理允许集 `T_phys`（如“静摩擦→滑移”允许，“真空→无接触”不允许）。

**定义 124（指纹条件化鲁棒性）**
`ρ_tactile(d) = P(robust_d | ||Φ_t||_∞ ≤ δ_t)`。即鲁棒性不再是仿真内的无条件概率，而是**以指纹距离为条件的概率**。迁移可用当且仅当 `∀d, ρ_tactile(d) ≥ ρ_min(d)`。

**定义 125（触觉迁移证书）**
`T = (ρ_t, α_S, κ, Φ_t, Anchors, δ_t, evidence)`：
- `ρ_t` 为定义 124 的指纹条件化鲁棒谱；
- `α_S` 为第 54 轮动作剖面；
- `κ` 为组合后的接触剖面；
- `Φ_t` 为指纹；
- `Anchors` 为有效锚点集；
- `δ_t` 为指纹估计的置信半径；
- `evidence` 至少含真实接触反例与探针原始记录。
**放行条件**：`||Φ_t||_∞ + δ_t ≤ Θ_t ∧ cov_anchor(A_T) ≥ θ_anchor ∧ compat_κ ≥ θ_κ ∧ min_d ρ_t(d) ≥ ρ_min(d)`。

**定义 126（主动可证伪探针）**
探针选择策略 `π_probe` 最大化期望信息增益与指纹敏感度的乘积：
`p* = argmax_{p∈P_cand(A_T)} I(Φ_t ; y_p | D_{1:t}) · ||∂Φ_t/∂p||`，
当 `δ_t ≤ δ_budget` 或探针预算耗尽时停止。

## 2. 关键算法 伪代码

### IP-121 TSF（Tactile Sim-to-Real Fingerprint）

```python
def tactile_fingerprint(sim_env, real_env, probes, n=256):
    phi = {}
    for p in probes:
        ds = sim_env.sample_tactile(p, n)      # {geo, comp, trans}
        dr = real_env.sample_tactile(p, n)
        phi[p] = {
            'geo':   wasserstein(ds['geo'],   dr['geo']),
            'comp':  wasserstein(ds['comp'],  dr['comp']),
            'trans': wasserstein(ds['trans'], dr['trans']),
        }
    return phi

def fingerprint_distance(phi):
    return max(norm2(v.values()) for v in phi.values())   # 最坏探针
```

### IP-122 TAC（Tactile Anchor Calibration）

```python
def build_anchors(traj_pairs, semantics, tau_anchor):
    anchors = []
    for traj_sim, traj_real in traj_pairs:
        for e_sim, e_real in align_events(traj_sim, traj_real, semantics):
            eps = fingerprint_gap(e_sim, e_real)
            if eps <= tau_anchor:
                anchors.append(Anchor(e_sim, e_real, semantics, eps))
    return anchors

def anchor_coverage(anchors, A_T):
    covered = {a.action for a in anchors}
    return len(covered & set(A_T)) / max(1, len(A_T))
```

### IP-123 CCP（Contact Compatibility Profile）

```python
def contact_profile(skill, C, contact_sampler):
    return {c: contact_sampler.distribution(skill, c) for c in C}

def contact_compat(k1, k2, boundary, Z):
    w = wasserstein(k1[boundary], k2[boundary])
    return 1.0 - w / Z

def compose_contact_chain(skill_seq, Z, theta_kappa):
    kappa = {}
    for s1, s2 in zip(skill_seq, skill_seq[1:]):
        if contact_compat(s1.kappa, s2.kappa, boundary='exit_entry', Z=Z) < theta_kappa:
            return ('reject', 'contact_discontinuity', (s1.id, s2.id))
        kappa[(s1.id, s2.id)] = merge_profiles(s1.kappa, s2.kappa)
    return ('ok', kappa)
```

### IP-124 AFP（Active Falsification Probe）

```python
def active_probes(phi_hat, posterior, A_T, delta_budget, max_probes):
    chosen = []
    for _ in range(max_probes):
        if posterior.confidence_radius(phi_hat) <= delta_budget:
            break
        p = max(candidate_probes(A_T),
                key=lambda q: (mutual_info(q, posterior) *
                               fingerprint_sensitivity(q, phi_hat)))
        y = observe_real(p)
        phi_hat, posterior = update(phi_hat, posterior, p, y)
        chosen.append((p, y))
    return phi_hat, chosen
```

### IP-125 TRP（Tactile-Triggered Replanning）

```python
def tactile_triggered_replan(cert, contacts):
    for c in contacts:
        if violates(c, cert.kappa) or c.mode not in T_phys:
            local = contact_local_replan(cert, c)
            report = explain_contact(c)          # 反例：哪一通道/哪一探针失配
            return ('replan', local, report)
    return ('ok', None, None)
```

### IP-126 TTC（Tactile Transfer Certificate）

```python
def tactile_transfer_certify(rho, alpha, phi, anchors, A_T,
                             Theta_t, theta_anchor, theta_kappa, delta_t):
    if fingerprint_distance(phi) + delta_t > Theta_t:
        return ('reject', 'fingerprint_gap', fingerprint_distance(phi))
    if anchor_coverage(anchors, A_T) < theta_anchor:
        return ('reject', 'anchor_insufficient')
    ok, kappa = compose_contact_chain(A_T.sequence, Z, theta_kappa)
    if not ok:
        return ('reject', 'contact_discontinuity', kappa)
    rho_t = fingerprint_conditioned_robustness(rho, phi)
    if min(rho_t.values()) < RHO_MIN:
        return ('reject', 'robustness_fail', rho_t)
    return ('ok', TactileCert(rho_t, alpha, kappa, phi, anchors, delta_t))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TSF | O(m·n·d) | O(m·d) | 探针覆盖任务接触分布、W_2 估计相合 |
| TAC | O(|T|·|E|) | O(|Anchors|) | 语义对齐无错配、ε 阈值 sound |
| CCP | O(|S|²·|C|) | O(|S|²) | 接触边界采样充分、转移集物理完备 |
| AFP | O(k·|P|·cost(observe)) | O(|P|) | 信息增益可估、停止条件收敛 |
| TRP | O(|contacts|) | O(1) | 证书界与真实接触可判 |
| TTC | O(m·d + |S|·|C|) | O(|Anchors|+|C|) | 四闸门合取 sound |

**正确性定理（Tactile-Grounded Transfer Soundness）**
承接第 53–54 轮 (A22)–(A28)；新增假设：**(A29)** 锚点语义匹配正确率 ≥ 1−β_a；**(A30)** 指纹估计在 n≥N(δ_t) 时以 1−β_f 概率满足 `||Φ̂_t − Φ_t|| ≤ δ_t`；**(A31)** 接触剖面在接触状态上关于力/滑移是 L_κ-Lipschitz，且物理转移集 `T_phys` 完备。则
```
P_success ≥ 1 - Σ_d (1-ρ_min(d)) - P(Φ_t > Θ_t) - β_a - β_f - L_κ·δ_t - P(compat_κ < θ_κ)
```
关键：迁移的成功上界被**四道独立闸门**同时约束——指纹、锚点、接触兼容、条件化鲁棒；任一闸门失效都会使上界下降，因而证书**只会更保守，不会虚假乐观**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 探针集与任务接触分布错位（指纹虚假对齐） | 高 | 任务条件化探针 + 主动反证 + 覆盖分位报告 |
| 锚点语义错配 | 高 | 视觉/本体/触觉多模态锚定 + 人工审计抽样 |
| 传感器温漂/磨损使指纹非平稳 | 高 | 在线重校准 + 漂移状态项 + 定期重打指纹 |
| 接触剖面仿真成本高 | 中 | 稀疏接触事件 + 代理模型 + 事件触发采样 |
| 证书过保守导致可用性下降 | 中 | 分级证书（保守/乐观带）+ 风险预算调度 |

## 6. 本轮最大风险

**一句话**：触觉指纹把虚实鸿沟从玄学变成可度量、可设阈、可拒绝的证书，但其 soundness **三重依赖探针集覆盖真实任务接触分布、锚点语义无错配、以及指纹在时间上平稳**；一旦探针与任务接触分布错位或传感器漂移，指纹会给出“虚假对齐”，使第 54 轮的双证书在真实接触瞬间系统性失效并触发负迁移，故必须以 **任务条件探针 + 多模态锚点验证 + 在线漂移补偿** 三道护栏，宁可拒迁，也绝不把触觉的“校准假象”当作迁移许可。

```python
        y = observe_real(p)
        phi_hat, posterior = update(phi_hat, posterior, p, y)
        chosen.append((p, y))
    return phi_hat, chosen
```

### IP-126 TTC

```python
def tactile_transfer_certify(rho, alpha, phi, anchors, A_T,
                             Theta_t, theta_anchor, theta_kappa, delta_t, rho_min):
    if fingerprint_distance(phi) + delta_t > Theta_t:
        return ('reject', 'fingerprint_gap', fingerprint_distance(phi))
    if anchor_coverage(anchors, A_T) < theta_anchor:
        return ('reject', 'anchor_insufficient')
    ok, kappa = compose_contact_chain(A_T.sequence, Z, theta_kappa)
    if not ok:
        return ('reject', 'contact_discontinuity', kappa)
    rho_t = fingerprint_conditioned_robustness(rho, phi)
    if min(rho_t.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_t)
    return ('ok', TactileCert(rho_t, alpha, kappa, phi, anchors, delta_t))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TSF | O(m·n·d) | O(m·d) | 探针覆盖任务接触分布，W_2 相合 |
| TAC | O(|T|·|E|) | O(|Anchors|) | 语义对齐无错配，ε 阈值 sound |
| CCP | O(|S|²·|C|) | O(|S|²) | 边界采样充分，T_phys 完备 |
| AFP | O(k·|P|·c_obs) | O(|P|) | 信息增益可估，停止条件收敛 |
| TRP | O(|contacts|) | O(1) | 证书界可判，局部重规划有界 |
| TTC | O(m·d+|S|·|C|) | O(|Anchors|+|C|) | 四闸门合取 sound |

**正确性定理（Tactile-Grounded Transfer Soundness）**
承接 (A22)–(A28)；新增 **(A29)** 锚点语义匹配正确率 ≥ 1−β_a；**(A30)** 指纹估计满足 `‖Φ̂_t−Φ_t‖ ≤ δ_t`（概率 1−β_f，n≥N(δ_t)）；**(A31)** 接触剖面 L_κ-Lipschitz 且 `T_phys` 完备。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(Φ_t>Θ_t) - β_a - β_f - L_κ·δ_t - P(compat_κ<θ_κ)
```
关键：**四道独立闸门**（指纹 / 锚点 / 接触兼容 / 条件化鲁棒）任一收紧都只降低上界，证书只会更保守，不会虚假乐观。

## 6. 本轮最大风险

**一句话**：触觉指纹把虚实鸿沟变成可度量、可设阈、可拒绝的证书，但其 soundness **三重依赖探针集覆盖真实任务接触分布、锚点语义无错配、以及指纹在时间上平稳**；一旦探针与任务接触分布错位或传感器漂移，指纹会给出“虚假对齐”，使第 54 轮双证书在真实接触瞬间系统性失效并触发负迁移，故必须以 **任务条件探针 + 多模态锚点验证 + 在线漂移补偿** 三道护栏，宁可拒迁，也绝不把触觉的“校准假象”当作迁移许可。
