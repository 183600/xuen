# 第 43 轮（新循环第 3 轮） · 跨物体泛化 × 数据规模：从「单物体证书模板」到「物体空间上可传输的证书场」（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」。本轮灵感词「跨物体泛化」「数据规模」精准命中 v19 的两个结构性盲点：**(1) 物体轴缺失**——飞轮沉淀的证书都是任务/实例级的，KB 的键是 (φ, ψ)，唯独没有物体指纹 z(o)，「换个杯子/箱子」在检索空间里几乎等于「换了个世界」，证书知识库越大越像「经验碎片库」而非「可泛化的物理规律」；**(2) 规模幻觉**——飞轮默认「数据越多越安全」，却违背分布无关学习理论的铁律：尾风险收敛是 O(1/√N)，堆仿真买不到长尾安全。本轮主张：**证书应被参数化为物体的证书充分统计量 z(o) 的条件场，而不是逐物体重算的法则**；只有当证书在 z 空间满足有界 Lipschitz 时，一次验证才能覆盖整个 ε-邻域，数据规模才第一次产生「杠杆」。我们把这套结构叫 **X-Cert Field（跨物体证书场）**，并用 **证书标度律** 显式刻画「数据规模到底买到了什么、买不到什么」。

## 0. 直觉与动机

**灵感 1（跨物体泛化 → 证书不该记住「这是杯子」，而该记住「接触几何 + 摩擦锥 + 质量分布」）**：人抓过一百个杯子后，抓一个新杯子不需要从零试错，因为他迁移的是「圆柱侧壁、质心偏上、摩擦中等」这类**充分统计量**，而不是某个具体杯子。v19 的 KB 记录 (φ, ψ, C)，把「物体」隐式地压进了任务指纹和环境指纹，导致物体一变、检索命中率断崖。直觉方案：定义一个只保留**证书相关**信息的物体嵌入 z(o)（接触流形拓扑、曲率谱、质量/惯量比、摩擦锥开口、柔顺性），把证书写成 z 的条件场 C(x, z)。只要边际函数 m(x; z) 对 z 是 L_Z-Lipschitz 的，那么被验证过的锚点物体 o_i 的证书就能**合法外推**到 z 空间里它附近的物体。**跨物体泛化 = 物体空间里的覆盖问题，而不是逐个物体重新合成的问题**。这把「知识库」从「案例库」抬升为「场」。

**灵感 2（数据规模 → 没有结构时，N 个样本只买 √N 的尾收敛；有结构时，每个样本买一整个物体邻域）**：这是本轮最反直觉、也最关键的观察。给定 N 个独立验证样本，DKW 不等式告诉我们：真实尾风险与经验尾风险的偏差以 O(1/√N) 收敛；要把 ε 尾风险证到置信 1−δ，分布无关地需要 N ≈ log(2/δ)/(2ε²)。也就是说，**「再多跑一万条仿真」对 ε=1% 的尾风险几乎无济于事**——这正是 v19 飞轮可能「越飞越自信、却仍然静默失效」的根因。破局点不是更多数据，而是**让每个数据点覆盖物体空间的一个体积**：若证书场在 z 空间 L_Z-Lipschitz、嵌入内蕴维度为 d_Z，则每个锚点覆盖半径 r=(m−θ)/L_Z 的球，有效样本量 **N_eff = N·Λ**，其中杠杆 Λ = V_ball = V_{d_Z}·r^{d_Z} 是「一个锚点抵多少个随机点」。**数据规模只有在「低内蕴维 + 有界 Lipschitz」的结构下才产生指数级杠杆**。因此本轮把「数据规模」从一句口号变成可测量对象：证书标度律 Cov(N) ≈ 1 − exp(−N·Λ/V_Z)，并用 Λ 解释经验幂律指数 α。

**灵感 3（两者耦合 → 「主动制备锚点 + 长尾拒绝」的证书场数据引擎）**：既然覆盖靠邻域、尾风险靠结构，数据采集就必须从「均匀随机撒点」升级为「在 z 空间最大化覆盖增量」——用证书信息增益/覆盖 UCB 做主动采样，专挑当前证书场**没覆盖或不确定**的物体；同时用**新颖性拒绝（novelty rejection）**处理「离所有锚点都超过信任半径 r_i」的物体：证书场直接拒绝签发、回退 SafeStop/人在环，而不是外推。这把 v19 的「Sim→RAG→Edge→Sim」升级为 **「锚点主动制备→物体场覆盖→邻域外推→新颖性拒绝→反例回灌」** 的 v8 飞轮。数据规模不再是「越多越好」，而是「在结构化嵌入下的覆盖效率」。

**耦合升级**：跨物体泛化给出「证书如何外推」（空间结构），数据规模给出「外推的样本预算与统计可信度」（统计结构）；两者相乘补齐了 v19 缺失的 **物体轴**。四层架构 v8 在两处插入：L4 新增 IP-57/58（物体证书场 + 标度引擎），L3 在 ECR 上加「物体条件查表 + 新颖性门」，并让 CAR 新增 `NoveltyRejected` 态。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（物体证书充分统计量与物体等价）**：物体 o 的**证书相关特征** z(o) = (𝒯_contact, Σ_curv, ρ_mass, β_fric, χ_comp) ∈ Z ⊆ ℝ^{d_Z}，其中 𝒯_contact 为接触流形拓扑类，Σ_curv 为曲率谱（离散化特征值），ρ_mass 为质量/惯量比，β_fric 为摩擦锥半角，χ_comp 为柔顺性，d_Z 为 Z 的内蕴维度。取加权马氏距离 d_Z。定义**物体边际 Lipschitz 常数** L_Z := sup_{x, z₁≠z₂} |m(x;z₁) − m(x;z₂)| / d_Z(z₁,z₂)。称 o₁ ~_ε o₂ 当且仅当 d_Z(z₁,z₂) ≤ ε。**命题 38.1（物体迁移界，与定义 32 的 Sim→Real 界对偶）**：m(x;o₂) ≥ m(x;o₁) − L_Z·d_Z(z₁,z₂)。因此若锚点阈值 θ(o₁)、信任半径 r₁=(m_lo(o₁)−θ)/L_Z，则对所有 d_Z ≤ r₁ 的物体，锚点证书的边际下界仍不低于 θ，**保 sound**。

**定义 39（跨物体证书传输算子）**：同接触拓扑（同胚）时，传输退化为 Lipschitz 外推：C_{o₂} = erode(C_{o₁}, L_Z·d_Z)。跨拓扑（如圆柱→方块）时，两个接触流形 (M₁,d₁,ρ₁)、(M₂,d₂,ρ₂) 不是同一度量空间，普通 W₁ 无定义，改用**函数型 Gromov–Wasserstein（FGW）**求近似等距耦合 T_{o₁→o₂} = argmin_T GW(T) + λ·F(T)，GW 失真 Γ(T) = ∫|d₂(Tx,Tx′) − d₁(x,x′)|² dρ₁dρ₁。**命题 39.1**：若 Γ(T) ≤ δ_GW，则证书推送后的有效域收缩带 b = √δ_GW·L_M + L_Z·d_Z(z₁,z₂)，其中 L_M 为边际对接触位置的时间 Lipschitz 常数；**故跨形态传输的 sound 性由「GW 失真上界 + 物体 Lipschitz」共同兜底**。

**定义 40（跨物体证书场与泛化覆盖率）**：锚点集 A = {(z_i, C_i)}_i，每个锚点带信任半径 r_i = (m_i − θ)/L_Z。**证书场边际下界** m_lo(x;z) := max_i [ m(x;o_i) − L_Z·d_Z(z, z_i) ]（每个锚点给一个合法下界，取最紧者）。物体 z 的可认证域 R(z) = {x : m_lo(x;z) ≥ θ}。**泛化覆盖率** Gen(A) := P_{o~D_obj}[ z(o) 落在 ⋃_i B(z_i, r_i) 内 ]。**命题 40.1（覆盖 ⟹ 泛化）**：若 A 是 Z 的一个 r-网（每点距某锚点 ≤ min_i r_i），则 Gen(A)=1；反之 Gen(A) 由 Z 上的覆盖数 N(ε) 与锚点分布共同界出，且 Gen 是锚点集合的**次模函数**。

**定义 41（证书标度律与数据杠杆）**：设锚点在 Z 上按体积 V_Z 均匀独立撒点，每个锚点覆盖体积为球的 V_ball = V_{d_Z}·r^{d_Z}（V_{d_Z} 为单位球体积）。则未覆盖比例的期望精确为 (1 − V_ball/V_Z)^N，故
**Cov(N) ≈ 1 − exp(−N·V_ball / V_Z) = 1 − exp(−N_eff)，其中 N_eff = N·Λ/V_Z，Λ := V_ball = V_{d_Z}·(m−θ)^{d_Z}/L_Z^{d_Z}。**
Λ 称为**数据杠杆**：一个锚点等价于多少个随机样本。推论：L_Z 翻倍或裕度 (m−θ) 减半，Λ 降为 2^{−d_Z}；**内蕴维 d_Z 主导杠杆**。经验上同时拟合幂律 Cov(N) = 1 − a·N^{−α}，用 Λ 与 d_Z 解释 α 偏离 1 的原因（α→0 表示尾重、结构弱）。

**定义 42（证书信息增益与主动锚点采样）**：对候选物体 o，定义其**证书信息增益** I(o) := 期望减少的未覆盖质量 × 该处证书标签的熵。选择规则 argmax_o I(o)/cost(o)。**命题 42.1**：在覆盖目标下 I 次模，贪心选择达到 (1−1/e) 近似最优；若再按不确定度 UCB 加权，可在有限预算内把 Gen(A) 推到 1−δ_unc。

**定义 43（规模化统计可靠性下界 / 有效样本量账本）**：设证书标签的尾风险经验估计基于 N_eff 个**有效独立**样本。由 DKW 不等式，sup|F̂−F| ≤ √(ln(2/δ)/(2N_eff)) 以概率 1−δ 成立。故要证尾风险 ≤ ε（置信 1−δ），需 **N_eff ≥ ln(2/δ)/(2ε²)**。**命题 43.1（结构即压缩）**：纯均匀采样 Λ=1 时需 N ≥ ln(2/δ)/(2ε²)，对 ε=1%、δ=0.05 约需 1.8×10⁴ 个**真正独立**样本且随 ε 平方恶化；引入证书场后只需 N ≥ ln(2/δ)/(2ε²)·(V_Z/Λ)，当 d_Z 小时 V_Z/Λ 可指数级缩小。**这正是「数据规模」有意义的唯一严格路径：不是增加 N，而是放大 Λ。**

**定义 44（长尾最坏组覆盖与统计预算）**：将物体按类别分 G 组，第 g 组占比 π_g（长尾 π_g≪1）。**最坏组覆盖率** Gen_wg := min_g P_{o~D_obj|g}[z(o)∈⋃B_i]。对每组独立做 DKW 并以 δ/G 做 Bonferroni，则每组需 N_g ≥ ln(2G/δ)/(2ε²) 个样本。**命题 44.1**：均匀采样下尾组期望样本 N·π_g，故 N ≥ ln(2G/δ)/(2ε²·π_g) 才能覆盖尾组——π_g 小时**均匀规模完全无望，必须主动/尾定向采样**；否则整体 Gen 逼近 1 但 Gen_wg 仍可能崩。

## 2. 产出设计（新增 IP-57/58 + 升级 IP-51/52/54/55/56/49/50/45/47）

### 2.1 IP-57 X-OBJ CERT-TRANSPORT（XOCT，跨物体证书传输器）
1. **证书充分统计量嵌入**：z(o) 由「多视图几何 + 物理先验」联合估计——接触流形拓扑、曲率谱、质量/惯量比、摩擦锥、柔顺性；用对比学习 + 物理正则（同拓扑近、异接触力学远）训练，目标是**证书相关**而非外观相似。
2. **证书场构建与外推**：每个锚点存 (z_i, C_i, r_i)；查询时按定义 40 取 max_i(m_i − L_Z d_Z)，得保守下界；查询 O(k) 最近邻 + 一次外推。
3. **跨形态 FGW 传输**：不同拓扑物体走定义 39 的函数型 GW，输出收缩带 b；带内有效、带外弃权。
4. **新颖性门**：若 d_min(z, A) > min_i r_i，直接 `NoveltyRejected`（不签发），触发 SafeStop/人在环 + 数据回灌。

### 2.2 IP-58 CERT-SCALE-ENGINE（CSE，证书标度引擎）
1. **标度律测量**：横轴 N（锚点数/轨迹数），纵轴 Gen_wg 与尾风险；拟合几何律 1−exp(−NΛ/V_Z) 并校验经验幂律，输出 (Λ, d_Z, α)。
2. **主动锚点制备**：以次模覆盖增益 + 不确定度 UCB 选物体/轨迹，贪心 1−1/e；长尾组按命题 44.1 设最小配额。
3. **统计账本**：每次签发记录 (N, Λ, N_eff, DKW 界, 分组 Bonferroni)，对不达标者**拒绝声称 sound**，只给经验置信。
4. **分布外与偏差告警**：物体轴分布偏移（新类别）与仿真偏差双通道；任一越界触发扩域或弃权，而非放大规模。

## 5. 本轮最大风险

**一句话**：把「数据规模」误当成「跨物体安全」的充分条件——一旦物体嵌入坍缩（z 近而动力学远）或标度律外推越过数据支撑集，证书场会在长尾物体上**系统性假迁移**，且整体覆盖率可以逼近 1 而最坏组早已失效，比 v19 的单物体模板更难被人发现；因此 E87（迁移界）、E91（N_eff 账本）、E92（最坏组）必须作为红线实验，任一不达标即收回自动签发、退回逐物体证书 + 新颖性弃权。

## 2. 关键算法（伪代码）

### IP-57 XOCT：物体证书场与外推
```
def object_embedding(o):
    # 证书相关充分统计量（对比学习 + 物理先验正则）；非外观相似
    return z  # (𝒯_contact, Σ_curv, ρ_mass, β_fric, χ_comp)

def cert_field_margin(x, z, anchors, L_Z):
    # 每条锚点给出一个合法下界，取最紧者（max 仍是 sound 下界）
    lb = [a.m_lo(x) - L_Z * object_metric(z, a.z) for a in anchors]
    return max(lb) if lb else -inf

def trust_radius(anchor, theta, L_Z):
    return max(0.0, (anchor.m_lo_min - theta) / max(1e-9, L_Z))

def novelty_gate(z, anchors, L_Z, theta):
    d_min = min(object_metric(z, a.z) for a in anchors)
    r_min = min(trust_radius(a, theta, L_Z) for a in anchors)
    if d_min > r_min:
        return 'REJECT_SAFESTOP'          # 邻域外：不签发，人在环 + 回灌
    return 'TRANSFER'

def transport_certificate(C_src, o_src, o_dst, L_Z):
    z1, z2 = object_embedding(o_src), object_embedding(o_dst)
    if same_topology(z1, z2):
        # 同拓扑：Lipschitz 外推，按距离收缩有效域
        return C_src.erode(L_Z * object_metric(z1, z2))
    # 跨形态：函数型 Gromov-Wasserstein 近似等距传输
    T, distortion = fgw_transport(contact_manifold(o_src), contact_manifold(o_dst))
    band = sqrt(max(0.0, distortion)) * L_M + L_Z * object_metric(z1, z2)
    return C_src.push_forward(T).erode(band)   # 失真大 -> 收缩大 -> 弃权
```

### IP-58 CSE：标度律、主动锚点、统计账本
```
def fit_certificate_scaling(records):
    # records: [(N, Gen_wg)]
    # 结构律（可证伪）：Cov = 1 - exp(-N * Lambda / V_Z)
    Lambda, V_Z = fit_geometric_law(records)      # 由 d_Z, L_Z, 裕度反推校验
    a, alpha = fit_power_law(records)             # 经验幂律 Cov = 1 - a N^{-alpha}
    return ScalingLaw(Lambda=Lambda, dZ=d_Z, alpha=alpha, a=a)

def active_anchor_select(Z_pool, field, budget, cost, theta, L_Z):
    # 次模覆盖增益 + 不确定度 UCB；贪心 (1-1/e)
    for _ in range(budget):
        best, best_val = None, -inf
        for o in Z_pool:
            gain = uncovered_mass(o, field) * label_entropy(o, field)
            val = gain / max(1e-9, cost(o))
            if val > best_val: best, best_val = o, val
        field.add_anchor(certify(best), trust_radius_of(best))
    return field

def soundness_ledger(N, Lambda, V_Z, eps, delta, n_groups=1):
    N_eff = N * Lambda / V_Z
    # 长尾：每组 Bonferroni，delta/G
    need = log(2 * n_groups / delta) / (2 * eps**2)
    return {'N': N, 'Lambda': Lambda, 'N_eff': N_eff,
            'required': need, 'certified': N_eff >= need,
            'claim': 'SOUND' if N_eff >= need else 'EMPIRICAL_ONLY'}

def worst_group_coverage(groups, field):
    return min(group_coverage(g, field) for g in groups)  # 只报最坏组，不报平均

def long_tail_quota(group_shares, eps, delta, total_budget):
    G = len(group_shares)
    need_per = log(2 * G / delta) / (2 * eps**2)          # 命题 44.1
    return [max(need_per, total_budget * pi) for pi in group_shares]
```

### IP-52/56 升级：物体条件运行时 + 新颖性门

def certify_light_v3(x, z, anchors, theta, L_Z, budget_us=200):
    # T-2: 物体场查表 + 信任半径判定（只读，O(k) 近邻）
    if novelty_gate(z, anchors, L_Z, theta) == 'REJECT_SAFESTOP':
        return 'REJECT_SAFESTOP', -2
    # T-1: 最近锚点集合上查表 + Lipschitz 外推
    k_anchor = k_nearest(anchors, z, k=3)
    m_lo = cert_field_margin(x, z, k_anchor, L_Z)
    if m_lo >= theta:
        return 'OK', -1
    # T0: 物体条件 INT8 监控器（键含 z 摘要）
    if budget_us < 110:
        return downgrade_monotone(m_lo), -1
    status, margin = monitor_step_INT8(quantize_obs(x), z_digest(z))
    return status, 0

def car_transition_guard_v8(e, x, z, cert_obj):
    if cert_obj.novelty_flag[e]:
        return False                       # NoveltyRejected：不转移
    theta_real = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    return cert_field_margin(x, z, cert_obj.anchors, cert_obj.L_Z) >= theta_real

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 物体嵌入坍缩：z 近而动力学远 → 假迁移 | 高 | 物理先验正则 + 反例回灌 + 多距离（拓扑/曲率/摩擦）联合门控；L_Z 实测上界 |
| 标度律外推过自信：支撑集外指数律失效 | 高 | 只在支撑集内报告；外推输出区间并降级为经验置信；E89 红线 |
| 数据规模放大仿真偏差：N 增而偏差不减 | 高 | 多仿真器交叉 + sim-to-real α_e 与物体传输双重界；真实锚点少量标定 |
| 长尾无数据：Gen 高但 Gen_wg 崩 | 高 | 命题 44.1 分组配额 + 尾定向主动采样 + 尾组强制弃权/人在环 |
| GW 失真低估：跨形态收缩带过窄 | 中 | 失真上界取实测高分位；跨拓扑默认保守带；带外弃权 |
| z 在线辨识误差（质量/摩擦） | 中 | 在线辨识 + 保守区间；区间超界即新颖性拒绝 |
| 规模化检索噪声/召回下降 | 中 | 分层索引 + 重排 + 一致性校验；必要时精确近邻 |

## 6. 本轮最大风险

**一句话**：把「数据规模」误当成「跨物体安全」的充分条件——一旦物体嵌入坍缩（z 近而动力学远）或标度律外推越过数据支撑集，证书场会在长尾物体上**系统性假迁移**，且整体覆盖率可以逼近 1 而最坏组早已失效，比 v19 的单物体模板更难被人发现；因此 E87（迁移界）、E91（N_eff 账本）、E92（最坏组）必须作为红线实验，任一不达标即收回自动签发、退回逐物体证书 + 新颖性弃权。
