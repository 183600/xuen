# 第 43 轮 · 证书智能体（Cert-Agent）：用「证明携带动作」把智能体关进可信内核，用「保形语义编译」把多模态大模型变成可审计的规格翻译官（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮，SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」导致证书静默失效。本轮灵感词「智能体」「多模态大模型」恰好补上 v19 缺的两个角色：**谁来驾驶这个飞轮**——v19 仍默认人类/固定流水线开环驱动；**自然语言安全需求如何进入形式化守卫**——v19 的规格仍靠人手写。核心主张：让智能体做它最擅长的（提议、检索、修复、协商），让一个小而可信的内核做它唯一该做的（验证）；多模态大模型只做「候选规格」的编译与「反例根因」的假设，且必须过保形覆盖与因果检验两道闸。**智能体可以错，但错误只能表现为「被拒绝」，不能表现为「不安全动作」。**

## 0. 直觉与动机（先给画面，再给定义）

**灵感 1（智能体 →「证明携带的智能体」，不是「大模型开机器人」）**：直接把 VLM/LLM 接到控制回路上，是在用「概率性文本生成」承担「确定性安全责任」，一旦幻觉就是物理事故。Proof-Carrying Code 的直觉反过来用：**不信任生产者，只信任检查器**。把智能体想象成一个「拿着草稿找公证处」的工程师——它可以自由地查资料（CKB）、跑仿真（SCV）、改方案（修复）、拉群商量（协商），但它提交的每一个动作都必须附带一张**可机器核验的证明单**（witness：查表项 + 区间界 + 仿真统计置信 + 契约包含关系）。公证处（可信内核）只花 <10ms 盖章或驳回。于是 LLM 的不确定性被**降维**成一个可测量、可优化的量：**认证自主率 AR 与误拒率 FRR**，而不是不可观测的安全概率。这是把「智能体的自由」与「形式化的可靠」解耦。

**灵感 2（多模态大模型 →「语义规格编译器」，不是「端到端策略」）**：机器人竞赛里真正的瓶颈常不是控制，而是**规格**：用户说「别靠人太近，别把杯子碰下桌」，谁来把它变成可验证的谓词与阈值？多模态大模型的直觉定位是**翻译官**：读取语言指令 + 图像/点云/地图，产出「危险类别清单 + 参数化谓词候选 + 理由」。但翻译官会漏译、会过度自信——最危险的失效是**欠定（under-specification）**：漏掉一个真实危险约束，系统会对一个「错误的定理」给出完美证明。因此我们把它形式化为**保形语义规格证书**：对参数用 split-conformal 给出覆盖集合并取交（更保守），对危险类别用封闭分类法 + 检索 + 红队审计，并允许**弃权升级人工**。同时 MLLM 只负责对反例提出**因果假设**，由反事实仿真做裁判——归因是假设，干预实验才是证据。

**灵感 3（多智能体 → 契约协商，不是集中式裁判）**：UniBot 天然是多机器人共享空间。让每个机器人各持本地证书，LLM 智能体提议 assume-guarantee 契约（我在什么假设下保证什么），可信检查器验证包含关系与循环依赖的良基性。这把 v19 的 IP-47 组合代数从「手写模板拼接」升级为「协商生成 + 形式验收」。

**耦合（v8 = v7 + 信任分层）**：v19 的 SCV/CKB/ECR 原封不动变成智能体的**工具与记忆**；新增的可信内核对智能体的**每个动作**把关；语义规格编译器把「人写的规格」变成「可审计的候选规格」。飞轮的驾驶员从人类换成智能体，但飞轮的刹车（内核）与方向盘（规格）都被形式化约束。

**边界声明（先泼冷水）**：本方案能证明的是「**相对于被编译出的规格 H 安全**」，不能在系统内部证明「H 完整覆盖了真实世界的一切危险」。这是规格有效性问题（specification validity），只能靠封闭分类法、对抗审计与经验欠定率 USR 来压低——这也是本轮最大风险所在，必须诚实标注。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（证明携带动作 PCAA 与证书演算 Γ）**：动作 α = (s, u)（技能/状态/控制）。动作证书 C_α 是固定证书演算 Γ 中的证明项，Γ 的推理规则均为可判定、低复杂度检查：`LOOKUP`（IP-56 表项 + 网格误差 η 推出边际下界）、`INTERVAL`（区间传播/LipSDP 推出状态包络）、`SAMPLE`（N 条 i.i.d. 仿真轨迹经 Clopper–Pearson 给出违例概率 ≤ ε，置信 1−δ）、`MEET`（两证书保守取交）、`WEAKEN`（仅允许单调弱化后件）、`COMPOSE`（assume-guarantee 组合）。可信检查器 V(C_α, π_α, S) ∈ {accept, reject, unknown}，**unknown 一律按 reject（fail-closed）**。**定理 1（提议者无关性）**：若执行器只执行 V=accept 的动作，则无论提案者 P（任意 LLM 乃至对抗者）如何，执行轨迹满足规格 S 的概率 ≥ 1 − Σ_α ε_α（统计规则取 union bound，确定性规则 ε=0）。证明：对执行步归纳，每步可靠性仅依赖 Γ 各规则的可靠性，与 P 的生成过程无关。**推论**：LLM 幻觉不会直接造成不安全，只会造成拒绝与重规划。

**定义 39（保形语义规格证书）**：设指令 ℓ、多模态观测 o。语义证书 C_sem = (H, {Θ_α(h)}_{h∈H}, amb, δ_ground)。其中 H 为危险类别集合（取自**封闭危险分类法**并经 MLLM 提议/检索筛选），Θ_α(h) 为类别 h 的接地参数（距离阈值、区域边界、接触判定）的**保形集合**（split-conformal，覆盖概率 ≥ 1−α），amb 为解释歧义度 1−max_i p_i，δ_ground = radius(Θ_α)。保守安全集 S(C_sem) = {x : ∀h∈H, ∀θ∈Θ_α(h), ¬hazard_h(x;θ)}（对参数取交 = 最保守）。**条件可靠性**：若真实危险类别 H* ⊆ H，且真实参数 θ* 的等价类落在 Θ_α（覆盖事件，概率 ≥ 1−α），则 S(C_sem) ⊆ S(H*, θ*)。**规格欠定率** USR = Pr[H* ⊄ H]——**该量不能被系统内部证明，只能经验估计**，是规格有效性的度量。amb > τ_amb 时**弃权**（升级人工或退到最保守谓词 P_⊥）。

**定义 40（良基修复策略）**：修复战术 τ: C ↦ C′ 由智能体自由选择。定义进展测度 Φ(C) = (|Cex(C)|, −Cov(C)) 的字典序。单调修复监督器仅当 Φ(C′) < Φ(C)，或 C′ 的证明义务多重集在有限证书格上严格下降时才接受；否则强制回退到预设战术集合（网格加密 / 保守放大 / 降档）。**定理 2（终止性）**：在有限证书格上，单调修复 + 有限战术集使 CEGAR 在 ≤ N_max 步内终止于不动点（可能输出「不可证」而非死循环）。这把 LLM 的任意选择约束为**良基搜索**。

**定义 41（多智能体 assume-guarantee 契约）**：机器人 i 的契约 K_i = ⟨A_i, G_i⟩（假设轨迹集 / 保证轨迹集）。组合 K_1∥…∥K_n 可靠当且仅当对每个 i，G_i ⊆ A_{¬i}（非循环），或在循环依赖时存在良基秩函数 ρ 使依赖图按 ρ 严格下降。检查器验证包含关系与 ρ。**定理 3**：若所有契约通过检查，则并系统满足 ⋂G_i 且组合不引入新的不安全轨迹（相对各自规格）。

**定义 42（认证自主率与安全自主前沿）**：AR = N_accept/N_attempt（被证明接受并自主执行的比例）；FRR = N_false_reject/N_safe_attempt（本可安全执行却被拒）。**安全自主前沿** = 在硬约束 {USR ≤ δ_spec, 不安全事件 = 0} 下，(AR, FRR, 人工介入 H) 的 Pareto 面。这是形式化证书与竞赛指标（成功率、步骤分、排行榜）之间的显式接口：**形式化不该牺牲泛化，而应把泛化能力换成可度量的自主率**。

**定义 43（智能体开销模型 v3 与「慢思考快检查」）**：Γ_agent = f_MLLM·Γ_MLLM + f_check·Γ_check + E[veto]·Γ_repair。频率分层：f_MLLM ≈ 1–5 Hz（任务级），f_check ≥ 100 Hz（控制级）。**命题**：只要 Γ_check ≤ 10ms，大模型延迟不进入实时回路，只影响任务级吞吐——这从成本上论证「大 MLLM + 小内核」在边缘可行（MLLM 可跑云端/Orin，内核跑 MCU 级）。

## 2. 三大新增产出（IP-57/58/59 + 对 v19 的升级）

### 2.1 IP-57 CERT-AGENT（证书智能体 CAA）
1. **角色拆分**：规划者（任务分解/技能选择）、修复者（读反例改证书）、归因者（反例根因假设）、协商者（契约谈判）。可共用一个多模态 LLM 的多角色，也可分工。
2. **工具即能力边界**：智能体只能通过受审计的工具 API 影响外部：`stress_test`(IP-54)、`retrieve`(IP-55)、`lookup`(IP-56)、`cegar`、`rollout`、`counterfactual`、`check`(V)。工具返回**结构化结果 + witness**，不接受自由文本作为证据。
3. **动作门（Action Gate）**：智能体的每次技能调用 / 重规划 / 契约提交，都走「构造 PCAA → V 检查 → 执行或驳回」。驳回后允许**有界**修复（定义 40），超界即 SafeFallback（回退 v19 的保守策略）。
4. **记忆与反思**：CKB 作为长期记忆（检索模板、反例、契约、语义规格片段）；失败反思写入带 provenance 的日志，供审计与回滚。

### 2.2 IP-58 SEMANTIC-SPEC-COMPILER（保形语义规格编译器 SSC）
1. **危险类别落地**：以封闭危险分类法为骨架（碰撞/夹持/跌落/越界/接触危险物/动态遮挡/失稳…），MLLM 在骨架上做「勾选 + 证据 + 缺失告警」，而非开放生成——从结构上降低漏项。
2. **谓词接地**：解释文本 ↦ 参数化谓词模板（空间关系、接触、可通行、动态区域），几何参数由检测/点云/地图估计；开放词表检测负责物体类别。
3. **保形参数集**：在人工确认的规格标定集上做 split-conformal，得到 Θ_α(h)；运行时对参数取交（保守），δ_ground 写入证书并参与漂移界。
4. **弃权与升级**：amb/冲突/证据不足 → 弃权，转人工或退到 P_⊥；弃权率是被显式优化与审计的指标，而非隐藏失败。

### 2.3 IP-59 CONTRACT-NEGOTIATOR（跨智能体契约协商 ACN）
1. **协议**：`propose(K_i)` → `challenge(witness)` → `refine` → `accept`；所有消息携带证明项（proof-carrying message）。
2. **检查器**：验证 G_i ⊆ A_{¬i} 的包含关系；循环契约要求良基秩 ρ；无解则 FAIL_TO_HUMAN。
3. **与 IP-47 融合**：乘积自动机模板由协商生成并预存 CKB，新组合 = 检索 + 协商 + 验收。

## 3. 四层架构 v8（信任分层）

```
L0 可信内核对 (Trusted Kernel, 小/可审计/形式化验证):
   V 动作检查器(证书演算 Γ) + IP-56 ECR(L0查表/L1 INT8) + IP-51 动作门 + SafeStop
L1 感知与接地层:
   TRI-FUSE + IP-49 LIO → 度量语义图 C_ms + 漂移界 B_t
   + 检测/分割/开放词表 → 多模态观测 o
   + IP-58 SSC → 语义规格证书 (H, Θ_α, amb, δ_ground)（可弃权）
L2 证书智能体层 (Untrusted, 沙箱):
   规划/修复/归因/协商 Agent + 工具 API(SCV/CKB/ECR/CEGAR/反事实) + CKB 记忆 + 反思日志
   唯一输出 = 证明携带动作 PCAA；不得直接驱动执行器
L3 飞轮与治理层:
   IP-54 SCV 仿真 + IP-55 CKB 知识库 + IP-59 ACN 契约协商 + 人工监督 + 版本/审计/回滚
运行期：任务/语言 → SSC 编译规格(可弃权) → Agent 检索+规划+构造 PCAA
        → V 检查(≥100Hz, fail-closed) → 执行 → 监测 → 反例
        → 因果归因 → 单调修复 → CKB/仿真飞轮 → 热更新
```

回退：E87 失效 → 关闭 MLLM 规格，退回人工/形式化手写规格（v19 行为）；E88 失效 → 降低自主率、强制人工确认；E89 失效 → 提高证明粒度/降低歧义阈值/增人工；E90 失效 → 固定战术调度表；E91 失效 → 非循环手工契约；E92 失效 → 规则归因；E93 失效 → 收缩到已验证任务集。

## 5. 本轮最大风险

**一句话**：整套体系只保证「相对于编译出的规格 H 安全」；若多模态接地在对抗场景中**静默漏掉一个真实危险约束（欠定）**，系统会以可证明的方式驶向危险——「证明了一个错误的定理」比「没有证明」更危险，因此 E87 的对抗规格审计与 E88 的对抗证明审计是仅有的两条不可回退红线。

# 第 43 轮产物 · 创新点清单 v20：证书智能体（CAA × SSC × ACN）× 证明携带动作（四层架构 v8）

> 承接第 42 轮产物 v19。本轮**增量插入** IP-57/58/59，并升级 IP-51/52/53/49/50/45/47/35；不推倒任何既有层级。核心是把 v19 的「仿真→知识→边缘」飞轮交给一个**不可信但可管控**的智能体驾驶，同时用**可信内核 + 证明携带动作**把 LLM 幻觉隔离为「拒绝」而非「不安全」，用**保形语义编译**把自然语言安全需求变成可审计的候选规格。

## 2. 关键算法（伪代码）

### IP-58 SSC：保形语义规格编译
```
def compile_semantic_spec(instruction, obs, calib, alpha=0.05):
    # 0. 封闭危险分类法为骨架：MLLM 只做勾选/证据/缺失告警，不开放生成
    H = hazard_taxonomy.intersect(mllm.propose_hazards(instruction, obs))
    per_h = {}
    for h in H:
        # 1. 多模态接地：解释文本 -> 参数化谓词模板 + 几何参数
        params = [ground_params(c, obs) for c in mllm.interpret(h, obs, k=K)]
        # 2. split-conformal：用人工确认的规格标定集算非一致性分数
        scores = [nonconformity(p, calib[h]) for p in params]
        q = conformal_quantile(scores, alpha)          # 覆盖 >= 1-alpha
        per_h[h] = [p for p, s in zip(params, scores) if s <= q]
    # 3. 歧义/冲突弃权（fail-safe：宁可要人，不要猜）
    amb = 1.0 - max(max(interpret_p(c)) for c in ...)
    if not H or amb > TAU_AMB or conflicts(per_h):
        return SPEC_ABSTAIN(per_h, amb)                # 升级人工 / 退 P_bottom
    # 4. 保守取交：S(C_sem) 对所有参数解释取交（更保守，保 sound）
    delta_ground = max(radius(per_h[h]) for h in H)
    return SemanticCert(H, per_h, amb, delta_ground, alpha)

def nonconformity(params, calib_h):
    # 与人工确认规格的距离：参数区间越界 + 谓词真值不一致
    return pred_mismatch(params, calib_h) + interval_violation(params, calib_h)
```

### IP-57 CAA：证明携带的智能体主循环
```
class CertifyingAgent:
    def act(self, task, obs):
        spec = SSC.compile_semantic_spec(task.instruction, obs, CALIB)   # IP-58
        if is_abstain(spec):  return request_human(spec)

        mem  = CKB.retrieve(task.fp, env.fp)                             # IP-55
        plan = self.llm.plan(task, spec, mem, tools=TOOL_NAMES)          # 不可信提议

        done = []
        for a in plan.actions:
            cert, witness = self.build_pcaa(a, spec, obs)                # 构造证明项
            verdict = TRUSTED_CHECKER.verify(cert, witness, spec)        # 小内核
            if verdict == REJECT:
                a, cert, witness = self.repair_monotone(                 # 有界修复
                    a, spec, verdict.counterexample, budget=MAX_REPAIR)
            if verdict != ACCEPT:
                return SAFE_FALLBACK(reason=verdict, last=done)          # v19 保守回退
            EXEC(a); done.append((a, cert))                              # 携带证明执行
        CKB.write(task.fp, env.fp, [c for _, c in done], provenance=...)
        return SUCCESS(done)

    def build_pcaa(self, a, spec, obs):
        # 优先廉价证明：L0 查表 -> L1 INT8 -> 仿真统计
        b = ECR.lookup(a.x)                                              # IP-56
        if proves(b, a, spec):  return b.cert, b.witness
        w = SCV.stress_test(a, spec, N=N_sim)                            # IP-54 作工具
        return make_cert(a, spec, w), w

    def repair_monotone(self, a, spec, cex, budget):
        C = current_cert(a)
        for step in range(budget):
            t = self.llm.pick_tactic(C, cex)                             # LLM 选战术
            C2 = apply_tactic(t, C)
            if progress(Phi(C2), Phi(C)):  C = C2                       # 仅接受良基进展
            else:                          C = fallback_tactic(C)       # 强制回退
            cex2 = TRUSTED_CHECKER.find_counterexample(C2)
            if cex2 is None:  return a, C2, witness(C2)
            cex = cex2
        return a, C, INCOMPLETE                                          # 明确报告不可证

    def attribute(self, cex):
        # MLLM 只提因果假设；反事实仿真才是裁判
        hyp = mllm.root_cause(render(cex), cex.sim_state)               # 假设
        for h in hyp:
            delta = counterfactual_sim(cex, do(h.variable, h.new_value))# do-calculus
            if delta.violation_drop >= TAU_CAUSAL and ci_significant(delta):
                return h                                                # 仅接受可复现因果
        return UNKNOWN_CAUSE
```

### IP-59 ACN：proof-carrying 契约协商
```
def negotiate(agents, checker, rounds=MAX_ROUNDS):
    K = [a.propose_contract() for a in agents]          # LLM 提议 assume/guarantee
    for r in range(rounds):
        for i in range(len(K)):
            if not checker.well_founded(K, i):          # 循环依赖需良基秩 rho
                w = checker.dependency_witness(K, i)
                K[i] = agents[i].refine(w)              # 只接受减少秩的修订
        if all(checker.compatible(K, i) for i in range(len(K))):
            return checker.compose(K)                   # 已验证组合（附证明）
    return FAIL_TO_HUMAN(K)                             # 无解显式升级
```

### 可信检查器 V：证书演算与 fail-closed
```
def verify(cert, witness, spec):
    # 每条证明项必须匹配一条 Γ 规则；规则检查均 O(1)/O(log N)
    if cert.rule == 'LOOKUP':
        return check_table_entry(witness, cert, spec, eta_interval)   # 网格误差界
    if cert.rule == 'INTERVAL':
        return check_interval_enclosure(witness, cert, spec)          # 区间/LipSDP
    if cert.rule == 'SAMPLE':
        return check_statistical_bound(witness, cert, epsilon, delta)# Clopper-Pearson
    if cert.rule == 'MEET':
        return all(verify(*p, spec) for p in cert.parts)              # 保守取交
    if cert.rule == 'WEAKEN':
        return is_weaker(cert.post, cert.src.post) and verify(cert.src)
    if cert.rule == 'COMPOSE':
        return check_assume_guarantee(cert.parts)                     # 包含 + 良基
    return UNKNOWN                                                    # 未知规则 -> reject
```

### IP-51/52/56 升级：动作门与快速检查路径
```
# CAR：只有证明接受的动作才迁移
def car_step(e, x, action):
    if action is None:
        return SAFE_STOP
    verdict = TRUSTED_CHECKER.verify(action.cert, action.witness, SPEC[e])
    if verdict != ACCEPT:
        return VETO_REPLAN if replan_budget > 0 else SAFE_STOP
    return ADVANCE(e, action.u)                                       # 携带证明执行

# LCS v3：检查优先，档位即证明强度
def certify_check(x, guards, budget_us=10000):
    b = ECR.lookup(x)                       # T-1: L0 查表 (~5us)
    if proves_all(b, guards): return b, -1
    if budget_us < 110: return DOWNGRADE(b), -1
    m = ECR.monitor_int8(x)                 # T0: L1 INT8 (~100us)
    if proves_all(m, guards): return m, 0
    w = SCV.stress_test(x, guards, N)       # T1: 仿真统计（任务级预算）
    return w, 1
```

## 6. 与已有工作的差异（定位）

- **vs Proof-Carrying Code / Proof-Carrying Data**：把「代码携带证明」迁移到「智能体动作携带证明」，并引入 **LLM 作为不可信提议者** 的显式可靠性定理（定理 1）。
- **vs Shielding / 安全屏障**：传统 shield 是手写安全集；本方案用 **证书演算 + 可验证证明项** 作为 shield，且与 IP-54/55/56 的仿真/检索/边缘查表打通。
- **vs LLM-modulo / 带验证器的智能体**：多数工作把验证器当「事后检查」；本方案把每个动作的证明构造、失效修复、契约协商都纳入**同一个证明演算 Γ**，并给出终止性与组合可靠性。
- **vs 保形预测**：这里用于**语义规格参数**而非分类标签，且取交方向保证「不弱化规格」，同时把无法内部证明的**类别完整性**单列为 USR 风险，避免过度承诺。

## 7. 本轮最大风险

**一句话**：整套体系只保证「相对于编译出的规格 H 安全」；若多模态接地在对抗场景中**静默漏掉一个真实危险约束（欠定）**，系统会以可证明的方式驶向危险——「证明了一个错误的定理」比「没有证明」更危险，因此 E87 的对抗规格审计与 E88 的对抗证明审计是仅有的两条不可回退红线。
