# 第 56 轮（承接第 55 轮 v31 GroundEdge-GenSim+++；本轮灵感：「安全对齐」×「迭代验证」）

> 第 55 轮把感知标签升级为可执行的语义-接触约束，并给出单轮的语义-接触联合证书 `J_s`。本轮追问两个被证书悄悄假设掉的问题：**证书是“对谁”安全的**（安全对齐：语义可行 ≠ 人类意图可接受）与**证书能保鲜多久**（迭代验证：一次离线验证无法覆盖部署分布漂移）。核心矛盾：**H24** 安全对齐不是给策略加一个偏好奖励项，而是把“接触意图”投影到经授权的安全宪法上，且该投影必须与生存核**求交**而非串联；**H25** 证书的 soundness 是时间局部的，部署本身会改变数据分布，一次验证的固定样本置信界在可选停止与漂移下会系统性失效——必须用 anytime-valid 的迭代验证把“证书”变成“可持续撤销的验证过程”。

## 0. 直觉与动机

**灵感 1（安全对齐 → 接触意图的宪法投影，而非奖励塑形）**
直觉：安全对齐常被写成 RLHF 式的偏好奖励，但机器人接触安全不是“平均人类更喜欢”，而是“某些接触在后果上不可逆、因此在任何情境下都不允许”。应先把安全规范编译成 **安全宪法** `𝒦`：一个对“接触-后果”事件的偏序加不可逆严重度，再把策略的 **接触意图**（它准备压哪些点、以多大力、持续多久）投影到 `𝒦` 的可接受集。对齐残差不是 log-prob，而是“意图与宪法允许集之间、按不可逆性加权的距离”。

**灵感 2（安全对齐 → 对齐集与生存核求交，而非级联）**
直觉：常见做法是“先算动力学可行，再做对齐”，但两者会互相掏空：对齐可能删掉唯一可用的支撑接触，使动力学不可行；生存核又可能要求压上宪法禁止的接触。必须求交 `K_𝒦(Σ)=K(Σ)∩A_𝒦`，并在交为空时触发 **意图重协商**（换技能 / 求助 / 降级到保守子集），而不是让护盾 QP 在下游硬崩。

**灵感 3（迭代验证 → anytime-valid 安全下界，而非一次性区间）**
直觉：部署中我们持续看到安全/不安全事件，但会“看着数据决定何时停”。固定样本置信区间在可选停止下失效。应维护 **e-process / 置信序列**，给出对任意停止时刻都有效的安全概率下界 `L_t(α)`。于是证书不再是“某次验证通过”，而是“到 t 时刻为止仍未被推翻”。

**灵感 4（迭代验证 → 证书有半衰期与漂移触发器）**
直觉：验证数据来自旧分布，部署分布会漂移。证书应带 **有效期 `T_valid`** 与 **对齐/语义/接触漂移** 监测；一旦漂移超预算，证书自动降级为“待复验”，系统回退到保守子集。迭代验证因此是 **验证—撤销—复验** 的闭环，而不是一次性门禁。

**灵感 5（安全对齐 × 迭代验证 → 验证预算的后果敏感分配）**
直觉：验证是昂贵的（要真机试接触）。哪些接触该优先复验？应优先验证 **不可逆性高 × 对齐残差大 × 漂移快 ÷ 验证成本低** 的接触类，即把验证预算投到“证书最先失效且后果最重”的角落。这把第 55 轮的边界保守膨胀升级为 **后果敏感的验证采样**。

## 1. 形式化定义（增量：定义 127–133）

**定义 127（安全宪法与可接受接触意图）**
`𝒦=(O,⪯,sev)`：`O` 为接触-后果事件空间；`⪯` 为安全偏序（`o⪯o'` 表示 `o` 不劣于 `o'`）；`sev:O→[0,1]` 为不可逆严重度。可接受事件集 `O_𝒦={o | o⪯o_ref}`；接触意图 `ι∈Δ(O)` 的可接受集 `I_𝒦={ι | supp(ι)⊆O_𝒦}`。

**定义 128（对齐残差）**
策略 `π` 在状态 `x` 的接触意图为 `ι_π(·|x)`。按严重度加权的对齐残差
`Δ_align(π,x)=inf_{ι'∈I_𝒦} ∫_O sev(o)·|ι_π(o|x)-ι'(o)| do`，
轨迹级 `Δ_align(π)=sup_{x∈𝒳_reach} Δ_align(π,x)`。称 `π` 为 `ε_a`-对齐当且仅当 `Δ_align(π)≤ε_a`。

**定义 129（对齐-生存耦合核与耦合护盾）**
`K_𝒦(Σ)={x∈K(Σ) | Δ_align(π,x)≤ε_a}`。耦合护盾
`u*=argmin_u ||u-u_nom||²_W s.t. x_{t+1}∈K_𝒦(Σ), supp(λ)⊆C^+(Σ)∩C_𝒦, λ∈FC(μ), u∈A_WB`。
若可行集为空，输出 **意图重协商** `ρ(x)∈{换技能, 求助, 保守子集, u_stop}`，而非直接制动。

**定义 130（迭代验证过程）**
验证发生在时刻 `t_1<t_2<…`，批次 `D_k`。验证算子 `V(J_s^{(k)},D_{k+1})→J_s^{(k+1)}`。证书带有效期 `T_valid` 与撤销谓词 `revoke(J_s, class, reason)`；撤销沿第 54 轮技能组合图 `G_S` 的依赖闭包传播。

**定义 131（anytime-valid 安全下界）**
令 `X_i=1{第 i 次接触安全}`。对候选下界 `p`，用可预测的 `λ_i∈[-1/(1-p),1/p]` 定义 e-process
`M_t(p)=∏_{i=1}^t (1+λ_i(X_i-p))`。
在 `H_0: p_true≤p` 下 `M_t(p)` 为非负上鞅，由 Ville 不等式，
`P(∃t: M_t(p_true)≥1/α)≤α`。
取 `L_t(α)=inf{p | M_t(p)<1/α}`，则 `P(∀t≥1: p_true≥L_t(α))≥1-α`。可对 `λ` 做混合/多臂投注以提升功效。

**定义 132（对齐漂移与漂移触发）**
以严重度核的 MMD 度量意图分布漂移 `D_t=MMD(ι_{π_t}, ι_ref)`，并维护 CUSUM 统计量。当 `D_t>ε_d` 连续 `w` 个窗口，或 CUSUM 越界，触发 **证书降级**。

**定义 133（迭代验证证书）**
`J_IV=(J_s, L_t(α), Δ_align, D_t, T_valid, chain_hash, evidence_chain)`。
可部署条件：
`L_t(α)≥p_min ∧ Δ_align≤ε_a ∧ D_t≤ε_d ∧ t<T_valid ∧ ¬revoked(J_s)`。
`evidence_chain` 为哈希链，`chain_hash_t=H(chain_hash_{t-1}, batch_id, bounds)`，保证验证可复现、不可静默改写。

**定义 134（验证预算优先级）**
对接触类 `c`：`prio(c)=sev(c)·Δ_align(c)·drift_rate(c)/cost(c)`；每轮验证按 `prio` 降序采样，把预算投到“最不可逆且最先失效”的接触类。

## 2. 关键算法 伪代码

### IP-127 SCB（Safety Constitution Builder）

```python
def build_constitution(specs, human_prefs, irreversibility):
    O = enumerate_contact_outcomes(specs)              # (point, force, duration, consequence)
    prec = derive_partial_order(human_prefs, specs)    # o <= o' : o no worse than o'
    sev = {o: irreversibility.score(o) for o in O}     # monotone, calibration-checked
    O_k = {o for o in O if prec.le(o, specs.o_ref)}    # default-deny for irreversible
    return Constitution(O, prec, sev, O_k)
```

### IP-128 CAK（Coupled Alignment Kernel）

```python
def coupled_kernel(K_sem, policy, constitution, eps_a):
    K, margins = set(), []
    for x in K_sem.samples:
        iota = policy.contact_intent(x)
        d = weighted_tv_to_admissible(iota, constitution.I_k, constitution.sev)
        if d <= eps_a:
            K.add(x)
            margins.append(eps_a - d)
    return KernelApprox(K_in=inner_hull(K), K_out=outer_hull(K, eps_a),
                        margin=min(margins) if margins else 0.0)
```

### IP-129 ESM（E-process Safety Monitor）

```python
def safety_lower_bound(state, events, alpha, p_grid):
    for x in events:
        state = update_predictable_bets(state, x)     # lambda_t from past only
    # M_t(p) is nonincreasing in p; confidence set is [L_t, 1]
    L = min(p for p in p_grid
            if e_value(state, p) < 1.0 / alpha)
    return L, state
```

### IP-130 IVL（Iterative Validation Loop）

```python
def iterative_validation(cert, policy, validator, drift, budget):
    while deployed(cert):
        classes = priority_order(cert, budget)         # IP-134 / 定义 134
        batch = validator.sample(classes, budget)
        new_cert = validator.run(batch)                # replay + real contact trials
        new_cert.J_s = update_semantic_contact_cert(cert.J_s, batch)
        new_cert.L = safety_lower_bound(cert.L_state, batch.events,
                                        budget.alpha, budget.p_grid)
        new_cert.D = drift.estimate(policy, batch.window)
        if new_cert.D > budget.eps_d or not validator.coverage_ok(batch):
            new_cert = revoke(new_cert, batch.contact_classes, 'drift_or_coverage')
        if new_cert.expired() or new_cert.L < budget.p_min:
            new_cert = revalidate(new_cert, policy, validator)
        gate(new_cert)                                 # deploy / degrade / stop
```

### IP-131 ADM（Alignment Drift Monitor）

```python
def alignment_drift(policy, constitution, window):
    iota = empirical_intents(policy, window)
    mmd = kernel_mmd(iota, constitution.I_ref, kernel=severity_kernel(constitution.sev))
    cusum = max(0.0, cusum_prev + mmd - budget.eps_d / 2)
    return DriftStat(mmd=mmd, cusum=cusum,
                     alarm=(mmd > budget.eps_d and windows_above >= budget.w))
```

### IP-132 RVC（Recursive Validation Certificate）

```python
def append_validation(cert, batch, bounds):
    h = hash_chain(cert.chain_hash, batch.id, bounds, batch.contact_classes)
    return IterativeCert(J_s=cert.J_s, L=bounds.L, align=cert.align,
                         drift=bounds.D, valid_until=bounds.T_valid,
                         chain_hash=h, evidence_chain=cert.evidence_chain + [batch.id])

def revoke(cert, classes, reason):
    for s in dependency_closure(cert.deps, classes):   # via SCOM G_S
        s.status = 'revoked'
        s.fallback = conservative_subset(s)            # never fail-open
    return cert.with_status('revoked', reason)
```

### IP-133 VBA（Verification Budget Allocator）

```python
def verification_priority(classes, sev, residual, drift_rate, cost):
    return sorted(classes,
                  key=lambda c: sev[c] * residual[c] * drift_rate[c] / cost[c],
                  reverse=True)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SCB | O(|O|·log|O| + |P|) | O(|O|) | 偏序无环、严重度单调校准 |
| CAK | O(|K_sem|·|O|) | O(|K|) | 对齐残差上界 sound、交非空或重协商 |
| ESM | O(T·|p_grid|) | O(|p_grid|) | 投注可预测、上鞅性、Ville 界 |
| IVL | O(N_val·(QP+|Ω|)+|deps|) | O(|cert|) | 批次可交换、撤销传播覆盖依赖闭包 |
| ADM | O(n²)（流式 O(n)） | O(n) 或 O(1) | 核函数正定、漂移阈值校准 |
| RVC | O(|deps|) | O(|evidence|) | 哈希链单调、撤销不可回滚 |
| VBA | O(|C|·log|C|) | O(|C|) | 优先级与后果单调一致 |

**正确性定理（Aligned-Iterative Safety Soundness）**
假设第 55 轮 (A29)–(A32) 成立；并新增
**(A33)** 宪法 sound：`O_𝒦` 不漏放真实不可逆事件（默认拒绝不可逆接触）；
**(A34)** 验证批次与部署分布可交换，或 `D_t≤ε_d` 给出 `TV(P_deploy,P_val)≤ε_d`；
**(A35)** `λ_t` 可预测且有界，故 `M_t(p)` 在 `H_0` 下为非负上鞅；
**(A36)** `T_valid≤1/τ_drift`，且撤销沿 `G_S` 的依赖闭包传播完整。
则对任意停止时刻 `τ`（anytime）：
```
P_safe(τ) ≥ L_τ(α) - P(Δ_align>ε_a) - P(D_τ>ε_d) - P(cert stale) - P(constitution unsound)
```
且一致覆盖保证
```
P(∃t: L_t(α) > p_true) ≤ α
```
关键：**宪法把“可行”收窄为“被授权”**，**耦合核保证对齐不掏空动力学**，**e-process 抵抗可选停止**，**漂移触发撤销防止证书永续**，四者缺一不可。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 宪法欠规约，漏掉不可逆接触 | 高 | 对抗式红队宪法 + assume-guarantee + 不可逆默认拒绝 |
| anytime 下界过松（vacuous） | 高 | 混合投注/多臂 e-process + 分类分界 + 复用离线样本 |
| 慢漂移未被检测 | 高 | CUSUM + 定期 held-out 重放 + `T_valid` 强制复验 |
| 撤销级联导致系统“冻结” | 中 | 保守子集降级 + 重协商 + 撤销范围最小化 |
| 验证数据自证/泄漏 | 高 | 预注册验证协议 + 外部审计集 + 接触类隔离 |

## 6. 本轮最大风险

**一句话**：安全对齐与迭代验证把“单轮可行证书”升级为“宪法约束下的持续验证过程”，但其 soundness **三重依赖宪法的完备性、验证分布与部署分布的可交换性、以及 e-process 投注设定的有效性**；一旦宪法以“平均偏好”冒替“不可逆硬约束”而漏放某类接触，anytime 下界又因漂移与自证数据不断续期，系统会拿着一份“看起来仍然有效”的证书，把策略持续推向人类从未真正授权的接触——因此必须以 **默认拒绝不可逆接触 + 外部 held-out 审计 + 漂移即撤销** 三重护栏，宁可让证书过期，也不把“验证未推翻”当作“安全已证明”。

```python
            K.add(x)
            margins.append(eps_a - d)
    if not K:
        return ('renegotiate', intent_renegotiation(policy, K_sem))
    return KernelApprox(K_in=inner_hull(K), K_out=outer_hull(K, eps_a),
                        margin=min(margins))
```

```python
def iterative_validation(cert, policy, validator, drift, budget):
    while deployed(cert):
        classes = priority_order(cert, budget)         # IP-133
        batch = validator.sample(classes, budget)
        new_cert = validator.run(batch)                # replay + real contact trials
        new_cert.J_s = update_semantic_contact_cert(cert.J_s, batch)
        new_cert.L = safety_lower_bound(cert.L_state, batch.events,
                                        budget.alpha, budget.p_grid)
        new_cert.D = drift.estimate(policy, batch.window)
        if new_cert.D > budget.eps_d or not validator.coverage_ok(batch):
            new_cert = revoke(new_cert, batch.contact_classes, 'drift_or_coverage')
        if new_cert.expired() or new_cert.L < budget.p_min:
            new_cert = revalidate(new_cert, policy, validator)
        gate(new_cert)                                 # deploy / degrade / stop
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCB | O(|O|·log|O| + |P|) | O(|O|) | 偏序无环、严重度单调校准 |
| CAK | O(|K_sem|·|O|) | O(|K|) | 残差上界 sound、空交转重协商 |
| ESM | O(T·|p_grid|) | O(|p_grid|) | 投注可预测、上鞅、Ville 界 |
| IVL | O(N_val·(QP+|Ω|)+|deps|) | O(|cert|) | 批次可交换、撤销覆盖依赖闭包 |
| ADM | O(n²) / 流式 O(n) | O(n) / O(1) | 核正定、阈值校准 |
| RVC | O(|deps|) | O(|evidence|) | 哈希链单调、撤销不可回滚 |
| VBA | O(|C|·log|C|) | O(|C|) | 优先级对后果单调 |

**正确性定理（Aligned-Iterative Safety Soundness）**
假设第 55 轮 (A29)–(A32) 成立；并新增
**(A33)** 宪法 sound：`O_𝒦` 不漏放真实不可逆事件（不可逆接触默认拒绝）；
**(A34)** 验证批次与部署分布可交换，或 `D_t≤ε_d` 界定 `TV(P_deploy,P_val)≤ε_d`；
**(A35)** `λ_t` 可预测有界，`M_t(p)` 在 `H_0:p_true≤p` 下为非负上鞅；
**(A36)** `T_valid≤1/τ_drift`，撤销沿 `G_S` 依赖闭包传播完整。
则对任意停止时刻 `τ`：
```
P_safe(τ) ≥ L_τ(α) - P(Δ_align>ε_a) - P(D_τ>ε_d) - P(cert stale) - P(constitution unsound)
```
以及一致覆盖：
```
P(∃t: L_t(α) > p_true) ≤ α
```
关键：**宪法把“可行”收窄为“被授权”**，**耦合核保证对齐不掏空动力学**，**e-process 抵抗可选停止**，**漂移即撤销防止证书永续**，**依赖闭包撤销防止组合技能借尸还魂**。

## 7. 本轮最大风险

**一句话**：安全对齐与迭代验证把“单轮可行证书”升级为“宪法约束下的持续验证过程”，但其 soundness **三重依赖宪法的完备性、验证分布与部署分布的可交换性、以及 e-process 投注设定的有效性**；一旦宪法以“平均偏好”冒替“不可逆硬约束”而漏放某类接触，anytime 下界又因漂移与自证数据不断续期，系统会拿着一份“看起来仍然有效”的证书，把策略持续推向人类从未真正授权的接触——因此必须以 **默认拒绝不可逆接触 + 外部 held-out 审计 + 漂移即撤销** 三重护栏，宁可让证书过期，也不把“验证未推翻”当作“安全已证明”。
