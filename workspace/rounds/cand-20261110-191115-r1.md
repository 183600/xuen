# 第 47 轮（承接第 46 轮 v23；本轮灵感：用户测试 × 创新点提炼） · UT-CIX：把用户测试升级为外部观测通道，把创新点提炼为带证据等级的声明图（验证层 v11）

> 承接第 46 轮 v23。v10/v23 已堆叠 26 个 IP 与五条保证链（姿态证书 P_t、能量租约 ℓ_e、记忆检索、语音-动作绑定、安全队列），但它们共享一个从未被检验的隐含假设 H5：所有退化层 Ω_deg、功耗模型、锚点预测都在系统自身模型内闭合，soundness 是"自证"的。本轮两个灵感词正面命中 H5：**用户测试**提供系统无法自造的对抗性观测（用户遮挡镜头、含糊指代、非预期运动），**创新点提炼**要求把技术增量收敛为可证伪、可消融、可度量、可分级的声明。二者耦合出新的科学问题：**如何把用户测试从"事后打分"变成外部观测算子，发现模型外退化并回流；同时把 IP 堆叠提炼成带证据等级 E0–E3 的创新点声明图，并对证书施加外部有效性校准**。

## 0. 直觉与动机

**灵感 1（用户测试 → 外部观测算子，而非满意度打分）**
直觉：用户测试最贵的产出不是 4.2/5 分，而是系统"想不到"的输入分布。实验室把退化层枚举成 Ω_deg={透明/高光/弱纹理/深度空洞/快速运动}，真实用户却会举手挡镜头、把物体摆到镜面旁、用"那个"做指代、因等待而改变站姿。于是定义外部观测算子 O_ext: episode → (ω_ext, f_ext)，模型外退化集 Ω_unk = ω_ext ∖ Ω_int。用户测试由此与深度相机并列，是一种**外部可观测性通道**：深度相机补充几何观测，用户测试补充"人因退化"观测。

**灵感 2（创新点提炼 → 带证据等级的声明图，而非 IP 编号堆叠）**
直觉：26 个 IP 编号不等于 26 个创新点。评审只问三件事：相对已有工作的 delta 是什么？去掉它系统会怎样（消融）？证据到什么等级？把创新点建模为声明图 CG=(V,E,L,τ)，顶点标注 delta δ、用户可观测指标 metric、证据等级 evidence∈{E0 理论, E1 仿真, E2 实验室用户, E3 现场}，边上区分 supports / attacks / ablates。可辩护判据 = 至少一条 E2/E3 supports + 无未决 attacks + 消融效应显著。IP 编号只是索引，声明才是货币。

**灵感 3（耦合：κ_ext 成为继 ℓ_p、ℓ_e 之后的第三条根信任腿）**
直觉：姿态租约与能量租约都是"内部世界"的租约；外部有效性系数 κ_ext 度量内部模型覆盖真实世界的比例。κ_ext 足够高，证书才敢按 1-α_p 签发；κ_ext 过低说明模型外退化未被覆盖，必须降级或 fail-closed。这样 v10 的双租约被补上"外部世界"这条腿。

**耦合升级**：在 v10 四层之外增加正交的 **L5 外部验证层 UT-CIX**，它不进入实时控制路径，而是离线闭环：UTS 采集 episode → CIX 更新声明图并做盲法消融 → EVC 估计 κ_ext → 回写 CAR 阈值与 DCL 任务。实时控制保持 v10，验证与提炼成为独立、可审计、可预注册的过程。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（用户测试事件与外部观测算子）**
用户测试事件 e=(φ, u, ξ, τ, y)：任务 φ、用户 u、环境 ξ、交互轨迹 τ、结果 y。内部观测 O_int(e)=(ω_int, P_t)，外部观测 O_ext(e)=(ω_ext, f_ext)。**模型外退化集** Ω_unk=ω_ext∖Ω_int；当归一化测度 |Ω_unk|/|ω_ext|≥ε_u 称该事件暴露模型缺口。

**定义 60（创新点声明图）**
CG=(V,E,L,τ_type)。顶点 v=(claim, δ, metric, evidence, ablation)，evidence∈{E0 理论, E1 仿真, E2 实验室用户, E3 现场}；边∈{supports, attacks, ablates}。**可辩护判据**：v 至少一条 E2/E3 supports、无未决 attacks、消融效应 Δ_abl(v)≥δ_min 且新颖度 nov(v)≥ν_min。

**定义 61（外部有效性系数与外部条件 soundness）**
κ_ext = w1·Cover(Ω_int,Ω_ext) + w2·(1−d_TV(P(ω_ext),P(ω_int))) − w3·Fail_unk，
其中 Cover 为内部退化层被外部观测覆盖的比例，Fail_unk 为归因于未知退化的失败率。**外部条件 soundness**：
P(X_t∈P_t | ω_t, m_t, ℓ_p, ℓ_e, κ_ext≥κ_min) ≥ 1−α_p − L_ext·(κ_min−κ_ext)_+，
且当 κ_ext<κ_min 时所有高等级声明降级、CAR 进入保守模式。

**定义 62（用户测试驱动的创新点提炼算子 UDIO）**
给定技术增量集 Δ={δ_j} 与用户测试证据 U，UDIO(Δ,U)={(δ_j, m_j, Δ_abl, nov_j, e_j)}，仅保留 Δ_abl≥δ_min、nov_j≥ν_min、e_j≥E2 的项；**创新点密度** ICE=|可辩护声明|/|总声明|。

**定义 63（提炼的资源最优）**
测试预算 B_u 下 argmax_{测试计划 π} E[Σ_v 1(v 可辩护)] s.t. cost(π)≤B_u，用不确定性采样 + 信息增益贪心近似；消融必须配对、盲法、预注册。

## 2. 三大新增产出与既有 IP 升级

**IP-69 UTS（User-Test Sensor）**
- 结构化 episode schema：任务/用户分层/环境/轨迹/结果/外部退化标注
- 盲法协议：Wizard-of-Oz 注入、双人独立标注、预注册测试计划
- 环境库 + 对抗场景生成：把 Ω_unk 固化为可复现测试用例

**IP-70 CIX（Claim Induction & eXternalization）**
- 从版本 diff 抽取技术增量 δ_j 并初始化/继承声明图
- 证据升级规则：仿真报告→E1，用户测试→E2，现场部署→E3
- 盲法消融：mask 冻结单个 δ_j，配对检验效应量与置信区间
- 新颖性差分：对 prior art 做检索与逐条 claim 对照

**IP-71 EVC（External Validity Calibrator）**
- κ_ext 估计：覆盖度 + 分布距离 + 未知退化失败归因
- κ_ext 校准：分层 bootstrap、按用户/环境分组的方差控制
- 回写：κ_ext<κ_min → CAR 保守化、声明降级、DCL 增采

**既有 IP 升级**
IP-62 CCA：新增人因红队、Wizard-of-Oz、盲法消融审计
IP-61 DCL：Ω_unk 与用户测试回放转为采集任务，带证据等级标签
IP-51 CAR：守卫加入 κ_ext≥κ_min 门控
IP-45 总线：新增 user-test-episode / claim-graph / external-validity 话题

## 3. 算法骨架

UT-CIX 每个测试周期：
1. 版本 diff → 技术增量集 Δ={δ_j}
2. 声明图继承上一轮，标出待验证/待消融边
3. 按不确定性 + 信息增益选测试计划 π（预注册、分层用户）
4. UTS 执行：盲法、Wizard-of-Oz、多模态日志
5. O_ext → Ω_unk；Ω_unk 回流 DCL 与环境库
6. 盲法消融：关 δ_j 重跑同任务，配对检验 Δ_abl
7. CIX 更新声明图，EVC 重估 κ_ext
8. 若 κ_ext<κ_min 或高等级声明被 attacks → 降级声明 + CAR 保守化
9. 输出创新点清单 v+1 与证据附录

## 4. 本轮最大风险

**一句话**：用户测试样本量小且行为分布偏移，κ_ext 的估计可能被少数极端事件或引导性任务设计污染，导致把偶然现象误判为模型外退化并催生伪创新点，或反过来低估 Ω_unk 让证书带着错误的自信继续签发；因此必须以预注册协议、盲法消融与分层抽样控制 κ_ext 偏差，并对低样本声明强制标 E1 而非 E2。

## 2. 关键算法伪代码

### IP-69 UTS
```
@dataclass
class Episode:
    task: str; user: str; env: dict
    trace: list; outcome: str
    omega_ext: set          # 外部标注的退化层
    failure: Optional[str]

def run_user_test(plan, system, users, blind=True):
    eps = []
    for spec in plan:
        sys = system.freeze(mask=spec.mask) if blind else system
        ep = execute(sys, spec, users[spec.user_stratum])
        ep.omega_ext = dual_annotate(ep)      # 双人独立标注，分歧仲裁
        eps.append(ep)
    return eps

def model_gap(eps, Omega_int):
    seen = set().union(*[e.omega_ext for e in eps]) if eps else set()
    Omega_unk = seen - Omega_int
    rate = len(Omega_unk) / max(1, len(seen))
    return Omega_unk, rate
```

### IP-70 CIX：声明图构建 + 盲法消融
```
def build_claim_graph(deltas, prior_graph, eps):
    CG = init_graph(prior_graph)
    for d in deltas:
        v = Claim(delta=d, metric=user_metric(d), evidence='E1',
                  ablation=None)
        CG.add(v)
        for ev in d.sim_evidence:
            CG.add_edge('supports', v, ev, level='E1')
    for ep in eps:
        for d in deltas:
            if not ep.exercises(d):
                continue
            v = CG.claim_of(d)
            if ep.outcome == 'success':
                CG.add_edge('supports', v, ep, level='E2')
                v.evidence = max_level(v.evidence, 'E2')
            elif ep.failure and attributable(ep.failure, d):
                CG.add_edge('attacks', v, ep)
    return CG

def ablate(delta, plan, system, users, n_boot=2000):
    on  = run_user_test(plan, system,        users, blind=True)
    off = run_user_test(plan, system.mask(delta.off_mask), users, blind=True)
    effect = paired_diff(on.metric, off.metric)
    lo, hi = bootstrap_ci(effect, n_boot)
    return effect, lo, hi, (lo > delta_min)
```

### IP-71 EVC：外部有效性系数
```
def external_validity(eps, Omega_int, w=(0.4, 0.4, 0.2)):
    Omega_all = Omega_int | set().union(*[e.omega_ext for e in eps])
    cover = len(Omega_int & Omega_all) / max(1, len(Omega_all))
    tv = total_variation(P_ext(eps), P_int(Omega_int))
    fail_unk = mean([e.failure is not None and
                     not e.failure in Omega_int for e in eps])
    kappa = w[0]*cover + w[1]*(1-tv) - w[2]*fail_unk
    return clip(kappa, 0, 1)

def evc_writeback(kappa, kappa_min, CG):
    if kappa < kappa_min:
        for v in CG.claims:
            v.evidence = downgrade(v.evidence)   # E2->E1, E3->E2
        car.set_mode('conservative')
        dcl.enqueue(Omega_unk_task_list(CG))
    return CG
```

### UDIO：创新点提炼
```
def extract_innovation_points(CG, delta_min, nu_min, prior_art):
    out = []
    for v in CG.claims:
        if not has_support(v, levels=('E2','E3')):  continue
        if has_unresolved_attack(v):                continue
        if (v.ablation is None) or v.ablation < delta_min: continue
        if novelty(v.delta, prior_art) < nu_min:    continue
        out.append(v)
    ICE = len(out) / max(1, len(CG.claims))
    return sorted(out, key=lambda v: v.ablation, reverse=True), ICE
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| UTS 计划选择 | O(\|Δ\|·\|π\|·log\|π\|) | O(\|π\|) | 不确定性采样近最优覆盖高方差声明 |
| CIX 图更新 | O(\|ε\|·\|Δ\|) | O(\|V\|+\|E\|) | 证据等级单调升级，攻击边不自动消除 |
| 盲法消融 | O(2·\|π\|) | O(\|π\|) | 配对 + mask 冻结抑制版本混淆 |
| EVC 估计 | O(\|ε\|) | O(\|Ω\|) | κ_ext∈[0,1]，分层 bootstrap 给方差 |
| UDIO 提炼 | O(\|V\|+\|E\|) | O(\|V\|) | 三条件联合过滤，可复现 |

正确性定理：若 κ_ext≥κ_min，且所有标 E2 的声明均通过预注册盲法消融（Δ_abl 置信下界 > δ_min）且无未决 attacks，则由 UDIO 提取的声明具有外部用户证据支撑；反之若 κ_ext<κ_min，联合证书 soundness 至少下降 L_ext·(κ_min−κ_ext)，系统必须降级声明并进入保守控制。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 外部退化发现率 | 每 10 用户小时新发现 Ω_unk 类别数 | 首轮 ≥3 类；连续两轮新增 ≤1（收敛） |
| E116 声明可辩护率 | ICE；E2+ 声明占比 | ICE ≥ 0.7；E2+ ≥ 50% |
| E117 消融显著性 | 配对效应 95% CI 下界 > δ_min | 假阳性 ≤ 5% |
| E118 κ_ext 校准 | κ_ext 与现场失败率秩相关；ECE | Spearman ≥ 0.7；ECE ≤ 0.1 |
| E119 用户任务体验 | 任务成功率；SUS；信任校准 | 成功率 ≥ 95%；SUS ≥ 75；信任误差 ≤ 0.15 |
| E120 L5 对照（盲评） | 开/关 L5 的 ICE、漏检 Ω_unk 数、评审可辩护率 | 开 L5 时 ICE +≥20%，漏检 −≥50% |

回退策略：E115 不收敛 → 扩充环境库并招募极端用户分层；E117 假阳性 >5% → 增大样本、严格预注册与双盲标注；E118 ECE>0.1 → 先校准 κ_ext 再签发任何 E2 声明；E120 L5 无增益 → 将 L5 降级为轻量评审清单，避免流程成本拖垮迭代。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 小样本致 κ_ext 方差大 | 高 | 分层抽样 + bootstrap + 预注册样本量 |
| 引导性任务/Hawthorne 效应 | 高 | 盲法、Wizard-of-Oz、双人独立标注 |
| 消融混淆（版本间其他改动） | 高 | mask 冻结单 delta、配对任务、同用户回放 |

## 6. 本轮最大风险

**一句话**：以用户测试估计的 κ_ext 为证书背书时，小样本、引导性任务与消融混淆可能同时高估外部有效性，使带 E2 标签的伪创新点进入清单并让 CAR 以错误的自信放行；因此必须坚持预注册、盲法配对消融与分层抽样，κ_ext 未达标时宁可把声明降回 E1 并保守控制。
