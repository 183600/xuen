# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 1 轮；本轮灵感：「双臂协调」×「竞品分析」）

> R73 把「证据计量」做成可组合契约（EC / MReg / CCA / ΣREFLEX / CPB），并宣称三类系统级性质在热替换下保持。但它有三个**被自身成功掩盖的隐含假设**：
> - **默认独立**：PAR 只有在一致性审计通过且 |ρ̂| < ρ_max 时才允许缩窄——相关被当作「估计出来的意外」，共因耦合只是风险 5 的工程缓解，不是结构对象。
> - **自作用反作用**：χ_R: 我的动作 g → 我的噪声。没有「你动 → 我的证据变差」这一类型。
> - **否决可交换、证据可复用**：VETO 取并（安全 ≠ 活性）；PAR 的 conformal 审计集与估计集未强制分离（同一批残差既用来估、又用来证）。
>
> **双臂协调是这三条的同时反例**：
> - **闭链**：两手抓同一刚体，两条运动链合成一个闭链机构，位姿不再独立；loop-closure 残差既是约束又是证据。
> - **内力**：物体完全不动，两手却在「对拧」。任务空间看不见它，它却能捏碎或打滑——这是位姿与接触之外的**第三种计量**。
> - **交叉耦合**：左臂遮挡右臂相机、共同激励桌面振动、共享同一温度场/光源；一个肢体的动作直接改变另一个肢体的噪声。
> - **否决冲突**：两臂各自局部安全，联合却可能死锁，或联合违反共享物体约束——**安全模块的组合不再自动安全**。
>
> **竞品分析**提供第二重纪律：R73 的 C1–C3 只与自己的消融比较，缺少「能力匹配的最强竞品」就谈不上可识别。把竞品也写成契约，可以做**跨契约重放**：用同一组合代数审阅别人公布的模块级不确定度/覆盖率，把「竞品分析」从叙事变成代数。
>
> 核心命题：**把「耦合」从审计里的一个意外（ρ̂）升为一等公民——耦合契约（bond）与耦合预算；系统安全从「每个模块可信」变为「模块及其之间的物理键可信」。** 命名 **COGAUGE-RAS**（COupled & COordinated evidence metrology with GAUGE audits for RAS）。

## 0. 直觉与动机

**灵感 1（双臂协调 → 耦合是物理的，不是统计的；必须被计量，不能被估计掉）**

直觉一：**闭链把「两个智能体」变成一个「有冗余的机构」**。单臂是串链，位姿误差沿链累积；双臂抓同一物体时两链闭合，误差不是各自累积，而是被同一个 loop residual 同时约束。于是相对基座外参、关节编码、连杆柔性、抓取柔顺、热漂移、打滑六类误差第一次能被同一残差同时观测——但**它们也第一次能被同一个残差同时「自证」**。用同一残差既估计又认证，是 R73「深度自标定自举」的同型病，只是从单模块升到闭链级。

直觉二：**内力是「零位移的力」**。两手对拧时物体位姿不变，任何基于物体运动/末端位姿的计量都无残差可用；但它落在抓取映射 G=[G_L G_R] 的零空间里，`G_L f_L + G_R f_R = 0`。它不可由任务空间观测识别（引理 39），却能捏碎物体或让摩擦锥越界。因此它必须是一个**新的证据维度**（u_int 六分量），而不是接触计量的一个分量：接触计量看「手与物体是否滑」，内力计量看「手与手是否在对抗」。

直觉三：**交叉反作用通道是一个矩阵，不是一个向量**。R73 的 χ_R 是自同态；双臂系统里真正的接口对象是 χ_{i→j}(g_i)——i 的动作如何调制 j 的噪声与有效域。最具体的实例是**互遮挡**：左臂在右相机视野里扫过的面积是两臂位姿与相机几何的函数；遮挡比例 α 直接进入右臂深度模块的 u_occlusion。忽略它，就等于把「我自己挡的」误读为「场景变了」——这是 R72/R73 反复批判的「把 A 的不确定度误读为 B 的不确定度」的第三层版本。

直觉四：**安全不等于活性**。R73 的 VETO 取并、非补偿，这保证「任一否决即整体否决」，但没回答「否决之后怎么办」。双臂系统里，支撑臂一旦被否决就可能直接放开物体；两个否决同时触发可能让系统停在「谁也不能动、物体正在下滑」的状态。因此需要**协调否决 + 支撑转移**：否决必须伴随一个联合可达的安全回退。

直觉五：**哪只手臂去「看」本身是一个计量决策**。R73 的 PVOP（视角感知规划）默认单执行者；双臂里「左臂去获得更好视角」可能同时「挡住右臂的视角」。于是 NBV 从单目标优化变成**共享预算下的联合角色分配**，两臂对同一份反作用预算、工作空间与注意力是**内部竞争者**（正好接上「竞品分析」）。

**灵感 2（竞品分析 → 从叙事到代数：能力匹配竞品 + 跨契约重放）**

直觉：论文里的「竞品分析」常退化为「挑一个最弱的基线」。更严谨的做法有两层：
- **外部（可识别性）**：主张 C 的可信度不取决于「比某基线好」，而取决于「**比能力匹配的最强竞品好，且该竞品的机制差异正好是被主张的机制**」。定义竞品能力向量 κ，强制 b* = 能力 ≥ 我们 − δ 且缺少机制 M 的最强者；并配**判别性签名**与**负控制**（关掉 M，其余全同）。找不到能力匹配竞品 ⇒ 主张「不可识别」，降级为附录——与 R73 的 CPB 蒸馏纪律兼容。
- **内部（跨契约重放）**：把每个竞品公布的「模块级不确定度/覆盖率/校准协议」读成外部契约元组，尝试用 CCA² 组合它。若其报告的组合结果优于单调性下界却拿不出**条件化证书**（把共因隐变量条件掉），或覆盖率在组合下不可保持，则标记为**不可组合主张**。这不是攻击竞品，而是把「我们的审计语言」当透镜：**能通过重放的主张，才可比较**。
- **博弈边界**：竞品分析本身会诱导稻草人。对策是**预注册竞品清单**、由第三方挑选 b*、报告负结果；内部竞标（两臂/模块争预算）也不假设策略无偏，而用**事后审计**而非机制设计来约束谎报。

**灵感 3（合并的洞见：耦合契约是「类型」「预算」之外的第三根柱子）**
R73 的契约柱是「类型 + 预算 + 通道」，组合柱是「单调 + 审计 + 热替换」。本轮加第三根柱：**耦合（bond）**。bond 是**超边**（同一物体/同一温度场可耦合 >2 个模块），带声明性的相关下界 ρ_floor、耦合不确定度 u_bond、零空间内力维数、交叉通道矩阵项。于是 R73 风险 5 的「隐共享物理过程」从「希望 conformal 覆盖相关」变成「**声明相关下界并用最坏情况组合**」——保守但可证。

**灵感 4（对 R73 的一次自我修正）**
R73 的定理 29 说「任一模块失效 ⇒ stub ⇒ 零级联」。双臂耦合下这条**是错的**：若失效的是支撑臂，直接 stub（输出 ∅）会松手，物体掉落。正确语义是「冻结-保持 + 支撑转移」。本轮因此把「新层是旧层的严格泛化」精确化为：**在不承载耦合的模块上严格包含 R73；在承载耦合的模块上有限制地扩展，并显式修正一条旧定理**。这是好的研究进程应有的样子：新证据不是给旧定理加注脚，而是划出它的失效边界。

## 1. 形式化定义（增量：定义 383–400）

**定义 383（COGAUGE-RAS 总览与九不变式）** COGAUGE-RAS = (COGAUGE†, CCB, LCEM, IWEM, χ̂, CCA², CVL, EARA, CAP, MODGAUGE-RAS†)。在 R73 五不变式上增四条：
(vi) **耦合显式性**：每一条物理耦合必须声明为 bond（定义 384）；未声明耦合由「残差膨胀审计」检出（定义 385 附），但检出前不得视为独立。
(vii) **闭链证据完整性**：闭链约束进入证据代数，且估计/验证残差必须分离（引理 38）。
(viii) **活性**：联合否决必须携带联合可达安全回退（定义 389）；死锁是可审计的安全失效，不是性能问题。
(ix) **跨臂通道完备**：χ̂ 的每个非对角项必须声明（可为平凡），缺失即组合非法。

**定义 384（耦合契约 CC / bond）** CC = (B, E_c, G_c, ρ_floor, u_bond, D_c, τ_c, I⊥_c, W_c, seal_ref)：
- B ∈ {KIN_CLOSED, WRENCH_INTERNAL, OCCLUSION, COMMON_MODE, OBJECT_SHARED}；
- E_c ⊆ V_M，|E_c| ≥ 2：耦合是**超边**（共享物体可耦合双臂 + 物体位姿 + 力传感器）；
- G_c：约束生成元（闭链约束、内力零空间基 N、遮挡核、共因载荷）；其行空间/零空间是 bond 的「物理内容」；
- ρ_floor ∈ [0,1]：**声明的共因相关下界**（不是估计值）；u_bond ≥ 0：bond 自身生成的不确定度地板；
- D_c：有效域（刚体假设、无滑动、光路存在、温度在范围）；τ_c：追溯合并；
- I⊥_c：bond 级否决（如「刚体假设」「内力有界」「视线存在」）；W_c：校验时序预算。
**bond 是类型不是注释**：组合前必须逐项校验；ρ_floor 与 u_bond 只能由 SEAL-BOND 标定表给出，不允许运行时「估一个更小的 ρ̂ 来换取缩窄」。

**定义 385（闭链位姿证据 LCEM）** r_loop = Log((T_b^L T_L^o)(T_b^R T_R^o)^{-1}) ∈ se(3)，条件似然 p(r_loop | ξ_rel, grasp_mode) = N(h(ξ_rel), Σ_loop)。六分量：
`u_loop² = u_relbase² + u_enc² + u_kin² + u_grasp² + u_therm² + u_slip²`
（双臂相对基座外参 / 关节编码 / 连杆-柔性 / 抓取-物体柔顺 / 热漂移 / 打滑模式）。
**分离审计（关键）**：残差分成估计通道 C_est 与验证通道 C_val（按时间/空间/频带或左右子集），要求 C_est ∩ C_val = ∅；否则闭链带来的 u 缩窄不可认证（引理 38）。**残差膨胀审计**：若经验联合残差协方差超出块对角预测的 conformal 界，则判定存在未声明 bond，强制降级为 PAR 保守并触发 bond 发现流程。

**定义 386（内力计量 IWEM）** 抓取映射 G_L, G_R ∈ R^{6×6}；内力空间 N = ker([G_L G_R]) ⊂ R^{12}，w_int = Nβ。观测：ŵ_int = 把 (f_L^meas + f_R^meas) 投影到 N（扣除外载模型）。六分量：
`u_int² = u_ft² + u_model² + u_comp² + u_ctrl² + u_therm² + u_quant²`
（力/力矩传感器零偏与噪声 / 抓取-外载模型误差 / 物体柔顺 / 双臂控制环耦合 / 温漂 / 量化）。
有效域 D_int = {|β|_∞ ≤ β_max} ∧ {摩擦锥裕度 s(β) ≥ 0} ∧ {挤压裕度 c(β) ≥ 0}。**内力预算** B_int：`Σ_t |β_t| ≤ B_int`，越界即 bond 否决（非补偿）。

**定义 387（交叉反作用通道矩阵 χ̂）** χ̂: 𝒢^{|V|} → (Θ_noise × D′)^{|V|×|V|}，分量 χ_{i→j}(g_i) 表示 i 的动作如何调制 j 的噪声参数与有效域；对角项即 R73 的 χ_R。通道沿组合路径按矩阵合成（不可交换）。**互遮挡实例**：α_{i→j}(g) = 视锥内 i 的连杆/夹爪遮挡 j 相机的立体角占比；u_occl^j = f(α)，作为模式条件项进入 j 的深度分量。**矩阵反作用预算**：`Σ_{i,j} c^{i→j}(g) ≤ B_total`，`c^{i→j} = E[Δu_j | g_i]`；对角是「自伤」，非对角是「伤同伴」。
**性质**：非对角项可为平凡恒等，但必须声明；声明由 bond 的 G_c 与 SEAL-BOND 标定共同约束。

**定义 388（耦合组合代数 CCA² / COMP-BOND）** 对由 bond b 耦合的 (L,R)：
`u_out² = u_L² + u_R² + 2 ρ_b u_L u_R + u_bond²`，其中 `ρ_b ≥ ρ_floor(b)`（取声明下界，而非估计 ρ̂）。
- 仅当存在**条件化证书**（把共享隐变量 c——物体位姿、温度场、光源、振动模态——联合估计/差分测量并验证条件独立）时，才允许用条件残差替换 (u_L, u_R, ρ_b) 并缩窄；
- 无证书 ⇒ 用最坏相关（取 ρ_floor，必要时上界 1，退化为 u_L + u_R + u_bond）。
**单调性**：u_out² 对每个 u_i、对 ρ_b 非减；唯一下降路径被证书显式认证。**这使 R73 风险 5 结构化：相关是声明预算项，不是审计发现。**

**定义 389（协调否决与活性 CVL）** 联合有效 = valid_L ∧ valid_R ∧ (∧_b valid_b)。否决后必须存在**联合可达安全回退** F(s) = {联合动作 a : 在 T 内到达 Safe ∧ ¬ObjRisk}。**活性证书**：对有限抽象后的否决自动机，∀ 可达否决态 s，F(s) ≠ ∅，且存在**释放序 π**（先松哪只手/先后退哪只手）使支撑臂在松手后仍能承载。**支撑转移（support transfer）**是标准回退：被否决臂先「冻结并保持内力」，另一臂接管后再释放；转移期间 |β| ≤ β_max、接触模式不变。死锁 ⇔ F(s) = ∅，是可审计的安全失效。

**定义 390（证据感知角色分配 EARA）** 联合动作 a = (a_L, a_R)：
`a* = argmax [ Progress(a) − λ Σ_i u_i(a) − Σ_{i,j} c^{i→j}(a) − μ·DeadlockPenalty(a) ]`
s.t. 联合安全集、预算闭合、ΣREFLEX² 矩阵预算、bond 有效域。这是 R73 PVOP 的联合推广：视角动作同时进入自己的 χ 与对方的 χ（遮挡通道），因此 NBV 必须显式扣「我挡住了谁」。

**定义 391（竞争性证据竞标 CMB）** 每个模块/肢体提交 bid_i = (Δprog_i, Δu_i, c_i, veto_i)，协调器按**单调分配规则**（边际收益/成本比排序）分配共享预算。**不假设策略无偏**：事后审计把 bid 与实现值对比，系统性高报触发重加权与降级（工程附件）；真实申报由审计而非机制设计保证。

**定义 392（竞品-契约重放 CAP / CCR）** 外部契约 Competitor = (κ, EC_meta, claims, calibration_protocol)，κ 为能力向量（传感器集/数据预算/算力/调参预算/人类先验/基准）。**能力匹配竞品** b*(C) = argmax_b {κ(b) : κ(b) ≥ κ(ours) − δ, 机制 M ∉ b}。主张 C 可识别 ⇔ 对 b* 有预注册配对改进 ∧ 判别性签名 ∧ 负控制（关 M 后效应消失）。**跨契约重放**：把竞品模块级报告代入 CCA²，若组合结果优于单调下界却无 CCA² 条件化证书、或覆盖率不可组合保持、或存在未声明 bond，则标记**不可组合主张**；不可组合 ⇒ 不可比，不进入主比较表。

**定义 393（耦合证书 J_COUP）** `J_COUP = J_MOD^L ⊗ J_MOD^R ⊗ (⊗_{b∈E_b} J(b)) ⊗ J_live`；J(b) 校验 ρ_floor/u_bond 标定、G_c 与零空间维数、χ̂ 非对角完备、D_c 非空；J_live 见定义 389。Valid(J_COUP) ⇒ Valid(J_EMB) 的耦合扩展。

**定义 394（耦合复杂度结构上限）** |V_M| ≤ 24（不变）、|E_b| ≤ 16、bond 元数 ≤ 4、耦合深度 ≤ 2、dim ker ≤ 6、回退图节点 ≤ 64；全部为可审计图性质。

**定义 395（耦合感知退化链）** 单臂模块失效 ⇒ 该臂 stub 化；**但若该臂所在 bond ∈ {KIN_CLOSED, WRENCH_INTERNAL} 且是支撑臂，则 stub 语义必须升级为「冻结-保持」**（保持位姿与内力于 B_int，否决外部运动），直到支撑转移完成；禁止直接释放。**这修正 R73 定理 29**：零级联对「不承载耦合的模块」成立，对支撑模块不成立，必须由 CVL 显式处理。

**定义 396（MBench-B 双臂最小基准）** MB-B1 闭链六分量辨识；MB-B2 内力安全（捏碎/打滑边界）；MB-B3 耦合组合与活性（死锁注入）；MB-B4 竞品重放与判别实验。均 ≤3h 单卡/单台双臂可复现，预注册脚本 + 固定种子 + SEAL-B。

**定义 397（耦合认证成本）** `CertCost_coup = Σ 模块 + Σ 关联 bond 重认证 + J_live 校验`。C3 的双臂可证伪形式：只换一只手（bond 不变）时成本比 > 10×；换手改变 β_max（bond 变）时只重认证**关联 bond**，成本 ~ O(度数)。

**定义 398（SEAL-BOND）** 密封 bond 标定集：受控闭链（已知物体/已知柔顺）、内力标定台、共因激励台（温度/振动/光照）、互遮挡标定场。用于给出 ρ_floor / u_bond / β_max 的保守表，禁止运行时从测试集反推。

**定义 399（耦合有效域与 bond 否决）** D_c 失效（刚体假设破坏、视线中断、温度越界）⇒ bond 否决 ⇒ 联合降级为「自由模式」（禁止闭链/内力相关动作），而非整系统停机；与 R73 的模块 stub 正交。

**定义 400（主张扩展 C4）** **C4（耦合感知计量）**：显式 bond + 相关下界 + 内力维度的联合组合，在**耦合故障（捏碎/打滑/互遮挡/死锁）**上显著优于「把双臂当两个独立单臂 + 事后统计相关」的基线；且不牺牲解耦场景性能（严格包含）。

## 2. 推导

**引理 38（闭链证据的不可自证性 / 分离审计）** 若估计残差与验证残差取自同一测量通道（同一批 C_est = C_val），则由闭链约束报告的条件覆盖 `P(ξ ∈ C_α | C_est)` 不构成对交换性（exchangeability）的有效校准，conformal 覆盖率在验证集上无保证。证明：conformal 的有效性要求校准样本与测试样本可交换；用同一残差既定义缩窄又评估缩窄，等价于在校准集上评估训练集误差。系：**闭链带来的位姿缩窄必须来自与验证残差不相交的通道，否则 u 缩窄不可进证书。**

**引理 39（内力的不可识别性）** 存在非零内部力向量 f_int = Nβ（β ≠ 0）使物体净力/力矩为零（`G_L f_L + G_R f_R = 0`），因此任何仅观测物体位姿/运动的计量映射 h(ξ_rel) 对 β 的 Jacobian 为零：`∂h/∂β = 0`。系：**内力不能从任务空间计量中识别；必须有专用观测量（FT + 抓取模型）与独立的 u_int 维度，否则系统对「零位移的伤害」结构性失明。**

**引理 40（耦合地板与保守性）** 设两模块共享隐变量 c（温度/光源/振动/物体位姿），其方差占总方差比例为 γ ∈ [0,1]，则真实相关系数满足 `ρ ≥ ρ_floor(γ) = γ`（同向共因）或按载荷符号取最坏符号。若 CCA² 使用 `ρ_b ≥ ρ_floor`，则 `u_out²` 不小于真实联合方差，即组合永不乐观。系：**用声明下界替代 ρ̂ 估计，牺牲缩窄换得对隐共因的鲁棒性；只有条件化证书能合法收回缩窄。**

**引理 41（交叉通道的 Lipschitz 与矩阵预算吸收）** 在 D_c 内，χ_{i→j}(g_i) 对 g_i Lipschitz（遮挡比例 α 对方位角连续、u_occl 对 α Lipschitz；内力对关节加速度 Lipschitz），故 `c^{i→j}` 有正下界且对 g Lipschitz。若矩阵预算 `Σ_{i,j} c^{i→j}` 的边际成本有正下界、总边际增益非增（R73 引理 36 的矩阵推广），则 ΣREFLEX² 仍有限停止；**但**分配是两方（或多方）联合优化，若采用竞标，停止性只对「协调器实际执行的联合动作序列」成立，不对「各自独立的局部策略」成立。系：**层数从向量升到矩阵不破坏停止性，破坏的是「去中心化各自停」的假设。**

**引理 42（活性的充分条件）** 若 (i) 每个单模块否决非补偿；(ii) 回退关系 F 在有限抽象图上无「全出边被否决」的可达态；(iii) 存在释放序 π 使支撑臂在转移期间承载的 |β| ≤ β_max 且接触模式不变；则联合系统从任一可达否决态出发，必在 ≤ T 内到达 Safe ∧ ¬ObjRisk，且不经过 ObjRisk 态。证明：对抽象图做后向可达性归纳，π 保证每一步的中间态仍在 Safe。系：**「否决即停机」被替换为「否决即有序撤退」；活性成为可证而非期望。**

**引理 43（耦合热替换的边界）** R73 引理 35 的证明只引用模块 EC 与组合校验。在 COGAUGE 下，替换实现若改变任一关联 bond 的 (ρ_floor, u_bond, β_max, dim ker) 或改变 χ̂ 的非对角项，则组合证明不再成立；仅当替换保持**所有关联 bond 的契约项**时，逐指令性质保持。系：**热替换的单元从「模块」变成「模块 + 其关联 bond 的超边邻域」；认证成本 O(系统) → O(模块 + 度数)。**

**定理 30（COGAUGE 严格包含 / 解耦极限）** 当所有 bond 平凡（无闭链、无内力维、χ̂ 非对角为恒等、ρ_floor = 0、u_bond = 0）且 CVL 空（无耦合否决）时，COGAUGE 逐指令退化为 MODGAUGE-RAS，再退化为 R72 / R71 / R68。**安全单调不减；效率仅在 bond 契约满足时获益。** 注意：该定理**不覆盖**承载耦合的模块（定义 395 的保留）。

**定理 31（耦合证书有效性 ⇒ 耦合安全）** 在 A-coup 假设（契约表达力、ρ_floor 下界真实、零空间模型覆盖真实内力、χ̂ 非对角完备且 Lipschitz、条件化证书有效）下：Valid(J_COUP) ⇒ (i) 各模块 cert 有效；(ii) 每条 bond 的 G_c/ρ_floor/u_bond 经 SEAL-BOND 标定；(iii) 组合满足 CCA² 单调下界；(iv) CVL 活性证书有效；(v) 联合风险 ≤ ε_coup（相对耦合测量模型与 **bond 契约表达力**）。**证明重量现在落在「bond 的建模假设在分布外仍成立」，比 R73 又深一层。**

**定理 32（活性保持的降级）** 若 J_live 有效，则任一模块 stub（含支撑臂的冻结-保持）或 bond 否决，都导致「有序撤退」而非死锁或物体风险；且降级路径不违反 R73 的模块级零级联（在去除支持耦合后）。**「安全只增不减」在形式上保留，但语义从「少一个模态」变为「少一个模态 + 一次有序交接」。**

**定理 33（耦合感知热替换）** impl′ 与 impl 同 EC，且与 impl 关联的每条 bond 契约项逐项相同、cert′ 有效 ⇒ 系统级性质保持；若仅 bond 的数值标定改变（如 β_max 降低），只需重认证该 bond 的 J(b) 与 J_live，无需全系统重审。系：**模块化的复利在双臂场景中变为「超边局部化」：换手/换负载改变的是邻域，不是系统。**

## 5. 本轮最大风险

**一句话**：COGAUGE 把证明负担从「模块契约的表达力」再推深一层到「**耦合契约（bond）的表达力**」——ρ_floor、u_bond、β_max、零空间维数与 χ̂ 的非对角项都是**部署期不可直接观测的建模声明**；只要真实耦合超出这些声明（共因相关低于地板假设、内力落在建模零空间之外、遮挡通道在极端位姿失效），「所有 bond 证书有效、所有组合校验通过、活性证书有效」的系统仍会给出**错误的安全界**，而审计日志会证明「每一步都合规」。竞品分析的存在会放大这一风险：一个被预注册为「能力匹配」的最强竞品，也可能与我们的指标不可公度，使「通过重放」变成「在一个错误坐标轴上正确」。

次级风险与缓解：
1. **Bond 建模假设不可验证** → SEAL-BOND 强制保守表 + 部署期在线残差膨胀审计 + 地板随环境上浮（只增不减）；任何「收窄」须条件化证书。
2. **过度保守导致不可用** → 条件化证书（联合估计共享隐变量/差分测量）+ 自由模式降级 + 分场景 bond 版本化。
3. **CVL 状态爆炸** → 有限抽象（64 节点）+ 单调回退偏序 + 只对可达否决态增量验证。
4. **内力零空间维数/抓取模型失配** → 在线抓取模式后验 + 未知接触即征用安全内力上界 + 越界即 bond 否决。
5. **竞品选择被操纵（稻草人）** → 预注册竞品清单 + 第三方选 b* + 判别性签名 + 报告负结果；不可识别主张降级附录。
6. **跨契约重放误伤竞品（不公）** → 只标记「不可组合」，不判优劣；重放协议与坐标公开；双盲评审校验公平性。
7. **内部竞标谎报** → 事后审计 + 重加权 + 附件的工程降级，不声称机制设计意义上的真实申报。
8. **支撑转移本身的瞬态风险** → 转移期间 B_int 收紧、接触模式不变、转移轨迹预认证；无法认证则冻结并求援（外部人类/制动）。

## 2. 形式化定义（要点版）

**定义 383（总览与九不变式）** R73 五不变式 + 耦合显式性 / 闭链证据完整性 / 活性 / 跨臂通道完备。

**定义 384（耦合契约 CC）** bond 是超边契约；ρ_floor 与 u_bond 只能来自 SEAL-BOND 标定表；禁止运行时估小 ρ 换缩窄；D_c 定义刚体/无滑/光路/温度前提。

**定义 385（LCEM）** 闭链残差条件似然；六分量；**分离审计**要求 C_est ∩ C_val = ∅；残差膨胀超块对角 conformal 界 ⇒ 未声明 bond，强制保守。

**定义 386（IWEM）** 内力是抓取映射零空间分量；六分量；有效域含摩擦锥与挤压裕度；Σ|β| ≤ B_int，越界即 bond 否决。

**定义 387（χ̂ 交叉通道矩阵）** χ_{i→j}(g_i) 调制 j 的噪声与有效域；对角继承 R73；互遮挡 α_{i→j}→u_occl；矩阵反作用预算与有限停止。

**定义 388（CCA² / COMP-BOND）** `u_out²=u_L²+u_R²+2ρ_b u_L u_R+u_bond²`，ρ_b ≥ ρ_floor；只有条件化证书（联合估计/差分测量共享隐变量）可合法缩窄；否则最坏相关。

**定义 389（CVL）** 联合有效 = 各模块 ∧ 各 bond；回退集 F(s) 非空 + 释放序 π；支撑转移期间 |β|≤β_max、接触模式不变；死锁 ⇔ F(s)=∅。

**定义 390（EARA）** 联合动作最大化 Progress − λΣu − Σc^{i→j} − μ·DeadlockPenalty；NBV 显式扣除遮挡同伴的成本。

**定义 391（CMB）** 模块/肢体提交 bid，单调分配；事后审计谎报，重加权/降级；不声称激励相容。

**定义 392（CAP / CCR）** 能力匹配最强竞品 b* + 判别性签名 + 负控制；不可识别主张降级附录；跨契约重放标记不可组合主张，不可组合⇒不可比。

**定义 393（J_COUP）** 模块证书 ⊗ bond 证书 ⊗ 活性证书；Valid ⇒ Valid(J_EMB) 的耦合扩展。

**定义 394（结构上限）** \|V_M\|≤24、\|E_b\|≤16、bond 元数≤4、耦合深度≤2、dim ker≤6、回退图≤64。

**定义 395（耦合感知退化链）** 支撑臂失效 ⇒ stub_support（冻结-保持）；禁止直接释放；修正 R73 定理 29。

**定义 396（MBench-B）** MB-B1 闭链 / MB-B2 内力 / MB-B3 耦合活性 / MB-B4 竞品重放；≤3h、预注册、密封集。

**定义 397（耦合认证成本）** CertCost_coup = Σ模块 + Σ关联 bond 重认证 + J_live；只换手且 bond 不变时比 >10×，bond 变时 O(度数)。

**定义 398（SEAL-BOND）** 闭链/内力/共因/遮挡四类密封标定台；给出保守 ρ_floor/u_bond/β_max 表。

**定义 399（bond 否决与自由模式）** D_c 失效 ⇒ bond 否决 ⇒ 禁用闭链/内力动作的自由模式，非整系统停机。

**定义 400（主张 C4）** 耦合感知计量在捏碎/打滑/互遮挡/死锁上显著优于「独立单臂 + 事后统计相关」，且解耦场景不退化（严格包含）。

# IP-302 CCB：耦合契约（超边）与 bond 注册表
@dataclass(frozen=True)
class CouplingContract:
    btype: str                      # KIN_CLOSED / WRENCH_INTERNAL / OCCLUSION / COMMON_MODE / OBJECT_SHARED
    endpoints: FrozenSet[str]       # 超边，|E_c| >= 2（共享物体可 >2）
    G_c: Callable                   # 约束生成元：闭链约束 / 零空间基 N / 遮挡核 / 共因载荷
    rho_floor: float                # 声明的共因相关下界（非估计）
    u_bond: float                   # 耦合不确定度地板
    domain: Predicate               # D_c：刚体 / 无滑 / 光路 / 温度
    tau_merge: Callable; veto_set: FrozenSet[str]; wcet_us: float; seal_ref: str

class BondRegistry:                 # 超边图（与 R73 MReg 正交，每轮增量校验）
    def check(self):
        return (len(self.bonds) <= 16 and self.max_arity() <= 4
                and self.coupling_depth() <= 2 and all(b.domain.nonempty() for b in self.bonds)
                and all(b.rho_floor >= self.seal.table[b.seal_ref] for b in self.bonds))  # 只能更保守

    def discover(self, resid_cov, blockdiag_pred):   # 残差膨胀审计：发现未声明 bond
        if not conformal_covers(resid_cov, blockdiag_pred):
            return 'UNDECLARED_BOND'                  # 强制降级 PAR 保守 + 触发标定

# IP-303 LCEM：闭链位姿证据（分离审计，禁止自证）
class LoopClosureMetrology:
    def update(self, T_bL, T_Lo, T_bR, T_Ro, enc, thermal, slip_post):
        r = se3_log( (T_bL @ T_Lo) @ inv(T_bR @ T_Ro) )
        u_relbase, u_enc, u_kin = self.calib_relbase, self.calib_enc, self.calib_kin
        u_grasp, u_therm, u_slip = self.calib_grasp, self.calib_thermal(thermal), self.calib_slip(slip_post)
        u_loop = sqrt(u_relbase**2+u_enc**2+u_kin**2+u_grasp**2+u_therm**2+u_slip**2)
        ok = disjoint(self.c_est, self.c_val)         # 引理 38：估计/验证残差通道必须不相交
        return LoopEvidence(r=r, u=u_loop, shrink_certified=ok, tau=self.tchain.merge(enc, thermal, slip_post))

# IP-304 IWEM：内力计量（零位移的力）
class InternalWrenchMetrology:
    def update(self, fL, fR, G_L, G_R, grasp_post, external_model):
        N = null_space(np.hstack([G_L, G_R]))        # w_int = N β，dim ker <= 6
        beta = lstsq(N, project(fL + fR - external_model))
        u_ft, u_model, u_comp = self.ft_noise, self.grasp_model_unc(grasp_post), self.compliance_unc
        u_ctrl, u_therm, u_quant = self.ctrl_coupling, self.thermal, self.quant
        u_int = sqrt(u_ft**2+u_model**2+u_comp**2+u_ctrl**2+u_therm**2+u_quant**2)
        valid = (abs(beta).max() <= self.beta_max) and friction_margin(beta) >= 0 and crush_margin(beta) >= 0
        return InternalWrenchEvidence(beta=beta, u=u_int, valid=valid, tau=self.tchain.merge(fL, fR, grasp_post))

# IP-305 χ̂：交叉反作用通道矩阵（对角=自伤，非对角=伤同伴）
def chi_matrix(modules, g, state):
    C = {}
    for i, mi in modules.items():
        for j, mj in modules.items():
            if i == j: C[(i,j)] = mi.ec.chi_R(g[i])                    # R73 自通道
            else:      C[(i,j)] = mj.ec.chi_cross[i](g[i])             # 交叉通道（须声明，可为恒等）
    occ = {(i,j): occluded_fraction(modules[i].geom(g[i]), modules[j].camera)
           for i in modules for j in modules if i != j}
    return C, occ                                                    # occ 进入 j 的 u_occlusion

def sigmareflex2_step(modules, g, state, budget):
    C, occ = chi_matrix(modules, g, state)
    total = 0.0
    for (i,j), chi in C.items():
        cost = modules[j].reflex_cost(state[j], chi) + occlusion_cost(occ[(i,j)])   # 矩阵预算
        total += cost
        if modules[j].safe_set.violated(chi): return None, total    # 任一稳态越界 → 拒绝
    return (total <= budget.B), total                              # 引理 41：矩阵预算吸收

# IP-306 CCA²：COMP-BOND（声明下界，不估小 ρ）
def compose_bond(ev_L, ev_R, bond, cond_cert=None):
    if cond_cert and cond_cert.valid:                    # 条件化证书：联合估计/差分测量共享隐变量
        uL, uR, rho = cond_cert.conditional(ev_L, ev_R)
    else:
        uL, uR, rho = ev_L.u, ev_R.u, max(bond.rho_floor, 0.0)   # 最坏相关下界，绝不乐观
    u2 = uL**2 + uR**2 + 2*rho*uL*uR + bond.u_bond**2
    return Ev(u=sqrt(u2), D=ev_L.D & ev_R.D & bond.domain,
              tau=ev_L.tau.merge(ev_R.tau).merge(bond.tau_merge),
              veto=ev_L.veto | ev_R.veto | bond.veto_set)        # 引理 40：组合单调且保守

# IP-307 CVL：协调否决、活性与支撑转移
def coordinated_veto(s, mods, bonds, graph):
    valid = all(m.valid(s) for m in mods) and all(b.valid(s) for b in bonds)
    if valid: return s, None
    F = graph.reachable_safe(s, horizon=T)               # 有限抽象图（<=64 节点）
    if not F: return s, 'DEADLOCK'                       # 可审计安全失效
    pi = graph.release_order(s)                          # 释放序：先松/先后退
    assert all(graph.safe_through(s, a, pi) for a in F)   # 引理 42
    if any(m.is_support for m in mods if not m.valid(s)):
        return support_transfer(s, pi)                   # 冻结-保持 → 另一臂接管 → 释放
    return graph.best_retreat(s, F, pi), None

# IP-308/309 EARA + CMB：联合角色分配与内部竞争性竞标
def eara_allocate(mods, bids, state, budget):
    ranked = sorted(bids.items(), key=lambda kv: (kv[1].dprog - kv[1].du) / (kv[1].cost + 1e-9),
                    reverse=True)                        # 单调分配规则
    alloc, spent = {}, 0.0
    for i, b in ranked:
        if spent + b.cost <= budget.B:
            alloc[i] = b; spent += b.cost
    audit.record(bids, realized=None)                    # 事后审计：高报 → 重加权/降级（不假设真实申报）
    return alloc, spent

# IP-310 CAP / CCR：能力匹配竞品 + 跨契约重放
def capability_matched_competitor(claim, baselines, ours_kappa, delta, mechanism):
    cands = [b for b in baselines
             if all(b.kappa[k] >= ours_kappa[k] - delta for k in ours_kappa) and mechanism not in b.mechanisms]
    b_star = max(cands, key=lambda b: capability_score(b)) if cands else None
    if b_star is None: return None                       # 不可识别 → 主张降级为附录
    return b_star                                        # 配对改进 + 判别性签名 + 负控制（关 M）

def cross_contract_replay(competitor, cca2):
    try:
        composed = cca2.compose_from_report(competitor.module_uncertainties, competitor.assumptions)
    except ContractViolation:
        return 'INCOMPOSABLE'                            # 无证书却优于单调界 / 覆盖率不可保持 / 隐 bond
    return 'COMPOSABLE'                                  # 可比重放，进入主比较表

# IP-311 COGAUGE 主闭环（双臂；复用 R73 三域，全部经契约）
def COGAUGE_round(M, obs, audio, tac_L, tac_R, depth_L, depth_R):
    # === 感知域（异步 100Hz）===
    dL = M.dpeL.update(depth_L, M.camL, M.motion, M.peers); dR = M.dpeR.update(depth_R, M.camR, M.motion, M.peers)
    C, occ = chi_matrix(M.mods, M.last_g, M.state)       # 交叉通道 + 互遮挡
    dR = M.dpeR.apply_occlusion(dR, occ[('L','R')]); dL = M.dpeL.apply_occlusion(dL, occ[('R','L')])
    lc = M.lcem.update(M.T_bL, M.T_Lo, M.T_bR, M.T_Ro, M.enc, M.thermal, M.slip_post)   # 闭链
    iw = M.iwem.update(M.fL, M.fR, M.G_L, M.G_R, M.grasp_post, M.ext_model)            # 内力
    # === 计量域（50Hz）===
    if M.clock.due_metric():
        if not M.bonds.check() or M.bonds.discover(M.resid_cov, M.blockdiag_pred) == 'UNDECLARED_BOND':
            M.bonds.degrade_conservative()               # 强制 PAR 保守 + 触发标定
        b_t = M.bse.step_full(..., d_ev=merge(dL, dR), lc=lc, iw=iw)
        M.pvop2 = M.eara.plan(b_t, M.mods, M.risk_params)          # 联合视角/角色
        g = M.ervoi2.choose(b_t, M.budget, M.mods)                  # R73 ERVOI†
        if g:
            alloc, spent = eara_allocate(M.mods, M.cmb.bids(M.state), M.state, M.budget)
            ok, cost = sigmareflex2_step(M.mods, g, M.state, M.budget)
            joint, deadlock = coordinated_veto(M.state, M.mods, M.bonds, M.fallback_graph)  # CVL
            if ok and deadlock is None: M.last_g, M.state = g, joint
        M.snapshot.write(b_t, dL, dR, lc, iw, M.state)
    # === 控制域（1kHz，只读快照）===
    snap = M.snapshot.read_latest()
    lam = coupled_risk_scale(snap, max(snap.dL.u, snap.dR.u), snap.lc.u, snap.iw.u, M.risk_params)
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop2); k = M.c_ras_wm.certified_prefix(A, lam)
    return k, lam, J_COUP(M.mreg, M.bonds, M.fallback_graph)     # 定义 393

## 4. 推导（引理 38–43，定理 30–33）

**引理 38（闭链不可自证）** 估计残差与验证残差同源 ⇒ conformal 覆盖率无保证。系：闭链缩窄必须来自不相交通道。
**引理 39（内力不可识别）** `∂h/∂β = 0`；存在 β≠0 而物体净力为零。系：必须有专用 u_int 维度。
**引理 40（耦合地板保守）** 共享隐变量方差占比 γ ⇒ `ρ ≥ ρ_floor(γ)`；用 ρ_b ≥ ρ_floor ⇒ u_out² 不小于真实联合方差。系：声明下界替代 ρ̂ 估计，缩窄只能由条件化证书收回。
**引理 41（交叉通道与矩阵预算）** χ_{i→j} Lipschitz + 矩阵预算 ⇒ 联合序列有限停止；但「各自独立停」不再成立。
**引理 42（活性充分条件）** 非补偿否决 + 回退图无「全出边否决」的可达态 + 释放序 π ⇒ 必在 ≤T 内有序撤退且不经过 ObjRisk。
**引理 43（耦合热替换边界）** 替换改变关联 bond 契约项 ⇒ R73 引理 35 失效；保持所有关联 bond ⇒ 逐指令性质保持。系：热替换单元变为「模块 + 超边邻域」。

**定理 30（解耦极限严格包含）** 所有 bond 平凡、CVL 空 ⇒ 逐指令退化为 MODGAUGE → R72 → R71 → R68；安全单调不减。**不覆盖**承载耦合的模块。
**定理 31（J_COUP ⇒ 耦合安全）** 在 A-coup（契约表达力、ρ_floor 真实下界、零空间模型覆盖、χ̂ 完备 Lipschitz、条件化证书有效）下，Valid(J_COUP) ⇒ 联合风险 ≤ ε_coup。证明重量落在 **bond 建模假设在分布外仍成立**。
**定理 32（活性保持的降级）** J_live 有效 ⇒ stub（含冻结-保持）/bond 否决均导致有序撤退而非死锁或物体风险；语义从「少一个模态」变为「少一个模态 + 一次有序交接」。
**定理 33（耦合感知热替换）** 同 EC 且关联 bond 逐项相同 ⇒ 性质保持；仅 bond 数值标定变化 ⇒ 只重认证 J(b)+J_live，成本 O(度数)。

## 6. 本轮最大风险

**一句话**：COGAUGE 把证明负担从「模块契约的表达力」再推深一层到「**bond 契约的表达力**」——ρ_floor、u_bond、β_max、零空间维数与 χ̂ 非对角项都是部署期不可直接观测的建模声明；一旦真实耦合越出这些声明（共因相关低于地板、内力落在建模零空间之外、遮挡通道在极端位姿失效），「所有 bond 证书有效、所有组合校验通过、活性证书有效」的系统仍会给出**错误的安全界**，而审计日志证明「每一步都合规」——且竞品重放可能把这种错误包装成「在错误坐标轴上正确」。

次级风险与缓解：
1. **Bond 假设不可验证** → SEAL-BOND 保守表 + 在线残差膨胀审计 + 地板只上浮；收窄须条件化证书。
2. **过度保守不可用** → 条件化证书（联合估计/差分测量）+ 自由模式降级 + bond 版本化。
3. **CVL 状态爆炸** → 64 节点有限抽象 + 单调回退偏序 + 仅可达否决态增量验证。
4. **零空间/抓取模型失配** → 抓取模式后验 + 未知接触征用安全上界 + 越界即 bond 否决。
5. **竞品稻草人** → 预注册清单 + 第三方选 b* + 判别性签名 + 负控制 + 报告负结果；不可识别降级附录。
6. **跨契约重放误伤** → 只标「不可组合」不判优劣；协议公开；双盲公平性校验。
7. **内部竞标谎报** → 事后审计 + 重加权 + 工程降级；不声称机制设计意义下的真实申报。
8. **支撑转移瞬态** → 转移期 B_int 收紧、接触模式不变、轨迹预认证；不可认证则冻结求援。
