# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「实例分割」×「用户体验」）

> 第 57 轮把证据承诺推进到"少样本可校准、跨模态可对账、个性化有界"，但其自陈风险暴露了两个更深的结构性问题：**(a)** 整轮仍以"区域 r"为信念原子——b_r 把一个区域内可能并存的冰面与干岩平均成单一后验；有限点探针无法排除足迹下未被采样的坏斑块，于是"证据承诺"的健全性其实悬置在一个未声明、未审计的空间正则假设上；**(b)** 整轮的交互设计只关心"人是否可信"，不关心"人是否还在"——当安全协商因过度保守而频繁打断、解释不可理解时，真实世界的最大风险不是系统算错，而是人类把安全协商整个关掉。本轮两个灵感各补一条结构性腿：**实例分割**把信念原子从"区域"下沉为"物理参数均质的实例"，并显式把边界、分割不确定性与证据局部性纳入证书——让"点探针为何足够"这一隐含假设第一次可声明、可证伪；**用户体验**把"人继续参与"从背景假设变成可维护的安全前提，用注意力预算、可读性与信任校准不变量约束协商，但严禁 UX 以任何方式放宽安全界。核心命题由"证据说可信"升级为 **"世界可细分、边界可设防、协商可理解、信任可校准的证据说可信"**。

核心矛盾：
- **H29（区域混合 vs 可识别性）**：区域级 b_r 把多种物理实例混为一谈；k≤5 点探针既可能全落在好实例上，也可能漏掉足迹下的坏斑块——这不是"校准差"，而是**参数不可识别**。细分能解混，但分割本身带先验、会出错（过分割碎片化证据、欠分割掩盖新奇），安全赌注从"元先验质量"又挪到"分割先验质量"。
- **H30（边界 vs 承诺）**：风险集中在实例边界（混合材质、边缘效应），而边界恰是观测最稀、模型最不可靠之处；区域级裕度会把边界风险平均掉，且一次点探针的证据会越过弱边界"泄漏"给相邻实例。
- **H31（UX vs 安全）**：安全协商消耗注意力、打断任务、磨损信任；过度保守的系统会被人类关机或绕过——**健全性定理默认"人还在参与"，而坏 UX 直接摧毁这个前提**。但若允许 UX 为了顺滑而减少警告，又会喂养过度信任与橡皮章化。

## 0. 直觉与动机

**灵感 1（实例分割 → 信念原子下沉：物理参数实例）**
直觉：机器人脚下的地面不是"一个区域"，而是一张由不同物理材质拼成的马赛克——冰斑、碎石、湿草各自成"块"。把整张马赛克压成一个 b_r，等于把冰的 μ=0.2 和岩的 μ=0.8 平均出一个"看起来还行"的 μ≈0.5，然后用三次探针给这个平均值发证书。实例分割的启示不是"识别物体"，而是**把"哪里是同一种物理性质、边界在哪"变成一等公民**：安全真正需要的是足迹范围内的 μ_min，而有限点探针只有在"同一实例内参数平滑、探针覆盖其支撑"的假设下才能给出下界。因此本轮把 **traversability instance** 定义为参数均质块，并把分割假设写进证书——**点探针的健全性不再悬空，而是被显式声明并可被证伪**。

**灵感 2（实例分割 → 边界带与证据局部性）**
直觉：马赛克的接缝最危险——那里一半是冰一半是岩，平均摩擦最好看、局部却最坏。区域级裕度会把边界风险平均掉。本轮把**边界带 B_Γ 设为一等不确定性源**：承诺裕度按"足迹×边界带"的最坏实例计算；探针预算优先投向边界（那里 VOI 最高）；**证据不跨越弱边界转移**——在岩石上打的一次点探针，不能给一墙之隔的冰面背书，除非边界置信度足够高、两者在可信分割集中确属同一实例。

**灵感 3（实例分割 → 解混与可识别性闸门）**
直觉：当观测分不清"一个中等表面"还是"两块表面拼成足迹"时，正确反应不是给一个更宽的分布，而是**承认参数不可识别**，然后要么打一发"判别性边界探针"（专打疑似接缝，最大化两种分割假设的分离度），要么弃权。这把"主动探询"从"降低方差"升级为"恢复可识别性"——探针的价值第一次包含"让问题变得可回答"。

**灵感 4（用户体验 → 参与是安全前提，不是装饰）**
直觉：第 57 轮把健全性写成 P_safe(每次承诺)，但真实部署的风险还包括"人类因为烦、因为看不懂、因为不信任而把安全协商关掉或长期绕过"。**健全性其实是条件命题：只在人类持续参与时成立。** 于是 UX 不是审美问题而是**前提维护问题**：注意力预算 A(t)、打断成本、解释理解时延、可读性（人能否预测机器人何时会问、何时会停）。设计原则是"约束优先"——UX 只在**已经安全的动作集内**做选择（早探针 vs 晚停、合并解释 vs 分次），当唯一安全动作是不讨喜的（必须停）时，安全压倒 UX；系统公布可预测的干预策略，让人的心智模型与真实可靠性对齐。

**灵感 5（UX → 信任校准不变量，给第 57 轮授权装刹车）**
直觉：第 57 轮的授权养成攻击本质是"先攒信任再滥用"。UX 视角给出上游根因：**过度顺滑的交互会制造过度信任**（警告越来越少、解释越来越短，人退化成橡皮章）。本轮把"感知可靠性 R_perc 不得超过实际可靠性 R_act 太多"设为**硬不变量**：即便标注准确率很高，只要检出过度信任（低敏感性、橡皮章响应），就不许升级授权；并保留**合法摩擦**——周期性暴露真实不确定性、安全校准探针——因为"一直很顺"本身就是风险。信任可以赢得慢、失去快，且**不能靠让人忘记风险来赢得**。

**灵感 6（合流 → 证书从 J_p 到 J_u，健全性从条件承诺到条件参与）**
直觉：实例分割把"世界信念"从区域级升级到实例级并显式登记边界/分割不确定性；UX 把"人还在"从假设升级为受维护的约束。二者共同把证书扩为 J_u：分割证书（实例图/边界置信/分割歧义）+ 证据局部性日志 + 可识别性日志 + UX 遥测（打断/理解/TCE/覆盖）+ 可读性声明 + 安全地板存证。部署界第一次同时乘上"每次承诺健全"与"参与被维持"两个因子。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（物理参数实例分割 PIS）** 对区域 r 的足迹场 F_r，分割 π={I_i}，I_i=(M_i,∂I_i,b_i,θ_i)，满足实例内均质假设 H_hom：∀x,x'∈M_i，‖θ(x)−θ(x')‖≤ε_hom；边界集 Γ=∪∂I_i。可行分割不止一个：维护分割粒子集 Π_r 及后验 w(π|o)，取 α_seg 可信集 Π_r^α，承诺只对**可信集内的最坏分割**计算。边界置信图 C_Γ(x)∈[0,1] 与合并/拆分置信度是分割的显式不确定输出；单实例内仍用第 57 轮 b_i 与 MFSL 摊销先验（实例簇作为元上下文 z_r 的新维度）。

**定义 140（边界带与证据局部性 BBA）** 边界带 B_Γ^δ={x:dist(x,Γ)≤δ(C_Γ)}，δ(·) 随边界置信下降而增宽。承诺裕度改为 K_cross=min over 相邻实例对 (I_i,I_j) 跨越接触足迹的 K(I_i,I_j)；足迹与 B_Γ^δ 相交且 C_Γ<c_irr ⇒ 禁不可逆接触。证据局部性：EV-probe(I_i) 可提升 I_j 的置信当且仅当 C_Γ(∂I_i∩∂I_j)≥c_0 且二者在可信分割集中同属一个实例；否则证据不可转移（记为一次"证据泄漏"违规）。探针排序的 VOI 额外含边界项（见定义 144）。

**定义 141（解混与可识别性闸门 BDM）** 对候选分割 (π_a,π_b)，观测分离度 sep(π_a,π_b|o)=min_{θ_a,θ_b} TV(p(·|θ_a,π_a), p(·|θ_b,π_b))。若 sep≤θ_sep，则判**不可识别**并禁止承诺；此时允许一次判别性边界探针 p_Γ=argmax_p E[sep after p]−cost(p)，其目标是恢复可识别性而非仅降方差。不可识别是第三种终态（承诺/绕行之外），必须在证书中显式登记。

**定义 142（UX 感知协商 UXN）** UX 状态 u=(A,c_int,ℓ_c,τ_c)，A∈[0,A_max] 注意力预算（干预消耗、休息恢复），c_int 打断成本，ℓ_c 理解时延，τ_c 为可读性缺口。干预事件消耗注意力：A_{t+1}=A_t−Σc_int(e)。协商是**约束优先**的两层优化：可行集 𝔸_safe={a:P_fail(a)≤δ_f}；在 𝔸_safe 内最大化"任务效用−λ_ux·UXcost(a)"；若 𝔸_safe 中存在低 UX 成本安全动作则选之，否则安全动作（含停）优先，记为"安全地板"。可读性：系统公布策略 σ_legib（何时探/何时停/为何），人预测动作与真实动作的一致率即 ℓ_c；低 ℓ_c ⇒ 强制补充解释或转为更可预测的保守策略，绝不因"解释嫌烦"而放宽安全。

**定义 143（信任校准不变量 TCI）** 实际可靠性 R_act（事后统计）与感知可靠性 R_perc（由行为反推：条件于警告的覆盖率、响应时延、橡皮章率、信号检测 d′/criterion）。不变量：R_perc−R_act≤ε_over（禁过度信任）且 R_act−R_perc≤ε_under（禁无谓不信）。授权升级（第 57 轮 auth）额外要求 TCI 成立：cal 高但 R_perc−R_act>ε_over 则拒绝升级。保留**校准摩擦**：每 T_cal 允许一次低风险、正确且有益的安全校准探针或真实不确定性暴露，使 R_perc 不因"长期零告警"而漂移；校准摩擦预算与注意力预算联合调度。

**定义 144（细分-体验证书 J_u / LEC）** J_u=J_p ∪ (π̂,C_Γ,Amb,instance_probe_log,boundary_log,id_log, UX=(interruptions,A,ℓ_c,TCE,override), σ_legib 存证, safety_floor_log)。证据门在 FSE 上增量：EV-probe* 须绑定实例 id 且通过证据局部性；EV-margin 取 K_cross；不可识别未决 ⇒ 一律拒。部署界把"每次承诺健全"与"参与维持"相乘（见 §3）。

## 2. 关键算法伪代码（完整版见产物区）

```python
def segment_and_infer(M, r, obs, meta):
    field = predict_param_field(r, M)                 # θ̂(x) 与不确定性
    Pi = sample_partitions(field, obs, n=n_seg)       # 分割粒子集
    Pi_a = credible_set(Pi, alpha=alpha_seg)          # α_seg 可信集
    for pi in Pi_a:
        for I in pi.instances:
            I.b = meta_few_shot_infer(M, I, obs_in(I), meta)   # 复用 IP-133
    C_G = boundary_confidence(Pi_a)                   # 边界置信图
    Amb = identifiability(Pi_a, obs)                  # IP-141
    return M, Pi_a, C_G, Amb

def boundary_aware_gate(c, M, Pi_a, C_G, persona, ux):
    K = min(K_cross(I_i, I_j, c.footprint) for I_i, I_j in adjacent(Pi_a))
    if c.irreversible and intersects(c.footprint, band(C_G)) and min_conf(C_G) < c_irr:
        return ('reject', 'unresolved_boundary')
    if Amb.unidentifiable and not c.discriminative_probe_done:
        return ('reject', 'unidentifiable')
    if c.ev == 'EV-probe*' and not evidence_local(c, Pi_a, C_G):
        return ('reject', 'evidence_leak')            # IP-140
    return round57_fse(c, M, persona, K)              # 继承 FSE

def ux_negotiate(cp, safe_actions, ux):
    feasible = [a for a in safe_actions if P_fail(a) <= delta_f]
    if not feasible:
        return safe_stop(cp)                          # 安全地板
    best = argmax(feasible, key=lambda a: task_util(a) - lam_ux * ux_cost(a))
    if legibility_gap(best, ux) > theta_leg:
        best = most_legible(feasible)                 # 只换安全动作，不放宽
    ux.attention -= ux_cost(best)                     # 注意力预算
    return best

def tci_update(s, ev, audit):
    s.R_perc = infer_perceived(s.behavior_window)     # 覆盖/时延/橡皮章
    s.TCE = s.R_perc - s.R_act
    if s.auth_pending_promote and s.TCE > eps_over:
        s.auth = deny_promote(s.auth)                 # 过度信任不升级
    if calibration_due(s) and safe_to_probe():
        schedule_calibration_probe(s)                 # 合法摩擦
    return s
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| PIS | O(n_seg·(\|F_r\|+\|I\|·d_φ)) | O(\|Π_r\|·\|I\|) | H_hom 声明诚实、α_seg 覆盖 |
| BBA | O(\|I\|²·\|∂\|) | O(\|Γ\|) | 边界置信校准、证据局部性完备 |
| BDM | O(\|Π_r\|²·d_o) | O(\|Π_r\|²) | sep 保守、不可识别不承诺 |
| UXN | O(\|𝔸_safe\|·C_ux) | O(A_max) | 安全地板、UX 不放宽安全 |
| TCI | O(1)+O(W_beh) | O(\|操作者\|) | 过度信任禁升级、校准摩擦有界 |
| J_u | O(\|σ\|·\|Π_r\|) | O(\|σ\|) | 分割/边界/UX 全登记 |

**正确性定理（Segmented UX-Calibrated Soundness, SUCS 概要）**：在 A33–A40 基础上加 (A41) 实例均质假设 H_hom 成立或其违反被 α_seg 可信集与边界带覆盖；(A42) 证据局部性与边界置信校准（边界置信 ECE≤ε_b，泄漏率≤δ_leak）；(A43) 可识别性闸门完备（不可识别必弃权或判别探针，漏判≤δ_id）；(A44) UX 约束优先且注意力预算不破坏安全地板，可读性与校准摩擦有界；(A45) 参与维持：干预过载与过度信任导致的关机/绕过风险 ≤δ_eng。则：
(i) **细分承诺健全性**：每次承诺 P(fail) ≤ δ_f+ε_meta+δ_probe+ε_h+ε_b+δ_id+1[边界带]·δ_leak；
(ii) **参与条件健全性**：P_safe(部署)=P_safe(单次承诺)·P(参与维持) ≥ [1−Σ_cp(…)][1−δ_eng]，UX 只作用于第二个因子且只经"更可读/更省注意力/更准校准"；
(iii) **交互与 UX 单调性**：无论实例分割、解混、UX、TCI 如何调整，均不存在放宽 δ_f/K_cross/不可逆禁令的路径；UX 只能在 𝔸_safe 内选，TCI 只能拒绝升级；
(iv) **终止性**：PCE+ 在 k_probes+k_cons+k_disc 内终止于 {承诺, 绕行, L2, 安全停, 不可识别弃权}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 过分割 → 证据碎片化（每实例样本更少，校准更差） | 高 | 实例簇摊销先验 + 合并置信 + 最小实例样本门 + 可退回区域级共形带 |
| 欠分割 → 坏斑块被平均掉（旧病复发） | 高 | 可信集最坏分割 + 边界带 + 未识别斑块对抗测试 |
| 处处边界 → 保守爆炸 → 系统不可用 | 高 | 保守度上界 + 区域级带兜底 + UX 只换安全动作而非放宽安全 |
| 安全校准摩擦被嫌烦而被关闭 | 中 | 摩擦预算 + 可读性 + 注意力调度，宁可少而准 |
| TCE 估计被行为噪声误导 | 中 | 多信号融合 + 保守阈值 + 审计回放 |

## 6. 本轮最大风险

**一句话**：本轮把世界细分到实例、把协商优化到 UX，最大的风险不是算错，而是**"细到处处是边界、顺到人忘了风险"**——过分割与边界保守会把系统推向"处处停车"，坏 UX 又可能诱发人类绕过安全协商，而 TCI 的"合法摩擦"若调度失当同样会加速关机；必须以保守度上界、区域级共形兜底、UX 只能在安全集内选择、校准摩擦有界且可读四条护栏，把"细分与顺滑"都锁在安全地板之上。

## 2. 关键算法伪代码

### IP-139 PIS（物理参数实例分割）

```python
def segment_and_infer(M, r, obs, meta):
    field = predict_param_field(r, M)                 # 逐点 θ̂(x) 与不确定度
    Pi = sample_partitions(field, obs, n=n_seg)       # 分割粒子（区域生长/多阈值）
    Pi_a = credible_set(Pi, alpha=alpha_seg)          # 只保留 α_seg 可信集
    for pi in Pi_a:
        for I in pi.instances:
            I.b = meta_few_shot_infer(M, I, obs_in(I), meta)   # 复用 IP-133
            I.z_meta = (cluster_of(I), slope(r), season(r))    # 实例簇进元上下文
    C_G = boundary_confidence(Pi_a)                   # P(边界|x) → ECE 校准
    Amb = identifiability(Pi_a, obs)                  # 转 IP-141
    M.ver.bump(r)
    return M, Pi_a, C_G, Amb

def worst_over_credible(Pi_a, footprint):
    return max(P_fail(I.b, footprint & I.M) for pi in Pi_a for I in pi.instances)
```

### IP-140 BBA（边界带与证据局部性）

```python
def boundary_band(C_G, conf):
    delta = delta0 * (1.0 - conf) + delta_min          # 置信越低，带越宽
    return dilate(boundaries(C_G), delta)

def K_cross(Pi_a, footprint):
    K = +inf
    for pi in Pi_a:
        for Ii, Ij in adjacent_instances(pi, footprint):
            K = min(K, K_margin_of(Ii, footprint), K_margin_of(Ij, footprint))
    return K

def evidence_local(e, Pi_a, C_G):
    if e.inst is None:
        return False                                  # 证据必须绑定实例
    for pi in Pi_a:
        if same_instance(pi, e.inst, e.other_inst):
            return boundary_conf(C_G, e.inst, e.other_inst) >= c_0
    return False                                      # 跨可信分割都不同实例 → 不可转移

def irreversible_ok(c, C_G):
    return not intersects(c.footprint, boundary_band(C_G, min_conf(C_G))) \
           or min_conf(C_G) >= c_irr
```

### IP-141 BDM（解混与可识别性闸门）

```python
def identifiability(Pi_a, obs):
    pairs = [(a, b) for a, b in combinations(Pi_a, 2)]
    amb = [p for p in pairs if separation(p, obs) <= theta_sep]
    return Amb(unidentifiable=bool(amb), pairs=amb)

def separation(pair, obs):
    return min(TV(predict(obs, a.theta), predict(obs, b.theta))
               for a, b in [pair])

def discriminative_boundary_probe(M, r, Amb, F_abs):
    if not Amb.unidentifiable:
        return None
    return argmax(admissible_probes(r, M, F_abs),
                  key=lambda p: E_sep_after(p, Amb) - cost(p))   # 目标：可识别
```

### IP-142 UXN（UX 感知协商，约束优先）

```python
def ux_negotiate(cp, safe_actions, ux):
    feasible = [a for a in safe_actions if P_fail(a) <= delta_f]
    if not feasible:
        return safe_stop(cp)                          # 安全地板，不受 UX 协商
    best = argmax(feasible, key=lambda a: task_util(a) - lam_ux * ux_cost(a))
    if legibility_gap(best, ux) > theta_leg:          # 低可读 → 换更可预测的安全动作
        best = most_legible(feasible)
    ux.attention = max(0.0, ux.attention - ux_cost(best))
    if ux.attention < A_min and needs_L2(cp):
        return preempt_probe_early(cp, feasible)      # 提前把 L2 风险探掉
    return best

def ux_cost(a):
    return c_int * interrupts(a) + explanation_load(a) + latency_penalty(a)
```

### IP-143 TCI（信任校准不变量）

```python
def tci_update(s, ev, audit):
    s.R_act = empirical_reliability(s.history)        # 事后统计
    s.R_perc = infer_perceived(s.behavior_window)     # 覆盖/时延/橡皮章/d'
    s.TCE = s.R_perc - s.R_act
    if s.auth_pending_promote and s.TCE > eps_over:
```

```python
def legible_evidence_certificate(sched, log, M, Pi_a, C_G, Amb,
                                 consent_log, auth_log, ood_reg, ux):
    for c in contacts(sched):
        st = boundary_aware_gate(c, M, Pi_a, C_G, persona_of(c), ux)
        if st[0] != 'ok': return st
    if Amb.unidentifiable and not all(a.resolved for a in Amb.pairs):
```

### IP-138→PCE++（细分-解混-体验版探-诺-演）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, ux):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        M, Pi_a, C_G, Amb = segment_and_infer(M, cp.region, M.obs[cp.region], meta)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while (select_gait(R) == 'halt' or Amb.unidentifiable) and budget.probes_left > 0:
            if Amb.unidentifiable:                     # 先恢复可识别性
                p = discriminative_boundary_probe(M, cp.region, Amb, F_abs)
            else:                                       # 边界优先的悲观元 VOI
                p = argmax(admissible_probes(cp, M, F_abs),
                           key=lambda q: voi_meta_pessym(q, M) + border_bonus(q, C_G)
                                         - cost(q))
            if p is None or voi(p) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            if D > theta_D and 'consensus' not in cp.done:
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(
                    most_disagreeing_modality_probe(M, cp.region), cap=F_abs))
                cp.done.add('consensus')
            M, Pi_a, C_G, Amb = segment_and_infer(M, cp.region, M.obs[cp.region], meta)
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R)
        feasible = safe_actions(cp, sigma, M, Pi_a, C_G)      # 过边界/解混/证据门
        act = ux_negotiate(cp, feasible, ux)                 # 只在安全集内选
        if isinstance(act, Commit):
            sched.append(act); log.append(tag_evidence(sigma, M, level(cp))); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PIS | O(n_seg·(\|F_r\|+\|I\|·d_φ)) | O(\|Π_r\|·\|I\|) | H_hom 声明诚实、α_seg 覆盖（A41） |
| BBA | O(\|I\|²·\|∂\|) | O(\|Γ\|) | 边界置信 ECE≤ε_b、证据局部性完备（A42） |
| BDM | O(\|Π_r\|²·d_o) | O(\|Π_r\|²) | sep 保守、不可识别不承诺（A43） |
| UXN | O(\|𝔸_safe\|·C_ux) | O(A_max) | 安全地板、UX 不放宽安全（A44） |
| TCI | O(1)+O(W_beh) | O(\|操作者\|) | 过度信任禁升级、校准摩擦有界（A44） |
| LEC | O(\|σ\|·\|Π_r\|) | O(\|σ\|) | 分割/边界/UX 全登记 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_d)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 边界优先 VOI、五态终止 |

**正确性定理（Segmented UX-Calibrated Soundness, SUCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 实例均质假设 H_hom 成立，或其违反被 α_seg 可信集与边界带覆盖（分割失败概率 ≤δ_seg）；**(A42)** 边界置信校准诚实（ECE≤ε_b）且证据局部性完备（泄漏率 ≤δ_leak）；**(A43)** 可识别性闸门完备：不可识别必弃权或先发判别探针，漏判 ≤δ_id；**(A44)** UX 约束优先：UX 只在 𝔸_safe 内选择、注意力预算不破坏安全地板、可读性与校准摩擦有界（每 T_cal ≤1 次、且有真实不确定性支撑）；**(A45)** 参与维持：干预过载与过度信任导致的关机/绕过风险 ≤δ_eng。则：

1. **细分承诺健全性**：每次承诺
   `P(fail) ≤ δ_f + ε_meta + δ_probe + ε_h + ε_b + δ_id + 1[足迹∩边界带]·δ_leak + δ_seg`；
   区域级证据不再能"跨实例"为相邻坏斑块背书。
2. **参与条件健全性**：`P_safe(部署) = P_safe(单次承诺)·P(参与维持) ≥ [1−Σ_cp(…)]·[1−δ_eng]`；UX/TCI 只作用于第二个因子，且只经"更可读、更省注意力、更准校准"三条通道，不进入安全项。
3. **交互与 UX 单调性**：实例细分、解混、UX 协商、信任校准的所有更新，都不存在放宽 `δ_f / K_cross / 不可逆禁令 / 证据局部性` 的路径；UX 只能在安全动作集内改选，TCI 只能拒绝升级。
4. **终止性**：PCE++ 在 k_p+k_c+k_d 内终止于 {承诺, 绕行, L2 协商, 安全停, 不可识别弃权}。

**部署界**（对检查点取联合界，并乘参与维持因子）：

```
P_safe ≥ [ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + ε_b + δ_id + δ_seg·1[细分] + δ_leak·1[边界带])
             − P(分割可信集失效) − P(护盾回退失败)
             − P(注意力耗尽 ∧ L2 超时 ∧ 安全停失效) ] · [ 1 − δ_eng ]
```

关键：**H_hom 把"有限点探针足以承诺"从隐含假设变成可声明、可证伪的证书前提**；**边界带把风险集中处显式设防，证据局部性堵住"跨实例泄漏"这条新的坏证据通道**；**解混把"更宽的分布"升级为"诚实的不可识别/弃权"**；**UX 进入健全性不是因为好看，而是因为"人还在"是安全定理的前件**；**TCI 用合法摩擦守住信任校准，防止顺滑交互反噬为橡皮章**。

## 6. 本轮最大风险

**一句话**：本轮把世界细分到实例、把协商优化到 UX，最大的风险不是算错，而是**"细到处处是边界、顺到人忘了风险"**——过分割与边界保守会把系统推向"处处停车"，坏 UX 又可能诱发人类绕过安全协商，而 TCI 的"合法摩擦"若调度失当同样会加速关机；必须以保守度上界、区域级共形兜底、UX 只能在安全集内选择、校准摩擦有界且可读四条护栏，把"细分与顺滑"都锁在安全地板之上。
