# 第 1 轮（灵感驱动研究循环·新灵感二元组第 1 轮；本轮灵感：「最优控制」×「视觉感知」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21+IP-425–430（其上是 v20 联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl、v19 证书体系 DCM/OGCC/CCV/DRS/OGC、v17 感知链 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**最优控制把"安全证书"从快照布尔过滤升级为闭环不变集与认证值函数；视觉感知把"感知"从外生给定升级为可被控制的信息获取过程**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 全部保留。本轮只做一件事：**把 v21 的语义-合规证书编译进一个"感知在环的认证最优控制"——证书变约束（CBF/viability），感知变决策变量（主动覆盖），值函数变可审计对象（VCert），并顺手把 v21 最大风险（缺席幻觉）从"假设召回"换成"实测视况 + 可认证模型界"**。

## 0. 直觉与动机

**灵感 1（最优控制 → 安全不是一个判决，而是一条闭环不变的水平集）**
直觉：v21 的 HPC+ 是"快照法官"——在某一时刻把候选计划判成准入/不准入，判完就不再负责。可真实执行中扰动会持续把状态往安全边界推，一次采样点的准入根本无法阻止区间内的越界；这正是"过滤式安全"的先天缺陷：过滤器只在被查询的离散时刻成立。最优控制给出的直觉完全相反——**安全应当是值函数上的一个水平集**。Bellman 原理说"最优代价满足 V(x)=min_u[ℓ+∇V·f]"，而"安全"就是"存在策略使到碰撞的代价恒 ≥ 阈值"，即 viability / 前向不变性。把证书给出的几何裕度 h(x) 当作控制屏障函数（CBF），"准入集合"立刻变成"闭环不变集"；并且在最小侵入意义下恢复活性：不是把所有不安全计划统统删掉，而是**在安全集边界上取最接近你原计划的安全控制**。副产品：v21 因保守过滤而损失的活性（风险 4）有了正式的补救框架。
严谨定义：考虑 ẋ=f(x,u,w)、x∈X、u∈U、扰动/未建模动态 w∈W，阶段代价 ℓ(x,u)。证书给出有符号距离 `h_t(x)=dist(x,Obs_t)−r_safe−r_lat·‖v‖`，其中 `Obs_t` 取 v21 P34 的**单调增障碍集**、`r_lat` 为感知-反应延迟外推裕度。定义鲁棒控制屏障约束
`K_cbf(x) = { u∈U : inf_{w∈W} [ L_f h + L_g h·u + L_w h·w + α(h) ] ≥ 0 }`，α 为 K∞ 类函数。若 `h(x_0)≥0` 且对一切 t 有 `u(t)∈K_cbf(x(t))`，则由比较引理 `h(x_t) ≥ β(h(x_0),t) ≥ 0`，即安全集前向不变。**证书值屏障（CVB）**就是把 v21 的 HPC+ 裕度编译成 `(h, α, 认证 Lipschitz 常数 L_h)` 三元组，使"准入"从 pointwise 升级为 forward-invariant；取 `r_safe ≥ max(margin_col_fed, ρ_j)` 保证 `h≥0 ⇒ v21 几何准入`，安全继承不被编译破坏。

**灵感 2（视觉感知 → 召回不是一个常数，而是一个可被主动调优的视况函数）**
直觉：v21 最脆弱的地方，是把召回率 κ_c 当成一个全局常数（"这套检测器平均能检出 95% 的人"）。但凡有视觉常识就知道：**能不能看清，取决于视况**——离得近不近、像素够不够、逆不逆光、遮没遮住、动不动糊不糊。于是 κ 不该是一个数，而应是**可测函数 κ(x,v)**，其中 v 是机器人可主动选择的感知动作（视角/注视/变焦/驻留）。这一转念立刻改变两件事：其一，"覆盖"不再是地图上画死的扇形，而是"机器人把视况主动调到阈值以上"的**取证过程**（active perception / next-best-view）；其二，控制动作与感知质量发生**耦合**——开快车推进任务，却带来运动模糊与更短驻留、牺牲视况与安全裕度；停下来看清则安全但费时。这正是 Feldbaum 的**对偶控制(dual control)**：控制同时改变状态与信息态。视觉感知因此不只是"传感器"，而是最优控制里的另一组决策变量。
严谨定义：设视况特征 `φ(x,v) = (q_px, θ_inc, o_occ, illum, blur)`（每目标像素数、入射角、遮挡率、光照、运动模糊）。用可校准的 FNR 模型给出 `κ(x,v) = 1 − f_FNR(φ(x,v))`。定义视况条件化覆盖
`Cov^κ_t = { x : φ(x,v_t) 落在标定支撑内 ∧ κ(x,v_t) ≥ κ_min }`。
缺席证书只在 `Cov^κ_t` 上签发，以 `1−κ_min` 可靠；一旦视况 OOD（烟尘/强逆光/密集遮挡/标定外尺度）即令 κ:=0 并**拒发**（保守）。主动视角规划
`v_t = argmax_v Σ_c risk(c)·(κ(c,v) − κ_min)⁺ + β·I(presence; z | v)`，
第一项保证"把最危险区域的视况抬到达标线"，第二项是信息增益（对偶效应项）。于是 v21 那条不可验证的"平均召回"经验假设，被拆成**可测的视况校准 + 显式的 OOD 拒发**。

**三者如何统一**
统一为 **感知在环的认证最优控制 (Perception-in-the-loop Certified Optimal Control, PiC-OC)**：SDC/CAC/DCL/GIC 继续回答"有什么/凭什么/该不该/想要什么"，CVB 把它们编译成闭环约束，ACC 把"感知"升格为决策变量，VCert 把"代价到风险"变成可审计数值。共享状态扩展为 `ζ_ctl = ζ_sem ∪ (x, b, h_t, V̲, V̄, v_t, φ_t)`（b 为存在后验/信息态）。统一准入门升级为 **HPC++ = (HPC, CC, AbsCert, VCert) 四证一体**：几何安全 ∧ 规范允许 ∧ 负信息可靠 ∧ 代价可控。执行集
`Exec_v22 = { 闭环轨迹 τ : ∀t, HPC+(t) 成立 ∧ u(t)∈K_cbf(x(t)) }`。
关键守恒点：**在相同证据语义下 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`**——因为 CBF 要求在每一时刻连续成立（比快照准入更严），QP 不可行时回退到最小侵入刹车（仍在 v21 安全集内）。主动感知改变的是"能拿到什么证据"，而不是放宽约束：它只在**实测视况 ≥κ_min** 时签发证书，属于**证据替换**（用更强的可测证书替换弱的全局假设），不是约束松弛。

## 1. 研究问题（轮次升级版）

- **Q1（证书→CBF 的编译与保守性）**：如何把 v21 HPC+ 的几何裕度编译成鲁棒 CBF `h_t`，并给出**认证的 Lipschitz 常数 L_h 与 Lie 导数下界**？`Obs_t` 是框并/非凸 Hull，h 非光滑，如何用光滑过近似或 Dini 导数可靠地维持前向不变性？`r_safe ≥ max(margin_col_fed, ρ_j)` 与延迟外推 `r_lat‖v‖` 如何联合标定，使得 `h≥0 ⇒ v21 准入`（编译不引入乐观）？CBF-QP 的"最小侵入"在何种范数下可证最优？

- **Q2（视况条件化召回与主动覆盖）**：`κ(x,v)` 如何由 `φ(x,v)` 标定（像素数/入射角/遮挡/光照/模糊→FNR），其外推安全性条件是什么？`κ_min ≥ κ_c` 如何选，才能让 v22 的缺席证书至少和 v21 一样强？主动视角规划的"最小风险加权 κ 最大化"与信息增益如何加权，避免退化成"信息量大但看不清关键区"？多视角累积证据（e-process / 随时有效置信序列）在自适应采样下是否仍保持 `1−δ_abs` 覆盖？

- **Q3（对偶效应与值函数可认证性）**：控制-感知的对偶效应（u 影响未来 φ 与信念 b）使问题成为 POMDP/对偶控制，如何在实时性内可解——信念空间 MPC、信息态代理、还是对偶控制近似？`V̲ ≤ V ≤ V̄` 如何认证（区间值迭代/HJ 可达性/IBP 认证网络 + Lipschitz 界），值隙 `ε_V=V̄−V̲` 如何并进 MPC 终端代价以证明 horizon 足够？认证失败时如何优雅降级而不影响安全？

- **Q4（实时性、可行性与安全继承）**：鲁棒 CBF-QP 与主动视角规划如何分频——50Hz 控制路径只跑 CBF-QP + 缓存计划，10Hz 跑感知/覆盖/MPC？QP 不可行（多约束冲突）时的回退序列（软约束→最小刹车→SafeStop）与抖动/滞回如何设计？如何严格证明：相同证据语义下 `Exec_v22 ⊆ Exec_v21`，而主动感知只改变证据强度、不改变约束方向（引理 169）？

## 2. 设计原则（在 P34–P36 基础上新增 P37–P39）

**P37 证书即约束律（Certificates-as-Constraints）**
v21 的每一类证书都编译为闭环上连续成立的约束，而非快照布尔判决：障碍证书 → 屏障 `h_t≥0`（带认证 Lipschitz/Lie 界）；合规证书 → 输入/状态约束（F 收缩为 `u∈U_F`，O 期限过滤保留）；缺席证书 → 屏障安全半径的门控（未认证覆盖区令 `r_safe` 膨胀）。保证的是**前向不变性**而非 pointwise 准入；`r_safe≥margin_col_fed` 确保编译不引入乐观。QP 不可行时按"软约束→最小侵入刹车→SafeStop"逐级回退，全部留在 v21 安全集内。

**P38 感知即控制律（Perception-as-Control）**
感知质量是状态/决策变量，而非外生输入。`κ(x,v)` 是视况的可校准函数；控制器必须在风险加权区域维持 `κ(x,v_t)≥κ_min` 才可签发 AbsCert；信息增益进入目标函数；任何将降低覆盖的预测动作必须**与速度耦合**（看不清就减速/拒发），而非事后补救。覆盖保证只建立在**实测视况**上，OOD 视况一律 κ:=0、拒发；自适应采样策略不得改变证书语义（仅改变可获得的证据）。

**P39 可审计最优性律（Auditable Optimality）**
控制器不仅须安全，还须**在认证值隙内近最优**：VCert 给出 `V̲ ≤ V ≤ V̄`，执行计划次优性 `J−V* ≤ ε_V`，风险预算 `V̄` 可上报，模型/扰动集/标定版本经 merkle 锚定。在认证安全集内取最小代价（最不保守），而非一味加严——这是把 v21 保守性叠加导致的活性坍缩真正"赎回"的机制。

## 3. 与基线的接口（如何退化）

- CVB 失效/QP 不可行 ⇒ 回退 v21 的布尔过滤 + 最小侵入刹车 ⇒ 等价或更保守，`Exec_v22 ⊆ Exec_v21`；
- ACC 失效/标定 OOD ⇒ `κ:=0`、拒发 AbsCert、全域"可能有人"膨胀 ⇒ 比 v21 更保守；
- DE-MPC 超时 ⇒ 只执行 CBF-QP（安全滤波）⇒ 放弃近最优性，安全不变；
- EVB 失效（跟踪不可信）⇒ 取 `v_max` 最大速度外推 ⇒ 安全半径最大，保守；
- VCert 认证失败 ⇒ 放弃近最优性与风险预算，退回 v21 过滤 ⇒ 安全不变，仅失去最优性声明；
- 全失效 ⇒ 完全回退 v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19`（引理 169）。
- **安全继承**：编译只收不放（`r_safe≥margin`）、连续成立严于快照、失败向保守、最优性可丢弃而安全不可丢弃。50Hz 控制路径仅 CBF-QP + 缓存；10Hz 跑感知/覆盖/MPC；语义层仍 10Hz 事件化，接入 v17 APS 新鲜度阶梯与 TTL。

## 4. 预期贡献

1. **证书→约束的首次编译**：把感知/合规/缺席证书统一编译为鲁棒控制屏障与不变集，给出认证 Lipschitz/Lie 界，使安全从"快照准入"升级为"闭环前向不变"；
2. **视况条件化召回**：把不可验证的全局 κ_c 替换为可测 κ(x,v)，配合 OOD 拒发与主动取证，直接瓦解 v21 的"缺席幻觉"结构性来源；
3. **对偶效应认证 MPC**：显式建模"控制影响未来信息"的 Feldbaum 对偶效应（任务/信息/安全三方权衡），并在自适应采样下保持证书有效性；
4. **可审计近最优性**：认证值函数 VCert + 风险预算 + 次优性界，把"安全但畏手畏脚"变成"可证明地接近最优且可审计"；
5. **动态鲁棒屏障**：认知速度屏障（视觉跟踪/光流→速度不确定集）与延迟裕度，使动态行人场景获得最坏情形保证；
6. **四证一体 HPC++**：HPC ∧ CC ∧ AbsCert ∧ VCert，`Exec_v22 ⊆ Exec_v21` 在相同证据语义下闭环，主动感知仅作证据替换。

## 5. 本轮最大风险

**一句话**：把"缺席幻觉"换成了"模型幻觉"——CVB/VCert 的全部保证依赖动力学模型、扰动集与"视况→召回"标定这三条外生假设，一旦在分布外视况（逆光/烟尘/人群遮挡）或未建模动力学下外推，机器人会以**形式可证、审计通过、事实失效**的方式越过安全边界，形成"认证的模型幻觉"。

## 1. 关键算法骨架

```python
# IP-431 Certified Value Barrier：把 v21 HPC+ 几何裕度编译成鲁棒 CBF
class CertifiedValueBarrier:
    def __init__(self, dynamics, alpha, r_safe, lip_h, disturbance_set):
        self.f = dynamics                 # ẋ = f(x,u,w)
        self.alpha = alpha                # K∞ 类增益
        self.r_safe = r_safe              # ≥ max(margin_col_fed, ρ_j)：编译不引入乐观
        self.Lh = lip_h                   # h 的认证 Lipschitz 常数（证书几何导出）
        self.W = disturbance_set          # 扰动/未建模动态集合（采样或盒）

    def barrier(self, x, t, obs_t, v, latency):
        # Obs_t 取 v21 P34 单调增障碍集；延迟外推只增不减 → 保守
        obs_ahead = predict_forward(obs_t, latency + self.r_lat * norm(v) / v_max)
        rho = signed_distance(x, obs_ahead) - self.r_safe
        return rho                        # h_t(x) ≥ 0 ⇔ 认证安全（引理 163）

    def admissible_control_set(self, x, t, obs_t, v, latency):
        h = self.barrier(x, t, obs_t, v, latency)
        def K(u):
            # 鲁棒 CBF：对最坏扰动取 inf，用认证 L_h 界定 Lie 导数误差
            worst = min(lie_derivative_bound(self.f, h, x, u, w, self.Lh)
                        + self.alpha(h) for w in self.W)
            return worst >= 0
        return K                          # K_cbf(x)（引理 164）

    def qp_filter(self, x, u_nom, t, obs_t, v, latency):
        # 最小侵入安全滤波：不是删计划，而是取最近的安全控制
        K = self.admissible_control_set(x, t, obs_t, v, latency)
        try:
            return solve_qp(obj=lambda u: norm(u - u_nom) ** 2, cons=K)
        except Infeasible:
            return self.minimal_braking(x, t, obs_t)   # 仍在 v21 安全集内

    def minimal_braking(self, x, t, obs_t):
        # 回退：沿最保守减速方向，保证 h 不下降（滞回避免抖动）
        return decelerate_towards(self.safe_stop_set(obs_t), hysteresis=True)
```

    def __init__(self, fnr_model, kappa_min, kappa_c_global, risk_weights,

        if self.ood.is_ood(phi):          # 外推不安全 → 不覆盖（保守）
            return 0.0
        return 1.0 - self.fnr.predict(phi)

        return {x for x in region if self.kappa(x, v) >= self.kappa_min}

    def plan_view(self, state, risk_horizon):

        return self.planner.next_best_view(
            objective=lambda v: sum(self.risk[c] * max(self.kappa(c, v)
                                                       - self.kappa_min, 0.0)
                                    for c in risk_horizon)
                              + self.beta_info * mutual_info_presence(v))

    def issue_absence(self, cov_kappa, detections, gestures):

        for g in gestures:
            if g.valid:
                return None, "HUMAN_PRESENT_BY_GESTURE"
        if any(d.in_cov(cov_kappa) for d in detections):
            return None, "DETECTION_IN_COV"
        return AbsCert(region=cov_kappa, kappa=self.kappa_min), "OK"  # 引理 165

    def anytime_absence(self, stream, delta_abs):
        # 可选：e-process 累积多视角证据，Ville 不等式给出随时有效保证
        E, lam = 1.0, self.predictable_lambda(stream)

## 3. 推导

**引理 163（证书→屏障的保守性）** `Obs_t` 由 v21 P34/引理 157 只增不减地包含真实障碍，延迟外推 `predict_forward` 只增大障碍；故屏障 `h_t(x)=dist(x,predict_forward(Obs_t))−r_safe−r_lat‖v‖` 是对真实有符号间隙的下界。取 `r_safe≥max(margin_col_fed,ρ_j)`，则 `h_t(x)≥0 ⇒` 真实间隙 `≥r_safe≥` v21 要求的碰撞裕度，即 `h≥0 ⇒ v21 几何准入`。编译只收不放，不引入假自由空间。∎

**引理 164（鲁棒前向不变性）** 设 h 沿 f 的 Lie 导数由认证 `L_h` 与 `L_f h` 下界可靠界定，且 `u(t)∈K_cbf(x(t))` 即 `inf_w[L_f h+L_g h u+L_w h w+α(h)]≥0`。由比较引理，`h(x_t)≥β(h(x_0),t)`；当 `h(x_0)≥0` 时对所有 t 有 `h(x_t)≥0`，安全集前向不变。连续成立严于任一快照准入，故 `Exec_v22` 在几何上 ≤ v21 的连续化准入集。∎

**引理 165（视况条件化缺席可靠性）** 若 `φ(x,v)` 位于标定支撑内且 `κ(x,v)≥κ_min`，则覆盖区内"有人而零检测"的概率 `≤1−κ_min=δ_abs`，AbsCert 以 `≥1−δ_abs` 可靠。视况 OOD 时令 `κ:=0` 并拒发，退化为全域保守。取 `κ_min≥κ_c`，则 v22 签发的证书至少与 v21 的全局假设一样强；主动感知扩大了**可签发的覆盖**，但每个签发点都由实测视况背书。∎

**引理 166（对偶效应不破坏证书有效性）** 视角/采样策略 `v_t` 由历史观测可预测地选取；AbsCert 的语义只条件于**已实现的视况** `φ_t`（引理 165），不条件于策略，故任意自适应采样策略下证书保证不变。信息增益项仅改变代价，不改变证书判定。e-process 变体中，若 `λ_t` 可预测，则 `E_t` 在"有人"零假设下仍为测试超鞅，Ville 不等式给出 `P(∃t:E_t≥1/δ_abs)≤δ_abs`，即随时有效（可处理连续多次查看）。∎

**引理 167（认证值函数的近最优性）** 若 `V̲≤V*≤V̄` 且 MPC 终端代价用 `V̄` 上界、执行代价 `J≤V̄`，则次优性 `J−V*≤V̄−V̲=ε_V`；当 `ε_V≤` 终端裕度时 horizon 充分。QCert 同时给出可审计风险预算 `V̄`。认证失败（界不可信）时丢弃最优性声明、退回 v21 过滤，安全不受影响。∎

**引理 168（动态障碍鲁棒性）** 由视觉跟踪/光流给出速度估计与误差半径 `σ_track`，用 `v_max` 外推并膨胀 `σ_track`、再加延迟裕度。若真实速度 `∈[−v_max,v_max]`、跟踪误差 `≤σ_track`，则 `predict_obstacle ⊇` 真实未来位形，故 `robust_h≥0 ⇒` 整个延迟窗内无碰撞。跟踪不可信时取 `v_max` 最大外推（最保守），安全方向不变。∎

**引理 169（v22 安全继承与证据替换）** 相同证据语义（同一 `κ_min`、同一规则库、同一障碍集）下：CVB 连续不变 ⇒ 逐时刻 HPC+ 准入（163–164），QP 回退刹车仍在 v21 安全集内，故 `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19`。主动感知改变的是**可获得的证据**（引理 165–166）：只在实测视况达标处签发，故新增可行域是用**更强、可测**的证书证明的，而非放宽约束；这是"证据替换"而非"约束松弛"。∎

## 7. 已知风险与失效模式

1. **模型/标定假设的外推失效**（最大风险，见第 8 节）：CBF/VCert 依赖动力学模型、扰动集与视况-召回标定；OOD 或未建模动态下会"形式可证、事实失效"。缓解：OOD 检测拒发（E806/E828）、扰动集在线膨胀、模型失配看门狗、标定支撑显式化。
2. **CBF-QP 不可行与边界抖动**：多约束冲突导致 QP 无解或高频切换。缓解：软约束+slack、最小刹车回退、滞回与随机退避（E804）。
3. **非光滑屏障/Lipschitz 界过松**：框并/非凸 Hull 使 h 不可微，界过松则过度保守、过紧则失效。缓解：光滑过近似、认证 `L_h`、Dini 导数（E801/E815）。
4. **主动感知的瞬态盲区**：转向/变焦期间覆盖短暂下降。缓解：速度-覆盖耦合（看不清即减速）、重定向期拒发 AbsCert（E807/E822）。
5. **信息项被投机（Goodhart）**：优化器追逐信息代理而非真实降低存在不确定。缓解：证书只认实测 κ，信息项仅作代价；安全约束独立（E810）。
6. **对偶效应的计算不可解**：POMDP 实时性。缓解：信息态代理+10Hz 重规划+缓存（E809/E822）。
7. **隐私与审计**：视觉取证处理图像、审计链复杂化。缓解：原始图像不出设备、只传证书与视况特征；merkle 锚定模型/扰动/标定版本（延续 E794）。

## 8. 本轮最大风险

**一句话**：把"缺席幻觉"换成了"模型幻觉"——CVB/VCert 的全部保证依赖动力学模型、扰动集与"视况→召回"标定这三条外生假设，一旦在分布外视况（逆光/烟尘/人群遮挡）或未建模动力学下外推，机器人会以**形式可证、审计通过、事实失效**的方式越过安全边界，形成"认证的模型幻觉"。
