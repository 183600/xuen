# 第 44 轮（新循环重启 · 第 1 轮） · Context-Motion Certificates：上下文只做「路由」、运动只做「执行」，用切换守卫把两者焊进同一张证书（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「用户」与「并发」纳入证书闭环，但仍压着两个未言明的假设：**(H1) 上下文理解只是语义提案源**——VLM/LLM 说「这是厨房」「这是同事」「任务快结束了」，语义层提出动作，几何层再认证；上下文本身从不进入证书。于是「厨房里可以快一点」这类语义先验要么被无视（过度保守、可用性差），要么被偷偷当成放宽安全域的理由（静默不 sound）。**(H2) 运动技能是上下文无关的静态单元**——真实运动控制是「切模式」的：同一个人从「障碍」变成「协作者」、同一区域从「走廊」变成「作业区」、同一任务从「探索」变成「收尾」，运动不变式随之切换，而切换瞬间恰恰是安全最容易被撕开的地方。本轮灵感词「运动控制」「上下文理解」正命中这两个假设：**运动控制**迫使我们把证书的最小单位从「单步动作」提升为「带前后条件与不变式的技能」，并显式处理模式切换；**上下文理解**迫使我们把语义从「自由先验」降格为「可验证的路由键」——上下文只能选择/收缩已认证的运动证书，不能凭空扩张。二者耦合出的真问题：**语义是离散的、运动是连续的，上下文切换会在两个模式的可行集之间撕开一道安全缝隙**。

## 0. 直觉与动机

**灵感 1（运动控制 → 证书的最小单位是「技能」而不是「动作」）**：单步 CBF 只保证「下一步不撞」，但长时程任务需要「这一段能走完、走完后能接上下一段」。因此把运动控制组织成**认证技能库**：每个技能 σ 携带 (Pre, Inv, Post, 执行时限, 跟踪误差包络)，证书从「逐点安全」升级为「区间契约」。直觉上，**动作级证书像每步都重新问路，技能级证书像先验证整条公交线路**；好处是组合可预认证、可缓存，代价是技能边界处必须显式校验 Post→Pre 的衔接与切换。

**灵感 2（上下文理解 → 上下文是路由键，不是放宽阀）**：VLM/LLM 的「理解」本质是把高维观测压成离散语义，它天然会犯错，且错误在分布漂移时最密集。若允许上下文直接调低安全阈值（「这是熟人，可以靠近一点」），语义幻觉就变成物理违例。于是规定：**上下文只能在已认证技能集合上做选择、只能收紧裕度、只能触发降级；任何「扩张」都必须来自预先离线认证过的新技能**。一句话：**上下文负责「用哪张证书」，不负责「改证书上的数字」**。

**灵感 3（耦合 → 真正的危险点是「上下文切换」）**：设模式 q 的安全集为 Inv_q(c)，模式 q' 为 Inv_{q'}(c')。若在 x ∉ Inv_q ∩ Inv_{q'} 时切换，新控制器一接管就可能立刻违例。这与 v20 的混合关键级模式切换同源，但更隐蔽：v20 的切换由负载触发、可控；上下文切换由**外部世界与语义理解**触发、不可控。解决三件套：**(a) 切换守卫**只在两模式安全集交集内允许切换；**(b) 公共鲁棒障碍函数**保证切换窗口内裕度非增；**(c) 否则保持旧模式并 dwell-time 等待，或先降级到通用安全技能 σ_⊥**。注意一个漂亮的性质：**上下文越不确定（语义直径 δ 越大），允许切换的窗口越窄**——这把「理解得有多准」直接换算成「能有多灵活」。

**耦合升级**：CLMA（上下文-运动自动机）把上下文格编译成模式与切换守卫；CCSL（认证技能库）提供带上下文前置条件的技能与组合文法；CSRR（切换鲁棒运行时）用上下文条件 CBF + 鲁棒裕度 + 指纹缓存执行。四层架构由 v8 的「人格/并发证书」扩展为 v9 的「**上下文路由 + 技能组合 + 切换安全**」闭环；v20 的人格契约与并发租约作为正交层继续复用。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（上下文格与上下文证书）**：设上下文原子集合 A_c（场景类别、社会角色、任务阶段、可通行性、人的意图等），上下文空间 C = 2^{A_c} 赋予偏序 ⊆（信息越具体、集合越大）。上下文理解器 U: O → Γ(o)，Γ(o) ⊆ C 为**可信上下文集**（credal set），由分层共形预测/集合值分类器给出，满足 P(c* ∈ Γ(o)) ≥ 1−α。**上下文证书** γ=(Γ, δ)，其中 δ = diam_e(Γ) := max_{c,c'∈Γ} ||e(c)−e(c')|| 为语义直径，e: C → R^d 为上下文嵌入。**格操作**：join = 信息合并，meet = 共同约束；要求 U 单调：观测越丰富，Γ 越小。

**定义 45（运动技能与上下文-运动契约）**：技能 σ=(π_σ, D_σ, Pre_σ, Inv_σ, Post_σ, T_σ, h_σ)，π_σ 为反馈控制器，D_σ 为动力学/跟踪误差包络，Pre/Inv/Post 为状态谓词，T_σ 为最大执行时限，h_σ 为障碍函数。**上下文-运动契约** K_σ = {c ∈ C : c ⊨ Pre_c(σ)}，表示技能证书成立的上下文集合。称 σ 对上下文 c **sound**，当且仅当 ∀x∈Pre_σ(c)，执行 π_σ 在 T_σ 内保持 Inv_σ(c) 并到达 Post_σ(c)。**技能库** L={σ_i, K_i}。

**定义 46（上下文条件障碍证书与 Lipschitz 鲁棒裕度）**：技能 σ 的上下文条件障碍函数 h_σ(x; e(c))。若 (i) h_σ 对 e 是 L_h-Lipschitz；(ii) 在标称上下文 ĉ 下 h_{ĉ} 是有效离散 CBF，即 h_{ĉ}(x_{k+1}) ≥ (1−η)h_{ĉ}(x_k)；(iii) 对所有 c∈Γ(o)，|h_c(x) − h_{ĉ}(x)| ≤ L_h·δ，则**鲁棒裕度判据** h_{ĉ}(x) ≥ L_h·δ + ε 蕴含 h_c(x) ≥ ε ≥ 0。**定理（上下文鲁棒安全）**：满足该判据的 CBF-QP 安全滤波输出，对 Γ(o) 内任意上下文保持前向不变。**推论**：语义不确定度 δ 被一个 Lipschitz 常数直接换算成运动保守度——这是「上下文理解」与「运动控制」之间唯一可静态审计的接口。

**定义 47（上下文门控选择与「只路由、不放宽」定理）**：选择算子 Sel(Γ(o), L) = argmax_{σ∈L} U(σ)，约束为 Γ(o) ⊆ K_σ 且 h_σ 的鲁棒裕度成立；若可行集为空，返回通用安全技能 σ_⊥（K_{σ_⊥}=C，最保守、可覆盖全上下文）。**定理（不放宽）**：任意选择输出的运动证书 ⊆ 全局安全证书；上下文理解误差只可能降低技能利用率（更保守），不可能扩大可行域。**协商**：当 Γ 同时跨越多个不相容 K_σ 且 σ_⊥ 无法到达目标时，输出**最小消歧查询**（一个能最大熵缩减 Γ 的观测/提问），而不是猜测。

**定义 48（上下文切换安全的混合运动自动机）**：自动机 M=(Q, C, →, Inv, h, G_sw)，Q 为运动模式（技能），→ ⊆ Q×C×Q 为上下文触发的模式切换。**切换守卫** G_sw(q→q', c) 要求 x ∈ Inv_q(c) ∩ Inv_{q'}(c)，且存在**公共鲁棒障碍函数** h_{q,q'} 在切换窗口 [t, t+τ_d] 内非增：h_{q,q'}(x) ≥ L_h(q,q')·δ + ε。若不满足则禁止切换、保持 q 直到进入交集（dwell-time）。**定理（切换安全）**：若 (i) 每个模式内 h_q 前向不变，(ii) 每次切换经过 G_sw，(iii) 切换只允许进入交集或先降级到 σ_⊥，则任意上下文切换序列保持全局安全不变式。**直觉**：这相当于给「语义换挡」加了一个只有在两个档位都安全时才踩得下去的离合器。

**定义 49（上下文-运动组合文法与证书组合）**：文法 G=(Σ, N, R, σ_start)，产生式 r: σ_1⋯σ_k → σ 携带**组合证书** (Post_{σ_i} ⊨ Pre_{σ_{i+1}}，时间/资源界，切换守卫)。**组合可靠性定理**：若每个终端技能有 sound 契约、每条产生式的后置-前置蕴含与切换守卫成立，则任意合法推导出的运动计划 sound。**推论（受约束的语义生成）**：LLM/VLM 只在文法内生成或选择产生式（语法约束解码），不能凭空生成未认证的新技能，从而把「上下文理解」限制在一个可验证的离散选择空间里。

**定义 50（上下文指纹与 anytime 运动缓存）**：缓存键 φ = H(Γ 摘要, 技能版本, 动力学包络, 校准集版本, 地图指纹)。缓存证书可复用，当且仅当 φ 完全匹配、conformal 残差检验通过、且 staleness ≤ T_fresh。**命题（缓存只影响延迟，不影响 soundness）**：指纹不匹配或残差越界时禁用缓存、回退重算，则缓存不改变证书语义。**收益**：上下文理解给出下一时刻上下文分布，可预取/预热候选技能证书，把运动规划延迟从 O(|L|) 降到 O(log|L|)+ε。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CONTEXT-LATTICE-MOTION-AUTOMATON（上下文-运动自动机 CLMA）
1. **上下文原子本体与格**：定义场景/角色/任务阶段/可通行性等原子及其偏序、join/meet；支持粗化（省算力）与细化（提精度）。
2. **可信上下文证书**：按人格/场景分层的 Mondrian 共形，输出 (Γ, δ)；维护条件覆盖率与漂移检测（分布漂移即 δ 膨胀）。
3. **契约编译**：把技能语义前置条件 ground 成几何谓词，得到 Pre/Inv/Post 与 K_σ，并导出上下文索引的安全阈值表。
4. **切换守卫与公共障碍**：编译模式切换图，离线求公共鲁棒障碍函数或证明其存在；在线执行 G_sw，禁止非交集切换。
5. **消歧协商**：Γ 跨不相容技能时，生成最小消歧查询；无可行技能则降级 σ_⊥ 并上报，不静默放行。

### 2.2 IP-61 CERTIFIED-CONTEXT-SKILL-LIBRARY（认证技能库 CCSL）
1. **技能离线认证**：对每个技能在上下文网格上做可达性/CBF 认证，产出 Pre/Inv/Post、时限、跟踪误差包络与 K_σ。
2. **鲁棒裕度表**：标定每个技能的 L_h 与 δ_max，得到「上下文不确定度 → 允许动作裕度」查表。
3. **上下文-运动组合文法**：产生式携带组合证书；支持顺序、并发、条件分支、恢复（recovery）四类组合。
4. **受约束语义生成**：LLM 输出被语法约束解码到文法产生式，越界生成直接拒绝，不进入执行。
5. **覆盖率与兜底**：统计技能库对上下文空间的覆盖；未覆盖区域必须由 σ_⊥ 接管并进入课程补齐。

### 2.3 IP-62 CONTEXT-SWITCH-ROBUST-RUNTIME（切换鲁棒运行时 CSRR）
1. **上下文条件 CBF-QP**：以 h_{ĉ}(x) − L_h·δ 作为硬约束求解，把语义不确定度显式变成保守裕度。
2. **切换调度器**：原子模式切换（seqlock/epoch 快照），dwell-time 与守卫拒绝计数；切换期间冻结技能参数。
3. **指纹缓存与预取**：按 φ 缓存证书与运动计划；按预测上下文分布预取下一批技能。
4. **漂移与一致性监控**：条件覆盖、δ 标定误差、切换审计、缓存误用四路监控，任一越界即降级。
5. **回退梯**：鲁棒 CBF → 标称 CBF + 降速 → σ_⊥ 通用安全技能 → 安全停机。

## 5. 本轮最大风险

**一句话**：上下文理解在分布漂移时的错误恰恰最密集，而 Lipschitz 鲁棒证书依赖对语义直径 δ 的正确估计——一旦 δ 被系统性低估，「鲁棒」裕度会静默消失；因此 E95（条件覆盖）、E96（δ 鲁棒性）、E102（漂移检测）必须设为红线，且默认回退到与上下文无关的 σ_⊥ 通用安全技能这条永不失 sound 的底线。

## 2. 关键算法（伪代码）

### IP-60 CLMA：上下文格、契约编译与切换守卫
```
def build_context_lattice(atoms):
    C = powerset(atoms)
    return Lattice(C, leq=subset, join=union, meet=intersection)

def context_certificate(obs, alpha, persona=None):
    gamma = conformal_context_set(obs, alpha, strata=persona)  # credal set
    delta = embedding_diameter(gamma)                          # 语义直径
    return ContextCert(gamma, delta)

def compile_contract(skill, atoms):
    pre  = ground(skill.pre,  atoms)      # 语义前置 -> 几何谓词
    inv  = ground(skill.inv,  atoms)
    post = ground(skill.post, atoms)
    K    = {c for c in C if entails(c, skill.context_pre)}
    return Contract(skill, pre, inv, post, K)

def switch_guard(q, q2, x, ctx, delta):
    if x not in meet(inv[q](ctx), inv[q2](ctx)):
        return False                       # 不在交集，禁止换挡
    h_shared, L = common_barrier(q, q2)
    return h_shared(x) >= L * delta + EPS  # 切换窗口内裕度非增

def select_skill(Gamma, library, goal):
    feasible = [s for s in library
                if subset(Gamma, s.K) and robust_margin_ok(s, Gamma)]
    if feasible:
        return max(feasible, key=utility)  # 只路由，不放宽
    if reachable(SIGMA_BOT, goal):
        return SIGMA_BOT                    # 通用安全兜底
    return disambiguate(Gamma, library)     # 最小消歧查询
```

### IP-61 CCSL：技能认证与组合文法
```
def certify_skill(skill, context_grid):
    for c in context_grid:
        pre, inv, post = ground_all(skill, c)
        if not reach_avoid_verify(skill.pi, pre, inv, post, skill.T):
            return UNSOUND(skill, c)
    K = {c for c in context_grid if certified(skill, c)}
    return CertifiedSkill(skill, K, lipschitz=estimate_L(skill.h))

def compose(grammar, chain):
    plans = []
    for r in grammar.derivations(chain):
        seq = r.terminals
        if all(implies(post[seq[i]], pre[seq[i+1]])
               for i in range(len(seq)-1)) \
           and all(switch_guard_ok(r, i) for i in range(len(seq)-1)):
            plans.append(r)
    return plans

def constrained_decode(llm_tokens, grammar):
    # 只允许生成文法产生式；越界 token 直接屏蔽
    return grammar.valid_continuation(llm_tokens)
```

### IP-62 CSRR：鲁棒 CBF-QP、缓存与回退梯
```
def robust_cbf_qp(x, skill, ctx_cert):
    e_hat = embed(ctx_cert.center)
    h = skill.h(x, e_hat) - L_h[skill] * ctx_cert.delta   # 鲁棒裕度
    return solve_qp(cost=tracking_cost(x),
                    constraints=[h >= 0,
                                 h_next >= (1-eta)*h,
                                 u in skill.actuation])

def cache_lookup(ctx_cert, skill, map_id):
    phi = hash((ctx_cert.summary, skill.version, skill.dynamics_env,
                calibration_version, map_id))
    e = cache.get(phi)
    if e and e.staleness <= T_FRESH and conformal_residual_ok(e):
        return e.plan
    return None                       # 不匹配即重算，绝不复用

def prefetch(ctx_belief_next, library):
    for c in top_k(ctx_belief_next, k=3):
        for s in skills_covering(c):
            cache.warm(async(lambda: certify_on_demand(s, c)))

def runtime_step(x, obs, goal):
    ctx = context_certificate(obs, ALPHA)
    s   = select_skill(ctx.gamma, LIBRARY, goal)
    if not switch_guard(CURRENT_MODE, s.id, x, ctx.gamma, ctx.delta):
        return dwell_or_degrade(CURRENT_MODE, SIGMA_BOT)   # 守卫拒绝
    plan = cache_lookup(ctx, s, MAP_ID)
    if plan is None:
        plan = robust_cbf_qp(x, s, ctx)
    return atomic_switch_and_execute(s, plan)              # 冻结参数后切换
```

## 6. 本轮最大风险

**一句话**：上下文理解在分布漂移时的错误恰恰最密集，而 Lipschitz 鲁棒证书依赖对语义直径 δ 的正确估计——一旦 δ 被系统性低估，「鲁棒」裕度会静默消失；因此 E95（条件覆盖）、E96（δ 鲁棒性）、E102（漂移检测）必须设为红线，且默认回退到与上下文无关的 σ_⊥ 通用安全技能这条永不失 sound 的底线。
