# 第 45 轮（承接第 44 轮 v21；本轮灵感：基线复现 × 轨迹优化） · Repro-Cert × Traj-Cert：把「基线复现」升为比较证据证书，把「轨迹优化」升为求解器可证轨迹（四层架构 v10 + E 证据横层）

> 承接第 44 轮 v21（Pose-Cert × Data-Cert）。v21 把姿态升为根信任、把采集升为审计闭环，但它与 v19–v21 整个证书栈仍共享两个未言明假设：**(H4) 我们报告的「提升」是在可比、可复现的基线上测得的**；**(H5) 消费这些 margin 的轨迹优化器是一个收敛、可行、确定的 oracle**。这两个假设都不成立。H4 不成立在：44 轮里我们从未真正重跑过基线，未锁定基线的代码/数据/检查点/配置/预算，也未把「复现噪声」当作零假设——于是所有证书改进可能只是种子噪声或协议漂移。H5 不成立在：轨迹优化是非凸、限时、热启动敏感、带数值容差的；它返回的离散解可能不可行、可能远离连续执行轨迹、可能在滚动时域交接处失配，而 v21 的 per-waypoint □ 提升对此完全无感。两个灵感词精确命中：**基线复现**迫使我们把「比较」升级为**带复现噪声地板的效应证书**，**轨迹优化**迫使我们把「规划」升级为**求解器残差 + 连续时间 tube + 滚动契约的可证轨迹**。二者耦合出本轮真正的新问题：**复现协议定义了问题分布 Q 与算力预算 b，而轨迹证书的 sound 性与性能恰恰只在给定 (Q,b) 下才有意义——若预算被悄悄放宽、Q 被悄悄缩窄，证书与比较会同时变成自我实现（评测层的 Goodhart）**。

## 0. 直觉与动机

**灵感 1（基线复现 → 「跑过」不等于「复现」，比较本身要有证书）**
直觉：说「我们比基线好」，至少要做三件事：真的把基线跑起来；在**同一批 episode、同一传感器配置、同一算力预算、同一指标与选择规则**下跑；且提升要超过「同一基线换个种子」的自然抖动。所以给每次比较发一张**复现证书**：基线护照（代码/数据/配置/检查点哈希 + 隐藏旋钮声明）、协议等价谓词（数据划分/观测模态/决策频率/动作限幅/预算/指标/停止与选择规则）、配对分块样本、复现噪声地板 τ_rep、效应下界 Δ_LCB。只有 Δ_LCB > τ_rep 且 > 0 才允许写「提升」。这把「复现」从一句礼貌话变成可审计的证据对象。

**灵感 2（轨迹优化 → 优化器返回的是「候选」，不是「已证轨迹」）**
直觉：求解器返回 ξ=(x_0…x_N,u) 时，它可能 (a) 约束违反超过容差，(b) 只是局部最优，(c) 只看离散节点、真实连续执行在节点之间越界，(d) 跟踪控制器与扰动让真实轨迹偏离标称 tube。安全证书必须覆盖**连续时间执行**，并把求解器自身的误差当成 margin 的一部分：先用**认证修复/投影**得到严格可行解，再把「可行性修复量 + 离散化/积分误差 + 跟踪误差 + 姿态 tube」叠成一条时间相关的 tube T(t)，安全谓词只在 T(t) 上做 □ 提升。优化器的「最优性」不进安全证书，只进性能证书——不要把 performance 和 safety 混进同一个不等式。

**灵感 3（耦合 → 预算匹配的轨迹分布复现 + anytime 安全）**
直觉：对随机/anytime 轨迹优化器，「复现基线」不是复现一个数，而是复现**在匹配问题分布 Q 与算力预算 b 下的轨迹/指标分布**；预算不同、Q 不同，比较就无效。反过来，轨迹证书若只在「给足迭代」时成立，就不可部署。于是新的对象是**预算感知（budget-aware）的 anytime 可证轨迹**：任意预算 b 下，要么返回一条已证安全的轨迹，要么返回一条预证的制动/停机轨迹；绝不允许「时间到了返回一条未证的解」。复现协议负责锁死 (Q,b) 与零假设，轨迹证书负责在同一个 (Q,b) 下给出 sound 执行与性能下界。

**耦合升级**：RCE（复现证书引擎）产出基线护照、协议等价、τ_rep 与 Δ_LCB；TCE（轨迹证书引擎）产出求解器残差、连续时间 tube、滚动契约与 anytime fallback；EVA（证据审计器）红队复现（隐藏旋钮/种子钓鱼/基线削弱/污染）与轨迹（近边界不可行/限时/交接失配）。四层架构由 v9 升级为 v10：新增 **L3.5 轨迹证书层** 与贯穿全栈的 **E 证据横层**。

## 1. 形式化定义（增量：定义 50–55）

**定义 50（复现证书与协议等价）**
设基线 B=(method, code, ckpt, cfg, train_data)，评测协议 P=(Q, 初始条件分布, 种子集, 传感器配置, 决策频率, 动作空间/限幅, 算力预算 b, 指标 m, 选择/停止规则)。复现证书
C_rep = (π_B, Eq(P), {m_B^(j)}_{j=1..k}, τ_rep, n_eff)。
π_B 为基线护照（全部可改旋钮的哈希与声明）；Eq(P) 为协议等价谓词，对上述不变量逐项判等，任一项不等只允许**条件比较**并显式标注；{m_B^(j)} 为同协议重跑 k 次的指标。**复现噪声地板** τ_rep(γ) = Q_{1−γ}(|m_B^(j) − m_B^(j')|)（不同种子、同配置），即「同一方法自己和自己比」的自然抖动。未声明隐藏旋钮的基线，其 C_rep 视为无效。

**定义 51（配对分块效应下界与声明闸门）**
以 task×scene 为块、episode 为配对单位，Δ_e=m_M(e)−m_B(e)。块感知单侧下界
Δ_LCB = Δ̄ − t_{1−β,df_eff}·se_block，se_block = sqrt( (1/B) Σ_b (Δ̄_b − Δ̄)^2 )，
df_eff 由 n_eff（定义 47 的自相关校正）给出。**声明闸门**：仅当 (i) C_rep 有效且 Eq(P) 全通过；(ii) Δ_LCB > τ_rep(γ)；(iii) 逐层（姿态层 ω / 任务层 / 场景层）效应不全由单层驱动、最差关键层不恶化；(iv) EVA 未检出泄漏/污染/基线削弱——才允许声明「提升」。否则结论只能是「未决（unresolved）」，必须如实报告。

**定义 52（求解器可证轨迹与连续时间 tube）**
设轨迹优化器 O 在容差 ε_tol、预算 b 内返回离散 ξ=(x_0..x_N,u_0..u_{N-1})。定义四项界：
- **认证可行性修复** r_repair：对返回解做区间/对偶验证，或经投影 ξ̃=Π_C(ξ) 得到严格可行解，使 g(ξ̃) ≤ 0 且 ‖ξ̃−ξ‖ ≤ r_repair（可计算上界）；
- **离散化/积分误差** ε_disc：在 f 为 L_f-Lipschitz、控制零阶保持、积分器 p 阶下，sup_t d(x(t), interp(ξ̃)) ≤ ε_disc ≈ C·(e^{L_f T}−1)/L_f · h^p；
- **跟踪 tube** r_track(t)：执行控制器 + 扰动界；
- **姿态 tube**：由 IP-60 的 P(t) 给出。
**轨迹 tube** T(t) = P(t) ⊕ B(r_repair) ⊕ B(ε_disc) ⊕ B(r_track(t))。安全轨迹证书要求 ∀t∈[0,T_exec]，φ^□(T(t)) 对所有安全谓词成立。**命题（安全轨迹）**：若 x(t)∈T(t)（由上述四界保证）且 φ^□(T(t))，则 φ(x(t))。次优间隙 r_dual 不进安全证书，只进性能报告。

**定义 53（滚动时域轨迹契约与 anytime fallback）**
计划 i 在 [t_i,t_i+H_i] 上获证，但只执行到 t_i+δ_i（δ_i≤H_i）。**契约**：(i) t_{i+1} 真实状态落在计划 i 的预测可达集 R_i(t_{i+1})，且 R_i(t_{i+1}) ⊆ 计划 i+1 的初始证书集；(ii) 计划 i+1 必须在 t_i+δ_i 前完成认证；(iii) 交接失败或认证超时 → 立即切到**预证的制动/停机轨迹**（其 tube 仍安全）。**命题（组合 soundness）**：若每个计划的 tube sound 且所有契约成立，则拼接执行安全。**anytime 安全**：对任意预算 b，O 必须返回「已证计划」或「预证 fallback」二者之一；返回未证解即违约——时间到不是安全的借口。

**定义 54（预算匹配的轨迹分布复现）**
对随机/anytime 优化器，基线在问题分布 Q、预算 b 下的行为是轨迹分布 D_B(Q,b)。复现证书要求：(i) Q 匹配（同一 episode/初始条件分布，或显式分层）；(ii) b 匹配（墙钟/迭代/FLOPs 与 anytime 截断一致）；(iii) 分布接近：d_OT(D_B,D̂_B) ≤ δ_B，或逐层指标（成功率/代价/违约率/分位数）差在容差内；(iv) 种子配对以降方差。**命题**：若 Q 或 b 不匹配，则任何标量比较都可能被分布漂移或「多算即更强」污染，此时只能做分层/条件比较，不得做总均值声明。

**定义 55（复现-轨迹联合审计）**
EVA 对 C_rep 与轨迹证书做红队：(a) 隐藏旋钮搜索（网格/日志差分找未声明配置）；(b) 种子钓鱼检测（海量种子取最优 vs 预注册种子）；(c) 基准污染/泄漏（同 episode、同 scene、训练测试重叠）；(d) 基线削弱检测（基线配置被降级、预算被克扣）；(e) 求解器 fuzz（近边界约束、退化 QP、限时、热启动切换、交接时刻）验证 tube 不越界、fallback 真能触发。任一高危项 → 声明冻结并回灌。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-63 REPRO-CERT-ENGINE（复现证书引擎 RCE）
1. **基线护照与协议清单**：哈希锁定代码/数据/检查点/配置；自动枚举可改旋钮并要求逐项声明。
2. **协议等价检查器**：对数据划分、观测模态/频率、动作限幅、算力预算、指标、选择与停止规则逐项判等，输出「等价 / 条件等价 / 不可比」。
3. **配对分块效应下界**：块感知 bootstrap + n_eff，输出 Δ_LCB 与逐层（姿态层/任务/场景）分析。
4. **复现噪声地板与声明闸门**：k 次同协议重跑估计 τ_rep；四条件闸门；未过闸门只允许「未决」结论。

### 2.2 IP-64 TRAJ-CERT-ENGINE（轨迹证书引擎 TCE）
1. **认证修复/可行性验证**：区间/对偶界或带界投影修复，输出 r_repair；不可修复即拒。
2. **连续时间 tube**：Lipschitz 界 + 积分阶 + 跟踪界 + 姿态 tube 叠成 T(t)，在节点之间也成立。
3. **轨迹级 □ 提升与滚动契约**：计划级证书 + 预测可达集包含检查 + 交接前必须完成下一计划认证。
4. **anytime fallback**：预证制动/停机轨迹常驻；预算耗尽优先 fallback，绝不返回未证解。

### 2.3 IP-65 EVIDENCE-AUDITOR（证据审计器 EVA）
1. **复现红队**：隐藏旋钮、种子钓鱼、污染/泄漏、基线削弱。
2. **轨迹红队**：近边界/退化 QP/限时/热启动/交接 fuzz，验证 tube 越界与 fallback 触发。
3. **声明回归**：预注册隐藏任务/场景，每次声明前跑；失败即冻结声明。
4. **证据谱系**：把每个声明的 C_rep、Δ_LCB、τ_rep、tube 参数与审计结果存档、可追溯、可重放。

## 4. 实验设计（E103–E110 硬门槛，承接 E95–E102）

回退：E103 失败 → 冻结对外声明，只做同种子内部相对比较；E105 失败 → 退回手工膨胀 margin + 降速；E106 界失效 → 缩小单步/缩短 horizon、提高控制频率；E107 失败 → 取消长滚动，改短 horizon + 频繁 stop；E108 失败 → 要求静态算力或默认预证停机；E109 失败 → 只报分层/定性结论；E110 任一红项 → 熔断声明并隔离该批证据。

## 5. 本轮最大风险

**一句话**：连续时间 tube 依赖 Lipschitz/积分阶/修复界，而这些在接触、非光滑动力学与长 horizon 下会指数膨胀至 vacuous，同时复现噪声地板可能大到任何真实提升都无法通过声明闸门——于是方案「sound 但无用」，并诱使我们在「严谨」的名义下悄悄缩窄问题分布 Q 或放宽预算 b，制造出评测层的 Goodhart：证书和比较都成立，但只在一个被精心挑选的世界里成立。

# 第 45 轮产物 · 创新点清单 v22：Repro-Cert × Traj-Cert（RCE × TCE × EVA）× 可审计「证据-求解器」双横层（四层架构 v10）

## 1. 符号体系（增量：定义 50–55 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| B=(method,code,ckpt,cfg,data) | 基线身份 | 全部可改旋钮须哈希锁定并声明 |
| P=(Q,初始分布,种子,传感器,频率,动作限幅,b,m,选择/停止) | 评测协议 | 比较的可复现前提 |
| C_rep=(π_B,Eq(P),{m_B^(j)},τ_rep,n_eff) | 复现证书 | 基线护照 + 协议等价 + 重跑样本 + 噪声地板 |
| Eq(P) | 协议等价谓词 | 逐项判等；不等则只许条件比较 |
| τ_rep(γ) | 复现噪声地板 | Q_{1−γ}(\|m_B^(j)−m_B^(j')\|)，同配置换种子 |
| Δ_LCB | 效应下界 | Δ̄ − t_{1−β,df_eff}·se_block |
| r_repair | 认证修复量 | 使 g(ξ̃)≤0 且 ‖ξ̃−ξ‖≤r_repair 的可计算上界 |
| ε_disc | 离散化/积分误差 | sup_t d(x(t), interp(ξ̃)) ≤ C·(e^{L_f T}−1)/L_f·h^p |
| r_track(t) | 跟踪 tube | 执行控制器 + 扰动界随时间 |
| T(t) | 轨迹 tube | P(t) ⊕ B(r_repair) ⊕ B(ε_disc) ⊕ B(r_track(t)) |
| D_B(Q,b) | 轨迹分布 | 基线在问题分布 Q、预算 b 下的输出分布 |
| d_OT / δ_B | 分布距离/容差 | 预算匹配复现的可比判据 |
| R_i(t) | 预测可达集 | 计划 i 在 t 时刻可能到达的状态集 |
| C_claim | 声明闸门 | C_rep 有效 ∧ Δ_LCB>τ_rep ∧ 逐层不恶化 ∧ 无污染 |

## 2. 关键算法（伪代码）

### IP-63 RCE：基线护照、协议等价、噪声地板与声明闸门
```
def reproduction_certificate(B, protocol, k, gamma):
    passport = hash_lock(B.code, B.ckpt, B.cfg, B.train_data)
    knobs = enumerate_free_knobs(B.code)
    if not passport.declares(knobs):
        return Invalid('undeclared_knobs')           # 未声明隐藏旋钮 = 无效
    eq = protocol_equivalence(protocol, B.reported_protocol)
    if eq != FULL:
        return Conditional(eq, note='only stratified comparison')
    runs = [run_baseline(B, protocol.seeds[j]) for j in range(k)]
    tau_rep = quantile([abs(runs[j].m - runs[j2].m)
                        for j, j2 in pairs(range(k))], 1 - gamma)
    return ReproCert(passport, eq, runs, tau_rep,
                     n_eff=effective_sample_size(runs, blocks=protocol.blocks))

def paired_effect_lcb(method_metrics, baseline_metrics, blocks, beta):
    delta = [m - b for m, b in zip(method_metrics, baseline_metrics)]
    delta_bar_b = block_means(delta, blocks)          # task×scene 块
    se = sqrt(sample_var(delta_bar_b) / len(delta_bar_b))
    df = effective_dof(blocks, method_metrics)        # 由 n_eff 校正
    return mean(delta) - t_quantile(1 - beta, df) * se

def claim_gate(method, baseline, protocol, audit, gamma=0.05, beta=0.05):
    crep = reproduction_certificate(baseline, protocol, k=5, gamma=gamma)
    if not crep.valid:
        return Claim('unresolved', why=crep.why)
    lcb = paired_effect_lcb(method.metrics, baseline.metrics,
                            protocol.blocks, beta)
    if lcb <= crep.tau_rep:
        return Claim('unresolved', why='within_seed_noise')
    if not stratified_nonworsening(method, baseline, protocol.strata):
        return Claim('unresolved', why='worst_stratum_degraded')
    if audit.contaminated(protocol):
        return Claim('frozen', why='contamination')
    return Claim('certified_improvement', effect_lcb=lcb, tau_rep=crep.tau_rep)
```

### IP-64 TCE：认证修复、连续时间 tube、滚动契约与 anytime
```
def certified_trajectory(optimizer, problem, budget, pose_tube, phi):
    xi = optimizer.solve(problem, budget)
    xi_rep, r_repair = certify_or_repair(xi, problem.constraints)
    if r_repair is None:
        return None                                  # 不可认证修复 -> fallback
    eps_disc = discretization_bound(problem.f, problem.h,
                                    problem.solver_order, problem.T)
    tube = [pose_tube(t) + r_repair + eps_disc + tracking_bound(t)
            for t in problem.horizon]
    for t, T_t in zip(problem.horizon, tube):
        if not forall_in(T_t, phi):                  # 连续时间安全
            return None
    return TrajCert(xi_rep, tube, r_repair, eps_disc)

def receding_horizon_step(cert_i, state, t, budget):
    if t >= cert_i.exec_deadline:
        return fallback(cert_i)                      # 交接前必须已认证
    if state not in cert_i.predicted_reachable(t):
        return fallback(cert_i)                      # 契约 (i) 失效
    next_cert = certified_trajectory(..., budget)
    if next_cert is None:
        return fallback(cert_i)                      # 契约 (ii)(iii)
    return next_cert

def anytime_safe(optimizer, problem, budget, fallback_cert):
    try:
        with timeout(budget):
            c = certified_trajectory(optimizer, problem, budget, ...)
        return c if c is not None else fallback_cert
    except Timeout:
        return fallback_cert                          # 绝不返回未证解
```

### IP-65 EVA：复现红队、轨迹 fuzz、声明回归与谱系
```
def reproduction_redteam(B, claim, protocol):
    findings = []
    for knob in grid_search_free_knobs(B):            # 隐藏旋钮
        if not B.passport.declares(knob):
            findings.append(('undeclared', knob))
    if claim.seed_optimized and protocol.preseeded:
        findings.append(('seed_fishing', claim.seed_range))
    if overlaps(protocol.eval_set, B.train_data):
        findings.append(('contamination', overlap_id))
    if claim.baseline_cfg != B.reference_cfg:
        findings.append(('baseline_sabotage', claim.baseline_cfg))
    return findings

def trajectory_fuzz(tce, problem, n):
    for _ in range(n):
        p = mutate_near_boundary(problem)             # 近边界/退化 QP
        b = random_budget()
        c = tce.certify(p, budget=b)
        if c is not None and not verify_tube_contains_real(c, p):
            return Counterexample(p, 'tube_violation')
        if c is None and not verify_fallback_safe(p):
            return Counterexample(p, 'unsafe_fallback')
    return None

def declaration_regression(claim, hidden_suite):
    return all(claim.gate(p) == 'certified' for p in hidden_suite)
```

def car_transition_guard_v6(e, x, cert_obj, persona, lease_p, lease_c, traj, t):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    if not pose_lease_valid(lease_p, t, theta):
        cascade_invalidate(cert_obj.lease_graph, 'pose')
        return FailClosed('pose_root_invalid')
    if traj is None:
        return FailClosed('solver_infeasible')
    m_lookup = cert_lookup_L0(x, stratum=x.stratum).m_lo[e]
    m_lease  = lease_c.m - lease_c.lam * (t - lease_c.tau)
    m_cap    = persona_cap[e](persona)
    m_traj   = L_phi[e] * (geodesic_radius(cert_obj.pose_cert)

    return min(m_lookup, m_lease, m_cap) - m_traj >= theta

def monitor_step_continuous(traj, t):
    T_t = traj.tube_at(t)                             # 连续时间 tube

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-63 护照/协议 | O(knobs + |P|) | O(护照) | 未声明旋钮/不变量不等 ⟹ 无效或仅条件比较 |
| IP-63 噪声地板 τ_rep | O(k²·B) | O(k) | 同配置换种子 ⟹ 零假设的真实抖动 |
| IP-63 效应下界 | O(B log B) | O(B) | 块感知单侧界 ⟹ 假阳性受 β 控制 |
| IP-63 声明闸门 | O(|A|+B) | O(claim) | 四条件全过才可称「提升」，否则「未决」 |
| IP-64 认证修复 | O(|C|·d) | O(ξ) | 修复后 g(ξ̃)≤0 且 ‖ξ̃−ξ‖≤r_repair |
| IP-64 连续 tube | O(|horizon|·d) | O(|horizon|) | 四界叠加 ⟹ x(t)∈T(t) |
| IP-64 轨迹 □ 提升 | O(|horizon|·|φ|) | 同证书 | φ^□(T(t)) ∀t ⟹ 连续执行安全 |
| IP-64 滚动契约 | O(V+E) / 交接 O(1) | O(证书链) | 契约成立 ⟹ 拼接执行安全 |
| IP-64 anytime | O(budget) | O(1) 额外 | 超时 ⟹ 返回预证 fallback，绝不未证 |
| IP-65 复现红队 | O(knobs·|A|) | O(findings) | 隐藏旋钮/钓鱼/削弱可检出 |
| IP-65 轨迹 fuzz | O(n·certify) | O(n) | 近边界/限时下 tube 越界或 fallback 失效可检出 |
| IP-65 声明回归 | O(|hidden|·gate) | O(1) | 任一隐藏项失败 ⟹ 冻结声明 |

## 4. 实验设计（E103–E110，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E103 基线复现保真度 | 同协议重跑误差 \|m_rerun−m_reported\|；协议违例检出；隐藏旋钮发现率 | <τ_rep；≥95%；≥90% |
| E104 复现噪声与效应下界 | τ_rep 估计稳定性；噪声当提升的假阳性率；真实 Δ=2τ 检出功效 | 变异<20%；<5%；≥80% |
| E105 轨迹证书 soundness | 100h 连续时间违例；tube 对真实轨迹包含率；修复后可行率 | 0 起；100%；≥99% |
| E106 求解器残差/离散化界 | r_repair 上界不越界率；ε_disc 估计误差；r_track 标定误差 | 100%；<20%；<20% |

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 连续时间 tube 在接触/非光滑/长 horizon 下指数膨胀至 vacuous | 高 | E105/E106 红线；分段短 horizon；接触段专用界；不可界则降速/停机 |
| 复现噪声地板过大，真实提升无法过闸门 → 方案 sound 但无用 | 高 | E104 红线；配对种子降方差；报告「未决」而非硬凑；只在可分辨层声明 |
| 「严谨」演化为缩窄 Q / 放宽 b 的评测层 Goodhart | 高 | E103/E109/E110 红线；预注册 Q 与 b；EVA 检测分布与预算匹配 |
| 隐藏旋钮/基线削弱导致比较失真 | 高 | E103/E110；护照强制声明；自动枚举旋钮；基线配置公证 |
| 认证修复改变轨迹导致性能下降甚至不可行 | 中-高 | 报告 r_repair 与代价；修复失败即 fallback；修复量进 margin |
| 滚动交接高频失败 → 频繁停机 | 中-高 | E107；预测可达集保守估计；提前认证；分级降级 |
| 求解器限时返回不可行解被误当已证 | 高 | 定义 53 anytime 安全；超时即 fallback；E108 红线 |
| 轨迹分布复现成本高（多预算多 Q 重跑） | 中 | 配对种子；分层抽样；缓存与谱系复用 |
| 证据谱系本身庞大且可能被篡改 | 中 | 哈希链 + 只追加；EVA 抽查重放；与 CKB 同源 |

## 6. 本轮最大风险

**一句话**：连续时间 tube 依赖 Lipschitz/积分阶/修复界，而这些在接触、非光滑动力学与长 horizon 下会指数膨胀至 vacuous，同时复现噪声地板可能大到任何真实提升都无法通过声明闸门——于是方案「sound 但无用」，并诱使我们在「严谨」的名义下悄悄缩窄问题分布 Q 或放宽预算 b，制造出评测层的 Goodhart：证书和比较都成立，但只在一个被精心挑选的世界里成立。
