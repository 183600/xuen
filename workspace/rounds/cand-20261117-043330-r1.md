# 第 11 轮（新灵感循环第 1 轮；本轮灵感：「能耗优化」×「故障诊断」）
> **基线**：第 10 轮 MetricVoiceGauge-NCD（定义 540–553；引理 87–95；实验 E571–E588），其下为 v9 ACMD / v8 DA-SPR-Cal。九不变式全部保留（其中 FaultCert 只**强化**不放宽）。
> 本轮纪律：**资源约束 + 健康诊断**。不推倒 v10：规范盾、故障盾、能量盾都是**单调删除**算子；能量证书与诊断证书只做合取检查、只删候选、只重排序，绝不绕过 v10 任何既有证书；新组件失效即注入中立元、严格退回 v10（引理 100），再沿 v10 九级链退回 v9/v8/v7/v6。本轮只做三件事：给"能量"发证书、把"故障检测"升级为"故障诊断"、让"节能"与"诊断"在因果上不再互相遮蔽。

## 0. 直觉与动机

**灵感 1（能耗优化）——能量不是一个代价项，而是一张会耗尽的证书。**
直觉：v10 把"能不能做"写成了空间证书与接触证书，但那都是**状态可行性**，没有任何一层回答"我做完这块还回得去吗？电还够吗？算力本身耗的电值得吗？"。真实机器人最典型的失败之一不是撞了，而是"任务做成了却卡在半路没电/过热"，或"为了省电把安全算力也省掉了"。核心创新：**能量账本引擎（EnergyLedgerEngine, ELE）**。把能量拆成运动/操作/计算/感知/热五个分量的账本 L_t；定义边际能效 η=任务进展/焦耳；定义**能量证书** Ĉ_E 与**能量安全返航不变式** E_safe(s)（"从 s 出发、按已认证方式安全停靠所需的最坏能量"）。关键点：能量像安全一样是**前向递归可达性**问题——块可执行当且仅当执行后仍落在能量安全集 S_E 内，且块内存在能量中止点 P^e。更进一步，规划器**自身**的算力也耗能，所以设"计算能量预算" E_comp：安全守卫算力**不可被节能优化挪用**（防优先级反转），节能只在松弛预算里做 anytime 决策。能量回答"我能不能持续做、以多大代价做"。

**灵感 2（故障诊断）——诊断是因果预测的反演，能量是健康的投影。**
直觉：v10 的 FaultCert 只做"有没有故障"的二值检测然后急停；真实系统需要"哪坏了（隔离）、坏多少（辨识）、还能撑多久（预测）"。核心创新：**故障诊断引擎（FaultDiagnosisEngine, FDE）**，把 FaultCert 从检测升级为**检测→隔离→辨识→预测**四级：残差/CUSUM 检测、贝叶斯故障树隔离、故障参数辨识、RUL（剩余寿命）分布预测。深层观察：v10 的 CWM 是**前向因果**（do(π) 预测结果），诊断是**反向因果**（从症状反推病因）——二者是同一 SCM 的对偶。因此诊断天然复用 v10 的 SCM/CAE，只是把"模块归因"换成"故障归因"。并且：**能量是健康的可观测量**——部件磨损/摩擦增大/电池老化首先表现为能效下降。这给了 FDE 一个免费的高信噪比通道，也埋下本轮最大的坑（见下）。故障回答"是否带病、还能撑多久"。

**两者如何统一——节能与诊断是一对张力。**
最关键的洞察：**可诊断性需要激励（费能），而节能恰好抑制激励（掩盖故障）**。诊断要看清故障，必须在输入空间里"抖动"（变速、变载、探测性动作）以获得可辨识性；而激进的节能策略把动作压到平滑、低幅、低载的窄流形上，使故障特征**不可观**——系统越省电，越"健康盲"。反过来，故障会让能效下降，但能效下降也可能是"任务/域变难"或"我主动降载节能"造成的，三者被同一个动作策略混杂。于是本轮不是给 v10 打两个补丁，而是提出**可诊断性能耗（Diagnosability-Aware Energy）**：在能量预算内保留**有界激励/巡检**，用 v10 的因果模型把"能效异常"在故障/上下文/节能模式三者间做因果归因，并把健康损耗（RUL 折减）计入能量目标——**不省出带病运行，也不为诊断无谓烧电**。三者共享同一块级接口 ζ=(skills, Ĉ_safety, Ĉ_contact, Ĉ_norm, Ĉ_E, Ĉ_F, P)：规范盾删"社会不允许"、故障盾删"身体做不到"、能量盾删"资源撑不住"，三盾皆为单调删除、可交换、可退化。

## 1. 研究问题（轮次升级版）

- **Q1（能量证书与返航不变式）**：如何把"做完还回得去"写成可在线检查、可证明的安全约束，并让计算能量预算在不饿死安全算力的前提下参与决策？
- **Q2（故障诊断与带病运行）**：如何在未知故障、sim-to-real 差距与部分可观测下，给出可校准的隔离后验与 RUL 下界，并用它门控块长/技能集而不是简单急停？
- **Q3（可诊断性-能耗权衡）**：节能策略会降低故障可观测性；如何定义并在有界能量内维持可诊断性，使"越省电越健康盲"不成立？
- **Q4（耦合与可识别）**：当能效异常同时可由故障、域偏移、主动节能解释时，如何用因果调整去混杂？三盾同时收紧时如何保证不僵死、且不把"节能"误做成"过维护"？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 能量证书律（Energy Certification, ELE）**
任何块必须携带能量证书 Ĉ_E；只有执行后仍处于能量安全集 S_E、且块内存在能量中止点 P^e 才可执行。能量优化只能删候选或改评分，不得放宽物理/接触/规范证书；计算能量优化不得挪用安全守卫算力（安全算力是非抢占保留项）。

**P17 诊断完备律（Diagnosis Soundness, FDE）**
故障证书 Ĉ_F 必须显式区分 healthy / degraded-within-envelope / fault / unknown 四态；unknown 一律按最坏情况收紧包络。RUL 用下置信界门控块长；诊断必须附带识别假设标签，不可识别时给保守界，禁止把"能效低"直接当故障。

**P18 可诊断性能耗律（Diagnosability-Aware Energy, EFC）**
能量最优策略不得使关键故障集 Φ_crit 的可诊断性低于 D_min；若低于，必须在预算 E_exc 内安排有界激励/巡检。能效异常的归因必须对动作策略与上下文做因果调整（do/后门/IV），并把健康损耗计入目标（防"省电省出大修"）。

## 3. 与基线的接口（如何退化）

- ELE 失效 ⇒ 能量中立元（E≡∞、M_E 关闭、η≡1、P^e≡P^nav），**等价 v10**；
- FDE 失效 ⇒ FaultCert 退回 v10 二值检测、RUL 门控关闭、故障盾退化为 v10 回退条件，**等价 v10**；
- EFC 失效 ⇒ 能量层与诊断层独立合取、跨诊断退化为"存疑即按故障收紧"的保守规则（Level-1，v11-uncoupled）；
- 三者全失效 ⇒ 严格退回 v10（引理 100），再沿 v10 九级链退回 v9/v8/v7/v6；
- **安全继承**：三盾皆为单调删除（A_soc∩A_health∩A_energy），只删不加；能量/健康证书是合取项，任何人都不能把未过 v10 证书的块放行（引理 97）。

## 4. 预期贡献

1. **能量证书与返航不变式**：把能量提升为可递归检查的一等安全资源，含分项账本、边际能效、能量中止点与非挪用计算预算；
2. **诊断即因果反演**：把 FaultCert 从二值检测升级为检测-隔离-辨识-预测，复用 v10 SCM 做故障归因与 RUL 门控，覆盖 v10 完全未建模的"带病运行"；
3. **可诊断性能耗**：显式刻画"节能掩盖故障"的张力，给出有界激励与因果去混杂的可诊断性维持机制；
4. **三盾统一的规范-健康-资源规划**：E589–E604 覆盖能量安全、诊断精度、可诊断性-能耗 Pareto、带病运行与端到端续航任务。

## 5. 本轮最大风险

**一句话**：能效异常是"真实故障、任务/域变化、主动节能"三者的共同症状，且三者被同一个动作策略混杂；一旦交叉诊断把"节能导致的可观测性下降"误当成健康、或把"真实故障的能效下降"误当成节能机会继续压榨，系统就会在**看起来最省电的时候最接近不可逆的带病崩溃**——即"高效地健康盲"。

**定义 554（能量账本 Energy Ledger）** 能量状态满足
```
E_t = E_{t−1} − ℓ_loco − ℓ_manip − ℓ_comp − ℓ_sense − ℓ_thermal + r_t ,  r_t ≥ 0 为充电
```
分项皆由动作 a_{t−1}、负载与状态决定。能量模型 ê(π|s) 满足 |ê(π|s) − Σℓ(π|s)| ≤ β_E(s)。L_t 的五维向量用于定义 564 的诊断（不同故障有不同的"耗电指纹"：摩擦↑→ℓ_manip↑且热↑；电池老化→同任务 ℓ_total↑；传感器故障→ℓ_sense 异常）。

**定义 555（能量安全集与返航不变式 Energy-Safe Set）**
```
E_safe(s) = inf_{π_ret ∈ Π_cert(s)}  sup_{model 不确定}  Σ_{步} (ê + β_E)
S_E(E_t) = { s : E_safe(s) + E_margin ≤ E_t }
```
Π_cert(s) 为从 s 出发、通过 v10 物理/接触/规范证书且满足硬规范的停靠/返航策略集；不要求最短，只要求**存在**。边界 E_safe(s_dock)=0。E_safe 由离线值迭代预计算成表，在线只查表 + 局部修正。

**定义 556（能量证书 Energy Certificate）** 对候选块 π^{1:K} 从 s_t 出发：
```
Ĉ_E(π|s_t) = ( Ê_cost = Σ_k ê(π_k|s_k)+β_E ,  Ê_after = E_t − Ê_cost ,
              Ê_safe = E_safe(s_{t+K}) ,  P̂_deplete = P(Ê_after < Ê_safe+E_margin) ,
              T̂_thermal = max_k T̂_k ,  η̂ = ΔP(π)/Ê_cost )
```
有效 ⇔ `Ê_after ≥ Ê_safe + E_margin ∧ P̂_deplete ≤ ε_E ∧ T̂_thermal ≤ T_max ∧ P^e(π) ≠ ∅`。
能量证书与 v10 的物理/接触证书是**合取**关系；能量只做删减或评分，不得放宽任何既有证书。

**定义 557（能量中止点 Energy-Safe Abort Point）**
```
P^e(π) = { p∈[1,K] : E_t − Σ_{k≤p}(ê_k+β_E) ≥ E_safe(s_p)+E_margin
                     ∧ v10 物理/接触/规范证书在 s_p 仍成立 }
```
导航中止点 P^nav（v9 定义 534）与接触中止点 P^c（v10 定义 548）是"状态安全"，P^e 是"资源 + 状态安全"。块可执行的必要条件升级为：**当前模式对应中止点非空 ∧ 能量中止点非空**。

**定义 558（计算能量预算与决策能效 Decision Energy Budget）**
```
E_comp(Δ,n,K) = a₀ + a₁·n·K + a₂·Δ          # Δ 为 anytime 推演深度
E_opt = E_budget − E_safety_reserved          # 安全守卫算力非抢占保留
Δ* = argmax_{Δ: E_comp(Δ,n,K) ≤ E_opt} [ E[V(Δ)] − λ_E·E_comp(Δ) ]
η_dec = ΔE[V] / ΔE_comp
```
`E_safety_reserved` 由 50Hz 守卫链最坏执行时间折算，**永不被节能优化挪用**（防优先级反转）。OTL 的时限契约同时是 E_comp 的硬约束。

**定义 559（健康状态、故障模式与退化动力学 Health Dynamics）** 隐健康 h_t∈H，故障模式 φ∈Φ∪{φ_⊥}。退化与症状：
```
h_{t+1} = f_h(h_t, a_t, ξ_t)          # a_t 的应力 stress(a_t) 加速或减缓退化
σ_t     = g_σ(h_t, a_t, x_t) + ν_t    # 症状含 L_t（能量签名）
```
关键：σ_t 同时依赖 **h_t（健康）**、**a_t（动作/降载策略）**、**x_t（上下文/域）**。因此"能效低"是 h、a、x 的**共同后果**，天然混杂——这正是定义 564 要用因果调整的原因。

**定义 560（故障诊断四级 Four-Stage Fault Diagnosis）**
- **检测**：健康残差 r_t = σ_t − ŝ_t(h=healthy, a_{1:t})；CUSUM/GLR 探测突变，报警时刻 t_a。
- **隔离**：贝叶斯故障树/BN 给 P(φ | σ_{1:t_a}, a_{1:t_a})，取 top-k 模式与后验熵。
- **辨识**：θ̂_φ = argmax_θ p(σ_{1:t_a} | φ, θ, a)。（如摩擦系数、电池内阻、传感器偏置）
- **预测**：p(RUL | φ̂, θ̂, history)，报告 α-分位下界 `RÛL_lo`。
未知故障 φ_⊥：用非参数退化包络 + 最坏斜率外推，不假设具体机理。

**定义 561（故障证书 Fault Certificate）** 四态语义：
```
healthy            : P̂_fault ≤ ε_F0 ∧ RÛL_lo ≥ T_horizon
degraded-in-envelope: φ̂ 已知 ∧ RÛL_lo ≥ RUL_min(π)        # 允许受限包络内的块
fault / danger     : RÛL_lo < RUL_min(π) 或 P̂_fault 越阈    # 只允许终止/维修/恢复技能
unknown            : 检测到异常但隔离不唯一 ⇒ 保守子集，禁用高应力技能
```
`RUL_min(π) = duration(π) + duration(安全中止) + margin`。原 FaultCert 的报警与回退条件全部保留为其子集（fault 态至少和 v10 一样严）。

**定义 562（故障盾 Health Shield）**
```
A_health(Ĉ_F) = { π∈Π : required_subsystems(π) ∩ failed_subsystems(φ̂) = ∅
                        ∧ stress(π) ≤ stress_env(φ̂, RÛL_lo)
                        ∧ (Ĉ_F=healthy ∨ RÛL_lo ≥ RUL_min(π)) }
```
单调删除。示例：某指故障⇒在手操作技能被删；电池 SoH 低⇒高功率/高加速度块被删；未知故障⇒只保留标称包络内技能。

**定义 563（三盾可行集与能量可行情形式 Tri-Shield Feasible Set）**
```
A_v11(s,b,Ĉ_F,Ĉ_E) = A_soc(b) ∩ A_health(Ĉ_F) ∩ A_E(s,E_t) ∩ C_v10
```
`C_v10` 为通过 v10 物理/接触/规范证书的候选；三盾皆为单调删除，交运算可交换。若 A_v11=∅，沿**回退阶梯**（每级都须自身通过能量证书与 v10 证书）：
1. `a_ask`（v10 认知恢复，若能量可行）；
2. `a_retreat`（能量可安全的返航/停靠）；
3. `a_land`（受控停机/原地释放，若在接触态则先 hold→place）；
4. `a_beacon`（低功耗求救/上报，进入最低功耗守候）。
此阶梯保证**不因等待/询问直到没电**而僵死（对应引理 98 的能量活性）。

**定义 564（能效异常与交叉诊断 Energy-Fault Cross-Diagnosis）**
能效异常事件 `A_E(t) ⇔ η̂_t < η_exp(a_t,x_t) − τ_η`。其成因集合 {φ（真实故障）, x（任务/域变难）, a（主动降载节能）, 传感器误差}。用 v10 SCM，以 φ 为处理、以 (a,x) 为观测混杂，做后门调整：
```
ACE_φ→η = Σ_{a,x} ( E[η | φ=1,a,x] − E[η | φ=0,a,x] ) P(a,x)
```
h 不可观测时用安全上下文中的**随机化巡检/激励** W 作工具变量（IV），否则报告敏感性界 B_Γ。**反向去混杂**同样关键：诊断不能看 P(σ|φ,a) 的边缘，必须看 `P(σ | φ, do(a))`——否则"为省电而降载"会被误读为"故障好转"或"新故障"。输出 `attr = (P(φ|A_E), 处理假设标签, 界)`，只在可识别时把 A_E 当故障证据；不可识别时只降置信、不硬判。

**定义 565（可诊断性 Diagnosability）** 故障 φ 在策略 π^{1:K} 下的可诊断性取症状分布间的期望 KL（或 φ 的 Fisher 信息）：
```
D_φ(π) = E_{τ∼π}[ KL( p(σ|φ,do(a_τ),x) ‖ p(σ|healthy,do(a_τ),x) ) ]
```
D_φ→0 即"输入不激励该故障 ⇒ 不可观"。节能把 a 压在窄流形上会使 D_φ 下降；这是"越省电越健康盲"的形式化。

**定义 566（可诊断性能耗与有界激励 Diagnosability-Aware Energy）** 维护窗口 T_obs 内的**可诊断性不变式**：
```
∀φ∈Φ_crit : D_φ(π^{1:K}) ≥ D_min   （否则触发激励）
a_exc = argmax_a E[ΔD_{Φ_crit}]  s.t.  v10 证书 ∧ Ĉ_E(a) 有效 ∧ E_cost(a_exc) ≤ E_exc
E_exc ≤ ρ_exc · E_budget ,  ρ_exc 例 2%
```
激励证书：a_exc 必须同时通过物理/接触/规范证书与能量证书，且期望信息增益 ≥ 其能量代价。激励按周期 T_exc 注入（如变速、变载、微幅探测），检测延迟上界 ≤ T_exc + O(1/D_min)（引理 101）。

**定义 567（健康-能量目标 Health-Weighted Objective）** 在 v10 目标上增加能量与健康项：
```
J_v11(ζ|s,b) = E_{M̂}[ Σ_{k≤K} γ^k R_task ] − Σ_{κ≠hard} ω_ν R_ν − λ_E·Ê_cost
               − λ_H·C_maint·E[ΔRUL(π)]                       # 短期焦耳 ↔ 长期寿命
subject to  Ĉ_safety ∧ Ĉ_contact ∧ Ĉ_norm valid（v10 定义 533/534/496）
          ∧ Ĉ_E valid（定义 556） ∧ Ĉ_F admissible（定义 561）
          ∧ D_{Φ_crit} ≥ D_min 或已排定 a_exc（定义 566）
          ∧ E_comp(Δ) ≤ E_opt ∧ p99 ≤ T_otl
```
ζ*=argmax J_v11；`ΔRUL` 为执行该块造成的期望寿命折减（由 stress 积分映射）。λ_H 可由耐久约束 RÛL_lo≥RUL_target 的对偶定标，避免手工调参。若 A_v11=∅，按定义 563 回退阶梯。

**定义 568（v11 中立元表 Neutral-Element Table）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| ELE 能量层 | E≡∞；S_E=全状态；P^e=P^nav；η≡1；E_comp 不计；M_E 关闭 | Level-3（v10） |
| FDE 诊断层 | FaultCert←v10 二值；RÛL_lo≡∞；A_health=Π；四态退化为二元 | Level-2（v10 故障路径） |
| EFC 交叉诊断 | 归因禁用；可诊断性不约束；激励不触发；λ_H=0 | Level-1（独立合取 + 存疑即收紧） |
| v10 六组件 | 沿用 v10 定义 553 中立元 | Level-4…12 |

## 2. 与 v10 的接口（升级定义）

**升级定义 496″（软证书，v11）** 在 v10 六条件（σ<τ_safe ∧ γ_grasp ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid ∧ Ĉ_contact valid ∧ 硬规范未删）上再加：

# IP-363 EnergyLedgerEngine
class EnergyLedgerEngine:
    def __init__(self, esafe_table, beta_E, eps_E, T_max, E_margin,
                 e_budget, e_safety_reserved, rho_exc=0.02):
        self.E_safe = lambda s: esafe_table[s] + E_margin   # 定义 555 预计算表
        self.beta_E, self.eps_E, self.T_max = beta_E, eps_E, T_max
        self.E_budget, self.E_reserved = e_budget, e_safety_reserved
        self.rho_exc = rho_exc

    def update(self, ledger, r=0.0):
        return ledger.E_prev - sum(ledger.L) + r              # 定义 554

    def certify(self, skill_seq, state):
        cost = sum(e_hat(p, state) for p in skill_seq) + self.beta_E
        after = state.E - cost
        need = self.E_safe(state.s_after)
        p_dep = deplete_prob(after, need, self.beta_E)
        cert = EnergyCert(cost, after, need, p_dep,
                          max_thermal(skill_seq), eta_of(skill_seq, cost))
        ok = (after >= need and p_dep <= self.eps_E
              and cert.t_max <= self.T_max
              and self.energy_abort_points(skill_seq, state))   # 定义 557
        return cert if ok else None

    def energy_abort_points(self, skill_seq, state):
        return [p for p in range(1, len(skill_seq))
                if (state.E - sum(e_hat(skill_seq[k], state) for k in range(p))
                    >= self.E_safe(state.s[p]) and v10_certs_hold(state.s[p]))]

    def decision_budget(self):
        return self.E_budget - self.E_reserved              # 定义 558，非抢占

    def excitation_budget(self):
        return self.rho_exc * self.E_budget                  # 定义 566


# IP-364 FaultDiagnosisEngine
class FaultDiagnosisEngine:
    def __init__(self, healthy_model, fault_tree, rul_model,
                 eps_F0, delta_diag, alpha=0.05):
        self.healthy, self.tree, self.rul = healthy_model, fault_tree, rul_model
        self.eps_F0, self.delta_diag, self.alpha = eps_F0, delta_diag, alpha

    def residual(self, obs, action_hist):
        return obs.sigma - self.healthy.predict(action_hist)   # 定义 560

    def detect(self, residual):
        return cusum_glr(residual)

    def isolate(self, sig_hist, action_hist):
        return self.tree.posterior(sig_hist, do_action=action_hist)  # do(a) 去混杂

    def identify(self, fault_mode, sig_hist):
        return argmax_theta(sig_hist, fault_mode)

    def prognosis(self, fault_mode, theta, hist):
        return self.rul.lower_quantile(hist, fault_mode, theta, self.alpha)

    def certify(self, phi_hat, rul_lo, skill_seq, assumption_tag):
        cert = FaultCert(p_fault=phi_hat.prob, mode=phi_hat.mode,
                         rul_lo=rul_lo, assumption=assumption_tag)
        if phi_hat.mode is UNKNOWN:
            return cert.restrict_to_conservative()          # 定义 561 unknown
        return cert if admissible(cert, skill_seq) else cert.as_restricted()

    def health_shield(self, cert, skills):
        return [p for p in skills if p.required <= cert.envelope]  # 定义 562


# IP-365 EnergyFaultCoupler
class EnergyFaultCoupler:
    def __init__(self, cwm, cae, phi_crit, D_min, T_obs, T_exc, lam_H=0.0):
        self.cwm, self.cae = cwm, cae
        self.phi_crit, self.D_min = phi_crit, D_min
        self.T_obs, self.T_exc, self.lam_H = T_obs, T_exc, lam_H

    def is_anomaly(self, eta_hat, eta_exp, tau_eta):
        return eta_hat < eta_exp - tau_eta                    # 定义 564

    def attribute(self, anomaly, a, x):
        est = self.cae.estimate_ace(treatment='fault', outcome='eta',
                                    adjust_on=(a, x))          # 后门/IV/敏感性界
        return Attribution(p_fault=est, tag=est.assumption, bound=est.bound)

    def diagnose_with_do(self, sigma, a, x):
        return self.cae.condition(sigma, do_action=a, context=x)  # 反向去混杂

    def diagnosability(self, policy):
        return {phi: kl_signature(policy, phi) for phi in self.phi_crit}  # 定义 565

    def need_excitation(self, policy):
        return any(d < self.D_min for d in self.diagnosability(policy).values())

    def schedule_excitation(self, state, budget_left):
        if not self.need_excitation(state.policy) or budget_left <= 0:
            return None
        a = argmax_info_gain_over_certified_actions(state)    # 定义 566
        return a if a.cost <= budget_left else None

    def health_cost(self, skill_seq):
        return self.lam_H * CMaint * expected_rul_reduction(skill_seq)


# IP-366 TriShieldHealthEnergyPlanner
class TriShieldHealthEnergyPlanner:
    def __init__(self, ncp_v10, ele, fde, efc, K_max=10):
        self.ncp, self.ele, self.fde, self.efc = ncp_v10, ele, fde, efc
        self.K_max = K_max

    def plan(self, state, belief, delta_dom, tau_dom, trust_ok):
        K = effective_K(delta_dom, tau_dom, trust_ok)         # v10 定义 539
        cands = self.ncp.dsl.sample_skill_sequences(state, K, n=64)

        # 1) v10 证书：物理 ∧ 接触 ∧ 规范
        cands = [z for z in cands if v10_all_certs_valid(z, state)]

        # 2) 能量盾（只删）
        cands = [z for z in cands if self.ele.certify(z.skills, state)]

        # 3) 故障盾（四态诊断，只删）
        cert_F = self.fde.certify(state.phi_hat, state.rul_lo,
                                  state.skills, state.assumption)
        cands = [z for z in cands if z in self.fde.health_shield(cert_F, z.skills)]

        # 4) 规范盾（v10，只删）
        cands = self.ncp.nge.shield(cands, belief)
        if not cands:
            return self.energy_feasible_fallback(state, belief, cert_F)  # 定义 563

        # 5) 因果评分 + 能量/健康项 + 可诊断性
        best = None
        for z in cands:
            pred = self.ncp.cwm.rollout(state, z.skills, z.z)
            if self.ncp.cwm.uncertainty(state, z.skills) > self.ncp.eps_u:
                continue
            score = (expected_task_return(pred)
                     - norm_penalty(z, belief)
                     - self.ele.energy_penalty(z)
                     - self.efc.health_cost(z.skills))
            if best is None or score > best.score:
                best, z.score = z, score
        if best is not None and self.efc.need_excitation(best.policy):
            exc = self.efc.schedule_excitation(best, self.ele.excitation_budget())
            if exc is not None:
                best = best.prepend(exc)                     # 有界激励，仍过全部证书
        return best or self.energy_feasible_fallback(state, belief, cert_F)

    def energy_feasible_fallback(self, state, belief, cert_F):
        for a in (self.ncp.nge.epistemic_recovery(),      # a_ask
                  self.ele.retreat_plan(state),           # a_retreat
                  self.ele.land_plan(state),               # a_land
                  self.ele.beacon_plan(state)):            # a_beacon
            if a is not None and self.ele.certify(a, state) and v10_all_certs_valid(a, state):
                return a
        return self.ele.beacon_plan(state)                # 最坏仍低功耗守候

## 4. 推导

**引理 96（能量证书安全性 / 返航可达）** 设能量模型误差 |ê−ℓ|≤β_E 且 E_safe 为定义 555 的保守值。若块 π^{1:K} 通过 Ĉ_E 且执行中任一点取 p∈P^e，则对任意时刻 t'≤K 均有 E_{t'} ≥ E_safe(s_{t'})+E_margin，故系统始终存在一条通过 v10 证书的返航/停靠路径。证明：对执行步归纳。t=0 由定义 563 初始可行；每步能量下降 ≤ ê+β_E，而定义 556 保证块末 Ê_after ≥ E_safe(s_{t+K})+E_margin；P^e 非空提供中途重启点。若中途故障使实际耗能超 ê+β_E，则触发定义 557 的中止点 p，该点构造要求回到安全集，归纳假设保持。热约束与确定性下界由 T̂_thermal≤T_max 保证。∎

**引理 97（三盾单调性与安全继承 / 无绕过）** 能量盾 A_E、故障盾 A_health、规范盾 A_soc 均为单调删除算子，且 `A_v11 ⊆ C_v10`。故不存在绕过 v10 物理/接触/规范证书的执行路径；在 v10 子集上 v10 的物理安全继续成立。证明：定义 562/563 中 A_health 与 A_E 只按附加谓词过滤，不新增候选；A_v11 先取 C_v10 再交三盾，故为子集。与 v10 引理 95 逐条合并即得。∎

**引理 98（诊断去混杂与误诊界）** 若 (a,x) 满足 (φ,η) 的后门准则，定义 564 的调整式一致估计 ACE_φ→η；若 h 不可观测而巡检激励 W 满足 IV 条件（相关性、排他性、单调性），则 IV 估计一致；否则 |ACE_obs−ACE| ≤ B_Γ(Γ)。因此"能效低⇒故障"只在可识别时作为证据，不可识别时仅降置信。反向：对 a 使用 do(a) 而非条件 a，消除"降载节能"对诊断的混杂。证明：前两式为标准后门/IV 定理；第三式由 Rosenbaum 敏感性模型展开；反向由 do-算子的截断公式即得。∎

**引理 99（RUL 门控的带病运行安全）** 设 RÛL_lo 为 RUL 的 α-分位下界（P(RUL≥RÛL_lo)≥1−α），退化单调，块只在 `RÛL_lo ≥ RUL_min(π)` 时执行。则块内发生灾难性失效的概率 ≤ α+ε_diag，其中 ε_diag 为隔离/辨识误差上界。证明：若 RUL≥RUL_lo 且 RUL_lo≥duration+中止时长，则块及其安全中止都能在失效前完成；失败只可能来自 RUL 分位违背（概率 ≤α）或诊断模型误差（≤ε_diag），并集界。∎

**引理 100（中立元退化等价 v10）** 将定义 568 的 ELE/FDE/EFC 中立元分别注入能量端口、健康端口、耦合端口，则 A_v11=C_v10、J_v11=J_v10、主闭环调用序列与 v10 逐位一致（仅调度顺序可交换）。证明：ELE 中立元使能量证书恒真、P^e=P^nav、η 不进入评分；FDE 中立元使 Ĉ_F 退化为 v10 二值、A_health=Π、RUL 门控关闭；EFC 中立元使 λ_H=0、无激励、无跨诊断。三个端口互不相交（耦合端口依赖健康端口，健康端口退化时耦合端口随之退化），逐端口代入即得 v10 程序，再由 v10 引理 93 继续退回 v9/v8/v7/v6。∎

**引理 101（可诊断性维持的能量下界与充分调度）** 在 Fisher 信息症状模型下，维持 D_φ≥D_min（φ∈Φ_crit）所需的最小激励能量满足 Cramér–Rao 下界 `E_exc ≥ c·D_min²/I_max`，其中 I_max 为单位激励能量可产生的最大 Fisher 信息；反之，每 T_exc 注入能量 E_exc≥E_min 的受证激励，可使检测延迟 ≤ T_exc + O(1/D_min)。故存在**有限**能量预算维持可诊断性；而零激励的纯节能策略对输入不敏感故障有 D_φ→0（不可观）。证明：Cramér–Rao 给出 φ̂ 方差下界 1/D_φ，要求方差 ≤1/D_min 即得能量下界；充分性由周期性激励下的信息累积与 GLR 平均检测延迟公式得到。∎
**推论 101.1**：这精确刻画了"节能↔健康盲"的张力：把 E_exc 设为 0 就把 D_min 设为 0；EFC 的作用是在两者之间选一个有界工作点，而不是二选一。

**引理 102（诊断状态迟滞与无抖振）** 若 Ĉ_F 的状态切换（healthy↔degraded↔fault/unknown）带 Schmitt 迟滞（P̂_fault 与 RÛL_lo 各设进入/退出双阈），则健康盾的切换存在最小驻留时间，不产生 Zeno 抖振；激励调度单独计时、不触发盾切换。证明：双阈使任一方向的切换需越过带宽，单次穿过至少耗时由残差变化率下界给出；激励只改动作不改证书状态，二者正交。∎

**引理 103（能耗-预算守恒与优先级）** 新增在线成本上界：ELE 账本 O(d_L)≤0.05ms、证书 O(K)≤0.2ms；FDE 检测 O(d_σ)≤0.1ms，隔离/辨识/预测每 T_f 一次、均摊≤0.2ms；EFC 每 T_c 一次、均摊≤0.1ms；激励极低频、均摊≤0.05ms。总量满足 p99≤20ms、50Hz 不丢拍；安全守卫链算力由 E_safety_reserved 非抢占保留，节能优化只用 E_opt，故无优先级反转。总能耗开销 ≤ ρ_total（例 3%）于 v10。证明：逐项代入复杂度表并对决策侧做静态 EDF 校验与功率预算校验；非抢占保留使最坏响应时间与 v10 相同。∎

## 8. 已知风险与失效模式

1. **能量模型与 E_safe 低估**：域偏移使 ê 偏小、β_E 不足，引理 96 失效。缓解：保守 β_E、在线账本残差监测、E_margin 随 Δ_dom 增大。
2. **故障签名库不完备**：未知故障 φ_⊥ 的保守包络可能过紧（任务停滞）或过松（漏报）。缓解：四态显式建模、非参数包络、未知即禁高应力技能、人工复核出口。
3. **可诊断性-能耗权衡误设**：D_min 太高⇒频繁激励费能，太低⇒健康盲。缓解：E598 Pareto 标定、按 Φ_crit 分级设 D_min、激励证书记录性价比。
4. **能耗异常三源混杂**：故障 / 域变难 / 主动节能均可致 η 下降；后门/IV 假设不成立时归因错。缓解：独立证据（振动/热/电流指纹）、do(a) 去混杂、不可识别只降置信不硬判、E596/E597 专项。
5. **健康-能量目标错配**：λ_H 过小⇒省出带病运行；过大⇒过度保守、任务失败。缓解：用耐久约束对偶定标、RUL 门控兜底、长跑看 RUL 趋势。
6. **三盾同时收紧导致僵局**：规范+健康+能量一起删空可行集。缓解：定义 563 能量可行情形式阶梯、预留返航能量、a_ask 本身须能量可行、对抗性歧义超时升级。
7. **诊断/激励的实时与功率挤占**：FDE/EFC 与安全守卫争算力或耗电。缓解：非抢占 E_safety_reserved、FDE 低频、ICP/诊断离线、静态 EDF 与功率预算校验。

## 9. 本轮最大风险

**一句话**：能效异常是"真实故障、任务/域变化、主动节能"三者的共同症状，且三者被同一个动作策略混杂；一旦交叉诊断把"节能导致的可观测性下降"误当成健康、或把"真实故障的能效下降"误当成节能机会继续压榨，系统就会在**看起来最省电的时候最接近不可逆的带病崩溃**——即"高效地健康盲"。
