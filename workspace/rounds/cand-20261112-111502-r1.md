# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；本轮灵感：「末端执行器控制」×「云边协同」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「执行层→证据层」升级为「认知驱动的场景-执行闭环」，但**三个结构性局限**仍未解决：
> 1. **K_safe 只是“被编译出的阻抗”，不是“末端物理上能实现的阻抗”**：EEIS 编译出的 K_safe 在末端执行器处受关节力矩上限、传动摩擦/回差、控制带宽、接触稳定性共同约束；K_safe 可能**根本落不进末端可实现集**，系统却仍能产出“证据链完整”的假象。
> 2. **云边时间尺度失配未被纳入安全**：云端以 1–10 Hz 做全局场景/意图推理，边缘以 ~1 kHz 做力控；第 60 轮 EPIR 只做“证据回传”，没有回答“云端命令在边缘是否仍然新鲜、是否可实现”。一条 200 ms 前的 K_des，可能在边缘已是危险的。
> 3. **“证据链完整”≠“物理实现正确”**：EPIR 能证明消息没丢、顺序没错，却不能证明 `K_real ≈ K_des`；最危险的状态是“证据全绿、阻抗根本没实现”。

## 0. 直觉与动机

**灵感 1（末端执行器控制 → 可实现阻抗包络 ERIE）**
直觉：阻抗不是控制器的“愿望”，而是执行器的“能力”。给定关节力矩上限 τ_max、传动摩擦/回差、接触环境刚度 K_e 与控制时延 T_d，末端能稳定实现的刚度是一个**有上下界的集合** R：
- 刚度太低 → 摩擦死区与回差淹没力信号，力控“看不见”接触；
- 刚度太高 → 力矩饱和，且与 K_e 耦合后离散采样导致接触振荡；
- 变化太快 → 执行器带宽跟不上，阻抗切换出现“瞬态空窗”。
关键洞见：**把“安全阻抗”重新定义为“可实现集 R 中的阻抗”**，并用谱投影 Π_R 把云端愿望投影到 R；**可实现裕度 m_R** 成为与 K_safe 同等重要的安全量。

**灵感 2（云边协同 → 云边阻抗契约 CEC）**
直觉：云端不该“写执行器寄存器”，而应“提交一份带时效的契约”。契约不是单个 K_des，而是 `(K_des, ε_gap, TTL, 版本, 模式)`：边缘是 R 的**唯一权威**，收到契约后做三件事——验版本、验时效、投影到 R——再回传 `(K_real, ρ, R_hash)`。关键洞见：**边缘主权（edge sovereignty）**——即使云端有 bug 或被攻击，边缘输出的 K_real 恒在 R 内，物理安全不依赖云端的正确性。

**灵感 3（两灵感合流 → 双时间尺度安全治理 DTG）**
直觉：云边是两个时间尺度。云端契约有 TTL，边缘在每个 1 ms 周期里检查“新鲜度 f(t)=exp(−(t−t_c)/TTL)”；f 低于阈值即回退到本地安全阻抗 K_edge^safe。同时边缘跑一个**独立于云端的能量/无源性监视器**：若接触能量注入异常，则无论云端说什么都降刚度、增阻尼。关键洞见：**安全必须在边缘自治，性能才交给云端协同**。

**灵感 4（实现差 → 实现差证据 RGE 与云边能力对账 CRC）**
直觉：K_real 与 K_des 的差不是“误差”，而是**可归因的证据**：是力矩饱和？稳定性上限？摩擦下限？还是带宽滞后？把 gap 分解成 ρ_τ/ρ_stab/ρ_min/ρ_bw 回传云端，云端据此维护自己的**能力信念 R̂_cloud**，并在规划时把 K_des 限制在收缩后的可信集 T_cloud 内。关键洞见：**云边协同的本质是“能力对账”**——云端越了解边缘的真实包络，投影率越低、性能越好。

**灵感 5（预算 → PCE+++++）**
直觉：第 60 轮的 B_cog 不含“末端执行”和“云边同步”两类持续消耗。扩展为 **B_cog+ = (B_scene, B_intent, B_ros, B_exec, B_ee, B_ce)**：B_ee 限制力矩裕度、调制带宽、热裕度与探针能量；B_ce 限制契约带宽、同步时延、版本陈旧度与 TTL 预算。B_ee 耗尽 ⇒ 冻结在 K_edge^safe；B_ce 耗尽 ⇒ 延长 TTL、降低云端置信、边缘本地闭环。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（末端可实现阻抗包络 ERIE）** 设边缘状态 s_e = (q, q̇, τ, h_tool, K_e, T_e, T_d)，末端目标刚度为对称正定阵 K。定义可实现集：
```
R(s_e) = { K ≻ 0 : λ_min(K) ≥ K_min(h_tool)
                  ∧ λ_max(K) ≤ K_max^τ(s_e)
                  ∧ λ_max(K) ≤ K_max^stab(K_e, T_d, T_e)
                  ∧ K ∈ P_passive }
```
其中
- `K_max^τ(s_e) = sup{ k : max_{‖Δx‖≤δ_task} ‖J^{-T}(q) k Δx‖_∞ ≤ τ_max }`，由力矩上限决定；
- `K_max^stab(K_e,T_d,T_e)` 为离散阻抗控制与环境刚度耦合的稳定上界（Colgate 无源性条件的采样版本）；
- `K_min(h_tool)` 为摩擦死区/回差决定的刚度下限；
- `P_passive` 为无源阻抗集合。
- **谱投影**：对 K_des = UΛU^T，`Π_R(K_des) = U · clip(Λ; K_min, min(K_max^τ, K_max^stab)) · U^T`。若 R 可表为特征值区间，谱投影即精确欧氏投影。
- **可实现裕度**：`m_R(K) = min{ 1 − λ_max(K)/K_max^τ, 1 − λ_max(K)/K_max^stab, λ_min(K)/K_min − 1 }`。
- **变化率约束**：`K̇_r = (Π_R(K_des) − K_r)/τ_ee`，且 `‖K̇_r‖_F ≤ K̇_max`；带宽不足产生瞬态 gap。

**定义 162（云边阻抗契约 CEC）** 契约 `C_ce = (cid, K_des, ε_gap, TTL, ver_c, ver_e, mode, nonce)`。边缘接受谓词：
```
Accept(C_ce) = [ver_c ∈ V_compat(ver_e)] ∧ [now − t_issue < TTL] ∧ [mode ∈ M_supported]
```
边缘应答 `C_ack = (cid, K_real, ρ, R_hash, m_R, t_ack, sig_e)`，其中 `K_real = Π_{R(s_e)}(K_des)`，`ρ = ‖K_des − K_real‖_F`。
- **契约精化**：`C′ ⊑ C` 当且仅当 `ε′_gap ≤ ε_gap`、`TTL′ ≤ TTL`、且 `K′_des` 的邻域被 `K_des` 邻域包含。
- **边缘主权**：边缘是 R 的唯一权威；云端不得直接写执行寄存器，只能提交契约。
- **语义**：K_des ∉ R 时边缘**不拒绝执行**，而是投影并标记 `PROJECTED`；仅当 `ρ > ρ_max` 或契约非法时拒绝。

**定义 163（双时间尺度安全治理 DTG）** 云端周期 T_c，边缘周期 T_e，`T_c/T_e ≥ N_ratio`（如 100）。
- **新鲜度**：`f(t) = exp(−(t − t_issue)/TTL)`，仅当 `f ≥ f_min` 应用云端契约。
- **治理规则**：
```
K_edge(t) = Π_R(K_des)           if C_ce fresh and accepted
           = K_edge^safe         otherwise (STALE / REJECTED)
K_edge(t) ← shrink(K_edge(t))    if passivity_monitor.unsafe
```
其中 `K_edge^safe = K_abs_safe ∩ R`（承接第 59 轮硬安全集）。
- **独立无源性监视**：窗口能量 `E_int = ∫ F_ext·ẋ dt`，无源残差 `r_p = dE_int/dt − P_inj`；若 `r_p > r_max` 连续 `N_p` 周期，则降刚度、增阻尼，且不受云命令覆盖。
- **陈旧界**：TTL 内无云端更新，边缘必须在一个边缘周期内进入 `K_edge^safe`。

**定义 164（实现差证据 RGE）** 实现差分解：
```
ρ = ‖K_des − K_real‖_F
ρ_τ    = max(0, λ_max(K_des) − K_max^τ)/K_max^τ
ρ_stab = max(0, λ_max(K_des) − K_max^stab)/K_max^stab
ρ_min  = max(0, K_min − λ_min(K_des))/K_min
ρ_bw   = ‖K_real(k) − Π_R(K_des(k))‖_F  (瞬态)
```
`RGE = (cid, K_des, K_real, ρ, (ρ_τ,ρ_stab,ρ_min,ρ_bw), R_hash, flags, t)`，flags ∈ {SATURATED, STABILITY_MARGIN, FRICTION_FLOOR, BANDWIDTH_LAG, STALE}。RGE 不只是误差，而是**下一轮能力对账的输入**。

**定义 165（云边能力对账 CRC）** 云端维护能力信念 `R̂_cloud = (K̂_lo, K̂_hi, K̂_stab)`：
- **保守收缩**：若 ack 中 `ρ > ε_gap`，则 `K̂_hi ← (1−α)K̂_hi + α·λ_max(K_real)`，α∈(0,1)。
- **谨慎扩张**：若连续 N 次 `m_R > m_hi`，则 `K̂_hi ← min(K̂_hi + β, K̂_hi^hard)`。
- **可信集**：`T_cloud = interior(R̂_cloud)` 再收缩安全系数 `(1−γ)`；云端规划约束 `K_des ∈ T_cloud`。
- **一致性**：`κ = 1 − P(ρ > ε_gap)`（滑窗）；云端按 κ 调节信任度（κ 高则扩张，低则收缩）。
- **版本指纹**：`R_hash = H(h_tool, firmware, actuator_params)`；与云端期望不一致即触发工具快换/固件变更的重握手。

**定义 166（PCE+++++ 六维预算）** `B_cog+ = (B_scene, B_intent, B_ros, B_exec, B_ee, B_ce)`：
- `B_ee = (torque_headroom, modulation_bw, thermal_headroom, probe_energy)`；
- `B_ce = (contract_bw, sync_latency, version_staleness, ttl_budget)`。
```
voi_impl(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_ee(π) − cost_ce(π)
cost_ee = λ_τ·max(0, τ_req−τ_max) + λ_bw·max(0, ‖K̇‖−K̇_max) + λ_th·max(0, P−P_th)
cost_ce = λ_ce·(contract_size/BW) + λ_lat·latency + λ_stale·staleness
```
降级：B_ee 耗尽 ⇒ 冻结 `K_edge^safe`，禁止探针；B_ce 耗尽 ⇒ 延长 TTL、降低云端置信、进入本地闭环；其余沿用第 59/60 轮规则。

**定义 167（可实现契约门控 RCG）** 边缘判决规则：
```
s_e ← observe()
R ← ERIE.estimate(s_e)
C ← recv_contract()
if C and Accept(C):
    K_des = C.K_des
    K_real = Π_R(K_des); ρ = gap(K_des, K_real)
    if ρ > ε_gap: emit PROJECTED; request_replan(cid, ρ_decomp)
    K_cmd = K_real
elif C and not Accept(C):
    K_cmd = K_edge^safe; emit REJECTED
else:
    K_cmd = K_edge^safe; emit STALE
if passivity_monitor.unsafe: K_cmd = shrink(K_cmd)   # 云不可覆盖
return K_cmd
```
**核心不变式（边缘主权安全）**：`K_cmd ∈ R(s_e) ⊆ K_abs_safe`，对所有云端命令（含错误/恶意）恒成立。

**定义 168（末端实现证书 J_real）** `J_real = (cid, K_des, K_real, ρ, ρ_decomp, R_hash, m_R, t_issue, t_ack, sig_e, flags, J_exec_ref)`。云端验证条件：
1. `K_real = Π_{R(s_e)}(K_des)`（容差内）；
2. `ρ_decomp` 与 flags 自洽，且 `ρ = ‖K_des−K_real‖_F`；
3. `R_hash` 与最近一次能力握手一致；
4. `J_exec_ref` 存在且可验证（承接第 59 轮 J_exec）；
5. TTL 未被逾越。
全通过才接受；否则标记 `REALIZATION_BREAK`，与第 60 轮 `CAUSAL_BREAK` 并列。

### IP-161 ERIE（可实现阻抗包络）

```python
class EndEffectorRealizableEnvelope:
    def __init__(self, tau_max, k_min_fn, dk_max, tau_ee):
        self.tau_max, self.k_min_fn = tau_max, k_min_fn
        self.dk_max, self.tau_ee = dk_max, tau_ee

    def estimate(self, state):
        J = state.jacobian
        k_tau = self._torque_bound(J, state.tau_max, state.delta_task)
        k_stab = self._stability_bound(state.K_env, state.T_delay, state.T_e)
        return Envelope(lam_lo=self.k_min_fn(state.tool),
                        lam_hi=min(k_tau, k_stab),
                        hash=sha256(state.tool_fingerprint()).hexdigest()[:16])

    def project(self, K_des, env):
        lam, U = np.linalg.eigh(0.5 * (K_des + K_des.T))
        lam = np.clip(lam, env.lam_lo, env.lam_hi)
        K_real = U @ np.diag(lam) @ U.T
        margin = min((env.lam_hi - lam.max()) / env.lam_hi,
                     (lam.min() - env.lam_lo) / env.lam_lo)
        return K_real, margin

    def track(self, K_des, K_r, env, dt):
        K_target, _ = self.project(K_des, env)
        dK = (K_target - K_r) / self.tau_ee
        n = np.linalg.norm(dK)
        if n > self.dk_max:
            dK *= self.dk_max / n
        return K_r + dK * dt
```

```python
class CloudEdgeImpedanceContract:
    def accept(self, c, caps):
        if c.ver_c not in caps.compatible_versions: return False, 'VERSION'
        if now() - c.t_issue >= c.TTL:              return False, 'STALE'
        if c.mode not in caps.modes:                return False, 'MODE'

        gap = gap_decomp(c.K_des, K_real, env)
        status = 'PROJECTED' if gap.total > c.eps_gap else 'EXACT'
        ack = ContractAck(c.cid, K_real, gap, env.hash, margin, now())
        return ack, status
```

### IP-163 DTG（双时间尺度治理）

```python
class DualTimescaleGovernor:
    def __init__(self, f_min, r_max, n_p, edge_safe):
        self.f_min, self.r_max, self.n_p = f_min, r_max, n_p
        self.edge_safe = edge_safe
        self.unsafe_streak = 0

    def freshness(self, c):
        return np.exp(-(now() - c.t_issue) / c.TTL)

    def govern(self, K_cmd, c, energy_monitor):
        flag = None
        if c is None or self.freshness(c) < self.f_min:
            K_cmd, flag = self.edge_safe, 'STALE'
        if energy_monitor.residual() > self.r_max:
            self.unsafe_streak += 1
            if self.unsafe_streak >= self.n_p:
                K_cmd, flag = self.shrink(K_cmd), 'ENERGY'
        else:
            self.unsafe_streak = 0
        return K_cmd, flag

    def shrink(self, K):
        lam, U = np.linalg.eigh(K)
        return U @ np.diag(lam * 0.7) @ U.T + 0.3 * self.damping_boost
```

### IP-164 RGE（实现差证据）

```python
def gap_decomp(K_des, K_real, env):
    lam = np.linalg.eigvalsh(K_des)
    r_tau    = max(0.0, lam.max() - env.k_tau) / env.k_tau
    r_stab   = max(0.0, lam.max() - env.k_stab) / env.k_stab
    r_min    = max(0.0, env.lam_lo - lam.min()) / env.lam_lo
    total    = np.linalg.norm(K_des - K_real, 'fro')
    flags = []
    if r_tau > 0:   flags.append('SATURATED')
    if r_stab > 0:  flags.append('STABILITY_MARGIN')
    if r_min > 0:   flags.append('FRICTION_FLOOR')
    return RealizationGap(total, r_tau, r_stab, r_min, 0.0, flags)
```

### IP-165 CRC（云边能力对账）

```python
class CapabilityReconciler:
    def __init__(self, alpha=0.2, beta=0.02, gamma=0.1):
        self.k_hi, self.k_lo = None, None
        self.alpha, self.beta, self.gamma = alpha, beta, gamma
        self.window = deque(maxlen=100)

    def update(self, ack):
        lam_hi = np.linalg.eigvalsh(ack.K_real).max()
        if ack.gap.total > ack.eps_gap:
            self.k_hi = lam_hi if self.k_hi is None else (1-self.alpha)*self.k_hi + self.alpha*lam_hi
        self.k_lo = self.k_lo or ack.env_lo
        self.window.append(ack.gap.total <= ack.eps_gap)

    def trusted_set(self):
        return (self.k_lo, (1 - self.gamma) * self.k_hi)

    def concordance(self):
        return float(np.mean(self.window)) if self.window else 1.0
```

### IP-166 PCE+++++（六维预算）

```python
class ImplBudget:
    def __init__(self, b_scene, b_intent, b_ros, b_exec, b_ee, b_ce):
        self.B = dict(scene=b_scene, intent=b_intent, ros=b_ros,
                      exec=b_exec, ee=b_ee, ce=b_ce)

    def voi_impl(self, plan, meta_voi):
        return (meta_voi - self._cost_cog(plan) - self._cost_exec(plan)
                - self._cost_ee(plan) - self._cost_ce(plan))

    def allow_probe(self):
        return self.B['ee'].probe_energy > 0 and self.B['ce'].ttl_budget > 0

    def degrade_reason(self):
        if self.B['ee'].probe_energy <= 0: return 'FREEZE_EE_SAFE'
        if self.B['ce'].ttl_budget <= 0:   return 'LOCAL_CLOSED_LOOP'
        if self.B['ros'] <= 0:             return 'LOCAL_LOOP_ONLY'
        return None
```

### IP-167 RCG（可实现契约门控）

```python
def realizable_contract_gate(env, contract, energy_monitor, governor):
    K_cmd, flag = governor.edge_safe, None
    if contract and governor.accept(contract):
        K_real, _ = env.project(contract.K_des)
        gap = gap_decomp(contract.K_des, K_real, env)
        if gap.total > contract.eps_gap:
            emit('PROJECTED', contract.cid, gap)
            request_replan(contract.cid, gap)
        K_cmd, flag = K_real, 'PROJECTED'
    elif contract:
        flag = 'REJECTED'
    else:
        flag = 'STALE'
    K_cmd, gov_flag = governor.govern(K_cmd, contract, energy_monitor)
    return K_cmd, flag or gov_flag
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ERIE | O(m³)/周期（m=6 任务维） | O(m² + N_hist) | 投影后 K_real ∈ R；裕度 m_R ≥ 0 |
| CEC | O(m³)（含投影） | O(1) | 版本/时效/模式三验；非法契约必拒绝 |
| DTG | O(1) | O(1) | TTL 过期 ≤ 1 边缘周期进入 K_edge^safe |
| RGE | O(m³) | O(1) | gap 可归因；ρ 与分解自洽 |
| CRC | O(m³)（低频） | O(N_win) | 一致性 κ 收敛；可信集单调保守 |
| RCG | O(m³)/周期 | O(1) | K_cmd ∈ R ⊆ K_abs_safe（含恶意云端） |

**正确性定理（REIC-Sound）**：假设 A66–A71 成立：
- **(A66) 包络可靠性**：真实可实现集 R_true 满足 R(s_e) ⊆ R_true，且估计误差 ≤ δ_R。
- **(A67) 谱投影一致性**：若 R 可表为特征值区间，谱投影 Π_R 是欧氏投影且唯一。
- **(A68) 无源性充分性**：能量监视器残差 `r_p ≤ r_max` ⇒ 接触闭环无源（采样版本）。
- **(A69) 契约时效**：TTL、版本与回传签名保证“云端命令—边缘执行”的因果与新鲜。
- **(A70) 对账收敛**：CRC 的保守收缩/谨慎扩张使 R̂_cloud 在有限次 ack 内收敛到 R 的保守内近似。
- **(A71) 预算单调**：B_cog+ 各维单调消耗，耗尽必触发对应降级。

则：
1. **边缘主权安全性**：对任意云端命令 K_des（含错误/恶意），`K_cmd ∈ R(s_e) ⊆ K_abs_safe`。
2. **实现一致性**：被接受的 `J_real` 必有 `‖K_des − K_real‖_F ≤ ρ_max`，且 gap 分解可解释。
3. **时效安全性**：TTL 过期或云端静默时，边缘 ≤ 1 个周期回退到 `K_edge^safe`。
4. **协同单调性**：随 ack 累积，投影率 `P(ρ > ε_gap)` 单调不增（在平稳环境下），云端性能趋近 `R_true` 的内边界。
5. **证据完整性**：`J_real` 与 `J_exec`、EPIR 因果链三者可拼接，任何 `REALIZATION_BREAK` 都可定位到具体约束维度。

## 2. 关键推导

### 2.1 刚度上限的两条硬边界

**(a) 力矩边界。** 任务空间小位移 Δx 所需关节力矩 `τ = J^{-T} K Δx`。要求 `‖τ‖_∞ ≤ τ_max` 对所有 `‖Δx‖ ≤ δ_task` 成立，得
```
K_max^τ = τ_max / (‖J^{-1}‖_2 · δ_task)
```
即刚度上限与 `τ_max` 成正比、与任务容差和雅可比条件数成反比。这解释了“越精细的任务，末端越难做硬”。

**(b) 接触稳定边界。** 离散阻抗控制（采样 T_e、时延 T_d）与刚度 K_e 的环境耦合，采用采样无源性条件，稳定上界近似
```
K_max^stab ≈ (2·D_d / T_e − K_e) / (1 + 2·T_d/T_e)
```
刚度越高、环境越硬、时延越大，越容易失稳。故 R 的上界是 `min(K_max^τ, K_max^stab)`，这是“云端愿望”和“末端物理”之间的第一道鸿沟。

### 2.2 谱投影的最优性

若 R 可表为特征值区间 `λ ∈ [λ_lo, λ_hi]^m`，则
```
Π_R(K_des) = argmin_{K∈R} ½‖K − K_des‖_F² = U · clip(Λ; λ_lo, λ_hi) · U^T
```
因为 Frobenius 范数在正交相似变换下不变，问题解耦为 m 个标量区间投影。该式给出 O(m³) 的闭式解（仅一次 `eigh`），满足 1 kHz 边缘实时性。

### 2.3 实现差的保守上界

`ρ = ‖K_des − Π_R(K_des)‖_F ≤ ‖K_des − K_real^true‖_F + δ_R`。当 `ρ ≤ ε_gap` 时，云端可认为契约“基本实现”；当 `ρ > ε_gap` 时，必须把 `(ρ_τ, ρ_stab, ρ_min, ρ_bw)` 回传，作为 CRC 的收缩信号。由此得到契约可接受性的充分条件：
```
Accept_safe(C) ⇔ Accept(C) ∧ ρ ≤ ρ_max ∧ m_R(K_real) ≥ 0
```

### 2.4 TTL 与云边通信的时序约束

设云端推理时延 `L_c`、下行传输抖动 `J_d`、边缘处理时延 `L_e`。要保证“命令在执行时刻仍新鲜”，需
```
TTL ≥ L_c + J_d + L_e + T_c
```
且边缘回退时延 `≤ T_e`。若 `TTL < T_c`，云端每个周期都在“命令过时”状态下运行，DTG 会持续回退到 `K_edge^safe`——这从时序上解释了“为什么云边必须双层闭环，而不能把力控放到云上”。

### 2.5 边缘主权安全定理（非形式版）

对任意 `K_des`，RCG 的输出只可能来自 `{Π_R(K_des), K_edge^safe, shrink(K_cmd)}` 三者；三者都在 R 内（`shrink` 只降刚度、增阻尼，仍在 R 的下界以上），且 `R ⊆ K_abs_safe`（A66）。故边缘物理安全与云端正确性解耦。**这是本轮最重要的结构性结论**：第 59/60 轮的安全依赖“证据正确”，本轮把安全根植于“能力包络 + 本地治理”，证据只负责可审计。

### IP-161 ERIE（可实现阻抗包络）

```python
class EndEffectorRealizableEnvelope:
    def __init__(self, tau_max, k_min_fn, dk_max, tau_ee):
        self.tau_max, self.k_min_fn = tau_max, k_min_fn
        self.dk_max, self.tau_ee = dk_max, tau_ee

    def estimate(self, state):
        J = state.jacobian
        k_tau = self._torque_bound(J, state.tau_max, state.delta_task)
        k_stab = self._stability_bound(state.K_env, state.T_delay, state.T_e)
        return Envelope(lam_lo=self.k_min_fn(state.tool),
                        lam_hi=min(k_tau, k_stab),
                        hash=sha256(state.tool_fingerprint()).hexdigest()[:16])

    def project(self, K_des, env):
        lam, U = np.linalg.eigh(0.5 * (K_des + K_des.T))
        lam = np.clip(lam, env.lam_lo, env.lam_hi)
        K_real = U @ np.diag(lam) @ U.T
        margin = min((env.lam_hi - lam.max()) / env.lam_hi,
                     (lam.min() - env.lam_lo) / env.lam_lo)
        return K_real, margin

    def track(self, K_des, K_r, env, dt):
        K_target, _ = self.project(K_des, env)
        dK = (K_target - K_r) / self.tau_ee
        n = np.linalg.norm(dK)
        if n > self.dk_max:
            dK *= self.dk_max / n
        return K_r + dK * dt
```

### IP-163 DTG（双时间尺度治理）

```python
class DualTimescaleGovernor:
    def __init__(self, f_min, r_max, n_p, edge_safe):
        self.f_min, self.r_max, self.n_p = f_min, r_max, n_p
        self.edge_safe, self.unsafe_streak = edge_safe, 0

    def freshness(self, c):
        return np.exp(-(now() - c.t_issue) / c.TTL)

    def govern(self, K_cmd, c, energy_monitor):
        flag = None
        if c is None or self.freshness(c) < self.f_min:
            K_cmd, flag = self.edge_safe, 'STALE'
        if energy_monitor.residual() > self.r_max:
            self.unsafe_streak += 1
            if self.unsafe_streak >= self.n_p:
                K_cmd, flag = self.shrink(K_cmd), 'ENERGY'
        else:
            self.unsafe_streak = 0
        return K_cmd, flag

    def shrink(self, K):
        lam, U = np.linalg.eigh(K)
        return U @ np.diag(lam * 0.7) @ U.T + 0.3 * self.damping_boost
```

### IP-164 RGE（实现差证据）

```python
def gap_decomp(K_des, K_real, env):
    lam = np.linalg.eigvalsh(K_des)
    r_tau  = max(0.0, lam.max() - env.k_tau) / env.k_tau
    r_stab = max(0.0, lam.max() - env.k_stab) / env.k_stab
    r_min  = max(0.0, env.lam_lo - lam.min()) / env.lam_lo
    total  = np.linalg.norm(K_des - K_real, 'fro')
    flags = []
    if r_tau > 0:  flags.append('SATURATED')
    if r_stab > 0: flags.append('STABILITY_MARGIN')
    if r_min > 0:  flags.append('FRICTION_FLOOR')
    return RealizationGap(total, r_tau, r_stab, r_min, 0.0, flags)
```

### IP-165 CRC（云边能力对账）

```python
class CapabilityReconciler:
    def __init__(self, alpha=0.2, beta=0.02, gamma=0.1):
        self.k_hi, self.k_lo = None, None
        self.alpha, self.beta, self.gamma = alpha, beta, gamma
        self.window = deque(maxlen=100)

    def update(self, ack):
        lam_hi = np.linalg.eigvalsh(ack.K_real).max()
        if ack.gap.total > ack.eps_gap:
            self.k_hi = lam_hi if self.k_hi is None else \
                        (1-self.alpha)*self.k_hi + self.alpha*lam_hi
        self.k_lo = self.k_lo or ack.env_lo
        self.window.append(ack.gap.total <= ack.eps_gap)

    def trusted_set(self):
        return (self.k_lo, (1 - self.gamma) * self.k_hi)

    def concordance(self):
        return float(np.mean(self.window)) if self.window else 1.0

    def check_fingerprint(self, R_hash):
        if self.expected_hash and R_hash != self.expected_hash:
            return 'TOOL_OR_FIRMWARE_CHANGED'
        return 'OK'
```

2. **实现一致性**：被接受的 `J_real` 必有 `‖K_des − K_real‖_F ≤ ρ_max`，gap 可归因。
3. **时效安全性**：TTL 过期或静默时，边缘 ≤ 1 个周期回退 `K_edge^safe`。
4. **协同单调性**：平稳环境下投影率随 ack 累积单调不增，云端性能趋近 R 的保守内边界。
5. **证据完整性**：`J_real × J_exec × EPIR` 可拼接，任一 `REALIZATION_BREAK` 可定位到具体约束维度。

## 6. 与既有轮次的衔接

- **对第 59 轮**：`K_abs_safe` 被细化为 `K_edge^safe = K_abs_safe ∩ R`；`J_exec` 被 `J_real` 补上“实现层”证据。
- **对第 60 轮**：`EPIR` 的因果链新增 `REALIZATION_BREAK` 类型；`XMC+` 的融合可引入“实现差”作为执行模态的新证据。
- **对 UniBot 场景**：云边部署天然契合“云端大模型规划 + 边缘实时力控”，ERIE/CEC/DTG 可直接落到 ROS 2 的控制器切换与 lifecycle 节点上。

## 7. 本轮最大风险

**一句话**：若边缘的“可实现包络 R”本身被错误建模（摩擦/回差/接触刚度估计偏了、工具快换未被 R_hash 检出），那么“边缘主权”会退化为“边缘主权的自洽失效”——边缘会用一套错误的 R 自信地投影、自信地签发 J_real，而物理上正在把系统推向接触失稳；必须以在线激励更新 R、独立无源性/能量监视、云边能力对账的保守内近似与工具指纹重握手四重护栏，确保“可实现”永远是“可验证地可实现”。
