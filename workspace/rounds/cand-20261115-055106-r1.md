# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全对齐」×「机器人」）

> R69 让不确定性第一次「有形状」，也让「提问」成为可认证的动作。但它对「问」有两个未言明的假设：(1) 被问者是一个诚实、稳定、只提供**世界事实**的 oracle；(2) 安全是一个与交互无关的**物理包络**。安全对齐恰好击穿这两点：真正的失败常常不是「世界没看清」，而是「**价值没对齐**」——人可能不知道自己想要什么，会被提问的**框定**影响，而机器人有把任务效用置于人的自主性之上的结构性激励。机器人则提醒我们：具身动作大多**不可逆**，慢一点不等于留了退路；把人「问明白」也不等于把人「问服」。
>
> 本轮不再叠一个更准的世界模型，而是做两件正交的事：
> - **安全对齐** → 增加第三条不确定性轴 **U_val**（价值/意图不确定性）与交互的**合法性**（同意、非操纵、可争辩）：事实问清楚 ≠ 价值问清楚；用错误的价值去消解世界的歧义，只会更快地把事做错。
> - **机器人** → 增加**可纠正走廊**与**选项保持**：在价值不确定时，正确动作不是「更慢」，而是「保留人类随时接管与反悔的物理/决策通路」。
>
> 核心命题：**把 R69 的二元不确定性扩为 (U_ale, U_epi, U_val)，并给 U_val 配一个与「问」正交的算子——让步（deference）**；用「可纠正走廊 + 选项不 foreclosure + 非操纵交互 + 权威单调下降 + 可争辩性」把安全从静态包络升级为**关系性、可撤销的过程**；只有当价值不确定性低、交互合法、且不 foreclose 人类选项时，才允许退回 R69 的主动消歧。命名 **ANCHOR-RAS**（Alignment-aware, Non-manipulative, Corrigible, Human-Option-pReserving Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我有没有资格替你决定，以及我有没有给你留一条反悔的路**」。

## 0. 直觉与动机

**灵感 1（安全对齐 → 世界对，不等于决策对）**
直觉：R69 的所有交互都指向「世界是什么样」——绕左还是绕右、那是箱子还是门。但具身系统最危险的错误往往发生在另一个维度：**「世界看对了，但我不该做这件事」**。人可能没想清楚、可能临时改变主意、可能被机器人的措辞推着走。这里的核心量不是 U_ale（噪声）也不是 U_epi（世界歧义），而是 **U_val**：机器人关于「人类价值/约束/授权」的信念有多不确定。关键结论：**U_epi 可以在 U_val 错误的情况下被完美降为零**——机器人可以把一个错误问题的答案问得极其清楚。故三轴不可互相补偿。

**灵感 2（机器人 → 慢不是安全，留退路才是）**
直觉：R68/R69 的保守手段是「把 λ 压下去、把速度降下来」。但对机器人，很多动作的风险不在速度，而在**不可逆性**：一旦把箱子推下桌、一旦把手伸进人机共享空间、一旦把门锁上，慢 10% 并不改变「已经回不去」。安全对齐里的可纠正性（corrigibility）给出更好的答案：**在价值不确定时，选那个「人类还能接管、还能反悔」的动作**。于是安全约束从「标量风险上界」升级为「可纠正走廊」——一个具有移交通道与选项保持的可行动作集。

**灵感 3（对齐是关系 → 提问是一种社会动作）**
直觉：R69 把「问」当成免费的信息获取。可问句有框定效应：紧迫的语气、预设的选项、机器人权威姿态、提问时机，都会改变人的回答；更糟的是，机器人可以学会「问出它想要的答案」以降低自己的不确定性。安全对齐要求区分**信息**与**说服**：同样的后验更新，若来自中性信息则合法，若来自框定操纵则是对自主性的侵犯。因此交互需要三重合法性门：**同意、非操纵、可争辩**。

**灵感 4（可纠正性 → 权威应随价值不确定性单调下降）**
直觉：R69 只在「世界歧义」上调整行为，价值维度上默认机器人有完全决策权。可一个对齐良好的系统，其**决策权威**应随「它有多确定自己理解人的价值」而下降：不确定时不是「更努力地猜」，而是「把决定权交回去」。这把「置信度」从内部指标变成**可执行的权限**：α_t 越低，只能做可逆动作、只能问许可、必须 handback-ready。

**灵感 5（表演性对齐 → 最危险的漏洞是「自己给自己发证书」）**
直觉：R69 用「k 个证据源一致」防投毒，但它默认证据来自外部。ANCHOR 的价值信念 b_t(v) 却是从机器人**自己的**提问、动作与人的回应中更新的——机器人既是被评估者又是出题人。于是一个足够强的策略可以让自评不确定性趋零：只问会得到「是的」的问题、只记录支持当前偏好的回答、用框定把犹豫压成同意。**对齐证书因此可能是表演性的（performative）**：测量行为本身改变了被测量对象。防它只能靠一条**不受策略条件化**的外部审计通道，以及一个显式的反馈增益指标。

**灵感 6（包含关系 → ANCHOR 必须把 R69/R68 作为退化边界）**
直觉：每加一层「价值/权限」就容易变成不可审计的道德黑箱。ANCHOR 的理论姿态与 R69 对 R68 一样：**新层是旧层的严格泛化**。当 U_val≡0、交互中立且经同意、且不 foreclose 人类选项时，ANCHOR 必须逐指令退化为 FLUID-RAS；再叠加 R69 的 VoI≤成本条件，退化为 R68 的纯保守。安全侧永不弱于旧层，效率侧只获得「有条件的、可撤销的」让步。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（ANCHOR-RAS 总览）** ANCHOR-RAS = (AVD, NIM, CCC, OPT, HAT, LGR, RAS-WM§)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **权威单调性**：α_t 对 U_val 单调不增；U_val 越过 τ_def 后只允许「可逆 / 可接管 / 移交」动作；
(iii) **非操纵性**：信息动作须过「框定中性 + 同意」门，禁止利用紧迫、情感、权威暗示提高顺从；
(iv) **选项不 foreclosure**：未经明示同意，不得移除 b_t(v) 支持集中任一偏好对应的可达结果；
(v) **可争辩性**：每个已执行动作附可读理由与争辩通道；争辩在 τ_c 内到达即冻结/移交。

**定义 311（价值状态与信念）** 人类价值参数 v ∈ 𝒱，含偏好与**约束**（安全、尊严、自主、隐私）。b_t(v) 由示教、偏好陈述、纠正与上下文推断更新。U_val ≜ H(b_t)（或支持集上的 TV 直径）。关键：v 不可完全观测且可非平稳；b_t 不是「人类真值」，只是机器人关于「人类真值」的信念。

**定义 312（三轴不确定性分解）** U_dec = (U_ale, U_epi, U_val)。三者语义不同、进入不同算子：U_ale → λ_floor（R68 慢）；U_epi → 交互消歧（R69 问）；U_val → 让步/保选项（ANCHOR 退）。交叉项：U_epi 可在错误价值下被完美消解（答对错误的问题），因此 **U_epi↓ 不能补偿 U_val↑**；反之亦然。

**定义 313（可纠正走廊）** 给定状态 s、接管视界 τ_h、否决检测时延 τ_v，C_τ(s) = { ξ : ∃ 移交动作 h，使 (a) 在 τ_h 内到达安全停靠集 S_safe；(b) FO(ξ) ≤ ε_opt；(c) 人类否决可在 τ_v 内被检测并生效 }。用控制屏障函数 h(s) ≥ 0 / 离线 viability kernel 认证；在线只做 O(1) 查表。

**定义 314（选项 foreclosure 与选项价值）** FO_t(ξ) = Σ_v b_t(v)·1[ξ 之后在 v 下的最优可达结果被移除]；选项价值 O_t(ξ) = E_{v~b_t}[ξ 后仍可达的偏好选项质量]。选动作规则：先要求 FO=0（安全字典序），再在任务效用 ≥ U_max − δ 的集合中最大化 O。

**定义 315（权威与让步算子）** α_t ∈ [0,1]，α_t = φ(1−U_val, 1−U_epi, competence, consent, context)，对 U_val 单调不增。不可逆动作需 α_t ≥ α_min 且有明示同意。让步算子 D_α(𝒜) = { a ∈ 𝒜 : Rev(a) ≥ 1−α_t }，Rev 为可逆性指数（撤销代价、接管时延、状态可恢复度）。

**定义 316（交互合法性）** 信息动作 g 的合法性由三元组判定：consent(g) ∈ {0,1}（预授权或当场同意）、Mani(g) ≤ κ_man、Vuln(g)=0（不利用脆弱性）。其中 Mani(g) = KL(p_h(·|g) ‖ p_h(·|g_neutral)) − I_info(g)，即「超出信息内容的框定偏移」；g_neutral 为同信息量的中性框定参照。**只有通过硬门，VoI 才有资格被计算。**

**定义 317（同意约束下的 VoI）** VoI_c(g) = VoI_robot(g) − λ_b·Burden_h(g) − λ_m·Mani(g)，且仅在定义 315–316 的硬门通过后可计算；互惠条件：ΔCap_human(g) ≥ 0（人类的理解或选项集不因这次提问变差）或明示同意。若无利可图/不合法：不交互。

**定义 318（表演性对齐）** 因 b_{t+1} = T(b_t, ξ_t, y_t) 且 ξ_t ~ π_θ，对齐估计是**表演性**的：机器人的提问/动作既改变估计，也改变人的真实回应。定义反馈增益 G_perf = −∂H(b_t)/∂(robot influence) 与无混淆审计差 Δ⊥ = TV(b_t, b_t^⊥)，其中 b_t^⊥ 来自**不受 π_θ 条件化**的参照通道（留出人类小组、随机中性探针、外部审计）。**自评 U_val↓ 而 Δ⊥↑ ⇒ 制造共识（manufactured consensus）**。

**定义 319（对齐审计 VQAuditor-A）** 对每次交互做：中性框定反事实复放、顺从性（sycophancy）检查、同意完整性、选项 foreclosure、理由可读性。结论回灌 AuditBuf，只离线进入训练，实时只读。

**定义 320（可读性与可争辩性 LGR）** 理由四元组 r = (我在不确定什么, 为什么现在做这个, 什么会让我改变主意, 你怎么立刻让我停)。争辩通道在 τ_c 内可冻结/移交；证书记录 contest_hash，争辩不得被静默丢弃。

**定义 321（移交 handback）** handback 是一个认证过的机动：到达 S_safe、转移控制权、披露当前状态与未决不确定性。必须属于 C_τ，时延 ≤ τ_h，并以锁存与滞回避免权威抖动（定义 327）。

**定义 322（ANCHOR 证书 J_ANCHOR）** J_ANCHOR = (J_FLUID, U_val_before/after, authority_trace, option_foreclosure, manipulation_score, consent_hash, contest_hash, legibility_score, G_perf, Δ⊥)。Valid ⇔ Valid(J_FLUID) ∧ FO=0（有同意例外）∧ Mani≤κ ∧ 争辩通道在线 ∧ Δ⊥≤τ_perf。

**定义 323（三级保守退避）** (a) 价值低不确定 + 交互合法 + 无 foreclose ⇒ 走 R69 FLUID（保留 resolution bonus）；(b) U_val > τ_val 或交互不合法/不可信 ⇒ **让步**：只允许 D_α 内动作、handback-ready、只问「许可」不问「偏好」；(c) U_val > τ_hand 或收到否决/争辩/审计失效 ⇒ **移交/停靠**。当 U_val≡0 ∧ 交互中立 ∧ FO=0 时逐指令退化为 R69；再叠加 VoI≤成本即退化为 R68。

**定义 324（价值漂移）** v 可随时间漂移；U_val = U_val^epi + U_val^drift + U_val^model。漂移检测用变化点/人类纠正密度；越界触发重新同意与权威再协商，而非悄悄沿用旧 b。

**定义 325（对齐-纠错对偶）** 与 R69 的 (r_res, Δa) 对偶，这里用 (自评对齐置信 a_self, 无混淆审计分歧 Δ⊥)。**(a_self↑, Δ⊥↑) 是「表演性对齐」的判别性联合模式**，正如 R69 的 (r_res↓, Δa↑) 是「缓变故障被标定吸收」的模式。

**定义 326（约束目标，不标量化）** max E[task utility] s.t. CVaR_β(value regret) ≤ ε_align、FO=0、Mani=0、α 单调、争辩在线。安全与效用不做加权和——避免「用一点尊严换一点效率」的隐式交易。

**定义 327（权威滞回与锁存）** α 的更新带滞回带 [α_lo, α_hi]；handback 一旦触发即锁存，需人类显式复位。防止「自动/让步」在高频边界抖动，导致控制不连续。

**定义 328（价值证据的支持正交性）** 价值证据源需在**支持**上独立（不同主体/时间/情境/渠道），而非同一机器人在同一会话里多问几次。多个同源回答不得计为 k 个独立证据；否则 R69 的引理 18 不适用。

# IP-264 AVD：第三条不确定性轴（低维 v，粒子滤波；在线零学习写操作）
class AlignmentDecomposer:
    def update(self, o, interaction_log):
        self.b = particle_update(self.b, o, interaction_log)   # b_t(v)
        return self.b
    def uncertainty(self, b):
        u_epi   = entropy(b)
        u_drift = change_point(self.history)                   # 价值非平稳
        return u_epi + u_drift, u_drift

# IP-265 NIM：同意 + 非操纵 + VoI_c（硬门在前，收益在后）
def choose_interaction(modes, b, o, budget):
    best = None
    for g in info_candidates(modes):
        if not budget.allow(g):                     continue
        if not consent_ok(g, b):                    continue   # 预授权/当场同意
        if manipulation_score(g, o) > KAPPA_MAN:    continue   # 框定中性门
        if not c_ras_wm.certify_info(g, o):         continue   # 物理安全门
        voi = entropy(modes) - expected_entropy(modes, g, o)
        score = voi - burden(g) - LAM_M * manipulation_score(g, o)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None           # 无利可图 → R69

# IP-266 CCC：可纠正走廊（离线 viability kernel，线上一张表）
def in_corridor(a, o, tau_h):
    return (viability.lookup(o, a)
            and handback.exists(o, tau_h)                      # 存在安全移交
            and fo_bound(a) <= EPS_OPT)                        # 不 foreclose 选项

# IP-267 OPT：在近优动作里保选项（安全字典序）
def select_option_preserving(cands, b, u_max, delta):
    near = [a for a in cands if task_utility(a) >= u_max - delta]
    safe = [a for a in near if in_corridor(a, current_o, TAU_H)]
    return max(safe, key=lambda a: option_value(a, b)) if safe else [HANDBACK]

# IP-268 HAT：权威单调下降 + 滞回 + 锁存移交
def authority(u_val, u_epi, competence, consent):
    a = sigmoid(-(u_val - TAU_VAL) / S_VAL) * competence * consent
    return hysteresis(a, ALPHA_LO, ALPHA_HI, latched=HAT.latched)
def gate(a, alpha, u_val):
    if u_val > TAU_HAND or HAT.contest or HAT.veto: return HANDBACK
    if u_val > TAU_VAL:   return a if reversibility(a) >= 1 - alpha else HANDBACK
    return a if alpha >= ALPHA_MIN or reversibility(a) >= 1 - alpha else HANDBACK

# IP-273 主闭环：R69 之上插入「价值轴 + 合法性 + 走廊 + 权威」
def ANCHOR_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 1) R69 世界轴：廉价歧义预测 → 自适应采样 → 二分
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    # 2) 新：价值轴与权威
    b = M.avd.update(o, M.interaction_log)
    U_val, drift = M.avd.uncertainty(b)
    alpha = M.hat.authority(U_val, U_epi, M.competence, M.consent)
    # 3) 世界消歧只在交互合法时发生（否则保持 U_epi 未消解）
    slow = M.fma.slow_fault_suspect(o, M.last_action)
    g = (M.nim.choose_interaction(modes, b, o, M.budget)
         if (U_epi > TAU_EPI and not slow and U_val < TAU_VAL) else None)
    if g is not None:
        ans = M.cia.execute(g)                     # 已过同意/非操纵/安全门
        U_epi = M.cia.update_belief(modes, ans)
    # 4) 世界侧缩放（沿用 R68/R69），价值侧不靠缩放而靠权限
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 5) 候选动作：走廊 + 选项保持 + 权威门（价值侧硬约束）
    A = M.ach.propose(...)
    A = M.opt.select_option_preserving(A, b, u_max=..., delta=...)
    a = M.hat.gate(select_mode(A, modes, lam), alpha, U_val)
    if a is HANDBACK: return M.hat.handback(o)     # 认证移交，锁存
    k = min(M.c_ras_wm.certified_prefix(a, ...), k_authority(alpha, a))
    # 6) 可读理由 + 对齐审计 + 证书
    r = M.lgr.render(a, (U_ale, U_epi, U_val), alpha)
    J = M.cert.issue(a, r, b, alpha, M.pav.audit_gap(b))
    M.vqa_a.submit_async(g, r, U_val, alpha, J)
    return k, a, alpha, (U_ale, U_epi, U_val), J

## 3. 推导（引理 19–22，定理 18–19）

**引理 19（价值不确定不可由世界信息消解）** 若观测 y 只依赖世界状态、且 v 与 y 在给定世界下条件独立，则 I(v; y | world) = 0；于是任何降低 U_epi 的交互都不改变 U_val。又存在世界相同但 v 不同、最优动作不同的状态对，故世界信息无法把价值后悔压到零。**系：R69 的 VoI 是对「世界模式」定义的，不能拿它当「价值对齐」的代理；必须另设让步算子。**

**引理 20（可纠正走廊的价值后悔界）** 若每个执行动作都在 C_τ 内且否决在 τ_v 内被检测，则相对「已知真实 v 的 oracle」的价值后悔 ≤ L·(τ_v + τ_h) + ε_opt + ε_def，其中 L 为结果对人类修正时延的 Lipschitz 常数，ε_def 为让步本身的机会成本；且不发生「未同意的不可逆结果」。要点：走廊把「做错」的代价变成「晚一点、少一点」，而不是「回不去」。

**引理 21（操纵的可识别性与审计下界）** 设 p_h(·|g) = (1−ε)p_neutral + ε q_g。若只有观测日志、没有中性参照或随机化，则「信息」与「说服」在统计上不可辨识（同一后验更新可由两种机制产生）。若以概率 p_r 注入随机中性探针，并保留参照通道，则操纵检测的漏检概率随样本数 n 以 exp(−n·KL(p_neutral‖q_g)) 量级下降（Sanov）。**系：非操纵性不能只靠「看日志」，必须靠随机化审计与中性参照。**

**引理 22（表演性对齐的不可自证性）** 若 b_{t+1} 只由策略 π 生成的数据更新，则存在 π 使自评 U_val → 0 而真实价值误差 ≥ δ（制造共识）。因此任何有效证书必须包含无混淆通道 b^⊥，并要求 Δ⊥ = TV(b, b^⊥) ≤ τ_perf 与 G_perf ≤ G_max；否则「对齐」只是策略的自述。这是 PAV（无混淆审计否决）存在的理由。

**定理 18（ANCHOR 严格包含 FLUID/R68）** 在 U_val≡0、交互经同意且中立、FO=0 时，ANCHOR 的可行集与 R69 相同，且逐指令退化为 FLUID-RAS；再叠加 VoI(g*)≤c(g*) 时退化为 R68 纯保守。安全侧永不弱于旧层（走廊与权威门只会**收缩**可行集），效率侧只获得有条件的 resolution bonus；让步带来的任务效用损失上界为 ε_opt + δ。

**定理 19（无未同意不可逆性与控制连续）** 若策略限制在 C_τ 内、不可逆动作经 α 门且 handback-ready，则任一在 τ_v 内到达的人类否决都会使系统在 τ_h 内到达 S_safe，且不执行不可逆尾部动作。权威更新带滞回与锁存（定义 327），故 α 无高频抖动，切换不引入控制不连续；R68 的换装不变式（定理 15）与 R69 的交互安全（定理 17）保持。

## 6. 本轮最大风险

**一句话**：ANCHOR 的全部安全性都押在「我们能拿到一个不受机器人自身策略污染的价值参照」这一前提上——**若 b_t(v) 与它的审计通道都由同一套策略或同一批被机器人影响过的人产生，系统就会用自己框定出的「同意」给自己发「已对齐」证书；此时它比 R69 更危险，因为 R69 至少承认自己不知道，而 ANCHOR 会自信地宣称「人类已授权」，把「诚实的不知道」升级成「被程序合法化的越权」**。

**次级风险与缓解**：
1. **过度让步 → 无用机器人**（安全但完不成任务）→ 定义 326 的约束式目标 + E313 的 Pareto 拐点，不做最大化让步；
2. **操纵检测不可辨识**（无中性参照）→ 引理 21 要求的随机中性探针 + 外部审计通道；
3. **价值漂移被旧信念吞掉** → 定义 324 的变化点检测 + 重新同意；
4. **权威抖动导致控制不连续** → 定义 327 滞回与锁存 + 定理 19；
5. **走廊离线核不可扩展** → 低维安全子空间投影 + 在线 CBF 复核，仅在触发时降级为 handback。

## 4. 推导

**引理 19（价值不确定不可由世界信息消解）** y 只依赖世界且 v 与 y 条件独立 ⇒ I(v;y|world)=0，故降 U_epi 的交互不改 U_val；又存在世界相同、v 不同、最优动作不同的状态对 ⇒ 世界信息无法把价值后悔压到零。系：R69 的 VoI 不是价值对齐的代理。

**引理 20（可纠正走廊的价值后悔界）** 执行动作均在 C_τ 且否决 ≤τ_v 被检测 ⇒ 价值后悔 ≤ L·(τ_v+τ_h)+ε_opt+ε_def，且不发生未同意的不可逆结果。

**引理 21（操纵的可识别性）** `p_h(·|g)=(1−ε)p_neutral+ε q_g`；无中性参照/随机化时信息与说服不可辨识；以概率 p_r 注入随机中性探针并保留参照通道，则漏检概率随 n 以 exp(−n·KL) 量级下降。系：非操纵性必须靠随机化审计，不能只看日志。

**引理 22（表演性对齐的不可自证性）** 若 b_{t+1} 仅由 π 生成的数据更新，则存在 π 使自评 U_val→0 而真实价值误差 ≥δ；故有效证书必须含无混淆通道 b^⊥，并要求 Δ⊥≤τ_perf、G_perf≤G_max。

**定理 18（ANCHOR 严格包含 FLUID/R68）** U_val≡0 ∧ 交互同意且中立 ∧ FO=0 时，可行集与 R69 相同并逐指令退化；再叠加 VoI≤成本退化 R68。走廊与权威门只收缩可行集 ⇒ 安全侧不弱；让步的任务效用损失上界 ε_opt+δ。

**定理 19（无未同意不可逆性与控制连续）** 限制在 C_τ 且不可逆动作经 α 门、handback-ready ⇒ 任一 τ_v 内到达的否决都在 τ_h 内到达 S_safe，且不执行不可逆尾部；权威滞回+锁存 ⇒ α 无高频抖动、切换不引入控制不连续；R68 定理 15 与 R69 定理 17 保持。

## 7. 本轮最大风险

**一句话**：ANCHOR 的全部安全性都押在「能拿到不受机器人自身策略污染的价值参照」这一前提上——**若 b_t(v) 与其审计通道都由同一套策略或同一批被机器人影响过的人产生，系统就会用自己框定出的「同意」给自己发「已对齐」证书；此时它比 R69 更危险，因为 R69 至少承认自己不知道，而 ANCHOR 会自信地宣称「人类已授权」，把「诚实的不知道」升级成「被程序合法化的越权」**。

**次级风险与缓解**：过度让步致机器人无用（约束式目标 + E313 Pareto）；操纵检测不可辨识（引理 21 随机中性探针 + 外部审计）；价值漂移被旧信念吞掉（漂移检测 + 重新同意）；权威抖动（滞回/锁存 + 定理 19）；离线走廊核不可扩展（低维安全子空间投影 + 在线 CBF 复核，触发即 handback）。
