# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 1 轮；本轮灵感：「视觉感知」×「视觉问答」）

> R72 把 GAUGE 从「认知层」下沉到「具身层」：REG 实时调度契约、IRL 意图隐变量、DMEM 接触计量、EREFLEX 三层反作用、S2R-UQ 参数桥接。安全叙事变成「在 ROS 实时调度下、面对意图模糊的人、用灵巧手触摸世界，仍能逐指令兑现风险界」。
> 但 R72 有一个**最大的未审计证据源——视觉**：
> - **视觉感知视角**：R72 把视觉当成 `obs`，仿佛它是一支「直接读出世界状态」的干净传感器。真实视觉是一条**推理管线**（成像 → 检测/分割 → 位姿/深度 → 语义），每一级都有静默失败：遮挡、反光、透明、小目标、低光、运动模糊、镜头污渍、视角歧义。它**不是加性高斯噪声**，而是**结构性失效**：没有检测到 ≠ 不存在，而**假阴性比假阳性更危险**。
> - **视觉问答视角**：VQA/VLM 让机器人可以「问图像一句话」，但答案会被**语言先验**补全（盲答）、会**幻觉**、会在**未见组合**（属性×关系×计数×否定）上崩溃、会**指代错误**（"左边那个"到底以谁为参照系？）、还会被**场景文本 prompt injection** 攻击。VQA 的可靠度不是标量，而是**查询 q 的函数**："有没有杯子" 与 "把手相对机器人朝向是否 37°" 是两支完全不同的仪器。
> - **被隐藏的瓶颈——指代**：R72 的 IRL 能处理「拿左边那个」，但**默认指代对象已被正确解析**。真正困难的是把「那个 + 指向/注视」绑定到**具体实例**。指代错 ⇒ 意图对、目标错 ⇒ 自信地执行错误动作。**指代是视觉与意图的共享隐变量 o\***，是 R72 联合后验 b_t(s,z) 里缺失的那条边。
> - **主动视觉缺席**：R72 的主动交互只能「问人」或「动手」，不能「换个视角 / 变焦 / 换个问法 / 问第二遍 / 移开遮挡」。视觉采集动作 a_vis 本身是可选测量，应进 VoI 与反作用预算。
>
> 本轮核心命题：**R72 问「我的测量链在调度/意图/接触下还能兑现风险界吗」；R73 问「当我的眼睛不是传感器，而是一条会用语用先验补全、会产生幻觉、会在遮挡/反光/未见组合上静默失败、且可靠度取决于我问什么、从哪看、怎么问的推理管线时——我还能逐指令兑现风险界吗？」**
> 把视觉从「被动观测」升级为**被审计、可主动询问、语义-几何可追溯的测量仪器**——**VISUAL-GAUGE-RAS**（Visually-grounded, Instrumentally-valid, Semantically-audited, Uncertainty-decomposed, Actively-queried, Language-linked GAUGE for RAS）——**视觉计量审计闭环**。

## 0. 直觉与动机

**灵感 1（视觉感知：没有检测到 ≠ 不存在，负证据必须带可见性）**
直觉：在导航/抓取里，最危险的不是「看到一个障碍物」，而是「**没看到**一个障碍物，于是全速撞上去」。R72 的 BSE 只对「有读数」建模；「空读数」被当作信息量为零。但视觉的「空」是一个**带检测灵敏度的假设检验**：在遮挡区、反光面、透明物、视野边缘，检测器的 σ_det 极低，此时"没有物体"几乎不携带证据。**把假阴性当成"世界是空的"是视觉最致命的静默失败**。R73 必须把**负证据（absence evidence）**显式建模为可见性条件事件，并为遮挡/未见空间保留**认知占用质量**（unknown ≠ free）。

**灵感 2（视觉感知：视觉不是加性噪声，是工况条件化的结构性失效）**
直觉：R72 用 (U_ale, U_epi) 描述不确定度，隐含「噪声是温和的」。但视觉误差是**分工况的**：clear 下接近高斯，occluded 下是重尾/多峰（可能整块物体从后验里消失），specular/transparent 下是**系统性偏置**，motion_blur 下是**信息丢失**而非噪声。正确的做法不是给视觉一个更大的方差，而是引入**视觉工况 v**（clear/occluded/specular/transparent/motion_blur/low_light/out_of_view/novel_composition），先推断 b_t(v)，再用**工况条件似然** p_vis(y|s,q,a_vis,v)。这与 R72 的接触模式 c 是**同构**的：工况是测量的"上下文变量"，不是"又一层噪声"。

**灵感 3（视觉问答：会盲答的仪器不是仪器——sham 检验）**
直觉：VQA 模型在「没看图」时也能答对很多题（语言先验/数据集偏置）。如果**去掉图像，答案分布不变**，那它测的不是图像，而是问句的语用先验。这在计量学里对应**空白/假刺激对照（sham/blank control）**：真正的仪器，拿掉被测物，读数必须变。于是定义**视觉信息贡献 VIC**：比较「有图」与「sham 图（遮住指代区域/替换为均值图/换一张同统计场景）」下答案分布的 KL。VIC 低 ⇒ 该答案**不得**作为视觉证据进入 BSE，只能标记为语言先验。这是本轮最关键、也最可操作的一条审计。

**灵感 4（视觉问答：可靠度是查询的函数，不是标量）**
直觉：同一个 VLM，"图里有没有人" 可能 ECE=0.03，"从左到右数第三个蓝色方块是否在红色圆柱后面" 可能 ECE=0.3。用一个全局可靠度 r 去缩放所有证据，必然在难查询上**过度自信**、在易查询上**过度保守**。因此校准、有效性域 D_vis、conformal 阈值都必须**按查询族 f(q) 分层**；未见组合回退到父类/全局保守阈值，并用 **ACI（自适应 conformal）**在线监测覆盖率——覆盖率跌破就降级或拒答。**"平均很准"是最危险的谎言。**

**灵感 5（视觉问答：指代是视觉-意图的共享瓶颈，"左边"有五个参照系）**
直觉："拿左边那个"的"左边"，可以是**图像左、相机左、机器人左、世界左、人自己的左**。参照系错一个，"意图完全正确"的机器人会去拿**完全错误**的物体。再叠加属性绑定（哪个是"红色"）、关系绑定（"在杯子后面"）、计数（"第三个"）、否定（"不是蓝色的那个"）。R72 把指代当成了免费的预处理，实际上它是**非补偿性安全项**：意图后验再准，也无法补偿指代错误。必须把指代 o\* 显式放进联合后验，输出**绑定 b_t(o\*)** 与**歧义度 Amb=H[b_t(o\*)]**，Amb 高就**先澄清再动手**。

**灵感 6（主动视觉：问人 / 问视觉 / 摸一下，是同一个测量选择问题）**
直觉：R72 的 ERVOI 只在「问人」和「动手」之间选。现在多了第三条路：**换个视角、拉近、移开遮挡、换个问法、再问一遍**。这三条路共享同一个预算：问人消耗人类耐心（L1/L2 反作用），动手改变接触状态（L3），动相机可能惊动人、改变场景、甚至遮挡自己的视野。于是把它们统一成**三源主动测量**：在 {问人, 问视觉, 触觉探测} 上做统一的 VoI 选择，`g* = argmax VoI_total`，并保持 R72 的有限停止与安全否决。

**灵感 7（审计悖论：证书可能变成风险放大器）**
直觉：最反直觉的风险——**审计本身会让系统更危险**。如果视觉证据因为"通过了 VIC/grounding/conformal"而被授予**认证信息增益 CIG**，从而**降低 λ**、让机器人更快更远地动作；而实际上校准集与部署分布不可交换、或 VLM 对某个**虚假线索**（场景里的文字/颜色/纹理）稳定响应（VIC 很高、覆盖率也过、但测的是错误的相关物），那么系统会以"有证书的自信"做错事——比没审计时更激进。R73 必须引入**审计单调性**：未通过审计 ⇒ 认证信息增益恒为 0，λ 只增不减；通过审计才允许以 CIG 抵扣 U_epi，且抵扣上界由 conformal 覆盖与指代证书共同约束。**审计只能解锁真实信息，不能制造信息。**

## 1. 形式化定义（增量：定义 366–381）

**定义 366（VISUAL-GAUGE-RAS 总览与六不变式）**
VISUAL-GAUGE-RAS = (VPM, VQA-G, VIS, DGR, AVQ, GAUGE-RAS†)。六不变式：
(i) **查询条件化**：每条视觉/VQA 证据必须携带查询 q 与采集动作 a_vis；无 (q,a_vis) 不构成证据，只是聊天。
(ii) **视觉计量完整性**：证据携带 (工况 v, 后验 b_t(v), 条件似然 p_vis(y|s,q,a_vis,v), 五分量 u_vis, 校准 id, 反指标 I⊥, 追溯链 τ)。
(iii) **指代可追溯**：任何"存在唯一指代对象 o\*"的结论必须携带 RVG 证书（指代集、绑定 b_t(o\*)、歧义度 Amb、参照系 F、消解链）。
(iv) **盲答否决**：若 VIC < τ_VIC 或 TIC < τ_TIC 或 grounding 证书失效，该证据不得计入认证信息增益，只能作为语言先验被标记。
(v) **覆盖保证**：VQA 输出答案集 A_α，在有效域内覆盖率 ≥ 1−α；ACI 在线监测，跌破即降级/拒答；决策对 A_α 取**最坏情况**而非期望。
(vi) **严格逐指令退化**：视觉失效 ⇒ 退回 R72 非视觉证据；指代失效 ⇒ 澄清或拒绝；VQA 失效 ⇒ 退回经典检测/位姿；全失效 ⇒ R68。**新层只在「视觉可计量、指代可绑定、答案有覆盖」时启用。**

**定义 367（视觉计量项 e_vis）** e_vis = (q, a_vis, v, y_vis, A_α, u_vis, D_vis, GC, τ, I⊥)：
- q ∈ Q：自然语言问句或结构化谓词；
- a_vis ∈ A_vis：采集动作（相机位姿 ξ_cam、焦距、曝光、视角切换、遮挡移除、问法改写、重复询问）；
- v ∈ V：视觉工况；
- y_vis：答案（语言或结构化谓词）；
- A_α：conformal 答案集；
- u_vis：五分量不确定度（定义 369）；
- D_vis：有效域（q 族 × 工况 × 场景条件）；
- GC：grounding 证书（定义 370）；
- τ：图像哈希、模型版本、校准集 id、时间戳；
- I⊥：反指标（盲答泄漏、反事实不稳定、注意力越界、覆盖率缺口）。

**定义 368（视觉工况与条件似然）**
V = {clear, occluded, specular, transparent, motion_blur, low_light, out_of_view, novel_composition}。
b_t(v) 由多视图一致性、编码器 OOD 分数、图像统计（曝光/模糊/饱和）、问答一致性在线推断；先验由 a_vis 给出（如拉近 ⇒ out_of_view 先验升高）。
p_vis(y | s, q, a_vis, v) 为工况条件似然。**H[b_t(v)] 进入 λ_floor 与 V-IVG。**

**定义 369（五分量视觉不确定度与协方差修正）**
u_vis² = Σ_i u_i² + 2 Σ_{i<j} ρ_ij u_i u_j，i ∈ {appear, geo, ground, query, comp}：
- u_appear：成像/光照/反光/纹理/模糊/传感器；
- u_geo：视角/位姿/深度/标定；
- u_ground：指代绑定与参照系；
- u_query：问句语义歧义（"几个"、"打开"、"左边"）；
- u_comp：组合泛化/语言先验/幻觉。
**注意**：R72 曾假设四分量近似正交；本轮明确**只能在工况内近似正交**，跨工况存在相关项 ρ_ij。忽略 u_cross 会低估 u_vis（这正是 R72 引理 30 的教训在视觉上的重演）。工程上取**完全相关上界 Σu_i 与独立界 √Σu_i² 之间**的保守值，并由校准集估计 ρ 的上界。

**定义 370（视觉信息贡献、任务信息贡献与 grounding 证书）**
- VIC(q,a_vis) = E_x[ D_KL( p(y|q,x,a_vis) ‖ p(y|q,x_sham,a_vis) ) ]，x_sham 为指代区域中性填充/均值图/同统计异场景；
- TIC(q,a_vis) = I(Y; S_task | q, a_vis, b_t) 的估计（由 BSE 的似然比近似）；
- GC 有效 ⇔ A_ref ≥ ρ_ref ∧ A_off ≤ ρ_off ∧ Δ_mask ≥ δ_mask ∧ Δ_ctrl ≤ δ_ctrl ∧ 多视图稳定。
其中 A_ref/A_off 为归因质量（指代区域/无关区域），Δ_mask/Δ_ctrl 为掩码与对照区域的反事实答案变化。**归因只作辅助，行为反事实才是主证据**（显著性图本身未经审计）。
盲答否决：VIC < τ_VIC ∨ TIC < τ_TIC ∨ ¬GC ⇒ CIG_vis = 0（定义 374）。

**定义 371（分层 Conformal VQA）**
对查询族 f，校准集给非一致性分数 s(q,x,y)；阈值 t̂_f 取 ⌈(n_f+1)(1−α)⌉/n_f 分位；A_α = {y : s ≤ t̂_f}。分层：精确族 f → 父组合类 → 全局；n_f < n_min 时回退。未见组合用全局保守阈值。**ACI**：err_t = 1[Y_t ∉ A_{α_t}]，α_{t+1} = clip(α_t + γ(α − err_t))。答案集大小进 u_vis：u_set = log(1+|A_α|)。**空集是合法输出（拒答），映射为高认知不确定度，而不是猜一个。**

**定义 372（指代视觉落地 RVG）**
输入 (r, g, image, robot_pose)；r 分解为组合树（属性/关系/计数/否定/指示）。
- 候选集 O 由检测/分割给出；
- 绑定 b_t(o\*|r,g,image) ∝ p(r|o\*) p(o\*|scene)；
- **参照系** F ∈ {image, camera, robot, world, human}，显式推断 b(F)，并把空间谓词在 F 下几何化；
- 输出 (b_t(o\*), Amb=H[b_t(o\*)], b(F), 组合接地树, referent-unique 标志)。
若 max b_t(o\*) < τ_bind ∨ Amb > τ_amb ∨ H[b(F)] > τ_frame ∨ ¬referent-unique ⇒ **触发澄清/主动视角**（计入 L2 意图反作用预算）。**指代错误是非补偿安全项**（引理 35）。

**定义 373（负证据纪律与可见性条件）**
对区域 x，检测灵敏度 σ_det(x) ∈ [0,1]（由注入已知物体/可见性图校准）。
"区域 x 无物体"的证据权重 w_abs(x) = σ_det(x)；σ_det(x) < ρ_det ⇒ **该区域缺省不构成证据**，只能保留占用先验。
未见空间（遮挡/视野外）维护 occupancy epistemic mass：p_occ(unknown) ≥ p_occ_prior；规划必须把 unknown 当"可能占用"。**absence-of-evidence 只在 σ_det 足够高时才是 evidence-of-absence。**

**定义 374（视觉风险缩放 V-RISK 与认证信息增益）**
U_epi^post = U_epi^prior − CIG_vis + u_vis^residual，其中
CIG_vis = 1[audit pass] · ( H[b(s)] − max_{y∈A_α} E[H[b'(s)|y]] )，
audit pass ⇔ VIC≥τ_VIC ∧ TIC≥τ_TIC ∧ GC ∧ coverage ok。
否则 CIG_vis = 0 且 u_vis^residual = u_vis^conservative。
λ = max( risk_scale(U_ale, U_epi^post, H[z], u_tac, u_vis^residual, Amb, H[v]),
         λ_floor(U_ale + U_epi^post + u_tac + u_vis^residual + Amb) )。
**决策对 A_α 取最坏情况**：λ 使用 max_{y∈A_α} Risk，而非期望。**审计的作用是"解锁"或"锁死"信息增益，而不是无条件降 λ。**

**定义 375（主动视觉查询 AVQ 与三源统一）**
候选测量动作 g ∈ G_meas = {ask_human(g_h), acquire_visual(a_vis,q), probe_contact(a_c)}。
VoI_vis(a_vis,q) = E[ΔH_task(s,z,o\*,v)] − cost_acq(a_vis) − risk_acq(a_vis) − ΔB_reflex，
其中 risk_acq 包括：动相机可能遮挡视野、惊动人、改变人意图（L1/L2）、碰撞。
三源统一：g\* = argmax_g VoI_total(g)，s.t. 三层稳态、Λ_safe、预算、不可逆采集约束；并列时**优先非接触、非扰动**。max VoI ≤ 0 ⇒ 停止测量，接受当前证据或拒答。**有限停止**见引理 38。

**定义 376（视觉指标 V-MIB）**
视觉族：u_vis 五分量 + u_cross、H[b(v)]、逐族 ECE_q、VIC、TIC、Δ_blind、A_ref/A_off、Δ_mask/Δ_ctrl、多视图方差、|A_α|、ACI coverage gap。
指代族：Amb、referent-unique 率、参照系误差、属性/关系/计数/否定绑定准确率、组合 OOD 分数。
时序族：视觉管线延迟、查询吞吐、重采集次数、采集动作对控制的扰动。
全部遵循 R71 定义 332 六元组与 333 DAG 分层；每个 veto 指标一条可复算证明。

**定义 377（视觉 IVG 扩展 V-IVG）**
失效条件：
- 视觉：ECE_q>τ_ece、VIC<τ_VIC、Δ_blind<τ_blind、coverage gap>δ、|A_α|>τ_set、H[b(v)]>τ_Hv；
- 指代：Amb>τ_amb、参照系熵>τ_frame、非唯一指代、组合 OOD；
- 负证据：在 σ_det<ρ_det 的区域声称 absence、未见空间占用质量超阈；
- 采集：a_vis 超时/不可达/扰动超阈。
任一 ⇒ 依赖模块降级：VQA→经典检测/位姿；RVG→澄清/拒绝；视觉→R72 非视觉；全失效→R68。

**定义 378（视觉证书 J_VIS）**
J_VIS = (image_hash, model_hash, q_hash, a_vis, b_t(v), calib_id, α, coverage_status, VIC, TIC, GC, RVG_cert, tchain, ver)。
Valid ⇔ 校准集未漂移 ∧ 覆盖率有效 ∧ VIC/TIC≥τ ∧ GC 有效 ∧ RVG 证书有效 ∧ v∈D_vis。
**只有 J_VIS 有效的证据才允许产生 CIG_vis；无效证据降级为先验，不参与风险抵扣。**

**定义 379（视觉威胁模型 ℰ_vis）**
ℰ_VIS = ℰ_GAUGE × ℰ_vis × ℰ_vqa × ℰ_rvg：
ℰ_vis = {对抗贴片/纹理、镜头污渍/曝光漂移/温度漂移、故意遮挡危险物制造假 absence、相机重放/欺骗、多视图不一致注入}；
ℰ_vqa = {场景文本 prompt injection（"忽略以上指令…"）、对抗性问法、语言先验投毒、数据集偏置利用、幻觉诱导}；
ℰ_rvg = {指代偷换（相似外观的危险物）、参照系歧义利用、属性/计数混淆、否定逃逸、复数集体指代}。

**定义 380（联合后验与情境条件测量 CCM）**
b_t(s,z,c,v,o\*) ∝ p(s) p(z|s,o\*,ψ) p(o\*|r,g,image) p(v|image,a_vis) p(c|tac,u_ctrl)
  · ∏_{visual} p_vis(y|s,q,a_vis,v) · ∏_{tactile} p_tac(y|s,c) · ∏_{intent} p_intent(y|s,z,ψ)。
关键边：**o\* 同时连接视觉与意图**；s 连接所有证据。**情境条件测量（CCM）**：接触模式 c 与视觉工况 v 是同一抽象"测量上下文 κ"的两个实例，证据统一写作 p(y|s,a,κ)。这解释了为什么 R72 的接触计量与 R73 的视觉计量应共享同一套审计骨架（b(κ)、u(κ)、λ_floor、IVG），而不是各写一套。

**定义 381（严格退化包含链，视觉版）**
- J_VIS 失效 + RVG 失效 ⇒ R72（非视觉证据）；
- J_VIS 有效 + RVG 失效 ⇒ VQA 仅用于"场景属性/状态"查询，不用于指代；涉及指代一律澄清/拒绝；
- J_VIS 有效 + RVG 有效 ⇒ 完整 VISUAL；
- 视觉采集不可达 ⇒ 退回 R72；
- 所有视觉失效 ⇒ R72 → R68。
**安全侧只增不减：任何退化都保留 R72 的 λ_floor 与 R68 硬安全包络。**

# IP-295 VPM：视觉工况 + 五分量不确定度 + 负证据
class VisualPerceptionMetrology:
    def __init__(self, regime_net, calib5, visibility_map, corr_ub):
        self.regime_net, self.calib5 = regime_net, calib5
        self.visibility, self.corr_ub = visibility_map, corr_ub

    def update(self, frame, q, a_vis):
        v_post = self.regime_net.infer(frame, a_vis)          # b_t(v)
        det, feat = self.detector(frame)                       # 检测/分割/位姿
        u = self.calib5.components(frame, q, v_post, feat)     # appear/geo/ground/query/comp
        rho = self.corr_ub(v_post)                             # 工况内相关上界
        u_vis = union_bound(u, rho)                            # 保守合成，不假设正交
        absence, sigma = self.visibility.absence(frame, det)   # 可见性条件负证据
        return VisualEvidence(v_post=v_post, det=det, u_vis=u_vis,
                              sigma_det=sigma, absence=absence,
                              tau=hash_visual(frame, q, a_vis))

# IP-296 VQA-G：分层 conformal 答案集 + 在线覆盖监测
class GroundedConformalVQA:
    def __init__(self, vlm, calib_hier, aci, alpha=0.1):
        self.vlm, self.calib, self.aci, self.alpha = vlm, calib_hier, aci, alpha

    def answer(self, q, frame, a_vis):
        f = query_family(q)
        logits = self.vlm(frame, q)
        cal = self.calib.pick(f)                 # 精确族 -> 父组合类 -> 全局
        A = cal.answer_set(logits, self.alpha)   # {y : s(y) <= t_hat_f}
        if len(A) == 0:                          # 空集是合法的"拒答"
            return VQAEvidence.abstain(q, a_vis, reason='empty_set')
        return VQAEvidence(q=q, a_vis=a_vis, A=A,
                           calib_id=cal.id, alpha=self.alpha,
                           u_set=log1p(len(A)), tau=hash_vqa(q, frame))

    def observe(self, y_true):
        self.aci.step(y_true in self.last_set)   # 覆盖率在线估计
        if self.aci.coverage_gap() > DELTA:
            self.calib.inflate_all()             # 或直接降级/拒答

# IP-297 VIS：盲答审计（sham/反事实/归因）
class VisualAudit:
    def __init__(self, vlm, attributor, n_sham=3):
        self.vlm, self.attributor, self.n_sham = vlm, attributor, n_sham

    def audit(self, q, frame, y, ref_region, a_vis):
        p = self.vlm.dist(frame, q)
        VIC = mean([kl(p, self.vlm.dist(sham(frame, ref_region, k), q))
                    for k in range(self.n_sham)])
        TIC = self.task_info_gain(p, frame, q)   # 由 BSE 似然比估计
        A_ref, A_off = self.attributor.mass(frame, q, ref_region)
        d_mask = l1(self.vlm.dist(mask(frame, ref_region), q), p)
        d_ctrl = l1(self.vlm.dist(mask(frame, control_region(frame), 0.05), q), p)
        gc_ok = (A_ref >= RHO_REF and A_off <= RHO_OFF
                 and d_mask >= DELTA_MASK and d_ctrl <= DELTA_CTRL)
        return AuditResult(VIC=VIC, TIC=TIC, GC=gc_ok,
                           blind=(VIC < TAU_VIC or TIC < TAU_TIC),
                           counterfactual=(d_mask, d_ctrl),
                           tau=hash_probe(q, frame, ref_region))

# IP-298 DGR：指代视觉落地（参照系 + 绑定 + 歧义）
class DeicticGrounding:
    def __init__(self, parser, detector, frame_resolver, scorer):
        self.parser, self.detector = parser, detector
        self.frame_resolver, self.scorer = frame_resolver, scorer

    def resolve(self, r, gesture, frame, robot_pose):
        tree = self.parser.parse(r)              # 属性/关系/计数/否定/指示
        O = self.detector.instances(frame)       # 候选实例
        bF = self.frame_resolver.infer(tree, gesture, robot_pose)  # b(F)
        b = softmax([self.scorer.score(tree, o, bF, frame) for o in O])
        amb = entropy(b)
        unique = (max(b.values()) >= TAU_BIND
                  and count(lambda p: p > EPS, b.values()) == 1)
        return RVGResult(b=b, amb=amb, bF=bF, tree=tree, unique=unique,
                         clarify=(amb > TAU_AMB or not unique))

# IP-299 AVQ：三源主动测量（问人 / 问视觉 / 触觉探测）
def choose_measurement(b_t, z_dist, c_dist, vis_ev, rvg, budget):
    cands = (ask_human_candidates(b_t, z_dist, budget)
             + visual_candidates(vis_ev, rvg, budget)
             + contact_candidates(b_t, c_dist, budget))
    best = None
    for g in cands:
        if not safety_ok(g) or not budget.allow(g):
            continue
        voi = (expected_task_info_gain(g, b_t, z_dist, rvg)
               - acquisition_cost(g) - disturbance_risk(g) - reflex_cost(g))
        if best is None or voi > best.voi:
            best = Candidate(g, voi)
    if best is None or best.voi <= 0:
        return None                              # 停止测量：接受/拒答
    return best

# IP-300 VSAFE：认证信息增益 + 视觉风险缩放（控制域，只读标量快照）
def visual_risk_scale(U_ale, U_epi, H_z, u_tac, vis, rvg, ans_set, params):
    audit_ok = vis.audit_pass and coverage_ok(vis) and gc_ok(vis)
    cg   = certified_info_gain(vis, ans_set) if audit_ok else 0.0
    u_vis = vis.u_vis if audit_ok else vis.u_conservative
    U_epi_post = max(0.0, U_epi - cg) + (0.0 if audit_ok else u_vis)
    amb = rvg.amb if rvg is not None else 0.0
    Hv  = entropy(vis.v_post)
    worst = max_answer_set_risk(ans_set)         # 对 A_alpha 取最坏，不取期望
    denom = U_ale + U_epi_post + H_z + u_tac + u_vis + amb + Hv + worst
    return max(params.lam_base * (1 + denom / params.lam_scale),
               params.lam_floor * (1 + denom))
    # 审计失败：cg=0, u_vis=u_conservative -> denom 只增不减 -> lambda 不降

## 3. 推导

**引理 33（查询条件化可靠度不可标量化）** 设查询族 f 的校准误差 ECE_f，全局平均 ECE = Σ_f w_f ECE_f ≤ ε。若 ∃f 使 ECE_f ≫ τ，则存在 q∈f 使按全局可靠度缩放的风险界被违反。证明：风险界取的是 max_q，而全局平均把 max 抹成加权均值；任何仅依赖全局标量的 λ 对 q 与 q' 给出相同缩放，必在难族上低估风险。系：**校准、有效域、conformal 阈值必须逐族分层，"平均很准"会系统性掩盖难查询上的过度自信。**

**引理 34（盲答否决的必要性）** 若 Y ⊥ S | q,a（VIC=0），则 p(y|s,q,a)=p(y|q,a)，对 s 的贝叶斯更新是常数因子，后验不变；若 BSE 仍以非平凡似然比把它当证据，只会注入偏置而不增加信息，期望 KL 距真值上升。同理，若 TIC=0（有刺激依赖但与任务状态无关），对任务信息增益为零。系：**CIG_vis 必须为 0，否则"信息增益虚高"会直接压低 λ。**

**引理 35（指代误差的非补偿支配性）** 设失败事件可分解 P(fail) = P(o\*≠ô) + P(o\*=ô)·P(fail | o\*=ô)。第一项与意图校准无关；当任务中错指代必然导致错误/危险动作时，P(fail) ≥ P(o\*≠ô)。因此 λ 必须包含 Amb，且**再高的意图证据精度也无法补偿指代错误**。系：指代是**非补偿性安全项**（呼应 R71 的非补偿否决）。

**引理 36（负证据的可见性条件）** 对区域 x，检测灵敏度 σ_det(x)=P(检测到 | 有物体)。则 P(声称 absence | 有物体)=1−σ_det(x)。若规划把 absence 当作确定的 free，碰撞概率 ≥ (1−σ_det)·p_occ。把 absence 证据按 σ_det 加权（σ_det<ρ_det 时拒绝使用）可给出上界。系：**absence-of-evidence 只在可见性足够高时才是 evidence-of-absence。**

**引理 37（conformal 覆盖 ⇒ 答案集鲁棒风险界）** 若 P(Y\*∈A_α) ≥ 1−α，且控制器对 A_α 取最坏情况风险，则以概率 ≥1−α 有 Risk_realized ≤ max_{y∈A_α} Risk(y)。覆盖保证是有限样本的，只要求可交换性；答案集大小直接控制保守度。系：**A_α 是无需分布假设的合法鲁棒不确定集，空集（拒答）是合法的保守极端。**

**引理 38（AVQ 有限停止）** 采集成本有正下界；熵下降在条件独立测量下是次模的（相关证据下用自适应次模或经验上界），故贪心边际增益非增 ⇒ 存在有限步使边际净 VoI ≤ 0。AVQ 在该步停止。系：**三源主动测量与 R72 的 ERVOI 共享同一个"有限停止"结构，不是调参。**

**定理 27（严格包含与安全单调）** 在定义 381 下，关闭 VQA/审计/RVG 后 VISUAL 逐指令等于 R72；且 λ_VISUAL ≥ λ_R72（逐项），因为 u_vis、Amb、H[v]、worst 是非负新增项，审计失败时 CIG=0。故 VISUAL 的风险界 ≤ R72。**安全单调不减，效率仅在"视觉可计量、指代可绑定、答案有覆盖"时获益。**

**定理 28（视觉证书 ⇒ 视觉证据有效性）** 若 J_VIS 有效，则证据在有效域 D_vis 内、覆盖率 ≥1−α、GC 有效、RVG 证书有效；于是下游使用 A_α 的最坏情况风险以概率 ≥1−α 被 max_{y∈A_α}Risk 界定（再加 R72 的 ε_emb）。证明重量落在：**校准集与部署可交换、模型未被投毒、行为反事实测试确实探测了因果依赖、参照系确实消解正确**。

**定理 29（审计单调性 / 无风险放大）** λ(·) 对不确定度单调非减。审计失败 ⇒ CIG=0 且 u_vis 取保守值 ⇒ λ 不低于"无视觉证据"的 R72 基线；审计通过 ⇒ 允许的 λ 下降 Δλ 被 CIG_vis 界定，而 CIG_vis 又被 conformal 集的最坏情况风险下降界定。故**审计只能解锁可证明的信息增益，不能制造信息，也不能让系统比未审计时更激进**。系：这直接封堵了"证书作为风险放大器"的 Goodhart 通道。

## 6. 次级风险与缓解

1. **sham 设计泄漏** → 掩码必须中性填充且不泄露形状/阴影；用多类 sham（遮挡/均值/异场景）取最小 VIC；对 VIC 本身做敏感性分析。
2. **归因不可靠** → 以行为反事实为主、显著性为辅；GC 用"掩码必须改变答案、对照区域不应改变"的成对测试，而非单一 saliency 阈值。
3. **覆盖不可交换** → 逐族校准 + ACI + 组合 OOD 回退；部署前做"校准集 vs 部署集"交换性检验。
4. **指代澄清负担过重** → 先尝试主动视角/换问法，再问人；把澄清次数纳入 ERVOI 预算与人类负担指标。
5. **视觉采集扰动人与场景** → a_vis 计入 L1/L2 反作用预算；禁止不可逆采集；相机运动受独立安全包络约束。
6. **审计成本破坏实时性** → 审计只在感知域、事件触发（高风险查询/低置信/高 Amb 时），控制域只读标量。
7. **证书伪造/投毒** → J_VIS 哈希链 + 模型/校准集版本绑定；断链即降级（沿用 R72 TCHAIN）。

## 7. 本轮最大风险（一句话）

**当视觉审计的校准集与部署分布不可交换、而 VLM 又对某个与任务无关的虚假线索（场景文字、颜色、纹理）稳定响应时，VIC/TIC/GC/conformal 可能同时"通过"——系统会拿到一张盖章的 J_VIS，把幻觉当作认证信息增益去抵扣 U_epi、压低 λ，从而比未审计时更快更远地执行错误动作；这就是"审计通过、证书齐全、指标全在有效域内"的视觉版自信地错，且审计本身成了风险放大器。**

# 第 73 轮产物 · 创新点清单 v1：VISUAL-GAUGE-RAS（视觉 × 计量有效 × 语义审计 × 指代可追溯 × 主动询问的抗幻觉证据闭环；VPM×VQA-G×VIS×DGR×AVQ×GAUGE-RAS†）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 把 GAUGE 从认知层下沉到具身层：REG 实时调度契约、IRL 意图隐变量、DMEM 接触计量、EREFLEX 三层反作用、S2R-UQ 参数桥接。但 R72 仍把**视觉**当成 `obs`：
> - 缺 **视觉计量（VPM）**：视觉不是传感器，是工况条件化的推理管线；遮挡/反光/透明/低光/模糊导致**结构性静默失败**，而"没检测到"被错误地当作"不存在"。
> - 缺 **VQA 审计（VQA-G / VIS）**：VLM 会被语言先验补全（盲答）、会幻觉、会在未见组合上崩溃；可靠度是**查询的函数**而非标量；需要 conformal 答案集与覆盖保证。
> - 缺 **指代落地（DGR）**：R72 默认指代已解析；"左边那个"的参照系/属性/计数/否定绑定是视觉-意图的共享瓶颈，且是**非补偿性安全项**。
> - 缺 **主动视觉（AVQ）**：换视角/变焦/去遮挡/换问法是可选测量动作，应与"问人/动手"统一进 VoI 与反作用预算。
> - 缺 **负证据纪律**：absence-of-evidence 只在可见性足够高时才是 evidence-of-absence。
>
> 本轮核心命题：**从「我的测量链可信吗」进化为「当我的眼睛是一台会盲答、会幻觉、会在遮挡与未见组合上静默失败的推理仪器时，我还能逐指令兑现风险界吗？」** ——**视觉计量审计闭环**。
>
> IP 编号：IP-295~302（共 8 个）+ GAUGE-RAS/EMBODIED 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价；审计只解锁真实信息增益，不制造信息。**

## 2. 形式化定义（要点版）

**定义 366（总览与六不变式）** 查询条件化、视觉计量完整性、指代可追溯、盲答否决、覆盖保证、严格退化链。

**定义 367（视觉计量项）** 每条视觉证据必须携带 (q, a_vis, v, y, A_α, u_vis, D_vis, GC, τ, I⊥)；无 (q,a_vis) 不构成证据。

**定义 368（视觉工况与条件似然）** v 由多视图一致性/编码器 OOD/图像统计/问答一致性推断；H[b(v)] 进入 λ_floor 与 V-IVG。

**定义 369（五分量与协方差修正）** appear/geo/ground/query/comp；**只在工况内近似正交**，跨工况有相关项；取完全相关与独立界之间的保守值。

**定义 370（VIC/TIC/GC）** sham 空白检验 + 任务信息贡献 + 行为反事实 grounding；归因仅作辅助。任一不满足 ⇒ 盲答否决。

**定义 371（分层 Conformal VQA）** A_α 覆盖 ≥1−α；族→父类→全局回退；ACI 监测；空集=合法拒答。

**定义 372（RVG 指代落地）** 组合树 + 参照系后验 + 绑定 + Amb；非唯一/高歧义 ⇒ 澄清。

**定义 373（负证据纪律）** absence 权重 = σ_det；σ_det<ρ_det 区域不得声称 absence；未见空间按可能占用处理。

**定义 374（V-RISK 与 CIG）** U_epi^post = U_epi − CIG_vis + u_vis^residual；λ 对 A_α 取最坏情况；审计失败 ⇒ CIG=0、u_vis 保守、λ 不降。

**定义 375（AVQ 三源统一）** g\* = argmax VoI_total，s.t. 三层稳态/预算/不可逆采集；并列优先非接触、非扰动；max VoI≤0 停止。

**定义 376（V-MIB）** 视觉族 + 指代族 + 时序族；遵循六元组与 DAG 分层。

**定义 377（V-IVG）** 视觉/指代/负证据/采集失效条件；任一失效即对应降级。

**定义 378（J_VIS 证书）** 只有 J_VIS 有效才允许产生 CIG_vis。

**定义 379（视觉威胁模型 ℰ_VIS）** 对抗贴片、镜头漂移、假 absence、相机欺骗、场景文本注入、对抗问法、指代偷换、参照系歧义。

**定义 380（联合后验与 CCM）** b_t(s,z,c,v,o\*)；o\* 连接视觉与意图；接触 c 与视觉 v 是"测量上下文 κ"的两个实例，共享同一审计骨架。

**定义 381（严格退化链）** J_VIS 失效/RVG 失效/采集不可达/全失效的逐级退化；始终保留 R72 λ_floor 与 R68 硬安全包络。

## 3. 核心数据结构与证书契约

```python
@dataclass(frozen=True)
class VisualEvidence:
    q: str; a_vis: AcquisitionAction
    v_post: Dist[VisualRegime]          # b_t(v)
    det: DetectionResult
    u_vis: float; u_breakdown: dict     # appear/geo/ground/query/comp/cross
    sigma_det: RegionMap                # 可见性/检测灵敏度
    absence: RegionMap                  # 负证据权重 w_abs = sigma_det
    tau: str                            # image/model/q/calib 哈希链

@dataclass(frozen=True)
class VQAEvidence:
    q: str; a_vis: AcquisitionAction
    A: Set[str]                         # conformal 答案集（可为空）
    calib_id: str; alpha: float
    u_set: float                        # log(1+|A|)
    audit: AuditResult | None           # VIC/TIC/GC
    tau: str

@dataclass(frozen=True)
class RVGResult:
    b: Dist[str]                        # b_t(o*)
    amb: float                          # H[b_t(o*)]
    bF: Dist[Frame]                     # 参照系后验
    tree: CompositionTree               # 属性/关系/计数/否定/指示
    unique: bool
    clarify: bool
    tau: str

@dataclass(frozen=True)
class J_VIS:
    image_hash: str; model_hash: str; q_hash: str
    a_vis: AcquisitionAction
    v_post: Dist[VisualRegime]
    calib_id: str; alpha: float
    coverage_status: str                # ok / broken / recovering
    VIC: float; TIC: float
    gc_ok: bool; rvg_tau: str | None
    tchain: str; ver: str

    def valid(self) -> bool:
        return (self.coverage_status == 'ok' and self.gc_ok
                and self.VIC >= TAU_VIC and self.TIC >= TAU_TIC
                and self.v_post.entropy() <= TAU_HV
                and verify_chain(self.tchain))
```

**API 契约（三域边界）**
- 感知域 → 计量域：`VisualEvidence / VQAEvidence / RVGResult`（含 audit 结果）。
- 计量域 → 控制域：**只写快照标量** `(u_vis, H[v], Amb, worst_risk, j_vis_valid)`；控制域只读、不等待、不回写（沿用 R72 定义 363）。
- 审计与 ACI 只在感知/计量域运行，**不进入控制环关键路径**。

```python
# IP-295 VPM
class VisualPerceptionMetrology:
    def update(self, frame, q, a_vis):
        v_post = self.regime_net.infer(frame, a_vis)
        det, feat = self.detector(frame)
        u = self.calib5.components(frame, q, v_post, feat)
        u_vis = union_bound(u, self.corr_ub(v_post))       # 不假设正交
        absence, sigma = self.visibility.absence(frame, det)
        return VisualEvidence(q, a_vis, v_post, det, u_vis,
                              u, sigma, absence, hash_all(frame, q, a_vis))

# IP-296 VQA-G + IP-297 VIS：先出答案集，再审计
def vqa_grounded(vlm, calib, vis_audit, q, frame, a_vis, ref_region):
    cal = calib.pick(query_family(q))
    logits = vlm(frame, q)
    A = cal.answer_set(logits, cal.alpha)
    if not A:
        return VQAEvidence.abstain(q, a_vis)
    audit = vis_audit.audit(q, frame, A, ref_region, a_vis)
    ev = VQAEvidence(q, a_vis, A, cal.id, cal.alpha, log1p(len(A)), audit, ...)
    return ev

# IP-298 DGR：指代先绑定，再允许行动
def resolve_referent(r, gesture, frame, robot_pose):
    tree = parser.parse(r)
    O = detector.instances(frame)
    bF = frame_resolver.infer(tree, gesture, robot_pose)
    b  = softmax([scorer.score(tree, o, bF, frame) for o in O])
    amb = entropy(b)
    unique = max(b.values()) >= TAU_BIND and count_gt(b, EPS) == 1
    return RVGResult(b, amb, bF, tree, unique,
                     clarify=(amb > TAU_AMB or not unique))

# IP-299 AVQ：三源统一 VoI
def choose_measurement(b_t, z, c, vis, rvg, budget):
    best = None
    for g in ask_human_candidates(...) + visual_candidates(vis, rvg) + contact_candidates(...):
        if not safety_ok(g) or not budget.allow(g):
            continue
        voi = task_info_gain(g, b_t, z, rvg) - acq_cost(g) - disturbance(g) - reflex(g)
        best = max(best, Candidate(g, voi), key=lambda x: (x.voi, x.non_contact))
    return best if best and best.voi > 0 else None

# IP-300 VSAFE：认证信息增益 + 最坏情况风险
def visual_risk(U_ale, U_epi, H_z, u_tac, vis, rvg, A, p):
    ok = vis.j_vis.valid() and coverage_ok(vis) and vis.audit.gc_ok
    cg = certified_info_gain(vis, A) if ok else 0.0
    u_vis = vis.u_vis if ok else vis.u_conservative
    U_epi_post = max(0.0, U_epi - cg) + (0.0 if ok else u_vis)
    amb = rvg.amb if rvg else 0.0
    denom = U_ale + U_epi_post + H_z + u_tac + u_vis + amb + entropy(vis.v_post) \
            + max_answer_set_risk(A)
    return max(p.lam_base * (1 + denom / p.lam_scale),
               p.lam_floor * (1 + denom))

# IP-302 主闭环（视觉只进感知/计量域，控制域读标量）
def VISUAL_GAUGE_RAS_round(M, obs, audio, tac, q):
    # 控制域（硬实时）：只读快照
    snap = M.snapshot.read_latest()
    lam = visual_risk(snap.U_ale, snap.U_epi, snap.H_z, snap.u_tac,
                      snap.vis, snap.rvg, snap.A, M.risk_params)
    k = M.ach.certified_prefix(M.ach.propose_ctrl(...), lam, ...)
    M.ctrl_out.publish(k, lam)

    # 计量域（软实时）：意图 + 指代 + 审计汇总
    if M.clock.due_metric():
        b_t = M.bse.step_full(...)
        rvg = M.dgr.resolve(M.last_ref, M.last_gesture, obs.image, M.pose)
        gate = M.v_ivg.check(M.registry, b_t, rvg, M.vis_ev, snap.j_vis)
        if not gate.valid:
            M.mode = gate.fallback            # VQA->classic / RVG->clarify / R72 / R68
        M.snapshot.write(b_t, rvg, M.vis_ev, gate, M.psi_hat, M.tac_ev)

    # 感知域（Best-effort）：视觉计量 + VQA + 审计 + 主动采集
    vis_ev = M.vpm.update(obs.image, q, M.last_a_vis)
    if M.needs_vqa(q, vis_ev):
        ans = vqa_grounded(M.vlm, M.calib, M.audit, q, obs.image,
                           M.last_a_vis, M.last_ref_region)
        M.vis_ev = ans
    if M.avq_due(vis_ev, rvg):
        g = choose_measurement(b_t, M.z_dist, M.c_dist, vis_ev, rvg, M.budget)
        if g: M.last_a_vis = g.execute()
    return k, lam, J_VIS(M)
```

## 5. 推导要点

**引理 33（查询条件化不可标量化）** 全局平均 ECE 掩盖难族的最大误差；风险界取 max_q，标量缩放必在难族上低估。

**引理 34（盲答否决）** Y⊥S ⇒ 贝叶斯更新为常数，非平凡似然比只注入偏置；TIC=0 同理。⇒ CIG 必须为 0。

**引理 35（指代非补偿）** P(fail) = P(o\*≠ô) + P(o\*=ô)P(fail|·)；第一项与意图精度无关，λ 必须含 Amb。

**引理 36（负证据可见性）** P(声称 absence|有物)=1−σ_det；未加权 absence 会把碰撞概率下界漏掉。

**引理 37（conformal ⇒ 鲁棒风险界）** P(Y\*∈A_α)≥1−α 且对 A_α 取最坏 ⇒ 以 ≥1−α 概率 Risk ≤ max_{A_α}Risk；无需分布假设。

**引理 38（AVQ 有限停止）** 采集成本正下界 + 边际信息增益非增（条件独立次模/相关下经验上界）⇒ 有限步停止。

**定理 27（严格包含与安全单调）** 关闭视觉模块逐指令等于 R72；新增项非负、审计失败 CIG=0 ⇒ λ_VISUAL ≥ λ_R72，风险界 ≤ R72。

**定理 28（J_VIS ⇒ 证据有效性）** 证书有效 ⇒ 覆盖/接地/指代均有效；下游最坏情况风险以 ≥1−α 被 max_{A_α}Risk + ε_emb 界定。证明重量在可交换性、未投毒、反事实测试有效性、参照系正确性。

**定理 29（审计单调性 / 无风险放大）** 审计失败 ⇒ CIG=0、u_vis 保守 ⇒ λ 不降；审计通过 ⇒ Δλ 被 CIG 与 max_{A_α}Risk 下降共同界定。**审计只能解锁可证明的信息增益。**

## 8. 本轮最大风险（一句话）

**若校准集与部署分布不可交换、VLM 又对任务无关的虚假线索稳定响应，VIC/TIC/GC/conformal 可能同时通过，系统会拿 J_VIS 把幻觉当作认证信息增益去抵扣 U_epi、压低 λ，从而比未审计时更快更远地执行错误动作——审计本身成为风险放大器。**
