# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计层」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「机器人竞赛」×「力觉传感」）

> R70 把 FLUID 的「动作模态不确定性」升级为「世界状态后验」，交付了 BSE、基线协议与原型验收。但它仍站在三个未言明的假设上：(a) **证据是被动的、廉价的**——看/问/等不改变世界；(b) **安全可以从信念继承**——只要后验足够准，动作就足够安全；(c) **所有模态同等可信**——人类回答与传感器残差可以在同一个 Bayes 更新里直接相加。力觉/触觉把这三条同时打破：
> - 接触不是观测，是**干预（do）**：碰一下会改变物体状态、消耗不可逆的机会；「知道」与「还能做什么」第一次正面冲突。
> - 接触是**稀疏事件 + 高带宽**的：1kHz 触觉流不可能塞进 R70 的 4.5ms 后验环；安全必须在慢环之外独立成立。
> - 竞赛是**对抗、计分、限时**的：对手会主动制造你看到的证据（虚招、示弱、诱使接触），观测模型第一次多出「对手」这一项。
>
> 「机器人竞赛」给出的不是场景装饰，而是三样结构性约束：**零和计分（该不该接触是一个 contest 决策）**、**对抗性观测（证据可被策略性制造）**、**时限与规则（裁判可独立验证的硬约束）**。「力觉传感」给出的也不只是新传感器，而是**唯一一类不能被对手凭空伪造的证据——物理不变量**：动量/能量平衡、摩擦锥、滑移动力学。对手要让你「看错」，可以近乎零成本地演；要让你「摸错」，必须付出真实的力与功。
>
> 核心命题：把 BELIEF-RAS 的「被动贝叶斯估计 + 廉价查询」升级为 **GRASP-RAS：博弈化（Game-theoretic）、反射门控（Reflex-gated）、主动干预（Active-interventional）、物理接触感知（Physical-contact sensing）** 的闭环。三件事同时发生：epistemic 由**干预**而非观测来消解（interventional VoI，显式扣除不可逆机会成本）；安全由**反射包络**而非信念正确性来保证（safety ⊥ belief）；对抗证据由**物理不变量通道**来裁决（骗过力学必须真的做功）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「我信什么」，R71 问「**为了知道，我愿意在物理世界付出什么、又凭什么证明即使我想错了也不会出事**」。

## 0. 直觉与动机

**灵感 1（力觉 → 接触是干预，不是观测）**
直觉：视觉可以「多看两眼」，触觉不能「多碰两下」而不改变世界。你为了测摩擦系数去推一下，可能已经把物体推离抓取位；为了确认是否抓牢而加力，可能压碎它。因此信息价值必须减去「我还剩多少选择」。用因果语言写很干净：普通感知是 p(y|s)，接触探测是 p(y|do(g), s)，而 do(g) 同时改变下一状态 s' 与可行策略集 Φ(s')。R70 的 VoI 只算了前一半。
这一条还给出一个很硬的推论：**要辨识摩擦系数，探测必须带切向激励；而切向激励天然逼近滑动边界**。最有信息量的接触动作，恰好最接近不可逆失败——「好奇心」与「稳定性」在最优点上短兵相接。这不是调参能消掉的，是结构性的 risk–information Pareto。

**灵感 2（力觉 → 物理不变量是唯一不能零成本伪造的证据）**
直觉：对手可以假装很重（绷紧身体），可以假装很轻（顺从），可以用表情/语气/行为误导你；但他不能在不施加真实力、不做真实功的情况下改变你测到的力旋量。Newton–Euler 残差、摩擦锥残差、滑移运动学残差，对「同一物理状态」下的任何策略都一致。于是证据第一次可以按**可伪造成本**分层：物理不变量（伪造需做功）> 被动传感器（伪造需改环境）> 行为/语言（伪造近乎免费）。R69 的「k 个正交源一致」在这里升级为「**按对抗成本加权的证据层级**」：免费可伪造的证据永远不能单独定案，而物理不变量可以只靠一条就接近定案。

**灵感 3（机器人竞赛 → 该不该接触是一个 contest 决策）**
直觉：竞赛里「稳」和「赢」是两件事。保守不动可以零失误，但零得分；主动接触能拿分，但一次滑脱可能直接输掉回合。R70 的风险缩放只会「不确定就收紧」，在计分系统里等价于「永远不进攻」。正确的问题不是「风险多小」，而是「**这次接触的期望得分增量，是否覆盖它的风险、机会成本与对手的反制收益**」。这把 R71 的目标从「最小化不确定性」改写成「在不确定性下最大化竞赛效用」——不确定性只是成本项之一。

**灵感 4（机器人竞赛 → 对手是另一个估计器，观测是双向的）**
直觉：对手也在估计你。你的探测动作会**泄露信息**（你想测摩擦 → 你要发力 → 他预判你的接触方向），你的犹豫也会泄露（后验熵高 → 你还没定 → 他可以诱使）。所以信息动作的价值要减去「情报泄漏成本」，主动感知因此变成一个**信号博弈**：有时最优策略是「做出一个无信息但误导性的接触」，即**反侦察**。R69 把交互当双刃剑只考虑了被投毒；竞赛把「你的观测行为本身是策略」摆上台面。

**灵感 5（力觉 + 实时 → 把安全从信念里剥离出来）**
直觉：R70 最大的工程脆弱性是「后验自信地错 → 动作不安全」。但接触任务的安全其实可以不依赖任何学习组件：用一个 1kHz 的**反射包络**（基于实测力旋量的 CBF-QP）把任何上层指令投影进安全集。上层可以错得离谱，只要投影有效，硬约束（力上限、摩擦锥、滑移、冲量）就不会被破坏。这不是「再加一层」，而是**改变了安全的证明义务**：从「证明我的信念对」变成「证明我的包络对」——后者更小、更可测、可被裁判独立验证。代价是：包络模型成为新的单点承重墙（见本轮最大风险）。

**灵感 6（竞赛 → 假设也可以「比赛」）**
直觉：R70 为省算力用固定 K 采样做模态/状态聚类；竞赛的限时预算要求更狠。接触模式是离散互斥的（自由/接触/粘滞/滑移/分离），正适合用 SPRT/racing 让假设彼此「淘汰」：谁先被证据淘汰谁出局，期望样本数由 KL 散度决定，通常远小于固定 K 聚类。把淘汰赛机制搬进假设空间，是对实时预算最直接的回应。

## 1. 形式化定义（增量：定义 331–349）

**定义 331（GRASP-RAS 总览与四不变式）** GRASP-RAS = (CI-BSE, IVoI, DOPE, PIR, ADVE, REFLEX, SPRT-R, CG, OPP-θ, SAFE-HOLD, RAS-WM‡)。四不变式：
(i) **零学习写操作**（继承 R68）；
(ii) **干预预算**：单位时间接触干预 ≤ 1 次、累积冲量 ≤ J_max、不可逆机会损失 ≤ OV_max；
(iii) **反射包络硬约束**：任何上层指令必须经 REFLEX 投影，硬约束由快速环独立保证，与 b_t 无关；
(iv) **证据分层纪律**：物理不变量证据可直接更新；行为/语言证据须按可伪造成本折价，且不得单独触发不可逆动作。

**定义 332（接触增广状态）** s = (s_phys, s_mode, θ)。s_phys = (m, c_com, μ, k, q_grasp)（质量、质心、摩擦系数、刚度、抓取质量）；s_mode ∈ {free, approach, first_contact, stick, slip, separate}；θ 为对手类型。b_t 同时维护连续参数的粒子集与离散模式/类型的分类分布。

**定义 333（接触观测模型）** y_t = (w_t, τ_t, T_t, e_t)：力旋量、关节力矩、触觉阵列、接触事件标志。p(y|s,g) = p_phys(w,τ,T|s,g) · p_event(e|s_mode,s_mode',g)。事件稀疏；连续触觉流由 REFLEX 消费，BSE 只吃事件与降采样摘要。

**定义 334（接触干预模型与机会价值损失）** 接触动作 g 通过 do(g) 改变状态：s' ~ T(s, do(g))。定义机会价值 OV(b) = E_{s~b}[max_{π∈Φ(s)} J_π(s)]，不可逆机会损失 OVL(g) = E_b[OV(b) − E_{s'|s,do(g)} OV(b')]。R70 的「观测不变世界」对应 OVL ≡ 0，是本定义的特例。

**定义 335（干预式 VoI）** VoI_int(g) = I(s; y | do(g), b_t) − β·OVL(g) − c(g)，其中 I 用后验熵差估计：H[b_t] − E_y[H[b_{t+1}]]。选择 g* = argmax_g VoI_int(g) s.t. risk(g) ≤ ε_int、预算未超、PE(g) 满足（定义 336）。VoI_int ≤ 0 ⇒ 不接触，回退 BELIEF/R68 的非接触通道。

**定义 336（持续激励与 D-最优探针 DOPE）** 待辨识物理参数 φ = (m, c_com, μ, k)。接触力旋量 w ≈ W(s, φ, g)，Fisher 信息 FIM(φ;g) = J_g^T Σ_w^{-1} J_g，J_g = ∂W/∂φ。探针设计 g* = argmax_g log det FIM(φ;g) s.t. 力/摩擦锥/冲量/OVL 约束。**可辨识性条件（PE）**：FIM 在 φ 的相关子空间上满秩；仅法向激励无法辨识 μ（需切向分量）。系：要学 μ，必须靠近滑移边界——这是 risk–information 的结构性耦合。

**定义 337（物理不变量残差 PIR）** 三条不依赖对手意图的残差：
r_NE = ‖M(q)q̈ + C(q,q̇)q̇ + g(q) − τ_meas − J^T w_meas‖；
r_FC = max(0, |f_t| − μ̂ f_n)（摩擦锥违背量）；
r_SLIP = |v_t|·1[stick 预测] + |f_t − μ̂ f_n·sign(v_t)|·1[slip 预测]（滑移动力学违背）。
r_phys = (r_NE, r_FC, r_SLIP)。**命题（成本-可伪造性）**：在已知机器人动力学与质量矩阵的前提下，对手要使 r_NE 低于 ε 而不改变真实物理状态，必须至少注入相应的力/功，成本 W ≥ W_min(ε)；PIR 因此是「按焦耳计费」的证据通道。

**定义 338（对抗证据门 ADVE）** 采用 ε-污染观测模型：真实观测以 1−ε 来自 p(y|s)，以 ε 来自对手任意分布 q(y)。鲁棒后验 b^rob ∝ b · min(L(y|s), τ_adv·max_{s'} L(y|s'))，其中 τ_adv 由对手信息预算 B_adv（≈ 其可做功/时间折算）标定。行为证据的似然比按层级折价 κ_beh < κ_sensor < κ_phys = 1。若 PIR 与行为证据冲突，U_epi 上调，且禁止由行为证据单独触发不可逆动作。

**定义 339（双速率反射包络 REFLEX）** 快环 f_fast ≥ 1kHz：给定上层参考 g_cmd，求解
g* = argmin_g ‖g − g_cmd‖²_Q s.t. L_f h_i(x) + L_g h_i(x)g + α_i h_i(x) ≥ 0, ∀i，
h = (F_max − f_n, μ f_n − |f_t|, s_max − |v_slip|, J_max − ∫f dt, 关节/热限)。h 由**实测**力旋量与本体感受计算。慢环 f_slow（事件触发）只提供 g_cmd。**定理 20（安全 ⊥ 信念）**：若 h 是真实接触动力学的有效 CBF 且快环时延有界，则任意有界 g_cmd（包括由错误 b_t 产生的指令）经投影后满足 h ≥ 0；安全不依赖 b_t 的正确性。输入时延用 delay-aware CBF（backward reachable set）补偿。

**定义 340（事件触发 BSE 调度）** 快环检测接触相变事件（free→contact、stick→slip、separate 等，带滞回阈值）；事件触发一次完整 CI-BSE 更新（P99 ≤ 0.8ms），非事件期只做 100Hz 轻量预测。事件检测延迟 τ_det 有界；BSE 在 τ_det 后与真值相变对齐（概率保证）。这样重后验永不出现在 1kHz 快路径上。

**定义 341（假设淘汰赛 SPRT-R）** 接触模式假设 {m_k} 两两进行 SPRT：累积对数似然比 Λ_ij 越过 A = log((1−β)/α) 或 B = log(β/(1−α)) 即淘汰/保留。经典 SPRT 的期望样本数 E[N_ij] ≈ [w_i D(m_i‖m_j) + w_j D(m_j‖m_i)]/(w_i+w_j) 量级；用 racing 把计算预算优先给「未分胜负」的模式对。替代 R70 固定 K 聚类，随证据增长自适应终止。

**定义 342（竞赛阈值 CG）** 竞赛效用 U = 得分率 − ρ_risk·风险 − ρ_time·耗时 − ρ_leak·情报泄漏。接触动作 g 被采纳当且仅当
ΔU(g) = E[score gain from resolving ambiguity | g] − ρ_risk·Risk(g) − ρ_time·c(g) − ρ_leak·Leak(g) > 0。
这是把「该不该知道」翻译成「该不该赌」的判定线；R70 的「不确定就收紧」对应 ρ_score = 0 的退化。

**定义 343（对手类型后验 OPP-θ）** θ ∈ Θ（合作/中立/虚招/诱捕/抢攻…），b_t(θ) 仅由行为证据更新且受 ADVE 折价；物理不变量证据不更新 θ（对手不能靠力学伪造意图）。θ 影响 Leak(g) 与 Risk(g)，从而影响 CG 阈值。

**定义 344（证据分层纪律†）** 三层：物理不变量（PIR，κ=1，可近单独定案）、被动传感（视觉/本体，κ_sensor，需两条一致）、行为/语言（κ_beh，需 k≥2 正交一致且不得单独授权不可逆动作）。R69 的 k-一致纪律成为最弱层的规则；最强层由「做功成本」担保。

**定义 345（接触校准门 MCG-contact）** 校准对象新增：接触模式后验可靠性 ECE_contact、力模型残差分布、摩擦锥参数漂移。ECE_contact > τ ⇒ 禁用由接触证据驱动的 CG/VoI，切入 **SAFE-HOLD**（只保留 REFLEX + 非接触保守通道），而不是退回 R70（R70 仍可能用错误后验指挥接触）。

**定义 346（最终安全退避 SAFE-HOLD）** 当 PIR 冲突、ECE_contact 越界、对手类型后验不可信或干预预算耗尽时，冻结一切由学习组件授权的接触动作；仅保留 REFLEX 的硬约束投影与「退出/保持」元动作。**SAFE-HOLD 不依赖任何学习模块的正确性**——它是 GRASP 安全链的最底端，也是 R68 之外新的「零信任」边界。

**定义 347（AIC-GRASP 威胁模型）** ℰ_GRASP = ℰ_BELIEF × ℰ_contact × ℰ_adversary：摩擦/刚度误辨识、力传感器饱和/死通道、触觉阵列漂移、执行器时延、虚招/示弱/诱捕、物理 spoofing（用外力伪造接触）、滑移诱发的观测污染、快环 CBF 模型失配。

**定义 348（证书 J_GRASP）** J_GRASP = (J_BELIEF, ECE_contact, PIR_p95, PE_margin, reflex_envelope_hash, ovl_p95, adversary_margin, safe_hold_count, grasp_ver)。Valid ⇔ Valid(J_BELIEF) ∧ ECE_contact ≤ τ ∧ PIR 无未解释冲突 ∧ 反射包络版本与实测一致。

**定义 349（双预算与不可逆配额）** 预算 = (算力预算, 接触预算, 不可逆配额)。不可逆配额按 episode 计：每次「可能致失败」的接触消耗配额，配额耗尽后只允许可逆探测。竞赛效用下，配额是比时间更硬的约束。

```python
# IP-275/276 CI-BSE：事件触发 + 干预式更新
class ContactInterventionalBSE:
    def __init__(self, phys_model, particle_bank, mode_filter):
        self.M, self.pf, self.mf = phys_model, particle_bank, mode_filter

    def predict(self, b, g_prev):
        return self.pf.predict(b, g_prev), self.mf.predict(b)   # do(g) 改变状态

    def event_update(self, b, y, g_prev):
        r_phys = physics_invariant_residual(self.M, y, b)       # IP-279
        w_phys = pir_likelihood(r_phys)                          # kappa = 1
        w_beh  = robust_behavior_likelihood(y, b, self.tau_adv) # IP-280
        return self.pf.update(b, w_phys * w_beh)

# IP-277/278 IVoI + DOPE
def interventional_voi(b, g, phys_model, ov_model):
    info = entropy(b) - expected_entropy(b, g, phys_model)
    ovl  = ov_model(b) - expectation(b, lambda s: ov_model(T(s, g)))
    return info - BETA * ovl - cost(g)

def d_optimal_probe(b, constraints):
    best = None
    for g in probe_candidates(b):
        if not constraints.allow(g): continue
        fim = fisher_information(phys_model, b, g)
        if not persistent_excitation_ok(fim): continue          # 仅法向 -> 不可辨识 mu
        score = logdet_regularized(fim) - BETA * ovl(b, g)
        if best is None or score > best.score: best = (g, score, fim)
    return best

# IP-279 PIR
def physics_invariant_residual(M, y, b):
    return (M.rigid_body_residual(y.tau, y.w),              # r_NE
            friction_cone_violation(y.w, mu_hat(b)),         # r_FC
            slip_kinematic_residual(y, b))                   # r_SLIP

# IP-280 ADVE：epsilon-污染鲁棒更新（似然比截断）
def robust_behavior_likelihood(y, b, tau_adv):
    L = [p_beh(y, s) for s in b.support()]
    return {s: min(L_s, tau_adv * max(L)) for s, L_s in zip(b.support(), L)}

# IP-281 REFLEX：1kHz CBF-QP（快环，只依赖实测 x）
def reflex_filter(x, g_cmd, h_list):
    return solve_qp(cost=lambda g: (g-g_cmd) @ Q @ (g-g_cmd),
                    cons=[cbf_constraint(h, x) for h in h_list])

# IP-282 SPRT-R：假设淘汰赛
def sprt_tournament(modes, y_stream, alpha=1e-3, beta=1e-2):
    alive = set(modes)
    for (i, j) in pairs(alive):
        update(llr[i][j], y_stream)
        if llr[i][j] > A: alive.discard(j)
        elif llr[i][j] < B: alive.discard(i)
        if len(alive) == 1: break
    return alive

def GRASP_RAS_round(M, obs, x_meas):
    # ---- 1kHz 快环：独立于慢环与后验 ----
    g_safe = M.reflex.filter(x_meas, M.g_cmd, M.h_list)        # IP-281
    ev = M.reflex.detect_event(x_meas)                         # IP-340
    if ev is None:
        return g_safe, M.b_t
    # ---- 事件触发的慢环 ----
    b = M.cibse.predict(M.b_t, M.last_g)
    b = M.cibse.event_update(b, obs, M.last_g)                 # PIR + ADVE
    if M.pir.has_unexplained_conflict(b) or M.mcg.ece_contact(b) > TAU:
        return M.safe_hold(g_safe), b                          # IP-285 零信任退避
    cand = M.dope.d_optimal_probe(b, M.budget)                 # IP-278
    g = M.cg.select(cand, b, M.opp_theta)                      # IP-283 / 定义 342
    if g is None or entropy(b) < TAU_ENT:
        M.b_t = b
        return g_safe, b
    g_exec = M.reflex.project_through_reflex(g)                # 干预仍须过快环
    y = M.actuate(g_exec)
    b = M.cibse.event_update(b, y, g_exec)
    M.vqa_iii.submit_async(b, g, y, M.pir.stats(), M.opp_theta) # IP-286
    M.b_t = b
    return g_exec, b
```

## 3. 推导

**引理 23（被动 VoI 的高估）** 若 OVL(g) > 0，则 R70 的被动 VoI_pas(g) = H[b] − E[H[b']] 满足 VoI_pas(g) ≥ VoI_int(g) + β·OVL(g)。即忽略不可逆机会成本会系统性高估探测价值，且高估量随「离抓取/滑移边界的距离」增大而增大。系：R69/R70 在接触任务上会「过度好奇」，必须显式扣除 OVL。

**引理 24（PIR 的伪造成本下界）** 在 A102（机器人连杆质量矩阵与关节力矩测量已知，对手只能通过接触施加力）下，对手使 r_NE ≤ ε 且不改变真实 (m, c_com) 的最小注入功 W_min ≥ c·ε²/‖J^T‖²（一阶扰动展开）。系：骗子要么露馅（r_NE 大），要么付功；不存在「零成本伪装质量」。

**引理 25（ε-污染下鲁棒后验的熵下界）** 若对手的 KL 信息预算 ≤ B_adv（由引理 24 的做功成本与时间折算），则对数域截断 τ_adv 下的鲁棒后验满足 H(b^rob) ≥ H(b) − B_adv。系：ADVE 不是「更保守的拍脑袋」，而是把对手能力换算成熵罚项；B_adv 大则自动退化到接近均匀后验（即「不信任任何行为证据」）。

**引理 26（SPRT-R 的样本-预算权衡）** 对任意两模式 i,j，SPRT 在错误率 (α,β) 下的期望样本 E[N_ij] = O(log(1/α)/D_ij)，D_ij 为模式间 KL 散度；racing 的总期望样本 ≤ K·max_{i,j} E[N_ij] 的常数倍，且显著优于固定 K 采样的最坏情况。系：接触相变越可分辨（D 大），淘汰越快——「竞争」本身就是计算资源分配器。

**定理 20（安全 ⊥ 信念）** 在 A102–A103（有效 CBF、快环有界时延、执行器带宽满足）下，对任意 b_t（包括被投毒或发散的后验）产生的任意有界 g_cmd，REFLEX 投影后的控制满足所有硬约束 h_i ≥ 0；因此 GRASP 的安全保证不依赖 BSE 的正确性。证明要点：CBF 条件保证前向不变性；投影只把 g 拉回可行集；时延由 delay-aware 项吸收。**这是 R71 相对 R70 最重要的结构性改进：把「信念正确」从安全证明的前件中删掉。**

**定理 21（严格包含链与退化边界）** A102–A103 下，GRASP 的期望竞赛效用 ≥ BELIEF ≥ FLUID ≥ R68（在各自可行域上），风险不增；且当无接触动作（𝒜_info∩contact=∅）、OVL≡0、无对手（θ 单点）、PIR 不可用时，GRASP 逐指令退化为 BELIEF（再退化为 R69/R68）。当 ECE_contact 越界或 PIR 冲突时，GRASP 退化为 SAFE-HOLD，而非退化为可能用错后验的 BELIEF——**新边界比旧边界更安全，而不是更弱**。

**定理 22（竞赛阈值的最优性）** 在 A104（得分函数对歧义消解单调、风险与泄漏可加）下，CG 的阈值规则 ΔU > 0 等价于「接触/不接触」二元动作上的贝叶斯最优决策；ρ_score→0 时退化为 R70 的保守规则，ρ_risk→0 时退化为「见缝就探」的贪婪探索。系：R70 的 λ_floor 是 CG 在 ρ_score=0、OVL=0 下的特例。

```python
# IP-276 CI-BSE：事件触发 + 干预式更新（PIR 与 ADVE 双通道）
def ci_bse_update(b, y, g_prev, M):
    b = M.pf.predict(b, g_prev); b = M.mf.predict(b)
    w_phys = pir_likelihood(physics_invariant_residual(M.phys, y, b))   # IP-279, kappa=1
    w_beh  = robust_behavior_likelihood(y, b, M.tau_adv)                # IP-280
    return M.pf.update(b, w_phys * w_beh)

# IP-277/278：干预式 VoI 与 D-最优探针
def select_probe(b, M):
    best = None
    for g in probe_candidates(b):
        if not M.budget.allow(g) or not M.reflex.feasible(g): continue
        fim = fisher_information(M.phys, b, g)
        if not persistent_excitation_ok(fim): continue        # 仅法向 -> mu 不可辨识
        voi = entropy(b) - expected_entropy(b, g, M.phys)
        ovl = expected_option_loss(b, g, M.ov)
        score = voi - BETA * ovl - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-281 REFLEX：1kHz 快环（不读 b_t）
def reflex_filter(x_meas, g_cmd, h_list):
    return solve_qp(cost=lambda g: (g - g_cmd) @ Q @ (g - g_cmd),
                    cons=[cbf_constraint(h, x_meas) for h in h_list])

# IP-287 主闭环：快慢解耦 + 零信任退避
def GRASP_RAS_round(M, obs, x_meas):
    g_safe = reflex_filter(x_meas, M.g_cmd, M.h_list)
    ev = M.reflex.detect_event(x_meas)
    if ev is None:
        return g_safe, M.b_t                                  # 非事件：只跑快环
    b = ci_bse_update(M.b_t, obs, M.last_g, M)
    if M.pir.has_unexplained_conflict(b) or M.mcg.ece_contact(b) > TAU:
        return M.safe_hold(g_safe), b                          # IP-285
    g = select_probe(b, M) if entropy(b) > TAU_ENT else None   # IP-277/278
    g = M.cg.select(g, b, M.opp_theta)                         # IP-283/284
    if g is None:
        M.b_t = b; return g_safe, b
    g_exec = M.reflex.project(g)                               # 干预仍受包络约束
    y = M.actuate(g_exec)
    b = ci_bse_update(b, y, g_exec, M)
    M.vqa_iii.submit_async(b, g, y, M.pir.stats(), M.opp_theta)
    M.b_t = b
    return g_exec, b
```

## 4. 推导（新增）

- **引理 23（被动 VoI 高估）**：OVL>0 时 VoI_pas ≥ VoI_int + β·OVL；忽略不可逆成本会系统性「过度好奇」。
- **引理 24（PIR 伪造下界）**：对手使 r_NE≤ε 且不改变真实质量/质心，至少需注入功 W_min ≥ c·ε²/‖J^T‖²；骗力学必须付焦耳。
- **引理 25（鲁棒后验熵下界）**：对手 KL 预算 ≤ B_adv ⇒ H(b^rob) ≥ H(b) − B_adv；ADVE 把对手能力换算成熵罚。
- **引理 26（SPRT-R 预算）**：E[N_ij]=O(log(1/α)/D_ij)；racing 期望样本远低于固定 K 最坏情况。
- **定理 20（安全 ⊥ 信念）**：有效 CBF + 有界快环时延 ⇒ 任意有界 g_cmd（含错误后验产生者）投影后 h_i≥0；安全证明不再以 b_t 正确为前提。
- **定理 21（严格包含链）**：GRASP ≥ BELIEF ≥ FLUID ≥ R68（效用）/ 风险不增；无接触、OVL≡0、无对手、PIR 不可用时逐指令退化；ECE_contact 越界或 PIR 冲突时退到 SAFE-HOLD（比 BELIEF 更安全）。
- **定理 22（CG 最优性）**：A104 下 ΔU>0 等价于「接触/不接触」的贝叶斯最优决策；ρ_score→0 退化为 R70 保守规则。

## 8. 本轮最大风险

**一句话**：GRASP-RAS 把安全从「信念正确」解耦到「反射包络正确」，但整条新信任链只有一处承重墙——1kHz 反射层的 CBF/摩擦锥/时延模型；**一旦该模型漏掉未建模接触动力学、执行器延迟或摩擦锥漂移，系统就会以「已被证明安全」的姿态执行物理上不可逆的错误动作——把安全押在一个更小、但同样可能错误的模型上，比 R70「信念自信地错」更危险**。
