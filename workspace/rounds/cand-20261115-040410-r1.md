# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉伺服」×「群体智能」）

> R69 把不确定性一分为二，给 epistemic 配了一张嘴：看、问、触。但它仍然是**一个 agent、一个视角、一条信任链**。这留下两个它自己看不见的盲点：
> - **R69 的信息动作是「离散地问」，却没问「看不看得见」**。VoI 假设「再看一眼就能分辨模态」，可如果相机正对一块无纹理平面、特征退化、视差为零，看多久都不会增加信息——**歧义的不可解，不只因为噪声，还因为几何**。视觉伺服恰好把这件事写成了一个可计算的量：交互矩阵 L 的奇异值与条件数。它告诉你「沿哪个方向动、看多少，特征才会分开」，并把「注视」从一次离散查询升级为一条**可认证稳定性的连续控制律**。
> - **R69 的「k 个正交证据源」其实假设了独立性，但在群体里根本不成立**。同一批模型、同一套标定、同一个视角训练出来的 N 个机器人，它们的一致不是「N 个独立证人」，而是「同一个证人说了 N 遍」。群体智能能给出局部规则、去中心化融合、quorum 与鲁棒聚合，但它同时打开了新的深渊：**共识可以把一个相关错误放大成集体确信**。N 份相同偏见叠在一起，不是证据，是回声。
>
> 本轮的核心命题：**在 FLUID-RAS 之上加一层「集体可观性层」——把「还能不能看见」（U_obs，来自视觉伺服的交互矩阵）与「还能不能相信别人看见的」（N_eff，来自失败模式去相关）作为两个新的、彼此对偶的不确定性通道；只有当「信息几何可解且证人来路独立」时，集体才允许比单体更勇敢。** 命名 **OCELLI-RAS**（Observability-Conditioned Epistemic Local-rule Interaction；ocelli 是昆虫群体共享的分布式单眼——视觉与群体恰好在同一个器官上相遇）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看得见吗、别人看见的和我看见的是同一件事吗**」——不确定性不仅可以是一句提问，也可以是一次为了获取视差而绕行的移动，以及一次对「共识是否只是回声」的怀疑。

## 0. 直觉与动机

**灵感 1（视觉伺服 → 信息获取是几何受控的过程，不是一次查询）**
直觉：IBVS 的出发点是特征误差 e = s − s* 与相机旋量 v_c 的线性关系 ṡ = L v_c。L 退化（边缘正视图、所有特征共线、纯旋转下的平移不可观、深度缺失导致视差为零）时，特征对相机运动几乎不响应，任何「再看一眼」都是空转。R69 的 VoI 只算了「后验熵能降多少」，却没问「物理上到底能降多少」。把 L 的奇异值接进 VoI，就得到一条乘性折扣：几何越差，同样的注视越不值钱。更关键的推论是：退化时最优信息动作不是凝视，而是**主动移动去改变 L 的秩**——这正是「视觉伺服」相对普通「主动感知」的增量：它把「看」变成一条带稳定性证书的控制律。

**灵感 2（视觉-运动一致性 → 动作通道的第三只眼）**
直觉：R68 的 r_res 测「传感器说的和它对不对得上」，R69 的 Δa 测「动作像不像这个模型会做的」，但两者都默认「我让它动多少，它就真的动了多少」。执行器刻度、轮速计标度、伺服增益、控制时延——这些**动作通道**的慢变漂移会同时骗过前两者：传感器自洽（r_res≈0）、策略似然正常（Δa≈0），可系统实际的视觉-运动增益已经变了。视觉伺服给出第三个量：用 (v_c, ṡ_obs) 辨识 L̂_obs，与冻结的名义 L_nom 比较得 ΔL。COF 只建模「观测→校正」，从不联合观测「指令→特征流」，因此**吸收不了动作通道漂移**。三通道分属传感器、策略、运动学三个故障源，才真正正交。

**灵感 3（群体智能 → 有效独立数，而非成员数）**
直觉：N 个等方差、等相关系数 ρ 的估计，其均值的方差是 σ²(1+(N−1)ρ)/N，N→∞ 只降到 ρσ²。等价地 N_eff = N/(1+(N−1)ρ) → 1/ρ。**超过约 1/ρ 个 agent，再加机器人不带来任何新信息。** 所以群体的价值不是数量，而是失败模式的去相关。去相关证书 DCF 的作用，本质上就是估计 1/ρ、并把超过它的「伪证人」权重清零。这把 R69 的「k 个正交证据源」从一句口号变成可测量、可门控的量。

**灵感 4（局部规则与 quorum → 既不要中央聚合器，也不要多数暴政）**
直觉：群体智能的教训是局部规则 + 鲁棒聚合：有界度通信、几何中位数/截尾均值、quorum sensing 决定何时 commit。两个细节必须坚持：(a) 融合的是**模态后验**而不是动作均值——多峰分布的均值是一个危险虚构（R69 已经知道模态不可糊）；(b) 少数派异议不投票抹掉，而转成**集体取证动作**：移动到能产生视差的位置、换波段、联合触碰。一个正确但孤立的 agent 因此能拉动群体，而不是被多数处决。

**灵感 5（两灵感的焊接点 → (U_obs, 1/N_eff) 四象限）**
直觉：视觉伺服回答「我的几何行不行」，群体智能回答「别人的几何能不能补我的」。于是有四种策略：看得清且证人独立→伺服+共识；看得清但证人只是回声→只信自己；**看不清但证人独立→委派观测**（请另一视角的 agent 去看）；看不清且证人也回声→收手走 FLUID/R68 纯保守。这个二维平面是本轮把两个灵感真正焊在一起的地方。

**灵感 6（新风险 → 伪独立）**
直觉：一旦集体会「互相印证」，就有了新的攻击面：假多样性（不同噪声、同一偏差）、回声转述（A 的答案经 B 转回 A）、多数胁迫少数、探针泄漏（agent 知道被测试而伪装）、延迟诱发的陈旧共识。去相关证书本身是从审计数据估出来的，可被博弈。**伪独立会把 R69 的「一个会撒谎的嘴巴」升级成「一群互相盖章的嘴巴」——R69 是问错，R70 是集体证明错。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（OCELLI-RAS 总览）** OCELLI-RAS = (VIS, OBS, JAC, DCF, QSC, MDV, CFL, RAS-WM‡)。在 FLUID-RAS（FMP×AUD×MINT×CIA×FMA）之上加一层「集体可观性层」。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **可观性门控**：任何视觉信息动作必须落在特征可控锥内、κ(L̂) ≤ κ_max、特征在视场内、深度不确定度 ≤ σ_Z,max；否则其 VoI_eff 记 0；
(iii) **去相关门控**：外来证据的信任权重 w_ij ≤ f(ρ̂_ij)，且集体 commit 需 N_eff ≥ q_min；
(iv) **集体安全单调**：任一门控失败时 λ_collective = max_i λ_i^FLUID，即集体永不弱于任一成员单独行动。

**定义 311（视觉伺服观测模型）** 图像特征 s ∈ ℝ^m，期望 s*，误差 e = s − s*。相机旋量 v_c ∈ ℝ^6。特征动力学 ṡ = L(s,Z) v_c + η，L ∈ ℝ^{m×6} 为交互矩阵（interaction matrix），Z 为特征深度。IBVS 律 v_c = −λ_s L̂⁺ e。局部可观性由 σ_min(L̂)、条件数 κ(L̂)=σ_max/σ_min 与有效秩 rk_ε(L̂) 刻画。眼在手上 / 眼在手外只改变 L 的参数化，不改本层接口。

**定义 312（可观性缺陷 U_obs）** U_obs = α₁·log(1+κ(L̂)) + α₂·(1−m_FOV) + α₃·σ_Z/Z̄ + α₄·1[遮挡]，归一化到 [0,1]。几何折扣 φ(U_obs) = exp(−β U_obs)，β>0 单调递减且 φ(1)≈0。有效信息增益 VoI_eff(g) = φ(U_obs(g))·VoI(g)。U_obs 的语义：**即使模态完全可分、噪声为零，当前几何也可能让「再看一眼」在物理上不产生任何新信息**。

**定义 313（伺服信息动作 VIS）** 视觉信息动作不是离散的「看一眼」，而是一条受约束的连续控制律：g_vis = argmin_{s(τ)} ∫ [eᵀWe + β·κ(L̂(s(τ)))] dτ + γ·cost，s.t. 特征/本体在安全包络内、位移 ≤ ε_g、时间 ≤ T_g。R69 的 g_gaze（定义 294）是其零阶近似（只选一个注视点、不规划路径）。关键推论：当当前几何退化时，最优信息动作往往不是「盯着看」，而是**主动移动以获得视差、改变 L 的秩**。

**定义 314（视觉-运动雅可比一致性 JAC / ΔL）** 在激励窗口内（A99：指令速度张成 ≥6 个线性无关方向，即持续激励），用带遗忘的递归最小二乘从 (v_c(t), ṡ_obs(t)) 辨识 L̂_obs；定义 ΔL = ‖L̂_obs − L_nom‖_F / ‖L_nom‖_F，以及运动学残差 r_kin = ‖(I − L̂_obs L̂_obs⁺) ṡ_obs‖。ΔL 测的是**指令运动 → 特征流**这一动作通道，与 r_res（传感器自洽，R68）和 Δa（策略行为自洽，R69）分属三个不同故障源。慢变故障判别式升级为三元组 (r_res, Δa, ΔL)。

**定义 315（集体信念结构与通信图）** N 个 agent，时刻 t 的通信图 G_t 有界度 Δ_c、时延 τ_ij ≤ τ_max。每个 agent i 维护 FLUID 信念 B_i = (m_k^i, ŵ_k^i, ECE_i, COF 状态, 标定摘要)。消息 m_ij = (模态后验 p_i(M), 证据向量 e_i, 模型/标定摘要 digest_i, 时间戳, 盲探针响应历史)。无中央聚合器。

**定义 316（失败去相关证书 DCF 与有效独立数）** 在审计保留的盲探针任务集 P 上记录各 agent 的失败指示 f_i(p) ∈ {0,1}，ρ̂_ij = corr(f_i, f_j)。有效独立数 N_eff = N/(1+(N−1)ρ̄)，ρ̄ 为加权平均相关。信任权重 w_ij = w_max·max(0, 1 − ρ̂_ij/ρ_max)·r_ij（r_ij 为审计信誉）。门控：ρ̂_ij > ρ_max ⇒ w_ij = 0（回声，不计第二源）。探针必须对 agent **盲**，否则可被博弈。

**定义 317（局部规则共识与 quorum，QSC）** 每个 agent 只与邻居交换**模态后验**（不是动作均值——多峰均值是危险虚构），在 Hellinger / Wasserstein 度量下做鲁棒聚合（几何中位数 / 截尾均值 / Krum），局部迭代 ≤ T_c 轮。Quorum 状态 ∈ {gather, commit, fallback}：仅当聚合后熵 H(p̄) ≤ τ_q、N_eff ≥ q_min、时间戳新鲜时才 commit。

**定义 318（少数派异议即集体 VoI，MDV）** 异议度 D_j = KL(p_j ‖ p̄)。若 D_j > τ_d 且 agent j 的证据与多数去相关，则**不投票抹掉它**，而把它转成一个集体信息动作：g_col = argmax_g VoI_collective(g | 分离「多数假设」与「少数假设」)，例如移动到能产生视差的位姿、换一个波段照明、联合触碰。异议 = 集体「再去看一眼」的触发器；一个正确但孤立的 agent 因此可以拉动整个群体。

**定义 319（集体证据纪律）** commit 需同时满足：(1) ≥ q_min 个去相关源；(2) 至少一个源来自不同模型族或不同传感模态；(3) 时间戳新鲜且无陈旧 quorum；(4) provenance 图无环、无回声转述（A 的答案经 B 转述回 A 不计第二源）；(5) 集体 VoI 增益 > 阈值；(6) 无未消解的高异议（D_j > τ_d 须先被集体观测处理）。

**定义 320（集体证书 J_OCELLI）** J_OCELLI = ({J_FLUID^i}_i, N_eff, hash(ρ̂), quorum_state, κ_p95, ΔL_p95, dissent_log_hash, provenance_dag_hash, ocelli_ver)。Valid ⇔ ∀i J_FLUID^i valid ∧ N_eff ≥ q_min ∧ κ ≤ κ_max ∧ 无伪独立告警 ∧ 证据纪律满足。

**定义 321（群体威胁模型 ℰ_swarm）** 相关故障（同训练/同标定/同视角/同模型族）、伪多样性（不同噪声、同一偏差）、回声转述、拜占庭成员、多数胁迫少数（把正确少数标记为异常）、延迟诱发的陈旧共识、探针泄漏。ℰ_OCELLI = ℰ_FLUID × ℰ_swarm。

**定义 322（两级集体退避 + 去相关奖金 δ_bonus）** 若 quorum 达成 ∧ N_eff ≥ q_min ∧ κ ≤ κ_max ∧ 无伪独立：λ_collective = λ_floor(Σ_k ŵ̄_k tr Σ_k) − δ_bonus，其中 0 ≤ δ_bonus ≤ δ_max 且仅在集体 VoI 增益 > 0 时发放；否则 λ_collective = max_i λ_floor^i(U_ale^i + U_epi^i)（取全体最保守者，拒绝集体行动）。⇒ 集体只在「信息真的新增」时才更勇敢。

**定义 323（可观性-去相关对偶 ODD）** 二维平面 (U_obs, 1/N_eff) 给出四象限策略：
- (低 U_obs, 低 1/N_eff)：自己看得清、证人也独立 → **伺服 + 共识**（最优）；
- (低 U_obs, 高 1/N_eff)：自己看得清、但证人只是回声 → **只信自己**，不融合、不 commit；
- (高 U_obs, 低 1/N_eff)：自己看不全、但证人来路独立 → **委派观测**：请位于另一视角的去相关 agent 去看，或主动移动到其视域；
- (高 U_obs, 高 1/N_eff)：看也没用、问也没用 → **收手**，走 FLUID/R68 纯保守。
这是本轮把两个灵感焊在一起的地方：视觉伺服回答「我的几何行不行」，群体智能回答「别人的几何能不能补我的」。

**定义 324（双时间尺度与信息新鲜度）** 内环视觉伺服 500Hz–1kHz；中环 FLUID 策略 300–400Hz（<2.6ms）；外环共识 2–10Hz。要求时间尺度分离比 ≥ 10 以保证级联稳定。陈旧消息按时间戳丢弃；共识只在「新鲜 quorum」上成立；共识结果不进入硬实时控制路径，控制只用最近一次已 commit 的聚合。

**定义 325（通信-算力预算与降级）** 每 agent 每轮下行消息 ≤ B_msg、通信邻居 ≤ Δ_c、共识轮数 ≤ T_c；超出即降级：先降 N_eff 的有效采样（只用最高信誉源），再降 K（继承 R69 定义 308），最后退回单体 FLUID。降级顺序固定，保证可预测的最坏延迟。

**定义 326（OCELLI 状态机）** 状态 S ∈ {SOLO, SERVO, DELEGATE, CONSENSUS, FALLBACK}，转移受 (U_obs, N_eff, quorum_state, 伪独立告警) 驱动；所有转移只能单调增加保守性，或在门控全部通过时以 ≤ δ_bonus 的幅度放宽（安全性由定理 19 保证）。

# IP-264/265 VIS+OBS：视觉伺服信息动作与可观性门控
class ObservableServo:
    def interaction_matrix(self, s, Z):  return self.L(s, Z)              # m×6
    def observability(self, L, fov_margin, sigma_Z):
        U, S, Vt = svd(L)                      # σ_min = S[-1]
        kappa = S[0] / max(S[-1], 1e-9)
        U_obs = normalize(a1*log1p(kappa) + a2*(1-fov_margin) + a3*sigma_Z)
        return U_obs, kappa, S[-1]            # 定义 312
    def servo_step(self, e, L):  return -self.lam * pinv(L) @ e          # IBVS
    def best_info_traj(self, modes, budget):                             # 定义 313
        # 在安全包络内最大化「沿消歧方向的 σ_min(L)」，而非单纯放大特征
        return argmax_traj(lambda tau: phi(obs(tau)) * voi(modes, tau) - cost(tau))

# IP-266 JAC：视觉-运动一致性（动作通道的第三只眼）
class JacobianMonitor:
    def __init__(self, L_nom): self.L_nom, self.L_hat = L_nom, L_nom.copy()
    def update(self, v_c, s_dot):            # 持续激励下 RLS，A99
        self.L_hat = rls(self.L_hat, v_c, s_dot, forget=0.99)
        dL    = norm(self.L_hat - self.L_nom) / norm(self.L_nom)
        r_kin = norm((eye - pinv(self.L_hat) @ self.L_hat) @ s_dot)
        return dL, r_kin                     # 定义 314、引理 20

# IP-267 DCF：失败去相关证书与有效独立数
class Decorrelation:
    def __init__(self, rho_max=0.3, q_min=3):
        self.rho_max, self.q_min = rho_max, q_min
    def update(self, blind_probe_failures):  # dict i -> [f_i(p)]
        self.rho = corr_matrix(blind_probe_failures)   # 盲探针，防博弈
    def weight(self, i, j, reputation):
        rho = self.rho[i, j]
        return 0.0 if rho > self.rho_max else (1.0 - rho) * reputation[j]
    def n_eff(self):
        n, rho_bar = len(self.rho), mean_offdiag(self.rho)
        return n / (1 + (n - 1) * rho_bar)   # 引理 21：超过 1/ρ 无增益

# IP-268 QSC：局部规则鲁棒共识 + quorum
def quorum_consensus(agent, peers, dcf):
    msgs = [p.posterior for p in peers
            if dcf.weight(agent.id, p.id, p.rep) > 0 and fresh(p.stamp)]
    if len(msgs) < dcf.q_min:  return 'gather', agent.posterior
    post = geometric_median(msgs, metric=hellinger)   # 不平均动作均值
    if entropy(post) <= TAU_Q and dcf.n_eff() >= dcf.q_min:
        return 'commit', post
    return 'gather', post

# IP-269 MDV：少数派异议 → 集体取证，而非投票处决
def minority_dissent(peers, post):
    for p in peers:
        if KL(p.posterior, post) > TAU_D and decorrelated(p):
            return collective_info_action(separate=[p.hypothesis, post])  # 定义 318
    return None

# IP-270 CFL：集体外环（不阻塞硬实时）
def collective_round(agents, G, dcf):
    for i in agents:
        state, post = quorum_consensus(i, G.neighbors(i), dcf)
        if minority_dissent(G.neighbors(i), post) is not None:
            state = 'gather'                 # 异议优先取证，不 commit
        i.ocelli_state, i.posterior = state, post
    lam = max(a.fluid_lambda() for a in agents)
    if all(a.state == 'commit' for a in agents):
        lam -= delta_bonus(dcf, agents)      # 只在全员 commit 时发放，定义 322
    return lam

# IP-274 单体闭环（在 R69 FLUID_RAS_round 的观测/动作处插入）
def OCELLI_agent_round(A, obs):
    s = A.perception.features(obs)
    U_obs, kappa, smin = A.servo.observability(A.servo.L(s, obs.Z), obs.fov, obs.sigma_Z)
    dL, r_kin = A.jac.update(A.last_vc, A.perception.feature_flow())
    mode = odd_quadrant(U_obs, 1.0 / max(A.dcf.n_eff(), 1e-6))   # 定义 323
    if mode == 'delegate' and A.dcf.n_eff() >= A.dcf.q_min:
        A.request_peer_observation(best_view_peer(A, A.dcf))
    g = (A.mint.choose_interaction(A.modes, obs, A.budget)
         if mode in ('servo', 'consensus') else None)
    if g is not None: A.servo.execute(g)     # 连续伺服，非定点凝视
    slow_sensor = (A.fma.delta_a(obs) > TAU_FMA) and (A.last_r_res < TAU_RES)
    slow_action = (dL > TAU_DL) and (r_kin > TAU_KIN)
    if slow_sensor or slow_action: A.ocelli_state = 'FALLBACK'
    A.fluid_round(obs)                       # 继续 R69 的 FLUID 主闭环
    return A.ocelli_state, (U_obs, A.dcf.n_eff(), dL)

## 3. 推导

**引理 19（可观性对信息增益的乘性上界）** 在 A99（沿消歧方向的特征敏感度由 σ_min(L) 控制、单位时间相机速度 ≤ v_max、预算 T_g）下，任何视觉信息动作的 VoI ≤ φ(U_obs)·H(M)；且当 L 沿消歧方向奇异（σ_min→0）时 VoI→0。系：**歧义的可解性 = 可分性（R69 的 Δ_min）× 可观测性（U_obs）**。Δ_min 大而 U_obs 高时应当移动而非凝视——最优信息动作常是「改变 L 的秩」，这解释了 R69 的定点注视在退化几何下为何白烧预算。

**引理 20（三通道故障可辨识性）** 在 A100 下——(a) 传感器加性漂移主要抬升 r_res；(b) 世界模型/策略偏差主要抬升 Δa，但不改变指令-特征流的增益；(c) 执行器刻度/轮速计标度/伺服增益/时延等**动作通道**漂移主要抬升 ΔL，而不改变传感器自洽与策略似然——故障类型到 (r_res, Δa, ΔL) 的雅可比在原点邻域满列秩，故三类缓变故障可分离。要点：COF 只建模「观测→校正」，从不联合观测「指令→特征流」，因此吸收不了动作通道漂移；ΔL 正是补这个洞的第三只眼。

**引理 21（群体信息饱和律）** 设 N 个同方差 σ²、等相关系数 ρ 的估计，其均值的后验方差 σ_N² = σ²(1+(N−1)ρ)/N，互信息增益 ≤ ½·log(1 + N_eff·SNR)，N_eff = N/(1+(N−1)ρ)。N→∞ 时 σ_N² → ρσ²、N_eff → 1/ρ：**超过约 1/ρ 个 agent 后，再加机器人不带来新信息**。系：群体的价值不是数量而是去相关；DCF 门控本质上是在估计 1/ρ 并把超过它的「伪证人」清零，防止回声被当作证据累加。

**引理 22（鲁棒聚合与少数派保全）** 设拜占庭比例 β < 0.5，几何中位数聚合误差有界 O(β)（相对截尾均值）；若正确假设落在单一去相关 agent 上且 MDV 触发一次信息量 ≥ Δ 的共享观测，则该假设被保留的概率 ≥ 1 − exp(−c·Δ)，且不随多数规模增大而下降（因为不投票、只观测）。要点：**MDV 把「少数服从多数」换成「少数触发取证」**。

**定理 18（OCELLI 严格包含 FLUID）** 在 A99–A101 下，任意状态：(a) 若 U_obs* ≥ τ_obs（可达几何内无消歧方向）或 N_eff < q_min 或 κ > κ_max 或伪独立告警，则 OCELLI **逐指令等于**单体 FLUID-RAS；(b) 否则期望风险 ≤ FLUID，且仅当集体 VoI 增益 > 0 且两门控通过时严格更优。因此 FLUID 是 OCELLI 在「看也没用 / 问也没用」边界上的退化：安全侧不做任何让步，效率侧获得至多 δ_bonus 的去相关奖金。

**定理 19（集体安全与无突变）** 在双时间尺度分离比 ≥ 10、局部鲁棒聚合与定义 326 状态机下：(i) 共识误差在有限时间内收缩到 O(β) 邻域，不因 N 增大而振荡；(ii) 任一门控失败或共识破裂时 λ_collective 单调不降地回到 max_i λ_i^FLUID；(iii) 控制指令始终经 C-RAS-WM 前缀认证、认证包络不变 ⇒ 控制连续、无突变（继承 R69 定理 17 / R68 定理 15）。

**定理 20（两门控的必要性）** 集体期望误差下降 > 0 当且仅当 (i) 存在安全、预算内的观测动作使 U_obs 落入可控锥（可观性），且 (ii) ρ̄ < ρ*（去相关）。任一不满足时集体 VoI ≤ 0，系统必须不发起集体动作。⇒ ODD 四象限不是经验法则，而是必要条件的分区：**看不清且证人不独立时，「大家一起确认」只会把错误确认得更响**。

## 6. 本轮最大风险

**一句话**：OCELLI 的全部集体增益都押在「去相关证书可信」这一前提上——**若 N 个机器人共享同一训练偏差/标定历史，却因噪声、视角或刻意的假多样性而通过了 DCF 门，系统就会把「一个模型的不确定」升级成「N 个成员的集体确信」；共识不是证据，共识只是回声——伪独立把 R69 的「一个会撒谎的嘴巴」升级成「一群互相盖章的嘴巴」，R69 是问错，R70 是集体证明错。**

**次级风险与缓解**：
1. **可观性估计被操纵**（伪造丰富纹理、对抗特征让 κ 假性变小）→ OBS 与 ΔL 交叉校验 + 对抗特征干扰集 + E305；
2. **动作通道漂移被在线自适应吸收**（把 L_nom 也一起漂走）→ 冻结证书时刻的 L_nom、对 L̂ 更新做审计与限速，ΔL 只用冻结基线；
3. **多数胁迫少数 / 异议 DoS**（拜占庭多数把正确少数标为异常、反复触发取证耗尽预算）→ 证据纪律的 provenance + 取证预算硬上限 + 审计回灌；
4. **陈旧 quorum / 时钟攻击** → 时间戳新鲜度 + 共识不入硬实时 + 降级顺序固定；
5. **双时间尺度耦合振荡** → 分离比 ≥ 10 + 状态机只单调增保守 + E311。

    def observability(self, L, fov, sigma_Z):
        _, S, _ = svd(L); kappa = S[0] / max(S[-1], 1e-9)
        return normalize(a1*log1p(kappa)+a2*(1-fov)+a3*sigma_Z), kappa, S[-1]
    def servo_step(self, e, L): return -self.lam * pinv(L) @ e          # IBVS
    def best_info_traj(self, modes):
        # 最大化沿消歧方向的 σ_min(L)，安全包络内；退化时主动移动而非凝视
        return argmax_traj(lambda t: phi(obs(t))*voi(modes,t) - cost(t))

# IP-266 JAC：动作通道第三只眼
class JacobianMonitor:
    def update(self, v_c, s_dot):                 # A99 持续激励
        self.L_hat = rls(self.L_hat, v_c, s_dot, forget=0.99)
        dL    = norm(self.L_hat-self.L_nom)/norm(self.L_nom)
        r_kin = norm((eye-pinv(self.L_hat)@self.L_hat)@s_dot)
        return dL, r_kin

# IP-267 DCF：去相关证书
class Decorrelation:
    def update(self, blind_fail): self.rho = corr_matrix(blind_fail)
    def weight(self, i, j, rep):
        r = self.rho[i,j]
        return 0.0 if r > self.rho_max else (1.0-r)*rep[j]
    def n_eff(self):
        n, rb = len(self.rho), mean_offdiag(self.rho)
        return n/(1+(n-1)*rb)                       # 饱和于 1/ρ

# IP-268 QSC：局部规则共识
def quorum_consensus(agent, peers, dcf):
    msgs = [p.posterior for p in peers
            if dcf.weight(agent.id,p.id,p.rep)>0 and fresh(p.stamp)]
    if len(msgs) < dcf.q_min: return 'gather', agent.posterior
    post = geometric_median(msgs, metric=hellinger)     # 不平均动作
    ok = entropy(post)<=TAU_Q and dcf.n_eff()>=dcf.q_min
    return ('commit' if ok else 'gather'), post

# IP-269 MDV：异议 → 取证
def minority_dissent(peers, post):
    for p in peers:
        if KL(p.posterior,post) > TAU_D and decorrelated(p):
            return collective_info_action(separate=[p.hypothesis, post])
    return None

# IP-270/274 主闭环
def collective_round(agents, G, dcf):               # 外环，不阻塞硬实时
    for i in agents:
        st, post = quorum_consensus(i, G.neighbors(i), dcf)
        if minority_dissent(G.neighbors(i), post) is not None: st = 'gather'
        i.ocelli_state, i.posterior = st, post
    lam = max(a.fluid_lambda() for a in agents)     # 缺省取全体最保守
    if all(a.state=='commit' for a in agents):
        lam -= delta_bonus(dcf, agents)              # 仅全员 commit 才发放
    return lam

def OCELLI_agent_round(A, obs):
    U_obs, kappa, smin = A.servo.observability(A.servo.L(A.s, obs.Z), obs.fov, obs.sigma_Z)
    dL, r_kin = A.jac.update(A.last_vc, A.perception.feature_flow())
    mode = odd_quadrant(U_obs, 1.0/max(A.dcf.n_eff(),1e-6))
    if mode=='delegate' and A.dcf.n_eff()>=A.dcf.q_min:
        A.request_peer_observation(best_view_peer(A, A.dcf))
    g = (A.mint.choose_interaction(A.modes,obs,A.budget)
         if mode in ('servo','consensus') else None)
    if g is not None: A.servo.execute(g)
    if ((A.fma.delta_a(obs)>TAU_FMA and A.last_r_res<TAU_RES) or
        (dL>TAU_DL and r_kin>TAU_KIN)):
        A.ocelli_state = 'FALLBACK'
    A.fluid_round(obs)                               # 继续 R69 FLUID
    return A.ocelli_state, (U_obs, A.dcf.n_eff(), dL)

## 4. 推导

**引理 19（可观性对信息增益的乘性上界）** A99 下任何视觉信息动作 `VoI ≤ φ(U_obs)·H(M)`；`σ_min(L)→0` 时 `VoI→0`。系：可解性 = 可分性 × 可观测性；Δ_min 大但 U_obs 高时应移动改变 L 的秩，定点凝视在退化几何下白烧预算。

**引理 20（三通道故障可辨识性）** A100 下，传感器加性漂移→r_res↑；策略/世界模型偏差→Δa↑；执行器刻度/轮速计/伺服增益/时延等动作通道漂移→ΔL↑（而 r_res、Δa 近零）。三类故障到 (r_res,Δa,ΔL) 的雅可比满列秩 ⇒ 可分离。COF 只建模「观测→校正」，不联合观测「指令→特征流」，故吸收不了动作通道漂移——这是 ΔL 的合法性来源。

**引理 21（群体信息饱和律）** N 个同方差、等相关 ρ 的估计：`σ_N²=σ²(1+(N−1)ρ)/N`，互信息 ≤ `½log(1+N_eff·SNR)`，`N_eff=N/(1+(N−1)ρ)`；N→∞ 时 `σ_N²→ρσ²`、`N_eff→1/ρ`。系：超过 ~1/ρ 个 agent 无新信息；DCF 就是估计 1/ρ 并清零伪证人。

**引理 22（鲁棒聚合与少数派保全）** 拜占庭比例 β<0.5 时几何中位数误差 O(β)；正确假设落在单一去相关 agent 且 MDV 触发信息量 ≥Δ 的共享观测，则其被保留概率 ≥ `1−exp(−cΔ)`，不随多数规模下降。系：MDV 把「少数服从多数」换成「少数触发取证」。

**定理 18（OCELLI 严格包含 FLUID）** A99–A101 下：若 `U_obs*≥τ_obs` 或 `N_eff<q_min` 或 `κ>κ_max` 或伪独立告警，OCELLI 逐指令等于 FLUID；否则期望风险 ≤ FLUID，仅当集体 VoI>0 且两门控通过时严格更优。FLUID = 「看也没用/问也没用」边界上的退化；安全不让步，效率至多 δ_bonus。

**定理 19（集体安全与无突变）** 分离比≥10 + 鲁棒聚合 + 状态机：共识误差有限时间收缩到 O(β) 邻域、不随 N 振荡；门控失败/共识破裂时 λ 单调不降回 `max_i λ_i^FLUID`；认证包络不变 ⇒ 控制连续无突变（继承 R69 定理 17 / R68 定理 15）。

**定理 20（两门控必要性）** 集体期望误差下降>0 ⇔ (i) 预算内存在观测动作使 U_obs 落入可控锥 且 (ii) ρ̄<ρ*。任一不满足则集体 VoI≤0，不得发起集体动作。⇒ ODD 四象限是必要条件的分区：看不清且证人不独立时，「大家一起确认」只会把错误确认得更响。

## 7. 本轮最大风险

**一句话**：OCELLI 的全部集体增益押在「去相关证书可信」这一前提上——**若 N 个机器人共享同一训练偏差/标定历史，却因噪声、视角或刻意的假多样性通过了 DCF 门，系统就会把「一个模型的不确定」升级成「N 个成员的集体确信」；共识不是证据，共识只是回声**——伪独立把 R69 的「一个会撒谎的嘴巴」升级成「一群互相盖章的嘴巴」：R69 是问错，R70 是集体证明错。

**次级风险与缓解**：可观性估计被操纵（伪造纹理/对抗特征让 κ 假小）→ OBS×ΔL 交叉校验 + 对抗特征集 + E305；动作通道漂移被在线自适应吸收 → 冻结证书时刻 L_nom、L̂ 更新限速审计；多数胁迫少数/异议 DoS → provenance + 取证预算硬上限 + 审计回灌；陈旧 quorum/时钟攻击 → 时间戳新鲜度 + 共识不入硬实时 + 固定降级；双时标耦合振荡 → 分离比≥10 + 状态机只单调增保守 + E311。
