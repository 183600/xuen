# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「跨任务泛化」×「可靠性」）

> 第 68 轮用在线潜变量 c_t 回答了「测量是否可信」，用单 trunk 五头回答了「如何同源一致」。但它对多任务共享给出了两个未经可靠性审查的乐观主张：引理 14 说稠密自监督任务能正则化稀疏安全任务（**平均风险**迁移），引理 15 说共享 trunk 带来共模抵消、跨头一致性检验更灵敏（**提高 ρ_c 是纯收益**）。从可靠性工程看，这两条都只对「均值」成立：
>
> 1. **跨任务泛化的货币不是平均精度，而是尾部保证**。共享表征能改善平均损失，却可能在稀有慢故障、边缘情绪这些「安全真正所在的尾部」产生负迁移；而 R68 从未给每个任务单独签发尾部可靠性证书。
> 2. **引理 15 的 ρ_c 恰好就是共因故障（common-cause failure, CCF）的耦合旋钮**。同一个 trunk 漂移、表征坍缩、量化 bug 或对抗输入会让 cal/fault/wm/emo 一起错，而跨头一致性检验恰恰看不出来——它们「一致地错」。R68 把单点故障的耦合度当成了灵敏度红利。
> 3. R68 的失效处理是全局收紧（λ_floor、k 收缩）：安全，但牺牲可用性，且掩盖了「到底哪个任务不可信」；一次 wm_drift 就冻结整个闭环，没有故障隔离。
>
> 核心命题：
>
> **把「跨任务泛化」从特征/参数共享重述为「可靠性预算下的保证迁移」：每个任务持有一份可机检的可靠性档案（尾部风险上界 + 有效域 + 机制见证 + 证据时效）；共享表征是一份带共因故障预算的显式资源；证书只有在有效域包含、机制见证、尾部 Lipschitz 三前提被解除时才能跨任务复用；用逐任务熔断 + 架构多样性回退做故障隔离，避免一次失效级联成系统失效——TRUST-RAS（Task-wise Reliability Under Shared Trunk）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我还敢信哪些任务，且信一个任务是否被迫信了全部**」——跨任务泛化最隐蔽的代价不是精度下降，而是失败被耦合。

## 0. 直觉与动机

**灵感 1（跨任务泛化 → 泛化的单位是「保证」，不是「精度」）**
直觉：多任务学习里我们说任务 B 从任务 A 受益，通常指 B 的平均验证损失下降；但安全系统需要的是**条件保证**：对每一个相关分组、每一段尾部，B 的风险上界仍然成立。一个模型完全可以在平均故障检出率上受益，却在「缓变泄漏」这类稀有尾部变差——而尾部才是安全所在。于是「A 是否泛化到 B」应被重新定义为：**A 的可靠性证书能否在 B 上继续成立**；能，才算泛化；不能，就必须拒绝复用并重新取证。泛化的对象是论证（assurance argument），不是权重。

**灵感 2（可靠性 → 共享是共因故障之源）**
直觉：经典可靠性里，冗余只在失效独立时有用；一个共因可以同时击穿所有备份。R68 为了锐化跨头 KL 检验**故意**提高共享 trunk 的误差相关性 ρ_c；但同一条 ρ_c 就是共因耦合：trunk 级扰动会让各头同时偏移，跨头一致性反而检测不到（共享误差在 KL 里被当成共同信号）。可靠性工程的 β-factor 模型把这件事量化：系统失效率中有一部分 β 是共因份额。R68 的引理 15 因此是一笔「浮士德交易」——用可靠性换灵敏度，却只记账了收益那一半。

**灵感 3（两者合流 → 可靠性预算化的共享）**
直觉：共享对泛化必要、对可靠性危险，所以不该「全共享」也不该「全独立」，而应把**表征共享当作带预算的资源**：任务 τ 的共享系数 γ_τ 越高，跨任务迁移收益越大，但共因暴露也越大。在「每任务尾部风险 ≤ 要求」与「系统共因份额 ≤ β_budget」两条约束下最大化任务能力，会得到一个**内点 Pareto 最优**：安全关键的稀疏任务保留私有/多样容量，辅助稠密任务尽量共享。这把 R68 的「一个 trunk 全共享」从架构默认值降级为一个需要被优化的决策变量。

**灵感 4（可靠性的第二层 → 故障隔离与优雅降级）**
直觉：可靠性不只是「不出错的概率」，更是「出错时坏到哪里为止」。逐任务熔断器 + 架构多样性回退 + 包含矩阵：一个任务失效只切换它自己的输出，安全决策永远用「已认证任务 + 保守默认」，绝不在熔断后继续悄悄信任它；只有 CCA 确认共因事件时才允许全局冻结。于是单任务失效只损失该任务的可用性，不会级联成整机失效——这正是 R68 缺失的故障包含区域（fault containment region）。

**灵感 5（对 R68 最大风险的正交补丁）**
直觉：R68 的最大风险是「缓变故障落在标定带宽内 → 被 COF 标好 → 隐形」。TRUST 无法也不应改标定带通，但它加了两条与均值正交的证据通道：(i) 每个安全关键任务的**尾部证书**独立于平均表现，慢故障在尾部先暴露；(ii) **任务级独立监测**——即使 cal 头自信，fault 任务的 tail-CUSUM 与私有多样回退仍能报警，且故障包含保证 cal 的自我欺骗无法放松 fault 任务的要求。这把 R68 的「单点防线」变成「带预算的多通道 + 隔离」。

**灵感 6（为什么不直接堆规模/域随机化）**
直觉：更大模型和域随机化改善的是平均覆盖，给不出逐任务尾部保证；共享容量越大，CCF 反而越严重。TRUST 的立场是：**不承诺跨任务泛化一定成功，只承诺泛化失败时它发生在一个被声明的区域内、可被检测、且单调退化**。在安全关键场景，这比「测试集平均不失分」更接近可部署的可靠性。

**灵感 7（合流 → TRUST-RAS 七组件）**
1. **TDR Task Dependability Register**：逐任务可靠性档案（Claim/Arg/Ev/有效域/尾部上界/机制见证/时效）；
2. **TDC Tail-aware Decomposition & Capacity allocation**：共享-私有子空间分解 + CCF 感知的 γ 分配；
3. **CCA Common-Cause Analyzer**：trunk+头的故障树、β-factor 估计、多样性独立性审计；
4. **ACT Assurance Certificate Transfer**：带三前提的证书迁移算子 ⊳，可拒绝迁移；
5. **NTS Negative-Transfer Sentinel**：尾部 CUSUM + 梯度子空间侵入 + 反事实探针三重检测；
6. **FCB Fault-Containment Breaker + DFB Diverse Fallback Bank**：逐任务状态机、架构多样性保守回退、包含矩阵；
7. **RAS-CALM† 继承核**：COF/CFA/CAC/MTM/SSG 全部保留，只在共享分配与决策融合层上加可靠性约束。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（TRUST-RAS 总览）** TRUST-RAS = (TDR, TDC, CCA, ACT, NTS, FCB, DFB, RAS-CALM†)。四条新增不变式：
(i) **任务级保证**：任何进入安全决策的输出都必须携带有效证书 C_τ；无有效证书者按最坏情况处理，不得默认信任；
(ii) **共享受预算约束**：γ_τ 与共因预算 β_budget 显式登记；任何共享分配的变更都需走 CAC† 重认证；
(iii) **故障包含**：任务 i 失效不得使任务 j（同为安全关键）的认证风险上界恶化超过 ε_contain；全局冻结仅在 CCA 确认 F_CCF 时允许；
(iv) **单调退化**：任何可靠性证据变差只能降低攻击性（λ↑、k↓、任务→回退），任何重配置都不得在证书失效期间提升攻击性。

**定义 294（任务划分）** 任务集 𝒯 = {emo, fault, wm, cal, qual}；安全关键集 𝒯_s = {emo, fault, cal, wm}（四者均直接影响 λ 或 k），支撑集 𝒯_a = {qual}。每个 τ ∈ 𝒯 有要求 R*_τ（该任务允许的最坏尾部风险）与失败代价 ρ_τ。

**定义 295（任务可靠性档案 TDR）** C_τ = (Claim_τ, Arg_τ, Ev_τ, 𝒟_τ, R̂_τ^tail, α_τ, μ_τ, t_exp, ver)：
- Claim_τ：逐分组 g ∈ 𝒢_τ 的尾部声明 CVaR_{α}(L_τ | g) ≤ R*_τ；
- Arg_τ：类 GSN 的论证结构哈希（claim→sub-claim→evidence 的可机检骨架）；
- Ev_τ：证据集（金标、探针、分组切片、仿真）哈希；
- 𝒟_τ：证据成立的有效域（输入/表征/工况）；
- R̂_τ^tail：以置信 1−α_τ 成立的尾部风险上界（共形风险控制 / DRO 给出）；
- μ_τ：机制见证（例如「同一传感器硬件与热时间常数」「同一执行器摩擦模型」），是结构化布尔证据而非学习得到；
- t_exp：证据时效期。
Valid(C_τ) ⇔ 证据未过期 ∧ 有效域检验通过 ∧ 无作用域内的 CCF/NTS 未决告警 ∧ ver 在 J 链中登记。

**定义 296（尾部可靠性与非回归）** 对 τ，要求 sup_{g∈𝒢_τ} CVaR_α(L_τ | g) ≤ R*_τ。定义跨任务迁移的尾部效应
Δ_tail_{A→B} = R̂_B^tail(共享 A) − R̂_B^tail(仅私有 B)。
平均迁移可以为正而 Δ_tail 为正（**尾部负迁移**）。可靠性约束要求：对任意安全关键 B，Δ_tail_{A→B} ≤ ε_tail；即引入辅助任务不得恶化任何安全关键任务的尾部分组上界。

**定义 297（共享-私有分解与共享系数）** z_t = [z_c; z_τ]，z_c ∈ ℝ^{d_c} 为共享子空间，z_τ ∈ ℝ^{d_τ} 为任务私有子空间。头 τ 读取 (z_τ, P_τ z_c)，P_τ 为认证投影。定义
γ_τ = dim(P_τ z_c) / (dim(P_τ z_c) + dim(z_τ)) ∈ [0,1]，系统共享容量 S = Σ_τ γ_τ，安全关键共享暴露 γ_s = max_{τ∈𝒯_s} γ_τ。
私有子空间须保留认证秩 r_τ（VICReg 方差约束，继承 R68 定义 282）。

**定义 298（共因故障模型）** 故障树：组件 trunk Φ 与五头。对 τ∈𝒯_s 定义失效事件 F_τ；独立失效率 p_τ^⊥，共因事件 F_CCF 由 trunk 级扰动触发。β-factor：p_CCF = β·Σ_{τ∈𝒯_s} p_τ^⊥。等相相关误差模型 e_τ = √ρ_c·s + √(1−ρ_c)·u_τ（s 为 trunk 共享误差，u_τ 独立）下，β 关于 ρ_c 单调不减，β(0)=0。系统一阶失效界
P_f ≤ Σ_{τ∈𝒯_s} p_τ^⊥ + p_CCF。设计红线：p_CCF ≤ β_budget（例如取总 P_f 预算的 10%）。

**定义 299（CCF 感知共享分配）** 选 γ = (γ_τ) 求解
max_γ Σ_τ w_τ·b_τ(γ_τ)  s.t.  R̂_τ^tail(γ) ≤ R*_τ (τ∈𝒯_s)，p_CCF(γ_s) ≤ β_budget，0 ≤ γ_τ ≤ γ_max，
其中 b_τ 为迁移收益（关于 γ 单调凹），p_CCF 关于 γ_s 单调凸。
KKT 语义：安全关键任务的边际迁移收益必须同时支付「共因影子价格」与「尾部风险影子价格」；当其失败代价 ρ_τ 高时，最优 γ_τ 被压低，剩余迁移需求改由**私有的 LoRA 容量**满足（提升任务拟合但不增加共享耦合）。

**定义 300（跨任务泛化的操作性定义）** 称任务 A 的证书可迁移到 B，当且仅当迁移算子 C_{A→B} = C_A ⊳ C_B 产生一个有效证书且其尾部上界 ≤ R*_B；否则称「A 不泛化到 B」，并显式拒绝复用。**拒绝迁移是一等公民结果，必须审计**，而不是静默回退到共享权重。

**定义 301（保证迁移算子 ACT）** 迁移需解除三前提：
(T1) **有效域包含**：𝒟_B ⊆ 𝒟_A，用双样本覆盖检验，误判率 α_dom；
(T2) **机制见证**：μ_A ⇒ μ_B 成立（同一传感器/执行器/标定动力学），布尔可审计；
(T3) **尾部 Lipschitz 稳定**：|R_B^tail(f) − R_A^tail(f)| ≤ L_R·W_1(𝒟_A, 𝒟_B) + λ_joint。
若三前提成立，则输出
C_{A→B} = (R̂_A^tail + L_R·Ŵ_1 + λ̂_joint, α_A + α_dom + α_div, 𝒟_B, Ev = C_A)。
任一前提失败或迁移后上界 > R*_B ⇒ 拒绝迁移，转重新取证或任务私有回退。

**定义 302（负迁移哨兵 NTS，三重独立检测）**
(a) **尾部 CUSUM**：在固定审计探针集上逐分组累计尾部损失偏移，阈值 h 按 ARL_0 校准；
(b) **子空间侵入**：任务更新子空间 U_τ 与安全关键认证子空间 U_s 的主夹角 θ；若 min cos θ > τ_encroach，则阻断该更新对安全关键方向的投影；
(c) **反事实探针**：同一探针上比较「共享分支」与「仅私有无共享分支」的尾部损失差 Δ_ct = L_shared − L_private；Δ_ct > δ 判尾部负迁移。
判定：任一检测器 → τ 进入 WATCH；两独立检测器同时报警或单检测器持续超阈 → TRIPPED。

**定义 303（故障包含熔断 FCB）** 每任务状态机 {CERTIFIED, WATCH, TRIPPED, FALLBACK}，转移由 Valid(C_τ)、NTS、CCF 告警、证据过期驱动。进入 TRIPPED 后 τ 的输出被替换为 DFB 的保守回退，安全决策改用最坏默认。包含矩阵 M_contain[i,j] ∈ [0,1] 表示 i 失效对 j 认证界的最大影响；不变式：∀i,j∈𝒯_s, i≠j，M_contain[i,j] ≤ ε_contain。仅当 CCA 判定 F_CCF（≥2 个安全关键任务同因同时失效）才允许全局 k=0。

**定义 304（多样性回退库 DFB）** 对每个 τ∈𝒯_s 维护一个**架构多样性**的廉价回退，且不得与主模型共享 trunk 权重或训练数据（独立性需审计）：
- cal：物理静态标定（零力/已知质量/已知外参）vs MTM cal_head；
- fault：规则/阈值残差监测 vs 学习 FIR 头；
- wm：恒速/运动学短时外推 vs 学习 wm_head；
- emo：仅上下文保守先验 vs 面部分类器。
回退按构造保守：输出会膨胀 U、抬高 λ 下限、收缩 k；若回退的上界仍超过 R*_τ，则该任务不可用，进入「能力声明降级」。

**定义 305（可靠性感知决策融合）** 每任务可取性 a_τ ∈ [0,1]：CERTIFIED=1，WATCH∈[0.5,1)，TRIPPED/FALLBACK=0（回退输出替代）。决策：
λ_floor^TRUST = max(0.6, 0.8·1[∃τ∈𝒯_s: a_τ < 1])（继承 R68 纪律：任何不确定只收紧）；
k = min(k_RAS, k_reliability)，其中 k_reliability 随未认证安全关键任务数单调不增；
tripped cal ⇒ 回退膨胀 U，tripped emo ⇒ λ ≥ 0.8，tripped wm ⇒ 禁用 WM 前缀，tripped fault ⇒ 用保守先验。
与 R68 的关键差别：**降级是逐任务、包含在故障区域内的**；全局收缩只在共因确认时作为最后手段。

**定义 306（可靠性证书 J_TRUST）** J_TRUST = (J_CALM, {C_τ}_τ, γ, p̂_CCF, ccf_alarm, nts_flags, cb_states, contain_hash, trust_ver)。
Valid ⇔ Valid(J_CALM) ∧ (∀τ∈𝒯_s Valid(C_τ)) ∧ p̂_CCF ≤ β_budget ∧ 包含不变式成立 ∧ 所有 TRIPPED 任务均已切至回退。

**定义 307（干扰集与管线）** ℰ_TRUST = ℰ_CALM × ℰ_xfer × ℰ_ccf × ℰ_cb：
ℰ_xfer = {有效域越界、机制见证误判、尾部负迁移、证书过期}；
ℰ_ccf = {trunk 漂移/坍缩、相关训练数据、回退的伪独立、共享传感器/对抗共因}；
ℰ_cb = {熔断抖动、回退本身不安全、包含泄漏、恢复竞态}。
离线：逐任务分组取证 → TDR 建档 → CCA 故障树与 β 估计 → γ 分配 → DFB 独立性审计 → 签发证书。
在线：CALM 主环 + 每 tick 的 a_τ 检查 + 周期 NTS 探针；候选适配器走 R68 五关 + **第六关跨任务非干扰** → 原子换装；证据按 t_exp 滚动刷新。

**定义 308（可靠性单调性）** 对任意证据流，a_τ 在证据变差时单调不增；λ_floor^TRUST 单调不减；k 单调不增；任何重配置（换装、γ 变更）都不得在存在过期/失效关键证书时提升攻击性。此定义把 R68 的 λ_floor 从「标量纪律」升级为「逐任务可靠性状态 + 全局单调护栏」。

# IP-253 TDR：逐任务可靠性档案与准入
class TaskDependabilityRegister:
    def __init__(self, tasks, requirements):
        self.C = {t: load_certificate(t) for t in tasks}   # Claim/Arg/Ev/D/R_hat/alpha/mu/t_exp
        self.req = requirements

    def admissibility(self, tau, out, z):
        c = self.C[tau]
        if not (c.evidence_fresh() and c.domain_contains(out, z)
                and not c.scoped_alarm(self.ccf, self.nts)):
            return 0.0                                  # 无有效证书 → 最坏处理
        return 1.0 if c.verdict == 'CERTIFIED' else c.watch_level


# IP-254/255 TDC + CCA：CCF 感知共享分配
class SharingAllocator:
    def __init__(self, tasks, beta_budget):
        self.tasks, self.beta_budget = tasks, beta_budget

    def allocate(self, transfer_benefit, ccf_cost, tail_risk):
        # max sum w_t*b_t(gamma_t) s.t. tail_risk<=R*, ccf_cost(gamma_s)<=beta
        gamma = solve_kkt(transfer_benefit, ccf_cost, tail_risk, self.beta_budget)
        if ccf_cost(max(gamma[t] for t in SAFETY)) > self.beta_budget:
            gamma_safe = invert_ccf(self.beta_budget)      # 卡死安全关键共享
            for t in SAFETY: gamma[t] = min(gamma[t], gamma_safe)
        return gamma                                       # 余量转私有 LoRA


class CommonCauseAnalyzer:

# IP-256 ACT：保证证书迁移（可拒绝）
def transfer_certificate(C_A, task_B, domain_test, mechanism_witness, W1_hat, L_R):
    if not domain_test(C_A.D, task_B.D):        return None, 'DOMAIN_FAIL'
    if not mechanism_witness(C_A.mu, task_B.mu): return None, 'MECHANISM_FAIL'
    bound = C_A.R_hat_tail + L_R * W1_hat + task_B.lambda_joint
    if bound > task_B.R_star:                   return None, 'BOUND_EXCEEDED'
    return Certificate(R_hat_tail=bound,
                       alpha=C_A.alpha + domain_test.alpha + task_B.alpha_div,
                       D=task_B.D, evidence=C_A), 'PASS'

class FaultContainmentBreaker:
    def transition(self, tau, valid, nts_flag, ccf_alarm):
        s = self.state[tau]
        if not valid or (nts_flag and s == 'WATCH'):  s = 'TRIPPED'
        elif nts_flag:                                 s = 'WATCH'
        elif s in ('WATCH', 'TRIPPED') and valid:      s = 'CERTIFIED'
        if ccf_alarm:                                  s = 'FALLBACK'   # 全局共因
        self.state[tau] = s
        return s

    def k_budget(self, states):
        n_bad = sum(states[t] in ('TRIPPED', 'FALLBACK') for t in SAFETY)
        return max(0, self.k0 - self.kappa * n_bad)      # 只有共因才允许 0

## 3. 推导

**引理 16（共模的可靠性对偶）** 在等相相关误差模型 e_τ = √ρ_c·s + √(1−ρ_c)·u_τ 下：
(i) 由 R68 引理 15，一致性检验 SNR(ρ_c) = C/√(1−ρ_c)，严格递增；
(ii) 共因份额 β_CCF(ρ_c) 单调不减，β_CCF(0)=0；当 trunk 级失效主导时 β_CCF → 1；
(iii) 因此不存在「只提高灵敏度、不提高共因风险」的 ρ_c 调整；任何以跨头一致性为由提高 ρ_c 的架构决策，都必须在 β_budget 内显式记账，最优共享度是内点而非最大值。
*证明要点*：误差协方差分解给出 Corr(e_τ,e_σ)=ρ_c，即引理 15 的 SNR 来源；共因失效定义为给定 trunk 事件 |s|>θ_s 时 ≥2 个安全关键头同时失效的概率，其对 ρ_c 的单调性来自共享项系数 √ρ_c 的单调性，ρ_c=0 时共享事件不传导失效，故 β=0。两目标关于 ρ_c 同向单调但方向相反（灵敏度↑、可靠性↓），故为 Pareto 冲突。

**引理 17（共享分配的 KKT 结构）** 若 b_τ(γ) 单调凹、p_CCF(γ_s) 单调凸，则定义 299 的最优解唯一且满足：对 τ∈𝒯_s，
∂b_τ/∂γ_τ = λ_CCF·∂p_CCF/∂γ_s + μ_τ·∂R̂_τ^tail/∂γ_τ，
其中 λ_CCF、μ_τ ≥ 0 分别为共因预算与尾部约束的影子价格；对 τ∈𝒯_a，最优 γ_τ = γ_max（辅助任务尽量共享）。当 β_budget 绑定时，所有安全关键任务的 γ_τ 被统一压到 γ_safe* = p_CCF^{-1}(β_budget)，剩余迁移需求由私有 LoRA 容量满足（不增加 γ_s）。
*系*：**安全关键任务的共享度应是其失败代价 ρ_τ 的非增函数**；R68 的「五头全共享 d=256」在 ρ_fault, ρ_cal 很高时不是最优。这为 R69 的架构选择提供了可证明的依据。

**引理 18（证书迁移的可靠性）** 若 ACT 的 T1–T3 成立，则迁移证书有效：
P(R_B^tail ≤ R̂_A^tail + L_R·W_1(𝒟_A,𝒟_B) + λ_joint) ≥ 1 − α_A − α_dom − α_div。
*证明要点*：由 T3 的尾部 Lipschitz 与三角不等式，真实 R_B^tail ≤ R_A^tail + L_R·W_1 + λ_joint；R̂_A^tail 以 1−α_A 覆盖 R_A^tail（共形风险控制），Ŵ_1 以 1−α_div 覆盖 W_1，域包含检验以 1−α_dom 成立；联合界即得。注意 T2 是布尔前提，不消耗概率预算——它无法被统计检验替代，这正是「机制见证」存在的理由。

**定理 16（TRUST 端到端可靠性）** 在 A87–A94 与定义 293 的四不变式下，安全违规概率
P(V) ≤ Σ_{τ∈𝒯_s} [ a_τ·R̂_τ^cert + (1−a_τ)·R̂_τ^fallback ] + p_CCF + o(Σ p^2)，
且满足：
1. 任一安全关键任务证书失效 ⇒ λ_floor ≥ 0.8 ∧ k 单调不增（单调退化）；
2. 回退按构造保守 ⇒ (1−a_τ) 项的贡献不低于直接信任该任务；
3. 包含不变式 ⇒ 单任务失效不会放大其他任务项（无级联）；
4. p_CCF ≤ β_budget ⇒ 共因项被显式封顶；仅 CCF 确认时 k=0。
*证明要点*：安全决策只读取 (a_τ, o_eff)，其风险由 CERTIFIED 证书或 FALLBACK 上界支配；在包含矩阵下各任务失效事件的条件贡献可加而不交叉放大；共因事件单独计入并受 β_budget 约束；λ、k 对 a_τ 的单调性由定义 305/308 直接给出。

**定理 17（优雅降级与负迁移检测）** 在 NTS 三重检测与 FCB 状态下：
1. **无级联**：单任务 TRIPPED 仅损失其自身可用性权重 w_τ；其他安全关键任务的认证界变化 ≤ ε_contain；
2. **检测延迟有界**：尾部损失均值偏移 δ、探针量 n_p 时，未检出概率 ≤ exp(−2 n_p δ²)（Hoeffding），检测延迟 ≤ h/δ（CUSUM）；
3. **可恢复**：WATCH→CERTIFIED 需连续 N_clean 个干净窗口（滞回），故熔断抖动概率随 N_clean 指数下降；
4. 若 CCF 确认，允许全局 k=0，此时可用性降级但恢复路径与单任务回退同构，不引入控制突变（λ 连续、k 单调）。

## 6. 本轮最大风险

**一句话**：TRUST 的全部安全性押在「可靠性档案已穷尽故障模式、且多样性回退彼此真正独立」这一前提上——**若存在未被登记的共同原因（共享训练数据、同一传感器、同一物理假设，或回退之间实为伪独立），系统会同时拿到多张「看起来独立」的证书并判定 Valid，把「只有一层防护」误认为「多层冗余」**；这种**伪独立性**比 R68 明示的耦合更危险，因为 R68 至少知道自己耦合，而 TRUST 会以为自己已经隔离。

**次级风险与缓解**：
1. **证书过期/证据腐化**：t_exp + 滚动刷新 + 过期即降级（定义 295/308）；
2. **谱系外任务漂移**：ACT 的 T1 双样本检验 + 拒绝迁移优先（定义 301）；
3. **β 估计偏差**：CCA 用注入式校准 + 置信上界，β_budget 留安全裕度；
4. **熔断抖动/恢复竞态**：滞回 + 双缓冲状态提交 + 回退与主路径同构；
5. **回退本身不安全**：DFB 独立取证，且每当触发都抬高 λ、收缩 k；回退不可用则声明能力降级，不冒险复用主模型。

| `J_TRUST = (J_CALM, {C_τ}, γ, β̂, ccf_alarm, nts_flags, cb_states, contain_hash, trust_ver)` | 可靠性证书 |

## 2. 形式化定义（要点版）

**定义 293（总览与四不变式）** TRUST-RAS 八组件；不变式：任务级保证（无有效证书按最坏处理）、共享受预算约束、故障包含（单任务失效不恶化其他关键任务 > ε_contain）、单调退化（证据变差只收紧）。

**定义 294–295（任务划分与 TDR）** 𝒯_s = {emo, fault, cal, wm}，𝒯_a = {qual}；每任务档案含尾部声明、GSN 类论证、证据、有效域、机制见证与时效；`Valid(C_τ)` 要求证据未过期、域检验通过、无作用域内未决 CCF/NTS 告警、版本在 J 链中。

**定义 296（尾部可靠性与非回归）** 要求 `sup_g CVaR_α(L_τ|g) ≤ R*_τ`；`Δ_tail_{A→B} = R̂_B^tail(共享 A) − R̂_B^tail(仅私有 B)`；安全关键任务须 `Δ_tail ≤ ε_tail`——平均迁移正不代表尾部迁移正。

**定义 297（共享-私有分解）** `z = [z_c; z_τ]`；`γ_τ = dim(P_τ z_c)/(dim(P_τ z_c)+dim(z_τ))`；私有子空间保留认证秩 r_τ；γ_s 是安全关键的共享暴露。

**定义 298（共因故障模型）** 等相相关误差 `e_τ = √ρ_c·s + √(1−ρ_c)·u_τ`；β-factor `p_CCF = β·Σ p_τ^⊥`；系统一阶失效界 `P_f ≤ Σ p_τ^⊥ + p_CCF`；红线 `p_CCF ≤ β_budget`。

**定义 299（CCF 感知共享分配）** `max Σ w_τ b_τ(γ_τ)` s.t. 逐任务尾部约束、`p_CCF(γ_s) ≤ β_budget`、`γ_τ ≤ γ_max`；b_τ 单调凹、p_CCF 单调凸 ⇒ 内点最优；高失败代价任务共享度低，余量转私有 LoRA。

**定义 300–301（泛化的操作性定义与 ACT）** A 泛化到 B 当且仅当 `C_A ⊳ C_B` 产出有效证书且上界 ≤ R*_B；三前提：T1 有效域包含 `𝒟_B ⊆ 𝒟_A`、T2 机制见证 `μ_A ⇒ μ_B`、T3 尾部 Lipschitz `|R_B^tail−R_A^tail| ≤ L_R·W_1 + λ_joint`；通过则 `R̂_{A→B} = R̂_A^tail + L_R·Ŵ_1 + λ̂_joint`，置信 `1−α_A−α_dom−α_div`；否则拒绝并审计。

**定义 302（NTS 三重检测）** (a) 逐分组尾部 CUSUM（按 ARL_0 定阈）；(b) 更新子空间与安全关键认证子空间的主夹角侵入；(c) 共享 vs 仅私有分支的反事实尾部差。任一→WATCH，两独立或持续→TRIPPED。

**定义 303–304（FCB + DFB）** 逐任务四态状态机；`M_contain[i,j] ≤ ε_contain`（i≠j，安全关键）；仅 CCA 确认共因时允许全局 k=0。每关键任务配架构多样性回退（cal 物理静态标定、fault 规则残差、wm 运动学外推、emo 上下文先验），不与主模型共享权重/训练数据，独立性须审计，且回退按构造保守。

**定义 305–306（可靠性感知决策与证书）** `λ_floor^TRUST = max(0.6, 0.8·1[∃τ∈𝒯_s: a_τ<1])`；`k = min(k_RAS, k_reliability)`，k_reliability 随未认证关键任务数单调不增；tripped 任务按类型局部降级（cal 膨胀 U、emo 抬 λ、wm 禁前缀、fault 用保守先验）。`J_TRUST` Valid 需 Valid(J_CALM) ∧ 所有关键 C_τ ∧ β̂ ≤ β_budget ∧ 包含不变式 ∧ 所有 TRIPPED 已切回退。

**定义 307–308（干扰集 / 管线 / 单调性）** ℰ_TRUST = ℰ_CALM × ℰ_xfer × ℰ_ccf × ℰ_cb；在线每 tick 检查 a_τ、周期 NTS、候选适配器过六关；a_τ、λ_floor、k 对证据单调（证据变差只收紧），任何重配置不得在关键证书失效期提升攻击性。

def transfer_certificate(C_A, task_B, domain_test, mechanism_witness, W1_hat, L_R):

                       alpha=C_A.alpha + domain_test.alpha + task_B.alpha_div,
                       D=task_B.D, evidence=C_A), 'PASS'

class FaultContainmentBreaker:
    def transition(self, tau, valid, nts_flag, ccf_alarm):
        s = self.state[tau]
        if not valid or (nts_flag and s == 'WATCH'):  s = 'TRIPPED'
        elif nts_flag:                                s = 'WATCH'
        elif s in ('WATCH', 'TRIPPED') and valid:     s = 'CERTIFIED'
        if ccf_alarm:                                 s = 'FALLBACK'
        self.state[tau] = s
        return s

    def k_budget(self, states):
        n_bad = sum(states[t] in ('TRIPPED', 'FALLBACK') for t in SAFETY)

## 4. 推导

**引理 16（共模的可靠性对偶）** 等相相关误差模型下，(i) 一致性检验 `SNR(ρ_c)=C/√(1−ρ_c)` 严格递增；(ii) 共因份额 `β_CCF(ρ_c)` 单调不减且 `β_CCF(0)=0`，trunk 级失效主导时趋于 1；(iii) 故不存在「只提高灵敏度、不提高共因风险」的 ρ_c 调整，R68 引理 15 的收益必须与 β_budget 一起记账，最优共享是内点。

**引理 17（共享分配的 KKT 结构）** b_τ 单调凹、p_CCF 单调凸时最优唯一：安全关键任务满足
`∂b_τ/∂γ_τ = λ_CCF·∂p_CCF/∂γ_s + μ_τ·∂R̂_τ^tail/∂γ_τ`；
辅助任务 γ_τ = γ_max。β_budget 绑定时所有关键任务被压到 `γ_safe* = p_CCF^{-1}(β_budget)`，剩余迁移需求由私有 LoRA 满足。系：安全关键任务的共享度应是失败代价 ρ_τ 的非增函数，「五头全共享」不是最优。

**引理 18（证书迁移可靠性）** T1–T3 成立时
`P(R_B^tail ≤ R̂_A^tail + L_R·W_1 + λ_joint) ≥ 1 − α_A − α_dom − α_div`。
由尾部 Lipschitz + 三角不等式 + 共形覆盖 + 联合界即得；T2 是布尔前提，不消耗概率预算，无法被统计检验替代。

**定理 16（TRUST 端到端可靠性）** 在 A87–A94 与四不变式下：
`P(V) ≤ Σ_{τ∈𝒯_s}[a_τ·R̂_τ^cert + (1−a_τ)·R̂_τ^fallback] + p_CCF + o(Σp²)`；
且证书失效 ⇒ λ_floor ≥ 0.8 ∧ k 单调不增；回退按构造保守；包含不变式禁止级联；p_CCF ≤ β_budget；仅 CCF 确认 k=0。

**定理 17（优雅降级与检测）** 单任务 TRIPPED 仅损失自身可用性权重，其他关键任务认证界变化 ≤ ε_contain；探针 n_p、偏移 δ 时未检出概率 ≤ exp(−2n_pδ²)，CUSUM 延迟 ≤ h/δ；WATCH→CERTIFIED 需 N_clean 个干净窗口（滞回），抖动概率指数下降；CCF 确认时全局 k=0，恢复路径与单任务回退同构、无控制突变。

## 7. 本轮最大风险

**一句话**：TRUST 的全部安全性押在「可靠性档案已穷尽故障模式、且多样性回退彼此真正独立」这一前提上——**若存在未被登记的共同原因（共享训练数据、同一传感器、同一物理假设，或回退之间实为伪独立），系统会同时拿到多张「看起来独立」的证书并判定 Valid，把「只有一层防护」误认为「多层冗余」**；伪独立性比 R68 明示的耦合更危险，因为 R68 至少知道自己耦合，而 TRUST 会以为自己已经隔离。

**次级风险与缓解**：证书过期/证据腐化（t_exp + 滚动刷新 + 过期即降级）；谱系外任务漂移（ACT 的 T1 双样本检验 + 拒绝迁移优先）；β 估计偏差（注入式校准 + 置信上界 + 预算裕度）；熔断抖动/恢复竞态（滞回 + 双缓冲原子提交）；回退本身不安全（DFB 独立取证，触发即抬 λ、缩 k，不可用则声明能力降级）。
