# 第 9 轮（灵感循环第 9 轮；本轮灵感：「开源软件」×「视觉语言动作模型」）
> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal v8（定义 493–531；引理 77–81；实验 E531–E550）。
> **本轮纪律**：开源化只改变**组装与治理方式**，VLA 只改变**动作提议来源**；二者都不进入 M₀ 的语义。所有新增一律为可选插件，任一缺失、失效或不可信，必须逐级退回 v8。

## 0. 直觉与动机

**灵感 1（开源软件 → 仪表内核的插件化、可复现、可审计）**
直觉：前八轮把每个新模块「焊」进主闭环，退化链只写在论文里，靠人守纪律。开源软件真正可迁移的启示不是「免费」，而是四件工程事实：
1. **显式接口契约**：模块之间只通过声明式接口耦合，谁替换谁不影响语义；
2. **语义版本与锁文件**：依赖解析是确定性的，错误组合在「安装期」就失败，而不是在运行时炸；
3. **来源与许可证可追溯**：每个构件能回答「谁产的、什么许可、改过没有」；
4. **可复现构建**：任何人拿同一组哈希能重放出同一行为。
把这四点搬进指标体系：每层 Mᵢ / 每个增强模块都是一个带 manifest 的 **GaugePlugin**，运行时由 lockfile 解析出兼容集合，证书附带 **repro_hash**。于是「退化链」从文字承诺变成**可执行的类型系统**：契约不兼容的插件根本装不进来，缺失插件由解析器回落到 v8 静态表。但开源也引入新风险面：第三方权重/插件的**供应链污染、版本行为漂移、许可证不兼容**——「能装进来」不等于「可以信」。

**灵感 2（视觉语言动作模型 → 语言直连动作，提议而非决策）**
直觉：v7/v8 的语音层是「语音 → 符号指令 → 经典规划」两跳，开放指代（「把那个红色杯子放到左边盘子旁边」）在符号化时就丢了。VLA 把图像 + 语言直接映射到动作块（action chunk），语义泛化强得多。但它有三个致命属性：延迟数十到数百毫秒、置信度未校准、OOD 时会**自信地胡说**；而且模型本身通常就是第三方开源权重。因此 VLA 不能直接驱动执行器，只能「提议 + 自证」：输出动作块时附带**接地证据**（指令 token 的注意力区域、affordance 掩码、温度校准置信、模型/提示哈希），由仪表层计算接地风险，再决定动作块长度以及是否回退经典规划器。

**交叉洞察**：开源让 VLA 可替换、可复现，也让「信任」第一次成为一等公民；VLA 则给「开源插件」提供了一个高价值、高风险的具体实例。本轮真正研究的不是「更大的模型」或「更多的模块」，而是**开放生态里的信任边界与接地保真**：一个签名合法、版本兼容、但语义已漂移的插件，如何不把整条退化链变成一条「可复现的、可审计的、系统性的错误路径」。

## 1. 研究问题（轮次升级版）

- **Q1（契约化退化）**：如何定义 GaugePlugin 的接口契约与锁文件解析，使任意子集插件缺失、版本冲突或 ABI 不匹配时，系统可证明地退回 v8，而不是在运行时崩溃或静默改变 M₀ 语义？
- **Q2（VLA 接地认证）**：如何在 50Hz 主环上对低频、高维、未校准的 VLA 动作块做「接地保真 + 指令-动作一致性」认证，并把接地风险传播到指标阈值与奖励权重，而不让 VLA 获得直接执行权？
- **Q3（供应链与可复现）**：如何度量开源权重/插件的来源风险（签名、许可证、版本漂移、行为漂移），并让每张证书都能被 repro_hash 第三方重放，从而把「审计」变成可验证谓词而非声明？

## 2. 设计原则（P7–P9 之后升级为 P10–P12）

**P10 仪表插件协议（Gauge Plugin Protocol, GPP）**
每个插件是一个带 manifest 的包：
```
π = (id, semver, iface, manifest, provenance)
iface_π : (S × L) → (m_π, cert_π, wcet_π)
manifest_π = (requires, provides, sensors, wcet_budget, degrade_to, license_spdx)
```
`iface` 固定签名，`manifest` 声明依赖、能力、实时预算、退化目标和许可证。系统只按 lockfile 组装，不按「谁最后写进主环」组装。

**P11 VLA 接地提议（VLA Grounded Proposal, VGP）**
VLA 只暴露 `propose(o_t, ℓ_t) → (A_{t:t+H}, e_t)`，绝不暴露 `execute()`；接地证据 `e_t` 与动作块同生命周期。执行器只接受经 `M_VLA` 认证的前缀，未认证动作一律回退 v8 规划器。

**P12 来源认证的热切换（Provenance-Certified Swap, PCS）**
新插件/新权重先进入 **shadow 隔离** K 个回合，仅记录不执行；只有 `trust(π) ≥ τ_trust`、canary 行为一致率 `≥ τ_agree` 且影子期零硬约束违背时才允许切换。证书携带 `repro_hash`，任何第三方可重放校验。

## 3. 与基线的接口（如何退化）

- GPP / 锁文件解析失败 ⇒ 冻结为 v8 的静态模块表（等价 v8）；
- 来源校验失败 ⇒ 禁止热切换与新插件启用，沿用已锁定版本（安全但不可升级，语义等价 v8）；
- VLA 提议器缺失或无受信权重 ⇒ 退回 v8 的 VoiceCommandTyping + 经典规划器，`risk_VLA ≡ 0`；
- 接地风险模块缺失 ⇒ 风险向量退回 5 维（等价 v8）；
- 动作分块器缺失 ⇒ 固定最短块长 `H_min` 并逐块认证（保守但安全）；
- 全部缺失 ⇒ 逐位等价 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

## 4. 预期贡献

1. **Gauge Plugin Protocol**：把指标层级与增强模块统一为带契约/manifest/lockfile 的可组合包，让退化链成为安装期可判定的谓词；
2. **VLA 接地认证**框架：给出接地保真 Γ_vla、指令-动作一致性 κ_ia 与自适应动作块长 H(t) 的可证明认证时域；
3. **来源风险与可复现账本**：用签名、许可证、版本/行为漂移定义 `risk_SUP`，用 `repro_hash` 把证书变成可第三方重放的审计对象；
4. 完整的 **开放插件-来源-接地-指标-动作** 闭环：E551–E570 覆盖契约解析、供应链、接地认证、块长安全、退化等价与实机集成。

## 5. 本轮最大风险

**一句话**：开源插件生态让退化链变成可执行契约，但「类型兼容 ≠ 语义兼容」——一个签名合法、版本兼容、却在 canary 分布上恰好通过的插件，会把 VLA 的接地幻觉「合法地」装进主环，使系统能够**可复现地、可审计地、系统性地犯错**，而所有证书看起来都完美无缺。

**新增定义 532（Gauge 插件与 manifest）** 插件是唯一可装配单元：
```
π = (id, semver, iface, manifest, prov)
iface_π : (S × L) → (m_π, cert_π, wcet_π)
manifest_π = (requires, provides, sensors, wcet_budget, degrade_to, license_spdx)
```
良构（well-formed）当且仅当：`iface` 与注册槽位的类型签名一致；`requires` 全可满足；`wcet_budget` 不超过宿主剩余预算；`degrade_to` 指向合法层级。

**新增定义 533（锁文件与兼容解析）** 依赖求解是确定性的：
```
L ⊨ Compatible  ⇔  ∀j: requires(π_j) ⊆ (core ∪ ⋃_{k≠j} provides(π_k))

Resolve(P, B) = argmax_{L ⊆ P, L ⊨ Compatible, Σ_j wcet_πj ≤ B} 
                  ( Σ_j semver_score(v_j),  −|L|,  −Σ_j hash(π_j) )
```
三元组按字典序比较，保证同一输入同一输出。若不存在可行 `L`，返回 `L_v8`（静态表），**绝不部分装载**。`semver_score` 对主版本一致者给高分；跨主版本需显式 `allow_major` 声明。

**新增定义 534（来源风险与可信度）** 开源供应链的一等度量：
```
risk_SUP(π) = λ_sig·1[sig invalid] + λ_lic·1[license_spdx ⋢ 项目许可]
            + λ_ver·d_ver(π, π_ref) + λ_beh·d_beh(π, π_ref)

trust(π) = exp(−risk_SUP(π))

d_ver(π,π_ref) = |major diff| + 0.1·|minor diff| + 0.01·|patch diff|
d_beh(π,π_ref) = (1/|C|) Σ_{x∈C} 1[ ‖π(x) − π_ref(x)‖_∞ > ε_beh ]
```
`C` 为离线 canary 集，`d_beh` 用输出差异而非参数差异度量「行为漂移」，天然覆盖重新打包/量化/微调等权重突变。

**新增定义 535（VLA 接地提议与证据）** VLA 只提议，不执行：
```
(A_{t:t+H}, e_t) = VLA_θ(o_t, ℓ_t)
e_t = (Aatt_t, Φ_t, c_t, h_θ, h_ℓ, h_cfg)
```
`Aatt_t` 为指令 token 在图像 patch 上的注意力质量，`Φ_t` 为 affordance 掩码，`c_t` 为温度校准后的成功概率，`h_θ/h_ℓ/h_cfg` 分别为权重、提示模板、配置的哈希。接口层面不存在 `execute()`，执行权在证书层。

**新增定义 536（接地保真 Grounding Fidelity）** 注意力是否落在「可操作区域」：
```
Γ_vla(s) = Σ_{p∈Φ_t} Aatt_t(p) / (Σ_{p∈Ω} Aatt_t(p) + ε)  ∈ [0,1]
```
其空间对偶为 `IoU(top-k(Aatt_t), Φ_t)`，用于需要区域精确对齐的任务；本文默认用质量占比，因其对掩码噪声更稳健。

**新增定义 537（指令-动作一致性 Instruction-Action Consistency）** 冻结双编码器上的归一化余弦：
```
κ_ia(s) = (1 + cos( φ_act(A_{t:t+H}), φ_ling(ℓ_t) )) / 2  ∈ [0,1]
```
`φ_act, φ_ling` 为冻结的轻量编码器（不参与在线训练），避免「用被检验模型自己给自己打分」。

**新增定义 538（VLA 接地风险分量）** 第 6 维风险：
```
risk_VLA(s) = λ_g·(1 − Γ_vla(s)) + λ_i·(1 − κ_ia(s)) + λ_u·U_vla(s) + λ_s·risk_SUP(θ)

U_vla(s) = clip( Ĥ(π_θ) + λ_ens·Var_ens , 0, 1 )
```
`Ĥ` 为归一化预测熵，`Var_ens` 为集成方差；`λ_* ≥ 0`，故 `risk_VLA ≥ 0` 且各项有界，可直接进 softmax。

**新增定义 539（自适应动作分块与陈旧风险上界）** 高风险 → 短块 → 更频繁重接地：
```
H(t) = clip( round( H₀ / (1 + ρ·risk_VLA(s_t)) ), H_min, H_max )

认证时域：设 risk_VLA 沿时间满足 Lipschitz 常数 L_r，
则对块内年龄 τ ∈ [0, H(t)·Δt]：
    risk_VLA(t+τ) ≤ risk_VLA(t) + L_r·τ
要求整块满足 τ_VLA ⇒ H(t) ≤ (τ_VLA − risk_VLA(s_t)) / (L_r·Δt)
```
取上式与 clip 的交集作为最终块长；若交集为空，则 `H=H_min` 并触发重接地或回退 v8。

**新增定义 540（影子隔离与来源认证切换）** 新版本先「只看不动」：
```
ShadowRun(π_new, K) → {a_new^(k), violations^(k)}_{k=1..K}

agree_K(π_new, π_cur) = (1/K) Σ_k 1[ ‖a_new^(k) − a_cur^(k)‖_∞ ≤ ε_agree ]

Swap(π_new) 允许 ⇔ trust(π_new) ≥ τ_trust
                 ∧ agree_K ≥ τ_agree
                 ∧ Σ_k violations^(k) = 0
                 ∧ canary_pass(π_new)
```
否则保持 `π_cur`，并把 `π_new` 写回来源账本（记录但不启用）。

**新增定义 541（可复现账本与复现指纹）** 让证书可被第三方重放：
```
repro_hash(C) = H( h_model ‖ h_weights ‖ h_cfg ‖ h_seed ‖ h_data ‖ h_lockfile ‖ h_env )

ReplayOK(C) ⇔ ‖ C_replay ⊖ C ‖_∞ ≤ ε_repro   （在确定性算子子集上）
```
`h_lockfile` 使「同一代码 + 不同依赖组合」必然产生不同指纹；非确定性算子（GPU 原子加、异步采样）须显式登记并给出 `ε_repro` 容差，不能假装确定性。

**新增定义 542（七层指标闭合与 M_VLA）** 指标层级再加一层：
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_VLA)
M_VLA 监控：Γ_vla ≥ τ_ground, κ_ia ≥ τ_consist, risk_VLA < τ_VLA, trust(θ) ≥ τ_trust
```
`M_VLA` 具备到 M₀ 的退化映射 `δ_VLA`：任一条件违背 ⇒ 直接触发 M₀ 硬约束检查，并暂停 VLA 前缀执行。

**新增定义 543（六维风险与 MetaWeight 升级）**：
```
risk(s) = [risk_SEN, risk_SEM, risk_EFF, risk_PERF, risk_SLAM, risk_VLA] ∈ ℝ⁶
w_i(s) = softmax(α · risk(s))_i,   i = 0..5
w'_i(s) = softmax(α·risk_i(s) + β·emo(s)·Ṽ_i)_{i=0..5}
```
VLA 关闭时截断为前 5 维并重归一化，结果与 v8 逐位一致。

**新增定义 544（软证书扩展）** 六层软硬约束统一尺度：
```
δ_trigger = { σ < τ_safe  ∧  γ_grasp valid  ∧  Δ_dom < τ_dom  ∧  risk_SLAM < τ_SLAM
              ∧ Γ_vla ≥ τ_ground  ∧  κ_ia ≥ τ_consist  ∧  trust(θ) ≥ τ_trust }
```
任一条件失败 ⇒ `M₀` 硬约束检查；`τ_ground, τ_consist, τ_trust` 与 `τ_safe` 均为同尺度上界/下界（概率或风险量纲），避免「软通过、硬失配」的空洞。

**新增定义 545（OSVA 系统标识）**：
```
Φ_OSVA = { 组装: lockfile+contract, 信任: provenance+quarantine,
           动作: VLA-propose+certify, 复现: repro_hash }
Φ_v8   = { 组装: static,         信任: implicit,          动作: voice+planner, 复现: none }
```

**新增定义 546（插件退化态射）** 任一插件集合 `L` 的退化映射：
```
D(L) = L_v8           若 Resolve(L) 失败或 ∀π∈L: ¬well_formed(π)
D(L) = L ∩ Trusted    若来源校验失败
D(L) = L               否则
```
`D` 幂等（`D∘D=D`）且单调（`L₁⊆L₂ ⇒ D(L₁)⊆D(L₂)`），为引理 88 提供代数结构。

**新增定义 547（开放基准协议 OpenBench）** 发布物须包含：
```
(id, 代码哈希, 权重哈希, 配置, 种子, 参考域数据哈希, 期望证书, 许可)
```
任何声称的增益必须在 `repro_hash` 可重放的条件下成立；不可重放的实验不计入社区排行榜。

# IP-354/355 GaugePlugin + LockfileResolver
from dataclasses import dataclass, field

@dataclass(frozen=True)
class GaugePlugin:
    id: str
    version: tuple            # (major, minor, patch)
    iface: str                # 注册槽位签名
    requires: frozenset
    provides: frozenset
    sensors: frozenset
    wcet_ms: float
    degrade_to: str           # 'v8' | 'M0' | ...
    license_spdx: str
    prov: dict = field(default_factory=dict)   # sig, source_url, weight_hash

    def well_formed(self, budget_ms):
        return (self.iface in REGISTERED_SLOTS
                and self.wcet_ms <= budget_ms
                and self.prov.get('sig_ok', False))


class PluginLockfileResolver:
    def __init__(self, registry, v8_static_table, budget_ms):
        self.registry = registry
        self.v8 = v8_static_table
        self.budget = budget_ms

    def _compatible(self, chosen):
        provided = set().union(*[set(p.provides) for p in chosen]) | {'core'}
        return all(p.requires <= provided for p in chosen)

    def _semver_score(self, v):
        return v[0] * 1e6 + v[1] * 1e3 + v[2]

    def resolve(self, pins=None):
        pins = pins or {}
        candidates = []
        for pid, versions in self.registry.items():
            if pid in pins:
                candidates.append([v for v in versions if v.version == pins[pid]])
            else:
                candidates.append(list(versions))
        # 确定性回溯：按 (id, -version) 排序，预算剪枝，永不部分装载
        ordered = sorted(self.registry.keys())
        best = None
        def backtrack(i, chosen, used_ms):
            nonlocal best
            if used_ms > self.budget:
                return
            if i == len(ordered):
                if self._compatible(chosen):
                    key = (sum(self._semver_score(p.version) for p in chosen),
                           -len(chosen),
                           -sum(hash(p.id) for p in chosen))
                    if best is None or key > best[0]:
                        best = (key, list(chosen))
                return
            pid = ordered[i]
            for p in sorted(candidates[i], key=lambda x: x.version, reverse=True):
                if not p.well_formed(self.budget - used_ms):
                    continue
                backtrack(i + 1, chosen + [p], used_ms + p.wcet_ms)
        backtrack(0, [], 0.0)
        return best[1] if best is not None else list(self.v8)   # Level-1


# IP-356 ProvenanceLedger
class ProvenanceLedger:
    def __init__(self, canary, ref_plugin, eps_beh=0.05,
                 lams=(1.0, 1.0, 0.2, 1.0)):
        self.canary, self.ref = canary, ref_plugin
        self.eps_beh = eps_beh
        self.l_sig, self.l_lic, self.l_ver, self.l_beh = lams

    def _d_beh(self, plugin):
        bad = 0
        for x in self.canary:
            if np.max(np.abs(plugin(x) - self.ref(x))) > self.eps_beh:
                bad += 1
        return bad / max(1, len(self.canary))

    def risk_sup(self, plugin):
        prov = plugin.prov
        d_ver = (abs(plugin.version[0] - self.ref.version[0])
                 + 0.1 * abs(plugin.version[1] - self.ref.version[1])
                 + 0.01 * abs(plugin.version[2] - self.ref.version[2]))
        return (self.l_sig * (not prov.get('sig_ok', False))
                + self.l_lic * (not license_compatible(plugin.license_spdx))
                + self.l_ver * d_ver
                + self.l_beh * self._d_beh(plugin))

    def trust(self, plugin):
        return float(np.exp(-self.risk_sup(plugin)))

# IP-358 接地风险传播
class GroundingRiskPropagation:
    def __init__(self, ledger, ling_enc, act_enc,
                 lams=(0.4, 0.3, 0.2, 0.3), tau_ground=0.6):
        self.ledger, self.phi_l, self.phi_a = ledger, ling_enc, act_enc
        self.l_g, self.l_i, self.l_u, self.l_s = lams
        self.tau_ground = tau_ground

    def grounding_fidelity(self, evidence):
        attn, phi = evidence['attn'], evidence['affordance']
        inside = attn[phi].sum()
        return float(np.clip(inside / (attn.sum() + 1e-9), 0.0, 1.0))

    def consistency(self, chunk, instruction):
        a = self.phi_a.encode(chunk)
        l = self.phi_l.encode(instruction)
        return float((1.0 + np.dot(a, l) /
                      (np.linalg.norm(a) * np.linalg.norm(l) + 1e-9)) / 2.0)

    def compute(self, proposal, instruction, plugin):
        ev = proposal['evidence']
        gamma = self.grounding_fidelity(ev)
        kappa = self.consistency(proposal['chunk'], instruction)
        cert = ev.get('conf', 0.5)
        u = float(np.clip(1.0 - cert, 0.0, 1.0))       # 简化：未校准熵以上界替代
        r_sup = self.ledger.risk_sup(plugin)
        risk = (self.l_g * (1 - gamma) + self.l_i * (1 - kappa)
                + self.l_u * u + self.l_s * r_sup)
        return float(risk), {'gamma': gamma, 'kappa': kappa, 'u': u,
                             'risk_sup': r_sup}


# IP-359 自适应分块 + 认证前缀
class SemanticActionChunker:
    def __init__(self, H0=12, H_min=2, H_max=24, rho=1.5,
                 tau_vla=0.7, lipschitz=1.0, dt=0.02):
        self.H0, self.H_min, self.H_max = H0, H_min, H_max
        self.rho, self.tau_vla = rho, tau_vla
        self.Lr, self.dt = lipschitz, dt

    def length(self, risk_vla):
        h = round(self.H0 / (1.0 + self.rho * risk_vla))
        h = int(np.clip(h, self.H_min, self.H_max))
        if risk_vla >= self.tau_vla:
            return 0                                   # 不认证任何块 -> 回退 v8
        # 陈旧风险上界约束
        h_safe = int(np.floor((self.tau_vla - risk_vla) / (self.Lr * self.dt)))
        return max(self.H_min, min(h, h_safe))

    def certified_prefix(self, proposal, certifier, state, h):
        if h == 0:
            return None
        chunk = proposal['chunk'][:h]
        ok, _ = certifier.certify(state, chunk)        # 复用 v8 M₀/M₁ 抽样认证
        return chunk if ok else None


# IP-360 影子隔离 + 来源认证切换
class ProvenanceCertifiedSwap:
    def __init__(self, ledger, tau_trust=0.8, tau_agree=0.95,
                 eps_agree=0.05, K=50):
        self.ledger, self.tau_trust = ledger, tau_trust
        self.tau_agree, self.eps_agree, self.K = tau_agree, eps_agree, K
        self.shadow = {}

    def register_shadow(self, plugin):
        self.shadow[plugin.id] = {'plugin': plugin, 'acts': [],
                                  'violations': 0}

    def observe(self, plugin_id, a_new, a_cur, violated=False):
        rec = self.shadow.get(plugin_id)
        if rec is None:
            return
        rec['acts'].append((a_new, a_cur))
        rec['violations'] += int(violated)

    def can_swap(self, plugin_id):
        rec = self.shadow.get(plugin_id)
        if rec is None or len(rec['acts']) < self.K:
            return False
        agree = np.mean([np.max(np.abs(a - b)) <= self.eps_agree
                         for a, b in rec['acts']])
        return (self.ledger.trust(rec['plugin']) >= self.tau_trust
                and agree >= self.tau_agree
                and rec['violations'] == 0)


# IP-361 可复现账本
class ReproducibilityLedger:
    def __init__(self, env_hash, eps_repro=1e-6):
        self.env_hash, self.eps = env_hash, eps_repro

    def repro_hash(self, model_hash, cfg_hash, seed, data_hash, lockfile_hash):
        payload = '|'.join(map(str, [model_hash, cfg_hash, seed,
                                     data_hash, lockfile_hash, self.env_hash]))
        return hashlib.sha256(payload.encode()).hexdigest()

    def replay_ok(self, cert_orig, cert_replay):
        return bool(np.max(np.abs(np.asarray(cert_replay) -
                                  np.asarray(cert_orig))) <= self.eps)

def metricvoicegauge_round_9(M, s, obs, audio_stream=None, ell=None,

## 3. 推导

**引理 82（契约组合保持软硬约束无空洞）**
设每个已装载插件 `π` 满足契约诚实性 `(A1)`：`cert_π` 与 `τ₀` 同尺度；`(A2)` 其退化目标 `degrade_to` 可达 M₀。则对任意兼容锁文件 `L`，组合后的 `δ_trigger` 仍满足「任一软层违背 ⇒ 必经 M₀」。
证明：`δ_trigger` 是各层触发条件的合取。插件只能**增加合取项**并各自附带 `δ_π→M₀`，不能删除已有项；`L ⊨ Compatible` 保证每个 `δ_π` 的目标槽位存在。由归纳，合取中任一项为真即触发 M₀，故无空洞。注意：该引理不防「插件谎报 `cert_π`」，后者需由来源账本与影子隔离（引理 85）处理。

**引理 83（接地风险有界且对保真度单调）**
`Γ_vla, κ_ia ∈ [0,1]`，`U_vla ∈ [0,1]`，`risk_SUP ≥ 0`，`λ_* ≥ 0`，故 `risk_VLA ≥ 0`；当 `λ` 有界且 `risk_SUP` 有界（签名/许可为指示项，漂移项归一化），`risk_VLA` 有界，注入 6 维 softmax 不产生数值爆炸。并且 `∂risk_VLA/∂Γ_vla = −λ_g ≤ 0`，`∂risk_VLA/∂κ_ia = −λ_i ≤ 0`：接地越准、动作越一致，风险越低。

**引理 84（自适应块长的认证时域安全）**
若 `risk_VLA` 沿时间 `L_r`-Lipschitz，选择 `H(t)` 满足定义 539 的两条约束，则对块内任意年龄 `τ ≤ H(t)Δt` 有 `risk_VLA(t+τ) ≤ τ_VLA`。因此「按当前风险认证过的前缀」在整个执行窗口内仍满足接地风险上界；块长越短，最坏陈旧风险越小。推论：`H_min` 提供下界可用性，`H_max` 限制重接地延迟上界 `H_max·Δt`。风险超过 `τ_VLA` 时 `H=0`，强制回退 v8，而不是「硬着头皮执行」。

**引理 85（影子隔离的零直接激活与覆盖缺口）**
在 `Swap(π_new)` 未满足前，`π_new` 只写 `shadow` 记录、不进入执行路径，故其直接激活概率为 0（构造性）。设 canary 集 `C` 覆盖所有「会导致 M₀ 违背」的输入类，且 `agree_K≥τ_agree` 的采样以高概率捕捉该类的行为差异，则不安全切换概率 ≤ `(1−τ_agree)^K`（按回合独立近似）。**关键缺口**：若 `C` 未覆盖某危险输入类，则上述保证失效——这正是本轮最大风险的来源，不能把「canary 通过」当成「语义等价」的证明。

**引理 86（来源风险不改变 M₀ 语义）**
`trust(π)` 只作为「是否允许提议进入认证路径」的门控，以及 `risk_VLA` 的一个加性项；它不参与 M₀ 的判据、阈值或退化映射。因此无论 `trust` 取何值，被执行动作仍须通过 `certifier` 的 `M₀∧M₁` 检查。来源风险的唯一后果是「更保守」（更早回退 v8），而非「放宽硬约束」。

**引理 87（复现指纹的篡改可检测性与重放等价）**
设 `H` 为抗碰撞哈希。若 `(model, weights, cfg, seed, data, lockfile, env)` 任一改变，则 `repro_hash` 以可忽略概率改变，第三方重放会因指纹不匹配或 `ReplayOK=False` 而拒绝。反向（同指纹 ⇒ 同证书）仅在确定性算子子集上成立；GPU 非确定性、异步采样、时间依赖调度会破坏该方向，故必须以 `ε_repro` 容差与「已登记非确定性算子」显式限定，而不能声称逐位可复现。

**引理 88（六级退化正交性）**
各新模块的接口互不重叠：PLR 只决定「装载哪些插件」；PL 只决定「是否允许插件进入认证/切换」；VLA-AP 只产生提议与证据；GRP 只写 `risk_VLA`；SAC 只决定块长与认证前缀；PCS 只决定版本切换。按声明顺序逐级关闭，均不改变其余模块的输入/输出契约。由定义 546 的幂等与单调性，`D` 的组合仍返回 v8 子集；全关即逐位等价 v8。

**引理 89（开放基准的激励相容性）**
若排行榜只接受 `repro_hash` 可重放的条目，则任何「不可复现的增益」无法进入榜单；发布者若要提升排名，必须公开足够信息使第三方能重建同一 `repro_hash`。这不能阻止造假，但把「造假成本」从「写一个数字」抬高到「构造一整套自洽且可重放的假证据」，从而提高审计效率。

## 7. 本轮最大风险

**一句话**：开源插件化把退化链变成可执行契约，却把安全性押在「canary 覆盖」上；VLA 的接地幻觉与供应链的版本/行为漂移会在契约层之下悄悄耦合——一个签名合法、版本兼容、canary 恰好通过的插件，能让系统**可复现地、可审计地、系统性地犯错**，而所有证书都显示通过。
