## 0. 直觉与动机

**灵感 1（云端协同 → 单机不可辨识，群体可辨识）**
直觉：计量学的第一性原理是「没有外部参考就没有标定」。R68 的 COF 是自标定（self-calibration），它默认「静止时跨模态一致即真相」——但当所有模态一起缓慢漂移，或所有模态共享同一环境缓慢变化时，环一致性检验对共同模完全盲。云端的价值不是算力，而是**第二个参考系**：同一环境里其他设备、同一批次其他单元、同一任务的长期统计，构成一个本机没有的 anchor。把标定状态分解为「群体共同模 μ + 个体偏差 b_i」（定义 294），跨设备对比 Δ_i = r_i − r̄ 让 μ 在差分中抵消（定义 295）——原本不可辨识的共同模被「差分」免费消掉，剩下的 b_i 才是个体问题。

**灵感 2（迭代验证 → 从被动等待到主动实验；可逆性是免费的判别器）**
直觉：R68 只在「机器人碰巧静止」的静态段被动回归标定，信息量取决于运气。迭代验证把它翻过来：**云侧设计安全激励（热脉冲、力归零动作、已知同步脉冲、定姿保持），主动把 H_cal 与 H_fault 推到可分的方向上**（定义 298）。更关键的是物理判别器：**标定漂移通常是可逆的（温漂随热循环回到原点，形成闭合滞回环），而老化/磨损类故障是不可逆的（单调累积、有迟滞不回零）**。一次热循环就是一次天然对照实验：可逆性指数 R 高 ⇒ 标定；老化累积 A 高且 R 低 ⇒ 故障（定义 296）。这把 R68 里「慢变量全归标定」的粗暴二分，换成了一个有物理依据的二分。序贯检验（SPRT/Bayes factor）再把每次探测的证据迭代累积，给出**可量化的隐藏时间上界**（引理 18）。

**灵感 3（联邦 canary → 补齐 R68 盲点不靠更好的单机金标集，而靠「别人踩过的坑」）**
直觉：R68 的 canary 不可修复性关卡受限于「本地金标集是否恰好包含这个故障模式」，而缓变故障恰恰不在其中。云端可以汇聚全队的慢故障签名（轴承磨损斜坡、接插件氧化、安装座蠕变），甚至合成注入老化轨迹，形成一个持续增长的**联邦 canary 库**（定义 300）。这直接命中 R68「CAC 金标集未覆盖该故障模式则放行」的失败路径——覆盖率不再由单机负责。

**灵感 4（两灵感合流 → FEDMET-RAS 六组件 + 继承核）**
1. **CMP Cloud Metrology Prior**：层级贝叶斯群体先验 c_i = μ + b_i，云端维护 μ 并下发先验；
2. **CDD Cross-Device Disentangler**：跨设备差分 + 共同模/个体分解 + 可逆性指数 + 老化累积 + 四象限归因；
3. **APG Active Probe Generator**：在安全包络内选信息量最大的激励（约束 D-最优实验设计）；
4. **IVL Iterative Validation Loop**：序贯 Bayes factor，三值决策 {H_cal, H_fault, H_und}，undecided ⇒ 保守；
5. **FCB Federated Canary Bank**：全队慢故障签名 + 合成老化，CAC 第六关；
6. **CEC Cloud-Edge Contract**：L1 边缘硬护栏 + L2 云端证明 + 「无证明不吸收」+ 分区安全回退 + Byzantine 鲁棒聚合 + DP 预算；
7. **CALM-RAS† 继承核**：R68 的 COF/CFA/CAC/MTM 全部保留，只是 COF 改为层级、并受 CEC 门控。

**灵感 5（对 R68 风险对症下药）**
- R68「缓变故障被标定吸收」→ 三保险：群体差分识别共因、可逆性实验识别个体、undecided 默认保守；
- R68「金标集不覆盖」→ FCB 联邦覆盖（引理 19）；
- R68「标定能力越强故障越隐形」→ 新纪律 **无证明不吸收**：慢 c 更新需云端 attestation，否则冻结（定义 301）；
- 新增攻击面（云污染、分区、探测可预测）→ Byzantine 鲁棒聚合 + 分区回退 + 随机化探测时刻（定义 298/302）。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（FEDMET-RAS 总览与三不变式）** FEDMET-RAS = (CMP, CDD, APG, IVL, FCB, CEC, CALM-RAS†)。三不变式（在 R68 之上收紧）：
(i) **无证明不吸收（No absorption without attestation）**：个体慢标定 b_i 的更新仅在云端 attestation A_t = PASS 时被允许；缺失证明（分区、陈旧、污染）⇒ 冻结 c 到最近一次已证明状态，U ← ∞，λ_floor = 0.8，k 收缩。R68 的「速率限制」降级为**必要非充分**防线；
(ii) **可辨识性前置**：任何「把慢残差归为标定」的判定，必须同时给出 (a) 跨设备共同模解释，或 (b) 主动探测可逆性证据；两者皆无 ⇒ 判 H_und（未决），按保守处理，禁止默认吸收；
(iii) **云边预算约束**：上行仅传充分统计量 + DP 梯度，总预算 (B bit/s, ε)；下行仅传探测计划与 attestation；任何时刻边缘 L1 硬护栏（速率上限、R68 红线）本地独立生效，不依赖云。

**定义 294（CMP 层级标定先验）** 设备 i 的标定状态分解 c_i,t = μ_t + b_i,t，其中 μ_t ∈ ℝ¹² 为群体共同模（环境/批次/工况的共享分量），b_i,t 为个体偏差。层级先验：μ_t ~ 𝒩(μ_{t−1}, Q_μ)（云侧共享），b_i,t ~ 𝒩(0, Q_b)（个体，零均值）。上下文对齐函数 κ(·) 把不同设备映射到可比工况（姿态、负载、温度分箱），仅在 κ 匹配的设备子集上计算群体均值 r̄_t（定义 295），避免把「不同工况」误当「不同故障」。

**定义 295（CDD 跨设备残差分解）** 对设备 i 与匹配群体 S_i(t)：
r_i,t = r_cal(μ_t) + r_cal(b_i,t) + r_fault(f_i,t) + ε_i,t，
跨设备对比 Δ_i,t = r_i,t − r̄_t = r_cal(b_i,t − b̄_t) + r_fault(f_i,t) + (ε_i,t − ε̄_t)，
其中共同模 r_cal(μ_t) 在差分中被消去。于是：**共同模只能由横截面（fleet）识别，个体漂移/故障由对比识别**（引理 16–17 的结构基础）。

**定义 296（可逆性指数与老化累积）** 对一次探测循环（如热脉冲 T→T+ΔT→T），记录标定后残差轨迹。可逆性指数
R_i = 1 − ‖c_i(t_end) − c_i(t_start)‖ / ‖∫(dc/dt)dt‖（滞回环闭合度）∈ [0,1]；
老化累积 A_i,t = ∫₀ᵗ max(0, d/dτ‖b_i,τ‖)·1[单调 ∧ 不回零] dτ。
判别：R 高（环闭合）∧ A 低 ⇒ 可逆标定漂移；R 低 ∧ A 高（单调、迟滞不回零）⇒ 不可逆老化故障。R、A 均由探测数据计算，无需人工标签。

**定义 297（四象限归因）** 由 (R_i, A_i) 与共同模判别 g_i = ‖Δ_i − r_cal(b̂_i)‖ 定义四象限：
| | 可逆 (R 高) | 不可逆 (R 低, A 高) |
|---|---|---|
| 个体 (g 高) | Q1 温漂/曝光漂（可标定） | Q2 个体老化（真故障，最高优先） |
| 共同 (g 低) | Q3 环境/批次共同模（可标定，但需审计） | Q4 全队共因故障（最高危，禁止当标定） |

Q4 是 R68 完全看不见的格子：**共因缓变故障**。R69 用「不可逆 + 共同」显式将其从标定中剥离并升级为全队告警。

**定义 298（APG 主动探测）** 探测 u_t ∈ U_safe（定义 309）。选择规则：
u* = argmax_{u∈U_safe} D_KL(p(r|Q2∪Q4) ‖ p(r|Q1∪Q3); u)，s.t. safety_cost(u) ≤ C_max，availability_loss(u) ≤ L_max，frequency ≤ f_probe。
候选探测：受控热脉冲、力归零动作、已知同步冲击、定姿静止保持、微幅已知轨迹激励。**探测即实验设计**：只做能把两个假设分开的动作，不做无信息动作；探测时刻随机化（防可预测利用）。

**定义 299（IVL 序贯三值验证）** 逐探测累积对数 Bayes factor：
log BF_t = log BF_{t−1} + log [p(r_t | H_fault)/p(r_t | H_cal)]。
三值决策：H_cal if log BF < log b_lo；H_fault if log BF > log b_hi；否则 H_und。Wald 阈值 b_hi = (1−β)/α，b_lo = β/(1−α)。**关键纪律：H_und 按 H_fault 的保守侧处理**（λ_floor ≥ 0.8、k 收缩），绝不按 H_cal 放行。这堵死了 R68「默认吸收」的路径。

**定义 300（FCB 联邦 canary 库）** C_fleet = ∪_{i=1}^{N_f} C_i，C_i 含该设备历史故障签名与合成老化注入（轴承磨损斜坡、接插件氧化、安装座蠕变、慢泄漏）。CAC 第六关（fleet_canary_gate）：候选 θ′ 对任一 canary 不得吸收——若 ∃ canary c 使 ‖r_c(θ′)‖ < ρ_can·‖r_c(θ)‖（ρ_can = 0.3）则一票否决。版本号写入 J_FEDMET。

**定义 301（CEC 云边安全契约）** 两层护栏：
- **L1 边缘硬护栏（本地、恒在）**：R68 速率限制、红线、λ_floor；即使云完全不可达也必须成立；
- **L2 云端证明（软、门控吸收）**：attestation A_t = PASS ⇔ 云端 (CMP, CDD, IVL) 联合后验 P(Q1∪Q3) > 1−δ_att ∧ FCB 通过 ∧ 无污染告警。
吸收权限 = L1 ∧ L2。分区/陈旧/失败 ⇒ 状态机进入 S2（冻结 + 保守），并记录待重放证据。

**定义 302（Byzantine 鲁棒聚合）** 云端对上报的 {b_i} 用坐标中位数 / Krum 聚合：b̂ = Krum({b_i}; N_f − 1)，要求 N_f ≥ 2f+1 抵抗 f 个恶意节点。群体统计另设**一致性交叉检验**：若某设备 b_i 与群体中位数偏离 > 3·MAD 且伴随不可逆累积，则升级为个体故障候选而非剔除（防止「把真故障当离群点抹掉」）。

**定义 303（隐私与通信预算）** 上行：{b_i, Σ_i, 残差直方图, clip(C,S)·∇}，加高斯机制 𝒩(0, σ_dp²)（仅作用于群体先验；**canary 安全路径不加噪**）。总隐私预算 ε ≤ ε_max，按 RDP 组合跨轮记账。下行：探测计划 + attestation + 群体 μ。带宽 B ≤ B_max（典型 ~4 KB/s）。

**定义 304（FEDMET 干扰集）** ℰ_FEDMET = ℰ_CALM × ℰ_cloud × ℰ_ivl × ℰ_probe；ℰ_cloud = {陈旧先验, 投毒, 分区, 重放, Sybil}；ℰ_ivl = {早期误判, 未决滞留, 阈值操纵}；ℰ_probe = {探测致扰动, 探测时序泄露, 探测不安全}。

**定义 305（J_FEDMET 证书）** J_FEDMET = (J_CALM, μ_hash, attestation_verdict, probe_log_hash, log BF_t, R_i, A_i, canary_bank_ver, dp_epsilon, fedmet_ver)。Valid ⇔ Valid(J_CALM) ∧ attestation_verdict = PASS ∧ (BF 已决 ∨ 处于保守未决) ∧ fleet_canary_pass ∧ ε ≤ ε_max。

**定义 306（管线）** 云端（异步）：聚合充分统计 → 拟合 CMP → 生成探测计划 → 计算 attestation → 更新 FCB。边缘（实时）：L1 护栏 → COF（受 L2 门控的慢更新）→ IVL 日志 → 局部前向/控制。探测在低风险窗口执行，不占实时控制预算。

**定义 307（保守回退状态机）** S0 正常（attested，μ/b 更新允许）；S1 探测中（c 冻结，收集中）；S2 分区/陈旧（c 冻结，U=∞，λ≥0.8，k 收缩，本地仅 L1）；S3 污染告警（全队降级，禁用共同模先验，回退到 R68 单机保守 COF，λ≥0.8）。状态跃迁**单调保守**：任何不确定都只能向 S2/S3 迁移，恢复需云端重新 attestation。

**定义 308（attestation 判定）** A_t = PASS ⇔ (i) P(Q1∪Q3 | Δ, probe, μ) > 1−δ_att；(ii) 所有 canary 残余 > ρ_can 阈值；(iii) 状态机在 S0/S1；(iv) 上报数据通过一致性交叉检验（定义 302）；(v) 未触发 ℰ_cloud 的重放/陈旧检测（μ 版本单调、nonce 新鲜）。

**定义 309（安全探测集 U_safe）** U_safe = {u : safety_cost(u) ≤ C_max ∧ availability_loss(u) ≤ L_max ∧ ‖u‖_∞ ≤ u_max ∧ 不改变任务目标 ∧ 可在当前状态安全中止}。热脉冲幅度受材料与热时间常数约束；力归零仅在已知无接触窗口；同步脉冲不干扰主控制环。

**定义 310（证明链）** proof_chain_t = H(proof_chain_{t−1} ‖ A_t ‖ probe_log_t ‖ canary_ver ‖ μ_hash) 哈希链，防重放/篡改，纳入 J_FEDMET；不可信证明即 S3。

```python
        u = M.apg.schedule(M.ivl.hypotheses(), M.U_safe, M.budget)
        M.probe_buffer.push(execute_probe(u))            # 热脉冲/力归零/同步
    verdict = M.ivl.update(r, M.probe_buffer.last())
    if M.ivl.conservative(verdict):                      # 未决 -> 保守
        c, U = M.cal.freeze(), float('inf')
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(M.ach, U))
    # ---- 云边异步（不占实时预算）----
    M.cec.uplink(M.stat_summary(b_safe=True), dp_eps=M.eps)
    M.fcb.sync(M.cloud.canary_bank())
    M.cac6.maybe_commit(M.shadow, M.time_since_last_commit)   # 六关
    return k, lam, joint, (c, U, verdict)
```

## 3. 推导

**引理 16（单机不可辨识性 / gauge 自由度）** 设单机观测 r_t = r_cal(c_t) + r_fault(f_t) + ε_t，c、f 均慢（ω ≤ ω_cal）。若 im(∂r_cal/∂c) ∩ im(∂r_fault/∂f) ≠ {0}（可标定方向与故障方向在残差空间有重叠），则映射 (c,f) ↦ r 非单射：存在非零 gauge 方向 δ 使 r_cal(c+δ) + r_fault(f−δ) = r_cal(c) + r_fault(f)。故任何单机估计器都有零空间，R68 的缓变故障风险是**结构性不可辨识**而非滤波器缺陷。证：由隐函数定理，J = [J_c, J_f] 列数 > rank(J) 时存在零空间向量 (δ, −δ)。

**引理 17（群体 + 探测恢复可辨识）** 在 A95（个体故障 f_i 跨设备独立、共同模 μ 共享、b_i 零均值）与 A96（可逆性探针给出与残差空间正交的独立测量维度 s = ψ(c,f)，且 ψ 对 c、f 符号相反）下，跨设备对比 Δ_i 消去 μ（降维），探针维度 ψ 再消去 gauge 方向 δ ⇒ 联合 Jacobian [J_Δ; J_ψ] 列满秩，故 (b_i, f_i) 局部可辨识。系：共同模与个体故障可分离，正是 R68 缺失的外部参考。

**引理 18（序贯检验延迟界）** IVL-SPRT 在每探测 KL 散度 D_t = D_KL(p(·|H_fault)‖p(·|H_cal); u_t) 下，期望探测数 E[N] ≤ [(1−β)log b_hi + β log b_lo] / D̄（Wald），D̄ 为平均 KL。故缓变故障的平均隐藏时长 ∝ 1/D̄；APG 在 U_safe 内最大化 D̄（定义 298）等价于最小化隐藏时长。可操作结论：**探测信息量决定故障能被多快揪出**；被动等待的 D̄→0 正是 R68 的隐患。

**引理 19（联邦 canary 覆盖率）** 设各设备 canary 对故障流形覆盖率为 p_c、故障跨设备可交换（A97）。N_f 台设备并集覆盖率为 1−(1−p_c)^{N_f}；N_f = 50、p_c = 0.1 ⇒ > 99.5%。故 FCB 以高概率补齐 R68「单机金标集未覆盖该模式」的盲点。**代价**：A97 失效（全新故障模式、共因故障）时覆盖率归零——这是定理 17 与最大风险的来源。

**定理 16（FEDMET 端到端风险一致性）** 在 R68 的 A87–A94 与新增 A95–A97 下：
1. P(|τ_cmd − τ*| > ε) ≤ [R68 全项] + α_cloud + α_ivl + α_probe，其中 α_ivl ≤ α+β（序贯检验），α_cloud 由 attestation 错误界，α_probe 由 U_safe 内探测安全性界；
2. **无证明不吸收**：分区/陈旧/污染 ⇒ 状态机 ≤ S2 ⇒ c 冻结、U=∞、λ≥0.8、k 收缩——不确定性只导向收紧；
3. **缓变故障不静默吸收**：若故障可逆性低（Q2）或共同模异常（Q4），IVL 判 H_fault 或 H_und ⇒ 保守；若两者皆不成立且未被 FCB 覆盖，则属于 A97 失效的残余风险，概率 ≤ (1−p_c)^{N_f}·δ_und + 攻击面项；
4. **共因故障升级**：Q4（不可逆 + 共同）触发全队告警，禁止写入 μ——这是 R68 完全缺失的一格。

**定理 17（云边契约的安全-可用性权衡）** 设分区概率 p_part、投毒比例 p_poi、鲁棒聚合容忍 f 个恶意节点（N_f ≥ 2f+1）。则：
(i) 静默吸收概率 ≤ p_poi·1[p_poi > f/N_f] + δ_att + (1−p_c)^{N_f}·δ_und；
(ii) 可用性损失（进入保守 S2/S3 的比例）≤ p_part + p_poi·1[p_poi > f/N_f]。
安全与可用性呈 Pareto 关系，本设计**显式选择安全优先**：宁可保守停机也不静默放宽；回退路径与提交路径同构，恢复需重新 attestation。

**定理 18（迭代验证 + 联邦 + 六关的收敛）** 六关 + 三值纪律下：有害适配器上线概率 ≤ (1−r_canary^fleet)·p_h，其中 r_canary^fleet = 1−(1−r_canary)^{|C_fleet|} 随库增长单调趋近 1；误吸收概率随探测数几何下降（BF 为似然比乘积，至边界即停）。代价：未决期（H_und）的控制保守性有可用性成本，且 BF 收敛速度受 D̄ 限制（引理 18）。

## 6. 本轮最大风险

**一句话**：FEDMET-RAS 把 R68 的「单机不可辨识」外包给了云端，却把安全押在两条更强的新假设上——**「故障不可逆、标定可逆」的可逆性二分，与「设备间故障独立、共同模共享」的交换性假设**。机械蠕变（不可逆的标定漂移）与热致重接触（可逆的间歇故障）会同时违反前者；同批次/同环境的共因缓变故障会违反后者，此时云端把整队的系统性故障误判为「群体共同模」，再经联邦先验**同步注入全队**，造成比 R68 单机吸收更严重的相关性失效（herd 误判）。这是「把辨识外包给群体」的原罪：**群体一致性既是证据，也可能是共谋**；而且主动探测本身构成可预测的扰动窗口，可被对抗者利用。

**次级风险与缓解**：
1. **云分区 → 可用性下降**：分区回退到 S2（保守），安全但可能频繁降级 → 探测计划与 attestation 缓存 + 分级超时；
2. **云侧投毒**：鲁棒聚合（Krum/中位数）+ N_f ≥ 2f+1 + 一致性交叉检验（不误删真故障）；
3. **DP 噪声与检测的权衡**：噪声只加在群体先验、canary 安全路径不加噪；ε 跨轮 RDP 记账；
4. **探测安全性/可预测性**：U_safe 硬约束 + 安全中止 + 时刻随机化 + 探测日志哈希链；
5. **未决滞留（H_und 长期不决）**：设定最大未决时长，超时升级 S2 并请求人工/云端重标定，绝不自动放行。

## 4. 推导

**引理 16（单机不可辨识）** r = r_cal(c) + r_fault(f) + ε，若 im(∂r_cal/∂c) ∩ im(∂r_fault/∂f) ≠ {0}，则存在非零 gauge δ 使两参数化残差等价；单机估计器必有零空间——R68 风险是结构性不可辨识，不是 bug。

**引理 17（群体 + 探测恢复可辨识）** A95（故障独立、共同模共享、b_i 零均值）+ A96（可逆性探针提供正交且符号相反的测量）下，Δ_i 消去 μ、ψ 消去 gauge ⇒ [J_Δ; J_ψ] 列满秩 ⇒ (b_i, f_i) 局部可辨识。

**引理 18（序贯延迟界）** SPRT 期望探测数 E[N] ≤ [(1−β)log b_hi + β log b_lo]/D̄；隐藏时长 ∝ 1/D̄；APG 最大化 D̄ = 最小化隐藏时长。被动等待 D̄→0 正是 R68 隐患。

**引理 19（联邦覆盖）** 覆盖率 1−(1−p_c)^{N_f}；N_f=50、p_c=0.1 ⇒ > 99.5%，补齐单机金标盲点；A97 失效（全新/共因故障）时覆盖率归零。

**定理 16（端到端风险一致性）** 1) 误差界 = R68 全项 + α_cloud + α_ivl(≤α+β) + α_probe；2) 无证明不吸收，任何不确定 → λ≥0.8、k 收缩；3) 缓变故障不静默吸收（Q2/Q4 或未决 ⇒ 保守），残余风险 ≤ (1−p_c)^{N_f}·δ_und + 攻击面；4) Q4 共因故障升级全队告警、禁止写入 μ。

**定理 17（安全-可用性权衡）** 静默吸收 ≤ p_poi·1[p_poi>f/N_f] + δ_att + (1−p_c)^{N_f}·δ_und；可用性损失 ≤ p_part + p_poi·1[p_poi>f/N_f]。显式安全优先，回退与提交同构，恢复需 attestation。

**定理 18（收敛）** 有害适配器上线 ≤ (1−r_canary^fleet)·p_h，r_canary^fleet 随库增长趋 1；误吸收概率随探测数几何下降；代价是未决期保守与 D̄ 受限的收敛速度。

## 7. 本轮最大风险

**一句话**：FEDMET-RAS 把 R68 的「单机不可辨识」外包给云端，却把安全押在两条更强的新假设上——**「故障不可逆、标定可逆」的可逆性二分，与「设备间故障独立、共同模共享」的交换性假设**；机械蠕变（不可逆标定漂移）与热致重接触（可逆间歇故障）同时违反前者，同批次/同环境共因缓变故障违反后者，此时云端会把整队系统性故障误判为「群体共同模」并经联邦先验同步注入全队，造成比 R68 单机吸收更严重的相关性失效（herd 误判）——群体一致性既是证据，也可能是共谋。

**次级风险与缓解**：云分区致可用性下降（探测计划与 attestation 缓存 + 分级超时）；云侧投毒（Krum/中位数 + N_f ≥ 2f+1 + 一致性交叉检验）；DP 噪声与检测权衡（仅群体先验加噪、canary 路径不加噪、RDP 记账）；探测安全/可预测（U_safe 硬约束 + 安全中止 + 时刻随机化 + 哈希链）；未决滞留（最大未决时长，超时升 S2 请求重标定，绝不自动放行）。
