# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「具身智能」×「姿态估计」）

> R69 教会闭环去「问」——问人、问环境、问自己的传感器，用 VoI 决定一次注视、一次探针、一句问话。但 R69 的证据链有一个共同的根：**它们全部来自外感受（exteroception）**——传感器残差 r_res、被观测到的回答 y、以观测 o 为条件的流似然 Δa。只要外部通道被系统性偏置、且偏置恰好落在策略流形上，R69 的第二意见也会失效；而人的回答可以被投毒。R69 自陈的最大风险是「信了一个会撒谎的外部证人」。
>
> 本轮问一个更靠底层的问题：**有没有一个证人，是外部贿赂不了的？** 答案是**自己的身体**——但只在你能判断「身体自己是否也在骗你」的前提下。两个灵感正好给出这两半：
> - **具身智能**：身体不是执行器、也不是一路输入，而是一个**物理耦合的闭环参考系**。本体感觉（关节、力矩、IMU）、接触、重力方向、运动学闭包，都是「实际物理交互生成」的证据，而不是某条可被远程伪造的通道。你抬了手，物体就该动；物体没动，要么世界不在你以为的地方，要么你的手不在你以为的地方。
> - **姿态估计**：姿态是低维、受物理约束、带 SE(3) 结构的量。它同时给出三样东西：(a) 紧凑且等变的模态表示；(b) **时间闭包残差**——「我的身体移动了 Δξ_self，世界的相对姿态就应当变化 Δξ_pred」；(c) **可观测性**——姿态歧义依赖视角，因此「移动到更好的视角」本身就是一个可计算、可认证的具身信息动作。
>
> 核心命题：**以身体姿态为最后锚点，建立第三条「物理耦合」证据通道（姿态闭包 r_kin），与 R68 的传感器残差 r_res、R69 的行为似然 Δa 构成三通道互证；但锚本身必须被审计（自模型审计 SMA），锚不可信时严格退化为 R69/R68。** 命名 **ANCHOR-RAS**（Anchored Non-forgeable Closure, Hierarchical trust, Observability-driven Repositioning）。
>
> 一句话定位：R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我自己的身体动了，世界是否按它该有的方式动了——以及，我是否真的站在我以为的地方**」——身体是最后一个可信的证人，但它也会生锈。

## 0. 直觉与动机

**灵感 1（具身智能 → 身体是不可贿赂的证人，但会生锈）**
直觉：外感受是「世界寄来的一封信」，可以伪造、可以被标定层解释掉；本体感觉与接触是「我用手推了世界一把」的因果耦合——它不是报告，而是物理事实。伪造它，不能只改一封信，必须让整条因果链自洽：关节角、力矩、IMU 重力方向、接触事件、物体相对位姿的变化必须一起对上。这就是为什么「身体」比「传感器」更难被骗。但反命题同样成立：编码器会老化、负载会变化、运动学模型会失配——**锚会生锈**。所以本轮的姿态不是「无条件相信身体」，而是「**比相信世界更相信身体，但比审计世界更严格地审计身体**」。

**灵感 2（姿态估计 → 闭包残差是第三条独立通道）**
直觉：R68 测「传感器是否自洽」（r_res），R69 测「策略行为是否自洽」（Δa），两者都以观测 o 为条件——共享同一个可能被污染的前提。姿态估计给出第三个量：**我的动作导致的身体相对位姿变化 Δξ_pred（由运动学/接触模型算出），与世界相对位姿变化 Δξ_obs（由他者/物体姿态估计得到）之间的差**。三者测的是三种不同的「诚实」：传感器诚实、策略诚实、物理耦合诚实。三通道的联合分布可做故障隔离（2-of-3），而 r_kin 不需要外部标定——它是自指的、跨时间的物理账本。

**灵感 3（姿态估计 → 歧义在姿态空间更可解，「移动去看」是信息动作）**
直觉：姿态歧义（自遮挡、深度翻转、对称物体）是 epistemic 且**依赖视角**的。R69 的 MINT 只会在「看/问/触」里选，但具身智能多了一类动作：**改变自己的身体位姿去获得更好的观测**——凑近、侧移、绕到背面、改变腕部朝向。这不是启发式，而是可计算的：姿态后验协方差在 D-optimal 视角下最小，VoI_pose 可以在动作前估计。于是「问一句」和「走过去看清楚」进入同一个 VoI 目标，后者还带物理成本与安全认证。多模态交互由此从「询问」扩展为「**具身探询**」。

**灵感 4（具身智能 → 姿态等变与具身可行性：先验不是正则，是硬物理约束）**
直觉：R69 的流策略能生成「几何上漂亮」的模态，但它可能对**这个身体**不可行：超出关节限位、够不到、力矩不够、接触点落在支撑多边形外、自碰撞。把模态重新参数化到姿态空间并施加 SE(3)/关节等变，再用「具身可行性证书」剪枝，正好击中 R69 的最大风险（幻觉模态）：**幻觉模态往往不是「不像话」，而是「这副身体做不到」**。等变性还带来跨具身迁移：不同机器人共享姿态空间的模态结构，只在运动学差距处修正。

**灵感 5（非言语证据 → 姿态是并行的诚实通道，但也会被「演」）**
直觉：R69 担心人会撒谎；但人的身体常常与嘴不一致——口头说「没事」，姿态却在后撤、重心在远离、手在护住伤处。姿态因此是一个**正交证据源**（对应 R69 的 k 个正交源一致纪律）。但姿态同样可以被表演、被对抗贴片攻击、被深度伪造与重放。因此它只有在通过**独立性认证**（非自主微动作、接触真值、时间不可控的一致性）时才计入证据；否则与言语通道相关 ρ→1，R69 引理 18 的收益立刻塌缩为单源——「身体也会配合谎言演戏」。

**灵感 6（形态计算 → 身体给的不是信息，是免费的约束）**
直觉：具身智能的经典论点是「形态本身承担计算」。对可信性而言这等价于：身体提供了一组**免费、不可协商的物理约束**（不能瞬移、加速度有界、接触必须因果、重力方向固定）。这些约束既可作为姿态估计的强先验，也可作为伪造者的额外负担——你想骗我，得连这些约束一起骗。本轮把它显式化为 PCN 的先验项与引理 19 的伪造成本下界。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ANCHOR-RAS 总览）** ANCHOR-RAS = (BSP, EPE, PCN, TAF, SMA, AOB, PEM, EAC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **锚定层级**：本体感觉自姿态是「最后锚点」，但**永不单独作为权威**；外感受姿态必须经闭包互证；
(iii) **三通道异议纪律**：任何「升级动作/宣布故障」需至少两个正交通道一致；单通道只产生怀疑、不定案；
(iv) **先审计再信任**：仅当 SMA 给出 t_s ≥ τ_s 时，r_kin 才可作锚定证据；否则降级。

**定义 311（具身状态与自姿态 BSP）** 本体状态 s_t = (q_t, q̇_t, τ_t, a_t^IMU, ω_t^IMU, C_t)，运动学模型 K(·)。自姿态 ξ_s,t = (R_s,t, p_s,t) ∈ SE(3)，协方差 Σ_s。绝对参考：静止时的重力方向 g_w（IMU 加速度对齐）与零速修正 ZUPT；接触事件提供相对位置约束。BSP 用因子图/EKF 融合本体量、IMU 与接触，输出 ξ_s 及 Σ_s。**注意：自姿态的绝对基准不来自纯学习模型**——否则「用被污染的自模型去审计自模型」构成循环。

**定义 312（他者/物体姿态与可观测性 EPE）** 姿态 ξ_o ∈ SE(3)^N，协方差 Σ_o；姿态 Fisher 信息 F_o(v) 依赖视角 v = (ξ_s, 传感器外参)。可观测性指标 O(v) = det(F_o(v) + εI)（D-optimal）或 λ_min(F_o)。姿态熵 H_pose = ½ log det(2πe Σ_o)。

**定义 313（姿态闭包残差 PCN）** 对时间窗 k，预测相对变换 Δξ_pred = FK(q_{t−k:t})（自身运动）或接触模型预测（物体随动）；观测相对变换 Δξ_obs = ξ_o,t ⊖ ξ_o,t−k（EPE 给出）或回环闭合量。定义
r_kin = ‖ log(Δξ_obs⁻¹ Δξ_pred) ‖_{Σ_kin}。
三种模式：(a) 自身运动→世界变化；(b) 动作→物体姿态变化；(c) 跨视角回环闭合。r_kin ≈ 0 表示「身体与世界对账成功」。这是与被标定吸收的 r_res、与行为密度 Δa 都不同的**物理耦合残差**。

**定义 314（锚定层级与三通道仲裁 TAF）** 归一化通道向量 c = (r_res, Δa, r_kin)。决策 D ∈ {OK, sensor_fault, policy_fault, coupling_fault, self_model_fault}。规则：2-of-3 一致为「可定案」；r_kin 仅在 t_s ≥ τ_s 时拥有打破平局的投票权。给出固定映射表（见算法骨架），保证同一输入下决策确定、可审计。

**定义 315（自模型审计 SMA）** 用物理冗余检测自模型漂移：重力一致性 e_g = ‖a_IMU − R_s g_w‖；接触一致性 e_c = ‖τ − τ_kin(q,q̇,q̈) − Jᵀ F_c‖；回环漂移 e_l；负载/质心在线估计残差。t_s = 由 (e_g, e_c, e_l, 负载残差) 标定得到的可信度 ∈ [0,1]。t_s < τ_s ⇒ 自模型不可信，r_kin 降级（定义 324）。

**定义 316（姿态可观测性信息动作 AOB）** 信息动作空间扩展 g_body = (reposition, reorient, dwell) ∈ 𝒜_body（位移/朝向/停留，受 ε_g 与安全包络约束）。姿态信息增益
VoI_pose(g) = H_pose(Σ_o) − E[H_pose(Σ_o⁺)]，其中 Σ_o⁺ ≈ (F_prior + F_o(v(g)))⁻¹。
总决策 g* = argmax_g [VoI_pose(g) + VoI_mode(g) − c(g)]，s.t. EAC 可行、C-RAS-WM 认证、预算未超。D-optimal 特例：g* 使 log det(F_prior + F_o(v)) 最大。

**定义 317（姿态等变模态表示 PEM）** 模态轨迹以姿态坐标表示 ξ̄_k；要求策略近似等变：π_θ(g·ξ | g·o) = g·π_θ(ξ | o)，g ∈ SE(3)（关节空间对应重参数化）。等变残差 ε_eq = E‖π_θ(g·ξ|g·o) − g·π_θ(ξ|o)‖。聚类在归一化姿态坐标中进行，得到跨具身可比的模态权重与间距。

**定义 318（具身可行性证书 EAC）** 模态 m 可行 ⇔ 存在关节轨迹 q(t) 满足 q ∈ [q_min, q_max]、|q̇| ≤ v_max、|τ| ≤ τ_max、接触目标可达、接触稳定（CoP 落在支撑多边形内）、无自碰撞。不可行 ⇒ 剪枝并记录原因；若全部模态被剪空 ⇒ 退回 R68 保守（定义 324）。

**定义 319（非言语证据 NVE）** 言语回答 y 与人体姿态/手势 ξ_o^H 的一致性 κ(y, ξ_o^H) = P(y | ξ_o^H, context)。NVE 只有在独立性认证 indep(pose, verbal) ≥ τ_ind（非自主微动作、接触真值、时间不可控的一致性）时才计为一个正交证据源；否则与言语相关 ρ→1，不计入（定义 314 的 k-一致纪律）。

**定义 320（自模型漂移 vs 世界漂移的可辨识性）** 两个假设 H_model（自模型错）与 H_world（世界变了）产生的通道签名雅可比为 J_m、J_w。可辨识 ⇔ rank([J_m, J_w]) = dim 且两列空间不共线；等价地，存在持续激励输入（关节运动足够丰富）使联合 Fisher 信息块对角且两块正定。静态姿势、单一接触、无重力参照时二者**混叠**——这正是「锚生锈却像世界在动」的失效模式。

**定义 321（姿态攻击集 ℰ_pose）** 对抗姿态贴片、深度伪造/重放动作、遮挡与反射欺骗、姿态流形投毒、自模型投毒（篡改运动学参数）、跨通道共谋（言语与姿态一起演）。并入 AIC：ℰ_ANCHOR = ℰ_FLUID × ℰ_pose。

**定义 322（参与式审计 VQAuditor-B）** 审计锚定决策：r_kin 是否在 t_s < τ_s 时被使用、姿态证据是否被重复计数、AOB 位移是否越出安全包络、模态剪枝是否以「不可行」为名误杀可行模态。结论回灌 AuditBuf，成为 SMA 与 MINT 的先验。

**定义 323（证书 J_ANCHOR）** J_ANCHOR = (J_FLUID, r_kin_p95, self_model_trust t_s, pose_observability O, ε_eq, pose_spoof_flag, nve_independence, anchor_ver)。Valid ⇔ Valid(J_FLUID) ∧（若使用 r_kin 则 t_s ≥ τ_s）∧ 证据纪律满足 ∧ 姿态可观测性未越下界。

**定义 324（三档退避）** Tier A（锚健康：t_s ≥ τ_s 且姿态可观测且无 spoof）：完整 ANCHOR；Tier B（自模型存疑/姿态不可观测）：r_kin 降级为旁证，行为退回 FLUID；Tier C（姿态不可信/spoof 触发/所有模态不可行）：退回 R68 纯保守。λ 随档位单调不降。

# IP-264 BSP：高频本体自姿态估计（不依赖学习模型作绝对基准）
class BodyPoseEstimator:
    def step(self, q, qd, tau, imu, contact):
        self.fg.add_proprio(q, qd, tau)             # 关节/力矩因子
        self.fg.add_gravity_ref(imu, self.g_w)      # 重力方向绝对参照
        self.fg.add_zupt(qd, contact)               # 零速修正
        self.fg.add_kinematic_closure()             # 运动学闭包
        xi_s, Sigma_s = self.fg.solve()
        return xi_s, Sigma_s

# IP-265 EPE：他者/物体姿态 + 视角可观测性
def estimate_pose(o_img, v):
    xi_o, Sigma_o = pose_head(o_img)                # 复用 R68 trunk 的感知特征
    F = pose_fisher(xi_o, v)                         # 视角依赖 Fisher
    return xi_o, Sigma_o, F, observability(F)       # det / lambda_min

# IP-266 PCN：姿态闭包残差（第三条物理耦合通道）
def pose_closure(xi_s_hist, xi_o_hist, q_hist, contact_hist):
    dxi_pred = forward_kinematics(q_hist)            # 自身运动预测
    if contact_hist.any():                           # 接触随动预测
        dxi_pred = contact_model(xi_s_hist, contact_hist)
    dxi_obs = xi_o_hist[-1] @ inv(xi_o_hist[0])      # 世界相对姿态变化
    return norm_log(dxi_obs.inv() @ dxi_pred, Sigma_kin)

# IP-267 TAF：三通道 2-of-3 仲裁（r_kin 需 t_s 达标才有平局票）
def arbitrate(r_res, da, r_kin, t_s, tau_s):
    votes = [r_res > TAU_RES, da > TAU_DA,
             (r_kin > TAU_KIN) if t_s >= tau_s else None]
    if sum(v is True for v in votes) >= 2: return 'FAULT'
    if votes[0] and not votes[1]:          return 'sensor_fault'
    if votes[1] and not votes[0]:          return 'policy_fault'
    if votes[2]:                           return 'coupling_fault'
    return 'OK'

# IP-268 SMA：自模型审计（重力/接触/回环冗余）
def audit_self_model(e_g, e_c, e_l, payload_res):
    t_s = sigmoid(-(w1*e_g + w2*e_c + w3*e_l + w4*payload_res))
    return t_s                                      # < tau_s ⇒ r_kin 降级

# IP-269 AOB：姿态可观测性驱动的具身信息动作
def choose_info(gaze, probe, ask, body, Sigma_o, F_prior):
    best = None
    for g in body.candidates():                     # 凑近/侧移/绕后/换腕
        if not budget.allow(g) or not c_ras_wm.certify(g): continue
        F = pose_fisher_at(g.viewpoint())            # D-optimal
        voi = 0.5*logdet(I + Sigma_o @ F)            # 姿态熵下界
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-270/271：姿态等变模态 + 具身可行性剪枝
def admissible_modes(modes, robot):
    out = []
    for m in modes:
        if equivariance_residual(m) > TAU_EQ: continue
        if not robot.reachable(m.xi) or not robot.torque_ok(m.xi): continue
        if not robot.contact_stable(m.xi) or robot.self_collide(m.xi): continue
        out.append(m)
    return out                                     # 剪空 ⇒ 回 R68

    if t_s < TAU_S or D in ('self_model_fault', 'coupling_fault'):
        return M.fluid_round(modes, obs)                 # Tier B
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_unresolved))
    mode = select_mode(modes, U_epi, lam)
    M.vqa_b.submit_async(D, r_kin, t_s, g, mode)
    return M.pi_sigma.prefix_dispatch(mode.a) * lam, mode, D
```

## 3. 推导

**引理 19（姿态闭包的伪造成本下界）** 设攻击者只控制外感受通道，可任意伪造 ξ_o。若要让 r_res 与 r_kin 同时对账成功，伪造的相对姿态必须满足 Δξ_obs = Δξ_pred（在 Σ_kin 内），而 Δξ_pred 由本体感觉 q 决定。于是伪造者必须在 T 步内维持一条与真实运动学一致的 SE(3) 轨迹，其逐步一致性约束给出伪造代价 C_forge ≥ c₀·T·‖Δξ_pred‖ / σ_kin。对预算 B 的攻击者，检出概率 ≥ 1 − exp(−(B − c₀T)²/2σ²)。要点：**欺骗外感受不再是一封信，而是要伪造整条物理账本**——这正是 r_kin 比 r_res 更难被吸收的原因（R69 引理 17 的具身镜像）。

**引理 20（自模型漂移/世界漂移的可辨识性）** 记两假设下的通道签名为 μ_m(θ), μ_w(ζ)，雅可比 J_m, J_w。当联合 Fisher 信息 I = diag(I_m, I_w) 且 I_m ≻ 0, I_w ≻ 0 时，两假设可分离；充分条件为持续激励：关节轨迹覆盖足够多方向、存在重力绝对参照、至少一次接触事件。反之，若激励不足（静止站立、单点接触、IMU 饱和），存在非零 (δθ, δζ) 使 J_m δθ = J_w δζ，两假设**观测等价**——「锚生锈」与「世界在动」在数据上不可分。系：AOB 不仅要「移动去看」，还要「**动一动以自检**」；纯视角变化不激发运动学参数。

**引理 21（姿态可观测性的 D-optimal 下界）** 由 Loewner 序，期望后验协方差满足 Σ_o⁺ ⪰ (F_prior + E_v[F_o(v)])⁻¹。选 v* 最大化 log det F_o(v)（D-optimal）使期望姿态熵的上界最小，可实现的熵降 ΔH_pose ≥ ½ log det(I + Σ_prior F_o(v*))。系：这是 R69 引理 16 在姿态空间的镜像——「移动去看」的价值非负、可在动作前计算，且与「问一句」进入同一 VoI 目标。

**引理 22（姿态等变 → 模态权重稳定与跨具身可比）** 若策略 ε_eq-等变、聚类在归一化姿态坐标进行，则视角变换 g 下原型 ξ̄_k → g·ξ̄_k，模态权重满足 |ŵ_k(g·o) − ŵ_k(o)| ≤ L_w·ε_eq。故视角变化导致的伪模态分裂/合并被 ε_eq 控制；R69 的模态幻觉风险下降，且不同具身共享模态结构，迁移误差由 ε_eq 与运动学差距共同界定。

**引理 23（非言语证据的独立性塌缩）** NVE 增加的有效信息为 I(M; ξ_o^H | y, o) − I(M; y | o)；当姿态与言语共谋（ρ→1）时该项 ≤ 0，等价于 R69 引理 18 的单源情形。故 NVE 只有在独立性认证通过时才计为第 k 个正交源；否则「身体配合撒谎」会让 k-一致纪律的收益归零。

**定理 18（ANCHOR 严格嵌套 FLUID/R68）** 在 A99–A102（SMA 审计可靠、姿态可观测性有下界、闭包一致性成立）下，ANCHOR 任意状态期望风险 ≤ FLUID ≤ CALM；且当 t_s < τ_s、spoof 触发、所有模态不可行、或 VoI−c ≤ 0 时，ANCHOR 逐指令退化为 FLUID（Tier B）或 R68（Tier C）。安全侧单调不弱；效率增益只来自三处：故障隔离更准、姿态空间消歧更稳、主动可观测性更值钱。

**定理 19（具身可行性剪枝保安全、无突变）** 被剪枝的模态按定义不可被 C-RAS-WM 认证（不可达/超力矩/接触不稳/自碰撞），故剪枝不增加执行风险；若剪枝清空模态集，管线退回 R68 保守 λ，且 λ 单调不降，提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。代价是可能过度保守——由 E307 度量剪枝的假阳性。

## 6. 本轮最大风险

**一句话**：ANCHOR-RAS 把可信性押在「身体锚不可伪造」上，可 **r_kin 是自指的**——预测与观测最终都经过同一个身体/同一套运动学模型，锚一旦锈蚀（编码器老化、负载变化、运动学失配），系统会得到一条内部自洽、全局错误的证据链，反而**自信地拒绝真实的世界观测**；R69 怕的是「信了外部的骗子」，R70 的危险是「信了自己的回声」——**以己为锚，锚若锈蚀，则举世皆成幻象**。

**次级风险与缓解**：
1. **自模型-世界漂移混叠**（静止/单接触时不可辨识）→ 定义 320 可辨识性判据 + SMA + AOB 的「动一动自检」激励；不可辨识时诚实降级；
2. **绝对参考本身被污染**（IMU 偏置、接触模型错误）→ 多绝对参考交叉（重力/接触/回环/第二具身）+ 引理 19 的伪造成本；
3. **姿态估计歧义与自遮挡** → 定义 316 D-optimal 主动视角 + 协方差驱动的保守退避；
4. **姿态欺骗/深度伪造/重放** → ℰ_pose 对抗训练 + 独立性认证 + 定理 18 的 Tier C 退避；

6. **过度保守（剪枝误杀/噪声误报）** → E307/E309 度量假阳性，剪枝/降级需审计留痕（VQAuditor-B）。

class BodyPoseEstimator:
    def step(self, q, qd, tau, imu, contact):
        self.fg.add_proprio(q, qd, tau)
        self.fg.add_gravity_ref(imu, self.g_w)       # 重力绝对参照

def choose_info(body, Sigma_o, F_prior):
    best = None
    for g in body.candidates():                       # 凑近/侧移/绕后/换腕
        if not budget.allow(g) or not c_ras_wm.certify(g): continue
        F = pose_fisher_at(g.viewpoint())
        voi = 0.5 * logdet(I + Sigma_o @ F)           # 姿态熵下界
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-271 EAC：具身可行性剪枝（拦截幻觉但不可行的模态）
def admissible_modes(modes, robot):
    return [m for m in modes
            if equivariance_residual(m.xi) <= TAU_EQ
            and robot.reachable(m.xi) and robot.torque_ok(m.xi)
            and robot.contact_stable(m.xi) and not robot.self_collide(m.xi)]

# IP-275 ANCHOR 主闭环
def ANCHOR_round(M, obs):
    xi_s, _ = M.bsp.step(...); xi_o, S_o, F, O = M.epe.estimate_pose(obs)
    r_kin = M.pcn.pose_closure(xi_s, xi_o, q_hist, contact_hist)
    t_s   = M.sma.audit_self_model(...)
    D     = M.taf.arbitrate(M.last_r_res, M.last_da, r_kin, t_s, TAU_S)
    if D == 'self_model_fault': t_s = min(t_s, TAU_S)
    modes = admissible_modes(M.fmp.sample(obs, K), M.robot)
    if not modes: return M.r68_conservative(...)            # Tier C
    g = M.aob.choose_info(M.body, S_o, F) if (t_s >= TAU_S and D == 'OK') else None
    if g is not None: modes = M.cia.update_belief(modes, M.cia.execute(g))
    if t_s < TAU_S or D in ('self_model_fault', 'coupling_fault'):
        return M.fluid_round(modes, obs)                     # Tier B
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_unresolved))
    return M.pi_sigma.prefix_dispatch(select_mode(modes, U_epi, lam).a) * lam
```

## 4. 推导

**引理 19（姿态闭包的伪造成本下界）** 只控外感受的伪造者若要让 `r_res` 与 `r_kin` 同时对账，必须维持与真实运动学一致的 SE(3) 轨迹，代价 `C_forge ≥ c₀·T·‖Δξ_pred‖/σ_kin`；预算 B 下检出率 `≥ 1−exp(−(B−c₀T)²/2σ²)`。欺骗外感受从「伪造一封信」升级为「伪造整条物理账本」，故 r_kin 不被标定吸收（R69 引理 17 的具身镜像）。

**引理 20（自模型/世界漂移可辨识性）** 两假设签名雅可比 `J_m,J_w`；联合 Fisher 块对角正定时可分离，充分条件为持续关节激励 + 重力绝对参照 + 至少一次接触。激励不足（静止、单接触、IMU 饱和）时存在非零 `(δθ,δζ)` 使 `J_mδθ=J_wδζ`，观测等价。系：AOB 必须包含「动一动自检」，纯视角变化不激发运动学参数。

**引理 21（D-optimal 姿态可观测性下界）** `Σ_o⁺ ⪰ (F_prior+E_v[F_o(v)])⁻¹`；D-optimal 视角最小化期望姿态熵上界，可达熵降 `ΔH_pose ≥ ½logdet(I+Σ_priorF_o(v*))`。「移动去看」的 VoI 非负、可预算，与「问一句」同一目标（R69 引理 16 镜像）。

**引理 22（姿态等变稳定性）** ε_eq-等变且归一化姿态聚类下，`|ŵ_k(g·o)−ŵ_k(o)| ≤ L_w·ε_eq`；伪模态分裂/合并被 ε_eq 控制，并支持跨具身迁移（误差由 ε_eq 与运动学差距界定）。

**引理 23（NVE 独立性塌缩）** NVE 净信息 `I(M;ξ_o^H|y,o)−I(M;y|o) ≤ 0` 当姿态与言语共谋（ρ→1），退化为 R69 单源上界；故须独立性认证后才计为第 k 个正交源。

**定理 18（ANCHOR 严格嵌套 FLUID/R68）** A99–A102 下，ANCHOR 期望风险 ≤ FLUID ≤ CALM；当 `t_s<τ_s`、spoof、模态全不可行或 `VoI−c≤0` 时逐指令退化为 FLUID（Tier B）/R68（Tier C）。安全单调不弱，效率增益仅来自故障隔离、姿态消歧、主动可观测性。

**定理 19（EAC 剪枝保安全、无突变）** 被剪模态按定义不可被 C-RAS-WM 认证；剪枝不增风险，剪空则回 R68 保守，λ 单调不降，提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变；代价是过度保守，由 E307 度量假阳性。

## 7. 本轮最大风险

**一句话**：ANCHOR-RAS 把可信性押在「身体锚不可伪造」上，但 **r_kin 是自指的**——预测与观测最终都经过同一个身体和同一套运动学模型；锚一旦锈蚀（编码器老化、负载变化、运动学失配），系统会得到内部自洽、全局错误的证据链，反而**自信地拒绝真实的世界观测**；R69 怕「信了外部的骗子」，R70 的危险是「信了自己的回声」——**以己为锚，锚若锈蚀，则举世皆成幻象**。

**次级风险与缓解**：自模型-世界漂移混叠（定义 320 可辨识性 + SMA + 「动一动自检」激励，不可辨识时诚实降级）；绝对参考被污染（多绝对参考交叉 + 引理 19 伪造成本）；姿态歧义与自遮挡（D-optimal 主动视角 + 协方差保守退避）；姿态欺骗/深度伪造（ℰ_pose 对抗训练 + 独立性认证 + Tier C）；实时预算被姿态估计击穿（频率解耦 + E311）；过度保守（E307/E309 度量假阳性 + VQAuditor-B 留痕）。
