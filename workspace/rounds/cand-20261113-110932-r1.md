# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 1 轮；本轮灵感：「轻量化设计」×「视觉编码器」）

> 第 66 轮 RAS 在实时性一节留下了一个被轻描淡写的脚注：面部 ROI + 情绪分类在嵌入式平台是瓶颈，建议「事件相机 + MobileNetV3-Quant」。本轮把这个脚注当作主问题。但直接把 VISTA/RAS 的视觉编码器换成一个通用轻量骨干，是**危险的**：VISTA 的故障签名 ρ 与 RAS 的情绪风险 `R_emotion` 都建立在编码器特征几何之上，按 FLOPs / ImageNet 精度选型的通用压缩，很可能恰好抹掉「低能量、但决定归因」的残差方向——于是系统在基准集上更轻、更快、更准，却在真正需要它的故障时刻失去可辨识性。
>
> 本轮核心命题：
>
> **把「轻量化」从「模型压缩指标（Params / FLOPs / ImageNet Acc）」重新定义为「安全相关子空间上的可容许降维」：轻量化不是删参数，而是删「对控制决策不可辨识的信息」；压缩后的编码器必须在故障归因子空间与情绪风险序上被证明与原编码器等价到 ε，并且在分布漂移时必须失效安全（fail-closed），而不是悄悄放行。**
>
> 由此得到 **LENS：Lightweight ENcoder with Safety-preservation（面向安全证书的轻量视觉编码器）**。它不是一个新的骨干网络，而是一套把「压缩」纳入 VISTA/RAS 认证闭环的机制：属性子空间蒸馏（ASD）× 敏感度感知滤波（SAF）× 单调风险校准（MCM）× 风险自适应算力（RAC）× 零空间探针（NSP）× 编码器证书（CEC）。

## 0. 直觉与动机

**灵感 1（视觉编码器是决策的前置算子，不是分类器）**
直觉：在 VISTA/RAS 里，视觉编码器 `E: x → z` 的输出会分叉成两条下游链：
- `z → ρ 签名 → 故障后验 P(H|ρ) → 认证前缀 k*`；
- `z → face 特征 → π 情绪分布 → R_emotion → λ_risk`。
所以编码器的评价标准不是「`z` 能否重建图像 / 能否分类」，而是「**`z` 的扰动会不会改变 ρ 的序与 λ 的序**」。一个把 ImageNet top-1 提高 1% 的压缩，可能在 ρ 的 32 维签名上把两个故障假设推成同一类。轻量化的第一性原理应由这两个下游算子定义，而不是由参数量定义。

**灵感 2（轻量化设计 = 按决策敏感度分配比特，而不是按参数多少分配）**
直觉：不同通道对 ρ 与 R_emotion 的敏感度差好几个数量级。大量通道只贡献纹理与外观冗余（对故障归因近似处于零空间），少数通道承载几何残差、面部关键点位移与风险姿态。因此最优的轻量化不是「全局均匀剪 50%」，而是**把高精度（int8/fp16）留给安全子空间，把低精度（int4/二值）甚至整条剪掉留给零空间**。这与传统剪枝「按权重范数」相反：范数大的通道未必对决策重要，范数小的通道可能恰好是故障残差的放大器。

**灵感 3（视觉编码器 anytime 化 → 算力成为闭环控制变量）**
直觉：第 66 轮的 RAS 已经有一个现成的高质量风险信号 `λ_risk(t)`。若把编码器设计成**可分组的 anytime 编码器**（channel groups `G_1 ⊂ G_2 ⊂ … ⊂ G_max`），那么 λ_risk 就能在运行时直接决定「这一帧看多细」：
- λ_risk 低（使用者紧张/故障疑似）→ 激活更多组，牺牲延迟换可辨识性；
- λ_risk 高（一切正常）→ 只用前一两组，把 2ms 预算留给控制。
这一步的意义是**范式性的**：轻量化不再是部署前的一次性静态折衷，而是和力限、几何球一样，成为闭环里被调度、被认证、被追溯的控制变量。我们把它称为**风险自适应算力（RAC）**。

**灵感 4（零空间：免费压缩的真正来源）**
直觉：设归因映射的雅可比 `J_H = ∂ρ/∂z`。若存在方向 `v` 使 `J_H v ≈ 0`，则沿 `v` 压缩对一阶归因误差**免费**。把所有这样的方向张成 `N_S`（安全零空间），轻量化的可证边界就是「只删 `N_S` 内的分量」。这把「压缩到什么程度」从一个经验超参变成一个**可计算的几何量**：可容许压缩率 ≈ `dim(N_S) / dim(z)`（在给定 ε 下的局部近似）。同时也给出一个悲观但重要的推论：**轻量化存在一个由安全相关信息量决定的地板**，压到地板以下必然破坏证书（定理 14）。

**灵感 5（压缩必须 fail-closed，不能 fail-open）**
直觉：任何离线估计的零空间都只在标定分布上成立。新光照、口罩/遮挡、不同肤色与年龄、对抗性的假笑，都可能让「被剪掉的方向」突然变得重要。此时若仍用压缩特征，RAS 会把「无法观测」误当成「情绪安全」，从而**放宽容差**——这是比第 66 轮更隐蔽的失效。因此 LENS 必须内置一个极廉价的**零空间探针（NSP）**：当输入离开标定流形、或安全子空间能量占比异常升高时，立刻升级算力 / 回退大编码器 / 置 `face_unobservable`，并让证书失效。原则一句话：**压缩只能在被证明安全时生效，一旦可疑就退回未压缩基线，绝不 silently permissive。**

## 1. 形式化定义（增量：定义 245–258）

- **定义 245（LENS 总览）**：`LENS = (ASD, SAF, MCM, RAC, NSP, CEC)`，定位为 VISTA/RAS 的「感知前端轻量化层」。不变式：(i) ASD/SAF/MCM 只在语义流离线进行；(ii) 实时流只做分组选择、查表校准、探针打分，零学习写操作；(iii) 所有回退都是 fail-closed（只会收紧 λ_risk，绝不放松）。
- **定义 246（安全相关信息量）**：对编码器 `E`，`z = E(x)`，定义安全相关向量 `I_S(z) = (I(z; H), I(z; E))`，其中 `H` 为故障假设、`E` 为情绪假设。称 `E_lite` 相对 `E_big` 是 `(δ_H, δ_E)`-信息可容许的，当且仅当
  `I(z_lite; H) ≥ I(z_big; H) − δ_H` 且 `I(z_lite; E) ≥ I(z_big; E) − δ_E`。
  （实操中用 Fisher 信息 / HSIC 作为互信息的可计算代理。）
- **定义 247（归因敏感度度量）**：令 `J_H(z) = ∂ρ/∂z`、`J_E(z) = ∂R_emotion/∂z`。定义安全敏感度矩阵
  `G_S(z) = J_Hᵀ Σ_ρ⁻¹ J_H + β J_Eᵀ Σ_E⁻¹ J_E`，
  其中 `Σ_ρ, Σ_E` 为签名与风险观测噪声协方差，`β` 为风险项权重。
- **定义 248（安全零空间）**：`N_S(z) = { v ∈ ℝ^{d_z} : vᵀ G_S(z) v ≤ ε₀ }`。`N_S` 内的方向在一阶意义上不改变故障归因与情绪风险；`N_S` 的正交补 `S_S = N_S^⊥` 称为安全子空间。
- **定义 249（ε-可容许压缩）**：`E_lite` 相对 `E_big` 是 ε-可容许的，当且仅当在标定支撑集上
  1. `d_H := E_x‖J_H(z)(z_lite − z_big)‖ ≤ ε_H`；
  2. `d_E := E_x |R_emotion^lite − R_emotion^big| ≤ ε_E`；
  3. （风险序保持）对任意 `|R_a − R_b| > 2ε_E` 的两点，`sign(g(R_a) − g(R_b)) = sign(R_a − R_b)`，其中 `g` 为定义 252 的校准映射。
- **定义 250（ASD，属性子空间蒸馏）**：学生编码器 `E_s` 的损失为
  `L_ASD = ‖P_S(E_s(x)) − P_S(E_big(x))‖² + λ_rank·L_rank(R_emotion) + λ_KD·KL(P(H|ρ_s) ‖ P(H|ρ_b))`，
  其中 `P_S` 为到安全子空间 `S_S` 的投影。关键点：**只蒸馏 `P_S z`，不蒸馏完整特征**——零空间分量允许不同。
- **定义 251（SAF，敏感度感知滤波）**：对第 `c` 个通道/头，定义重要度 `w_c = tr(W_cᵀ G_S W_c)`。剪枝集合 `{c : w_c < τ_w ∧ ‖W_c‖_F < τ_norm}`（保底保留 `d_min` 个安全通道）；混合精度 `p_c ∈ {4, 8, 16}` 由 `w_c` 的分位阈值决定：`w_c` 越高，位宽越高。
- **定义 252（MCM，单调风险校准）**：标定一个非降分段线性映射 `g: ℝ → ℝ`，使 `g(R_emotion^lite) ≈ R_emotion^big`，并强制 `g'(r) ≥ 0`、`|g(r) − r| ≤ ε_E`（在标定支撑集内）。`g` 只改数值刻度，不改风险序。
- **定义 253（RAC，风险自适应算力）**：设 anytime 编码器的通道组为 `G_1 ⊂ … ⊂ G_max`，延迟 `τ(g)` 单调增。运行时选择
  `g_t = clamp( g_min + ⌊(g_max − g_min)·clip(1 − λ_risk(t), 0, 1)⌋ + ⌈u_t/Δu⌉ , g_min, g_max )`，
  其中 `u_t` 为归因不确定性（如后验熵）。约束 `τ(g_t) ≤ τ_max`；单调性要求：`λ_risk` 越小（越危险）→ `g_t` 越大（看得越细）。
- **定义 254（NSP，零空间探针）**：定义廉价统计量
  `s_nsp(x) = E_NSP(z) / E_S(z)`（零空间能量 / 安全子空间能量，或到标定流形的马氏距离）。
  若 `s_nsp(x) > τ_nsp`，判定「压缩假设不可靠」。
- **定义 255（失效安全回退）**：若 `s_nsp > τ_nsp` 或 `g_t < g_min(λ_risk)`，则执行优先序为：(a) 升到 `g_max` 重算；(b) 若仍不达标，回退 `E_big`；(c) 仍不可观测则置 `face_unobservable = True`、`λ_risk ← max(λ_risk, 0.8)`。禁止在回退期间提高 λ_risk 或降低认证前缀的保守度。
- **定义 256（CEC，编码器证书）**：
  `J_LENS = (J_RAS, enc_version, r_comp, ε_H, ε_E, g_t, s_nsp, mcm_version)`。
  `Valid(J_LENS) ⇔ Valid(J_RAS) ∧ s_nsp ≤ τ_nsp ∧ ε_H ≤ ε_H^max ∧ ε_E ≤ ε_E^max ∧ τ(g_t) ≤ τ_max`。
- **定义 257（LENS 认证前缀）**：`k*_LENS = min(k*_RAS, k_ε)`，其中 `k_ε` 是满足「对所有 `s ≤ k`，膨胀后安全裕度 `margin_s − L_ρ·ε_H ≥ 0`」的最大整数，`L_ρ` 为签名映射的 Lipschitz 常数。
- **定义 258（风险-算力对偶）**：给定延迟预算 `B`，RAC 求解 `min_g E[R(g)] s.t. E[τ(g)] ≤ B`。若各组带来的风险下降 `ΔR_g` 对 `g` 边际递减，则按 `ΔR_g / Δτ_g` 从大到小激活通道组（水注式分配）；这是把「算力」当作与「力限」同构的可分配安全资源。

## 2. 关键算法骨架

```python
# ASD + SAF：离线压缩（语义流，一次性）
def compress_with_safety(E_big, calib_loader, beta=0.5, eps_H=0.02, eps_E=0.02):
    J_H, J_E = estimate_jacobians(E_big, calib_loader)     # ∂ρ/∂z, ∂R_emotion/∂z
    G_S = J_H.T @ inv(Sigma_rho) @ J_H + beta * J_E.T @ inv(Sigma_E) @ J_E
    P_S = projector_onto_safety_subspace(G_S)              # 定义 248
    E_s = distill(E_big, P_S, loss=L_ASD, ...)             # 定义 250
    w = {c: trace(W_c.T @ G_S @ W_c) for c in E_s.channels}  # 定义 251
    E_lite = prune_and_quantize(E_s, w, keep_min=d_min)
    g = fit_monotone_map(E_lite, E_big, calib_loader)      # 定义 252
    return E_lite, g, (eps_H, eps_E, G_S)


# RAC + NSP + CEC：运行时（实时流，零学习写）
class LensRuntime:
    def __init__(self, E_lite, g_map, G_max, tau_max, tau_nsp):
        self.E, self.g, self.G_max = E_lite, g_map, G_max
        self.tau_max, self.tau_nsp = tau_max, tau_nsp

    def select_groups(self, lambda_risk, entropy):
        span = self.G_max - self.G_min
        base = self.G_min + int(span * clip(1 - lambda_risk, 0, 1))
        extra = int(ceil(entropy / self.delta_u))
        return clip(base + extra, self.G_min, self.G_max)

    def encode(self, x, lambda_risk, entropy):
        g_t = self.select_groups(lambda_risk, entropy)
        z, e_nsp, e_safe = self.E.forward(x, upto=g_t)
        s_nsp = e_nsp / (e_safe + 1e-6)                    # 定义 254
        if s_nsp > self.tau_nsp:                           # 定义 255：fail-closed
            z, e_nsp, e_safe = self.E.forward(x, upto=self.G_max)
            s_nsp = e_nsp / (e_safe + 1e-6)
            if s_nsp > self.tau_nsp:
                return None, s_nsp, g_t                    # 触发回退/face_unobservable
        R_lite = self.E.risk_head(z)
        return self.g(R_lite), s_nsp, g_t                  # MCM 校准后的风险


# 与 RAS 闭环的耦合：算力由 λ_risk 驱动，风险由压缩特征驱动
def LENS_RAS_round(M, obs):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) 先用上一拍的风险做 RAC 预调度（warm start）
    g_t = M.lens.select_groups(M.last_lambda_risk, M.last_entropy)

    # 2) 轻量视觉前端（带 fail-closed 探针）
    r_hat, s_nsp, g_t = M.lens.encode(img, M.last_lambda_risk, M.last_entropy)
    if r_hat is None:                       # 不可靠 → 回退大编码器
        r_hat, s_nsp = M.lens.full_encoder_risk(img)
        M.fallback_flag = True
    # 3) 情绪网关使用校准后的风险
    face_gate = M.er.gateway.recognize(img, risk_override=r_hat)
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post, _ = M.efs.synthesize(rho, face_gate)

    # 4) CEC：证书在压缩有效时才允许放宽
    eps_H, eps_E = M.lens.eps
    k_ras = M.csc_ras.certified_prefix_ras(A, joint_post, M.m_ras, M.alpha_chunk)
    k_lens = M.csc_ras.certified_prefix_lens(A, joint_post, k_ras, eps_H)
    lam = M.efs.risk_scale(joint_post)
    J = build_cert(J_ras=M.vista.J, enc=M.lens.version, r_comp=M.lens.r_comp,
                   eps_H=eps_H, eps_E=eps_E, g_t=g_t, s_nsp=s_nsp, valid_ras=True)
    if not valid(J):                        # 定义 256
        k_lens, lam = conservative_fallback(k_ras, lam)   # 只收紧，不放松
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_lens]) * lam
    M.last_lambda_risk, M.last_entropy = lam, entropy(joint_post)
    return k_lens, lam, joint_post, face_gate, J
```

## 3. 推导

**引理 11（决策空间压缩误差传播）** 设签名映射 `ρ(z)` 关于 `G_S` 度量是 `L_ρ`-Lipschitz 的，风险映射是 `L_E`-Lipschitz 的，则
`‖ρ_lite − ρ_big‖ ≤ L_ρ·d_H`，`|R_lite − R_big| ≤ L_E·d_E`；
且故障后验的全变差距离满足 `TV(P(H|ρ_lite), P(H|ρ_big)) ≤ ½·L_ρ·d_H / σ_min(Σ_ρ)`。
*证明*：中值定理 + `d_H` 的定义 249(1) + Pinsker 不等式；`Σ_ρ` 的最小奇异值给出贝叶斯后验的 Lipschitz 下界。

**引理 12（MCM 保持风险序）** 若 `g` 非降且 `|g(r) − r| ≤ ε_E`，则对任意满足 `R_a − R_b > 2ε_E` 的两点，有 `g(R_a) > g(R_b)`。因此 λ_risk 的偏序与 C-RAS 认证前缀关于风险单调性保持不变。
*证明*：`g(R_a) ≥ R_a − ε_E > R_b + ε_E ≥ g(R_b)`。这说明校准只平移刻度，不会把「高风险」翻成「低风险」，是 fail-closed 的代数基础。

**引理 13（RAC 的单调性与近最优性）** 若通道组嵌套（`G_1 ⊂ G_2 ⊂ …`）且不确定性 `U(g)` 关于 `g` 非增，则 `g_t(λ)` 关于 `λ_risk` 非增（风险越低、算力越高）。进一步，若各组风险下降 `ΔR_g` 边际递减，则按 `ΔR_g/Δτ_g` 贪心激活在延迟预算 `B` 下是风险最小化的最优（凸情形）/ `(1−1/e)` 近似（子模情形）。
*证明*：单调性由定义 253 的 clip 结构直接得到；最优性来自带线性约束的可分凸规划 KKT 条件 / 子模最大化的经典贪心界。

**定理 11（LENS 端到端安全保持）** 在定义 249 的 ε-可容许性与定义 252 的单调校准下，RAS 定理 9 的三条结论以膨胀项成立：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + L_τ·L_E·ε_E`；
2. 实际执行风险 `≤ 设定上限 × (1.2 + L_E·ε_E)`；
3. `k*_LENS ≥ k*_RAS − ⌈L_ρ·ε_H / m_min⌉`，其中 `m_min` 为最小安全裕度步长。
*证明思路*：三角不等式拆出「原 RAS 误差 + 压缩引入误差」，前者由定理 9 界定，后者由引理 11/12 界定；认证前缀的损失由每次签名偏移消耗的最大裕度步长折算。

**定理 12（失效安全：压缩不会悄悄放松约束）** 若 `τ_nsp` 取标定集上 `s_nsp` 的 `(1−α)` 分位数，则只要 `Valid(J_LENS)` 成立，压缩路径的风险相对未压缩基线的增量以 `ε_E` 为界（概率 `≥ 1−α`）；当真实压缩误差超过 `ε_E^max` 时，NSP 以概率 `≥ 1−β` 触发并回退，使系统恢复到未压缩基线。特别地，**不存在**「压缩导致 λ_risk 反而升高（放宽）」的可证书路径。
*证明思路*：由探针的分位数构造得到误报/漏报界；再由定义 255 的回退只单调收紧 λ_risk、以及引理 12 的序保持，排除 fail-open 分支。

**定理 13（RAC 的近最优算力分配）** 在引理 13 的条件下，RAC 的贪心调度在预算 `B` 下达到最优期望风险的 `(1−1/e)` 因子近似，且最坏尾延迟不超过 `G_max·τ_unit`。
*证明*：风险下降函数在嵌套组上子模；贪心近似界 + 延迟上界由单组延迟的单调可加性给出。

**定理 14（安全信息率下界）** 对任意满足 `(δ_H, δ_E)`-信息可容许的编码器，其表示所需比特数满足 `B(z) ≥ I(z_big; H) − δ_H + β(I(z_big; E) − δ_E)`（在标准率-失真与数据处理不等式下）。因此轻量化存在由安全相关信息量决定的**地板**：任何低于该地板的压缩必然破坏证书。
*证明思路*：数据处理不等式 `I(z_lite; H) ≤ min(I(z_big; H), B(z))`，对两项加权求和即得。该定理把「压缩率」从工程超参上升为受信息论约束的物理量。

**定义 245（LENS 总览）**
```

```
不变式：(i) ASD/SAF/MCM 只在语义流离线进行；(ii) 实时流只做分组选择、查表校准、探针打分，零学习写操作；(iii) 所有回退 fail-closed（只收紧 `λ_risk`，绝不放松）。

**定义 246（安全相关信息量）** 对 `z = E(x)`：
```
I_S(z) = ( I(z; H), I(z; E) )
```
`E_lite` 是 `(δ_H, δ_E)`-信息可容许的 ⇔
```
I(z_lite; H) ≥ I(z_big; H) − δ_H  ∧  I(z_lite; E) ≥ I(z_big; E) − δ_E
```
实操代理：Fisher 信息 / HSIC / 后验 KL。

**定义 247（归因敏感度度量）**
```
J_H(z) = ∂ρ/∂z,   J_E(z) = ∂R_emotion/∂z
G_S(z) = J_Hᵀ Σ_ρ⁻¹ J_H + β J_Eᵀ Σ_E⁻¹ J_E
```

**定义 248（安全零空间）**
```
N_S(z) = { v ∈ ℝ^{d_z} : vᵀ G_S(z) v ≤ ε₀ },   S_S = N_S^⊥
```
沿 `N_S` 的压缩在一阶意义上不改变故障归因与情绪风险。

**定义 249（ε-可容许压缩）** `E_lite` 相对 `E_big` 满足：
```
1. d_H = E_x ‖ J_H(z)(z_lite − z_big) ‖ ≤ ε_H
2. d_E = E_x | R_emotion^lite − R_emotion^big | ≤ ε_E
3. 风险序保持：|R_a − R_b| > 2ε_E ⇒ sign(g(R_a) − g(R_b)) = sign(R_a − R_b)
```

**定义 250（ASD 属性子空间蒸馏）**
```
L_ASD = ‖P_S(E_s(x)) − P_S(E_big(x))‖²
        + λ_rank · L_rank(R_emotion)
        + λ_KD · KL( P(H|ρ_s) ‖ P(H|ρ_b) )
```

只蒸馏 `P_S z`；零空间分量不设约束。

```
prune: { c : w_c < τ_w ∧ ‖W_c‖_F < τ_norm },  保留 ≥ d_min 个安全通道
precision: p_c ∈ {4,8,16}, 由 w_c 分位阈值决定（w_c ↑ ⇒ 位宽 ↑）
```

**定义 252（MCM 单调风险校准）**

```
g: ℝ → ℝ 非降分段线性,  g'(r) ≥ 0,  |g(r) − r| ≤ ε_E  (标定支撑集内)
```

```
(b) 仍不达标 → 回退 E_big
```

```python
def compress_with_safety(E_big, calib_loader, beta=0.5,
                         eps_H=0.02, eps_E=0.02, d_min=16):
    J_H = estimate_jacobian(E_big, 'fault_signature', calib_loader)
    J_E = estimate_jacobian(E_big, 'emotion_risk', calib_loader)
    G_S = J_H.T @ inv(Sigma_rho) @ J_H + beta * J_E.T @ inv(Sigma_E) @ J_E
    P_S = projector_onto_complement_of_nullspace(G_S, eps0=1e-4)

    E_s = distill(E_big, target_proj=P_S, loss='L_ASD',
                  lam_rank=0.5, lam_kd=0.5, loader=calib_loader)

    w = {c: trace(W_c.T @ G_S @ W_c) for c, W_c in E_s.named_channels()}
    keep = select_keep_channels(w, tau_w=quantile(w, 0.3),
                                tau_norm=1e-3, min_count=d_min)
    E_lite = prune_and_quantize(E_s, keep=keep, bitwidth_from=w)

    g = fit_isotonic_map(src=E_lite.risk_head, dst=E_big.risk_head,
                         loader=calib_loader, eps_E=eps_E)
    eps_H = validate_admissibility(E_lite, E_big, calib_loader)['d_H']
    return {'E': E_lite, 'g': g, 'eps_H': eps_H, 'eps_E': eps_E,
            'P_S': P_S, 'G_S': G_S, 'r_comp': bitratio(E_lite, E_big)}

class LensRuntime:
    def __init__(self, bundle, G_min=1, G_max=4, tau_max=2.0,
                 tau_nsp=0.18, delta_u=0.1):
        self.E, self.g_map = bundle['E'], bundle['g']
        self.G_min, self.G_max = G_min, G_max
        self.tau_max, self.tau_nsp, self.delta_u = tau_max, tau_nsp, delta_u
        self.version, self.r_comp = bundle.get('version'), bundle['r_comp']
        self.eps = (bundle['eps_H'], bundle['eps_E'])

    def select_groups(self, lambda_risk, entropy):
        span = self.G_max - self.G_min
        base = self.G_min + int(span * clip(1.0 - lambda_risk, 0.0, 1.0))
        extra = int(ceil(entropy / self.delta_u))
        g = clip(base + extra, self.G_min, self.G_max)
        while g > self.G_min and self.latency(g) > self.tau_max:
            g -= 1
        return g

    def latency(self, g):
        return self.E.latency_lut[g]

    def encode(self, x, lambda_risk, entropy):
        g_t = self.select_groups(lambda_risk, entropy)
        z, e_nsp, e_safe = self.E.forward(x, upto=g_t)
        s = e_nsp / (e_safe + 1e-6)
        if s <= self.tau_nsp:
            return self.g_map(self.E.risk_head(z)), s, g_t, 'LITE'
        # fail-closed 升级
        z, e_nsp, e_safe = self.E.forward(x, upto=self.G_max)
        s = e_nsp / (e_safe + 1e-6)
        if s <= self.tau_nsp:
            return self.g_map(self.E.risk_head(z)), s, self.G_max, 'ESCALATE'
        return None, s, self.G_max, 'FALLBACK_BIG'
```

## 4. 推导

**引理 11（决策空间压缩误差传播）** 设 `ρ(·)`、`R_emotion(·)` 关于 `G_S` 度量分别 `L_ρ`、`L_E`-Lipschitz，则
```
‖ρ_lite − ρ_big‖ ≤ L_ρ·d_H,   |R_lite − R_big| ≤ L_E·d_E
TV(P(H|ρ_lite), P(H|ρ_big)) ≤ ½·L_ρ·d_H / σ_min(Σ_ρ)
```
*证明*：中值定理 + 定义 249 + Pinsker 不等式。

**引理 12（MCM 保持风险序）** `g` 非降且 `|g(r)−r|≤ε_E` ⇒ 对 `R_a−R_b > 2ε_E` 有 `g(R_a) > g(R_b)`。
*证明*：`g(R_a) ≥ R_a−ε_E > R_b+ε_E ≥ g(R_b)`。故 λ_risk 偏序与 C-RAS 前缀单调性不变。

**引理 13（RAC 单调性与近最优）** 通道组嵌套 + `U(g)` 非增 ⇒ `g_t(λ_risk)` 非增。若 `ΔR_g` 边际递减，贪心按 `ΔR_g/Δτ_g` 在预算 `B` 下最优（凸）/ `(1−1/e)` 近似（子模）。
*证明*：KKT / 子模贪心界。

**定理 11（LENS 端到端安全保持）** 在 ε-可容许性与单调校准下，RAS 定理 9 变为：
```
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + L_τ·L_E·ε_E
2. 实际执行风险 ≤ 设定上限 × (1.2 + L_E·ε_E)
3. k*_LENS ≥ k*_RAS − ⌈L_ρ·ε_H / m_min⌉
```
*证明思路*：三角不等式拆为「原 RAS 误差 + 压缩误差」，分别用定理 9 与引理 11/12 界定。

**定理 12（失效安全）** `τ_nsp` 取标定集 `s_nsp` 的 `(1−α)` 分位数。只要 `Valid(J_LENS)` 成立，压缩路径风险增量以 `ε_E` 为界（概率 `≥1−α`）；真实误差超 `ε_E^max` 时 NSP 以概率 `≥1−β` 触发并回退到未压缩基线。**不存在「压缩导致 λ_risk 升高（放宽）」的可证书路径。**
*证明思路*：分位数探针的误报/漏报界 + 定义 255 只收紧 + 引理 12 序保持。

**定理 13（RAC 近最优算力分配）** 在上述条件下，贪心调度在预算 `B` 下达到最优期望风险的 `(1−1/e)` 近似，尾延迟 `≤ G_max·τ_unit`。
*证明*：风险下降函数在嵌套组上子模；贪心近似界 + 延迟单调可加。

**定理 14（安全信息率下界）** 任意 `(δ_H, δ_E)`-信息可容许编码器满足
```
B(z) ≥ (I(z_big; H) − δ_H) + β·(I(z_big; E) − δ_E)
```
故轻量化存在由安全相关信息量决定的**地板**：低于地板的压缩必然破坏证书。
*证明思路*：数据处理不等式 `I(z_lite;H) ≤ min(I(z_big;H), B(z))`，加权求和。

## 7. 本轮最大风险

**一句话**：LENS 的全部可证性依赖「安全零空间 `N_S` 由标定数据估计且在整个部署分布上稳定」——一旦新故障模式/新环境/对抗样本把真实安全子空间漂出 `S_S`，LENS 会恰好剪掉未来最需要的那一维，而离线证书仍显示 `Valid`，形成比第 66 轮更隐蔽的「持证失效（certified-but-unsafe）」；NSP 只能降低、无法消除该风险，因为探针本身也在同一个有偏标定集上训练。

**次级风险与缓解**：
1. **标定集覆盖不足** → 主动标定（覆盖遮挡/光照/肤色/年龄）+ 每类故障的最坏情形采样；
2. **零空间估计误差** → 用敏感度下置信界而非点估计，保留 `d_min` 安全通道作为鲁棒冗余；
3. **NSP 与压缩同源偏差** → 引入与压缩器解耦的独立探针（如时序一致性、行为-情绪跨模态校验）；
4. **RAC 抖振** → 对 `g_t` 加迟滞（hysteresis）与最小驻留时间，避免算力频繁切换；
5. **定理 14 地板不可达** → 若目标压缩率低于信息地板，应放弃压缩而改用架构级轻量（事件相机、稀疏注意力），而非硬压。
