# 第 44 轮（新循环第 4 轮） · Ground-Cert × Plan-Cert：把「视觉编码器」的语义不确定性接地到几何证书，把「决策规划」从单步守卫升级为轨迹级证书（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约空集」，但它仍压着两个未言明的单点假设：**(H1) 视觉编码器被当作可信证书源**——VLM/视觉编码器被默认为「看→懂→证书」的确定性管道，但其嵌入空间非度量、分布外脆弱、INT8 量化会损伤语义，**语义与几何之间存在从未被证明的 grounding gap**；**(H2) 决策规划被当作单步守卫选择**——v20 定义 43 的证书一致选择只是单步 argmax，但真实规划是有限时域序列决策，**单步 sound 不蕴含轨迹 sound**，感知不确定性还会沿时域累积。本轮灵感词「视觉编码器」「决策规划」精确命中这两个假设：**视觉编码器**迫使我们把编码器从 oracle 降级为 certified transducer，用共形语义集 + 表示 Lipschitz/区间界 + 跨模态接地，把语义不确定性**外扩**成几何外扩界；**决策规划**迫使我们把单步证书升级为轨迹级证书（前缀认证 + 尾部可行 + 时域 ≤ 租约），并显式处理安全证书造成的死锁/活性。两者耦合处（感知不确定性 × 长时域）是本轮真正的新问题：**外扩过度会锁死规划，外扩不足会静默不 sound；而规划本身又能主动降低不确定性**。

## 0. 直觉与动机

**灵感 1（视觉编码器 → 「点估计不是证书，不确定性要外扩成几何」）**：编码器说「前方是空的」，若直接当几何真值，就会撞墙。直觉上，编码器的价值不在于它「猜对了」，而在于我们能给它的**每个语义结论配一个几何外扩界**——把「前方可通行」读成「墙可能存在于 ±δ 内」，规划器躲开整个可能区域。这样编码器越不确定，外扩越大，越保守但永不撞：不确定性被**吸收进安全裕度**，而不是被悄悄丢给下游。

**灵感 2（决策规划 → 「单步不撞 ≠ 整段不撞」）**：每步都有 CBF margin 并不保证有限时域内可行；裕度会被感知不确定性逐步侵蚀，可能规划出「当下安全、五步后无路可走」的方案。直觉上，证书要像签证覆盖整段行程，且行程长度不得超过证书租约有效期。与此同时，安全证书很容易把机器人锁死（越保守越不动，越不动越要先看清），因此必须配一张**活性/进展证书**：证明每一步要么朝目标推进、要么能安全停车，而不是无限期僵持。

**灵感 3（耦合 → 规划可以「主动看」把不确定性变成可优化资源）**：既然不确定性是保守性的来源，规划就能主动选择动作/视角去降低它——减速、转头、换道以获得更好观测。但「为了看清而靠近危险」必须自身安全，探索要有**认证预算**。这把感知不确定性从「只能忍受的税」变成「可被规划优化的资源」，也把感知与规划从串联管道变成闭环。

**耦合升级**：GVC 把语义不确定性**接地**成几何外扩界；TPC 把单步证书**组合**为轨迹证书并约束时域 ≤ 租约；APP 用**主动感知**降低不确定性；SG-Monitor 跨模态检测语义-几何失配。四层架构由此从 v8 的「人格契约 + 并发证书」升级为 v9 的「接地证书 + 轨迹证书 + 主动感知」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（接地语义证书 GVC）**：视觉编码器 E: O→S，语义空间 S；共形语义集 Ŝ^α(o) 满足 P(s_true ∈ Ŝ^α) ≥ 1−α。接地映射 Γ: S→2^G 把语义解释映射为几何约束集合。**接地 sound**：若 ∀s∈Ŝ^α，Γ(s) ⊇ G_true（几何真值），则语义证书接地 sound。工程实现用**外扩算子** Γ_δ(s) = inflate(Γ_0(s), δ(s))，其中 δ(s) ≥ grounding 误差上界。**命题（保守传递）**：δ 单调 ⟹ Γ_δ 单调；越大的语义不确定性只产生更大的几何外扩，绝不缩小安全域，故接地对 soundness 只可能过保守、不可能过乐观（前提是 δ 是真上界）。

**定义 45（表示 Lipschitz 与语义鲁棒半径）**：编码器在嵌入空间满足 ‖E(o_1)−E(o_2)‖ ≤ L_E·d_O(o_1,o_2)，语义谓词 φ 在嵌入上满足 L_φ-Lipschitz。**语义鲁棒半径** r_φ(o) = margin_φ(E(o)) / (L_φ·L_E)。若 r_φ(o) ≥ ε_pix，则任意 L∞ 像素扰动 ≤ ε_pix 不改变 φ 的判定。**用途**：把「编码器鲁棒性」从一次性的对抗测试，提升为可随观测实时计算的证书量，并作为 δ(s) 的下界来源（鲁棒性越差，δ 越大）。

**定义 46（轨迹级规划证书 TPC）**：规划 π=(a_0..a_{H−1})，不确定性集合 U = Ŝ^α × 控制扰动。证书 C_π = (I_π, H, ε_π) 有效，当且仅当 ∀u∈U、∀t≤H，闭环状态 z_t∈I_π（前向不变），且 H·Δt ≤ H_lease（证书租约有效期，复用定义 41）。**前缀-尾部引理**：若前缀 [0,k] 在实测轨迹上不变、尾部 [k,H] 在名义模型 + 外扩不确定性下不变，且切换点状态属于两段不变集交集，则整段 sound。**推论**：允许执行中重规划，但切换点必须落在「旧证书 ∩ 新证书」内，否则必须停车。

**定义 47（活性/进展证书与安全-活性对）**：定义进展测度 ϕ(z)（到目标距离或势函数）与停车安全集 S_stop。**活性证书**：在每个决策周期，要么 ϕ(z_{t+1}) ≤ ϕ(z_t) − η（推进），要么 z_t∈S_stop 且存在经认证的停车轨迹（可停）。**定理（无死锁）**：若安全证书与活性证书同时成立，则系统不会无限期停在「不安全也不推进」的状态；若活性不可达，必须显式输出「不可行」并请求协商/接管，而非静默冻结。

**定义 48（主动感知决策规划 APP）**：动作 a 同时具有任务价值 V_task(a) 与信息价值 I(a) = E[vol(Ŝ^α(o')) − vol(Ŝ^α(o))]（共形集体积期望缩减）或接地误差 δ 的期望下降。**认证探索约束**：a 必须属于当前安全证书允许集合 C_π；**探索预算**：每周期最多消耗 β_explore 的证书裕度用于信息获取。**目标**：a* = argmax_{a∈C_π} [V_task(a) + μ·I(a)]，μ 由不确定性—保守性权衡调节。**命题**：若信息动作只在 C_π 内选取且消耗的裕度 ≤ β_explore，则主动感知不破坏安全证书；它只把「原本因保守而放弃的可行性」赎回。

**定义 49（跨模态接地监控 SG-Monitor）**：语义结论 s 与几何观测 g（LIO/深度/占据栅格）的一致性谓词 Cons(s,g)。若 Cons 失败（如 VLM 说「门开」而几何显示「墙」），则**单调降级**：丢弃语义证书，只用几何证书 C_geo，并把该样本回灌 CKB 作为失配反例。**命题**：降级是单调的安全收缩（C_geo ⊆ C_sem 的保守版本），故失配时可用性下降但 soundness 不降。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 GROUNDED-VISUAL-CERTIFICATE（接地视觉证书 GVC）
1. **语义共形层**：Mondrian 分层共形（按场景/光照/距离）输出 Ŝ^α，复用 IP-57 的共形机制但作用在语义谓词上。
2. **接地外扩层**：构造可验证的 Γ_δ（区间/包围盒/占据膨胀），δ 由表示 Lipschitz、量化误差、标定残差三者上界并集给出。
3. **语义鲁棒监视**：实时计算 r_φ(o)，低于阈值即标记该语义不可信，强制扩大 δ 或降级。
4. **证书输出**：给规划器输出「语义谓词 + 几何外扩约束 + 置信/接地标签」，而非裸语义。

### 2.2 IP-61 TEMPORAL-PLAN-CERTIFICATE（轨迹规划证书 TPC）
1. **轨迹不变集**：由 CBF/可达管（reachable tube）在 U 上做鲁棒前向不变集，输出 I_π。
2. **前缀-尾部组合**：执行中每个 k 检查切换点是否落在 I_old∩I_new，否则安全停车。
3. **时域-租约耦合**：H·Δt ≤ H_lease；租约过期即强制重认证，禁止用陈旧证书续跑。
4. **活性证书**：进展测度 + 停车安全集，显式区分「推进/可停/不可行」三态。

### 2.3 IP-62 ACTIVE-PERCEPTION-PLANNER（主动感知规划 APP）
1. **双目标规划**：任务价值 + 信息价值，在 C_π 内联合优化。
2. **安全探索**：信息动作必须已认证；探索预算 β_explore 从证书裕度扣除。
3. **视角/速度/换道动作空间**：把「看得更清」作为可执行动作显式建模。
4. **不确定性回收**：用观测更新 δ 与外扩，把保守性变成可赎回资产。

### 2.4 IP-63 SEMANTIC-GEOMETRIC MONITOR（跨模态接地监控）
1. **一致性谓词**：语义 vs 几何冗余校验。
2. **单调降级**：失配即弃语义、退几何。
3. **反例回灌**：失配样本进 CKB/SCV，驱动编码器课程。

```

    → IP-39 规划(CBF + 可达管) → IP-47 组合(RG + 前缀-尾部)
    → IP-45 总线(grounding/plan/activity/explore) → IP-53 CMC
L4: IP-57 PCE(persona + 语义共形/信任预算) + IP-55 CKB(接地指纹)
    ← IP-59 ICV(失配 fuzz + 轨迹组合 + 死锁/活性) + IP-54 SCV
    → IP-44 蒸馏 + IP-50 课程 → RCA 重颁(grounding-conditioned) → 热更新
```

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 接地 soundness | 语义集外扩后几何覆盖率；δ 真上界违例 | ≥1−α；0 起 |
| E96 表示鲁棒性 | 像素扰动下语义翻转率；r_φ 校准误差 | <5%@ε；<15% |
| E97 轨迹证书组合 | 前缀-尾部切换违例；超租约续跑；组合反例 | 0；0；0 |

| E99 主动感知收益 | 不确定性体积降幅；赎回可行率；探索违例 | ≥20%；≥10pp；0 起 |

| E101 长时域接地闭环 | 100h 不安全事件；语义漂移检出；重规划违例 | 0 起；≥95%；0 |
| E102 端到端可用性 | 任务成功率；平均保守裕度；p99 规划延迟 | ≥基线；↓≥10%；<10ms |

回退：E95 外扩界不 sound → δ 取最坏静态上界并关闭语义通道；E97 组合失效 → 每步重认证 + 缩短时域；E98 死锁 → 强制停车接管；E99 无收益 → 关主动感知；E100 失配频发 → 只信几何；任何红线失败 → 熔断回退 v20。

## 5. 本轮最大风险

**一句话**：接地映射 Γ_δ 的 δ 若不是真上界，外扩后的语义证书仍会**静默不 sound**（比不用语义更危险，因为它给了虚假信心）；而 δ 取得过保守又会把轨迹证书压成死锁、让主动感知无路可走——因此 E95（接地 soundness）与 E98（死锁）必须设为红线，且默认回退到「只用几何证书 + 逐步重认证」这条不依赖语义的底线。

| Γ_δ(s) | 接地外扩映射 | inflate(Γ_0(s), δ)，δ 为 grounding 误差真上界 |
| L_E, L_φ | 表示/谓词 Lipschitz 常数 | 嵌入距离与语义判定的稳定性界 |
| r_φ(o) | 语义鲁棒半径 | margin_φ(E(o))/(L_φ·L_E) |
| I_π | 轨迹不变集 | 在 U 上鲁棒前向不变 |
| H, H_lease | 规划时域、租约有效期 | 约束 H·Δt ≤ H_lease |
| ϕ(z), S_stop | 进展测度、停车安全集 | 活性证书的两要素 |
| I(a), β_explore | 信息价值、探索预算 | 共形集体积期望缩减；裕度消耗上限 |
| Cons(s,g) | 跨模态一致性谓词 | 语义结论与几何观测是否相容 |

## 2. 关键算法（伪代码）

### IP-60 GVC：共形语义、鲁棒半径与接地外扩
```
def conformal_semantic_set(o, alpha, context_id):
    # Mondrian 分层：按场景/光照/距离维护各自分数分布
    scores = calib_scores[context_id]
    q = quantile(scores, 1 - alpha)
    return SemanticSet(center=encoder(o), radius=q)

def semantic_robust_radius(o, pred):
    L_E = encoder_lipschitz_bound()
    L_phi = predicate_lipschitz_bound(pred)
    return predicate_margin(encoder(o), pred) / (L_phi * L_E)

def grounding_inflate(s_hat, o):
    delta_q = quant_error_bound()          # INT8 量化误差上界
    delta_c = calib_residual_bound()       # 标定残差上界
    delta_r = max(0.0, radius_gap(s_hat, o))  # 鲁棒半径不足的补偿
    delta   = delta_q + delta_c + delta_r
    geom    = {p: inflate(base_geometry(p), delta) for p in s_hat.predicates}
    return geom, delta

def grounded_certificate(o, alpha, ctx):
    s_hat = conformal_semantic_set(o, alpha, ctx)
    geom, delta = grounding_inflate(s_hat, o)
    ok = (delta <= delta_max) and all(
        semantic_robust_radius(o, p) >= eps_pix for p in s_hat.predicates)
    return GroundCert(preds=s_hat, geom=geom, delta=delta, trusted=ok)
```

### IP-61 TPC：轨迹证书、前缀-尾部与活性
```
def plan_certificate(pi, U, H_lease, dt):
    if H_lease is not None and len(pi) * dt > H_lease:
        return None                          # 时域超过租约 => 不可认证
    I_pi = robust_forward_invariant(pi, U)   # 可达管 / CBF over horizon
    if I_pi is None:
        return None
    return PlanCert(I=I_pi, H=len(pi), eps=U)

def compose_prefix_tail(C_old, C_new, z_k):
    if z_k in C_old.I and z_k in C_new.I:
        return C_new                         # 切换点交集内 => 允许重规划
    return safe_stop(z_k)                    # 否则安全停车

def activity_certificate(z, goal, dt):
    phi_now, phi_next = progress(z, goal), progress(z_next, goal)
    if phi_next <= phi_now - eta:
        return "PROGRESS"                    # 朝目标推进
    if z in S_stop and stop_traj_certified(z):
        return "SAFE_STOP"                   # 经认证的停车
    return "INFEASIBLE"                      # 显式上报，不静默冻结
```

### IP-62 APP：主动感知与安全探索预算
```
def active_perception_plan(cands, C_pi, budget, mu):
    best = None
    for a in cands:
        if a not in C_pi:
            continue                          # 只选已认证动作
        info = expected_information_gain(a)   # 共形集体积 / δ 期望下降
        cost = cert_margin_cost(a)
        if cost > budget:
            continue                          # 探索预算不足以支付
        score = V_task(a) + mu * info
        if best is None or score > best.score:
            best = (a, score, cost)
    if best is None:
        return fallback_task_action()         # 退化为纯任务动作
    return best
```

```
def semantic_geometric_monitor(o, sem, geo):
    for pred, claim in sem.predicates.items():
        if not consistent(claim, geo[pred]):
            log_mismatch(pred, claim, geo[pred])
            return downgrade_to_geometric(geo)   # 单调收缩，保 sound

def car_guard_v9(e, x, cert, persona, lease, ground, t):
    theta = cert.alpha_e[e] * cert.theta_sim[e]
    m = min(cert_lookup_L0(x).m_lo[e],
            lease.m - lease.lam * (t - lease.tau),
            persona_cap[e](persona),
            ground.delta_cap[e] if ground.trusted else 0.0)
```

## 4. 实验设计（E95–E102，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E95 接地 soundness | 外扩后几何覆盖率；δ 真上界违例；条件覆盖率 | ≥1−α(α=0.1)；0 起；≥0.9 |
| E96 表示鲁棒性 | 像素扰动语义翻转率；r_φ 校准误差；INT8 附加翻转 | <5%@ε；<15%；<2% |
| E97 轨迹证书组合 | 前缀-尾部切换违例；超租约续跑；组合反例 | 0；0；0 |
| E98 活性/死锁 | 死锁率；不可行显式上报率；冻结超时 | <1%；100%；0 |
| E99 主动感知收益 | 不确定性体积降幅；赎回可行率；探索违例 | ≥20%；≥10pp；0 起 |
| E100 跨模态失配 | 失配检出率；降级后违例；误报率 | ≥95%；0；<5% |
| E101 长时域接地闭环 | 100h 不安全事件；语义漂移检出；重规划违例 | 0 起；≥95%；0 |
| E102 端到端可用性 | 任务成功率；平均保守裕度；p99 规划延迟 | ≥基线；↓≥10%；<10ms |

回退：E95 外扩不 sound → δ 取最坏静态上界 + 关闭语义通道；E96 鲁棒性不足 → 提高 ε_pix 或禁用该谓词；E97 组合失效 → 每步重认证 + 缩短时域；E98 死锁 → 强制停车接管；E99 无收益 → 关主动感知；E100 失配频发 → 只信几何；任何红线失败 → 全链路熔断回退 v20。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 接地 δ 不是真上界，外扩语义证书静默不 sound | 高 | E95 红线；δ 由量化+标定+鲁棒三项上界并集；影子证书零违例才启用 |
| 接地外扩过保守，轨迹证书压成死锁/不可行 | 高 | E98 红线；活性证书显式上报不可行；δ 分场景自适应；主动感知赎回 |
| 轨迹级时域组合在时变不确定性下不封闭 | 高 | E97 红线；H·Δt≤H_lease 硬约束；切换点必须在 I_old∩I_new；否则停车 |
| 语义鲁棒半径 r_φ 低估，像素扰动翻转语义 | 中-高 | E96 红线；L_E/L_φ 取保守上界；INT8 量化误差单独记账；EPS 对抗训练 |
| 主动感知为降不确定而靠近危险 | 中-高 | 只选 C_π 内动作；β_explore 硬预算；E99 探索违例红线 |
| 跨模态监控误报导致频繁降级（可用性崩塌） | 中 | 一致性谓词分场景校准；误报率 E100 <5%；降级仍保 sound，可恢复 |
| 前缀-尾部切换点数值误差越界（边界情形） | 中 | 切换点用外扩交集 + 安全裕度；边界样本进 ICV 交错 fuzz |

## 6. 本轮最大风险

**一句话**：接地映射 Γ_δ 的 δ 若不是真上界，外扩后的语义证书仍会**静默不 sound**（比不用语义更危险，因为它给了虚假信心）；而 δ 取得过保守又会把轨迹证书压成死锁、让主动感知无路可走——因此 E95（接地 soundness）与 E98（死锁）必须设为红线，且默认回退到「只用几何证书 + 逐步重认证」这条不依赖语义的底线。
