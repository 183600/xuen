# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「路径规划」×「论文创新点」）

> R69 补上了「问」的能力：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略显式表示歧义，用 VoI 选择看 / 问 / 触去消解。但 R69 仍有两处「近视」：
> - **MINT 是单步贪心**：每次只选当前 VoI 最大的一个信息动作。可「先问什么」取决于「后问什么」——证据是互补的、问题是有前提的；贪心会在错误的问题上花光预算，或问到一个答案无法被验证的问题。
> - **消解不了时只会刹车**：U_epi 未消解 → 视同 aleatoric → 一体化 λ 收紧。可真实世界往往存在一条**对所有候选模式都安全**的路（走廊交汇处、宽通道、低速段）；在岔口前多走一段、晚一点承诺，比原地减速更高效，也比盲目选一个模式更安全。
> - R69 自陈的最大风险是「模态分布不可信 → 问错比不问更危险」；但它没有回答「**如果问不出结果，我还能怎么走**」。
>
> 本轮两个灵感正好补上：
> - **路径规划**把「交互」与「行动」统一成一条**信念空间中的路径**：信息动作是路径上的取证路标，任务动作是路径本身；消歧不是目的，**推迟承诺（defer commitment）** 才是——只要还存在一条对全部存活模式都安全的「模式覆盖走廊」，就不必现在选。
> - **论文创新点**提醒我们：不要再用「又加了一层模块」冒充贡献。本轮只主张**一个可证伪的 delta**，并给出它与前几轮的严格包含关系：**交互 = 走廊修复 / 承诺窗口延长**，而不是又一个并列的 VoI 模块。
>
> 核心命题：**把 R69 的单步 VoI 贪心，升级为「决策加权、任务损失导向」的联合信息-任务路径规划；把「消解不了就刹车」，升级为「先沿模式覆盖走廊推迟承诺，再用信息动作延长可推迟窗口，超过承诺点才按 R69 兜底」。** 命名 **COMPASS-RAS**（Commitment-aware Multi-step Planning of Active Sensing and Safe-route Synthesis）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**在必须选之前，我还能安全地走多远**」——不确定性不只决定要不要问，也决定**什么时候必须不再等**。

## 0. 直觉与动机

### 灵感 1（路径规划 → 交互是信念空间里的路径，不是一次查询）

直觉：问路不是站在原点问一次。你先走到岔口（获得新观测），再看路牌（选择判别力最大的证据），还拿不准就问人（信息动作），同时脚不能停下（任务在推进）。R69 的 MINT 把每一步拆成独立的「问 / 不问」，等价于在信念空间里做 greedy hill-climbing：只看眼前一步的熵降。但信息的价值常常是**非近视**的：A 的答案决定 B 是否值得问；两个各自增益很小的证据合起来可能一举定案；而一个增益很大的问题，若答案无法验证，会把系统带进更深的错误。**路径规划**给的正解是：在信念空间的图上做有限时域搜索（A* / beam / MCTS），以「任务损失」而非「熵」为代价，以「可验证性」为硬约束，得到一条**取证路径** γ_info = (g_1,…,g_H)。

### 灵感 2（路径规划 → 承诺点与模式覆盖走廊）

直觉：人过马路不会先决定「那边那个人会不会突然冲出来」，而是先走一段**对两种可能都安全**的路径（停在安全岛、贴着路缘），直到必须穿越的那条线——那就是**承诺点**。形式化：对每个存活模式 m_k，定义其安全可行集 Safe_k(t)；它们的交集 C_t = ∩_k Safe_k(t) 就是「无论哪个模式为真都安全」的**模式覆盖走廊**。只要 C_t 非空，就可以**推迟承诺**；当 C_t 即将为空时，必须 (a) 交互以缩小模式集（修复走廊）、(b) 提前承诺并承担选错损失、或 (c) 退回 R69 的减速兜底。R69 的「未消解就收紧」只是 (c)，把 (a)(b) 两条更优的路都丢掉了。更漂亮的是：**信息动作的价值可以被重新定义为「走廊修复量 / 承诺窗口延长量」ΔW**——它与任务直接相关，天然避免「为了好奇去问一个与任务无关的问题」。

### 灵感 3（论文创新点 → 单一可证伪 delta + 严格包含）

直觉：一个研究循环最危险的堕落方式，是每轮加一个模块、每轮都自称 SOTA，最后没有一个能被单独推翻的贡献。**论文创新点**这个词逼我们做减法：本轮只主张一句话——「**在存在多个都合理的动作模式时，把主动交互视为对模式覆盖走廊的修复、并以任务损失为代价规划一条推迟承诺的路径，能在不牺牲安全的前提下，严格优于单步 VoI + 统一收紧**」。围绕这句话，每个组件都必须回答三件事：(i) 它对应哪条既有工作（prior art anchor）；(ii) 它改变哪个**单一标量**（falsifiable delta）；(iii) 哪个实验能杀死它（kill experiment）。并且必须证明：当路径长度为 0、承诺点退化为 0 时，COMPASS 逐指令退化为 R69——**新层严格包含旧层，而不是并列替代**。这把「创新点」从修辞变成可审计的工程约束（Delta 账本，定义 321）。

### 灵感 4（对 R69 最大风险的正面回答：问错不如不问，问不出就走）

直觉：R69 说「模态分布不可信时，主动交互会把诚实的不知道升级成被证实的错误」。COMPASS 的回答不是「那就不问」，而是给交互加两道**路径级**闸门：(i) **先声明验证方式再提问**（pre-committed verification）：发出 g 之前，系统必须写下「什么样的观测算支持 / 否定哪个模式」，否则该 g 不允许执行——问一个无法被验证的问题，比不问更糟；(ii) **证据服务于决策**：只有当 ΔW > 0（能延长可推迟窗口）或能显著降低承诺损失时，信息动作才有价值；否则歧义再大也不问。这样「好奇」被「承诺窗口」替代，问句数量随任务相关性而非模态熵变化。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（COMPASS-RAS 总览）** COMPASS-RAS = (BPP, CTP, CWP, JCS, DWA, IPG, CMG, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **联合路径预算**：信息路径的期望耗时 / 社交成本 + 任务路径耗时 ≤ B，任一时刻只有一条认证中的动作前缀；
(iii) **承诺单调性**：承诺点只能在「认证重开事件」下回退，否则单调推迟（定义 318）；
(iv) **严格包含**：路径长度 0 且承诺点 0 时逐指令退化为 R69（定义 325）。

**定义 311（信念与任务损失）** 信念 b = (ŵ_k, ξ̄_k, Σ_k, p_world) 继承 R69 定义 296；任务损失矩阵 L ∈ ℝ^{K×K}，L_{kl} = 真实模式为 m_k 而按 m_l 执行时的期望任务代价（碰撞、超时、舒适度、任务失败）。承诺风险 R_commit(b) = min_l Σ_k b_k L_{kl}；神谕风险 R_oracle(b) = Σ_k b_k L_{kk}。注意 L 由**任务**定义，不是熵。

**定义 312（决策加权歧义 DWA）** 替代 R69 的 U_epi = H_mode·g(Δ_min)：
U_epi^task(b) = R_commit(b) − R_oracle(b)。
直观：只有会改变「该选哪个动作、损失多少」的歧义才是真歧义；两个模式若诱导同一安全动作，则 U_epi^task = 0，哪怕 H_mode 很大。这条替换直接消掉 R69「为无关歧义做交互」的浪费（引理 21）。

**定义 313（信息路径）** γ_info = (g_1,…,g_H) ⊂ 𝒜_info^H；观测 y_i ~ p(·|g_i, b_{i−1})；成本 C(γ) = Σ_i [c_phys(g_i) + c_attn(g_i)] + c_switch。决策增益 ΔL(γ) = R_commit(b_0) − E_{y_{1:H}}[R_commit(b_H)]。净价值 VoI_path(γ) = ΔL(γ) − λ_C C(γ)。

**定义 314（BPP：有限时域信念路径规划）** γ* = argmax_{γ: C(γ) ≤ B, ∀i g_i 认证} VoI_path(γ)，用 beam search + 可采纳启发（R_commit 下界、ΔW 上界）求解；H ≤ 3、候选 ≤ 5，保证 anytime 有解（定义 323）。

**定义 315（模式覆盖走廊）** 对存活模式集 M_t，C_t = ∩_{k ∈ M_t} [Safe_k(t) ∩ Feasible_k(t)]（安全包络沿用 R69 的 C-RAS-WM）。若 C_t 非空，则存在一条「对全部存活模式都安全」的任务路径。

**定义 316（承诺点与可推迟窗口）** 给定任务路径 π 与走廊序列 {C_t}，承诺点 t*(π) = 最小的 t，使 t 之后不存在同时覆盖 M_t 的安全可行子路径；可推迟窗口 W(b; π) = t*(π) − t。**信息动作的全部价值 = ΔW**：ΔW(g) = E[W(b'; π) − W(b; π)]（允许「承诺损失下降」作为第二收益项）。

**定义 317（CTP：模式覆盖任务路径）** 在 C_t 内选 a_t，使任务进度最大：π_cont = argmax E[progress] s.t. a_t ∈ C_t, ∀t。R69 的「减速」是 C_t 退化为极窄集合时的特例；R69 的「按 w 采样选一个模式执行」是 t* = t 的立即承诺特例。

**定义 318（承诺单调性与认证重开）** 一旦 t = t* 并选 m_l，不得因轻微证据变化改选；仅当出现认证重开事件（FMA 异常、两条正交证据一致地否定 m_l、走廊在 m_l 下失效）才允许回退承诺。重开事件必须留审计记录，且两次重开间隔 ≥ 最小驻留时间 τ_dwell。

**定义 319（信息路径守卫 IPG：先验证后提问）** 每个候选 g 必须携带**预先声明**的验证谓词 V_g(y, m)（「若回答 y，则支持 / 否定模式 m」），在提问前写入审计日志；不满足 V_g 可判定性或缺少第二正交源的 g 不得进入路径。这从 R69 的「事后证据纪律」升级为「事前可验证性约束」。

**定义 320（路径级证据纪律）** 承诺（不是单次查询）需要至少两个正交证据源支持；单次交互只能更新后验、不能跨越承诺点。与 R69 定义 293-iii 兼容，并收紧为「承诺级」而非「查询级」。

**定义 321（Delta 账本 NLED）** 每个 IP 登记四元组 (prior_art, delta_scalar, kill_experiment, containment)。准入规则：delta_scalar 必须是一个**可测标量**（如「不必要交互次数」「承诺损失」「取消耗时」）；kill_experiment 必须能在机制被移除时让该标量显著退化；containment 必须给出退化条件。未满足者记为「novelty debt」，不得计入本轮创新点。

**定义 322（联合信息-任务调度 JCS）** 在 π_cont 上选择信息路标的插入点：在「模式分歧最大、且路径有余量（低速 / 停顿 / 宽通道）」的区段插入 g，目标 max ΔL − λ_C C，s.t. 插入不破坏 C_t。这把「在哪问」变成路径规划的一部分，而不是独立模块。

**定义 323（路径预算与 anytime 截止）** 规划器有硬 deadline T_plan；超时即以 R69 的贪心解作为可行解返回（降级但仍满足安全），并记录 `plan_mode = {searched, greedy_fallback}`。

**定义 324（AIC-COMPASS 与 J_COMPASS）** 威胁集 ℰ_COMPASS = ℰ_FLUID × ℰ_path，新增：**走廊投毒**（让某模式的 Safe_k 被高估）、**证据陷阱**（廉价高增益但不可验证的问题）、**延迟诱导**（无限许愿更确定的证据以拖垮承诺）、**账本伪造**（声称包含关系却无退化测试）。证书 J_COMPASS = (J_FLUID, W_before, W_after, commit_time, corridor_margin, n_queries, delta_scalar_table_hash, containment_pass, plan_mode)。

**定义 325（严格包含）** 当 H = 0（不规划信息路径）或 W < 0（无走廊可推迟，立即承诺）时，COMPASS 的输出与 R69 逐指令相同：λ 取 R69 的 λ_floor(U_ale + U_epi)，mode 取 R69 的 select_mode。故 R69 = COMPASS 的「零路径、零推迟」边界。

## 2. 关键算法骨架

```python
# IP-264 DWA：把熵式歧义换成任务损失式歧义
def decision_weighted_ambiguity(b, L):
    R_commit = min(sum(b[k] * L[k][l] for k in b) for l in b)
    R_oracle = sum(b[k] * L[k][k] for k in b)
    return R_commit - R_oracle                    # 只有影响决策的歧义才非零

# IP-267 CWP：承诺窗口预测（带安全侧偏置，宁可低估）
def predict_window(b, task_plan, safe_sets, eps):
    W = 0
    for t in range(len(task_plan)):
        corridor = intersect(safe_sets[k][t] for k in b.alive)   # C_t
        if corridor.is_empty(): break
        W += 1
    return max(0, W - eps)                        # eps>0：保守下界，禁止乐观

# IP-265 BPP + IP-266 CTP：联合路径（beam search over query paths）
def plan_compass(b, L, safe_sets, budget, deadline):
    best = None
    for gamma in beam_search(info_candidates(b), H=3, budget=budget):   # γ_info
        if not all(IPG.precommit_ok(g) for g in gamma):  continue       # 先验证后问
        bH, dW, dL = rollout_belief(b, gamma)
        pi = contingent_path(bH, safe_sets)          # CTP：走廊内最大进度
        if pi is None:                               # 无走廊：只能立即承诺或 R69
            continue
        score = dL + LAMBDA_W * dW - LAMBDA_C * cost(gamma, pi)
        if best is None or score > best.score: best = (gamma, pi, dW, dL)
        if time.now() > deadline: break              # anytime：保留当前最好解
    return best if best else r69_greedy(b, L)        # 降级 = R69（严格包含）

# IP-268 CMG / IP-270 IPG：承诺与重开
def commit_and_guard(mode, t, audit):
    audit.log_commit(mode, t, window=W)
    def on_evidence(ev):
        if ev.is_certified_reopen() and ev.n_orthogonal_sources >= 2 \
           and ev.dwell >= TAU_DWELL:
            return REOPEN
        return HOLD                              # 默认不反悔：防震荡
    return on_evidence

# IP-275 主闭环（继承 R69/R68）
def COMPASS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    b = M.aud.belief(modes, z)                   # R69 的模态后验
    if M.cmg.locked:                             # 已承诺：只做一致性监控
        return M.cmg.hold_or_reopen(b, o)
    # 1) 决策加权歧义：与任务无关的歧义不驱动交互
    U_task = decision_weighted_ambiguity(b, M.L)
    # 2) 先算承诺窗口：够长就沿走廊推迟，根本不问
    W = predict_window(b, M.task_plan, M.safe_sets, eps=M.eps_w)
    if W >= M.task_plan.horizon:                  # 不需要承诺，也不需要问
        return M.ctp.follow(b, safe_sets=M.safe_sets)
    # 3) 窗口不够：规划信息路径去「修复走廊」
    plan = plan_compass(b, M.L, M.safe_sets, M.budget, M.deadline)
    if plan is not None:
        M.cia.execute(plan.gamma, evidence_discipline='precommitted')   # 看/问/触
        b = M.cia.posterior(modes)
    # 4) 承诺窗口仍不够 / 被投毒 / 不可验证 → R69 兜底
    if predict_window(b, M.task_plan, M.safe_sets, M.eps_w) <= 0:
        return M.r69_fallback(b, U_task)          # λ_floor(U_ale + U_epi)
    # 5) 走廊内推进，临近承诺点再定案
    pi = M.ctp.follow(b, safe_sets=M.safe_sets)
    if pi.at_commitment_point:
        M.cmg.commit(M.aud.select_mode(b, M.L), pi.t)
    M.vqa_p.submit_async(b, plan, W, U_task)
    return pi
```

## 3. 推导

**引理 19（非近视信息路径的严格增益）** 记决策增益 ΔL 为查询集合的函数。若 ΔL 对查询集**自适应子模**（adaptive submodular），则贪心取得 (1−1/e) 近似；但决策加权增益一般不满足自适应子模：存在两个查询 A、B，使 ΔL({A}) = ΔL({B}) ≈ 0（单独问都不改变承诺选择），而 ΔL({A,B}) 很大（互补证据才能跨越承诺阈值）。此时单步贪心的近似比可任意差，必须显式做路径搜索。系：**R69 的 MINT 是 COMPASS 在「查询增益自适应子模」这一特殊情形下的贪心近似**；互补证据场景正是 R70 的增量。

**引理 20（推迟承诺的安全中性）** 若 π_cont 在 t ≤ t* 上恒满足 a_t ∈ C_t = ∩_{k∈M_t} Safe_k(t)，则对任意真实模式 m_k ∈ M_t，路径都安全；因此把承诺从 t 推迟到 t* 不会降低安全性。代价只体现在进度 / 时间（走廊更窄）；安全性的让步为零。系：R69「未消解 ⇒ 收紧」不是唯一安全选择，**沿交集走廊推进是等安全、更高进度的选择**。

**引理 21（决策加权歧义是熵式歧义的下界收紧）** 0 ≤ U_epi^task(b) ≤ D_L·(1 − max_k b_k)，其中 D_L = max_{k,l} L_{kl} − min_k L_{kk}；而 H_mode 可在大 U_epi^task = 0 时仍很大（多个模式诱导同一动作）。故熵式 VoI 是决策 VoI 的**松上界代理**，会为无关歧义付费；DWA 把它收紧到任务真正关心的那部分。

**定理 18（COMPASS 严格包含 R69 与 R68）** 在 A99–A101（信念校准、走廊安全集可靠、L 有界）下，COMPASS 的期望任务损失 ≤ R69，且安全性 ≥ R69；当 H = 0 或 W < 0 时两者逐指令相同（定义 325）。进一步地，R68 是 COMPASS 在「R69 也不交互」处的二次退化。安全侧不做让步，效率侧获得「推迟承诺 + 走廊推进」的双重 resolution bonus。

**定理 19（联合路径的 anytime 可行性与分解）** 若信息动作经认证且不抢占任务安全包络（R69 定义 302），则联合目标可按「BPP（信息路径）× CTP（走廊任务路径）× JCS（插入点）」分解求解，beam search 在 deadline 内返回可行解；超时降级为 R69 贪心解，仍满足全部安全不变式。故实时预算被击穿时，系统退回 R69 而不是失效。

**定理 20（交互价值 = 承诺窗口延长）** 在 A102（损失对承诺时机局部 Lipschitz、模式分歧与窗口近似线性）下，ΔL(γ) = λ_W·ΔW(γ) + o(ΔW)。即：**信息动作的第一性价值不是熵降，而是把「必须做决定」的时刻往后推、或把承诺损失压下去**。这给出本轮唯一的可证伪主命题：移除 ΔW 估计（只按熵选问题）应导致「不必要交互↑、取消耗时↑、而成功率不升」。

## 6. 本轮最大风险

**一句话**：COMPASS-RAS 把「晚一点承诺」当作免费的效率来源，但**承诺窗口 W 是从模型里估出来的**——一旦 W 被高估（安全集算乐观了、模式集漏了一个、走廊跨度过大），系统就会在「其实已经不安全」的时刻继续推迟，把本可由 R69 的保守所避免的碰撞，变成一次**自信的、可审计的**错误；**路径规划把安全从「阈值」变成了「时间」，而时间是最难估准的状态量**。

**次级风险与缓解**：
1. **无限推迟 / 分析瘫痪**（证据永不定案、走廊不断缩窄）→ 定义 316 的硬承诺点 + E310 死锁率指标 + 预算到点必承诺（承诺单调性不阻止「到期承诺」）；
2. **走廊投毒**（Safe_k 被高估）→ 定义 324 威胁集 + 安全集由 C-RAS-WM 认证 + E309 对抗训练；
3. **证据陷阱 / 问题农场**（廉价高增益但不可验证）→ 定义 319 预声明验证谓词 + 路径级证据纪律；
4. **规划超时击穿实时性** → 定义 323 anytime + R69 贪心降级（定理 19）；
5. **创新点虚胖**（每层都能声称包含却无退化测试）→ Delta 账本 + E314 审稿式消融，未过者记 novelty debt、不计入贡献。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；联合路径预算（信息成本 + 任务耗时 ≤ B，单一认证前缀）；承诺单调（仅认证重开可回退）；严格包含（H=0 或 W<0 时逐指令退化为 R69）。

**定义 318（承诺单调与认证重开）** 承诺后仅 FMA 异常 / 两正交源一致否定 / 走廊失效才回退；间隔 ≥ `τ_dwell`；全部留痕。

## 3. 关键算法伪代码

```python
# IP-264 DWA：只保留会影响决策的歧义
def decision_weighted_ambiguity(b, L):
    R_commit = min(sum(b[k] * L[k][l] for k in b) for l in b)
    R_oracle = sum(b[k] * L[k][k] for k in b)
    return R_commit - R_oracle

# IP-267 CWP：承诺窗口（保守下界，宁可低估）
def predict_window(b, plan, safe_sets, eps):
    W = 0
    for t in range(len(plan)):
        if intersect(safe_sets[k][t] for k in b.alive).is_empty(): break
        W += 1
    return max(0, W - eps)

# IP-265/266/268：BPP + CTP + JCS 联合规划
def plan_compass(b, L, safe_sets, budget, deadline):
    best = None
    for gamma in beam_search(info_candidates(b), H=3, budget=budget):
        if not all(IPG.precommit_ok(g) for g in gamma): continue   # 先验证后问
        bH, dW, dL = rollout_belief(b, gamma)
        pi = contingent_path(bH, safe_sets)                        # 走廊内最大进度
        if pi is None: continue                                    # 无走廊 → 承诺或 R69
        score = dL + LAMBDA_W * dW - LAMBDA_C * cost(gamma, pi)
        if best is None or score > best.score: best = (gamma, pi, dW, dL)
        if time.now() > deadline: break                            # anytime
    return best if best else r69_greedy(b, L)                      # 降级=R69

# IP-269/270：承诺单调 + 认证重开
def commit_and_guard(mode, t, audit, W):
    audit.log_commit(mode, t, window=W)
    def on_evidence(ev):
        if ev.certified_reopen() and ev.n_orthogonal_sources >= 2 \
           and ev.dwell >= TAU_DWELL: return REOPEN
        return HOLD                                                # 默认不反悔
    return on_evidence

# IP-275 主闭环（继承 R69/R68）
def COMPASS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K); b = M.aud.belief(modes, z)
    if M.cmg.locked: return M.cmg.hold_or_reopen(b, o)
    U_task = decision_weighted_ambiguity(b, M.L)
    W = predict_window(b, M.task_plan, M.safe_sets, M.eps_w)
    if W >= M.task_plan.horizon:                   # 走廊够长：不问，直接推进
        return M.ctp.follow(b, safe_sets=M.safe_sets)
    plan = plan_compass(b, M.L, M.safe_sets, M.budget, M.deadline)
    if plan is not None:
        M.cia.execute(plan.gamma, evidence_discipline='precommitted')
        b = M.cia.posterior(modes)
    if predict_window(b, M.task_plan, M.safe_sets, M.eps_w) <= 0:
        return M.r69_fallback(b, U_task)           # λ_floor(U_ale + U_epi)
    pi = M.ctp.follow(b, safe_sets=M.safe_sets)
    if pi.at_commitment_point:
        M.cmg.commit(M.aud.select_mode(b, M.L), pi.t)
    M.vqa_p.submit_async(b, plan, W, U_task)
    return pi
```

## 4. 推导

**引理 19（非近视信息路径的严格增益）** `ΔL` 对查询集自适应子模时贪心为 `(1−1/e)` 近似；但决策加权增益一般不满足：存在 A、B 单独问几乎不改变承诺、合起来才跨越阈值（互补证据）。此时单步贪心近似比可任意差，必须做路径搜索。系：R69 的 MINT 是本轮在「自适应子模」特例下的贪心近似；互补证据是 R70 的增量。

**引理 20（推迟承诺的安全中性）** 若 `a_t ∈ C_t = ∩_k Safe_k(t)` 对所有 `t ≤ t*` 成立，则任意真模式都安全；把承诺从 t 推迟到 t* 不降低安全性，代价仅体现在进度 / 时间。系：R69「未消解 ⇒ 收紧」不是唯一安全选择；沿交集走廊推进是**等安全、更高进度**的选择。

**引理 21（DWA 收紧熵式歧义）** `0 ≤ U_epi^task ≤ D_L·(1 − max_k b_k)`，`D_L = max_{k,l}L_{kl} − min_k L_{kk}`；而 `H_mode` 可在 `U_epi^task=0` 时仍很大。故熵式 VoI 是决策 VoI 的松上界代理，会为无关歧义付费。

**定理 18（COMPASS 严格包含 R69 与 R68）** A99–A101 下，期望任务损失 ≤ R69、安全性 ≥ R69；H=0 或 W<0 时逐指令相同。R68 为二次退化。安全不让步，效率得双重 bonus。

**定理 19（联合路径的 anytime 可行性与分解）** 信息动作经认证且不抢占安全包络时，目标可按 BPP × CTP × JCS 分解；beam search 在 deadline 内返回可行解，超时降级为 R69 贪心解，仍满足全部安全不变式。

**定理 20（交互价值 = 承诺窗口延长）** A102 下 `ΔL(γ) = λ_W·ΔW(γ) + o(ΔW)`。信息动作的第一性价值不是熵降，而是把「必须决定」的时刻往后推或压低承诺损失。可证伪主命题：移除 ΔW（只按熵选问题）应使「不必要交互↑、取消耗时↑、成功率不升」。

## 8. 本轮最大风险

**一句话**：COMPASS-RAS 把「晚一点承诺」当作免费的效率来源，但**承诺窗口 W 是从模型里估出来的**——一旦 W 被高估（安全集算乐观、模式集漏项、走廊跨度过大），系统就会在「其实已经不安全」的时刻继续推迟，把本可由 R69 保守避免的碰撞，变成一次**自信的、可审计的**错误；**路径规划把安全从「阈值」变成了「时间」，而时间是最难估准的状态量**。

**次级风险与缓解**：无限推迟 / 分析瘫痪（硬承诺点 + E310 死锁率 + 到期必承诺）；走廊投毒（C-RAS-WM 认证安全集 + E309 对抗训练）；证据陷阱 / 问题农场（IPG 预声明验证 + 路径级证据纪律）；规划超时击穿实时性（anytime + R69 贪心降级，定理 19）；创新点虚胖（Delta 账本 + E314 审稿式消融，未过记 novelty debt）。
