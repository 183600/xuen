# 第 56 轮（承接第 55 轮 v32 GroundEdge-MemoryNav；灵感循环第 7 轮；本轮灵感：「实时推理」×「同步定位与建图」）

> 第 55 轮已把记忆变成可认证、可检索、可遗忘的资产。本轮把视角推进到「时间」本身：**SLAM 向推理提供位姿与地图信念，推理向 SLAM 提出截止时间与信息需求；二者共享同一个 deadline 与同一份不确定性预算**。核心矛盾：H24：SLAM 是渐近一致但任意时刻都在漂移的，而实时推理要求证书在截止时间前可判定；H25：回环检测会让地图帧发生跳变，旧推理证书可能在「几何正确但帧已失效」的情况下继续被使用，形成「实时幻觉」。

## 0. 直觉与动机

**灵感 1（实时不是更快，而是带截止时间的可判定推理）**
直觉：把推理做快只是工程优化，真正的问题是「这个结论在我要用它的时候还成不成立」。一条在 `t_c` 时刻由位姿信念 `b_t` 与地图 `M_t` 推出的结论，若不携带有效期，就会在机器走到走廊尽头时悄悄失效。于是每个实时结论都应是一张**时间有效证书**：不仅写「结论为真」，还要写「在什么位姿/地图误差内、到什么时候为止为真」。这把实时性从吞吐指标变成**证书在截止时刻的可判定性指标**。

**灵感 2（SLAM 不确定性是推理证书的第一类资源）**
直觉：位姿误差和地图误差不是背景噪声，而是推理能消耗的预算。任务允许的总误差 `Θ` 必须分给位姿、地图、推理近似与云边对齐四本账；SLAM 后端多花算力降低 `ε_p`，就应该允许推理用更粗的界，反之亦然。**预算账本 `ledger` 是实时推理与 SLAM 之间真正的接口**，而不是一个模糊的「定位精度够用」。

**灵感 3（回环是帧纪元事件，不是普通更新）**
直觉：普通里程计更新是连续的小扰动，而回环/重定位会重参数化整张地图，使所有依赖旧帧的几何结论瞬间「坐标系不对」。因此必须引入**帧纪元 `e`**：回环触发 `e→e+1`，旧证书要么经过带残差检验的重绑定 `Reb`，要么直接失效重推。缺少这一步，系统会拿着旧帧的安全结论去执行新帧的动作，这是比单纯漂移更隐蔽的失败。

**灵感 4（推理反向驱动主动 SLAM）**
直觉：当推理发现在多个假设间无法判定（混叠、遮挡、地标歧义），导航与观测本身就是信息获取动作：去回环、换个视角、重访地标。选动作时同时评估**信息价值 `VOI`**、运动代价与「做完后还赶不赶得上 deadline」。这把第 55 轮的主动记忆检索推广为**推理驱动的主动 SLAM**：推理的歧义直接变成 SLAM 的采集指令。

**灵感 5（共享截止时间的调度：SLAM 后端与推理细化争抢同一份算力）**
直觉：在机载算力上，SLAM 后端优化与推理界细化是零和的。合理的策略不是固定分配，而是**按「单位算力换来的证书收紧量/不确定性下降量」动态调度**，并保留 SLAM 后端的最低配额防止定位饿死。实时系统的正确性因此是一个**调度 + 证书**的联合问题，而不是两个模块各自的最优化。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（时间有效推理证书 TVC）**
证书 `C_rt = (φ, b_t, M_t, e, ε_p, ε_m, t_c, τ_v, [L,U], evidence)`：
- `φ` 为结论（如「路径无碰撞」「地标可见」「目标可达」）；
- `b_t`、`M_t` 为生成结论时的位姿信念与地图信念，`e` 为帧纪元；
- `ε_p`、`ε_m` 为位姿与地图误差容限；`t_c` 为生成时刻；
- `τ_v` 为有效期；`[L,U]` 为结论的置信区间。
有效性判定：
```
valid(C_rt, t) ⇔ e = epoch(t) ∧ t ∈ [t_c, t_c+τ_v]
                ∧ σ_p(t) ≤ ε_p ∧ ΔM(t_c,t) ≤ ε_m
```
其中 `τ_v = min{τ_p, τ_m, D - t_c}`，`τ_p = inf{τ : σ_p(t_c+τ) > ε_p}`，`τ_m = inf{τ : ΔM(t_c,t_c+τ) > ε_m}`。
**soundness**：若在 `t` 时刻使用满足 `valid(C_rt,t)` 的证书执行动作，则 `φ` 以概率 `≥ 1-δ(C_rt)` 成立。

**定义 128（帧纪元与证书重绑定 FEM）**
回环/重定位事件 `LC: (e,M) → (e+1, M')` 使纪元自增。旧证书 `C` 的重绑定 `Reb(C,e+1)` 可行当且仅当
```
residual(T_e^{e+1}, supp(C)) ≤ ε_reb ∧ epoch_drift(T_e^{e+1}) ≤ δ_e
```
其中 `T_e^{e+1}` 为旧帧到新帧的变换，`supp(C)` 为结论的几何支撑集。不满足则 `C` 失效并需重推。
定义**陈旧使用率** `stale_rate = |{决策使用 C : ¬valid(C,t)}| / |{决策}|`。

**定义 129（任意时间有界推理 ABR）**
对查询 `q` 与截止时间 `D`，细化序列在第 `k` 步给出区间 `[L_k,U_k]`，满足单调收紧
```
L_{k+1} ≥ L_k，U_{k+1} ≤ U_k，P(φ ∈ [L_k,U_k]) ≥ 1-δ_k
```
给定接受阈 `θ`，判定规则：
```
accept  if L_k ≥ θ
reject  if U_k < θ
abstain otherwise（回退到已认证安全策略）
```
定义任意时间剖面 `k ↦ (U_k-L_k)` 与判定延迟 `t_k`。ABR 的正确性要求**任意 k 的界都 sound**，而非只在收敛时 sound。

**定义 130（SLAM 不确定性预算 SUB）**
任务总容差 `Θ` 分解为四本账：
```
ε_p + ε_m + ε_r + ε_a ≤ Θ
```
分别对应位姿、地图、推理近似与第 54 轮云边对齐误差 `δ_a`。分配算子
```
(ε_p*,ε_m*,ε_r*,ε_a*) = argmin Σ_j cost_j(ε_j)
                          s.t. Σ_j ε_j ≤ Θ, ε_j > 0
```
即按风险权重做带下界的注水分配。SLAM 退化时 `ε_p` 需求上升，必须从 `ε_r`/`ε_a` 借预算；推理若借不到预算，应主动 abstain 而不是伪造紧界。

**定义 131（推理驱动主动 SLAM RAS）**
主动动作集 `A_SLAM`（回环候选、重观测、换视角、重定位）。定义信息价值
```
VOI(a|C) = H(φ|C) − E_{o~a}[H(φ|C,a)]
```
选择
```
a* = argmax_{a∈A_SLAM} [VOI(a|C) − λ_c·c_slam(a)]
     s.t. t_exec(a) + t_reason(k') ≤ D ∧ VOI(a|C) > 0
```
若不存在可行且净收益为正的动作，则回退到被动策略或弃权。

**定义 132（联合截止时间调度与实时联合证书 JDS/RTSC）**
截止时间 `D` 前可用算力 `B_D`。调度 `χ: [0,B_D] → {SLAM_backend, reason_refine, verify}`，每个算力单元返回「不确定性下降量」或「证书收紧量」。目标是最大化
```
P(决策在 D 前完成 ∧ 决策 sound ∧ ledger ≤ Θ)
```
联合证书
```
J_rt = (C_rt, e, [L,U], ledger, χ, fallback, evidence)
```
部署条件：`t_decision ≤ D` 且（`[L,U]` 可判定 或 `fallback` 已认证）且 `Σ ledger ≤ Θ` 且 `e = epoch(t_decision)`。

## 2. 关键算法 伪代码

### IP-127 TVC（Time-Validity Certificate）

```python
def time_valid_cert(phi, belief, map_belief, epoch, eps_p, eps_m, D, t_now):
    tau_p = time_to_exceed(belief.pose_uncertainty, eps_p)
    tau_m = time_to_exceed(map_belief.change_rate, eps_m)
    tau_v = min(tau_p, tau_m, D - t_now)
    return TimeCert(phi, belief, map_belief, epoch,
                    eps_p, eps_m, t_now, tau_v,
                    bounds=belief.bounds(phi), evidence=belief.log)

def cert_valid(c, t, epoch, pose_unc, map_change):
    return (c.epoch == epoch
            and c.t0 <= t <= c.t0 + c.tau_v
            and pose_unc(t) <= c.eps_p
            and map_change(c.t0, t) <= c.eps_m)
```

### IP-128 FEM（Frame-Epoch Manager）

```python
def on_loop_closure(certs, T_old_new, eps_reb, new_epoch):
    kept, dropped = [], []
    for c in certs:
        if residual_support(T_old_new, c.support) <= eps_reb:
            kept.append(rebind(c, T_old_new, new_epoch))
        else:
            dropped.append(c)
    return kept, dropped

def guard_epoch(cert, current_epoch):
    if cert.epoch != current_epoch:
        return ('reject', 'stale_epoch', cert.epoch, current_epoch)
    return ('ok', cert)
```

### IP-129 ABR（Anytime Bounded Reasoning）

```python
def anytime_reason(q, deadline, refiner, theta, eps_width):
    lo, hi = refiner.init_bounds(q)
    k = 0
    while time_left(deadline) > 0:
        if hi - lo <= eps_width or lo >= theta or hi < theta:
            break
        lo, hi = refiner.step(q)
        k += 1
    if lo >= theta:
        return ('accept', lo, hi, k)
    if hi < theta:
        return ('reject', lo, hi, k)
    return ('abstain', lo, hi, k)
```

### IP-130 SUB（SLAM Uncertainty Budgeting）

```python
def allocate_budget(theta, demands, risk_weights):
    eps = {k: demands[k].init for k in demands}
    while sum(eps.values()) > theta:
        j = max(eps, key=lambda k: risk_weights[k] * marginal_gain(k, eps[k]))
        eps[j] = shrink(eps[j])
    return eps

def borrow_for_pose(ledger, pose_need, min_reason):
    if ledger.eps_p < pose_need:
        take = min(pose_need - ledger.eps_p, ledger.eps_r - min_reason)
        ledger.eps_p += take
        ledger.eps_r -= take
    return ledger
```

### IP-131 RAS（Reasoning-Active SLAM）

```python
def reasoning_active_slam(cert, A_slam, deadline, lam_c):
    best = None
    for a in A_slam:
        voi = expected_info_gain(cert.phi, a)
        net = voi - lam_c * slam_cost(a)
        if net <= 0:
            continue
        if exec_time(a) + reason_time(cert) > deadline:
            continue
        if best is None or net > best[0]:
            best = (net, a)
    return best  # None 表示歧义不足以支付主动观测代价
```

### IP-132 JDS（Joint Deadline Scheduler / RTSC）

```python
def joint_deadline_schedule(slam_state, cert, D, budget, fallback):
    chi = []
    while budget > 0 and not decidable(cert):
        opts = [
            ('slam',   marginal_cert_gain_via_slam(slam_state), slam_step_time()),
            ('reason', marginal_tightening(cert),              reason_step_time()),
            ('verify', marginal_soundness(cert),               verify_step_time()),
        ]
        unit = max(opts, key=lambda o: o[1] / o[2])
        chi.append(unit)
        budget -= unit[2]
        apply(unit)
        if cert.epoch != slam_state.epoch:
            cert = rebind_or_invalidate(cert, slam_state)
    ledger_ok = sum(cert.ledger.values()) <= cert.theta
    if decidable(cert) and ledger_ok and time_left(D) >= 0:
        return ('ok', RealtimeCert(cert, chi))
    if fallback.cert is not None and cert_valid(fallback.cert, now(), *guard(fallback)):
        return ('degrade', fallback)
    return ('reject', 'deadline_missed')
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TVC | O(\|supp(C)\|) | O(\|C_rt\|) | 漂移界 sound、有效期保守 |
| FEM | O(\|C\|·\|supp\|) | O(\|C\|) | 重绑定残差可判定、纪元单调 |
| ABR | O(k_ref·T_step) | O(k_ref) | 任意步界均 sound |
| SUB | O(\|stages\|·log(1/δ)) | O(\|stages\|) | 预算闭合、下界不为零 |
| RAS | O(\|A_SLAM\|·(T_VOI+T_cost)) | O(\|A_SLAM\|) | VOI 估计无偏、deadline 可行 |
| JDS | O((B_D/Δt)·log\|opts\|) | O(\|χ\|) | 调度不饿死 SLAM、回退已认证 |

**正确性定理（Real-Time SLAM-Reasoning Soundness）**
承接第 55 轮 (A29)–(A32)；新增假设：
**(A33)** 位姿/地图不确定性增长率有界：`‖dσ_p/dt‖ ≤ v_p`、`‖dΔM/dt‖ ≤ v_m`；
**(A34)** 回环变换在证书支撑集上的残差可判定，满足 `residual ≤ ε_reb` 时重绑定 sound；
**(A35)** ABR 在任意细化步 `k` 的区间界 sound，失效概率 `≤ δ_k`；
**(A36)** 调度开销与抢占有界，SLAM 后端最长饥饿时间 `≤ τ_starve`。
则截止时间前做出正确认证决策的概率满足：
```
P(certified ∧ correct before D)
  ≥ 1 − δ_k − P(τ_v 低估漂移) − P(stale_epoch)
    − P(deadline_missed) − P(ledger > Θ) − P(SLAM 饥饿 > τ_starve)
```
该式表明：**实时推理的失败主要不是「算得慢」，而是「证书在截止时已失效」与「回环后仍用旧帧」**；因此 TVC 是一级闸门，FEM 是二级闸门，ABR+JDS 保证在 deadline 前要么给出可判定区间、要么显式回退。

## 4. 实验设计 E167–E171

| 实验 | 指标 | 目标 |
|---|---|---|
| E167 时间有效性准确度 | 证书失效时刻 vs 实际漂移失效 | 误报有效 ≤ 3%，提前失效 ≥ 90% |
| E168 回环陈旧证书 | `stale_rate` / 重绑定成功率 | stale ≤ 1%，重绑定成功 ≥ 95% |
| E169 任意时间推理质量 | 区间宽度-时间曲线、deadline 判定准确率 | 同等算力下宽度 −25%，准确率 ≥ 95% |
| E170 联合调度 | deadline 内认证决策率、P99 延迟 | 认证率 ≥ 93%，P99 ≤ 100ms |
| E171 推理驱动主动 SLAM | ATE 下降 / 回环次数 / 任务成功率 | ATE −15%，回环 −20%，成功率 +8% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 漂移界乐观导致证书虚假有效 | 高 | 保守漂移界 + 在线校准 + 提前失效 |
| 回环帧跳变使旧证书静默失效 | 高 | 帧纪元强制校验 + 残差重绑定 + 失效重推 |
| 任意时间界因模型误差而不 sound | 高 | 模型误差膨胀 + 留出集校准 + 不可判定即弃权 |
| SLAM 后端被推理饿死 | 中 | 预留最低算力配额 + 抢占上界 |
| deadline 错过时回退不安全 | 中 | 预认证安全回退策略 + 看门狗 |
| 预算账本被局部最优锁死 | 中 | 分层注水 + 周期性重分配 |

## 6. 本轮最大风险

**一句话**：实时推理 × SLAM 的最大风险是「时间有效性证书的漂移乐观假设」与「回环帧跳变」叠加——证书在落笔时 sound，却可能在截止时间前因位姿漂移或回环重参数化而失效；必须以保守漂移界、帧纪元失效与 deadline 看门狗三重护栏，宁可在截止前显式弃权并回退到已认证安全策略，也不把「刚好及时算完」当作「此刻仍然正确」。

```python
            and pose_unc(t) <= c.eps_p
            and map_change(c.t0, t) <= c.eps_m)
```

### IP-128 FEM

```python
def on_loop_closure(certs, T_old_new, eps_reb, new_epoch):
    kept, dropped = [], []
    for c in certs:
        if residual_support(T_old_new, c.support) <= eps_reb:

def guard_epoch(cert, current_epoch):
    if cert.epoch != current_epoch:
        return ('reject', 'stale_epoch', cert.epoch, current_epoch)
    return ('ok', cert)
```

### IP-129 ABR

```python
def anytime_reason(q, deadline, refiner, theta, eps_width):
    lo, hi = refiner.init_bounds(q)
    k = 0
    while time_left(deadline) > 0:
        if hi - lo <= eps_width or lo >= theta or hi < theta:
            break
        lo, hi = refiner.step(q)
        k += 1
    if lo >= theta:
        return ('accept', lo, hi, k)
    if hi < theta:
        return ('reject', lo, hi, k)
    return ('abstain', lo, hi, k)
```

### IP-130 SUB

```python
def allocate_budget(theta, demands, risk_weights):
    eps = {k: demands[k].init for k in demands}
    while sum(eps.values()) > theta:
        j = max(eps, key=lambda k: risk_weights[k] * marginal_gain(k, eps[k]))
        eps[j] = shrink(eps[j])
    return eps

def borrow_for_pose(ledger, pose_need, min_reason):
    if ledger.eps_p < pose_need:
        take = min(pose_need - ledger.eps_p, ledger.eps_r - min_reason)
        ledger.eps_p += take
        ledger.eps_r -= take
    return ledger
```

### IP-131 RAS

```python
def reasoning_active_slam(cert, A_slam, deadline, lam_c):
    best = None
    for a in A_slam:
        voi = expected_info_gain(cert.phi, a)
        net = voi - lam_c * slam_cost(a)
        if net <= 0 or exec_time(a) + reason_time(cert) > deadline:
            continue
        if best is None or net > best[0]:
            best = (net, a)
    return best
```

### IP-132 JDS / RTSC

```python
def joint_deadline_schedule(slam_state, cert, D, budget, fallback):
    chi = []
    while budget > 0 and not decidable(cert):
        opts = [
            ('slam',   marginal_cert_gain_via_slam(slam_state), slam_step_time()),
            ('reason', marginal_tightening(cert),              reason_step_time()),
            ('verify', marginal_soundness(cert),               verify_step_time()),
        ]
        unit = max(opts, key=lambda o: o[1] / o[2])
        chi.append(unit)
        budget -= unit[2]
        apply(unit)
        if cert.epoch != slam_state.epoch:
            cert = rebind_or_invalidate(cert, slam_state)
    ledger_ok = sum(cert.ledger.values()) <= cert.theta
    if decidable(cert) and ledger_ok and time_left(D) >= 0:
        return ('ok', RealtimeCert(cert, chi))
    if fallback.cert is not None and cert_valid(fallback.cert, now(), *guard(fallback)):
        return ('degrade', fallback)
    return ('reject', 'deadline_missed')
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TVC | O(\|supp(C)\|) | O(\|C_rt\|) | 漂移界 sound、有效期保守 |
| FEM | O(\|C\|·\|supp\|) | O(\|C\|) | 重绑定残差可判定、纪元单调 |
| ABR | O(k_ref·T_step) | O(k_ref) | 任意步界 sound |
| SUB | O(\|stages\|·log(1/δ)) | O(\|stages\|) | 预算闭合、下界非零 |
| RAS | O(\|A_SLAM\|·(T_VOI+T_cost)) | O(\|A_SLAM\|) | VOI 无偏、deadline 可行 |
| JDS | O((B_D/Δt)·log\|opts\|) | O(\|χ\|) | 不饿死 SLAM、回退已认证 |

**正确性定理（Real-Time SLAM-Reasoning Soundness）**
承接 (A29)–(A32)；新增 **(A33)** 位姿/地图不确定性增长率有界 `‖dσ_p/dt‖≤v_p`、`‖dΔM/dt‖≤v_m`；**(A34)** 回环变换在支撑集残差可判定，满足 `residual≤ε_reb` 时重绑定 sound；**(A35)** ABR 任意步区间界 sound，失效概率 `≤δ_k`；**(A36)** 调度开销与抢占有界，SLAM 后端最长饥饿 `≤τ_starve`。则：
```
P(certified ∧ correct before D)
  ≥ 1 − δ_k − P(τ_v 低估漂移) − P(stale_epoch)
    − P(deadline_missed) − P(ledger > Θ) − P(SLAM 饥饿 > τ_starve)
```
关键：**先给证书定有效期、回环必换帧、任意步可弃权、算力按证书增益调度**。

## 6. 本轮最大风险

**一句话**：实时推理 × SLAM 的最大风险是「时间有效性证书的漂移乐观假设」与「回环帧跳变」叠加——证书在落笔时 sound，却可能在截止时间前因位姿漂移或回环重参数化而失效；必须以保守漂移界、帧纪元失效与 deadline 看门狗三重护栏，宁可在截止前显式弃权并回退到已认证安全策略，也不把「刚好及时算完」当作「此刻仍然正确」。
