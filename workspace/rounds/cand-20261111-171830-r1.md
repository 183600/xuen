# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感驱动循环第 1 轮；本轮灵感：「末端执行器控制」×「场景理解」）

> 第 54 轮把技能剖面化为动作占用 `α_S`，把技能组合变成动作兼容图，并把云边协同做成「粗规划—细校验—反向解释—重剖分」的闭环。本轮把「向上理解」与「向下执行」真正接起来：场景理解给出物体、关系与可供性，末端执行器控制要求 SE(3) 位姿、力闭合、奇异性与接触可行。核心矛盾：H24：场景理解层面的「可抓/可操作」是语义-几何判断，末端执行器需要的却是**位姿空间上的接触与力可行集**，理解正确不等于能执行；H25：场景理解依赖视角，遮挡（尤其末端执行器自遮挡）会让「看起来可抓」的区域在接触瞬间消失，形成**遮挡驱动的可供性幻觉**；而末端执行器既是执行者又是观察者，制造感知-控制的循环依赖。

## 0. 直觉与动机

**灵感 1（场景理解不是物体标签，而是末端位姿上的可供性场）**
直觉：场景理解常输出 `(物体, 类别, 位姿, 关系)`，但机械臂并不需要「这是一只杯子」，它需要「在哪个 SE(3) 位姿、用哪个末端工具、以什么接触力抓才成立」。因此可供性不应定义在物体中心或图像像素上，而应定义在**末端执行器位姿空间**：
```
β_{tool}(g; B) ∈ [0,1],   g ∈ SE(3)
```
并分解为语义可供性 `β_sem`（该位姿符合操作意图）、几何可供性 `β_geo`（夹持/支撑/插入几何成立）、接触可供性 `β_contact`（摩擦锥与力闭合可满足）。这正好是第 54 轮动作剖面 `α_S` 在**末端位姿空间的对偶**：`α_S` 描述技能占哪些动作，`β` 描述场景允许哪些末端位姿。

**灵感 2（可供性-可达鸿沟 → 把「看懂」与「做到」的差集显式化）**
直觉：即便可供性判断完全正确，它也可能落在关节极限、奇异位形或力矩椭球退化之外。于是定义差集
```
Φ(e,B) = { g | β(g;B) ≥ θ_β } ∩ 𝒦(e)
```
其中 `𝒦(e)` 是末端执行器构型 `e` 下的可达-力可行集。**可供性-可达鸿沟** `Γ = 1 - vol(Φ)/vol({β≥θ_β})` 度量的正是「场景说能做、身体做不到」的比例。纯场景理解指标（affordance accuracy、grasp success in simulation）完全看不见这部分失效，因为它默认了执行器可以到达任何被理解的位姿。

**灵感 3（遮挡与自遮挡 → 可供性幻觉必须按可见性打折）**
直觉：场景理解对未观测区域会做先验补全（amodal completion），但接触恰好发生在被遮挡区域时，补全可能就是幻觉。更棘手的是，末端执行器靠近目标时会自己遮住目标——**观察者遮挡被观察对象**，越接近越看不见。因此每个可供性断言都必须附带可见性证据与后验下界：
```
β_LCB(g; v) = β̄(g) - z_δ · σ(g, v)
```
只有当 `β_LCB ≥ θ_β` 时才接受；「看不见」必须被显式地区分于「不存在」和「存在」，而不是被先验悄悄填成「存在」。

**灵感 4（主动感知与末端运动联合设计 → 每单位控制代价的信息增益）**
直觉：要看清楚就得动，动又改变场景理解，这是闭环。于是「下一步看哪里」与「下一步怎么动」不应分属两个模块，而应统一为一个以控制代价归一的信息增益目标：
```
v* = argmax_{v ∈ 𝒦_safe(e)}  IG(β; v) / (λ_m·cost_move(v) + λ_t·τ(v))
```
但主动感知可能为了信息而进入危险位形，因此候选视角必须约束在安全可达域 `𝒦_safe` 内，并把「信息不足」作为**推迟抓取、继续观察**的合法动作，而不是盲抓。

**灵感 5（接触是场景理解的传感器 → 触觉残差驱动场景修订）**
直觉：场景理解不只在视觉里。接触时的实际力/力矩与基于场景信念预测的力/力矩之差
```
d_c = || w_meas - w_pred(B) ||_{Σ_w}
```
是一个高信息量的**场景证伪信号**：若信念预测「平面支撑」却测得明显点接触扭矩，场景图就是错的。把 `d_c` 作为贝叶斯更新输入，就形成「视觉理解—末端控制—触觉证伪—场景修订」闭环。末端执行器由此从被动执行者变成主动的**场景探针**。

**灵感 6（场景-末端联合证书 → 三级接地的金字塔扩展）**
直觉：在第 54 轮的动作-鲁棒双证书 `J` 之上叠加**场景可供性层 `𝔹`**：`𝔹_0` 场景观测证据，`𝔹_1` 可供性场 `β`，`𝔹_2` 可达-力可行交集 `Φ`，`𝔹_3` 任务级可供性序列。跨层传递证书必须同时携带 `β` 场、可达证书、可见性折扣与接触见证，形成**场景-末端-力矩三级接地**，而不是三段各自正确、拼起来失效的流水线。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（场景信念）**
场景信念 `B_t = (𝒢_t, Σ_t, V_t)`：`𝒢_t` 为场景图（物体、位姿、几何、关系），`Σ_t` 为物体位姿与几何的认知协方差场，`V_t` 为视角集合下的可见性场。可供性场与证书都以 `B_t` 为条件，而不是以单帧点云为条件。

**定义 122（末端执行器构型与可达-力可行集）**
末端执行器构型 `e = (g, q, tool)`，`g ∈ SE(3)` 为末端位姿，`q` 为关节配置，`tool` 为工具/夹爪形态。可达-力可行集
```
𝒦(e) = { g | IK(g,q) ≠ ∅ ∧ σ_min(J(q)) ≥ σ_min^0 ∧ w(g) ∈ 𝒲(e) }
```
其中 `σ_min(J)` 为雅可比最小奇异值，`𝒲(e)` 为执行器力矩极限下的可行接触力集合。`𝒦` 同时编码运动学可达与力可行，二者缺一都会把「能碰到」误当作「能操作」。

**定义 123（可供性场）**
工具 `tool` 在场景信念 `B` 下的可供性场
```
β_{tool}(g; B) = min( β_sem(g; 𝒢), β_geo(g; B, tool), β_contact(g; B, tool) )
```
`β_sem` 为操作意图匹配度，`β_geo` 为几何抓取质量（力闭合、`ε` 度量、支撑多边形），`β_contact` 为摩擦锥余量归一值。采用 `min` 而非加权平均，是为了让任一维度的硬约束不被其他维度的高分掩盖。

**定义 124（可供性-可达交集与鸿沟）**
```
Φ(e,B) = { g | β_{tool}(g;B) ≥ θ_β } ∩ 𝒦(e)
Γ(e,B) = 1 - vol(Φ(e,B)) / vol({ g | β_{tool}(g;B) ≥ θ_β })
```
当分母为零时约定 `Γ=1`（无处可供性即完全不可执行）。`Γ` 是**理解-执行鸿沟**：纯理解侧不可见，纯控制侧也不会报告，只有把两个空间求交才暴露。

**定义 125（可见性折扣与遮挡幻觉）**
对视角 `v`，可见性 `vis(g,v) ∈ [0,1]`（含末端自遮挡掩码）。后验
```
β̄(g) = E[β(g;B)],   σ(g,v) = sqrt( σ_epi(g)^2 + η^2·(1-vis(g,v))^2 )
β_LCB(g;v) = β̄(g) - z_δ·σ(g,v)
```
若可供性断言的主要证据落在隐藏集 `H(v)` 内，或 `β_LCB < θ_β`，称该断言**遮挡脆弱**。遮挡幻觉率定义为：被接受（`β_LCB≥θ_β`）但在真实接触中失败的比例。

**定义 126（接触残差与场景修订算子）**
接触力/力矩残差
```
d_c(g) = || w_meas(g) - w_pred(g; B) ||_{Σ_w}
```
若 `d_c > ε_c`，触发场景修订 `B' = Update(B, (g, w_meas, d_c))`，并生成**接触见证** `ω = (g, w_meas, w_pred, d_c, ΔB)`。`ΔB` 记录被修订的物体位姿/几何/接触模式，使「为什么改了场景」可回溯。

**定义 127（场景-末端联合证书）**
```
J_SE = ( β_core, Φ_cert, Γ, σ_scene, vis_margin, C_contact, tool, evidence )
```
- `β_core ⊆ Φ` 为在可见性与不确定性折扣后仍高于 `θ_β` 的核心可供性位姿集；
- `Φ_cert` 为可达-力可行证书（含 `σ_min(J)`、`𝒲(e)` 余量）；
- `Γ` 为可供性-可达鸿沟；`σ_scene` 为场景信念不确定性；
- `vis_margin = min_{g∈β_core} β_LCB(g) - θ_β`；
- `C_contact` 为接触一致性声明；`evidence` 至少含遮挡见证与一条接触见证。
若 `dom(T)=in`、`Γ ≤ Θ_Γ`、`vis_margin ≥ 0`、且在接触密集任务中 `C_contact` 成立，则称 `J_SE` **三级接地成立**，可部署。

## 2. 关键算法 伪代码

### IP-121 AFE（Affordance Field Estimation）

```python
def affordance_field(scene_belief, tool, pose_grid, theta_beta):
    beta = {}
    for g in pose_grid:
        sem = semantic_affordance(g, scene_belief.graph)
        geo = geometric_grasp_quality(g, scene_belief.geometry, tool)
        con = contact_cone_margin(g, scene_belief, tool)
        value = min(sem, geo, con)
        sigma = sqrt(scene_belief.sigma(g)**2 + tool.sigma**2)
        beta[g] = Affordance(value, sigma, evidence=scene_belief.evidence(g))
    return beta
```

### IP-122 ARG（Affordance-Reachability Gap）

```python
def affordance_reachability_gap(beta, e, theta_beta, sigma_min):
    A = {g for g, b in beta.items() if b.value >= theta_beta}
    if not A:
        return 1.0, set()
    K = set()
    for g in A:
        q = inverse_kinematics(g, e)
        if q is not None and min_singular(sigma(J(q))) >= sigma_min:
            if contact_force_in_limits(g, e):
                K.add(g)
    Gamma = 1.0 - volume(K) / volume(A)
    return Gamma, A - K      # 鸿沟位姿：语义可行、身体不可行
```

### IP-123 OAH（Occlusion-Aware Hallucination guard）

```python
def occlusion_aware_accept(beta, g, viewpoint, z_delta, theta_beta, vis_min):
    b = beta[g]
    vis = visibility(g, viewpoint)            # 含末端自遮挡掩码
    sigma = sqrt(b.sigma**2 + ETA**2 * (1.0 - vis)**2)
    lcb = b.value - z_delta * sigma
    hidden_primary = b.evidence.primary_region in hidden_set(viewpoint)
    if hidden_primary or vis < vis_min:
        return ('defer', OcclusionWitness(g, viewpoint, vis, lcb))
    return ('accept' if lcb >= theta_beta else 'reject', lcb, sigma)
```

### IP-124 ICE（Information-per-Control-cost Exploration）

```python
def next_best_view_control(beta, e, candidate_views, safe_set, lambda_m, lambda_t):
    best = None
    for v in candidate_views:
        if v not in safe_set:
            continue
        ig = expected_info_gain(beta, v)      # 对 β 后验熵的期望下降
        cost = lambda_m * cost_move(e, v) + lambda_t * time_cost(v)
        score = ig / max(cost, EPS)
        if best is None or score > best.score:
            best = ViewAction(v, score, ig, cost)
    return best if best and best.ig >= IG_MIN else DeferAndObserve()
```

### IP-125 TSU（Tactile Scene Update）

```python
def tactile_scene_update(B, g, w_meas, eps_c):
    w_pred = predict_wrench(B, g)
    d_c = mahalanobis(w_meas - w_pred, B.sigma_w)
    if d_c <= eps_c:
        return B, None
    B2 = bayes_update_scene(B, evidence=ContactEvidence(g, w_meas, d_c))
    delta = scene_diff(B, B2)
    witness = ContactWitness(g, w_meas, w_pred, d_c, delta)
    return B2, witness
```

### IP-126 SEC（Scene-EndEffector Joint Certificate）

```python
def scene_end_joint_cert(skill_seq, B, tool, e, theta_beta, theta_gamma,
                         z_delta, theta_gamma_budget, contact_rich):
    grid = union_pose_grid([s.alpha for s in skill_seq])   # 第54轮 α_S 支撑集
    beta = affordance_field(B, tool, grid, theta_beta)
    Gamma, gap_poses = affordance_reachability_gap(beta, e, theta_beta, SIGMA_MIN)
    if Gamma > theta_gamma_budget:
        return ('reject', 'affordance_reachability_gap', Gamma, gap_poses)

    accepted, deferred, witnesses = {}, [], []
    for g, _ in beta.items():
        status, out = occlusion_aware_accept(beta, g, B.viewpoint, z_delta,
                                             theta_beta, VIS_MIN)
        if status == 'accept':
            accepted[g] = out
        elif status == 'defer':
            deferred.append(out)
            witnesses.append(out)

    if not accepted:
        return ('reject', 'no_visible_affordance', deferred)
    vis_margin = min(accepted.values()) - theta_beta

    contact_ok = True
    if contact_rich:
        contact_ok = contact_consistency(skill_seq, B, tool)
        if not contact_ok:
            return ('reject', 'contact_inconsistent', witnesses)

    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    mu_env = min(torque_margin_envelope(s, C_env) for s in skill_seq)
    if min(rho_comp.values()) < RHO_MIN or mu_env < MU_MIN:
        return ('reject', 'physical_floor', rho_comp, mu_env)

    return ('ok', J_SE(beta_core=accepted, Phi_cert=reach_cert(e),
                       Gamma=Gamma, sigma_scene=B.sigma_summary(),
                       vis_margin=vis_margin, C_contact=contact_ok,
                       tool=tool, evidence=witnesses))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| AFE | O(|G_pose|·(C_sem+C_geo+C_con)) | O(|G_pose|) | 可供性分解完备、标定一致 |
| ARG | O(|A|·(T_IK+T_force)) | O(|A|) | IK/奇异/力可行判定 sound |
| OAH | O(|G_pose|·C_vis) | O(|G_pose|) | 可见性模型保守、自遮挡被计入 |
| ICE | O(|V|·C_IG) | O(|V|) | 信息增益估计无偏、候选在安全域 |
| TSU | O(T_contact·|J|) | O(|ΔB|) | 残差协方差标定、更新可回溯 |
| SEC | O(|G_pose|·(T_IK+C_vis)+|S|·T_rollout) | O(|G_pose|) | 四类前置条件联合闭合 |

**正确性定理（Scene-EndEffector Triple-Grounding Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** 可供性估计器在可见区域校准：`P(β_real ≥ θ_β | β_LCB ≥ θ_β) ≥ 1-δ_β`；**(A30)** 可见性模型保守，即 `∀g∈H(v)` 的不确定性已被 `σ(g,v)` 覆盖；**(A31)** 接触残差有界 `d_c ≤ ε_c`，否则触发的修订在 `τ_rev` 内收敛；**(A32)** `𝒦(e)` 的 IK/奇异/力可行判定误差可忽略。
则携带 `J_SE` 的部署满足
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(Γ > Θ_Γ)
            - δ_β - P(d_c > ε_c) - P(𝒦 判定错误)
```
且**失败模式可分解**：`P(Γ>Θ_Γ)` 对应「理解到但做不到」，`δ_β` 对应「遮挡幻觉被当成真」，`P(d_c>ε_c)` 对应「场景先验被接触证伪且未及时修订」。三者分别由 ARG、OAH、TSU 独立拦截，证书拒绝时可归因到具体层。

**引理（鸿沟-成功率上界）**
若 `Γ(e,B) > Θ_Γ`，则对任意只依赖 `β` 而忽略 `𝒦(e)` 的规划器，其可达成功位姿占比不超过 `1-Γ`。故「可供性准确率高但成功率低」不是数据噪声，而是 `Γ` 的结构性下界。

**引理（自遮挡-信息权衡）**
在可见性单调假设下，推迟抓取并执行一次 `ICE` 视角最多将 `β_LCB` 的期望提升 `IG_max`，但消耗 `cost_move`；因此 `defer` 是当且仅当 `IG_max/(λ_m cost_move) > ΔP_success` 时的最优动作。这给「看还是抓」提供了可计算的判据，而非拍脑袋阈值。

## 4. 实验设计 E162–E168

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 可供性场准确度 | `|β - β_real|` 与位姿级 IoU | MAE ≤ 0.06，IoU ≥ 0.80 |
| E163 鸿沟预测 | `Γ` 预测 vs 真实不可执行率 | 校准误差 ≤ 0.05，AUROC ≥ 0.85 |
| E164 遮挡幻觉检出 | 遮挡注入下的 precision / recall / 误抓率 | recall ≥ 90%，误抓率 −≥ 50% |
| E165 主动感知效率 | 成功率 / 移动代价 / 视角数 | 视角数 −≥ 30%，成功率不降 |
| E166 接触驱动场景修订 | 错误场景信念的恢复时间与成功率 | 恢复 ≤ 2 个控制周期，成功率 +≥ 15% |

**消融设计**：E163/E167 分别去掉 ARG、OAH、TSU，验证三个算子是否各自拦截对应的失败模式；特别检查去掉 OAH 后 E162 指标不降但真实成功率显著下降的「纸面理解」现象。

## 6. 本轮最大风险

### IP-121 AFE

```python
def affordance_field(scene_belief, tool, pose_grid, theta_beta):
    beta = {}
    for g in pose_grid:
        sem = semantic_affordance(g, scene_belief.graph)
        geo = geometric_grasp_quality(g, scene_belief.geometry, tool)
        con = contact_cone_margin(g, scene_belief, tool)
        value = min(sem, geo, con)          # 硬约束不被高分维度掩盖
        sigma = sqrt(scene_belief.sigma(g)**2 + tool.sigma**2)
        beta[g] = Affordance(value, sigma, evidence=scene_belief.evidence(g))
    return beta

def pose_grid_from_skills(skill_seq, step=POSE_STEP):

    return stratified_sample(support, step)
```

### IP-122 ARG

```python
def affordance_reachability_gap(beta, e, theta_beta, sigma_min):
    A = {g for g, b in beta.items() if b.value >= theta_beta}
    if not A:
        return 1.0, set()
    K = set()
    for g in A:
        q = inverse_kinematics(g, e)
        if q is None:
            continue
        if min_singular(sigma(jacobian(q))) < sigma_min:
            continue
        if not contact_force_in_limits(g, e):   # 力椭球 / 力矩极限
            continue
        K.add(g)
    Gamma = 1.0 - volume(K) / volume(A)
    return Gamma, A - K          # 鸿沟位姿：语义可行、身体不可行
```

### IP-123 OAH

```python
def occlusion_aware_accept(beta, g, viewpoint, z_delta, theta_beta, vis_min):
    b = beta[g]
    vis = visibility(g, viewpoint)             # 含末端自遮挡掩码
    sigma = sqrt(b.sigma**2 + ETA**2 * (1.0 - vis)**2)
    lcb = b.value - z_delta * sigma
    hidden_primary = b.evidence.primary_region in hidden_set(viewpoint)
    if hidden_primary or vis < vis_min:
        return ('defer', OcclusionWitness(g, viewpoint, vis, lcb))
    return ('accept' if lcb >= theta_beta else 'reject', lcb, sigma)

def hidden_set(viewpoint):
    # 由深度/占据栅格与执行器自身几何求差集
    return frustum(viewpoint) - observable(viewpoint)
```

### IP-124 ICE

```python
def next_best_view_control(beta, e, candidate_views, safe_set,
                           lambda_m, lambda_t):
    best = None
    for v in candidate_views:
        if v not in safe_set:                 # 安全可达域硬约束
            continue
        ig = expected_info_gain(beta, v)      # 对 β 后验熵的期望下降

        score = ig / max(cost, EPS)
        if best is None or score > best.score:
            best = ViewAction(v, score, ig, cost)

        return DeferAndObserve()              # 信息不足：先看不抓
    return best
```

```python
def tactile_scene_update(B, g, w_meas, eps_c):
```

### IP-126 SEC

```python
def scene_end_joint_cert(skill_seq, B, tool, e, theta_beta, theta_gamma_budget,
                         z_delta, contact_rich):
    grid = pose_grid_from_skills(skill_seq)
    beta = affordance_field(B, tool, grid, theta_beta)
    Gamma, gap_poses = affordance_reachability_gap(beta, e, theta_beta, SIGMA_MIN)
    if Gamma > theta_gamma_budget:
        return ('reject', 'affordance_reachability_gap', Gamma, gap_poses)

    for g in beta:

        if status == 'accept':

        elif status == 'defer':
            deferred.append(out); witnesses.append(out)
    if not accepted:
        return ('reject', 'no_visible_affordance', deferred)

    contact_ok = True
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AFE | O(|G_pose|·(C_sem+C_geo+C_con)) | O(|G_pose|) | 分解完备、标定一致、min 硬约束 |
| ARG | O(|A|·(T_IK+T_force)) | O(|A|) | IK/奇异/力可行判定 sound |
| OAH | O(|G_pose|·C_vis) | O(|G_pose|) | 可见性保守、自遮挡计入 |
| ICE | O(|V|·C_IG) | O(|V|) | 信息增益无偏、候选在安全域 |
| TSU | O(T_contact·|J|) | O(|ΔB|) | 残差协方差标定、更新可回溯 |
| SEC | O(|G_pose|·(T_IK+C_vis)+|S|·T_rollout) | O(|G_pose|) | 四类前置条件联合闭合 |

**正确性定理（Scene-EndEffector Triple-Grounding Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** 可供性估计器在可见区域校准，`P(β_real≥θ_β | β_LCB≥θ_β) ≥ 1-δ_β`；**(A30)** 可见性模型保守，隐藏区不确定性被 `σ(g,v)` 覆盖；**(A31)** 接触残差有界 `d_c ≤ ε_c`，否则修订在 `τ_rev` 内收敛；**(A32)** `𝒦(e)` 的 IK/奇异/力可行判定误差可忽略。
则携带 `J_SE` 的部署：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(Γ > Θ_Γ)
            - δ_β - P(d_c > ε_c) - P(𝒦 判定错误)
```
失败模式可分解：`P(Γ>Θ_Γ)` = 「理解到但做不到」；`δ_β` = 「遮挡幻觉被当真」；`P(d_c>ε_c)` = 「场景先验被接触证伪却未及时修订」。三者分别由 ARG、OAH、TSU 拦截，证书拒绝可归因到具体层。

**引理 1（鸿沟-成功率上界）**
若 `Γ(e,B) > Θ_Γ`，则任何只依赖 `β`、忽略 `𝒦(e)` 的规划器，其可达成功位姿占比不超过 `1-Γ`。故「可供性准确率高而成功率低」是 `Γ` 的结构性下界，而非数据噪声。

**引理 2（自遮挡-信息权衡）**
在可见性单调假设下，执行一次 `ICE` 视角至多把 `β_LCB` 的期望提升 `IG_max`，代价为 `λ_m·cost_move`。因此 `defer` 优于立即抓取当且仅当
```
IG_max / (λ_m·cost_move) > ΔP_success
```
这给「先看还是先抓」一个可计算判据，而不是硬编码阈值。

**推论（三级接地的必要性）**
若只签发 `β` 证书（理解层）而不附带 `Φ`（执行层）与 `C_contact`（接触层），则存在场景使 `β` 全高、`Γ=1`，证书仍会签发但在真实末端完全不可执行。故 `J_SE` 的三层缺一不可。
