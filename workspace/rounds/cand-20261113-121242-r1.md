# 第 68 轮（承接第 67 轮「PACE 能量-原型闭环」IP-234~243；灵感循环第 5 轮；本轮灵感：「多机器人协作」×「比赛策略」）

> PACE 把「安全证书」变成「能量注解证书」，把「闭环设计」变成「能量约束下的快速原型搜索」。但 PACE 仍默认一件从未被检验的事：**环境是非策略性的**——故障、情绪、能耗都是外生随机过程，可以用一个固定证书去覆盖。多机器人竞赛打破了这个默认：最大的不确定性不是传感器噪声，而是**队友与对手的策略**；它们会学习、会隐藏、会专门针对你的证书接口和保真阶梯设计攻击。单机证书因此第一次遇到「组合失效」与「对抗失效」的双重压力。
>
> 本轮的核心命题：
>
> **把「能量注解证书」升级为「策略注解证书」，把「能量约束下的原型搜索」升级为「证书可行域上的竞合策略博弈」：ARENA（Adversarial-robust Equilibrium with Negotiated Assurance，对抗鲁棒的协商保证均衡）。**
>
> ARENA 问的不是「单个机器人安不安全」，也不是「一个团队省不省电」，而是：**当 N 个机器人共享预算、互相依赖、并且其中一部分在与你竞争时，哪一组策略既落在团队证书的可行域里，又能达到一个可证明的（近似）均衡？**

## 0. 直觉与动机

**灵感 1（多机器人协作 → 团队证书不是合取）**
直觉：三个各自 99% 安全的机器人，团队安全既可能是 97%（独立、联合界），也可能是 90%（共享感知/通信的共因故障），甚至 99.7%（通过冗余互补）。因此团队证书不是 `AND(J_1, …, J_n)`；真正决定它的是**接口**与**共因**。多机器人协作要求每台机器人把自己的证书写成 assume-guarantee 契约：在队友保证 X 的假设下，我保证 Y。团队证书于是变成一个可组合的代数对象 `⊕`，而不是一叠并列的单机证书。
更尖锐的是：**协作越紧，接口假设越强，证书越容易被队友或对手的一次违约同时击穿**。团队证书的安全性，本质上由「最弱的接口 + 最隐蔽的共因割集」决定，而不是由平均单机安全决定。

**灵感 2（比赛策略 → 策略是新的隐变量）**
直觉：比赛中你不知道对手下一步，但你能观测轨迹、资源占用、承诺节奏——这就是**策略签名**。VISTA 用残差签名归因「哪一层坏了」，RAS 用表情签名归因「主体什么态度」，ARENA 用策略签名归因「对手属于哪一类打法」。三者同构：`签名 → 后验 → 认证响应`。
于是策略归因可以直接复用 FIR 的贝叶斯机器，只是假设空间从故障集 `ℋ_RAS` 换成对手类型集 `Θ`。这一步不是类比修辞，而是**同一推断问题的第三次实例化**：当环境开始有意图，安全系统必须把「意图」也纳入可辨识假设。

**灵感 3（协作 × 竞争 → 安全是公共品，证书本身是策略）**
直觉：团队安全一旦发生共因故障，所有机器人一起受损；但为安全花能量（降速、增加冗余、升保真）的成本却由个体承担。竞争会系统性地把能量从安全转向进攻——这是「安全搭便车」。更微妙的是，**证书本身也成了策略**：你可以选择一个容易认证但得分低的保守策略，也可以选择一个得分高但证书脆弱的激进策略。ARENA 必须在证书可行域内求均衡，而不是先求均衡再做安全检查；否则会出现「均衡策略根本无法认证」的空洞。

**灵感 4（PACE 的接口 → 侦察预算与对抗保真阶梯）**
直觉：PACE 的 EIG/焦耳原本买的是「仿真是否可信」；在竞赛里，它买的是「对手是哪种类型」。低保真 = 本地仿真/自博弈；中保真 = 联赛回放；高保真 = 真实热身赛。快速原型从「验证证书」升级为「侦察对手」。同一个次模信息增益理论，目标从仿真误差 `ε_sim` 变成对手类型 `θ`，保真阶梯变成**对抗保真阶梯**。
这条接口让第 68 轮不是另起炉灶：ARENA 直接复用 PACE 的能量账本、EIG/焦耳调度与证伪纪律，只是把「原型」换成「scrimmage/热身赛」。

**灵感 5（三级归因与退化链）**
直觉：VISTA 归因故障层，RAS 归因意图，ARENA 归因策略。ARENA 不是另起一套栈，而是把同一台「签名→后验→认证」引擎推到策略空间。退化链保证连续性：`N=1 ⇒ ARENA ≡ PACE`；`κ=0`（纯合作）⇒ PACE 团队 + 证书代数；`B_team→∞` ⇒ 完整博弈均衡；`κ↑` ⇒ 认证时域必须缩短。

## 1. 形式化定义（增量：定义 261–276）

- **定义 261（ARENA 总览）** `ARENA = (TCA, SIG, CSG, CSE, OAA, SAF, ACB, DCR, CGA, LCR)`：团队证书代数、策略接口图、认证策略博弈、认证策略均衡、对手归因与适应、策略感知证伪（侦察）、保证信用机制、漂移感知证书刷新、认证目标拍卖、联赛证书库。不变式：策略选择、证书融合、均衡计算、信用清算只在语义流；实时流只做角色派发、漂移检测、认证前缀早停，零学习写操作。
- **定义 262（策略与策略组合）** 机器人 `i` 的策略 `σ_i = (ρ_i, π_i, h_i, b_i)`：角色 `ρ_i ∈ R`、策略映射 `π_i: O_i × Θ_i → Δ(A_i)`、承诺块长度 `h_i`、能量投标 `b_i`。策略组合 `σ = (σ_1,…,σ_n) ∈ Σ = ×_i Σ_i`，每个 `Σ_i` 为有限策略集。
- **定义 263（策略接口契约）** 机器人 `i` 的证书契约 `C_i = (A_i, G_i)`，`A_i` 为对队友/环境的假设，`G_i` 为自身保证。对每条交互边 `(i,j) ∈ E_I` 要求接口相容：
  `G_{i→j} ⊆ A_{j→i}`，违约事件记 `I_{ij} = {G_{i→j} \nsubseteq A_{j→i}}`。
- **定义 264（团队证书代数 TCA）**
  `J_team = ⊕_{i=1}^n J_PACE_i = ((J_PACE_i)_i, (W_{ij})_{(i,j)∈E_I}, Cut, B_team)`。
  `Valid(J_team) ⇔ (∀i Valid(J_PACE_i)) ∧ (∀(i,j)∈E_I: G_{i→j}⊆A_{j→i}) ∧ (∀C∈Cut: ∃ witness) ∧ Σ_i b_i ≤ B_team`。
  组合安全上界：`P(V_team) ≤ Σ_i P(V_i) + Σ_{(i,j)∈E_I} P(I_{ij}) + Σ_{C∈Cut} P(C)`。
- **定义 265（策略签名）** `s(σ) = (v_motion, v_resource, v_commit) ∈ ℝ^d`，分别刻画运动模式、资源占用轨迹、承诺节奏；度量 `δ(s,s')` 为加权 Mahalanobis 距离。策略归因与漂移检测共用该签名。
- **定义 266（认证策略博弈 CSG）** 博弈 `G = (N, {Σ_i}, Φ_cert, {u_i}, B_team)`，其中
  `Φ_cert(σ) = 1 ⇔ Valid(J_ARENA(σ)) ∧ Σ_i b_i ≤ B_team`，
  `u_i(σ) = score_i(σ) - c_E b_i - c_R·risk_i(σ) - c_D·drift_i(σ)`，
  证书可行域 `Σ_cert = {σ ∈ Σ : Φ_cert(σ) = 1}`。
- **定义 267（认证策略均衡 CSE）** 组合 `σ*` 是 `ε-CSE`，若对每个 `i` 及任一满足 `(σ'_i, σ*_{-i}) ∈ Σ_cert` 的偏离 `σ'_i`：
  `u_i(σ*) ≥ u_i(σ'_i, σ*_{-i}) - ε`。
  记可行偏离集 `D_i(σ_{-i}) = {σ_i : (σ_i, σ_{-i}) ∈ Σ_cert}`；安全性是硬约束，不是罚项。
- **定义 268（认证目标拍卖 CGA）** 角色/子目标分配为拍卖：投标 `bid_i = (ρ_i, b_i, J_i^{ρ})`，分配 `α: R → N`，
  `α* = argmax_α Σ_i score_i(α)  s.t.  Valid(⊕_i J_i^{ρ_i}) ∧ Σ_i b_i ≤ B_team`；
  支付为关键值（second-price）加保证信用。当可行角色分配构成拟阵时，认证 VCG 分配激励相容且安全。
- **定义 269（对手类型与贝叶斯策略博弈）** 对手 `j` 类型 `θ_j ∈ Θ_j`，信念 `b_j(θ)`。贝叶斯期望效用
  `U_i(σ; b) = Σ_θ b(θ) u_i(σ, θ)`；策略博弈在信念上求解，而非假设单一确定类型。
- **定义 270（策略归因后验）** `P(θ | s_{1:t}) ∝ p(s_{1:t}|θ)·P(θ)`，签名似然取
  `p(s|θ) = exp(-δ(s, s̄_θ)^2 / (2σ_s^2))`。这是 FIR 故障归因在策略空间的对偶实例。
- **定义 271（策略探测的 EIG/焦耳）** `EIGS_θ(x) = I(θ; y_x) / E_cost(x)`，`x* = argmax_x EIGS_θ(x)`。探测阶梯 `T_1 ≺ … ≺ T_L` 的保真度为 `φ_j`，依次为本地仿真、自博弈、联赛回放、真实热身赛；每次探测计入 PACE 的 `E_proto`。
- **定义 272（安全公共品与搭便车）** 安全支出 `c = (c_1,…,c_n)`，可加安全 `S(c) = Σ_i s_i(c_i)`（或最弱环节 `min_i s_i(c_i)`）。个体可占有比例 `α_i ∈ (0,1]`，私人收益 `α_i S(c) - c_i`。无机制时 Nash 条件 `α_i s_i'(c_i^NE)=1`，社会最优 `s_i'(c_i^OPT)=1`，故 `c_i^NE < c_i^OPT`——竞争导致安全系统性供给不足。
- **定义 273（保证信用机制 ACB）** 每台机器人质押保证信用 `a_i`；发生团队级共因或接口违约时按未覆盖暴露扣罚。Pigouvian 转移
  `t_i(c) = (1-α_i)·∂S/∂c_i = (1-α_i) s_i'(c_i)`，
  个体目标变为 `α_i S(c) - c_i + t_i(c)`，一阶条件回到 `s_i'(c_i)=1`。若罚金对未覆盖暴露线性，则真实上报 `c_i` 为占优策略。
- **定义 274（策略漂移与证书陈旧度）** `d_drift(t) = δ(s_t, s_cert)`；对手信念漂移 `d_opp(t) = δ(b_t(θ), b_cert(θ))`。若 `max(d_drift, d_opp) > τ_drift`，则 `J_ARENA` 标记为陈旧，必须重认证或降级。
- **定义 275（团队认证策略前缀与 J_ARENA）**
  `k_ARENA = min( min_i k_PACE_i, k_if, k_drift, k_sync )`，
  其中 `k_if` 为接口契约保持一致的块数，`k_drift ≤ τ_drift/(v(κ)Δt)`，`k_sync` 为分布式承诺屏障对齐块。
  `J_ARENA = (⊕_i J_PACE_i, σ*, ε_gap, credit_ledger, drift_vec, b_opp, κ, arena_ver)`。
  `Valid(J_ARENA) ⇔ Valid(J_team) ∧ ε_gap ≤ ε_max ∧ max_i d_drift,i ≤ τ_drift ∧ Σ_i b_i ≤ B_team`。
- **定义 276（退化链）** `N=1 ⇒ ARENA ≡ PACE`；`κ=0 ⇒` 纯合作 `(TCA, CGA)`，无对抗均衡；`B_team→∞ ⇒` 完整 CSE；`κ↑ ⇒ k_ARENA` 单调不增（认证刷新更频繁）。ARENA 是连接「单机证书」「合作团队」「对抗博弈」三端的一族单调插值。

## 2. 关键算法骨架

```python
# ARENA 主循环：先建接口与候选，再侦察对手，最后在证书可行域内求均衡
def ARENA_match(M, task, obs, B_team, kappa):
    Sigma, E_I = M.sig.build(task, M.library)          # 策略组合 + 接口图
    opp = M.oaa.prior()
    for probe in M.saf.schedule(Sigma, opp, M.B_scout): # EIG/焦耳侦察
        y = M.scrimmage.run(probe)                     # sim / self-play / real
        opp = M.oaa.update(opp, y)

    cand = []
    for sigma in product(*Sigma):
        Jt = M.tca.compose(sigma, M.pace_certs(sigma)) # 团队证书代数
        if Valid(Jt) and sum(s.b for s in sigma) <= B_team:
            cand.append((sigma, Jt))
    if not cand:
        return M.mfc_team.fallback(), None             # 无证书可行策略 -> MFC 团队

    sigma_star, eps = M.cse.solve(cand, opp, kappa)    # 可行域内 no-regret CSE
    credits = M.acb.clear(sigma_star, B_team)          # Pigouvian 信用清算
    k = M.arena_prefix(sigma_star)                     # k_ARENA
    while not M.done:
        obs = M.step(sigma_star[:k])
        if M.dcr.drift(obs, sigma_star) > M.tau_drift:
            M.spent += M.epu.used
            return ARENA_match(M, task, obs, B_team - M.spent, kappa)
    return sigma_star, k, credits, M.jarena()


class TeamCertificateAlgebra:
    def compose(self, sigma, certs):
        Jt = TeamCert(certs)
        for (i, j) in self.E_I:
            if not self.implies(sigma[i].G_to[j], sigma[j].A_from[i]):
                return InvalidCert(reason=f"interface {i}->{j}")
        for cut in self.min_cuts(sigma):
            if not any(c.witnesses(cut) for c in certs):
                return InvalidCert(reason=f"uncovered cut {cut}")
        return Jt


class OpponentAttribution:
    def update(self, belief, y):
        for theta in belief:
            belief[theta] *= self.signature_likelihood(y.s, theta)
        return normalize(belief)


class CertifiedEquilibrium:
    def solve(self, cand, opp, kappa, T=10_000):
        # 在可行偏离集 D_i(sigma_-i) 上做投影 no-regret
        w = initialize_uniform(cand)
        for t in range(T):
            sigma = sample_profile(w)
            for i in range(self.n):
                for sigma_i in self.feasible_deviations(cand, sigma, i):
                    payoff = self.U_i(sigma_i, sigma, opp)
                    w[i][sigma_i] *= exp(self.eta * payoff)
        return best_response_profile(w, cand), self.gap(w)


class AssuranceCredit:
    def clear(self, sigma, B_team):
        credits = {}
        for i in sigma:
            external = sum((1 - self.alpha[j]) * self.marginal_safety(j, sigma[j])
                           for j in self.neighbors(i))
            credits[i] = external                       # Pigouvian stake
        return self.enforce_budget(credits, B_team)
```

## 3. 推导

**引理 13（团队证书的组合上界）** 设团队失效事件
`V_team = (∪_i V_i) ∪ (∪_{(i,j)∈E_I} I_{ij}) ∪ (∪_{C∈Cut} V_C)`。
由联合界，
`P(V_team) ≤ Σ_i P(V_i) + Σ_{ij} P(I_{ij}) + Σ_{C∈Cut} P(C)`。
若各失效事件正相关，则最小割集给出更紧的上界 `P(V_team) ≤ Σ_{C∈MinCut} P(C)`（Fréchet 上界 + 单调性）。该引理说明：**团队证书的瓶颈通常不是单机 `P_i`，而是接口与共因割集**；这也是为什么「每台机器人都认证通过」不能推出「团队认证通过」。

**引理 14（策略归因的收缩率）** 设类型 `θ ≠ θ'` 的签名中心分离度 `δ_min = min_{θ≠θ'} δ(s̄_θ, s̄_θ')`，单次观测噪声为 `σ_s`。则 `t` 次独立侦察后，误归因概率满足
`P(err) ≤ (π_max/π_min)·exp(-t·δ_min²/(8σ_s²))`。
证明：签名似然为 Gaussian，两类对数似然比的期望为 `δ_min²/(2σ_s²)`，用 Chernoff 界即得。所需侦察次数 `t* = O(σ_s²·log(1/ε)/δ_min²)`。推论：**策略归因的样本复杂度只取决于类型分离度与噪声，而不取决于策略空间大小**——这解释了为什么「能区分打法」的少量热身赛，比「穷举策略」更值钱。

**定理 14（认证均衡的存在与可达性）** 设策略组合有限、`Σ_cert` 非空闭。则：
1. 若混合扩展下 `Φ_cert` 凸且 `u_i` 拟凹，则 CSE 存在（Glicksberg 不动点）；
2. 一般情形，在可行偏离集 `D_i(σ_{-i})` 上做投影 no-regret 动力学，平均遗憾以 `O(√(log|Σ|/T))` 收敛到 CSE 的粗相关扩展；
3. 若 `Σ_cert = ∅`，ARENA 不返回任何激进策略，而是退化为 MFC 团队（全员保守）。
要点：**安全性不是罚项而是硬约束；均衡只在证书可行域内定义**，这避免了「均衡存在但不可认证」的空洞。

**定理 15（保证信用消除安全搭便车）** 在可加安全 `S(c)=Σ_i s_i(c_i)`、`s_i` 凹可微、个体可占有比例 `α_i` 下：
- 无机制 Nash 支出满足 `α_i s_i'(c_i^NE)=1`，社会最优满足 `s_i'(c_i^OPT)=1`，故 `c_i^NE < c_i^OPT`；
- 引入 Pigouvian 信用 `t_i(c)=(1-α_i)s_i'(c_i)` 后，个体一阶条件回到 `s_i'(c_i)=1`，即 `c_i^* = c_i^OPT`；
- 若罚金对未覆盖暴露线性，则真实上报 `c_i` 是占优策略。
安全维度的 PoA 由 `≥ 1/α_min` 降为 1；信用只做内部转移，不额外消耗团队能量。

**定理 16（漂移下的团队安全）** 设策略漂移速度 `v(κ)=v_0+v_κ·κ`，认证刷新周期 `Δt_rec`，漂移证书的瞬时失效上界为 `L_δ·v·Δt_rec`。则
`P(V_team^actual) ≤ P(V_team^cert) + n·L_δ·v(κ)·Δt_rec + P(检测失败)`。
故给定 `τ_drift` 必须满足 `Δt_rec ≤ τ_drift/(v_0+v_κ·κ)`，即 `k_ARENA` 随竞争强度 `κ` 单调不增。证明：刷新间隔内漂移最多累积 `v·Δt`，经 Lipschitz 传播到风险度量后逐机器人相加。

**推论 12（竞合相变）** 存在临界竞争强度 `κ_c(B_team)`，当 `κ > κ_c` 时 `Σ_cert` 为空，或所有 CSE 得分低于任务阈值。此时 ARENA 只有三条出路：(a) 增大团队预算；(b) 降低竞争强度、转回合作/保守策略；(c) 退化到 MFC 团队。**竞争不是免费的：它用安全预算购买得分，且存在买不起的临界点。**

## 4. 复杂度与能量分析

## 6. 本轮最大风险

**一句话**：ARENA 的全部安全性都押在一个假设上——**策略可以被可靠归因，且所有参与者都在证书可行域内做（近似）理性博弈**；而比赛策略的本质恰恰是隐藏类型、诱导误归因、并利用你的证书接口假设，一旦对手进行「证书投毒」（伪装安全签名、故意触发接口违约、在漂移检测盲区切换打法），团队证书会在「组合」与「漂移」两处同时失效，把 PACE 的「能量可核算」变成「对抗可套利」。

**次级风险与缓解**：
1. **共因割集被低估** → 用最小割集而非联合界做保守上界，并强制每对接口至少一个独立见证；
2. **均衡不可解/不唯一** → 以 no-regret 近似替代精确均衡，并在 `ε_gap > ε_max` 时直接退化到 MFC 团队；
3. **信用机制被博弈**（低报支出、质押套利）→ 罚金线性于未覆盖暴露 + 信用不可转让 + 哈希入账；
4. **策略漂移检测延迟** → `κ` 高时自动缩短 `k_ARENA`，并保留随机真机抽检；
5. **非理性/人类对手** → 用鲁棒信念集（`Θ` 的 Wasserstein 球）替代单点信念，求 min-max 认证策略；
6. **通信/时钟不同步** → 以承诺屏障 `k_sync` 显式建模，证书只对同步窗口内有效。

**定义 262（策略与策略组合）**
```
σ_i = (ρ_i, π_i, h_i, b_i),  π_i: O_i × Θ_i → Δ(A_i)
```

```
C_i = (A_i, G_i)
```

```
              ∧ (∀(i,j)∈E_I: G_{i→j}⊆A_{j→i})
```

正相关时用最小割集收紧为 `P(V_team) ≤ Σ_{C∈MinCut} P(C)`。

**定义 265（策略签名）**

```python
# IP-244/245/246/247/248/249/250/251 联合主循环
def ARENA_match(M, task, obs, B_team, kappa):
    Sigma, E_I = M.sig.build(task, M.library)
    opp = M.oaa.prior()
    for probe in M.saf.schedule(Sigma, opp, M.B_scout):
        y = M.scrimmage.run(probe)
        opp = M.oaa.update(opp, y)

    cand = []
    for sigma in product(*Sigma):
        Jt = M.tca.compose(sigma, M.pace_certs(sigma))
        if Valid(Jt) and sum(s.b for s in sigma) <= B_team:
            cand.append((sigma, Jt))
    if not cand:
        return M.mfc_team.fallback(), None

    sigma_star, eps = M.cse.solve(cand, opp, kappa)
    credits = M.acb.clear(sigma_star, B_team)
    k = M.arena_prefix(sigma_star)
    while not M.done:
        obs = M.step(sigma_star[:k])
        if M.dcr.drift(obs, sigma_star) > M.tau_drift:
            M.spent += M.epu.used
            return ARENA_match(M, task, obs, B_team - M.spent, kappa)
    return sigma_star, k, credits, M.jarena()

class StrategyAwareFalsification:

        probes = self.ladder.candidates(Sigma)
        while probes:
            x = max(probes, key=lambda p: p.expected_info_gain / p.cost)

class CertifiedEquilibrium:
    def solve(self, cand, opp, kappa, T=10_000):
        w = initialize_uniform(cand)
        for _ in range(T):
            sigma = sample_profile(w)
            for i in range(self.n):
                for sigma_i in self.feasible_deviations(cand, sigma, i):

                if (s_i, sigma[:-i]) in cand]

class AssuranceCredit:

        credits = {}
        for i in sigma:
            external = sum((1 - self.alpha[j]) *
                           self.marginal_safety(j, sigma[j])
                           for j in self.neighbors(i))
```

## 4. 推导

**引理 13（团队证书的组合上界）** 失效事件按「单机 / 接口 / 共因割集」分解，联合界给出
`P(V_team) ≤ Σ_i P(V_i) + Σ_ij P(I_ij) + Σ_{C∈Cut} P(C)`；
正相关时最小割集把上界收紧为 `Σ_{C∈MinCut} P(C)`。故团队证书的瓶颈是接口与共因，而非平均单机安全。

**引理 14（策略归因收缩率）** 若类型间签名分离度 `δ_min`、噪声 `σ_s`，则
`P(err) ≤ (π_max/π_min)·exp(-t δ_min²/(8σ_s²))`，
所需侦察次数 `t*=O(σ_s² log(1/ε)/δ_min²)`。策略空间变大不增加样本复杂度，只增加每个类型的先验维护成本。

**定理 14（认证均衡存在与可达）** 有限组合、非空闭 `Σ_cert`：
1. 混合扩展下 `Φ_cert` 凸、`u_i` 拟凹 ⇒ CSE 存在（Glicksberg）；
2. 一般情形，可行偏离集上的投影 no-regret 以 `O(√(log|Σ|/T))` 平均遗憾收敛到 CSE 的粗相关扩展；
3. `Σ_cert=∅ ⇒` 退化为 MFC 团队，绝不返回不可认证策略。

**定理 15（保证信用消除搭便车）** 可加安全、凹可微、可占有比例 `α_i` 下，无机制 Nash 满足 `α_i s_i'=1`，社会最优满足 `s_i'=1`，故 `c_i^NE<c_i^OPT`；Pigouvian 信用 `t_i=(1-α_i)s_i'` 使个体最优回到 `c_i^OPT`，安全维度 PoA 由 `≥1/α_min` 降为 1。信用只做内部转移，不额外消耗能量。

**定理 16（漂移下的团队安全）** `v(κ)=v_0+v_κκ`，刷新周期 `Δt_rec`：
`P(V_team^actual) ≤ P(V_team^cert) + n L_δ v(κ) Δt_rec + P(检测失败)`。
故 `Δt_rec ≤ τ_drift/(v_0+v_κκ)`，`k_ARENA` 随 `κ` 单调不增；高竞争必须高刷新。

**推论 12（竞合相变）** 存在 `κ_c(B_team)`：当 `κ>κ_c` 时 `Σ_cert=∅` 或所有 CSE 得分低于阈值；此时只能增预算、降竞争、或退化到 MFC 团队。竞争用安全预算买得分，存在买不起的临界点。

## 6. 本轮最大风险

**一句话**：ARENA 的全部安全性都押在一个假设上——**策略可以被可靠归因，且所有参与者都在证书可行域内做（近似）理性博弈**；而比赛策略的本质恰恰是隐藏类型、诱导误归因、并利用你的证书接口假设，一旦对手进行「证书投毒」（伪装安全签名、故意触发接口违约、在漂移检测盲区切换打法），团队证书会在「组合」与「漂移」两处同时失效，把 PACE 的「能量可核算」变成「对抗可套利」。

**次级风险与缓解**：
1. **共因割集被低估** → 用最小割集而非联合界做保守上界，每对接口至少一个独立见证；
2. **均衡不可解/不唯一** → no-regret 近似替代精确均衡，`ε_gap>ε_max` 时退化到 MFC 团队；
3. **信用机制被博弈** → 罚金线性于未覆盖暴露、信用不可转让、账本哈希入证；
4. **漂移检测延迟** → `κ` 高时自动缩短 `k_ARENA`，保留随机真机抽检；
5. **非理性/人类对手** → 以 `Θ` 的 Wasserstein 球做鲁棒信念集，求 min-max 认证策略；
6. **通信/时钟不同步** → 显式建模承诺屏障 `k_sync`，证书只在同步窗口内有效。
