# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「移动操作」×「基准测试」）

> 第 66 轮 RAS 把闭环从「故障响应」推进到「意图协商」，第 67 轮 SimRAS 又从「在线反应」推进到「离线仿真预演 + 视觉问答审计」。但这两轮共享一个未被言明的前提：**闭环是在一个「固定基座、单一场景分布」的世界里被校准和认证的**。
>
> 移动操作（mobile manipulation）打破了这个前提：机器人要边走边抓，基座在动、里程计会漂、负载会变、地面会滑、行人会闯入；同一个「几何故障」在不同基座速度下含义完全不同。基准测试（benchmarking）则提供了另一半答案：**既然移动操作的场景空间如此之大，任何在线闭环都无法在单次运行中「现场证明」自己安全，唯一可行的办法，是让安全证书以基准测试的统计覆盖为锚。**
>
> 本轮的核心命题：
>
> **把「单场景在线认证闭环」升级为「移动操作基准校准的认证闭环（MBC: Mobile-Benchmark Closure）」：用全身共动动作块刻画移动，用 SE(3) 不变签名隔离「运动」与「故障」，用共形风险控制把基准结果转成有覆盖保证的风险上界，再用「证书伪证循环」让基准主动寻找闭环最危险的场景。**
>
> MBC 问的是新一轮的问题：「**这张证书在哪些场景成立？它凭什么成立？谁会来推翻它？**」

## 0. 直觉与动机

**灵感 1（移动操作 → 全身共动动作块）**
直觉：第 65–67 轮的「动作块」默认了固定基座：机械臂可以在一个小球里随意撤回，最坏情况是「停手」。移动操作把最坏情况改成了「停不住」——基座有惯性、有刹车距离、有不可逆位移。于是安全裕度不再是一个几何球，而是「**障碍距离 − 刹车距离 − 机械臂外伸 − 负载挠度**」的联合余量。把基座、机械臂、夹爪打包成一个**全身动作块**，认证前缀才第一次真正对应「机器人整体的承诺」。

**灵感 2（移动操作 → 运动混淆，而非运动噪声）**
直觉：基座一移动，视觉残差、力残差、里程计残差都会整体漂移。第 65 轮的故障签名是在世界坐标里算的，于是「走得太快」会被误判成「传感器坏了」，「负载偏重」会被误判成「模型漂移」。这不是加性噪声，而是**坐标系混淆（motion confound）**。解决办法不是加大噪声方差，而是把签名搬到**机体坐标并用 SE(3) 不变量表示**：让「运动」在特征空间里被商掉，只留下真正的故障方向。这样 H_base（基座滑移）与 H_geo（几何误差）才可分。

**灵感 3（基准测试 → 从「点估计」到「覆盖保证」）**
直觉：前几轮所有风险缩放都依赖手调参数（α_risk、β_risk、γ、η）和「似乎合理」的阈值。基准测试的真正价值不是排行榜，而是**一组可交换的校准样本**：用 split conformal / conformal risk control，可以把基准上的非一致性分数转成一个 distribution-free 的风险上界 q̂_α，使新场景的风险以 ≥1−α 的概率被包住。这把 RAS 的「经验调参」替换成「**统计契约**」。更关键的是它给出了一个可被证伪的「证书有效域」：基准支撑之外，证书自动失效并回退保守。

**灵感 4（基准测试 → 基准即攻击面）**
直觉：一旦安全证书依赖基准，基准就变成了策略的「考试范围」——任何静态基准都会被过拟合（Goodhart 定律）。移动操作尤甚：场景是组合爆炸的，公开基准只覆盖极少数地形×负载×行人×光照的组合。因此基准不能是一次性数据集，而必须是**对抗课程**：用「证书伪证分数」主动搜索当前证书最可能失效的场景，把最坏的场景加入下一轮校准。基准与策略共同演化，直到找不到能推翻证书的场景（在统计置信度内）。

**灵感 5（三灵感合流 → MBC 六件套）**
把上述直觉落成六个部件，接在 SimRAS 之后：
1. **MoChunk 全身共动动作块**：动作块从 `(a_arm, a_grip)` 扩到 `(a_base, a_arm, a_grip)`，引入移动安全裕度与刹车不可逆视界；
2. **MIFS 运动不变故障签名**：把残差映射到机体坐标的 SE(3) 不变特征，隔离运动混淆；
3. **BCR 基准共形风险先验**：分层 conformal risk control 给每个场景层一个风险上界 q̂_α；
4. **BSS 基准支撑门（OOD gate）**：用场景嵌入的支撑距离判定证书是否仍有效，失效即保守回退；
5. **BAC 基准对抗伪证循环**：主动搜索最坏场景，扩充校准集，给出样本复杂度界；
6. **MC-RAS 移动认证前缀 + J_MBC 证书**：把 k* 从 min(k_VISTA,k_emo,k_wm,m_ras) 再与 m_mob、k_bench 取交，并把基准版本、覆盖层、共形分位数、OOD 分数写进证书。

## 1. 形式化定义（增量：定义 266–285）

- **定义 266（MBC 总览）**：`MBC = (MoChunk, MIFS, BCR, BSS, BAC, MC-RAS, J_MBC)`。定位：在 SimRAS 的「仿真预演 + VQA 审计」之上，追加「移动一致性 + 基准统计契约」两层。不变式：基准校准、伪证搜索、共形分位数拟合全部离线；在线只做签名计算、分位数查表、支撑距离判定，零学习写操作。

- **定义 267（移动操作状态与全身动作块）**：状态 `s_t = (T_t ∈ SE(3), q_t ∈ ℝ^{n_a}, v_t ∈ ℝ^3, m_p ∈ ℝ_+, e_t)`，其中 T_t 为基座位姿、q_t 为关节角、v_t 为基座速度、m_p 为负载、e_t 为场景嵌入。全身动作块 `B_t = ((a_base, a_arm, a_grip)_1, …, (a_base, a_arm, a_grip)_m)`。

- **定义 268（移动安全裕度）**：直觉是「还能不能安全停下」。形式化：
  `ρ_safe^mob(s_t, B_t) = min_{i=1..m} [ d_obs(s_{t+i}) − v_{t+i}·τ_brake − v_{t+i}²/(2a_brake) − r_reach(q_{t+i}) − κ·m_p ]`，其中 d_obs 为到最近障碍的距离，τ_brake 为反应延迟，a_brake 为最大减速度，r_reach 为机械臂超出认证包络的外伸量，κ 为负载挠度系数。

- **定义 269（移动不可逆视界）**：`m_mob = min(m_ras, m_brake)`，`m_brake = ⌈v_max·τ_brake/Δt_chunk⌉`。含义：只能承诺「仍在刹车能力内」的动作块数；超出的块一旦执行就无法撤回。

- **定义 270（运动不变故障签名 MIFS）**：设世界系残差为 ρ_t，定义机体系残差 `ρ_t^b = Ad_{T_t^{-1}}·ρ_t`，再取不变量特征
  `γ_t = Φ(ρ_t^b) = (‖f‖, ‖τ‖, cos∠(f, n_surface), 滑移率, 关节残差相对比例, 力矩-速度比)`。
  性质：对任意全局 `g ∈ SE(3)`，`γ(g·s) = γ(s)`；故障归因在商空间 `SE(3)\S` 上进行。

- **定义 271（移动故障假设集）**：`ℋ_mob = ℋ_RAS ∪ {H_base, H_odom, H_payload, H_dyn_occl}`，分别对应基座滑移、里程计漂移、负载导致的动力学偏移、动态遮挡。联合后验仍在 `ℋ_mob × E` 上做贝叶斯更新，但证据改为 `γ_t` 而非 ρ_t。

- **定义 272（基准套件与场景层）**：`ℬ = {(task_i, scene_i, embodiment_i, seed_i)}_{i=1}^n`。场景层函数 `σ: scene → {地形} × {人机距离} × {负载} × {光照}`，共 K 层；每层校准样本数 `n_σ`。

- **定义 273（非一致性分数）**：对每条基准轨迹定义 `E_i = g(s_i, B_i, J_i) ∈ [0,1]`，取「归一化裕度亏损 + 违规指示 + 任务失败」的复合分数；`D_cal = {(s_i, E_i)}` 为校准集，`D_test` 与 `D_cal` 可交换。

- **定义 274（分层共形分位数与风险上界）**：第 σ 层取
  `q̂_σ = E_{(⌈(n_σ+1)(1−α)⌉)}`（升序第该名次），并以 `R̂_α(s) = q̂_{σ(s)}` 作为该场景的风险上界。当 `n_σ` 不足时回退到全局分位数并标记 `stratum_fallback = True`。

- **定义 275（基准支撑与 OOD 分数）**：`d_OOD(s) = dist(φ(s), S_ℬ)`（φ 为场景嵌入，`S_ℬ` 为基准场景集），`support(s) = 1[d_OOD(s) ≤ τ_support]`，τ_support 由基准的 95% 分位标定。证书有效域 `V(ℬ) = {s : support(s)=1}`。

- **定义 276（基准校准的风险缩放）**：`λ_bench(s) = clip(1 − α_b·R̂_α(s) − β_b·1[¬support(s)], 0.5, 1.2)`。支撑外强制 `λ_bench ≤ 0.8` 且 `k_bench = 0`（回退到纯 SimRAS 保守模式）。

- **定义 277（MC-RAS 认证前缀）**：`k*MBC = max{k ≤ min(k_SimRAS, m_mob) : ∀i≤k, λ_bench(s_{t+i})·ρ_safe^mob(s_{t+i}, B_{t+i}) ≥ 0 ∧ R̂_α(s_{t+i}) ≤ R_max}`。

- **定义 278（证书伪证分数）**：对场景 s 与证书 J，
  `CF(s, J) = max(0, R̂_α(s) − R_max) + max(0, −min_i ρ_safe^mob) + w_ood·1[¬support(s)]`。它度量「证书在此场景被推翻的程度」。

- **定义 279（基准对抗伪证循环 BAC）**：`ℬ_{j+1} = ℬ_j ∪ {s* : CF(s*, J_j) ≥ δ}`，其中 `s* = argmax_{s∈Pool} CF(s, J_j)`；当 `P(sup_{s∈Pool} CF(s, J_j) > δ) ≤ β` 时停止。

- **定义 280（MBC 记分卡）**：CSR（认证成功率）、VRC（认证内违规率）、CSG（覆盖-安全差 `|empirical coverage − (1−α)|`）、BGG（公开基准与留出私有基准的性能差）、XEG（跨本体迁移差）、RCC-AUC（风险-覆盖率曲线下面积）。

- **定义 281（证书 J_MBC）**：`J_MBC = (J_SimRAS, bench_ver, stratum_id, q̂_σ, coverage_flag, ood_score, support_flag, m_mob, mifs_ver, scorecard_hash)`。Valid ⇔ Valid(J_SimRAS) ∧ support_flag ∧ (q̂_σ ≤ R_max) ∧ (λ_bench ≥ 0.6)。

- **定义 282（移动共因故障）**：`ℰ_mob = ℰ_SimRAS × {基座滑移, 里程计漂移, 动态遮挡, 负载突变}`；共因项 `ℰ_common_mob` 捕获「地面湿滑 → 基座滑移 → 视觉残差同向漂移」这条因果链，避免把共因误归为独立故障。

- **定义 283（跨本体迁移假设）**：本体参数 `η ∈ E`（轮式/足式/不同臂长）。基准校准默认在 `η_train` 上；对 `η_test` 要求 `d_OOD^emb(η_test) ≤ τ_emb`，否则 `XEG` 记入证书风险栏并触发保守回退。

- **定义 284（预注册判定规则）**：每个实验在运行前固定「通过/失败」阈值；若未通过，则视为证书被伪证，必须回到 BAC 扩充基准，而非事后调参。

- **定义 285（实时部署不变式）**：在线环路 = MIFS + BCR 查表 + BSS 判定 + MC-RAS；BAC 与共形拟合只在离线/后台。在线新增延迟预算 ≤0.5ms。

## 2. 关键算法骨架

```python
# MIFS：运动不变签名
def motion_invariant_signature(rho_world, T):
    rho_b = transform_to_body(rho_world, T.inverse())   # Ad_{T^-1}
    return invariant_features(rho_b)                    # ||f||, slip, ratios...

# BCR：分层共形校准（离线）
def fit_stratified_conformal(scores, strata, alpha):
    qhat = {}
    for k in set(strata):
        s = sorted(scores[strata == k])
        n = len(s)
        idx = min(n - 1, math.ceil((n + 1) * (1 - alpha)) - 1)
        qhat[k] = s[idx]
    return qhat

# MC-RAS：移动认证前缀
def certified_prefix_mbc(B, s_seq, qhat, support, lam_bench, m_ras, m_mob, R_max):
    k_best = 0
    for k in range(1, min(m_ras, m_mob, len(B)) + 1):
        if not support[k]:
            break                      # 支撑外：零承诺
        row = (qhat[stratum(s_seq[k])] <= R_max
               and min(safety_mob(s_seq[i], B[i]) for i in range(k)) >= 0)
        if row:
            k_best = k
        else:
            break
    return min(k_best, m_ras, m_mob)

# BAC：证书伪证循环（离线/后台）
def benchmark_falsification_loop(pool, cert, delta, beta):
    N = math.ceil(math.log(2 * len(pool) / beta) / (2 * delta ** 2))
    worst = max(pool, key=lambda s: cert.falsification_score(s))
    while cert.falsification_score(worst) > delta:
        cert.add_to_benchmark(worst)
        cert.refit_conformal()
        worst = max(pool, key=lambda s: cert.falsification_score(s))
    return cert
```

## 3. 推导

**引理 13（共动裕度的停止充分性）** 若对块内所有 i 有 `ρ_safe^mob(s_i, B_i) ≥ 0`，且基座按 `a_brake` 减速，则从任意块内状态触发急停都不会与障碍碰撞。证明要点：`v·τ_brake + v²/(2a_brake)` 是保守刹车距离上界，减去负载挠度后仍非负即保证停止轨迹在自由空间内。

**引理 14（MIFS 的可辨识性）** 若 Φ 在商空间 `SE(3)\S` 上单射，则全局基座运动不能改变 γ；于是 `H_base`（滑移率异常）与 `H_geo`（接触力方向异常）在 γ 空间线性可分，故障归因不再被运动混淆。

**定理 14（共形覆盖）** 若 `D_cal` 与测试场景可交换，则 `P(E_test ≤ q̂_σ) ≥ 1 − α`；分层版本在每层内单独成立。若存在协变量偏移且 `TV(P_test, P_cal) = δ_TV`，覆盖退化为 `≥ 1 − α − δ_TV`。

**定理 15（支撑内证书有效性）** 若 `s ∈ V(ℬ)` 且可交换性成立，则 MC-RAS 输出的控制指令满足 `P(风险 > R_max) ≤ α + α_chunk + δ_fi`；若 `s ∉ V(ℬ)`，则 `k_bench = 0 ∧ λ_bench ≤ 0.8`，证书自动降级为 SimRAS 保守模式。

**定理 16（伪证循环样本复杂度）** 对大小为 `|Pool|` 的候选池与容差 δ，BAC 每层需 `N ≥ ln(2|Pool|/β)/(2δ²)` 个场景，才能以 1−β 置信度保证池内不存在伪证分数 > δ 的场景。

**定理 17（MBC 端到端风险一致性）** 在 A87–A91、定理 14/15/16 下，`P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_bench + α_ood`，且 `k*MBC ≥ 0.9·min(k_SimRAS, m_mob, k_bench*)`。

| E290 预注册复现 | 判定规则是否可复现 | 两次独立运行结论一致 |

## 6. 本轮最大风险

**一句话**：MBC 把安全证书的合法性外包给「基准覆盖」，但移动操作的场景层是组合爆炸且持续漂移的——一旦某个稀有层（如「湿滑坡面 + 重载 + 近距离行人」）在基准中样本不足，分层共形给出的 q̂_σ 会因 `n_σ` 过小而失真，证书会在全局覆盖率好看的假象下，在真实的长尾移动场景中**系统性失效**，而这恰恰是 MBC 全部统计保证所依赖的核心假设：**基准的分层覆盖能代表在线分布，且场景层内可交换性成立**。

## 2. 形式化定义（完整版）

**定义 266（MBC 总览）** MBC 是在 SimRAS 之上的「移动一致性 + 基准统计契约」增强层：
```
MBC = (MoChunk, MIFS, BCR, BSS, BAC, MC-RAS, J_MBC)
```
不变式：基准校准、伪证搜索、共形分位数拟合全部离线；在线只做签名计算、分位数查表、支撑距离判定与认证前缀求解，零学习写操作。

**定义 267（移动操作状态与全身动作块）** 状态 `s_t = (T_t ∈ SE(3), q_t ∈ ℝ^{n_a}, v_t ∈ ℝ^3, m_p ∈ ℝ_+, e_t)`；全身动作块 `B_t = ((a_base,a_arm,a_grip)_1, …, (a_base,a_arm,a_grip)_m)`。基座动作含速度/转向/急停，机械臂与夹爪沿用第 66 轮定义。

**定义 268（移动安全裕度）**
```
ρ_safe^mob(s_t,B_t) = min_{i=1..m} [ d_obs(s_{t+i}) − v_{t+i}·τ_brake
                                    − v_{t+i}²/(2a_brake)
                                    − r_reach(q_{t+i}) − κ·m_p ]
```
其中 `d_obs` 为到最近障碍距离，`τ_brake` 为反应延迟，`a_brake` 为最大减速度，`r_reach` 为机械臂超出认证包络的外伸量，`κ` 为负载挠度系数。

**定义 269（移动不可逆视界）**
```
m_mob = min(m_ras, m_brake),  m_brake = ⌈v_max·τ_brake / Δt_chunk⌉
```
含义：只能承诺「仍处于刹车能力内」的块数；超出的块一旦执行便不可撤回。

**定义 270（运动不变故障签名 MIFS）** 设世界系残差 `ρ_t`，取
```
ρ_t^b = Ad_{T_t^{-1}} · ρ_t
γ_t = Φ(ρ_t^b) = (‖f‖, ‖τ‖, cos∠(f,n_surface), slip_ratio,
                  joint_residual_ratio, torque_velocity_ratio)
```
性质：对任意 `g ∈ SE(3)`，`γ(g·s) = γ(s)`；故障归因在商空间 `SE(3)\S` 上进行。

**定义 271（移动故障假设集）**
```
ℋ_mob = ℋ_RAS ∪ {H_base, H_odom, H_payload, H_dyn_occl}
```
联合后验在 `ℋ_mob × E` 上更新，证据由 ρ_t 改为 γ_t：
```
P(H,E | γ,face) ∝ p(γ | H) · p(face | E) · P(H) · P(E | H)
```

**定义 272（基准套件与场景层）** `ℬ = {(task_i, scene_i, embodiment_i, seed_i)}_{i=1}^n`；场景层函数
```
σ(s) ∈ {地形} × {人机距离} × {负载} × {光照}
```
共 K 层，每层校准样本数 `n_σ`。

**定义 273（非一致性分数）** 对每条基准轨迹，定义
```
E_i = g(s_i,B_i,J_i) = w_m·margin_deficit + w_v·violation + w_f·task_failure ∈ [0,1]
```
校准集 `D_cal = {(s_i,E_i)}`，与测试集 `D_test` 可交换。

**定义 274（分层共形分位数）** 第 σ 层：
```
q̂_σ = E_(⌈(n_σ+1)(1−α)⌉)          # 升序第该名次
R̂_α(s) = q̂_{σ(s)}
```
若 `n_σ < n_min`，回退全局分位数并置 `stratum_fallback = True`。

**定义 275（基准支撑与 OOD 分数）** `φ` 为场景嵌入，`S_ℬ = {φ(s_i)}`：
```
d_OOD(s) = dist(φ(s), S_ℬ),   support(s) = 1[d_OOD(s) ≤ τ_support]
V(ℬ) = {s : support(s)=1}
```
`τ_support` 由基准支撑的 95% 分位标定。

**定义 276（基准校准风险缩放）**
```
λ_bench(s) = clip(1 − α_b·R̂_α(s) − β_b·1[¬support(s)], 0.5, 1.2)
```
支撑外强制 `λ_bench ≤ 0.8` 且 `k_bench = 0`。

**定义 277（MC-RAS 认证前缀）**
```
k*MBC = max{ k ≤ min(k_SimRAS, m_mob) :
             ∀i≤k, λ_bench(s_{t+i})·ρ_safe^mob(s_{t+i},B_{t+i}) ≥ 0
                    ∧ R̂_α(s_{t+i}) ≤ R_max }
```

**定义 278（证书伪证分数）**
```
CF(s,J) = max(0, R̂_α(s) − R_max)
        + max(0, −min_i ρ_safe^mob(s_i,B_i))
        + w_ood·1[¬support(s)]
```

**定义 279（基准对抗伪证循环 BAC）**
```
ℬ_{j+1} = ℬ_j ∪ {s*},  s* = argmax_{s∈Pool} CF(s,J_j)
```
以概率 ≥1−β 保证 `sup_{s∈Pool} CF(s,J_j) ≤ δ` 时停止。

**定义 280（基准记分卡）** 六指标：
- `CSR`：认证成功率（任务成功 ∧ 证书有效 ∧ 零违规）；
- `VRC`：认证内违规率；
- `CSG`：`|empirical coverage − (1−α)|`；
- `BGG`：公开基准与留出私有基准的 CSR 差；
- `XEG`：跨本体 CSR 差；
- `RCC-AUC`：风险-覆盖率曲线下面积。

**定义 281（J_MBC 证书）**
```
J_MBC = (J_SimRAS, bench_ver, stratum_id, q̂_σ, coverage_flag,
         ood_score, support_flag, m_mob, mifs_ver, scorecard_hash)
```
`Valid ⇔ Valid(J_SimRAS) ∧ support_flag ∧ (q̂_σ ≤ R_max) ∧ (λ_bench ≥ 0.6)`。

**定义 282（移动共因故障）**
```
ℰ_mob = ℰ_SimRAS × {base_slip, odom_drift, dyn_occlusion, payload_shift}
```
共因项 `ℰ_common_mob` 捕获「地面湿滑 → 基座滑移 → 视觉残差同向漂移」，避免把共因误归为独立故障。

**定义 283（跨本体迁移）** 本体参数 `η ∈ E`；基准校准默认在 `η_train` 上。对 `η_test` 要求 `d_OOD^emb(η_test) ≤ τ_emb`，否则记入 XEG 风险栏并触发保守回退。

**定义 284（预注册判定规则）** 每个实验运行前固定通过/失败阈值；未通过即视为证书被伪证，必须回到 BAC 扩充基准，禁止事后调参。

**定义 285（实时部署不变式）** 在线环路 = MIFS + BCR 查表 + BSS 判定 + MC-RAS；BAC 与共形拟合只在离线/后台。在线新增延迟预算 ≤0.5ms。

# IP-243 MoChunk：全身共动动作块
class MobileWholeBodyChunk:
    def propose(self, s, H, m=8):
        base = self.base_policy.propose(s.T, s.v, H)
        arm  = self.vista.ach.propose(s.q, H)
        return [WholeBodyAction(base[i], arm[i]) for i in range(m)]

    def safety_mob(self, s, B):
        worst = float('inf')
        for i, (a, si) in enumerate(zip(B, self.rollout(s, B))):
            d = distance_to_obstacle(si)
            brake = si.v * self.tau_brake + si.v**2 / (2 * self.a_brake)
            reach = reach_overshoot(si.q)
            worst = min(worst, d - brake - reach - self.kappa * si.m_p)
        return worst

    def braking_horizon(self, v_max):
        return math.ceil(v_max * self.tau_brake / self.dt_chunk)

def motion_invariant_signature(rho_world, T):

# IP-245 BCR：分层共形校准（离线）
class BenchmarkConformalRisk:
    def fit(self, scores, strata, alpha, n_min=500):
        self.qhat = {}
        for k in set(strata):
            s = sorted(scores[strata == k])
            n = len(s)
            if n < n_min:
                self.qhat[k] = self.global_qhat
                continue
            idx = min(n - 1, math.ceil((n + 1) * (1 - alpha)) - 1)
            self.qhat[k] = s[idx]
        return self.qhat

    def risk_upper(self, s):
        return self.qhat.get(stratum(s), self.global_qhat)

# IP-248 MC-RAS：移动认证前缀
def certified_prefix_mbc(B, s_seq, qhat, gate, lam_bench,
                         m_ras, m_mob, R_max):
    k_best = 0
    for k in range(1, min(m_ras, m_mob, len(B)) + 1):
        g = gate.check(s_seq[k])
        if not g['support']:
            break                                  # 支撑外：零承诺
        ok = (qhat.risk_upper(s_seq[k]) <= R_max)
        ok &= min(safety_mob(s_seq[i], B[i])
                  for i in range(1, k + 1)) >= 0
        if ok:
            k_best = k
        else:
            break
    return min(k_best, m_ras, m_mob)


# IP-247 BAC：证书伪证循环（离线/后台）
class BenchmarkFalsifier:
    def __init__(self, pool, cert, delta=0.05, beta=0.01):
        self.pool, self.cert = pool, cert
        self.N = math.ceil(math.log(2 * len(pool) / beta) / (2 * delta**2))
        self.delta, self.beta = delta, beta

    def run(self):
        while True:
            worst = max(self.pool, key=self.cert.falsification_score)
            if self.cert.falsification_score(worst) <= self.delta:
                return self.cert                 # 无场景能推翻证书
            self.cert.add_to_benchmark(worst)
            self.cert.refit_conformal()
            self.pool.remove(worst)

## 4. 推导

**引理 13（共动裕度的停止充分性）** 若对块内所有 i 有 `ρ_safe^mob(s_i,B_i) ≥ 0`，且基座按 `a_brake` 减速，则从任意块内状态触发急停均不与障碍碰撞。
*证明要点*：`v·τ_brake + v²/(2a_brake)` 是保守刹车距离上界（匀减速 + 反应延迟），减去负载挠度后仍非负，说明停止轨迹整体位于自由空间内；`r_reach` 保证机械臂在减速期间不越出认证包络。∎

**引理 14（MIFS 不变性与可辨识性）** 对任意 `g ∈ SE(3)`，`γ(g·s) = γ(s)`；若 Φ 在商空间 `SE(3)\S` 上单射，则 `H_base` 与 `H_geo` 在 γ 空间可分。
*证明要点*：`Ad_{T^{-1}}` 把全局变换抵消，Φ 仅由内积、范数、比值构成，均为 SE(3) 不变量；单射性把不同的故障流形映射到不相交的特征集。∎

**引理 15（支撑门与风险缩放的一致性）** 若 `support(s)=0`，则 `λ_bench(s) ≤ 0.8` 且 `k_bench=0`；于是 MC-RAS 在该场景退化为「零承诺 + 保守控制」，不会因基准外推而放行。

**定理 14（分层共形覆盖）** 若 `D_cal` 与 `D_test` 可交换，则对每层 σ：
```
P(E_test ≤ q̂_σ | σ(test)=σ) ≥ 1 − α
```
全局覆盖由全概率公式加权成立。若 `TV(P_test,P_cal)=δ_TV`，则覆盖 `≥ 1−α−δ_TV`。

**定理 15（支撑内证书有效性）** 在定义 275 的支撑域内且可交换性成立时，MC-RAS 输出满足
```
P(risk > R_max) ≤ α + α_chunk + δ_fi
```
支撑外则 `k_bench=0 ∧ λ_bench≤0.8`，证书降级为 SimRAS 保守模式，且不会把「看不见」误判为安全。

**定理 16（伪证循环样本复杂度）** 对候选池 `Pool`、容差 δ，BAC 每层至少需要
```
N ≥ ln(2|Pool|/β) / (2δ²)
```
个场景，才能以 1−β 置信度保证 `sup_{s∈Pool} CF(s,J) ≤ δ`（Hoeffding + 联合界）。

**定理 17（MBC 端到端风险一致性）** 在 A87–A91、定理 14/15/16 下，
```
P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_bench + α_ood
k*MBC ≥ 0.9·min(k_SimRAS, m_mob, k_bench*)
```
其中 `α_bench = α + δ_TV`，`α_ood = P(¬support ∧ 实际在分布内)`。

**推论 1（Goodhart 界）** 若公开基准 `ℬ_pub` 与留出私有基准 `ℬ_priv` 的分布差为 `δ_priv`，则 `BGG ≤ δ_priv + α_bench`；当 BAC 仅在 `ℬ_priv` 上运行时，BGG 不随公开基准过拟合而增长。

## 8. 本轮最大风险

**一句话**：MBC 把安全证书的合法性外包给「基准分层覆盖」，但移动操作的场景层是组合爆炸且持续漂移的——一旦某个稀有层（如「湿滑坡面 + 重载 + 近距离行人」）样本不足，`q̂_σ` 会因 `n_σ` 过小而失真，证书会在全局覆盖率好看的假象下于真实长尾移动场景中**系统性失效**；这是本轮全部统计保证所依赖的核心假设：**基准的分层覆盖能代表在线分布，且层内可交换性成立**。
