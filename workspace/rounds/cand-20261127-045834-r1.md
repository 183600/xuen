### 第 1 轮灵感驱动研究记录

**灵感词**：长程任务、用户画像

**直觉与动机**：
现有证书链（HPC-E+ v24：感知-合规-能量 + 结构-力学）本质上仍是「单步/单场景」的准入谓词：给定时点状态 (x, v, z, E) 与计划 π，判定 π 当下是否安全可执行。但真实部署中的任务往往跨越数分钟到数小时、成百上千个决策步，且服务对象是具体的、会变化的个体。受「长程任务」启发：证书不能只在 t=0 签发一次，而应沿时间轴摊销为「证书流」——每阶段续期、可监控、可回滚，并带进度势函数与任意时点有效的统计保证。受「用户画像」启发：准入门不能只面向「通用用户」，而应面向带偏好、能力边界、隐私预算与同意状态的个体画像——个性化必须可解释、可同意、可撤回、可遗忘。

核心洞见：**长程任务把「一次性证书」变成「随时间摊销的证书流」，用户画像把「通用准入」变成「个体化准入」；二者耦合后，证书从静态谓词升级为「带进度漂移界与隐私预算的时序契约」——必须在时间上可续期、在个体上可同意、在失效时可回滚。**

**形式化目标**：
1. 定义长程任务证书（LHTC）：对时限 H、阶段划分 {1..K} 与 STL 公式 φ，证书要求 (a) 轨迹鲁棒度 ρ_φ(τ) ≥ ε_φ；(b) 进度势函数 V_k ≥ 0 且 E[V_{k+1} | F_k] ≤ V_k − δ_k（非负上鞅带漂移），从而 E[T] ≤ V_0/δ_min、P(T > H) ≤ V_0/(δ_min·H)；(c) 任意时点有效的 e-process 监控，防止「看数据后改承诺」。
2. 定义用户画像证书（UPC）：画像 P = (Pref, Cap, Cons, ε_p, τ) 上验证偏好可行性、能力包络（置信下界）、Rényi-DP 预算 ε_total(α) = Σ ε_k(α) ≤ ε_max、同意令牌有效且未撤回；未验证属性只能作软先验，不得作硬约束（防刻板印象）。
3. 定义检查点与进度账本（CPL）：阶段边界 Merkle 检查点链，回滚代价 R_k ≤ R_max，且「已耗能 + 剩余计划能 + 回滚能 ≤ E_budget」，保证恢复不破 EVC 预算；账本追加式、可审计、防篡改。
4. 构建时变个性化准入门（TPC）：HPC-E+ v24 ∪ LHTC ∪ UPC ∪ CPL 四证一体，Exec_v25 = Exec_v24 ∩ Fil_lh ∩ Fil_up ∩ Fil_ck ⊆ Exec_v24。
5. 证明单调退化链在「任务时限延长 / 画像漂移或同意撤回 / 隐私预算耗尽 / 回滚超预算」四条路径下的保持性。

```python
# ============================================================
# IP-444 Long-Horizon Task Certificate (LHTC) — 长程任务证书
# ============================================================
@dataclass
class LongHorizonTaskCertificate:
    """STL 鲁棒度 + 进度上鞅 + anytime-valid e-process 的跨阶段证书流"""
    horizon_H: int
    stages: list['StageSpec']          # 阶段规范（时长、子目标、资源预算）
    phi: 'STLFormula'                  # 时序任务规范
    epsilon_phi: float                 # 鲁棒度阈值
    V0: float                          # 初始进度势
    delta_min: float                   # 最小期望进度
    alpha_h: float                     # 终止风险容忍度
    drift_bound_kappa: float           # 动力学漂移上界
    e_process: 'AnytimeProgressMonitor' = None
    _V: float = None                   # 当前进度势

    def verify_temporal(self, trace: 'Trajectory') -> bool:
        """STL 带裕度满足：min_t ρ_φ(τ,t) ≥ ε_φ"""
        return self.phi.robustness(trace).min().item() >= self.epsilon_phi

    def verify_termination(self) -> bool:
        """P(T > H) ≤ V0 / (delta_min * H) ≤ alpha_h（Markov + 可选停时）"""
        if self.delta_min <= 0 or self.horizon_H <= 0:
            return False
        return self.V0 / (self.delta_min * self.horizon_H) <= self.alpha_h

    def verify_drift(self, observed_drift: float) -> bool:
        """实测单阶段漂移不得超过证书假设的 κ"""
        return observed_drift <= self.drift_bound_kappa + 1e-9

    def renew(self, k: int, stage_outcome: 'Outcome',
              observed_drift: float) -> bool:
        """阶段边界续期：进度下降 + e-process 更新 + 漂移复核"""
        if not self.verify_drift(observed_drift):
            return False                      # 假设失效，拒绝续期
        progress = stage_outcome.progress   # 实测进度增量
        self._V = max(self._V - progress, 0.0)
        self.e_process.update(progress)
        if self.e_process.reject_stalled():
            return False                      # 进度停滞，拒绝续期
        # 剩余时限内的可达性复核（保守：用 δ_min 重算尾部概率）
        remaining = self.horizon_H - k
        if remaining <= 0:
            return self._V <= 1e-9
        return self._V / (self.delta_min * remaining) <= self.alpha_h

    def verify_all(self, trace: 'Trajectory', observed_drift: float) -> bool:
        return (self.verify_temporal(trace) and
                self.verify_termination() and
                self.verify_drift(observed_drift))


class AnytimeProgressMonitor:
    """任意时点有效的进度监控（e-process / 混合鞅），防止 p-hacking"""
    def __init__(self, delta_min: float, alpha: float = 0.05):
        self.delta_min = delta_min
        self.alpha = alpha
        self.log_e = 0.0

    def update(self, progress: float):
        # 以 δ_min 为原假设的指数鞅：E[e^{λ(X−δ)}] ≤ 1 时仍为鞅
        lam = 1.0 / max(self.delta_min, 1e-9)
        self.log_e += lam * (progress - self.delta_min) - 0.5 * (lam ** 2)

    def reject_stalled(self) -> bool:
        return math.exp(self.log_e) >= 1.0 / self.alpha


# ============================================================
# IP-445 User Profile Certificate (UPC) — 用户画像证书
# ============================================================
@dataclass
class UserProfileCertificate:
    """偏好可行性 + 能力包络 + 隐私预算 + 同意状态 四重验证"""
    pref: 'PreferenceModel'
    capability: 'CapabilityEnvelope'
    hard_constraints: 'ConstraintSet'
    rdp_budget: 'RDPAccountant'
    epsilon_max: float
    consent: 'ConsentToken'
    evidence_ledger: 'ProfileEvidenceLedger'

    def verify_constraints(self, plan) -> bool:
        """硬约束必须可行；未验证画像属性不得进入硬约束"""
        if not self.hard_constraints.feasible(plan):
            return False
        for attr in self.hard_constraints.attributes():
            if not self.evidence_ledger.is_verified(attr):
                return False
        return True

    def verify_capability(self, plan) -> bool:
        """计划所需技能 ⊆ 能力包络（置信下界 ≥ 1−β）"""
        required = plan.required_skills()
        return all(self.capability.lower_confidence(s, 1 - 0.05) >= 0.9
                   for s in required)

    def verify_preference(self, plan) -> bool:
        """软偏好：仅要求可解释排序一致，不做跨用户效用聚合"""
        return self.pref.explainable_score(plan) >= self.pref.min_score

    def verify_privacy(self) -> bool:
        """Rényi-DP 顺序组合：ε_total(α_p) = Σ ε_k(α_p) ≤ ε_max"""
        return self.rdp_budget.total() <= self.epsilon_max + 1e-9

    def verify_consent(self, now: float) -> bool:
        """同意令牌有效、未过期、未撤回、覆盖当前用途"""
        return (not self.consent.revoked and now <= self.consent.expiry and
                self.consent.scope.covers(self.consent.current_purpose))

    def verify_all(self, plan, now: float) -> bool:
        return (self.verify_constraints(plan) and
                self.verify_capability(plan) and
                self.verify_preference(plan) and
                self.verify_privacy() and
                self.verify_consent(now))

    def revoke(self, reason: str):
        """撤回同意：立即失效，并触发下游证书失效"""
        self.consent.revoke(reason)

# IP-446 Checkpoint & Progress Ledger (CPL) — 检查点与进度账本
# ============================================================
@dataclass
class CheckpointLedger:
    """阶段边界 Merkle 检查点链 + 回滚预算证书"""
    entries: list['Checkpoint'] = field(default_factory=list)
    merkle_root: bytes = b'\x00' * 32
    R_max: float = 0.05               # 单次回滚代价上界（归一化能量）
    rollback_budget: float = 0.2      # 全生命周期回滚能量预算

    def append(self, k: int, state_digest: bytes, cost: float):
        entry = Checkpoint(k=k, digest=state_digest, cost=cost,
                           parent=self.merkle_root)
        self.merkle_root = sha256(self.merkle_root + entry.encode())
        self.entries.append(entry)

    def rollback_cost(self, from_k: int, to_j: int) -> float:
        """从阶段 k 回滚到 j 的代价（仅统计阶段边界重放）"""
        return sum(self.entries[i].cost for i in range(j, from_k))

    def verify_recovery(self, from_k: int, to_j: int,
                        spent_energy: float, remaining_energy: float,
                        E_budget: float) -> bool:
        """已耗能 + 剩余计划能 + 回滚能 ≤ E_budget，且单次回滚 ≤ R_max"""
        cost = self.rollback_cost(from_k, to_j)
        return (cost <= self.R_max + 1e-9 and
                spent_energy + remaining_energy + cost <= E_budget + 1e-9 and
                cost <= self.rollback_budget + 1e-9)

    def verify_chain(self) -> bool:
        """重放哈希链，检测篡改/断链"""
        root = b'\x00' * 32
        for e in self.entries:
            root = sha256(root + e.encode())
        return root == self.merkle_root

# IP-447 TPC 时变个性化准入门
# ============================================================
@dataclass
class TemporalPersonalizedCertificate:
    hpc_e_plus: 'HPCEPlus'
    usmc: 'UnifiedStructuralMechanicalCertificate'
    lhtc: LongHorizonTaskCertificate
    upc: UserProfileCertificate
    cpl: CheckpointLedger

    def admits(self, plan, now: float, trace: 'Trajectory',
               observed_drift: float, from_k: int, to_j: int,
               spent_energy: float, remaining_energy: float,
               E_budget: float) -> bool:
        # 1-7. v24 基础七证（安全/版本/覆盖/专利/结构/力控/轻量化）
        if not self.usmc.admits(plan, *self._v24_args()):
            return False
        # 8. 长程时序 + 终止 + 漂移
        if not self.lhtc.verify_all(trace, observed_drift):
            return False
        # 9. 画像约束 + 能力 + 偏好 + 隐私 + 同意
        if not self.upc.verify_all(plan, now):
            return False
        # 10. 检查点链完整 + 回滚预算可行
        if not (self.cpl.verify_chain() and
                self.cpl.verify_recovery(from_k, to_j, spent_energy,
                                         remaining_energy, E_budget)):
            return False
        return True

    def stage_admit(self, k: int, stage_outcome, plan, now: float,
                    trace, observed_drift: float) -> bool:
        """阶段边界续期：任一证书失效即拒绝续期并触发退化"""
        if not self.lhtc.renew(k, stage_outcome, observed_drift):
            return False
        if not self.upc.verify_all(plan, now):
            return False
        return self.cpl.verify_chain()
```

## 3. 正确性论证（增量）

### 引理 9（长程任务证书的时序-终止-漂移三重保证）
**陈述**：若 `LHTC.verify_all(trace, κ̂) = True`，则 (1) 轨迹 τ 带裕度满足 φ（ρ_φ ≥ ε_φ）；(2) 在进度上鞅假设下 E[T] ≤ V_0/δ_min 且 P(T>H) ≤ V_0/(δ_min·H) ≤ α_h；(3) 实测漂移 κ̂ ≤ κ，tube-MPC 的鲁棒不变集假设成立。

**证明**：
1. STL 鲁棒度的可靠性（soundness）是标准结论：ρ_φ(τ,t) ≥ 0 ⇒ (τ,t) ⊨ φ，取 ε_φ 裕度即得带裕度满足。
2. 令 M_k = V_k + k·δ_min。由 E[V_{k+1}|F_k] ≤ V_k − δ_k ≤ V_k − δ_min，得 E[M_{k+1}|F_k] ≤ M_k，即 M 为非负下界 −kδ_min 的（平移）上鞅；在停时 T 上 E[V_T] + δ_min·E[T] ≤ V_0，而 V_T ≥ 0，故 E[T] ≤ V_0/δ_min。再由 Markov 不等式 P(T>H) ≤ E[T]/H ≤ V_0/(δ_min·H)。
3. 漂移界保证每阶段真实动力学落在 tube 内，鲁棒不变集递推成立；κ̂ > κ 时 `verify_drift` 直接拒绝续期，避免用失效假设继续承诺。
∎

### 引理 10（用户画像证书的约束-能力-隐私-同意四重保证）
**陈述**：`UPC.verify_all(plan, now) = True` ⟺ 计划 π 同时满足：(1) 硬约束可行且所用画像属性均已验证；(2) 所需技能 ⊆ 能力包络（置信下界 ≥ 0.9）；(3) Rényi-DP 顺序组合预算 ε_total(α_p) ≤ ε_max；(4) 同意令牌有效、未过期、未撤回且覆盖当前用途。

**证明**：
1. 硬约束由 `ConstraintSet.feasible` 直接判定；`evidence_ledger.is_verified` 阻断未经验证的属性进入硬约束，防止以刻板印象替代证据。
2. 能力包络用单侧置信下界，避免「平均能力达标但个体失败」的幸存者偏差。
3. RDP 顺序组合：对自适应机制序列，ε_total(α_p) = Σ_k ε_k(α_p) 成立（Mironov 2017），再经标准转换得 (ε,δ)-DP；`rdp_budget.total()` 为保守上界。
4. 同意是显式令牌而非隐式默认；撤回/过期/越权用途任一发生即 `verify_consent=false`，下游证书随之失效。
∎

### 引理 11（检查点账本的可恢复性保证）
**陈述**：若 `CPL.verify_chain() ∧ CPL.verify_recovery(...)` 为真，则任意阶段 k 的失败可回滚到 j < k，且 (a) 单次回滚代价 R ≤ R_max；(b) 回滚后总能量不超 E_budget；(c) 账本未被篡改。

**证明**：
1. `verify_recovery` 逐项检查 R ≤ R_max、spent + remaining + R ≤ E_budget、R ≤ rollback_budget，三者合取即 (a)(b)。
2. Merkle 链的碰撞阻力保证任意条目改动都会改变根哈希，`verify_chain` 失败即检出篡改（c）。
3. 阶段边界均设检查点，故任意 k 都存在 j < k 的可回滚点。
∎

### 引理 12（时变个性化单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v25 ⊆ Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：在引理 8 基础上增加四条退化路径：
- 任务时限延长/进度停滞 → `LHTC.renew=false` → `TPC` 拒证 → 退回 `Exec_v24`（缩短时限重规划，保留结构-力学证书）。
- 画像漂移/同意撤回 → `UPC.verify_all=false` → `TPC` 拒证 → 退回 `Exec_v24`（切换通用画像，停止个性化）。
- 隐私预算耗尽 → `UPC.verify_privacy=false` → `TPC` 拒证 → 退回 `Exec_v24`（停止画像查询，按群体级策略运行）。
- 回滚超预算/链篡改 → `CPL=false` → `TPC` 拒证 → 退回 `Exec_v24`（保守停机或人工接管）。
- 组合失效取交集，集合单调性保持。
∎

### 定理（TPC 时变个性化准入门的安全-合规-可部署-可保护-结构-时序-个体完备性）
**陈述**：对任意计划 π 与时刻 now，`TPC.admits(π, now) = True` ⟺ π 同时满足：
(1) 物理接地安全（几何∧规范∧负信息∧能量∧差距）；
(2) 云边版本一致性与统计覆盖承诺；
(3) 少样本适应后的 conformal 覆盖 ≥ 1−α；
(4) 核心模块专利保护完备且无侵权风险；
(5) 结构应力/能量/可制造性三重达标；
(6) 力控无源性/带宽/稳定性三重达标；
(7) 轻量化刚度/质量/屈曲三重达标；
(8) 长程时序鲁棒、终止概率有界、漂移假设成立；
(9) 画像约束/能力/偏好/隐私/同意五重达标；
(10) 检查点链完整且回滚预算可行。

**证明**：由 `TPC.admits` 的十个连言条件与引理 1–3、5–7、9–11 直接可得。必要性：任一条件缺失即拒证，对应十类风险之一未被缓解。充分性：十条件全满足，由引理 4、8、12 保证执行集单调退化链与统计覆盖，构成完整闭环。
∎
