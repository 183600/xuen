# 第 66 轮（承接第 65 轮「VISTA 视觉知情时序归因」IP-214~223；灵感循环第 1 轮；本轮灵感：「决策规划」×「分层规划」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**当故障不在有限假设集内、且视觉与几何共享同一个分布外失效源时，FIR 会把未知的复合故障强行归入最近假设、只膨胀错误的球；系统反而因为「已经归因」而更自信地继续执行。** 这暴露了一个更上游的问题：VISTA 仍然默认「**计划结构是对的，只是执行需要被认证**」。它回答「哪一层坏了、膨胀哪个球、执行几步」，却没有回答「**现在到底该行动、该探测、还是该换一层重规划**」，也没有回答「**抽象计划是否真的能被具体执行细化**」。本轮把提问再上移一层：**不是如何安全地执行一个给定计划，而是如何在一个分层抽象里，用有限的风险预算做「行动 / 探测 / 升级 / 重规划」的联合决策，并保证抽象到具体的细化可靠。** 本轮核心命题是：
>
> **把「故障可归因的安全执行」升级为「风险预算约束下的分层信息-决策规划」：把探测、承诺、升级、重规划都变成一等决策变量；用可消费的风险账本把任务级风险预算沿抽象层级守恒地分解；用细化见证（refinement witness）保证抽象计划到具体认证前缀的向下可靠性；用分层故障归因决定「该在哪一层重规划」。**

## 0. 直觉与动机

**灵感 1（决策规划 → 从「反应式归因」到「信息-行动联合决策」）**
直觉：VISTA 的 AFA 只在归因模糊时才探测，本质仍是一条阈值触发的反应式规则。真正的决策规划要问三个问题：(i) 这次探测的**期望收益**（降低不确定性 → 解锁更低风险、更高成功率的动作）是否超过它的**物理风险 + 时间成本 + 机会成本**？(ii) 现在「不探测、等自然接触阶段激励出现再归因」是否更优？(iii) 什么时候**停止**探测、接受不确定并保守行动，才是最优停止？把「动作」和「测量」放进同一个风险约束的 POMDP，用**单位风险的信息价值密度**排序，才是「决策规划」的语言；互信息只是它的一个特例。

**灵感 2（分层规划 → 抽象既是加速器，也是风险容器）**
直觉：分层规划（options / HTN）让我们在长视界上做粗粒度决策、在短视界上做细粒度执行，把「规划多长」与「承诺多深」解耦。但它有一笔隐藏债务：**抽象层做出的承诺，必须能被下层真正细化执行**。若抽象模型错了（前置条件、效果、时长、接触模型任一失配），上层的「安全」只是幻觉；而残差又总是在底层传感器上显现，系统会误以为「是眼睛坏了」，不断重标定底层，却永远不去怀疑「计划本身不可细化」。因此分层规划必须配一张**向下细化证书**（simulation relation + refinement gap），而不是只做抽象搜索。

**灵感 3（合流 → 风险预算沿抽象树守恒）**
直觉：VISTA 的 α_chunk 是「每块」预算。长任务有 T 个块，风险就线性累积成 T·α_chunk；无论每块多小，任务越长越不安全——这等于「每一步都赌一次」。分层规划天然提供一棵预算分解树：**任务预算分给子目标，子目标分给技能，技能分给动作块，块分给原语步**。只要规定「父预算 = 子预算之和 + 保留」，风险就像资源一样沿树守恒：任意叶层分配之和 ≤ α_task。于是任务级总风险有界、**与任务长度无关**——「长预测」从「每一步都赌一次」变成「整条任务只赌一次总预算」。这是本轮的数学支点。

**灵感 4（三灵感合流 → HALO：Hierarchical Attribution-aware Layered Options，分层归因知情选项规划）**
闭环：VISTA 语义链 → 分层抽象 φ_ℓ → HOP 分层决策（act / probe / escalate / replan / abort）→ HFA 分层故障归因（输出「哪一层」）→ RBL 风险预算账本（沿细化树守恒）→ CSP-H 分层规划（options/HTN）→ HSC 分层认证（高层承诺 c_ℓ、底层前缀 k*）→ 只执行已提交前缀 → 实时残差采集与分级早停 → 重归因。第 65 轮把「接触」拆成「接触前/中/后」，HALO 把「计划」拆成「任务段/技能/块/原语」，并让每一层都对应一个**可归因的规划故障源**与一份**可消费的风险预算**。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → HFA**：故障假设增 `H_abs`（抽象/细化错）、`H_plan`（分解不可行/目标误设）、`H_budget`（风险模型乐观）；每层残差签名带层级索引，归因输出「故障 + 层级 ℓ*」。
- **AFA → HOP**：探针选择从「最大化故障假设互信息」升级为「最大化风险归一化信息价值 + 最优停止」，与物理动作同台比较。
- **CSC → HSC**：从单块认证前缀升级为分层认证——高层承诺 c_ℓ、底层前缀 k*，预算由 RBL 逐层下发。
- **RSC-V → RSC-H**：不确定半径按「归因类型 × 层级」分配，只膨胀该层该源的球。
- **CSP-V → CSP-H**：从块级 A* 升级为 options/HTN 分层规划，每个节点带细化见证、细化缺口与预算标签。
- **AIC-V → AIC-H**：干扰集增抽象投毒、层级错配、细化缺口低报、预算乐观偏置。
- **OLP / DIR / SSB**：在线证据融合增抽象层残差与预算残差；实时流仍不写学习、不写预算。
- **J_vista → J_halo**：证书增 `risk_ledger`、`voi_trace`、`refinement_witness_hash`、`refinement_gap`、`level_commit`、`abstraction_ver`、`hfa_level`。

## 1. 形式化定义（增量：定义 233–246）

- **定义 233（HALO 闭环）**：HALO = (VISTA, L, O, R, RBL, HOP, HFA, RC, J_halo)。定位：VISTA 的「分层决策 + 风险预算 + 细化可靠性」升级。不变式：**分层推断、HOP 决策、HFA 归因、RBL 记账、HSC 证书只在语义流；实时流只执行已提交前缀、只读账本、只做分级早停，零学习写、零预算写。**
- **定义 234（分层状态抽象与选项）**：层 ℓ∈L={0 原语, 1 动作块, 2 技能/选项, 3 任务段}。抽象映射 φ_ℓ:S→S_ℓ，φ_0=id。选项 o_ℓ=(I_o⊆S_ℓ, β_o:S_ℓ→[0,1], π_o:S_ℓ→ΔO_{ℓ−1}, μ_o:S_ℓ→Δℝ_+)，I 启动集、β 终止概率、π 子选项策略、μ 时长分布。动作块是 ℓ=1 的固定时长选项；任务段是 ℓ=3 的宏选项。在 ℓ 层规划 K_ℓ 个选项，等价于原语层约 ∏_ℓ K_ℓ 步——**时间抽象即视界放大**。
- **定义 235（细化算子与细化树）**：细化算子 R_ℓ:O_ℓ→2^{O_{ℓ−1}^*} 把抽象选项映射为下层选项序列集合（可为随机策略）。递归展开得细化树 𝒯(o_ℓ)，叶为 ℓ=0 原语。若 R_ℓ(o)=∅，称该抽象选项**不可细化**。抽象可行 ≠ 可细化，这是分层规划的核心债务。
- **定义 236（近似仿真、细化见证与细化缺口）**：关系 ≼_ℓ⊆S×S_ℓ 为 ε-近似仿真，若 (s,s̄)∈≼_ℓ ⇒ d_ℓ(φ_ℓ(s),s̄)≤ε_abs，且对 R 对应的任意 (a,ā) 有 (T(s,a),T_ℓ(s̄,ā))∈≼_ℓ。细化见证 W_ℓ 是 ≼_ℓ 的可机器检查证书（仿真关系 / 抽象解释的 Galois 连接 / 区间算术）。细化缺口 g_ℓ(s,o)=max_{a∈R(o)} d_ℓ(φ_ℓ(T(s,a)), T_ℓ(φ_ℓ(s),ā))。HALO 只信任「W_ℓ 有效且 g_ℓ≤ḡ_ℓ」的抽象；否则标 `abstraction_unreliable`，禁止据其作安全承诺。
- **定义 237（风险预算账本 RBL）**：任务级预算 α_task∈(0,1)。账本是细化树上的守恒资源：细化守恒 α(o_ℓ)=Σ_{o'∈R(o_ℓ)}α(o')+ρ_reserve(o_ℓ)；一次认证决策 d 消费 α_d=其认证越界概率上界；t 时刻分配的 α_t 只依赖 t 之前观测（predictable）；下层可借预算但须在结算点恢复守恒。由归纳，任意叶层分配之和 ≤ α_task。**风险从「每步一次赌注」变为「整条任务一次总赌注」。**
- **定义 238（分层决策问题 HOP）**：在信念 b（对隐藏状态与故障假设）上，决策 d∈D={act(o), probe(p), escalate(ℓ→ℓ+1), replan(ℓ), abort}。HOP 是风险约束 POMDP：max_π E[Σ_t γ^t U(s_t,d_t)]，s.t. E[Σ_t risk(d_t)]≤α_task 且 CVaR_β(risk)≤ρ_max。act 追求任务效用，probe 追求信息，escalate 换更粗更可靠的抽象，replan 在同层换分解，abort 保底。**信息不免费**，必须与行动在同一目标下比较。
- **定义 239（信息价值、风险密度与最优停止）**：VoI(d)=E_{z∼p(·|b,d)}[V(b_z)]−V(b)，V 为在 b 下的最优期望效用。风险-时间归一化密度 η(d)=VoI(d)/(λ_r·E[risk(d)]+λ_t·E[time(d)]+ε)。选择 d*=argmax_{d∈D_cert} η(d)，D_cert 为账本允许且满足物理风险约束的决策集。探测最优停止：当 max_p η(p)≤λ*（预算约束的 Lagrange 影子价格）或边际互信息<δ_fi 时停止，转行动或保守降级。**「模糊就探」升级为「值得才探、探够就停」。**
- **定义 240（分层故障归因 HFA）**：ℋ_HALO=ℋ_VISTA∪{H_abs 抽象/细化错（g_ℓ>ḡ_ℓ 或 W_ℓ 失效）, H_plan 分解/子目标不可行或目标误设（抽象可行但无可细化）, H_budget 风险模型乐观（实际越界率>分配预算）}。每层残差签名 ρ_ℓ=[ē_abs, ḡ_ℓ, e_refine, e_budget, ē_vista]ᵀ。归因输出 (H,ℓ*)：H_abs→升层并收紧 ḡ；H_plan→同层重分解；H_budget→收缩 α 并重校准；VISTA 系列→交回 ℓ=1 处置。**归因决定「在哪一层动手」，而不只是「膨胀哪个球」。**
- **定义 241（分层承诺与不可逆视界）**：层 ℓ 的承诺深度 c_ℓ∈ℕ 为实际执行、不可回滚的选项数；不可逆视界 m_ℓ 为该层「从决策到越过不可逆点」的最大选项数。要求 c_ℓ≤m_ℓ，且原语层复合承诺 ∏_ℓ c_ℓ≤m_0。上层规划视界 K_ℓ 可远大于 c_ℓ（长预测），但只提交 c_ℓ（短承诺）。VISTA 的 k*≤m 是 c_1≤m_1 的特例。
- **定义 242（分层安全证书 HSC）**：对层 ℓ 的抽象选项 o，HSC 检查：(i) 账本守恒且预算非负；(ii) 细化见证 W_ℓ 有效、g_ℓ≤ḡ_ℓ；(iii) 对后验支持集内每个故障假设与每个细化叶，认证前缀满足 ρ_safe≥0；(iv) 承诺 c_ℓ≤m_ℓ。输出 (c_ℓ, k*, α_consumed, margin)；只有 HSC 通过的选项才进入分层计划。
- **定义 243（升级/重规划触发）**：实时残差超过层级 conformal 上界 q_ℓ(α) 或细化缺口超限时，按层级触发：e_abs>q_abs → escalate(ℓ→ℓ+1)；R_ℓ(o)=∅ → replan(ℓ) 或 escalate；e_budget>0（实际消耗超分配）→ 收缩 α 并重归因。触发必须携带层级索引 ℓ，避免「只会重标定传感器」的层级盲。
- **定义 244（预算重分配控制律）**：设层 ℓ 的敏感度 s_ℓ=∂P(任务失败)/∂α_ℓ 的估计。在守恒约束下按 α_ℓ←α_ℓ·(1+κ·ŝ_ℓ)/归一化、Σα_ℓ=剩余预算 重分配；借贷以未来保留抵扣。目标是让「最缺预算且最敏感」的层获得额度，同时不破坏 Σ≤α_task。
- **定义 245（HALO 证书 J_halo）**：J_halo=(J_vista, risk_ledger_state, voi_trace, refinement_witness_hash, refinement_gap, level_commit, abstraction_ver, hfa_level)。Valid ⇔ Valid(J_vista) ∧ 账本守恒且非负 ∧ 见证有效 ∧ g≤ḡ ∧ 每层 c_ℓ≤m_ℓ ∧ 归因层级与处置一致 ∧ 升级触发均带层级。
- **定义 246（HALO 闭环算子）**：语义流 [VISTA 语义链→分层抽象 φ→HOP 决策→HFA 归因(层级)→RBL 分配→CSP-H 分层规划→HSC 分层认证→提交 c_ℓ]；实时流 [读账本→执行已提交前缀→层级残差采集→分级早停/升级触发→J_halo 构建]。所有预算与决策写操作在语义流。

## 2. 关键算法骨架

```python
# HOP：把行动、探测、升级、重规划放进同一个风险约束决策
def choose_decision(belief, ledger, level, candidates):
    feasible = [d for d in candidates if ledger.allows(d, level)]
    def score(d):
        q    = expected_utility(d, belief)
        voi  = value_of_information(d, belief)
        cost = (lam_r * expected_risk(d, belief)
                + lam_t * expected_time(d) + 1e-9)
        return (q + voi - lam_b * ledger.price(d, level)) / cost
    d_star = max(feasible, key=score)
    if is_probe(d_star) and voi_density(d_star, belief) <= lam_star:
        return act_or_conservative(belief, ledger, level)   # 探够就停
    return d_star

# RBL：父预算 = 子预算之和 + 保留；任意叶子和 ≤ alpha_task
def allocate(o, alpha, tree):
    children = tree.refine(o)
    if not children:
        return {o: alpha}
    budget = alpha - rho_reserve(o)
    w = sensitivity_weights(children)          # Σw = 1
    return {c: budget * wi for c, wi in zip(children, w)}

def spend(ledger, d, alpha_d):
    assert alpha_d <= ledger.remaining(d.level)
    ledger.remaining[d.level] -= alpha_d
    ledger.commit(d, alpha_d)                  # 只记账，不在这里做安全承诺
    return ledger

# HFA：层级化签名 → (故障, 层级)
def attribute(phases_by_level, gaps, budget_residual):
    rho = concat([phase_signature(phases_by_level[l]) for l in LEVELS],
                 gaps, budget_residual)
    post = softmax({h: loglik[h](rho) + logprior[h] for h in H_HALO})
    h_star = argmax(post); level = level_of(h_star)
    if post[h_star] < 1 - delta: return 'ambiguous', None, post
    return h_star, level, post

def directed_fix(h, level, state):
    if h == 'H_abs':    return escalate(level + 1), tighten_gap(state)
    if h == 'H_plan':   return replan(level), new_decomposition(state)
    if h == 'H_budget': return shrink_budget(state), recalibrate(state)
    return vista_fix(h, state)                 # 交回 VISTA 的 ℓ=1 处置

# HSC：高层承诺 c_l，底层认证前缀 k*；承诺不越过不可逆视界
def hierarchical_certificate(o, level, post, m, alpha):
    if not witness_valid(o, level) or gap(o, level) > g_bar[level]:
        return None, 0, 'abstraction_unreliable'
    c = min(c_max[level], m[level])
    k = csc.certified_prefix(o.plan, post, m[0], alpha / c)
    return c, k, 'ok'
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（风险预算守恒）**：若细化守恒式与「可预测分配」成立，则任意叶层分配之和 ≤ α_task，且任务全程至少一次越界的概率 ≤ Σ_t α_t ≤ α_task（union bound）；该界**与任务长度 T 无关**。对照 VISTA：T 个块累积 T·α_chunk，长任务下失效。这是 HALO 相对 VISTA 的第一处严格改进。
- **引理 10（细化可靠性）**：若 ≼_ℓ 是 gap≤g 的 ε-近似仿真，抽象安全裕度 ρ̄ 关于抽象距离 L_g-Lipschitz，则具体裕度 ρ≥ρ̄−L_g·g。故只需抽象层验证 ρ̄≥L_g·ḡ+缓冲，即可保证具体层安全；g=0 时退化为精确仿真。若 g>ḡ，则拒绝该抽象的安全承诺。
- **定理 9（VoI 贪心的近最优性）**：在信息增益对观测自适应子模（adaptive submodular）、风险预算为背包约束时，按 η 贪心选择探针/行动可达最优自适应策略的 1−1/e；Lagrange 松弛下阈值停止规则 λ* 对松弛问题最优，对偶间隙有界。AFA 的互信息贪心是其在 λ_r=λ_t=0、只比信息时的特例。
- **定理 10（HALO 端到端）**：在 A94–A99（抽象是带有效见证的 ε-仿真；预算模型校准；各层证书可靠；故障假设含真值；细化算子可靠）下，Valid(J_halo) ⇒ 任务累计越界 ≤α_task ∧ 故障被归因到正确层级（或显式 ambiguous 并保守降级）∧ 每层承诺 c_ℓ≤m_ℓ ∧ ℓ=1 继承 VISTA 全部安全性质。
- **命题（视界放大不放大承诺）**：L 层、每层规划视界 K_ℓ、承诺 c_ℓ，则原语规划视界 ≈∏K_ℓ，原语承诺 ≈∏c_ℓ≤m_0。若 K_ℓ/c_ℓ=r，则「视界/承诺」放大 r^L，而承诺与风险均不变。**这正是「分层规划」的严格收益：指数级拉长规划视界，不加深不可逆承诺。**

## 2. 形式化定义（完整版）

**定义 233（HALO 闭环）** HALO 是 VISTA 的「分层决策 + 风险预算 + 细化可靠性」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 LAA（分层抽象与选项）、ROP（细化算子与见证）、RBL（风险预算账本）、HOP（分层选项决策）、HFA（分层故障归因）、HSC（分层安全证书），并原位升级 CSP-V→CSP-H、RSC-V→RSC-H、WCV-V→WCV-H、AIC-V→AIC-H、J_vista→J_halo。不变式：**分层推断、HOP 决策、HFA 归因、RBL 记账、HSC 证书只在语义流；实时路径只执行已提交前缀、只读账本、只做分级早停，零学习写、零预算写。**

**定义 234（分层状态抽象与选项）** 对层 ℓ∈L={0,1,2,3}，给定抽象映射 φ_ℓ:S→S_ℓ（φ_0=id）。选项
o_ℓ=(I_o⊆S_ℓ, β_o:S_ℓ→[0,1], π_o:S_ℓ→ΔO_{ℓ−1}, μ_o:S_ℓ→Δℝ_+)，
其中 I_o 为启动集，β_o 为终止概率，π_o 为子选项策略，μ_o 为时长分布。动作块 A_t 是 ℓ=1 的固定时长选项（μ=H·dt 退化分布）；技能是 ℓ=2 的选项，由动作块序列构成；任务段是 ℓ=3 的宏选项，由技能序列构成。时间抽象的直接后果：在 ℓ 层规划 K_ℓ 个选项，约等于在原语层规划 ∏_{j≤ℓ} K_j 步，因此**高层可以用极低代价获得极长视界**。

**定义 235（细化算子与细化树）** 细化算子 R_ℓ:O_ℓ→2^{O_{ℓ−1}^*} 把抽象选项映射为下层选项序列集合（可为随机策略，此时按策略采样展开）。递归展开得到细化树 𝒯(o_ℓ)，叶节点是 ℓ=0 原语。若 R_ℓ(o)=∅，称 o **不可细化**（abstract-feasible but not refinable）。注意「抽象可达」与「存在具体可执行细化」是两件不同的事：前者由抽象模型判定，后者由细化算子与具体模型共同判定，这正是分层规划最容易被忽视的债务。

**定义 236（近似仿真、细化见证与细化缺口）** 关系 ≼_ℓ⊆S×S_ℓ 称为 ε-近似仿真，若 (s,s̄)∈≼_ℓ 蕴含 d_ℓ(φ_ℓ(s),s̄)≤ε_abs，且对任意经 R 对应的 (a,ā) 有 (T(s,a), T_ℓ(s̄,ā))∈≼_ℓ。细化见证 W_ℓ 是 ≼_ℓ 的可机器检查证书（离散系统可用仿真关系矩阵；连续系统可用区间算术 / 抽象解释的 Galois 连接 / 局部 Lipschitz 界）。细化缺口定义为
g_ℓ(s,o)=max_{a∈R(o)} d_ℓ(φ_ℓ(T(s,a)), T_ℓ(φ_ℓ(s),ā))。
HALO 只信任「W_ℓ 有效且 g_ℓ≤ḡ_ℓ」的抽象；否则把该层标为 `abstraction_unreliable`，禁止据其作安全承诺，并触发定义 243 的升级。**见证是「抽象层安全」能落到「具体层安全」的唯一桥梁。**

**定义 237（风险预算账本 RBL）** 任务级风险预算 α_task∈(0,1)。账本是细化树上的守恒资源，四条规则：
1. **细化守恒**：对每个内部节点 o_ℓ，α(o_ℓ)=Σ_{o'∈R(o_ℓ)}α(o')+ρ_reserve(o_ℓ)，ρ_reserve≥0；
2. **消费**：一次认证决策 d 消费 α_d=其认证越界概率上界；
3. **可预测性**：t 时刻分配的 α_t 只能依赖 t 之前的观测（predictable），不得偷看未来；
4. **借贷**：下层可向上层借预算，但须使守恒式在结算点恢复（借额计入保留，未来扣回）。
由归纳可得：任意叶层分配之和 ≤ α(o_root)=α_task。因此**风险不再是「每块赌一次」的线性累积，而是整条任务的一次总预算**；即使任务有一千个块，总越界概率仍 ≤α_task。

**定义 238（分层决策问题 HOP）** 在信念 b（对隐藏状态与故障假设的后验）上，决策
d∈D={act(o), probe(p), escalate(ℓ→ℓ+1), replan(ℓ), abort}。
HOP 是带风险约束的 POMDP：
max_π E[Σ_t γ^t U(s_t,d_t)]，s.t. E[Σ_t risk(d_t)]≤α_task，CVaR_β(risk)≤ρ_max。
其中 act 追求任务效用，probe 追求信息，escalate 换更粗但更可靠的抽象，replan 在同层换分解，abort 保底。核心立场：**信息不是免费的**——探测消耗时间、预算，且可能带来物理风险（即使很小），故必须与物理行动在同一个目标与同一个账本下比较，而非用「模糊就探」的规则替决策。

**定义 239（信息价值、风险密度与最优停止）** 决策 d 的信息价值
VoI(d)=E_{z∼p(·|b,d)}[V(b_z)]−V(b)，
其中 V(b) 为在信念 b 下的最优期望效用，b_z 为观测到 z 后的后验。定义风险-时间归一化密度
η(d)=VoI(d)/(λ_r·E[risk(d)]+λ_t·E[time(d)]+ε)。
在账本允许且满足物理风险约束的决策集 D_cert 上选 d*=argmax_d η(d)。探测最优停止：当 max_{p∈probes}η(p)≤λ*（预算约束的 Lagrange 影子价格）或边际互信息<δ_fi 时停止探测，转入行动或保守降级。该定义把 VISTA 的「模糊就探」升级为「**值得才探、探够就停**」，并把 AFA 的互信息最大化作为特例（λ_r=λ_t=0 且只比较信息时）。

**定义 240（分层故障归因 HFA）** 在 VISTA 的故障假设 ℋ_VISTA={H0,H_geo,H_force,H_model,H_vis,H_policy} 上增三类规划层故障：
ℋ_HALO=ℋ_VISTA∪{H_abs（抽象/细化关系错：g_ℓ>ḡ_ℓ 或 W_ℓ 失效）, H_plan（分解/子目标不可行或目标误设：抽象可行但无可细化）, H_budget（风险模型乐观：实际越界率>分配预算）}。
每层残差签名 ρ_ℓ=[ē_abs, ḡ_ℓ, e_refine, e_budget, ē_vista]ᵀ，整树签名按层拼接。归因输出 (H,ℓ*)：
- H_abs → escalate(ℓ*→ℓ*+1)，收紧 ḡ，重验见证；
- H_plan → replan(ℓ*)，更换分解或子目标；
- H_budget → 收缩 α、重校准风险模型；
- VISTA 系列 → 交回 ℓ=1，由 VISTA 的 directed_demote 处置。
**HFA 的产出不只是「哪个球膨胀」，而是「在哪一层动手」。**

**定义 241（分层承诺与不可逆视界）** 层 ℓ 的承诺深度 c_ℓ∈ℕ 为实际执行、不可回滚的选项数；不可逆视界 m_ℓ 为该层「从决策到越过不可逆点」的最大选项数。要求
c_ℓ≤m_ℓ，且原语层复合承诺 ∏_ℓ c_ℓ≤m_0。
上层规划视界 K_ℓ 可远大于 c_ℓ（长预测），但只提交 c_ℓ（短承诺）。VISTA 的 k*≤m 是 c_1≤m_1 的特例；HALO 把它推广为「每一层都长视界、每一层都短承诺」。

**定义 242（分层安全证书 HSC）** 对层 ℓ 的抽象选项 o，HSC 检查：
1. 账本守恒且预算非负；
2. 细化见证 W_ℓ 有效、g_ℓ≤ḡ_ℓ；
3. 对后验支持集 supp_δ(post) 内每个故障假设与每个细化叶，认证前缀满足 ρ_safe≥0；
4. 承诺 c_ℓ≤m_ℓ。
输出 (c_ℓ,k*,α_consumed,margin)。只有 HSC 通过的选项才进入分层计划；任一检查失败即按定义 243 触发升级或重规划。

**定义 243（升级/重规划触发）** 实时残差超过层级 conformal 上界 q_ℓ(α) 或细化缺口超限时，按层级触发：
- e_abs>q_abs → escalate(ℓ→ℓ+1)；
- R_ℓ(o)=∅（不可细化）→ replan(ℓ) 或 escalate；
- e_budget>0（实际消耗超分配）→ 收缩 α 并重归因。
触发事件必须携带层级索引 ℓ，避免系统形成「只会重标定底层传感器」的层级盲——这正是 VISTA 在复合故障下的行为退化模式。

**定义 244（预算重分配控制律）** 设层 ℓ 的敏感度 s_ℓ=∂P(任务失败)/∂α_ℓ 的估计。在守恒约束下按
α_ℓ←α_ℓ·(1+κ·ŝ_ℓ)/Z，Σ_ℓ α_ℓ=剩余预算
重分配；借贷以未来保留抵扣。目标：把额度给「最缺且最敏感」的层，同时不破坏 Σ≤α_task。该控制律可在语义流实现，实时流只读。

**定义 245（HALO 证书 J_halo）** J_halo=(J_vista, risk_ledger_state, voi_trace, refinement_witness_hash, refinement_gap, level_commit, abstraction_ver, hfa_level)。验证规则：
Valid(J_halo) ⇔ Valid(J_vista)
∧ 账本守恒且非负
∧ 细化见证有效 ∧ g≤ḡ
∧ 每层 c_ℓ≤m_ℓ
∧ 归因层级与处置一致
∧ 所有升级触发均带层级
∧ abstraction_ver 为当前版本。
审计链新增：为何选这个决策（voi_trace）、预算从哪来/花到哪（risk_ledger）、抽象凭什么可信（witness/gap）、承诺到哪一层（level_commit）、在哪个层级修（hfa_level）。

### IP-224/225 LAA + ROP（分层选项与细化见证）

```python
class LayeredOptions:
    LEVELS = (0, 1, 2, 3)          # 原语 / 块 / 技能 / 任务段

    def __init__(self, abstractions, options, refinements, witnesses, gaps):
        self.phi = abstractions        # phi[l]: S -> S_l
        self.options = options         # options[l]: list of Option
        self.refine = refinements      # R_l: Option -> list[list[Option]]
        self.witness = witnesses       # W_l
        self.gap = gaps                # g_l(s,o)
        self.g_bar = {l: G_BAR[l] for l in self.LEVELS}

    def abstraction_reliable(self, o, level, s):
        return (self.witness[level].valid()
                and self.gap[level](s, o) <= self.g_bar[level])

    def demand_refinement(self, o, level):
        children = self.refine[level](o)
        if not children:
            return None                # 不可细化：禁止入图
        return children
```

### IP-226 RBL（风险预算账本）

```python
class RiskBudgetLedger:
    """alpha(parent) = sum alpha(child) + reserve；叶子总和 <= alpha_task。"""
    def __init__(self, alpha_task, reserve_fn, sensitivity_fn, kappa=0.2):
        self.alpha_task = alpha_task
        self.remaining = {3: alpha_task}
        self.reserve_fn = reserve_fn
        self.sensitivity_fn = sensitivity_fn
        self.kappa = kappa

    def allocate(self, o, level):
        children = o.children
        if not children:
            return {o: self.remaining.get(level, 0.0)}
        budget = self.remaining[level] - self.reserve_fn(o)
        w = self.sensitivity_fn(children)          # 归一化 Σw = 1
        alloc = {c: budget * wi for c, wi in zip(children, w)}
        for c in children:
            self.remaining[level - 1] = self.remaining.get(level - 1, 0.0) + alloc[c]
        self.remaining[level] -= budget + self.reserve_fn(o)
        return alloc

    def allows(self, d, level):
        return d.alpha_bound <= self.remaining.get(level, 0.0)

    def spend(self, d, level):
        if not self.allows(d, level):
            raise BudgetExhausted(level)
        self.remaining[level] -= d.alpha_bound
        self.commit(d, d.alpha_bound)
        return self.remaining[level]
```

### IP-227 HOP（分层信息-决策规划）

```python
class HierarchicalDecision:
    PROBES = ('visual_probe', 'null_test', 'press', 'rub', 'tap', 'lift', 'fi_probe')

    def __init__(self, voI, risk_model, ledger, lam=(1.0, 0.1, 0.5), lam_star=0.0):
        self.voI, self.risk_model, self.ledger = voI, risk_model, ledger
        self.lam_r, self.lam_t, self.lam_b = lam
        self.lam_star = lam_star

    def choose(self, belief, level, state):
        cands = self._candidates(belief, level, state)     # act/probe/escalate/replan/abort
        feasible = [d for d in cands if self.ledger.allows(d, level)]
        if not feasible:
            return Decision('abort', None, 0.0), 0.0

        def eta(d):
            q = self._expected_utility(d, belief)
            v = self.voI(d, belief)
            cost = (self.lam_r * self.risk_model(d, belief)
                    + self.lam_t * self._time(d) + 1e-9)
            return (q + v - self.lam_b * self.ledger.price(d, level)) / cost

        d_star = max(feasible, key=eta)
        if d_star.type == 'probe' and eta(d_star) <= self.lam_star:
            return self._act_or_conservative(belief, level, state), eta(d_star)
        return d_star, eta(d_star)

    def _candidates(self, belief, level, state):
        out = [Decision('act', o, alpha_bound=state.alpha_of(o))
               for o in state.applicable_options(level)]
        out += [Decision('probe', p, alpha_bound=PROBE_ALPHA[p])
                for p in self.PROBES if state.probe_safe(p)]
        out.append(Decision('escalate', level + 1, alpha_bound=0.0))
        out.append(Decision('replan', level, alpha_bound=state.replan_alpha()))
        out.append(Decision('abort', None, alpha_bound=0.0))
        return out
```

### IP-228 HFA（分层故障归因）

```python
class HierarchicalFaultAttribution:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis',
           'H_policy', 'H_abs', 'H_plan', 'H_budget')

    def __init__(self, lik, prior=None, delta=0.15):
        self.lik = lik
        self.prior = prior or {h: 1.0 / len(self.HYP) for h in self.HYP}
        self.delta = delta

    def signature(self, per_level_phases, gaps, budget_residual):
        parts = []
        for l in (0, 1, 2, 3):
            parts.append(np.asarray(per_level_phases[l]))
        parts.append(np.asarray(gaps))
        parts.append(np.asarray(budget_residual))
        return np.concatenate(parts)

    def attribute(self, per_level_phases, gaps, budget_residual):
        rho = self.signature(per_level_phases, gaps, budget_residual)
        logp = {h: np.log(self.lik[h](rho) + 1e-12) + np.log(self.prior[h])
                for h in self.HYP}
        z = np.array(list(logp.values())); z -= z.max()
        post = {h: float(np.exp(v) / np.exp(z).sum()) for h, v in logp.items()}
        h_star = max(post, key=post.get)
        ambiguous = post[h_star] < 1.0 - self.delta
        return post, h_star, level_of(h_star), ambiguous

    def directed_fix(self, h, level, state):
        if h == 'H_abs':
            return state.escalate(level + 1).tighten_gap()
        if h == 'H_plan':
            return state.replan(level, new_decomposition=True)
        if h == 'H_budget':
            return state.shrink_budget().recalibrate()
        return state.vista_fix(h)          # H_geo/H_force/H_model/H_vis/H_policy -> VISTA
```

### IP-229 HSC（分层安全证书）

```python
class HierarchicalSafetyCertificate:
    def certify(self, o, level, post, ledger, m, alpha_alloc):
        # 1) 账本与守恒
        if not ledger.consistent() or ledger.remaining[level] < 0:
            return Cert(ok=False, reason='budget')
        # 2) 抽象可靠性
        if not o.abstraction_reliable(level):
            return Cert(ok=False, reason='abstraction_unreliable')
        # 3) 承诺深度与不可逆视界
        c = min(C_MAX[level], m[level], o.available_prefixes)
        # 4) 对支持集逐层验证，底层用 CSC
        support = {h: p for h, p in post.items() if p >= DELTA}
        ok = True
        for h in support:
            k = self.csc.certified_prefix(o.plan, {h: 1.0}, m[0],
                                          alpha_alloc / max(c, 1))
            if k < 1 or self.margin(o, h) < 0:
                ok = False
                break
        if not ok:
            return Cert(ok=False, reason='unsafe_margin')
        ledger.spend(o, level)
        return Cert(ok=True, c=c, k=k, consumed=alpha_alloc, margin=self.margin(o, None))
```

### IP-230 CSP-H（分层规划）

```python
def plan_hierarchical(goal, x_prime, phi_hat, post, ledger, level=3):
    """options/HTN 分层规划；不可细化/见证失效的节点不入图。"""
    frontier = [(level, goal)]
    plan = []
    while frontier:
        l, g = frontier.pop()
        for option in enumerate_applicable_options(g, l, phi_hat):
            if not option.abstraction_reliable(l):
                continue                                   # 抽象不可信
            children = option.demand_refinement(l)
            if children is None:
                continue                                   # 不可细化
            if not certificate_precheck(option, l, post, ledger):
                continue
            if l == 1:
                plan.append(option)                        # 块级：交给 HSC/CSC
            else:
                frontier.extend((l - 1, c.goal) for seq in children for c in seq)
    return plan
```

## 4. 推导

**引理 9（风险预算守恒）** 设细化树上每个内部节点满足 α(o)=Σ_{o'∈R(o)}α(o')+ρ_reserve(o)，ρ_reserve≥0；每个时刻 t 的分配 α_t 可预测（只依赖 t 前观测）。则叶层分配之和 ≤α(o_root)=α_task，且
P(∃t: 越界_t) ≤ Σ_t P(越界_t) ≤ Σ_t α_t ≤ α_task。
证明：对细化树作结构归纳得 Σ_{叶}α(叶)≤α(o_root)；对时间作 union bound 得第二式；可预测性保证 α_t 不是事后选择、union bound 合法。**关键**：该界只依赖总预算，不依赖任务长度 T。对照 VISTA 的每块 α_chunk：T 块累积 T·α_chunk，当 T>1/α_chunk 时界失效。∎

**引理 10（细化可靠性）** 设 ≼_ℓ 为 gap≤g 的 ε-近似仿真，即对任意 (s,s̄)∈≼_ℓ 与对应动作 (a,ā)，d_ℓ(φ_ℓ(T(s,a)),T_ℓ(s̄,ā))≤g。设安全裕度 ρ 关于抽象距离 L_g-Lipschitz。若抽象层验证 ρ̄≥0，则具体层 ρ≥ρ̄−L_g·g。因此抽象层只需验证 ρ̄≥L_g·ḡ+缓冲；g=0 时退化为精确仿真的标准结论。证明：由仿真关系把具体后继映射到抽象后继，偏差≤g，再由 Lipschitz 性得裕度最多下降 L_g·g。∎

**定理 9（VoI 贪心的近最优性）** 若信息增益函数对观测自适应子模（adaptive submodular），风险预算为背包约束，则按 η 贪心选择探针/行动可达最优自适应策略的 1−1/e；对预算约束做 Lagrange 松弛后，阈值停止规则 λ* 对松弛问题最优，原始问题的对偶间隙由 α_task 的整数性与子模性控制。AFA 的互信息最大化是 λ_r=λ_t=0 且只比较信息时的特例。∎

**定理 10（HALO 端到端归因-安全）** 在假设 A94–A99 下：
1. **风险有界**：RBL 守恒 + 引理 9 ⇒ 任务累计越界 ≤α_task，且与任务长度无关；
2. **细化可靠**：HSC 只在 W_ℓ 有效且 g≤ḡ 时放行 ⇒ 抽象安全经引理 10 传递到具体前缀；
3. **层级可归因**：三阶段与跨层残差使 S 近似块三角（VISTA 引理 7 的层级版），HFA 把故障定位到机制层 ℓ*，错误归因时判 ambiguous 并保守降级；
4. **承诺不越界**：每层 c_ℓ≤m_ℓ 且原语复合承诺 ∏c_ℓ≤m_0 ⇒ 即使故障在块首激活，也在越过不可逆点前触发升级/重规划；
5. **继承 VISTA**：ℓ=1 的 VCV/FIR/CSC 全部保留，J_halo 蕴含 J_vista。
故 Valid(J_halo) ⇒ 安全 ∧ 可归因 ∧ 可细化 ∧ 承诺受控。∎

**命题（视界放大不放大承诺）** L 层、每层规划视界 K_ℓ、承诺 c_ℓ，则原语规划视界 ≈∏_ℓ K_ℓ，原语承诺 ≈∏_ℓ c_ℓ≤m_0。若所有层 K_ℓ/c_ℓ=r，则「视界/承诺」放大 r^L，而承诺深度与风险预算均不变。证明：选项时长复合相乘，承诺沿细化树相乘；由定义 241 的约束与 RBL 守恒即得。∎

**命题（预算分配的保守界）** 若敏感度估计误差 |ŝ_ℓ−s_ℓ|≤ε_s，则定义 244 的分配相对 oracle 分配的失败概率增量 ≤Σ_ℓ ε_s·|α_ℓ−α_ℓ^oracle|，在 α 总预算固定时为 O(ε_s·α_task)。故敏感度估计不必精确，只需足够排序正确。∎

## 7. 已知风险

**一句话**：HALO 的全部论证都压在「抽象层级是带有效见证的 ε-仿真、且风险预算模型是校准的」这两个隐藏假设（A94、A95）上；一旦抽象本身失配（gap 低报、假见证、细化算子不完备），账本会**把预算花在无法细化的计划上并显示「仍有余额」**，HFA 又会因残差总在底层显现而把「计划不可细化」误判成「底层传感器漂移」——**VISTA 的「归因错误的复合故障」由此升级为「抽象错误下的预算幻觉」：系统越记账越自信，且不断在错误的层级上重标定。**

**次级风险与缓解**：
1. **抽象失配 / 假见证**：主风险。缓解：见证必须可机器检查（仿真矩阵/区间算术），g 用保守上界而非点估计；每次规划前强制重验，失效即 `abstraction_unreliable`；AIC-H 显式注入投毒。
2. **预算模型乐观**：α_d 估计偏低导致实际越界超预算。缓解：用 conformal 上界而非点估计、在线校准、e_budget>0 即收缩预算并重归因；预算只做保守记账。
3. **细化的不完备性**：R_ℓ 可能找不到可行细化，但「找不到」不等于「不存在」（搜索不完备）。缓解：有限深度完备搜索 + 显式 `no_refinement_found`（保守视为不可行），不把不完备当可行性证明。
4. **HFA 层级混淆**：H_abs/H_plan/H_budget 的残差相关，可能互相误判。缓解：跨层签名（上层 vs 下层残差对比）、主动 `fi_probe`/`replan_probe`、判 ambiguous 时联合保守。
5. **层级盲**：残差总在底层显现 → 倾向重标定传感器。缓解：HFA 强制输出层级、HOP 显式 escalate、审计链记录 hfa_level；若连续 k 次底层重标定仍不收敛，强制升层。
6. **VoI 估计依赖模型**：模型错时 VoI 失真，可能过度或不足探测。缓解：VoI 只用相对排序、加保守折扣；对最坏 VoI 做鲁棒决策；λ* 可在线学习。
7. **非平稳长任务**：预算与故障先验漂移。缓解：分阶段重置预算（保留总预算）、漂移检测触发重校准、长任务分块结算。
8. **分层规划计算量**：HTN 搜索可能超语义流预算。缓解：分支定界 + 缓存 + 只在升级时重规划；底层块仍由 VISTA 的快速 CSP 处理。
