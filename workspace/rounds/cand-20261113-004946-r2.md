# 第 3 轮迭代（灵感循环 v3：「真实世界泛化」×「意图理解」）—— 从“撤回检测”到“意图锚定泛化”

> 本轮是一次**方向校正**，不是继续加模块。v2 把 `human_*` 读成“把已完成进度撤回”，并据此把旗舰 UIP-09′ 建成“谓词回退检测→重做”。复核 v2 §2 的 32 条 `human_*` 摘要文本后，这个读法只覆盖约 **8–9/32** 的任务；至少 **26/32** 的人为干扰是**搬移目标物/支撑物**，谓词真值不变，纯回退检测器在结构上看不见它们。两个新灵感词恰好给出补丁：**意图是跨轴不变量；真实世界泛化 = 对意图的稳定锚定 + 对进度扰动的正确类型响应**。

## 0. 本轮复核的事实（来源沿用 v2 §0，复核日期 2026-11-13）

| 复核项 | 结论 | 依据 |
|---|---|---|
| `human_*` 的语义分布 | **搬移/支撑物移动 ≥26/32**；**明确撤回 8–9/32**（T31 描述不完整）；**移除/替换 3/32**；**明确遮挡 0/32**（文本未写；`O` 作为待验证类型保留） | v2 §2 的 32 条 `info.json.generalization.human_*` 文本逐条再分类（见产物区 §2） |
| v2 的 ★ 列偏差 | v2 把 T08/T11/T25/T26/T29 这类**搬移/支撑物移动**也标成撤回型，导致“至少 11 个撤回”的高估；按语义拆开后明确撤回约 **8–9/32** | 对 v2 §2 的 ★ 逐条复核 |
| v2 旗舰的显式覆盖 | DCR-R 只在“谓词真值 1→0”时触发 ⇒ 显式机制最多覆盖 **9/32** 任务 | 由 UIP-09′ 的定义直接推出 |
| 机会上界（算术） | 一次干扰发生在第 j 步后，剩余步骤分均值：2 步 50、3 步 55、4 步 50、5 步 50；全部 32 任务加权 **≈52.2 分**，**26 个含搬移任务加权 ≈52.5 分** | 官方 `scoring_points`（v2 §2）直接计算 |

| 泛化轴文本化情况 | 仍只有 `unseen_object_*` 与 `human_*` 在 `info.json` 中逐条实例化；位置/干扰物/背景三轴仍待手册确认 | 同 v2 §0（2026-11-12） |

**v2 为什么会读偏**：撤回型描述（“叠好后翻开”“拉上后再拉开”“合上后再打开”）更有戏剧性、被引用得最多；搬移型描述（“水果向右”“架子左移”“插口移开”）平淡，被当成普通域随机化忽略了。这是典型的**可得性偏差**，不是证据不足。

**一个必要的澄清**：本文按“对人类干扰的**效果**”分类（进度回退/物体搬移/遮挡/移除），不假设人类有恶意或合作意图；`human_*` 文本只描述动作，不描述动机。文本中可确认的是 `R/M/S/X` 四类；`O`（遮挡）未在摘要中明确出现，但作为真实世界可能事件保留为待验证分支。

## 1. v2 清单诊断：哪些保留、哪些升级、哪些修剪

- **保留为基础设施**：UIP-02′（计分步安全网）、UIP-08′（多端口延迟工程）、UIP-11（GSO 几何判分）、UIP-13（ACS）、UIP-15（CSG）。GSO 的几何谓词在本轮获得新用途——它们正好是 UIP-16 评论器的**弱监督标签源**；DRF 的脚本化干扰正好是 UIP-09″ 的**类型标签源**。
- **升级**：UIP-01′ → **UIP-01″**（加入 rubric 进度评论器 + 干扰类型推断）；UIP-09′ → **UIP-09″**（从“检测回退”升级为“四型干扰意图推断 + 分型响应”）；UIP-12 → **UIP-12′ DRF-I**（生成“意图保持/意图扰动”配对，而不仅是撤回演示）；UIP-14 → **并入 UIP-05′ RIG**（技能图直接由 rubric 生成，避免两套路由）。
- **修剪/降级**：把“`human_*` = 反向撤回”从**规则级事实**降回**子类假设**；把“布尔进度向量足以描述任务状态”降为**不充分**——搬移/遮挡下谓词真值不变，必须增加位姿/可见性/存在性三个观测通道。
- **新增（命中两词）**：UIP-16 RSC（rubric 进度评论器）、UIP-17 AIT（轴不变意图训练）、UIP-18 WGS（泛化签名评测）、UIP-19 IAP（意图歧义先验）、UIP-20 HRS（危害-响应调度）。

## 2. 直觉解释（先讲人话）

想象两个场景：

1. 测试时换了一个没见过的杯子。模型不该问“这个杯子的颜色/纹理和训练时一样吗”，而该问“它在任务里扮演什么角色？是要被挂到架子上的那个‘杯’吗？”——**角色/意图不变，外观是噪声**。
2. 你刚把书放上书架，人把整个书架挪了 10 厘米。这不是“把你的进度撤回”，书还在架上；但如果你只检查“书是否在架上”这个布尔谓词，你会认为一切正常，然后伸手去抓一个已经不在原位的目标。正确响应是**重新定位支撑物**，不是重做放书。

所以，真实世界泛化不是“对所有变化都不变”，而是**两层分离**：

- **意图层（invariant）**：语言 + 官方计分 rubric 定义的“要达成哪些谓词、角色如何绑定、顺序如何”。它跨外观/位置/背景/干扰物都不该变；人为干扰也不改变任务意图。
- **进度层（equivariant）**：哪些计分谓词已经达成、目标物/支撑物在哪、是否被遮挡/移除。它必须对搬移、遮挡、移除**敏感**，并给出正确的响应类型。

一句话类比：**意图是程序语义，观测轴是不同硬件，人类干扰是运行时故障；你需要一个语义状态机 + 故障分类器，而不是像素级比对。**

## 3. 严谨定义（再讲形式）

**定义 1（计分 rubric）**：任务 τ 的 rubric 为 `R_τ=(Φ_τ,w_τ,≺_τ)`，其中 `Φ_τ={φ_1..φ_m}` 是接地的布尔谓词（如 `on(cup,rack)`、`stacked(bowl2,bowl1)`），`w_i>0`、`Σw_i=100`，`≺_τ` 是计分步的偏序。官方 `scoring_points` 给出 `w` 与（隐含的）`≺`。

**定义 2（意图）**：意图是 rubric 的一个**实例化** `I=(β,≺)`，`β` 把语言中的角色（“红杯”“架子”“第二个碗”）绑定到场景中的具体实体，并（在语言有歧义时）选定一个与 rubric 一致的顺序。`G(I)={x: ∀i, φ_i(x)=1 且顺序满足}`。两个实例化若给出相同 `G(I)` 与相同得分，则视为同一意图等价类。

**定义 3（进度状态）**：`s_t∈{0,1}^m`，`s_{t,i}=1` 当且仅当第 i 个计分谓词在本 episode 中已被达成且尚未被失效（带迟滞：一旦为真，除非被扰动，不因单帧误检而清零）。

**定义 4（泛化轴与签名）**：设 `T={T_obj,T_pos,T_dist,T_bg,T_hum}` 分别为未见物品、位置、干扰物、背景、人为干扰算子。策略 π 的轴签名为 `σ(π)=(S_clean,S_obj,S_pos,S_dist,S_bg,S_hum,S_combo)`，其中 `S_a=E_{τ,x~T_a D_τ}[score_τ(π(x))]`。最坏组泛化差距 `G(π)=max_a (S_clean−S_a)`；组合交互 `I_ab=S_a+S_b−S_ab−S_clean`（>0 表示两轴差距**超可加**，即组合比单轴更糟）。`(ε,δ)`-泛化：对每个轴，`P(score ≥ S_clean−ε) ≥ 1−δ`。

**定义 5（干扰事件与四型）**：一次人为干扰是事件 `e=(type,A,t)`，`A⊆Φ_τ∪O_τ`（受影响的谓词/物体）：
- `RETRACT(R)`：`s_i:1→0`（进度被撤回）；
- `RELOCATE(M/S)`：`s` 不变，但目标物 `M` 或支撑物 `S` 的位姿显著变化；
- `OCCLUDE(O)`：可见性骤降，位姿信念暂不变；
- `REMOVE/REPLACE(X)`：物体消失或被替换，相关谓词可能不可达。

**命题 1（误差分解）**：若高层规划在 `(Î,ŝ)=(I,s)` 时正确，低层执行损失为 `ℓ_exec`，则 `E[score] ≥ 100·(1−P(Î≠I)−P(ŝ≠s)) − E[ℓ_exec]`。
（证明：对“意图错/进度错/都对”三种情况取并集界；都对时按假设得满分减执行损失。）
**推论**：真实世界泛化的主要矛盾在**意图识别误差 + 进度估计误差**，而不是像素分布偏移本身；应优先投资 rubric 进度评论器与意图歧义消解，而不是只做外观增广。

**命题 2（纯谓词检测的结构盲区）**：若事件满足 `A∩Φ=∅`（搬移/遮挡/移除不改变谓词真值），则 `Δs=0`。任何只依赖 `Δs` 的响应策略无法把该事件与“无事件”区分；因此它在搬移/遮挡子群上的显式恢复能力为 0。
（证明：`Δs` 是事件到 `{−1,0,1}^m` 的映射；当 `A∩Φ=∅` 时映射与无事件相同，故不可分。）**v2 的 UIP-09′ 正是这样的策略。**

**命题 3（核验间隔）**：对权重 `w_i`、单位时间反转风险 `λ_i`、每次核验代价 `c` 的单个可逆步骤，检测延迟约 `k/2`，期望损失约 `w_i λ_i k/2 + c/k`；最优间隔 `k* = sqrt(2c/(w_i λ_i))`，并截断到 `[1,K_MAX]`。
**推论**：高权重、高风险的步骤应更频繁核验；在有序 rubric 中，越早完成的步骤暴露时间越长（`λ_i` 累积更大），越应早核验；末步可在接近完成时加密核验。

## 4. 从两词到 v3 清单（发散→收敛）

围绕“真实世界泛化”发散：轴签名/最坏组、意图保持增广、组合轴交互、泛化差距归因。
围绕“意图理解”发散：rubric 接地、角色绑定、歧义先验、干扰者意图分类、意图-进度解耦表示。
9 个草案合并后得到 v3：**旗舰从“撤回检测”转为“四型干扰意图推断 + rubric 进度评论器”**；GSO/DRF 降为基础设施与标签源；新增 16–20。详见产物区。

**→ 本轮最值得押注**：UIP-09″（四型干扰意图推断）× UIP-16（rubric 进度评论器）——它修补 v2 旗舰对 26/32 任务的结构性盲区，且完全落在 `observation→action` API 与离线算力之内。

## 5. 本轮最大风险

**一句话**：把“意图”写成 32 条手工 rubric，容易把“意图理解”退化成“背 32 条答案”——在隐藏任务/不同角色绑定下会自信地错，且只在合成干扰上训练的类型分类器可能把真实搬移误判为撤回而反复重做。

## 1. 概念框架：意图锚定泛化 IAG

### 1.1 两层意图

- **任务意图** `I`：语言 + 官方 rubric 决定的角色绑定、计分谓词与顺序。它跨五轴**不变**。
- **干扰者意图** `θ`：人类在某一时刻想对你的进度做什么（撤回/搬移/遮挡/移除）。它跨事件**可变**，需要在线推断。

把两者混为一谈，是 v2 旗舰的根因：v2 只建模了“进度被撤回”这一种 `θ`，把其余三种当成了噪声。

### 1.2 形式定义（与想法区 §3 对齐）

- `R_τ=(Φ_τ,w_τ,≺_τ)`：rubric；`Σw_i=100`，`≺_τ` 为计分步偏序。
- `I=(β,≺)`：意图实例化；`β` 为语言角色→场景实体的绑定；`G(I)={x: ∀i φ_i(x)=1 且顺序满足}`。
- `s_t∈{0,1}^m`：进度状态，带迟滞；`s_{t,i}=1` 表示第 i 步已达成且未失效。
- `σ(π)=(S_clean,S_obj,S_pos,S_dist,S_bg,S_hum,S_combo)`：轴签名；`G(π)=max_a(S_clean−S_a)`；`I_ab=S_a+S_b−S_ab−S_clean`。
- 干扰事件 `e=(type,A,t)`，`type∈{R,M,S,O,X}`；`A` 为受影响的谓词/物体集合。

### 1.3 三个命题

**命题 1（误差分解）**：若高层规划在 `(Î,ŝ)=(I,s)` 时正确，低层执行损失为 `ℓ_exec`，则
`E[score] ≥ 100·(1−P(Î≠I)−P(ŝ≠s)) − E[ℓ_exec]`。
证明：按“意图错/进度错/都对”取并集界；都对时得满分减执行损失。∎
**推论**：泛化差距主要吃**意图识别误差 + 进度估计误差**；应优先投资评论器与歧义消解，而非只做外观增广。

**命题 2（纯谓词检测的结构盲区）**：若 `A∩Φ=∅`（搬移/遮挡/移除不改变谓词真值），则 `Δs=0`；任何只依赖 `Δs` 的响应策略无法把该事件与“无事件”区分，故其显式恢复能力为 0。
证明：`Δs` 是事件到 `{−1,0,1}^m` 的映射；`A∩Φ=∅` 时该映射与无事件相同，不可分。∎
**v2 的 UIP-09′ 正是这样的策略。**

**命题 3（核验间隔）**：对权重 `w_i`、单位时间反转风险 `λ_i`、每次核验代价 `c` 的单个可逆步骤，检测延迟约 `k/2`，期望损失约 `w_i λ_i k/2 + c/k`；最优 `k* = sqrt(2c/(w_i λ_i))`，截断到 `[1,K_MAX]`。
证明：对 `k` 求导并令 `w_iλ_i/2 − c/k² = 0`。∎
**推论**：高权重/高风险步骤更密核验；有序 rubric 中早完成步骤暴露更久（`λ_i` 累积更大），应早核验。

### 1.4 设计推论

1. 表示应**解耦**：`z=(z_I,z_s)`；`z_I` 对五轴不变，`z_s` 对四类噪声轴不变、对人类扰动等变。
2. 评论器应输出**四通道**：谓词真值 `ŝ`、任务相关物体位姿 `p̂`、可见性 `v̂`、干扰类型 `θ̂`。只输出 `ŝ` 必然漏掉搬移/遮挡。
3. 恢复应**分型**：`R→redo`、`M/S→re-localize`、`O→active sensing`、`X→salvage/fallback`。默认“regressed→redo”在搬移类上会浪费步骤分。
4. 调度应**按风险**：`k*` 随 `w_i λ_i` 下降；高权重/早暴露步骤更密核验。

## 3. UIP-16 · RSC（Rubric-State Critic）

- **目标**：把观测映射到四通道 `(ŝ,p̂,v̂,θ̂)`，为主策略提供稠密进度、回归/搬移/遮挡检测与分数塑形。
- **架构**：共享主骨干（与策略同一视觉-语言编码器）；`m` 个 rubric query（`m≤5`）输出谓词 logit；一个物体 query 池输出任务相关物体的位姿/存在性/可见性；一个事件头输出四型 logit。参数增量小。
- **弱标签流水线（离线）**：
  1. 用 GSO（UIP-11）的几何谓词在仿真回放上自动标注 `φ_i`；对无法重建的任务，用现成感知 + 人工抽检；
  2. 用数据集 `state/action` 与现成感知（分割/深度/跟踪）标注任务相关物体位姿与可见性；
  3. 用 DRF-I（UIP-12′）注入四型干扰，得到 `θ` 标签；
  4. 用时间平滑/迟滞生成 episode 级 `s` 标签。
- **损失**：`L_RSC = Σ_i BCE(φ_i) + λ_p Huber(p) + λ_v BCE(v) + λ_θ CE(θ) + λ_t TV(s_t,s_{t−1}) + λ_c Calibration`。校准用温度缩放/保形预测；回归检测用 CUSUM。
- **输出**：`(ŝ_t, p̂_t, v̂_t, θ̂_t, uncertainty)`；`Δŝ`、`Δp̂`、`Δv̂` 送入 UIP-09″。
- **单模型合规**：RSC 是同一骨干上的辅助头，不引入第二个部署模型；离线标注工具（外部 VLM/感知）不进入评测端。
- **延迟**：复用视觉 token，额外 `m+1` 个 query + 小 MLP；目标 <5% FLOPs；事件头 CPU 级。

```python
def rsc(obs, rubric):
    z = backbone.encode(obs)                 # shared with policy
    s_logits = [pred_query_i(z, rubric.phi_i) for i in range(rubric.m)]
    p, v, exist = object_head(z, rubric.objects)
    theta_logits = event_head(z, s_logits, p, v)
    return {
        "s": sigmoid(s_logits), "p": p, "v": v, "exist": exist,
        "theta": softmax(theta_logits), "u": entropy(s_logits)
    }
```

## 4. UIP-09″ · DII（Disturber-Intent Inference）

### 4.1 事件代数

| 信号 | R | M/S | O | X |
|---|---|---|---|---|
| `Δs` 有 1→0 | ✅ | — | — | 可能 |
| `Δp` 超阈值 | 可能 | ✅ | — | 可能 |
| `Δv` 骤降 | — | — | ✅ | ✅ |
| 存在性消失 | — | — | — | ✅ |

> `O` 型在当前 32 条摘要中未明确出现；但真实人扰（人手遮挡、包装遮挡）可能出现，故保留为待验证分支。`X` 与 `R` 可同时发生（如“中途把锁拿走”）。

### 4.2 推断

`P(θ|Δ) ∝ P(θ) P(Δ|θ)`；先验来自 32 条 `human_*` 的类型频率与时间（步骤完成后更可能被干扰）；用置信度门限做“不确定时先观望”。

### 4.3 分型响应

| 类型 | 响应 | 不做什么 | 备注 |
|---|---|---|---|
| R | 重做受影响谓词；保留未受影响进度 | 不整体重启 | v2 已有 |
| M/S | 重定位目标/支撑物，重算抓取/放置位姿 | 不重做已完成步骤 | **v2 缺失** |
| O | 主动感知（腕相机扫视）+ 记忆维持 | 不盲目重做 | **v2 缺失** |
| X | 尝试替代接地/弃子，优先保高权重后续步 | 不在不可达步上耗预算 | **v2 缺失** |

```python
def dii(delta, belief, budget):
    theta = infer_type(delta, prior=HUMAN_TYPE_PRIOR)
    if max(theta.prob) < CONF_THR:
        return "observe"                     # value-of-information: pause & re-look
    t = argmax(theta)
    if t == "R":  return ("redo", affected_predicates(delta))
    if t in ("M","S"): return ("relocalize", affected_objects(delta))
    if t == "O":  return ("active_sense", occluded_objects(delta))
    if t == "X":  return ("salvage", plan_remaining(belief, budget))
```

**与 v2 差异**：v2 的 `regressed→replace` 是这里的 `R` 分支；新增 `M/S/O/X` 三个分支与“不确定→观望”的价值信息决策。这样不会把搬移误判为撤回而反复重做。

## 5. UIP-01″ · IAG-RHPV（集成）

- **reset**：解析 `l` + 首帧 `o_0` → 意图后验 `{I_k,p_k}`（UIP-19）；选 `I*=argmax E[score]`；初始化 `s=0`、计划=rubric 拓扑序、`k` 由 HRS 给出。
- **get_action**：若缓冲区空或检测到事件 → 运行 RSC；`Δ` 送 DII；按类型更新 `s`/计划/重定位；按分数价值决定修复优先级；生成动作块。
- **分数感知修复**：若时间预算紧，只修复“高权重且是后续步前置”的谓词；低权重且非前置的步骤可放弃。用 `w_i × 1[是后续前置]` 排序。

```python
class IAG_RHPV:
    def reset(self, obs, lang):
        self.I = intent_posterior(lang, obs, demo_prior=IAP_PRIOR)
        self.s = zeros(self.I.m); self.plan = topo(self.I.rubric)
        self.buf = []; self.k = HRS(self.I, s=self.s)
    def get_action(self, obs):
        r = rsc(obs, self.I.rubric)
        delta = diff(r, self.prev)
        if event_detected(delta):
            resp = dii(delta, self.s, self.budget)
            self.apply(resp, r, delta)       # redo / relocalize / sense / salvage
        if not self.buf:
            k = HRS(self.I, s=self.s)        # UIP-20
            self.buf = list(self.policy.get_action(obs, self.I, self.s, k))[:k]
        return self.buf.pop(0)
```

**与 ACS/CSG 的关系**：HRS 决定“何时看”，ACS 决定“看之前先算什么”，CSG 决定“看太频繁时如何收敛”；三者不冲突。

## 6. UIP-17 · AIT（Axis-Invariant Intent Training）

| 轴 | 变换 | 意图 `z_I` | 进度 `z_s` |
|---|---|---|---|
| 未见物品 | 换同类别/同可供性资产 | 不变 | 不变（角色重绑定） |
| 位置 | 6-DoF 刚体变换 | 不变 | 不变（相对位姿） |
| 干扰物 | 增删无关物体 | 不变 | 不变 |
| 背景 | 换纹理/光照 | 不变 | 不变 |
| 人为干扰 | 注入 R/M/S/O/X | 不变 | **等变**（按事件转移） |

- **配对**：正对 `(o,T_a o)` 共享同一意图与同一进度语义；负对 `(o,o')` 改变意图（角色绑定/顺序/目标物），用于把 `z_I` 与 `z_s` 解耦。
- **损失**：`L = L_policy + α L_InfoNCE(z_I) + β L_CE(intent) + γ L_BCE(rubric) + δ L_pose + η L_cov(z_I,z_s)`；`L_cov` 惩罚意图与进度的协方差，防止“用进度泄漏意图”。
- **最坏组 DRO**：以 `g=(task,axis)` 分组，优化 `max_g L_g` 或 `CVaR_0.8(L_g)`，直接对准 worst-group，而不是平均分。
- **数据**：公开 32k + DRF-I 的配对增广；DRF-I 的仿真干扰只作为**训练增广**，真机校准仍是必需锚点。

## 7. UIP-19 · IAP（Intent Ambiguity Prior）

- **歧义来源**：语言中的“整理/收拾/收纳/放好”可能对应多个角色绑定或顺序；官方计分步是偏序时，不同拓扑序得分不同。
- **枚举**：用 Hungarian 匹配语言属性/可供性与检测实体，得到候选 `β`；对偏序枚举候选顺序（限制在前 `k` 个）。
- **示范先验**：从 32k 公开示范估计 `p(order|lang,task)` 与 `p(β|lang,task)`（小分类器/查表）；部署端只保留小头或查表，保持单模型。
- **决策规则**：`I* = argmax_I Σ_g p(g|o_0,l) · Score(I_g)`，即**最大期望得分**而非最大似然。若后验熵高，前几步用信息增益动作（腕相机扫视/轻触）降低歧义。
- **例子**：T31/T17 这类“整理/收纳”任务，语言本身不指定顺序；用示范先验选规范顺序，避免“做对了状态但顺序错”丢步骤分。
- **指标**：意图识别准确率、歧义子集上的步骤分增益、错误顺序率。

## 8. UIP-20 · HRS（Hazard-Response Scheduler）

- **推导**：`k* = sqrt(2c/(w_i λ_i))`，截断 `[1,K_MAX]`。`λ_i` 用仿真/真机日志估计；`c` 是每次核验的延迟/可信度代价（可用 UIP-15 的预算折算）。
- **示例表**（`c=5`，仅示意）：

| w\λ | 0.05 | 0.10 | 0.20 |
|---|---|---|---|
| 20 | 3.2 | 2.2 | 1.6 |
| 30 | 2.6 | 1.8 | 1.3 |
| 40 | 2.2 | 1.6 | 1.1 |
| 50 | 2.0 | 1.4 | 1.0 |

- **有序 rubric 的修正**：早完成步骤的暴露时间更长，`λ_i` 应乘以剩余步数/剩余时间；因此“早步骤更密、末步骤在接近完成时加密”。
- **约束**：`metadata` 只声明一个 `action_chunk_size=K_MAX`；实际每次可返回 `≤K_MAX` 的块，HRS 只决定本次返回多少，不改变声明。

## 10. 合规、资源、时间线

- **单模型合规**：RSC/DII 都是主骨干上的头；语言解析用规则/模板；示范先验用查表或小头；离线标注工具不部署。若规则手册禁止任何辅助头，则退化为“主策略直接输出 rubric 谓词”的多任务训练。
- **资源**：公开 32 数据集 + DRF-I 合成；1 张推理卡；RSC 额外 <5% FLOPs；DII CPU；AIT 离线多卡可选。
- **时间线**：
  - 第 1–2 周：RSC 弱标签流水线 + 3 个代表任务（T26 插网线、T27 叠碗、T19 拉链）的谓词/位姿标注。
  - 第 3–4 周：DII 四型分类 + 分型响应；DRF-I 生成配对干扰。
  - 第 5–6 周：IAG-RHPV 集成；HRS/CSG 接入；E201–E203。
  - 第 7–8 周：AIT/IAP/WGS；E204–E207。
  - 第 9 周起：真机锚点校准（E209），用真实榜单/步骤分修正代理。
- **风险**：仿真标签偏差、类型先验过拟合、核验过密伤可信度；均需真机锚点与 CSG 护栏。

**→ 押注**：UIP-09″（四型干扰意图推断）× UIP-16（rubric 进度评论器）——修补 v2 旗舰对 26/32 任务的结构性盲区，且完全落在 API 与离线算力之内。

## 11. 本轮最大风险

**一句话**：把“意图”写成 32 条手工 rubric，容易把“意图理解”退化成“背 32 条答案”——在隐藏任务/不同角色绑定下会自信地错，且只在合成干扰上训练的类型分类器可能把真实搬移误判为撤回而反复重做。
