# 第 13 轮（新循环第 1 轮）· DT-MIX / TR-FUSE：数字孪生不是风洞，是「带缺口标签的数据源」；数据配比不是拍 50/50，而是一个带约束的凸优化；技术融合不是堆模型，而是把 VLA、伺服、孪生放进同一个信赖域

> 检索/复核日期：**2026-10-31（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮是新灵感循环第 1 轮，研究线承接第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO。三个灵感词是「技术融合」「数据配比」「数字孪生」。本轮不推倒 CHUNK-SERVO 的「30 步规划 + 5 步伺服」，而是补它默认掉的一层：**CHUNK-SERVO 把执行层闭环了，但它的目标库、action head 和伺服增益仍由真实演示与手工标定决定；5 个泛化轴在数据层还是开环的。**

## 0. 先给结论：第 12 轮把最后 3 厘米闭环了，但闭环所用的数据仍是开环的

第 12 轮 CHUNK-SERVO 的三件事——30 步 VLA 规划、5 步视觉伺服、演示检索相对目标——都依赖同一个隐含假设：**33k 真实演示足以覆盖比赛会遇到的分布**。这个假设在名义条件下成立，但在比赛的 5 个泛化轴上不成立：

1. **位置泛化**：真实演示覆盖的目标位置有限。目标被移动后，检索到的相对位姿可能仍然「看起来对」，但夹爪的接近方向、预接触点、插入轴已经偏了。
2. **干扰物/背景**：腕部目标图和头部 ROI 会被干扰物/背景污染；检索的视觉描述子会把「相似背景」误当成「相似目标」。
3. **未见物品**：真实演示没有见过测试物体的外观；纯检索只能匹配到「形状相似」的旧物体，相对位姿可能差几毫米。
4. **人为干扰**：人移动目标后，CHUNK-SERVO 能检测「场景动了」，但它的目标库没有「人移动后如何恢复」的样本；伺服只能追当前目标，不知道该不该先退、再接近。

数字孪生恰好能生成这些缺失样本。但第 12 轮明确说「数字孪生只做标定/风洞，不训练策略」，理由是 sim-to-real gap。这个理由是对的，但结论太粗：**不是所有孪生数据都一样坏，坏的程度可以估计，也应该被用来决定配比。** 把孪生锁在风洞里，等于因为「有些合成数据有毒」而拒绝所有合成数据，也等于承认 5 个泛化轴只能靠 32×10 次真机 trial 去撞。

所以本轮的押注是 **DT-MIX / TR-FUSE**：

> **用数字孪生为 5 个泛化轴生成反事实样本；给每个孪生模式打一个可校准的「缺口分数」；把真实/孪生/检索数据按轴解一个带合成预算和缺口上限的配比 QP；在线把真实与孪生关键帧融合成目标位姿，再把 VLA 前馈与伺服反馈限制在一个由孪生标定的信赖域里。**

一句话：**第 12 轮把「1 秒开环」变成「167ms 闭环」；第 13 轮要把「用哪些数据、信多少孪生、让伺服改多少」也变成闭环。**

## 1. 直觉：三个词指向同一个缺口

### 1.1 技术融合：不是模型融合，是「数据源融合 + 目标融合 + 控制融合」

单模型规则堵死了「再训一个模型」的路。所以「技术融合」不能理解为模型集成或 MoE，而应该理解为三层融合，且三层共享同一个缺口信号：

- **数据源融合**：真实演示 + 孪生反事实 + 检索关键帧，按缺口加权混合，训练同一个 action head。
- **目标融合**：真实关键帧和孪生关键帧同时进检索库，输出一个带置信度的融合目标位姿，而不是硬选一个。
- **控制融合**：VLA 前馈 + 伺服反馈，在一个由孪生标定的信赖域内融合；超出信赖域不是硬压，而是触发重定位/重规划。

这三层融合的共同敌人是「不知道哪个源可信」。所以缺口分数 `g` 是本轮的核心变量：它既是数据配比的约束，也是检索加权的权重，还是信赖域半径的校准依据。**一个缺口信号，驱动三种融合。**

### 1.2 数据配比：不是拍 50/50，是按 5 个泛化轴解一个带约束的凸优化

比赛每个任务 10 次，5 个泛化轴各 2 次。这意味着每个轴权重相同，但难度、真实数据量、孪生保真度不同。naive 的「真实:孪生 = 1:1」会同时犯两个错：

- 对孪生保真度低的轴（未见物品、人为干扰），孪生数据会教坏 action head；
- 对孪生保真度高的轴（背景、位置），孪生数据明明可以大幅补覆盖，却被 1:1 拖累。

所以配比应该是一个**按轴、按源、带缺口约束的凸优化**：

```math
w_{a,s}\ge 0,\qquad
\sum_{s} w_{a,s}=1,\qquad
0\le w_{a,m}\le \rho_0\,(1-g_{a,m}),\qquad
\sum_{m} w_{a,m}\le \rho_0
```

其中 `a` 是泛化轴，`s` 是数据源（真实 `R` 或孪生模式 `m`），`g_{a,m}` 是缺口分数，`\rho_0` 是全局合成预算。缺口越大，允许的合成比例越低；配比不是超参数，是解出来的。

### 1.3 数字孪生：不是风洞，是「数据工厂 + 标定台 + 安全壳」

风洞只回答「控制器在仿真里稳不稳」；数据源要回答「这条孪生样本对真实任务有没有用」。所以孪生管线要输出三样东西：

1. **反事实样本**：位置/背景/干扰物/未见物体/人手介入下的观测-动作对；
2. **缺口分数**：每条样本/每个模式的视觉、几何、动作、动力学缺口；
3. **信赖域参数**：伺服修正的协方差 `\Sigma` 和半径 `r`，以及「多大修正曾在孪生里成功收敛」。

这三样分别喂给数据配比、目标融合、控制融合。数字孪生从「风洞」升级为「数据工厂 + 标定台 + 安全壳」。

## 3. 形式化：一个缺口信号，驱动三种融合

### 3.1 数据域与缺口

记泛化轴集合 `A = {pos, dist, bg, unseen, human}`，`|A|=5`。数据源 `s \in S = {R} \cup M`，其中 `M` 是孪生模式集合。对每个轴 `a` 和源 `s`，有数据域 `D_{a,s}`。真实数据的缺口定义为 0。

对孪生模式 `m`，定义四个归一化残差：

```math
r^{\mathrm{vis}}_{a,m}=1-\mathrm{SSIM}(\mathcal R_m,\mathcal R_R),\qquad
r^{\mathrm{geo}}_{a,m}=\mathrm{clip}\left(\frac{\mathrm{Chamfer}(\mathcal P_m,\mathcal P_R)}{0.01\,\mathrm m},0,1\right)
```

```math
r^{\mathrm{act}}_{a,m}=\mathrm{clip}\left(\frac{\mathrm{NLL}_m-\mathrm{NLL}_R}{\kappa},0,1\right),\qquad
r^{\mathrm{dyn}}_{a,m}=\mathrm{clip}\left(\frac{\mathrm{RMSE}(\tau_m,\tau_R)}{0.01\,\mathrm m},0,1\right)
```

缺口分数：

```math
g_{a,m}=\sigma\!\left(\beta_0+\sum_{j=1}^{4}\beta_j r^{j}_{a,m}\right)\in[0,1]
```

`\beta` 不是在代码里拍脑袋，而是用 G8 的校准集拟合：对每个孪生模式/任务做一次小规模 proxy 微调，测「孪生-only 模型在真实验证集上的损失增量」作为负迁移标签 `y`，再拟合 `y \approx \sigma(\beta^T r)`。若没有校准集，退化为等权 `\beta_j=1`、`\beta_0=-2`，并把 `\rho_0` 压到 0.1。

### 3.2 配比目标

配比向量 `w_a \in \Delta^{|S|}`，满足 §1.2 的约束。训练分布：

```math
P_a(w_a)=\sum_{s} w_{a,s}D_{a,s}
```

记 `\theta(w)` 为在混合数据上微调后的 action head，`p_a(\theta)` 为轴 `a` 的真实验证成功率。优化目标：

```math
\max_{w}\;
(1-\gamma)\frac{1}{5}\sum_{a}p_a(\theta(w))
+\gamma\,\mathrm{CVaR}_{0.4}\big(\{p_a(\theta(w))\}_a\big)
-\lambda_g\sum_{a,m}w_{a,m}g_{a,m}
-\lambda_c\sum_{a,s}w_{a,s}c_{a,s}
```

其中 `\mathrm{CVaR}_{0.4}` 对 5 个轴取最差 2 个的均值：

```math
\mathrm{CVaR}_{0.4}(p)=\frac{1}{2}\left(p_{(1)}+p_{(2)}\right),\qquad p_{(1)}\le p_{(2)}
```

这样既不完全放弃平均分，也不让最弱的两个轴被平均掉。`\gamma=0.5` 是默认值，G9 扫。

### 3.3 配比求解：梯度匹配 QP

直接对 `\theta(w)` 做外层优化需要反复微调，太贵。用一阶代理：在初始 action head `\theta_0` 上，计算每个源的真实验证梯度 `h_{a,s}` 和目标验证梯度 `h_{a,val}`，解一个带缺口罚的凸 QP：

```math
\min_{w_a}\;
\left\|\sum_s w_{a,s}h_{a,s}-h_{a,\mathrm{val}}\right\|_2^2
+\lambda_g\sum_m w_{a,m}g_{a,m}
+\lambda_c\sum_s w_{a,s}c_{a,s}
+\lambda_p\|w_a-w_a^0\|_2^2
```

约束同 §1.2。第一项让混合梯度逼近真实验证梯度；第二项惩罚高缺口源；第三项把解拉向一个保守先验（例如 `w_R=0.8`）。这是标准的梯度匹配/影响函数思路：在小的学习率下，验证损失的一阶下降由内积 `\langle h_{a,val}, \sum_s w_s h_{a,s}\rangle` 决定，最小化上式等价于最大化一阶下降。

为了不让 6B 参数的梯度爆内存，只对 action head + state projector 求梯度，并用随机投影把梯度压到 `d=256` 维；内积在投影后近似保持（Johnson–Lindenstrauss）。每个轴 `S\le 6` 个源，QP 的规模是 `6×6` 的核矩阵，可忽略。

### 3.4 目标融合：真实与孪生关键帧的 Karcher 均值

检索库同时放真实关键帧和孪生关键帧。对查询，取 top-k 目标 `(T_i, d_i, g_i, c_i)`，权重：

```math
u_i=\frac{\exp(-d_i/\tau)\,(1-g_i)\,c_i}
{\sum_j\exp(-d_j/\tau)\,(1-g_j)\,c_j}
```

融合目标：

```math
T^{*}=\arg\min_T\sum_i u_i\left\|\log(T^{-1}T_i)\right\|^2
```

用 Karcher 迭代求解：

```math
T^{(k+1)}=T^{(k)}\exp\!\left(\sum_i u_i\log(T^{(k)-1}T_i)\right)
```

离散度：

```math
\sigma_{\mathrm{goal}}^2=\sum_i u_i\left\|\log(T^{*-1}T_i)\right\|^2
```

若 `\sigma_{\mathrm{goal}}` 超过阈值，说明候选目标多峰/不可信，回退到 top-1 真实目标或纯 VLA。这样，位置/背景/未见物品轴可以借孪生关键帧补覆盖，但不会被高缺口样本带偏。

### 3.5 控制融合：信赖域

设 `T_{\mathrm{ff}}` 是 VLA 30 步 plan 经 adapter 组合后的绝对 EE 目标，`\Delta\in\mathbb R^6` 是伺服修正（EE 局部系）。孪生标定得到成功修正的协方差 `\Sigma` 和半径 `r`。信赖域：

```math
\mathcal E(T_{\mathrm{ff}})=\left\{T_{\mathrm{ff}}\exp(\Delta):\Delta^{T}\Sigma^{-1}\Delta\le r^2\right\}
```

在线融合：

```math
\alpha=\min\!\left(1,\frac{r}{\|\Delta\|_\Sigma}\right)c_{\mathrm{goal}}c_{\mathrm{servo}},
\qquad
T_{\mathrm{cmd}}=T_{\mathrm{ff}}\exp(\alpha\Delta)
```

`c_{\mathrm{goal}}=\exp(-\sigma_{\mathrm{goal}}^2/\sigma_0^2)`，`c_{\mathrm{servo}}` 是特征/深度置信度。若 `\alpha` 连续多个 chunk 低于阈值，不是继续压，而是触发「冲突处理」：先停，再重定位；目标可见→更新 goal；不可见→VLA 重规划。信赖域是安全壳，不是把伺服关掉的开关。

## 4. 方法总览

```text
真实演示 ─┐
孪生模式 ─┼─▶ 缺口估计 ─▶ 配比 QP ─▶ action-head 微调 ─▶ θ*
检索关键帧 ┘                                      │
                                                  ▼
观测 ─▶ VLA 30 步 plan ─┐
       目标检索/融合 ────┼─▶ 伺服 Δ ─▶ TR-FUSE ─▶ 5 步 chunk
       孪生 Σ,r ─────────┘
```

离线只多两件事：一次孪生数据生成 + 一次配比 QP；在线只多两件事：一次目标融合 + 一次信赖域缩放。没有第二个学习模型，没有额外 VLA 调用。

## 7. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 缺口分数与真实负迁移不相关 | 配比优化变成「给错误数据更精细的权重」 | G8 先验；不通过就压到 0.1 或 real-only |
| 孪生动作标签错误（IK/恢复轨迹） | action head 学到错误动作 | IK 残差门；恢复轨迹只用控制器生成并标注来源 |
| 梯度匹配代理失效 | 配比 QP 选错源 | 与 3 个随机配比做 A/B；G9 不过就回退 |
| 信赖域误裁剪 | 真正需要的伺服修正被挡住 | 冲突触发重规划而不是永久裁剪；G10 误裁剪 ≤5% |
| 孪生渲染/数据成本 | 工程周期拉长 | 只生成关键帧窗口，不生成整 episode；按轴优先级逐步加 |
| 数据泄漏 | 离线指标虚高 | 先按 session/物体/背景划分，再生成孪生数据；相邻帧不跨 split |
| 单模型合规 | 被判定为第二个模型 | 孪生数据是训练数据；缺口指标确定性/冻结 VLA 特征；在线无第二个模型 |
| 标定漂移/换机器人 | 信赖域失配 | 每机器人一次重标定；误差大回退 CHUNK-SERVO |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap 95% CI；承认 5 次/任务的低功效 |

## 8. 一句话押注与最大风险

**押注**：用缺口分数把孪生数据变成「可配比的药」，用梯度匹配解配比，用 Karcher 融合真实/孪生目标，用信赖域把 VLA 与伺服的安全边界标定出来；在不新增学习模型、不做完整 sim2real 策略训练的前提下，把 5 个泛化轴从「数据稀疏」变成「数据可控」。

**最大风险**：缺口分数如果和真实负迁移不相关，配比优化会变成「给错误的数据加更精细的权重」，而信赖域还会把真正需要的伺服修正挡在外面。

# 第 13 轮产物 · DT-MIX / TR-FUSE 技术报告

> 检索/复核日期：**2026-10-31（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是第 13 轮想法区「DT-MIX / TR-FUSE」的工程化产物；不替换第 12 轮 CHUNK-SERVO，而是在它的数据层和融合层做增量。本轮以设计为主，**不新增外部事实断言**；所有官方事实沿用第 12 轮已核实来源，新增数字均为设计目标或门槛，不是实测结果。

## 0. 结论与边界

### 0.1 一句话结论

第 12 轮 CHUNK-SERVO 把执行层从「30 步 / 1 秒开环」压到「5 步 / 167ms 闭环」，但它的目标库、action head 和伺服增益仍由真实演示与手工标定决定；DT-MIX 用带缺口标签的数字孪生数据，按 5 个泛化轴解一个带合成预算约束的配比 QP，TR-FUSE 用孪生标定的信赖域把 VLA 前馈和伺服反馈融合起来。目标是在**不新增学习模型、不做完整 sim2real 策略训练**的前提下，提升 5 个泛化轴、尤其是人为干扰轴的鲁棒性。

### 0.2 证据等级

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 第 12 轮已核实的官方文档/数据/规则 | 32×10 trials、5 轴各 2 次、单模型、无深度/力/触觉、33,276 eps、WLA 6B/24GB 微调 |
| B | 本报告在公开数据/几何上的推导 | 双目视差量级、Karcher 融合、信赖域稳定性、QP 复杂度 |
| C | 设计假设，需 G8–G11 验证 | 缺口分数预测负迁移、梯度匹配代理有效、孪生修正分布可迁移、配比带来 +5–10pp |

### 0.3 本轮不做什么

- 不训练第二个策略/残差模型；不加载第二个视觉编码器做在线决策。
- 不做完整 sim2real 策略训练；孪生只生成数据、标定信赖域、做压力测试。
- 不做 30Hz 广域网伺服；仍用 5 步 chunk / 双频执行。
- 不做力/触觉闭环；API 没有。
- 不把孪生数据无条件混入；必须先过缺口门。
- 不做逐任务策略；配比是数据层，不是模型层。
- 不把榜单预览分数当难度表或失败分布。

### 1.2 第 12 轮的数据层盲区

| 泛化轴 | 真实演示缺什么 | 孪生能补什么 | 混入的风险 |
|---|---|---|---|
| 位置 | 目标位置覆盖有限；移动后接近方向/预接触点偏移 | 随机化目标位姿 + IK 重算动作 | IK 残差、关节限位、碰撞 |
| 干扰物 | 干扰物组合/遮挡模式有限 | 插入 1–3 个干扰物 mesh | 视觉外观不真实，模型学错关联 |
| 背景 | 桌面纹理/光照覆盖有限 | 换纹理/光照/相机曝光 | 颜色/纹理 shortcut |
| 未见物品 | 没有测试物体外观 | 用 held-out mesh 做几何代理 | 抓取 affordance 不匹配，最危险 |
| 人为干扰 | 几乎没有「人移动目标后如何恢复」的样本 | 人手/遮挡 + 确定性恢复轨迹 | 恢复轨迹是控制器生成，不是人类示范 |

这正是第 12 轮把孪生锁在风洞里的原因：如果不区分孪生模式的质量，混入就是赌博。DT-MIX 的核心不是「用孪生」，而是「**给每个孪生模式估计一个缺口，再决定用多少**」。

### 1.3 新增假设

- **H1（缺口可估）**：孪生模式的视觉/几何/动作/动力学残差可以用确定性指标估计，并组合成一个 `[0,1]` 的缺口分数。
- **H2（缺口可预测负迁移）**：缺口分数与「在该孪生模式上训练后、真实验证损失的增量」单调相关。
- **H3（梯度可代理）**：action head 的梯度匹配可以近似全模型微调后验证损失的一阶下降。
- **H4（信赖域可迁移）**：孪生里成功修正的协方差/半径，可以迁移到真机的信赖域标定，误差由 G10 覆盖。
- **H5（目标可融合）**：top-k 目标位姿落在 SE(3) 的局部凸球内时，Karcher 均值唯一、迭代收敛；离散度可用于拒绝多峰候选。

### 1.4 事实边界

本轮没有重新抓取官网、榜单 JSON、HF 数据集或 WLA 仓库；第 12 轮的 A 级事实继续有效，但**不应把第 12 轮的数字当作本轮的新测量**。本报告中的 `+5–10pp`、`p99 ≤150ms`、`Spearman ≥0.6`、`CV ≤0.2` 等都是门槛/设计目标，不是结果。

## 2. 问题形式化

### 2.1 任务、轴、评分

任务集合 `T={1..32}`，泛化轴集合 `A={pos, dist, bg, unseen, human}`，`|A|=5`。每个任务每个轴 2 次 trial：

```math
S=\frac{1}{32}\sum_{t=1}^{32}\frac{1}{5}\sum_{a\in A}p_{t,a},
\qquad
p_{t,a}=\frac{1}{2}\sum_{j=1}^{2}y_{t,a,j},\quad y_{t,a,j}\in\{0,1\}.
```

对固定任务，`p_{t,a}\in{0,0.5,1}`，粒度很粗。因此单任务 A/B 只能用配对设计和方向性判断，不能把 +0.5 当成显著涨点。DT-MIX 的评价必须在**多任务×多轴**上聚合，并报告 bootstrap 置信区间。

### 2.2 数据域

数据源集合：

```math
S=\{R\}\cup M,\qquad
M=\{pos,dist,bg,unseen,human\}.
```

对每个轴 `a` 和源 `s`，`D_{a,s}` 是若干 `(o_t, a_t, task, phase)` 窗口。真实源 `D_{a,R}` 从 33k 演示中按任务/相位/视觉聚类划分；没有轴标签时，真实数据在 5 个轴上均匀复用（权重 `1/5`），孪生源按轴生成。

关键工程约束：**先划分 session/物体/背景，再生成孪生数据**。孪生扰动只能作用于训练 split 的真实帧/网格，不能碰验证 split，否则 G8/G9 会虚高。

### 2.3 缺口分数

对孪生模式 `m`，在匹配状态（同任务、同相位、最近 EE 位姿）上计算四个归一化残差：

```math
r^{\mathrm{vis}}_{a,m}=1-\frac{1}{2}\left(\mathrm{SSIM}_{head}+\mathrm{SSIM}_{wrist}\right)
```

```math
r^{\mathrm{geo}}_{a,m}=\mathrm{clip}\!\left(\frac{\mathrm{Chamfer}(\mathcal P_{a,m},\mathcal P_{a,R})}{0.01\,\mathrm m},0,1\right)
```

```math
r^{\mathrm{act}}_{a,m}=\mathrm{clip}\!\left(\frac{\mathrm{NLL}_{a,m}-\mathrm{NLL}_{a,R}}{\kappa},0,1\right)
```

```math
r^{\mathrm{dyn}}_{a,m}=\mathrm{clip}\!\left(\frac{\mathrm{RMSE}(\tau_{a,m},\tau_{a,R})}{0.01\,\mathrm m},0,1\right)
```

其中 `\mathcal P` 是头双目点云（对齐后），`\tau` 是同一动作序列下的 EE 轨迹，`NLL` 是当前 action head 在匹配状态上的去噪损失。缺口：

```math
g_{a,m}=\sigma\!\left(\beta_0+\sum_{j=1}^{4}\beta_j r^{j}_{a,m}\right)\in[0,1].
```

`\beta` 的标定（G8）：

1. 对每个 `(a,m)`，用该孪生源单独训练一个 proxy action head（只训 action head，1–2 epoch），在真实验证集上得到 `L_{a,m}`；用真实源训练得到 `L_{a,R}`。
2. 负迁移标签：

```math
y_{a,m}=\mathrm{clip}\!\left(\frac{L_{a,m}-L_{a,R}}{L_{a,R}},0,1\right).
```

3. 拟合 `y \approx \sigma(\beta^T r)`（带 L2），报告 Spearman 相关与期望校准误差（ECE）。

若没有校准集，退化为等权 `\beta_j=1`、`\beta_0=-2`，并把 `\rho_0` 压到 0.1。**这是保守兜底，不是等价方案。**

### 2.4 配比变量与约束

对每个轴 `a`，配比向量 `w_a\in\Delta^{|S|}`：

```math
w_{a,s}\ge 0,\qquad
\sum_{s}w_{a,s}=1,\qquad
0\le w_{a,m}\le \rho_0(1-g_{a,m}),\qquad
\sum_{m}w_{a,m}\le \rho_0.
```

默认 `\rho_0=0.5`；`unseen`/`human` 两个高风险轴单独取 `\rho_0=0.3`，其余轴取 0.5。逐源上限 `\rho_0(1-g_{a,m})` 比总上限更严格：`g=0.8` 的源最多拿 0.1 权重；`g=0.2` 的源最多拿 0.4。这样即使总预算允许，高缺口源也进不来。

训练分布：

```math
P_a(w_a)=\sum_{s}w_{a,s}D_{a,s}.
```

### 2.5 配比目标

设 `\theta(w)` 是在混合数据上微调后的 action head，`p_a(\theta)` 是轴 `a` 的真实验证成功率。目标：

```math
\max_{w}\;
(1-\gamma)\frac{1}{5}\sum_{a}p_a(\theta(w))
+\gamma\,\mathrm{CVaR}_{0.4}\big(\{p_a(\theta(w))\}_a\big)
-\lambda_g\sum_{a,m}w_{a,m}g_{a,m}
-\lambda_c\sum_{a,s}w_{a,s}c_{a,s}
```

约束同 §2.4。`\mathrm{CVaR}_{0.4}` 对 5 个轴取最差 2 个的均值：

```math
\mathrm{CVaR}_{0.4}(p)=\frac{1}{2}\left(p_{(1)}+p_{(2)}\right),\qquad p_{(1)}\le p_{(2)}.
```

默认 `\gamma=0.5`：一半权重给平均分，一半给最弱两轴。这是对「总分是平均，但失败集中在弱轴」的折中；G9 扫 `\gamma\in{0,0.5,1}`。

### 2.6 信赖域与融合算子

设 `T_{\mathrm{ff}}` 是 VLA plan 经 adapter 组合后的绝对 EE 目标（base 系），`\Delta\in\mathbb R^6` 是伺服修正（EE 局部系）。孪生标定得到成功修正的协方差 `\Sigma` 和半径 `r`。信赖域：

```math
\mathcal E(T_{\mathrm{ff}})=\left\{T_{\mathrm{ff}}\exp(\Delta):\Delta^{T}\Sigma^{-1}\Delta\le r^2\right\}.
```

融合：

```math
\alpha=\min\!\left(1,\frac{r}{\|\Delta\|_\Sigma}\right)c_{\mathrm{goal}}c_{\mathrm{servo}},
\qquad
T_{\mathrm{cmd}}=T_{\mathrm{ff}}\exp(\alpha\Delta),
```

其中 `\| \Delta \|_\Sigma^2=\Delta^T\Sigma^{-1}\Delta`。`\alpha` 是标量收缩，不是逐维硬裁剪；它保留修正方向，只缩短幅度，并且当 `\alpha` 持续很小时触发冲突处理（§4.4），而不是永久关闭伺服。

三个融合层共享同一个缺口信号：

| 层 | 变量 | 求解 | 作用 |
|---|---|---|---|
| 硬配比（训练） | `w_{a,s}` | 带约束 QP（§3.4） | 决定 action head 吃什么 |
| 软配比（检索） | `u_i` | 闭式权重（§4.1） | 决定目标位姿信谁 |
| 控制融合（在线） | `\alpha` | 闭式缩放（§2.6） | 决定伺服改多少 |

## 3. DT-MIX 离线算法

### 3.1 总览

```text
真实演示 D_R ──按 session 划分──▶ D_train / D_val
        │
        ├──▶ 孪生生成（5 轴 × 模式）──▶ D_twin
        │                                  │
        │                                  ├──▶ 缺口残差 r / 缺口 g
        │                                  │
        └──▶ 梯度匹配 QP ◀─────────────────┘
                    │
                    ▼
          配比 w_{a,s} + 轴采样 q_a
                    │
                    ▼
        action-head 微调（VLM 冻结）──▶ θ*
                    │
                    ▼
        真实验证集逐轴检查 / 回退
```

### 3.2 孪生数据生成

| 轴 | 场景扰动 | 动作标签 | 缺口风险 | 默认比例上限 |
|---|---|---|---|---|
| 位置 `pos` | 目标/受器位姿在任务合法范围内随机；桌面高度/朝向小扰动 | IK 到同一相对目标 `T_target·T_target,ee*`；关节限位/残差门 | 中 | `0.5(1-g)` |
| 干扰物 `dist` | 插入 1–3 个干扰物 mesh；随机遮挡 | 回放匹配的真实动作窗口 | 低–中 | `0.5(1-g)` |
| 背景 `bg` | 桌面纹理/光照/曝光/相机白平衡 | 回放匹配的真实动作窗口 | 低–中 | `0.5(1-g)` |
| 未见物品 `unseen` | 用 held-out mesh 替换目标物；保持任务几何/受器 | 几何/抓取 affordance 兼容才回放；否则丢弃 | 高 | `0.3(1-g)` |
| 人为干扰 `human` | 人手/手臂进入、移动目标、遮挡 | 确定性恢复控制器：停→退→重定位→再接近 | 高 | `0.3(1-g)` |

动作标签必须记录来源：`replay` / `ik` / `controller`。训练时对 `controller` 样本加一个小的损失权重（例如 0.5），避免恢复轨迹压过真实示范。

规模建议（首轮）：

- 每任务每模式 `N_T=30` 个关键帧窗口，窗口长 30 步；
- 总计 `32×5×30 = 4,800` 窗口，约 `4,800×30×4 = 576k` 张图；
- 头图 240×320、腕图 128×128、JPEG q=90，约 5–8KB/张 → 3–5GB；
- 单 GPU 渲染/合成可在 1–2 天内完成（取决于渲染器）；可并行。

为什么只生成关键帧窗口而不是整 episode：配比要的是「接触前后 + 泛化轴」的样本，不是自由空间巡航。全 episode 生成既贵，又会把自由空间样本比例进一步推高。

### 3.3 缺口估计与校准

缺口残差按 §2.3 计算。校准协议（G8）：

1. 选 5 个代表任务 × 5 个孪生模式 = 25 个条件；每个条件用对应孪生源单独训练 proxy action head（1–2 epoch，action head only）。
2. 在真实验证集上计算 `L_{a,m}` 与 `L_{a,R}`，得到 `y_{a,m}`。
3. 拟合 `y \approx \sigma(\beta^T r)`；报告 Spearman `\rho` 与 ECE。
4. 通过标准：`\rho\ge0.6` 且 `ECE\le0.1`。

如果 G8 不过：

- 所有孪生源的总比例 `\rho_0` 压到 0.1；
- 对 `unseen`/`human` 直接禁用；
- 只保留 `bg`/`dist`/`pos` 中缺口最低的一个源；
- 仍不过，则本轮退回纯 CHUNK-SERVO，DT-MIX 只作为离线分析。

### 3.4 配比 QP

只对 action head + state projector 求梯度，冻结 VLM。对每个轴 `a`：

```math
h_{a,s}=\frac{1}{|B_{a,s}|}\sum_{x\in B_{a,s}}\nabla_\theta\ell(\theta_0;x),
\qquad
h_{a,\mathrm{val}}=\frac{1}{|B_{a,\mathrm{val}}|}\sum_{x\in B_{a,\mathrm{val}}}\nabla_\theta\ell(\theta_0;x).
```

随机投影到 `d=256`：

```math
\tilde h=\frac{1}{\sqrt d}Rh,\qquad R_{ij}\sim\mathcal N(0,1).
```

Johnson–Lindenstrauss：`S\le6` 个向量，`d=256` 足够以高概率保持内积在 `1\pm\epsilon` 内。

QP：

```math
\min_{w_a}\;
w_a^{T}K_a w_a-2b_a^{T}w_a
+\lambda_g\,g_a^{T}w_a
+\lambda_c\,c_a^{T}w_a
+\lambda_p\|w_a-w_a^{0}\|_2^2
```

其中：

```math
(K_a)_{ss'}=\langle\tilde h_{a,s},\tilde h_{a,s'}\rangle,\qquad
(b_a)_s=\langle\tilde h_{a,s},\tilde h_{a,\mathrm{val}}\rangle.
```

约束同 §2.4。`K_a` 是 `|S|×|S|`（≤6×6），用小型 active-set/投影梯度即可；`\lambda_g` 默认 1.0，`\lambda_c` 默认 0.1，`\lambda_p` 默认 0.1。先验 `w_a^0` 取「真实 0.8 + 各孪生均分 0.2」，避免无数据时解到角点。

QP 是 §2.5 的一阶松弛：梯度匹配项对应逐轴验证损失的一阶下降；缺口项 `\lambda_g g_a^T w_a` 和成本项 `\lambda_c c_a^T w_a` 直接进入目标；CVaR 项不在 QP 内显式求解，而是通过 §3.5 的轴重加权 `q_a` 和 G9 的 `\gamma` 扫描体现。这样避免在每次 QP 里嵌套一个不可微的 CVaR/成功率目标，代价是 CVaR 只能近似优化——这点在 §5.5 明确列为局限。

多轴共享（可选）：

```math
\min_{\{w_a\}}\sum_a\left[w_a^T K_a w_a-2b_a^T w_a+\lambda_g g_a^T w_a+\lambda_c c_a^T w_a\right]
+\lambda_{\mathrm{sh}}\sum_a\|w_a-\bar w\|_2^2
+\lambda_p\sum_a\|w_a-w_a^0\|_2^2.
```

`\bar w=\frac{1}{5}\sum_a w_a`。默认 `\lambda_{\mathrm{sh}}=0`（各轴独立）；G9 里把共享作为消融，因为不同轴的缺口结构可能完全不同。

#### 为什么梯度匹配是合理的

在小的学习率 `\eta` 下，一次梯度更新 `\theta'=\theta_0-\eta h_w` 后，验证损失的一阶变化为：

```math
L_{\mathrm{val}}(\theta')\approx L_{\mathrm{val}}(\theta_0)
-\eta\langle h_{\mathrm{val}},h_w\rangle.
```

固定 `\|h_{\mathrm{val}}\|` 时，最大化内积等价于最小化 `\|h_w-h_{\mathrm{val}}\|^2`。QP 的第一项正是这个；第二项用缺口罚限制高缺口源；第三项控制方差。严格的误差界见 §5.1。

### 3.5 鲁棒重加权

QP 给的是静态配比。微调过程中，某些轴可能仍然掉点。用指数梯度（Group DRO 风格）调整**轴采样概率** `q_a`：

```math
q_a^{(k+1)}=
\frac{q_a^{(k)}\exp(\eta_k\hat L_a(\theta_k))}
{\sum_{a'}q_{a'}^{(k)}\exp(\eta_k\hat L_{a'}(\theta_k))},
\qquad
q_a\in[0.1,0.4].
```

`\hat L_a` 是真实验证集上按轴归一化的损失（或 `1-成功率`）。数据加载顺序：先按 `q_a` 选轴，再按 `w_{a,s}` 选源，再按任务均匀采样。

注意：`q_a` 是训练时的轴采样分布，不是最终配比；报告时必须同时给出 `w` 和 `q`，否则复现不了。

### 3.6 微调协议

| 项 | 设置 |
|---|---|
| 模型 | 官方 WLA Base；冻结 VLM，只训 DiT action head + robot-state projector |
| 数据 | 30 步窗口；真实 + 孪生；按 §3.5 采样 |
| 损失 | WLA 原 flow-matching/diffusion 去噪损失；`controller` 样本权重 0.5 |
| 优化 | AdamW，lr `1e-4`，batch 64，3 epoch，cosine，early stop |
| 验证 | 真实 held-out session；按轴分层；动作 NLL + 成功率代理 |
| 种子 | 3 个；报告均值与 CV |
| 划分 | 先按 session/物体/背景分组，再生成孪生；相邻帧不跨 split |
| 回退 | 任一轴验证掉点 >5pp，把该轴合成比例乘 0.5 重训（最多 2 次） |

### 3.7 伪代码

```python
def dt_mix(D_real, twin, theta0, cfg):
    # 1. split first, then generate
    D_train, D_val = split_by_session_object_background(D_real)
    D_twin = {}
    for a in AXES:
        for m in MODES[a]:
            D_twin[(a, m)] = twin.generate(
                axis=a, mode=m, source=D_train[a],
                n=cfg.N_T, window=30,
            )

    # 2. gap residuals and scores
    r = {key: gap_residuals(D_train, D_twin[key]) for key in D_twin}
    g = {key: sigmoid(beta @ r[key]) for key in D_twin}

    # 3. gradient-matching QP per axis
    w = {}
    for a in AXES:
        h_val = projected_grad(theta0, D_val[a], d=cfg.d)
        h_src = {
            s: projected_grad(theta0, source_data(a, s), d=cfg.d)
            for s in SOURCES
        }
        w[a] = solve_qp(
            h_val, h_src, g[a],
            rho0=cfg.rho0, lam_g=cfg.lam_g, lam_p=cfg.lam_p,
        )

    # 4. fine-tune with axis reweighting
    theta = theta0
    q = {a: 1.0 / len(AXES) for a in AXES}
    for epoch in range(cfg.epochs):
        for batch in mixed_loader(D_train, D_twin, q, w):
            theta = sgd_step(theta, batch)
        L_val = eval_loss_by_axis(theta, D_val)
        q = exponentiated_gradient_update(q, L_val, eta=cfg.eta, clip=(0.1, 0.4))

    # 5. per-axis post-check and rollback
    for a in AXES:
        if val_success(theta, a) < baseline[a] - cfg.delta:
            w[a] = shrink_synthetic(w[a], factor=0.5)
            theta = fine_tune(theta0, D_train, D_twin, q, w, cfg)
    return theta, w, g
```

### 3.8 复杂度

记 `A=5`，`|M|=5`，`S=|S|≤6`，`N_T` 为每模式窗口数，`N` 为训练窗口数，`E` 为 epoch 数，`P` 为 action head 参数，`d=256`。

| 阶段 | 复杂度 | 说明 |
|---|---|---|
| 孪生生成 | `O(A|M|N_T(C_render+C_phys))` | 渲染/物理是主成本；只生成关键帧窗口 |
| 缺口残差 | `O(A|M|N_T C_g)` | SSIM/Chamfer/NLL/轨迹 RMSE |
| 梯度投影 | `O(A S P)`（反向）+ `O(A S P d)`（投影） | 每个源一个 mini-batch；只对 action head |
| QP | `O(A S^3)` | S≤6，可忽略 |
| 微调 | `O(E N P)` | 与第 12 轮 action-head 微调同阶 |
| 在线 | `O(k)` Karcher 迭代 + `O(1)` 缩放 | 无额外 VLA 调用 |

主导成本是孪生渲染和 action-head 微调；QP 与在线融合可忽略。内存上，随机投影把梯度从 `P` 维压到 `d` 维，避免 6B 级梯度缓存。

## 4. TR-FUSE 在线算法

### 4.1 混合检索与目标融合

检索库条目：

```text
(task, phase, T_target_ee, I_wrist, descriptor, source, gap, quality)
```

- 真实条目：第 12 轮 DG-KEYFRAME 管线；
- 孪生条目：§3.2 生成的关键帧，带 `gap` 和 `source=pos/dist/bg/unseen/human`；
- 任务/阶段过滤优先于外观，避免「插网线」匹配到「拔网线」。

对查询取 top-k（`k=5..10`），权重：

```math
u_i=\frac{\exp(-d_i/\tau)(1-g_i)c_i}
{\sum_j\exp(-d_j/\tau)(1-g_j)c_j}.
```

`d_i` 是描述子距离（ORB/颜色/冻结 VLA encoder 特征，C3 合规），`c_i` 是目标图质量/相位置信度。融合目标用 Karcher 迭代：

```math
T^{(k+1)}=T^{(k)}\exp\!\left(\sum_i u_i\log(T^{(k)-1}T_i)\right).
```

离散度：

```math
\sigma_{\mathrm{goal}}^2=\sum_i u_i\left\|\log(T^{*-1}T_i)\right\|^2.
```

若 `\sigma_{\mathrm{goal}}>\sigma_{\max}` 或 `\sum_i u_i(1-g_i)<c_{\min}`，说明候选多峰/高缺口，回退：

1. 只用真实 top-1；
2. 若真实 top-1 也不可信，回退 VLA 开环 + 头双目 PBVS 粗对齐；
3. 不硬做 IBVS。

### 4.2 伺服修正

沿用第 12 轮：

```math
T_{ee}^{d}(t)=T_{\mathrm{base,target}}(t)\,T_{\mathrm{target,ee}}^{*},
\qquad
e(t)=\log\!\left(T_{ee}(t)^{-1}T_{ee}^{d}(t)\right),
```

```math
\Delta=\mathrm{clip}\!\left(K_p e+K_d\dot e,\ \pm\delta_p,\ \pm\delta_r\right).
```

- 远距离/大误差：PBVS 主导；
- 近距离/小误差：IBVS 辅助；
- 接触段：`\Delta` 分解为法向/切向，法向乘 0.3–0.5 并低通，切向保留；
- `r_grasp` 突变 → 滑移 → 重抓；
- `edit_score` 超阈值 → 停 → 重定位 → 重规划。

### 4.3 信赖域标定

在孪生里对 3 个任务族（peg-in-hole、hang/stack、zip/unlock）各跑 50–100 个带扰动的 episode，记录每个 chunk 的修正 `\Delta_k` 和最终是否成功。对成功修正集合 `\mathcal K^+`：

```math
\Sigma_\phi=\frac{1}{|\mathcal K^+|}\sum_{k\in\mathcal K^+}
(\Delta_k-\bar\Delta)(\Delta_k-\bar\Delta)^{T}+\epsilon I,
\qquad
r_\phi=1.2\,q_{0.95}\!\left(\|\Delta_k\|_{\Sigma_\phi}\right).
```

- 按任务族 `\phi` 条件化；不同接触类型的修正分布不同；
- 协方差用 trimmed/Huber 估计，避免少数异常修正撑大 `r`；
- `\epsilon I` 保证正定；
- 真机验证：统计成功修正落在椭球内的比例；若 `<95%`，把 `r` 乘 1.5 或关闭 TR-FUSE；
- 换机器人/换相机后重标定。

### 4.4 冲突处理

```text
SERVO ── α < α_min 连续 K 个 chunk ──▶ CONFLICT
CONFLICT:
    hold 1 chunk
    re-localize T_base_target with head stereo
    if target visible and goal confidence high:
        update goal; r ← 1.2 r; resume SERVO
    else:
        request VLA re-plan with new image + language
    if retries > 2:
        safe hold / fail gracefully
```

关键设计：**信赖域不是把伺服关掉的开关**。`\alpha` 小只说明「当前修正超出标定包络」，可能是真的人为干扰/目标移动，也可能是目标估计错误。两种情况都不应该继续压着伺服走；应该停下来重新看一眼。这样既避免大修正导致碰撞，又不会把第 12 轮的伺服收益吃掉。

### 4.5 稳定性

简化标量积分器（单轴、纯延迟 `d` 个 chunk）：

```math
e_{k+1}=e_k-KH_c e_{k-d}.
```

TR-FUSE 把有效增益变成 `\alpha K`，`\alpha\in[0,1]`。

- `d=0`：稳定条件 `0<KH_c<2`；缩小增益仍稳定。
- `d=1`：`z^2-z+KH_c=0`，稳定条件 `0<KH_c<1`；缩小增益仍稳定。
- `d≥2`：稳定域进一步缩小；缩小增益一般改善稳定裕度，但收敛变慢。

MIMO 情况下，`\alpha` 是标量收缩，控制输入整体缩放；对稳定线性系统，正标量增益缩小通常保持稳定，但非正规系统需要孪生验证。**因此 TR-FUSE 的稳定性结论是「标量/解耦情形可证，MIMO 情形靠 G2/G10 仿真与真机门」，不是无条件保证。**

如果 `T_fb>300ms`，关闭 IBVS，只做 PBVS 粗对齐 + VLA；不要用高增益追。

### 4.6 伪代码

```python
def get_action(obs):
    plan = plan_cache.get_or_request(obs)
    goals = retrieve_mixed(obs)
    T_goal, c_goal, disp = fuse_goals(goals)

    if disp > cfg.sigma_max or c_goal < cfg.c_min:
        Delta, c_servo = zeros(6), 0.0
    else:
        Delta, c_servo = servo.compute(obs, T_goal)

    a_ff = plan[plan_idx:plan_idx + cfg.H_c]

    if norm_Sigma(Delta) < 1e-9:
        alpha = 1.0
    else:
        alpha = min(1.0, cfg.r / norm_Sigma(Delta))
    alpha *= c_goal * c_servo

    a_cmd = compose(a_ff, exp(alpha * Delta))

    if alpha < cfg.alpha_min:
        conflict_counter += 1
    else:
        conflict_counter = 0
    if conflict_counter >= cfg.K:
        trigger_conflict_handler(obs)
        conflict_counter = 0

    return adapter.to_api(a_cmd, obs, token)
```

### 4.7 复杂度

- 目标融合：`O(k I)`，`I` 是 Karcher 迭代次数（3–5），`k≤10`；
- 信赖域：一次 6×6 求解，`O(1)`；
- 无额外 VLA 调用；每端口 CPU 开销 `<1ms`（除图像描述子）；
- 相比第 12 轮，在线只增加一次融合和一次缩放，p99 预算不变。

## 5. 正确性论证

### 5.1 梯度匹配的一阶最优性

**引理 1**：设 `L_{\mathrm{val}}` 二阶连续可微，梯度 `L`-Lipschitz，更新 `\theta'=\theta_0-\eta h_w`，`h_w=\sum_s w_s h_s`。则

```math
L_{\mathrm{val}}(\theta')=L_{\mathrm{val}}(\theta_0)
-\eta\langle h_{\mathrm{val}},h_w\rangle
+\frac{\eta^2}{2}h_w^{T}\nabla^2L_{\mathrm{val}}(\tilde\theta)h_w.
```

**证明**：沿 `\theta_0` 到 `\theta'` 的线积分做二阶 Taylor 展开，余项用中值定理。∎

**推论**：当 `\eta` 小、二阶项可忽略时，验证损失的下降由 `\langle h_{\mathrm{val}},h_w\rangle` 决定。若 `\|h_w\|` 近似固定（或加 `\lambda_n\|h_w\|^2` 正则），最小化 `\|h_w-h_{\mathrm{val}}\|^2` 等价于最大化一阶下降。QP 的第一项就是这个匹配；`\lambda_p` 控制 `w` 的方差，`\lambda_g` 用缺口罚限制高缺口源。

**局限**：深度微调是非凸的，一阶代理不能保证全局；G9 必须用真实 A/B 验证，不能只看 QP 目标值。

### 5.2 域适应上界

对任意假设 `h`，标准域适应界（Ben-David 等）：

```math
\epsilon_T(h)\le\epsilon_S(h)
+\frac{1}{2}d_{\mathcal H\Delta\mathcal H}(S,T)+\lambda^{*}.
```

对混合源：

```math
\epsilon_{\mathrm{real}}(h)\le\sum_s w_s\epsilon_s(h)
+\sum_s w_s d_s+\lambda^{*}.
```

若 H2 成立，`g_s` 是 `d_s` 的单调代理，则缺口罚 `\sum_s w_s g_s` 控制第二项；逐源上限 `w_s\le\rho_0(1-g_s)` 进一步限制高缺口源的权重。这个界对深度网络不紧，但它给出了配比目标的形式依据：**不是所有源等权，也不是按数据量等权，而是按「源风险 + 缺口」加权。**

### 5.3 信赖域的概率界

设 `F_{\mathrm{twin}}` 是孪生成功修正范数 `\|\Delta\|_\Sigma` 的 CDF，`F_{\mathrm{real}}` 是真机成功修正的 CDF。假设校准误差有界：

```math
\sup_x|F_{\mathrm{real}}(x)-F_{\mathrm{twin}}(x)|\le\epsilon.
```

取 `r` 为孪生成功修正的 95% 分位，则：

```math
\Pr_{\mathrm{real}}\!\left(\|\Delta\|_\Sigma>r\right)
\le 1-F_{\mathrm{twin}}(r)+\epsilon
=0.05+\epsilon.
```

因此，把修正缩放到 `\|\alpha\Delta\|_\Sigma\le r` 后，执行修正超出「95% 成功修正包络」的概率不超过 `0.05+\epsilon`。这是**修正幅度**的概率界，不是任务成功率的保证；它依赖 H4（孪生/真机修正分布可迁移）。若真实覆盖率低于 95%，说明 `\epsilon` 太大，应扩大 `r` 或关闭 TR-FUSE。

### 5.4 目标融合的局部最优性

Karcher 均值 `T^*` 最小化 `\sum_i u_i d^2(T,T_i)`。若所有 `T_i` 落在 SE(3) 的一个测地球内（半径小于 injectivity radius），目标函数严格凸，`T^*` 唯一，Karcher 迭代局部线性收敛。离散度 `\sigma_{\mathrm{goal}}^2` 是该最小值的加权残差；超过阈值说明候选多峰，融合无意义，应回退。这是标准 Riemannian center of mass 结果，此处只作为工程判据。

### 5.5 局限

1. 梯度匹配是 first-order proxy；非凸微调可能让它选错源。
2. 缺口分数是 domain divergence 的代理，不是上界；H2 可能不成立。
3. 信赖域标定依赖孪生修正分布与真机的可迁移性；换机器人/换夹爪会失效。
4. `\mathrm{CVaR}` 代理针对最弱两轴，可能牺牲平均分；`\gamma` 需要 G9 调。
5. 孪生动作标签（尤其 `unseen`/`human`）不是人类示范，存在系统性偏差。
6. 5 次/任务的 A/B 功效很低，只能看方向；不能把 +10pp 当成统计显著。

### 6.3 真机单任务

分三批，避免一次性烧太多 trial：

| 批次 | 任务 | 轴 | 次数 | 条件 | 门 |
|---|---|---|---|---|---|
| S1a | PlugInEthernet、HangCup、ZipUp、StackBowls、FoldTowel | nominal + human | 每任务每轴 5 次 | real-only、naive 50/50、DT-MIX | G9 |

- S1a = `5×2×5×3 = 150` trials；S1b = `3×2×5×2 = 60`；S2 = `2×4×5×2 = 80`；总计 290，可先跑 S1a，过门再跑 S1b/S2；
- 同一初始条件尽量配对；
- 指标：成功率、步骤分、耗时、p99、恢复时间、误裁剪率；
- 统计：配对差值 + bootstrap 95% CI；5 次/格只能看方向；
- 失败即回退：任一 A 档任务掉 >5pp，关闭 TR-FUSE 或把该轴合成比例乘 0.5。

### 6.4 全量干跑

- 32 任务×10 次，N 个连续端口；
- 检查端口隔离、`reset()` 干净、内存不涨、p99 ≤150ms；
- 与第 12 轮 CHUNK-SERVO 基线做配对比较（若基线可复现）；
- 不在正式 320 trials 上做未验证的配比 A/B。

### 6.5 消融

1. real-only vs naive 50/50 vs DT-MIX；
2. 缺口罚 `\lambda_g=0` vs 默认；
3. 逐轴配比 vs 全局配比（`\lambda_sh` 大）；
4. 目标融合 on/off（real-only top-1 vs Karcher）；
5. TR-FUSE on/off；
6. `\gamma=0`（纯平均）vs `0.5` vs `1`（纯 CVaR）；
7. 随机投影维度 `d∈{64,256,1024}`；
8. 孪生模式逐个加入（`bg` → `dist` → `pos` → `human` → `unseen`）。

| 门 | 问题 | 通过标准 | 失败动作 |
|---|---|---|---|
| **G8** | 缺口分数是否预测负迁移？ | 25 条件 Spearman `≥0.6`；ECE `≤0.1` | `\rho_0=0.1`；禁用 `unseen`/`human`；仍不过则 real-only |

| P2 配比/微调 | 2 周 | 梯度投影；QP；3 seed 微调；逐轴验证 | G9 预检 |
| P3 TR-FUSE | 1 周 | 信赖域标定；目标融合；冲突状态机 | G10 预检 |
| P4 真机 A/B | 2 周 | S1/S2；配对统计 | G9/G10 |
| P5 干跑/提交 | 1 周 | 32×10 干跑；合规说明；回滚开关 | G11 + 全部门 |

算力估算：

- 孪生渲染/合成：16–32 CPU 核 + 1 GPU，1–2 天；
- proxy/正式微调：1×24GB 或 40GB GPU；3 seed × 3 配比 × 2h ≈ 18–36 GPU-hours；
- 梯度投影：与一次微调同阶的若干 backward，几小时；
- 存储：孪生窗口 3–5GB；真实关键帧/索引 <1GB；
- 真机：S1a 约 150 trials，S1b 约 60，S2 约 80；正式 320 trials 另计。

人员：1 人视觉/孪生，1 人 WLA 微调/推理，1 人评测/统计；可兼职，总计 8–10 周。

## 8. 风险与合规

### 8.1 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| 缺口分数与真实负迁移不相关 | 配比优化变成「给错误数据更精细的权重」 | G8 先验；不通过压到 0.1 或 real-only |
| 孪生动作标签错误（IK/恢复轨迹） | action head 学到错误动作 | IK 残差门；记录标签来源；controller 样本降权 |
| 梯度匹配代理失效 | QP 选错源 | 与随机配比 A/B；G9 不过回退 |
| 信赖域误裁剪 | 真正需要的伺服修正被挡住 | 冲突触发重规划而非永久裁剪；G10 误裁剪 ≤5% |
| 孪生渲染/数据成本 | 周期拉长 | 只生成关键帧窗口；按轴优先级逐步加 |
| 数据泄漏 | 离线指标虚高 | 先 split 再生成；相邻帧不跨 split；按 session/物体/背景分组 |
| 单模型解释 | 被判定为第二个模型 | 孪生是训练数据；缺口指标确定性/冻结 VLA 特征；在线无第二模型 |
| 标定漂移/换机器人 | 信赖域失配 | 每机器人重标定；误差大回退 CHUNK-SERVO |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap 95% CI；承认低功效 |
| 提交次数限制 | 无法多次 A/B | 邮件确认；单任务通道先验证；一次提交则保守 |

### 8.2 合规模式

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | 孪生只离线生成/筛选数据；在线只有 VLA + 确定性伺服 | 最低 | 保守首选 |
| C2 确定性控制器 | 配比/缺口/信赖域都是离线或确定性算法；VLA 是唯一学习模型 | 低；需说明 | 主推 |
| C3 同 checkpoint 特征 | 目标描述子/缺口特征用 VLA 同一 checkpoint 的 encoder，不加载第二个模型 | 低–中；需说明 | 需要强描述子时用 |

禁止：加载第二个学习策略/残差网络/独立视觉编码器做在线决策；把孪生数据伪装成真实数据；用测试集生成孪生数据。

提交材料应写清楚：

- 孪生数据的来源、比例、生成方式；
- 缺口分数的定义与校准结果（G8）；
- 在线系统的组件（VLA、确定性伺服、Karcher 融合、信赖域）；
- 没有第二个在线学习模型；
- 失败回退路径（关闭 TR-FUSE / real-only）。

## 10. 一句话押注

**用缺口分数把孪生数据变成「可配比的药」，用梯度匹配解配比，用 Karcher 融合真实/孪生目标，用信赖域把 VLA 与伺服的安全边界标定出来；在不新增学习模型、不做完整 sim2real 策略训练的前提下，把 5 个泛化轴从「数据稀疏」变成「数据可控」。**

**最大风险**：缺口分数如果和真实负迁移不相关，配比优化会变成「给错误的数据加更精细的权重」，而信赖域还会把真正需要的伺服修正挡在外面。
