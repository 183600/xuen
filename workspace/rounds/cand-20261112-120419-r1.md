# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「任务分解」×「双臂协调」）

> 第 57 轮把"这一次接触是否可信"做成了分层证书：q_φ 从区域史摊销先验、证据按模态分账对账、操作者变成单向有界的信任状态机，并给出对检查点求并集的部署界 P_safe ≥ 1 − Σ_cp(δ_f+ε_meta+…)。但它默认了三个从未写进形式化的前提：**(a) 证书的合成方式是显然的**——把每个检查点的安全概率乘起来、或把并集界一路加下去即可，没人追问长任务上这个界会不会先于成功归零；**(b) 两条臂要么是两个独立智能体、要么是一个整体**——没有"它们共享同一张地图、同一份标定、同一条计划前缀、同一个底座位姿"这一层共因，也没有"一条臂的抓握是另一条臂安全的前提"这一层依赖；**(c) 协调可由观测推断**——但示教数据里两臂"都在动"占 86.2%~99.6% 的帧，真正"一臂持、一臂动"只有 0%~8.5%（15 个可获取任务的中位 0.1%），相对位姿每帧近似不变只占 5.7%~41.8%（中位 24.6%）——**共动不是协调，活动相关不是耦合证据**。本轮两个灵感各补一层结构：**任务分解**把"任务成功"从乘积直觉升级为带共同因声明的合成证书（Fréchet 并集下界 + 检查点重置 + 有界重试），并把块长 b 变成受步骤分惩罚约束的显式变量；**双臂协调**把两臂关系升级为按区间生效的**协调契约**（相对帧不变式/持-动事务/共享对象）与**跨臂共模检验**，让"一致"只在路径不相交时才算第二个证据。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"任务可合成、双臂可契约、共模可区分的证据说可信"**。

核心矛盾：
- **H32（合成健全 vs 步骤分经济）**：n 个块的联合成功无分布下界是 max(0, Σp_i−(n−1))，在 n≈1/(1−p)+1 时归零；检查点重置+重试能恢复可合成性，但每次重置要花步骤分。于是块长 b 的最优值由 λ（步骤分权重）决定，而不是由安全单独决定——**证书粒度本身成了可被分数诱导的旋钮**：为了分数把 b 调大，合成界会更早变空。
- **H33（共动 vs 协调）**：两臂几乎全程"都在动"，但真正的持-动结构极稀疏；相对位姿近不变只在少数帧成立。用活动相关认证协调 = 认证了错的东西；要求全局刚体耦合 = 几乎认证不出东西。协调必须显式声明"哪条不变式、在哪个区间、容差多少"，区间外两臂退回独立证书。
- **H34（跨臂一致 vs 共模 / 事务依赖）**：两臂共享底座位姿、地图、标定与计划前缀，其"一致"可能是同一个错误被问了两遍；更麻烦的是持-动事务让持臂的抓握证书成为动臂安全前提，两组证书**按构造相关**。把跨臂一致当独立证据，正是第 57 轮"同一模态问五遍"的臂级版本。

## 0. 直觉与动机

**灵感 1（任务分解 → 合成证书，而不只是规划树）**
直觉：长任务不是"把 n 个 0.97 乘起来"。若各块失败有共同因（同一块没探过的地图、同一张漂移的标定、同一段被误判的计划前缀），一次失败会让后面的块更容易失败，成功事件负相关，乘积会系统性高估联合成功。安全的问法是反过来：**每个块只贡献一个事后可审计的失败上界 δ_v，任务成功下界用并集界 max(0, 1−Σδ_v)**。这个界对任意相关结构都成立，代价是长任务上会归零——而"归零"正是提醒：**长程任务必须被检查点切开**。检查点做一次重新观测+重规划，切断共同因；失败的块允许一次重试；于是任务成功率变成"若干被重置隔开的超级块"的乘积，重试把单块失败率从 p 降到 1−(1−p)²。**分解不是免费的**：每次检查点吃步骤分，块太细会被步骤分惩罚，块太粗会让合成界变空——存在一个由 λ 决定的 b*。

**灵感 2（检查点 = 共同因重置 = 双臂交接点）**
直觉：检查点和双臂交接其实是同一件事的两种说法——都是"重新看一眼、重新对齐、把之前共享的误差链断开"。一个 7 帧 lead-lag 的交接（示教数据里 Unlock 就能看到）如果不被当成重置点，两条臂就会继续背负交接前的相对位姿误差；如果被当成重置点，就必须显式记录"重置后哪些证据仍有效、哪些作废"。这把第 57 轮"事后证伪回溯"从"降权历史证据"推进到"**在拓扑切割点上作废跨切割的继承**"。

**灵感 3（双臂协调 → 相对帧契约，而非两套绝对位姿）**
直觉：两条臂常常共享同一个底座位姿误差：底座一歪，两套绝对坐标一起歪。但**相对帧把共模精确消掉**——在 3cm/10° 的共模扰动下，独立绝对伺服的位置误差均值 29.3mm、最大 53.3mm，而相对帧伺服是 0.000mm。所以协调的正确证书单位是相对变换 T_HA 与共享对象位姿，而不是两套绝对位姿各自"安全"。但相对帧只消共模、不消每条臂自己的噪声（噪声从 0.5mm/0.1° 升到 2mm/0.4° 时，2mm/1° 的相对成功率从 498/500 掉到 93/500），也不消时延：协调回路增益必须满足 a*(d)=2sin(π/(2(2d+1)))，d=7 帧时只有 0.209——**交接越慢，增益必须越低**。

**灵感 4（持-动事务 → 证书继承与中止，而非两臂各签各的）**
直觉：一条臂持住物体、另一条臂在上面操作，动臂的安全其实建立在"持臂不会松/不会滑"这个前提上。这是一个**物理事务**：先 prepare（持臂抓握证书 + 协调契约都有效）→ commit（动臂运动，继承前提 P_H）→ release（动臂建立自己的支撑后才允许持臂松手）；任一中途持臂证书失效，动臂证书必须**立即作废**并进入安全停。示教的 handover 算术说明这笔交易很值：单块失败率 0.01、交接能以 0.85 概率救回时，20 个块的无交接成功率 0.818，有交接 0.970。但它也说明：**交接制造依赖**——继承来的证据永远不能算作第二个独立证据。

**灵感 5（合流 → 任务级证据门与分解感知的探针预算）**
直觉：第 57 轮的五类证据现在要过两道新闸：任务级合成界是否仍非空（否则再好的单点证据也撑不起整条任务），以及依赖声明是否诚实（共同因、事务继承、跨臂共模）。反过来，任务分解也给探针预算一张**拓扑**：在并集界下，某块的边际价值正比于它的 δ_v 与其"下游/共因中心性"，因此不该每块平均探针；**开在切割点之前的共因节点最值钱**，因为一次探针同时降低多个下游块的 δ。少样本、多模态、个性化、分解、协调五个机制，仍然只能经"信念更准（含加宽）"或"动作更保守"两个安全通道起作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（任务分解图与块证书 TDG）** 任务 τ 分解为技能 DAG 𝒢_τ=(𝒱,ℰ,dep)，节点 v=(skill, pre_v, post_v, [t_v^0,t_v^1], J_p(v), p_v^{lb}, dep_v)。J_p(v) 是第 57 轮证书在块上的作用域化；p_v^{lb}=1−δ_v 是由 J_p(v) 保证的块成功**下界**（点估计只许用于规划，永不许进证书）。dep_v⊆{map_region, calibration, plan_prefix, base_pose, shared_object} 是**声明的共同因集**；切割点 C⊆𝒱 为重新观测+重规划处，也是双臂交接处。块长 b_v 为块内原始步数。𝒢_τ 必须无环且有限。

**定义 140（健全任务合成界 TCB）** 两种合成模式：
(M1 任意相关，Fréchet/并集界) LB_F(𝒢)=max(0, Σ_{v∈𝒱} p_v^{lb} − (|𝒱|−1)) = max(0, 1 − Σ_v δ_v)。
(M2 检查点重置) 若每个切割点 c 的重观测使 c 之后的块与 c 之前的块条件独立（须**审计**，不能只在声明里写），且每块至多一次重试，则按重置隔开的超级块 j 有 LB_R(𝒢)=Π_j (1−(1−p_j^{lb})²)，并需扣减重置审计误差 δ_reset(c)。块粒度的选择：b\* = argmax_b [LB(𝒢_b) − λ·steps(𝒢_b)]，s.t. LB≥δ_task，λ 为步骤分权重。退化阈值 n_collapse(p)=⌊1/(1−p)⌋+1：当 Σp_v^{lb}≤|𝒱|−1 时 M1 自动归零。**合成契约**：证书里必须写明用的是 M1 还是 M2 及审计结果；M2 审计失败自动退回 M1。

**定义 141（双臂协调契约 BCC）** 契约 c=(H,A,o,I,inv,ε)，H/A 为持臂/动臂角色，o 为共享对象（可为空），I=[t_0,t_1] 为生效区间，inv∈{rigid_rel, hold_act, shared_obj, independent}，ε 为容差向量。监测量：相对变换 T_HA(t)=T_A(t)⁻¹T_H(t)、两爪闭合度 g_H,g_A、持臂准静态速度 ‖v_H‖、共享对象位姿残差。契约仅在 I 上、且不变式逐时刻满足容差时有效；允许"覆盖比例+置信下界"的弱形式，但必须显式声明。**反代理规则**：两臂活动相关性（co-movement score）明确不可作为协调证据；协调只能由声明的不变式+残差监测给出。任何交接/角色交换都使继承失效并要求重新 prepare。

**定义 142（持-动事务 HAT 与证书继承）** 事务 hat=(H,A,o,I,prepare,commit,release,abort)：
（所有权）任一时刻每个对象至多一个持臂；臂/对象上取全序 ≺ 以避免死锁。
（prepare）J_p(H,grasp o) 有效 ∧ BCC(inv=hold_act) 有效 ∧ 相对帧残差在 ε 内。
（commit）动臂 A 的运动证书可把命题 P_H="o 由 H 稳定支撑"当作前提；P_H 的有效性**持续依赖** J_p(H) 与 g_H 不失效。
（release）H 只有在 A 建立自身独立支撑（或完成并交还）后才可松手；禁止运动中释放。
（abort）P_H 一旦失效（滑移、力骤降、地图证伪、共模检验报警），A 的证书**立即作废** → 安全停/重新 prepare；重试有界。交接同时是共因重置点：交接前继承的证据在重置后不得跨接续用。

**定义 143（跨臂共模检验 CMT 与 EV-bimanual）** 独立性声明 indep(H,A) 为真，仅当感知路径、标定证书、计划前缀、对象所有权四者两两不相交（底座位姿默认是**共享**路径，除非底座静止或位姿已独立标定）。共模分 CM(H,A)=1 若存在任一共享路径。跨臂证据规则：
(R1') 若 CM=1，"两臂一致"只算**一条**证据，权重取 min(w_H,w_A)，绝不相加；
(R2') EV-bimanual ⇔ indep(H,A) ∧ 两臂同侧一致 ∧ D≤θ_D ∧ level=L1；仅可替代 L1 的一次佐证，**禁止进入不可逆接触必要证据集**；
(R3') HAT 的证书继承按构造相关，**永不**算独立证据，只作为条件前提传播（条件失败率相加或取保守上界，不许相乘）。
事后证伪：若共模被揭穿，回溯作废所有把该"一致"计入独立证据的承诺，并把该共享路径加入同类区域的共因集。

**定义 144（任务级证据门 TSE、证书 J_t 与 PCE^T）** J_t=(τ, {J_p(v)}, 合成模式与界, 重置审计, {BCC}, {HAT_log}, CM_log, checkpoint/retry_log, probe_ledger)。任务级门：
commit_task ⇔ (∀ v∈load_bearing(τ): J_p(v) 有效) ∧ LB(𝒢_τ)≥δ_task ∧ 无 open HAT ∧ 无未决 CM ∧ 无未决同意。
PCE^T 在 PCE+ 上加两层预算分配：①**按块分配探针**——VoI_τ(v)=降低 δ_v 对 LB 的边际收益 × 下游/共因中心性 c_v（c_v 为 dep 中依赖 v 所声明共同因的块数），因此切割点前的共因节点优先；②**按角色分配**——hold_act 区间内优先探共享对象与持臂抓握（它们同时是动臂前提），independent 区间才允许两臂各自探。终止预算 k_probes+k_cons+k_retry+检查点数全部有界。

## 2. 关键算法伪代码（完整版见产物区）

```python
def compose_task_cert(G, mode, reset_audit, lam, delta_task):
    p = [v.p_lb for v in G.nodes]
    if mode == 'M1' or not reset_audit.ok:          # 任意相关，永远健全
        lb = max(0.0, sum(p) - (len(p) - 1))
    else:                                            # 重置 + 每块一次重试
        lb = 1.0
        for blk in reset_audit.super_blocks(G):
            pb = block_lb(blk)
            lb *= (1.0 - (1.0 - pb) ** 2)
        lb -= reset_audit.delta_reset
    return lb, lb >= delta_task

def bcc_monitor(c, M, t):                            # 区间化协调契约
    if c.inv == 'rigid_rel':
        ok = norm(rel_residual(M.T_H(t), M.T_A(t), c.ref)) <= c.eps
    elif c.inv == 'hold_act':
        ok = M.grasp[c.H] and quasi_static(M.v[c.H], c.eps) \
             and M.grasp[c.A] and not shared_ownership_violation(c.o)
    elif c.inv == 'shared_obj':
        ok = object_pose_residual(c.o, M) <= c.eps
    else:
        ok = True                                    # independent: 两臂各签各的
    if not ok and c.inv != 'independent':
        c.valid = False                              # 区间外退回独立证书
    return c

def hat_execute(hat, M, cert):
    if not (cert.Jp[hat.H] and bcc_monitor(hat.bcc, M, t_now).valid):
        return 'abort', 'prepare_failed'
    premise = cert.Jp[hat.H].grasp_cert(hat.o)       # 动臂继承的前提 P_H
    while hat.in_motion(t_now):
        if not premise.still_valid(M) or not bcc_monitor(hat.bcc, M, t_now).valid:
            cert.void(hat.A); return 'abort', 'holder_premise_lost'
        execute(hat.A)
    if not cert.support_independent(hat.A):
        return 'hold', 'release_order_violation'     # 禁止运动中松手
    hat.release(hat.H); hat.log(); return 'ok', 'committed'

def cmt_gate(H, A, M, level):
    indep = disjoint([M.sense[H], M.sense[A]], [M.calib[H], M.calib[A]],
                     [M.plan_prefix[H], M.plan_prefix[A]], M.owner)
    if not indep:
        return 'single_evidence', min(M.w[H], M.w[A])
    if level != 'L1':
        return 'reject', 'bimanual_on_irreversible'
    return ('EV-bimanual',) if agreement(H, A) and M.D <= theta_D else ('reject', 'disagree')
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TDG | O(\|𝒱\|+\|ℰ\|) | O(\|𝒱\|) | DAG 无环、块证书作用域完整 |
| TCB | O(\|𝒱\|) / 合成；重置审计 O(\|C\|·\|𝒱\|) | O(\|𝒱\|) | M1 任意相关健全；M2 仅在审计通过时用 |
| BCC | O(1) / 控制拍（相对变换） | O(\|契约\|) | 不变式逐时刻监测、区间外退回独立 |
| HAT | O(1) / 事务步 | O(\|HAT\|) | 所有权唯一、全序无死锁、前提失效即作废 |
| CMT | O(1) / 证据 | O(\|证据\|) | 独立声明诚实、CM=1 不得相加 |
| TSE/PCE^T | O(\|𝒱\|·(k_p+k_c+k_r)·(C_VOI+d_φ)) | O(\|𝒱\|+\|σ\|) | 合成界非空、预算有界、四态完备 |

**正确性定理（TCP: Task-Composable, Contract-based, Common-mode-aware soundness）** 在 A22–A40 上新增：**(A41)** 块证书与合成模式声明诚实，M2 的重置独立由审计保证（漏检 ≤δ_reset）；**(A42)** BCC 不变式监测的漏检 ≤δ_bcc，区间外正确退回独立证书；**(A43)** HAT 满足所有权唯一、全序无死锁、前提失效即作废，继承可追踪；**(A44)** 跨臂独立声明诚实，共模检出率 ≥1−δ_cm；**(A45)** 𝒢_τ 有限无环、检查点/重试/HAT 次数有界。则：
(i) **任务合成健全**：M1 下 P(task)≥LB_F；M2 下 P(task)≥LB_R−δ_reset。第 57 轮对检查点求并集的部署界是 M1 的特例，会在 n_collapse 处归零——本轮把它当成"必须切割"的告警而非可接受的保证。
(ii) **协调健全**：依赖 BCC 不变式的块只在该契约区间内被认证；区间外两臂必须各自持证，交接后继承作废。
(iii) **共模不升险**：CM=1 时跨臂一致只能算一条证据且权重取 min，CM 检出后该路径进入共因集；EV-bimanual 仅限 L1。
(iv) **交互单调性延续**：分解与协调机制只能经"更保守的动作"（检查点/重试/中止/退回独立）或"更准的信念"（重置/契约/相对帧）影响系统。
(v) **终止性**：探针、共识探针、重试、检查点与 HAT 均有界，PCE^T 有限步终止于 {任务承诺, 绕行, L2 协商, 安全停}。

**部署界**：M1 下 `P_task ≥ 1 − Σ_{v∈𝒱}δ_v − Σ_{c∈C}δ_reset(c) − Σ_hat δ_abort_fail − P(CM漏检)·δ_cm`；M2 下用 `LB_R−δ_reset` 替换首项，并额外扣减"重置审计失败时退回 M1 的保守损失"（只影响可用性，不影响健全性）。

## 6. 本轮最大风险

**一句话**：本轮把任务级保证建立在"分解与依赖声明"之上，而检查点重置与跨臂独立都是**声明**出来的——若存在跨切割、跨臂的隐藏共同因（同一块未探地图、同一个底座位姿、同一条计划前缀），重置就是虚构的，合成界会悄悄从"重置乘积"退回"长程并集归零"，甚至在错误的地方被当成可乘的独立项；系统恰恰会在最长、耦合最紧的双臂任务上最自信，因为那正是它最看不见耦合的地方——因此必须把重置审计、共因披露、相对帧契约与共模检验作为不可协商的前置，审计失败一律退回 M1 或直接不承诺。

def build_task_graph(task, M, persona):

### IP-140 TCB（健全任务合成界）

```python
def compose_task_bound(G, mode, reset_audit, lam, delta_task):
    p = [v.p_lb for v in G.nodes]
    if mode == 'M1' or reset_audit is None or not reset_audit.ok:
        lb = max(0.0, sum(p) - (len(p) - 1))         # 任意相关：永远健全
        used = 'M1'
    else:
        lb = 1.0
        for blk in reset_audit.super_blocks(G):      # 切割点隔开、条件独立
            pb = min(v.p_lb for v in blk)            # 块内取最弱
            lb *= (1.0 - (1.0 - pb) ** 2)            # 每块一次重试
        lb = max(0.0, lb - reset_audit.delta_reset)
        used = 'M2'
    feasible = lb >= delta_task
    return {'lb': lb, 'mode': used, 'feasible': feasible}

def choose_granularity(G, mode, lam, delta_task):
    best = None
    for b in admissible_block_lengths(G):
        Gb = regroup(G, b)
        r = compose_task_bound(Gb, mode, reset_audit(Gb), lam, delta_task)
        score = r['lb'] - lam * steps_per_skill(Gb)
        if r['feasible'] and (best is None or score > best[1]):
            best = (b, score, r)
    return best                                       # 安全硬约束先于分数
```

def bcc_monitor(c, M, t):
    if c.inv == 'rigid_rel':
        ok = norm(rel_residual(M.T_H(t), M.T_A(t), c.ref)) <= c.eps
    elif c.inv == 'hold_act':
        ok = (M.grasp[c.H] and quasi_static(M.v[c.H], c.eps)

def hat_execute(hat, M, cert):
    if not (cert.Jp[hat.H] and bcc_monitor(hat.bcc, M, t_now).valid):
        return 'abort', 'prepare_failed'
    premise = cert.Jp[hat.H].grasp_cert(hat.o)       # 动臂继承 P_H
    while hat.in_motion(t_now):
        if not premise.still_valid(M) or not bcc_monitor(hat.bcc, M, t_now).valid:
            cert.void(hat.A)                         # 前提失效 → 动臂证书立即作废
            return 'abort', 'holder_premise_lost'
        execute(hat.A)
    if not cert.support_independent(hat.A):
        return 'hold', 'release_order_violation'     # 禁止运动中松手
    hat.release(hat.H)
    hat.log(); return 'ok', 'committed'

def hat_serialize(tasks):

### IP-144 TSE / PCE^T（任务级证据门与分解感知的探针预算）

```python
def task_evidence_gate(G, contracts, hats, cm_log, consent):
    if not all(v.Jp.valid for v in G.load_bearing()):
        return 'reject', 'block_certificate'
    r = compose_task_bound(G, G.mode, G.reset_audit, G.lam, delta_task)
    if not r['feasible']:
        return 'reject', 'composition_vacuous', r
    if any(h.open for h in hats):       return 'reject', 'hat_open'
    if cm_log.unresolved:               return 'reject', 'common_mode_open'
    if consent.pending:                 return 'reject', 'consent_open'
    return 'ok', J_t(G, r, contracts, hats, cm_log, consent)

def dag_voi(v, G, M, inf):
    downstream = centrality(v, G.dep)            # 依赖 v 所声明共同因的块数
    marginal = delta_lb_from_reducing(G, v)      # 并集界下正比于 δ_v
    return marginal * (1.0 + downstream)         # 切割点前的共因节点最值钱

def pce_task(x0, G, M, budget, consent):
    for cp in G.C:                               # 先按拓扑选切割点
        if compose_task_bound(G, G.mode, G.reset_audit, G.lam, delta_task)['feasible']:
            break
        cands = admissible_probes(cp, M, F_abs)
        v = max(G.nodes, key=lambda u: dag_voi(u, G, M, inf))
        if dag_voi(v, G, M, inf) < theta_voi: break
        M = probe_and_reconcile(v, M)            # 继承第 57 轮元推断/对账
        G = recap_certificates(G, M)             # 只更新受影响的块证书
    hats = [h for h in G.handovers if h.open]
    for h in hat_serialize(hats):
        st = hat_execute(h, M, G.cert)
        if st[0] != 'ok': return reroute_or_stop(h, M, st)
    return task_evidence_gate(G, G.contracts, hats, M.cm_log, consent)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TDG | O(\|𝒱\|+\|ℰ\|) | O(\|𝒱\|) | DAG 无环、块证书作用域完整 |
| TCB | O(\|𝒱\|) / 合成；审计 O(\|C\|·\|𝒱\|) | O(\|𝒱\|) | M1 任意相关健全、M2 仅审计后使用（A41） |
| BCC | O(1) / 控制拍 | O(\|c\|) | 不变式逐拍监测、区间外退回独立（A42） |
| HAT | O(1) / 事务步 | O(\|HAT\|) | 所有权唯一、全序无死锁、失效即作废（A43） |
| CMT | O(1) / 证据 | O(\|证据\|) | 独立声明诚实、CM=1 不相加（A44） |
| TSE/PCE^T | O(\|𝒱\|·(k_p+k_c+k_r)·(C_VOI+d_φ)) | O(\|𝒱\|+\|σ\|) | 合成界非空、预算有界、四态完备（A45） |

**正确性定理（TCP: Task-Composable, Contract-based, Common-mode-aware soundness）**
假设 A22–A40 成立；新增 **(A41)** 块证书与合成模式声明诚实，M2 重置独立由审计保证（漏检 ≤δ_reset）；**(A42)** BCC 不变式监测漏检 ≤δ_bcc，区间外正确退回独立证书；**(A43)** HAT 满足所有权唯一、全序无死锁、前提失效即作废且继承可追踪；**(A44)** 跨臂独立声明诚实，共模检出率 ≥1−δ_cm；**(A45)** 𝒢_τ 有限无环，检查点/重试/HAT 次数有界。则：

1. **任务合成健全**：M1 下 `P(task) ≥ max(0, 1−Σδ_v)`；M2 下 `P(task) ≥ Π_j(1−(1−p_j^{lb})²) − δ_reset`。第 57 轮对检查点求并集的部署界是 M1 特例，会在 `n_collapse` 归零——本轮将其作为"必须切割"的告警。
2. **协调健全**：依赖 BCC 不变式的块只在该契约区间内被认证；区间外两臂必须各自持证；交接后跨切割继承作废。
3. **共模不升险**：CM=1 时跨臂一致只算一条证据、权重取 min；EV-bimanual 仅限 L1；HAT 继承按构造相关，永不作为独立证据。
4. **交互单调性延续**：分解与协调只经"更保守的动作"（检查点/重试/中止/退回独立）或"更准的信念"（重置/契约/相对帧）影响系统。
5. **终止性**：探针、共识探针、重试、检查点、HAT 均有界，PCE^T 有限步终止于 {任务承诺, 绕行, L2 协商, 安全停}。

**部署界**（M1）：
```
P_task ≥ 1 − Σ_{v∈𝒱} δ_v − Σ_{c∈C} δ_reset(c)
           − Σ_hat δ_abort_fail − P(CM漏检)·δ_cm
```
M2 下用 `LB_R − δ_reset` 替换首项，并额外扣减"审计失败退回 M1"的保守损失（只影响可用性，不影响健全性）。

| 时延-增益 | a\*(d)=2sin(π/(2(2d+1)))：d=0→2.0，d=7→0.209 | 7 帧 lead-lag 下协调回路增益须 ≤0.21 |
| 交接算术 | p_fail=0.01, p_h=0.85, 20 块：无交接 0.818 → 有交接 0.970（MC 0.817/0.970） | HAT/重试把失败转为可恢复；但继承制造依赖 |

**读法**：合成界检查证明"乘起来"在共同因下不健全、并给出何时该切割；双臂检查证明"共动"不能替代协调、相对帧能抵消共模但不能抵消单臂噪声与时延；交接算术证明事务/重试的价值与"依赖代价"并存。三者共同支持本轮把 b、契约区间与共模声明做成证书的一等公民。

## 7. 本轮最大风险

**一句话**：本轮把任务级保证建立在"分解与依赖声明"之上，而检查点重置与跨臂独立都是声明出来的——若存在跨切割、跨臂的隐藏共同因（同一块未探地图、同一个底座位姿、同一条计划前缀），重置就是虚构的，合成界会悄悄从"重置乘积"退回"长程并集归零"，甚至在错误的地方被当成可乘的独立项；系统恰恰会在最长、耦合最紧的双臂任务上最自信，因为那正是它最看不见耦合的地方——因此必须把重置审计、共因披露、相对帧契约与共模检验作为不可协商的前置，审计失败一律退回 M1 或直接不承诺。
