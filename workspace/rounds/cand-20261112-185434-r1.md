# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC；灵感循环第 8 轮；本轮灵感：「推理延迟」×「视觉定位」）

> 第 61 轮构建了「语义-实时双流」的具身语义进化闭环 ESEC：USR 统一语义表征、MEL 零样本物理推断、DMS 多轮对话接地、SRT-Dual 解耦大模型推理与实时控制、PCE+++++ 六元认知-语义预算。但**四个时空层面的核心局限**仍待突破：
> 1. **语义锚点是「事后快照」，实时流永远消费过去**：SRT-Dual 只读 `read_latest_anchor()`，而锚点一经产生就已过期 τ_mel≈200ms。第 61 轮用「超时→保守扩展」应对，但这是**反应式**的：它无法区分「可预测的过期」（匀速慢速运动，外推即可补偿）与「不可预测的过期」（接触瞬变，外推会放大错误），只能一刀切地放大安全裕度，牺牲精度换安全。
> 2. **延迟被当作标量常数**：MEL 推理延迟随输入复杂度、Token 长度、KV 命中率剧烈波动（~20–500ms），`τ_sem_max=500ms` 是一个魔数；既没有对延迟本身建模/预测，也没有 deadline 感知的调度与 anytime 推理，导致「有时白等、有时不够等」。
> 3. **缺乏空间几何接地**：USR 的 `scene_emb/intent_emb` 是纯语义向量，不含 6-DoF 位姿。阻抗控制不知道目标在哪、末端偏了多少；而视觉定位的位姿误差与延迟直接决定接触成败，却被完全忽略。**语义说「轻触」，几何却可能对不准**。
> 4. **位姿不确定性未进入控制**：即使引入视觉定位，其协方差 Σ_pose 也未映射到阻抗参数。各向同性的 K 无法表达「沿某方向看不清 → 该方向应更柔顺」这一物理直觉，定位噪声因此被均匀地放大到所有方向。

## 0. 直觉与动机

**灵感 1（推理延迟 → 时空锚点场 STAF）**
直觉：把「最新锚点」升级为「最近 K 个带时间戳的锚点 + 速度估计」的**时空锚点场**。实时流不再问「最新的是谁」，而是问「**在控制时刻 t_c，语义/位姿最可能是什么**」。锚点携带 `(z, ż, p, Σ_p, ξ̇, τ_prov, mode)`，查询接口 `A.query(t_c)` 在潜空间做 Kalman 预测外推、在位姿空间做 twist 运动补偿。这样，延迟不再是「必须等待的空白」，而是「一段可以被预测填补的区间」。

**灵感 2（推理延迟 → 延迟预算代数 LBA + 随时语义推理 ASI）**
直觉：延迟不是常数，而是一个**可预测的分布**。用一个轻量延迟预测器 `τ̂ = h_φ(输入复杂度)` 在推理前估计耗时，配合 anytime 推理（粗→细、可早退、每级带质量分 q_k 与时延 τ_k）和 deadline 感知调度（EDF + 准入控制）：若 `τ̂` 超过语义 slack，就提前降级到粗粒度结果，而不是等到超时再慌忙回退。**关键洞见：不是「让推理变快」，而是「让系统永远在 deadline 前拿到当时能拿到的最好结果」**。

**灵感 3（视觉定位 → 定位接地各向异性阻抗 LGI）**
直觉：视觉定位输出 6-DoF 位姿 p 与协方差 Σ_p。把 Σ_p 的平移块特征分解 `Σ_p = UΛUᵀ`，沿特征方向 i 的定位标准差为 `√λ_i`。于是定义方向刚度 `k_i = k_min + (k_max-k_min)·exp(-λ_i/λ_0)`：定位越精确（λ_i 小）→ 刚度越高（敢精确接触）；定位越模糊（λ_i 大）→ 刚度越低、阻尼越高、力上限越低（柔顺避碰）。**协方差谱 → 阻抗谱**，定位不确定性第一次真正进入控制律。

**灵感 4（视觉定位 → 延迟补偿视觉伺服 LCVS + 主动定位 ALP）**
直觉：视觉定位本身也有延迟 τ_loc，机器人在此期间仍在运动，产生「运动诱导位姿误差」≈ v·τ_loc（0.1 m/s × 100ms = 1cm，接触任务足以致命）。用 VIO 的 twist ξ̇ 把位姿外推到 t_c：`p̂(t_c) = p_t ⊕ exp((t_c-t)·ξ̇)`，并传播协方差。当外推后的 Σ̂ 仍过大或置信度不足时，触发**主动定位**：用 VOI（期望信息增益 - 动作代价）选择一次受安全包络约束的小幅探索运动/换视角，主动降低位姿熵——把「被动等待定位」变成「主动改善定位」。

**灵感 5（双灵感合流 → 时空对齐接地进化闭环 STAG-ESEC）**
直觉：语义流产出 `(语义嵌入, 位姿, 协方差, 时间戳, 延迟来源)`，写入 STAF；实时流按控制时刻 t_c 查询 STAF，得到时空对齐的 `(ẑ(t_c), p̂(t_c), Σ̂(t_c))`；LGI 把 Σ̂ 编译为各向异性阻抗先验，EEIS 在此先验下编译 K_safe；执行证据 EV-exec 回填 STAF，形成「语义-几何-控制-证据」的时空闭环。证书 TSC 在原有语义/执行校验之外，新增 `latency_slack / semantic_age / pose_cov / loc_conf` 四项时空校验。

**灵感 6（预算 → 八维 B_cog8 / PCE++++++）**
直觉：上一轮的六元预算缺少「延迟」和「定位」两条命脉。新增 `B_lat = (deadline, slack_min, predict_horizon, inference_mode)` 与 `B_loc = (loc_freq, keyframe_rate, pose_cov_tol, active_perception_budget)`。VOI 扩展为 `voi_st = VOI_meta - cost_lat - cost_loc - cost_exec`；B_lat 耗尽⇒收紧预测视界并降级 anytime 精度；B_loc 耗尽⇒降低定位频率、冻结位姿外推、强制保守阻抗。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（时空锚点场 STAF, Spatio-Temporal Anchor Field）** `A = (B, P, Q)`：
- **锚点缓冲**：`B = ⟨a_1, …, a_K⟩`，按时间升序，`K=16`；每个锚点
  `a_i = (t_i, z_i ∈ ℝ^{d_us}, p_i ∈ SE(3), Σ_i ∈ ℝ^{6×6}, ż_i ∈ ℝ^{d_us}, ξ̇_i ∈ ℝ^6, τ_i^prov, mode_i)`
  其中 `τ_i^prov` 为延迟来源分解（采集/传输/推理/对齐），`mode_i ∈ {full, distill, cached, frozen}`
- **预测器** `P`：潜空间 Kalman 预测（定义 174）+ 位姿 twist 外推（定义 177）
- **查询**：`A.query(t_c) → (ẑ(t_c), Σ_z(t_c), p̂(t_c), Σ_p(t_c), age, mode)`，其中 `age = t_c - t_i`
- **非阻塞语义**：查询只读快照，不持锁；写入为 CAS，版本号 64 位单调（承接定义 165）

**定义 174（潜空间预测外推 LPE, Latent Predictive Extrapolation）** 在语义潜空间维护一阶 Kalman 状态 `x = [z; ż] ∈ ℝ^{2d_us}`：
- **状态转移**：`F(Δt) = [[I, Δt·I], [0, I]]`
- **过程噪声**：`Q(Δt) = q·[[Δt³/3·I, Δt²/2·I], [Δt²/2·I, Δt·I]]`（连续白噪声加速度模型）
- **观测**：`H = [I, 0]`，观测噪声 `R = Σ_obs`
- **预测**：`x⁻ = F(Δt)·x`，`P⁻ = F(Δt)·P·F(Δt)ᵀ + Q(Δt)`
- **查询输出**：`ẑ(t_c) = x⁻_z`，`Σ_z(t_c) = P⁻_{zz}`；有效语义年龄 `age_eff = Δt`（残差不再随延迟线性增长）

**定义 175（随时语义推理 ASI, Anytime Semantic Inference）** MEL 不再「一次算完」，而是产出细化序列：
- **细化链**：`r_0 → r_1 → … → r_n`，第 k 级质量 `q_k`、增量时延 `τ_k`、累计时延 `T_k = Σ_{j≤k} τ_j`
- **质量-时延曲线** `Q(T)`：非降、凹（边际收益递减），满足 `Q(T_k)=q_k`
- **deadline 策略**：给定语义截止 `D_sem`，取 `k* = max{k : T_k ≤ D_sem}`，返回 `r_{k*}`
- **早退**：若 `confidence(r_k) ≥ q_stop` 或 `U_epistemic(r_k) ≤ U_stop`，立即停止细化
- **保证**：`Q(T)` 非降 ⇒ 分配更多时延永不降低结果质量；早退条件保证安全下界 `q_k ≥ q_stop`

**定义 176（延迟预算代数 LBA, Latency Budget Algebra）** 端到端延迟分解与调度：
- **分解**：`τ_e2e = τ_cap + τ_trans + τ_infer + τ_align + τ_commit`
- **语义 slack**：`slack_sem(t) = D_sem - (t_release + τ̂_infer + τ_trans)`，其中 `τ̂_infer = h_φ(complexity(V,T,P,L))`
- **实时 slack**：`slack_rt(t) = D_rt - τ_rt_exec`，要求 `slack_rt ≥ 0` 恒成立（实时流永不等待语义流）
- **EDF 调度**：语义作业按 deadline 升序执行；单处理器 EDF 在 `Σ utilization ≤ 1` 时最优
- **准入控制**：若 `τ̂_infer + τ_trans > slack_sem`，则在推理**之前**降级模式（full→distill→cached），而非事后回退
- **延迟预测器误差界**：`|τ̂_infer - τ_infer| ≤ δ_τ`（假设 A74），用于证书保守化

**定义 177（视觉定位接地 VLG, Visual Localization Grounding）** 定位模块与运动补偿：
- **定位算子**：`L: (I_t, I_{t-1}, IMU, Map) → (p_t ∈ SE(3), Σ_t ∈ ℝ^{6×6}, c_t ∈ [0,1])`，延迟 `τ_loc`
- **twist 估计**：由 VIO/相邻帧 `ξ̇_t ∈ ℝ^6`（线速度 + 角速度），协方差 `Σ_ξ`
- **位姿外推**：`p̂(t_c) = p_t · exp((t_c - t)·ξ̇_t)`
- **协方差传播**：`Σ̂(t_c) = Σ_t + J_m(Δt)·Σ_ξ·J_m(Δt)ᵀ·Δt² + Σ_proc·Δt`，`J_m` 为运动模型对 twist 的雅可比
- **运动诱导误差**：零阶保持误差 ≈ `v·Δt`；一阶外推误差 ≈ `½a·Δt² + σ_ξ·Δt`（见定义 179）

**定义 178（定位接地各向异性阻抗 LGI, Localization-Grounded Impedance）** 把位姿协方差映射为阻抗谱：
- 取平移块 `Σ_p^{tt} = UΛUᵀ`，`Λ = diag(λ_1,λ_2,λ_3)`，`U` 正交
- **方向刚度**：`k_i = k_min + (k_max - k_min)·exp(-λ_i/λ_0)`
- **方向阻尼**：`d_i = d_min + (d_max - d_min)·(1 - exp(-λ_i/λ_0))`
- **方向力上限**：`F_i = F_max · exp(-λ_i/λ_1)`
- **合成**：`K_p = U·diag(k_i)·Uᵀ`，`K_d = U·diag(d_i)·Uᵀ`，`F_max(Σ_p) = U·diag(F_i)·Uᵀ`
- **谱界（向后兼容 EEIS）**：`k_min·I ⪯ K_p ⪯ k_max·I`，故第 61 轮 EEIS 的谱约束仍成立；当 `Σ_p = 0` 时 `K_p = k_max·I`，退化为各向同性

**定义 179（预测视界-不确定性权衡 PU-Tradeoff）** 用严格判据替代魔数超时：
设语义/位姿轨迹满足 `‖ż‖ ≤ v_max`、`‖z̈‖ ≤ a_max`，速度估计误差标准差 `σ_ż`。
- **零阶保持误差**：`E[‖e_zoh‖²] = v²·Δt²`
- **一阶外推误差**：`E[‖e_pred‖²] = (½·a·Δt²)² + σ_ż²·Δt²`
- **可预测视界**：`Δt_pred ≜ 2·√(max(v² - σ_ż², 0)) / a_max`
- **判据**：`Δt ≤ Δt_pred ⇒ E[e_pred²] ≤ E[e_zoh²]`，外推有益；否则外推会放大错误，必须回退保守扩展
- 当 `v ≤ σ_ż`（运动慢于速度估计噪声）时 `Δt_pred = 0`，预测无益，直接保守扩展
- **本判据完全取代第 61 轮的 `τ_sem_max=500ms` 魔数**

**定义 180（时空一致性证书 TSC, Temporal-Spatial Certificate）** 扩展定义 170 的 `J_sem_exec`：
```
J_stag = (J_sem_exec,
          latency_slack,        # 语义 slack（秒，可为负）
          semantic_age,         # 查询残差 age_eff
          pose_cov_trace,       # tr(Σ̂_p(t_c))
          pred_horizon,         # Δt = t_c - t_i
          loc_confidence,       # c_t
          lgi_spectrum)         # K_p 的特征值谱（审计用）
Valid(J_stag) ⇔ Valid(J_sem_exec)
               ∧ latency_slack ≥ 0
               ∧ semantic_age ≤ τ_age_max
               ∧ pose_cov_trace ≤ Σ_max
               ∧ loc_confidence ≥ c_min
               ∧ pred_horizon ≤ Δt_pred
```

**定义 181（延迟补偿视觉伺服与主动定位 LCVS-ALP）**：
- **伺服律**：`u = J_p†(p̂(t_c))·(e_p + K_p·e_p) + K_f·F_ext`，`e_p = p* ⊖ p̂(t_c)`
- **主动定位触发**：若 `c_t < c_min` 或 `tr(Σ̂) > Σ_active`，则求
  `a_loc* = argmax_{a ∈ A_safe} [ EIG(Σ̂; a) - λ_cost·cost(a) - λ_risk·risk(a) ]`
  其中 `EIG` 为预期信息增益（位姿熵下降），`A_safe` 为受 ERTC 安全包络约束的小幅探索动作集
- **安全门**：任何主动定位动作须通过 ERTC 预检，绝不为了「看清」而进入危险位形

**定义 182（八维认知-时空预算 B_cog8 / PCE++++++）** 在上一轮六元预算的实质分量上新增两维：
`B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_lat, B_loc)`
（注：上一轮记作 `B_cog5` 但实际列出六个分量，本轮按其实质六元扩展为八元，以消除编号歧义。）
- **B_lat** = `(D_sem, slack_min, predict_horizon_max, inference_mode, early_exit_thresh)`
- **B_loc** = `(loc_freq, keyframe_rate, pose_cov_tol, active_perception_budget, motion_comp_tol)`
- **成本扩展**：`cost_cog8 = cost_cog5 + λ_lat·(τ_infer/τ̂_infer + max(0,-slack)/D_sem) + λ_loc·(tr(Σ̂)/Σ_tol + cost_active/AP_budget)`
- **降级**：`B_lat` 耗尽 ⇒ `predict_horizon_max ← 0`（停止外推）、anytime 精度降级、保守扩展；`B_loc` 耗尽 ⇒ 定位降频、冻结 twist 外推、LGI 取 `k_i = k_min`（全局柔顺）

**定义 183（时空对齐接地进化闭环 STAG-ESEC）** 统一语义流、几何流与实时流：
```
STAG-ESEC(M, obs, t_c):
  # —— 语义流（异步，10–100Hz）——
  D_sem ← M.lba.next_deadline()
  z_sem, q_sem ← M.asi.infer_until(obs, D_sem)          # anytime，deadline 感知
  loc ← M.vlg.step(I_t, I_{t-1}, IMU, Map)              # 6-DoF + Σ + conf + τ_loc
  M.staf.push(t=t_sem, z=z_sem, p=loc.p, Σ=loc.Σ,
              ż=M.lpe.velocity(), ξ̇=loc.ξ̇, τ_prov=..., mode=M.budget.mel_mode)

  # —— 实时流（同步，1–10kHz，按控制时刻查询）——
  st ← M.staf.query(t_c)                                 # 语义 Kalman 外推 + 位姿 twist 补偿
  if not M.stc.gate(st):                                 # 新息门控 / 可预测视界检查
      st ← M.staf.query_conservative(t_c)                # 回退：零阶保持 + 协方差下限
  K_prior ← M.lgi.compile(st.Σ_p, k_nom, d_nom, F_max)  # 协方差谱 → 各向异性阻抗
  K_safe  ← M.eeis.compile(delta_f_req, fused, ξ_exec, Z_env, K_prior, st.ẑ)
  cert    ← M.ertc.dispatch(K_safe)

  # —— 证据回填与证书 ——
  EV_exec ← wait_contact_and_build_evidence()
  M.staf.push_evidence(EV_exec)
  J_stag  ← M.tsc.build(cert, st, M.lba.slack(), loc.conf, M.budget)
  return K_safe, EV_exec, J_stag
```

**定义 184（时空一致性监控器 STC-Monitor）** 用可证伪的统计检验守住「预测不越界」：
- **新息检验**：`d_t = z_obs - H·x⁻`，`S_t = H·P⁻·Hᵀ + R`；若 `d_tᵀS_t⁻¹d_t > χ²_{d,1-α}` 判为「动力学突变」，拒绝外推，触发保守扩展
- **协方差下限**：`Σ̂ ← max(Σ̂, Σ_floor)`，防止 Kalman 过度自信（协方差塌缩）
- **视界硬截断**：`Δt > Δt_pred ⇒ 强制保守`（定义 179）
- **连续失配**：连续 3 个周期新息检验失败 ⇒ 冻结 STAF 外推、清空速度估计、请求主动定位
- **可审计**：每次 gate 决策写入诊断缓冲（承接 DMS 的 B_diag）

## 2. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| STAF | O(K + d_us) 查询 | O(K·(d_us + 36)) | 查询非阻塞；版本号 64 位单调；无撕裂读 |
| LPE (Kalman) | O(d_us²) 预测/更新 | O(d_us²) | 新息白化检验通过；协方差 ≥ Σ_floor |
| ASI | O(Σ τ_k) ≤ D_sem | O(1) 状态 | 质量随时延非降；早退质量下界 q_stop |
| LBA | O(log N) EDF 调度 | O(N) 作业队列 | slack<0 前完成降级；实时流不阻塞 |
| VLG | ~10–50ms（30Hz） | O(1) 关键帧 | 位姿外推误差 ≤ ½aΔt² + σ_ξΔt |
| LGI | O(3³) 特征分解 | O(9) | K_p 对称正定；k_min·I ⪯ K_p ⪯ k_max·I |
| LCVS-ALP | O(1) 伺服 / O(|A_safe|) VOI | O(1) | 主动动作必过 ERTC 安全预检 |
| TSC | O(1) 校验 | O(1) | 六项时空条件全部满足才 Valid |
| PCE++++++ | O(1) 预算检查 | O(1) | 任一维耗尽触发对应安全降级 |

**正确性定理（STAG-Complete）**：
假设 A61–A70 及
**(A71)** STAF 锚点时间戳一致、查询原子、版本号单调（承接 A69）。
**(A72)** LPE 的连续白噪声加速度模型成立，过程噪声 `q` 上界真实加速度功率谱，Kalman 一致（NEES ∈ 置信带）。
**(A73)** ASI 的质量-时延曲线 `Q(T)` 非降，早退阈值 `q_stop` 为真实质量下界。

```python
class SpatioTemporalAnchorField:
    def __init__(self, d_us=256, K=16, q_proc=1e-3, sigma_floor=1e-6):
        self.d_us = d_us
        self.buffer = deque(maxlen=K)          # 时间升序锚点
        self.kf = LatentKalman(d=d_us, q=q_proc, r=1e-3)  # 见 IP-184
        self.sigma_floor = sigma_floor
        self.version = 0

    def push(self, t, z, p, Sigma_p, zdot, xi_dot, tau_prov, mode):
        a = Anchor(t=t, z=z, p=p, Sigma_p=Sigma_p, zdot=zdot,
                   xi_dot=xi_dot, tau=tau_prov, mode=mode)
        self.buffer.append(a)
        self.kf.update(z, R=np.eye(self.d_us) * 1e-3)   # 观测更新
        self.version = (self.version + 1) & ((1 << 64) - 1)
        return a

    def query(self, t_c):
        if not self.buffer:
            return None
        a = self.buffer[-1]
        dt = max(t_c - a.t, 0.0)
        # 语义：潜空间 Kalman 外推
        z_hat, Sigma_z = self.kf.predict(dt)
        # 位姿：twist 运动补偿 + 协方差传播
        p_hat, Sigma_p = compensate_pose(a.p, a.Sigma_p, a.xi_dot, dt)
        Sigma_z = np.maximum(Sigma_z, self.sigma_floor)   # 协方差下限
        Sigma_p = np.maximum(Sigma_p, self.sigma_floor)
        return STE(t=t_c, z=z_hat, Sigma_z=Sigma_z, p=p_hat,
                   Sigma_p=Sigma_p, age=dt, mode=a.mode)

    def query_conservative(self, t_c):
        """回退：零阶保持 + 协方差膨胀，不做外推"""
        a = self.buffer[-1]
        dt = max(t_c - a.t, 0.0)
        return STE(t=t_c, z=a.z, Sigma_z=a.Sigma_p[:self.d_us, :self.d_us] * (1 + dt),
                   p=a.p, Sigma_p=a.Sigma_p * (1 + dt), age=dt, mode=a.mode)
```

### IP-184 LPE（潜空间预测外推）

```python
class LatentKalman:
    def __init__(self, d, q=1e-3, r=1e-3):
        self.d = d
        self.x = np.zeros(2 * d)            # [z; zdot]
        self.P = np.eye(2 * d)
        self.q, self.r = q, r

    def _F(self, dt):
        F = np.eye(2 * self.d)
        F[:self.d, self.d:] = dt * np.eye(self.d)
        return F

    def _Q(self, dt):
        I = np.eye(self.d)
        return self.q * np.block([[dt**3/3 * I, dt**2/2 * I],
                                  [dt**2/2 * I, dt * I]])

    def predict(self, dt):
        F = self._F(dt)
        self.x = F @ self.x
        self.P = F @ self.P @ F.T + self._Q(dt)
        return self.x[:self.d], self.P[:self.d, :self.d]

    def update(self, z_obs, R):
        d = self.d
        H = np.hstack([np.eye(d), np.zeros((d, d))])
        S = H @ self.P @ H.T + R
        K = self.P @ H.T @ np.linalg.inv(S)
        innov = z_obs - H @ self.x
        self.x = self.x + K @ innov
        self.P = (np.eye(2*d) - K @ H) @ self.P
        # 新息白化统计量，供 STC-Monitor 使用
        self.last_nis = float(innov.T @ np.linalg.inv(S) @ innov)
        return self.last_nis
```

```python
class AnytimeSemanticInference:
    def __init__(self, mel, refiner_costs, refiner_quality, q_stop=0.9):
        self.mel = mel
        self.costs = refiner_costs          # [τ_1, ..., τ_n]
        self.quality = refiner_quality      # [q_0, ..., q_n]
        self.q_stop = q_stop

    def infer_until(self, obs, deadline):
        t0 = time.time()
        z = self.mel.coarse(obs)            # r_0, ~20ms
        best = (z, self.quality[0], time.time())
        for k, refiner in enumerate(self.mel.refiners):
            if (time.time() - t0) + self.costs[k] > deadline:
                break                        # 预算不足，返回当前最优
            z = refiner(z, obs)              # r_{k+1}
            best = (z, self.quality[k+1], time.time())
            if self.mel.confidence(z) >= self.q_stop:
                break                        # 置信早退
        return best[0], best[1]
```

### IP-186 LBA（延迟预算代数）

```python
class LatencyBudgetScheduler:
    def __init__(self, D_sem=0.5, D_rt=0.001, predictor=None,
                 slack_min=0.02):
        self.D_sem = D_sem
        self.D_rt = D_rt
        self.tau_hat = predictor or (lambda c: 0.2)
        self.slack_min = slack_min
        self.jobs = []

    def slack_sem(self, job, now):
        return self.D_sem - ((now - job.t_release)
                             + self.tau_hat(job.complexity)
                             + job.t_transport)

    def admit(self, job, now):
        """推理前准入：不够预算就提前降级，而非事后回退"""
        if self.slack_sem(job, now) < self.slack_min:
            return 'distill' if self.slack_sem(job, now) > 0 else 'cached'
        return 'full'

    def schedule(self, now):
        """EDF：deadline 升序，单处理器最优"""
        ready = [j for j in self.jobs if j.t_release <= now]
        ready.sort(key=lambda j: j.deadline)
        return ready[0] if ready else None
```

```python
class LocalizationGroundedImpedance:
    def __init__(self, k_min=50.0, k_max=2000.0,
                 d_min=5.0, d_max=200.0,
                 lambda0=1e-4, lambda1=2e-4):
        self.k_min, self.k_max = k_min, k_max
        self.d_min, self.d_max = d_min, d_max
        self.lambda0, self.lambda1 = lambda0, lambda1

    def compile(self, Sigma_p, F_max=30.0):
        St = Sigma_p[:3, :3]
        lam, U = np.linalg.eigh(St)                # lam 升序
        lam = np.maximum(lam, 1e-12)
        k = self.k_min + (self.k_max - self.k_min) * np.exp(-lam / self.lambda0)
        d = self.d_min + (self.d_max - self.d_min) * (1 - np.exp(-lam / self.lambda0))
        F = F_max * np.exp(-lam / self.lambda1)
        Kp = U @ np.diag(k) @ U.T
        Kd = U @ np.diag(d) @ U.T
        return Impedance(Kp=Kp, Kd=Kd, F_max=U @ np.diag(F) @ U.T,
                         spectrum=k)
```

```python
        self.kp = kp
        self.c_min = c_min
        self.Sigma_active = Sigma_active

    def servo(self, p_hat, p_star, Jp, F_ext):

        u = np.linalg.pinv(Jp) @ (e + self.kp * e) + F_ext
        return u

    def maybe_active_localize(self, Sigma_hat, conf):
        if conf >= self.c_min and np.trace(Sigma_hat) <= self.Sigma_active:

        best, best_voi = None, -np.inf
        for a in self.safe_actions():
            if not self.ertc.precheck(a):       # 安全包络硬约束
                continue

        return best
```

```python
        self.lat_exhausted = False
        self.loc_exhausted = False

    def predict_horizon(self, dt):
        if self.lat_exhausted:
            return 0.0                      # 耗尽：禁止外推，退回零阶保持
        return min(dt, self.horizon_max)

    def allow_active_localize(self):
        return (not self.loc_exhausted) and (self.ap_used < self.ap_budget)

    def loc_step(self, trace_Sigma):
        if trace_Sigma > self.cov_tol:
            self.loc_freq = max(5, self.loc_freq // 2)   # 降频
        if self.loc_freq <= 5 and self.ap_used >= self.ap_budget:
            self.loc_exhausted = True
            self.horizon_max = 0.0          # 冻结 twist 外推
```

### IP-192 STAG-ESEC（时空对齐接地进化闭环）

```python
class STAG_ESEC:
    def __init__(self, mel, staf, lpe, asi, lba, vlg, lgi, lcvs,
                 eeis, ertc, tsc, budget):
        self.mel, self.staf, self.lpe, self.asi = mel, staf, lpe, asi
        self.lba, self.vlg, self.lgi, self.lcvs = lba, vlg, lgi, lcvs
        self.eeis, self.ertc, self.tsc, self.budget = eeis, ertc, tsc, budget
        self.stc = STCMonitor(tau_age=0.2)

    def semantic_step(self, obs):
        D_sem = self.budget.D_sem
        z_sem, q = self.asi.infer_until(obs, D_sem)
        loc = self.vlg.step(obs.I_t, obs.I_prev, obs.imu, obs.world_map)
        self.staf.push(t=time.time(), z=z_sem, p=loc.p, Sigma_p=loc.Sigma,
                       zdot=self.lpe.x[self.lpe.d:], xi_dot=loc.xi_dot,
                       tau_prov=loc.tau, mode=self.budget.legacy.get('mel_mode'))
        return z_sem, loc

    def realtime_step(self, t_c, delta_f_req, fused, xi_exec, Z_env):
        st = self.staf.query(t_c)
        # 可预测视界 + 新息门控（STC-Monitor）
        if (st is None) or (not self.stc.gate(st, self.lpe)) \
           or (st.age > self.budget.predict_horizon(st.age)):
            st = self.staf.query_conservative(t_c)
        imp = self.lgi.compile(st.Sigma_p, F_max=xi_exec.get('F_max', 30.0))
        K_safe = self.eeis.compile(delta_f_req, fused, xi_exec, Z_env,
                                   imp, st.z)
        cert = self.ertc.dispatch(K_safe)
        EV = wait_contact_and_build_evidence()
        self.staf.push_evidence(EV)
        J = self.tsc.build(cert, st, self.lba.slack_sem(None, time.time()),
                           st.conf if hasattr(st, 'conf') else 1.0,
                           st.age, imp.spectrum)
        return K_safe, EV, J


class STCMonitor:
    def __init__(self, tau_age=0.2, chi2_thresh=None, max_miss=3):
        self.tau_age = tau_age
        self.chi2_thresh = chi2_thresh
        self.max_miss = max_miss
        self.miss = 0

    def gate(self, st, lpe):
        if st.age > self.tau_age:
            return False
        nis = getattr(lpe, 'last_nis', 0.0)
        if self.chi2_thresh and nis > self.chi2_thresh:
            self.miss += 1
            return self.miss < self.max_miss
        self.miss = 0
        return True
```

## 3. 复杂度与正确性

|---|---|---|---|

**正确性定理（STAG-Complete）**：假设 A61–A78（见想法区）。则
1. **时序对齐界**：`Δt ≤ Δt_pred` 时 `E‖ẑ-z‖² = tr(Σ_z) ≤ tr(P_0)+qΔt³/3 ≤ ε_age²`；有效年龄由线性 `vΔt` 降为二次 `½aΔt²`。
2. **空间接地界**：LGI 输出 `K_p = U diag(k_i) Uᵀ`，`k_min ≤ k_i ≤ k_max`；沿 λ_i 大（定位模糊）方向刚度与力上限单调下降，接触冲量受 `F_i` 界约束。
3. **延迟安全性**：EDF 可调度 ⇒ `slack_sem ≥ 0`；不可调度 ⇒ 推理前降级，`slack_rt ≥ 0`，实时流永不阻塞。
4. **随时单调性**：`T ≤ T' ⇒ Q(T) ≤ Q(T')`；早退结果 `q ≥ q_stop`。
5. **最优视界**：`Δt_pred = 2√(v²-σ_ż²)/a_max` 是外推优于零阶保持的充要上界。
6. **向后兼容**：`τ_loc=Σ_p=σ_ż=Δt=0` 时退化为第 61 轮 ESEC。

## 5. 本轮最大风险

**一句话**：若延迟预测器失准或潜空间动力学在接触瞬变（非光滑、速度突变）时外推失控，再叠加视觉定位漂移与协方差低估，就会产生「自信而错误」的时空锚点，使 LGI 在错误方向上变刚/变柔，把安全裕度用反，导致接触失稳甚至过力；必须以「Kalman 新息门控 + 协方差下限 + 可预测视界硬截断 + 主动定位兜底 + ERTC 安全包络」构成时空安全护栏，确保「外推预测」永不凌驾于「实时安全」之上。
