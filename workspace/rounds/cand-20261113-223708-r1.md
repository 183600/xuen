# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多模态融合」×「场景理解」）

> R69 的核心动作是「把不确定性拆成 aleatoric / epistemic，然后去问」。但它从未回答一个更前置的问题：**我到底在对什么不确定？** FLUID-RAS 的隐变量是**动作模态 M**——场景只是经由策略被间接看见。这留下两个结构性问题。
>
> 第一，**投影盲区**：两个截然不同的场景可以投影到同一个动作模态（杯空 / 杯满都 →「移到杯口」），于是 H(M)=0，R69 判定「没有 epistemic 不确定性」，却对真正会改变安全的风险视而不见；反过来，落在任务无关细节上的场景差异又可能凭空制造动作多峰，诱导无谓提问。动作边缘是场景的**商空间**，R69 在这个商空间里做信息论，丢掉了被边缘化的自由度。
>
> 第二，**融合粒度错位**：R69 的模态权重与 ECE 是全局的（MCG 对整组模态权重做校准），但真实的多模态可靠性是**因子局部**的——相机对几何可信、对材质未必；听觉对事件可信、对位置几乎无用；触觉只在接触后可信。全局权重要么过度信任要么过度保守，而全局 ECE 很小可以完全掩盖某条任务关键关系上的严重错校准（Simpson 型聚合）。
>
> 本轮两个灵感正好给出解药：
> - **场景理解**把隐变量从「动作模态」抬升为**任务条件场景图**（实体、属性、关系、可供性），不确定性因此**有位置、有结构**：不是「整体有多糊」，而是「哪条边、哪个节点不确定」；
> - **多模态融合**不再是「把模态向量拼起来 / 加权平均」，而是**在共享场景变量上做因子化推断**（product of experts）——融合的单位是**场景因子**，不是模态。
>
> 核心命题：**先在任务条件场景图上做因子化多模态融合，把不确定性分成 aleatoric / structural-epistemic / ontological 三类；只用「会改变认证安全集或最优动作」的任务敏感度加权 VoI 去定向修边；R69 的 FLUID 退化为「图坍缩为单隐变量」时的边界情形。** 命名 **PRISM-RAS**（Per-factor Relational Inference Scene Modeling for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「**我在理解哪一个场景、哪一条关系错了会让安全集翻面**」——先理解场景，再决定值不值得问。

## 0. 直觉与动机

**灵感 1（多模态融合 → 融合的单位是「场景因子」，不是「模态」）**
直觉：我们习惯把融合想成 f(v, a, t, l) → z：先各模态编码，再拼接 / 注意力 / 加权。这个图像预设了「所有模态都在描述同一个整体」，于是只能学一个全局权重。场景理解给出另一种单位：世界由**实体**与**关系**组成，每个模态只是对其中某些因子提供证据——相机看「杯子在门后」这条遮挡边，触觉看「杯壁摩擦」这个材质节点，语言听「把左边那个给我」这个指代边。真正的融合是**在同一组场景变量上叠加各自的局部势函数**，而不是把模态压成一个向量。**对象 / 关系是融合的天然公分母。** 这一点可检验：早融合 = 单个覆盖全变量的因子；晚融合 / 加权 = 单变量上的若干因子；R69 的模态可靠性路由 = 对因子权重做全局近似。它们都是因子图的特例。因子图不是新模型，而是把已有融合方式放回它们本就属于的坐标系。

**灵感 2（场景理解 → 不确定性有位置，因而可被「定点清除」）**
直觉：R69 的不确定性是一个标量 / 模态集合，处置方式是全局的：要么整体慢下来，要么整体去问。但场景理解让不确定性变成**图上的局部对象**：可能是「门后有没有东西」这条遮挡边，可能是「杯壁是陶瓷还是金属」这个材质节点，可能是「他把'那个'指成哪个」这条指代边。局部性带来两个能力：(a) **定向交互**——只去看那条边、只去摸那个面、只去问那个指代；(b) **定向保守**——只有会改变安全集 / 最优动作的边才值得收紧，其余不确定性可以带着跑。这把 R69 的「不确定 → 全局降速或提问」升级为「**哪条边不确定 → 只修那条边、只在必要时收紧**」。

**灵感 3（投影盲区 → R69 的动作熵是场景不确定性的商，不是全部）**
直觉：策略看到的不是场景，而是场景的一个**投影**：p(a|o)=∫p(a|X)p(X|o)dX。R69 对动作分布聚类得到 H(M)，本质上是对**投影后的商空间**取熵。信息论上 H(π#X) ≤ H(X)，等式只在投影于支撑上单射时成立。危险恰在非单射处：杯空 / 杯满、门半开 / 全开、地面干 / 湿，可能导出同一个「移动到目标」动作模态，动作熵为 0，但二者的安全风险截然不同。**R69 会自信地说「没有歧义」，因为歧义恰好在它取熵之前被策略边缘化掉了。** 这不是精度问题，是观测通道选择错误：信息应该在场景层获取，而不是在动作层获取。

**灵感 4（安全导向 → 只消解「会让安全集翻面」的边，其余歧义允许共存）**
直觉：场景理解不该追求「把世界完全看清」，而该追求「把会影响安全的那些自由度看清」。给定场景图的一个具体取值 X，C-RAS-WM 能认证一个安全动作集 S(X)。一条边 / 节点是**任务关键的**，当且仅当沿着它的后验取值变化会改变 S(X) 或最优动作。对非关键变量，多峰共存无害，甚至该保留（过度消解浪费预算、打扰人、还可能引入新攻击面）。这给出一个比 R69 更锐利的 VoI：VoI_task(g)=Σ_x s_x·I(X_x;Y|g,o)−c(g)，其中 s_x 是「改变安全集 / 最优动作」的概率质量。**不是所有不确定性都值得一分钱。**

**灵感 5（组合性 → 场景理解最大的红利与最大的漏洞是同一件事）**
直觉：场景图是组合的：关系、实体、属性可以重组，因而能泛化到没见过的组合（把「杯子在门后」的知识迁移到「药瓶在抽屉后」）。局部因子让这种泛化有界。但组合性也制造了本轮最大的漏洞：**图是一个封闭假设空间**。一个没被解析成节点的实体、一条没被实例化的关系，根本不在 VoI 的求和里；系统会极其勤勉地消解所有**已命名**的歧义，却对「它从没想过那里可能有东西」保持沉默。这把 R68 / R69 一直回避的「未知未知」推到台前：R69 只会问「A 还是 B」，PRISM 必须额外处理「**是不是连选项都没列全**」。所以本轮必须交付开放世界警报（未解释证据 + 跨模态相干性）、组合覆盖证书，以及一个与「已知歧义」分开计费的探索预算。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PRISM-RAS 总览与四不变式）** PRISM-RAS = (TSG, FUSE-PoE, SGU, STAR, EAG, FCG, OWA, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **交互预算硬约束**（继承 R69 定义 293-ii），且定向交互必须绑定到一个明确的图变量 x；
(iii) **因子级证据纪律**：任一节点 / 边不得由单一模态在关键判据上单独定案，需 ≥2 个正交因子一致（或因子后验置信超过高阈值且 ECE 达标）；
(iv) **保守单调性**：任何门控触发（FCG / OWA / 超时 / 绑定冲突）只能使安全集收缩、λ 不降，绝不因「已理解」而放大安全集。

**定义 311（任务条件场景图 TSG）** G_t = (V, E, X, ρ_τ)。V 为实体节点；E 为关系边；X=(X_V,X_E) 为变量集，节点变量 X_v=(c_v,b_v)（类别 / 身份 + 连续属性：位姿、尺度、材质参数、可供性），边变量 X_e=(r_e,θ_e)（关系类型 + 连续参数：相对位姿、接触点、遮挡比）。任务 τ 给出相关性 ρ_τ: vars→ℝ_{≥0} 与任务支持 supp_τ（由策略 / 风险对变量的敏感度导出）。任务相关子图 G^τ={x:ρ_τ(x)>0}。

**定义 312（因子作用域与绑定变量）** 模态 m 的证据 o_m 通过因子集 Φ_m={φ_{m,c}} 作用，scope(c)⊆X。跨模态绑定变量 A={a_{m,x}}：模态 m 的检测 / 读数分配给图变量 x 的关联。联合推断 p(X,A|o) ∝ p_0(X,A)·Π_mΠ_{c∈Φ_m}φ_{m,c}(X_{scope(c)},A_{·,scope(c)}|o_m)。绑定错误（把对象 A 的触觉记到 B 上）是一类独立故障，不可与属性噪声混同。

**定义 313（FUSE-PoE 因子化融合）** p(X|o)=(1/Z)p_0(X)Π_mΠ_{c∈Φ_m}φ_{m,c}(X_{scope(c)}|o_m)，绑定按定义 312 边缘化或采样。**缺失模态 = 中性因子（φ≡1），不是零证据**；异步模态按时间戳差进入因子。全局模态权重 w_m 是「所有因子共享同一 scope 且 φ_{m,c}=φ_m^{w_m}」的退化特例。

**定义 314（场景不确定性三分）**
- U_ale(x)=E_{p(X|o)}[tr Cov(b_x)]（连续属性、不可约噪声）；
- U_epi=H(S|o)，S=(存在掩码、类别标签、关系类型、绑定) 为离散结构，即可约的结构歧义；
- U_ont = 未解释证据质量：对每个证据区域 / 模态读数，若在任何现有 scope 下的似然都低于阈值，但在跨模态上互相自洽（相干性 > κ），则计入 U_ont。
三者语义不同，**不求和、不同通道**：U_ale→保守 λ floor；U_epi→定向交互；U_ont→开放世界警报 + 探索预算 + 保守兜底。

**定义 315（动作投影与观测商）** π_#: p(a|o)=∫p(a|X)p(X|o)dX。动作模态 M=π_#X。称 PRISM 相对 R69 的**投影盲区**为 H(X) 与 H(π_#X) 的差中、被安全 / 风险敏感度加权后仍非零的部分。R69 的 U_epi 是 H(π_#X) 的函数；PRISM 的 U_epi 是 H(X) 的函数，故可检测被边缘化的结构歧义。

**定义 316（风险敏感度与认证安全集）** 给定 X 与 C-RAS-WM，安全动作集 S(X)⊆𝒜；最优动作 a*(X)=argmin_{a∈S(X)}R(a,X)。变量 x 的风险敏感度
s_x=P_{p(X|o)}(S(X)≠S(X_{\setminus x}) ∨ a*(X)≠a*(X_{\setminus x}))，
其中 X_{\setminus x} 表示对 x 取后验重采样。任务关键集 C_τ={x:s_x>s_0}。

**定义 317（STAR：安全-任务感知的边定向 VoI）** 对信息动作 g（其本身绑定到图变量 x_g，见定义 318），
VoI_task(g)=Σ_{x∈C_τ} s_x·I(X_x;Y|g,o)，Y 为执行 g 后的观测。选择 g*=argmax_g[VoI_task(g)−c(g)]，s.t. 认证（定义 319）、预算、且 x_g∈C_τ。若 max≤0：不交互，走 R69 / R68 兜底。**只有任务关键边进入求和**——这是相对 R69 定义 298 的唯一但关键的改动。

**定义 318（EAG：边定向动作接地）** 每条候选信息动作必须落到一个图变量：
- g_gaze → 绑定到遮挡 / 不可见边（看门后、看桌下）；
- g_probe → 绑定到材质 / 接触 / 摩擦边（摸杯壁、轻推确认）；
- g_ask → 绑定到指代 / 意图 / 偏好边（「是左边这个吗」「你要我放下还是递给你」）。
映射 EAG:(x,p(X|o))→候选 g 集合；候选生成可复用 R69 的 FMP 动作块，但**条件从「动作模式」改为「目标图变量」**。执行后按定义 312 做局部重推断（只更新 x 的马尔可夫毯，不重跑整图）。

**定义 319（信息动作安全与图局部认证）** g 的控制指令过 C-RAS-WM 前缀认证；且要求：注视不得诱发危险转身、探针不得越力 / 位包络、等待不得使任务窗过期、问句不含诱导且不泄露不可逆决策。任一不过 ⇒ g 作废，x 保持未消解。

**定义 320（因子校准门 FCG）** 对每类因子域 c（节点类别、关系类型、连续属性族、绑定）估计局部 ECE_c。门控：∃x∈C_τ: ECE_{type(x)}>τ_fce ⇒ 禁用该域的 VoI 权重，x 走保守兜底；并要求**最坏关键因子 ECE**≤τ_fce（而非全局 ECE）。这直接修补 R69 MCG 的聚合盲区（引理 20）。

**定义 321（开放世界警报 OWA）** 未解释证据 U_ont 超过 τ_ont 且跨模态相干（同一区域在 ≥2 个模态上都有自洽但无 scope 可解释的信号）时触发 OWA。OWA 不是「某个已知变量不确定」，而是「假设空间可能缺项」。处置：收缩安全集、分配独立探索预算 ε_explore（与已知歧义预算分开计费），并允许一次「本体问询」（「这个区域里有我没识别到的东西吗？」）。OWA 的触发 / 未触发本身写入证书。

**定义 322（组合覆盖证书 CBC）** 设关系 / 属性词表与因子局部性成立。定义已认证组合覆盖集 C_cov（训练 / 验证中见到的关系组合及其邻域）。若当前场景的组合 s(G)∉C_cov ⇒ 组合外推，误差界失效，强制保守。CBC=(C_cov, 当前组合距离, 因子局部误差上界, 绑定误差上界)。

**定义 323（两级退避扩展）** 若 C_τ 全部在预算内消解且 FCG / OWA 未触发：λ=λ_floor(U_ale)（resolution bonus，继承 R69 定义 307）；若有任一关键边未消解 / 超时 / 绑定冲突 / FCG 越界：λ=λ_floor(U_ale+U_epi^{crit})；若 OWA 触发：λ=λ_floor(U_ale+U_epi^{crit}+U_ont)，并叠加 R68 最保守前缀。保守侧逐级单调。

**定义 324（证据纪律与预算继承）** 交互频率 / 位移 / 社交成本约束、k 正交证据源一致、单次交互不得定案，全部继承 R69 定义 293-ii/iii；新增**定向性纪律**：任何一次信息动作必须记录其绑定的 x 与预期降低的 I(X_x;Y)，不可「泛泛地多看一眼」。

**定义 325（增量因子图运行时）** 常态只维护任务相关子图 G^τ（规模 ≤N_τ），局部 BP / 束搜索；交互只更新目标 x 的马尔可夫毯；结构大改（新增 / 删除节点、OWA）触发一次全图重推断，并标记为一次性预算事件。

**定义 326（证书 J_PRISM）** J_PRISM=(J_FLUID, factor_ece_worst, critical_edge_coverage, U_ont, owa_triggered, binding_conflict_rate, cbc_distance, prism_ver)。Valid ⇔ Valid(J_FLUID) ∧ 关键因子 ECE≤τ_fce ∧ 关键边覆盖满足 ∧ 组合覆盖成立或已保守降级。

## 2. 关键算法骨架

```python
# IP-264/265 TSG + FUSE-PoE：任务相关子图 + 因子化多模态融合
class SceneGraphFusion:
    def infer(self, o, task):
        G = init_graph(entity_proposals(o), priors=self.prior)  # 节点/边/绑定先验
        G = self.relevance_prune(G, task)                       # 只留任务相关子图 G^τ
        for m, o_m in o.by_modality():
            for phi in self.factors[m]:                         # scope-aware 局部势
                G = phi.apply(G, o_m)                           # 缺失模态=中性因子
        return self.bp.infer(G)                                 # p(X,A|o)，绑定已边缘化

# IP-266 SGU：三分不确定性（aleatoric / structural-epistemic / ontological）
def decompose_scene(pX, G, o):
    U_ale = {x: attr_var(pX, x) for x in G.vars()}              # 节点/边内连续噪声
    U_epi = entropy(pX.structure)                              # 存在/类别/关系/绑定
    U_ont = unexplained_mass(o, pX, G)                          # 无 scope 可解释但相干
    crit = {x for x in G.vars() if risk_sensitivity(x, pX, G) > S0}
    return U_ale, U_epi, U_ont, crit

# IP-267/268 STAR + EAG：任务敏感度加权、边定向的交互选择
def choose_edge_interaction(pX, G, crit, budget):
    best = None
    for x in crit:                                             # 只对会改变安全集的变量花预算
        if not budget.allow(x):                    continue
        for g in ground_info_actions(x, pX):                    # 看遮挡/触材质/问指代
            if not c_ras_wm.certify_info(g, G):    continue
            score = risk_sensitivity(x, pX, G) * IG(x, g, pX) - cost(g)
            if best is None or score > best.score: best = (x, g, score)
    return best if best and best.score > 0 else None           # 无利可图 → R69/R68

# IP-269/270 FCG + OWA：因子级校准门 + 开放世界警报
def gates(pX, G, calib):
    bad = [x for x in G.critical_vars()
           if calib.factor_ece(x) > TAU_FCE]                   # 全局 ECE 小也可能漏掉它
    if bad: return Gate(fallback='R68', why=('factor_ece', bad))
    if unexplained_mass > TAU_ONT and cross_modal_coherent:
        return Gate(fallback='conservative+explore', why='open_world')
    return Gate(fallback=None)

# IP-276 主闭环：在 R69 的交互层之下插入“场景图层”
def PRISM_RAS_round(M, obs, task):
    z, o = M.mtm.forward(obs)
    c, U_cal, _ = M.cof.step(...)                              # R68 标定（保留）
    G, pX = M.fuse.infer(o, task)                              # 1) 因子化场景理解
    U_ale, U_epi, U_ont, crit = M.sgu.decompose(pX, G, o)
    gate = M.gates(pX, G, M.calib)                             # 2) 因子校准/开放世界门
    if gate.fallback:                                          # 不可信/缺项 → 保守+探索
        return conservative_rollout(M, gate, U_ale, U_epi, U_ont)
    x, g, _ = M.star.choose_edge_interaction(pX, G, crit, M.budget)
    if g is not None:                                          # 3) 只修任务关键边
        y = M.eag.execute(g)                                   # 看/触/问，过 C-RAS-WM
        pX = M.fuse.update_local(pX, x, y)                     # 只更新马尔可夫毯
        U_epi = M.sgu.structure_entropy(pX)
    # 4) 动作投影：R69 的流策略在“已认证图”上做最后的细粒度消歧
    p_a = project_policy(pX, M.fmp)                            # π# p(X|o)
    return M.fluid.round_with(p_a, U_ale, U_epi, U_ont)        # 退化边界=R69
```

## 3. 推导

**引理 19（投影盲区）** 存在场景对 X_1≠X_2 与策略 π，使 π_#p(X_1|o)=π_#p(X_2|o)（动作分布相同），但 R(a*,X_1)≠R(a*,X_2) 且 S(X_1)≠S(X_2)。此时 R69 的 H(M)=0、U_epi=0，判定「无歧义、无需交互」；PRISM 的 H(S|o)>0 且存在 s_x>0，判定「关键边未消解」。证明：构造杯空 / 杯满（动作「移到杯口」相同，洒出风险与安全集不同），令 π 对二者输出同一动作块。要点：**信息必须在投影前获取，投影后再取熵会漏掉被边缘化的安全自由度。** 系：R69 的 U_epi 是 H(π_#X) 的函数，故对场景层风险不是充分统计量。

**引理 20（因子校准的聚合盲区）** 设因子域分为大而准的 A 与小而任务关键的 B。全局 ECE=w_A ECE_A+w_B ECE_B。当 w_B 小，全局 ECE 可 <τ，而 ECE_B≫τ_fce。构造 B 为任务关键边（如「门是否锁住」），则 R69 MCG 放行，PRISM FCG 拦截。证明：加权平均；关键性由 s_x 选择而非样本频率选择，故「频率小但关键」正是全局门控的系统盲点。系：校准门必须按**关键性加权的最坏因子**，不能按样本频率加权。

**引理 21（任务加权 VoI 的效率）** 在因子近似独立、互信息自适应子模下，对 C_τ 做贪心边定向选择达到 (1−1/e) 近似最优；且对任意非关键变量 x∉C_τ，s_x=0，故其 I(X_x;Y) 对目标函数无贡献。于是相同预算下，PRISM 的目标风险下降 ≥ R69 的全动作模式 VoI（后者把预算按动作熵隐式分配）。证明：一阶条件 + 自适应子模的贪心界；非关键项系数为零。要点：**不是「问得更多」，而是「把同一份预算问在会改变安全的地方」。**

**引理 22（组合覆盖误差界）** 若每个因子在其 scope 上的误差 ≤ε_c、绑定误差 ≤ε_b，且当前组合落在 C_cov 的 ε-邻域，则场景图后验的任务风险误差 ≤Σ_{c∈supp_τ}ε_c+|E_τ|ε_b（并集界）；若组合距离超出 C_cov，界不成立，必须由 OWA / CBC 降级。证明：局部性 + 并集界；组合外推时出现训练中未见的因子交互项，界失效。系：**组合泛化的安全保证只在覆盖集内成立**，覆盖集外的「自信」没有证书。

**定理 18（PRISM 对 FLUID 的严格细化）** 在 A99（因子局部校准）、A100（绑定可观测或已门控）、A101（组合覆盖成立）下，PRISM 的期望任务风险 ≤ FLUID；且当场景图退化为单变量（无结构、无绑定、单 scope）且 s_x 均匀时，两者逐指令相同。证明思路：把 FLUID 的模态证据视为单 scope 因子、动作模态视为 π_#X 的聚类；PRISM 在非单射投影处多检测到被边缘化的结构歧义（引理 19），在非均匀敏感度处把预算移到关键边（引理 21），退化情形二者一致。**FLUID 是 PRISM 在「图坍缩」边界上的投影。**

**定理 19（定向交互安全与无突变）** 信息动作 g 经 C-RAS-WM 认证且绑定到 x∈C_τ 后，其物理风险 ≤ε_int；局部重推断只改变 x 的马尔可夫毯内的后验，不改变安全包络；失败 / 超时 / 绑定冲突 / FCG / OWA 触发时 λ 单调不降地退化为 R69 / R68；R68 定理 15 的提交 / 换装不变式保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：PRISM 把「不知道」变成了图上的一个空位——**凡是没被解析成节点的东西，VoI 永远不会去查它**；于是系统会极其勤勉地消解所有已知歧义，却对一个从未进入假设空间的危险保持沉默，而开放世界警报只是启发式，无法把这种沉默变成可验证的安全保证。

```python
# IP-264/265 TSG + FUSE-PoE
def infer_scene(o, task):
    G = init_graph(entity_proposals(o), priors=prior)   # 节点/边/绑定先验
    G = relevance_prune(G, task)                        # 只留任务相关子图 G^τ
    for m, o_m in o.by_modality():
        for phi in factors[m]:
            G = phi.apply(G, o_m)                       # scope-aware；缺失=中性因子
    return bp_infer(G)                                  # p(X,A|o)

# IP-266 SGU：三分不确定性
def decompose_scene(pX, G, o):
    U_ale = {x: attr_var(pX, x) for x in G.vars()}
    U_epi = entropy(pX.structure)                       # 存在/类别/关系/绑定
    U_ont = unexplained_mass(o, pX, G)                  # 无 scope 可解释但相干
    crit  = {x for x in G.vars() if risk_sensitivity(x, pX, G) > S0}
    return U_ale, U_epi, U_ont, crit

# IP-267/268 STAR + EAG
def choose_edge_interaction(pX, G, crit, budget):
    best = None
    for x in crit:
        if not budget.allow(x): continue
        for g in ground_info_actions(x, pX):            # 看遮挡/触材质/问指代
            if not c_ras_wm.certify_info(g, G): continue
            score = risk_sensitivity(x, pX, G)*IG(x, g, pX) - cost(g)
            if best is None or score > best.score: best = (x, g, score)
    return best if best and best.score > 0 else None    # 无利可图 → R69/R68

# IP-269/270 FCG + OWA
def gates(pX, G, calib):
    bad = [x for x in G.critical_vars() if calib.factor_ece(x) > TAU_FCE]
    if bad: return Gate(fallback='R68', why=('factor_ece', bad))
    if unexplained_mass > TAU_ONT and cross_modal_coherent:
        return Gate(fallback='conservative+explore', why='open_world')
    return Gate(fallback=None)

# IP-276 主闭环
def PRISM_RAS_round(M, obs, task):

    G, pX = M.fuse.infer_scene(o, task)                 # 1) 因子化场景理解

    gate = M.gates(pX, G, M.calib)                      # 2) 校准/开放世界门

```

## 4. 推导

**引理 19（投影盲区）** 存在 X_1≠X_2 使 `π_#p(X_1|o)=π_#p(X_2|o)`，但 `R(a*,X_1)≠R(a*,X_2)` 且 `S(X_1)≠S(X_2)`。此时 R69 的 `H(M)=0` 判定无歧义，PRISM 的 `H(S|o)>0` 且 `s_x>0` 判定关键边未消解。构造：杯空/杯满→同一“移到杯口”动作，安全风险不同。系：信息必须在投影前获取。

**引理 20（因子校准的聚合盲区）** 全局 `ECE=w_A ECE_A+w_B ECE_B`；当关键因子 B 的样本频率 `w_B` 小，全局 ECE 可低于阈值而 `ECE_B≫τ_fce`。故校准门必须按关键性加权取最坏因子，不能按样本频率加权。

**引理 21（任务加权 VoI 的效率）** 因子近似独立、互信息自适应子模下，对 `C_τ` 贪心边定向选择达 `(1−1/e)` 近似最优；非关键变量 `s_x=0` 不贡献目标。相同预算下，PRISM 的目标风险下降 ≥ R69 的全动作模式 VoI。

**引理 22（组合覆盖误差界）** 因子局部误差 `ε_c`、绑定误差 `ε_b` 下，覆盖集内任务风险误差 `≤Σ_{c∈supp_τ}ε_c+|E_τ|ε_b`（并集界）；组合距离超出 `C_cov` 时界失效，必须 OWA/CBC 降级。

**定理 18（PRISM 对 FLUID 的严格细化）** 在 A99（因子局部校准）、A100（绑定可观测/门控）、A101（组合覆盖成立）下，PRISM 期望任务风险 ≤ FLUID；当图退化为单变量且 `s_x` 均匀时逐指令相同。FLUID 是 PRISM 在“图坍缩”边界上的投影。

**定理 19（定向交互安全与无突变）** g 经 C-RAS-WM 认证且绑定 `x∈C_τ` 后物理风险 `≤ε_int`；局部重推断只改马尔可夫毯；失败/超时/绑定冲突/FCG/OWA 时 λ 单调不降退化 R69/R68；R68 定理 15 的提交/换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：PRISM 把「不知道」变成了图上的一个空位——**凡是没被解析成节点的东西，VoI 永远不会去查它**；系统会极其勤勉地消解所有已知歧义，却对一个从未进入假设空间的危险保持沉默，而 OWA 只是启发式，无法把这种沉默变成可验证的安全保证。

**次级风险与缓解**：场景图解析错误（因子局部 ECE + 结构校验）；绑定配错（定义 312 + E310）；全局校准盲区（FCG 取关键性加权最坏因子）；组合外推失效（CBC + 强制保守）；实时预算被因子图击穿（任务相关子图 + 局部重推断 + 图坍缩快路径）。
