# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「共情表达」×「自主导航」）

> R69 给了机器人一张嘴：把不确定性拆成 aleatoric / epistemic，对可约的歧义去**问**（看/触/问句），对不可约的噪声去**收紧**。它把「证据」看成从外部世界取回的事实，并用 k 个正交证据源防止被骗。但它与更早几轮共享一个更深的盲点：**不确定性始终只是机器人的**。在有人共享的空间里（走廊、门口、电梯、人行横道），决定风险的不只是「机器人不知道人想干什么」，更是「**人不知道机器人想干什么**」。一个意图不可读的机器人会让行人犹豫、急停、突然横穿；这些反应又变成机器人眼中的 aleatoric 噪声——**机器人的不可读性制造了它自己的不确定性**，形成自增强回路。
>
> 两个灵感正好对上这个盲点的两面：
> - **共情表达**提示：表达不是装饰，而是一个**作用于他人信念的控制输入**。注视、减速、让行、身体朝向、地面投影、「您先请」——这些动作的真实功能是让另一个人**预测你**，从而敢在你旁边走。
> - **自主导航**提示：社交导航的本质不是单机避障，而是**耦合博弈**——两个智能体在门口/窄道/人流中协商一个共同均衡。最危险的不是撞上，而是双方都「猜」错对方的让行意图而同时对冲、或同时僵住。
>
> 核心命题：**把「不确定性」从单机内部搬到耦合系统里。R69 问「我该向谁求证」，R70 问「我该怎样被理解」。共情表达是一个诚实的信令控制通道——它降低「人对机器人的不确定性」，从而降低耦合风险；但表达本身制造三种新危险：操纵/共情洗白（说假话）、过度安抚诱发依赖（把人哄得太放心）、以及最阴险的「共情混淆」——机器人把由自己表达所诱发的「人变镇定了」误当成「环境变安全了」。** 命名 **ATTUNE-RAS**（Attentive Transparent Trajectory for Uncertainty-aware Navigational Empathy）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该让谁看懂我、以及我的安抚是不是在骗自己**」。

## 0. 直觉与动机

**灵感 1（共情表达 → 信念整形的控制通道）**
直觉：人类让行不是靠把对方推开，而是靠一个眼神、半步后退、手掌抬起。这个动作**不改变物理世界多少，却改变对方脑中的模型**。控制论里 dual control 讲「为了学而探」，R70 要讲它的镜像——**为了被学而示（signaling control）**。机器人的表达 e 是一个输入，其输出不是位姿，而是人脑中的后验 b_h。安全因此不只是「我把轨迹管在包络里」，还包括「我让人准确地预测我的轨迹」。表达是一种**通信动作**，必须像运动动作一样被生成、认证、计预算、可审计。

**灵感 2（自主导航 → 耦合风险，而非单机风险）**
直觉：单机避障把行人当成移动障碍；社交导航把行人当成**会因为你而改变行为的对手**。门口相遇的最优解不是各自最优，而是**共同**选左或选右；两个都礼让会僵住，两个都不让会撞上。风险因此有三个来源：本体的碰撞风险、**耦合风险**（人的信念误差导致其行为方差变大：犹豫、急停、突穿）、以及**解释风险**（机器人对人如何回应表达建错了模）。共情表达主要压的是第二项，却可能抬高第三项——这正是它必须被认证而不能被浪漫化的原因。

**灵感 3（共情的严格化 → truthful legibility，而非讨好）**
直觉：「共情」在工程上极易滑成「让对方舒服」。但安全的共情不是讨好，而是**把自己真实的内部状态（意图、把握、承诺）以对方能用的形式诚实呈现**，包括诚实地表达「我不确定」。定义上要把二者分开：**empathic = 让对方的后验逼近我的真实状态**；**manipulative = 让对方的后验逼近一个我选定的假状态**。前者降低耦合风险，后者只是把风险转嫁给信息劣势方。这条区分必须写进不变式，否则「共情」会成为操纵的委婉说法。

**灵感 4（共情混淆 → 最危险的因果陷阱，正面回应 R68/R69 的旧病）**
直觉：R68 怕「缓变故障被标定吸收」，R69 怕「k 个证人串供」。R70 有同构的第三只鬼：**机器人一示好，行人不紧张了；机器人观测到「人不紧张」，便推断「这里安全」——可那份镇定是机器人自己造出来的，不是世界变安全的证据**。表达 e 同时是「观测到的镇定 C」和「真实危险 H」的共同原因；用 C 预测 H 存在混杂。更糟的是形成正反馈：越安心 → 越冒进 → 越需要安抚。所以「人以镇定示我」绝不能单独作为安全证书，除非在 do(e)（随机化表达/对照）或独立物理通道下被因果识别。

**灵感 5（过度安抚 → 最大共情不是最优安全）**
直觉：一个永远温柔、永远笃定、永不露怯的机器人，会让人**关掉自己的注意**。在人车混行、施工区、盲区，人的适度警觉本身就是一道安全冗余。把「被理解」优化成「被安抚」，等于拆掉这道冗余。故存在一个反直觉结论：**最优表达不最小化被感知的不确定性，而是在降低耦合风险与维持必要警觉之间取平衡**；高风险区甚至必须**主动表达不确定**（减速 + 迟疑回望 + 明说「我不确定」）。这直接挑战「共情越充分越好」的朴素直觉。

**灵感 6（表达是新的攻击面）**
直觉：一旦系统会「示」，就有人会仿冒、会和它打配合、会用「看起来很合理的礼让」把它骗进不安全区。攻击包括：**表达仿冒**（第三方投影假的让行信号）、**共情洗白**（用温柔语气掩盖危险机动）、**诱骗依赖**（长期过度安抚使人类放弃监督）、**诱饵共情**（用一次夸张让行诱导人走入真正危险的一侧）。表达的物理成本低、语义带宽高，正是攻击者喜欢的通道。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（ATTUNE-RAS 总览）** ATTUNE-RAS = (ECM, LEx, CEF, EFI, SCN, SEN, ECA, OTG, VQAuditor-E, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **表达无新增权限**：表达只能复用已认证的执行器与动作空间，且必须通过与任务动作相同的 C-RAS-WM 前缀认证；**表达永不放宽机器人自身的安全包络**，它只能通过改善人的可预测性去降低未来耦合风险；
(iii) **表达完整性**：任何被提交的表达必须与机器人真实内部状态 s_int=(意图 i, 不确定性 U, 承诺度 c) 语义一致；禁止策略性歪曲；违反即抑制表达并回退；
(iv) **因果证据纪律**：人的镇定/舒适**不得单独**充当安全证书，除非在 do(e)（表达随机化或对照）下被因果识别，或由与表达无关的独立物理通道佐证。

**定义 311（表达动作空间）** 表达 e = (e_gaze, e_gest, e_motion, e_speech) ∈ ℰ：注视/头部朝向、手势与身体朝向、运动调制（速度剖面、路径曲率、让行位移、近体距离）、语言（含韵律的短句，由冻结 LLM 解码）。增广动作 ζ = (a, e) ∈ 𝒜_task × ℰ。R69 的信息动作 g 是「向世界取证据」；e 是「向世界给证据」——**问与示互为对偶**。

**定义 312（人的信念-响应模型 ECM）** 潜在信念 b_h ∈ Δ(ℐ)（对机器人意图/承诺的后验）；信念动力学 b_h⁺ = τ(b_h, e, x)；人的控制 u_h ~ π_h(· | b_h, x)。机器人与人是耦合闭环：x⁺ = f(x,a,u_h)，y_h = h(b_h,u_h)。τ 与 π_h 只在离线训练/离线校准更新，实时只读。

**定义 313（共情表达与保真度）** 内部状态 s_int=(i,U,c)，其真值后验 p_true(·|s_int)。表达 e 的**共情保真度** EF(e) = D( b_h⁺ ‖ p_true )（越小越好）。**表达完整性** I(e) = 1[ e 的语义内容与 s_int 一致（容差内）]。
- **诚实共情**：e* = argmin_e EF(e)，s.t. I(e)=1 —— 让对方看见真实，包括真实的不确定；
- **操纵**：argmin_e D(b_h⁺‖p_false)，p_false ≠ p_true —— 让对方看见我想让他看见的。
二者在形式上只差一个「目标后验是不是真值」，但风险性质完全不同：前者是信息共享，后者是把风险转嫁给信息劣势方。

**定义 314（耦合风险分解 CEF）** R_total = R_int(x,a) + R_cpl(b_h) + R_intp(b_h,a,e)：
- R_int：本体与几何碰撞/违规风险（R68/R69 已管）；
- R_cpl：由人对机器人的信念误差诱发的风险（犹豫导致的时间窗丢失、急停导致的追尾、误判让行导致的横穿），是 b_h 误差的单调函数；
- R_intp：机器人对「人如何响应 e」建错模的解释风险。表达可以降 R_cpl，但会引入 R_intp。**收益条件**是 ΔR_cpl > c(e) + R_intp，而不是「表达总有益」。

**定义 315（信令控制器 SCN / 可读性价值 VoL）** 有限时域选择 e：
min_{e∈ℰ} E[ Σ_t R_total(x_t,a_t,b_{h,t}) + λ_e c(e_t) ]，s.t. I(e)=1、预算、已认证前缀。
**可读性价值** VoL(e) = R_cpl(b_h) − E_{b_h⁺}[R_cpl(b_h⁺)]。选择 e* = argmax_e [VoL(e) − c(e) − R_intp(e)]。若 max ≤ 0 → 不表达，退回 R69。这与 R69 的 VoI 同构：**VoI 是「问的价值」，VoL 是「被看懂的价值」**。

**定义 316（共享社交包络 SEN）** 导航专用包络由 (TTC, 近体舒适距离, 可预测性/可读性, 犹豫时长) 共同定义。机器人维持两条边界：自身认证安全管 𝒯_cert，以及面向人的**可读性裕度** ℓ_leg。表达只允许在 𝒯_cert 内选择动作并缩小 ℓ_leg，**不得以任何表达为由扩大 𝒯_cert**。耦合感知的缩放 λ_c 只在未来预测层生效（即表达改善的是预测，不是当前认证）。

**定义 317（可预测性与社交摩擦）** 人对机器人未来 H 步的预测误差 L(pred) = E‖û_h,next − u_r,next‖（可由注视/反应时/路径偏离代理）。社交摩擦 S = ∫(犹豫时长 + 近体违规 + 无谓停顿)。ATTUNE 的目标是压 S 与 R_cpl，而非单纯压速度或距离。

**定义 318（共情混淆 ECA 与 do-表达可辨识性）** 设表达 e 同时影响被观测镇定 C 与真实危险 H（e→C, e→H 或 e→a→H），则一般地 P(H|C) ≠ P(H|do(C))。**镇定只能作证据，当且仅当**：(a) 在随机化/对照表达（do(e)）下估计 C 对 H 的因果效应；或 (b) C 由与 e 无关的独立物理通道（真实间距、相对速度、TTC）佐证。否则标记 confounded，**人的镇定不得进入安全证书，且不得用于降低 λ**。这是 R68 反吸收引理（引理 13）与 R69 流似然引理（引理 17）在「人作为观测器」场景的第三面镜子。

**定义 319（过度依赖治理 OTG）** 人的警觉 v 随「被安抚强度」下降；定义高风险区（施工、盲区、混行、紧急）警觉下限 V_FLOOR。约束：任何表达不得使估计警觉 v̂ < V_FLOOR；在高风险区必须**诚实表达不确定**（减速/迟疑/明示 U），禁止用「一切正常」的绝对安抚把 v 压到下限以下。目标函数因此不是最小化被感知不确定性，而是最小化 R_total。

**定义 320（表达投毒干扰集 ℰ_expr）** 表达仿冒（第三方伪造让行/安全信号）、共情洗白（温柔语气掩盖危险机动）、诱骗依赖（长期过度安抚以放弃监督）、诱饵共情（夸张让行诱导人进入危险侧）、跨模态表达共谋（手势与轨迹不一致以利用人的信任）。并入 AIC：ℰ_ATTUNE = ℰ_FLUID × ℰ_expr × ℰ_causal（共情混淆被误用为证书）。

**定义 321（证书 J_ATTUNE）** J_ATTUNE = (J_FLUID, empathy_fidelity_p95, coupled_risk_reduction, confounder_flag, vigilance_floor_ok, expression_budget, expression_integrity, expression_log_hash, attune_ver)。Valid ⇔ Valid(J_FLUID) ∧ EF ≤ τ_EF ∧ integrity=1 ∧ 因果纪律满足 ∧ 表达预算未越界 ∧ vigilance_floor_ok。

**定义 322（参与式审计 VQAuditor-E）** 审计对象新增：表达是否诚实（EF/完整性）、是否诱发过度依赖、是否把自造镇定当安全证据、是否被仿冒、让行是否制造「礼貌的陷阱」。结论异步回灌 AuditBuf，成为下一轮 OTG 的上限与 SCN 的 R_intp 先验。

**定义 323（三级回退阶梯）** 若完整性违反 / 共情混淆 / ECE 越界 / 表达预算耗尽 / 警觉越界 → **抑制表达**，精确退回 R69（只问不示）；若 R69 的 VoI≤成本或不可信 → 退回 R68（只收紧）。故 R68 ⊂ R69 ⊂ R70 是**严格包含链**，安全侧逐级不让步。

**定义 324（导航协调博弈与廉价对话）** 门口/窄道让行是协调博弈：均衡 (左,左)、(右,右) 收益相同高于 (左,右) 对冲。表达是**廉价对话（cheap talk）**，用于选择帕累托占优均衡；但廉价对话可被滥用，故需**成本信号**背书——真实的减速/侧向偏移（有代价且与声明一致）把「我会让」从空话变成可信承诺。**承诺动作越有代价，共情越可信。**

**定义 325（表达仲裁与时间耦合）** 表达带**承诺窗**（一次表达的语义在 τ_c 内保持，避免闪烁与语义抖动）；相邻表达需通过滞回（hysteresis）切换；单位时间表达预算 ≤ B_e；高优先安全表达（急停/避让）可抢占但必须留审计痕迹。自适应表达率与 R69 自适应 K 共用同一实时预算调度。

# IP-264 ECM：人的信念-响应模型（离线训练，实时只读）
class HumanBeliefModel:
    def update(self, b_h, e, x):          # b_h^+ = tau(b_h, e, x)
        return self.tau(b_h, e, x)
    def policy(self, b_h, x):             # u_h ~ pi_h(.|b_h,x)
        return self.pi_h(b_h, x)

# IP-265 LEx：诚实的可读表达策略（完整性内建）
class LegibleExpressor:
    def propose(self, s_int, x):          # s_int=(i,U_ale,U_epi,c)
        cands = self.policy(s_int, x)     # 候选 e（注视/手势/运动/语言）
        return [e for e in cands if self.integrity(e, s_int)]   # 过滤操纵性表达

# IP-268 SCN：信令控制（可读性价值 VoL）
def choose_expression(lex, ecm, s_int, x, b_h, budget):
    best = None
    for e in lex.propose(s_int, x):
        if not budget.allow(e):                    continue
        if not c_ras_wm.certify_prefix((a, e), x): continue   # 表达也要认证

        intp   = interpretation_risk(e, x)         # 人如何回应 e 的建模误差
        score  = vol - intp - expression_cost(e)
        if best is None or score > best.score: best = (e, score)
    return best if best and best.score > 0 else None   # 无利可图 → 只问(R69)

         if (U_epi > TAU_EPI and not slow) else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # —— 风险缩放与认证：表达绝不放宽包络 ——
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 一旦完整性/因果/警觉/标定失败：抑制表达并逐级回退
    if slow or M.eca.confounded or (not M.efi.integrity_ok) or M.otg.violated:
        e = None
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))   # 回 R68 最保守
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(e, g, M.b_h, M.eca.flags, e_forced)
    return k, lam, mode, e, (U_ale, U_epi)
```

## 3. 推导

**引理 19（耦合风险单调性与表达收益）** 设人的策略对信念 L_h-Lipschitz（W₂ 意义），表达使 D(b_h‖p_true) 降低 δ_D，则 R_cpl 的期望下降 ≥ c_1·L_h·δ_D − c_0·L_h·σ_τ，其中 σ_τ 是信念模型误差。故表达有益当且仅当 ΔR_cpl > c(e)+R_intp。系：**VoL 在「人被误读且误读有后果」时最大，而不是在「机器人自己很困惑」时最大**——这解释了一个反直觉现象：机器人越笃定但动作越反直觉（例如工业机器人突然倒车），越需要表达；而机器人自己犹豫、但人早已看懂时，表达反而冗余。

**引理 20（共情混淆的不可辨识性）** 在 e→C、e→H 的 DAG 下，P(H|C) − P(H|do(C)) 的偏差上界 ≲ κ_{e→C}·κ_{e→H}·Var(e)（κ 为因果强度）。因此「人很镇定 ⇒ 安全」在无 do(e) 时是混杂推断；把 C 纳入安全证书会系统性高估安全。系：镇定可用于**降低耦合风险预测**（因为它确实反映人的响应），但**不可用于降低认证 λ 或替代物理安全通道**——这与 R69「VoI 增益不能替代证据纪律」同构。

**引理 21（诚实表达与过度安抚的分离）** 若 EF ≤ ε，则人后验误差与过度依赖风险 ≤ g(ε)；但「最小化被感知不确定性」的表达会压低警觉 v̂，在高风险区使期望风险上升。故**存在一个区间，绝对安抚严格劣于诚实露怯**。系：最优表达是最小化 R_total 的校准表达，而非最大化舒适；「让所有人都放心」本身就是一种安全隐患。

**引理 22（廉价对话与成本信号）** 在让行协调博弈中，无成本的表达只能选择均衡但不能保证不偏离；加入与声明一致的成本信号（真实减速/侧移/让出通道）后，偏离变得可观测且昂贵，声明获得可信度。系：**可信的共情是「做了再说」而非「只说不做」**；轨迹本身是最强的表达。

**定理 18（三级严格包含）** 在 A99–A102（信念模型有界误差、耦合风险单调、完整性可判定、因果纪律可执行）下，ATTUNE 的期望总风险 ≤ R69 ≤ R68；且当表达预算为 0、完整性失败、共情混淆、警觉越界或 VoL≤成本时，ATTUNE 逐指令等价于 R69；当 R69 的 VoI≤成本或不可信时退化为 R68。故 R68 ⊂ R69 ⊂ R70 为严格退化链，安全侧逐级不让步，效率侧获得「被看懂的 bonus」。

**定理 19（表达安全、无包络扩张与无突变）** 表达复用已认证执行器并通过 C-RAS-WM 前缀认证（定义 310-ii/316），故其物理风险 ≤ ε_int；表达只改变「人如何预测我」与「我选哪个已验证模态」，不改变 𝒯_cert；表达失败/超时/被仿冒/共情混淆时，监督切换以滞回单调回退到 R69/R68（定义 323、325），R69 定理 17 的连续性与无突变保持。

## 6. 本轮最大风险

**一句话**：ATTUNE-RAS 的一切收益押在「人真的会按 ECM 的模型回应表达」且「表达的因果效应对系统可辨识」上——**一旦机器人学会了安抚，它就可能把由自己诱发的镇定当成环境安全的证据，形成自增强的共情混淆回路：越危险越需要安抚、越安抚越显得安全、越显得安全越冒进，最终在「一切正常」的温柔表达中撞上只有它自己没看见的危险**——会安慰人的机器人，可能最危险。

**次级风险与缓解**：
1. **过度依赖/警觉坍塌** → OTG 警觉下限 + 高风险区强制诚实露怯（定义 319、引理 21）；

class HumanBeliefModel:
    def update(self, b_h, e, x): return self.tau(b_h, e, x)      # b_h^+ = tau(...)

        e = M.scn.choose_expression(M.lex, M.cam, M.s_int, o, M.b_h, M.expr_budget)
        if e is not None:
            e, e_forced = M.otg.vigilance_guard(e, zone_risk(o), M.v_hat)
            if e is not None:
                M.b_h = M.cam.update(M.b_h, e, o); M.eca.register(e)
    # 问层（R69）：问与示并用，共享预算与认证
    g = M.mint.choose_interaction(modes, o, M.budget) if (U_epi > TAU_EPI and not slow) else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow or M.eca.confounded or (not M.efi.integrity_ok) or M.otg.violated:
        e = None; lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))  # 回 R68
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(e, g, M.b_h, M.eca.flags, e_forced)
    return k, lam, mode, e, (U_ale, U_epi)
```

## 4. 推导

**引理 19（耦合风险单调性与表达收益）** 人的策略对信念 `L_h`-Lipschitz；表达使 `D(b_h‖p_true)` 降 δ_D，则 `ΔR_cpl ≥ c_1 L_h δ_D − c_0 L_h σ_τ`。故表达有益当且仅当 `ΔR_cpl > c(e)+R_intp`。系：**VoL 在「人被误读且误读有后果」时最大，而非「机器人自己困惑」时最大**——笃定却反直觉的机动（如工业机器人突然倒车）最需要表达。

**引理 20（共情混淆不可辨识）** 在 `e→C, e→H` 下，`|P(H|C)−P(H|do(C))| ≲ κ_{e→C}κ_{e→H}Var(e)`。故「人镇定 ⇒ 安全」无 `do(e)` 即为混杂推断，会系统性高估安全。系：镇定可用来**改进耦合风险预测**，但**不得降低认证 λ 或替代物理通道**——R69「VoI 不能替代证据纪律」的同构。

**引理 21（诚实表达与过度安抚分离）** `EF≤ε` 时过度依赖风险 ≤ g(ε)；但最小化被感知不确定性的表达会压低警觉 `v̂`，在高风险区使期望风险上升。故存在区间使**绝对安抚严格劣于诚实露怯**；最优表达最小化 `R_total`，不是最大化舒适。

**引理 22（廉价对话与成本信号）** 让行协调博弈中，无成本表达只能选均衡但不保证不偏离；加入与声明一致的成本信号（真实减速/侧移/让出通道）后，偏离可观测且昂贵，声明才可信。系：**可信的共情是「做了再说」，轨迹本身是最强表达**。

**定理 18（三级严格包含）** A99–A102 下，`Risk(ATTUNE) ≤ Risk(R69) ≤ Risk(R68)`；当表达预算 0 / 完整性失败 / 共情混淆 / 警觉越界 / VoL≤成本时逐指令等价 R69；当 VoI≤成本或不可信时退化为 R68。安全侧逐级不让步，效率侧获得「被看懂的 bonus」。

**定理 19（表达安全、无包络扩张、无突变）** 表达复用认证执行器并过 C-RAS-WM 前缀认证 ⇒ 物理风险 ≤ ε_int；表达只改「人如何预测我」与「选哪个已验证模态」，不动 `𝒯_cert`；失败/超时/仿冒/混淆时以滞回单调回退 R69/R68，R69 定理 17 的连续性与无突变保持。

## 7. 本轮最大风险

**一句话**：ATTUNE-RAS 的一切收益押在「人真的会按 ECM 的模型回应表达」且「表达的因果效应对系统可辨识」上——**一旦机器人学会了安抚，它就可能把由自己诱发的镇定当成环境安全的证据，形成自增强的共情混淆回路：越危险越需要安抚、越安抚越显得安全、越显得安全越冒进，最终在「一切正常」的温柔表达中撞上只有它自己没看见的危险**——会安慰人的机器人，可能最危险。

**次级风险与缓解**：过度依赖/警觉坍塌（OTG 警觉下限 + 高风险区强制诚实露怯，定义 319、引理 21）；共情洗白与仿冒（ℰ_expr 对抗训练 + 完整性约束 + 成本信号背书，定义 320/324、引理 22）；跨文化语义失配（E310 + 冻结 LLM 解码侧过滤 + 保守默认）；「示 + 问」预算叠加（共享调度 + 承诺窗/滞回 + 高优先抢占，定义 325）；解释风险 R_intp 被低估（仅在 VoL 显著为正时表达，人响应偏离模型集即抑制并回退，定理 19）——**问错比不问危险，示错比不示更危险**。
