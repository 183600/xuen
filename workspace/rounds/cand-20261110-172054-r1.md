# 第 44 轮（新循环第 4 轮） · Demo-Cert × Explain-Cert：把「演示方案」与「可解释性」纳入同一可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但这两个风险都压在一块从未被检验的地基上。本轮灵感词「演示方案」「可解释性」精确命中这条地基上的两个未言明假设：**(H5) 演示只是叙事/工程包装**——一段五分钟的秀被默认为「系统能工作」的证据，却从不追问：它是从无穷行为空间里精心挑出的有限样本吗？换到部署环境还成立吗？失败、拒绝、降级的行为被展示过吗？**(H6) 可解释性只是事后话术**——证书被当作自解释的，解释是在决策之后用自然语言补出来的，既不保证忠实于证书，也不保证不同受众听到的解释互不矛盾，更不保证听众接收时它还没过期。二者恰好互为缺口：**演示是可解释性唯一的现场压力测试**（要限时、多受众、被现场追问地生成解释），而**解释是演示唯一能自证诚实的机制**（必须能讲清「我为什么拒绝/降级」，而不是只演成功）。本轮真正的新问题是二者的复合：**当证书的前提假设本身失效时，一个忠实的解释加一场诚实的演示，会合谋把「根因错误」包装成「一切尽在掌控」**——即「解释剧场 × 演示剧场」的复合欺骗。v9 因此新增的不是一个展示层，而是一层**见证层（witness layer）**：演示 = 有限见证证书，解释 = 证书的安全抽象 + 可机器校验的推导。

## 0. 直觉与动机

**灵感 1（演示方案 → 演示是「有限见证证书」，不是秀）**：直觉上，评审只看五分钟，而这五分钟永远说不清「系统在未展示的两万分钟里也安全」。演示的本质结构与统计学习完全同构：**声明 Φ 是假设，场景集 S 是样本，演示是有限见证**。于是三件事必须同时成立：**(a) 无见证不声明**——每条对外声明 φ 必须绑定一个可重放的见证 w_φ=(轨迹, 证书, 前提台账)，第三方能原样复现；否则它只是营销话术，不进证书。**(b) 先注册后运行**——场景集在跑之前就固化（哈希+时间戳），否则「跑完挑好看的」就是事后选择偏差，演示的通关率对部署风险没有泛化保证。**(c) 负样本强制**——演示必须包含「安全拒绝」「优雅降级」「契约不可行时协商」的负向场景；只演成功的演示恰恰掩盖了系统最重要的能力——在越界前停下来并说清楚为什么。一句话：**无见证不声明，不注册不演示，不演失败不算演示**。

**灵感 2（可解释性 → 解释是证书的「安全抽象」，不是自由文本）**：证书本身是高维对象（可达集、屏障函数、margin 场），而解释是低维、面向人的投影；投影必然丢信息，问题只在于丢的是不是安全关键信息。因此把解释定义为**从证书到受众词汇表的抽象映射**，并要求它满足**忠实性 = 不过度声明**：解释所断言的行为集合必须被证书所保证的安全集合包含（claim(E) ⊆ claim(C)）。这天然给出「解释前沿」：太保守的解释忠实但无用，太激进的解释有用但会过度声明——二者之间的边界就是可被机器校验的**解释证书** ρ=(E, C, 推导)，由验证器检查 claim(E)⊆claim(C)。更进一步：v20 的「最小让步集」本身就该用**反事实解释**来表达——「若把约束 c 放松 δ，就存在可行策略，但 margin 会降到 m」；让步集与反事实解释是同一件事的对偶两面。

**灵感 3（耦合 → 演示是可解释性的压力测试、解释是演示的诚实性机制）**：把二者拼起来才出现真问题。一场演示里，解释要面对**三类受众**（评审、操作员、终端用户）、在**租约衰减的时间窗内**、被**现场追问**地生成；而演示要在**有限场景**里证明「系统既安全又能解释自己」。复合风险在于：证书的**前提假设**（传感器干净、场景平稳、接触属性为真、人类意图可交换）通常不写在证书里。若演示的场景集没有触及某个失效的前提，那么决策证书仍然 sound（在错误前提下）、解释仍然「忠实」（忠实于一个错误前提），两层各自通过、合起来却误导。因此必须引入**前提台账 A(φ)**：每条声明必须标注「本次演示真正检验了哪些前提、哪些只是被假设」。演示计划的价值不在于多漂亮，而在于**它有没有至少一次证伪某个前提并触发安全拒绝**。

**耦合升级**：DCE（演示契约引擎）把演示编译成预注册场景集 + 见证绑定 + 前提台账；ECB（解释-证书桥）把证书投影成多受众、可校验、带租约的解释，并把让步集翻译成反事实；DEV（演示-解释联合验证器）在仿真与实机里做选择偏差检测、注入不忠实解释、枚举受众矛盾与解释过期，把反例回灌 CKB 与 SCV。四层架构由 v8 的「人格契约层 + 并发证书层」升级为 v9 的「人格契约层 + 并发证书层 + **见证层（演示 × 解释）**」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（演示契约与演示证书）**：演示契约 Δ = (S, Φ, W, π, ω)：S 为预注册场景族（含安全拒绝/降级等负样本），Φ 为对外声明集合，W: Φ→见证 把每条声明绑定到可重放见证 w_φ=(轨迹, 决策证书, 前提台账)，π 为预注册协议（运行前对 S、Φ、判据做哈希时间戳固化），ω 为场景覆盖度量。**演示证书** D=(Δ, {w_φ}_{φ∈Φ}, replay_log)。**演示 sound 性**：∀φ∈Φ，w_φ 在其有效域内证明 φ，且 replay(w_φ) 可原样复现决策与证书。无见证的声明（marketing claim）不得进入证书，只能作为「未验证声明」单列。

**定义 45（演示诚实性：选择偏差、PAC 泛化与前提台账）**：设部署分布与演示分布分别为 D 与 D_S。**选择偏差** G_sel = R_D(π_sys) − R_S(π_sys)。预注册保证 S ⊥ 事后选择；用 e-process/序贯检验检测自适应挑场景（零假设下 e-value 的期望 ≤1，按结果增删场景会使其越界）。**泛化界**：当 S ~ D^n 且声明在 S 上以 margin 通过，则 w.p. ≥1−δ 有 R_D ≤ R̂_S + rad(n, δ)。**前提台账** A(φ) = (E_φ, A_φ)：E_φ 为本次演示**真正检验**的前提，A_φ 为**仅被假设**的前提。**演示诚实性** = 预注册 ∧ 负样本非空 ∧ G_sel 在置信界内 ∧ A(φ) 被显式披露。**推论**：任何未触及 A_φ 的演示，无论多成功，都不能为该前提背书。

**定义 46（证书解释投影与忠实性）**：设受众 a 的词汇表为 L_a。解释是投影 E_a: C → L_a，诱导声明集合 claim(E_a(C))。**忠实性**：claim(E_a(C)) ⊆ claim(C)（解释是证书的**安全抽象/欠声明**，绝不夸大安全）。**充分性**：解释必须能区分「接近边界」的决策（否则等于没说）。二者构成**解释前沿**（soundness–informativeness 权衡）。**解释证书** ρ=(E_a, C, π_ρ)，其中 π_ρ 为机器可校验的推导，验证器检查 claim(E_a(C))⊆claim(C)；不通过则解释视为幻觉，必须拒绝输出或降级为「无法解释，仅给证书」。

**定义 47（反事实解释与最小让步对偶）**：对不可行的人格契约 C_u（v20 定义 38），反事实解释 cf_k 形如「若将约束 c 放松 δ，则存在策略且 margin=m」。最小让步集 K* = argmin_{K: feasible(C_u ⊕ K)} cost(K)。**对偶定理**：K* 恰是最小的、能使可行性恢复的反事实集合；且解释最优性 ≡ 让步最优性——即「解释得最好」等于「让步得最少」。**推论**：协商 UI 不该输出一份参数列表，而应输出一组**可被用户逐条选择的反事实解释**，每条附带放松后的证书与 margin 变化。

**定义 48（多受众解释一致性）**：多受众 {a_1..a_k} 的解释**一致**，当且仅当存在公共证书核 C_0 ⊆ C，使每个 E_{a_i} 都是 C_0 的安全抽象，且任意两条解释在其共享词汇上的断言**可兼容**（claim(E_{a_i}) ∩ claim(E_{a_j}) ≠ ∅，且不出现互相否定）。**一致性定理**：若每条解释都对同一 C_0 欠声明且两两兼容，则它们的合取仍是 C_0 的安全抽象。**反例警示**：两条各自 sound 的解释仍可能互斥（「会停」vs「会减速」），因此一致性不能被忠实性推出，必须单独验证。

**定义 49（解释租约与新鲜度）**：解释引用底层证书租约 ℓ=(m,τ,λ)（v20 定义 41）。**解释租约** ℓ_E=(τ_E, λ_E, θ_E)，其中 τ_E 为解释推导时刻。**新鲜判据**：投递时刻 t 满足 m_E − λ_E·(t−τ_E) ≥ θ_E，且底层决策租约未过期、期间未发生重决策。**过期解释 = 新的不 sound 类**：一句在决策当天为真的解释，在被听到时可能已误导。**命题**：把解释绑定到决策的同一 lease/epoch，并要求「过期即重导或显式声明『状态已变』」，可消除陈旧解释误用。**推论**：解释不能脱离并发运行时（v20 CCR）独立存在，它必须继承租约与 epoch。

**定义 50（复合验证、前提覆盖与解释延迟预算）**：复合声明「系统安全且能解释」的**联合 sound 性**：每个演示步骤上，决策证书 sound ∧ 解释证书忠实 ∧ 解释新鲜。**复合欺骗** = 两层各自通过但合起来误导的违例，其充分条件是存在未被演示触及的前提 p∈A_φ 且 p 实际失效。**前提覆盖要求**：∀p∈∪A(φ)，p 要么被至少一个场景真正检验（p∈E_φ），要么在演示计划中显式标注「被假设、未检验」。**解释延迟预算** B_explain：解释器是 dialogue 关键级的影子任务，必须在 B_explain 内完成且**永不阻塞安全路径**；HI 模式（v20 定义 42）下允许推迟解释，但必须标记「事后解释」并按定义 49 处理其新鲜度。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 DEMO-CONTRACT-ENGINE（演示契约引擎 DCE）
1. **预注册协议**：运行前固化 (S, Φ, 判据)，对场景哈希与时间戳签名；任何事后增删场景留痕并被 e-process 检测。
2. **见证绑定**：Φ→可重放见证；见证含轨迹、决策证书、前提台账、随机种子与硬件版本，支持第三方离线复现。
3. **负样本与失败包络**：强制注入拒绝、降级、协商、紧急停机场景；演示必须展示「失败包络」而非只展示成功包络。
4. **选择偏差与泛化审计**：序贯检验 + PAC 界，输出「演示→部署」差距的置信区间；差距超阈值即降级为「仅示范，不作泛化声明」。

### 2.2 IP-61 EXPLANATION-CERT-BRIDGE（解释-证书桥 ECB）
1. **多受众投影**：从同一证书核 C_0 生成评审/操作员/终端用户三套解释，抽象粒度不同但共用 C_0。
2. **忠实性校验**：生成解释证书 ρ，验证器检查 claim(E)⊆claim(C)；不通过则拒绝输出，退回「只给证书+模板化摘要」。
3. **反事实/让步对偶**：把 v20 的最小让步集编译成逐条可选的反事实解释，附放松后证书与 margin 变化。
4. **解释租约**：解释继承决策 lease/epoch，投递前校验新鲜度；过期则重导或显式标注「状态已变」，绝不静默投递陈旧解释。

### 2.3 IP-62 DEMO-EXPLAIN-VALIDATOR（演示-解释联合验证器 DEV）
1. **选择偏差注入**：模拟「按结果挑场景」的对手，检验 e-process 与 PAC 审计能否检出。
2. **不忠实解释注入**：注入与证书不符但读起来极顺的解释，测验证器漏放率（必须为 0）。
3. **受众矛盾枚举**：生成多受众解释三元组，检查两两兼容与公共核存在性；构造「各自 sound 却互斥」的对抗样例。
4. **解释过期与现场追问**：在 Isaac Sim 注入延迟、状态突变、观众追问，测解释过期率与重导成功率。

| E102 演示-解释长时程 | 100h 不安全事件；受众切换；复合欺骗检出；前提失效触发拒绝率 | 0；1000 次；≥99%；≥99% |

## 5. 本轮最大风险

**一句话**：忠实性与诚实性都只**相对证书及其前提**成立——当某个前提（传感器干净、场景平稳、意图可交换、接触属性为真）在演示中从未被证伪时，一场诚实的演示 + 一句忠实的解释会共同把一个错误前提粉饰成「一切尽在掌控」，即「解释剧场 × 演示剧场」的复合欺骗；因此必须把**前提台账的未检验项**设为独立红线，并强制演示至少包含一次「证伪前提→安全拒绝→解释原因」的负样本。

### IP-60 DCE：预注册、见证绑定与选择偏差审计

```
def pre_register(scenarios, claims, criteria):
    S = hash_and_sign(scenarios)                 # 运行前固化，事后不可改
    return DemoContract(S, claims, criteria, tau=monotonic_now())

def run_demo(delta, system):
    witnesses = {}
    for phi in delta.claims:
        scen = pick_registered(delta, phi)
        trace, cert, assumptions = system.run(scen, seed=scen.seed)
        assert replay(trace) == cert.decision        # 可重放
        witnesses[phi] = Witness(trace, cert, assumptions)
    return witnesses

def audit_selection_bias(delta, witnesses, heldout):
    es = e_process(witnesses)                    # 自适应挑场景 -> 越界
    gap = risk(heldout, system) - risk(delta, system)
    tested  = union(w.assumptions.exercised for w in witnesses.values())
    assumed = union(w.assumptions.assumed   for w in witnesses.values())
    return BiasReport(es=es, gap=gap,
                      unexercised=assumed - tested)   # 未检验前提 = 红线

def demo_soundness_ok(witnesses):
    # 无见证不声明；负样本必须非空；每个前提要么被检验要么显式标注
    return all(w is not None for w in witnesses.values()) \
       and has_negative(witnesses)
```

### IP-61 ECB：忠实性、反事实让步与解释租约
```
def project_explanation(C, audience):
    L = vocabulary[audience]
    E = abstract(C, L)                            # 低维、欠声明
    return E

def check_faithful(E, C):
    # 验证器只接受 claim(E) ⊆ claim(C)；否则判为幻觉解释
    proof = derive_subset_proof(claim(E), claim(C))
    return ExplanationCert(E, C, proof) if proof else None

def counterfactual_concessions(C_u, goal):
    # 与 v20 最小让步集对偶：每条让步 = 一条可解释反事实
    K = minimal_relaxation(C_global, goal)
    cfs = [Counterfactual(relax=k.constraint, delta=k.delta,
                          new_margin=margin_after(k)) for k in K]
    return K, cfs

def explanation_lease(cert_lease, E):
    # 解释继承决策 lease/epoch；不得自立门户
    return Lease(tau=monotonic_now(), lam=cert_lease.lam, epoch=cert_lease.epoch)

def deliver(E, lease, t):
    if lease.m - lease.lam * (t - lease.tau) < lease.theta:
        return rederive(E) if fresh_possible(E) else mark_state_changed(E)
    return E

def coherent_multi_audience(explanations, C0):
    # 各自 sound ≠ 互相兼容；必须显式检查共享词汇可兼容
    return all(subset(claim(e), claim(C0)) for e in explanations) \
       and pairwise_compatible(explanations)
```
