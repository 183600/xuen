# 第 3 轮（灵感循环第 3 轮；本轮灵感：「常识推理」×「惯性测量单元」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其下为第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45；实验 E411–E425）。
> 本轮纪律：**继续在既有台阶上加固，而不是另起炉灶**。ToolGauge 的三个核心模块不重写，
> 而是补上它自己在 §6 承认的最大缺口——**跨盲区强相关的先验污染**。
> 补法不是再训练一个更强的先验，而是引入两个**失效模式与学习先验不同**的独立证据源：
> **惯性测量单元（IMU）** 提供带误差证书的自运动参考；**常识推理** 提供可证伪、可败退的物理可行性约束。
> MODGAUGE 五不变式、6C 骨架、严格退化链全部保留；6C 扩展为 7C。
> 新增编号：IP-321–326；定义 432–447；引理 51–57；实验 E441–E454。

## 三位一体映射（两词三用：两个独立通道 + 一个合成判据）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 惯性测量单元 | IP-319 V 阶段：单条 `cross.modal` 回执 | **I-Box / IRC**：IMU 预积分 + 漂移预算 + 惯性回执；V 阶段获得物理独立的第二票 | 视觉与语言先验可以一起错；本体惯性不会跟着它们的偏差一起错（除非共模，见 §6） |
| 常识推理 | IP-315 L-Box：VLA 生成的语义假设 + SNC 指纹 | **C-Box / CIL**：可操作化、可败退的常识不变式库；假设剪枝与参数可行域 Ω_common | 常识是廉价的物理先验，但**不操作化就零作用**，可被数值反例击败 |
| 二者合成 | IP-319 V：`|z| ≤ ε_cross` 单阈值 | **TCM**：三源一致性（E/I/C）+ 共模金丝雀 + 弃权语义 | 相关误接受的界从 p_E 降到 p_E·p_I + ε_C + η_common；代价是必须实测 η_common |

**核心命题**：把 ToolGauge 的「语义假设 → 契约工具 → 摊销校准 → 交叉验证 → 热替换」升级为
「**语义假设 + 可败退常识 → 契约工具 → 摊销校准 → 惯性/常识独立审问 → 三源一致 → 热替换**」。
数值真值仍由计量层独占：常识只生成**数值可判定**的约束，IMU 只提供**带误差证书**的相对运动。
两者都不是真值，且都必须能弃权；系统必须把「有几票、哪一票弃权」写进修复证书，而不是假装永远有三票。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- 主张绑定不变式扩展到**每条修复证书必须声明证据组合与弃权状态**（定义 441/442）；
- **严格退化链延长**：SensusGauge ⇒（IMU 不可用 / 常识规则全 inert / 预算耗尽）ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；
- **新增弃权 ≠ 矛盾**：`ABSTAIN` 安静降级；`CONTRADICT` 必须升级或 stub+RED，禁止静默回退（定义 442）。

## 0. 直觉与动机

### 0.1 第 2 轮的最大风险为什么还没有被真正堵住

第 2 轮把最大风险写得很诚实：AP-Cal 的摊销后验在预训练→部署偏移下会产生**跨盲区强相关**的系统性偏差，
一次错误先验会同时污染所有被热替换的子图。但它给出的三道兜底都有结构性缺陷：

1. **交叉验证不独立**：V 阶段用的 `cross.modal` 回执虽然换了物理模态，但只要它和主估计共享同一个学习管线
   （同一个 VLA 特征、同一个材质先验、同一套标定），它们的误差就是相关的。所谓"交叉"只是在同一口井里打两桶水。
2. **P-Quarantine 是事后断路器**：它要看到连续 q 次同向残差才触发，此时前 q 个被污染的盲区**已经热替换完成**。
   断路器挽救的是后面的盲区，不是已经被污染的子图。
3. **共形覆盖只保证假设集，不保证数值后验**：SNC 用运行时观测过滤 H_s，若过滤规则本身看了校准数据，
   共形保证的可交换性被破坏；第 2 轮没有审计这一点。

因此第 3 轮的出发点不是"再加一个先验"，而是：**在第一次热替换发生之前，引入一个不与学习先验共享误差的物理投票。**

### 0.2 灵感 1：常识推理 = 可败退的物理可行性先验

直觉上，人类修复感知盲区时大量依赖常识："杯子不会穿过桌面"、"静置的物体下面一定有支撑"、
"刚体上两点距离不会突变"、"没有接触和重力之外的力，物体不会自己加速"。
这些规则廉价、常开、且**与深度网络学到的纹理先验在错误模式上不同**——网络会被反光骗，常识不会因为反光而认为杯子会穿桌。

但常识有两个致命问题，第 2 轮的 VLA 幻觉已经演示过一次：
- **不可操作化**：很多常识说不清对应哪个可测量，直接拿来做数值约束就是"自信地胡说"；
- **有例外**：可变形物体、磁吸、气流、容器倾倒……硬套规则会误删正确假设。

本轮的处理因此不是"把常识塞进数值通道"，而是：
- **可操作化才生效**：每条常识不变式 κ 必须等价于一个可测量的数值谓词 `m_κ(s,u) ≤ τ_κ`；
  不能操作化的 κ 是 **inert（零作用）**，既不剪枝也不进入证书；
- **可败退（defeasible）**：κ 是一条默认规则 `A : ¬δ₁,…,¬δ_m ⇒ φ`；任何 δ_i 被有效回执支持，
  κ 就被**击败**、从约束集中移除。删除约束只会**放宽**可行域，永远不会误删正确解；
- **审计化**：每次激活/击败/剪枝都进 DefeatLedger，规则有覆盖率和被击败率；常被击败的规则要退休。

常识因此是一个**保守的、可撤销的可行域先验**，而不是一个会说话的 oracle。

### 0.3 灵感 2：IMU = 带误差证书的自运动参考通道

IMU 的工程直觉是：它是**本体感受**的高频传感器，采样率远高于视觉，且**因果上与外部感知管线独立**——
相机被反光骗、激光被透明物骗时，陀螺仪和加速度计仍在测机器人自己的运动。
这正好补上 ToolGauge 最缺的一票：一个不与"材质先验/VLA/视觉标定"共享误差的运动参考。

但 IMU 也绝不是真值：它是**相对**测量，积分会漂移，偏置和尺度因子会随机游走，重力方向标定错会全局污染，
时间戳没对齐会让残差系统性偏置。把它当真值，会比没有它更危险。因此本轮把 IMU 当成**带误差证书的参考通道**：

- **预积分 + 协方差传播**：在关键帧之间预积分，给出相对旋转/速度/位移及其解析传播的协方差；
- **漂移预算硬顶**：偏置观测器（ZUPT、重力对齐、回环）在线更新；协方差按 `αΔt+βΔt²` 膨胀；
  一旦漂移上界超过 `D_max`，IRC 直接 `ABSTAIN`，不允许"带病投票"；
- **时间同步契约**：残差里显式加入 `σ_sync²=(v_max·δ_t)²`；同步自检失败即弃权；
- **主动激励**：新增 `imu.excite` 工具，用有界、安全的小幅运动制造可观测性（视差/接触激励），
  让"本来不可被 IMU 验证"的盲区变成可验证；激励本身走 λ/β 双闸门与 PROBING 安全态。

一句话：**IMU 的價值不在"更准"，而在"错得不一样且知道自己何时不可信"。**

### 0.4 合成：误差源多样性，而不是更强的单一先验

第 2 轮的思路是"把先验做得更强、更可审计"；本轮改成"让错误源尽量不重合"。
三源分别是：
- **E（Exteroceptive）**：视觉/几何/契约的估计，误差来自感知与学习先验；
- **I（Inertial）**：IMU 预积分的相对运动，误差来自漂移、偏置、时间同步；
- **C（Commonsense）**：可操作化的物理可行性，误差来自规则误设（例外未建模）；
在"条件独立 + 共模误差可忽略"的假设下，E 与 I 同时犯同向错误的概率近似相乘，
这是本轮唯一真正的新安全来源。但这个假设**本身不可由三源内部证明**——所以必须用共模金丝雀与故障注入
把它变成一个**可测量的预算 η_common**，并且当 η_common 不可接受时，系统必须诚实地说"我只有一票"。
这也是本轮最大风险的来源（§6）。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（惯性参考通道 IRC 与预积分）**
设 IMU 采样 `{(ω_k,a_k)}`，偏置 `b=(b_g,b_a)`，关键帧 i→j 的时间间隔 Δt。预积分量
`ΔR_ij=∏Exp((ω_k−b_g)Δt)`，`Δv_ij=Σ ΔR_ik(a_k−b_a)Δt`，`Δp_ij=Σ[Δv_ikΔt+½ΔR_ik(a_k−b_a)Δt²]`。
对状态 `(R_i,p_i,v_i,R_j,p_j,v_j)` 与重力 g 定义残差 `r_ij=(r_ΔR,r_Δv,r_Δp)`，
协方差 `Σ_ij^I` 由噪声 `(σ_g,σ_a)` 与偏置随机游走 `Q_b` 一阶传播得到。
IRC 输出**相对运动证书** `I_ij=(ΔR,Δv,Δp,Σ_ij^I,validity_window,drift_bound)`。
有效性条件：无饱和、激励充分 `∫‖ω‖²dt ≥ e_min`、时间同步 `|Δt_sync| ≤ δ_t`、偏置观测器收敛、
漂移上界 ≤ `D_max`。任一不满足 ⇒ `ABSTAIN`。

**定义 433（惯性回执、残差与适用域）**
对盲区 s，记外部感知的相对运动估计 `(μ_s^E,Σ_s^E)`。定义适用域 `App_I(s)`：
(i) s 涉及载有 IMU 的本体运动；或 (ii) s 涉及**刚性抓取/接触**的物体，且外参 `T_BI` 与接触刚度界已知。
`¬App_I(s)` ⇒ IRC 弃权（不投票、不惩罚、不伪造一票）。
若适用，惯性回执 `r_s^I=(μ_s^I,Σ_s^I,d_s²,sig,ts,seq)`，其中
`d_s² = ‖μ_s^E ⊖ μ_s^I‖²_{(Σ_s^E+Σ_s^I+σ_sync²I)⁻¹}`。
`valid(r_s^I)` ⇔ 定义 432 的有效性 ∧ `d_s² ≤ χ²_{d,1−δ_I}`。
**注意**：`d_s²` 大只说明 E 与 I 分歧，**不说明 I 对**；它触发定义 438 的分诊，绝不直接触发替换。

**定义 434（漂移预算与偏置观测器）**
偏置随机游走 `b_{t+1}=b_t+w_t, w_t~N(0,Q_b)`；观测更新来自零速检测 ZUPT（`‖v‖<v_z,‖ω‖<ω_z`）、
重力对齐与回环。协方差膨胀 `σ_drift²(Δt)=αΔt+βΔt²`。定义累积漂移上界 `D(t)`；
当 `D(t)>D_max` ⇒ IRC 进入 `DEGRADED` 并弃权。这是防止"惯性权威化"的硬边界。

**定义 435（可操作常识不变式 CIL）**
一条常识不变式 `κ=(id,φ,A,D,τ_κ,cov_κ)`：
- `φ`：类型化谓词；**可操作化要求**：存在可测函数 `m_φ` 使 `φ ⇔ m_φ(s,u_s) ≤ τ_κ`（或 ≥）；
  否则 κ 为 **inert**，永久不生效；
- `A`：适用谓词（刚体/容器/静置/接触…）；
- `D={δ_1,…,δ_m}`：败退集，每个 δ_i 是可操作谓词，且必须由**有效回执**支持才能击败 κ；
- `cov_κ`：在预注册审计集上的覆盖率；`τ_trust`：规则信任上限（常识永远不能压过数值证据）。
默认语义：`A : ¬δ_1,…,¬δ_m ⇒ φ`；采用**怀疑论默认逻辑**——只有出现在**所有扩展**中的约束才被采纳。

**定义 436（常识可行域 Ω_common 的两级作用）**
- **假设级**：`H_s^C={h∈H_s : h 满足所有被采纳的 φ_κ}`；每次剪枝必须携带 `m_φ` 的数值证书；
- **参数级**：`Ω_param={u : 所有被采纳的参数不等式成立}`；非凸时取其**保守内近似** `Ω̃`（盒/线性约束）。
**冲突规则（防止投影洗白）**：若 `dist(μ_θ,Ω̃)>δ_proj`，判定 **prior-commonsense conflict**，
不投影、直接升级/隔离；只有小违反才做保守投影
`μ̃=Π_{Ω̃}(μ_θ)`，`Σ̃=Σ_θ+(μ_θ−μ̃)(μ_θ−μ̃)ᵀ+κ_cI`（均值平移膨胀保覆盖）。
这条规则专门防止"把一个错得很离谱的先验投影到可行域内，再假装它是被常识支持的"。

**定义 437（败退台账 DefeatLedger）**
`(κ,t,receipts,decision,rule_version)` 逐条记录激活/击败/剪枝；禁止静默击败。
规则信任由 `cov_κ` 与被击败率更新；`cov_κ<cov_min` 或击败率 >ρ_max ⇒ 降权/退休。
信任硬顶 `trust(κ)≤τ_trust<1`：常识只能缩小可行域，不能推翻数值回执。

**定义 438（三源一致性 TCM 与分歧升级）**
记三源 E（外部估计）、I（惯性）、C（常识可行域）。规范化分歧 `d_EI,d_EC,d_IC`，各带阈值与弃权集。
一致谓词
`Cons = (d_EI≤τ_EI ∨ ¬App_I) ∧ (d_EC≤τ_EC ∨ C_inert) ∧ (d_IC≤τ_IC ∨ ¬App_I)`。
`¬Cons` 时：若可由偏置更新/额外激励/重跑解决 ⇒ 预算内定向探测；否则 `stub+RED`，**不热替换**。
`Cons` 是**必要非充分**条件：V 仍需契约回归、物理可行性回归与残差白化检验。

**定义 439（主动惯性激励工具 imu.excite）**
`schema: |a|≤a_max, |jerk|≤j_max, duration≤T_ex`；`Pre`：自由工作空间或力限接触、人不在包络内；
`Post`：激励回执 `(FIM, realized_profile, sig, ts, seq)`。预测增益
`Ĝ_ex=½log det(Σ_post^{-1}Σ_prior)`；仅当 `β=Ĝ_ex−c_ex≥γ_B` 且风险门 λ 通过才执行。
用途：把"当前激励下不可观"的盲区变成可观；若 Fisher 信息在所需方向奇异，则激励无效，诚实弃权。

**定义 440（共模金丝雀与独立性监控）**
周期性向某一源注入**已知**偏移 `Δ_canary`（仿真/维护态，或受控微动），验证 `Cons` 是否翻为 false。
若检测不到，说明一致性监控对该尺度的共模误差**失敏**；取 `η_common ≥ Δ_canary` 作为共模预算下界，
超预算 ⇒ 隔离并重新标定。这是对"验证器本身"的计量自检。

**定义 441（SensusGauge 7C 闭环）**
`H → C → E → C → I → V → U`：
1. H：L-Box 语义假设 + C-Box 常识种子（类型化）；
2. C：TCV 编译（T₀ 增加 `imu.excite`）；
3. E：逐工具执行，产出有效回执；
4. C：AP-Cal 摊销校准 + 参数级投影（遵守定义 436 的冲突规则）；
5. **I（Interrogate）**：计算惯性回执（若适用）；评估常识可行域与败退集；必要时在预算内触发激励；
6. V：TCM 三源一致 + 独立回执 + 契约回归 + **物理可行性回归**（定义 444）；
7. U：热替换 + 扩展修复证书（证据组合、弃权状态、被击败规则、惯性残差）。
I/V 失败 ⇒ 有界重试一次 ⇒ `stub+RED`。

**定义 442（弃权语义与扩展退化链）**
`ABSTAIN`（不可用/不适用/漂移超限/规则全 inert）与 `CONTRADICT`（有票但互斥）严格区分：
- 两源弃权 ⇒ 退回 ToolGauge 6C（安静降级）；
- 出现矛盾 ⇒ 定向探测；预算内不能解决 ⇒ `stub+RED`，**禁止静默回退**（矛盾可能是真的）；
- VLA 不可用但常识种子可用 ⇒ C-Box 单独供假设；常识规则全失效 ⇒ ToolGauge；
  ToolGauge 失效 ⇒ LeanGauge；再失效 ⇒ MODGAUGE。

**定义 443（时间同步契约 TSC）**
IMU 与外部感知的时间戳偏移满足 `|Δt_sync|≤δ_t`；残差膨胀含 `σ_sync²=(v_maxδ_t)²`；
时钟金丝雀失败 ⇒ IRC 弃权。同步契约是惯性回执有效性的前置条件，不得省略。

**定义 444（物理可行性回归 PFR）**
契约回归除数值等价外，新增：新 EC 必须满足所有被采纳的 `Ω_common`，
且不得把任何被 DefeatLedger 记录为物理荒谬的字段重新引入。PFR 失败 ⇒ 拒绝热替换（stub+RED）。

**定义 445（有效样本量，修正定义 426）**
对自相关残差，定义 `n_eff=n/(1+2Σ_{k=1}^{K}ρ_k)`（或 `n_eff=(Σw)²/Σw²`）。
AP-Cal 的样本下界用 `n_eff` 而非调用次数 `n`；`n_eff<n_min` ⇒ 不校准、不替换。
这修复第 2 轮"独立高斯观测"假设与真实时序相关的冲突。

class InertialReference:
    def ingest(self, sample):
        self.preint.update(sample)
        self.bias_obs.update(sample)
        self.drift.integrate(sample.dt)

    def receipt(self, s, mu_E, Sig_E):
        if not App_I(s) or self.drift.upper() > D_MAX or not self.tsc.ok():
            return ABSTAIN                       # 诚实弃权，不伪造一票
        mu_I, Sig_I = self.preint.query(s.window)
        Sig_I = inflate_drift(Sig_I, s.window.dt, self.bias_obs.cov)
        Sig   = Sig_E + Sig_I + outer(ones, ones) * self.tsc.sigma_sync2
        d2    = mahalanobis(mu_E, mu_I, Sig)
        return IReceipt(mu_I, Sig_I, d2, sign(self.key), now(), next_seq())

# IP-322 C-Box：可操作、可败退的常识约束
class CBox:
    def active(self, scene, receipts):
        ext = skeptical_extensions(self.W, self.defaults)   # 分层默认理论，多项式时间
        return [k for k in ext
                if k.operational
                and not any(defeated(d, receipts) for d in k.D)
                and self.trust[k] <= TAU_TRUST]

    def prune(self, H, scene, receipts):
        out = []
        for h in H:
            rules = self.active(scene, receipts)
            ok = all(self.certified_true(k.phi, h, receipts) for k in rules)
            self.ledger.record(rules, h, ok)               # 禁止静默剪枝
            if ok: out.append(h)
        return out or ["UNKNOWN"]

    def project(self, mu, Sig, Om):
        if dist(mu, Om) > DELTA_PROJ:
            raise PriorCommonsenseConflict                 # 不洗白，升级
        mu2  = project_convex(mu, Om)
        Sig2 = Sig + outer(mu - mu2, mu - mu2) + KAPPA_C * I
        return mu2, Sig2

# IP-323 TCM：三源一致 + 共模金丝雀
def tri_source_consensus(mu_E, r_I, Om, ctx):
    checks = []
    if r_I is not ABSTAIN:
        checks.append(("EI", norm_residual(mu_E, r_I) <= TAU_EI))
    if Om is not None:
        checks.append(("EC", dist(mu_E, Om) <= TAU_EC))

    ok = all(v for _, v in checks)
    if not ok:
        return False, triage(checks, ctx)                  # 定向探测/升级/stub
    return True, checks

# IP-325 SensusGauge 7C 闭环
def sensusgauge_7c(M, s):

        return stub_and_red(s, "insufficient_effective_samples")

    Om, H2   = M.cbox.feasible(s, receipts)
    try:
        mu, Sig = M.cbox.project(mu, Sig, Om)
    except PriorCommonsenseConflict:
        return escalate(s, "prior_commonsense_conflict")                     # 定义 436
    r_I      = M.irc.receipt(s, mu, Sig)                                     # I
    if r_I is ABSTAIN and M.irc.excitation_warranted(s):
        M.tcv.execute([imu_excite(s)], M.env)                                # 安全激励

    ok, why  = tri_source_consensus(mu, r_I, Om, s)                          # V

## 3. 推导（引理 51–57）

**引理 51（惯性回执的校准性与漂移支配）**
在高斯 IMU 噪声、预积分协方差一阶传播、偏置观测器误差有界且漂移膨胀按定义 434 的条件下，
对有效且无未建模模型误差的回执，`P(d_s²>χ²_{d,1−δ_I}) ≤ δ_I+ε_lin`，其中 `ε_lin` 为线性化误差。
若漂移上界超过 `D_max`，IRC 弃权 ⇒ 不产生带病投票。
证明要点：Forster 预积分残差的高斯性 + 卡方检验；偏置随机游走由 `D_max` 截断；线性化误差用一阶界并入。
系：IRC 是**校准过的票**，不是真值；其弃权是保守的（宁可少一票）。

**引理 52（常识约束的保守性与不误删）**
设 κ 可操作，D 为其败退集，采用怀疑论默认语义。
(a) 增加一个败退条件只会**放宽** `Ω_common`（可行域单调不减）；
(b) 若当前场景所有被采纳规则都成立，则 `u*∈Ω_common`，且假设级剪枝不会删掉 `h*`；
(c) 若每条规则误设率 ≤ε_C，则 `P(u*∉Ω_common) ≤ 1−(1−ε_C)^{|active|}`。
系：inert 规则作用恰好为零；审计与败退机制必须压低 `|active|·ε_C`，不能靠堆规则提精度。
证明：(a) 怀疑论语义下删除约束只增大交集；(b) 逐规则代入；(c) 并集界。

**引理 53（三源相关误接受界）**
在假设 A120 下：给定共享物理状态与时间同步契约，E 与 I 的残差除显式预算 `η_common` 外条件独立；
C 的误设率为 ε_C。对阈值 ε，
`P(接受且‖x̂−x‖>ε) ≤ p_E(ε)·p_I(ε) + ε_C + η_common`，
其中 `p_E(ε)` 是 ToolGauge 单源误接受率，`p_I(ε)` 是 IRC 误接受率。
当 IRC 弃权时右端退化为 `p_E(ε)`；系统必须在修复证书中报告当前处于哪种情形。
系：理想独立时安全性由乘积给出；若 `η_common` 主导，三源收益趋零——这正是 §6 的最大风险。
证明：全概率按 E/I 是否超差展开；条件独立使联合项分解；C 与共模项用并集界加入。

**引理 54（7C 的时序与预算保持）**
IMU 摄入与预积分是每样本 O(1)、滑动窗口 O(W) 内存；50Hz 控制路径只增加缓冲/累加，实测开销 <0.3ms/周期。
I/V 全异步；`imu.excite` 受 `T_ex` 与安全包络约束；7C 预算 `B_7C=B_tools+B_imu`，耗尽强制降级。
故硬实时（引理 45）与预算不变式保持。
证明：把新增计算按路径拆分；控制路径不含矩阵求逆与默认逻辑求解；异步事件单飞。

**引理 55（激励可观测性与增益注）**
对线性高斯盲区，先验协方差 `Σ_0`，激励程序 `Π_ex` 的 Fisher 信息 `J(Π_ex)`，则
`Σ_post=(Σ_0^{-1}+J(Π_ex))^{-1}`，期望对数行列式缩减 `½log det(I+Σ_0J)`。
`imu.excite` 仅在 λ 与 β（定义 446 的 LCB）同过时执行；若 J 在所需方向奇异，激励无增益，弃权。
证明：标准高斯后验与 Fisher 信息恒等式。

**引理 56（常识/语言不进入数值通道）**
C-Box 的符号推理只产生两类数值对象：可操作谓词的布尔结果与可行域 `Ω̃`；
符号解释、败退理由与文字主张只进 DefeatLedger / RepairCert，不参与任何数值更新。
因此第 2 轮引理 49（语言层不破坏热替换等价性）与引理 44 的数值等价性原样成立；
被击败规则只通过显式记录的数值谓词改变可行域。SensusGauge 在 IRC=∅、无活动规则时严格退化为 ToolGauge。
证明：逐字段检查数值路径的输入集合；符号只作为日志/证书的附加字段。

**引理 57（过滤后共形覆盖的修正，审计第 2 轮）**
若 SNC/过滤使用运行时观测，则把校准集分为 `C_cal=C_fit⊎C_audit`：过滤规则只在 `C_fit` 上拟合，
覆盖率在 `C_audit` 上按过滤决策分层评估；每层可交换时 `P(h*∈H_s | 过滤层)≥1−α`。
若某层样本不足，退回未过滤的共形集（保守）。否则第 2 轮的 `P(h*∈H_s)≥1−α` 在过滤后**不成立**。
证明：分层可交换性 + 标准共形；不足则并回全集。

## 6. 本轮最大风险（一句话）

**一句话**：三源一致性的全部收益都押在「E 与 I 条件独立、共模误差 η_common 可忽略」这个**无法由三源内部自证**的假设上；一旦时间同步、重力/偏置标定或某个场景级扰动同时污染 E 与 I，三源会以**更高的置信度一致地错**，而新增的惯性/常识通道反而制造"独立幻觉"，使第 2 轮的跨盲区相关污染以更难察觉的形式复发。

**次级风险与缓解**：
1. **共模误差** → 时间同步契约 + 已知偏移金丝雀 + 故障注入实测 η_common；η_common 超预算即禁用三源结论（定义 440/443，E442/E446/E452）；
2. **IMU 漂移/欺骗** → 漂移硬预算 + 偏置观测器 + 弃权 + 饱和/振动检测；绝不把 IMU 当真值（定义 432/434，E441/E451）；
3. **常识过度剪枝** → 可操作化门槛 + 败退集 + 怀疑论语义 + 信任硬顶 + 覆盖率审计（定义 435/437，引理 52，E443/E444）；
4. **投影洗白** → 冲突距离阈值；大违反不投影，直接升级/隔离（定义 436）；
5. **激励安全** → PROBING 态 + 力/加加速度/工作空间包络 + 人在场检测；λ/β 双闸门（定义 439，E445）；
6. **适用域过度声称** → `App_I` 显式化；仅本体运动或刚性抓取/接触物体可投 I 票，否则弃权（定义 433）；
7. **默认逻辑复杂度** → 限制为分层理论、`|K|≤64`、预编译为判定表；最坏情况回退到"只用高置信子集"（E450）；
8. **虚假安全感** → 修复证书必须报告证据组合与弃权状态；一致只是必要条件，仍需契约回归 + PFR + 残差白化（定义 441/442）。

| `Σ_ij^I` | 预积分协方差（噪声 + 偏置随机游走传播） |
| `D_max` | IRC 漂移硬预算；超限即 `DEGRADED`/弃权（定义 434） |
| `δ_t, σ_sync²` | 时间同步偏差上界与残差膨胀（定义 443） |
| `App_I(s)` | 惯性回执适用域：本体运动或刚性抓取/接触物体（定义 433） |
| `d_s²` | E 与 I 的规范化马氏残差；大只触发分诊，不直接替换 |
| `κ=(φ,A,D,τ_κ,cov_κ)` | 可操作常识不变式（定义 435） |
| `D={δ_1,…,δ_m}` | 败退集；任一被有效回执支持即击败 κ |
| `Ω_common, Ω̃` | 常识可行域及其保守凸内近似（定义 436） |
| `δ_proj` | 投影洗白阈值；`dist(μ,Ω)>δ_proj` 即升级而非投影 |
| `DefeatLedger` | 败退/剪枝台账（定义 437） |
| `TCM, τ_EI, τ_EC, τ_IC` | 三源一致性监控与分歧阈值（定义 438） |
| `η_common` | 共模误差预算；由金丝雀/故障注入实测（定义 440） |
| `imu.excite, T_ex, J(Π_ex)` | 安全惯性激励工具、时长上限、Fisher 信息（定义 439/引理 55） |
| `n_eff` | 有效样本量（修正定义 426，定义 445） |
| `LCB_δ(Ĝ_t)` | 增益下置信界（修正定义 419 的循环性，定义 446） |

## 2. 形式化定义（要点）

**定义 432（IRC/预积分）** IMU 采样流 → 关键帧间 `(ΔR,Δv,Δp)` 与协方差 `Σ^I`；输出相对运动证书。
有效性：无饱和、激励充分、时间同步、偏置收敛、漂移 ≤ `D_max`；否则弃权。
**定义 433（惯性回执/适用域）** 仅本体运动或刚性抓取/接触物体可投 I 票；`d²` 超阈值是**分歧**而非 I 正确。
**定义 434（漂移预算）** 偏置随机游走 + ZUPT/重力对齐/回环观测；协方差按 `αΔt+βΔt²` 膨胀；超预算弃权。
**定义 435（CIL）** 常识 = 默认规则 `A:¬δ_1…¬δ_m⇒φ`；`φ` 必须可操作化为 `m_φ≤τ`；inert 规则零作用；怀疑论语义。
**定义 436（Ω_common）** 假设级剪枝 + 参数级投影；大违反 ⇒ prior-commonsense conflict，不投影、升级。
**定义 437（DefeatLedger）** 每次激活/击败/剪枝带数值回执；规则信任 `≤τ_trust<1`；常被击败者退休。
**定义 438（TCM）** `Cons` 为三源一致谓词；`¬Cons` ⇒ 分诊（定向探测/升级/stub+RED）；`Cons` 非充分条件。
**定义 439（imu.excite）** 有界安全微动；`Ĝ_ex=½logdet(Σ_post⁻¹Σ_prior)`；λ/β 双闸门；Fisher 奇异则弃权。
**定义 440（共模金丝雀）** 注入已知偏移验证 TCM 是否失敏；得到 `η_common` 下界并作为预算。
**定义 441（7C）** H→C→E→C→I→V→U；I 阶段做惯性票 + 常识可行性；V 阶段三源 + 回归；U 绑定扩展证书。
**定义 442（弃权语义）** `ABSTAIN` 安静降级；`CONTRADICT` 必须升级或 stub+RED；禁止静默回退。
**定义 443（TSC）** `|Δt_sync|≤δ_t`；残差含 `σ_sync²`；时钟金丝雀失败即弃权。
**定义 444（PFR）** 契约回归之外新增物理可行性回归；物理荒谬的 EC 不得热替换。
**定义 445（n_eff）** `n_eff=n/(1+2Σρ_k)`；自相关观测不得按调用次数充数。
**定义 446（G-LCB）** `β=LCB(Ĝ)−c≥γ_B`；LCB 取先验与独立估计的较小者；无独立估计加探索下限。
**定义 447（退化）** IRC=∅、无活动规则、7C→6C ⇒ SensusGauge ≡ ToolGauge。

# IP-321 IRC
class InertialReference:
    def ingest(self, x):
        self.preint.update(x); self.bias_obs.update(x); self.drift.integrate(x.dt)
    def receipt(self, s, mu_E, Sig_E):
        if not App_I(s) or self.drift.upper() > D_MAX or not self.tsc.ok():
            return ABSTAIN
        mu_I, Sig_I = self.preint.query(s.window)
        Sig_I = inflate_drift(Sig_I, s.window.dt, self.bias_obs.cov)
        Sig   = Sig_E + Sig_I + self.tsc.sigma_sync2 * I
        return IReceipt(mu_I, Sig_I, mahalanobis(mu_E, mu_I, Sig),
                        sign(self.key), now(), next_seq())

# IP-322 C-Box
class CBox:
    def active(self, scene, receipts):
        ext = skeptical_extensions(self.W, self.defaults)     # 分层默认理论，多项式
        return [k for k in ext if k.operational
                and not any(defeated(d, receipts) for d in k.D)
                and self.trust[k] <= TAU_TRUST]
    def prune(self, H, scene, receipts):
        rules = self.active(scene, receipts); out = []
        for h in H:
            ok = all(self.certified_true(k.phi, h, receipts) for k in rules)
            self.ledger.record(rules, h, ok)                   # 禁止静默剪枝
            if ok: out.append(h)
        return out or ["UNKNOWN"]
    def project(self, mu, Sig, Om):
        if dist(mu, Om) > DELTA_PROJ: raise PriorCommonsenseConflict
        mu2  = project_convex(mu, Om)
        return mu2, Sig + outer(mu-mu2, mu-mu2) + KAPPA_C * I

# IP-323 TCM
def tri_source_consensus(mu_E, r_I, Om):
    checks = []
    if r_I is not ABSTAIN: checks.append(norm_residual(mu_E, r_I) <= TAU_EI)
    if Om is not None:     checks.append(dist(mu_E, Om) <= TAU_EC)
    if r_I is not ABSTAIN and Om is not None:
        checks.append(dist(r_I.mu, Om) <= TAU_IC)
    return (all(checks), checks)        # False ⇒ triage；True 仍需回归

# IP-325 7C
def sensusgauge_7c(M, s):
    H = M.cbox.prune(M.lbox.hypothesize(s) + M.cbox.seed(s), s, [])   # H
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))         # C
    receipts = M.tcv.execute(prog, M.env)                            # E
    if n_eff(receipts) < n_min(s): return stub_and_red(s, "n_eff")   # 定义 445
    mu, Sig = M.apcal.calibrate(receipts, H, s)                      # C
    Om, H2  = M.cbox.feasible(s, receipts)
    try: mu, Sig = M.cbox.project(mu, Sig, Om)
    except PriorCommonsenseConflict: return escalate(s, "conflict")  # 定义 436
    r_I = M.irc.receipt(s, mu, Sig)                                  # I
    if r_I is ABSTAIN and M.irc.excitation_warranted(s):
        M.tcv.execute([imu_excite(s)], M.env); r_I = M.irc.receipt(s, mu, Sig)
    ok, why = tri_source_consensus(mu, r_I, Om)                      # V
    if not ok: return resolve_or_stub(M, s, why)
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)              # U
    if not contract_regression(new_ec):              return stub_and_red(s, "regression")
    if not physical_feasibility_regression(new_ec):  return stub_and_red(s, "pfr")
    M.mreg.hot_replace(M.dpe, new_ec)
    bind_claims(new_ec, H2, prog, receipts, r_I, M.dledger)
    M.dbox.update_from_posterior(s, mu, Sig)
    return True

# IP-326 主闭环
def SensusGauge_round(M, obs, audio, tac, depth, det, imu_batch):
    for x in imu_batch: M.irc.ingest(x)                 # O(1)/样本
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(sensusgauge_7c, M, s)
    if M.irc.canary_due(): M.tcm.run_canary()
    if M.tcm.common_mode_blind(): M.quarantine()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 51（惯性回执校准性）** 高斯噪声 + 预积分协方差传播 + 偏置误差有界 + 漂移膨胀 ⇒
`P(d²>χ²_{d,1−δ_I}) ≤ δ_I+ε_lin`；漂移超 `D_max` 即弃权，不带病投票。
**引理 52（常识保守性）** 增加败退条件只放宽 `Ω_common`；规则成立时不误删 `h*`；
误设率 ε_C 下 `P(u*∉Ω_common) ≤ 1−(1−ε_C)^{|active|}`；inert 规则零作用。
**引理 53（三源相关误接受界）** A120 下
`P(接受且误差>ε) ≤ p_E(ε)·p_I(ε)+ε_C+η_common`；IRC 弃权时退化为 `p_E(ε)`；
系统必须在修复证书中报告当前票数与弃权状态。若 η_common 主导，三源收益趋零。
**引理 54（时序预算）** IMU 摄入/预积分 O(1)/样本，50Hz 路径 <0.3ms；I/V 异步；7C 预算 `B_7C=B_tools+B_imu`；
硬实时与预算不变式保持。
**引理 55（激励增益）** `Σ_post=(Σ_0⁻¹+J(Π_ex))⁻¹`，期望 log-det 缩减 `½logdet(I+Σ_0J)`；
J 奇异方向激励无效；λ/β 双闸门。
**引理 56（符号不入数值）** C-Box 只输出可操作谓词与可行域；符号解释只进台账/证书 ⇒
第 2 轮引理 49 与第 1 轮引理 44 原样成立；IRC=∅、无活动规则时严格退化为 ToolGauge。
**引理 57（过滤后共形修正）** SNC 使用观测时，`C_cal=C_fit⊎C_audit` 分层评估；
每层可交换则 `P(h*∈H_s|层)≥1−α`；样本不足回退未过滤集。修复第 2 轮覆盖性缺口。

## 8. 本轮最大风险

**一句话**：三源一致性的收益完全依赖「E 与 I 条件独立、共模误差 η_common 可忽略」这个无法由三源内部自证的假设；
一旦时间同步、重力/偏置标定或场景级扰动同时污染 E 与 I，三源会以更高置信度一致地错，
新增的惯性/常识通道反而制造"独立幻觉"，使第 2 轮的跨盲区相关污染以更难察觉的形式复发。
以 E442/E446/E451/E452 实测共模预算，以 TSC + 金丝雀 + 漂移弃权 + PFR 四重设防；
若 η_common 超预算，系统必须降级为"只有一票"，而不是继续宣称三源安全。
