# 第 1 轮（UniBot 线 · 第 1 轮；本轮灵感：「运动控制」×「柔顺控制」）

> **基线变更声明**：本文件此前承载的是 UniBot 线的「抓取 × 技能学习 × 地形适应」草案（定义 U1–U12 / 引理 L1–L7 / 实验 E601–E618），以及更早的 MetricVoiceGauge 线。本轮起把研究重心从「**做什么**（抓什么、用哪个技能、如何适应场景）**整体迁移**到「**怎么动、怎么让**（参考轨迹的动力学可行性、接触中的柔顺与稳定）」；旧编号全部封存停用，本线启用新编号：定义 **C1–C14**、引理 **M1–M8**、实验 **E801–E824**。任务域、提交接口与官方数据集事实继续沿用，不重新造题。

## 0. 情报核实（检索日期 2026-11-17）

**本轮独立核实到的一手接口事实**（GitHub `unitreerobotics/unibot_submission` README / README.zh.md）：

1. **观测里只有位置量，没有任何速度 / 力矩 / 力 / 触觉字段**：4 路 480×640 RGB（左右高位 + 左右腕）、左右臂各 7 维关节**位置**、左右 EE 6 维位姿 `xyz+rpy`、左右夹爪各 1 维开合、下半身 15 维、语言指令。没有关节速度、没有关节力矩、没有腕部六维力、没有触觉阵列。
2. **动作也只是位置目标**：`control_space` ∈ {`joint`,`ee`} 二选一互斥；`joint` 下发 7 维关节**目标位置**，`ee` 下发 6 维**目标位姿**；另有 `action.pivot`(7) 与左右夹爪目标。没有刚度、阻尼、力矩、阻抗参数通道。
3. **chunk 是顺序开环执行**：`action_chunk_size = T_a ≥ 1`，每次 `get_action` 返回形状 `(T_a, …)` 的动作；评测端先执行索引 0，再按顺序执行其余，直到下一次调用。README **没有**声明跨 chunk 的插值、平滑或控制器重置语义。
4. **没有声明控制频率 / 时间戳**：接口以「action step」为时间单位，步长 `Δt` 未公开；数据集是 30 fps，但评测端执行频率不能由数据卡直接推出。
5. token 在两处校验；评测在 **N 台真机**上随机顺序进行，必须暴露 **8765…8765+N−1** 连续端口，每端口独立完成全流程，共享后端须并发安全且状态隔离。
6. 官方明确记录**每步响应延迟及其波动**与**返回动作的统计规律性**，并可能据此评估结果可信度。

**本轮未能独立核实的事**：`unibot.unitree.com` 首页与 `leaderboard_data.json` 本轮均返回 **HTTP 567**，榜单/排名/成功率不可复核。因此本稿**不以任何 teaser 数字为设计前提**；所有推论只依赖「任务名 + 接口 schema + 控制语义」这些可由 README 与数据卡直接确认的结构性事实。

**由事实直接推出的关键结构性结论**：

| 接口事实 | 对方案的含义 |
|---|---|
| 只有位置观测与位置目标 | 「柔顺」无法被直接命令；只能在**参考层**用导纳/阻抗的方式去"让"，且实际接触力不可观测 |
| 无 FT / 触觉 / 力矩 | 接触只能从「跟踪残差 + 视觉滑移 + 夹爪反应 + 速度不连续」**间接推断**；绝对力不可辨识（见引理 M5） |
| chunk 顺序执行、语义未声明 | chunk 边界最多 C0；加速度跳变会在接触瞬间放大成冲击 |
| 控制频率 / 延迟未声明 | 「动力学可行」与「延迟补偿」都必须在**线辨识**之后才成立 |
| N 台真机、共享后端 | 每台机的内环增益/延迟可能不同；一套固定导纳增益会在某些机上振荡 |

## 1. 直觉：先给画面，再给定义

### 1.1 灵感一「运动控制」——参考不是运动，闭环才是运动

大多数端到端策略把「输出一条位置序列」当成任务的终点：只要路点大致落在物体上，就认为轨迹是对的。但真机上，**成功与否由闭环响应决定**，不由路点决定。两个路点完全相同的轨迹，一条在接触前突然加速、chunk 边界处速度跳变，另一条速度/加速度连续且接触前减速，前者会在插入/旋转/放置的最后一毫米把物体撞飞，后者不会。

运动控制的第一性原理是：**位置目标只是参考（reference），真正被执行的是「参考 + 内环动力学 + 延迟 + 限幅」的复合体**。因此本轮把 VLA 的输出降级为「路点建议」，在它之后插入一个**运动编译器**：把路点变成 C2 连续、满足速度/加速度/ jerk 约束、且在接触相位自动减速的参考。由于排行榜只按成功率（与步骤分）计分、且任务时长有富余，「为成功率牺牲速度」在原则上是免费的（引理 M2）。

### 1.2 灵感二「柔顺控制」——没有柔顺通道，就伪造一个

柔顺控制的教科书前提是「你能命令力矩或阻抗」。这里没有：你只能命令位置。于是必须换一个第一性原理：**柔顺不是控制器的属性，而是「参考对测量的让步」**。如果参考永远刚性追一个理想点，接触力就由「位置误差 × 未知内环刚度」决定，且不可控；如果让参考根据推断出的接触反向偏移（导纳），系统就会在接触处"软下来"。

代价是：① 让步多少取决于未知的内环刚度 `K_in`；② 让步本身是一个反馈环，**在延迟下会振荡**；③ 没有力传感器，你只能估一个**相对**力代理，不能声称绝对力。因此柔顺层必须与「黑箱内环辨识」和「被动性/能量罐」一起设计，否则"更柔顺"会变成"更抖"。这三点恰是本轮与常见"加个阻抗头"方案的分水岭。

### 1.3 合成：运动—柔顺协同栈

**L0 辨识层（PlantID）→ L1 运动编译层（MotionCompiler）→ L2 接触感知 + 目标空间导纳（ContactSense + AdmitTarget）→ L3 chunk 缝合与延迟感知调度（C2Stitch）→ 工程审计层（Audit）**。

一句话：**先让轨迹在动力学上"跑得动"，再让它在接触时"让得起"，最后让它在网络与多机环境下"稳得住"。**

## 2. 瓶颈在哪里（结构性分析，不依赖榜单）

结合官方 32 个任务名（插拔、拧盖/解锁、堆叠、整理、折叠/拉链、双手倒水等）与接口事实，接触密集任务的失败可以拆成五条**机制性**瓶颈，而不是笼统的"泛化不够"：

| 失败机制 | 为什么在 UniBot 上必然出现 | 对应设计 |
|---|---|---|
| **B1 参考动力学不可行** | VLA 输出路点，不管速度/加速度/jerk；接触前的高速逼近 = 冲击 | L1 运动编译器（C3/C4/C5） |
| **B2 chunk 边界 C0/C1 断裂** | 顺序执行、无插值声明；每块独立生成 ⇒ 边界速度/加速度跳变 | L3 C2 缝合（C10），接触相位短 chunk |
| **B3 刚性跟踪导致卡死/力尖峰** | 只有位置目标 ⇒ 误差直接变成穿透与力；插入类任务最敏感 | L2 目标空间导纳（C7/C8） |
| **B4 接触不可见** | 无 FT/触觉；只能从残差/视觉/夹爪推断 | L2 接触信念（C6）+ 相对力代理 |
| **B5 延迟/多机异质** | N 台真机、未知控制频率与延迟；一套固定增益不普适 | L0 在线辨识（C2/C12）+ 能量罐（C11） |

**可执行的三条**：

- **T1（唯一货币）**：只优化终态成功；平滑、减速、让步都只是手段，不能自带独立 KPI。
- **T2（接触是主战场）**：插入/旋转/放置类任务对「参考连续性 + 接触柔顺 + 延迟稳定」最敏感，收益也最集中。
- **T3（可观测性诚实）**：不假设力/力矩可测；所有接触量都带置信度，低置信时退回刚性保守策略。

## 3. 研究问题（本轮版）

- **Q1（参考层的柔顺可实现性）**：在只下发位置目标、内环未知的前提下，目标空间导纳 `M_aΔ̈+B_aΔ̇+K_aΔ=ŵ_ext` 能把系统的等效串联刚度降到多少？其稳态等效刚度是否严格满足 `1/K_eff = 1/K_in + 1/K_a`？
- **Q2（无传感器接触可辨识性）**：仅用跟踪残差、腕部视觉滑移、夹爪开合反应与位姿差分，能否估计"接触发生 + 相对力代理 + 卡死"？在什么条件下绝对力**不可**辨识？置信度如何校准？
- **Q3（延迟下的被动性）**：当总延迟 `d` 未知且有抖动时，导纳增益 `K_a`、阻尼 `B_a` 满足什么条件不会自激？能量罐能否给出可证明的被动性边界？
- **Q4（运动编译的收益）**：C2 缝合 + 相位相关时间伸缩，在插入/旋转任务上是否稳定优于固定 chunk、固定速度的基线？代价（超时率、跟踪误差）有多大？
- **Q5（多机与合规）**：N 台机内环不同，在线辨识与适配是否仍属"单模型、单 API"？在线改的是参考生成器而非策略权重，是否天然合规？

## 4. 设计原则

- **P1 单一计分货币**：一切改动必须能写成"提升某任务终态成功率"的因果链；平滑/减速只在能降低冲击或卡死时才保留。
- **P2 参考即接口**：所有控制律都实现为「参考生成/修正」，不假设能命令力矩、刚度或接触力。
- **P3 可观测性诚实**：接触量一律带置信度；不得把相对力代理当绝对力报告；低置信时退回刚性。
- **P4 被动性优先**：任何让步/导纳都必须配能量罐与保守增益；默认形态是"刚性 + 减速"，导纳按需启用。
- **P5 未知者辨识**：`Δt`、延迟、内环增益、死区都先估后用；估不准就退回固定保守参数，不做"信仰式调参"。
- **P6 合规与可信度**：单 checkpoint、单 API；不利用未声明的执行语义；延迟平滑、动作良构、无异常离群。

## 5. 最小可提交闭环（MVP）与退化链

**MVP = IP-01 运动编译器 + IP-03 接触感知 + IP-04 黑箱内环辨识/延迟守卫 + IP-06 柔顺回归台 + 通用 VLA 基线。**
IP-02（目标空间导纳）紧随其后，但必须先由 IP-04 给出安全增益、由 IP-06 给出稳定性证据；IP-05（C2 缝合）先做"零成本探测"确认评测端不做插值再启用。

**严格退化链（任何一环不可用 ⇒ 行为回退而非漂移）**：

- Level-0：辨识失败 ⇒ 固定保守增益、关闭导纳，仅保留减速与限幅；
- Level-1：接触信念置信度低 ⇒ 不介入、刚性执行，只做运动学平滑；
- Level-2：导纳检测到振荡/发散 ⇒ `K_a→0` 冻结让步，退回刚性 + 降速；
- Level-3：C2 缝合与评测端插值冲突 ⇒ 关闭缝合，退回原 chunk；
- Level-4：整条链路失效 ⇒ 退回纯基线策略（始终保留一份能跑通、可信度合规的最小提交作安全网）。

## 6. 预期贡献（可验收）

1. **把"柔顺"从不可用通道变成参考层的可计算对象**：给出位置接口下的目标空间导纳形式、稳态等效刚度公式 `1/K_eff=1/K_in+1/K_a`，以及在未知内环下的保守整定规则。
2. **给出无传感器接触感知的可辨识性边界**：明确"相对力代理可辨识、绝对力不可辨识"，并交付带校准曲线的接触信念与卡死检测器。
3. **把 chunk 边界从工程细节升级为一级失效源**：用 C2 缝合 + 相位相关时间伸缩，量化边界冲击的下降与成功率收益。
4. **对多机异质给出可复现的稳定性证据**：用延迟/增益扫描的回归台 + 能量罐被动性证书，替代"在 3 台机上试出来"的经验主义。
5. **一套可复用的"运动—柔顺"回归台**：把官方数据回放、黑箱内环模型、延迟注入与失败分解组合起来，让后续每轮不依赖真机时段。

## 7. 本轮最大风险

**一句话**：本方案的命门是「在只有位置目标、没有力/力矩反馈、且内环增益与延迟未知」的条件下，**目标空间导纳可能既降不下真实接触力、又在延迟下自激**——它只是参考层的一厢情愿，若内环本身很硬或评测端自带平滑，我们把"更柔顺"做成"更抖/更慢"，反而比刚性基线更差。

## 8. 下一轮迭代计划（深化与修剪，不推倒重来）

- **深化**：把接触信念从二值升级为「接触相位 × 卡死 × 滑移」三状态，并用它驱动搜索原语（螺旋/抖动）与时间伸缩；把能量罐从"状态量"升级为可导出的稳定性证书。
- **修剪预案**：若 E801（辨识）在真机上无法把延迟误差压到 1 个控制步内，或 E808（延迟鲁棒性）显示安全 `K_a` 区域为空，则**关闭导纳主线**，只保留运动编译器 + C2 缝合 + 减速（它们不依赖力观测），把"柔顺"降级为"保守刚性"。
- **保留项**：IP-01（运动编译器）、IP-03（接触感知）、IP-04（辨识/延迟守卫）、IP-06（回归台）在任何情况下不砍；IP-02 的启用必须以 M4 的被动性条件与 E806 的振荡率为闸门。

## 0. 本轮结论摘要

**一句话路线**：把 UniBot 的成功率问题重新表述为「**参考轨迹在未知位置内环下的动力学可行性 + 接触时的参考让步 + 延迟下的稳定性**」问题，交付一个不依赖力/力矩通道、可在 N 台异质真机上退化运行的单策略执行层。

**三条结构性依据（不依赖榜单）**：

| 依据（接口/数据可直接确认） | 对设计的强制约束 |
|---|---|
| 观测无速度/力矩/力/触觉，动作为位置目标 | 柔顺只能实现为**参考层导纳**；接触量只能间接推断；绝对力不可辨识（M5） |
| chunk 顺序执行，插值/平滑/控制频率均未声明 | chunk 边界最多 C0；必须先辨识 `Δt`、延迟与内环语义，再谈时序优化（M1/M8） |
| N 台真机、随机顺序、共享后端 | 内环增益/延迟可能逐机不同；固定导纳增益不安全，必须在线辨识 + 能量罐（M4） |

**合规红线（P6）**：单 checkpoint、单 API；运动/柔顺层只做**参考变换**，不训练多个策略；不读取评测侧私有信息；不利用未声明的插值/重置语义；不按任务名硬编码分支（只用语言 embedding 做软条件）。

| **IP-05** | C2Stitch 二次连续 chunk 缝合 | **P1** | 用五次 Hermite/B 样条匹配位置/速度/加速度，消除边界冲击 | 评测端不做插值（须探测） | 边界加速度跳变 ↓≥80%；jerk p99 ↓≥50%；端点漂移 <1 mm |
| **IP-06** | ComplianceBench 运动—柔顺回归台 | **P0** | 用官方数据回放 + 可配置黑箱内环 + 延迟注入做稳定性/收益回归 | 官方数据 | 与真机方向一致率 ≥0.7；能复现振荡/卡死 |
| **IP-07** | YieldResume 人为干扰下的让位与恢复 | **P1** | 识别"非指令性大残差"→ 让位 → 干扰消失后恢复计划 | IP-03/IP-04 | 干扰场景成功率相对 +≥15%；不误触发正常接触 |
| **IP-08** | WholeBodyCompliance 下肢/枢轴协同（P2） | P2 | 用 pivot/lower_body 扩展可达并吸收反力 | 语义实测 | 边界任务可达率提升；不引入抖动；否则关闭 |

> **P0 = 本轮 MVP**（IP-01/02/03/04/06）；**P1 = 通过稳定性闸门后推进**；**P2 = 零成本探测后再定**。

## 2. 创新点详述

### IP-01 · MotionCompiler 运动编译器（P0）

- **动机**：VLA 输出的是"看起来对"的路点，但真机执行的是"参考 + 内环 + 延迟"的闭环；接触瞬间的失败往往不是位置错，而是速度/加速度不可行（B1）。排行榜只按成功计分，时间有富余（引理 M2），因此可以主动减速换稳定。
- **与现有方案的差异**：常见做法是直接把策略输出的位置序列下发给评测端；我们把它当作**建议路点**，在其后插入一个确定性的编译层：①五次样条插值；②投影到速度/加速度/jerk 约束集；③按接触相位做单调时间伸缩（接近/接触前减速，自由空间加速）；④保持端点精确可达（M6）。
- **技术可行性**：高。纯几何/数值，不需要训练，不需要力反馈；输入是动作 chunk 与相位信念，输出仍是同形状位置目标。
- **落地步骤**：①从官方数据统计各类任务的关节/EE 速度、加速度、jerk 分布，得到保守限幅；②实现 C2 样条 + 约束投影 + 单调时间伸缩；③相位来自 IP-03；④在 IP-06 回归台上做"编译前/后"对照；⑤真机 A/B 只在插入/旋转/放置族上做。
- **风险**：①过度平滑会降低纠错带宽（见 E814）；②时间伸缩可能触发超时（E819）；③若评测端另有平滑，编译收益被摊薄 ⇒ 用回归台 + 真机 A/B 决定启用强度。

### IP-02 · AdmitTarget 目标空间导纳（P0）

- **动机**：位置接口下，刚性跟踪把位置误差直接变成穿透与接触力（B3）；插入/拧盖/放置需要"让"。既然不能命令力矩，就让**参考对测量让步**。
- **与现有方案的差异**：多数提交只做位置跟踪或简单限速；我们把导纳显式写在**参考层**：`M_aΔ̈+B_aΔ̇+K_aΔ=ŵ_ext`，其中 `Δ` 是参考的让步位移，`ŵ_ext` 是**力代理**（由 IP-03 给出）。稳态给出严格的串联柔顺 `1/K_eff=1/K_in+1/K_a`（M3），因此"更软"有可计算的物理含义，而不是拍脑袋的滤波。
- **技术可行性**：中–高，但**必须**与 IP-04（安全增益）和能量罐（C11）绑定，否则延迟下会自激（§6 玩具自证：2 ms 延迟即可把 2.5 N 平滑接触变成 ~10.5 N 抖振）。
- **落地步骤**：①一维/三维导纳离散实现；②用 IP-04 估 `K_in` 代理与延迟；③按 M4 的小增益条件选 `K_a,B_a`；④能量罐限幅；⑤卡死时叠加螺旋/抖动搜索（C9）；⑥振荡检测 → 冻结让步回刚性。
- **风险**：①**延迟自激**（最大）；②`K_in` 估错导致实际力不降反升；③让步过大导致"够不到/插不进" ⇒ 设 `Δ_max` 与进度闸门；④力代理噪声导致抖动 ⇒ 低通 + 滞回。

### IP-03 · ContactSense 无传感器接触感知（P0）

- **动机**：没有 FT / 触觉 / 力矩（B4），但接口给了 4 路视觉、EE 位姿、关节位置、夹爪开合的历史，足以间接判断"接触/卡死/滑移"。
- **与现有方案的差异**：常见方案把抓取/接触当作策略隐式学习；我们把接触变成**显式、带校准置信度的观测量**，并且明确它的可辨识边界（M5：相对力可辨识，绝对力不可辨识）。
- **技术可行性**：高。四类信号：①跟踪残差 `r=x_meas−x_ref`（指令在动、实测不动 ⇒ 受阻）；②腕部视觉的物体相对位移/遮挡/滑移；③夹爪开合与指令的偏差及其导数；④位姿差分得到的加速度不连续。用轻量时序模型（TCN/GRU）融合，输出 `c_t`、卡死标志、滑移方向。
- **落地步骤**：①从官方数据伪标接触段（指令与实测的残差持续 + 视觉相对运动停止）；②训练 + 温度校准；③可靠性图与阈值；④只在 `c_t` 高置信时驱动导纳/搜索；⑤低置信一律退回刚性。
- **风险**：①残差受内环跟踪误差与模型误差混淆（M5）⇒ 必须做"空载基线"扣除；②未见物体的视觉滑移不可靠 ⇒ 用残差为主、视觉为辅；③伪标噪声 ⇒ 双标注器一致性检查。

### IP-04 · PlantID + LatencyGuard 黑箱辨识与延迟守卫（P0）

- **动机**：`Δt`、延迟、内环增益、死区都未声明，且 N 台机可能不同（B5）。不辨识就调导纳 = 赌博。
- **与现有方案的差异**：多数队伍把控制频率/延迟当作常数假设；我们把它们当作**必须在线估计的状态**，并把估计结果同时用于：导纳整定、chunk 长度调度、延迟补偿与审计。
- **技术可行性**：中–高。可用安全的"自由空间微激励"（小幅、低频、限幅）估计 `Δt` 与延迟；用"指令阶跃 vs 实测响应"估一阶增益/时间常数/死区；接触时只能估**相对**刚度（M5）。所有激励都受限幅与安全包络约束。
- **落地步骤**：①自由空间微激励协议（不接触物体）；②一阶/二阶系统辨识 + 延迟互相关；③输出带不确定度的参数；④安全整定规则（M4）；⑤延迟感知 chunk 调度（C12）；⑥参数不确定度大 ⇒ 回退固定保守值。
- **风险**：①激励本身扰动任务（E815 量化）；②辨识偏差导致不安全增益；③延迟抖动非平稳 ⇒ 用分位数而非均值；④跨 episode 辨识是否合规 ⇒ 只改参考生成器参数，不改策略权重（Q5）。

### IP-05 · C2Stitch 二次连续 chunk 缝合（P1）

- **动机**：chunk 顺序执行、无插值声明（B2）；边界速度/加速度跳变在接触瞬间最致命。旧稿只做 C0/C1，本轮升级为 C2。
- **与现有方案的差异**：常见做法是固定 chunk、首尾拼接或线性外推；我们用五次 Hermite/B 样条在边界同时匹配位置、速度、加速度，再做约束投影；并按相位自适应 `T_a`（接触相位 1–4，自由空间 8–16）。
- **技术可行性**：中。必须先确认评测端不做跨 chunk 插值（否则叠加）；纯参考层实现。
- **落地步骤**：①用官方 `run_client.py` 探测 chunk 执行语义；②实现 C2 缝合；③相位自适应 `T_a`；④边界连续性断言与审计；⑤真机 A/B 决定默认开关。
- **风险**：①评测端自带平滑 ⇒ 叠加抖动（默认关，探测后再开）；②短 chunk 增加调用次数 ⇒ 延迟压力（IP-04/E808）；③过平滑降低带宽（E814）。

### IP-06 · ComplianceBench 运动—柔顺回归台（P0）

- **动机**：真机时段稀缺，榜单不可复核；没有可信的回归台，运动/柔顺参数无法迭代，也无法证明稳定性。
- **与现有方案的差异**：不是"仿真器里刷分"，而是**可配置的黑箱内环回归台**：用官方数据回放作为参考/视觉输入，用一族二阶位置内环（不同 `K_in,B_in`、延迟、死区、插值开关）模拟评测端，输出成功率方向、振荡率、跟踪误差与失败分类。
- **技术可行性**：中–高。数据齐备；难点是"与真机方向一致"，需少量真机锚点标定。
- **落地步骤**：①解析官方数据，提取动作/观测序列；②实现可配置内环 + 延迟注入；③定义指标（接触力代理、卡死率、边界冲击、振荡率）；④真机锚点标定（方向一致率）；⑤作为其他 IP 的"稳定性闸门"。
- **风险**：①回归台与真机相关性不足 ⇒ 只用于**否决**（发现振荡/发散），不用于**择优**；②内环模型过简 ⇒ 用参数扫描覆盖不确定性，而非拟合单一模型。

### IP-07 · YieldResume 人为干扰下的让位与恢复（P1）

- **动机**：5 类泛化场景含"人为干扰"；刚性策略在被人推/挡时会硬顶，既危险又容易把物体撞飞。
- **与现有方案的差异**：把"外部扰动"与"自身接触"区分开（前者残差方向与指令无关、且视觉可见人/物体运动），触发**让位**（导纳软化 + 暂停推进），扰动消失后**恢复**原计划而非重新规划。
- **技术可行性**：中。依赖 IP-03 的残差分解与 IP-02 的让步能力。
- **落地步骤**：①扰动检测器；②让位状态机（C13 的 YIELD）；③恢复条件与重试上限；④真机干扰脚本 A/B。
- **风险**：①误把正常接触当干扰 ⇒ 用方向/视觉一致性区分；②让位后超时 ⇒ 恢复优先、限时。

### IP-08 · WholeBodyCompliance 下肢/枢轴协同（P2）

- **动机**：桌面任务也有可达性边界；`action.pivot`(7) 与 `lower_body`(15) 存在于接口，可用于扩可达、吸收反力。
- **与现有方案的差异**：多数方案把 pivot 写常量；我们把下肢当作"反力吸收器 + 可达性扩展"，但仍以手臂为主。
- **技术可行性**：低–中。pivot 语义未声明，可能被忽略或引入抖动。
- **落地步骤**：①零成本探测（发微小 pivot 看是否被跟踪）；②仅当被跟踪且不抖时启用；③用先验约束避免大幅动作。
- **风险**：收益可能为 0；语义未知 ⇒ 默认保持常量，探测后再定。

## 3. 符号与定义（C1–C14）

| 符号 | 含义 |
|---|---|
| `G` | 未知黑箱内环：位置参考序列 → 实测状态序列 |
| `Δt` | 一个 action step 的真实时长（未知，需辨识） |
| `d` | 参考到实测的总延迟（控制步数） |
| `x_d` | 运动编译器输出的期望参考 |
| `x_ref` | 实际下发的参考（= `x_d + Δ`） |
| `x_meas` | 实测 EE 位姿 / 关节位置 |
| `r` | 跟踪残差 `x_meas − x_ref` |
| `c_t` | 接触信念 `P(contact | y_{t−k:t}) ∈ [0,1]` |
| `ŵ_ext` | 外部接触力代理（非绝对力） |
| `Δ` | 导纳让步位移 |
| `K_in, B_in` | 未知内环等效刚度 / 阻尼 |
| `K_a, B_a, M_a` | 导纳虚拟刚度 / 阻尼 / 惯量 |
| `K_eff` | 串联等效刚度 `(K_in K_a)/(K_in+K_a)` |
| `p̂` | 估计穿透/变形量 |
| `T_a` | action chunk 长度（官方 `action_chunk_size`） |
| `z_phase` | 相位 ∈ {free, approach, contact, search, insert, release, yield, degraded} |
| `E_t` | 能量罐余量 |
| `σ(·)` | 接触平面搜索策略（螺旋/抖动） |

**定义 C1（控制步时间）** 设一次 `get_action` 后的第 `k` 个 action step 对应真实时刻 `t_k = t_0 + k·Δt + ε_k`，`Δt>0` 未知，`ε_k` 为抖动。所有速度/加速度在未标定时以「每步」为单位；需要物理单位时用 `Δt̂` 换算。

**定义 C2（黑箱内环）** `x_meas[k] = G({x_ref[j]}_{j≤k−d}, x_meas[k−1], …)`，其中 `G` 含未知的等效刚度 `K_in`、阻尼 `B_in`、死区、饱和与可能的内部插值；**不对 `G` 做任何线性/无延迟假设**。

**定义 C3（运动编译器）** `MC: (W, z_phase) → x_d(·)`，`W={ (x_i, t_i) }` 为路点。要求：①`x_d(t_i)=x_i`（端点精确）；②`x_d ∈ C²`；③`|ẋ_d|≤v_max, |ẍ_d|≤a_max, |x⃛_d|≤j_max`。

**定义 C4（可行轨迹集）** `𝒯 = { x(·) | x∈C², |ẋ|≤v_max, |ẍ|≤a_max, |x⃛|≤j_max }`，`MC` 输出为 `W` 在 `𝒯` 上的可行插值/投影。

**定义 C5（相位相关时间伸缩）** `ds/dt = ρ(z_phase) ∈ [ρ_min,1]`，`s` 为弧长参数；`ρ` 在 free/approach 取大、在 contact/search/insert 取小；伸缩保持端点与单调性。

**定义 C6（接触代理观测量）** `y_t = (r_t, s_t, g_t, ν_t)`：`r` 跟踪残差，`s` 腕部视觉的物体相对位移/滑移，`g` 夹爪开合与指令的偏差及其导数，`ν` 由位姿历史得到的加速度不连续量。接触信念 `c_t = P(contact | y_{t−k:t})`。

**定义 C7（目标空间导纳）** 以期望参考 `x_d` 为平衡点，让步 `Δ` 满足
`M_a Δ̈ + B_a Δ̇ + K_a Δ = ŵ_ext`，
并对 `Δ` 施加 `‖Δ‖≤Δ_max`、速度/加速度限幅与能量罐约束；实际下发 `x_ref = x_d + Δ`。

**定义 C8（力代理与穿透预算）** `ŵ_ext = −K̂_c · p̂`（方向由残差/视觉给出），`K̂_c` 为接触刚度代理；安全约束以 `p̂≤p_max` 与 `‖Δ‖≤Δ_max` 为主，**不以绝对力为主**（M5）。

**定义 C9（接触相搜索）** 当 `c_t` 高且进度停滞（`‖r‖` 持续大、`dx_meas/dt≈0`）时，在接触平面叠加 `σ(t)=a_t·(cos ωt, sin ωt)`（或 Lissajous），幅度 `a_t ∝ ‖ŵ_ext‖` 并受 `a_max` 限；用于替代刚性的"硬怼"。

**定义 C10（C2 缝合）** 设上一块末端状态 `(x_T, ẋ_T, ẍ_T)`，新块路点 `W⁺`。构造五次 Hermite/五次 B 样条段 `h(τ)` 使 `h(0)=x_T, ḣ(0)=ẋ_T, ḧ(0)=ẍ_T`，并在新块首路点匹配位置/速度/加速度；再重采样为 `T_a` 步。

**定义 C11（被动性能量罐）** `E_t ≥ 0`；每步注入 `E_in = Δᵀ ŵ_ext`，经 `B_a` 耗散 `E_out`；若 `E_in > E_t + E_out`，按 `γ=(E_t+E_out)/E_in` 缩放 `Δ`（或冻结导纳），保证参考端口不向系统净注能。

**定义 C12（延迟感知调度）** 给定延迟分位数 `(p50,p99)` 与相位，选 `T_a(z_phase)` 与执行视界 `H`：接触相位 `T_a∈[1,4]` 以保反馈带宽，自由空间 `T_a∈[8,16]` 以降开销；并满足 `H·Δt̂ ≥ p99 + margin`。

**定义 C13（安全状态机）** `z_phase ∈ {FREE, APPROACH, CONTACT, SEARCH, INSERT, RETREAT, YIELD, DEGRADED}`；转移由 `c_t`、`r`、`ŵ_ext`、进度与振荡检测驱动；每个状态有独立的 `Δ_max`、速度上限与超时。

**定义 C14（合规单策略）** `π` 为单一 checkpoint/单一 API；运动编译器、导纳、缝合、调度都是围绕 `π` 的**确定性参考变换**，不引入按任务名的硬编码分支（条件只用语言 embedding 与在线观测）。

        if s.need_id and self.fsm.is_free(obs):
            self.pid.probe(obs)                          # IP-04

        # 1) 接触信念 + 相对力代理
        c, w_hat, slip = self.cs(obs, s)                 # IP-03

        # 2) 相位与安全状态
        z = self.fsm.update(c, w_hat, obs, s)            # C13

        # 3) VLA 输出路点（仍是单一策略）
        W = self.model.waypoints(obs, z)                 # (T_a, dim)

        # 4) 运动编译：C2 + 限幅 + 相位伸缩
        x_d = self.mc.compile(W, z, self.pid.dt_hat)     # IP-01

        # 5) 目标空间导纳：仅在接触/搜索/插入且高置信时让步
        if z in ("CONTACT", "SEARCH", "INSERT", "YIELD") and c > self.tau_c:
            Delta = self.adm.step(w_hat, self.pid.delay_hat)  # IP-02
            Delta = self.tank.limit(Delta, w_hat)              # C11
            x_ref = x_d + Delta
        else:
            x_ref = x_d

        # 6) C2 缝合（探测到评测端不插值才启用）
        x_ref = self.st.stitch(x_ref, s.last_ref_state)  # IP-05

        # 7) 延迟守卫 + 调度（U12/C12）
        T_a = self.schedule(z, self.pid.latency)
        x_ref, degraded = self.latency_guard(x_ref, T_a, t0)
        s.last_ref_state = derivative_state(x_ref)
        return self.pack(x_ref, obs, degraded)

# ===== IP-02：目标空间导纳（离散 + 能量罐）=====
class AdmitTarget:
    def step(self, w_hat, delay_hat):
        # 离散二阶导纳；延迟经 IP-04 估计，按 M4 选增益
        acc = (w_hat - self.B*self.v - self.K*self.d) / self.M
        self.v = self.v + acc*self.dt
        self.d = self.d + self.v*self.dt
        return clip(self.d, -self.d_max, self.d_max)

class EnergyTank:
    def limit(self, d, w_hat):
        e_in = abs(float(np.dot(d, w_hat)))
        if e_in > self.E + self.dissipation(d):
            gamma = (self.E + self.dissipation(d)) / max(e_in, 1e-9)
            d = gamma * d
            self.frozen = True
        self.E = max(0.0, self.E + self.dissipation(d) - e_in)
        return d

class C2Stitcher:

## 5. 推导（引理 M1–M8）

**引理 M1（C2 缝合消除边界加速度跳变）** 设上一块末端速度为 `v⁻`、新块首端速度为 `v⁺`。C0 拼接产生速度跳变 `δv=‖v⁺−v⁻‖`，在步长 `Δt` 下加速度量级 `≈δv/Δt`，jerk 量级 `≈δv/Δt²`；C1 拼接消除速度跳变但保留加速度跳变 `δa`，jerk `≈δa/Δt`；C2 拼接使 `δv=0, δa=0`，jerk 由两段的最大 `|x⃛|` 界定，不再含 `1/Δt` 的奇异放大。⇒ 接触瞬间的冲击注入随连续性阶数单调下降。∎

**引理 M2（时间伸缩的收益条件）** 设接触相位的成功率 `S(ρ)` 关于速度比例 `ρ` 单调不增，且任务时限 `T_lim` 满足 `T_base/ρ_min + margin ≤ T_lim`。则把 `ρ` 从 1 降到 `ρ_min` 有 `S(ρ_min) ≥ S(1)`，且计分不变（只按成功），代价仅为时间；若时限绑定，则需在 `S` 的增益与超时风险之间权衡。∎

**引理 M3（目标空间导纳的串联等效刚度）** 设内环在接触平衡处可近似为刚度 `K_in` 的位置伺服，接触环境刚度为 `K_c`，标称穿透 `δ0=x_d−x_env`。导纳稳态满足 `K_a(x_ref−x_d)=−K_c p`，内环平衡满足 `K_in(x_ref−x)=−K_c p`，且 `x=x_env+p`。解得
`p = δ0 / [1 + K_c(1/K_in + 1/K_a)]`，
即 `K_eff=(K_in K_a)/(K_in+K_a)` 为 `K_in` 与 `K_a` 的**串联**刚度；`K_a` 越小，`K_eff` 越小，稳态接触力代理 `K_c p` 越小。∎
（注：该式只在"内环可用刚度近似"的平衡点成立；动态与延迟下需 M4。）

**引理 M4（延迟下的被动性设计条件）** 离散导纳在总延迟 `d` 步下，每步向被控系统注入的能量上界为 `~½K_eff‖Δ_k−Δ_{k−d}‖²`。若能量罐以 `B_a` 耗散且每步满足 `½K_eff‖Δ_k−Δ_{k−d}‖² ≤ E_t`，则参考端口被动，系统不会通过导纳通道净获能。工程化保守规则：选 `K_a,B_a` 使 `(K_c/K_eff)·(ω_a d Δt) < 1`（小增益），并始终保留能量罐与振荡检测兜底。∎
（§6 玩具自检：不满足该条件时，2 ms 延迟即可出现 ~10.5 N 峰峰抖振。）

**引理 M5（无传感器下的可辨识性边界）** 仅观测位置时，三元组 `(K_in, K_c, F_ext)` 不可分别辨识：对任意 `λ>0`，`(λK_in, λK_c, λF_ext)` 在同一参考与同一实测位移下给出相同的观测。可辨识的只有**比值/相对变化**（例如同一参考扰动下 `ΔF/F` 或 `Δp/Δx_d`），以及在已知激励下的局部刚度代理。⇒ 不允许声称绝对接触力；导纳指标必须是相对量；`K̂_c` 只能作为带不确定度的先验。∎

**引理 M6（C2 缝合的端点保持）** 若缝合段 `h(τ)` 满足 `h(0)=x_T` 且新块首点满足 `h(τ_1)=x_1`，重采样为单调序列，则缝合后端点位置不变，误差不累积；对比之下，一阶外推 `x_T+Δt·v` 会因 `v` 估计误差产生累积漂移。∎

**引理 M7（穿透预算 ⇒ 力代理上界）** 若系统强制 `p̂≤p_max` 且 `K̂_c` 取保守上界 `K̄_c`，则力代理 `‖ŵ_ext‖≤K̄_c·p_max`。由于 `K̂_c` 的不确定度（M5），真正可靠的安全旋钮是 `p_max` 与 `Δ_max`，而不是"设定一个力阈值"。∎

**引理 M8（chunk 边界风险随 T_a 与速度单调）** 在"顺序执行、无跨块插值"的语义下，新块首动作与上一块末动作的偏差 `‖a⁺−a⁻‖` 随参考速度与 `T_a`（块越长，重规划越滞后）非减；边界冲击能量 `∝‖a⁺−a⁻‖²`。因此接触相位应取短 `T_a`，自由空间取长 `T_a`。∎

## 6. 玩具级数值自检（机制验证，不是真机证据）

> 目的：验证"机制方向"是否如引理所言，而非估计真实收益。两个玩具都用一维模型；数值不可外推到 G1 真机。

### 6.1 运动编译：线性 / C1 / C2 插值的边界冲击

对一条 30 Hz 路点流（2 s，含两个频率成分），用 1 kHz 差分估计加速度与 jerk：

| 插值方式 | max\|acc\| | p99\|jerk\| | 相对 C2 的 jerk 比 |
|---|---|---|---|
| 分段线性（naive） | 180.98 | 31288.4 | 500× |
| 三次 Hermite（C1） | 16.04 | 959.6 | 15.3× |
| 五次样条（C2） | 4.96 | 62.6 | 1× |

**读法**：C2 相对 C1 把 max|acc| 降约 3.2×、jerk p99 降约 15×；相对 naive 降 36× / 500×。方向支持 M1；绝对数值依赖路点频率与差分步长，不是物理预测。

### 6.2 目标空间导纳：稳态力代理与延迟稳定性

模型：一维质量 `M=1`，内环 PD `K_p=400, K_d=40`，环境弹簧 `K_c=2000`，标称穿透 `δ0=0.02`（刚性稳态力 ≈ 6.67 N）。

| 导纳刚度 `K_a`（无延迟） | 稳态力代理 |
|---|---|
| 刚性（`K_a=∞`） | 6.67 N |
| 2000 | 5.71 N |
| 1000 | 5.00 N |
| 500 | 4.00 N |
| 200 | 2.50 N |
| 100 | 1.54 N |

**读法**：与 M3 的串联柔顺公式一致；`K_a` 越小越软。

**延迟扫描（`K_a=200`）**：

| 延迟 | 稳态力代理（均值） | 峰峰值 |
|---|---|---|
| 0 ms | 2.50 N | 0.00 N |
| 2 ms | 3.26 N | **10.56 N** |
| 4 ms | 4.10 N | 10.55 N |
| 8 ms | 4.65 N | 10.54 N |
| 10 ms | 2.23 N | 10.54 N |
| 20 ms | 6.67 N | 0.03 N（相位巧合，非稳健） |
| 30 ms | 2.75 N | 10.51 N |
| 40 ms | 0.00 N | 0.00 N（脱离接触） |

**读法**：哪怕 2 ms 延迟，未加能量罐/保守整定的导纳也会从"平滑 2.5 N"退化为"~10.5 N 峰峰抖振"，比刚性还差——这正是 M4 与 IP-04 必须前置的原因。20 ms 的"平静"是特定相位巧合，不能当作稳定证据。

**对未知内环增益的鲁棒性（`K_a=200`，无延迟）**：`K_p` 从 100 到 1600 变化时，相对刚性基线的力代理下降为 32% / 48% / 63% / 74% / 82%——**相对收益稳健，绝对力仍不可知**（M5）。

**代理噪声（20% 乘性，无延迟）**：稳态均值仍 2.50 N、峰峰 0.14 N ⇒ 低通 + 滞回足够；但有延迟时噪声会恶化振荡，故仍以能量罐为兜底。

| **合规**：在线改参考生成器是否算"多模型" | 低–中 | 高 | 只改确定性参考变换、不改策略权重；准备"关闭导纳/关闭辨识"的严格形态 |
| **回归台失真** | 中 | 中 | 只用于否决不用于择优；真机锚点标定 |
| **接口事故**（端口/并发/token/reset 隔离） | 中 | 高 | 自动化体检脚本（端口、握手、token、并发、隔离） |

**剪枝预案（下一轮起执行）**：
- **必保**：IP-01（运动编译器）、IP-03（接触感知）、IP-04（辨识/延迟守卫）、IP-06（回归台）。
- **闸门后推进**：IP-02（导纳）——以 M4 + E806 为闸门；不过则降级为"搜索原语 + 减速"的保守柔顺。
- **条件推进**：IP-05（缝合，先探测）、IP-07（让位，仅在干扰场景权重高时）。
- **暂存/默认关**：IP-08（pivot）。

## 12. 本轮最值得押注的创新点（一句话）

**押注 IP-01 + IP-03 + IP-04 的「运动编译 + 接触感知 + 延迟辨识」三角：它们不依赖任何力/力矩通道，只把位置接口下的"参考连续性、接触可见性、延迟可知性"做到位，就已经能直击插入/旋转/放置类任务的最后一环；而 IP-02 的目标空间导纳作为可开关的放大器，只有在被动性闸门通过后才启用——这样即使最坏的"延迟自激"发生，系统也只是退回刚性减速，而不是全盘失效。**
