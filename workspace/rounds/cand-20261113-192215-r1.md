# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「同步定位与建图」×「技能学习」）

> 第 68 轮把「测量可信度」升为一等公民：静态段自标定 + 自监督残差 + 单模型多任务，让系统能回答「我的测量还准吗」。但它自陈的最大风险暴露了一个结构性缺陷：**CALM-RAS 是纯因果、纯被动的**。因果——COF 是带宽 ω_cal 的在线滤波，只解释「此刻」的残差，慢于带宽的缓变故障会被当作漂移「标好」；被动——系统只观测轨迹恰好经过的地方，若某故障方向从未被激励，它在物理上不可辨识（缺乏持续激励），再保守的回退也只是「带着盲区少做少错」。
>
> 本轮两块积木恰好补上这两个缺失的维度：
> - **同步定位与建图（SLAM）** 给出「非因果的长时程记忆」：地图是过去测量的只读锚点，跨 epoch 的语义回环把「此刻是否自洽」升级为「此刻是否仍与过去一致」——标定可以改写当下，却改不了历史锚点。
> - **技能学习** 给出「主动可观测性」：技能是可复用、可组合、带结果契约的行为原语；重执行同一技能于同一上下文 = 天然语义回环（matched pair），不同技能 = 不同工作点（负载/温度/姿态），为辨识提供持续激励；当激励秩亏时，系统还能**合成诊断技能**去主动制造可观测性。
>
> 核心命题：**标定滤掉当下，地图记住过去，技能创造可观测性**——LOOP-RAS（Long-horizon, Outcome-verified, Observability-Probing Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我凭什么相信自己还准**」——答案不是更强的标定，而是可证伪的记忆 + 会试探的动作。

## 0. 直觉与动机

**灵感 1（SLAM → 地图是唯一能揭发慢漂移的非因果记忆）**

直觉：R68 的 COF 是带宽 ω_cal 的因果滤波器，慢于带宽的故障在当下被「标好」。SLAM 的回环闭合提供补集：回环误差是**跨时间**约束。但真正关键的不是「同一趟里的回环」——那只检验自洽，标定能同时污染两端；而是**跨 epoch 的地图差**（map-vs-map loop closure）：epoch 0 的健康地图是只读锚点，epoch 1 的测量再来回环时，差值里包含总偏置变化 Δb。历史锚点不可被重写 ⇒ 标定无法通过「把过去也标一遍」把故障洗掉。

数学直觉：`m_t = h(x_t) + c + f(op) + n`。单 epoch 内，回环只看见 `b = c + f`，`c` 与 `f` 共线不可分（正是 R68 盲区）。跨 epoch 看见 `Δb = (c₁ − c₀) + f₁`，但**标定流形 C 低维且与工作点无关，故障 `f(op)` 随工作点变化**。于是用「多工作点的回环族」做联合回归，`c` 与 `f` 的可辨识性等价于回归量列满秩——即持续激励。SLAM 提供「多次重访 = 多工作点采样」，技能学习提供「主动制造工作点差异」。

一句话：**地图不是用来定位的，是用来举证的。**

**灵感 2（技能学习 → 技能是可控激励与可复用对照）**

直觉：技能是「带结果契约（outcome contract）的可复用行为原语」：每个技能记住「在什么上下文、应产生什么结果分布」。三个直接推论：

1. 重执行同一技能于同一上下文 = **语义回环**，天然生成对照实验（matched pair），这正是慢故障检出所需；
2. 不同技能落到不同工作点 = 辨识所需的激励多样性；
3. 当技能库对某故障「秩亏」时，可以**合成新技能**——目标不是完成任务，而是最大化 Fisher 信息。系统由此学会「如何测试自己」，把标定从被动观测升级为主动实验设计。

关键：技能结果契约给出一个**与标定解耦的对照量**。标定改变的是「测量的公共偏置」，契约约束的是「同类行为应产生同类结果」；两者误差结构不同，因而可分离。

**灵感 3（合流 → 按可辨识性分工的三通道）**

不做简单投票，而是**先算零空间，再让探针去填**：

- **因果通道**（COF，继承 R68）：处理标定可解释方向 `b_∥ = P_c b`；
- **记忆通道**（跨 epoch SLC）：处理慢变方向，提供只读锚点对照；
- **主动通道**（DSP 诊断技能）：专门激发标定的**零空间**方向 `b_⊥ = P_⊥ b`，把不可辨识变可辨识。

COF 每步输出标定零空间与条件数 κ_ex；DSP 选择最能提升该方向信噪比的技能；SLC 提供跨时对照；MAD 融合三者做归因。

**灵感 4（七组件）**

1. **SPG Skill–Place Graph**：持久双层因子图（几何层 + 结果层），epoch 分层、append-only，是「记得过去的账本」；
2. **SLC Semantic Loop Closure**：同 (技能, 上下文) 的语义回环；区分 within-epoch（自洽）与 cross-epoch（地图差）；
3. **MAD Map-Anchored Discrimination**：把瞬时残差、跨 epoch 地图差、激励秩三通道融合归因 cal / fault / real；
4. **DSP Diagnostic Skill Policy**：主动实验设计，选「最能降低归因不确定性」的安全探针；
5. **ProbeSynth 探针合成**：激励秩亏时，从技能组合空间合成最大化 Fisher 信息的诊断技能；
6. **PAC Probe-Aware Certification**：在 R68 五关之上加「主动 canary」——用生成式探针验证适配器没把真实故障学会吸收；
7. **RAS-CALM† 继承核**：ACH-RAS / EFS / C-RAS-WM / ERS-WM / MTM / SSG / COF / CFA / CAC 全部保留，仅新增记忆与探针两路，并把归因从单通道升级为三通道。

**灵感 5（对 R66–R68 风险的对症下药）**

- R68「缓变故障被标定吸收」→ append-only 锚点（定义 307）+ 反洗白引理 18 + MAD 第三通道；
- R68「静态 canary 覆盖不足」→ PAC 主动 canary：探针生成式验证适配器是否学会吸收故障；
- R67「WM 黑箱前瞻失真」→ 技能结果契约给 WM 增加行为条件化的独立对照；
- R66「情绪被欺骗」→ 用「社交技能结果的可预测性」作为行为侧证据（探针不能直测情绪，但能测行为一致性）；
- 纪律保留：任何不确定性（含 UNIDENT）只抬升 λ_floor，绝不放宽。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（LOOP-RAS 总览）** LOOP-RAS = (SPG, SLC, MAD, DSP, SOL, PAC, RAS-CALM†)。三不变式：
(i) **记忆不可洗白（append-only）**：标定/学习更新只能追加新节点与新 epoch，历史锚点 (ξ_v, y_v) 只读；任何回写历史的行为视为证据污染并拒绝提交；
(ii) **探针安全**：诊断技能必须可逆、有界、无人物接触、落在安全包络与预算内；违反即不执行；
(iii) **可辨识性披露**：任何归因决策必须附带激励秩/条件数 κ_ex 与状态 IDENT / UNIDENT；秩亏时不得把后验收敛到单一 cause，必须保留 {cal, fault} 稳健集并抬升 λ_floor。

**定义 294（Skill–Place Graph, SPG）** 持久因子图 G_t=(V_t,E_t,X_t)，双层：
- 几何层：位姿/路标因子（经典 SLAM）；
- 结果层：节点 `v=(τ, a, b, ξ_v, y_v, Σ_v, e_v)` 记录时刻、技能 id、上下文桶、几何锚点、结果向量、不确定度、epoch；
- 边 `e=(u,v,Δξ,Ω,a)` 为度量-拓扑转移因子；
- 版本链 X_t 按 epoch 分层，append-only。

**定义 295（技能结果契约 SOL）** 对技能 a 与上下文桶 b，结果模型 `ŷ_ab=μ_θ(a,b), Σ_θ` 由历史学得；契约残差 `e_v = y_v − ŷ_ab`。`y` 含任务成功、接触力矩、终态位姿误差、时长等。契约不是「期望为零」，而是「同类行为在健康系统里可重复」。

**定义 296（语义回环 SLC 与跨 epoch 地图差）** 匹配 `μ: v_t ↦ v_h`，要求同 (a,b) 且地图邻近。回环残差
`ρ_slc(v) = [ξ_v ⊖ ξ_{v_h}; e_v − e_{v_h}]`，协方差由 Σ 传播。
- 同 epoch 回环（within-epoch）：检验地图自洽，对公共偏置 c 不变（引理 18）；
- 跨 epoch 回环（cross-epoch）：检验地图-地图差 Δ_t，慢故障的暴露面在这里。

**定义 297（标定可达子空间与零空间）** 标定映射 `c ↦ r_cal(c)`，雅可比 `J_c=∂r_cal/∂c`（d×12）。投影 `P_c=J_c(J_cᵀJ_c)^{-1}J_cᵀ`，`P_⊥=I−P_c`。偏置变化 b 分解为 `b_∥=P_c b`（可标定）与 `b_⊥=P_⊥ b`（标定零空间）。COF 只能估计 b_∥；R68 的盲区正是 b_⊥ 中的慢变成分。

**定义 298（工作点激励与可辨识矩阵）** 设探针在若干工作点 {op_j} 执行，回归量 `Ψ=[J_c, F(op)]`，其中 `F(op)=∂r/∂θ_f` 随 op 变化。持续激励（PE）条件：`rank(Ψ)=dim(c)+dim(θ_f)` 且 F(op) 的列不落入 span(J_c)。激励质量 `κ_ex=σ_min(Ψ)/σ_max(Ψ)`。可辨识 ⇔ `κ_ex ≥ κ_min`。
注：若某故障在所有工作点都与标定同向（b_⊥≈0 且 F 不随 op 变），则它在物理上不可辨识——这是定义 298 的退化情形，也是本轮风险的核心。

**定义 299（诊断技能与信息增益）** 诊断技能 `π_d∈Π`，执行结果 y。价值 `V(π_d)=I(Θ_cause; y | ℋ, π_d)=H(Θ)−E[H(Θ|y)]`。诊断策略 π_probe 在安全包络内最大化 V，即主动贝叶斯实验设计 / 主动 SLAM。

**定义 300（探针安全包络与预算）** 探针须满足：状态/力矩扰动有界、`T_rev` 内可逆、无人物接触、能耗与磨损 ≤ `B_probe`/小时。若包络内无信息量足够的探针，返回 UNIDENT 并抬升 λ_floor（只抬不降）。

**定义 301（探针合成 ProbeSynth）** 当 `κ_ex<κ_min` 且存在故障嫌疑时，在组合空间 `Π_comp` 上求解
`π_new = argmax_{π∈Π_comp} tr(Fisher(θ_f; π))`，约束 `π∈安全包络`。
F 为关于故障参数的 Fisher 信息。合成出的技能进入技能库，经 PAC 认证后可用。

**定义 302（Skill–SLAM 联合目标）**
`L_LOOP = L_SLAM(位姿图) + λ_y·L_contract(结果契约) + λ_p·L_probe(认知回报) + λ_mt·L_MT(继承 R68)`。
其中 `L_probe` 给予「制造有效回环 / 提升 κ_ex」的辅助回报，使探索主动生成 SLAM 所需的重访——**技能学习为 SLAM 供给回环，SLAM 为技能结果供给可归因的几何**。

**定义 303（地图锚定归因 MAD）** 三通道融合：
`P(cause | r_t, ρ_slc, κ_ex) ∝ p(r_t | cause, ĉ) · p(ρ_slc | cause, κ_ex) · P(cause)`，
其中 `p(r_t|cause,ĉ)` 继承 R68 CFA；`p(ρ_slc|cal)` 在 `κ_ex<κ_min` 时取平坦（不可归因），`κ_ex` 高时用 b_⊥ 的 op-回归残差；`p(ρ_slc|fault)` 用变化签名（定义 304）。

**定义 304（空间-频谱变化签名）** 地图差 Δ 分解为：
- 平滑全局 warp（低空间频、与 J_c 对齐）→ cal；
- 与工作点相关的中等尺度结构畸变（op-correlated）→ fault；
- 稀疏、物体状、语义连贯（高频、紧支撑）→ real world change。
签名 `s(Δ)=(E_smooth, Corr(Δ,op), Sparsity/Semantic)`，给 `p(cause|s)` 作先验。

**定义 305（PAC 主动 canary）** 继承 R68 五关，追加第六关 **active-probe gate**：让候选适配器 M′ 执行针对其疑似吸收方向的诊断技能集 D_probe，要求 `‖b_⊥(M′)‖ ≥ 0.7·‖b_⊥(M)‖`（M′ 没把真实故障「学会吸收」），否则一票否决。静态 canary 升级为**生成式 canary**。

**定义 306（J_LOOP 证书）** `J_LOOP=(J_CALM, map_version_hash, κ_ex, probe_log_hash, identifiability∈{IDENT,UNIDENT}, slc_stats, loop_ver)`。Valid ⇔ Valid(J_CALM) ∧ (`κ_ex≥κ_min` ∨ (identifiability=UNIDENT ∧ λ_floor 已抬升)) ∧ 探针安全未越界 ∧ append-only 未被违反。

**定义 307（append-only 锚点不变式）** 每次更新 `V_{t−1}→V_t` 保持历史节点的 `(ξ_v,y_v,Σ_v)` 不变，只允许新增节点/边与 epoch 元数据。形式化：对任意 `e<current` 的节点 `v∈V_e`，写入后 `ξ_v,y_v` 逐位相等。这是「反洗白」的操作性定义。

**定义 308（回环可辨识性增益）** 有 `n_slc` 个跨 epoch matched pairs 时，可辨识误差 `~ σ_noise/(√n_slc·κ_ex)`。技能复用提高 n_slc，主动探针提高 κ_ex，二者共同压低误差——**技能学习同时攻击两个因子**。

**定义 309（频带与时标互补）** 时间常数为 τ_f 的故障在跨 epoch SLC 中的演化比例为 `1−e^{−Δt_slc/τ_f}`，可检当 `τ_f ≲ Δt_slc`；R68 的 COF 可检 `τ_f ≲ 1/(3ω_cal)`。故双通道覆盖 `τ_f ≤ max(Δt_slc, 1/(3ω_cal))`；当 `Δt_slc ≥ 1/(3ω_cal)` 时两带重叠、无缝隙（引理 17）。

**定义 310（UNIDENT 回退）** 若 `κ_ex<κ_min` 且无安全探针：状态=UNIDENT；`λ_floor←max(0.8, λ_floor)`；`k←min(k,k_unident)`；cause 后验保留 `{cal,fault}` 稳健集；任何下游决策不得以「已标定」为由放宽。

# IP-253 SPG：持久技能-地点图（append-only）
class SkillPlaceGraph:
    def __init__(self):
        self.V = {}; self.E = []; self.epoch = 0; self.frozen = set()
    def append(self, node):
        assert node.vid not in self.frozen          # 历史锚点只读
        self.V[node.vid] = node
    def match(self, a, b, xi, k=3):
        idx = self.index[a, b]                       # 按(技能,上下文)分桶
        return idx.query(xi, k)                      # 近似最近邻（位姿描述子）

# IP-255 SLC：语义回环残差（同 epoch / 跨 epoch）
def semantic_loop_closure(spg, v_new, Jc):
    v_h = spg.match(v_new.a, v_new.b, v_new.xi, k=1)
    r_pose = se3_log(v_new.xi.inv() * v_h.xi)
    r_out  = v_new.y - v_h.y
    r = concat([r_pose, r_out])                     # 定义 296
    if v_h.epoch == v_new.epoch:
        return r, 'within'                           # 对公共偏置不变
    b_par = project_cal(r, Jc); b_perp = r - b_par  # 定义 297
    return b_perp, 'cross'                           # 慢故障暴露面

# IP-256 MAD：地图锚定的三通道归因
def map_anchored_discrimination(r_t, rho_slc, kappa_ex, cal_post):
    p_cal   = cal_post['cal'] * (1.0 if kappa_ex < K_MIN else
                                 gaussian(rho_slc, R_cal))
    p_fault = cal_post['fault'] * change_signature_likelihood(rho_slc)  # 定义 304
    if kappa_ex < K_MIN:                             # 不可辨识：不坍缩到 cal
        return robust_set({'cal': p_cal, 'fault': p_fault})
    return normalize({'cal': p_cal, 'fault': p_fault, 'real': p_real})

# IP-257 DSP：诊断技能策略（主动实验设计）
def choose_probe(theta_belief, pi_lib, envelope, budget):
    cands = [p for p in pi_lib if envelope.admits(p) and budget.ok(p)]
    scored = [(expected_info_gain(theta_belief, p), p) for p in cands]
    best = max(scored, key=lambda t: t[0])
    return best[1] if best[0] >= TAU_VOI else None   # 无收益则 UNIDENT

# IP-258 ProbeSynth：激励秩亏时合成新探针
def synthesize_probe(theta_f, pi_lib, envelope):
    def neg_fisher(pi): return -fisher_info(theta_f, pi)
    return compose_search(pi_lib, neg_fisher, constraint=envelope)  # 定义 301

# IP-259 PAC：六关认证（含主动 canary）
class ProbeAwareCertification:
    GATES = [gold_regression, auditbuf_replay, tv_bound, risk_bound,
             canary_unfixable, active_probe_gate]
    def active_probe_gate(self, M_shadow, M_live):
        D = diagnostic_probes(M_live.spg)            # 生成式 canary
        b_new = aggregate(b_perp(M_shadow, D))
        b_old = aggregate(b_perp(M_live,   D))
        return norm(b_new) >= 0.7 * norm(b_old)      # 未吸收真实故障

# IP-262 主闭环：LOOP-RAS round
def LOOP_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)                        # 继承 R68：一次前向五头
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    r = residuals(x_prime, o, M.wm_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))   # 因果通道
    Jc = M.cof.jacobian()
    kappa_ex = M.spg.excitation_rank(M.probe_log, Jc)
    # 记忆通道
    v_new = M.spg.new_node(M.a_prev, M.ctx_bucket, M.pose, o['outcome'])
    rho_slc, kind = semantic_loop_closure(M.spg, v_new, Jc)
    # 主动通道
    if kappa_ex < K_MIN and M.suspect_fault:
        probe = M.dsp.choose_probe(M.cause_belief, M.skill_lib, M.envelope, M.budget)
        if probe is None:
            probe = M.synth.synthesize(M.fault_params, M.skill_lib, M.envelope)
        if probe is not None:
            y = M.executor.run(probe); M.probe_log.append(probe, y)
            kappa_ex = M.spg.excitation_rank(M.probe_log, Jc)   # 更新秩
    # 归因 + 风险
    rho = M.fir_signature(z, M.residual_log)
    joint = M.mad(r, rho_slc, kappa_ex, M.cfa(rho, o['pi'], c, U))
    if kappa_ex < K_MIN:
        lam = max(M.efs.risk_scale(joint), 0.8)      # UNIDENT：只抬不降
    else:
        lam = max(M.efs.risk_scale(joint), thr['lam_floor'])
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime), joint, M.m_ras)
    M.spg.append(v_new)                              # append-only 提交
    M.pac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint, (c, U, kappa_ex)
```

## 3. 推导

**引理 16（慢故障可辨识性）** 测量模型 `r(op)=J_c δc + F(op) θ_f + n`。若在探针集 {op_j} 上联合回归量 `Ψ=[J_c,F(op)]` 列满秩、最小奇异值 `σ_min(Ψ)>0`，则 `(δc,θ_f)` 可辨识，误差上界 `E‖θ̂_f−θ_f‖ ≤ σ_noise/σ_min(Ψ)`。若 `rank(Ψ)<dim(c)+dim(θ_f)`（激励秩亏），则存在不可辨识方向，且该方向恰为 R68 的盲区。系：**R68 的失败不是缺陷而是秩亏特例**；技能多样性/探针正是提升 `σ_min(Ψ)` 的手段（κ_ex 定义 298）。

**引理 17（双通道频带互补覆盖）** COF 对 `τ_f≤1/(3ω_cal)` 的故障保留 ≥2/3 残差（R68 引理 13）；跨 epoch SLC 对 `τ_f≤Δt_slc` 的故障产生可检的地图差（定义 309）。故双通道覆盖 `τ_f ≤ max(Δt_slc, 1/(3ω_cal))`；当 `Δt_slc ≥ 1/(3ω_cal)≈0.53s` 时两带重叠，任意 `τ_f≤Δt_slc` 的故障至少被一条通道检出。**自标定的盲带被记忆通道填平。**

**引理 18（反洗白）** 设 epoch 0 健康锚点固定（定义 307）。若 epoch 1 某故障 f 被 COF 吸收，即 `r_cal(ĉ₁)≈r_cal(c₀)+f`。跨 epoch 残差 `ρ_slc = P_⊥[r_cal(ĉ₁)−r_cal(c₀)+f] = P_⊥ f`（因 `P_⊥J_c=0`）。故只要 f 不在标定可达子空间（`P_⊥f≠0`），历史锚点就保留一份非零证据，标定无法通过在 epoch 1「重新标定」把它归零。**地图记住了标定忘掉的东西。** 若 `P_⊥f=0`（故障完全落在标定流形内），则需靠工作点依赖（引理 16）——否则物理不可辨识。

**定理 16（LOOP-RAS 慢故障风险一致性）** 在 A92–A94 与定义 298 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_slc+α_probe`；
2. 若 `κ_ex≥κ_min` 且 `Δt_slc≥1/(3ω_cal)`，则慢故障检出概率 `≥ 1−β`（引理 16、17），且误归因到 cal 的概率 `≤ exp(−n_slc·κ_ex²/(2σ²))`；
3. 若 `κ_ex<κ_min`（探针被禁止/预算耗尽），输出 UNIDENT，`λ_risk ≥ 0.8` ∧ k 收缩 ∧ cause 保留 `{cal,fault}` 稳健集——**不可辨识只会收紧，绝不假装已解决**；
4. append-only 保证反洗白（引理 18），cal 通道无法在下游把 α_slc 抹去。

**定理 17（探针安全与单调性）** 探针构造上满足定义 300 包络 ⇒ 不安全探针执行概率 = 0；探针合成只在候选集内求解 Fisher 最大化 ⇒ 加入新探针不降低 κ_ex（单调不减）；PAC 主动 canary 对「学会吸收故障」的适配器检出率 `≥ 1−(1−r_probe)^m`，m 为诊断探针数，r_probe 单探针检出率。若 `r_probe=0.6、m=5`，则检出 ≥ 99%。

## 6. 本轮最大风险

**一句话**：LOOP-RAS 的全部新增能力都押在「技能库能提供覆盖工作点的持续激励（κ_ex≥κ_min）」这一可辨识性前提上——在禁止扰动的安全关键场景里激励必然秩亏，系统会退化为 R68 的盲区；更危险的是它现在多了一条「地图证据」而更自信，可能把不可辨识的慢故障**高置信度地误判为标定**；而为了消除秩亏而合成的主动探针本身会引入磨损、瞬态与新的故障源，把「探测」变成「制造」。

**次级风险与缓解**：
1. append-only 存储膨胀 → 关键帧压缩 + epoch 归档；
2. 跨 epoch 地图差把真实世界变化误判为故障 → 语义变化签名 + 保守稳健集；
3. 人在场时探针不可用 → 安全包络优先，转 UNIDENT 并抬升 λ_floor；
4. 技能库长尾覆盖不足 → ProbeSynth + 主动学习补探针；
5. 地图锚点本身在部署前就带漂移 → 出厂计量溯源，锚点版本纳入 J_LOOP 版本链。

# IP-253 SPG：持久技能-地点图（append-only，历史锚点只读）
class SkillPlaceGraph:
    def __init__(self):
        self.V = {}; self.E = []; self.epoch = 0; self.frozen = set()
    def append(self, node):
        assert node.vid not in self.frozen          # 反洗白：不得回写历史
        self.V[node.vid] = node
    def match(self, a, b, xi, k=1):
        return self.index[(a, b)].query(xi, k)      # 同(技能,上下文)近似最近邻
    def excitation_rank(self, probe_log, Jc):
        Psi = assemble_regressors(probe_log, Jc)    # Ψ=[J_c,F(op)]
        s = svdvals(Psi); return s[-1] / s[0]       # κ_ex

# IP-255 SLC：语义回环残差（within/cross epoch）
def semantic_loop_closure(spg, v_new, Jc):
    v_h = spg.match(v_new.a, v_new.b, v_new.xi)
    r = concat([se3_log(v_new.xi.inv() * v_h.xi), v_new.y - v_h.y])
    if v_h.epoch == v_new.epoch:
        return r, 'within'                           # 对公共偏置不变
    return r - project_cal(r, Jc), 'cross'           # P_⊥ 残差 = 慢故障暴露面

# IP-256 MAD：三通道地图锚定归因
def map_anchored_discrimination(r_t, rho_slc, kappa_ex, cal_post):
    if kappa_ex < K_MIN:                             # 不可辨识：不坍缩到 cal

                           'fault': cal_post['fault'] * change_sig(rho_slc)})
    return normalize({'cal':   cal_post['cal']   * gaussian(rho_slc, R_cal),
                      'fault': cal_post['fault'] * change_sig(rho_slc),
                      'real':  cal_post['real']  * semantic_change(rho_slc)})

    scored = [(expected_info_gain(theta_belief, p), p) for p in cands]
    best = max(scored, key=lambda t: t[0]) if scored else (0, None)

             canary_unfixable, active_probe_gate]
    def active_probe_gate(self, M_shadow, M_live):

        return norm(b_perp(M_shadow, D)) >= 0.7 * norm(b_perp(M_live, D))
    def maybe_commit(self, shadow, dt):

        verdict = {g.__name__: g(shadow, self.live) for g in self.GATES}
        if all(verdict.values()):
            atomic_swap(self.live_ptr, shadow); return 'PASS'
        log_to_ecac(verdict); return 'REJECT'

def LOOP_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)                        # 继承 R68：一次前向五头
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    r = residuals(x_prime, o, M.wm_cache)
    c, U, thr = M.cof.step(o['cal'], r, sigma_stat(M))     # 因果通道
    Jc = M.cof.jacobian(); kappa_ex = M.spg.excitation_rank(M.probe_log, Jc)
    # 记忆通道
    v_new = M.spg.new_node(M.a_prev, M.ctx_bucket, M.pose, o['outcome'])
    rho_slc, kind = semantic_loop_closure(M.spg, v_new, Jc)
    # 主动通道（安全窗口内）
    if kappa_ex < K_MIN and M.suspect_fault:
        probe = (M.dsp.choose_probe(M.cause_belief, M.skill_lib, M.envelope, M.budget)
                 or M.synth.synthesize(M.fault_params, M.skill_lib, M.envelope))
        if probe is not None:
            M.probe_log.append(probe, M.executor.run(probe))
            kappa_ex = M.spg.excitation_rank(M.probe_log, Jc)
    # 三通道归因 + 风险
    rho = M.fir_signature(z, M.residual_log)
    joint = M.mad(r, rho_slc, kappa_ex, M.cfa(rho, o['pi'], c, U))
    lam = max(M.efs.risk_scale(joint),
              thr['lam_floor'] if kappa_ex >= K_MIN else max(0.8, thr['lam_floor']))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime), joint, M.m_ras)
    if kappa_ex < K_MIN: k = min(k, k_unident)       # UNIDENT 只收紧
    M.spg.append(v_new)                              # append-only 提交
    M.vqa_c.submit_async(rho_slc, {'kappa_ex': kappa_ex, 'joint': joint})
    M.pac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint, (c, U, kappa_ex)
```

## 4. 推导

**引理 16（慢故障可辨识性）** `r(op)=J_c δc + F(op) θ_f + n`。若 `Ψ=[J_c,F(op)]` 在探针集上列满秩且 `σ_min(Ψ)>0`，则 `(δc,θ_f)` 可辨识，`E‖θ̂_f−θ_f‖ ≤ σ_noise/σ_min(Ψ)`；秩亏方向恰为 R68 盲区。系：**R68 失败是秩亏特例**，技能多样性/探针提升 σ_min(Ψ)。

**引理 17（双通道频带互补覆盖）** COF 对 `τ_f≤1/(3ω_cal)` 保留 ≥2/3 残差（R68 引理 13）；跨 epoch SLC 对 `τ_f≤Δt_slc` 产生可检地图差。故覆盖 `τ_f≤max(Δt_slc,1/(3ω_cal))`；`Δt_slc≥0.53s` 时两带重叠、无缝隙——**自标定盲带被记忆通道填平**。

**引理 18（反洗白）** epoch 0 锚点固定；epoch 1 故障 f 被 COF 吸收时 `ρ_slc=P_⊥[r_cal(ĉ₁)−r_cal(c₀)+f]=P_⊥f`。故 `P_⊥f≠0` 时历史锚点保留非零证据，标定无法在 epoch 1 重新归零。**地图记住了标定忘掉的东西**；`P_⊥f=0` 时须靠工作点依赖（引理 16），否则物理不可辨识。

**定理 16（慢故障风险一致性）** A92–A94 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_slc+α_probe`；
2. `κ_ex≥κ_min ∧ Δt_slc≥1/(3ω_cal)` ⇒ 慢故障检出 `≥1−β`，误归因到 cal `≤exp(−n_slc·κ_ex²/(2σ²))`；
3. `κ_ex<κ_min` ⇒ UNIDENT，`λ_risk≥0.8` ∧ k 收缩 ∧ 后验保留 `{cal,fault}`——**不可辨识只会收紧**；
4. append-only 保证 α_slc 不被 cal 通道在下游抹去。

**定理 17（探针安全与单调性）** 包络内构造 ⇒ 不安全探针执行概率=0；ProbeSynth 在候选集内最大化 Fisher ⇒ κ_ex 单调不减；主动 canary 对吸收型适配器检出 `≥1−(1−r_probe)^m`（r_probe=0.6、m=5 ⇒ ≥99%）。

## 7. 本轮最大风险

**一句话**：LOOP-RAS 的全部新增能力都押在「技能库能提供覆盖工作点的持续激励（κ_ex≥κ_min）」这一可辨识性前提上——在禁止扰动的安全关键场景里激励必然秩亏，系统会退化为 R68 的盲区；更危险的是它现在多了一条「地图证据」而更自信，可能把不可辨识的慢故障**高置信度地误判为标定**；而为了消除秩亏而合成的主动探针本身会引入磨损、瞬态与新的故障源，把「探测」变成「制造」。

**次级风险与缓解**：append-only 存储膨胀（关键帧压缩 + epoch 归档）；真实世界变化被误判为故障（语义变化签名 + 稳健集）；人在场探针不可用（安全包络优先转 UNIDENT）；技能库长尾覆盖不足（ProbeSynth + 主动学习）；锚点部署前自带漂移（出厂计量溯源，锚点版本纳入 J_LOOP）。
