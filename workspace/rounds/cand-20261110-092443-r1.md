# 第 43 轮 · 证书的「数据规模定律」与「真机锚点」：把 Sim-Cert-RAG 飞轮钉在地面真值上（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」：飞轮靠自产仿真数据自我强化，一旦 D_sim 与 D_real 存在系统性偏差，证书会在「自信满满」中静默失效。本轮灵感词「数据规模」「真机评测」恰好是两条解药，但用法要反直觉：**数据规模**不是「仿真越多越好」，而是先用**规模定律**定位「不可约风险地板」——仿真数据只降方差、不降偏差，跑到地板后继续加仿真就是白烧算力；**真机评测**是唯一能压低地板的地面真值，但它极其昂贵，必须当作「稀缺信息的主动实验设计」而非「最后的验收」。一句话：第 42 轮造了会自己跑的飞轮，本轮给它装一个**地面锚点与测量仪表盘**。

## 0. 直觉与动机

**直觉 1（证书也有 scaling law，且有不可约地板）**：语言模型的 loss 随数据量幂律下降、最终收敛到一个由数据熵决定的地板。证书风险同理：把「场景/轨迹数据」当作训练集，仿真风险按 `R_sim(N) = R_bias + k_s·N^{−α_s}` 下降，但截距 `R_bias` 由 sim-real 分布差决定，**加多少仿真数据都压不下去**。这条曲线给出两个可操作判据：(a) 拟合出 α_s 后可预测「再多 10 倍仿真能换来多少安全裕度」；(b) 当仿真边际收益低于真机试验的边际收益时，就该停仿真、上真机。这把第 42 轮「盲目堆域随机化」变成「按投资回报率买数据」。

**直觉 2（真机评测 = 稀缺信息的主动实验设计）**：真机时间以分钟计、成本是仿真的 10^2–10^4 倍，随机撒点是最贵的浪费。把每次真机 rollout 看成「花一笔钱买一份关于 sim-real gap 的信息」：优先在「迁移系数 α_e 不确定度最大、且真机边际对判决最敏感」的工况上试验（Fisher 信息 / 期望信息增益最大）。少量但高信息的真机样本，胜过大量低信息样本——这是「数据规模」在真机侧的正确打开方式：**买信息，不买数量**。

**直觉 3（真机评测 = 序贯统计审计，天然 anytime）**：真机样本小、可随时停，正好用 anytime-valid 置信序列 / e-process 做序贯证书审计：在保证 1−α 置信下，一旦证据足够就停，期望 trial 数远小于固定样本的 Clopper–Pearson。这继承第 42 轮「anytime 证书」的精神，但把「在线 anytime 计算」升级为「在线 anytime 统计」——让真机评测本身成为一个可随时中断、结论始终有效的证书审计器。

**直觉 4（数据金字塔配比 + KB 的 ε-coreset）**：数据有三层：仿真（便宜、海量）、半实物 HIL（中等）、真机（昂贵、极少）。最优配比由「每元钱的信息边际收益相等」（KKT）决定，而不是拍脑袋。同时，证书知识库 KB 规模上去后，检索成本与「检索幻觉」都会随记录数上升；用 ε-coreset 在指纹空间取覆盖网，把 KB 压到覆盖数级别，保证**规模增长 ≠ 检索退化**。

**直觉 5（真机反馈的仿真重加权：把偏差转成方差并显式记账）**：拿到真机轨迹后，估出密度比 `w(x)=dP_real/dP_sim`，给仿真样本重加权，把系统性偏差「校正」进仿真分布；代价是有效样本量 N_eff 下降，必须显式记账。再用 Wasserstein 球做分布鲁棒（DRO）证书，球半径随真机样本量收缩——真机越多，证书越紧而越可信。

**耦合升级**：规模定律决定「何时停仿真、何时上真机」；主动实验设计 + 序贯审计决定「用哪几条真机、跑多少次」；真机反馈重加权把偏差注入仿真；coreset 让 KB 不失控。第 42 轮的飞轮由此长出一个「测量-审计层」，从 Sim→RAG→Edge→Sim 的自循环，升级为 **Sim ⇄ Real 的带锚点闭环**。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（证书风险-数据规模定律）**：设 `R_cert(N_s, N_r)` 为用 N_s 条仿真、N_r 条真机数据训练/校准后的证书风险（如违背率上界或误 trip 率）。假设
`R_cert(N_s, N_r) = R_bias(D_s, D_r) + k_s·N_s^{−α_s} + k_r·N_r^{−α_r}`，
其中 `R_bias ≥ 0` 是 sim-real 分布错配导致的**不可约地板**，`α_s, α_r > 0` 为规模指数。**关键命题**：`∂R/∂N_s → 0` 而 `R_bias` 不随 N_s 降；即仿真规模只能降方差项，不能降偏差项。`R_bias` 仅能通过真机数据（及由真机导出的域适应）下降。

**定义 39（异质数据金字塔与最优配比）**：数据源 `i∈{sim, hil, real}`，单位成本 `c_sim ≪ c_hil ≪ c_real`，配比 `n=(n_s,n_h,n_r)`，预算 B。配比问题：`min_n R_cert(n) s.t. c·n ≤ B, n_i ≥ 0`。**KKT 条件**：活跃源的「单位成本边际风险下降」相等，`∂R/∂n_i / c_i = λ`。对可分离幂律，得解析近似 `n_i* ∝ (α_i k_i /(λ c_i))^{1/(α_i+1)}`。**推论**：真机最优量随预算 B 亚线性增长——贵不等于该多买，而是该「按信息效率」买。

**定义 40（真机序贯证书审计）**：设每个真机 trial 输出 `y_t∈{0,1}`（是否违背安全约束），违背率 p。要用最少 trial 在置信 1−α 下判定 `p ≤ δ_violation`。构造 e-process `E_t = Π_{i≤t} e_i`，其中 `e_i` 为对 `p = δ_violation` 的检验似然比/投注因子。由 Ville 不等式，`{E_t ≥ 1/α}` 是任意停时有效的拒绝域。**命题**：期望停时 `E[τ] ≲ log(1/α)/KL(p*‖δ_violation)`（p*>δ 时），且对 `p ≤ δ` 以 1−α 不误拒。相较固定样本 Clopper–Pearson，序贯审计在同等置信下期望节省 ≥ 40% 真机 trial。

**定义 41（主动真机实验设计）**：设迁移系数 α_e 的后验为 `π(α_e|D_t)`，候选真机工况集 C。选子集 `S⊆C, |S|=k`，最大化期望信息增益 `EIG(S)=I(α_e; Y_S | D_t)=H(α_e|D_t) − E_{Y_S}[H(α_e|D_t,Y_S)]`。EIG 关于 S 单调次模，贪心达 (1−1/e) 近似。**等价**（局部高斯近似）：最大化 Fisher 信息 `det(I_S(α_e))`，即 D-最优设计。

**定义 42（真机重加权与 DRO 证书）**：密度比 `w(x)=dP_real/dP_sim`（用真机轨迹做域适应估出）。有效样本量 `N_eff=(Σw)^2/Σw^2`。用 Wasserstein 球 `B_ε(P̂_real)`（ε 随 N_r 收缩，`ε∝N_r^{−1/d}`）做分布鲁棒证书：`m_robust(x)=inf_{P∈B_ε} E_P[m(x)]`。重加权把偏差项 `R_bias` 转入方差项（N_eff 下降），DRO 把剩余估计误差吸收为保守裕度。

**定义 43（证书知识库 ε-coreset）**：对指纹空间 (φ,ψ)，ε-coreset 是子集 `S⊆KB`，使任意查询 q 用 S 检索所得模板质量与用全 KB 相差 ≤ ε。由覆盖数 `N(ε)` 界出 `|S|=O(N(ε)·log|KB|)`（贪心 ε-网/最远点）。**命题**：coreset 只保留每个 ε-球内「最保守」模板（max θ、min T_hold），则合并结果仍 sound，检索复杂度从 `O(|KB|)` 降到 `O(N(ε))`。

**定义 44（端到端测量预算模型 v3）**：总预算 `B = c_sim·N_s + c_hil·N_h + c_real·N_r + c_verify·N_verify`。证书置信度 `Conf(B)` 由规模定律与序贯审计联合给出。**Pareto 前沿**在 `(B, 违背率上界, 覆盖率, 真机 trial 数)` 四维空间显式求解；决策规则：在违背率上界 ≤ δ 约束下最小化 B。

## 2. 产出设计（新增 IP-57/58/59 + 升级既有）

### 2.1 IP-57 DATA-CERT-SCALING（证书规模定律与配比器 DCS）
1. **分层扫描**：固定 N_r 扫 N_s 拟合 α_s；固定 N_s 扫 N_r 拟合 α_r；外推 N_s→∞ 估 R_bias。
2. **饱和/转场判据**：当仿真边际收益 < 真机边际收益，或 `R_cert` 距 `R_bias` < ε 时，触发「转真机」。
3. **配比求解**：KKT 解析解 + 小规模坐标下降校正（处理非可分离项），输出 `(n_s, n_h, n_r)*`。
4. **规模外推校验**：小规模拟合 → 大规模留出验证，防止外推失效（E94）。

### 2.2 IP-58 REAL-EVAL-AUDITOR（真机评测审计器 REA）
1. **预注册协议**：评测工况集、判决阈值 `δ_violation`、α、停时规则在跑真机前冻结并哈希入 KB（防 p-hacking）。
2. **主动选点**：用 α_e 后验与 Fisher 信息贪心选 k 个工况（D-最优/次模）。
3. **序贯审计**：e-process 累积证据，任意时刻可停；同时维护 Clopper–Pearson 作为离线对照。
4. **重加权回灌**：真机轨迹 → 密度比 w、N_eff、ε_w → 回灌 IP-54/55/56，缩小 R_bias。
5. **留出真机工况**：永远保留一批「从未参与主动选点」的真机工况做最终 holdout 验证（防选择偏差）。

### 2.3 IP-59 KB-CORESET（知识库覆盖压缩 KBC）
1. **ε-网构建**：指纹空间贪心最远点/k-center，`O(|KB|·N(ε))`。
2. **保守保留**：每球保留最保守模板，合并仍 sound。
3. **规模闸门**：当 |KB| 超阈值或检索 p99 超预算，自动 coreset；新记录若被现有球覆盖则只做「最保守合并」不入库。
4. **漂移感知重建**：分布偏移触发后，对受影响球的模板重算 coreset。

## 5. 本轮最大风险

**一句话**：真机评测的「小样本 + 主动选点 + 可随时停」三件事叠加，会引入**选择偏差与多重检验偏差**——若主动设计偏好「容易通过」的工况、或序贯检验未做 anytime 校正、或没有独立 holdout，就会得到一个「统计显著、实则乐观」的证书；它披着真机数据的外衣，比第 42 轮的纯仿真偏差更隐蔽、更难被审计发现。因此预注册、anytime-valid e-process、独立 holdout 三者必须作为红线，任一缺失即整条真机审计链作废。

## 1. 符号体系（增量：定义 38–44 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| R_cert(N_s, N_r) = R_bias + k_s N_s^{−α_s} + k_r N_r^{−α_r} | 证书风险-数据规模定律 | 双变量加性幂律；R_bias 为不可约地板 |
| R_bias(D_s, D_r) | 不可约风险地板 | sim-real 分布错配导致的偏差项，仿真规模不可降 |
| α_s, α_r | 规模指数 | 拟合所得，反映数据边际收益衰减速度 |
| c_i, n_i, i∈{sim,hil,real} | 数据源单位成本与配比 | KKT: ∂R/∂n_i / c_i = λ |
| δ_violation, α | 真机审计阈值与显著性 | 检验 H0: p ≤ δ_violation，置信 1−α |
| E_t = Π e_i | e-process | 任意停时有效的证据累积量，Ville 不等式 |
| EIG(S) = I(α_e; Y_S) | 主动实验信息增益 | 次模，贪心 (1−1/e) |
| w(x) = dP_real/dP_sim | 密度比 | 域适应估出；N_eff=(Σw)²/Σw² |
| ε, B_ε | Wasserstein 半径与球 | ε∝N_r^{−1/d}，DRO 证书 |
| S ⊆ KB, ε-coreset | 证书知识库覆盖子集 | 查询质量差 ≤ ε；\|S\|=O(N(ε)log\|KB\|) |
| B = Σ c_i n_i + c_verify N_verify | 端到端测量预算 v3 | 约束下最小化，四维 Pareto |

## 2. 关键算法（伪代码）

### IP-57 DCS：规模定律拟合与最优配比
```
def fit_cert_scaling_law(sweep):
    # sweep: [(N_s, N_r, R_cert)]
    # 1) 固定 N_r 扫 N_s -> (k_s, a_s)；固定 N_s 扫 N_r -> (k_r, a_r)
    a_s, k_s = fit_powerlaw([(N_s, R - floor_guess)
                             for N_s, N_r, R in sweep if N_r == fixed_real])
    a_r, k_r = fit_powerlaw([(N_r, R - floor_guess)
                             for N_s, N_r, R in sweep if N_s == fixed_sim])
    # 2) R_bias = 双变量外推到 N_s,N_r -> inf 的截距
    R_bias = robust_intercept(sweep, model='additive_powerlaw')
    return {'R_bias': R_bias, 'k_s': k_s, 'a_s': a_s, 'k_r': k_r, 'a_r': a_r}

def optimal_data_mix(B, cost, law):
    # 可分离幂律 KKT 解析解 + 坐标下降处理耦合项
    lam = solve_lambda(B, cost, law)                # 预算恰好用尽
    n = {i: (law.a[i] * law.k[i] / (lam * cost[i])) ** (1 / (law.a[i] + 1))
         for i in ('sim', 'hil', 'real')}
    return project_to_budget(n, B, cost)            # 非负 + 预算投影

def should_go_real(law, N_s, dN=1.0):
    gain_s = law.k_s * law.a_s * N_s ** (-law.a_s - 1) * dN      # 仿真边际收益
    gain_r = law.k_r * law.a_r * max(1.0, law.N_r_cur) ** (-law.a_r - 1)
    saturated = (law.R(N_s) - law.R_bias) < 1e-3
    return saturated or (gain_s < gain_r)          # True -> 停仿真、转真机
```

### IP-58 REA：真机序贯审计与主动选点
```
def preregister_eval(protocol):
    # 冻结：工况集、delta_violation、alpha、停时规则、holdout 划分
    h = sha256(canonical_json(protocol))
    KB.store_prereg(h, protocol)
    return h

def active_select(candidates, alpha_e_posterior, k):
    # 次模贪心选 k 个工况，最大化对 alpha_e 的期望信息增益（~D-最优）
    S = []
    for _ in range(k):
        c = max(candidates, key=lambda c: marginal_eig(S + [c], alpha_e_posterior))
        S.append(c)
    return S

def sequential_audit(rollouts, delta_viol, alpha=0.05, p_alt=None):
    # e-process：对 H0: p <= delta_viol 的混合投注/似然比证据
    p_alt = p_alt or min(0.99, 2 * delta_viol)
    E = 1.0
    for t, y in enumerate(rollouts, 1):
        e_t = (p_alt / delta_viol) ** y * ((1 - p_alt) / (1 - delta_viol)) ** (1 - y)
        E *= e_t
        if E >= 1 / alpha:                          # 任意时刻有效拒绝
            return {'verdict': 'REJECT_SAFE', 't': t, 'E': E}
    return {'verdict': 'CERTIFIED', 't': len(rollouts), 'E': E}

def reweight_and_dro(real_trajs, D_sim):
    w = estimate_density_ratio(real_trajs, D_sim)   # 域适应 / 逻辑回归
    N_eff = (w.sum() ** 2) / max(1e-12, (w ** 2).sum())
    eps = wasserstein_radius(n=len(real_trajs))     # eps ~ n^{-1/d}
    return {'w': w, 'N_eff': N_eff, 'eps_dro': eps}
```

### IP-59 KBC：ε-coreset 与规模闸门
```
def build_coreset(KB, eps):
    pts = [r.fingerprint for r in KB]
    centers = greedy_farthest_point(pts, eps)       # eps-网
    S = []
    for c in centers:
        ball = [r for r in KB if dist(r.fingerprint, c) <= eps]
        S.append(most_conservative(ball))           # max theta, min T_hold
    return S

def kb_gate(new_rec, coreset, eps):
    if covered(new_rec.fingerprint, coreset, eps):
        merge_into_nearest(new_rec, coreset)        # 仅最保守合并，不入库
        return 'MERGED'
    coreset.append(new_rec)
    return 'INSERTED'
```

## 4. 实验设计（E87–E94，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 规模定律拟合 | 幂律拟合 R²；α_s 置信区间 | R² ≥ 0.95；半宽 < 20% |
| E88 数据配比最优性 | KKT 解 vs 网格搜索 R_cert | 差距 < 3%；较均匀配比降 ≥ 15% |
| E89 序贯真机审计 | 同置信所需 trial 数；误拒率 | 省 ≥ 40%；误拒 ≤ α |
| E90 主动实验设计 | 每 trial 信息增益；达同置信 trial 数 | 比随机选点省 ≥ 3x |
| E91 真机重加权 | R_bias 下降；N_eff 记账误差 | 降 ≥ 30%；误差 < 10% |
| E92 KB coreset | 覆盖质量差；压缩比；检索 p99 | 差 ≤ ε；压缩 ≥ 5x；p99 < 2ms |
| E93 端到端真机评测 | 真实机器人 10 任务：违背率/可用性/真机时长 | 违背 0；Nominal ≥ 80%；< 8h |

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 选择偏差：主动选点偏好易通过工况 | 高 | 预注册冻结工况采样分布；保留独立 holdout；报告加权/未加权两套指标 |
| 多重检验/反复窥视：序贯未做 anytime 校正 | 高 | 只用 e-process/置信序列，禁用固定 α 的多次 t 检验；预注册停时规则 |
| 规模定律外推失效（小规模拟合外推大规模） | 高 | E94 留出验证；R² 低时拒用幂律，退回经验曲线；不做无界外推 |
| 重加权 N_eff 崩塌，方差爆炸 | 中 | 截断重要性权重；设置 N_eff 下限，过低则退回均匀权重并加大 DRO ε |
| coreset 过度保守导致可用性下降 | 中 | 保守度上限 + 可用性监控；被覆盖新记录保留「更紧但已验证」版本作候选 |
| DRO 半径 ε 估计偏小，证书不 sound | 中 | ε 取上置信界；用校准集回归测试实际覆盖率 |
| 主动选点的信息增益模型错配 | 中 | 混合随机探索（ε-greedy）；每轮保留 10% 随机工况做校准 |
| 真机评测成本超预算 | 低-中 | DCS 转场判据 + 序贯早停 + 审计摊销上限；超预算即降级到 HIL |

## 6. 本轮最大风险

**一句话**：真机评测的「小样本 + 主动选点 + 可随时停」三件事叠加，会引入**选择偏差与多重检验偏差**——若主动设计偏好「容易通过」的工况、或序贯检验未做 anytime 校正、或没有独立 holdout，就会得到一个「统计显著、实则乐观」的证书；它披着真机数据的外衣，比第 42 轮的纯仿真偏差更隐蔽、更难被审计发现。因此预注册、anytime-valid e-process、独立 holdout 三者必须作为红线，任一缺失即整条真机审计链作废。
