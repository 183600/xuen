# 第 56 轮（承接第 55 轮 v31 GroundEdge-GenSim+++ 与语义-接触层；灵感循环第 2 轮；本轮灵感：「少样本学习」×「点云配准」）

> 第 55 轮把证书推进到“语义-接触生存核”，回答了“接触在语义上是否可信”。本轮补上更底层的一问：**这些接触所在的几何表面，到底被对齐到了哪里？** 当机器人进入新场景，只有少量示例和局部点云时，配准不是确定性求解，而是一个受支持集约束的位姿后验。核心矛盾：**H24（少样本-证书错位）**：少样本学习优化的是支持集拟合，证书要求的是查询域最坏覆盖；k 个示例只提供“局部证据”，却常被当成“全局几何已确认”。**H25（配准多峰-动作放大）**：部分重叠、遮挡与对称结构使配准后验天然多峰，而接触点位于离物体/工具中心较远的位置，微小的旋转误差会经杠杆臂放大为可观的接触位移，直接改变生存核 `K(Σ)` 的边界。

## 0. 直觉与动机

**灵感 1（少样本学习 → 支持集是“证据预算”，不是“训练集”）**
直觉：少样本的意义不在于“用 k 个样本把模型训得更好”，而在于 **k 个样本决定了假设允许移动多远**。如果把支持集当作训练集，适配会尽力拟合这 k 个点；如果把它当作证据预算，适配就必须回答“这 k 个点能为我担保多大的查询域”。于是少样本学习的目标从 `min L_support` 变成 `min L_task s.t. 证据可覆盖查询域`，默认结论是“证据不足则拒绝适配”，而不是“拟合成功即可部署”。

**灵感 2（点云配准 → 输出应是位姿可信集，而非一个 SE(3) 点）**
直觉：在部分重叠与对称物体上，配准的解不是唯一的；一个“最优位姿”旁边可能藏着另一个几乎同样好、但接触后果完全不同的位姿。正确的输出是一个 **多峰位姿后验/可信集** `𝒯_α`：它既包含“物体可能在哪里”，也包含“模型有多不确定”。把配准从点估计升级为集合估计，后面的接触检查才有可用的输入。

**灵感 3（配准误差 → 接触位移证书，而不是像素级重投影误差）**
直觉：重投影误差小，不代表接触安全。机器人在离物体中心 `||p||` 处接触，旋转误差 `δθ` 造成的接触位移近似 `δθ·||p||`——**杠杆放大**。因此配准不确定性必须被翻译成任务空间里的 **接触位移上界** `D_p(𝒯_α)`，再与语义边界裕度、摩擦锥裕度、质心裕度逐项比较。配准精度的单位应从“米/度”换成“毫米的接触位移”。

**灵感 4（接触可供性 → 配准影响的可行动集）**
直觉：第 55 轮的语义-接触生存核 `K(Σ)` 默认接触几何是确定的。若位姿只能确定到一个集合 `𝒯_α`，则可行性也必须对集合内所有位姿成立：`K_R(Σ,𝒯_α)` 是“无论真实位姿落在可信集的哪一处，都存在一个动作保持安全”的 **鲁棒生存核**。配准越模糊，`K_R` 越小；这不是感知模块的内部指标，而是可行动集的直接收缩。

**灵感 5（少样本主动配准 → 支持集是可控变量）**
直觉：具身系统与离线配准最大的区别是——机器人可以动。它可以选择下一个视角、下一次扫描、甚至一次轻触，来获取最有信息量的支持样本。于是少样本配准不是被动等待更多标注，而是 **主动实验设计**：选择使位姿可信集体积/接触位移上界下降最多的动作，同时该动作本身必须受安全护盾约束。这把“感知不确定性”接入了控制回路。

**灵感 6（云边几何接口 → 粗先验在云、少样本校正在边）**
直觉：云端拥有全局地图、物体 CAD 与跨场景配准先验，适合给出粗位姿与多峰模式；边端拥有实时点云、力/触觉与局部几何，适合做少样本校正与可信集收缩。两者以 **位姿可信集接口** 对接：云端下发 `(T_m, r_m, prior)`，边端回传 `𝒯_α`、支持覆盖 `(cov_ρ, δ_SQ)` 与接触残差，触发云端重新选择先验模式。这把第 55 轮的语义-接触接口再下沉一层，形成 **几何-语义-动作** 三级重剖分。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（少样本配准任务与支持证据）**
任务分布 `𝔗` 上的一个少样本配准任务为 `τ=(M,P,S_k)`：`M` 为先验点云/地图，`P` 为查询局部点云，`S_k={(P_i,M_i,T_i)}_{i=1}^k` 为同一任务族中 `k` 个已配准支持对，`T_i∈SE(3)`。元学习得到位姿先验 `π_θ(T | P,M,S_k)`。支持-查询划分 `S_k ∩ Q=∅`。称 `k≪|𝒢_c|`（接触相关几何的样本数）为少样本条件。**支持证据域** 记为 `E(S_k)`，它只覆盖任务族中与支持样本相似的那部分几何，而不是整个查询域。

**定义 128（共形位姿可信集与歧义半径）**
对候选位姿 `T` 定义非一致性分数
`s(τ,T)=e_reg(T;P,M)+λ_s e_supp(T;S_k)+λ_m e_mode(T)`，
其中 `e_reg` 为配准残差（如截断 Chamfer/对应点距离），`e_supp` 为支持一致性，`e_mode` 为模式先验偏离。在独立校准任务集 `D_cal` 上计算分数 `{s_i}`，取
`q_α = Quantile_{⌈(n+1)(1−α)⌉/n}({s_i})`，
定义 **共形位姿可信集**
`𝒯_α(τ)={T∈SE(3) | s(τ,T) ≤ q_α}`。
在任务可交换假设下，`P(T_true∈𝒯_α) ≥ 1−α`。将其分解为模式并集 `𝒯_α=∪_{m=1}^M B_SE3(T_m,r_m)`，定义 **歧义半径** `r_α=max_m r_m`。注意：该保证是 **边缘覆盖**，不是逐物体/逐对称类的条件覆盖；后者必须另行审计（见定义 131 与实验 E168）。

**定义 129（配准诱导的接触位移与杠杆放大）**
对接触点 `p`（物体/工具坐标系），
`D_p(𝒯)=sup_{T,T'∈𝒯} ||Tp − T'p||`，
`D_contact(𝒯)=max_{p∈C_core} D_p(𝒯)`。
若 `𝒯=∪_m B_SE3(T_m,r_m)`，则
`D_p(𝒯) ≤ 2 max_m r_m + max_{m,n} ||T_m p − T_n p||`。
对小幅旋转，`D_p ≈ r_t + r_R·||p||`，定义 **杠杆放大因子** `Λ(p)=D_p / d_SE3(T̂,T_true)`，它随 `||p||` 近似线性增长。故“位姿误差 1°”在近端接触与远端接触上完全不是同一件事。

**定义 130（配准鲁棒的全身生存核）**
给定语义图 `Σ` 与位姿可信集 `𝒯_α`，
`K_R(Σ,𝒯_α) = {x | ∃u∈A_WB, ∀T∈𝒯_α : f(x,u,λ_T)=ẋ ∧ supp(λ_T)⊆C^+(Σ) ∧ x_{t+1}∈𝒳_safe}`，
其中 `λ_T` 是在位姿 `T` 下重新计算的接触力。语义可行性扩展为 `viable_R(x)=1 ⇔ x∈K_R(Σ,𝒯_α)`。由定义立即有 `K_R(Σ,𝒯_α) ⊆ K(Σ,𝒯_α)`；配准歧义只会 **收缩** 可行动集，绝不会扩大它。

**定义 131（支持覆盖与少样本证据缺口）**
设 `𝒢_c(x)` 为当前任务接触相关几何，`φ` 为局部几何描述子，`μ` 为几何测度。支持覆盖
`cov_ρ(S_k)=μ({g∈𝒢_c : min_{i≤k} d(φ(g),φ(s_i)) ≤ ρ}) / μ(𝒢_c)`，
支持-查询差异 `δ_SQ=MMD(φ(S_k),φ(𝒢_c))`。**证据缺口** 为二元组 `Gap=(1−cov_ρ, δ_SQ)`。当 `cov_ρ < θ_c` 或 `δ_SQ > ε_SQ` 时，支持集不足以担保查询域，必须拒绝适配、触发主动采集或退回已验证技能。注意 `cov_ρ` 是几何描述子空间的覆盖，不是接触成功率的充分条件；其阈值必须用风险-覆盖率曲线校准。

**定义 132（少样本配准-接触联合证书）**
`J_FR=(𝒯_α, D_contact, cov_ρ, δ_SQ, K_margin, δ_T, evidence)`：
- `D_contact` 为核心接触集上的最大配准诱导位移；
- `K_margin = min_{x∈轨迹} dist(x, ∂K_R(Σ,𝒯_α))` 为鲁棒生存核裕度；
- `δ_T` 为留出扫描/触觉校验得到的实际配准残差；
- `evidence` 含共形校准分数、模式聚类、拒绝适配与主动采集日志。
若 `P(T_true∈𝒯_α) ≥ 1−α`、`D_contact ≤ margin_contact−buffer`、`cov_ρ ≥ θ_c`、`δ_SQ ≤ ε_SQ`、`K_margin ≥ θ_K` 且 `δ_T < Θ_T`，则证书判定为可部署。该证书显式条件于任务分布 `𝔗` 与校准集 `D_cal`；分布漂移必须触发重校准，而不是沿用旧覆盖。

## 2. 关键算法 伪代码

### IP-127 FMR（Few-shot Meta-Registration）

```python
def meta_registration_prior(episodes, meta_iters):
    theta = init_meta_prior()
    for it in range(meta_iters):
        tau = sample_task(episodes)              # (M, P, S_k, Q)
        T_hyps = model(theta, tau.M, tau.P, tau.S_k)   # mixture over SE(3)
        loss = chamfer_loss(T_hyps, tau.Q) \
             + lambda_s * support_consistency(T_hyps, tau.S_k) \
             - lambda_d * mode_diversity(T_hyps)
        theta = meta_update(theta, loss)
    return theta

def few_shot_posterior(theta, M, P, S_k, n_modes=8):
    modes = predict_modes(theta, M, P, S_k, n_modes)
    return PoseMixture([(T, weight(theta, M, P, S_k, T)) for T in modes])
```

### IP-128 CPCP（Conformal Pose Credible Prediction）

```python
def conformal_pose_set(tau, model, cal_scores, alpha):
    pi = few_shot_posterior(model, tau.M, tau.P, tau.S_k)
    cand = []
    for T_m, w in pi.modes:
        cand += local_refine(T_m, tau, steps=REFINE_STEPS)
    cand = cluster_modes(cand, tol=tau_cluster)
    scores = {T: nonconformity(tau, T) for T in cand}
    q = quantile(cal_scores, ceil((len(cal_scores)+1)*(1-alpha)) / len(cal_scores))
    T_set = {T for T, s in scores.items() if s <= q}
    # 以模式球膨胀填补候选间空隙，保证集合可被 D_p 上界覆盖
    return inflate_union_of_balls(T_set, q)
```

### IP-129 RDC（Registration-induced Displacement Certificate）

```python
def displacement_certificate(T_set, contacts):
    D = {}
    for p, c in contacts:
        balls = T_set.as_union_of_balls()
        D[(p, c)] = max_pairwise_diameter(balls, p)   # sound upper bound
    D_contact = max(D.values())
    lever = {p: D[p] / max(eps, T_set.diameter_to_estimate(p)) for p, _ in contacts}
    return DisplacementCert(D, D_contact, lever)
```

### IP-130 SCA（Support Coverage Audit）

```python
def support_coverage_audit(S_k, contact_geom, phi, theta_c, eps_sq):
    f_g = encode(phi, contact_geom)
    f_s = encode(phi, S_k)
    cov = measure({g for g, fg in zip(contact_geom, f_g)
                   if min_dist(fg, f_s) <= rho}) / len(contact_geom)
    dist = mmd(f_g, f_s)
    if cov < theta_c or dist > eps_sq:
        return ('insufficient', cov, dist, propose_acquisition(contact_geom, S_k))
    return ('ok', cov, dist, None)
```

### IP-131 AGR（Active Geometry Registration）

```python
def active_register(posterior, T_set, candidates, safety_shield, budgets):
    best = None
    for a in candidates:                       # next-best-view / gentle touch
        if not safety_shield.admissible(a):
            continue
        obs_model = predict_observation(posterior, a)
        gain = mutual_information(posterior, obs_model)   # 或期望 D_contact 降幅
        cost = motion_cost(a) + risk_penalty(a)
        score = gain - lambda_c * cost
        if best is None or score > best.score:
            best = (a, score, gain)
    if best is None or best.gain < budgets.min_gain:
        return ('stop', 'no_safe_informative_action')
    return ('act', best[0])
```

### IP-132 JFR（Joint Few-shot Registration Certificate）

```python
def joint_fewshot_registration_certificate(traj, Sigma, T_set, S_k, phi, budgets):
    contacts = contacts_used(traj)
    disp = displacement_certificate(T_set, contacts)
    if disp.D_contact > budgets.margin_contact - budgets.buffer:
        return ('reject', 'contact_displacement', disp.D_contact)
    status, cov, dist, hint = support_coverage_audit(
        S_k, contact_geom(traj), phi, budgets.theta_c, budgets.eps_sq)
    if status != 'ok':
        return ('reject', 'support_evidence_gap', cov, dist, hint)
    K_margin = min(robust_kernel_margin(x, Sigma, T_set) for x in traj)
    if K_margin < budgets.theta_K:
        return ('reject', 'robust_viability_fail', K_margin)
    delta_T = heldout_registration_residual(T_set, S_k)
    if delta_T > budgets.Theta_T or not T_set.coverage_at_least(1 - budgets.alpha):
        return ('reject', 'registration_budget_exceeded', delta_T)
    return ('ok', FewShotRegCert(T_set, disp, cov, dist, K_margin, delta_T))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FMR | O(E·k·H·C_reg) 训练；O(H·C_reg) 推理 | O(|θ|+H) | 元任务覆盖、支持-查询划分无泄漏 |
| CPCP | O(|C|·N_cal + |C| log |C|) | O(N_cal+|C|) | 可交换性、分数下界、模式聚类不丢峰 |
| RDC | O(|C|·M)（M 为模式数） | O(|C|·M) | 球并集外近似 sound、杠杆上界有效 |
| SCA | O(|𝒢_c|·k) | O(|𝒢_c|) | 描述子与覆盖率标定、阈值来自风险-覆盖率曲线 |
| AGR | O(|A_view|·(H·I_gain)) | O(|A_view|) | 信息增益可估、动作受护盾约束 |
| JFR | O(|轨迹|·(|C|+M)+|𝒢_c|·k) | O(|C|·M) | 证书条件闭合、分布漂移可检测 |

**正确性定理（Few-shot Registration-Contact Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 校准任务与测试任务可交换，或分布漂移被检测并以 `δ_shift` 计入预算；**(A34)** 共形可信集满足 `P(T_true∈𝒯_α) ≥ 1−α`，且模式并集覆盖所有显著后验峰；**(A35)** `D_p(𝒯_α)` 是接触位移的 sound 上界，`K_R` 的内/外近似 sound，护盾不可行时回退到 `u_stop∈𝒳_safe`；**(A36)** 支持覆盖 `(cov_ρ,δ_SQ)` 与接触域泛化误差之间的映射经风险-覆盖率曲线校准，主动观测被计入 `S_k`。
则部署后单步安全概率满足：
```
P_safe ≥ 1 − α − P(support false-accept) − P(mode missed) − P(K_R approx gap) − P(shield fallback fails) − P(δ_shift > Θ_shift)
```
关键：**位姿不确定性进可信集、可信集进接触位移、接触位移进鲁棒生存核、少样本证据不足则拒绝**。任一层把“边缘覆盖”误读为“条件保证”，都会让安全承诺失效。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共形可交换性在真实任务漂移下失效 | 高 | 漂移检测 + 在线重校准 + 条件覆盖审计 + 保守回退 |
| 对称/重复结构导致后验多峰被漏掉 | 高 | 多假设模式聚类 + 并集膨胀 + 对称感知非一致性分数 |
| 支持覆盖描述子与真实接触泛化脱节 | 高 | 任务分层风险-覆盖率校准 + 几何/触觉联合描述子 + 保守阈值 |
| `D_p` 上界过松导致可行动集冻结 | 中 | 球并集紧致化 + 分层可信集 + 保守度预算 |
| 主动采集动作本身不安全或代价过高 | 中 | 动作护盾 + 信息增益/风险联合约束 + 最小增益停止 |
| 云边先验模式不一致 | 高 | 版本化地图 + 位姿可信集握手 + 接触残差回传重选模式 |

## 6. 本轮最大风险

**一句话**：少样本配准证书把“配准点估计”升级为“位姿可信集 + 接触位移 + 鲁棒生存核”，但其 soundness **三重依赖共形覆盖的可交换性、支持覆盖与接触泛化的校准、以及多峰后验的无漏捕获**；一旦任务分布漂移、对称峰未被模式集合覆盖，`𝒯_α` 会漏掉真实位姿而 `D_contact` 仍显得很小，机器人就会带着“有证书”的自信把接触压到真实表面之外——因此必须以 **漂移检测 + 多峰并集 + 条件覆盖审计** 三重护栏，宁可在支持证据不足时拒绝适配并退回安全技能，绝不把少样本的“看起来对齐”当作接触几何的“已证实”。

# 第 56 轮产物 · 创新点清单 v32：FeSCoR-Cert（FMR×CPCP×RDC×SCA×AGR×JFR）

> 承接第 55 轮语义-接触层（IP-121~126）与 v31 动作-协同层（IP-115~120）。本轮把证书体系下沉到几何配准：当机器人只有少量示例与局部点云时，不再把配准当成一个确定的 `SE(3)` 解，而是输出 **位姿可信集**，并把其不确定性逐级翻译为 **接触位移、鲁棒生存核、可部署证书**。
> - **FMR（Few-shot Meta-Registration）**：少样本元配准先验，输出多假设位姿后验；
> - **CPCP（Conformal Pose Credible Prediction）**：用共形预测构造带覆盖保证的位姿可信集；
> - **RDC（Registration-induced Displacement Certificate）**：位姿歧义 → 接触位移上界与杠杆放大；
> - **SCA（Support Coverage Audit）**：支持集对接触相关几何的覆盖审计与证据缺口判定；
> - **AGR（Active Geometry Registration）**：主动视角/触觉采集以收缩位姿可信集；
> - **JFR（Joint Few-shot Registration Certificate）**：少样本配准-接触联合证书。
>
> IP 编号：IP-127~IP-132（共 6 个新增），升级 IP-118/120/124/126 以接入配准维度。

### IP-127 FMR

```python
def meta_registration_prior(episodes, meta_iters):
    theta = init_meta_prior()
    for it in range(meta_iters):
        tau = sample_task(episodes)              # (M, P, S_k, Q)
        T_hyps = model(theta, tau.M, tau.P, tau.S_k)
        loss = chamfer_loss(T_hyps, tau.Q) \
             + lambda_s * support_consistency(T_hyps, tau.S_k) \
             - lambda_d * mode_diversity(T_hyps)
        theta = meta_update(theta, loss)
    return theta

def few_shot_posterior(theta, M, P, S_k, n_modes=8):
    modes = predict_modes(theta, M, P, S_k, n_modes)
    return PoseMixture([(T, weight(theta, M, P, S_k, T)) for T in modes])
```

### IP-128 CPCP

```python
def conformal_pose_set(tau, model, cal_scores, alpha):
    pi = few_shot_posterior(model, tau.M, tau.P, tau.S_k)
    cand = []
    for T_m, w in pi.modes:
        cand += local_refine(T_m, tau, steps=REFINE_STEPS)
    cand = cluster_modes(cand, tol=tau_cluster)
    scores = {T: nonconformity(tau, T) for T in cand}
    q = quantile(cal_scores, ceil((len(cal_scores)+1)*(1-alpha)) / len(cal_scores))
    T_set = {T for T, s in scores.items() if s <= q}
    return inflate_union_of_balls(T_set, q)      # 球并集 sound 外近似
```

### IP-129 RDC

```python
def displacement_certificate(T_set, contacts):
    D = {}
    for p, c in contacts:
        balls = T_set.as_union_of_balls()
        D[(p, c)] = max_pairwise_diameter(balls, p)
    D_contact = max(D.values())
    lever = {p: D[p] / max(eps, T_set.diameter_to_estimate(p)) for p, _ in contacts}
    return DisplacementCert(D, D_contact, lever)
```

### IP-130 SCA

```python
def support_coverage_audit(S_k, contact_geom, phi, theta_c, eps_sq):
    f_g = encode(phi, contact_geom)
    f_s = encode(phi, S_k)
    cov = measure({g for g, fg in zip(contact_geom, f_g)
                   if min_dist(fg, f_s) <= rho}) / len(contact_geom)
    dist = mmd(f_g, f_s)
    if cov < theta_c or dist > eps_sq:
        return ('insufficient', cov, dist, propose_acquisition(contact_geom, S_k))
    return ('ok', cov, dist, None)
```

### IP-131 AGR

```python
def active_register(posterior, T_set, candidates, safety_shield, budgets):
    best = None
    for a in candidates:                       # next-best-view / gentle touch
        if not safety_shield.admissible(a):
            continue
        obs_model = predict_observation(posterior, a)
        gain = mutual_information(posterior, obs_model)   # 或期望 D_contact 降幅
        cost = motion_cost(a) + risk_penalty(a)
        score = gain - lambda_c * cost
        if best is None or score > best.score:
            best = (a, score, gain)
    if best is None or best.gain < budgets.min_gain:
        return ('stop', 'no_safe_informative_action')
    return ('act', best[0])
```

### IP-132 JFR

```python
def joint_fewshot_registration_certificate(traj, Sigma, T_set, S_k, phi, budgets):
    contacts = contacts_used(traj)
    disp = displacement_certificate(T_set, contacts)
    if disp.D_contact > budgets.margin_contact - budgets.buffer:
        return ('reject', 'contact_displacement', disp.D_contact)
    status, cov, dist, hint = support_coverage_audit(
        S_k, contact_geom(traj), phi, budgets.theta_c, budgets.eps_sq)
    if status != 'ok':
        return ('reject', 'support_evidence_gap', cov, dist, hint)
    K_margin = min(robust_kernel_margin(x, Sigma, T_set) for x in traj)
    if K_margin < budgets.theta_K:
        return ('reject', 'robust_viability_fail', K_margin)
    delta_T = heldout_registration_residual(T_set, S_k)
    if delta_T > budgets.Theta_T or not T_set.coverage_at_least(1 - budgets.alpha):
        return ('reject', 'registration_budget_exceeded', delta_T)
    return ('ok', FewShotRegCert(T_set, disp, cov, dist, K_margin, delta_T))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| FMR | O(E·k·H·C_reg) 训练；O(H·C_reg) 推理 | O(|θ|+H) | 元任务覆盖、无支持-查询泄漏 |
| CPCP | O(|C|·N_cal + |C| log |C|) | O(N_cal+|C|) | 可交换性、分数下界、模式不丢峰 |
| RDC | O(|C|·M) | O(|C|·M) | 球并集外近似 sound、杠杆上界有效 |
| SCA | O(|𝒢_c|·k) | O(|𝒢_c|) | 覆盖率标定、阈值来自风险-覆盖率曲线 |
| AGR | O(|A_view|·H·I_gain) | O(|A_view|) | 信息增益可估、动作受护盾约束 |
| JFR | O(|轨迹|·(|C|+M)+|𝒢_c|·k) | O(|C|·M) | 证书条件闭合、漂移可检测 |

**正确性定理（Few-shot Registration-Contact Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 校准任务与测试任务可交换，或漂移被检测并以 `δ_shift` 计入预算；**(A34)** 共形可信集满足 `P(T_true∈𝒯_α)≥1−α`，模式并集覆盖所有显著后验峰；**(A35)** `D_p(𝒯_α)` 是接触位移的 sound 上界，`K_R` 的内/外近似 sound，护盾不可行时回退 `u_stop∈𝒳_safe`；**(A36)** 支持覆盖 `(cov_ρ,δ_SQ)` 与接触域泛化误差的映射经风险-覆盖率曲线校准，主动观测计入 `S_k`。
则部署后单步安全概率满足：
```
P_safe ≥ 1 − α − P(support false-accept) − P(mode missed) − P(K_R approx gap) − P(shield fallback fails) − P(δ_shift > Θ_shift)
```
关键：**位姿不确定性进可信集、可信集进接触位移、接触位移进鲁棒生存核、少样本证据不足则拒绝**；四层任一把“边缘覆盖”误读为“条件保证”，安全承诺即失效。

## 5. 本轮最大风险

**一句话**：少样本配准证书把“配准点估计”升级为“位姿可信集 + 接触位移 + 鲁棒生存核”，但其 soundness **三重依赖共形覆盖的可交换性、支持覆盖与接触泛化的校准、以及多峰后验的无漏捕获**；一旦任务分布漂移、对称峰未被模式集合覆盖，`𝒯_α` 会漏掉真实位姿而 `D_contact` 仍显得很小，机器人就会带着“有证书”的自信把接触压到真实表面之外——因此必须以 **漂移检测 + 多峰并集 + 条件覆盖审计** 三重护栏，宁可在支持证据不足时拒绝适配并退回安全技能，绝不把少样本的“看起来对齐”当作接触几何的“已证实”。
