# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「视觉编码器」×「应用落地」）

> 第 59 轮把安全论证一路压到电流环、WCET 与阻抗参数，堵住了「执行器不是理想执行器」的抽象泄漏。但整条证据链的最上游仍踩在一个从未被审计的隐含前提上：**「感知 = 视觉编码器输出 = 可信观测」**。第 53~59 轮反复使用的 EV-vis、区域嵌入、共形校准、OOD 判据、跨模态对账，全部活在一个抽象的「特征空间」里，却从未追问：这个特征空间是谁给的？它在落地时还是同一个吗？**「视觉编码器」** 提醒我们：感知不是原生的像素真理，而是一个**冻结的、预训练的、各向异性的、可被量化的黑箱度量**——它决定了系统「能看见什么、把什么当作相似、把什么当作新奇」；**「应用落地」** 提醒我们：落地不是在实验室里再跑一遍，而是把模型塞进真实相机、真实光照、真实算力与真实 ISP 管线后，**它已经变成了另一个编码器**，而所有在 FP32 训练特征上签发的校准证书、覆盖保证、OOD 阈值，可能在部署那一刻就悄悄失效。本轮核心命题：**「把视觉编码器从『黑箱特征提取器』升级为『可校准、可预算、可契约化的感知证据源』；把『应用落地』从『部署一次』升级为『持续在场证明』——凡理论保证，必须附带一张随域偏移动态衰减、可在线续约、可被部署变换证伪的『在场证书』」**——从第 59 轮的**执行接地**推进到**感知落地（Perception-Grounded Deployment）**。

核心矛盾：

- **H42（部署变换失真·你签发的编码器不是你上线的编码器）**：共形阈值、ECE、OOD 判据都是在 FP32 / 原始分辨率 / 训练 ISP 的嵌入上校准的；落地却要经过 INT8/FP16 量化、TensorRT 算子融合、输入分辨率 224→518、patch size 变化、相机 ISP 调色、去噪、自动曝光。这些**不是无害的实现细节，而是嵌入空间上的非平凡映射 T**。一个 INT8 量化后的 DINOv2 与 FP32 版本余弦相似度分布会整体漂移，类条件共形集合的覆盖率保证随之作废——**「参数没变」不等于「证据没变」**。→ 需要**变换感知校准（DTI）**：把部署变换当协变量，用配对探针集给出失真上界，并据此膨胀共形阈值或拒绝上线。
- **H43（感知预算·编码器是落地算力的最大黑洞）**：第 59 轮的预算体系（探针/微调/解释/执行）完全没有显式计入视觉编码器的开销。现实是：边缘端 ViT 在 5~30 Hz 下的推理往往吃掉整机算力的最大一块，分辨率、token 数、编码器档位、推理频率共同决定「看得见」与「跑得动」。若不给感知单列预算，所有名义上的安全保证在真实硬件上**根本付不起**。→ 需要**感知预算 B_perc 与多保真感知（PBA）**：廉价档位常驻门控，昂贵档位按证据价值升级，五预算联合不可挪用。
- **H44（域外静默·ODD 从未声明，漂移从未量化）**：校准的交换性假设只在「部署域 = 校准域」时成立。真实场景的光照、材质、镜头、天气、遮挡持续漂移，编码器会**低熵地自信犯错**（anisotropic feature collapse）。没有显式运行设计域（ODD），系统无法知道「自己已经不在证书覆盖的范围内」。→ 需要 **ODD 契约 + 在场证书（DPC）**：运行期双样本漂移检验、保证衰减曲线、有效期与吊销机制；出域即保守降级。
- **H45（现场证据污染·落地数据会把系统越训越自证）**：落地后若把现场数据拿回来自我校准，会踩三重偏差：**选择偏差**（只记录成功/到访过的片段）、**表演性偏差**（我们的策略改变了数据分布）、**标签稀缺**。若不加护栏，现场证据会把不确定性往「更自信」的方向推，形成自证预言。→ 需要**现场证据闭环（FEL）与单调保守律**：现场证据只能加宽不确定性或触发重新认证，**不得**在没有独立审计的情况下收窄保证、减少探针。

## 0. 直觉与动机

**灵感 1（视觉编码器 → 嵌入几何接地 VEC）**
直觉：编码器不是「特征提取器」，而是**度量提供者**。所谓「区域」不过是预训练流形上的一个点，所谓「相似」不过是各向异性空间里的余弦。直接用原始嵌入会踩两个坑：**hubness**（少数「枢纽点」在任意查询里都排前面，导致假相似）与**各向异性**（少数主方向主导相似度，抹掉细粒度差异）。所以第一步不是换更大的模型，而是把嵌入**白化（ZCA）**、按类做**类条件共形**、用**能量/马氏/密度比**做几何感知的 OOD。关键洞见：**「共形」不会自动成立，它只在「分数函数 + 校准分布」都正确时成立；而视觉编码器的分数函数几何必须被显式矫正。**

**灵感 2（视觉编码器 × 应用落地 → 变换感知校准 DTI）**
直觉：落地是一条**变换链** `T = quantize ∘ prune ∘ fuse ∘ resize ∘ ISP`。每经过一环，嵌入都变一点，但没人量「变了多少」。DTI 的做法很朴素：准备一个**配对探针集**（同一批图像同时过 FP32 参考编码器与部署编码器），量出相对失真 `d_T`；只要 `d_T` 有界，就用分数函数的 Lipschitz 常数把共形阈值**保守抬高** `L_s·d_T`，覆盖率就仍然成立。若失真超界、或变换哈希变了，证书**立即作废**，必须重认证或回退保守感知。于是「落地」第一次有了**可证伪的验收标准**，而不是「跑起来了就算成功」。

**灵感 3（应用落地 → 感知预算与多保真感知 PBA）**
直觉：人看东西也不是每一帧都全神贯注。落地系统应该是**感知的 anytime 级联**：默认用 tiny 编码器 + 低分辨率 + 低频率做「有没有异常」的门控；只有当证据价值（VOI）超过升级成本时，才切到 DINOv2-large / 高分辨率 / VLM。感知动作 `π_perc=(encoder, resolution, tokens, frequency)` 是一个**有成本、有收益、可预算**的决策；它和 B_exec 共享同一块硬件，必须联合约束 `B_perc + B_exec ≤ B_hw`。

**灵感 4（应用落地 → ODD 与在场证书 DPC）**
直觉：安全保证不是永久产权，而是**有期限、有地域的租约**。定义 ODD（照度、相机、场景、天气、遮挡的取值集合）与校准域绑定；运行期用输入级与嵌入级的双样本检验持续监视漂移 `D̂_t`；保证强度 `W(t)` 随漂移与时间衰减，低于阈值或超出有效期即**吊销在场证书**，系统退回保守模式（降速、请求人工、切安全停）。落地 = 持续证明「我还站在证书覆盖的地面上」。

**灵感 5（应用落地 → 现场证据闭环 FEL 与单调保守律）**
直觉：现场数据是最贵的证据，也是最脏的证据。FEL 规定：现场证据**只能往保守方向用力**——加宽共形集合、触发重新认证、触发降级；**不能**直接减少探针、收窄置信区间。要收窄，必须通过**随机化审计采样 + 独立留出核验**这两道闸；否则宁可继续保守。这延续第 59 轮「EV-exec 只作对账、不作佐证」的单向安全原则，把它推广为**现场证据的单向保守性**。

**灵感 6（四灵感合流 → 五预算 PCE++++）**
直觉：第 59 轮的四预算再补上 `B_perc`，得到五预算：`B_probe / B_ft / B_ux / B_exec / B_perc`。VOI 计算显式扣除感知成本；任一预算耗尽只能让动作更保守。感知预算耗尽 ⇒ 降到最低档位 + 保守保底带；执行预算耗尽 ⇒ 冻结适配/降级；二者共享硬件时由联合约束裁决。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（视觉编码器证据校准 VEC）** 冻结编码器 `E_φ: ℐ→ℝ^d`，均值 `μ_cal`、协方差 `Σ_cal`。白化嵌入
```
z(x) = Σ_cal^{-1/2} (E_φ(x) − μ_cal)          # ZCA 白化，抑制 hubness/各向异性
```
类 `y` 的类条件原型 `m_y = mean_{x∈D_cal,y} z(x)`，非一致性分数
```
s_y(x) = 1 − cos(z(x), m_y)  （或马氏距离 ‖z(x)−m_y‖_{Σ_y^{-1}}）
```
类条件共形阈值 `q_y = Quantile_{1−α}({s_y(x): x∈D_cal, label=y})`，预测集 `C(x)={y : s_y(x) ≤ q_y}`，在交换性下 `P(y∈C(x)) ≥ 1−α`。几何感知 OOD：
```
E_ood(x) = −τ·log Σ_y exp(−s_y(x)/τ)          # 能量分数
ρ_ood(x) = p̂_field(z(x)) / p̂_cal(z(x))         # 密度比（分类器双样本估计）
```
`x` 判为 OOD 当 `E_ood > q_E` 或 `ρ_ood < ρ_min`。协变量偏移下用加权共形：权重 `w(x)=p̂_field(x)/p̂_cal(x)`，阈值取加权分位数，覆盖率仍 `≥1−α−ε_w`。

**定义 154（部署变换失真与变换感知校准 DTI）** 部署变换链 `T = T_k∘…∘T_1`（量化/剪枝/算子融合/分辨率/ISP），部署嵌入 `z_T(x)=Σ_T^{-1/2}(T(E_φ(x))−μ_T)`。配对探针集 `D_T={(x_i)}`，相对失真
```
d_T = E_{x~D_T}[ ‖z_T(x) − z(x)‖ / (‖z(x)‖+ε) ]   （或用 sup / 分位数）
```
若分数函数对嵌入是 `L_s`-Lipschitz，则部署后阈值保守化为
```
q_y^T = q_y + L_s·d_T   ⇒   P(y∈C_T(x)) ≥ 1−α
```
变换证书 `Cert_T=(hash(T), d_T, L_s, q^T, version, timestamp)`。规则：**变换哈希一变、或 `d_T > δ_T,max`，证书立即作废**；`d_T ≤ δ_T,max` 才允许上线，否则回退参考编码器或保守保底感知。

**定义 155（感知预算 B_perc 与多保真感知 PBA）** 感知动作 `π_perc=(e,ρ,k,f) ∈ Π`（编码器档位、分辨率、token 数、频率）。成本与延迟 `C(π)=c_comp(e,ρ,k)·f + c_energy`，`L(π)`；硬件联合约束 `B_perc + B_exec ≤ B_hw`。感知收益用互信息或共形集合收缩
```
U(π) = H(b) − E_{obs~π}[H(b|obs)]   （或 |C(x)| 的期望收缩）
VOI_perc(π) = U(π) − λ_c·C(π) − λ_l·L(π)
```
分配：在 `L(π) ≤ L_max, C(π) ≤ B_perc` 下最大化 `Σ VOI_perc`（贪心/注水/级联早退）。级联策略：默认 `e=small, ρ=low, f=low` 常驻；仅当边际 `VOI_perc > θ_perc` 时升级一档。预算单调消耗、跨类不可挪用；耗尽 ⇒ 最低档位 + 保守保底带。

**定义 156（运行设计域与在场证书 DPC）** ODD `𝒪 = {D : 照度∈𝕃, 相机∈ℂ, 场景∈𝕊, 天气∈𝕎, 遮挡率≤o_max}`，校准域 `D_cal ⊆ 𝒪`。运行期漂移统计 `D̂_t`（MMD / 分类器双样本检验 / 嵌入能量分布差异）。在场保证强度
```
W(t) = clip((1−α) − β·D̂_t − λ_age·(t−t_cert), 0, 1)
```
在场证书 `Cert_field=(E_φ version, hash(T), hash(D_cal), D̂_t, W(t), H_valid, timestamp)`。有效条件：`W(t) ≥ 1−α_min` ∧ `t−t_cert < H_valid` ∧ 漂移检验未报警。失效 ⇒ 保守降级（降速/请求人工/切安全停）。保证半衰期 `t_{1/2}` 由漂移速率估计，用于设定 `H_valid`。

**定义 157（现场证据闭环 FEL 与单调保守律）** 现场日志 `D_log` 由选择机制产生，`p_log(x)≠p_field(x)`；用重要性权重 `w(x)=p̂_field/p̂_log` 校正。四道护栏：**(G1)** 随机化审计采样：以固定概率 `ε_audit` 记录任意片段，与策略无关；**(G2)** 金丝雀留出区永不参与适配；**(G3) 单调保守律**：现场证据只能（a）加宽后验/共形集、（b）触发重新认证、（c）触发降级，**不得**直接收窄保证或减少探针；**(G4)** 重新认证需 `n_audit` 个独立样本 ∧ 人工抽检通过。只有 G1–G4 全过，才允许把现场证据写入校准集并续约 `Cert_field`。

**定义 158（感知证据 EV-perc 与证据门扩展）** 
```
EV-perc = (cert_field_valid, d_T, coverage_hat, D̂_t, encoder_version, ttl)
```
规则扩展：**(R1)** EV-perc 是 EV-vis 的**前置条件**，不是替代；`cert_field_valid=false ⇒ EV-vis 降级为「未认证观测」**。**(R2)** EV-perc 不得进入 EV-xmodal / EV-human 佐证集（感知非独立佐证）。**(R3)** `D̂_t` 报警 ⇒ 该区域历史 EV-vis 回溯标记为「可能域外」。**(R4)** 变换证书作废 ⇒ 全部 EV-vis 立即失效，直到重认证。

**定义 159（五预算耦合 PCE++++）** `B = (B_probe, B_ft, B_ux, B_exec, B_perc)`，五者单调、互不挪用、共享硬件处由 `B_perc+B_exec ≤ B_hw` 裁决。探针/承诺的 VOI：
```
voi_total(π) = VOI_meta_pessimistic(π) − cost_exec(π) − cost_perc(π; e,ρ,k,f)
```
任一预算不足 ⇒ 退到「可负担的次优」或保守停；**任何预算都不能被挪用去支撑更冒险的动作**，只能让动作更保守。

**定义 160（部署证书 J_deploy 与封装）** 
```
J_deploy = (E_φ version, Cert_T chain, D_cal hash, Cert_field chain,
            D̂_t trajectory, FEL audit log, B_perc trajectory, degradation_log)
```
`verify_deploy()` 检查：变换链哈希一致、`d_T ≤ δ_T,max`、`Cert_field` 未过期、FEL 审计计数达标、五预算无挪用、版本单增。任一失败 ⇒ 拒绝上线或强制保守模式。

### IP-152 VEC（视觉编码器证据校准）

```python
class VisualEncoderCalibrator:
    def __init__(self, encoder, alpha=0.05):
        self.E = encoder                 # frozen E_phi
        self.alpha = alpha
        self.mu, self.Sigma = None, None
        self.m_y, self.q_y, self.Sigma_y = {}, {}, {}
        self.q_energy, self.rho_ood = None, None

    def fit_whitening(self, D_cal):
        feats = np.stack([self.E(x) for x in D_cal])
        self.mu = feats.mean(0)
        self.Sigma = np.cov(feats, rowvar=False)
        self.W = zca_whiten(self.Sigma)   # Sigma^{-1/2}

    def embed(self, x):
        return self.W @ (self.E(x) - self.mu)

    def fit(self, D_cal):
        self.fit_whitening(D_cal)
        for y in classes(D_cal):
            Z = np.stack([self.embed(x) for x in D_cal if label(x) == y])
            self.m_y[y] = Z.mean(0)
            self.Sigma_y[y] = np.cov(Z, rowvar=False) + 1e-6*np.eye(Z.shape[1])
            s = [self.score(x, y) for x in D_cal if label(x) == y]
            self.q_y[y] = conformal_quantile(s, self.alpha)
        # OOD 校准：能量分数 + 密度比
        e_scores = [self.energy(x) for x in D_cal]
        self.q_energy = conformal_quantile(e_scores, self.alpha)
        self.rho_ood = fit_density_ratio(self.embed_many(D_cal),
                                          self.embed_many(heldout_id))

    def score(self, x, y):
        z = self.embed(x)
        return 1.0 - cosine(z, self.m_y[y])

    def energy(self, x):
        z = self.embed(x)
        return -TAU * logsumexp([-self.score_z(z, y)/TAU for y in self.m_y])

    def predict_set(self, x):
        return {y for y in self.m_y if self.score(x, y) <= self.q_y[y]}

    def is_ood(self, x):
        return self.energy(x) > self.q_energy or self.rho(x) < RHO_MIN

    def coverage_report(self, D_test):
        return mean([label(x) in self.predict_set(x) for x in D_test])
```

### IP-153 DTI（变换感知校准）

```python
class DeploymentTransformCertifier:
    def __init__(self, ref_calibrator, delta_T_max=0.08):
        self.ref = ref_calibrator
        self.delta_T_max = delta_T_max

    def certify(self, deployed_encoder, D_probe):
        dT = []
        for x in D_probe:
            z_ref = self.ref.embed(x)
            z_dep = zca_whiten_proj(deployed_encoder(x), self.ref)  # 用参考统计白化
            dT.append(np.linalg.norm(z_dep - z_ref) / (np.linalg.norm(z_ref) + 1e-8))
        d_T = float(np.percentile(dT, 99))          # 用 99% 分位，避免均值掩盖尾部
        if d_T > self.delta_T_max:
            return None, TransformVerdict(ok=False, d_T=d_T, reason="distortion_exceeds_bound")
        # 分数函数 Lipschitz 常数（数值估计）
        L_s = self.estimate_lipschitz(self.ref, D_probe)
        cert = TransformCertificate(
            transform_hash=hash_transform(deployed_encoder),
            d_T=d_T, L_s=L_s,
            delta_q=L_s * d_T,                    # 阈值保守抬升量
            version=self.ref.version, timestamp=now()
        )
        return cert, TransformVerdict(ok=True, d_T=d_T)

    def inflated_thresholds(self, base_q):
        return {y: q + self.cert.delta_q for y, q in base_q.items()}
```

### IP-154 PBA（感知预算与多保真感知）

```python
class PerceptionBudgetAllocator:
    TIERS = [("tiny", 224, 128, 5), ("small", 336, 256, 10),
             ("base", 518, 576, 15), ("large", 518, 1024, 20)]

    def __init__(self, budget_perc, hw_budget):
        self.B = budget_perc
        self.hw = hw_budget
        self.used = 0.0

    def select(self, belief, exec_reserve):
        best, best_voi = None, -inf
        for (e, rho, k, f) in self.TIERS:
            C = self.cost(e, rho, k, f)
            if self.used + C > self.B:            # 感知预算
                continue
            if C + exec_reserve > self.hw:        # 硬件联合约束
                continue
            L = self.latency(e, rho, k, f)
            if L > LAT_MAX:
                continue
            U = self.expected_evidence_gain(belief, e, rho, k, f)
            voi = U - LAMBDA_C*C - LAMBDA_L*L
            if voi > best_voi:
                best_voi, best = voi, (e, rho, k, f, C)
        if best is None or best_voi < THETA_PERC:
            return self.conservative_tier(), 0.0     # 保底带
        self.used += best[4]
        return best, best_voi

    def expected_evidence_gain(self, belief, e, rho, k, f):
        # 用历史分层统计近似：档位 e 在该区域带来的共形集合收缩
        return belief.expected_set_shrink(e, rho) * min(1.0, f / F_REF)
```

### IP-152 VEC（视觉编码器证据校准）

```python
class VisualEncoderCalibrator:
    """白化 + 类条件共形 + 几何感知 OOD"""
    def __init__(self, encoder, alpha=0.05):
        self.E, self.alpha = encoder, alpha
        self.mu, self.W = None, None
        self.m_y, self.q_y, self.Sigma_y = {}, {}, {}
        self.q_energy = None

    def fit(self, D_cal):
        feats = np.stack([self.E(x) for x in D_cal])
        self.mu = feats.mean(0)
        self.W = zca_whiten(np.cov(feats, rowvar=False))   # Σ^{-1/2}
        for y in classes(D_cal):
            Z = np.stack([self.embed(x) for x in D_cal if lab(x) == y])
            self.m_y[y] = Z.mean(0)
            self.Sigma_y[y] = np.cov(Z, rowvar=False) + 1e-6*np.eye(Z.shape[1])
            self.q_y[y] = conformal_quantile(
                [self.score(x, y) for x in D_cal if lab(x) == y], self.alpha)
        self.q_energy = conformal_quantile(
            [self.energy(x) for x in D_cal], self.alpha)

    def embed(self, x):
        return self.W @ (self.E(x) - self.mu)

    def score(self, x, y):
        return 1.0 - cosine(self.embed(x), self.m_y[y])

    def energy(self, x):
        z = self.embed(x)
        return -TAU * logsumexp([-self.score_z(z, y)/TAU for y in self.m_y])

    def predict_set(self, x):
        return {y for y in self.m_y if self.score(x, y) <= self.q_y[y]}

    def is_ood(self, x):
        return self.energy(x) > self.q_energy

    def weighted_conformal(self, D_cal, w):        # 协变量偏移
        self.q_y = {y: weighted_quantile(
            [self.score(x, y) for x in D_cal if lab(x) == y],
            [w(x) for x in D_cal if lab(x) == y], 1-self.alpha)
            for y in self.m_y}
```

### IP-153 DTI（部署变换感知校准）

```python
class DeploymentTransformCertifier:
    """配对探针测失真，膨胀共形阈值，变换哈希变更即作废"""
    def __init__(self, ref_calibrator, delta_T_max=0.08):
        self.ref, self.delta_T_max = ref_calibrator, delta_T_max

    def certify(self, deployed_encoder, D_probe):
        d = []
        for x in D_probe:
            z_ref = self.ref.embed(x)
            z_dep = zca_project(deployed_encoder(x), self.ref)   # 用参考统计白化
            d.append(np.linalg.norm(z_dep - z_ref) / (np.linalg.norm(z_ref)+1e-8))
        d_T = float(np.percentile(d, 99))                        # 尾部分位，非均值
        if d_T > self.delta_T_max:
            return None, TransformVerdict(False, d_T, "distortion_exceeds_bound")
        L_s = self.estimate_lipschitz(D_probe)                   # 数值估计
        cert = TransformCertificate(
            transform_hash=hash_transform(deployed_encoder),
            d_T=d_T, L_s=L_s, delta_q=L_s*d_T,
            version=self.ref.version, timestamp=now())
        return cert, TransformVerdict(True, d_T)

    def inflated_thresholds(self, base_q, cert):
        return {y: q + cert.delta_q for y, q in base_q.items()}
```

### IP-154 PBA（感知预算与多保真感知）

```python
class PerceptionBudgetAllocator:
    TIERS = [("tiny",224,128,5),("small",336,256,10),
             ("base",518,576,15),("large",518,1024,20)]

    def __init__(self, budget_perc, hw_budget):
        self.B, self.hw, self.used = budget_perc, hw_budget, 0.0

    def select(self, belief, exec_reserve):
        best, best_voi = None, -np.inf
        for (e, rho, k, f) in self.TIERS:
            C = self.cost(e, rho, k, f)
            if self.used + C > self.B: continue          # 感知预算
            if C + exec_reserve > self.hw: continue       # 硬件联合约束
            L = self.latency(e, rho, k, f)
            if L > LAT_MAX: continue
            U = belief.expected_set_shrink(e, rho) * min(1.0, f/F_REF)
            voi = U - LAMBDA_C*C - LAMBDA_L*L
            if voi > best_voi: best_voi, best = voi, (e,rho,k,f,C)
        if best is None or best_voi < THETA_PERC:
            return self.conservative_tier(), 0.0          # 保底档位
        self.used += best[4]
        return best, best_voi
```

### IP-155 ODD / 在场证书

```python
class InFieldWarrantMonitor:
    def __init__(self, alpha, beta=1.5, lambda_age=1e-4,
                 alpha_min=0.01, H_valid=3600.0):
        self.alpha, self.beta, self.lambda_age = alpha, beta, lambda_age
        self.alpha_min, self.H_valid = alpha_min, H_valid
        self.t_cert = now()

    def drift(self, D_recent, D_cal_emb):
        return mmd_rbf(D_recent, D_cal_emb)              # 或 C2ST-0.5

    def warranty(self, D_hat):
        age = now() - self.t_cert
        return clip((1-self.alpha) - self.beta*D_hat - self.lambda_age*age, 0, 1)

    def check(self, D_recent, D_cal_emb):
        D = self.drift(D_recent, D_cal_emb)
        W = self.warranty(D)
        valid = (W >= 1-self.alpha_min and
                 (now()-self.t_cert) < self.H_valid and D < D_ALARM)
        cert = FieldCertificate(
            encoder_version=CURRENT_ENC_VER, transform_hash=CURRENT_T_HASH,
            cal_hash=hash_cal(D_cal_emb), D_hat=D, W=W,
            H_valid=self.H_valid, valid=valid, timestamp=now())
        if not valid:
            enter_conservative_mode("warrant_revoked", D, W)
        return cert

    def renew(self, cert, audit_ok):
        if audit_ok and cert.valid:
            self.t_cert = now()
```
