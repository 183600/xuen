# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「深度学习」×「抓取位姿估计」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> **本轮纪律**：**共形化不确定性 + 抓取条件证书 + 学习否决单向律**。两个灵感直指 v9 的两处"承重假设"：其一，块证书余量 β 是离线常数，域一偏移就失效，而 v9 自陈最大风险恰是"Δ_dom 的 20 帧滑窗滞后于真实跳变"；其二，抓取位姿 γ̂_grasp 只是一个布尔，中止不变式只看末端点间隙，漏掉夹爪主体/腕部碰撞与力闭合滑脱。深度学习在这里提供的不该是"更强的网络"，而是**可检验的不确定性**与**只收紧不放宽的学习否决**；抓取位姿估计提供**任务终点即安全证书**的几何。仍以中立元退化保证：任一环节不可用 ⇒ 严格等价退回 v9。

## 0. 直觉与动机

**灵感 1（深度学习 → 把静态 β 换成自适应共形余量）**
直觉：v9 的 β = 信任域内经验误差上界 ×1.2，是一个**离线常数**。它把"域内误差"当成了"永远成立"。深度学习社区处理这件事的成熟工具不是换更大模型，而是**共形预测**：留出校准集算非一致性分数，取分位数 q̂，就有有限样本覆盖保证；分布漂移时再用**自适应共形推断（ACI）**按在线误覆盖反馈更新 α_t，得到长期覆盖保证。于是 β 从常数升级为状态量 β_t：既随当前 SE(3) 位姿不确定集收缩/膨胀，又随在线覆盖误差自校正。关键收益：ACI 的反馈直接用当前观测，不需要攒 20 帧——这在结构上补 v9 最危险的那个时间差。

**灵感 2（抓取位姿估计 → 任务终点即证书）**
直觉：抓取不是"把末端点送到一个坐标"，而是"让夹爪、接近方向、力闭合一起进入一个可信任的位姿管"。v9 的块证书只约束末端点间隙、γ̂_grasp 只有真/假两值，于是两类失败落在证书之外：(i) 指尖没碰但夹爪主体/腕部扫到障碍；(ii) 位姿够得着但力闭合裕度不足，搬运时滑脱。核心创新：**抓取条件块证书（GC）** 以 6-DoF 位姿 g 为块终态，证书同时约束**接近走廊扫掠间隙**（把夹爪包围体沿接近方向扫掠）、**力闭合鲁棒裕度**（抓取矩阵最小奇异值）与**可操作度裕度**；深度网络输出 SE(3) 位姿分布，共形集 C_α(x) 回答"哪些 g 仍值得信任"。

**灵感 3（深度学习 → 学习否决器，单向收紧）**
直觉：把深度学习放进安全闭环，最可信的接口不是"发许可"，而是"投否决"。核心创新：**学习否决器（LV）**，一个校准过的抓取成功率预测器，只与解析证书做**与门**：它可以拒绝解析证书接受的候选（例如透明物体、点云缺失、软体滑脱这些解析模型没建模的失败），却永远不能把解析证书拒绝的候选放进来。这样安全 soundness 完全由解析侧承担，学习侧只贡献"更保守"。再配**覆盖监控与回滚（CM）**，防止测试时自适应（TTA）用自生成伪标签形成"自我确认回声室"。

**灵感交叉（把"学习的不确定"接到"证书的几何"）**
直觉：共形集 C_α(x) 不是一个抽象集合，它在 SE(3) 里有直径 D_t；D_t 正是"终点抓取还没定准"的几何度量。于是 v9 用 Δ_dom/risk_SLAM 门控块长，v10 再乘一个**抓取不确定性门控**：位姿集越大，块越短；模态分歧 E_t 越大，越早收缩。这不是再加一个阈值，而是把学习不确定性变成和间隙同一量纲的证书约束。

## 1. 研究问题（轮次升级版）

- **Q1（漂移下的共形覆盖）**：交换性被域偏移破坏后，ACI 的长期覆盖保证如何在"成功标签延迟到达、且只对被安全否决器放行的抓取才有标签"这一**删失/选择偏差**下仍然成立？如何用重要性重加权或 ε-随机探索估计真实覆盖？
- **Q2（抓取条件中止安全）**：把接近走廊扫掠、力闭合、可操作度并入停车不变式后，中块中止是否仍保持 v9 引理 82 的局部安全论证？三维扫掠检查如何压进 0.3ms 的 50Hz 守卫预算？
- **Q3（学习否决的单向性与活性代价）**：如何形式化"学习只收紧不放宽"？假否决率与任务活性如何权衡？覆盖率监控能否在 TTA 漂移时阻止共形集塌缩而不引入新的抖振？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 共形证书律（Conformal Certificate, CC）**
软证书余量是**可观测量**而非常数：β_t 由 SE(3) 非一致性分数在目标误覆盖率 α_t 下的分位数 q̂_t 与共形集直径 D_t 决定；α_t 按 ACI 用在线覆盖误差更新。覆盖率是被监控的不变式，而不是写死在文档里的假设。

**P14 抓取条件安全律（Grasp-Conditioned Safety, GC）**
块终态是 6-DoF 抓取位姿 g ∈ C_α(x)：证书必含 (i) 夹爪包围体沿接近走廊扫掠的最小间隙、(ii) 力闭合裕度 σ_min(G(g)) ≥ ε_fc、(iii) 轨迹上最小可操作度 ≥ ε_μ。中止点不变式在"抓取条件证书"下重新定义，不再只检查末端点。

**P15 学习否决单向律（Learned-Veto-Only, LV）**
学习组件只允许与解析证书做**与门**：可行 = 解析证书 ∧ (学习否决器 abstain)。禁止"学习许可"。测试时自适应仅在覆盖监控健康时启用；监控越界即冻结自适应、回滚到最近通过校验的检查点，并把 K_eff 压到 1。

## 3. 与基线的接口（如何退化）

- CC 失效（校准集缺失 / ACI 发散 / 覆盖监控冻结）⇒ β_t ← β_0（v9 静态常数），K_eff 退回 v9 定义 539；严格等价 v9；
- GC 失效（位姿网络不可用 / 无 6-DoF 输出）⇒ 退回点间隙证书 + 布尔 γ̂_grasp（v9 定义 533/534）；严格等价 v9；
- LV 失效（成功率预测器不可用 / 未校准）⇒ 学习分支恒 abstain，仅解析证书；严格等价 v9；
- CM 触发回滚 ⇒ 恢复最近通过校验的 q̂ 与网络权重，冻结自适应，行为 ∈ 已认证格点；
- v9 的 AC/MW/ID 失效 ⇒ 逐级退回 v9 契约化五级链 → v8 → …；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9，再退回 v8。

中立元对应关系：共形约束的中立元是**全集 SE(3)**（交上它等于不变）；抓取条件的中立元是**点间隙证书**；学习否决的中立元是**恒 abstain**；ACI 的中立元是 **α_t ≡ α_0, β_t ≡ β_0**。四者都为恒等注入，故退化是逐位等价而非行为漂移。

## 4. 预期贡献

1. **共形块证书**：把 v9 的静态误差余量升级为有限样本/长期覆盖双保证的自适应余量，使"最需要安全时证书最不可靠"这一 v9 自陈风险获得结构性对冲；
2. **抓取条件安全证书**：把抓取位姿从布尔升级为带走廊、力闭合、可操作度三重约束的证书载体，覆盖"末端点安全但夹爪/腕部碰撞"和"到位但滑脱"两类 v9 盲区；
3. **学习否决单向律**：给"深度学习进安全闭环"一个可证明的接口——学习只能收紧可行集，安全 soundness 不依赖网络；并以覆盖监控阻断 TTA 自我确认漂移；
4. **不确定性-块长耦合**：用共形集直径 D_t 与模态分歧 E_t 直接门控 K_eff，形成比 DA-ML 更快的前导收缩通道；E571–E590 覆盖覆盖有效性、走廊/力闭合、否决 soundness、TTA 压力与端到端。

## 5. 本轮最大风险

**一句话**：共形覆盖保证依赖"可观测的抓取成功标签"，而真实成功标签只在抓取尝试之后延迟到达、且被安全否决器与信任域**选择性删失**（我们只尝试自认为安全的抓取），这种选择偏差会让 ACI 在从未探索的陌生抓取位上系统性高估覆盖率——证书在最需要证据的地方最缺乏标签。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-GCP**（Metric Voice Gauge with Grasp-Conformal Pose certificates）

**新增定义 540（抓取位姿分布 GraspPoseDistribution）** 位姿网络（深度集成或扩散蒸馏）在点云 x 上输出混合：p(g|x) = Σ_{k=1}^{K} ω_k·N_{se(3)}(g; μ_k, Σ_k)，Σω_k=1。每个模态给出局部协方差 Σ_k（aleatoric），模态间测地距离给出 E_t（epistemic）。E_t 是比 Δ_dom 更早的分布外信号：它不需要标签，也不依赖 20 帧滑窗。

**新增定义 541（SE(3) 非一致性分数 ConformityScore）**
```
s(x,g) = sqrt( (1/σ_t²)·||t − t̂(x)||² + (1/σ_R²)·||log(R̂(x)^T R)||² )
```
其中 (t̂,R̂) 为网络点估计，σ_t,σ_R 为标定尺度。校准集用人工标注或仿真真值抓取位姿 g_i*；亦可用"抓取成功残差"作为替代分数（成功=0，失败=1），两者按实验 E571/E588 选择。

**新增定义 542（分裂共形抓取集 SplitConformalGraspSet）** 校准集 {(x_i,g_i*)} 大小 n，分数 s_i=s(x_i,g_i*)。取
```
k = ⌈(n+1)(1−α)⌉,   q̂ = s_(k)（第 k 个次序统计量）
C_α(x) = {g : s(x,g) ≤ q̂}
```
在可交换性下 P(g* ∈ C_α(x)) ≥ 1−α（引理 87）；同时 ≤ 1−α+1/(n+1)。C_α 是测地球，D_t=2q̂，可直接与点间隙同量纲相加。

**新增定义 543（自适应共形与状态余量 AdaptiveConformal）** 每次真实标签到达（可能滞后 d 步）计算 err_t = 1[g_t* ∉ C_{α_t}(x_t)]：
```
α_{t+1} = Π_{[α_min,α_max]}( α_t + η·(α_target − err_t) )
q̂_t   = Quantile({s_i}, 1 − α_t)        # 滑动/扩张校准缓冲
β_t    = λ_β · q̂_t
```
ACI 在任意（含对抗）序列上给出长期覆盖：平均误覆盖率 → α_target（引理 88）。于是 β_t 是随漂移自校正的状态量，而非 v9 的离线常数。

**新增定义 544（抓取条件块证书 GraspConditionedCertificate）** 块终态 g ∈ C_α(x)，证书
```
Ĉ^g_t = ( g, ĝ_min^ap, γ_fc, μ_min, ê_max, q̂_t, D_t )
ĝ_min^ap = min_{θ∈[0,1]} clearance( Sweep(W_g, θ·ℓ·a(g)) , O )
γ_fc     = σ_min(G(g)) / σ_ref
μ_min    = min_{k≤K} μ(g_k)
```
其中 a(g) 为接近方向，ℓ 为接近走廊长，W_g 为夹爪包围体。证书有效 ⇔
`ĝ_min^ap ≥ d_safe ∧ γ_fc ≥ ε_fc ∧ μ_min ≥ ε_μ ∧ ê_max ≤ τ_eff ∧ q̂_t ≤ q_max ∧ g ∈ C_α(x)`。

**新增定义 545（学习否决器 LearnedVeto）** 校准后的成功率预测器 f_θ(x,g,traj) → p̂ ∈ [0,1]，附不确定度 σ̂（集成方差或 temperature-scaled 后验）。定义
```
v_learn = veto   若 UCB = p̂ + κσ̂ < τ_veto
        = abstain 否则
```
组合规则（与门，单向）：
```
feasible_v10 = feasible_analytic(Ĉ^g_t) ∧ (v_learn = abstain)
```
结构上不存在 permit 分支，故 LV 只能缩小可行集（引理 89）。

**新增定义 546（覆盖监控与回滚 CoverageMonitor）** 滑窗 W_c 内已获标签的抓取尝试覆盖率 cov_t。若 cov_t < 1−α_target−δ 连续 H_cov 个窗口：
1) 冻结 TTA（禁止任何权重更新）；2) 回滚到最近通过校验的检查点 (q̂, weights)；3) β_t ← β_last_good；4) K_eff ← 1，直到 cov_t ≥ 1−α_target+δ/2 连续 H_rec 个窗口。双阈 + 驻留，防止回滚-恢复抖振。

**新增定义 547（抓取锚定信任域与有效块长 GraspAnchoredGate）**
```
U_t^g = U_t^v9 ∧ (E_t < τ_E) ∧ (q̂_t ≤ q_max) ∧ (cov_t healthy)
K_eff^g(t) = 1                                        若 ¬U_t^g 或所有终态 g 被 veto
           = min( K_eff^v9(t),
                  max(1, ⌊K_max·(1 − D_t/τ_D)⌋) )       否则
```
K_eff^g ≤ K_eff^v9 恒成立；位姿越不确定、模态分歧越大、覆盖越差，块越短。

# IP-357 ConformalChunkCertifier：分裂共形 + ACI
class SplitConformalGrasp:
    def __init__(self, pose_net, alpha=0.1):
        self.net, self.alpha, self.qhat, self.scores = pose_net, alpha, None, []

    def calibrate(self, calib):                     # calib: [(pointcloud, g_star)]
        self.scores = sorted(d_se3(g_star, self.net.predict_pose(x))
                             for x, g_star in calib)
        n = len(self.scores)
        k = math.ceil((n + 1) * (1 - self.alpha))
        self.qhat = self.scores[min(k, n) - 1]

    def predict_set(self, x):
        return PoseBall(center=self.net.predict_pose(x), radius=self.qhat)

class AdaptiveConformal:
    def __init__(self, alpha0=0.1, eta=0.01, amin=0.02, amax=0.4):
        self.alpha = self.alpha_target = alpha0
        self.eta, self.amin, self.amax = eta, amin, amax

    def update(self, err_t, score_buffer):
        self.alpha = min(self.amax, max(self.amin,
                     self.alpha + self.eta * (self.alpha_target - err_t)))
        self.qhat = quantile(score_buffer, 1 - self.alpha)
        return self.qhat


# IP-358 GraspConditionedCertifier：在 AC 上增加抓取几何
class GraspConditionedCertifier(ActionChunkCertifier):
    def __init__(self, forward_model, policy, pose_net, conformal,
                 veto, d_safe=0.15, eps_fc=0.2, eps_mu=0.05, K_max=10):
        super().__init__(forward_model, policy, K_max)
        self.pose_net, self.cp = pose_net, conformal
        self.veto, self.d_safe = veto, d_safe
        self.eps_fc, self.eps_mu = eps_fc, eps_mu

    def generate_chunk(self, state, K_v9, gate):
        K = gate.effective_K(K_v9)
        if K == 1:
            return self._single_step_fallback(state)       # 等价 v9
        C = self.cp.predict_set(state.obs)
        best = None
        for cand in self.policy.sample_sequences_with_grasp(state, K, n=64):
            g = cand.terminal_pose
            if not C.contains(g):                          # 定义 542
                continue
            if force_closure_margin(g, state.obs.cloud) < self.eps_fc:
                continue
            g_ap = corridor_clearance(g, cand.approach, state.obs)  # 定义 544
            if g_ap < self.d_safe:
                continue
            pred = self.F.rollout(state, cand)
            if min_manipulability(cand) < self.eps_mu:
                continue
            if g_ap < self.d_safe - self.cp.qhat:          # 残差保守复核
                continue
            if self.veto.decide(state.obs, g, cand) == 'veto':   # 定义 545
                continue
            pts = self._abort_points_grasp(state, cand, pred, g)  # 定义 534
            if not pts:
                continue
            best = self.policy.better(best, Chunk(cand, Cert(g_ap, pred), pts))
        return best or self._single_step_fallback(state)

    def _abort_points_grasp(self, state, actions, pred, g):
        pts = []
        for p in range(1, len(actions)):
            remaining = pred.path_len[p:]
            margin = (pred.clearance_ap[p] - self.d_brake(pred.speed[p])
                      - self.d_safe - self.cp.qhat * KAPPA_AP)
            if margin >= remaining and force_closure_ok(g, state.obs):
                pts.append(p)
        return pts


# IP-359 LearnedVeto：只投否决
class LearnedVeto:
    def __init__(self, model, tau_veto=0.35, kappa=1.0):
        self.model, self.tau, self.kappa = model, tau_veto, kappa

    def decide(self, obs, g, traj):
        p, sigma = self.model.predict_success(obs, g, traj)
        ucb = p + self.kappa * sigma
        return 'veto' if ucb < self.tau else 'abstain'   # 无 permit 分支


# IP-360 CoverageMonitor：覆盖监控 + 回滚
class CoverageMonitor:
    def __init__(self, alpha=0.1, delta=0.05, H_cov=3, H_rec=3, win=50):
        self.alpha, self.delta, self.win = alpha, delta, win
        self.H_cov, self.H_rec = H_cov, H_rec
        self.buf, self.bad, self.good, self.frozen = deque(maxlen=win), 0, 0, False

    def observe(self, covered, cp, ckpt):
        self.buf.append(covered)
        cov = sum(self.buf) / len(self.buf) if self.buf else 1.0
        if cov < 1 - self.alpha - self.delta:
            self.bad += 1; self.good = 0
        elif cov >= 1 - self.alpha + self.delta / 2:
            self.good += 1; self.bad = 0
        if self.bad >= self.H_cov and not self.frozen:
            self.frozen = True; cp.restore(ckpt)         # 回滚
        if self.frozen and self.good >= self.H_rec:
            self.frozen = False
        return cov, self.frozen


# IP-361 GraspAnchoredGate：不确定性门控块长
class GraspAnchoredGate:
    def __init__(self, K_max, tau_D=0.15, tau_E=0.08):
        self.K_max, self.tau_D, self.tau_E = K_max, tau_D, tau_E

    def effective_K(self, K_v9, D_t=0.0, E_t=0.0, cov_ok=True):
        if not cov_ok or D_t > self.tau_D or E_t > self.tau_E:
            return 1
        return min(K_v9, max(1, int(self.K_max * (1 - D_t / self.tau_D))))

## 4. 推导

**引理 87（分裂共形覆盖）** 若校准样本 (x_i,g_i*) 与测试样本 (x,g*) 可交换，且分数 s 固定，则对任意 α∈(0,1)，P(g*∈C_α(x)) ≥ 1−α，且 ≤ 1−α+1/(n+1)。证明：次序统计量的标准秩论证；q̂ 取第 ⌈(n+1)(1−α)⌉ 个分数，测试分数落入前 k 的概率至少 k/(n+1)。C_α 为测地球，故 D_t=2q̂。∎

**引理 88（ACI 漂移下长期覆盖）** 对任意分数/标签序列（不要求可交换），按定义 543 的投影更新，长期平均误覆盖率满足
```
| (1/T)Σ_{t≤T} err_t − α_target | ≤ (α_max − α_min)/(ηT) + o(1)
```
故 β_t 不会系统性偏小；与 v9 静态 β_0 相比，漂移下覆盖更接近名义值。证明：ACI 的 Gibbs–Candès 漂移跟踪论证；投影保证 α_t 有界，逐步展开望远镜求和即得。标签滞后 d 步只把误差计入时刻后移 d，不改变长期平均。∎

**引理 89（学习否决单向安全）** feasible_v10 = feasible_analytic ∧ (v_learn=abstain) ⊆ feasible_analytic。故任何被解析证书排除的不安全动作仍被排除，v10 不引入新的不安全行为；LV 的假否决只减少可行候选，表现为活性/吞吐代价而非安全代价。特别地，v9 引理 82 对 v10 的解析部分原样成立。∎

**引理 90（抓取条件中止安全）** 设 (a) 走廊证书在模型误差界 β_t 下 sound；(b) 退避路径上力闭合裕度 σ_min(G(g))≥ε_fc 保持；(c) 退避沿接近方向单调。则从中止点 p* 停驻 (i) 夹爪包围体与腕部沿扫掠走廊无碰撞，(ii) 滑脱概率上界 1−γ_fc。证明：由 (a)(c)，扫掠体与障碍的最小间隙 ≥ d_safe + q̂κ_ap − β_t ≥ d_safe；由 (b)，力闭合锥在退避中不被破坏，滑脱事件包含于力闭合失效事件，其概率 ≤ 1−γ_fc。v9 引理 82 的末端点情形是本引理在 W_g→点 时的特例。∎

**引理 91（覆盖监控阻断自我确认漂移）** 若 TTA 更新仅在 cov_t ≥ 1−α−δ 时被接受，且监控在连续 H_cov 次越界后回滚到最近通过校验的检查点，则任一次被接受的更新都发生在经验覆盖健康窗口内；越界后状态返回已认证点（固定 q̂ 与权重），故共形集不会沿一条未经验证的伪标签链无界塌缩。结论是监控状态机的不变式：frozen ⇒ (q̂,weights)=(q̂_last_good, w_last_good)∧K_eff=1。∎（该引理以标签可得为前提；删失情形见第 8 节风险。）

**引理 92（抓取门控的单调保守性）** 对任意 t，K_eff^g(t) ≤ K_eff^v9(t)；且定义 544 的有效集 ⊆ v9 定义 533 的有效集（新增约束均为与门）。故 v10 的每块可行域与块长都不超过 v9，安全性不劣于 v9；性能损失由 D_t/τ_D、E_t/τ_E 与假否决率界定。∎

**引理 93（中立元与 v9 逐位等价）** 对表 548 每行：
CC→(β_t≡β_0)；GC→(点间隙证书、g←ĝ)；LV→(v≡abstain)；CM→(固定校准)；GG→(K_eff=K_eff^v9)。
这些分别是交运算的全集元、约束删除、与门真元、状态冻结与恒等映射；注入后算法骨架的每个分支回到 v9 定义 532–539，引理 82–86 原样适用，可观测日志逐位一致。∎

| 校准规模（E582） | n≤200 达标 | 主动采样校准集 |

| 块长平滑（E584） | 无 >1 跳变 | D_t 一阶低通、插值门控 |

## 8. 本轮最大风险

**一句话**：共形覆盖保证依赖"可观测的抓取成功标签"，而真实成功标签只在抓取尝试之后延迟到达、且被安全否决器与信任域**选择性删失**（我们只尝试自认为安全的抓取），这种选择偏差会让 ACI 在从未探索的陌生抓取位上系统性高估覆盖率——证书在最需要证据的地方最缺乏标签。
