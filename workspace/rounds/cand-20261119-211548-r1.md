# 第 14 轮（本轮灵感：「社会规范理解」×「成功率」）

> **基线**：MetricVoiceGauge-NCD-HUTDH v15（技能扩散版；定义 607–626；引理 125–130；实验 E661–E670；IP-378–401）。
> 本轮纪律：**规范只缩不放 + 成功率按规范细胞分层 + 歧义时先澄清后行动**。不推倒 v15：v14 的 SCD/DSD/DCA/EDC、v13 的 AIO/CPD/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。四个新组件——SNGI（社会规范语法归纳）、NCSC（规范条件成功率证书）、PRSR（群体鲁棒成功率路由）、NDBC（规范漂移边界检查）——一律以**中立元**接入，失效即严格退回 v15。本轮只做三件事：把"社会规范"从硬编码的礼貌规则改写为**带歧义的隐变量后验**、把"成功率"从标量平均值改写为**按规范细胞分层的最坏群体下界**、把二者合成一条"歧义越高，越先澄清/越保守"的行动规则。

## 0. 直觉与动机

**灵感 1（社会规范理解 → 规范是隐变量，不是几何约束）**
直觉：v15 的安全性建立在"碰撞、越界、失稳"这类**物理可观测**的硬约束上；但家用机器人在人身边失败，往往不是撞到人，而是"从两人中间穿过""在别人说话时插嘴""把东西递到错误的一侧""盯着人看太久"。这些规范的共同点是：(i) 没有物理 ground truth，只有**观察者的事后评判**；(ii) 随文化、角色、亲疏、场景而变；(iii) 常常**部分可观测**，机器人只能从示范、语言、微表情和纠正中反推；(iv) 规范之间可能**互相冲突**，且没有唯一正确解。因此不能把规范写成一条固定约束 `g(a,x)≤0`，而应写成**隐变量语法假设** `h`：每条假设给出"在什么上下文、对什么动作、对哪类观察者、违反到什么程度"。核心创新：**社会规范语法归纳（Social Norm Grammar Induction, SNGI）**。它维护后验 `b_t(h)`，把与观测相容的假设集合 `H_ε` 显式保留下来，并对每个候选动作给出**最坏违反区间** `[V_lo, V_hi]`。关键反直觉点与 v13 的 anytime 同构：**规范推断必须从"最保守的交集"出发，更多证据只能扩大假设集、从而缩小可接受集；任何提前停止都只会更保守，绝不会更放肆**。规范不是被"学会"后就可以放心使用的真理，而是一个**永远带歧义的约束源**。

**灵感 2（成功率 → 规范条件成功率与最坏群体下界）**
直觉：论文里的"成功率 95%"通常是在一个固定的评测分布上取平均。这个数字会同时掩盖两类失败：一是任务失败，二是**任务成功但规范失败**——机器人把杯子递到了人手里，却从人家胸前越过；它完成了任务，但这次交互在社会意义上是失败的。更糟的是，平均值会把少数群体、少数场景、少数文化**平均掉**：对 90% 的观察者很得体，对 10% 的观察者持续冒犯，平均成功率仍然漂亮。核心创新：**规范条件成功率（Norm-Conditioned Success Rate, NS）**与**规范条件成功率证书（Norm-Conditioned Success Certificate, NCSC）**。把每次交互的"成功"重新定义为 `S^N = 1{任务成功}·1{规范违反≤β}`，并按规范细胞（文化×角色×场景×观察者类型）分层；对每个细胞用 Mondrian 共形/Clopper–Pearson 给出**同时覆盖**的最坏群体下界 `WSucc = min_c NS(c)`。关键点：**成功率不是标量，而是一个按规范细胞索引的向量；只有最坏细胞的下界才是可承诺的成功率**。平均成功率只允许作为描述统计，不允许作为部署判据。

**灵感 3（两者相乘 → 敬让序、澄清—行动前沿与歧义塌缩）**
直觉：当规范歧义很高时，机器人有两条路：**(a) 行动但敬让**——在所有与证据相容的规范下，选一个"最不冒犯且仍能完成任务"的动作；**(b) 先澄清**——问一句"我可以从您右边递过去吗？"用一个低成本的社会动作换取规范信息。两者都有代价：敬让可能降低任务成功率（比如绕远路），澄清会打断人、显得笨拙，而且**"什么时候问、怎么问"本身也受规范约束**。核心创新：**群体鲁棒成功率路由（Population-Robust Success Router, PRSR）**与**澄清—行动前沿（Ask–Act Frontier）**。PRSR 在每一帧比较"行动的规范风险 + 任务失败风险"与"澄清的社会成本 + 延迟成本 + 澄清后的残余风险"，在 `WSucc` 下界、违反上界 `V_hi` 和澄清预算三者之间做在线选择；当歧义或观察者漂移超出校准支撑时，**规范漂移边界检查（NDBC）**强制塌缩到内置的"通用礼貌先验" `h_0`，而不是拿多数人的规范去赌少数人的容忍。

**三者如何统一**
v15 回答"在给定毫秒与技能预算内，能安全实现多少"；v16 回答"在多元观察者下，这个'实现'是否社会可接受、对最弱群体是否仍然成立"。统一为 **v15 之上的规范语义层**：`Exec_v16 ⊆ Exec_v15`。共享状态 `ζ_norm = (H_ε, V_hi, cell, s_lower, v_upper, ρ_norm, κ, drift, mode)`。SNGI 回答"规范可能是什么"，NCSC 回答"在这个规范细胞里，最坏群体的成功率下界是多少"，PRSR 回答"这一帧该行动、该敬让、还是该澄清"，NDBC 回答"现在还能不能相信校准集"。四者不是四个附加惩罚项，而是"规范后验—分层证书—澄清路由—漂移塌缩"的一条语义链。

## 1. 研究问题（轮次升级版）

- **Q1（规范的可证语义）**：如何把社会规范表示为可推断、可组合、可证伪的隐变量？在示范、语言、反馈三种异质监督下，后验 `b_t(h)` 的校准意味着什么？规范假设类的可识别性边界在哪里，何时只能得到"歧义集"而不能得到"规范"？
- **Q2（规范条件成功率的同时保证）**：`S^N` 是一个带规范事件的复合 Bernoulli，且规范细胞可能极不平衡。Mondrian 共形/Clopper–Pearson 在细胞样本极少、细胞数随场景增长时如何保持同时覆盖？"最坏群体下界"能否在观察者分布漂移与规范争议下仍然 sound？平均成功率的 Simpson 陷阱如何被证书结构本身排除？
- **Q3（敬让与澄清的最优性）**：在规范歧义下，"最小冒犯动作"与"先澄清"之间的最优策略是什么？澄清的信息增益、社会成本、延迟成本如何统一进 v15 的时限预算？澄清动作本身受规范约束时，是否存在"问也不对、不问也不对"的死区？敬让序是否一定存在极小元？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 规范只缩不放律（Norm Understanding Shrinks, Never Expands）**
规范可接受集必须定义为所有相容假设下可接受集的**交集**：`Acc^N_ε(c)=∩_{h∈H_ε} {a: V_h(a,c)≤β}`。证据增加、假设集收缩时，可接受集只能单调扩大；推断提前终止、假设集变大时，可接受集只能单调收缩。任何单个规范假设、任何多数投票、任何平均偏好，都不得**新增**动作授权或放宽 v15 的物理/技能阈值。

**P26 成功率分层报告律（Success Rate Is a Vector, Not a Scalar）**
部署与论文主指标必须报告按规范细胞分层的 `NS(c)` 及其同时下界，主判据是 `WSucc = min_c NS(c)`，平均成功率只能作为描述统计。任何"平均成功率达标"都不构成部署理由；未覆盖或样本不足的细胞必须显式标为"未认证"，不得用邻近细胞插补。

**P27 歧义先澄清律（Clarify Before Acting Under Ambiguity）**
当规范歧义 `κ(c)` 超过阈值、或最坏违反下界仍高于预算 β、且澄清的期望净收益为正时，只允许执行澄清动作或内置礼貌回退 `h_0`；禁止按"最可能规范"或"多数观察者偏好"行动。澄清动作本身也必须通过 v15 的物理/技能证书与 `h_0` 的规范检查。

## 3. 与基线的接口（如何退化）

- SNGI 失效 ⇒ `H_ε={h_0}`：只保留内置通用礼貌先验，不学习任何群体规范，**等价 v15 + 固定礼貌先验**；
- NCSC 失效 ⇒ 规范维度不做成功率承诺，沿用 v15 的任务成功率证书，规范细胞只记录不判据，**等价 v15 + SNGI 观测**；
- PRSR 失效 ⇒ 固定策略：先取 `h_0` 下的最小冒犯动作，再按 v15 的静态档位执行，无澄清优化，**等价 v15 + 敬让后处理**；
- NDBC 失效 ⇒ 使用静态规范先验、不做漂移检测，**等价 v15 + 静态规范层**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→…→v6 退化链退回；
- **安全继承**：SNGI 只做交集、NCSC 只做分层下界、PRSR 只在可行集中选动作/澄清、NDBC 只做塌缩。四端口均不能新增授权或放宽 v15 阈值；只要 `h_0` 的约束包含于 v15 的物理安全集，`Exec_v16⊆Exec_v15` 成立。

## 4. 预期贡献

1. **规范作为隐变量语法**：把社会规范从手工礼貌规则改写为带后验、歧义集与最坏违反区间的可推断对象，给出"只缩不放"的保守推断语义；
2. **规范条件成功率与最坏群体证书**：把成功率从标量平均改写为按规范细胞分层的向量，用 Mondrian 同时覆盖给出可承诺的最坏群体下界，显式排除平均成功率的 Simpson 陷阱；
3. **敬让序与澄清—行动前沿**：把"最小冒犯"和"先问再做"统一为规范歧义下的在线决策，给出澄清的净收益阈值与"问也不对、不问也不对"的死区刻画；
4. **规范语义层与物理实现层分离**：v15 管"物理/技能上能否实现"，v16 管"对最弱观察者是否社会可接受"，用 `Exec_v16⊆Exec_v15` 把社会风险与物理安全解耦；E671–E690 覆盖规范归纳、分层覆盖、平均幻觉、澄清权衡、漂移塌缩与端到端。

## 5. 本轮最大风险

**一句话**：社会规范没有独立于人群的 ground truth，校准集里的"观察者"很可能不是部署现场的"观察者"；机器人可能对校准人群做到"可证的最坏群体成功"，却把一个多数群体的规范当成普遍规范、系统性地冒犯未覆盖的少数群体，而澄清动作本身又被判断为失礼——于是它"对校准集既成功又礼貌"，却在真实世界里社会性地错了。

# IP-402 Social Norm Grammar Induction：交集式规范推断
class SocialNormGrammarInduction:
    def __init__(self, hypotheses, prior, beta, eps=0.05, h0=None):
        self.H = list(hypotheses)
        self.b = dict(prior)              # b_t(h)
        self.beta = beta
        self.eps = eps                    # 歧义半径：越大越保守
        self.h0 = h0 or UniversalCourtesyPrior()

    def update(self, demos, language, feedback):
        # 三类异质证据统一为对 h 的似然；
        # 反馈中的否定只提高违反规则的权重，不直接删规则。
        for h in self.H:
            ll = self._log_likelihood(h, demos, language, feedback)
            self.b[h] = normalize(self.b[h] * exp(ll))
        return self.b

    def ambiguity_set(self):
        return {h for h, p in self.b.items() if p >= self.eps}

    def violation_interval(self, a, c):
        Hs = self.ambiguity_set() or {self.h0}
        vals = [self._V(h, a, c) for h in Hs]
        return min(vals), max(vals)

    def acceptable(self, c):
        # 交集语义：只有在所有相容假设下都不超预算的动作才被放行
        return {a for a in ActionSpace
                if self.violation_interval(a, c)[1] <= self.beta}

    def contestation(self, c):
        Hs = self.ambiguity_set()
        return normalized_entropy([self.b[h] for h in Hs])

    def deference_order(self, a1, a2, c):
        # a1 ⪯_c a2 当且仅当在所有相容假设下 a1 都不比 a2 更冒犯
        Hs = self.ambiguity_set()
        return all(self._V(h, a1, c) <= self._V(h, a2, c) + 1e-9 for h in Hs)


# IP-403 Norm-Conditioned Success Certificate：Mondrian 同时下界
class NormConditionedSuccessCertificate:
    def __init__(self, alpha, beta, cells, n_min=200):
        self.alpha = alpha
        self.beta = beta
        self.cells = cells               # 预注册的规范细胞划分
        self.n_min = n_min
        self.data = {c: [] for c in cells}  # [(success, violation)]

    def add(self, c, success, violation):
        if c in self.data:
            self.data[c].append((int(success), float(violation)))

    def certify(self):
        K = max(1, len([c for c in self.cells if self.data[c]]))
        alpha_c = self.alpha / K          # Bonferroni；e-value 可自适应分配
        out = {}
        for c in self.cells:
            n = len(self.data[c])
            if n < self.n_min:
                out[c] = Cert(s_lower=0.0, v_upper=1.0, n=n,
                              alpha_c=alpha_c, valid=False,
                              reason='undercovered')
                continue
            ok = [s for s, v in self.data[c] if v <= self.beta]
            k = sum(ok)
            s_lower = clopper_pearson_lower(k, n, alpha_c)
            v_upper = hoeffding_upper([v for _, v in self.data[c]], alpha_c)
            out[c] = Cert(s_lower=s_lower, v_upper=v_upper, n=n,
                          alpha_c=alpha_c, valid=True)
        return out

    def worst_group_lower(self, certs):
        if not all(c.valid for c in certs.values()):
            return 0.0
        return min(c.s_lower for c in certs.values())

    def recalibrate(self, new_interactions):
        for c, s, v in new_interactions:
            self.add(c, s, v)

        self.C_ask = C_ask
        self.C_delay = C_delay
        self.ask_budget = ask_budget

    def choose(self, c, v15_candidates, sngi, certs, budget_remaining):
        # 1) v15 可行集：物理/技能/时限证书已通过
        V15 = list(v15_candidates)
        # 2) 规范交集可行集
        Nacc = sngi.acceptable(c)
        feasible = [a for a in V15 if a in Nacc]
        # 3) 最坏群体下界
        W = certs.worst_group_lower()
        # 4) 有可行且达标动作：先最小化最坏违反，再最大化成功率下界
        if feasible and W >= self.s0:
            return min(feasible, key=lambda a: (
                sngi.violation_interval(a, c)[1],
                -certs.expected_lower(a, c),
            )), 'act'
        # 5) 评估澄清：信息增益必须覆盖社会成本与延迟成本
        a_clar = self.best_clarification(c, sngi, certs)
        if a_clar is not None and budget_remaining > 0 and self.ask_budget > 0:
            ig = self.expected_info_gain(a_clar, sngi, c)
            net = ig * self.L_viol - (self.C_ask + self.C_delay)
            if net > 0 and sngi.violation_interval(a_clar, c)[1] <= self.beta:
                return a_clar, 'clarify'
        # 6) 死区：行动不安全、澄清不划算 -> 内置礼貌回退
        return sngi.h0.fallback(c), 'degrade'


# IP-405 Norm Drift Boundary Check：观察者 / 反馈 / 争议度漂移
class NormDriftBoundaryCheck:
    def __init__(self, cal_audience, cal_feedback, kappa_max=0.7,
                 rho_min=0.6, mmd_threshold=0.15, feedback_delta=0.1):
        self.cal_audience = cal_audience
        self.cal_feedback = cal_feedback
        self.kappa_max = kappa_max
        self.rho_min = rho_min
        self.mmd_threshold = mmd_threshold
        self.feedback_delta = feedback_delta

    def check(self, obs, sngi, certs, c):
        reasons = []
        if mmd(obs.audience_embedding, self.cal_audience) > self.mmd_threshold:
            reasons.append('audience_shift')
        if abs(obs.disapproval_rate - self.cal_feedback) > self.feedback_delta:
            reasons.append('feedback_shift')
        if sngi.contestation(c) > self.kappa_max:
            reasons.append('contestation')
        if certs.coverage(c) < self.rho_min:
            reasons.append('undercovered')
        return bool(reasons), reasons

## 2. 定义 627–646（关键形式化）

**定义 627（规范上下文）** `c=(task, setting, audience, culture, role)`；观察者 `o∼P_o(c)`。规范上下文不是场景坐标，而是**评判者的构成**：同一个几何动作在不同 `c` 下可以有不同的违反度。

**定义 629（规范语法假设）** 假设 `h={(φ_i,ψ_i,ω_i,w_i)}_{i=1}^{m_h}`，其中 `φ_i` 为上下文谓词、`ψ_i` 为动作谓词、`ω_i` 为观察者范围、`w_i∈[0,1]` 为违反权重：
```
ν_h(a,c,o) = 1 − ∏_{i: φ_i(c) ∧ ψ_i(a) ∧ o∈ω_i} (1 − w_i).
```
该形式允许规则叠加、冲突与部分违反；`h_0` 只包含"不触碰、不贴脸、进入私域先声明"等跨文化通用核。

**定义 631（歧义集）** `H_ε={h∈H: b_t(h)≥ε}`。ε 不是超参数噪声，而是**显式的保守旋钮**：ε 越大，越多低概率规范被纳入交集，授权越保守。

**定义 636（规范条件成功率）** 
```
NS(c) = P(S=1 ∧ V≤β | c) = E[1{S=1}·1{V≤β} | c].
```
任务成功与规范合规是**合取**，不是两个可互相补偿的加权项：一次高价值但严重冒犯的成功不折算成"部分成功"。

**定义 638（最坏群体成功率与证书）** `WSucc=min_{c∈Π} NS(c)`；证书 `C_succ` 满足
```
P( ∀c∈Π: NS(c) ≥ s_lower(c) ) ≥ 1−α.
```
部署判据是 `min_c s_lower(c) ≥ s_0`，而不是 `mean_c NS(c) ≥ s_0`。

**定义 640（规范—成功前沿）** 
```
F(c) = closure{ (s,v) : ∃π, P_π(S=1|c)≥s, sup_{h∈H_ε} E_π[V_h|c]≤v }.
```
PRSR 只在前沿的**可证下包络**上选点：`(s_lower(c), v_upper(c))`，不选经验均值点。

**定义 641（敬让序与最小冒犯动作）** `a⪯_c a' ⇔ ∀h∈H_ε: V_h(a,c)≤V_h(a',c)`。有限动作集上的预序必有极小元；`Min_c(S)` 为 `S` 中所有 `⪯_c` 极小元。注意：极小元不唯一，且**最小期望违反**不一定是**最小最坏违反**。

**定义 642–643（澄清—行动前沿）** `A^+=A∪A_clar`。行动的期望损失为
```
L_act(a) = V_hi(a,c)·L_viol + (1−s_lower(a,c))·L_fail,
L_clar(a) = C_ask + C_delay + (V_hi(a,c)−IG(a))·L_viol
            + (1−s_lower'(a,c))·L_fail,
```
其中 `IG(a)=E[V_hi^{before}−V_hi^{after}|a]`。澄清优于行动当且仅当
```
IG(a)·L_viol > C_ask + C_delay + (s_lower'(a,c)−s_lower(a,c))·L_fail.
```
若 `V_hi>β` 且上式不成立，则进入**死区**：行动不安全、澄清不划算，只能执行 `h_0` 回退。

**定义 646（v16 授权集）** 
```
Acc^{v16}(c) = Acc^{v15} ∩ Acc^N_ε(c) ∩ {a: C_succ(c).valid ∧ v_upper(a,c)≤β}，
Exec_v16 = { a ∈ Acc^{v16}(c) : RTIC_v15 可证 ∧ mode∈{act,clarify,degrade} }.
```
交集顺序不可交换：v15 先排除物理/技能不可行，SNGI 再排除规范不可接受，NCSC 最后排除统计上不可承诺的细胞。

## 3. 推导（引理 131–137）

**引理 131（规范推断的保守单调性）** 若 `H_{ε1}⊆H_{ε2}`，则
```
Acc^N_{ε2}(c) ⊆ Acc^N_{ε1}(c).
```
证明：交集对集合族单调反变：`∩_{h∈H_{ε2}} S_h ⊆ ∩_{h∈H_{ε1}} S_h`。推断提前停止只会让 `H_ε` 变大，因此只会缩小可接受集，绝不新增动作。∎ 推论：**规范学习不需要"学到正确规范"才安全；只需要"学得越多，交集越精确"。** 这与 v13 的 anytime 保守扩张同构。

**引理 132（平均成功幻觉）** 对任意 `δ∈(0,1)`，存在规范细胞分布与策略使
```
NS_avg ≥ 1−δ  而  WSucc = 0.
```
证明：取两个细胞，`P(c_1)=δ`、`NS(c_1)=0`、`NS(c_2)=1`，则 `NS_avg=1−δ`、`min_c NS(c)=0`。∎ 推论（Simpson 型）：跨策略比较时，若两策略在各细胞的成功/冒犯结构不同、细胞访问比例也不同，合并后的平均成功率可以**反转**逐细胞排序；因此"平均成功率更高"既不能证明更安全，也不能证明更成功。证书必须以 `WSucc` 为判据。

**引理 133（Mondrian 同时覆盖）** 设每个规范细胞 `c` 内校准样本与测试样本可交换，且对 `c` 使用显著性 `α_c` 的单侧 Clopper–Pearson 下界；若 `Σ_{c∈Π} α_c ≤ α`，则
```
P( ∀c∈Π: NS(c) ≥ s_lower(c) ) ≥ 1−α.
```
证明：对每个 `c`，`P(NS(c)<s_lower(c))≤α_c`；对所有 `c` 取并集上界得 `≤Σα_c≤α`。∎ 推论：细胞数 `K` 增大时 `α_c=α/K`，区间必然变宽；当 `n_c<n_min` 时证书必须标为 `valid=False`，不得用邻近细胞插补。可用 e-value 或分层 α 分配降低 Bonferroni 的保守性，但不得牺牲同时覆盖。

**引理 134（澄清—行动阈值）** 在定义 642–643 的损失下，澄清严格优于行动当且仅当
```
IG(a)·L_viol > C_ask + C_delay + Δs·L_fail,
```
其中 `Δs=s_lower'(a,c)−s_lower(a,c)`。证明：比较 `L_clar` 与 `L_act`，消去共同项即得。∎ 推论：当澄清几乎不提高成功率（`Δs≈0`）时，阈值退化为 `IG·L_viol > C_ask+C_delay`：**澄清只为规范信息付费，不为"问而问"付费**。当 `V_hi>β` 且阈值不成立时，存在既不能行动也不能澄清的死区，只能回退。

**引理 135（敬让序的 minimax 性质）** 设 `a*=argmin_{a∈Acc^{v15}(c)} V_hi(a,c)`。若 `V_hi(a*,c)>β`，则 `Acc^N_ε(c)=∅`；若 `V_hi(a*,c)≤β`，则 `a*∈Acc^N_ε(c)` 且在所有 v15 可行动作中最小化最坏违反度。证明：由 `V_hi` 的定义与 `a*` 的最优性，任意 `a` 满足 `V_hi(a,c)≥V_hi(a*,c)`；故若 `a*` 超预算，无动作可通过交集；否则 `a*` 通过且 minimax 最优。∎ 推论：**期望最优动作可能因少数观察者而被判为不可接受**；在规范歧义下，minimax 敬让与期望效用最大化不是同一个决策规则。

**引理 136（漂移下的规范安全塌缩）** 设漂移检测器触发后只允许 `h_0` 与 v15 物理证书的交集，则对任意未被检测到的规范变化，
```
P(规范违反超出 β) ≤ P(漏检) + P(h_0 本身超出 β) + P(无可用回退).
```
证明：若漂移被检出，系统不使用任何群体特定规范，违反只可能来自 `h_0` 未覆盖的文化特例（漏检项）或 `h_0` 自身失效；若漂移未被检出，则第一项计入漏检概率。`h_0` 的回退动作由物理构造保证可执行，故第三项为活性损失而非规范违规。∎ 推论：**漂移时不是"用更多数据赌一个规范"，而是用通用礼貌核买重校准时间**；`h_0` 只承诺通用礼貌，不承诺文化特例，必须把这个残余风险显式报告，而不是假装仍有完整保证。

**引理 137（规范—成功率—澄清三难）** 存在两个观察者群体与两个动作，使得对任意策略
```
WSucc = 1  ∧  sup_h V_h = 0  ∧  C_clar = 0
```
不可同时成立。证明：构造 `o_1,o_2`：`a_1` 对 `o_1` 合规且任务成功、对 `o_2` 完全冒犯；`a_2` 反之。若 `β=0` 且不澄清，任何动作都会对一个群体造成违反，故 `WSucc=0`；若强制 `WSucc=1`，必须按观察者选择动作，而这需要澄清或额外观测，故 `C_clar>0` 或存在残余违反。∎ 推论：**"最坏群体成功、零规范违反、零澄清成本"不可能三角**；可证的部署只能在 `β`、`s_0`、`C_ask`/澄清预算三者之间显式交换。

| 争议场景（E682） | 弃权/澄清可解释，不伪造共识 | 报告分歧谱、引入人类仲裁 |
| 消融（E683–E686） | 对应指标劣化达门槛 | 证明各模块必要性，定位瓶颈 |
| 实时性（E687） | p99≤22ms | 降 `|H_ε|`、预计算、扩大 `B_safe` |
| 端到端（E690） | 成功率 ≥v15−5% 且严重违规 ↓≥50% | 按消融定位、调 β/ε/澄清预算 |

## 7. 已知风险与失效模式

1. **规范假设类不可识别**：示范/语言/反馈可能同时兼容多个结构不同的 `h`，`H_ε` 永远无法收缩到单点。缓解：显式报告歧义集、主动澄清、把 `κ(c)` 纳入部署判据，而不是假装已学到唯一规范。

2. **没有 ground truth，规范是争议性的**：不同人群对同一动作的判断可能根本冲突，"最坏群体"也可能不是一个良定义的群体。缓解：把 `WSucc` 限制在预注册、可识别的细胞上；对争议场景只报告分歧与弃权，不把多数偏好包装成普遍规范。

3. **观察者分布偏移与少数群体欠覆盖**：校准集可能系统性缺少某类观察者，导致 `WSucc` 对真实少数群体失效。缓解：分层主动采样、少数细胞过采样、`n_min` 硬门槛、未知细胞直接判 `valid=False`。

4. **Mondrian 细胞过多导致样本不足**：`K` 增大使 `α_c=α/K` 与 `n_c` 同时恶化，证书变得极宽或全部失效。缓解：细胞合并、层级先验、e-value 自适应分配、预注册最小可识别细胞。

5. **Performative 反馈与内生校准**：机器人的澄清/敬让会改变观察者的反馈分布，使"校准集—部署"可交换性失效。缓解：分块/在线校准、探索下限、把澄清动作视为干预而非被动观测、报告因果漂移。

6. **澄清本身失礼或成本被低估**：频繁询问会打断人、显得无能，甚至在某些文化中被视为不礼貌。缓解：把 `C_ask` 设为上下文相关、限制澄清预算、把"问的方式"也纳入 `h_0` 与规范证书。

7. **语言/示范偏差与欺骗性反馈**：语言指令可能来自单一文化，反馈可能被少数人主导或对抗性操纵。缓解：多来源证据、对抗校准、置信度加权、检测后塌缩。

8. **规范冲突的死区**：两个观察者的规范完全相反且无澄清机会时，任何动作都违规。缓解：显式识别死区、执行 `h_0` 最小动作、请求人类仲裁，而不是随机选边。

9. **敬让绕行把机器人推入物理风险区**：为了"不冒犯"而绕开人群，可能进入 v15 未覆盖的狭窄/动态区域。缓解：每个候选动作必须先过 v15 证书，再做规范筛选；`Acc^{v16}` 是交集而非后处理，禁止"先选礼貌动作再补物理检查"。

10. **规范推断的隐私与监控风险**：对观察者文化、角色、偏好建模可能构成画像与隐私侵犯。缓解：只在本地、最小化特征、聚合而非个体化、明确同意与数据治理。

11. **实时预算被规范推断挤占**：`|H_ε|` 与 `|A|` 增大时交集计算可能超出 p99。缓解：预计算规则索引、限制 `|H_ε|`、分层缓存、超时则塌缩到 `h_0`。

12. **"对错误人群可证"与道德脆弱性**：最危险的不是数值错误，而是把校准人群的规范当成世界规范，并因为证书同时覆盖而获得虚假的道德确定性。缓解：把"证书对谁成立"作为一等公民写入接口；任何 `WSucc` 必须附带群体定义与覆盖声明；对未覆盖群体默认弃权/澄清。

## 8. 本轮最大风险

**一句话**：社会规范没有独立于人群的 ground truth，`WSucc` 只对预注册的规范细胞成立；当部署现场的观察者构成、反馈分布与规范争议同时漂移时，SNGI 可能把多数群体的规范当成通用核、NCSC 又因少数细胞欠覆盖而给出 `valid=False` 或过宽下界，PRSR 在"行动会冒犯、澄清也失礼"的死区里只能执行 `h_0`，最终在"每个细胞都有证书、每次澄清都合规"的表象下，系统性地把一个未被校准的群体排除在"成功"之外——即**对校准集可证的、对世界却社会性错误的成功**。
