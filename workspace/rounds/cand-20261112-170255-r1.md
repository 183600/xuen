# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「语义地图」×「知识图谱」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 场景-阻抗先验、CIEC 意图-约束锁定、EPIR 因果隔离、SERC 场景感知闭环、PCE++++ 四维认知预算、SIC 三元校验。但本轮两个灵感暴露出**三个结构性局限**：
> 1. **场景是封闭标签，不是空间实体**：SSM 的 Z_scene 是 10 个固定标签，π_scene(K|z) 与地图坐标 r 无关。同一「湿滑地面」在充电站旁与走廊尽头被赋予同一先验，而真实摩擦、坡度、可达性不同；场景先验因此是**无接地（ungrounded）**的，既无法跨区域迁移，也无法解释「为什么这里湿」。
> 2. **知识是平行表，不是关系图**：场景、意图、约束、证据各自是独立的数据结构，缺少 is-a / part-of / affords / causes 关系。于是「楼梯上的湿滑金属」无法由「楼梯」与「湿滑」组合泛化；「轻触」只能查硬编码表，无法沿「物体—脆弱属性—力约束」推理；开放世界新场景只能落入 unknown。
> 3. **证据是时序日志，不是可溯源的信念**：EPIR 用 seq+hash 保证「先后到达」，却无法回答「这条证据支持/否定了哪条先验」「错误先验应由哪条证据撤销」。证据之间没有 supports/refutes 边，错误观测可被静默吸收，无法做信念修正（belief revision），也无法追溯一次 dispatch 的完整推理路径。

## 0. 直觉与动机

**灵感 1（语义地图 → 场景是「空间-语义锚定的区域」）**
直觉：语义地图不是「给栅格贴标签」，而是把「区域 r」与「概念 z」用锚定函数 α 连起来：r 有米制坐标、协方差、有效时间；z 有本体类型与属性。场景语义应活在**区域节点**上，而不是全局标签上。关键洞见：**先验必须条件化于接地区域 (z, r)**；只有当锚定不确定度 σ_α 足够小，才允许把 A 区域的先验迁移到 B 区域，否则只能使用通用先验。这把第 60 轮的「场景置信度」升级为「场景置信度 × 锚定可信度」。

**灵感 2（知识图谱 → 机器人知识是「带类型的关系图」）**
直觉：把机器人知识写成异构图：区域—contains→物体—affords→动作；场景—is-a→概念；意图—requires→约束；证据—supports/refutes→先验。场景识别不再是「在 N 个标签里选一个」，而是**观测证据子图与本体概念子图的近似同构匹配**；新场景由已知概念经 part-of/is-a 组合而成。关键洞见：**关系边携带「为什么安全」的推导路径**，K_safe 不再是黑箱数值，而是可审计的图查询结果。

**灵感 3（合流 → 接地语义知识图谱 SMKG）**
直觉：语义地图提供「在哪里」，知识图谱提供「是什么、与什么相关、为什么」。二者合流为 SMKG：节点有类型，边有关系，符号节点经 α 锚定到米制区域。场景识别 = 开放世界子图匹配 OGSR；先验 = 带空间条件与溯源的 GKP；意图 = 图查询编译 IBG。关键洞见：**同一张图同时承担感知、推理与审计**，避免「感知标签、规划符号、证据日志」三套表示互相漂移。

**灵感 4（证据 → 溯源图证据 PGE 与信任修正 TBR）**
直觉：每条执行证据不是日志行，而是 Merkle DAG 中的一个事件节点，边指向它验证/反驳的先验、它所在的区域、它的因果父事件。证据链从「序号连续」升级为「因果+空间+信念三重可溯源」。当新证据与旧先验矛盾时，不静默覆盖，而由 TBR 按来源可信度、独立佐证数、时间衰减做最小修正；错误证据被隔离（quarantine），可回滚。

**灵感 5（预算 → 图谱认知预算 GCB / PCE+++++）**
直觉：图推理不是免费的：索引维护 B_index、子图匹配 B_query、锚定更新 B_ground、信念修正 B_revise 都要算力与延迟。把第 60 轮四维认知预算扩展为七维；图查询采用 anytime 语义：预算耗尽时返回当前最优且有误差界的结果，或退回物化视图/通用先验，绝不阻塞执行安全。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（语义-度量知识图谱 SMKG）** 时变异构图 G_t = (V_t, E_t, τ_V, τ_E, α, ω)：
- **节点类型**：V = V_region ∪ V_object ∪ V_scene ∪ V_afford ∪ V_intent ∪ V_constraint ∪ V_evidence ∪ V_prior ∪ V_agent；
- **关系类型**：E_sp（near/contains/adjacent/above/occludes）、E_sem（is-a/part-of/affords/requires/causes）、E_tmp（precedes/during/overlaps）、E_evi（supports/refutes/derived_from/validates）、E_epi（contradicts/refines/supersedes）；
- **类型签名**：τ_V: V→T_V，τ_E: E→T_E，并满足 domain/range 约束（如 affords: object→affordance）；
- **锚定函数**：α: V_region ∪ V_object → (r ⊂ M, Σ_α, [t_start, t_end])，把符号节点锚定到米制地图 M 的区域，Σ_α 为锚定协方差，t_start/t_end 为有效期；
- **溯源权重**：ω: E → (source, timestamp, trust) ∈ [0,1]。
图查询语言 Q 支持模式匹配、路径查询（如 r —contains→ o —affords→ a）与本体闭包 closure_onto(·)。

**定义 162（开放世界图场景识别 OGSR）** 给定观测证据子图 O_t = (V_obs, E_obs)（由力/滑移/视觉/地图遥测构建）与本体概念集 C：
- **概念闭包**：C* = closure_onto(C)（沿 is-a/part-of 展开，保持类型约束）；
- **匹配能量**：E_align(O, c, h) = λ_s·E_struct + λ_a·E_attr + λ_g·E_spatial，其中 h: O ↪ c 为子图同态；
- **场景后验**：P(c | O_t) ∝ P(c) · max_h exp(−E_align(O, c, h))；
- **开放检测**：s_open(O_t) = max_{c∈C_known} max_h exp(−E_align(O_t, c, h))；若 s_open < τ_open，不强制归入已知类，而生成假设节点 h_new（type=UNKNOWN，带 evidence 边与 quarantine 标记），并回退通用先验；
- **组合泛化**：若 c₁,c₂∈C* 且存在 part-of/affords 兼容关系，则 c_new = c₁ ⊗ c₂ 参与候选集，其先验由组件先验经关系算子合成。

**定义 163（空间接地知识先验 GKP）** 对场景概念 z 与其锚定区域 r = α(z)：
π(K | z, r, G) = N(K; μ_z + Δ_r, Σ_z + Σ_r)
其中 Δ_r 为区域特定偏移（由该区域历史证据估计），Σ_r 随锚定协方差 Σ_α 膨胀。信任度：
τ_trust(z,r) = σ( Σ_{e∈E_evi(z,r)} w_rel(e)·λ^{age(e)}·corr(e) − ρ·contradiction(z,r) )
corr(e) 为独立佐证数，λ∈(0,1) 为时间衰减。接地安全集：
K_safe^G = {K | P(K | z, r, G) ≥ τ_scene ∧ τ_trust(z,r) ≥ τ_trust} ∩ K_safe_base。
跨区域迁移核：k_G(r₁,r₂) = exp(−d_G(r₁,r₂)/ℓ)；仅当 σ_α(r₁),σ_α(r₂) ≤ τ_α 且 k_G ≥ τ_transfer 时，允许以方差膨胀方式迁移先验。

**定义 164（意图绑定图 IBG）** 意图表示为语义框架 I = (predicate, args, temporal, modality)，语句 u 经语义解析得到图查询 Q_u；绑定函数
ψ: (u, G, context) → Dist(Φ_constraint)
其中 Φ_constraint 为信号时序逻辑（STL）约束程序集合。组合规则：
- **序列**：ψ(u₁「然后」u₂) = ψ(u₁) ⋈_seq ψ(u₂)；
- **条件**：ψ(「若看到人则慢点」) = guard → constraint；
- **指代消解**：沿 E_sp/E_sem 从 context 节点解析「这个/它」；
- **歧义**：H(ψ) > τ_amb ⇒ 不锁定，生成澄清对话动作，而非猜测。
置信度足够时，锁定 ERTC 的约束子集，锁定持续到 STL 满足或超时。与第 60 轮 CIEC 相比，映射不再是固定字典，而是**图上的可组合查询**。

**定义 165（溯源图证据 PGE）** 证据事件 e = (id, t, seq, r, payload, parents, validates, pol)，其中 id = H(payload ‖ parents ‖ t ‖ seq) 为内容寻址。PGE 是只追加的 Merkle DAG E ⊂ G_evidence：
- **空间边** located_at(e, r)；**时序边** precedes(e₁,e₂)；**因果边** derived_from(e, parents)；
- **信念边** supports(e,f)/refutes(e,f)，f 为被验证/反驳的先验或约束节点；
- **因果偏序** ≺ 由祖先关系与「时间邻近 + 区域相邻」共同定义；seq 只作局部队列顺序，不再承担全局因果；
- **溯源完备度**：对每次 dispatch 的 K_safe 节点，若存在从 K_safe 到原始观测节点的路径，则该次执行溯源完备；完备率 = 完备 dispatch 数 / 总 dispatch 数。

**定义 166（信任感知信念修正 TBR）** 信念状态 B = (F, τ)，F 为图事实集，τ: F→[0,1]。新证据 e 到达时，修正算子 ∘：
1. **矛盾集**：K⊥ = {f∈F | e refutes f}；
2. **佐证门控**：若 e 对 f 的支持来自 ≥k 个独立来源（多模态/空间邻居/时间重复），或 τ(f) < τ_trust，则 commit；否则将 e 放入隔离区 Q，不改变 f；
3. **信任更新**：τ(f) ← clip(τ(f) + η·(supp(e,f) − γ·ref(e,f))·λ^{age}, 0, 1)；
4. **最小变更**：仅收缩 τ 低于阈值且无存活支持的 f，并追加 supersedes/tombstone 边，不删除历史；
5. **回滚**：沿 PGE 的祖先 DAG 重放到检查点，保证修正幂等。

**定义 167（语义图谱闭环 SGCL）** 算子 SGCL(M, G, goal, u)：
```
① 地图更新：M ← SLAM/odometry；α 更新；标记 stale 区域
② 预测：沿 E_sp/E_tmp 的场景转移子图做马尔可夫/随机游走，预测 z_{t+Δ} 并预取先验
③ 识别：OGSR(O_t, G) → (z, c_new?, s_open)
④ 接地：GKP 生成 π(K|z,r,G)，EEIS 编译 K_safe^G
⑤ 意图：IBG 解析 u → STL 约束；歧义则澄清；否则锁定 ERTC
⑥ 执行：dispatch(K_safe, cert)；采集 EV-exec
⑦ 证据：PGE.append(EV-exec) 并连 supports/refutes 边
⑧ 修正：TBR.revise；更新 z/r 的信任与先验
⑨ 预算：GCB 检查，必要时降级
⑩ 返回 (z, r, K_safe, evidence_subgraph, revision_log, cert)
```

**定义 168（图谱认知预算 GCB / PCE+++++）** B_G = (B_index, B_query, B_ground, B_revise, B_scene, B_intent, B_exec)：
- **B_index**：图内存、空间索引（R-tree/HSM）与物化视图维护；
- **B_query**：子图匹配/路径查询的 anytime 算力与延迟；
- **B_ground**：锚定更新与地图一致性检查；
- **B_revise**：信念修正与回滚；
- 其余继承第 60 轮。
VOI：
```
voi_G(π) = VOI_meta_pessimistic(π) − cost_query(π) − cost_ground(π) − cost_revise(π) − cost_exec(π)
```
降级：B_query 耗尽 ⇒ 返回物化视图 π_cache；B_ground 耗尽或 σ_α > τ_α ⇒ 通用先验；B_revise 耗尽 ⇒ 新证据只入隔离区不入信念；B_index 耗尽 ⇒ 丢弃冷区域子图（保留 tombstone 可重建）。

## 2. 关键推理骨架

```python
def semantic_graph_loop(M, G, goal, utterance):
    M.update_map()                                   # ① 地图/锚定更新
    stale = G.mark_stale_regions(M.drift, M.now)     # 锚定有效期检查

    z_pred = G.predict_scene(M.current_region, horizon=3)   # ② 图拓扑预测
    O = G.observe_subgraph(M.telemetry)              # ③ 观测证据子图
    z, c_new, s_open = OGSR.recognize(O, G.ontology)

    if s_open < TAU_OPEN:                            # 开放世界：不强行归类
        z = G.quarantine_hypothesis(c_new, O)
        prior = GKP.general_prior()
    else:
        r = G.anchor(z)                              # ④ 接地先验
        prior = GKP.prior(z, r) if anchor_ok(r) else GKP.general_prior()

    K_safe = EEIS.compile_with_prior(prior, M.delta_f_req)

    C = IBG.ground(utterance, G, M.context)          # ⑤ 意图图查询
    if C.entropy > TAU_AMB:
        return M.ask_clarification(C)                # 歧义：先澄清
    ERTC.lock(C.stl_constraints)

    cert = dispatch(K_safe, M.budget)                # ⑥ 执行
    ev = build_exec_evidence(M.telemetry, K_safe)

    pge = PGE.append(ev, located_at=M.current_region,
                     supports=K_safe.prior_node)     # ⑦ 溯源证据
    G = TBR.revise(G, pge)                           # ⑧ 信任修正
    G = GCB.throttle(G, M.budget)                    # ⑨ 图谱预算
    return z, K_safe, pge, G.revision_log, cert
```

## 3. 复杂度与正确性（概要）

| 组件 | 时间 | 空间 | 关键保证 |
|---|---|---|---|
| SMKG 更新 | O(log |V| + ΔE) | O(|V|+|E|) | 锚定误差有界，stale 区域可检测 |
| OGSR | O(b^d·|O|)（beam 剪枝） | O(|C*|·|O|) | s_open < τ_open 时禁止高置信归类 |
| GKP | O(k) 邻域查询 | O(1) 增量 | σ_α 门控下才允许跨区迁移 |
| IBG | O(|Q_u|·deg) | O(|Φ|) | 歧义熵超阈值必须先澄清 |
| PGE | O(1) 追加 | O(N_evid) 只追加 | hash 链 + DAG 因果可验证 |
| TBR | O(|K⊥|·k) | O(1) 增量 | k 源佐证门控，错误证据可隔离/回滚 |
| SGCL | O(闭环) | 复用 | 任一步失败回退第 60 轮 SGEC |

**正确性命题（SGC-61，条件性）**：若 A66–A70 成立，则：
1. **接地迁移安全**：σ_α > τ_α 时禁止跨区迁移，故先验迁移误差 ≤ L_π(σ_α + ε_drift)；
2. **开放世界不误判**：s_open < τ_open 时只用通用先验，错误归入已知类的概率 ≤ ε_open；
3. **修正可信**：单条对抗观测无法翻转 τ(f) ≥ τ_trust 的事实，需 ≥k 独立佐证；
4. **溯源完备**：每次 dispatch 都有到原始观测的路径，完备率 ≥ 1−ε_evid；
5. **预算安全**：任一 B_G 维度耗尽都返回保守策略，不阻塞执行安全。

## 5. 本轮最大风险

**一句话**：定位漂移会让错误区域的先验被「合法地」迁移到新场景，而知识图谱的本体闭包与子图匹配会把这一错误包装成高置信度、可自证的推理链，导致系统「有理有据地失败」——必须以锚定不确定度门控、未知隔离区、k 源独立佐证与可回滚溯源四重护栏，把「图上的自洽」与「物理上的正确」严格分开。

### IP-161 SMKG（语义-度量知识图谱）

```python
class SemanticMetricKnowledgeGraph:
    def __init__(self, ontology):
        self.V = {}                 # id -> Node(type, attrs, t_start, t_end)
        self.E = []                 # Edge(src, rel, dst, source, ts, trust)
        self.anchor = {}            # id -> (region, Sigma_alpha, t0, t1)
        self.spatial = RTree()      # 米制空间索引
        self.ontology = ontology

    def add_node(self, nid, ntype, attrs, t0, t1):
        self.V[nid] = Node(ntype, attrs, t0, t1)

    def add_edge(self, src, rel, dst, source, ts, trust=1.0):
        assert self.ontology.signature_ok(rel, self.V[src].type, self.V[dst].type)
        self.E.append(Edge(src, rel, dst, source, ts, trust))

    def anchor_node(self, nid, region, Sigma_alpha, t0, t1):
        self.anchor[nid] = (region, Sigma_alpha, t0, t1)
        self.spatial.insert(region.bbox, nid)

    def anchor_valid(self, nid, now, tau_alpha):
        if nid not in self.anchor:
            return False
        r, Sig, t0, t1 = self.anchor[nid]
        return t0 <= now <= t1 and trace(Sig) <= tau_alpha

    def mark_stale_regions(self, drift, now, tau_drift):
        return [n for n,(r,Sig,t0,t1) in self.anchor.items()
                if drift > tau_drift or not (t0 <= now <= t1)]

    def query(self, pattern, budget):
        # anytime beam search：返回当前最优匹配与下界
        best, bound = None, -inf
        for partial in beam_search(self, pattern, width=budget.beam):
            if not budget.spend_query(): break
            if partial.complete and partial.score > (best.score if best else -inf):
                best, bound = partial, partial.lower_bound
        return best, bound

    def closure_onto(self, concepts, max_depth=4):
        return self.ontology.closure(concepts, max_depth)
```

### IP-162 OGSR（开放世界图场景识别）

```python
class OpenWorldGraphSceneRecognizer:
    def __init__(self, G, tau_open=0.65, beam=32):
        self.G, self.tau_open, self.beam = G, tau_open, beam

    def recognize(self, O):
        known = [v for v in self.G.V.values() if v.type == 'scene']
        candidates = self.G.closure_onto(known)            # is-a / part-of 闭包
        candidates += self._compose_candidates(O)          # c1 ⊗ c2
        scored = []
        for c in candidates:
            h, energy = self._match(O, c, self.beam)
            if h is not None:
                scored.append((c, h, energy))
        if not scored:
            return None, self._new_hypothesis(O), 0.0
        c, h, energy = max(scored, key=lambda x: self._posterior(x))
        s_open = exp(-energy)
        if s_open < self.tau_open:                         # 开放集：拒绝强归类
            return None, self._new_hypothesis(O), s_open
        return c, None, s_open

    def _match(self, O, c, beam):
        # 近似子图同态：结构 + 属性 + 空间锚定三重能量
        best_h, best_e = None, inf
        for h in beam_homomorphisms(O, c, beam):
            e = (LAMBDA_S * structural_energy(O, c, h)
                 + LAMBDA_A * attribute_energy(O, c, h)
                 + LAMBDA_G * spatial_energy(O, c, h, self.G.anchor))
            if e < best_e:
                best_h, best_e = h, e
        return best_h, best_e

    def _posterior(self, item):
        c, h, energy = item
        return self.G.prior_concept(c) * exp(-energy)

    def _new_hypothesis(self, O):
        nid = f"scene:hyp:{hash_subgraph(O)[:12]}"
        self.G.add_node(nid, 'UNKNOWN', {'evidence': O.id}, t0=now(), t1=inf)
        for n in O.nodes: self.G.add_edge(nid, 'derived_from', n, 'OGSR', now())
        self.G.quarantine(nid)
        return nid
```

### IP-163 GKP（空间接地知识先验）

```python
class GroundedKnowledgePrior:
    def __init__(self, G, tau_scene=0.7, tau_trust=0.8, tau_alpha=0.05,
                 tau_transfer=0.6, ell=2.0):
        self.G = G
        self.tau_scene, self.tau_trust = tau_scene, tau_trust
        self.tau_alpha, self.tau_transfer, self.ell = tau_alpha, tau_transfer, ell

    def prior(self, z, r, now):
        if not self.G.anchor_valid(z, now, self.tau_alpha):
            return self.general_prior(z)
        if self.trust(z, r, now) < self.tau_trust:
            return self.general_prior(z)
        mu = self.mu[z] + self.delta_r.get(r, 0.0)
        Sigma = self.Sigma[z] + self.anchor_cov[r]
        return Normal(mu, Sigma)

    def transfer(self, z, r_src, r_dst, now):
        if not (self.G.anchor_valid(z, now, self.tau_alpha)
                and self.G.anchor_valid(r_dst, now, self.tau_alpha)):
            return None
        k = exp(-self.G.graph_distance(r_src, r_dst) / self.ell)
        if k < self.tau_transfer:
            return None
        # 迁移即方差膨胀：越远越不确定，绝不假装确定
        return Normal(self.mu[z] + self.delta_r.get(r_src, 0.0),
                      self.Sigma[z] + (1.0 - k) * self.Sigma_inflate)

    def trust(self, z, r, now):
        s = 0.0
        for e in self.G.evidence_edges(z, r):
            s += (e.weight * (LAMBDA ** (now - e.t))
                  * e.corroboration - RHO * e.refutes)
        return sigmoid(s)

    def safe_set(self, z, r, now, K_base):
        prior = self.prior(z, r, now)
        return {K for K in K_base
                if prior.pdf(K) >= self.tau_scene
                and self.trust(z, r, now) >= self.tau_trust}
```

### IP-164 IBG（意图绑定图）

```python
class IntentBindingGraph:
    def __init__(self, G, tau_amb=0.6):
        self.G, self.tau_amb = G, tau_amb

    def ground(self, utterance, context, budget):
        frame = self._parse(utterance)           # predicate/args/temporal/modality
        Q = self._to_graph_query(frame, context) # 指代沿 E_sp/E_sem 消解
        bindings, _ = self.G.query(Q, budget)    # 只在图上查，不查硬编码字典
        programs = self._compile_stl(bindings)
        for op, sub in frame.sequence_ops:
            programs = compose_stl(op, programs, self._compile_stl(sub))
        return ConstraintDistribution(programs)

    def need_clarification(self, dist):
        return entropy(dist) > self.tau_amb

    def _to_graph_query(self, frame, context):
        # 例："轻触 这个 玻璃杯"
        #  object --affords--> grasp
        #  object --has_property--> fragile
        #  fragile --requires--> F_max <= 0.8*F_nom, K_p <= 0.5*K_p_nom
        return Query(frame.predicate, args=resolve_refs(frame.args, context),
                     paths=['object -affords-> affordance',
                            'object -has_property-> property',
                            'property -requires-> constraint'])

    def _compile_stl(self, bindings):
        return [STL(until=..., always=..., eventually=..., bounds={
            'v_max': b.constraint.v_max,
            'F_max': b.constraint.F_max,
            'K_p': b.constraint.K_p,
            'K_d': b.constraint.K_d}) for b in bindings]
```

### IP-165 PGE（溯源图证据）

```python
class ProvenanceGraphEvidence:
    def __init__(self):
        self.dag = MerkleDAG()

    def append(self, event, located_at, supports=(), refutes=()):
        parents = tuple(event.parents)
        digest = sha256(canonical(event.payload)
                        + canonical(parents)
                        + str(event.t) + str(event.seq)).hexdigest()
        nid = f"ev:{digest[:16]}"
        self.dag.add_node(nid, type='evidence', payload=event, t=event.t)
        self.dag.add_edge(nid, 'located_at', located_at)
        for p in parents: self.dag.add_edge(nid, 'derived_from', p)
        for f in supports: self.dag.add_edge(nid, 'supports', f)
        for f in refutes:  self.dag.add_edge(nid, 'refutes', f)
        return nid

    def verify(self, nid):
        e = self.dag.node(nid)
        recomputed = sha256(canonical(e.payload) + canonical(e.parents)
                            + str(e.t) + str(e.seq)).hexdigest()[:16]
        return nid == f"ev:{recomputed}" and all(self.verify(p) for p in e.parents)

    def provenance_complete(self, dispatch_nid, raw_obs_types=('force', 'pose', 'vision')):
        # 从 dispatch 节点沿 derived_from 反向可达任一原始观测即完备
        return any(n.type in raw_obs_types
                   for n in self.dag.ancestors(dispatch_nid))

    def causal_precedes(self, e1, e2):
        # 因果偏序优先于 seq；seq 仅作局部队列
        return e1 in self.dag.ancestors(e2) or (
            abs(e1.t - e2.t) <= DELTA_T and adjacent(e1.r, e2.r) and e1.seq < e2.seq)
```

### IP-166 TBR（信任感知信念修正）

```python
class TrustAwareBeliefRevision:
    def __init__(self, k=2, tau_trust=0.8, eta=0.2, gamma=0.3, lam=0.99):
        self.k, self.tau_trust = k, tau_trust
        self.eta, self.gamma, self.lam = eta, gamma, lam
        self.quarantine = []

    def revise(self, B, e):
        contradictions = B.facts_refuted_by(e)
        for f in contradictions:
            sources = independent_sources(e, f)       # 多模态/空间邻居/时间重复
            if len(sources) >= self.k or B.tau[f] < self.tau_trust:
                B.tau[f] = clip(B.tau[f] + self.eta * (
                    self._supp(e, f) - self.gamma * self._ref(e, f))
                    * self.lam ** (now() - e.t), 0.0, 1.0)
                B.append_tombstone(f, e)               # 不删除历史，只标记失效
            else:
                self.quarantine.append(e)             # 单源反证：先隔离，不改信念
        return B

    def rollback(self, B, checkpoint_nid):
        for e in self.dag.forward_from(checkpoint_nid):
            B = B.replay_idempotent(e)
        return B
```

### IP-167 SGCL（语义图谱闭环）

```python
def semantic_graph_closed_loop(M, G, goal, utterance):
    M.update_map()                                           # ① 地图/锚定
    for n in G.mark_stale_regions(M.drift, M.now, TAU_DRIFT):
        G.anchor.pop(n, None)

    z_pred = G.predict_scene(M.current_region, horizon=3)    # ② 图拓扑预测
    O = G.observe_subgraph(M.telemetry)                      # ③ 观测子图
    z, c_new, s_open = OGSR.recognize(O)

    if s_open < TAU_OPEN:                                    # 开放世界：保守回退
        z = c_new
        prior = GKP.general_prior()
    else:
        r = G.anchor_of(z)
        prior = GKP.prior(z, r, now()) if G.anchor_valid(z, now(), TAU_ALPHA) \
                else GKP.general_prior()

    K_safe = M.eeis.compile_with_prior(prior, M.delta_f_req) # ④ 接地编译
    C = IBG.ground(utterance, G, M.context, M.budget)        # ⑤ 意图绑定
    if IBG.need_clarification(C):
        return M.ask_clarification(C)
    M.ertc.lock(C.stl_constraints)

    cert = dispatch(K_safe, M.budget)                        # ⑥ 执行
    ev = build_exec_evidence(M.telemetry, K_safe, cert)

    pge = PGE.append(ev, located_at=M.current_region,        # ⑦ 溯源证据
                     supports=(K_safe.prior_node,))
    G = TBR.revise(G, pge)                                   # ⑧ 信任修正
    M, G = GCB.throttle(M, G, M.budget)                      # ⑨ 图谱预算

    return z, K_safe, pge, G.revision_log, cert
```

### IP-168 GCB（图谱认知预算 / PCE+++++）

```python
class GraphCognitiveBudget:
    def __init__(self, index_ops, query_ops, ground_ops, revise_ops,
                 scene_ops, intent_ops, exec_budget):
        self.B = dict(index=index_ops, query=query_ops, ground=ground_ops,
                      revise=revise_ops, scene=scene_ops,
                      intent=intent_ops, exec=exec_budget)
        self.used = {k: 0 for k in self.B}

    def spend_query(self, n=1):
        if self.used['query'] + n > self.B['query']:
            return False
        self.used['query'] += n
        return True

    def mode(self, anchor_stale=False):
        if self.used['index'] >= self.B['index']: return 'evict_cold_subgraph'
        if self.used['query'] >= self.B['query']: return 'materialized_cache_only'
        if self.used['ground'] >= self.B['ground'] or anchor_stale:
            return 'generic_prior'
        if self.used['revise'] >= self.B['revise']: return 'quarantine_only'
        if self.used['scene'] >= self.B['scene']: return 'general_scene_prior'
        if self.used['intent'] >= self.B['intent']: return 'default_constraint'
        if self.used['exec'] >= self.B['exec']: return 'degrade_exec'
        return 'normal'

def voi_graph(pi, meta_voi, cost):
    return (meta_voi - cost.query - cost.ground
            - cost.revise - cost.exec)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SMKG 更新 | O(log \|V\| + ΔE) | O(\|V\|+\|E\|) | 锚定有效期/协方差可检查，stale 可检测 |
| OGSR | O(beam·\|O\|·\|C*\|) | O(\|C*\|·\|O\|) | s_open<τ_open 时拒绝高置信归类 |
| GKP | O(k) 邻域查询 | O(1) 增量 | σ_α 门控下才允许跨区迁移 |
| IBG | O(\|Q_u\|·deg) | O(\|Φ\|) | 歧义熵超阈值必须先澄清 |
| PGE | O(1) 追加 | O(N_evid) 只追加 | 内容寻址 + DAG 因果可验证 |
| TBR | O(\|K⊥\|·k) | O(1) 增量 | k 源佐证门控，可隔离/回滚 |
| SGCL | O(闭环) | 复用 | 任一步失败回退第 60 轮 SGEC |
| GCB | O(1)/维度检查 | O(1) | 任一预算耗尽返回保守策略 |

**假设 A66–A70**：
- **A66（锚定有界）**：锚定误差有界，且 α 对区域扰动 Lipschitz 连续；
- **A67（本体覆盖）**：观测概念可由已知概念在有限组合深度内表达，否则进入 UNKNOWN；
- **A68（溯源完整）**：PGE 只追加、哈希抗碰撞，EPIR 传输不破坏 DAG 父子关系；
- **A69（来源独立）**：佐证来源可判定独立，对抗来源比例上界已知；
- **A70（anytime 有界）**：图查询在预算内返回带误差界的结果，预算单调消耗。

**正确性定理（SGC-61， Semantic-Graph Consistency）**：若 A66–A70 成立，则：
1. **接地迁移安全**：当 σ_α > τ_α 时禁止跨区迁移；允许迁移时，先验误差 ≤ L_π(σ_α + ε_drift)，且方差随 k_G 膨胀，不会产生「远距离伪确定」。
2. **开放世界不误判**：当 s_open < τ_open 时只使用通用先验，故把新场景高置信误归为已知类的概率 ≤ ε_open；UNKNOWN 假设保留 evidence 边，可被后续证据提升或撤销。
3. **修正可信**：单条对抗观测无法翻转 τ(f) ≥ τ_trust 的事实；需 ≥k 个独立来源同时反证，故单源投毒成功率 ≤ 1/|S_ind|；所有修正可沿 PGE 回滚。
4. **溯源完备**：由归纳，每次 dispatch 节点沿 derived_from 可达至少一个原始观测；完备率 ≥ 1−ε_evid。
5. **预算安全**：任一 B_G 维度耗尽，GCB 返回保守模式（通用先验/物化视图/仅隔离/降级执行），不阻塞安全回退。

## 5. 本轮最大风险

**一句话**：定位漂移会让错误区域的先验被「合法地」迁移到新场景，而知识图谱的本体闭包与子图匹配会把这一错误包装成高置信度、可自证的推理链，导致系统「有理有据地失败」——必须以锚定不确定度门控、未知隔离区、k 源独立佐证与可回滚溯源四重护栏，把「图上的自洽」与「物理上的正确」严格分开。
