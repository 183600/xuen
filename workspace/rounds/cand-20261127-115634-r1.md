### 第 1 轮灵感驱动研究记录（新循环：快速原型 × 模块化设计）

**灵感词**：快速原型、模块化设计

**直觉与动机**：

前几轮把 KEMPC 一路加码到「九证一体」的 KTCG，安全论证越来越厚，系统却越来越像一块不可拆的巨石：每加一条常识规则，都要重走一遍证书、引理、复杂度分析；在真机上验证一个想法的周期以周计。这恰恰是「快速原型」与「模块化设计」要对症的两个病。

1. **快速原型（直觉）**：把「想法 → 可运行证据」的路径压缩到小时级。关键不是降低安全标准，而是把验证拆成阶梯：先在仿真里跑通（P1），再以影子模式与现役控制器并行（P2，不接管执行器），最后才上 HIL / 真机（P3/P4）。每一级都有明确的晋升证据与回滚点，因此「快」来自风险分层，而不是省略检查。

2. **模块化设计（直觉）**：把九证巨石拆成若干「带契约的知识单元」（MKU）。每个单元自己声明输入/输出端口、前置/后置条件、证书等级与代价；准入不再是写死的九连与，而是「按端口类型组合 + 逐单元验证」。这样一条规则可以独立开发、独立替换、跨机器人复用，而不是每次改动都牵一发动全身。

3. **关键洞见**：两者互为放大器。模块化把单个原型的成本降下来，快速原型又为模块的晋升/淘汰提供经验证据；于是系统从「静态证书巨石」变成「可演化的认证架构」。但这也埋下本轮最大的坑：**模块各自安全 ≠ 组合安全**，因为双足系统的执行器与状态是强耦合的，端口不相交在物理上往往并不成立。

**严谨定义（增量）**：

1. **模块化知识单元 MKU**：\(M=(id, V_{in}, V_{out}, P, Q, c, \kappa, \ell)\)。其中 \(V_{in},V_{out}\) 为带类型的端口集合；\(P:V_{in}\to\mathbb{B}\) 为前置，\(Q:V_{in}\times V_{out}\to\mathbb{B}\) 为后置；\(c\in\{\text{FAST},\text{FULL}\}\) 为证书等级；\(\kappa\) 为最坏证书代价；\(\ell\in\{P0,\dots,P4\}\) 为原型阶梯状态。其语义关系 \(R_M=\{(x,y)\mid P(x)\Rightarrow Q(x,y)\}\)。

2. **组合代数**：顺序组合 \(M_1\oplus M_2\) 要求 \(V_{out}(M_1)\) 与 \(V_{in}(M_2)\) 类型可对接，且 \(P_1(x)\Rightarrow P_2(y)\) 对所有 \((x,y)\in R_{M_1}\) 成立；并行组合 \(M_1\otimes M_2\) 要求写端口不相交（非干涉）或效应可交换。组合按 assume-guarantee 规则合成前后置条件，且 \(\ell(M_1\otimes M_2)=\min(\ell(M_1),\ell(M_2))\)——组合的成熟度不能高于最不成熟的成员。

3. **双层证书 TTC**：\(C_{full}\Rightarrow C_{fast}\)。\(C_{fast}\) 是 \(O(N_{module})\) 的必要条件，在 50Hz 控制环内运行；\(C_{full}\) 是离线充分证明。快速门只拒绝「不可能被完全认证」的计划，绝不误杀已被完全认证的计划。

4. **原型阶梯 RPL**：\(P0\) 规格 → \(P1\) 仿真 → \(P2\) 影子 → \(P3\) HIL → \(P4\) 现场。晋升需证据束 \(E\)；任一级失败回滚到上一已认证级；\(P1/P2\) 不接管执行器，故回滚天然安全。

5. **精化热插拔**：新模块 \(M'\) 可替换 \(M\)，当且仅当 \(P'\supseteq P\)、\(Q'\subseteq Q\)（更宽的前置、更强的后置）且 \(c'\ge c\)。精化保证替换不会新引入不满足不变式的计划。

6. **PM-KEMPC**：把 KT-MPC 的求解与准入重写为「模块注册表 + 类型检查 + 双层证书 + 阶梯状态机」，\(\mathrm{Exec}_{PM}=\bigcap_{M\in active}\mathrm{Admit}(M)\cap \mathrm{Fil}_{dynamics}\)，且只有 \(\ell=P4\) 的模块可进入执行分支。

**形式化目标（增量）**：

1. 给出组合类型安全（良类型组合仍是良类型 MKU）；
2. 给出带裕度的并行组合安全（\(\sum m_i + c_{couple}\le \rho\)）；
3. 给出精化单调性（精化替换保持不变式）；
4. 给出双层门的 soundness 与 liveness；
5. 给出阶梯回滚安全（非执行级永不破坏现场不变式）；
6. 在指南针步态/倒立摆上做 TTP、复用率、回归检出时延三组实验，验证「快」不以安全性为代价。

**本轮最大风险**：**模块化谬误**——每个模块的单体证书只看得见自己的端口与不变式，看不见多个模块对同一组执行器的耦合效应；快速原型又倾向于在交互测试之前就把模块晋升，于是「所有单体证书都通过、组合后却联合不安全」会成为最难发现的系统性风险。

### IP-467 Modular Knowledge Unit (MKU)

```python
@dataclass(frozen=True)
class Port:
    name: str
    typ: str                 # 'state' | 'control' | 'terrain' | 'mode'
    write: bool = False

@dataclass
class ModularKnowledgeUnit:
    """统一知识容器：任何规则先成为 MKU，才能进入组合与准入。"""
    id: str
    version: str
    v_in: frozenset[Port]
    v_out: frozenset[Port]
    pre: Callable[[Mapping], bool]
    post: Callable[[Mapping, Mapping], bool]
    cert_class: str = "FAST"        # FAST | FULL
    cost: float = 0.0               # 最坏证书代价 ms
    margin: float = 0.0             # m_i 安全裕度
    ladder: str = "P0"              # P0..P4
    provenance: str = "human"       # human | learned | transferred

    @property
    def write_ports(self) -> frozenset[Port]:
        return frozenset(p for p in self.v_out if p.write)

    def type_check(self, other: 'ModularKnowledgeUnit') -> bool:
        """顺序组合前的端口类型检查：输出能喂给输入。"""
        out_sig = {(p.name, p.typ) for p in self.v_out}
        in_sig = {(p.name, p.typ) for p in other.v_in}
        return bool(out_sig & in_sig) or not other.v_in

    def refines(self, old: 'ModularKnowledgeUnit') -> bool:
        """行为精化：更宽的前置 + 更强的后置 + 不降证书等级。"""
        return (self._pre_implies(old.pre)
                and self._post_stronger(old.post)
                and self._cert_rank(self.cert_class) >= self._cert_rank(old.cert_class))

    @staticmethod
    def _cert_rank(c: str) -> int:
        return {"FAST": 1, "FULL": 2}[c]

    def _pre_implies(self, old_pre) -> bool:
        # 由离线采样/区间验证给出；此处返回已缓存的精化证明位
        return self._refinement_witness.get(("pre", id(old_pre)), False)

    def _post_stronger(self, old_post) -> bool:
        return self._refinement_witness.get(("post", id(old_post)), False)
```

### IP-468 Module Composition Algebra (MCA)

```python
class ModuleCompositionAlgebra:
    """组合代数：顺序 ⊕、并行 ⊗，以及带裕度的安全判据。"""

    def compose_sequential(self, a: ModularKnowledgeUnit,
                           b: ModularKnowledgeUnit) -> ModularKnowledgeUnit:
        if not a.type_check(b):
            raise TypeError(f"port mismatch: {a.id} -> {b.id}")
        # assume-guarantee：a 的后置必须能推出 b 的前置
        if not self._guarantee_implies_assume(a, b):
            raise ContractError(f"{a.id} does not guarantee precondition of {b.id}")
        return ModularKnowledgeUnit(
            id=f"({a.id}>>{b.id})",
            version=f"{a.version}+{b.version}",
            v_in=a.v_in,
            v_out=(a.v_out | b.v_out),
            pre=lambda x: a.pre(x),
            post=lambda x, z: self._exists_mid(a, b, x, z),
            cert_class=self._min_cert(a.cert_class, b.cert_class),
            cost=a.cost + b.cost,
            margin=min(a.margin, b.margin),
            ladder=self._min_ladder(a.ladder, b.ladder),
        )

    def compose_parallel(self, a: ModularKnowledgeUnit,
                         b: ModularKnowledgeUnit) -> ModularKnowledgeUnit:
        # 非干涉：写端口不相交；若相交，必须有可交换或耦合界证明
        interference = a.write_ports & b.write_ports
        if interference and not self._effects_commute(a, b):
            self._require_coupling_certificate(a, b, interference)
        return ModularKnowledgeUnit(
            id=f"({a.id}||{b.id})",
            version=f"{a.version}*{b.version}",
            v_in=(a.v_in | b.v_in),
            v_out=(a.v_out | b.v_out),
            pre=lambda x: a.pre(x) and b.pre(x),
            post=lambda x, z: a.post(x, z) and b.post(x, z),
            cert_class=self._min_cert(a.cert_class, b.cert_class),
            cost=max(a.cost, b.cost),
            margin=min(a.margin, b.margin),
            ladder=self._min_ladder(a.ladder, b.ladder),
        )

    def composition_safety_margin(self, mods: list[ModularKnowledgeUnit],
                                  rho: float) -> float:
        """CSM = rho - Σ m_i - c_couple；>=0 才允许组合进入 P2 以上。"""
        coupling = self._coupling_bound(mods)
        return rho - sum(m.margin for m in mods) - coupling

    def _coupling_bound(self, mods: list[ModularKnowledgeUnit]) -> float:
        """共享执行器上的 Lipschitz 耦合界；由离线辨识得到。"""
        shared = set()
        for m in mods:
            for p in m.write_ports:
                if p.name in shared:
                    continue
                shared.add(p.name)
        # L 为执行器耦合矩阵的谱范数上界（辨识/区间包络）
        L = self._actuator_coupling_spectral_bound(shared)
        return L * sum(m.margin for m in mods)
```

### IP-469 Two-Tier Certificate (TTC)

```python
@dataclass
class TwoTierCertificate:
    """C_fast 是环内必要条件；C_full 是离线充分证明。"""
    fast_rules: list[Callable[[Mapping, Mapping], bool]]
    full_prover: Callable[[list[Scenario]], bool] | None = None
    fast_budget_ms: float = 0.5

    def fast(self, state: Mapping, action: Mapping) -> bool:
        # 一旦任一必要规则失败，立即拒绝，绝不进入优化后的执行分支
        return all(rule(state, action) for rule in self.fast_rules)

    def full(self, scenarios: list[Scenario]) -> bool:
        if self.full_prover is None:
            return False
        return self.full_prover(scenarios)

    def check_implication(self, scenarios: list[Scenario]) -> bool:
        """晋升前的自检：凡 full 通过者，fast 必须通过。"""
        for sc in scenarios:
            for state, action in sc.rollout():
                if self.full([sc]) and not self.fast(state, action):
                    return False
        return True
```

### IP-470 Rapid Prototype Ladder (RPL)

```python
@dataclass
class PromotionEvidence:
    type_checked: bool = False
    sim_pass_rate: float = 0.0
    shadow_divergence: float = 1.0
    hil_faults_passed: bool = False
    human_signoff: bool = False

class RapidPrototypeLadder:
    ORDER = ["P0", "P1", "P2", "P3", "P4"]

    def can_actuate(self, m: ModularKnowledgeUnit) -> bool:
        return m.ladder == "P4"

    def promote(self, m: ModularKnowledgeUnit, ev: PromotionEvidence,
                thresholds: dict) -> bool:
        cur = self.ORDER.index(m.ladder)
        if cur >= len(self.ORDER) - 1:
            return False
        nxt = self.ORDER[cur + 1]
        ok = {
            "P1": ev.type_checked and ev.sim_pass_rate >= thresholds["sim"],
            "P2": ev.sim_pass_rate >= thresholds["sim"] and m.cert_class == "FULL",
            "P3": ev.shadow_divergence <= thresholds["shadow"],
            "P4": ev.hil_faults_passed and ev.human_signoff,
        }[nxt]
        if ok:
            m.ladder = nxt
        return ok

    def rollback(self, m: ModularKnowledgeUnit) -> str:
        cur = self.ORDER.index(m.ladder)
        m.ladder = self.ORDER[max(0, cur - 1)]
        return m.ladder
```

### IP-471 Module Registry & Hot-Swap Gate (MRHG)

```python
class ModuleRegistry:
    def __init__(self):
        self._modules: dict[str, ModularKnowledgeUnit] = {}
        self._lock = threading.RLock()

    def register(self, m: ModularKnowledgeUnit) -> None:
        with self._lock:
            self._modules[m.id] = m

    def active(self, mode: str, terrain: dict) -> list[ModularKnowledgeUnit]:
        return [m for m in self._modules.values()
                if self._applies(m, mode, terrain)]

    def hot_swap(self, old_id: str, new: ModularKnowledgeUnit,
                 shadow_steps: int, probe) -> bool:
        """精化替换：先双跑 shadow_steps，再原子替换。"""
        with self._lock:
            old = self._modules.get(old_id)
            if old is None or not new.refines(old):
                return False
            # 双跑：新模块只观察、不执行；比较关键状态偏差
            for _ in range(shadow_steps):
                if probe.divergence(new) > probe.threshold:
                    return False
            self._modules[old_id] = new      # 原子替换
            return True
```

### IP-472 Prototype-Modular KEMPC (PM-KEMPC)

```python
@dataclass
class PrototypeModularKEMPC:
    dynamics: Callable
    registry: ModuleRegistry
    mca: ModuleCompositionAlgebra
    horizon: int = 20
    dt: float = 0.01
    rho: float = 0.05                # 不变式总裕度
    thresholds: dict = field(default_factory=lambda: {
        "sim": 0.95, "shadow": 0.05})

    def solve(self, x0: Tensor, mode: str, terrain: dict) -> 'PMResult':
        mods = self.registry.active(mode, terrain)

        # 1) 组合类型检查 + 契约检查（任一失败即拒绝，不进入优化）
        try:
            composed = self._fold(mods)
        except (TypeError, ContractError):
            return self._reject("composition_type_error")

        # 2) 环内双层证书的 fast 层
        ttc = self._build_ttc(composed, mods)
        if not ttc.fast({"x": x0, "mode": mode}, {"u": None}):
            return self._reject("fast_cert_failed")

        # 3) 优化（复用 KT-MPC 骨架，代价项来自 MKU 的 margin/权重）
        u_seq, x_traj = self._optimize(x0, composed)

        # 4) 只有 P4 模块可执行；其余进入影子
        exec_mods = [m for m in mods if m.ladder == "P4"]
        shadow = [m for m in mods if m.ladder != "P4"]
        u_exec = self._project_actuation(u_seq, exec_mods)
        self._shadow_step(x0, x_traj, shadow)

        # 5) 离线 full 证书（异步，不阻塞控制环）
        self._enqueue_full_cert(composed, x0)

        return PMResult(u=u_exec, traj=x_traj, composed=composed,
                        shadow_ids=[m.id for m in shadow])

    def _fold(self, mods):
        if not mods:
            raise ContractError("no active module")
        acc = mods[0]
        for m in mods[1:]:
            acc = (self.mca.compose_sequential(acc, m)
                   if acc.type_check(m)
                   else self.mca.compose_parallel(acc, m))
        return acc
```

## 4. 正确性论证（增量）

### 引理 26（组合类型安全）

**陈述**：若 \(M_1,M_2\) 端口类型可对接且契约蕴含成立，则 \(M_1\oplus M_2\) 是良类型 MKU，其 \(V_{in}=V_{in}(M_1)\cup(V_{in}(M_2)\setminus V_{out}(M_1))\)，\(V_{out}=V_{out}(M_1)\cup V_{out}(M_2)\)。

**证明**：类型检查保证共享端口的名称与类型一致；契约检查保证 \(P_1(x)\Rightarrow P_2(y)\) 对 \(R_{M_1}\) 中所有中间态成立，故后置合成 \(\exists y.\,Q_1(x,y)\wedge Q_2(y,z)\) 有定义。端口按定义取并集并消去内部端口，结构封闭。归纳到 \(N\) 个模块即得。\(\blacksquare\)

### 引理 27（带裕度的并行组合安全）

**陈述**：设不变式 \(I_\rho=\{x\mid \mathrm{dist}(x,\partial I)\ge\rho\}\)。若每个 \(M_i\) 以裕度 \(m_i\) 保持 \(I\)，且耦合界满足 \(c_{couple}=\sum_i m_i\cdot L\)，当 \(\sum_i m_i+c_{couple}\le\rho\) 时，\(M_1\otimes\cdots\otimes M_n\) 保持 \(I\)。

**证明**：各模块单独作用后状态距边界至少 \(m_i\)；共享执行器上的联合偏差由 Lipschitz 界 \(\|\Delta u_{joint}\|\le L\sum_i\|\Delta u_i\|\) 控制，折算到状态空间不超过 \(c_{couple}\)。由三角不等式，组合后的边界距离 \(\ge \rho-\sum_i m_i-c_{couple}\ge 0\)，故不越界。\(\blacksquare\)

### 引理 28（精化单调性）

**陈述**：若 \(M'\preceq M\) 且 \(M\) 保持 \(I\)，则 \(M'\) 保持 \(I\)。

**证明**：\(\preceq\) 要求 \(P'\supseteq P\)、\(Q'\subseteq Q\)，故在 \(P\) 成立的域上 \(R_{M'}\subseteq R_M\)；在 \(P\) 不成立而 \(P'\) 成立的扩展域上，\(Q'\) 更强，仍落在 \(M\) 的保证集合内。因此任何 \(M'\) 产生的转移都满足 \(M\) 的不变式，\(I\) 保持。\(\blacksquare\)

### 定理（双层门的 soundness 与 liveness）

**陈述**：设 \(C_{full}\Rightarrow C_{fast}\)。则 (i) 若 \(C_{fast}(\pi)\) 失败，则不存在 \(\pi\) 的完全证书；(ii) 若 \(C_{full}(\pi)\) 成立，则快速门必接受 \(\pi\)。

**证明**：(i) 由逆否命题：\(\neg C_{fast}\Rightarrow\neg C_{full}\)。(ii) 由蕴含直接得 \(C_{fast}(\pi)\) 成立，快速门只做必要条件的合取，故不拒绝。\(\blacksquare\)

### 定理（原型阶梯回滚安全）

**陈述**：对 \(\ell\in\{P0,P1,P2,P3\}\) 的模块，任何晋升失败或回滚都不改变现场控制器的安全不变式；\(P4\) 模块的降级回到最近一次通过 \(C_{full}\) 与 HIL 的版本。

**证明**：由 RPL 的 `can_actuate`，只有 \(P4\) 写执行器，非 \(P4\) 模块只做影子观测；因此其失败/回滚不产生执行作用。\(P4\) 晋升需 \(C_{full}\) 与 HIL 证据，降级按阶梯退回，且精化检查保证替换版本不弱于旧版本（引理 28）。对阶梯转移归纳即得。\(\blacksquare\)

## 5. 实验设计（快速原型闭环）

**平台**：指南针步态（compass-gait）简化模型 + 倒立摆平衡；状态 \(n_x=6\)，控制 \(n_u=2\)，仿真步长 \(dt=10\) ms。

**E1（十分钟原型，验证 TTP）**：只实现一个 `balance_rule` MKU（质心投影落在支撑多边形内），走 \(P0\to P1\)。记录从写规格到首次仿真通过的时间 \(TTP\)，并与在 v28 单体 KTCG 上新增同一条规则所需时间对比（LOC、改动文件数、验证步骤数）。

**E2（模块化 vs 单体）**：实现 5 条规则（平衡、支撑面积、关节限位、步高、地面摩擦）。模块化组按 MKU 独立开发并组合；单体组直接在 KTCG 中追加。比较：总验证时间、单规则平均改动面、\(\mathrm{RR}\)（复用模块工时占比）。

**E3（精化热插拔）**：把 `support_area` 规则从阈值 200 cm² 精化为「随摩擦系数自适应」的新版本，要求 \(P'\supseteq P, Q'\subseteq Q\)。在 1000 条留出场景上做替换前后回归；记录替换耗时与是否出现回归。

**E4（影子回归检出）**：向仿真注入 3 类故障（传感器偏置、执行器增益漂移、地面摩擦突变），新模块以 \(P2\) 影子运行，测量 \(\mathrm{RDL}\) 与误报率。

**E5（耦合反例，直击本轮最大风险）**：构造两个单体各自安全、但并行作用于同一踝关节时联合不安全的模块（一个要求快速前倾纠偏、一个要求快速后仰保持步高）。检验 (a) 非干涉判据是否报警；(b) 带裕度组合的 \(\mathrm{CSM}\) 是否转为负值并阻断 \(P2\) 晋升；(c) 若强行晋升，影子期能否在 \(k\) 步内检出。

**指标与预期**：

| 指标 | 定义 | 预期 |
|---|---|---|
| \(\mathrm{TTP}\) | 想法→首次 \(P1\) 通过 | 模块化 \(\le 0.5\) h，单体 \(\ge 4\) h |
| \(\mathrm{RR}\) | 复用模块工时 / 总工时 | \(\ge 0.6\) |
| \(\mathrm{CSM}\) | \(\rho-\sum m_i-c_{couple}\) | 安全组合 \(\ge 0\)，反例 \(<0\) |
| \(\mathrm{RDL}\) | 注入→影子告警 | \(\le 2\) s |
| 回归漏检率 | E3 中未检出的回归数 | \(0\) |

## 7. 本轮最大风险（最终确认）

**一句话**：**模块化谬误**——每个模块的单体证书只看得见自己的端口与不变式，看不见多个模块对同一组执行器的物理耦合，而快速原型又倾向于在交互测试之前就把模块晋升，于是「所有单体证书都通过、组合后却联合不安全」会成为最难发现的系统性风险。
