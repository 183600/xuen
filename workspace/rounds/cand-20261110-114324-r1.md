# 第 43 轮（新循环第 3 轮） · 协同鲁棒证书网 CoRoCert：从「单机证书飞轮」到「多智能体 Assume-Guarantee 鲁棒证书网」（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮：SCV × CKB × ECR）。v19 把证书变成「可进化的资产」，但它自始至终默认了**单体假设**：证书签给一台机器人、一条状态轨迹，扰动是「环境加给它的」。本轮两个灵感词精准击中这个盲点：**「协同控制」补上主体轴**——真实任务是多角色、共享工作空间、接触耦合、通信受限的团队作业，「每台都安全」并不推出「团队安全」，因为偏差会沿耦合接口被放大；**「鲁棒性」补上量化轴**——鲁棒性不能再是一个标量阈值 θ，而必须是**结构化扰动下的鲁棒半径**，并沿耦合图给出可组合的**放大界**。两轴相乘得到本轮主张：**协同安全 = 局部 Assume-Guarantee 证书的契约闭合 + 耦合图的鲁棒小增益条件；协同鲁棒性 = 在「角色/接口/时序」乘积空间上的可组合半径，而非逐机阈值的并集**。这把 v19 的「单机证书飞轮」升级为「CoRoCert 协同鲁棒证书网」。

## 0. 直觉与动机

**灵感 1（协同控制 → 证书不是「每台各签一张」，而是「角色之间的合同」）**：人类团队搬一张桌子，没人会分别证明「我这一侧不摔」，而是先约定「你抬左前、我抬右后、同时起、保持水平」——每个人承担的是一份**带前提的承诺**：只要邻居按约运动、通信不超时、共享物体不变形，我保证我这一侧不出界。v19 的 CAR/组合代数（IP-47）是「事后把单体证书拼起来」，缺的正是这个**事先的合同层**。直觉方案：显式定义协同任务结构（协作图 + 角色分配 + 耦合约束 + 接口变量），每个角色签一张 **Assume-Guarantee (A/G) 证书** C_i = (A_i, G_i, ρ_i)：A_i 是对邻居轨迹、共享物体、通信时延的显式假设，G_i 是对自身状态与接口输出的保证，ρ_i 是鲁棒半径。团队证书成立，不是「所有 G_i 各自成立」，而是**所有 A_i 都能被环境界或邻居的 G_j 消解**——这是一次**契约闭合**，不是一次逻辑与。

**灵感 2（鲁棒性 → 从「阈值 θ」到「半径 ρ + 沿图的放大谱」）**：v19 的 θ 是「边际不低于多少」，本质是单点鲁棒性。但协同系统里真正致命的不是「我离边界多远」，而是「邻居抖一下，会把我的裕度吃掉多少」。直觉方案：给每个角色定义**结构化扰动集** Δ = Δ_proc ⊕ Δ_model ⊕ Δ_adv ⊕ Δ_comm 与**鲁棒半径** ρ_i(x) = sup{ε : 所有 ‖δ‖≤ε 的扰动下，T_hold 内仍守 Inv_i}。更关键的是定义**耦合增益** γ_ij = 「j 的单位偏差，导致 i 为维持安全所需的控制/裕度消耗的上界」，组装成增益矩阵 Γ。若谱半径 ρ(Γ) < 1（小增益条件），则可证团队鲁棒下界 ρ_team ≥ (1−ρ(Γ))·min_i ρ_i；若 ρ(Γ) ≥ 1，说明协同结构本身不鲁棒，必须**收紧耦合**（降速、拉距、加缓冲、改角色），而不是继续给单机加保守裕度。

**灵感 3（两者耦合 → 退化格：把「鲁棒 vs 可用」的张力变成显式设计变量）**：v19 的最大可用性隐患是「一保守就长期滞留 Degraded/SafeStop」。协同场景把这个隐患放大：团队作业一停，吞吐骤降。直觉方案：预先定义一条**单调退化格** D = {Full → FormationTighten → RoleHandover → LeaderReassign → Decouple → SafeStop}，每一档都有可证的更大鲁棒半径、更低性能、更高可用性。运行时用**鲁棒裕度账本**跟踪每台/每接口的 ρ，当 ρ 低于阈值时只**下降到刚好恢复鲁棒性的最小档位**，并用无扰（bumpless）契约切换保证切换过程本身不越界。这样「鲁棒性 ↔ 可用性」不再是二选一，而是一条可计算、可审计的前沿。

**灵感 4（与 v19 飞轮的耦合升级）**：v19 飞轮的四段是「Sim 产数据 → RAG 存索引 → Edge 推理 → 实机反馈再入 Sim」。本轮把它改造成 **「相关/对抗联合扰动压力测试 → 契约模板与接口差集入库 → 边缘裕度账本与局部小增益检查 → 联合反例回灌（归因到角色/接口而非单机）」** 的 v8 飞轮。特别地，**联合反例是最高价值的数据**：它指出的往往不是某台机器人的控制器错，而是**接口假设不完备**（漏了一个共享变量、低估了通信延迟、没考虑接触切换时的力旋量跳变）——这正是最容易被平均指标掩盖、也最值得写进论文的失效面。

## 1. 形式化定义（增量：定义 38–46）

**定义 38（协同任务结构与角色契约）**：协同任务 ω = (G_c, r, Φ, I)，其中 G_c = (V, E_c) 为协作图（V 为智能体，E_c 为耦合边），r : V → R 为角色分配，Φ = {φ_e}_{e∈E_c} 为耦合约束（相对位姿、共享物体位姿、接触力旋量、共享资源令牌、时序先后），I = ⊔_{e=(i,j)} I_{ij} 为接口变量集 I_{ij} = (p_rel, v_rel, w_contact, o_shared, σ_comm, τ_time)。角色 ρ 的控制器 π_ρ 受其契约约束，任务语义由契约代数给出。

**定义 39（局部 Assume-Guarantee 证书）**：角色 i 的证书 C_i = (A_i, G_i, ρ_i)，其中 A_i 是**假设谓词**，定义在（环境扰动界、邻居轨迹投影 proj_{I_{ij}} x_j、通信时延/丢包界）上；G_i 是**保证谓词**，定义在（自身状态 x_i、接口输出 proj_{I_{ij}} x_i）上；ρ_i(x_i; A_i) 为在假设 A_i 下的鲁棒半径。**局部 sound**：若 [0,T] 内 A_i 恒成立，则从任意满足 Pre 的状态出发执行 π_i，在 T_hold 内要么守 Inv_i，要么在越 Guard_i 前触发 Abort_i；且对所有 ‖δ‖ ≤ ρ_i 的结构化扰动仍成立。

**定义 40（契约闭合与循环依赖的良基断裂）**：团队契约集合 {C_i} **AG-闭合**，指存在一个良基偏序 ≺（承诺序/时间交错序）与激活错位 Δ_t，使得对每个 i，A_i 要么被环境硬界消解，要么被某个 j≺i 的 G_j 在接口投影上消解，且通信延迟上界 Δ_comm 满足 Δ_comm < Δ_t。**接口残差** ρ_AG := max_{e=(i,j)} dist_{I_{ij}}(A_i, G_j)（各接口量程归一化）。**定理 40.1（良基闭合保 sound）**：若 A/G 闭合、ρ_AG ≤ τ_AG、且所有局部证书 sound，则团队在 [0,T] 内守 ∧_i Inv_i。**注意**：循环契约（i 假设 j、j 又假设 i）在无良基序或无收缩性时**不可证**——这是本轮刻意与「直接取交集」区分开的地方。

**定义 41（结构化扰动集与鲁棒半径）**：扰动 δ = (δ_proc, δ_model, δ_adv, δ_comm)，分别对应过程噪声、模型误差（含物体质量/摩擦/柔顺性偏差）、对抗性外部输入、通信延迟/丢包/抖动。**鲁棒半径** ρ_i(x) := sup{ε ≥ 0 : ∀δ ∈ Δ, ‖δ‖_W ≤ ε ⟹ 轨迹在 T_hold 内守 Inv_i}，W 为按量程归一化的加权范数；等价地，ρ_i 是**鲁棒可行核** K_i^rob 到安全边界的加权距离。用 CVaR_α 与最坏情形双估计给出 ρ_i 的上下界（上界用于认证，下界用于触发退化）。

**定义 42（耦合增益与协同小增益条件）**：对耦合边 (i,j)，**耦合增益** γ_ij := sup_{轨迹} [ i 为维持安全所消耗的裕度增量 ] / [ j 的接口偏差量 ]。组装增益矩阵 Γ = [γ_ij]（无耦合边取 0）。**协同鲁棒指标** η_team := 1 − ρ_spec(Γ)（ρ_spec 为谱半径）。**定理 42.1（协同鲁棒小增益界）**：若 ρ_spec(Γ) < 1，则团队鲁棒半径 ρ_team ≥ (1 − ρ_spec(Γ)) · min_i ρ_i。**推论 42.2**：当 η_team ≤ 0（临界或超临界）时，单机加裕度**不能**救团队——必须降低 γ_ij（降速/拉距/加缓冲/减耦合）或切换协同结构（改角色/解耦），否则任何有限的局部 ρ_i 都无法保证团队安全。

**定义 43（退化格与鲁棒-可用性前沿）**：退化格 (D, ⪯) 为全序 {Full ⪯ FormationTighten ⪯ RoleHandover ⪯ LeaderReassign ⪯ Decouple ⪯ SafeStop}，每档 d 带 (ρ(d), p(d), a(d))：鲁棒半径、性能、可用性，且 d 越靠后 ρ 越大、p 越小、a 一般越高（SafeStop 除外）。运行时策略：在保持 ρ_i ≥ θ_rob 与 η_team ≥ τ_η 的前提下，选**性能最高**的最小退化档；切换需满足**无扰条件** dist(Inv_d, Inv_{d'}) ≤ τ_switch 且切换窗口内 Δ_t 仍成立。**前沿** F := {(p(d), ρ(d), a(d))} 显式给出，作为设计与路演的一等指标。

**定义 44（相关/对抗联合扰动与覆盖）**：联合扰动分布 D_couple 定义在 ⊔_e Δ_{ij} 上，**相关结构**（共享地面摩擦、同一阵风、同一网络拥塞、同一物体刚度）用 copula 或结构化因子建模，禁止把各分量当独立采样。**联合覆盖** Cov_ε(D_couple) := P_{δ∼D_couple}[存在角色/接口失效] 的经验估计；**关键命题 44.1**：独立覆盖下界不能推出联合覆盖下界（相关失效会让联合覆盖率显著低于 ∏ 独立覆盖率），故 v19 的「逐边压力测试」必须替换为**联合对抗搜索**（在耦合约束边界的角点与同步故障组合上搜索）。

**定义 45（协同证书知识库与契约模板检索）**：KB 记录扩展为 (φ, ψ, G_c-拓扑摘要, R-角色集, Φ-耦合类型, C-契约模板, Ξ-联合反例, Π-协同课程相位)。检索 R(φ, ψ, G_c, R) 返回契约骨架；**差集** Δ_contract := { 接口假设 A_i 未被消解 } ∪ { 接口变量缺失 } ∪ { 时延界不满足 }，只在 Δ_contract 上重合成，而非整团队重算。

**定义 46（协同鲁棒成本模型）**：COT_team = C_sim / N_deploy + C_edge·T_life + C_comm·T_life + C_coord·N_task + C_human·N_verify，其中 C_comm 为邻居裕度/契约心跳的通信开销，C_coord 为每次重协调（改角色/收紧耦合）的开销。要求 COT_team 与单机 v19 **同数量级**，否则「协同」不可部署。

## 2. 产出设计（增量 IP-57/58/59 + 升级 IP-47/45/51/52/53/54/55/56/50/39/49）

### 2.1 IP-57 CO-ROBUST-CERT-COMPOSER（协同鲁棒证书合成器 CRCC）
1. **契约骨架生成**：从 (G_c, r, Φ) 自动生成每个角色的 A/G 骨架，显式列出接口变量集与时延界；缺失接口变量直接报错，不进入合成。
2. **循环断裂**：优先用**时间交错承诺**（j 先承诺 t+Δ_t 的 G_j，i 才假设 t 时刻的 A_i）或**收缩性/小增益**打破循环；无法断裂的契约标注 `Unverifiable` 并拒绝签发。
3. **小增益检查**：从仿真与在线数据估 Γ；若 ρ_spec(Γ) ≥ 1，返回**耦合收紧建议**（速度缩放、最小间距、缓冲时间、角色替换），而非简单放大 θ。
4. **契约模板检索**：KB 检索相似 (G_c, r, Φ) 的已验契约，只在 Δ_contract 上补全。
5. **输出团队证书**：含每条边的 A/G 证明义务、ρ_AG、Γ 估计与不确定度、退化格映射。

### 2.2 IP-58 ROBUST-MARGIN-LEDGER（鲁棒裕度账本 RML）
1. **逐角色裕度账本**：每拍记录 (ρ_i 上下界, 消耗速率, 已用扰动预算)，用 i16 定点压缩，<1KB/角色。
2. **邻居裕度交换**：经总线（IP-45）以低带宽心跳交换 ρ_j 摘要与契约版本；交换失败即视为 A_i 前提失效，进入退化格。
3. **在线增益估计**：由「邻居偏差 → 自身裕度消耗」的滑窗回归估 γ_ij，带乐观偏差修正（保守取上界），EWMA 平滑避免抖动。
4. **η_team 触发**：η_team < τ_η 或 ρ_i < θ_rob 时，按退化格选**最小可恢复档**，并检查无扰切换条件。
5. **切换审计**：每次退化/恢复写入可追溯日志（触发量、档位、切换残差），供事后 RCA 与论文。

### 2.3 IP-59 COOP-STRESS-REPLAY（协同对抗压力回放 CSR）
1. **相关联合扰动**：用结构化因子采样（共享摩擦/风/网络/刚度）替代独立采样，避免覆盖度虚高。
2. **对抗联合搜索**：在耦合约束边界（接触切换、最小间距、时延临界）上做角点与同步故障组合搜索，专打 γ_ij 的 sup。
3. **联合反例归因**：把失败归因到「角色 / 接口 / 时序 / 通信」四类，并指出缺失的接口变量，回灌 KB。
4. **鲁棒回归**：每次证书更新后重跑 ρ_i 与 Γ 的回归测试，防「修好单机、弄坏团队」。
5. **覆盖率-失效曲线**：输出联合覆盖 vs 团队失效率的经验曲线，作为 E87/E88 的直接证据。

    → IP-45 总线(协同心跳) → IP-53 CMC(本地+邻居+小增益三合一)

    → IP-55 CKB(契约模板 + 接口差集 + 版本化) → IP-44 蒸馏(边缘契约检查)
    → IP-50 协同课程(按 η_team 提难度) → RCA 重颁团队证书(含 ρ, Γ, 退化格) → 契约热更新
运行期：本地裕度(5μs) + 邻居摘要交换(低频) + O(E_c) 小增益检查 → 退化格最小迁移 → 飞轮触发 → Sim 联合重跑 → 契约更新
```

### IP-57 CRCC：A/G 契约合成与循环断裂

def compose_team_certificate(G_c, roles, coupling, KB):
    # 1. 契约骨架：显式列出接口变量与时延界；缺失即拒绝
    skeleton = build_ag_skeleton(G_c, roles, coupling)
    missing = check_interface_completeness(skeleton)
    if missing:
        return Reject(reason='missing_interface', vars=missing)

    # 2. 检索相似契约模板，只在接口差集上补全
    cand = KB.retrieve(topology=hash(G_c), roles=roles, coupling_types=coupling)
    C = merge_contract_templates(cand, skeleton)

    # 3. 用时间交错承诺断裂循环；失败则尝试小增益收缩
    if has_cycle(G_c):
        order = try_time_staggering(G_c, comm_delay_bound=DELTA_COMM)
        if order is None:
            order = try_small_gain_order(G_c)     # 收缩性/耗散性判据
        if order is None:
            return Reject(reason='unverifiable_cycle')
        C.set_commit_order(order)

    # 4. 接口闭合检查
    rho_AG = max_interface_residual(C)            # dist(A_i, G_j|I_ij)
    if rho_AG > TAU_AG:
        C = patch_assumptions(C, delta=find_contract_gaps(C))
        rho_AG = max_interface_residual(C)

    # 5. 小增益检查：超临界则给收紧建议，不放宽阈值
    Gamma = estimate_gain_matrix(C, sim=SimCfg.coupled)
    if spectral_radius(Gamma) >= 1.0 - TAU_ETA:
        tighten = propose_coupling_tightening(Gamma, C)
        return Recompose(tighten)                 # 降速/拉距/加缓冲/换角色

    return TeamCertificate(C, rho_AG=rho_AG, Gamma=Gamma,
                           order=order, degradation=map_degradation_lattice(C))
```

### IP-58 RML：裕度账本、γ 估计与退化格迁移
```
def rml_step(local_state, neighbor_summaries, cert, ledger):
    # 1. 本地鲁棒半径上下界（认证用上界，触发用下界）
    rho_hi, rho_lo = robust_radius_bounds(local_state, cert.A_i)
    ledger[i].update(rho_hi, rho_lo, used_budget=disturbance_used(local_state))

    # 2. 邻居心跳缺失 = 假设 A_i 失效 → 直接考虑退化
    for j in cert.neighbors(i):
        if not fresh(neighbor_summaries[j], timeout=DELTA_COMM):
            return migrate_degradation(ledger, reason=f'contract_lost:{j}')

    # 3. 在线保守估计 γ_ij（滑窗回归 + 乐观偏差上修 + EWMA 平滑）
    for j in cert.neighbors(i):
        g = regress_upper_bound(margin_consumed=ledger[i].d_margin,
                                dev=neighbor_summaries[j].dev)
        ledger.gamma[i][j] = ewma(g, alpha=0.2, conservative=True)

    # 4. 小增益触发：只降到刚好恢复鲁棒性的最小档
    eta = 1.0 - spectral_radius(ledger.gamma)
    if min(rho_lo.values()) < THETA_ROB or eta < TAU_ETA:
        return migrate_degradation(ledger, target='minimal_recover')

    # 5. 无扰切换检查（切换窗口内承诺序仍成立）
    return ledger

def migrate_degradation(ledger, target='minimal_recover', reason=''):
    d = ledger.current
    while not (min(ledger.rho_lo) >= THETA_ROB and
               1.0 - spectral_radius(ledger.gamma) >= TAU_ETA):
        d = next_degradation(d)                 # Full → … → SafeStop
        if d is None:
            return SafeStop(reason=reason)
    if not bumpless_condition(ledger, d):       # dist(Inv_d,Inv_d') ≤ τ_switch
        d = next_degradation(d)
    ledger.current = d
    audit_log(ledger, d, reason)
    return ledger
```

def cooperative_stress_test(G_c, coupling, N=1000):
    # 1. 相关联合扰动：共享因子（摩擦/风/网络/刚度），禁止独立采样

**一句话**：协同鲁棒证书网把失效点从「单机保守」换成了 **「循环契约的良基性」与「耦合增益 Γ 的乐观估计」**——若通信延迟破坏了「更早承诺」的时间错位、或相关联合扰动覆盖不足导致 γ_ij 被低估，系统会「每台局部有证、团队全局失稳」；这种失效比单机静默失效更隐蔽、后果更大，因此 E87（契约闭合正确性）与 E88（小增益漏报 = 0）必须作为**红线实验**，任一不达标即全链路熔断并回退到严格主从契约。
