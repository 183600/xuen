# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「痛点分析」×「深度相机」；技术基线延续 v15）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版：SCD/DSD/DCA/EDC；定义 607–626；引理 125–130；实验 E661–E670）。
> 本轮纪律：**自由空间只认证不假设 + 痛点只增不减 + 感知预算只买回不越权 + 失效即退回 v15**。不推倒 v15：v15 的 SCD/DSD/DCA/EDC、v13 的 AIO/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。六个新组件——CIF（认证深度区间场）、DPA（深度痛点图谱）、CFS（认证自由空间）、PPM（痛点监视器）、PBA（痛点预算分配器）、DFL（深度退化阶梯）——一律以**收缩/中立元**接入：只给区间、只加膨胀、只取单侧包含、只做嵌套；失效即严格退回 v15（引理 135），再沿 v15→v14→…→v6 退化链退回。本轮只做三件事：把"深度相机输出"从点云改写为**带覆盖保证的深度区间场**、把"无碰撞"从"没看到点"改写为**有正证据的认证自由空间**、把"痛点分析"从定性清单改写为**可分配预算的证书损耗函数**。

## 0. 直觉与动机

**灵感 1（深度相机 → 深度不是距离，是区间；自由空间需要正证据）**
直觉：机器人几乎都把深度相机当成"度量真值"，但每个像素其实只报告"我看到的第一个表面大约在 d"。它从未说过"这条射线前面是空的"——那是我们替它补上的假设。真实传感器有透明、镜面、暗色、掠射、多路径、运动模糊、标定漂移等失效模态；在这些地方，它可能返回一个**又窄又自信、却系统性错误**的深度，也可能什么都不返回。于是最危险的错误不是"点云很脏"，而是**把"没有点"当成"没有东西"**：一个洞可能是一面玻璃、一块黑色吸光海绵，也可能真的是空。核心创新：**认证深度区间场（Certified Interval Field, CIF）**。对每条射线 r，不再只保留一个深度 `d̂`，而是保留一个带覆盖保证的区间 `I_r=[d_lo,d_hi]`，满足 `P(d*∈I_r)≥1−α`；无效返回直接置 `I_r=[0,∞)`。**认证自由空间（Certified Free Space, CFS）** 只把 `s ≤ d_lo − m_safe` 的部分算作自由；`[d_lo,∞)` 一律算作"未认证"，规划器把它当障碍。关键反直觉点：**自由空间是"看出来的"，不是"没看见障碍"推出来的**；证书只做单侧包含 `F ⊆ Free*`，宁可把未知当障碍，也绝不把洞当通道。

**灵感 2（痛点分析 → 痛点图谱、只增不减与证书损耗函数）**
直觉：工程上的"痛点分析"常写成一张定性清单：玻璃、反光、黑色、强光、快速运动……然后各自打补丁。但安全证书需要的不是清单，而是**每个痛点对认证自由空间的定量损耗**：它把区间加宽多少、把 `F` 吃掉多少、在什么视角/距离/入射角下最严重、以及现有监视器能否可靠发现它。更关键的是，痛点的默认状态不是"不存在"，而是"可能活跃"：没有证据证明它不活跃，就必须为它保留膨胀项。核心创新：**深度痛点图谱（Depth Pain-point Atlas, DPA）+ 痛点监视器（Pain-Point Monitor, PPM）**。DPA 把 `P={透明, 镜面, 暗色, 掠射, 多路径, 运动, 标定, 量程, 遮挡}` 映射为局部膨胀函数 `e_p(x,context)` 与可检测信号；PPM 在线估计哪些痛点活跃。设计原则是**痛点只增不减**：膨胀项只能由"带假阴性上界的认证不活跃检验"移除，否则一律保留一个残差膨胀 `e_res`。这把"我们没发现问题"从"没问题"改写成"证据不足以移除风险"。

**灵感 3（痛点 × 深度相机 → 感知预算买回自由空间，但不越权）**
直觉：既然每个痛点都会吃掉认证自由空间，而多看一眼、换一个视角、加一次曝光、补一次标定又能把空间买回来，那么"痛点分析"的下一步自然是一个**预算分配问题**：有限的感知/验证预算，应该花在哪个痛点上，才能使"每毫秒买回的认证自由体积"最大？这正是主动感知（next-best-view）该被安全证书驱动、而不是被重建精度驱动的地方。核心创新：**痛点预算分配器（Pain-point Budget Allocator, PBA）**：它把每个候选观测（新视角、HDR 曝光、偏振、结构光模式、标定动作、触觉探针）看成对认证自由体积的边际增益，按 `PPI_p = ΔVol(F)/(cost_p·(1+risk_p))` 贪心分配。关键反直觉点：**主动感知只能把 `F` 恢复到 v15 已授权的上限，绝不能创造新权限**；它买回的是"被未知吃掉的已授权空间"，而不是"新的安全边界"。因此 PBA 的输出必须再与 `Exec_v15` 取交，感知越主动不等于授权越宽。

**三者如何统一**
统一为 **v15 语义层之下的"观测可信层"**：v15 回答"技能/扩散在语义上允许什么"（`Exec_v15`），v16 回答"在当前这台深度相机、这个视角、这段延迟下，哪些自由空间是被正证据认证的"（`F`）。CIF 把深度改写为区间；DPA/PPM 把痛点改写为膨胀与在线证据；CFS 把区间改写为单侧自由空间证书；PBA 在预算内买回 `F`；DFL 在痛点失控或预算耗尽时沿嵌套档位单调退化。共享状态 `ζ_depth=(I, P_act, e_res, F, rung, B_sense, drift, U_cal)`。**CIF 回答"这条射线能证明多远是空的"，DPA/PPM 回答"哪些失效模态必须被计入"，CFS 回答"这块空间到底能不能走"，PBA/DFL 回答"再花多少预算、退到哪一档"**。三者不是三个感知补丁，而是"区间—痛点—预算"的可信链。

## 1. 研究问题（轮次升级版）

- **Q1（深度区间与自由空间的可证语义）**：如何定义逐射线区间与帧级联合覆盖，使 `F⊆Free*` 单侧成立？无效返回、遮挡、量程外如何统一为 `[0,∞)`？运动/延迟/标定膨胀如何用三角不等式合成而不重复计错？区间覆盖的联合保证该用 union bound 还是帧级共形分数？
- **Q2（痛点图谱的可检测性与只增不减）**：每个痛点如何给出可校准的膨胀函数与带假阴性上界的在线检测？当检测器与传感器共享失效模态时，如何用失效独立信号（多视角、偏振、时序、触觉）打破"自信地错"？残差膨胀 `e_res` 如何随假阴性预算设定？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 自由空间正证据律（Free Space Needs Positive Evidence）**
一个空间点只有在"存在有效射线穿过它、该射线深度区间有覆盖保证、且该点严格早于区间下界减去安全余量"时，才可被认证为自由。无返回、遮挡、量程外、覆盖不足一律记为未认证，规划器将未认证视为障碍。禁止用"没有观测到障碍"推断自由。

**P26 痛点只增不减律（Pain Points Only Accumulate）**
用于膨胀的活跃痛点集合默认取"可能活跃"的超集；只有当某个痛点的"不活跃"检验具有可证假阴性上界、且该上界被计入 `e_res` 时，才允许移除其膨胀。检测器与传感器共享模态时，必须引入至少一个失效独立的证据源，否则不得移除。

**P27 感知预算只买回不越权律（Perception Budget Buys Back, Never Grants）**
主动感知/校准/多曝光只能减少未认证体积、把 `F` 恢复到 `Exec_v15` 已授权的上限；任何观测都不得扩大 `Exec_v15`，不得降低既有安全余量。预算分配以"每单位代价买回的认证自由体积"为目标，并显式计入假阴性风险与延迟成本。

## 3. 与基线的接口（如何退化）

- CIF 失效 ⇒ 退化为原始点云 + 固定全局误差球：`I_r=[d̂−ε, d̂+ε]`，无效点按障碍处理，**等价 v15 的固定安全膨胀**；
- DPA/PPM 失效 ⇒ 只保留最保守残差膨胀 `e_res=e_max`（所有痛点都可能活跃），`F` 收缩到最小但 sound，**等价"最保守深度后端"**；
- CFS 失效 ⇒ 不做自由空间认证，只在 v15 已确认的局部工作区内动作，**等价 v15 的接触局部策略**；
- PBA 失效 ⇒ 单视角、无主动感知，`F` 只减不增，**等价 v15 静态感知预算**；
- DFL 失效 ⇒ 固定单档 + 硬回退，**等价"v15 证书 + 固定深度安全球"**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15，再沿 v15→v14→…→v6 退化链退回；
- **安全继承**：CIF 只给区间、CFS 只取单侧包含、DPA/PPM 只加膨胀、PBA 只买回不越权、DFL 只做嵌套，均不能新增授权；`Exec_v16=Exec_v15∩{a:swept(a)⊆F}`，故 `Exec_v16⊆Exec_v15`（引理 135）。

## 4. 预期贡献

1. **认证深度区间场与认证自由空间**：把"深度相机输出"从点云改写为带覆盖保证的区间，把"无碰撞"从"没看到点"改写为"有正证据的自由空间"，直接封堵透明/反光/黑洞导致的幻影自由空间；

## 5. 本轮最大风险

**一句话**：深度区间证书的覆盖保证是相对于"已建模痛点"而言的；当透明/镜面物体让传感器在一个**又窄又自信**的区间里返回背景深度，而痛点监视器又与传感器共享同一强度/回波特征、因而看不见这个失效模态时，CFS 会把真实障碍认证成自由空间——即**窄而自信、可证却错误的自由空间**。

```python
# IP-402 Certified Interval Field：把深度改写为带覆盖保证的区间
class CertifiedIntervalField:
    def __init__(self, sensor_model, atlas, alpha=0.05, m_safe=0.01):
        self.sensor = sensor_model                 # e_stat(d)
        self.atlas = atlas                         # 痛点膨胀
        self.alpha = alpha
        self.m_safe = m_safe
        self.calibrator = ConformalCalibrator(alpha)  # 帧级联合覆盖

    def build(self, depth, valid, context, motion, extrinsics):
        I = {}
        for r in rays(depth):
            if not valid[r]:
                I[r] = (0.0, INF)                  # 无正证据：不产生自由空间
                continue
            d_hat = depth[r]
            e_stat = self.sensor.stat_error(d_hat)
            e_pain = self.atlas.inflation(context, r)   # Σ_{p∈P_act} e_p + e_res
            e_motion = motion.envelope(r, context.dt)   # v_max·δt + ½a_max·δt²
            e_cal = extrinsics.error(d_hat)             # ε_t + d̂·ε_R
            w = e_stat + e_pain + e_motion + e_cal
            I[r] = (max(0.0, d_hat - w), d_hat + w)
        return I

    def frame_certified(self, I, score):
        # score 为校准后的帧级最大归一化残差；返回 Cov_α 是否成立
        return score <= self.calibrator.threshold


# IP-403 Depth Pain-point Atlas：痛点 → 膨胀函数 + 检测信号
class DepthPainPointAtlas:
    PAIN_POINTS = ("transparent", "specular", "dark", "grazing",
                   "multipath", "motion", "calibration", "range", "occlusion")

    def __init__(self, bounds, residual):
        self.bounds = bounds      # e_p 的保守上界/校准分位，按 context 分层
        self.residual = residual  # e_res：未建模/未检出痛点的残差

    def inflation(self, context, ray):
        active = context.active_pain_points       # PPM 给出；默认全活跃
        e = self.residual
        for p in active:
            e += self.bounds[p](ray, context)     # 非负求和：只增不减
        return e

    def residual_for(self, missed_fnr):
        # 由假阴性预算反推残差膨胀：取 Σβ_p 对应的最坏膨胀分位
        return self.residual.quantile(missed_fnr)


# IP-404 Certified Free Space：区间 → 单侧自由空间证书
class CertifiedFreeSpace:
    def __init__(self, m_safe, voxel_size):
        self.m_safe = m_safe
        self.voxel = voxel_size

    def build(self, intervals, origin, pose, motion):
        F = set()
        for r, (lo, hi) in intervals.items():
            if lo <= self.m_safe:
                continue                            # 无可用下界
            s_max = lo - self.m_safe                # 严格早于区间下界
            for s in samples(0.0, s_max, self.voxel):
                x = pose.apply(origin + s * r.dir)  # 运动补偿到当前帧
                F.add(voxelize(x, self.voxel))
        return F

    def covers(self, F, swept_volume):
        # 扫掠体必须完全落在认证自由空间内；否则该动作被删除
        return swept_volume.voxels() <= F


# IP-405 Pain-Point Monitor：只增不减 + 假阴性预算
class PainPointMonitor:
    def __init__(self, atlas, fnr_budget=1e-3):
        self.atlas = atlas
        self.fnr_budget = fnr_budget
        self.evalues = {p: EProcess() for p in atlas.PAIN_POINTS}

    def update(self, obs, independent_evidence):
        active = set(self.atlas.PAIN_POINTS)       # 默认全活跃（超集）
        for p in self.atlas.PAIN_POINTS:
            e = self.evalues[p].update(obs.signal(p),
                                       independent_evidence[p])
            # 只有带假阴性上界的“不活跃”检验才能移除膨胀
            if e.test_inactive(fnr_bound=self.fnr_budget):
                active.discard(p)
        return active


# IP-406 Pain-point Budget Allocator：认证自由体积驱动的贪心
class PainPointBudgetAllocator:
    def __init__(self, budget, cost, risk):
        self.B = budget
        self.cost = cost
        self.risk = risk

    def allocate(self, F, candidates):
        chosen = []
        while self.B > 0:
            best, best_gain = None, 0.0
            for b in candidates:
                gain = marginal_vol(F, b) / (self.cost[b] * (1 + self.risk[b]))
                if gain > best_gain and self.cost[b] <= self.B:
                    best, best_gain = b, gain
            if best is None:
                break
            chosen.append(best)
            self.B -= self.cost[best]
            F = F | certify(b)     # 只增加认证自由空间，绝不扩权
        return chosen, F


# IP-407 Depth Fallback Ladder：单调塌缩
class DepthFallbackLadder:
    # rung 0 最保守；F_0 ⊆ F_1 ⊆ … ⊆ F_m ⊆ Exec_v15
    def select(self, active, drift, budget_left, calib_valid):
        if drift or not calib_valid:
            return 0
        if budget_left <= 0:
            return 1
        if len(active) > 0:
            return max(1, self.max_rung - len(active))
        return self.max_rung

    def collapse(self, rung, trigger):
        return min(rung, trigger.safe_rung)


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-D v16（认证深度自由空间版）
def metricvoicegauge_round_16_depth(M, s, obs, ...):
    # ---- v15 主路径原样保留（MW→NGE→HCC→HDT→HATD→NCP→守卫）----
    results = M.inherited_v15_path(ctx)
    nge.update_belief(obs)
    hcc.update_identification(obs.motor_enc, obs.joint_enc, obs.current)

    # 1) 认证区间场
    I = cif.build(obs.depth, obs.valid, obs.context,
                  motion=ctx.motion, extrinsics=ctx.extrinsics)

    # 2) 痛点监视（只增不减）
    P_act = ppm.update(obs, independent_evidence=ctx.evidence)
    ctx.active_pain_points = P_act
    ctx.residual = dpa.residual_for(missed_fnr=ppm.fnr_budget * len(P_act))

    # 3) 认证自由空间
    F = cfs.build(I, obs.origin, obs.pose, ctx.motion)

    # 4) 感知预算：只买回，不越权
    if ctx.allow_active_perception:
        _, F = pba.allocate(F, ctx.candidate_views)

    # 5) 选档；rung 0 只允许回退/询问
    rung = dfl.select(P_act, ctx.drift.fired(), ctx.B_sense, ctx.calib.valid)
    if rung == 0:
        F = set()
    Exec = {a for a in M.Exec_v15 if cfs.covers(F, swept(a))}

    # 6) 覆盖/漂移失败：单调塌缩
    if ctx.drift.fired() or not cif.frame_certified(I, ctx.score):
        rung = dfl.collapse(rung, ctx.trigger)
        Exec = {a for a in Exec if a in ctx.safe_fallback}

    # 7) 审计：深度可信层只能删动作
    assert Exec <= M.Exec_v15
    execute(select_action(Exec) if Exec else ctx.a_ask)
    return M.inherited_v15_path(ctx)
```

## 3. 推导

**引理 131（深度区间到自由空间的单侧 soundness）** 设对每条射线 r 有事件 `Cov_r={d*(r)∈I_r=[d_lo,d_hi]}`，帧级联合覆盖 `Cov_α=⋂_r Cov_r` 满足 `P(Cov_α)≥1−α`。定义 `F={o+s u_r : 0≤s≤d_lo(r)−m_safe, V(r)=1}`。则在 `Cov_α` 上 `F⊆Free*`。证明：若 `x=o+s u_r∈F`，则 `s≤d_lo−m_safe≤d*−m_safe<d*`（因 `d*≥d_lo`）。`d*` 是沿 r 的首个表面距离，故 `s<d*` 的点必在首个表面之前，真实自由。对全部 r 成立，故 `F⊆Free*`。∎ 推论：**自由空间证书只需下界 `d_lo`，不需要精确深度 `d̂`；在覆盖事件内，误差只会让 `F` 变小，不会让它变假**。

**引理 132（痛点膨胀的单调收缩）** 若 `P_act⊆P'_act` 且每个 `e_p≥0`，则同一观测下 `w'≥w`，从而 `d_lo'≤d_lo`，`F'⊆F`。证明：膨胀按非负求和，`d_lo=d̂−w` 关于 w 单调不增；`F` 的每条射线长度 `d_lo−m_safe` 单调不增。∎ 推论：**痛点分析只能让系统更保守；把某个痛点从"可能活跃"移出，必须付出可证假阴性预算**。

**引理 133（无返回/遮挡不产生自由空间）** 若射线 r 无效（无返回、量程外、被遮挡），令 `I_r=[0,∞)`，则 `F_r=∅`；因此 `F` 对缺失数据单调不增：增加一个无效射线不会增加任何自由空间。证明：`d_lo=0≤m_safe`，故 `F_r=∅`。∎ 推论：**"洞"在证书里永远是障碍，不是通道**；把洞当自由的系统，其幻影自由体积恰为 `Vol(U)`，这是可计算的"诚实代价"。

**引理 134（运动/延迟/标定膨胀的合成）** 设观测延迟 `δt`、相对速度上界 `v_max`、加速度上界 `a_max`、外参平移误差 `ε_t`、旋转误差 `ε_R`。则对距离 `d̂` 的表面点，当前帧沿射线的位置误差满足
```
e_motion ≤ v_max·δt + ½ a_max·δt²
e_cal(d̂) ≤ ε_t + d̂·ε_R
```
从而 `w=e_stat+e_pain+e_motion+e_cal(d̂)+e_res` 使 `[d̂−w,d̂+w]` 覆盖真实当前距离。证明：刚性运动下点位移由速度积分界定；小角度旋转使距离 d 的点横向偏移 `d·ε_R`，投影到射线方向不超过该值；各独立误差由三角不等式合成。∎ 推论：**高速运动或长延迟会以 `v_max·δt` 直接吃掉自由空间**；这是深度相机"看不到自己正在撞上去"的定量版本。

**引理 135（与 v15 的授权包含）** 定义 `Exec_v16={a∈Exec_v15 : swept(a)⊆F}`。则 `Exec_v16⊆Exec_v15`，且 v15 的九不变式与四重证书在 `Exec_v16` 上继续成立。证明：集合交的子集性；安全性是 `Exec_v15` 上的谓词，子集保持。∎ 推论：**深度可信层只能删动作，不能加动作**；主动感知买回的是 `Exec_v15` 中被未知挡住的子集，不是新权限。

**引理 136（认证自由体积的单调子模性与贪心近似）** 把观测集合 S 映射到认证自由体积 `f(S)=Vol(F(S))`。若每个体素一旦被某个 sound 观测认证为自由即保持认证，则 `f` 单调且子模：对 `A⊆B` 有 `f(A∪{b})−f(A) ≥ f(B∪{b})−f(B)`。于是贪心 next-best-view 在预算 `B_sense` 下达到 `(1−1/e)` 近似。证明：覆盖函数的标准子模性；每个体素的边际收益随已覆盖集合增大而递减。∎ 推论：**"再看一眼"的收益递减是可证的**；预算应优先花在尚未认证且被遮挡/痛点吃掉的区域，而不是重复确认已认证区域。

**引理 137（痛点只增不减的假阴性预算）** 设痛点 p 的"不活跃"检验假阴性率为 `β_p`。若移除 `e_p` 要求该检验通过，则未计入膨胀的活跃痛点期望数满足 `E[#missed]≤Σ_p β_p`；为保持总覆盖 `1−α`，残差膨胀 `e_res` 至少覆盖 `Σ_p β_p` 对应的最坏膨胀分位。证明：union bound 与分位数定义。∎ 推论：**"没检测到"不是"不存在"；检测器的假阴性必须转成 `e_res` 的显式膨胀**，否则覆盖保证被悄悄破坏。

**引理 138（深度退化阶梯的单调性与活性损失）** 设阶梯 `F_0⊆F_1⊆…⊆F_m`，触发条件为痛点失控、漂移、预算耗尽、校准过期。则任一触发只允许向低档移动，且
```
P(无可执行认证动作) ≤ P(drift)+P(校准过期)+P(预算耗尽)+P(F_0=∅) .
```
证明：`F_0` 为物理回退（停/退/`a_ask`），不依赖深度证书；其余事件由触发条件覆盖。∎ 推论：**退化不是"看得更少还硬走"，而是"用停/问买回可信度"**。

## 7. 已知风险与失效模式

1. **自信地错（透明/镜面返回背景深度）**：区间窄、覆盖事件成立，却系统性偏离真实首个表面；若 PPM 与传感器共享强度/回波特征，则监视器看不见。缓解：多视角/偏振/时序/触觉等失效独立证据；`e_res` 覆盖未建模模态；透明场景专项端到端测试。

2. **覆盖保证的分布外**：校准集未覆盖新材料/光照/距离/入射角，`1−α` 在部署分布上失效。缓解：分层共形、EVT 尾部分位、漂移检测即塌缩、在线重校准。

3. **区间过度膨胀使 `F` 清空**：痛点全活跃或 `e_res` 过大，系统频繁 `a_ask`。缓解：证书驱动的主动感知、分层痛点、预算优先买回高价值区域、常见档预认证。

4. **运动/延迟界估计过低**：`v_max`、`a_max` 或 `δt` 低估，`e_motion` 不足。缓解：硬件时间同步、最坏情形速度/加速度界、滚动快门逐行时间戳、压力测试。

5. **外参/标定漂移**：eye-in-hand 外参随负载/温度变化，`e_cal` 不足。缓解：在线标定残差监视、定期标定动作、漂移即降档。

6. **遮挡/自遮挡**：被机械臂自身挡住的区域不在 `F`，导致过度保守或规划死锁。缓解：本体感知建模、多视角、把自遮挡区域显式记入 `U` 并允许主动换视角。

7. **子模性假设失效**：观测相关、校准耦合或体素认证可撤销时，贪心近似比下降。缓解：部署前验证子模性、保守预算、对候选集做证书检查。

8. **计算预算超时**：全分辨率区间场与体素化可能超 22ms。缓解：ROI 下采样、分层/八叉树、GPU/硬件加速、watchdog 强制塌缩。

9. **与 v15 的组合错误**：膨胀重复计入或漏计，`Exec` 子集断言失败。缓解：三角不等式合成审计、`Exec_v16⊆Exec_v15` 运行时断言、消融验证。

10. **深度看不到的物性**：透明薄膜、可变形物、柔软物在几何上可能"自由"但物理上危险。缓解：触觉/力反馈兜底、材质先验、接触前减速与柔顺策略。

## 8. 本轮最大风险

**一句话**：深度区间证书的覆盖保证是相对于"已建模痛点"而言的；当透明/镜面物体让传感器在一个**又窄又自信**的区间里返回背景深度，而痛点监视器又与传感器共享同一强度/回波特征、因而看不见这个失效模态时，CFS 会把真实障碍认证成自由空间——即**窄而自信、可证却错误的自由空间**。
