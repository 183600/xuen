# 第 3 轮（研究线累计第 3 轮；任务书将本轮记为「灵感循环新阶段第 1 轮」；承接基线 **ToolGauge**；本轮灵感：「检索增强生成」×「LoRA」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E439），
> 其下承第 1 轮 **LeanGauge**（IP-310–314；定义 398–415；引理 42–45）与 **MODGAUGE**。
> **本轮纪律**：不推倒 6C 闭环、MTC/TCV 工具契约、风险门 λ 与增益注 β、MP-Φ/AP-Cal、L-Box 共形假设、
> MODGAUGE 五不变式、严格退化链与 50Hz 硬实时约束；只正面攻击 ToolGauge 的三个**未言明假设**：
>
> 1. **「参数记忆垄断」**：MP-Φ 把全部跨盲区经验压进一组全局权重。它像大模型参数一样，**不能引用、不能局部删除、不能即时更新**；
>    而 RAG 的核心恰恰是：知识可以留在外部、按需检索、逐条审计、随时撤回。ToolGauge 只有「训练时学到的先验」，
>    没有「部署后检索到的、有出处的证据」。
> 2. **「适配必须全局」**：AP-Cal 的一次校准作用于共享先验。LoRA 的启示是：适配应当是**低秩、可组合、可冻结、可撤销**的局部增量；
>    秩 r 就是「这次修复被允许改变多少先验」的显式容量预算。ToolGauge 无法回答「这次修复到底改了多少、改的是哪一类、能不能只撤回这一小块」。
> 3. **「隔离等于全局断电」**：P-Quarantine 连续 K 次同向残差就暂停整个 AP-Cal。这是烟雾报警器 + 全楼断电，
>    不是**定向召回**——它保证安全，却把可用性一次性打穿，且无法定位「是哪一条先验/哪一个案例/哪一个适配器坏了」。
>
> **核心命题**：把 ToolGauge 的「盲区 → 契约探测 → 摊销校准 → 局部热替换」升级为
> 「**检索已验证案例 → 装配低秩适配器 → 契约探测 → 检索增强校准 → 按溯源锥定向召回**」。
> 一句话：ToolGauge 问「证据可不可信」；**RecallGauge 进一步问「这条证据是不是本地的？这条经验该以多大秩、从哪个案例、借到哪个盲区？出错后能精确撤回哪一块？」**

## 三灵感映射（升级而非重写）

| 灵感词 | ToolGauge 的隐含假设 | 升级为 | 一句话动机 |
|---|---|---|---|
| 检索增强生成 | MP-Φ 的参数记忆足够；先验只能训练时获得 | **R-Box 案例记忆**：检索已验证的修复案例，作为**提案与先验**，绝不直接作证 | 非参数记忆可即时增删、逐条溯源、按需撤回；但相似 ≠ 因果，检索必须被本地见证 |
| LoRA | AP-Cal 的更新作用于全局先验，无法限定改动范围 | **A-Box 低秩适配器库**：冻结物理骨干，只学秩 ≤ r 的增量；支持组合、秩预算与版本回滚 | 容量预算把「改多少」变成可审计量；低秩增量可组合、可撤销、抗灾难遗忘 |
| 两者交汇 | P-Quarantine：全局暂停 | **C-Quarantine（案例/适配器定向召回）**：沿 provenance DAG 只撤销污染锥 | 污染应像产品召回一样精确，而不是像断电一样粗暴 |

**三条新不变式（不替换五不变式，只做扩展）**：
- **R1 检索只提案、不作证**：检索结果可进入假设集与调用排序，但在本地 witness 回执通过前，永不进入校准样本集；
- **R2 适配只低秩、不重写**：任何在线变更只能通过秩受限适配器（或等价闭式低秩修正）作用于冻结骨干，且受双重秩预算约束；
- **R3 召回按锥、不全停**：发现坏案例/坏适配器时，只撤销 provenance 锥内的派生物；全局 P-Quarantine 仅作为 DAG 不完整时的兜底。

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- 主张绑定获得**出处分级扩展**：数值主张必须引用 `(receipts, CaseCert, AdapterCert)` 三元组，缺一在契约序列化时剥离（扩展定义 423）；
- **严格退化链延长**：RecallGauge 失效（索引不可用 / 案例全过期 / 适配器校验失败 / 检索覆盖不足）⇒ 退回 ToolGauge 冷启动路径
  ⇒ LeanGauge ⇒ MODGAUGE。检索与适配是增强项，不是正确性依赖（引理 57）。
- **50Hz 硬实时路径不变**：检索、适配器装配、案例写回全部异步；50Hz 内只增加 O(1) 的 provenance/hash 检查。

## 0. 直觉与动机

### 0.1 RAG：参数记忆的三个盲区

把 MP-Φ 想成一个大模型的权重：它擅长压缩**平均规律**，但有三件事天生做不好。

1. **不能引用**。部署现场问「为什么把这个盲区的 σ 收缩到 0.3？」MP-Φ 只能给出一个前向值，
   无法说「因为三周前在 2 号产线的镜面不锈钢案例中，同样的 IR/RGB 残差模式下，σ 收到 0.28」。
   ToolGauge 用语言修复证书（定义 427）补了一层解释，但证书本身仍是**生成物**，不是可检索的**历史证据**。
2. **不能局部遗忘**。如果发现某批预训练数据被污染，AP-Cal 只能重训或全局暂停（P-Quarantine）。
   但现实中的污染往往是局部的：某个材质族、某个工位、某类光照。全局重训的代价与风险都不可接受。
3. **长尾覆盖差**。预训练分布覆盖不到的罕见组合，参数记忆只能外推；而外推误差在盲区里最危险。
   RAG 的直觉是：**把长尾留在外部索引里**，遇到时检索，而不是逼权重记住。

因此 R-Box 的第一条设计原则是：**案例库只存「已通过 V 阶段 + 独立回执 + 契约回归」的修复案例**，
每条案例带结构化指纹、有效回执、校准后验、适配器引用、版本与有效期。
检索命中的不是一段文本，而是一份**可重放的实验记录**。

但 RAG 也带来一个致命幻觉：**相似不等于因果**。两件都是「镜面反射」的盲区，可能一个来自不锈钢、一个来自镀膜玻璃；
一个在 20°C、一个在 70°C。检索到错误案例，再配上一个自信的语言证书，比没有检索更危险。
所以第二条设计原则是：**检索只能提案，不能作证**（R1）。
检索结果先进入 L-Box 的假设集与 T-Box 的调用排序；只有当一条**未参与检索案例拟合**的本地 witness 回执
（例如一次 cross.modal 互检）通过后，该案例才被允许以「伪回执」形式、带膨胀方差、进入 RA-Cal。
这把「借用经验」变成了「带着本地见证借用经验」。

### 0.2 LoRA：把「改多少先验」变成可审计的秩预算

AP-Cal 的问题是：一次校准会更新整个共享先验。这在数学上优雅，在工程上却无法回答三个问题：
**改了多少？改了哪一类？怎么只撤回这一次？**

LoRA 的直觉恰好相反：冻结大骨干，只学一个低秩增量 ΔW = B Aᵀ（rank r）。
把它搬到计量先验上：

- **冻结物理骨干 W₀**：物理先验、噪声底、守恒关系永远不被在线修复覆盖；这直接继承 AP-Cal 的保守性夹紧精神；
- **低秩适配器 δ = (A, B, r, supp, prov)**：只被允许影响它所声明支持的参数块与指纹区域；
- **秩预算 B_r**：总秩 Σr 有硬上限。秩越小，单次修复能造成的影响越小，但表达能力也越弱；
  这给出一个天然的「容量-样本」权衡（引理 52）；
- **可组合**：不同盲区/不同材质族的适配器可以组合，组合是否安全由支持集不相交或子空间正交保证（引理 53）；
- **可撤销**：适配器是一个有版本、有 lineage 的独立制品；撤销它不需要重训骨干，只需从组合中移除并回滚受影响子图。

更妙的是，LoRA 与 RAG 在统计上正好互补：

- **适配器负责「类级」结构**：同一材质族、同一光照区间内可复用的偏差；
- **案例检索负责「实例级」残差**：当前盲区特有的、无法被类级低秩结构吸收的部分。

于是 RA-Cal 可以写成一个**混合效应模型**：
`u_s = f_{W₀}(φ_s) + g_{δ_S}(φ_s) + Σ_c w_c K(φ_s, φ_c)(u_c − f_{W₀}(φ_c)) + ε`。
第一项是固定效应（物理 + 预训练），第二项是类级随机效应（LoRA），第三项是实例级随机效应（检索），
`ε` 是观测噪声。**检索与适配谁该多用力，由三重下注的第三个门 ρ 根据 held-out witness 的实测增益决定**，
而不是由相似度或秩大小拍脑袋决定。

### 0.3 合流：RecallGauge = 检索（实例） + 低秩适配（类） + 定向召回（治理）

把两条灵感接起来，得到一个清晰的分工：

1. **R（Retrieve）**：用结构化指纹检索已验证案例；检索结果只做假设提案与候选程序排序；
2. **A（Adapt）**：按当前假设与指纹装配/拟合低秩适配器；秩受预算约束，支持集受可影响范围约束；
3. **H → C → E → C → V → U**：ToolGauge 原有 6C 原样执行；RA-Cal 取代 AP-Cal 但保留其退化特例；
4. **W（Write-back）**：只有通过 V、独立回执、回归测试与 witness 复核的修复，才被签名写入案例库；
   失败案例写入**反例库**，用于未来否决相似但已知会失败的类比；
5. **CQ（Recall）**：一旦发现坏案例/坏适配器，沿 provenance DAG 计算召回锥，只撤销锥内派生物；
   全局 P-Quarantine 仅在 DAG 不完整或污染源不明时启用。

一句话：**ToolGauge 把机器人当「带工具的观察者」，RecallGauge 把过去的修复经历当成「可检索、可适配、可召回的资产」。**

### 0.4 为什么这不是「换皮」

| 维度 | ToolGauge | RecallGauge |
|---|---|---|
| 经验载体 | 全局参数先验 MP-Φ | 冻结骨干 + 低秩适配器 + 外部案例库 |
| 更新方式 | 重训/摊销后验覆盖共享先验 | 检索案例、装配适配器；不改骨干 |
| 更新粒度 | 全局 | 案例级（实例）与适配器级（类），均带支持集 |
| 证据来源 | 本地回执 + 预训练先验 | 本地回执 + 检索先验；检索须本地 witness 复核 |
| 失效治理 | P-Quarantine 全局暂停 | provenance 定向召回 + 反例库 + 全局兜底 |
| 可解释性 | 语言证书（生成物） | 案例出处 + 适配器 lineage + 召回审计链 |
| 关键新风险 | 全局先验跨盲区相关偏差 | 错误类比 / 索引投毒 / 适配器后门，且看起来更有出处 |

## 1. 形式化定义（增量：定义 432–447）

**定义 432（计量案例与案例库）** 一条计量案例
`c = (id, φ, h, Π, R⁺, q, δ, verdict, prov, ver, ttl)`：
- `φ`：结构化指纹（见定义 433），**禁止自由文本**（继承并强化定义 429）；
- `h`：假设标签；`Π`：通过 TCV 的探测程序；`R⁺`：有效回执集（定义 417）；
- `q = (μ, Σ)`：该案例的校准后验；`δ`：可选的适配器引用；
- `verdict`：V 阶段独立回执残差、契约回归结果、witness 复核结果；
- `prov`：provenance DAG 节点（签名、父边）；`ver`：骨干/工具/schema 版本；`ttl`：有效期包络。
案例库 `C⁺ = {c}`；反例库 `C⁻ = {(φ, h_fail, F_fail, prov)}` 只存失败指纹，不存原始数据。
**只有通过定义 440 准入协议的案例才能进入 C⁺。**

**定义 433（指纹与检索）** 指纹
`φ(s) = [数值特征(盲区统计, 回执统计), SNC 指纹匹配向量, 工具响应签名, 环境包络(温度/光照/负载/工位)]`。
距离 `d(φ, φ')` 为归一化特征的 Mahalanobis 距离（或学习到的度量，但度量本身须版本化、可审计）。
检索 `TopK_τ(φ) = {c ∈ C⁺ : d(φ, φ_c) ≤ τ_ret}`，按距离排序；τ_ret 由共形分位给出（引理 54）。
实现用 HNSW/IVF 近似最近邻，`O(d log N)`；索引不可用时退回精确扫描或直接冷启动。

**定义 434（检索假设 vs 检索证据）** 检索结果分两级使用：
- **提案级**：从 TopK 的 `h` 生成候选假设集 `H_s^ret`，与 L-Box 的共形假设取并；只影响搜索顺序，不改变证据集；
- **证据级**：仅当本地 witness 回执 `r_w` 通过，且 `r_w` 与案例的拟合回执在 provenance 上独立时，
  才构造**伪回执** `r̂_c = (μ_c, Σ_c + Σ_w, weight w_c)` 并以权重 `w_c` 进入 RA-Cal。
**硬约束**：`w_c ≤ w_max`，`Σ_c w_c ≤ W_max`；未复核的检索案例权重恒为 0。

**定义 435（低秩适配器）** 适配器
`a = (A_a ∈ R^{d_in×r_a}, B_a ∈ R^{d_out×r_a}, r_a ≤ r_max, supp_a, α_a, prov_a, cert_a)`，
表示 `ΔW_a = α_a B_a A_aᵀ`。适配器只作用于冻结骨干 `W₀`：
`f_{W₀+δ_S}(x) = f_{W₀}(x) + Σ_{a∈S} α_a B_a A_aᵀ ψ(x)`。
`supp_a` 声明它允许影响的契约参数块与指纹区域；越界即视为非法适配器。
总秩预算 `B_r = Σ_{a∈S} r_a ≤ r_budget`。适配器训练用**闭式低秩岭回归**（或等价交替最小二乘），
目标是 `min_{A,B} ||Y − XW₀ − XBAᵀ||² + λ||BAᵀ||²`，秩约束 `rank ≤ r_a`；训练只使用 C⁺ 中签名案例。

**定义 436（适配器组合与干扰）** 组合 `S` 的增量为 `ΔW_S = Σ_{a∈S} ΔW_a`。
称 `a, b` **可合并**，若 `supp_a ∩ supp_b = ∅` 或 `A_aᵀ B_b = 0`（子空间正交）；此时组合精确可加。
否则定义干扰 `I(a,b) = ||B_a A_aᵀ B_b A_bᵀ||_F`；仅当 `I(a,b) ≤ ε_merge` 且组合后 held-out witness 不退化时允许合并，
否则保留为独立专家，由路由门择一（不做「adapter soup」式无审计相加）。
**原则：能正交就不相加，不能正交就不合并。**

**定义 437（检索增强校准 RA-Cal，推广定义 420）** 给定骨干 `f_{W₀}`、适配器集 `S`、检索案例集 `C_ret`：
`u_s = f_{W₀}(φ_s) + g_{δ_S}(φ_s) + Σ_{c∈C_ret} w_c K(φ_s, φ_c)(u_c − f_{W₀}(φ_c)) + ε`。
其后验以**温控专家乘积**给出：
`p(u | φ_s) ∝ p_phys(u) · p_adapt(u; S) · Π_{c∈C_ret} p(u | c)^{w_c}`，
其中 `p_phys` 是物理锚（KL 锚），`p_adapt` 是适配器诱导的类级先验，`w_c` 满足定义 434 的预算。
**保守性夹紧保留**：`Σ ≽ κ_phys I`；**信任域投影**：若检索项导致的均值偏移超过 `R_trust`，按比例裁剪到 `R_trust` 球内。
退化：`C_ret = ∅`、`r_budget = 0` ⇒ RA-Cal ≡ AP-Cal；`W_max = 0` ⇒ 关闭检索。

**定义 438（三重下注，推广定义 419）** 一次「检索 + 适配 + 探测」被允许执行，当且仅当三门同过：
- **风险门 λ**（继承）：`λ(a,s) = σ_pred − σ_decl ≥ γ`，管物理安全；
- **增益注 β**（继承）：`β = Ĝ_tool − c_tool ≥ γ_B`，管探测值不值；
- **迁移注 ρ**（新增）：`ρ = Ĝ_transfer − c_ret − c_adapt ≥ γ_R`，管「借来的经验值不值得借」。
`Ĝ_transfer` 必须由**未参与拟合的 witness / 留一案例**估计，不得用检索相似度代替。
任一门失败 ⇒ 该检索/适配不进入执行，退回 ToolGauge 冷路径；不产生物理副作用。

**定义 439（检索覆盖与弃权）** 对盲区 `s`，检索覆盖
`cov(s) = 1[∃ c ∈ C⁺: d(φ_s, φ_c) ≤ τ_ret ∧ c.ver 与当前兼容 ∧ c 未过期 ∧ witness 可复核]`。
`cov(s)=0` ⇒ **弃权**：不检索、不适配，直接走 ToolGauge 冷路径，并把先验方差抬高到保守值。
运行期 SLA：校准集上 `P(cov=1) ≥ 1−α_ret`；漂移下按引理 54 修正；SLA 跌破 ⇒ 全局弃权并告警。

**定义 440（案例准入与写回协议 W）** 一条案例进入 C⁺ 必须同时满足：
① V 阶段独立回执 `|z| ≤ ε_cross`；② 契约回归通过；③ 无活跃召回；
④ witness 复核残差在预注册界内；⑤ provenance 完整、签名有效、schema/骨干版本可复现；
⑥ 结构化字段齐全，且不含任何自由文本/OCR/二维码内容（继承定义 429）。
失败修复写入 C⁻（反例库），带失败指纹 `F_fail`。写回是异步的，且**写回失败不影响已提交的修复**。

**定义 441（溯源 DAG 与定向召回 C-Quarantine）** 每个案例、适配器、契约字段版本都是 provenance 节点，
边类型 `derived_from / trained_on / used_by / replaced_by`。
发现坏案例 `c_bad`（审计、反例命中、witness 反复失败）时，召回锥
`Recall(c_bad) = {v : v 在 DAG 中由 c_bad 可达}`。
后果：撤销锥内案例与适配器；回滚使用过锥内适配器的热替换子图到前一版本；重跑受影响盲区的 V；
把 `c_bad` 的指纹写入 C⁻。
**与 P-Quarantine 的关系**：P-Quarantine 保留为「DAG 不完整 / 污染源未知」时的全局兜底；
C-Quarantine 是默认路径。召回动作本身进入审计日志，并可被二次审计。

**定义 442（时效、版本与撤销表）** 每条案例/适配器带有效期包络
`V = (骨干 hash, 工具版本, schema 版本, 环境包络, ttl)`。检索时过滤 `V` 不兼容或过期项；
适配器带撤销表 `RL`，撤销后所有组合中立即移除。过期不等于删除：保留只读审计副本，但不得进入校准。
**版本不匹配时只能作为「提案」，不能作为「证据」。**

**定义 443（反例记忆与负迁移否决）** 反例 `n = (φ_n, h_fail, F_fail)`。
若当前 `d(φ_s, φ_n) ≤ τ_neg` 且当前回执模式与 `F_fail` 匹配，则该假设/适配器被**硬否决**，
除非一条新的本地 witness 明确推翻反例。反例库是「检索幻觉」的第一道负向门。

**定义 444（适配器证书与触发器扫描）** `AdapterCert = (base_hash, train_case_ids, rank, supp,
validation_receipts, trigger_scan, lineage)`。
入 A-Box 前必须通过：留出 witness 验证、支持集检查、秩预算检查、触发器扫描
（在预注册的触发模式/激活聚类上检测后门；扫描集不参与训练）。
扫描失败或有未解释高激活的适配器进入隔离区，不参与组合。

**定义 445（R²-6C 闭环）** 在 ToolGauge 6C 外层加两段，中间六段不变：
`R(Retrieve) → A(Assemble/Adapt) → H → C → E → C → V → U → W(Write-back)`。
R 与 W 异步；A 位于 C 阶段内（先装配候选适配器，再由 TCV 校验程序）；
U 仍只在 V 通过后触发；CQ 是横切监控器，不在正常路径上。
称「R²」= Retrieval × Rank-adaptation。

**定义 446（信任域与影响预算）** 两条硬预算：
`Σ_c w_c ≤ W_max`（检索影响预算）与 `Σ_a r_a ≤ r_budget`（适配容量预算）；
以及一条软约束 `||μ_RA − μ_base|| ≤ R_trust`（后验均值信任域）。
任何检索/适配组合超出预算即被裁剪或拒绝；`R_trust` 与 `κ_phys` 共同构成「借用经验」的安全包络。
预算不是超参数，而是**可审计契约**：每次修复都记录实际使用量。

**定义 447（继承、等价与严格退化链）** 未重定义记号沿用定义 398–431。
RecallGauge 在 `C⁺=∅, r_budget=0, ρ 门恒假, C-Quarantine 退化为 P-Quarantine` 时**严格等价于 ToolGauge**。
退化链：**RecallGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE**。
索引失效 ⇒ 关闭检索但保留适配器；适配器校验失败 ⇒ 关闭适配但保留检索提案；两者皆失效 ⇒ ToolGauge；
ToolGauge 失效 ⇒ LeanGauge；再失效 ⇒ MODGAUGE。检索与适配永远不是硬实时或正确性的依赖。

## 2. 关键算法骨架

```python
# IP-321 R-Box：结构化案例检索（检索只提案，不作证）
@dataclass
class Case:
    id: str; phi: Vec; h: str; prog: Prog; receipts: list[Receipt]
    mu: Vec; Sig: Mat; adapter_id: str | None
    verdict: dict; prov: ProvNode; ver: Version; ttl: float

class RBox:
    def retrieve(self, s, ctx):
        phi = fingerprint(s, ctx)                       # 数值+SNC+响应签名，无自由文本
        if not self.index.ready:
            return []                                   # 索引不可用 ⇒ 冷启动，退化链
        cands = self.index.ann(phi, k=self.K, ef=self.ef)
        cands = [c for c in cands
                 if self.valid(c, ctx) and distance(phi, c.phi) <= self.tau_ret]
        return self.rank(cands)                         # 只返回提案级列表

    def to_hypotheses(self, cands, s):
        return union_conformal([c.h for c in cands], self.lbox.cal)   # 与 L-Box 假设取并

    def to_pseudo_receipts(self, cands, s, env):
        out = []
        for c in cands:
            r_w = env.witness_probe(s, c)               # 本地独立 witness（如 cross.modal）
            if r_w is None or not independent(c.receipts, r_w):
                continue                                # 未复核/非独立 ⇒ 权重 0
            if not witness_ok(r_w, c, self.eps_w):
                self.negmem.add_from_failure(c, r_w)    # 反例库
                continue
            w = min(self.w_max, self.kernel(s, c))
            out.append(PseudoReceipt(c, r_w, weight=w,
                                     var=c.Sig + r_w.var))
        return clip_budget(out, self.W_max)             # 定义 434/446

# IP-322 A-Box：低秩适配器库（冻结骨干，秩预算，组合校验）
class ABox:
    def assemble(self, H_s, phi, budget):
        cands = self.bank.query(phi, H_s)               # 支持集/版本/证书/触发器扫描过滤
        chosen, used_r = [], 0
        for a in sorted(cands, key=lambda x: x.priority):
            if used_r + a.r > budget.r_budget: continue
            if any(not mergeable(a, b) for b in chosen): continue
            chosen.append(a); used_r += a.r
        return AdapterSet(chosen, delta_fn=lambda x: sum(
            a.alpha * a.B @ a.A.T @ psi(x) for a in chosen))

    def fit_online(self, cases, H_s, r_max):
        X, Y = featurize(cases), residuals(cases)
        A, B = low_rank_ridge(X, Y, W0=self.base, rank=r_max,
                              lam=self.lam)             # 闭式/交替最小二乘
        a = Adapter(A, B, r=rank(A), supp=support(H_s),
                    prov=new_prov(cases), cert=None)
        a.cert = certify_adapter(a, self.heldout, self.trigger_scan)
        return a if a.cert.ok else Quarantine(a)        # 证书失败 ⇒ 隔离

# IP-323 RA-Cal：检索增强校准（混合效应 + 信任域 + 保守夹紧）
class RACal:
    def calibrate(self, receipts, H, s, adapters, pseudo):
        mu0, S0 = self.mp_phi(featurize_ctx(receipts, H, s))       # AP-Cal 骨干
        mu_a = adapters.apply(featurize(s)) if adapters else 0
        # 温控专家乘积（沿用 AP-Cal 的物理锚与夹紧）
        mu, Sig = gaussian_product(
            base=(mu0, S0),
            experts=[(p.mu, p.var, p.weight) for p in pseudo],
            temper=self.temper)
        mu = mu0 + mu_a + clip_radius(mu - mu0 - mu_a, self.R_trust)
        return mu, clamp_min(Sig, self.kappa_phys)

    def transfer_gain(self, pseudo, adapters, s):
        # 只在 held-out witness / 留一案例上估计，绝不用相似度替代
        return heldout_nll_gain(pseudo, adapters, s) - self.cost_ret - self.cost_adapt

# IP-324 三重下注（λ 安全 / β 信息 / ρ 迁移）
def triple_gate(call, pseudo, adapters):
    return (risk_gate(call)                       # 继承 ToolGauge
            and gain_bet(call)                    # 继承 ToolGauge
            and transfer_bet(pseudo, adapters))   # 新增：ρ ≥ γ_R

# IP-325 R²-6C 闭环（6C 本体不动，外面套 R/A/W）
def recallgauge_R2_6C(M, s):
    cands   = M.rbox.retrieve(s, M.ctx)                        # R
    H_ret   = M.rbox.to_hypotheses(cands, s)
    H       = conformal_union(M.lbox.hypothesize(s, M.dbox.R[s]), H_ret)
    pseudo  = M.rbox.to_pseudo_receipts(cands, s, M.env)       # 仍非证据
    adapters= M.abox.assemble(H, fingerprint(s), M.budget)     # A
    prog    = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s), cands)
    if not triple_gate(prog, pseudo, adapters):                # λ ∧ β ∧ ρ
        return M.toolgauge_6c(s, H=H, prog=prog)               # 冷路径（退化）
    receipts = M.tcv.execute(prog, M.env)                      # E（PROBING）
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient_evidence")
    mu, Sig = M.racal.calibrate(receipts, H, s, adapters, pseudo)   # C
    if not M.racal.cross_validate(mu, Sig, M.cross_receipt(s)):     # V
        return stub_and_red(s, "cross_check_failed")
    new_ec = M.racal.update_contract(M.dpe, mu, Sig, s)        # U
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression_failed")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    cert = CaseCert(H, prog, receipts, pseudo, adapters, mu, Sig)
    if case_admissible(cert):                                  # W（定义 440）
        submit_async(M.cases.write, cert)                      # 异步写回
    bind_claims(new_ec, H, prog, receipts, cert)               # 定义 423 扩展
    return True

# IP-326 C-Quarantine：沿 provenance DAG 定向召回
class CQuarantine:
    def recall(self, bad_case):
        cone = self.dag.descendants(bad_case.prov)            # derived_from/trained_on/used_by
        for a in self.abox.trained_on(cone):
            self.abox.revoke(a); self.rl.add(a.id)
        for (s, ver) in self.mreg.versions_using(cone):
            self.mreg.rollback(s, ver.prev)                   # 只回滚受影响子图
            self.reverify_async(s)
        self.cases.revoke(cone); self.negmem.add(bad_case)
        if not self.dag.complete:                             # DAG 不完整 ⇒ 兜底
            self.pquar.trigger_global()                       # 第 2 轮 P-Quarantine
        self.audit.log("recall", cone, reason=bad_case.verdict)

# IP-327 主闭环：50Hz 路径不动，检索/适配/写回/召回全异步
def RecallGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(recallgauge_R2_6C, M, s)             # 异步，偏离 50Hz
    if M.cq.pending(): M.cq.drain()                           # 定向召回异步执行
    if M.pquar.triggered(): M.racal.pause()                   # 兜底全局断路
    return MODGAUGE_round(M, obs, audio, tac, depth, det)     # 主控不变
```

## 3. 推导

**引理 51（检索影响的信任域界）** 设案例残差有界 `||u_c − f_{W₀}(φ_c)|| ≤ Δ_max`，核 `|K| ≤ 1`，
权重非负且 `Σ_c w_c ≤ W_max`。则检索项对后验均值的偏移满足
`||Δμ_ret|| ≤ W_max · Δ_max`；经过 `R_trust` 投影后更紧。
若 `C_ret` 中案例彼此相关（provenance 非独立），其有效样本量
`n_eff = (Σw_c)² / Σw_c² ≤ |C_ret|`；用 `n_eff` 替代 `|C_ret|` 进入定义 426 的样本门槛。
**系 51.1**：单个恶意案例最多造成 `w_max Δ_max` 的均值偏移；把 `w_max` 设为 `O(ε)` 即可使单点投毒有界。
**系 51.2**：与 ToolGauge 的全局先验不同，检索偏移是**可加、可定位、可回滚**的；坏案例的影响不会自动扩散到未使用它的盲区。

**引理 52（低秩适配的泛化-近似权衡）** 设适配器 `ΔW = BAᵀ`，`rank ≤ r`，有效维数
`d_eff = r(d_in + d_out − r)`。在 N 条签名案例上，超额风险满足
`R(δ) − R* ≤ ε_approx(r) + O(√((d_eff·log(1/δ) + log N) / N))`，
其中 `ε_approx(r) = min_{rank≤r} ||ΔW* − ΔW||_F` 为低秩近似误差。
**证明思路**：低秩矩阵类的 Rademacher 复杂度按 `d_eff` 计；加上标准 PAC 界与近似误差分解。
**推论 52.1（自动秩规则）** 当案例稀少（`N_bl` 小）时最优 `r*` 小（甚至 `r=1`）；
当案例充足时 `r*` 随 `√(N_bl / log N)` 增长。工程上取 `r* = clip(round(√(N_bl)), 1, r_max)` 作为默认。
**推论 52.2（抗灾难遗忘）** 骨干 `W₀` 冻结且适配器支持集有限 ⇒ 对未触及参数块的一阶影响为 0；
对触及块的干扰由引理 53 控制。

**引理 53（适配器组合的干扰界）** 对适配器 `a,b`：
`||ΔW_{a+b} − (ΔW_a + ΔW_b)||_F = ||B_a A_aᵀ B_b A_bᵀ||_F`
`≤ ||B_a||₂ ||A_b||₂ · √(r_a r_b) · σ_max(A_aᵀ B_b)`
（最后一因子度量两个低秩子空间的重叠）。
若 `supp_a ∩ supp_b = ∅` 或 `A_aᵀ B_b = 0`，则精确可加，干扰为 0。
**系 53.1**：组合误差随 `√(r_a r_b)` 与子空间重叠增长；因此「支持集不相交」比「秩小」更重要。
这给 A-Box 的合并规则提供了可计算判据，而不是经验性的 adapter soup。

**引理 54（检索覆盖的共形保证）** 在校准集上以「检索到的最近案例是否实际可迁移」为标签，
取 `1−α_ret` 分位的 `τ_ret`，则在可交换性下 `P(cov(s)=1) ≥ 1−α_ret`；
校准-部署 TV 距离为 `η_ret` 时覆盖下界降为 `1−α_ret−2η_ret`；加权共形可恢复至 `1−α_ret−η_ret L'`。
**系 54.1**：SLA 取 `α_ret=0.1, η_ret≤0.05 ⇒ 覆盖 ≥ 0.8`；跌破即弃权（定义 439），退回 ToolGauge 冷路径。
这与第 2 轮引理 48 的 `H_s` 覆盖 SLA 同构，但作用于「案例相关性」而非「假设正确性」。

**引理 55（三重下注的负迁移界）** 设迁移增益估计误差关于 held-out witness 亚高斯，参数 `ξ_ρ`。
若 `ρ ≥ γ_R` 才允许借用，则单次借用发生「实际增益 < 0」的概率
`≤ exp(−γ_R² / 2ξ_ρ²)`；L 次借用联合 ≤ `L·exp(−γ_R²/2ξ_ρ²)`。
**系 55.1**：去掉 ρ 门（等价于 `γ_R = −∞`）时，检索可以无限负迁移；ρ 门是 RAG 在本系统中的「安全带」。
**系 55.2**：ρ 的估计必须来自独立 witness，若用检索相似度替代，`ξ_ρ` 不可控，界失效。

**引理 56（定向召回的可达性与最小性）** 若每个契约字段版本都记录 provenance 父边，
且每个适配器记录 `trained_on` 案例集、每个热替换记录 `used_by` 适配器，
则对坏案例 `c_bad`：
- **完备性**：`Recall(c_bad)` 包含所有取值依赖 `c_bad` 的案例、适配器与契约字段版本；
- **最小性**：删除 `Recall(c_bad)` 后，其余已提交字段的数值与版本逐位不变（不受影响）。
**证明思路**：对 DAG 拓扑序归纳；`used_by` 边保证依赖闭包；版本化写入保证回滚点是精确的。
**系 56.1**：C-Quarantine 的可用性严格优于 P-Quarantine（后者撤销全部在飞/已提交修复），
在 DAG 完备时安全性相同（完备性保证不漏）；DAG 不完备时由全局 P-Quarantine 兜底。
**系 56.2**：召回精度 = 真正受污染的节点数 / 召回锥节点数；DAG 越细，精度越高。E445 度量之。

**引理 57（时序与预算保持）** R-Box 检索异步，`O(d log N)`；A-Box 装配 `O(Σ r_a(d_in+d_out)) < 1ms`；
在线拟合 `O(N_bl d r) < 20ms`；RA-Cal 单前向/低秩更新 `< 10ms`；C-Quarantine 只处理受影响锥，异步。
50Hz 路径仅增加 O(1) 的 provenance/hash 检查（`< 0.05ms`），且检索/适配/写回/召回均不在 50Hz 内。
单盲区修复时延增加 `τ_ret + τ_adapt + τ_fit ≤ τ_repair` 预算；超出由 TB-Contract 强制降级。
**因此第 2 轮引理 50 的硬实时与预算不变式保持。**

**相对第 2 轮的关键改进**：
① 经验更新从「重训/覆盖全局先验」变为「检索 + 装配适配器」，不触碰骨干，支持局部撤回；
② 先验污染的治理从「全局暂停」变为「定向召回」，可用性从 0/1 变为按锥局部降级；
③ 新增加载经验的安全闸门（ρ 门 + witness 复核 + 信任域 + 秩预算），把 RAG/LoRA 的常见失效模式显式建模；
④ 新增反例记忆，使「曾经失败过的类比」成为可检索的负向证据。
**总增开销**：50Hz 路径 ≤ 0.05ms/周期；异步修复新增 ≤ 20ms 计算 + 1 次 witness 探测；稀疏触发。

## 5. 对 ToolGauge 的缺陷审计与修复清单

| # | ToolGauge 的缺陷/未言明假设 | 本轮处置 |
|---|---|---|
| 1 | MP-Φ 全局参数记忆，无法局部遗忘/引用/即时更新 | R-Box 案例库 + 结构化 provenance；案例可逐条撤销（定义 432/441） |
| 2 | AP-Cal 一次校准覆盖共享先验，无法限定改动范围 | A-Box 低秩适配器 + 支持集 + 秩预算（定义 435/436/446） |
| 3 | 预训练先验偏移导致跨盲区强相关污染 | 检索按实例、适配按类；信任域 + 权重预算 + witness 复核限制传播（定义 434/437、引理 51） |
| 4 | P-Quarantine 全局暂停，可用性一次性崩塌 | C-Quarantine 按 provenance 锥定向召回；全局暂停仅兜底（定义 441、引理 56） |
| 5 | V 阶段只用 1 条独立回执，无法识别「同一案例被重复借用」 | `n_eff` 有效样本量 + provenance 独立性检查（引理 51/54） |
| 6 | 无容量控制：少数案例可显著改变先验 | 秩预算 + 检索权重上限 + 信任域投影（定义 446、引理 52） |
| 7 | 语言证书是生成物，审计仍依赖叙述 | 案例出处 + 适配器 lineage + 召回审计链，主张必须引用三元组（定义 423 扩展、444） |
| 8 | RAG/LoRA 引入的新攻击面（索引投毒、后门适配器、过期案例） | 结构化签名案例、触发器扫描、反例库、有效期/撤销表（定义 440/442/443/444） |

## 6. 本轮最大风险（一句话）

**一句话**：检索带来的是「外来经验」而不是本地证据——一旦检索到**看似相似但因果不同**的案例，系统会用
「已签名回执 + 案例证书 + 低秩适配器」把它包装成高度可信的修复，从而造成比第 2 轮全局先验污染更隐蔽、
更具**按需定向性**的污染：攻击者只需毒化索引里少数关键案例或适配器，就能精确影响特定盲区，
而信任域只限制偏移的**幅度**、不限制偏移的**方向**（E442/E445/E456 为证伪实验，R1 + witness 复核 + C-Quarantine 为三重兜底）。

**次级风险与缓解**：
1. **错误类比 / 负迁移** → ρ 门只在 held-out witness 上估计增益；反例库硬否决；相似度不得替代因果验证（定义 438/443、引理 55）；
2. **索引投毒 / 适配器后门** → 只收结构化签名案例（禁自由文本）；适配器证书 + 触发器扫描；召回锥可追溯（定义 440/444、引理 56）；
3. **案例过期 / 版本漂移** → 有效期包络、版本过滤、撤销表；过期项只可提案不可作证（定义 442）；
4. **相关性重复计数** → `n_eff` 与 provenance 独立性检查；权重预算 `W_max`（引理 51）；
5. **适配器组合干扰** → 支持集不相交/子空间正交才可精确合并；否则独立专家路由（定义 436、引理 53）；
6. **检索覆盖不足** → 共形阈值 + 弃权；SLA 跌破直接走 ToolGauge 冷路径（定义 439、引理 54）；
7. **索引/延迟增长** → ANN + 秩预算 + 异步写回 + 只存指纹不存原始数据；50Hz 不受影响（引理 57）。

# 第 3 轮产物 · 创新点清单 v3：**RecallGauge**（Retrieval-Augmented, Low-Rank-Adapted Metrology with Recallable Provenance）

> 背景：第 2 轮 ToolGauge（IP-315–320；定义 416–431；引理 46–50）解决了「盲区探测的契约化」与「先验的摊销校准」，
> 但留下三个结构性弱点：MP-Φ 的参数记忆不能引用/局部遗忘/即时更新；AP-Cal 的校准是全局更新、无法限定改动范围；
> P-Quarantine 只能全局暂停、不能定向召回。本轮以「检索增强生成 × LoRA」为灵感，**在 ToolGauge 之上**增加
> 「外部案例记忆 + 低秩适配 + 溯源召回」三层，而不改动 6C 本体与硬实时路径。

> 三条新不变式：**R1 检索只提案不作证、R2 适配只低秩不重写、R3 召回按锥不全停**。
> IP 编号：IP-321–327（共 7 个）。定义增量 432–447；引理增量 51–57；实验增量 E441–E455。

## 2. 形式化定义（要点）

**定义 432（案例与案例库）** 案例是「可重放的修复实验记录」：结构化指纹、已通过 TCV 的程序、有效回执、
校准后验、适配器引用、V/回归/witness 判定、provenance 节点、版本与有效期。只有通过准入协议（定义 440）者进入 `C⁺`；
失败修复进入 `C⁻`，只保留失败指纹，供未来硬否决。

**定义 433（指纹与检索）** 指纹由数值特征、SNC 指纹匹配、工具响应签名、环境包络拼接；距离用归一化 Mahalanobis。
检索阈值 `τ_ret` 由共形分位给出；ANN 实现 `O(d log N)`，不可用时退化为精确扫描或冷启动。

**定义 434（检索假设 vs 检索证据）** 检索结果第一用途是**提案**：并入 L-Box 假设集与 T-Box 排序，不改变证据集。
第二用途才是**证据**：必须由本地独立 witness 回执复核，才能以伪回执、膨胀方差、受限额权重进入 RA-Cal。
**硬约束：未复核案例权重为 0；`Σw_c ≤ W_max`。**

**定义 435（低秩适配器）** 冻结骨干 `W₀`，在线只学 `ΔW = BAᵀ`，`rank ≤ r`，并声明支持集 `supp`。
训练用闭式低秩岭回归（或交替最小二乘）；总秩预算 `Σr_a ≤ r_budget`。适配器是独立、版本化、可撤销的制品。

**定义 436（组合与干扰）** 支持集不相交或子空间正交时组合精确可加；否则干扰
`I(a,b)=||B_aA_aᵀB_bA_bᵀ||_F`，超过 `ε_merge` 即不合并，保留独立专家路由。**能正交就不相加，不能正交就不合并。**

**定义 437（RA-Cal）** 混合效应模型
`u_s = f_{W₀}(φ_s) + g_{δ_S}(φ_s) + Σ_c w_c K(φ_s,φ_c)(u_c − f_{W₀}(φ_c)) + ε`；
后验用温控专家乘积，物理先验作 KL 锚；保守性夹紧 `Σ ≽ κ_phys I`；均值偏移经 `R_trust` 球投影。
`C_ret=∅, r_budget=0` ⇒ 严格退化为 AP-Cal。

**定义 438（三重下注）** 三门同过才执行：λ（物理安全，继承）、β（工具信息增益，继承）、ρ（迁移增益，新增）。
`ρ` 只在 held-out witness / 留一案例上估计，**禁止用检索相似度替代**。任一门失败不产生物理副作用。

**定义 439（覆盖与弃权）** `cov(s)=0` ⇒ 弃权，走 ToolGauge 冷路径并抬高方差。
SLA：`P(cov=1) ≥ 1−α_ret`（可交换性下）；漂移下按引理 54 降级；跌破 SLA ⇒ 全局弃权告警。

**定义 440（准入与写回 W）** 六条件全满足才可写回：V 独立回执、契约回归、无活跃召回、witness 复核、
provenance/签名/版本可复现、结构化字段齐全且无自由文本。写回异步，失败不影响已提交修复。

**定义 441（provenance DAG 与 C-Quarantine）** 案例/适配器/字段版本为节点，边为
`derived_from / trained_on / used_by / replaced_by`。坏案例的召回锥为 DAG 可达集；
撤销锥内案例与适配器，回滚使用过它们的子图，重跑 V，并把坏指纹写入反例库。
P-Quarantine 仅作为 DAG 不完整/来源不明时的全局兜底。

**定义 442（时效与撤销）** 每条案例/适配器带 `(骨干 hash, 工具版本, schema 版本, 环境包络, ttl)`；
过期/版本不匹配项只能作提案，不能作证据；撤销表 `RL` 立即生效。

**定义 443（反例记忆）** 反例存 `(φ_n, h_fail, F_fail)`；若当前指纹与失败指纹匹配，则硬否决该假设/适配器，
除非新的本地 witness 明确推翻。反例库是「检索幻觉」的第一道负向门。

**定义 444（适配器证书与触发器扫描）** 适配器入 A-Box 前必须通过留出 witness、支持集检查、秩预算检查与
触发器扫描（预注册触发模式/激活聚类，扫描集不参与训练）；失败者隔离。

**定义 445（R²-6C）** `R(Retrieve) → A(Assemble/Adapt) → H → C → E → C → V → U → W(Write-back)`；
中段六段与 ToolGauge 完全相同；CQ 为横切监控器。R/W 异步，A 位于 C 内。

**定义 446（信任域与影响预算）** 硬预算 `Σw_c ≤ W_max`、`Σr_a ≤ r_budget`；软约束
`||μ_RA − μ_base|| ≤ R_trust`。每次修复记录实际使用量，作为可审计契约。

**定义 447（继承与严格退化链）** `C⁺=∅, r_budget=0, ρ 门恒假, CQ=P-Quarantine` ⇒ 严格等价 ToolGauge；
退化链 **RecallGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE**。

## 3. 关键算法骨架

```python
# IP-321 R-Box：检索只提案，不作证
class RBox:
    def retrieve(self, s, ctx):
        phi = fingerprint(s, ctx)                     # 数值 + SNC + 响应签名，无自由文本
        if not self.index.ready: return []            # 索引不可用 ⇒ 冷启动
        cands = self.index.ann(phi, k=self.K)
        return [c for c in cands
                if self.valid(c, ctx) and distance(phi, c.phi) <= self.tau_ret]

    def to_hypotheses(self, cands, s):
        return union_conformal([c.h for c in cands], self.lbox.cal)

    def to_pseudo_receipts(self, cands, s, env):
        out = []
        for c in cands:
            r_w = env.witness_probe(s, c)             # 本地独立 witness
            if r_w is None or not independent(c.receipts, r_w): continue
            if not witness_ok(r_w, c, self.eps_w):
                self.negmem.add_from_failure(c, r_w); continue
            out.append(PseudoReceipt(c, r_w, weight=min(self.w_max, self.kernel(s, c)),
                                     var=c.Sig + r_w.var))
        return clip_budget(out, self.W_max)

# IP-322 A-Box：冻结骨干 + 低秩适配 + 秩预算
class ABox:
    def assemble(self, H_s, phi, budget):
        chosen, used_r = [], 0
        for a in self.bank.query(phi, H_s):           # 已过证书/触发器/版本过滤
            if used_r + a.r > budget.r_budget: continue
            if any(not mergeable(a, b) for b in chosen): continue
            chosen.append(a); used_r += a.r
        return AdapterSet(chosen)

    def fit_online(self, cases, H_s, r_max):
        A, B = low_rank_ridge(featurize(cases), residuals(cases),
                              W0=self.base, rank=r_max, lam=self.lam)
        a = Adapter(A, B, r=rank(A), supp=support(H_s),
                    prov=new_prov(cases), cert=None)
        a.cert = certify_adapter(a, self.heldout, self.trigger_scan)
        return a if a.cert.ok else Quarantine(a)

# IP-323 RA-Cal：混合效应 + 信任域 + 保守夹紧
class RACal:
    def calibrate(self, receipts, H, s, adapters, pseudo):
        mu0, S0 = self.mp_phi(featurize_ctx(receipts, H, s))
        mu_a = adapters.apply(featurize(s)) if adapters else 0
        mu, Sig = gaussian_product(
            base=(mu0, S0),
            experts=[(p.mu, p.var, p.weight) for p in pseudo],
            temper=self.temper)
        mu = mu0 + mu_a + clip_radius(mu - mu0 - mu_a, self.R_trust)
        return mu, clamp_min(Sig, self.kappa_phys)

    def transfer_gain(self, pseudo, adapters, s):
        return heldout_nll_gain(pseudo, adapters, s) - self.cost_ret - self.cost_adapt

# IP-324 三重下注
def triple_gate(call, pseudo, adapters):
    return risk_gate(call) and gain_bet(call) and transfer_bet(pseudo, adapters)

# IP-325 R²-6C：6C 本体不动，外面套 R/A/W
def recallgauge_R2_6C(M, s):
    cands    = M.rbox.retrieve(s, M.ctx)                       # R
    H        = conformal_union(M.lbox.hypothesize(s, M.dbox.R[s]),
                               M.rbox.to_hypotheses(cands, s))
    pseudo   = M.rbox.to_pseudo_receipts(cands, s, M.env)      # 仍非证据
    adapters = M.abox.assemble(H, fingerprint(s), M.budget)    # A
    prog     = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s), cands)
    if not triple_gate(prog, pseudo, adapters):
        return M.toolgauge_6c(s, H=H, prog=prog)               # 冷路径（退化）
    receipts = M.tcv.execute(prog, M.env)                      # E
    if len(receipts) < n_min(s): return stub_and_red(s, "insufficient")
    mu, Sig = M.racal.calibrate(receipts, H, s, adapters, pseudo)   # C
    if not M.racal.cross_validate(mu, Sig, M.cross_receipt(s)):     # V
        return stub_and_red(s, "cross_failed")
    new_ec = M.racal.update_contract(M.dpe, mu, Sig, s)        # U
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.dbox.update_from_posterior(s, mu, Sig)
    cert = CaseCert(H, prog, receipts, pseudo, adapters, mu, Sig)
    if case_admissible(cert): submit_async(M.cases.write, cert)     # W
    bind_claims(new_ec, H, prog, receipts, cert)               # 定义 423 扩展
    return True

# IP-326 C-Quarantine：沿 provenance DAG 定向召回
class CQuarantine:
    def recall(self, bad_case):
        cone = self.dag.descendants(bad_case.prov)
        for a in self.abox.trained_on(cone):
            self.abox.revoke(a); self.rl.add(a.id)
        for (s, ver) in self.mreg.versions_using(cone):
            self.mreg.rollback(s, ver.prev); self.reverify_async(s)
        self.cases.revoke(cone); self.negmem.add(bad_case)
        if not self.dag.complete: self.pquar.trigger_global()  # 兜底
        self.audit.log("recall", cone)

# IP-327 主闭环：50Hz 不动，其余异步
def RecallGauge_round(M, obs, audio, tac, depth, det):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s); submit_async(recallgauge_R2_6C, M, s)
    if M.cq.pending(): M.cq.drain()
    if M.pquar.triggered(): M.racal.pause()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（检索影响信任域界）** 若 `||u_c − f_{W₀}(φ_c)|| ≤ Δ_max`、`|K| ≤ 1`、`Σw_c ≤ W_max`，则
`||Δμ_ret|| ≤ W_max Δ_max`；`R_trust` 投影后更紧。相关案例的有效样本量 `n_eff=(Σw)²/Σw²≤|C_ret|`，
以 `n_eff` 替代 `|C_ret|` 进入定义 426 的样本门槛。
系：单点投毒偏移 ≤ `w_max Δ_max`；检索偏移可加、可定位、可回滚，不会自动扩散到未使用它的盲区。

**引理 52（低秩泛化-近似权衡）** `d_eff = r(d_in+d_out−r)`，
`R(δ) − R* ≤ ε_approx(r) + O(√((d_eff log(1/δ)+log N)/N))`。
推论：案例稀少时最优 `r*` 小；案例充足时 `r* ∝ √(N_bl/log N)`，工程默认 `r* = clip(round(√N_bl),1,r_max)`。
冻结骨干 + 支持集有限 ⇒ 对未触及参数块一阶影响为 0，抗灾难遗忘。

**引理 53（适配器组合干扰界）**
`||ΔW_{a+b} − (ΔW_a+ΔW_b)||_F = ||B_aA_aᵀB_bA_bᵀ||_F ≤ ||B_a||₂||A_b||₂√(r_a r_b)σ_max(A_aᵀB_b)`。
支持集不相交或 `A_aᵀB_b=0` ⇒ 精确可加、干扰 0。组合误差随 `√(r_a r_b)` 与子空间重叠增长：
**支持集不相交比秩小更重要。**

**引理 54（检索覆盖共形保证）** 可交换性下 `P(cov=1) ≥ 1−α_ret`；漂移 `η_ret` 下 `≥1−α_ret−2η_ret`；
加权共形可恢复至 `1−α_ret−η_ret L'`。系：`α_ret=0.1, η_ret≤0.05 ⇒ 覆盖 ≥0.8`，跌破即弃权。
与第 2 轮引理 48 同构，但作用于「案例相关性」而非「假设正确性」。

**引理 55（三重下注负迁移界）** 若 `ρ ≥ γ_R` 才借用，且增益估计误差关于 held-out witness 亚高斯（参数 `ξ_ρ`），
则单次「实际增益 <0」概率 `≤ exp(−γ_R²/2ξ_ρ²)`，L 次联合 `≤ L·exp(−γ_R²/2ξ_ρ²)`。
去掉 ρ 门则检索可无限负迁移；ρ 的估计必须来自独立 witness，不能用相似度替代。

**引理 56（定向召回完备性与最小性）** 若契约字段版本记录 provenance 父边、适配器记录 `trained_on`、
热替换记录 `used_by`，则 `Recall(c_bad)` 包含所有依赖 `c_bad` 的案例/适配器/字段版本（完备性），
且删除后其余已提交字段逐位不变（最小性）。证明：DAG 拓扑序归纳 + 版本化写入的精确回滚点。
系：C-Quarantine 可用性严格优于 P-Quarantine；DAG 完备时安全性相同；不完备时全局兜底。

**引理 57（时序与预算保持）** 检索 `O(d log N)`、适配装配 `<1ms`、在线拟合法 `<20ms`、RA-Cal `<10ms`，
全部异步；50Hz 仅增加 O(1) provenance/hash 检查 `<0.05ms`。修复时延增量 `τ_ret+τ_adapt+τ_fit ≤ τ_repair`；
超出由 TB-Contract 强制降级。第 2 轮引理 50 的硬实时与预算不变式保持。

- **继承**：D-Box 盲区判定（398/399）、风险门 λ（400）、M_ver（401）、热替换定理（44）、
  IV-Contract（407，细化为 TB-Contract 424）、6C（421）、TCV/MTC（416–418）、双层下注（419）、
  MP-Φ/AP-Cal（420）、L-Box 共形假设（422）、语言主张绑定（423）、P-Quarantine（428）、
  VLA 白名单（429）、PROBING 状态（430）。
- **升级**：AP-Cal → RA-Cal（加入检索案例与低秩适配，保留 AP-Cal 为退化特例）；
  L-Box → R-Box 增强（检索提案 + 共形并集）；T-Box → 三重下注（λ/β/ρ）；

- **修复第 2 轮缺陷**：全局参数记忆不可局部遗忘 → 案例可逐条撤销；全局校准不可限定范围 → 低秩适配 + 支持集 + 秩预算；
  P-Quarantine 全局停机 → 按 provenance 锥定向召回；V 阶段单回执与重复计数 → `n_eff` + provenance 独立性；
  缺少容量控制 → 信任域 + 权重/秩双预算；语言证书不可审计 → 案例/适配器出处分级。

  签名结构化案例 + 触发器扫描、有效期/撤销表、可合并判据处理；并全部纳入 E442/E445/E448/E455 的证伪实验。

## 8. 本轮最大风险

**一句话**：检索带来的是「外来经验」而非本地证据——一旦检索到**看似相似但因果不同**的案例，
系统会用「已签名回执 + 案例证书 + 低秩适配器」把它包装成高度可信的修复，
造成比第 2 轮全局先验污染更隐蔽、更具**按需定向性**的污染：
攻击者只需毒化索引里少数关键案例或适配器，就能精确影响特定盲区，
而信任域只限制偏移的**幅度**、不限制偏移的**方向**。

**三重兜底**：
1. **R1 检索只提案不作证** + 本地独立 witness 复核（定义 434）——把「借来的经验」降格为待验证假设；
2. **三重下注 ρ**（定义 438、引理 55）——只在 held-out witness 上估计迁移增益，拒绝负迁移；
3. **C-Quarantine 定向召回**（定义 441、引理 56）——即使污染发生，也只回滚 provenance 锥，不全局停机。

**次级风险与缓解**：索引投毒 → 结构化签名案例 + 禁自由文本（定义 429/440）；适配器后门 → 证书 + 触发器扫描（定义 444）；
案例过期 → 有效期/版本过滤（定义 442）；相关案例重复计数 → `n_eff` + provenance 独立性（引理 51）；
适配器组合干扰 → 支持集不相交/子空间正交判据（定义 436、引理 53）；检索覆盖不足 → 共形弃权（定义 439）；
索引/延迟增长 → ANN + 秩预算 + 异步写回，50Hz 仅 O(1) 检查（引理 57）。
