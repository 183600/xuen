# 第 4 轮（灵感循环第 4 轮；本轮灵感：「阻抗控制」×「机械臂抓取」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。前三轮默认「测量是非接触的」——移动传感器去看，而不去碰对象。本轮第一次引入**接触**：阻抗控制负责「让接触有界」，抓取负责「主动改变对象位姿以暴露盲区」。二者都必须是增强项：抓不到 / 力控不可用 / 接触不可辨识，都必须能一键退回纯非接触的 ToolGauge 路径。

## 0. 直觉与动机

**灵感 1（阻抗控制 → 把「无界冲击」换成「有界顺应」）**
直觉：位置控制的机械臂撞上零件时，接触力由「刚度 × 侵入深度」和接近速度共同决定，冲量可以瞬间很大且不可预测；而阻抗控制不让机械臂"死盯"一个位置，而是让它表现得像弹簧-阻尼系统 `M_d ẍ + D_d ẋ + K_d(x−x_r) = F_ext`。于是接触力天然被刚度与允许偏差夹住：`‖F‖ ≤ λ_max(K_d)·δ_sat`（外加阻尼项）。这对计量系统的意义不只是"更安全地碰"，而是**接触强度第一次成为一个可设计、可上界、可审计的量**。因为准静态下对象变形 `δ ≈ F/K_obj`，力界直接翻译成**几何变形界**，再翻译成**计量契约仍然成立的界**——这是本轮最核心的一条链。

**灵感 2（机械臂抓取 → 从「动传感器」升级为「动对象」）**
直觉：盲区有两种成因——传感器到不了，或对象朝向不对。前几轮只会挪传感器；抓取让我们把对象**主动转过来**，用更短路径、更少光学妥协暴露盲区。但抓取引入三类新失败：**抓不稳**（力闭合/摩擦锥不足）、**抓滑/掉落**（外部力超出可承受力旋量集）、**抓挡视线/压变形**（遮挡与接触变形破坏测量）。所以抓取不能是"能不能抓"的二值判断，而必须带**抓取证书**（力闭合 ε-裕度、可承受外力旋量集 `W_g`、滑移裕度、净空/遮挡检查）。

**灵感 3（两者耦合 → 接触-计量耦合：安全 ≠ 有效）**
直觉：阻抗 + 抓取 = 接触式操作。最危险的耦合不是"撞坏"，而是**系统在安全接触下悄悄测错**：力被夹住了，但对象被转了个角度、或表面残留了弹性/塑性变形，而现有契约仍按"未接触时的对象几何"解释回执。于是"接触安全"与"计量有效"之间出现一道缝：力界能保证不压坏，却不能保证几何没变。解法是三根结构支柱：**无源能量约束**（接触稳定、不注入能量）、**接触可辨识**（用接触回执判定 free/contact/slip/drop/jam，辨识不清就冻结）、**变形-契约屏障**（变形超界即判契约失效，强制重校准或中止，绝不静默沿用）。

## 1. 研究问题（本轮要回答什么）

- **Q1（接触的力安全性）**：阻抗控制能否把接触力从"随速度与环境刚度无界"变为"由 `(K_d, D_d, F_max)` 显式界定"，并在执行器/时延受限下仍保持接触稳定？
- **Q2（抓取的计量代价）**：抓取把"挪传感器"换成"挪对象"，在什么条件下净信息增益为正？抓不稳、抓滑、遮挡、变形这些失败能否被证书与回执提前界住？
- **Q3（接触-计量耦合）**：力有界是否足以保证计量有效？当接触改变对象几何/位姿，契约何时必须失效、如何检测、如何退化回非接触路径？

## 2. 三条设计原则（雏形，正式化见产物区定义 448–456）

**P1 无源与力界（Passivity & Force Bound）**
阻抗内环必须**无源**：用能量槽 `E_tank ≥ 0` 记账，控制器只能注入已储存的能量；一旦槽耗尽或内环超时，退回**纯阻尼安全保持**（零刚度、只耗散），绝不继续硬顶。同时力指令硬饱和到 `F_max`，使接触力有上界，并与接近速度解耦。

**P2 抓取证书（Grasp Certificate）**
任何抓取候选必须先过证书：力闭合 + `ε ≥ ε_min` + 任务外力旋量 `W_ext ⊆ W_g` + 净空/遮挡通过。无证书 ⇒ 不抓，退回 `RELOCATE`（纯非接触 ToolGauge）。抓取过程中用接触回执持续复核滑移裕度，滑移即中止。

**P3 变形-契约屏障（Deformation-Contract Barrier）**
把力界经对象刚度翻译成变形界 `δ ≤ F_max/K_obj`；当 `δ > δ_max(EC)`（契约允许的几何扰动）时，**判契约失效**，强制重校准或中止，禁止用旧契约解释变形后的回执。这条把"安全"与"有效"显式解耦：力安全不等于计量有效。

## 3. 与基线的接口（如何退化）

- 无抓取证书 / 对象易碎 / 净空不足 / 任务不需要动对象 ⇒ 选 `RELOCATE` ⇒ 严格等价 InstructGauge 7C（再退 ToolGauge）；
- 阻抗控制器不可用 / 能量槽耗尽 / 1kHz 内环错过截止期 ⇒ 纯阻尼安全保持；若连阻尼都不可用 ⇒ 冻结（fail-safe）；
- 接触状态不可辨识（回执噪声大 / 传感器缺失）⇒ 冻结当前块，不猜测、不前进；
- 变形超 `δ_max` ⇒ 契约失效：优先重校准，失败则中止并退回非接触路径；
- InstructGauge 失效 ⇒ 用默认 `ι₀` 的 ContactGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一套**接触力界的闭环保证**：阻抗 + 饱和 + 无源能量槽，把"冲击危险"变成可设计上界，并给出接触稳定性论证；
2. 一个**抓取证书 + 接触状态辨识**的执行框架，把抓取失败（滑/掉/卡/超力）压成可在回执周期内检测与中止的事件；
3. 一条**力-变形-契约**的传导链：力界 ⇒ 变形界 ⇒ 共形覆盖界，首次把"接触安全"与"计量有效"显式连起来；
4. 一条完整可证伪路径：E457–E472 覆盖力界、无源性、力闭合、滑移时延、变形契约、抓取决策、分层时序与 sim→real 迁移。

## 5. 本轮最大风险

**一句话**：阻抗控制把接触变"安全"（力有界），但力有界并不等于几何不变——抓取带来的位姿偏移与残余/塑性变形可能在对象上留下不可见的状态改变，使契约在"安全接触"下悄悄失效；安全性（力）与计量有效性（几何）之间有一道仅靠力界封不住的缝。

## 2. 形式化定义（要点）

**定义 448（阻抗律与力界）** `M_d ẍ + D_d ẋ + K_d(x−x_r) = F_ext`，`M_d,D_d,K_d ≻ 0`。指令饱和 `F_cmd = sat(F, F_max)`。准静态接触力 `‖F_ext‖ ≤ λ_max(K_d)·δ_sat + λ_max(D_d)·v_sat`，且 `≤ F_max`。设计式 `F_max = min(F_hard, λ_max(K_d)δ_sat + λ_max(D_d)v_sat)`。关键：上界只依赖阻抗参数与饱和量，**与接近速度解耦**。

**定义 449（无源能量槽）** `Ṫ(t) = −Fᵀẋ`（充值）`+ P_diss`，约束 `T(t) ≥ 0 ∀t`。当 `T` 将耗尽，把控制输出投影到 `P_inj ≤ 0`（只耗散）；耗尽 ⇒ `K_d←0` 纯阻尼保持。对任意无源环境，闭环无源 ⇒ 不含自激振荡。

**定义 450（抓取证书）** `GraspCert(g)=(fc,ε,W_g,m_slip,clear)`。`fc=True` 当且仅当各接触力旋量正张成 `R⁶`；`ε=dist(0,∂conv{w_i})` 要求 `≥ ε_min`；`W_g` 为可承受外力旋量集，要求 `W_ext⊆W_g`；`m_slip=ε/‖W_ext‖>1`；`clear=True` 要求夹爪不遮挡目标视域且不与场景碰撞。

**定义 451（接触状态与回执）** `s_c(t)=id(F_t,τ_t,tactile_t,Δpose_t)`：`‖F‖<F_c ⇒ free`；触觉剪切峰 > `S_slip` 或力高频方差 > `V_slip` ⇒ `slip`；`‖Δpose‖>D_drop ∧ ‖F‖<F_c ⇒ drop`；`‖F‖>0.95F_max ⇒ jam`；辨识置信度 < `C_min ⇒ unknown`（触发冻结）。

**定义 452（变形-契约屏障 DCB）** 准静态线性化 `δ = F/K_obj`。契约 `EC` 在未变形几何上校准，允许几何扰动 `δ_max(EC)`。若 `δ > δ_max` ⇒ `INVALID`，触发重校准或中止；绝不静默沿用旧契约。

**定义 453（抓取条件化规划 GCP）** `m* = argmax_{m∈M_adm}[ ΔH(m) + w_g·Gain_grasp(m) − λ_r·R_contact(m) − λ_d·D_def(m) − λ_c·cost(m) ]`。`M_adm` 始终包含 `RELOCATE`，只额外纳入通过 GraspCert 的 `GRASP` 与合法 `CONTACT_PROBE`。`m*=RELOCATE ⇒ 严格 InstructGauge`。

**定义 454（接触技能原语）** `Skill=(φ_pre, Z_d, trajectory, exit, abort)`；`trajectory` 为力-位混合轨线；`exit` 必须由可测回执判定；`abort` 必须能过渡到安全保持（零力或纯阻尼），否则技能不得注册。

**定义 455（抓取-指令能力闭包）** 在 InstructGauge 的 `Γ` 上增加抓取槽：`tools(ι)⊆T₀ ∧ grasp_prim(ι)⊆T_g⊆T₀ ∧ ‖F_cmd‖≤M_phys.force`。语言只能**选择**已注册抓取原语与刚度档，不能新增抓取策略，也不能指定超包线夹持力。

**定义 456（接触解释证书）** `RepairCert″(s)=(ι,m*,GraspCert,Z_d,C_rec,ChunkCert,claims)`——审计可沿「指令→模式→抓取证书→阻抗参数→接触回执→分块证书→主张」链复现一次接触式修复。

```python
# IP-328 ICB：1kHz 阻抗内环（力饱和 + 无源能量槽）
class ImpedanceController:
    def __init__(self, Z, f_max, dt):
        self.M, self.D, self.K = Z             # 期望惯量/阻尼/刚度
        self.f_max, self.dt = f_max, dt
        self.E = E0                            # 能量槽初值

    def step(self, x, dx, ddx_r, x_r, dx_r, F_ext):
        F = self.M @ ddx_r + self.D @ (dx_r - dx) \
            + self.K @ (x_r - x)               # 期望阻抗输出力
        F = saturate(F, self.f_max)            # 硬力界 ⇒ ||F|| <= F_max
        P = float(F @ dx)                      # 与环境交换功率
        self.E = self.E - P * self.dt          # 无源记账
        if self.E <= 0:                        # 槽耗尽 ⇒ 安全保持
            self.K = 0.0                       # 零刚度，仅阻尼耗散
            return self.D @ (dx_r - dx)
        return F

# IP-329 GCF：抓取证书（力闭合 + ε-裕度 + 外力旋量 + 净空/遮挡）
class GraspCertifier:
    def certify(self, g, obj, scene, w_ext):
        if not force_closure(g.contacts, obj.mu):
            return None                               # 无力闭合 ⇒ 不抓
        eps = wrench_margin(g.contacts, obj.mu)       # ε-裕度
        Wg  = graspable_wrench_set(g, obj.mu)
        if eps < EPS_MIN or not subset(w_ext, Wg):
            return None                               # 外力超出可承受集
        if not clearance_ok(g, obj, scene) or occludes(g, scene.target):
            return None                               # 碰撞 / 遮挡
        return GraspCert(eps=eps, W_g=Wg,
                         slip_marg=eps / max(norm_dual(w_ext), 1e-9),
                         clearance=True)

# IP-330 CSI：接触状态辨识（不可辨识 ⇒ 冻结）
class ContactIdentifier:
    def identify(self, rec, f_max):
        if norm(rec.F) < F_CONTACT:
            return DROP if norm(rec.dpose) > D_DROP else FREE
        if shear_peak(rec.tactile) > S_SLIP or hf_var(rec.F) > V_SLIP:
            return SLIP
        if norm(rec.F) > 0.95 * f_max:
            return JAM
        if confidence(rec) < C_MIN:
            return UNKNOWN                            # ⇒ 冻结，不猜测
        return CONTACT

# IP-331 DCB：变形-契约屏障
class DeformationBarrier:
    def check(self, F, obj, ec):
        delta = norm(F) / max(obj.K_obj, 1e-9)        # δ ≈ F / K_obj
        if delta > ec.delta_max:
            return INVALID                            # 契约失效：重校准/中止
        return OK

# IP-332 GCP：抓取条件化模式选择（RELOCATE 恒合法 ⇒ 可退化）
class GraspConditionedPlanner:
    def select(self, iota, s, scene):
        modes = [Mode(RELOCATE)]                       # 基线模式始终可用
        for g in self.grasp_gen.propose(s, scene):
            cert = self.gcf.certify(g, scene.obj, scene, self.w_ext(s))
            if cert is not None:
                modes.append(Mode(GRASP, g, cert))
        if self.skill.available(s):
            modes.append(Mode(CONTACT_PROBE, self.skill.best(s)))
        return max(modes, key=lambda m: self.utility(m, iota, s))

    def utility(self, m, iota, s):
        return (info_gain(m, s) + W_G * gain_grasp(m, s)
                - LAM_R * contact_risk(m, s)
                - LAM_D * deform_cost(m, s)
                - LAM_C * cost(m, s))

    Z = M.icb.profile(m, iota)                         # 选刚度档
    H = M.lbox.hypothesize(s, M.dbox.R[s], iota)
    C = M.iac.plan_chunk(iota, H, M.tools,
                         M.budget_left(s), M.drift_bound(s))
    for a in C.actions:
        rec = M.csi.sample()                            # 采样接触回执
        s_c = M.csi.identify(rec, Z.f_max)
        if s_c in (SLIP, DROP, JAM, UNKNOWN):
            M.icb.safe_hold()                           # 安全保持
            return abort_contact(s, s_c)                # 中止并补偿
        if M.dcb.check(rec.F, M.scene.obj, M.ec(s)) is INVALID:
            M.contract.invalidate(s)
            return recalibrate_or_abort(s)              # 契约失效
        M.icb.commit(a)
    # 沿用的校准/热替换纪律不变
    mu, Sig = M.apcal.calibrate(M.csi.receipts, H, s)
    M.mreg.hot_replace_at_quiescence(M.dpe, M.apcal.update_contract(M.dpe, mu, Sig, s), chunk_boundary(C))
    bind_claims(RepairCert2(iota, m, M.csi.receipts), M.csi.receipts)
    return True

# IP-335 主闭环：50Hz 认知不变；1kHz 内环在独立实时线程
def ContactGauge_round(M, obs, audio, tac, depth, det, ell=None):
    M.icb.ensure_inner_loop_hz(1000)                   # 内环下沉，硬实时
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(contactgauge_8c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)   # 50Hz 路径不变
```

## 4. 推导

**引理 59（阻抗力界与冲击对比）** 在定义 448 下，准静态接触力满足 `‖F_ext‖ ≤ λ_max(K_d)δ_sat + λ_max(D_d)v_sat ≤ F_max`，该上界与接近速度解耦。对比纯位置控制：冲击峰值 `F_pos ≈ √(m_eff·k_env)·v`，随 `v` 无界增长。故阻抗把"冲击危险"变成可设计上界。
*证明骨架*：准静态力平衡 `F_ext = K_d(x_r−x)+D_d(ẋ_r−ẋ)`；对范数用算子范数 `λ_max` 放缩，再用饱和截断；位置控制按能量法 `½m v² = ∫F dx` 给出峰值随 `v` 单调无界。

**引理 60（无源接触稳定）** 若能量槽 `T≥0`，则控制器从环境吸能不超过已储量，闭环对任意无源环境无源，总能量单调不增，故不存在自激极限环。`T→0` 时 `K_d→0` 的纯阻尼保持仍无源。因此在设计刚度域内接触对任意被动对象稳定。
*证明骨架*：Port-Hamiltonian 记账；无源环境满足 `∫Fᵀẋ ≤ 0`，串接后储能非增；`K_d=0` 时只剩 `D_d≻0` 耗散项。

**引理 61（力闭合保持与滑移时延）** 若 `ε≥ε_min` 且 `W_ext⊆W_g`，且外力变化慢于接触回执率，则抓取保持力闭合；滑移可在至多一个回执周期 `Δ_rec` 内被检测（力高频方差 / 触觉剪切阈值），故最大滑移位移 `≤ v_slip·Δ_rec` 有界；若滑移持续则中止。
*证明骨架*：准静态力闭合对 `W_g` 内旋量封闭；检测时延 ≤ 采样周期；位移 = 速度 × 时延。

**引理 62（力-变形-覆盖链，本轮签名结果）** 在线性化 `δ=F/K_obj` 与 DCB 下，`F≤F_max ⇒ δ≤F_max/K_obj`。若 `δ_max(EC)` 按共形覆盖要求标定为「`δ≤δ_max` 时 `coverage(EC|δ)≥1−α−η`」，则阻抗力界与 DCB 联合给出「力安全 ⇒ 计量有效」。逆命题：不设力界时存在 `F` 使 `δ>δ_max` 且覆盖静默跌破 `1−α`——这正是本轮最大风险的形式化。
*证明骨架*：链式不等式 + 覆盖对 `δ` 的 Lipschitz 单调性；取 `δ_max` 为满足覆盖约束的最大扰动。

**引理 63（抓取条件化增益与严格退化）** `U(GRASP)−U(RELOCATE)=ΔH_grasp+w_g·Gain−λ_r·R−λ_d·D−Δcost`，抓取当且仅当该差 > 0。若 `GraspCert` 失败，则 `GRASP∉M_adm`，故 `m*=RELOCATE`，算法代码路径与 `instructgauge_7c` 相等——抓取是严格增强：移除它不降低安全性，只损失潜在增益。
*证明骨架*：`M_adm` 定义 + 代码路径逐行等价。

**引理 64（分层时序保全）** 1kHz 内环抖动 `J < dt_inner`；50Hz 认知路径不含新增加载（仅模式选择 + 异步提交）。若内环看门狗检出超时，在一个 50Hz 拍内闩锁到纯阻尼安全保持，不变量 `Inv` 保持。新增 50Hz 周期 < 0.2ms，继承 ToolGauge 引理 50 / InstructGauge 引理 58。
*证明骨架*：实时线程与认知线程解耦；闩锁在单拍内有界；加载量估计同前。

**引理 65（抓取-指令能力闭包）** 在定义 455 下对指令文法做结构归纳（同引理 51），得 `grasp_prim(ι)⊆T_g⊆T₀` 且 `‖F_cmd‖≤M_phys.force`。故语言不能新增抓取能力或超包线力；越权抓取请求一律 `⊥` ⇒ 默认 `ι₀`。语言仍只是固定抓取库上的偏好选择。
*证明骨架*：基础情形抓取槽取白名单 `T_g`；复合指令只做过滤/重排；越权产生式落 `⊥`。

## 8. 本轮最大风险

**一句话**：`ICB` 的力界与 `GCF/DCB` 的几何假设在接口处形成**安全-有效裂缝**——力被夹住只保证"不压坏"，却无法保证抓取位姿偏移与残余/塑性变形没有改变被测几何；一旦变形未被 `δ_max` 捕获（如蠕变、局部塑性、抓取滑移后的重定位误差），契约会在"安全接触"下静默失效。缓解只能依赖结构（无源使接触稳定、抓取证书使失败可检测、DCB 使超界必失效、CSK 的 `exit/abort` 使中止可执行），并以 E457/E460/E461/E467/E471 主动证伪。
