### 第 1 轮灵感驱动研究记录（新循环起点，继承第 5 轮 CADVS-v5）

**灵感词**：实例分割、产学研合作

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议升级为条件流匹配、记忆升级为可固化 LMEM-v2、人因升级为情感阈值调制，并用定理 6 确立了「提议可换、门不可换」的证书不变性，执行集链为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。v5 留下了两个未被形式化的隐含假设：(H1) 场景可被完整枚举为「全局对象」，门在场景级求值；(H2) 证明者与提议者是同一主体，证书可自我背书。本轮两个灵感词恰好分别攻击这两个假设：**实例分割**把门从场景级细化到实例级，**产学研合作**把证书从单方断言升级为多方独立共证。二者统一为主题「认证的实例化多方共证执行」（Certified Instance-Scoped Multi-Party Attested Execution, CIMA），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量仍为七**——新增的不是门，而是证书的两个有效性维度：作用域 scope 与出处 provenance；二者缺失都按 fail-closed 处理，因此执行集只缩不涨：Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **实例分割 → 安全不是场景级平均，而是实例级合取**。v5 的 3DCF 覆盖门检查「轨迹扫掠体是否被场景解释」，但一个被遮挡、未被分割出的实例，会让覆盖门在「看起来空」的区域错误通过。直观上，一条轨迹对整幅场景「平均安全」没有意义：只要有一个相关实例未被认证处理，它就是不安全的。因此把证书从 `(谓词 φ, 证据 w)` 扩展为 `(φ, scope, w)`，其中 scope 是该证书所覆盖的实例集合与掩码；3DCF 变成实例索引覆盖，并新增「未知区域要么被证明为空、要么按占据处理」的开放世界闭合条件。关键是不加新门：覆盖完整性并入 3DCF，物理门按接触实例对求值，价值门按受影响实例求值。

2. **产学研合作 → 证书的「谁证明」与「证明什么」同等重要**。v5 的最大风险 R57 是记忆固化的自指回路：策略在自己铸证的片段上学习，再为自己铸证。单靠冻结门、KL 正则和内部红队只能经验性缓解。产学研合作给出一个结构性答案：把「提议者 / 认证者 / 审计者」三种角色分离，证书必须由 n 个独立机构中至少 k 个签名才有效，且提议方签名不得计入认证与审计票数、至少一名审计方须不同于提议方。这样「铸证→学习→再铸证」的闭环被外部真值（学术红队、产业运行遥测、第三方/监管审计）打断。数学上，这把 v5 定理 7 的「博弈率仅有经验上界」提升为「在非合谋假设下的结构上界」——诚实边界是：非合谋是社会组织假设，不是密码学保证。

3. **统一视角：证书 = 谓词 × 作用域 × 出处**。实例分割回答「这张证书覆盖哪些对象」，产学研合作回答「谁有权为这张证书背书」。两者相乘，恰好补上 v5 的 (H1)(H2) 两个隐含假设。更妙的是，它们都只增加证书的有效性合取项，不改变门谓词本身，因此定理 6 的证书不变性、定理 5 的调制单调性、以及整条执行集嵌套链全部原样保持——v6 是 v5 的「有效性收紧」，而非框架重写。

**关键洞见**：v5 证明「换提议器不破坏证书边界」；v6 证明「换证书粒度与签发主体同样不破坏边界，且能堵住自指」。安全边界从「一条轨迹是否通过七门」变成「一条轨迹是否在每一个相关实例上、由足够独立的机构共同认证通过七门」。这把信任从「单点模型正确」迁移到「分布式制度正确」，代价是引入两个新的社会技术假设：分割召回完整、机构相互独立。

**形式化目标（增量）**：

1. 实例集与作用域：`I_t = I_t^thing ∪ I_t^stuff`，每个实例 `i` 有掩码 `M_i`、amodal 补全掩码 `A_i`、可见度 `ρ_i`、不确定度 `u_i`、身份 `id_i`；证书 `κ = (φ, scope, w, att)`，`scope ⊆ I_t`。
2. 实例化七门：`kc_j(x) = ∧_{i∈I_rel(x)} kc_j^i(x) ∧ pairwise(x on G_contact)`，`j` 仍为七门；`I_rel(x) = {i : M_i ∩ E(x) ≠ ∅}`，`E(x)` 为轨迹扫掠安全包络。
3. 开放世界覆盖：`Cov(x)=1` 当且仅当 `E(x)` 中未被任何实例解释的区域被证明为空或不可达；否则该区域按占据处理并 fail-closed。`3DCF_v6 = 3DCF_v5 ∧ Cov`。
4. 多方共证：`Att(κ)=1` 当且仅当 `≥k` 个不同机构签名、角色合法、提议方不计入认证/审计票、至少一名审计方 ≠ 提议方、无撤销；`kc^v6 = φ ∧ Att ∧ Cov`。
5. 执行集：`Exec_v6 = {x ∈ supp(π_FM) : ∧_j ∧_{i∈I_rel} kc_j^i(x; τ_j^6)=1, Cov(x)=1, Att(κ)=1} ⊆ Exec_v5`，其中 `τ_j^{6,i} ≥ τ_j^{5}`（逐实例只紧不松）。
6. 新定理：定理 9（实例分解精确性）、定理 10（开放世界单调性/遮挡 fail-closed）、定理 11（多方共证不可伪造与自指打破）、定理 12（七锚完备性在实例化与共证下保持）；引理 45（实例身份连续性）、引理 46（amodal 覆盖假接受界）。

**本轮最大风险**：**两个 fail-closed 前提的社会-感知耦合失效**——分割漏检会把未识别实例从 `scope` 中静默抹掉，而产学研各方的经费、数据与标准利益趋同会让 `k-of-n` 退化为单方背书；一旦「覆盖完整」与「机构独立」这两个非密码学假设被同时腐蚀，系统会用形式完备的证书为真实世界的未知实例背书。

```python
    def segment(self, obs) -> InstanceSet:
        # 输出：M_i, A_i(amodal), rho_i, u_i, id_i, 类别/开放词表嵌入
        ...

    def relevant(self, I: InstanceSet, x: Trajectory) -> list[int]:
        E = swept_envelope(x)                       # 含安全边际
        return [i for i in I.ids if intersects(I.A[i], E)]

    def coverage_cert(self, I: InstanceSet, x: Trajectory) -> bool:
        """Cov：未知区域为空或不可达；不确定 amodal 区按占据处理。
        关键：分割漏检不能成为静默通过的理由。"""
        U = swept_envelope(x).difference(union_amodal(I))
        if is_empty(U):
            return True
        if all(unreachable_by_robot(r) for r in components(U)):
            return True
        return False                                # fail-closed：按占据

    def gate(self, j: str, x: Trajectory, I: InstanceSet,
             tau: dict) -> Certificate:
        rel = self.relevant(I, x)
        scope = set(rel)
        phi = all(kc_gate_j(j, x, i, tau[j]) for i in rel)
        if j in ('physics', 'balance'):
            phi &= all(kc_pair(x, i, l, tau[j])
                       for (i, l) in active_contact_edges(I, x))
        phi &= self.coverage_cert(I, x) if j == 'coverage' else True
        return Certificate(phi=phi, scope=scope, w=evidence(j, x, rel),
                           att=None)                 # att 由 MPAS 填充
```

```python
@dataclass
class InstanceGroundedProposalAmodalCoverage:
    """IGPAC：流匹配条件升级为实例 token 集合；开放词表支撑新物体。
    定理 6 仍成立：只换提议分布，不改门。"""
    fmpp_v5: Any                   # 复用 v_θ 主干与 ODE 采样
    seg: InstanceScopedGateDecomposition
    n_inst_tokens: int = 32

    def build_ctx(self, I, mem, s_emo, task) -> Context:
        T_I = [token(mask_pool(I.M[i]), I.A[i], I.rho[i], I.u[i],
                     I.cls_emb[i]) for i in I.ids[:self.n_inst_tokens]]
        return Context(inst_tokens=set_attn(T_I), mem=mem,
                       s_emo=s_emo, task=task)

    def propose(self, c: Context, k: int = 8) -> list[Trajectory]:
        # 以实例 token 为 cross-attn 条件积分 ODE；接触图约束采样先验

    def unknown_as_occupied(self, I, x) -> bool:
        """amodal 不确定区与 E(x) 相交即视为占据，供覆盖门使用"""
        return not self.seg.coverage_cert(I, x)
```

### IP-499 MPAS：多方共证与角色分离（异步，发布/准入慢时域）

```python
@dataclass
class MultiPartyAttestation:
    """MPAS：产学研三方角色分离的 k-of-n 共证。
    直接攻击 v5-R57：证书不再能自我背书。"""
    n: int = 5
    k: int = 3
    pubkeys: dict                  # org_id -> 公钥
    roles: dict                    # org_id -> {P,C,U}
    ledger: Ledger

    def sign(self, cert: Certificate, org_id: str, role: str) -> Signature:
        assert role in self.roles[org_id]
        assert role != 'P' or org_id == cert.proposer_id
        return sign(self.pubkeys[org_id], canonical(cert, role))

    def verify(self, cert: Certificate) -> bool:
        sigs = self.ledger.signatures(cert.digest)
        orgs = {s.org for s in sigs if self._valid(s)}
        if len(orgs) < self.k:
            return False
        # 角色分离：提议方不计入认证/审计票
        certifiers = {s.org for s in sigs if s.role == 'C' and s.org != cert.proposer_id}
        auditors  = {s.org for s in sigs if s.role == 'U' and s.org != cert.proposer_id}
        if not certifiers or not auditors:
            return False
        if not any(a != cert.proposer_id for a in auditors):
            return False
        return not self.ledger.is_revoked(cert.digest)

    def release(self, theta_new, regression_ok: bool, redteam_ok: bool) -> bool:
        """模型/固化策略上线需 ReleaseCert；无共证则回滚旧 θ"""
        cert = make_release_cert(theta_new, regression_ok, redteam_ok)
        return self.verify(cert)
```

### IP-500 EFA-v6：七硬门 + 实例作用域 + 共证校验

```python
@dataclass
class EvidenceForgingAssemblerV6:
    isgd: InstanceScopedGateDecomposition
    igpac: InstanceGroundedProposalAmodalCoverage
    mpas: MultiPartyAttestation
    v5: EvidenceForgingAssemblerV5          # 复用 scf/msrg/hic/eek/vack/bck

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Trajectory|None, str]:
        I = self.isgd.segment(context.obs)
        s_emo = self.v5.famk.observe(context.face, t_now)
        gamma = self.v5.famk.gamma(s_emo)                    # 只紧不松
        c = self.igpac.build_ctx(I, self.v5.lmem, s_emo, context.task)
        cands = self.igpac.propose(c, self.v5.fmpp.K)        # K=8，异步
        # 第 1 层：实例化廉价门（coverage/physics/memory/novelty）
        surv = []
        for x in cands:
            rel = self.isgd.relevant(I, x)
            if not self.isgd.coverage_cert(I, x):
                continue                                     # 未知区 fail-closed
            if not all(self._cheap_gate(j, x, I, rel, gamma) for j in CHEAP):
                continue
            surv.append((x, rel))
        if not surv:
            return self._fallback_rule_proposal(I, gamma)    # 回退 v4/v5 规则提议
        # 第 2 层：VACK 逐实例评估 ≤3 幸存者
        finals = []
        for x, rel in surv[:3]:
            cert = self.v5.vack.evaluate_instances(x, I, rel, context_with(s_emo), t_now)
            if cert.phi and self.isgd.coverage_cert(I, x):
                finals.append((x, rel, cert))
        # 第 3 层：BCK 按接触边预览（事件触发 QP + 缓存内插）
        ok = [(x, rel, cert) for (x, rel, cert) in finals
              if self._bck_preview_edges(x, I, gamma)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        # 共证：候选证书必须带 k-of-n 出处，否则视为无效
        attested = [(x, rel, cert) for (x, rel, cert) in ok
                    if self.mpas.verify(cert)]
        if not attested:
            return self._fallback_rule_proposal(I, gamma)    # fail-closed
        best = max(attested, key=lambda t: certified_margin_instances(t[0], I, t[1]))
        return True, best[0], 'FORGED_CIMA'
```

```
  IGPAC.propose（实例 token 条件，K=8）──▶ 实例化廉价门
        ├─ 全灭/未知区占据 ──▶ fail-closed 回退规则提议
        └─ 幸存 ≤3 ──▶ VACK 逐实例 ──▶ BCK 接触边预览 ──▶ MPAS 共证校验
                                        └─ 无共证 ──▶ fail-closed 回退

在线控制环（目标 < 0.6 ms）：
  每周期：EEK(kc_ee) + BCK（接触图未变 → 缓存证书 + 解析边际内插）
  证书消费：仅消费已共证且 scope 覆盖当前相关实例的证书；作用域不匹配即拒绝
```

## 4. 正确性论证（增量更新）

### 引理 45（实例身份连续性）

**陈述**：若相邻帧实例匹配满足外观嵌入距离 ≤ δ_e 且掩码 IoU ≥ δ_m，则身份切换概率 ≤ ε_id；身份一旦变更，旧 scope 证书作废并触发重认证。**证明**：匹配为二分图最小代价匹配，错误匹配需距离越过阈值；由 Hoeffding 界得 ε_id。∎

### 引理 46（amodal 覆盖假接受界）

**陈述**：设分割对相关实例的漏检率为 r_miss，amodal 补全对遮挡区的覆盖召回为 r_amodal，未知区可达性判定假阴性率为 r_reach。则覆盖证书的假接受率 `P(Cov=1 | 存在未认证相关实例) ≤ r_miss·(1−r_amodal) + r_reach`。**证明**：未认证实例被覆盖证书放行，必须同时满足「未被分割」或「被 amodal 漏补」且「未知区被误判不可达」；并集界。∎ **诚实边界**：该界依赖 r_miss、r_amodal、r_reach 的估计；开放世界中新类别可能同时压低三者，界不可先验保证。

### 定理 9（实例分解精确性）

**陈述**：若七门谓词可分解为实例局部项与接触边配对项，且覆盖证书完整，则
`kc_j(x) = (∧_{i∈I_rel} kc_j^i(x)) ∧ (∧_{(i,l)∈E_contact} kc_j^{pair}(x))` 为**精确**分解（非仅充分），且 `Exec_scene ⊆ Exec_i` 对每个 i 成立；`Exec_v6 = ⋂_j ⋂_i Exec_j^i ∩ Exec_pair ∩ Exec_cov`。**证明**：门是轨迹空间上的合取谓词；局部项与配对项覆盖所有相互作用，无遗漏项；交集对每个因子单调。∎ **边界**：三体及以上同时接触的耦合若不能分解为成对项，需引入超边证书；本轮只保证二体接触图精确。

### 定理 10（开放世界单调性 / 遮挡 fail-closed）

**陈述**：设 `I_t ⊆ I_{t+1}`（新实例被揭示，删除实例须有「缺席证书」），且阈值只紧，则 `Exec_v6(t+1) ⊆ Exec_v6(t)`。**证明**：新增相关实例只增加合取项；未知区按占据处理只会使 Cov 由 1 变 0；阈值单调升使各门通过集缩。∎ **推论**：分割召回错误在「未知区按占据」策略下只导致过度拒绝（安全侧）；唯一危险是覆盖证书错误声明未知区为空，即引理 46 的假接受。

### 定理 11（多方共证不可伪造与自指打破）

**陈述**：在 EUF-CMA 签名与「任意 <k 个机构不被同一对手控制」的非合谋假设下，对手伪造被接受的证书的概率 ≤ negl(λ)。进一步，策略 θ 通过自指固化获得「形式合规、实质违背」证书的概率满足
`P_game ≤ P_collude(k) + (1 − recall_audit) + ε_id`，
其中 P_collude(k) 为 ≥k 机构被同一利益方控制的概率，recall_audit 为独立审计对博弈样本的检出率。**证明**：有效证书需 ≥k 独立签名（阈值签名不可伪造）；提议方不计票与审计方独立性切断自签；剩余漏网来自合谋、审计漏检与实例身份错误，取并集界。∎ **诚实边界**：非合谋是社会组织假设，非密码学保证；P_collude 无法从系统内部估计，只能由外部治理（轮换、披露、独立经费）压低。

### 定理 12（七锚完备性在实例化与共证下保持）

**陈述**：v6 不增删锚点，七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 完备性（v4 定理 4）保持；ISGD 是 3DCF/MSRG/VACK/BCK 的实例索引细化，IGPAC 是提议器升级，MPAS 是证书有效性元数据，均非新锚。**证明**：锚点集合不变；实例化只细化已有谓词的作用域；共证只增加有效性合取；由定理 5、6、9、10，覆盖链不变且只强不弱。∎

### 定理 v6（执行集四重收缩与制度不变性，总装）

**陈述**：在 v4 假设 (B1)~(B6)、v5 假设 (B7) 及新增 (B8) 实例身份连续性（引理 45）、(B9) 非合谋共证（定理 11）下：
(i) `Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29`；
(ii) 证书不变性（定理 6）在实例作用域下保持：换提议器不改变任何门谓词；
(iii) 实例分解精确（定理 9），开放世界只缩不涨（定理 10）；
(iv) 共证把自指博弈率从「仅有经验上界」提升为「非合谋假设下的结构上界」（定理 11）；
(v) 七锚完备性保持（定理 12）；
(vi) 覆盖假接受率由引理 46 界，身份切换率由引理 45 界。
**证明**：(i) 同门 + 逐实例阈值只紧 + scope 限制 + Att 合取；(ii)~(v) 分别由定理 6、9、10、11、12；(vi) 由引理 45、46。∎

**诚实声明**：(B8) 开放世界分割召回无法先验保证，遮挡/新类别是原理性盲区；(B9) 非合谋是制度假设，监管俘获与经费绑定可使其失效；(iii) 三体以上接触的超边证书未形式化；(iv) 加性价值假设 (B4) 继承自 v4，未解决；(v) 共证引入治理延迟与责任/IP 摩擦，可能拖慢安全修复上线。

## 5. 实验设计与初步结果（仿真 + 三方共证 dry-run；实机/真实联盟列入下一轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX；分割用 Mask2Former（COCO/ADE20K 预训练）+ SAM2 提示式 amodal 补全；实例数上限 32；记忆库 50k 仿真片段。

## 7. 本轮最大风险（最终确认）

**一句话**：**两个 fail-closed 前提的社会-感知耦合失效**——分割漏检会把未识别实例从 `scope` 中静默抹掉，而产学研各方的经费、数据与标准利益趋同会让 `k-of-n` 退化为单方背书；一旦「覆盖完整」与「机构独立」这两个非密码学假设被同时腐蚀，系统会用形式完备的证书为真实世界的未知实例背书。
