### 第 1 轮灵感驱动研究记录

**灵感词**：通用机器人、桌面操作

**直觉与动机**：
前几轮（v22–v26）的演进是「失败模式覆盖」：每发现一类风险就新增一枚证书（结构 → 力控 → 语义 → 重构 → 协同 → 成本 → 记忆 → 可扩展）。这在单机上越来越安全，却与「通用机器人」的目标背道而驰：证书越专用，换一个本体、末端或桌面就要重新标定，而 `Exec` 的交集还随证书数量单调收缩。真正卡住通用化的不是「缺检查」，而是**证书不可搬运**。

「桌面操作」恰好是检验通用性的最小完备试验台：重力主导、支撑面约束、接触丰富、工作空间狭窄、物体小且被遮挡、人机共享同一桌面。它把抽象证书逼回物理现实——语义覆盖再高，若静力学上不成立（会滑、会翻、会穿桌），计划仍不可执行。

核心洞见：**通用性 = 证书沿具身同态的可迁移性（transport）；桌面操作 = 重力-支撑-接触约束下的可满足性（satisfiability）。** 因此 v27 不再横向堆叠证书，而是给证书体系加一个纵向的「传输层 + 物理层 + 组合层」：把证书改写成**无量纲形式**（Froude 数、力重比、能量密度），使其在本体缩放/换型下保持；用桌面静力学 LP/SOCP 给出物理可行裕度；用技能契约代数保证组合闭包。三者交汇处是「能力保持」问题，而非重新发明控制。

**形式化目标**：
1. 定义具身迁移证书（ETC）：具身无量纲描述子 θ_E、模拟关系 R 与动作抽象 α、证书传输算子 F_{A→B}、δ-可迁移性，并给出迁移的 Lipschitz 误差界。
2. 定义桌面物理可行证书（TPFC）：支撑多边形裕度、摩擦锥/静力平衡 LP 裕度、非穿透、可达性、力闭合抓取五元裕度，取瓶颈裕度 t* ≥ τ_task。
3. 定义通用技能组合证书（GSCC）：技能契约 (Pre, Post, Inv)、组合闭包与胶水证书、任务分布上的 conformal 覆盖，以及迁移造成的覆盖缺口 α_B ≤ α_A + L_θ·δ_emb + δ_trans。
4. 构建通用桌面统一准入门（GTUC v27）：`Exec_v27 = Exec_v26 ∩ Fil_emb ∩ Fil_table ∩ Fil_skill ∩ Fil_task ⊆ Exec_v26`，证明退化链与「通用性代价」定理。
5. 以桌面静力学微型数值实验验证 TPFC 的可靠性与保守度（与解析滑移/倾覆阈值对照）。

**本轮最大风险（一句话）**：若无量纲描述子遗漏了不可缩放的隐藏物理（柔性、间隙、摩擦各向异性、传感延迟），ETC 会把一个具身上的安全裕度错误外推为另一个具身上的安全保证，而 TPFC 的刚体点接触假设又无法察觉这种外推错误。

# v27：通用桌面证书传输层（GTUC）

> 相对 v26（SRC-USC + CACB + TCM + HSC）的定位：v22–v26 是「失败模式覆盖」路线，证书随场景变多而变专；v27 转向「证书搬运」路线——先把证书无量纲化，使其沿具身同态可迁移，再用桌面静力学把它钉回物理。核心不是新增更多检查，而是回答：**在一台机器人/一个桌面上证明过的安全，凭什么能搬到另一台机器人/另一个桌面？**

## 2. 核心定义

### 2.1 无量纲具身描述子

直觉：同一套「小心地推一个杯子」的策略，放在 5 kg 桌面臂和 50 kg 移动臂上，绝对速度、力、能量都不同，但**力重比、Froude 数、能量密度**应大体相同。证书只有写成这些无量纲群，才可能跨具身保持。

**定义 1300（具身描述子）**：对具身 E，记其特征长度 ℓ、质量 m、重力 g，定义

```
θ_E = ( n_dof,
        τ_max/(m g ℓ),  F_max/(m g),  v_max/√(gℓ),
        κ·m g/ℓ,  μ,  m_payload/m,  ℓ_tool/ℓ )  ∈ Θ
```

距离 `d_Θ(A,B) = max_j |log(θ_A[j]/θ_B[j])|`（n_dof 用 |n_A−n_B| 单独计），对尺度缩放严格不变。迁移球 `B_δ(θ_A) = {θ_B : d_Θ(A,B) ≤ δ_emb}`。

### 2.2 证书的无量纲化

**定义 1301（无量纲裕度）**：给定证书中的绝对裕度 m_k（长度/力/力矩/能量/时间/速度），取特征单位 u_k 得 `π_k = m_k/u_k`。证书 `Cert = (Pre, Post, Inv, π)`，其中安全判据只依赖 π 向量而非绝对量。绝对量在目标具身上按 `m_k^B = π_k · u_k^B` 反算。

### 2.3 模拟关系与动作抽象

**定义 1302（A ⪯_{R,α} B）**：存在 R ⊆ S_A×S_B 与 α: U_A→U_B，使得

```
∀(s_A,s_B) ∈ R, ∀u_A ∈ U_A:
    ( f_A(s_A,u_A), f_B(s_B, α(u_A)) ) ∈ R
且任务相关观测一致：‖h_A(s_A) − h_B(s_B)‖ ≤ ε_obs。
```

即 B 能在抽象状态空间跟踪 A 的任务级轨迹。注意方向：**从参考具身 A 迁移到目标具身 B**，要求 B 能模拟 A，并用 2.4 的描述子条件补足「物理上够得着」。

### 2.4 传输算子与 δ-可迁移性

**定义 1303（传输算子）**：

```
F_{A→B}(π^A) 定义为一组等式/不等式：
    · 能量：   Ê_max^B ≥ Ê_max^A · (m_B ℓ_B)/(m_A ℓ_A)
    · 力：     F̄_max^B ≥ F̄_max^A
    · 速度：   v̄_max^B ≥ v̄_max^A
    · 可达：   ℓ_reach^B ≥ ℓ_reach^A （目标点集合包含）
    · 时间：   t̄_B ≤ t̄_A · (ℓ_B/v_B)/(ℓ_A/v_A)
    传输残差： δ_trans = max_k |π_k^B − π_k^A| / max(|π_k^A|, ε)
```

**定义 1304（δ-可迁移）**：`Cert_A` δ-可迁移到 B，当且仅当

```
(1) A ⪯_{R,α} B 存在见证；
(2) d_Θ(A,B) ≤ δ_emb；
(3) F_{A→B}(π^A) 在 B 上重算后的残差 δ_trans ≤ δ_budget；
(4) 每个 Inv_k 的裕度满足 π_k^B ≥ π_k^A − L_π·δ_emb − δ_trans。
```

满足时记 `A ⊢_δ B`。**关键点**：迁移降低的是无量纲裕度，绝对安全裕度在 B 上按其自身尺度重新计算，因此「更大的机器人可以更安全」是可能的，反之亦然。

### 2.5 桌面物理可行证书（TPFC）

**定义 1310（桌面场景）**：平面 Π = {z=0}，重力 g e_z 向下，物体 O 的质心 c、质量 m，接触点 {r_i}，外作用力 F_ext 作用于 r_ext。

**定义 1311（静力可行裕度）**：以多面体摩擦锥（L 条边、方向 u_k）内近似，解 LP

```
最大化  t
约束:
    Σ_i f_i                     = −(F_ext + m g e_z)          (3)
    Σ_i (r_i − c) × f_i         = −(r_ext − c) × F_ext        (3)
    f_i · e_z                   ≥ t                            (法向非负裕度)
    u_k · (f_i)_xy              ≤ μ (f_i·e_z − t),  ∀k         (摩擦锥裕度)
    f_i 自由, t ≥ 0
```

最优值 t* 即静力可行瓶颈裕度。多面体锥 ⊂ 精确二阶锥，故 `t*_LP ≤ t*_SOCP`：**通过 LP 即通过精确锥（sound），反之可能保守（incomplete）**。

**定义 1312（五元桌面证书）**：`TPFC = (d_sup, t*, d_clear, t_reach, t_grasp)`，归一化为

```
π_sup = d_sup/ℓ_body,  π_fric = t*/(m g),  π_clear = d_clear/ℓ_body,
π_reach = t_reach/ℓ_reach,  π_grasp = t_grasp/(m g ℓ_grasp)
瓶颈： t*_bottleneck = min_k π_k
判据： t*_bottleneck ≥ τ_task    （τ_task 为任务级无量纲安全要求）
```

非穿透 `d_clear ≥ 0`、可达 `t_reach ≥ 0`、力闭合 `t_grasp > 0` 分别作为硬约束进入上式；任一为负即直接拒证。

```python
# ============================================================
# IP-451 Embodiment Transport Certificate (ETC)
# ============================================================
@dataclass
class EmbodimentDescriptor:
    n_dof: int
    tau_bar: float          # tau_max / (m g l)
    f_bar: float            # F_max / (m g)
    v_bar: float            # v_max / sqrt(g l)
    kappa_bar: float        # kappa * m g / l
    mu: float               # 摩擦系数
    payload_ratio: float    # m_payload / m
    tool_ratio: float       # l_tool / l
    ell: float              # 特征长度 (m)
    mass: float             # 质量 (kg)
    g: float = 9.81

    def vector(self) -> np.ndarray:
        return np.array([self.tau_bar, self.f_bar, self.v_bar,
                         self.kappa_bar, self.mu,
                         self.payload_ratio, self.tool_ratio])

    def distance(self, other: "EmbodimentDescriptor") -> float:
        a, b = self.vector(), other.vector()
        log_ratio = np.abs(np.log(np.maximum(a, 1e-12) /
                                  np.maximum(b, 1e-12)))
        return float(max(log_ratio.max(), abs(self.n_dof - other.n_dof)))


@dataclass
class EmbodimentTransportCertificate:
    """参考具身 A -> 目标具身 B 的证书搬运"""
    desc_A: EmbodimentDescriptor
    desc_B: EmbodimentDescriptor
    delta_emb: float = 0.15       # 允许的描述子相对偏差 (log)
    delta_budget: float = 0.10    # 允许的无量纲裕度损失
    L_pi: float = 1.0             # 描述子->裕度 Lipschitz 常数 (离线拟合)

    def transport_margins(self, pi_A: dict) -> dict:
        """把 A 的无量纲裕度搬成 B 的无量纲裕度（缩放律）"""
        r_m = self.desc_B.mass / self.desc_A.mass
        r_l = self.desc_B.ell / self.desc_A.ell
        pi_B = dict(pi_A)
        # 能量密度与力重比在理想缩放下保持不变；此处显式写出缩放残差
        pi_B["energy"] = pi_A["energy"] * (r_m * r_l) / (r_m * r_l)
        pi_B["force"] = pi_A["force"]
        pi_B["velocity"] = pi_A["velocity"]
        pi_B["time"] = pi_A["time"] / (r_l / (self.desc_B.v_bar /
                                              max(self.desc_A.v_bar, 1e-9)))
        return pi_B

    def transferable(self, pi_A: dict) -> tuple[bool, dict]:
        d = self.desc_A.distance(self.desc_B)
        pi_B = self.transport_margins(pi_A)
        delta_trans = max(abs(pi_B[k] - pi_A[k]) / max(abs(pi_A[k]), 1e-9)
                          for k in pi_A)
        ok = (d <= self.delta_emb and delta_trans <= self.delta_budget)
        degraded = {k: pi_A[k] - self.L_pi * d - delta_trans for k in pi_A}
        return ok, {"d_theta": d, "delta_trans": delta_trans,
                    "degraded_margins": degraded}

# IP-452 Tabletop Physical Feasibility Certificate (TPFC)
# ============================================================
@dataclass
class TabletopPhysicalFeasibilityCertificate:
    """桌面五元裕度：支撑 / 摩擦-静力 / 穿透 / 可达 / 抓取"""
    contacts: np.ndarray          # [C, 3] 桌面接触点
    com: np.ndarray               # [3] 质心
    mass: float
    mu: float = 0.5
    g: float = 9.81
    L_cone: int = 16              # 摩擦锥多面体边数
    ell_body: float = 0.1
    tau_task: float = 0.05        # 任务要求无量纲瓶颈裕度

    def _dirs(self) -> np.ndarray:
        th = np.linspace(0, 2 * np.pi, self.L_cone, endpoint=False)
        return np.stack([np.cos(th), np.sin(th)], axis=1)

    def static_equilibrium_margin(self, F_ext: np.ndarray,
                                  r_ext: np.ndarray) -> tuple[bool, float]:
        """LP: max t s.t. 力/力矩平衡 + 法向非负 + 多面体摩擦锥（内近似）"""
        from scipy.optimize import linprog
        C = len(self.contacts)
        n = 3 * C + 1                      # [f_1..f_C, t]
        A_eq = np.zeros((6, n)); b_eq = np.zeros(6)
        for i, r in enumerate(self.contacts):
            A_eq[0:3, 3*i:3*i+3] = np.eye(3)
            d = r - self.com
            A_eq[3:6, 3*i:3*i+3] = np.array(
                [[0, -d[2], d[1]], [d[2], 0, -d[0]], [-d[1], d[0], 0]])
        b_eq[0:3] = -(F_ext + np.array([0, 0, self.mass * self.g]))
        b_eq[3:6] = -np.cross(r_ext - self.com, F_ext)

        A_ub, b_ub = [], []
        for i in range(C):
            row = np.zeros(n); row[3*i+2] = -1; row[-1] = 1
            A_ub.append(row); b_ub.append(0)          # f_z - t >= 0
            for u in self._dirs():
                row = np.zeros(n)
                row[3*i] = u[0]; row[3*i+1] = u[1]
                row[3*i+2] = -self.mu; row[-1] = self.mu
                A_ub.append(row); b_ub.append(0)      # u.f_xy <= mu(f_z - t)
        c = np.zeros(n); c[-1] = -1                    # maximize t
        bounds = [(None, None)] * (3*C) + [(0, None)]
        res = linprog(c, A_ub=np.array(A_ub), b_ub=np.array(b_ub),
                      A_eq=A_eq, b_eq=b_eq, bounds=bounds, method="highs")
        if not res.success:
            return False, -1.0
        return True, float(-res.fun)

    def support_margin(self) -> float:
        """质心投影到支撑多边形边界的有符号距离（凸多边形内部为正）"""
        pts = self.contacts[:, :2]
        c = self.com[:2]
        # 凸包按角度排序
        ang = np.arctan2(pts[:, 1] - c[1], pts[:, 0] - c[0])
        pts = pts[np.argsort(ang)]
        dmin = np.inf
        for i in range(len(pts)):
            a, b = pts[i], pts[(i + 1) % len(pts)]
            e = b - a; nrm = np.array([-e[1], e[0]])
            nrm /= np.linalg.norm(nrm) + 1e-12
            d = np.dot(c - a, nrm)
            dmin = min(dmin, d if d >= 0 else -abs(d))
        return float(dmin)

    def verify(self, F_ext, r_ext, d_clear=1.0, reach=True,
               grasp_margin=1.0) -> tuple[bool, dict]:
        ok_lp, t = self.static_equilibrium_margin(F_ext, r_ext)
        d_sup = self.support_margin()
        pi = {
            "support": d_sup / self.ell_body,
            "friction": t / (self.mass * self.g),
            "clearance": d_clear / self.ell_body,
            "reach": 1.0 if reach else -1.0,
            "grasp": grasp_margin / (self.mass * self.g * self.ell_body),
        }
        t_bn = min(pi.values())
        return (ok_lp and t_bn >= self.tau_task), {"margins": pi,
                                                    "bottleneck": t_bn,
                                                    "lp_optimal": t}

@dataclass
class SkillContract:
    name: str
    pre: set            # 前置条件（任务状态谓词）
    post: set           # 后置条件
    inv: set            # 安全不变量（含 TPFC 判据族）

    cert: dict = field(default_factory=dict)

@dataclass
class GeneralistSkillCoverageCertificate:
    alpha_task: float = 0.05
    delta_glue: float = 0.01
    L_theta: float = 1.0
    calibration_scores: list = field(default_factory=list)
    q_hat: float = None

    def compose(self, s1: SkillContract, s2: SkillContract,
                glue_ok: bool) -> SkillContract | None:
        if not s1.post.issubset(s2.pre) or not glue_ok:
            return None
        return SkillContract(
            name=f"{s2.name}∘{s1.name}",
            pre=set(s1.pre), post=set(s1.post),
            inv=set(s1.inv) | set(s2.inv),
            success_rate=min(s1.success_rate, s2.success_rate) - self.delta_glue,
            cert={"margin": min(s1.cert.get("margin", 1.0),
                                s2.cert.get("margin", 1.0)) - self.delta_glue},
            depth=max(s1.depth, s2.depth) + 1,
        )

    def calibrate(self, scores, alpha=None):
        import numpy as np
        scores = np.sort(np.asarray(scores))
        n = len(scores)
        a = self.alpha_task if alpha is None else alpha
        # split conformal 的有限样本分位数
        idx = min(n - 1, int(np.ceil((n + 1) * (1 - a))) - 1)
        self.calibration_scores = scores.tolist()
        self.q_hat = float(scores[idx])

    def coverage_after_transport(self, alpha_A, delta_emb, delta_trans,
                                 depth=1) -> float:
        """v27 通用性代价界：α_B <= α_A + L_θ δ_emb + δ_trans + depth·δ_glue"""
        return (alpha_A + self.L_theta * delta_emb + delta_trans
                + depth * self.delta_glue)


# ============================================================
# IP-454 Generalist-Tabletop Unified Certificate (GTUC)
# ============================================================
@dataclass
class GeneralistTabletopUnifiedCertificate:
    src_usc: object                 # v26 七/九证准入门
    etc: EmbodimentTransportCertificate
    tpfc: TabletopPhysicalFeasibilityCertificate
    gscc: GeneralistSkillCoverageCertificate
    tau_task: float = 0.05

    def admits(self, plan, sensor_data) -> tuple[bool, dict]:
        # 1) v26 基础准入（USMC + SMC + RMC + MCC + 预算/记忆/可扩展）
        base_ok = self.src_usc.admits(plan, sensor_data)
        if not base_ok:
            return False, {"reason": "v26_reject"}

        # 2) 迁移证书：方案来自参考具身 A，目标具身 B 须在迁移球内
        pi_A = sensor_data["pi_A"]
        emb_ok, emb_info = self.etc.transferable(pi_A)
        if not emb_ok:
            return False, {"reason": "Fil_emb", **emb_info}

        # 3) 桌面物理证书：静力学/支撑/穿透/可达/抓取
        table_ok, table_info = self.tpfc.verify(
            sensor_data["F_ext"], sensor_data["r_ext"],
            sensor_data.get("d_clear", 1.0),
            sensor_data.get("reach", True),
            sensor_data.get("grasp_margin", 1.0),
        )
        if not table_ok:
            return False, {"reason": "Fil_table", **table_info}

        # 4) 技能组合证书：闭包 + 迁移后的任务覆盖
        alpha_B = self.gscc.coverage_after_transport(
            self.gscc.alpha_task, emb_info["d_theta"],
            emb_info["delta_trans"], sensor_data.get("skill_depth", 1))
        if alpha_B > sensor_data.get("alpha_max", 0.10):
            return False, {"reason": "Fil_skill", "alpha_B": alpha_B}

        # 5) 任务覆盖证书
        if sensor_data.get("task_score", 0.0) > self.gscc.q_hat:
            return False, {"reason": "Fil_task",
                           "score": sensor_data["task_score"],
                           "q_hat": self.gscc.q_hat}

        return True, {"reason": "admitted", "emb": emb_info,
                      "table": table_info, "alpha_B": alpha_B}
```

## 4. 微型数值验证：桌面静力学证书（已实际运行）

为验证 `TPFC.static_equilibrium_margin` 的 sound 性与保守度，构造刚性方块（m = 1 kg，半边长 0.05/0.04/0.03 m，μ = 0.4，g = 9.81），四个桌角点接触，水平推力作用于高度 z_p = 0.06 m，摩擦锥用 L = 16 边多面体内近似，用 `scipy.optimize.linprog(method="highs")` 求 `max t`。

**实验 1：质心居中，扫描推力 F**

| F (N) | LP 最优裕度 t | 通过 (t ≥ 0.02) |
|---:|---:|:---:|
| 0.0 | 2.4525 | ✓ |
| 1.0 | 1.8275 | ✓ |
| 2.0 | 1.2025 | ✓ |
| 3.0 | 0.5775 | ✓ |
| 3.5 | 0.2650 | ✓ |
| 4.0 | 不可行 | ✗ |

二分求得最大可证推力 **3.892 N**，解析阈值 `min(μmg = 3.924 N 滑移, mg·a/z_p = 8.175 N 倾覆) = 3.924 N`。LP 比解析值保守 **0.8%**，方向正确（多面体摩擦锥内近似 + 正裕度要求）。

**实验 2：质心偏移 x = 0.04 m（倾覆主导）**

解析倾覆阈值 `mg(a−c_x)/z_p = 1.635 N`；LP 二分给出 **1.568 N**，保守 **4.1%**。质心扫描（F = 1.0 N）显示 LP 裕度随支撑裕度单调下降：`c_x = 0/0.01/0.02/0.03/0.04 m → t = 1.8275/1.6620/1.1715/0.6810/0.1905`。

**结论**：TPFC 在刚体点接触、已知 μ 的理想桌面场景下与经典滑移/倾覆判据一致，且始终偏保守，符合「sound but not complete」的设计目标；真实桌面需把 μ、接触位置、柔性纳入鲁棒集合（见 R20）。

## 6. 正确性论证（增量）

### 引理 16（无量纲传输的裕度保持）
**陈述**：若 `d_Θ(A,B) ≤ δ_emb`、`δ_trans ≤ δ_budget`，且每个不变量裕度对描述子满足 Lipschitz 常数 `L_π`，则对任意 `π^A`，目标具身满足
`π_k^B ≥ π_k^A − L_π·δ_emb − δ_trans`，且绝对裕度 `m_k^B = π_k^B·u_k^B`。

**证明**：`π_k` 是 θ_E 的连续函数；由 `d_Θ` 定义，分量相对偏差 ≤ e^{δ_emb}−1；在迁移球内 `π_k` 的 Lipschitz 性给出第一项。`δ_trans` 由 1303 的重算残差定义，三角不等式合并两项即得。绝对裕度按 1301 反算，量纲自动一致。∎

> 注意这是**条件性**保证：若真实的 `L_π` 远大于离线拟合值，结论失效。这正是 R19 的核心。

### 引理 17（桌面物理可行证书的 sound 性）
**陈述**：若 `TPFC.verify(...) = True`，则桌面场景存在一组接触力满足力/力矩平衡、法向非负、精确摩擦锥约束，且瓶颈无量纲裕度 `≥ τ_task`；反之 `False` 仅说明多面体内近似下不可行，不排除精确锥可行。

**证明**：LP 可行域的每个约束都是精确物理约束的**内近似**（多面体锥 ⊆ 二阶锥，`f_z − t` 收紧法向）。故 LP 的最优 `t*` 是精确锥 `t*_SOCP` 的下界。`t*_bottleneck ≥ τ_task` 即存在满足平衡与摩擦的力分布并留正裕度，静力学可执行。反向的「不可行」只对多面体锥成立，精确锥可能更宽松，故不 complete。∎

### 引理 18（技能组合闭包）
**陈述**：若 σ₁、σ₂ 各自通过 `TPFC` 与 `GSCC`，且 `Post₁ ⊨ Pre₂` 且胶水证书 `glue_ok`，则组合 σ₂∘σ₁ 通过同一判据，组合裕度为
`m_{12} = min(m₁,m₂) − δ_glue`，覆盖率为 `β_{12} ≥ β₁ + β₂ − 1 − δ_glue`（union bound）。

**证明**：组合的前置/后置按关系复合，安全不变量取交集（交集仍满足各自 TPFC 约束，因约束是逐点合取、对取交封闭）。裕度取 min 再扣胶水残差，保证最坏约束仍有余量。成功率由联合事件下界 `P(A∩B) ≥ P(A)+P(B)−1` 再扣胶水即得。∎

### 引理 19（通用性代价：迁移后的覆盖缺口）
**陈述**：设参考具身 A 上 split conformal 给出 `P(s ≤ q̂) ≥ 1−α_A`；在描述子距离 `δ_emb`、传输残差 `δ_trans`、组合深度 d 下，目标具身 B 的覆盖率满足
`1 − α_B ≥ 1 − α_A − L_θ·δ_emb − δ_trans − d·δ_glue`。

**证明**：非一致性得分 `s = max(0, τ_task − t*_bottleneck)`。由引理 16，迁移使每个 `t*` 最多下降 `L_π δ_emb + δ_trans`，故 `s` 最多上升同一量（`L_θ` 为复合常数）。由 conformal 的边际保证与 union bound 合并组合深度项，即得。∎

### 定理（GTUC v27 的准入完备性与单调退化）
**陈述**：对任意多机/多技能计划 Π，`GTUC.admits(Π) = True` 当且仅当 Π 同时满足：
(1) v26 的九类条件（物理接地、云边一致、少样本覆盖、专利保护、结构/力控/轻量化、语义/重构/协同、成本预算、时间记忆、层级可扩展）；
(2) 迁移：`d_Θ ≤ δ_emb` 且 `δ_trans ≤ δ_budget`；
(3) 桌面：`t*_bottleneck ≥ τ_task`（含支撑/摩擦/穿透/可达/抓取）；
(4) 技能：组合闭包与迁移后覆盖 `α_B ≤ α_max`；
(5) 任务：conformal 任务得分 `s ≤ q̂`。
且 `Exec_v27 ⊆ Exec_v26 ⊆ … ⊆ Exec_v18`。

**证明**：充分性由 `admits` 的五段连言直接得到，分别对应引理 16–19。必要性：任一条不满足，`admits` 在对应阶段返回 False，故不属于 `Exec_v27`。单调性：`Exec_v27` 由 `Exec_v26` 与四个过滤器的交定义，集合交单调收缩；退化路径（迁移失配 → 回退 v26 的固定具身；桌面违约 → 冻结接触/降低速度；组合断裂 → 禁止该技能组合；任务漂移 → 保守重置 conformal）均只删除计划、不新增，故链保持。∎
