灵感驱动研究循环·新灵感三元组第 2 轮；本轮灵感：「数据采集」×「在线学习」

> **基线**：第 2 轮产出 MetricVoiceGauge-NCD-HUTDH-v22（HPC-E = HPC+ ∪ EVC ∪ RGC；其上承 v21 语义-规范层 SDC/CAC/DCL/GIC 与 IP-431–435，再上承 v20 联邦感知证书与 v19/v17 各模块）。
> 本轮纪律：**数据采集是"证据的生产"，在线学习是"证据的维护"，而证书是"证据的所有权"**。不推倒 v22：HPC-E / EVC / PGEV / ACSC / DCSC / CFC++ 全部保留。本轮只做一件事：**给 v22 的每一张统计证书补上"它从哪些数据来（provenance）、现在是否还新鲜（freshness）、模型改了还算不算数（sovereignty）"的生命周期证明**——把"有证书"升级为"证书的来源、时效与主权可审计"，并顺手封堵 v22 的最大风险（合规的缺席幻觉）。

## 0. 直觉与动机

**灵感 1（数据采集 → 缺席证书的保险不是"更多数据"，而是"可审计的采集"）**
直觉：v22 的 AbsCert 把全部可靠性押在召回率下界 κ_c 上，而 κ_c 是一个**关于采样分布的陈述**：如果采样偏离了真实人流分布，κ_c 就在忠实地描述一个**错误的人群**。数据采集补上的不是"再来一百万张图"，而是三件统计上更根本的东西：**分层（stratum）**——按人体形态把"人"拆成儿童/轮椅/蹲姿/强逆光/重遮挡/非常规衣着等层，每层单独给有限样本下界；**重要度加权与有效样本量**——采集分布 Q 与部署分布 P 不一致时用 w=P/Q 校正，用 n_eff 而不是样本总数说话；以及最关键的**未知层质量 ε_unk**——分层框架 S 之外的人群，证书必须**显式承认自己不知道**，而不是把"没采到"写成"不存在"。核心创新：**采集证明与覆盖证书 (Data Provenance & Coverage Certificate, DPCC) + 主动证据采集 (Active Evidence Acquisition, AEA)**。关键反直觉点：**采集越多，证书未必越诚实**——有偏采集会被统计公式"忠实放大"为更紧的伪置信；真正的安全来自"拒绝签发"的能力（某层样本不足或 ε_unk 不可估时，AbsCert 不签发），而不是来自数据量。附带一层伦理：采集对象是儿童、行动不便者等弱势群体，**代表性不足既是统计缺陷也是合规缺陷**，故 DPCC 同时是公平性审计证书（与 v21 DCL 的 P 规则、E794 隐私最小化、φ(x) 特征外传而非原始像素对接）。

**灵感 2（在线学习 → 证书的敌人不是"模型变差"，而是"证书变旧"）**
直觉：conformal 覆盖保证的前提是**校准集与测试集可交换、模型版本在签发期内不变**。在线学习每一秒都在破坏这个前提：校准分位数过期（staleness）、部署分布漂移（drift）、以及最阴险的**自证回路**——模型按自己的检测结果筛数据、再用这些数据继续训练，于是"被模型看见的人"被反复采样，"模型看不见的人"被系统性遗漏，κ_c 看起来节节攀升而真实召回原地不动。故在线学习不能直接改写证书：核心创新：**在线 conformal 维护 (Online Conformal Maintenance, OCM) + 证书主权与学习防火墙 (Certificate Sovereignty & Learning Firewall, CSLF)**。OCM 用 ACI（自适应 conformal 推断）与 e-value 鞅做 O(1) 的漂移检测与长期覆盖维护；CSLF 规定**学习器只许"提议"，签发者永远在学习环之外**，模型版本切换必须过影子重认证与"保守下界不回归"门槛，训练标签必须排除模型自标注（自标注只能进提议器，不能进校准集）。关键反直觉点：**允许激进的在线学习反而可能更安全——前提是签发权与学习权严格分离**：学习越快，漂移越早被 e-value 捕获，旧证书越早被撤销，失效方向永远向保守。

**二者的张力与统一：证据的生命周期（Evidence Lifecycle）**
采集与学习合起来构成一个闭环，闭环的每一段都可能污染证书：采集偏置污染 κ_c，自标注污染召回估计，在线更新污染 conformal 覆盖，版本切换污染可追溯性。统一为 **v22 之上的"证据生命周期"层**：`Produce (DPCC/AEA) → Maintain (OCM) → Own (CSLF) → Gate (HPC-EL)`。共享状态扩展为 **ζ_el = ζ_pgev ∪ (κ_c^strat, ε_unk, n_eff, ProvRoot, α_t, drift_e, m_t, cert_age)**。统一准入门：**HPC-EL = (HPC-E, DPCC-valid, OCM-coverage-in-force, CSLF-approved)**——几何∧规范∧负信息∧能量（v22）之外，再要求"统计证据有来源、未过期、模型已认证"。任一缺失退回 v22 的保守收缩。核心不变量：`Exec_v23 = Exec_v22 ∩ Gate_el ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`，因为 DPCC/OCM/CSLF 都只能**收紧**（不签发、撤销、拒绝版本），没有任何一路能凭空扩大执行域。

**一个由二者耦合涌现的第三个直觉：采集必须"先被动后主动"，且不能"为讨好模型而采集"。**
主动采集（重定向相机、多视角、受控靠近）能补足低覆盖层，但它本身消耗能量、引入延迟、甚至需要移动——因此 AEA 的每个动作都必须先通过 HPC-E，并在已认证安全态中执行；更隐蔽的是**采集策略的确认偏误**：若采集策略由模型的不确定性驱动且只采"模型已能看见的人附近"，则采集会放大已有偏置。故采集策略必须带**随机化/分层配额**并冻结其审计哈希，否则 DPCC 的 provenance 本身不可信。"采集谁"和"采集多少"一样是安全问题。

## 2. 设计原则（在 P34–P42 基础上新增 P43–P46）

**P43 证据生产可审计律（Evidence Production Auditability）**
任何进入证书签发的统计量必须携带 provenance：采样框、分层定义 S、每层样本数 n_s、权重与 n_eff、采样策略哈希、时间窗与标签来源。缺少 provenance 或 provenance 哈希不在审计链上的统计量**不得签发**。证书必须**显式声明其覆盖面**：AbsCert 只能声明"对 S-典型人体、在 ε_unk ≤ ε_max 条件下无人"，绝不声明无条件无人。

**P44 采集受证书约束律（Acquisition-under-Certificate）**
AEA 分三级：L0 被动多视角（不动、不耗能）→ L1 传感器重定向（微动、能量可忽略）→ L2 受控靠近（移动）。任一级动作 π_acq 必须先满足 HPC-E，且 `E_acq` 计入储备不变量；L2 仅允许在已认证安全态执行。采集只能**收紧**不确定性、不得扩大执行域：`Obs_t` 只增不减，`Cov_t` 只减不增（在采集完成前）。采集策略须含分层随机配额并冻结审计哈希，禁止"只采模型附近"的确认偏误。

**P45 证书主权律 / 学习防火墙（Certificate Sovereignty）**
在线学习器只可更新"提议器"，**永不持有签发权**；校准集对学习器写保护，模型自标注只能进提议器、不能进校准集（防自证回路）。模型版本切换 m→m′ 必须通过影子重认证：对每层 s 要求 `LCB_recall(m′,s) ≥ LCB_recall(m,s) − δ_regress` 且影子期 OCM 覆盖有效，否则拒绝并回滚。版本清单与 DPCC 的 ProvRoot 一起挂到 v21 的 merkle 审计链。

**P46 漂移失效保守律（Drift Fail-Conservative）**
漂移检测超界或 conformal 覆盖失效 ⇒ 当前证书立即降级为"未认证"：AbsCert 撤销、类先验收紧关闭、模型版本冻结在最后一个已认证版本。证书新鲜度 `age > τ_fresh` 一律视为失效，**不得续用**。失效方向恒为保守：任何 OCM/CSLF 异常都只会让 `Exec_v23` 收缩，绝不扩张。

## 3. 与基线的接口（如何退化）

- DPCC 失效（某层 n_s < n_min 或 ε_unk 不可估）⇒ 该层对应的 AbsCert 不签发 ⇒ 退回"该区域假设有人"的 v22 保守模式；
- AEA 失效（采集超预算/采集动作不安全）⇒ 放弃采集、按当前证书最保守处置 ⇒ 只损失活性，不损失安全；
- OCM 失效（漂移检测器报错/覆盖失效）⇒ 冻结校准、撤销受影响证书 ⇒ 比 v22 更保守；
- CSLF 失效（影子重认证不通过）⇒ 保持旧模型版本、不回滚到未认证新版本 ⇒ 等价或更保守于 v22；
- 采集/学习/证书三者全失效 ⇒ 冻结为"静态已认证模型 + v22 证书" ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`；
- **安全继承**：DPCC 只能收紧 κ_c（拒绝签发）、AEA 只能在安全态采集、OCM 只能撤销/冻结、CSLF 只能拒绝版本；四者均无"扩张"通路，故单调性 `Exec_v23 ⊆ Exec_v22` 由构造保证。所有状态迁移携带时间戳，接入 v17 APS 新鲜度阶梯与 v21 merkle 审计链，控制路径仅 O(1) 查询。

## 4. 预期贡献（在 1–9 基础上新增 10–13）

10. **可审计的采集证书**：首次把"召回率下界"从一条经验假设升级为带分层、有效样本量、未知层质量与 provenance 哈希的 DPCC；给出 AbsCert 的"有条件签发 + 拒绝签发"语义，正面回应 v22 的缺席幻觉；
11. **采集安全学**：把主动采集本身当作受证书约束的动作，给出 L0/L1/L2 三级准入与"采集不得扩大执行域"的单调性，并指出采集策略的确认偏误是独立的污染源；
12. **证据维护**：ACI + e-value 鞅的 O(1) 在线 conformal 维护，给出任意漂移下的长期覆盖与 anytime-valid 漂移告警；以"影子重认证 + 逐层 LCB 不回归"定义模型版本的保守支配；
13. **证书主权**：把"学习器只提议、签发者不学习"形式化为 CSLF，斩断自标注/自证回路，形成"采集—维护—所有权—准入"的完整证据生命周期 `HPC-EL`，并保持 `Exec_v23 ⊆ Exec_v22` 闭环。

## 5. 本轮最大风险

**一句话**：最大的风险不是数据太少，而是"认证的采集"退化为"采集的认证"——分层框架 S 之外的未知人体形态其质量 ε_unk 不可估，而在线学习在漂移中让过期证书继续被当作新鲜证书签发（学习速度掩盖 staleness），最终得到一份**统计上无可挑剔、语义上覆盖不到受害者、时间上已经过期**的"合规幻觉 2.0"。

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
# IP-436 Data Provenance & Coverage Certificate
from math import log, sqrt

class DPCC:
    def __init__(self, strata, delta=0.01, n_min=200, eps_max=0.02):
        self.S = strata            # 分层定义（不可被学习器在线修改）
        self.delta = delta
        self.n_min = n_min
        self.eps_max = eps_max

    def certify(self, log):
        """log: [{x, y, s, w, t, source}]；返回证书或 REFUSE。"""
        ProvRoot = merkle_root(canonicalize(log))
        per = {}
        delta_s = self.delta / max(len(self.S), 1)   # Bonferroni
        for s in self.S:
            rows = [r for r in log if r.s == s]
            n_s = len(rows)
            if n_s < self.n_min:
                return Refuse(reason=f"UNDER_SAMPLED:{s}", ProvRoot=ProvRoot)
            k_s = sum(r.y for r in rows)            # 1 = 检出
            w = [r.w for r in rows]
            n_eff = (sum(w) ** 2) / max(sum(x * x for x in w), 1e-12)
            if max(w) > self.w_max_guard(n_s):
                # 加权过猛：下界不可信 → 拒绝而非硬算
                return Refuse(reason=f"WEIGHT_UNSTABLE:{s}", ProvRoot=ProvRoot)
            # 等概率分层：Clopper-Pearson；加权：保守经验 Bernstein（n_eff）
            kappa_s = clopper_pearson_lower(k_s, n_s, delta_s, n_eff=n_eff)
            per[s] = kappa_s
        eps_unk = estimate_unknown_mass(log, self.S)   # None 表示不可估
        if eps_unk is None or eps_unk > self.eps_max:
            # 语义空洞：形式上可算，但覆盖不到 S 外人群 → 拒签 AbsCert
            return Refuse(reason="UNKNOWN_STRATUM_UNBOUNDED",
                          ProvRoot=ProvRoot, kappa=per, eps_unk=eps_unk)
        return DPCCert(kappa_c=min(per.values()), per=per, eps_unk=eps_unk,
                       ProvRoot=ProvRoot, n_eff=min(n_eff_by_stratum(log, self.S)),
                       S_version=hash(self.S))

    def w_max_guard(self, n_s):
        # 权重上界保证加权下界可控：w_max = O(n_s) 的经验阈值，可标定
        return max(4.0, sqrt(n_s))

# IP-437 Active Evidence Acquisition（三级准入）
class ActiveEvidenceAcquisition:
    L_ORDER = ["L0", "L1", "L2"]

    def __init__(self, hpce, evc, budget=0.0):
        self.hpce = hpce
        self.evc = evc
        self.B_acq = budget

    def propose(self, scene, dpcc_gap):
        # 只对 DPCC 覆盖不足且与当前场景先验相关的层提出采集
        for level in self.L_ORDER:
            if dpcc_gap.needs(level):
                yield AcquisitionAction(level=level, target=dpcc_gap.strata)

    def admit(self, action, plan, state):
        # 采集先过 HPC-E：几何/规范/负信息/能量
        if not self.hpce.admits(plan, **state):
            return Reject("HPC_E_FAIL")
        # L2 需要移动：必须在已认证安全态
        if action.level == "L2" and not self.evc.in_certified_safe(state):
            return Reject("L2_NOT_IN_SAFE_STATE")
        if self.evc.E_acq(action) > self.B_acq:
            return Reject("ACQ_BUDGET_EXCEEDED")
        # 采集不得扩大执行域（同步收紧 Cov/Obs）
        assert action.monotone  # Obs 只增，Cov 只减直至采集完成
        return Admit(action)

    def run(self, scene, dpcc_gap, state):
        for a in self.propose(scene, dpcc_gap):
            if isinstance(self.admit(a, state.plan, state), Admit):
                return a.execute()          # 返回新样本或被审计确认的"无法安全采集"
        return NoAcquisition()              # 放弃 → 走保守处置

# IP-438 Online Conformal Maintenance（ACI + e-value 鞅）
class OnlineConformalMaintenance:
    def __init__(self, alpha=0.05, gamma=0.005, lo=0.001, hi=0.5):
        self.alpha, self.gamma = alpha, gamma
        self.lo, self.hi = lo, hi
        self.alpha_t = alpha
        self.logM = 0.0                      # e-value 鞅的对数
        self.lam = 0.1

    def update(self, err_t):
        # ACI：覆盖错误 → 收紧 α；否则放宽（长期平均逼近 α*）
        self.alpha_t = min(self.hi, max(
            self.lo, self.alpha_t + self.gamma * (self.alpha - int(err_t))))
        # e-value 鞅：H0 为"覆盖仍有效"，漂移时 E[err]>α 使 logM 上升
        self.logM += log(1.0 + self.lam * (int(err_t) - self.alpha))
        if self.logM >= log(1.0 / 0.01):     # Ville 界：P(误报) ≤ δ=0.01
            return DriftAlarm(alpha_t=self.alpha_t, logM=self.logM)
        return Normal(alpha_t=self.alpha_t)

    def forecast_set(self, score, calib_quantile):
        # 用当前 α_t 取分位数；O(1)（滑动/指数加权分位数）
        return ScoreSet(score, self.alpha_t, calib_quantile)

# IP-439 Certificate Sovereignty & Learning Firewall
class LearningFirewall:
    def __init__(self, dpcc, ocm, delta_regress=0.01, tau_shadow=300):
        self.dpcc, self.ocm = dpcc, ocm
        self.delta_regress = delta_regress
        self.tau_shadow = tau_shadow

    def may_train(self, sample_batch):
        # 自标注 / 未审计标签永不得进入校准集
        return all(s.source in ("human_audited", "dpcc_certified")
                   for s in sample_batch)

    def shadow_recertify(self, m_old, m_new, shadow_log):
        for s in self.dpcc.S:
            lcb_old = self.dpcc.per[s]
            lcb_new = recall_lcb(m_new, shadow_log, s, delta=self.dpcc.delta)
            if lcb_new < lcb_old - self.delta_regress:
                return RejectVersion(reason=f"LCB_REGRESS:{s}")
        if not self.ocm.coverage_in_force(shadow_log):
            return RejectVersion(reason="OCM_NOT_IN_FORCE")
        return AcceptVersion(m_new, merkle=merkle_root(canonicalize(shadow_log)))

# IP-440 HPC-EL 统一准入门
@dataclass
class HPCEL:
    hpce: HPCE
    dpcc: DPCC
    ocm: OnlineConformalMaintenance
    cslf: LearningFirewall

    def admits(self, plan, state):
        base = self.hpce.admits(plan, **state)            # v22: 几何∧规范∧负信息∧能量
        d = self.dpcc.certify(state.log)                  # 采集证书（或 REFUSE）
        dpcc_ok = not isinstance(d, Refuse)
        ocm_ok = self.ocm.coverage_in_force(state.recent)
        cslf_ok = state.model_version in state.accepted_versions
        return base and dpcc_ok and ocm_ok and cslf_ok

# 主控：每轮只做"收紧"操作，无任何扩张分支
def v23_step(state):

        return withdraw_certificates(state)               # P46 失效保守
    r = state.ocm.update(state.err_t)
```

## 2. 推导与引理（证明草图）

**引理 L23.1（分层召回下界的有效性）**
设对每层 s 以 Bonferroni 水平 δ/K 计算 Clopper-Pearson 下界 κ_s。则
`P(∀s: recall_s ≥ κ_s) ≥ 1 − Σ_s (δ/K) = 1 − δ`，
故 `κ_c^strat = min_s κ_s` 以 ≥1−δ 概率是"对 S 内每一层都成立"的联合下界。**该下界只对 S 有效**：S 之外的群体不参与样本框，其召回不受任何约束。

**引理 L23.2（加权采集下的保守性）**
当 Q ≠ P 且使用 w_i=P(s_i)/Q(s_i) 时，加权召回估计的方差 ~ O(1/n_eff)，其中 `n_eff=(Σw)²/Σw² ≤ n`。在权重上界 w_max 受控（`w_max ≤ sqrt(n_s)` 的 guard 通过）时，Hoeffding/Bernstein 型下界用 n_eff 替换 n 得保守 LCB。若权重失控（单点主导），n_eff→1，下界→0：这正是"有偏采集被统计公式诚实放大为不自信"的机制；当 n_eff 小到不可签发时，DPCC 返回 REFUSE。

**引理 L23.3（未知层质量与 AbsCert 的语义）**
定义 `ε_unk = 1 − Σ_{s∈S} P(s)`（P 可估时）。AbsCert 的命题严格为：
`P(覆盖区内无 S-人体) ≥ 1 − δ`，其无条件残余风险上界为 `ε_unk + δ`。
若 `ε_unk` 不可估或 > ε_max，则 AbsCert **不可签发**（返回 ⊥），而不是默认"无人"。这直接消除了 v22"形式成立而事实为假"的一类失败，但把风险转移为"未知的未知层"（见 §5）。

**定理 L23.4（ACI 的长期覆盖）**
在 α_t 被裁剪到 [α_min, α_max]、步长 γ>0 下，ACI 更新 `α_{t+1}=α_t+γ(α*−err_t)` 满足
`(1/T)Σ_{t=1}^T err_t ≤ α* + (α_0 − α_T)/(γT) ≤ α* + α_max/(γT)`。
故即使分布任意漂移（只要 err_t 可观测），长期平均失效率被 α* 加 O(1/(γT)) 控制；漂移只影响瞬态，不影响长期有效性。

**引理 L23.5（e-value 鞅的 anytime-valid 告警）**
令 `M_t = Π_{i≤t}(1+λ_i(err_i−α*))`。若覆盖有效（E[err_i|past] ≤ α*），则 M 为上鞅，Ville 不等式给出 `P(∃t: M_t ≥ 1/δ) ≤ δ`。漂移使 E[err]>α* 时 logM 线性上升，故可在不预设时间段的前提下做 O(1) 告警，误报率 ≤ δ（anytime-valid），无需多次校正。

**引理 L23.6（执行域单调性）**
HPC-EL 是 v22 的 HPC-E 与三个"只收紧"谓词的合取：DPCC 只能签发/拒签（拒签 ⇒ 更保守），OCM 只能撤销/冻结，CSLF 只能拒绝版本。故
`Exec_v23 = Exec_v22 ∩ DPCC-valid ∩ OCM-in-force ∩ CSLF-approved ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
失败方向由 P46 规定为保守，故不存在"学习/采集反向扩大执行域"的路径。

**引理 L23.7（最坏失效窗口）**
证书从"事实失效"到"被撤销"的时间不超过 `τ_fresh + τ_detect + τ_recert`，其中 τ_detect 为漂移检测延迟（e-value 告警期望时长），τ_recert 为影子重认证时长。v22 的 margin_col 必须覆盖该窗口内的最坏位移，即 `margin_col_fed ⊇ v_peak · (τ_fresh + τ_detect + τ_recert)`；否则需缩短 τ_fresh 或提高采集/检测频率。

## 3. 实验设计

### 3.1 数据与分层
- **分层人体检测基准**：K=6 层（儿童、轮椅、蹲姿、强逆光、重遮挡、非常规衣着）；每层 ≥200 张校准样本 + 独立测试集；合成渲染（可控光照/遮挡）与真实仓储日志混合。
- **漂移流**：按时间顺序模拟新用户、新衣着、季节光照漂移；注入"自标注污染"（用模型输出伪标签训练）作为负对照。
- **采集模拟**：被动多视角、重定向、受控靠近三级动作，带能耗与延迟模型。

### 3.2 基线
1. v22（固定经验 κ_c）；
2. v23-DPCC（仅分层采集证书）；
3. v23-DPCC+AEA（加主动采集）；
4. v23-DPCC+OCM（加在线 conformal 维护）；
5. v23 完整（DPCC+AEA+OCM+CSLF）。

### 3.3 指标
- **覆盖有效性**：各层经验召回 vs 名义下界（应 ≥1−δ 的比例）；
- **FAHR（假缺席幻觉率）**：AbsCert 签发且 Cov 内真有人 / 全部 AbsCert 签发；核心安全指标；
- **活性**：可赎回自由空间比例、任务完成时间（采集/学习不应造成坍塌）；
- **漂移鲁棒性**：检测延迟、ARL（假警间隔）、漂移后覆盖率；
- **治理**：过期证书被误用次数、版本回滚次数、自标注污染下的召回虚高幅度；
- **采集安全**：采集动作违反 HPC-E 的次数（必须为 0）、采集能耗占比。

### 3.4 消融
- 去掉 ε_unk 条款 → 预期 FAHR 上升（验证"未知层"是主要风险源）；
- 去掉 CSLF 自标注禁令 → 预期召回被虚高、漂移后 FAHR 反弹；
- 去掉 OCM → 预期漂移后覆盖失效、证书过期仍被使用；
- 变化 γ / τ_fresh / B_acq → 覆盖-活性 Pareto 前沿。

### 3.5 模拟预测（非实测，仅用于假设检验方向）
| 配置 | 名义覆盖 | FAHR（预期） | 自由空间赎回（预期） | 漂移后覆盖（预期） |
|---|---|---|---|---|
| v22 固定 κ_c | 名义 99% | 高（未知层不受约束） | 中 | 失效 |
| v23-DPCC | 分层 99% | 中（S 内下降，S 外仍盲） | 中低（拒签更频繁） | 失效 |
| v23-DPCC+OCM | 分层 99% | 中 | 中低 | 恢复（ACI） |
| v23 完整 | 分层 99% | 低 | 中（AEA 补足低覆盖层） | 恢复且不误用过期证书 |

> 说明：上表为设计阶段的**预期趋势**，用于预注册假设；真实结论以实验为准。核心可证伪假设：H1 "ε_unk 条款显著降低 S 外 FAHR"；H2 "OCM 在漂移后 1/(γα*) 步内恢复名义覆盖"；H3 "CSLF 使自标注污染下的召回虚高 ≤ δ_regress"。

## 4. 与 v22/v21 的接口

- **状态**：`ζ_el` 继承 `ζ_pgev`，新增的 κ_c^strat/ε_unk/n_eff/ProvRoot/α_t/drift_e/m_t/cert_age 均带时间戳，接入 v17 APS 新鲜度阶梯，控制路径仅 O(1) 查询；
- **审计**：ProvRoot 与模型版本清单挂到 v21 DCL 规则库的 merkle 审计链，形成"规则版本—数据来源—模型版本"三链合一；
- **隐私与公平**：原始像素不出机器人（沿用 DCSC 的 φ(x) 特征外传），DPCC 只记录分层统计与哈希；代表性不足作为合规缺陷上报 DCL；
- **退化链**：DPCC/OCM/CSLF 任一路失效 → 撤销对应证书 → 退回 v22 保守 → 再退 v21/v20/v19/v18，全程 `Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

## 5. 本轮结论

把 v22 的"统计证书"升级为"有来源、有时效、有主权"的证据生命周期证书：DPCC 让召回下界可审计且可拒签，AEA 让采集受证书约束，OCM 让在线学习在漂移下仍保守可用，CSLF 斩断自标注/自证回路。最大风险见想法区 §5：未知层质量不可估 + 过期证书被学习速度掩盖，可能产生"合规幻觉 2.0"。
