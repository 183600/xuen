# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「多机协同」×「数据质量」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 493–539；引理 69–86；实验 E531–E570）。
> 本轮纪律：**协同成约 + 质量会计 + 保守性对偶**。两个灵感分别治理 v9 的两笔债：**单机债**（v9 的所有证书、契约、预算都隐含“世界只有我一台”；多机共享空间时，最大误差源不是我自己的模型，而是我对同伴的模型）与**输入债**（v9 的 β、SpatialCert、DA 阈值默认数据“足够好”，却从未把数据质量本身变成可审计、可进证书的量）。安全论证必须满足**乐观中立元律**：v9 是乐观基线，新模块只是“怀疑者”；关掉怀疑者必须严格回到 v9 的乐观假设，而不是产生新行为。若部署假设本身无法认证（质量下界 q_floor 不可证），系统必须拒绝多机任务、退回单机 v9，而不是假装乐观。

## 0. 直觉与动机

**灵感 1（多机协同 → 从“我对世界的模型”到“我对同伴的模型”）**
直觉：单机时，安全证书的误差来自传感器与模型；多机时，新增的最大误差来自“我以为同伴要做什么”。v9 的 AC 把障碍集 O 当作静态集合，这在双机窄廊相遇时会直接失效：两台机器人各自生成“无冲突”的块，却在共享空间里互相成为动态障碍。最自然的想法是让它们交换意图；但交换意图引入了新的信任问题——消息可能过期、丢失、被伪造，或者同伴的标定已经漂移。核心创新：**机群成约协调器（FleetCommitCoordinator, FCC）**：每台机器人在 5Hz 块边界发布“时空承诺集” S_i（包含所有中止点对应的执行前缀与刹车轨迹）；协调不是“相信同伴的意图”，而是“用同伴意图 + 质量 + 年龄构造一个保守可达足迹”，承诺集与该足迹不相交才允许成约。关键设计：**安全由本地 50Hz 防御守卫兜底，协调只买通行率（liveness），不买安全**。

**灵感 2（数据质量 → 把质量缺陷编译成不确定度预算）**
直觉：数据质量通常被当作离线数据集指标（标注准确率、缺失率），但在实时安全回路里，它必须变成“这一帧数据让我多不确定”的在线量。一帧数据可以时间戳很新但标定漂移，可以字段完整但跨源矛盾，可以来源已认证但来自一台正在失效的机器人。核心创新：**数据质量护照门控（QualityPassportGate, QPG）**：每个数据项携带五维护照（时效、完整、标定、一致、来源）与一个**保守扰动界 δ(x)**；护照不是“打分”，而是“会计”——δ 直接进入前向模型误差上界 β_eff = β_0 + L·δ，进而进入 AC 的块证书。质量越差，证书余量越大、块越短、甚至 K=1；质量不是靠“相信”来使用，而是靠“多留余量”来使用。

**灵感 3（两者合流 → 质量担保的通行权）**
直觉：协同与质量是一对对偶。协同把“我对同伴的无知”变成足迹；质量决定这个足迹能收紧多少。高质量的同伴意图可以“担保”一个更小的预约，换取通行权；低质量或过期的意图必须“抵押”更大的保守足迹，换取安全。反过来，多机的独立观测又能通过佐证提升共享地图的质量——但前提是来源真正独立，否则只是把同一个错误复制 N 遍。核心创新：**质量耦合预约（QualityCoupledReservation, QCR）**：把“质量→足迹”与“佐证→质量”写成同一套单调算子，证明 **质量只买通行率、不买安全**：任何 q 的估计只要满足单向性（q̂ ≤ q*），安全就由保守足迹与本地守卫保证；质量估计失效时，系统退回预标定的质量下界 q_floor，而不是退回盲目乐观。

## 1. 研究问题（轮次升级版）

- **Q1（异步协同的组合安全）**：在无全局时钟、消息可丢失/延迟、各机意图视图不对称的条件下，如何定义可本地检查的承诺集与保守足迹，使“两两不相交”的局部检查蕴含机群无碰撞？是否需要共识？能否做到“不需要共识也安全”？
- **Q2（质量到不确定度的编译）**：如何把五维数据质量缺陷编译成可证明的输入扰动界 δ，使 β_eff = β_0 + L·δ 仍是前向模型误差的保守上界？质量审计器自身的单向性（只许低估质量）如何验证，如何避免无限回退？
- **Q3（质量担保的通行率）**：质量 q 与足迹半径的单调映射如何设计，使高质量确实换来更高通行率，而低质量只降低 liveness、不降低安全？在窄廊、交叉口、死胡同中，优先级 + 让行闭包能否避免循环等待与饥饿？
- **Q4（质量门控的学习安全）**：在低质量数据上做 DA/ID 的在线更新，如何用质量分层与准入门槛避免“在噪声上蒸馏出错误的创新点”？当 QPG 失效时，学习路径如何严格退化为 v9 的更新规则？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 本地防御主导律（Local-Defense Primacy, LDP）**
机群安全的第一责任人是每台机器人自己的 50Hz 守卫：它必须对每个同伴使用包含其真实可达位置的保守足迹，并维持 `dist(x_i, R̄_j) ≥ d_safe + d_brake(v_i)`。协同协议只允许“缩小保守足迹以换取通行权”，永不允许“跳过本地守卫”。协议失败、消息丢失、甚至同伴谎报，都只能降低通行率，不能直接造成碰撞。

**P14 质量保守编译律（Quality-Conservative Compilation, QCC）**
数据质量缺陷必须编译为不确定度的**膨胀**，绝不能编译为检查的**放宽**。质量未知 = 质量最差；审计器只许低估质量（δ̂ ≥ δ*）；质量护照失效时注入预标定下界 q_floor，而不是注入 q=1 的乐观值。任何“因为数据看起来不错所以放宽证书”的路径都被禁止。

**P15 乐观中立元律（Optimism Neutral Element, ONE）**
v9 是乐观基线（无同伴、数据完美）。FCC/QPG/QCR 是怀疑者；它们的失效必须注入“乐观中立元”并逐位退回 v9：无同伴时冲突图为空、q_floor=1 时 β_eff=β_0、无膨胀时预约等于预测集。但“乐观”只在 v9 已验证的部署假设下成立；若 q_floor 无法认证，系统不得声称 v9 等价，必须升级到保守协同或拒绝多机任务。

## 3. 与基线的接口（如何退化）

- **F0 全协同**：FCC + QPG + QCR 全开，N≥2；高质量意图使用小足迹，低质量/过期意图自动膨胀。
- **F1 保守协同**：FCC 消息超时或 QPG 控制路径失效 ⇒ 所有同伴按最保守可达足迹处理，机器人让行/停驻；安全仍由本地守卫保证，通行率下降。
- **F2 单机 v9**：QCR 不可用、q_floor 不可证、或连续 H_fleet 个 epoch 无法获得任何同伴的合格数据 ⇒ 拒绝共享空间任务，退回 v9 单机；此时 N=1、q=1、冲突图为空，与 v9 逐位一致。
- **v9 内层退化**：AC 失效 ⇒ K_eff←1；MW 失效 ⇒ v8 手写网关；ID 失效 ⇒ 全模块 active；DA/SPR/Cal 失效 ⇒ 各自中立元（Δ_dom≡0 / risk_SLAM≡0 / weight≡1）；全失效 ⇒ v8→v7→v6。

## 4. 预期贡献

1. **无共识的异步协同安全**：承诺集 + 保守可达足迹 + 本地守卫，证明局部两两检查蕴含机群安全，且不要求全局时钟或共识；给出“质量只买 liveness”的分离定理。
2. **数据质量的证书化**：五维护照 → 保守扰动界 δ → β_eff 的编译链，使数据质量第一次成为块证书的正式输入，而不是监控面板上的事后指标。
3. **质量担保的通行权**：q→足迹的单调映射与质量耦合预约，把“信任”变成可定价、可退化、可审计的资源；附带多机佐证对共享地图质量的正向作用及其共同模式边界。
4. **乐观中立元退化链**：F0→F1→F2→v9→v8→v7→v6 的严格退化，保证任何新模块失效都不产生行为漂移；E571–E590 覆盖异步协同、质量编译、佐证、退化与对抗。

## 5. 本轮最大风险

**一句话**：质量护照的单向性无法由护照自身证明——审计器与被审计数据同源，一旦共同模式误差或同伴谎报使 q̂ 高于真值，保守足迹会缩到预测集，而“乐观中立元”又让审计器失效时悄悄退回 v9 的信任假设，系统将在最需要怀疑的时刻表现得最自信。

## 1. 退化链声明（F0→F1→F2→v9 五级）

- **F0 全协同**：FCC + QPG + QCR 全开，N≥2；同伴意图质量高且新鲜 ⇒ 使用小足迹 S_j^pred ⊕ B(ε_track)；质量低/过期 ⇒ 自动膨胀为 R̄_j。
- **F1 保守协同**：FCC 通信超时、QPG 控制路径失效、或同伴质量低于 τ_peer ⇒ 所有同伴按最保守可达足迹处理，机器人让行/停驻；安全仍由本地守卫保证，通行率下降。
- **F2 单机 v9**：QCR 不可用、q_floor 不可证、或连续 H_fleet 个 epoch 无法获得任何同伴的合格数据 ⇒ 拒绝共享空间任务，退回 v9 单机；此时 N=1、q=1、冲突图为空，与 v9 逐位一致。
- **v9 内层**：AC 证书失效/信任域破坏 ⇒ K_eff←1；MW 失效 ⇒ v8 手写网关；ID 失效 ⇒ 全模块 active；DA/SPR/Cal 失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / weight≡1），等价 v7；全失效 ⇒ v7→v6。

**新增定义 540（机群、协调图与优先级）** 机群 R={1,…,N}，协调图 G_c=(R,E_c)，边 (i,j)∈E_c 当且仅当两机的承诺集在时空上可能相交。优先级 π_i=(κ_i,w_i(t),D_i^task,H(i)) 按字典序比较：安全关键度、已等待时长、任务截止、确定性哈希。π 是全序，所有机器人在同一意图集合上可独立算出相同顺序，用于把“同时成约”串行化；w_i(t) 是老化项，防止低优先级任务永久饥饿。

**新增定义 541（时空承诺集 Committed Set）** 给定块 ζ_i=(a^{1:K},Ĉ_i,P_i)，承诺集为
```
S_i(ζ_i,P_i) = ⋃_{p∈P_i} ( Traj_i^{0:p} ∪ Brake_i(p) ) ⊕ B(ε_i^track)
```
即“在任意中止点 p 停下”的所有可能轨迹的并，再膨胀跟踪误差球 B(ε_track)。S_i 是机器人对机群的**行为承诺**：无论它在块内何处中止，实际位置都不会离开 S_i。P_i 为空即拒绝该候选（v9 的“无点可退”语义保留）。

**新增定义 542（机群契约 Fleet Contract）** 对每条协调边 (i,j)：
```
κ_ij = (D_ij^comm, H_ij, v_ij^⊥, π_ij, φ_ij^conf)
```
其中 v_ij^⊥ = `YIELD`（让行/安全停驻中立元）；φ_ij^conf 为冲突谓词（两机承诺/足迹相交）。若在 D_ij^comm 内未收到对端意图，或意图年龄 Δ>H_ij，则对端不可协调，注入 v_ij^⊥，并使用最保守足迹。若对端意图完整且新鲜，则允许用其预测集缩小足迹。

**新增定义 543（社交证书 Social Certificate）** 对边 (i,j)：
```
Ŝ_ij = 1[ S_i ∩ R̄_j(q_{j→i}, Δ_{j→i}) = ∅ ∧ dist(S_i, R̄_j) ≥ d_safe ]
```
块 i 可成约当且仅当：对所有 j∈N(i)，Ŝ_ij=1；或 i 的优先级低于 j 且 i 执行让行块（其承诺集收缩到让行闭包内）。社交证书不要求全局共识，只要求每台机器人对“已知意图 + 保守足迹”做本地检查。

**新增定义 544（让行闭包中止点 Yield-Closed Abort）** 中止点集 P_i 是让行闭包的，若对任意 p∈P_i，从 p 安全停驻的刹车轨迹不进入任何更高优先级邻居的当前承诺集，且停驻后仍满足两两停车不变式。若不满足，则 p∉P_i；若 P_i 因此为空，则该候选被拒绝，机器人改用纯让行/停驻块。该定义保证“停”不会制造新冲突，是引理 90 无循环等待的基础。

**新增定义 545（数据质量护照 Quality Passport）** 每个数据项 x 附护照 QP(x) 与保守扰动界 δ(x)：
```
QP(x) = (q_time, q_comp, q_cal, q_cons, q_prov) ∈ [0,1]^5
δ(x)  = δ_time + δ_comp + δ_cal + δ_cons + δ_prov
q(x)  = 1 − min(1, δ(x)/Δ_max)
```
五维不是五个任意打分，而是五个**可观测的扰动来源**：时效→状态外推误差；完整→缺失字段插补误差；标定→Calib-FI 漂移界；一致→跨源马氏距离/残差映射；来源→认证失败时的最大扰动界。δ 用求和而非取 max，是因为三角不等式下各误差源可以叠加，求和是保守上界。

**表 545a：五维质量到扰动界的编译表**

| 维度 | 可观测量 | 保守扰动界 δ_d |
|---|---|---|
| 时效 q_time | 采样/消息年龄 Δ | `v_max·Δ + 0.5·a_max·Δ²` |
| 完整 q_comp | 缺失字段比例、丢包率 | `δ_imp`（最坏插补误差，离线标定） |
| 标定 q_cal | Calib-FI 漂移/重标定间隔 | `δ_cal`（标定不确定度上界） |
| 一致 q_cons | 跨源马氏距离、残差 | `δ_cons`（由残差到状态误差的保守映射） |
| 来源 q_prov | 认证链、账本信任 | `0`（可信）或 `Δ_max`（不可信） |

**新增定义 546（质量调整不确定度 Quality-Adjusted Uncertainty）** 设前向模型 F̂ 对输入扰动 L-Lipschitz。对数据项 x，块证书的误差余量替换为
```
β_eff(x) = β_0 + L·δ(x)
```
多源融合时，δ 采用保守相关界：若来源独立，`δ_fuse ≤ Σ w_s δ_s`；若来源可能相关，取 `δ_fuse ≤ Σ w_s δ_s + δ_corr`，其中 δ_corr 是共同模式误差上界。禁止用“平均”降低 δ，除非有独立性证据。

**新增定义 547（数据流质量契约 Stream Quality Contract）** 每条流 s 声明
```
κ_s^q = (D_s^q, τ_s^q, v_s^⊥, φ_s^adm, ρ_s)
```
截止期、质量阈值、缺失/失效中立元、学习准入谓词、重标定/重采集脚本。若流不可用或 q_s<τ_s^q，注入 v_s^⊥（缺失标记或预标定下界），并让下游 δ 上升；禁止静默使用低质量值。

**新增定义 548（质量门槛学习 Quality-Gated Learning）** 学习/蒸馏样本 z 的权重
```
w(z) = 1[q(z) ≥ τ_q] · clip(q(z), 0, 1)
```
并做质量分层归一化，保证每个质量层在经验风险中的占比受控。ID 的消融回合仅在 q_episode≥τ_q 时更新 c_m；否则冻结 c_m（等价 v9 ID 的“本回合跳过”）。DA-ML 在 q 低于阈值时冻结阈值更新，使用 v9 先验；Calib-FI 在 q_cal 低于阈值时触发重标定，失败则注入恒等权重。

**新增定义 549（机群质量账本 Fleet Quality Ledger）** 对每条流/每个对端维护下界 \underline q_s(t) 与异常计数，更新规则是**慢恢复棘轮**：
```
若 q̂_s(t) < \underline q_s(t):  \underline q_s(t+1) = q̂_s(t)          # 立即降信任
若连续 H_rec 帧 q̂_s ≥ τ_s^q:   \underline q_s(t+1) = min(1, \underline q_s(t)+η^+)  # 缓慢恢复
否则:                            \underline q_s(t+1) = \underline q_s(t)
```
账本只用于收紧信任（降低 q、增大 δ），不用于放宽；恢复需要连续合格证据与冷却期，防止一次好帧洗白一次故障。

**新增定义 550（保守可达足迹 Conservative Reachable Footprint）** 给定同伴 j 在意图时刻 t_0 的状态 (p_j,v_j)，速度/加速度界 (v_max,a_max)，意图年龄 Δ=t−t_0，质量 q_{j→i}，足迹
```
R̄_j(t) = S_j^pred ⊕ B( ε_track + δ_j(q_{j→i}) + v_max·Δ + 0.5·a_max·Δ² )
```
若意图缺失或 Δ>H_ij，则 S_j^pred 替换为“最后已知位置的全向 v_max/a_max 包络”，并取 δ_j=Δ_max。关键性质：R̄_j 对 q 单调不增、对 Δ 单调不减；质量越高、消息越新，足迹越小，但永远不会小于 S_j^pred⊕B(ε_track)。

**新增定义 551（质量耦合预约 Quality-Coupled Reservation）** 预约就是足迹的实例：S_j^π ≡ R̄_j(q,Δ)。当 q≥τ_peer 且 Δ≤H_ij 时，S_j^π 退化为“预测集 + 跟踪误差”，即高质量买来的小足迹；当 q<τ_peer 或 Δ>H_ij 时，S_j^π 膨胀为保守可达足迹，即低质量必须支付的抵押。**质量只改变 S_j^π 的大小，不改变本地守卫的检查式**——这是 P13 的直接体现。

**新增定义 552（质量-协同对偶 Quality-Coordination Duality）** 两个单调算子：
- 协同→质量（佐证）：若 m 个来源独立且各自合格，共享地图单元的质量下界 `q_corr ≥ 1 − Π_s(1−q_s^{ind})`；若来源相关，则必须加上共同模式项 δ_corr，不能声称提升。
- 质量→协同（担保）：q 越高，R̄_j 越小，可成约的候选集越大；q 越低，R̄_j 越大，通行率越低但安全不变。
两者构成同一“保守性预算”的对偶：**节省的足迹必须由可验证的质量证据支付；没有证据，就必须抵押保守性**。

δ_trigger = σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom

# IP-357 FleetCommitCoordinator：5Hz 决策、下一 epoch 生效（双缓冲）
class FleetCommitCoordinator:
    def __init__(self, ac, qpg, d_safe=0.15, eps_track=0.02,
                 tau_peer=0.7, H_comm=0.4, H_fleet=10, N=1):
        self.ac, self.qpg = ac, qpg
        self.d_safe, self.eps_track = d_safe, eps_track
        self.tau_peer, self.H_comm, self.H_fleet = tau_peer, H_comm, H_fleet
        self.N = N
        self.last_known = {}          # j -> (pose, vel, t0)
        self.committed = {}           # j -> (S_j, expire_epoch)
        self.wait = defaultdict(int)

    def committed_set(self, chunk, state):
        S = set()
        for p in chunk.abort_points:                 # 定义 541
            S |= swept(chunk.trajectory[:p])
            S |= brake_envelope(chunk.trajectory[p], state.v[p])
        return inflate(S, self.eps_track)

    def footprint(self, j, now, peer_msg):
        if peer_msg is None or now - peer_msg.t0 > self.H_comm:
            p, v, t0 = self.last_known[j]            # 最保守：全向包络
            age = now - t0
            return reachable_envelope(p, v, age, self.v_max, self.a_max,
                                      self.eps_track + self.qpg.delta_max)
        age = now - peer_msg.t0
        q = self.qpg.peer_quality(peer_msg)          # 五维护照 → q
        delta = self.qpg.delta_from_q(q, floor=self.qpg.q_floor)
        return inflate(peer_msg.S, self.eps_track + delta
                       + self.v_max*age + 0.5*self.a_max*age**2)

    def decide(self, i, cand, peers, now):
        """返回 ('commit', S_i)、('yield', stop_set) 或 ('wait', None)。"""
        S_i = self.committed_set(cand, cand.state)
        # 1) 本地防御：对每个同伴使用保守足迹；安全不依赖协议成功
        for j in self.N_set - {i}:
            R_j = self.footprint(j, now, peers.get(j))
            if intersects(S_i, R_j) and higher_priority(j, i):
                self.wait[i] += 1
                return ('yield', self.yield_closure(i, R_j))
        # 2) 双缓冲：只与上一 epoch 已生效承诺比较
        for j, (S_j, exp) in self.committed.items():
            if j != i and exp > now and intersects(S_i, S_j):
                if lower_priority(i, j):
                    return ('yield', self.yield_closure(i, S_j))
                return ('preempt', j)                # 需 j 的让行确认
        # 3) 优先级串行化本 epoch 候选：所有机器人算出同一顺序
        accepted = {}
        for j in sorted(self.N_set, key=priority_key):
            if j == i:
                if all(not intersects(S_i, S) for S in accepted.values()):
                    return ('commit', S_i)            # 下一 epoch 生效
                return ('yield', self.yield_closure(i, accepted))
            msg = peers.get(j)
            if msg is not None and self.qpg.is_fresh(msg, now):
                accepted[j] = msg.S                  # 只接受新鲜、合格意图
            else:
                accepted[j] = self.footprint(j, now, msg)  # 否则用保守足迹
        return ('wait', None)

    def yield_closure(self, i, conflict_sets):
        """让行闭包：把 P_i 收缩到不进入冲突集的中止点，并保留停车不变式。"""
        keep = [p for p in self.cand[i].abort_points
                if not any(enters(self.brake(p), C) for C in conflict_sets)]
        return self.ac.rebuild_with_abort_points(i, keep)   # 可能为空 ⇒ 纯停驻


# IP-358 QualityPassportGate：把质量缺陷编译为不确定度
class QualityPassportGate:
    def __init__(self, beta0, L, delta_max, tau_q, q_floor,
                 v_max, a_max, H_rec=20, eta_plus=0.05):
        self.beta0, self.L, self.delta_max = beta0, L, delta_max
        self.tau_q, self.q_floor = tau_q, q_floor
        self.v_max, self.a_max = v_max, a_max
        self.H_rec, self.eta_plus = H_rec, eta_plus
        self.ledger = defaultdict(lambda: 1.0)

    def audit(self, datum):
        dt = self.v_max*datum.age + 0.5*self.a_max*datum.age**2
        dc = self.imputation_bound(datum)            # 完整
        dk = self.calib_drift_bound(datum)           # 标定
        ds = self.consistency_bound(datum)           # 一致
        dp = 0.0 if datum.authenticated else self.delta_max  # 来源
        delta = dt + dc + dk + ds + dp               # 求和 = 保守
        q = max(0.0, 1.0 - min(1.0, delta/self.delta_max))
        return Passport(q, delta, (dt, dc, dk, ds, dp))

    def beta_eff(self, passport):
        return self.beta0 + self.L * passport.delta

    def delta_from_q(self, q, floor=None):
        q_eff = max(self.q_floor if floor is None else floor, q)
        return self.delta_max * (1.0 - q_eff)

    def admit(self, sample):
        return sample.q >= self.tau_q and self.ledger[sample.stream] >= self.tau_q

    def update_ledger(self, stream, q_hat):
        old = self.ledger[stream]
        if q_hat < old:
            self.ledger[stream] = q_hat           # 立即降信任
        elif self.good_count[stream] >= self.H_rec:
            self.ledger[stream] = min(1.0, old + self.eta_plus)
        # 否则保持不变（慢恢复棘轮）

## 5. 推导（引理 87–94）

**引理 87（质量调整证书的可靠性）** 设前向模型 F̂ 对输入扰动 L-Lipschitz，数据项 x 的真实输入误差满足 `‖e(x)‖ ≤ δ*(x)`，审计器输出 `δ̂(x) ≥ δ*(x)`（单向性），且 `β_eff = β_0 + L·δ̂`。则 v9 引理 82 的块证书保守性与中止安全性在 β←β_eff 下仍成立。

证明：由三角不等式，
```
‖F(x) − F̂(x)‖ ≤ ‖F(x) − F̂(x_ideal)‖ + ‖F̂(x_ideal) − F̂(x)‖
               ≤ β_0 + L·‖e(x)‖
               ≤ β_0 + L·δ̂ = β_eff.
```
其余“证书保守、可行至中止点”的论证逐字复用 v9 引理 82。单向性保证 δ̂ 不会小于真实 δ*；若审计器失效，按 P14 取 δ̂=Δ_max 或 q_floor，而不是 0。∎

**引理 88（异步协同的组合安全 / 不需要共识）** 若每台机器人 i 的本地守卫在每步使用满足 `Reach_j(t) ⊆ R̄_j(t)` 的保守足迹，且成约时只接受与所有已知承诺集、所有更高优先级候选不相交的 S_i，则无论消息是否同步、是否存在视图不对称，机群不会发生两两碰撞。

证明：反设 i、j 的承诺集相交，即 `S_i ∩ S_j ≠ ∅`。若 j 使用 i 的保守足迹 R̄_i，则 j 的冲突检查会发现 `S_j ∩ R̄_i ⊇ S_j ∩ S_i ≠ ∅`；若 j 使用 i 的高质量预测集 S_i^pred，同样会发现（因为 S_i ⊆ S_i^pred⊕B(ε_track) 且检查含 ε_track）。故至少一侧不会成约，矛盾。双缓冲保证新承诺在生效前已能被对端从其保守足迹中看到；本地守卫再提供第二道防线。该证明不需要全局时钟、不需要共识、不需要所有机器人同时在线。∎

**引理 89（陈旧/丢失消息的保守性）** 若同伴满足速度/加速度界，则定义 550 的 R̄_j(t) 包含其在意图时刻之后的所有可达位置；当 Δ>H_comm 时取“最后已知位置的全向 v_max/a_max 包络”，仍然包含。故丢包与延迟只增大 R̄_j、降低通行率，不产生漏检冲突。

证明：标准可达集膨胀：位置误差 ≤ `v_max·Δ + 0.5·a_max·Δ²`；加上跟踪误差 ε_track 与质量扰动界 δ_j(q)。对 Δ>H_comm，全向包络对所有可能速度方向取上界，故包含任意实际轨迹。∎

**引理 90（无循环等待与老化公平）** 优先级全序 + “只让行给更高优先级”消除循环等待；冲突分量中最高优先级机器人若物理可行则必成约。加入老化项 w_i(t) 后，任一机器人的等待时间上界由更高优先级任务的有限占用时间之和给出；若物理通道被永久阻塞，系统进入显式“全局停驻”而非振荡死锁。

证明：冲突图上的等待关系是严格全序的子关系，不可能成环；老化项随时间单调增加，最终使被饿死的机器人优先级超过竞争者。物理阻塞情形由 F1/F2 降级处理：F1 让行/停驻，F2 拒绝多机任务。∎

**引理 91（质量门控学习的无害性）** 若 DA/ID 只接受 `q≥τ_q` 的样本，并对质量分层做加权归一化，则低质量样本对安全关键阈值（DA 的 τ_dom、ID 的 c_m）的一阶更新为零；当 QPG 中立（q≡1、门开）时，更新公式逐项退化为 v9 的 DA/ID。

证明：低于 τ_q 的样本权重为 0；分层归一化保证每个合格质量层在经验风险中的总权重受控，不因样本数量偏置。q≡1 时 w(z)≡1、门槛恒真，退化为 v9 的未加权更新。∎

**引理 92（佐证融合的边界）** 若共享地图单元的每个认证观测至少有一个独立、合格来源，且融合使用保守相关界，则认证单元的误差不超过膨胀界；若所有来源共享同一系统误差（同型号相机、同一标定、同一遮挡），佐证不增加信息，误差不受控。故佐证只能消除独立故障，不能消除共同模式误差。

证明：独立来源的误差可按方差/界叠加，融合后误差 ≤ 膨胀界；共同模式误差 δ_corr 对所有来源相同，增加来源数量不改变 δ_corr，故不能声称提升。该引理是引理 87 在共享地图上的实例，也是本轮最大风险的来源之一。∎

**引理 93（严格退化到 v9）** 当 N=1、q=q_floor=1、无同伴意图时，FCC 冲突图为空、QCR 的膨胀项为零、QPG 的 β_eff=β_0，AC/MW/ID 的输入输出与 v9 逐位一致；因此 MetricVoiceGauge-FQC 在退化部署中严格等价于 MetricVoiceGauge-ACMD。

证明：N=1 ⇒ 协调边集为空，FCC 的冲突检查与串行化均为空操作；q=1 ⇒ δ=0、β_eff=β_0、R̄_j 不存在；QCR 的 footprint 只在 N≥2 时被调用。AC 的 O 仍为静态 O，MW 契约表只多出三行但均立即返回其 v9 等价值，ID 的质量门槛在 q=1 时恒真。逐项比较输入输出即得逐位一致。∎

**引理 94（协同/质量开销可行性）** 5Hz 协调消息包含 O(K) 个路点、中止点集与五维护照；N≤8、K≤10 时单条 ≤2KB，5Hz 总带宽 ≤80KB/s。本地成约计算 O(N²K) ≤1ms，摊销 ≤0.2ms/cycle；QPG 审计 O(1)（五维固定），QCR 足迹 O(|P|)。新增总开销 ≤1.2ms/cycle，满足 v9 的 20ms 决策预算与 50Hz 节拍。

证明：逐项复杂度相加；消息大小由路点数与固定维护照界定；最坏 N=8、K=10 时 O(640) 次相交检查，单次为常数时间包围盒/胶囊体检查，≤1ms。∎

## 7. 机制自检（结构性结论，不等同于基准证据）

1. **质量单调性**：由定义 550，R̄_j(q,Δ) 对 q 单调不增、对 Δ 单调不减。因此 `{候选块 : S_i ∩ R̄_j = ∅}` 随 q 增大而单调增大——高质量确实只扩大可行域（liveness），不改变安全谓词。
2. **冲突不可双成约**：由引理 88，若两机承诺集相交，则至少一侧的保守足迹检查会失败；双缓冲保证新承诺在生效前已被对端可见。该结论是结构性的，不依赖消息到达顺序。
3. **退化恒等**：由引理 93，N=1、q=1 时 FCC/QPG/QCR 的所有新增项消失，主闭环逐位回到 v9。该结论可用 E584 的轨迹/日志逐位比对验证。
4. **残余风险**：上述三条都建立在“保守足迹包含真实可达集”之上；若审计器高估 q 或同伴违反物理可达界，保守足迹不再包含真实位置，安全论证失效。这正是本轮最大风险，不能用更多代码消除，只能靠独立感知、物理缓冲与失效检测缓解。

## 10. 本轮最大风险

**一句话**：“质量只买通行率”的证明依赖审计器单向性与“同伴不会违反物理可达界”；若审计器与被审计数据共享同一失效模式，q̂ 会高估，保守足迹退化为预测集，而乐观中立元又让系统在审计器崩溃时回到 v9 的信任假设——此时最需要保守的协同场景反而最乐观。
