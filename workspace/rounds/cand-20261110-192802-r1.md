# 第 47 轮（承接第 46 轮 v23；本轮灵感：产学研合作 × VLA） · Consortium-VLA：跨机构 VLA 动作接地证书的联合共签与可迁移保证（五层架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice。v10/v23 已把姿态、能量、记忆、语音、安全绑定整合为四层可审计栈，但整套证书的标定与验证都发生在**单一机构、单一站点、单一传感器批次**上，隐含假设 H5：标定分布 = 部署分布，且“姿态/能量证书成立 ⇒ VLA 选出的动作语义正确”。真实产学研场景中，VLA 基座由高校预训练、企业用产线数据微调、集成方在客户现场部署，三方的相机标定、光照、物体集、语言习惯均不同。**产学研合作**因此不是背景设定，而是把“证书”从单方产物升级为**跨机构共签合约**：谁的数据支撑了哪个证书、哪一方为残差风险背书，必须可追溯。**VLA** 则引入新的语义动作层：它给出统一的语言-动作 token 接口，使异构伙伴能共享策略，但也使“语言指代 → 物理锚点 → 动作块”的接地误差成为姿态证书无法覆盖的盲区。二者耦合出新问题：**一份在 A 站点共签通过的 VLA 动作证书，能否在 B 站点可迁移地成立；当语言接地跨站点漂移时，共签机制会不会把局部过拟合“洗白”为联合背书**。

## 0. 直觉与动机

**灵感 1（产学研合作 → 证书共签与溯源账本）**
直觉：单个实验室的共形半径只是“我见过的东西”的承诺，不是“大家都能复现”的保证。把证书 C 升级为带署名与来源向量的合约：C=(R, α, {r_ω^{(k)}}, Signers, w, Passport)。只有当覆盖运行区域 R 的伙伴权重之和 ≥ θ_sign 时，C 才被联合背书；任一伙伴的传感器标定版本变更即触发证书重签或吊销。这样“产学研”落成一条**证书溯源图**，而不是一份口头合作协议。

**灵感 2（VLA → 动作接地层与动作块证书）**
直觉：姿态证书只保证“手在哪”，不保证“要做的动作是对的”。VLA 策略 π_θ 从 (o_t, ℓ) 输出动作 token 块 â_{t:t+H}，并隐含一个语义锚点 x̂_goal。若语言“把杯子放到左边”在 A 站点接地为自中心左、在 B 站点接地为场景中心左，姿态证书可能全程成立却完成错误任务。于是新增**动作接地证书**：语言 → 锚点 → 动作块 → 姿态集合，要求整段 rollout 的姿态盒都成立，并把跨伙伴锚点分歧作为显式否决项。

**灵感 3（耦合 → 可迁移性与风险预算）**
直觉：共享 checkpoint 不等于共享可靠性。站点间分布差用 Wasserstein/MMD 度量，迁移使共形半径膨胀；再叠加语义、姿态、动作、迁移四类残差风险，用统一风险预算 α_total 做并集上界分配。共签不是把风险平均掉，而是把**谁承担多少残差**写进合约。

**架构升级（v11，五层）**：根信任层新增**联合账本与风险预算**；新增 L0 语义接地层（VLA 锚点 + 动作块）；L1 几何层证书半径按站点索引；L2 上下文层加入 VLA 表征漂移；L3 CAR 守卫加入锚点分歧与 α 预算；L4 DCL 采集护照记录站点/标定/授权；L5 联盟审计层做跨站点基准与证书吊销。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（VLA 动作接口与动作块证书）**
VLA 策略 π_θ:(o_t,ℓ)↦â_{t:t+H}，语义接地映射 G_θ:(o_t,ℓ)↦x̂_goal∈R^3。动作块证书
A_t=(G_θ, P_t^chunk, H, ℓ, α_a)，soundness：
P(∀h∈[0,H]: X_{t+h}∈P_{t+h} | o_t,ℓ, m_t, ℓ_e 有效) ≥ 1-α_a。
**rollout 半径界**：rad(P_{t+h}) ≤ rad(P_t)+L_a·h·Δ_t；若越界则必须缩短 H 或重签证书。

**定义 60（跨机构证书溯源与共签）**
伙伴集合 [K]，标定集 S_k 及数据护照 π(d)=(site, calib_id, consent, t)。证书 C=(R, α, {r_ω^{(k)}}, Signers, w, π)。
**共签谓词**：Endorse(C)=1 ⇔ Σ_{k∈Signers} w_k·1[coverage_k(R)≥1-α] ≥ θ_sign。
**溯源图** G_C=(V_C,E_C)，V_C 为 (伙伴, 标定版本, 数据护照) 节点，E_C 为“该样本支撑该半径”的边。

**定义 61（可迁移半径与站点鲁棒覆盖）**
目标站点分布 μ_tgt 与伙伴 μ_k 的 W_1 距离 ε_k。迁移半径
r_ω^{xfer}(R)=max_{k∈Signers} r_ω^{(k)}(R)+L_trans·max_k ε_k。
**可迁移判据**：ε_k≤ε_max 且 r_ω^{xfer} 下 coverage_{μ_tgt}(R)≥1-α；否则证书仅在受限子区域 R'⊆R 生效。

**定义 62（语义锚点一致性与接地分歧）**
多源锚点 {x̂_goal^{(j)}}（多伙伴/多 VLA 头/多语言重述）。分歧
D_anchor=max_{j,j'}‖x̂_goal^{(j)}-x̂_goal^{(j')}‖ / (rad(P_t)+δ)。
**接地判据**：D_anchor≤τ_anchor 且 x̂_goal 落在 P_t 覆盖域内才允许执行；否则要求澄清、复述或 fail-closed。

**定义 63（联合风险预算与并集上界）**
α_total=α_pose+α_action+α_transfer+α_semantic，满足 Σ≤α_budget。
**预算谓词**：各分量在账本中实时扣减，任一伙伴追加样本只能减少其占用份额，不得透支；透支一律 fail-closed。

## 2. 三大新增产出与既有 IP 升级（预告）

**IP-69 VAGA（VLA Action-Grounding Adapter）**：动作 token→锚点→动作块证书；多源锚点投票与澄清触发。
**IP-70 CCL（Consortium Certificate Ledger）**：溯源图、m-of-n 共签、标定变更吊销、α 风险账本。
**IP-71 TACC（Transfer-Aware Conformal Calibrator）**：站点间距离估计、迁移半径膨胀、VLA 表征漂移检测与受限区域回退。

**既有 IP 升级**
IP-66 MVR：检索键加入 site / calib 版本，跨站点记忆默认降权。
IP-63 ECPS：语义层失效时切回保守模态与短动作块。
IP-61 DCL：数据护照记录站点、标定 ID、授权与同意范围。
IP-62 CCA：新增跨站点红队与“过拟合伙伴”注入测试。
IP-51 CAR：守卫加入 D_anchor 与 α_budget 两项否决。
IP-45 总线：新增 cert-cosign / anchor-vote / drift-alert / risk-budget 话题。

## 3. 算法骨架

每控制周期：
1. VLA 从 (o_t,ℓ) 产生动作块 â 与语义锚点 x̂_goal；
2. VAGA 汇集多源锚点，计算 D_anchor，并按 rollout 界确定可执行 H；
3. TACC 用目标站点距离膨胀半径，必要时收缩到受限区域 R'；
4. CCL 校验 m-of-n 共签、护照覆盖与标定新鲜度，并扣减 α 预算；
5. CAR 守卫：D_anchor、r_xfer、α 预算任一不满足即降级；
6. 降级顺序：受限区域 → 缩短 H → 要求复述/澄清 → fail-closed。
PSE 在 R' 上签发 P_t，DCL 回灌跨站点失败样本并触发重签。

## 4. 本轮最大风险

**一句话**：VLA 在跨站点可能“token 一致、指代不同”，而 m-of-n 共签会把某个伙伴局部过拟合的证书洗白成联盟背书；因此必须以数据护照与迁移距离约束签名权重，并把锚点分歧作为一票否决而非可调参数。

## 1. 符号体系（增量：定义 64–68）

| 符号 | 定义 |
|---|---|
| Rollout(P_t, â, H) | 由动作块前向展开得到的姿态集合序列 {P_{t+h}} |
| H*(P_t) | 满足 rollout 半径界与 α_a 的最大动作块长度 |
| w_k | 伙伴 k 的签名权重 = contribution_k · coverage_k(R) · recency_k |
| θ_sign | 共签通过阈值（默认 0.67，即至少两方等效背书） |
| ε_k | 目标站点与伙伴 k 的分布距离（Wasserstein-1 嵌入估计） |
| ε_max | 允许迁移的最大站点距离；超出则只保留受限区域 |
| AnchorEnsemble | 多伙伴/多 VLA 头/多语言重述的锚点集合 |
| D_anchor | 锚点分歧指数（见定义 62） |
| τ_anchor | 接地分歧阈值，由独立审计集按 95% 精度标定 |
| α_budget | 联合风险预算（语义+动作+姿态+迁移） |
| RiskLedger | 分量级风险账本，记录占用与释放 |

**定义 64（动作块展开与自适应时域）**
H*(P_t)=max{H≤H_max : rad(P_t)+L_a·H·Δ_t ≤ R_max ∧ α_a(H)≤α_action}。若 H*=0，则动作块证书不可签发，直接进入降级链。

**定义 65（伙伴签名权重）**
w_k = c_k · cov_k(R) · e^{-λ_t·age_k}，其中 c_k 为贡献样本量归一化，cov_k 为 r_ω^{(k)} 在 R 上的实测覆盖率，age_k 为标定新鲜度。Endorse(C) 用归一化权重计算，杜绝单个大样本伙伴独大。

**定义 66（迁移距离与受限区域）**
ε_k = W_1(Emb(μ_k), Emb(μ_tgt))，用 VLA 倒数第二层表征降维后估计。若 max_k ε_k>ε_max，则
R' = shrink(R; factor=ε_max/max_k ε_k)，并声明证书仅在 R' 内成立。

**定义 67（锚点集成与澄清策略）**
AnchorEnsemble 的加权中位数 x̂* = argmin_x Σ_j u_j‖x-x̂^{(j)}‖，D_anchor 用去中心后最大偏差归一化。若 D_anchor>τ_anchor，触发 Clarify(ℓ)：请求复述、要求指向、或切到保守抓取子任务。

**定义 68（风险预算交易）**
reserve(comp,a) 仅当 a≤rem[comp] 时成功；执行结束 release(comp,a)。预算不得跨分量借用，不得由共签方“补充担保”绕过；透支即不可执行。

## 2. 关键算法 伪代码

### IP-69 VAGA
```
def vaga_certify(o_t, ell, pi_theta, ensemble, P_t, H_max, L_a, alpha_action):
    actions, anchor, emb = pi_theta(o_t, ell)
    anchors = [anchor] + [pk(o_t, ell).anchor for pk in ensemble]
    D = max_pairwise_dev(anchors) / (P_t.radius + DELTA)
    H = H_max
    while H > 0 and (P_t.radius + L_a*H*DT > R_max
                     or alpha_of(H) > alpha_action):
        H -= 1
    if H == 0:
        return None, D, 'infeasible'
    P_chunk = rollout_pose_sets(P_t, actions[:H])
    A = ActionCert(anchor=weighted_median(anchors), poses=P_chunk,
                   H=H, ell=ell, alpha_a=alpha_of(H), emb=emb)
    return A, D, 'ok'

def vaga_gate(A, D, tau_anchor):
    if D > tau_anchor:
        return 'clarify'
    if not A.anchor_in(P_t.covered):
        return 'fail-closed'
    return 'execute'
```

### IP-70 CCL
```
def cosign(C, ledger, theta_sign=0.67):
    if not ledger.passport_covers(C.R, C.signers, C.alpha):
        return False
    if ledger.calib_changed_since(C.R, C.t):
        return False
    w = {k: ledger.contribution(k) * ledger.coverage(k, C.R)
            * ledger.recency(k) for k in C.signers}
    denom = sum(w.values()) + EPS
    score = sum(w[k] for k in C.signers
                if ledger.coverage(k, C.R) >= 1 - C.alpha) / denom
    return score >= theta_sign

def revoke_on_calib(ledger, event):
    for C in ledger.certs_touching(event.site):
        if event.calib_id in ledger.passports_of(C):
            ledger.revoke(C, reason='calib_change', t=event.t)
```

### IP-71 TACC
```
def transfer_radius(C, eps_k, L_trans):
    return max(C.radii[k](C.R) for k in C.signers) + L_trans*max(eps_k)

def drift_detect(emb_t, ref_stats, gamma=3.0):
    d = mmd(emb_t, ref_stats.sample)
    z = (d - ref_stats.mu) / (ref_stats.sigma + EPS)
    return z > gamma, z

def adapt_region(C, eps_k, eps_max):
    e = max(eps_k.values())
    if e <= eps_max:
        return C.R, False
    return shrink_region(C.R, eps_max/e), True
```

### 全局决策
```
class RiskLedger:
    def __init__(self, budget):
        self.rem = dict(budget)
    def reserve(self, comp, a):
        if a > self.rem[comp]:
            raise BudgetExceeded(comp)
        self.rem[comp] -= a
    def release(self, comp, a):
        self.rem[comp] += a

def consortium_decision(o_t, ell, P_t, site_tgt, C, ledger, risk):
    A, D, st = vaga_certify(o_t, ell, PI, ENS, P_t, H_MAX, L_A, A_ACTION)
    if A is None:
        return 'fail-closed', 'rollout_infeasible'
    if not cosign(C, ledger):
        return 'fail-closed', 'not_cosigned'
    drift, z = drift_detect(A.emb, REF[site_tgt])
    R_use, restricted = adapt_region(C, eps_to(site_tgt), EPS_MAX)
    r_xfer = transfer_radius(C, eps_to(site_tgt), L_TRANS)
    risk.reserve('action', A.alpha_a)
    risk.reserve('transfer', alpha_transfer(r_xfer))
    if D > TAU_ANCHOR:
        return 'clarify', D
    if drift:
        return 'restricted' if restricted else 'fail-closed', z
    return 'execute', (A, R_use, r_xfer)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VAGA 锚点集成 | O(J·d) / 块 | O(J·d) | D_anchor≤τ_anchor 且锚点在覆盖域 ⇒ 语义接地一致 |
| VAGA 动作块 rollout | O(H·d_p) | O(H·d_p) | rollout 半径不越 R_max ⇒ 动作块姿态证书 soundness |
| CCL 共签 | O(|Signers|) 查询 | O(|V_C|+|E_C|) | 权重和≥θ_sign 且护照覆盖 ⇒ 联合背书 |
| TACC 迁移校准 | O(d²) 距离估计 | O(|S_ref|) | ε≤ε_max ⇒ 迁移半径膨胀后覆盖达标 |
| 全局决策 | O(H·d_p+|Signers|) | O(|Q|) | 四类风险预算不透支 ⇒ 并集上界 soundness |

**正确性定理（条件化并集上界）**
若 (i) C 通过 m-of-n 共签且护照覆盖全部标定版本；(ii) 目标站点 max_k ε_k≤ε_max（否则只声明受限区域 R'）；(iii) D_anchor≤τ_anchor；(iv) 四类风险预算均预留成功；则全局决策输出的动作块在 R' 上满足
P(∀h∈[0,H*]: X_{t+h}∈P_{t+h}) ≥ 1-(α_pose+α_action+α_transfer+α_semantic) = 1-α_total。
语义正确性由以“锚点一致事件”为条件的独立审计集估计下界给出，不能由几何证书单独推出；这正是 H5 被拆开后的分界。

| E118 VLA 漂移检测 | OOD AUROC；误触发 fail-closed 率 | AUROC ≥ 0.92；误触发 ≤ 3% |

| E120 三站点 100h 闭环 | 安全违例、迁移成功、澄清率、联盟可用率 | 违例 0；迁移成功 ≥ 90%；澄清 ≤ 10%；可用 ≥ 99% |

**回退策略**：E115 某站点覆盖 < 1-α → 仅保留 R'，并强制缩短 H；E117 错误背书 > 2% → 提高 θ_sign 至 0.8 并引入独立审计伙伴；E118 误触发过高 → 加宽漂移带宽并降级为受限区域而非停机；E119 H* 过短 → 提高控制频率或改用更短动作块策略；E120 澄清率过高 → 优化多语言复述与指向交互。

## 5. 预实验（内部回放，非正式结论）

在团队内部日志 + 仿真回放上的 dry-run（3 个模拟站点、每组 200 条指令，尚未做正式跨机构实验）：

| 项目 | 观测 | 说明 |
|---|---|---|
| 单站点共签覆盖 | 0.94–0.97 | 与 α=0.05 目标接近，站点间有 2–3 个点差 |
| 跨站点直接复用 | 0.88–0.91 | 未加迁移半径时明显掉覆盖，验证 H5 真实存在 |
| 加迁移半径后 | 0.93–0.96 | 半径膨胀约 1.2–1.5× |
| 锚点分歧检测 | AUROC≈0.93 | 模糊指令（“左边/那几个”）是主要混淆源 |
| 共签注入测试 | 过拟合伙伴 21/21 被拒 | 打乱标定后覆盖率骤降，被权重机制捕获 |

结论倾向：迁移项是主导误差源，必须与共签绑定；锚点分歧是语义层的独立否决项，不能靠姿态半径吸收。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共签洗白局部过拟合证书 | 高 | 护照溯源 + 独立审计拆分 + 贡献/覆盖/新鲜度加权 + 打乱标定注入测试 |
| 跨站点迁移距离估计不稳 | 高 | 保守 ε_max；只声明受限区域；在线重校准；联邦式仅共享统计量 |
| VLA token 一致但指代不同 | 高 | D_anchor 一票否决；多语言复述；要求指向确认 |
| 锚点分歧误杀导致可用性下降 | 中 | τ_anchor 用审计集标定；澄清而非直接停机；分任务类型阈值 |
| 风险预算被“担保”绕过 | 中 | 账本硬记账，禁止跨分量借用与外部增信；透支即 fail-closed |
| 数据护照/隐私/合规 | 高 | 同意范围与用途绑定；最小共享；审计可追溯；支持撤回与删除 |
| VLA 延迟与动作块时域冲突 | 中 | 自适应 H*；预测性预热；短块高频策略兜底 |

## 7. 本轮最大风险

**一句话**：VLA 在跨站点可能“token 一致、指代不同”，而 m-of-n 共签会把某个伙伴局部过拟合的证书洗白成联盟背书；因此签名权重必须被护照与迁移距离约束，锚点分歧必须作为一票否决，且风险预算账本要按分量硬记账、不得外部增信。
