# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「UniBot」×「行为克隆」）

> 第 54 轮把技能组合推进到动作空间双证书，但留下一个更根本的空白：**技能从哪来？** `α_S` 与 `ρ` 被当作既有输入，而真实 UniBot 体系中最主要的技能来源是**人类演示 + 行为克隆（BC）**。本轮聚焦 **演示支撑→动作剖面、BC 策略→行为证书、跨本体→统一动作空间**。核心矛盾：H22：BC 学到的只是演示分布上的条件均值，动作剖面一旦离开演示支撑就是外推幻觉，第 54 轮的证书在 OOD 动作上失效；H23：UniBot 的统一接口让跨任务/跨本体复用成为可能，但演示行为风格与目标本体动力学不一致，部署时协变量偏移会沿时间步复合放大。

## 0. 直觉与动机

**灵感 1（演示支撑 = 动作剖面的经验下界）**
直觉：`α_S(a)` 不应由仿真可行性单独定义，而应由“这个动作在演示中被真实执行过多少次”给出。演示越密，可信度越高；离最近演示动作越远，越接近外推。于是 `α_S = min(α_sim, α_demo)`：仿真给上界（物理上能不能），演示给下界（人有没有真的这样干过），取交集才敢部署。

**灵感 2（BC 是分布，不是点）**
直觉：把 BC 策略当成确定性函数会系统性低估风险。多峰演示（同一情境多种合理动作）下，点策略会落在两峰之间，产生“平均动作”这种谁也做不对的动作。需要行为证书 `B_S` 记录条件熵、模态数与 OOD 率，并把多峰性作为组合前的显式约束（多峰技能优先 chunk / diffusion，而非回归）。

**灵感 3（支持投影 = 把 BC 关进演示笼子）**
直觉：与其相信 BC 不在 OOD 处乱来，不如在动作发射前加一道护栏：一旦动作密度低于阈值或观测 OOD，就把动作投影回演示支撑集；投影不可行则回退到第 54 轮已认证技能。这把“不可验证的神经网络策略”变成“落在可审计动作集合内的策略”。

**灵感 4（跨本体行为映射 = UniBot 的统一动作空间）**
直觉：UniBot 的价值在于统一接口，但统一接口不等于统一动力学。把演示编码到共享行为隐空间 `Z`，再由目标本体解码，得到 `γ_m = D_t ∘ E_s`。证书必须携带本体鸿沟 `δ_m`，否则“能映射”会被误当作“能执行”。

**灵感 5（负演示与主动补采）**
直觉：演示支撑的边界最好由失败演示来刻画。负演示给出“不要做什么”，主动补采（DAgger/不确定性采样）在支撑空洞处要标签，能把覆盖从被动数据集变成主动证书。

**灵感 6（BC2C 闭环：演示→证书→组合）**
直觉：第 54 轮的 `G_S` 需要节点属性 `(α_S, ρ_S)`；本轮让这些属性由 `DCP→BC2C→SPD` 自动产出，形成 **演示进、证书出、组合图用** 的闭环。这是把整个体系从“假设技能已认证”推进到“技能可被生产并认证”。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（演示支撑与演示剖面）**
给定演示集 `D_S = {(o_t,a_t,c_t)}_{t=1}^N`，动作空间 `A`，演示支撑集 `D_S^A = {a_t}`。核密度 `ω_S(a) = (1/N) Σ_t k_h(a - a_t)`，演示剖面
```
α_S^demo(a) = clip(ω_S(a)/ω_min, 0, 1)
```
支撑 `supp_θ(S) = {a | α_S^demo(a) ≥ θ_cov}`。双源融合：`α_S(a) = min(α_S^sim(a), α_S^demo(a))`，即仿真给物理上界、演示给经验下界。

**定义 122（行为证书）**
`B_S = (H̄_S, M_S, δ_ood, e_BC)`：
- `H̄_S = E_{o~D_S}[H(π_BC(·|o))]` 为条件熵，度量多峰/不确定性；
- `M_S` 为动作模态数估计；
- `δ_ood = P_{o~d_π}(s_ood(o) > τ_ood)` 的 conformal 上界；
- `e_BC` 为支撑内逐步偏差上界估计。
多峰判据 `M_S > 1 ∧ H̄_S > H_min` ⇒ 必须使用 chunk / diffusion 策略，禁止单峰回归。

**定义 123（协变量偏移与复合误差）**
部署访问分布 `d_π` 与演示分布 `d_D` 的偏移
```
Δ_obs(S) = sup_{o ∈ supp d_π} min_{o' ∈ D_S} ||φ(o) - φ(o')||
```
在支撑内，复合误差界为 `E[cost] ≤ (Λ_S·T + 1)(ε_BC·T + Δ_obs)`，其中 `Λ_S` 为动力学 Lipschitz 常数、`T` 为任务视野。证书要求 `(Λ_S·T+1)(ε_BC·T+Δ_obs) ≤ δ_comp`。

**定义 124（支持投影护栏 SPD）**
投影 `Π_S(a) = argmin_{a'∈D_S^A} ||a - a'||_A`，安全动作为
```
a^safe = a,              若 α_S^demo(a) ≥ θ_cov 且 s_ood(o) ≤ τ_ood
a^safe = Π_S(a),         若 α_S^demo(Π_S(a)) ≥ θ_cov
a^safe = π_fallback(o),  否则
```
`π_fallback` 必须携带第 54 轮联合证书 `J`。SPD 保证 `a^safe ∈ supp_θ(S) ∪ A_cert(π_fallback)`，即执行期间不产生无证书动作。

**定义 125（跨本体行为映射与本体鸿沟）**
共享行为隐空间 `Z`，源编码 `E_s: A^{e_s}→Z`，目标解码 `D_t: Z→A^{e_t}`，`γ_m = D_t ∘ E_s`。给定锚点对 `P = {(a_s^k, a_t^k)}`，本体鸿沟
```
δ_m = max_k ||E_s(a_s^k) - E_t(a_t^k)||_Z
```
并要求 `γ_m` 在 `supp_θ(S)` 上 `L_m`-Lipschitz。部署条件 `δ_m ≤ Θ_m ∧ L_m < 1`。

**定义 126（BC 联合证书）**
`J_BC = (α_S^demo, α_S, ρ_S, B_S, γ_m, δ_m, δ_ood, δ_comp, evidence)`，其中 `evidence` 至少包含演示覆盖直方图、OOD conformal 校准集、SPD 触发日志、跨本体锚点误差。`dom(J_BC)=in` 当且仅当任务动作被 `α_S ≥ θ_cov` 覆盖、`δ_ood ≤ Θ_ood`、`δ_comp ≤ Θ_comp`、`δ_m ≤ Θ_m`。

**定义 127（BC 技能生产算子）**
`Π_BC: D_S → Skill`，`Skill = (α_S, ρ_S, B_S, J_BC)`。其中 `ρ_S` 必须由 **SPD 包裹后的策略** 在支撑内做有界扰动得到，而非原始 BC 策略；这样第 54 轮组合图 `G_S` 只接受 `J_BC` 可部署的技能，从源头杜绝“未经护栏的 BC 策略混入组合”。

## 2. 关键算法 伪代码

### IP-121 DCP（Demo Coverage Profiling）

```python
def demo_coverage_profile(demos, action_grid, k=8, omega_min=1e-3, theta_cov=0.8):
    index = build_knn_index(demos.actions)      # LSH / Faiss，支持大规模演示
    alpha = {}
    for a in action_grid:
        dists, _ = index.knn(a, k)
        omega = kernel_density(dists, h=max(median(dists), 1e-6))
        alpha[a] = min(1.0, omega / omega_min)
    support = {a for a, v in alpha.items() if v >= theta_cov}
    return DemoProfile(alpha=alpha, support=support, coverage=len(support)/len(action_grid))
```

### IP-122 BC2C（Behavior-Clone-to-Certificate）

```python
def bc_to_certificate(demos, policy, sim, budgets, gamma_m=None, delta_m=0.0):
    prof = demo_coverage_profile(demos, action_grid=sim.A)
    # 双源保守融合：仿真上界 ∩ 演示下界
    alpha = {a: min(sim.alpha.get(a, 0.0), prof.alpha.get(a, 0.0)) for a in sim.A}
    B = behavior_certificate(policy, demos)      # entropy / modes / conformal OOD
    shielded = support_projected_policy(policy, prof)   # 先加护栏再测鲁棒性
    rho = robustness_spectrum_supported(shielded, prof.support, sim.K)
    delta_comp = compound_error_bound(policy, demos, sim)
    J = JointBC(alpha, rho, B, gamma_m or identity, delta_m,
                delta_ood=B.delta_ood, delta_comp=delta_comp)
    if not budgets_ok(J, budgets):
        return ('reject', diagnose(J))
    return ('ok', Skill(alpha, rho, B, J))
```

### IP-123 SPD（Support-Projection Defense）

```python
def shield_step(obs, pi_bc, prof, fallback, theta_cov=0.8, tau_ood=0.95):
    a = pi_bc(obs)
    if prof.alpha.get(a, 0.0) >= theta_cov and ood_score(obs) <= tau_ood:
        return a, 'nominal'
    a_proj = prof.project(a)                      # 最近演示动作
    if prof.alpha.get(a_proj, 0.0) >= theta_cov:
        return a_proj, 'projected'
    return fallback(obs), 'fallback'              # fallback 必须携带 J
```

### IP-124 DMR（Demonstration-Morphology Remapping）

```python
def cross_embodiment_adapter(demos_src, anchors, z_dim=32):
    E_s, E_t, D_s, D_t = train_shared_latent(demos_src, anchors, z_dim)
    gamma_m = lambda a: D_t(E_s(a))
    delta_m = max(norm(E_s(a_s) - E_t(a_t)) for a_s, a_t in anchors)
    L_m = estimate_lipschitz(gamma_m, domain=demos_src.actions)
    if delta_m > THETA_M or L_m >= 1.0:
        return ('reject', 'embodiment_gap', delta_m, L_m)
    return ('ok', gamma_m, delta_m, L_m)
```

### IP-125 CIX（Covariate-shift Index & eXpert correction）

```python
def certified_dagger(policy, env, demos, rounds, delta_target, theta_ood):
    pi, agg = policy, demos
    for r in range(rounds):
        rollout = env.rollout(pi, collect_states=True)
        shift = max_visitation_drift(rollout.states, demos.observations)
        ood = ood_rate(rollout.states, demos.observations)
        if shift <= delta_target and ood <= theta_ood:
            return ('certified', shift, ood, pi)
        q = select_high_shift(rollout.states, top_k=64)   # 主动选择高偏移状态
        agg = agg + expert_label(q)                       # 只标注，不执行高风险动作
        pi = retrain(agg)
    return ('reject', shift, ood)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DCP | O(|A|·k·log N) | O(|A|+N) | 核带宽自适应、LSH 近邻误差有界 |
| BC2C | O(|A|+N·T+|𝔇_ρ|) | O(|A|+|𝔇_ρ|) | 双源 min 融合单调、ρ 在支撑内测 |
| SPD | O(|A|·log N) 每次触发 | O(N) | 投影可判定、fallback 证书有效 |
| DMR | O(|P|·z + |supp|) | O(z+|P|) | 锚点覆盖、γ_m Lipschitz L<1 |
| CIX | O(rounds·(T+|A|·N)) | O(N+rounds·T) | 偏移估计一致、专家标签可信 |

**正确性定理（BC-Certified Skill Soundness）**
承接第 54 轮 (A22)–(A28)；新增假设：
**(A29)** 演示采样使 `α_S^demo` 一致收敛，支撑估计误差 ≤ `ε_D`；
**(A30)** 在 `supp_θ(S)` 内 BC 逐步偏差 ≤ `ε_BC`，动力学 Lipschitz 常数 `Λ_S`；
**(A31)** 跨本体映射在锚点集上 `L_m`-Lipschitz 且 `δ_m ≤ Θ_m`；
**(A32)** SPD 投影失败率 ≤ `P_proj`，fallback 技能携带有效 `J`。
则在 SPD 包裹下：
```
P(success) ≥ 1 - P_ood - β_E - (Λ_S·T + 1)(ε_BC·T + ε_D) - P_proj - P(δ_m > Θ_m)
```
关键点：**执行动作不离开演示支撑**消去了动作外推项；**支撑内的复合误差**由 `T²` 界控制；**跨本体鸿沟**以 `δ_m` 显式入账，而非隐含在“统一接口”里。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 演示覆盖稀疏，`α_S^demo` 高估支撑 | 高 | 负演示 + 主动补采 + conformal 覆盖下界 |
| 支持投影过保守导致“冻结机器人” | 高 | 软投影半径 + hysteresis + 回退优先级调度 |
| 多峰 BC 熵/模态标定错误 | 高 | 策略集成 + conformal 熵 + 模态可视化审计 |
| 跨本体映射非单调、本体鸿沟被低估 | 高 | 锚点对齐 + 多本体联合训练 + 本体不变表征 |
| 证书对仿真/训练集过拟合 | 中 | 真机小样本校准 + 红队 OOD + 留出本体测试 |

## 6. 本轮最大风险

**一句话**：BC2C 把技能生产从“仿真假设”推进到“演示可证”，但其 soundness **双重依赖演示支撑的统计覆盖与跨本体映射的本体对齐**；一旦演示稀疏处被核密度误判为高置信、或 UniBot 统一接口掩盖了目标本体的动力学鸿沟，SPD 会把策略“安全地”投影到一个错误但自洽的演示子空间，系统在真实本体上稳定地做错事，故必须以 **负演示边界 + conformal 覆盖下界 + 本体鸿沟硬预算** 三重护栏，宁可拒绝认证，也不把演示的“覆盖幻觉”当作部署许可证。

```python
    a = pi_bc(obs)
    if prof.alpha.get(a, 0.0) >= theta_cov and ood_score(obs) <= tau_ood:
        return a, 'nominal'
    a_proj = prof.project(a)
    if prof.alpha.get(a_proj, 0.0) >= theta_cov:
        return a_proj, 'projected'
    return fallback(obs), 'fallback'              # fallback 必须携带 J
```

### IP-124 DMR

```python
def cross_embodiment_adapter(demos_src, anchors, z_dim=32):
    E_s, E_t, D_s, D_t = train_shared_latent(demos_src, anchors, z_dim)
    gamma_m = lambda a: D_t(E_s(a))
    delta_m = max(norm(E_s(a_s) - E_t(a_t)) for a_s, a_t in anchors)
    L_m = estimate_lipschitz(gamma_m, domain=demos_src.actions)
    if delta_m > THETA_M or L_m >= 1.0:
        return ('reject', 'embodiment_gap', delta_m, L_m)
    return ('ok', gamma_m, delta_m, L_m)
```

### IP-125 CIX

```python
def certified_dagger(policy, env, demos, rounds, delta_target, theta_ood):
    pi, agg = policy, demos
    for r in range(rounds):
        rollout = env.rollout(pi, collect_states=True)
        shift = max_visitation_drift(rollout.states, demos.observations)
        ood = ood_rate(rollout.states, demos.observations)
        if shift <= delta_target and ood <= theta_ood:
            return ('certified', shift, ood, pi)
        q = select_high_shift(rollout.states, top_k=64)
        agg = agg + expert_label(q)
        pi = retrain(agg)
    return ('reject', shift, ood)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DCP | O(|A|·k·log N) | O(|A|+N) | 近邻误差有界、带宽自适应 |
| BC2C | O(|A|+N·T+|𝔇_ρ|) | O(|A|+|𝔇_ρ|) | min 融合单调、支撑内测 ρ |
| SPD | O(|A|·log N) 每触发 | O(N) | 投影可判定、fallback 证书有效 |
| DMR | O(|P|·z+|supp|) | O(z+|P|) | 锚点覆盖、L_m<1 |
| CIX | O(rounds·(T+|A|·N)) | O(N+rounds·T) | 偏移一致估计、标签可信 |

**正确性定理（BC-Certified Skill Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 演示采样使 `α_S^demo` 一致收敛，支撑误差 ≤ `ε_D`；**(A30)** 支撑内 BC 逐步偏差 ≤ `ε_BC`，动力学 Lipschitz 常数 `Λ_S`；**(A31)** `γ_m` 在锚点集上 `L_m`-Lipschitz 且 `δ_m ≤ Θ_m`；**(A32)** SPD 投影失败率 ≤ `P_proj`，fallback 携带有效 `J`。则
```
P_success ≥ 1 - P_ood - β_E - (Λ_S·T + 1)(ε_BC·T + ε_D) - P_proj - P(δ_m > Θ_m)
```
关键：**执行动作不离开演示支撑**消去动作外推项；**支撑内复合误差**由 `T²` 界控制；**本体鸿沟**显式入账而非藏在“统一接口”中。

## 6. 本轮最大风险

**一句话**：BC2C 把技能生产从“仿真假设”推进到“演示可证”，但其 soundness **双重依赖演示支撑的统计覆盖与跨本体映射的本体对齐**；一旦演示稀疏处被核密度误判为高置信、或 UniBot 统一接口掩盖了目标本体的动力学鸿沟，SPD 会把策略“安全地”投影到一个错误但自洽的演示子空间，系统在真实本体上稳定地做错事，故必须以 **负演示边界 + conformal 覆盖下界 + 本体鸿沟硬预算** 三重护栏，宁可拒绝认证，也不把演示的“覆盖幻觉”当作部署许可证。
