# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「物体泛化」×「场景泛化」）

> R69 教会系统「问」，但「问」隐含两个未经检验的前提：**我看见的是我以为的那类东西**，**我的证书在我所处的地方仍然有效**。物体泛化与场景泛化同时打穿这两条：
> - 新物体常常不是「没见过的类别」，而是**外观相同、可供性不同**的 metamer：仿真水果 vs 真水果、玻璃门 vs 敞开的门、干毛巾 vs 湿毛巾、看起来能坐的纸箱。R69 的流策略会自信地生成一个「对错误物体正确」的动作。
> - 新场景常常不是「换了背景」，而是**度量变了、拓扑没变或拓扑悄悄变了**：地面更滑、光更暗、通道被玻璃封住、镜面制造假可达性。R69 的标定 ECE 与模态权重只在标定域内可信；域一变，证书本身失效，而系统不会知道。
> - 更根本：R68/R69 的所有保证都是**域条件**的。它们从未声明「在哪些物体/场景上有效」。没有作用域的证书，在分布外不是「略微不准」，而是**没有意义**。
>
> 核心命题：**泛化不是「在新数据上表现好」，而是「知道自己的保证在哪里成立，并在边界处安全退化」。** 把物体/场景表示成可迁移不变量（可供性 + 任务相关拓扑），把新颖性拆成外观/可供性/关系三通道，给每张证书附加显式**作用域**，用**干预性证据**（推、抬、敲、照、问）而非被动观察来扩张作用域，扩张不了就退到**域不变安全地板**。命名 **SCOPE-RAS**（Scoped-Certificate, Object/Scene-generalization, Provenance-aware Envelope for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我过去的保证，在这里还算数吗**」——泛化的核心不是看见新事物，而是知道自己保证的边界，并在边界上不装懂。

## 0. 直觉与动机

**灵感 1（物体泛化 = 对外观群取商，而不是记住更多类别）**
直觉：人看到新椅子也知道能坐，不是因为它和训练集里的椅子像素接近，而是因为「支撑面 + 稳定 + 高度合适」这些**可供性**被保留。把物体表示分成（可供性 φ，外观 ψ，运动学/材质 κ），并要求 φ 对光照、纹理、背景、位姿、相机增益等 nuisance 变换不变，泛化就从「覆盖更多类别」变成「在商空间里保持不变量」。这给出一个可证伪的判据：**外观漂移本身不是拒绝的理由；可供性漂移才是。** 这条判据也直接修正了常见做法——把所有 OOD 都当成危险，结果一个换了颜色的杯子就让机器人停机。

**灵感 2（场景泛化 = 保持任务相关拓扑，而不是匹配布局）**
直觉：换一个房间，家具位置全变，但「从 A 到 B 可达、杯子在桌上、门后是通道、这条支撑链不断」这些关系可能不变；反过来，看起来一样的房间可能因为一块玻璃、一滩油、一面镜子而拓扑全变。因此场景泛化应盯住**任务相关拓扑不变量 T(G_s)**（可达分量、包含、支撑、遮挡、连通割），而不是像素或度量坐标。度量/布局变化交给重规划；**拓扑变化**才触发重新评估与降级。这把「场景泛化」从一个感知问题改写成一个带不变量的规划/安全接口问题。

**灵感 3（最危险的不是未知，而是「看起来已知」——可供性 metamer）**
直觉：OOD 检测通常假设「陌生 = 远离训练分布」，但真正致命的是**在传感器/特征空间里与已知样本不可分、却行为不同**的物体：高仿水果、玻璃门、贴了标签的空盒子、干湿难辨的毛巾。本文把它形式化为**可供性 metamer**：h(x)=h(x′) 但 A(x)≠A(x′)。信息论上，任何只依赖 h 的被动策略在这对样本上都有不可约错误率；**要区分它们，必须做干预**（推一下、抬一下、敲一下、照一下）。这把 R69 的「问」从语言/注视扩展到物理系统辨识，也解释了为什么纯表征学习无法保证物体泛化。

**灵感 4（证书必须有作用域——R68/R69 的保证都是域条件的）**
直觉：R68 的标定 ECE、R69 的模态校准与流似然，全部是在某个数据域上估计的。把它们原样搬到新场景，就像拿厨房的秤去称仓库的货：读数还在，意义没了。正确做法不是「再调一个阈值」，而是让证书显式携带 (claim, scope, confidence, expiry, provenance)，并定义组合规则：两张证书只在**作用域交集**上同时有效；交集为空就必须停下/求助。于是「泛化」变成「作用域管理」，而不是「自信地外推」。这也是本轮最重要的理论姿态：**把 R69 的「证书」升级为「带类型的证书」——类型不对，禁止运算。**

**灵感 5（适应很诱人，但没有干预证据的适应只是「信心洗白」）**
直觉：测试时自适应能很快把新物体拟合到很低的训练损失，但它可能只是把错误先验拟合得更自信；更糟的是，若适配器连安全证书一起改，系统会「适应」掉自己的护栏。所以适应必须：只改低秩策略残差、不改安全预测器与证书、有信任域、必须消费干预性证据、可回滚、且**不能自行扩张证书作用域**。扩张作用域的唯一合法货币是「新的干预证据或新标签」，不是更多梯度步。否则 R70 只是在 R69 的「会问的嘴」上再装一个「会自我说服的脑」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SCOPE-RAS 总览）** SCOPE-RAS = (OCF, SGD, NCD, CEE, SCA, DVC, LTA, AGP, DIF, RAS-WM§)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **作用域纪律**：每张证书 J 显式携带作用域 C；x∉C ⇒ J 不可用，控制退到域不变安全地板；
(iii) **干预证据原则**：被动观测只能缩小或维持作用域；扩张作用域必须消费干预/标签证据（定义 318、326）；
(iv) **适应护栏**：适配器只作用于策略条件残差，不改安全预测器/证书，范数受限、可回滚、离线冻结后生效；
(v) **延迟不劣化**：无证书可用时的行为风险不高于任何依赖语义模型的策略（定义 319）。

**定义 311（对象中心因子分解 OCF）** 观测 o 分解为对象槽 {z_i} 与场景图 G_s。z_i = (φ_i, ψ_i, κ_i)，φ_i 为可供性描述子（支撑面、可抓取性、质量/摩擦/关节先验、易碎性），ψ_i 为外观（纹理/颜色/光照响应），κ_i 为运动学类别。设 nuisance 群 G_nuis（光照、纹理、背景、位姿、相机增益）作用在 o 上。定义**对象等价**：x ~_obj x′ ⇔ ∃g∈G_nuis 使 φ(gx)=φ(x′) 且关系角色一致。对象泛化的目标是学习 φ∘g = φ，而不是让 ψ 也变得“更鲁棒”。

**定义 312（新颖性三通道 NCD）** 对当前 x 定义三个不可混用的非一致性分数：
- d_app(x)：外观商空间距离（对 G_nuis 取商后的密度比）；
- d_aff(x)：可供性空间到支持集的距离/密度比（含材质、质量、关节、摩擦）；
- d_rel(x)：场景图到最近受支持关系图的编辑距离（拓扑/关系）。
三者不合成单一标量，而路由到不同响应：d_app → 归一化/忽略；d_aff → 探针/适应/延迟；d_rel → 重规划/保守。定义总新颖性为向量 d(x)=(d_app,d_aff,d_rel)。

**定义 313（可供性 metamer 与不可分下界）** 给定传感器/表征映射 h，称 (x,x′) 为 (ε,δ)-metamer，若 ‖h(x)−h(x′)‖≤ε 且可供性散度 D_A(x,x′)≥δ。记 metamer 集 M_{ε,δ}。对任意仅用 h(x) 的决策规则，在 {x,x′} 等先验上的可供性错误率 ≥ δ/2（Bayes 下界）。若存在干预 u 使 I(A; y_u | do(u), x) ≥ γ，则称 u **γ-可分**该 metamer。**结论：被动泛化有不可约误差地板；干预不是可选项，而是越过该地板的唯一通道。**

**定义 314（能力包络 CEE）** 对管线 Π 与风险阈值 ε_risk，定义能力包络 C_α(Π) = {x : UCB_α(R_Π(x)) ≤ ε_risk}，用分层/Mondrian conformal 在（物体因子 × 场景因子）上估计；非一致性分 s(x)=任务损失，阈值 q_{1−α}；边界裕度 b(x)=q_{1−α}−s(x)。协变量偏移下用加权 conformal，权重 w(x)=p_cur(x)/p_src(x)，有效样本量 n_eff=(Σw)²/Σw²。b(x)≤0 ⇒ x 出包络。

**定义 315（作用域证书代数 SCA）** 证书 J=(claim, C, level 1−α, expiry τ, provenance π, ver)，Valid(J,x) ⇔ Valid_base(J) ∧ x∈C ∧ t<τ。组合 J1⊗J2=(claim1∧claim2, C1∩C2, min level, min τ, π1⊕π2)。若 C1∩C2=∅ 或 min level<τ_conf，组合失败，**不得**用任一单证书替代。此规则把「在厨房标定，在雪地部署」这类错误变成类型错误，而不是调参问题。

**定义 316（域有效性证书 DVC）** 在当前域 D_cur 上检验标定残差的可交换性：加权 ECE_cur、n_eff、以及 φ/ψ/G_s 三通道漂移。判据：若 ECE_cur>τ_ece 或 n_eff<n_min 或残差分布 TV 距离>τ_tv，则 C←C∩C_cur；若为空 ⇒ 证书整体失效、走定义 319。注意：**仅 ψ 漂移不触发失效**（否则外观泛化会被误判为能力丧失）；φ 或 G_s 漂移才触发。

**定义 317（新颖性门控局部适应 LTA）** 适配器 δθ 限低秩 r、仅作用于策略条件/动作头；‖δθ‖_F≤ε_θ；训练必须含 ≥m 次 γ-可分干预探针；在留出探针上验证；若作用域估计变小或 DVC 失效则回滚。实时控制路径不做梯度写；适配在离线/异步完成并以冻结版本生效（继承定义 293-i）。

**定义 318（主动泛化探针 AGP）** 干预动作 u∈𝒰_probe（推、抬、敲、照、换视角、问）。可供性信息增益 VoI_A(u)=H(A|o)−E_{y_u}[H(A|o,y_u)]；选择 u*=argmax[VoI_A(u)−c(u)]，s.t. risk(u)≤ε_p 且 u 过 C-RAS-WM 前缀认证。与 R69 MINT 的区别：MINT 消解「选哪个动作模态」，AGP 消解「这个物体/场景到底是什么可供性」，因此其观测量是物理响应（位移、力、声音、形变），不是语言回答。

**定义 319（延迟与域不变安全地板 DIF）** 若 x∉C 且 DVC 失效且 AGP 无利可图/不安全，则进入 DIF：只允许依赖本体感觉与已知不变约束的动作集 𝒜_DIF（停止、保持、后退、柔顺、限力、移交），其风险 R_DIF≤ε_floor **与物体身份/场景语义无关**。定义延迟算子 Defer，满足：对任意语义策略 π，R_DIF(x) ≤ R_π(x) + B_scope，其中 B_scope 为语义模型在 x 上的作用域误差上界（定义 324）。

**定义 320（场景拓扑不变量 SGD）** 场景图 G_s 的边谓词包括 on/in/reachable/support/occlude/connect。度量形变群 G_met（平移、旋转、尺度、布局重排）作用在节点坐标上。**场景等价**：G_s ~_scn G_s′ ⇔ ∃g∈G_met 使任务相关拓扑不变量 T(G_s)=T(gG_s′)，T 包括可达分量、包含关系、支撑链、连通割。场景泛化 = 保持 T；**拓扑 metamer** 指 T 不同但外观/度量接近（玻璃门、镜面、油污地面）。

**定义 321（泛化溯源图）** 每个泛化决策记录 DAG：传感器证据 → 不变性假设 → 干预探针及其响应 → 作用域证书 → 适配器版本 → 延迟/执行决定。节点带哈希，可回放审计。证书 J_SCOPE 含 provenance_hash。

**定义 322（J_SCOPE 证书）** J_SCOPE=(J_FLUID, C, b(x), d_aff, d_rel, metameric_risk, adapter_ver, n_interventions, DVC, provenance_hash, scope_ver)。Valid ⇔ Valid(J_FLUID) ∧ x∈C ∧ DVC ok ∧ 适配器已认证 ∧ 证据纪律满足。

**定义 323（AIC-SCOPE 威胁模型）** ℰ_SCOPE = ℰ_FLUID × ℰ_novelty，新增：对抗纹理/伪装制造的 metamer、镜面/玻璃/假门制造的场景拓扑欺骗、探针诱发损伤、作用域投毒（污染标定数据抬高包络）、适配器后门、把 OOD 伪装成 ID 的「泛化剧场」。

**定义 324（风险分解与边界主导）** R_total(x) ≤ R_in(x)·1[x∈C] + P_out·R_OOD + R_metamer + R_scope_est；其中 R_scope_est 在边界附近最大。含义：**安全的主导项不是模型误差，而是「包络估计误差」；而包络恰在数据最稀疏的边界最难估计。**

**定义 325（作用域自适应控制律）** λ(x)=max(λ_floor, λ_base(x)+κ_aff·d_aff(x)+κ_rel·d_rel(x))；当 x∈C 时沿用 R69 的 FLUID 控制；当 b(x)≤0 或 DVC 失效时切换 DIF，λ 单调不降。切换需满足无突变条件（继承 R69 定理 17）。

**定义 326（作用域扩张预算 / 无免费泛化公理）** 作用域扩张 ΔC 必须由证据预算 E=(干预次数×可分性×标签信息) 支付：ΔC ⊆ {x: I(A;E|x) ≥ γ}。没有 γ-可分干预证据时，ΔC=∅——系统不得因适配器训练损失下降而扩张作用域。这是定理 19 的公理形式。

## 2. 关键算法骨架

```python
# IP-264 OCF + IP-265 SGD：对象/场景因子化
def factorize(o):
    slots, G_s = object_encoder(o)              # 每槽 (φ 可供性, ψ 外观, κ 运动学)
    phi = {i: slots[i].affordance for i in slots}
    T   = scene_topology(G_s)                   # 可达/包含/支撑/连通
    d   = novelty_channels(o, slots, G_s)       # (d_app, d_aff, d_rel)
    return phi, T, d, G_s

# IP-267 CEE + IP-269 DVC：能力包络与域有效性
def scope_check(M, x, d):
    C, b = M.cee.envelope(x)                    # 分层 conformal
    dvc  = M.dvc.test(residuals=M.last_r_res,
                      phi_drift=d.aff, graph_drift=d.rel)
    C    = C if dvc.ok else C.intersect(dvc.C_cur)
    return C, b, dvc

# IP-270 LTA：干预证据驱动的有界适应
def adapt_if_worth(M, x, d, C):
    if d.aff < TAU_AFF or x in C: return None
    u = M.agp.choose(x)                         # IP-271：推/抬/敲/照/问
    if u is None: return None
    y = M.agp.execute_certified(u)              # 过 C-RAS-WM 认证
    if M.agp.separability(u, y) < GAMMA: return None   # 无 γ-可分证据 → 不扩张作用域
    return M.lta.freeze_update(x, u, y)         # 低秩、信任域、可回滚

# IP-276 主闭环（继承 R69，仅在“证书是否还在作用域内”处插入 SCOPE 层）
def SCOPE_RAS_round(M, o):
    phi, T, d, G_s = factorize(o)
    C, b, dvc = scope_check(M, o, d)
    if not Valid(M.j_scope, o):                 # 出作用域
        if d.aff < TAU_AFF and dvc.psi_only:    # 仅外观漂移 → 仍可执行
            pass
        else:
            u = M.agp.choose(o)
            M.lta.maybe_apply(u)
            if u is None or not M.agp.success:
                return M.dif.act(o)             # IP-272：域不变安全地板
    # 在作用域内：完全复用 R69 FLUID-RAS（定理 18 的“严格包含”）
    k, lam, mode, U = M.fluid_round(o)
    # 作用域感知缩放 + 拓扑变化时缩短认证前缀
    lam = scope_scale(lam, d, b)                # IP-275 控制律
    if d.rel > TAU_REL: k = M.dif.shorten(k)    # 拓扑存疑 → 只执行短前缀
    M.vqa_g.submit_async(d, C, u, provenance=M.prov)
    return k, lam, mode, U
```

## 3. 推导

**引理 19（外观不变性 → 物体泛化界）** 若 φ 对 G_nuis 不变且可供性预测器 L-Lipschitz，则对任意 g∈G_nuis，|R(x)−R(gx)| ≤ L·‖φ(x)−φ(gx)‖ = 0（理想情形），实际有估计误差项 ε_φ。系：**外观 OOD 不应触发延迟；只有 d_aff/d_rel 触发**——这修正了「OOD 即危险」的常见误设，也是 SCOPE 比 R69 更少误停机的来源。

**引理 20（metamer 不可分下界）** 对 (ε,δ)-metamer 对，任何仅用 h(x) 的规则期望可供性错误 ≥ δ/2。证明：两样本在决策规则输入上不可分，最坏先验下必错其一，损失至少 δ/2。系：被动物体泛化存在不可约误差；AGP 的 γ-可分干预是越过该下界的必要证据，**纯表征学习无法消除它**。

**引理 21（作用域组合可靠性）** 若 Valid(J1,x)、Valid(J2,x)，则 Valid(J1⊗J2,x)；且 C1∩C2 非空是组合可用的必要条件。系：多证书系统只在共同有效域内产生联合保证；交集为空必须延迟，不能「加权平均」两个证书——加权平均会让一张失效证书污染一张有效证书。

**引理 22（偏移下标定误差上界）** 设源/当前域边缘分布 TV 距离为 ρ，则 |ECE_cur−ECE_src| ≤ 2ρ + O(√(log(1/δ)/n_eff))。当 n_eff<n_min 时上界超过 τ_ece，DVC 必须收缩作用域。这给定义 316 一个可操作阈值，也解释了为什么「在少量新数据上重新标定」比不标定更危险：n_eff 太小时上界反而更宽。

**定理 18（SCOPE 在包络内严格包含 FLUID-RAS，界外安全退化）** 对 x∈C 且 DVC 通过，SCOPE 的决策与 R69 FLUID 逐指令一致，故风险 ≤R69；对 x∉C 或 DVC 失效，SCOPE 不允许执行未认证语义动作，切换到 DIF，风险 ≤ε_floor。因此 R_SCOPE(x) ≤ R_FLUID(x)（x∈C），且界外不会出现「带着失效证书继续执行」的灾难模式。R69 是本轮在「包络无限大且永不失效」边界上的退化。

**定理 19（适应不能静默扩张作用域）** 在定义 317 的护栏下，若本次适应消费的干预证据可分性 <γ（或没有干预），则认证作用域 C′ ⊆ C；即适配器只能改变 C 内的条件分布，不能把 C 外样本「认证」进来。证明要点：作用域由 conformal 证据与 DVC 决定，适配器不改证书与安全预测器；无 γ-可分证据时定义 326 强制 ΔC=∅。系：**泛化能力只能由新证据购买，不能由梯度步数购买。**

**定理 20（边界延迟的支配性）** 当 b(x)→0 时，R_scope_est 的发散速度不低于 1/b(x)（conformal 边界附近有效样本数趋零），而任何语义策略的风险下界由 R_metamer 决定。故在边界附近，DIF 的常数风险 ε_floor 优于任何「继续用语义模型但调低速度」的策略；延迟不是保守，而是边界处的最优可证行为。

## 6. 本轮最大风险

**一句话**：能力包络与作用域证书是用有限、有偏数据估计的，而**包络边界恰是数据最稀疏、估计最不可靠的地方**——一个「刚好落在估计包络内、实际却在包络外」的新物体/新场景会拿到一张看起来合法的证书；SCOPE-RAS 于是为过度自信的泛化提供了「安全不在场证明」，而延迟又由同一张错误包络门控，系统会在它本该保护的边界上最自信地失败。

**次级风险与缓解**：
1. **metamer 基准覆盖不足**（只测视觉新类，不测可供性同形异义）→ E303/E311 配对基准 + 对抗纹理/材质/透明度分层；
2. **干预本身造成损伤**（推倒、压坏、探针越界）→ 定义 318 认证 + 最小力/位移包络 + E304；
3. **作用域投毒**（污染标定数据让包络膨胀）→ 定义 316 的独立留出集 + 定义 323 威胁模型 + E312；
4. **场景拓扑提取错误**（误把玻璃识别为可通行）→ T(G_s) 显式不确定性 + 保守边谓词 + E310；
5. **适配器回滚延迟**（在线切换出现短暂不一致）→ 离线冻结、双缓冲、定理 17 无突变条件。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** SCOPE-RAS = (OCF, SGD, NCD, CEE, SCA, DVC, LTA, AGP, DIF, RAS-WM§)；零学习写操作继承；作用域纪律（x∉C ⇒ 证书不可用）；干预证据原则（被动观测不能扩张作用域）；适应护栏（只改策略残差、不改证书、可回滚）；延迟不劣化。

**定义 311–312（OCF 与 NCD）** 对象槽 `z=(φ,ψ,κ)`，对象等价 `x~_obj x′ ⇔ ∃g∈G_nuis: φ(gx)=φ(x′)`；新颖性 `d=(d_app,d_aff,d_rel)`，三通道分别路由到忽略、探针/适应/延迟、重规划/保守，不合成标量。

**定义 313（metamer 不可分下界）** `(ε,δ)`-metamer：`‖h(x)−h(x′)‖≤ε` 且 `D_A≥δ`；任何仅用 `h` 的规则错误率 `≥δ/2`；只有 `γ`-可分干预 `I(A;y_u|do(u),x)≥γ` 才能越过下界。

**定义 314（能力包络）** `C_α={x: UCB_α(R_Π(x))≤ε_risk}`，分层/Mondrian conformal 估计，边界裕度 `b(x)=q_{1−α}−s(x)`；加权 conformal 权重 `w=p_cur/p_src`，`n_eff=(Σw)²/Σw²`。

**定义 315（作用域证书代数）** `Valid(J,x) ⇔ Valid_base(J) ∧ x∈C ∧ t<τ`；`J1⊗J2=(claim1∧claim2, C1∩C2, min level, min τ, π1⊕π2)`；交集为空或置信不足 ⇒ 组合失败，禁止单证书替代。

**定义 316（DVC）** 检验标定残差可交换性、`ECE_cur`、`n_eff`、φ/ψ/G_s 漂移；`ECE_cur>τ_ece ∨ n_eff<n_min ∨ TV>τ_tv ⇒ C←C∩C_cur`；为空则证书失效、走 DIF。仅 ψ 漂移不触发失效。

**定义 317（LTA）** 低秩 r 适配器只作用于策略条件/动作头，`‖δθ‖_F≤ε_θ`，必须含 ≥m 次 γ-可分干预，留出探针验证，作用域缩小或 DVC 失效即回滚；实时路径零梯度写。

**定义 318（AGP）** `u*=argmax[VoI_A(u)−c(u)]`，s.t. `risk(u)≤ε_p` 且过 C-RAS-WM 认证；观测量是物理响应（位移/力/声音/形变），区别于 R69 MINT 的语言回答。

**定义 319（DIF）** 出域且无可用证书时，只允许 `𝒜_DIF`（停/保持/后退/柔顺/限力/移交），`R_DIF≤ε_floor` 与物体身份/场景语义无关。

**定义 320（场景拓扑）** 场景图谓词 on/in/reachable/support/occlude/connect；`G_s~_scn G_s′ ⇔ ∃g∈G_met: T(G_s)=T(gG_s′)`；拓扑 metamer 指 T 不同但外观/度量接近（玻璃门、镜面、油污）。

**定义 321–323（溯源/证书/威胁）** 每个泛化决策记录 DAG 并哈希；`J_SCOPE=(J_FLUID,C,b,d_aff,d_rel,metameric_risk,adapter_ver,n_interventions,DVC,provenance_hash,scope_ver)`；`ℰ_SCOPE=ℰ_FLUID×ℰ_novelty`。

**定义 324（风险分解）** `R_total ≤ R_in·1[x∈C] + P_out·R_OOD + R_metamer + R_scope_est`；边界附近 `R_scope_est` 最大——安全主导项是包络估计误差，不是模型误差。

## 3. 关键算法伪代码

```python
# IP-264/265/266：因子化 + 三通道新颖性
def factorize(o):
    slots, G_s = object_encoder(o)                 # (φ 可供性, ψ 外观, κ 运动学)
    T = scene_topology(G_s)                        # 任务相关拓扑
    d = (app_score(o), affordance_score(slots), graph_edit(G_s))
    return slots, T, d, G_s

# IP-267/269：能力包络与域有效性
def scope_check(M, x, d):
    C, b = M.cee.envelope(x)                       # 分层 conformal
    dvc  = M.dvc.test(M.last_r_res, d.aff, d.rel)
    return (C if dvc.ok else C & dvc.C_cur), b, dvc

# IP-270/271：干预证据驱动的有界适应
def adapt_if_worth(M, x, d, C):
    if d.aff < TAU_AFF or x in C: return None
    u = M.agp.choose(x)                            # 推/抬/敲/照/问
    if u is None: return None
    y = M.agp.execute_certified(u)
    if M.agp.separability(u, y) < GAMMA: return None   # 无 γ-可分证据 → 不扩张
    return M.lta.freeze_update(x, u, y)            # 低秩 / 信任域 / 可回滚

# IP-276：主闭环（包络内严格复用 R69 FLUID-RAS）
def SCOPE_RAS_round(M, o):
    slots, T, d, G_s = factorize(o)
    C, b, dvc = scope_check(M, o, d)
    if not Valid(M.j_scope, o):
        if not (d.aff < TAU_AFF and dvc.psi_only): # 非“仅外观漂移”
            u = M.agp.choose(o); M.lta.maybe_apply(u)
            if u is None or not M.agp.success:
                return M.dif.act(o)                # IP-272：域不变安全地板
    k, lam, mode, U = M.fluid_round(o)             # 定理 18：包络内 = R69
    lam = scope_scale(lam, d, b)
    if d.rel > TAU_REL: k = M.dif.shorten(k)       # 拓扑存疑 → 只执行短前缀
    M.vqa_g.submit_async(d, C, u, provenance=M.prov)
    return k, lam, mode, U
```

## 4. 推导

**引理 19（外观不变性 → 物体泛化界）** φ 对 G_nuis 不变且可供性预测器 L-Lipschitz ⇒ `|R(x)−R(gx)|≤L·‖φ(x)−φ(gx)‖`；实际含估计误差 ε_φ。系：外观 OOD 不应触发延迟，只有 d_aff/d_rel 触发。

**引理 20（metamer 不可分下界）** 对 `(ε,δ)`-metamer，任何仅用 `h(x)` 的规则期望可供性错误 `≥δ/2`；被动物体泛化存在不可约误差，AGP 的 γ-可分干预是必要证据。

**引理 21（作用域组合可靠性）** `Valid(J1,x)∧Valid(J2,x) ⇒ Valid(J1⊗J2,x)`；`C1∩C2≠∅` 是组合可用必要条件；交集为空必须延迟，不能加权平均。

**引理 22（偏移下标定误差上界）** `|ECE_cur−ECE_src| ≤ 2ρ + O(√(log(1/δ)/n_eff))`；`n_eff<n_min` 时上界可超过 τ_ece，DVC 收缩作用域。

**定理 18（SCOPE 含 FLUID，界外安全退化）** `x∈C` 且 DVC 通过时逐指令等于 R69，风险 ≤R69；`x∉C` 或 DVC 失效时禁执行未认证语义动作，切 DIF，风险 ≤ε_floor。界外不再出现「带失效证书继续执行」。

**定理 19（适应不能静默扩张作用域）** 护栏下，若适应所消费干预证据可分性 <γ（或无干预），则 `C′⊆C`；适配器只能改 C 内条件分布，不能把 C 外样本认证进来。系：泛化能力只能由新证据购买，不能由梯度步数购买。

**定理 20（边界延迟支配性）** `b(x)→0` 时 `R_scope_est` 发散速度不低于 `1/b(x)`（边界有效样本趋零），而语义策略风险下界由 `R_metamer` 决定；边界附近 DIF 的常数 `ε_floor` 优于任何「减速但继续用语义模型」的策略。

## 7. 本轮最大风险

**一句话**：能力包络与作用域证书由有限、有偏数据估计，而**包络边界恰是数据最稀疏、估计最不可靠之处**——一个「刚好落在估计包络内、实际却在包络外」的新物体/新场景会拿到一张看起来合法的证书；SCOPE-RAS 于是为过度自信的泛化提供「安全不在场证明」，而延迟又由同一张错误包络门控，系统会在它本该保护的边界上最自信地失败。

**次级风险与缓解**：metamer 基准覆盖不足（E303/E311 配对基准 + 材质/透明度/纹理分层）；干预造成损伤（定义 318 认证 + 最小力/位移包络 + E304）；作用域投毒（独立留出集 + 定义 323 威胁模型 + E312）；场景拓扑提取错误（T(G_s) 显式不确定性 + 保守谓词 + E310）；适配器回滚延迟（离线冻结、双缓冲、定理 17 无突变）。
