# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环第 2 轮；本轮灵感：「任务规划」×「推理延迟」）

> R70 把不确定性搬进了显式世界后验 b_t，代价是每一拍都要做预测-更新、流采样、VoI 枚举与边缘化似然。它自己的复杂度表已经露馅：K=1 环路 4.5ms、K=4 达 6.2ms，而 Proto-Val 验收线是 P99<3.5ms——**R70 按自己的标准就已不可行**。这不是调参问题，而是范式问题：它默认「计算永远在线、每拍都算」。
>
> 而前几轮都在优化「孤立的一步决策」。真实决策活在任务里：抓取必须在传送带到达前完成，问句必须在人离开前发出，避让必须在碰撞前 80ms 定稿。R70 自陈的最大风险（后验「自信地错」+ 实时部署放大）本质上是一个**时间风险**：不是不知道，而是**来不及在决策过期前知道**。
>
> 本轮两个灵感正好咬合：
> - **任务规划**给出时间结构——任务 DAG 上的决策节点、截止期、先序约束与关键性 κ；不是每拍都同等重要；
> - **推理延迟**给出计算的代价——任何推理结果都是 o_t 的函数却在 t+δ 执行，于是「算得更多」同时意味着「更接近过期」。计算不是免费的精度，而是一场与时间的交换。
>
> 核心命题：**把「计算」本身变成被规划的资源**——在任务 DAG 上分配带截止期的推理预算，用「计算的价值 VoC」决定何时想 / 想多久 / 何时问 / 何时必须行动；用「决策时效」判定结果是否还可用；昂贵模块只在关键节点触发，并通过投机与流水线隐藏延迟；任何超时都退化为可认证反射（fail-to-reflex，而非 fail-to-unsafe）。命名 **TEMPO-RAS**（Task-level Executive Metareasoning with Predictive-latency Objectives）。
>
> 一句话定位：R69 问「该向谁求证」，R70 问「世界是什么状态」，R71 问「**这些计算还来得及吗、值得现在算吗**」——不确定性不只要被消解，还要**在它过期之前**被消解。

## 0. 直觉与动机

**灵感 1（任务规划 → 不是每个 tick 都值得思考）**
直觉：R70 在控制频率上均匀地跑全套估计与决策，等于假设「每一拍的认知价值相同」。但人类不是这样：走路时不会每一步都重新规划全身，只在岔口、门槛、伸手前才「想一下」。把任务表示为 DAG G=(V,E)，节点是决策/承诺点（抓取、接近人、进入窄道、发出问句），边是先后与数据依赖；每节点带截止期 d_v 与关键性 κ_v（该决策做错对任务成功的敏感度）。于是「思考」从时间上的一张均匀网，变成一个**按节点分配的预算问题**。

**灵感 2（推理延迟 → 每个决定都有保质期）**
直觉：一个在 t 时刻用 o_t 算出、在 t+δ 执行的动作，实际上是关于**预测状态**的动作。计算越多，近似误差越小，但决策越旧：总误差 = 近似误差(ℓ)↓ + 陈旧误差(δ)↑ + 能量/机会成本。它是 U 型的，所以「算到最大」是错的；正确的问题是**在哪里停**。这把延迟从工程噪声提升为一等公民：**延迟不是吞吐指标，而是信息的价格**。

**灵感 3（VoC：VoI 的时间版）**
直觉：R69/R70 的 VoI 问「多一条信息值多少钱」，却没问「买到它要花多少时间、以及这段时间里世界会变成什么样」。理性元推理（Russell–Wefald）的 value-of-computation 正好补这一半：VoC(c) = 预期质量增益 − κ·预期陈旧损失 − 时间/能量成本 − 机会成本。停止规则是内生的：当最好的计算动作 VoC ≤ 0，就停止思考并执行。VoI 是 VoC 在信息动作上的一阶特例——**R71 再次把旧层包含为边界，而不是并列替代**。

**灵感 4（R70 的预算矛盾是结构性提示，不是 bug）**
直觉：与其把 4.5ms 压到 3.5ms（继续在同一范式里挤），不如改变计算的时间分布：**每拍走廉价路径**（反射策略 + 只做 predict 的 BSE，<1.1ms），**昂贵 burst 只在关键节点发生**，并借助投机预计算 + 流水线把这些 burst 藏在运动/等待期间。更妙的是，超时不再是隐形的：跳过 update 只做 predict，会让后验熵按 H[T^δ b_t]−H[b_t] 增长，这个增量被显式计入 λ_floor——**「来不及」被翻译成 R70 已经会处理的熵**。

**灵感 5（三分解：aleatoric / epistemic / temporal）**
直觉：R69 分出「噪声 vs 歧义」，R70 把歧义升级为世界后验熵。但仍漏掉第三种无知：**本来可以知道、却没能在决策过期前知道**。定义 U_τ = H[b^{pred}_{t+δ}] − H[b_t]（时效无知）。它与 U_epi 的区别是因果性的：U_epi 是「信息不存在」，U_τ 是「信息来晚了」。这决定了处置方式：前者去交互/多采样，后者去调度/投机/提前算，二者混为一谈会导致「用更贵的推理去追一个已经过期的答案」。

**灵感 6（交互与调度都是双刃剑 → 新的时间威胁模型）**
直觉：一旦系统按时间分配算力，就有了新的攻击面与失败模式：
- **compute-DoS**：敌人制造歧义，逼系统升 K=4、触发交互，从而拖垮预算（把「不确定性」当武器）；
- **投机投毒**：让预计算的分支总是落空，浪费算力并制造抖动；
- **时序侧信道 / 抖动注入**：利用延迟分布推断内部状态，或让关键节点恰好超时；
- **deadline-induced myopia**：系统学会「永远反射」来刷 deadline 指标，牺牲任务质量；
- **相关失效陷阱**：超时往往发生在世界最糟的时候（歧义大→算得多→更慢→更危险），此时反射回退可能恰好最不安全。所以时间安全必须是**条件安全**（在超时状态分布上），不能是平均安全。

## 1. 形式化定义（增量：定义 331–350）

**定义 331（TEMPO-RAS 总览）** TEMPO-RAS = (TPG, QLC, VoC, AQC, DSL, TSE, TSG, LBP, SPEC, CL, RAS-Baselines†, Proto-Val†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R70 定义 310-i）；
(ii) **时间安全优先于截止期**：任何组件超时/抖动/预算耗尽 ⇒ 退化为可认证反射 π_reflex，**绝不为了赶 deadline 放松安全包络**（fail-to-reflex, not fail-to-unsafe）；
(iii) **计算预算硬约束**：单 tick ≤ b_tick、单节点 ≤ b_node、单任务 ≤ b_task；在线延迟模型必须持续校准，离线延迟表不得作为唯一依据；
(iv) **证据纪律 + 基线纪律**（继承 R70 定义 310-iii）。

**定义 332（任务计划图 TPG）** 任务 = DAG G=(V,E)。节点 v∈V 为决策/承诺点；有向边表示先后与数据依赖。每节点附：截止期 d_v（绝对或相对 t）、关键性 κ_v∈[0,1]（做错该决策对任务成功的敏感度）、进入时的信念 b_v、可行动作集 𝒜_v。反射策略 π_reflex 在每个节点都必须有定义（作为兜底）。

**定义 333（动作-信息-计算三合一动作空间）** 增广动作 ξ = (a, g, c)：任务动作 a∈𝒜_task，信息动作 g∈𝒜_info（继承 R69 定义 294），计算动作 c∈𝒞 = {no-op, BSE-update, FMP-K1, FMP-K4, MINT-VoI, FMA, SPEC(branch)}。每个 c 有延迟分布 p(ℓ|c)（含抖动）、能量成本 e(c) 与占用（阻塞后续计算）。策略在节点上输出的是**计算计划 + 动作计划**，而非单一动作。

**定义 334（决策陈旧度与有效视界）** 决策在 t 计算、在 t+δ_exec 执行。陈旧度 stale(δ) = D_KL(b_{t+δ|t} ‖ b_t)（或等价的动作分布漂移）。有效视界 τ_valid(v) = sup{δ : stale(δ) ≤ ε_stale}。若 δ_exec > τ_valid(v)，该决策失效：不得执行高风险版本，必须重算或退反射。

**定义 335（Anytime 质量-延迟曲线 QLC）** 对每个可中断组件 c，质量 q_c(ℓ) 单调不减、凹（边际递减），q_c(0)=0，以负期望损失计量。在线维护 q_c 及其置信区间（分位数回归）；QLC 的失配（热降频、缓存争用、调度抖动）必须被在线检测并触发保守档。

**定义 336（计算价值 VoC）** 在节点 v、信念 b、策略 π 下：
VoC(c | v,b) = E[ΔQ(c)] − κ_v·E[陈旧损失(ℓ_c+δ_exec)] − λ_e·E[ℓ_c] − Opp(c)，
其中 Opp(c) 为占用计算通道导致后续节点预算下降的机会成本。**停止规则**：当 max_c VoC(c) ≤ 0，停止计算，进入执行。系：VoI 是 VoC 在 c=信息动作、且忽略时间项时的一阶特例。

**定义 337（节点内计算分配 AQC）** 在节点 v，选计算序列 c_{1:m} 最大化 Σ VoC，s.t. Σ E[ℓ_{c_i}] ≤ min(b_node, d_v − t)。当 QLC 凹且计算间依赖可忽略时，这是分数背包：按边际 VoC/时间密度降序贪心即最优；整数约束下贪心误差 ≤ 最大单项。

**定义 338（任务级调度 DSL）** 跨节点分配全局预算：max Σ_v κ_v·q_{c(v)}(ℓ_v)，s.t. Σ_v E[ℓ_{c(v)}] ≤ b_task 且满足 DAG 先序。可行性（能否全部在 d_v 前完成）用 EDF 判定；预算分配本身是 precedence-constrained knapsack。宽度小（|V|≤20）用 DAG 上的 DP 精确求解；宽度大时，若质量函数子模且可行域为背包/拟阵，贪心达 (1−1/e)。

**定义 339（时间安全包络 TSE）** 对每个节点，反射策略 π_reflex 必须在**将要超时的状态分布**上满足 R(π_reflex | v, timeout) ≤ ε_reflex。这是条件安全，不是平均安全。给出两个充分条件之一：(a) 超时事件与危险状态弱相关（协方差有界）；(b) π_reflex 是时延无关安全（无论算多久，其动作始终在安全包络内）。任一不满足 ⇒ 该节点禁止使用长延迟计算。

**定义 340（投机计算与有效延迟）** 在 t 预计算 t+1 的分支（依预测的观测/回答/状态跳变）。命中率 h，预计算成本 ℓ_pre，未命中时追加 ℓ_compute 与回滚 ℓ_rollback。有效延迟 E[ℓ_eff] = ℓ_pre + (1−h)(ℓ_compute+ℓ_rollback)。投机预测器须报告乐观/悲观校准；被投毒（人为压低命中）时自动关闭。

**定义 341（延迟感知信念传播 LBP）** 超时/无预算时跳过 BSE update，只做预测：b^{pred}_{t+δ} = T^δ b_t（R70 定义 313 的转移算子）。时效无知 U_τ(δ) = H[b^{pred}_{t+δ}] − H[b_t] ≥ 0。U_τ 直接进入 λ_floor（与 R70 定义 320 的 α 通道合并：α 通道改用 U_epi+U_τ）。系：延迟不再隐形，而是显式熵增。

**定义 342（时效门 TSG）** 执行前检查：(a) δ_exec ≤ τ_valid(v)；(b) H[b^{pred}_{t+δ}] ≤ τ_entropy；(c) 在线延迟模型未报警（p99 漂移超阈值）。任一不过 ⇒ 该高价值动作不执行，改走 π_reflex 或重新进入 AQC。

**定义 343（计算台账与在线延迟校准 CL）** 逐任务记录 (节点, 计算动作, 预测延迟, 实际延迟, 结果, 是否超时) 的哈希链台账；用分位数回归 + 滑动窗口校准 p(ℓ|c)，检测非平稳（热、争用、网络）并提高保守系数。台账同时用于事后审计与预算漂移检测（前松后紧）。

**定义 344（时间审计 VQAuditor-III）** 审计新增：是否用「永远反射」刷 deadline 指标（myopia）；是否在低 κ 节点浪费预算；超时是否被静默吞掉；投机是否被投毒；是否在 deadline 附近牺牲安全换取守时。结论回灌 CL 与 DSL。

**定义 345（时间对抗集 ℰ_time）** compute-DoS（诱导歧义使 K 升 4 / 触发无效交互）、抖动注入、投机污染、时序侧信道、以及「最后时刻提问」（诱导系统等待一个不会来的回答）。并入 AIC：ℰ_TEMPO = ℰ_BELIEF × ℰ_time。

**定义 346（证书 J_TEMPO）** J_TEMPO = (J_BELIEF, deadline_miss_rate, stale_violations, tse_coverage, voc_ratio, latency_model_ece, compute_ledger_hash, tempo_ver)。Valid ⇔ Valid(J_BELIEF) ∧ deadline_miss ≤ τ_miss ∧ stale_violations = 0 ∧ tse_coverage ≥ 1−γ。

**定义 347（两级时间退避，与风险退避正交）** 不确定性处置有两条独立轴：**知识轴**（U_epi：可交互/多采样消解）与**时间轴**（δ_exec、U_τ：可提前算/投机消解）。任一轴失败都不允许用另一轴「补偿」：不能因为「快」就跳过安全认证，也不能因为「想得清楚」就忽略已经过期。两轴同时满足才升级计算；否则反射。

**定义 348（质量-延迟 Pareto 报告规约）** 所有主张必须报告 (任务成功率, P50/P99 延迟, 计算能量) 的 Pareto 前沿，禁止单点报数；与 R68/R69/R70 在同一 v1 协议下配对比较。

**定义 349（任务关键性 κ 的估计）** κ_v = E_{b_v}[∂ Success / ∂ decision_v]，由计划的敏感性/一阶影响近似；不可靠时取保守上界（宁可高估关键性，避免漏掉关键节点）。

**定义 350（TEMPO 与旧层的严格包含关系）** 当 b_task→∞ 且延迟=0 时，AQC/DSL 退化为「每拍全算」，TEMPO≡BELIEF；当 τ_valid→∞（决策永不过期）时 TEMPO≡FLUID；当全部节点强制 π_reflex 且 κ 相等时 TEMPO≡R68。R68 ⊂ FLUID ⊂ BELIEF ⊂ TEMPO，安全侧逐层不让步。

# IP-275 TPG：任务图与关键性
class TaskPlanGraph:
    def __init__(self, nodes, edges, horizon):
        self.V, self.E = nodes, edges                  # v: d_v, kappa_v, A_v
    def criticality(self, b):                         # 保守上界，宁高勿低
        return {v: sensitivity_upper(v, b) for v in self.V}
    def ready_nodes(self, t, done):
        return [v for v in self.V if v not in done and preds(v) <= done]

# IP-276/277 QLC + VoC：在线质量-延迟曲线与理性停止
class AnyTimeProfiler:
    def __init__(self, quantiles=(0.5, 0.99)):
        self.q = {}                                   # c -> q_c(ell) 凹拟合
        self.lat = {}                                 # c -> p(ell|c) 分位数回归
    def quality(self, c, ell): return self.q[c](ell)
    def latency_p99(self, c): return self.lat[c].quantile(0.99)

def voc(prof, v, b, c, tau_valid, lam_e):
    gain = expected_quality_gain(prof, c)             # Delta Q
    stale = v.kappa * expected_stale_loss(prof, c, b)
    return gain - stale - lam_e * prof.latency_p99(c)

def stop_rule(prof, v, b, cands, tau_valid):
    scored = [(c, voc(prof, v, b, c, tau_valid, LAM_E)) for c in cands]
    best = max(scored, key=lambda kv: kv[1], default=(None, -1))
    return best[0] if best[1] > 0 else None           # VoC<=0 -> 立即执行

# IP-278/279 AQC + DSL：节点内 + 任务级预算分配
def allocate_node(prof, v, b, budget):
    plan, left = [], budget
    while left > 0:
        c = max((c for c in CAND if prof.latency_p99(c) <= left),
                key=lambda c: marginal_voc(prof, v, b, c) / prof.latency_p99(c),
                default=None)
        if c is None or marginal_voc(prof, v, b, c) <= 0: break
        plan.append(c); left -= prof.latency_p99(c)
    return plan                                        # 凹 QLC 下贪心最优(分数)

def allocate_task(prof, G, b, b_task):
    if width(G) <= 20: return dp_exact(prof, G, b, b_task)     # precedence knapsack
    return greedy_submodular(prof, G, b, b_task)               # (1-1/e)

# IP-280/281 TSE + TSG：条件时间安全与时效门
def certified_temporal_exec(action, c, b, t, now, G, M):
    delta = now + M.prof.latency_p99(c) - t
    if delta > M.tau_valid(G.current):
        return M.reflex.execute(b), "stale"
    if entropy(M.bse.predict(b, delta)) > TAU_ENTROPY:
        return M.reflex.execute(b), "entropy"
    if not M.tse.holds(G.current, timeout_dist=M.prof.lat, eps=EPS_REFLEX):
        return M.reflex.execute(b), "tse"                    # 条件安全不成立
    return action, "ok"

# IP-282 LBP：超时时只传播、不更新（把延迟变成熵）
def belief_under_deadline(M, b, o, dt, have_budget):
    if have_budget:
        return M.bse.update(M.bse.predict(b, dt), o)
    b_pred = M.bse.predict(b, dt)                    # 便宜
    M.latency_budget.charge(U_tau=entropy(b_pred) - entropy(b))  # 显式记账
    return b_pred

# IP-283 SPEC：投机分支，命中则隐藏延迟
def speculative(M, v, b, h_hat):
    branch = M.fmp.predict_branch(b)                 # 预计算最可能分支
    if M.spec_poisoned.recent(): return None          # 被投毒即关闭
    return branch if h_hat >= H_MIN else None

# IP-288 TEMPO 主闭环（关键节点 burst，常规拍 reflex）
def TEMPO_RAS_round(M, obs, G, t):
    now = M.clock.now()
    # 0) 常规拍：只 predict + 反射，<1.1ms
    b = M.bse.predict(M.b_prev, now - t)
    # 1) 是否到达决策/承诺节点？
    if G.current not in G.ready_nodes(now, M.done):
        return M.reflex.act(b)                        # 非关键拍不思考
    # 2) 节点内计算分配（VoC 停止）+ 任务级调度余量
    cands = M.prof.all_components()
    plan = M.aqc.allocate_node(M.prof, G.current, b, min(B_NODE, G.deadline(now)))
    if M.dsl.remaining_budget() <= 0: plan = []
    # 3) 执行计算计划；超预算就截断（时间优先）
    for c in plan:
        if M.clock.elapsed() + M.prof.latency_p99(c) > G.deadline(now):
            break
        b = M.exec_compute(c, b, obs)
    # 4) 时效门：还来得及吗？来不及就反射（绝不差一点点地硬上）
    action, why = M.tsg.certified_temporal_exec(
        M.ctrl.propose(b), plan[-1] if plan else None, b, t, now, G, M)
    if why != "ok":
        M.auditor3.log_forced_reflex(G.current, why)
    # 5) 若时间安全且无慢变故障，才允许用信念做风险缩放（继承 R70）
    U_ale = expectation(b, lambda s: trace(obs_noise_cov(s)))
    U_epi = entropy(b)
    U_tau = M.latency_budget.current_utau()
    lam = max(M.efs.risk_scale([U_ale, U_epi, U_tau]),
              lam_floor(U_ale + ALPHA * (U_epi + U_tau)))   # 三分解入风险
    # 6) 投机：为下一节点抢跑（失败只浪费预算，不影响安全）
    M.spec.branch = M.spec.speculative(M, G.next(), b, M.spec.hit_hat())
    M.cl.record(G.current, plan, now, why)
    return action, lam
```

## 3. 推导

**引理 23（Anytime 最优停止）** 设质量 q(ℓ) 凹、非减，q(0)=0；状态漂移速率 ρ（单位时间信念/状态变化），动作损失对状态漂移的斜率 κ。执行年龄 δ 的期望任务损失
L(ℓ) = L_approx(ℓ) + κ·ρ·ℓ + λ_e·ℓ，
其中 L_approx 凸减。则最优计算量 ℓ* 满足 |L'_approx(ℓ*)| = κρ + λ_e；且当 |L'_approx(0)| < κρ + λ_e 时，**最优是不算**（直接反射）。系：延迟高/世界变化快时，「多算」严格劣于「早做」；这解释了 R70 在 4.5ms 下为何越算越差。

**引理 24（有效视界与陈旧误差界）** 若信念漂移满足 D_KL(b_{t+δ|t}‖b_t) ≤ ρ_b·δ，且动作损失对信念为 κ·L_b-Lipschitz，则执行年龄 δ 的决策超额损失 ≤ κ·L_b·√(2ρ_b·δ)（Pinsker 型），更粗的线性界为 ≤ κ·L_b·ρ_b·δ。取 ε_stale 得 τ_valid = ε_stale/(κ L_b ρ_b)。系：τ_valid 可在线估计，直接给出 TSG 的门限。

**引理 25（两级分配的近似保证）** (a) 节点内：QLC 凹 ⇒ 分数背包，按边际 VoC/时间贪心最优；整数时误差 ≤ 最大单项质量。(b) 任务级：precedence-constrained knapsack 一般 NP-hard；宽度 ≤20 时 DAG-DP 精确；若质量函数子模且可行域为背包/拟阵，贪心达 (1−1/e)。(c) 可行性：可抢占且释放/截止已知时，EDF 在「全部按时」判定上最优。系：R70 的「均匀每拍全算」在 b_task 有限时甚至不可行，而 TEMPO 有可行性与近似保证。

**引理 26（投机加速与浪费上界）** 记预计算成本 ℓ_p、命中率 h、未命中追加 ℓ_c+ℓ_r。则 E[ℓ_eff] = ℓ_p + (1−h)(ℓ_c+ℓ_r)。相对纯反应式（ℓ_c）的加速条件为 ℓ_p + (1−h)(ℓ_c+ℓ_r) < ℓ_c，即 h > (ℓ_p + ℓ_c + ℓ_r − ℓ_c)/(ℓ_c+ℓ_r)。期望浪费算力 = (1−h)·ℓ_p，可被 b_task 截断。系：投毒使 h↓ 时，投机自动变为净损失，故需命中率校准与投毒检测（定义 340、345）。

**引理 27（延迟-认识对偶）** 跳过 BSE update 仅做 predict 时，时效无知 U_τ = H[T^δ b_t] − H[b_t] ≥ 0；若转移算子对噪声注入为 ρ_b-扩张，则 U_τ ≤ δ·ρ_b·C。**U_τ 是「被延迟偷走的认识」的可观测量**：任何由算力不足/被拖慢造成的延迟都会抬高 U_τ，因此 U_τ 的异常增长可作为时序攻击（compute-DoS、抖动注入）的检测信号，正如 R68 的 Δa 之于缓变故障。系：延迟第一次进入不确定性账本，而不是藏在工程指标里。

**定理 20（TEMPO 严格包含 BELIEF/FLUID/R68）** 在 A102–A105（QLC 凹且在线可校准；信念漂移有界；TSE 成立；κ 估计为保守上界）下，TEMPO 的期望任务损失 ≤ BELIEF ≤ FLUID ≤ R68；且当 b_task→∞、延迟=0 时逐指令等于 BELIEF，当 τ_valid→∞ 时等于 FLUID，当全反射时等于 R68。安全侧不做任何让步，效率侧获得「按关键性分配预算 + 投机隐藏延迟」的双重收益。

**定理 21（时间安全与无突变）** 若 TSG 在每次执行前强制 δ_exec ≤ τ_valid、H[b^pred] ≤ τ_entropy，且每个节点的 π_reflex 满足 TSE（定义 339），则任一超时/抖动/预算耗尽事件都以概率 ≥ 1−γ 执行风险 ≤ ε_reflex 的反射动作，控制连续、无突变；deadline miss 不改变安全包络，只降低任务质量。注：该保证是**条件**的——若「超时」与「危险」正相关，TSE 必须用保守上界 ε_reflex，否则保证失效（见 §6）。

# IP-275 TPG：节点价值与就绪判定
class TaskPlanGraph:
    def __init__(self, nodes, edges):
        self.V, self.E = nodes, edges                 # v: d_v, kappa_v, A_v
    def criticality(self, b):
        return {v: sensitivity_upper(v, b) for v in self.V}   # 宁高勿低
    def ready_nodes(self, t, done):
        return [v for v in self.V if v not in done and preds(v) <= done]

# IP-276/277 QLC + VoC：在线曲线与理性停止
class AnyTimeProfiler:
    def quality(self, c, ell): return self.q[c](ell)          # 凹拟合
    def latency_p99(self, c): return self.lat[c].quantile(0.99)

def voc(prof, v, b, c):
    return (expected_quality_gain(prof, c)
            - v.kappa * expected_stale_loss(prof, c, b)
            - LAM_E * prof.latency_p99(c)
            - opportunity_cost(c))

def stop_rule(prof, v, b, cands):
    best = max(cands, key=lambda c: voc(prof, v, b, c), default=None)
    return best if best and voc(prof, v, b, best) > 0 else None

# IP-278/279 AQC + DSL：预算分配
def allocate_node(prof, v, b, budget):
    plan, left = [], budget
    while left > 0:
        c = max((c for c in CANDS if prof.latency_p99(c) <= left),
                key=lambda c: marginal_voc(prof, v, b, c) / prof.latency_p99(c),
                default=None)
        if c is None or marginal_voc(prof, v, b, c) <= 0: break
        plan.append(c); left -= prof.latency_p99(c)
    return plan

def allocate_task(prof, G, b, b_task):

    return greedy_submodular(prof, G, b, b_task)              # (1-1/e)

# IP-280/281 TSE + TSG：条件时间安全与时效门
def certified_temporal_exec(action, c, b, t, now, G, M):
    delta = now + M.prof.latency_p99(c) - t
    if delta > M.tau_valid(G.current):          return M.reflex.act(b), "stale"
    if entropy(M.bse.predict(b, delta)) > TAU_ENTROPY: return M.reflex.act(b), "entropy"
    if not M.tse.holds(G.current, M.prof.lat, EPS_REFLEX): return M.reflex.act(b), "tse"
    return action, "ok"

# IP-282 LBP：超时只传播不更新，延迟变熵
def belief_under_deadline(M, b, o, dt, have_budget):
    if have_budget:
        return M.bse.update(M.bse.predict(b, dt), o)
    b_pred = M.bse.predict(b, dt)
    M.budget.charge_utau(entropy(b_pred) - entropy(b))
    return b_pred

# IP-283 SPEC：投机分支，命中藏延迟，投毒即关
def speculative(M, v, b):
    if M.spec_poisoned.recent(): return None
    return M.fmp.predict_branch(b) if M.spec.hit_hat() >= H_MIN else None

# IP-288 TEMPO 主闭环
def TEMPO_RAS_round(M, obs, G, t):
    now = M.clock.now()
    b = M.bse.predict(M.b_prev, now - t)                 # 常规拍：便宜
    if G.current not in G.ready_nodes(now, M.done):
        return M.reflex.act(b)
    plan = M.aqc.allocate_node(M.prof, G.current, b,
                               min(B_NODE, G.deadline(now)))
    if M.dsl.remaining_budget() <= 0: plan = []
    for c in plan:
        if M.clock.elapsed() + M.prof.latency_p99(c) > G.deadline(now): break
        b = M.exec_compute(c, b, obs)
    action, why = M.tsg.certified_temporal_exec(
        M.ctrl.propose(b), plan[-1] if plan else None, b, t, now, G, M)
    if why != "ok":
        M.auditor3.log_forced_reflex(G.current, why)
    U_ale = expectation(b, lambda s: trace(obs_noise_cov(s)))
    U_epi = entropy(b); U_tau = M.budget.current_utau()
    lam = max(M.efs.risk_scale([U_ale, U_epi, U_tau]),
              lam_floor(U_ale + ALPHA * (U_epi + U_tau)))
    M.spec.branch = speculative(M, G.next(), b)
    M.cl.record(G.current, plan, now, why)
    return action, lam
```

## 4. 推导

**引理 23（Anytime 最优停止）** 凹 q(ℓ)，漂移速率 ρ，损失 L(ℓ)=L_approx(ℓ)+κρℓ+λ_eℓ。最优 ℓ* 满足 |L'_approx(ℓ*)|=κρ+λ_e；若 |L'_approx(0)|<κρ+λ_e，最优是不算。系：延迟高/世界快时，「多算」严格劣于「早做」。

**引理 24（有效视界）** 漂移 D_KL ≤ ρ_bδ、损失 κL_b-Lipschitz ⇒ 陈旧超额损失 ≤ κL_b√(2ρ_bδ)；取 ε_stale 得 τ_valid。系：τ_valid 可在线估计，直接给 TSG 门限。

**引理 25（两级分配近似保证）** 节点内分数背包贪心最优（整数误差 ≤ 最大单项）；任务级 precedence knapsack NP-hard，小宽度 DP 精确，子模+背包/拟阵贪心 (1−1/e)；可抢占 EDF 判可行性最优。系：R70 的「均匀每拍全算」在 b_task 有限时可能不可行。

**引理 26（投机界）** E[ℓ_eff]=ℓ_p+(1−h)(ℓ_c+ℓ_r)；加速条件 ℓ_p+(1−h)(ℓ_c+ℓ_r)<ℓ_c；期望浪费 (1−h)ℓ_p，可被 b_task 截断。投毒 h↓ ⇒ 投机变净损失，须校准与检测。

**引理 27（延迟-认识对偶）** 跳过 update 只 predict 时 U_τ=H[T^δb_t]−H[b_t]≥0；若转移 ρ_b-扩张则 U_τ≤δ·ρ_b·C。故 U_τ 可作为 compute-DoS/抖动注入的检测信号，如同 Δa 之于缓变故障。系：延迟进入不确定性账本。

**定理 20（严格包含）** A102–A105 下，TEMPO 期望任务损失 ≤ BELIEF ≤ FLUID ≤ R68；当 b_task→∞、延迟=0 时逐指令等于 BELIEF，τ_valid→∞ 时等于 FLUID，全反射时等于 R68。

**定理 21（时间安全与无突变）** TSG 强制 δ_exec≤τ_valid、H[b^pred]≤τ_entropy，且每节点 π_reflex 满足 TSE ⇒ 超时/抖动/预算耗尽以概率 ≥1−γ 执行风险 ≤ ε_reflex 的反射动作，控制连续、无突变。保证是**条件**的：若超时与危险正相关，TSE 必须用保守上界。

## 7. 本轮最大风险

**一句话**：TEMPO-RAS 把全部收益押在「在线延迟模型与 QLC 可信、且反射回退在**发生超时的那些状态**里仍安全」——但超时与危险往往正相关（歧义大→算得多→更慢→世界更危险），fail-to-reflex 可能恰在最危险时最不可靠；一旦热降频、缓存争用或对抗性抖动使延迟非平稳，调度器就会把预算错配到错误节点，系统或错过截止期、或用「永远反射」刷绿指标，而 U_τ 只能事后显示「来不及」，不能替你赶上。
