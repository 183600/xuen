# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「低成本方案」×「Gazebo」）

> 第 54 轮把技能组合提升为“动作空间剖面 + 云边协同 + 动作-鲁棒性双证书”，但其 soundness 的第一块基石是 `α_S` 的**完备采样**，而真实世界采样成本极高。本轮引入开源物理仿真器 Gazebo 作为**低成本证据层**，把问题从“如何采得更全”改写为“**如何在固定预算下把证据分配到最需要保真的动作单元**”。核心矛盾：H22：高保真真机证据昂贵到无法覆盖 `A_T`，而低价仿真证据存在 sim-real gap，直接用它判兼容会产生虚假覆盖；H23：“低成本”若只降低采样成本、不显式建模保真度与差距，会把失败从仿真阶段推迟到部署阶段，形成**假节省**；H24：在预算 B 下，证据层级、动作单元与证书强度之间缺少可优化的联合分配律。

## 0. 直觉与动机

**灵感 1（证据分层 → 把“保真度”做成可购买的商品）**
直觉：不要把仿真与真机看作二元对立，而应看作一条**证据价格阶梯**：E0 解析/几何可达性（几乎免费）→ E1 Gazebo-Lite（无头、简化传感器、低物理步长，便宜）→ E2 Gazebo-full + HIL（中等）→ E3 真机（昂贵）。每个动作单元 `a` 只需买到“够用”的保真度，而不是一律买最贵。这样，预算被花在**证书边际收益最高**的单元上。

**灵感 2（Gazebo 动作剖面 → 用域随机化换置信区间）**
直觉：Gazebo 的最大价值不是“一次仿真很准”，而是**廉价地做大量域随机化 rollout**。对每个动作单元采样 N 次物理参数/摩擦/传感噪声，得到经验可行率 `α_S^G(a)` 与 Wilson 置信区间。仿真不保证无偏，但它能把“方差”压得足够小；偏差则交给下一层的差距账本处理。

**灵感 3（仿真-现实差距账本 → 用少量真机样本给仿真“打折”）**
直觉：在少数真机可测的锚点单元上测量 `g(a)=|α^G(a)-α^R(a)|`，再用 Lipschitz/局部邻域把差距外推到未测单元，得到保守上界 `ĝ(a)`。证书判据从 `α^G ≥ θ_cov` 改为 `α^U = clip(α^G + ĝ + CI) ≥ θ_cov`。**宁可欠估计兼容性，也不要用仿真的乐观均值去承诺部署。**

**灵感 4（Gazebo-Lite 边端预演 → 便宜的部署前否决器）**
直觉：边端不必跑完整 Gazebo；可在云/边工作站上跑**无头轻量数字孪生**，把云端计划 `P_c` 与边端细化 `P_e=γ_ce(P_c)` 先在 Gazebo-Lite 中预演，提前否决动作错配或 `ρ_e<ρ_min` 的路径，并签发“临时分层证书”。真机与 HIL 只用于抽检与差距锚点，而不是全量验证。

**灵感 5（低成本证据分配 → 预算约束下的子模最大化）**
直觉：每个 (动作单元, 证据层级) 的采样都只是**降低该单元证书置信半径**的边际收益，且收益递减。于是自然写成带预算的子模最大化/背包问题，用贪心拿到 `1-1/e` 近似。这把“低成本方案”从口号变成可求解的优化对象，并允许画出 **成本-保证概率 Pareto 前沿**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证据层级格）**
证据层级 `𝔼 = {E0,E1,E2,E3}`，分别对应解析界、Gazebo-Lite、Gazebo-full+HIL、真机。每层 `i` 具有单位成本 `c_i` 与保真度 `φ_i ∈ (0,1]`，满足 `0=c_0 < c_1 < c_2 < c_3` 且 `φ_0 ≤ φ_1 ≤ φ_2 ≤ φ_3 = 1`。证据算子
```
Ev_i : (S, a) ↦ (α̂_i(a), [l_i(a), u_i(a)], N_i(a))
```
其中 `α̂_i` 为该层估计，`[l_i,u_i]` 为置信区间。**保真域** `F_i = { a | ĝ_S(a) ≤ γ }`。

**定义 122（Gazebo 动作剖面与置信区间）**
在域随机化分布 `θ ∼ D_θ` 下执行 N 次 Gazebo rollout：
```
α_S^G(a) = (1/N) Σ_{k=1}^{N} 1[ feasible(rollout_k(S,a,θ_k)) ]
```
以 Wilson 区间给出 `[l_N(a), u_N(a)]`。**校准剖面**取下置信界 `α_S^- = l_N(a)`，用于任何“必须为真”的判据。

**定义 123（仿真-现实差距账本）**
在真机锚点集 `A_R ⊆ A_T` 上测得
```
g_S(a) = |α_S^G(a) - α_S^R(a)|,  a ∈ A_R
```
对未测单元用 Lipschitz 外推得到上界
```
ĝ_S(a) = min{1, max_{a'∈A_R, ||a-a'||≤k·h} (g_S(a') + L_g·||a-a'||)}
```
**保守可用剖面**
```
α_S^U(a) = clip( α_S^- (a) + ĝ_S(a), 0, 1 )
```
只有当 `α_S^U(a) ≥ θ_cov` 时，才承认动作 `a` 被技能覆盖。

**定义 124（低成本证据分配 LCE）**
给定动作单元集合 `C = A_T`、层级 `𝔼`、预算 `B`，分配 `x_{a,i} ∈ {0,1}`：
```
max_{x}  Σ_{a∈A_T} U_a( { (i) | x_{a,i}=1 } )
s.t.     Σ_{a,i} c_i·x_{a,i} ≤ B,
         ∀ a: width(α_S^U(a)) ≤ ε_a  required only for a∈A_T^crit,
         ∀ a: x_{a,i}=1 时 i 层证据 append-only.
```
其中 `U_a` 为“证书置信半径缩减量”，对证据集合单调且子模。贪心按 `ΔU/c_i` 排序，得 `(1-1/e)` 近似。

**定义 125（分层证据证书 TEC）**
在第 54 轮联合证书 `J=(ρ,A_cert,γ_ce,δ_a,evidence)` 上增加证据维度：
```
TEC = ( J, e_min, N_eff, ĝ_max, φ_min, C_spent, A_crit )
```
- `e_min = min_{a∈A_crit} max{ i | x_{a,i}=1 }` 为关键单元的最低保真层级；
- `N_eff` 为有效独立样本数（去相关后）；
- `ĝ_max = max_{a∈A_crit} ĝ_S(a)`；
- `φ_min` 为所用证据层的最低保真度；
- `C_spent ≤ B` 为实际成本。
**部署判据**更新为：`J` 在 `α^U` 下成立，且 `e_min ≥ e_req`、`φ_min ≥ φ_req`、`ĝ_max ≤ γ`、`C_spent ≤ B`。

**定义 126（成本感知可靠性界）**
若每个关键单元用 `N_a` 次独立 Gazebo rollout、Hoeffding 半径 `ε_a`，差距上界偏差 `β_g = P(ĝ < g)`，则
```
P_success ≥ 1 - Σ_d (1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(compat(α^U_Si, α^U_Sj) < θ_a)
            - β_g - Σ_{a∈A_crit} 2·exp(-2 N_a ε_a²)
```
且总成本 `C = Σ_{a,i} c_i x_{a,i} ≤ B`。该界明确显示：**降低成本只能通过减小 `N_a` 或降低层级来换，代价直接出现在指数惩罚项与 β_g 上。**

## 2. 关键算法 伪代码

### IP-121 GAP（Gazebo Action Profiler）

```python
def gazebo_profile(skill, A_cells, N, dr_dist, gz_world):
    alpha = {}
    for a in A_cells:
        succ = 0
        for k in range(N):
            theta = dr_dist.sample()
            ok = gz_world.rollout(skill, a, theta, headless=True)
            succ += int(ok)
        l, u = wilson_interval(succ, N)   # 下界用于保守判据
        alpha[a] = {'hat': succ/N, 'lo': l, 'hi': u, 'N': N}
    return alpha
```

### IP-122 GSL（Gap-Sensitive Ledger）

```python
def update_gap_ledger(alpha_sim, real_samples, L_g, radius):
    ledger = {}
    for a, r in real_samples.items():
        ledger[a] = abs(alpha_sim[a]['hat'] - r)
    def gap_upper(a):
        near = [a2 for a2 in ledger if dist(a, a2) <= radius]
        if not near:
            return 1.0                      # 无锚点 -> 最保守
        return min(1.0, max(ledger[a2] + L_g*dist(a, a2) for a2 in near))
    alpha_U = {a: clip(alpha_sim[a]['lo'] + gap_upper(a), 0, 1) for a in alpha_sim}
    return ledger, alpha_U
```

### IP-123 LCE（Low-Cost Evidence Allocator）

```python
def allocate_evidence(A_crit, tiers, budget, U):
    alloc, spent = {}, 0.0
    # 每个 (cell, tier) 的边际收益 / 成本；U 子模 -> 贪心
    candidates = [(a, i) for a in A_crit for i in tiers if i > 0]
    while True:
        best, best_ratio = None, 0.0
        for (a, i) in candidates:
            if (a, i) in alloc: continue
            gain = U.marginal_gain(a, alloc.get(a, []), i)
            ratio = gain / tiers[i].cost
            if ratio > best_ratio:
                best, best_ratio = (a, i), ratio
        if best is None or spent + tiers[best[1]].cost > budget:
            break
        alloc.setdefault(best[0], []).append(best[1])
        spent += tiers[best[1]].cost
    return alloc, spent
```

### IP-124 GDT（Gazebo-Lite Edge Digital Twin）

```python
def edge_precheck(P_c, gamma_ce, gz_lite, rho_min, tec_budget):
    P_e, reports = [], []
    for sid, a_c in P_c:
        s = skill_lib[sid]
        a_e = gamma_ce(a_c)
        alpha_U = s.alpha_U.get(a_e, 0.0)
        if alpha_U < theta_cov:
            return ('reject', 'uncovered_under_upper_bound', a_e)
        rho_sim = gz_lite.estimate_robustness(s, a_e, N=tec_budget.n_lite)
        if min(rho_sim.values()) < rho_min:
            reports.append(('rho_warn', sid, a_e, rho_sim))
        P_e.append((sid, a_e, alpha_U, rho_sim))
    return ('ok', P_e, reports)
```

### IP-125 TEC（Tiered Evidence Certificate）

```python
def tiered_certificate(J, alloc, tiers, alpha_U, gap_ledger, A_crit, B):
    C_spent = sum(tiers[i].cost for a in alloc for i in alloc[a])
    if C_spent > B:
        return ('reject', 'budget_exceeded', C_spent)
    e_min = min(max(alloc.get(a, [0])) for a in A_crit)
    phi_min = min(tiers[e_min].fidelity, min(tiers[i].fidelity for a in alloc for i in alloc[a]))
    gap_max = max(gap_ledger.gap_upper(a) for a in A_crit)
    if e_min < tiers.e_req or phi_min < tiers.phi_req or gap_max > tiers.gamma:
        return ('reject', 'evidence_insufficient', e_min, phi_min, gap_max)
    J_U = J.with_profile(alpha_U)          # 用保守剖面重验兼容性与覆盖
    if not J_U.deployable():
        return ('reject', 'certificate_fails_under_upper_bound')
    return ('ok', TEC(J_U, e_min, N_eff=alloc.min_n_eff(), gap_max, phi_min, C_spent, A_crit))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GAP | O(|A_crit|·N·T_rollout) | O(|A_crit|) | 域随机化覆盖真实分布、Wilson 下界 |
| GSL | O(|A_crit|·|A_R|) | O(|A_R|) | 锚点充分、Lipschitz 常数 sound |
| LCE | O(|A_crit|·|𝔼|·log(...)) 贪心 | O(|A_crit|·|𝔼|) | 子模性、预算闭合 |
| GDT | O(|P_c|·N_lite·T_rollout) | O(|P_c|) | Lite 模型与全模型偏差有界 |
| TEC | O(|A_crit|·|𝔼|) | O(|A_crit|) | 用 α^U 而非 α^G 判定 |

**正确性定理（Low-Cost Evidence Soundness, LCES）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** 真实参数分布落在域随机化分布 `D_θ` 的 Wasserstein 半径 `W_0` 内；**(A30)** `g_S` 在动作空间上 `L_g`-Lipschitz；**(A31)** Gazebo-Lite 与 Gazebo-full 的鲁棒性估计偏差 ≤ `β_lite`；**(A32)** 预算与回传满足 `C ≤ B`、`τ_loop` 约束。
则对任一通过 TEC 的计划：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(compat(α^U)<θ_a) - β_g - β_lite
            - Σ_{a∈A_crit} 2·exp(-2 N_a ε_a²)
```
关键点：**兼容性判据使用 α^U，故 sim-real gap 被显式计入保证下界；低成本只影响界，不影响 sound 的方向。**

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 域随机化分布错配，Gazebo 偏差被低估 | 高 | Wasserstein 覆盖检验 + 真机锚点强制抽检 + `α^U` 下界 |
| 差距账本外推失真（锚点过稀） | 高 | 邻域覆盖检查、无锚点默认 `ĝ=1`、主动选锚点 |
| Gazebo-Lite 与全模型物理断层 | 高 | Lite 层仅做否决不做承诺、层级偏差标定 `β_lite` |
| “低成本”变成假节省 | 高 | 成本-保证 Pareto 显式报告，禁止只报成本 |
| Gazebo/ROS 工具链集成成本被忽视 | 中 | 固定版本容器、无头 CI、离线资产缓存 |
| `α^U` 过保守导致可行组合锐减 | 中 | 差距锚点主动扩展 + 分层放宽 θ_cov 的可证配置 |

## 6. 本轮最大风险

**一句话**：本轮把 Gazebo 变成可购买的“低成本证据层”，并用差距账本与 `α^U` 保守上界维持 soundness，但其全部价值都押在**域随机化分布对真实分布的覆盖**与**差距账本的 Lipschitz 外推**上；一旦 DR 分布错配或锚点过稀，低成本仿真会系统性地低估 sim-real gap，使证书在仿真中更“好看”、在真机上更“易碎”，因此必须以 Wasserstein 覆盖检验、无锚点默认最保守、以及成本-保证 Pareto 作为三道硬护栏，绝不允许用仿真均值直接替换上界。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim-Lite（GAP×GSL×LCE×GDT×TEC）

> 承接第 54 轮产物 v31。第 54 轮的 `α_S` 动作剖面要求完备采样，真机成本不可承受；本轮以开源 Gazebo 为**低成本证据层**，增加“证据分层—差距账本—预算分配—边端预演—分层证书”五算子：
> - **GAP（Gazebo Action Profiler）**：用域随机化 rollout 估计动作剖面与 Wilson 置信区间；
> - **GSL（Gap-Sensitive Ledger）**：少量真机锚点 + Lipschitz 外推，构造保守上界 `α^U`；

> - **GDT（Gazebo-Lite Edge Digital Twin）**：边端无头轻量孪生，部署前否决器；
> - **TEC（Tiered Evidence Certificate）**：把证据层级、有效样本、差距上界、成本写入证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120 以纳入证据维度。核心立场：**低成本只允许降低样本数与层级，不允许放宽证书方向；一切判据使用保守上界 `α^U`。**

## 2. 关键算法 伪代码

### IP-121 GAP

```python
def wilson_interval(k, n, z=1.96):
    p = k / n
    den = 1 + z*z/n
    mid = (p + z*z/(2*n)) / den
    half = z * ((p*(1-p)/n + z*z/(4*n*n)) ** 0.5) / den
    return max(0.0, mid-half), min(1.0, mid+half)

def gazebo_profile(skill, A_cells, N, dr_dist, gz_world):
    out = {}
    for a in A_cells:
        k = sum(int(gz_world.rollout(skill, a, dr_dist.sample(), headless=True))
                for _ in range(N))
        lo, hi = wilson_interval(k, N)
        out[a] = {'hat': k/N, 'lo': lo, 'hi': hi, 'N': N}
    return out
```

```python
def update_gap_ledger(alpha_sim, real_samples, L_g, radius):

        if not near:
            return 1.0
        return min(1.0, max(ledger[b] + L_g * dist(a, b) for b in near))

    alpha_U = {a: clip(alpha_sim[a]['lo'] + gap_upper(a), 0.0, 1.0)
               for a in alpha_sim}
    return ledger, alpha_U
```

### IP-123 LCE

```python
def allocate_evidence(A_crit, tiers, budget, U):
    alloc = {a: [0] for a in A_crit}       # 每单元至少 E0 解析界
    spent = 0.0
    while True:
        best, best_ratio = None, 0.0
        for a in A_crit:
            for i in range(1, len(tiers)):
                if i in alloc[a]:
                    continue
                gain = U.marginal_gain(a, alloc[a], i)   # 子模收益
                ratio = gain / tiers[i].cost
                if ratio > best_ratio:
                    best, best_ratio = (a, i), ratio
        if best is None or spent + tiers[best[1]].cost > budget:
            break
        alloc[best[0]].append(best[1])
        spent += tiers[best[1]].cost
    return alloc, spent
```

### IP-124 GDT

```python
def edge_precheck(P_c, gamma_ce, gz_lite, alpha_U_lib, rho_min, n_lite):
    P_e, warns = [], []
    for sid, a_c, theta_cov in P_c:
        a_e = gamma_ce(a_c)
        aU = alpha_U_lib[sid].get(a_e, 0.0)
        if aU < theta_cov:
            return ('reject', 'uncovered_under_upper_bound', sid, a_e, aU)
        rho_sim = gz_lite.estimate_robustness(sid, a_e, N=n_lite)  # headless
        if min(rho_sim.values()) < rho_min:
            warns.append(('rho_warn', sid, a_e, rho_sim))
        P_e.append((sid, a_e, aU, rho_sim))
    return ('ok', P_e, warns)
```

### IP-125 TEC

```python
def tiered_certificate(J, alloc, tiers, alpha_U, gap_upper, A_crit, B):
    C_spent = sum(tiers[i].cost for a in alloc for i in alloc[a])
    if C_spent > B:
        return ('reject', 'budget_exceeded', C_spent)
    e_min = min(max(alloc[a]) for a in A_crit)
    phi_min = min(tiers[e_min].fidelity,
                  min(tiers[i].fidelity for a in alloc for i in alloc[a]))
    gap_max = max(gap_upper(a) for a in A_crit)
    if e_min < tiers.e_req or phi_min < tiers.phi_req or gap_max > tiers.gamma:
        return ('reject', 'evidence_insufficient', e_min, phi_min, gap_max)
    J_U = J.with_profile(alpha_U)              # 关键：用上界重验
    if not J_U.deployable():
        return ('reject', 'fails_under_upper_bound')
    return ('ok', TEC(J_U, e_min, alloc.min_n_eff(), gap_max,
                      phi_min, C_spent, A_crit))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GAP | O(|A_crit|·N·T_rollout) | O(|A_crit|) | 域随机化覆盖、Wilson 下界 |
| GSL | O(|A_crit|·|A_R|) | O(|A_R|) | 锚点充分、`L_g` sound、无锚点默认 1 |
| LCE | O(|A_crit|·|𝔼|·K)（K 次贪心） | O(|A_crit|·|𝔼|) | 子模性 → `1-1/e`，预算闭合 |
| GDT | O(|P_c|·N_lite·T_rollout) | O(|P_c|) | Lite 只否决不承诺，`β_lite` 标定 |
| TEC | O(|A_crit|·|𝔼|) | O(|A_crit|) | 判据用 `α^U`，证据层级/差距/成本三闭合 |

**正确性定理（Low-Cost Evidence Soundness, LCES）**
承接 (A26)–(A28)；新增 **(A29)** 真参分布落在 `D_θ` 的 Wasserstein 半径 `W_0` 内；**(A30)** `g_S` 为 `L_g`-Lipschitz；**(A31)** Lite 与 full 的 `ρ` 偏差 ≤ `β_lite`；**(A32)** `C_spent ≤ B` 且回传满足 `τ_loop`。则通过 TEC 的计划满足：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(compat(α^U)<θ_a) - β_g - β_lite
            - Σ_{a∈A_crit} 2·exp(-2 N_a ε_a²)
```
**推论（低成本不破 sound）**：降低层级或样本数只会增大最后三项（`β_g`、指数项、`β_lite`），不会改变“用上界判定”的方向；因此预算 B 的收缩表现为保证下界的下降，而非证书从假变真。

## 6. 本轮最大风险

**一句话**：低成本证据层的 soundness 完全押在 **DR 分布覆盖真实分布** 与 **差距账本 Lipschitz 外推** 两个假设上；一旦二者失守，Gazebo 会系统性低估 sim-real gap，让证书在仿真中更乐观、在真机上更脆弱，故必须以 Wasserstein 覆盖检验、无锚点默认 `ĝ=1`、以及成本-保证 Pareto 作为硬护栏，禁止用仿真均值替代保守上界。
