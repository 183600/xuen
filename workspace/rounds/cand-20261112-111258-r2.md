# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「成功率」×「ROS」）

> 第 57 轮把安全赌注从"模型置信"换到"证据质量"，又用元推断、跨模态对账、个性化信任把证据质量本身做成可校准、可对账、有界；但它的定理有一个从未被检验的共同前提：**证据门真的在正确的时间、以正确的数据、被正确地执行了**。它的风险自陈同时暴露另一件事——它优化的是"每个检查点的局部失效率 δ_f"，而部署与竞赛的裁判只认一个聚合数：**成功率**。局部健全不等于任务成功，二者甚至可能反向：把检查点证据门收紧到 `P_fail≤δ`，超时/绕行/保守停机会让 episode 失败；反过来为了刷成功率放宽证据门，则把失败从"高频小失败"搬到"低频灾难"。本轮两个灵感正好补上这两个缺口：**成功率**把"安全"从局部谓词升级为带尾部约束的**任务级契约**（SR 下界 + CVaR 上界 + 分布声明 + 风险-成功前沿，禁止只报 SR）；**ROS**把"保证"从论文定理拉回中间件现实——证据门只是一个节点，topic 会因 QoS 丢包、TF 会过期、executor 会堵塞、lifecycle 会崩溃、时钟会跳变，**保证链上最弱的一环是执行保真度而不是模型**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"成功率可契约、执行可保真、失败可回放的证据说可信"**。

核心矛盾：
- **H29（局部健全 vs 任务成功率）**：逐检查点 `P_fail≤δ` 无法直接相乘成 episode 成功率（相关性、重复暴露、保守停机的成功损失）；把 SR 当目标会被 Goodhart——只要允许缩小 𝒟_decl，任何系统都能"刷"出高 SR 下界。
- **H30（保证 vs 执行保真）**：所有决策层定理都隐含"证据门按时、按新鲜数据、在回路内执行"；ROS2 的 best-effort QoS、TF 过期、回调抖动、节点重启、时钟跳变把这隐含前提逐个击穿，而击穿是静默的——系统会用旧证据继续承诺。
- **H31（安全停机不是免费的成功）**：fail-safe 越保守，执行违约时越容易把"本可完成"的 episode 变成失败；只优化鲁棒 SR 下界会把系统推向"一遇抖动就保守停"的保守瘫痪，安全指标漂亮而成功率归零。

## 0. 直觉与动机

**灵感 1（成功率 → 从局部健全到任务级成功契约）**
直觉：前 57 轮都在证明"这一次接触安全"，但比赛看的是 N 个 episode 成功几次。成功率是一个**聚合统计量**，它同时掩盖两样东西：**尾部**（95% 成功里可能藏着 5% 的不可逆损坏）与**分布**（在什么地图/任务/操作者/中间件条件下测的）。把成功率当排行榜数字，等于允许用未声明的尾部风险换 SR。本轮把它升级成**契约** `K_sr=(SR 下界, 给定安全约束下的 CVaR 上界, 分布声明)`，并强制在**风险-成功前沿**上报点：任何"更高 SR"的声明必须同时给出尾部代价，禁止单报 SR。同时引入**成功率归因**——在可回放 episode 上做消融/Shapley，把 SR 的 credit 分摊到各机制；否则无法判断新加的六个 IP 是真涨了成功率，还是只把失败挪到了没被统计的角落。

**灵感 2（ROS → 保证的载体是中间件，不是论文）**
直觉：第 57 轮定理都以"若证据门运行"开头。在 ROS2 上，证据门是一个节点：证据走 topic（best-effort 会丢），几何信念走 TF（会过期），回调在 executor 里（会堵），状态在 lifecycle 里（重启即丢），时间戳依赖时钟（会被 NTP 跳变）。**静默的执行违约比模型过度自信更危险**，因为它绕过的是整条证据链而非某一类证据。于是把决策层保证翻译成**运行时契约** `E=(delivery, freshness, liveness, authority, clock)`：安全关键 topic 必须 reliable+deadline+liveliness；证据 `age≤Δ_t` 才有效；授权单写者；安全门必须在控制回路关键路径并带 dead-man watchdog；违约则在 `T_fs` 内落 fail-safe（hold/brake），且**执行退化只能让动作更保守**。

**灵感 3（合流 → 成功率契约 × 执行保真 = 部署级联合保证）**
直觉：成功率契约说"目标是什么、尾部多大"，执行保真说"承诺能不能按时按量兑现"。二者合成**部署级联合界**：SR 下界只在执行契约成立时可用；违约要扣掉"fail-safe 停机本身造成的成功损失" `P_fs_loss`。**fail-safe ≠ fail-success**——把 H31 显式写进公式的意义正是：保守不是免费的，它必须在 SR 里付账，于是"安全-成功率"权衡第一次被摆上台面，而不是藏在 δ 里。

**灵感 4（成功率 → 探询预算转向任务杠杆 MVOI）**
直觉：第 57 轮的 VOI 是局部的（探这个区域能降多少局部风险）。成功率是任务级的：探一个"关键路径上、每个 episode 都经过、历史上多次出错"的区域，价值远高于探一个"绕行就不经过"的区域。于是 VOI 乘上**任务杠杆** `λ_mission(r)=经过频次×失败概率×成功敏感度`，把探针预算从"均匀覆盖"拉向"卡脖子区域"，直接抬 SR 的分子。硬约束：λ 只重排探针顺序与预算，**不得绕过安全门**（保持交互单调性）。

**灵感 5（ROS → 失败可回放，成功率可审计 SRR）**
直觉：不可复现的成功率只是一个数字。rosbag+确定性回放（虚拟时钟+录制并注入丢包/抖动/TF age）让每个失败 episode 变成可重放用例：失败取证、成功率归因，甚至**反事实回放**（若证据早到 50ms 会不会成功？）。回放用独立硬件时间戳做锚点，部分打破"系统自己审计自己"的自证循环。

**灵感 6（合流 → 安全门在回路、拓扑即规则）**
直觉：第 57 轮说"个性化只改参数、不改决策规则"。在 ROS 上，**拓扑与 QoS 本身就是决策规则的一部分**：把安全门做成旁路 advisor、或把 consent 走 best-effort，等于悄悄改规则。因此安全门必须是关键路径上的 LifecycleNode，下游只接受已激活门签发的指令；拓扑、QoS、单写者权都是不可被个性化触碰的"规则本体"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（成功率契约 SRC）** 部署分布 𝒟_deploy（地图/任务/操作者/季节/中间件故障的联合），episode `e`，成功指示 `S_e=1[任务完成 ∧ 无不可逆违约 ∧ 无安全中止]`，损失 `L_e`。契约 `K_sr=(SR_LB(α_sr), CVaR_{α_tail}^{UB}, 𝒟_decl)`，其中 `SR_LB` 为 distribution-free 下界（Clopper–Pearson 或 conformal risk control），`CVaR^{UB}` 为分布无关上界（order-statistics/Hoeffding）。**风险-成功前沿** `ℱ={π: ¬∃π' s.t. SR(π')≥SR(π) ∧ CVaR(π')≤CVaR(π) 且至少一个严格}`；任何方案须在 ℱ 报点，禁止单报 SR。**成功率归因** `A(φ)=E_e[反事实回放 R_e^{do(φ=off)}]` 的边际贡献（|Φ| 大时用采样 Shapley），满足 `ΣA(φ)≤SR−SR_0`（交互项另记）。

**定义 140（任务加权探询价值 MVOI）** `λ_mission(r)=E_{e~𝒟}[N_visit(r,e)]·P_fail(r)·(∂S/∂P_fail)(r)`，敏感度由回放估计。`VOI_mission(π)=λ_mission(r)·ΔH[b_r]−cost(π)`，按 argmax 重排探针预算；约束：MVOI 只影响探针选择，不得修改证据门 `few_shot_evidence_gate`（A42 交互单调性保持）。

**定义 141（执行保真契约 EXF）** ROS2 可观测契约 `E=(qos_ok, age≤Δ_t, alive, single_writer, clock_mono)`。安全关键 topic 集 𝒯_safe 必须 Reliable+Deadline(Δ_t)+Liveliness(T_hb)；证据 `age(e)=now−stamp(e)≤Δ_t(r,L)`，超龄即该证据不可用（等价证据类缺失）。**保真证书** `E_fid=(ok, viol, Δ_guar)`：若 E 以概率 `≥1−δ_ros` 成立，则决策保证劣化 `≤Δ_guar(δ_ros)`（丢包→证据缺失→退回保守；时钟跳变→age 不可信→按最坏 age）；违约则 `T_fs` 内进入 fail-safe 并记 `E_viol`。**执行单调性**：E 退化只能使动作更保守。

**定义 142（安全门生命周期 SGL）** 证据门 G 实现为 LifecycleNode 并位于控制回路关键路径：下游控制器只接受 G 处于 ACTIVE 且签发的指令；G 未激活/心跳丢失（dead-man）⇒ 下游 fail-safe。consent/evidence 禁用 best-effort。不可逆接触用 ROS2 Action，取消语义：已进入不可逆阶段不可免费取消，须 L2 协商。TF age 进入证据新鲜度（几何信念过期⇒证据失效）。拓扑/QoS/单写者权属"规则本体"，个性化不得修改。

**定义 143（成功率回放与取证 SRR）** Episode 记录 `R_e=(rosbag, 中间件故障轨迹, 决策输入/输出, 证据, auth, hw_stamp)`，确定性回放用虚拟时钟与故障注入器重放丢包/抖动/TF age/节点崩溃。**反事实回放** `R_e^{do(x)}` 支持失败取证与 `A(φ)`。审计指标：可复现失败率 `ρ_replay=|可重放失败|/|失败|`；不可复现失败一律按最坏损失计入（隐藏失败不能获益）。

**定义 144（部署级联合证书 J_sr）** `J_sr=(K_sr, A(φ), E_fid, E_viol_log, replay_log, SR_LB, CVaR_UB)`，继承 `J_p` 全检。部署级合成：
`SR ≥ 1 − δ_dec − δ_ros − P_fs_loss`，
其中 `δ_dec=Σ_cp(δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1])`（第 57 轮），`δ_ros=执行违约贡献（≤Δ_guar）`，`P_fs_loss=P(episode 失败 ∧ 该失败由 fail-safe 保守停造成)`（由 SRR 回放估计）。

## 2. 关键算法伪代码（完整版见产物区）

```python
def success_rate_contract(episodes, alpha_sr, alpha_tail, dist_decl):
    n = len(episodes)
    sr_lb = clopper_pearson_lower(sum(e.success for e in episodes), n, alpha_sr)
    cvar_ub = distribution_free_cvar_upper([e.loss for e in episodes], alpha_tail)
    K = (sr_lb, cvar_ub, dist_decl)
    if not dominates(K, frontier.previous):            # 禁止只报 SR / 前沿回退
        audit.flag('pareto_regression')
    return K

def mission_weighted_probe(r, M, inf, budget):
    lam = expected_visits(r) * M.b[r].p_fail * success_sensitivity(r)
    cands = admissible_probes(r, M, F_abs)
    p = argmax(cands, key=lambda q: lam * info_gain(M.b[q.region]) - cost(q))
    return p if lam * info_gain(M.b[p.region]) - cost(p) >= theta_voi_m else None

def execution_fidelity(ros, contract):
    viol = []
    for t in S_CRITICAL_TOPICS:
        if not qos_ok(t, contract):        viol.append(('qos', t))
        if age(t) > contract.dt(t):        viol.append(('stale', t))
        if not alive(pub(t)):              viol.append(('dead', t))
    if not single_writer('consent'):       viol.append(('authority', 'consent'))
    if not clock_monotonic(ros):           viol.append(('clock',))
    return E_fid(ok=not viol, viol=viol, delta=degrade_bound(viol, contract))

def safety_gate_tick(cmd, now):
    if gate.state != 'ACTIVE' or now - gate.last_hb > T_hb:
        return downstream.fail_safe('hold')            # dead-man：只保守
    return cmd if gate.signed(cmd) else downstream.fail_safe('hold')
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SRC | O(N_ep) 统计；归因 O(\|Φ\|·N_ep·C_rep) | O(N_ep) | 下界有效（覆盖≥1−α_sr）、前沿不回退、𝒟_decl 诚实 |
| MVOI | O(1)/区域（λ 缓存） | O(\|V\|) | 只重排预算、不改证据门 |
| EXF | O(\|𝒯_safe\|)/tick | O(\|𝒯_safe\|) | QoS/age/liveness 契约、Δ_guar 显式、执行单调 |
| SGL | O(1)/tick | O(1) | 关键路径、dead-man、拓扑即规则 |
| SRR | 回放 O(len(bag)) | O(Σ\|R_e\|) | 确定性、失败不可隐藏、硬件时钟锚 |
| J_sr | O(\|Φ\|·N_ep + N_ep·C_rep) | O(N_ep) | 联合界含 P_fs_loss |

**正确性定理（SRCS：Success-Rate Contractual & Runtime-Faithful Soundness 概要）**：在 A33–A40 上加 **(A41)** 成功率估计量良定义且 `𝒟_decl` 诚实、episode 弱平稳（非平稳按 β-mixing 修正）；**(A42)** 风险-成功前沿联合上报、禁止单报 SR，MVOI 不改证据门；**(A43)** 执行保真契约可被外部锚点审计，`δ_ros` 与 `Δ_guar` 诚实，安全关键 QoS 强制，fail-safe 时延 `≤T_fs`；**(A44)** 安全门在关键路径、lifecycle watchdog 生效、执行单调。则：
(i) **成功率下界**：`Pr[SR ≥ 1−δ_dec−δ_ros−P_fs_loss] ≥ 1−α_sr−δ_ros−…`；
(ii) **尾部约束**：`Pr[CVaR_{α_tail}(L) ≤ CVaR^{UB}] ≥ 1−α_tail`；
(iii) **执行单调性**：任何 E 违约只会降低动作激进度，不存在中间件退化反而增大承诺的路径；
(iv) **保守不免费**：`P_fs_loss` 显式入界，保守停机对成功率的代价无法被隐藏；
(v) **取证完备**：可复现失败率 `ρ_replay` 作为审计硬指标，不可复现失败按最坏损失计入。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| SR 契约被 Goodhart（收窄分布刷分） | 高 | 𝒟_decl 强制声明 + 前沿联合上报 + 分布漂移检测 + 外部基准集 |
| 执行保真证书自证（审计数据被故障污染） | 高 | 硬件时间戳/独立看门狗/第三方故障注入锚点；失败不可复现按最坏计入 |
| fail-safe 导致保守瘫痪 | 高 | `P_fs_loss` 显式入界 + 分级 fail-safe（hold→brake→abort 可逆优先）+ 误停率入实验 |
| ROS2 QoS 配置错误静默降级 | 中高 | 启动期 QoS 契约自检 + 运行时 age/liveness 监控 + CI 拓扑快照比对 |
| 归因成本（回放/Shapley）爆炸 | 中 | 采样 Shapley + 分层回放 + 缓存反事实 |

## 6. 本轮最大风险

**一句话**：本轮把赌注从"证据质量"移到"成功率契约与执行保真"，最大风险是**自证循环**——SR 下界与 E_fid 都从被审计系统自己的日志/回放里算出，而 ROS 的故障恰恰会污染这些日志（丢包使失败 episode 未被记录、时钟跳变使 age 失真、回放复用同一份有偏录制），于是"契约成立"可能只是"审计数据恰好完整"；必须在 SRR 中引入独立硬件时钟与外部故障注入锚点、并把不可复现失败按最坏损失计入，否则系统会在一个自定的成功分布上刷出漂亮下界，却对真实部署分布与未记录的执行违约完全失明。

### IP-139 SRC（成功率契约与风险-成功前沿）

```python
def success_rate_contract(episodes, alpha_sr, alpha_tail, dist_decl):
    n = len(episodes)
    sr_lb = clopper_pearson_lower(sum(e.success for e in episodes), n, alpha_sr)
    # 分布无关 CVaR 上界：只用损失样本的分位数/次序统计，不假设分布族
    cvar_ub = distribution_free_cvar_upper([e.loss for e in episodes], alpha_tail)
    K = dict(sr_lb=sr_lb, cvar_ub=cvar_ub, dist=dist_decl)
    # 前沿一致性：只报 SR 或前沿回退都视为违规
    if not dominates((sr_lb, cvar_ub), frontier.previous):
        audit.flag('pareto_regression')
    if not dist_decl_complete(dist_decl):
        audit.flag('undeclared_distribution')      # 防 Goodhart：收窄分布即被发现
    return K

def success_attribution(episodes, mechanisms, replay, n_samples=None):
    base = empirical_sr(episodes)
    if n_samples and len(mechanisms) > 8:           # 采样 Shapley，避免 2^|Φ|
        return sampled_shapley(episodes, mechanisms, replay, n_samples)
    A = {}
    for phi in mechanisms:
        cf = replay.counterfactual(episodes, disable=phi)   # do(phi=off)
        A[phi] = base - empirical_sr(cf)
    return A                                        # ΣA ≤ SR - SR_0（交互另记）
```

### IP-140 MVOI（任务加权探询，只重排不改门）

```python
def mission_leverage(r, M, episodes):
    visits = expected_visit_count(r, episodes)      # 每 episode 经过该区域次数
    pf     = M.b[r].p_fail
    sens   = success_sensitivity(r)                 # ∂S/∂P_fail，由 SRR 回放估计
    return visits * pf * sens

def mission_weighted_probe(cp, M, inf, budget, episodes):
    lam = mission_leverage(cp.region, M, episodes)
    cands = admissible_probes(cp, M, F_abs)
    if not cands:
        return None
    p = max(cands, key=lambda q: lam * info_gain(M.b[q.region]) - cost(q))
    # 硬约束：任务杠杆只影响“探哪个/先探谁”，绝不触碰证据门
    return p if lam * info_gain(M.b[p.region]) - cost(p) >= theta_voi_m else None
```

### IP-141 EXF（执行保真契约 → 保证劣化界）

```python
def execution_fidelity(ros, contract):
    viol = []
    for t in S_CRITICAL_TOPICS:                     # consent/evidence/safety heartbeat...
        if not qos_ok(t, contract): viol.append(('qos', t))
        if age(t, ros) > contract.dt(t): viol.append(('stale', t))
        if not alive(pub(t)): viol.append(('dead', t))
    if not single_writer('consent'): viol.append(('authority', 'consent'))
    if not clock_monotonic(ros): viol.append(('clock',))
    # 显式映射：违约 → 受影响的保证项与劣化上界
    return E_fid(ok=not viol, viol=viol, delta=degrade_bound(viol, contract.delta_ros))

def on_contract_violation(E, robot):
    log_E_viol(E)
    # 执行单调性：只允许更保守的降级，禁止用旧证据继续承诺
    if 'stale' in [v[0] for v in E.viol] or 'clock' in [v[0] for v in E.viol]:
        robot.enter_failsafe('hold', deadline=T_fs)
    elif 'qos' in [v[0] for v in E.viol] or 'authority' in [v[0] for v in E.viol]:
        robot.enter_failsafe('brake_or_reversible_abort', deadline=T_fs)
```

### IP-142 SGL（安全门生命周期与关键路径）

```python
class SafetyGate(LifecycleNode):
    """下游控制器只接受本节点 ACTIVE 且签发的指令。"""
    def on_configure(self, state): ...
    def on_activate(self, state):
        self.last_hb = hw_now(); self.timer = create_timer(T_hb / 2, self.tick)
        return super().on_activate(state)

    def tick(self):
        self.last_hb = hw_now()                      # 外部/硬件时间戳
        if self.evidence_expired() or not self.self_check():
            self.deactivate()                        # 主动退出关键路径 → 下游 fail-safe

    def sign(self, cmd):
        return signed(cmd, key=self.authority_key, fresh=True)

def downstream_command(cmd, gate, now):
    # dead-man：门不在 ACTIVE 或心跳超时 ⇒ 保守保持，绝不透传旧指令
    if gate.state != 'ACTIVE' or now - gate.last_hb > T_hb or not gate.verify(cmd):
        return safe_hold()
    return cmd
```

| topic | QoS | 说明 |
|---|---|---|
| `/evidence` `/consent` | Reliable, KeepLast(1), Deadline `Δ_t`, Liveliness `T_hb` | 禁用 best-effort，丢一条即证据缺失 |
| `/safety_heartbeat` | Reliable, Deadline `T_hb` | dead-man 依赖，超时即 fail-safe |

### IP-143 SRR（成功率回放与取证）

```python
def record_episode(bag, faults, decisions, evidence, auth):
    return R_e(bag=bag, faults=faults, decisions=decisions, evidence=evidence,
               auth=auth, hw_stamp=hw_now())         # 硬件时钟锚，独立于 ROS 时钟

def replay(R_e, virtual_clock=True, inject_faults=True):
    with clock_override(R_e.hw_stamp) if virtual_clock else nullcontext(), \
         fault_injector(R_e.faults if inject_faults else []):
        return run(R_e.decisions)

def counterfactual(R_e, disable=None, patch=None):
    return replay(patch_episode(R_e, disable=disable, patch=patch))

def replay_audit(failures):
    reproducible = [f for f in failures if reproduces(f)]
    rho = len(reproducible) / max(1, len(failures))
    # 不可复现失败按最坏损失计入，隐藏失败不能获益
    return dict(rho_replay=rho,
                loss_for_bound=sum(worst_case_loss(f) for f in failures))
```

```python
def deployment_certificate(episodes, mechanisms, ros_contract):
    K = success_rate_contract(episodes, alpha_sr, alpha_tail, dist_decl)
    A = success_attribution(episodes, mechanisms, replay)
    for e in episodes:
        if not execution_fidelity(e.ros_snapshot, ros_contract).ok:

                replay_log=replay_log, sr_lb=K['sr_lb'], cvar_ub=K['cvar_ub'])
```

```python
def probe_commit_evolve_plusplus(x0, M, task, budget, consent, personas, ros):

    sched, log = [], []

                                                  personas, ood_reg)[0] == 'ok':
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SRC | O(N_ep)；归因 O(\|Φ\|·N_ep·C_rep) 或 O(n_s·\|Φ\|·C_rep) | O(N_ep) | SR_LB 覆盖 ≥1−α_sr、CVaR_UB 覆盖 ≥1−α_tail、前沿不回退（A41/A42） |
| MVOI | O(1)/区域（λ 缓存，重算 O(N_ep)） | O(\|V\|) | 只重排预算、不改证据门（A42） |
| EXF | O(\|𝒯_safe\|)/tick | O(\|𝒯_safe\|) | QoS/age/liveness/authority/clock 契约、Δ_guar 显式（A43） |
| SGL | O(1)/tick | O(1) | 关键路径、dead-man、拓扑/QoS 即规则（A44） |
| SRR | 回放 O(len(bag)) | O(Σ\|R_e\|) | 确定性、失败不可隐藏、硬件时钟锚（A43） |
| J_sr | O(\|Φ\|·N_ep + N_ep·C_rep) | O(N_ep) | 联合界含 P_fs_loss（定义 144） |

**正确性定理（SRCS：Success-Rate Contractual & Runtime-Faithful Soundness）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 成功率估计量良定义、`𝒟_decl` 诚实完整、episode 弱平稳（非平稳按 β-mixing 修正）；**(A42)** 风险-成功前沿联合上报且禁止单报 SR，MVOI 只重排探针不改证据门；**(A43)** 执行保真契约可被独立锚点（硬件时钟/外部看门狗/第三方注入）审计，`δ_ros` 与 `Δ_guar` 诚实，安全关键 QoS 强制，fail-safe 时延 `≤T_fs`；**(A44)** 安全门位于控制回路关键路径、lifecycle watchdog 生效、执行单调。则：

1. **成功率下界**：`Pr[SR ≥ 1 − δ_dec − δ_ros − P_fs_loss] ≥ 1−α_sr−δ_ros−…`，其中 `δ_dec` 为第 57 轮联合界；
2. **尾部约束**：`Pr[CVaR_{α_tail}(L) ≤ CVaR^{UB}] ≥ 1−α_tail`；
3. **执行单调性**：任何 E 违约只会降低动作激进度（hold/brake/可逆 abort），不存在中间件退化反而增大承诺的路径；
4. **保守不免费**：`P_fs_loss` 显式入界，fail-safe 对成功率的代价无法被藏进 δ；
5. **取证完备**：`ρ_replay` 为审计硬指标，不可复现失败按最坏损失计入，隐藏失败不能改善下界；
6. **终止性**：继承 PCE+ 的 `k_probes+k_cons` 终止，执行违约只触发四态中的保守分支。

**部署界**：

```
SR ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
        − δ_ros − P_fs_loss
CVaR_{α_tail}(L) ≤ CVaR^{UB}(1−α_tail)
```

关键：**成功率契约给目标与尾部，执行保真给兑现条件，回放取证给审计锚点**；三者合起来把"安全"从局部谓词变成可结算、可复现、可归因的部署契约，并第一次把"保守停机也会失败"写进界里。

## 6. 本轮最大风险

**一句话**：本轮把赌注从"证据质量"移到"成功率契约与执行保真"，最大风险是**自证循环**——SR 下界与 `E_fid` 都从被审计系统自己的日志/回放里算出，而 ROS 的故障恰恰污染这些日志（丢包使失败 episode 未被记录、时钟跳变使 age 失真、回放复用同一份有偏录制），于是"契约成立"可能只是"审计数据恰好完整"；必须以独立硬件时钟、外部看门狗、第三方故障注入作为锚点，并把不可复现失败按最坏损失计入，否则系统会在自定的成功分布上刷出漂亮下界，却对真实部署分布与未记录的执行违约完全失明。
