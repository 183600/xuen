# 第 5 轮（灵感驱动研究循环·新灵感二元组第 1 轮；本轮灵感：「同步定位与建图」×「跨任务泛化」）

> **基线**：v22 产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HDL 分层义务 / ACSC 臂配空间能量证书 / DCSC 深度 conformal 证书 / HPC-E 统一准入门 / CFC++ 层级模态共识；其上承 v21 的 SDC/CAC/DCL/GIC/HPC+/CFC+，v20 的 PCA/CTS/CFC/HPC，v19 的 DCM/OGCC/CCV/DRS/OGC 与 v17 的 CLP/S2C/HCG/PSV/APS/AMC）。
> **本轮纪律**：**证书永远不会自动为真，它只相对于一个未被写下的"上下文"为真——地图/坐标系版本与任务分布**。不推倒 v22：HDL、ACSC、DCSC、HPC-E、CFC++ 全部保留。本轮只做一件事：给 v22 的整套证书装上"**上下文户口 + 有价搬运 + 诚实包络**"，把"单地图、单任务分布的静态证书"升级为"跨地图版本、跨任务分布可搬运、越界即拒签"的证书体系；并顺手把 v22 遗留的两个活性病灶（分层退化振荡、臂能耗过度保守）用"相对帧局部化 + 上下文稳定驻留"收一收。

## 0. 直觉与动机

### 灵感 1（同步定位与建图 → 证书的"户口"：地图版本、相对坐标系、回环追溯失效）

直觉：v22 的所有证书都默认"一个静止、精确已知的世界坐标系"。但机器人一边走一边建图、一边用图定位：位姿是带协方差的估计，地图是带版本的产物，而且二者循环依赖。最危险的时刻是**回环闭合**——地图会整体"跳"一下，昨天的自由空间可能瞬间压到今天的障碍上。更隐蔽的是：**用绝对位姿协方差去膨胀证书是错的保守**。碰撞本质是"机器人与障碍之间的相对量"，同一张图里两者的漂移高度相关，真正该用的是**相对变换协方差 `Σ_rel`**，它通常远小于两个绝对协方差之和，且不随离回环锚点的距离线性增长。核心创新：**相对帧溯源证书（Relative-Frame Provenance Certificate, RFPC）** 把每张证书绑到 `(地图版本哈希 μ, 帧 φ, 相对协方差 Σ_rel, 签发时刻)`，并用**局部度量一致性半径 `ρ_map`** 决定回环后哪些证书可增量重锚、哪些必须整体重证。

关键反直觉点 1：**相对帧既是"更紧"的，又是"更安全"的**。设机器人/障碍世界误差各为 `σ²I`、交叉协方差 `ρσ²I`。精确相对方差约 `2(1-ρ)σ²`（正相关时远小于 `2σ²`）；忽略交叉项时 `2σ²` 仍是**声音（sound）** 的安全上界；而两次绝对协方差相加得到 `2σ²` 并把全局漂移再算一遍。也就是说，相对帧不是"为了活性牺牲安全"，而是**用更正确的相关性结构同时买到安全与活性**（引理 180）。

关键反直觉点 2：**回环修正只能撤销、不能搬运**。修正量 `δT` 超过证书一致性裕度 `m_c = ε_rel − ‖δT_φ‖` 时，正确动作是**作废该证书、撤销它赎回的自由空间**，而不是把旧结论"平移"到新帧——平移会在新帧里凭空造出旧帧的"无人"结论，而那正是最致命的假自由（引理 181）。局部形变 ≤ `ρ_map` 的邻域允许增量重锚，但必须**额外膨胀 `ρ_map`**，仍然只增不减。

严谨定义（空间侧）：上下文空间分量 `c_s = (μ, φ, T_φ, Σ_rel, t_issue, ttl)`，其中 `μ = Merkle(关键帧位姿图 ⊕ 占据栅格)`；相对膨胀半径 `ε_rel(c_s,δ) = sqrt(χ²_{d,1−δ} · λ_max(Σ_rel))`；全局可靠盒 `CertBox_global = T_rel ⊗ CertBox_local ⊕ Ball(ε_rel + ε_loc)`；一致性裕度 `m_c = ε_rel − ‖δT_φ‖₂`。

### 灵感 2（跨任务泛化 → 证书是任务条件化的假设；泛化 = 有界搬运 + 诚实包络）

直觉：v22 的 DCSC 用 conformal 保证深度网络输出"以 ≥1−α 覆盖"，但 conformal 的覆盖是**相对于校准分布**的。仓库里校准的人体检测器，搬到"家里有蹲着的小孩/轮椅/趴着的宠物"时，样本分布变了，`1−α` 可以在数学上成立、在事实上失效——这就是 v21/v22 那条"合规的缺席幻觉"在**任务维度上的复燃**。跨任务泛化的正确对象不是"一个更强的模型"，而是一条**可审计的搬运定理**：源任务 `P₀` 上校准的分数，能否在目标任务 `P₁` 上继续保持覆盖？协变量漂移下的**加权 conformal**给出答案，代价是一个显式的**搬运差距 `d_gap`**：当似然比 `w = dP₁/dP₀` 可估且 `B = sup w < ∞`、有效样本量 `ess` 足够大时，`P₁` 上覆盖 ≥ `1−α − ε_w − O(ess^{−1/2})`；一旦目标分布在源支撑之外（`B = ∞`），**不存在有限保证，只能拒签**。核心创新：**任务条件化 conformal 搬运（Task-Conditioned Conformal Transport, TCCT）** 给出任务×类别的召回下界 `κ̂_τ,c`，并由**能力包络与拒签证书（Capability Envelope & Refusal Certificate, CERC）** 显式声明"这套证书到底为哪些任务做过保"。

关键反直觉点 1：**泛化不是"外推得更远"，而是"把能外推的边界说清楚并越界即停"**。把 `E_cap` 之外的输入硬塞进同一张证书，得到的不是泛化，是乐观偏差。诚实的拒签（退回"全域假设有人"）看似保守，却把"何时可以活跃"变成了可证明的命题：**包络内活跃、包络外保守**。

关键反直觉点 2：**更多源任务数据不能弥补目标支撑缺失**。如果目标任务有一块质量在源任务里出现概率为零（新型人体形态、极端逆光、湿滑反光地面导致点云失效），再大的 `n` 也把 `d_gap` 压不下去。这决定了跨任务泛化的极限是**分布覆盖**，不是样本量。

关键反直觉点 3：**召回下界必须按任务×类别条件化**。用一个全局最坏 `κ_c` 去覆盖所有任务，会让"正常任务"也被按最坏情形限速（活性坍缩）；用无条件 `κ_c` 则会在新任务上过度自信（安全崩塌）。任务条件化是同时救活性和救安全的唯一位置。

严谨定义（任务侧）：任务上下文 `c_τ = (τ, P_τ, ŵ_τ, B̂_τ, ess_τ)`；搬运差距 `d_gap(τ) = ε_w + C·ess_τ^{−1/2} + ∞·𝟙[目标支撑 ⊄ 源支撑]`；任务条件召回下界 `κ̂_τ = κ̂_0 − d_gap(τ)`；能力包络 `E_cap = {τ : B̂_τ ≤ B_max ∧ ess_τ ≥ ess_min ∧ d_gap(τ) ≤ δ_budget}`。

### 两者如何统一：上下文是证书的"隐藏索引"，本轮把它显式化并给搬运定价

v22 的每张证书其实都在悄悄索引一个 `c = c_s ⊗ c_τ`。本轮不改变任何证书的**载荷**，只给它套一层**上下文索引证书（Context-Indexed Certificate, CIC）** `(payload, c, t_issue, state)`，并把"能否在当前上下文使用它"定义为一个**搬运判定**：`gap(c → c') ≤ margin`。于是 SLAM 的回环与跨任务的任务切换变成同一件事——**上下文漂移**；相对帧与加权 conformal 变成同一种技术——**在正确的相对坐标/相对分布里评估，而不是在绝对坐标/源分布里硬套**；`ρ_map` 与 `B_max` 变成同一类阈——**超过即拒签**。

统一准入门升级为 **HPC-CT = HPC-E ∧ frame_ok ∧ task_ok ∧ envelope_ok**；共享状态扩展为 `ζ_ctx = ζ_pgev ∪ (μ, {c_s}, {c_τ}, E_cap, κ̂_τ,c, dep, B_cas)`。安全继承铁律：**上下文失配只撤销赎回、只增障碍、只降召回、只拒签**，故 `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ … ⊆ Exec_v18` 由构造保持（定理 39）。而活性收益来自"保守性局部化"：不引入新风险的前提下，v23 的执行域**严格包含**"把 v22 直接用于未知上下文时被迫采用的全域保守域"，因为它用相对帧与任务包络把保守半径压到了真正相关的那一小块。

## 1. 研究问题（轮次升级版）

- **Q12（相对帧的可证界与紧致性）**：如何由位姿图边缘化（含交叉项 `Σ_{ro}`）严格导出 `Σ_rel` 的上界，并给出"相对帧优于绝对帧"的充分条件？交叉协方差不可得时，因子 2 的三角上界如何标定才能既 sound 又不把活性吃光？`ε_rel` 的卡方半径与 `ε_loc`（类条件检测误差）如何做置信预算分配（union bound 如何不浪费）？

- **Q13（回环追溯失效与级联有界）**：`ρ_map` 如何由漂移模型与形变统计标定？回环修正后如何保证"只撤销自由空间赎回、只增障碍、绝不搬运旧结论"？依赖图上的追溯失效如何用**依赖半径 `r_dep` 与级联预算 `B_cas`** 限制爆炸，超出即转 SafeStop——如何避免"一次回环 → 全域停机 → 活性归零"？

- **Q14（估计似然比下的搬运覆盖）**：加权 conformal 在 `ŵ` 有误差、`ess` 有限时，覆盖损失如何被 `ε_w` 与 `ess` 显式界住？支撑不匹配（`B=∞`）如何被**在线检测**而不是等到出事后才发现？多任务、多类别（成人/儿童/轮椅/蹲姿）的组条件 conformal 如何在不做多重检验爆炸的前提下同时保覆盖？

- **Q15（能力包络与不可见维度）**：任务描述子 `τ` 应包含哪些维度（场景类别、物体分布、人体形态、光照/材质、交互脚本）？如何证明"包络外"的输入确实被路由到拒签而非静默外推？当新任务的差异落在**描述子没有的维度**上时，有没有任何基于数据的方法能察觉（还是只能靠人审）？

- **Q16（上下文协调与跨上下文共识）**：跨机器人投票在"不同地图版本/不同任务"下如何融合？障碍取并、安全票"每个上下文组独立法定人数"的双向单调规则是否足以阻止"地图没对齐造成的假共识"？上下文切换与 v22 分层退化如何用**驻留时间 + 滞回**避免来回振荡？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 上下文相对律（Context Relativity）**
任何证书的有效性都相对于上下文 `c = (μ, φ, Σ_rel, τ, P_τ)`；证书必须携带 `c` 与签发时刻，全局复用前必须经过显式**搬运判定** `gap(c→c') ≤ margin`。上下文不匹配时，证书**默认无效**，只允许向更保守方向转化（增障碍、降召回、收缩域、拒签），**禁止静默迁移**。

**P44 相对帧声音律（Relative-Frame Soundness）**
碰撞在**相对帧**评估：`CertBox_global = T_rel ⊗ CertBox_local ⊕ Ball(ε_rel + ε_loc)`，其中 `Σ_rel` 由边缘化严格导出；交叉项不可得时用 `Σ_rel ⪯ 2(J_rΣ_rJ_rᵀ + J_oΣ_oJ_oᵀ)` 的 sound 上界。回环修正 `‖δT_φ‖ > ε_rel`（即 `m_c < 0`）或地图版本变更时，相关证书 STALE，**只撤销其自由空间赎回**；局部形变 ≤ `ρ_map` 才允许增量重锚且额外膨胀 `ρ_map`。障碍集合在任一上下文迁移中**单调不减**。

**P45 任务搬运有界律（Task Transport Bound）**
任务条件覆盖只在"似然比有界 `B̂ ≤ B_max` ∧ 有效样本量 `ess ≥ ess_min` ∧ 支撑覆盖可证"时成立；搬运差距 `d_gap` 从覆盖预算中显式扣除，得到 `κ̂_τ,c`。目标支撑逃出源支撑（`B=∞`）时**不存在有限保证**，必须拒签并退化为"全域可能有人"。禁止把"源任务表现好"当作"目标任务安全"。

**P46 包络诚实律（Envelope Honesty）**
整套证书的安全声明**恰好等于**能力包络 `E_cap` 内可证命题的并集；`E_cap` 之外一律由**拒签证书**路由到保守模式，而不是靠模型外推。包络、拒签与失效必须进 merkle 审计链，能回放到"哪条假设、哪个上下文、哪个版本"失责。

## 3. 与基线的接口（如何退化）

- 地图无关/无回环 ⇒ 相对帧退化为绝对帧的安全上界（因子 2），仍 sound，只是更保守；
- 地图版本不可信/回环跳变超 `ρ_map` ⇒ 相关证书 STALE、撤销赎回、全局保守，`Exec_v23 ⊆ Exec_v22`；
- 似然比不可得或 `B̂=∞` ⇒ 不签发 `AbsCert`，声明 UNVALIDATED，退回 v22 的保守分支；
- `E_cap` 为空 ⇒ 全域拒签 + 静态人距上限（比 v22 更保守）；
- 上下文协调失败（CRR 崩溃）⇒ 任一上下文变更直接全局保守化，只收紧；
- 跨上下文共识无法满足法定人数 ⇒ 退回 v22 CFC++ 的保守仲裁，等价 v22；
- 全失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ … ⊆ Exec_v18`（定理 39）。
- **活性局部化**：相对帧与任务包络把保守性从"全域最坏"压到"当前上下文"，故 v23 在已证上下文内的可执行域**严格包含**"v22 直接用于未知上下文时的全域保守域"，同时仍是 v22 原执行域的子集；CRR 的驻留/滞回把 v22 的分层退化振荡阻尼住。

## 4. 预期贡献

1. **上下文索引证书（CIC）**：首次把地图版本、相对坐标系与任务分布显式纳入证书有效性，给出"证书只相对上下文为真"的形式化与失效语义；
2. **相对帧溯源证书（RFPC）**：给出相对协方差的声音界与紧致性条件，证明相对帧同时改善安全与活性；给出回环"只撤销不搬运"的单调性引理；
3. **任务条件 conformal 搬运（TCCT）**：把跨任务泛化从"模型外推"改写为"估计似然比下的有界覆盖搬运"，给出 `d_gap(ε_w, ess)` 与支撑缺失时"无有限保证"的判据；
4. **能力包络与拒签（CERC）**：把"能泛化到哪"变成可审计的包络 `E_cap` 与越界拒签，封堵"缺席幻觉"在任务维度上的复燃；
5. **上下文协调（CRR）与跨上下文共识（CFC-CT）**：回环/任务切换的追溯失效有界化，跨版本投票用"障碍取并、安全票分组独立法定人数"保持双向单调；
6. **HPC-CT 统一准入 + 保守性局部化**：`Exec_v23 ⊆ Exec_v22` 闭环，同时在已证上下文内把活性从全域最坏解放出来。

## 5. 本轮最大风险

**一句话**：搬运差距只在**描述子写下的维度**上可测，而真正的新任务/新地图恰恰在**没有被写进描述子的维度**上不同（新型人体形态、让 SLAM 退化的反光/湿滑地面、从未见过的遮挡结构），于是证书会以"包络内、回环一致、覆盖达标"的姿态，撞上一个它从未校准过、也永远无法从数据里察觉"自己没校准过"的人。

# 产物区 · v23：CCTL — 上下文证书与可搬运安全（Context-Certified Transport Layer）

> 名称：**MetricVoiceGauge-NCD-HUTDH-v23 + CCTL**
> 定位：v22 的 5 个模块（IP-431–435）原样保留；本轮在其上新增 7 个模块（IP-436–442），只做"给证书加上下文、给搬运定价、给越界拒签"一件事。
> 状态：设计稿 + 形式化引理（180–183）+ 定理 39 + 可运行算法骨架 + 实验设计 + 解析可检验数值。未接真实 SLAM 后端，未跑真机，`ρ_map`/`B_max`/`ess_min` 为待标定超参。

## 1. 形式化核心

### 1.1 上下文索引证书（CIC）

```text
CIC := (payload, c, t_issue, state, dependents)
payload ∈ { CertBox, AbsCert, ComplianceCert, EnergyCert, ConsensusVote }
```

**定义 926（上下文有效性）**：`CIC` 在上下文 `c*`、时刻 `t` 有效，记 `Valid(CIC,c*,t)`，当且仅当：

```text
(1) t − CIC.t_issue ≤ CIC.c.ttl
(2) dist_map(CIC.c.μ, c*.μ) ≤ ρ_map                  // 地图版本兼容
(3) λ_max(Σ_rel(c*)) ≤ λ_max(Σ_rel(CIC.c)) + γ        // 相对不确定性未恶化
(4) CIC.c.τ ∈ E_cap ∧ d_gap(CIC.c.τ → c*.τ) ≤ δ_budget // 任务搬运可证
(5) module_sound(CIC.payload, c*, t)                  // v22 各模块自身谓词
```

任一不满足 ⇒ 状态转为 `STALE`（时间/空间）或 `UNVALIDATED`/`REFUSED`（任务），且**只允许**执行 `revoke_free_space` / `add_obstacle` / `lower_recall` 三类单调动作。

### 1.2 空间溯源：相对帧与回环（SLAM 侧）

**引理 180（相对协方差声音性）**
设机器人与障碍在共享地图中的位姿误差为 `e_r, e_o`（零均值，协方差 `Σ_r, Σ_o`，交叉协方差 `Σ_ro`）。在 `T_rel=T_r^{−1}T_o` 处一阶展开 `δξ_rel = J_r e_r + J_o e_o`，则

```text
Σ_rel = J_rΣ_rJ_rᵀ + J_oΣ_oJ_oᵀ + J_rΣ_roJ_oᵀ + J_oΣ_roᵀJ_rᵀ .
```

若 `Σ_ro` 不可得，则 `Σ_rel ⪯ 2(J_rΣ_rJ_rᵀ + J_oΣ_oJ_oᵀ) =: Σ_rel^tri`（因为 `(A+B)(A+B)ᵀ ⪯ 2AAᵀ+2BBᵀ`）。因此以 `ε_rel = sqrt(χ²_{d,1−δ} λ_max(Σ_rel^tri))` 膨胀，仍以 ≥1−δ 概率包含真实相对变换。

*紧致性*：各向同性且交叉相关 `ρ` 时精确相对方差 ≈ `2(1−ρ)σ²`，三角上界 `2σ²`，绝对帧两次相加亦 `2σ²` 且随离锚点距离增长。故相对帧**既 sound 又更紧**；代价仅需边缘化交叉项（或接受因子 2）。∎

**引理 181（回环只撤销、不搬运）**
回环后端解出节点修正 `{δT_φ}`，地图版本 `μ→μ'`。对每张 `frame=φ` 的证书：
- 若 `m_c = ε_rel − ‖δT_φ‖₂ < 0`：置 `STALE`，执行 `revoke_free_space`，**不**把旧 payload 变换到 `μ'`；
- 若证书支撑的形变 `sup_x d_φ(x) ≤ ρ_map`：允许增量重锚，但膨胀加 `ρ_map`；
- 否则：置 `UNVALIDATED`，需整体重证。

障碍集合做 `Obs' = Obs ∪ T_φ(Obs)`（并集、单调不减），自由空间赎回只减不增。故对任意后续计划集，`Exec(t⁺) ⊆ Exec(t⁻)`。∎

**定义 927（版本兼容距离）**：`dist_map(μ,μ') = 0` 若同版本；否则取位姿图共同锚点上的 `max_φ ‖δT_φ‖₂`；超过 `ρ_map` 即不兼容。

### 1.3 任务溯源：加权 conformal 搬运（跨任务侧）

**引理 182（估计似然比下的覆盖搬运）**
设源校准样本 `(X_i,Y_i)~P_0`，非共形分数 `s_i∈[0,1]`，目标 `P_τ` 满足 `w=dP_τ/dP_0`、`B=sup w<∞`。取权重 `p_i = ŵ(X_i)/(Σ_j ŵ(X_j)+ŵ(x))` 并做加权分位（含 `+∞` 原子）。若 `w` 已知，则 `P_τ(Y∈C(X)) ≥ 1−α`。若仅知 `ε_w=sup|ŵ−w|`，则

```text
P_τ(Y∈C(X)) ≥ 1 − α − ε_w − C·ess^{−1/2},   ess=(Σŵ)²/Σŵ²,
```

其中 `C` 只依赖分数界（`s∈[0,1]` 时取 2）与置信水平。若 `supp(P_τ) ⊄ supp(P_0)`（存在目标正测度集上 `w=∞`），则对任意有限 `n` 均无有限下界——**只能拒签**。∎

**推论 183（任务条件召回下界）**
令 `κ̂_0` 为源任务召回，则目标任务 `κ̂_τ = κ̂_0 − d_gap(τ)` 是源码召回的 sound 下界；按类别 `c` 分组再做一次即得 `κ̂_τ,c`。把它代入 v21 的 `AbsCert` 召回假设即完成跨任务加固。

### 1.4 统一门与单调性

**定义 928（HPC-CT）**：

```text
HPC-CT(π,c) = HPC-E(π) ∧ frame_ok(c) ∧ task_ok(c) ∧ envelope_ok(c)
frame_ok  ⇔ (2)(3) 成立且 m_c ≥ 0
task_ok   ⇔ c.τ∈E_cap ∧ κ̂_τ,c ≥ κ_min
envelope_ok ⇔ Transport 的 gap ≤ δ_budget
```

**定理 39（安全继承与上下文单调）**
在 P43–P46 与引理 180–183 下：
1. `Exec_v23 = Exec_v22 ∩ Fil_spatial ∩ Fil_task ⊆ Exec_v22`；
2. 任意上下文迁移 `c→c'`（回环、任务切换、拒签、失效）后 `Exec_v23(t⁺) ⊆ Exec_v23(t⁻)`；
3. 反之，`Exec_v23 ⊇ Exec_v22^{global-conservative}(c)`：v23 在已证上下文内**严格更活跃**于"把 v22 用于未知上下文时被迫的全域保守"。

*证明提要*：CIC 只在五条件全真时放行，故新门只会求交；引理 181/182 的失效动作均属单调收缩；相对帧与任务包络把 `Fil_spatial/Fil_task` 的保守半径限定在相关子集，故包含"全域保守域"。∎

```python
import numpy as np

# ---------- IP-436 CIC ----------
from dataclasses import dataclass, field

@dataclass
class Context:
    mu: str                 # merkle(map) 版本
    frame: str
    T_frame_rel: np.ndarray
    Sigma_rel: np.ndarray
    task_id: str
    B_hat: float            # sup w 的估计
    ess: float
    t_issue: float
    ttl: float

@dataclass
class CIC:
    payload: object
    ctx: Context
    state: str = "VALID"    # VALID/STALE/UNVALIDATED/REFUSED/FALSIFIED
    dependents: list = field(default_factory=list)

def valid_in(cic: CIC, c_now: Context, t: float,
             envelope, kappa_hat, kappa_min, module_sound) -> bool:
    if t - cic.ctx.t_issue > cic.ctx.ttl:
        return False
    if dist_map(cic.ctx.mu, c_now.mu) > RHO_MAP:
        return False
    if np.linalg.eigvalsh(c_now.Sigma_rel).max() > \
       np.linalg.eigvalsh(cic.ctx.Sigma_rel).max() + GAMMA:
        return False
    if cic.ctx.task_id not in envelope:
        return False
    if d_gap(cic.ctx.task_id, c_now) > DELTA_BUDGET:
        return False
    if kappa_hat[cic.ctx.task_id] < kappa_min:
        return False
    return module_sound(cic.payload, c_now, t)

# ---------- IP-437 RFPC ----------
def relative_cov_bound(Sigma_r, Sigma_o, J_r, J_o, Sigma_ro=None):
    base = J_r @ Sigma_r @ J_r.T + J_o @ Sigma_o @ J_o.T
    if Sigma_ro is None:
        return 2.0 * base                       # sound triangle bound
    return (base + J_r @ Sigma_ro @ J_o.T + J_o @ Sigma_ro.T @ J_r.T)

def cert_box_relative(box_local, T_rel, Sigma_rel, delta, eps_loc):
    from scipy.stats import chi2
    eps_rel = np.sqrt(chi2.ppf(1 - delta, d=6) * np.linalg.eigvalsh(Sigma_rel).max())
    return inflate(transform(box_local, T_rel), eps_rel + eps_loc)

def on_loop_closure(pg, corrections, rho_map, ledger):
    pg.mu = bump_version(pg.mu)
    invalidated = []
    for cid, cic in pg.certs.items():
        dT = corrections.get(cic.ctx.frame, np.eye(4))
        m_c = rel_inflation(cic) - np.linalg.norm(dT - np.eye(4))
        if m_c < 0:
            revoke_free_space(cic)              # 只撤销
            cic.state = "STALE"
            invalidated.append(cid)
        elif local_deformation(cic, corrections) <= rho_map:
            cic.reanchor(extra_inflation=rho_map)   # 增量、加膨胀
        else:
            cic.state = "UNVALIDATED"
            invalidated.append(cid)
    ledger.anchor(("LOOP", pg.mu, invalidated))
    return invalidated

# ---------- IP-438 TCCT ----------
def task_conditioned_recall(scores_src, labels_src, w_hat, alpha, delta_conf):
    x = scores_src.x
    w = np.clip(w_hat(x), 0, None)
    n = len(w)
    ess = (w.sum() ** 2) / (w ** 2).sum()
    B_hat = float(w.max())
    if not support_covered(x, w_hat, delta_conf):
        return 0.0, np.inf, ess, B_hat        # 支撑缺失 → 无有限保证
    p = w / (w.sum() + 1.0)
    q = weighted_quantile(scores_src.nonconformity, 1 - alpha, p)
    kappa0 = float(np.mean(scores_src.nonconformity <= q))
    eps_w = estimate_ratio_error(w_hat)
    gap = eps_w + 2.0 / np.sqrt(max(ess, 1.0))
    return max(kappa0 - gap, 0.0), gap, ess, B_hat

# ---------- IP-439 CERC ----------
def capability_envelope(tasks, B_max, ess_min, delta_budget):
    return {t.task_id for t in tasks
            if t.B_hat <= B_max and t.ess >= ess_min
            and t.d_gap <= delta_budget}

def envelope_gate(cic, c_now, envelope):
    if c_now.task_id not in envelope:
        return RefusalCertificate(task=c_now.task_id, fallback="HUMAN_EVERYWHERE")
    return cic

# ---------- IP-440 CRR ----------
def reconcile(root_certs, c_old, c_new, r_dep, B_cas, now):
    frontier, seen, cascade = list(root_certs), set(), 0
    while frontier:
        cert = frontier.pop()
        if cert.id in seen:
            continue
        seen.add(cert.id)
        if not compatible(cert.ctx, c_new):
            revoke_free_space(cert)            # 单调
            cert.state = "STALE"
            cascade += 1
            if cascade > B_cas or depth(cert, root_certs) > r_dep:
                return enter_global_conservative(now)   # 有界级联→保守停机
            frontier.extend(cert.dependents)
    if dwell_ok(c_new, now) and not hysteresis_blocked(c_old, c_new):
        commit_context(c_new)
    return "OK"

# ---------- IP-441 HPC-CT ----------
def hpc_ct_admits(plan, cic_set, c_now, hpc_e, envelope, kappa_min):
    frame_ok = all(valid_in(c, c_now, now(), envelope,
                            kappa_hat, kappa_min, module_sound)
                   for c in cic_set if c.ctx.frame in plan.frames)
    task_ok = (c_now.task_id in envelope and
               kappa_hat.get(c_now.task_id, 0.0) >= kappa_min)
    return hpc_e.admits(plan) and frame_ok and task_ok

# ---------- IP-442 CFC-CT ----------
def cross_context_consensus(votes, quorum):
    obstacles = union(v.obstacle for v in votes)        # 永远取并
    groups = partition(votes, key=transport_compatible) # 上下文组
    # 安全/缺席结论：每个上下文组必须独立达到法定人数
    safe = all(sum(1 for v in g if v.claim == "SAFE") >= quorum for g in groups)
    return obstacles, safe
```

## 3. 推导与可检验数值

**(a) 相对帧的紧致性（解析）**：取 `Σ_r=Σ_o=σ²I`、`Σ_ro=ρσ²I`，则精确相对方差 `2(1−ρ)σ²`。`ρ=0.9` 时半径因子 `sqrt(2·0.1/2)=sqrt(0.1)≈0.32`——相对帧比"忽略相关性的 `2σ²` 复制"紧约 `3.2×`；且绝对帧的 `σ²` 还随离锚点距离增长，长走廊任务中差距进一步拉大。**可检验预测**：在 20m 走廊、回环稀疏场景，v23 的相对帧净空膨胀应比 v22 的绝对帧小 ≥2×，同时缺勤证书假阴性率不升（soundness 保持）。

**(b) 搬运的活性代价（解析）**：`B̂=2, ess=500, ε_w=0.01, C=2` ⇒ `d_gap ≈ 0.01 + 2/√500 ≈ 0.01+0.0894 = 0.099`。若 `κ̂_0=0.95, α=0.05`，则 `κ̂_τ≈0.851`；若安全要求 `κ_min=0.90` ⇒ 该任务应被**拒签**（回到全域保守）。这正说明"跨任务泛化有价"：包络不是免费的，而是用 `κ_min` 与 `ess` 显式标出来的。**可检验预测**：随 `ess` 从 100→5000，`d_gap` 按 `1/√ess` 收缩，认证任务数（`E_cap` 大小）单调不减，且经验假阴性率始终 ≤ `δ_budget+α`。

**(c) 回环单调性（可检验）**：构造人为回环跳变 `δT` 扫参。预测：`‖δT‖<ρ_map` 时计划集几乎不变（增量重锚）；`‖δT‖≈ε_rel` 附近开始出现 STALE；`>ε_rel` 后计划集单调收缩、障碍并集单调增大；全程 `Exec(t⁺)⊆Exec(t⁻)` 的自动断言 0 违例。

**(d) 无自由午餐（可证伪）**：构造目标分布 `P_τ` 在源支撑外放置正测度（如"蹲姿儿童"类在源校准集中完全缺失）。预测：任何仅基于 `ŵ` 加权的方法都无法把 `d_gap` 压到 `δ_budget` 以下，正确行为是 CERC **拒签**；若强行放行，则假阴性率显著高于 `δ_abs`。这条实验专门验证"样本量救不了支撑缺失"。

## 4. 实验设计

**环境**：2D/3D 仿真 SLAM（位姿图 + 回环）+ 三个任务域：仓库（成人、纸箱、空旷）→ 家庭（儿童/宠物/杂物/低照度）→ 医院（轮椅/担架/强反光地面）。检测器沿用 v22 的 DCSC 网络（真实或合成），按类别注入不同召回。

**对照**：
1. **v22**：无上下文，默认单一地图/单一任务；
2. **v22 + 绝对帧膨胀**（去掉 RFPC 的交叉项，改为 `Σ_r+Σ_o`）；
3. **v23 去加权**（TCCT 关掉 `ŵ`，退化为无权重 conformal）；
4. **v23 去包络**（CERC 恒放行，直接外推）；
5. **v23 去协调**（CRR 不失效，回环后沿用旧证书）；
6. **完整 v23**。

**指标**：
- 安全：缺勤证书**实测假阴性率**（应 ≤ `δ_abs`）；回环后是否出现"旧自由空间压障碍"（计数）；
- 覆盖：各任务域经验覆盖 vs 名义 `1−α`（分任务×类别）；
- 活性：任务成功率、平均速度、认证任务数 `|E_cap|`、单位时间被拒签比例；
- 协调：STALE 触发的精确率/召回率、级联规模分布、是否触及 `B_cas`；
- 单调：自动断言 `Exec(t⁺)⊆Exec(t⁻)`、`Obs(t⁺)⊇Obs(t⁻)` 全程 0 违例；
- 上下文：`ess`、`B̂`、OOD 检测 AUROC 与"支撑缺失"识别率。

**消融预期（可证伪）**：去包络（4）在家庭/医院域假阴性率显著升高（即本轮最大风险的可控复现）；去加权（3）在医院域覆盖跌破 `1−α`；去协调（5）在回环后出现假自由；绝对帧（2）活性显著低于 RFPC。完整 v23 应在保持 `δ_abs` 的同时 `|E_cap|` 最大、被拒签只发生在真正 OOD 的任务上。

**统计协议**：所有覆盖/召回结论用 anytime-valid 置信序列报告（避免 optional stopping），与 v21 AVRM 口径一致；每次上下文切换记一次审计事件。

## 5. 复杂度

- CIC `valid_in`：O(1) 查表（`dist_map`、特征值、包络成员为缓存值）；
- RFPC：相对协方差 O(d³)（d=6），回环事件 O(|certs|)；
- TCCT：离线 O(n log n) 加权分位，在线 O(1) 查 `κ̂_τ,c`；重校准仅在 drift 触发时按有限样本做；
- CRR：仅在事件（回环/任务切换）时 O(|dep|≤r_dep)，控制环 50Hz 只做 O(1) 状态查询；
- CFC-CT：O(#votes·#groups)，组数通常 ≤ 机器人数；
- 结论：控制路径保持 v20/v21/v22 的 O(1) 查询；重活全在 10Hz 上下文层与离线校准。

## 6. 与基线退化 & 风险

| 失效 | 行为 | 与 v22 关系 |
|---|---|---|
| 无回环/地图可信 | 绝对帧 sound 上界（因子 2） | 更保守，等价或 ⊆ |
| 回环 > ρ_map | 相关证书 STALE、撤销赎回 | ⊆ v22 |
| 似然比 `B=∞` | AbsCert 拒签、UNVALIDATED | 退回 v22 保守分支 |
| `E_cap=∅` | 全域拒签 + 静态人距上限 | 比 v22 更保守 |
| CRR 崩溃 | 任一上下文变更→全局保守 | 只收紧 |
| 共识不满足法定人数 | 退回 CFC++ 保守仲裁 | 等价 v22 |
| 全失效 | 完全回退 v22 | `Exec_v23⊆Exec_v22⊆…`（定理 39） |

**本轮最大风险（可审计化）**：`d_gap` 只能度量描述子里有的维度；未写入描述子的分布变化（新人体形态、SLAM 退化材质/光照、未见遮挡）对 CERC 不可见，系统会"包络内自信"地拒签不了本应拒签的情形。缓解只能靠：审计链强制记录"包络外一律拒签"、把 OOD 检测与证书**解耦**（不同模态/外部设施/人审），并把"未描述维度"显式列为残余义务——但这仍无法从数据里证明"没有未描述维度"，故这是本方案的结构性上限，而非可完全消除的工程缺陷。
