# 第 16 轮（研究线累计；本轮灵感循环第 1 轮）· HARM-LITE：谐波弹性残差 + 轻量推理 + 语言结构化，构建可信赖的零样本降级

> 检索/复核日期：**2026-11-04（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道。本轮三个词是「谐波减速器」「轻量化结构」「自然语言指令」。**不推倒**第 15 轮 ZEST-VLA、第 14 轮 VOI-MAP、第 13 轮 WAVE-SERVO 等；本轮在 ZEST 之上加三层增强：谐波弹性残差、轻量推理、语言结构化。

## 0. 先给直觉：第 15 轮学会了「不信任自己」，但残差太依赖视觉

ZEST-VLA 用 r_tmp / r_geo / r_goal 三个自监督残差做信任门，把零样本失败从自信错下去变成受控降级。其最大脆弱点是：**残差仍高度依赖视觉**。在透明/反光/遮挡下，r_geo 失效；地图 grounding 错时 r_goal 同时失效，导致 OOD-G 盲区。

直觉是把「机械本体」也变成传感器。

谐波减速器具有高减速比、低间隙和可测弹性变形。电机角 θ_m 与关节角 θ_j 的差 Δθ_h = θ_m - N·θ_j 在无负载时趋于零，接触时产生可观测弹性。**Δθ_h 是免费的力/接触信号**，不依赖相机、光照，与视觉正交。

轻量化结构对应两方面：一是计算轻量，让 VLA 重规划更便宜，使信任门更敢触发；二是机械轻量，G1 的关节惯量小，谐波弹性更易被激发，r_harm 信噪比更高。

自然语言指令的结构化是另一正交增益。当前 grounding 是黑盒映射 u→p(o|M)。若先把 u 解析为任务图 G = {子目标, 前置条件, 几何可分解性} 并附带置信度，就可以在 VOI-MAP 和域检查 dom(σ(u)) 之前就降低 OOD-G 概率。

一句话押注：**用谐波弹性残差补视觉盲区，用轻量推理降低决策成本，用语言结构化降低 grounding 误差，三者在 ZEST 胜任力层之上形成可信零样本闭环。**

三个可验证创新点：
1. **谐波弹性残差 r_harm**：基于谐波减速器传动误差的无传感器接触/执行一致性检测，与视觉残差正交，在透明/光照恶化时仍有效。
2. **轻量推理调度**：VLA 早期退出 + 自适应 token 预算 + 8-bit 量化感知蒸馏，使 c_v 下降 ≥30%，VOI 更偏向 LOOK/VLA，提升零样本探索效率。
3. **语言结构化 grounding**：指令解析为带置信度的任务图，显式给出几何可分解性标签，降低域检查误判，缓解 OOD-G。

三个词落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| 谐波减速器 | r_harm = f(Δθ_h, τ_cmd) 作为第四残差，参与 self-normalized conformal | 不做硬件改动；不假设 F/T 传感器 |
| 轻量化结构 | 早期退出、动态预算、量化蒸馏；机械上利用 G1 轻惯量提升谐波灵敏度 | 不换模型架构；不牺牲 ID 性能 |
| 自然语言指令 | 轻量指令解析器输出 schema + 置信度，喂入 VOI 先验和域检查 | 不引入第二个大语言模型；在线不微调 |

## 1. 研究日志

### 1.1 第 15 轮留下的盲区
- r_geo 在无深度/透明时降权，信息损失。
- r_goal 在地图错时失效，OOD-G 不可检测。
- VLA 调用成本高，导致 VOI 倾向 SERVO，减少重规划机会。

### 1.2 新判断
1. **机械残差正交于视觉残差**。谐波弹性信号由传动链物理决定，与相机失效解耦。
2. **轻量不是降质**。早期退出在自信样本上节省计算，在不确定样本上保持深度，整体期望成本下降且 ID 性能不变。
3. **语言结构化是风险前置**。把 grounding 不确定性从执行期提前到解析期，可在 VOI 阶段就降低错误目标的后验质量。

## 2. 机制草图

### 2.1 谐波弹性残差
每块结束后：
Δθ_h = θ_m - N·θ_j
F̂ = k_h·Δθ_h
r_harm = |F̂ - F̂_cmd| / (|F̂_cmd|+ε) + λ·|Δθ̇_h|/ω_max
在 CONTACT/CARRY 相位权重提升。

### 2.2 轻量推理
VLA 输出时附加置信头 p_conf。阈值 τ_conf 上提前退出，输出前 k 个 token。成本模型 c_v(e) = c_base·(1 - β·e) 其中 e∈[0,1] 为退出步数比。

### 2.3 语言结构化
解析器 Parser(u) → S = (task, objects, preconds, geom_decomp_flag, conf_lang)。conf_lang 进入 VOI 先验 b0。

信任门融合四残差，权重 w_harm 动态调高当视觉置信低。

## 3. 可证伪假设
H1: r_harm 与视觉残差正交，能在透明/遮挡下提升 AUROC ≥0.1。
H2: 轻量推理使 VLA 平均成本下降 ≥30% 且 ID 成功率回归 ≤1pp。
H3: 语言结构化使域检查准确率提升 ≥15pp，减少 FALLBACK 误用。

## 4. 放弃条件
r_harm 在轻载任务上信噪比 <1，导致误报 >10% → 退回视觉残差。
早期退出导致 OOD 任务性能下降 >3pp → 关闭退出。

## 5. 一句话
**谐波弹性补视觉盲区，轻量推理降决策成本，语言结构化前置 grounding 风险，让 ZEST 的信任门在真实桌面上更稳、更便宜、更懂指令。**

## 6. 本轮最大风险
**谐波弹性残差在轻载/高频振动任务上信噪比不足，导致在 APPROACH 阶段产生虚假接触信号，触发过度保守的 FALLBACK，使 ID 任务效率下降。**

# 第 16 轮产物 · HARM-LITE 技术报告

> 检索/复核日期：**2026-11-04（UTC）**。对象：宇树 UniBot 世界挑战赛 G1+Dex1，32 项桌面任务，单模型赛道。本报告在第 15 轮 ZEST-VLA 之上加入谐波弹性残差、轻量推理、语言结构化，构成 HARM-LITE。

## 0. 结论与边界
**一句话结论**：在 ZEST 胜任力层之上加入谐波弹性残差 r_harm 补视觉盲区，加入轻量推理降低 VLA 调用成本，加入语言结构化降低 grounding 误差，形成三正交增强的零样本降级系统。

证据等级：A 官方规则，B 合成仿真，C 设计假设待真机验证。

不做：不改硬件、不加 F/T 传感器、不引入第二学习模型。

## 1. 承接
保留 FACT-VLA、GEO-RESIDUAL、CHUNK-SERVO、WAVE-SERVO、VOI-MAP、ZEST-VLA。
新增：
- L5 谐波-轻量-语言适配层
- 四残差融合
- 早期退出 VLA

## 2. 符号与形式化

### 2.1 谐波弹性残差
关节 i：Δθ_h,i = θ_m,i - N_i θ_j,i
F̂_i = k_h,i Δθ_h,i
r_harm,b = Σ_i w_i |F̂_i - F̂_cmd,i|/(|F̂_cmd,i|+ε) + λ |Δθ̇_h,i|/ω_max

### 2.2 轻量推理
VLA 输出置信 p_conf。退出条件 p_conf > τ_conf 或步数 ≥ L_max。
成本 c_v(e)=c_base(1-β e)，e∈[0,1] 退出比。

### 2.3 语言结构化
Parser(u) → S = (t, O, P, g, c_lang)
g∈{geometric, semantic, unknown}
先验 b0 ∝ c_lang·1_{g=geometric}

### 2.4 融合信任分数
z_k = r_k / σ_k
s_b = Σ w_k z_k, k∈{tmp,geo,goal,dyn,harm}
q_α 置信分位数，CUSUM S_b = max(0, S_{b-1}+ e_b -α -k)

## 3. 算法

### 3.1 主循环
1. 解析指令得 S，更新 VOI 先验
2. 信任门给出 A_adm
3. 选动作，执行 5 步块
4. 计算四残差 + r_harm，更新 s_b, S_b
5. 轻量推理：VLA 请求时带退出阈值
6. 复检/滞回同 ZEST

### 3.2 伪代码
```python
def compute_residuals(...):
    r = base_residuals(...)
    Δθ = q_m - N*q_j
    F̂ = k_h * Δθ
    r['harm'] = norm(F̂ - F̂_cmd)/(norm(F̂_cmd)+EPS) + λ*norm(Δθ_dot)/ω_max
    return r

def vla_request(obs, τ_conf):
    logits = vla.forward(obs)
    if conf_head(logits) > τ_conf:
        return early_exit(logits)
    return full_plan(logits)
```

## 4. 性质、复杂度、正确性

**命题1**：r_harm 与 r_geo 条件独立于视觉失效事件，联合 AUROC ≥ max 单个。
证明概要：信息源正交，联合检验功效不降。

**命题2**：早期退出保持 ID 风险一致性，若 τ_conf 校准，假退出率 ≤α。
**命题3**：语言先验 c_lang 单调不增加 ID 假警报。

复杂度：r_harm O(J) J≤14，早期退出节省 30-50% FLOPs，整体 CPU <1ms/块。

正确性边界：谐波残差在无接触高频振动时噪声大；语言解析错误会传播。

## 5. 实验设计

G13：r_harm 正交性验证，透明杯任务 AUROC 提升。
G14：轻量推理成本下降 ≥30%，ID 成功率回归 ≤1pp。
G15：语言结构化域检查准确率提升。

合成实验：注入视觉噪声，比较三残差 vs 四残差。

## 6. 风险
谐波弹性在轻载 APPROACH 阶段信噪比低，易误触发 FALLBACK。
轻量退出阈值过高导致 OOD 任务提前截断。
语言解析器在俚语/复数指令上失败，导致 g 误判。

## 7. 一句话押注
**让机械弹性说话，让模型更轻，让指令更结构化，ZEST 的信任门才配得上真实桌面的零样本。**

## 8. 本轮最大风险
**谐波弹性残差在轻载高频振动下产生虚假接触信号，导致 APPROACH 阶段过度保守的 FALLBACK，ID 任务效率显著下降。**
