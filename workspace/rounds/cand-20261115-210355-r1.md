# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「指标体系」×「视觉语言模型」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**不新增控制律，只新增对指标系统自身的审计**。v9 已把"怎么算指标、怎么退化、怎么分块"推到极致，却从未回答"这套指标体系本身是否有效"。两个灵感合成一个判断：**用开放词表的视觉语言模型（VLM）充当指标系统的语义裁判**。为防 VLM 不可靠反噬安全，审计只被授予**单向否决权**——只能让系统更保守，绝不能更激进。

## 0. 直觉与动机

**指标体系的三类经典失效（直觉）**
一套指标体系（indicator system）在测量学上有三种与"数值计算本身"无关的坏法：
1. **构念失效（construct invalidity）**：数字在动，但没在测它声称要测的东西。系统说"间隙 0.42m 安全"，可那 0.42m 里是一个半透明玻璃杯——数值对、语义错。
2. **覆盖漏洞（coverage hole）**：场景里存在任务相关的语义类别（泼洒的液体、人的手、散落电缆），却没有任何一层指标去追踪它。系统不是算错，而是**设计性失明**。
3. **标度失配（scale incommensurability）**：六层指标的阈值 τ_i 不在同一尺度上，"五条件软证书"是把苹果和橘子做成的合取式——某层失效可能被另一层"补偿"掉。

**VLM 为什么是对的药（直觉）**
VLM 是**开放词表的语义裁判**：它能把场景中任何可被语言表达的东西命名，并据此判断某个指标声称的指涉物是否真的成立。这恰好能审计上述三类失效：逐指标问"你的指涉物成立吗"（构念），枚举任务词表问"场景里有词表外的高危物吗"（覆盖），对状态对做偏好排序问"你的聚合序和语义序一致吗"（标度）。

**VLM 为什么是危险的药（直觉）**
VLM 慢（百毫秒级，进不了 50Hz）、会幻觉，且其漏检（false negative）是**系统性相关**的——换个说法、相邻帧，错误一起犯。若让它"授权"动作，等于把安全押在一个会自信说错话的裁判身上。因此本轮的**核心安全设计**是给它**单向否决权**：VLM 只能否决、只能加码，永不授权、永不放行；它失效就等于"审计缺席"，系统逐位退回 v9。

## 1. 研究问题（轮次升级版）

- **Q1（单向否决的安全性）**：在一套只会收缩可接受动作集的语义审计下，能否证明 v10 的可达不安全状态集 ⊆ v9？审计引入的"安全停驻"是否总落在 v9 已认证的动作集内？
- **Q2（VLM 召回的可审计边界）**：VLM 漏检是系统相关的，K-of-N 时间确认只能降虚警、不能补漏检；那么 SIA 究竟能对哪一类危害提供保证，其保证如何用一个可测量的"按类别召回"刻画？
- **Q3（时延-安全分工）**：VLM 查询间隔 Δ_v 与危害"起始到碰撞时间" T_c 满足什么不等式时，SIA 才可能及时否决？这如何把"运动学快危害"与"语义慢危害"清晰分工给 M₀ 与 SIA？
- **Q4（防 Goodhart）**：当 OTL 在线调整阈值 τ_i 以最大化数值奖励时，固定的审计协议能把多少"静默的构念漂移"变成"被标记的事件"？审计协议本身为何必须冻结？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 单向否决律（One-Sided Veto, SIA）**
语义审计输出 σ_sem ∈ {clear, warn, veto} 只能**收缩**可接受动作集：
A_acc(clear) ⊇ A_acc(warn) ⊇ A_acc(veto) = A_safe_stop。
任何执行路径都不得因 σ_sem 新增 v9 本不允许的动作。VLM 假阳性只损失活性，假阴性只回到 v9。

**P14 开放词表覆盖律（Open-Vocabulary Coverage, OVCM）**
指标系统必须对任务语言 L_task 做覆盖审计：由 L_task 诱导语义类别集 C，VLM 检出"场景中存在但无指标指涉"的类别即覆盖漏洞 H(t)；只有落在**动作走廊**内、严重度 ≥ s_min 的漏洞才升级为否决。覆盖是"相对任务语言"的覆盖，绝非绝对完备。

**P15 语义审计中性律（Semantic Audit Neutrality, SIA⊥）**
SIA 是 MW 契约表中一行可休眠模块；VLM 超时/失败/陈旧超过 T_stale ⇒ 注入中立元 σ_sem=clear、审计报告冻结 ⇒ 系统逐位等价 v9（引理 83 链）。审计协议（问题集 q_i、类别集 C、阈值 c_min/s_min/K_s/N_s）部署时**冻结**，永不针对 VLM 输出优化。

## 3. 与基线的接口（如何退化）

- SIA 失效/超时/陈旧 ⇒ σ_sem≡clear，审计不参与决策，逐位等价 v9（新 Level-1）；
- σ_sem=veto ⇒ 仅允许安全停驻集 A_safe_stop（⊆ v9 已认证动作），K_eff←1，强制 M₀ 硬检查；
- σ_sem=warn ⇒ K_eff←max(1,K_eff−1)、β←β+β_sem（语义余量膨胀），仍是 v9 动作子集；
- 词表外盲区 ⇒ 显式记录"未审计类别"，交 v9 的 M₀ 运动学兜底，**不声称覆盖**；
- 其余退化（AC/MW/ID/DA/SPR/Cal）逐级继承 v9 五级链。

## 4. 预期贡献

1. **语义指标审计（SIA）**：把"指标体系有效性"从论文假设变成运行时可观测的元指标（构念残差 γ、覆盖漏洞 H、秩一致性残差 ρ_rank）；
2. **单向否决安全定理**：证明只收缩动作集的审计可安全叠加在任意已认证控制律之上（v10 安全性 ⊒ v9）；
3. **VLM 的可审计边界**：用"按类别召回 × 时延不等式"给出 VLM 在实时控制中的**可用性判据**，明确它只管语义慢危害、不管运动学快危害；
4. **防 Goodhart 的冻结审计协议**：与在线自适应（OTL）解耦，把指标漂移从静默故障转为可测量事件。

## 5. 本轮最大风险

**一句话**：SIA 的权威建立在 VLM 的**召回**上，而 VLM 漏检跨帧、跨换述**系统性相关**——K-of-N 时间确认只压虚警、不补漏检，于是系统可能恰在它被引入要捕捉的那个分布外语义危害上给出自信的 "clear"，即**把语义盲区盖章认证为安全**。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| I = {(m_i, ρ_i, g_i, τ_i)} | 指标系统：指标泛函、自然语言指涉物（构念）、极性、阈值 |
| C_I = {ρ_i} | 已被指标系统覆盖的语义指涉集合 |
| L_task | 任务语言；诱导语义类别集 C(L_task) |
| V(o,q) → (ℓ,p,κ) | 语义裁判：观测 o、问题 q ⟶ 序数答案 ℓ、置信 p、可选接地区域 κ |
| γ_i(t) ∈ {0,1} | 构念残差（危险方向）：数值判"过"而语义判"不过" |
| H(t) = P_t \ C_I | 覆盖漏洞：场景存在但无指标指涉的高危语义类别 |
| ρ_rank(t) | 秩一致性残差：VLM 成对偏好序与数值复合序的 Kendall τ |
| d(t) = (γ, H, ρ_rank)^{ts} | 带时间戳的语义审计报告 |
| σ_sem ∈ {clear, warn, veto} | 语义证书（单向：只能收缩动作集） |
| A_acc(σ) | 在证书 σ 下的可接受动作集 |

| T_stale, Δ_v | VLM 报告陈旧上限、查询间隔 |
| Π_audit | 冻结审计协议（问题集、类别集、阈值），定义 549 |

**定义 540（指标系统 Indicator System）**
I = {(m_i, ρ_i, g_i, τ_i)}_{i=1}^n，其中 m_i: S→ℝ 为指标泛函；ρ_i ∈ L 为该指标**声称测量的自然语言指涉物（构念）**；g_i∈{+1,−1} 为极性（+ 表示越大越安全）；τ_i 为阈值。六层层级 M 是 I 的一个分块实例。**关键约定**：每个 m_i 必须显式登记 ρ_i，否则该指标为"无构念指标"，默认不可信。

**定义 541（语义裁判 Semantic Referee）**
V: (o,q) ↦ (ℓ,p,κ)，q 为带序数答案集的封闭验证问题（如"动作走廊内是否存在对抓取构成语义威胁的物体？"），ℓ∈Y_q。**V 不被假设正确或已标定**；安全论证只依赖其被**单向使用**（定义 546）。

**定义 542（构念残差 Construct Gap，直觉→定义）**
直觉：只惩罚"数字说安全、语义说危险"这一个方向，因为反方向（数字保守、语义乐观）本就安全。定义：
γ_i(t) = 1 ⟺ [m_i 在 τ_i 下判 pass] ∧ [V(o,q_i) 判 fail] ∧ [p_i ≥ c_min]；否则 0。γ(t)=(γ_i)_{i∈I_crit}。单帧 γ 不直接否决，需经时序确认（定义 545/547）。

**定义 543（覆盖漏洞 Coverage Hole）**
由 L_task 诱导类别集 C(L_task)（任务规格中的物体/关系/物质词表）。存在检测 P_t = {(c, conf_c, sev_c) : V(o,"场景/动作走廊内是否存在 c？")=yes}。覆盖漏洞：
H(t) = { (c,·,·) ∈ P_t : c ∉ C_I, conf_c ≥ c_min, sev_c ≥ s_min, c 命中动作走廊 }。
落点由 VLM 接地 κ 与走廊多边形求交；交为空则不升级（抑制骚扰）。sev_c 由部署期人工小表给定（避免 VLM 输出直接充当严重度）。

**定义 544（语义审计报告 Semantic Audit Report）**
d(t) = (γ(t), H(t), ρ_rank(t))^{ts}，附各子项时间戳。ρ_rank 由 IP-357 的秩一致性探针给出：在同一任务下采样 M 对状态，问 VLM"哪个更安全"，得偏好序；与数值复合序做 Kendall τ，作为**聚合/权重（MetaWeight）的构念校验残差**。ρ_rank 只用于**标记**（告警/离线复盘），不自动改权重——防 Goodhart。

**定义 545（语义证书 Semantic Certificate）**
σ_sem(t) 由**时序确认 + 信念**决定：
- veto ⟺ ∃i∈I_crit: γ_i 连续 K_s/N_s 帧为 1，或 ∃c∈H(t): sev_c=high 且 b_c(t) > b_veto；
- warn ⟺ 仅低严重度漏洞或孤立 γ，或 b_c∈(b_warn, b_veto]；
- clear ⟺ 其余（含报告陈旧）。
K_s/N_s 是"确认式"滤波，用于压虚警**而非补漏检**；这一点在引理 89/91 中被显式量化。

**定义 546（单向否决门 One-Sided Veto Gate）**
可接受动作集按证书单调收缩：
```
A_acc(clear) = A_acc^{v9}
A_acc(warn)  = { ζ ∈ A_acc^{v9} : K_eff(ζ) ≤ K_eff^{v9} − 1 ∧ β(ζ) ≥ β^{v9} + β_sem }
A_acc(veto)  = A_safe_stop           （⊆ A_acc^{v9}，因安全停驻由 AC 中止点保证）
```
故 A_acc(clear) ⊇ A_acc(warn) ⊇ A_acc(veto)。**任何代码路径不得从 σ_sem 获得 v9 之外的动作。**

**定义 547（语义危害信念 Semantic Hazard Belief）**
VLM 低帧率、高时延，故对每类 c 维护泄漏积分，并采用**非对称时间常数**（确认快、清除慢，防抖与防过早清除）：
```
b_c ← λ_conf·b_c + e_c          （e_c=1 当本帧 VLM 确认）
b_c ← λ_clear·b_c               （无确认时衰减，λ_clear 接近 1）
b_c ← 0                         仅当连续 T_clear 帧 VLM 明确"不存在"该 c
陈旧：若 now − ts > T_stale ⇒ 报告作废、σ_sem←clear、b_c 冻结（不升不降）
```
非对称衰减是安全关键：不确定时**保持**否决，而非因超时释放否决。

**定义 548（按类别召回预算 Per-Category Recall Budget）**
对每类 c ∈ C(L_task)，部署期离线估计 VLM 的单帧召回 r_c 与虚警率。SIA 的安全承诺只对满足 r_c ≥ r_min 的类别成立；r_c < r_min 的类别列入"未审计清单"，不得声称覆盖，必须由 v9 的 M₀ 运动学兜底。**这是把 VLM 从"全能裁判"降格为"有档案的传感器"。**

**定义 549（冻结审计协议 Frozen Audit Protocol）**
Π_audit = ( {q_i}, C(L_task), c_min, s_min, K_s, N_s, b_warn, b_veto, β_sem, T_stale ) 在部署时一次性冻结并纳入认证包；OTL 只允许调整数值层阈值 τ_i，**不得读写 Π_audit**。审计协议的任何变更都是新的版本、需重新认证。理由：若协议可针对 VLM 反馈优化，则系统会学到"让裁判闭嘴"，构成 Goodhart。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变；每层指标补登指涉物 ρ_i（定义 540）。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变；其权重合法性由 ρ_rank（定义 544）**审计**而非直接修改。
**定义 521（DA-OTL）** 继承 v9 不变；OTL 自适应域 τ_i 的变化被 γ（若影响已覆盖构念）与 H（若产生新覆盖漏洞）审计，形成"自适应—审计"闭环。
**升级定义 496（软证书，v10）** δ_trigger 增加**语义合取项**：
```
δ_trigger = { σ<τ_safe ∧ γ_grasp ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid ∧ σ_sem=clear }
```
且由 P13，σ_sem 只能把 δ_trigger 由真变假、不能由假变真 ⇒ 九不变式的安全侧单调保持。
**升级定义 531（软硬约束衔接）** σ_sem=veto 直接作为块级 M₀ 入口：立即切换至安全停驻，不等块边界。

## 3. 关键算法骨架

```python
# IP-357 SemanticIndicatorAuditor：语义指标审计器（2Hz，异步）
class SemanticIndicatorAuditor:
    def __init__(self, vlm, indicator_system, task_language, protocol):
        self.V = vlm
        self.I = indicator_system            # {(m_i, rho_i, g_i, tau_i)}
        self.C = enumerate_categories(task_language)  # C(L_task)
        self.P = freeze(protocol)            # 定义 549：冻结，永不优化

    def construct_gaps(self, obs):
        gamma = {}
        for (m_i, rho_i, g_i, tau_i) in self.I.critical():
            q_i = self.P.question_for(rho_i)             # 冻结问题（定义 542）
            ell, conf, _ = self.V(obs, q_i)
            num_pass = (g_i * (m_i(obs) - tau_i) >= 0)    # 数值判定
            sem_fail = (ell == 'fail') and (conf >= self.P.c_min)
            gamma[m_i] = int(num_pass and sem_fail)       # 仅危险方向
        return gamma

    def coverage_holes(self, obs, corridor):
        present = []
        for c in self.C:                                  # 开放词表枚举
            ell, conf, kappa = self.V(obs, self.P.presence_q(c))  # 冻结问句
            if ell == 'yes' and conf >= self.P.c_min \
               and self.P.severity(c) >= self.P.s_min \
               and intersects(kappa, corridor):           # 仅动作走廊内
                present.append(c)
        covered = {self.P.category_of(rho) for rho in self.I.referents()}
        return [c for c in present if c not in covered]   # 定义 543

    def rank_residual(self, obs_samples):
        pairs = sample_pairs(obs_samples, self.P.m_pairs)
        sem_order = self.V.pairwise_safety(pairs)          # VLM 偏好序
        num_order = self.numeric_composite_order(pairs)    # 数值复合序
        return kendall_tau(sem_order, num_order)           # 定义 544，仅告警

    def audit(self, obs, corridor):
        return AuditReport(self.construct_gaps(obs),
                           self.coverage_holes(obs, corridor),
                           self.rank_residual(self.P.calib_pool),
                           ts=now())


# IP-359 SemanticHazardBelief：非对称泄漏积分（定义 547）
class SemanticHazardBelief:
    def __init__(self, P):
        self.P, self.b = P, defaultdict(float)

    def update(self, report, now):
        if now - report.ts > self.P.T_stale:               # 陈旧 ⇒ 冻结 + 中立
            return 'clear'
        for c in report.holes:
            self.b[c] = self.P.lam_conf * self.b[c] + 1.0
        for c in set(self.b) - set(report.holes):
            self.b[c] *= self.P.lam_clear                  # 清除慢
        return None

    def certify(self, report, now):
        stale = (now - report.ts > self.P.T_stale)
        if stale:
            return 'clear'                                 # 中立元（引理 88）
        if any(report.gamma[i] for i in report.gamma if self._sustained(i)):
            return 'veto'
        if any(self.b[c] > self.P.b_veto for c in self.b):
            return 'veto'
        if report.holes or any(self.b[c] > self.P.b_warn for c in self.b):
            return 'warn'
        return 'clear'


# IP-358 OneSidedVetoGate：单调收缩（定义 546）
def one_sided_gate(A_v9, K_eff_v9, beta_v9, sigma, P):
    if sigma == 'veto':
        return A_v9.safe_stop_set()                        # ⊆ A_v9
    if sigma == 'warn':
        return [z for z in A_v9
                if z.K <= max(1, K_eff_v9 - 1) and z.beta >= beta_v9 + P.beta_sem]
    return A_v9                                            # clear：逐位等价 v9
```

## 4. 推导

**引理 87（单向否决的安全性单调性）** 设 v9 的每条被接受动作均由引理 82 在证书 (K_eff^{v9}, β^{v9}) 下认证，且安全停驻 A_safe_stop ⊆ A_acc^{v9}。则由定义 546，对任意 σ_sem，A_acc^{v10}(σ_sem) ⊆ A_acc^{v9}。于是 v10 在每个决策点执行的动作都在 v9 的已认证动作集内（或为 v9 允许的安全停驻），逐点归纳得 Reached_unsafe(v10) ⊆ Reached_unsafe(v9)。故九不变式与 v9 安全性由 v9 引理 80–86 直接传递。∎

**引理 88（中立元与 v9 逐位等价）** SIA 作为 MW 契约表一行，超时/失败/陈旧 ⇒ fail_value=clear，且 50Hz 路径不读任何 SIA 中间量、仅读 σ_sem；σ_sem=clear 时 one_sided_gate 返回 A_v9 恒等。故此时可观测行为与 v9 逐位一致（与引理 83 同构）。∎

**引理 89（Goodhart 探测下界）** 设 OTL 对阈值 τ_i 的调整使某真实构念偏离，且该偏离落在类别 c 的审计范围、VLM 对 c 的单帧召回为 r_c、确认窗需 K_s 次。则一次"危险漂移事件"被 σ_sem 标记的概率满足
P(flag) ≥ 1 − (1 − r_c)^{K_s} ≥ K_s·r_c·(1 − r_c)^{K_s−1}，
而漏检概率 ≤ (1 − r_c)^{K_s}。**注意**：该式在 r_c<1 时仍随 K_s 增大而单调下降，但下降的只是"同类别内独立漏检"；若漏检跨帧相关（实际如此），应以有效召回 r_c^{eff} 代入，K_s 的收益远小于上式——这正是引理 91 与最大风险的来源。∎

**引理 90（覆盖的相对完备性下界）** 覆盖完备性只在 C(L_task) 与 VLM 词表的张成空间内成立：任何不可由 L_task 表达、或不在 VLM 词表内、或无接地能力的语义危害，H(t) 恒不包含之。故"未审计清单"必须显式外化，安全承诺表述为"对 C(L_task) 中 r_c≥r_min 的类别成立"。∎

**引理 91（时延-安全可行性不等式）** 设 VLM 查询间隔 Δ_v、确认窗时延 K_s·Δt、安全停驻耗时 T_stop、危害 c 的"起始→碰撞时间" T_c。SIA 对 c 的否决能及时生效的必要条件为
Δ_v + K_s·Δt + T_stop ≤ T_c。
推论（**分工定理**）：若 T_c 小于该下界（运动学快危害），SIA 在结构上无法保证；此类危害必须且只能由 v9 的 M₀/AC 逐步守卫覆盖。SIA 的合法辖区是**慢变语义危害**（T_c 大于百毫秒级）。这解释了为何 SIA 是审计层而非控制层。∎

**引理 92（词表外盲区）** 对任意 v10 运行，存在场景 S* 使 M₀ 与 SIA 同时给出 pass/clear 而真实存在安全违背：S* 含一语义危害 c* ∉ C(L_task) ∪ Vocab(V)。证明：由定义 543，H(t) 仅在 C(L_task) 上枚举；由定义 542，γ 仅在已登记 ρ_i 上计算；c* 不进入任何一项，故两者均无信号。∎（此引理不是缺陷，而是本方案安全边界的**诚实声明**，并直接导出本轮最大风险。）
