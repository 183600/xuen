### 第 6 轮灵感驱动研究记录（新循环第 1 轮 · 综合提炼轮，承接 CADVS-v5）

**灵感词**：创新点提炼、演示方案

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议器升级为条件流匹配（FMPP）、记忆升级为嵌入+固化（LMEM-v2）、人因升级为情感调制（FAMK），并用「定理 6 证书不变性」把框架推广为「任意生成器 + 认证边界」（CGE），执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮**不新增安全机制、不新增硬门、不改变任何阈值**，而是一次反向操作：v1~v5 已累积 24+ 模块（IP-473~496）、七硬门、八条定理、五级执行集嵌套，边际创新递减而「创新熵」递增——每个新模块都在稀释「这个纲领到底发现了什么」。两个灵感词恰好要求把研究从「还能加什么」切换到「什么是承重的」以及「如何用一场**允许失败**的演示把它钉死」。产物是两个元模块：IP-497 贡献提炼账本（CDL）与 IP-498 可证伪演示协议（FDP），并对 v5 架构做**减法审计**。因为本轮不触碰信任边界，执行集保持不变：Exec_v6 := Exec_v5。

**直觉与动机**：

1. **创新点提炼 → 贡献不是模块清单，而是一组「删掉就会塌」的承重命题**。直觉：一个 24 模块的系统对外行像创新，对审稿人像负债——他们只会问「所以呢？哪一个是新的？」严谨化：把每个候选贡献写成单元 u=(C 命题, M 机制, E 证据, F 证伪器)，定义承重度 L(u)（删去 M 是否使某个顶层保证/主指标变化超出噪声）、新颖度 N(u)（相对先前工作集 P 是否被包含）、可证伪度 F(u)（是否存在一个实验能判 C 为假）、耦合度 κ(u)。打分 CS(u)=L·N·F/(1+κ)。按 CS 排序只留前 3 为「脊柱」，其余降级为「支撑件/见证实例」。提炼结论：v1~v5 的承重命题只有三条，七门的具体内容是**实例化**而非独立贡献。

2. **演示方案 → 好的演示不是「证明它能工作」，而是「设计一个它可能当场失败的实验」**。直觉：安全系统的 demo 极易退化成魔术——挑成功案例、隐藏回退、用平均值掩盖尾部、把构造使然的性质说成经验发现。严谨化：为每条脊柱命题配一个 kill experiment（若命题为假，该实验必然露馅），把「预期失败模式」写进脚本，并强制包含红队、消融与「当门不充分时会怎样」的诚实分支。演示对象不是「机器人多能干」，而是「证书边界是否真的独立于智能」。

3. **减法审计 → 主动合并/降级模块，用更少的名字讲同一个故事**。直觉：若 C1（证书/提议分离）成立，则 FMPP、LMEM-v2、FAMK 都只是「被冻结边界包住的任意生成器/调制器」，它们是 C1 的**见证实例**，而不是三个并列创新。严谨化：定义「支撑件」为只影响完备性/时延/成功率的模块（可替换、可删除而顶层安全保证不变），「承重件」为影响执行集或安全保证的模块。审计结论：v5 的四个新模块没有一个**定义**安全边界——FMPP 与 LMEM-v2 的提议部分安全中性（只通过支撑集收缩影响 Exec，且只减不增），FAMK 与新颖度裁决是**单调收紧**通道。这本身就是 C1 的最强证据，也是本轮最重要的「负创新」发现：删掉名字，保留不变量。

**脊柱三命题（提炼结果）**：

- **C1 证书/提议分离（Certification–Proposal Separation）**：执行集只由冻结门谓词与阈值决定，对任意提议分布 π（规则库、流匹配、扩散、LLM、随机噪声）不变；提议只能改变「尝试什么」，不能改变「什么被认证」。操作化：对固定探针语料，门判定函数 kc_i(x) 跨生成器逐点相同；实际接受集 = 门集 ∩ supp(π) ⊆ 门集。证伪器 F1：同一门谓词下两个生成器对同一 x 得到不同判定（隐藏耦合/预处理泄漏），或某生成器通过全门却以超界概率违反物理契约（说明门而非分离才是边界）。
- **C2 信任棘轮（Monotone Trust Ratchet）**：所有自适应通道（情感调制 γ≥1、记忆/新颖度 fail-closed、固化、级联回退）都是收缩算子，只能使 Exec 变小，永不变大；系统里不存在可被博弈的「扩张算子」。证伪器 F2：找到任一输入使 Exec(adapted) ⊄ Exec(static)，或对抗输入在不改门代码时提高接受率（例如伪造平静表情换更大安全边际）。
- **C3 可靠实时级联（Sound Real-Time Cascade）**：昂贵认证可被摊销，**当且仅当**廉价级是完整门的必要条件的松弛（CheapReject ⊇ FullReject，即 FullAccept ⊆ CheapAccept），且「全灭」回退到安全规则提议而非放行；此时级联接受集等于全量接受集，且不引入新的假接受。证伪器 F3：找到廉价级误拒而全量级接受的轨迹超出完备性损失界（非松弛），或级联放行而全量级拒绝（不可靠），或控制环 P99 超预算。

**关键洞见**：v1~v5 的叙事是「不断加能力」；本轮把叙事改为「**一个不变量 + 三条承重命题 + 一场允许失败的演示**」。真正稀缺的不是又一个模块，而是一个**可被第三方复现、可被红队证伪、且命题为假时会公开失败**的证明性演示。若 C1~C3 成立，「任意生成器 + 冻结信任边界 + 单调收紧」就是本纲领可迁移的贡献；若任一被证伪，我们也明确知道该放弃哪一支，而不是继续在 24 个模块上叠加第 25 个。

**形式化目标（元层，非新安全机制）**：
1. CDL：贡献单元 u=(C,M,E,F)；承重度 L、新颖度 N、可证伪度 F、耦合 κ；CS=L·N·F/(1+κ)；输出「脊柱/支撑件/降级」三分表与「claim→figure→experiment→falsifier→threshold」证据矩阵。
2. FDP：每条脊柱命题配 kill experiment K_i 与判假阈值 θ_i；演示脚本含红队、消融、诚实失败分支；禁止选择性汇报（预注册指标与随机种子）。
3. 减法审计：定义承重件/支撑件；论证 v5 新增模块全部位于信任边界之外（由定理 6），故 Exec_v6 = Exec_v5，且「新增承重创新数 = 0」。
4. 演示不变量：接受集指纹 H_acc 在换生成器时逐点不变（ε 内）；棘轮审计 ∀a: Exec(a) ⊆ Exec(static)；级联可靠审计 CheapReject ⊇ FullReject 且 CascadeAccept = FullAccept（引理 47）。
5. 诚实边界（引理 48）：有限输入网格上的棘轮审计不能证明全域单调性，只能作经验证据；门的**充分性**（规格鸿沟）本轮不证明、也无法由本演示证明。

**本轮最大风险**：**演示的同义反复**——C1 之所以「成立」是因为门被定义为边界、接受集相同是构造使然而非经验发现；演示只能证明架构自洽，不能证明七门本身充分；真正致命的「规格鸿沟」（门全过但世界仍不安全）被悬置，于是我们可能用一场精致、可复现、却空洞的演示，为一张可能系统性错误的证书背书。

## 0. 本轮定位：元轮（减法轮），不新增安全机制

### 0.1 触发诊断：创新熵

v1~v5 的演进是单调加法：IP 编号从 473 增至 496，硬门恒为七，定理增至八，执行集嵌套五级。加法带来两个隐性代价：

1. **注意力稀释**：对外只能讲「我们有一个大系统」，讲不出「一个可被复用的不变量」。评审/复现者无法判断哪个模块是承重的，也无法设计针对性证伪。
2. **维护负债**：每加一个模块就多一处与冻结门交互的接口（R52 锚点维护负债、R59 条件接口漂移），而新增模块的安全增益被定理 6 证明为「只能收紧、不能扩张」——即安全上的边际收益递减，工程上的耦合成本递增。

本轮把「创新点提炼」「演示方案」统一为一次**可证伪性工程**：先把承重命题提炼出来（IP-497 CDL），再为每条命题设计一个会公开失败的演示（IP-498 FDP），最后做减法审计，把 v5 的四个新模块重新归类为见证实例。**本轮不产生新的执行集**：Exec_v6 := Exec_v5，七门与 τ^4/τ^5 冻结只读。

## 2. 脊柱三命题：精确陈述

### 2.1 C1 证书/提议分离

**陈述**：设门栈 G = ∧_i kc_i(·; τ_i) 冻结只读。对任意提议分布 π，认证过程为 `certify(x) = G(x)`，与 π 无关。故对固定探针语料 D：∀x∈D，kc_i(x) 跨生成器逐点相同；实际接受集 Exec(π) = {x ∈ supp(π) : G(x)=1} ⊆ Exec(G)。γ≡1、无调制时，π=规则库给出 v4 执行集。

**证明依赖**：定理 6（门是轨迹空间上的固定谓词，换提议不换谓词）+ 执行集嵌套。

**诚实的操作化**：C1 有「定义使然」的成分——若实现严格分层，逐点判定当然相同。因此它的**经验内容**只有两条：(i) 不存在隐藏耦合（生成器特有的预处理改变了 x 或 c，从而改变 kc 的输入）；(ii) 门本身充分。D1 只能测 (i)；(ii) 属于规格鸿沟，本轮不声称解决（见 4.4 与第 7 节）。

### 2.2 C2 信任棘轮

**陈述**：设静态基线 Exec(static) = {x : G(x)=1}。所有自适应通道 a ∈ A（γ_i ≥ 1、n_flow 拒绝、固化后 θ_FM 更新、级联回退）满足 Exec(a) ⊆ Exec(static)。即 A 中不存在扩张算子；系统无法用任何「表现更好/更配合」的信号换取更大安全边际。

**证明依赖**：定理 5（γ≥1 ⇒ 门通过集单调缩）、定理 7（固化只改提议器 + 门冻结 ⇒ 执行集只缩）、fail-closed 回退（无候选 → 规则提议，不放行）。

**诚实边界**：这是**结构性**保证，强于统计防御；但只保证「不放大」，不保证「收紧得对」（可能误收紧，见 R55/误收紧率）。

### 2.3 C3 可靠实时级联 + 引理 47

**陈述**：级联为 `G_cheap → G_val(VACK) → G_bal(BCK 预览)`，`G_full = G_cheap ∧ G_val ∧ G_bal`。若廉价级满足**必要条件的松弛**：

```
FullAccept ⊆ CheapAccept   ⇔   CheapReject ⊇ FullReject
```

且「cheap 全灭」时回退到安全规则提议（而非放行），则：

1. **可靠性**：CascadeAccept ⊆ FullAccept（级联不会放行全量级会拒的轨迹）；
2. **完备性**：在全量级本会接受且提议覆盖到的轨迹上，CascadeAccept = FullAccept（廉价级不误杀全量级接受者）；
3. 故在回退被计为「拒绝/规则替代」时，级联接受集与全量级一致，级联只改变时延，不改变认证边界。

**引理 47（级联可靠性）**：
> 若 CheapReject ⊇ FullReject，且级联对廉价级幸存者逐一执行剩余门、对全灭执行安全回退，则 CascadeAccept = FullAccept（在提议支撑内），且级联不引入新的假接受。

**证明**：设 x ∈ CascadeAccept。则 x 通过 G_cheap 且通过 G_val、G_bal，故 G_full(x)=1，即 CascadeAccept ⊆ FullAccept。反向：设 x ∈ FullAccept 且在提议支撑内，则 G_cheap(x)=1（因 FullAccept ⊆ CheapAccept），且 G_val(x)=G_bal(x)=1，故 x 进入幸存者并通过剩余门，即 FullAccept ⊆ CascadeAccept。回退分支只在 CheapAccept 为空时触发，此时 FullAccept 也为空（因 FullAccept ⊆ CheapAccept），不改变等式。∎

**工程含义**：级联的正确性**完全押在「廉价级是必要条件」这一条**上。任何「启发式预筛」若可能拒绝一个全量级会接受的轨迹（或反之），都会破坏 C3；因此 FDP 的 D3 必须直接审计 `CheapReject ⊇ FullReject`，而不是只看端到端成功率。

### 2.4 引理 48（棘轮审计的有限性，诚实边界）

> 在有限输入网格 A_grid 上验证 ∀a∈A_grid: Exec(a) ⊆ Exec(static)，只给出经验证据，不构成对连续输入空间 A 的全域单调性证明。

**证明**：单调性命题为 ∀a∈A，属不可被有限样本穷尽的全称命题；A_grid 上无反例只说明网格内无反例。要得到全域保证，必须对每个通道**解析地**证明其算子单调（定理 5/7 已对 γ、固化给出；其余通道需逐条补证），网格审计仅作回归防线。∎

## 3. 演示方案（FDP）

### 3.1 演示论点（一句话）

**「换脑不换闸」**：把机器人的提议引擎换成任意生成模型（规则/流匹配/扩散/LLM/随机），安全证书边界一寸不动；每一路自适应（情感、记忆、新颖度）都只会把闸门收得更紧，而不会为「表现得更配合」松开任何一道门。

### 3.2 演示场 D1~D5

| 场次 | 命题 | 做什么 | 观众看到什么 |
|---|---|---|---|
| D1 换脑 | C1 | 冻结门栈，依次换 5 个生成器提议同一批任务；逐探针对比门判定，并对比实际接受集与假接受率 | 接受集指纹逐点相同；任务成功率随「脑」变好而升高，但安全违例率不变 |

### 3.5 指标定义

- **接受集指纹一致率**：跨生成器逐探针门判定一致的比例，目标 1.0。
- **假接受率差**：各生成器实际假接受率与认证上界之差，目标 ≤ ε（CI 内）。
- **执行集增长**：|Exec(a) \ Exec(static)|，目标 0，理想 < 0（收紧）。
- **级联可靠性泄漏**：|CascadeAccept \ FullAccept|，目标 0。
- **级联完备性损失**：|FullAccept \ CascadeAccept| / |FullAccept|，目标 ≤ δ。
- **控制环 P99**：目标 < 0.6 ms（v5 设计值 0.55 ms）。
- **固化遗忘率**、**误收紧率**、**红队门博弈通过率**：沿用 v5 定义。

| 指标 | 判假阈值 θ | 设计目标（预期） | 依据 |

| 接受集指纹一致率 | < 1.0 即判 C1 假 | 1.0（逐点） | 门谓词冻结，逐点同函数 |

### 3.7 反自欺协议

1. **预注册**：演示前锁定指标、阈值、随机种子、语料切分，写入版本控制，演示后不得改。
2. **尾部优先**：只报 P99/P99.9 与最差场景，不用均值掩盖尾部。
3. **回退可见**：所有 fail-closed 回退在界面上显式计数，不得隐藏为「成功」。
4. **构造性声明**：凡由定义/定理直接推出的性质（如逐点门判定一致），在演示中明确标注「构造使然」，不计为经验发现。
5. **允许失败**：K1~K3 任一触发，演示按「公开判假」分支收尾，而不是删掉该场次。

## 4. 叙事重构与交付物

### 4.1 三层叙事

- **一句话**：把可学习的一切（提议、记忆、人因）放进一个冻结、只会收紧的认证边界里——换脑不换闸。
- **一段话**：现有生成式机器人把安全过滤器绑在模型上，换模型就要重训过滤器，且过滤器可被策略博弈。我们把「生成什么」与「认证什么」分离：门谓词与阈值冻结，任何生成器只能改变尝试的分布，不能改变认证边界；所有自适应通道被设计成收缩算子，只能收紧、不能放松。三条命题（分离、棘轮、可靠级联）各配一个会公开失败的演示。
- **摘要骨架**：问题（生成式提议与安全认证耦合）→ 观察（执行集只由门决定）→ 机制（冻结门 + 单调收紧 + 必要条件级联）→ 证据（换脑/棘轮/级联三场 kill experiment）→ 边界（门充分性未证，规格鸿沟）。

### 4.4 我们不声称什么（诚实边界）

1. **不声称门是充分的**：七门可能系统性漏掉某个物理/人因耦合，演示无法证明规格正确性（规格鸿沟）。
2. **不声称 SOTA 任务成功率**：成功率随「脑」变化，正是 C1 的预期；我们不把成功率当卖点。
3. **不声称 OOD 鲁棒**：密度新颖度有原理性盲区（v5 引理 43），只靠 fail-closed 回退兜底。
4. **不声称全域单调性已被证明**：除定理 5/7 覆盖的通道外，其余靠有限网格审计（引理 48），只是经验证据。
5. **不声称解决加性价值假设**：B4 继承自 v4，仍未解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**演示的同义反复**——C1 之所以「成立」是因为门被定义为边界、接受集相同是构造使然而非经验发现；演示只能证明架构自洽，不能证明七门本身充分；真正致命的「规格鸿沟」（门全过但世界仍不安全）被悬置，于是我们可能用一场精致、可复现、却空洞的演示，为一张可能系统性错误的证书背书。
