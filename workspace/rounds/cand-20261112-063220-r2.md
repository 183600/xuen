# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「UniBot-V1」×「物体泛化」）

> 第 57 轮把安全的赌注从"模型置信"推进到"证据质量"，用 MFSL/XMC/PTM 分别补上少样本校准、跨模态对账与个性化信任；但它默认了一个从未被审计的中介：**证据总是关于某个"已经被正确指认"的物体或区域属性的**。真实部署里，"这是什么东西"本身就是一个会错、会漏、会被外观欺骗的推断；而 UniBot-V1 作为统一本体、统一表征、统一策略的第一版，倾向于把没见过的物体**平滑地插值**到已见物体之间。物体泛化于是不是"识别得更准"的感知问题，而是**证据链的根节点问题**：身份一旦被语义相似性带偏，少样本先验、跨模态一致、能力判断会一致地、安静地错。这正是统一模型最危险的失败形态——错误跨任务相关，冗余不产生独立证据。本轮把命题升级为 **"身份可证伪、泛化可度量、迁移可追责的物体级证据承诺"**：身份假设进入显式台账并允许被探针推翻；泛化能力用**任务条件化的物理距离**与**物体级共形证书**度量；UniBot-V1 的能力被刻画为带**共模相关修正**的能力包络，包络外一律隔离；跨物体先验迁移必须过"物理近邻验证 + 判别探针 + 负迁移回溯"三道闸门。

核心矛盾：
- **H29（统一表征 vs 局部失配）**：统一表征让泛化看起来平滑，安全需要的却是逐物体下界；平滑插值会跨过真实的不连续（把手、空腔、填充物、透明壳、铰接关节），而模型没有机制知道自己跨过了。
- **H30（语义相似 ≠ 物理相似）**：按外观/类别迁移先验最省探针，但决定成败的隐藏物理量（质量、质心、摩擦、刚度、脆性、可变形性）与外观只是弱相关；"像杯子"不能证明"能当杯子抓"。
- **H31（迁移收益 vs 共模污染）**：复用邻居证据能省探针，但共享表征使一次身份误判污染整簇物体与整条任务链；迁移越激进，错误越相关，"独立同分布"越假。
- **H32（泛化证明 vs 不可逆代价）**：要证明泛化就得在没见过的物体上试，但试可能弄坏物体或摔坏机器人；需要非破坏的物体级探针与可偿还的"泛化债"，而不是"没试过就默认安全"。

## 0. 直觉与动机

**灵感 1（物体泛化 → 身份是证据链的根，先验沿物体流形摊销但必须可证伪）**
直觉：第 57 轮让先验沿"区域"摊销；物体泛化把摊销轴换成"物体"。人拿起新杯子会先归入"杯状物"，借来质量、抓法、易碎性——高效，但也极易被骗：蜡烛杯、灌满水的"空"瓶、陶瓷外观的塑料件。关键是**身份假设必须能被动作检验，而不是感知模块输出的常量**。所以物体先验允许借，但每个借来的物理量都挂"来源物体 / 迁移距离 / 待检验"三标签；一次轻抬、一记轻敲、一次微推，就是推翻"它像看起来那样"的最小实验。

**灵感 2（物体泛化 → 任务条件化的物理距离，而非视觉嵌入距离）**
直觉：能否沿用邻居的证据，取决于**当前任务对哪些物理量敏感**。抓取对质量/摩擦/质心敏感，踩踏对刚度/稳定性/滑移敏感，插装对几何/公差敏感。于是泛化距离应是 d_skill=‖S_task⊙(θ_o−θ_{o'})‖，把属性差投影到任务敏感方向。视觉嵌入距离 d_sem 只能"提名邻居"，不能"签发证书"——它是提案，不是判决。

**灵感 3（UniBot-V1 → 统一策略的能力包络与插值隔离）**
直觉：统一模型的能力不是全空间均匀的，而是有洞、有脊、有悬崖的地形图。不能因为两个已认证物体之间的点"看起来在中间"就假定安全——泛化连续性假设在安全上不成立。于是为 UniBot-V1 建 **能力包络 E_κ**：只在被实测覆盖的 (任务, 物体) 单元内允许承诺；落在已认证单元之间但自身未认证的"插值区"进入隔离，补探针或降级。并且统一表征让失败跨物体相关，证书必须用**有效样本数 n_eff=n/(1+(n−1)ρ_cm)** 折算，不能假装每个物体是独立样本。

**灵感 4（UniBot-V1 → 共模失效：冗余不等于独立）**
直觉：第 57 轮的跨模态对账假设模态条件独立；但 UniBot-V1 的手眼、腕部、本体传感共享安装、时钟与分割模型，共因失效是常态。物体泛化把它放大：同一个"把蜡烛认成杯子"的分割错误会同时污染视觉先验、抓取规划与力控期望。因此物体级"多模态一致"只提供**相关的**证据；必须显式估计 ρ_cm 并给一致性加成打折。真正独立的证据只有**动作后果**：抬起来轻、敲起来空、推起来滑。

**灵感 5（合流 → 物体级证据门与 PCE++）**
直觉：第 57 轮证据门问"哪类证据、取证上下文是否允许"；本轮再加一问"**它到底在证明哪个物体、哪个物理量**"。新增 EV-obj（身份认证且物体级证书覆盖该物理量）、EV-transfer（物理近邻验证 + 判别探针通过，仅替代一次 L1 佐证）；不可逆接触仍必须有直接物理测量或带覆盖保证的证书。算子 PCE++ 把探针预算分成识别、测量、证伪三份，用统一 VOI 选择——**最值得做的探针，常常是那个能同时拆穿身份的探针**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（物体台账与身份假设 OCL）** 物体实例 o，物理属性 θ_o=(m,c,μ_s,μ_k,k,β,γ,ρ_e)（质量、质心偏移、静/动摩擦、刚度、脆性阈值、回弹、电阻抗等）；身份假设集 H_o={h_i} 带后验 p(h_i)，h_i 可为类别/实例/affordance 类型。证据事件 e=(o,p,m,ctx,verdict) 必须声明其**归属物体**与**所支持的物理量** p；禁止把未归属证据并入物体信念。身份熵 H(H_o)=−Σp log p；当 H>θ_id 或 top-1 后验 < p_id 时判"身份未定"，只能进入识别探针，不得签发任何物体级证书。身份合并不再由分割器静默完成：任何跨帧/跨实例合并必须留审计记录，并可由动作后果推翻。

**定义 140（物体泛化证书 OGC）** 任务敏感矩阵 S_t=∂ℓ_t/∂θ（ℓ_t 为任务损失/失效指示的代理），任务条件物理距离 d_skill(o,o')=‖S_t⊙(θ_o−θ_{o'})‖_W。认证物体集 𝒪_cert(t) 上的加权共形：C_{t,α}(o)={θ: |θ̂(o)−θ|≤Q_{1−α}({w_i·r_i})}，w_i=K(d_skill(o,o_i)/h)，h 为带宽。证书有效需：o 落在 𝒪_cert(t) 的物理支撑凸包内、有效样本 n_eff≥n_min、且 d_skill(o,𝒪_cert)≤R_gen。覆盖保证 ≥1−α_obj；支撑外一律退保守外包 C_hull（取邻居最坏值）或拒证。**泛化半径 R_gen 是任务相关的、可声明的量**，不是模型自报的"泛化能力"。

**定义 141（统一能力包络 UCE）** 对 UniBot-V1 策略 π_uni，能力 K(t,o)=P(success|t,o)；用共模相关 ρ_cm 折算有效样本：n_eff=n/(1+(n−1)ρ_cm)，并以 K_LB=LCB_κ 定义包络 E_κ={(t,o):K_LB(t,o)≥κ ∧ n_eff≥n_min}。**插值隔离**：若 o 位于两个已认证单元之间但自身不在 E_κ，仍判"未认证"，不得因"看起来在中间"而承诺。包络随模型版本冻结并做回归审计；跨物体失败相关 ρ_cm 由留一族（leave-one-family-out）残差估计并取置信上界。

**定义 142（跨物体迁移与负迁移闸门 XOT）** 候选源物体 N_sem(o)=kNN(d_sem)；但迁移前须用**度量探针** a_met（轻抬/轻敲/微推/小位移）估计 d_skill 的下界 d_skill^LB。迁移许可：d_skill^LB≤R_gen 且源物体∈𝒪_cert(t)。迁移权重 λ=clip(exp(−(d_skill^LB)²/2ℓ²),0,λ_max)·(1−ε_trans)；迁移先验按 λ 收缩，置信按 (1−λ·δ_trans) 折扣，并给 P_fail 加 δ_trans。**判别探针**：top-2 身份或 top-2 物理假设不可区分时，必须执行能最大分离它们的探针；不可逆接触不接受纯迁移证据。**负迁移回溯**：若事后 verdict 证伪某条迁移，标记迁移边 (o←o_src) 并沿迁移图乘法降权其全部后代证据（含已承诺记录），记入"泛化债"。

**定义 143（物体泛化证据门 OGE）** 证据类 EV-obj（身份认证 ∧ OGC 覆盖所证物理量 ∧ 非插值区）/EV-transfer（XOT 许可 ∧ 判别探针通过，仅可替代一次 L1 佐证）/EV-probe*/EV-visit/EV-margin/EV-xmodal/EV-human。硬规则：(a) 语义/视觉相似永不单独作为物理量证据；(b) 身份未定或新颖物体在隔离解除前禁不可逆接触；(c) 不可逆接触必要证据集={{EV-obj 且覆盖} ∨ 直接物理测量} ∪ 佐证，不含 EV-transfer/EV-xmodal；(d) 一条证据同时支撑多个物体时，只能按最弱归属物体的置信计入。

**定义 144（探-诺-演++ 算子 PCE++）** 每检查点：①更新物体身份假设 H_o 与物理台账；②若 H>θ_id 或 o∉E_κ ⇒ 分配识别/度量探针预算 k_obj；③计算 OGC 与迁移候选，执行度量探针与判别探针；④选 argmax_π[VOI_obj(π)−cost(π)]，VOI_obj 同时计入身份信息增益、敏感物理量方差下降与迁移假设证伪价值；⑤承诺 ⇔ ∃g:R≤δ_f(g) ∧ OGE 过 ∧ (t,o)∈E_κ；否则绕行→降档→L2 协商（τ_int(auth)）→安全停。终止预算 k_probes+k_cons+k_obj。

## 2. 关键算法伪代码（完整版见产物区）

```python
def object_certificate(o, task, ledger, model):
    if identity_entropy(o.H) > theta_id:
        return Inf('AMBIGUOUS', H=o.H)             # 身份未定：只许识别探针
    if not in_envelope(model.E, task, o) or novel(o, model.certified):
        return Inf('NOVEL', hull=conservative_hull(o, ledger))  # 隔离
    d = skill_metric(ledger.theta(o), model.certified, task)    # d_skill
    if d > R_gen:
        return Inf('OUT_OF_RADIUS', d=d)
    return Inf('CERTIFIED', C=weighted_conformal(model.calib, o, d), d=d)

def transfer_guard(o, src, task, ledger):
    d_lb = metric_probe_lower(execute_metric_probe(o), ledger.theta(src), task)
    if d_lb > R_gen or src not in ledger.certified(task):
        return None                                # 物理近邻不过：禁迁移
    lam = clip(exp(-d_lb**2 / (2*ell**2)), 0, lam_max) * (1-eps_trans)
    return Transfer(prior=shrink(ledger.theta(src), lam),
                    delta=lam*delta_trans, need=discriminator(o, src))

def object_evidence_gate(c, M, ledger, model):      # OGE 核心
    if c.ev == 'EV-obj':
        ok = ledger.identity_cert(c.o) and covers(model.cert(c.o, c.task), c.p) \
             and not in_interpolation_zone(c.o, model)
    elif c.ev == 'EV-transfer':
        ok = c.transfer.allowed and discriminator_passed(c) and c.level == 'L1'
    else:
        ok = inherited_gate(c, M)                   # EV-probe*/visit/margin/xmodal/human
    if c.irreversible and c.ev in ('EV-transfer', 'EV-xmodal'):
        return ('reject', 'semantic_or_transfer_on_irreversible', c)
    return ('ok', c) if ok else ('reject', 'object_evidence_insufficient', c)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| OCL | O(1)/证据；合并 O(H_o) | O(\|𝒪\|·d_θ) | 身份假设显式、无静默合并 |
| OGC | O(\|𝒪_cert\|·d_θ)/物体 | O(\|𝒪_cert\|·d_θ) | 任务条件距离诚实、支撑外拒证 |
| UCE | 查询 O(log N_cell) | O(\|T\|·\|𝒪\|) | K_LB 保守、ρ_cm 上界、插值隔离 |
| XOT | O(k_sem·C_met) | O(\|E_trans\|) | 物理近邻下界、迁移可回溯 |
| OGE | O(\|σ\|) | O(\|σ\|) | 无 EV-obj/测量即拒、迁移限 L1 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_o)·(C_VOI+d_θ)) | O(\|V\|+\|σ\|+\|𝒪\|) | 三预算终止、四态完备 |

**正确性定理（Object-Grounded Calibrated Soundness, OGCS 概要）**：在 A37–A40 上加 (A41) 身份台账诚实（身份熵与 top-1 后验可观测，误合并可由动作后果检出）；(A42) 物体级共形覆盖 ≥1−α_obj 且 d_skill 是行为差异的可声明代理；(A43) 能力包络下界诚实、ρ_cm 为保守上界；(A44) 迁移仅经物理近邻验证 + 判别探针，负迁移回溯完备。则：(i) 已认证物体上不可逆接触 P(fail)≤δ_f+ε_meta(k)+ε_obj(o)+δ_skill+δ_probe+ε_h+δ_trans·1[迁移]；(ii) 新颖/插值区在隔离解除前承诺数=0，误放行贡献 ≤δ_novel·α_obj；(iii) 交互单调性：物体机制只经"信念更准/加宽"或"动作更保守（隔离、降档、加探针）"起作用；(iv) PCE++ 在 k_probes+k_cons+k_obj 内终止于 {承诺, 绕行, L2 协商, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把"证据链的根"从区域/属性换成了**物体身份**，风险从"坏先验普遍"变成"身份误判即全局共模"——若 UniBot-V1 的分割/识别把一个物理性质迥异的新物体自信地归入熟悉类别，身份证书、跨物体迁移与能力包络会一致地给它背书，而统一表征使这一错误跨任务相关、无法靠多模态冗余洗掉；必须以"身份熵门 + 语义相似禁止单独作证 + 插值隔离 + 负迁移回溯"四道闸门，永远让动作后果而不是外观来签署物体级证据。

def ledger_update(ledger, e):                          # e=(o,p,m,ctx,verdict)
    o = ledger.resolve(e.raw)                          # 显式解析，禁止静默合并
    if e.merge_proposal:

def identity_gate(o, theta_id, p_id):
    H = entropy(o.identity.posterior)
    top1 = max(o.identity.posterior.values())
    return 'AMBIGUOUS' if (H > theta_id or top1 < p_id) else 'RESOLVED'

### IP-140 OGC（物体泛化证书：任务条件物理距离 + 加权共形）

```python
def object_generalization_certificate(o, task, ledger, calib):
    if identity_gate(o, theta_id, p_id) != 'RESOLVED':
        return Inf(cls='AMBIGUOUS', H=o.identity)
    if not inside_physical_hull(o, calib.certified(task)):
        return Inf(cls='NOVEL', hull=conservative_hull(o, ledger))   # 支撑外拒证
    d = skill_distance(ledger.theta[o], calib.certified(task),
                       S=task_sensitivity(task))                     # d_skill
    if d > R_gen(task):
        return Inf(cls='OUT_OF_RADIUS', d=d)
    w = [kernel(d_i / h) for d_i in d]
    C = weighted_conformal(calib.residuals(task), w, alpha=alpha_obj)
    n_eff = len(w) / (1 + (len(w) - 1) * rho_cm(task))
    if n_eff < n_min:
        return Inf(cls='UNDERPOWERED', n_eff=n_eff)
    return Inf(cls='CERTIFIED', C=C, d=d, n_eff=n_eff, ce=ce_obj(o))
```

### IP-141 UCE（UniBot-V1 统一能力包络与插值隔离）

```python
def competence_envelope(task, o, model, fam_holdout):
    cell = nearest_cells(model.E_grid, task, o)        # (任务, 物体) 网格
    K = model.competence[cell]                         # 经验成功率
    rho = upper_bound_corr(fam_holdout.residuals)      # 留一族估计 ρ_cm 上界
    n_eff = K.n / (1 + (K.n - 1) * rho)
    K_lb = lcb(K, kappa, n_eff)
    in_env = (K_lb >= kappa_comp) and (n_eff >= n_min)
    interp = between_certified(o, model.E_grid) and not in_env
    return Env(in_env=in_env, K_lb=K_lb, rho_cm=rho, interp=interp)

def commit_allowed(task, o, model):
    env = competence_envelope(task, o, model)
    return env.in_env and not env.interp                # 插值区仍按未认证处理
```

def cross_object_transfer(o, task, ledger, model):
    cands = knn_by_semantics(o, ledger, k=k_sem)       # 语义只提名
    out = []
    for src in cands:
        if src not in ledger.certified(task): continue

def retroactive_negative_transfer(edge, verdict, ledger):

def object_generalization_gate(c, M, ledger, model, persona, ood_reg):
    if   c.ev == 'EV-obj':
        cert = object_generalization_certificate(c.o, c.task, ledger, model.calib)
        ok = (cert.cls == 'CERTIFIED') and covers(cert.C, c.p) \
             and not competence_envelope(c.task, c.o, model).interp
    elif c.ev == 'EV-transfer':
        ok = (c.transfer is not None) and c.transfer.allowed \
             and discriminator_passed(c) and c.level == 'L1'
    elif c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok:
        return ('reject', 'object_evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-transfer', 'EV-xmodal'):
        return ('reject', 'semantic_or_transfer_on_irreversible', c)   # 硬禁令
    if c.o.identity.is_ambiguous and c.irreversible:
        return ('reject', 'identity_ambiguous', c)                     # 身份未定
    return ('ok', c)

def object_certificate_J(sched, log, M, ledger, model, consent_log, auth_log, ood_reg):
    for c in contacts(sched):
        st = object_generalization_gate(c, M, ledger, model, persona_of(c), ood_reg)

    if min(x.K_margin for x in sched) < budgets.theta_K: return ('reject', 'K_margin')
    if any(not commit_allowed(c.task, c.o, model) for c in contacts(sched)):
        return ('reject', 'outside_envelope_or_interp')

### IP-144 PCE++（探-诺-演++：识别 × 测量 × 证伪三预算）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, ledger, model):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        ledger = ledger_update(ledger, observe_object(cp, M))
        o = ledger.object_at(cp)
        while budget.object_left(o) > 0 and (
                identity_gate(o, theta_id, p_id) == 'AMBIGUOUS'
                or not commit_allowed(task, o, model)):
            cands = admissible_object_probes(cp, o, ledger, F_abs)  # 非破坏过滤
            if not cands: break
            p = argmax(cands, key=lambda q: voi_obj(q, o, ledger, model) - cost(q))
            if voi_obj(p, o, ledger, model) < theta_voi_obj: break
            ledger = ledger_update(ledger, execute_object_probe(p, cap=F_abs))
            if identity_gate(o, theta_id, p_id) == 'AMBIGUOUS':
                p2 = max_separation_probe(o, ledger)          # 判别探针
                ledger = ledger_update(ledger, execute_object_probe(p2, cap=F_abs))
            budget.spend_o(p)
        sigma = foothold_schedule(x0, cp, M)
        R = schedule_risk(sigma, M, ledger)                    # 物体台账进风险
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M) - cost(q))
            if voi_meta_pessimistic(p, M) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M, ledger)
            budget.spend(p)
        g = select_gait(R)
        ev = tag_evidence_object(sigma, M, ledger, contact_level(cp))
        if g != 'halt' and object_generalization_gate(
                core_contact(cp), M, ledger, model, personas, ood_reg)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M, ledger)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M, ledger
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OCL | O(1)/证据；合并 O(H_o) | O(\|𝒪\|·d_θ) | 归属显式、无静默合并、身份熵可观测（A41） |
| OGC | O(\|𝒪_cert\|·d_θ)/证书 | O(\|𝒪_cert\|·d_θ) | 支撑外拒证、覆盖 ≥1−α_obj（A42） |
| UCE | O(log N_cell)/查询 | O(\|T\|·\|𝒪\|) | K_LB 保守、ρ_cm 上界、n_eff 折算、插值隔离（A43） |
| XOT | O(k_sem·C_met) | O(\|E_trans\|) | 物理近邻下界、迁移可回溯、负迁移降权（A44） |
| OGE | O(\|σ\|) | O(\|σ\|) | 无 EV-obj/直接测量即拒、迁移限 L1 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_o)·(C_VOI+d_θ)) | O(\|V\|+\|σ\|+\|𝒪\|) | 三预算终止、四态完备 |

**正确性定理（Object-Grounded Calibrated Soundness, OGCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 身份台账诚实：身份熵/top-1 后验可观测，误合并可由动作后果检出并审计；**(A42)** 物体级校准：认证物体类内加权共形覆盖 ≥1−α_obj，且 d_skill 是任务行为差异的可声明代理（支撑外退 C_hull 或拒证）；**(A43)** 统一能力包络：K_LB 诚实，ρ_cm 为跨物体失败相关的保守上界，n_eff 折算不抬高置信；**(A44)** 迁移闸门：仅经物理近邻验证与判别探针的迁移可用，且仅限 L1；负迁移回溯沿迁移图完备。则：

1. **物体级承诺健全性**：对已认证物体上的不可逆接触，
   `P(fail) ≤ δ_f + ε_meta(k) + ε_obj(o) + δ_skill + δ_probe + ε_h + δ_trans·1[迁移]`；
   其中 ε_obj 已按 n_eff 折算放大，迁移项仅在 XOT 许可时计入。
2. **泛化隔离**：新颖物体、支撑外物体与"插值区"在隔离解除前承诺数 = 0；误放行贡献 ≤ δ_novel·α_obj。
3. **交互单调性强化**：物体机制只能经 (a) 更校准（含加宽）的物体信念，或 (b) 更保守的动作（隔离、降档、加识别/度量探针、升级 L2、安全停）影响系统；身份歧义与负迁移只会使系统更保守。
4. **终止性**：每检查点物体探针 ≤ k_obj、共识探针 ≤ k_cons，PCE++ 在 k_probes+k_cons+k_obj 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + ε_obj + δ_skill + δ_probe + ε_h
                  + δ_trans·1[迁移] + δ_novel·α_obj)
             − P(身份误合并未检出) − P(包络陈旧/版本漂移)
             − P(迁移图污染未回溯) − P(护盾回退失败)
```

关键：**身份给效率、可证伪给安全**（先验沿物体流形摊销，但每条先验可被动作推翻）；**物理距离给泛化、语义只给提名**（语义相似永远不能单独签发物理证书）；**包络给边界、插值隔离给保守**（统一模型平滑不代表安全）；**迁移给复用、判别探针与回溯给追责**（负迁移可被定位、降权、记债）；四个新机制全部经"信念更准或动作更保守"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把"证据链的根"从区域/属性换成了**物体身份**，风险从"坏先验普遍"变成"身份误判即全局共模"——若 UniBot-V1 的分割/识别把一个物理性质迥异的新物体自信地归入熟悉类别，身份证书、跨物体迁移与能力包络会一致地给它背书，而统一表征使这一错误跨任务相关、无法靠多模态冗余洗掉；必须以"身份熵门 + 语义相似禁止单独作证 + 插值隔离 + 负迁移回溯"四道闸门，永远让动作后果而不是外观来签署物体级证据。
