# 第 13 轮 · FORGE：没有力传感器，就把整条手臂变成力传感器

> 本轮是当前灵感循环的第 1 轮，承接状态文件第 12 轮。三个灵感词：**力觉传感**、**Isaac Sim**、**商业模式**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮不推倒第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO，而是在 CHUNK-SERVO 的 5 步执行块上补一个它一直缺的通道：**接触力**。

## 0. 先给结论：视觉把夹爪带到孔口，力觉把它送进孔里

第 12 轮 CHUNK-SERVO 的判断是对的：30 步开环 chunk 是最后 3 厘米的结构性瓶颈，必须把执行块缩短到 5 步并用视觉闭环。但它留下了一个更大的洞：

1. **接触瞬间，视觉最不可靠。** 插入、挂杯、拉拉链、拧瓶盖、开锁，最后 1–2 厘米往往被夹爪、物体、手臂自身遮挡；透明/反光物体让深度和特征匹配失效；变形物体让 6D 位姿没有定义。
2. **API 没有 force/torque/tactile。** 四路 RGB、7 维双臂关节、EE 位姿、gripper、lower_body；没有力、没有力矩、没有触觉。第 12 轮因此把“力/触觉闭环”直接剪枝了。
3. **但“没有力传感器”不等于“没有力信息”。** 关节编码器一直在测量实际运动；低层控制器一直在跟踪我们的指令。接触会让实际运动落后于指令，这个落后量乘以有效刚度，就是外部力矩的一阶估计；更严格地，用广义动量观测器可以从关节位置/速度和重建的控制力矩估计外部关节力矩，不需要加速度，也不需要额外硬件。

所以本轮的押注是 **FORGE**：

> **F**orce-**O**bserver **R**esidual **G**uided **E**xecution——用虚拟力观测器（VFO）把本体残差变成 6D 末端力/力矩估计；用 Isaac Sim 标定这台“虚拟力传感器”和接触参数；用 5 步（或更短）chunk 做力位混合伺服；用商业模式约束“不加硬件、软件交付、skill pack 打包”。

一句话：**视觉负责“到孔口”，力觉负责“进孔、挂上、拧动、拉上”；Isaac Sim 不是策略训练场，而是虚拟力传感器的标定台；商业模式不是赛后作业，而是“为什么必须软件-only”的设计约束。**

三个可验证创新点（不是三个宏大名目）：

1. **VFO（Virtual Force Observer）**：基于关节指令-实际残差与广义动量观测器的 6D 末端 wrench 估计；无额外传感器、无学习权重；用 Isaac Sim 标定，真机用已知负载/临时 F/T 验证。
2. **FAC（Force-Aware Compliance）**：力触发的混合位置/力伺服——法向力限制、摩擦锥投影、虚拟 RCC、力引导螺旋搜索、滑移/卡滞检测；直接接在 CHUNK-SERVO 的 5 步执行块上。
3. **Isaac Forge + 软件 skill pack**：Isaac Sim 只做接触参数辨识、观测器标定、力标注合成数据和风洞；商业上做成不加硬件的 skill pack，按机器人/年授权 + 标定服务，竞赛榜单是验证飞轮。

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **力觉传感** | VFO 从关节残差/动量观测器估计 6D wrench；FAC 用法向力、摩擦锥、RCC、滑移/卡滞做接触控制 | 不买/不加真实力传感器；不做 30Hz 高带宽力控；不做第二个学习模型 |
| **Isaac Sim** | 接触参数辨识（摩擦/刚度/阻尼）、观测器标定、域随机化风洞、力标注合成数据 | 不在仿真里训 6B 策略；不假设 sim 成功率能预测真机；不把仿真当真机 |
| **商业模式** | 软件-only、无 BOM、小时级标定、skill pack 订阅、标定/集成服务；竞赛作为 go-to-market 验证 | 不做硬件产品；不做每任务一个模型；不把商业收入预测当实验结果 |

## 1. 直觉与动机

### 1.1 上一轮留下的三个洞

- **遮挡**：接触瞬间，腕部相机被夹爪/物体挡住，头部双目被手臂挡住；视觉伺服在最需要修正的时候置信度最低。
- **透明/反光/变形**：深度和特征匹配失效；GEO-RESIDUAL 的米制表面距离也会退化。
- **没有力**：API 没有 force/torque/tactile；但接触任务的核心恰恰是“顶住多大劲、有没有滑、是不是卡住、孔在哪一侧”。

### 1.2 关键观察：机器人自己就是力传感器

- 低层控制器在跟踪我们的关节/EE 指令；接触会让实际运动落后于指令。
- 跟踪误差乘以有效刚度，是外部力矩的一阶估计：\(\hat\tau_{ext}\approx K_q(q-q_d)\)。
- 更严格地，广义动量观测器从 \(q,\dot q\) 和重建的控制力矩 \(\hat\tau_c\) 估计外部关节力矩，不需要 \(q̈\)，不需要力传感器。
- 关节力矩映射到末端 wrench：\(\hat w=(JJ^T+\lambda I)^{-1}J\hat\tau_{ext}\)。
- 这不是“第二个模型”：它是基于 URDF/动力学模型的确定性观测器；唯一的可学习模型仍是 VLA。

### 1.3 为什么现在做

- 第 12 轮已经有 30 步规划 + 5 步视觉伺服、相对目标、数字孪生标定、单任务通道；FORGE 只需要在控制层加一个力通道，不需要重做规划/感知。
- 官方 WLA 基座、33k 演示、官方 IsaacLab/MuJoCo 仓库都在；Isaac Sim 可以离线标定，不抢在线 GPU。
- 官方 API 明确提供 `left_arm`/`right_arm` 7 维关节位置（2026-10-31 复核 README），且 `control_space` 可以是 `joint` 或 `ee`；joint 模式下指令-实际残差最干净。
- 商业模式要求不加硬件：软件-only 的虚拟力觉正好匹配；skill pack 打包也要求确定性原语，而不是每任务一个学习模型。

### 1.4 与第 10–12 轮的关系

**保留**：

- FACT-VLA 的相位化 BC、CAC 柔顺执行、EGP 证据门控；
- GEO-RESIDUAL 的动作条件化残差、米制表面距离、编辑检测；
- CHUNK-SERVO 的 30 步规划 + 5 步伺服、演示检索相对目标、数字孪生只做标定、单任务通道。

**升级**：

- 视觉接触代理（\(d_t\), \(r_{grasp}\)）→ VFO 的 6D wrench + 视觉几何融合；
- 纯视觉伺服 → 力位混合（法向力限制、切向摩擦锥、虚拟 RCC、力引导搜索）；
- 固定 5 步 → 把 \(T_a\in\{1,2,3,5\}\) 当作控制参数标定，力事件触发恢复；
- 仿真只标定外参/增益/RTT → 仿真标定接触/摩擦/观测器 + 力标注合成数据；
- 竞赛策略 → 商业模式约束下的 skill pack 与标定服务。

**剪枝**：

- 不做真实力/触觉传感器（API 没有，商业上也不想加 BOM）；
- 不做第二个学习模型/残差策略（单模型规则）；
- 不做 30Hz 高带宽力控（固定 chunk + RTT 不允许）；
- 不做变形/透明物体的力闭环（只做刚体接触类）；
- 不做每任务一个策略（规则禁止，且 skill pack 要复用）。

## 2. 形式化定义

### 2.1 观测、动作、时间

- \(o_k\)：第 \(k\) 个策略步的观测：四路 RGB、\(q_L,q_R\in\mathbb R^7\)、EE 位姿 \(x_L,x_R\in SE(3)\)、gripper \(g_L,g_R\)、lower_body \(b\in\mathbb R^{15}\)、语言 \(\ell\)。
- \(T_a\)：提交的固定 `action_chunk_size`（步）。
- \(f_c\)：evaluator 控制频率（假设 30Hz，待实测）。
- \(\tau\)：等效网络 + 推理延迟。
- 反馈周期：\(T_{fb}=T_a/f_c+\tau\)。
- 动作空间：`joint` 或 `ee`。FORGE 默认 `joint`，因为可以直接比较 \(q_d\) 与 \(q\)，避免 IK 冗余导致的假残差；若 joint 模式 IK/限位有问题，回退 `ee`，用笛卡尔跟踪误差。

### 2.2 动力学与虚拟力观测器

单臂 7-DoF 刚体动力学：

```math
M(q)\ddot q + C(q,\dot q)\dot q + g(q) + \tau_f(\dot q) = \tau_c + \tau_{ext},
\qquad \tau_{ext}=J(q)^T w_{ext}.
```

广义动量 \(p=M(q)\dot q\)。动量观测器：

```math
r(t)=K_o\left[p(t)-p(0)-\int_0^t\left(\hat\tau_c+C^T\dot q-g-\tau_f+r\right)ds\right],
```

```math
\dot r=K_o(\tau_{ext}-r).
```

因此 \(r\) 以 \(K_o\) 的带宽跟踪外部关节力矩，不需要 \(q̈\)。控制力矩重建：

```math
\hat\tau_c=K_p(q_d-q)+K_d(\dot q_d-\dot q)+g(q).
```

末端 wrench：

```math
\hat w=(JJ^T+\lambda I)^{-1}J\hat\tau_{ext}.
```

静态近似（准静态接触，作为兜底）：

```math
\hat\tau_{ext}\approx K_q(q-q_d)+D_q(\dot q-\dot q_d)-\hat\tau_{bias}.
```

### 2.3 负载/重力补偿

观测器看到的是总外部 wrench，包括被抓物体的重力/惯性。定义：

```math
\hat w_{contact}=\hat w_{total}-\hat w_{payload}.
```

自由搬运阶段用低通估计 \(\hat w_{payload}\)，接触段冻结；或用估计的物体质量/惯性和 EE 加速度做前馈补偿。负载补偿是 VFO 能否用于接触检测的关键；不做这一步，抓着重物就会被误判为“一直接触”。

### 2.4 接触帧与力位混合

接触法向 \(n\) 从环境指向机器人；接近方向 \(a=-n\)。接触力 \(f_n=n^Tf\ge0\)，切向 \(f_t=f-f_nn\)。

力位混合（所有修正都在 base 系，左乘）：

```math
T_{cmd}=\exp(\Delta\xi)\,T_d,\qquad \Delta\xi=[\Delta p;\Delta\theta].
```

法向（沿接近方向 \(a\) 的位移）：

```math
\Delta p_a=\mathrm{clip}\left(K_a(f_n^*-\hat f_n)-K_v\dot{\hat f}_n,\ \pm\delta_a\right).
```

切向：

```math
\Delta p_t=\mathrm{clip}\left(K_t e_t^{vis},\ \pm\delta_t\right),
```

摩擦锥：

```math
\|\hat f_t\|\le\mu_s\hat f_n,\qquad \mu_s=0.5\hat\mu.
```

虚拟 RCC（把柔顺中心放到夹爪前方 \(d_c\) 处）：

```math
m_{eff}=m-d_c\,a\times f.
```

力限制：

```math
\|\hat f\|\le f_{max},\qquad \|\hat m\|\le m_{max}.
```

### 2.5 可辨识性条件

VFO 只在以下条件同时满足时启用：

1. 关节位置/速度有效，\(\dot q\) 的滤波噪声低于阈值；
2. 低层控制器增益/摩擦已标定，残差 bias 漂移在门限内；
3. 手臂处于准静态或低速（接触段），惯性项不占主导；
4. 负载补偿有效（物体已抓住，质量/惯性已知或在线估计）；
5. 任务是刚体接触类（A 档），不是变形/透明/反光为主。

任一条不满足 → 只用视觉伺服或 VLA 开环；不硬做力闭环。

## 3. 算法：FORGE

### 3.1 总架构

```text
Evaluator (N ports 8765..)
   │ obs / action chunk
   ▼
Per-port PolicyService (CPU)
   ├─ VLA plan cache (30-step, async)
   ├─ visual servo (CHUNK-SERVO)
   ├─ VFO: virtual force observer (new)
   ├─ FAC: force-aware compliance (new)
   ├─ skill primitives (insert/hang/stack/twist)
   └─ action adapter (EE/joint)
   │
   ▼
Shared VLA server (GPU, WLA)
```

- VLA：唯一学习模型，30 步规划。
- VFO/FAC：确定性，无学习权重。
- Isaac Sim：离线标定/风洞/合成数据，不在在线环。
- 每端口独立 observer 状态、bias、contact state、plan cache。

### 3.2 离线标定

1. URDF/动力学：\(M,C,g\)；关节摩擦（Coulomb+viscous）；低层 \(K_p,K_d\) 或 \(K_q,D_q\)。
2. VFO：\(K_o\)、bias、噪声 floor；用已知负载/临时 F/T 验证。
3. 接触：摩擦系数 \(\mu\)、接触刚度、力上限、搜索幅度。
4. Isaac Sim：接触参数辨识、domain randomization、力标注合成数据。
5. 可选：force-conditioned VLA action head 微调（同一 checkpoint）。

### 3.3 在线伪代码

```python
class FORGEPolicy:
    def reset(self):
        self.vfo.reset()
        self.state = FREE
        self.plan = None
        self.bias = None
        self.search = None

    def get_action(self, obs):
        # 1. async VLA plan (30 steps; never block except cold start)
        self._maybe_update_plan(obs)

        # 2. nominal EE trajectory for next Ta steps
        T_nom = self._plan_slice(obs, self.plan, self.Ta)
        T_nom = self.visual_servo(T_nom, obs)

        # 3. virtual force observer
        w_hat = self.vfo.estimate(obs, self.last_cmd)
        w_c = w_hat - self.payload_bias(obs, self.state)

        # 4. contact state machine
        self.state = self._transition(self.state, w_c, obs)

        # 5. force-aware correction
        if self.state in (CONTACT, INSERT, SEARCH):
            T_cmd = self.fac.apply(T_nom, w_c, obs, self.state)
        elif self.state == SLIP:
            T_cmd = self._slip_response(T_nom, w_c, obs)
        elif self.state == RECOVER:
            T_cmd = self._recover(obs)
        else:
            T_cmd = T_nom

        # 6. joint/EE conversion, limits, safety
        a = self.adapter.to_action(T_cmd, obs)
        a = self._clip_and_check(a, w_c)
        self.last_cmd = a
        return a
```

### 3.4 状态机

```text
FREE ──approach──▶ APPROACH ──|f|>f_on──▶ CONTACT
  ▲                    │                    │
  │                    │                    ├─ progress ──▶ INSERT
  │                    │                    ├─ stall ─────▶ SEARCH
  │                    │                    ├─ slip ──────▶ SLIP
  │                    │                    └─ |f|>f_max ─▶ RECOVER
  │                    │                                   │
  └──── done ◀─────────┴──────── retry ◀───────────────────┘
```

- 进入/退出阈值带迟滞（\(f_{on}/f_{off}\)，连续 \(K\) 帧确认）。
- SEARCH：力引导螺旋/摆动，幅度从 1mm 开始，逐步增大到 3–5mm；超时或力超限 → RECOVER。
- RECOVER：先停，再撤退 2–5mm，视觉重定位；目标可见 → 更新 goal；不可见 → VLA 重规划；重试上限 3 次。

### 3.5 复杂度

- 动力学/观测器：7-DoF 单臂 \(O(n^2)\)–\(O(n^3)\)，\(n=7\)，单次 <1ms CPU；双臂 <2ms。
- IK：阻尼最小二乘，10–50 次迭代，<1ms。
- 视觉伺服：1–10ms（特征提取/匹配），可选。
- VLA：100–300ms GPU，异步，每 30 步一次，摊薄到每步 3–10ms。
- 总 per-chunk CPU <10ms；内存 <1GB（沿用 CHUNK-SERVO 目标库）。
- 力观测器不增加显著开销；Isaac Sim 只在离线。

### 3.6 正确性论证

**命题 1（观测器收敛）**：在模型精确、\(\tau_c\) 已知、无摩擦/噪声的理想条件下，动量观测器误差 \(e=r-\tau_{ext}\) 满足 \(\dot e=-K_oe+\dot\tau_{ext}\)；对慢变 \(\tau_{ext}\)，\(e\) 指数收敛到 0，速率 \(K_o\)。离散稳定性要求 \(0<T_sK_o<2\)。

**命题 2（接触检测）**：若自由空间残差服从 \(F_0\)、接触残差服从 \(F_1\)，阈值 \(f_{th}\) 的误报率为 \(1-F_0(f_{th})\)，漏报率为 \(F_1(f_{th})\)；用 ROC 选工作点。检测延迟上界约为 \(T_a/f_c+\tau+1/K_o\)。

**命题 3（力限制）**：若观测误差有界 \(\|\hat f-f\|\le\epsilon\)，且控制器在 \(\hat f\le f_{max}\) 时执行撤退/限幅，则实际接触力上界为 \(f_{max}+\epsilon+\Delta_{overshoot}\)，其中 overshoot 由 chunk 内开环运动决定；降低接近速度/减小 \(T_a\) 可减小 overshoot。

**命题 4（搜索有界性）**：螺旋搜索在有限半径内覆盖所有方向；若孔位在搜索半径内且间隙 >0，存在有限步数使横向误差进入间隙；若超时则撤退重试。该命题依赖接触几何和力方向，不是任意形状的保证。

**命题 5（单模型合规）**：VFO/FAC 的所有参数来自 URDF、系统辨识和固定控制律，没有在线学习权重；唯一学习模型是 VLA。若使用 force-conditioned VLA，仍是同一 checkpoint 增加输入通道，不构成第二个模型。

### 3.7 已知风险

- VFO 是“虚拟”力传感器，模型误差/摩擦/负载/加速度都会污染估计；动态接触中可能把惯性误判为力。
- 30Hz + 固定 chunk 使力反馈是离散、延迟的；chunk 内的力过冲无法完全避免，只能靠降速/柔顺/小 chunk 减小。
- Isaac Sim 的接触参数与真机有差距；标定迁移是最大不确定性。
- 透明/变形/反光物体：力只能告诉“碰到了”，不能告诉“在哪”；仍需视觉/几何。
- 低层控制器可能不是简单 PD+重力补偿；如果它有未知的自适应/阻抗控制，VFO 模型会偏。
- 单模型规则的解释风险：force-conditioned VLA 是同一模型，但需向官方说明；VFO 是控制器，不是模型。
- 商业模式风险：平台依赖、原生力传感器竞争、责任/安全、客户获取。

### 3.8 一句话风险

**最大风险：虚拟力观测器把模型误差、负载重力和真实接触混在一起，而 30Hz/固定 chunk 的低带宽让接触瞬间的力过冲无法及时闭环；如果 Isaac Sim 标定的刚度/摩擦与真机偏差过大，力反馈可能从“帮助”变成“误触发”。**

## 2. 问题形式化

### 2.1 观测、动作、时间

第 \(k\) 个策略步的观测：

```math
o_k=\left(I_k^{LH},I_k^{RH},I_k^{LW},I_k^{RW},\ q_{L,k},q_{R,k},\ x_{L,k},x_{R,k},\ g_{L,k},g_{R,k},\ b_k,\ \ell\right).
```

- \(q\in\mathbb R^7\)：关节位置；\(x\in SE(3)\)：EE 位姿；\(g\in\mathbb R\)：夹爪开度；\(b\in\mathbb R^{15}\)：下身体；\(\ell\)：语言。
- 动作：\(A_k=\{a_{k,0},\dots,a_{k,T_a-1}\}\)，\(a\in\mathbb R^7\times\mathbb R^7\times\mathbb R^2\times\mathbb R^7\)（joint 模式）或 \(SE(3)^2\times\mathbb R^2\times\mathbb R^7\)（ee 模式）。
- 反馈周期：

```math
T_{fb}=\frac{T_a}{f_c}+\tau.
```

| 场景 | \(T_a\) | \(f_c\) | \(\tau\) | \(T_{fb}\) | 评价 |
|---|---:|---:|---:|---:|---|
| WLA 默认 | 30 | 30 | 50ms | 1050ms | 接触段基本开环 |
| CHUNK-SERVO | 5 | 30 | 50ms | 217ms | 1–2 次修正 |
| FORGE 默认 | 3 | 30 | 50ms | 150ms | 力事件检测可用 |
| FORGE 低延迟 | 1 | 30 | 50ms | 83ms | 需 RTT 低且算力够 |
| 高延迟 | 3 | 30 | 150ms | 250ms | 降增益/保守限幅 |

**关键限制**：策略只在 chunk 边界看到新观测。即使 \(T_a=1\)，也要加上 RTT；VFO 是**离散外环**，不是 30Hz 力控。FORGE 的目标是接触事件检测、慢速力位混合、超力撤退，不是高带宽力跟踪。

### 2.2 评分与统计（沿用第 12 轮）

```math
S=\frac{1}{32}\sum_{t=1}^{32}p_t,\qquad p_t=\frac{1}{10}\sum_{j=1}^{10}y_{t,j}.
```

320 trials、\(p\approx0.25\) 时单次标准误约 \(2.42\)pp；5 次/任务的 A/B 只能看方向，必须用配对 bootstrap 报告置信区间。人为干扰轴权重 20%，\(\Delta S_{human}=0.2\Delta p_h\)。

### 2.3 力觉可观测性

我们需要的不是“真实力传感器读数”，而是**足够做接触决策的力代理**：

1. **接触事件**：\(\|\hat w\|\) 是否超过自由空间噪声；
2. **法向力大小**：用于限幅/撤退；
3. **切向力方向**：用于摩擦锥/滑移/搜索；
4. **力矩方向**：用于虚拟 RCC/轴对齐；
5. **接触置信度**：用于视觉/力切换。

不可观测/不可靠的部分：

- 接触点位置（除非视觉/几何给出）；
- 表面摩擦系数（需辨识，且随物体/污染变化）；
- 内部力/闭链力（7-DoF 冗余零空间）；
- 快速动态接触（30Hz/固定 chunk 带宽不够）；
- 变形物体的接触分布。

因此 FORGE 把 VFO 定位为**事件检测 + 慢速力位混合**，不把它当计量级力传感器。

### 2.4 可辨识性条件

VFO 只在以下条件同时满足时启用：

1. \(q,\dot q\) 有效；\(\dot q\) 的滤波噪声低于阈值；
2. 低层控制器增益/摩擦已标定；bias 漂移在门限内；
3. 手臂准静态/低速（接触段）；惯性项不占主导；
4. 负载补偿有效（物体已抓住，质量/惯性已知或在线估计）；
5. 任务是刚体接触类（A 档），不是变形/透明/反光为主。

任一条不满足 → 只用视觉伺服或 VLA 开环；不硬做力闭环。

## 3. 虚拟力观测器 VFO

### 3.1 动力学模型

单臂 7-DoF：

```math
M(q)\ddot q+C(q,\dot q)\dot q+g(q)+\tau_f(\dot q)=\tau_c+\tau_{ext},
\qquad \tau_{ext}=J(q)^Tw_{ext}.
```

- \(M(q)\)：惯性矩阵；\(C(q,\dot q)\dot q\)：科氏/离心；\(g(q)\)：重力；\(\tau_f\)：关节摩擦。
- \(\tau_c\)：低层控制器力矩；\(\tau_{ext}\)：外部关节力矩（接触 + 负载 + 模型误差）。
- \(w_{ext}\in\mathbb R^6\)：末端 wrench（力 + 力矩），base 系。

### 3.2 广义动量观测器

广义动量：

```math
p=M(q)\dot q.
```

利用 \(\dot M=C+C^T\)：

```math
\dot p=\tau_c+\tau_{ext}+C^T\dot q-g-\tau_f.
```

动量观测器：

```math
r(t)=K_o\left[p(t)-p(0)-\int_0^t\left(\hat\tau_c+C^T\dot q-g-\tau_f+r\right)ds\right].
```

求导：

```math
\dot r=K_o(\tau_{ext}-r).
```

所以 \(r\) 以 \(K_o\) 的带宽跟踪 \(\tau_{ext}\)，**不需要 \(q̈\)**。

离散实现（积分递推，避免对 \(p\) 求导）：

```math
S_k=S_{k-1}+T_s\left(\hat\tau_{c,k-1}+C_{k-1}^T\dot q_{k-1}-g_{k-1}-\tau_{f,k-1}+r_{k-1}\right),
```

```math
r_k=K_o\left(p_k-p_0-S_k\right).
```

- \(S_0=0\)，\(r_0=0\)，\(p_0=M(q_0)\dot q_0\)（episode 开始时通常 \(\dot q_0=0\)）。
- 稳定性：连续系统 \(\dot r=K_o(\tau_{ext}-r)\) 对 \(K_o>0\) 稳定；离散实现要求 \(0<T_sK_o<2\)，实际取 \(T_sK_o\le0.2\) 并加低通。
- 噪声：\(p_k\) 依赖 \(\dot q_k\)；用 3 帧有限差分 + Savitzky-Golay/低通，避免高频噪声进入 \(r\)。

### 3.3 控制力矩重建

低层控制器未知，先假设 PD + 重力补偿：

```math
\hat\tau_c=K_p(q_d-q)+K_d(\dot q_d-\dot q)+g(q).
```

- \(q_d\)：我们上一个 chunk 下发的关节目标（joint 模式）或由 EE 目标 IK 得到的关节目标（ee 模式）。
- 若 evaluator 的低层控制器输出的是已含重力补偿的总力矩，则 \(\hat\tau_c\) 直接采用该总力矩；若只给 PD 部分，则加 \(g(q)\)。必须用 G0 的自由空间实验辨识约定，避免重复/遗漏。
- 若低层是阻抗/自适应控制，PD 模型会偏；此时改用静态偏转观测器（§3.4）或降低 VFO 置信度。
- \(K_p,K_d\) 可用阶跃响应/自由空间轨迹拟合；也可从 Isaac Sim 的控制器模型给初值。

### 3.4 静态偏转观测器（兜底）

准静态接触时，惯性/科氏项小，外部力矩近似为关节偏转：

```math
\hat\tau_{ext}\approx K_q(q-q_d)+D_q(\dot q-\dot q_d)-\hat\tau_{bias}.
```

- \(K_q\)：有效关节刚度（控制器 + 谐波减速器 + 连杆柔性）；\(D_q\)：有效阻尼。
- \(\hat\tau_{bias}\)：自由空间残差（重力补偿误差、摩擦、负载）。
- 优点：简单、鲁棒、不需要 \(M,C\)；缺点：动态/快速运动时偏差大。

### 3.5 融合与置信度

把两种观测器做互补融合：

```math
\hat\tau_{ext}=\alpha\hat\tau_{mom}+(1-\alpha)\hat\tau_{def},
```

```math
\alpha=\sigma\left(\frac{v_{th}-\|\dot q\|}{s_v}\right)\cdot c_{model}.
```

- 低速/准静态 → 更信静态偏转；高速/动态 → 更信动量观测器。
- \(c_{model}\in[0,1]\)：模型置信度，由自由空间残差、\(\|\tau_{null}\|\)、标定漂移、关节限位/奇异值等决定。
- 也可以用 1D Kalman 滤波器把两个测量融合；工程上先做加权融合即可。

置信度门控：

```math
c_{VFO}=\sigma\left(\frac{\|\hat w\|-f_{on}}{s}\right)
\cdot\exp\left(-\frac{\|\tau_{null}\|}{\tau_0}\right)
\cdot\exp\left(-\frac{\|\dot q\|}{v_0}\right)
\cdot\mathbb 1[\text{bias valid}].
```

若 \(c_{VFO}<c_{min}\)，FAC 不启用，回退视觉/VLA。

### 3.6 负载/重力补偿

观测器看到的是总外部 wrench，包括被抓物体的重力/惯性：

```math
\hat w_{contact}=\hat w_{total}-\hat w_{payload}.
```

**在线低通法**（默认）：

```math
\hat w_{payload,k}=
\begin{cases}
\lambda\hat w_{payload,k-1}+(1-\lambda)\hat w_{total,k}, & \text{FREE/TRANSPORT},\\
\hat w_{payload,k-1}, & \text{CONTACT}.
\end{cases}
```

- 抓取/释放时用 gripper 状态和力突变重置。
- 物体很重或运动很快时，低通法不够；用质量/惯性前馈：

```math
\hat w_{payload}=\begin{bmatrix}m_o(g+a_{ee})\\ I_o\alpha+\omega\times I_o\omega\end{bmatrix},
```

其中 \(m_o,I_o\) 由自由空间的不同姿态/加速度数据估计；\(a_{ee},\alpha,\omega\) 由 EE 位姿差分/规划得到。

- **这是 VFO 最容易出错的地方**：不补偿负载，抓着重物就会被误判为“一直接触”；补偿过度，真正接触会被抵消。G1 必须专门测。

### 3.7 关节力矩 → 末端 wrench

```math
\hat w=(JJ^T+\lambda I)^{-1}J\hat\tau_{ext}.
```

- \(J\in\mathbb R^{6\times7}\)；\(\lambda\) 是阻尼（奇异/近奇异时增大）。
- 7-DoF 冗余：\(\tau_{ext}\) 的零空间分量不可观测为末端 wrench；定义

```math
\tau_{null}=\left(I-J^T(JJ^T+\lambda I)^{-1}J\right)\hat\tau_{ext}.
```

- \(\|\tau_{null}\|\) 大 → 可能是内部力/摩擦/模型误差 → 降低 \(c_{VFO}\)。
- 力/力矩的符号约定：本报告定义 \(n\) 从环境指向机器人，\(f_n=n^Tf\ge0\)；接近方向 \(a=-n\)。

### 3.8 时间对齐与延迟

VFO 的跟踪误差必须在**同一时刻**比较：

1. 维护命令缓冲区：每条命令带 chunk index、下发时间、目标关节/EE 序列。
2. 观测到达时，用观测时间戳（若有）或测得的 RTT 找到当时正在执行的命令。
3. 对齐 \(q_d(t_{obs})\) 与 \(q(t_{obs})\) 后计算静态偏转；若用 chunk index 对齐，注意 evaluator 可能插值/变速。
4. 若时间对齐误差 > \(T_a/2\)，VFO 置信度下降；不要用错位残差做接触判断。

### 3.9 标定协议

| 步骤 | 数据 | 拟合/验证 | 指标 |
|---|---|---|---|
| 自由空间 | 慢速/快速轨迹，无接触 | \(\tau_{bias}\)、摩擦、\(K_q,D_q\)、\(K_p,K_d\) | 残差 RMSE、漂移 |
| 已知负载 | EE 挂已知质量，静态多姿态 | \(K_q\)、负载补偿、重力项 | 力估计误差 |
| 临时 F/T | 实验室临时装 F/T 传感器（不进正式提交） | 全观测器 \(K_o\)、符号/约定 | 6D wrench RMSE |
| Isaac Sim | 仿真 ground-truth 接触力 | 初值/域随机化 | sim-real gap |
| 真机接触 | 按压已知弹簧/砝码 | 接触段力 RMSE、检测 ROC | AUC/FPR |

通过标准（G1）：自由空间 RMSE ≤0.5N；接触 0–10N 范围 RMSE ≤1.5N；接触检测 AUC ≥0.95；FPR ≤5% @95%TPR。

### 3.10 复杂度

- \(M(q),C(q,\dot q),g(q)\)：7-DoF，递归牛顿-欧拉可做到 \(O(n)\)；朴素矩阵 \(O(n^3)\)，\(n=7\) 可忽略。
- 观测器递推：\(O(n^2)\)/步；双臂 \(n=14\)，仍 <2ms CPU。
- wrench 映射：6×7 矩阵，\(O(6^3)\)，可忽略。
- 内存：每臂 O(n) 状态；无历史大数组。
- 在线总开销远小于视觉伺服/VLA；VFO 不是瓶颈。

## 4. 力位混合控制 FAC

### 4.1 接触帧

- 视觉提供表面法向 \(n_v\) 与置信度 \(c_v\)（GEO-RESIDUAL 的局部几何）。
- 力提供反作用力方向 \(f/\|f\|\)。
- 融合：

```math
n=\mathrm{normalize}\left(c_v n_v+(1-c_v)\frac{f}{\|f\|+\epsilon}\right),\qquad a=-n.
```

- 若 \(c_v\) 低（透明/遮挡），用法向力方向；若力太小，用视觉法向；两者都低 → 不做力位混合，回退 VLA。
- 切向基 \(t_1,t_2\) 由 \(n\) 与任意参考轴 Gram-Schmidt 得到。

### 4.2 法向力限制

沿接近方向 \(a\) 的位移修正：

```math
\Delta p_a=\mathrm{clip}\left(K_a(f_n^*-\hat f_n)-K_v\dot{\hat f}_n,\ -\delta_{retreat},\ \delta_{approach}\right).
```

- \(f_n^*\)：目标法向力（插入 2–5N，挂/叠 1–3N，具体按任务标定）。
- 若 \(\hat f_n<f_n^*\)：\(\Delta p_a>0\)，沿 \(a\) 继续压入；若 \(\hat f_n>f_n^*\)：\(\Delta p_a<0\)，撤退。
- 输出前再乘一个低速门控：接近速度 \(v_a\le v_{max}\)；接触前 5mm 降速到 1–2cm/s。
- 所有 \(\Delta p,\Delta\theta\) 都在 base 系表达；最终位姿左乘：\(T_{cmd}=\exp(\Delta\xi)T_d\)。若改用 EE 局部系，必须统一左/右乘约定，否则力修正会被错误旋转。

### 4.3 切向摩擦锥

切向修正来自视觉伺服/搜索：

```math
\Delta p_t=\mathrm{clip}\left(K_t e_t^{vis},\ \pm\delta_t\right).
```

摩擦锥约束：

```math
\|\hat f_t\|\le\mu_s\hat f_n,\qquad \mu_s=0.5\hat\mu.
```

若超限，按比例缩小：

```math
\Delta p_t\leftarrow\Delta p_t\cdot\min\left(1,\frac{\mu_s\hat f_n}{\|\hat f_t\|+\epsilon}\right).
```

- \(\hat\mu\) 由 Isaac Sim + 真机滑动实验辨识；用 0.5 倍保守系数。
- 切向运动被缩小时，不要继续加力“硬怼”；进入 SEARCH 或 RECOVER。

### 4.4 虚拟 RCC

经典 RCC（Remote Center of Compliance）用机械柔顺让夹爪绕接触点微转；FORGE 用软件模拟：

- 柔顺中心：\(c=p_{ee}+d_c a\)（夹爪前方 \(d_c\)，沿插入轴）。
- 关于 \(c\) 的力矩：

```math
m_{eff}=m-d_c\,a\times f.
```

- 旋转修正：

```math
\Delta\theta=\mathrm{clip}\left(K_\theta m_{eff},\ \pm\delta_\theta\right).
```

- 效果：侧向接触时，夹爪绕前方接触点微转，减小卡滞/侧向力；插入轴对齐更稳。
- \(d_c\) 取夹爪长度/工具长度的一半到全长；\(K_\theta\) 小增益，接触段才启用。

### 4.5 力引导螺旋搜索

当接触已发生但插入无进展（视觉/EE 沿 \(a\) 的位移 < 阈值）时：

```math
\Delta p_t(k)=r_k\left[\cos(\theta_0+k\Delta\theta),\ \sin(\theta_0+k\Delta\theta)\right]^T,
\qquad r_k=r_0\left(1-\frac{k}{K}\right).
```

- \(r_0=1\)mm 起步，最大 3–5mm；\(K\) 由任务间隙/允许时间决定。
- 力偏置：若 \(\hat f_t\) 有方向，叠加 \(-\alpha\hat f_t\)，让搜索偏向力反方向（孔在力反方向）。
- 力超限或搜索超时 → 撤退 2–5mm → 重对齐 → 换搜索相位重试。
- 这是“盲搜 + 力反馈”的组合；不是学习策略。

### 4.6 滑移/卡滞检测

**滑移**：

```math
\rho=\frac{\|\hat f_t\|}{\mu\hat f_n+\epsilon}.
```

- \(\rho>1-\delta\) 或视觉物体相对夹爪运动 → 滑移。
- 响应：增大夹持（按 gripper 方向小步闭合）、降低切向加速度、必要时重抓。
- 若夹持已到极限 → 放弃当前抓取，RECOVER。

**卡滞**：

- 条件：\(\hat f_n>f_{jam}\)、沿 \(a\) 的进度 < 阈值、\(\|\hat f_t\|\) 高、持续 \(K\) 个 chunk。
- 响应：撤退 2–5mm，虚拟 RCC 增大/减小，换搜索相位；不要继续加压。
- 若反复卡滞 → 回退 VLA 重规划或换抓取位姿。

### 4.7 状态机

```text
FREE ──approach──▶ APPROACH ──|f|>f_on──▶ CONTACT
  ▲                    │                    │
  │                    │                    ├─ progress ──▶ INSERT
  │                    │                    ├─ stall ─────▶ SEARCH
  │                    │                    ├─ slip ──────▶ SLIP
  │                    │                    └─ |f|>f_max ─▶ RECOVER
  │                    │                                   │
  └──── done ◀─────────┴──────── retry ◀───────────────────┘
```

- 进入/退出阈值带迟滞：\(f_{on}\) 高、\(f_{off}\) 低；连续 \(K_{on}/K_{off}\) 帧确认。
- FREE/APPROACH：视觉伺服；VFO 只监控，不改动作。
- CONTACT：FAC 接管；法向力限制 + 摩擦锥 + RCC。
- INSERT：沿 \(a\) 低速推进；力下降/进度到位 → TRANSPORT/DONE。
- SEARCH：力引导螺旋；超时/超力 → RECOVER。
- SLIP：夹持/切向响应；恢复 → CONTACT，否则 RECOVER。
- RECOVER：停 → 撤退 → 视觉重定位 → 目标可见更新 goal；不可见 VLA 重规划；重试 ≤3。
- 任意状态：超力/超时/异常 → 安全 hold/撤退；绝不返回 NaN/错误形状。

### 4.8 伪代码

```python
class VirtualForceObserver:
    def __init__(self, model, Ko, dt):
        self.model = model       # M, C, g, J, friction, Kp, Kd
        self.Ko = Ko
        self.dt = dt
        self.reset()

    def reset(self):
        self.p0 = None
        self.S = np.zeros(7)
        self.r = np.zeros(7)
        self.filt = LowPass(alpha=0.3)

    def update(self, q, qd, q_d, qd_d, tau_bias):
        p = self.model.M(q) @ qd
        if self.p0 is None:
            self.p0 = p.copy()
        tau_c = self.model.Kp @ (q_d - q) + self.model.Kd @ (qd_d - qd)
        tau_c += self.model.g(q)
        tau_f = self.model.friction(qd)
        self.S += self.dt * (
            tau_c + self.model.CT(q, qd) @ qd
            - self.model.g(q) - tau_f + self.r
        )
        self.r = self.Ko @ (p - self.p0 - self.S) - tau_bias
        J = self.model.J(q)                    # 6x7
        w = np.linalg.solve(J @ J.T + 1e-6*np.eye(6), J @ self.r)
        return self.filt(w), self.r

class ForceAwareCompliance:
    def apply(self, T_nom, w, obs, state):
        f, m = w[:3], w[3:]
        n = self.estimate_normal(f, obs)       # reaction normal
        a = -n
        fn = max(0.0, float(n @ f))
        ft = f - fn*n
        # normal admittance along approach direction
        dpa = self.Ka*(self.f_star - fn) - self.Kv*self.dfn
        dpa = np.clip(dpa, -self.retreat, self.approach)
        # tangential visual correction
        dpt = self.visual_tangential(obs)
        if np.linalg.norm(ft) > self.mu*fn + 1e-9:
            dpt *= self.mu*fn / (np.linalg.norm(ft) + 1e-9)
        # virtual RCC
        c = self.p_ee + self.dc*a
        m_eff = m - self.dc*np.cross(a, f)
        dth = np.clip(self.Kth @ m_eff, -self.dtheta, self.dtheta)
        # compose in base frame
        dp = dpa*a + dpt
        T_cmd = exp_se3(np.r_[dp, dth]) @ T_nom
        # hard force limit
        if np.linalg.norm(f) > self.f_max or np.linalg.norm(m) > self.m_max:
            T_cmd = self.retreat_pose(obs)
            self.state = RECOVER
        return T_cmd

class FORGEPolicy:
    def reset(self):
        self.vfo.reset()
        self.state = FREE
        self.plan = None
        self.bias = None
        self.last_cmd = None

    def get_action(self, obs):
        self._maybe_update_plan(obs)            # async 30-step VLA plan
        T_nom = self._plan_slice(obs, self.plan, self.Ta)
        T_nom = self.visual_servo(T_nom, obs)   # CHUNK-SERVO
        w, r = self.vfo.update(
            obs.q, obs.qd, self.last_qd, self.last_qdd, self.tau_bias
        )
        w_c = w - self.payload_bias(obs, self.state)
        self.state = self._transition(self.state, w_c, obs)
        if self.state in (CONTACT, INSERT, SEARCH):
            T_cmd = self.fac.apply(T_nom, w_c, obs, self.state)
        elif self.state == SLIP:
            T_cmd = self._slip_response(T_nom, w_c, obs)
        elif self.state == RECOVER:
            T_cmd = self._recover(obs)
        else:
            T_cmd = T_nom
        a = self.adapter.to_action(T_cmd, obs)
        a = self._clip_and_check(a, w_c)
        self.last_cmd = a
        return a
```

### 4.9 稳定性

1D 法向模型：\(f_k=K_e(s_k-s_{env})\)，控制器 \(s_{k+1}=s_k+T_aK_a(f^*-f_{k-d})\)。误差 \(e_k=f_k-f^*\)：

```math
e_{k+1}=e_k-T_aK_aK_e e_{k-d}.
```

特征方程：

```math
z^{d+1}-z^d+T_aK_aK_e=0.
```

- \(d=0\)：稳定条件 \(0<T_aK_aK_e<2\)。
- \(d=1\)：\(z^2-z+T_aK_aK_e=0\)，稳定条件 \(0<T_aK_aK_e<1\)。
- \(d\ge2\)：稳定域进一步缩小；必须降增益或加预测。
- 工程规则：\(T_aK_aK_e\le0.5\)，加低通，接触段降速；不要用高增益追力。

### 4.10 正确性论证

**命题 1（观测器收敛）**：理想模型下 \(\dot e=-K_oe+\dot\tau_{ext}\)；慢变外部力矩时 \(e\to0\)。离散稳定 \(0<T_sK_o<2\)。

**命题 2（接触检测）**：阈值 \(f_{th}\) 的误报/漏报由 \(F_0,F_1\) 决定；检测延迟上界约 \(T_a/f_c+\tau+1/K_o\)。

**命题 3（力限制）**：观测误差有界时，实际力上界 \(f_{max}+\epsilon+\Delta_{overshoot}\)；降低接近速度/\(T_a\) 可减小 overshoot。

**命题 4（搜索有界）**：螺旋在有限半径内覆盖所有方向；孔在半径内且间隙 >0 时存在有限步进入间隙；超时则撤退重试。非任意几何保证。

**命题 5（单模型合规）**：VFO/FAC 参数来自 URDF/辨识/固定控制律，无在线学习权重；唯一学习模型是 VLA。force-conditioned VLA 仍是同一 checkpoint 增加输入通道。

## 5. Isaac Forge：数字孪生标定

### 5.1 场景

- 机器人：G1 29-DoF URDF + Dex1 夹爪；关节限位/速度/加速度。
- 桌面：刚性桌面 + 刚体对象（杯架、碗、纸杯、网口/充电器、试管架、锁、瓶盖、拉链头）。
- 相机：头双目（含基线/内参/外参）+ 左右腕部（先 D435 先验，再标定）。
- 控制：30Hz；chunk 执行；RTT 注入；低层 PD/阻抗模型。
- 只做刚体接触；变形/透明/反光任务不进入力闭环。

### 5.2 接触参数辨识

| 参数 | 含义 | 先验/范围 | 数据 |
|---|---|---|---|
| \(\mu\) | 摩擦系数 | 0.2–1.0 | 仿真滑动/真机斜面/拉力 |
| \(k_e\) | 接触刚度 | \(10^3\)–\(10^5\) N/m | 按压力-位移 |
| \(c_e\) | 接触阻尼 | 1–100 Ns/m | 阶跃/振荡 |
| \(\tau_f\) | 关节摩擦 | 辨识 | 自由空间匀速 |
| \(K_q,D_q\) | 关节有效刚度/阻尼 | 辨识 | 已知负载偏转 |
| \(\tau\) | 等效延迟 | 0–150ms | 时间戳/互相关 |

方法：最小二乘/极大似然；Isaac 给初值，真机用已知负载/弹簧/临时 F/T 校准；域随机化覆盖不确定性。

### 5.3 观测器标定

```math
\min_{K_o,K_q,D_q,\tau_f}\sum_i\left\|\hat w_i-w_i^{gt}\right\|^2.
```

- 仿真：ground truth 接触力可直接读；拟合初值。
- 真机：临时 F/T 或已知质量/弹簧；拟合/验证。
- 留出集：不同物体/速度/姿态；报告 RMSE、偏差、漂移。
- 若真机误差 >20%，VFO 只用于接触事件，不用于力幅值；FAC 退化为“接触即停/撤退”。

### 5.4 域随机化/风洞

| 维度 | 取值 | 目的 |
|---|---|---|
| 摩擦 | 0.2–1.0 | 滑移/摩擦锥鲁棒性 |
| 质量 | ±30% | 负载补偿 |
| 接触刚度 | \(10^3\)–\(10^5\) N/m | 力过冲 |
| 传感器噪声 | 0.1–1N | 检测阈值 |
| 延迟 | 0–150ms | 稳定性 |
| 相机位姿 | ±5mm/1° | 视觉法向/目标 |
| 扰动 | 遮挡/移动/人手 | 恢复 |

每个组合至少 50 次仿真；报告成功率、峰值力、收敛时间、恢复率。仿真只用于找稳定域和相对排序，不预测真机绝对成功率。

### 5.5 力标注合成数据（可选）

- 目的：给 force-conditioned VLA 的 force-context 投影/action head 预训练。
- 内容：接触力 ground truth、接触状态、滑移/卡滞标签、对应图像/关节状态。
- 限制：视觉域差距大；不用合成数据训视觉编码器；只用它学“力上下文 → 动作”的局部映射，再用真机代理标签微调。
- 若单模型规则解释风险高，跳过这一步，只做 servo-only FORGE。

### 5.6 sim-to-real gap 预算

| 项 | 允许误差 | 超过后的动作 |
|---|---|---|
| 接触力 RMSE | ≤20% 或 ≤1.5N | 只做事件检测，不做力幅值 |
| 摩擦系数 | ≤0.15 | 用保守 \(\mu_s=0.3\) |
| 延迟 | ≤30ms 估计误差 | 降增益/加 \(T_a\) |
| 关节刚度 | ≤20% | 重标定/降置信度 |
| 负载质量 | ≤10% | 在线估计/重置 bias |
| 相机外参 | ≤2cm/2° | 只用腕部/力方向 |

## 7. 预实验（非 Isaac Sim、非真机，仅 sanity check）

> 以下结果来自自写的最小 Python 模型，用于检查控制逻辑/延迟趋势，**不是** Isaac Sim 或真机结果，不能外推为成功率预测。代码在临时目录，未进入提交包。

### 7.1 1D chunked contact：检测延迟与峰值力

模型：一维准静态接近 + 模型参考观测器；接触刚度 5000 N/m；接近速度 2cm/s；\(f_{max}=5\)N；力反馈按 \(T_a\) 离散、加 \(\tau\) 延迟。

**检测延迟（首次接触 → 检测，ms）**：

| \(T_a\) \ \(\tau\) | 0ms | 50ms | 100ms | 150ms |
|---:|---:|---:|---:|---:|
| 1 | 100 | 200 | 200 | 267 |
| 3 | 133 | 233 | 267 | 333 |
| 5 | 233 | 300 | 367 | 367 |
| 8 | 400 | 433 | 200* | 233* |
| 30 | 967 | 967 | 967 | 967 |

\* 8 步的非单调来自 toy 模型的相位/阈值效应，不代表真实趋势；总体趋势是 \(T_a\) 和 \(\tau\) 越大，检测越晚。

**峰值接触力**（\(T_a=3,\tau=50\)ms）：开环约 **82N**；二值“接触即停”约 **2.4N** 但会停在接触面、没有受控插入；力限制 admittance 约 **6.5N**，在限幅附近来回修正。结论：**二值停不够，必须做力限制的柔顺推进/撤退**；toy 的绝对力值由任意刚度决定，不可当真。

### 7.2 2D 插入 toy：横向误差与延迟

模型：二维准静态 peg-in-hole；间隙 1mm；初始横向误差 \(\sim\mathcal N(0,\sigma^2)\)；接触力径向 + 15° 方向噪声 + 0.4N 幅值噪声；每条件 1000 trials；25 步预算。控制器：

- open：不修正；
- vision：朝带噪声的孔中心估计移动；
- random：随机横向搜索；
- force：朝估计接触力的反方向移动（理想化上界）；
- hybrid：视觉先验 + 力修正（朴素加权）。

**成功率**：

| \(\sigma\) (mm) | open | vision | random | force (上界) | hybrid (朴素) |
|---:|---:|---:|---:|---:|---:|
| 1 | 0.678 | 0.743 | 0.874 | 1.000 | 0.803 |
| 2 | 0.359 | 0.491 | 0.635 | 1.000 | 0.608 |
| 3 | 0.270 | 0.347 | 0.499 | 1.000 | 0.489 |
| 5 | 0.164 | 0.254 | 0.332 | 1.000 | 0.392 |

**延迟敏感性（\(\sigma=3\)mm）**：

| 延迟（策略步） | force | hybrid |
|---:|---:|---:|
| 0 | 1.000 | 0.489 |
| 1 | 1.000 | 0.589 |
| 2 | 1.000 | 0.719 |
| 3 | 0.946 | 0.733 |
| 5 | 0.870 | 0.699 |

解读：

- 力方向确实能把横向误差“推”进间隙；但 force 是理想化上界（力方向近似径向、无摩擦锥），不能当真机成功率。
- **朴素视觉+力加权反而可能更差**：视觉噪声会把已经对准的夹爪推偏。正确做法是**按接触置信度切换**：视觉负责接近，力负责接触后；不要盲目融合。
- 延迟 5 个策略步（约 167ms + RTT）仍有一定成功率，但峰值力上升；这支持 \(T_a=1\)–3 和降速。

### 7.3 接触检测 ROC：噪声 floor 决定可用性

自由空间力估计 \(\sim\mathcal N(0,\sigma_f^2)\)，接触力 \(\sim\mathcal N(f_c,\sigma_f^2)\)；20000 样本/类。

| \(\sigma_f\) (N) | \(f_c=1\)N AUC | 2N | 3N | 5N | FPR@95%TPR（3N） |
|---:|---:|---:|---:|---:|---:|
| 0.3 | 0.991 | 1.000 | 1.000 | 1.000 | 0.000 |
| 0.5 | 0.922 | 0.998 | 1.000 | 1.000 | 0.000 |
| 1.0 | 0.759 | 0.920 | 0.983 | 1.000 | 0.088 |
| 2.0 | 0.632 | 0.761 | 0.855 | 0.962 | 0.561 |

解读：

- 要可靠检测 2–3N 的接触，VFO 的自由空间噪声必须压到 **≤0.5–1N**；否则误报/漏报都不可接受。
- 这就是为什么 G1/G2 的标定和负载补偿是硬门，不是可选项。
- 工作点建议：\(f_{on}=\mu_0+3\sigma_0\)，\(f_{off}=\mu_0+1.5\sigma_0\)，连续 2–3 帧确认。

### 7.4 预实验的局限

- 1D/2D 模型没有真实摩擦锥、接触几何、柔性、关节耦合、视觉遮挡。
- force-only 是上界，不是可实现结果；hybrid 是反例，说明融合策略要设计。
- 绝对成功率/力值不可外推；只支持“延迟越小越好、力方向有信息、朴素融合会出错”这三个定性结论。
- 真正的证据必须来自 G1–G5 的 Isaac Sim + 真机单任务 A/B。

### 9.1 任务组合

- **A 档：力觉优先（19）**：T01 HangCup、T05 DisconnectEthernet、T09 ToolboxStorage、T10 PlugCharger、T12 Unlock、T13 ArrangeTestTubes、T14 OpenPillBottle、T17 OrganizeStationery、T18 PackBag、T19 ZipUp、T20 PaperCupStacking、T23 StoreRacket、T25 StackCups、T26 PlugInEthernet、T27 StackBowls、T28 StoreEarphones、T29 PackPhone、T31 OrganizePencilCase、T32 SyringeWaterTransfer。
- **B 档：VLA 优先（13）**：T02 FruitCollection、T03 PackDoll、T04 FruitSorting、T06 ColorArrangement、T07 PlacePhotoFrame、T08 OrganizeBookshelf、T11 PickOutBatteries、T15 OrganizeTools、T16 FoldTowel、T21 ArrangePlates、T22 SpellRobot、T24 ConveyorSorting、T30 RemovePinnedNote。
- **C 档：低投入/观察**：单任务通道里 \(p_t\approx0\) 且失败在早期感知/抓取的任务。

优先级：

```text
priority_t = q_t * Δ_t / cost_t
```

\(q_t\)：失败在最后 3 厘米的比例；\(\Delta_t\)：FORGE 条件增益；\(cost_t\)：标定/目标库/评测成本。先做 A 档中 \(q_t\) 高、\(cost_t\) 低的 3–5 个任务，不要一次铺 19 个。

### 9.2 单任务通道协议

1. 5 个代表任务：PlugInEthernet、HangCup、StackBowls、Unlock/ZipUp、FoldTowel。
2. 每任务 5 次 A/B：CHUNK-SERVO vs FORGE；同初始条件；记录成功/步骤分/耗时/p99/峰值力/恢复。
3. 通过：≥3/5 +10pp；FoldTowel 不回归 >5pp；无安全违规。
4. 扫 \(T_a\in\{1,2,3,5\}\)；选 p99 和成功率的最佳折中。
5. 最后跑 32×10 正式评测。

### 9.3 提交节奏

1. **W0**：WLA + API adapter + CHUNK-SERVO 基线；单任务通道跑通 1 个任务；确认 joint/ee、token、\(T_a\)。
2. **W1**：安全基线提交（若允许多次），锁“更早提交”tie-break。
3. **W2–W4**：VFO 标定、Isaac 接触辨识、FAC 集成；单任务 A/B。
4. **W5**：\(T_a\)/增益扫描；全量干跑。
5. **W6**：最终提交；保留回滚开关。

若只允许一次提交：跳过 W1，W5 后再交；不要用正式 320 trials 做未验证 A/B。

### 9.4 商业模式

**产品**：FORGE Skill Pack——G1/Dex1 的软件-only 虚拟力觉 + 接触技能包。

| 模块 | 内容 |
|---|---|
| 客户细分 | 机器人实验室、系统集成商、电子装配/实验室自动化/包装产线、Unitree 生态 OEM |
| 价值主张 | 不加力传感器完成接触密集任务；小时级标定；软件交付；skill 可复用 |
| 渠道 | 竞赛榜单/论文/开源社区；Unitree 生态合作；系统集成商 |
| 收入 | 每机器人年费；skill pack 订阅；标定/集成服务；企业支持 |
| 成本 | 研发、支持、仿真资产；边际成本近零 |
| 关键指标 | 接触任务成功率提升、峰值力降低、标定时间、部署数、续费率 |

| 风险 | 平台依赖、原生力传感器、责任/安全、sim-to-real gap |

**单位经济（示意，未验证）**：每机器人年费 3k 美元；100 台 = 300k ARR；毛利率 85%；CAC 10k；回收期约 4 个月；标定/集成服务 5–10k/站点。必须用试点验证，不能当承诺。

1. 不加硬件 → VFO，而不是 F/T 传感器。
