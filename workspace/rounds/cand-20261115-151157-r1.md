# 第 8 轮（灵感循环第 1 轮；本轮灵感：「移动底盘」×「时空推理」）
> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–525；引理 73–76；实验 E513–E525）。
> 本轮纪律：**把「当前位形安全」升级为「整条时空管安全」**。移动底盘引入基座位姿与定位不确定性，时空推理引入未来占用与时间逻辑；两者必须共同进入证书，而不是作为两个新的加权项并排放置。

## 0. 直觉与动机

**灵感 1（移动底盘 → 证书的参考系必须跟着动）**
直觉：v7 的 SpatialCert 实际上默认了一个“站着不动”的基座：它在某一帧里检查当前位形是否安全，然后把这个结论当作一段时间内有效。移动底盘一来，这个假设立刻破裂——基座在动，局部地图在动，障碍的相对位置也在动。于是“空间证书”必须从**世界坐标系里的一个点**，变成**随基座位姿和定位误差一起搬移的一片区域**。关键不是多加一个底盘运动学模块，而是承认：没有位姿置信度的空间证书是不可信的。

**灵感 2（时空推理 → 安全不是一个瞬间，而是一条管）**
直觉：现有指标层级 M₀–M₃ 基本是“瞬时快照”式判据：此刻速度是否超限、此刻距离是否足够。但真正的碰撞发生在未来，且未来占用是不确定的。时空推理把每个实体表示成一条**时空管（space-time tube）**：均值轨迹 + 随时间增长的预测/定位膨胀。安全判据随之变成“规划轨迹是否在所有 t 上都不进入任何障碍管”，即一个时空可达性问题，而不是单帧几何问题。

**交叉洞察（本轮真正的创新点）**
移动底盘让空间证书必须“随动”，时空推理让证书必须“覆盖未来”；两者相乘，得到一个统一对象：**移动框架下的时空证书（Moving-frame Space-Time Certificate, MST-Cert）**。它回答的问题从“我现在安全吗”变成“在定位漂移与预测误差共同膨胀后，我未来 H 秒的整条管是否仍与所有障碍管不相交”。一句话类比：静态证书像“此刻站在安全点”，时空证书像“整条走廊都被预订为安全”。

## 1. 研究问题（轮次升级版）

- **Q1（移动框架的保守平移）**：如何把 v7 的静态 SpatialCert 严格平移到移动基座上，使得证书在定位协方差存在时仍然**保守成立**，而不是“看起来成立”？
- **Q2（时空推理与指标层级的对齐）**：如何把 M₀–M₃ 的瞬时判据编译成有时序算子的 STL 公式，使 `ρ_φ ≥ 0` 与层级满足在语义上等价，而不是两套并行的判据？
- **Q3（时空指令的接地）**：语音中的空间指代（“桌子左边”）与时间窗（“5 秒内／稍后”）如何解析到 ST-Graph 的具体实体与 STL 时间区间，并在指代不唯一或不可验证时安全退化？
- **Q4（双速率不抖动）**：时空推理若以 10Hz 运行、关键安全环以 50Hz 运行，如何保证 50Hz 决策永远使用**不更乐观**的包络，避免证书在快慢环之间来回翻转？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 基座状态显式化与锚纪元（Base-Anchored Certification）**
基座状态 `b(t) = (p, θ, v, ω, Σ_b)` 与定位置信度必须显式进入证书；每次重定位/跳变产生新的 `anchor_epoch`。证书只在同一 `anchor_epoch` 内有效，跨纪元必须失效重算——这是防止“用旧位姿给新地图发证书”的第一道闸门。

**P11 时空管证书（Space-Time Tube Certificate, STTC）**
把每个动态/静态障碍与自车轨迹都膨胀为时空管 `𝒯_i`，自由空间定义为 `ℱ(t) = 𝒳 \ ⋃ᵢ 𝒯_i`。证书不是单帧布尔值，而是三元组 `(φ_ι, ρ_min, H)`：STL 公式、最差鲁棒度、时域长度。退化触发条件从 `σ < τ_safe` 升级为 `ρ_φ < 0 ∨ anchor_epoch` 改变。

**P12 时空指令接地（Spatio-Temporal Command Grounding）**
在 VoiceCommandTyping 之后增加一层指代消解：`𝒟(text, b(t₀), G_ST) → (target_id, relation, time_window)`，再编译为 STL 公式 `φ_ι`。例如“到桌子左边并在 5 秒内停下”编译为 `◇_[0,5]( near(target, left(desk)) ∧ speed ≤ 0.1 )`。接地必须可验证：目标必须落在传感器已确认区域内，否则退回默认指令 `ι₀`。

**P13 双速率单向保守（Monotone Dual-Rate Envelope）**
10Hz 的时空推理只允许把包络“加粗”（膨胀增大、时域截短），不允许在 50Hz 关键环内把包络“变细”。形式化：`𝒯_frozen(t) ⊇ 𝒯_latest(t)` 必须逐 tick 成立；违反即触发保守停车而非继续。

## 3. 与基线的接口（如何退化）

- **时空推理器 STR 失效** ⇒ 冻结基座速度，退回 v7 静态 SpatialCert（当前帧、单点证书）；
- **时空指令接地失败** ⇒ `ι ← ι₀`，退回 v7 VoiceCommandTyping 的基础类型检查；
- **定位置信度低于门限 / 锚纪元跳变** ⇒ 触发 Anchor Loss：清空所有时空证书，进入带大膨胀的固定框架保守包络并停车；
- **双速率一致性检查失败** ⇒ 丢弃最新预测，保持上一冻结包络并降速；
- **三个新模块全部可用** ⇒ 启用完整 MetricVoiceGauge-MST。

## 4. 预期贡献

1. **移动框架证书理论**：给出静态 SpatialCert 在移动基座上的保守平移条件（管膨胀 = 定位误差 + 跟踪误差 + 预测误差），并证明其充分性；
2. **时空指标层级**：把 M₀–M₃ 的瞬时判据时序化，证明在给定 STL 片段上 `ρ_φ ≥ 0` 与层级逐时满足等价；
3. **时空指令接地**：把空间指代与时间窗解析到 ST-Graph 与 STL，形成“语音-地图-时间”三者可验证的接地链；
4. **双速率安全调度**：给出单向保守包络的一致性与最坏延迟分析，保证 50Hz WCET 不被 10Hz 推理拖垮；
5. 完整实验 E526–E545：覆盖定位漂移、动态障碍、指代歧义、双速率抖动与端到端竞赛。

## 5. 本轮最大风险

**一句话**：时空管的膨胀系数是安全性与可用性的总开关——膨胀太小会漏掉定位漂移与预测误差导致的动态碰撞，膨胀太大会让可行域塌缩成“只会停车”的保守系统；本轮最大的风险是把静态证书平移到移动基座时，**证书的保守性与任务可用性无法同时成立**。

**新增定义 526（移动基座状态）** 移动基座状态及其非完整约束：
```
b(t) = (p(t), θ(t), v(t), ω(t), Σ_b(t)) ∈ SE(2) × ℝ² × 𝕊¹ × 𝔰𝔢(2)_cov
非完整约束： ẋ·sinθ − ẏ·cosθ = 0
定位置信： conf_loc = exp(−tr(Σ_b)/s₀) ∈ [0,1]
```

**新增定义 527（时空语义图 ST-Graph）** 带时间区间的实体-关系图：
```
G_ST(t) = (V, E, τ)
V = { (id, class, μᵢ(·), Σᵢ(·), [t_start, t_end]) }
E = { (i, r, j, I_ij) | r ∈ {left, right, near, on, behind, inside}, I_ij ⊆ ℝ }
```
其中 `I_ij` 是空间关系 r 成立的时间区间。查询 `Q(G_ST, r, j, t)` 返回 t 时刻与 j 满足关系 r 的实体集合。

**新增定义 528（时空管 Space-Time Tube）** 实体 i 在时域 H 内的可达管：
```
𝒯ᵢ = { (x,t) : (x − μᵢ(t))ᵀ Σᵢ(t)⁻¹ (x − μᵢ(t)) ≤ χ²₂(1−ε),
              t ∈ [t₀, t₀+H] }
```
自由空间 `ℱ(t) = 𝒳 \ ⋃ᵢ 𝒯ᵢ(t)`。硬安全版本取椭球的外接膨胀球，半径
`rᵢ(t) = λ_max(Σᵢ(t))^{1/2} · sqrt(χ²₂(1−ε))`，以保证后续判据是保守的。

**新增定义 529（STL 鲁棒度）** 对 STL 片段
`φ ::= ⊤ | μ ≥ c | ¬φ | φ ∧ φ | ◇_I φ | □_I φ | φ U_I φ`：
```
ρ(⊤, t)        = +∞
ρ(μ ≥ c, t)    = μ(x(t)) − c
ρ(¬φ, t)       = −ρ(φ, t)
ρ(φ ∧ ψ, t)    = min(ρ(φ,t), ρ(ψ,t))
ρ(□_I φ, t)    = min_{t' ∈ t+I} ρ(φ, t')
ρ(◇_I φ, t)    = max_{t' ∈ t+I} ρ(φ, t')
ρ(φ U_I ψ, t)  = max_{t' ∈ t+I} min( ρ(ψ,t'),
                     min_{t'' ∈ [t,t']} ρ(φ,t'') )
```
语义：`x ⊨ φ` 当且仅当 `ρ(φ,t) ≥ 0`。

**新增定义 530（时空指令规格）** 语音指令经指代接地与 STL 编译后的规格：
```
ι_st = (action, target_id, relation, I_time, φ_ι)
𝒟: (text, b(t₀), G_ST(t₀)) → (target_id, relation, I_time) ∪ {⊥}
φ_ι = Compile(action, target_id, relation, I_time)
```
例：“到桌子左边并在 5 秒内停下” ⇒
```
φ_ι = ◇_[0,5]( near(target, left(desk)) ∧ speed ≤ 0.1 )
```

**新增定义 531（移动框架指标层级 MFML）** 第 i 层的时空满足条件：
```
βᵢ(t) = mᵢ(b(t)) − τᵢ(b(t), t) − κ · σ_tube(t)
Layer_i 满足 ⇔ min_{t ∈ [t₀, t₀+Hᵢ]} βᵢ(t) ≥ 0
```
示例（随障碍距离衰减的限速阈值）：
```
τ_v(x,t) = v_min + (v_max − v_min) · (1 − exp(−d(x, O_t)/λ))
```

**新增定义 532（时空证书）** 取代静态 SpatialCert：
```
C_st = (φ_ι, ρ_min, H, e, valid)
ρ_min = min_{t ∈ [t₀, t₀+H]} ρ_{φ_ι}(t)
valid ⇔ (ρ_min ≥ 0) ∧ (e = e_now) ∧ (H_remaining > 0)
```

**新增定义 533（双速率一致性）** 冻结包络与最新包络的包含关系：
```
𝒯_frozen(t) = ⋃_{k: t_k ≤ t} Tube( 𝒯_latest(t_k) ⊕ Ball(v_max·(t−t_k)) )
不变式： ∀t, 𝒯_latest(t) ⊆ 𝒯_frozen(t)
```
其中 `⊕` 表示 Minkowski 膨胀。更新只做并集与膨胀，因此包络在时间上单调不减。

**新增定义 534（锚失效 Anchor Loss）** 定位置信或纪元失效的正式条件：
```
AnchorLoss(t) ⇔ conf_loc(t) < τ_loc ∨ e(t) ≠ e_cert ∨ H_remaining ≤ 0
```
触发后：`C_st.valid ← false`，基座目标速度 `v* ← 0`，进入固定框架保守包络。

**新增定义 535（膨胀预算合成）** 管的膨胀半径由四类误差保守合成：
```
σ_tube(t) = Δ_loc(t) + Δ_track(t) + Δ_pred(t) + Δ_sens
rᵢ(t) = λ_max(Σᵢ(t))^{1/2} · sqrt(χ²₂(1−ε)) + κ · σ_tube(t)
```

**新增定义 536（MST 闭环标识）** 完整与退化模式的形式标识：
```
Φ_MST = { b(t) anchored, 𝒯ᵢ inflated, ρ_φ ≥ 0, e consistent }
Φ_v7  = { b(t) frozen,   SpatialCert static, ρ_φ absent }
```

## 2. 形式化定义（要点）

**定义 493′（指标层级，移动版）** M = (M₀,M₁,M₂,M₃) 不变，但每层的判据从常数阈值升级为 `τᵢ(x,t)`；层内满足由定义 531 的 `βᵢ(t)` 给出。

**定义 494′（语音指令类型化，时空版）** 在 v7 的 ASR 置信门与 NLI 类型检查之后，增加指代接地与 STL 编译两个阶段；任一阶段失败即 `ι ← ι₀`。

**定义 495′（奖励可逆向性，时空版）** 奖励分解形式不变，但“可行动作集”被时空证书裁剪：
```
R(s,a) = Σᵢ wᵢ(s)·rᵢ(s,a),   a ∈ A_feasible(C_st)
```
即证书不直接改权重，而是先剔除会导致 `ρ_φ < 0` 的动作。

**定义 496′（软证书，时空版）** 软证书的触发条件从 `σ < τ_safe` 升级为
```
δ_trigger ⇔ (ρ_{φ_safe} < 0) ∨ AnchorLoss ∨ (𝒯_frozen ⊉ 𝒯_latest)
```

**定义 528′（时空管证书构造）** 对规划轨迹 `ξ: [t₀,t₀+H] → 𝒳`，证书构造为：
```
ρ_min = min_t ρ_{φ_ι}(ξ, t)
m_min = min_t min_i dist( ξ(t), 𝒯ᵢ(t) )      # 与所有障碍管的距离
C_st = (φ_ι, ρ_min, m_min, H, e, valid)
valid ⇔ ρ_min ≥ 0 ∧ m_min ≥ 0 ∧ e = e_now
```
注意 `m_min ≥ 0` 与 `ρ_φ ≥ 0` 在几何安全谓词上是冗余的；保留两者是为了让证书同时覆盖“空间不碰撞”与“任务时序正确”两类违约。

**定义 537（时空退化映射）** 定义从 MST 到 v7 的映射：
```
δ_ST: Φ_MST → Φ_v7
δ_ST(𝒯ᵢ, φ_ι, e) = ( SpatialCert(current pose), freeze(v=0), e ↦ e_ref )
```
该映射在 STR 失效、指代失败或锚失效时被触发；映射后 v7 的 CVC/SpatialCert 不变式必须全部成立。

# IP-351 MobileBaseStateEstimator：移动基座状态与锚纪元
class MobileBaseStateEstimator:
    def __init__(self, tau_loc=0.7, jump_eps=0.15, s0=0.05):
        self.tau_loc = tau_loc
        self.jump_eps = jump_eps
        self.s0 = s0
        self.anchor_epoch = 0
        self.b = None

    def update(self, odom, scan, t):
        """融合里程计与扫描，输出 b(t)、定位置信度、锚纪元"""
        p, theta = self._fuse(odom, scan)
        Sigma_b = self._covariance(odom, scan)
        conf = math.exp(-trace(Sigma_b) / self.s0)
        # 重定位跳变检测：位置/朝向突变即开新锚纪元
        if self.b is not None:
            dp = norm(p - self.b.p)
            dtheta = abs(wrap_to_pi(theta - self.b.theta))
            if dp > self.jump_eps or dtheta > self.jump_eps:
                self.anchor_epoch += 1
        if conf < self.tau_loc:
            self.anchor_epoch += 1       # 低置信也视为锚不可信
        self.b = BaseState(p, theta, odom.v, odom.omega, Sigma_b)
        return self.b, conf, self.anchor_epoch

    def predict(self, b, dt):
        """非完整约束下的短时预测（用于 50Hz 关键环）"""
        theta_mid = b.theta + 0.5 * b.omega * dt
        p_next = b.p + dt * b.v * array([cos(theta_mid), sin(theta_mid)])
        theta_next = b.theta + b.omega * dt
        Sigma_next = b.Sigma_b + dt**2 * self._motion_noise(b)
        return BaseState(p_next, theta_next, b.v, b.omega, Sigma_next)


# IP-352 SpaceTimeTube：时空管
class SpaceTimeTube:
    def __init__(self, mu_fn, Sigma_fn, H, kappa, eps=0.05):
        self.mu_fn = mu_fn          # t -> mean position
        self.Sigma_fn = Sigma_fn    # t -> covariance
        self.H = H
        self.kappa = kappa
        self.chi2 = chi2_ppf(1 - eps, df=2)

    def radius(self, t, sigma_tube):
        """保守外接半径：椭球半径 + 误差预算膨胀"""
        return sqrt(self.chi2 * max_eig(self.Sigma_fn(t))) + self.kappa * sigma_tube(t)

    def contains(self, other, t, tol=0.0):
        """other 管在 t 时刻是否被本管包含（用于双速率一致性）"""
        return (norm(self.mu_fn(t) - other.mu_fn(t))
                + other.radius(t, lambda _: 0.0) * 0.0
                <= self.radius(t, lambda _: 0.0) + tol)


# IP-353 SpatioTemporalReasoner：10Hz 时空推理
class SpatioTemporalReasoner:
    def __init__(self, H=2.0, dt_pred=0.1, kappa=1.5, v_max=1.0):
        self.H = H
        self.dt_pred = dt_pred
        self.kappa = kappa
        self.v_max = v_max

    def reason(self, b, perception, t, epoch):
        """更新 ST-Graph 并对所有实体生成时空管"""
        graph = STGraph()
        graph.update(perception, b, t)
        tubes = {}
        for ent in graph.entities():
            mu_fn, Sigma_fn = ent.predict_trajectory(t, self.H, self.dt_pred)
            # 膨胀预算：定位 + 跟踪 + 预测 + 感知（保守相加）
            def sigma_tube(tt, ent=ent, b=b, t0=t):
                return (sqrt(trace(b.Sigma_b))
                        + ent.track_err
                        + ent.pred_err(tt - t0)
                        + ent.sens_err)
            tubes[ent.id] = SpaceTimeTube(
                mu_fn, Sigma_fn, self.H, self.kappa, eps=0.05)
            tubes[ent.id].sigma_fn = sigma_tube
        return graph, tubes

    def robustness(self, phi, traj, t0):
        """在离散采样上计算 STL 鲁棒度（下界）"""
        ts = [t0 + k * self.dt_pred
              for k in range(int(self.H / self.dt_pred) + 1)]
        return stl_robustness(phi, traj, ts)


# IP-355 DeicticGrounding + IP-354 STLSpecCompiler：时空指令接地
class STCommandTyping(VoiceCommandTyping):
    def __init__(self, asr, nli, default_iota, grounder, compiler,
                 tau_voice=0.85, tau_referent=0.8):
        super().__init__(asr, nli, default_iota, tau_voice)
        self.grounder = grounder
        self.compiler = compiler
        self.tau_referent = tau_referent

    def process(self, audio_stream, b, graph, t):
        text, conf = self.asr.recognize(audio_stream)
        if conf < self.tau_voice:
            return self.ι₀, False, f"ASR低置信 {conf}"

        ι, ok = self.nli.parse(text)
        if not ok or not self._type_check(ι):
            return self.ι₀, False, "类型检查失败"

        # 空间指代 + 时间窗解析；不可验证即退化
        ref = self.grounder.resolve(text, b, graph, t)
        if ref is None or ref.conf < self.tau_referent:
            return self.ι₀, False, "指代不可验证"

        φ = self.compiler.compile(ι, ref)
        if φ is None:
            return self.ι₀, False, "STL 编译失败"

        spec = STCommandSpec(action=ι['action'], target=ref.target_id,
                             relation=ref.relation, I_time=ref.time_window,
                             phi=φ)
        return spec, True, f"接地 {ref.target_id} / {ref.relation}"


# IP-356 MovingFrameMetricLadder：移动框架判据
class MovingFrameMetricLadder:
    def __init__(self, base_ladder, kappa=1.5):
        self.base = base_ladder
        self.kappa = kappa

    def threshold(self, layer, b, t, obstacles):
        """τᵢ(x,t)：示例为随障碍距离衰减的速度阈值"""
        if layer == 1:
            d = min_dist(b.p, obstacles)
            return self.base.tau_min + (self.base.tau_max - self.base.tau_min) \
                   * (1 - math.exp(-d / self.base.lam))
        return self.base.thresholds[layer]

    def margin(self, layer, metric, b, t, obstacles, sigma_tube):
        tau = self.threshold(layer, b, t, obstacles)
        return metric - tau - self.kappa * sigma_tube

    def satisfies(self, layer, traj_metrics, b_fn, obstacles_fn, sigma_fn):
        """整条时域上的逐点满足（离散采样下界）"""
        return all(
            self.margin(layer, m, b_fn(t), t, obstacles_fn(t), sigma_fn(t)) >= 0
            for t, m in traj_metrics)


# IP-357 SpaceTimeCertificate：时空证书
class SpaceTimeCertificate:
    def __init__(self, H=2.0, kappa=1.5):
        self.H = H
        self.kappa = kappa

    def issue(self, plan_traj, tubes, phi, b, epoch, t0):
        rho_min = stl_robustness(phi, plan_traj, sample_times(t0, self.H))
        m_min = min(
            min(dist_to_tube(plan_traj(t), tube, t) for tube in tubes.values())
            for t in sample_times(t0, self.H))
        valid = (rho_min >= 0) and (m_min >= 0) and (epoch == b.epoch)
        return SpaceTimeCert(phi=phi, rho_min=rho_min, m_min=m_min,
                             H=self.H, epoch=epoch, valid=valid)

    def invalidate(self, cert, reason):
        cert.valid = False
        cert.reason = reason
        return cert


# IP-358 DualRateScheduler：双速率单向保守
class DualRateScheduler:
    def __init__(self, reasoner, v_max=1.0):
        self.reasoner = reasoner
        self.v_max = v_max
        self.frozen = {}        # id -> SpaceTimeTube（只增不减）
        self.last_update = None

    def critical_tick(self, t):
        """50Hz：只用冻结包络，禁止现场缩小"""
        return self.frozen

    def reasoning_tick(self, b, perception, t, epoch):
        """10Hz：新预测只能并入冻结包络，不能替换"""
        graph, latest = self.reasoner.reason(b, perception, t, epoch)
        for eid, tube in latest.items():
            grown = self._grow(tube, t - (self.last_update or t))
            self.frozen[eid] = self._union(self.frozen.get(eid), grown)
        # 一致性自检：最新管必须被冻结管包含
        for eid, tube in latest.items():
            assert self._contains(self.frozen[eid], tube, t), \
                "双速率一致性违约：冻结包络比最新预测更乐观"
        self.last_update = t
        return graph, self.frozen

    def _grow(self, tube, dt):
        """按 v_max·dt 做 Minkowski 膨胀，保证时间单调"""
        return tube.inflate(self.v_max * max(dt, 0.0))


# IP-359 AnchorLossGuard：锚失效守卫
class AnchorLossGuard:
    def __init__(self, tau_loc=0.7):
        self.tau_loc = tau_loc

    def check(self, b, conf, epoch, cert):
        if conf < self.tau_loc or (cert is not None and epoch != cert.epoch):
            if cert is not None:
                cert.invalidate("AnchorLoss")
            return False            # 触发保守停车
        return True


# IP-360 主闭环：MetricVoiceGauge-MST
def metricvoicegauge_mst(M, s, obs, audio_stream, b, conf, epoch,
                         str_reasoner=None, st_typing=None,
                         tube_cert=None, scheduler=None, guard=None):
    """50Hz 主路径；MST 全部为可选增强，任一失效退回 v7"""
    # 1) 锚失效守卫（最高优先级）
    if guard is not None and not guard.check(b, conf, epoch, M.cert):
        return M.fallback_v7(s, obs, reason="AnchorLoss")

    # 2) 时空推理（10Hz，仅在到点时更新冻结包络）
    if str_reasoner is not None and scheduler is not None and M.due_reasoning():
        graph, tubes = scheduler.reasoning_tick(b, obs.perception,
                                                M.t, epoch)
    elif scheduler is not None:
        graph, tubes = M.st_graph, scheduler.critical_tick(M.t)
    else:
        graph, tubes = None, None

    # 3) 时空指令接地（可用则用，失败即退回 v7 指令）
    if st_typing is not None and audio_stream is not None and graph is not None:
        spec, ok, log = st_typing.process(audio_stream, b, graph, M.t)
        if not ok:
            spec = M.default_iota
    else:
        spec = M.default_iota

    # 4) 规划与指标（沿用 v7 的 Hypothesis/IAC/RT-CVC，仅阈值改为 MFML）
    plan = M.plan(s, spec, tubes)
    metrics = M.evaluate(plan, b, tubes)

    # 5) 时空证书（可用则签发，否则退回静态 SpatialCert）
    if tube_cert is not None and tubes is not None and hasattr(spec, 'phi'):
        cert = tube_cert.issue(plan, tubes, spec.phi, b, epoch, M.t)
    else:
        cert = M.static_spatial_cert(plan, b)      # v7 退化

    # 6) 软硬约束与奖励（v7 逻辑；证书只裁剪可行动作集）
    if not cert.valid:
        plan = M.conservative_stop(s, b)
    R = M.reward(plan, s, cert)

    # 7) SpatialCert / FaultCert / ROS 发布（沿用 v7）
    return M.finalize(plan, cert, R, spec)

## 4. 推导

**引理 77（时空管可靠性 / Tube Soundness）**
设 t₀ 时刻真实状态落在以 `μᵢ(t₀)` 为中心、协方差 `Σᵢ(t₀)` 的置信椭球内，且跟踪误差、预测误差、感知误差分别不超过 `Δ_track, Δ_pred, Δ_sens`，定位误差半径不超过 `Δ_loc`。若规划轨迹 `ξ` 满足 `dist(ξ(t), 𝒯ᵢ(t)) ≥ 0`（其中 `𝒯ᵢ` 使用定义 535 的膨胀半径），则对任意 `t ∈ [t₀,t₀+H]`，真实实体与 `ξ(t)` 不发生碰撞的概率至少为 `1−ε`。
*证明要点*：真实位置 = 预测均值 + 定位误差 + 跟踪误差 + 预测误差 + 感知误差；四项由三角不等式被 `σ_tube` 统一上界，故真实点始终落在膨胀后的管内。若 ξ 与膨胀管不相交，则与真实位置不相交。∎

**引理 78（STL–指标层级等价）**
取 STL 片段 `φ = □_[0,H]( ∧ᵢ (mᵢ ≥ τᵢ) )`，其原子谓词恰为各层余量。则 `ρ_φ(t₀) ≥ 0` 当且仅当对所有 `t ∈ [t₀,t₀+H]` 与所有层 i，`βᵢ(t) ≥ 0`。
*证明要点*：`ρ` 对 `□` 取时域最小值、对 `∧` 取逐层最小值；`ρ(mᵢ ≥ τᵢ) = mᵢ − τᵢ = βᵢ + κσ_tube`。将膨胀项移入阈值即得。需要 `κσ_tube` 在时域上解析可积或采样足够密；否则只能得到离散下界（见引理 77 的 ε 项）。∎

**引理 79（指代接地的可靠性）**
若 `𝒟(text, b(t₀), G_ST(t₀))` 返回唯一目标 `target_id`，且该目标的置信椭球完全落在传感器已验证区域 `𝒱(t₀)` 内，则接地结果与真实指代一致；若返回 `⊥` 或置信度低于 `τ_referent`，系统退化为 `ι₀`，不会对未验证实体执行动作。
*证明要点*：指代消解只使用 `G_ST` 中带时间区间与置信度的实体；`target ∈ 𝒱` 排除“地图里存在但当前不可见”的幻觉指代。退化分支不产生新的动作，故安全性由 v7 的 `ι₀` 保证。∎

**引理 80（双速率单调性）**
按定义 533 的并集-膨胀更新，`𝒯_frozen(t)` 在时间上单调不减；因此 50Hz 关键环使用的包络永远不弱于 10Hz 最新预测，不会出现“快环用乐观包络、慢环随后判违约”的证书翻转。
*证明要点*：每步更新为 `𝒯_frozen ← 𝒯_frozen ∪ (𝒯_latest ⊕ Ball(v_max·Δt))`；并集与 Minkowski 膨胀均单调，故包含关系保持。∎

**引理 81（锚失效安全性）**
若 `AnchorLoss` 成立，则系统立即令 `C_st.valid=false` 且 `v*←0`，其后续行为等价于 v7 在“基座冻结 + 固定框架大膨胀包络”下的行为，仍满足 CVC 与静态 SpatialCert。
*证明要点*：锚失效意味着位姿与地图的关联不可信；冻结基座把移动框架问题降为静态问题，大膨胀包络覆盖残余定位误差，故 v7 的静态证书证明可直接复用。∎

**引理 82（三新模块联合退化正确性）**
STR、STCT、STTC 任一失效时，系统等价于 MetricVoiceGauge v7；三者同时失效时等价于 v6。合并失效不产生级联违约。
*证明要点*：① STR 失效 ⇒ `𝒯` 退化为固定半径保守球，证书仍有保守上界；② STCT 失效 ⇒ `spec = ι₀`，v7 类型检查接管；③ STTC 失效 ⇒ 退回 `static_spatial_cert`；④ 三者皆失效 ⇒ 无 `φ`、无管、无锚约束，行为即 v6/v7。各退化分支均不修改奖励分解，故无耦合放大。∎

## 8. 本轮最大风险

**一句话**：时空管的膨胀系数是安全性与可用性的总开关——膨胀太小会漏掉定位漂移与预测误差导致的动态碰撞，膨胀太大会让可行域塌缩成“只会停车”的保守系统；本轮最大的风险是把静态证书平移到移动基座时，**证书的保守性与任务可用性无法同时成立**。
