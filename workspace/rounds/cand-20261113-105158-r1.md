# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环控制」IP-224~233；灵感循环第 4 轮；本轮灵感：「强化学习」×「力控」）

> 第 66 轮 RAS 把闭环从「被动故障响应」推进到「主动意图感知」：用面部表情捕获风险态度，用 λ_risk 缩放控制量，用 ERS 沿情绪风险梯度做局部整形。但它对“力”的使用仍然是**信息盲的**——λ_risk 把力当作一个需要收缩的安全旋钮，ERS 只是一个短视的梯度修正。系统越不确定，RAS 越收缩、越保守、越不敢接触；于是**越不可能获得消除不确定性所需的信息**。这是一种「不确定性冻结」：后验不降，保守不止。
>
> 本轮命题：
>
> **把力控从「安全旋钮」升级为「实验设计通道」：用强化学习在证书护盾内学习「何时、沿哪个方向、用多大力去探询」，以决策相关的信息增益为回报，主动切断故障别名。**
>
> VISTA 问「哪层坏了」，RAS 问「谁该控制、控制多少」，APEX 问「**为了弄清楚哪里坏了，我该主动施加多大的力、施加在哪里，同时不把系统推过安全边界**」。

## 0. 直觉与动机

**灵感 1（强化学习 → 把“探索”变成物理实验设计）**
直觉：强化学习的核心难题是探索-利用权衡。但在接触丰富的力控任务里，探索不是免费的：一次 ε-greedy 的随机动作可能压碎杯子、打滑或失稳。于是“探索”必须被重新定义——它不是随机扰动，而是**有信息价值的物理实验**。把故障假设 H 纳入信念状态，RL 就在信念空间里做探索：只有当某个力探询能显著降低 H 的后验熵、且其风险在预算内时，才值得做。这把经典 RL 的 exploration bonus 换成了 **expected information gain about faults**。

**灵感 2（力控 → 力既是执行器也是传感器）**
直觉：在接触任务中，力/位混合控制、阻抗/导纳控制既改变任务执行，也改变“能看到什么”。法向载荷 N 决定摩擦锥半径 μN，从而决定切向力对摩擦系数 μ 的可观测性；接触刚度 K_d 决定法向残差对模型误差的敏感度。换言之，**控制输入直接塑造故障可观测性**。这就是信息-风险权衡的物理来源：加大 N 能让 μ 更可见，但也把接触推向更危险的区域；减小 N 更安全，却让 μ 永远不可辨识。RAS 只看到了后半句。

**灵感 3（RAS 的缺口 → 信息盲的保守性）**
直觉：RAS 的 `λ_risk = 1 - α·R_emotion - β·H_face` 是单调保守的：不确定性越高，动作幅值越小。但在力控中，某些故障维度**只有在激励方向上才可观测**。若 λ_risk 把所有激励压到零，后验熵停在信息地板上，系统就永久保守。可以把它形式化为：被动策略的观测矩阵 H_passive 存在零空间，任何落在零空间里的故障分量信息增益恒为 0。RAS 能降低性能，却降不了这个熵。

**灵感 4（两灵感咬合 → 护盾内的信息驱动探索）**
直觉：不能裸用 RL。正确的结构是「RL 提议、证书护盾裁决」：
- **慢环（语义流，10–50Hz）**：贝叶斯故障信念 + RL 探询策略 π_θ + 残差力策略 π_res；
- **快环（实时流，1kHz）**：阻抗/力控执行 + 硬约束检查 + C-RAS 认证前缀。
RL 只在慢环里“想”，快环永远只执行落在安全探针集 `A_safe` 内的动作。护盾既是安全保证，也是探索的**可行域先验**。

**灵感 5（别名消歧 → 只买“会改变处置”的信息）**
直觉：并非所有不确定性都值得花钱。真正致命的是**别名**：足底打滑的力残差与“有意迈步”几乎同分布；负载变化与摩擦变化在法向通道上难分；传感器零漂与模型偏差在稳态下同号。把这些别名建成图 `A(H)`，RL 的目标就从“降低全部熵”收缩为“切断会改变处置决策的别名边”。这既更安全，也更样本高效。定义**对比信息增益**与**最小辨识力** `f_dist`，让系统只施加“刚好够分辨”的力。

**灵感 6（合流 → APEX：主动探询式执行安全）**
`APEX = (ℳ_F, b, A_probe, A_safe, S, π_θ, π_res, J_A)`：
1. **ℳ_F**：故障增广力控 POMDP，状态含未知故障 h、动作分裂为任务力 + 探询力；
2. **b**：VISTA/RAS 后验升级为在线信念，含别名结构；
3. **A_safe**：在 top-k 故障假设下仍通过 C-RAS 认证的探针集合；
4. **S**：护盾算子，把任意 RL 动作投影回 `A_safe`；
5. **π_θ**：以“任务回报 + 决策信息增益 − 探询成本”为目标的约束 RL 策略；
6. **π_res**：认证管内的残差力策略，补偿模型误差；
7. **J_A**：在 J_RAS 上增加信息增益、峰值风险、护盾干预、OOD 等字段的证书。

**为什么不是已有方法的直接组合**：主动感知（active perception）大多作用于视觉/视角选择；安全 RL 的护盾通常面向“到达目标”；残差 RL 通常只做跟踪补偿；变阻抗 RL 通常只优化任务回报。APEX 的新意在于：**把“施加力”本身当作带故障证书的辨识实验**，并用决策 VOI 而非全熵、峰值风险而非仅期望风险来约束它。信息获取与安全认证在同一动作上竞争，这是接触任务特有的结构。

## 1. 形式化定义（增量：定义 245–262）

- **定义 245（APEX 总览）**：`APEX = (ℳ_F, b, A_probe, A_safe, S, π_θ, π_res, J_A)`。定位：在 VISTA 故障归因与 RAS 风险缩放之上，增加「主动信息获取」层。不变式：RL 训练与推理、信念更新、信息增益计算只在语义流；实时流只执行带护盾的力动作与硬约束检查，学习组件零写操作。
- **定义 246（故障增广力控 POMDP）**：`ℳ_F = (S, A, O, T, Z, ℋ, r, c, γ)`，状态 `s = (x, ẋ, h)`，`h ∈ ℋ_V × E`；动作 `a = (a_task, a_probe)`；观测 `o = (ρ, y_vis, π_emotion)`；目标为约束优化：`max_π E[Σγ^t (r_task + β·IG_t − c_probe)]  s.t.  E[Σγ^t c_t] ≤ d`，其中 `c_t = r_contact + η·r_emotion`。
- **定义 247（力动作分解）**：`a_task = (f_d, K_d, D_d)`（任务力/阻抗）；`a_probe = (Δf_p, ΔK_p, Δx_c, u_p, τ_p)`（探询力增量、刚度调制、接触点、方向、时长）。总动作 `a = a_task ⊕ a_probe ∈ A_act`，受执行器与摩擦锥约束。
- **定义 248（故障敏感雅可比）**：`J_h(x,a) = ∂ρ/∂h |_{x,a}`，其中残差 `ρ = f_meas − f_model(x,h)`。`J_h` 度量当前接触状态下故障对残差的可见性；关键性质：`J_h` 依赖 `a_probe`。
- **定义 249（期望信息增益）**：`IG(a;b) = I(H;O | b,a) = H(b) − E_{o~p(·|b,a)} H(b')`。局部线性高斯下
  `IG ≈ ½ log det(I + Σ_b^{1/2} J_h^T Σ_o^{-1} J_h Σ_b^{1/2})`。
  一阶近似定义故障可观测性指数 `FOI(a) = tr(Σ_b^{1/2} J_h^T Σ_o^{-1} J_h Σ_b^{1/2})`。
- **定义 250（接触探询风险）**：`r_probe(a,b) = max_{h∈top-k(b)} [max(0,−m_N) + max(0,−m_f) + max(0,−m_c) + κ‖f‖²]`，其中 `m_N, m_f, m_c` 为法向力、摩擦锥、支撑/CoM 裕度。硬风险 `R∞(a,b) = max_h r_probe`。
- **定义 251（安全探针集）**：`A_safe(b) = {a∈A_act : R∞(a,b) ≤ 0 ∧ k*(a,b) ≥ 1 ∧ λ_risk·ρ_safe ≥ 0}`，即最坏 top-k 故障假设下仍通过 C-RAS 认证的动作集合。`A_safe` 恒包含零探针 `a_probe = 0`（见假设 A93）。
- **定义 252（护盾算子）**：`S_b(a) = argmin_{a'∈A_safe(b)} ‖a' − a‖²_W`；若 `A_safe = ∅`，返回 fail-safe 动作 `a_fallback`（RAS 的安全动作）。部署策略为 `π_S = S_b ∘ π_θ`。
- **定义 253（别名图）**：`(h₁,h₂) ∈ A(H)` 若 `KL(p(ρ|h₁,a_task) ‖ p(ρ|h₂,a_task)) < τ_alias`。典型边：slip vs 有意迈步、负载变化 vs 摩擦变化、传感器零漂 vs 模型偏差。
- **定义 254（对比信息增益）**：`IG_alias(a;b) = H(b_A) − E H(b'_A)`，`b_A` 为 b 在别名等价类上的边缘。只奖励会改变处置决策的不确定性，忽略与决策无关的熵。
- **定义 255（最小辨识力）**：`f_dist(h₁,h₂) = min{ ‖a_probe‖ : KL(p(ρ|h₁,a) ‖ p(ρ|h₂,a)) ≥ τ_id }`。线性高斯下近似 `f_dist ∝ τ_id·σ_o / ‖(J_{h₁}−J_{h₂})a_task‖`。
- **定义 256（情绪条件探询预算）**：`d_t = d_0·λ_risk(t)·(1 − ζ·1[P(fear)+P(pain) > τ_e])`。情绪信号只允许收紧预算，**不得放宽任何硬约束**。
- **定义 257（残差力策略）**：`π_res(o_t,b_t) → Δa`，且 `‖Δa‖ ≤ ε_tube(b_t)`；总动作 `a = a_task + π_res`。残差只补偿模型误差，不改变护盾判定。
- **定义 258（探询集中度约束）**：除累计预算 d 外，增加每步峰值约束 `r_probe ≤ r_peak` 与尾部约束 `CVaR_α(r_probe) ≤ r_max`。理由见引理 12：仅有累计预算时，凹的信息增益会诱导“一次性猛探”。
- **定义 259（J_APEX 证书）**：
  `J_APEX = (J_RAS, π_θ_hash, π_res_hash, IG_expected, IG_realized, peak_risk, cvar_risk, shield_interventions, ood_score, λ_safe_dual, apex_ver)`。
  `Valid ⇔ Valid(J_RAS) ∧ peak_risk ≤ r_peak ∧ CVaR_α ≤ r_max ∧ (ood_score ≤ τ_ood ∨ fallback_engaged)`。
- **定义 260（失效回退与活性）**：若 `A_safe = ∅`、`ood_score > τ_ood`、或 IG 估计置信区间过宽，则回退到 RAS 安全动作。活性条件：`a_task ∈ A_safe`，保证“无探询也可安全执行”，系统不会冻结。
- **定义 261（无效探询检测）**：对抗性/奖励黑客式探询表现为「IG 预测高但执行后决策后验不降」。监测 `probe_ineffective = 1[IG_realized < κ_ig·IG_expected]`，连续触发则降级。
- **定义 262（部署协议）**：离线训练（仿真 + 域随机化 + 离线 RL）；在线语义流计算 b、IG、π；实时流以 1kHz 执行阻抗/力控、护盾投影与硬约束检查。任何学习组件不得写实时控制回路。

## 2. 关键算法骨架

```python
# APEX 运行时：RL 提议，证书护盾裁决
def APEX_round(M, obs):
    # 0) VISTA/RAS 前向（复用第 65/66 轮）
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis   = M.f_vis(img, depth, flow)

    # 1) 信念：故障 × 情绪 × 模式
    rho, face_gate = M.fir.signature(...), M.er.recognize(img)
    b = M.belief.update(rho, face_gate, tactile)

    # 2) RL 在语义流提议「任务力 + 探询力」
    a_task  = M.pi_task(x_prime, b)                 # 任务力/阻抗
    a_probe = M.pi_theta(x_prime, b, M.alias_graph) # 探询提议
    a_raw   = combine(a_task, a_probe)

    # 3) 护盾：投影到 top-k 故障下的安全探针集
    a_safe, projected = M.shield.project(a_raw, b, top_k=3)

    # 4) 实时流执行（1kHz 内层），返回真实力残差
    tau_cmd, rho_exec = M.rt_force_loop.execute(a_safe)

    # 5) 贝叶斯更新 + 信息增益核算
    b_next = M.belief.update(rho_exec, face_gate, tactile)
    IG_real = entropy(b) - entropy(b_next)
    M.log(J_APEX(b, a_safe, IG_real, projected))

    # 6) 失败回退与无效探询检测
    if M.shield.empty or M.ood(b) or M.probe_ineffective(IG_real):
        M.engage_fallback()
    return a_safe, b_next, IG_real


# 安全探针投影（小规模 QP / 主动集，热启动）
def project_to_safe(a_raw, b, top_k=3):
    if feasible(a_raw, b, top_k):
        return a_raw, 0.0
    best, best_d = None, +inf
    for a in ACTIONS_GRID:                 # 或对 a_raw 做局部 QP
        if not feasible(a, b, top_k):      # 最坏 h 下的接触/证书约束
            continue
        d = weighted_dist(a, a_raw)
        if d < best_d:
            best, best_d = a, d
    return (best if best is not None else FALLBACK_ACTION), best_d


# 约束 RL 训练：PPO-Lagrangian + 护盾 rollout
def train_APEX(sim_env, episodes):
    theta, lam_safe = init_policy(), 0.0
    for ep in range(episodes):
        b = sim_env.reset_belief()
        for t in range(T):
            a_task  = policy_task(theta, b)
            a_probe = policy_probe(theta, b)          # 输出均值/方差
            a_safe, _ = sim_env.shield.project(combine(a_task, a_probe), b)
            if sim_env.shield.empty:
                a_safe = FALLBACK_ACTION
            o, r_task, c_risk = sim_env.step(a_safe)
            b2 = bayes_update(b, o)
            r = r_task + beta * decision_VOI(b, b2) - c_probe(a_safe)
            buffer.add(a_safe, r, c_risk, b)
            b = b2
        # 约束：E[Σ c] ≤ d，用对偶变量 λ_safe 拉格朗日化
        theta, lam_safe = ppo_update(theta, buffer, lam_safe, cost_budget=d)
        lam_safe = max(0.0, lam_safe + lr_dual * (avg_cost - d))
    return theta, lam_safe


# 残差力策略：只在认证 tube 内学习
def residual_force_action(o, b, theta_res):
    delta = policy_res(theta_res, o, b)
    eps = certified_tube_radius(b)                    # 来自 J_RAS/C-RAS
    return clip_norm(delta, eps)

## 3. 推导

先声明本轮新增假设：
- **A92（基座稳定性）**：认证前缀内，阻抗/导纳基座力控器满足无源性（passivity）或能量槽约束。
- **A93（安全集非空）**：`A_safe(b)` 恒包含零探针动作；任务动作本身安全可行。
- **A94（护盾失真界）**：`‖S_b(a) − a‖_W ≤ ε_shield`。
- **A95（模型线性化误差）**：在认证 tube 内，接触模型相对线性化误差 `≤ ε_model`。
- **A96（IG 估计校准）**：集成模型给出的 `IG_expected` 与真实信息增益的偏差 `≤ ε_IG`。
- **A97（情绪只收紧）**：RAS 的情绪信号只进入预算与成本，不进入硬约束的放松方向。

**引理 11（信息-风险的内点最优）**
在局部线性高斯接触模型下，`IG(f) = ½ log(1 + c·f²)` 关于探询力幅 `f` 严格凹增；接触风险 `r(f) = κ·f^p (p≥2)` 凸增。最大化 `IG(f) − λ·r(f)` 的解满足
`c·f / (1 + c·f²) = λ·p·κ·f^{p−1}`，
当 `λ > 0` 时存在内点 `f*`，且 `f*` 随 `λ` 单调递减。故“最大力”与“零探询”都不是信息-风险最优，最优探询力由风险价格 λ 决定。这与 RAS 的“只收缩不激励”形成对照：RAS 取的是 `f=0` 的角点。

**引理 12（累计预算导致探询集中）**
设 `IG_i(f_i)` 为凹增函数，风险可加 `Σ f_i ≤ D`。由 Jensen 不等式，`Σ IG_i(f_i)` 在单纯形上的最大值在顶点取得——即把全部预算集中到一步。因此仅用累计风险预算会诱导“一次性猛探”（峰值风险 = D），而不是平滑探询。加入每步峰值约束 `f_i ≤ f_peak` 或 `CVaR_α` 后，可把同样的信息量摊平；在合成实验中，峰值风险从 29.9 降到 10.0 而最终熵几乎不变（见产物区）。

**定理 11（护盾安全、改进与活性）**
在 A92–A97 下，`π_S = S_b ∘ π_θ` 满足：
1. **安全**：`P(接触/力/几何违规) ≤ α_chunk + δ_fi + α_probe + δ_model`，其中 `δ_model` 由 `ε_model` 与 `ε_shield` 界定；
2. **改进**：在原 MDP 中 `V^{π_S} ≥ V^{π_base} − L·ε_shield/(1−γ)`，`L` 为值函数 Lipschitz 常数；在护盾子 MDP `M_S` 中，任何策略改进都真实可执行；
3. **活性**：由 A93，零探针恒可行，故 `A_safe ≠ ∅` 且系统不会因护盾而死锁；`A_safe` 为空时回退到 RAS 安全动作。
注意：第 2 条是“相对基座不退化”的界，而不是“探索一定提升任务回报”。当护盾收缩过强时，`π_S` 可能退化为基座策略——这正是 `r_peak` 与 `d_t` 需要标定的原因。

**定理 12（别名可辨识性与样本复杂度）**
对别名对 `(h₁,h₂)`，探询 `a` 使其可辨识当且仅当
`½‖J_h(a)(h₁−h₂)‖²_{Σ_o^{-1}} ≥ τ_id²`。
若每次探询的对称 KL 为 `kl > 0`，则主动策略以 `O(log(1/δ)/kl)` 次探询将误判概率降到 δ；而任何被动策略若 `(h₁−h₂)` 落在 `H_passive` 的零空间，则所需次数为 `∞`。这解释了 RAS 在“打滑 vs 迈步”这类别名上的结构性失明，也给出 `f_dist` 的存在性。

**定理 13（主动探询的信息地板突破）**
设被动策略的观测矩阵为 `H_passive`，则其对 `H` 的信息增益满足 `IG_passive ≤ ½ log det(I + Σ_b^{1/2} H_passive^T Σ_o^{-1} H_passive Σ_b^{1/2})`；落在 `null(H_passive)` 的故障分量永不可辨识。主动策略若选择使 `J_h(a)` 满秩的探询，则后验协方差可按 `Σ_b^{-1} ← Σ_b^{-1} + J_h^T Σ_o^{-1} J_h` 持续收缩，直到接触非线性或执行器饱和成为新的信息上界。因此 APEX 不是“更聪明的 λ_risk”，而是**改变了可观测性本身**。

**命题 1（奖励黑客与认知分解）**：若把总熵（含偶然不确定性）作为信息奖励，策略会偏好高噪声接触状态以“制造信息”。应只奖励**认知不确定性**（ensemble disagreement）并使用 decision-VOI；`probe_ineffective` 监测可检测“预测高、实际低”的伪探询。

def APEX_round(M, obs):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    a_task  = M.pi_task(x_prime, b)
    a_probe = M.pi_theta(x_prime, b, M.alias_graph)
    a_raw   = combine(a_task, a_probe)

    # (3) 护盾：top-k 故障假设下的安全投影
    a_safe, proj_dist = M.shield.project(a_raw, b, top_k=3)

    # (4) 实时流执行（1kHz）
    tau_cmd, rho_exec = M.rt_force_loop.execute(a_safe)

    # (5) 贝叶斯更新与信息核算
    b_next = M.belief.update(rho_exec, face_gate, tactile)

    M.log(J_APEX(b, a_safe, IG_real, proj_dist))

    if M.shield.empty or M.ood(b) or M.probe_ineffective(IG_real):
        M.engage_fallback()
    return a_safe, b_next, IG_real

def project_to_safe(a_raw, b, top_k=3):
    if feasible(a_raw, b, top_k):
        return a_raw, 0.0
    best, best_d = FALLBACK_ACTION, float('inf')
    for a in ACTIONS_GRID:                 # 小规模网格；或局部 QP + 热启动

            continue
        d = weighted_dist(a, a_raw, W)
        if d < best_d:

    return best, best_d

            a_safe, _ = sim_env.shield.project(a_raw, b)
            if sim_env.shield.empty:

            buffer.add(a_safe, r, c_risk, b)

        lam_safe = max(0.0, lam_safe + lr_dual * (avg_cost(buffer) - d))
    return theta, lam_safe


# ---------- 残差力策略 ----------
def residual_force_action(o, b, theta_res):
    delta = policy_res(theta_res, o, b)
    eps   = certified_tube_radius(b)       # 来自 J_RAS / C-RAS
    return clip_norm(delta, eps)
```

## 4. 推导

新增假设：
- **A92（基座稳定性）**：认证前缀内，阻抗/导纳基座力控器满足无源性（passivity）或能量槽约束。
- **A93（安全集非空）**：`A_safe(b)` 恒包含零探针动作；任务动作本身安全可行。
- **A94（护盾失真界）**：`‖S_b(a) − a‖_W ≤ ε_shield`。
- **A95（模型线性化误差）**：在认证 tube 内，接触模型相对线性化误差 `≤ ε_model`。
- **A96（IG 估计校准）**：`|IG_expected − IG_true| ≤ ε_IG`。
- **A97（情绪只收紧）**：RAS 的情绪信号只进入预算与成本，不进入硬约束的放松方向。

**引理 11（信息-风险的内点最优）**
在局部线性高斯接触模型下，`IG(f) = ½ log(1 + c·f²)` 关于探询力幅 `f` 严格凹增；接触风险 `r(f) = κ·f^p (p≥2)` 凸增。最大化 `IG(f) − λ·r(f)` 的一阶条件为
```
c·f / (1 + c·f²) = λ·p·κ·f^{p−1}
```
当 `λ > 0` 时存在内点 `f*`，且 `f*` 随 `λ` 单调递减。故“最大力”与“零探询”都不是最优；RAS 的 `f=0` 角点只是 `λ→∞` 的极限。

**引理 12（累计预算导致探询集中）**
若每步 `IG_i(f_i)` 凹增、风险可加且 `Σ f_i ≤ D`，由 Jensen 不等式，`Σ IG_i(f_i)` 在单纯形上的最大值在顶点取得——即把全部预算集中到一步。因此仅用累计风险预算会诱导“一次性猛探”（峰值风险 = D）。加入 `f_i ≤ f_peak` 或 `CVaR_α` 后，可将同样信息量摊平。合成实验：峰值风险从 29.9 降到 10.0，最终熵几乎不变（−0.865 vs −0.862）。

**定理 11（护盾安全、改进与活性）**
在 A92–A97 下，`π_S = S_b ∘ π_θ` 满足：
1. **安全**：`P(接触/力/几何违规) ≤ α_chunk + δ_fi + α_probe + δ_model`，`δ_model` 由 `ε_model` 与 `ε_shield` 界定；
2. **改进**：在原 MDP 中 `V^{π_S} ≥ V^{π_base} − L·ε_shield/(1−γ)`；在护盾子 MDP `M_S` 中任何改进都真实可执行；
3. **活性**：由 A93，零探针恒可行，`A_safe ≠ ∅`；为空时回退 RAS 安全动作。

**证明要点**：安全项把每次动作的违规概率分解为 VISTA 归因误差 `δ_fi`、动作块认证误差 `α_chunk`、探询模型误差 `α_probe` 与线性化/投影误差 `δ_model`；护盾把动作限制在 `A_safe`，故每一项都落在证书假设内。改进项来自护盾投影的 1-Lipschitz 性质与值函数 Lipschitz 常数 `L`；活性由 A93 直接得到。注意第 2 条是“相对基座不退化”的界，探索未必提升任务回报；护盾过强时 `π_S` 退化为基座，这正是 `r_peak` 与 `d_t` 需要标定的原因。

**定理 12（别名可辨识性与样本复杂度）**
对别名对 `(h₁,h₂)`，探询 `a` 使其可辨识当且仅当
```
½‖J_h(a)(h₁−h₂)‖²_{Σ_o^{-1}} ≥ τ_id²
```
若每次探询的对称 KL 为 `kl > 0`，主动策略以 `O(log(1/δ)/kl)` 次探询将误判概率降到 δ；若 `(h₁−h₂) ∈ null(H_passive)`，任何被动策略所需次数为 `∞`。这解释了 RAS 在“打滑 vs 迈步”“负载 vs 摩擦”上的结构性失明，并给出 `f_dist` 的存在性。

**定理 13（主动探询突破信息地板）**
被动策略的观测矩阵 `H_passive` 给出信息上界
```
IG_passive ≤ ½ log det(I + Σ_b^{1/2} H_passive^T Σ_o^{-1} H_passive Σ_b^{1/2})
```
落在 `null(H_passive)` 的故障分量永不可辨识。主动策略选择使 `J_h(a)` 满秩的探询，则后验精度按 `Σ_b^{-1} ← Σ_b^{-1} + J_h^T Σ_o^{-1} J_h` 持续增长，直到接触非线性或执行器饱和成为新的上界。因此 APEX 改变的是**可观测性本身**，而不只是“更聪明的 λ_risk”。

**命题 1（奖励黑客与认知分解）**
若把总熵（含偶然不确定性）作为信息奖励，策略会偏好高噪声接触状态以“制造信息”。应只奖励认知不确定性（ensemble disagreement）并使用 decision-VOI；`probe_ineffective` 可检测“预测高、实际低”的伪探询。

## 7. 合成机制验证（非基准证据）

为隔离“信息驱动探询 + 风险预算”这一机制，做一个**线性高斯 2 维接触玩具**（见下），只验证信息-风险权衡，不声称真实机器人性能。

**设定（声明式生成模型，非拟合）**：未知故障 `θ = (k 刚度, μ 摩擦)`，先验 `N([1,1], diag(0.25,0.25))`；每步动作 `(a_n, a_t)`，观测 `o = diag(a_n, a_t)θ + ε`，`ε~N(0,0.25)`；摩擦锥约束 `a_t ≤ 0.6a_n`；风险代理 `r(a) = a_n² + (a_t/0.6)²`；视界 `B=5`。高斯期望信息增益有闭式，信念用 Kalman 精度更新。每策略 400 次蒙特卡洛。

| 策略 | 最终熵 H | ΔH vs 被动 | RMSE | μ 辨识率 | 累计风险 | 峰值风险 | 每单位风险增益 |
|---|---|---|---|---|---|---|---|
| 被动任务力 | 0.556 | — | 0.336 | 0.20 | 5.0 | 1.0 | — |
| 单步上限信息贪心 | −1.317 | 337% | 0.117 | 0.64 | 49.4 | 10.0 | 0.076 |
| 预算信息（峰值上限 10） | −0.862 | 255% | 0.145 | 0.51 | 30.0 | 10.0 | **0.102** |
| 预算信息（仅累计预算） | −0.865 | 256% | 0.145 | 0.53 | 30.0 | 29.9 | 0.102 |
| 最大力 | −2.881 | 618% | 0.052 | 0.95 | 250.0 | 50.0 | 0.025 |

**读法与结论**：
1. **信息驱动探询显著突破信息地板**：预算策略用 6× 被动风险换来 255% 的熵降，μ 辨识率从 20% 升到 51%；被动策略的 μ 通道长期不可观测，正是 RAS「越保守越瞎」的玩具版本。
2. **存在内点最优**：最大力把熵再降到 −2.881，但风险是被动的 50×，每单位风险增益仅 0.025，远低于预算策略的 0.102。这与引理 11 一致——信息增益凹增、风险凸增，最优不是最大力。
3. **累计预算会诱发“猛探”，峰值约束几乎免费**：仅累计预算把风险集中在单步（峰值 29.9）；加上每步峰值上限 10 后，最终熵几乎不变（−0.862 vs −0.865），峰值风险降到 1/3。这是引理 12 的直接设计含义：**必须约束峰值/CVaR，而不只是期望总预算**。
4. **局限**：线性高斯、无摩擦滞后、无 sim-to-real；真实接触的非光滑与模型失配仍需 E252/E255/E258 验证。该玩具只证明机制方向，不作为基准证据。

## 8. 本轮最大风险

**一句话**：APEX 的核心假设是「证书护盾在探询边界附近仍然准确」——但信息驱动的 RL 恰恰会被激励去**主动逼近认证边界**（那里故障最可观测、信息增益最大），而接触动力学的非光滑、摩擦滞后与 sim-to-real 失配也恰好在边界处最严重；一旦护盾模型失配，系统会把「高风险探询」误判为「安全且高信息」，从而在一次最“聪明”的实验里造成最严重的物理越界。

**次级风险与缓解**：
1. **护盾模型失配**：用无源性能量槽兜底 + 在线系统辨识 + 保守 `ε_tube`；护盾永远保留 `ε_margin`，不允许探询贴边。
2. **奖励黑客 / 伪探询**：只奖励认知不确定性（ensemble disagreement），用 decision-VOI 过滤无关熵；`probe_ineffective` 连续触发即降级。
3. **探询集中 / 峰值风险**：由引理 12，强制每步 `r_peak` 与 `CVaR_α` 约束，而非仅累计预算。
4. **样本效率与 sim-to-real**：域随机化 + 残差 RL + 离线 RL + 真实低风险探询数据；先用仿真学“何时探”，再在真实学“探多少”。
5. **人类不适 / 情绪操纵**：情绪只收紧预算（A97），探询意图可解释、用户可 veto；禁止用情绪信号作为放宽硬约束的依据。
6. **认证边界利用**：把“动作距安全边界的裕度”本身计入成本，护盾保留保守内缩；OOD 时直接回退。
7. **活性 / 冻结**：零探针动作恒可行（A93），超时则升级到 RAS 安全策略或请求人类介入，避免“为了安全而永远不动”。

**与第 66 轮的最大风险对照**：RAS 怕「情绪被欺骗 → 放行真实故障」；APEX 怕「信息诱惑 → 主动贴近故障边界」。两者共同指向同一个教训：**任何把“观测”接入安全闭环的机制，都必须为观测本身设安全预算。**
