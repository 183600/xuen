# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「泛化能力」×「力觉传感」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据承诺"，再换到"元先验+共形保底"，纵深做到五层；但它的风险自陈暴露了一个更深的循环：**(a)** 元推断的效率来自"跨区域摊销"，而摊销本质是一次**外推**——它在语料覆盖的流形上便宜，在覆盖之外自信地错；OOD 门只能识别"看起来新"，识别不了"看起来旧但物理已变"（透明冰面、季节迁移、同材质不同含水量）；**(b)** 第 57 轮的全部证据仍以"外观/标签"为主，缺少一个**因果上更靠近失效本身**的观测量——接触会不会滑、会塌、会破，最终由接触力/力矩/滑移决定，而不由"看起来像什么"决定；**(c)** 于是"泛化能力"与"力觉传感"在本轮合成同一个问题：**泛化到底该在哪个坐标系里成立？** 本轮主张：泛化不应在像素/外观坐标系里声明，而应在**接触物理不变量坐标系**里声明——力觉给出"物理真值"的一阶近似，泛化契约只在被力觉锚定（或明确标为未锚定）的区域生效。核心命题由"少样本可校准、跨模态可对账"升级为 **"可泛化的证据承诺必须由物理不变量锚定：泛化有契约、锚定有象限、探询有信息、扩张有税"**。

核心矛盾：
- **H29（泛化 vs 锚定）**：泛化能力越强，越能在远离训练分布处仍给出高置信——而这正是最危险的区域；力觉想用物理不变量做锚，但不变量要在正确参照系（校准、接触几何、尺度）里被解释；若锚点本身偏了，泛化越强，错得越一致。
- **H30（力觉保真 vs 可及性）**：力觉是最接近因果的模态，却只能在**接触时**获得——获取物理真值的代价就是先承受一次接触风险；"先摸再走"与"不可逆接触安全"存在根本张力：要锚定就得接触，而接触可能已经不可逆。
- **H31（泛化红利 vs 泛化通胀）**：泛化能省探针（红利），但每次外推都在付"泛化税"（概念漂移界 δ_c）；若允许泛化账本自动扩张包络，就会泛化通胀——把"没验证过的同物理类"当成"已验证"，与第 57 轮"坏先验普遍"同构，只是换成了"坏包络普遍"。

## 0. 直觉与动机

**灵感 1（泛化能力 → 从泛化信念到泛化契约）**
直觉：第 57 轮的元先验像一位"见过很多表面"的老师傅，凭手感给你一个后验；但老师傅的自信没写清楚"我在什么范围内保证"。本轮把泛化从一种**信念**（我觉得它能迁移）改造成一份**契约**（在声明的分布族内、以声明的风险上界迁移）。契约三件套：**包络**（在哪些物理条件下保证）、**偏移分解**（新区域是"协变量变了/概念变了/标签先验变了"）、**违约处理**（概念变了就撤销授权，而不是调低置信）。一句话：**泛化不是"敢不敢推"，而是"推了之后谁负责、负多少责"。**

**灵感 2（力觉传感 → 物理不变量作为泛化的锚）**
直觉：视觉/外观是"表面"，接触力/力矩/滑移是"里子"。失效（打滑、塌陷、刺破、失稳）的因果链末端几乎都经过接触力，因此**力觉是离失效最近的观测量**。把一次接触的力-位移曲线、切向/法向比、滑移起始、接触斑与压力中心提炼成物理不变量 ι，再比较"新区域的 ι 是否落在已知安全类的 ι 包络内"，就得到一个不依赖外观的泛化判据。关键是不对称：**力觉可以"否决"视觉的泛化（看起来像、摸起来不像），但不能单独"批准"不可逆接触**（一个接触斑不代表整个区域）。

**灵感 3（泛化 × 力觉 → 四象限锚定检验）**
直觉：把"外观判定 a_v"与"力觉归属 a_h"交叉，得到四种情况：Q1 外观与物理都说是同类 → 授权泛化；Q2 外观说是、物理说不是 → **伪相似**（第 57 轮元先验最容易踩的坑），立即撤销；Q3 外观说不是、物理说是 → **隐性同类**，这是泛化红利的主战场，可给有界信用、省探针；Q4 两者都说不是 → 真新颖，退共形带/绕行。第 57 轮只有 a_v，本轮补上 a_h，于是"看起来新"不再等于"物理新"，"看起来旧"也不再等于"物理旧"。

**灵感 4（力觉探询 → 探针是物理实验，不是被动采样）**
直觉：触觉探针可以主动设计——法向刚度斜坡测 k_n，切向微滑移测摩擦锥，压力中心扫描测稳定边界。这是一个**干预** do(u)，不是观察；干预能识别"物理不变量"而不只是"相关外观"。于是探询目标从"减少标签熵"升级为"最大化安全谓词的不确定性下降"，且必须在**非破坏力预算**（法向力、能量、剪切）内做，形成"信息增益 − 接触风险 − 时间"的净收益。

**灵感 5（合流 → 泛化感知证据门与泛化账本）**
直觉：第 57 轮证据门 EV-* 只看"证据是否够强"，本轮再加一维"证据来自多可信的泛化"。同一份 EV-probe，在 G2（已锚定）区域是全额证据，在 G1（力觉许可但外观不一致）区域要打折并加佐证，在 G0（未锚定）区域不能进不可逆接触。泛化红利（省下的探针）与泛化税（δ_c 风险）必须记账：**只有红利折价 > 税时才授权外推**。包络扩张只能靠独立力觉验证且有速率上限——防"泛化通胀"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（接触物理不变量 TPI）** 一次接触片段 e=(u_{1:T}, w_{1:T})，w=(f_n,f_t,τ,CoP,A_c,slip)。不变量提取 ι=Φ(e)=(k_n, μ_eq, s_slip, A_eff, h_dis, κ_an)∈ℝ^d：法向接触刚度 k_n=∂f_n/∂δ；等效摩擦 μ_eq=‖f_t‖/f_n 及其锥角；滑移起始指标 s_slip；有效接触面积 A_eff 与压力中心 CoP；耗散滞回比 h_dis；接触各向异性 κ_an。传感器操作系统 Ω_s，含饱和/遮挡指示 o_occ。误差模型 ι̂=ι+b_cal(t)+b_geo(u)+ε，|ε|≤ε_max，b_cal 慢变，须由**校准见证** c(t)（参照面集合上的已知不变量）持续标定；o_occ 或饱和 ⇒ ι̂ 不可用于锚定。

**定义 140（泛化包络与偏移分解 GED）** 泛化包络 ℰ={(z,ι,c)}，z 为上下文（坡度/材质簇/季节/载荷），c 为安全类。**声明式泛化契约**：对歧义分布族 𝒫(ℰ,δ_env)，要求 sup_{P∈𝒫} R_P(π) ≤ R̂_ℰ + rad(ℰ,n,η)（PAC-Bayes 或一致收敛取其一），即"在该族内、以 1−η 概率、期望风险不超过该上界"。偏移分解 σ(r)=(σ_cov,σ_con,σ_lab)：σ_cov=d(p̂(z),p_src(z)) 外观/上下文偏移；σ_con=d_M(ι̂(r),ℰ_c) 概念偏移（观测到的物理响应与类条件不变量模型的距离）；σ_lab=同类不变量下结果先验的变化。泛化许可 g(r)∈{G2,G1,G0}：G2 ⇔ a_v=c ∧ ι̂∈ℰ_c ∧ σ_con≤θ_con；G1 ⇔ σ_con≤θ_con ∧ a_v≠c（力觉许可、外观不一致）；G0 ⇔ σ_con>θ_con ∨ ι̂∉∪ℰ_c ∨ o_occ。

**定义 141（力觉锚定泛化检验 HAG）** 外观判定 a_v(r)∈C∪{⊥}，力觉归属 a_h(r)=argmin_c d_M(ι̂(r),ℰ_c) 若 ≤θ_env 否则 ⊥。四象限裁决：
- Q1（a_v=c ∧ a_h=c）：**锚定确认** → G2；
- Q2（a_v=c ∧ (a_h=⊥ ∨ a_h≠c)）：**伪相似** → G0 并触发撤销，这是第 57 轮"视觉元先验"最易漏的一类；
- Q3（a_v=⊥ ∧ a_h=c）：**隐性同类** → G1（有界信用，可省探针，不得单独授权不可逆接触）；
- Q4（a_v=⊥ ∧ a_h=⊥）：**真新颖** → G0，退共形带或绕行。

非对称授权约束：G2 可进 L1/L2；G1 仅进 L1 且须一次独立佐证并付泛化税；L2（不可逆）只接受 G2，或"新颖受限探针路径"（定义 142）后的显式人工确认。

**定义 142（信息导向触觉探询 ITE）** 探针策略 u∈U 受非破坏预算：‖f_n(t)‖∞≤F_abs、∫|f·ẋ|dt≤E_abs、‖f_t‖∞≤F_shear、接触时长≤τ_c。干预信息增益 IGE(u)=I(S; w_{1:T} | do(u), h)，S 为安全谓词（滑/塌/破/稳）。探针选择 u\*=argmax_{u∈U}[IGE(u)−λ_r·risk(u)−λ_t·time(u)]，仅在净收益≥θ_probe 时执行。三种规范探针：**刚度斜坡**（估 k_n）、**微滑移测试**（估 μ_eq 与 s_slip，剪切受限不触发宏观滑移）、**压力中心扫描**（估 A_eff 与稳定边界）。输出**锚定证书** anc(e)=(ι̂,置信集,o_occ,c(t))，只有 anc 有效才允许用于 g(r) 判定。

**定义 143（泛化感知证据门 GAE 与泛化账本 GLD）** 在第 57 轮五类证据上，为每类证据 e 与接触级别 L 定义最低许可 g_min(e,L)：EV-probe\*/EV-margin 需 G1+；EV-xmodal 仅 L1 且需 G1+；EV-human 需 G1+ 且佐证数按 auth；L2 需 G2（或定义 142 的新颖受限探针 + 人工确认）。承诺条件由 "R≤δ_f ∧ 证据门过" 升级为 "R≤δ_f(g) ∧ 证据门过 ∧ g(r)≥g_min"。**泛化账本** GLD 记录 (r,ι̂,c,g,verdict,c(t))；包络扩张算子 ⊕ 仅在 n_indep 次独立力觉验证且留出交叉检验通过后生效，扩张速率 ≤Δ_ℰ/T；任一证伪事件回溯收缩包络并**连带降级**依赖该包络的历史许可（第 57 轮 ρ 回溯的"包络版"）。**泛化红利/税**：红利 Δn_probe（省下的探针数），税 tax=δ_c(g)（写入风险预算的概念漂移界）；仅当红利折价 > 税时才授权外推。

**定义 144（守恒泛化算子 PCE++）** 每检查点：⓪ 提取力觉不变量 ι̂（无接触则用先验 ι 及其不确定集）；① 偏移分解 σ(r)；② 四象限锚定 → g(r)；③ 若 G2：正常跑证据门；若 G1：仅 L1，打税并加一次独立佐证；若 G0：优先信息导向探针补锚，探尽→绕行→降档→L2 人工；④ 承诺后把 verdict 与 anc 写入 GLD，按 ⊕ 规则保守扩张包络；⑤ 任一证伪立即回溯收缩并重算未决承诺。

## 2. 关键算法伪代码（完整版见产物区）

```python
def haptic_anchor(M, r, e, tpi):                       # IP-139/140/141
    i_hat, occ, cal = tpi.extract(e)                   # 不变量+遮挡+校准见证
    a_h = tpi.classify(i_hat, M.envelope) if not occ else None
    a_v = M.visual_class(r)
    if a_v and a_h == a_v:      return 'G2', i_hat     # Q1 锚定确认
    if a_v and a_h != a_v:      return 'G0', i_hat     # Q2 伪相似→撤销
    if a_h and not a_v:         return 'G1', i_hat     # Q3 隐性同类
    return 'G0', i_hat                                 # Q4 真新颖

def choose_probe(cp, M, F_abs, E_abs):                 # IP-142
    cands = [u for u in probe_primitives(cp) if within_budget(u, F_abs, E_abs)]
    return max(cands, key=lambda u: ige(u, M) - lam_r*risk(u) - lam_t*time(u),
               default=None)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TPI | O(T·d)/接触片段；标定 O(N_cal) | O(d)/片段 | 遮挡/饱和即弃、b_cal 受见证约束 |
| GED | O(\|C\|·d)/区域 | O(\|ℰ\|) | 包络声明诚实、σ_con 距离保守 |
| HAG | O(\|C\|·d) | O(1) | Q2 必撤、G1 不得单独授权 L2 |
| ITE | O(\|U\|·(IGE+cost)) | O(\|U\|) | 非破坏预算硬约束、净收益门 |
| GAE | O(\|σ\|) | O(\|GLD\|) | 许可不足即拒、税入风险预算 |
| PCE++ | 同 PCE+ 加 O(\|CP\|·(\|C\|·d+\|U\|)) | O(\|V\|+\|GLD\|) | 锚定先于承诺、证伪即收缩 |

**正确性定理（Generalization-Anchored Soundness, GAS 概要）**：在 A33–A40 上加 (A41) 力觉不变量估计在 δ_h 内且有有效校准见证，遮挡/饱和被正确标记；(A42) 包络声音性：每类真不变量落入 ℰ_c 的概率 ≥1−α_env，且 |b_cal|≤b_max；(A43) 许可单调性：许可只经"不变量归属+独立佐证"授予、撤销实时，任何外推都在风险预算中付 δ_c 税；(A44) 账本扩张需独立验证且速率有界。则：
(i) **伪相似健全性**：Q2 承诺被拒；残余失效仅当力觉未能检出概念偏移，概率 ≤α_env+δ_h+δ_sensor；
(ii) **隐性同类外推**：Q3 的概念漂移 ≤δ_c（概率 ≥1−α_env−δ_h），且永不单独授权不可逆接触；
(iii) **泛化单调性**：许可变化只经"省探针（效率）"或"更严的门/更高的税（保守）"起作用；包络声音时无升险通道；
(iv) **终止性**：每检查点新增触觉探针 ≤k_tac，PCE++ 在 k_probes+k_cons+k_tac 内终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：本轮把"泛化"从信念改造成以力觉不变量为锚的契约，风险也随之从"坏先验普遍"变成"**坏锚点普遍**"——若力觉存在未被见证捕获的系统性校准偏差（温漂、软传感器滞回、探头磨损），所有不变量会共享同一偏差，包络在内部完全自洽却在外部整体错误，而强泛化能力会把这种错误高效地从一个区域复制到所有"物理上被判为同类"的区域，形成比第 57 轮更难察觉的一致性失效；必须以校准见证、尺度无关不变量、多传感器冗余与"力觉不得单独授权不可逆接触"四重护栏把锚点偏差关在可检测范围内，宁可放弃泛化红利，也不让一个自洽的错锚点统治整张地图。

## 2. 关键算法伪代码

### IP-139 TPI（接触物理不变量提取与校准见证）

```python
def extract_invariants(e, sensor, cal):
    w, u = e.wrench, e.motion
    if sensor.saturated(w) or sensor.occluded(e):          # 饱和/遮挡 → 不可锚定
        return Inv(valid=False, occ=True)
    k_n    = regress_slope(w.f_n, u.delta)                 # 法向接触刚度 ∂f_n/∂δ
    mu_eq  = quantile(norm(w.f_t) / max(w.f_n, eps), 0.9)  # 等效摩擦
    s_slip = slip_onset(w.f_t, w.v_t)                      # 滑移起始指标
    A_eff, CoP = contact_patch(w.pressure)                 # 有效接触斑与压力中心
    h_dis  = hysteresis(w.f_n, u.delta)                    # 耗散滞回比
    i_hat  = vector(k_n, mu_eq, s_slip, A_eff, CoP, h_dis)
    return Inv(valid=True, i=i_hat, b_cal=cal.bias(e.t),
               b_geo=geom_bias(e.pose), eps=eps_max)
```

### IP-140/141 GED + HAG（泛化许可与四象限锚定）

```python
def generalization_license(r, i_hat, M, env):
    if not i_hat.valid:
        return 'G0', ('sensor_invalid',)
    a_h = env.nearest_class(i_hat, tol=theta_env)          # 力觉归属；超界为 None
    a_v = M.visual_class(r)                                # 外观判定
    sig_con = env.mahal(i_hat, a_h) if a_h else float('inf')
    if a_v and a_h == a_v and sig_con <= theta_con:
        return 'G2', ('anchored', a_v, sig_con)            # Q1 锚定确认
    if a_v and (a_h is None or a_h != a_v):
        return 'G0', ('spurious_similarity', a_v, a_h)     # Q2 伪相似 → 撤销
    if a_h and not a_v and sig_con <= theta_con:
        return 'G1', ('hidden_equivalent', a_h, sig_con)   # Q3 隐性同类 → 有界信用
    return 'G0', ('novel', a_v, a_h)                       # Q4 真新颖
```

### IP-142 ITE（信息导向触觉探询）

```python
def tactile_probe_value(u, cp, M, i_prior):
    ig = mutual_info_safety(u, M, i_prior)                 # I(S;W|do(u),h)
    return ig - lam_r * contact_risk(u, cp) - lam_t * duration(u)

def choose_tactile_probe(cp, M, i_prior):
    U = [u for u in TACTILE_PRIMITIVES(cp)                 # 刚度斜坡/微滑移/CoP 扫描
         if norm_inf(u.f_n) <= F_ABS and energy(u) <= E_ABS
         and norm_inf(u.f_t) <= F_SHEAR and dur(u) <= TAU_C]
    u_star = max(U, key=lambda u: tactile_probe_value(u, cp, M, i_prior),
                 default=None)
    if u_star is None or tactile_probe_value(u_star, cp, M, i_prior) < theta_probe:
        return None
    return u_star
```

### IP-143 GAE / GLD（泛化感知证据门与泛化账本）

```python
G_MIN = {('EV-probe*','L1'): 'G1', ('EV-probe*','L2'): 'G2',
         ('EV-margin','L2'): 'G2', ('EV-xmodal','L1'): 'G1',
         ('EV-visit','L1'): 'G1',  ('EV-human','L2'): 'G2'}
RANK  = {'G0': 0, 'G1': 1, 'G2': 2}

def generalization_aware_gate(c, g, M, persona):
    need = G_MIN.get((c.ev, c.level), 'G2')
    if RANK[g] < RANK[need]:
        return ('reject', 'license_insufficient', g)
    if g == 'G1' and c.level == 'L2':
        return ('reject', 'haptic_only_on_irreversible', g)  # 硬禁令：力觉不得单独授权
    if g == 'G1':
        tax = delta_c(g)                                     # 泛化税进风险预算
        if c.risk + tax > delta_f(c.gait):
            return ('reject', 'generalization_tax', tax)
        if not c.independent_corroboration:
            return ('reject', 'need_corroboration')
    return round57_gate(c, M, persona)                       # 第 57 轮五类证据门

def ledger_update(GLD, r, i_hat, g, verdict, cal):
    GLD.append((r, i_hat, g, verdict, cal))
    if verdict == 'falsified':                               # 证伪 → 回溯收缩
        GLD.shrink_from(r)
        for entry in GLD.dependent_on(r):
            demote_license(entry); entry.g = min(entry.g, 'G0')
    elif verdict == 'confirmed' and GLD.n_indep(r) >= N_INDEP:
        if rate_ok(GLD) and holdout_ok(GLD, r):
            GLD.envelope = GLD.envelope + expand(r, i_hat)   # 保守扩张 ⊕
    return GLD
```

### IP-144 PCE++（守恒泛化算子）

```python
def probe_commit_evolve_pp(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        i_hat = extract_invariants(M.last_contact.get(cp.region), tpi, cal)
        g, why = generalization_license(cp.region, i_hat, M, M.envelope)
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while (g == 'G0' or select_gait(R) == 'halt') and budget.tactile_left > 0:
            u = choose_tactile_probe(cp, M, i_hat)
            if u is None: break
            e = execute_tactile(cp, u, cap=(F_ABS, E_ABS, F_SHEAR))
            i_hat = extract_invariants(e, tpi, cal)
            g, why = generalization_license(cp.region, i_hat, M, M.envelope)
            M, _, D = xmodal_fuse(M, cp.region, e)           # 第 57 轮继承
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend_tactile(u)
        if g != 'G0' and select_gait(R) != 'halt' and \
           generalization_aware_gate(core_contact(cp), g, M, personas)[0] == 'ok':
            sched.append(commit(sigma, select_gait(R))); log.append(why); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TPI | O(T·d)/片段；标定 O(N_cal) | O(d)/片段 | 遮挡/饱和即弃、b_cal 受见证约束（A41） |
| GED | O(\|C\|·d)/区域 | O(\|ℰ\|) | 包络声明诚实、σ_con 保守（A42） |
| HAG | O(\|C\|·d) | O(1) | Q2 必撤、G1 不得单独授权 L2（A43） |
| ITE | O(\|U\|·(IGE+cost)) | O(\|U\|) | 非破坏预算硬约束、净收益门 |
| GAE/GLD | O(\|σ\|) | O(\|GLD\|) | 许可不足即拒、税入预算、扩张有界（A44） |
| PCE++ | 同 PCE+ 加 O(\|CP\|·(\|C\|·d+\|U\|)) | O(\|V\|+\|GLD\|) | 锚定先于承诺、k_tac 终止 |

**正确性定理（Generalization-Anchored Soundness, GAS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 力觉不变量估计误差 ≤δ_h 且校准见证 c(t) 有效，遮挡/饱和被正确标记；**(A42)** 包络声音性：每类真不变量落入 ℰ_c 的概率 ≥1−α_env，且 |b_cal|≤b_max；**(A43)** 许可单调性：许可只经"不变量归属 + 独立佐证"授予、撤销实时，任何外推在风险预算中付 δ_c 税；**(A44)** 账本扩张需 n_indep 次独立验证且速率 ≤Δ_ℰ/T，证伪即时回溯。则：

1. **伪相似健全性**：Q2 承诺被拒；残余失效仅当力觉未检出概念偏移，概率 ≤α_env+δ_h+δ_sensor。
2. **隐性同类外推**：Q3 的概念漂移 ≤δ_c（概率 ≥1−α_env−δ_h），且永不单独授权不可逆接触。
3. **泛化单调性**：许可变化只经 (a) 省探针（效率）或 (b) 更严的门/更高的税/更大扩张约束（保守）影响系统；包络声音时不存在升险通道。
4. **终止性**：每检查点新增触觉探针 ≤k_tac，PCE++ 在 k_probes+k_cons+k_tac 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + α_env + δ_h + δ_sensor + δ_c·1[G1])
             − P(锚点系统性偏差未被见证检出)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**泛化给红利、锚定给定价**——每次外推都在风险预算里付 δ_c，锚定强度决定税的高低；**力觉是非对称锚**（能否决视觉、不能单独批准不可逆接触）；**触觉探询是干预而非采样**（识别物理不变量而非相关外观）；**包络只保守扩张、证伪即连带降级**（防泛化通胀）。三个新机制全部经"信念更准（含收缩）"或"动作更保守"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把"泛化"从信念改造成以力觉不变量为锚的契约，风险也随之从"坏先验普遍"变成"**坏锚点普遍**"——若力觉存在未被见证捕获的系统性校准偏差（温漂、软传感器滞回、探头磨损），所有不变量会共享同一偏差，包络在内部完全自洽却在外部整体错误，而强泛化能力会把这种错误高效地从一个区域复制到所有"物理上被判为同类"的区域，形成比第 57 轮更难察觉的一致性失效；必须以校准见证、尺度无关不变量（比值/对称性）、多传感器冗余与"力觉不得单独授权不可逆接触"四重护栏把锚点偏差关在可检测范围内，宁可放弃泛化红利，也不让一个自洽的错锚点统治整张地图。
