# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 2 轮；本轮灵感：「数字孪生」×「动作空间」）

> R73 用「证据契约 EC + 组合代数 CCA + 主张绑定 CPB」把具身系统重构为可组合的计量模块图，并把证明负担从「全系统审计」转移到「**契约的表达力**」。但 R73 的大厦立在两个从未被命名的隐含依赖上：
> - **预测源未审计（数字孪生缺口）**：R73 的 PVOP 用 χ_v **解析预测**「下一视角的期望不确定度」、ΣREFLEX 用 χ_R **预测**「动作如何调制噪声」、J_MOD 用契约**预测**「组合后的安全界」——三处都在用「一个关于自身感知过程的模型」做决策与认证。R73 从未把这个模型当证据来审计：它是「系统心里的世界」，没有类型、没有不确定度、没有追溯链。当这个模型被显式化为数字孪生（用于反事实 rollout、动作空间探索、稀缺场景离线标定），就暴露一个 R73 无法处理的新失效：**孪生与真实模块共享同一套物理假设，二者的「一致性」不是独立证据，而是同义反复**。而 R73 的 PAR 缩窄恰恰会把同义反复当成双源确认——这是 R73 最大风险（隐共享物理过程）的**自我指涉版本**。
> - **动作空间缺席（索引集未定义）**：R73 的 χ_R: 𝒢×X→Θ_noise 把动作 g 当自由变量，却从未定义 𝒢 的结构、可及性，以及在什么意义下两个动作「计量等价」。孪生让人可以在动作空间里自由「做实验」，但物理本体只能执行其中一部分；**孪生可模拟的动作 ≠ 本体能执行的动作 ≠ 对证据质量有影响的动作**。动作空间必须从优化器的隐式参数提升为**契约的一等索引**。
>
> 本轮两个灵感正好补这两块：
> - **数字孪生** → **DTEM + RGM + CGCA**：把孪生降格为「一个带保真度契约的生成式证据模块」，现实间隙六分量可计量；组合代数升级为**溯源感知组合**，给出**非双重计数定理**（共享溯源类 κ 的 N 个模块融合后不确定度不得低于 κ-条件不确定度）——这是对 R73 PAR 缩窄的硬下界，也是对「用孪生验证孪生」的结构性禁令。
> - **动作空间** → **AQX（计量动作商）+ ASA（动作空间充分性）**：在动作空间上定义「计量等价」~_ε，商掉对证据质量不可分辨的动作；PVOP/ΣREFLEX 只在商空间上求值；孪生只需在商空间上保真。给出**动作空间混叠**这一新失效模式：抽象把证据相关方向压塌 ⇒ 系统以为自己能主动感知，其实动作早已在计量上重合。
>
> 核心命题：**不再问「证据计量能否组合」，而问「当系统用一个可仿真自身感知的孪生来规划与认证时，如何防止孪生的假设冒充世界的真相——并让『预测』成为可审计、不可自我确认、按动作商索引的证据源？」** 把 R73 的计量契约代数升级为 **TWINGAUGE-RAS**（Twin-indexed, provenance-aware metrology with GAUGE audits for RAS）——**孪生索引的溯源计量**。

## 0. 直觉与动机

**灵感 1（数字孪生 → 孪生是「生成式证据模块」，不是神谕）**
直觉：数字孪生最常见的误用是把它当成 ground truth 的廉价替代：在仿真里跑一万次，就「知道」真实系统的行为。但对计量审计而言，孪生恰恰是最危险的一类证据——它是**生成式**的（能凭空造出观测）、**因果耦合**的（与真实模块共享物理模型/参数/标定）、且**自洽**的（它和它自己总是一致）。R73 的跨模态一致性审计在这里会给出最坏结果：真实观测与孪生预测几乎总落在同一个 conformal 集里，因为二者由同一模型生成；于是 PAR 缩窄不确定度，系统极其自信地「确认」了一个由自己假设造出来的世界。
正确抽象：孪生是一个**生成式证据模块 DTEM**，其证据是「在假设模型 M_θ 下，动作 g 会产生什么观测」；它必须声明**保真度契约 FC**（结构误差、参数误差、同步延迟、动作错配、传感器模型误差、未建模现象六分量），必须声明**溯源类 κ**（与哪些真实模块共享哪些机制），且**默认不独立**。孪生的价值不在「多一个独立证据源」，而在**反事实覆盖**：它能评估本体从未执行、也无法廉价执行的动作（动作空间扩展），能生成稀缺场景（透明/镜面/接触形变）用于离线标定。它可**加速**标定与规划，但绝不能**降低**已认证的不确定度地板。

**灵感 2（动作空间 → 证据通道的索引集与计量商）**
直觉：主动感知的全部前提是「不同动作 ⇒ 不同证据质量」。若两个动作在证据通道下不可分辨（对某深度模块，绕目标转 5° 与转 6° 的噪声调制在 ε 内相同），规划器在二者间的选择就是**计量噪声**，不是信息增益。R73 把 χ_R 定义在连续动作空间上，导致 PVOP 在大部分方向「平坦」的空间里做昂贵优化，且无法回答「我的动作空间是否丰富到足以实现所需感知」。
正确抽象：用证据通道把动作空间**商掉**：g₁ ~_ε g₂ ⇔ d_Θ(χ_R(g₁), χ_R(g₂)) ≤ ε，距离定义在（噪声参数，有效域半径）上。商空间 𝒢_ε = 𝒢/~_ε 是**计量可分辨动作空间**。三个直接收益：(i) 复杂度从动作维数降为商类数；(ii) 孪生只需在商空间上保真，动作空间错配 u_action 有了严格定义域；(iii) 可定义**动作空间充分性 ASA**：真实动作空间里每个证据相关方向是否在商空间中被保留。ASA 失败 = **动作空间混叠**——系统宣称能主动感知，实际动作在计量上重合，这比「规划器次优」更根本。
孪生在这里是双刃剑：它让我们能在商空间里「预演」每个类的证据质量（离线构造证据景观），也可能让我们**只在孪生能模拟的动作子集里**做优化，从而把本体的真实动作空间悄悄缩成「孪生可及域」。

**灵感 3（溯源与自我确认 → 非双重计数）**
直觉：统计上，融合 N 个独立估计可把方差降到 1/N；但若它们共享一个偏差源，融合只会把**同一个偏差**用更小的误差棒表达出来。R73 已意识到「隐共享物理过程」，但只当作次级风险（用环境级共因传感器缓解）。孪生让这个风险变成**结构性**的：孪生的定义就是共享模型。因此需要一条**组合层硬约束**：对任意溯源类 κ，融合结果的 κ-条件不确定度不得低于 u_κ（所有共享 κ 的模块都无法消去的共同不确定度）。这不是「打个折扣」，而是给 PAR 缩窄设一个**不可越过的地板**。推论：**用孪生验证孪生不可能**——认证路径中若孪生某部分仅由它自身生成的数据校验，则这部分不贡献任何置信度（TCAA 分离原则）。

**灵感 4（孪生证书 → J_TWIN 与「预测即负债」）**
直觉：R73 的 J_MOD 认证的是「模块图在某时刻有效」。引入孪生后，系统大量依赖「预测」做决策（PVOP 预演、ΣREFLEX 预算、离线标定）。预测一旦失真，系统不是「算错一个数」，而是「在错误的世界模型上做了全局一致的优化」——所有局部证书都有效，整体却在优化一个幻影。因此孪生证书必须把**预测的可信度**显式记账：每条被孪生支撑的决策都要携带 gap 膨胀后的不确定度；孪生越被用于「减少真实观测」，其 gap 越应以**保守膨胀**方式进入下游 λ 与预算，而不是被当成免费信息。

**灵感 5（动作空间扩展的纪律）**
直觉：孪生最有价值的用法是**动作空间扩展**：在仿真里尝试本体做不到/不敢做的动作，发现「如果我能这样动，证据会好很多」，再反推本体的近似实现。但这引入「可及性幻觉」：孪生能做的动作，本体未必能做（关节限位、力矩饱和、碰撞、通信延迟）。因此扩展必须过三道闸：孪生可模拟（twin-feasible）→ 本体可执行（embodiment-feasible，REG 契约校验）→ 证据相关（metrologically-relevant，χ_R 非平凡）。三者交集才是**可部署动作空间** 𝒢_deploy，证书只在其上有效。

(vii) **非双重计数**：PAR 缩窄受 κ-条件下界 u_κ 约束（引理 39）；
(viii) **动作商完备**：χ_R 的定义域声明为商空间 𝒢_ε，证书只覆盖 𝒢_deploy（定义 388–389）；
(ix) **无自我确认**：孪生参与认证的任何组件必须有分离于该孪生的物理校验（定义 392）；
(x) **gap 膨胀单调**：孪生替代真实观测的比例越高，进入下游的不确定度膨胀越保守（引理 38）。

**定义 384（数字孪生证据模块 DTEM 与保真度契约 FC）** DTEM = (FC, M_θ, sync, impl, cert)：
- FC = (T_in, T_gen, 𝒰_gap, κ, 𝒢_twin, Δ_sync, seal_ref)：保真度契约；
- M_θ：参数化世界模型，输入（状态估计 ŝ，动作类 [g]）输出合成观测 ŷ 与模型不确定度 Σ_twin；
- κ：溯源类集合，声明 M_θ 与哪些真实模块共享哪些机制（如与 DPEM 共享针孔/立体几何，与 DMEM 共享刚体接触假设）；
- 𝒢_twin ⊆ 𝒢：孪生可模拟动作子集；
- Δ_sync：孪生状态与真实状态的同步容差；
- 𝒰_gap：现实间隙预算（定义 385）。
DTEM 输出证据必须携带 `synthetic=True` 与溯源账本（定义 398）。

**定义 385（现实间隙计量 RGM）** 孪生预测 ŷ 与真实观测 y 的差异分解为六分量：
Δ_twin² = u_model² + u_param² + u_sync² + u_action² + u_sensor² + u_unmodeled²，
- u_model：结构/渲染/物理保真误差（接触模型、透明折射、软体）；
- u_param：辨识参数误差（质量、摩擦、外参）；
- u_sync：状态同步滞后（用旧状态预测新观测）；
- u_action：动作空间错配（孪生执行的动作与本体实际动作之差，定义于商空间）；
- u_sensor：传感器模型误差（模型噪声分布与真实噪声分布之差）；
- u_unmodeled：未建模现象（软体形变、人、光场变化）。
每分量独立追溯；有效域 D_twin = {每个分量 < 阈值} ∧ {动作 ∈ 𝒢_twin}。**与 R73 深度六分量同构：两者都是「模式条件计量」，区别只在模式从（场景/材质）扩展到（模型/同步/动作）。**

**定义 386（溯源类与耦合关系）** 证据模块 i 携带溯源标签 κ_i = {(机制, 来源)}。「共享溯源」κ_i ∩ κ_j ≠ ∅ 表示二者无法被认为完全独立。孪生与真实感知模块典型共享 {几何模型, 相机模型, 外参标定}。**共享不确定度** u_κ = 所有继承 κ 的模块共同面对、无法通过融合消去的不确定度。

**定义 387（溯源感知组合代数 CGCA）** 在 R73 CCA 上：
- **SER†**：κ_out = κ_A ∪ κ_B；u_out ≥ u_A + L_B·u_A；且 u_out ≥ u_κ,out。
- **PAR†**：先做一致性审计，再算**有效独立度** ρ_eff = max(ρ̂_stat, ρ_κ)，其中 ρ_κ ∈ [0,1] 由共享溯源决定（κ 交集越大 ρ_κ 越接近 1）；缩窄仅当 conformal 通过且 ρ_eff < ρ_max，且**缩窄下界 u_out ≥ u_κ（非双重计数地板）**。
- **VETO†**：validity = validity_A ∧ validity_B，且合成证据**不得否决其自身溯源来源**（禁止 A ⊠ A′，当 A′ 由 A 生成）。
**非双重计数定理（引理 39）**：任意 PAR† 组合，若 A、B 共享溯源类 κ，则 u_out ≥ u_κ；特别地当 B = DTEM(A 的模型) 且 κ 完全共享时 ρ_eff = 1，融合不能降低任何不确定度（退化为 max）。系：**同义反复不是确认。**

**定义 388（计量动作商 AQX）** 在动作空间 𝒢 上定义 g₁ ~_ε g₂ ⇔ d_Θ(χ_R(g₁), χ_R(g₂)) ≤ ε，d_Θ 为（噪声参数，有效域半径）上的加权距离。商空间 𝒢_ε = 𝒢/~_ε 称**计量可分辨动作空间**；每个商类 [g] 携带证据梯度 ∇_g χ_R（类内代表）。**ASA（动作空间充分性）**：∀ 真实动作方向 v，若其诱导的证据 Fisher 信息 I_v > 0（对某被关注量证据相关），则 ∃ 商类 [g] 使 v 与 χ_R 类内梯度夹角 ≤ δ。ASA 失败称**动作空间混叠**。

**定义 389（可部署动作空间与信任域）** 𝒢_deploy = 𝒢_twin ∩ 𝒢_embodiment ∩ 𝒢_relevant，其中 𝒢_embodiment 由 REG 时序/力矩/碰撞契约给出，𝒢_relevant = {g : χ_R(g) ≠ 恒等}。证书只在 𝒢_deploy 上有效；投影算子 π_deploy: 𝒢_twin → 𝒢_deploy 的残差进入 u_action。

**定义 390（孪生同步与同步债）** 孪生状态更新 ŝ_twin ← sync(ŝ_real, Δ_sync)。同步债 Dsync(t) = ∫ w·|ŝ_twin − ŝ_real|（w 为影响量权重）的累积。Dsync 超预算 ⇒ 孪生 stub（定义 396），所有依赖孪生的预测失效并回退到 R73 解析 χ_R 保守界。

**定义 391（现实间隙膨胀的仿真到现实标定）** 若用孪生离线标定得到 u_twin-cal，则真实证书必须使用 u_real ≥ u_twin-cal ⊕ Δ_twin，⊕ 为保守膨胀算子（按分量上界相加，**非方差相加**）。孪生只能**加速**标定（更少真实样本），不能降低认证不确定度地板。系：**仿真不是免费的数据。**

**定义 392（反事实证据审计 TCAA 与分离原则）** TCAA 用孪生生成反事实观测 {ŷ(g) : g ∉ 已执行} 压力测试契约（离线、无风险）。**分离原则**：参与认证的孪生组件 c 必须存在物理校验集 V(c)，且 V(c) 的数据生成过程不经过 c（真实保留集、独立高保真测量、接触/本体外部基准）。否则 c 的「验证」不贡献置信度。**自我确认禁令**：若 c 仅由自身生成的证据校验，则 c 的贡献恒为 0。

**定义 393（孪生组合证书 J_TWIN）** J_TWIN = J_MOD† ⊗ (⊗_c J(DTEM_c)) ⊗ J_couple，J_couple 校验：溯源类声明完整、非双重计数地板生效、动作商覆盖 𝒢_deploy、gap 膨胀已进入 λ 与预算、每个认证用孪生组件有分离物理校验。Valid(J_TWIN) ⇒ Valid(J_MOD)（孪生置 stub 时严格退化为 R73）。

**定义 394（孪生威胁面 AIC-TWIN）** ℰ_twin = {孪生投毒（污染 M_θ 使预测偏向攻击者）、溯源洗白（把合成证据标注为独立）、动作空间收缩攻击（诱导系统只在孪生可及域优化）、同步劫持（延迟/篡改 sync 使孪生与真实错位）、gap 低估（系统性低估未建模现象）}。防线：溯源账本 + 非双重计数地板 + 分离物理校验 + Dsync 监控 + gap 保守膨胀 + 单源不定案。

**定义 395（C4 与绑定表扩展）** 新主张 **C4（孪生索引的溯源计量）**：显式声明孪生为生成式耦合证据、施加非双重计数地板与分离审计，相比（i）无孪生、（ii）朴素孪生独立融合，在**同标定预算**下获得更低规划后悔、更低过度自信率，且认证不确定度地板不被侵蚀。绑定 MB4/AB4。C1–C3 保持；孪生相关组件必须绑定 C4，否则为工程附件。

**定义 396（孪生 stub 与保守回退）** stub(DTEM)：合成证据 = ∅、u = Δ_twin 上界（不是 ∞，因为孪生失效时真实模块仍在）、κ = 全集、动作可及域 = 𝒢_embodiment，预测回退到 R73 解析 χ_R 保守界。**孪生 stub 不阻断真实模块**，只移除反事实收益。

**定义 397（复杂度结构上限）** |𝒢_ε| ≤ 256、孪生 rollout 深度 ≤ 3、|κ| ≤ 8、DTEM ≤ 4、组合深度 ≤ 4——全部为**商空间/图性质**，部署期校验、运行时增量维护。

**定义 398（孪生溯源账本）** 每条证据记录 provenance = (真实/合成, 生成链, 模型版本哈希, 共享 κ, 校验集引用)。任何进入下游 λ/预算的证据必须可追溯；账本是审计的不可否认日志（篡改即断链）。

**定义 399（严格包含）** TWINGAUGE 在 DTEM 置 stub、𝒢_ε = 𝒢（ε→0 无商化）、κ 全部声明为互不相交时，逐指令退化为 MODGAUGE-RAS；再退化到 R71/R68。安全侧只增不减。

## 2. 关键算法骨架

```python
# IP-302 DTEM：数字孪生证据模块（生成式 + 溯源 + 保真度契约）
@dataclass(frozen=True)
```

## 3. 推导

**引理 38（现实间隙膨胀的单调性）** ⊕ 按分量上界相加，故 Δ_twin 各分量非负 ⇒ u_real = u_twin-cal ⊕ Δ_twin ≥ u_twin-cal，且对孪生替代率单调不减；若用孪生替代 r 比例的真实观测，进入 λ 的膨胀项至少 r·Δ_twin。系：**孪生越多地替代观测，下游越保守——预测是负债而非资产。**

**引理 39（非双重计数：同义反复不是确认）** 设 A、B 共享溯源 κ，则二者的联合误差可写为「共享分量 e_κ + 各自独立分量」。共享分量无法通过任何加权融合消去，故任何融合估计的 κ-条件方差 ≥ Var(e_κ)，即 u_out ≥ u_κ。当 B 由 A 的模型生成（完全共享），独立分量为 0，方差下界恰为 Var(e_κ)，融合无增益（ρ_eff = 1，退化为 max）。系：**R73 的 PAR 缩窄必须加地板，否则孪生会把置信度凭空抬高。**

**引理 40（动作商充分性与混叠）** 若 χ_R 在商映射下保留所有证据相关方向的 Fisher 信息（ASA 成立），则在商空间上优化的证据收益与在原始空间上优化的差距 ≤ ε·L_χ；若 ASA 失败，则存在证据相关方向 v 被映射到零梯度类，规划器沿 v 的任何搜索都得到零增益，**动作信息不可达**。系：**混叠是一种「看不见的不可观测性」——不是缺传感器，而是缺动作区分度。**

**引理 41（分离审计的可靠性）** 若参与认证的组件 c 有独立于 c 的数据生成过程 V(c)，则对 c 的校验是有效的统计检验；若 V(c) 由 c 自身生成，则检验的零假设被数据生成过程本身满足，检验功效为 0（无法拒绝任何自洽模型）。系：**孪生可以审计别人，但不能审计自己共享的假设。**

**引理 42（孪生加速的收益上界）** 在固定认证不确定度地板 u_κ 下，孪生把「达到给定校准质量所需真实样本数」降低至多 (1 − r_cf) 倍（r_cf 为反事实覆盖比例），但认证不确定度不因样本减少而降低；收益只体现在真实交互成本与稀缺场景覆盖。系：**孪生的复利在「省真实交互」，不在「更确定」。**

**定理 30（TWINGAUGE 严格包含 MODGAUGE）** 在 A114–A116（保真度契约可估、非双重计数地板生效、分离校验可得）下：DTEM 置 stub、𝒢_ε = 𝒢、κ 声明为互不相交时，TWINGAUGE 逐指令退化为 MODGAUGE-RAS；再退化到 R71/R68。**安全侧只增不减**（孪生只可能因 u_κ 地板而更保守）。

**定理 31（孪生证书有效性 ⇒ 系统安全）** Valid(J_TWIN) ⇒ (i) 各模块 cert 有效；(ii) MReg 组合校验通过且 PAR† 受 u_κ 约束；(iii) gap 膨胀已进入 λ/预算；(iv) 认证用孪生组件有分离物理校验；(v) J_MOD 特例成立 ⇒ 物理执行风险 ≤ ε_mod + ε_gap（ε_gap 为**未建模现象**的相对界）。**证明重量落在「Δ_twin 六分量可估且不被系统性低估」与「分离校验确实独立」上。**

**定理 32（无自我确认）** 对任何仅使用孪生自身生成数据构造的认证路径，其可证明的风险界不优于「无该组件」；即自我确认组件的贡献严格为 0。故冗余的孪生自洽不构成额外置信度。系：**一致性不是独立性——这是 R73「隐共享物理过程」风险的最终回答。**

1. **gap 六分量不可辨识 / 相关** → 环境级独立 co-variate（温度/振动/光照）作第三方 VETO 输入；不可辨识时按上界而非点估计膨胀。

4. **孪生投毒/同步劫持** → 模型版本哈希 + 账本断链即 stub；sync 走独立通道与时间戳。

## 2. 形式化定义（要点版）

**定义 383（总览与十不变式）** R73 五不变式 + 溯源显式 / 非双重计数 / 动作商完备 / 无自我确认 / gap 膨胀单调。证书只覆盖 𝒢_deploy；合成证据不得计入独立性。

**定义 384（DTEM）** 孪生是生成式证据模块：M_θ 由（状态估计，动作类）生成合成观测 ŷ 与 Σ_twin；FC 声明 gap 预算、溯源类、孪生可及动作、同步容差；输出必带 synthetic 与 provenance。

**定义 385（RGM）** Δ_twin 六分量，各独立追溯；D_twin = 分量皆小于阈值 ∧ 动作 ∈ 𝒢_twin；失效即 stub。

**定义 386（溯源类）** κ_i 声明共享机制；κ_i ∩ κ_j ≠ ∅ ⇒ 不可视为完全独立；u_κ 为共享不确定度。

**定义 387（CGCA）** SER† 取 κ 并集且 u_out ≥ u_κ；PAR† 用 ρ_eff = max(统计相关, κ 相关) 且缩窄受 u_κ 地板约束；VETO† 非补偿且禁止自我否决。非双重计数定理见引理 39。

**定义 388（AQX / ASA）** 用 χ_R 把动作空间按 ε 量化成商类；ASA = 证据相关方向在商空间保留；ASA 失败 = 动作空间混叠。

**定义 389（𝒢_deploy）** 孪生可及 ∩ 本体可执行（REG 契约）∩ 证据相关；投影残差进 u_action，证书不越界。

**定义 390（同步债）** 加权状态偏差累积；超预算即孪生 stub，回退解析 χ_R 保守界。

**定义 391（gap 膨胀标定）** u_real ≥ u_twin-cal ⊕ Δ_twin，分量上界相加；孪生只加速标定，不降认证地板。

**定义 392（TCAA）** 反事实压力测试 + 分离原则；认证组件若仅由自身生成数据校验，贡献恒为 0。

**定义 393（J_TWIN）** J_MOD† ⊗ 孪生证书 ⊗ 耦合校验（溯源完整 / 非双重计数 / 动作覆盖 / gap 膨胀 / 分离校验）；Valid(J_TWIN) ⇒ Valid(J_MOD)。

**定义 394（AIC-TWIN）** 五类威胁；防线：账本 + 地板 + 分离校验 + Dsync 监控 + gap 膨胀 + 单源不定案。

**定义 395（C4）** 溯源孪生 vs 无孪生 vs 朴素独立融合：同标定预算下规划后悔更低、过度自信率更低，且认证地板不被侵蚀。绑定 MB4/AB4。

**定义 396（孪生 stub）** 合成证据 ∅、u = Δ_twin 上界、κ = 全集、动作域 = 𝒢_embodiment；不阻断真实模块，只移除反事实收益。

**定义 397（复杂度上限）** |𝒢_ε| ≤ 256、rollout 深度 ≤ 3、|κ| ≤ 8、DTEM ≤ 4、组合深度 ≤ 4——商空间/图性质，部署期校验。

**定义 398（溯源账本）** 每条证据记 (真实/合成, 生成链, 模型哈希, κ, 校验集)；账本哈希链，篡改即断链。

**定义 399（严格包含）** DTEM stub + ε→0 + κ 互不相交 ⇒ 逐指令退化为 MODGAUGE-RAS ⇒ R71/R68；安全侧只增不减。

```python
# IP-302 DTEM：数字孪生证据模块（生成式 + 溯源 + 保真度契约）
@dataclass(frozen=True)
class FidelityContract:
    kappa: FrozenSet[str]              # 溯源类：与真实模块共享的机制
    g_twin: Set[ActionClass]           # 孪生可模拟动作子集（商空间）
    gap_budget: Tuple[float, ...]      # RGM 六分量预算
    sync_tol: float; seal_ref: str

@dataclass
class DTEM:
    fc: FidelityContract; model: WorldModel; cert: Cert
    def generate(self, s_hat, g_class, state):
        y_hat, sigma = self.model.rollout(s_hat, g_class)      # 合成观测
        gap = self.rgm.estimate(state, g_class)                # 定义 385 六分量
        if not within(self.fc.gap_budget, gap): return stub(self)
        return Evidence(y=y_hat, synthetic=True, u=inflate(sigma, gap),  # 定义 391
                        kappa=self.fc.kappa, provenance=ledger.record(self, g_class))

# IP-303 RGM：现实间隙六分量
def reality_gap(state, g_class):
    return Gap(u_model=..., u_param=..., u_sync=...,
               u_action=project_residual(g_class),             # 𝒢_twin → 𝒢_deploy 残差
               u_sensor=..., u_unmodeled=...)

# IP-304 CGCA：溯源感知组合（非双重计数）
def compose_cgca(a, b, op):
    k_shared = a.kappa & b.kappa
    u_k = shared_uncertainty(k_shared)                         # 共享不确定度
    if op == 'PAR':
        r = cross_modal_residual(a, b)
        rho_eff = max(audit.estimate_corr(a, b), rho_from_kappa(k_shared))
        if audit.conformal_covers(r) and rho_eff < RHO_MAX:
            return fuse(a, b, rho_eff, floor=u_k)               # 地板：u_out >= u_k
        return Ev(u=max(a.u, b.u, u_k), veto={'PAR_AUDIT_FAIL'}, kappa=a.kappa | b.kappa)
    if op == 'SER':
        return Ev(u=max(a.u + lipschitz(b, a.u), u_k), kappa=a.kappa | b.kappa)
    if op == 'VETO':
        assert not b.generated_by(a)                            # 禁止自我否决
        return Ev(valid=a.valid and b.valid, kappa=a.kappa | b.kappa)

# IP-305 AQX：计量动作商 + 充分性检查
def build_action_quotient(chi_R, g_space, eps):
    classes = partition(g_space, key=lambda g: quantize(chi_R(g), eps))
    return Quotient(classes, grad_within_class=estimate_grad(chi_R, classes))

def action_sufficiency(quotient, relevant_dirs, delta):
    return all(any(angle(v, quotient.grad([g])) <= delta for g in quotient)
               for v in relevant_dirs)                          # False ⇒ 动作空间混叠

# IP-306 TCAA：反事实审计 + 分离原则
def counterfactual_audit(dtem, executed, contracts):
    verdicts = {g: contracts.check(dtem.generate(state, g, None))
                for g in dtem.fc.g_twin - executed}             # 离线压力测试
    for c in dtem.certified_parts:
        if not independent_validation(c): return False          # 自我确认禁令
    return all(verdicts.values())

# IP-307 TWINGAUGE 主闭环（在 R73 三域上加孪生索引）
def TWINGAUGE_round(M, obs, audio, tac_frame, depth_img):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    if M.clock.due_metric():
        b_t = M.bse.step_full(..., d_ev=d_ev, t_ev=t_ev)
        g_q = M.aqx.representative(b_t, M.ervoi.class_of(b_t))  # 商类代表
        y_hat = M.dtem.generate(b_t, g_q, M.state)              # 反事实预演
        U = fold([d_ev, t_ev, y_hat], compose_cgca)             # 溯源感知融合
        M.pvop = viewpoint_plan(b_t, M.aqx, U, M.risk_params)
        lam = embodied_risk_scale(U, gap_inflate(M.dtem, U), M.risk_params)
        if not M.twin.sync_ok(): M.dtem = stub(M.dtem)          # 同步债超限
        M.snapshot.write(b_t, U, M.dtem.status)
        M.mreg.audit(); M.ledger.verify()                       # 图 + 账本
    return control_step(M, lam), J_TWIN(M)

# IP-308 J_TWIN：孪生组合证书
def J_TWIN(M):
    return (J_MOD(M.mreg) and all(cert_valid(m) for m in M.dtems)
            and provenance_complete(M.ledger) and non_double_counting_ok(M.mreg)
            and action_coverage_ok(M.aqx, M.dtem, M.reg)
            and gap_inflated_in_lambda(M) and independent_validation_ok(M.dtem))
```

## 4. 推导

**引理 38（gap 膨胀单调）** Δ_twin 各分量非负 ⇒ u_real = u_twin-cal ⊕ Δ_twin ≥ u_twin-cal；孪生替代真实观测比例 r 越高，进入 λ 的膨胀项至少 r·Δ_twin。系：**孪生越多替代观测，下游越保守——预测是负债。**

**引理 39（非双重计数）** 共享 κ 的两模块联合误差 = 共享分量 e_κ + 独立分量；共享分量无法通过任何加权融合消去 ⇒ 融合估计 κ-条件方差 ≥ Var(e_κ) ⇒ u_out ≥ u_κ。完全共享时 ρ_eff=1，融合无增益（退化为 max）。系：**同义反复不是确认；R73 PAR 必须加地板。**

**引理 40（动作商充分性与混叠）** ASA 成立时，商空间优化与原始空间优化的证据收益差 ≤ ε·L_χ；ASA 失败时存在证据相关方向被压成零梯度类，沿其搜索恒得零增益。系：**混叠 = 看不见的不可观测性——不是缺传感器，而是缺动作区分度。**

**引理 41（分离审计可靠性）** V(c) 独立于 c 时校验为有效检验；V(c) 由 c 生成时零假设被数据生成过程满足，检验功效为 0。系：**孪生可审计别人，不能审计自己共享的假设。**

**引理 42（孪生加速上界）** 固定认证地板 u_κ 下，孪生把达到给定校准质量所需真实样本数降至至多 (1−r_cf) 倍，但认证不确定度不降；收益只在真实交互成本与稀缺覆盖。系：**孪生复利在省交互，不在更确定。**

**定理 30（严格包含）** A114–A116（保真度可估 / 非双重计数生效 / 分离校验可得）下，DTEM stub + ε→0 + κ 互不相交 ⇒ 逐指令退化为 MODGAUGE ⇒ R71/R68；安全侧只增不减。

**定理 31（孪生证书 ⇒ 系统安全）** Valid(J_TWIN) ⇒ 模块 cert 有效 ∧ MReg 校验通过且 PAR† 受 u_κ 约束 ∧ gap 膨胀进 λ/预算 ∧ 认证孪生组件有分离校验 ∧ J_MOD 特例成立 ⇒ 风险 ≤ ε_mod + ε_gap。**证明重量在「Δ_twin 不被系统性低估」与「分离校验确实独立」。**

**定理 32（无自我确认）** 仅用孪生自身生成数据构造的认证路径，可证风险界不优于「无该组件」；自我确认贡献严格为 0。系：**一致性不是独立性——R73「隐共享物理过程」风险的最终回答。**

## 7. 本轮最大风险

**一句话**：TWINGAUGE 把「预测」纳入审计，但审计有效性的最终落点是**现实间隙 Δ_twin 的可估性**——如果未建模现象（软体形变、人、光场/透明折射）与动作错配被系统性低估，系统会在「溯源账本完整、非双重计数地板生效、分离校验通过」的表象下，用一个局部校准良好但整体错位的孪生，**把认证不确定度地板悄悄压到真实 gap 之下**：所有日志都合规，而它正在一致地优化一个幻影世界。

次级风险与缓解：
1. **gap 六分量不可辨识 / 相关** → 环境级独立 co-variate 作第三方 VETO 输入；不可辨识时按上界而非点估计膨胀。
2. **溯源类声明不诚实（洗白）** → 账本哈希链 + 生成链强制记录 + 单源不定案；κ 声明与模型版本绑定的密封审计集。
3. **动作商 ε 选择** → ε 由 SEAL-Twin 校准而非手调；ASA 作部署期硬门槛，失败即拒绝宣称主动感知。
4. **孪生投毒 / 同步劫持** → 模型版本哈希 + 账本断链即 stub；sync 走独立通道与时间戳。
5. **分离校验样本不足** → 保留集最小规模预注册；不足则孪生组件降权为「仅工程附件」，不进核心认证。
6. **TwinBench 过拟合** → 密封保持集 + 预注册 + 三方复现；C4 只认预注册指标。
