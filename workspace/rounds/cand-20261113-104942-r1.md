# 第 66 轮（承接第 65 轮「VISTA 故障归因安全时序闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「具身智能」×「移动底盘」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险也很清楚：**VISTA 的归因依赖「故障属于有限假设集」与「视觉与几何的失效相互独立」；真实故障常是未知复合，且透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，于是 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统还因「已经归因」而更自信地继续执行。** 本轮不再增加一个外感知模态，而是换一个证据来源：**让机器人自己的身体成为第三条物理独立证据，并让移动底盘既是新的故障源、也是可安全约束的主动诊断执行器。** 本轮核心命题是：
>
> **把「外感知故障归因」升级为「具身故障归因」：用浮动基动力学、轮-地接触与全身运动学构造与视觉/几何错误结构不同的第三条可错证据；用底盘运动提供的外在激励，把「静态下不可辨识」变成「可设计激励下的可辨识」；同时把移动底盘引入的定位漂移、打滑、倾覆与接触耦合纳入全身安全包络，保证「动底盘去诊断」不会把可恢复的感知故障变成不可逆的物理摔倒。**

## 0. 直觉与动机

**灵感 1（具身智能 → 身体是第三条可错证据，而非新真值）**
直觉：第 65 轮的视觉与几何都是外感知，它们可能被同一个分布外物体同时骗过（透明、镜面、对抗纹理）。但机器人自己的身体不是这样工作的：如果物体真的被推动了，浮动基的广义动量、轮-地接触反力、质心/ZMP 必然留下痕迹；如果末端真的受力了，臂-基座的反作用与全身功率流也会不一致。**外感知可以共同失败，身体的物理一致性却具有不同的错误结构。** 因此身体可以提供「接触之外、视觉之外」的第三条证据。但必须同样诚实：身体模型本身也可能错（未建模负载、质心/惯量标定误差、柔性模态、地面打滑/坡度），所以 WBC 不是新的接地真值，而是**第三条可错证据**。关键从「该信谁」转为「**用不同错误结构去分离故障**」。

**灵感 2（具身智能 → 身体是假设生成器：不同故障随运动以不同方式缩放）**
直觉：VISTA 的阶段化签名只在「接触时间轴」上做文章，缺少「运动激励轴」。而不同故障对运动的响应完全不同：**F/T 偏置是常量，底盘静止时也在；本体/质心/惯量误差随加速度与角速度平方增长；轮地打滑与定位漂移随行驶距离累积；接触模型错只在加载后随法向力显现；视觉/几何错则随视点变化。** 这意味着「让底盘动起来」不是单纯换视角，而是在做**主动系统辨识**：静止时 H_force 与 H_body 的签名列共线、不可辨识；只要有一段受控的平移/旋转/微振，二者就会沿不同回归子空间分开。**移动性因此成为可辨识性设计资源。**

**灵感 3（移动底盘 → 移动性既是新故障源，也是探针和安全动作）**
直觉：底盘带来的第一个后果是新的故障源——轮式里程计漂移、轮地打滑、非完整约束、质心偏移/负载变化、倾覆、臂-基座动态耦合；第二个后果是新的探针——底盘可以平移/旋转制造运动视差、拉开安全距离、用惯性激励分离力偏置与本体误差；第三个后果是新的安全动作——不是只有「机械臂回退」，还可以「底盘后撤/锁定/换站位」。但底盘的运动常常是**不可逆或难以急停**的：制动距离、支撑多边形、打滑与倾覆阈值决定了「底盘版不可逆视界 m_b」。所以移动底盘必须同时进入**探针集合**与**安全证书**，而不能只当作一个更大的工作空间。

**灵感 4（三灵感合流 → EMBODY：Embodied Multi-channel Base-grounded fault attribution with whole-body safety envelope，具身多通道·底盘接地安全归因闭环）**
闭环：VISTA 的阶段化外感知签名 → 新增全身一致性证据 WBC → 底盘接地重锚定 BGE 与本体参数标定 → 8 类故障归因 E-FIR（新增 H_base 轮地/定位、H_body 本体模型）→ 归因模糊时用底盘运动探针 MBP（最大化故障假设互信息，受全身安全包络约束）→ 保接触底盘运动 CPBM 或底盘锁定 → 全身安全证书 BSC（ZMP/支撑多边形/打滑/非完整/定位协方差/制动距离）→ 认证底盘前缀 k*_b → RSC-B 只膨胀被归因的球 → WCV-B/CSP-B/AIC-B → J_embody。第 65 轮是「几何-技能-干扰-接触-归因」五层，EMBODY 再加一层「**身体/底盘**」，并让「运动」本身成为可辨识性变量。

**灵感 5（VISTA 组件的原位升级）**
- **VPG → VPG-W**：视觉前瞻接入全身运动预测，视点变化由底盘运动显式解释，避免把「底盘移动导致的视觉变化」误判为物体运动。
- **FIR → E-FIR**：签名从 15 维扩到「阶段 × 运动模式 × 证据」张量；假设集从 6 类扩到 8 类，新增 H_base 与 H_body；静止退化时显式输出「不可辨识」，不强行归因。
- **AFA → MBP**：探针集加入底盘动作（look/standoff/dither/perch/retreat/lock），优化目标仍是故障假设互信息，但约束变为全身安全包络 + 保接触条件。
- **CSC → BSC**：块级认证前缀扩为「臂前缀 k*_a + 底盘前缀 k*_b」，后者受 m_b 与支撑/打滑/制动约束。
- **RSC-V → RSC-B**：不确定半径拆为 r_geo / r_force / r_model / r_base / r_body，只膨胀被归因者；H_base 时先底盘锁定再重定位，H_body 时先做安全激励标定。
- **WCV-V → WCV-B**：搜索域增底盘位姿可行集 W_b、非完整约束与支撑多边形约束；定位协方差进入碰撞间隙。
- **CSP-V → CSP-B**：新增 `perch`（稳定站位）、`viewpoint`（可观测站位）、`retreat`（全身后撤）等底盘技能，技能绑定全身块签名分布。
- **AIC-V → AIC-B**：干扰集增轮地打滑、坡度/起伏、定位漂移、负载/质心变化、臂-基座耦合、底盘指令延迟、动态障碍与支撑多边形侵蚀。
- **J_vista → J_embody**：证书增 wbc_hash、body_schema_ver、base_pose_cov、zmp_margin、slip_margin、excitation_rank、κ_emb、k*_b、cpbm_flag、H_base/H_body 后验。

r_wbc = momentum_observer(pi, tau, q, qd, f_c_hat, K_o)

    a = mbp.choose(post, phi_hat, f_safe, contact, fragile)   # 底盘探针，受全身安全包络
else:
    balls, w_vis = rsc_b.directed_demote(h_star, balls, w_vis)

# CPBM：接触时底盘运动许可
if contact and not cpbm.feasible(a, contact_wrench, object_model, S_B):
    a = 'lock'; base_lock = True
base_prefix = bsc.certified_base_prefix(a, post, m_b, alpha_base)

# EMBODY：长预测、短执行（臂 + 底盘）
A_a = policy.propose_chunk(obs, H_a)

for s in range(min(k_a, base_prefix)):
    dispatch_arm(A_a[s]); dispatch_base(a[s])
    if whole_body_monitor(z_wbc, post).abort: break

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（运动激励下的具身可辨识性）**：若签名矩阵 S_wb 的列在至少一个动态模式（translate/rotate/dither）与一个静态模式上被同时激励，且 H_force 的常量列与 H_body 的加速度回归列不共线，则 rank(S_wb)=dim θ、J_emb≻0；Laplace 近似下归因错误率 ≤ exp(−n·κ_emb/2)。反之，若 M={static}，H_force 与 H_body 不可分，退化为 VISTA 的不可辨识。
- **引理 10（保接触底盘运动与前缀安全）**：若 CPBM 满足摩擦锥/法向力/形变约束，且 BSC 的离散 CBF h_B 在前缀内非负、k*_b≤m_b，则底盘前缀执行不引入新的打滑/倾覆/接触损伤，单块违反 𝒮_B 的概率 ≤ α_base+δ_fi+α_vis。
- **定理 9（EMBODY 端到端归因-安全）**：在 A94–A99 下，身体通道为外感知共因故障提供独立残差；H_base/H_body 可被运动缩放分离；归因确定时只膨胀正确球，归因模糊时底盘锁定并保守降级；Valid(J_embody) ⇒ 几何/力/模型/底盘/本体处置正确 ∧ 全身安全包络 ∧ 前缀安全 ∧ 证书链完整。
- **定理 10（移动性的诊断收益与安全代价）**：在线性高斯近似下，底盘动作 a 的期望信息增益 I(ℋ_B;ρ|a)≈½logdet(I+Σ_ρ⁻¹S(a)ᵀS(a))；静止动作的 S 秩亏，增益最低；动态动作提高秩，但受 𝒮_B 与 CPBM 压缩可行激励幅值。故最优策略是「**在安全包络内最大化激励秩，接触时退化为不接触/小加速度探针，否则锁定**」。
- **命题（身体不是新真值）**：若本体参数误差/未建模负载落在 r_body 内，则 WBC 的「独立证据」也被污染；此时 EMBODY 只能保证不静默接受，不能保证归因正确，必须显式 `ambiguous` 并降级。
- **实时性**：动量观测与全身安全包络在实时线程（目标 <0.3ms/1kHz）；阶段/模式判定 <0.05ms；BSC 早停 <0.03ms；WBC 特征压缩与语义流归因移出实时环，目标总实时预算 ≤3.0ms。

## 2. 形式化定义（完整版）

**定义 233（EMBODY 闭环）** EMBODY 是 VISTA 的「具身证据 + 移动激励 + 全身安全」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 WBC（全身一致性）、BGE（底盘接地重锚定）、E-FIR（具身故障归因）、MBP（底盘运动探针）、CPBM（保接触底盘运动）、BSC（全身安全证书），并原位升级 RSC-V→RSC-B、WCV-V→WCV-B、CSP-V→CSP-B、AIC-V→AIC-B、J_vista→J_embody。不变式：**全身动力学推断、本体参数标定、故障归因、底盘探针规划、证书构建只在语义流/低频线程；实时路径只做动量观测、全身安全包络监测、阶段/运动模式判定、前缀执行与早停，零学习写操作。**

**定义 234（浮动基全身观测与广义动量残差）** 机器人状态 q=(q_b,q_a)∈SE(3)×ℝ^{n_a}，浮动基动力学
M(q)q̈+C(q,q̇)q̇+g(q)=Sᵀτ+J_cᵀf_c+J_eᵀf_ext，
其中 f_c 为轮-地接触力、f_ext 为末端/环境外力。广义动量 π=M(q)q̇；动量观测器
r(t)=K_o[π(t)−π(0)−∫₀ᵗ(Sᵀτ+Cᵀq̇−g+r+J_cᵀf̂_c)ds]。
在模型精确时 r→J_eᵀf_ext + η_model，η_model 为未建模柔性/负载/摩擦。将 r 投影到基座通道与臂通道：
r_b=Π_b r，r_a=Π_a r；
二者对同一外力的估计差、以及由 r 反推的质心加速度/ZMP，构成全身动量残差。**关键：它不依赖视觉，也不依赖接触模型；但它依赖本体参数与轮-地接触模型，因此仍是可错证据。**

**定义 235（全身一致性证据 z_wbc）** z_wbc=[z_mom,z_zmp,z_kin,z_wheel,z_power]ᵀ∈ℝ⁵：
- z_mom=‖r_b−Π_b J_eᵀf̂_ext‖²_{Σ_mom⁻¹}：基座与臂对同一外力的估计差；
- z_zmp=‖ZMP_meas−ZMP_pred(r)‖²_{Σ_zmp⁻¹}：由动量反推的 ZMP 与足/轮支撑测量的一致性；
- z_kin=‖T_vis(t)−T_enc(t)‖²_{Σ_kin⁻¹}：视觉/相机链末端运动与编码器/IMU 运动学链的闭环残差；
- z_wheel=‖v_wheel−v_base‖²_{Σ_wheel⁻¹}+‖ω_imu−ω_odom‖²：轮速与底盘速度/航向的滑移与里程计一致性；
- z_power=|P_mech−P_act|²/σ_power²：机械功率与执行器功率的一致性（可选，低采样率）。
每项用 split-conformal 或 GMM 离线标定，只产生「身体不一致」证据，不产生物理真值。

**定义 236（底盘接地重锚定 BGE 与本体参数标定）** 轮-地接触是机器人少数「已知接触」：由重力方向、支撑平面与轮接触点构造 T_{G←B}；由轮速/IMU 估计底盘在接地平面上的运动。对本体参数 β（质量、质心、惯量、连杆），用回归
Y(q,q̇,q̈)β=τ+ε_β
在安全激励集上辨识。接地锚与 β 均可能被坡度、打滑、柔性、未建模负载污染，故仅作为先验/交叉验证，不得单独否决视觉或力觉；当 z_wbc 与 β 残差同时升高时，优先怀疑 H_body 或 H_base，而非直接相信身体。

**定义 237（具身故障假设集与 E-FIR）** ℋ_B={H0 健康, H_geo 几何幻觉, H_force F/T 偏置/漂移/饱和, H_model 接触模型错, H_vis 视觉错, H_policy 策略 OOD, H_base 底盘定位漂移/轮地打滑/非完整约束失效, H_body 本体模型错（质心/惯量/连杆/柔性/未建模负载）}。离线故障注入（仿真 + 真机标定台）拟合 p(ρ|H)（高斯混合/小归一化流），后验
P(H|ρ)=p(ρ|H)P(H)/Σ_{H'}p(ρ|H')P(H')。
若 max_H P(H|ρ)≥1−δ_fi 则定向处置；否则 `ambiguous` 并触发 MBP。**与第 65 轮不同：ambiguous 不再只是「探针」，而是允许底盘锁定与全身保守降级。**

**定义 238（激励条件化签名）** 接触阶段 P={approach,touch,load}，底盘运动模式 M={static,translate,rotate,dither}。每格证据
ρ_{p,m}=[ē_vis,ē_force,ē_torque,d̄_chunk,ū_chunk,z_wbc]ᵀ∈ℝ^{10}，
整块签名 ρ=vec(ρ_{p,m})∈ℝ^{120}。运动模式由底盘指令与轮速/IMU 实测共同标记；若指令为 translate 但 z_wheel 显示实际滑移/未动，则该格标记为 `excitation_invalid`，不进入可辨识性计算，避免「假激励」污染归因。

**定义 239（具身可辨识性）** 线性化 E[ρ|θ]=S_wbθ、ρ∼N(S_wbθ,Σ_ρ)，θ 为故障幅度。具身 Fisher 信息
J_emb=S_wbᵀΣ_ρ⁻¹S_wb。
θ 可辨识 ⇔ rank(S_wb)=dim θ；可辨识裕度 κ_emb=λ_min(J_emb)/λ_max(J_emb)。签名矩阵的关键列结构：
- **H_force**：常量偏置，在所有运动模式上近似同号、同幅，且不随加速度/距离变化；
- **H_body**：与加速度 q̈、角速度平方 q̇² 的回归子成正比，静态时只剩重力/质心常量项；
- **H_base**：随行驶距离、轮扭矩、滑移率累积，translate/rotate 模式显著；
- **H_model**：只在 load 段随法向力显现；
- **H_vis**：随视点/光照变化，rotate/look 模式显著，但不随轮扭矩变化；
- **H_geo**：在 approach/touch 出现视觉足迹/落点冲突，且不随加速度缩放；
- **H_policy**：只在 d_chunk/u_chunk 出现。
若 M={static}，H_force 与 H_body 的常量列共线，J_emb 奇异——这正是第 65 轮静态归因的隐藏退化。

**定义 240（全身安全包络）** 状态 x 的安全集
𝒮_B={d_zmp≥d_min；s_i≤s_max；a_lat≤μ_min g；|v|≤v_max,|ω|≤ω_max,|κ|≤κ_max；dist(机器人,障碍)≥r_safe+3√λ_max(Σ_b)；接触时 f_c∈FC(μ) 且 f_n≤f_safe}。
其中 d_zmp 为 ZMP 到支撑多边形边界的距离，s_i 为第 i 轮滑移率，Σ_b 为底盘定位协方差。由全力制动距离、通信/执行延迟与最坏打滑定义底盘不可逆视界
m_b=inf{t: 在全力制动+延迟下 x(t)∉𝒮_B 仍不可避免}。
m_b 与第 65 轮的臂端不可逆视界 m_a 分开计算，取联合前缀 k*≤min(m_a,m_b)。

**定义 241（底盘运动探针 MBP）** 底盘动作集 A_b={lock,look_left,look_right,standoff,dither,perch,retreat}。选择
a*=argmax_{a∈A_b} I(ℋ_B;ρ_new(a)|ρ)，
s.t. 预测轨迹 ∀t≤H_b 满足 𝒮_B；若末端在接触则满足 CPBM；易损物体禁用接触/大加速度探针；激励有效性需满足 z_wheel 阈值（防止原地打滑冒充激励）。即把第 65 轮「最大化故障假设互信息」扩展到**底盘自由度**：移动本身是诊断动作，但必须安全且真实发生。

**定义 242（保接触底盘运动 CPBM）** 末端与环境接触时，底盘加速度 a_b(t) 必须满足：
(i) 对夹持/接触物体的惯性力前馈补偿后，接触力仍在摩擦锥内且 f_n≤f_safe；
(ii) 物体预测形变≤ε_strain；
(iii) 接触点相对滑移≤δ_slip；
(iv) 底盘运动不使 ZMP 裕度低于 d_min。
形式化：存在前馈 f_ff=−m_obj a_b^ff 使 f_c+f_ff∈FC(μ)、‖f_c,n+f_ff,n‖≤f_safe，且 h_B(x_s)≥0。若不存在，强制 `base_lock=True`，仅允许臂端柔顺/回退；**不允许为了诊断而牺牲接触稳定性。**

**定义 243（全身/底盘安全证书 BSC）** 对臂前缀 k_a 与底盘前缀 k_b，在归因后验支持集 supp_δ(post) 上逐一验证 𝒮_B 的离散时间控制障碍函数
h_B(x_{s+1})≥(1−γ)h_B(x_s)，h_B(x_s)≥0，s≤k_b，
并用 conformal 选最大安全前缀 (k*_a,k*_b)，满足
P[∃s≤k_b: x_s∉𝒮_B]≤α_base，
k*_b≤m_b，k*_a≤m_a。执行器只执行到前缀即强制重规划/重归因；若 h_B 在第一步即不可行，输出 `base_lock + safe_idle`。

**定义 244（RSC-B 归因定向球校准）** 维护 r_geo,r_force,r_model,r_base,r_body 与视觉信任 w_vis。定向处置：
- H_geo：r_geo←min(r_max,κ_infl r_geo)，且要求 VCV 观测到接触斑落点/法向确实不符；
- H_force：r_force←min(r_max,κ_infl r_force)，零力窗重标定，**不降级几何**；
- H_model：r_model←min(r_max,κ_infl r_model)，切柔顺、扩大接触模型不确定集；
- H_base：r_base←min(r_max,κ_infl r_base)，先 `base_lock`，重定位/重标定后再解锁；
- H_body：r_body←min(r_max,κ_infl r_body)，在安全激励下重辨识 β，未收敛则保持保守；
- H_vis：w_vis←max(0,κ_vis w_vis)，VCV 降权，退回 F/T+WBC；
- H_policy：H←max(H_min,H/2)，k↓，强制重规划。
融合 r=√(r_geo²+r_force²+r_model²+r_base²+r_body²) 进 WCV-B。**绝不因 H_base/H_body 而盲目膨胀几何球。**

**定义 245（WCV-B 全身鲁棒编译）** 搜索域

class WholeBodyConsistency:
    """浮动基动量观测 + 全身一致性证据。实时只读传感器，不学习。"""
    def __init__(self, K_o, Sigma, model):
        self.K_o, self.Sigma, self.model = K_o, Sigma, model
        self.r = np.zeros(model.nv)

    def observe(self, q, qd, tau, f_c_hat, dt):
        M = self.model.M(q)
        pi = M @ qd
        C = self.model.C(q, qd)
        g = self.model.g(q)
        Jc = self.model.J_contact(q)
        integrand = tau + C.T @ qd - g + self.r + Jc.T @ f_c_hat
        self.r = self.K_o * (pi - self.pi0 - integrand * dt)
        self.pi0 = pi
        return self.r

    def evidence(self, r, q, qd, imu, wheels, encoders, vision_kin, power):
        r_b, r_a = project_base(r), project_arm(r)
        z_mom = mahalanobis(r_b - r_a, self.Sigma['mom'])
        z_zmp = mahalanobis(zmp_from_momentum(r, q, qd) - zmp_meas(imu, wheels),
                            self.Sigma['zmp'])
        z_kin = mahalanobis(vision_kin.end_effector - forward_kin(encoders),
                            self.Sigma['kin'])
        z_wheel = mahalanobis(wheels.v - imu.v_base, self.Sigma['wheel'])
        z_power = mahalanobis(power.mech - power.act, self.Sigma['power'])
        return np.array([z_mom, z_zmp, z_kin, z_wheel, z_power])

class EmbodiedFaultIsolation:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model',
           'H_vis', 'H_policy', 'H_base', 'H_body')

    def signature(self, phases, modes, valid):
        cells = []
        for p in ('approach', 'touch', 'load'):
            for m in ('static', 'translate', 'rotate', 'dither'):
                cells.append(modes[p][m] if valid[p][m] else np.zeros(10))
        return np.concatenate(cells)                      # R^120

    def attribute(self, rho):
        logp = {h: np.log(self.lik[h](rho) + 1e-12) + np.log(self.prior[h])
                for h in self.HYP}
        z = np.array(list(logp.values())); z -= z.max()
        post = {h: float(np.exp(v) / np.exp(z).sum()) for h, v in logp.items()}
        h_star = max(post, key=post.get)
        S = self.jacobian_at(rho)                         # 离线/在线线性化
        rank = np.linalg.matrix_rank(S @ self.Sigma_inv_sqrt())
        ambiguous = (post[h_star] < 1.0 - self.delta_fi) or (rank < self.d_req)
        return post, h_star, ambiguous

    def directed_demote(self, h_star, balls, w_vis, H):
        if h_star == 'H_geo':
            balls['r_geo'] = min(R_MAX, K_INFL * balls['r_geo'])
        elif h_star == 'H_force':
            balls['r_force'] = min(R_MAX, K_INFL * balls['r_force'])
            request_null_window_recalibration()
        elif h_star == 'H_model':
            balls['r_model'] = min(R_MAX, K_INFL * balls['r_model'])
            switch_compliant_control()
        elif h_star == 'H_base':
            balls['r_base'] = min(R_MAX, K_INFL * balls['r_base'])
            request_base_lock_and_relocalize()
        elif h_star == 'H_body':
            balls['r_body'] = min(R_MAX, K_INFL * balls['r_body'])
            request_safe_excitation_and_reidentify()
        elif h_star == 'H_vis':
            w_vis = max(0.0, K_VIS * w_vis)
        elif h_star == 'H_policy':
            H = max(H_MIN, H // 2)
        return balls, w_vis, H

class ContactPreservingBaseMotion:
    def feasible(self, base_traj, contact_wrench, object_model, S_B):
        for a_b in base_traj:
            f_ff = -object_model.mass * a_b                  # 惯性前馈
            f_c = contact_wrench + f_ff
            if not in_friction_cone(f_c, object_model.mu):
                return False
            if f_c.normal > object_model.f_safe:
                return False
            if object_model.strain(f_c) > EPS_STRAIN:
                return False
            if predicted_slip(f_c, base_traj) > DELTA_SLIP:
                return False
            if not invariant(base_traj, S_B):
                return False
        return True

    def execute_or_lock(self, a, contact_wrench, object_model, S_B):
        if not self.feasible(a, contact_wrench, object_model, S_B):
            return 'lock', True
        return a, False

## 4. 推导

**引理 9（运动激励下的具身可辨识性）** 设故障幅度 θ，线性化 E[ρ|θ]=S_wbθ、ρ∼N(S_wbθ,Σ_ρ)。则 J_emb=S_wbᵀΣ_ρ⁻¹S_wb，Laplace 后验协方差≈J_emb⁻¹；θ 可辨识 ⇔ rank(S_wb)=dim θ。把签名按运动模式分块，S_wb=[S_static;S_translate;S_rotate;S_dither]。对 H_force 与 H_body 两列：
- H_force 为常量偏置，其列在所有模式块上相同（c_force）；
- H_body 由动力学参数误差产生，其列在模式 m 上近似 Y(q̈_m,q̇_m²)β_err，静态时只剩重力常量项 c_body，动态时随加速度线性增长、随角速度平方增长。
若仅静态，c_force 与 c_body 同为常量，两列共线，J_emb 奇异；若至少一个动态模式被有效激励（excitation_valid=True），则 H_body 列出现与 a_b、ω² 成正比的非零分量，与 H_force 常量列线性无关。H_base 由行驶距离/轮扭矩累积，其列在 translate/rotate 块显著；H_vis 随视点变化但在 rotate 块与 H_base 的里程计列不同（前者不随轮速/IMU 滑移变化）；H_model 只在 load 块非零。故当静态 + 至少一个动态模式同时有效、且各块证据不退化时，S_wb 列满秩、J_emb≻0，κ_emb=λ_min/λ_max 由运动激励的信噪比与阶段对比度控制。Laplace 近似下归因后验错误率 ≤ exp(−n·κ_emb/2)。∎

**引理 10（保接触底盘运动与前缀安全）** 设 CPBM 对每个 s≤k_b 满足摩擦锥/法向力/形变/滑移约束，BSC 的离散 CBF 满足 h_B(x_{s+1})≥(1−γ)h_B(x_s)≥0，且 k_b≤m_b。由 CBF 前向不变性，x_s∈𝒮_B 对所有 s≤k_b 成立；由 k_b≤m_b，即使故障在块首激活，全力制动+延迟也能在越出 𝒮_B 前停下。对后验支持集外的假设，其总质量≤δ_fi；视觉 conformal 覆盖≥1−α_vis；故单块执行 k_b 步内违反 𝒮_B 的概率
P[违反]≤α_base+δ_fi+α_vis+α_geo。
由于 CPBM 已把接触力约束在摩擦锥/力限内，底盘运动不引入新的接触滑移/损伤。∎

**定理 9（EMBODY 端到端归因-安全）** 在 A94–A99 下：
1. **身体通道独立残差**：外感知共因故障（视觉+几何同时失效）不会自动传播到 WBC；若本体模型与轮-地接触在 r_body 内可信，则 z_wbc 提供非零独立残差，系统至少判 `ambiguous`，不静默接受。
2. **H_base/H_body 可分离**：在有效运动激励下，由引理 9，H_force（常量）、H_body（加速度缩放）、H_base（距离/扭矩缩放）列近正交，归因可分离；静止时显式秩亏、强制 ambiguous，不强行归类。
3. **归因确定时只膨胀正确球**：按定义 244，H_force 不降级几何、H_geo 不怀疑力传感器、H_base 先锁定再重定位、H_body 先安全再辨识。
4. **物理伤害受控**：MBP 禁用易损物体的接触/大加速度探针；CPBM 不可行则 base_lock；BSC 限制 k*_b≤m_b、k*_a≤m_a。
5. **优雅降级**：身体不可信→base_lock+保守本体模型；视觉失效→w_vis↓、退回 F/T+WBC；定位失效→base_lock+safe_idle；未知故障→ambiguous+保守联合膨胀；共因故障→base_lock+compliant retreat。
6. **证书六层链**：Valid(J_embody) ⇔ VISTA 有效 ∧ 全身安全包络 ∧（激励秩足够 ∨ 显式锁定）∧ 接触时 CPBM/锁定 ∧ 未把不可观测当不存在。
7. **实时性**：实时路径目标 ≤3.0ms，零学习写操作（A100）。∎

**定理 10（移动性的诊断收益与安全代价）** 在线性高斯近似下，给定当前后验 N(θ̂,Σ_θ)，底盘动作 a 产生新观测 ρ_new=S(a)θ+ε，ε∼N(0,Σ_ρ)。期望信息增益
I(ℋ_B;ρ_new|a)≈½logdet(I+Σ_ρ⁻¹S(a)ᵀΣ_θS(a))。
静止动作的 S(a) 秩亏（H_force/H_body 列共线），故增益低于任何能提高秩的动态动作；随激励幅值增大，S(a)ᵀS(a) 的特征值增大，增益单调上升。但可行激励受全身安全包络 𝒮_B 与 CPBM 约束：a∈A_safe={a: ∀t≤H_b, x(t)∈𝒮_B, 接触时 f_c∈FC(μ), f_n≤f_safe}。因此最优策略为
a*=argmax_{a∈A_safe} ½logdet(I+Σ_ρ⁻¹S(a)ᵀΣ_θS(a))，
接触时 A_safe 收缩，增益下降，系统应退化为「不接触/小加速度探针或锁定」；易损物体时 A_safe 进一步收缩到 look/standoff。**移动性是诊断资源，但其收益被安全包络严格定价。** ∎

**命题（身体不是新真值）** 设本体参数误差/未建模负载 η_body 落在 r_body 内，则 WBC 残差 r=J_eᵀf_ext+η_body。当 η_body 与真实故障同向时，E-FIR 可能把 H_body 误判为 H_force 或反向；此时 EMBODY 只保证「不静默接受 + 进入 ambiguous/保守」，不保证归因正确。若 r_body 无界或本体模型不可信，则必须 base_lock 并退回第 65 轮外感知归因 + 保守联合膨胀。∎

**命题（相对 VISTA 的过度保守降低）** 第 65 轮在 H_force 时仍可能因外感知共因而不确定，倾向膨胀几何球；EMBODY 在 WBC 排除 H_body、且运动激励分离 H_force 后，只膨胀 r_force，r_geo 不变。若真实故障为 H_force 而几何正确，EMBODY 的几何搜索域体积相对 VISTA 的联合膨胀缩小约 1/κ_infl^{d_φ}（几何分量），同时底盘保持锁定以保护接触。∎

## 5. 假设 A94–A100

- **A94（本体模型有界）**：浮动基动力学结构已知，未建模柔性/负载/摩擦有界，且可由 r_body 覆盖。
- **A95（接地可观测）**：轮-地接触/支撑多边形可观测，滑移率与坡度有界；否则 BGE 降权。
- **A96（定位有界漂移）**：底盘位姿协方差 Σ_b 可得，且在规划视界内漂移有界；否则 base_lock。
- **A97（激励可安全实施）**：存在满足 𝒮_B 的运动模式；若不存在，允许 base_locked_conservative 并接受秩亏。
- **A98（CPBM 可行性可判定）**：接触力/物体模型可预测；若不可判定，默认 base_lock。
- **A99（共因故障可判 ambiguous）**：未知复合故障可表现为后验不集中或 𝒮_B 边界，系统能进入 safe_idle。
- **A100（实时契约）**：动量观测、CBF 监测、前缀派发在实时线程；世界模型/归因/标定在语义流。

## 8. 已知风险

**一句话**：身体/底盘并不是独立于故障的真值——未建模负载、质心/地形误差与轮地打滑会让 WBC 与故障共享同一个模型误差源，而「动底盘去诊断」本身可能诱发打滑、倾覆或接触损伤，于是 EMBODY 可能把一次可恢复的感知故障升级为不可逆的物理摔倒，这是本轮「具身可辨识性 + 全身安全证书」共同依赖的隐藏假设（A94/A99）。

**次级风险与缓解**：
1. **本体模型误差成为新共因**：未建模负载/柔性会让 z_wbc 与真实故障同向；缓解：r_body 显式建模、AIC-B 含负载/柔性、本体不可信时 base_lock + 退回外感知。
2. **接地锚不可靠**：斜坡、软地、低摩擦会让 BGE 与轮速失真；缓解：坡度/滑移检测、Σ_b 膨胀、BGE 只作先验不作否决。
3. **激励与安全冲突**：大激励提高可辨识性但逼近倾覆/滑移边界；缓解：在 𝒮_B 内最大化激励秩，接触时 CPBM 或锁定，易损物体用 look/standoff。
4. **底盘不可逆失败**：倾覆/坠落比臂端误差严重得多；缓解：k*_b≤m_b、CBF 前向不变、制动距离+延迟计入 m_b、默认保守。
5. **CPBM 依赖物体模型**：质量/摩擦/形变未知时惯性前馈可能错；缓解：先视觉力代理估 m/k，未知则 base_lock，只做臂端柔顺。
6. **定位漂移无界**：长距离移动后 Σ_b 增大，碰撞间隙与可达性恶化；缓解：重定位、限制单块行驶距离、漂移超阈即锁定。
7. **E-FIR 维度与过拟合**：120 维签名 × 8 假设，小样本易过拟合；缓解：PCA/特征选择、分层先验、离线大规模故障注入、未知故障 OOD 检测。
8. **实时预算**：动量观测/CBF/WCV-B 叠加可能超 3ms；缓解：矩阵稀疏化、CBF 降采样、世界模型全留语义流、与 LSF 共享状态估计。
9. **共因故障仍可能骗过身体**：同一负载既改动力学又改视觉，且身体模型也错；缓解：只要求判 ambiguous + base_lock + compliant retreat，不要求归因正确。
