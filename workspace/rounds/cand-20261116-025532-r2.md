# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「阻抗控制」×「运动学」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**先补 v9 的两个结构洞，再谈新能力**。v9 有两条未闭合的债：(a) 块证书的全部可信度压在黑箱前向模型的误差界 β 上，而 β 在域偏移时最大；(b) 中块中止假设"总有一个运动学可行的停车点"，但在接触丰富任务里硬停本身可能制造力尖峰或不可行。运动学补 (a)，阻抗控制补 (b)；两者共用同一个置信度 s_t，单调地收块长、软阻抗。

## 0. 直觉与动机

**灵感 1（运动学 → 把证书拆成"精确骨架 + 有界残差"）**
直觉：v9 让一个学出来的 LSTM-MPC 去预测"块内最小间隙"，把几何问题也交给了学习。但间隙的**几何骨架**其实可以精确算：给定 URDF 与关节角 q，正运动学 FK 给出每根连杆位姿，碰撞几何之间的有符号距离是解析量（模型准确时误差为零）；速度由雅可比 J(q) 给出。真正学不准的只有接触、形变、摩擦这些**残差动力学**。核心创新：**运动学骨架证书器（KinematicSkeletonCertifier, KSC）**：ĝ = ĝ_kin(FK) + r̂(残差模型)，误差界从全局 β 收缩为残差界 β_r。额外收益：可操作度 μ(q)=√det(JJᵀ) 与最小奇异值 σ_min(J) 成为新的**预测量**——临近奇异位形时任何模型的预测都会爆，v9 的 β 假设恰在此处最脆弱，故用可操作度直接门控 K_eff 与阻抗刚度。

**灵感 2（阻抗控制 → 用被动性换掉"必须能停车"）**
直觉：v9 的安全兜底是"切到最近中止点刹停"。这在自由空间成立，但在接触/抓取里有两个问题：硬停需要运动学可行性（可能没有），且硬停会在接触点制造力尖峰。阻抗控制给了一个根本不同的兜底：不控制位置，而控制力-运动的动态关系 τ = M ẍ + D ẋ + K(x−x_d) + τ_g；**把刚度 K 单调降到 0 = 自由顺从**，此时机械臂不向环境注入能量（被动/耗散），接触力有界、永远可执行，不需要任何"停车点"。核心创新：**被动性阻抗退化器（PassivityImpedanceFilter, PIF）**：每个块携带阻抗包络 (M,D,K) 与能量罐 E_tank，守卫强制 E_tank ≥ 0；置信度下降时按**单调调度**把 K 从 K_nom 连续降到 0。零刚度 τ=0 就是阻抗域的中立元（"交出权限"），与 v9 的中立元契约中间件天然同构。

**两个灵感的合流**：它们共享一个标量置信度 s_t ∈ [0,1]。s_t ↓ ⇒ 同时**块更短**（K_eff ↓）且**更软**（K_stiff ↓），最坏 s_t=0 时 (K_eff=1, K_stiff=0) 恰是 v8 的逐步 + 顺从保持。v9 的"最需要安全时证书最不可靠"被拆成两半：几何那一半用运动学做成了零误差；剩下那一半即使错了，**顺从退化也不依赖证书正确**——被动性只依赖能量罐符号，不依赖预测精度。

## 1. 研究问题（轮次升级版）

- **Q1（运动学-残差分解）**：在什么条件下把前向证书拆成"解析 FK 骨架 + 有界残差"能把有效误差界从 β 收缩到 β_r ≤ β？域偏移是否主要作用于残差项、而几何项保持零误差？可操作度门控能否消除奇异位形处的预测爆差？
- **Q2（被动性阻抗退化）**：零刚度自由顺从是否构成合格的中立元——在重力补偿、关节限位、最小阻尼约束下被动、力有界且永远可行？它能否在不引入接触失稳的前提下替代"最近中止点"作为唯一兜底？
- **Q3（双门控单调性）**：是否存在置信度→(K_eff, K_stiff) 的单调调度，使"置信度下降 ⇒ 安全裕度不降"，且 s_t=0 时严格退化为 v8 的逐步顺从保持？能量罐与块证书如何共享预算而不互相饿死？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 运动学骨架分解律（Kinematic Skeleton Decomposition, KSC）**
证书拆为 ĝ_t = ĝ_kin(q, a^{1:K}) + r̂_t，其中 ĝ_kin 由 FK/雅可比解析计算（模型准确时几何误差为零），r̂ 只建模接触/形变/摩擦残差，误差界 β_r = sup_{U_t} ‖r̂ − r‖∞。证书的间隙判据改用 ĝ_kin + r̂ − β_r；可操作度 μ(q) < τ_μ 或 σ_min(J) < τ_σ 时块证书强制失效、K_eff ← 1。

**P14 被动性阻抗退化律（Passivity Impedance Degradation, PIF）**
每个块携带阻抗包络 Π_t=(M,D,K) 与能量罐 E_tank。守卫每周期更新 E_tank 并要求 E_tank ≥ 0；置信度 s_t 下降时按单调调度 K_stiff = K_nom·h(s_t)（h 非减，h(0)=0）连续软化，D 相应升高以维持耗散。K=0 的自由顺从（含重力补偿、关节限位、最小阻尼）是阻抗域中立元 v_Π^⊥，被动、力有界、永远可行。

**P15 双门控单调律（Dual-Gate Monotonicity, DG）**
单一置信度 s_t 同时驱动块长与刚度：K_eff(t)=1+⌊(K_max−1)·s_t⌋，K_stiff(t)=K_nom·h(s_t)。要求调度对 s_t 单调：s_t 下降时块长与刚度均不增；s_t=0 ⇒ (K_eff=1, K_stiff=0) = v8 逐步顺从保持。任何门控分支不得出现"块更长却更硬"或"更软却更短"的反向组合。

## 3. 与基线的接口（如何退化）

- KSC 失效（无 URDF / FK 不可用 / 残差模型缺失）⇒ 证书退回 v9 全局 β（ĝ 由 v9 前向模型直接给出），等价 v9 证书；
- PIF 失效（能量罐实现缺失 / 阻抗接口不可用）⇒ 退回 v9 的"最近中止点刹停"，等价 v9 兜底；
- 能量罐耗尽 ⇒ K_stiff ← 0（自由顺从，被动兜底），不 crash、不硬停；
- KSC 与 PIF 同时失效 ⇒ 完整退回 v9 ACMD；再按 v9 链退回 v8/v7/v6；
- 双门控 s_t=0 ⇒ 逐步执行 + 零刚度顺从保持，严格等价 v8 决策粒度下的最保守行为。

## 4. 预期贡献

1. **运动学-残差证书分解**：把黑箱证书的误差界从全局 β 收缩为残差 β_r，从结构上移除 v9"域偏移即误差最大化"的相关性风险（几何项零误差）；
2. **被动性阻抗退化**：以零刚度自由顺从作为新的中立元类别，给出不依赖预测精度、永远可行的接触安全兜底，替代/涵盖中止点停车；
3. **置信度双门控单调调度**：块长与刚度共享一个标量并形式化单调退化到 v8，消除"更软却更短"之类的调度悖论；
4. **接触安全证书与预算**：能量罐与块证书共享预算的可行性分析，E571–E590 覆盖 β 收缩、奇异规避、被动性、顺从力界、域偏移相关性与端到端任务。

## 5. 本轮最大风险

**一句话**：KSC 的"几何零误差"只在 URDF 与真实几何一致时成立——抓取/形变/软体任务里**接触几何本身会变**，所谓"精确骨架"可能恰好把最关键的那部分（接触时的有效间隙、指尖形变）算错，而 PIF 的被动性又只保证不注入能量、不保证任务不失败，于是"证书很紧、力很安全"仍可能夹坏物体。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| q, q̇, q̈ | 关节位置、速度、加速度 |
| T_i(q) | 第 i 根连杆的正运动学位姿（FK，解析） |
| ĝ_kin, ê_kin | 解析骨架给出的块内最小间隙 / 最大等效力（几何项） |
| r̂, β_r | 残差模型输出及其信任域内一致误差界 |
| μ(q)=√det(JJᵀ) | 可操作度；σ_min(J) 为雅可比最小奇异值 |
| τ_μ, τ_σ | 可操作度与奇异值门限（块证书失效门控） |
| Π=(M,D,K) | 阻抗包络：惯量、阻尼、刚度矩阵（对称半正定） |
| E_tank, E_min | 能量罐存量与下限（被动性守卫） |
| s_t ∈ [0,1] | 统一置信度（证书裕度 + 奇异裕度 + 能量裕度 + Δ_dom/risk_SLAM 的归一化最小值） |
| K_eff(t), K_stiff(t) | 有效块长与刚度，均由 s_t 单调驱动 |
| v_Π^⊥ | 阻抗域中立元：K=0、D=D_min、τ=τ_g（重力补偿自由顺从） |
| h(·) | 软化曲线，非减，h(0)=0，h(1)=1 |

**新增定义 540（解析运动学骨架 KinematicSkeleton）** 给定 URDF 与关节状态 (q,q̇)，FK 给出连杆位姿 {T_i(q)}；块内第 k 步的几何量由关节轨迹 q^{1:k} 解析积分后计算：
```
ĝ_kin = min_{k≤K}  min_{i,j}  sd( G_i(T_i(q^k)),  O_j )      # 有符号距离
ê_kin = max_{k≤K}  ‖ τ_grav(q^k) + τ_inertia(q^k, q̇^k, q̈^k) ‖
```
其中 sd(·,·) 为凸碰撞几何的有符号距离（解析）。若动作为任务空间增量 ẋ，则经阻尼最小二乘微分 IK 映射 q̇ = Jᵀ(JJᵀ+λ²I)⁻¹ẋ（λ=λ₀(1−μ/τ_μ)⁺）后再积分。模型准确时，几何项相对真实几何误差为零。

**新增定义 541（残差动力学与残差误差界 ResidualDynamics）** 将真实指标分解为 g_true = g_kin + r、e_true = e_kin + r_e；残差模型 r̂=f_θ(q,q̇,a) 只拟合接触/形变/摩擦。信任域 U_t 内的一致误差界：
```
β_r = sup_{U_t} ‖ (r̂ − r, r̂_e − r_e) ‖∞
```
证书总误差上界为 β_r（几何项不贡献误差）。

**新增定义 542（可操作度与奇异门控 ManipulabilityGate）** 令 J=J(q)。
```
μ(q) = sqrt(det(J Jᵀ)),    σ_min = σ_min(J)
gate_ok ⇔ (μ ≥ τ_μ) ∧ (σ_min ≥ τ_σ)
```
gate_ok=false ⇒ 块证书强制失效、K_eff←1、且按定义 546 软化阻抗。理由：∂g/∂q 与 ‖J⁺‖ 在奇异附近以 1/σ_min 发散，任何残差模型的 Lipschitz 界都会爆。

**新增定义 543（阻抗包络 ImpedanceEnvelope）** 块内执行阻抗控制：
```
τ = M(q) ẍ_d + D(q)(ẋ_d − q̇) + K(q)(x_d − x) + τ_g(q)
```
Π=(M,D,K)，M≻0、D⪰D_min≻0、K⪰0。自由度上的期望由块动作 a^{1:K} 给出；K 的谱范数即"权限"。

**新增定义 544（能量罐 PassivityTank）** 标准能量罐，用输入调制保证非负：
```
P_in = τᵀ q̇ ,   α_t = clamp( E_t / (Δt·P_in⁺ + ε), 0, 1 )
E_{t+1} = clamp( E_t + Δt·( α_t P_in⁺ − q̇ᵀ D q̇ ), E_min, E_max )
```
守卫要求 E_t ≥ E_min 方可注入控制能量；E_t 触底 ⇒ 下一周期强制 K←0（定义 547）。

**新增定义 545（统一置信度 UnifiedConfidence）** 所有安全裕度归一到 [0,1] 后取最小值：
```
s_t = clamp( min{
        (ĝ_min − d_safe)/Δ_g,
        (τ_eff − ê_max)/Δ_e,
        (μ − τ_μ)/Δ_μ,
        (σ_min − τ_σ)/Δ_σ,
        (E_t − E_min)/Δ_E,
        1 − Δ_dom/τ_dom,
        1 − risk_SLAM/τ_SLAM
      }, 0, 1 )
```
任一项为负 ⇒ s_t=0。

**新增定义 546（双门控调度 DualGateSchedule）** 令 h(s)=s^α（α≥1，默认 α=1）：
```
K_eff(t)   = 1 + floor( (K_max − 1) · s_t )
K_stiff(t) = K_nom · h(s_t)
D(t)       = D_nom · (2 − h(s_t))          # 越软越阻尼，保持耗散
```
s_t=0 ⇒ (K_eff, K_stiff, D)=(1, 0, 2D_nom)。

**新增定义 547（阻抗域中立元 ImpedanceNeutral）** 自由顺从：
```
v_Π^⊥ : τ = τ_g(q) − D_min q̇ ,   K = 0
```
它是权限合成 ⊕_Π（"串联权限，取最小"）的恒等元：任何指令与 v_Π^⊥ 合成后不再向环境施加主动力。与 v9 的契约中立元同构，但作用于**力矩端口**而非**旁路端口**。

**新增定义 548（接触安全证书 ContactSafetyCert）** 块级三联证书：
```
CSC_t = ( g_min ≥ d_safe ,  max_{k≤K} ‖F_c^k‖ ≤ F_max ,  min_{k≤K} E_tank^k ≥ E_min )
```
三项与 v9 块证书 Ĉ_t 合并为 v10 证书；任一失败 ⇒ 立即软化并使 K_eff←1。

**新增定义 549（单调退化序 MonotoneDegradationOrder）** 定义偏序 (K_eff, −K_stiff) 的字典序；要求调度映射 s↦(K_eff(s),K_stiff(s)) 保序。即 s₁≤s₂ ⇒ K_eff(s₁)≤K_eff(s₂) 且 K_stiff(s₁)≤K_stiff(s₂)。此禁令由引理 90 与 E577 单元测试共同守护。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8/v9 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承不变。
**升级定义 533（块证书，v10）**

```
Ĉ_t = ( ĝ_min = ĝ_kin + r̂_g − β_r,
```

**升级定义 539（有效块长，v10）** K_eff 不再由 Δ_dom 单独公式给出，而由统一置信度 s_t 经定义 546 单调驱动；v9 公式是其在"仅 Δ_dom/risk_SLAM 项激活"时的特例。

## 3. 关键算法骨架

```python
# IP-357 KinematicSkeletonCertifier：运动学骨架证书器
class KinematicSkeletonCertifier:
    def __init__(self, urdf, residual_model, beta_r, d_safe,
                 tau_mu=0.05, tau_sigma=0.02, lam0=0.01):
        self.model, self.res = urdf, residual_model
        self.beta_r, self.d_safe = beta_r, d_safe
        self.tau_mu, self.tau_sigma, self.lam0 = tau_mu, tau_sigma, lam0

    def manipulability(self, q):
        J = self.model.jacobian(q)
        return math.sqrt(max(0.0, det(J @ J.T))), min_singular_value(J)

    def joint_traj(self, q, actions):
        qs, mu_min = [q], float('inf')
        for a in actions:
            mu, smin = self.manipulability(qs[-1])
            mu_min = min(mu_min, mu)
            lam = self.lam0 * max(0.0, 1.0 - mu / self.tau_mu)
            qd = self.model.jacobian(qs[-1]).T @ solve(
                J @ J.T + lam**2 * I, a)          # 阻尼最小二乘 IK
            qs.append(self.model.integrate(qs[-1], qd))
        return qs, mu_min

    def certify(self, state, actions):
        qs, mu_min = self.joint_traj(state.q, actions)
        g_kin = min(self.model.min_signed_distance(qk) for qk in qs)
        e_kin = max(self.model.effort(qk) for qk in qs)
        r = self.res.rollout(state, actions)              # 仅残差
        _, smin = self.manipulability(state.q)
        g_min = g_kin + r.clearance - self.beta_r          # 定义 540/541
        e_max = e_kin + r.effort + self.beta_r
        gate_ok = (mu_min >= self.tau_mu) and (smin >= self.tau_sigma)
        valid = gate_ok and g_min >= self.d_safe and e_max <= state.tau_eff
        return Cert(g_min, e_max, mu_min, smin, gate_ok, valid)


# IP-358 PassivityImpedanceFilter：被动性阻抗退化器
class PassivityImpedanceFilter:
    def __init__(self, M_fn, D_fn, tau_g, K_nom, D_nom, D_min,
                 E0=5.0, E_min=0.0, E_max=10.0, F_max=100.0, alpha=1.0, dt=0.02):
        self.M, self.D_fn, self.tau_g = M_fn, D_fn, tau_g
        self.K_nom, self.D_nom, self.D_min = K_nom, D_nom, D_min
        self.E, self.E_min, self.E_max = E0, E_min, E_max
        self.F_max, self.alpha, self.dt = F_max, alpha, dt

    def h(self, s):                          # 定义 546 的软化曲线
        return max(0.0, min(1.0, s)) ** self.alpha

    def update_tank(self, tau, qd):          # 定义 544
        P_in = max(0.0, float(tau @ qd))
        alpha_t = min(1.0, self.E / (self.dt * P_in + 1e-9))
        diss = float(qd @ self.D_fn @ qd)
        self.E = min(self.E_max,
                     max(self.E_min, self.E + self.dt * (alpha_t * P_in - diss)))
        return self.E

    def gains(self, s):
        hs = self.h(s)
        return self.K_nom * hs, self.D_nom * (2.0 - hs)

    def command(self, q, qd, x_d, xd_d, xdd_d, s):
        if self.E <= self.E_min:              # 能量触底 ⇒ 中立元
            return self.compliant_hold(q, qd)
        K, D = self.gains(s)
        tau = (self.M(q) @ xdd_d + D @ (xd_d - qd)
               + K @ (x_d - q) + self.tau_g(q))
        return clip_tau(tau, self.F_max)

    def compliant_hold(self, q, qd):          # 定义 547 v_Π^⊥
        return self.tau_g(q) - self.D_min @ qd


# IP-359 DualGateScheduler：统一置信度 + 单调双门控
def confidence(cert, state, energy, delta_dom, tau_dom,
               risk_slam, tau_slam, sc):
    s = min((cert.g_min - sc.d_safe) / sc.dg,
            (state.tau_eff - cert.e_max) / sc.de,
            (cert.mu - sc.tau_mu) / sc.dmu,
            (cert.smin - sc.tau_sigma) / sc.dsig,
            (energy - sc.E_min) / sc.dE,
            1.0 - delta_dom / tau_dom,
            1.0 - risk_slam / tau_slam)
    return max(0.0, min(1.0, s))

def dual_gate(s, K_max):
    K_eff = 1 + int((K_max - 1) * s)          # 定义 546
    return K_eff, s
```

## 4. 推导

**引理 87（运动学-残差误差收缩）** 设模型几何精确（真值 g_true = g_kin + r），残差模型在信任域内一致误差 ≤ β_r，则块内证书误差 ≤ β_r；若残差目标严格小于总量且残差模型在残差上的误差不大于 v9 黑箱在总量上的误差（假设 A1），则 β_r ≤ β。证明：ĝ = g_kin + r̂，故 |ĝ − g_true| = |r̂ − r| ≤ β_r，几何项误差为零，不含入界；A1 直接给出 β_r ≤ β。A1 不是定理，由 E571/E572 经验检验。∎

**引理 88（可操作度门控使残差界保持有效）** 设间隙函数 g 对 q 的 Lipschitz 常数为 L_g，微分 IK 用阻尼最小二乘，则 ‖q̇‖ ≤ ‖ẋ‖/(2λ)（λ≥λ_min）。若门控保证 σ_min ≥ τ_σ 且 λ ≥ λ_min，则块内 ‖q̇‖ 有界，∂g/∂q 的放大被 1/τ_σ 封顶，残差模型所需的 Lipschitz 界有限，β_r 不因奇异而失效。证明：阻尼最小二乘满足 ‖Jᵀ(JJᵀ+λ²I)⁻¹ẋ‖ ≤ ‖ẋ‖·σ_max/(σ_max²+λ²) ≤ ‖ẋ‖/(2λ)；Lipschitz 链式 g(q^{k})−g(q^{k−1}) ≤ L_g‖q̇‖Δt。∎

**引理 89（零刚度顺从的被动安全）** 在 K=0、D⪰D_min≻0、重力补偿精确下，取存储函数 V=½q̇ᵀM(q)q̇+U(q)，则 V̇ = −q̇ᵀD_min q̇ + q̇ᵀF_ext + q̇ᵀ(τ−τ_g)。无外部能量注入时控制器不注入能量（τ−τ_g=−D_min q̇），V̇≤0；接触力界由准静态 F_ext=D_min q̇ 给出 ‖F_ext‖≤D_min‖q̇‖，而 ‖q̇‖ 由 V 有界。故自由顺从不自激、力有界；执行器只需能提供 τ_g 与 D_min‖q̇‖，在假设执行器能保持重力时可执行，无需停车几何。∎

**引理 90（双门控单调安全）** h(s)=s^α 非减且 h(0)=0，故 K_eff(s)=1+⌊(K_max−1)s⌋ 与 K_stiff(s)=K_nom h(s) 均对 s 非减。s₁≤s₂ ⇒ K_eff(s₁)≤K_eff(s₂) 且 K_stiff(s₁)≤K_stiff(s₂)，即不存在"更软却更短"或"更长却更硬"的反向组合（定义 549）。块变短使前视时域缩短、所需停车距离下降；阻抗变软使接触力上界下降；二者共同使安全裕度对 s 单调不增，且 s=0 时 (K_eff,K_stiff)=(1,0) 恰为 v8 逐步 + 顺从保持。∎

**引理 91（能量罐与证书预算不互饿）** 能量罐是状态量、块证书是逐块量，二者只在 s_t 处耦合。若 E_t→E_min，则 s_t 的能量项→0，双门控使 K_stiff→0；主动力矩下降使 P_in 下降，能量罐停止消耗并可从非负耗散中保持 E≥E_min，不会为"补证书"而反向延长块或要求更多算力。故能量耗尽只降权限、不增预算，不构成互饿。∎

**引理 92（退化链与 v9/v8 等价）** KSC 不可用时 ĝ 由 v9 前向模型给出（全局 β），逐位等于 v9 证书；PIF 不可用时中止走 v9 最近中止点，逐位等于 v9 兜底；二者同时不可用即 v9 ACMD 本体。s_t=0 ⇒ (K_eff,K_stiff)=(1,0) 等价 v8 逐步 + 被动保持。叠加 v9 引理 83 的中立元映射，任一增强失效均落在 v9/v8 的退化格点上，无行为漂移。∎

## 8. 本轮最大风险

**一句话**：KSC 的"几何零误差"只在 URDF 与真实几何一致时成立——抓取/形变/软体任务里**接触几何本身会变**，所谓"精确骨架"可能恰好把最关键的那部分（接触时的有效间隙、指尖形变）算错，而 PIF 的被动性又只保证不注入能量、不保证任务不失败，于是"证书很紧、力很安全"仍可能夹坏物体。
