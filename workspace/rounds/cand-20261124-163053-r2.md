## 1. 两个灵感的第一性原理

### 灵感 1 ·「自主导航」→ 缺的不是局部控制，而是「可修正的计划 + 恢复监督」

自主导航之所以稳，不是因为某个更强的控制器，而是因为**三级解耦 + 计划可修正 + 卡滞恢复**这三件事被显式工程化了：

- **全局规划 / 局部控制 / 监督恢复**三层分离：全局规划在图上搜索一条带代价的路线（慢、审慎、吃显式地图）；局部控制器高频跟随（快、反应式、吃局部观测）；监督层监控「有没有进展」，卡住就升级恢复行为。VLA 栈现在只有「局部控制」（IP-09 伺服）和一张「地图」（IP-13 场景图），**中间的计划层与上面的监督层都缺**。
- **计划可修正（D* Lite / MPC）**：路线不是圣旨。某条边走不通，就在图上重搜，而不是死磕单点。当前 IP-09 是**一条固定路标链**——某个路标彻底失败时，IP-02 只能就地重试，无法「换一条路到达同一个任务目标」。这个结构性弱点在长时程复合任务（组装置物凳、叠衣服）上会被放大。
- **代价图 = 风险图**：导航里每条边的代价是「通行时间 + 碰撞风险」；操作域每条边的代价应是「期望步数 + 失败惩罚」。谁来填这个权？正是灵感 2 的世界模型评论家（V 通道）——两个灵感在此合流。
- **恢复阶梯 + 预算**：导航的恢复行为（清代价图 → 原地转 → 后退 → 放弃）是按侵入度排序、有预算的。操作域对应：抖动 → 重感知 → 重抓 → 重定位 → 重路由 → 止损。**拒绝无限重试**，这是步数经济（L12/L13）的直接推论（L14）。
- **进度/卡滞监控**：补第 3 轮的短板。第 3 轮的「复读检测」检测的是**行为环**（同一动作反复）；卡滞检测的是**无进展**（动作不同但子目标完成度不涨）——两者互补，必须都上。

**策略含义**：新增长时程语料（F4）把「计划层」从锦上添花变成刚需；IP-16 用「子目标图 + 重规划 + 恢复阶梯 + 卡滞监控」把固定路标链升级为可修正计划。

### 灵感 2 ·「世界模型」→ 一个模型，三种用法，按可信度分级信任

世界模型不是单一功能，而是**同一个动力学模型的三种可复用输出**：

1. **预测器 P**：`p(s_{t+1} | s_t, a_t)`，可想象 rollout 做规划（model-based control）。
2. **惊讶 S**：`s_t = −log p(z_t | ẑ_t)`（预测误差 / 负对数似然）。**这是最稳健、最被低估的用法**：它不要求模型能精确预测接触动力学，只要求模型知道「什么是正常」；一旦现实偏离预测，surprise 升高 = 世界变了（滑移 / 干扰 / 目标位移 / 卡滞）。
3. **评论家 V**：成功概率或 cost-to-go，给路线打分、当安全门（「这一步值不值得试」）。

关键洞察：**第 3 轮手写了三个专用异常检测器（SlipGuard 光流、人工干扰分类、复读相似度），本质都是 surprise 的特例**。用一个世界模型的 surprise 通道，就能把它们统一成一个带校准误报率的检测器（L15），且省掉三套手工阈值。这正是「预测-比较」优于「预测-替代」的原因：越往 P/rollout 走，越依赖保真度；越往 S 走，越只依赖校准。

**分级信任原则（P14）**：世界模型先作 surprise 检测器（最稳）→ 次作评论家给路线打分（中等，需 L16 门控）→ 最后才作 rollout 规划（最脆，须实测保真度过门槛）。操作域接触丰富、WM 保真度普遍差，这个顺序不是保守，而是风险定价。

### 综合 · 导航给「搜索结构」，世界模型给「边权与监督信号」

把两个灵感焊在一起，得到本轮的中心思想——**模型基路线规划与恢复（Model-Based Route Planning & Recovery, MBRP）**：

- 导航提供**图**：任务图 G=(V,E)，子目标为节点、多种实现手段为并行边（抓顶 vs 抓侧；直接放 vs 经中转台面）。
- 世界模型提供**权与灯**：V 通道给边打「期望步数+失败惩罚」，S 通道给卡滞/异常报警，P 通道仅在保真度达标时评估候选路线。
- 执行层不变：IP-09 伺服照跑、IP-02 介入照用，只是触发源新增「surprise 超阈」与「卡滞」，动作菜单从扁平列表升级为有预算的恢复阶梯。

一句话：**第 3 轮回答了「现在到底在哪、目标是谁」；本轮回答「下一步该走哪条路、走不通怎么办、凭什么相信预测」。**

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（计划可修正）**：任何路线/子目标序列都不得视为不可变；每次断言失败、surprise 超阈或卡滞即触发重搜。固定路标链只是任务图的退化特例（退化链 Level-1.8）。
- **P14（预测-比较优于预测-替代）**：世界模型的使用按可信度分级——先 surprise（预测-比较），再 V（预测-评估），最后 rollout（预测-替代）；越靠后越依赖保真度，须逐级通过实测门槛（L16）。
- **P15（恢复阶梯与预算）**：干预按侵入度排序为阶梯，逐级升级；总恢复预算 R_max 有限，耗尽即止损（放弃当前路线/任务），禁止无限重试（L14 + L12 步数经济）。

## 5. 本轮最大风险

**世界模型幻觉（过信）**：把一个保真度不足的动力学模型当作安全门或规划器，会两类出错——**误否决**（V 把一个正确动作判成低成功，逼系统反复恢复、吃光步数）与**误放行**（rollout 把一个注定失败的动作想象成成功）。接触丰富的操作恰恰是 WM 最不擅的地方，因此这个风险不是理论上的，而是大概率的。对冲：①P14 分级信任，默认只用最稳的 surprise；②L16 门控，V/rollout 必须先在留出任务上过排序/误差门槛才开放；③退化链 Level-1.7 保证世界模型下线后系统不崩；④surprise 只对「持续多帧 + 强幅度」报警，宁漏勿误。次要风险：长尾域偏移（Dex1 长尾与挑战 32 项分布不同，只能留出法）；卡滞误判导致过早放弃（预算与滞回）。

**一句话最大风险：世界模型幻觉——把保真度不足的动力学模型当安全门/规划器，可能否决正确动作或放行错误动作，反而不如无世界模型的反应式基线。**

## 3. 新增 IP 详述

### IP-16 · RoutePlanner 任务图 + 重规划 + 恢复阶梯 + 卡滞监控（P0，新）

- **动机**：F4 的长尾语料是「组装置物凳、叠衣服、整理药盒」这类长时程复合任务——固定路标链一旦某段失败就整链报废；自主导航的三级解耦（全局规划/局部控制/监督恢复）恰好补这个结构缺口。且反馈环依赖 IP-13 的显式状态与 IP-17 的边权/异常信号，是 v3 状态层的自然上层。
- **与现有方案差异**：基线是「观测→动作」单通路 + 固定链；v3 加了状态但计划仍是硬的。本方案让**计划成为一等公民且可修正**：子目标为节点、同一子目标的多种实现为并行边（抓顶/抓侧、直接放/经中转），失败即降权重搜。
- **技术可行性**：高。任务图可从 IP-06 的 32 项阶段标注 + Dex1 长尾任务分解半自动导出；A*/D* Lite 是教科书件；恢复阶梯与卡滞逻辑是规则，无新模型、无训练。
- **资源**：数据=IP-06 标注（图 schema）；算力=小（图搜索微秒级）；接口=无新增字段（策略内部）。
- **落地步骤**：①从任务标注导出 G=(V,E)（U19）；②边权接口先接启发式先验（期望步数+固定失败先验），IP-17 就绪后换 critic；③A* 初规划 + 失败边降权重搜（D* Lite 简化版）；④卡滞监控（progress 窗口 + surprise 持续）挂监督环；⑤恢复阶梯接入 IP-02（预算 R_max）；⑥E634/E638 验证。
- **风险**：卡滞误判过早放弃（滞回 + 预算 + 保守阈值）；任务图 schema 覆盖不全（先只对强失败任务建局部替代边）；重规划抖动（换路需代价显著低于原路才换，加滞回）。

### IP-17 · PredictiveWorldModel：surprise / success-critic / rollout（P1，新）

- **动机**：v3 手写了三套异常检测（SlipGuard 光流、干扰分类、复读相似度），阈值各自标定、维护成本高。世界模型的 surprise 是它们的统一母体；WMA-0 已在库（F6），可低成本派生。同时 IP-16 需要边权与「该不该试」的安全门，critic 正好供给。
- **三通道与可信度（P14）**：
  - **S（surprise，最稳）**：`s_t = −log p(z_t | ẑ_t)`，校准后分位阈值固定误报率（L15）。统一滑移 / 干扰 / 目标位移 / 卡滞检测。
  - **V（success-critic，中等）**：边成功概率 / cost-to-go，给 IP-16 打分、当安全门。须过 L16 门控（E636）。
  - **P（rollout，最脆）**：仅在 L16 通过时评估候选路线；失败即退回启发式。
- **与现有方案差异**：IP-10 只把 WMA-0 当负样本源与潜空间前瞻；本方案把它变成**在线监督信号源**，但严格分级信任，且整套可下线（Level-1.7）。
- **技术可行性**：中。WMA-0 前向可用，但在线延迟是硬约束（低频 / 事件触发 / 裁剪 ROI）；接触丰富段保真度差——所以主打 surprise，不主打 rollout。
- **资源**：WMA-0 权重；算力=小到中（低频）；数据=IP-06 回放 + Dex1 长尾做校准/留出。
- **落地步骤**：①S 通道最小实现（预测-比较 + 分位校准，E635）；②V 通道（在 32 项+留出上训/校准 success-critic，E636）；③P 通道仅做离线评估，达标才上线；④接入 IP-16 边权与安全门；⑤延迟实测（E639）与退化（Level-1.7）。
- **风险**：**过信/幻觉（本轮最大风险）**——L16 门控 + 只作 advisory + 退化链；校准漂移（分位阈值在线重估需谨慎，默认离线定标）；延迟（事件触发 + ROI）。

## 5. 符号与定义（新增 U19–U21；U1–U18 沿用第 1–3 轮）

- **定义 U19（任务图 / 路线）**：任务图 `G=(V,E)`；V=子目标状态（路标），E=可行转移（同一子目标的多种实现为并行边）。边权 `w(e)=E[steps|e] + λ·(1−p_succ(e))`，`p_succ` 由 IP-17 critic 或启发式先验给。路线 `ρ = v_0 → … → v_g`；选路 = `argmin_ρ Σ_{e∈ρ} w(e)`；重规划 = 失败边降权后重搜（D* Lite 简化）。
- **定义 U20（世界模型三通道）**：`WM=(P,S,V)`；P=动力学 `p(s'|s,a)`；S=surprise `s_t=−log p(z_t|ẑ_t)`（校准后近似 χ²_d，L15）；V=成功-代价评论家 `V(s)→[0,1]` 或 cost-to-go。在线默认只用 S/V（低频），P 仅离线或 L16 达标后上线。
- **定义 U21（恢复阶梯与卡滞）**：恢复阶梯 `R=[r_1,…,r_m]` 按侵入度排序（抖动→重感知→重抓→重定位→重路由→止损）；卡滞判据：窗口 W 内 `Δprogress ≤ ε` 且 `persist(surprise>τ) ≥ k` 帧 → 升级 `r_{k+1}`；总预算 `R_max` 耗尽 → 止损。progress 由 IP-13 场景图子目标完成度估计。

## 6. 关键算法骨架（新增片段；主体沿第 1–3 轮 `UniBotSAGEPolicy`）

```python
# ===== IP-16: 任务图上的重规划（D* Lite 简化；边权由 IP-17 评论家给）=====
class TaskGraph:
    def __init__(self, task_id):
        self.V, self.E = load_subgoal_graph(task_id)   # U19：子目标 + 多实现并行边
    def cost(self, e, state, wm):
        p = wm.success_prob(e, state) if wm.enabled else PRIOR_P[e]   # V 通道或先验
        return wm.expected_steps(e) + LAM * (1.0 - p)
    def plan(self, s0, goal):
        return astar(self.V, self.E, s0, goal, self.cost)
    def replan(self, s_now, goal, failed_edge):
        self.E = self.E.demote(failed_edge)            # 失败边降权，不硬删（防抖动）
        return self.plan(s_now, goal)
```

```python
# ===== IP-16: 卡滞检测 + 恢复阶梯（P15 / L14）=====
LADDER = ["JITTER", "REPERCEIVE", "REGRASP", "RELOCALIZE", "REROUTE", "ABORT"]
def supervise(traj, state, wm, budget):
    if progress(traj.W) <= EPS and wm.persist_surprise(traj.W, k=K):
        r = LADDER[min(traj.level, len(LADDER) - 1)]
        traj.level += 1
        return r if budget.spend(r) else "ABORT"       # 预算耗尽即止损
    return None
```

```python
# ===== IP-17: 世界模型三通道（在线用 S/V，低频；P 受 L16 门控）=====
class WorldModel:
    def surprise(self, obs, action):                   # S：预测-比较（统一异常）
        z_hat = self.predict_latent(self.history, action)
        z = self.encode(obs)
        return -self.logp(z, z_hat)                    # nats；校准后分位阈值=固定误报率
    def success_prob(self, edge, state):               # V：边成功概率（路线打分 / 安全门）
        return self.critic(self.feats(edge, state)).sigmoid()
    def rollout(self, route):                          # P：仅 L16 通过时用于规划
        assert self.fidelity_ok, "rollout gated by L16"
        return self.imagine(route)
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（重路由 vs 重试的盈亏平衡）** 设关键边 e 失败，剩余目标 g。选项 A 就地重试：单次成本 `c_r`、成功率 `p_r`、上限 n 次；选项 B 经替代路线 ρ′：期望成本 `C_alt=Σ_{e′∈ρ′} c_{e′}`。则重路由严格占优 ⇔
`C_alt < c_r(1−p_r^n)/(1−p_r) + (1−p_r^n)·C_fail`。
⇒ 替代路线足够便宜时，换路优于死磕；固定路标链（无并行边）只能退化为重试，正是当前基线的结构性弱点。∎

**引理 L15（surprise 的校准与统一检测）** 若 WM 预测经温度/协方差校准使 `z_t|ẑ_t ~ N(ẑ_t,Σ)`，则 `s_t=(z_t−ẑ_t)ᵀΣ⁻¹(z_t−ẑ_t) ~ χ²_d`，与 L11 同构：分位阈值把误报率固定为 α，且三类异常（滑移/干扰/目标位移）共用同一套阈值。⇒ 统一检测的前提不是「预测准」，而是「校准好」；预测误差只降低检出功效（非中心参数），不破坏误报率控制——这解释了为何 surprise 比 rollout 稳健。∎

**引理 L16（世界模型可信度门控）** 设评论家排序误差 `ε_V`（1−Kendall-τ）、多步预测误差 `ε_P`；用 V/P 做路线选择相对启发式先验的期望后悔 `R(ε_V,ε_P)`。存在阈值 `θ`，使 `ε_V + βε_P > θ` 时 `R>0`（模型规划劣于启发式）。⇒ 必须先在留出任务上实测 ε_V 与 ε_P，低于门槛才开放 rollout；否则 WM 仅作 surprise 日志与二值安全门。这是 P14 分级信任的定量依据。∎
