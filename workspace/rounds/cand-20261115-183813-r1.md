# 第 9 轮（本次会话第 1 轮 / 全局第 9 轮；灵感：「意图识别」×「竞赛策略」）

> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal v8（定义 493–531；引理 77–81；实验 E531–E550）。
> **本轮纪律**：意图识别与竞赛策略都只作用于**决策侧**，不进入 M₀/M₁ 的物理安全语义。意图只决定「想做什么」与软目标权重，竞赛只决定「先做什么、冒多少性能风险」；二者均不得扩大安全动作集。任一模块缺失必须逐级退化回 v8。

## 0. 直觉与动机

**灵感 1（意图识别 → 从“指令分类”到“带校准不确定性的意图后验”）**

直觉：现有 VoiceCommandTyping 本质上仍是字符串槽位填充，它把 ASR top-1 当成事实。真实交互中，同一个「把那个拿给我」可能对应多个目标物体、多个交付位置和不同紧迫度；ASR 还会在噪声下给出错误 n-best。正确对象不是某个标签，而是意图假设空间上的**后验分布**。更重要的是：意图识别错误的代价通常不是「动作不安全」，而是「做了错的任务」。因此意图只能改变**任务选择与软目标**，不能改变 M₀/M₁ 的物理安全判据。这一区分是整轮设计的地基。

进一步，意图后验应支持**弃权**：当后验熵高、最大后验低、或出现未知意图时，系统应主动澄清或执行安全默认动作，而不是自信地猜。意图识别因此是一个带外部动作（澄清/弃权）的贝叶斯决策问题，而不是一个分类精度问题。

**灵感 2（竞赛策略 → 分数约束下的风险预算，而不是“更激进”）**

直觉：竞赛中的策略不是简单提高速度。比赛分数通常是多维的：任务完成、部分分、时间奖励、违规扣分、平局打破规则；而且有时间上限和对手分数。真正的最优策略是一个**受约束的组合优化**：在截止时间前，把有限的时间与“性能风险预算”分配给期望分数密度最高的子任务；领先时锁定已完成的高价值任务，落后时才在**不影响安全**的子任务上提高尝试率。竞赛压力恰恰是团队最容易放松安全的时刻，因此必须把「安全约束」与「分数优化」做成两层：分数只能在安全包络内分配风险。

把竞赛规则形式化为评分函数 S(x) 与规则合规谓词 R(a,s)，可以把“策略”从启发式口号变成可审计的约束优化问题。

**交叉洞察（1+1>2）：意图不确定性 × 竞赛紧迫性 = 澄清/行动/弃权的元决策**

意图后验给出 b(h)，竞赛状态给出每个意图的分数价值 V(h) 与澄清的时间成本 c_q(t)。于是「现在问清楚还是先做」不再是拍脑袋，而是**完美信息期望价值（EVPI）**问题：澄清的收益是消除意图不确定性带来的期望分数提升，成本是占用比赛时间。紧迫度越高，c_q 越大，澄清阈值越低；但无论多紧迫，安全包络不变。这样，意图识别负责「不确定性」，竞赛策略负责「不确定性的价格」，二者共同决定元动作。这是本轮真正的新东西。

## 1. 研究问题（轮次升级版）

- **Q1（意图后验与校准）**：如何在 ASR n-best、多轮对话、任务上下文与未知意图并存的条件下，维护一个校准的意图后验，并使弃权/澄清的风险可控？
- **Q2（意图不变安全）**：如何把意图后验注入指标层级、奖励权重与阈值调节，同时证明意图误判永远不会扩大物理安全动作集？
- **Q3（竞赛策略）**：如何把竞赛规则、分数差距、截止时间与性能风险预算形式化为可实时求解的约束优化，并保证紧迫度不侵蚀 M₀/M₁？
- **Q4（元决策）**：如何在「行动 / 澄清 / 弃权」之间做 Bayes-最优选择，并给出可计算的阈值与后悔界？

## 2. 设计原则（P7–P9 之后升级为 P10–P14）

**P10 意图后验化（Intent-as-Belief）**
意图是 H 上的后验 b_t，不是标签；用 HMM/贝叶斯滤波更新，用温度缩放与分裂共形校准发射概率；保留未知意图 h_∅。

**P11 意图不变安全（Intent-Invariant Safety）**
A_safe 由 M₀/M₁ 与物理约束定义，与 b 无关；意图只产生 A_intent(b)，最终 A_adm = A_intent(b) ∩ A_safe。意图错误只能导致任务失败/分数损失，不能导致物理不安全。

**P12 意图风险传播（Intent Risk Propagation）**
risk_INT(b) 作为风险向量新维度注入 MetaWeight / ER / OTL，但不进入 M₀/M₁；risk_INT=0 时逐位退化为 v8。

**P13 分数感知组合策略（Score-Aware Portfolio）**
把子任务视为带（期望分数、CVaR 风险、时长、前置约束）的项目，在截止时间与性能风险预算下做 0-1 背包/约束 MDP；安全预算恒为 0。

**P14 紧迫单调阈值（Urgency-Monotone Ladder）**
τ₀、τ₁ 对紧迫度不变；τ₂、τ₃ 只能在 [ε_min, ε_max] 内随紧迫度放松；任何情况下 A_safe 不扩大。

## 3. 与基线的接口（如何退化）

- 意图组（IBT/IAG/IRP）失效 ⇒ 退回 v8 的 VoiceCommandTyping top-1，risk_INT≡0，风险向量退回 5 维；
- 竞赛组（CSE/SAPP/PRB/UMTL）失效 ⇒ 退回 v8 的固定任务顺序、固定阈值与 InstructGauge-RTDI 权重；
- 元决策组（VoCP/SSC/CC/RCS）失效 ⇒ 永远执行当前最大后验意图，不澄清、不弃权；
- 三组全失效 ⇒ 逐位等价于 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

## 4. 预期贡献

1. **意图后验与校准弃权**：把意图识别从分类器升级为带未知意图、共形覆盖与 EVPI 弃权的信念滤波器；
2. **意图不变安全定理**：证明意图误判不会扩大物理安全集，给出 risk_INT 的有界注入与退化等价；
3. **分数感知风险预算**：把竞赛策略形式化为 CVaR 约束下的子任务组合优化，给出紧迫单调性与实时 DP；
4. **澄清元策略**：用 EVPI 统一行动/澄清/弃权，给出阈值 τ_ask = 1 − c_q/ΔS 与后悔界；
5. 完整的 **意图-分数-风险-证书-动作** 五元闭环：E551–E570 覆盖校准、安全不变性、竞赛收益、实时性与退化等价。

## 5. 本轮最大风险

**一句话**：意图后验的校准误差与竞赛紧迫性会耦合出「越落后越自信地猜意图、越没时间越跳过澄清」的联合失效；若 risk_INT 或性能风险预算的实现边界没守住，竞赛压力会通过 τ₂/τ₃ 的放松反向侵蚀安全包络，导致系统在最有得分动机时最不安全。

**新增定义 532（意图假设空间 IntentHypothesisSpace）**
意图被显式展开为可接地的离散假设，而不是一个字符串标签：
```
H = { h = (task, object, destination, constraints) } ∪ { h_∅ }
p0(h) ∝ exp( wᵀ φ_ctx(s, h) )
0 ≤ φ(h,s) ≤ 1   # 当前场景下 h 的可行性
```
其中 `φ_ctx` 为手工特征（任务阶段、可见物体、先前对话槽位），`p0` 为先验；连续参数（如抓取位姿）在给定 h 后由局部规划器求解，不进入离散后验。

**新增定义 533（意图信念滤波 IntentBeliefFilter）**
用切换隐马尔可夫模型维护后验：
```
b_t⁻(h) = Σ_{h'} T(h|h') b_{t-1}(h')
b_t(h)  = p(z_t|h) · b_t⁻(h) / Z_t,   Z_t = Σ_h p(z_t|h) · b_t⁻(h)
```
`p(z_t|h)` 由意图分类器经温度缩放校准：`p_T(z|h) = softmax(f_θ(z)/T)_h`，`T` 在验证集上以 NLL 最小化选取。对未知意图，保留 `h_∅` 的 Dirichlet 质量；当 `b_t(h_∅)` 超阈值时，不把任何已知意图当作事实。

**新增定义 534（意图风险分量 IntentRiskComponent）**
把后验的不确定性映射为有界标量，注入风险向量第 6 维：
```
H(b)        = −Σ_h b(h) log b(h)
risk_INT(b) = 1 − b_max + λ_H · H(b)/log|H| + λ_U · b(h_∅)
```
约定 `|H|=1` 时熵项为 0；`b_max=max_h b(h)`。当 b 退化为已知意图上的点质量时 `risk_INT=0`，从而逐位退回 v8 的 5 维风险。

**新增定义 535（意图不变安全包络 IntentInvariantSafetyEnvelope）**
```
A_safe(s)    = { a | M₀(s,a)=1 ∧ M₁(s,a)=1 ∧ Phys(s,a)=1 }
A_intent(b)  = { a | ∃h: b(h) ≥ τ_ground ∧ Achieves(a,h) }
A_adm(s,b)   = A_intent(b) ∩ A_safe(s)
A_meta(s,b)  = A_adm(s,b) ∪ { q, a_∅ }
```
`A_safe` 不含任何 `b` 项；`q` 与 `a_∅` 是元动作，不直接驱动执行器。该定义把「意图正确性」与「物理安全性」彻底解耦：意图错只改变 `A_intent`，不可能改变 `A_safe`。

**新增定义 536（竞赛状态与紧迫度 CompetitionState & Urgency）**
```
d_t  = clip( (ŝ_opp^hi − s_self)/S_max, −1, 1 )
q_t  = clip( 1 − T_rem/T_ref, 0, 1 )
u_t  = 1 − (1 − max(0,d_t))·(1 − q_t)   ∈ [0,1]
```
`ŝ_opp^hi` 为对手分数的上置信界（稳健估计），`T_ref` 为赛段参考时长。`u_t` 同时编码「落后压力」与「时间压力」：任一项高则紧迫度高，但 `u_t` 只进入性能层，不进入安全层。

**新增定义 537（评分函数与规则合规 CompetitionScore）**
```
S(x) = S_task(x) + S_partial(x) + S_time(x) − S_penalty(x) − S_violation(x)
R(a,s) ∈ {0,1}
```
`S` 按规则书编译为“主分 + 字典序 tie-break”向量；`R(a,s)=0` 的动作直接不可执行。规则合规是硬过滤，不是奖励项，避免“用扣分换分数”的 specification gaming。

**新增定义 538（分数感知约束目标 ScoreAwareObjective）**
策略 π 的优化目标为约束 MDP：
```
max_π  J(π) = E[ Σ_{k=1}^K γ^{t_k} S_k(x_k) − λ_T Σ_k d_k − λ_P N_pen ]
s.t.   a_t ∈ A_adm(s_t,b_t)          # 意图不变安全
       Pr(M₀ ∧ M₁) = 1               # 物理安全
       CVaR_α(Cost) ≤ B_R^perf(t)    # 性能风险预算
       t_K ≤ T_rem                   # 截止时间
```
其中 `Cost` 只统计 M₂/M₃ 的性能代价（如尝试次数、超时、部分分损失），安全代价不进入可交易预算。

**新增定义 539（性能风险预算 PerformanceRiskBudget）**
```
B_R^perf(t) = clip( B₀ + β·u_t, 0, B_max )
B_R^safe(t) ≡ 0
CVaR_α(X)   = min_ζ { ζ + (1−α)⁻¹ E[(X−ζ)⁺] }
```
紧迫度上升只提高可交易的性能风险预算；安全预算恒为 0，因此不存在“用安全换分数”的通道。

**新增定义 540（紧迫单调阈值梯度 UrgencyMonotoneThresholdLadder）**
约定 `τ_i` 越大越严格。在 v8 的 DA-OTL 轨迹上叠加紧迫项：
```
τ_i(t) = clip( τ_i^v8(t) + δ_i·u_t, ε_min,i, ε_max,i )
δ₀ = δ₁ = δ_dom = δ_SLAM = 0
δ₂ ≤ 0,   δ₃ ≤ 0
```
因此 `τ₀, τ₁` 对紧迫度**逐位不变**，`τ₂, τ₃` 随紧迫度非增（放松），且始终被 `[ε_min, ε_max]` 夹住。`M_dom/M_SLAM` 与安全相关，保持 v8 行为。

**新增定义 541（完美信息期望价值与澄清阈值 ValueOfClarification）**
```
EVPI(b) = Σ_h b(h)·max_a S(a,h) − max_a Σ_h b(h)·S(a,h)
c_q(t)  = λ_T·d_q + λ_P·r_q
VoC(b)  = EVPI(b) − c_q(t)
τ_ask   = 1 − c_q(t)/ΔS
```
元动作选择：
```
if b_max ≥ max(τ_ground, τ_ask):   act = argmax_a Σ_h b(h)S(a,h)
elif VoC(b) > 0 and T_rem > d_q:   clarify
else:                              act 或 a_∅（取期望分更高者）
```
`τ_ask` 是充分筛查阈值：当 `b_max ≥ τ_ask` 时必有 `EVPI ≤ c_q`，澄清不可能优于行动；当 `b_max < τ_ask` 时再用精确 EVPI 决定是否值得问。

**新增定义 542（子任务组合 SubtaskPortfolio）**
每个子任务 k 有 `(μ_k, C_k, d_k, P_k)`，`P_k` 为前置子任务集合。求解 0-1 背包：
```
max_{x∈{0,1}^K}  Σ_k μ_k x_k
s.t.  Σ_k C_k x_k ≤ B_R^perf(t)
      Σ_k d_k x_k ≤ T_rem
      x_k ≤ x_j,  ∀j ∈ P_k
```
`K ≤ 10`，时间与预算各离散为 ≤20 档，动态规划复杂度 `O(K·T·B) ≤ 4000`，可在 5–10Hz 规划线程内精确求解。

**新增定义 543（策略切换滞回 StrategySwitchController）**
三档宏观策略：
```
Π = { π_LockIn, π_Balanced, π_Push }
```
每档携带 `(μ_π, σ_π, C_π, d_π)`。选择下置信界 `LCB_π = μ_π − κσ_π`；仅当 `LCB_{π'} > LCB_π + h` 连续 `N_h` 个周期才切换。`h` 为滞回裕度，`N_h` 为驻留计数，防止分数估计噪声导致策略颤振。

**新增定义 544（竞赛证书 CompetitionCertificate）**
```
cert_t = ( safety_margin, CVaR_α(Cost), score_LCB, coverage_1−α, degradation_level, R )
```
签发条件：`safety_margin ≥ 0`（M₀/M₁ 全满足）、`CVaR_α(Cost) ≤ B_R^perf(t)`、`score_LCB` 满足当前策略档门槛、意图覆盖集 `C_α` 非空、`R=1`。证书随 ROS 消息发布；任一条件失败则按退化链降级，而不是继续执行。

**新增定义 545（意图条件指标层级 IntentConditionedLadder）**
在 v8 六层之上增加**软诊断层** `M_int`：
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_int)
M_int: risk_INT(b) < τ_int
```
`M_int` 违背只触发 `{clarify, a_∅, continue}` 三种元动作，不映射到 M₀，也不改变 v8 的 `δ_trigger`。v8 的软硬约束触发条件保持原样，从而不引入新的“软通过硬失”空洞。

**新增定义 546（意图-竞赛集成标识 IntegratedIdentity）**
```
Φ_IC  = { b_t, risk 6-dim, c_t, B_R^perf, τ(u), VoC }
Φ_v8  = { intent top-1, risk 5-dim, fixed thresholds, fixed order }
```
当 `risk_INT≡0 ∧ u_t≡0 ∧ B_R^perf≡0 ∧ VoCP 关闭` 时，`Φ_IC` 逐位退化为 `Φ_v8`。

**新增定义 547（退化签名 DegradationSignature）**
每个模块组输出一个可观测签名 `(intent_mode, risk_dim, budget_mode, threshold_mode, meta_mode)`；主环在每个控制周期比对签名与期望退化级别。若签名与声明不一致，立即进入 Level-6 安全回退并记录 FaultCert。

## 2. 形式化定义（要点汇总）

**定义 532（意图假设空间）** 意图是离散可接地假设 `h=(task,object,destination,constraints)` 加未知 `h_∅`，先验由场景特征给出。

**定义 533（意图信念滤波）** 用切换 HMM 做预测-更新；发射概率经温度缩放校准；未知意图保留 Dirichlet 质量。

**定义 534（意图风险）** `risk_INT = 1−b_max + λ_H·H(b)/log|H| + λ_U·b(h_∅)`，有界且点质量时为 0。

**定义 535（意图不变安全）** `A_adm = A_intent(b) ∩ A_safe`，`A_safe` 与 `b` 无关；这是全轮的核心安全定理来源。

**定义 536（竞赛状态）** 分数差、剩余时间、规则阶段与对手分数区间合成紧迫度 `u_t`；只用上置信界做稳健估计。

**定义 537（评分与规则）** 分数是规则书编译出的多目标向量；违规动作由 `R(a,s)=0` 直接过滤，不参与分数权衡。

**定义 538（约束目标）** 在安全、CVaR 预算与截止时间约束下最大化期望竞赛分；安全代价不可交易。

**定义 539（风险预算）** `B_R^perf` 随紧迫度上升，`B_R^safe≡0`；CVaR 约束用 Rockafellar–Uryasev 形式。

**定义 540（紧迫单调阈值）** 安全层阈值对 `u_t` 不变，性能层阈值只能放松且被上下界夹住。

**定义 541（澄清元决策）** EVPI 减澄清成本；`τ_ask=1−c_q/ΔS` 是“不必再问”的充分阈值。

**定义 542（子任务组合）** 带前置约束的 0-1 背包，K≤10，实时 DP 精确求解。

**定义 543（策略切换）** 三档策略 + LCB + 滞回 + 驻留计数，避免颤振。

**定义 544（竞赛证书）** 安全裕度、CVaR、分数 LCB、意图覆盖、退化级别与规则合规的联合证书。

**定义 545（意图条件层级）** 新增软诊断层 `M_int`，只触发澄清/弃权，不映射 M₀。

**定义 546（集成标识）** 给出 `Φ_IC = Φ_v8` 的逐位退化条件。

**定义 547（退化签名）** 用可观测签名检测“声明退化但实际未退化”的配置错误。

import numpy as np

class IntentBeliefTracker:
    def __init__(self, intents, transition, emission_fn,
                 unknown_prior=0.05, tau_ground=0.5):
        self.H = list(intents) + ['__unknown__']
        self.T = transition
        self.emission = emission_fn
        self.b = np.array([(1.0 - unknown_prior) / len(intents)] * len(intents)
                          + [unknown_prior])
        self.tau_ground = tau_ground

    def predict(self):
        self.b = self.T.T @ self.b

    def update(self, z_t):
        self.predict()
        lik = np.array([self.emission(z_t, h) for h in self.H])
        self.b = lik * self.b
        s = self.b.sum()
        self.b = self.b / s if s > 0 else np.ones_like(self.b) / len(self.b)
        return self.b

    def max_prob(self):
        return float(self.b.max())

    def entropy(self):
        p = np.clip(self.b, 1e-12, 1.0)
        return float(-(p * np.log(p)).sum())

    def risk(self, lam_H=0.5, lam_U=0.5):
        logN = np.log(max(len(self.H), 2))
        unk = self.b[self.H.index('__unknown__')]
        return float(1.0 - self.b.max()
                     + lam_H * self.entropy() / logN
                     + lam_U * unk)

    def conformal_set(self, z_t, q_alpha):
        lik = np.array([self.emission(z_t, h) for h in self.H])
        return {h for h, p in zip(self.H, lik) if p >= q_alpha}


class IntentInvariantSafetyEnvelope:
    def __init__(self, M0, M1, phys, achieves, tau_ground=0.5):
        self.M0, self.M1, self.phys = M0, M1, phys
        self.achieves = achieves
        self.tau_ground = tau_ground

    def filter(self, s, actions, belief, intents):
        safe = [a for a in actions
                if self.M0(s, a) and self.M1(s, a) and self.phys(s, a)]
        grounded = [a for a in safe
                    if any(belief[i] >= self.tau_ground and self.achieves(a, h)
                           for i, h in enumerate(intents))]
        return grounded if grounded else ['__safe_default__']


class CompetitionStateEstimator:
    def __init__(self, S_max=100.0, T_ref=600.0):
        self.S_max, self.T_ref = S_max, T_ref

    def urgency(self, s_self, opp_hi, T_rem):
        d = np.clip((opp_hi - s_self) / self.S_max, -1.0, 1.0)
        q = np.clip(1.0 - T_rem / self.T_ref, 0.0, 1.0)
        return float(1.0 - (1.0 - max(0.0, d)) * (1.0 - q))


class PerformanceRiskBudgeter:
    def __init__(self, B0=0.02, beta=0.08, B_max=0.10):
        self.B0, self.beta, self.B_max = B0, beta, B_max

    def budget(self, u_t):
        return float(np.clip(self.B0 + self.beta * u_t, 0.0, self.B_max))


class ScoreAwarePortfolioPlanner:
    def __init__(self, dt=0.5, db=0.005):
        self.dt, self.db = dt, db

    def plan(self, subtasks, T_rem, B_perf):
        # subtasks: list of (mu, cvar, duration, prereq_indices)
        Tn = int(T_rem / self.dt) + 1
        Bn = int(B_perf / self.db) + 1
        dp = np.full((len(subtasks) + 1, Tn, Bn), -1e18)
        dp[0, 0, 0] = 0.0
        for k, (mu, cvar, dur, prereq) in enumerate(subtasks, start=1):
            ti = min(Tn - 1, int(np.ceil(dur / self.dt)))
            bi = min(Bn - 1, int(np.ceil(cvar / self.db)))
            for t in range(Tn):
                for b in range(Bn):
                    dp[k, t, b] = dp[k - 1, t, b]          # 不选
                    if t >= ti and b >= bi and dp[k - 1, t - ti, b - bi] > -1e17:
                        dp[k, t, b] = max(dp[k, t, b],
                                          dp[k - 1, t - ti, b - bi] + mu)
        t_best, b_best = np.unravel_index(np.argmax(dp[-1]), (Tn, Bn))
        selected, t, b = [], t_best, b_best
        for k in range(len(subtasks), 0, -1):
            if dp[k, t, b] != dp[k - 1, t, b]:
                selected.append(k - 1)
                mu, cvar, dur, _ = subtasks[k - 1]
                t -= min(Tn - 1, int(np.ceil(dur / self.dt)))
                b -= min(Bn - 1, int(np.ceil(cvar / self.db)))
        return list(reversed(selected))


class UrgencyMonotoneThresholdLadder:
    def __init__(self, delta_perf=(0.05, 0.03), eps_min=None, eps_max=None):
        self.delta_perf = delta_perf
        self.eps_min = eps_min or {}
        self.eps_max = eps_max or {}

    def update(self, tau_v8, u_t):
        tau = dict(tau_v8)
        for i in range(7):
            if i in (0, 1, 4, 5):
                delta = 0.0
            else:
                delta = -self.delta_perf[min(i - 2, 1)]
            lo = self.eps_min.get(i, -np.inf)
            hi = self.eps_max.get(i, np.inf)
            tau[i] = float(np.clip(tau[i] + delta * u_t, lo, hi))
        return tau


class ValueOfClarificationPolicy:
    def __init__(self, delta_S, tau_ground=0.5, d_q=2.0):
        self.delta_S = delta_S
        self.tau_ground = tau_ground
        self.d_q = d_q

    def expected_scores(self, belief, score_matrix):
        return belief @ score_matrix          # (|A|,)

    def evpi(self, belief, score_matrix):
        oracle = float((belief * score_matrix.max(axis=1)).sum())
        bayes = float(self.expected_scores(belief, score_matrix).max())
        return oracle - bayes

    def decide(self, belief, score_matrix, c_q, T_rem):
        b_max = float(belief.max())
        tau_ask = 1.0 - c_q / max(self.delta_S, 1e-9)
        evpi = self.evpi(belief, score_matrix)
        if b_max >= max(self.tau_ground, tau_ask):
            return 'act', int(np.argmax(self.expected_scores(belief, score_matrix)))
        if evpi > c_q and T_rem > self.d_q:
            return 'clarify', None
        return 'act_or_default', int(np.argmax(self.expected_scores(belief, score_matrix)))

## 4. 推导

**引理 82（意图信念的期望熵单调性）**
在模型正确且观测条件独立的假设下，贝叶斯更新满足
`E[H(b_t) | b_{t-1}] ≤ H(b_{t-1})`。
证明：`H(H|Z) = H(H) − I(H;Z) ≤ H(H)`，其中 `I(H;Z) ≥ 0` 为互信息；对 `z_t` 取期望即得。故 `risk_INT` 中的熵项期望非增；但 `1−b_max` 项可能路径波动，因此只能声明期望单调，不能声明逐周期单调，需用在线校准监控。

**引理 83（意图不变安全性）**
对任意后验 `b`，若执行动作 `a ∈ A_adm(s,b)`，则 `a ∈ A_safe(s)`；改变 `b` 不会改变 `A_safe`。
证明：由定义 535，`A_adm = A_intent(b) ∩ A_safe(s)`，故 `a ∈ A_safe(s)`。`A_safe` 的定义只引用 `M₀/M₁/Phys`，不含 `b`；因此对任意 `b,b'`，`A_safe` 相同。若 `A_intent(b)=∅`，可执行集退化为 `{a_∅}` 或澄清元动作，二者均不扩大物理动作集。证毕。
推论：意图误判最多导致任务失败或分数损失，不会导致 M₀/M₁ 违背。这正是“意图只决定想做什么，不决定允许做什么”。

**引理 84（意图风险有界性与退化等价）**
`risk_INT(b) ∈ [0, 1+λ_H+λ_U]`；当 `b=δ_{h*}` 且 `h*≠h_∅` 时 `risk_INT=0`。
证明：`b_max ∈ [1/|H|,1]`，`H(b)/log|H| ∈ [0,1]`，`b(h_∅) ∈ [0,1]`，三项非负且分别有上界，故有界。点质量时 `b_max=1`、`H=0`、`b(h_∅)=0`，故为 0。于是 `w_6d = softmax([risk_5d, 0])` 与 v8 的 `w_5d` 在数值上一致（差一个常数归一化项），退化成立。有界输入也保证 softmax 不会数值爆炸。

**引理 85（紧迫单调性）**
设 `u₁ ≤ u₂`，则 `τ₀(u₁)=τ₀(u₂)`、`τ₁(u₁)=τ₁(u₂)`，且 `τ₂(u₁) ≥ τ₂(u₂)`、`τ₃(u₁) ≥ τ₃(u₂)`；`A_safe` 不变。
证明：由定义 540，`δ₀=δ₁=0`，故安全层阈值不变；`δ₂,δ₃≤0`，故性能层阈值随 `u` 非增；`clip` 保序。`A_safe` 只依赖 `τ₀,τ₁` 与物理约束，故不变。注意 `B_R^perf` 随 `u` 增大只扩大性能风险的可交易集，不改变安全集。证毕。

**引理 86（EVPI 上界与澄清阈值）**
令 `ΔS = max_{a,a',h} |S(a,h)−S(a',h)|`，则
`EVPI(b) ≤ (1−b_max)·ΔS`。
因此当 `b_max ≥ 1 − c_q/ΔS` 时，`EVPI(b) ≤ c_q`，澄清的期望收益不超过成本，行动（或安全默认）不劣于澄清。
证明：设 `h*=argmax_h b(h)`，`a*` 为在 `h*` 下的最优动作，`a_b` 为 Bayes 动作。由 `a_b` 的最优性：
`Σ_h b(h)S(a_b,h) ≥ Σ_h b(h)S(a*,h)`。
于是
`EVPI = Σ_h b(h)(max_a S(a,h) − S(a_b,h))`
`     ≤ Σ_h b(h)(S(a_h,h) − S(a*,h))`
`     = Σ_{h≠h*} b(h)(S(a_h,h) − S(a*,h))`
`     ≤ (1−b(h*))·ΔS`。
最后一步用了 `h*` 项相消与其余概率质量和为 `1−b_max`。证毕。注意 `τ_ask` 是充分条件，不是必要条件；实际系统在 `b_max<τ_ask` 时仍用精确 EVPI 复核。

**引理 87（CVaR 预算可行性）**
若子任务 k 的 `C_k` 是其代价的 `CVaR_α` 上界，且所选组合满足 `Σ_k C_k x_k ≤ B_R^perf`，则组合总代价的 `CVaR_α` 不超过 `B_R^perf`。
证明：`CVaR_α` 是相干风险度量，满足次可加性 `CVaR_α(X+Y) ≤ CVaR_α(X)+CVaR_α(Y)`。对选中子任务归纳即得 `CVaR_α(Σ_k Cost_k x_k) ≤ Σ_k C_k x_k ≤ B_R^perf`。证毕。该界是保守的（忽略分散化收益），但计算简单且安全侧偏保守。

**引理 88（组合规划的实时性）**
在 `K≤10`、时间档 `T≤20`、预算档 `B≤20` 的离散化下，定义 542 的 DP 至多 `K·T·B = 4000` 次状态转移，单次转移为常数时间。
证明：三重循环分别为子任务、时间档、预算档；每个状态只做一次“选/不选”比较。前置约束在子任务拓扑序下检查，仍为常数时间。故 5–10Hz 规划线程内可在毫秒级完成，不进入 50Hz 主环关键路径。

**引理 89（策略切换无颤振）**
设各策略的 `LCB` 估计噪声有界 `ε`，滞回裕度 `h>2ε`，驻留计数 `N_h≥1`。则当真实策略优势小于 `h−2ε` 时不会发生切换；一旦切换，反向切换需要相反的、超过同一裕度的真实优势。
证明：切换条件为 `LCB_{π'} > LCB_π + h`。用 `LCB` 与真实值的误差界展开，若真实优势 `≤ h−2ε`，则 `LCB_{π'} − LCB_π ≤ h`，条件不成立。反向同理。故切换次数被真实优势的累计变化除以 `h−2ε` 所界，不会在阈值附近高频振荡。

**引理 90（六级退化正确性）**
意图组、竞赛组、元决策组分别只写 `(b,risk_INT)`、`(c_t,B_R,τ)`、`(meta,cert)` 三组正交接口；任一组失效时将其输出替换为 v8 默认值，系统行为等价于对应 v8 子集；三组全失效时逐位等价于 v8。
证明：按接口定义逐一检查：IBT/IAG 只影响 `b` 与 `risk_INT`，IRP 只影响风险向量维数；CSE/SAPP/PRB 只影响 `u_t`、`B_R` 与任务顺序；UMTL 只影响 `τ₂,τ₃`，且 `δ=0` 时恒等于 v8 的 DA-OTL；VoCP/SSC/CC/RCS 只影响元动作与证书，不影响 v8 的 `δ_trigger` 与 `M₀/M₁` 判据。各组无共享可变状态，故组合失效可交换、无级联副作用。证毕。

**引理 91（竞赛证书可靠性）**
若 `cert_t` 签发，则当前周期满足：① `M₀/M₁` 全满足；② 组合性能代价的 `CVaR_α ≤ B_R^perf`；③ 意图覆盖集非空；④ 规则合规。
证明：签发条件是上述四项的合取；①由 IISE 与 v8 的 SpatialCert 保证，②由引理 87 与 PRB 保证，③由 IBT 的共形集保证，④由 RCS 的硬过滤保证。证书不是“预测”，而是对当前周期已计算量的联合断言，故可靠。

## 8. 本轮最大风险

**一句话**：意图后验的校准误差与竞赛紧迫性会耦合出「越落后越自信地猜意图、越没时间越跳过澄清」的联合失效；若 `risk_INT` 或性能风险预算的实现边界没守住，竞赛压力会通过 τ₂/τ₃ 的放松反向侵蚀安全包络，导致系统在最有得分动机时最不安全。
