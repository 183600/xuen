### 第 1 轮灵感驱动研究记录（承接 v27，新循环）

**灵感词**：UniBot-V1、遥操作

**直觉与动机**：
设想操作员隔着 5G 链路，用 VR 手柄遥操作一台 UniBot-V1 人形机器人去开门。操作员看到的是 150–300ms 前的画面，发出的是「向前一点、右手抬高」的低维意图；机器人却要在接触、摩擦、关节限位和地面反力中，把它展开成全身 20+ 自由度的动作。传统遥操作把这条链路当成一根「延迟的摇杆管道」：人给命令，机器人执行，安全靠限速/急停兜底。它忽略了四道鸿沟：
1. **意图鸿沟**：人给的是低维意图，机器人要解高维全身控制，命令空间与动作空间不同构；
2. **时间鸿沟**：延迟与丢包让操作员对机器人当前状态的认知过期，操作员在「过去」上做「现在」的决策；
3. **安全鸿沟**：操作员的错误、激进或不可实现指令，可能在动力学上直接导致跌倒/碰撞；
4. **信任鸿沟**：硬拒绝指令会让操作员困惑并反复试错，过度自动修正又会让操作员产生依赖或疏离，二者都会破坏人机共同 ground。

前几轮的 KEMPC/KACG 已经把「机器人自主规划」做到了证书级安全，但它默认指令来自自主规划器。遥操作把指令源换成了「人」，于是证书要证明的对象也变了：不再只是「机器人会安全」，而是「人对机器人的意图被安全且忠实地实现，并且这个过程对人可理解」。这就是**意图级、双向的证书**。

**关键洞见**：把遥操作从「命令管道」重构为「意图协商」（intent negotiation）。具体地：
- 操作员在低维意图流形 Z 上表达意图，UniBot-V1 的全身控制器 D_θ 把意图解码为动作；这叫「意图级接口」，从源头缩小人机语义差。
- 证书栈分两层设防：**前向证书**证明「人的意图被安全实现」（IC、TSE、DRC、IRO、SAAC），**后向证书**证明「机器人行为对人可理解」（LC、CIPD）。
- 当意图不可安全实现时，不做硬拒绝，而做**最小意图保持修复**：把命令投影到遥操作安全包络，修复量 δ 若在半径 r 内则自动执行；超过 r 则升级为显式确认，并把「证书预测的未来 + 修复向量 + 风险色带」回显给操作员，形成闭环协商。
- 延迟不是事后补偿，而是**一等公民**：用嵌套延迟不变集把 τ_max 吸收进证书，而不是等命令到了才发现状态已过期。

**形式化目标**：
1. 定义意图流形 Z⊂R^d、命令空间 C、全身解码器 D_θ: Z×X→U，以及意图实现间隙 g_I = max_t d_U(u_t, D_θ(z_t,x_t))；
2. 定义遥操作安全包络 TSE_x = {c∈C | ∀τ≤τ_max，保持/切换 rollout 均留在安全集 S}；
3. 定义意图证书 IC：g_I ≤ ε_I，witness 为 (z,x,D_θ,ε_I)；
4. 定义延迟鲁棒证书 DRC：用嵌套延迟不变集 {S_τ} 与备份策略 π_b，保证任意 τ_t≤τ_max、丢包率≤ρ_max 下 x_t∈S；
5. 定义最小意图修复算子 IRO：c* = Proj_{TSE_x}(c)，δ=c*−c，修复半径 r，超 r 升级确认；
6. 定义共享自治仲裁证书 SAAC：u_α=αu_h+(1−α)u_a，证明凸混合仍满足 CBF 安全约束且偏离人类意图有界；
7. 定义可读性证书 LC：P(z_true | ξ) ≥ 1−β，保证操作员能从轨迹正确读出意图；
8. 定义共同意图码本 CGIC 与证书预测显示 CIPD，降低带宽与操作负荷、校准信任；
9. 构建 TA-KACG 准入门：Exec_v28 = Exec_v27 ∩ Fil_intent ∩ Fil_delay ∩ Fil_legibility ⊆ Exec_v27；
10. 证明组合安全性、意图保真界、延迟鲁棒性，以及通信中断/修复超界/计算超时下的退化路径；
11. 给出仿真 + 小规模人因实验的设计与验收指标。

**本轮最大风险**：意图证书的「语义自证」风险——证书只能保证「实现忠于我们推断出的意图」，却无法保证「推断出的意图就是操作员真正的意图」。当意图模糊、延迟导致意图漂移、或系统过度修复时，机器人会以很高的置信度执行一个「安全但错误」的意图；更隐蔽的是，操作员看到的是被证书修饰过的预测画面，可能根本察觉不到这种意图错位。这种「安全地做错事」比单纯碰撞更难发现，也更危险。

## 0. 本轮定位与新增核心模块

上一轮 v27 的 KACG 证明了「自主规划器给出的机器人计划是安全的」。本轮把指令源从自主规划器换成「人」，新增的是**意图级、双向的遥操作证书栈 UniTeleop-Cert（UTC）**：前向证书保证「人的意图被安全实现」，后向证书保证「机器人行为对人可理解」。所有新增模块都作为 KACG 的外层包装，不修改底层证书语义。

| 编号 | 名称 | 类型 | 关键改进（相对 v27） |
|---|---|---|---|
| IP-465 | Intent Certificate (IC) | 前向证书 | 证明执行动作是对操作员意图 z 的 ε_I-忠实实现；witness=(z,x,D_θ,ε_I)，校验 g_I≤ε_I |
| IP-466 | Teleoperation Safety Envelope (TSE) | 安全包络 | TSE_x={c∈C \| ∀τ≤τ_max，保持/切换 rollout 均留在 S}；离线可达集 + 在线成员查询 |

## 2. 关键算法骨架

### IP-465 Intent Certificate (IC)

```python
@dataclass
class IntentCertificate:
    """IC：执行动作 u 是操作员意图 z 的 eps_I-忠实实现。"""
    z: Tensor                     # 操作员意图码（CGIC 输出）
    x: Tensor                     # 当前机器人状态
    eps_I: float                  # 任务空间保真上界
    decoder: Callable             # D_theta: (z, x) -> u
    task_map: Callable            # J(x, u) -> y（任务空间可观测输出）
    weight: Tensor                # 任务空间加权矩阵 W
    witness: dict = field(default_factory=dict)

    def gap(self, u_exec: Tensor) -> float:
        y_exec = self.task_map(self.x, u_exec)
        y_ref = self.task_map(self.x, self.decoder(self.z, self.x))
        e = y_exec - y_ref
        return float(torch.sqrt(e @ self.weight @ e))

    def issue(self, u_exec: Tensor) -> bool:
        g = self.gap(u_exec)
        self.witness = {"gap": g, "eps_I": self.eps_I, "z": self.z.detach()}
        return g <= self.eps_I

    def verify(self) -> bool:
        return self.witness.get("gap", float("inf")) <= self.eps_I
```

### IP-466 Teleoperation Safety Envelope (TSE)

```python
@dataclass
class TeleoperationSafetyEnvelope:
    """TSE_x = {c : 任意 tau<=tau_max 下，保持/切换 rollout 均安全}。"""
    decoder: Callable                 # D_theta
    step: Callable                    # x_{k+1} = f(x_k, u_k)
    safe_set: Callable                # h_S(x) >= 0
    last_u: Tensor                    # 上一条已发送命令（用于保持段）
    tau_max: float = 0.30
    dt: float = 0.02
    n_tau: int = 8
    n_roll: int = 16
    backup_policy: Callable = None    # pi_b

    def contains(self, c: Tensor, x: Tensor) -> bool:
        taus = torch.linspace(0.0, self.tau_max, self.n_tau)
        return all(self._held_rollout_safe(c, x, float(t)) for t in taus)

    def _held_rollout_safe(self, c: Tensor, x: Tensor, tau: float) -> bool:
        xk = x
        n_hold = max(1, int(round(tau / self.dt)))
        for _ in range(n_hold):                 # 命令到达前的保持段
            xk = self.step(xk, self.last_u)
            if self.safe_set(xk) < 0:
                return False
        for _ in range(self.n_roll):            # 到达后的切换段
            xk = self.step(xk, self.decoder(c, xk))
            if self.safe_set(xk) < 0:
                return False
        return True
```

### IP-467 Delay-Robust Certificate (DRC)

```python
@dataclass
class DelayRobustCertificate:
    """DRC：嵌套延迟不变集 S_tau，保证任意 tau_t<=tau_max 下 x_t in S。"""
    step: Callable
    safe_set: Callable
    backup_policy: Callable
    tau_max: float = 0.30
    n_layers: int = 10
    sets: dict = field(default_factory=dict)   # tau -> membership oracle

    def build(self) -> "DelayRobustCertificate":
        # 反向构建：S_0 = S；S_{k+1} = Pre(S_k) ∩ S
        self.sets = {0.0: self.safe_set}
        for k in range(1, self.n_layers + 1):
            tau = k * self.tau_max / self.n_layers
            self.sets[tau] = self._pre(self.sets[(k - 1) * self.tau_max / self.n_layers])
        return self

    def verify(self, x: Tensor, u: Tensor, tau_meas: float) -> bool:
        # 取覆盖实测延迟的最保守层；要求当前与后继都在该层内
        tau = min(t for t in self.sets if t >= tau_meas)
        x_next = self.step(x, u)
        return self.sets[tau](x) and self.sets[tau](x_next)

    def _pre(self, inner: Callable) -> Callable:
        # 前驱集：存在 u，使 x 与 x' 均在内层，且保持段安全
        def oracle(x: Tensor) -> bool:
            u = self.backup_policy(x)
            return inner(x) and inner(self.step(x, u)) and self.safe_set(x) >= 0
        return oracle
```

### IP-468 Intent Repair Operator (IRO)

```python
@dataclass
class IntentRepairOperator:
    """IRO：c* = Proj_{TSE_x}(c)，最小范数修复；超 r 升级确认。"""
    envelope: TeleoperationSafetyEnvelope
    r: float = 0.15
    n_scp: int = 5
    trust_radius: float = 0.20

    def repair(self, c: Tensor, x: Tensor) -> tuple[Tensor, Tensor, bool, float]:
        if self.envelope.contains(c, x):
            zero = torch.zeros_like(c)
            return c, zero, False, 0.0

        c_star = c.clone()
        for _ in range(self.n_scp):
            grad = self._linearized_violation_grad(c_star, x)
            if grad is None:
                break
            delta = self._trust_region_qp(c_star, c, grad, self.trust_radius)
            c_star = c_star + delta
            if self.envelope.contains(c_star, x):
                break

        delta = c_star - c
        dist = float(torch.norm(delta))
        feasible = self.envelope.contains(c_star, x)
        escalate = (not feasible) or dist > self.r
```

### IP-469 Shared Autonomy Arbitration Certificate (SAAC)

```python
@dataclass
class SharedAutonomyArbitrationCertificate:
    """SAAC：u_alpha = alpha*u_h + (1-alpha)*u_a，凸混合仍满足 CBF。"""
    alpha: float
    cbf: Callable                 # h(x)
    lie: Callable                 # (x, u) -> L_f h + L_g h u
    alpha_gain: float = 1.0

    def blend(self, u_h: Tensor, u_a: Tensor) -> Tensor:
        return self.alpha * u_h + (1.0 - self.alpha) * u_a

    def certify(self, x: Tensor, u_h: Tensor, u_a: Tensor) -> bool:
        h = self.cbf(x)
        if self.lie(x, u_h) + self.alpha_gain * h < 0:
            return False
        if self.lie(x, u_a) + self.alpha_gain * h < 0:
            return False
        # 控制仿射系统下安全控制集是半空间，凸组合自动满足
        return self.lie(x, self.blend(u_h, u_a)) + self.alpha_gain * h >= 0
```

### IP-470 Common-Ground Intent Codebook (CGIC)

```python
class CommonGroundIntentCodebook:
    """从示教学习低维意图词表；操作员发索引/连续码，机器人解码为任务命令。"""

    def __init__(self, codebook: Tensor, encoder: Callable, decoder: Callable):
        self.V = codebook          # [K, d]，K 个意图原型
        self.enc = encoder         # demo -> z
        self.dec = decoder         # z -> c

    def encode(self, demo: Tensor) -> Tensor:
        return self.enc(demo)

    def decode(self, z: Tensor) -> Tensor:
        return self.dec(z)

    def quantize(self, z: Tensor) -> tuple[int, Tensor]:
        d = torch.cdist(z.unsqueeze(0), self.V).squeeze(0)
        k = int(torch.argmin(d))
        return k, self.V[k]

    def bandwidth(self, k: int) -> int:
        # 离散词表只需 ceil(log2 K) bit；连续码按维度量化
        return max(1, (k - 1).bit_length())
```

### IP-471 Legibility Certificate (LC)

```python
@dataclass
class LegibilityCertificate:
    """LC：操作员从轨迹 xi 正确推断真实意图 z 的后验概率 >= 1-beta。"""
    operator_model: Callable      # log P(z | xi)（操作员先验下的贝叶斯意图推断）
    beta: float = 0.10
    n_mc: int = 64

    def score(self, z_true: Tensor, xi: Tensor) -> float:
        # 蒙特卡洛估计操作员后验（先验 + 轨迹似然）
        return float(torch.exp(self.operator_model.log_posterior(z_true, xi)))

    def verify(self, z_true: Tensor, xi: Tensor) -> bool:
        return self.score(z_true, xi) >= 1.0 - self.beta
```

### IP-472 Certificate-Informed Predictive Display (CIPD)

```python
class CertificateInformedPredictiveDisplay:
    """把证书状态翻译成操作员可读的回显：预测未来、修复向量、风险色带。"""

    def render(self, x, c, c_rep, delta, drc_ok, ic_ok, lc_ok) -> dict:
        return {
            "ghost_traj": self._rollout(x, c_rep),          # 证书预测未来
            "repair_vector": delta,                          # 人看到自己被改了多少
            "risk_band": self._risk_color(drc_ok, ic_ok, lc_ok),
            "intent_gap": float(torch.norm(delta)),
            "escalate": not (drc_ok and ic_ok and lc_ok),
            "haptic": self._haptic_from_delta(delta),        # 力反馈/震动强度
        }

    def _risk_color(self, drc_ok, ic_ok, lc_ok):
        return "green" if (drc_ok and ic_ok and lc_ok) else ("amber" if drc_ok else "red")
```

### IP-473 Teleop-Aware Certification Gate (TA-KACG)

```python
@dataclass
class TeleopAwareCertificationGate:
    """UTC 准入门：前向安全 + 后向可读，失败一律退回证书备份策略。"""
    kacg: "KnowledgeAwareCertificationGate"   # 前轮八证门
    cgic: CommonGroundIntentCodebook
    tse: TeleoperationSafetyEnvelope
    drc: DelayRobustCertificate
    iro: IntentRepairOperator
    saac: SharedAutonomyArbitrationCertificate
    lc: LegibilityCertificate
    cipd: CertificateInformedPredictiveDisplay
    eps_I: float = 0.10
    tau_max: float = 0.30
    rho_max: float = 0.15

    def step(self, z, x, tau_meas, loss_meas, u_auto=None):
        # 0) 链路越界：先进入证书备份，而不是继续追延迟命令
        if tau_meas > self.tau_max or loss_meas > self.rho_max:
            return self.drc.backup_policy(x), "degraded_hold"

        # 1) 意图级接口
        c = self.cgic.decode(z)

        # 2) 最小意图保持修复
        c_rep, delta, escalate, dist = self.iro.repair(c, x)
        if escalate:
            self.cipd.render(x, c, c_rep, delta, False, False, False)
            return self.drc.backup_policy(x), "await_confirm"

        # 3) 解码 + 延迟鲁棒校验
        u_h = self.tse.decoder(c_rep, x)
        if not self.drc.verify(x, u_h, tau_meas):
            return self.drc.backup_policy(x), "degraded_hold"

        # 4) 共享自治仲裁（若存在自主建议）
        u = u_h if u_auto is None else self.saac.blend(u_h, u_auto)
        if not self.saac.certify(x, u_h, u_auto if u_auto is not None else u_h):
            return self.drc.backup_policy(x), "degraded_hold"

        # 5) 前向意图证书
        ic = IntentCertificate(z, x, self.eps_I, self.tse.decoder,
                               self.tse.task_map, self.tse.weight)
        if not ic.issue(u):
            return self.drc.backup_policy(x), "degraded_hold"

        # 6) 后向可读性证书（对即将执行的短轨迹）
        xi = self._short_rollout(x, u)
        if not self.lc.verify(z, xi):
            self.cipd.render(x, c, c_rep, delta, True, True, False)
            return self.drc.backup_policy(x), "degraded_legibility"

        # 7) 底层八证门复核（结构/语义/常识/动力学）
        if not self.kacg.admits_control(x, u):
            return self.drc.backup_policy(x), "degraded_hold"

        self.cipd.render(x, c, c_rep, delta, True, True, True)
        return u, "ok"
```

## 3. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| IC 校验 | O(n_y²) | O(n_y) | n_y≤12（任务空间维） |
| TSE 成员查询 | O(n_τ·(τ_max/dt + H)) | O(n_x) | n_τ=8, H=16, dt=20ms |
| DRC 校验 | O(n_layers + H) | O(n_layers) | n_layers=10 |
| IRO 投影 | O(n_scp·QP(n_c)) | O(n_c²) | n_scp≤5, n_c≤8 |
| SAAC 校验 | O(1) | O(1) | 控制仿射半空间 |
| CGIC 解码 | O(K·d) | O(K·d) | K≤64, d≤8 |
| LC 校验 | O(n_mc·H) | O(H) | n_mc=64 |
| TA-KACG 总体 | O(n_scp·QP + n_τ·H + n_mc·H) | O(n_x + n_c²) | 关键路径：IRO + TSE |

**实时性**：全身解码 QP 约 1–3ms；TSE 成员查询约 1–3ms；IRO 投影约 1–4ms；LC 约 0.5–1ms；其余 <0.5ms。单步合计约 5–12ms，满足 100Hz 证书频率 / 50Hz 控制频率的分层调度。若 TSE 查询超时，直接降级到 DRC 备份策略，证书链路仍闭合。

## 4. 正确性论证（增量）

### 引理 23（嵌套延迟不变性）

**陈述**：设 S_0=S，S_{k+1}=Pre(S_k)∩S，τ_max=K·Δ。若在每一时刻 t 都有 x_t∈S_K，且实际执行的命令满足「保持段 + 切换段」rollout 全程留在 S_K，则对任意延迟序列 τ_t≤τ_max、丢包率≤ρ_max，恒有 x_t∈S。

**证明**：把延迟视为「已发出但尚未生效」的命令队列。保持段由已生效的旧命令驱动，切换段由新命令驱动；两者都在 S_K 内。对剩余延迟预算做归纳：当 τ_t 减少 Δ 时，状态从 S_k 落入 S_{k-1}，而 S_k⊆S_{k-1}⊆…⊆S_0=S，故任意时刻状态都在 S 内。丢包只延长保持段，不改变「保持段在 S_K 内」这一前提。∎

### 引理 24（IRO 的最小性与可证性）

**陈述**：若 TSE_x 是闭凸集且 c∉TSE_x，则投影 c*=Proj_{TSE_x}(c) 唯一，且 ‖c*−c‖=dist(c,TSE_x)，是所有可行修复中范数最小者。若 TSE_x 非凸，SCP 只保证局部稳定点；仅当残差裕度 ≥ L·r（L 为 TSE 边界的局部 Lipschitz 常数）时，才签发「修复可行」证书。

**证明**：凸情形由 Hilbert 投影定理直接得到。非凸情形下，信赖域 SCP 每步解凸子问题，收敛到稳定点；用 Lipschitz 界把线性化误差控制住，残差裕度足够大即可保证真实约束不被违反。否则证书拒绝签发并升级确认。∎

### 引理 25（SAAC 的凸混合安全性）

**陈述**：对控制仿射系统 ẋ=f(x)+g(x)u 与 CBF h，安全控制集 K(x)={u : L_f h+L_g h·u+αh≥0} 是半空间（凸）。若 u_h,u_a∈K(x)，则 u_γ=γu_h+(1−γ)u_a∈K(x) 对任意 γ∈[0,1] 成立。

**证明**：L_f h+L_g h·u_γ+αh = γ(L_f h+L_g h·u_h+αh)+(1−γ)(L_f h+L_g h·u_a+αh) ≥ 0。∎

### 引理 26（IC 的保真界）

**陈述**：若解码器 D_θ 在 TSE_x 上对 c 满足 L_D-Lipschitz，且 ‖c_rep−c‖≤r，则任务空间实现间隙 g_I ≤ L_D·r + ε_D，其中 ε_D 为解码器近似误差。取 ε_I=L_D·r+ε_D 即可由 IC 签发。

**证明**：‖D(c_rep,x)−D(c,x)‖≤L_D‖c_rep−c‖≤L_D r；再叠加解码器自身误差 ε_D，三角不等式即得。∎

### 定理（UTC 组合安全与意图保真）

**陈述**：若 TA-KACG 接受遥操作计划 Π，则：
1. 在任意 τ_t≤τ_max、ρ_t≤ρ_max 下，机器人状态恒在 S 内（安全性）；
2. 意图实现间隙 g_I≤ε_I（前向保真）；
3. 操作员正确读出意图的概率 ≥1−β（后向可读）；
4. Exec_v28⊆Exec_v27（不放松上一轮安全边界）。

**证明**：(1) 由 DRC 引理 23 与 TSE 的保持/切换检查；(2) 由 IRO 引理 24 与 IC 引理 26；(3) 由 LC 定义直接得到；(4) TA-KACG 在最后一步仍调用 KACG.admits_control，且所有新增过滤器都是合取项，故 Exec_v28=Exec_v27∩Fil_intent∩Fil_delay∩Fil_legibility⊆Exec_v27。∎

**退化路径**：
- 修复超界 → `await_confirm`，机器人进入 DRC 备份保持，等待操作员确认或改意图；
- 通信中断/延迟越界 → `degraded_hold`，执行 π_b（安全站立/缓停），任务可中止但安全不破；
- TSE 非凸投影失败 → 拒绝签发修复证书，退回 π_b；
- 计算超时 → 分层调度丢弃本轮 TSE/IRO，只保留 DRC + KACG 的保守路径；
- 所有退化路径都只减少任务能力，不扩大 Exec_v28。

**统计校准（可选强化）**：τ_max 与 ε_I 可用 conformal prediction 从在线标定数据取 (1−α) 分位数，从而把「任意 τ≤τ_max」的确定性假设替换为分布无关的 ≥1−α 概率保证；代价是需要在部署初期收集一段标定轨迹。

## 5. 实验设计（本轮为设计，不伪造结果）

**平台**：UniBot-V1 人形机器人（29 DoF）在 MuJoCo/Isaac Gym 中的数字孪生；任务空间接口为末端位姿 twist + 夹爪 + 步态模式。

**任务**：
- T1 崎岖地形按路点行走（含台阶、斜坡、滑移面）；
- T2 全身接触操作（开门、推车、抓取高处置物）；
- T3 外力扰动后的恢复（模拟操作员误判导致的推挤）。

**网络条件**：往返延迟 τ~U(50,300)ms，抖动 ±50ms，丢包 0–20%，另设突发拥塞段（τ 阶跃到 500ms）。

**操作员模型**：主实验用「带噪声与偶发错误指令的模拟操作员」保证可复现；辅以 N=8 的小规模 VR 人因实验验证负荷与信任。

**基线**：
- B1 直接遥操作（无证书）；
- B2 限速/急停安全盾（reject-only）；
- B3 上一轮 KEMPC 自主控制（无人在环）；
- B4 本轮 UTC（完整证书栈）。

**指标**：安全违规率（跌倒/碰撞/超限）、任务成功率、意图实现间隙 RMSE、平均修复范数、升级确认率、完成时间、操作员负荷（NASA-TLX 代理）、信任校准误差（预测成功率 vs 实际成功率）。

**消融**：去掉 DRC（τ_max=0）、IRO 改为 reject-only（r=0）、去掉 CGIC（原始摇杆）、去掉 CIPD、去掉 LC。

**验收标准（预期趋势，非实测）**：
| 指标 | B1 直接 | B2 拒绝盾 | B4 UTC | 期望结论 |
|---|---|---|---|---|
| 安全违规率 | 高 | 低 | 最低 | UTC 相对 B1 降低 ≥60% |
| 任务成功率 | 中 | 低（频繁拒绝） | 高 | UTC 相对 B2 提升 ≥20% |
| 意图间隙 | — | 大（拒绝/限速） | 小 | 修复半径内自动保持 |
| 升级确认率 | 0 | 高 | <10% | 修复优于硬拒绝 |
| 操作负荷 | 高 | 高 | 低 | CGIC + CIPD 降低 ≥25% |

**关键对照假设**：
- H1：高延迟段，无 DRC 的 B4 消融会出现延迟导致的越界，证明「延迟一等公民」必要；
- H2：reject-only 在高延迟/复杂任务下成功率显著低于 IRO，证明「修复优于拒绝」；
- H3：去掉 LC/CIPD 后信任校准误差变大，证明后向证书对人因指标有独立贡献。

## 6. 已知风险与缓解（增量）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R22 | 语义鸿沟：证书证明的是「推断意图」，不是「真实意图」 | 高 | 1) 多假设意图并行；2) LC 后向校验；3) 修复超 r 强制确认；4) CIPD 透明回显 | 真正模糊/自相矛盾的意图无法被任何证书消解 |
| R23 | TSE 非凸、IRO 投影陷入局部解 | 中 | 1) SCP + 信赖域；2) Lipschitz 残差验证；3) 失败即退回 π_b | 接触丰富、高维构型下包络过保守 |
| R24 | 自动化依赖与信任错配 | 高 | 1) CIPD 显示修复量；2) 可变权限 α；3) 定期强制接管训练 | 长期使用导致操作员技能退化 |

## 7. 与上一轮的接口

- 所有新增模块只包装 KACG，不修改 USMC/SMC/KC/DCC 的语义；底层仍以 KACG.admits_control 为最后一道门。
- `Exec_v28 = Exec_v27 ∩ Fil_intent ∩ Fil_delay ∩ Fil_legibility`，集合单调收缩，延续 v27 的安全单调性。
- 上一轮的「常识闭塞」风险（R19）在本轮转化为「意图错位」风险（R22）：两者都源于「证书证明了错误的对象」，但本轮至少用 LC/CIPD 把「人是否理解机器人」纳入证书视野，属于可观测、可干预的改进。

## 8. 本轮最大风险（最终确认）

**一句话**：**UTC 能把「安全」和「可读」都做成证书，却无法证明「被安全执行的意图就是操作员真正想要的意图」；当意图模糊、延迟漂移或修复过度时，系统会以高置信度执行一个「安全但错误」的意图，而操作员看到的是被证书修饰过的预测画面，这种「安全地做错事」是当前方案最大、也最难在线检测的风险。**
