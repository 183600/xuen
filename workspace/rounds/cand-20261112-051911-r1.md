# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；本轮灵感：「竞赛策略」×「可扩展性」）

> 第 59 轮把证据层一路接地到执行层：BUQ 辨识电机结构性不确定性、ERTC 契约化嵌入式时限、EEIS 把 δ_f 编译成末端阻抗证书、CLEP 让执行实测回传为第 5 模态。但它仍隐含两个**部署前提**：其一，**「安全」是逐检查点、单机器人、可无限重算的局部目标**——默认每个检查点独立优化自己的 δ_f，默认失败只是概率事件而非「淘汰/扣分/名次」，默认时间、算力、尝试次数近乎免费；其二，**「证书」是单体、易腐、不可组合的**——每个接触都从零重算 UKF+μ+Pareto+XMC，证书链随接触数无界增长，跨机器人/跨区域/跨构型的经验无法复用。真实 UniBot 是**竞赛**：有限时间、有限电量、有限尝试、评分权重不均、存在对手、裁判规则部分未知；真实部署是**规模化**：多机器人、多区域、长时程、跨固件与标定批次。本轮两个灵感精准击中这两个被忽略的前提：**竞赛策略**要求把「风险」当作可跨检查点**配置的预算**、把「对手」当作**策略性隐变量**；**可扩展性**要求把「证书」做成**可组合、可复用、可增量、可认证近似**的代数对象。本轮核心命题：**「安全是硬约束，得分是目标函数；把全局失效预算当作投资组合分配给检查点，把证书当作可组合的证明对象分片复用——否则规模一大，方案既算不完，也赢不了」**——即 **竞争性证据战略 CSES × 组合可扩展证书 CSC**，把 v59 的「执行接地」升级为「战略-证据-执行」三层可扩展闭环。

核心矛盾：
- **H35（目标错位·逐点最安全 ≠ 竞赛最优）**：v59 的证据门默认「每个检查点的 δ_f 同质、失败同价」，但竞赛里「把杯子放到终点」与「穿过一段空地」的分值可能差 100 倍；某些失败是扣分，某些失败是**直接淘汰**（S=−∞）。均匀分配风险预算会把算力和探针花在低分检查点上，在关键高分区反而过度保守——**机器人可以极其安全地输掉比赛**。必须把 δ_total 从「逐点同质」变为**按得分权重、淘汰风险、边际成功增益分配的全局投资组合**。
- **H36（对手与评分非平稳·策略性不确定性）**：v59 的信念把环境当作被动隐变量，更新的是「世界是什么」。竞赛中还存在**会响应我方策略的对手**（抢占通道、遮挡、消耗共享资源）、**带噪声与偏好的裁判**、**随机化赛道**。对手不是 aleatoric 噪声，而是 strategic 隐变量；一个安全但可预测的策略会被针对到失效。必须引入对手信念、混合策略与遗憾界，同时保证**随机化只在已认证安全动作集内进行**。
- **H37（规模爆炸·单体重算与无界证书链）**：CLEP 每次接触都跑 UKF 辨识、μ 分析、Pareto 投影与 XMC 融合；XMC 的成对分歧 O(|ℳ|²)；JCPS++ 证书链随接触数线性甚至超线性增长；多机器人时共识/通信成本二次增长。**规模翻倍，实时预算先崩**，ERTC 只能触发降级，竞赛中降级即掉分。若用近似替代 μ/UKF/Pareto 却不给**误差界**，又会直接破坏 EGES 假设 A51–A55。
- **H38（证书不可组合·局部合格 ≠ 路径/编队安全）**：单个接触的 Cert_eeis 合格，不代表路径级安全：相邻接触的力/姿态/能量耦合、共享执行预算被前序检查点耗尽、机器人间碰撞与总线争用、证书在跨构型/跨固件/跨标定批次复用后失效。**没有组合代数与有效性区域，证书只是「每个点各自成立的幻觉」**。

## 0. 直觉与动机

**灵感 1（竞赛策略 → 风险预算投资组合 RBP）**
直觉：把每个检查点想成一笔**投资**。多花一点失效预算 δ_i、多花一点探针/时间，就能买来更高的成功率与得分；但全局安全预算 δ_total 是有限的，且有些标的是「一旦违约直接爆仓」（淘汰型检查点）。理性的竞赛策略不是「每笔都最保守」，而是**在硬性总风险约束下，把风险配置到边际得分增益最高的地方**——这就是水填充（water-filling）：内点最优满足 `w_i·g_i'(δ_i)=λ`，淘汰型检查点强制 `δ_i ≤ ε_cat`。更妙的是，**风险姿态应随名次变化**：领先时降方差、守成（exploit）；落后时在**已认证安全集内**提高方差、搏高分（explore）。这不是赌博，而是把「名次的效用曲率」显式写进风险预算，让安全预算服务于竞赛目标，而不是与竞赛目标对立。

**灵感 2（竞赛策略 → 对手建模与混合策略 OME）**
直觉：对手不是环境噪声，而是**对我方策略做最优响应的策略体**。安全但固定可预测的路线会被堵死、被卡位、被针对。因此要把对手策略 π' 当作隐变量维护信念 μ(π')，并选择**混合策略** σ 而不是单一策略；用在线镜像下降/虚拟对弈求解，使遗憾 `R_T ≤ O(√T)`、可利用性 `ε_expl` 有界。关键安全约束：**混合策略的支撑集必须完全落在已认证安全策略集 Σ_safe 内**——对手只能改变「得分」，不能通过诱导我方抽取未认证动作来改变「物理安全」。这条「安全不变性」把博弈论与安全证书解耦：博弈层在安全集内优化期望名次，安全层对每个被抽中的动作独立负责。

**灵感 3（可扩展性 → 组合可扩展证书 CSC）**
直觉：v59 的证书像「一次性体检报告」，本轮要把它变成「可组合的类型/证明对象」。一张证书 `C=(控制器参数, 保证 G, 残余风险 δ, 资源 res, 有效性区域 V, 依赖哈希, 版本)`：**V 是它在构型×执行状态×环境×固件/标定空间里仍然成立的那块区域**。证书可以**串联**（路径拼接，风险用联合界、资源相加、接口必须落在下一张的有效区域内）、**并联**（多机器人编队，风险按独立性合成再叠加干涉项）、**共享**（同一 δ_total/总线/热预算必须守恒，禁止「双重记账」）。于是扩容不等于重算：大多数时候只是**在缓存里命中一张仍然有效的证书**，或在脏分片上局部重算。证书复用必须过「有效性区域 + 依赖哈希 + 版本」三关，出区域即作废——这把 v59 的「时间鲜度」升级为**语义有效域**。

**灵感 4（可扩展性 → 分片增量证据 SIE + 认证近似 CA）**
直觉：规模化的敌人不是「计算量大」，而是「每次都为全量重算」。把区域/机器人分片，每片维护局部信念摘要、局部证书与边界状态；用依赖 DAG 做**脏传播**，只重算受影响的片；全局只组合边界摘要（δ、资源、边界状态、证书哈希），通信量随**接口**而非随全图增长。若某分片超时/离线，就把它视为 `δ=∞` 并保守绕行/停止，绝不拿陈旧摘要冒充新鲜证据。进一步，把最贵的 μ 分析、Pareto 投影、UKF、共形校准换成**输出可靠区间**的代理模型：只有区间上界仍满足约束才接受，否则回退精确计算；代理误差经共形校准并记入 `δ_ca`。**近似不是免费的，但可以被定价、被守界、被回退。**

**灵感 5（合流 → CSES 战略算子与 J_strat）**
直觉：在 v59 的 PCE+++ 之上加一层「战略层」：先全局规划候选路线/任务与评分模型，用 RBP 分配 δ 与算力预算；用 OME 维护对手信念并求混合策略；把路线切成分片，各分片在**分配到的局部预算**内跑 CLEP；再沿组合树拼出路径/编队证书；一旦组合失效、预算超支或分片陈旧，就重新分配/改道/降级，**从不放松硬安全预算**。赛后输出 `J_strat`：风险预算曲线、对手信念与混合策略、证书组合 DAG、分片映射与新鲜度、近似区间、得分估计与名次快照。三条单向通道继续成立：**信念更准、不确定性更大（组合/陈旧/近似项）、动作更保守（组合失败即降级）**；竞赛层只能在安全集内重新配置风险，永远不能突破 δ_total 或绕过证据门。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（竞赛目标与安全策略集）** 设路线 π=(cp_1,…,cp_n)（含节奏与探询策略），随机因素 ξ=(环境, 对手, 裁判/评分噪声)。得分
```
S(π,ξ) = Σ_{i:success} w_i + W_fin·1[完成] − c_T·T(π) − c_E·E(π) − c_F·N_fail(π)
任意 i∈C_cat 失败 ⇒ S(π,ξ) = −∞        # 淘汰型检查点
```
名次效用 U_rank(·) 单调，且依赖当前排行榜。安全策略集
```
Π_safe = { π | P(任一淘汰失败) ≤ δ_cat
             ∧ 路径证书 C_path 有效
             ∧ Σ_i δ_i ≤ δ_total
             ∧ 每检查点 δ_i ≤ δ_i^max }
```
竞赛目标为 `max_{σ∈Δ(Π_safe)} E[U_rank(S)] − λ_var·Var[S]`（或 CVaR_α）。**关键约束：优化变量只在 Π_safe 的凸包内，任何得分动机都不能扩大 Π_safe。**

**定义 154（风险预算分配 RBA）** 给定全局失效预算 δ_total、检查点权重 w_i、淘汰集 C_cat、成功率-风险曲线 g_i(δ_i)=P(success_i | 允许失效预算 δ_i)（单调不减、凹近似），定义
```
δ* = argmax_{δ} Σ_i w_i·g_i(δ_i) − λ_T·cost_time(δ_i) − λ_E·cost_energy(δ_i)
s.t.  Σ_i δ_i ≤ δ_total
      δ_i ∈ [δ_i^min, δ_i^max]
      i ∈ C_cat ⇒ δ_i ≤ ε_cat
```
内点最优满足水填充条件 `w_i·g_i'(δ_i) = λ`（λ 为预算影子价格）；边界点取截断。算力预算 B_comp 同构分配（以「每毫秒边际得分增益」为水位）。在线重分配带迟滞：名次领先 ⇒ 提高 λ_var、压低 δ_i 与探索；落后 ⇒ 在 Π_safe 内提高方差与关键点预算。**预算守恒是硬不变量：任何重分配后仍有 Σδ_i ≤ δ_total。**

**定义 155（对手建模与混合策略 OME）** 对手策略空间 Π_opp，信念 μ_t∈Δ(Π_opp)，鲁棒收益 `J(σ,μ)=E_{π~σ,π'~μ}[S(π,ξ(π'))]`。混合策略更新用在线镜像下降：
```
σ_{t+1} = Proj_{Δ(Π_safe)}( σ_t − η_t·∇_σ J(σ_t, μ_t) )
```
遗憾 `R_T = max_{σ*} Σ_t J(σ*,μ_t) − Σ_t J(σ_t,μ_t) ≤ O(√T)`；可利用性 `ε_expl = max_{π'} J(π',σ) − J(σ,σ)`。**安全不变性：supp(σ) ⊆ Π_safe**，故对手只能通过得分项影响我方，不能使我方执行未认证动作。

**定义 156（组合可扩展证书 CSC）** 证书 `C=(id, K, G, δ, res, V, deps, ver)`：K 控制器/参数快照，G 保证（μ 裕度、力限、跟踪误差），δ 残余失效概率，res=(WCET, 总线, 热, 能量, δ) 资源向量，V⊆Q×Ξ×E×F 为有效性区域（构型×执行状态×环境×固件/标定版本），deps 为假设哈希。组合算子：
```
串联  C1 ⊗_s C2：要求 post(V1) ⊆ pre(V2) ∩ V2
      δ_s = δ1 + δ2 − δ1δ2（独立可证时）否则 δ1 + δ2（联合界）
      res_s = res1 + res2；V_s = V1 ∩ {x | post(x) ∈ V2}
并联  ⊗_p {C_i}：δ_p = 1 − Π_i(1−δ_i) + δ_int     # δ_int 为碰撞/干涉上界
      res_p = Σ res_i + res_contention；V_p = ∩ V_i ∧ 无碰撞条件
共享  ⊗_b {C_i}：要求 Σ_i δ_i ≤ δ_total ∧ res 各分量 ≤ 预留
```
**组合健全性**：若 C_path = Compose({C_i}) 通过上述检查，则在该组合的有效区域 V_path 内，保证 G_path 成立且失效概率 ≤ δ_path。

**定义 157（证书有效域与语义鲜度）** `valid(x,C) ≡ x∈V(C) ∧ hash(deps)=C.deps_hash ∧ ver=C.ver`。证书的「新鲜」不再只由墙钟定义，而由**是否仍在有效域内、依赖是否变化**定义：状态离开 V(C) 或任一依赖哈希改变即**事件触发作废**（不等时间到期）。定义语义年龄 `τ_sem(C) = min{t | x(t)∉V(C) ∨ deps 变}`；仅当 `τ_sem ≤ τ_renew` 时可复用。这直接修补 v59 的漏洞：**时戳很新、构型已死**。

**定义 158（分片增量证据 SIE）** 将证据域划分为分片 `D={D_j}`；局部状态 `s_j=(b_j 摘要, {C_j}, δ_j, res_j, boundary_j, ver_j)`；依赖 DAG `G_dep`。更新时从变化节点出发做脏传播，只重算 `dirty(D_j)`；全局证书 `C_global = Compose({s_j})`，通信只传边界摘要。新鲜度契约：`age(s_j) ≤ τ_shard`，否则令 `δ_j=∞` 并标 `degraded=true`。增量代价 `O(|dirty| + |A|)`（A 为受影响接口），而非 `O(|D|)`。

**定义 159（认证近似 CA）** 对昂贵算子 f（μ 分析、Pareto 投影、UKF 后验、共形分位数、XMC 分歧），使用代理 f̂ 输出**可靠区间** `[L_f(x), U_f(x)]`，满足 `P(f(x)∈[L,U]) ≥ 1−α_ca`（由共形校准 + Lipschitz/量化误差给出）。约束检查只用保守端：稳定性用 `U_μ<1`，风险用 `U_δ≤δ_req`；若区间过宽或超界则回退精确 f。近似误差记入部署界的 `δ_ca`，**禁止无界近似**。

**定义 160（竞争性可扩展证据战略 CSES 与 J_strat）** 战略算子：

### IP-152 RBP（风险预算投资组合）

```python
class RiskBudgetPortfolio:
    def __init__(self, delta_total, delta_cat, eps_cat):
        self.delta_total, self.delta_cat, self.eps_cat = delta_total, delta_cat, eps_cat

    def allocate(self, checkpoints, score_model, leaderboard_gap):
        # 1) 每个检查点的成功率-风险曲线 g_i(δ) 与时间/能量成本
        curves = [self.fit_success_curve(cp, score_model) for cp in checkpoints]
        w = np.array([score_model.weight(cp) for cp in checkpoints])
        caps = np.array([self.eps_cat if cp in score_model.catastrophic
                         else score_model.delta_max(cp) for cp in checkpoints])
        floor = np.array([self.delta_min(cp) for cp in checkpoints])

        # 2) 名次姿态：落后允许在安全集内提高方差（等价于降低 λ_T），领先收紧
        lam_T = self.risk_posture(leaderboard_gap)   # 单调：gap<0 更保守

        # 3) 水填充：对偶变量 λ 二分，δ_i = clip(g_i'^{-1}(λ/w_i), floor, caps)
        lo, hi = 0.0, 1e6
        for _ in range(60):
            lam = 0.5 * (lo + hi)
            d = np.array([np.clip(self.inv_marginal(c, lam / w[i]), floor[i], caps[i])
                          for i, c in enumerate(curves)])
            if d.sum() > self.delta_total: lo = lam
            else: hi = lam
        delta = np.array([np.clip(self.inv_marginal(c, hi / w[i]), floor[i], caps[i])
                          for i, c in enumerate(curves)])
        # 4) 守恒校正：超预算则按边际得分最小者削减；有余量优先给淘汰型留底
        delta = self.conserve(delta, caps, floor, self.delta_total)
        return delta, self.allocate_compute(delta, checkpoints, w)
```

### IP-153 OME（对手建模与混合策略）

```python
class OpponentModelEstimator:
    def __init__(self, policy_basis, eta=0.05):
        self.mu = np.ones(len(policy_basis)) / len(policy_basis)  # 对手策略单纯形
        self.basis, self.eta = policy_basis, eta
        self.sigma = None

    def update(self, opponent_observation):
        # 贝叶斯更新对手策略信念（可换成粒子滤波）
        lik = np.array([p.likelihood(opponent_observation) for p in self.basis])
        self.mu = self.normalize(self.mu * lik)

    def solve(self, route_candidates, safe_mask, score_fn, T=50):
        # 在线镜像下降，支撑集仅覆盖已认证安全策略
        sigma = np.where(safe_mask, 1.0 / safe_mask.sum(), 0.0)
        for _ in range(T):
            grad = self.expected_score_grad(sigma, route_candidates, self.mu, score_fn)
            sigma = self.proj_simplex(sigma - self.eta * grad, mask=safe_mask)
        expl = self.exploitability(sigma, route_candidates, score_fn)
        return MixedStrategy(sigma=sigma, exploitability=expl, belief=self.mu)
```

### IP-155 SIE（分片增量证据引擎）

```python
class ShardedIncrementalEngine:
    def __init__(self, shards, dep_graph, tau_shard):
        self.shards, self.dag, self.tau = shards, dep_graph, tau_shard

    def invalidate(self, changed_facts):
        dirty = set()
        stack = list(changed_facts)
        while stack:                       # 依赖 DAG 脏传播
            f = stack.pop()
            for j in self.dag.dependents(f):
                if j not in dirty:
                    dirty.add(j); stack.append(j)
        return dirty

    def refresh(self, dirty, budget):
        for j in sorted(dirty, key=self.criticality):
            if budget.remaining() <= 0:
                self.shards[j].mark_stale()   # 陈旧 ⇒ δ_j=∞
                continue
            self.shards[j] = CLEP_shard(self.shards[j].model, self.shards[j].delta_alloc,
                                        budget.slice(j))
        return self.compose_boundary_summaries()

    def compose_boundary_summaries(self):
        summaries = []
        for s in self.shards:
            if s.stale or s.age > self.tau:
                summaries.append(StaleSummary(delta=float("inf"), degraded=True))
            else:
                summaries.append(s.boundary_summary())
        return CertificateAlgebra().compose_parallel_or_serial(summaries)
```

```python
class CertifiedApproximator:
    def __init__(self, surrogate, conformal_calibrator, alpha_ca):
        self.f, self.cal, self.alpha = surrogate, conformal_calibrator, alpha_ca

    def interval(self, x):
        q = self.cal.quantile(1 - self.alpha)       # 共形半径
        m = self.f(x)
        return (m - q - self.f.lipschitz_error(x),
                m + q + self.f.lipschitz_error(x))

    def safe_eval(self, x, constraint, exact_fn, budget):
        L, U = self.interval(x)
        if constraint.upper_ok(U):
            return U, "approx_ok"
        if budget.allows_exact():
            return exact_fn(x), "exact_fallback"
        return float("inf"), "degrade"             # 无法认证 ⇒ 保守降级
```

**正确性定理（Competitive Compositional Soundness, CCS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** 评分模型 S 与名次效用 U_rank 诚实上界真实得分（含时间/能量/失败惩罚）；**(A57)** RBA 预算守恒、淘汰型留底、重分配单调（不会把已花预算重复使用）；**(A58)** OME 对手信念按贝叶斯/无遗憾更新，混合策略支撑集完全落在 Π_safe，安全不变性成立；**(A59)** CSC 三算子健全，且独立性判定、干涉上界、资源争用上界诚实；**(A60)** SIE 脏传播完备（无漏标脏分片），新鲜度契约 τ_shard 诚实，陈旧分片被判 δ=∞；**(A61)** CA 区间覆盖真实值概率 ≥1−α_ca，Lipschitz/量化误差上界诚实；**(A62)** 证书缓存命中条件 `valid(x,C)` 完整（区域、依赖哈希、版本三者齐备）。则：

1. **全局安全预算守恒**：任意时刻 `Σ_i δ_i ≤ δ_total`，且淘汰型检查点 `δ_i ≤ ε_cat`；竞赛层调整风险姿态前后该不变量不变。
2. **组合证书健全性**：若 `C_path` 被接受，则在其有效区域 V_path 内，路径级保证成立且失效概率 ≤ `Σδ_i + δ_int + δ_stale + δ_ca`。
3. **战略不可越权**：对手建模与混合策略只能改变期望得分，不能使系统执行 Π_safe 之外的动作；落后时的「升方差」仍受硬安全预算与证据门约束。
4. **增量复用健全性**：任何缓存命中都必须通过有效性区域、依赖哈希、版本三关；离开区域或依赖变化即刻作废；陈旧分片按 δ=∞ 处理，不得被组合为「新鲜证据」。
5. **近似可定价**：所有认证近似只以保守端参与约束检查；代理区间不满足时精确回退，否则降级；`δ_ca` 显式计入部署界。
6. **终止性与规模**：CSES 在 `k_probes + k_cons + k_ft + k_ux + k_exec` 与有限战略重规划次数内终止于 {承诺(带组合证书), 改道, 降档, L2 协商, 安全停, 执行降级停}；增量刷新代价与脏集和接口规模成正比，而非与全域规模成正比。
7. **部署界**（对检查点/分片取联合界）：

```
P_safe ≥ 1 − [ Σ_i δ_i^alloc + δ_comp + δ_stale + δ_int + δ_ca + δ_opp_model ]
         − P(评分/规则模型结构性错误未检出) − P(有效性区域外命中缓存)
         − P(脏传播漏标) − P(组合 DAG 审计失败) − P(护盾回退失败)
```

关键：**RBP 把「安全预算」从逐点常数变成可投资组合**——按边际得分增益水填充，淘汰型留底，名次决定风险姿态但绝不突破 δ_total；**OME 把「对手」变成可在安全集内博弈的策略性隐变量**——混合策略降低可利用性，但随机化不越安全界；**CSC 把「证书」变成可串联/并联/共享的证明对象**——组合健全性 + 有效区域让局部证书可安全复用；**SIE 把「规模」变成脏集与接口问题**——增量刷新、陈旧即 ∞、通信随边界而非全域；**CA 把「近似」变成可定价的可靠区间**——超界回退，误差入账；**CSES 在 v59 之上加战略层**，让竞赛目标与安全约束不再对立。

```python
        # gap>0 领先：降低探索、收紧风险；gap<0 落后：安全集内提高方差
        return BASE_LAMBDA_T * (1.0 + K_POSTURE * max(0.0, leaderboard_gap)) \
               / (1.0 + K_POSTURE * max(0.0, -leaderboard_gap))

    def allocate(self, checkpoints, score_model, leaderboard_gap):
        w = np.array([score_model.weight(cp) for cp in checkpoints])
        curves = [self.fit_success_curve(cp, score_model) for cp in checkpoints]
        caps = np.array([self.eps_cat if score_model.is_catastrophic(cp)
                         else score_model.delta_max(cp) for cp in checkpoints])
        floor = np.array([self.delta_min(cp) for cp in checkpoints])
        lam_T = self.risk_posture(leaderboard_gap)

        # 对偶二分求水填充水位 λ：w_i g_i'(δ_i) = λ
        lo, hi = 0.0, LAMBDA_MAX
        for _ in range(64):
            lam = 0.5 * (lo + hi)
            d = np.array([np.clip(self.inv_marginal(curves[i], lam / w[i]),
                                  floor[i], caps[i]) for i in range(len(w))])
            if d.sum() > self.delta_total:
                lo = lam
            else:
                hi = lam
        delta = np.array([np.clip(self.inv_marginal(curves[i], hi / w[i]),
                                  floor[i], caps[i]) for i in range(len(w))])
        delta = self.conserve(delta, caps, floor)      # 守恒校正
        comp = self.allocate_compute(delta, checkpoints, w, score_model)
        return delta, comp

    def conserve(self, delta, caps, floor):
        over = delta.sum() - self.delta_total
        while over > 1e-12:                            # 按边际得分最小者削减
            order = np.argsort([self.marginal_gain(i, delta[i]) for i in range(len(delta))])
            for i in order:
                take = min(over, delta[i] - floor[i])
                if take > 0:
                    delta[i] -= take; over -= take
                    break
            else:
                break
        return delta

    def allocate_compute(self, delta, checkpoints, w, score_model):
        # 算力预算同构水填充：每毫秒边际得分增益为水位
        return waterfill_compute([score_model.marginal_score_per_ms(cp, delta[i])
                                  for i, cp in enumerate(checkpoints)], self.B_comp)
```

### IP-153 OME（对手建模与混合策略）

```python
class OpponentModelEstimator:
    def __init__(self, policy_basis, eta=0.05):
        self.basis = policy_basis
        self.mu = np.ones(len(policy_basis)) / len(policy_basis)
        self.eta = eta

    def update(self, observation):
        lik = np.array([p.likelihood(observation) for p in self.basis]) + 1e-12
        self.mu = lik / lik.sum()

    def solve(self, route_candidates, safe_mask, score_fn, T=32, clip=1.0):
        sigma = np.where(safe_mask, 1.0 / max(safe_mask.sum(), 1), 0.0)
        for _ in range(T):
            grad = self.expected_score_grad(sigma, route_candidates, self.mu, score_fn)
            sigma = project_simplex(sigma - self.eta * grad, mask=safe_mask)
        # 安全不变性：再次清零非安全支撑，防止投影数值泄漏
        sigma = np.where(safe_mask, sigma, 0.0)
        sigma = sigma / sigma.sum()
        return MixedStrategy(sigma=sigma,
                             exploitability=self.exploitability(sigma, route_candidates, score_fn),
                             belief=self.mu.copy(),
                             safety_invariant=True)

    def expected_score_grad(self, sigma, candidates, mu, score_fn):
        # E_{π~σ,π'~μ}[S(π,π')] 对 σ 的梯度
        payoff = np.array([sum(mu[k] * score_fn(candidates[i], self.basis[k])
                               for k in range(len(self.basis)))
                           for i in range(len(candidates))])
        return payoff

    def exploitability(self, sigma, candidates, score_fn):
        best = max(sum(sigma[i] * score_fn(candidates[i], p)
                       for i in range(len(candidates)))
                   for p in self.basis)
        own = sum(sigma[i] * sum(self.mu[k] * score_fn(candidates[i], self.basis[k])
                                 for k in range(len(self.basis)))
                  for i in range(len(candidates)))
        return best - own
```

### IP-154 CSC（证书组合代数）

```python
@dataclass
class Cert:
    id: str
    K: object                 # 控制器/阻抗参数快照
    G: dict                   # 保证：mu_margin, force_bound, tracking_q99, ...
    delta: float              # 残余失效概率
    res: ResourceVector       # WCET, bus, thermal, energy, delta
    V: ValidityRegion         # 构型×执行状态×环境×固件/标定
    deps: str                 # 依赖哈希
    ver: int

class CertificateAlgebra:
    def valid_at(self, x, C):
        return (C.V.contains(x) and
                C.deps == current_deps_hash(C) and
                C.ver == current_version(C))

    def compose_serial(self, C1, C2, interface_state, budget):
        if not (self.valid_at(interface_state, C1) and self.valid_at(interface_state, C2)):
            return Invalid("interface_outside_valid_region")
        delta = C1.delta + C2.delta - (C1.delta * C2.delta if self.certified_independent(C1, C2) else 0.0)
        if delta > budget:
            return Invalid("serial_delta_over_budget")
        return Cert(id=new_id(), K=(C1.K, C2.K), G=self.chain_G(C1, C2),
                    delta=delta, res=C1.res + C2.res,
                    V=self.forward_intersection(C1, C2), deps=hash_deps(C1, C2),
                    ver=max(C1.ver, C2.ver))

    def compose_parallel(self, certs, interference_bound, contention_res):
        if not self.no_collision_condition(certs):
            return Invalid("unbounded_interference")
        delta = 1.0 - np.prod([1.0 - C.delta for C in certs]) + interference_bound
        return Cert(id=new_id(), G=self.parallel_G(certs), delta=delta,
                    res=sum_res(certs) + contention_res,
                    V=intersect_all([C.V for C in certs]),
                    deps=hash_deps(*certs), ver=max(C.ver for C in certs))

    def compose_shared(self, certs, delta_total, reserve):
        if sum(C.delta for C in certs) > delta_total:
            return Invalid("delta_budget_double_spent")
        if not dominates(reserve, sum_res(certs)):
            return Invalid("resource_overcommit")
        return Cert(id=new_id(), G=self.shared_G(certs),
                    delta=sum(C.delta for C in certs),
                    res=sum_res(certs), V=intersect_all([C.V for C in certs]),
                    deps=hash_deps(*certs), ver=max(C.ver for C in certs))
```

### IP-155 SIE（分片增量证据引擎）

```python
class ShardedIncrementalEngine:
    def __init__(self, shards, dep_graph, tau_shard):
        self.shards, self.dag, self.tau = shards, dep_graph, tau_shard

    def invalidate(self, changed_facts):
        dirty, seen, stack = set(), set(changed_facts), list(changed_facts)
        while stack:
            f = stack.pop()
            for j in self.dag.dependents(f):
                if j not in dirty:
                    dirty.add(j)
                    stack.extend(self.dag.facts_of(j))   # 级联脏传播
        return dirty

    def refresh(self, dirty, budget):
        # 关键分片优先；预算不足者标陈旧，绝不拿旧摘要冒充新证据
        for j in sorted(dirty, key=lambda j: self.shards[j].criticality, reverse=True):
            if budget.remaining() <= 0:
                self.shards[j].mark_stale(reason="budget_exhausted")
                continue
            self.shards[j] = clep_shard(self.shards[j], budget.slice_for(j))
        return self.compose()

    def compose(self):
        summaries = []
        for s in self.shards:
            if s.stale or s.age() > self.tau:
                summaries.append(StaleSummary(delta=float("inf"), degraded=True))
            else:
                summaries.append(s.boundary_summary())
        # 单机按检查点串联；多机按并联 + 干涉/争用
        if len(self.shards) == 1:
            return CertificateAlgebra().compose_serial_chain(summaries)
        return CertificateAlgebra().compose_parallel(summaries,
                                                     self.interference_bound(),
                                                     self.contention_res())
```

```python
class CertifiedApproximator:
    def __init__(self, surrogate, conformal, alpha_ca, lipschitz):
        self.f, self.cal, self.alpha, self.L = surrogate, conformal, alpha_ca, lipschitz

    def interval(self, x):
        q = self.cal.radius(1 - self.alpha) + self.L * self.f.quantization_error(x)
        m = self.f(x)
        return m - q, m + q

    def checked(self, x, constraint, exact_fn, budget):
        lo, hi = self.interval(x)
        if constraint.accepts_upper(hi):          # 只信保守端
            return hi, "approx"
        if budget.allows_exact():
            return exact_fn(x), "exact_fallback"
        return float("inf"), "degrade"            # 无法认证 ⇒ 保守
```

### IP-157 CSES（竞争性可扩展证据战略算子）

```python
def competitive_scalable_evidence_strategy(M, task, delta_total, B_total, leaderboard):
    # ① 全局规划与评分模型
    route_cands, score_model = plan_on_map(M, task)
    # ② 风险与算力预算组合（预算守恒）
    rbp = RiskBudgetPortfolio(delta_total, score_model.delta_cat, score_model.eps_cat,
                              score_model.delta_min)
    delta_alloc, comp_alloc = rbp.allocate(route_cands.best, score_model, leaderboard.gap)
    assert delta_alloc.sum() <= delta_total + 1e-12
    # ③ 对手信念 + 安全混合策略
    ome = OpponentModelEstimator(route_cands.policy_basis)
    ome.update(M.opponent_history)
    sigma = ome.solve(route_cands, M.safe_mask, score_model.score)
    route = route_cands.sample(sigma)
    # ④ 分片 + 依赖 DAG 脏传播
    sie = ShardedIncrementalEngine(M.shards_for(route), M.dep_graph, M.tau_shard)
    dirty = sie.invalidate(M.changed_facts())
    # ⑤ 预算化局部 CLEP（每片只花分配到的 δ 与算力）
    for j in dirty:
        M.shards[j] = clep_shard(M.shards[j], delta_alloc[j], comp_alloc[j])
    # ⑥ 证书组合（串/并/共享）；失败只准更保守
    csc = CertificateAlgebra()
    C_path = csc.compose(route, M.shards, delta_total)
    if isinstance(C_path, Invalid):
        return rebalance_or_degrade(M, route, reason=str(C_path))
    if sie.any_stale() or C_path.delta > delta_total:
        return rebalance_or_degrade(M, route, reason="stale_or_delta_overrun")
    # ⑦ 下发 + 收集执行证据
    dispatch_route(route, M.shards, C_path)
    M = collect_and_update(M, route)
    # ⑧ 名次反馈 → 只在安全集内调整风险姿态
    leaderboard.observe()
    M = adjust_risk_posture(M, leaderboard, delta_total)
    # ⑨ 战略证书
    J_strat = build_strategy_certificate(
        score_model=score_model, delta_alloc=delta_alloc, comp_alloc=comp_alloc,
        mu_opp=ome.mu, sigma=sigma, C_path=C_path, shard_snapshot=sie.snapshot(),
        ca_intervals=M.ca_log, S_est=score_model.estimate(route),
        leaderboard=leaderboard.snapshot(), J_exec_chain=M.J_exec_log)
    return route, M, J_strat
```

### IP-158 J_strat（战略证书）

```python
@dataclass
class StrategyCertificate:
    score_model_id: str
    delta_alloc: list             # 每检查点风险预算
    compute_alloc: list
    opponent_belief: list
    mixed_strategy: list
    cert_composition_dag: object  # CSC 组合 DAG

    semantic_age_map: dict
    ca_intervals: list
    score_estimate: float

    budget_invariant_log: list    # Σδ_i ≤ δ_total 的逐步审计

    version: int
    timestamp: float

    def verify(self):
        # 1) 预算守恒：每一步分配都不得超 δ_total
        if any(s["sum_delta"] > s["delta_total"] + 1e-12 for s in self.budget_invariant_log):
            return False
        # 2) 混合策略只落在安全支撑
        if any(not s["in_safe_set"] for s in self.mixed_strategy):

            return False
        return True
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RBP | O(n·(log(1/ε)+C_g)) | O(n) | 预算守恒 Σδ_i≤δ_total；淘汰型 δ_i≤ε_cat |
| OME | O(\|Π_opp\|·d + T·d)/轮 | O(\|Π_opp\|+d) | 遗憾 O(√T)；可利用性有界；supp(σ)⊆Π_safe |
| CSC | O(\|deps\|) 校验；O(1) 缓存命中 | O(\|C\|+DAG) | 串/并/共享健全；超预算即 Invalid |
| SIE | O(\|dirty\|+\|A\|) | O(\|D\|·摘要) | 脏传播完备；陈旧/离线 δ=∞ |
| CA | O(1)/查询 + 离线校准 | O(模型+校准集) | 区间覆盖 ≥1−α_ca；超界回退 |
| CSES | O(\|dirty\|·CLEP+\|C\|·compose+\|Π_opp\|·d) | 复用组件 | 战略层不扩 Π_safe；终止性 |

**正确性定理（Competitive Compositional Soundness, CCS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** 评分模型与名次效用诚实上界真实得分（含时间/能量/失败惩罚）；**(A57)** RBA 预算守恒、淘汰型留底、重分配单调；**(A58)** OME 信念按贝叶斯/无遗憾更新，混合策略支撑集完全落在 Π_safe；**(A59)** CSC 三算子健全，独立性判定、干涉上界、资源争用上界诚实；**(A60)** SIE 脏传播完备、新鲜度契约诚实、陈旧分片被判 δ=∞；**(A61)** CA 区间覆盖 ≥1−α_ca，Lipschitz/量化误差上界诚实；**(A62)** 缓存命中条件 `valid(x,C)` 完整（区域、依赖哈希、版本齐备）。则：

1. **全局安全预算守恒**：任意时刻 `Σ_i δ_i ≤ δ_total`，淘汰型 `δ_i ≤ ε_cat`；风险姿态调整前后不变量成立。
2. **组合证书健全性**：若 `C_path` 被接受，则在其有效区域 V_path 内，路径级保证成立，失效概率 ≤ `Σδ_i + δ_int + δ_stale + δ_ca`。
3. **战略不可越权**：对手建模与混合策略只改变期望得分，不能使系统执行 Π_safe 之外的动作；落后时的「升方差」仍受硬安全预算与证据门约束。
4. **增量复用健全性**：缓存命中必须通过有效性区域、依赖哈希、版本三关；离开区域或依赖变化即刻作废；陈旧分片按 δ=∞ 处理。
5. **近似可定价**：认证近似只以保守端参与约束检查；区间不满足则精确回退，否则降级；`δ_ca` 显式计入部署界。
6. **终止性与规模**：CSES 在有限探询/承诺/微调/解释/执行次数与有限战略重规划次数内终止于 {承诺(带组合证书), 改道, 降档, L2 协商, 安全停, 执行降级停}；增量刷新代价随脏集与接口规模，而非全域规模。
7. **部署界**（对检查点/分片取联合界）：

```
P_safe ≥ 1 − [ Σ_i δ_i^alloc + δ_comp + δ_stale + δ_int + δ_ca + δ_opp_model ]
         − P(评分/规则模型结构性错误未检出) − P(有效性区域外命中缓存)
         − P(脏传播漏标) − P(组合 DAG 审计失败) − P(护盾回退失败)
```

关键：**RBP** 把安全预算变成可投资组合（水填充、淘汰留底、名次姿态、预算守恒）；**OME** 把对手变成安全集内可博弈的策略性隐变量（混合策略、遗憾界、可利用性）；**CSC** 把证书变成可串联/并联/共享的证明对象（有效区域、组合健全、资源/干涉入账）；**SIE** 把规模变成脏集与接口问题（增量、边界摘要、陈旧即 ∞）；**CA** 把近似变成可定价的可靠区间（保守端、回退、误差入账）；**CSES** 在 v59 的 PCE+++ 之上加战略层，让竞赛目标与安全约束不再对立；**J_strat** 让整条战略链可审计、可复现、可回放。
