# 第 14 轮（新灵感循环第 5 轮；本轮灵感：「UniBot」×「视觉感知」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTD（定义 583–594；引理 113–121；实验 E627–E646）。
> 本轮纪律：**感知歧义集证书 + 通用只经接地 + 主动感知的单向扩张**。不推倒 v13：v13 的 AIO/CPD/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。三个新组件——UEG（通用体身接地，含 CEGC）、PAC（感知歧义证书，含 PASC）、APO（主动感知算子）——一律以**中立元**接入，失效即严格退回 v13（引理 128），再沿 v13 退化链退回 v12/v11/v10/v9/v8/v7/v6。本轮只做三件事：把"视觉感知"从点估计改写为**必含真值的歧义集**、把"UniBot 的通用"从模型能力改写为**可迁移的证书**、把"看"从廉价预处理改写为**能扩张授权的主动算子**。

## 0. 直觉与动机

**灵感 1（UniBot → 通用体身策略的"通用"必须被证书化）**
直觉：UniBot 的卖点是"一个大脑驱动多种身体"——共享视觉-运动潜空间，跨本体迁移技能。但"通用"是关于**训练分布**的陈述，不是关于"此刻这台机器人在这个视角下"的陈述。同一块 RGB-D 像素，对不同臂长、不同相机外参、不同接触刚度、不同负载的身体，意味着不同的可达性、不同的接触几何、不同的动力学。通用先验最自信的地方，恰好是训练数据最密的地方；而它最危险的地方，是视觉与物理交界的薄边界：玻璃、镜面、被自身手臂遮挡的区域、新装相机。于是核心创新是：**把通用性做成可迁移的证书，而不是可宣称的能力**。共享潜变量只能经**每体身份接地适配器**转成可执行动作，并且必须携带**跨体接地间隙证书（Cross-Embodiment Gap Certificate, CEGC）** `U_e`：它单侧界定"共享 UniBot 比该体专用 v13 策略乐观了多少"。通用先验只允许**提议**，永不允许**授权**。

**灵感 2（视觉感知 → 把感知从点估计改写为含真值的歧义集）**
直觉：现有感知输出一个点估计（6D 位姿、深度、接触点），安全层默认它为真。但视觉误差是**结构化**的：边缘深度、透明/反光物体、自遮挡、运动模糊、标定漂移。正确的对象不是一个点，而是一个**在当前图像证据下与真值相容的状态集合** `S(o)`，覆盖率 `P(s*∈S(o)) ≥ 1−α_p`。于是动作授权的语义变成对集合的**全称量化**：`a` 被允许，当且仅当 `S(o)` 中**每一个**状态都在 v13 下被认证。直觉一句话：**看不清，就当作所有看得清的可能状态都必须安全**。这把视觉误差从"不可控噪声"转成"状态集半径 `r=rad(S(o))`"，再用安全余量的 Lipschitz 传输把半径压成一条可检查的不等式 `m(ŝ,a) ≥ L·r`。

**灵感 3（UniBot × 视觉感知 → 以视觉为索引的通用—特定分解与主动感知）**
直觉：如果视觉是证书，那么"再看一眼"本身就是一种有证书价值的动作：换视角、变焦、降速、主动探触，都能**单调缩小**歧义集，从而**单调扩张**授权集。预算应花在"单位毫秒能缩小多少状态半径、能换回多少授权价值"最大的感知动作上，而不是盲目多推一次网络。跨体方面，让 UniBot 既通用又不鲁莽的唯一办法是：**一个共享感知骨干 + 每体视觉接地适配器 + 主动感知去消解共享先验无法分辨的体身特有歧义**。核心创新：**主动感知算子（Active Perception Operator, APO）** 与 **视觉感知路由器（Visual Perception Router, VPR）**。这把"通用"和"感知"合成同一个对象：一条**以状态集半径 `r` 为索引的授权阶梯**——看得越清、体身接地越可信，放行越多，但永不超过 v13。

**三者如何统一**
统一为 **v13 实时实现层之上的感知接地层**：v13 回答"在给定毫秒预算内，哪些动作被证书允许"（`Exec_v13`）；v14 回答"在视觉此刻能分辨的状态集合上、对这台具体身体、这些被允许的动作里还有哪些整体成立"（`Exec_v14`）。UEG 把通用潜变量压成受体身接地约束的提议；PAC 把感知压成含真值的歧义集与全称量化的安全证书；APO 把"看"做成单向收缩算子；VPR 在 `B_perc` 内选感知动作并做视觉漂移塌缩。共享状态 `ζ_p=(S_k,r_k,e,U_e,PASC,B_perc,drift_vis,mode)`。**UEG 回答"这个提议属于哪具身体、能信多少"，PAC 回答"此刻哪些状态无法区分、动作必须对所有状态成立"，APO/VPR 回答"再花多少毫秒看，才值得把授权从哪一档抬到哪一档"**。三者不是三个视觉补丁，而是"歧义—接地—观察"的证书链，且 `Exec_v14 ⊆ Exec_v13 ⊆ Exec_v12`。

## 1. 研究问题（轮次升级版）

- **Q1（感知歧义集的可靠性）**：如何构造 `S(o)` 才使其在遮挡、透明/反光、新视角、标定漂移下仍以 `≥1−α_p` 覆盖真值？对 6D 位姿、深度、接触点、物体外延分别做共形区间再合成集合，如何控制合成后的覆盖率与体积？支撑外（新物体/新相机）如何检测并禁止使用？
- **Q2（感知—动作证书的可证性与非空性）**：`∀s∈S(o)` 的全称量化何时不退化空集？用 Lipschitz 余量传输 `m(ŝ)≥L·r` 近似全称量化时，`L` 如何保守估计？`S` 收缩与授权扩张的单调性在组合模块（USG→TGC→HDT→BAA→v13）上如何保持？感知证书与 v13 的 TGC/UC/DGC 如何合取而不重复计错？
- **Q3（UniBot 的通用—特定分解）**：共享潜变量中哪些维度跨体可迁移、哪些必须由体身接地适配器重建（运动学、相机外参、接触刚度）？CEGC 的 `U_e` 如何在目标体少量校准数据下给出单侧界？"越通用越保守"是否存在可证的下界？
- **Q4（与 v13 的兼容、活性与退化）**：PAC/APO 能否绕过 v13 的 DGC/TGC/RTIC？感知预算是否会挤占 v13 的安全切片 `B_safe`？主动感知塌缩到被动后是否频繁清空可行集、导致 `a_ask` 爆炸？能否严格退回 v13，并守住 50Hz/p99≤22ms？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 感知即证书律（Perception as Certificate）**
不存在"点估计可执行"。每个进入安全关键路径的动作必须携带感知证书：歧义集 `S(o)` 以 `≥1−α_p` 覆盖真值，且动作对 `S(o)` 中**所有**状态通过 v13 认证。禁止用点估计直接执行；点估计只允许作为 `S(o)` 的中心与采样锚点。感知证书必须与 v13 的物理/接触/谐波/规范/gap/DGC/RTIC 证书**合取**，不得替代或放宽任何一项。

**P26 通用只经接地律（Universality Only Through Grounding）**
UniBot 的共享潜变量 `z=Φ(o)` 不得直接产生可执行动作；必须先经当前体身份 `e` 的接地适配器 `g_e`，且 `z` 落在共享支撑域内、`U_e ≤ B_emb`。通用先验只做**提议**与**预筛**；授权只能由体身接地的 v13 证书给出。跨体共享不得成为绕过任何单体验证的通道。

**P27 主动感知单向扩张律（Active Perception Only Expands）**
主动感知只能**单调收缩**歧义集 `S_k⊆S_{k-1}`，因而只能**单调扩张**授权集 `Acc^vis_k⊇Acc^vis_{k-1}`，且 `Acc^vis_k⊆Acc_v13`。任何时刻停止观察都返回一个仍含真值、因而仍然安全的更大集合；预算收缩只能"少看"，绝不能"假设看见"。主动感知不得改变物理状态到不可回退点（探触须在 `P^rt` 内）。

## 3. 与基线的接口（如何退化）

- UEG 失效 ⇒ 注入中立元：`Φ` 退化为每体 v13 专用策略，无共享潜变量、无跨体提议，`U_e≡+∞` 只表示"禁用共享"；PAC/APO/VPR 仍可作用于该策略，即**v13 + 视觉证书**；
- PAC 失效 ⇒ 歧义集退化为单点 `S(o)={ŝ}`，PASC 等价 v13 的点估计检查，**等价 v13 安全语义**；
- APO 失效 ⇒ 无主动感知，固定被动视角，`r` 不可再收缩，**等价被动 v13 + PAC**；
- VPR 失效 ⇒ 固定感知预算与固定被动视角，由 v13 静态调度主导，**等价 v13 调度 + 感知证书门**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTD v13，再沿 v13 退化链退回 v12/v11/v10/v9/v8/v7/v6；
- **安全继承**：UEG 只提议、PAC 只对状态集做全称量化、APO 只收缩状态集、VPR 只分配感知预算。四端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v14⊆Exec_v13` 由引理 123 保证。

## 4. 预期贡献

1. **感知歧义集与全称量化安全证书**：把"视觉感知"从点估计改写为含真值的状态集与 `∀s∈S` 的授权语义，给出覆盖率、集合体积与 Lipschitz 余量传输的可证关系，填补"视觉误差如何在安全关键执行层被证明地吸收"的空白；
2. **通用只经接地的跨体证书**：把 UniBot 的"通用"改写为共享潜变量 + 每体接地适配器 + CEGC 单侧间隙，给出 `Acc_Ue⊆Acc_v13,e` 的共形保证与"越通用越保守"的下界，避免共享先验成为绕过单体验证的旁路；
3. **主动感知作为单向授权扩张算子**：把"看"变成可中断、单调收缩、以毫秒为索引的算子，使系统能在遮挡/反光/新视角下用观察买回授权，而不是用猜测赌安全；
4. **感知层—实时层—语义层三层分离**：v12/v13 管"允许什么/时限内能实现多少"，v14 管"对此刻可分辨的状态集是否整体成立"；`Exec_v14⊆Exec_v13⊆Exec_v12` 把感知风险与执行风险解耦；E647–E666 覆盖歧义集覆盖、全称量化、跨体间隙、主动感知、视觉漂移塌缩与消融。

## 5. 本轮最大风险

**一句话**：感知证书的全部安全性都押在"真值落在 `S(o)` 内"这一条上，而视觉失效的典型形态恰恰是**支撑外**（透明/镜面、极端光照、新视角、标定漂移）——此时 UniBot 的共享先验仍会给出一个视觉上非常合理、跨体语言上非常连贯的提议，PAC 又会围绕一个**错误的中心**构造出一个"内部自洽"的歧义集；系统于是证明了"对所有 `s∈S(o)` 都安全"，却不知道真实的 `s*` 根本不在 `S(o)` 里——即**感知盲区中的、体身自洽的、被普遍量化证书背书的绝对错误决定**。

**定义 595（UniBot 通用体身策略 Universal Embodiment Policy）** 一个 UniBot 策略是
```
U = ( Φ, { (g_e, ψ_e) }_{e∈E}, π_0 ; supp_E )
z = Φ(o) ,   Z_e = g_e(z, o_e) ,   a ∼ ψ_e(Z_e) ,
```
其中 `Φ` 是跨体共享的视觉-运动编码器，`o_e` 是体身特有观测量（关节编码器、相机外参、负载、接触刚度估计），`g_e` 是**接地适配器**，`ψ_e` 是动作解码器。要求：
1. **唯一执行通道**：只有 `ψ_e∘g_e` 可产生可执行动作；`Φ` 或 `π_0` 的直接输出只能是候选/提议；
2. **体身注册**：`e∈supp_E`，且 `e` 的运动学、相机外参与接触参数带有可核验证书；
3. **支撑约束**：`z` 必须落在共享潜变量支撑域内，否则禁止跨体复用；
4. **提议—授权分离**：`U` 的输出不构成授权，授权只由定义 597 的 PASC 与 v13 证书给出。

**定义 596（视觉感知歧义集 Perception Ambiguity Set）** 感知模块在覆盖率水平 `α_p` 下输出
```
P : (o, α_p) ↦ S(o) ⊆ State ,   s.t.  P( s* ∈ S(o) ) ≥ 1 − α_p ,
r(o) := rad(S(o)) = sup_{s,s'∈S(o)} d(s,s') .
```
构造：分别对 6D 位姿、深度、接触斑中心/面积、物体外延做分裂共形区间，再按通道做笛卡尔积/并集；各通道 `α` 用 Bonferroni 或加权共形分配。`S(o)` 必须显式绑定支撑签名（光照区间、视角区间、材质类别、相机标定版本）；签出支撑即视为无证书。

**定义 597（感知—动作安全证书 PASC）** 动作 `a` 在观测 `o` 下被**视觉认证**当且仅当
```
a ∈ Acc^vis(o) := { a ∈ A : a ∈ Acc_v13(ŝ)  ∧  ∀s∈S(o) : a ∈ Exec_v13(s) } .
```
其中 `ŝ` 是 `S(o)` 的中心/代表点，用于 v13 的 RTCR 选档；`Exec_v13(s)` 是在状态 `s` 下重算的 v13 执行集（物理/接触/谐波/规范/gap/DGC/RTIC 全部合取）。`Acc^vis` 是**全称量化**授权集：只要集合里还有一个状态未认证，动作就不放行。v14 执行必须同时通过 PASC 与 v13：`Exec_v14 ⊆ Exec_v13`。

**定义 598（感知余量传输 Lipschitz Margin Transport）** 设 v13 的安全边界余量 `m(s,a)` 关于状态满足 `L`-Lipschitz：
```
|m(s,a) − m(s',a)| ≤ L · d(s,s') .
```
则
```
min_{s∈S(o)} m(s,a) ≥ m(ŝ,a) − L·r(o) .
```
因此**可计算的充分条件**是 `m(ŝ,a) ≥ L·r(o)`；等价的**可容许半径**为 `r_max(a)=m(ŝ,a)/L`。`L` 由 v13 证书函数的解析导数上界或区间自动微分给出保守估计；当 `S(o)` 不可微/非凸时用分段 Lipschitz + 采样验证。

**定义 599（主动感知算子 Active Perception Operator）**
```
P = ( h_0, h_1, …, h_n ; c_0 < c_1 < … < c_n ; Act )
h_0 : o ↦ S_0(o)                                  # 被动起点（固定视角）
h_k : (o, S_{k-1}) ↦ S_k ⊆ S_{k-1} ,  r_k ≤ r_{k-1}   # 换视角/变焦/降速/探触
```
要求：
1. **覆盖率保持**：对每个 k，`P(s*∈S_k) ≥ 1−α_p`；
2. **单调收缩**：`S_k⊆S_{k-1}`（观察只增加信息，不删除已知信息）；
3. **成本可测**：`c_k` 为硬件在环测得的上界，且 `Σ c_k` 计入 `B_perc`；
4. **物理可回退**：任何探触类观察动作必须满足 `Act_k ∈ P^rt`，不得把系统带到不可回退状态；
5. **可中断**：在任一 k 停止都返回仍含真值、因而仍安全的 `(S_k,c_k)`。
注意：主动感知的安全方向与 v13 的 AIO 相反——AIO 从最保守动作集向上扩张，APO 从最大状态集向下收缩；两者都满足"早停只更保守"。

**定义 600（视觉授权阶梯 Visual Authorization Ladder）**
```
Acc^vis_0(o) ⊆ Acc^vis_1(o) ⊆ … ⊆ Acc^vis_n(o) ⊆ Acc_v13(o) ,
r_0 ≥ r_1 ≥ … ≥ r_n .
```
由定义 597 的单调性（引理 122）自动成立。预算映射 `k*(b)=max{k : Σ_{j≤k}c_j ≤ b}`。阶梯把"毫秒—状态半径—授权价值"三者绑成一条可预算曲线，是 v13 DDL 在**状态空间**上的对偶。

**定义 601（跨体接地间隙证书 CEGC）** 对目标体 `e` 的分层校准集定义
```
h_i = m_{U,e}(x_i,a_i) − m_{v13,e}(x_i,a_i)          # 共享 UniBot 相对该体 v13 的乐观量
U_e(α_e) = Quantile_{1−α_e}( {h_i} ∪ {+∞} )          # 有限样本修正阶 ⌈(1−α_e)(n+1)⌉
```
证书 `Ĉ_emb=(Û_e,U_e,cov_e,supp_e)` 有效当且仅当：(i) 校准与部署在目标体支撑域内可交换（或已加权共形）；(ii) `e∈supp_E` 且相机外参证书有效；(iii) `U_e ≤ B_emb`。有效时以概率 `≥1−α_e` 有 `Acc_Ue(U_e)⊆Acc_v13,e`，即共享先验只产生该体的 v13 授权子集。`U_e=+∞` 是"禁用共享"的中立元。

**定义 602（四预算不可挪用 Four-Budget Non-Fungibility）** 在 v13 定义 593 上扩展：
```
B_total = B_transfer + B_distill + B_emb        # 三类真实侧误差可加
B_time  = B_safe + B_infer + B_perc             # 安全切片硬预留，感知不得挤占
```
四类预算各自独立、不得互相冲抵：感知时间不能拿安全切片买单，跨体间隙不能拿迁移/蒸馏预算买单。任一预算耗尽时，唯一允许的动作是**沿视觉阶梯/时限阶梯更保守**、触发 `a_ask` 或认证回退。

**定义 603（视觉支撑与漂移 Visual Support & Drift）** 记 `supp_vis` 为校准覆盖的光照、视角、材质、标定版本联合域，`ρ(o)` 为 OOD 分数。视觉漂移判据为

```
drift_vis(o) ⇔ ρ(o) > τ_ρ  ∨  S(o) = ∅  ∨  supp_signature(o) ⊄ supp_vis  ∨  覆盖自检失败 .
```

**定义 604（感知路由状态）**

```
ζ_p = ( S_k, r_k, k*, e, U_e, PASC, B_perc, drift_vis, mode )
mode ∈ {passive, active, ground-only, collapse}
```

VPR 只读 `ζ_p` 分配观察预算、选档与塌缩；感知证书由 PAC/APO 预先产生，UEG 只提供提议。

```python
class ActivePerceptionOperator:
```

## 4. 推导

**引理 122（歧义集收缩的授权单调性）** 若 `S'⊆S`，则 `Acc^vis(S') ⊇ Acc^vis(S)`；因此沿 APO 的阶 `Acc^vis_0⊆Acc^vis_1⊆…⊆Acc^vis_n⊆Acc_v13`。证明：`Acc^vis(S)=⋂_{s∈S}Exec_v13(s)`，对更小的集合取交得到更大的交集。∎ 推论：**观察只会放宽授权、不会收紧**；任何早停返回的更大集合对应更保守授权，因此"少看"是安全侧。

**引理 123（PASC 的安全继承）** 若 `s*∈S(o)` 且 `a∈Acc^vis(o)`，则 `a∈Exec_v13(s*)⊆Exec_v12(s*)`。故 `Exec_v14⊆Exec_v13`（对真实状态逐点），v13 引理 117 与 v12/v11 的安全继承在 v14 上继续成立。证明：定义 597 的全称量化取 `s=s*`；再由定义 583/585/587 与 v13 引理 117 得 `Exec_v13⊆Exec_v12`。∎ 推论：**全称量化把感知误差转成了 v13 的保守性，而非新的授权**；代价是 `S(o)` 越大越可能清空 `Acc^vis`（假拒绝）。

**引理 124（Lipschitz 余量传输的可靠性）** 若 `m(s,a)` 关于状态 `L`-Lipschitz、`r=rad(S(o))`，则
```
min_{s∈S(o)} m(s,a) ≥ m(ŝ,a) − L·r .
```
因此 `m(ŝ,a) ≥ L·r` 是 `∀s∈S(o): m(s,a)≥0` 的充分条件。证明：对任意 `s∈S`，`d(s,ŝ)≤r`，故 `m(s,a)≥m(ŝ,a)−L d(s,ŝ)≥m(ŝ,a)−Lr`。∎ 推论：**可容许半径 `r_max=m(ŝ,a)/L`**；当 `r>r_max` 时该动作必须被拒绝或继续观察。注意 `L` 必须取保守上界，低估 `L` 会直接破坏该充分条件。

**引理 125（CEGC 的单侧覆盖与总间隙可加）** 若 `U_e` 取有限样本修正的 `⌈(1−α_e)(n+1)⌉` 阶次序统计量，且校准/部署在目标体支撑内可交换，则
```
P( Acc_Ue(U_e) ⊆ Acc_v13,e ) ≥ 1−α_e .
```
记 `Δ_tr=J_real(v13)−J_sim(v13)`、`Δ_dis=J_real(S)−J_real(v13)`、`Δ_emb=J_real(U,e)−J_real(v13,e)`，则
```
J_real(U,e) − J_sim(v13) = Δ_tr+Δ_dis+Δ_emb ≤ U_gap+U_dis+U_e   （w.h.p.）
```
联合成立概率 `≥1−α_gap−α_dis−α_e`。证明：标准分裂共形 + 对三个单侧界取并集；`Δ_emb` 的负值（共享先验偶然更好）不计入收益，安全界取 `max(0,Δ_emb)`。∎ 推论：**跨体间隙不能拿迁移/蒸馏预算冲抵**，`B_total=B_transfer+B_distill+B_emb` 必须加性；通用性越强、体身越多，`U_e` 越可能吃紧。

**引理 126（观察—授权—时限三难下界）** 存在感知/环境族，使任何满足覆盖率 `1−α_p` 的主动感知算子族若要达到状态半径 `r`，必须付出
```
c(r) ≥ Ω( (d_eff + log(1/δ_p)) · σ_p^2 / r^2 )
```
的观察/采样成本（`d_eff` 为需辨识几何量的有效维度，`σ_p` 为单次观测噪声）；且相对半径 `r_prev` 的授权价值增益满足
```
0 ≤ v(r_prev) − v(r) ≤ L_v · (r_prev − r) ,
```
故当 `r ≤ r* = m_min/L` 后继续观察**不增加任何授权**，只消耗时间。证明：第一式由非参数估计/主动感知的样本复杂度下界给出；第二式由 `value` 关于状态的 Lipschitz 性与引理 124 的最小余量饱和给出。∎ 推论：**"看得越清越好"是错的**；存在有限最优感知预算 `B_perc*`，超过后应把毫秒还给推理或执行。

**引理 127（主动感知的中断安全性）** 若 APO 满足定义 599 的覆盖率保持、单调收缩与探触可回退，则对任意中断档 k，`s*∈S_k`（w.p. `≥1−α_p`）且 `Acc^vis_k⊆Acc_v13`；因此任意早停都安全，且 `Acc^vis_0⊆…⊆Acc^vis_n`。证明：覆盖率对每个 k 成立；`S_k⊆S_{k-1}` 与引理 122 给出授权单调；定义 599(4) 保证物理可回退；引理 123 给出继承。∎ 推论：**观察预算是"安全的可选项"**；即使一帧只看了 0ms，也只是回到更保守的被动集合，而不是回到未验证状态。

**引理 128（中立元退化等价 v13）** 将定义 606 的四个中立元注入 UEG/PAC/APO/VPR，则共享策略退化为每体 v13 专用策略、歧义集退化为单点、主动感知退化为被动、路由器退化为 v13 静态调度；主闭环调用序列与 v13 逐位一致，再沿 v13 链退回 v12/v11/v10/v9/v8/v7/v6。证明：逐端口代入定义 606，并用定义 595–607 的边界条件核对；四端口互不相交且中立元不改变 v13 任何证书检查。∎

**引理 129（视觉支撑失效的安全塌缩）** 设 `drift_vis` 按定义 603 触发后 VPR 只允许 `P^rt_vis`（零假设回退），则：物理硬违规概率不高于 v13 对应回退；活动性损失满足
```
P(无可执行认证动作) ≤ P(drift_vis) + P(s*∉S(o) | ¬drift_vis) + P(a_ask 预算耗尽) .
```
证明：`drift_vis` 后禁止 `k≥1` 且不使用 `S(o)` 的中心做全称量化；`P^rt_vis` 要求回退在本帧可完成；剩余项由全概率公式与并集界。∎ 推论：**视觉漂移不是用更高档感知去赌，而是用最保守回退去买重校准时间**；这也暴露 v14 的根本脆弱点——若漂移未被检出，第二项会悄悄变大。

**引理 130（通用性—保守性权衡下界）** 设共享 UniBot 策略 `U` 需在体身族 `E` 上同时满足每体安全。对同一观测 `o`，令 `D(o)={a : a 在 e∈E 上被 v13 认证的体身集合不一致}` 为体身分歧区。则任何共享提议若不在 `D(o)` 上弃权，必须付出
```
U_e ≥ Q_{1−α}( { h_i } ) ≥ Ω( vol(D(o)) / |E| )   （对该体）
```
的跨体间隙或等量的假拒绝。证明：构造两个仅在某区域可达集不同的体身；共享策略在同一 `o` 上无法同时匹配两者，若强行放行则在该区域相对其中一个体身乐观，其乐观量下界正比于分歧体积；对 `E` 取平均并用共形分位即得。∎ 推论：**"越通用"与"每体越保守"是同一枚硬币**；体身越多、异构度越高，`B_emb` 与假拒绝预算越紧，这正是 v14 必须显式定价的交换。

## 8. 已知风险与失效模式

1. **真值不在 `S(o)` 内（支撑外幻觉）**：透明/镜面、极端光照、新视角、标定漂移下，感知误差不再是"集合内噪声"而是**支撑外偏移**；系统会围绕错误中心构造自洽集合，并证明"集合内全安全"。缓解：定义 603 的支撑签名 + 覆盖自检 + OOD 检测；支撑外一律塌缩到 `P^rt_vis`；保留独立几何/触觉锚点做交叉校验。
2. **Lipschitz 常数 `L` 低估**：`L` 低估会使 `m(ŝ)≥Lr` 的充分条件失效，直接产生假接受。缓解：区间自动微分、分段保守上界、对抗采样验证、在 `L` 不确定时退回逐状态全称量化。
3. **全称量化导致活动性塌缩**：物体边缘/遮挡使 `r` 偏大，`Acc^vis` 频繁清空，系统退化为频繁 `a_ask`。缓解：主动感知优先补看、分通道收紧、把假拒绝显式计入 `B_perc`/任务预算，并允许在安全侧增加观察档而非直接放弃。
4. **通用先验的跨体幻觉**：共享视觉-运动潜空间会把 A 体的可达/可抓模式迁移到 B 体，在视觉上极合理但物理上不可行。缓解：唯一执行通道 `ψ_e∘g_e`、CEGC 单侧包含、`supp_E` 注册、跨体分歧区弃权（引理 130）。
5. **CEGC 校准集过小/目标体过少**：新体只有少量数据时 `U_e` 可能偏松或偏紧。缓解：分层/加权共形、体身参数化先验、主动采集分歧区数据、`U_e` 超预算即禁用共享改走每体 v13。
6. **感知预算与安全切片竞争**：若调度把 `B_perc` 与 `B_safe` 混用，感知会悄悄吃掉安全余量。缓解：定义 602 硬隔离、静态 EDF 校验、运行时断言 `B_perc∩B_safe=∅`、看门狗强制塌缩。
7. **主动感知的物理副作用**：换视角/探触会改变接触状态，可能在易损物体上造成不可逆影响。缓解：探触必须 `∈P^rt`、力/位限幅、优先纯视觉观察、把主动观察当作有成本的技能而非免费查询。
8. **视觉退化与 v13 漂移联合发作**：新场景同时触发 v13 的分布漂移与 v14 的视觉支撑失效，`U_gap`、`U_dis`、`U_e` 可能同向偏低。缓解：联合三角界（引理 125）、四预算加性、双重漂移检测、任一失效即 `a_ask`/最低档。

## 9. 本轮最大风险

**一句话**：感知证书的全部安全性都押在"真值落在 `S(o)` 内"这一条上，而视觉失效的典型形态恰恰是**支撑外**（透明/镜面、极端光照、新视角、标定漂移）——此时 UniBot 的共享先验仍会给出一个视觉上非常合理、跨体语言上非常连贯的提议，PAC 又会围绕一个**错误的中心**构造出一个"内部自洽"的歧义集；系统于是证明了"对所有 `s∈S(o)` 都安全"，却不知道真实的 `s*` 根本不在 `S(o)` 里——即**感知盲区中的、体身自洽的、被普遍量化证书背书的绝对错误决定**。
