# 第 3 轮（灵感循环第3轮；本轮灵感：「视觉定位」×「跨任务泛化」×「跌倒恢复」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50）。
> 本轮纪律：在前人基础上改进——ToolGauge 的 VLA 假设、工具契约、摊销校准三模块各沿一条灵感轴升级；
> MODGAUGE 五不变式与 7C 骨架保留；修复第 2 轮遗留风险：视觉盲区缺乏度量锚、跨盲区先验泛化能力弱、紧急安全动作无硬实时保障。

- 严格退化链延长：FR 失效 ⇒ ToolGauge 纯数值探测 ⇒ MODGAUGE；V-Box 失效 ⇒ 回退 ToolGauge L-Box。

## 0. 直觉与动机

**灵感1 视觉定位 → 盲区的度量锚与可回溯性**
直觉：ToolGauge 的盲区 s 是格子索引 (d,m,i)，缺乏世界坐标系的度量锚。探测程序 Π_s 生成的回执无法在物理空间回溯，导致“定位漂移”时校准失效。视觉-IMU 融合的 pose 估计提供度量锚 V-Anchor，盲区可映射为 SE(3) 不确定椭球。探测动作的 Pre 条件可从“力/温”扩展到“pose 误差包络”，工具回执必须携带 pose 戳。攻击面增加：伪造回执需同时伪造 pose 轨迹。

**灵感2 跨任务泛化 → 先验从盲区级到任务族级**
直觉：MP-Φ 在同一任务内摊销，但行走/奔跑/搬运/跌倒恢复的物理动力学共享低维流形。跨任务元学习把任务嵌入 z_task 注入先验，训练目标加入任务间一致性正则。元泛化界从 M 个环境扩展到 M×T 个任务，样本效率提升 O(√T)。同时保留物理 KL 锚防止跨任务漂移。

**灵感3 跌倒恢复 → 安全关键工具的硬实时下注**
直觉：跌倒恢复是典型的“必须执行且不得误触发”场景。ToolGauge 的双层下注 λ/β 仅管安全与收益，需增加第三层 **安全门 μ**：μ = P(fall|ξ_pose, ξ_contact) ≥ μ_thr 强制触发；且执行时延 τ ≤ 50ms 硬约束。跌倒恢复工具集 FR-T₀ = {torso.roll, hip.abduct, arm.swing, base.low} 预注册安全包络，Pre 条件含关节极限与碰撞预测。VLA 编程器对 FR 工具受限：只能选预注册安全动作，参数限包络内。

## 1. 形式化定义（增量：定义 432–440）

**定义 432（视觉定位锚 V-Anchor）** V-Anchor(s) = (T̂_ws ∈ SE(3), Σ_pose) 由视觉-IMU 滤波输出；度量一致性要求 ‖log(T̂_ws⁻¹ T_gt)‖ ≼ Σ_pose。盲区映射 s ↦ cell_in_world(s, T̂_ws)。回执 r 扩展为 r = (t, args, obs, sig, ts, seq, T̂_ws)。有效性 valid(r) 追加 PosePre(t, T̂_ws) 校验。

**定义 433（V-Box：视觉-不确定性融合假设器）** V-Box 在 L-Box 基础上输入 V-Anchor，输出假设集 H_s^v = H_s ∩ {h: pose_compatibility(h, Σ_pose) ≥ δ_p}。共形覆盖水平保持 1−α，但覆盖条件加入可交换的 pose 残差序列。

**定义 434（跨任务元先验 MT-Φ）** MT-Φ_θ : (z_task, h, {r_j}) ↦ q_θ(u_s | z_task)。元训练 min_θ Σ_{m,t} E[−log p(u*|ctx)] + β_KL KL(q‖p_phys) + β_task‖∇_z E‖²。任务嵌入 z_task 由任务描述编码器产出，维度 d_z ≤ 16。

**定义 435（跨任务泛化界）** 设任务族 𝒯，TV(𝒟_dep,𝒟_env) ≤ η_task。超额风险 R̄ ≤ 2η_task + O(√((C(Θ)+d_z log T)/MT)) + O(√(d_u/N_bl))。T→∞ 时单任务样本需求 N_bl→1。

**定义 436（跌倒恢复工具契约 FR-MTC）** t_fr ∈ FR-T₀ 额外字段 SafetyMargin(t_fr) 与 HardDeadline τ_fr ≤ 50ms。Pre_fr 含动力学可达性与碰撞自由谓词；Post_fr 必须含 joint-limit 回执与落地冲击估计。

**定义 437（安全三层闸门）** 风险门 λ、增益门 β 如前；新增安全门 μ(s) = P_fall(ξ_pose, ξ_contact) ≥ μ_thr。FR 工具仅当 μ 通过且 λ/β 通过才执行；μ 触发时 β 门放宽至 β ≥ 0（强制执行）。

**定义 438（7C 闭环）** H → V → C → E → C → V → U：新增 V 阶段 Visual Anchor Validation。校准后需验证后验均值与独立视觉-IMU 再定位残差 |z_pose| ≤ ε_pose。

**定义 439（跌倒风险监控 FallWatch）** 维护滑动窗口 W=0.5s 的 pose 加速度与接触力序列；P_fall 由轻量校准分类器输出，误报率 ≤ 1%。FallWatch 触发直接跳过 VLA 编程，走预编译安全程序 Π_fr。

**定义 440（退化链）** V-Anchor 失效 ⇒ Σ_pose → ∞，V-Box 输出 UNKNOWN，回退 ToolGauge L-Box；MT-Φ 失效 ⇒ 回退 MP-Φ 单任务先验；FR 预算耗尽 ⇒ 立即 stub + 硬减速。

# 第 3 轮产物 · 创新点清单 v3：**RoadGauge**（Capability-Roadmap Metrology with Audited Embodied Foundation Model）

## 2. 形式化定义（要点）

**定义 432/433（能力单元与能力图）** 能力 = 预注册签名（工具+契约+先验+失败指纹）+ 前置依赖 + 程序模板 + 成本/时延 + 覆盖增益核；获取集须前置闭包，覆盖足迹由 `max_c g_c(s)` 给出。

**定义 435（路线图）** 有序阶段，满足严格前驱、阶段预算、里程碑、期限；`K=0` 即 ToolGauge。
**定义 436/437（目标与安全保留）** 稳健最大化期望已验证覆盖（含 CVaR 尾项与期权价值）；**安全关键集 `S_safe` 的覆盖与预测无关**。
**定义 438（里程碑闸门）** 在未参与规划的样本上验收，过则解锁、败则回滚 1 次后冻结。
**定义 439（规划接口 POI）** 制图 / 从预注册本体提案 / 转移主张；编造能力直接拒绝，输出永不进数值通道。
**定义 440（转移账本）** 只信 `LCB ≥ ρ_min`，否则按全新能力计价，杜绝纸面能力。
**定义 441/442（RC 与 RTS）** RC 细化 TB-Contract；战略层只发布收缩后的可行集 `Adm_road ⊆ Adm_tool`。
**定义 443/444（漂移与懊悔）** 漂移/陈旧触发重规划；实测覆盖持续低于计划 ⇒ 冻结规划器回退近视修复。

# IP-321 C-Box：能力制图（规划专用，带 conformal 模糊集）
class CBox:
    def forecast(self, task_summary, A_current):
        D_hat = self.emb_model.predict_demand(featurize(task_summary))
        return ConformalSet(D_hat, self.cal_d, alpha=self.alpha_d)
    def propose(self, D_hat, ontology):
        return [c for c in self.emb_model.propose_capabilities(D_hat)
                if c.sig in ontology]                       # 本体审计
    def transfer_claim(self, c, e_src, e_tgt):
        rho_hat, ev = self.emb_model.transfer(c, e_src, e_tgt)
        return TransferClaim(c, e_src, e_tgt, rho_hat, ev)

# IP-322 能力图与闭包
class CapabilityGraph:
    def closure_ok(self, A):
        return all(p in A for c in A for p in c.prereq)
    def footprint(self, A):
        return {s for s in self.S
                if max((c.g(s) for c in A), default=0) >= self.g_min}

# IP-323 路线图规划：依赖 + 预算 + 安全保留 + 稳健目标
class RPlanner:
    def plan(self, Dset, CG, B_total, stages, S_safe, tau_safe):
        best = None
        for R in self.density_greedy(Dset.worst_case(), CG, B_total, stages):
            if not CG.closure_ok(union(R)):          continue
            if cov(union(R), S_safe) < tau_safe:     continue   # 预测无关的硬约束
            if not self.budget_ok(R):                continue
            if best is None or self.J(R, Dset) > self.J(best, Dset):
                best = R
        return best or []                                # 空 ⇒ K=0

# IP-324 里程碑闸门
class MilestoneGate:
    def check(self, k, A_k, S_hat, rc):
        c_hat = cov(A_k, S_hat[k])                       # 未参与规划
        ok = (c_hat >= rc.tau[k]) and contract_regression(A_k)
        return ok, StageCert(k, A_k, c_hat, S_hat[k])

# IP-325 转移账本
class TransferLedger:
    def audit(self, claim):
        return lcb(self.get(claim.c, claim.e_src, claim.e_tgt),
                   delta=self.delta_tx) >= self.rho_min

# IP-326 战略层主闭环
def roadgauge_strategic(M):
    if M.regret.triggered() or not M.cbox.available():
        M.freeze_roadmap(); return
    Dset = M.cbox.forecast(M.task_summary, M.acquired)           # 制图
    props = M.cbox.propose(Dset, M.ontology)                     # 本体审计
    props = [c for c in props
             if c.fresh or M.tl.audit(M.cbox.transfer_claim(c, *M.emb))]
    R = M.rplanner.plan(Dset, M.CG, M.B_total, M.stages,
                        M.S_safe, M.tau_safe)                # 依赖+预算+安全保留
    for k, stage in enumerate(R):
        ok, cert = M.gate.check(k, union(R[:k+1]), M.S_hat, M.rc)
        if not ok:

            if not M.replan_once(): M.freeze_roadmap(); return
        M.publish_constraints(union(R[:k+1]), stage.budget)  # 只收缩可行集
    M.regret.record(M.J_plan, M.measured_coverage)

## 4. 推导

**引理 51（RTS 安全继承）** `Adm_road ⊆ Adm_tool` 且路线图不改任何安全判定 ⇒ RoadGauge 的每次探测仍是
ToolGauge 合法探测；引理 46/49/50 全部继承，路线图只能让系统更保守。
**引理 52（路线图近似）** 子模 `g` + 独立到达 + 拟阵前置 ⇒ 密度贪心 `(1−1/e−ε)`；一般 DAG ⇒ `O(log n)` 或 CP-SAT。
诚实声明：覆盖冗余严重时子模性失效，贪心界不成立（E447 证伪点）。
**引理 53（双时间尺度稳定）** `T_strat ≥ c·max τ_repair` + 滞回 ⇒ 无振荡，重规划 `O(H/T_strat)`。
**引理 54（预测→懊悔界）** conformal 1−α_d + 稳健规划 ⇒ 相对 oracle 损失 `≤ α_d·尾部质量 + O(√(log(1/δ)/n_cal)) + δ_model`；
`δ_model` 不可消除，由 E448 实测入账。
**引理 55（转移可靠性）** 仅接受 `LCB ≥ ρ_min` ⇒ 移植后实际覆盖 `≥ ρ_min·g_c`（置信 1−δ_tx）；否则按全新获取，J 下界仍成立。
**引理 56（退化有界损失）** 熔断 ⇒ `K=0` ToolGauge；安全不变（引理 51），性能损失 ≤ `J(R*)−J(ToolGauge)`（E442 估计）。

## 8. 本轮最大风险

**一句话**：**需求预测与转移主张构成自我确认回路**——大模型预测未来盲区，规划器据此分配全部预算，
里程碑又只在同一预测条件化的样本上验收，于是一个系统性偏移的具身大模型可以把整个能力组合引向错误区域
（能力单一种植 / 能力债），而每站里程碑都"通过"；战略级错误会重分配全部预算并饿死低频但安全关键的盲区。

**三重兜底**：① 与预测无关的**安全保留 `S_safe` + CVaR 尾项**（定义 436/437）；
② **转移账本 LCB + 移植后强制复验**（定义 440/446）；③ **懊悔熔断 + 冻结回退 ToolGauge**（定义 444/引理 56）；
以 E442/E448/E450/E453 为证伪实验，E454 验证安全继承。
