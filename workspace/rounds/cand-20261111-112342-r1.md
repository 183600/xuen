# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「避障控制」×「场景落地」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书 `J`，并用云边协同闭环保证动作对齐。本轮引入两个常被当作“下游工程”的维度：**避障控制**与**场景落地**。核心判断：避障不是鲁棒性谱 `ρ` 的第 n 维，而是动作空间上的**硬可行域否决**；场景落地不是“多跑几个场景”，而是把点态证书升级为**带覆盖率保证的分布契约**。据此提出“安全-落地双闸”：先过避障可行域闸，再过场景分布风险闸，最后按部署阶梯逐级放行。H22：`ρ` 是扰动平均意义下的鲁棒，避障是几何最坏意义下的可行，二者不可互相替代；H23：仿真点态证书无法自动迁移到部署场景分布，场景选择偏差会造成“证书为真、落地为假”。

## 0. 直觉与动机

**灵感 1（避障否决权 → 从“能做”到“做了不撞”）**
直觉：技能 `S` 的动作占用剖面 `α_S` 只说明“能做”，不说明“做了不撞”。同一个动作在开阔地可行，在窄通道可能直接穿过障碍的安全半径。因此给技能增加**安全占用剖面** `β_S(x,u)`，并把组合的第一约束从 `A_i∩A_j` 改为 `A_i^safe∩A_j^safe`。若安全交集为空，即使 `ρ` 再高也必须否决。**避障对技能组合拥有一票否决权，鲁棒性只能在安全可行域内做排序。**

**灵感 2（安全管 + 备份 → 避障不是一个检查点，而是一条执行链）**
直觉：避障不能只在规划时查一次，还要在执行时用 CBF 安全滤波器把标称动作投影到安全集；当 QP 不可行时，必须有“最小风险备份”（刹车、后退、侧移）。因此技能证书要携带**安全管 `C_S`** 与**备份可达性**，而不是只带成功率。形成“标称动作 → 安全滤波 → 备份接管”的三级执行链，任何一级都不能把风险偷偷转嫁给下一级。

**灵感 3（场景落地 = 分布契约 → 从点态通过到覆盖率-风险上界）**
直觉：落地成败不取决于平均场景，而取决于长尾。把场景库当作校准集，用保形风险控制/霍夫丁上界给出部署风险的分布无关上界；同时用场景新奇度定义**落地包络**，包络外一律降级或拒绝。落地证书从“单场景通过”变成“在 `D_{ε,c}` 内风险 ≤ ε、覆盖率 ≥ c”。这使“场景落地”第一次成为一个可被统计检验的命题，而不是演示视频。

**灵感 4（部署阶梯 → 落地是状态机，不是开关）**
直觉：真实落地不是一次性开关，而是阶梯：仿真 → 影子回放 → 受限区域带安全员 → 全场景。每一级有独立门槛和证据，达标升级，异常降级。把“场景落地”建模为带序贯检验的部署状态机，能让安全违规触发自动回滚，而不是等到事故后才复盘。

**灵感 5（安全-落地金字塔 → 在动作层与鲁棒层之外再加两层）**
直觉：在第 54 轮的动作层 `𝔸` 与鲁棒层 `𝕃` 之外，增加安全层 `𝕊` 与落地层 `𝔻`：`𝕊_0` 几何安全集，`𝕊_1` 技能 CBF，`𝕊_2` 组合安全走廊，`𝕊_3` 备份不变式；`𝔻_0` 单场景，`𝔻_1` 场景分布，`𝔻_2` 落地包络，`𝔻_3` 阶梯部署。跨层证书同时携带 `ρ`、`A_cert`、`B_cert`、`L_cert`，形成**可解释的安全-鲁棒-落地三证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（障碍场、安全裕度与离散 CBF）**
环境 `E=(X,U,O,r_safe)`；状态 `x∈X`，控制 `u∈U`，障碍集 `O⊂X`，机器人安全半径 `r_safe`。技能 `S` 的闭环一步预测为 `f_S(x,u)`。安全裕度定义为
```
m_S(x,u;O) = min_{o∈O} dist(f_S(x,u), o) - r_safe - δ_perc
```
其中 `δ_perc` 为感知膨胀。归一化屏障函数 `h_S(x)=clip(m_S(x,π_S(x);O)/m_ref, -1, 1)`。安全集 `C_S={x | h_S(x) ≥ 0}`。离散 CBF 条件为
```
h_S(f_S(x,u)) ≥ (1-η) h_S(x),  η∈(0,1]
```
避障安全剖面 `β_S(x,u)=1[ m_S(x,u;O) ≥ 0 ∧ h_S(f_S(x,u)) ≥ (1-η)h_S(x) ]`。

**定义 122（安全动作占用与避障否决）**
在任务状态域 `X_task` 上，技能 `S` 的安全动作占用为
```
A_S^safe = { u∈A_S | ∀x∈X_task, β_S^κ(x,u) ≥ θ_s }
```
其中 `β_S^κ` 为有限样本下 `β_S` 的置信下界（Clopper–Pearson/Hoeffding），`θ_s` 为安全置信阈值。组合 `S_i⊗S_j` 的动作集合先取 `A_Si^safe ∩ A_Sj^safe`；若为空，则 `veto(S_i⊗S_j)=1`，无论 `ρ_{S_i⊗S_j}` 多高都不可部署。定义安全容量 `cap_safe(S)=|A_S^safe|/|A_S|`。

**定义 123（安全转换走廊与安全兼容性）**
两技能 `S_i,S_j` 的转换走廊 `Γ_ij:[0,T]→X` 从 `X_i^out` 到 `X_j^in`，其膨胀管为 `Γ_ij^⊕`。若 `Γ_ij^⊕ ∩ O = ∅`，且 `∀t, h_i(x(t)) ≥ 0 ∨ h_j(x(t)) ≥ 0`，且 `T ≤ τ_e`，则称 `Γ_ij` 为安全走廊。安全兼容性
```
compat_safe(S_i,S_j) = max_{Γ_ij} min_{t∈[0,T]} m(t)/m_ref
```
组合边要求 `compat_safe ≥ θ_s`。边证书 `B_ij=(h_corridor, margin^LCB, T, π_bk)`，其中 `π_bk` 为走廊内可接管的最小风险备份策略。

**定义 124（场景分布、落地包络与落地证书）**
场景空间 `𝒮`，部署分布 `μ`，策略 `π` 的场景风险 `R(s,π)∈[0,1]`，部署风险 `R_μ(π)=E_{s~μ}[R(s,π)]`。给定风险预算 `ε`、覆盖率预算 `c`、场景新奇度 `nov(s)`，落地包络
```
D_{ε,c} = { s∈𝒮 | R(s,π) ≤ ε ∧ nov(s) ≤ q_{1-c} }
```
落地证书 `L=(D_{ε,c}, R̂^UCB, ĉov^LCB, n, δ)` 满足
```
P( R_μ(π|D_{ε,c}) ≤ R̂^UCB ) ≥ 1-δ
P( cov_μ(D_{ε,c}) ≥ ĉov^LCB ) ≥ 1-δ
```
其中风险上界由校准集上的 Hoeffding/保形风险控制给出，覆盖率下界由 Clopper–Pearson 给出。证书的有效性以校准场景与部署场景**可交换**为前提。

**定义 125（部署阶梯）**
部署级别 `ℓ∈{0,1,2,3}`：`L0` 仿真全覆盖，`L1` 影子/回放，`L2` 受限区域 + 安全员，`L3` 全场景。每级门槛 `G_ℓ=(r_ℓ, c_ℓ, v_ℓ, o_ℓ)`：最大风险上界、最小覆盖率下界、最大安全违规率、最大 OOD 率。升级 `ℓ→ℓ+1` 当且仅当 `R̂^UCB≤r_ℓ`、`ĉov^LCB≥c_ℓ`、序贯检验通过；降级当 `SPRT` 拒绝、备份接管或 OOD 告警触发。部署策略是一个带吸收态（强制回滚）的有限状态机。

**定义 126（安全-落地联合证书）**
联合证书 `J^safe=(J, B_cert, L_cert, π_bk, ℓ, evidence)`：
- `J` 为第 54 轮动作-鲁棒性联合证书；
- `B_cert=(h_S, C_S, margin^LCB, π_bk)` 为安全管证书；
- `L_cert` 为定义 124 的落地证书；
- `ℓ` 为当前部署级别；
- `evidence` 至少包含 CBF-QP 日志、场景校准集、影子回放与备份接管记录。

在级别 `ℓ` 可部署，当且仅当：`dom_J(T)=in`，`B_cert` 满足前向不变式与备份可达，`R̂^UCB≤r_ℓ`，`ĉov^LCB≥c_ℓ`，`δ_a≤Θ_a`。任一条件失败则 `reject`，不允许用其他维度的裕度补偿。

## 2. 关键算法 伪代码

### IP-121 SOC（Safe Occupancy Characterization）

```python
def safe_occupancy(skill, scenes, n, theta_s, delta):
    stats = defaultdict(lambda: [0, 0])
    for s in scenes:
        for x in sample_reachable_states(skill, s, n):
            u = skill.policy(x, s)
            h_now = skill.margin(x, s) / skill.m_ref
            h_next = skill.margin(skill.step(x, u), s) / skill.m_ref
            safe = (skill.margin(skill.step(x, u), s) >= 0) and \
                   (h_next >= (1 - skill.eta) * h_now)
            key = discretize(x, u)
            stats[key][0] += int(safe)
            stats[key][1] += 1
    return {k: clopper_pearson_lower(v[0], v[1], delta)
            for k, v in stats.items()}

def veto(si, sj, theta_s):
    return not any(beta >= theta_s
                   for beta in intersection(si.beta_lcb, sj.beta_lcb).values())
```

### IP-122 STG（Safe Transition Graph）

```python
def safe_composition_graph(skills, scenes, theta_s, tau_e, rho_min, K):
    G = nx.DiGraph()
    for i, si in enumerate(skills):
        for j, sj in enumerate(skills):
            if i == j:
                continue
            if veto(si, sj, theta_s):
                continue
            corridor = plan_safe_corridor(si, sj, scenes, tau_e)
            if corridor is None or corridor.margin_lcb < theta_s:
                continue
            rho_comp = compose_robustness(si.rho, sj.rho, K)
            if min(rho_comp.values()) < rho_min:
                continue
            G.add_edge(i, j,
                       compat_safe=corridor.margin_lcb,
                       cost=corridor.time + corridor.risk,
                       B_cert=corridor.cert,
                       rho_comp=rho_comp)
    return G
```

### IP-123 SLC（Scenario Landing Certificate）

```python
def landing_certificate(policy, calib_scenes, alpha_risk, alpha_cov, delta):
    n = len(calib_scenes)
    risks = [evaluate_risk(policy, s) for s in calib_scenes]
    r_ucb = min(1.0, mean(risks) + sqrt(log(1 / delta) / (2 * n)))

    novelty = [scene_novelty(policy, s) for s in calib_scenes]
    q = quantile(novelty, 1 - alpha_cov)          # 保形 OOD 包络
    in_domain = lambda s: scene_novelty(policy, s) <= q

    covered = sum(in_domain(s) for s in calib_scenes)
    cov_lcb = clopper_pearson_lower(covered, n, delta)
    return LandingCert(domain=in_domain, risk_ucb=r_ucb,
                       coverage_lcb=cov_lcb, n=n)
```

### IP-124 DLL（Deployment Ladder Logic）

```python
def deployment_step(level, cert, monitor, gate):
    if monitor.ood_alert() or monitor.violation_ucb() > gate[level].v_max:
        monitor.trigger_backup()
        return max(0, level - 1)
    if cert.risk_ucb <= gate[level].r_max and \
       cert.coverage_lcb >= gate[level].c_min and \
       sprt_pass(monitor):
        return min(3, level + 1)
    return level
```

### IP-125 OBF（Obstacle-aware Backup & Filter）

```python
def safety_filter(skill, x, u_nom, env):
    qp = solve_qp(
        minimize=norm(u - u_nom) ** 2,
        subject_to=[
            skill.margin(skill.step(x, u), env) >= 0,
            skill.h(skill.step(x, u)) >= (1 - skill.eta) * skill.h(x),
            u in skill.U,
        ])
    if qp.feasible:
        return qp.u
    if backup_reachable(skill, x, env):
        return skill.backup(x, env)
    return emergency_stop(skill, x)
```

### IP-126 SJC（Safe Joint Certificate）

```python
def safe_joint_certificate(seq, gamma_ce, delta_a_budget,
                           landing_cert, level, gate, theta_s):
    J = joint_certificate(seq, gamma_ce, delta_a_budget, rho_min)
    if J.status != 'ok':
        return J

    B = compose_safe_tubes(seq, theta_s)
    if not B.invariant or not B.backup_reachable:
        return reject('barrier_or_backup')

    if landing_cert.risk_ucb > gate[level].r_max:
        return reject('landing_risk', landing_cert.risk_ucb)
    if landing_cert.coverage_lcb < gate[level].c_min:
        return reject('landing_coverage', landing_cert.coverage_lcb)

    return ok(SafeJointCert(J, B, landing_cert, level))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SOC | O(\|S\|·N_scene·N_sample·(QP+\|A\|)) | O(\|S\|·\|X\|·\|U\|) | 安全剖面置信下界、采样覆盖 |
| STG | O(\|S\|²·(N_plan·N_sample+\|A\|)) | O(\|S\|²+\|E\|) | 走廊膨胀管无碰撞、规划概率完备 |
| SLC | O(N_cal·T_rollout) | O(N_cal) | 可交换性、风险有界、覆盖率下界 |
| DLL | O(1)/step + O(1) SPRT 更新 | O(1) | 门槛单调、回滚及时 |
| OBF | O(QP) 每步 | O(\|X\|+\|U\|) | QP 可行域、备份可达 |
| SJC | O(\|seq\|·\|A\|+N_cal) | O(\|A\|+N_cal) | 四类证书联合 sound |

**正确性定理（Safe-Landing Composition Soundness）**
假设第 53/54 轮 `(A22)–(A28)` 成立；新增：
**(A29)** 每个技能的 `h_S` 在感知膨胀 `δ_perc` 下有效，QP 数值求解误差可忽略；
**(A30)** 场景校准集与部署分布可交换，或已用重要性权重校正；
**(A31)** 安全走廊规划器在分辨率 `r` 下概率完备，且证书覆盖膨胀管；
**(A32)** 备份策略 `π_bk` 在 `C_S` 内前向不变（刹车带可达）；
**(A33)** 部署阶梯的序贯检验控制第一类错误 ≤ δ_dll。

则对任意一条每边都持有 `J^safe` 的组合作业，在落地包络 `D_{ε,c}` 内、以概率至少 `1-δ_total`：
```
P(无碰撞 ∧ 任务成功 | s∈D)
  ≥ 1 - ε_risk - Σ_d(1-ρ_min(d)) - β_E
      - P(δ_a>Θ_a) - δ_CBF - δ_dll
```
且 `P(R_μ(π) ≤ r_ℓ) ≥ 1-δ`、`P(cov_μ(D) ≥ c_ℓ) ≥ 1-δ`。

证明要点：对“CBF/滤波失败、鲁棒性组合失败、云边动作对齐失败、落地校准失败”四类事件做并集界；A31 保证 STG 不会为未验证走廊签发边证书；A32 保证 QP 不可行时备份仍留在安全集内；A30 把 SLC 的风险上界从校准集搬到部署分布；DLL 只允许在所有门槛同时满足时升级，因此不会用一级的裕度掩盖另一级的缺口。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 场景分布不可交换，保形保证失效 | 高 | OOD 护栏 + 在线校准 + 重要性权重 + 影子回放 |
| CBF 在真实动力学/感知噪声下失效 | 高 | 感知膨胀 + 鲁棒 CBF + 硬件在环验证 |
| 安全滤波导致死锁、任务无法完成 | 中 | liveness-aware CBF + 有限时间可达性 + 主动脱困 |
| 过度保守导致无法场景落地 | 中 | 风险-覆盖率可调门槛 + 分区域放行 |
| 长尾障碍构型覆盖不足 | 高 | 场景生成/模糊测试 + 对抗采样 + 失败回灌 |
| 云边延迟使备份不可达 | 中 | 边端实时调度 + 备份预算预留 + 降级策略 |

## 6. 本轮最大风险

**一句话**：安全-落地双闸把避障从软鲁棒升级为硬否决、把落地从点态演示升级为分布契约，但其 soundness 同时依赖 **场景校准集与真实部署分布的可交换性、CBF 在感知膨胀下的有效性、以及备份策略的实时可达性**；一旦长尾障碍构型落在校准集之外，保形上界会给出“统计上安全”的假信心，而 CBF 恰在该构型下不可行，系统就会以证书齐全的姿态在真实场景中失效，故必须以 **OOD 检测 + 在线校准 + 备份不变式** 作为不可绕过的三道绊线。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SEB×MPC-Cert×RFS×OPC×BCE×STC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，加入 **状态估计条件化、模型预测证书、递归可行性盾** 三大算子：
> - **SEB（State-Estimation-aware Bound）**：把鲁棒性证书条件化到信念信任域 `B_ε(x̂)`，并否决可观测性缺口方向；
> - **MPC-Cert（Model-Predictive Certificate）**：沿预测时域给出前瞻证书、证书 horizon `H_cert` 与衰减率 `λ_cert`；
> - **RFS（Recursive Feasibility Shield）**：用递归可行性在闭环中自维持证书；
> - **OPC（Observability-Predictability Coupling）**：把第 53 轮耦合矩阵 `K` 扩展为估计-预测耦合 `K_se`；
> - **BCE（Belief-Conditioned Explanation）**：失败四路归因，接入第 54 轮反向解释信道；
> - **STC（Spatio-Temporal Certificate）**：空间（动作/信任域）× 时间（horizon/衰减）联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118/120 以纳入信念与时间维度。

## 2. 关键算法 伪代码

### IP-121 SEB

```python
def belief_certificate(skill, belief, dims, eps, lambda_obs):
    xhat, Sigma = belief
    B = trust_region_samples(xhat, Sigma, eps)
    rho_b = {d: min(robustness(skill, x, d) for x in B) for d in dims}
    O = observability_gramian(skill, belief)
    o_gap = [v for v in eigvecs(O) if eigval(O, v) < lambda_obs]
    if any(required_direction(v, dims) for v in o_gap):
        return ('reject', 'observability_gap', o_gap)
    return ('ok', BeliefCert(rho_b, B, o_gap, Sigma))
```

### IP-122 MPC-Cert

```python
def mpc_certificate(skill, belief, model, H, W, rho_min, eps):
    b, rho_min_h, H_cert = belief, float('inf'), 0
    for tau in range(H):
        b = propagate_belief(b, model, W)
        c = belief_certificate(skill, b, dims, eps, lambda_obs)
        if c.status != 'ok' or min(c.rho.values()) < rho_min:
            break
        rho_min_h = min(rho_min_h, min(c.rho.values()))
        H_cert = tau + 1
    lam = decay_rate(rho_min_h, H_cert)
    return MPCert(rho_min_h, H_cert, lam, tube=Z)
```

### IP-123 RFS

```python
def recursive_feasibility_shield(belief, plan, model, W, Xf, rho_min):
    if not feasible(belief, plan, Xf):
        return ('fallback', safe_stop(belief))
    b_next = propagate_belief(belief, model, W)
    c = belief_certificate(plan.skill, b_next, dims, eps, lambda_obs)
    if c.status != 'ok' or min(c.rho.values()) < rho_min:
        return ('veto', 'certificate_would_violate', b_next, c)
    return ('ok', plan)
```

### IP-124 OPC

```python
def estimation_prediction_coupling(K, belief, model, H):
    K_se = {}
    for (d1, d2), k in K.items():
        K_se[(d1, d2)] = k * obs_weight(d1, belief) * pred_weight(d2, model, H)
    return K_se
```

### IP-125 BCE

```python
def belief_conditioned_explain(failure, belief, model, W):
    if nees(failure, belief) > chi2_thresh:        return 'estimation_error'
    if prediction_residual(failure, model) > r:    return 'model_mismatch'
    if failure.action not in failure.skill.alpha:  return 'action_infeasible'
    if failure.disturbance not in W:               return 'disturbance_ood'
    return 'unknown'
```

### IP-126 STC

```python
def spatio_temporal_certificate(skill_seq, belief, model, H_task, W):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)  # 第54轮
    if J.status != 'ok':
        return ('reject', 'action_layer', J)
    mc = mpc_certificate(skill_seq[0], belief, model, H_task, W, rho_min, eps)
    if mc.H_cert < H_task:
        return ('reject', 'horizon_short', mc.H_cert)
    return ('ok', STC(J, mc, BCE_channel=True))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SEB | O(|B|·|𝔇| + n²) | O(|B|+|𝔇|) | 信任域采样覆盖 ≥ 95%、NEES 一致 |
| MPC-Cert | O(H·|B|·|𝔇|) | O(H·|B|) | 传播误差有界、horizon 截断 |
| RFS | O(|B|·|𝔇|) 每步 | O(|B|) | 递归可行性、盾无漏检 |
| OPC | O(|K|) | O(|K|) | 权重单调、耦合非负 |
| BCE | O(1) | O(1) | 四路互斥、证据可追溯 |
| STC | O(H·|B|·|𝔇| + |S|·|A|) | O(H·|B|+|A|) | 空间-时间预算闭合 |

**正确性定理（Belief-Time Certificate Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 估计器一致，`P(x_t∉B_ε(x̂_t))≤δ_est` 且 NEES 检验通过；**(A30)** 预测误差在 `H_cert` 内满足 `||x_true(τ)-x̂_pred(τ)||≤Δ_pred(τ)`，且 `Δ_pred(H_cert)≤Δ_max`；**(A31)** `w_t∈W` 有界；**(A32)** RFS 在控制周期 `τ_ctrl` 内完成检查。则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
              - δ_est - P(Δ_pred(H_cert)>Δ_max) - P(RFS miss)
```
关键：**信任域包含真值**、**预测误差在 horizon 内有界**、**递归可行性由盾维持**。任一项破缺，证书都会从"保守"退化为"乐观"。

## 5. 本轮最大风险

**一句话**：状态估计与 MPC 把证书从静态空间扩展到信念-时间维度，但其 soundness **双重依赖估计器一致性（`Σ` 不收缩到虚假自信）与预测模型在证书 horizon 内的误差有界**；一旦估计器过度自信或模型失配沿 horizon 累积，信任域将不包含真值、预测证书将系统性乐观，递归可行性盾反而会在错误信念上"安全地"驶向不可恢复区，故必须以 **NEES 在线监测 + 协方差膨胀 + 证书 horizon 截断 + 保守 fallback** 四重护栏，宁可频繁重估，绝不把"自以为知道的状态"当作真值。
