# 第 9 轮（本次会话第 1 轮；技术基线 v8；本轮灵感：「开源硬件」×「模型量化」）
> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal v8（定义 493–531；引理 77–81；实验 E531–E550）。
> **本轮纪律**：开源硬件只改变**物理基座的可替换性与可审计性**，模型量化只改变**数值精度的分配方式**；二者都不改变 M₀/M₁ 的物理安全语义。新增模块一律为可选增强，任一失效必须逐级退回 v8（最终 FP32 全精度）。

## 0. 直觉与动机

**灵感 1（开源硬件 → 仪表系统的「物料清单 + 数据手册」）**
直觉：前八轮把所有保证都写在软件闭环里，仿佛算法可以无限透支硬件。开源硬件真正可迁移的不是「开放图纸」本身，而是四个工程事实：
1. **每个部件都有数据手册**：算力、功耗、热包络、时延、机械公差、寿命，都是**有界承诺**而非口号；
2. **物料清单（BOM）显式可审计**：换了哪块加速器、哪颗传感器、哪版固件，能逐项追溯；
3. **可替换、可修复**：模块热插拔是常态，而不是灾难；
4. **物理根信任**：安全元件/TPM 对 BOM + 固件 + 标定数据做度量签名。
把这四点搬进来：指标体系必须显式承认「**硬件包络是证书能力的上界**」。于是新增 `M_HW` 层监控热节流、功耗、时钟、公差与固件度量；每张证书附带**硬件证明** `At_HW`；计算模块可热替换，但替换必须过「影子 + 证明」双重门。开源硬件同时暴露新风险：**换了兼容接口但行为不同的模块**，会让证书继续「合法地」签发。

**灵感 2（模型量化 → 把精度当作可分配、可证明的资源）**
直觉：量化本质上是**对数值精度的受控退化**——它和本课题的「软→硬退化链」是同一件事在数值轴上的投影，只是以前从未被显式建模。量化的三个事实必须正面处理：
1. 误差有上界但非零：仿射量化 `q(x)=clamp(round(x/s)+z, q_min, q_max)` 的去量化误差满足 `|x̂−x| ≤ s/2 + 饱和项`；
2. 误差会**逐层传播放大**（Lipschitz 复合），早期感知层的误差往往主导最终指标误差；
3. 低位宽不是均匀可用的：安全关键层用 INT4 是拿命换功耗，而效率层用 INT8 是合理取舍。
核心机制：给每个指标层定义**量化误差上界** `ε_i^UB`，阈值加**保护带（guard band）** `τ'_i = τ_i ∓ ε_i^UB`，并维护一个总**误差预算** `E_total`，由控制器在「精度-时延-能耗-误差」之间做多选背包分配。

**交叉洞察（1+1>2）：精度是一份可以被硬件证明背书的合同**
开源硬件让「每个计算模块」成为可替换、有数据手册的部件；模型量化让「每个模块的数值误差」成为可声明、可累积的量。二者合流，得到一个此前不存在的对象：**带硬件证明的精度合同**（attested precision contract）。系统不再问「模型准不准」，而问「这块被证明过的硬件上、这份被哈希锁定的量化清单，其误差上界是否仍在总预算内」。若预算吃紧，系统不是盲目降速，而是**按层升级精度**或**收紧保护带**——两条都只让系统更保守，不会放宽安全。反过来，一个签名看似合法但低报了误差的量化清单，会把保护带算得过窄，令系统在决策边界上**确定性地、可复现地**漏掉真实违背。

## 1. 研究问题（本次会话第 1 轮）

- **Q1（精度即预算）**：如何把逐层量化误差上界组织成可加、可传播、可在线核算的误差预算，并在 50Hz 主环内完成「精度分配 → 保护带收紧」而不破坏 WCET？
- **Q2（保护带无空洞）**：如何设计保护带阈值 `τ'_i`，使「量化后的测量通过」严格蕴含「真实指标通过」，且 `ε_i^UB→0` 时逐位退化为 v8 阈值；同时保证收紧只发生在软层，M₀ 永远用不依赖量化的硬检查？
- **Q3（可替换硬件的可信边界）**：热替换计算模块时，如何用硬件度量 `At_HW` + 影子 canary 判定「新 BOM 的量化清单与实测行为一致」，并在不一致时回滚到已证明 BOM，而不把供应链风险带入 M₀？

## 2. 设计原则（P13–P15）

**P13 精度合同化（Attested Precision Contract, APC）**
每个计算模块 π 发布一份量化清单：
```
Q_π = (b, scheme, s, z, h(C_cal), ε^UB_π, T_π, E_π, h(fw))
```
其中 b 为位宽，scheme ∈ {FP32, FP16, INT8, INT4, QAT/PTQ}，s/z 为量化尺度与零点，`h(C_cal)` 为校准集哈希，`ε^UB_π` 为该模块对下游指标的误差上界，`T_π/E_π` 为时延/能耗。清单由安全元件签名，构成 BOM 的一部分。

**P14 误差预算与保护带（Error-Budget Guard Band, EBG）**
总预算 `E_total` 约束 `Σ_i w_i ε_i^UB ≤ E_total`；阈值按误差方向收紧：
```
τ'_i = τ_i − σ_i · γ_i · ε_i^UB ,  σ_i = +1（≤ 型指标）/ −1（≥ 型指标），γ_i ≥ 1
```
只在软层（M₂、M₃、M_dom、M_SLAM、M_HW、M_Q）生效；M₀/M₁ 始终用全精度重算或硬件比较器，不读量化值。`γ_i` 是保守余量，吸收误差界不紧的风险。

**P15 证明 + 影子热替换（Attested Shadow Swap, ASS）**
新模块先进入 shadow 期 K 个回合，只算不执行；同时校验 `At_HW=(h(BOM),h(fw),h(Q),n,Sig)`。只有 `trust_HW ≥ τ_trust` 且 canary 一致率 `≥ τ_agree` 且影子期零 M₀ 违背，才允许替换；否则回滚到已证明 BOM。精度切换带**迟滞 + 最小驻留时间**，防抖。

## 3. 与基线的接口（如何退化）

- 量化清单缺失/未签名 ⇒ 该模块按「最坏误差」处理并强制安全层全精度重算，语义等价 v8（代价上升）；
- 误差预算控制器失效 ⇒ 静态精度表（安全层 FP16/FP32，效率层 INT8）+ 固定保守保护带；
- 保护带模块失效 ⇒ M₀/M₁ 不读量化值、全精度重算，等价 v8 数值路径；
- 硬件证明失效 ⇒ 冻结 BOM、禁热替换，沿用已锁定 BOM，语义等价 v8；
- 量化漂移监控失效 ⇒ `risk_Q ≡ 0`，保护带退化为静态最坏上界；
- 全部失效 ⇒ 全层 FP32、风险向量退回 5 维，逐位等价 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

## 4. 预期贡献

1. **带证明的精度合同（APC）**：把「模型量化」从部署细节提升为一等公民，使每层指标的数值误差可声明、可核算、可审计；
2. **误差预算保护带（EBG）**：给出「量化测量通过 ⇒ 真实指标通过」的无空洞充分条件，并证明 `ε→0` 时逐位退化 v8；
3. **证明 + 影子热替换（ASS）**：把开源硬件的可替换性与供应链风险纳入证书，热替换有回滚、无静默语义漂移；
4. 完整的**硬件包络-精度预算-保护带-指标-动作**闭环：E551–E570 覆盖误差传播、预算分配、防抖、证明、热替换、漂移与实机验证。

## 5. 本轮最大风险

**一句话**：整套无空洞保证都建立在「`ε^UB` 真的是上界」这一前提上——一份签名合法、版本兼容、却低报了量化误差的清单（或一块证明通过但实测行为已漂移的加速器）会让保护带过窄，使系统在新硬件上**确定性地、可复现地**在决策边界漏判 M₀，而所有证书看起来依然完美。

**新增定义 532（精度合同 PrecisionContract）** 每个计算模块 π 的可审计精度声明：
```
Q_π = ( b_π, scheme_π, s_π, z_π, h(C_cal,π), ε^UB_π, T_π, E_π, h(fw_π) )
```
其中仿射量化为 `x̂ = s·(clamp(round(x/s)+z, q_min, q_max) − z)`。清单由安全元件签名，任何字段被篡改都会使 `At_HW` 校验失败。

**新增定义 533（硬件证明 AttestedBOM）** 物料清单与运行环境的物理根信任：
```
At_HW = ( h(B), h(fw), h(Q), n, Sig_{sk}( h(B) || h(fw) || h(Q) || n ) )
trust_HW = exp( −risk_SUP(B) ) · 1[Sig verify ∧ h(B)=h(B_known_good)]
```
其中 `n` 为防重放 nonce，`B_known_good` 为审计通过的锁定 BOM。签名只证明「来源与完整性」，不证明「行为正确」——后者由 ASS 的影子 canary 补足。

**新增定义 534（八层指标闭合 PrecisionAwareMetricLadder）**
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_HW, M_Q)
```
`M_HW` 监控热包络/功耗/时钟/公差/固件度量是否越出数据手册；`M_Q` 监控误差预算使用率 `E_used/E_total`、饱和率与偏差。二者均有到 M₀ 的退化映射 `δ_HW, δ_Q`。

**新增定义 535（量化误差上界 QuantErrorBound）** 设指标函数可分解为 `f = f_L∘…∘f_1`，各层 `f_l` 为 `L_l`-Lipschitz，则
```
ε_i^UB ≤ (Π_{l=1..L} L_l)·ε_x + Σ_{l=1..L} (Π_{k>l} L_k)·ε_l
```
其中 `ε_x` 为输入量化误差，`ε_l` 为第 l 层权重/激活量化误差（由 `s_l/2` 与饱和界给出）。该式给出保守可计算上界，并揭示**误差主导层**（通常是感知前端）。

**新增定义 536（误差预算 ErrorBudget）**
```
E_total = 由任务风险等级设定的标量（如 1e-2）
E_used  = Σ_i w_i · ε_i^UB ,   w_i 为层语义权重（M₀/M₁ 权重大）
```
可行性要求 `E_used ≤ E_total`；精度分配的目标是在满足该约束下最小化时延/能耗。

**新增定义 537（保护带阈值 GuardBandThreshold）**
```
τ'_i = τ_i − σ_i · γ_i · ε_i^UB ,  γ_i ≥ 1
```
仅在软层生效。M₀/M₁ 使用全精度重算结果或硬件比较器，`ε^UB=0` 时 `τ'_i = τ_i`（逐位退回 v8）。收紧顺序固定为：先 DA-OTL（`τ_i(t)`），再 GBT（`τ'_i(t)`）——因为保护带必须作用在**最终阈值**上，顺序不可交换。

**新增定义 538（误差预算控制器 ErrorBudgetController）** 多选背包（MCKP）：
```
minimize   Σ_π T_π(b_π)
s.t.       Σ_i w_i ε_i^UB(b_i) ≤ E_total
           b_i ≥ p_min(i),  b_i ∈ {FP32,FP16,INT8,INT4}
           T_总 ≤ T_budget,  E_总 ≤ E_budget
```
用 DP 或按「单位时延换取的误差下降」贪心求解；精度只允许**升级到更保守**的方向由安全规则强制（安全层不得低于 `p_min`）。

**新增定义 539（混合精度调度 MixedPrecisionScheduler）** 带迟滞与驻留：
```
若 E_used/E_total > θ_hi 连续 T_hi 拍 → 升级高权重层精度
若 E_used/E_total < θ_lo 连续 T_lo 拍 → 允许降级低权重层
否则保持；相邻两次切换间隔 ≥ T_dwell
```
`θ_lo < θ_hi` 且 `T_dwell > c_sw`，保证无极限环抖动。

**新增定义 540（精度切换 WCET）**
```
WCET_总 = WCET_主环 + Σ_{switch in window} c_sw + c_verify
```
`c_sw` 为权重重载/流水线排空耗时，`c_verify` 为证明校验耗时；调度器把每秒切换次数上界 `N_sw` 写入证书，保证 `WCET_总 ≤ 22ms`。

**新增定义 541（量化漂移监控 QuantDriftMonitor）**

## 2. 形式化定义（要点）

**定义 534（八层指标闭合）** 在 v8 六层之上新增 `M_HW`、`M_Q`；两层的退化映射均定义为「直接触发 M₀ 硬检查 + 缩短 `H̃`」，与既有 `δ_dom, δ_SLAM` 同尺度。

**定义 535（误差传播）** 采用 Lipschitz 复合界，允许逐层在线累乘；对非线性激活使用其全局 Lipschitz 常数（如 ReLU 为 1），对注意力/归一化层取标定实测的经验界并乘安全系数 `γ_i`。

**定义 537（保护带）** 关键性质是「只收紧」：`∂τ'_i/∂ε_i^UB = −σ_i γ_i`，故 `ε` 增大时 `≤` 型阈值变小、`≥` 型阈值变大，安全不变式单调增强。

**定义 538（预算分配）** 复杂度 `O(|B|·K·E_total/δ_E)`；实践中 `|B|≤8`、`K=4`，可离线预算表 + 在线查表，主环 `O(1)`。

**定义 540（切换 WCET）** 通过每秒切换次数上界与离线测得的 `c_sw`，把切换成本折算为常数，纳入 22ms 预算。

**定义 543（风险向量）** 新增两维与 v8 的 `risk_SLAM` 正交；`risk_Q` 单调于预算使用率与饱和率，`risk_HW` 单调于热/功耗越界与证明失配。

```python
# IP-372 QuantErrorPropagator：基于 Lipschitz 复合的逐层误差上界
class QuantErrorPropagator:
    def __init__(self, layer_lipschitz, input_err):
        self.L = list(layer_lipschitz)   # [L_1..L_L]
        self.input_err = input_err

    def layer_bounds(self, layer_quant_err):
        """返回每个指标层的 ε^UB；layer_quant_err[l] = ε_l"""
        L = self.L
        n = len(L)
        bounds = []
        prefix = 1.0
        for i in range(n):
            prefix *= L[i]
        # 输入项
        base = prefix * self.input_err
        # 逐层项：Π_{k>l} L_k · ε_l
        suffix = [1.0] * n
        acc = 1.0
        for l in range(n - 1, -1, -1):
            suffix[l] = acc
            acc *= L[l]
        layer_terms = [suffix[l] * layer_quant_err[l] for l in range(n)]
        total = base + sum(layer_terms)
        # 单调拆分为各指标层（保守均摊 + 主导层标注）
        return {
            'total': total,
            'per_layer': layer_terms,
            'dominant': int(np.argmax(layer_terms)) if layer_terms else -1,
        }


# IP-373 ErrorBudgetController：多选背包 + 安全下界
class ErrorBudgetController:
    PREC = ['FP32', 'FP16', 'INT8', 'INT4']

    def __init__(self, E_total, weights, latency_table, energy_table,
                 p_min, gamma, alpha=0.5):
        self.E_total = E_total
        self.w = weights               # 层语义权重
        self.T = latency_table         # T[layer][prec]
        self.E = energy_table          # E[layer][prec]
        self.p_min = p_min             # 最低精度索引
        self.gamma = gamma
        self.alpha = alpha

    def allocate(self, err_table):
        """err_table[layer][prec] = ε^UB；返回 (assignment, E_used, T_total)"""
        # 安全规则：先钉死 p_min
        base = {i: self.p_min[i] for i in range(len(self.w))}
        E_used = sum(self.w[i] * err_table[i][base[i]] for i in base)
        T_tot = sum(self.T[i][base[i]] for i in base)
        # 贪心：每次挑选“单位时延换取误差下降最大”的升级
        while E_used > self.E_total:
            best, best_gain = None, -1.0
            for i in base:
                if base[i] == 0:      # 已 FP32
                    continue
                nxt = base[i] - 1     # 更高精度
                d_err = err_table[i][base[i]] - err_table[i][nxt]
                d_T = self.T[i][nxt] - self.T[i][base[i]]
                gain = (self.w[i] * d_err) / max(d_T, 1e-6)
                if gain > best_gain:
                    best, best_gain = (i, nxt, d_err), gain
            if best is None:
                break                 # 无法再升，交由 M_Q 触发退化
            i, nxt, d_err = best
            E_used -= self.w[i] * d_err
            T_tot += self.T[i][nxt] - self.T[i][base[i]]
            base[i] = nxt
        return base, E_used, T_tot


# IP-374 GuardBandThreshold：只收紧、可退化
class GuardBandThreshold:
    def __init__(self, tau, sigma, gamma):
        self.tau = dict(tau)           # 软层阈值
        self.sigma = dict(sigma)       # +1 / -1
        self.gamma = dict(gamma)

    def tighten(self, eps_ub):
        out = {}
        for i, t in self.tau.items():
            out[i] = t - self.sigma[i] * self.gamma[i] * eps_ub.get(i, 0.0)
        return out
    # 当 eps_ub 全 0 ⇒ out == tau（逐位退回 v8）


# IP-371/378 硬件证明与影子热替换
class AttestedShadowSwap:
    def __init__(self, known_good_hash, tau_trust=0.9,
                 tau_agree=0.95, K=20):
        self.known_good = known_good_hash
        self.tau_trust = tau_trust
        self.tau_agree = tau_agree
        self.K = K
        self.shadow_count = 0
        self.shadow_violations = 0

    def verify_attestation(self, at_hw, pubkey):
        ok = (at_hw['h_B'] == self.known_good
              and verify_sig(at_hw, pubkey))
        return ok, (1.0 if ok else 0.0)

    def shadow_step(self, agree, m0_violated):
        self.shadow_count += 1
        if m0_violated:
            self.shadow_violations += 1
        return (self.shadow_count >= self.K
                and self.shadow_violations == 0
                and agree >= self.tau_agree)

    def can_swap(self, trust_hw, agree):
        return (trust_hw >= self.tau_trust
                and agree >= self.tau_agree
                and self.shadow_count >= self.K
                and self.shadow_violations == 0)

    return C, cert, claims, metrics, rewards
```

## 4. 推导

**引理 82（保护带无假通过 / No False-Pass）** 设真实指标 `m`，量化估计 `m̂`，`|m̂−m| ≤ ε^UB`。对 `≤` 型安全条件 `m ≤ τ`，令 `τ' = τ − ε^UB`，判决 `d = 1[m̂ ≤ τ']`。则 `d=1 ⇒ m ≤ m̂+ε^UB ≤ τ'+ε^UB = τ`。故凡判决为「安全」，真实指标必安全；量化只能造成**假阴性（误报不安全）**，绝不造成**假阳性（漏报危险）**。`≥` 型由 `σ_i=−1` 对称成立。∎

**引理 83（收紧单调性与极限退化）** `τ'_i = τ_i − σ_i γ_i ε_i^UB`。因 `γ_i≥1, ε_i^UB≥0`：`≤` 型 `τ'_i ≤ τ_i`，`≥` 型 `τ'_i ≥ τ_i`，故保护带只收紧不放宽；且 `ε_i^UB→0` 时 `τ'_i→τ_i`，逐位退回 v8。复合顺序上 `GBT∘OTL ≠ OTL∘GBT`，必须把 GBT 放在最后（作用于最终阈值），否则 OTL 的下一拍会把保护带吞掉。∎

**引理 84（误差传播有界与预算可行性）** 由定义 535，`ε_i^UB ≤ (Π L_l)ε_x + Σ_l (Π_{k>l}L_k)ε_l`。有限 Lipschitz 常数与有限量化误差 ⇒ `ε_i^UB` 有限。EBC 在 `E_used > E_total` 时持续升级精度；因 FP32 档 `ε≈0`，最迟在所有层取 FP32 时 `E_used ≈ 0 ≤ E_total`，故分配一定终止且可行（若无 FP32 硬件，则 M_Q 触发 Level-3 全精度外包重算）。∎

**引理 85（精度切换 WCET 有界且无抖动）** 设每秒切换次数上界 `N_sw`，单次切换成本 `c_sw`，证明校验 `c_verify`。则附加开销 `≤ N_sw·c_sw + c_verify` 为常数。迟滞 `θ_lo<θ_hi` 与最小驻留 `T_dwell` 使预算使用率必须跨越一个非零带才允许反向切换，排除极限环；故切换次数在任意窗口内有限，WCET 不随时长增长。∎

**引理 86（硬件证明可靠性）** 在「安全元件未被攻破、签名方案 EUF-CMA、哈希抗碰撞」的假设下：`At_HW` 校验通过 ⇒ 实际 BOM/固件/量化清单与签名时一致（除可忽略概率）。但**证明不蕴含行为正确**：一个合法但低报 `ε^UB` 的清单仍可通过。故 `trust_HW` 只回答「是不是这份东西」，行为一致性必须由定义 544 的影子 canary 回答。二者缺一不可。∎

**引理 87（漂移可检测性）** 若量化尺度因传感器增益变化产生偏差 `b`，则 `bias_q` 的滑动均值收敛到 `b`（无量化噪声时期望意义），且饱和率随增益偏离单调上升。取 `τ_bias, τ_sat` 小于最小可容忍安全偏移，可在 `W` 拍内检出超过阈值的漂移。检测延迟 `≤ W/50 Hz`。∎

**引理 88（六级退化正确性）** 六级退化接口两两正交：APC 只影响 `ε^UB` 来源，EBC 只影响 `b_i`，GBT 只影响软层 `τ'`，PBA/HEM/ASS 只影响 BOM 冻结与 `risk_HW`，QDM 只影响 `risk_Q` 与 `γ`。故任意子集失效可独立组合；全失效时 `ε→0`、`risk_Q=risk_HW=0`、BOM 冻结、阈值回到 `τ_i(t)`，逐位等价 v8。∎
