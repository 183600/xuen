# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「技能组合」×「动力学」）

> R69 把不确定性一分为二，问出「我该向谁求证」。但它默认了一个更深的前提：**只要每个技能/策略单独被认证、单独被标定、单独被消歧，把它们接起来就是安全的**。这在模块化机器人里恰恰是最危险的假设。单独的行走、单独的抓取、单独的递送各自都有安全证书；可一旦在手中交接、在运动中换挡、两条技能同时争用同一个关节，失稳往往发生在**两段都「合格」的地方之间**——接缝（seam）不属于任何一方，因此也没有任何一方为它负责。R69 自陈的最大风险是「用学习到的置信度发放执行许可」；R70 发现还有一条同构但更隐蔽的漏洞：**用每个技能局部的证书去签发全局的执行许可**。
>
> 本轮两个灵感正好补上「组合」这块缺失：
> - **技能组合**给出组合代数——串联、并联、切换、叠加四种算子，以及它们各自的 assume-guarantee 契约与失效模式；它迫使我们问「Post(A) 是否真的落在 Pre(B) 里」「两条技能是否争用同一个自由度」「切换会不会抖振」。
> - **动力学**给出可组合的守恒量——能量、耗散、无源性（passivity）、端口哈密顿结构。动力学的价值不在「更准地预测轨迹」，而在**提供一个跨技能可加的账本**：只要每个子系统耗散、接缝互联是无源的，整体耗散性可以由局部耗散性**推导**出来，而不必重新认证整个系统。
>
> 核心命题：**安全不是一个技能的性质，而是接缝的性质；R70 把「技能」升级为带耗散契约的可组合单元，把「组合」升级为受接缝证书与能量账本约束的代数运算，并在 R69 的 aleatoric/epistemic 二分之外补上第三类「结构化不确定性」——对互联模型本身的不确定，它既问不出来、也平均不掉，只能被动力学结构吸收或被在线功率残差抓住。当组合不可认证时，逐指令退化为 R69（去问）或 R68（收紧）。** 命名 **BRAID-RAS**（Braided Risk-adaptive Interconnection of Dissipative skills）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这些各自合格的技能，凭什么能被安全地编在一起——谁为接缝签字**」——不确定性不只在单个技能内部，更在两段技能之间那条没人负责的缝里。

## 0. 直觉与动机

**灵感 1（技能组合 → 安全住在接缝里，不在技能里）**
直觉：搭积木时，每块积木都合格，不代表塔不会倒；倒的那一刻，力恰好传过「两块都合格」的接触面。机器人技能也一样：一个抓取技能在「已抓住」状态下被认证安全，一个行走技能在「空手」状态下被认证安全，但「边走边抓」或「抓着走」这个组合状态可能从未被任何一方认证过。技能组合研究的真正贡献不是「把动作排成序列」，而是把**组合本身**变成一个有语义、有契约、可验证的对象：串联要求前置/后置条件对齐，并联要求权限不冲突，切换要求驻留时间与迟滞，叠加要求共享不变式。R69 只关心「这一段动作该不该做」，R70 必须先问「这一段和下一段之间，谁保证状态落在对方的合法域里」。**很多灾难不是某个技能错了，而是两个都对的动作在接缝处互相拆台。**

**灵感 2（动力学 → 能量是可加的，因此是可组合的）**
直觉：概率置信度不能相加——两个 0.9 的置信度拼起来不会自动变成 0.9；安全集合也不能简单相加——两个不变集的并可能不是不变的。但**能量可以**。如果每个技能都是一个耗散系统（它消耗能量、不凭空产生能量），并且技能之间的互联是「功率保持」或「耗散」的，那么所有技能的储能函数之和就是一个合法的储能函数，整体的稳定性由局部的耗散性**结构性**地推出。这就是无源性/端口哈密顿理论给组合问题的礼物：它把「重新认证整个巨系统」换成「认证每个模块 + 认证每条接缝」。R70 的数学脊椎因此不是更复杂的概率模型，而是一条**能量账本**：串联要付交接能，切换要付切换冲量，并联要付耦合功率，只要账本不赤字，组合就成立。

**灵感 3（能量槽 → 让任意学习技能变成可组合单元）**
直觉：真实的学习策略（R69 的流匹配策略、各类 VLA）几乎都不是无源的：它可能在某些状态下「凭空加速」，把不确定性、接触、甚至对抗扰动放大成能量注入。要求「只许用无源技能」等于放弃学习。能量槽（energy tank）给出一个工程上优雅的折中：给每个技能配一个有限储能槽，非无源的那部分动作只能从槽里**借**能量，耗散时再**还**回去；槽见底就自动把非无源分量缩放到零。于是任意学习技能都能被「驯化」成一个带能量预算的可组合单元，代价是它一旦挥霍完预算就会失去权限。这把 R69 的「信不信模型」换成了「模型还能透支多少能量」——一个可审计、可耗尽、可拒绝的物理量。

**灵感 4（结构化不确定性 → R69 的二分法漏了第三类）**
直觉：R69 把不确定性分成 aleatoric（噪声，问了也没用）与 epistemic（歧义，可以问出来）。但「我以为技能 A 的出口在技能 B 的入口里，其实不是」「我以为接缝没有时延，其实有 20ms」「我以为两个技能不争用同一个关节，其实争用」——这类不确定性**既不是噪声，也不是靠问一句能消解的语义歧义**，它是关于**互联模型本身**的结构性错误。问操作员「你希望我抓杯子吗」不会告诉你动力学里有没有未建模的时延。R70 因此引入第三类 **U_struct（结构不确定性）**：它只能被系统辨识、鲁棒裕度、或动力学结构（耗散性）吸收，或者在组合拓扑层面被绕开。把 U_struct 混进 U_epi 会导致系统去「问一个物理问题」，把 U_struct 混进 U_ale 会导致系统无谓地永远保守。这是本轮最重要的概念修正：**R69 没有错，它的二分不完整。**

**灵感 5（组合即攻击面 → 假证书比没证书更危险）**
直觉：R69 的交互即使问错，最坏是得到一个错误答案，还能再问、还能降级。组合失稳往往**不可逆且静默**：每个子系统都在报告「我正常」，只有接缝在注入能量；等状态越出不变集时，已经来不及了。更糟的是，组合引入了全新的攻击面：伪造一份看起来合法的技能契约、在认证与执行之间偷换技能版本（TOCTOU）、故意让某个技能把能量槽耗尽以便在关键时刻夺走权限、或训练一个「单独安全、一到接缝就使坏」的技能。R70 的安全性押在「契约与接缝模型是真的」上——**当证书本身可以被伪造时，系统会带着一张错误的全局证明去执行，并且因为「已经证明过了」而取消 R69 仅存的怀疑**。所以本轮必须同时交付：契约来源与版本、接缝残差的独立通道、证书吊销的单调传播、以及「单张证书不得授权不可逆组合」的纪律。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（BRAID-RAS 总览与四不变式）** BRAID-RAS = (SKG, PHA, SEC, EBA, SWX, SRC, CAP, CRV, UST3, AIC-BRAID, J_BRAID, RAS-WM†)。四不变式：
(i) **在线零学习写**（继承 R68 定义 276-i）；
(ii) **接缝证书先于运动**：任何串联/并联/切换/叠加组合都必须携带可检查的接缝证书；不存在「隐式组合」——两段技能被先后调用而中间没有证书，视为未认证；
(iii) **能量账本非负**：所有模块的储能预算之和，减去所有接缝的交接/切换/耦合成本，必须 ≥ 0；任一割集赤字即禁止该组合；
(iv) **严格包含**：单技能图、接缝不可认证、或 U_struct 主导时，逐指令退化为 R69（语义歧义去问）或 R68（未知动力学只收紧）（定理 19）。

**定义 311（技能作为耗散动力系统 PHA）** 技能 σ_i 是带端口哈密顿结构的受控动力系统：
ẋ = (J_i(x) − R_i(x))∇H_i(x) + g_i(x)u_i， y_i = g_i(x)ᵀ∇H_i(x)，
其中 J_i 反对称（内部能量路由），R_i ⪰ 0（耗散），H_i ≥ 0 为储能（能量函数），u_i, y_i 为端口功率变量。若满足
Ḣ_i = ∇H_iᵀẋ ≤ u_iᵀ y_i − ρ_i(x)，ρ_i ≥ 0，
则称 σ_i 关于供给率 s_i = u_iᵀy_i − ρ_i 耗散。**关键性质：耗散性对功率保持互联封闭**（引理 19）——这正是「动力学」相对于「概率」在本轮的核心价值。

**定义 312（能量槽与可组合化）** 对任意学习策略 π_i，把它拆成无源骨干 π_i^pass 与非无源残差 u_i^res，并用能量槽 T_i ∈ [0, T_i^max] 调制：
u_i = π_i^pass(x) + α_i(T_i)·u_i^res(x)， α_i = clip(T_i/T_i^ref, 0, 1)，
Ṫ_i = −α_i·u_i^resᵀ y_i^res（耗散时充电，注入时放电）。
于是合成端口满足 Ḣ_i ≤ u_iᵀy_i（即无源），槽见底（T_i→0）时 α_i→0、技能退回无源骨干；若无无源骨干，则权限归零。能量槽把「任意学习技能」变成「带有限透支额度的可组合单元」。

**定义 313（技能契约）** 技能契约
C_i = (Pre_i, Post_i, Inv_i, H_i, β_i, T_i^0, T_i^max, τ_i^dwell, Ω_i, v_i, h_i^cal)，
其中 Pre/Post 为进入/退出状态集，Inv_i 为受控不变安全集，β_i 为储能预算（H_i ≤ β_i on Inv_i），τ_i^dwell 为最小驻留时间，Ω_i 为**权限掩码**（允许驱动的执行器/自由度子集），v_i 为版本，h_i^cal 为标定/溯源哈希。C_i 认证 ⇔
(a) Inv_i 在 σ_i 权限内受控不变；
(b) 沿 Inv_i 内轨迹 H_i ≤ β_i；
(c) Pre_i, Post_i 非空且与 Inv_i 相容；
(d) 版本与溯源哈希可验证且未过期。

**定义 314（组合代数）** 四种算子及其契约：
- **串联** σ_j ∘ σ_i：先 i 后 j。要求 Post_i ⊆ Pre_j；接缝管 𝒯_ij；能量 β_ij = β_i + β_j + ΔH_ij^hand + ε_hand。
- **并联/叠加** σ_i ⊕ σ_j：同时运行。要求权限解耦 Ω_i ∧ Ω_j = 0，或存在仲裁且重叠权限 ≤ Ω_max；耦合功率 P_ij = u_iᵀy_j + u_jᵀy_i 必须 ≤ 0（耗散互联），否则需计入耦合增益上界 κ_ij‖u‖²。
- **切换** σ_j ◁ σ_i：由守卫 G_ij 触发。要求接缝管、驻留时间 τ^dwell ≥ max(τ_i,τ_j)、迟滞带，并预留切换冲量 ΔH_ij^sw。
- **优先叠加** σ_j ⊳ σ_i：冲突时 j 优先。要求仲裁后的合成指令仍落在 Inv_i ∩ Inv_j（或显式合并不变集）内。
「组合树」是由上述算子构成的有根表达式；每个内部节点必须携带该算子的接缝证书。

**定义 315（接缝与交接管 SEC）** 对边 (i→j)，接缝证书是一个五元组
S_ij = (𝒯_ij, σ_ij, Ω_ij, τ_ij^dwell, v_ij)，
- **可达性**：存在从 Post_i 到 Pre_j、且全程留在 𝒯_ij 的轨迹；
- **不变性**：𝒯_ij ⊆ Inv_i ∪ Inv_j（每个点至少被一方守护）；
- **能量余量**：σ_ij = β_j − sup_{x∈𝒯_ij} H_j(x) − ΔH_ij^sw ≥ 0；
- **权限交接**：Ω_ij 给出交接窗口内的仲裁掩码，重叠权限持续时间 ≤ τ_over^max；
- **版本绑定**：v_ij 同时绑定 v_i、v_j 与两者的标定哈希。
S_ij 有效 ⇔ 上述五项全部通过；**接缝无效时，两段技能不得被宣称组合安全**（这正是 R69 缺失的那张签字）。

**定义 316（组合能量账本与最小割 EBA）** 把组合树展开为有向技能图 G=(V,E)，节点预算 β_i，边成本 ΔH_ij（交接 + 切换 + 耦合上界，可为负表示净能量回收），设总能量容量 B_cap、任务最小需求 B_req。对任意 s-t 割 (S, V∖S)，定义**能量盈余**
Surplus(S) = Σ_{i∈S} β_i − Σ_{i∈S, j∉S} ΔH_ij − B_req。
组合可认证 ⇔ min_{s-t 割} Surplus(S) ≥ 0 且 B_cap 约束满足。由最大流最小割，可用一次最大流在 O(V·E) 内求出瓶颈割；**瓶颈割就是最需要被加预算或改拓扑的接缝**。该判据是保守的（充分非必要），因为耗散只会让实际能量更低。

**定义 317（结构化不确定性三分与路由 UST3）** 在 R69 的 U_ale（定义 297）与 U_epi 之外，定义
U_struct = 关于互联模型（接缝时延、接触耦合、权限划分、技能版本是否如声明）的模型形式不确定性。
三者语义不同、不可加和，分通道处置：
- U_ale → R68 的 λ_floor（噪声，收紧是对的）；
- U_epi → R69 的 MINT/CIA（语义歧义，可以去问）；
- U_struct → R70 的 SEC/EBA（结构错误，问不出来，只能辨识、鲁棒吸收或改拓扑）。
判据：若残差表现为「问一句就能改变决策」，归 U_epi；若「再怎么问系统行为也不变，但动力学账本对不上」，归 U_struct。把 U_struct 误当 U_epi，会让系统去问一个物理问题；误当 U_ale，会让系统永久保守。

**定义 318（驻留时间切换与无 Zeno SWX）** 切换逻辑维护守卫 G_ij、迟滞带 h_ij、最小驻留 τ_i^dwell 与切换计数。仅当
(now − t_last ≥ τ_current^dwell) ∧ G_ij(x) ∧ ¬G_ji(x) ∧ S_ij 有效
才允许切换；且每次切换要求储能下降
H_j(x(t_k)) ≤ H_i(x(t_k)) − ΔH_min 或 H_j ≤ (1−κ)H_i，
否则视为「无效切换」并保持原技能。由此切换时刻两两间隔 ≥ τ^dwell > 0，有限时域内切换次数有界（排除 Zeno 抖振）。

**定义 319（接缝功率残差 SRC）** 观测储能变化率与端口功率，定义滑动窗残差
r_pass(t) = max(0, (1/Δt)∫_{t−Δt}^{t} [Ḣ_i^obs − (u_iᵀy_i − ρ_i^min)] dτ)。
名义模型下 r_pass ≤ ε_obs。**未建模时延、接触碰撞、权限争用、对抗能量注入都会表现为 r_pass 升高，而传感器残差 r_res 与动作似然 Δa 可能同时正常**。于是 (r_res, Δa, r_pass) 构成三条正交通道：
- 真漂移：r_res↑、Δa↑、r_pass≈0；
- 缓变故障被标定吸收：r_res≈0、Δa↑、r_pass 可变；
- **接缝能量注入：r_res≈0、Δa≈0、r_pass↑**。
这是 R68 的标定通道与 R69 的行为似然通道之外的第三条独立第二意见。

**定义 320（组合感知规划 CAP 与组合树）** 规划器不只输出任务动作序列，而输出**组合树** τ：叶为技能契约实例，内部节点为组合算子，边为接缝证书。搜索目标是在满足任务目标的前提下最小化「鲁棒性成本」：
J(τ) = Σ_i C_exec(i) + Σ_{e∈τ} C_seam(e) + λ_E·[−min-cut surplus(τ)]₊ + λ_U·U_struct(τ)。
若不存在同时满足全部证书与账本的 τ，返回 none，交由 R69 就**语义歧义**发问、或由 R68 就**未知动力学**收紧。

**定义 321（证书吊销与单调降级 CRV）** 证书带版本 v 与依赖集 Dep。若技能 i 被标定门/残差/审计判为失效，则
Revoke(i) ⇒ ∀τ: i ∈ τ, Revoke(τ)，
即吊销沿组合树**单调、传递**传播；任何持有旧版本证书的执行请求在 TOCTOU 检查点被拒绝。降级顺序固定为：
compose（接缝与账本均通过）→ reduce（R69 问询消解语义歧义）→ retreat（R68 纯保守）。
任一步失败，λ 单调不降，禁止「吊销后仍按已证明执行」。

**定义 322（组合威胁模型 AIC-BRAID）** 在 R69 的 ℰ_FLUID 上新增：
- **ℰ_seam**：时延注入、接触耦合、权限竞争、认证与执行之间的版本偷换（TOCTOU）；
- **ℰ_tank**：诱导某技能耗尽能量槽以在关键时刻夺走权限，或利用能量槽掩盖非无源行为；
- **ℰ_graph**：单独安全、接缝作恶的「特洛伊技能」，伪造契约/溯源，陈旧证书复用。
ℰ_BRAID = ℰ_FLUID × ℰ_seam × ℰ_tank × ℰ_graph。核心判据：**假接缝证书比没有证书更危险**，因为它取消了 R69 仅存的怀疑，且失稳往往不可逆。

**定义 323（证书 J_BRAID）** J_BRAID = (J_FLUID, contract_hashes, seam_slacks, ledger_mincut, tank_levels, dwell_log, r_pass_p95, revocation_epoch, braid_ver)。
Valid ⇔ Valid(J_FLUID) ∧ 所有 C_i 与 S_ij 有效 ∧ min-cut ≥ 0 ∧ 无未处理吊销 ∧ r_pass ≤ τ_pass ∧ 权限重叠 ≤ Ω_max。

    return registry.put(contract)                 # O(1) 哈希索引

# IP-265 PHA：能量槽把任意学习技能驯化成耗散单元
class EnergyTankSkill:

        u_pass, y = self.passive_backbone(x)

# IP-266 SEC：接缝五元组认证（可达/不变/能量/权限/版本）
def certify_seam(ci, cj, tube):

    if not subset(tube, union(ci.inv, cj.inv)): return Fail("invariant")
    slack = cj.beta - sup_H(cj.H, tube) - switch_cost(tube)
    if slack < 0:                               return Fail("energy_slack", slack)
    if overlap(ci.authority, cj.authority) > OMEGA_MAX: return Fail("authority")
    if not version_bind(ci, cj):                return Fail("version")
    return SeamCert(slack, dwell=max(ci.dwell, cj.dwell), tube=tube)

# IP-267 EBA：组合能量账本 = 最小割盈余
def ledger_ok(tree, B_req):

    return max_flow_min_cut(G, node_budget="beta",
                            edge_cost="deltaH") - B_req >= 0
    # 返回的瓶颈割直接指出最该加预算/改拓扑的接缝

# IP-268 SWX：驻留 + 迟滞 + 能量下降的切换
def next_skill(state, now, last_switch):

    cands = [j for j in graph[current]
             if guard(current, j, state)
             and not guard(j, current, state)          # 迟滞
             and seam[current, j].valid
             and energy_drops_enough(current, j, state)]  # 排除无效切换
    return argmin(cands, key=lambda j: cost_to_switch(current, j)) if cands else current

    return max(0.0, (dH - (u @ y - skill.rho_min)) / dt)
    # r_pass↑ 且 r_res≈0、Δa≈0 ⇒ 接缝注入能量（时延/接触/攻击）

# IP-270 CAP：组合感知规划（证书剪枝的 A*）
def plan_composition(task, skills, belief):
    frontier = priority_queue([CompositionTree(task.start, skills)])
    while frontier:
        tree = frontier.pop()
        if not all(cert(leaf, belief) for leaf in tree.leaves): continue
        if not all(certify_seam(*e).valid for e in tree.edges): continue
        if not ledger_ok(tree, task.B_req): continue        # 账本剪枝
        if tree.solves(task.goal): return tree
        frontier.extend(tree.expand(skills))                # 串联/并联/切换/叠加
    return None                                  # → R69 问 / R68 收紧

        return M.r68_retreat(o, U_cal)                        # 结构不可认证 → 收紧

## 3. 推导

**引理 19（耗散组合引理）** 设子系统 σ_i 关于供给率 s_i = u_iᵀy_i − ρ_i 耗散，且互联映射是功率保持的（内部端口满足 Σ_i u_iᵀy_i ≤ 0）。则 H = Σ_i H_i 满足
Ḣ ≤ Σ_i s_i = −Σ_i ρ_i ≤ 0（无外部输入时），
即整体耗散、储能函数可加。系：**只要每条接缝的互联是耗散/功率保持的，整体稳定性可由局部耗散性 + 接缝证书推出，无需重新辨识整个系统**。串联额外付出交接能 ΔH^hand、切换额外付出冲量 ΔH^sw，它们只消耗账本、不破坏耗散方向。

**引理 20（最小割组合可行性）** 定义割盈余 Surplus(S)（定义 316）。若对所有 s-t 割都有 Surplus(S) ≥ 0 且容量约束满足，则组合树的任意可达执行都不会耗尽总能量预算；反之，若存在割 S* 使 Surplus(S*) < 0，则该割必然在某个可达阶段被跨越，且跨越所需能量超过预算。故最小割是组合可行性的**充分**判据与瓶颈定位器。系：EBA 不只是一个「过/不过」的门，它输出**该给哪条接缝加预算**的可操作诊断。

**引理 21（驻留时间排除 Zeno）** 若每次切换满足最小驻留 τ^dwell > 0 与迟滞带 h > 0，则切换时刻序列 {t_k} 满足 t_{k+1} − t_k ≥ τ^dwell，有限时域内切换次数 ≤ T/τ^dwell；再叠加储能下降条件 H_j ≤ (1−κ)H_i，多储能函数沿切换单调下降，得到实用稳定（practical stability）。**没有驻留时间的组合会在守卫边界上抖振，抖振本身就在往接缝里注入冲量能量**——这是纯组合层（不含动力学）无法看见的失效。

**引理 22（接缝残差的可检测性）** 设未建模功率注入为 ΔP(t)，观测噪声上界 ε_obs。若 ΔP 在窗口内持续满足 ΔP > τ_pass + ε_obs，则 r_pass 必然越阈；且只要监控频率高于状态离开不变集的最短时间，检测发生在违反不变式之前。更关键的是，ΔP 不出现在 r_res（传感器自洽仍可通过标定吸收）与 Δa（动作仍可能处于策略高密度区），故 **r_pass 提供了与 R68/R69 正交的第三条证据通道**。系：(r_res≈0, Δa≈0, r_pass↑) 是「接缝被未建模动力学/攻击穿透」的判别性指纹。

**定理 18（接缝组合安全）** 在 A104–A109 下——各契约有效、各接缝五元组通过、最小割盈余 ≥ 0、驻留与迟滞满足、监控在环——BRAID 的组合闭环状态始终留在 ∪_i Inv_i 内，总储能 ≤ B_cap；任一残差越阈或证书吊销都在下一个驻留边界前触发单调降级，且不晚于状态离开不变集。故组合系统的安全性不低于「每个技能单独安全」这一局部保证，并额外覆盖了接缝。

**定理 19（BRAID 严格包含 R69/R68）** 单叶组合树（无接缝）时 BRAID 与 R69 逐指令相同；接缝因语义歧义（U_epi）不可认证时调用 R69 的问询；U_struct 主导或账本赤字时走 R68 的 λ_floor。因此 R69 是 BRAID 在「组合维度退化」时的边界，R68 是「结构不可认证」时的边界：新层不并列替代旧层，而是把旧层作为退化情形包含，安全侧不做任何让步。

**定理 20（吊销的单调传播）** 证书带版本与依赖集，吊销沿组合树传递且单调（epoch 只增不减）。任何旧版本证书在 TOCTOU 检查点被拒绝，故不存在「吊销后仍按已证明执行」的窗口；降级延迟 ≤ 一个驻留周期。系：组合系统的信任是**可撤销的**，这正好补上「假证书不能再被永久信任」这一 R69 遗留问题。

## 6. 本轮最大风险

**一句话**：BRAID-RAS 的全部安全保证都押在「接缝的能量/互联模型是正确的」这一前提上——**一旦未建模的时延、接触耦合或对抗注入在接缝处注入能量，每个技能都会继续真诚地报告「我合格」，而系统会带着一张全局证书失稳；这不是 R69 那种「问错」，而是「局部都对、接缝无人负责」的静默失败，且往往不可逆。**

**次级风险与缓解**：
1. **无源 ≠ 安全**（能量有界仍可能违反状态约束）→ 契约同时包含 Inv_i 受控不变集 + CBF，不以能量账本替代几何安全；

3. **时延与采样破坏无源性** → 延迟感知无源化（散射变换/保守裕度）+ r_pass 在线监控，E307；
4. **契约模型误差/伪造** → 溯源哈希 + 版本绑定 + TOCTOU 检查 + 单调吊销，定理 20；
5. **组合爆炸** → 最小割剪枝 + 懒展开 + 证书缓存，E311；
6. **U_struct 被误分类** → UST3 三通道判据 + 误分类压力测试，E312。

| `r_pass` | 接缝功率残差（未建模时延/接触/注入） |
| `τ^dwell, h_ij` | 最小驻留时间 / 迟滞带（排除 Zeno） |
| `Revoke(i) ⇒ Revoke(τ ∋ i)` | 证书吊销的单调传递 |
| `J_BRAID` | 组合证书 |

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** BRAID-RAS 总览；零学习写继承；**接缝证书先于运动**（禁止隐式组合）；**能量账本非负**（割集赤字即禁止）；**严格包含**（退化到 R69/R68）。

**定义 311–312（耗散技能与能量槽）** 技能为端口哈密顿系统 `Ḣ_i ≤ u_iᵀy_i − ρ_i`；学习残差经槽调制 `u = π^pass + α(T)u^res`，`Ṫ = −α u^resᵀy^res`；槽见底 → 退回无源骨干或权限归零。⇒ 任意学习技能可被驯化为有限透支的可组合单元。

**定义 313（技能契约）** `C_i=(Pre,Post,Inv,H,β,T^0,T^max,τ^dwell,Ω,v,h^cal)`；认证 ⇔ 受控不变 + 储能界 + 前后置相容 + 版本可验。

**定义 314（组合代数）** 串联 `Post_i⊆Pre_j`；并联权限解耦或耦合功率 `≤0`；切换需管 + 驻留 + 迟滞 + 冲量；优先叠加需合并不变集。组合树每个内部节点都必须携带接缝证书。

**定义 315（接缝五元组）** 可达管、`𝒯⊆Inv_i∪Inv_j`、能量余量 `σ_ij=β_j−sup H_j−ΔH^sw≥0`、权限重叠 ≤ `Ω_max`、版本三方绑定。五项全过才算有效签字。

**定义 316（能量账本 / 最小割）** 节点预算 `β_i`、边成本 `ΔH_ij`；组合可行 ⇔ 所有 s-t 割盈余 ≥ 0；min-cut 给出瓶颈接缝，是充分判据与可操作诊断。

**定义 317（U_struct 三分路由）** `U_ale→R68`、`U_epi→R69`、`U_struct→SEC/EBA`；判据：问一句能改决策 → U_epi；怎么问都不变但动力学账本对不上 → U_struct。

**定义 318（驻留切换）** `now−t_last≥τ^dwell ∧ G_ij ∧ ¬G_ji ∧ S_ij有效`，且切换时储能下降；⇒ 切换间隔 ≥ τ^dwell，无 Zeno。

**定义 319（接缝功率残差）** `r_pass=max(0, (1/Δt)∫[Ḣ_obs−(uᵀy−ρ_min)]dτ)`；`(r_res≈0, Δa≈0, r_pass↑)` 是接缝能量注入的判别指纹。

**定义 320–321（组合规划与吊销）** CAP 输出带证书的组合树，缺失则交回 R69/R68；CRV 沿依赖树单调传递吊销，TOCTOU 拒绝旧版本。

**定义 322–324（威胁/证书/包含）** `ℰ_BRAID=ℰ_FLUID×ℰ_seam×ℰ_tank×ℰ_graph`；`J_BRAID` 并入契约哈希、接缝余量、账本割、槽位、驻留、r_pass、epoch；单叶/语义回退/结构未知分别退化为 R69/R69/R68。

def register(contract, provenance):

class EnergyTankSkill:

        u_pass, y = self.passive_backbone(x)
        alpha = clip(self.T / self.T_ref, 0.0, 1.0)
        u = u_pass + alpha * u_nom
        dH = grad_H(x) @ self.f(x, u)
        self.T = clip(self.T - (u_nom @ y) * dt, 0.0, self.Tmax)
        return u, dH

# IP-266：接缝五元组认证
def certify_seam(ci, cj, tube):
    if not subset(ci.post, cj.pre):            return Fail("pre/post")
    if not subset(tube, union(ci.inv, cj.inv)): return Fail("invariant")
    slack = cj.beta - sup_H(cj.H, tube) - switch_cost(tube)
    if slack < 0:                               return Fail("energy_slack", slack)
    if overlap(ci.authority, cj.authority) > OMEGA_MAX: return Fail("authority")
    if not version_bind(ci, cj):                return Fail("version")
    return SeamCert(slack, dwell=max(ci.dwell, cj.dwell), tube=tube)

# IP-267：能量账本（最小割）
def ledger_ok(tree, B_req):
    G = expand(tree)
    return max_flow_min_cut(G, "beta", "deltaH") - B_req >= 0

# IP-268：驻留 + 迟滞 + 能量下降
def next_skill(state, now, last_switch):
    if now - last_switch < current.dwell: return current
    cands = [j for j in graph[current]
             if guard(current, j, state) and not guard(j, current, state)
             and seam[current, j].valid and energy_drops_enough(current, j, state)]
    return argmin(cands, key=lambda j: cost_to_switch(current, j)) if cands else current

# IP-269：接缝功率残差
def seam_residual(skill, x, u, y, dt):
    dH = observed_dH(skill, x, dt)
    return max(0.0, (dH - (u @ y - skill.rho_min)) / dt)

# IP-275：主闭环
def BRAID_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)
    U_ale, U_epi = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    U_struct = M.ust3.estimate_seam_uncertainty(z, M.skg)
    tree = M.cap.plan_composition(M.task, M.skg, M.belief)
    if tree is None:
        return M.r69_reduce(o, U_epi) if U_epi > TAU_EPI else M.r68_retreat(o, U_cal)
    seams = [M.sec.certify(e) for e in tree.edges]
    if not all(s.valid for s in seams) or not M.eba.ledger_ok(tree, M.task.B_req):
        return M.r68_retreat(o, U_cal)
    for phase in tree.schedule():
        u, dH = M.tank[phase.id].step(M.x, phase.u_nom, M.dt)
        r = M.src.seam_residual(M.skg[phase.id], M.x, u, phase.y, M.dt)
        if r > TAU_PASS or M.crv.revoked(phase.id, epoch=M.epoch):
            M.crv.revoke_downstream(phase.id)
            return M.degrade(tree, reason="seam_energy")
        M.x = M.wm.step(M.x, u, M.dt)
    M.vqa_b.submit_async(tree, seams, r)

## 4. 推导

**引理 19（耗散组合）** 子系统耗散 + 功率保持互联 ⇒ `Ḣ ≤ −Σρ_i ≤ 0`，储能函数可加。串联付交接能、切换付冲量，只消耗账本、不反转耗散方向。⇒ 整体稳定可由局部耗散 + 接缝证书推出。

**引理 20（最小割可行性）** 所有 s-t 割盈余 ≥ 0 ⇒ 任意可达阶段不耗尽预算；存在赤字割 ⇒ 该割必被跨越且能量不足。故 min-cut 是充分判据与瓶颈定位器。

**引理 21（驻留排除 Zeno）** 最小驻留 + 迟滞 ⇒ `t_{k+1}−t_k ≥ τ^dwell`，切换次数有界；叠加储能下降 ⇒ 多储能实用稳定。无驻留的组合会在守卫边界抖振，抖振本身向接缝注入冲量。

**引理 22（接缝残差可检测）** 未建模注入 `ΔP > τ_pass+ε_obs` ⇒ `r_pass` 越阈，且先于不变集违反被检出；`ΔP` 不进 `r_res`、也不必然进 `Δa`，故 `(r_res≈0, Δa≈0, r_pass↑)` 是接缝穿透的判别指纹。

**定理 18（接缝组合安全）** A104–A109 下，契约有效 + 接缝五元组通过 + min-cut ≥ 0 + 驻留/迟滞 + 监控在环 ⇒ 状态留在 `∪Inv_i`、总储能 ≤ `B_cap`；越阈/吊销在下一驻留边界前触发单调降级，不晚于状态离开不变集。

**定理 19（严格包含 R69/R68）** 单叶 → 与 R69 逐指令相同；语义歧义接缝不可认证 → R69；U_struct 主导/账本赤字 → R68。⇒ R69/R68 是 BRAID 在组合维度上的退化边界。

**定理 20（吊销单调传播）** 版本 + 依赖 + epoch 单调 ⇒ 吊销传递且不可回滚；TOCTOU 拒绝旧证书；降级延迟 ≤ 1 个驻留周期。⇒ 组合信任可撤销，补上「假证书不得永久信任」的漏洞。

## 7. 本轮最大风险

**一句话**：BRAID-RAS 的全部安全保证都押在「接缝的能量/互联模型是正确的」这一前提上——**一旦未建模的时延、接触耦合或对抗注入在接缝处注入能量，每个技能都会继续真诚地报告「我合格」，而系统会带着一张全局证书失稳；这不是 R69 的「问错」，而是「局部都对、接缝无人负责」的静默失败，且往往不可逆。**

**次级风险与缓解**：无源 ≠ 安全（契约含受控不变集 + CBF，不以能量替代几何安全）；能量槽饥饿/被游戏（槽下限 + 权限缩放 + 流水审计，E308/E310）；时延与采样破坏无源性（延迟感知无源化 + r_pass 监控，E307）；契约模型误差/伪造（溯源哈希 + 版本绑定 + TOCTOU + 单调吊销，定理 20）；组合爆炸（min-cut 剪枝 + 懒展开 + 缓存，E311）；U_struct 误分类（UST3 三通道判据 + 压力测试，E312）。
