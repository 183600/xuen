# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「大语言模型」×「交互设计」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**语言只许编译成有限谓词，交互只许求证与收缩，二者都不进 50Hz 控制回路**。v10 自认最大风险是分割面 τ_sem 的经验性：长尾/对抗语义在 ν≤τ_sem 下穿透，失败是**静默**的。v11 不幻想"LLM 让分割面归零"，而是正面处理 v10 遗留的三个债：**分割面债**（把静默失败变成可观测灰区与有限兜底）、**编写债**（≤12 条手写规范与 ≤512 类原型无法覆盖自然语言长尾）、**申诉/可读债**（人类看不懂系统为何保守/为何中止，问不到、无法追责）。铁律不变：任一新模块失效 ⇒ 注入声明中立元，行为对 v10 **等价**（LNC/LP）或**支配/更保守**（IG），绝不行为漂移。

## 0. 直觉与动机

**灵感 1（大语言模型 → 离线编译器与红队，而非在线决策者）**
直觉：v10 的 τ_sem 之所以危险，不是阈值调得不好，而是**"可命名的东西"是封闭的**——规范表 ≤12 行、地标类原型 ≤512 个，全部由人预先写死；长尾语义没有名字，于是 ν 算不出来、也进不了灰区。LLM 在安全关键机器人里的真正价值，不是"在 50Hz 里推理"（它慢、随机、不可验证，绝不能进实时回路），而是**把自然语言与世界知识的长尾压缩成有限、可测试、可版本化的工件**：把 NL 规范编译成谓词行，把事件复盘编译成候选规范/候选修复算子，把类原型补丁与红队用例生成出来。核心创新：**语言规范编译器（Language Norm Compiler, LNC）**——LLM 只出**候选**，随后必须过一道确定性**编译门 Γ**：模式/类型检查、留出集测试、误准入率、复杂度预算、影子模式无回退，且**原型扩类必须携带留出前向误差证据**（否则只降低 ν 而不降保守性，等于用语言替代证据）。更关键：LLM 的另一半用途是当**红队**——主动生成"看起来像已知类、实际会击穿前向模型"的对抗语义，把 v10 的 E589 从一次性测试升级为持续回归套件。LLM 在这里是"编译器 + 攻击者"，不是"驾驶员"。
严谨对应：LNC 输出三类受限工件——(i) 规范表补丁 N′，(ii) 地标类原型补丁 P′，(iii) 红队/回归用例集 Q′；三者都进入 IP-363 的**版本化规范注册表**，各有内容哈希与准入证据包。

**灵感 2（交互设计 → 把"不确定"变成可申诉、可限时的求证通道）**
直觉：v10 在 τ_sem 之上只剩两个动作——继续，或中止/收缩。这制造了一个两难：阈值调高则过度中止（活性差），调低则静默穿透（安全差）。交互设计给的启示是：**不确定本身应当被表达给人，并通过一个有截止时间的协议去求证**。但"会提问的机器人"也可能是新的安全漏洞：人会延迟回答、会误授权、会被界面诱导过度信任、系统会为等回答而错过物理窗口。因此交互必须被建模为**契约**而非功能：**核心创新：交互治理器（Interaction Governor, IG）**——(i) 规范被划分 `N = N_safe ⊔ N_defer`，物理安全规范（车距、停车不变式、硬 d_eth 下界、中止点集）**永不可交互豁免**，只有隐私同意、财产 claim、公平、解释这类可委托规范可被人类证据裁决；(ii) 定义**语义灰区** `τ_low < ν ≤ τ_sem`，命中即三值守卫输出 `gray`、`K_eff≤2`、并在块边界发起**限时**求证；(iii) 人类回执 `E_int` 必须**认证 + 限定 scope + 留痕**，且**即时只能收紧、放宽只许在下一块重验定义 543 全条件后生效**——当期执行中的块永不被外部输入放宽；(iv) 超时/拒答/台账缺口 ⇒ 直接退 `Π_r`（复用 v10 审查失明即收缩律）。这样，交互把"静默失败"变成"响亮的、有截止时间的、可审计的不确定"，但它**不改变物理安全包络**。
严谨对应：IG 是块边界的五状态机（autonomous → gray-escalate → resolved/relax-pending → Π_r → manual-takeover），通道本身作为带时延与可靠性的传感器进 MW 契约（`v^⊥=Π_r`）。

**灵感 3（交互设计 × 可解释性 → 显示即控制变量，解释须可溯源）**
直觉（第三个债）：v10 的信任场 T、块长 K_eff、规范通过向量 n_t 都是控制变量，却没有面向人的投影；一旦用 LLM 生成解释，最容易发生的是"事后合理化"——解释说得通，但与控制实际依据无关，人反而更信。交互设计给的原则是：**可读性不是旁白，而是控制状态的确定性投影**。核心创新：**可读性投影器（Legibility Projector, LP）**——信任仪表盘 `Π_leg = f(T, K_eff, N_active, n_t, 升级状态)` 与控制器读同一个变量、同一个时间戳；解释不是自由生成，而是**解释证书**：每条断言必须引用台账记录 ID，引用不上就拒答或降级为"未知"，LLM 只能做"把台账翻译成人话"的受限改写，不能新增因果断言。配套把 v10 的伦理台账扩展为 `Λ⁺`，编译准入、交互请求/回执/拒绝等事件一律入链，版本可回滚、跨机可对账。

三者咬合：LNC 把**语言变成可测试的有限工件**（治编写债），IG 把**灰区变成限时求证**（治分割面债），LP+Λ⁺ 把**系统状态变成可读可追责的投影**（治申诉/可读债）；共同把 v10 的"结构化信任证书"升级为**可溯源信任证书 Ĉ_t^‡ = (ĝ_min, ê_max, γ̂_grasp, β_STF, n_t, v_N, e_int)**，其中 `v_N` 是准入规范版本哈希、`e_int` 是该块内生效的交互证据摘要。

## 1. 研究问题（轮次升级版）

- **Q1（语言可编译）**：如何把开放词汇的自然语言规范与长尾语义，编译成有限谓词/原型/测试工件，使得 (a) 确定性重放 100%、(b) 无留出误差证据时不得降低保守性、(c) 长尾类覆盖 ↑≥30% 且误报率不高于基线 +1%？
- **Q2（交互可治理）**：如何设计带截止时间的交互契约，使灰区新颖性在 1 个块内被暴露并可裁决、超时 1 块内退 `Π_r`、物理安全动作时延不升（50Hz 守卫预算不变）、且未授权放宽为 0？
- **Q3（可读可追责）**：显示与解释能否成为控制变量与台账的确定性投影，使解释断言溯源 100%、幻觉 0、操作员信任校准（过信/不信）显著改善，且解释通道对控制零回灌？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 语言可编译律（Compilable Language, LNC）**
LLM 永不进入实时控制回路，也永不直接写入证书；其输出只有经过确定性编译门 Γ 并携带准入证据包（源哈希、翻译、测试、成本、影子回放）的**有限工件**才可生效。**语言不得替证据降保守**：任何使 ν 下降的原型扩类，必须同时给出该区域的留出前向误差上界；无证据则保持灰区。

**P17 安全不可交互豁免律（No Interactive Exemption of Safety, IG）**
交互只可裁决 `N_defer`，`N_safe`（物理安全不变式与硬下界）永不因人类回执、LLM 解释或社会压力而放宽；外部证据**即时只许收紧**，放宽必须延迟到下一块并经定义 543 全条件重验；超时/认证失败/scope 越界/台账缺口 ⇒ `Π_r`。交互是"求证与收缩"的通道，不是"授权扩权"的通道。

**P18 显示即控制变量律（Display-as-Control-Variable, LP）**
面向人的状态与解释必须是控制变量 `(T, K_eff, N_active, n_t, 升级状态)` 与台账记录的确定性投影；不存在只影响显示、不影响控制的"第二套状态"，也不存在只影响解释、不被控制的因果断言；不可溯源的断言必须拒答。

## 3. 与基线的接口（如何退化）

- **LNC/注册表失效**（慢循环不可用、模型版本未准入、影子回放失败）⇒ 冻结上一准入版本 `v_N*`，原型与规范表不变，红队暂停：行为**等价 v10**（新提案只停留在候选区）；未准入工件永不进入控制；
- **IG 失效**（通道断、超时率越界、认证服务不可用）⇒ 灰区直接按 v10 语义处理（`ν>τ_sem` 才 veto，其余不升级），并把灰区额外收缩为 `Π_r`（比 v10 更保守，**支配** v10）；
- **LP 失效** ⇒ 仪表盘显示"可读性离线/未知"，解释退化为台账原始记录；控制与证书不变；
- **STF 失效** ⇒ `K_eff←1`、`β←β_base`（v10 Level-1 原样）；**NRB 失效** ⇒ `Π_r`（v10 Level-2 原样）；
- **AC/ID/MW/v8 失效** ⇒ 沿 v10 六级退化链原样；新增 LNC/IG/LP 的准入与交互事件一律写入 `Λ⁺`，不参与 `φ^elig` 蒸馏（安全/审计面永不消融，仅"红队用例生成"可离线蒸馏）。

## 4. 预期贡献

1. **可编译的语言安全**：LLM 从"不可控在线决策者"降格为"离线编译器 + 红队"，其贡献被编译门、留出误差证据与版本哈希约束——长尾覆盖 ↑≥30% 而不降低证书保守性（引理 92）；
2. **灰区三值守卫与限时交互**：把 v10 的静默分割面失败压缩为 `gray` 可观测态，超时 1 块内 `Π_r`，物理安全时延不升（引理 93）；交互不越安全包络、即时只紧不放宽（引理 94）；
3. **可溯源可读性**：显示与解释是控制变量与 `Λ⁺` 的确定性投影，解释断言溯源 100%（引理 95）；版本注册表支持跨机对账与精确回滚（引理 96）；
4. **E591–E610** 覆盖编译门、扩类保界、灰区标定、交互时延/越权、解释忠实、红队回归、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：LNC 的编译门与 IG 的授权通道共同把"外部证据"引入安全论证——一旦编译门用测试通过替代了分布覆盖证明、或人在可读性界面下被诱导给出超范围授权，v11 会把同一个分割面失效包装成"已编译、已授权、已留痕"的制度性信任，失败不再静默却更难被质疑（v10 至少把怀疑留在阈值上，v11 把怀疑外包给了语言、流程与模型版本漂移）。

| `v_N` | 准入规范版本哈希；`N_active=v_N*` 为运行期冻结版本；`V={v_0,v_1,…}` 版本链 |
| `N_safe / N_defer` | 规范划分：`N_safe`（物理安全，不可交互豁免）⊔ `N_defer`（同意/财产/公平/解释，可委托） |
| `G_t` | 语义灰区：`τ_low < sup_{kNN} ν̄_ℓ ≤ τ_sem`；三值守卫输出 `o_t∈{pass,gray,veto}` |
| `κ_int` | 交互契约 `(D_int, modes, authority_scope, auth_scheme, fallback=Π_r)`；通道时延 `L_int` |
| `E_int` | 交互证据 `(signer, scope⊆N_defer, predicate_ids, decision, ts, nonce, sig)`；认证 + 限域 + 限时 |
| `Π_leg` | 可读性投影：控制变量 + 台账引用的确定性函数；同一时间戳、同源变量 |
| `X_exp` | 解释证书：断言集，每条断言携带 `ledger_ids`；无引用断言 ⇒ 拒答 |
| `Λ⁺` | 扩展台账：v10 `Λ` 的哈希链上增记 compile/admission/escalation/interaction/rollback 事件 |
| `Ĉ_t^‡` | 可溯源证书 `(ĝ_min, ê_max, γ̂_grasp, β_STF, n_t, v_N, e_int)`；`e_int` 为本块生效证据摘要 |

**新增定义 549（慢循环语言接口）** `L_LLM` 以 `T=0`、固定 schema、固定权重哈希运行；接口层对 `(prompt, weight_hash)` 做重放缓存，同一输入必须返回逐字节相同的候选工件（否则由缓存返回首次结果并标记 `nondeterministic=1` 拒绝准入）。LLM 输出仅为 JSON 候选，不含可执行代码、不含直接动作、不含对 `d_safe/κ` 的写权限。

**新增定义 550（规范编译器）** `C_NL = C_det ∘ L_LLM`。`L_LLM` 产出候选三元组；`C_det` 做确定性归一：规范行必须落在谓词 DSL 的有限语法内（`scope, φ, sev, remedy`），原型补丁必须是 `(class_id, 16 维 fp16 原型, 覆盖区域)`，测试用例必须是 `(输入描述, 期望谓词值)`。DSL 外的自然语言残留一律拒绝，不允许"运行时再解释"。

**新增定义 551（编译门与扩类保界条件）** `Γ` 的准入条件：
(i) 良构率 100%（DSL 类型/作用域/单位检查）；
(ii) 留出测试通过率 ≥ `1−ε_a`，且 false-admission ≤ `ε_FA`（E591/E593）；
(iii) 成本预算：编译产物使运行期新增开销 ≤ 契约行预算；
(iv) 影子模式：在未接入控制的情况下回放 `E_shadow` 个块，安全集上无回退（`Ĉ^‡` 有效率不降）；
(v) **扩类误差证据**：若原型补丁使某区域 `ν` 下降（即"把陌生认成熟"），必须附该区域留出集上的 `sup‖F̂_q−F‖ ≤ β_base` 证据（E594）；无证据 ⇒ 该区域保持 `unknown`（ν 不降），只许走灰区交互；
(vi) 溯源：候选、翻译、测试、证据、成本全部入 `Λ⁺` 并计算版本哈希。
只有六项全过才 `admit`；否则 `reject` 并记录失败原因。`Γ` 不可修改准入门槛（门槛为部署期只读常量，写入注册表哈希）。

**新增定义 552（版本化规范注册表）** `V` 为 append-only 版本链，`v_k = H(v_{k−1}‖artifact_k‖evidence_k)`。运行期只读 `v_N*`；部署期对账校验 `v_N*` 的哈希与证据包；跨机版本偏斜（不同机器人 `v_N` 不一致且未声明兼容）⇒ 该机进入 `Π_r` 直至对齐。回滚是把指针移到历史 `v_k` 并重新验证书，不删除历史。

**新增定义 553（语义灰区与三值守卫）** 令 `ν_sup = sup_{kNN} ν̄_ℓ`。守卫输出
```
o_t = veto   若 ν_sup > τ_sem                         （显著新颖：立即 K=1/切 p*）
    = gray   若 τ_low < ν_sup ≤ τ_sem                 （灰区：K_eff≤2 + 限时求证）
    = pass   若 ν_sup ≤ τ_low                          （v10 常规门控）
```
`τ_low` 经 E595 标定，要求灰区召回 ≥99%、灰区误报 ≤10%。灰区不改变物理安全动作的时限：`veto` 路径与 v10 完全一致；`gray` 只是把 `K` 压到 2 并启动交互，**不许**以"正在等人回答"为由延长任何物理安全截止时间。

**新增定义 554（规范可委托划分）** `N = N_safe ⊔ N_defer`。`N_safe ⊇ {ν-PROX, 停车不变式, d_safe, d_eth 硬下界, 中止点集}`，其谓词只读确定性状态，`E_int` 与 `L_LLM` 对其无写权限；`N_defer ⊆ {ν-PRIV 同意标志, ν-PROP claim, ν-FAIR, ν-TRAN}`，可接受认证回执。划分表为只读常量并进注册表哈希；任何"把 `N_safe` 移到 `N_defer`"的补丁视为非法（`Γ` 直接拒绝）。

**新增定义 555（交互契约）** `κ_int = (D_int, modes={clarify, consent, claim, takeover}, authority_scope⊆N_defer, auth_scheme, fallback=Π_r)`。`D_int` 默认 1 个块周期（≤200ms），可配置上限 `D_max=1s`；`modes` 限定请求类型；`authority_scope` 限定可裁决谓词集；超时/拒答/认证失败/scope 越界 ⇒ `fallback`。通道时延 `L_int` 作为传感器参数进 MW，`L_int+D_int` 不得超过任务允许的等待预算。

**新增定义 556（交互证据与单调生效）** `E_int` 必须通过签名认证、时间窗、nonce 防重放、`scope⊆N_defer` 校验。生效规则：
- **即时只紧**：`E_int` 可在当期块内**收紧**行为（停/慢/遮蔽/放弃），因为收缩是安全的；
- **放宽延迟**：任何放宽（恢复计划、允许抓取、解除遮蔽）只在**下一块边界**、且重验定义 543 全条件（含 `Ĉ^‡`、停车不变式、中止点集）后生效；
- **永不改写**：`E_int` 永不修改 `N_safe`、永不修改当前已执行动作序列、永不回灌当期证书的物理侧。

**新增定义 557（交互治理器状态机）** `IG: (S, event) → S'`，`S ∈ {AUTONOMOUS, GRAY_ESCALATE, RELAX_PENDING, RESTRICTIVE(Π_r), MANUAL_TAKEOVER}`。迁移：`AUTONOMOUS --gray--> GRAY_ESCALATE`；`GRAY_ESCALATE --valid E_int(tighten)--> RESTRICTIVE`；`GRAY_ESCALATE --valid E_int(relax)--> RELAX_PENDING`；`RELAX_PENDING --next block reverify pass--> AUTONOMOUS`；`--reverify fail/timeout--> RESTRICTIVE`；`GRAY_ESCALATE --timeout/auth fail--> RESTRICTIVE`；任意态 `--human takeover--> MANUAL_TAKEOVER`（只紧不放）。每次迁移写 `Λ⁺`。

**新增定义 558（可读性投影）** `Π_leg(t) = f(T(·,t), K_eff(t), N_active, n_t, IG_state, Λ⁺_refs)`，`f` 为确定性函数，与控制共享同一时间戳与同一缓存变量（不允许重新估计一遍 T）。显示字段至少含：当前信任场热点、有效块长、活跃规范版本与硬/软规范状态、当前升级状态、下一步默认动作（继续/收缩/停）、最近 3 条台账引用。

**新增定义 559（解释证书）** `X_exp = {(claim_i, ledger_ids_i)}`。生成器（可为 LLM）只许**改写**台账内容为自然语言，不许新增未被 `ledger_ids` 支持的因果/意图断言；校验器逐条检查引用存在、时间一致、谓词一致，任一失败 ⇒ 删除该断言；全部失败 ⇒ 输出"无可溯源解释"并给出原始台账指针。解释生成不在控制回路内，失败不影响控制。

**新增定义 560（扩展台账与事件类型）** `Λ⁺` 继承 v10 哈希链（`κ_h=256`、`C_w=64` 校验点），事件类型扩展为 `{compile, admission, reject, escalation, interaction_accept, interaction_reject, rollback, abort, norm}`；每条记录含 `(prev_hash, ts, kind, refs, actor, payload_hash)`。缺口/校验失败 ⇒ 下一块 `Π_r`（v10 原样）。

# IP-361 LanguageNormCompiler：慢循环编译器 + 红队（不在 50Hz 回路）
class LanguageNormCompiler:
    def __init__(self, llm, gate, registry, ledger, shadow_blocks=200):
        self.llm, self.gate = llm, gate          # L_LLM / Γ
        self.registry, self.ledger = registry, ledger
        self.shadow_blocks = shadow_blocks

    def propose(self, nl_corpus, incident_refs):  # 定义 549–550
        raw = self.llm.generate(nl_corpus, schema=NormDraft,
                                references=incident_refs, temperature=0)
        cand = DeterministicLint(raw)             # DSL 归一；DSL 外残留 ⇒ 拒绝
        return cand                               # 仍只是候选

    def try_admit(self, cand):                    # 定义 551：六项全过才准入
        if not self.gate.well_formed(cand):       return self._reject(cand, 'syntax')
        if not self.gate.tests_pass(cand):        return self._reject(cand, 'tests')
        if not self.gate.cost_ok(cand):           return self._reject(cand, 'budget')
        if not self.gate.shadow_no_regression(cand, n=self.shadow_blocks):
            return self._reject(cand, 'shadow')
        if cand.prototype_patch and not self.gate.error_calibrated(
                cand.prototype_patch):            # 定义 551(v)：扩类须有误差证据
            return self._reject(cand, 'uncalibrated_expansion')
        if not self.gate.safe_partition_unchanged(cand):  # N_safe 不可移动
            return self._reject(cand, 'safe_partition')
        v = self.registry.commit(cand, evidence=self.gate.evidence(cand))
        self.ledger.append(kind='admission', refs=[v.hash, cand.source_hash])
        return v

    def red_team(self, k=256):                    # 兼作对抗用例生成（φ^elig=✓）
        cases = self.llm.generate_adversarial(k, schema=RedTeamCase, temperature=0.7)
        return DeterministicLint(cases)           # 只进测试集，不直接改控制


# IP-362 InteractionGovernor：灰区三值 + 限时求证 + 单调生效
class InteractionGovernor:
    def __init__(self, contract, ledger, pi_r, n_safe):
        self.contract, self.ledger = contract, ledger   # 定义 555
        self.pi_r, self.n_safe = pi_r, n_safe           # 定义 554
        self.state, self.pending = 'AUTONOMOUS', None

    def three_valued(self, stf, live):                # 定义 553
        nu = stf.surprise_near(live.pose)
        if nu > stf.tau_sem:  return 'veto'
        if nu > stf.tau_low:  return 'gray'
        return 'pass'

    def escalate_if_gray(self, o_t, block, ctx):      # 5Hz，块边界
        if o_t != 'gray':
            self.state = 'AUTONOMOUS'; return None
        req = self.contract.issue(block.id, modes=('clarify', 'consent'),
                                  scope=ctx.deferrable_scope())  # ⊆ N_defer
        self.pending = req
        self.state = 'GRAY_ESCALATE'
        self.ledger.append(kind='escalation', refs=[block.id, req.id])
        return req

    def on_evidence(self, e, block):                  # 定义 556：即时只紧
        if not (self.contract.auth(e) and self.contract.scope_ok(e)
                and self.contract.nonexpired(e)):
            self.ledger.append(kind='interaction_reject', refs=[e.hash])
            return self._to_pi_r(block)
        if e.decision == 'tighten':
            self.ledger.append(kind='interaction_accept', refs=[e.hash])
            return self._apply_tighten_now(e, block)  # 收缩立即生效
        self.ledger.append(kind='interaction_accept', refs=[e.hash])
        self.pending = ('relax', e, block.id)         # 放宽只排队到下一块
        self.state = 'RELAX_PENDING'
        return None

    def tick_50hz(self, block, now):                  # 守卫第 5 检，O(1)
        if self.state == 'GRAY_ESCALATE' and self.pending.expired(now):
            return self._to_pi_r(block)               # 超时 ⇒ Π_r
        return 'ok'

    def _to_pi_r(self, block):
        self.state = 'RESTRICTIVE'
        self.ledger.append(kind='interaction_reject', refs=[block.id, 'timeout'])
        return self.pi_r                              # 定义 546，v10 原样


# IP-363 LegibilityProjector：显示即控制变量 + 解释证书
class LegibilityProjector:
    def __init__(self, ledger):
        self.ledger = ledger

    def project(self, ctx):                           # 定义 558：同源、同时间戳
        return LegibilityFrame(
            t=ctx.t, trust_hotspots=ctx.stf.top_k(3),
            K_eff=ctx.K_eff, norm_version=ctx.v_N,
            hard_ok=ctx.norm_status.hard_ok,
            soft_state=ctx.norm_status.soft,
            ig_state=ctx.ig.state,
            next_default=ctx.guard.next_default(),
            ledger_refs=self.ledger.recent(3))

    def explain(self, frame, llm=None):               # 定义 559：只许改写，不许新增断言
        draft = llm.rewrite(frame.ledger_refs) if llm else frame.ledger_refs
        cert = []
        for claim in draft:
            refs = [r for r in claim.ledger_ids if self.ledger.exists(r)]
            if refs and self.ledger.consistent(claim, refs):
                cert.append((claim.text, refs))
        return cert or '无可溯源解释，见原始台账'


# IP-354（升级）：五检守卫 + 可溯源证书生成
class TraceableChunkCertifier(StructuredChunkCertifier):
    def generate_chunk(self, state, ctx, stf, nrb, ig):
        K = self.effective_K_v11(ctx, stf, ig)        # 定义 539-v11
        if K == 1:
            return self._single_step_fallback(state)
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)
            beta_stf = self.beta_base + self.lam * stf.field_on_footprint(pred.corridor)
            g_min = pred.min_clearance - beta_stf
            e_max = pred.max_effort + beta_stf
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            chunk = Chunk(cand, CertSharp(g_min, e_max, beta_stf,
                                          v_N=ctx.v_N, e_int=ctx.e_int), pts)
            chunk, verdict = nrb.review_chunk(chunk, stf, ctx)  # v10
            if chunk is None:
                continue
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs, stf, nrb, ig):
        """50Hz 五检 ≤0.5ms；返回 ('continue', k+1) 或 ('abort', p*)"""
        if not chunk.cert_still_valid(live_obs):            # 检 1（v10 原检）
            return self._nearest_abort(chunk, k_exec)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):          # 检 2（v10 原检）
            return self._nearest_abort(chunk, k_exec)
        o_t = ig.three_valued(stf, live_obs)                # 检 3：三值语义
        if o_t == 'veto':
            return self._nearest_abort(chunk, k_exec)
        if nrb.fast_norms(live_obs).violated:               # 检 4（v10 原检）
            return self._nearest_abort(chunk, k_exec)
        if ig.tick_50hz(chunk, live_obs.t) == 'timeout':    # 检 5：交互期限
            return self._nearest_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 92（编译门良构与确定性）** 设 `C_det` 只接受 DSL 内的有限语法，`L_LLM` 以 `T=0` 运行且接口层按 `(prompt, weight_hash)` 缓存。则：(a) 任一 `admit` 工件都是有限、确定性、可静态枚举的函数，运行期行为只依赖 `(状态, v_N*)`，与 LLM 在线状态无关；(b) 同一输入的重放候选逐字节一致（缓存兜底），版本哈希可复现；(c) 若准入条件 (v) 成立，则原型扩类只在"有留出误差 ≤β_base 证据"的区域降低 `ν`，故 `β_STF` 的保守性不被语言单方面削弱。证明：(a)(b) 由 DSL 封闭性与缓存定义直接得；(c) 扩类仅在 `error_calibrated` 为真时提交，未提交区域保持 `unknown`，`ν` 不降 ⇒ `β_STF` 不降。∎ 注：该引理**不**保证语义正确，只保证"进入控制的工件是有限的、可重放的、未获证据的保守性下调被禁止"。

**引理 93（灰区升格与中止及时性）** 设 (A2) v10 的显著类召回 ≥1−ε_s；(A2′) 灰区标定：`ν>τ_low` 的事件在 1 帧内被三值守卫捕获的召回 ≥1−ε_g（E595）；(A3) 非显著误差覆盖 ≥1−ε_β（v10 E574）。则任一中块危险事件 `e` 以概率 ≥1−ε_s−ε_g−ε_β 满足：`ν>τ_sem` ⇒ 检 3 `veto`，1 帧内切 `p*`（与 v10 同路径）；`τ_low<ν≤τ_sem` ⇒ 检 3 输出 `gray`，`K_eff≤2` 且块边界发起限时求证，超时 `D_int` ⇒ 至多 1 块内 `Π_r`；`ν≤τ_low` 且 `e` 非显著 ⇒ 由 (A3) 误差被 `β_STF` 覆盖。证明：三值划分互斥完备，`veto` 路径与 v10 引理 87(i) 同构；`gray` 路径的物理动作时限由 50Hz 检 1/检 2 保证，交互只在块边界改变 `K`/非安全约束，故不引入额外物理时延；超时由定义 555/557 的状态机保证 1 块内落到 `Π_r`。并集界收尾。∎ 关键差异：v10 对灰区**不可见**，v11 把灰区变为**有截止时间的事件**；但残余静默集 `{ν≤τ_low}` 仍可能非空。

**引理 94（安全不可交互豁免与支配性）** 对任意认证/未认证的 `E_int` 与任意 `L_LLM` 输出：(i) 物理可执行动作集在 v11 下 ⊆ v10 下；(ii) `E_int` 只能改变 `N_defer` 的同意标志/claim/披露状态，不能改变 `N_safe` 谓词、`d_safe`、停车不变式与中止点集；(iii) 即时只紧、放宽下一块重验，故当期执行块的动作序列不被外部输入放宽；(iv) IG 失效时灰区退 `Π_r`，而 `Π_r` 的各约束只收缩 v10 可行集（v10 引理 89(i) 原样）。证明：(ii) 由定义 554 的只读划分与 `Γ` 的 `safe_partition_unchanged` 检查；(i)(iii) 由定义 556 的单调生效规则与定义 543 重验；(iv) 由 v10 引理 89。∎ 活性注记：`Π_r` 与 `D_int` 下的任务完成率是假设，需 E596/E602 验证；失败路径为语音披露 + 受控放弃（v10 兼容中止）。

**引理 95（显示与解释的忠实性）** `Π_leg` 与 `X_exp` 由定义 558/559 生成。(a) `Π_leg` 是控制变量的确定性函数且与控制共享时间戳/缓存，故显示值与控制依据同源，不存在独立"第二估计"；(b) `X_exp` 的每条断言必须通过 `ledger.exists ∧ consistent`，无引用断言被删，故所有输出断言均可溯源到 `Λ⁺`；(c) 解释生成器只读台账，输出不回写控制，故解释通道对控制零回灌。证明：(a)(b)(c) 由定义直接得。∎ 注：忠实性保证的是"解释不超出台账"，不保证台账本身捕获了全部真实因果；这是可追责性而非全知性。

**引理 96（版本链完整性与回滚）** `V` 为哈希链，`v_k=H(v_{k−1}‖artifact_k‖evidence_k)`。则：(a) 对历史版本/证据的任何删改以 ≥1−2^{−256} 概率被对账检出（继承 v10 引理 90）；(b) 回滚到 `v_k` 恢复逐字节相同的准入工件，因为工件与证据均在链上且有内容哈希；(c) 跨机 `v_N` 偏斜若未声明兼容，则以 ≥1−2^{−256} 概率被检出并触发 `Π_r`。证明：哈希链性质与注册表定义。∎

**引理 97（v11 退化等价/支配）** 沿定义 0 的八级退化链：(a) LNC/注册表失效 ⇒ 运行期只读 `v_N*`，控制路径与 v10 逐位相同；(b) LP 失效 ⇒ 只影响显示，控制路径与 v10 逐位相同；(c) IG 失效 ⇒ 灰区退 `Π_r`，由引理 94(i) 物理可行集 ⊆ v10（支配）；(d) STF/NRB/AC/ID/MW/v8 失效 ⇒ 沿 v10 引理链原样。故任一新增组件失效，v11 对 v10 的行为是等价或更保守，不存在"新模块坏了反而更激进"的路径。∎

## 8. 本轮最大风险

**一句话**：LNC 的编译门与 IG 的授权通道共同把"外部证据"引入安全论证——一旦编译门用测试通过替代了分布覆盖证明、或人在可读性界面下被诱导给出超范围授权，v11 会把同一个分割面失效包装成"已编译、已授权、已留痕"的制度性信任，失败不再静默却更难被质疑（v10 至少把怀疑留在阈值上，v11 把怀疑外包给了语言、流程与模型版本漂移）。
