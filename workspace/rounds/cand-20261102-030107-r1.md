# 第 13 轮（新灵感循环第 1 轮）· PACE：把示教学习从「检索一个关键帧」升级为「按能量排序、按碰撞认证的运动原语仲裁」

> 检索/复核日期：**2026-11-02（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮三个灵感词是「示教学习」「能耗优化」「碰撞避免」。本轮承接第 10 轮 **FACT-VLA**、第 11 轮 **GEO-RESIDUAL**、第 12 轮 **CHUNK-SERVO**；不推倒它们，而是把 CHUNK-SERVO 的「单目标 + PID 伺服」升级为「候选运动原语 + 能量排序 + 碰撞认证」。

## 0. 先给结论：最后 3 厘米缺的不只是闭环，而是「闭环里该走哪条演示路」

第 12 轮 CHUNK-SERVO 做对了一件关键的事：把 VLA 的 30 步开环 chunk 切成 6 个 5 步执行块，用 33k 成功演示检索「目标→夹爪」相对位姿，再用确定性视觉伺服每 167 ms 修正一次。它回答的是：

> 「目标在哪？我现在偏了多少？往哪修？」

但它默认了三件事：

1. **演示只有一个正确目标。** 检索返回一个关键帧相对位姿，PID 就朝它走；可是同一任务的成功演示有 **969–1,533 条**，夹爪可以从上方、侧面、内侧、先退后进——这些风格的能量、平滑度、与旁物的间距并不相同。
2. **到达目标的路不需要被认证。** 关键帧只约束终点；从当前位姿到目标的那一段，可能擦过新出现的干扰物，可能穿过人手，可能经过一个肘部接近奇异、力矩很大的构型。
3. **能量/热/磨损是隐形的。** 320 次 trial、每次上限 180 s，连续评测会让关节持续出力；API 没有力/力矩/温度，但关节状态 + 官方 URDF 其实能算出一个免费的逆动力学 effort 代理。它不该被当成主目标，却是一个物理上可解释的「选哪条演示路」的排序信号。

所以本轮的押注是 **PACE**（Primitive-Arbitrated Collision-safe Energy-optimal execution，按能量排序、按碰撞认证的运动原语仲裁）：

> **离线**：把 33k 成功演示切成「阶段—原语边」，用逆动力学给每条边打能量标签，用逆最优控制从演示里恢复代价权重，用成功演示的间隙分布学习安全余量；
> **在线**：每个 5 步执行块，从原语图里取候选，先用**碰撞硬约束**（自身 / 环境 / 人）过滤，再按「学到的能量代价 + 对 VLA 意图的跟踪偏差」排序，选中的边做**时间重参数化**，最后叠加 CHUNK-SERVO 的伺服修正。

一句话：**把「朝一个检索到的关键帧做 PID」改成「在演示学到的、能量排序的、碰撞认证的原语图里选下一段路，再在上面做伺服」。**

三个灵感词怎么落到方案里：

| 灵感词 | 落到哪里 | 不做什么 |
|---|---|---|
| **示教学习** | 不只是检索目标；从演示恢复代价权重（MaxEnt 逆最优控制）、构建阶段条件原语图、学习安全余量 | 不做第二个在线学习策略；不在线更新网络权重 |
| **能耗优化** | 逆动力学 effort 代价、原语排序、块内时间重参数化、能量预算/热代理 | 不把能量当唯一目标；不假装 API 有力矩/温度 |
| **碰撞避免** | 路径级硬约束（自身胶囊、双目点云、人的膨胀体）；选中前整块预测轨迹认证 | 不做事后急停当安全；不对目标物一律保持距离 |

**诚实的边界**：能耗不是赛题的计分项。PACE 的价值主张不是「省了多少焦耳就能加分」，而是「在同样能到达目标的演示风格里，能量与碰撞过滤能挑出更稳、更不易擦碰、更不易热降额的那条，从而把成功率往上抬」。如果 G5 证明能量层不能转化为成功率，就砍掉能量层，只保留「原语图 + 碰撞认证」——这是本轮预先写好的剪枝条件。

## 1. 直觉与动机

### 1.1 演示里不只有「去哪」，还有「怎么去」

第 12 轮的 DG-KEYFRAME 把每条演示压缩成一个「目标→夹爪」相对位姿 + 一张腕部目标图。这丢掉了同一任务的大量自由度：

- **接近方向**：从上方垂直下压，还是从侧面斜插？对插入任务，侧插可能避开上方障碍，但横向力矩更大。
- **速度剖面**：先在自由空间快走、最后 2 cm 慢压，还是全程匀速？前者通常更省 effort，也更安全。
- **绕行方式**：绕过旁物时，从内侧兜还是从外侧兜？内侧路径短但可能经过奇异构型，外侧路径长但力矩小。
- **安全余量**：成功演示自己会与桌沿、旁物保持一个经验间隙；这个间隙是免费的「人类示教安全策略」。

这些信息在 33k 条演示里是现成的。把它们压成一个关键帧，等于把「一个运动库」压成「一个点」。PACE 的第一个动机就是：**把演示当运动库，而不是目标库。**

### 1.2 能量是 API 里唯一免费的高带宽物理信号

挑战赛 API 没有 depth、没有 force/torque、没有 tactile、没有 camera_info；腕部相机甚至没有内参。但它给了：

- 双臂关节 `[7]`、EE 位姿 `[6]`、夹爪 `[1]`、下身体 `[15]`，30 Hz；
- 官方 G1 URDF 与 MuJoCo/IsaacLab 仓库。

有了关节位置序列，就可以用逆动力学算

```math
\tau = M(q)\ddot q + C(q,\dot q)\dot q + g(q),
```

再用 `∫||τ||² dt` 或 `∫|τ·q̇| dt` 做 effort/工作代理。它不需要新传感器、不需要第二个模型、每端口 CPU 可算。更重要的是：

- 它与**热降额、电池压降、关节磨损、振荡**同向；
- 它对**任务语义不可知**，所以跨 32 个任务通用；
- 它天然是**同目标多风格**之间的比较尺度：两条都能到目标的演示路，effort 低的那条通常更平滑、更不激进。

但必须说清楚：**这不是力矩测量，是模型估计。** 30 Hz 有限差分、URDF 参数误差、夹爪/物体负载未建模，都会让绝对能量不可信。PACE 只用它做**相对排序**和**预算/异常信号**，不做绝对物理断言。

### 1.3 碰撞不是「检测到再停」，而是「选路时就不选会撞的」

第 11 轮 GEO-RESIDUAL 的编辑检测、第 12 轮 CHUNK-SERVO 的「停→重定位→重规划」，都是**事后**的：等场景动了、等人手进来了，才停。对 20% 的人为干扰 trial，这不够。

PACE 把碰撞前移成**选路时的硬约束**：

- 自身碰撞：G1 URDF 胶囊，左右臂、臂—躯干、臂—桌面；
- 环境碰撞：头部双目点云 → 局部 ESDF/体素，目标物与受器按「任务相关」单独处理，允许接触；
- 人的碰撞：GEO-RESIDUAL 的编辑残差 + 双目运动/肤色分割 → 膨胀胶囊，带速度上界；
- 认证范围：不是只认证当前帧，而是认证**整个 5 步块的预测轨迹**（因为 chunk 内没有新观测、也没有打断机制）。

这样，安全不是「走得慢一点」，而是「根本不选那条会撞的边」。代价是可能过度保守；所以约束必须按「目标物可碰、非目标不可碰」分区，并设可辨识性门（不可靠时回退到 CHUNK-SERVO 的 PBVS 粗对齐）。

### 1.4 为什么是现在：四个事实

1. **数据量足够建图**：33,276 条演示 / 169.28 h / 32 任务，单任务 969–1,533 条；足够为每个任务/阶段提供多条风格的原语边。
2. **官方基座已就位**：UnifoLM-WLA-1.0 提供 30 步、30 Hz 的 action head；PACE 不碰大模型，只在其动作块上做选择与重参数化。
3. **接口允许确定性控制**：EE 位姿 30 Hz、关节 30 Hz、头部双目已标定（基线 58.2526 mm），足以在 CPU 上做局部几何与逆动力学。
4. **竞赛结构放大边际收益**：20% 人为干扰 + 19/32 接触密集任务 + 320 次 trial 的连续热负载；碰撞与 effort 都直接作用在这些 trial 上。

## 2. 形式化（完整版见产物区 §2）

### 2.1 数据与原语图

设成功演示集合 $\mathcal D=\{\xi_i\}_{i=1}^{M}$，$M=33{,}276$，每条

```math
\xi_i = \{(q_t,\dot q_t,u_t,o_t)\}_{t=1}^{L_i},
```

其中 $q_t\in\mathbb R^{14}$ 为双臂关节，$u_t$ 为动作，$o_t$ 为四路图像/本体。按 FACT-VLA 的相位分割得到阶段 $\phi$。把每条演示按阶段切成段，每段作为原语图的一条边 $e=(v,v')$，边特征

```math
\varphi(e)=\Big[\textstyle\int\|\tau\|^2dt,\ \int\|\dot q\|^2dt,\ \int\|\ddot q\|^2dt,\ T_e,\ d^{\min}_e,\ \ell_e\Big],
```

其中 $T_e$ 为时长，$d^{\min}_e$ 为演示中的最小间隙，$\ell_e$ 为路径长。节点 $v$ 记录任务、阶段、相对目标位姿、腕部目标图。

### 2.2 学到的代价

不手调能量权重，而是假设演示来自一个以 $w$ 为参数的代价，用 MaxEnt 逆最优控制恢复 $w$：

```math
p(\xi\mid w)=\frac{\exp(-w^\top\varphi(\xi))}{Z(w)},\qquad
\nabla_w(-\log p)=\mathbb E_{\mathcal D}[\varphi]-\mathbb E_{p(\cdot\mid w)}[\varphi].
```

在原语图上，配分函数与边概率可以用 soft value iteration 精确算：

```math
Z(v)=\sum_{e=(v,v')}e^{-w^\top\varphi(e)}Z(v'),\qquad
p(e\mid v)=\frac{e^{-w^\top\varphi(e)}Z(v')}{Z(v)}.
```

于是「示教学习」不是再训一个策略，而是**在演示图上恢复一个可解释的代价向量**；在线只做确定性的最短路/枚举。尺度不可辨识（$w$ 与 $cw$ 等价），固定 $\|w\|=1$ 或某个分量即可。

### 2.3 在线问题

第 $k$ 个 5 步块、块时长 $T_b=H_c/f_c$。给定 VLA 意图 $a^{\mathrm{ff}}$、当前状态、估计的目标位姿与障碍，选择原语边 $e$ 与单调时间缩放 $s:[0,T_b]\to[0,1]$：

```math
\min_{e,\,s(\cdot)}\ \ 
\underbrace{w^\top\varphi(e)}_{\text{学到的 effort}}
+\lambda_{\mathrm{trk}}\big\|T^{\mathrm d}_{ee}(e)-T^{\mathrm{VLA}}_{ee}\big\|^2
+\lambda_{\mathrm{s}}\!\int_0^{T_b}\!\|\Delta(t)\|^2dt
```

subject to

```math
\begin{aligned}
&d_{\mathrm{self}}(\hat x(t))\ge \epsilon_s,\quad
d_{\mathrm{env}}(\hat x(t))\ge \epsilon_e,\quad
d_{\mathrm{human}}(\hat x(t))\ge \epsilon_h,\quad \forall t\in[0,T_b],\\
&s(0)=0,\ s(T_b)=1,\ \dot s(t)\ge 0,\\
&|\dot q(t)|\le \dot q_{\max},\quad |\tau(t)|\le \tau_{\max},\\
&\hat x(t)=\mathrm{FK}(B(s(t))),\quad \tau(t)=\mathrm{ID}(q,\dot q,\ddot q).
\end{aligned}
```

**关键顺序**：先碰撞硬过滤（可行集），再在可行集里按「能量 + 跟踪」排序。能量永远不能把一条会撞的路抬进可行集；碰撞也永远不能因为「那条路更省能量」而放宽。

## 3. PACE 总体设计

```text
离线（一次性，可离线跑数小时）
  33k 演示 ──相位分割──▶ 原语段
      │                    │
      │                    ├─ 逆动力学 ──▶ effort/平滑度特征 φ
      │                    ├─ 演示间隙 ──▶ 安全余量 ε 的先验分布
      │                    └─ 相对目标 ──▶ 原语图节点
      ▼
  MaxEnt IRL（图上的 soft value iteration）──▶ 代价权重 w
      ▼
  原语图 G=(V,E)，边权 c(e)=w^T φ(e)，边附间隙/时长/相对位姿

在线（每端口 CPU，每个 5 步块）
  obs ──▶ 目标位姿 / 障碍（双目+URDF）/ 人（GEO-RESIDUAL）
      │
      ▼
  检索候选边（任务/阶段/相对位姿）──▶ 碰撞认证（整块预测轨迹）
      │                                   │
      │                                   ├─ 不可行：丢弃
      │                                   └─ 可行：进入排序
      ▼
  排序 min [c(e) + λ_trk·跟踪 + λ_s·平滑] ──▶ 选中边
      ▼
  时间重参数化到 T_b ──▶ 叠加 CHUNK-SERVO 伺服 Δ ──▶ 5 步动作块
```

两层循环：

- **慢层（阶段边界 / 编辑触发）**：在原语图上做 A*/Dijkstra，得到从当前节点到目标节点的名义路径与能量预算。
- **快层（每个 5 步块）**：只对下一段边做碰撞再认证、时间重参数化、叠加伺服；不重跑全局规划。

这样既保留了「演示运动库」的长程结构，又满足 167 ms 的块级预算。

## 4. 与第 10/11/12 轮的关系

| 轮次 | 保留 | PACE 的升级 |
|---|---|---|
| 第 10 轮 FACT-VLA | 相位化 BC、CAC 柔顺、EGP 门控 | 相位从「标签」变成「原语图的索引」；代价权重由演示恢复 |
| 第 11 轮 GEO-RESIDUAL | 动作条件化残差、米制距离、编辑检测 | 残差从「标注/触发」变成「碰撞硬约束 + 人的膨胀体」 |
| 第 12 轮 CHUNK-SERVO | 30 步规划 + 5 步伺服、DG-KEYFRAME、双频执行 | 单关键帧目标 → 原语图选路；PID → 在选中的边上做伺服；加能量排序与整块碰撞认证 |

**剪枝**（沿用前几轮结论）：不从零训 VLA/世界模型；不做第二个学习策略/残差网络；不做 30 Hz 广域网高增益伺服；不做力/触觉闭环（API 没有）；不把预览榜单的任务排名当难度表。

## 5. 可验证的创新点

1. **演示即代价（LfD-as-cost）**：用 MaxEnt IRL 在 33k 演示的原语图上恢复 effort/平滑度权重，而不是手工设 `∫τ²` 的系数；可离线验证「恢复的权重能复现留出演示的排序」。
2. **能量排序 + 碰撞认证的分离**：先硬过滤后软排序，给出条件安全论证与「不劣于 CHUNK-SERVO（在可行候选内）」的性质；避免把安全做成软惩罚。
3. **块内时间重参数化**：在固定 5 步块时长内，用单调时间缩放降低 effort，而不是靠缩短 chunk 或提高增益；与 CHUNK-SERVO 的伺服修正正交。

## 7. 风险（完整表见产物区 §9）

| 风险 | 影响 | 缓解 |
|---|---|---|
| 能量不直接计分 | 投入可能不转化为成功率 | G5 预注册剪枝；能量只做 tie-breaker |
| 逆动力学噪声 | 绝对 effort 不可信 | 只用相对排序；低通/分段；G0 |
| 无 depth / 透明反光 | 碰撞认证失效 | 目标物分区；不可用即回退；G2 |
| 原语图不泛化 | 位置/背景变化下选错边 | 相对目标帧；任务/阶段过滤；在线再认证 |
| IRL 不可辨识 | 权重不唯一 | 归一化 + 非负约束 + 留出验证；G1 |
| 过度保守 | 停在最后 3 cm 外 | 目标物可碰；可辨识性门；降级到 CHUNK-SERVO |
| 单模型合规 | 被判定为第二个模型 | 离线固定代价 + 在线确定性优化；C1/C2 |
| 延迟 | 双目/图搜索超预算 | 降采样；慢层/快层分离；G7 |
| 玩具不预测真机 | 数字好看但无效 | 明确标注；G5 才是判据 |

## 8. 一句话押注

**用 33k 演示学一个可解释的 effort 代价与一张碰撞认证的原语图，让 CHUNK-SERVO 的最后 3 厘米不再只追一个关键帧，而是在「能安全走通的演示路」里挑一条能量最低、最平滑的路，再做伺服。**

**当前方案最大的风险：能耗在赛题里不直接计分，而 30 Hz 有限差分估出的逆动力学 effort 既噪声大、又可能被一个更便宜的平滑正则完全替代——如果 G5 看不到成功率增益，PACE 就应退化成「原语图 + 碰撞过滤」，能量层必须被砍掉。**

# 第 13 轮产物 · PACE 技术报告

> 检索/复核日期：**2026-11-02（UTC）**。对象：宇树 **UniBot 世界挑战赛**（G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API）。本报告是第 13 轮想法区「PACE」的工程化产物；承接第 10 轮 **FACT-VLA**、第 11 轮 **GEO-RESIDUAL**、第 12 轮 **CHUNK-SERVO**，不替换它们。官方事实沿用第 12 轮（2026-10-28）已核实来源；本轮 **2026-11-02** 未新增外部数据，新增的是形式化、算法与一个可复现的玩具实验。

## 0. 结论与边界

### 0.1 一句话结论

CHUNK-SERVO 把最后 3 厘米从「1 秒开环」变成了「167 ms 闭环」，但它的目标仍是一个检索到的关键帧、它的执行仍是单条 PID 轨迹。**PACE** 在同样的 5 步块内增加两层：先用**碰撞硬约束**（自身 / 环境 / 人）对候选运动原语做整块认证，再在可行集里按**从演示学到的 effort 代价 + 对 VLA 意图的跟踪偏差**排序，最后对选中的边做**时间重参数化**并叠加伺服修正。演示不再只是「目标库」，而是「带能量标签与安全余量的运动库」。

### 0.2 证据等级

| 等级 | 含义 | 本报告中的例子 |
|---|---|---|
| A | 官方文档、提交模板、数据集元数据、排行榜 JSON 直接核实（沿用第 12 轮） | 规则、API、33,276 eps、WLA `chunk_size=30`、头部双目基线 |
| B | 我们在公开数据/网页上做的分析，可复现（沿用第 12 轮） | 榜单 `step~success` 回归、跨模型任务相关 |
| C | 设计假设，需 G0–G9 验证；或本报告的玩具计算 | 能量排序涨点、IRL 权重可恢复、碰撞认证误差 |
| T | 本报告新增的玩具实验（2-link 平面臂，可复现脚本） | 安全溢价 4.79%、时间缩放降 effort 15.87% |

### 0.3 本轮不做什么

- 不从零训 VLA/World Model；官方 WLA 已提供 30 步 action head。
- 不做第二个**在线学习策略/残差网络**；IRL 是离线固定代价，在线是确定性过滤 + 枚举/最短路。
- 不把能量当主目标；它只在碰撞可行集内做排序与预算信号。
- 不做力/触觉闭环（API 没有）；不做 30 Hz 广域网高增益伺服。
- 不做完整 sim-to-real 策略训练；仿真只验证机制与稳定域。
- 不把玩具实验的数字外推为真机成功率。

### 1.2 本轮新增的假设（C，必须验证）

1. **演示中有可用的关节状态序列**，至少能以 30 fps 读出双臂关节 `[7]×2`，用于有限差分估计 $\dot q,\ddot q$。若数据只有图像/EE，则退化到只用平滑度与 EE 曲率代理。

## 2. 问题形式化

### 2.1 状态、动作、评分

沿用第 12 轮：

```math
S=\frac{1}{32}\sum_{t=1}^{32}p_t,\qquad
p_t=\frac{1}{10}\sum_{j=1}^{10}y_{t,j},\quad y_{t,j}\in\{0,1\}.
```

单任务成功是主目标；能量/平滑是**约束内的次级目标**，不进入官方评分。我们优化的不是 $S$ 的直接代理，而是「在给定 VLA 意图下，提高单次 trial 的完成概率并降低碰撞/热失效风险」。

### 2.2 Effort 泛函

设关节 $q\in\mathbb R^{n}$（$n=14$ 双臂，忽略腰/腿；若动作涉及下身体再扩到 $n=29$）。逆动力学：

```math
\tau(q,\dot q,\ddot q)=M(q)\ddot q+C(q,\dot q)\dot q+g(q).
```

定义 **effort 泛函**

```math
\mathcal E(\xi)=\int_0^T\Big(\tau^\top W\tau+\mu\,\dot q^\top V\dot q\Big)\,dt,
```

$W,V\succ0$ 对角，按关节热/负载加权。它不是机械功（机械功 $\int|\tau\cdot\dot q|dt$ 可正可负），而是常用的**力矩平方 effort 代理**：对高力矩、快运动、抖动都单调惩罚。绝对单位不可信，只做相对排序。

也可用平滑度代理

```math
\mathcal J(\xi)=\int_0^T\|\dddot q\|^2dt
```

作为消融基线；若 $\mathcal J$ 与 $\mathcal E$ 排序高度一致，则能量层可被更便宜的代理替代——这是 G8 的剪枝条件。

### 2.3 碰撞安全集

在 base 系定义障碍：

- 自身：G1 胶囊集 $\mathcal C_{\text{self}}(q)$；
- 环境：双目点云 + 桌面平面 + 目标物/受器（任务相关，允许接触）→ 有符号距离 $d_{\text{env}}(x)$；
- 人：膨胀胶囊/扫掠体，$d_{\text{human}}(x,t)$，带速度上界 $v_h^{\max}$。

安全集（对预测轨迹逐点）：

```math
\mathcal S_t=\Big\{x:\ d_{\text{self}}(x,q)\ge\epsilon_s,\ 
d_{\text{env}}(x)\ge\epsilon_e,\ 
d_{\text{human}}(x,t)\ge\epsilon_h\Big\}.
```

余量分解：

```math
\epsilon=\epsilon_{\text{sensor}}+\epsilon_{\text{state}}+\epsilon_{\text{track}}+\epsilon_{\text{margin}},
```

其中 $\epsilon_{\text{sensor}}$ 为双目/标定误差，$\epsilon_{\text{state}}$ 为位姿估计误差，$\epsilon_{\text{track}}$ 为跟踪误差上界，$\epsilon_{\text{margin}}$ 为工程余量。真实默认 1.5–2 cm：桌面任务必须允许目标物接触，所以**只对非目标物与人**施加该余量；目标物用「任务相关接触许可」单独标记。

### 2.4 原语图

**节点** $v=( \text{task},\text{phase},T_{\text{target},ee}^{*},I_{\text{wrist}},q_{\text{ref}})$：任务、阶段、目标→夹爪相对位姿、腕部目标图、参考关节构型。

**边** $e=(v,v')$：一条演示中相邻节点之间的段。边特征

```math
\varphi(e)=\Big[
\tfrac{1}{T_e}\!\int\!\|\tau\|^2dt,\ 
\tfrac{1}{T_e}\!\int\!\|\dot q\|^2dt,\ 
\tfrac{1}{T_e}\!\int\!\|\ddot q\|^2dt,\ 
T_e,\ d^{\min}_e,\ \ell_e
\Big]\in\mathbb R^{6}.
```

**边权** $c(e)=w^\top\varphi(e)$，$w\ge0$。

**图** $\mathcal G=(\mathcal V,\mathcal E)$。同一 (task, phase) 内的节点/边构成子图；跨阶段边只在演示中真实相邻时存在。位置泛化时，整张子图按当前 $T_{\text{base,target}}$ 迁移，而不是固定 base 坐标。

### 2.5 在线优化问题

第 $k$ 个块，块时长 $T_b=H_c/f_c$（默认 $H_c=5$、$f_c=30$ → 167 ms）。给定 VLA 前馈 $a^{\text{ff}}_{1:H_c}$、当前 $q,\dot q$、估计目标 $T_{\text{base,target}}$、障碍与人的估计，选择边 $e$ 与单调时间缩放 $s:[0,T_b]\to[0,1]$：

```math
\boxed{
\begin{aligned}
\min_{e\in\mathcal E,\ s(\cdot)}\quad
& w^\top\varphi(e)
+\lambda_{\text{trk}}\big\|T^{\text d}_{ee}(e)-T^{\text{VLA}}_{ee}\big\|^2
+\lambda_{\text{s}}\!\int_0^{T_b}\!\|\Delta(t)\|^2dt\\
\text{s.t.}\quad
& d_{\text{self}}(\hat x(t),q(t))\ge\epsilon_s,\\
& d_{\text{env}}(\hat x(t))\ge\epsilon_e,\\
& d_{\text{human}}(\hat x(t),t)\ge\epsilon_h,\qquad \forall t\in[0,T_b],\\
& s(0)=0,\ s(T_b)=1,\ \dot s(t)\ge0,\\
& |\dot q(t)|\le\dot q_{\max},\quad |\tau(t)|\le\tau_{\max},\\
& \hat x(t)=\mathrm{FK}(B_e(s(t))),\quad
\tau(t)=\mathrm{ID}(q(t),\dot q(t),\ddot q(t)).
\end{aligned}}
```

**求解顺序**（不可交换）：

1. **硬过滤**：对每个候选边，把整块预测轨迹逐点做碰撞检查；不可行直接丢弃。
2. **软排序**：在可行集 $\mathcal F_k$ 内，用上式（去掉碰撞约束）排序。
3. **时间重参数化**：只对选中的边求 $s(\cdot)$。
4. **伺服叠加**：在选中边上叠加 CHUNK-SERVO 的 $\Delta$，再检查一次可行性；若叠加后不可行，缩小 $\Delta$ 或回退。

## 3. 离线学习

### 3.1 逆动力学能量标签

对每条演示 $\xi_i$：

1. 取双臂关节 $q_t$，30 fps；
2. 低通滤波（例如 10 Hz 零相位）后中心差分：
   ```math
   \dot q_t\approx\frac{q_{t+1}-q_{t-1}}{2\Delta t},\qquad
   \ddot q_t\approx\frac{q_{t+1}-2q_t+q_{t-1}}{\Delta t^2};
   ```
3. 用 G1 URDF 的 $M,C,g$ 算 $\tau_t$；
4. 对每段 $e$ 积分 $\int\|\tau\|^2dt$、$\int\|\dot q\|^2dt$、$\int\|\ddot q\|^2dt$。

**采样策略**：不必对 18.28M 帧全算。按阶段段取 10 Hz 子采样（约为原帧数的 1/3），33k episodes × 平均 ~15 s × 10 Hz ≈ 5M 个样本；$n=14$ 的逆动力学每样本约 $O(n^3)$ 但 $M,C,g$ 可缓存，离线数小时可完成。若 URDF 惯量与真实有偏差，绝对 effort 偏移，但同一任务内的相对排序通常保留（G0 验证）。

**已知退化**：若演示数据只有图像/EE 而无关节序列，则 $\tau$ 不可算；退化为
```math
\hat{\mathcal E}=\int\|\ddot x_{ee}\|^2dt+\mu\int\|\dot x_{ee}\|^2dt,
```
仍然可以做相对排序，但解释力下降。

### 3.2 MaxEnt 逆最优控制恢复权重

**假设**：演示由代价 $c(\xi)=w^\top\varphi(\xi)$ 生成，轨迹分布为

```math
p(\xi\mid w)=\frac{\exp(-w^\top\varphi(\xi))}{Z(w)},\qquad
Z(w)=\sum_{\xi}\exp(-w^\top\varphi(\xi)).
```

负对数似然：

```math
\mathcal L(w)=\sum_{i=1}^{M}w^\top\varphi(\xi_i)+M\log Z(w).
```

梯度：

```math
\nabla_w\mathcal L
=\sum_{i=1}^{M}\varphi(\xi_i)-M\,\mathbb E_{p(\cdot\mid w)}[\varphi].
```

**在原语图上的精确计算**。把图按阶段视为 DAG（时间前进），从终点反向做 soft value iteration：

```math
Z(v)=\sum_{e=(v,v')}e^{-w^\top\varphi(e)}Z(v'),\qquad Z(v_{\text{goal}})=1.
```

前向消息（从起点到 $v$）：

```math
\alpha(v_{\text{start}})=1,\qquad
\alpha(v')=\sum_{e=(u,v')}\alpha(u)e^{-w^\top\varphi(e)}.
```

边的后验访问概率：

```math
p(e)=\frac{\alpha(u)\,e^{-w^\top\varphi(e)}\,Z(v')}{Z(v_{\text{start}})}.
```

于是

```math
\mathbb E_{p}[\varphi]=\sum_{e\in\mathcal E}p(e)\varphi(e),
```

梯度可精确计算，不需要采样轨迹。**算法**：

```text
输入：图 G、演示计数 n(e)（每条演示边计 1）
初始化 w = 1/6（归一化），或手调先验
for iter in 1..K:
    前向/反向 soft VI → Z, α
    p(e) ← α(u) exp(-w^T φ(e)) Z(v') / Z(start)
    g ← Σ_e n(e) φ(e) - M Σ_e p(e) φ(e)
    w ← proj_{w≥0, ||w||=1}( w - η g )
    if ||g|| < tol: break
返回 w
```

**可辨识性**：$w$ 与 $cw$ 给出同一策略，固定 $\|w\|=1$；特征共线时加 $\lambda\|w\|^2$；非负约束用投影或 $w=\mathrm{softplus}(z)$。若特征在图上秩亏，某些分量不可辨识，G1 会检测并回退手调。

**为什么用 MaxEnt 而不是 max-margin**：演示有 33k 条、风格多样，MaxEnt 给出平滑的后验与可计算的 $\log Z$；max-margin 只给约束集交点，遇到噪声/次优演示会不稳定。

### 3.3 原语图构建

```text
for each episode ξ:
    phases = segment(ξ)                     # FACT-VLA
    for each phase φ:
        segments = split_by_phase(ξ, φ)
        for each segment e:
            v = node(task, φ, relative_pose(k), wrist_image(k), q_ref)
            v' = node(task, φ', relative_pose(k'), ...)
            φ(e) = inverse_dynamics_features(e)
            add_edge(v, v', φ(e), duration, clearance(e))
```

**节点合并**：相对位姿按 5 mm / 2° 量化，腕部描述子用 ORB/颜色直方图（不引入第二个学习编码器）；同 (task, phase, 位姿桶) 的节点合并，边保留多条风格（不同 duration/clearance/energy），供在线仲裁。

**剪枝**：

- 演示间隙 $d^{\min}_e<\epsilon_{\text{prior}}$ 的边不进入图（成功演示也可能擦碰，按先验剔除）；
- 时长/能量离群的边（$>3\sigma$）标记为低质量，只在候选不足时启用；
- 跨阶段边只在演示中真实相邻时保留，禁止「跳阶段」。

**规模估算**：33k eps，每 eps 约 3–6 个阶段段 → 约 10–20 万条边；边特征 6 维 + 元数据，几百 MB 内存，可按任务分片、端口只读共享。

### 3.4 安全余量学习（可选）

若演示的双目点云可用，对每条成功演示的每个关键帧估计最小间隙 $d^{\min}$，得到任务/阶段的条件分布。取低分位数作为先验：

```math
\epsilon_{\text{demo}}(\text{task},\phi)=\mathrm{Quantile}_{0.1}\big(\{d^{\min}_e\}\big).
```

在线余量取

```math
\epsilon=\max\big(\epsilon_{\text{demo}},\ \epsilon_{\text{sensor}}+\epsilon_{\text{state}}+\epsilon_{\text{track}}\big).
```

若双目/深度不可靠（透明、反光、无纹理），$\epsilon_{\text{demo}}$ 不可信，回退固定 1.5–2 cm，并把该任务标记为「只做目标物接触许可，非目标物用保守盒」。

### 3.5 时间重参数化

给定一条几何路径 $B:[0,1]\to\mathbb R^n$（关节空间，来自演示边或迁移后的逆解），块时长 $T_b$，求单调 $s:[0,T_b]\to[0,1]$：

```math
q(t)=B(s(t)),\quad
\dot q=B_s(s)\dot s,\quad
\ddot q=B_{ss}(s)\dot s^2+B_s(s)\ddot s.
```

代入 effort：

```math
\min_{s(\cdot)}\int_0^{T_b}\Big(\tau(q,\dot q,\ddot q)^\top W\tau(q,\dot q,\ddot q)+\mu\dot q^\top V\dot q\Big)dt
```

s.t. $s(0)=0,s(T_b)=1,\dot s\ge0,|\dot q|\le\dot q_{\max},|\tau|\le\tau_{\max}$。

**离散化**：在 $N$ 个节点上取 $s_j$，用有限差分/梯形积分；约束 $\dot s_j\ge0$、边界固定。用 SLSQP 或 1D DP（状态 $(s,\dot s)$ 网格）求解。

**为什么不用简单的恒定 $\dot s$**：恒定参数速度在「高力矩构型」和「低力矩构型」上花同样的时间；把时间多分给高力矩段、少分给低力矩段，可以在同一 $T_b$ 内降低 $\int\|\tau\|^2dt$。玩具实验显示固定 $T_b=1$ s 时可降 **15.87%**（§7）。

**实时性**：不预计算所有边（10–20 万条太贵）。只对当前选中的边在线解一次小规模 DP：$N_s=20$、$N_{\dot s}=15$ → 300 个格点，微秒–毫秒级。若超预算，退化为预计算的三档速度剖面（慢/中/快），按能量选档。

## 4. 在线算法

### 4.1 两层循环

```text
慢层（阶段边界 / 编辑触发 / 每 ~1 s）
  A*(G, v_now, v_goal) → 名义边序列 + 能量预算
  缓存 path = [e_1, e_2, ...]

快层（每个 5 步块，T_b=167 ms）
  1. 更新目标位姿 / 障碍 / 人（双目 + URDF + GEO-RESIDUAL）
  2. 取 path 的下一段 e（以及同 (task,phase) 的 K-1 个候选）
  3. 迁移到当前目标帧；整块预测轨迹碰撞认证
  4. 可行集 F 内按 J 排序；取 argmin
  5. 对选中边在线时间重参数化
  6. 叠加 CHUNK-SERVO 伺服 Δ；再认证；不可行则缩小 Δ / 回退
  7. 返回 5 步动作块；更新 path 指针
```

慢层保证长程结构（演示图的阶段连接）；快层保证 167 ms 反应性。编辑检测触发慢层重规划。

### 4.2 候选生成

```text
C = { e ∈ G : e.task = current_task,
             e.phase ∈ {current_phase, next_phase},
             ||T_target_ee(e) - T_target_ee(current)|| ≤ δ_pose }
C = top_K(C, descriptor_distance(wrist), pose_consistency)
```

- $K$ 默认 5：1 条来自慢层名义路径，4 条来自同阶段不同风格（不同接近方向/速度/绕行）。
- 任务/阶段过滤优先于外观，避免把「插网线」匹配到「拔网线」。
- 相对位姿先验只用于 rerank，不硬筛；否则位置泛化会失效。

### 4.3 碰撞认证

对候选边 $e$、时间缩放 $s(\cdot)$：

```text
for j in 1..N_check:                      # N_check ≈ 5–10，覆盖整块
    t_j = j * T_b / N_check
    q_j = B_e(s(t_j)); x_j = FK(q_j)
    if capsule_self_distance(q_j) < ε_s: return INFEASIBLE
    if esdf(x_j) < ε_e:                 return INFEASIBLE
    if human_distance(x_j, t_j) < ε_h:  return INFEASIBLE
    if |qdot_j| > qdot_max or |tau_j| > tau_max: return INFEASIBLE
return FEASIBLE
```

- **自身**：只算双臂 + 躯干 + 桌面附近的胶囊，$O(n_{\text{caps}}^2)$，$n_{\text{caps}}\sim20$。
- **环境**：头部双目下采样到 240×320，块匹配/半全局匹配得深度；只维护目标附近 0.8 m³ 的局部 ESDF/体素；查询 $O(1)$ 插值。
- **人**：GEO-RESIDUAL 的编辑分数 + 双目运动掩码 → 膨胀胶囊；用速度上界外推 $T_b$ 的扫掠体。
- **目标物**：按任务/阶段标记为「允许接触」，不施加 $\epsilon_e$；但仍检查自身碰撞与夹爪闭合。

### 4.4 仲裁

在可行集 $\mathcal F$ 上：

```math
e^\star=\arg\min_{e\in\mathcal F}\Big[
w^\top\varphi(e)
+\lambda_{\text{trk}}\|T^{\text d}_{ee}(e)-T^{\text{VLA}}_{ee}\|^2
+\lambda_{\text{s}}\|\Delta_e\|^2
\Big].
```

- $w$ 来自 IRL；$\lambda_{\text{trk}},\lambda_{\text{s}}$ 由仿真/单任务通道调。
- 若 $\mathcal F=\varnothing$：不硬走；返回安全保持（零速/微退）并触发慢层重规划；若连续 3 块为空，回退 CHUNK-SERVO 的 PBVS 粗对齐（降低速度）。
- 若最小代价与次小代价差距小于阈值，选**间隙更大/能量更低**的那条（保守 tie-break）。

### 4.5 与 CHUNK-SERVO 伺服合成

CHUNK-SERVO 的修正在 EE 局部系：

```math
a_{\text{cmd}}=a_{\text{ff}}\circ\exp(\Delta),\qquad
\Delta=\mathrm{clip}(K_p e+K_d\dot e,\pm\delta_p,\pm\delta_r).
```

PACE 只改变 $a_{\text{ff}}$ 的来源（选中原语边的时间重参数化），$\Delta$ 仍是反馈：

```math
a_{\text{cmd}}(t)=a^{\text{PACE}}_{\text{ff}}(t)\circ\exp(\Delta(t)).
```

- 时间重参数化给出 $q(t),\dot q(t)$ 或 EE 路径；用 adapter 转成 API 的绝对 EE 位姿序列。
- 若选中边的端点与当前 VLA 意图偏差过大（$\lambda_{\text{trk}}$ 项爆炸），拒绝该边，回退 VLA 前馈 + 伺服。
- 接触段沿用第 11 轮的法向缩幅/切向保留；PACE 不改变接触控制律，只改变接近路径。

### 4.6 `get_action` 伪代码

```python
class PACEPolicy:
    def get_action(self, obs):
        self._tick(obs)
        self._maybe_replan_slow(obs)          # A* on primitive graph, async

        cands = self._candidates(obs)          # K edges
        feasible = []
        for e in cands:
            s = self._time_scale(e, obs, self.T_b)
            if self._collision_certify(e, s, obs):
                feasible.append((self._cost(e, obs), e, s))

        if not feasible:
            return self._safe_hold_or_fallback(obs)

        _, e, s = min(feasible, key=lambda z: z[0])
        a_ff = self._edge_to_actions(e, s, obs)     # 5-step EE targets
        delta = self.servo.compute(obs, self.goal)  # CHUNK-SERVO
        a_cmd = compose(a_ff, delta)

        if not self._collision_certify_actions(a_cmd, obs):
            a_cmd = self._shrink_until_feasible(a_cmd, obs)

        return self.adapter.to_api(a_cmd, obs, self.token)
```

`_maybe_replan_slow` 用线程池异步执行；不阻塞 `get_action`。冷启动时若没有图/目标，回退 CHUNK-SERVO 的同步 VLA。

## 5. 正确性论证

### 5.1 条件安全（Theorem 1）

**设定**：真实障碍集 $\mathcal O$，估计障碍集 $\hat{\mathcal O}\supseteq\mathcal O$（保守膨胀）。预测轨迹 $\hat x(t)$，实际轨迹 $x(t)$，跟踪误差上界 $\|x(t)-\hat x(t)\|\le e_{\text{trk}}$。距离函数 $d(\cdot,\mathcal O)$ 是 1-Lipschitz。

**命题**：若对块内所有 $t$，$d(\hat x(t),\hat{\mathcal O})\ge\epsilon$，则

```math
d(x(t),\mathcal O)\ge\epsilon-e_{\text{trk}}.
```

**证明**：

```math
d(x,\mathcal O)
\ge d(x,\hat{\mathcal O})          & \text{（}\hat{\mathcal O}\supseteq\mathcal O\text{）}\\
\ge d(\hat x,\hat{\mathcal O})-\|x-\hat x\|
                                   & \text{（1-Lipschitz）}\\
\ge \epsilon-e_{\text{trk}}.       & \text{（假设）}
```

取 $\epsilon>e_{\text{trk}}$ 即得正间隙。**边界**：这是条件安全，不是绝对安全；$\hat{\mathcal O}\supseteq\mathcal O$ 依赖双目/标定的保守性，$e_{\text{trk}}$ 依赖控制器与延迟。透明/反光/快速人手可能破坏前提，所以 G2/G6 是硬门。

### 5.2 不劣于 CHUNK-SERVO（Theorem 2）

**设定**：候选集 $\mathcal C$，可行集 $\mathcal F\subseteq\mathcal C$。CHUNK-SERVO 的输出对应某个候选 $c_0$（单关键帧 + $\Delta$）。若 $c_0\in\mathcal F$，则

```math
\min_{c\in\mathcal F}J(c)\le J(c_0).
```

**证明**：$c_0$ 在可行集内，最小值不可能大于它。**边界**：如果 $c_0\notin\mathcal F$（例如关键帧路径会撞人或新障碍），PACE 会牺牲跟踪换取安全；此时 $J(c^\star)>J(c_0)$ 是**预期的**，应在报告中同时给出跟踪误差与安全增益，而不是只报总代价。

### 5.3 能量单调性 / Pareto（Theorem 3）

**设定**：有限候选集，$J_\lambda(c)=C_{\text{trk}}(c)+\lambda c_E(c)$，$c^\star(\lambda)=\arg\min_{c\in\mathcal C}J_\lambda(c)$。

**命题**：若 $\lambda_1<\lambda_2$，则 $c_E(c^\star(\lambda_2))\le c_E(c^\star(\lambda_1))$。

**证明**：记 $c_1=c^\star(\lambda_1)$，$c_2=c^\star(\lambda_2)$。由最优性：

```math
C_{\text{trk}}(c_1)+\lambda_1c_E(c_1)\le C_{\text{trk}}(c_2)+\lambda_1c_E(c_2),
```
```math
C_{\text{trk}}(c_2)+\lambda_2c_E(c_2)\le C_{\text{trk}}(c_1)+\lambda_2c_E(c_1).
```

两式相加：

```math
(\lambda_2-\lambda_1)\big(c_E(c_2)-c_E(c_1)\big)\le0
\ \Longrightarrow\ c_E(c_2)\le c_E(c_1).
```

所以扫描 $\lambda$ 可以描出「跟踪—能量」Pareto 前沿；实践中用单任务通道选 $\lambda$，而不是拍脑袋。

### 5.4 IRL 一致性（Theorem 4）

**命题**：若演示由 $p(\xi\mid w^\star)$ 生成，特征映射在图上满秩（至多差一个尺度），则负对数似然 $\mathcal L(w)$ 是凸的，梯度下降收敛到全局最优；当 $M\to\infty$，$\hat w\to w^\star$（至尺度）。

**证明要点**：$\log Z(w)=\log\sum_\xi\exp(-w^\top\varphi(\xi))$ 是 log-sum-exp，凸；线性项不破坏凸性；满秩保证严格凸（至尺度）。有限样本下有估计误差；加 $\ell_2$ 正则有偏。**边界**：若特征共线或演示非最优（人类抖动、次优风格），$\hat w$ 只反映「演示的平均偏好」，不是「物理真值」。G1 用留出演示的排序相关验证，而不是看权重数值好不好看。

### 5.5 时间缩放的最优性（Proposition 5）

**命题**：固定几何路径 $B$ 与边界 $s(0)=0,s(T_b)=1$，在离散节点上最小化 §3.5 的积分，SLSQP 收敛到满足 KKT 的局部最优；若把动力学线性化、代价凸化，则问题是凸的，得到全局最优。

**边界**：完整非线性动力学 + 单调约束不是凸问题；多起点可降低陷入差局部解的风险，但不能保证全局。报告应给「相对恒定速度的改进」，而不是「全局最优」。

### 5.6 局限汇总

- 安全定理依赖保守障碍与有界跟踪；二者都是估计。
- 不劣性只在「CHUNK-SERVO 候选在可行集内」时成立。
- 能量排序依赖 URDF/有限差分；绝对数值不可信。
- IRL 只恢复演示的**平均**偏好，可能把「人类习惯」误当「物理最优」。
- 玩具实验只验证机制，不预测 G1 真机。

## 7. 玩具实验（T，可复现）

### 7.1 目的与边界

验证三个机制，不验证 G1 真机：

1. 碰撞硬过滤是否会把「最小能量但会撞」的原语删掉；
2. 在可行集里做能量排序，安全溢价是否可接受；
3. 固定块时长内做时间重参数化，是否能降低 effort。

**模型**：2-link 平面臂，$m_1=m_2=1$ kg，$l_1=l_2=0.30$ m，$I_i=m_il_i^2/12$，$g=9.81$；标准二连杆逆动力学；effort $=\int(\|\tau\|^2+0.02\|\dot q\|^2)dt$（归一化 effort 单位，非焦耳）。路径为关节空间二次 Bézier；候选由目标附近的极坐标 via 点 + 解析 IK 生成（139 条）；障碍为圆心 $(0.52,0.16)$、半径 0.07 m 的圆；碰撞余量 0.01 m（即要求最小间隙 >0.08 m）；块时长 $T_b=1.0$ s。

### 7.2 结果

| 指标 | 数值 |
|---|---:|
| 候选原语数 | 139 |
| 碰撞可行原语数 | 18（12.9%） |
| 关节直线路径 | 间隙 **0.0559 m**（撞），effort **74.65** |
| 全候选最小 effort | effort **43.09**，间隙 **0.0611 m**（违反 0.08 余量） |
| 可行集最小 effort（选中） | effort **45.16**，间隙 **0.0873 m** |
| 安全溢价（选中 vs 全最小） | **+4.79%** |
| 时间重参数化（$T_b=1.0$ s） | effort **45.16 → 37.99**（**−15.87%**），$\min\dot s=0.049$ |
| effort 最优块时长（该路径） | $T^\star\approx0.5$ s，effort $\approx21.8$ |
| $T_b=1.0$ s 相对 $T^\star$ 的 effort | 约 **+74%** |

### 7.3 解读

- **碰撞过滤确实在做事**：全候选最小 effort 的间隙 0.0611 m < 0.08 m，被硬过滤删除；选中可行边的间隙 0.0873 m。安全溢价只有 4.79%，说明「安全」在这个例子里不昂贵。
- **关节直线既撞又费能量**：它经过 $q_2\approx0$ 的肘部伸直构型，接近奇异；演示原语里折叠的 via 路径同时更安全、更省 effort。这支持「演示运动库 + 能量排序」优于「直线插值 + 目标 PID」。
- **时间重参数化是免费的午餐（在固定块时长内）**：15.87% 的 effort 下降不需要改 chunk size、不需要加增益，只改速度剖面。
- **但不要盲目加速**：effort 最优时长约 0.5 s，比 1 s 块短；在真机上这会被接触动力学、RTT、关节速度上限和碰撞认证约束，不能直接外推。PACE 的默认仍是「块时长由 $H_c/f_c$ 固定，只在块内重参数化」；缩短时长是 G4/G7 之后的选项。

### 7.4 复现

玩具脚本位于本轮临时工作区（`/tmp/opencode/pace_final.py`），依赖 numpy/scipy；随机种子固定，结果可复现。它是机制验证，不是机器人实验；所有数字标注为 T 级。

| 玩具外推 | 数字好看但真机无效 | 明确 T 级；G5 才是判据 |
| 数据泄漏 | 离线指标虚高 | 按 session/物体/背景分组；相邻帧不跨 split |

## 11. 一句话押注

**用 33k 演示学一个可解释的 effort 代价与一张碰撞认证的原语图，让 CHUNK-SERVO 的最后 3 厘米不再只追一个关键帧，而是在「能安全走通的演示路」里挑一条能量最低、最平滑的路，再做伺服。**

**当前方案最大的风险：能耗在赛题里不直接计分，而 30 Hz 有限差分估出的逆动力学 effort 既噪声大、又可能被一个更便宜的平滑正则完全替代——如果 G5 看不到成功率增益，PACE 就应退化成「原语图 + 碰撞过滤」，能量层必须被砍掉。**
