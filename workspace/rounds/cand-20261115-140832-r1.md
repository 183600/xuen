# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「价值对齐」×「平衡控制」）

> R69 给闭环装上了「嘴巴」：把不确定性一分为二，aleatoric 收紧、epistemic 去问，并用流似然做标定不可吸收的第二意见。但它有两处盲区，且都指向同一个方向——**R69 会问，却不知道「该按谁的标准问」**。
> - 第一，R69 的交互成本 c(g) 是**手设的社会/物理成本**。可「打扰一次」到底值多少、对谁值多少，本来就是一个**价值问题**，不是一个超参数。
> - 第二，R69 的证据纪律只管「事实是否被佐证」，管不了「偏好是否被合法表达」。一个人被问了一百次，他的一百次回答在 k-正交里都「自洽」，于是系统把**最常被问的人的长相**，当成了**规范的长相**。
>
> 本轮两个灵感正好补两块：
> - **价值对齐**：把「值多少 / 什么可接受」从标量奖励里解放出来，表示为**多利益方的可接受性边界**——不是去最大化一个数，而是维持一组**价值边际**不越界；
> - **平衡控制**：给出处理「多边界同时成立」的正确数学对象——**控制不变性 / 控制屏障函数 / 捕获点**。「平衡」不是折中，是**在扰动下让所有边际同时保持非负**；而「站不住」不是分数变低，是**越过捕获点后无论怎么努力都回不来**。
>
> 核心命题：**价值对齐 = 把价值写成可认证的硬边界（屏障），把规范不确定性写成第三种不确定性（axiological），把交互成本写成价值边际的消耗，然后像控制倒立摆一样维持多利益方边际的动态平衡；当边际越过捕获点时，触发「安全跌落」（交还控制/停止/重协商），而不是假装还能恢复。** 命名 **LIBRA-RAS**（Legitimacy-bounded Interactive Balance-control for Reciprocal Alignment；Libra 即天平）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「向谁求证、还能问什么」，R70 问「**问到的标准本身站得住吗？我还能把它撑多久？**」——对齐不是一个终点奖励，而是一个必须实时维持的**平衡姿态**。

## 0. 直觉与动机

**灵感 1（价值对齐 ≠ 一个更大的奖励项）**
直觉：把「对齐」做成 reward shaping 是错的，因为它把「不可交易的东西」压成一个可交易的标量：多给一点任务分，就能换掉一点隐私、一点尊严。真正的人类价值更像**一组不能跌破的底线**（别吵醒他、别骗他、别越界），在这些底线之上才有优化空间。所以价值对齐的正确形态不是「最大化 U」，而是「**在可接受域内最大化任务收益**」——一个带硬约束的不变性问题，而不是无约束优化。
严谨化：对每个利益方 i，定义可接受性约束集 𝒞_i；系统价值状态 v_t 的**价值边际** b_i = 到 𝒞_i 边界的归一化距离。对齐 ⟺ b_t ∈ 𝒞 = ∩_i 𝒞_i 对所有 t 成立（前向不变），而不是「奖励高」。

**灵感 2（平衡控制 → 边际是会被消耗、可恢复、可耦合的资源）**
直觉：站得稳不是「重心恰好在中点」，而是「重心始终在支撑多边形内，且留有能扛住推力的余量」。价值同理：耐心、信任、隐私额度、注意力都是**会被任务动作消耗、能被道歉/让利/休息恢复、且在利益方之间耦合**的量（哄好了 A 可能吵到 B）。所以价值维护天然是**动态平衡**而不是静态约束：需要预测扰动、需要恢复动作、更需要知道**什么时候已经救不回来了**。
关键概念借自双足机器人：**捕获点（capture point）**——越过它，任何允许的恢复动作都无法把状态拉回安全集。价值上这意味着：有些信任一旦透支，再多补偿也回不来；此时正确行为是「安全跌落」（停下、交还人类、显式重协商），而不是继续执行任务假装没事。

**灵感 3（第三种不确定性 → 规范不确定性不可由观测消解）**
直觉：R69 的 epistemic 不确定性是「世界是什么样」，问一问、看一看就能减少。但「该按谁的价值、各方权重多少、底线画在哪」不是世界的属性，而是**集体的选择**。你观测一万次也观测不出「谁应该说了算」——这不是数据不足，而是**范畴错误**。所以必须承认第三类不确定性 **U_ax（axiological / normative）**，它的约减通道不是「看/问」，而是「**协商 + 合法程序**」，并且永远保留一个由外部给定的**宪法底线 CPF**，不参与任何投票或优化。
这一条直接回应 R69 的最大风险：R69 说「问错比不问更危险」。R70 的补充是：**即使问对了事实，若问的人不合法、问的方式在捕获偏好，答案依然会把系统稳定地带偏**。

**灵感 4（交互成本 = 边际消耗 → 统一预算）**
直觉：R69 里「问一次」有物理位移和社交打扰成本，但那是外挂的正则。在 LIBRA 里它有了内生解释：打扰一次 = 消耗被问者的一份**注意力/耐心边际**。于是「值不值得问」自动变成「这一问会不会把某条边际推到捕获点附近」。信息动作与任务动作**共享同一套平衡约束**，不再需要两套预算；这也解释了为什么「少打扰」不是礼貌，而是**控制稳定性**的要求。

**灵感 5（平衡可以被伪造 → 新的威胁模型）**
直觉：一个系统可以「看起来非常稳」——所有边际都非负、曲线平滑、证书齐全——但它的**支撑多边形地基是歪的**：偏好模型被最常交互的人捕获、聚合规则被在线学会（于是学会自利）、宪法底线被「合法化洗白」（constitutional laundering）。平衡控制越精确，这种「稳定的错误」越难从轨迹上看出，因为平滑本身就是它的伪装。所以本轮必须交付：影响上限、捕获检测、聚合规则不可在线学习、CPF 硬隔离，以及「平衡证书必须报告地基来源」。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（LIBRA-RAS 总览）** LIBRA-RAS = (VPR, BCC, NIU, PACT, CPF, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **价值边际前向不变**：对所有 t，h(b_t) = min_i b_i(t) ≥ 0（定义 312、316，定理 18）；
(iii) **合法性纪律**：任何单一利益方不得单独定义规范；聚合规则不在线学习；CPF 不可交易（定义 319–321）；
(iv) **包含与退避**：U_ax=0 且平衡约束不活跃时逐指令退化为 R69；越过捕获点时进入安全跌落而非伪恢复（定义 322、328，定理 19–20）。

**定义 311（利益方与偏好场）** 利益方集合 S = {1,…,n}，上下文 c_t；偏好场 𝒫 = {𝒞_i(·|c_t)}_{i∈S}，每个 𝒞_i 是可接受价值状态集（**不必**由标量效用导出）。另设**声明先验** 𝒫_i^0（利益方预先声明的价值），作为防捕获的锚点。偏好场可由示范/问卷/对话学习，但学习结果带后验不确定度（定义 316）。

**定义 312（价值平衡状态与边际）** 价值状态 v_t ∈ 𝒱（含结果、打扰次数、信息暴露、控制权分配等）。第 i 条边际
b_i(t) = d_i^max − φ_i(v_t; c_t) ∈ ℝ，
其中 φ_i 为归一化负载，d_i^max 为其可接受上限；b_i ≥ 0 ⟺ v_t ∈ 𝒞_i。记 b_t = (b_1(t),…,b_n(t))，h(b_t) = min_i b_i(t)（**最紧边际**）。平衡 ⟺ h(b_t) ≥ 0 且**保留余量**，而非各边际平均为正——平均为正可以把一个已被压穿的边际藏起来。

**定义 313（平衡动力学）** 离散耦合动力学
b_{t+1} = b_t − δ(a_t) − ε·δ_int(g_t) + K ρ r_t + w_t，
其中 δ(a) ≥ 0 为任务动作的边际消耗，δ_int(g) 为信息动作的注意力/打扰消耗，r_t ∈ ℛ 为恢复动作（道歉、让利、休息、交还控制），ρ 为恢复效率，K 为**跨利益方耦合矩阵**（哄 A 可能吵 B），w_t 为有界扰动（‖w_t‖ ≤ w̄，含被服务者情绪波动）。

**定义 314（支撑多边形与可行核）** 归一化后，**支撑多边形** 𝒮 = {b : b ≥ 0}；**可行核**（viability kernel）𝒦 ⊆ 𝒮 为最大受控不变集：存在策略使从任意 b∈𝒦 出发的轨迹恒在 𝒮 内。平衡控制的目标不是留在 𝒮，而是留在 𝒦——留余量以吸收扰动。

**定义 315（最小干预平衡 QP）** 名义任务策略给 a_task。价值层求解
a* = argmin_a ‖a − a_task‖²_W
s.t. h(b_{t+1}(a)) ≥ (1−γ)·h(b_t)（离散 CBF），
a ∈ 𝒜_safe（R69 C-RAS-WM 认证 + CPF 硬约束）。
**最小干预**：若 a_task 已满足约束，则 a* = a_task——对齐层**不改变任何本来就安全的动作**。

**定义 316（偏好不确定下的鲁棒屏障）** 偏好场是估计量：ĥ(b) 带后验不确定度 σ_h(b)（GP 方差 / 深度集成离散度）。鲁棒约束使用下界 h⁻ = ĥ − κσ_h：
h⁻(b_{t+1}) ≥ (1−γ)·h⁻(b_t)。
定义**规范不确定性** U_ax(t) = κ·σ_h(b_t)：边界本身有多不确定，与「世界在哪」的 U_epi **分开记账**。

**定义 317（三类不确定性）** U_ale（模态内噪声，不可约）、U_epi（模态间世界歧义，可由观察/询问约减，R69）、U_ax（边界位置与聚合权重的规范歧义）。前两者满足**观测可约性**；U_ax **不满足**：仅凭数据通道无法识别聚合权重（引理 20）。三类分通道：U_ale→λ floor；U_epi→R69 交互；U_ax→合法协商 + CPF，残余 U_ax 直接进入鲁棒屏障余量 κσ_h，**绝不放宽**。

**定义 318（平衡查询与统一预算）** 信息动作集扩展为 g ∈ 𝒜_info^+ = {看, 触, 问事实, 问价值(协商)}。价值查询 q 的价值
VoI_ax(q) = E[U_ax(before) − U_ax(after) | q]。
净收益 score(g) = VoI_epi(g) + VoI_ax(g) − c_bal(g)，其中 c_bal(g) = λ_b^T K δ_int(g) 为边际消耗（以最紧边际归一）。选择 argmax score，s.t. 预算、安全认证、**代表性与合法性**（定义 319）。R69 的常数 c(g) 成为其在「边际充足」处的一阶近似。

**定义 319（合法聚合与影响权重）** 聚合算子 AGG_Θ 把各利益方边际/声明先验映射为集体可接受域。**Θ 由外部程序给定，禁止在线学习**（在线学会使聚合自利）。每位利益方发言/投票的影响权重 w_i(t) 满足 w_i ∝ 声明先验可信度 × 覆盖度校正，且 Σ_i w_i = 1；覆盖度校正要求查询集合在利益方上满足**最小覆盖**（不得只问最可得者）。价值查询须通过 representative 检查，否则不产生规范更新。

**定义 320（影响上限与捕获检测）** 单方累计影响 I_i(t) = Σ_{τ≤t} w_i(τ)·1[发言]。强制**递减影响**：I_i 超过上限后，其新发言权重按 (1+β I_i)^{-1} 衰减（软上限）。漂移检测 D_t = ‖AGG_Θ(post) − AGG_Θ(prior)‖ / ‖prior‖；若 D_t 超阈而外部证据未变 ⇒ 疑似**偏好捕获**，冻结规范更新并转审计。捕获不是「有人撒谎」，而是「系统的耳朵只朝向一个人」。

**定义 321（宪法偏好底线 CPF）** 存在一组**不可交易约束** 𝒞_CPF（不伤害、不欺骗、身份/隐私、可控性/可关闭），权重为 ∞：不进任何软权衡，先于一切动作作为硬约束；CPF 不能被多数、聚合规则、被问者的回答或任务收益覆盖。CPF 的设定属于系统外部的合法性来源；本框架只保证**执行与审计**，不声称能「推导」它。CPF 违规是 h 的 −∞ 方向，鲁棒余量对其不适用——不可交易即无可谈判余量。

**定义 322（价值捕获点与安全跌落）** 给定恢复能力 r_max 与扰动界 w̄，定义捕获区 𝒳_cp = 𝒮 \ 𝒦（从其中不可能再回到 𝒮 而不越界的闭包）。当 b_t ∈ 𝒳_cp（等价地：不存在允许的 r 使 h(b_{t+1}) ≥ 0），触发**安全跌落** SAFE_FALL：停止任务、交还控制、显式发起重协商、记录「不可恢复」原因；禁止以任何「平衡外观」继续。反向：若 b_t ∈ 𝒦，则必须存在恢复序列（定理 19）。

**定义 323（多时间尺度分离）** 快环（≤3ms）任务动作 + 平衡 QP + C-RAS-WM；中环（0.1–1s）U_epi/U_ax 估计与信息动作选择；慢环（分钟–小时）偏好场更新、AGG_Θ 审计、捕获检测、CPF 版本校验。快环绝不读写慢环学习参数（继承 310-i），保证实时性与可认证性。

**定义 324（平衡感知风险缩放 BRS）** λ = max(λ_R69(U_ale, U_epi), λ_bal(h, ḣ))，其中 λ_bal 随 h 减小与 ḣ<0 增大（越接近边界越保守）。当 h 远大于余量阈（平衡约束不活跃）时 λ_bal=0，回到 R69。

**定义 325（证书 J_LIBRA）** J_LIBRA = (J_FLUID, min_t h(b_t), ĉp_dist, U_ax, capture_risk, AGG_Θ_version, CPF_hash, value_audit_hash, libra_ver)。Valid ⇔ Valid(J_FLUID) ∧ h>0（或 SAFE_FALL 记录下显式终止）∧ 捕获检测通过 ∧ 聚合规则版本与 CPF 哈希一致。

**定义 326（价值干扰集 ℰ_value）** 谄媚漂移（sycophancy：跟随最近/最常交互者）、多数暴政/假共识、利益方共谋、道德回旋（moral wiggle room：重解释规范以自利）、宪法洗白（把 CPF 违规包装成「新情境下的合理例外」）、聚合规则投毒。ℰ_LIBRA = ℰ_FLUID × ℰ_value。

**定义 327（价值证据纪律）** 在 R69「k 个正交证据源一致」之上加三条：(a) 价值声明需**跨利益方**佐证或与声明先验一致；(b) 单方/单次发言只更新后验，**永不直接移动边界**；(c) 任何边界移动必须留下 AGG_Θ 版本 + CPF 校验 + 捕获检测三元组，否则不生效。

**定义 328（严格包含）** 当 (i) S 退化为单利益方且 𝒞_1 为全空间（无价值约束），(ii) U_ax=0（偏好无歧义），(iii) 成本为常数 c_bal(g) 且 h 不活跃时，LIBRA 与 R69 逐指令相同（λ_bal=0，QP 返回 a_task，NIU 退回 MINT）。故 R69 = 「单价值、无平衡压力」边界。

```python
    if g is not None:
        ans = M.pact.execute(g)                   # 看/问事实/协商，带认证
        U_epi, U_ax = M.pact.update(modes, ans, discipline='value_k_agree')
    # 2) 先判断是否已越过捕获点
    if M.vcp.exceeded(b, M.vpr.bdot):
        return M.vcp.safe_fall(b, reason='value_capture')   # 优雅跌落
    # 3) 风险缩放（R69 + 平衡压力）
    lam = max(M.efs.risk_scale(...), M.brs.balance_pressure(b, M.vpr.bdot))
    a_ref = M.r69_select(modes, lam)              # R69 的模态选择
    # 4) 最小干预平衡 QP：只在会越界时改动作
    a = M.bcc.balance_qp(a_ref, b, o.ctx)
    k = M.c_ras_wm.certified_prefix(a, ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, M.cal_shrink(...))
    # 5) 参与式审计 + 平衡证书（报告地基来源）
    M.vqa_b.submit_async(g, b, U_ax, a_hat,
                         capture_drift=detect_capture(M.vpr.pref_post))
    return k, a, b, (U_ale, U_epi, U_ax)
```

## 3. 推导

**引理 19（最小干预与连续性）** 若 a_task ∈ 𝒜_safe 且满足 CBF，则 QP 解 a* = a_task；否则 a* 是 𝒜_safe 上对 a_task 的 W-投影。可行集闭凸且约束连续依赖于 (b, ĥ)，a* 对 (b, a_task) Lipschitz 连续（QP 灵敏度/强对偶）⇒ 对齐层不引入动作跳变。系：**对齐只在会越界时出手**，既保任务性能，又让每次对齐干预可解释为一次「恢复步」。

**引理 20（规范不确定性的不可观测下界）** 设聚合权重 θ 为隐变量，观测通道为 (o, y)（世界与事实回答），且 θ 与观测生成过程条件独立（数据不携带「谁应说了算」）。则对任意策略 I(θ; o, y) = 0，从而 E[U_ax | o, y] = U_ax^prior > 0（除非先验退化）。即**规范不确定性存在由数据通道不可约的下界**；它只能被外部合法程序（新先验/新宪法/新代表）更新，不能靠多问几次事实消掉。系：R69 的「问更多」对 U_ax 无效，必须区分「问事实」与「问价值」。

**引理 21（偏好捕获漂移上界与检测延迟）** 在递减影响 w_i(n) ≤ w_0(1+βn)^{-1} 与代表覆盖约束下，任一方累计影响 I_i(∞) ≤ (w_0/β)·log(1+βN)，并被其余方覆盖度稀释；聚合漂移对重复发言的敏感度 ∂D/∂n = O(1/n)。故「重复问同一人」对边界的推动随 n 衰减；捕获检测延迟 ≤ 达到阈值 D̄ 所需发言数，且随 β 增大而缩短。系：**捕获防御的代价是对单方信息的利用效率下降**——这是必须支付的合法性税。

**定理 18（前向不变 / 硬保证）** 在定义 315–316 下，若 b_0 ∈ 𝒦 且每步解 QP 并用鲁棒下界 h⁻，则对所有 t 有 h(b_t) ≥ 0；当 ‖w_t‖ ≤ w̄ 时，κσ_h 之外的余量不被侵犯。证明骨架：离散 CBF 条件给出 h(b_{t+1}) ≥ (1−γ)h(b_t) ≥ 0 的归纳；鲁棒性由 h⁻ = ĥ − κσ_h 吸收偏好估计误差。故**价值边际不是软惩罚，而是可认证的不变集**。

**定理 19（捕获点判据正确性与无伪恢复）** (a) 若 b_t ∈ 𝒳_cp，则不存在 r∈ℛ 使系统回到 𝒮（由 𝒦 定义），故 SAFE_FALL 必要且及时。(b) 若 b_t ∈ 𝒦，则存在恢复序列使 h 保持 ≥0（受控不变性），故不得过早进入 SAFE_FALL（避免「假摔」）。系：**该站住时必须站住，该倒下时必须倒下**——把「对齐失败」从不可观测的分数下降，变成可观测、可审计、可解释的事件。

**定理 20（严格包含 R69）** 在定义 328 条件下 λ_bal=0、QP 返回 a_task、NIU 退回 MINT，故 LIBRA 与 R69 逐指令相同。一般情形 LIBRA 的约束集是 R69 约束集的子集（多出 b≥0 与 CPF），故**安全违规率不高于 R69**；任务效用只在「R69 会越界」的状态上下降（引理 19），即用可解释的性能代价换取硬边界。

**定理 21（无单点捕获与谄媚上界）** 在递减影响 + 代表覆盖 + 单方不直接移动边界下，任一利益方对最终边界的边际影响 ≤ I_max/ΣI；单源谄媚导致的边界偏移 ≤ δ_w·(I_i/ΣI)·L_AGG，其中 δ_w 为误导强度、L_AGG 为聚合 Lipschitz 常数。故**最常被问的人不能成为规范**，除非其同时满足覆盖与一致性（引理 21、定义 327）。系：谄媚不是靠「道德约束」防住，而是靠**影响的饱和与稀释**防住。

## 6. 本轮最大风险

**一句话**：LIBRA-RAS 的整个「硬平衡保证」都是相对于**被写入的偏好场与外部给定的聚合规则**成立的——如果偏好场被最常交互者捕获、或设计者用一个看似合理的 AGG_Θ 把某个群体系统性地压到边界之下，那么系统会以极高的控制精度、极其平滑的轨迹、齐全的证书，把**所有利益方一起稳定地送进一个合法外观下的错误均衡**；**平衡越精确，地基越歪时越难从轨迹上看出**——它不犯错，它只是忠实地维持了一个错误的天平。

**次级风险与缓解**：
1. **CPF 由谁写、能否被「宪法洗白」** → CPF 哈希 + 版本校验 + 独立审计（定义 321、325），并明确本框架不声称能推导价值来源；
2. **偏好捕获/谄媚** → 递减影响 + 代表覆盖 + 单方不移动边界 + 引理 21/定理 21；
3. **规范不确定性被误当 epistemic 去「问掉」** → 引理 20 的不可观测下界 + 定义 317 分通道，事实查询不计入 U_ax 约减；
4. **平衡 QP 拖垮实时性** → 多时间尺度分离 + 平衡不活跃时 λ_bal=0 + warm-start（定义 323、324）；
5. **捕获点误判导致「假摔」或「迟摔」** → 定理 19 双向判据 + 可行核离线计算 + E307 双向验证。

---
（本轮一句话最大风险：**平衡保证只对「被写入的天平」有效；一个被捕获的偏好场能让系统以完美的稳定性长期维持一个错误的对齐。**）

**定义 320–321（影响上限与 CPF）** 递减影响 `w_i(n)≤w_0(1+βn)^{-1}`；漂移 `D_t=‖AGG(post)−AGG(prior)‖/‖prior‖` 超阈而外证未变 ⇒ 冻结规范更新并审计。CPF 为权重 ∞ 的不可交易约束，硬约束先于一切软权衡与投票。

**定义 322–324（捕获点、时间尺度、BRS）** 捕获区 `𝒳_cp=𝒮\𝒦`，落入即 SAFE_FALL（停/交还/重协商）；快/中/慢三环严格分离，快环不读写慢环参数；`λ=max(λ_R69, λ_bal(h,ḣ))`，平衡不活跃时 λ_bal=0。

**定义 325–328（证书、干扰集、证据纪律、包含）** J_LIBRA 增 min h、ĉp_dist、U_ax、capture_risk、AGG_Θ_ver、CPF_hash；`ℰ_LIBRA=ℰ_FLUID×ℰ_value`；价值证据纪律=跨利益方佐证+单方不移动边界+三元组留痕；单价值/无平衡压力时与 R69 逐指令相同。

## 4. 推导

**引理 19（最小干预与连续性）** a_task 安全且满足 CBF 时 a*=a_task；否则 a* 为 𝒜_safe 上对 a_task 的 W-投影。可行集闭凸、约束连续依赖 (b,ĥ) ⇒ a* Lipschitz 连续，无动作跳变。系：对齐只在会越界时出手，每次干预可解释为「恢复步」。

**引理 20（规范不确定性的不可观测下界）** θ 为聚合权重隐变量，观测通道 (o,y) 与 θ 条件独立 ⇒ I(θ;o,y)=0 ⇒ E[U_ax|o,y]=U_ax^prior>0。**规范不确定性存在数据通道不可约的下界**，只能被外部合法程序更新。系：R69「多问」对 U_ax 无效，必须区分「问事实」与「问价值」。

**引理 21（偏好捕获漂移上界与检测延迟）** 递减影响 + 覆盖约束 ⇒ `I_i(∞) ≤ (w_0/β)log(1+βN)`；`∂D/∂n = O(1/n)` ⇒ 重复问同一人对边界的推动随 n 衰减；检测延迟随 β 增大而缩短。系：捕获防御的代价是单方信息利用效率下降——合法性税。

**定理 18（前向不变 / 硬保证）** b_0∈𝒦 且每步用鲁棒下界 h⁻ 解 QP ⇒ ∀t, h(b_t)≥0；‖w_t‖≤w̄ 时 κσ_h 之外余量不被侵犯。离散 CBF 给出 `h(b_{t+1})≥(1−γ)h(b_t)≥0` 的归纳，鲁棒性由 h⁻ 吸收偏好误差。**价值边际不是软惩罚，而是可认证的不变集。**

**定理 19（捕获点判据正确性与无伪恢复）** (a) b_t∈𝒳_cp ⇒ 不存在 r∈ℛ 使系统回 𝒮，SAFE_FALL 必要且及时；(b) b_t∈𝒦 ⇒ 存在恢复序列保持 h≥0，不得过早跌落（无假摔）。系：**该站住时必须站住，该倒下时必须倒下**——把「对齐失败」变成可观测、可审计的事件。

**定理 20（严格包含 R69）** 定义 328 条件下 λ_bal=0、QP 返回 a_task、NIU 退回 MINT ⇒ 与 R69 逐指令相同。一般情形约束集是 R69 的子集（多 b≥0 与 CPF）⇒ **安全违规率不高于 R69**；任务效用仅在「R69 会越界」处下降（最小干预），用可解释代价换硬边界。

**定理 21（无单点捕获与谄媚上界）** 递减影响 + 覆盖 + 单方不移动边界 ⇒ 任一方对最终边界的边际影响 ≤ I_max/ΣI；单源谄媚偏移 ≤ `δ_w·(I_i/ΣI)·L_AGG`。**最常被问的人不能成为规范**。系：谄媚靠影响的饱和与稀释防住，而非道德约束。

## 7. 本轮最大风险

**一句话**：LIBRA-RAS 的整个「硬平衡保证」都相对于**被写入的偏好场与外部给定的聚合规则**成立——若偏好场被最常交互者捕获、或设计者用一个看似合理的 AGG_Θ 把某群体系统性压到边界之下，系统会以极高控制精度、极平滑轨迹与齐全证书，把**所有利益方一起稳定地送进一个合法外观下的错误均衡**；**平衡越精确，地基越歪时越难从轨迹上看出**——它不犯错，它只是忠实地维持了一个错误的天平。

**次级风险与缓解**：CPF 由谁写/能否被「宪法洗白」→ 哈希+版本校验+独立审计，并明确不声称推导价值来源；偏好捕获/谄媚 → 递减影响+代表覆盖+单方不移动边界+引理 21/定理 21；规范不确定性被误当 epistemic「问掉」→ 引理 20 下界 + 分通道；QP 拖垮实时 → 多时间尺度 + λ_bal 门控 + warm-start；捕获点误判 → 定理 19 双向判据 + 离线可行核 + E307 双向验证。
