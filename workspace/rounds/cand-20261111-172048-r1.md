# 第 56 轮（承接第 55 轮 v32 Semantic-Contact；灵感循环第 2 轮；本轮灵感：「四足机器人」×「语义地图」）

> 第 55 轮把“语义标签”升级为“接触可供性”，并用全身生存核保证单次接触可信。本轮换一个物种、换一个时间尺度：四足机器人的动作不是静态接触集合，而是 **周期性接触调度（步态）**。核心矛盾：**H24**：语义地图给出的是空间标签，而四足失效发生在时间维——每个落点单独看都“可踩”，但步态的支撑模式无法在语义补丁上持续成立；**H25**：四足冗余既是风险也是资源——某条腿的语义不可用可以被另外三条腿“借时间”跨过去，但可借的时间由三足支撑耐久严格封顶，越过即塌。

## 0. 直觉与动机

**灵感 1（四足机器人 → 步态是接触的时间调度，而非动作向量）**
直觉：轮式机器人问“这条路径的代价多大”，四足机器人问的是“**哪几条腿、在什么相位、踩多深、踩多久**”。trot 是两两对角支撑、walk 常有三足支撑、bound 有腾空相；同一块地形，换一种步态就换了一套支撑多边形序列。因此语义地图若只被消费成“格子代价”，就丢掉了四足最关键的自由度：**支撑模式的时序选择**。

**灵感 2（语义地图 → 从“标签/成本图”升级为“接触可用性日历”）**
直觉：语义标签真正的含义不是“这里是什么”，而是“**这里允许以什么方式、被支撑多久**”。冰面允许接触但不允许按普通摩擦假设持续蹬地；松土允许接触但受力后会缓慢下陷（驻留时间上限）；草丛可能根本不透明（遮挡，需探测）；台阶的接触是一个边缘而不是一个点。把标签 `l` 扩展为接触动力学剖面 `D_l=(μ_l, k_l, τ_l^max, c_l^swing, h_l)`，语义地图就从空间场变成 **时空可接触日历**。

**灵感 3（四足冗余 → 三足支撑耐久是“可调度预算”）**
直觉：如果只有两条腿，一个坏落点就是硬约束；有四条腿，一个坏落点只是“这条腿暂时不承重”。机器可以让该腿提前抬起、用其余三足多撑一会儿，把身体“荡”过这段语义禁区。这个“多撑一会儿”不是无限的，它由质心/捕获点相对三足支撑多边形的漂移速度决定，记作 **语义支撑耐久** `T_end`。所以语义不可用不是“禁止通行”，而是 **一笔有限的、必须按时归还的时间预算**。

**灵感 4（支撑模式自动机 → 语义步态是一种受限语言）**
直觉：步态可以写成接触事件的符号串（抬哪条腿、落哪条腿、支撑集如何切换）。语义日历则在每一步上允许/禁止某些事件。把两者做乘积，得到 **支撑模式自动机**：它接受的语言，就是“语义上合法且支撑上可行”的步态词。于是找步态不是连续优化一个控制向量，而是 **在这门语言里找一个带资源约束的可接受串**。

**灵感 5（语义不确定性 → 边界、驻留、遮挡三种失效，鲁棒性谱下沉到调度层）**
直觉：第 55 轮把不确定性集中在标签边界；对四足还要多两类：**驻留不确定性**（松土“能站多久”比“能不能站”更不确定）与 **遮挡不确定性**（草/水下的真实支撑未知）。更关键的是：这些不确定性会改变 **可行性本身**——同一条步态词在所有点标签都不变的情况下，可能仅因某个材质的驻留上限被下调而从可行变不可行。因此鲁棒性谱必须定义在 **步态词集合** 上，而不是逐点可行性上。

## 1. 形式化定义（增量：定义 127–133）

**定义 127（语义接触日历）**
语义图 `Σ: Ω → Δ(L)`；每个标签 `l` 带接触动力学剖面 `D_l=(μ_l,k_l,τ_l^{max},c_l^{swing},h_l)`。日历
`A: Ω × ℝ_{≥0} → {support, no-support, probe} × [0,1] × ℝ_{≥0}`，
`A(p,t)=(mode,conf,τ_remaining)`。`mode=support` 当且仅当 `conf(Σ(p))≥θ_conf` 且 `D_{Σ̄(p)}` 可支撑且该点未被判为遮挡/空洞；对 `no-support` 区域做保守膨胀 `Ω_no^+ = Ω_no ⊕ B(ε_s)`。驻留预算按支撑期累计：`dwell_i(t)=∫ c_i(s)·1[A(p_i,s).mode=support] ds`。

**定义 128（步态词 / 接触调度）**
在视界 `T` 内，步态词
`σ = {(i, p_i, t_i^{st}, t_i^{sw})}_{i=1..N}`，`i∈{FL,FR,RL,RR}`，
接触信号 `c_i(t)=1_{t∈[t_i^{st},t_i^{sw})}`。支撑集 `S(t)={i: c_i(t)=1}`，支撑多边形 `P(t)=conv{p_i(t): i∈S(t)}` 在水平面的投影。`σ` 需满足步态库 `G` 的相位/占空比/步长约束，记 `σ∈L(G)`。

**定义 129（支撑模式自动机）**
`𝒜_Σ = (Q, q_0, →_Σ, F)`，状态 `q=(phase, S, {cell_i}, {dwell_i}, t)`，迁移对应一次“抬腿/落腿”事件。迁移 `q→_Σ q'` 允许当且仅当：落点 `p'` 在 `t'` 时刻 `A(p',t').mode=support` 且 `dwell` 不超 `τ^{max}`；新支撑集 `S'` 的支撑裕度 `m(q')≥θ_m`；且 `q'` 满足 `L(G)` 的相位约束。`F` 为完成视界且全程满足可行性的状态集。`σ` 可行当且仅当 `𝒜_Σ` 中存在从 `q_0` 到 `F` 的接受路径。

**定义 130（语义支撑耐久）**
给定三足支撑集 `S`（`|S|=3`）与状态 `x=(ξ,ξ̇)`（质心位置/速度），
`T_end(x,S) = sup{τ≥0 | ∃ 质心轨迹 ξ(·): ξ(0)=ξ, ξ̇(0)=ξ̇, ξ_cp(t)∈P(S), |ξ̈|≤μ g, 关节/摩擦约束满足, ∀t∈[0,τ]}`，
其中 `ξ_cp=ξ+ξ̇/ω` 为捕获点。实际计算用保守下界 `T̄_end(x,S) ≤ T_end`，保证证书 sound。若全程四足支撑，`T_end` 不作为约束；出现连续三足区间时，其持续时间必须 `≤ T̄_end`。

**定义 131（语义步态可行性）**
`σ` 在 `(Σ,x_0,θ_m,θ_T)` 下可行，当且仅当：
1. **语义合法**：每个支撑事件 `(i,p_i,t)` 满足 `A(p_i,t).mode=support`、`conf≥θ_conf`，且 `dwell_i(t)≤τ_{l_i}^{max}`；
2. **支撑合法**：`∀t, m(t)=dist(ξ(t),∂P(t))≥θ_m`（四足支撑），且三足期间捕获点 `ξ_cp(t)∈P(t)`；
3. **耐久合法**：每个极大三足区间 `[t_a,t_b]` 满足 `t_b-t_a ≤ T̄_end(x(t_a),S(t_a))`；
4. **步态合法**：`σ∈L(G)`。
记可行步态词集合 `𝔖(Σ,x_0)`，`viable_gait(x_0,Σ)=1 ⇔ 𝔖(Σ,x_0)≠∅`。

**定义 132（语义步态鲁棒性谱）**
`ρ_gait(ε_s,ε_D) = inf_{||Σ-Σ̂||_∞≤ε_s, ||D-D̂||≤ε_D} P( viable_gait(x_0,Σ) | Σ̂,D̂ )`。
注意这是 **调度层** 的最坏保持概率：即使逐点标签全对，只要 `τ^{max}` 被高估，`ρ_gait` 也会下降。

**定义 133（语义步态证书）**
`J_g = (σ_core, S_margin, T_slack, dwell_slack, ρ_gait, δ_s, evidence)`：
- `σ_core` 为实际使用的接触事件序列（核心步态词）；
- `S_margin = min_t m(t)`，`T_slack = min_{三足区间}(T̄_end - 持续时间)`；
- `dwell_slack = min_{支撑事件}(τ^{max}-dwell)`；
- `δ_s` 为实测语义/剖面偏差，`evidence` 含支撑多边形录波、滑移与下陷日志。
若 `S_margin≥θ_m`、`T_slack≥θ_T`、`dwell_slack≥θ_d`、`ρ_gait≥ρ_min`、`δ_s<Θ_s` 且 `σ_core` 覆盖目标位移，则 **语义步态可部署**。

## 2. 关键算法 伪代码

### IP-127 SCA（Semantic Contact Availability）

```python
def semantic_contact_calendar(rgbd, seg, D_profiles, theta_conf, eps_s):
    Sigma = seg.predict_soft(rgbd)
    A = {}
    for p in grid(Sigma):
        l = argmax(Sigma[p]); conf = calibrated_conf(Sigma[p])
        prof = D_profiles[l]
        mode = 'support' if conf >= theta_conf and prof.supportable else 'no_support'
        A[p] = Availability(mode, conf, prof.tau_max, prof.mu, prof.h)
    A = dilate_forbidden(A, eps_s)          # no_support 保守膨胀
    A = mark_occluded_unknown(A, A.ci)      # 草/水/遮挡 -> probe
    return A
```

### IP-128 SPA（Support-Pattern Automaton）

```python
def build_support_automaton(gait_lib, A, com_plan, horizon, dtau):
    Q, q0 = [], init_state(gait_lib, com_plan)
    for g in gait_lib:                       # walk / trot / pace / bound / crawl
        for phase in discretize(g, dtau):
            for q in expand(Q, phase):
                for ev in g.events(phase):   # lift(i) / place(i,p')
                    if ev.is_place and not admissible(A, ev.p, ev.t, ev.i):
                        continue
                    q2 = transition(q, ev)
                    if support_margin(q2, com_plan) < theta_m:
                        continue
                    if three_leg(q2) and not endurance_ok(q2):
                        continue
                    add_edge(Q, q, q2, cost=gait_cost(ev))
    return Automaton(Q, q0, accepting=complete_states(Q, horizon))
```

### IP-129 SEE（Semantic Endurance Envelope）

```python
def endurance_envelope(x, S3, A, mu, dtau):
    P = support_polygon(S3, A)
    xi, vi = com_state(x); omega = sqrt(g / body_height(x))
    tau = 0.0
    while True:
        cp = xi + vi / omega
        if not point_in_polygon(cp, P, margin=0):
            return max(tau, 0.0)             # 保守下界
        if friction_workspace_violated(xi, vi, P, mu):
            return tau
        xi, vi, tau = integrate_worst_case(xi, vi, P, mu, dtau), tau + dtau
```

### IP-130 SGP（Semantic Gait Planner）

```python
def semantic_gait_plan(A, x0, goal, gait_lib, budgets):
    com_plan = com_trajectory_candidates(x0, goal)
    autom = build_support_automaton(gait_lib, A, com_plan, budgets.horizon, budgets.dtau)
    path = resource_search(                 # 资源：耐久时钟 + 驻留余量 + 相位
        autom, start=com_plan, goal=goal,
        cost=lambda e: w1*energy(e)+w2*gait_switch(e)+w3*dev(e)+w4*(1-slack(e)),
        prune=lambda q: not feasible_resources(q, budgets))
    if path is None:
        return ('reject', 'no_semantic_gait', autom.explain_infeasible(goal))
    return ('ok', extract_schedule(path))
```

### IP-131 SGS（Semantic Gait Shield）

```python
def semantic_gait_shield(sigma_nom, x, A_online, budgets):
    if schedule_feasible(sigma_nom, x, A_online, budgets):
        return execute(sigma_nom)
    # 局部步态变形：提高占空比、降低身高、缩短步长、延后抬腿
    for morph in gait_morphisms(sigma_nom, budgets):
        sigma = local_repair(sigma_nom, morph, A_online)
        if sigma and min_support_margin(sigma) >= budgets.theta_m \
           and endurance_slack(sigma, x) >= 0:
            return execute(sigma)
    return static_crawl_or_freeze(x)        # 兜底：四足/三足静态支撑
```

### IP-132 SGC（Semantic Gait Certificate）

```python
def semantic_gait_certificate(sigma, A, rho_gait, budgets):
    sigma_core = [(i,p,t_st,t_sw) for (i,p,t_st,t_sw) in sigma if stance_loaded(i)]
    S_margin = min(support_margin(sigma, t) for t in sigma.times)
    T_slack = min_endurance_slack(sigma, A)
    dwell_slack = min(A[p].tau_max - dwell(sigma, i, p) for (i,p,_,_) in sigma)
    delta_s = semantic_discrepancy(sigma_core, A)
    if S_margin < budgets.theta_m or T_slack < budgets.theta_T \
       or dwell_slack < budgets.theta_d:
        return ('reject', 'gait_budget_exceeded', S_margin, T_slack, dwell_slack)
    if rho_gait(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_gait_robustness_fail')
    return ('ok', GaitCert(sigma_core, S_margin, T_slack, dwell_slack, rho_gait, delta_s))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SCA | O(|Ω|·(|L|+|C|)) | O(|Ω|) | 置信校准、禁行区保守膨胀、驻留上限 sound |
| SPA | O(|G|·|Q|·b) | O(|Q|+|E|) | 自动机不过近似（无假接受），相位/占空约束完备 |
| SEE | O(1/dtau·poly) | O(1) | `T̄_end` 为真实耐久的下界（保守） |
| SGP | O(|Q| log|Q| + |E|) | O(|Q|) | 资源剪枝 sound、代价单调、可行才接受 |
| SGS | O(|σ|·|morph|) | O(|σ|) | 变形保持支撑不变量、兜底静态支撑 |
| SGC | O(|σ|·|Ω|) | O(|Ω|) | `δ_s` 闭合、四类 slack 同时满足 |

**正确性定理（Semantic Gait Soundness）**
假设第 55 轮 (A29)–(A32) 成立；并新增：
**(A33)** 语义日历经材质分层校准，`P(A` 将不可支撑判为 support`) ≤ ε_A`，且 `τ^{max}` 为真实驻留的上界；
**(A34)** 耐久包络为保守下界 `T̄_end ≤ T_end`；
**(A35)** 支撑自动机对动力学可行集是保守过近似（接受即物理可行，无假接受）；
**(A36)** 语义/剖面扰动 `||Σ-Σ̂||_∞≤ε_s`、`||D-D̂||≤ε_D`，护盾在不可行时回退到静态支撑 `u_stop∈𝒳_safe`。
则单次任务不发生“支撑塌陷”的概率：
```
P_safe ≥ 1 - P(ε_A 失效) - P(T̄_end 高估) - P(自动机假接受)
        - P(||Σ-Σ̂||>ε_s ∨ ||D-D̂||>ε_D) - P(盾回退失败)
```
关键：**语义日历只授权“事件”，不授权“格点”；支撑自动机只把“事件序列”变成“可行性”；耐久包络只借“有上限的时间”**。三者任一失守，都不允许把“每一点都可踩”当成“这套步态可持续”。

## 6. 本轮最大风险

**一句话**：语义步态框架把一个漂亮的“可踩”标签升级为“可持续的步态词”，但其 soundness **三层嵌套近似**——语义日历（标签能否预测驻留/摩擦）、耐久包络（三足到底能撑多久）、支撑自动机（接受的调度是否真可行）；一旦日历把松土/湿滑的驻留上限估高、或耐久包络偏乐观，规划器会“合法地”把一条腿按计划借出去跨语义禁区，而身体在证书内部自洽的情况下越过三足支撑边界——这不是感知错，而是 **把时间预算当成了无限额度**；因此必须以 **禁行区保守膨胀 + 耐久保守下界 + 在线滑移/下陷杀伤开关** 三重护栏，宁可多走一步 crawl，也绝不把“单点可踩”外推成“整段步态可持续”。

# 第 56 轮产物 · 创新点清单 v33：GroundGait-GenSim（SCA×SPA×SEE×SGP×SGS×SGC）

> 承接 v32 Semantic-Contact（第 55 轮，IP-121~126）与 v31 GroundEdge-GenSim+++（第 54 轮，IP-115~120）。本轮把“接触是否可信”推进为 **“接触事件的时间序列是否可持续”**：四足机器人真正消费语义地图的方式不是逐格选落点，而是选择一条 **被语义日历授权的支撑模式调度（步态词）**。
>
> - **SCA（Semantic Contact Availability）**：把语义标签扩展为带摩擦/刚度/驻留上限的 **语义接触日历**；
> - **SPA（Support-Pattern Automaton）**：步态相位自动机 × 语义日历的乘积自动机，接受“语义合法 + 支撑可行”的步态词；
> - **SEE（Semantic Endurance Envelope）**：三足支撑的 **语义耐久包络**，把“某条腿暂时不可用”变成有时间上限的可调度预算；

## 1. 符号体系增量（新增定义 127–133）

| 符号 | 含义 |
|---|---|
| `Σ: Ω→Δ(L)` | 语义图（标签分布） |
| `D_l=(μ_l,k_l,τ_l^{max},c_l^{swing},h_l)` | 标签 `l` 的接触动力学剖面（摩擦/刚度/驻留/抬脚间隙/风险） |
| `A(p,t)=(mode,conf,τ_remaining)` | 语义接触日历；`mode∈{support,no-support,probe}` |
| `σ={(i,p_i,t_i^{st},t_i^{sw})}` | 步态词（接触调度） |
| `S(t)={i:c_i(t)=1}` | `t` 时刻支撑集；`P(t)=conv{p_i(t)}` 支撑多边形 |
| `m(t)=dist(ξ(t),∂P(t))` | 支撑裕度；`ξ_cp=ξ+ξ̇/ω` 捕获点 |
| `T_end(x,S)` / `T̄_end` | 三足支撑真实耐久 / 保守下界 |
| `𝒜_Σ=(Q,q_0,→_Σ,F)` | 支撑模式自动机 |
| `𝔖(Σ,x_0)` | 可行步态词集合 |
| `ρ_gait(ε_s,ε_D)` | 调度层语义鲁棒性谱 |
| `J_g=(σ_core,S_margin,T_slack,dwell_slack,ρ_gait,δ_s,evidence)` | 语义步态证书 |

**定义 127（语义接触日历）** `A(p,t)=(mode,conf,τ_remaining)`，`mode=support ⇔ conf(Σ(p))≥θ_conf ∧ D_{Σ̄(p)}` 可支撑且非遮挡；`no-support` 区做 `Ω_no⊕B(ε_s)` 保守膨胀；`dwell_i(t)=∫c_i(s)1[A(p_i,s).mode=support]ds`。

**定义 128（步态词）** `σ={(i,p_i,t_i^{st},t_i^{sw})}`，`c_i(t)=1_{[t_i^{st},t_i^{sw})}`，`σ∈L(G)`（相位/占空比/步长约束）。

**定义 129（支撑模式自动机）** `q=(phase,S,{cell_i},{dwell_i},t)`；迁移为抬/落腿事件，允许当且仅当落点当时 `support`、`dwell≤τ^{max}`、新支撑裕度 `≥θ_m`、相位合法；`σ` 可行 ⇔ `𝒜_Σ` 有接受路径。

**定义 130（语义支撑耐久）** `T_end(x,S)=sup{τ | ∃ξ(·): ξ(0)=ξ, ξ̇(0)=ξ̇, ξ_cp(t)∈P(S), |ξ̈|≤μg, ∀t≤τ}`；实现用 `T̄_end≤T_end`。

**定义 131（语义步态可行性）** 同时满足：语义合法（事件级 `support`+驻留）、支撑合法（`m≥θ_m` 且三足期 `ξ_cp∈P`）、耐久合法（三足区间时长 `≤T̄_end`）、步态合法（`σ∈L(G)`）。记 `viable_gait(x_0,Σ)=1⇔𝔖(Σ,x_0)≠∅`。

**定义 132（语义步态鲁棒性谱）** `ρ_gait(ε_s,ε_D)=inf_{||Σ-Σ̂||≤ε_s,||D-D̂||≤ε_D}P(viable_gait(x_0,Σ)|Σ̂,D̂)`。注意其可因 `τ^{max}` 被高估而下降，即使逐点标签不变。

**定义 133（语义步态证书）** `J_g=(σ_core,S_margin,T_slack,dwell_slack,ρ_gait,δ_s,evidence)`；`S_margin=min_t m(t)`，`T_slack=min(T̄_end-三足时长)`，`dwell_slack=min(τ^{max}-dwell)`。四类 slack 与 `ρ_gait` 同时达标方可部署。

### IP-127 SCA

```python
def semantic_contact_calendar(rgbd, seg, D_profiles, theta_conf, eps_s):
    Sigma = seg.predict_soft(rgbd)
    A = {}
    for p in grid(Sigma):
        l = argmax(Sigma[p]); conf = calibrated_conf(Sigma[p])
        prof = D_profiles[l]
        mode = 'support' if conf >= theta_conf and prof.supportable else 'no_support'
        A[p] = Availability(mode, conf, prof.tau_max, prof.mu, prof.h)
    A = dilate_forbidden(A, eps_s)
    A = mark_occluded_unknown(A, A.ci)
    return A
```

### IP-128 SPA

```python
def build_support_automaton(gait_lib, A, com_plan, horizon, dtau):
    Q, q0 = [], init_state(gait_lib, com_plan)
    for g in gait_lib:                       # walk / trot / pace / bound / crawl
        for phase in discretize(g, dtau):
            for q in expand(Q, phase):
                for ev in g.events(phase):
                    if ev.is_place and not admissible(A, ev.p, ev.t, ev.i):
                        continue
                    q2 = transition(q, ev)
                    if support_margin(q2, com_plan) < theta_m: continue
                    if three_leg(q2) and not endurance_ok(q2): continue
                    add_edge(Q, q, q2, cost=gait_cost(ev))
    return Automaton(Q, q0, accepting=complete_states(Q, horizon))
```

### IP-129 SEE

```python
def endurance_envelope(x, S3, A, mu, dtau):
    P = support_polygon(S3, A); xi, vi = com_state(x)
    omega = sqrt(g / body_height(x)); tau = 0.0
    while True:
        if not point_in_polygon(xi + vi/omega, P, margin=0):
            return max(tau, 0.0)
        if friction_workspace_violated(xi, vi, P, mu):
            return tau
        xi, vi, tau = integrate_worst_case(xi, vi, P, mu, dtau), tau + dtau
```

### IP-130 SGP

```python
def semantic_gait_plan(A, x0, goal, gait_lib, budgets):
    com_plan = com_trajectory_candidates(x0, goal)
    autom = build_support_automaton(gait_lib, A, com_plan, budgets.horizon, budgets.dtau)
    path = resource_search(
        autom, start=com_plan, goal=goal,
        cost=lambda e: w1*energy(e)+w2*gait_switch(e)+w3*dev(e)+w4*(1-slack(e)),
        prune=lambda q: not feasible_resources(q, budgets))
    if path is None:
        return ('reject', 'no_semantic_gait', autom.explain_infeasible(goal))
    return ('ok', extract_schedule(path))
```

### IP-131 SGS

```python
def semantic_gait_shield(sigma_nom, x, A_online, budgets):
    if schedule_feasible(sigma_nom, x, A_online, budgets):
        return execute(sigma_nom)
    for morph in gait_morphisms(sigma_nom, budgets):   # 占空比/身高/步长/抬腿时序
        sigma = local_repair(sigma_nom, morph, A_online)
        if sigma and min_support_margin(sigma) >= budgets.theta_m \
           and endurance_slack(sigma, x) >= 0:
            return execute(sigma)
    return static_crawl_or_freeze(x)
```

### IP-132 SGC

```python
def semantic_gait_certificate(sigma, A, rho_gait, budgets):
    sigma_core = [(i,p,ts,tw) for (i,p,ts,tw) in sigma if stance_loaded(i)]
    S_margin = min(support_margin(sigma, t) for t in sigma.times)
    T_slack = min_endurance_slack(sigma, A)
    dwell_slack = min(A[p].tau_max - dwell(sigma, i, p) for (i,p,_,_) in sigma)
    delta_s = semantic_discrepancy(sigma_core, A)
    if S_margin < budgets.theta_m or T_slack < budgets.theta_T \
       or dwell_slack < budgets.theta_d:
        return ('reject', 'gait_budget_exceeded', S_margin, T_slack, dwell_slack)
    if rho_gait(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_gait_robustness_fail')
    return ('ok', GaitCert(sigma_core, S_margin, T_slack, dwell_slack, rho_gait, delta_s))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCA | O(|Ω|·(|L|+|C|)) | O(|Ω|) | 校准 sound、禁行保守膨胀、驻留上界 |
| SPA | O(|G|·|Q|·b) | O(|Q|+|E|) | 无假接受、相位约束完备 |
| SEE | O(1/dtau·poly) | O(1) | `T̄_end` 为真实耐久下界 |
| SGP | O(|Q|log|Q|+|E|) | O(|Q|) | 资源剪枝 sound、代价单调 |
| SGS | O(|σ|·|morph|) | O(|σ|) | 变形保持支撑不变量 + 静态兜底 |
| SGC | O(|σ|·|Ω|) | O(|Ω|) | 四类 slack 与 `ρ_gait` 联立 |

**正确性定理（Semantic Gait Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 语义日历材质分层校准，`P(`不可支撑被误判为 support`)≤ε_A`，`τ^{max}` 为真实驻留上界；**(A34)** `T̄_end≤T_end`（保守下界）；**(A35)** 支撑自动机对动力学可行集是保守过近似（无假接受）；**(A36)** `||Σ-Σ̂||_∞≤ε_s`、`||D-D̂||≤ε_D`，护盾不可行时回退静态支撑 `u_stop∈𝒳_safe`。则
```
P_safe ≥ 1 - P(ε_A 失效) - P(T̄_end 高估) - P(自动机假接受)
        - P(||Σ-Σ̂||>ε_s ∨ ||D-D̂||>ε_D) - P(盾回退失败)
```
关键：**日历授权事件、自动机授权序列、耐久授权时间**；三者缺一，不能把“逐点可踩”当作“整段步态可持续”。

## 6. 本轮最大风险

**一句话**：语义步态把“可踩”升级为“可持续”，但其 soundness **三层嵌套近似**——语义日历（标签能否预测驻留/摩擦）、耐久包络（三足能撑多久）、支撑自动机（接受调度是否真可行）；一旦松土/湿滑的驻留上限被估高、或耐久包络偏乐观，规划器会按证书“合法地”把一条腿借出去跨语义禁区，而身体在证书内部自洽时越过三足支撑边界——这不是感知错，而是 **把有限的时间预算误当成无限额度**；故必须以 **禁行区保守膨胀 + 耐久保守下界 + 在线滑移/下陷杀伤开关** 三重护栏，宁可多走一步 crawl，绝不把“单点可踩”外推成“整段步态可持续”。
