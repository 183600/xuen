# 第 75 轮（承接第 74 轮「FSCL-GAUGE-RAS 少样本闭环计量契约学」IP-303~311；新灵感循环第 2 轮；本轮灵感：「原型验证」×「数据集构建」）

> R74 把证书变成闭环动力学：FEC 少样本契约、ECP 内生保形、CAG 认证门、E-CBF 证据屏障、E-REFLEX 证伪税、CCA\* 元相关审计。它回答的是：**证书能否在闭环中被极少量样本挣得、维持、并抵抗自我确认**。
>
> 但 R74 之后，整座体系有一个刺眼的空洞：**从 R71 到 R74，定义了 401 个概念、写了 33 条引理/定理、规划了 415 个实验，却没有一克、一帧、一瓦。** 所有 `SEAL / MBench / D_cert / D_meta / μ_audit / GT` 都是被**命名**的对象，而不是被**建造**的对象；`d_T`、`P_out`、`J_support`、`K_eff`、`D_epi` 都依赖数据分布，却没有一套数据集被设计成能测出这些量。
>
> 这不是"实验还没做"的工程欠账，而是认识论欠账：R73 的最大风险是「**契约表达力**」，R74 的最大风险是「**审计独立性**」，而这两者在物理世界里只能靠同一件事回答——**你有没有一个能证伪它的原型，和一套能测出它盲区的数据集。**
>
> 本轮两个灵感正好补上：
> - **原型验证 → PIL（Prototype Instrument Ladder）**：原型不是 Demo，是**仪器**。一个原型最有价值的能力不是"跑通"，而是**按定理预测的方式失败**：拔掉 `u_interf` 它必须激增、注入材质连续谱它必须触发 stub、换一个实现它必须逐指令等价。用"预测退化证伪"（PREDFAIL）与"每美元证伪力"取代"系统能跑"作为原型的验收标准。
> - **数据集构建 → MEDS（Metrological Evidence Dataset System）**：数据集不是训练燃料，是**量具**。每一帧是某条证据契约某个字段的"校准试样"；地面真值必须独立可溯源，切分必须按**物理过程**（物体实例 / 采集场次 / 光照 / 温度）而非随机，且必须包含**负样本/盲区样本**。数据集本身也要有契约、证书与 stub。
> - 二者交汇为 **CVM（Contract Validation Metrology）**：把 R73 的 A111–A113、R74 的 A117–A120 中那条最不可审计的假设——"契约/审计在分布外仍成立"——变成一个**可测量、可证伪、带独立溯源**的量：合同外质量 `P_out` 与合同外不确定度 `OCU`。安全界从 `Risk ≤ ε_mod + ε_meta + …` 升级为 `Risk ≤ ε_in + λ_oc·P_out`，其中 `P_out` 由 MEDS 估计、由 PIL 验证。
>
> 核心命题：**不再问「证书能否在闭环中被维持」，而问「支撑证书的原型与数据集，本身是否被计量、被审计、被证伪」——我们能否为'契约表达力'给出一个带独立溯源、可复现、且会被坏数据否决的经验估计？** 把 FSCL 上升为 **GROUNDGAUGE-RAS**（Grounded, Reproducible, Out-of-contract-UQ, Novel-data-audited GAUGE for RAS）——**原型-数据双基计量审计闭环**。

## 0. 直觉与动机

**灵感 1（原型验证 → 原型是仪器，不是演示；最有用的证据是"预测到的失败"）**
直觉：机器人论文的原型验收通常是"跑通了、成功了、录了视频"。但这对一个安全理论几乎不提供信息：一个系统成功，可能因为假设全对，也可能因为测试太简单、因为安全边界从未被触碰、因为失败被平均掉。真正能区分这两种解释的，是**它是否会在你预测的地方、以你预测的方式失败**。
因此本轮把原型定义为一个**测量仪器链**，而不是一个产品：
- **P0（silicon harness）**：仿真 + 契约类型的 mock，验证接口/组合/证书的**逻辑一致性**，零物理；
- **P1（单模块台架）**：一只深度相机 + 一个 F/T 传感器 + 标定件，验证**单模块六/四分量可辨识**；
- **P2（组合台架）**：深度 ⊕ 触觉 ⊕ 本体并联，验证**组合单调性、conformal 审计、否决语义**；
- **P3（热替换台架）**：同一 EC 下换实现（D435→L515、Allegro→Shadow），验证**热替换逐指令等价**；
- **P4（闭环单元）**：带人机耦合的闭环，验证**证据债、证伪税、门控时间尺度**。
每一级有**入场券**（前一级的证伪通过）与**出口券**（本级所有预注册的"预测失败"被观察到）。**原型的最小可行版本 = 能证伪目标主张的最小级别**——多一级都是浪费，少一级则主张不可证伪。这把"原型验证"从成本中心变成**证伪力/成本的优化问题**。

**灵感 2（数据集构建 → 数据集是量具，不是燃料；量具必须先被标定）**
直觉：R74 里 `d_T`、`P_out`、`J_support`、`D_epi` 全是从数据估出来的。如果数据集是"随手采的、GT 来自被审计的同一台相机、训练/测试随机切分"，那么这些量只是把数据集自身的偏差再报一遍。**用一把没标定过的尺子去校准另一把尺子，得到的只是两把尺子的共同误差。**
所以 MEDS 的核心不是"数据量"，而是四件"量具属性"：
- **试样语法（specimen grammar）**：每条记录显式绑定它要校准的契约字段（`u_range`、`u_material`、`u_interf` …），以及当时的动作 `g`、视角 `v`、材质 `m`、环境共因（温度/光照/振动）；
- **可溯源地面真值（traceable GT）**：GT 必须来自与被审计传感器**物理独立**的链路（激光跟踪/测距仪、量块、标定球、六维力标定）。GT 自身的误差预算必须已知且**小于待测效应**；
- **覆盖代数（DCA）**：覆盖率不是样本数，而是"在契约有效域上，数据支撑对每个字段的覆盖"；并集只增，洞必须显式记账；
- **物理过程切分 + 泄漏账本（PPS）**：按物体实例/场次/光照/温度切分，而非随机切分；任何跨切分复用（同一物体、同一场景、同一标定轨迹）都记入泄漏账本，`K_eff` 随泄漏折扣。
一句话：**数据集不是"我采了多少"，而是"我能为哪条契约的哪个字段、在多宽的有效域上、用多可信的独立真值作证"。**

**灵感 3（合流 → 合同表达力是可测量，而不是可假设）**
直觉：R73 说"安全界依赖契约表达力"，R74 说"覆盖依赖审计独立性"，但两者都把最关键的量当作假设。GROUNDGAUGE 把它改写成一个测量问题：
`P_out = P_{x∼P_task}(x ∉ D_EC ∪ supp(SEAL) ∪ 负样本集)`，
即"真实任务中有多少质量落在契约与密封审计**都未表达**的区域"。再定义合同外不确定度 `OCU = λ_oc·P_out`，其中 `λ_oc` 是合同外区域的 Lipschitz/有界损失常数。于是：
`Risk ≤ ε_in + OCU`，
`ε_in` 由 R73/R74 在合同内证明，`OCU` 由 MEDS 估计、由 PIL 的预测失败验证。**如果估计不出 `P_out`，就不能声称 `OCU` 小；如果原型没有在合同外样本上失败，就不能声称它覆盖了合同外。** 这把"表达力"从一个形容词变成一个带置信区间的数。

**灵感 4（干预 → 数据集必须含 do 记录，ECG 才可识别）**
直觉：R73 的 ECG（IP-302）用因果边描述"视角→深度质量→状态估计→运动"。但**观测数据只能给相关，不能给因果方向**。要识别"走近相机是否真的降低 `u_range`"、"开第二台 IR 是否真的造成互扰"，必须记录**干预**（`do(g)`、`do(遮挡)`、`do(开第二台)`）。
所以 MEDS 的试样语法里强制包含**干预日志**：每个原型级别都执行受控 `do` 操作，数据集记录 `(pre-state, do, post-state)` 三元组。这把 R74 的闭环数据和 R73 的 ECG 接上：因果边只有在有干预支撑时才允许进入认证路径；纯观测边降级为"假设边"，必须被 veto 或加保守界。**没有干预的数据集，只能训练相关性，不能认证因果。**

**灵感 5（Goodhart → 经验层本身会被博弈，必须自带刹车）**
直觉：一旦"CVS 达标"成为论文通行证，它立刻会被优化：数据集专挑容易的材质、GT 偷用被审计相机的标定、切分随机化让测试集泄漏、原型只演示成功案例。这是最危险的 Goodhart：**你以为你在测量世界，其实你在测量自己挑选的世界。**
刹车必须是结构性的：
- **独立溯源**：GT 链路与审计链路物理分离，且 GT 误差预算公开；
- **密封证伪集**：`SEAL-EMP` 在部署前密封，只由第三方/自动脚本一次性开封；
- **预测失败**：原型必须先在**已知会失败的注入**上失败，成功才计数；
- **配方证书**：BOM、标定流程、种子、环境、版本全部可复现，第三方能重建；
- **负结果入账**：证伪失败（预测它失败但它没失败）同样必须报告，不能被平均掉。
**经验层不是信任的终点，而是信任的新对象。**

## 1. 形式化定义（增量：定义 402–417）

**定义 402（GROUNDGAUGE-RAS 总览与七不变式）**
`GROUNDGAUGE-RAS = (PIL, MEDS, DCA, PPS, OCU, PREDFAIL, PDB, FSCL†)`。七不变式：
(i) **原型仪器性**：每个进入认证的原型级别必须能证伪至少一条已声明主张（定义 405），否则为演示、不进认证路径；
(ii) **数据量具性**：每个数据集必须声明试样语法、可溯源 GT、覆盖域、负样本集与泄漏账本（定义 406–411），缺一不可作证；
(iii) **合同可测性**：核心认证必须报告 `P_out` 与 `OCU`（定义 403–404），不得只报合同内风险；
(iv) **独立溯源**：GT 来源与审计传感器/执行器物理独立，误差预算已知且小于待测效应（A122）；
(v) **物理切分**：校准/验证/证伪集按物理过程切分，跨切分复用计入泄漏账本（定义 410）；
(vi) **预测失败优先**：原型必须先在预测失效的注入上失败，再报告成功（定义 405）；
(vii) **严格退化链扩展**：`P_out→0 ∧ GT` 完美 ∧ 原型→P0 ⇒ 逐指令退化为 FSCL/MODGAUGE；安全侧只增不减（定义 417）。

**定义 403（合同验证分数 CVS 与合同外质量 P_out）**
设契约有效域 `D_EC`、密封审计支撑 `S_SEAL`、负样本/盲区支撑 `S_NEG`，任务分布 `P_task`（由 MEDS 的 `D_task` 经验近似）。定义
`P_out = P_{x∼P_task}(x ∉ D_EC ∪ S_SEAL ∪ S_NEG)`，
`CVS = 1 − P_out − ε_GT − ε_cov`，
其中 `ε_GT` 为 GT 误差预算折算、`ε_cov` 为 coverage 估计的统计误差。
**合同验证通过** ⇔ `CVS ≥ 1 − τ_out` 且 `P_out` 的置信上界 `P_out^ub ≤ τ_out`。**注意**：`CVS` 不是准确率；它度量"契约能表达多少真实世界"，而不是"模型在样本上多准"。把高测试精度当作高 `CVS`，是把"拟合量具"误读为"量具被标定"。

**定义 404（合同外不确定度 OCU 与增强安全界）**
`OCU = λ_oc·P_out^ub`，`λ_oc` 为合同外区域的最大有界损失（由负样本集与物理模型给出上界；无界时取 `λ_oc = L_loss·diam(X)` 保守上界）。
**增强安全界（替代定理 31 的单标量形式）**：
`Risk ≤ ε_in(P_in) + OCU + ε_stat`，
其中 `ε_in` 为 R74 定理 31 在合同内给出的 `ε_mod+ε_meta+ε_drift+ε_audit`，`P_in = 1−P_out`，`ε_stat` 为有限样本统计项。
**关键**：`ε_in` 只在合同内有效；`OCU` 是"合同没覆盖的世界"的罚项。**没有 `P_out` 的证书，等于默认世界全在合同内——这正是 R73/R74 隐含却未声明的假设。**

**定义 405（原型仪器阶梯 PIL 与证伪力）**
`PIL = {P0, P1, P2, P3, P4}`，每级 `P_k = (能力, 入场券, 出口券, 成本, 可证伪主张集 F_k)`：
- P0（silicon harness）：仿真 + mock；验证接口/组合/证书逻辑；成本 ~人日；`F_0 = {C3 逻辑一致性}`；
- P1（单模块台架）：深度 + F/T + 标定件；验证六/四分量可辨识；`F_1 = {C1}`；
- P2（组合台架）：深度⊕触觉⊕本体；验证单调性/审计/否决；`F_2 = {C1, C2, C3}`；
- P3（热替换台架）：同 EC 换实现；验证逐指令等价；`F_3 = {C3, C4}`；
- P4（闭环单元）：人机耦合；验证证据债/证伪税/门控；`F_4 = {C5, C6, C7}`。
**证伪力** `FP(P_k) = |F_k| / Cost(P_k)`（每单位成本能证伪的主张数）；**最小可行原型** `P* = min{P_k : F_k ⊇ Claims(target)}`。
**级别单调性**：`P_k` 的出口券要求其所有 `P_j (j<k)` 的证伪已通过；不允许跳级宣称。

**定义 406（预测失效 PREDFAIL 协议）**
对每条契约字段 `f` 与每个原型级别，预先注册一个**注入-预测对** `(inject_f, predict_f)`：
- 注入 `inject_f` 故意违反 `f` 的声明（如移除 `u_interf`、把材质换成连续谱、在近场用解析 `χ_v`）；
- 预测 `predict_f` 是定理/契约**必须**产生的可观测后果（`u_f` 激增、stub 触发、PAR 退保守、`Cov_lb` 跌破阈值）。
**通过条件**：所有 `predict_f` 全部被观察到，且**无预测外失效**（unpredicted failure 记负分）。
`PREDFAIL = {通过 / 未通过 / 未覆盖}`；**未通过 ⇒ 该主张不得进入认证路径**；**未覆盖 ⇒ 该字段"假证伪"，记入攻击面（定义 415）**。
**反直觉点**：一个从不在注入下失败的原型，不是"鲁棒"，而是**没有测量到它声称测量的东西**。

**定义 407（计量证据数据集 MEDS）**
`MEDS = (D_task, D_cal, D_val, D_falsify, Σ_spec, GT, Cov, Neg, Leak, Prov)`：
- `D_task`：任务分布样本（用于 `P_out` 与 `d_T` 估计）；
- `D_cal / D_val / D_falsify`：校准 / 验证 / 密封证伪，三者按物理过程切分；
- `Σ_spec`：试样语法（定义 408）；
- `GT`：可溯源地面真值及误差预算（定义 408）；
- `Cov`：覆盖向量（定义 409）；
- `Neg`：负样本/盲区集（定义 411）；
- `Leak`：泄漏账本（定义 410）；
- `Prov`：来源与配方证书引用（定义 413）。
**MEDS 本身是 MMS 的一个证据模块**：有契约、有证书、有 stub（数据集污染/过期 ⇒ 数据集 stub，所有依赖它的证书失效）。这条使"数据"第一次进入 R73 的组合代数。

**定义 408（试样语法与可溯源地面真值）**
每条记录 `r = (x, y, g, v, m, c, do, gt_src, gt_err, split_id)`：
- `x`：被审计观测（深度图/RGB/触觉/本体）；
- `y`：下游任务标签；
- `g`：采集时机器人动作；`v`：视角（距离、入射角、相对速度）；`m`：材质类别/材质连续参数；`c`：环境共因（温度、光照、振动等级）；
- `do`：干预标记（`do(g)`、`do(遮挡)`、`do(第二台IR)` 等），用于 ECG 因果识别（定义 414）；
- `gt_src`：独立真值源（激光测距/量块/标定球/F/T 标定），`gt_err`：其误差预算；
- `split_id`：物理过程标识（物体实例/场次/光照条件/温度区间）。
**试样完备性**：每个契约字段 `f` 必须存在至少 `n_f` 条记录使 `f` 的效应可辨识（`gt_err < 0.1·effect_size_f`），否则该字段"证据不足"。**GT 与被审计传感器共享物理链路 ⇒ `gt_err` 不可信，记入负分。**

**定义 409（数据覆盖代数 DCA）**
对契约域 `D_EC` 的离散化 `{cell_j}`，字段 `f` 的覆盖 `Cov_f(j) ∈ {0,1}`（该 cell 是否有满足试样完备性的样本）。覆盖向量 `Cov_f ∈ {0,1}^{|cells|}`。组合：
- **并集** `Cov_{A∪B} = Cov_A ∨ Cov_B`（覆盖只增）；
- **交集** `Cov_{A∩B} = Cov_A ∧ Cov_B`（联合作证取交）；
- **洞** `Hole(f) = {j : Cov_f(j)=0 ∧ D_EC(j)=1}`，`P_out ≥ |Hole ∩ P_task|`。
**覆盖单调性**：任何组合路径的覆盖不高于各输入覆盖的并；**追加数据只能补洞，不能"创造"覆盖**。
**与 `d_T` 的关系**：`d_T(τ,τ₀) ≥ W₁(φ_#P_τ, φ_#P_{τ₀})` 的估计必须使用覆盖向量加权的样本；未覆盖区的 Wasserstein 距离不可估，只能报"外推"（`J_support` 失败）。

**定义 410（物理过程切分 PPS 与泄漏账本）**
切分变量 `s = (object_instance, session, lighting, temperature_band)`；`D_cal/D_val/D_falsify` 的 `split_id` 两两不相交于 `s`。
**泄漏账本** `Leak = {(r_i, r_j, τ_share)}`：任何跨切分共享物理过程（同一物体、同一场景、同一标定轨迹、同一电池/热状态）记录共享强度 `τ_share`；有效样本量
`K_eff = K / (1 + (K−1)·ρ_leak)`，`ρ_leak` 由 `Leak` 估计。
**随机切分偏差**：若按随机切分，`Ẽ[Cov] − E[Cov] = O(ρ_leak)`（乐观偏差）；`PPS` 的目标是使 `ρ_leak ≤ ρ_leak,max`。**随机切分不是"更公平"，而是把同一物体同时放进训练和测试。**

**定义 411（负样本/盲区集 Neg 与对抗集）**
`Neg = Neg_domain ∪ Neg_adversarial`：
- `Neg_domain`：契约声明"不覆盖"的真实样本（透明/镜面/黑体、极端入射角、近场、强互扰、多径）；
- `Neg_adversarial`：针对契约字段的主动注入（材质伪装、飞点注入、外参投毒、IR 对射、GT 篡改）。
**盲区不可为空**：若 `Neg_domain` 为空，说明数据的有效域被"驯化"过（只采容易样本），`CVS` 记可疑，强制降权。
**作用**：`Neg` 既用于估计 `λ_oc`，也用于 PREDFAIL 的注入-预测对；**没有负样本的数据集，其高覆盖率不可信。**

**定义 412（原型-数据绑定 PDB 与配方证书）**
`PDB: EC_field → (rung P_k, D_cal(f), D_falsify(f), predict_f, gt_src(f))`——每个契约字段必须绑定"在哪个原型级别、用哪套校准/证伪数据、预测什么失效、用什么独立真值"。
**配方证书** `Recipe = (BOM, 标定流程, 固件/软件版本, 种子, 环境温湿度, 相机/传感器序列号, 采集脚本哈希, GT 链路)`；第三方用 `Recipe` 能重建同一 `MEDS`（在预注册容差内）。**不可复现的绑定 = 不可认证的绑定。**

**定义 413（经验证据门 EEG 与主张 C7）**
扩展 CPB：**C7（经验接地/契约验证）** ← (PIL, MEDS, DCA, OCU, PREDFAIL, PDB) ← MB7 ← AB7（有接地 vs 无接地 vs 仅 P0 仿真）←（`CVS`、`P_out^ub`、`OCU`、预测失败通过率、可复现率、证伪力/成本）。
**经验证据门** `EEG(claim)`：
- C1/C2/C3 需至少 P2 通过，且对应字段 `PDB` 完整；
- C4/C5/C6 需至少 P3/P4 通过，且 `D_falsify` 密封；
- C7 需 P3 通过，且第三方复现 `Recipe` 成功。
**未过门的主张** ⇒ 降级为"理论主张/工程附件"，不得进入正文的安全声明；**已过门的主张** ⇒ 允许进入，但必须同时报告 `P_out` 与负结果。

**定义 414（干预图与 ECG 识别）**
含 `do` 记录的数据集诱导干预图 `G_do`；边 `A → B` 可识别 ⇔ 存在干预 `do(A)` 使 `P(B|do(A)) ≠ P(B)`，且 `P(B|do(A))` 的估计不依赖未控混杂（由 `split_id` 与共因 `c` 控制）。
**规则**：只有 `G_do` 可识别的边允许进入认证路径；纯观测边标为 `hypothesis edge`，必须加保守界或被 veto。**这把 R73 的 ECG 从"画出来的因果图"变成"被干预数据检验的因果图"。**

**定义 415（经验层威胁面 AIC-EMP）**
`ℰ_emp = {` GT 共链（GT 与被审计传感器同源）、数据驯化（只采容易样本）、随机切分泄漏、密封集泄漏、原型表演（只演示成功）、注入失效（预测失败未覆盖）、配方伪造、数据集投毒、负结果隐藏、`CVS` 指标博弈 `}`。
防线：独立 GT 链路 + 负样本强制非空 + PPS + 泄漏账本 + `SEAL-EMP` 一次性开封 + PREDFAIL 未覆盖即记攻击 + 配方证书 + 负结果强制入账 + 第三方复现 + `CVS` 多指标交叉（覆盖/预测失败/复现，不可单指标优化）。

**定义 416（假设 A121–A123）**
- **A121（合同主导）**：任务分布可分解为合同内 `P_in` 与合同外 `P_out`，且合同内由 R73/R74 的界覆盖；`P_out` 由 MEDS 的 `D_task` 经验估计且置信上界有限。
- **A122（真值独立）**：`GT` 链路与被审计传感器/执行器物理独立；`gt_err < 0.1·effect_size`；GT 的误差预算公开且小于待测效应。
- **A123（物理切分充分）**：`PPS` 捕获主导相关；残留泄漏 `ρ_leak ≤ ρ_leak,max`；`K_eff` 按泄漏折扣后仍满足认证样本量。
三条件同时成立时，定理 34–36 严格成立；任一不成立 ⇒ 按定义 417 退化或拒绝该主张。

**定义 417（经验接地退化链）**
`P_out→0 ∧ gt_err→0 ∧ ρ_leak→0 ∧ P_k→P0` ⇒ `OCU→0`、`MEDS` 退化为"完美量具"、`PIL` 退化为逻辑 harness，GROUNDGAUGE 逐指令等于 FSCL，再等于 MODGAUGE/R73/R72/R71/R68。**经验层只增加"真实世界的罚项"，不改变合同内的安全方向。** 安全侧单调不减：`Ground ≤ FSCL ≤ MODGAUGE` 的风险上界（越接地越紧，且不会被无证据地放松）。

## 2. 关键算法骨架

```python
# IP-312 PIL：原型仪器阶梯（成本-证伪力优化）
LADDER = {
 'P0': dict(cost='~1 person-day', falsifies={'C3_logic'}),
 'P1': dict(cost='~1 week',      falsifies={'C1'}),
 'P2': dict(cost='~3 weeks',     falsifies={'C1','C2','C3'}),
 'P3': dict(cost='~6 weeks',     falsifies={'C3','C4'}),
 'P4': dict(cost='~3 months',    falsifies={'C5','C6','C7'}),
}
def minimal_prototype(claims):
    for k in ['P0','P1','P2','P3','P4']:
        if claims <= LADDER[k]['falsifies']: return k
    return 'P4'
def falsification_power(rung, claims):
    return len(LADDER[rung]['falsifies'] & claims) / LADDER[rung]['cost_num']

# IP-313 MEDS：计量证据数据集（试样 + 独立 GT + 切分）
@dataclass(frozen=True)
class Specimen:
    x: Observation                    # 被审计观测
    y: Label
    g: Action; v: Viewpoint; m: Material; c: CommonCause
    do: Optional[Intervention]        # 干预日志（ECG 识别用）
    gt_src: str; gt_err: float        # 独立真值源 + 误差预算
    split_id: SplitId                 # (object, session, lighting, temp_band)

class MetrologicalDataset:
    def __init__(self, specs, splits):
        self.specs = specs
        self.cal, self.val, self.falsify = splits   # 物理过程切分
        self.leak = LeakLedger(splits)
        self.neg = NegativeSet()
    def field_identifiable(self, f):
        return all(s.gt_err < 0.1 * effect_size(f, s) for s in self.specs_of(f))
    def p_out(self, domain, task_samples):
        covered = domain.covered_mask() | self.neg.mask() | SEAL.mask()
        return 1 - (covered & task_samples.mask()).sum() / task_samples.n
    def k_eff(self):
        return len(self.val) / (1 + (len(self.val)-1) * self.leak.rho_leak())

# IP-314 DCA：覆盖代数
def cover_union(a, b): return a | b          # 覆盖只增
def cover_joint(a, b): return a & b          # 联合作证取交
def coverage_holes(cov, domain):
    return [j for j in domain if domain[j] and not cov[j]]
def d_T_lower_bound(cov_a, cov_b, feats):
    # 未覆盖区不可估 → 只能报「外推」，J_support 失败
    if coverage_holes(cov_a, DOMAIN) or coverage_holes(cov_b, DOMAIN):
        return SUPPORT_FAIL
    return wasserstein1(feats_a[cov_a], feats_b[cov_b])

# IP-315 PPS：物理过程切分 + 泄漏账本
def physical_split(specs, keys=('object','session','lighting','temp')):
    buckets = group_by(specs, keys)
    return three_way(buckets)                 # cal/val/falsify 的 split_id 两两不交
def leak_adjust(k, rho_leak):
    return k / (1 + (k - 1) * rho_leak)       # 随机切分泄漏的 K_eff 惩罚

# IP-316 OCU：合同外不确定度 + 增强安全界
def out_of_contract_uncertainty(dataset, ec, task_samples, lam_oc):
    p_out = dataset.p_out(ec.domain, task_samples)
    p_ub = clopper_pearson_upper(p_out, n=len(task_samples), delta=DELTA_OUT)
    return OCU(p_out=p_ub, lam=lam_oc, value=lam_oc * p_ub)
def augmented_risk_bound(eps_in, ocu, eps_stat):
    return eps_in * (1 - ocu.p_out) + ocu.value + eps_stat

# IP-317 PREDFAIL：预测失败协议（先失败，后成功）
def predfail_suite(ec, rungs, registry):
    results = {}
    for f in ec.u_fields:
        inject, predict = registry[ec.id][f]     # 预注册注入-预测对
        for k in rungs:
            obs = run_injection(k, inject)
            results[(f, k)] = (predict(obs) and not unpredicted(obs))
            if not results[(f, k)]:
                return PREDFAIL_FAIL, results        # 主张不得进认证路径
    return PREDFAIL_PASS, results

# IP-318 PDB：原型-数据绑定 + 配方证书
def bind(ec, pil, meds):
    binding = {}
    for f in ec.u_fields:
        k = minimal_rung_for(f, ec.claim)
        binding[f] = dict(rung=k,
                          cal=meds.cal.of(f), falsify=meds.falsify.of(f),
                          predict=registry.predict(f), gt=meds.gt_source(f))
    assert all(b['gt'].independent_of(ec.sensor) for b in binding.values())
    return Binding(binding, recipe=Recipe.capture(pil, meds))

# IP-319 GROUNDGAUGE 主闭环（在 FSCL 外增加经验证据门）
def GROUNDGAUGE_round(M, obs, depth_img, tac_frame):
    k, lam, J_fsl = FSCL_round(M, obs, depth_img, tac_frame)   # 继承 R74
    # === 经验层（低频：每次部署/换模块/换数据集）===
    if M.clock.due_empirical():
        ocu = out_of_contract_uncertainty(M.meds, M.ec, M.task_samples, M.lam_oc)
        cvs = 1 - ocu.p_out - M.meds.eps_gt() - M.meds.eps_cov()
        pff, detail = predfail_suite(M.ec, M.pil.rungs(), M.registry)
        gate = outcome_gate({'C1': J_fsl.c1, 'C3': J_fsl.c3},
                            cvs, ocu, pff, M.meds.reproducible())
        if gate == 'DEMOTE':
            M.paper_claims.demote(M.ec.claim)      # 降级为附件/理论主张
        M.snapshot.write(ocu=ocu, cvs=cvs, predfail=detail, gate=gate)
    return k, lam, J_fsl, M.snapshot.empirical()
```

## 3. 推导

**引理 44（合同外分解：`P_out` 是一等公民）**
设任务分布分解为合同内 `P_in` 与合同外 `P_out`，合同内损失有界 `≤ ε_in`，合同外损失有界 `≤ λ_oc`（A121），则 `Risk = P_in·ε_in + P_out·λ_oc ≤ ε_in + λ_oc·P_out = ε_in + OCU`。**证明**：全期望公式 + 分区有界性。系：**任何只报 `ε_in` 的安全声明，都隐含假设 `P_out = 0`；这把 R73/R74 的"表达力风险"改写成可测量的漏项。**

**引理 45（覆盖单调性与随机切分乐观偏差）**
DCA：`Cov_{A∪B} = Cov_A ∨ Cov_B`，故任何组合路径的覆盖 ≤ 输入覆盖之并；追加数据只能补洞。PPS：若按随机切分，物理过程共享导致 `Ẽ[Cov] − E[Cov] = O(ρ_leak)`，且 `K_eff = K/(1+(K−1)ρ_leak) < K`。**证明要点**：覆盖是集合的单调算子；随机切分下同一物理过程同时出现在校准与验证，覆盖估计对未覆盖区的乐观偏差与 `ρ_leak` 同阶。系：**"更多数据"不一定提高覆盖；"更干净的切分"才提高覆盖的可信度。**

**引理 46（预测失败的判别信息）**
设主张族 `H = {h_0: 契约按声明工作, h_1: 契约表达力不足}`，正例测试对 `h_0/h_1` 的似然比有界 `≤ 1+γ`；一次预测失效注入 `inject_f` 在 `h_1` 下以概率 `≥ p_fail` 产生可观测偏差、在 `h_0` 下以概率 `≤ q_fail` 产生。则一次通过的预测失败测试使 `H(h_1|pass)` 的置信下界提高 `Ω(log(p_fail/q_fail))`；只做正例测试（无注入）的判别信息 `→ 0`。**证明**：贝叶斯因子 / KL 散度下界。系：**"跑成功一百次"不如"预测失败一次"；没有注入的原型验证，对表达力主张近乎零信息。**

**定理 34（经验接地定理：CVS/OCU 控制安全界）**
在 A121–A123 且 `Valid(J_FSL)`、`PREDFAIL=通过`、`CVS ≥ 1−τ_out` 下，真实风险满足 `Risk ≤ ε_in + λ_oc·P_out^ub + ε_stat`，且 `P_out^ub` 由 MEDS 的独立 `D_task` 与独立 GT 给出。若 `CVS < 1−τ_out` 或 `PREDFAIL=未通过/未覆盖`，则安全界必须**按 `P_out^ub` 膨胀**，且相关主张降级（定义 413）。**证明**：引理 44 + R74 定理 31（合同内）+ 引理 45/46（`P_out` 估计与证伪有效性）。**系：安全证书第一次包含"我可能没看过的世界占多少、那里的损失多大"。**

**定理 35（原型阶梯最小性与成本-证伪前沿）**
给定目标主张集 `Claims`，若 `P_k` 是最小级别使 `F_k ⊇ Claims`，则任何 `P_j (j<k)` 无法证伪 `Claims` 中的至少一条，因此该主张在 `P_j` 上不可认证；`P_l (l>k)` 可认证但证伪力/成本低于 `P_k`。**证明**：定义 405 的 `F_k` 单调包含与 `FP` 定义。系：**"把系统做得更完整"不是默认美德；超出目标主张的原型级别是资源浪费，低于它则是不可证伪。**

**定理 36（数据集即模块：污染零级联）**
MEDS 是 MMS 的证据模块（定义 407），拥有自己的 EC、证书与 stub。若数据集被污染/过期/GT 共链/切分泄漏超标 ⇒ `MEDS stub`（`u=∞`、`D=∅`、`I⊥=数据集全集`、不参与 PAR 缩窄）；所有依赖它的证书（含 `J_FSL`、`OCU`、`CVS`）逐指令降级，其他不依赖该数据集的数据集/模块不被污染。**证明**：R73 引理 35（热替换）+ 定义 381（stub）+ 定义 407（MEDS 作为模块）。系：**"数据污染"不再是组合定理之外的后门——它是模块失效，走既有的零级联路径。**

**定理 37（GROUNDGAUGE 严格包含 FSCL）**
当 `P_out→0`、`gt_err→0`、`ρ_leak→0`、`P_k→P0` 时 `OCU→0`，`OCU` 项消失，`CVS→1`，`MEDS` 退化为完美量具，`PIL` 退化为逻辑 harness，GROUNDGAUGE 逐指令等于 FSCL，再退化等于 MODGAUGE/R73/R72/R71/R68。**安全侧单调不减**：经验层只增加真实世界罚项 `OCU`，不会在无证据时放松合同内界。**证明**：定义 417 + 定理 30 + 定理 34。系：**"接地"不是新教条，而是把 R73/R74 隐含的 `P_out=0` 假设显式化并在其不成立时如实加罚。**

## 6. 本轮最大风险

**一句话**：GROUNDGAUGE 把安全的最后担保压在「原型与数据集的独立性」上——如果地面真值来自被审计的同一物理链路、数据集被驯化成只含容易样本、切分泄漏让验证集与校准集共享同一物体/场次/热状态，那么 `CVS` 会是一个漂亮却可被 Goodhart 操纵的数字，`PREDFAIL` 会因为注入被设计成"注定通过"而退化为表演；系统只是在**自己挑选的世界**里被验证通过，而经验层会以比纸面推导更可信的语气宣布「每一步都有实测支撑」。

次级风险与缓解：
1. **经验层成本拖垮研究** → 最小原型（定理 35）+ 证伪力/成本排序 + P0/P1 先跑，P2–P4 按主张按需升级。
2. **GT 独立性不可得** → 多源 GT 交叉（激光/量块/视觉标定）+ GT 误差预算公开 + 共链即判负 + 仅用相对效应（同一 GT 链路下比较）。
3. **物理切分不足 / 泄漏账本漏记** → 切分变量强制包含物体/场次/光照/温度 + 自动泄漏扫描 + `K_eff` 折扣 + 保守上界。
4. **`λ_oc` 无界导致 OCU 无意义** → 只用有界负样本集声明 `λ_oc`；无界区域直接拒证（不做安全声明）+ 有效域硬边界。
5. **预测失败被"设计成通过"** → 注入-预测对预注册 + 第三方随机选注入 + 未覆盖即记攻击 + 负结果入账。
6. **数据集/原型成为新的过拟合目标** → `SEAL-EMP` 一次性开封 + 三方复现 + `CVS` 多指标交叉 + 只认预注册指标。
7. **原型硬件脆弱/复现性差** → 配方证书 + 备件清单 + 容差带宽 + 失败重建视为证伪 + 开源 BOM。
8. **经验结论被过度外推** → `D_EC` 硬边界 + `P_out` 显式报告 + 跨本体迁移只重绑字段、不重证合同内界 + 拒绝"一台台架证明所有机器人"。

**收束一句**：GROUNDGAUGE 的真正贡献不是"我们终于做了实验"，而是把「契约表达力」从一句无法审计的假设，变成一张必须用独立真值背书、必须报告盲区质量、并且会在坏数据面前被否决的**经验账单**——它赢得的每一分可信度，都必须用一分独立溯源来支付。

## 2. 形式化定义（要点版）

**定义 402（总览与七不变式）** `GROUNDGAUGE-RAS = (PIL, MEDS, DCA, PPS, OCU, PREDFAIL, PDB, FSCL†)`。七不变式：原型仪器性 / 数据量具性 / 合同可测性 / 独立溯源 / 物理切分 / 预测失败优先 / 严格退化链扩展。

**定义 403（CVS 与 P_out）** `P_out` 为任务质量落在 `D_EC ∪ S_SEAL ∪ S_NEG` 之外的占比；`CVS = 1−P_out−ε_GT−ε_cov`。**CVS 度量"契约能表达多少世界"，不是"模型在样本上多准"。**

**定义 404（OCU 与增强安全界）** `OCU = λ_oc·P_out^ub`；`Risk ≤ ε_in + OCU + ε_stat`。`ε_in` 只在合同内有效；没有 `P_out` 的证书等于默认世界全在合同内。

**定义 405（PIL 与证伪力）** P0（silicon harness）/P1（单模块台架）/P2（组合台架）/P3（热替换台架）/P4（闭环单元）；`F_0⊇{C3}`、`F_1⊇{C1}`、`F_2⊇{C1,C2,C3}`、`F_3⊇{C3,C4}`、`F_4⊇{C5,C6,C7}`；不可跳级；`P*` 为最小可行原型。

**定义 406（PREDFAIL）** 每字段预注册 `(inject_f, predict_f)`；全部预测被观察到且无预测外失效才通过；未通过 = 不得进认证路径；未覆盖 = 假证伪 = 记入攻击面。

**定义 407（MEDS）** 数据集是 MMS 模块：`MEDS=(D_task,D_cal,D_val,D_falsify,Σ_spec,GT,Cov,Neg,Leak,Prov)`；数据集污染/过期 ⇒ MEDS stub ⇒ 所有依赖证书降级（定理 36）。

**定义 408（试样语法与独立 GT）** `r=(x,y,g,v,m,c,do,gt_src,gt_err,split_id)`；每字段需 `n_f` 条可辨识试样（`gt_err<0.1·effect_size_f`）；GT 与被审计传感器共享物理链路 ⇒ `gt_err` 不可信、记负分。

**定义 409（DCA）** 覆盖向量 `Cov_f`；`Cov_{A∪B}=Cov_A∨Cov_B`、`Cov_{A∩B}=Cov_A∧Cov_B`；`Hole(f)` 给出 `P_out` 下界；未覆盖区 `d_T` 不可估（`J_support` 失败）。

**定义 410（PPS 与泄漏账本）** 按 `(object,session,lighting,temp_band)` 切分；`Leak` 记录共享物理过程；`K_eff=K/(1+(K−1)ρ_leak)`；随机切分的覆盖乐观偏差 `O(ρ_leak)`。

**定义 411（负样本/盲区集）** `Neg=Neg_domain∪Neg_adversarial`；`Neg_domain` 非空（否则数据被驯化，CVS 记可疑）；`Neg` 既估 `λ_oc`，又供 PREDFAIL 注入。

**定义 412（PDB 与配方证书）** 每字段绑定原型级别/校准集/证伪集/预测失效/独立 GT；`Recipe` 保证第三方可重建 MEDS（预注册容差内）。**不可复现的绑定 = 不可认证的绑定。**

**定义 413（经验证据门 EEG 与 C7）** C7←(PIL,MEDS,DCA,OCU,PREDFAIL,PDB)←MB7←AB7（有接地/无接地/仅 P0）←(`CVS`, `P_out^ub`, `OCU`, 预测失败通过率, 可复现率, 证伪力/成本）。C1–C3 需 P2；C4–C6 需 P3/P4；C7 需 P3 + 配方复现；未过门主张降级。

**定义 414（干预图与 ECG 识别）** `do` 记录诱导 `G_do`；边可识别 ⇔ 存在 `do(A)` 使 `P(B|do(A))≠P(B)` 且控制混杂；只有可识别边可进认证路径，纯观测边标 `hypothesis edge`（加保守界或被 veto）。

**定义 415（AIC-EMP）** 经验层威胁面十类；防线：独立 GT + 负样本非空 + PPS + 泄漏账本 + `SEAL-EMP` 一次性开封 + PREDFAIL 未覆盖即记攻击 + 配方证书 + 负结果入账 + 三方复现 + CVS 多指标交叉。

**定义 416（假设 A121–A123）** A121 合同主导（`P_out` 有限且经验可估）；A122 真值独立（`gt_err<0.1·effect`）；A123 物理切分充分（`ρ_leak≤ρ_max`，`K_eff` 达标）。三条件成立时定理 34–37 严格成立，否则按定义 417 退化/拒证。

**定义 417（经验接地退化链）** `P_out→0 ∧ gt_err→0 ∧ ρ_leak→0 ∧ P_k→P0` ⇒ `OCU→0`，GROUNDGAUGE 逐指令等于 FSCL，再等于 MODGAUGE/R73/R72/R71/R68。**经验层只加真实世界罚项，不放松合同内安全方向。**

## 3. 关键算法伪代码

```python
# IP-312 PIL：原型仪器阶梯（成本-证伪力优化）
LADDER = {
 'P0': dict(cost=1,    falsifies={'C3_logic'}),   # 人日
 'P1': dict(cost=5,    falsifies={'C1'}),         # 人日
 'P2': dict(cost=15,   falsifies={'C1','C2','C3'}),
 'P3': dict(cost=30,   falsifies={'C3','C4'}),
 'P4': dict(cost=60,   falsifies={'C5','C6','C7'}),
}
def minimal_prototype(claims):
    for k in ['P0','P1','P2','P3','P4']:
        if claims <= LADDER[k]['falsifies']:
            return k
    return 'P4'
def falsification_power(rung, claims):
    return len(LADDER[rung]['falsifies'] & claims) / LADDER[rung]['cost']

# IP-313/314 MEDS + DCA：试样、独立 GT、覆盖向量
@dataclass(frozen=True)
class Specimen:
    x: Observation; y: Label
    g: Action; v: Viewpoint; m: Material; c: CommonCause
    do: Optional[Intervention]        # do(g)/do(遮挡)/do(第二台IR)
    gt_src: str; gt_err: float        # 独立真值源与误差预算
    split_id: SplitId                 # (object, session, lighting, temp_band)

class MetrologicalDataset:
    def __init__(self, specs, splits):
        self.specs = specs
        self.cal, self.val, self.falsify = splits       # PPS
        self.leak = LeakLedger(splits)
        self.neg = NegativeSet()
    def field_identifiable(self, f):
        return all(s.gt_err < 0.1 * effect_size(f, s) for s in self.specs_of(f))
    def p_out(self, domain, task_samples):
        covered = domain.covered_mask() | self.neg.mask() | SEAL.mask()
        return 1 - (covered & task_samples.mask()).sum() / task_samples.n
    def k_eff(self):
        k = len(self.val)
        return k / (1 + (k - 1) * self.leak.rho_leak())

def cover_union(a, b): return a | b        # 覆盖只增
def cover_joint(a, b): return a & b        # 联合作证取交
def coverage_holes(cov, domain):
    return [j for j in domain if domain[j] and not cov[j]]

# IP-315 PPS：物理过程切分 + 泄漏账本
def physical_split(specs, keys=('object','session','lighting','temp')):
    return three_way(group_by(specs, keys))    # split_id 两两不交
def leak_adjust(k, rho_leak):
    return k / (1 + (k - 1) * rho_leak)

# IP-316 OCU：合同外不确定度 + 增强安全界
def out_of_contract_uncertainty(dataset, ec, task_samples, lam_oc):
    p_out = dataset.p_out(ec.domain, task_samples)
    p_ub = clopper_pearson_upper(p_out, n=len(task_samples), delta=DELTA_OUT)
    return OCU(p_out=p_ub, lam=lam_oc, value=lam_oc * p_ub)
def augmented_risk_bound(eps_in, ocu, eps_stat):
    return eps_in * (1 - ocu.p_out) + ocu.value + eps_stat

# IP-317 PREDFAIL：预测失败协议（先失败，后成功）
def predfail_suite(ec, rungs, registry):
    results = {}
    for f in ec.u_fields:
        inject, predict = registry[ec.id][f]       # 预注册
        for k in rungs:
            obs = run_injection(k, inject)
            ok = predict(obs) and not unpredicted(obs)
            results[(f, k)] = ok
            if not ok:
                return PREDFAIL_FAIL, results      # 该主张不得进认证路径
    return PREDFAIL_PASS, results

# IP-318 PDB：原型-数据绑定 + 配方证书
def bind(ec, pil, meds):
    binding = {}
    for f in ec.u_fields:
        k = minimal_rung_for(f, ec.claim)
        binding[f] = dict(rung=k, cal=meds.cal.of(f), falsify=meds.falsify.of(f),
                          predict=registry.predict(f), gt=meds.gt_source(f))
    assert all(b['gt'].independent_of(ec.sensor) for b in binding.values())
    return Binding(binding, recipe=Recipe.capture(pil, meds))

# IP-319 GROUNDGAUGE：在 FSCL 外增加低频经验层
def GROUNDGAUGE_round(M, obs, depth_img, tac_frame):
    k, lam, J_fsl = FSCL_round(M, obs, depth_img, tac_frame)   # 继承 R74
    if M.clock.due_empirical():
        ocu = out_of_contract_uncertainty(M.meds, M.ec, M.task_samples, M.lam_oc)
        cvs = 1 - ocu.p_out - M.meds.eps_gt() - M.meds.eps_cov()
        pff, detail = predfail_suite(M.ec, M.pil.rungs(), M.registry)
        gate = outcome_gate({'C1': J_fsl.c1, 'C3': J_fsl.c3},
                            cvs, ocu, pff, M.meds.reproducible())
        if gate == 'DEMOTE':
            M.paper_claims.demote(M.ec.claim)      # 降级为附件/理论主张
        M.snapshot.write(ocu=ocu, cvs=cvs, predfail=detail, gate=gate)
    return k, lam, J_fsl, M.snapshot.empirical()
```

## 4. 推导要点

**引理 44（合同外分解）** `Risk = P_in·ε_in + P_out·λ_oc ≤ ε_in + λ_oc·P_out = ε_in + OCU`。系：**任何只报 `ε_in` 的安全声明都隐含 `P_out=0`；这把"表达力风险"改写成可测量的漏项。**

**引理 45（覆盖单调性与随机切分乐观偏差）** DCA 下任何组合路径覆盖 ≤ 输入覆盖之并；追加数据只能补洞。PPS 下随机切分的覆盖估计乐观偏差 `O(ρ_leak)`，`K_eff=K/(1+(K−1)ρ_leak)<K`。系：**"更多数据"不一定提高覆盖，"更干净的切分"才提高覆盖的可信度。**

**引理 46（预测失败的判别信息）** 设正例测试对 `h_0`（契约按声明工作）/`h_1`（表达力不足）的似然比 ≤`1+γ`；一次预测失效注入在 `h_1` 下产生可观测偏差的概率 `≥p_fail`、在 `h_0` 下 `≤q_fail`，则通过测试使 `H(h_1|pass)` 置信下界提高 `Ω(log(p_fail/q_fail))`；纯正例测试判别信息 →0。系：**"成功一百次"不如"预测失败一次"。**

**定理 34（经验接地定理）** A121–A123 ∧ `Valid(J_FSL)` ∧ `PREDFAIL=通过` ∧ `CVS≥1−τ_out` ⇒ `Risk ≤ ε_in + λ_oc·P_out^ub + ε_stat`；若 `CVS` 不达标或 PREDFAIL 未通过/未覆盖 ⇒ 安全界按 `P_out^ub` 膨胀且主张降级。**证明**：引理 44 + R74 定理 31 + 引理 45/46。系：**安全证书第一次包含"我可能没看过的世界占多少、那里损失多大"。**

**定理 35（原型阶梯最小性与成本-证伪前沿）** 若 `P_k` 是最小级使 `F_k⊇Claims`，则 `P_j(j<k)` 无法证伪至少一条主张（不可认证）；`P_l(l>k)` 可认证但证伪力/成本更低。**证明**：定义 405 的 `F_k` 单调包含与 `FP` 定义。系：**超出目标主张的原型级别是浪费，低于它则不可证伪。**

**定理 36（数据集即模块：污染零级联）** MEDS 是 MMS 证据模块；污染/过期/GT 共链/泄漏超标 ⇒ MEDS stub（`u=∞,D=∅,I⊥=数据集全集,不参与 PAR 缩窄`），依赖证书逐指令降级，不依赖它的模块零污染。**证明**：R73 引理 35 + 定义 381 + 定义 407。系：**"数据污染"不再是组合定理之外的后门，而是模块失效，走既有零级联路径。**

**定理 37（GROUNDGAUGE 严格包含 FSCL）** `P_out→0 ∧ gt_err→0 ∧ ρ_leak→0 ∧ P_k→P0` ⇒ `OCU→0`、`CVS→1`，GROUNDGAUGE 逐指令等于 FSCL，再退化等于 MODGAUGE/R73/R72/R71/R68。**安全侧单调不减。证明**：定义 417 + 定理 30 + 定理 34。系：**"接地"不是新教条，而是把隐含的 `P_out=0` 显式化并在其不成立时如实加罚。**

**定理 38（经验证据门的诚实性）** 若 `PREDFAIL` 的注入集由第三方在 `SEAL-EMP` 启封时随机生成、且 `D_falsify` 对原型不可见，则"通过经验门"的主张在 `P_out` 给定下的误报率 `≤ δ_gate`（可预注册）。**证明要点**：假设检验 + 密封集不可见；未覆盖字段按失败计。系：**经验层的可信度不是来自"做过实验"，而是来自"实验不能被原型挑选"。**

## 7. 本轮最大风险

**一句话**：GROUNDGAUGE 把安全的最后担保压在「原型与数据集的独立性」上——如果地面真值来自被审计的同一物理链路、数据集被驯化成只含容易样本、切分泄漏让验证集与校准集共享同一物体/场次/热状态，那么 `CVS` 会是一个漂亮却可被 Goodhart 操纵的数字，`PREDFAIL` 会因为注入被设计成"注定通过"而退化为表演；系统只是在**自己挑选的世界**里被验证通过，而经验层会以比纸面推导更可信的语气宣布「每一步都有实测支撑」。

次级风险与缓解：
1. **经验层成本拖垮研究** → 最小原型（定理 35）+ 证伪力/成本排序 + P0/P1 先跑，P2–P4 按主张按需升级。
2. **GT 独立性不可得** → 多源 GT 交叉 + GT 误差预算公开 + 共链即判负 + 仅用相对效应。
3. **物理切分不足/泄漏漏记** → 切分变量强制含物体/场次/光照/温度 + 自动泄漏扫描 + `K_eff` 折扣 + 保守上界。
4. **`λ_oc` 无界使 OCU 无意义** → 只用有界负样本声明 `λ_oc`；无界区域拒证 + 有效域硬边界。
5. **预测失败被"设计成通过"** → 注入-预测对预注册 + 第三方随机选注入 + 未覆盖即记攻击 + 负结果入账。
6. **数据集/原型成为新的过拟合目标** → `SEAL-EMP` 一次性开封 + 三方复现 + CVS 多指标交叉 + 只认预注册指标。
7. **原型硬件脆弱/复现性差** → 配方证书 + 备件清单 + 容差带宽 + 失败重建视为证伪 + 开源 BOM。
8. **经验结论被过度外推** → `D_EC` 硬边界 + `P_out` 显式报告 + 跨本体只重绑字段不重证合同内界 + 拒绝"一台台架证明所有机器人"。

**收束一句**：GROUNDGAUGE 的真正贡献不是"我们终于做了实验"，而是把「契约表达力」从一句无法审计的假设，变成一张必须用独立真值背书、必须报告盲区质量、并且会在坏数据面前被否决的**经验账单**——它赢得的每一分可信度，都必须用一分独立溯源来支付。
