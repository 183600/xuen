# 灵感驱动研究循环 · UniBot 创新点研究 第 3 轮；本轮灵感：「创新点」×「放置」

> 承接第 2 轮清单 v1.1（I1–I9）。前两轮是"供给侧"（数据更多、增广更准、恢复更强）；本轮把镜头拉到两个此前没正面处理的问题：**分数主要在哪一种动作上被兑现（放置）**，以及**创新点本身该放在预算图的哪一格（创新点）**。纪律不变：先核实赛事事实再立论；每个创新点过「计分轴对齐、单模型边界、部署预算」三道闸；清单只做增量深化与修剪。

## 0. 赛事核实（本轮检索 2026-11-27）

- **外部核验状态**：本轮直接请求 `challenges.html` 与任务数据端点，均被站点验证页（HTTP 567）拦截，无法新增一手事实。因此**不新增 F 编号**，F1–F19 沿用第 2 轮已核实结论（尤其 F9 任务名、F17 得分点制/每任务满分 100、F18 `reset()` 每集一次、F12 单步预算 ≈66ms）。
- **可复核推断（H，不是外部事实）**：
  - **H1（放置普遍性）**：F9 的 32 个任务名中，绝大多数以"把某物放到/装进/对齐到目标"为终止里程碑；把插入、连接、倾倒、悬挂、折叠后归位都算作广义放置时，**32/32 的终止里程碑都可表述为放置约束的满足**。抓取只是前置门槛。
  - **H2（放置分类）**：按任务名可粗分 7 类：精确位姿/堆叠、收纳/装箱、插入/连接、分拣/归集、倾倒/转移、悬挂/固定、可变形归位（产物 §1，任务可多标签）。
  - **H3（放置段欠采样）**：一条示教中"最后接近—放置—释放"通常只占全部帧的个位数百分比（待时间戳统计复核）；均匀流匹配损失因此系统性欠权放置段。
- **待核实**：逐任务 `score_steps` 与 `generalization` 的机器可读字段（端点恢复即可把 H2 直连评分卡）；放置段帧占比真实分布；N 值。

## 1. 直觉与动机（两个灵感的碰撞）

### 灵感 1（放置 → 这场比赛的主体不是"抓"，是"放"）

直觉：把 32 个任务名当需求文档读，会发现"抓"只是动词链的中间环节，真正的终止条件是"放到哪里、以什么姿态、是否稳定/装入/对齐"。StackBowls 考的是叠放稳定，PackPhone 考的是装入与闭合，PlugCharger/PlugInEthernet 考的是插入对位，PourOutMedicine 考的是倾倒终点。可是训练与推理都更像"抓取中心"：数据按帧均匀采样，推理按 chunk 开环推进，放置那几帧既没有被加权，也没有被显式验证。

核心反直觉点：**"放得准"不是抓取的附属品，而是一个独立、可监督、被严重欠采样的技能维度；提升它的最高杠杆不是换模型，而是把训练与推理的注意力"放置"到轨迹末端那一小段。**

### 灵感 2（创新点 → 创新点本身也要"放置"到分数图上）

直觉：清单已经从 I1 长到 I9（并行轮还会到 I10/I11）。继续加点的边际收益在下降，而"加错点"的成本在上升：有些创新只抬高已会任务的天花板，有些能让难任务从 0 迈到 1，二者的边际分数可能差一个数量级。分数是里程碑制（F17），所以创新点的价值必须按 (任务, 里程碑) 的格子来估，而不是按"模块看起来重不重要"来排序。

核心反直觉点：**创新点不是越多越好，而是"放对格子"；一个只作用于已会任务末端的创新点，其边际分数可能低于一个让难任务从 0 迈到 1 的廉价数据重加权。**

### 两者统一

「放置」给了内容：放置是 32/32 任务的共同终止里程碑，是分数兑现处；「创新点」给了方法：用"创新点-里程碑放置矩阵"把有限预算放到边际分数密度最高的格子。合成一句：**把创新点放到"放置"最容易丢分的格子里。** 本轮因此不追求再加一个大模块，而是新增一个便宜的内容点（I10）和一个元层分配器（I11），并据此修剪旧清单。

## 2. 严谨定义（先直觉后定义）

**定义 1（放置原语与可行集）**。放置原语 P=(o,R,C)：物体 o、目标区域/容器 R、约束 C=(朝向集、顺序、容纳、稳定、非碰撞、接触力界)。其可行集

F(P) = { T∈SE(3) : π_xy(T)∈R_xy⊖ε_p，∠(T,R)≤ε_r，support(T)⊆R_surf，stable(T)，contain(T,R)（若 C 含容纳），free(T,scene∖o)，order(T,{T_prev})（若 C 含顺序） }。

放置误差 e(π)=min_{T∈F} d_SE3(T,pose(o))。里程碑谓词 1[e≤ε_step]；ε_step 是任务容差。插入/连接类 F 是低维接触流形，堆叠类 F 依赖前一次放置（顺序耦合），分拣类 F 是多个 bin 的并集。**"会抓"只保证 o 进入手内，"会放"才保证 e 落进 F。**

**定义 2（最后一厘米段）**。给定轨迹 ξ=(s_0,…,s_T)，令 t_rel 为夹爪释放/接触建立的时刻，t_pre 为其前 h 帧的接近起点，则 L(ξ)=ξ[t_pre:min(t_rel+r,T)]。加权损失

L_place(θ)=E_{t∼ξ}[ w(t)·ℓ_FM(v_θ(s_t),v*(s_t)) ]，w(t)=1+(λ−1)·1[t∈L]。

H3 即"|L|/T 很小，而 λ=1"，所以放置段梯度贡献被稀释。

**定义 3（放置批判器与 best-of-M）**。学习能量 E_φ(o,R,T)（低=可行），用示教终态作正样本、位姿抖动/错目标作负样本对比训练。推理时对同一观测采样 M 个动作块，仅当处于放置阶段时取 argmin_m E_φ(·,terminal_pose(chunk_m))；置信阈值 τ_E 以下退回无批判器。零权重更新，属推理期选择。

**定义 4（创新点-里程碑放置矩阵）**。格子 k=(τ,m_j)，τ∈32 任务、m_j 为其第 j 个里程碑（或按难度×里程碑×泛化轴分层降维）。对创新点 i：覆盖 a_{ik}∈{0,1}、边际分数 Δ_{ik}≥0、成本 c_i、风险 r_i。由于里程碑分数有上限 w_k，加入集合 S 的增益

G(S)=E[Σ_k min(w_k−s_k, Σ_{i∈S} a_{ik}Δ_{ik})] − λ_r Σ_{i∈S} r_i

对 S 单调子模（边际递减）；在预算 Σc_i≤B 下用贪心得 1−1/e 近似。支配剪枝：若 ∃j 使 c_j≤c_i、r_j≤r_i 且 ∀k a_{jk}Δ_{jk}≥a_{ik}Δ_{ik}，则删 i。边际分数密度 ρ_i=ΔG({i})/c_i 决定"创新点放置"的先后。

## 3. 对第 2 轮痛点的增量修订

- P1（弱任务洼地）：从"按任务数/难度分配"升级为"按里程碑边际分数密度分配"（定义 4）。
- P2（泛化缺口）：新增"目标区域位置/朝向"这一独立扰动轴——泛化不只是物体初始位姿变了，也可能是**放置目标被移动**（人把容器挪走/把已放好的物体拿走）。
- P4（无触觉）：放置稳定性（堆叠、装箱）是无触觉下最易丢分的约束；I10 用视觉终端位姿 + 稳定性代理补一条廉价路径。
- P5（时间压力）：放置段是"最后一步"，一旦失败往往没有时间重来 → 放置恢复（并入 I5）优先级高于一般恢复。
- P8（示教质量）：质量分应显式含"终端放置误差 e"，而不只是平滑度/进度。
- **新增 P10（放置欠采样）**：训练损失对放置段系统性欠权（H3），推理期无放置验证。
- **新增 P11（创新点蔓延/自我确认）**：清单越长，Δ 估计越容易用同一套离线信号自证；必须用独立盲测集与支配剪枝约束。

## 4. 研究问题（本轮立项 Q12–Q14，Q1–Q11 保留）

- **Q12（放置段可检测与重加权增益）**：仅用夹爪指令切换 + 物体关键点速度能否稳定切出 L(ξ)？λ 的最优区间在哪，是否以牺牲标称场景为代价？
- **Q13（放置先验/批判器的最小充分形式）**：相对目标区域的关键点位姿先验、还是学习能量 E_φ 更省？best-of-M 在 15Hz/66ms 预算与"单模型"边界内是否可上线，降级路径是什么？
- **Q14（放置矩阵的可估性与稳健性）**：Δ_{ik} 在只有 L0 代理 + 少量真机回填时能否排序稳定？Δ 估计 ±50% 噪声下，子模贪心的选择是否仍优于均分/按难度分配？

## 5. 设计原则（新增 PR6/PR7，其余保留）

- **PR6 放置优先律（内容侧）**：任何训练信号/增广/恢复合成，先问"它改善 F(P) 的哪一项约束（位姿/稳定/容纳/顺序/插入）"；对不上任何放置约束的默认低优先。
- **PR7 边际放置律（组合侧）**：创新点必须填进 (τ,m) 网格并给出 ρ_i；同格只保留一个"核心"，被支配者剪枝；无独立证据来源的 Δ 不得进入 L2 预算决策。
- PR1–PR5 保留（第 2 轮 §4）。PR7 与 PR5 互补：PR5 管"数据来源"，PR7 管"创新预算来源"。

# UniBot-V1 参赛创新点清单（第 3 轮 v1.3）

> 检索日期：2026-11-26/27；本轮外部核验被站点验证页（HTTP 567）阻断，事实沿用 F1–F19，新增内容以 H（可复核推断）标注。承接 v1.1：新增 I10/I11，I1/I2/I5/I8/I9 升 v4，I3/I7 修剪。清单只增改不重置。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 放置位姿先验 + 最后一厘米重加权 + 放置批判器 ★★★★★（新，核心内容）

- **动机**：H1/H3；32/32 任务的终止里程碑是广义放置；放置段帧占比低、均匀损失欠权；推理开环释放无放置验证；放置误差按里程碑直接丢 20–50 分（F17）。
- **与现有方案差异**：现有 VLA 全帧等权、开环释放；本点把放置显式建模为"向可行集 F 投影"：训练端按 L(ξ) 重加权 + 辅助终端位姿/能量头；推理端仅在放置阶段用 best-of-M 选最可能落入 F 的 chunk，零权重更新。
- **技术可行性**：中-高。①放置段检测 = 夹爪释放指令上升沿 + 物体关键点速度→0 + 静止时长；②先验 = 相对目标区域的关键点位姿（高斯混合）；③批判器 = 轻量视觉/点云 encoder 对比学习（示教终态正样本，抖动/错目标负样本）；④推理额外 M=3–4 次小网络前向，仅在放置阶段。
- **所需资源**：1×24GB GPU；数据工程 1–2 人周；批判器 1 GPU 日/任务族；无新增大数据。
- **落地步骤**：①检测器 + 统计 H3（每任务放置帧占比）；②3 任务试点：StackBowls（堆叠稳定）/PackPhone（容纳）/PlugCharger（插入对位）；③λ∈{1,2,3,5} 重加权 + 辅助头；④L0：终端 SE(3) 误差、关键点误差、批判器 AUC；⑤合规确认后 best-of-M 真机 A/B。
- **风险**：目标被遮挡或被人为移走（human_4 型）→ 先验失效；缓解：每步重估相对位姿 + 置信门控 + 低置信退回无先验。**合规**：best-of-M 是推理期选择，需书面确认属"单模型"；降级方案=只保留训练重加权（纯数据侧，零合规风险）。

### I11 创新点-里程碑放置矩阵 ★★★★★（新，元层）

- **动机**：I1–I10 蔓延；分数是里程碑制，创新价值随 (τ,m) 异质；真机/算力预算有限，按"模块重要性"排序会错配。
- **与现有方案差异**：把创新点编译到网格，用边际分数密度 + 子模贪心 + 支配剪枝做组合选择；矩阵随 I8 注册表滚动更新。
- **技术可行性**：高（表格 + 脚本 + L0 代理）。Δ 初期用专家先验并显式标"待 L0"，后期用真机回填校准。
- **所需资源**：1 人周；无额外 GPU。
- **落地步骤**：①定义网格（32×里程碑，或难度×里程碑×泛化轴分层）；②填 a/Δ/c/r 初值；③实现支配剪枝 + 子模贪心；④首个用例=在 I2/I5/I10 间分配下一轮 L2 预算；⑤每次真机回填后重解并记录选择翻转率。
- **风险**：Δ 自我确认 → 矩阵变自欺机器；缓解：独立盲测集 + 每格至少一条独立证据 + 只当排序先验。

### I1 v4 考纲校准五轴增广引擎 ★★★★★

- **动机**：维持（P2/F2/F17）。
- **v4 深化**：①新增**目标区域位置/朝向轴**（不只物体初始位姿）——人可能移动容器或把已放物体拿走；②增广必须过 F(P) 物理可行性门（不可行目标不生成）；③与 I10 共享放置段权重，避免"增广只在接近段有效、放置段仍欠权"。
- **差异/可行性/资源**：同 v1.1；新增轴复用现有分割/inpainting 管线，成本 +10%。
- **落地步骤**：①考纲卡加"目标区域可移动范围"；②目标区域扰动 L0 先行；③不可行动作占比 >5% 即回退为仅平移。
- **风险**：目标区域扰动与真实 human_4 分布失配（缓解：用官方示例锚定 + 小规模真机抽测）。

### I2 v4 数据引擎 2.0 ★★★★

- **动机**：维持（P1/P8）。
- **v4 深化**：①示教质量分加入**终端放置误差 e**（复用 I10 检测器）；②按放置难度平衡采样（堆叠/插入/容纳类上采样）；③孪生表与 loader 加权 patch 同 v1.1。
- **与现有方案差异**：从"按任务/质量加权"升级为"按放置约束难度加权"。
- **所需资源**：同 v1.1；质量分计算 +1 GPU 日。
- **风险**：负迁移（同 v1.1）；放置难度标签噪声（缓解：I10 检测器置信门控）。

## 2. 关键伪代码

### 2.1 放置段检测与重加权（I10）

```python
def placement_segments(traj, h=8, r=8):
    segs = []
    for t_rel in detect_release(traj.gripper_cmd):          # 释放/接触建立上升沿
        t_pre = max(0, t_rel - h)                            # 可替换为关键点速度→0 的起点
        segs.append((t_pre, min(len(traj) - 1, t_rel + r)))
    return segs

def placement_loss(model, traj, lam=3.0):
    segs = placement_segments(traj)
    total, wsum = 0.0, 0.0
    for t, s in enumerate(traj):
        w = lam if any(a <= t <= b for a, b in segs) else 1.0
        total += w * flow_matching_loss(model(s), traj.action[t])
        wsum += w
    return total / wsum            # 按权重归一，避免总损失随 λ 放大
```

### 2.2 放置批判器与 best-of-M（I10）

```python
class PlacementCritic(nn.Module):

        ...

def select_chunk(policy, critic, obs, M=4, tau_E=0.3):
    cands = [policy.propose_chunk(obs) for _ in range(M)]
    if not in_placement_phase(obs):         # 只在放置段启用
        return cands[0]
    es = [critic.energy(obs, terminal_pose(c)) for c in cands]
    if min(es) > tau_E:                     # 低置信：退回无批判器
        return cands[0]
    return cands[int(np.argmin(es))]
```

### 2.3 创新点-里程碑放置矩阵与子模贪心（I11）

```python
# cells: [(task, milestone)]；A[i][k]∈{0,1}；D[i][k]=Δ分数；cost[i]；risk[i]
def gain(S, cells, A, D, cap):
    return sum(min(cap[k], sum(A[i][k] * D[i][k] for i in S)) for k in cells)

def prune_dominated(items, A, D, cost, risk, cells):
    return [i for i in items
            if not any(j != i and cost[j] <= cost[i] and risk[j] <= risk[i]
                       and all(A[j][k] * D[j][k] >= A[i][k] * D[i][k] for k in cells)
                       for j in items)]

def greedy_portfolio(items, budget, cells, A, D, cap, risk, lam_r=0.1):
    S, spent = [], 0.0
    while True:
        base = gain(S, cells, A, D, cap) - lam_r * sum(risk[i] for i in S)
        best, best_rho = None, 0.0
        for i in items:
            if i in S or spent + cost[i] > budget:
                continue
            new = gain(S + [i], cells, A, D, cap) - lam_r * sum(risk[j] for j in S + [i])
            rho = (new - base) / cost[i]
            if rho > best_rho:
                best, best_rho = i, rho
        if best is None:
            break
        S.append(best)
        spent += cost[best]
    return S            # 目标单调子模 → 1-1/e 近似
```
