# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim++；灵感循环第 6 轮；本轮灵感：「真机评测」×「意图识别」）

> 第 54 轮把技能组合建立在「动作空间剖面 α_S + 云边映射 γ_ce」之上，但隐含两个未被检验的前提：**(P1) 任务动作序列 A_T 已知且无歧义；(P2) 仿真得到的 α_S、ρ、γ_ce 能代表真机**。本轮用「意图识别」攻击 P1、用「真机评测」攻击 P2。核心矛盾：H22：意图识别误差会经 A_T 放大为组合错误，但“语义正确的意图标签”未必是控制所需——只有“动作可辨识”的意图才影响执行；H23：真机评测暴露的仿真-真机差距（sim-real gap）会让第 54 轮的兼容性边与联合证书系统性高估，仿真越自信、真机越危险。

## 0. 直觉与动机

**灵感 1（意图的动作可辨识商 → 识别目标从“语义标签”降维为“动作等价类”）**
直觉：意图 `I` 本身是语义的，但控制只关心它诱导的动作序列 `A_T(I)`。若两个意图产生同一动作序列，把它们区分开对部署毫无价值。于是定义等价关系 `I ~_A I' ⟺ d_A(A_T(I),A_T(I')) ≤ δ_A`，识别器只需输出商空间 `𝕀_A = 𝕀/~_A` 上的类。这把“意图识别准确率”从易受标注歧义影响的语义指标，变成与动作可执行性直接挂钩的控制指标：**识别错了标签但落在同一动作类，不构成控制错误**。

**灵感 2（共形意图集 + 拒识 → 把不确定性变成可部署的集合）**
直觉：单点意图预测没有误差保证。用共形预测（conformal prediction）在校准集上构造意图集 `C_α(o)`，在可交换性下保证真意图类以 `1-α` 概率被包含。集合大小 `|C_α|` 就是**意图歧义度**：单元素集可直达认证，多元素集需么做意图鲁棒计划、么主动澄清，空集/过大集则拒识。这把“识别置信度”升级为**分布无关的覆盖证书**。

**灵感 3（意图条件化联合证书 → 计划要对整个歧义集成立，而非某一个猜测）**
直觉：第 54 轮的联合证书 `J` 是针对单一 `A_T` 的。若意图集有多个类，不能只对最可能的类认证，而要问：**是否存在一个计划同时覆盖 `C_α` 中所有类且各自 `ρ`、`δ_a` 达标**？若存在，称“意图鲁棒计划”，可无澄清直接部署；若各类所需计划冲突，则送入决策论澄清；若某类根本不可行，则拒绝并回传不可行证据。这把意图不确定性内化进证书，而不是事后打补丁。

**灵感 4（真机评测作为证伪层 → 从“跑分”升级为“统计证据源”）**
直觉：真机评测的价值不是给方案加分，而是**证伪仿真**。对每个动作 `a` 做配对仿真-真机试验，估计差距 `ε_sr(a)` 并收缩剖面 `α_robust = α_sim - ε_sr^ub`，重新计算兼容性边，得到**兼容性假阳性率 FPR_sr**——这正是第 54 轮“虚假兼容”风险的直接量化。真机成功率不用固定样本点估计，而用 **anytime-valid 置信序列**给出下界，使“边测边停”不破坏统计有效性。

**灵感 5（双环闭合 → 内环意图澄清、外环真机校准）**
直觉：内环是「识别意图集 → 意图条件化认证 → 澄清/拒识 → 执行」，外环是「真机标定 α_robust → 真机验证成功率 → 重剖分/重认证」。运行期再加**意图漂移哨兵**：CUSUM 监测实际观测对计划意图类的支持度，越界即重认证或安全停机。这样第 54 轮的云边闭环之上再叠两层：意图闭环与真机闭环，证书必须同时通过“意图条件”和“真机证据”两道门。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（意图空间与动作可辨识商）**
意图空间 `𝕀`，任务映射 `A_T : 𝕀 → 2^{A*}`（意图到可行动作序列集合），动作序列编辑距离 `d_A`。定义等价关系
```
I ~_A I'  ⟺  d_A(A_T(I), A_T(I')) ≤ δ_A
```
商空间 `𝕀_A = 𝕀 / ~_A` 称为 **动作可辨识意图类**。识别目标是类 `[I]_A` 而非语义标签 `I`。若 `|𝕀_A| ≪ |𝕀|`，则大量语义差异对控制不可见，识别负担显著下降。

**定义 122（共形意图集与歧义度）**
校准集 `{(o_j,[I_j]_A)}_{j=1}^m`，非一致分数 `s(o,[I]) = 1 - p_θ([I]|o)`，阈值 `q_{1-α}` 取分数经验分布的 `⌈(m+1)(1-α)⌉/m` 分位数。意图集
```
C_α(o) = { [I] ∈ 𝕀_A : s(o,[I]) ≤ q_{1-α} }
```
在可交换性假设下 `P([I]_true ∈ C_α(o)) ≥ 1-α`。歧义度 `amb(o) = |C_α(o)|`；当 `C_α=∅` 或 `amb(o) > κ` 时输出拒识 `⊥`。

**定义 123（意图-动作发散与意图鲁棒计划）**
两意图类动作发散 `div_A([I],[I']) = 1 - |A_T(I)∩A_T(I')| / |A_T(I)∪A_T(I')|`。计划 `P` 对意图集 `C` **意图鲁棒**，当且仅当 `∀[I]∈C`，`P` 覆盖 `A_T(I)` 且第 54 轮联合证书 `J` 成立。若不存在单一鲁棒计划但每个类各自可行，则进入澄清；若某类不可行，则拒绝并回传不可行证据。

**定义 124（仿真-真机动作差距与鲁棒剖面）**
对动作 `a`，仿真剖面 `α_sim(a)`、真机剖面 `α_real(a)`，差距 `ε_sr(a)=|α_real(a)-α_sim(a)|`。`n` 次配对真机试验下，由 Hoeffding 以 `1-δ` 置信有
```
ε_sr(a) ≤ ε̂_sr(a) + sqrt( log(2/δ) / (2n) )
```
保守剖面 `α_robust(a) = max(0, α_sim(a) - ε_sr^ub(a))`。**兼容性假阳性率**
```
FPR_sr = |{(i,j) ∈ E_sim : compat_sim(i,j) ≥ θ_a ∧ compat_robust(i,j) < θ_a}| / |E_sim|
```
它是第 54 轮“动作剖面欠采样导致虚假兼容”风险的可计算度量。

**定义 125（真机证据证书）**
`R = (n, k, L_n, δ_req, strata)`：`n` 次真机试验、`k` 次成功、`L_n` 为任意时刻有效（anytime-valid）成功率下界、`strata` 为环境与意图分层。部署判据 `L_n ≥ 1-δ_req` 且无分层系统性失败。采用置信序列（confidence sequence）而非固定样本 Clopper–Pearson，保证“边测边停、看结果再决定是否继续”不破坏统计有效性。

**定义 126（意图漂移哨兵）**
在线观测 `o_t`，计划类 `c*`，替代类 `c_alt = argmax_{c≠c*} p(c|o_t)`。CUSUM 统计量
```
S_t = max(0, S_{t-1} + log( p(c_alt|o_t) / p(c*|o_t) ) )
```
当 `S_t > h_hi` 触发 `drift`，执行重认证或安全停机；`S_t < h_lo` 时复位，双阈值滞回抑制震荡。

## 2. 关键算法 伪代码

### IP-121 IRI（Intent Recognition with action quotient + conformal set）

```python
def action_class(intent, delta_A=0.1):
    a_seq = canonicalize(A_T(intent))          # 规范化动作序列
    for cls, rep in ACTION_CLASSES.items():
        if edit_distance(a_seq, rep) <= delta_A:
            return cls
    ACTION_CLASSES[new_id()] = a_seq
    return new_id()

def conformal_intent_set(recognizer, o, calib_scores, alpha=0.05):
    q = np.quantile(calib_scores, min(1.0, (len(calib_scores)+1)*(1-alpha)/len(calib_scores)))
    scores = {cls: 1.0 - recognizer.p(cls, o) for cls in ACTION_CLASSES}
    C = {cls for cls, s in scores.items() if s <= q}
    if not C or len(C) > KAPPA:
        return {'ABSTAIN'}
    return C
```

### IP-122 IAC（Intent-Conditioned Action Certificate）

```python
def intent_conditioned_certificate(o, G, recognizer, calib, build_J, rho_min):
    C = conformal_intent_set(recognizer, o, calib)
    if C == {'ABSTAIN'}:
        return ('clarify', {'reason': 'ambiguous_or_empty', 'C': C})
    plans = {cls: robust_path(G, A_T(cls), rho_min) for cls in C}
    if any(p is None for p in plans.values()):
        return ('reject', {'reason': 'intent_infeasible', 'plans': plans})
    sigs = {path_signature(p) for p in plans.values()}
    if len(sigs) == 1:                          # 单一意图鲁棒计划
        J = build_J(next(iter(plans.values())))
        return ('ok', IntentCert(C, next(iter(plans.values())), J))
    return ('clarify', {'reason': 'plans_disagree', 'C': C, 'plans': plans})
```

### IP-123 RTG（Real-to-Ground gap calibration）

```python
def sim_real_calibrate(alpha_sim, paired_trials, delta):
    alpha_robust, eps_ub = {}, {}
    for a in alpha_sim:
        sim_ys, real_ys = paired_trials[a]
        n = len(real_ys)
        gap = abs(mean(real_ys) - mean(sim_ys))
        eps_ub[a] = gap + sqrt(log(2/delta) / (2*max(1, n)))
        alpha_robust[a] = max(0.0, alpha_sim[a] - eps_ub[a])
    return alpha_robust, eps_ub

def compat_false_positive_rate(G_sim, alpha_robust, theta_a):
    bad = 0
    for i, j_, d in G_sim.edges(data=True):
        if d['compat'] >= theta_a and \
           jaccard(alpha_robust[i], alpha_robust[j_]) < theta_a:
            bad += 1
    return bad / max(1, G_sim.number_of_edges())
```

### IP-124 RMV（Real-Machine Verification, anytime-valid）

```python
def real_machine_verify(policy, env_sampler, delta_req, n_max, strata):
    n = k = 0
    per_stratum = defaultdict(lambda: [0, 0])
    for ep in env_sampler:
        ok = policy.run(ep)
        n += 1; k += ok
        s = ep.meta['stratum']; per_stratum[s][0] += 1; per_stratum[s][1] += ok
        L_n = anytime_lower_bound(k, n, delta_req)   # 置信序列下界
        if L_n >= 1 - delta_req and stratified_pass(per_stratum, delta_req):
            return ('ok', RealEvidence(n, k, L_n, delta_req, per_stratum))
        if n >= n_max:
            break
    return ('inconclusive', RealEvidence(n, k, L_n, delta_req, per_stratum))
```

### IP-125 ICR（Intent Clarification Request）

```python
def decide_clarify(C, plans, posterior, loss, cost_q):
    if len(C) == 1:
        return ('act', plans[next(iter(C))])
    no_q = sum(posterior[c] * loss(plans[c], c) for c in C)
    best_q, best_val = None, no_q
    for q in queries(C):
        post = posterior_after(posterior, q)
        val = sum(post[c] * loss(plans[c], c) for c in C) + cost_q[q]
        if val < best_val:
            best_q, best_val = q, val
    if best_q is None:
        return ('act_robust', robust_plan(plans))   # 澄清成本过高，退化为鲁棒计划
    return ('clarify', best_q)
```

### IP-126 IDS（Intent Drift Sentinel）

```python
def drift_sentinel(o_stream, planned_cls, recognizer, h_hi, h_lo):
    S = 0.0
    for t, o_t in enumerate(o_stream):
        c_alt = max((c for c in ACTION_CLASSES if c != planned_cls),
                    key=lambda c: recognizer.p(c, o_t))
        S = max(0.0, S + log(recognizer.p(c_alt, o_t) / recognizer.p(planned_cls, o_t)))
        if S > h_hi:
            return ('drift', t, re_certificate(o_stream[:t+1]))
        if S < h_lo:
            S = 0.0
    return ('stable', len(o_stream), S)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IRI | O(m log m + \|𝕀_A\|·\|o\|) | O(m+\|𝕀_A\|) | 校准可交换、商空间完备 |
| IAC | O(\|C\|·(\|V\|log\|V\|+\|E\|)) | O(\|V\|+\|E\|+\|C\|) | 意图集覆盖、每类证书 sound |
| RTG | O(\|A\|·n) | O(\|A\|) | 配对试验、差距上界置信 |
| RMV | O(n_max) | O(\|strata\|) | anytime-valid、分层无偏 |
| ICR | O(\|Q\|·\|C\|) | O(\|C\|) | 损失可定义、澄清可执行 |
| IDS | O(t) 流式 | O(1) | 漂移延迟有界、双阈值滞回 |

**正确性定理（Intent-Conditioned Real-Machine Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 校准集与部署分布可交换，共形意图集覆盖 ≥ `1-α_conf`；**(A30)** 真机配对试验在环境层内可交换、`ε_sr` 在评测分布上平稳；**(A31)** 真机证据使用 anytime-valid 置信序列，可选停止不破坏有效性；**(A32)** 漂移检测延迟 ≤ `τ_max` 且关键窗口内无漏检。则对通过 `α_robust` 重认证且意图类落入 `C_α` 的计划：
```
P_success ≥ 1 - α_conf - δ_real - β_E - Σ_d (1 - ρ_min(d)) - P(τ_detect > τ_max)
```
其中 `α_conf` 为共形误覆盖、`δ_real` 为真机验证失败概率、`β_E` 为执行误差、`ρ_min(d)` 为第 53/54 轮鲁棒性下界。关键：**意图不确定性被显式计入覆盖项，仿真-真机差距被显式计入剖面收缩**，而不是藏在点估计里。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 意图识别（动作等价类） | top-1 类准确率、ECE | acc ≥ 92%，ECE ≤ 0.03 |
| E163 共形意图集 | 覆盖率、平均 \|C_α\|、拒识率 | 覆盖 ≥ 95%，\|C_α\| ≤ 1.8 |
| E164 仿真-真机动作剖面差 | ε_sr 分布、兼容性假阳性率 FPR_sr | ε_sr P95 ≤ 0.08，FPR_sr ≤ 5% |
| E165 真机部署成功率 | 真机证书 vs 纯仿真证书 | 真机证书不高于实测 3%；纯仿真高估 ≥ 10% |
| E166 澄清策略收益 | 每次澄清的风险下降、延迟 | 风险 ↓ ≥ 20%，延迟 P95 ≤ 1s |
| E167 意图漂移检测 | 检测延迟、误报率 | 延迟 ≤ 2 步，FAR ≤ 1/1000 |

**真机评测矩阵**：横轴为意图歧义度（单类/多类/拒识），纵轴为环境偏移（同分布/光照与遮挡/地面材质/负载变化），每格采集配对仿真-真机轨迹。**评测目标是证伪而非加分**：优先报告 `FPR_sr`、纯仿真证书的过度自信幅度、以及意图漂移下的失败模式，配套红队长尾场景。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 意图后验在真机分布漂移下失准 | 高 | 共形覆盖 + 拒识 + 在线重校准 |
| 真机样本少且非平稳，ε_sr 证书失效 | 高 | 按环境分层抽样 + 序贯检验 + 元数据分层加权 |
| 澄清动作引入延迟与二次风险 | 中 | 决策论阈值 + 超时安全回退 + 澄清预算 |
| 意图漂移检测震荡/漏检 | 中 | 双阈值滞回 + 变点检验 + 最短驻留时间 |
| 真机评测成本不可持续 | 中 | 数字孪生预筛 + 主动选择高信息量场景 |
| 动作可辨识商过粗掩盖语义风险 | 中 | δ_A 敏感性分析 + 语义安全约束硬编码 |

## 6. 本轮最大风险

**一句话**：把意图识别降维为动作可辨识商、把真机评测升级为统计证书，确实同时修补了“任务给定”与“仿真即真机”两个隐含前提，但整套 soundness 依赖 **共形覆盖的可交换性、sim-real 差距的平稳性、以及漂移检测的延迟上界**；真实长尾环境恰好在最需要证书的地方破坏这三个假设，使“有覆盖保证的意图集 + 真机证据”在分布外仍可能过度自信，故必须以 **分布外压力测试 + 拒识安全阀 + 真机红队长尾** 三重护栏，宁可保守拒识，绝不把“校准集上的覆盖”当作部署安全性的通行证。

### IP-121 IRI

```python
def action_class(intent, delta_A=0.1):
    seq = canonicalize(A_T(intent))
    for cls, rep in ACTION_CLASSES.items():
        if edit_distance(seq, rep) <= delta_A:
            return cls
    ACTION_CLASSES[new_id()] = seq
    return new_id()

def conformal_intent_set(recognizer, o, calib_scores, alpha=0.05, KAPPA=3):
    q = np.quantile(calib_scores,
                    min(1.0, (len(calib_scores)+1)*(1-alpha)/len(calib_scores)))
    scores = {c: 1.0 - recognizer.p(c, o) for c in ACTION_CLASSES}
    C = {c for c, s in scores.items() if s <= q}
    return {'ABSTAIN'} if (not C or len(C) > KAPPA) else C
```

### IP-122 IAC

```python
def intent_conditioned_certificate(o, G, rec, calib, build_J, rho_min):
    C = conformal_intent_set(rec, o, calib)
    if C == {'ABSTAIN'}:
        return ('clarify', {'reason': 'ambiguous_or_empty', 'C': C})
    plans = {c: robust_path(G, A_T(c), rho_min) for c in C}
    if any(p is None for p in plans.values()):
        return ('reject', {'reason': 'intent_infeasible', 'plans': plans})
    if len({path_signature(p) for p in plans.values()}) == 1:
        J = build_J(next(iter(plans.values())))
        return ('ok', IntentCert(C, next(iter(plans.values())), J))
    return ('clarify', {'reason': 'plans_disagree', 'C': C, 'plans': plans})
```

### IP-123 RTG

```python
def sim_real_calibrate(alpha_sim, paired_trials, delta):
    alpha_robust, eps_ub = {}, {}
    for a in alpha_sim:
        sim_ys, real_ys = paired_trials[a]
        n = len(real_ys)
        gap = abs(mean(real_ys) - mean(sim_ys))
        eps_ub[a] = gap + sqrt(log(2/delta) / (2*max(1, n)))
        alpha_robust[a] = max(0.0, alpha_sim[a] - eps_ub[a])
    return alpha_robust, eps_ub

def compat_false_positive_rate(G_sim, alpha_robust, theta_a):
    bad = sum(1 for i, j, d in G_sim.edges(data=True)
              if d['compat'] >= theta_a
              and jaccard(alpha_robust[i], alpha_robust[j]) < theta_a)
    return bad / max(1, G_sim.number_of_edges())
```

### IP-124 RMV

```python
def real_machine_verify(policy, env_sampler, delta_req, n_max):
    n = k = 0
    per = defaultdict(lambda: [0, 0])
    for ep in env_sampler:
        ok = policy.run(ep); n += 1; k += ok
        per[ep.meta['stratum']][0] += 1
        per[ep.meta['stratum']][1] += ok
        L_n = anytime_lower_bound(k, n, delta_req)     # 置信序列
        if L_n >= 1 - delta_req and stratified_pass(per, delta_req):
            return ('ok', RealEvidence(n, k, L_n, delta_req, per))
        if n >= n_max:
            break
    return ('inconclusive', RealEvidence(n, k, L_n, delta_req, per))
```

### IP-125 ICR

```python
def decide_clarify(C, plans, posterior, loss, cost_q):
    if len(C) == 1:
        return ('act', plans[next(iter(C))])
    best_q, best_val = None, sum(posterior[c]*loss(plans[c], c) for c in C)
    for q in queries(C):
        post = posterior_after(posterior, q)
        val = sum(post[c]*loss(plans[c], c) for c in C) + cost_q[q]
        if val < best_val:
            best_q, best_val = q, val
    return ('clarify', best_q) if best_q else ('act_robust', robust_plan(plans))
```

### IP-126 IDS

```python
def drift_sentinel(o_stream, planned, rec, h_hi, h_lo):
    S = 0.0
    for t, o in enumerate(o_stream):
        alt = max((c for c in ACTION_CLASSES if c != planned),
                  key=lambda c: rec.p(c, o))
        S = max(0.0, S + log(rec.p(alt, o) / rec.p(planned, o)))
        if S > h_hi:
            return ('drift', t, re_certificate(o_stream[:t+1]))
        if S < h_lo:
            S = 0.0
    return ('stable', len(o_stream), S)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IRI | O(m log m + \|𝕀_A\|·\|o\|) | O(m+\|𝕀_A\|) | 共形覆盖 ≥ 1-α |
| IAC | O(\|C\|·(\|V\|log\|V\|+\|E\|)) | O(\|V\|+\|E\|+\|C\|) | 意图集整体 sound |
| RTG | O(\|A\|·n) | O(\|A\|) | ε_sr 置信上界、剖面收缩单调 |
| RMV | O(n_max) | O(\|strata\|) | anytime-valid、分层校验 |
| ICR | O(\|Q\|·\|C\|) | O(\|C\|) | 期望损失最小、预算可控 |
| IDS | O(t) | O(1) | 检测延迟 ≤ τ_max、FAR 可控 |

**正确性定理（Intent-Conditioned Real-Machine Soundness）**
假设 (A26)–(A28) 承接第 54 轮；**(A29)** 意图校准集与部署分布可交换；**(A30)** 真机配对试验分层内可交换、`ε_sr` 在评测分布上平稳；**(A31)** 真机证据用 anytime-valid 置信序列；**(A32)** 漂移检测延迟 ≤ `τ_max` 且关键窗口无漏检。则对经 `α_robust` 重认证、意图类落入 `C_α` 的计划：
```
P_success ≥ 1 - α_conf - δ_real - β_E - Σ_d(1-ρ_min(d)) - P(τ_detect > τ_max)
```
关键：**意图误覆盖（α_conf）与真机差距（δ_real）被显式扣减**，不再隐藏在点估计与仿真假设中。

## 6. 本轮最大风险

**一句话**：把意图识别降维为动作可辨识商、把真机评测升级为统计证书，确实同时修补了“任务给定”与“仿真即真机”两个隐含前提，但整套 soundness 依赖 **共形覆盖的可交换性、sim-real 差距的平稳性、以及漂移检测的延迟上界**；真实长尾环境恰好在最需要证书的地方破坏这三个假设，使“有覆盖保证的意图集 + 真机证据”在分布外仍可能过度自信，故必须以 **分布外压力测试 + 拒识安全阀 + 真机红队长尾** 三重护栏，宁可保守拒识，绝不把“校准集上的覆盖”当作部署安全性的通行证。
