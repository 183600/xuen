# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「鲁棒性」×「关节驱动」）

> R69 把不确定性拆成 aleatoric / epistemic，并给了机器人一张「会提问的嘴」：看不看、问不问、摸不摸由 VoI 决定，动作由流匹配策略给出多模态分布，FMA 用动作似然做标定不可吸收的第二意见。但整套机制悬在一个从未被检验的假设上——**身体是好的**。ξ=(a,g) 被当成可执行的动作，而真正把它变成运动的是 N 个关节驱动：力矩上限、热限制、摩擦、背隙、编码器漂移、减速器磨损。一个再好的「模态」如果弱关节跟踪不上，等于零；一次再聪明的「问」如果需要转头而颈关节已经降额，也只是空谈。
>
> 更尖锐的是：R69 的鲁棒性是**标量慢下来**（λ_floor）。对力矩受限的关节，这甚至可能反向——重力负载不随速度下降，低速高力矩区间反而更吃力；而慢下来同时把机器人本来拥有的**冗余**（多余 DOF、健康的邻居关节）全部浪费了。真正的鲁棒性不是「全都慢一点」，而是**在故障集下尽可能保住任务能力**：先卸载、再减速、最后才降任务。
>
> 本轮两个灵感正好补上这块地基：
> - **关节驱动**：把「可执行性」变成一个独立的、逐关节可测量、可认证的物理通道；
> - **鲁棒性**：把「安全」从标量收缩升级为**有最坏情况保证的能力包络 + 优雅降级阶梯**。
>
> 核心命题：在 R69 的两轴不确定性 (U_ale, U_epi) 之外，加入**第三轴 U_act（身体可实现性不确定性）**；在 R68/R69 的两条残差通道 (r_res, Δa) 之外，加入**第三条 r_act（跟踪残差）**；用三通道归因把「看错」「问错」「动不了」分开，再用「卸载 → 减速 → 降任务 → 安全停」的字典序阶梯替代单一 λ_floor。命名 **TRIAD-RAS**（Tri-channel Residual Isolation + Actuation-aware Degradation）。三重三元组：三轴不确定性、三条残差通道、三级降级梯。
>
> 理论姿态延续本线程：**R69 是 TRIAD 在「全关节健康、关闭卸载」边界上的严格退化**；健康时逐指令一致，退化时能力不低于 R69、风险不高于 R69。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的身体还撑得住吗、撑不住时我还能做什么**」。

## 0. 直觉与动机

**灵感 1（关节驱动 → 可执行性是独立的第三层）**
直觉：策略输出的是「意图动作」，关节驱动输出的是「实际运动」，两者之间隔着 N 个执行器。每个关节都有自己的可行域：力矩随温度降额、摩擦随磨损上升、背隙让力控失真、编码器漂移让「到位」变成假象。R69 的 C-RAS-WM 认证的是运动学前缀，默认「能规划就能执行」。但一个力矩只剩 60% 的髋关节可能连站立都勉强，谈何执行多模态轨迹。所以可执行性必须是独立通道：逐关节算 margin，取**瓶颈**（min）而不是均值——鲁棒性由最弱环节决定。

**灵感 2（鲁棒性 → 能力包络，而非标量）**
直觉：面对弱关节，R69 只会 λ_floor。但机器人是冗余系统：可以改变关节分配，让健康关节多出力、弱关节少出力，任务照做。这就是控制分配 / 全身控制的思路。于是鲁棒性有了层级：
(1) **卸载**：用冗余把负载从弱关节移走，任务不变；
(2) **减速**：若卸载不够，才按 R69 缩放；
(3) **降任务**：若减速仍不满足包络，明确声明「我只能做 X，不能做 Y」。
字典序按「能力损失」排：卸载不损任务，减速损速度，降任务损目标。鲁棒 = 在故障集下最大化保留的能力，而不是最小化速度。

**灵感 3（第三轴 → 不可由交互消解）**
直觉：U_ale 是策略自身噪声，U_epi 是世界的歧义，都可以通过更多采样 / 主动交互去逼近或消解。但「电机烧了」不是问一句就能好的。U_act 的语义完全不同：它不能被「问」消除，只能被「修 / 换 / 重新分配 / 降级」处理。把 U_act 塞进 U_ale 或 U_epi 会犯两类错：塞进 U_ale → 永远只会降速（对力矩受限无效，低速高力矩时甚至有害）；塞进 U_epi → 会去「问」一个物理上无解的问题（问错比不问更危险）。所以必须单列。

**灵感 4（三通道 → 正确归因才谈得上正确补救）**
直觉：R69 用 (r_res, Δa) 两通道判「传感器 vs 缓变故障」。但执行器故障会同时污染这两条：编码器偏置既能伪装成「传感器漂移」（r_res 高），也能让策略在错误本体状态下算出低似然（Δa 高）。补救方向却完全相反——传感器故障该重标定 / 追问，执行器故障该卸载 / 降级。三通道 r_act（指令 vs 实到的跟踪残差）把「动不了」单独拎出来：执行器坏 → r_act 高而 r_res 低；传感器偏 → r_res / Δa 高而 r_act 低（它忠实地执行了错误信念）；策略 OOD → Δa 高而 r_act / r_res 低。**归因错了，补救就是二次伤害**。

**灵感 5（鲁棒性是对抗性的 → 新威胁与级联风险）**
直觉：一旦引入「卸载」，就引入新的失败模式：把风险从被看见的弱关节**转移给没被看见的邻居**，形成级联。对抗者也能利用这一点：编码器注入、力矩指令重放、诱导热降额、用背隙制造「位置在容差内但力控已错」的隐蔽故障，甚至用无信息回答把 R69 的交互拖成无限追问（交互耗尽 DoS）。因此鲁棒性必须是有界最坏情况：no-overload 护栏、健康不可观测时禁止卸载、交互硬截止。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TRIAD-RAS 总览）** TRIAD-RAS = (JHM, JCE, AXD, CAA, GDL, TRA, FIC, CG, JRC, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **逐关节可执行性**：任何下发指令必须落在每个关节的认证包络内并保留余量 ρ（定义 315）；
(iii) **无级联（no-overload）**：卸载 / 再分配不得把任何健康关节推过其认证余量（定义 316、323）；
(iv) **有界降级**：降级梯在 ≤ 4 级、有限时间内终止；交互与降级均有硬截止，未解决即升级或安全停（定义 317、322）。

**定义 311（关节健康状态 JHM）** 关节 j∈[N] 的健康态 h_j = (τ_max,j(T_j), q̇_max,j, T_j, f_j, b_j, σ_enc,j, e_j)，分别为温 dependent 力矩上限、速度上限、温度、摩擦、背隙、编码器噪声与健康标志。由在线递归估计器给出带 conformal 区间的估计 (ĥ_j, CI_j)；估计过程只写独立健康缓冲，不进学习权重（继承零学习写操作）。

**定义 312（逐关节能力包络与裕度 JCE）** 关节 j 的可行域 𝒞_j(h_j) ⊂ ℝ³ 为 (q, q̇, τ) 的认证集；对指令 ξ 定义符号裕度 m_j(ξ) = dist(ξ_j, ∂𝒞_j(h_j))，归一化裕度 μ_j = m_j / m_j^req。**瓶颈裕度** μ_min = min_j μ_j（不是均值；由引理 19 证明能力对 μ_min 单调）。

**定义 313（第三不确定性轴 AXD）** U_act = (1 − μ_min)⁺ + β·CI_penalty(h)。语义：身体可实现性不确定性——既非策略内噪声（U_ale），也非世界歧义（U_epi），**不能被更多采样或主动交互消解，只能被再分配 / 减速 / 降任务 / 维修处理**。三轴不做简单加和，各入不同通道（定义 317）。

**定义 314（能力泛函 κ）** κ(π; ℱ, h) = 在故障集 ℱ 与健康 h 下、以认证风险 ≤ ε 所能达到的最大任务难度 / 速度 d。用于比较降级梯各档：能力损失最小的档优先。鲁棒性目标：max_π κ(π; ℱ, h) s.t. risk ≤ ε。

**定义 315（可执行性门 JCE-Gate）** 指令 ξ 可执行 ⇔ ∀j, μ_j(ξ) ≥ ρ（余量 ρ>0）。该门插在 R69 的 C-RAS-WM 认证之内：运动学前缀认证通过但 JCE 不过 ⇒ 整个指令作废，进入降级梯；不得以「动力学上可行」替代「执行器上可行」。

**定义 316（能力感知分配 CAA）** 给定任务约束（末端 / 质心 / 接触力），求关节努力 τ（或增量 q）：
τ* = argmin_τ [ Σ_j w_j·ℓ_j(τ_j; h_j) + λ_reg‖τ−τ_nom‖² ]，s.t. 任务约束 Jᵀτ = f_task，τ_j ∈ 𝒞_j(h_j)。
其中 w_j 对弱关节加权。**no-overload 约束**：设负载转移矩阵 L（卸载 Δ 引起的各关节余量变化 m′ = m − LΔ），要求 min_{健康 j} m′_j ≥ ρ。不满足 ⇒ 该分配非法（定义 323），而非「近似可接受」。

**定义 317（优雅降级梯 GDL）** 有序档 r1=卸载、r2=减速、r3=降任务、r4=安全停。选择**满足 κ ≥ κ_min 且证书有效的最早档**。字典序：r1 保任务、r2 损速度、r3 损目标、r4 保安全。R69 的 λ_floor 恰为「关闭 r1、固定 r3/r4」时的 r2 特例。每档都以认证命令收尾，禁止跨档「折中」。

**定义 318（跟踪残差 TRA）** r_act = ‖W_q(q_cmd − q_meas)‖ + ‖W_τ(τ_cmd − τ_meas)‖ 的窗化 CUSUM。测「身体是否跟得上意图」，与 r_res（传感器是否自洽）、Δa（策略是否自洽）条件独立（A100）。

**定义 319（三通道归因 FIC）** 证据 z=(r_res, Δa, r_act)；归因 â = argmax_a P(a|z)，a ∈ {sensor, policy, actuator, none}。补救映射：sensor→重标定 / 追问；policy→重采样 / 交互；actuator→卸载 / 降级 / 维修；none→正常。A99–A101 下混淆矩阵对角占优（引理 20）。

**定义 320（关节鲁棒证书 JRC）** J_TRIAD = (J_FLUID, health_ci_coverage, μ_min, κ_lb, load_ledger_hash, degradation_ledger, attribution_log_hash, triad_ver)。Valid ⇔ Valid(J_FLUID) ∧ CI 覆盖率 ≥ 1−δ ∧ no-overload 成立 ∧ 降级梯在硬截止内终止。

**定义 321（关节干扰集 ℰ_joint）** 编码器偏置 / 欺骗、力矩指令注入与重放、诱导热降额、背隙隐蔽故障（位置在容差内而力控已错）、交互耗尽（用无信息回答拖垮 R69 的 VoI）。并入 AIC：ℰ_TRIAD = ℰ_FLUID × ℰ_joint。

**定义 322（交互鲁棒界 IRB）** 对抗性无信息回答可使 R69 的后验永不收敛而 VoI 保持正增益。加入硬截止 T_int 与「无进展计数」：超时或连续 k 次无信息增益 ⇒ 停止交互，U_epi 视为未消解，降级梯至少从 r2 起。保证最坏解决时间 ≤ T_int。

**定义 323（级联护栏 CG）** 卸载前用健康 CI 上界预测 m′；若 ∃健康 j 使 m′_j < ρ，则禁止该分配并下移档位。余量 ρ 必须覆盖负载转移模型误差（A103）。CG 是正确性条件而非可选优化（引理 21）。

**定义 324（鲁棒占优序）** 在故障集 ℱ 上定义偏序：π₁ ⪰ π₂ ⇔ ∀h, ℱ: risk(π₁) ≤ risk(π₂) ∧ κ(π₁) ≥ κ(π₂)。定理 18 证明 TRIAD ⪰ R69。

**定义 325（关节关键度）** c_j = 任务能力对关节 j 的灵敏度（基于任务 Jacobian / 可操作度）；关键度加权瓶颈 μ_min^c = min_j (μ_j)^{1/c_j}。用于在多个弱关节时决定先卸载谁、以及任务降级时牺牲哪个自由度。

**定义 326（健康可观测性门 HMG）** 若 CI 宽度 > τ_CI（健康不可观测），令 U_act := U_act^max，且**禁止卸载**，直接进 r2 保守；只有健康可观测时才允许 CAA。这与 R69 的 MCG 同构：不可信的分布不得驱动决策——不可信的健康估计不得驱动再分配。

## 2. 关键算法骨架

```python
# IP-264 JHM：逐关节健康估计（带 conformal CI；不写学习权重）
def estimate_health(joint_telem, health_model):
    h, ci = health_model.filter(joint_telem)          # τmax,T,f,b,σ_enc + CI
    h_valid = ci.width <= TAU_CI                       # 健康可观测性门
    return h, ci, h_valid

# IP-265 JCE：逐关节包络与瓶颈裕度（取 min，不取均值）
def joint_envelope(xi, h):
    mu = {j: signed_margin(xi.joint(j), C_j(h[j])) / m_req[j]
          for j in JOINT_SET}
    return mu, min(mu.values())

# IP-266 AXD：第三不确定性轴
def actuation_uncertainty(mu, ci):
    return max(0.0, 1.0 - min(mu.values())) + beta * ci_penalty(ci)

# IP-267 CAA：冗余再分配（离弱关节，但不压垮邻居）
def capability_alloc(xi_task, h, mu, L, rho):
    q = solve_qp(task_constraint=xi_task,
                 objective=weak_joint_load(mu) + reg,
                 bounds=[C_j(h[j]) for j in JOINT_SET])
    if q is None: return None
    post = predict_margins(q, h, L)                    # m' = m - LΔ
    if min(post.values()) < rho:                       # 级联护栏
        return None                                    # 不许用邻居的命换
    return q, post

# IP-268 GDL：能力保持的字典序降级梯
def degrade_ladder(xi, h, mu, U_epi, budget):
    q = capability_alloc(xi, h, mu, L, RHO)            # r1 卸载
    if q is not None: return R1, q
    lam = max(lam_floor(U_ale + U_act + U_epi), risk_scale(xi))  # r2 减速
    if certified(scale(xi, lam), h): return R2, scale(xi, lam)
    if certified(task_degrade(xi), h): return R3, task_degrade(xi)  # r3 降任务
    return R4, safe_stop(xi)                           # r4 安全停

# IP-269 TRA：跟踪残差（第三条独立通道）
def tracking_residual(q_cmd, q_meas, tau_cmd, tau_meas):
    return cusum(||W_q @ (q_cmd - q_meas)|| + ||W_tau @ (tau_cmd - tau_meas)||)

# IP-270 FIC：三通道归因
def attribute(r_res, d_a, r_act):
    if r_act > TA and r_res < TR and d_a < TD: return ACTUATOR
    if d_a  > TD and r_res < TR and r_act < TA: return POLICY
    if r_res > TR or (r_res < TR and d_a > TD): return SENSOR
    return NONE

# IP-275 主闭环（继承 R69，在策略层之下插入身体层）
def TRIAD_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # ---- R69 策略层：不确定性二分 + 交互 ----
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    mode = select_mode(modes, U_epi)
    # ---- R70 身体层：第三轴 + 三通道归因 ----
    h, ci, h_valid = M.jhm.estimate_health(M.telemetry)
    mu, mu_min = M.jce.joint_envelope(mode.a, h)
    U_act = M.axd.actuation_uncertainty(mu, ci) if h_valid else U_ACT_MAX
    r_act = M.tra.tracking_residual(M.q_cmd, M.q_meas, M.tau_cmd, M.tau_meas)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, M.o_obs, M.o_cal)
    cause = M.fic.attribute(M.last_r_res, a_hat, r_act)
    # ---- 降级梯（字典序）：能力优先，安全兜底 ----
    rung, cmd = M.gdl.degrade_ladder(mode.a, h, mu, U_epi, M.budget)
    if (cause == ACTUATOR and not h_valid) or M.budget.exhausted():
        rung, cmd = max(rung, R2), slow_conservative(mode.a)   # 看不见则不许卸载
    k = M.c_ras_wm.certified_prefix(cmd, ..., wm_preds, joint_env=M.jce)
    tau = M.pi_sigma.prefix_dispatch(cmd[:k])
    M.vqa_j.submit_async(rung, cause, mu_min, U_act, U_epi)
    return k, tau, rung, (U_ale, U_epi, U_act, cause)
```

## 3. 推导

**假设** A99（单个诊断窗口内至多一个主导故障）、A100（给定故障源，三残差条件独立）、A101（对应残差对对应故障单调响应）、A102（关节包络模型在观测工况上有效，且 conformal 校准）、A103（负载转移模型误差有界，界由健康 CI 宽度给出）。

**引理 19（瓶颈律与阶梯序）** κ 对瓶颈裕度 μ_min 单调不减。均匀减速按系数 s 缩放所有关节的**速度相关**负载，但重力 / 外力项不随 s 缩放；故对力矩受限关节，减速对 μ_weak 的改善 ≤ 直接卸载（卸载减少 τ_weak 本身）。若存在满足任务约束的可行再分配，则 κ(r1) ≥ κ(r2)。系：卸载先于减速不是工程偏好，而是能力序的正确性要求。

**引理 20（三通道归因可分性）** 在 A99–A101 下，执行器故障主要改变 r_act 的条件分布而保持 r_res 的条件分布；传感器偏置主要改变 r_res 与 Δa，而 r_act 在「忠实执行错误信念」下保持低值。于是归因混淆矩阵对角占优：P(actuator|actuator) ≥ 1−ε_ra，P(actuator|sensor) ≤ ε_ra。二通道 (r_res, Δa) 无法区分「传感器偏置导致策略低似然」与「执行器降额导致行为异常」的联合偏移，故三通道严格提升可辨识性。系：R69 的 FMA 第二意见在**执行器**故障上是盲的，因为它只条件在观测上。

**引理 21（再分配无级联条件）** 设卸载后余量 m′ = m − LΔ。若存在健康关节 j 使 m′_j < ρ，则存在故障注入序列导致级联：j 成为新瓶颈 → 触发再次再分配 → 可能回到更差分配，能力沿阶梯非单调，甚至越过安全包络。故 no-overload 约束是降级梯正确性的**前置条件**；余量 ρ 至少覆盖 L 的模型误差（A103），否则「预测安全」不等于「实际安全」。

**引理 22（交互耗尽的鲁棒界）** 在对抗性无信息回答下，R69 的 VoI 可保持正增益而后验永不收敛（每轮提供看似合理的新证据），交互时间无界。加入硬截止 T_int 与 k 次无进展计数后，最坏解决时间 ≤ T_int；超时即 U_epi 未消解并强制 rung ≥ r2。系：交互层鲁棒性由「有界时间 + 可退化」保证，而非由「回答可信」假设保证。

**定理 18（TRIAD 严格包含 R69）** 在 A99–A103 下，对任意健康 h 与故障集 ℱ：
(i) 若 μ_min ≥ ρ 且无执行器故障：卸载可行则 κ(TRIAD) ≥ κ(R69)，卸载不可行则进入 r2，且**与 R69 的 λ_floor 逐指令相同**；
(ii) 若 μ_min < ρ：每一档都以认证命令收尾、最坏 r4 安全停，故 risk(TRIAD) ≤ risk(R69)；又因 r1 先于 r2，κ(TRIAD) ≥ κ(R69)；
(iii) 当交互超时、ECE 越界或健康不可观测时，退化为 R69 的保守分支。
因此 TRIAD ⪰ R69（定义 324），R69 = 「全关节健康 + 关闭卸载 + 交互可无限」的边界。

**定理 19（鲁棒能力证书的有界性）** 在 A102–A103 与健康 CI 覆盖率 ≥ 1−δ 下：(a) 认证命令的逐关节越界概率 ≤ ε_joint；(b) 能力下界 κ_lb 以概率 ≥ 1−δ 成立（对健康不确定性取最坏）；(c) 降级梯在 ≤ 4 级、有限时间内终止，且在 ℰ_joint（含交互耗尽）下最坏时间与风险有界。系：鲁棒性从「平均性能」升级为「带置信度的最坏情况能力下界」，且该下界可写进证书逐项审计。

## 6. 本轮最大风险

**一句话**：TRIAD 的全部能力保持押在「关节健康可观测、负载可转移」这两条假设上——**而恰恰在真正需要它的退化外推区，这两条最不成立：健康估计误差最大、负载转移模型最不可靠，于是「卸载」可能把风险从被看见的弱关节悄悄转移给未观测的邻居，鲁棒性反而成为级联故障的放大器——修错，比不修更危险。**

**次级风险与缓解**：
1. **级联过载**（卸载压垮邻居）→ no-overload 前置约束 + 余量 ρ 覆盖模型误差 + CG 护栏（引理 21）；
2. **健康估计不可观测**（摩擦 / 背隙难辨识）→ HMG 门，CI 越界即禁止卸载、退回 r2（定义 326）；
3. **归因错误导致补救二次伤害** → 三通道 FIC + 对角占优可分性 + 审计回灌（引理 20）；
4. **交互耗尽 DoS** → 硬截止 T_int + 无进展计数 + 超时降级（引理 22）；
5. **QP 实时性被击穿** → 健康路径零 QP、仅退化触发、小规模 active-set + 失败即安全停；
6. **关节干扰隐蔽**（背隙在位置容差内但力控已错）→ r_act 用力 / 力矩残差而非仅位置残差 + ℰ_joint 对抗训练。

# 第 70 轮产物 · 创新点清单 v1：TRIAD-RAS（Tri-channel Residual Isolation + Actuation-aware Degradation：关节驱动鲁棒性 × 能力保持式优雅降级的三轴不确定性闭环；JHM×JCE×AXD×CAA×GDL×TRA×FIC×CG×JRC×RAS-WM†）

```python
# IP-264 JHM：逐关节健康估计（带 conformal CI；不写学习权重）
def estimate_health(joint_telem, health_model):
    h, ci = health_model.filter(joint_telem)          # τmax,T,f,b,σ_enc + CI
    return h, ci, (ci.width <= TAU_CI)                # 第三项：健康可观测

# IP-265 JCE：逐关节包络与瓶颈裕度
def joint_envelope(xi, h):
    mu = {j: signed_margin(xi.joint(j), C_j(h[j])) / m_req[j]
          for j in JOINT_SET}
    return mu, min(mu.values())                       # min，不是 mean

# IP-266 AXD：第三不确定性轴
def actuation_uncertainty(mu, ci):
    return max(0.0, 1.0 - min(mu.values())) + beta * ci_penalty(ci)

# IP-267 CAA：冗余再分配 + 级联护栏
def capability_alloc(xi_task, h, mu, L, rho):
    q = solve_qp(task_constraint=xi_task,
                 objective=weak_joint_load(mu) + reg,
                 bounds=[C_j(h[j]) for j in JOINT_SET])
    if q is None: return None
    post = predict_margins(q, h, L)                   # m' = m - LΔ
    return (q, post) if min(post.values()) >= rho else None

# IP-268 GDL：字典序降级梯
def degrade_ladder(xi, h, mu, U_epi):
    q = capability_alloc(xi, h, mu, L, RHO)           # r1 卸载
    if q is not None: return R1, q
    lam = max(lam_floor(U_ale + U_act + U_epi), risk_scale(xi))
    if certified(scale(xi, lam), h): return R2, scale(xi, lam)
    if certified(task_degrade(xi), h): return R3, task_degrade(xi)
    return R4, safe_stop(xi)

# IP-269/270 TRA + FIC：跟踪残差与三通道归因
def tracking_residual(q_cmd, q_meas, tau_cmd, tau_meas):
    return cusum(||W_q @ (q_cmd - q_meas)|| + ||W_tau @ (tau_cmd - tau_meas)||)

def attribute(r_res, d_a, r_act):
    if r_act > TA and r_res < TR and d_a < TD: return ACTUATOR
    if d_a  > TD and r_res < TR and r_act < TA: return POLICY
    if r_res > TR: return SENSOR
    return NONE

    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    mode = select_mode(modes, U_epi)
    # R70 身体层
    h, ci, h_valid = M.jhm.estimate_health(M.telemetry)
    mu, mu_min = M.jce.joint_envelope(mode.a, h)
    U_act = M.axd.actuation_uncertainty(mu, ci) if h_valid else U_ACT_MAX
    r_act = M.tra.tracking_residual(M.q_cmd, M.q_meas, M.tau_cmd, M.tau_meas)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, M.o_obs, M.o_cal)
    cause = M.fic.attribute(M.last_r_res, a_hat, r_act)
    # 字典序降级梯
    rung, cmd = M.gdl.degrade_ladder(mode.a, h, mu, U_epi)
    if (cause == ACTUATOR and not h_valid) or M.budget.exhausted():
        rung, cmd = max(rung, R2), slow_conservative(mode.a)  # 看不见 → 不许卸载
    k = M.c_ras_wm.certified_prefix(cmd, ..., wm_preds, joint_env=M.jce)
    tau = M.pi_sigma.prefix_dispatch(cmd[:k])
    M.vqa_j.submit_async(rung, cause, mu_min, U_act, U_epi)
    return k, tau, rung, (U_ale, U_epi, U_act, cause)
```

## 4. 推导

**引理 19（瓶颈律与阶梯序）** κ 对 `μ_min` 单调不减。均匀减速只缩放速度相关负载，重力 / 外力项不缩放；对力矩受限关节，减速对 `μ_weak` 的改善 ≤ 直接卸载。存在可行再分配时 `κ(r1) ≥ κ(r2)`。系：卸载先于减速是能力序的正确性要求，不是工程偏好。

**引理 20（三通道归因可分性）** A99–A101 下，执行器故障主要改变 `r_act` 而保持 `r_res`；传感器偏置主要改变 `r_res/Δa`，`r_act` 因「忠实执行错误信念」保持低值。归因混淆矩阵对角占优：`P(actuator|actuator) ≥ 1−ε_ra`，`P(actuator|sensor) ≤ ε_ra`。二通道无法分开二者；三通道严格提升可辨识性。系：R69 的 FMA 对执行器故障是盲的。

**引理 21（再分配无级联条件）** `m′ = m − LΔ`；若 ∃健康 j 使 `m′_j < ρ`，则存在故障注入序列导致级联（新瓶颈→再次再分配→可能更差）。故 no-overload 是降级梯正确性的前置条件，ρ 至少覆盖 L 的模型误差。

**引理 22（交互耗尽鲁棒界）** 对抗性无信息回答可使 R69 后验不收敛而 VoI 保持正增益，交互时间无界；硬截止 `T_int` + 无进展计数保证最坏解决时间 ≤ `T_int`，超时强制 `rung ≥ r2`。

**定理 18（TRIAD 严格包含 R69）** A99–A103 下，对任意 h、ℱ：(i) 全健康且卸载可行 ⇒ `κ ≥ κ_R69`；卸载不可行 ⇒ 进 r2 且与 R69 λ_floor 逐指令相同；(ii) `μ_min < ρ` ⇒ 各档以认证命令收尾、最坏 r4 安全停，故 risk ≤ R69，且 r1 先于 r2 故 κ ≥ R69；(iii) 交互超时 / ECE 越界 / 健康不可观测时退回 R69 保守分支。故 TRIAD ⪰ R69；R69 = 「全健康 + 关闭卸载 + 交互无限」边界。

**定理 19（鲁棒能力证书有界性）** 在 A102–A103 与健康 CI 覆盖率 ≥ 1−δ 下：(a) 逐关节越界概率 ≤ ε_joint；(b) 能力下界 `κ_lb` 以概率 ≥ 1−δ 成立；(c) 降级梯 ≤ 4 级、有限时间终止，且 ℰ_joint（含交互耗尽）下最坏时间与风险有界。

## 7. 本轮最大风险

**一句话**：TRIAD 的能力保持押在「关节健康可观测、负载可转移」两条假设上——**而恰恰在真正需要它的退化外推区，这两条最不成立：健康估计误差最大、负载转移模型最不可靠，「卸载」可能把风险从被看见的弱关节悄悄转移给未观测的邻居，鲁棒性反而成为级联故障的放大器——修错，比不修更危险。**

**次级风险与缓解**：级联过载（no-overload 前置 + 余量 ρ + CG）；健康不可观测（HMG 门，CI 越界禁止卸载、退回 r2）；归因错误（三通道 FIC + 对角占优 + 审计回灌）；交互耗尽（T_int + 无进展计数 + 超时降级）；QP 实时性（健康路径零 QP、仅退化触发、失败即安全停）；关节隐蔽干扰（r_act 含力矩残差 + ℰ_joint 对抗训练）。
