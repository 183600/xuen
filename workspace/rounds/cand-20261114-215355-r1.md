# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉语言动作模型」×「虚拟仿真」）

> R69 让系统学会了「问」，但把全部效率收益押在「流模型的模态分布可信」上；其自陈最大风险——**问错，比不问更危险**——的本质是：**消歧的验证仍然发生在现实里，而现实是稀缺、不可逆、可被投毒的**。一次错误追问不仅浪费预算，还会把「诚实的不知道」升级为「被证实的错误」。
>
> 本轮两个灵感各补一块：
> - **视觉语言动作模型（VLA）** 把「视觉—语言—动作」压进同一个语义空间：每个动作模态可以有一个**名字**。语言不再只是问句的输出通道，而是可以用来**命名假设、交叉核对**的第三类观测。
> - **虚拟仿真** 给出一个可重复、可反事实、可廉价失败的地方：动作和追问都能**先排练**。仿真是证伪的廉价场所，却是确认的昂贵陷阱。
>
> 核心命题：**在 R69 的交互消歧之外再包一层「命名—排练—证伪」的虚拟验证；VLA 给模态命名并做语义核对，仿真只被允许「否决 / 缩减动作集」，永不被允许「授权」；只有通过可达性筛选、且跨仿真器稳健的歧义，才值得花一次真实交互，并且先用仿真问一遍看答案是否真的会改变决策。** 命名 **VIVID-RAS**（Vision-grounded Virtual Interaction & Dual-evidence RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**在真的问之前，我能不能先在脑子里演一遍**」——仿真不是现实，它只能帮你排除，不能替你相信。

## 0. 直觉与动机

**灵感 1（VLA → 名字是一种独立证据）**
直觉：R69 的模态是纯几何对象（轨迹原型 + 协方差），没有语义。但两个模态可能在动作空间离得很远、语义上却是同一件事（"绕过椅子左侧" vs "绕过椅子右侧"）；也可能动作几乎一样、语义完全相反（"接住" vs "推开"）。VLA 把 (o, ξ) 映射到语言标签，模态第一次**可以被说出名字**。命名带来三件新事：(a) **幻影检测**——流模型幻觉出的模态往往不可名状，或在几个名字之间摇摆；(b) **语义一致性**——动作名必须与场景名、指令名自洽；(c) **具名澄清**——问句从盲问变成"你是要我绕左还是绕右"。

**灵感 2（虚拟仿真 → 先排练，再花钱）**
直觉：R69 的 VoI 是对现实的期望，但现实的样本只有一次。仿真提供**反事实**：如果我问了，答案会不会改变决策？如果我走左，会不会真的到不了？这些都能先跑。关键的不对称是：**仿真的错误在安全侧可以被利用**——只要仿真只用来否决（仿真里撞了 → 不走），那么即使仿真是错的，最坏也只是变保守；一旦仿真用来授权（仿真里没事 → 走），仿真的错误就**直接变成现实的错误**。本轮把这条不对称写成架构铁律，而不是工程建议。

**灵感 3（命名 × 排练 → 幻影模态的双重筛）**
直觉：R69 最怕"追问一个幻影"。幻影通常同时具备两个特征：(1) 语义上说不清（VLA 给不出稳定名字，或两个相距很远的模态共用一个名字）；(2) 物理上不可实现（仿真里怎么试都抵达不了，或需要不可能的先验）。真实模态相反：有名有姓、可达、跨仿真器稳定。于是"名字 + 可达性 + 持久度"构成一道**不依赖流密度**的双重筛——这正好绕开 R69 的死穴：R69 用流模型自己验证流模型，本轮用两条**不同数据来源**的通道来验证它。

**灵感 4（仿真投毒 → 新的攻击面与"证书洗白"）**
直觉：一旦仿真进入安全路径，它就成了攻击目标。后门仿真器可在危险动作上返回"安全"；域随机化可掩盖系统性偏差；生成式世界模型会自信地幻觉出一个不存在的世界。更隐蔽的是**证书洗白**：一旦给仿真发一张"已校准"的证书，下游会比信任裸模型更信任它——**证书把模型误差洗成了制度性信任**。所以本轮必须同时交付：仿真对抗测试集、跨仿真器分歧作为异常信号、"仿真永不得单独定案"的证据记账、以及 gap 证书的失效检测。

**灵感 5（层次化 → R68 ⊂ R69 ⊂ R70）**
直觉：R69 把 R68 收编为"永不交互"边界；R70 应把 R69 收编为"零排练预算"边界。三层各回答一个问题：R68 用测量可信度决定**收紧多少**，R69 用歧义可约性决定**是否追问**，R70 用虚拟证伪决定**这个追问值不值得发生**。每一层只新增**建议通道**，不新增**执行权威**——这是保证"越加越安全"的唯一办法。若新层需要被独立信任，我们就是用一个黑箱去担保另一个黑箱。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（VIVID-RAS 总览）** VIVID-RAS = FLUID-RAS ⊕ (VLA-G, NCM, VSR, SRG, VETO, C-VoI, PIS)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **无新增执行权威**：VLA-G / NCM / VSR 只产出名字、可达性判定与否决；最终执行仍由 R69 的 C-RAS-WM 认证流策略给出；
(iii) **证伪不对称**：仿真只能缩小允许动作集，不能扩大；
(iv) **双证据**：仿真证据与真实证据分属不同数据族，仿真不得单独定案，真实单源也不得单独定案（继承 R69 定义 293-iii）。

**定义 311（VLA 语义桥 VLA-G）** 映射 g_φ: (o_t, ξ_{t:t+H}) → (ℓ, e)，ℓ 为有限语言标签，e ∈ ℝ^{d_e} 为语义嵌入；在（视觉, 语言, 动作）三元组上预训练，实时只做前向、不更新。对模态 m_k 得名字 ℓ_k 与嵌入 e_k。语义一致性 s_sem(k) = cos(e_k, e_inst) + 1[ℓ_k 与场景标签相容]，e_inst 为任务指令嵌入。

**定义 312（命名反事实模态 NCM）** 对每个模态 m_k 生成名字 ℓ_k，定义三类病理：
(a) **不可名状**：ℓ_k ∈ ∅，或 VLA 在 K 次重采样下名字熵 H(ℓ_k) > τ_name；
(b) **名字碰撞**：∃ i≠j，ℓ_i = ℓ_j 且 W_2(ξ̄_i, ξ̄_j) > Δ_collide；
(c) **名字分裂**：同一模态内名字不一致率 > τ_split。
命名一致性 C_name(k) = 1 − 三类病理的指示加权和。

**定义 313（可达性与幻影分）** 对模态 m_k 在仿真器集合 𝒮 上做可达性测试：从 o_t 出发、以 m_k 的动作原型为条件，测能否在预算内抵达该模态终态，得可达率 R_k = (1/M)Σ_j R_{k,j}，跨仿真器持久度 P_k = 1 − 2·std_j(R_{k,j})。幻影分
φ_k = 1 − [C_name(k) · R_k · P_k] ∈ [0,1]。
**φ_k > τ_phantom ⇒ 该模态不参与 VoI、不进入追问候选、也不被选为执行模态。**

**定义 314（虚拟仿真试验台 VSR）** 仿真器集合 𝒮 = {S_1,…,S_M}，S_j: (x_t, ξ) → (x_{t+1}, o_{t+1}, c_{t+1})。一次排练 Rehearse(ξ, o_t, B_sim) 在预算 B_sim 内给出结果分布 {τ_j}。排练对象既含任务动作 a，也含信息动作 g（尤其 g_ask：用一个参数化"人类模型"回答，见定义 318）。

**定义 315（仿真-现实差 SRG）** 在区域 z=(状态簇 × 动作簇) 上定义 gap 上界 δ(z) 与覆盖 1−α：以现实探针（R68 残差、R69 交互日志、真实执行结果）为标定样本，用保形预测 / 分位数回归给出 δ。若区域无足够真实样本，则 δ=+∞（**无证不仿真**）。许可证 L(z)=1 iff δ(z)<∞ 且该区域仿真器分歧 < τ_div。

**定义 316（仅证伪门 VETO）** 设 R69 给出的候选动作集为 𝒜_FLUID。VETO 输出
𝒜_VIVID = { a ∈ 𝒜_FLUID : ∀ S_j ∈ 𝒮_L, risk_sim(a; S_j) ≤ ε_int ∧ feasible_sim(a) }，
𝒮_L 为有许可证的仿真器子集。**恒有 𝒜_VIVID ⊆ 𝒜_FLUID。** 若 𝒜_VIVID=∅，不自动放行任何动作，而是回退到 R69 的保守分支（λ 上调 / 候选重采样 / 等待）。

**定义 317（反事实 VoI C-VoI）** 对信息动作 g，
VoI_C(g) = min_{π ∈ Π(𝒮_L)} E_{S~π}[ H(M|o) − E_{y~S(·|g,o)} H(M|o,y) ]，
即在有许可证仿真器集合上的**最坏情形**（或 CVaR）信息增益。仅当 VoI_C(g) − c(g) − κ·δ̄ > 0 才允许真实交互，δ̄ 为相关区域 gap 上界。⇒ 幻影模态在最坏情形仿真下几乎无信息增益，被自动筛掉。

**定义 318（预交互筛选 PIS）** 用参数化人类模型 H_ψ 作"仿真被问者"：对候选 g_ask，在仿真里得到回答分布；若在**所有**仿真器 / 人类模型下该回答都不改变后验决策（argmax 模态或 λ 档位不变），则 g_ask 的可执行性判为 0，不花真实交互。PIS 只剪枝、不确证。

**定义 319（证据正交性账本 EOL）** 证据按**数据族**分桶：𝒟_sem（VLA 视觉语言数据）、𝒟_dyn（仿真动力学数据）、𝒟_real（真实传感器/交互数据）、𝒟_flow（策略轨迹数据）。有效独立证据数 k_eff = 非空桶数，同桶多仿真器 / 多采样计为 1。族间错误相关 ρ_ij；错误采纳上界 ≤ δ_p·ρ_eff^{k_eff−1} + ε_σ（继承 R69 引理 18 的形式，但相关按族计）。

**定义 320（仿真投毒干扰集 ℰ_sim）** 后门仿真器（特定状态-动作返回安全）、域随机化掩盖的系统偏差、生成式世界模型幻觉、gap 利用（在 δ 估计不可靠处制造"仿真安全"）、奖励黑客（仿真奖励与真实代价错位）。ℰ_VIVID = ℰ_FLUID × ℰ_sim。

**定义 321（仿真课程飞轮 SCF）** 记录"真实结果与仿真预测分歧"的样本，按 分歧度 × 后果 排序，**离线**回灌以修正仿真器 / 人类模型 / gap 估计；实时流只读。与 R68 零学习写操作一致。

**定义 322（参与式审计 VQAuditor-V）** 新增审计项：是否用仿真单独授权（禁止）、gap 许可证是否在有效区域、幻影筛是否执行、PIS 是否误剪真实信息动作、EOL 是否把同族证据重复计数。结论回灌 AuditBuf。

**定义 323（证书 J_VIVID）** J_VIVID = (J_FLUID, gap_coverage, sim_disagreement, phantom_screen_rate, k_eff, rehearsal_budget_used, sim_audit_hash, vivid_ver)。Valid ⇔ Valid(J_FLUID) ∧ 许可证覆盖 ∧ 无仿真单独授权 ∧ EOL 一致 ∧ PIS 未违反召回下界。

**定义 324（三层退避）** 若仿真器分歧 > τ_div / 许可证缺失 / 幻影筛不确定 ⇒ U_epi 视为未消解 ⇒ 退 R69 保守；若再叠加流模态未校准（ECE > τ_ece）或 slow_fault ⇒ 退 R68 纯保守。三层按允许集单调：𝒜_VIVID ⊆ 𝒜_FLUID ⊆ 𝒜_CALM。

**定义 325（排练预算与时序）** 排练预算 B_sim（FLOPs / 墙钟）硬约束；排练必须 **anytime**：到截止时刻返回"当前最保守结论"。VSR 在实时环路之外以事件触发方式运行（歧义 / 新场景 / gap 告警），不占实时控制预算。

## 2. 关键算法骨架

```python
# IP-264 VLA-G：给模态命名并做语义核对（只读，不产生动作权威）
class VLAGroundingBridge:
    def name(self, o_t, mode):
        l, e = self.g(o_t, mode.prototype)          # 冻结 VLA，前向 only
        h = self.name_entropy(o_t, mode, k=5)        # 名字稳定性
        return l, e, h

# IP-265/313 NCM：命名病理 + 可达性 → 幻影分
def phantom_score(mode, names, sem, sims, o_t):
    R = [s.reachability(mode, o_t) for s in sims.licensed(o_t)]
    P = persistence(R) if R else 0.0
    C = 1.0 - pathology_weight(names, sem)           # 不可名状/碰撞/分裂
    return 1.0 - C * (sum(R) / len(R) if R else 0.0) * P

# IP-266/316 VSR+VETO：只在许可证区域内排练，且只允许缩减
def veto(candidates, o_t, sims, srg):
    allowed = set(candidates)
    for a in candidates:
        if not srg.licensed(o_t, a):
            continue                                  # 无证不仿真：不扩不缩，交回 R69
        lic = sims.licensed(o_t)
        if any(not s.feasible(a, o_t) for s in lic) or max(s.risk(a, o_t) for s in lic) > EPS_INT:
            allowed.discard(a)                        # 仅删除
    return allowed                                    # 恒 ⊆ candidates

# IP-269/317 C-VoI：最坏情形信息增益，幻影自动无收益
def counterfactual_voi(g, modes, sims, gap, region):
    gains = [entropy_after(g, modes, s) for s in sims.licensed(region)]
    return min(gains) - KAPPA * gap.bound(region)

# IP-270 PIS：在仿真里先问一遍，答案不改变决策就不问
def pre_interaction_screen(g_ask, modes, human_models):
    return any(decision_changes(answer_distribution(g_ask, h, modes)) for h in human_models)

# IP-276 主闭环（= R69 闭环 + 排练层；实时环路不变）
def VIVID_RAS_round(M, obs):
    # --- 实时路径（继承 R69，<2.6ms） ---
    k, lam, mode, U = FLUID_RAS_round(M, obs)         # R69 原样不改
    # --- 事件触发的排练路径（非实时） ---
    if M.trigger.ambiguity(U) or M.trigger.new_scene(obs):
        screened = []
        for m in M.aud.modes:
            l, e, h = M.vla.name(obs, m)
            if M.ncm.phantom_score(m, l, h, M.sim, obs) >= TAU_PHANTOM:
                continue                              # 幻影：不进追问候选
            screened.append(m)
        g = None
        if screened:
            cands = M.mint.info_candidates(screened)
            cands = [c for c in cands
                     if counterfactual_voi(c, screened, M.sim, M.srg, M.region(obs)) > M.cost(c)]
            cands = [c for c in cands if M.pis.answer_would_change(c, screened, M.human)]
            g = M.veto.choose(cands, obs, M.sim, M.srg)   # 只缩减，绝不新增
        if g is not None:
            answer = M.cia.execute(g)                 # 真实交互，仍受 R69 证据纪律
            U = M.cia.update_belief(screened, answer)
        if M.veto.empty(g):                           # 仿真把候选全否决
            k, lam = M.fallback_to_fluid(k, lam, U)   # 回 R69 保守，而非放行
    # --- 审计与飞轮（离线 / 异步） ---
    M.vqa_v.submit(M.sim.last_rollouts, M.srg.gap, M.eol.ledger, g)
    M.scf.record_disagreements_async(M.sim.predictions, M.real.outcomes)
    return k, lam, mode, U
```

## 3. 推导

**引理 19（仅证伪的保安全性 / 保真度无关）** 设对任意状态与任意（包括错误或被投毒的）仿真器都有 𝒜_VIVID(s) ⊆ 𝒜_FLUID(s)，执行器与 R69 相同，且 λ 不低于 R69。则逐状态实现风险 R_VIVID(s) ≤ R_FLUID(s)。要点：风险泛函在允许集包含下单调（可选集变小，同一保守选择规则下的期望代价不增），λ 单调与认证不变式保证执行侧不变差。**这条引理不需要仿真正确——这正是把仿真放进安全路径的唯一合法方式。** 系：仿真的全部价值在效率（少问、少试），不在安全；任何"仿真说安全所以更激进"的设计都越界。

**引理 20（幻影筛的可实现性上界）** 设幻影模态不可达概率 ≥ 1−ε_R，VLA 名字病理在幻影上的检出率 ≥ 1−ε_N，则一个幻影进入真实追问的概率 ≤ (ε_R + ε_N)·π_act·π_voi，π_act 为 C-VoI 未筛比例，π_voi 为 PIS 未剪枝比例。要点：两条通道数据来源不同（语义 vs 动力学），错误弱相关，联合漏检率乘性下降；但若二者共因（同一场景编码器 / 同一训练分布），相关系数 ρ↑，增益退化——这正是 EOL 必须按数据族记账的原因。

**引理 21（gap 许可证的证伪可靠性）** 若区域 z 上 gap 上界 δ(z) 以 1−α 覆盖真实 sim-real 偏差，且被否决动作在仿真中的风险超出 ε_int 的裕度 > δ(z)，则否决是安全侧可靠的（误杀真实安全动作的概率 ≥ 1−α 在界内）；反之若裕度 ≤ δ(z)，否决可能由 gap 而非真实风险引起——此时按定义 316 只是**更保守**，不构成安全违背。注意：这条只覆盖**否决**；若用于确认，同样的 δ 会让危险动作以约 α 的概率被放行——所以我们从不确认。

**定理 18（VIVID 严格包含 FLUID）** 在 A95–A100 下，对任意状态 𝒜_VIVID ⊆ 𝒜_FLUID，风险 VIVID ≤ FLUID；且当排练预算 B_sim=0、许可证缺失、仿真器分歧 > τ_div、或幻影筛不确定时，VIVID 与 FLUID 逐指令相同（定义 324）。因此 R69 是 R70 在"不排练"边界的退化；结合 R69 定理 16 得 R68 ⊂ R69 ⊂ R70 的三层包含。效率收益来自 PIS（少问）与 VETO（少试），安全侧不新增任何假设。

**定理 19（幻影-投毒联合上界）** 结合引理 20 与 EOL 的族相关界，错误采纳率 ≤ [ (ε_R+ε_N) + δ_p·ρ_eff^{k_eff−1} ]·π_act + ε_σ。当 k_eff≥2 且 ρ_eff<1 时，增加一个**正交证据族**（真实→仿真→语义）严格降低上界；**但三个仿真器变体只算一簇，不降低上界**——这是"多跑几个 seed 就以为更可信"的常见错误。

**定理 20（建议层无突变）** VLA-G / NCM / VSR 均不进入执行链；实时路径仍由 R69 的 certified_prefix + λ 决定；排练 anytime 且位于实时环路之外，超时返回保守结论。故控制连续性与换装不变式（R69 定理 17）保持；新增层可随时关闭而不破坏安全性，只损失效率。

## 6. 本轮最大风险

**一句话**：VIVID 把仿真放进了安全论证，却把仿真的可信度押在一张**由稀缺真实数据标定出来的 gap 证书**上；一旦这张证书在分布外被高估（仿真在简单区域很准、在关键长尾悄悄偏），"已认证的仿真"会比裸模型更危险——它把模型误差**洗成了制度性信任**，让系统在最该保守的地方显得最有把握。

**次级风险与缓解**：
1. **证书洗白 / gap 低估** → SRG 保形覆盖 + 区域外自动失效 + 许可证而非全局证书（定义 315）；
2. **仿真后门与投毒** → 跨仿真器分歧 + ℰ_sim 对抗测试 + 仿真永不单独授权（定义 316、320）；
3. **VLA 语义幻觉** → 名字只作证据不作权威 + 三类命名病理 + EOL 族记账（定义 312、319）；
4. **PIS 误剪真实信息动作** → 只剪枝不确证 + 召回下界约束 + E304 监控（定义 318）；
5. **排练击穿时序/能耗** → 排练在实时环外、anytime、事件触发（定义 325）。

**本轮结论（一句话风险）**：真正危险的不是仿真不准，而是我们给"不准的仿真"发了一张看起来很像真的证书——**被认证的仿真比裸奔的模型更容易被信任，也更难被纠错。**

# IP-264 VLA-G：给模态命名并做语义核对（只读，不产生动作权威）
class VLAGroundingBridge:
    def name(self, o_t, mode):
        l, e = self.g(o_t, mode.prototype)           # 冻结 VLA，前向 only
        h = self.name_entropy(o_t, mode, k=5)         # 名字稳定性
        return l, e, h

# IP-265/313 NCM：命名病理 + 可达性 → 幻影分
def phantom_score(mode, names, sem, sims, o_t):
    R = [s.reachability(mode, o_t) for s in sims.licensed(o_t)]
    P = persistence(R) if R else 0.0
    C = 1.0 - pathology_weight(names, sem)            # 不可名状/碰撞/分裂
    return 1.0 - C * (sum(R) / len(R) if R else 0.0) * P

# IP-266/316 VSR+VETO：只在许可证区域内排练，且只允许缩减
def veto(candidates, o_t, sims, srg):
    allowed = set(candidates)
    for a in candidates:
        if not srg.licensed(o_t, a):
            continue                                   # 无证不仿真：不扩不缩
        lic = sims.licensed(o_t)
        if any(not s.feasible(a, o_t) for s in lic) or max(s.risk(a, o_t) for s in lic) > EPS_INT:
            allowed.discard(a)                         # 仅删除
    return allowed                                     # 恒 ⊆ candidates

# IP-269/317 C-VoI：最坏情形信息增益，幻影自动无收益
def counterfactual_voi(g, modes, sims, gap, region):
    gains = [entropy_after(g, modes, s) for s in sims.licensed(region)]
    return min(gains) - KAPPA * gap.bound(region)

# IP-270 PIS：在仿真里先问一遍，答案不改变决策就不问
def pre_interaction_screen(g_ask, modes, human_models):
    return any(decision_changes(answer_distribution(g_ask, h, modes)) for h in human_models)

# IP-276 主闭环（= R69 闭环 + 排练层；实时环路不变）
def VIVID_RAS_round(M, obs):
    k, lam, mode, U = FLUID_RAS_round(M, obs)          # R69 原样，实时 <2.6ms
    if M.trigger.ambiguity(U) or M.trigger.new_scene(obs):
        screened = []
        for m in M.aud.modes:
            l, e, h = M.vla.name(obs, m)
            if M.ncm.phantom_score(m, l, h, M.sim, obs) >= TAU_PHANTOM:
                continue                               # 幻影：不进追问候选
            screened.append(m)
        g = None
        if screened:
            cands = M.mint.info_candidates(screened)
            cands = [c for c in cands
                     if counterfactual_voi(c, screened, M.sim, M.srg, M.region(obs)) > M.cost(c)]
            cands = [c for c in cands if M.pis.answer_would_change(c, screened, M.human)]
            g = M.veto.choose(cands, obs, M.sim, M.srg)  # 只缩减，绝不新增
        if g is not None:
            U = M.cia.update_belief(screened, M.cia.execute(g))   # 真实交互 + R69 纪律
        if M.veto.empty(g):
            k, lam = M.fallback_to_fluid(k, lam, U)    # 全被否 ⇒ 回 R69 保守
    M.vqa_v.submit(M.sim.last_rollouts, M.srg.gap, M.eol.ledger, g)
    M.scf.record_disagreements_async(M.sim.predictions, M.real.outcomes)
    return k, lam, mode, U

## 4. 推导

**引理 19（仅证伪的保安全性 / 保真度无关）** 若 ∀s：`𝒜_VIVID(s) ⊆ 𝒜_FLUID(s)`，执行器与 λ 不低于 R69，则逐状态风险 `R_VIVID ≤ R_FLUID`，**与仿真器是否准确无关**。系：仿真的价值在效率（少问、少试），不在安全；"仿真说安全所以更激进"越界。

**引理 20（幻影筛上界）** 幻影进入真实追问的概率 ≤ `(ε_R+ε_N)·π_act·π_voi`；语义与动力学两通道数据来源不同、错误弱相关，漏检乘性下降；若共因则 ρ↑、增益退化——故 EOL 按族记账。

**引理 21（gap 许可证的证伪可靠性）** 若 `δ(z)` 以 `1−α` 覆盖真实 sim-real 偏差且否决裕度 > δ，则否决安全侧可靠；裕度 ≤ δ 时只是更保守、非安全违背。**此引理只覆盖否决**；若用于确认，同一 δ 会让危险动作以约 α 概率被放行。

**定理 18（VIVID 严格包含 FLUID）** A95–A100 下 `𝒜_VIVID ⊆ 𝒜_FLUID`，风险 VIVID ≤ FLUID；当 `B_sim=0`、无许可证、仿真器分歧 > τ_div、幻影筛不确定时逐指令相同。结合 R69 定理 16 得 `R68 ⊂ R69 ⊂ R70`。

**定理 19（幻影-投毒联合上界）** 错误采纳率 ≤ `[(ε_R+ε_N) + δ_p·ρ_eff^{k_eff−1}]·π_act + ε_σ`。新增**正交证据族**严格降界；**多个仿真器 seed 只算一簇，不降界**。

**定理 20（建议层无突变）** VLA-G/NCM/VSR 不入执行链；实时路径仍由 certified_prefix + λ 决定；排练 anytime 且环外，超时返回保守结论；R69 定理 17 的无突变与换装不变式保持。

## 7. 本轮最大风险

**一句话**：VIVID 把仿真放进了安全论证，却把仿真的可信度押在一张**由稀缺真实数据标定出来的 gap 证书**上；一旦这张证书在分布外被高估，"已认证的仿真"会比裸模型更危险——它把模型误差**洗成了制度性信任**，让系统在最该保守的地方显得最有把握。

**次级风险与缓解**：证书洗白 / gap 低估（SRG 保形覆盖 + 区域外失效 + 许可证非全局证书）；仿真后门与投毒（跨仿真器分歧 + ℰ_sim + 永不单独授权）；VLA 语义幻觉（名字只作证据 + 三类病理 + EOL 族记账）；PIS 误剪（只剪枝不确证 + 召回下界 + E304）；排练击穿时序（环外 + anytime + 事件触发）。

**本轮结论（一句话风险）**：真正危险的不是仿真不准，而是我们给"不准的仿真"发了一张看起来很像真的证书——**被认证的仿真比裸奔的模型更容易被信任，也更难被纠错。**
