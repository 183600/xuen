# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「UniBot」×「无刷电机」）

> R69 把「不确定性」从一根标量刹车杆拆成 aleatoric 与 epistemic 两支，并让系统学会「问」——看、触、追问。但它对 epistemic 的整个处理都压在一个从未被检验的假设上：**被问的那个隐藏状态，是「在那里、只是模糊」的**。「绕左还是绕右」之所以能被消歧，是因为证据存在、只是还没去取。无刷电机恰好提供了一个反例，而且是最硬的那个：**无刷无感（sensorless）控制在零速/低速时，转子电角度 θ_e 在终端电压电流里根本不可观测**——反电动势 e = k_e·ω，ω→0 则 e→0，观测性矩阵秩亏。这不是「模糊」（ambiguous），是「不可见」（unobservable）。再多的被动观察也问不出来；唯一的出路是**主动往电机里注入一个高频探测信号**，靠磁凸极（L_d ≠ L_q）的电流响应把位置「照」出来。这正是 R69 的信息动作，只是它第一次有了真实的物理单位：安培、牛·米、开尔文。
>
> 与此同时，「UniBot」把另一处隐患推到台前：如果一套流策略要服务许多不同的机体（跨体/通用机器人），那么 R69 算出的模态权重 p(m|o) 其实是**对机体身份的边缘化**：p(m|o) = Σ_b p(b|o)·p(m|o,b)。看上去是「任务歧义」（两个都合理的任务动作），很可能是「机体歧义」（不知道自己是哪台电机、哪组参数）。**问人问不出机体的凸极比。** R69 的两分法（ale / epi）无法表示这第三类不确定性。
>
> 核心命题：**在任务层之下补一条「可观测性—可辨识性」底座。把不确定性三分 (U_ale, U_emb, U_epi)，并用一个「下层不通、上层无意义」的严格门控把 R69 的任务层 VoI 挂在这条底座上：执行器状态不可观测时，任何任务层信息增益都是伪的。** 命名 **EXCITE-RAS**（Excitation-gated Cross-embodiment Identifiability & Task-Epistemic decomposition for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我此刻到底看得见吗；如果看不见，我能往系统里打一束什么光**」。

## 0. 直觉与动机

**灵感 1（无刷电机 → 最深的不确定性不是「模糊」，而是「不可观测」）**
直觉：R69 把 epistemic 想成「证据在那儿、只是还没取」。可无感无刷电机告诉我们，存在一种更底层的情形：**证据在物理上就不在终端量里**。PMSM 的 d-q 电压方程是
`v_d = R i_d + L_d di_d/dt − ω_e L_q i_q`，`v_q = R i_q + L_q di_q/dt + ω_e(L_d i_d + ψ_f)`。
位置信息只通过含 ω_e 的两项（反电动势 ω_e ψ_f 与交叉耦合）进入；ω_e → 0 时两项同时消失，θ_e 从基频终端量里**不可观测**。这不是「噪声大」，而是「秩亏」——再怎么滤波也变不出来。要恢复，只能主动：在估计 d 轴注入高频电压 `u_h = V_h cos(ω_h t)`，凸极使电流响应含 `sin(2Δθ)` 分量，于是位置被「照」出来。**R69 的 VoI 不是隐喻了，它变成了一个可以按焦耳计价的物理探针。** 这也让我们能把 aleatoric 与 epistemic 的分界线从「能不能问」升级为「在不在可观测子空间里」。

**灵感 2（换相 → 最低层的「模式选择」错一个扇区就是转矩反转）**
直觉：六步换相的「动作模式」就是 6 个扇区中选一个通电；FOC 里则等价于用 θ̂_e 做 Park 变换。换相误差角 Δθ = θ̂_e − θ_e 使输出转矩近似正比于 cos(Δθ)；Δθ = 60° 时掉一半，Δθ ≥ 90° 时**转矩反号**——电机不是「慢一点」，而是被反向拖拽、电流飙升、可能去磁。R69 担心的「选错模式」在任务层还只是绕错路；在执行器层它是瞬时、不可逆的物理事故。于是安全必须**分层**：电学/热学包络（电流、母线电压、弱磁、去磁、结温）比运动学包络（R68 的 C-RAS-WM）更根本，任务层证书只有在下面几层都 valid 时才 valid。

**灵感 3（UniBot → 一个策略、多个身体：模态权重其实是「身体的混合」）**
直觉：跨体通用机器人（UniBot）意味着同一套流策略要覆盖不同极对数、不同 R/L/k_e、不同凸极比的机体。此时 `p(m|o) = Σ_b p(b|o)p(m|o,b)`。R69 看到双峰就以为「任务有歧义，去问人」；但那两峰可能只是「两台电机各自唯一正确的行为」。这类歧义**问人无效、问环境也无效**，只能靠**辨识激励**（d-q 扫频、d 轴阶跃）去识别自己是谁。把 U_emb 误判成 U_epi，系统就会去追问一个幻影式的「意图」；误判成 U_ale，它就会永远减速。所以三分不够，还要**有序**：先观测性、再可辨识性、最后才是任务认知。

**灵感 4（三层门控 → 观测性先于可辨识性，可辨识性先于任务认知）**
直觉：三层之间有天然的**蕴含关系**：任务层的信息增益是「在给定状态估计 x̂ 下」算的；若 x̂ 本身落在不可观测子空间，这个增益就是**伪的**（spurious）——不是偏小，而是无意义。同理，若机体参数 ĉ 不确定，则 p(m|o, ĉ) 的模态权重连「属于哪个身体」都没定，谈任务歧义是空中楼阁。于是本轮的理论对象不只是「三分」，而是一个**门控的层次化 VoI**：`G_obs → G_id → VoI_task`，下层不开，上层记为 ⊥。这是不确定性处理上的**分离原理**（separation principle），而非简单相加。

**灵感 5（反作用 → 主动激励会改变被测量的系统）**
直觉：高频注入不是免费的：注入电流产生转矩纹波、铜损与铁损、可听噪声；高速时又被反电动势淹没。更微妙的是**反作用（back-action）**：探针在测位置的同时也在改变电磁状态，磁饱和、交叉耦合、死区会让响应里混进与真实转子同频的畸变，产生一个**自洽但错误**的 θ̂_e。R69 的「k 个证据源一致」在这里可能失效，因为两个「独立」的物理通道可能共享同一个饱和畸变源。所以本轮必须新增一条物理版证据纪律：**探针响应必须与自身副作用可分（probe separability）**，否则判为伪观测、不准定案。这是把 R69 的「社交正交」升级为「物理正交」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（EXCITE-RAS 总览与四不变式）** EXCITE-RAS = (OMG, EID, HVI, CFP, LSC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；执行器快环（电流环 10–20 kHz）只允许固定速率观测器与查表，不允许在线梯度；
(ii) **观测性优先门控**：任何任务层 VoI 决策必须在 G_obs = 1 且 G_id = 1 之后才被允许定义与使用，否则记为 ⊥ 并走保守退化；
(iii) **激励预算与反作用上界**：单位时间的注入能量 E_inj、转矩纹波 τ_ripple、温升 ΔT 均 ≤ 各自硬上界，且激励不得把系统推出任何一层安全包络；
(iv) **分层且分体的证书**：每个机体 b 持有 J_EXCITE^(b)，禁止用一个全局 ECE 掩盖分体失准（定义 318）。

**定义 311（隐藏状态分层）** 隐藏状态 x = (θ_e, ω_e, i_dq, T_w, b)。b ∈ {1..B} 为机体/参数身份，含 (R, L_d, L_q, k_e, p, ψ_f)。任务层观测 y_task，执行器层观测 y_act = (v_a,v_b,v_c, i_a,i_b,i_c)。三层估计并列：状态估计 x̂（观测器/EKF）、参数估计 ĉ（辨识）、任务模式后验 w（R69 FMP）。

**定义 312（被动可观测性指数）** 对线性化 PMSM 模型 Σ(ω_e)，取离散可观测性矩阵 O_m。定义 `o_idx(ω_e) = σ_min(O_m)/σ_max(O_m)`。因位置信息仅经含 ω_e 的反电动势与交叉耦合项进入，故 `o_idx(0) = 0`：θ_e 不可从基频终端量被动观测。被动门 `G_obs^pass = 1[o_idx ≥ o_min]`。注意 o_idx 是**结构性质**，与传感器噪声无关——加滤波器不改变秩。

**定义 313（主动可观测性与 HFI）** 在估计 d 轴注入 `u_h = V_h cos(ω_h t)`。凸极比 ξ = L_q/L_d；电流响应中的 `sin(2Δθ)` 分量幅值 ∝ `(1/ξ − 1)·V_h/ω_h`。定义主动可观测性 `o_act(V_h, ω_h, ξ)`：仅当 ξ ≠ 1 且 ω_h ≫ ω_e 且 ω_h 低于开关频率约束时为正。总可观测性 `o_total = max(o_pass, o_act·1[注入激活])`。**表贴式永磁（ξ ≈ 1）在零速下结构上不可探**——这是"有些身体天生问不出来"的硬事实。

**定义 314（激励动作与增广动作空间）** R69 的信息动作 g 扩为激励 `e = (e_phys, e_id, e_soc)`：
- `e_phys = (V_h, ω_h, 注入轴, 时长)`：HFI 探针，恢复 θ_e 可观测；
- `e_id = 参数激励轨迹`（d-q 扫频 / d 轴阶跃 / 弱磁段），辨识 ĉ；
- `e_soc = g`（R69 的注视/触/问句）。
增广动作 `ξ = (a, e)`，分别对应三层不确定性。

**定义 315（反作用与净观测增益）** 执行 e_phys 的副作用为 `β(e) = (Δτ_ripple, Δloss, ΔT)`。定义净观测增益
`VoI_obs(e) = H(θ_e | y_act) − E_{y'~p(·|e)}[H(θ_e | y_act, y')] − c_β(β(e))`，
并定义**探针可分性** `sep(e) ∈ [0,1]`：探针诱发响应与真实转子项在物理特征（频率、注入轴、q/d 比）上可分的程度。`sep(e) < sep_min` ⇒ 该激励不得用于定案（伪观测防护）。

**定义 316（层次化 VoI 门控）** 定义
`VoI_hier = 1[G_obs] · ( VoI_obs(e_phys) + 1[G_id] · ( VoI_id(e_id) + 1[G_obs] · VoI_task(e_soc) ) )`。
语义：下层未解，上层项按定义取 0（⊥），不是"权重变小"。等价表述：`VoI_task` 的定义域是 `{G_obs=1 ∧ G_id=1}`；在其外，`VoI_task ≡ ⊥`。

**定义 317（不确定性三分与伪任务歧义）** `U = (U_ale, U_emb, U_epi)`：
- `U_ale = Σ_k ŵ_k tr(Σ_k)`（R69 模态内 + 齿槽转矩/PWM 量化/传感噪声，不可约）；
- `U_emb = H(b | o)`（机体/参数不确定性，可由 e_id 降低）；
- `U_epi = H_mode · g(Δ_min)`（R69 任务模式歧义，可由 e_soc 降低）。
定义**仿真任务歧义子空间**：若 `H(m|o)` 中可由 `H(b|o)` 解释的部分占比 ≥ ρ_emb，则判为 embodiment-induced，须先解 U_emb 再谈 U_epi。三者语义不同，不做简单加和。

**定义 318（分层校准门 MCG-S）** 全局模态校准误差 `ECE = Σ_b p(b) ECE_b + cross`，其中 cross 可为负（Simpson 型抵消）。定义分层门：`G_cal = 1[∀b ∈ 活跃机体: ECE_b ≤ τ_ece]`。`G_cal = 0` ⇒ 该机体的 VoI 决策禁用，退回 R68 纯保守。证书按 b 分别签发。

**定义 319（换相安全包络与转矩反转约束）** 换相误差 Δθ = θ̂_e − θ_e，近似 `τ ≈ τ* cos(Δθ)`。硬约束 `|Δθ| < Δθ_max`（默认 60°），并设绝对红线 `|Δθ| ≥ 90° ⇒ 立即切强制换相`。任何 e_phys 在激活期间必须给出 Δθ 的可证上界；不可证则不用该激励。

**定义 320（分层安全证书）** 安全分层为 `(J_elec, J_therm, J_kin, J_task)`：J_elec（相电流/母线电压/弱磁/去磁边界）、J_therm（绕组与结温）、J_kin（R68 C-RAS-WM 运动学包络）、J_task（R69 J_FLUID）。Valid 律：`Valid(J_kin) ⇒ Valid(J_elec) ∧ Valid(J_therm)`，即下层不 valid 则上层无意义。新增层只会收紧，不会放宽。

**定义 321（静默区与驻留规则）** 定义可观测速度阈 ω_obs。`|ω_e| < ω_obs` 且 `o_idx < o_min` 为静默区。规则：在静默区驻留超过 `t_hfi` 必须注入 HFI（若机体可探），或进入强制六步换相（保守但低效）；不得在静默区用 x̂ 计算任务层 VoI。

**定义 322（物理正交证据纪律）** 执行器层证据集 `E_act = {θ̂_e^bemf, θ̂_e^hfi, θ̂_e^flux-observer}`。要求任意两次定案至少两条**物理正交**通道一致（定义 A99：不同频率/注入轴/估计机理），且 `sep(e) ≥ sep_min`。若一致但 sep 低，判为共源畸变（伪观测），不得定案。这是 R69 定义 293-iii 的物理版。

**定义 323（跨体流策略 CFP）** 速度场 `v_θ(x_s, s | z, ĉ, Σ_ĉ)`，其中 z 为 R69 MTM trunk 表征，`ĉ` 经 adaLN/条件适配器注入（复用 trunk，零重复训练）。模式权重记 `p(m | o, b)`；未辨识 b 时输出混合物 `Σ_b p(b|o) p(m|o,b)`。

**定义 324（可辨识性指数）** 机体参数的 Fisher 信息矩阵 F(ĉ)。`i_idx = λ_min(F)`。低 i_idx ⇒ 参数不可辨（如 ξ≈1 时凸极不可辨、或激励轨迹未激发该参数）。辨识门 `G_id = 1[i_idx ≥ i_min]`。

**定义 325（激励预算与任务冲突）** 激励占用能量 E_inj、纹波 τ_ripple、温升 ΔT 与**时间**（挤占任务进度）。定义激励-任务冲突：若激励使任务动作偏离 J_kin 或不满足 J_elec/J_therm，则必须推迟/缩小/放弃激励，此时该层不确定性保持未解并向下传递为保守。

**定义 326（EXCITE 证书 J_EXCITE）** `J_EXCITE = (J_FLUID, o_idx, i_idx_p95, G_obs, G_id, G_cal, τ_ripple_p95, ΔT_p95, ECE_b, sep_min, embodiment_id_hash, excite_ver)`。Valid ⇔ Valid(J_FLUID) ∧ G_cal ∧ 反作用上界满足 ∧ 伪观测检测通过 ∧ 分层安全 valid。

```python
# IP-264 OMG：执行器可观测性监测与门（快环，固定速率、零学习）
class ObservabilityGate:
    def __init__(self, bemf_obs, hfi):
        self.bemf, self.hfi = bemf_obs, hfi
    def passive(self, y_act, omega):
        o_idx = self.bemf.min_singular_ratio(omega)   # ω→0 ⇒ o_idx→0（秩亏）
        return o_idx, (o_idx >= O_MIN)
    def active(self, y_act):
        return self.hfi.estimate(y_act)               # 返回 θ̂_e^hfi 与 sep

# IP-265 EID：激励与可辨识性导演（三层各自的信息动作）
def choose_excitation(need, y_act, budget, safety):
    cands = []
    if need == 'obs':
        for e in hfi_candidates():                    # V_h, ω_h, 注入轴, 时长
            if not budget.allow(e) or not safety.electrical(e): continue
            if probe_separability(e, y_act) < SEP_MIN: continue   # 防伪观测
            cands.append((e, voI_obs(e, y_act) - cost_beta(e)))
    elif need == 'id':
        for e in id_trajectories():                   # d-q 扫频 / d 轴阶跃
            if not budget.allow(e) or not safety.electrical(e): continue
            cands.append((e, voI_id(e, y_act) - cost_beta(e)))
    if not cands: return None
    e, score = max(cands, key=lambda t: t[1])
    return e if score > 0 else None

# IP-266 HVI：层次化 VoI（下层不开，上层记 ⊥）
def hierarchical_voi(G_obs, G_id, w, g):
    if not G_obs:  return ('obs_first', None)         # 任务 VoI 无定义
    if not G_id:   return ('id_first',  None)         # 先辨识机体
    return ('task', entropy(w) - expected_entropy(w, g))

# IP-267 CFP：跨体流策略（条件于辨识参数 ĉ）
class CrossEmbodimentFlow:
    def sample(self, o, chat, Sig_chat, K, N_step=2):
        z  = self.trunk(o)
        zc = self.emb_adapter(z, chat, Sig_chat)      # adaLN 条件化
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, zc)
        return [self.decode(x) for x in xs]           # ξ = (a, e)

# IP-268 LSC：分层安全证书（下层不 valid 则上层无效）
def layered_certificate(action, e, st):
    return (cert_electrical(e, st) and cert_thermal(st)
            and cert_kinematic(action, st) and cert_task(action, st))

# IP-274 主闭环
def EXCITE_RAS_round(M, y_task, y_act):
    # 1) 最底层门：执行器看得到吗？
    o_idx, G_obs = M.omg.passive(y_act, M.omega)
    if not G_obs:
        e = M.eid.choose_excitation('obs', y_act, M.budget, M.elec_safety)
        if e is not None:
            M.apply_excitation(e)                     # HFI 注入
            th, sep = M.omg.active(M.sense())
            G_obs = (sep >= SEP_MIN) and M.omg.passive(M.sense(), M.omega)[1]
        if not G_obs:
            return M.forced_commutation()             # 静默区：强制六步退化
    # 2) 机体可辨识门
    G_id, chat, Sig = M.eid.identify(y_act, M.excite_hist)
    if not G_id:
        e = M.eid.choose_excitation('id', y_act, M.budget, M.elec_safety)
        if e is not None:
            M.apply_excitation(e); G_id, chat, Sig = M.eid.identify(M.sense(),
                                                                    M.excite_hist)
    # 3) 任务层（R69 FLUID），条件于 ĉ、且被下层门控
    z, o = M.mtm.forward(y_task)
    K = 1 if M.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, chat, Sig, K)           # CFP
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    G_obs2, G_id2 = M.omg.passive(M.sense(), M.omega)[1], G_id
    g = None
    if G_obs2 and G_id2 and U_epi > TAU_EPI:
        g = M.mint.choose_interaction(modes, o, M.budget)   # R69
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 4) 风险缩放：下层未解的不确定性一律并入保守项
    U_unres = U_ale + (0.0 if g is not None else U_epi)
    if not G_obs: U_unres += U_emb_bound(M)
    lam = max(M.efs.risk_scale(...), lam_floor(U_unres))
    # 5) 分层证书 + 换相误差约束
    A  = M.ach.propose(x_prime, H=M.vista.H)
    k  = M.c_ras_wm.certified_prefix(A, ..., theta_hat=th)
    if not M.lsc.validate(A, None, M.state):
        k = M.lsc.shrink_until_valid(A)               # 电学/热学收紧
    # 6) 参与式审计 + 分体证书
    M.vqa_e.submit_async(e, g, U_emb, o_idx, sep, chat)
    return k, lam, th, (U_ale, U_emb, U_epi)
```

## 3. 推导

**引理 19（可观测性门控的必要性 / 无伪 VoI）** 设 θ_e 在不可观测子空间 V_⊥ 上的先验协方差为 Σ_⊥。若在 `G_obs=0` 时仍用 x̂ 计算任务层 VoI，则其与真实信息增益的期望偏差满足 `|E[VoI(x̂) − VoI(x)]| ≥ c · tr(P_⊥ Σ_⊥ P_⊥)`，c > 0 只依赖任务动作对 θ_e 的灵敏度。即：门控不是"更保险的选择"，而是**避免一个可正可负、量级正比于不可观测方差的系统性错误**。系：任务层 VoI 的定义域必须显式写成 `{G_obs=1}`。

**引理 20（HFI 的可观测性恢复与反作用权衡）** 设凸极比 ξ = L_q/L_d，注入轴为估计 d 轴。则 (a) θ_e 可由 HFI 可辨 ⇔ ξ ≠ 1 且 ω_h ≫ ω_e（避开基频）且 ω_h 低于逆变器开关频率可分辨上限；(b) 位置估计方差 `Var(θ̂_e) ∝ (ω_h / ((1/ξ − 1) V_h))² · σ_n²`，随 V_h 增大而下降；(c) 反作用 `β ∝ V_h · i_q · (注入轴泄漏量)`，转矩纹波与损耗随 V_h 上升。故净观测增益 `VoI_obs(V_h)` 存在内点最优 `V_h*`；当 ξ → 1（表贴式）时 (a) 失效、`V_h* → ∞`，此时**任何有限注入都不可辨**，必须退化到强制换相/外置编码器。这条把"R69 说去问"变成"有些身体根本问不出来"。

**引理 21（跨体模态校准的 Simpson 悖论）** 存在机体分布与各体偏差，使 `ECE_global ≤ τ_ece` 而 `Σ_b p(b) ECE_b > τ_ece`。证明：由 `ECE_global = Σ_b p(b)ECE_b + cross`，各体的系统性同号偏差可被 `cross < 0` 抵消。系：**全局模态校准门不安全**，必须用定义 318 的分体门 MCG-S；否则一台机体的坏校准会被另一台"抵消"成合格，跨体策略在每台机上都自信地错。

**定理 18（EXCITE 的分层严格包含与安全单调性）** 在 A95–A99 下：
(a) 当 `G_obs=0` 时，EXCITE 逐指令输出强制换相/最小安全动作，其物理风险 ≤ R69 在同等错误 x̂ 下的输出（因为 R69 会用伪 VoI 选模态）；
(b) 当 `G_obs=1 ∧ G_id=1` 时，U_emb 已由辨识消解、参数退化为常数，EXCITE 的决策与 R69 逐指令一致（保留 FLUID 的 resolution bonus）；
(c) 由于 `Valid(J_kin) ⇒ Valid(J_elec)∧Valid(J_therm)`，新增分层只会收紧安全集，不会放宽。
故 R69 是 EXCITE 在"执行器完全可观测 + 机体已知"边界上的严格退化，R68 是再退化；安全侧单调不劣，效率侧只在可认证时保留红利。

**引理 22（物理正交证据下伪观测的可检测性）** 设真实转子响应与激励副作用来自不同物理通道（d 轴注入 vs q 轴转矩、基频 vs ω_h、反电动势 vs 高频电流）。若两通道在特征空间可分（定义 315 的 sep ≥ sep_min），则一致性检验把伪观测误判率压到 `≤ ε_sep`；在 A99（通道正交）下 `ε_sep → 0`。系：R69 的"k 源一致"必须在物理层替换为"物理正交 + 可分性"，否则饱和/热耦合会让两个"独立"通道共享同一畸变源，一致地错。

**定理 19（激励安全与无突变）** 激励 e 经分层证书（定义 320）与换相约束（定义 319）认证后，其电学/热学/运动学风险 ≤ 各自 ε；激励只改变"先观测/辨识还是直接执行"的时序，不改变 J_kin 安全包络；激励失败/超时/不可分时，λ 单调不降地退化为 R69→R68；R68 的换装不变式（定理 15）保持 ⇒ 控制连续、无突变。加速退化时快环切强制换相，属于预定义的、有界的模式切换。

## 6. 本轮最大风险

**一句话**：EXCITE-RAS 的全部分层门控都押在「主动激励能制造真观测、且两条物理通道在磁饱和与热耦合下仍然正交」这一前提上——一旦饱和让 HFI 的伪位置估计与反电动势估计共享同一个畸变源，伪观测就会**同时骗过两个「独立」通道**并通过物理证据纪律，系统于是带着一个自洽的错角度去换相，在电机层把 R69 的「诚实的不知道」直接变成转矩反转（**越问越错，且错得自洽**）。

**次级风险与缓解**：
1. **激励反作用越界**（纹波/温升/去磁）→ 定义 315/325 的 β 上界 + 分层证书（定理 19）；
2. **静默区无法探测**（表贴式 ξ≈1）→ 引理 20 的硬退化到强制换相/外置编码器，绝不假装可探；
3. **跨体校准被全局掩盖**→ 定义 318 MCG-S 分体门 + E306 显式构造 Simpson 悖论；
4. **快环被慢环拖垮**→ 两时间尺度分离，快环只跑固定观测器/查表，零学习写（不变式 310-i）；
5. **辨识激励污染任务**→ 定义 325 激励-任务冲突，冲突时放弃激励并保守传递。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** `EXCITE-RAS=(OMG,EID,HVI,CFP,LSC,RAS-WM‡)`；实时零学习写（快环只跑固定观测器/查表）；观测性优先门控（`G_obs ∧ G_id` 前任务 VoI 记 ⊥）；激励预算与反作用上界；分层且分体证书。

**定义 311–312（分层状态与被动可观测性）** `x=(θ_e,ω_e,i_dq,T_w,b)`；PMSM 位置信息仅经含 `ω_e` 的反电动势/交叉耦合项进入，故 `o_idx(0)=0`，`G_obs^pass=1[o_idx≥o_min]`。秩是结构性质，滤波不改变秩。

**定义 313（主动可观测性与 HFI）** 估计 d 轴注入 `u_h=V_h cos(ω_h t)`；电流含 `sin(2Δθ)` 分量幅值 `∝(1/ξ−1)V_h/ω_h`；`o_total=max(o_pass, o_act·1[注入])`；`ξ≈1` 时不可探。

**定义 314–315（激励动作与反作用）** `e=(e_phys,e_id,e_soc)`，`ξ=(a,e)`；`VoI_obs(e)=H(θ_e|y)−E[H(θ_e|y,e)]−c_β(β(e))`；`sep(e)<sep_min` 不得定案。

**定义 316（层次化 VoI）** `VoI_hier=1[G_obs]·(VoI_obs+1[G_id]·(VoI_id+1[G_obs]·VoI_task))`；语义是「定义域门控」，不是权重衰减。

**定义 317（三分）** `U_ale=Σŵ trΣ`（模态内+齿槽/量化/噪声，不可约）；`U_emb=H(b|o)`（参数，可由 e_id 降低）；`U_epi=H_mode·g(Δ_min)`（任务，可由 e_soc 降低）；`H(m|o)` 中可由 `H(b|o)` 解释占比 ≥ ρ_emb 判为 embodiment-induced。

**定义 323–324（CFP 与可辨识性）** `v_θ(x_s,s|z,ĉ,Σ_ĉ)`，`ĉ` 经 adaLN 注入 R69 trunk；`i_idx=λ_min(F(ĉ))`，`G_id=1[i_idx≥i_min]`。

**定义 325–326（预算冲突与证书）** 激励与任务进度/安全冲突则推迟或放弃，未解不确定性向下传递为保守；`J_EXCITE` 由 `J_FLUID`、门控、反作用分位、分体 ECE 与可分性组成。

## 3. 关键算法伪代码

```python
# IP-264 OMG：可观测性门（快环，固定速率、零学习）
class ObservabilityGate:
    def passive(self, y_act, omega):
        o_idx = self.bemf.min_singular_ratio(omega)    # ω→0 ⇒ 秩亏
        return o_idx, (o_idx >= O_MIN)
    def active(self, y_act):
        return self.hfi.estimate(y_act)                # θ̂_e^hfi 与 sep

# IP-265 EID：三层激励选择（净 VoI，含反作用）
def choose_excitation(need, y_act, budget, safety):
    cands = []
    pool  = hfi_candidates() if need == 'obs' else id_trajectories()
    for e in pool:
        if not budget.allow(e) or not safety.electrical(e): continue
        if need == 'obs' and probe_separability(e, y_act) < SEP_MIN: continue
        voi = voI_obs(e, y_act) if need == 'obs' else voI_id(e, y_act)
        cands.append((e, voi - cost_beta(e)))
    if not cands: return None
    e, score = max(cands, key=lambda t: t[1])
    return e if score > 0 else None

# IP-266 HVI：下层不开，上层记 ⊥
def hierarchical_voi(G_obs, G_id, w, g):
    if not G_obs: return ('obs_first', None)
    if not G_id:  return ('id_first',  None)
    return ('task', entropy(w) - expected_entropy(w, g))

# IP-267 CFP：条件于辨识参数的跨体流策略
def sample(self, o, chat, Sig_chat, K, N_step=2):
    zc, xs = self.emb_adapter(self.trunk(o), chat, Sig_chat), randn(K, D)
    for i in range(N_step):
        xs = xs + (1.0/N_step) * self.v(xs, i/N_step, zc)
    return [self.decode(x) for x in xs]                # ξ=(a,e)

# IP-268 LSC：分层证书
def layered_certificate(action, e, st):
    return (cert_electrical(e, st) and cert_thermal(st)
            and cert_kinematic(action, st) and cert_task(action, st))

# IP-274 主闭环
def EXCITE_RAS_round(M, y_task, y_act):
    o_idx, G_obs = M.omg.passive(y_act, M.omega)       # 1) 最底层门
    if not G_obs:
        e = M.eid.choose_excitation('obs', y_act, M.budget, M.elec_safety)
        if e is not None:
            M.apply_excitation(e)
            th, sep = M.omg.active(M.sense())
            G_obs = (sep >= SEP_MIN) and M.omg.passive(M.sense(), M.omega)[1]
        if not G_obs: return M.forced_commutation()    # 静默区退化
    G_id, chat, Sig = M.eid.identify(y_act, M.excite_hist)   # 2) 可辨识门
    if not G_id:
        e = M.eid.choose_excitation('id', y_act, M.budget, M.elec_safety)
        if e is not None:
            M.apply_excitation(e); G_id, chat, Sig = M.eid.identify(M.sense(),
                                                                    M.excite_hist)
    z, o = M.mtm.forward(y_task)                       # 3) 任务层（R69）
    K = 1 if M.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, chat, Sig, K), z)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if (G_id and U_epi > TAU_EPI) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_unres = U_ale + (0.0 if g is not None else U_epi) + (0.0 if G_obs else U_emb_bound(M))
    lam = max(M.efs.risk_scale(...), lam_floor(U_unres))
    A = M.ach.propose(x_prime, H=M.vista.H)            # 4) 分层证书
    k = M.c_ras_wm.certified_prefix(A, ..., theta_hat=th)
    if not M.lsc.validate(A, None, M.state): k = M.lsc.shrink_until_valid(A)
    M.vqa_e.submit_async(e, g, o_idx, sep, chat)       # 5) 审计 + 分体证书
    return k, lam, th, (U_ale, U_emb, U_epi)
```

## 4. 推导

**引理 19（可观测性门控的必要性/无伪 VoI）** 若 `G_obs=0` 仍用 x̂ 算任务 VoI，则与真实信息增益的期望偏差 `≥ c·tr(P_⊥Σ_⊥P_⊥)`（c>0 由任务动作对 θ_e 的灵敏度决定）。故门控不是保守选项，而是避免一个正比于不可观测方差的系统性错误；任务 VoI 的定义域须显式写为 `{G_obs=1}`。

**引理 20（HFI 恢复与反作用权衡）** (a) θ_e 可由 HFI 可辨 ⇔ `ξ≠1` ∧ `ω_h≫ω_e` ∧ `ω_h<开关频率可辨上限`；(b) `Var(θ̂_e)∝(ω_h/((1/ξ−1)V_h))²σ_n²` 随 V_h 下降；(c) 反作用 `β∝V_h·i_q·泄漏`。故净 `VoI_obs(V_h)` 有内点最优；`ξ→1` 时不可辨，必须退化到强制换相/外置编码器。

**引理 21（跨体校准 Simpson 悖论）** 存在分布使 `ECE_global≤τ` 而 `Σ_b p(b)ECE_b>τ`：由 `ECE_global=Σ_b p(b)ECE_b+cross`，同号体偏差可被 `cross<0` 抵消。系：必须用定义 318 分体门；全局门会让坏校准被好机体「抵消」成合格。

**定理 18（分层严格包含与安全单调性）** (a) `G_obs=0` 时逐指令输出强制换相/最小安全动作，物理风险 ≤ R69 在错误 x̂ 下的输出；(b) `G_obs=1∧G_id=1` 时与 R69 逐指令一致（U_emb 已消解、参数为常数，保留 resolution bonus）；(c) `Valid(J_kin)⇒Valid(J_elec)∧Valid(J_therm)`，新增层只收紧。故 R69 是 EXCITE 在「执行器完全可观测 + 机体已知」边界上的严格退化，R68 为再退化。

**引理 22（物理正交证据下伪观测可检测性）** 若真实转子项与激励副作用来自不同物理通道（d/q 轴、基频/ω_h、反电动势/高频电流）且 `sep≥sep_min`，则一致性检验把伪观测误判率压到 `≤ε_sep`，A99 下 `ε_sep→0`。系：R69 的 k 源一致必须替换为「物理正交 + 可分性」，否则饱和/热耦合使两通道共源、一致地错。

**定理 19（激励安全与无突变）** 激励经分层证书与换相约束认证后风险 ≤ 各层 ε；激励只改时序不改 J_kin 包络；失败/超时/不可分时 λ 单调不降地退化为 R69→R68；R68 换装不变式（定理 15）保持 ⇒ 控制连续、无突变（快环切强制换相为有界预定义切换）。

## 7. 本轮最大风险

**一句话**：EXCITE-RAS 的全部分层门控都押在「主动激励能制造真观测、且两条物理通道在磁饱和与热耦合下仍然正交」这一前提上——**一旦饱和让 HFI 的伪位置估计与反电动势估计共享同一个畸变源，伪观测就会同时骗过两个「独立」通道并通过物理证据纪律，系统带着一个自洽的错角度去换相，在电机层把 R69 的「诚实的不知道」直接变成转矩反转**（越问越错，且错得自洽）。

**次级风险与缓解**：激励反作用越界（定义 315/325 + 分层证书）；静默区不可探（引理 20 硬退化，绝不假装可探）；跨体校准被全局掩盖（定义 318 MCG-S + E306）；快环被慢环拖垮（两时间尺度分离、快环零学习写）；辨识激励污染任务（定义 325 冲突处理，放弃激励并保守传递）。
