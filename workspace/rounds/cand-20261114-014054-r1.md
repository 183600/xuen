# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「自监督学习」×「多视角视觉」）

> R69 让闭环第一次学会「问」：aleatoric 只收紧，epistemic 去「看/问/触」。但整套信任架构有一个从未言明的前提——**真值必须从外部来**：标定要外部标签、ECE 要标签、交互要人回答、投毒检测要已知攻击样本。于是 R69 自陈的三个最大风险（模态未校准、交互投毒、缓变故障被标定吸收）其实指向同一件事：**当没有人可问、没有标签、只有一个会自我塌缩的表示时，我凭什么相信自己？**
>
> 本轮两个灵感正好从内部补上这条缺失的通道：
> - **自监督学习**给出**免费监督**：同一隐状态的不同视角/增广之间的一致性，本身就是一个不需要标签的训练信号，也天然是一个不需要标签的**验证信号**——系统可以「自己问自己」，且这个「问」是零社交成本、零延迟的。
> - **多视角视觉**给出**物理独立性**：不同基线、不同光学、不同模态对同一世界的观测之间存在**几何约束**（对极、三角化、光度一致、时延同步）。几何不是学出来的，**学习目标无法把它坍缩掉**，因此它是反自欺最硬的锚。
>
> 但两者合起来恰好生成一个更深的悖论：**自监督的目标是「让视角一致」，而验证的目标是「让不一致暴露」——这两个目标在数学上是对抗的。** 如果不管，系统可以用「把所有视角压成同一个常数」获得完美一致，从而把「不知道」变成「非常确定」。因此本轮真正的贡献不是「加多视角」，而是**给「一致」定价**：一致性只有在各方「能够不同意」时才构成证据。
>
> 核心命题：**把「一致」从一种默认证据改造成一种需要认证的有限资源——只有当视角集合通过「独立性认证（能不同意）」与「反坍缩认证（还带着信息）」时，共识才被换算成至多 n_eff 张有效票，而不是 V 张名义票；几何是多视角里唯一不可学习的锚；三者一起把 R68 的残差通道、R69 的似然通道与 R70 的跨视角通道三角化成一张「盲区互补」的信任网。** 命名 **MOSAIC-RAS**（Multi-view Online Self-supervised Agreement with certified Independence & anti-Collapse）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**当没人可问时，我凭什么相信我们达成的一致？**」——共识只有在各方能够不同意时才构成证据；一块马赛克只有在每块砖都不同时才是一幅画。

## 0. 直觉与动机

**灵感 1（自监督 → 监督信号可以从结构里免费长出来）**
直觉：R69 的信任是「标签饥渴」的：模态权重靠 ECE 校准、慢变故障靠标注、投毒靠已知攻击。自监督说：不用。同一场景在两个视角、两种增广、两个时刻应当映射到同一语义，让它们一致就是一个免费损失。更关键的是，**训练时的一致性信号可以直接当推断时的验证信号**——如果两个独立视角对「现在是哪个模态」投了同一票，这票就有权重；如果它们分裂，分歧本身就是 epistemic 的可观测读数。这把 R69 的 `U_epi` 从「对一个参数化模态后验的估计」变成「对一组可观测视角分歧的测量」：**不需要知道真值，只需要知道它们是否互相印证**。于是 R69 的 VoI 控制器第一次有了一个几乎免费的候选信息动作：不是去问人，而是「换个视角再看一次」。

**灵感 2（多视角视觉 → 独立性有物理来源，可测、可造）**
直觉：R69 定义 293-iii 要求「k 个正交证据源一致」，但正交性是**假设**的、不可验证的。两个同型号相机同处一个镜头罩下，雾一上来一起雾、标定一漂一起漂——名义上是两个源，有效上是一个源。多视角几何给出一个可量化的独立性：基线越长，三角化深度不确定性越小（`σ_z ∝ z²/(f·b)`）；不同模态（视觉 / 本体感觉 / 触觉）的失效机制更不同。于是「正交」第一次变成一个可以**测量**（有效视角数 n_eff）、也可以**主动制造**（主动视差）的量，而不再是一句口号。

**灵感 3（自欺悖论 → 一致是最便宜的真理代理，也最容易伪造）**
直觉：这是本轮的核心。要让两个视角一致，最简单的解不是「都学对」，而是「都别学」——把编码器压成常数，或只保留两视角共享、却与任务无关的那点信息（例如整体亮度）。这就是 SSL 的表示坍缩 / 冗余坍缩。一旦塌缩，一致性 = 1、信息 = 0。系统得到**最高的自信**和**最低的能力**，而且它没有任何外部信号能察觉——因为连「问」都被省掉了。所以 R69 的「问错比不问更危险」在此升级为「**一致错比不一致更危险**」：它不需要任何人配合、永远可得、而且长得像独立确认。

**灵感 4（三通道三角化 → 每个通道都有已知盲区，盲区互补才叫冗余）**
直觉：R68 的残差通道看不见「被标定吸收的缓变故障」；R69 的似然通道看不见「自洽的幻觉模态」；R70 的跨视角通道看不见「所有视角一起坏掉」或「视角塌缩」。三个通道的盲区**恰好互不重合**：慢漂移被几何抓到、幻觉模态被视角分歧抓到、共模污染被似然与残差抓到。于是「多通道」的意义不是投票数更多，而是**盲区覆盖**：任意单一故障必须同时躲进三个盲区才隐形，而这三个盲区由不同的物理/统计机制决定，很难被同一个攻击同时占据。**冗余的价值 = 盲区的补集面积**，不是通道个数。

**灵感 5（视角是可以主动购买的 → 独立性有一个「位移价格」）**
直觉：R69 的信息动作是「看 / 问 / 触」。多视角把「移动以产生视差」变成一个**物理的信息动作**：基线 b 增大，三角化不确定性按 1/b 下降。这不是被动等更好的观测，而是**用运动去买独立性**。它与 R69 的 VoI 完全同构，但成本项是电机能量与安全包络，收益项是可精确计算的几何信息增益。于是「多视角」从传感器配置升级成一种**可预算的主动探询**；也直接回答了 R69 的「视角不够时怎么办」——不是更保守，而是**走到能看清的地方**。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (MVE, SAS, ICC, CDA, TT, VRA, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **有效独立性预算**：任何跨视角证据按 `n_eff`（定义 314）计票，绝不按名义视角数 V 计票；`n_eff` 与反坍缩证书每个控制周期重算；
(iii) **反坍缩否决权**：若反坍缩证书（定义 313）不通过，跨视角一致性**不得进入证据**，系统无条件下沉到 R69 语义（再用 R68 兜底）；
(iv) **盲区互补纪律**：诊断/降险决策必须能指出「当前由哪个通道覆盖哪个已知盲区」（定义 317），未被任何通道覆盖的盲区视为「不可诊断」并进入最保守分支。

**定义 311（多视角观测模型）** 时刻 t 的观测 `o_t = {o_t^{(v)}}_{v=1}^{V}`，第 v 个视角带内参 K_v、外参 T_v、模态标签 μ_v 与时间戳 τ_v。视角算子 `o^{(v)} = Φ_v(s, ξ_v)`，s 为共享隐状态，ξ_v 为视角本地噪声/故障。允许 V 个视角属于不同模态（RGB / 深度 / 触觉 / 本体感觉）。**视角集合不是固定的**：V 与成员由 VRA（定义 321）在预算内选择。

**定义 312（自监督一致性目标 SAS 的训练侧）** 共享编码器 f_ψ 把每个视角映射到共同嵌入 `z_v = f_ψ(o^{(v)})`。训练损失
`L_SSL = Σ_{i≠j} w_ij·d(z_i, z_j) + λ_geo·L_geo + λ_red·L_red`，
其中 d 为对齐距离（视角/增广/时刻一致性），`L_geo` 为几何约束（对极距离、重投影误差、同步残差），`L_red` 为冗余缩减项（Barlow/VICReg 式去相关，**显式防止维度塌缩**）。关键：`L_geo` 与 `L_red` 不是可选的调参项，而是本方案反自欺的两个「锚」。

**定义 313（坍缩与反坍缩证书）** 坍缩 = 嵌入几乎不随观测变化（表示坍缩），或视角对之间保留了过多共享、却与任务无关的信息（冗余坍缩）。反坍缩证书含三项：
(a) **有效秩** `r_eff = (Σ_i σ_i)² / Σ_i σ_i²`（嵌入协方差奇异值的参与比）≥ ρ_min；
(b) **跨视角互信息的 Goldilocks 带**：`I(z_i; z_j) ∈ [ι_lo, ι_hi]`——过高 = 视角近乎重复（独立性造假），过低 = 视角说的不是同一件事（不可比较）；
(c) **一致性的信息下界**：用 PID 视角，一致（共识）承载的是**冗余信息** R，要求 `R(S : z_1,…,z_V) ≥ ρ_info`，且 R 与任务标签无关地可估（定义 320 的伪标签自检）。三项任一失败 ⇒ `collapse_veto = True`。

**定义 314（独立性证书与有效视角数 n_eff）** 视角度量矩阵 `R ∈ ℝ^{V×V}`，`R_ij` 为视角对在「给定隐状态后」的条件依赖（HSIC / 距离相关 / 条件互信息）。令 `{λ_i}` 为 R 的特征值，定义
`n_eff = (Σ_i λ_i)² / Σ_i λ_i²`（参与比）。
等相情况 `R_ij = ρ (i≠j)` 时闭式 `n_eff = V / (1 + (V−1)ρ)`。**这是本轮最重要的计价器**：V=10、ρ=0.99 ⇒ n_eff ≈ 1.009——十个相机只值一个相机；V=2、ρ=0.1 ⇒ n_eff ≈ 1.82。证据强度按 n_eff 而非 V 增长（引理 19）。

**定义 315（跨视角模态支持与多视角 epistemic）** 对 R69 的每个候选模态 m_k，令每个视角给出的支持票 `vote_v(k) = p_v(m_k | o^{(v)})`。定义
`U_epi^MV = H( normalized Σ_v w_v·vote_v )`，权重 `w_v` 由 ICC 给出的独立贡献度归一化（不是 1/V）。
**忠实支持数** `k_supp(k) = n_eff · 1[Σ_v vote_v(k) ≥ θ·V]`。一个模态只有获得 ≥2 的有效独立视角支持才被视为「被印证」；单视角强支持但其他视角中立 ⇒ 未消解（继承 R69 证据纪律，但把「正交」显式换成「有效独立」）。

**定义 316（自我咨询：零外部成本的信息动作）** 在 R69 增广动作空间中新增**内部信息动作** `g_self`：切换视角、改变曝光/增益、小幅改变姿态以改变反射、请求一次多视角重采样。成本 `c(g_self) = ` 延迟 + 位移能量（无社交成本、无被投毒风险）。扩展定义为
`VoI_total(g) = VoI_ext(g) + VoI_self(g)`，并采用**字典序纪律**：若 `max_k [VoI_self − c_self] > 0`，**必须先耗尽自我咨询**，才允许发起 R69 的外部交互（定义 298）。理由：自我咨询零投毒面、可认证、可复现，外部交互有 `ℰ_poison` 面。R69 的 `g` 成为本定义在「自我咨询无收益」时的边界。

**定义 317（三通道信任三角化 TT）** 信任通道 `T = (r_res, a_score, c_xview)`：R68 的传感器残差（自洽）、R69 的流似然（行为自洽）、R70 的跨视角一致性（世界几何/语义自洽）。每个通道对每类故障有**已知盲区** `B_c`：

| 故障类型 | r_res（R68） | a_score（R69） | c_xview（R70） |
|---|---|---|---|
| 缓变标定漂移 | **盲**（被吸收） | 弱（若偏离主脊） | **检出**（几何/对极破裂） |
| 自洽幻觉模态 | 盲 | **盲**（密度自洽） | **检出**（视角不支持） |
| 共模污染（一起起雾/一起被遮挡） | 部分 | 部分 | **盲**（一起错） |
| 视角塌缩 | 盲 | 部分 | **盲**（假一致） |
| 传感器重放/欺骗 | 盲 | 部分 | **检出**（时延/视差破裂） |

诊断规则：仅当存在至少一个通道 c 满足「该故障不在 B_c 且该通道当前有效（ICC 通过）」，系统才可对故障下结论；否则判定为「不可诊断」，强制进入 R69/R68 最保守分支。**三角化 = 盲区的并集覆盖，而不是三票多数。**

**定义 318（共模模型与泄漏 L_cc）** 存在共享隐变量 h（光照、温度、机械冲击、统一时钟漂移、机壳形变）同时影响多个视角：`o^{(v)} = Φ_v(s, h, ξ_v)`。定义**共模泄漏** `L_cc = I(h; consensus)`，并要求视角集合在 h 上尽量「去相关」。`L_cc` 高时 ICC 自动下调 n_eff（因为视角不是条件独立的），并在证书 J_MOSAIC 中显式记录。多视角的敌人不是「视角太少」，而是「视角太像」——包括**一起坏的像**。

**定义 319（视角投毒与共谋 ℰ_ssl）** 攻击面新增：物理遮挡/贴纸/雾化单个视角、重放视频、时间戳欺骗、对 SSL 目标的梯度投毒、以及**视角共谋**（同时伪造 k 个视角使其一致）。并入 R69 的 ℰ_poison：`ℰ_MOSAIC = ℰ_FLUID × ℰ_view × ℰ_ssl`。关键判据：若攻击者控制的视角数 `V_adv` 满足 `n_eff(V_adv) ≥ 1`，则多数一致不再安全（引理 19 的推论）——所以**反坍缩/独立性认证同时是投毒下界**。

**定义 320（无标签模态校准 SSC）** 用跨视角支持作为**伪标签**校准 R69 的模态权重：令 `ŵ_k ∝ Σ_v w_v·1[vote_v(k) ≥ θ]`，并以「跨视角留一法」估计校准误差 `ECE_self`（每次留出一个视角，用其余视角的共识预测它，统计一致性偏差）。**门控**：仅当 `collapse_veto = False` 且 `ECE_self ≤ τ_ece` 时，才允许用 SSC 权重替换 R69 的 MCG 输出；否则退回 R69 的标签校准或纯保守。SSC 诚实地承认：伪标签只有在视角确实独立时才是标签。

**定义 321（视角路由与主动视差 VRA）** 视角集合选择是预算约束下的子模最大化：`max_{S⊆𝒱} [ Ĩ(S)/c(S) ]`，其中 `Ĩ(S)` 用 n_eff 与覆盖度估计。主动视差动作 `g_parallax ∈ 𝒜_info` 通过移动基线 b 购买信息：立体深度方差 `σ_z² ∝ z⁴σ_d²/(f²b²)`，故把基线从 b 增到 b′ 的期望信息增益（高斯近似）`VoI_parallax ≈ ½ log(1 + (b′²−b²)/b_geo²)`，随 b 边际递减。**它必须与 R69 的 C-RAS-WM 认证共享安全包络**：为了看清而移动可以是危险动作，故 `g_parallax` 只能在不改变碰撞/稳定性包络的自由度内执行（如沿垂直于目标方向的横移、改变腕部视点）。

**定义 322（视角身份、陈旧与刷新）** 每个视角维护 `last_validated_v`（最后一次通过独立交叉验证的控制周期）与 `staleness_v = t − last_validated_v`。权重 `w_v ∝ exp(−staleness_v/τ_view)`；超过 `T_stale` 的视角降级为「未验证」，不参与定案。**视角身份漂移**（被重新标定、被替换、被物理遮挡而未被察觉）会先表现为「与其他视角的条件独立性异常」，故 ICC 同时充当视角健康监测器。这是 R68 标定窗口思想在「视角层」的镜像。

**定义 323（证书 J_MOSAIC）** `J_MOSAIC = (J_FLUID, n_eff, r_eff, redundant_info R, ECE_self, L_cc, view_coverage, staleness_p95, view_log_hash, mosaic_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ (collapse_veto = False) ∧ (n_eff ≥ n_min) ∧ (ECE_self ≤ τ_ece) ∧ 盲区覆盖满足定义 317 ∧ 视角预算未越界`。任何一项失败 ⇒ 跨视角层整体失效，回退 R69。

**定义 324（嵌套包含与降级序）** 降级链 `R70 ⇐ R69 ⇐ R68`，逐级为「冻结一层、语义不变」：
- 若 `collapse_veto ∨ n_eff < n_min ∨ V < 2`：R70 → R69（禁用跨视角证据，行为逐指令相同）；
- 若 R69 的交互不可得 / VoI≤成本：R69 → R68。
**安全侧单调**：每降一级，λ 不减、可执行前缀 k 不增。R70 只在「跨视角证据通过认证」时使用 resolution bonus（定义 307），否则与 R69 完全一致。

**定义 325（自适应视角预算与实时调度）** 默认 `V=2`（最便宜的双目/双模态对），n_eff 与 ICC 仅在「ICC 报警 / 模态分歧 / FMA 或 r_res 异常」时升到 V=4 并触发主动视差评估。视角特征共享 trunk，前向按视角批处理；保证 P99 实时预算（复杂度见表）。K 的自适应（R69 定义 308）与 V 的自适应相互独立，两者同时升档时走一次性预算超支并记录。

**定义 326（参与式审计 VQAuditor-V）** 审计对象新增：视角集合选择是否被共模污染主导、`n_eff` 是否被高估、一致性是否在坍缩下被误用、伪标签 SSC 是否被投毒、主动视差是否越安全包络。结论回灌 AuditBuf，成为下一轮 VRA 的独立性与成本先验。

**定义 327（证据可采纳代数）** 一条跨视角证据 e 的可采纳票数 = `n_eff(e) · 1[collapse_veto = False] · 1[staleness 合格] · 1[盲区覆盖可用]`。求和后再与 R69 的「k 个正交源一致」纪律对齐：**R69 的 k 是名义正交源数，R70 用有效独立票数替换它**。这使「k 一致」从假设升级为可计算、可审计的约束。

## 3. 推导

**引理 19（有效独立视角决定共识强度）** 设 V 个视角在给定隐状态下条件独立、单视角错误率 p<1/2，且其条件依赖矩阵的参与比为 n_eff。则共识错误率满足
`P(err) ≤ exp(−2·n_eff·(1/2 − p)²)`。
系 1：证据强度随 n_eff 指数增长，与名义 V 无关；等相 ρ 时 `n_eff = V/(1+(V−1)ρ)`，高相关视角带来**冗余幻觉**（V=10, ρ=0.99 ⇒ n_eff≈1.01）。
系 2（投毒推论）：若攻击者控制 `V_adv` 个视角，其有效票数 `n_eff(V_adv)` 超过诚实方即可能翻盘——故「加视角」必须先加**独立性**，否则只是给攻击者更多话筒。

**引理 20（共识自欺：坍缩使一致性的信息归零）** 共识信号 A 是各视角嵌入的函数。由部分信息分解，A 关于状态 S 的信息不超过视角的**冗余信息**：`I(S;A) ≤ R(S : z_1,…,z_V) ≤ min_v I(S;z_v)`。
(i) 表示坍缩使 `I(S;z_v) → 0`，故 `I(S;A) → 0`，而一致性度量 `d(z_i,z_j) → 0`——**一致性与信息量可以同时走到相反极端**；
(ii) 冗余坍缩使视角近乎重复，`I(S;A) ≤ I(S;z_1)`，增加视角不增加信息却让 n_eff 名义上升。
因此反坍缩证书（定义 313）不是工程保险，而是**一致性可被当作证据的必要条件**。系：SSL 目标本身（最大化一致）与验证目标（最大化可检测的不一致）对抗，**必须由几何锚 `L_geo` 与去相关 `L_red` 外部约束住**。

**引理 21（主动视差的信息—成本拐点）** 高斯观测下三角化深度方差 `σ_z² = z⁴σ_d²/(f²b²)`。把基线 b 增至 b′ 的信息增益 `ΔI ≈ ½ log(1 + (b′²−b²)/b_geo²)`，其中 b_geo 由深度先验决定。故 ΔI 随 b 边际递减，存在唯一拐点使「单位运动能量的信息增益」最大：`b* = argmax_b ΔI(b)/E_move(b)`。系：主动视差不是「越远越好」，而是**在安全包络内买到最划算的那段基线**；超出拐点的移动只买噪声。

**定理 18（三通道盲区互补与可诊断性）** 设故障类型 f 的盲区集合为 `B(f)`（定义 317），通道 c 在当前周期有效当且仅当 ICC 通过。则：
(i) f 可被**排除**，当且仅当存在有效通道 c 使 `f ∉ B(c)` 且 c 给出无异常；
(ii) f 可被**确诊**，当且仅当存在有效通道 c 使 `f ∉ B(c)` 且 c 给出异常；
(iii) 若所有有效通道都落在 `B(f)` 内，则 f **不可诊断**，系统必须进入最保守分支（定义 317/324）。
在通道失效条件独立（给定无故障）时，三通道同时漏检概率 ≤ ∏_c P(miss_c)；而缓变漂移与幻觉模态的盲区分别只被 c_xview 与 c_xview 覆盖，故 **R70 的跨视角层恰好补上 R68/R69 的两个结构性盲区**，且这一覆盖不依赖跨视角通道本身「更准」，只依赖它「坏得不一样」。

**定理 19（严格嵌套包含与安全单调）** 在 A95–A99 下，MOSAIC 在任意状态 s 的期望风险 ≤ FLUID ≤ CALM；且当 `collapse_veto`、`n_eff < n_min`、`V<2` 或跨视角证据不可采纳（定义 327）时，MOSAIC 与 FLUID **逐指令相同**；当 FLUID 退化为 CALM 时亦然。故 R70 是 R69 在「跨视角不可用」边界上的严格退化：安全侧不做任何让步，效率侧仅在认证通过时获得 resolution bonus。降级链上 λ 单调不降、k 单调不增，保证控制连续、无突变（继承 R69 定理 17）。

## 6. 本轮最大风险

**一句话**：MOSAIC-RAS 的全部收益押在「一致 = 证据」这一前提上，而**自监督的目标与验证的目标在数学上对抗**——系统可以在「视角全部塌缩成同一常数」或「所有视角被同一个共模故障一起腐蚀」时得到完美一致，把 R69 的「诚实的不知道」升级为「**不需要任何人配合就能自我确认的错误**」；由于这种假一致零成本、永远可得、且长得像独立证据，它比 R69 的问错更难被发现——**一致错，比不一致更危险**。

**次级风险与缓解**：
1. **视角塌缩 / 冗余幻觉** → ICC 反坍缩证书（r_eff + Goldilocks 带 + 冗余信息下界）+ 几何锚 `L_geo` + 边 `L_red`，任一失败即整体退回 R69；
2. **共模污染（一起坏）** → L_cc 泄漏度量 + 跨模态物理多样性（视觉/触觉/本体）+ 盲区矩阵显式标记「不可诊断」并走最保守；
3. **视角投毒 / 共谋伪造一致** → 有效票数 n_eff（而非 V）+ 时间戳/视差/重放校验 + ℰ_ssl 对抗训练 + 引理 19 系 2；
4. **主动视差本身不安全** → g_parallax 必须过 C-RAS-WM 认证（定义 321）+ 定理 19 无突变；
5. **实时预算被多视角击穿** → 共享 trunk + V=2 默认 + ICC 报警才升 V/触发视差 + P99 预算表；
6. **伪标签 SSC 被污染** → 留一视角交叉验证 + 门控（ECE_self 越界即退回 R69 标签校准/纯保守）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** MOSAIC-RAS = (MVE, SAS, ICC, CDA, TT, VRA, RAS-WM†)；零学习写操作继承；**有效独立性预算**（按 n_eff 计票，不按 V）；**反坍缩否决权**（ICC 不过 ⇒ 整体退回 R69）；**盲区互补纪律**（说不清谁覆盖哪个盲区 ⇒ 不可诊断 ⇒ 最保守）。

**定义 311–312（多视角观测与 SSL 目标）** `o^{(v)}=Φ_v(s,ξ_v)`；`L_SSL` 含对齐项 + 几何锚 `L_geo`（对极/重投影/同步）+ 去相关 `L_red`（Barlow/VICReg）。后两者是反自欺的硬约束，非可选调参。

**定义 313–314（反坍缩与独立性）** 反坍缩证书：`r_eff ≥ ρ_min` ∧ 跨视角互信息落 Goldilocks 带 ∧ 冗余信息 `R ≥ ρ_info`，任一失败即 `collapse_veto`。`n_eff` 用条件依赖矩阵特征值的参与比；等相闭式 `V/(1+(V−1)ρ)`。

**定义 315–316（跨视角消歧与自我咨询）** 每视角对候选模态投票，`U_epi^MV` 由加权投票熵给出；模态需 ≥2 有效独立视角支持。`g_self`（换视角/重采样）成本近零、零投毒面，**字典序上必须先耗尽自我咨询，才允许发起 R69 的外部交互**。

**定义 317–318（三通道三角化与共模）** `T=(r_res, a_score, c_xview)` 各有已知盲区；诊断 = 存在有效通道不在该故障盲区内，否则「不可诊断」。慢漂移盲区只由 c_xview 补、幻觉模态盲区只由 c_xview 补、共模/坍缩盲区由 r_res/a_score 补。共模泄漏 `L_cc` 高时自动下调 n_eff。

**定义 319–320（投毒与无标签校准）** `ℰ_MOSAIC = ℰ_FLUID × ℰ_view × ℰ_ssl`（遮挡/重放/时延/共谋/梯度投毒）。SSC 用留一视角伪标签校准模态权重，`ECE_self` 门控；伪标签只有在视角确实独立时才算标签。

**定义 321–322（主动视差与视角陈旧）** VRA 在预算下最大化 `Ĩ(S)/c(S)`；主动视差 `VoI ≈ ½log(1+(b′²−b²)/b_geo²)` 边际递减，且必须过 C-RAS-WM。视角按 `staleness` 衰减权重，超时降级为未验证；ICC 兼任视角健康监测器。

**定义 323–327（证书/嵌套/调度/审计/可采纳代数）** `J_MOSAIC` 增列 n_eff、r_eff、R、ECE_self、L_cc、coverage、staleness。降级链 `R70 ⇐ R69 ⇐ R68`，λ 不减、k 不增。默认 V=2，ICC 报警才升 V=4 并评估视差。可采纳票数 `= n_eff·¬collapse·staleness·盲区可用`；R70 用有效独立票替换 R69 的「k 个名义正交源」。

# IP-266 ICC：独立性 + 反坍缩认证（核心计价器）
def certify(zs, task_probe):
    Z = stack(zs); r = effective_rank(Z)
    R = conditional_dependence_matrix(zs); lam = eigvalsh(R)
    n_eff = (lam.sum()**2) / (lam**2).sum()        # 参与比
    mi = [mutual_info(zs[i], zs[j]) for i < j]     # Goldilocks 带
    Rinfo = redundant_info(task_probe, zs)         # PID 冗余信息
    veto = (r < RHO_MIN) or any(not (I_LO <= m <= I_HI) for m in mi) \
           or (Rinfo < RHO_INFO)
    return dict(n_eff=n_eff, r_eff=r, R=R, Rinfo=Rinfo, collapse_veto=veto)

# IP-265/267 SAS+CDA：跨视角支持 → 无标签模态后验
def cross_view_support(modes, zs, w, n_eff):
    votes = {k: sum(w[v]*mode_prob(zs[v], modes[k]) for v in range(len(zs)))
             for k in modes}
    U_epi_mv = entropy(normalize(votes))
    supported = [k for k in modes if independent_support(votes[k], w, n_eff) >= 2]
    return votes, U_epi_mv, supported

# IP-268 TT：三通道三角化（盲区覆盖，不是多数投票）
BLIND = {'slow_drift': {'r_res'}, 'hallucinated': {'r_res','a_score'},

                 for c in ('r_res','a_score','c_xview'))

    U_ale = M.aud.decompose(...)                    # 继承 R69 aleatoric

## 4. 推导

**引理 19（有效独立视角决定共识强度）** 条件独立、单视角错误率 p<1/2、有效视角数 n_eff 时，共识错误率 `≤ exp(−2 n_eff (1/2−p)²)`。系 1：强度随 n_eff 而非 V 增长；等相 ρ 时 `n_eff=V/(1+(V−1)ρ)`，V=10、ρ=0.99 ⇒ n_eff≈1.01（冗余幻觉）。系 2：攻击者控制 `V_adv` 个视角时，若 `n_eff(V_adv)` 超过诚实方即可翻盘——加视角必须先加独立性。

**引理 20（共识自欺：坍缩使一致性信息归零）** 共识 A 是视角嵌入的函数，由 PID `I(S;A) ≤ R(S:z_1..z_V) ≤ min_v I(S;z_v)`。表示坍缩使 `I(S;z_v)→0`，而一致性 `d(z_i,z_j)→0`——**一致性与信息量可同时走向相反极端**；冗余坍缩使增加视角不增信息却抬高名义 n_eff。故反坍缩证书是一致性可作证据的**必要条件**；SSL 目标与验证目标对抗，必须由 `L_geo`/`L_red` 外部约束。

**引理 21（主动视差的信息—成本拐点）** 高斯下 `σ_z²=z⁴σ_d²/(f²b²)`，基线 b→b′ 的 `ΔI≈½log(1+(b′²−b²)/b_geo²)`，边际递减；存在唯一 `b* = argmax ΔI(b)/E_move(b)`。系：主动视差不是越远越好，而是在安全包络内买最划算的那段基线。

**定理 18（三通道盲区互补与可诊断性）** 按定义 317 的盲区矩阵 B(f)：故障可排除/确诊当且仅当存在有效通道 c 使 `f∉B(c)` 且 c 无异常/有异常；若所有有效通道都在 B(f) 内，则不可诊断，必须进最保守分支。通道失效条件独立时三通道同时漏检 `≤∏P(miss_c)`。缓变漂移与幻觉模态的盲区只由 c_xview 覆盖 ⇒ **R70 恰好补 R68/R69 的结构性盲区**，且只依赖「坏得不一样」，不依赖「更准」。

**定理 19（严格嵌套包含与安全单调）** A95–A99 下 `Risk(MOSAIC) ≤ Risk(FLUID) ≤ Risk(CALM)`；当 `collapse_veto ∨ n_eff<n_min ∨ V<2 ∨ 证据不可采纳` 时 MOSAIC 与 FLUID 逐指令相同；FLUID→CALM 同理。故 R70 是 R69 在「跨视角不可用」边界的严格退化；降级链 λ 单调不降、k 单调不增，控制连续无突变。

## 7. 本轮最大风险

**一句话**：MOSAIC-RAS 的全部收益押在「一致 = 证据」上，而**自监督目标与验证目标数学上对抗**——系统可在「视角全部塌缩成同一常数」或「所有视角被同一共模故障一起腐蚀」时获得完美一致，把 R69 的「诚实的不知道」升级为「**无需任何人配合就能自我确认的错误**」；这种假一致零成本、永远可得、且长得像独立证据，比问错更难发现——**一致错，比不一致更危险**。

**次级风险与缓解**：视角塌缩/冗余幻觉（ICC 反坍缩证书 + L_geo/L_red 双锚，失败即退回 R69）；共模污染（L_cc 度量 + 跨模态物理多样性 + 盲区矩阵显式「不可诊断」）；视角投毒/共谋（按 n_eff 计票 + 时间戳/视差/重放校验 + ℰ_ssl 对抗训练 + 引理 19 系 2）；主动视差越界（C-RAS-WM 认证 + 定理 19）；实时预算（共享 trunk + V=2 默认 + ICC 报警升级）；伪标签被污染（留一视角 + ECE_self 门控）。
