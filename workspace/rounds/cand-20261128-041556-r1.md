### 第 5 轮灵感驱动研究记录

**灵感词**：云端协同、材料选型

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM）与联邦锚 FFA 之上，追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3 · η_val · η_bal；执行集嵌套 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。v4 的最大遗留风险是 R49：BCK 的 QP（~1–5 ms）与 VACK 的偏好推理（~10–50 ms）可能击穿 1 kHz 控制环。本轮以「云端协同」正面处理该实时性风险，以「材料选型」补上被 v1~v4 长期忽略的物理前提维度，形成 CADVS-v5（IP-493~496），执行集嵌套升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **云端协同：把「实时性硬伤」转化为分层证书架构，而非单纯卸载算力**。v4 把所有门塞进同一条控制路径，导致「慢门拖累快环」。v5 按**证书的时域尺度**分层：
   - **L0 边缘反射层**（硬实时，目标 < 0.5 ms）：只保留局部、可近似的门——kc_ee（材料条件化包络）、kc_bal 的近似实现（查表/线性化锥）、kc_mat（触觉辨识）；
   - **L1 云审议层**（异步，10–200 ms）：kc_physics 的全 S2RC 仿真、kc_val 的全 VACK 推理、kc_mem 的全局检索；
   - **L2 联邦慢时域**（分钟级）：Φ_global、全局材料库 M_lib、价值/平衡/材料先验。
   两层用**有界陈旧（bounded-staleness）证书**桥接。核心设计原则：**陈旧不是放宽而是单调收紧**——证书越旧，有效阈值越高、安全边际越小（C_t = ⊖_Δ C(t_c)，Δ = t − t_c）。于是云延迟或断连只会让执行集更小（fail-closed），与单调收缩定理完全兼容；断连时用「证书膨胀 + 阈值抬升」的保守回退，保证 Exec_edge(t) 随 t 非增且 ⊆ Exec_v4。

2. **材料选型：把「物理合法」从名义模型升级为材料条件化认证**。v4 的 MSRG 用名义材料参数（μ, k, c, m）做 S2RC 仿真，BCK 用名义摩擦锥，EEK 用固定安全包络。但玻璃、软泡沫、织物、颗粒袋的失效模式截然不同——材料误判会让「仿真通过、实机碎裂」。引入材料感知物理核 MAPK：在线（press→k、slide→μ、lift→m）辨识材料参数 θ_mat，融合视觉/音频先验，产出材料证书 MC = (m_class, θ_mat, U_mat, conf, t)；硬门 kc_mat 要求 conf ≥ τ_mat 且不确定集 U_mat 落在**已认证材料参数球** B(θ_0, ε_cert) 内（OOD/未知材料 fail-closed）；MSRG/BCK/EEK 全部条件化为 θ_mat 的函数，且材料包络 E_m ⊆ E_nominal（只收紧，不放宽）。

3. **两者合流：材料库与辨识模型天然是「云慢变量」，触觉探测是「边快变量」**。材料库、跨站材料先验、联邦价值/物理先验都跨站点共享、演化缓慢，适合放云端；触觉探测与反射门是毫秒级本地量，必须留边缘。因此「材料选型」与「云端协同」不是两个独立点，而是同一分层架构的两个侧面：**云端 = 材料库 + 深度证书，边缘 = 反射门 + 触觉辨识**。

**关键洞见**：v1~v4 回答「覆盖/物理/人因/末点/记忆/联邦/价值/平衡」是否满足；v5 追问「**由谁、在何时、基于哪种材料假设**去认证」。引入陈旧弱化算子 ⊖_Δ 与材料参数化证书 C(θ)，把「时效」与「材质」两个此前被忽略的维度纳入证据链，并把「认证单点」升级为「认证参数球」。八硬门 kc_evidence_forged_v5 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal ∧ kc_mat，其中云层门以 ⊖_Δ 调整阈值；软评分 ECS_v5 = ECS_v4 · η_mat · η_sync。

**形式化目标（增量）**：
1. 定义分层证书 L0/L1/L2 与陈旧算子 ⊖_Δ：C_t = ⊖_{t−t_c}(C(t_c))，满足单调性 Δ₁ ≤ Δ₂ ⟹ ⊖_{Δ₂}C ⪯ ⊖_{Δ₁}C ⪯ C（越旧越严）。
2. 定义断连保守回退：Exec_edge(t) 随 t 非增，且 Exec_edge(t) ⊆ Exec_v4（证书膨胀 + 阈值抬升，绝不放宽）。
3. 定义材料证书 MC = (m_class, θ_mat, U_mat, conf, t) 与硬门 kc_mat：conf ≥ τ_mat ∧ U_mat ⊆ B(θ_0, ε_cert)。
4. 定义材料条件化：S2RC(θ_mat)、摩擦锥 μ(θ_mat)、包络 E_m，且 E_m ⊆ E_nominal。
5. 定义 SLCC 演算：⊖_Δ、层级组合 ∧_layer、材料参数化证书 C(θ)；证明单调陈旧、分层 fail-closed、材料鲁棒认证、材料迁移 Lipschitz 界、层级时序一致性。
6. 定义 EFA-v5 八硬门 + 软评分 ECS_v5 = ECS_v4 · η_mat · η_sync。
7. 定义 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：kc_mat 非恒真（未知材料被拒）+ E_m 只收紧 + ⊖_Δ 只收紧，三者任一即可严格收缩。

**本轮最大风险**：**材料误辨识与云端证书陈旧会形成相关性失效**——单一错误的 θ_mat 会同时污染物理/平衡/末点三门（三者共享同一错误前提，合取仍"全过"却全错），而陈旧的云端价值/物理证书可能掩盖边缘状态漂移，使八门合取产生「全部通过但全部基于错误前提」的虚假保证。

### IP-493 ECCA：分层证书与单调陈旧（边缘 L0 < 0.5 ms，云 L1 异步）

```python
@dataclass
class EdgeCloudCertificateArchitecture:
    """ECCA：L0 边缘反射 + L1 云审议 + L2 联邦；⊖_Δ 只收紧不放宽"""
    ttl: float = 0.2                    # 云证书有效期
    kappa: float = 0.5                  # 阈值抬升系数
    gamma: float = 0.5                  # 边际收缩系数
    drift_bound: Callable = None        # Drift(t, t_c) 的上界估计器
    drift_max: float = 0.05
    l0_budget_ms: float = 0.5

    def weaken(self, cert, delta: float):
        """⊖_Δ：单调弱化。Δ↑ ⇒ τ↑、m↓，绝不放宽；Δ=0 为恒等"""
        f = min(max(delta, 0.0) / self.ttl, 1.0)
        return cert.with_threshold(cert.tau + self.kappa * f,
                                   cert.margin * (1.0 - self.gamma * f))

    def l0_edge_gate(self, eec, bcc_fast, mc, t_now) -> tuple[bool, str]:
        """L0：只用局部、可硬实时的证书；不依赖云"""
        if not self.eek.kc_ee(eec, mc.m_class):   return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal_fast(bcc_fast):     return False, 'BALANCE_UNSTABLE'
        if not self.mapk.kc_mat(mc):               return False, 'MATERIAL_UNPROVEN'
        return True, 'L0_OK'

    def l1_cloud_gate(self, cloud_certs, t_now):
        """L1：对每条云证书做 ⊖_Δ；断连/漂移超界则取保守底"""
        out = []
        for c in cloud_certs:
            delta = t_now - c.t
            if delta > self.ttl and self.drift_bound(t_now, c.t) > self.drift_max:
                out.append(self._conservative_floor(c))   # 断连：历史最严证书
            else:
                out.append(self.weaken(c, delta))
        return out                                        # 门只会更严

    def disconnected_fallback(self, last_certs, t_now):
        """断连：证书膨胀 + 阈值抬升，保证 Exec_edge(t) 非增且 ⊆ Exec_v4"""
        return [self.weaken(c, t_now - c.t) for c in last_certs]

    def _conservative_floor(self, cert):
        """取该证书历史上最保守的形态（τ 取最大、m 取最小）"""
        return cert.with_threshold(cert.tau_max, cert.margin_min)
```

### IP-494 MAPK：材料辨识与材料条件化（探测异步 ~50–200 ms）

```python
@dataclass
class MaterialAwarePhysicsKernel:
    """MAPK：在线材料辨识 → 材料证书 MC → 条件化物理/平衡/末点门"""
    tau_mat: float = 0.8
    probe_policy: str = "press_slide_lift"    # 触觉探测动作序列
```

### IP-495 SLCC：陈旧-分层证书演算与核心定理（离线理论）

```python
class StalenessLayeredCertCalc:
    """SLCC：在 CERTCALC 上增加 ⊖_Δ、层级组合 ∧_layer、材料参数化证书 C(θ)"""

    @staticmethod
    def weaken(cert, factor: float):
        # 单调弱化：factor∈[0,1]，越大越陈旧越严（与 ECCA.weaken 同构）
        return cert.with_threshold(cert.tau + KAPPA * factor,
                                   cert.margin * (1 - GAMMA * factor))

    @staticmethod
    def layer_and(l0, l1):
        # 层级合取：两层都过才过；l1 已由 ⊖_Δ 收紧
        return CertCalc.meet(l0, l1)

    @staticmethod
    def material_robust_cert(theta0, eps):
        # 认证参数球而非单点，覆盖辨识不确定集
        return CertBall(center=theta0, radius=eps)

# 定理 5：单调陈旧
def theorem_monotone_staleness():
    """
    ⊖_Δ 关于 Δ 单调：Δ₁ ≤ Δ₂ ⟹ Exec(⊖_{Δ₂}C) ⊆ Exec(⊖_{Δ₁}C) ⊆ Exec(C)。
    证明：weaken 中 τ 随 Δ 增、margin 随 Δ 减，门条件 m > τ 单调更难满足；Δ=0 为恒等。
    推论：云延迟/断连只会收缩执行集，与定理 2 一致，天然 fail-closed。
    """

# 定理 6：材料鲁棒认证
def theorem_material_robustness():
    """
    设安全违例指示 V(θ) 在 θ0 附近 L-Lipschitz 且 V(θ0)=0。
    则 ∀θ ∈ B(θ0, ε): V(θ) ≤ L·ε。故认证球 B(θ0, ε_cert) 覆盖 U_mat 即安全。
    推论：kc_mat 通过 ⇒ 该类内任意偏差 ≤ ε_cert 的实例安全（概率 ≥ 1−δ_mat）。
    """

# 定理 7：材料迁移界
def theorem_material_transfer():
    """
    在 m1 上认证的规则迁移到 m2：违例增量 ≤ L·d(θ_{m1}, θ_{m2})。
    仅当 d ≤ ε_cert 才允许迁移，否则必须重新 MSRG(θ)+MAPK。
    """

# 定理 8：分层 fail-closed 与执行集收缩
def theorem_layered_contraction():
    """
    Exec_v5 ⊆ Exec_v4：(a) kc_mat 非恒真（未知材料被拒）；(b) E_m ⊆ E_nom；
    (c) ⊖_Δ 只收紧（定理 5）。三者独立，任一即可严格收缩。
    """
```

### IP-496 EFA-v5：八硬门 + 软评分 + 分层流水线

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：八硬门 fail-closed；云层门经 ⊖_Δ；ECS_v5 = ECS_v4·η_mat·η_sync"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    ecca: EdgeCloudCertificateArchitecture
    mapk: MaterialAwarePhysicsKernel
    mu_S: float = 0.75

    def hard_gate(self, x, t_now, rule_id, hic, eec, bcc_fast, mc: MC,
                  cloud_certs, ctx, traj, context) -> tuple[bool, str]:
        # 优先级：HIC veto 最高
        if self.hic.veto_active(hic):                 return False, 'HIC_STOP'
        # L0 边缘反射（硬实时；含 kc_ee / kc_bal_fast / kc_mat）
        ok0, r0 = self.ecca.l0_edge_gate(eec, bcc_fast, mc, t_now)
        if not ok0:                                   return False, r0
        # L1 云审议（⊖_Δ 调整后；任一失败即拒）
        cc = self.ecca.l1_cloud_gate(cloud_certs, t_now)
        c_cov  = _get(cc, 'coverage'); c_phy = _get(cc, 'physics')
        c_mem  = _get(cc, 'mem');      c_val = _get(cc, 'val')
        if not c_cov.ok:                              return False, 'COVERAGE_BLIND'
        if not c_phy.ok or c_phy.mu_pass < self.mu_S: return False, 'PHYSICS_UNPROVEN'
        if not c_mem.ok:                              return False, 'MEMORY_REJECT'
        if not c_val.ok:                              return False, 'VALUE_MISALIGNED'
        return True, 'FORGED'

    def ecs_v5(self, base_v4: float, eta_mat: float, eta_sync: float) -> float:
        return base_v4 * eta_mat * eta_sync
```

## 4. 正确性论证（增量更新）

### 引理 43（有界陈旧证书的安全性）

**陈述**：设边缘状态漂移满足 Drift(t, t_c) ≤ D·(t − t_c)（D 为 Lipschitz 漂移常数），云证书在 t_c 时对状态 s(t_c) 有效。则对 t > t_c，⊖_Δ 调整后的证书 C_t 对 s(t) 仍安全，当且仅当 Δ ≤ min(TTL, Δ_max/D)。

**证明**：由 Drift 界，s(t) 与 s(t_c) 的最大偏差 ≤ DΔ；weaken 将阈值抬升 κΔ、边际收缩 γΔ，其收缩量覆盖漂移带来的安全裕度损失 DΔ 当 Δ ≤ Δ_max/D；超出则 TTL 触发保守回退。∎

**工程含义**：把「云证书能用多久」从拍脑袋的固定 TTL 变成由漂移常数 D 与 Δ_max 决定的**可计算时效**；陈旧期间只收紧，故不会因延迟而误放。

### 引理 44（材料辨识置信的 PAC 界）

**陈述**：设触觉探测样本 n 个、材料参数维度 d_θ，辨识器为 (ε, δ)-PAC。则 kc_mat 通过（conf ≥ τ_mat 且 U_mat ⊆ B(θ_0, ε_cert)）时，真实材料参数落入认证球的概率 ≥ 1 − δ_mat，其中 δ_mat = f(n, d_θ, τ_mat)。

**证明**：由 PAC 学习界，n ≥ O((d_θ + log(1/δ))/ε²) 即可保证 ε-近似；后验 conf 与 U_mat 由贝叶斯融合给出，阈值 τ_mat 对应置信下界。∎

### 定理 v5（分层收缩、材料鲁棒与八锚点完备）

**陈述**：在 (B1)~(B6)（继承 v4）与新增假设 (B7) 漂移 Lipschitz 有界、(B8) 材料参数可辨识且安全违例 L-Lipschitz、(B9) 材料包络 E_m ⊆ E_nom 下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格收缩）；
(ii) 云延迟/断连导致的误放率 = 0（⊖_Δ 只收紧，引理 43）；
(iii) 材料误判导致的违例率由引理 44 + 定理 6 界；
(iv) 材料迁移违例增量 ≤ L·d(θ_{m1}, θ_{m2})（定理 7）；
(v) 层级组合保持 fail-closed，八硬门合取为格中最大下界。

**证明**：(i) kc_mat 非恒真、E_m ⊆ E_nom、⊖_Δ 单调收紧，三者独立，任一即可严格收缩（定理 8）。(ii) 由引理 43 与定理 5。(iii) 由引理 44 与定理 6 的参数球覆盖。(iv) 由定理 7。(v) 由 SLCC 的层合取与 CERTCALC 格结构。∎

**诚实声明**：(B7) 漂移常数 D 在接触突变/滑移时可能瞬时超界，需在线估计并保留鲁棒放大；(B8) 安全违例对材料参数的 Lipschitz 常数在接触模式切换（粘→滑、刚→柔）处可能不连续，参数球认证在模式边界附近会失效，需按接触模式分段认证；(B9) 材料包络的「只收紧」约束会牺牲软材料的性能上限（本可允许更大形变）。缓解：分段/分模式认证 + 漂移常数在线辨识 + 软材料单独放宽通道（须重新走 MSRG 认证，不直接放宽 v4 包络）。

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|

## 7. 本轮最大风险（最终确认）

**一句话**：**材料误辨识与云端证书陈旧会形成相关性失效**——单一错误的 θ_mat 会同时污染物理/平衡/末点三门（三者共享同一错误前提，合取仍"全过"却全错），而陈旧的云端价值/物理证书可能掩盖边缘状态漂移，使八门合取产生「全部通过但全部基于错误前提」的虚假保证。
