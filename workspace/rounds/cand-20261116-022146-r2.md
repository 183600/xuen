# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「SLAM」×「跨任务泛化」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**空间锚定 + 证书迁移 + 地图可信门控**。v9 把 SLAM 压成一个标量 risk_SLAM、把「跨任务」压成在线从零学习；这一轮要把 SLAM 从「风险传感器」升格为「跨任务知识的空间载体」，并回答一个被 v9 回避的问题：**哪些安全知识可以迁移，哪些必须逐任务重证**。任何迁移模块失效都必须注入中立元、逐位退回 v9（再退回 v8），绝不允许「看起来合理」的跨任务先验越权。

## 0. 直觉与动机

**灵感 1（SLAM → 持久语义-可供性地图）**
直觉：人类走进一家新厨房找杯子，不是从零学起，而是带来「杯子通常在橱柜、抽屉可拉开、桌沿可临时放置」这类与空间绑定的经验。SLAM 给机器人的正是这样一个**度量一致、可持久**的坐标系——但 v8/v9 只把它榨成一个 risk_SLAM 标量（漂移/滑移风险），丢掉了地图作为**记忆**的价值。核心创新：**语义-可供性地图（SemanticAffordanceMap, SAMap, IP-357）**：在 SLAM 位姿图上挂可供性层 a(c)（可抓/可放/可穿越）、来源 prov(c)（自观测/迁移/人工标注）、不确定度 σ(c) 与时间戳 t(c)。跨任务知识 = (空间单元 c, 可供性 a(c), provenance prov(c))；**几何是任务不变的锚，语义是可证伪、可撤销的先验**。

**灵感 2（跨任务泛化 → 任务不变证书分解）**
直觉：跨任务泛化最诱人也最危险的地方是安全。v8 的 SpatialCert 逐任务、逐场景在线复核——安全但没有记忆；直接把它跨任务复用又会把「旧任务的安全」当成「新任务的安全」。真正可迁移的是**几何**：清障距离、可通行宽度、刹停距离只依赖 SLAM 地图与运动学，与「抓杯子还是擦桌子」无关；而可操作性、抓取余量、语义风险是任务相关的。核心创新：**任务不变证书（TaskInvariantCertificate, TIC, IP-358）**：g(c)=g_geo(c) − r_τ(c)，g_geo 由 SAMap 几何核给出（任务族共享，含地图一致性余量 ε_map），r_τ 是任务相关残差（必须当前任务在线标定，禁止跨任务复用）。跨任务安全论证由此**局部化**：迁移只迁移几何核，残差永不留白（引理 87）。

**灵感 3（跨任务泛化 → 迁移控制器 + 地图可信守卫）**
直觉：迁移不是无条件增益。把「厨房桌边可站立」搬到有玻璃挡板的场景，会得到自信的错误。更有害的是 SLAM 只保证位姿自洽、不保证世界不变：家具被移动后地图仍然「自洽地错着」。核心创新：**跨任务迁移控制器（CrossTaskTransferController, XTC, IP-359）** + **地图一致性守卫（MapConsistencyGuard, MCG, IP-360）**：任务嵌入 e_τ 与地图重叠 ρ 决定迁移先验权重 w_prior=λ_map·ρ（λ_map 由 loop-closure 残差、覆盖度、感知别名、动态变化共同给出），并配 do-no-harm 监控 η_neg；一旦迁移版显著劣于基线版，立即降级该 (单元,任务) 的可信度并回退。**迁移是加速器，不是安全假设**：φ^transfer 不成立时 w_prior=0，严格退回 v9 在线学习。

## 1. 研究问题（轮次升级版）

- **Q1（迁移保守性）**：在怎样的地图一致性（loop-closure 距离误差 ≤ ε_map）与覆盖条件下，几何核证书的跨任务迁移不会高估安全余量？「静态世界」假设被打破时，保守性如何被时间/变化检测截断？
- **Q2（收益/风险权衡）**：如何定义任务嵌入与地图重叠，使小样本迁移收益最大，同时把负迁移概率压在一个可计算、可预注册的界内？
- **Q3（地图可信度）**：如何及时检测 SLAM 漂移、感知别名与动态几何变化，使「看起来确定」的陈旧先验不能获得高权重，而未知 frontier 一律退回在线学习？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 空间锚定迁移律（Spatial-Anchored Transfer, STAM）**
一切跨任务知识必须以 SLAM 地图的度量一致空间单元为索引；知识三元组 = (空间单元 c, 可供性 a(c), provenance prov(c))，并携带 σ(c), t(c)。无空间锚的知识不得进入迁移池；迁移池中的每条知识可被 provenance 审计与单条撤销。

**P14 证书可迁移律（Transferable Certificate, TIC）**
安全证书分解为任务不变几何核 g_geo 与任务相关残差 r_τ；迁移只允许迁移 g_geo，且必须扣除地图一致性余量 ε_map（保守化）；r_τ 必须当前任务在线标定，禁止跨任务复用；几何核超一致性界或「静态世界」假设失效即禁用迁移，退回 v8 的逐任务 SpatialCert。

**P15 地图可信门控律（Map-Trust Gating, MCG）**
迁移先验权重 w_prior=λ_map·ρ，其中 λ_map=min(λ_cov, λ_loc, 1−λ_alias, 1−Δ_dyn)。λ_map 越阈下降使 φ^transfer 变假、w_prior←0；未知/退化地图一律视为「无先验」而非「全信任」。**安全守卫的中立元是拒绝先验，不是接受先验**——这与 v9 中 DA/SPR 的「零值即安全退化」方向相反，必须单独审计。

## 3. 与基线的接口（如何退化）

- PSAM 失效（无持久地图）⇒ 仅用瞬态 SLAM 几何（v9 的 risk_SLAM 标量）⇒ 等价 v9；
- TIC 失效（几何核超一致性界 / 静态假设破坏）⇒ 逐任务 SpatialCert 复核 ⇒ 等价 v8 安全语义；
- XTC 失效 ⇒ 无任务嵌入、无回放、w_prior≡0，从零在线学习 ⇒ 等价 v9；
- MCG 失效 ⇒ 保守禁用先验（w_prior≡0），而非全信任 ⇒ 等价 v9；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 契约化五级退回 v8；
- 全部失效 ⇒ 退回 MetricVoiceGauge-ACMD v9 → DA-SPR-Cal v8 → v7 → v6。

## 4. 预期贡献

1. **SLAM 从传感器升格为记忆**：SAMap 把可供性与 provenance 挂到度量一致的空间单元上，使跨任务知识可审计、可撤销、可时间衰减；
2. **任务不变证书与迁移定理**：SpatialCert 的几何核/任务残差分解与引理 87 给出「迁移只迁移几何核」的保守性条件，首次把安全论证从单任务推广到任务族；
3. **负迁移防护**：地图可信度门控 + do-no-harm 监控 + 空间键控回放，使泛化收益与风险都可在线度量、可预注册界约束；
4. **覆盖-泛化张力的显式化**：引理 91 证明门控把泛化收益严格限制在「已映射且可信」区域，从而把「跨任务泛化在 frontier 最有价值」这一结构性矛盾留作下一轮主动探索的入口；E571–E590 系统覆盖。

## 5. 本轮最大风险

**一句话**：跨任务泛化把旧任务证书迁移到「几何相似但世界已变」的场景时最危险——SLAM 只保证位姿自洽而非世界不变，家具移动与感知别名会让 λ_map 与 ρ 同时给出虚假高置信，迁移恰在最像的地方最自信地失效。

## 1. 符号体系增量（定义 540–547）

**新增定义 540（语义-可供性地图 SAMap）** 在 SLAM 位姿图 𝒫_t 上维护的单元级知识库：𝒮_t = {(c, g_geo(c), a(c), prov(c), σ(c), t(c))}，c 为度量一致的体素/语义栅格单元。更新规则：新观测以 provenance=self 融合并降低 σ；迁移知识以 provenance=transfer 写入且 σ 不低于地图一致性界；每条知识可由 provenance 单条撤销。SAMap 只存「几何核 + 可供性」，不存任务策略本身。

**新增定义 541（任务嵌入与地图重叠 ρ）** 任务 τ 的访问单元集 V_τ 与嵌入 e_τ；对任务对 (τ,τ′)：ρ(τ,τ′) = λ_vis·J(V_τ,V_τ′) + (1−λ_vis)·cos(e_τ,e_τ′)，J 为 Jaccard 相似度，默认 λ_vis=0.6。ρ 只描述「知识可能相关」，不描述「知识仍然正确」——后者由 λ_map 与 φ^transfer 决定（引理 91）。

**新增定义 542（任务不变证书分解 TIC）** 对单元 c 与任务 τ，几何清障证书分解为
```
g(c;τ) = g_geo(c) − ε_map − r_τ(c)
```
其中 g_geo 任务族共享、ε_map 为地图一致性余量（保守化项，见引理 87），r_τ 是任务相关残差（必须由当前任务在线标定，跨任务复用被 φ^transfer 拒绝）。当 τ 的抓取/操作语义改变，只改变 r_τ，几何核不变——这就是「可迁移」的精确定义。

**新增定义 543（地图可信度 λ_map）**
```
λ_map(c) = min( λ_cov(c), λ_loc, 1 − λ_alias(c), 1 − Δ_dyn(c) )
λ_loc    = 1 / (1 + ε_lc/ε_0)         # ε_lc: loop-closure 残差
```
λ_cov 为局部覆盖度（邻域已观测单元比例），λ_alias 为感知别名分数（place-recognition 后验熵归一化），Δ_dyn 为动态几何变化率（定义 544）。λ_map 是单调保守量：任一分量下降都只会降低迁移权重。

**新增定义 544（动态几何变化与时间衰减）** SAMap 每次重观测对每单元维护几何残差 ξ(c,t)=|g_geo^new(c) − g_geo^old(c)|；Δ_dyn(c)=滑窗内 ξ 超过 τ_geom 的单元比例。单元不确定度按年龄衰减 σ(c) ← σ_0·exp(−(t−t(c))/T_σ)，并随重观测复位。λ_map 与 σ 共同实现「先验有有效期」（引理 90）。

**新增定义 545（迁移先验与元权重）** 迁移先验权重 w_prior(c,τ)=λ_map(c)·ρ(τ,τ_retrieved)。新任务元权重 w_τ = w_base ⊕ w_prior·Δw(e_τ)，其中 w_base 为 v8 的 5 维元权重基线，Δw 为相似任务历史增量，`⊕` 为 v8 定义 495 的聚合算子；中立元 Δw^⊥=0 ⇒ w_τ=w_base ⇒ 与 v9 完全一致。w_prior 有界 ‖w_τ−w_base‖ ≤ γ·w_prior。

**新增定义 546（迁移信任谓词 φ^transfer）**
```
φ^transfer(c,τ) = [λ_map(c) ≥ τ_map] ∧ [ρ(τ,τ_ret) ≥ τ_ρ] ∧ [σ(c) ≤ τ_σ]
                  ∧ [age(c) ≤ τ_age] ∧ [η_neg(τ) ≤ τ_neg] ∧ [ε_map ≤ ε_max]
```
任一不成立 ⇒ w_prior(c,τ)=0，TIC 使用 v8 逐任务 SpatialCert。未知单元（λ_cov<τ_cov）自动满足 φ^transfer=false（引理 91）。

**新增定义 547（负迁移监控 η_neg）** 对任务 τ，滑窗 W_neg 内交替执行「迁移版（使用 SAMap 先验）」与「基线版（v9 在线学习）」，η_neg(τ)=EMA(J_base − J_transfer)/scale（J 为 v9 定义 537 的任务进展−安全罚）。若 η_neg>τ_neg 且统计显著（滑窗置信区间不重叠），触发 `demote(τ)`：把该任务所有 transfer 知识的 σ 抬升、w_prior 置 0，并记录 provenance 供审计。监控只做「降级+回退」，不做「升级+信任」。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v8 不变；w_τ 的迁移增量受引理 89 界约束。
**定义 521（DA-OTL）** 继承 v8 不变；τᵢ(t) 在迁移证书下以 (g_geo−ε_map, r_τ) 双源复核。
**升级定义 526（SpatialCert，v10）** SpatialCert(c;τ) 拆为任务不变几何核 g_geo(c) 与任务残差 r_τ(c)：几何核来自 SAMap（含 ε_map 保守项），残差来自当前任务在线标定；迁移仅在 φ^transfer 成立时把几何核跨任务复用，否则逐任务复核。
**升级定义 533（块证书，v10）** Ĉ_t 的几何项 ĝ_min 由 SAMap 几何核给出：ĝ_min = min_{k≤K} (g_geo(c_k) − ε_map) − r_τ − β；任务项 r_τ 与 β 不变。故块证书天然继承迁移保守性（引理 87 与 v9 引理 82 联合）。
**升级定义 496（软证书，v10）** δ_trigger 的六条件：σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid ∧ φ^transfer 一致性（迁移知识必须附带可信 provenance）。任一失败同样触发 M₀ 硬检查。

## 3. 关键算法骨架

```python
# IP-357 SemanticAffordanceMap：SLAM 图上的持久知识库
class SemanticAffordanceMap:
    def __init__(self, sigma0=0.10, T_sigma=3600.0, tau_geom=0.03):
        self.cells = {}                 # c -> Cell(g_geo, a, prov, sigma, t, eps)
        self.sigma0, self.T_sigma, self.tau_geom = sigma0, T_sigma, tau_geom

    def update(self, pose, obs, task_id, source='self'):
        for c, g_obs, a_obs in self.project(pose, obs):
            cell = self.cells.get(c)
            if cell is None:
                self.cells[c] = Cell(g_obs, a_obs, source, self.sigma0, now())
            else:
                xi = abs(g_obs - cell.g_geo)                    # 定义 544
                cell.g_geo = fuse_geometry(cell.g_geo, g_obs)   # metric fusion
                cell.a = fuse_affordance(cell.a, a_obs)
                cell.sigma = max(sigma_floor, cell.sigma * exp(-(now()-cell.t)/self.T_sigma))
                cell.t = now()
                cell.dyn_ratio = ema(cell.dyn_ratio, 1.0 if xi > self.tau_geom else 0.0)

    def query(self, c):  # O(log N) 空间索引
        return self.cells.get(c)

    def dynamic_change(self, region):
        return mean(self.cells[c].dyn_ratio for c in region)

    def revoke(self, provenance='transfer'):                # 单条知识撤销
        for c in [c for c, v in self.cells.items() if v.prov == provenance]:
            del self.cells[c]


# IP-360 MapConsistencyGuard：地图可信度与门控
class MapConsistencyGuard:
    def __init__(self, samap, eps0=0.02, tau_map=0.6):
        self.samap, self.eps0, self.tau_map = samap, eps0, tau_map

    def map_trust(self, pose, region):
        lam_cov   = coverage(self.samap, region)
        lam_loc   = 1.0 / (1.0 + loop_closure_residual(pose) / self.eps0)
        lam_alias = 1.0 - place_recognition_alias(pose)
        lam_dyn   = 1.0 - self.samap.dynamic_change(region)
        return min(lam_cov, lam_loc, lam_alias, lam_dyn)     # 定义 543


# IP-358 TaskInvariantCertificate：几何核 + 任务残差
class TaskInvariantCertificate:
    def __init__(self, samap, mcg, residual_model, eps_max=0.05):
        self.samap, self.mcg, self.r = samap, mcg, residual_model
        self.eps_max = eps_max

    def transfer_predicate(self, c, tau, rho, lam_map, eta_neg):
        cell = self.samap.query(c)
        return (lam_map >= self.mcg.tau_map and rho >= TAU_RHO
                and cell is not None and cell.sigma <= TAU_SIGMA
                and age(cell) <= TAU_AGE and eta_neg <= TAU_NEG
                and cell.eps_map <= self.eps_max)            # 定义 546

    def certificate(self, c, task, tau, rho, lam_map, eta_neg):
        if self.transfer_predicate(c, task, rho, lam_map, eta_neg):
            cell = self.samap.query(c)
            g_geo = cell.g_geo - cell.eps_map               # 保守化（引理 87）
            r = self.r.predict(c, task)                     # 当前任务在线标定残差
            return (g_geo - r, 'transfer')
        return (v8_spatial_cert(c, task), 'local')          # 逐任务复核（v8 语义）


# IP-359 CrossTaskTransferController：迁移控制器 + 负迁移防护
class CrossTaskTransferController:
    def __init__(self, samap, tic, mw, memory, tau_rho=0.30, tau_neg=0.05):
        self.samap, self.tic, self.mw, self.memory = samap, tic, mw, memory
        self.embed, self.visited = {}, {}
        self.tau_rho, self.tau_neg = tau_rho, tau_neg
        self.neg = DoNoHarmMonitor(window=200)

    def register(self, task_id, task_desc, skills):
        self.embed[task_id] = task_encoder(task_desc, skills)
        self.visited[task_id] = set()

    def overlap(self, a, b):                                # 定义 541
        return 0.6 * jaccard(self.visited[a], self.visited[b]) \
             + 0.4 * cos(self.embed[a], self.embed[b])

    def prior(self, task_id, c, lam_map):
        best = max((self.overlap(task_id, t) for t in self.embed if t != task_id),
                   default=0.0)
        eta = self.neg.stat(task_id)
        if not self.tic.transfer_predicate(c, task_id, best, lam_map, eta):
            return 0.0, best
        return lam_map * best, best                         # w_prior = λ_map·ρ

    def replay(self, task_id, c):                           # 空间键控回放（定义 545）
        return self.memory.retrieve(c, self.embed[task_id], k=8)

    def observe(self, task_id, J_transfer, J_base, use_transfer):
        self.neg.update(task_id, J_transfer, J_base, use_transfer)
        if use_transfer and self.neg.violated(task_id, self.tau_neg):
            self.mw.set_prior_weight(task_id, 0.0)          # demote：仅降级
            self.samap.revoke_task(task_id, provenance='transfer')


# 主闭环集成：MetricVoiceGauge-STAM
def metricvoicegauge_round_10(M, s, obs, task_id, task_desc=None, ...):

        w_prior = 0.0                                   # 迁移禁用，退回 v9
```

## 4. 推导

**引理 87（几何核一致性与证书迁移保守性）** 设 SAMap 由 SLAM 位姿图构建，任意两已映射单元间距离误差 ≤ ε_map（由 loop-closure 残差与协方差换算），且对静态世界有 |g_true(c) − g_geo(c)| ≤ ε_map。则迁移证书
```
g^trans(c;τ) = g_geo(c) − ε_map − r_τ(c)
```
满足 g^trans(c;τ) ≤ g_true(c) − r_τ(c)：对任意任务残差 r_τ ≥ 0，迁移证书对真实清障是**保守下界**，不会高估安全余量。若 ε_map>ε_max 或 λ_map 使一致性界失效（动态世界），则 φ^transfer=false，退回定义 526 的逐任务复核。证明：由 |g_true−g_geo|≤ε_map 得 g_geo−ε_map ≤ g_true；两侧同减 r_τ 保序，得证。注意该保守性**以静态世界假设为前提**，其失效由定义 544 的动态检测与引理 90 的时间衰减截断，这正是本轮最大风险的来源。∎

**引理 88（中和退化与方向性审计）** 对四个新模块注入中立元：SAMap⇒空地图/瞬态几何；TIC⇒v8 逐任务 SpatialCert；XTC⇒w_prior≡0、无回放；MCG⇒w_prior≡0（**拒绝先验**）。则主闭环可观测输出与 v9 对应退化级逐位一致；特别地 MCG 的中立元只会令迁移更保守，绝不会把「未知」当成「可信」。结合 v9 引理 83，整体可退回 v9 ACMD，再退回 v8。∎

**引理 89（负迁移风险上界与安全迁移域）** 设任务收益 |J|≤L_max，φ^transfer 在 ρ<τ_ρ 或 λ_map<τ_map 时为假，do-no-harm 监控以滑窗对比迁移/基线并在显著性水平 α 下降级。则在 φ^transfer 成立区域，迁移导致的单步性能下降期望满足
```
E[ΔJ] ≤ (1 − ρ)·L_max + η_neg^slack
```
且当 ρ→0 时 w_prior=λ_map·ρ→0、ΔJ→0。故负迁移风险随空间重叠单调收敛；监控把超出 τ_neg 的个案截断并回退。该界是**概率性**的（依赖滑窗显著性与 λ_map 估计），不是绝对安全保证——这是本方案与 v8 硬证书的语义差异，须在 E574/E582 中实测校准。∎

**引理 90（地图漂移的时间衰减与维护下界）** 设世界持续变化使 Δ_dyn(t) 非降，单元不确定度按 age 衰减 σ(c) ∝ exp(−Δt/T_σ)，则 λ_map(t) 单调不增，存在有限 T_expire 使 φ^transfer 在 T_expire 内变假。故任何被迁移的先验都有**有限有效期**；要维持泛化收益，地图重观测/重标定频率存在下界 f_min>0（由 T_expire 与任务节奏共同确定）。∎

**引理 91（覆盖-泛化结构性张力 / frontier 安全）** 对新任务 τ 访问的未映射单元 c（λ_cov(c)<τ_cov），φ^transfer(c,τ)=false，w_prior=0，系统退回 v9 在线学习。因此跨任务泛化收益被严格限制在「已映射且可信」的区域；而新任务的边际价值往往恰在陌生 frontier。该张力无法由门控本身消除（门控只能保证安全，不能变出信息），只能由主动探索缓解——这是本方案留给 v11 的显式接口，也是本轮最大风险的代数形式。∎
