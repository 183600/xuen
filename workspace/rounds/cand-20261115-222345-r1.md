# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「力矩控制」×「抓取规划」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570；IP-340–356）。
> 本轮纪律：**柔顺执行 + 鲁棒抓取证书 + 不可逆承诺**。两个灵感分别治理 v9 的两种债：**动作空间债**（v9 的 a 是运动学位姿，证书只预测间隙/努力，无法表达接触力、摩擦与柔顺，在接触丰富任务中"运动学安全≠物理安全"）与**不可逆债**（v9 的中止点假设动作可随时撤回；抓取一旦离台即承诺，撤回语义从"后退"变为"放下/保持"）。新模块一律为可选增强：失效即注入中立元，严格等价退回 v9（引理 90），而非行为漂移。

## 0. 直觉与动机

**灵感 1（力矩控制 → 分块的是阻抗，不是力矩）**
直觉：v9 把 5Hz 的块直接展开成逐步运动学指令；但力矩控制在接触中必须 1kHz 闭环，绝不能把原始力矩序列"分块后开环执行"——那等于把稳定性交给一个 200ms 前的预测。正确的分层是：**5Hz 分块阻抗参数 Z=(K_d,D_d,τ_ff) 与参考轨迹，50Hz 守卫相/证书，1kHz 由本地阻抗环+能量罐生成力矩**。核心创新：**阻抗-力矩执行端口（ITP）**＋**虚拟能量罐（ET）**：块证书不再只预测间隙，还预测能量预算 Ê 与力矩峰值 τ̂；能量罐把"接触稳定性"从模型精度问题转化为能量不等式。关键设计：ITP 失效时注入的中立元不是 τ=0（自由漂浮，危险），而是 **Z^⊥=刚性跟踪**，严格复现 v9 的运动学执行（定义 548）。

**灵感 2（抓取规划 → 从布尔抓取有效性到鲁棒扳手证书）**
直觉：v9 的 γ̂_grasp 是由前向模型给出的布尔值，它既不含摩擦系数、也不含位姿不确定性、更不含外载荷——"看起来能抓"与"力闭合可证"是两件事。抓取规划的正解是**抓取扳手空间（GWS）**：把接触力锥的所有原始扳手张成凸多面体，外载荷必须落在其内部才有静力平衡。核心创新：**鲁棒抓取证书（RGC）**：在摩擦系数区间 μ∈[μ^-,μ^+]、位姿椭球 o∈E(ô,Σ)、负载/加速度界上，计算 GWS 的**可证内近似**与实际外载荷球的比值 η_robust；η_robust≥1 才允许承诺。两档安全：力闭合（操作）与**笼闭（caging，运输）**——力闭合不可证时，笼闭仍可保证物体不逃逸。这把抓取从"分类器输出"升级为"带不确定集的凸证书"。

**灵感 3（两者耦合 → 承诺相与不可逆中止）**
直觉：导航的中止是"停下"，抓取的中止是"放哪、还能不能放"。抓取天然分相：接近（可退）→ 闭合（可重抓）→ 提起（**承诺点**）→ 运输（只能放/保持）→ 放置。核心创新：**承诺相执行器（CPE）**＋**相依赖中止集（PAA）**：每个块声明相 φ，并为每步提供相适配的中止动作——承诺前是"退回到已认证预抓取态"，承诺后是"放到最近认证支撑域"或"能量有界的保持"。配套**滑脱监视器与重抓取梯（SRL）**：用保守 μ^- 与力/力矩残差计算滑脱分数，按代价递增选择"增力→重闭合→换候选→放下重试"，且每级都有证书，禁止无限升级（引理 91）。

## 1. 研究问题（轮次升级版）

- **Q1（阻抗分块与被动性）**：分块阻抗参数 + 1kHz 本地环 + 能量罐，能否在接触瞬态下给出与 v8/v9 运动学执行同阶的安全保证？能量不等式能否替代精确接触模型来界定"接触稳定"？
- **Q2（鲁棒抓取证书）**：在摩擦/位姿/负载不确定集上，如何高效计算 GWS 的可靠内近似与 η_robust，使"承诺"不依赖单点估计？力闭合与笼闭两档如何无缝切换？
- **Q3（不可逆中止）**：相依赖中止集在什么条件下保证"承诺后永不无支撑释放"？滑脱检测与重抓取梯能否在有限代价内恢复，且不引入新的抖振？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 阻抗透明律（Impedance Transparency, ITP）**
柔顺层必须可旁路：ITP 正常时在 v9 参考上叠加阻抗/力矩修正；ITP 失效时注入 Z^⊥=刚性跟踪（或直接旁路），执行结果等价 v9。**禁止把 τ=0 当作中立元**——自由关节不是恒等，是不受控。分块对象是阻抗参数与参考，不是原始力矩序列。

**P14 鲁棒抓取证书律（Robust Grasp Certification, RGC）**
任何抓取承诺前必须持有 η_robust≥1 的力闭合证书，或 caging_flag=true 的笼闭证书；证书必须在整个不确定集 U_g 上成立，而非单点估计。禁止以"平均成功率"替代最坏情况证书。证书含抓取力上界 f_max 与易碎约束 f_fragile。

**P15 承诺相安全律（Commitment-Phase Safety, CPE）**
每块声明 φ∈{A,C,L,T,P}；承诺点定义为 C→L。承诺前每步必须有认证撤回；承诺后每步必须有认证放置或能量有界保持；若某步两者皆无，则该块在承诺点前即被拒绝。

## 3. 与基线的接口（如何退化）

- ITP/ET 失效 ⇒ 旁路阻抗层，Z^⊥=刚性，执行 v9 运动学指令；
- RGC 失效（不确定集无法给出可靠内近似）⇒ γ^⊥=v9 布尔 γ̂_grasp，按 v9 规则接受；
- CPE 失效 ⇒ P_t^φ 退化为 v9 的 P_t，相固定为"承诺前"，抓取仅在 v9 边界检查下执行；
- SRL 失效 ⇒ s^⊥=0、梯为空，不做滑脱响应；
- v9 任一模块失效 ⇒ 按 v9 五级链继续退化至 v8/v7。

## 4. 预期贡献

1. **阻抗分块/能量罐**：把 5Hz 分块与 1kHz 接触稳定性解耦，用能量预算而非精确接触模型给稳定性证书；
2. **鲁棒抓取证书**：把 γ_grasp 从布尔升级为带摩擦/位姿/负载不确定集的 GWS 余量，提供力闭合与笼闭两档；
3. **承诺相执行**：把"不可逆"显式写进中止语义，区分撤回/放下/保持，给出承诺点前的可证安全条件；
4. **接触-抓取闭环**：E571–E590 覆盖阻抗跟踪、被动性、扳手余量、相中止、滑脱恢复与端到端。

## 5. 本轮最大风险

**一句话**：鲁棒力闭合证书的保守性与接触瞬态模型误差同向放大——为通过率放宽 η_min 恰在冲击/滑脱时最危险，而收紧 η_min 又会让系统退化为"永不抓取"，即证书在最需要它的接触瞬态既可能过保守、又可能不可靠。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-TGC**（Metric Voice Gauge with Torque-Compliant Grasp Certificates）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570；IP-340–356）。
> 本轮灵感：「力矩控制」×「抓取规划」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v9 的 AC/MW/ID 三模块原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元，严格等价退回 v9（引理 90），而非行为漂移。特别地，**力矩端口的中立元是"刚性"而非"零力矩"**，这是本轮最容易写错的一处。

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |
|---|---|
| Z^k = (K_d^k, D_d^k, τ_ff^k, q_d^k, q̇_d^k) | 第 k 步阻抗参数与参考（刚度、阻尼、前馈力矩、位置/速度参考） |
| ζ_t = (Z^{1:K}, Ĉ_t, P_t^φ) | 阻抗-力矩动作块：阻抗参数序列、力矩-接触证书、相依赖中止集 |
| E_t ∈ [0,E_max] | 虚拟能量罐存量；E_min 为安全保持阈值 |
| C = {(i, p_i, n_i, μ_i)} | 接触集：接触点、法向、摩擦系数（含区间 [μ^- , μ^+]） |
| GWS(C) | 抓取扳手空间：接触力锥原始扳手的凸包 |
| ρ_ext(U) | 不确定集 U 上外载荷/冲击冲量球半径上界 |
| η_robust | 鲁棒扳手余量：inradius(GWS_inner)/ρ_ext |
| φ ∈ {A,C,L,T,P} | 抓取相：Approach / Close / Lift / Transport / Place |
| P_t^φ | 相依赖中止集；承诺前为撤回集，承诺后为放置/保持集 |
| s_t | 滑脱分数：切向/法向力与保守摩擦的比值 |
| L = (r_0,r_1,r_2,r_3) | 重抓取梯：增力、重闭合、换候选、放下重试 |

**新增定义 540（阻抗-力矩动作块 ImpedanceTorqueChunk）** 一次决策的输出单元升级为 ζ_t=(Z^{1:K}, Ĉ_t, P_t^φ)，其中 Z^k 为阻抗参数而非原始力矩。块的执行分三频：5Hz 生成/重规划，50Hz 相守卫，1kHz 本地阻抗环按
```
τ_cmd(k) = τ_ff^k + K_d^k(q_d^k − q) + D_d^k(q̇_d^k − q̇)
```
生成力矩，Z^k 之间线性插值。**禁止将 τ^{1:K} 作为开环序列分块执行**。块长同时受 v9 信任域与相门控：K_eff^φ = min(K_eff^{v9}, K_max^φ)，K_max^A=2（冲击前缩短）、K_max^C=1（闭合单步）、K_max^{L,T}=K_max、K_max^P=2。

**新增定义 541（虚拟能量罐 VirtualEnergyTank）** 能量罐 E_t 把接触稳定性写成能量不等式。设 P_cmd=τ_cmd^T q̇，P_inj≥0 为跟踪良好时的有界注入：
```
若 P_cmd > 0:  τ = τ_cmd · clip((E_t/Δt + P_inj)/P_cmd, 0, 1)
若 P_cmd ≤ 0:  τ = τ_cmd
Ė_t = P_inj − τ^T q̇,   E_t ∈ [0,E_max]
```
若 E_t<E_min：进入安全保持，τ=−D_safe q̇+g(q)（g(q) 作为势能整形，不计为能量注入），置 Ê 证书失效。离散实现须采用保被动性的离散化（否则 1kHz 采样会把能量不等式破坏）。

**新增定义 542（接触模型与抓取扳手空间 ContactModel & GWS）** 对接触 i 的线性化摩擦锥取 k 条棱 f_{i,j}=f_n(n_i+μ_i t_{i,j})，0≤f_n≤f_max，原始扳手 w_{i,j}=[f_{i,j}; p_i×f_{i,j}]∈R^6，GWS(C)=conv{w_{i,j}}。外载荷球半径
```
ρ_ext(U) = sup_{m∈[m^-,m^+], a≤a_max} ‖[m(g+a); r×(g+a)]‖ + δ_w + m^+ v_app/Δt_impact
```
其中最后一项把接近冲击冲量纳入。扳手余量
```
η(C,ρ_ext) = inradius(GWS(C)) / ρ_ext = min_{facet 法向 u_f} h_{GWS}(u_f) / ρ_ext
```
（凸多面体含原点时，以原点为心的最大内切球半径等于各支撑面支撑函数的最小值。）力闭合 ⇔ 0∈int(GWS) ⇔ η>0；要求 η≥1 才覆盖整个外载荷球。

**新增定义 543（鲁棒抓取证书 RobustGraspCertificate）** 不确定集 U_g = {μ_i∈[μ_i^-,μ_i^+], o∈E(ô,Σ), m∈[m^-,m^+], a≤a_max, 冲击≤v_app}。用区间/支撑函数 Lipschitz 界构造**可证内近似** GWS_inner，使 GWS_inner ⊆ GWS(C(μ,o)) 对所有 (μ,o)∈U_g 成立；则
```
η_robust = inradius(GWS_inner) / ρ_ext(U_g)
```
证书 γ=(η_robust, cage_flag, f_max, f_fragile) 有效 ⇔ η_robust≥1（力闭合）∨ cage_flag（笼闭，仅运输）。笼闭谓词 Cage(C,o) 需独立证书（拓扑/漏斗验证），不可用则降为单档力闭合。**禁止用标称 μ 或单点位姿估计求 η**。

**新增定义 544（抓取相与承诺点 GraspPhase & CommitmentPoint）** φ∈{A,C,L,T,P}，转移关系 A→C→L→T→P。**承诺点定义为 C→L**：其前物体仍有支撑，撤回安全；其后物体仅由抓取持有，中止只能是放置或保持。承诺门
```
CommitReady(C→L) ⇔ η_robust≥1 ∧ f_n∈[f_min,f_fragile] ∧ s_t≤1−δ ∧ Recoverable(lift chunk)
```
其中 Recoverable 要求整个提起块的每一步都有定义 545 的后承诺中止。

**新增定义 545（相依赖中止集 PhaseAwareAbortSet）** P_t^φ ⊆ {1..K}，每步 p 按相给出：
- 承诺前（A,C）：`retreat_ok(p)`——存在无碰反向轨迹退回已认证预抓取态，能量 ≤ E_retreat；
- 承诺后（L,T,P）：`place_ok(p) ∨ hold_ok(p)`——前者要求最近认证支撑域 S 与放置轨迹净空/能量可行，后者要求 E_t≥E_hold(T_hold) 且抓取力在 [f_min,f_fragile]。
中止代价 c(p)=w_e E(p)+w_t T(p)+w_r risk(p)，执行 p*=argmin_{p∈P_t^φ} c(p)。**若某块在承诺点前找不到覆盖全块的后承诺中止，则拒绝该承诺**。

**新增定义 546（滑脱分数与重抓取梯 SlipScore & RegraspLadder）** 保守滑脱分数
```
s_t = max_i ‖f_{i,t}^{tan}‖ / (μ_i^- f_{i,t}^{norm})
```
并辅以位姿残差/视觉滑移；s_t≥1−δ 触发滑脱告警（δ≥传感器噪声裕度）。重抓取梯 L=(r_0,r_1,r_2,r_3)：
- r_0 增法向力至 min(1.2f_n, f_fragile)；
- r_1 原候选重闭合/重定心；
- r_2 退回并换下一个抓取候选；
- r_3 放到最近支撑域后重规划。
每级有前置条件与证书；代价严格递增，r_3 为终态；两次滑脱事件间设 H_slip 周期不应期。

**新增定义 547（力矩-接触块证书 TorqueContactCertificate）**
```
Ĉ_t = (ĝ_min, ê_max, η̂_robust, Ê_min, τ̂_peak, ŝ_max)
```
有效 ⇔ v9 全部条件 ∧ η̂_robust≥1（或 cage）∧ Ê_min≥E_min ∧ τ̂_peak≤τ_max ∧ ŝ_max≤1−δ。前向模型 F̂ 现在预测阻抗执行下的间隙/努力/能量/接触力轨迹；能量与接触力界用保守功率积分给出，不依赖高保真接触仿真。

**新增定义 548（柔顺层中立元表 ComplianceNeutralTable）**

| 端口 | 中立元 v^⊥ | 退化后行为 | 备注 |
|---|---|---|---|
| ITP | Z^⊥=刚性跟踪（K_d,D_d→上限或直接旁路） | v9 运动学执行 | **τ=0 不是中立元**（自由关节≠恒等） |
| ET | E^⊥=关闭（随 ITP 旁路） | v9 无能量约束 | 单独关闭 ET 不安全，必须与 ITP 同退 |
| RGC | γ^⊥=v9 布尔 γ̂_grasp | v9 抓取判定 | 仅在 v9 判定通过时接受 |

# IP-357 ImpedanceTorquePort + EnergyTank：5Hz 分块阻抗，1kHz 生成力矩
class EnergyTank:
    def __init__(self, E_max=50.0, E_min=5.0, dt=1e-3, P_inj=0.5, D_safe=2.0):
        self.E, self.E_max, self.E_min = E_max, E_max, E_min
        self.dt, self.P_inj, self.D_safe = dt, P_inj, D_safe
        self.bypass = False

    def project(self, tau_cmd, qdot, gravity):
        if self.E < self.E_min:                     # 安全保持：仍是被动态
            self.bypass = True
            return -self.D_safe * qdot + gravity    # g(q) 作势能整形
        P = float(tau_cmd @ qdot)
        if P <= 0.0:
            tau = tau_cmd
        else:
            scale = min(1.0, (self.E / self.dt + self.P_inj) / max(P, 1e-6))
            tau = tau_cmd * scale
        self.E += self.dt * (self.P_inj - float(tau @ qdot))
        self.E = max(0.0, min(self.E_max, self.E))
        return tau


class ImpedanceTorquePort:
    def __init__(self, tank, K_max=10):
        self.tank, self.K_max = tank, K_max

    def phase_K(self, phase):
        return {"A": 2, "C": 1, "L": self.K_max,
                "T": self.K_max, "P": 2}[phase]

    def torque(self, chunk, k, q, qdot, gravity):
        Kd, Dd, tau_ff, qd, qd_dot = chunk.Z[k]
        tau_cmd = tau_ff + Kd * (qd - q) + Dd * (qd_dot - qdot)
        return self.tank.project(tau_cmd, qdot, gravity)   # 1kHz 线程

    def neutral_rigid(self, qd, qd_dot, q, qdot):           # Z^⊥：复现 v9
        return qd, qd_dot                                   # 直接旁路运动学指令

# IP-359 CommitmentPhaseExecutor：相门 + 相依赖中止
class CommitmentPhaseExecutor:
    def __init__(self, phase_max=None):
        self.phase_max = phase_max or {"A": 2, "C": 1, "L": 10, "T": 10, "P": 2}

    def commit_ready(self, cert, f_n, slip, lift_chunk):
        return (cert.eta_robust >= 1.0 and f_n >= self.f_min
                and f_n <= cert.f_max and slip <= 1.0 - self.delta
                and self._recoverable(lift_chunk))

    def plan_abort(self, chunk, phase, state):
        if phase in ("A", "C"):
            cand = [p for p in chunk.steps if self._retreat_ok(state, p)]
        else:
            cand = [p for p in chunk.steps
                    if self._place_ok(state, p) or self._hold_ok(state, p)]
        return min(cand, key=lambda p: chunk.cost[p], default=None)

    def guard(self, chunk, k, phase, obs):
        if not chunk.cert_valid(obs):
            p = self.plan_abort(chunk, phase, obs)
            return ("abort", p) if p is not None else ("hold", None)
        return ("continue", k + 1)

## 4. 推导

**引理 87（能量罐有界性与接触被动性）** 取存储函数 V=½q̇^T M(q)q̇+U(q)+E_t。在定义 541 的投影下，τ^T q̇ ≤ E_t/Δt+P_inj（当 P_cmd>0 时按比例缩放，P_cmd≤0 时本身耗散），故 V̇ ≤ P_ext+P_inj；又 E_t≥0，故任意有界外部能量注入下 q̇ 与接触力有界，不出现自激振荡。E_t<E_min 时切换为 τ=−D_safe q̇+g(q)，其中阻尼项功率 −q̇^T D_safe q̇≤0、g(q) 仅为势能整形，故仍不注入能量。∎（注：结论是接触稳定/有界，不替代 v9 的间隙证书；离散实现须保被动。）

**引理 88（鲁棒抓取证书的保守正确性）** 设 GWS_inner 由定义 543 构造且满足 GWS_inner⊆GWS(C(μ,o)) 对所有 (μ,o)∈U_g 成立，η_robust=inradius(GWS_inner)/ρ_ext(U_g)≥1。则外载荷球 B_{ρ_ext}⊆GWS_inner⊆GWS(C(μ,o))。对任意满足 ‖w_ext‖≤ρ_ext 的外载荷，−w_ext∈GWS(C(μ,o))，按 GWS 定义存在接触力 f_i 落在真实摩擦锥内且 0≤f_n≤f_max，使 ΣG_i f_i=−w_ext；由准静态平衡即无滑移。冲击项已计入 ρ_ext，故在给定接近速度界下结论保持。∎（注：μ 用下界、位姿用椭球最坏情形，故结论对不确定集一致成立；这是保守证书，非精确概率保证。）

**引理 89（相依赖中止的不可逆安全）** 对相做归纳。A/C：块被接受时每步 retreat_ok 成立，任一违规由定义 545 退回已认证预抓取态，物体仍在支撑上。C→L 仅在 CommitReady 时发生，而 CommitReady 含 Recoverable(lift chunk)，即提起块每步存在 place_ok∨hold_ok。L/T/P：任一违规由 place_ok 到达认证支撑域（物体重新有支撑）或由 hold_ok 以 E_t≥E_hold 保持（不释放）。因此承诺后不存在"无支撑释放"；所有中止动作自身经证书检查，M₀ 不被绕过。∎

**引理 90（柔顺中立元与 v9 逐位等价）** 按表 548 逐端口代入：ITP 取 Z^⊥=刚性（直接旁路或 K_d,D_d 上限）⇒ 执行轨迹等于 v9 的 q_ref；ET 关闭 ⇒ 无投影；RGC 取 v9 布尔 γ̂_grasp ⇒ 接受集合相同；CPE 取 P_t 且 φ 固定承诺前 ⇒ 中止集合/动作相同；SRL 取 s=0、L=∅ ⇒ 无重抓取。组合后数据流、调度顺序与可观测输出与 v9 流水线一致；故 v10 全中立元 = v9。特别地若误用 τ=0 作 ITP 中立元，则关节自由漂浮，不等于 v9，故明确禁止。∎

**引理 91（重抓取梯有限性与无 Zeno）** 梯 r_0→r_3 代价严格递增，每级要么返回有效证书、要么升级；r_3 为终态且在后承诺中止集非空时可行（引理 89）。故单次滑脱至多 4 级；相邻滑脱事件间有 H_slip 周期不应期，事件间隔 ≥H_slip·Δt，有限时间内事件数有限，无抖振。∎

**引理 92（三频预算守恒）** 1kHz 力矩环运行于独立实时线程，只消费 Z^k 与关节状态，不进入 50Hz 决策路径；5Hz 块生成沿用 v9 摊销（≤12ms/10 周期）；50Hz 守卫新增相/中止 O(K) 与滑脱 O(m)；RGC 的凸包内切球离线按候选预计算（O(n·F)），在线仅支持函数 O(F)（F 为 GWS 面数），鲁棒内近似用区间界 O(m·k)。故决策侧相对 v9 增量 ≤0.5ms，p99≤20ms；1kHz 环每周期 ≤50μs。∎
