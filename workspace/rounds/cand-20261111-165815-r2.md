# 第 56 轮（承接第 55 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「多机器人协作」×「闭环控制」）

> 第 55 轮把单机器人的语义分割升级为「语义-接触生存核 + 护盾」。本轮把单体可行性抬升到 **多体共享接触的契约闭环**：**H24** 多机器人共抬/共撑/交接使接触力成为跨体耦合约束，单体生存核既不能取并也不能取交；**H25** 分布式闭环中每个机器人只观测到邻居的过期承诺，局部安全动作的叠加可能全局不安全；**H26** 共享感知让语义误差在机器人间相关，「错误共识」比单机误判更隐蔽、更自信。

## 0. 直觉与动机

**灵感 1（多机器人协作 → 接触耦合图，而非接触集合并）**
直觉：两台机器人抬同一张桌子时，真正共享的不是「接触点集合」，而是「力/力矩的分配」。A 少抬一点，B 就多承一点；A 把脚从湿滑区挪开，B 的摩擦锥可能先饱和。所以接触要写成带权图 `G_C`，边上传递 wrench（力旋量），而不是把各自的 `C^+` 做并集。单体「我可行」不等于合体「我们可行」。

**灵感 2（闭环控制 → 契约是最小/最大不动点，不是一次性校验）**
直觉：多机器人闭环里，我的安全动作依赖「邻居会守住它的承诺」，邻居的承诺又依赖「我会守住我的承诺」。这不是一次性接口校验，而是一个互相假设的固定点。用 assume-guarantee 契约 `(A_i,G_i)`：每台机器人在「假设邻居满足 `A_i`」下保证 `G_i`；整组可部署，当且仅当存在不动点使 `G_i⊆A_j` 且共享物体力平衡成立。契约不是文档，是一个要迭代求解的数学对象。

**灵感 3（闭环控制 → 延迟是承诺的保质期）**
直觉：分布式闭环里最危险的不是「算错」，而是「用过期信息算出当时正确、此刻错误的动作」。邻居上一帧说「我托住了」，这一帧它可能已经松开。护盾必须按最坏延迟 `τ_max` 预测邻居接触力的下界，把屏障条件加上延迟补偿项；否则两台机器人会同时判断「对方会托住」而同时松手。

**灵感 4（多机器人协作 → 语义交叉否决，而非置信度平均）**
直觉：共享语义图的错误在机器人间是相关的（同一反光面、同一光照、同款模型）。把多机置信度做平均会产生「虚假共识」：四台同款相机在同一面玻璃上一起错，平均后置信度反而更高。正确做法是 **交叉否决**——只有当另一台机器人从不同视角/不同模态**独立**确认该接触面时，才提升 `κ`；否则保持悲观，并把相关性 `ρ_corr` 写进证书。

**灵感 5（证书 → 集体语义-接触契约证书）**
直觉：第 55 轮的 `J_s` 是单车证书。多机可部署条件要写成一份「契约文件」：每台机器人的 `(A_i,G_i,δ_i^s,τ_i)`、接触耦合图的全局力平衡证据、全局屏障裕度 `H_margin`、延迟-语义联合鲁棒谱 `ρ_col`。缺任何一项，「我们看起来能协作」都不能当作「我们已经证明能协作」。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（多机器人接触耦合图）**
机器人集合 `R={1..n}`，共享接触图 `G_C=(R,E,Φ)`。边 `(i,j)∈E` 表示 i、j 通过同一承载物体或同一支撑面发生接触耦合；`Φ_ij` 为耦合算子，把 i 的接触力映射为 j 需补偿的 wrench：
`Φ_ij: λ_i ↦ Δw_j`。共享物体平衡为
`Σ_{i∈R} J_i^T λ_i = w_obj`，其中 `J_i` 为 i 的接触雅可比、`w_obj` 为物体重力与惯性 wrench。

**定义 128（分布式生存契约）**
机器人 i 的契约 `C_i=(A_i,G_i,Σ_i^s,τ_i)`：
- `A_i`：对邻居接触力/位置的**假设集**（我允许邻居怎么做）；
- `G_i`：在 `A_i` 成立时我保证的**接触-状态集**；
- `Σ_i^s`：我承诺的核心语义接触集；
- `τ_i`：承诺有效时限。
契约组 `{C_i}` 相容 ⇔ 对所有 `(i,j)∈E`：`G_i⊆A_j ∧ G_j⊆A_i`。

**定义 129（契约条件下的闭环生存核）**
`K_i^C = {x_i | ∃u_i,λ_i: f_i(x_i,u_i,λ_i)=ẋ_i ∧ λ_i∈FC(μ) ∧ supp(λ_i)⊆C^+(Σ_i) ∧ ∀a_{N(i)}∈A_i: x_i^+∈𝒳_safe}`。
全局 `K^C = {x | x_i∈K_i^C ∀i ∧ Σ_i J_i^T λ_i = w_obj}`。
关键：`K^C` 是契约算子 `T` 的最大不动点 `K^C = gfp(T)`，`T` 用邻居的 `G_j` 更新自己的 `A_i`，用收缩核更新 `G_i`。

**定义 130（组合接触控制屏障函数 CCCF）**
对共享接触边 `e=(i,j)` 与共享物体平衡，定义标量屏障
`h_e(x)=min(h_e^col, h_e^force, h_e^delay)`：
- `h_e^col`：碰撞/工作空间间隔；
- `h_e^force`：共享 wrench 平衡裕度 `min_i(λ_i^T n_e-λ_min)`；
- `h_e^delay = min_{0≤s≤τ_max}[λ_i^T n_e(t+s|t)-λ_min]`：最坏延迟下预测的接触保持裕度。
闭环条件：`ḣ_e ≥ -α(h_e)` 对所有边**同时**成立。

**定义 131（延迟-语义联合鲁棒谱）**
`ρ_col(ε_s,τ,p_loss) = inf_{||Σ-Σ̂||_∞≤ε_s, delay≤τ, loss≤p_loss} P(x∈K^C ∧ h_e≥0 ∀e | Σ̂)`。
它把第 55 轮的 `ρ_sem` 扩展到「语义扰动 × 通信延迟 × 丢包」的联合球，并对跨机语义误差相关性 `ρ_corr` 做修正。

**定义 132（集体语义-接触契约证书）**
`J_m = ({C_i}, G_C, H_margin, ρ_col, δ_s, τ_max, evidence)`：
- `H_margin = min_{t,e} h_e(x(t))`；
- `δ_s = max_i ||Σ_i^s-Σ̂_i^s||`，并附跨机相关性 `ρ_corr`；
- `evidence` 含契约违约日志、延迟直方图、交叉否决记录。
可部署条件：契约组达到不动点、`H_margin≥θ_H`、`ρ_col≥ρ_min`、`δ_s<Θ_s`、`τ_max≤τ_budget`。

## 2. 关键算法 伪代码

### IP-127 MCCG（Multi-robot Contact Coupling Graph）

```python
def build_contact_coupling(robots, shared_objects, contact_maps):
    G = nx.Graph()
    for i in robots:
        for j in robots:
            if i == j:
                continue
            shared = contact_maps[i].supports & contact_maps[j].supports
            if shared or shares_payload(i, j, shared_objects):
                phi = coupling_operator(i, j, shared_objects)   # wrench transfer
                G.add_edge(i, j, Phi=phi, shared=shared,
                           J=(jacobian(i), jacobian(j)))
    return G
```

### IP-128 DVC（Distributed Viability Contract）

```python
def contract_fixed_point(robots, G, Sigma, tau_max, iters=64):
    A = {i: ALLOW_ALL for i in robots}
    Gset = {i: ALLOW_ALL for i in robots}
    for _ in range(iters):
        newA, newG = {}, {}
        for i in robots:
            N = list(G.neighbors(i))
            newA[i] = intersect_all([Gset[j] for j in N]) if N else ALLOW_ALL
            newG[i] = closed_loop_kernel(robots[i], newA[i], Sigma[i], tau_max)
        if all(newG[i] <= Gset[i] and newA[i] <= A[i] for i in robots):   # 收缩
            return {i: Contract(newA[i], newG[i], Sigma[i], tau_max) for i in robots}
        A, Gset = newA, newG
    return None      # 契约不相容：需要仲裁者松弛或降级任务
```

### IP-129 CCCF（Compositional Contact Control Barrier）

```python
def compositional_shield(u_nom, x, contracts, G_C, tau_max):
    pred = predict_neighbors(contracts, x, tau_max)     # 最坏延迟下邻居力下界
    cons = [h_e_constraint(x, pred, e) for e in G_C.edges]
    cons += [shared_wrench_balance(x, pred, G_C)]         # Σ J_i^T λ_i = w_obj
    u = qp_solve(H=W, g=-W @ u_nom, constraints=cons + local_constraints(x))
    if u is None or global_barrier_violated(u, pred, G_C):
        # 注意：不能各自独立急停，否则共享物会掉落
        return coordinated_hold(x, G_C, min_risk=True), 'collective_hold'
    return u, 'ok'
```

### IP-130 DCC（Delay-aware Closed-loop Consensus）

```python
def delay_aware_consensus(robots, G, tau_max):
    snap = {i: robots[i].local_state_with_stamp() for i in robots}
    for i in robots:
        for j in G.neighbors(i):
            s_j = snap[j]
            if now() - s_j.t > tau_max:
                # 承诺过期：按最坏情形收紧对 j 的假设，而不是沿用旧值
                robots[i].tighten_assumption(j, worst_case_extrapolate(s_j, tau_max))
            else:
                robots[i].refresh_assumption(j, s_j)
    return collective_deadline_check(robots, G, tau_max)
```

### IP-131 CRS（Collective Robustness Spectrum）

```python
def collective_spectrum(robots, G, Sigma_hat, eps_s, tau, p_loss, sampler):
    worst = 1.0
    for Sigma_adv in sampler.semantic_ball(Sigma_hat, eps_s):
        for delay in sampler.delay_ball(tau):
            for loss in sampler.loss_ball(p_loss):
                C = contract_fixed_point(robots, G, Sigma_adv, delay)
                if C is None:
                    return 0.0
                p = empirical_global_viability(robots, C, Sigma_adv, delay, loss)
                worst = min(worst, p)
    return worst
```

### IP-132 MSCC（Multi-robot Semantic-Contact Certificate）

```python
def collective_certificate(traj, robots, contracts, G_C, budgets, rho_col):
    if not contract_compatible(contracts, G_C):
        return ('reject', 'contract_incompatible')
    if not shared_wrench_balanced(traj, G_C):
        return ('reject', 'shared_wrench_unbalanced')
    H_margin = min(global_barrier(traj, e) for e in G_C.edges)
    delta_s, rho_corr = cross_robot_semantic_error(robots)   # 交叉否决 + 相关度
    tau_max = max_delay(traj)
    if H_margin < budgets.theta_H or delta_s > budgets.Theta_s or tau_max > budgets.tau:
        return ('reject', 'collective_budget_exceeded', H_margin, delta_s, tau_max)
    if rho_col(delta_s, tau_max, loss_rate(traj)) < budgets.rho_min:
        return ('reject', 'collective_robustness_fail')
    return ('ok', CollectiveCert(contracts, G_C, H_margin, rho_col,
                                 delta_s, rho_corr, tau_max))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MCCG | O(n²·|C|) | O(n²+n·|C|) | 共享接触识别完备、Φ 标定 |
| DVC | O(I·n·|X_i|·QP) | O(n·|X_i|) | 不动点收缩、契约相容 |
| CCCF | O(|E|·QP) 每次 | O(n·|A_i|) | 全边屏障同时满足、协同保持 |
| DCC | O(|E|) 每周期 | O(n) | 时间戳一致、最坏外推 sound |
| CRS | O(N_s·N_τ·N_l·|X|) | O(|X|) | 联合扰动球覆盖、相关性修正 |
| MSCC | O(|traj|·|E|+n·|Ω|) | O(n·|Ω|) | 力平衡证据、预算闭合 |

**正确性定理（Multi-robot Contracted Closed-loop Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 每台机器人语义置信已校准；**(A34)** 契约不动点在迭代上限内收敛，且通信延迟 `≤τ_max`、丢包 `≤p_loss`；**(A35)** 共享物体力平衡测量误差有界，耦合算子 `Φ` 在合约域上 Lipschitz；**(A36)** 跨机语义误差相关系数 `ρ_corr` 经实测标定，用于把独立概率界替换为相关界。
则部署后整组单步安全概率：
```
P_safe ≥ 1 - P(τ>τ_max) - P(loss>p_loss) - P(T 未收敛)
          - P(||Σ-Σ̂||_∞>ε_s | ρ_corr) - P(共享平衡测量越界) - P(协同保持回退失败)
```
关键：**多机安全是契约不动点的性质，不是各机安全概率的乘积**；延迟、丢包与相关语义误差必须显式进证书，否则「每台都安全」的局部证明会在耦合处漏掉最关键的那一项。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 契约假设漂移、承诺过期 | 高 | 时间戳契约 + 最坏外推 + 承诺过期即收紧假设 |
| 全局屏障耦合导致死锁或「协同急停丢物」 | 高 | 协同保持回退（最小风险而非独立急停）+ 分层解锁 |
| 跨机语义误差相关、虚假共识 | 高 | 交叉否决 + 相关性标定 + 多模态独立确认 |
| 契约不动点不存在或振荡 | 中 | 仲裁者松弛 + 分层契约 + 任务降级 |
| 通信带宽/丢包导致契约失效 | 高 | 事件触发通信 + 承诺压缩 + 本地保守兜底 |

## 6. 本轮最大风险

**一句话**：多机器人契约闭环把单体生存核升级为共享接触的不动点，但其 soundness **三重依赖契约不动点的存在、延迟承诺不过期、以及跨机语义误差相关性可标定**；一旦三者中任一失效，局部「我已保证」会在全局叠加成「我们都没保证」，而最危险的失效模式是协同保持回退本身把共享负载瞬间转嫁给最弱的一台——因此必须以 **时间戳契约 + 延迟感知屏障 + 交叉否决标定** 三重护栏，宁可在契约层保守降级，绝不把「邻居应该会托住」当作已证明的接触。

```python
        A, Gset = newA, newG
    return None       # 不相容：仲裁者松弛或任务降级
```

```python
def collective_spectrum(robots, G, Sigma_hat, eps_s, tau, p_loss, sampler):
    worst = 1.0
    for Sigma_adv in sampler.semantic_ball(Sigma_hat, eps_s):
        for delay in sampler.delay_ball(tau):
            for loss in sampler.loss_ball(p_loss):
                C = contract_fixed_point(robots, G, Sigma_adv, delay)
                if C is None:
                    return 0.0
                p = empirical_global_viability(robots, C, Sigma_adv, delay, loss)
                worst = min(worst, p)
    return worst
```

```python
def collective_certificate(traj, robots, contracts, G_C, budgets, rho_col):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MCCG | O(n²·|C|) | O(n²+n·|C|) | 共享接触完备、Φ 已标定 |
| DVC | O(I·n·|X_i|·QP) | O(n·|X_i|) | 不动点收缩、契约相容 |
| CCCF | O(|E|·QP) 每次 | O(n·|A_i|) | 全边屏障同时满足、协同保持 |
| DCC | O(|E|) 每周期 | O(n) | 时间戳一致、最坏外推 sound |
| CRS | O(N_s·N_τ·N_l·|X|) | O(|X|) | 联合扰动球覆盖、相关性修正 |
| MSCC | O(|traj|·|E|+n·|Ω|) | O(n·|Ω|) | 力平衡证据、预算闭合 |

**正确性定理（Multi-robot Contracted Closed-loop Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 每台机器人语义置信已校准；**(A34)** 契约不动点在迭代上限内收敛，通信延迟 `≤τ_max`、丢包 `≤p_loss`；**(A35)** 共享物体力平衡测量误差有界、耦合算子 `Φ` 在合约域上 Lipschitz；**(A36)** 跨机语义误差相关系数 `ρ_corr` 经实测标定。
则整组部署后的单步安全概率：
```
P_safe ≥ 1 - P(τ>τ_max) - P(loss>p_loss) - P(T 未收敛)
          - P(||Σ-Σ̂||_∞>ε_s | ρ_corr) - P(共享平衡测量越界) - P(协同保持回退失败)
```
关键：**多机安全是契约不动点的性质，不是各机安全概率的简单乘积**；延迟、丢包与相关语义误差必须显式进入证书。

## 5. 本轮最大风险

**一句话**：多机器人契约闭环把单体生存核升级为共享接触的不动点，但其 soundness **三重依赖契约不动点的存在、延迟承诺不过期、以及跨机语义误差相关性可标定**；一旦三者中任一失效，局部「我已保证」会在全局叠加成「我们都没保证」，而最危险的失效模式是协同保持回退本身把共享负载瞬间转嫁给最弱的一台——故必须以 **时间戳契约 + 延迟感知屏障 + 交叉否决标定** 三重护栏，宁可在契约层保守降级，绝不把「邻居应该会托住」当作已证明的接触。
