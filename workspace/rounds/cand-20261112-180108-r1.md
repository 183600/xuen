# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC：USR×MEL×DMS×SRT-Dual×PCE+++++；灵感循环第 1 轮（新循环）；本轮灵感：「可重构机构」×「个性化交互」）

> 第 61 轮让系统完成了「语义→执行」的表征对齐：USR 统一场景/意图/阻抗/证据，MEL 提供零样本物理先验，DMS 接地多轮对话，SRT-Dual 解耦语义与实时时序。但**四个新局限**暴露：
> 1. **「身体」被当成常量**：USR 编码了场景、意图、阻抗、证据，却把机构拓扑与几何当作固定参数；EEIS/ERTC 的 Jacobian、惯量矩阵、重力项、证书都默认构型不变。于是“换工具/换末端/换臂长/换自由度”会让已学技能与安全证书**整体失效**——系统有「任务语义」，没有「身体语义」。
> 2. **个性化停留在语言层**：DMS 能调整措辞与澄清策略，但**物理交互对所有人一视同仁**——同样的 K_p、同样的速度、同样的力上限。真实用户的技能、手部能力、偏好、信任水平差异巨大；「轻一点」对新手和专家意味着不同的阻抗，而现有系统无法区分。
> 3. **构型切换不是参数微调，而是混合系统事件**：可重构机构在切换中会短暂失去自由度、改变载荷路径、产生未建模的惯性突变；第 61 轮的连续安全证明与「锚点保守扩展」**完全不覆盖离散拓扑跳变**，切换瞬间是证书的真空期。
> 4. **个性化与构型会协同漂移**：用户会适应机器人，机器人也会适配用户；两套模型互相训练、互相验证，可能收敛到「用户很舒服、系统很自信、实际很危险」的**风险稳态化**（risk homeostasis）——而评估者正是被适配的模型本身，存在确认偏误。

## 0. 直觉与动机

**灵感 1（可重构机构 → 把「身体」提升为一等语义变量）**
直觉：第 61 轮的 USR 把「场景、意图、阻抗、证据」放进同一个向量空间，唯独漏了「机器人自己长什么样」。可重构机构（模块化关节、可锁自由度、可变臂长、可换末端、变刚度执行器）意味着**构型 c 本身就是任务语义的一部分**：抓大物体需要长臂+大行程，精细装配需要短臂+高刚度，人机共融需要柔顺末端。关键洞见：构造 **构型流形 CMG** 与**构型编码器 E_morph**，把 c 映射为 z_morph ∈ ℝ^d_us，使「换身体」与「换意图」在同一空间可运算；技能检索、阻抗投影、安全证书都必须以 (z_scene, z_intent, z_user, z_morph) 为条件——**身体从背景常量变成可推理变量**。

**灵感 2（个性化交互 → 个性化不只发生在对话，更发生在物理通道）**
直觉：现有「个性化交互」多指话术、推荐、界面；但对具身系统而言，最有意义的个性化是**阻抗、速度、力上限、自主权分配、构型选择**。两位用户都说「轻一点」，一位是力量弱、手抖、反应慢的新手，另一位是希望精细微调的专家；前者需要更软、更慢、更大阻尼、更多澄清，后者需要更硬、更快、更少打扰。关键洞见：建立 **个性化用户模型 PUM**（技能 s、运动能力 κ、偏好 p、信任 τ、可及性 a），并将个性化实现为**物理安全包络 PSE 内的投影**——个性化只能在硬安全地板之上调整，且对能力更弱的用户必须单调地更保守。

**灵感 3（可重构 × 个性化 → 构型-个性化联合匹配，而非各自优化）**
直觉：如果把「选构型」和「懂用户」分开做，会得到两个局部最优：机构按任务选最激进构型，交互按偏好选最舒适参数，二者相乘可能越过安全边界。关键洞见：**构型与个性化必须联合匹配**——为用户选择「他可安全驾驭、且能完成任务」的构型，而不是「任务理论最优」的构型。示例：手抖用户 + 精细装配，不应选高刚度长臂（放大抖动），而应选短臂 + 高阻尼 + 共享自主；匹配目标显式包含用户效用、重构代价、证书可获取性与公平性约束。

**灵感 4（重构安全 → 身体变化是混合自动机事件，必须有自己的过渡控制器）**
直觉：把 c→c′ 当成「改个参数」是致命的。真实切换要松锁、收臂、托举、换末端、重新锁紧、重新标定；期间可能只剩单载荷路径、重力矩突变、末端工具碰撞。关键洞见：建立 **安全重构过渡控制器 SRTC**：以准静态条件、载荷路径不变式、锁序拓扑序、力矩裕度与速度上限为硬约束；切换前**主动吊销证书**，切换后**强制系统辨识 + 重新认证**，实时流在过渡期降级为保守过渡阻抗——**证书真空期必须显式存在，而不是被悄悄忽略**。

**灵感 5（三灵感合流 → PRISM 三时间尺度闭环 + 锚定个性化 + 八维预算）**
直觉：构型变化慢（0.01–1 Hz）、语义推理中速（10–100 Hz）、实时控制快（1–10 kHz），个性化则更慢（按会话/任务，分钟级）。三者必须分层：**构型流**做 PUM 更新、构型匹配与安全切换；**语义流**（第 61 轮）做场景/意图/技能检索；**实时流**只消费双锚点（语义锚点 + 构型锚点）。同时引入**锚定个性化**：个性化参数带「安全地板锚 + 周期性去适配」，防止人机互相驯化。预算扩展 `B_prism = B_cog5 ⊕ (B_morph, B_user)`：构型预算耗尽⇒冻结当前构型、只做保守参数微调；用户预算耗尽⇒退回群体先验 + 更保守包络。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（构型流形与切换图 CMG）** 可重构机构的配置空间是一个**离散-连续混合流形**
```
C = ⊔_{τ∈T} ({τ} × Θ_τ),      c = (τ, θ)
```
- `T`：有限离散拓扑集合（自由度数目、连杆连接图、末端类型、驱动模式、是否含变刚度关节）；
- `Θ_τ ⊂ ℝ^{n_τ}`：该拓扑下的连续参数（臂长、关节限位、连杆质量、刚度范围、传感器安装位），紧致且带物理约束；
- **切换图** `G_C = (C, E)`，边 `e=(c,c') ∈ E` 表示物理可行切换，附带 `(T_e, r_e, j_e)`（切换时长、风险、代价）；
- **构型距离** `d_C(c,c') = 1[τ≠τ'] + ‖θ-θ'‖/θ_scale`；跨拓扑时取切换图最短路；
- **可达构型集** `Reach(c_0, T_budget) = {c | ∃ path c_0→c, Σ T_e ≤ T_budget, 每步过渡安全}`；
- **可认证性** `Cert(c) = 1` 当且仅当在 τ_cert 内能完成系统辨识并获得 `J_prism`（定义 183）。

**定义 174（构型-语义联合表征 MORPH-USR）** 在第 61 轮 USR 上增加构型通道：
```
U⁺ = (U, E_morph, Π_c, A_t)
E_morph: C × Ξ_emb → ℝ^{d_us},      z_morph = E_morph(c, ξ)
```
- **能力向量** `ψ(c) = (reach, payload, dof, stiffness_range, precision, footprint)`，是构型的物理语义投影；
- **构型锚点** `A_t = (c_t, z_morph_t, z_scene_t, z_intent_t, z_user_t, version_m, version_s, ts, checksum)`；
- **解耦约束**：`z_morph` 应能预测 ψ(c)，且对任务语义不变；`z_task` 对构型不变。以
```
ℒ_dis = ℒ_cap(ψ(c), D_cap(z_morph)) + λ_inv·ℒ_inv(z_task; c) + λ_adv·ℒ_adv(z_morph; task)
```
训练，使「身体表征」与「任务表征」可分离、可组合；
- **构型条件投影** `Π_c: (z_scene, z_intent, z_user, z_morph) → K_prior`，替代第 61 轮仅依赖 scene+intent 的 Π。

**定义 175（个性化用户模型 PUM）** 用户潜在状态
```
z_user = (s_skill, κ_motor, p_pref, τ_trust, a_access) ∈ ℝ^{d_user}
```
- `s_skill ∈ [0,1]`：任务熟练度；`κ_motor`：运动能力（抖动幅度、反应时、最大出力、可达范围）；`p_pref`：偏好（速度/力/自主权/解释详细度）；`τ_trust`：信任水平（欠信任↔过信任）；`a_access`：可及性（视觉/听觉/语言）；
- **信念** `b_user ∈ Δ(Z_user)`，贝叶斯更新 `b_user' ∝ p(o | z_user)·b_user`，观测 o 来自对话、示教、执行（成功率、犹豫时长、接管、越权、力偏差）；
- **用户效用** `U_user(a; z_user) = w(z_user)^⊤ φ(a, state)`，w 由偏好学习得到；
- **隐私**：对外发布/跨会话复用只暴露满足 `ε_dp`-差分隐私的充分统计量，原始交互数据不出端侧。

**定义 176（构型-个性化联合匹配 MPM）** 给定任务与用户信念，
```
c* = argmax_{c ∈ C}  E_{z_user~b_user}[ U_task(c, z_user) + λ_p·U_user(c, z_user)
                                        - λ_r·risk(c) - λ_t·T_reconf(c_0,c) ]
s.t.  c ∈ Reach(c_0, T_budget),   Cert(c)=1,
      S_user(c, z_user) ≠ ∅,     Δ_fair ≤ ε_fair
```
- `U_task` 含任务成功概率与精度；`risk(c)` 含过渡风险与构型固有风险；
- 在混合空间上用**约束上下文 bandit / 贝叶斯优化**求解：离散 τ 用 Thompson 采样，连续 θ 用可信域 BO；
- 约束 `Cert(c)=1` 是硬约束：**选不出可认证构型就退回当前构型**，绝不“先换再想办法认证”。

**定义 177（安全重构过渡 SRTC）** 重构是混合自动机
```
H = (Q, X, E, Inv, Guard, Reset),   Q = {stable(c), trans(e,k), fault}
```
- **过渡不变式** `I_trans`（每一步都必须成立）：
  1. 至少保留一条完整载荷路径（不允许“空中换手”）；
  2. `CoM(q) ∈ Support(c)`（或由外部托举/夹具补偿）；
  3. 力矩裕度 `τ_margin ≥ τ_min`；
  4. 承载状态下不允许解锁任一自由度；
  5. 重构速度 `‖q̇‖ ≤ v_reconf`，动能 `½q̇^T M(q;c) q̇ ≤ E_reconf`；
- **Guard**：`q = q_hold ∧ F_ext ≤ F_hold ∧ certificate_suspended`；
- **Reset**：`c ← c'`，构型哈希更新，`Cert=0`，进入 `recalibrate`；
- **锁序**：按载荷路径的拓扑序生成解锁/锁定序列（先建新载荷路径，再断旧路径），类似“先接后断”（make-before-break）；
- **过渡阻抗**：`K_trans` 采用低刚度 + 高阻尼 + 降额力上限，实时流在过渡期为独立控制模式。

**定义 178（构型等变技能迁移 CIST）** 第 61 轮 ISP 以笛卡尔阻抗轮廓 `K_x(t)` 表达。构型变化改变 `J(q;c)`、`M(q;c)`、`g(q;c)`，同一 K_x 在不同构型下产生不同末端动力学。定义迁移算子
```
T_{c→c'}: σ ↦ σ',    z_σ' = z_σ + g_φ(z_morph(c'), z_morph(c)),
K_x' = Σ_{c→c'} · R_{c→c'} K_x R_{c→c'}^T
```
- 对**运动学相似构型**（缩放/置换/镜像），要求 `T_{c→c'}` 与相似群等变：`T(g·c) = g·T(c)`；
- **退化界**：`Δperf ≤ L_dyn·d_C(c,c') + L_emb·‖z_morph - ẑ_morph‖ + ε_skill`；
- 若 `d_C(c,c') > δ_morph` 或辨识置信度不足，标记 **OOD 构型**，回退到「仿真重训 + 小样本系统辨识」，不做盲目迁移。

**定义 179（个性化安全包络 PSE 与自主权分配）** 
```
S_hard = {x=(K_p,K_d,F_max,v) | F_max ≤ F_std, K_p ≤ K_mech, v ≤ v_std, ...}   # 标准+机构硬限
S_user(z) = {x ∈ S_hard | margin(x) ≥ m(z), authority(x) ≤ α(z)}
α(z) = α_min + (α_max-α_min)·σ(w_a^⊤ z)          # 用户自主权权重
```
- **单调性**：若用户能力序 `z ⪯ z'`（z' 更强），则 `S_user(z) ⊆ S_user(z')`——越弱越保守，不得反向；
- **投影** `Proj_{S_user}(cmd)` 是实时流最后一道闸门；PSE 非空由 `m(z) ≤ m_max` 保证；
- **越权预算**：用户主动接管/越权次数计入 `B_user`，频繁越权 ⇒ 收紧 α(z) 并触发重新澄清。

**定义 180（个性化公平性与冷启动）** 用户簇 `G = {g_1..g_K}`：
```
Δ_fair = max_g success_g - min_g success_g ≤ ε_fair
calibration_gap = max_g |ECE_g| ≤ ε_cal
```
- **冷启动**：`b_user^0 = Σ_g π_g·N(μ_g, Σ_g)`，按簇分层先验；
- **主动偏好 elicitation**：选择问题 q 最大化 `VOI_user(q) = E[U(b') - U(b)] - cost_cog(q)`，受 `B_user` 约束；
- **公平性审计**：每 N 个会话检查簇间成功率、澄清次数、越权率差异，超阈则冻结个性化、回退群体策略。

**定义 181（个性化对话-构型接地 PDG）** 扩展第 61 轮 DMS：
```
A⁺ = A ∪ {propose_reconfigure(c'), explain(level), teach_preference(q), revoke_authority}
S⁺ = (H_diag, b_intent, b_user, c, C_exec, C_pending, U_mel, turn_id)
level = f_explain(z_user)          # 解释详细度/技术度随用户模型自适应
```
- **执行→构型接地**：同一构型下反复滑移/振动/超限 ⇒ 不只是降 K_p，而是提出**换构型**（换软末端、换短臂、换高阻尼模式）；
- **构型→对话接地**：构型切换前后必须生成可理解的状态说明与接管提示（“我将改为短臂柔顺模式，切换约 8 秒，请松手”）；
- **双向可撤销**：用户可拒绝构型提案或撤销自主权，拒绝记录进入 PUM 的偏好更新。

**定义 182（PRISM 三时间尺度闭环）** 
```
构型流  f_m  ≈ 0.01–1 Hz : PUM 更新 → MPM 选型 → SRTC 执行切换 → 系统辨识 → 证书重签
语义流  f_s  ≈ 10–100 Hz : MEL/DMS/USR（第 61 轮）→ 语义锚点
实时流  f_rt ≈ 1–10 kHz  : EEIS/ERTC → 消费 (语义锚点, 构型锚点) → PSE 投影 → 执行
```
- **双锚点一致性**：实时流每周期校验 `config_hash(anchor.c) == config_hash(runtime.c)`；不匹配立即进入 `transition/fault` 保守模式；
- **切换窗口**：非紧急重构只允许发生在「非关键接触窗口」（无外力、任务相位为 approach/release）；紧急重构（结构故障）走 `fault` 分支，先降载再切换；
- **版本序**：`version_m`（构型）与 `version_s`（语义）独立单调；证书同时引用两者。

**定义 183（构型-个性化联合证书 J_prism）** 
```
J_prism = (J_sem_exec, c_runtime, hash(c_planned), transition_cert,
           version_user, PSE_margin, Δ_fair_local, coadapt_drift, ood_score)
Valid(J_prism) ⇔ Valid(J_sem_exec)
              ∧ hash(c_runtime)=hash(c_planned)
              ∧ transition_cert.complete
              ∧ cmd ∈ S_user ⊆ S_hard
              ∧ (b_user 已校准 ∨ 使用保守先验)
              ∧ coadapt_drift ≤ δ_cd ∧ ood_score ≤ δ_ood
```
- **吊销优先**：任何构型变更/锁失败/用户越权/校准过期都先置 `Valid=0`，再决定是否降级运行；
- **可审计**：记录构型版本、用户模型版本、PSE 参数、过渡序列与拒绝记录，支持事后回放。

**定义 184（个性化-构型协同漂移监控 CADM）** 
```
d_t = ‖b_user(t) - b_user(t-k)‖ + ‖z_morph(t) - z_morph(t-k)‖
RH  = corr(user_override_or_comfort, actual_risk)      # 风险稳态化指标
```
- 若 `d_t > δ_cd` 且 `PSE_margin` 同期下降，或 `RH > ρ_rh`，判定为**协同漂移**；
- 触发**去适配（de-adaptation）**：个性化参数回退到保守先验、冻结 RL 对话策略、引入独立安全审计者（不复用被适配的模型）重新认证，必要时锁定构型做一次完整标定。

## 2. 关键算法伪代码

### IP-183 CMG（构型流形与切换图）

```python
class ConfigurationManifoldGraph:
    def __init__(self, topologies, theta_bounds, transition_rules):
        self.T = topologies                 # 离散拓扑集合
        self.Theta = theta_bounds           # 每个 tau 的连续参数盒约束
        self.rules = transition_rules       # (tau, tau') -> 允许的切换算子
        self.graph = self._build_graph()    # 节点=可行 (tau, theta) 区域, 边=切换

    def distance(self, c, c2):
        if c.tau != c2.tau:
            return 1.0 + self._graph_shortest(c, c2) / self.theta_scale
        return np.linalg.norm(c.theta - c2.theta) / self.theta_scale

    def reachable(self, c0, t_budget):
        # Dijkstra on transition graph, edge weight = T_e
        return {c for c, t in self._dijkstra(c0, weight="duration") if t <= t_budget}

    def certifiable(self, c, tau_cert, sysid_model):
        return sysid_model.expected_id_time(c) <= tau_cert

    def transition_plan(self, c, c2):
        # returns lock/unlock sequence respecting make-before-break
        return self.rules[(c.tau, c2.tau)].plan(c.theta, c2.theta)
```

### IP-186 MPM（构型-个性化联合匹配）

```python
class MorphPersonalizationMatcher:
    def __init__(self, cmg, pum, certifier, safety, budget):
        self.cmg, self.pum = cmg, pum
        self.certifier, self.safety = certifier, safety
        self.budget = budget

    def select(self, task, c0, b_user):
        # 1) 硬可行性过滤：可达 + 可认证 + PSE 非空 + 公平约束
        cands = [c for c in self.cmg.reachable(c0, self.budget.T_reconf)
                 if self.cmg.certifiable(c, self.budget.tau_cert, self.certifier)
                 and self.safety.pse_nonempty(c, b_user)]
        if not cands:
            return c0, "fallback_current"        # 绝不先换再认证

        # 2) 混合空间优化：离散 Thompson + 连续可信域 BO
        best, best_val = c0, -float("inf")
        for c in self._thompson_sample(cands, k=16):
            theta = self._trust_region_bo(c, task, b_user) if c.is_continuous else c.theta
            val = self._expected_utility(c.with_theta(theta), task, b_user)
            if val > best_val and self._constraints_ok(c.with_theta(theta), b_user):
                best, best_val = c.with_theta(theta), val
        return best, "ok"

    def _expected_utility(self, c, task, b_user):
        # Monte-Carlo over user belief
        zs = self.pum.sample(b_user, n=32)
        return np.mean([task.success(c, z) + self.lam_p * self.pum.utility(c, z)
                        - self.lam_r * self.safety.risk(c, z)
                        - self.lam_t * self.cmg.reconfig_cost(c) for z in zs])
```

```python
class SafeReconfigurationController:
    def __init__(self, ertc, eeis, certifier, budget):
        self.ertc, self.eeis, self.certifier = ertc, eeis, certifier
        self.budget = budget

    def execute(self, c_from, c_to, q_current, F_ext):
        # 0) 前置：非关键接触窗口 + 已主动吊销证书
        if not self._noncritical_window(q_current, F_ext):
            return False, "defer: critical contact"
        self.certifier.revoke(reason="reconfiguration_started")

        # 1) 进入保持位姿 + 托举/重力补偿
        q_hold = self._hold_pose(q_current, c_from)
        self._goto_quasi_static(q_hold, c_from)

        # 2) 按 make-before-break 锁序逐个执行
        for step in self._transition_plan(c_from, c_to):
            self._assert_invariant(step, q_hold, F_ext)      # I_trans 五项
            self.ertc.set_mode("transition", K=self._K_trans(step), F_max=self._F_derated(step))
            self._apply_lock_unlock(step)
            self._wait_settle(step.settle_time)

        # 3) 新构型就位：强制辨识 + 重签证书
        self.ertc.set_mode("recalibrate")
        cfg_id = self.certifier.system_identify(c_to)
        ok = self.certifier.reissue(cfg_id)
        self.ertc.set_mode("stable")
        return ok, "done" if ok else "fault_conservative"

    def _assert_invariant(self, step, q_hold, F_ext):
        assert self._load_path_count(step) >= 1
        assert self._com_in_support(q_hold, step.c)
        assert self._torque_margin(q_hold, step.c) >= self.budget.tau_min
        assert not (step.unlocks_loaded_dof)
        assert self._kinetic_energy(q_hold, step.c) <= self.budget.E_reconf
```

```python
class PersonalizedSafetyEnvelope:
    def __init__(self, hard_limits, monotone_map):
        self.S_hard = hard_limits
        self.map = monotone_map          # 保证 z 越强 -> 包络越大

                "v": self.S_hard.v * (1 - m),
                "authority": alpha}

        cmd = min(cmd, S)                 # 逐维截断到包络内
        assert self.subset_of_hard(S)     # S_user ⊆ S_hard 永真
```

**正确性定理（PRISM-Safe）**：在 A61–A70 之上补充
**(A71)** SRTC 的每次切换都存在保持位姿与至少一条载荷路径，锁序为 make-before-break，I_trans 可机械验证；**(A72)** 构型条件动力学对 `(c,θ)` 满足 Lipschitz 常数 `L_dyn`，系统辨识在 `τ_cert` 内达到置信度 `1-α`；**(A73)** PSE 构造保证 `S_user(z) ⊆ S_hard` 且 `z ⪯ z' ⇒ S_user(z) ⊆ S_user(z')`；**(A74)** 用户模型在分布内校准 ECE ≤ 0.05，分布外自动回退保守先验；**(A75)** 双锚点用 64 位版本号 + 构型哈希，实时流为无撕裂原子读；**(A76)** 公平约束在用户簇上可满足（否则冻结个性化）；**(A77)** 非紧急重构只在非关键接触窗口执行，紧急重构先降载。

则：
1. **重构安全性**：任意执行的构型切换满足 I_trans，不出现无载荷路径、带载解锁或力矩越界 ⇒ 切换过程无失控自由度/掉载（在 A71、A77 下）。
2. **个性化不侵蚀安全**：任意个性化命令经 PSE 投影后 `cmd ∈ S_user ⊆ S_hard`；弱用户包络单调更保守 ⇒ 个性化只在硬安全地板内改变体验（A73）。
3. **技能迁移有界**：`Δperf ≤ L_dyn·d_C + L_emb·‖Δz_morph‖ + ε_skill`；超过 `δ_morph` 或辨识置信不足则 OOD 回退，不做无保证迁移（A72）。
4. **构型-用户匹配有效性**：MPM 的解若存在，必属于可达、可认证、PSE 非空且公平可行的集合；不存在则返回当前构型，系统保持可运行（定义 176）。
5. **证书完整性**：`Valid(J_prism)` 蕴含实时构型与计划一致、过渡完成、命令在包络内、用户模型已校准或保守回退；任一不满足先吊销后降级（定义 183）。
6. **防协同漂移**：若 `RH > ρ_rh` 或 `d_t > δ_cd` 且安全裕度下降，CADM 触发去适配与独立审计，阻断“越用越危险”的均衡（定义 184）。

### IP-183 CMG（构型流形与切换图）

```python
class ConfigurationManifoldGraph:
    def __init__(self, topologies, theta_bounds, transition_rules, theta_scale=1.0):
        self.T, self.Theta = topologies, theta_bounds
        self.rules, self.theta_scale = transition_rules, theta_scale
        self.graph = self._build_graph()   # 节点: 可行 (tau, theta) 区域; 边: 安全切换

    def distance(self, c, c2):
        if c.tau != c2.tau:
            return 1.0 + self._shortest(c, c2) / self.theta_scale
        return np.linalg.norm(c.theta - c2.theta) / self.theta_scale

    def reachable(self, c0, t_budget):
        return {c for c, t in self._dijkstra(c0, weight="duration") if t <= t_budget}

    def certifiable(self, c, tau_cert, sysid):
        return sysid.expected_id_time(c) <= tau_cert

    def transition_plan(self, c, c2):
        return self.rules[(c.tau, c2.tau)].mb_plan(c.theta, c2.theta)  # make-before-break
```

```python
class MorphPersonalizationMatcher:
    def select(self, task, c0, b_user):
        feas = [c for c in self.cmg.reachable(c0, self.budget.T_reconf)
                if self.cmg.certifiable(c, self.budget.tau_cert, self.sysid)
                and self.safety.pse_nonempty(c, b_user)]
        if not feas:
            return c0, "fallback_current"           # 硬约束优先，绝不先换再认证
        best, best_val = c0, -float("inf")
        for c in self._thompson(feas, k=16):
            theta = self._trust_region_bo(c, task, b_user) if c.continuous else c.theta
            c2 = c.with_theta(theta)
            if self._fair_ok(c2, b_user) and self._pse_ok(c2, b_user):
                val = self._expected_utility(c2, task, b_user)
                if val > best_val:
                    best, best_val = c2, val
        return best, "ok"
```

### IP-187 SRTC（安全重构过渡控制器）

```python
class SafeReconfigurationController:
    def execute(self, c_from, c_to, q, F_ext):
        if not self._noncritical_window(q, F_ext):
            return False, "defer_critical_contact"
        self.certifier.revoke("reconfiguration_started")   # 先吊销，后动作

        q_hold = self._hold_pose(q, c_from)
        self._goto_quasi_static(q_hold, c_from)
        for step in self.cmg.transition_plan(c_from, c_to):
            self._assert_invariants(step, q_hold, F_ext)
            self.ertc.set_mode("transition", K=self._K_trans(step), F_max=self._F_derated(step))
            self._apply_lock_unlock(step)
            self._wait_settle(step.settle_time)

        self.ertc.set_mode("recalibrate")
        cfg_id = self.sysid.identify(c_to)                 # 切换后强制辨识
        ok = self.certifier.reissue(cfg_id)
        self.ertc.set_mode("stable")
        return ok, ("done" if ok else "fault_conservative")
```

### IP-189 PSE（个性化安全包络）

```python
class PersonalizedSafetyEnvelope:
    def envelope(self, c, z_user):
        m = self.margin(z_user)          # 能力越弱 -> 裕度越大
        return {"F_max": self.S_hard.F_max * (1 - m),
                "K_p": self.S_hard.K_p * (1 - 0.5 * m),
                "v": self.S_hard.v * (1 - m),
                "authority": self.alpha(z_user)}

    def project(self, cmd, c, z_user):
        S = self.envelope(c, z_user)
        out = {k: min(cmd[k], S[k]) for k in ("F_max", "K_p", "v")}
        assert self._subset_of_hard(out)     # S_user ⊆ S_hard 恒成立
        return out
```

### IP-192 PRISM（三时间尺度闭环）

```python
class PRISMLoop:
    def morphology_step(self, task, c0, obs, dialogue):
        self.pum.update(obs, dialogue)
        if not self.budget.morph_available():
            return self.dms.propose_fallback("morph_budget_exhausted")
        c_star, why = self.mpm.select(task, c0, self.pum.belief)
        if c_star != c0:
            ok, msg = self.srtc.execute(c0, c_star, self.rt.q, self.rt.F_ext)
            if ok: self.usr.commit_morphology(c_star)
            else:  self.dms.notify_transition_failure(msg)

    def realtime_step(self, delta_f_req, fused, xi_exec, Z_env):
        anchor, _ = self.usr.read_latest_anchor()
        c_rt = self.eeis.runtime_config()
        if anchor is None or anchor.c_hash != hash(c_rt):
            K = self.eeis.compile_conservative(delta_f_req, fused, xi_exec, Z_env)
        else:
            K_prior = self.usr.project(anchor)
            K = self.eeis.compile_with_prior(delta_f_req, fused, xi_exec, Z_env, K_prior)
        K = self.safety.project(K, c_rt, self.pum.belief_mean())   # 最后闸门
        cert = self.ertc.dispatch(K)
        self.usr.push_evidence(self.rt.wait_contact())
        return K, cert

    def cadm_step(self):
        d = self._belief_drift() + self._morph_drift()
        rh = self._risk_homeostasis()
        if d > self.budget.delta_cd and rh > self.budget.rho_rh:
            self.pum.reset_to_prior(); self.dms.freeze_rl()
            self.auditor.independent_recheck(); self.mpm.lock_current()
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CMG | O(\|E\|log\|C\|) | O(\|C\|+\|E\|) | 仅返回可行且切换安全的路径 |
| MORPH-USR | O(d_us) | O(d_us·N_anchor) | 解耦损失收敛 ≤100 迭代；双版本无撕裂 |
| PUM | O(d_user) | O(d_user+\|H_diag\|) | ECE≤0.05；ε_dp 可审计 |
| MPM | O(K\|C_feas\|+n_θT_bo) | O(\|C_feas\|) | 硬约束先行；不可认证即回退当前构型 |
| SRTC | O(L) | O(L) | I_trans 逐步断言；失败即 fault 保守 |
| CIST | O(d_us+n) | O(1) | 退化界成立；OOD 强制回退 |
| PSE | O(1) | O(1) | S_user⊆S_hard；弱用户单调更保守 |
| PRISM | 0.01Hz / 100Hz / 10kHz 三流 | ~10MB 共享内存 | 构型哈希不一致即保守降级 |

**正确性定理（PRISM-Safe）**：在 A61–A70 及 A71–A77（见想法区定义 173–184）下：
1. **重构安全**：每次切换满足 I_trans（保持载荷路径、CoM 支撑、力矩裕度、不带载解锁、动能上限）⇒ 无失控自由度与掉载。
2. **个性化安全**：`cmd ∈ S_user ⊆ S_hard`，且能力越弱包络越小 ⇒ 个性化只在硬安全地板内改变体验，不能跨越标准/机构硬限。
3. **迁移有界**：`Δperf ≤ L_dyn·d_C + L_emb·‖Δz_morph‖ + ε_skill`；`d_C>δ_morph` 或辨识置信不足 ⇒ OOD 回退，不做无保证迁移。
4. **匹配有效**：MPM 返回解必属可达、可认证、PSE 非空、公平可行集合；否则返回当前构型，系统保持可运行。
5. **证书完整**：`Valid(J_prism)` ⇒ 运行时构型与计划一致、过渡完成、命令在包络内、用户模型已校准或保守回退；任一不满足先吊销后降级。
6. **防协同漂移**：`RH>ρ_rh` 或 `d_t>δ_cd` 且安全裕度下降 ⇒ CADM 触发去适配与独立审计，阻断“越用越危险”。

## 5. 本轮最大风险

**一句话**：构型模型与用户模型在同一闭环内互相适配、互相验证，可能把「用户满意、模型自信」误判为「系统安全」，在无外部锚点时收敛到舒适但危险的**风险稳态化**均衡——必须以「硬安全地板 + 周期性去适配 + 独立审计者 + 构型/用户双版本联合证书」构建不可被个性化侵蚀的安全锚。
