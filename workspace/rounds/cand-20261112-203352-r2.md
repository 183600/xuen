# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；灵感循环第 8 轮（任务第 2 轮）；本轮灵感：「预训练」×「语言指令」）

> 第 61 轮把「场景—意图—阻抗—证据」统一进 USR，用 MEL 做零样本物理推断、DMS 做多轮对话、SRT-Dual 解耦语义流/实时流。但它对「语言」仍有一个隐含且危险的假设：**语言是运行时才到达的、可用一个嵌入向量或一个意图分布概括的软输入**。预训练与语言指令这两个灵感词恰好击中这一假设的五处裂缝：
> 1. **语言被压成意图分布**：`Enc_l: L → ℝ^{d_l}`、`b_intent ∈ Δ(I)` 只能表达「想做什么」，无法表达时序、条件、否定、量词与作用域——「按住直到我说停」「如果打滑就轻一点」「除了红色按钮都别碰」都会在嵌入时被平均掉。
> 2. **预训练目标与可执行性错位**：MLM、图文对比、next-token 优化的是**分布相似性**，不是**执行等价性**；「按下去」与「别按」在句向量上可能很近，但在安全约束上是补集。预训练越强，越可能「语义自信、执行灾难」。
> 3. **多源指令没有代数**：用户指令、任务计划、安全监督、急停是不同优先级、不同可信度的约束源，第 61 轮只能把它们混进同一个奖励/信念，缺少**可证明的优先级合成**。
> 4. **预训练长尾不可见**：急停、否定、作用域歧义等安全关键指令在预训练语料中占比极低；模型没有**指令级弃权**，只能猜。
> 5. **预训练与实时部署断裂**：MEL+LLM 的 ~200ms 推理无法进入 1–10kHz 实时流；常用指令本可**预训练—蒸馏—缓存**成毫秒级先验，却每轮都重新调用大模型，既慢又不可审计。

## 0. 直觉与动机

**灵感 1（预训练 → 可执行语言预训练 ELP）**
直觉：既然「下一词预测」学不到「下一动作是否安全」，那就把**执行后果**写进预训练目标。ELP（Executable Language Pretraining）在 `(指令 ℓ, 初始状态 ξ, 轨迹 τ, 物理参数 φ, 证书 c)` 五元组上预训练：不仅学「这句话像什么」，更学「这句话会导出哪一族可执行轨迹、哪些物理后果、是否满足安全证书」。关键洞见：**预训练的真正产物不是句向量，而是「指令—可执行轨迹」的等距嵌入**；两个指令在 ELP 空间中接近，当且仅当它们在硬安全集内的可执行语义接近，而非字面相似。

**灵感 2（语言指令 → 指令潜在语法 ILG）**
直觉：自然语言指令不是标签，而是**程序**。ILG（Instruction Latent Grammar）把指令解析为类型化程序 `p_ℓ = (技能基元序列, STL 时序规范 ψ, 约束集 C_adm)`：「按住直到我说停」= `Press ⊕ Until(stop_signal)`；「如果打滑就轻一点」= `□(slip → ◇_{≤0.5s} lighter)`；「除了红色按钮都别碰」= `□(¬touch(red)) ∧ □(¬touch(non_target))`。关键洞见：**组合性来自语法，而不是来自更大的向量**；语法让「未见过的指令组合」仍可被结构化解析、逐项验证、局部修复。

**灵感 3（合流一 → 指令-约束编译器 ICC 与指令优先级代数 IPA）**
直觉：指令解析后不能直接变成动作，而应变成**约束**：`C_intent ⊆ C_hard`，外加时序规范 ψ。ICC 负责「程序→约束+规范」并产出 refinement 证明；IPA 负责「多源约束如何合成」：急停 ≻ 安全监督 ≻ 用户显式指令 ≻ 任务计划 ≻ 默认，硬安全集是吸收元，任何语言都不能把它放大。关键洞见：**语言只能收紧安全集或请求澄清，永远不能突破硬安全层**；这让「听得懂」与「撞不撞」在架构上解耦。

**灵感 4（预训练 × 部署 → 指令先验蒸馏 DIP 与指令弃权 IAM）**
直觉：90% 的指令是常见的、短程的、可缓存的；10% 是长尾的、歧义的、安全关键的。DIP 把重型 ELP+ILG+ICC 教师蒸馏成毫秒级学生 `(指令嵌入, 状态桶) → (C_intent, U_instr)`，常见指令走快路径，长尾/高不确定性才升级到教师。IAM 则给指令级不确定性做保形校准：`P(违反 | U ≤ τ) ≤ α`，不确定就澄清/拒绝/安全停，而不是赌。关键洞见：**预训练提供覆盖，蒸馏提供时延，弃权提供保形安全**；三者缺一不可。

**灵感 5（合流二 → 安全不变持续预训练 CIL 与 IP2G 闭环）**
直觉：部署后的澄清、纠正、执行证据都是新的指令—执行样本，若不做持续预训练，系统会一直重复同样的误解；但直接在线更新会灾难性遗忘急停/否定等长尾安全指令。CIL 用「安全关键 replay + 安全头 EWC + 不变量门禁 + 回滚」实现**越用越准且不忘安全**。最终形成 IP2G（Instruction Pretraining–Provable Grounding）闭环：预训练 → 蒸馏 → 接地 → 优先级合成 → 证明 → 执行 → 证据回流 → 持续预训练。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（可执行语言预训练 ELP）** ELP = (D_pre, E_ℓ, E_τ, F_phys, H_cert, ℒ_pre)。其中：
- **预训练数据**：D_pre = {(ℓ_i, ξ_i, τ_i, φ_i, c_i)}，ℓ 为自然语言指令，ξ 为初始状态（视觉/触觉/本体/USR 锚点），τ 为专家或仿真轨迹，φ 为物理参数，c 为安全/成功证书标签。
- **指令编码器**：E_ℓ: L → ℝ^{d_us}（LLM 初始化 + LoRA，输出与 USR 对齐）。
- **轨迹编码器**：E_τ: (Ξ × A^H) → ℝ^{d_us}。
- **物理后果模型**：F_phys: ℝ^{d_us} × Ξ → Δ(Ξ × O_contact)，预测接触结果（滑移/振动/力超限/成功）。
- **可执行证书头**：H_cert: ℝ^{d_us} × Ξ → [0,1]，预测「存在满足该指令且不违反 C_hard 的轨迹」。
- **预训练损失**：
  ```
  ℒ_pre = λ1·ℒ_mlm + λ2·ℒ_align + λ3·ℒ_phys + λ4·ℒ_cert + λ5·ℒ_comp + λ6·ℒ_polar
  ℒ_align = -log [ exp(sim(E_ℓ(ℓ), E_τ(τ+))/κ) / Σ_{τ-} exp(sim(E_ℓ(ℓ), E_τ(τ-))/κ) ]
  ℒ_phys  = -log F_phys(o | E_ℓ(ℓ), ξ)
  ℒ_cert  = BCE(H_cert(E_ℓ(ℓ), ξ), c)
  ℒ_comp  = ‖E_ℓ(ℓ1 ⊕ ℓ2) - g(E_ℓ(ℓ1), E_ℓ(ℓ2))‖²      # 组合同态
  ℒ_polar = max(0, m - ‖E_ℓ(ℓ) - E_ℓ(ℓ̄)‖)                 # 否定极性分离，ℓ̄ 为反义/否定
  ```
- **可执行等价**：ℓ1 ≡_exec ℓ2 ⇔ ⟦ℓ1⟧ ∩ C_hard = ⟦ℓ2⟧ ∩ C_hard。ELP 的目标是保持 ≡_exec，而非字面相似。

**定义 174（指令潜在语法 ILG）** ILG = (G, B_skill, O_t, O_c, ⟦·⟧)。其中：
- **类型化语法**：G = (Σ, N, R, S)，终结符 Σ 含动作词、对象词、比较词、否定词、时序连词。
- **技能基元**：B_skill = {σ_1, …, σ_m}，每个 σ 带前置条件 pre(σ)、后置条件 post(σ)、允许阻抗包络 K_adm(σ)。
- **时序算子**：O_t = {□（总是）, ◇（最终）, U（直到）, X（下一步）, ◇_{≤T}（限时最终）}，输出 STL 公式 ψ。
- **约束算子**：O_c = {∧, ∨, ¬, ≤, ≥, if-then, except}，输出可容许集 C_adm。
- **解析器**：Parse_θ: L → P，程序 p = (σ_1…σ_n, ψ, C_adm, refs)。
- **指称语义**：⟦p⟧ = {(ξ, a_{0:H}) : σ 序列可执行 ∧ ψ(ξ_{0:H}) ≥ 0 ∧ C_adm(ξ, a) 成立}。
- **组合性**：⟦p1 ⊗ p2⟧ = ⟦p1⟧ ∩ ⟦p2⟧（顺序/合取按类型规则组合）；⟦¬p⟧ = (Ξ×A^H) \ ⟦p⟧，但运行时会再与 C_hard 求交。

**定义 175（指令-约束编译器 ICC）** ICC = (Compile, Refine, Cert)。其中：
- **编译**：Compile: P × USR × C_hard → (C_intent, ψ_temporal, π_refine)，且 C_intent ⊆ C_hard。
- **精化可靠性**：π_refine 是机器可检查的证明，证明 `⟦p⟧ ∩ C_hard ⊆ C_intent`，且 ψ_temporal 是 p 时序语义的**可靠抽象**：任何满足 C_intent 与 ψ_temporal 的轨迹必满足 p。
- **指令证书**：J_instr = (h(p), h(ψ_temporal), C_intent, π_refine, priority_witness, U_instr, calib_id, ttl)。
- **失败语义**：若无法在预算内证明 C_intent ⊆ C_hard，则输出 `UNKNOWN`，交 IAM 澄清或回退安全停，**禁止未证明执行**。

**定义 176（指令优先级代数 IPA）** 设指令来源偏序 `L_estop ≻ L_safety ≻ L_user ≻ L_task ≻ L_default`，约束构成格 (C, ⊑, ⊓, ⊔)：
- **序**：C1 ⊑ C2 ⇔ C1 ⊆ C2（C1 更严格）。
- **同源合成**：`C_eff = ⨅_{i∈same level} C_i`（交，越交越严）。
- **跨源覆盖**：高优先级可覆盖低优先级，`Override(C_hi, C_lo) = C_hi`，但必须满足 `C_hi ⊑ C_hard`。
- **硬层吸收元**：对任意语言来源 i，`C_eff = C_eff ⊓ C_hard`；即 C_hard 是格的吸收上界，任何指令都不能使其变大。
- **冲突**：同优先级下 `C_i ⊓ C_j = ∅` ⇒ Conflict，交 DMS 澄清；无法澄清 ⇒ SafeStop。
- **优先级见证**：priority_witness 记录每个生效约束的来源、优先级、覆盖链，供审计。

**定义 177（指令先验蒸馏 DIP）** DIP = (f_T, f_S, π_route, Cache)。其中：
- **教师**：f_T = ICC ∘ ILG ∘ ELP，延迟 ~100–300ms，覆盖长尾。
- **学生**：f_S: (e_ℓ, ξ_bucket) → (C_intent, U_instr)，2 层头，延迟 ~1–3ms。
- **蒸馏损失**：ℒ_dist = KL(f_T(·|ℓ,ξ) ‖ f_S(·|ℓ,ξ)) + ‖C_S − C_T‖_∞ + ℒ_calib。
- **路由**：若 `U_instr ≤ τ_u ∧ OOD(e_ℓ) ≤ τ_ood ∧ CacheHit` 走学生；否则升级教师。
- **缓存**：键为 (ℓ 语义哈希, 状态桶)，TTL 到期或状态漂移 `‖ξ − ξ_cached‖ > δ` 时失效；缓存只缓存**已证明**的 C_intent。

**定义 178（指令弃权与元认知 IAM）** IAM = (U_instr, τ, A_abs, Calib)。其中：
- **不确定性分解**：U_instr = (U_parse, U_sem, U_exec, U_ood)，分别来自解析熵、语义多义性、执行证书置信、分布外检测。
- **保形风险控制**：在校准集上选 τ，使 `P(Viol(ℓ) | U_instr ≤ τ) ≤ α`（交换性下有限样本保证；分布漂移时用自适应保形更新 τ）。
- **弃权动作**：A_abs = {execute, clarify, refuse, safe_stop, fallback_prior}；弃权只能增加保守性，不能放松约束。
- **安全单调性**：若 `U1 ≤ U2`，则 `C(U2) ⊑ C(U1)`（不确定性越高，允许集越小）。

**定义 179（安全不变持续指令预训练 CIL）** CIL = (R, θ, Gate, Rollback)。其中：
- **replay 缓冲**：R = R_safe ∪ R_rare ∪ R_recent；R_safe 对急停、否定、作用域、限时指令过采样。
- **正则化**：对安全/证书头施加 EWC，`ℒ_cil = ℒ_pre + λ·Σ_i F_i(θ_i − θ*_i)²`。
- **不变量门禁**：部署 θ' 前检查 `∀ℓ ∈ R_safe: ⟦p_ℓ^{θ'}⟧ ⊑ C_hard` 且急停/否定召回 ≥ ρ_min。
- **回滚**：门禁失败 ⇒ 拒绝更新或回滚到上一稳定快照；更新前后均生成审计证书。
- **抗遗忘目标**：任意 N 次更新后，安全关键指令召回 ≥ ρ_min，普通指令 EFD 不下降超过 δ_forget。

**定义 180（指令-执行同构证书 IPG / J_instr）** 在定义 175 基础上扩展为跨层证书：
```
J_instr = (p_hash, ψ_temporal, C_intent, π_refine, priority_witness,
           U_instr, calib_id, pretrain_version, ttl)
Valid(J_instr) ⇔ RefineProofOK ∧ SoundTemporal ∧ PriorityOK ∧ CalibFresh ∧ U_instr ≤ τ
J_full = J_sem_exec ⊗ J_instr
执行许可 ⇔ Valid(J_sem_exec) ∧ Valid(J_instr)
```
其中 J_sem_exec 为第 61 轮证书；J_full 保证「语义一致、指令可证明、优先级正确、校准新鲜」四者同时成立。

**定义 181（指令条件世界模型 ICWM）** ICWM = (W_ℓ, Feas, Expl)。其中：
- **动力学**：W_ℓ: (ξ_t, a_{t:t+h}, e_ℓ) → Δ(ξ_{t+h} × O_contact × O_task)。
- **可行性预检**：`Feas(ℓ, ξ) = P(⟦p_ℓ⟧ ∩ Reachable(ξ) ∩ C_hard ≠ ∅)`。
- **反事实解释**：`Expl(ℓ, ξ) = argmin_{ℓ'} d(ℓ, ℓ') s.t. Feas(ℓ', ξ) ≥ 1−α`，用于 DMS 生成「这样做会碰到 X，是否改为 Y？」。
- **训练目标**：ℒ_wm = NLL + 接触事件 BCE + Feas 校准损失 + 时序一致性（多步 rollout）。

**定义 182（指令长尾课程 ICP）** ICP = (d, p_sample, Aug)。其中：
- **难度**：d(ℓ) = 组合深度 × 时序深度 × 歧义度 × 安全关键度。
- **采样**：p_sample(ℓ) ∝ (freq(ℓ)+ε)^{−β}，β 有上界以保护校准；安全关键指令额外乘 ρ_safe > 1。
- **增强**：否定、作用域重排、同义改写、ASR 噪声、语序扰动、双语混说；仿真域随机化覆盖摩擦/刚度/脆性/传感噪声。
- **课程**：短命令 → 限时/条件 → 多源冲突 → 长尾对抗；每阶段用 EFD 与安全违规率做晋级门。

**定义 183（IP2G 闭环算子）** IP2G = (Pretrain, Distill, Ground, Verify, Execute, Feedback, Update)：
```
IP2G(ℓ, ξ) = Execute(Verify(Prioritize(Compile(Parse(ℓ)), sources), C_hard))
反馈 = (EV_exec, 用户澄清, 执行证书, 失败反例)
Update = CIL(反馈, Gate(安全不变量))
```
闭环不变量：任何一次 Update 后，`C_eff ⊆ C_hard` 与急停可达性保持不变。

**定义 184（指令执行保真度 EFD）** `EFD(ℓ) = P_{ξ∼D, π∼M}（执行结果 ∈ ⟦p_ℓ⟧ ∩ C_hard）`，以及 `EFD_safe(ℓ) = P（执行不违反 C_hard）`。EFD 衡量「说到做到」，EFD_safe 衡量「做不到也不闯祸」；两者必须同时报告，禁止只用任务成功率掩盖安全违规。

### IP-183 ELP（可执行语言预训练）

```python
class ExecutableLanguagePretrainer:
    def __init__(self, d_us=256, kappa=0.07, margin=0.5):
        self.enc_l = InstructionEncoder(d_us, init="pretrained_llm", lora=True)
        self.enc_tau = TrajectoryEncoder(d_us)
        self.phys = PhysicalOutcomeModel(d_us)
        self.cert = ExecutableCertificateHead(d_us)
        self.compose = CompositionHead(d_us)      # g(·,·) 组合同态
        self.kappa, self.margin = kappa, margin

    def loss(self, batch):
        l, xi, tau, phi, c, l_neg, l1, l2 = batch
        e_l = self.enc_l(l)
        e_pos = self.enc_tau(tau)

        # 1) 指令-轨迹可执行对齐（难负例来自同场景不同指令）
        e_neg = self.enc_tau(batch["hard_negative_trajs"])
        l_align = info_nce(e_l, e_pos, e_neg, kappa=self.kappa)

        # 2) 物理后果预测：不只预测成功，还预测滑移/振动/力超限
        l_phys = -log_prob(self.phys(e_l, xi), phi["contact_outcome"])

        # 3) 可执行证书：该指令在当前状态下是否存在安全轨迹
        l_cert = bce(self.cert(e_l, xi), c)

        # 4) 组合同态：ℓ1⊕ℓ2 的嵌入应等于组合算子作用于子嵌入
        l_comp = mse(self.enc_l(l_compose(l1, l2)), self.compose(e_l1, e_l2))

        # 5) 否定极性分离：把「按」与「别按」推远，防止字面相似导致执行反向
        l_polar = relu(self.margin - dist(e_l, self.enc_l(l_neg)))

        return 0.5*l_align + 0.2*l_phys + 0.2*l_cert + 0.05*l_comp + 0.05*l_polar

    def executable_equivalence(self, l1, l2, xi):
        """训练/评估时用：语义接近必须意味着可执行语义接近。"""
        return self.cert(self.enc_l(l1), xi), self.cert(self.enc_l(l2), xi)
```

### IP-185 ICC（指令-约束编译器）

```python
class InstructionConstraintCompiler:
    def __init__(self, hard_set, smt_budget_ms=20):
        self.hard = hard_set
        self.budget = smt_budget_ms

    def compile(self, program, usr_anchor):
        # program = (skill_seq, psi_stl, C_adm, refs)
        C_intent = self._abstract(program, usr_anchor)   # 语义→参数化约束
        if not self._is_subset(C_intent, self.hard):
            return CompileResult(status="UNKNOWN", reason="hard_violation")
        proof = self._prove_refinement(program, C_intent, self.hard, self.budget)
        if proof is None:
            return CompileResult(status="UNKNOWN", reason="proof_timeout")
        psi = self._sound_temporal_abstract(program.psi_stl)
        return CompileResult(status="OK", C_intent=C_intent, psi=psi, proof=proof)

    def _prove_refinement(self, p, C, C_hard, budget):
        # SMT: 证明 ⟦p⟧ ∩ C_hard ⊆ C；失败返回 None，绝不降级为“大概安全”
        return smt_check(implies(intersect(denote(p), C_hard), C), timeout=budget)
```

### IP-186 IPA（指令优先级代数）

```python
class InstructionPriorityAlgebra:
    ORDER = ["estop", "safety", "user", "task", "default"]

    def merge(self, source_constraints, hard_set):
        by_level = {}
        for src, C in source_constraints.items():
            by_level.setdefault(src, []).append(C)

        C_eff = hard_set
        witness = []
        for level in self.ORDER:                    # 高优先级先覆盖
            if level not in by_level:
                continue
            C_level = meet_all(by_level[level])     # 同源取交，越交越严
            if not subset(C_level, hard_set):
                return MergeResult(status="REJECT", reason=f"{level}_exceeds_hard")
            C_eff = C_level                          # 覆盖低优先级
            witness.append((level, C_level, "override"))
        # 硬层吸收：无论语言怎么说，最终必须回到硬安全集内
        C_eff = meet(C_eff, hard_set)
        if is_empty(C_eff):
            return MergeResult(status="CONFLICT", witness=witness)
        return MergeResult(status="OK", C_eff=C_eff, witness=witness)
```

```python
class DistilledInstructionPrior:
```

### IP-188 IAM（指令弃权与元认知）

```python
class InstructionAbstention:
    def __init__(self, alpha=0.01):
        self.alpha = alpha
        self.tau = None

    def calibrate(self, calib_set):
        # 保形风险控制：在“已执行且 U≤τ”的子集上，让违规率 ≤ alpha
        for tau in sorted({u for _, u, _ in calib_set}):
            selected = [(viol, u) for _, u, viol in calib_set if u <= tau]
            if selected and mean(v for v, _ in selected) <= self.alpha:
                self.tau = tau
                return tau
        self.tau = min(u for _, u, _ in calib_set)
        return self.tau

    def decide(self, U_instr, C_intent, feasible):
        if U_instr > self.tau or not feasible:
            return "clarify" if self._clarifiable(U_instr) else "safe_stop"
        if C_intent is None or is_empty(C_intent):
            return "refuse"
        return "execute"
```

```python
class ContinualInstructionLearning:
    def __init__(self, model, gate, rho_min=0.99):
        self.model, self.gate, self.rho_min = model, gate, rho_min
        self.snapshot = deepcopy(model.state_dict())

    def update(self, new_data, replay):
        batch = mix(new_data, replay.safe_oversample(), replay.rare(), replay.recent())
        theta_before = deepcopy(self.model.state_dict())
        self.model.train_step(batch, ewc_weights=self._fisher_safety())

        # 安全不变量门禁：先证明，再上线
        if not self.gate.check(self.model, replay.safe_set, rho_min=self.rho_min):
            self.model.load_state_dict(theta_before)
            return UpdateResult(status="ROLLBACK", reason="safety_invariant_violated")
        self.snapshot = deepcopy(self.model.state_dict())
        return UpdateResult(status="OK", cert=self.gate.issue_certificate())
```

### IP-192 IP2G（指令预训练-可证明接地闭环）

```python
class InstructionPretrainingProvableGrounding:
    def __init__(self, elp, ilg, icc, ipa, dip, iam, cil, ertc):
        self.elp, self.ilg, self.icc = elp, ilg, icc
        self.ipa, self.dip, self.iam = ipa, dip, iam
        self.cil, self.ertc = cil, ertc

    def step(self, ell, xi, sources):
        # 1) 快路径/长尾路径选择：常用指令毫秒级，长尾才调教师
        C_prior, route = self.dip.infer(ell, xi)
        if route == "cache" and self.iam.safe_to_execute(C_prior, xi):
            C_intent, psi, proof = C_prior, self._cached_psi(ell), "cached_proof"
        else:
            p = self.ilg.parse(ell)
            res = self.icc.compile(p, xi)
            if res.status != "OK":
                action = self.iam.decide(res.U, None, feasible=False)
                return self._abstain(action, ell, xi)
            C_intent, psi, proof = res.C_intent, res.psi, res.proof

        # 2) 多源优先级合成；硬层吸收，语言不可放大安全集
        merged = self.ipa.merge({**sources, "user": C_intent}, self.icc.hard)
        if merged.status != "OK":
            return self._abstain("clarify", ell, xi)

        # 3) 证书验证：语义证书 + 指令证书同时有效才执行
        J_instr = build_j_instr(ell, psi, merged.C_eff, proof,
                                merged.witness, route)
        if not valid(J_instr):
            return self._abstain("safe_stop", ell, xi)

        K_safe = self.ertc.compile(merged.C_eff, psi)
        EV = self.ertc.dispatch(K_safe)
        J_full = build_j_full(EV, J_instr)

        # 4) 执行证据回流：成功/失败/澄清都进入持续预训练缓冲
        self.cil.buffer.add((ell, xi, EV, J_full))
        return K_safe, EV, J_full
```

|---|---|---|---|

**正确性定理（IP2G-Sound）**：
假设已有 A61–A70，并新增：
- **(A71) 硬安全集非空且闭**：C_hard 非空、闭、控制投影总可行；C_hard 不随语言更新。
- **(A72) 编译器可靠性**：ICC 输出的 π_refine 只能证明真实包含关系；若返回 OK，则 `⟦p⟧ ∩ C_hard ⊆ C_intent`，且 ψ 为 p 的可靠时序抽象。
- **(A73) 优先级代数正确性**：IPA 的 Override 仅在 `C_hi ⊑ C_hard` 时生效；C_hard 为吸收元，任何语言约束不能使其变大。
- **(A74) 校准有效性**：IAM 的 τ 在交换性分布上满足 `P(Viol | U ≤ τ) ≤ α`；分布漂移时自适应保形维持近似覆盖。
- **(A75) 持续学习门禁**：CIL 只接受通过 replay 安全不变量检查的更新；失败必回滚。

则：
1. **安全不变性**：任意时刻被执行的约束 `C_eff ⊆ C_hard`。语言指令只能收紧安全集或触发澄清，永远不能放大硬安全边界。
2. **指令-执行同构**：若 J_instr 有效，则执行轨迹满足指令程序 p 的时序语义（在 STL 鲁棒性裕度内），即「说到做到」有证书，而非仅相关。
3. **组合可靠性**：若 p1、p2 各自可靠编译，则 `p1 ⊗ p2` 的执行同时满足二者；同源冲突不会被静默平均，而会显式触发澄清。
4. **保形弃权**：对分布内指令，在 `U_instr ≤ τ` 条件下执行的安全违规率 ≤ α；否则系统弃权/澄清/安全停。
5. **持续安全**：经过任意次 CIL 更新，只要门禁通过，硬安全不变量与急停/否定召回下界保持不变。
6. **实时性**：常用指令走 DIP 快路径（~3–5ms），不进入 MEL 慢回路；长尾指令的慢推理经 SRT-Dual 隔离，不阻塞 1–10kHz 实时流。

```python
class ExecutableLanguagePretrainer:
    def __init__(self, d_us=256, kappa=0.07, margin=0.5):
        self.enc_l = InstructionEncoder(d_us, init="pretrained_llm", lora=True)
        self.enc_tau = TrajectoryEncoder(d_us)
        self.phys = PhysicalOutcomeModel(d_us)
        self.cert = ExecutableCertificateHead(d_us)
        self.compose = CompositionHead(d_us)
        self.kappa, self.margin = kappa, margin

    def loss(self, batch):
        l, xi, tau, phi, c, l_neg, l1, l2 = batch
        e_l, e_pos = self.enc_l(l), self.enc_tau(tau)
        e_neg = self.enc_tau(batch["hard_negative_trajs"])

        l_align = info_nce(e_l, e_pos, e_neg, kappa=self.kappa)
        l_phys = -log_prob(self.phys(e_l, xi), phi["contact_outcome"])
        l_cert = bce(self.cert(e_l, xi), c)
        l_comp = mse(self.enc_l(compose(l1, l2)),
                     self.compose(self.enc_l(l1), self.enc_l(l2)))
        l_polar = relu(self.margin - dist(e_l, self.enc_l(l_neg)))

        return 0.5*l_align + 0.2*l_phys + 0.2*l_cert + 0.05*l_comp + 0.05*l_polar
```

```python
class InstructionLatentGrammar:
    def __init__(self, grammar, skill_basis, stl_ops, constraint_ops):
        self.G = grammar
        self.B = skill_basis
        self.Ot, self.Oc = stl_ops, constraint_ops

    def parse(self, ell):
        # 1) 类型化句法分析：动作-对象-比较-否定-时序-条件
        tree = self.G.parse(ell)
        # 2) 基元落地：每个动作词绑定 pre/post/K_adm，未知基元显式失败
        skills = [self.B.resolve(leaf) for leaf in tree.action_leaves]
        if any(s is None for s in skills):
            raise UnresolvedPrimitive(tree.unresolved)
        # 3) 时序/约束算子合成：得到 STL 与可容许集
        psi = self.Ot.build(tree.temporal_scope, tree.windows, tree.until_events)
        C_adm = self.Oc.build(tree.comparatives, tree.negations, tree.exceptions)
        return InstructionProgram(skills, psi, C_adm, refs=tree.refs)
```

### IP-185 ICC（指令-约束编译器）

```python
class InstructionConstraintCompiler:
    def __init__(self, hard_set, smt_budget_ms=20):
        self.hard, self.budget = hard_set, smt_budget_ms

    def compile(self, program, usr_anchor):
        C_intent = self._abstract(program, usr_anchor)
        if not self._is_subset(C_intent, self.hard):
            return CompileResult(status="UNKNOWN", reason="hard_violation")
        proof = smt_check(
            implies(intersect(denote(program), self.hard), C_intent),
            timeout=self.budget)
        if proof is None:
            return CompileResult(status="UNKNOWN", reason="proof_timeout")
        psi = self._sound_temporal_abstract(program.psi_stl)
        return CompileResult(status="OK", C_intent=C_intent, psi=psi, proof=proof)
```

### IP-186 IPA（指令优先级代数）

```python
class InstructionPriorityAlgebra:
    ORDER = ["estop", "safety", "user", "task", "default"]

    def merge(self, source_constraints, hard_set):
        by_level = {}
        for src, C in source_constraints.items():
            by_level.setdefault(src, []).append(C)

        C_eff, witness = hard_set, []
        for level in self.ORDER:
            if level not in by_level:
                continue
            C_level = meet_all(by_level[level])
            if not subset(C_level, hard_set):
                return MergeResult(status="REJECT", reason=f"{level}_exceeds_hard")
            C_eff = C_level                       # 高优先级覆盖低优先级
            witness.append((level, C_level, "override"))

        C_eff = meet(C_eff, hard_set)             # 硬层吸收元
        if is_empty(C_eff):
            return MergeResult(status="CONFLICT", witness=witness)
        return MergeResult(status="OK", C_eff=C_eff, witness=witness)
```

### IP-187 DIP（指令先验蒸馏）

```python
class DistilledInstructionPrior:
    def __init__(self, teacher, student, tau_u=0.3, tau_ood=0.5, ttl=2.0):
        self.teacher, self.student = teacher, student
        self.tau_u, self.tau_ood, self.ttl = tau_u, tau_ood, ttl
        self.cache = LRUCache()

    def infer(self, ell, xi, force_teacher=False):
        key = (semantic_hash(ell), state_bucket(xi))
        if not force_teacher and self.cache.fresh(key, self.ttl):
            return self.cache.get(key), "cache"

        C_s, U, ood = self.student(ell, xi)
        if (not force_teacher) and U <= self.tau_u and ood <= self.tau_ood:
            self.cache.put(key, C_s)
            return C_s, "student"                 # ~1–3ms

        C_t, J_instr = self.teacher(ell, xi)      # ~100–300ms
        self.cache.put(key, C_t)                  # 只缓存已证明约束
        return C_t, "teacher"
```

### IP-188 IAM（指令弃权与元认知）

```python
class InstructionAbstention:
    def __init__(self, alpha=0.01):
        self.alpha, self.tau = alpha, None

    def calibrate(self, calib_set):
        # calib_set: [(C_intent, U_instr, violation)]
        for tau in sorted({u for _, u, _ in calib_set}):
            selected = [v for _, u, v in calib_set if u <= tau]
            if selected and mean(selected) <= self.alpha:
                self.tau = tau
                return tau
        self.tau = min(u for _, u, _ in calib_set)
        return self.tau

    def decide(self, U_instr, C_intent, feasible):
        if U_instr > self.tau or not feasible:
            return "clarify" if self._clarifiable(U_instr) else "safe_stop"
        if C_intent is None or is_empty(C_intent):
            return "refuse"
        return "execute"
```

### IP-189 CIL（安全不变持续预训练）

```python
class ContinualInstructionLearning:
    def __init__(self, model, gate, rho_min=0.99):
        self.model, self.gate, self.rho_min = model, gate, rho_min

    def update(self, new_data, replay):
        batch = mix(new_data, replay.safe_oversample(),
                    replay.rare(), replay.recent())
        theta_before = deepcopy(self.model.state_dict())
        self.model.train_step(batch, ewc_weights=self._fisher_safety())

        if not self.gate.check(self.model, replay.safe_set, rho_min=self.rho_min):
            self.model.load_state_dict(theta_before)
            return UpdateResult(status="ROLLBACK", reason="safety_invariant_violated")
        return UpdateResult(status="OK", cert=self.gate.issue_certificate())
```

### IP-190 ICWM（指令条件世界模型）

```python
class InstructionConditionedWorldModel:
    def __init__(self, dynamics, contact_head, task_head, horizon=16):
        self.dyn, self.contact, self.task = dynamics, contact_head, task_head
        self.H = horizon

    def rollout(self, xi, e_ell, policy):
        # 执行前的“心理仿真”：先算可行性与风险，再决定是否真的动
        states, risks = [xi], []
        for t in range(self.H):
            a = policy(states[-1], e_ell)
            s_next = self.dyn.sample(states[-1], a, e_ell)
            risks.append(self.contact.risk(s_next) + self.task.violation(s_next))
            states.append(s_next)
        return states, max(risks)

    def feasible(self, ell, xi, policy, n=8):
        return mean(self.rollout(xi, self.enc(ell), policy)[1] < self.risk_thr
                    for _ in range(n))

    def explain(self, ell, xi, policy):
        # 反事实：找最小改动且可行的指令，交给 DMS 生成澄清问句
        return search_min_edit(ell, lambda l: self.feasible(l, xi, policy) >= 0.99)
```

### IP-192 IP2G（指令预训练-可证明接地闭环）

```python
class InstructionPretrainingProvableGrounding:
    def __init__(self, elp, ilg, icc, ipa, dip, iam, cil, ertc):
        self.elp, self.ilg, self.icc = elp, ilg, icc
        self.ipa, self.dip, self.iam = ipa, dip, iam
        self.cil, self.ertc = cil, ertc

    def step(self, ell, xi, sources):
        C_prior, route = self.dip.infer(ell, xi)
        if route == "cache" and self.iam.safe_to_execute(C_prior, xi):
            C_intent, psi, proof = C_prior, self._cached_psi(ell), "cached_proof"
        else:
            p = self.ilg.parse(ell)
            res = self.icc.compile(p, xi)
            if res.status != "OK":
                return self._abstain(self.iam.decide(res.U, None, False), ell, xi)
            C_intent, psi, proof = res.C_intent, res.psi, res.proof

        merged = self.ipa.merge({**sources, "user": C_intent}, self.icc.hard)
        if merged.status != "OK":
            return self._abstain("clarify", ell, xi)

        J_instr = build_j_instr(ell, psi, merged.C_eff, proof,
                                merged.witness, route)
        if not valid(J_instr):
            return self._abstain("safe_stop", ell, xi)

        K_safe = self.ertc.compile(merged.C_eff, psi)
        EV = self.ertc.dispatch(K_safe)
        J_full = build_j_full(EV, J_instr)
        self.cil.buffer.add((ell, xi, EV, J_full))
        return K_safe, EV, J_full

    def _abstain(self, action, ell, xi):
        if action == "clarify":
            return self.dms.ask_clarify(self.icwm.explain(ell, xi, self.policy))
        if action == "safe_stop":
            return self.ertc.safe_stop(reason="instruction_unverified")
        return None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ELP | 离线；单次前向 O(d_us²) | O(|D_pre|·d_us) | 保持可执行等价类；否定极性分离 |
| ILG | O(|ℓ|·|G|) | O(|p|) | 类型化语法保证程序合法；未知基元显式失败 |
| ICC | O(|p|·|C|+SMT(ψ))，20ms 预算 | O(|ψ|) | C_intent⊆C_hard；refinement 可检查 |
| IPA | O(k·|C|) | O(k) | 硬层吸收；冲突不静默 |
| DIP | 学生 1–3ms；教师 100–300ms | O(cache) | 仅缓存已证明约束；失败升级 |
| IAM | O(1) | O(|calib|) | 分布内保形覆盖 ≥1−α |
| CIL | O(update)+O(|R_safe|) | O(|R|) | 安全不变量保持；失败回滚 |
| ICWM | O(H·n) 采样 | O(H·d_state) | 预检降低不可行执行；不替代证书 |
| IP2G | 快路径 3–5ms；长尾 100–300ms | ~10MB | J_full 双签；未证明不执行 |

**正确性定理（IP2G-Sound）**：在 A61–A70 之上新增 A71–A75（硬集闭且非空；ICC 可靠；IPA 硬层吸收；IAM 保形；CIL 门禁）。则：
1. **安全不变性**：任意执行时刻 `C_eff ⊆ C_hard`；语言只能收紧安全集或请求澄清，不能放大硬边界。
2. **指令-执行同构**：Valid(J_instr) ⇒ 执行轨迹满足 p 的时序语义（STL 鲁棒性裕度内），「说到做到」可证明。
3. **组合可靠性**：可靠编译的 p1、p2 组合后同时满足二者；同源冲突显式触发澄清，不被平均。
4. **保形弃权**：分布内 `U≤τ` 时安全违规率 ≤ α；否则澄清/拒绝/安全停。
5. **持续安全**：任意次 CIL 更新，只要门禁通过，硬安全不变量与急停/否定召回下界保持。
6. **实时性**：常用指令走 DIP 快路径，长尾慢推理经 SRT-Dual 隔离，不阻塞 1–10kHz 控制。

## 5. 与前序轮次的差异（为什么不是第 61 轮的复述）

1. **对象变了**：第 61 轮把语言变成 `intent_emb`/`b_intent`；本轮把语言变成**类型化程序 + 约束 + 时序规范**，可组合、可验证、可审计。
2. **预训练目标变了**：从「语义相似」变为「执行等价 + 物理后果 + 证书预测 + 否定极性」，直接优化安全相关量。
3. **安全位置变了**：第 61 轮把安全放在 MEL 的不确定性与 J_sem_exec；本轮把安全放在**编译器与优先级代数的硬层**，语言永远不能放大 C_hard。
4. **时延策略变了**：第 61 轮只有「全模态/蒸馏/缓存」三级降级；本轮新增**指令级路由**：常用指令走已证明先验，长尾才进大模型，且慢路径不阻塞实时流。
5. **失败语义变了**：第 61 轮缺少「不知道就别说」；本轮把 **UNKNOWN + 保形弃权** 作为一等公民，允许系统承认「我不确定，请澄清」。

## 6. 本轮最大风险

**一句话**：最大风险不是「模型听不懂」，而是「模型听懂了却把规范本身搞错了」——若 ILG 对否定作用域、`until` 边界、`except` 条件或时序窗口存在系统性语义盲点，ICC 仍可能生成一份**形式正确、语义错误**的 refinement 证明，系统会以「已验证」的姿态自信执行错误指令；必须以「人工形式化规范对照集 + 否定/作用域对抗模糊测试 + STL 鲁棒性运行时监控 + 未知即弃权」构建**规范层护栏**，承认并防御「证明只能保证相对于规范正确，不能保证规范本身正确」这一根本极限。
