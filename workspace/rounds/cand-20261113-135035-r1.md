# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「触觉感知」×「伦理审查」）

> 第 67 轮 SimRAS 把「在线反应式闭环」升级为「离线仿真预训练 + 在线世界模型滚动 + 视觉问答审计」。它解决的是「未来风险如何预演、如何解释」，但暴露出一个更深的裂缝：**所有证书 J_vista / J_RAS / J_SimRAS 都由同一个控制栈自己签发**。控制器天然奖励更大的认证前缀 k*，于是「审计」很容易退化为「自证」；更危险的是第 66 轮的 ERS 会通过控制输入去「塑造情绪」——这在工程上叫闭环共振，在伦理上叫**操纵**。
>
> 本轮灵感的合流点非常锋利：
> - **触觉感知**是唯一必须「跨越边界、发生接触」才能获得的模态；它天然携带同意/抗拒的信息，且是最私密的生物特征。
> - **伦理审查**本质上是「谁有权决定、边界在哪里」的规范过程；它不应是事后的一次性 IRB 文档，而应是随每个动作块运行的**宪法可行性检查**。
>
> 二者是同构的：**触觉是同意在物理层的实例化，伦理是同意在规范层的实例化。** 本轮把「风险感知闭环」升级为「同意感知闭环」：
>
> **ETHOS（Embodied Tactile-Haptic Oversight System，触觉具身的伦理监督闭环）——先问「我有没有被允许」，再问「我该做多少」。**
>
> 它不把伦理压缩成一个可优化的标量风险项，而是把伦理做成**独立审查者 + 硬同意门 + 价值向量可行性 + 伦理债务账本**的四重约束；并用「权力分离」保证控制器无法给自己签发伦理许可。

## 0. 直觉与动机

**灵感 1（触觉感知 → 边界、接触与同意的物理载体）**
视觉可以远距离观察，触觉不能：**触觉的发生本身就意味着一次边界的穿越**。因此触觉阵列（taxel）、力/力矩、接触面积、剪切、皮肤电（EDA）、温度，天然构成一个**硬件级的同意通道**。更关键的是，人的退缩反射（withdrawal reflex）比语言和表情更快（约 100–200ms），它先于理性表达出现；而「僵住（freeze）」虽然看起来配合，却可能是恐惧或胁迫。直觉结论：**触觉不是又一路风险特征，而是「许可/撤回」这一硬约束的实时观测器。**

**灵感 2（伦理审查 → 运行时宪法，而非离线文档）**
IRB 是慢的、离线的、一次性的；自主系统却每分钟做上千次微决策。伦理若只存在于部署前的审查报告里，它在运行时就是**不可执行的**。因此伦理审查必须变成：随每个动作块运行的、可判定的**宪法可行性检查**（constitution feasibility check），并产出可追溯的证书。但它必须是**独立审查者**：如果审查器和控制器共享参数、共享损失，优化器会学会满足指标而不是满足价值（Goodhart / reward hacking）。直觉结论：**伦理不是控制器的一个正则项，而是控制器外部的一道闸门。**

**灵感 3（合流 → 同意是触觉的伦理，伦理是接触的同意）**
把两条灵感对齐：触觉把「我是否被允许接触你」变成一个可观测状态；伦理把「我在什么条件下才可以行动」变成一组规范约束。两者共享同一个对象——**接触点上的边界与同意**。于是控制目标从「最小化风险」升级为「在宪法可行域内、且尊重实时同意地行动」。这正好补上 SimRAS 缺失的维度：SimRAS 回答「未来会怎样」，ETHOS 先回答「**即使未来很好，我是否有权这么做**」。

**灵感 4（对前几轮的反身批判）**
- **RAS 的致命软化**：风险缩放 `λ_risk` 是乘在控制量上的，它可以让执行「变轻」，却不能保证「停止」。而同意必须是**硬约束**：撤回同意应使认证前缀直接归零，不能被任何风险收益权衡抵消。
- **SimRAS 的自证闭环**：WM + VQA 都是黑箱，且由被审计方提供；「审计哈希」只能证明「审计发生过」，不能证明「审计是独立的」。
- **ERS 的伦理红线**：用控制律去塑造人的情绪，在「安抚/照护（care）」与「操纵/诱导（manipulation）」之间存在一条必须显式标注和审查的界线。
- **伦理无法被仿真预训练**：偏好是非平稳的、依赖真实具体的人与情境；仿真能预训练**能力**，但无法预训练**正当性**。这构成对 SimRAS 「离线标定伦理参数」设想的根本限制。

**灵感 5（关键机制一览）**
1. **THP 触觉感知层**：taxel 张量 + 力/接触面积/剪切/EDA/温度，原始数据不出 MCU，只输出接触状态位与认证特征。
2. **CCS 接触同意状态机**：同意格 `X ≺ U ≺ T ≺ W`（撤回 < 未知 < 容忍 < 欢迎）；撤回态吸收，必须显式再同意才能恢复；用迟滞避免抖动。
3. **EIM 伦理影响矩阵**：每个动作块估计 6 维影响向量 `(自主、隐私、不伤害、有益、公正、可解释)`，并给出保形区间，避免把伦理当点估计。
4. **CPE 宪法策略引擎**：用有界时序逻辑（BLTL）编码不可协商规则，如「有接触 ⇒ 同意 ≥ 容忍」「撤回 ⇒ 下一步前缀为 0」「隐私触觉 ⇒ 禁止外传」「不可逆且高风险 ⇒ 必须明确欢迎」「操纵意图 ⇒ 禁止」。
5. **RER 运行时伦理审查器**：独立进程/独立信任域，参数冻结、无梯度回路、只读宪法、硬件否决权；输出 pass / review / block。
6. **T-Gate 触觉同意门**：把同意做成**硬最小值**而非软因子：`k_consent = 0`（撤回）、`k_consent` 由同意等级与可逆性共同决定。
7. **EDL 伦理债务账本**：记录大量「单次都合规」的微小越界，防止伦理像技术债一样被逐步侵蚀；债务超限触发人工复核或硬停。
8. **CEA 反事实伦理审计**：在 VQAuditor 基础上追问「若当事人完全知情，会否同意？」（无知之幕检验），把「解释」升级为「正当性检验」。
9. **ETHOS-Interlock**：把审查器放到独立安全 MCU / 可信执行环境，传感器与执行器使能走独立通路，控制器无法关闭审查器。
10. **MRA 反身审查**：审查器本身也要被审查（误放/误拦统计 + 人工伦理委员会定期更新宪法版本），避免「伦理剧场」。

# THP + CCS：触觉感知与同意状态机（原始数据留在 MCU）
class TouchConsentGate:
    def __init__(self, tau_f=2.0, tau_A=0.2, tau_freeze=0.5, h=3):
        self.state = 'U'          # X < U < T < W
        self.tau_f, self.tau_A, self.tau_freeze, self.h = tau_f, tau_A, tau_freeze, h
        self.stable = 0

    def update(self, q, dt, reconsent=False):
        if not q['obs']:
            self.state = 'U'                     # 不可观测 → 保守，不假设同意
            return self.state
        if q['recoil']:                          # 退缩 = 立即撤回
            self.state = 'X'
            self.stable = 0
            return self.state
        if self.state == 'X':
            if reconsent:                        # 吸收态，仅显式再同意可离开
                self.state = 'U'
            return self.state
        if q['freeze']:                          # 僵住 ≠ 欢迎
            self.state = 'U'
            self.stable = 0
            return self.state
        if q['contact'] and q['force_ok']:
            self.stable += 1
            if self.stable >= self.h:
                self.state = 'W' if q['relaxed'] else 'T'
        else:
            self.stable = 0
            self.state = 'U'
        return self.state

    def k_consent(self, reversible, high_stakes):
        need = 'W' if (not reversible or high_stakes) else 'T'
        return float('inf') if rank(self.state) >= rank(need) else 0


# EIM + RER：独立伦理审查（冻结参数、只读宪法、无梯度回路）
class RuntimeEthicalReviewer:
    def __init__(self, constitution, eim, alpha_conf=0.05):
        self.kappa, self.eim, self.alpha = constitution, eim, alpha_conf

    def review(self, A, ctx, q, c_state, debt):
        e_hat, lo, hi = self.eim.estimate(A, ctx, q)      # conformal 区间
        # 1) 硬规则（BLTL）
        for phi in self.kappa.hard_rules:
            if not phi.check(A, q, c_state):
                return 'BLOCK', (lo, hi), 'hard_rule_violation'
        # 2) 宪法可行集（用上界，保守）
        if not self.kappa.feasible(hi):
            return 'BLOCK', (lo, hi), 'infeasible_upper'
        # 3) 债务与边界
        if debt + self.kappa.excess(e_hat) > self.kappa.D_stop:
            return 'BLOCK', (lo, hi), 'ethical_debt'
        if not self.kappa.feasible(lo) or debt > self.kappa.D_review:
            return 'REVIEW', (lo, hi), 'boundary_case'
        return 'PASS', (lo, hi), 'ok'


# ETHOS 在线闭环：在 SimRAS 之后加“许可层”
def ETHOS_round(M, obs):
    # 0) 先按 SimRAS 得到安全/风险候选前缀与风险缩放
    base = SimRAS_round(M, obs)                 # (k_sim, lambda_risk, joint_post, face_gate, wm)
    k_sim, lambda_risk, joint_post, face_gate, wm = base

    # 1) THP + CCS：接触状态与同意门（硬约束）
    q = M.thp.read(obs)                          # 只读派生量，原始数据不出 MCU
    c_state = M.ccs.update(q, obs.dt, reconsent=obs.reconsent)
    k_consent = M.ccs.k_consent(reversible=obs.reversible, high_stakes=obs.high_stakes)
    if c_state == 'X':
        k_consent = 0

    # 2) EIM + RER：独立伦理审查
    A = M.vista.ach.propose(M.x_prime, H=M.vista.H)
    verdict, (e_lo, e_hi), reason = M.rer.review(A, obs.ctx, q, c_state, M.edl.balance())
    if verdict == 'BLOCK':
        M.edl.record(verdict, e_hi)
        M.ledger.append(M.cert(k=0, c=c_state, e=(e_lo, e_hi), reason=reason))
        return 0, lambda_risk, joint_post, c_state, 'BLOCK'
    if verdict == 'REVIEW':
        M.request_human_review(reason)           # 异步；在复核前只允许 k=0..k_safe_min
        k_sim = min(k_sim, M.k_safe_min)

    # 3) 伦理前缀：逐块校验，取最小值硬门
    k_eth = 0
    for k in range(1, min(len(A), M.m) + 1):
        e_k = M.eim.upper(A[k-1], obs.ctx, q)
        if not M.kappa.feasible(e_k) or not M.rer.hard_ok(A[k-1], q, c_state):
            break
        k_eth = k

    k = int(min(k_sim, k_eth, k_consent, M.m))

    # 4) 执行 + 债务 + 账本 + 反事实审计
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k]) if k > 0 else M.safe_hold()
    M.edl.update(M.eim.estimate(A[:k], obs.ctx, q)[0])
    M.ledger.append(M.cert(k=k, c=c_state, e=(e_lo, e_hi), reason='pass'))
    if k > 0:
        M.cea.submit_async(A[:k], obs.ctx, c_state)     # 无知之幕审计，异步
    return k, lambda_risk, joint_post, c_state, 'PASS'

## 3. 推导

**引理 13（同意不可洗白 / 撤回单调性）** 在 `X` 为吸收态、且 `k* = min(..., k_consent, ...)` 为硬最小值的前提下，任意控制器（含对抗性控制器）在真实撤回发生后都有 `k* = 0`，与预测风险、奖励或情绪置信度无关。证明：撤回使 `k_consent = 0`，最小值门不可被乘法缩放放大；吸收态阻断「等情绪恢复再继续」的规避路径。∎

**引理 14（伦理债务有界）** 若每步越界 `Δ_s = Σ_j w_j max(0, ê_{s,j} - b_j) ≤ Δ`，则 `D_t ≤ γ_D·D_{t-1} + Δ`，稳态上界 `D_∞ ≤ Δ/(1-γ_D)`。取 `D_review < Δ/(1-γ_D)` 可保证在债务无界累积前触发复核；首次触发时间下界满足 `t ≥ log(1-(1-γ_D)D_review/Δ)/log γ_D`。∎

**引理 15（触觉外传的隐私预算）** 若每次外传为 `(ε_s, δ_s)`-DP，且每回合外传次数 `n_t ≤ n_max`，则单回合总预算为 `(n_max·ε_s, n_max·δ_s)`（基本组合）。因此「原始 taxel 零外传 + 仅派生量 DP 外传」把触觉重构攻击的成功率约束在 `e^{ε_dp}` 因子内。∎

**定理 14（权力分离 ⇒ 无自证）** 在定义 282 的不变式下，任何 `k > 0` 的执行都必然经过一个与控制器参数无关的审查签名；若审查器对控制器诱导分布偏移的认证鲁棒半径为 `ρ_R`，则执行块违反宪法的概率上界为 `ε_R(ρ_R) + Pr(同意估计假阴性)`，且该上界不随控制器对 `θ_R` 的优化而增大。证明思路：`k*` 为独立门的最小值；`θ_R` 冻结且无梯度路径，故控制器只能改变输入分布、不能改变审查函数；`ρ_R` 界定分布偏移下的误放。∎

**定理 15（触觉同意门的可靠性）** 设退缩检测的假阴性率 `η`、不可观测时强制 `c = U ⇒ k=0`。则在真实撤回后单步执行概率 `≤ η`；在长度 `H` 的视界内累计执行概率 `≤ 1-(1-η)^H`。若 `η = 0.02, H = 50`，则 `≤ 63.6%`；故必须以「吸收态 + 每步重检」把单步 `η` 压低，而不能只靠一次性分类。∎

**定理 16（正当性不可仿真 / 规范域差不可约）** 存在两个部署情境 `S_1, S_2`，其物理动力学与状态分布完全相同，但真实偏好分布满足 `TV(P_real^pref(S_1) || P_real^pref(S_2)) ≥ δ_0 > 0`。任何仅由 `D_sim` 标定的伦理策略 `π_sim` 在其中一个情境的期望违规率 `≥ δ_0/2`。由于 `D_sim` 不含区分二者的规范信息，增加 `N_sim` 不能降低该下界。故：**仿真可预训练能力，不能预训练正当性；运行时同意观测不可被离线审计替代。**∎

**定理 17（ETHOS 端到端伦理-安全一致性）** 在 A87-A91、定理 11、定理 14-16 下，执行块同时满足：
1. `P(安全违规) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa`（继承 SimRAS）；
2. `P(伦理违规) ≤ ε_R(ρ_R) + η_consent`，且 `k=0` 时恒无违规；
3. `c_t = X ⇒ k* = 0`，`obs=0 ⇒ k* = 0`（不可观测自动保守）；
4. `不可逆 ∧ 高风险 ⇒ k* > 0 仅当 c_t = W`。∎

## 6. 本轮最大风险

**一句话**：ETHOS 把「同意」寄托于触觉代理信号、把「正当性」寄托于一份由部署方参与制定的宪法——于是最深的失败不是技术误判，而是**伦理剧场（ethics theater）**：一个形式上完全有效、哈希可追溯的证书，为一组实际上未经真正知情同意的行为盖章放行（受胁迫者不会退缩、感觉丧失者不会退缩、假手套可以伪造「欢迎」），而审查器又与部署方共享激励——这是本轮全部理论依赖的核心假设：**触觉信号能忠实编码同意，且宪法本身是独立且正当的。**

**次级风险与缓解**：
1. **同意代理偏差**：触觉 ≠ 知情同意；用周期性显式确认、可撤回授权、以及「默认拒绝」（`U` 不视为允许）来缩小差距。
2. **规范非平稳**：偏好会随关系与时间变化；用短周期再同意与在线校准，而非一次性标定。
3. **审查器 Goodhart**：控制器会寻找审查器的对抗样本；用认证鲁棒半径、随机化审查、以及外部红队持续评估。
4. **可用性代价**：过硬的门会频繁停機；用分级同意（容忍 vs 欢迎）、REVIEW 缓冲、以及最小风险回退动作平衡。
5. **合规不等于正当**：形式证书可能掩盖实质不公；保留人工伦理委员会对宪法与统计的定期复核（MRA），并公开账本供第三方审计。

        self.tau_f, self.tau_A, self.tau_freeze, self.h = tau_f, tau_A, tau_freeze, h

    def update(self, q, dt, reconsent=False):

        return float('inf') if RANK[self.state] >= RANK[need] else 0

        self.kappa, self.eim, self.alpha = constitution, eim, alpha_conf
        freeze_parameters(self)                       # 不参与任何控制器优化

    def review(self, A, ctx, q, c_state, debt):
        e_hat, lo, hi = self.eim.estimate(A, ctx, q)
        for phi in self.kappa.hard_rules:
            if not phi.check(A, q, c_state):
                return 'BLOCK', (lo, hi), 'hard_rule_violation'
        if not self.kappa.feasible(hi):
            return 'BLOCK', (lo, hi), 'infeasible_upper'
        if debt + self.kappa.excess(e_hat) > self.kappa.D_stop:
            return 'BLOCK', (lo, hi), 'ethical_debt'
        if not self.kappa.feasible(lo) or debt > self.kappa.D_review:
            return 'REVIEW', (lo, hi), 'boundary_case'
        return 'PASS', (lo, hi), 'ok'

    def hard_ok(self, a, q, c_state):
        return bool(self.kappa.contact_rule(a, q, c_state))


# IP-249 EDL：伦理债务账本
class EthicalDebtLedger:
    def __init__(self, gamma_D=0.95, D_review=1.0, D_stop=3.0, weights=None):
        self.D, self.gamma = 0.0, gamma_D
        self.D_review, self.D_stop = D_review, D_stop
        self.w = weights or [1.0] * 6

    def excess(self, e):
        return sum(self.w[j] * max(0.0, e[j] - BUDGET[j]) for j in range(6))

    def update(self, e):
        self.D = self.gamma * self.D + self.excess(e)
        return self.D

    def balance(self):
        return self.D


# IP-248 T-Gate + IP-278 最终前缀
def tactile_gate(k_sim, k_eth, k_consent, m, blocked):
    if blocked:
        return 0
    return int(min(k_sim, k_eth, k_consent, m))


# IP-252 ETHOS 在线闭环
def ETHOS_round(M, obs):
    # 0) SimRAS 基线（安全 / 情绪 / WM 候选前缀与风险缩放）
    k_sim, lambda_risk, joint_post, face_gate, wm = SimRAS_round(M, obs)

    # 1) THP + CCS：同意门（硬约束，硬件侧）
    q = M.thp.read(obs)                     # 原始 taxel 留在 MCU
    c_state = M.ccs.update(q, obs.dt, reconsent=obs.reconsent)
    k_consent = M.ccs.k_consent(obs.reversible, obs.high_stakes)
    if c_state == 'X':
        k_consent = 0

    # 2) EIM + RER：独立伦理审查
    A = M.vista.ach.propose(M.x_prime, H=M.vista.H)
    verdict, (e_lo, e_hi), reason = M.rer.review(A, obs.ctx, q, c_state, M.edl.balance())
    if verdict == 'BLOCK':
        M.edl.update(e_hi)
        M.ledger.append(M.cert(k=0, c=c_state, e=(e_lo, e_hi), reason=reason))
        return 0, lambda_risk, joint_post, c_state, 'BLOCK'
    if verdict == 'REVIEW':
        M.request_human_review(reason)
        k_sim = min(k_sim, M.k_safe_min)     # 复核前只允许最小安全回退

    # 3) 伦理前缀（逐块，用上界）
    k_eth = 0
    for k in range(1, min(len(A), M.m) + 1):
        if (not M.kappa.feasible(M.eim.upper(A[k-1], obs.ctx, q))
                or not M.rer.hard_ok(A[k-1], q, c_state)):
            break
        k_eth = k

    # 4) 硬最小值门
    k = tactile_gate(k_sim, k_eth, k_consent, M.m, blocked=False)

    # 5) 执行 / 债务 / 账本 / 异步正当性审计
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k]) if k > 0 else M.safe_hold()
    M.edl.update(M.eim.estimate(A[:k], obs.ctx, q)[0])
    M.ledger.append(M.cert(k=k, c=c_state, e=(e_lo, e_hi), reason='pass'))
    if k > 0:
        M.cea.submit_async(A[:k], obs.ctx, c_state)

    return k, lambda_risk, joint_post, c_state, 'PASS'

## 4. 推导

**引理 13（同意不可洗白 / 撤回单调性）** 在 `X` 为吸收态且 `k*=min(…,k_consent,…)` 为硬最小值下，任意控制器在真实撤回后 `k*=0`，与预测风险、奖励、情绪置信度无关。∎

**引理 14（伦理债务有界）** 若每步越界 `Δ_s ≤ Δ`，则 `D_t ≤ γ_D D_{t-1} + Δ`，稳态界 `D_∞ ≤ Δ/(1-γ_D)`；取 `D_review < Δ/(1-γ_D)` 可在无界累积前触发复核。∎

**引理 15（触觉外传隐私预算）** 每次外传 `(ε_s,δ_s)`-DP，每回合 `n_t ≤ n_max`，则总预算 `(n_max ε_s, n_max δ_s)`（基本组合）。原始 taxel 零外传 + 派生量 DP 将重构成功率约束在 `e^{ε_dp}` 因子内。∎

**定理 14（权力分离 ⇒ 无自证）** 在定义 282 下，任何 `k>0` 都经过与控制器参数无关的独立签名；若审查器对控制器诱导分布偏移的认证鲁棒半径为 `ρ_R`，则执行块违宪概率 `≤ ε_R(ρ_R) + Pr(同意假阴性)`，且不随控制器对 `θ_R` 的优化而增大。∎

**定理 15（触觉同意门可靠性）** 退缩检测假阴性率 `η`、不可观测强制 `k=0`。真实撤回后单步执行概率 `≤ η`，视界 `H` 内累计 `≤ 1-(1-η)^H`。故必须「吸收态 + 每步重检」，不能依赖一次性分类。∎

**定理 16（正当性不可仿真 / 规范域差不可约）** 存在 `S_1,S_2` 物理动力学相同、但 `TV(P_real^pref(S_1)||P_real^pref(S_2)) ≥ δ_0 > 0`。任何仅由 `D_sim` 标定的 `π_sim` 在其中一个情境期望违规 `≥ δ_0/2`；`D_sim` 不含区分二者的规范信息，故 `N_sim↑` 不降下界。因此仿真可预训练能力，不能预训练正当性，运行时同意观测不可替代。∎

**定理 17（ETHOS 端到端伦理-安全一致性）** 在 A87-A91、定理 11、定理 14-16 下：
1. `P(安全违规) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa`；
2. `P(伦理违规) ≤ ε_R(ρ_R) + η_consent`，且 `k=0` 时恒无违规；
3. `c_t=X ⇒ k*=0`，`obs=0 ⇒ k*=0`；
4. `不可逆 ∧ 高风险 ⇒ k*>0 仅当 c_t=W`。∎

## 7. 本轮最大风险

**一句话**：ETHOS 把「同意」寄托于触觉代理信号、把「正当性」寄托于一份由部署方参与制定的宪法，于是最深的失败不是技术误判，而是**伦理剧场（ethics theater）**——一个形式有效、哈希可追溯的证书，为一组实际上未经真正知情同意的行为盖章放行（受胁迫者不退缩、感觉丧失者不退缩、假手套可伪造「欢迎」），而审查器又与部署方共享激励——这是本轮全部理论依赖的核心假设：**触觉信号能忠实编码同意，且宪法本身独立且正当。**
