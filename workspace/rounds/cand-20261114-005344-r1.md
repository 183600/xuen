# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「最优控制」×「视觉问答」）

> R69 教会了闭环「问」：把不确定性拆成 aleatoric / epistemic，用流匹配策略呈现多峰动作，用信息动作（看/问/触）主动消解歧义，并用流似然做标定不可吸收的第二意见。但它有两条从未被审视的前提。
>
> 第一，**MINT 的 VoI 是一个熵代理，而不是决策价值**：`VoI(g)=H(M|o)−E[H(M|o,y)]` 只问「问完之后我对模态有多确定」，不问「这份确定性能把任务代价降多少」。它是一步、开环、无动力学、无代价-to-go 的贪心；在最优控制的语言里，这只是信念空间 Bellman 方程被截断到一步、并用熵势函数替换真值函数的特例。于是两类错误必然发生：**(a) 对任务无关的高熵歧义过度提问**（问了也不改变动作）；**(b) 对真正跨越决策边界的低熵歧义视而不见**（熵几乎不变，但最优动作翻转）。更糟的是，问句动作会扰动状态、消耗未来可观测性，甚至把系统推向一个「知道答案后反而无安全动作可选」的处境——**熵 VoI 对此完全无感**。
>
> 第二，**R69 的「问」没有接地**：问句只是冻结 LLM 从软提示解码出的自然语言，系统把回答当作低噪声标签；但真实回答来自 VQA/VLM 或人，二者都是**有语言先验、会幻觉、会被诱导、对图像区域可能不负责任**的噪声信道。一个流畅、自信、却无视觉依据的错误回答，比沉默危险得多。
>
> 本轮两个灵感正好补上这两块：
> - **最优控制**给出正确的价值定义：动作（含信息动作）的价值是它对**最优代价函数**的改善，而不是它对熵的改善；对偶控制（dual control）说明「控」与「学」在同一动作里耦合；约束最优控制进一步说明**信息可以是负价值的、知情本身可能不安全**——因此必须先创造一个「知道答案也安全」的条件，再去知道。
> - **视觉问答**给出一个**语义化、可接地、可多轮自适应**的观测通道：问题可以指向具体实体、属性、关系；答案能直接消解离散模态；并且「问谁」可以是 VLM，也可以是人。代价是必须把它建模为**带接地的校准噪声传感器**，而非神谕。
>
> 核心命题：**把 R69 的熵 VoI 升级为约束信念空间 MDP 上的精确双控 VoI；把 R69 的无接地问句升级为通过「反事实忠实性 + 校准 + 安全可知」三重门的接地 VQA 问句；问句序列由自适应问句树在预算内调度，回答以异构证据融合进入后验。** 命名 **OPTIC-RAS**（Optimal-control Policy with Task–Information Coupling，兼取 optic 之「视觉」意）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量准吗」，R69 问「我该向谁求证」，R70 问「**该问哪个问题、此刻知道答案是否安全、这份知情值多少代价-to-go**」——提问不是免费的熵泵，而是一个受约束的控制动作。

## 0. 直觉与动机

**灵感 1（最优控制 → VoI 是代价-to-go，不是熵）**
直觉：站在岔口，熵可以告诉我「我有多犹豫」，但不能告诉我「犹豫值多少钱」。如果两条路最终代价相同，熵再高也不该问；如果一条路是悬崖、一条是坦途，哪怕熵只差一点点，问清楚也价值千金。**决策相关的不是「不确定度」，而是「不确定性跨越了哪个代价边界」。** 最优控制的答案很直接：一个信息动作的价值等于「执行它之后的最优期望代价」相对「不执行它」的下降。把真值函数 V*(s,b) 放进 Bellman，问句就被自动定价——包括它未来还能省下几次提问。

**灵感 2（对偶控制 → 控制动作与信息动作本来就是同一个动作）**
直觉：Feldbaum 的对偶控制说，好的控制必须同时「控制」和「探测」。相机转一下既是看路也是获得信息；伸手既是抓取也是触觉测量；减速既是避险也是给「看清路况」争取时间。R69 把任务动作 a 与信息动作 g 拼成 ξ=(a,g) 已经摸到门口，但 MINT 仍把它们分开算：先选 g 再选 a。R70 要在同一个 Bellman 里联合优化 (a,g)：**信息动作会改变状态、改变未来可观测性、改变未来动作集**，这些都要计入它的价值。探一下可能让下一步更可观测（正的外部性），也可能把机械臂推离最佳视角（负的外部性）。

**灵感 3（约束最优控制 → 有些答案「知道得太早」会杀人）**
直觉：无约束决策里，信息永远不亏——大不了知道后仍按原计划做。但真实系统被**约束**绑定：一旦知道桥塌了，安全认证就禁止你继续原路线，而唯一替代路线是危险的；一旦知道对方愤怒，规程要求你立即退避，而退避会撞到后方的人。此时「知情」不是中性的，它会收缩你的可行动作集。更微妙的是**时序**：如果你先减速、拉开距离、进入一个「无论答案是什么都有安全动作」的信念区域，再问，同一个问题的价值就从负变正。**所以「何时问」本身是一个控制问题，答案是：先创造安全的知情条件，再知情。** 这把 R69 的「信息动作要安全」升级为「信息动作的**认知后果**要安全」。

**灵感 4（视觉问答 → 问题必须接地，答案必须是传感器而非神谕）**
直觉：R69 的问句是空中的语言。VQA 把它拉回地面：问题应当指向场景图里的**实体 e、属性/关系 r、问法 form**，例如「这个杯子里有液体吗」「地面反光处是水还是抛光」「嘴角上扬时眼角有皱纹吗」。接地有两个好处：一是问得可回答（well-posed），二是答案可被**反事实检验**——把被问属性改掉再问一次，答案若纹丝不动，说明模型根本没看图，只是在背语言先验。VQA 因此不应被当成标签，而应被当成一个**带盲区、带先验、带相关误差的信道**，进入与 FMA、WM 残差同级的证据融合。

**灵感 5（双通道 → 语义探针与行为似然正交，且可以「问到够用就停」）**
直觉：R69 的 FMA 测「行为像不像在这个观测下该有的样子」，VQA 测「语义属性和我假设的世界是否一致」。一个偏视觉语义，一个偏动作动力学，二者失败模式弱相关——这正是 R69 证据纪律要的「正交源」。但证据不是越多越好：最优停止告诉我们，当「再多问一个问题的期望边际价值 ≤ 成本」或「当前后验已足以认证一个安全动作」时就该停。问句树因此是一个**自适应、可提前停止**的策略，而不是固定问 K 个。

**灵感 6（严格包含 → R69 是「一步、熵势、神谕、无耦合」的边界）**
直觉：把真值函数换成熵势、把问句视界截到 1、把状态扰动设为零、把 VQA 信道设为神谕（κ=1、ECE=0），OPTIC 的 DVA 就逐项退化为 R69 的 MINT。这个姿态很重要：**新层不是并列替代旧层，而是把旧层包含为边界情形**；于是 R68 ⊂ R69 ⊂ R70 的安全单调性可以整条传递，而不是每加一层就多一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（OPTIC-RAS 总览与四不变式）** OPTIC-RAS = (DCO, BVN, DVA, AQT, QCG, GVQA, CFG, S2K, HEC, DCS, VCG, VQAuditor-O, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；BVN 训练、信道校准、技能获取只在慢通道，实时回路对价值网与技能库只读）；
(ii) **先接地后入信**：任何 VQA 答案在进入后验前必须通过反事实忠实性门与校准门（定义 316、319），未过门只降权、不单独定案；
(iii) **安全可知（safe-to-know）**：信息动作的每个可能回答都必须把信念留在可认证的安全信念集 B_safe 内（定义 317）；否则该问题被**推迟**，先执行安全裕度提升动作；
(iv) **R69 严格包含**：当问句视界 H_q=1、状态扰动为零、V 取熵势、VQA 信道为神谕且约束不活跃时，OPTIC 逐指令退化为 FLUID-RAS（定义 326、定理 18）。

**定义 311（约束信念空间 MDP）** 记
𝒫 = (S, M, 𝒜×𝒢, T, O, c, c_info, b_0, Safe, ε, B_tot)。
其中 m∈M 为离散模态（意图/世界属性），s∈S 为物理状态，a∈𝒜 任务动作，g∈𝒢 信息动作；转移 T(s'|s,a,g)，观测 O(y|s',g) 在模态条件下为 O(y|m,g)；信念更新 b' = τ(b,g,y) ∝ b(m)·O(y|m,g)。代价 c(s,a)+c_info(g)。约束：P(∀t, s_t∈Safe) ≥ 1−ε 且 Σ_t c_info(g_t) ≤ B_tot。策略 π(a,g|s,b) 定义在增广状态 (s,b) 上。

**定义 312（双控价值与精确 VoI）** 令 V*(s,b) 为 𝒫 的最优约束代价-to-go，
Q(s,b;a,g) = E[c(s,a)+c_info(g)+V*(s',b') | s,b,a,g]。
定义信息动作 g 的**双控优势**
A_dual(s,b;g) = min_a Q(s,b;a,∅) − min_a Q(s,b;a,g)，
其**精确 VoI** 为 VoI*(g) = max(0, A_dual(s,b;g))（g 可选时取期权值；若 g 被强制，则允许 A_dual<0 从而拒绝执行）。关键：Q 内的 V* 已把**未来还能问什么**定价，因此这是序列价值而非一步价值。R69 的熵 VoI 记为 VoI_H(g)=H(b)−E_y H(b')。

**定义 313（决策相关不确定性与近视差）** 定义决策相关不确定性
U_dec(b) = min_a E_{m~b}[ℓ(m,a)]（任务代价下的 Bayes 风险），以及决策边界 ∂𝒟 = {b : argmin_a E_{m~b}ℓ(m,a) 不唯一}。**近视差** Γ_H(b,g) = |VoI*(g) − κ·VoI_H(g)| 度量熵代理偏离真实价值的程度。要点：`H_mode·g(Δ_min)`（R69 定义 297）只是 U_dec 的一个势函数近似，当任务代价是 0-1 且先验均匀、似然对称时才与 Bayes 风险同序（引理 19）。

**定义 314（自适应问句树 AQT）** 问句策略 π_q 依序产生 q_1,…,q_k，且 q_{j+1} 依赖 y_{1:j}；停止时 τ_stop 由「当前后验存在认证安全动作」或「边际 VoI ≤ 成本」或「预算耗尽」触发（取先到者）。目标：min E[Σ_j c_info(q_j) + α·R_task(b_{τ})]，其中 R_task 为剩余任务风险。问句树跨控制轮携带信念，但每单位时间仍最多 1 次信息动作（继承 R69 交互预算）。

**定义 315（接地 VQA 信道 GVQA）** 问句 q=(e, r, form)：实体 e(q)、属性/关系 r(q)、问法 form(q)（是/否、选择、计数、程度）。接地集 G(q)=Ground(e,r;v)（开放词表检测/指代分割/场景图），问句**适定**当且仅当 |G(q)|>0 且接地置信 > τ_g。信道输出答案 y（可为 VLM，也可为人）。**关键：不使用 VLM 原始 softmax 作为模态似然**；而在联合校准集上估计 `κ_θ(y|m,q,v)`，并由诊断头 D(m|y,q,v) 给出模态后验，避免把语言模型的过度自信直接洗成世界信念。

**定义 316（反事实忠实性门 CFG）** 对被问属性/关系施加干预 do(v^cf)（仿真重渲染或受控编辑），对同一 q 重问，定义
sens(q)=P(y(v^cf)≠y(v) | r(v^cf)≠r(v))，
spec(q)=P(y(v^cf)=y(v) | r(v^cf)=r(v))，
盲测 β(q)=P(y(v_blank)=y(v))（v_blank 为置空/无关视觉输入）。
接地分 κ(q)=sens(q)·spec(q)·(1−β(q))。若 κ<τ_cf ⇒ 对似然做几何降温 `κ_θ ∝ ℓ^{κ}` 或直接拒答；另加**逻辑一致性**：语义相关的问句对（「空/满」「湿/干」）答案必须满足互斥/蕴含关系，违反则降权。单次回答永远只提供似然，不单独改写信念（定义 319）。

**定义 317（安全可知 S2K 与安全信念集）** 定义安全信念集
B_safe = {b : 存在认证策略 π 使定义 311 的机会约束可满足且 V*(s,b)<∞}。
信息动作 g 是**认知安全**的，当且仅当对所有满足 P(y|b,g)>δ 的回答 y，都有 τ(b,g,y) ∈ B_safe。定义约束 VoI：若存在某回答使出界，则 VoI*_safe(g)=−∞（必须推迟）；否则用 VoI* 计算。推迟不是放弃：先执行**裕度提升动作**（减速、拉开距离、扩大视角、降低承诺），使 b 进入「任何答案都可安全响应」的区域，再问。**问的时机因此是控制变量，而不是常量。**

**定义 318（双控动作选择 DVA）** 以 R69 的 MINT 替换为
g* = argmax_{g∈𝒢} [ VoI*_safe(g) − c_info(g) − Δ_perturb(g) + O(g) ]，
s.t. 预算未超、C-RAS-WM 认证通过、κ(q)≥τ_cf；
再联合选任务动作 a* = argmin_a Q(s,b;a,g*)。其中 Δ_perturb(g) 是信息动作对状态/未来可观测性的扰动代价，O(g) 是它带来的未来观测期权价值。当 H_q=1、Δ_perturb=O=0、V=熵势时，DVA 逐项退化为 MINT（定理 18）。

**定义 319（异构证据融合 HEC）** 证据源 ℰ={a_score（FMA 行为似然）, r_res（WM/标定残差）, y（VQA）, y_h（人答）, mem（历史）}。每个源带可靠度、偏置与相关矩阵 Σ_ρ；融合用带**源身份项**的约束 Bayes 更新，避免同一错误被重复计数。有效独立源数 k_eff = 1 / (1ᵀ Σ_ρ^{-1} 1)（或其归一化版本）。规则：k_eff<2 且 VoI 增益未超高置信阈值 ⇒ 信念不更新；单源（哪怕是人）不得单独定案（R69 定义 293-iii 的推广）。

**定义 320（双控安全屏蔽 DCS）** 在信念空间上做机会约束屏蔽：对提议的 (a,g)，要求存在从 b' 出发的认证备份策略；问句的社会/物理成本过 C-RAS-WM；注视/探针/等待不越包络；若屏蔽失败，退回当前最优认证任务动作并按 R68 收紧。退避链 R70→R69→R68 的 λ 单调不降（定义 326）。

**定义 321（信念价值网络 BVN 与慢-快双通道）** 慢通道离线拟合 V_φ(s,b)≈V*(s,b)，特征 φ(b)=[模态权重、协方差、熵、Bayes 风险、模态间距、任务进度、剩余预算、可观测性、时间窗]。慢通道负责训练/校准/红队；快通道只做只读推理。近似误差在验证域上给出证书；越出验证域即禁用问句、退回 R69（与定义 326 的 VCG 联动）。

**定义 322（问句候选生成 QCG）** 对决策相关间距高的模态对 (m_i,m_j)，找出使两模态观测分布差异最大的属性/关系，再经场景图与冻结 LLM 映射为问法模板；过滤适定性；用校准信道估计诊断力。候选集 ≤8，LLM **只提议、不裁决**（与 R69 IP-253 的语言接地姿态一致）。

**定义 323（参与式审计 VQAuditor-O）** 审计对象从 R69 的「交互决策」升级为「问句策略」：问句诱导性、答案接地、顺序证据、过度信任、安全可知时序、VoI 预测与实现之差、以及**没问的问题**（遗漏审计）。结论回灌 AuditBuf，成为下一轮 QCG 先验与慢通道训练信号。

**定义 324（威胁模型 AIC-OPTIC）** ℰ_OPTIC = ℰ_FLUID × ℰ_vqa × ℰ_qpolicy，其中
ℰ_vqa = {盲答/语言先验、幻觉答案、答案-区域错配、反事实不一致、校准漂移}；
ℰ_qpolicy = {诱导性提问、问句投毒、确认偏误式问句选择、安全可知违规、预算耗尽攻击}。
并入 AIC 做对抗训练与红队；VQAuditor-O 负责运行时可归因。

**定义 325（证书 J_OPTIC）** J_OPTIC = (J_FLUID, U_dec, VoI*_pred, VoI_realized, Γ_H, κ_cf, ece_vqa, s2k_flag, k_eff, H_q, question_log_hash, optiс_ver)。Valid ⇔ Valid(J_FLUID) ∧ κ_cf≥τ_cf ∧ ece_vqa≤τ_ece ∧ s2k_flag ∧ k_eff≥2（若信念被改写）∧ VoI 可靠度≥τ_voi ∧ 预算未越界。

**定义 326（VoI 校准门 VCG 与三级退化）** 在滑动窗口内比较预测 VoI 与实际代价改善：ρ_voi = E[VoI_realized]/E[VoI*_pred]。若 ρ_voi<τ_voi 或预测误差 >τ_err，或 BVN 越出验证域，或 slow_fault_suspect（R69 定义 301），则**禁用问句**：λ=λ_floor(U_ale+U_epi)（R69），必要时再退 R68。三级退化为
OPTIC →(VCG/KG 失败) FLUID →(ECE/证据失败) CALM →(标定/故障) 最保守。
R68 是 R69「永不交互」边界，R69 是 R70「永不优化时机、熵即价值、答案即神谕」边界。

```python
                      bayes_risk(b), separability(b),
                      task_progress, time_budget, observability)
    def V(self, s, b):            # 快通道只读推理
        return self.net(self.features(s, b))

# IP-266 DVA：双控 VoI（精确价值 + 安全可知 + 扰动/期权项）
def dual_control_voi(s, b, g, V, eps):
    if not s2k.epistemically_safe(s, b, g):      # 定义 317：有回答会出界
        return -INF, 'defer'
    q_no = min_a expected_cost(s, b, a, None, V)          # 不问的代价-to-go
    q_g  = min_a expected_cost(s, b, a, g,    V)          # 问后的期望代价-to-go
    return (q_no - q_g) - c_info(g) - perturb(g) + option(g), 'ok'

# IP-267 AQT：自适应问句树（依赖上一答，可提前停止）
def ask_policy(s, b, cands, V, budget):
    for depth in range(H_q):
        scored = [(q, *dual_control_voi(s, b, q, V, eps))
                  for q in cands if cfg.ok(q) and budget.allow(q)]
        q, val, st = max(scored, key=lambda z: z[1])
        if st == 'defer':  return defer_and_raise_margin(b)
        if val <= 0:       return None                    # 边际 VoI ≤ 成本 → 停
        y = vqa.answer(q)                                 # VLM/人，异步或蒸馏头
        b = hec.update(b, y, q, k_eff)                    # 需 k_eff≥2 才改写
        if safe_action_certified(s, b): return None       # 够用就停
        cands = qcg.condition_on_answer(cands, y)         # 自适应下一步
    return None

# IP-269/270 GVQA + CFG：先接地、再反事实、后降温/拒答
def grounded_answer(q, v, b):
    if not gvqa.well_posed(q, v):          return None
    y  = gvqa.channel(q, v)                              # 校准后的信道
    kappa = cfg.score(q, v)                              # sens·spec·(1−β)
    if kappa < TAU_CF:  return gvqa.temper(y, kappa)     # 不单独定案
    if not cfg.logical_consistent(q, y, b): return None
    return y

# IP-275 OPTIC-RAS 主闭环（继承 R68/R69，仅在「问什么/何时问」处替换）
def OPTIC_RAS_round(M, obs, task):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # 1) R69 不确定性分解（不变）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    b = belief(modes, U_ale, U_epi)
    # 2) R69 第二意见（不变）：缓变故障优先冻结问句
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 3) 双控价值门：只有「值得且安全可知」才问（替换 MINT）
    g = None
    if U_epi > TAU_EPI and not slow and M.vcg.reliable() and M.bvn.in_domain(b):
        cands = M.qcg.generate(modes, M.scene_graph(o))
        g = M.vqa_planner.ask_policy(o.s, b, cands, M.bvn.V, M.budget)
    # 4) 接地答案 + 异构证据（单源不立）
    if g is not None:
        y = M.vqa.grounded_answer(g, o.v, b)
        b_after, k_eff = M.hec.update(b, y, q=g, extras=[a_hat, M.last_r_res])
        resolved = (k_eff >= 2) and (M.vcg.consistent(g, y))
    else:
        b_after, resolved = b, False
    # 5) 联合动作 + 认证前缀（DCS）
    a = M.dva.select_task_action(o.s, b_after, M.bvn.V)
    lam = M.efs.risk_scale(...)
    lam = max(lam, lam_floor(U_ale if resolved else U_ale + U_epi))
    k = M.dcs.certified_prefix(a, b_after, M.vista.H)
    if slow or not M.vcg.ok():
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(a, U_cal))   # 回 R68
    # 6) 审计与证书
    M.vqa_o.submit_async(g, y, b, b_after, a_hat, k_eff)
    return k, lam, a, (U_ale, U_epi, resolved)
```

## 3. 推导

**引理 19（熵 VoI 与决策 VoI 的不可等价性）** 存在 𝒫 与信念 b、信息动作 g，使 VoI_H(g)>0 而 VoI*(g)=0：令两模态 m_1,m_2 在任务代价下对应**同一最优动作与同一代价**，仅名称不同；再令一状态使熵几乎不变但后验质量恰好跨过 ∂𝒟，使 VoI_H≈0 而 VoI*(g)≥δ。系：任何只依赖 H(b) 的排序都不可能等于决策价值排序。当任务代价取**对数损失**且无动力学时，VoI*(g)=I(M;Y|g)，此时才与熵 VoI 一致——即 R69 是「纯估计任务」下的最优特例（对应定理 18 的退化条件）。

**引理 20（约束下信息可为负价值，且「时机」是控制变量）** 无约束 POMDP 中信息价值非负（可忽略信息）。但在定义 311 的机会约束与「认证后必须按知情信念行动」的义务下，存在 b,g 使某些回答 y 迫使动作集收缩、代价上升，从而 A_dual<0；若某 y 使 τ(b,g,y)∉B_safe，则 VoI*_safe=−∞。因此正确的提问规则不是「问最 informative 的」，而是「先执行裕度提升动作，使 b 进入 B_safe 的 S2K 内核，再问」。系：S2K 门把「知情」从被动接收改造成主动创造的可行条件。

**引理 21（接地/校准误差对后验与 VoI 的传播上界）** 设 VQA 信道的接地分 κ、校准误差 ECE≤τ，且未接地回答按定义 316 降温。则相对神谕后验的 TV 误差满足
‖b'−b'_{oracle}‖_TV ≤ (1−κ) + ECE + L_τ·δ_τ，
从而 VoI 预测误差 |VoI*_true − VoI*_model| ≤ L_V·[(1−κ)+ECE+δ_V]。若该上界 >τ_err，定义 326 的 VCG 必须禁用问句。系：**确认偏误有上界**——问句选择最多按模型误差的比例利用语言先验，不能无限放大；但仍需 VCG 实测，因为上界依赖 L_V 的先验。

**引理 22（自适应问句树不劣于固定问句组）** 若各回答在给定模态下条件独立，则模态信息量对问句集合是次模的；因此自适应贪心（定义 314，边际 VoI ≤ 成本即停）达到固定问句组的最优信心所需问题数的期望 ≤ 固定组，且总代价不高于任何预承诺的非自适应策略。要点：**「问到够用就停」不是一个工程启发，而是最优停止的直接结论**；固定问 K 个在简单场景浪费、在困难场景又不够。

**定理 18（OPTIC 严格包含并支配 R69）** 在 A99–A104 下：
(i) **包含**：取 H_q=1、Δ_perturb=O=0、V=熵势、VQA 为神谕（κ=1,ECE=0）、约束不活跃，则 DVA 逐项等于 MINT，主闭环其余部分不变 ⇒ R69 是 OPTIC 的边界情形。
(ii) **支配**：若 V_φ=V* 精确且候选集/预算相同，OPTIC 的期望约束代价 ≤ R69（因它直接在真实代价-to-go 上优化，且「不问」始终在动作集中）；当 BVN 误差为 δ_V 时，最坏差距 ≤ 2δ_V·H_q + 信道误差项。
(iii) **传递**：R68 ⊂ R69 ⊂ R70 的安全单调性沿退化链成立。

**定理 19（认知安全与无突变）** 若 B_safe 在备份策略下是控制不变集，S2K 门保证所有可能回答的更新后信念仍属 B_safe，DCS 对 (a,g) 认证前缀，则执行动作的物理与认知风险均 ≤ 各自阈值；任一环节失败（CFG/VCG/超时/投毒/slow_fault）时 λ 单调不降地退化为 R69/R68，提交-换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。补充：问句选择是离散的，但 DCS 的屏蔽与 λ 的单调收紧保证离散跳变不越过安全包络。

## 6. 本轮最大风险

**一句话**：OPTIC-RAS 把提问从「被动熵泵」升级为「最优控制器」，但它的最优性完全建立在**价值网与 VQA 信道模型是对的**这一前提上——若 VQA 有系统性语言先验、价值网又在验证域外高估了某类问句的收益，那么**最优控制反而会主动搜出最能迎合偏置的那一个问题**，把「随机的感知错误」升级为「被优化过的确认偏误」；系统会以更低的熵、更漂亮的 VoI 曲线、更合法的证书，更确信地相信一个错误世界。**问得越优，偏置越致命。**

**次级风险与缓解**：
1. **价值网失配**（BVN 越域或 VoI 预测失真）→ VCG 滑动窗口比较预测/实现 VoI，失真即禁用问句退 R69；
2. **VQA 盲答/幻觉**（语言先验、答案-区域错配）→ CFG 的 sens/spec/β + 逻辑一致性 + 几何降温，未接地不单独定案；
3. **安全可知违规**（知道后无安全动作）→ S2K 门 + B_safe 不变集 + 先提升裕度再问；
4. **问句诱导/投毒**（确认偏误、社交工程）→ VQAuditor-O 审计问法与选择策略 + QCG 只提议不裁决 + 人类研究；
5. **实时预算**（价值网 + 问句树）→ 慢-快双通道 + 只读价值网 + 异步 VQA 回包，控制节拍内只做一步 VoI。

**定义 312–313（双控 VoI 与决策相关性）** `VoI*` 由 `Q` 的差定义，`Q` 内已含未来提问的期权价值；`U_dec=min_a E_b ℓ(m,a)`；`Γ_H=|VoI*−κVoI_H|`。熵 VoI 只在「纯估计 + 对数损失 + 无动力学」时最优。

**定义 314（AQT）** 答案条件问句树，`q_{j+1}|y_{1:j}`；停止于「已有认证安全动作 / 边际 VoI ≤ 成本 / 预算耗尽」；跨轮携带信念，仍守每单位时间 ≤1 次。

**定义 315–316（GVQA + CFG）** 问句 `(e,r,form)`，接地集 `G(q)`；`κ_θ(y|m,q,v)` 为校准信道；`κ(q)=sens·spec·(1−β)`；`κ<τ_cf` 降温/拒答；逻辑一致性检查；单答不改写信念。

**定义 317（S2K）** `B_safe={b: 存在认证策略满足机会约束}`；g 认知安全 ⇔ 所有高概率回答的更新后信念在 B_safe；否则 `VoI*_safe=−∞`，先做裕度提升动作再问。

**定义 318（DVA）** `g*=argmax[VoI*_safe−c_info−Δ_perturb+O]` s.t. 预算/认证/κ；再 `a*=argmin Q`；H_q=1、Δ=O=0、V=熵势时退化为 MINT。

**定义 319（HEC）** 证据源 `{a_score,r_res,y,y_h,mem}`，相关矩阵 `Σ_ρ`，`k_eff=1/(1ᵀΣ_ρ^{-1}1)`；`k_eff<2` 且未超高置信 ⇒ 不更新；单源不定案。

**定义 320（DCS）** 信念空间机会约束 + 认证备份；问句社会/物理安全；失败退最优认证动作并 R68 收紧；R70→R69→R68 λ 单调不降。

**定义 321（BVN）** 慢通道拟合 `V_φ(s,b)`，特征含模态权重/协方差/熵/Bayes 风险/间距/进度/预算/可观测性；快通道只读；越域禁用问句。

**定义 322（QCG）** 模态对 → 判别属性 → 场景图/LLM 问法模板 → 适定性过滤；候选 ≤8；LLM 只提议。

**定义 323–325（审计/威胁/证书）** VQAuditor-O 审问句策略与遗漏；`ℰ_OPTIC=ℰ_FLUID×ℰ_vqa×ℰ_qpolicy`；`J_OPTIC` 并入 `U_dec, VoI*, Γ_H, κ_cf, ece_vqa, s2k, k_eff, H_q, log_hash`。

**定义 326（VCG 与三级退化）** `ρ_voi` 滑动监控；失真/越域/slow_fault ⇒ 冻结问句 `λ=λ_floor(U_ale+U_epi)` 退 R69，必要时退 R68；R68 ⊂ R69 ⊂ R70。

## 3. 关键算法伪代码

```python
# IP-265 BVN：慢通道训练，快通道只读
class BeliefValueNet:
    def V(self, s, b):                       # 实时只读
        return self.net(self.features(s, b)) # 模态权重/协方差/熵/Bayes风险/预算/可观测性

# IP-266 DVA：精确双控 VoI（含安全可知、扰动、观测期权）
def dual_control_voi(s, b, g, V):
    if not s2k.safe(s, b, g):  return -INF, 'defer'   # 有回答会出 B_safe
    q_no = min_a expected_cost(s, b, a, None, V)
    q_g  = min_a expected_cost(s, b, a, g,    V)
    return (q_no - q_g) - cost(g) - perturb(g) + option(g), 'ok'

# IP-267 AQT：自适应问句树 + 最优停止
def ask_policy(s, b, cands, V, budget):
    for _ in range(H_q):
        q, val, st = max(((q, *dual_control_voi(s, b, q, V)) for q in cands
                          if cfg.ok(q) and budget.allow(q)), key=lambda z: z[1])
        if st == 'defer': return raise_margin(b)       # 先创造安全知情条件
        if val <= 0:      return None                 # 边际 VoI ≤ 成本 → 停
        b = hec.update(b, vqa.answer(q), q)           # k_eff≥2 才改写
        if safe_action_certified(s, b): return None   # 够用就停
        cands = qcg.condition_on_answer(cands, y)
    return None

# IP-269/270 GVQA + CFG：接地、反事实、逻辑一致
def grounded_answer(q, v, b):
    if not gvqa.well_posed(q, v): return None
    y, kappa = gvqa.channel(q, v), cfg.score(q, v)   # sens·spec·(1−β)
    if kappa < TAU_CF: return gvqa.temper(y, kappa)  # 不单独定案
    return y if cfg.logical_consistent(q, y, b) else None

# IP-276 主闭环（继承 R68/R69，替换「问什么/何时问」）
def OPTIC_RAS_round(M, obs, task):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    b = belief(modes, U_ale, U_epi)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = None
    if U_epi > TAU_EPI and not slow and M.vcg.reliable() and M.bvn.in_domain(b):
        g = M.vqa_planner.ask_policy(o.s, b, M.qcg.generate(modes, o), M.bvn.V, M.budget)
    resolved = False
    if g is not None:
        y = M.vqa.grounded_answer(g, o.v, b)
        b, k_eff = M.hec.update(b, y, g, extras=[a_hat, M.last_r_res])
        resolved = (k_eff >= 2) and M.vcg.consistent(g, y)
    a = M.dva.select_task_action(o.s, b, M.bvn.V)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale if resolved else U_ale + U_epi))
    k = M.dcs.certified_prefix(a, b, M.vista.H)
    if slow or not M.vcg.ok():
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(a, U_cal))   # 回 R68
    M.vqa_o.submit_async(g, y, b, a_hat, k_eff)                   # 参与式审计
    return k, lam, a, (U_ale, U_epi, resolved)
```

## 4. 推导

**引理 19（熵 VoI ≠ 决策 VoI）** 存在实例使 `VoI_H>0` 而 `VoI*=0`（任务无关的高熵歧义），也存在 `VoI_H≈0` 而 `VoI*≥δ`（后验跨过决策边界）。仅当任务为**对数损失、无动力学**时 `VoI*=I(M;Y|g)=VoI_H`——R69 是该纯估计特例。

**引理 20（约束下信息可为负价值；时机是控制变量）** 无约束 POMDP 中信息价值非负；但在机会约束与「认证后必须按知情信念行动」的义务下，某些回答会收缩动作集、抬升代价，甚至使 `τ(b,g,y)∉B_safe`，故 `VoI*_safe=−∞`。正确规则是**先提升安全裕度、把 b 推进 B_safe 内核，再问**——即「先创造安全的知情条件，再知情」。

**引理 21（接地/校准误差的传播上界）** 未接地回答按 `ℓ^κ` 降温后，
`‖b'−b'_{oracle}‖_TV ≤ (1−κ)+ECE+δ_τ`，
`|VoI*_true−VoI*_model| ≤ L_V·[(1−κ)+ECE+δ_V]`。
超过 `τ_err` 时 VCG 必须冻结问句。系：确认偏误的放大倍数被模型误差封顶。

**引理 22（自适应问句树不劣于固定问句组）** 条件独立下模态信息量对问句集合次模；自适应贪心（边际 VoI ≤ 成本即停）达到同等信心所需期望问题数 ≤ 固定组，总代价不高于任何预承诺非自适应策略。**「问到够用就停」是最优停止的结论，而非工程启发。**

**定理 18（严格包含并支配 R69）** (i) `H_q=1、Δ_perturb=O=0、V=熵势、κ=1、ECE=0`、约束不活跃 ⇒ DVA 逐项等于 MINT，其余闭环不变，R69 为边界情形；(ii) 精确 V* 下 OPTIC 期望约束代价 ≤ R69（「不问」始终可选），BVN 误差 δ_V 时最坏差距 ≤ `2δ_V·H_q+` 信道误差项；(iii) R68 ⊂ R69 ⊂ R70 安全单调传递。

**定理 19（认知安全与无突变）** B_safe 控制不变 + S2K 保证所有回答的更新后信念在 B_safe + DCS 认证前缀 ⇒ 物理与认知风险均不越界；任一失败（CFG/VCG/超时/投毒/slow_fault）时 λ 单调不降退 R69/R68，R68 定理 15 的提交-换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：OPTIC-RAS 的最优性完全依赖「价值网与 VQA 信道模型正确」——若 VQA 有系统性语言先验、价值网又在验证域外高估某类问句，**最优控制会主动搜出最能迎合偏置的那一个问题**，把随机的感知错误升级成被优化过的确认偏误；系统会以更低熵、更漂亮的 VoI 曲线、更合法的证书，更确信地相信一个错误世界——**问得越优，偏置越致命。**

**次级风险与缓解**：价值网失配（VCG 预测/实现 VoI 监控，失真即冻结问句退 R69）；VQA 盲答/幻觉（CFG 的 sens·spec·β + 逻辑一致性 + 几何降温，单源不定案）；安全可知违规（S2K + B_safe 不变集 + 先提裕度再问）；问句诱导/投毒（VQAuditor-O 审问法选择 + QCG 只提议不裁决 + 人类研究）；实时预算（慢-快双通道 + 只读价值网 + 异步 VQA）。
