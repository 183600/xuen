## 1. 两个灵感的第一性原理

### 灵感 1 ·「双足机器人」→ 桌面不是世界，基座是一个会被控制、会漂移、会失效的平台

**直觉**：一个人站在平衡板上画画，手的精度上限不由画笔决定，而由平台稳定性决定；而且这个人还能挪动平台来够到远处。前 3 轮把机器人当成「固定在桌边的机械臂」，隐式假设了三条：

1. **世界系 = 首帧系**：IP-13 的 `F`（工作台参考系）首帧锚定后当世界用；
2. **基座静止**：所有路标、断言、协方差都没算基座运动；
3. **可达性 = 臂运动学**：IP-05 的可达性只问 IK 能不能到，不问重心/支撑多边形。

双足把这三条同时打破：基座位姿随时间漂移、操作反力会推动重心、够不到时正确动作可能是**迈一步**而不是硬伸。

**推论（对应本轮设计）**：

- **断言要分两种协方差模型**：目标可见时，目标与末端都在机器人自身坐标系里测量，基座位姿误差是**共模**、在相对量中抵消；目标被遮挡而只能靠世界地图时，基座里程计误差直接进入协方差。两者混用会让卡方断言的误拒率悄悄漂移（L14 / U19）。
- **动态可行路标**：IK 可行只是必要条件；还要过「重心投影在支撑多边形内 + ZMP 裕度 + 关节力矩限」这一关。够不到时的合法动作是步进（U20 / L15）。
- **步进是一等动作**：它同时是「扩大工作空间」和「用运动更新基座状态」；成本记进 L12/L13 的步数账（深化 IP-05）。
- **基座失效是新的失败大类**：摔倒会让整条路标链归零，必须在安全集里显式建模（U22）。

### 灵感 2 ·「容错控制」→ 从「退化链」升级为「残差—隔离—重构—降级」四段流水线

**直觉**：容错不是一串 if-else 兜底，而像免疫系统——先监测异常（残差），再定位病灶（隔离），再重分配资源（重构），最后降低任务等级（降级），并且全程不离开安全集。

前 3 轮的 `Level-0..1.6` 退化链有三个结构性问题：

1. **没有隔离**：只知道「出问题了」，不知道是腿、臂、夹爪、感知还是通信；
2. **没有控制重分配**：要么继续原策略，要么整段回退，无法处理「部分失效」（例如某关节增益掉 30%，但仍可用）；
3. **触发是手写阈值**：没有残差的统计显著性，慢漂移（执行器渐进退化）几乎检测不到。

四段流水线对应四个可验收物：

- **残差**：关节指令-编码器跟踪误差、IMU 与模型预测差、视觉-本体一致性、延迟/ACK 残差；
- **隔离**：签名矩阵（哪组残差同时亮 → 哪类故障），带 CUSUM 检测慢漂移；
- **重构**：分层 QP 控制分配，任务优先级固定「安全 > 平衡 > 操作」，在健康自由度上重新分配；
- **降级**：按价值密度排序的任务子集选择（L16），而不是硬编码 level。

**双足特有的杀手锏——把桌子当拐杖**：腿部分失效时，用非主手撑桌形成闭运动链，牺牲一个手臂换回稳定，然后单臂继续操作。这把「fail-safe（安全停）」升级为「fail-operational（带伤继续）」，但前提是能估计桌面接触力/摩擦/高度，且力限可控（IP-17）。

**为什么这轮值得做**：榜单大概不会公开测故障，但真机评测与隐藏稳健性会；更重要的是，容错所需的「基座状态 + 残差」本身就是名义性能的地基（晃动补偿、增益调度）。它是「一周抄不走」的工程护城河，而不是一个只在故障时才生效的花活。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（浮基可观测性与断言校准）**：仅用本体感受（足式里程计/IMU/关节）+ 低频视觉锚定，能否在站立晃动与步进后把基座位姿及其协方差估到支撑条件断言（误拒率 ∈[α/2,2α]）的程度？可见/不可见两种协方差模型切换是否会引入新的抖动？（E634）
- **Q14（动态可行性与步进收益）**：把「支撑多边形 + ZMP 裕度」并入路标可行性，并允许步进重定位，能否提升远/别扭目标成功率？步数代价相对名义成功率是否划算（L12/L13 记账）？（E635/E636）
- **Q15（容错恢复与名义税）**：残差-FDI-分层 QP 能否在注入的部分故障下恢复，且名义性能不退化？接触支撑能救回多少腿部故障？「容错税」有多大？（E637/E638/E639）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（基座即状态）**：任何世界系断言必须显式声明基座协方差模型。目标可见 → 用基座系相对断言（共模误差抵消）；目标不可见 → 用世界系断言并把 `J_b Σ_b J_bᵀ`（含基座速度×延迟项）并进协方差。禁止两种模型静默混用；切换必须有可见性标志。
- **P14（安全集优先）**：控制分配的任务优先级固定为「安全 > 平衡 > 操作」；任何降级都不得离开安全集；若故障后无法留在安全集，则进入 fail-safe（受控支撑/坐下），而不是继续盲跑。
- **P15（容错潜伏）**：所有容错计算默认在旁路：监测廉价常开、重构按 trip 触发、接触支撑仅在隔离为腿故障后启用。名义路径不得为「未发生的故障」付出可测的性能代价；FT 税由 E639 一票否决。

## 4. 清单处置（深化 / 新增 / 修剪）

- **深化**：
  - **IP-13**：场景图升级为**浮基增强**（U19）——`F` 不再默认是静止世界系，改为「世界地图 + 基座位姿 + 可见性标志」三元；断言按 P13 切换协方差模型；环路闭合时重锚定并重置漂移。
  - **IP-05**：ReachNav 从「IK 可达」升级为「动态可行 + 步进动作」：可行性 = IK ∧ 支撑多边形裕度 ∧ 力矩限；步进成本与收益并入 L12/L13 记账。
  - **IP-09**：伺服增益/时间缩放按稳定裕度调度——用 L15 的 `a_max=(g/h)·m_safe` 给增益设上限，避免操作反力把 ZMP 推出支撑区。
  - **IP-02**：介入家族新增「重构/支撑」：故障隔离后优先重分配，腿故障可切接触支撑模式；触发优先级改为「安全事件 > 故障重构 > 重定位 > 重抓 > 换原语」。
  - **IP-06**：失败矩阵在「六因子 × 五泛化轴」之外增加**故障注入切片**（单列，不与泛化轴混算），用于 IP-18。
  - **IP-03**：延迟整形加入基座速度前馈项；`ACTION REJECTED` 的成因登记增加「基座运动学不可行」一类。
- **新增**：**IP-16 BaseState**（P0，IP-13 的必需子模块，非新模型）、**IP-17 FTES** 容错执行栈（P1）、**IP-18 FaultBench** 故障注入评测（P1）。
- **修剪/合并**：IP-15 的「接触」事件与 IP-17 的接触支撑合并（同一套接触检测）；IP-05 的步进与 IP-10/IP-14 的探测动作统一过 P12 记账；IP-11 继续「条件 + 与 IP-13 跨 episode 版合并跟踪」。
- **MVP 不变**：IP-06 + IP-02 + IP-09 + IP-03 + 通用基线；**IP-13 仍是 MVP 后第一扩展**，**IP-16 作为其子模块一并落地**（只是状态向量加基座位姿/速度/接触，不引入新网络）；IP-17/18 在 IP-16 验证后。
- **退化链更新**：Level-1.6 之后新增 **Level-1.7：基座状态不可用 → 冻结世界系断言，仅用基座系相对断言**；新增 **Level-2：平衡不可恢复 → 受控支撑/坐下（fail-safe）**。

## 5. 本轮最大风险

**容错税（fault-tolerance tax）**：残差监测、分层 QP 与安全裕度会持续占用时延/自由度，而榜单很可能根本不测故障——等于为一个可能不计分的能力，付出确定的名义成功率与步数代价。对冲：①P15 潜伏式设计，监测走旁路、重构只按 trip 触发；②E639 设名义非劣硬门槛（成功率 ≥ 基线−0.5 分、步数 ≤1.02×），不达标就把 FTES 降级为离线诊断/真机模式；③分层 QP 只在安全约束激活时求解，平常走零开销的解析控制。次要风险：浮基协方差估不准导致断言抖动 → 退回 Level-1.7；接触支撑把桌子推滑 → 接触力/摩擦估计 + 力限 + 只在准静态下启用。

## 6. 下一轮迭代计划（深化与修剪，不推倒重来）

- **先做 go/no-go**：E639（名义税）与 E634（基座可观测性/校准）先于一切容错功能；两项不过，IP-17 收缩为「检测 + 保守保持」，不做重分配与接触支撑。

## 3. 新增 IP 详述

### IP-16 · BaseState 浮基状态估计（P0，新，IP-13 子模块）

- **动机**：v3 的所有断言/协方差都默认基座已知且静止；双足 G1 的基座位姿会随晃动/步进变化，且官方数据（WBT 的 `Walk_To_Table`）证明平台确实会移动。基座误差不是小噪声，而是会让卡方断言**系统性误拒**的偏置（L14）。
- **与现有方案差异**：不训新模型。状态向量在 IP-13 上增加 `(b_t, v_b, C)`（位姿/速度/足接触）与 `(Σ_b, Σ_v)`；估计器 = 足式里程计（关节+IMU+接触）与低频视觉锚定（桌面特征/场景检测）的 EKF 融合；输出可见性标志 `ν` 供断言选择协方差模型。
- **可行性**：高。挑战桌面任务多为准静态站立，基座近似静止，估计退化到「低速漂移抑制」，比动态行走容易；新 Dex1 带 `hasState=True` 的 1000-episode 任务可用于离线校准。
- **资源**：新 Dex1 状态数据 + 32 项挑战集；算力小（低频，旁路 CPU）。
- **落地步骤**：①在 IP-13 状态里加基座块与 `ν`；②足式里程计 + 视觉锚定最小实现；③协方差校准（E634，含可见/不可见两模型）；④把 `Σ_b` 与 `(Δt)²J_vΣ_vJ_vᵀ` 接入 U17；⑤环路闭合重锚定并重置漂移。
- **风险**：足滑/视觉锚定失效导致漂移（退化到 Level-1.7）；估计延迟吃掉断言窗口（与 U12 共用预算）；把基座写成世界系反而放大误差（P13 的可见性条件）。

### IP-17 · FTES 容错执行栈（P1，新）

- **动机**：v3 的 Level 链是手写 if-else，无隔离、无控制重分配、无法处理部分失效。容错控制的四段流水线（残差/隔离/重构/降级）把它变成可验收的工程物。
- **组成**：
  1. **残差**：`r_joint=q_cmd−q_enc`、`r_base=IMU−模型预测`、`r_vis=‖x̂_scene−b_t·x̂_base_rel‖`、`r_grip=抓握确认−夹爪标量`、`r_time=P99 延迟−预算`；慢漂移用 CUSUM。
  2. **隔离**：签名矩阵 `S`（残差模式 → 故障类：腿执行器/臂执行器/夹爪/感知/通信）。
  3. **重构**：分层 QP，任务优先级「安全 > 平衡 > 操作」；在健康自由度上重新分配，失效关节从约束/任务中移除。
  4. **降级**：按价值密度排序的任务子集选择（L16），而非硬编码 level。
- **双足特有**：**接触支撑**——隔离为腿故障且准静态时，用非主手撑桌形成闭链，牺牲一臂换稳定，继续单臂操作；需估桌面高度/摩擦并设力限。
- **可行性**：中高。残差与 QP 都是成熟件；难点在阈值/签名标定与「接触支撑不推滑桌子」。
- **资源**：复用 IP-16/13/06；故障注入在 IsaacLab/replay，近零真机成本。
- **落地步骤**：①残差清单与签名矩阵；②分层 QP 最小实现（先只用安全/平衡）；③价值密度降级表（离线预计算）；④接触支撑模式（准静态 + 力限）；⑤E637/638/639。
- **风险**：误报（残差阈值太紧）→ 误触发重构反而降分；QP 在故障后不可行 → 必须回退 fail-safe；接触支撑推滑 → 仅准静态、力限、摩擦下限；FT 税 → P15 潜伏 + E639 一票否决。

### IP-18 · FaultBench 故障注入评测（P1，新）

- **动机**：榜单大概率不公开测故障，但真机与隐藏稳健性会；且故障数据能反向提升名义鲁棒性（晃动补偿、增益调度）。没有故障评测，容错就只是口头设计。
- **组成**：注入清单——关节增益下降 20–50%、编码器丢帧、通信延迟尖峰、外力推基座、相机遮挡、夹爪打滑；在 IsaacLab 与官方 replay 上可复现注入。
- **指标**：成功率-故障严重度曲线（优雅降级单调）、time-to-safe、误报率、恢复率；与真机（若可）故障排序一致性。
- **资源**：中算力（仿真）；无新数据依赖。
- **落地步骤**：①故障清单与注入器；②与 IP-06 失败矩阵的故障切片对齐；③基线对比（无 FT / 硬编码 Level / FTES）；④E637/638。
- **风险**：仿真故障与真机失配 → 只用它做「排序/回归」而非绝对分数；故障注入污染名义评测 → 故障切片单列，不混算。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（浮基增强场景图）**：`M_t = (b_t, v_b, C, Σ_b, Σ_v, T_w, D_w, ν)`——基座位姿/速度/足接触及其协方差、世界系目标/干扰物档案、可见性标志 `ν`。相对表示 `x_T^b = b_t^{-1}x_T^w`。断言协方差按可见性二选一：
  - `ν=1`（目标可见）：`Σ_rel = Σ_perc + (Δt)²J_vΣ_vJ_vᵀ`（基座位姿误差共模抵消，仅剩速度×延迟）；
  - `ν=0`（仅地图）：`Σ_world = Σ_perc + J_bΣ_bJ_bᵀ + (Δt)²J_vΣ_vJ_vᵀ`。
- **定义 U20（动态可行路标与步进）**：`wp` 可行 ⇔ `IK(wp) ∧ m(c_xy,P) ≥ m_safe ∧ τ∈[τ_min,τ_max]`；其中 `P` 为支撑多边形，`m` 为重心投影到边界距离，`c_xy` 为重心投影。操作反力的一阶 ZMP 偏移 `Δzmp ≈ −(h/g)a_ee`（h=重心高度，a_ee=末端水平加速度）。步进算子 `σ_k: b ← b⊕Δb`，成本 `s_step(k)`，同时扩大 `P` 有效域并降低 `Σ_b`。
- **定义 U21（故障签名与可重构度）**：故障类 `f∈{leg_act, arm_act, gripper, perception, comms}`；残差向量 `r(t)`；签名矩阵 `S`（`S_{ij}`=故障 j 对残差 i 的期望符号/幅度）。可重构度 `ρ = d_healthy / d_required`（健康控制自由度维数 / 任务所需维数）。隔离 = 在 `S` 中匹配 `r` 的最简解释。
- **定义 U22（安全集与运行模式）**：`S_safe = {m≥m_safe, τ∈limits, 无自碰/桌碰, |v_b|≤v_max, 接触力≤F_max}`。模式：`FAIL_OP`（安全集可行，带伤继续）、`FAIL_SAFE`（不可操作但可支撑/坐下）、`FAILURE`（摔倒/越界）。降级只能在 `FAIL_OP → FAIL_SAFE` 间转移，禁止反向自动恢复。

class BaseState:

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（浮基偏置使卡方断言误拒膨胀）** 设到位时感知误差 `e_p~N(0,Σ_p)`、基座误差 `e_b~N(0,Σ_b)`，相对量误差 `x̂ = J e_b + e_p`（J 为基座误差到相对位姿的雅可比）。若断言只用 `Σ_p`，则 `d²_p = x̂ᵀΣ_p⁻¹x̂` 的分布为广义卡方 `Σ_i λ_i z_i²`，其中 `λ_i` 是 `Σ_p^{-1/2}Σ_totalΣ_p^{-1/2}` 的特征值、`Σ_total=Σ_p+JΣ_bJᵀ`。因 `Σ_total ⪰ Σ_p`，所有 `λ_i ≥ 1`，故 `d²_p` 随机大于 `χ²_d`，`P(d²_p>χ²_{d,α}) ≥ α`（任一 `λ_i>1` 时严格）。若基座误差有偏 `μ_b≠0`，均值再增 `tr(Σ_p⁻¹JΣ_bJᵀ)+μ_bᵀJᵀΣ_p⁻¹Jμ_b`，误拒进一步膨胀。**可见时改用基座系相对断言**，`J e_b` 共模抵消，`Σ_total→Σ_p+(Δt)²J_vΣ_vJ_vᵀ`，校准恢复（前提：延迟项小）。⇒ 双足晃动/延迟不仅是精度问题，**也是断言校准问题**；L11 的校准只在「基座无偏或已并入协方差」的条件版本下成立。∎

**引理 L15（稳定裕度限制操作带宽）** 准静态双足上，末端水平加速度 `a` 引起的一阶 ZMP 偏移 `|Δzmp|≈(h/g)|a|`（h=重心高度）。要求 `Δzmp` 不越出支撑多边形安全裕度 `m_safe`，得 `a_max=(g/h)·m_safe`。伺服把路标位移 `d` 在时间 `T` 内完成时峰值加速度 `∝d/T²`，故必须 `T ≳ sqrt(d/a_max)`（时间缩放）；闭环增益相应满足 `K ≤ K_max(a_max)`。⇒ **要么降速、要么步进扩大 `m_safe`**；固定增益在高动态段会越界。这也是 IP-09 增益调度的依据。∎

**引理 L16（降级的价值密度最优与安全硬约束）** 设任务 i 的保留价值 `v_i`、控制开销 `c_i`，可重构度 `ρ`。降级即 `max Σ v_i x_i s.t. Σ c_i x_i ≤ ρ, x_i∈{0,1}`。其线性松弛按 `v_i/c_i` 降序贪心最优；任务数少时可离线枚举得到精确优先级表。安全任务是硬约束：若 `c_safety>ρ`，则不存在 fail-operational 解，必须转 fail-safe。⇒ 用**离线价值密度表 + 安全可行性检查**替代手写 Level 链；在线只做 O(1) 查表，不引入额外优化延迟。∎
