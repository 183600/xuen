# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「场景泛化」×「分层规划」）

> R69 问「我该向谁求证」，并给出一个漂亮但**扁平**的回答：在单一时间尺度上采样动作模态、算 VoI、选一个信息动作。它自陈的最大风险是「流模型的模态分布不可信 → 追问一个幻影 / 把误导回答盖章」。这个风险其实暴露了 R69 的两个隐含假设：
> - (a) 不确定性只发生在**一个层级**（下一个动作选哪个模态）；
> - (b) 场景是**同分布**的，标定门 MCG 与似然通道 FMA 足以判断「我还能不能信自己」。
>
> 真实部署中这两条同时失效：新房间可能**结构**全新而**外观**熟悉（或反之），而歧义可能发生在「做哪个子任务」而不是「先迈哪只脚」。
>
> 本轮两个灵感正好补上缺失：
> - **场景泛化**告诉我们：新颖性是**按因子分层**的（结构 / 外观 / 动力学），不是标量 OOD；正确反应不是「检测到新就冻结」，而是「**把新颖性路由到真正失效的那一层，复用其余层**」。
> - **分层规划**告诉我们：不确定性是**嵌套**的，高层歧义会剪掉整棵子树，低层歧义可能根本不影响任务；于是问题从「要不要问」升级为「**在哪一层花这笔交互预算**」。
>
> 核心命题：**用一个层级条件化的流策略统一生成各层动作，把 R69 的 (U_ale, U_epi) 提升为逐层分解，并新增一条 R69 没有的免费证据——自顶向下与自底向上后验的边际一致性 M_ℓ；用 M_ℓ 同时做幻影模态否决、场景迁移路由与「熟悉陷阱」检测。层级只负责提议，安全永远由最底层认证。** 命名 **STRATA-RAS**（Scene-Transfer Routed Abstraction-Tiered Arbitration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个新场景里，我计划中的哪一层还成立、该在哪一层重新规划**」。

## 0. 直觉与动机

**灵感 1（场景泛化 → 新颖性有层级，不是一个标量）**
直觉：人走进一间陌生厨房，不会因为「没来过」就把整段计划作废。他会先看**结构**（灶台、水槽、刀架的关系是否熟悉），再判断**外观**（同款灶台换了颜色无所谓），最后微调**动力学**（这把刀更钝）。认知科学把这种能力叫「图式复用 + 变量重绑定」：抽象图式跨场景保留，只有落在具体槽位上的参数需要重新估计。R69 的 MCG/FMA 把三维位移压成一个标量异常分，反应也只有一种（收紧/别问），既浪费了可复用的高层结构，又无法识别「看起来熟悉、结构全新」的最危险情形。

**灵感 2（分层规划 → 时间抽象给出「假设的嵌套结构」）**
直觉：扁平策略在动作块 H 上算 VoI，本质是**短视**的：它只知道「下一步选哪个模态」，不知道「这个模态属于哪个子任务、这个子任务是否值得做」。分层规划把决策组织成「模式 → 子目标序列 → 技能 → 原语轨迹」的树：高层选错，整棵子树都错；低层选错，可能只损失一个动作块。于是不确定性的价值天然按**后代规模**放大：消解一个高层歧义，等于免费剪掉指数多的低层决策。这给「先问大的」一个可计算的依据，而不是启发式。

**灵感 3（严格包含 → 分层是精化，不是替换）**
直觉：如果层级分解本身是值保持的（value-preserving），那么在同一场景、同一预算下，分层策略不应比 R69 更差；当深度 L=0 时它必须**逐指令**等于 R69。更重要的安全姿态是：高层只能**提议**子目标，真正的执行门仍在 ℓ=0 的 C-RAS-WM 认证。这样每加一层抽象，不会多一个可以直接下发控制的黑箱，只会多一个可以被底层否决的提议者。

**灵感 4（边际一致性 → 回应 R69 的幻影模态）**
直觉：R69 的幻影模态是「局部似然高、全局不可组合」。分层恰好提供两个独立的边际估计：自顶向下的规划器先验 p_td(z_ℓ|o)，和自底向上的技能可达性/价值反演 p_bu(z_ℓ|o)。真实模态应满足**边际化一致**（两个 factorization 给出同一 marginal），幻影模态只在一个 factorization 里存在、在另一个里没有父节点质量。于是「低层似然高 ∧ 边际一致性差」成为幻影的判别签名。这与视觉里的 cycle consistency、无监督翻译里的双向一致性是同一个思想：**没有 ground truth 时，让两条独立通路互相校验**。它是 R69「行为似然 vs 传感器残差」对偶通道在结构侧的自然升级。

**灵感 5（分层是双刃剑 → 相干妄想与熟悉陷阱）**
直觉：分层会带来两个新失败模式。(i) **承诺**：高层计划一旦锁定就持续 W 步，若抽象本身错了，系统会「自洽地」执行一段很长的错误计划，而底层安全门只看得到局部越界。(ii) **跨层共谋**：攻击者可以同时伪造高低层证据，让 M_ℓ≈0，内部一致性反而变成伪证。更隐蔽的是**熟悉陷阱**：外观高度熟悉（低层 OOD 检测说「在分布内」），但结构全新（高层词表不适用）。R69 的 MCG 会被前者骗过。因此本轮必须同时交付：边际一致性否决、因子分解的迁移路由、熟悉陷阱探针、可中断承诺窗口，以及跨层正交证据纪律。

## 1. 形式化定义（增量：定义 310–325）

> 记号约定：为避免与 R69 的 trunk 隐状态 z_t 冲突，本轮记 trunk 隐状态为 **h_t**，子目标为 **z_ℓ**（层级 ℓ）。除特别说明，R69 的定义 293–309 全部继承。

**定义 310（STRATA-RAS 总览）** STRATA-RAS = (HRL-Σ, LUD, ACC, STG, HVOI, CWC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **自底向上认证**：只有 ℓ=0 的已认证原语前缀可下发执行；ℓ≥1 只产生提议，不能绕过底层认证；
(iii) **分层预算与跨层证据**：交互预算按层分配，单层/单源证据不得跨层定案；
(iv) **可中断承诺窗口**：高层决策在 W_ℓ 内承诺执行，仅安全/一致性/迁移中断可提前撤销，且撤销经 ℓ=0 前缀混合保证连续。

**定义 311（层级与层级条件流策略）** 层级 ℓ = 0,…,L。ℓ 层选项 ω_ℓ = (I_ℓ, z_ℓ, π_ℓ, β_ℓ)，其中 z_ℓ ∈ Z_ℓ 为子目标（宏动作），π_ℓ 为执行策略，β_ℓ 为终止条件，持续时长 T_ℓ = N_ℓ·H_0（H_0 为 R69 的原语动作块长度）。层级条件速度场
v_θ(x_s, s | h_t, e_ℓ, z_{p(d)})，
其中 e_ℓ 为 level embedding，z_{p(d)} 为父决策的子目标；各层共享 trunk 与主干参数，只增加轻量条件编码。π_θ(ξ_{t:t+H_0} | o_t, e_ℓ, z_{p(d)})，ξ 沿用 R69 定义 294 的增广动作。**L=0 且 z_{p(d)}=∅ 时退化为 R69 的 FMP。**

**定义 312（场景因子与逐层假设谓词）** 观测 o 分解为因子 f = (f_s, f_a, f_d)：结构（物体/关系/布局）、外观（材质/光照/传感器风格）、动力学（摩擦/柔性/延迟）。每层有假设谓词 A_ℓ(f) ∈ {0,1}：ℓ 层模型（子目标词表、转移、价值）在当前场景成立。场景位移 δ = (δ_s, δ_a, δ_d)，novelty_ℓ = d_ℓ(f, 𝒟_ℓ) 为相对该层训练支撑的分位距离。**A_ℓ 不要求全场景同分布，只要求该层依赖的因子在支撑内。**

**定义 313（逐层不确定性分解 LUD）** 活跃层 ℓ 采样 K_ℓ 个轨迹，按 R69 定义 296 聚类得 {m^ℓ_k}, ŵ^ℓ_k, Σ^ℓ_k；定义
U^ℓ_ale = Σ_k ŵ^ℓ_k tr(Σ^ℓ_k)，U^ℓ_epi = H^ℓ_mode · g(Δ^ℓ_min)。
非活跃层由 mode_head 廉价预测（继承 R69 定义 308）。跨层耦合项 U^ℓ_cross = h(M_ℓ) 见定义 315。

**定义 314（双后验）** 对同一子目标边际 z_ℓ 构造两个独立估计：
- **自顶向下** p_td(z_ℓ | o)：由高层规划器/子目标先验给出；
- **自底向上** p_bu(z_ℓ | o)：由低层选项的可达性、价值与成功证据聚合反演，p_bu(z_ℓ|o) ∝ Σ_{z_{ℓ−1}} p(z_{ℓ−1}|o)·p(z_ℓ|z_{ℓ−1},o)。
二者使用不同参数、不同信息通路，只共享观测 o。

**定义 315（边际一致性残差 ACC）** M_ℓ = D_TV(p_td(·|o), p_bu(·|o))（或 W_2），并叠加可行性项
ρ_ℓ = |V_ℓ(z_ℓ, o) − V̂_{ℓ−1}(z_ℓ, o)| / (|V_ℓ| + |V̂_{ℓ−1}| + ε) + λ_f·1[z_ℓ ∉ Reach_{ℓ−1}(o)]。
判读：M_ℓ 小 ⇒ 两 factorization 一致；M_ℓ 大且两侧都自信 ⇒ 抽象错配/相干妄想候选；M_ℓ 大而一侧弥散 ⇒ 可交互消解的歧义。**M_ℓ 不需要 ground truth，是免费的第三意见。**

**定义 316（分层 value-of-information H-VoI）** 记 D(ℓ) 为层 ℓ 决策的后代决策集，γ∈(0,1) 为深度折扣，
VoI^ℓ(g) = Σ_{d∈D(ℓ)} γ^{depth(d)} ŵ_d [H(M_d|o) − E_{y~p(·|g,o)} H(M_d|o,y)] − c(g)，
s.t. g ∈ 𝒜_info^ℓ、预算允许、且 STG 允许在该层交互。选择
(ℓ*, g*) = argmax_{ℓ,g} VoI^ℓ(g)/c(g)（或等价拉格朗日形式）。
若最大值 ≤ 0：不交互，逐指令退化 R69 的 MINT。**高层歧义因后代数量而放大，这是「先问大的」的定量依据。**

**定义 317（分层预算与分层两级退避）** 总预算 B 分解为 {B_ℓ}；分配规则：边际 H-VoI/成本最高者优先，且高层查询必须能剪掉 ≥ b_min 个后代决策，否则预算下沉。未消解的 epistemic 沿活跃路径累积为
U_floor = U^0_ale + Σ_{ℓ 在活跃路径} κ_ℓ·U^ℓ_epi,unresolved，κ_ℓ = 该层约束的 ℓ=0 决策数（归一化杠杆），
λ = max( R69 的 efs 风险项, λ_floor(U_floor) )。
全部消解 ⇒ 仅 U^0_ale 进 λ（resolution bonus 的分层版）；任一未消解/超时/被投毒/ECE 越界 ⇒ 对应 κ_ℓ 项按 aleatoric 兜底。

**定义 318（跨层证据纪律）** 关于 z_ℓ 的主张需满足以下之一才可定案：(a) ℓ 层内 ≥1 个证据源且相邻层 ≥1 个正交源一致；(b) H-VoI 增益超过高置信阈值；(c) 出现可复现的执行负证据（选项终止失败）且被底层认证记录。禁止「两层共谋一致」单独定案（对应定理 20）。

**定义 319（场景迁移门 STG）** 每层动作 τ_ℓ ∈ {reuse, adapt, replan, abstain}。规则：自顶向下找到最高失效层
ℓ† = max{ ℓ : novelty_ℓ > ν_ℓ ∨ M_ℓ > θ_M }；
对 ℓ>ℓ† 置 reuse；若失效来自结构因子（δ_s≠0）置 τ_{ℓ†}=replan，若仅外观/参数因子（δ_a 或 δ_d）置 adapt；若 ℓ†=L 且结构全新 ⇒ abstain（回 R69 平面保守，不冒险重规划）。**新颖性被路由，而不是全局冻结。**

**定义 320（熟悉陷阱探针 FTP）** 把新颖性分解为 appearance-novel a 与 structure-novel s，FTP = 1[a < ν_a ∧ s > ν_s]（看起来熟悉、结构全新）。FTP 触发 ⇒ 禁止低层 reuse 与高层语言提问（接地不可信），强制 replan/abstain，并用选项终止失败的负证据更新 A_ℓ。这是 R69 幻影模态在场景层的对应物。

**定义 321（可中断承诺窗口 CWC）** 高层 z_ℓ 承诺 W_ℓ 步；中断谓词
I = safety ∨ (M_ℓ > θ_M) ∨ STG reroute ∨ R69 slow_fault ∨ FTP。
中断后在新计划与原计划的 ℓ=0 前缀之间做时间最优混合（继承 R68 换装不变式），保证执行轨迹 Lipschitz 连续、无控制突变。

**定义 322（层级失败模式 ℰ_STRATA）** ℰ_STRATA = ℰ_FLUID × ℰ_abs × ℰ_commit × ℰ_familiar，分别对应：抽象错配/词表缺失、等待承诺后突袭、熟悉陷阱与跨层共谋。新增攻击：**跨层共谋**——同时伪造高低层证据使 M_ℓ≈0。

**定义 323（分层审计 VQAuditor-H）** 审计：(a) 新颖性是否路由到正确层；(b) 预算是否给了边际 H-VoI 最高层；(c) 承诺是否超期；(d) M_ℓ 的证据是否跨层正交；(e) FTP 是否漏报。结论回灌 AuditBuf，作为 STG 阈值与 W_ℓ 的先验。

**定义 324（自适应深度 L）** 默认 L=1（一个子目标层 + 原语层）；仅当结构新颖且预算允许升 L=2；结构新颖度回落时降回 L=1。深度本身是资源，受 P99 实时预算门控。

**定义 325（递归认证 RAS-WM‡）** Cert(z_ℓ) ⇔ 存在已认证的 ℓ−1 前缀 π_{ℓ−1}，在时间窗 T_ℓ 内使 z_ℓ 达成且全程在安全包络内；基例 Cert(primitive) = R68 的 C-RAS-WM。认证自底向上传播；Cert 失败 ⇒ 该层 replan 或 abstain，**绝不放宽 ℓ=0 门限**。

```python
# IP-264 HRL-Σ：层级条件流策略（共享 trunk，只加 level embedding，零重复训练）
class StratifiedFlowPolicy:
    def __init__(self, trunk, velocity_net, mode_heads, L=1):
        self.trunk, self.v = trunk, velocity_net     # v(x_s, s, h, e_l, z_parent)
        self.mode_heads = mode_heads                 # 每层一个廉价歧义预测头

    def sample(self, o, level, z_parent, K, N_step=2):
        h  = self.trunk(o)                           # R69 的 h_t
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0 / N_step) * self.v(xs, i / N_step, h,
                                              embed(level), z_parent)
        return [self.decode(x, level) for x in xs]   # ξ=(a,g) 或子目标 z_l

# IP-265 LUD：逐层不确定性分解
def decompose_level(samples, h, level, mode_head):
    modes  = cluster_trajectories(samples)
    w      = mode_weights(modes)
    U_ale  = sum(w[k] * trace(cov(modes[k])) for k in modes)
    U_epi  = entropy(w) * sep_factor(modes)
    return U_ale, U_epi, modes, mode_head(h)         # h_hat 决定是否升 K/(深度)

# IP-266/267 ACC + STG：双后验、边际一致性、新颖性路由
def marginal_consistency(levels, o, planner, low_level):
    M, rho = {}, {}
    for l in levels:
        p_td = planner.posterior(l, o)               # 自顶向下
        p_bu = low_level.invert(l, o)                # 自底向上（可达性/价值反演）
        M[l]   = total_variation(p_td, p_bu)
        rho[l] = value_mismatch(planner.V(l, o), low_level.V_hat(l, o))
    return M, rho

def route_scene(o, M, rho, novelty):
    ftp = (novelty.appearance < NU_A) and (novelty.structure > NU_S)   # 熟悉陷阱
    if ftp: return {'mode': 'abstain', 'level': None, 'ftp': True}
    bad = [l for l in M
           if novelty[l] > NU[l] or M[l] > THETA_M or rho[l] > THETA_RHO]
    if not bad:
        return {'mode': 'reuse', 'level': None, 'ftp': False}
    l_dag = max(bad)                                # 最高失效层
    mode  = 'replan' if novelty.structure[l_dag] > 0 else 'adapt'
    if l_dag == MAX_L and mode == 'replan':
        return {'mode': 'abstain', 'level': None, 'ftp': False}   # 回 R69
    return {'mode': mode, 'level': l_dag, 'ftp': False}

# IP-269 H-VoI：按后代杠杆分配交互预算
def choose_level_interaction(M, rho, novelty, budget):
    best = None
    for l in active_levels():
        if not budget.allow(l):            continue
        if not stg.allows_interaction(l):  continue      # 结构新颖时禁止高层提问
        for g in info_action_candidates(l):
            if not c_ras_wm.certify_info(g, l): continue # 信息动作仍走认证
            voi = sum(GAMMA**depth(d) * w_hat[d] *
                      (entropy(d) - expected_entropy(d, g))
                      for d in descendants(l))
            score = (voi - cost(g)) / cost(g)
            if best is None or score > best.score:
                best = (l, g, score)
    return best if best and best.score > 0 else None     # 无利可图 → R69 平面

# IP-272：递归认证（自底向上；高层只提议）
def certify(z_l, state, horizon):
    if l == 0:
        return c_ras_wm.certified_prefix(primitive(z_l), state, horizon)
    return any(certify(child, state, T_l) for child in expand(z_l, state))

# IP-275 主闭环：在 R69 闭环外套一层「路由 → 分层规划 → H-VoI → 承诺 → 递归认证」
def STRATA_RAS_round(M, o):
    h, o = M.mtm.forward(o); c, U_cal, thr = M.cof.step(...)   # 继承 R68/R69
    nov = M.stg.measure_novelty(o)                            # 因子分解新颖性
    # 1) 双后验 + 边际一致性（免费第三意见）
    M_l, rho = M.acc.marginal_consistency(active_levels(), o,
                                          M.planner, M.low_level)
    route = M.stg.route_scene(o, M_l, rho, nov)
    # 2) 结构性失效：在失效层重规划；FTP 直接 abstain
    if route['mode'] in ('replan', 'adapt'):
        plan = M.planner.replan(at=route['level'], o=o)
        M.cwc.commit(plan, W=W_of(route['level']))
    elif route['mode'] == 'abstain':
        plan = M.flat_fallback(o)                             # 逐指令回 R69
        M.cwc.commit(plan, W=0)
    else:
        plan = M.cwc.current_plan()
    # 3) 逐层不确定性 + H-VoI（先高层、后低层）
    U = {l: M.lud.decompose_level(M.fmp.sample(o, l, plan.parent(l), K(l)), h, l,
                                  M.fmp.mode_heads[l]) for l in active_path(plan)}
    g = M.hvoi.choose_level_interaction(U, M_l, nov, M.budget)
    if g is not None:
        l, g, _ = g
        ans = M.cia.execute(g, level=l)
        U = M.cia.update_level(U, l, ans, discipline='cross_level_orthogonal')
    # 4) 分层两级退避（未消解的逐层按杠杆 κ_l 兜底）
    U_floor = U[0].ale + sum(KAPPA[l] * U[l].epi for l in active_path(plan))
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 5) 递归认证：高层只提议，底层下结论
    k = max(k for k in range(len(plan) + 1)
            if M.ras_wm_double.certify(plan[:k], o, horizon=k))
    if route['mode'] == 'abstain' or M.fma.slow_fault(o):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(plan, U_cal))  # R68 最保守
    # 6) 可中断承诺 + 审计
    if M.cwc.should_interrupt(M_l, rho, route):
        plan, k = M.cwc.switch(plan, M.flat_fallback(o), blend='lipschitz')
    M.vqa_h.submit_async(route, M_l, U, lam, k)
    return k, lam, plan, (U, route)
```

## 3. 推导

**引理 19（层级信息增益的指数放大）** 设层 ℓ 的模态熵为 H，每个 ℓ 模态在其子树内有 b_L−ℓ 个后代决策，后代价值按 γ 折扣、条件独立于模态给定父节点。则消解层 ℓ 的歧义所减少的期望后悔 ≥ (1−e^{−H})·γ^{L−ℓ}·b^{L−ℓ}·r_min，其中 r_min 为单决策最小后悔。故 VoI^ℓ/VoI^{ℓ−1} ≥ bγ（在同等成本下），**高层可分的歧义天然比低层值钱**。系：若高层 Δ_min 很小（模糊但不可分），交互仍无益，直接按 R69 引理 16 保守——可约性判据在每一层都成立。

**引理 20（幻影模态的不可组合性）** 设真实模态满足 A99（可组合性：存在正质量的父节点使其可行）。若 m 为幻影，则它在 p_bu 中的父节点质量为 0，于是 M_ℓ ≥ δ_m > 0；而 R69 的模态似然/熵判据可任意小。在观测噪声 σ 下，ACC 门拒斥幻影的概率 ≥ 1 − exp(−δ_m²/2σ²)。系：**（低层似然高 ∧ M_ℓ 大）是幻影的判别签名**，比单独 MCG 校准更稳，因为 M_ℓ 不依赖模态权重本身可信。

**引理 21（选择性泛化半径）** 在因子分解场景下，若抽象对 f_a 不变（A100），则 ‖δf_a‖ ≤ R 时高层计划有效性不变、低层模态位移 ≤ L_f·R；但任何 δf_s ≠ 0 都可能使高层有效性失效，且与外观相似度无关。因此：(i) 存在仅由外观位移刻画的泛化半径 R_ε；(ii) 标量 OOD/ECE 无法区分「外观新」与「结构新」，必有熟悉陷阱；STG 的因子路由是必要的，不是工程优化。

**引理 22（承诺窗口的安全-效率权衡）** 设结构突变强度 λ、重规划成本 c_r、错误计划单步成本 c_w。承诺 W 步的期望后悔满足 E[regret] ≤ c_r/W + c_w·λ·W²/2，最小化于 W* = (2c_r/(c_w λ))^{1/3}。故承诺不是越短越安全：过短会因频繁重规划引入抖动与成本；CWC 的 W* 给出可计算的折中，且中断谓词保证结构突变时不被 W 绑死。

**定理 18（STRATA 严格包含 FLUID/R68）** 在 A95–A100 下：
(i) L=0 且场景同分布 ⇒ STRATA 与 FLUID 逐指令相同；
(ii) 抽象值保持（A99）且 τ=reuse ⇒ 分层计划期望风险 ≤ FLUID；
(iii) 抽象失效（M_ℓ>θ_M 或 FTP）⇒ STG 路由到 replan/abstain，最坏退化为 FLUID；路由开销 ≤ ε_route。
故 STRATA 在安全侧不弱于 R69，只在抽象成立时获取组合泛化的效率收益；R69 是「单层 + 永不迁移」边界。

**定理 19（分层安全与无突变）** 递归认证（定义 325）保证任何下发前缀的物理风险 ≤ ε；高层提议不能绕过 ℓ=0 认证；CWC 中断经 Lipschitz 混合，继承 R68 定理 15 的换装不变式 ⇒ 轨迹连续、无控制突变；层级切换的最坏抖动 ≤ ε_blend。

**定理 20（跨层共谋上界）** 若单层欺骗率为 δ_p、跨层欺骗相关为 ρ<1，采用定义 318 的跨层正交纪律，错误定案率 ≤ δ_p·ρ^{k−1} + ε_σ（k 为正交层数）；当 ρ→1（完美共谋）时上界退化为 δ_p，此时任何内部一致性都无法救——必须依赖外部锚（执行负证据/人工审计）。这是 R69 引理 18 的分层版，并明确标出它的失效边界。

## 6. 本轮最大风险

**一句话**：STRATA-RAS 的全部泛化收益押在「层级分解本身正确」这一前提上——**若新场景需要一个技能库里根本不存在的抽象（或高层子目标词表本身错配），那么高低两层会在同一个错误假设下互相印证，M_ℓ≈0，系统将以「相干妄想」的方式自信执行一段很长的错误计划；这比 R69 的幻影模态更危险，因为边际一致性反而提供了伪证。**

**次级风险与缓解**：
1. **抽象词表缺失**（新场景需要不存在的子目标）→ FTP + A_ℓ 支撑域检查 + abstain；但这是本轮未解的核心，只能承认并交给下一轮（安全实验/技能发明）；
2. **跨层共谋**（ρ→1）→ 定理 20 明确失效边界；缓解为跨层正交证据 + 执行负证据 + 人工审计，不能宣称可完全防；
3. **承诺窗口被利用**（等待承诺后突袭）→ 中断谓词 + 引理 22 的 W* + 随机承诺抖动；
4. **深度带来延迟** → 自适应 L + 高层缓存 + P99 门控；
5. **自底向上后验被 R69 幻影污染** → ACC 只把它当「一致性检验」而非真值；FTP 专门覆盖结构层，任何单一 factorization 都不得单独定案。

```python
# IP-264 层级条件流策略（共享 trunk，零重复训练）
class StratifiedFlowPolicy:
    def sample(self, o, level, z_parent, K, N_step=2):
        h, xs = self.trunk(o), randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v(xs, i/N_step, h, embed(level), z_parent)
        return [self.decode(x, level) for x in xs]           # ξ 或子目标 z_l

# IP-266/267 双后验 + 边际一致性 + 场景路由
def marginal_consistency(levels, o, planner, low_level):
    M, rho = {}, {}
    for l in levels:
        p_td, p_bu = planner.posterior(l, o), low_level.invert(l, o)
        M[l]   = total_variation(p_td, p_bu)
        rho[l] = value_mismatch(planner.V(l, o), low_level.V_hat(l, o))
    return M, rho

def route_scene(o, M, rho, novelty):
    ftp = (novelty.appearance < NU_A) and (novelty.structure > NU_S)
    if ftp: return {'mode': 'abstain', 'level': None, 'ftp': True}
    bad = [l for l in M if novelty[l] > NU[l] or M[l] > THETA_M or rho[l] > THETA_RHO]
    if not bad: return {'mode': 'reuse', 'level': None, 'ftp': False}
    l_dag = max(bad)                                        # 最高失效层
    mode  = 'replan' if novelty.structure[l_dag] > 0 else 'adapt'
    if l_dag == MAX_L and mode == 'replan':
        return {'mode': 'abstain', 'level': None, 'ftp': False}   # 回 R69
    return {'mode': mode, 'level': l_dag, 'ftp': False}

# IP-269 分层 VoI：按后代杠杆分配预算
def choose_level_interaction(U, M_l, novelty, budget):
    best = None
    for l in active_levels():
        if not budget.allow(l) or not stg.allows_interaction(l): continue
        for g in info_action_candidates(l):
            if not c_ras_wm.certify_info(g, l): continue
            voi = sum(GAMMA**depth(d) * w_hat[d] *
                      (entropy(d) - expected_entropy(d, g)) for d in descendants(l))
            score = (voi - cost(g)) / cost(g)
            if best is None or score > best.score: best = (l, g, score)
    return best if best and best.score > 0 else None        # 无利可图 → R69

# IP-272 递归认证：高层只提议，底层下结论
def certify(z_l, state, horizon):
    if l == 0:
        return c_ras_wm.certified_prefix(primitive(z_l), state, horizon)
    return any(certify(child, state, T_l) for child in expand(z_l, state))

# IP-275 主闭环（R69 闭环外套分层路由）
def STRATA_RAS_round(M, o):
    h, o = M.mtm.forward(o); c, U_cal, thr = M.cof.step(...)
    nov  = M.stg.measure_novelty(o)
    M_l, rho = M.acc.marginal_consistency(active_levels(), o, M.planner, M.low_level)
    route = M.stg.route_scene(o, M_l, rho, nov)
    if route['mode'] in ('replan', 'adapt'):
        plan = M.planner.replan(route['level'], o); M.cwc.commit(plan, W_of(route['level']))
    elif route['mode'] == 'abstain':
        plan = M.flat_fallback(o); M.cwc.commit(plan, W=0)
    else:
        plan = M.cwc.current_plan()
    U = {l: M.lud.decompose_level(M.fmp.sample(o, l, plan.parent(l), K(l)), h, l,
                                  M.fmp.mode_heads[l]) for l in active_path(plan)}
    g = M.hvoi.choose_level_interaction(U, M_l, nov, M.budget)
    if g is not None:
        l, g, _ = g; U = M.cia.update_level(U, l, M.cia.execute(g, level=l),
                                            discipline='cross_level_orthogonal')
    U_floor = U[0].ale + sum(KAPPA[l] * U[l].epi for l in active_path(plan))
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = max(k for k in range(len(plan)+1)
            if M.ras_wm_double.certify(plan[:k], o, horizon=k))
    if route['mode'] == 'abstain' or M.fma.slow_fault(o):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(plan, U_cal))
    if M.cwc.should_interrupt(M_l, rho, route):
        plan, k = M.cwc.switch(plan, M.flat_fallback(o), blend='lipschitz')
    M.vqa_h.submit_async(route, M_l, U, lam, k)
    return k, lam, plan, (U, route)
```

## 4. 推导

**引理 19（层级信息增益的指数放大）** 层 ℓ 模态熵 H、后代数 `b^{L−ℓ}`、折扣 γ、条件独立（A99）下，消解该层歧义减少期望后悔 ≥ `(1−e^{−H})γ^{L−ℓ}b^{L−ℓ}r_min`。故同成本下 `VoI^ℓ/VoI^{ℓ−1} ≥ bγ`：**高层可分的歧义更值钱**。若高层 `Δ_min` 小（模糊不可分），交互仍无益，按 R69 引理 16 保守——可约性判据逐层成立。

**引理 20（幻影模态的不可组合性）** 真实模态满足 A99（存在正质量父节点）；幻影在 `p_bu` 中父节点质量为 0，故 `M_ℓ ≥ δ_m > 0`，而 R69 的似然/熵判据可任意小。观测噪声 σ 下 ACC 拒斥概率 ≥ `1−exp(−δ_m²/2σ²)`。系：**（低层似然高 ∧ M_ℓ 大）是幻影的判别签名**，且不依赖模态权重本身可信。

**引理 21（选择性泛化半径）** 抽象对 `f_a` 不变（A100）时，`‖δf_a‖≤R` 只使低层模态位移 ≤ `L_f R`，高层有效性不变；任何 `δf_s≠0` 都可使高层失效，且与外观相似度无关。故：(i) 存在仅由外观位移刻画的半径 `R_ε`；(ii) 标量 OOD/ECE 无法区分「外观新」与「结构新」，必有熟悉陷阱，STG 的因子路由是**必要**的。

**引理 22（承诺窗口权衡）** 结构突变强度 λ、重规划成本 `c_r`、错误计划单步成本 `c_w` 下，`E[regret] ≤ c_r/W + c_wλW²/2`，最优 `W* = (2c_r/(c_wλ))^{1/3}`。承诺不是越短越安全；CWC 的 W* 给出可计算折中，中断谓词保证突变时不被 W 绑死。

**定理 18（严格包含 FLUID/R68）** A95–A100 下：(i) `L=0` 且同分布 ⇒ 与 FLUID 逐指令相同；(ii) A99 成立且 `τ=reuse` ⇒ 分层期望风险 ≤ FLUID；(iii) 抽象失效（`M_ℓ>θ_M` 或 FTP）⇒ 路由到 replan/abstain，最坏退化为 FLUID，路由开销 ≤ `ε_route`。安全侧不弱于 R69，只在抽象成立时获取组合泛化收益。

**定理 19（分层安全与无突变）** 递归认证保证任何下发前缀物理风险 ≤ ε；高层不能绕过 ℓ=0 认证；CWC 中断经 Lipschitz 混合，继承 R68 定理 15 ⇒ 轨迹连续、无控制突变；切换抖动 ≤ `ε_blend`。

**定理 20（跨层共谋上界）** 单层欺骗率 `δ_p`、跨层欺骗相关 ρ<1、k 个正交层一致时，错误定案率 ≤ `δ_p·ρ^{k−1}+ε_σ`；`ρ→1`（完美共谋）时退化为 `δ_p`，内部一致性失效，只能依赖执行负证据/人工审计。**明确标出该防线的失效边界。**

## 7. 本轮最大风险

**一句话**：STRATA-RAS 的全部泛化收益押在「层级分解本身正确」这一前提上——**若新场景需要技能库里不存在的抽象（或高层子目标词表本身错配），高低两层会在同一个错误假设下互相印证，`M_ℓ≈0`，系统将以「相干妄想」的方式自信执行一段很长的错误计划；这比 R69 的幻影模态更危险，因为边际一致性反而提供了伪证。**

**次级风险与缓解**：抽象词表缺失（FTP + `A_ℓ` 支撑域检查 + abstain；本轮未解的核心）；跨层共谋 `ρ→1`（定理 20 标出失效边界，只能靠执行负证据/人工审计）；承诺窗口被利用（中断谓词 + 引理 22 的 W* + 随机承诺抖动）；深度延迟（自适应 L + 高层缓存 + P99 门控）；`p_bu` 被 R69 幻影污染（ACC 只作一致性检验、不作真值，任何单一 factorization 不得单独定案）。
