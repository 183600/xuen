研究循环·新灵感二元组·本轮；本轮灵感：「安全交互」×「故障诊断」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（PGEV 物理接地-能量层：HDL / ACSC / DCSC / HPC-E / CFC++；其上承 v21 语义-规范层 SDC/CAC/DCL/GIC/HPC+，再承 v20 联邦感知证书 PCA/CTS/CFC/HPC 与 v19/v17 各模块）。
> 本轮纪律：**故障是被隔离并可对证的证据、降级是沿依赖图定位到部件的证书收缩、交互是带力/功率约束的双向契约**。不推倒 v22：SDC/CAC/DCL/GIC/HPC+/EVC/RGC/HDL/ACSC/DCSC/CFC++ 全部保留。本轮只做一件事：**在 v22 之上加一层"健康-证据 + 接触契约"层，把"隐含假设健康 + 全局保守回退"升级为"已诊断健康 + 定向降级"，把"人是障碍/意图源"升级为"人是受功率约束的交互伙伴"**。

## 0. 直觉与动机

**灵感 1（故障诊断 → "健康"必须是被证明的，降级要定向不要坍塌）**
直觉：v22 的失效路径几乎都是"某模块坏了 → 整条证书链退回上一版"。这里藏着一个**单点全序**假设：只要有一处不可信，就只能在同一条全序上整体后退。可现实中的故障是**局部的、可隔离的**：编码器偏置坏了不影响激光雷达点云 Hull，力传感器漂移不影响几何 HPC，腕部关节卡滞不影响底盘的能量账户。故障诊断（残差生成 → 故障隔离 → 可诊断性分析）恰好提供 v22 缺失的两样东西：**健康掩码**——哪张子证书、哪个部件仍然有效；以及**对证责任**——"我判定它健康"本身必须有残差证据支撑，而不能是默认值。核心创新：**可诊断健康证书 (Diagnosability Health Certificate, DHC)** 把证书系统编码为**证书依赖图 (Certificate Dependency Graph, CDG)**，每个节点带 provenance（依赖哪些传感器/模型/上游证书）与一个由构造保证更保守的 `fallback`；给定隔离出的故障上界 `F̂⁺`，用**定向收缩算子 ⊓** 只砍掉被污染子树，保留**最大仍有效子证书**。关键反直觉点：**"健康"必须是诊断的输出，而不能是诊断的空输入**——未证明健康的部件一律按"可能故障"参与收缩，于是**漏诊只会让系统更保守，而不会让它越权**。

> 严谨定义：CDG $=(V,E,\mathrm{deps},\mathrm{prov})$；节点模式 $m_n\in\{\text{healthy},\text{fallback}\}$，且由构造 $A_n(\text{fallback})\subseteq A_n(\text{healthy})$。定向收缩 $\mathrm{Exec}_{v23}(H)=\bigcap_{n\in V} A_n(m_n(H))$，其中 $H$ 为健康掩码。**命题（声明集单调）**：对任意 $H$，$\mathrm{Exec}_{v23}(H)\subseteq \mathrm{Exec}_{v23}(\top)=\mathrm{Exec}_{v22}$。

**灵感 2（安全交互 → 从"避碰"到"受约束的接触 + 可预测的承诺"）**
直觉：v21/v22 把人当"要么障碍、要么意图源"，但真正的人机安全交互发生在两种被现有证书忽略的情形里：**接触**（交接、协作搬运、物理引导）与**可预测性**（人需要能预判机器人下一步要做什么）。避碰只保证"不碰"，不保证"碰了也不伤人"；而交互也不只是"机器人看人"，还包括**机器人向人承诺**：一段可读的、带撤销语义的运动契约。ISO/TS 15066 的功率与力限制给出了可标定的**接触安全包络**，可以把"接触"从失败升级为**受控模式**；交互契约则让机器人广播"我将在 $\tau$ 内进入 $Y$ 让位/停靠"，并显式建模**人对承诺的依赖**。关键反直觉点：**把人建模成永久障碍并不必然更安全**——人在无法预测机器人时会抢行、试探、误判，反而制造事故；**带承诺的可预测运动 + 受控接触**把安全性从"机器人单方的几何隔离"变成"双方共同维护的契约"。

> 严谨定义：区域 $r$ 的接触可行集 $C_{\mathrm{adm}}(r)=\{(F,p,P,v_{\mathrm{rel}}):F\le F_{\max}(r),\,p\le p_{\max}(r),\,F\,v_{\mathrm{rel}}\le P_{\max}(r)\}$。承诺算子 $\mathrm{commit}(\tau,Y)$ 带撤销提前量 $\tau_{\mathrm{cancel}}$ 与撤销语义；契约状态 $\kappa_{\mathrm{contract}}\in\{\text{offered},\text{active},\text{revoked},\text{kept},\text{broken}\}$。准入要求 $\mathrm{Promise\_kept}$，撤销只允许向更保守方向（停/远离）。

**三者如何统一**
统一为 **v22 之上的"健康-交互"层**：DHC 回答"哪张证书还值得信、坏在哪"，CCx/ICx 回答"接触与承诺的安全边界在哪"。共享状态 $\zeta_{\mathrm{pgev}}$ 扩展为 **$\zeta_{\mathrm{inter}}=\zeta_{\mathrm{pgev}}\cup(R_t,\hat F_t,\hat F^{+}_t,H_t,C_{\mathrm{contact}},F_{\mathrm{budget}},\kappa_{\mathrm{contract}})$**。统一准入门：**HPC-E-I $=$ (HPC-E, DHC, ICx)**——只有"几何/规范/负信息/能量（v22）$\wedge$ 已诊断健康（DHC）$\wedge$ 接触契约可兑现（ICx）"才进入执行；任一缺失，沿 CDG **定向**收缩到最大有效子证书，而不是全局坍塌。DHC 的"未证明健康即保守"与 CCx 的"接触即受控模式"共同保证 `Exec_v23 ⊆ Exec_v22`。

## 2. 设计原则（在 P37 / P41 / P42 基础上新增 P43–P45）

**P43 健康即证据律（Health-as-Evidence）**
证书节点健康 = **有残差证据支持** $\wedge$ **未被隔离故障污染**：$H_t(n)=(\text{evid}_t(n)\ \text{充分})\wedge(\mathrm{deps}(n)\cap\hat F^{+}_t=\varnothing)$，默认 $H_t=\bot$（未证明即不可信）。执行集 `Exec_v23 = Exec_v22 ⊓_{F̂⁺} CDG`：沿依赖图**只收缩被污染子树**，健康节点保留其已认证行为，污染节点替换为更保守的 `fallback`。收缩使用**污染上界** $\hat F^{+}_t\supseteq \hat F_t$（含隔离歧义类），因此漏诊只会使 $\hat F^{+}$ 被低估——故另以"未证明不健康"默认项兜底，保证声明集单调。

**P44 可诊断性守门律（Diagnosability Gating）**
系统的**可诊断性**（哪些故障可被隔离到粒度 $g$）是**认证前置条件**，不是运行时实现细节。任一不可隔离到所需粒度的故障类，必须映射到其最小可隔离歧义类 $A(f)$，并按 $A(f)$ 的**最保守成员**参与收缩。主动诊断探针 $\pi_{\mathrm{probe}}$ 必须先通过 HPC-E-I 门，且其信息增益必须超过风险/能量代价：$\mathrm{IG}(\pi_{\mathrm{probe}})/(\mathrm{cost}+\epsilon)\ge\theta_{\mathrm{probe}}$。

**P45 接触契约律（Contact-Contract）**
接触不是违规而是**受控模式**：$\mathrm{contact\_allowed}\iff (F\le F_{\max}(r)\wedge p\le p_{\max}(r)\wedge E_{\mathrm{contact}}\le E_{\mathrm{budget}})$。机器人对外承诺 $\mathrm{commit}(\tau,Y)$ 具**撤销语义**（撤销须提前 $\tau_{\mathrm{cancel}}$ 且可读），人对承诺的依赖被显式建模；**承诺撤销不得提高接触力上界**。故 `Exec_v23 = Exec_v22 ∩ Fil_contact ∩ Promise_kept ⊆ Exec_v22`。

## 3. 与基线的接口（如何退化）

- **DHC 失效**（无残差/诊断器崩溃）⇒ 所有节点健康视为未证明 ⇒ 全局按 v22 最保守退出 ⇒ 等价 v22（更保守）；
- **诊断误报**（把好部件判坏）⇒ 定向收缩过多 ⇒ 仍为子集，仅损失活性；
- **诊断漏报 / 共模** ⇒ 用污染上界 $\hat F^{+}$ 与"未证明不健康"条款兜底 ⇒ 声明集仍 $\subseteq$ v22（引理 163）；但见 §5 的现实安全风险；
- **CCx 失效**（无力/功率感知）⇒ 禁止接触、退化为纯避碰 ⇒ 等价 v22；
- **ICx 失效**（无法维持承诺）⇒ 撤销到最保守停靠 ⇒ 子集；
- **三者全失效** ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 162 / 163 串接）。
- **安全继承**：DHC 只把健康节点降为更保守 fallback、CCx 只缩小接触集、ICx 只允许可兑现承诺；任意失效都向更保守方向退化。DHC/ICx 状态机以事件方式（10Hz 注入 + TTL）接入 v17 APS 新鲜度阶梯，控制路径仅做 O(1) 健康掩码/契约状态查询。

## 4. 预期贡献

1. **可诊断健康证书 DHC + 证书依赖图 CDG**：把"健康"从隐含假设变成有残差证据的输出，给出**定向降级**（只砍被污染子树）而非全局坍塌；
2. **污染上界下的单调安全**：证明即使诊断漏报，`Exec_v23 ⊆ Exec_v22` 仍成立——把"诊断不可靠"从**越权风险**转化为**活性损失**（但明确其不覆盖现实前提被污染的盲区）；
3. **可诊断性守门 + 安全门控的主动诊断**：把可诊断性作为认证前置条件，探针动作纳入 HPC-E-I 与能量/暴露预算，做信息增益-风险权衡；
4. **接触证书 CCx**：按身体区域标定的力/压强/功率包络，把受控接触从失败升级为可审计模式，并把检测延迟与动量纳入接触能量账户；
5. **交互契约 ICx**：可撤销、可读、双向承诺的形式化，安全性从单方几何隔离升级为双方共同维护的契约；
6. **HPC-E-I 统一门**：HPC-E ∪ DHC ∪ ICx 三证一体，闭环 `Exec_v23 ⊆ Exec_v22 ⊆ …`。

## 5. 本轮最大风险

**一句话**：DHC 的全部可靠性押在"故障落在残差模型可张成的空间内"这一**可诊断性假设**上；若存在共模故障或全新失效模式，使多个看似独立的残差同时"健康地"失效（如标定被系统性篡改、传感器被对抗性欺骗），诊断器会**高置信地宣告健康**，定向降级反而比全局保守**保留了更多被污染的证书**——机器人将"有据可查地、自信地"用一张已被污染的证书执行；"健康幻觉"比上一轮的"缺席幻觉"更隐蔽，因为它把安全赌注从"看见"转移到了"证明自己没病"。

## 1. 关键算法骨架

```python
# ---------- IP-436: 证书依赖图与定向收缩 ----------
@dataclass
class CertNode:
    id: str
    deps: set[str]                 # 依赖的传感器/模型/上游证书 id
    provides: Callable             # 健康时授予的许可集（可能很宽松）
    fallback: Callable             # v22 保守默认；由构造保证 ⊆ provides
    primitives: set[str]           # 该证书直接消费的物理/模型原语

class CertificateDependencyGraph:
    def __init__(self, nodes: list[CertNode]):
        self.nodes = {n.id: n for n in nodes}
        self.order = self._topo_order()

    def _topo_order(self):
        seen, stack = set(), []
        def visit(nid):
            if nid in seen: return
            seen.add(nid)
            for d in self.nodes[nid].deps:
                visit(d)
            stack.append(nid)
        for nid in self.nodes: visit(nid)
        return stack

    def contract(self, fault_upper: set[str], evidence_ok: dict[str, bool]):
        """自底向上：健康 = 自身残差证据充分 ∧ 未被污染 ∧ 依赖皆健康。
        未证明 → fallback（默认不健康）。返回每个节点实际采用的许可集。"""
        health, modes = {}, {}
        for nid in self.order:
            n = self.nodes[nid]
            clean = not (n.primitives & fault_upper) and not (n.deps & fault_upper)
            dep_ok = all(health.get(d, False) for d in n.deps)
            healthy = clean and dep_ok and evidence_ok.get(nid, False)
            health[nid] = healthy
            modes[nid] = n.provides if healthy else n.fallback
        return health, modes


# ---------- IP-437: 可诊断健康证书 ----------
class DiagnosabilityHealthCertificate:
    def __init__(self, signature: np.ndarray, isolable_class: dict, alpha_diag=0.01):
        self.S = signature                 # 故障签名矩阵 S_f
        self.A = isolable_class            # f -> 最小可隔离歧义类
        self.alpha = alpha_diag

    def isolate(self, R: np.ndarray) -> tuple[set[str], set[str]]:
        """一致性诊断：候选 = 与残差模式一致的最小碰集。"""
        cands = consistency_based_diagnosis(self.S, R, self.alpha)
        f_hat = set(cands)                                   # 点估计（可含歧义）
        f_plus = set().union(*[self.A[f] for f in cands]) if cands else set()
        return f_hat, f_plus                                 # 报告用 f_hat，收缩用 f_plus

    def healthy_predicate(self, cdg, f_plus, residuals, evidence):
        """健康谓词：默认 ⊥；只有证据充分且不被污染才 ⊤。"""
        _, modes = cdg.contract(f_plus, evidence)
        return modes


# ---------- IP-438: 安全门控的主动诊断 ----------
class ActiveDiagnosisGate:
    def __init__(self, hpcei, theta_probe=0.1, risk_weight=1.0):
        self.hpcei, self.theta, self.w = hpcei, theta_probe, risk_weight

    def propose(self, candidates, state):
        best = (0.0, None)
        for p in enumerate_probes(candidates):
            if not self.hpcei.admits(p.plan, state):       # 探针本身必须先安全
                continue
            ig = information_gain(p, candidates)           # 对故障假设的熵减
            cost = p.energy + self.w * p.exposure
            score = ig / (cost + 1e-9)
            if score >= self.theta and score > best[0]:
                best = (score, p)
        return best[1]                                     # None = 放弃主动诊断


# ---------- IP-439: 接触证书 ----------
class ContactCertificate:
    # 依据 ISO/TS 15066 身体区域（示例值，需按机型/人体重新标定）
    REGION = {"hand": (140.0, 200e3, 80.0),
              "forearm": (120.0, 180e3, 60.0),
              "torso": (140.0, 160e3, 50.0),
              "head": (65.0, 120e3, 20.0)}

    def admissible(self, region, F, p, v_rel, dt_detect, momentum):
        Fmax, pmax, Pmax = self.REGION[region]
        # 检测延迟内的动量/力超调必须预留裕度
        F_eff = F + momentum / max(dt_detect, 1e-3)
        p_eff = p + self._pressure_overshoot(F, dt_detect)
        return (F_eff <= Fmax and p_eff <= pmax and F_eff * v_rel <= Pmax)

    def _pressure_overshoot(self, F, dt):
        # 线性一阶超调上界；标定时取 1-δ 分位
        return 0.15 * F * dt


# ---------- IP-440: 交互契约 + HPC-E-I 统一门 ----------
class InteractionContract:
    def __init__(self, hpcei, tau_cancel=0.4):
        self.hpcei, self.tau_cancel = hpcei, tau_cancel

    def commit(self, tau, Y, state):
        assert self.hpcei.admits(self.plan_to(Y), state)   # 承诺前先过安全门
        return Commitment(tau=tau, Y=Y, revocable=True,
                          cancel_lead=self.tau_cancel, state="offered")

    def revoke(self, c, now, reason):
        """撤销只允许向更保守方向（停/远离），且必须可读。"""
        if now < c.deadline - c.cancel_lead:
            c.state = "revoked"
            return conservative_stop(c.Y, signaling="human_readable")
        return None                                        # 来不及 → 不撤销，兑现承诺

    def promise_kept(self, plan, state):
        return state.contract not in ("broken",) and self._follows_committed_prefix(plan)


@dataclass
class HPCEI:
    hpce: HPCE
    dhc: DiagnosabilityHealthCertificate
    ccx: ContactCertificate
    icx: InteractionContract

    def admits(self, plan, state):
        return (self.hpce.admits(plan, state) and
                self.dhc.healthy_for(plan.deps, state) and
                self.ccx.admissible(state.contact_region, state.F, state.p,
                                    state.v_rel, state.dt_detect, state.momentum) and
                self.icx.promise_kept(plan, state))
```

## 2. 关键引理与证明草图

**引理 163（声明集单调降级）**
对任意健康掩码 $H_t$（**即使错误**），若污染节点替换为满足 $A_n(\text{fallback})\subseteq A_n(\text{healthy})$ 的保守默认、健康节点保留其认证行为，则 $\mathrm{Exec}_{v23}(H_t)\subseteq \mathrm{Exec}_{v22}$。

*证明草图*：$\mathrm{Exec}_{v23}(H_t)=\bigcap_n A_n(m_n)$。对健康节点 $A_n(\text{healthy})\subseteq A_n(\text{healthy})$（等式）；对污染节点 $A_n(\text{fallback})\subseteq A_n(\text{healthy})$。逐项取交，交对子集单调，故整体 $\subseteq \bigcap_n A_n(\text{healthy})=\mathrm{Exec}_{v22}$。$\square$

> **重要限定**：引理只约束**声明集**相对**声明前提**。它不保证现实安全：若 $H_t(n)=\top$ 而节点前提（传感器值/标定/模型）已被未建模故障污染，则 $A_n(\text{healthy})$ 这张"已被污染的证书"仍被采用，其现实语义失效。这正是 §5 风险的形式化位置，也是"健康幻觉"的入口。

**定理 164（正确隔离下的活性支配）**
若 $\hat F_t$ 等于真实故障集且所有故障均落在签名矩阵张成空间内，则全局坍塌集严格劣于定向降级：$\mathrm{Exec}_{\mathrm{global}}\subseteq \mathrm{Exec}_{v23}(\hat F^{+}_t)\subseteq \mathrm{Exec}_{v22}$，且当且仅当故障污染了某证书节点的全部依赖时取等号。

*直观*：定向降级只把被污染子树替换为 fallback，未污染子树维持 v22 行为；全局坍塌把整图替换为 fallback。故前者是后者的松弛，活性保留量 $\mathrm{Act}_{\mathrm{directed}}-\mathrm{Act}_{\mathrm{global}}$ 等于未污染子树的可用许可量。

**命题 165（接触能量上界）**
在检测延迟 $d$ 内，最坏接触能量增量为 $E_{\mathrm{over}}\le \tfrac12 m v_{\mathrm{rel}}^2 + F_{\max}(r)\,d\,\bar v$。故只要 $\tfrac12 m v_{\mathrm{rel}}^2 + F_{\max}(r)\,d\,\bar v\le E_{\mathrm{budget}}$，CCx 可在延迟内保证能量不越界。

## 3. 实验设计（可证伪）

**E1 故障注入 × 定向降级**
- 注入矩阵：传感器偏置 / 卡死 / 漂移 / 间歇 / **共模标定篡改** / 对抗性欺骗；
- 对照：v22 全局回退 vs v23 定向降级；
- 指标：活性保留率、安全违反率、误诊率、**污染泄漏 $\delta_{\mathrm{cont}}$**（被采用的污染许可节点占比）、诊断延迟；
- 预注册：若 $\delta_{\mathrm{cont}}>0$ 且共模场景下无可检测信号，则"健康幻觉"被证实（见 §4 证伪线）。

**E2 接触包络标定**
- 力敏假人 + 六维力传感器；按区域标定 $F_{\max},p_{\max},P_{\max}$ 的 $1-\delta$ 分位；
- 扫描检测延迟 $d\in[1,50]$ms，测力超调与能量越界率，验证命题 165。

**E3 交互契约人因实验**
- 条件：无承诺 / 承诺可撤销 / 承诺不可撤销；
- 指标：人的可预测性评分、信任、撤销引发的惊跳/抢行率、任务完成时间、over-trust（对承诺的过度依赖）率；
- 预注册假设：可撤销 + 可读承诺降低抢行率，但若撤销过频则信任崩塌（找最优撤销频率）。

**E4 主动诊断**
- 在 E1 的歧义类上比较：被动诊断 vs 安全门控主动诊断；
- 指标：隔离精度、信息增益/能量/暴露比、探针导致的安全违反（必须为 0）。

## 4. 证伪线与预期结果

- **证伪线 F1**：若 E1 的共模场景中 $\delta_{\mathrm{cont}}>0$ 且在线监测未能把系统推回保守，则"健康-证据层"未实现其核心安全主张，应降级为纯性能优化模块。
- **证伪线 F2**：若 E2 的力超调在最大可接受延迟下仍超区域阈值，则 CCx 不成立，接触必须被完全禁止。
- **证伪线 F3**：若 E3 显示可撤销承诺的抢行率不降反升，则 ICx 的"可预测性"假设错误。
- **预期**：E1 定向降级在单点故障下活性保留 $\ge 70\%$ 且 $\delta_{\mathrm{cont}}=0$；共模下 $\delta_{\mathrm{cont}}>0$ 但监测器可在 $\le 200$ms 内翻转保守；E2 在 $d\le 20$ms 内满足包络；E3 最优撤销频率区间存在。

## 5. 本轮最大风险（产物层复述）

**一句话**：整套定向降级的安全性依赖"可诊断性假设"——残差模型能张成真实故障空间；一旦发生模型外的共模/对抗性失效，诊断器高置信地报告"健康"，系统便以**更少**的保守约束、**更高**的自信去执行一张事实上已被污染的证书，形成"健康幻觉"，它比"缺席幻觉"更难被审计发现。
