# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「模型蒸馏」×「视觉语言动作模型」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 把「场景→意图→约束→阻抗→执行→证据」串成闭环，但**场景类目与意图词典都是人工枚举的**：Z_scene 只有 10 类，I 只有 5 个词。这带来三个新局限：
> 1. **语义覆盖瓶颈**：真实开放世界的场景/意图是长尾的，手工枚举必然漏掉「半湿滑的橡胶垫」「被遮挡的充电口」「只说『再靠左一点』的含糊指令」；SSM 的 Kalman 先验只能在内定类目内插值，无法外推。
> 2. **语义-物理断层**：VLA 大模型具备开放世界语义，但推理慢（数百 ms）、动作物理不可靠（幻觉动作、抓空、过冲）；它「懂语义」却「不懂阻抗」。直接部署 VLA 会摧毁第 59 轮建立的实时执行契约与第 60 轮的场景先验。
> 3. **知识不可持续**：第 60 轮的场景先验一旦写死，执行证据 EV-exec 无法回流去修正「语义模型本身」——系统只会「适应」，不会「学习」。

## 0. 直觉与动机

**灵感 1（模型蒸馏 → 把语义蒸馏进安全参数空间 VID）**
直觉：蒸馏通常把大模型的动作 logits 灌给小模型；但机器人真正需要被继承的不是「动作」，而是**动作之前的阻抗/约束**。于是把 VLA 教师蒸馏到「场景后验 + 阻抗先验 + 意图约束」这个**语义-执行接口**上：学生网络在控制频率（≥200Hz）输出 π_S(K|z)、q_S(z|o)、q_S(I)，既保留开放世界语义，又直接落在 EEIS 可编译、ERTC 可锁定的参数空间。关键洞见：**蒸馏目标空间选在「安全参数」而非「动作」，学生天然可被证书约束。**

**灵感 2（VLA 幻觉 → 证据门控蒸馏 ECD）**
直觉：VLA 会「自信地说错」。但执行层有一个它没有的东西——**物理证据**。若某帧的教师标签对应的执行 EV-exec 通过了哈希/因果/证书校验，则该标签「可信」；若执行失败或证据缺失，则降低其蒸馏权重。即用证据可靠度 ρ(e) 门控：只让物理验证过的语义往下灌。关键洞见：**教师教语义，物理当监考。**

**灵感 3（反向蒸馏 → 物理反过来教语义 RKD）**
直觉：蒸馏不该单向。执行残差（实际 K_exec 与教师预测 K 的偏差、力跟踪误差）是「物理梯度」，可以经由低秩适配器（LoRA）反写回 VLA 教师：让教师逐渐学会「湿滑地面不要给高 K_p」「被遮挡的充电口要先试探」。关键洞见：**学生用证据反向蒸馏教师，形成「语义↓、物理↑」的双向知识流。**

**灵感 4（主动蒸馏 → 场景漂移驱动查询 ASD）**
直觉：VLA 推理昂贵，不能每帧都问。用第 60 轮 SSM 的场景漂移检测 κ_scene 与学生新颖度 ν(o) 决定「何时问教师」：只在学生不确定或场景新颖时查询，且按信息增益选样本。关键洞见：**把教师查询当作稀缺预算，用场景漂移做触发器，用信息增益做采集函数。**

**灵感 5（合流 → 证据门控的双向蒸馏闭环 VECL + 蒸馏证书 DCC）**
直觉：学生每步输出都要带一张「蒸馏一致性证书」DCC（师生 KL 偏差、阻抗分布偏差、保形覆盖率、EEIS 安全域），并入 J_exec。任一超界即回退慢路径（教师）或保守域。这样「蒸馏」从性能技巧变成**可审计的安全机制**：语义层证书 × 物理层证书双层校验。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（VLA 语义-动作教师 VST）** 教师 T = (E_v, E_l, H_s, H_I, H_K, D_a, U_T)。其中：
- **视觉/语言编码器**：E_v: O→R^{d_v}，E_l: L→R^{d_l}；
- **语义头**：H_s: (h_v,h_l)→q_T(z|o,l)∈Δ^{N_scene}，H_I→q_T(I|o,l)∈Δ^{N_intent}，H_K→π_T(K|z)=N(μ_T(z),Σ_T(z))；
- **动作头**：D_a: (h_v,h_l,s_t)→π_T(a_{t:t+H}|o,l)（标准 VLA 动作块，仅作辅助输出）；
- **不确定度场**：U_T(o,l) = (H(q_T(z)), tr Σ_T, H(q_T(I)))；
- **时序**：查询时延 τ_T ~ O(10² ms) ≫ 控制周期 T_c，教师只以**异步、缓存、批处理**方式被调用；
- 教师提供**软标签分布**而非硬动作，故学生可学习「语义不确定性」。

**定义 162（语义-阻抗学生 SIS）** 学生 S_θ = (g_φ, H^S_z, H^S_K, H^S_I)，参数预算 |θ| ≤ B_SC。其中：
- 场景头：q_S(z|o) = softmax(H^S_z(g_φ(o)))；
- 阻抗先验头：π_S(K|z) = N(μ_S(z), Σ_S(z))，K∈R^{K_dim}（刚度/阻尼/力限）；
- 意图头：q_S(I|o) = softmax(H^S_I(g_φ(o)))；
- **控制周期内前向**：τ_S ≤ T_c（目标 ≤5ms），仅依赖本体感知 + 轻量视觉；
- 学生输出经 EEIS 编译为 K_safe，且**必须通过 DCC 校验**才允许下发。

**定义 163（证据门控蒸馏 ECD）** 给定带证据数据集 D = {(o,l,e)}，证据可靠度
```
ρ(e) = 1[hash_ok] · 1[causal_order_ok] · 1[cert_valid] · exp(-D⁺(e)/τ_D) ∈ [0,1]
```
蒸馏目标：
```
L_ECD(θ) = E_{(o,l,e)~D}[ ρ(e) · ( λ_z·KL(q_T(z|o,l) ‖ q_S(z|o))
                                   + λ_K·KL(π_T(K|z) ‖ π_S(K|z))
                                   + λ_I·KL(q_T(I|o,l) ‖ q_S(I|o)) ) ] + λ_r‖θ‖²
```
- **保形校准**：非一致性分数 s(o,l)=d(q_T,q_S)，阈值 q̂=Quantile_{1-α}({s_i})，预测集 C_α(o)={z: s(o,z)≤q̂}，在可交换性假设下 P(z_true∈C_α) ≥ 1-α；
- 关键：ρ(e)=0 的样本被**完全剔除**，防止 VLA 幻觉污染学生。

**定义 164（反向蒸馏 RKD / 物理梯度）** 物理残差 r(e)=K_exec(e)−μ_T(ẑ(e))，归一化损失
```
L_phys(ψ) = E_{(o,l,e)~D}[ ρ(e) · ‖r(e)‖²_{Σ_T^{-1}} ]
```
教师适配器 ψ（LoRA，秩 r≪d）仅在以下条件同时满足时更新：
(1) 认证证据数 ≥ n_min；(2) 场景漂移检测触发（κ_scene>θ_shift）；(3) B_RD 未耗尽。
更新 ψ←ψ−η∇_ψL_phys，教师主干冻结，保证可追溯与可回滚。

**定义 165（蒸馏预算 DPB / PCE+++++）** B_distill = (B_TQ, B_SC, B_CF, B_RD, B_exec)。其中：
- **B_TQ**：教师查询次数上限（最贵资源）；
- **B_SC**：学生参数/FLOPs 上限；
- **B_CF**：保形校准样本/计算上限；
- **B_RD**：反向蒸馏更新次数上限；
- **B_exec**：沿用第 60 轮执行预算。
```
voi_distill(π) = VOI_cog(π) − cost_distill(π) − cost_exec(π)
cost_distill = λ_TQ·Q(π) + λ_SC·FLOPs_S(π) + λ_CF·Calib(π) + λ_RD·Update(π)
```
耗尽策略：B_TQ 尽→student_only；B_SC 尽→pruned_student（丢意图头，回退规则 ϕ）；B_CF 尽→conservative_conformal（放大 α）；B_RD 尽→freeze_teacher；B_exec 尽→沿用第 60 轮降级。

**定义 166（蒸馏一致性证书 DCC）** DCC = (δ_z, δ_K, δ_I, cov, K_ok, J_exec)。其中：
- δ_z = KL(q_T(z)‖q_S(z))，δ_K = W₂(π_T(K), π_S(K))（2-Wasserstein），δ_I = KL(q_T(I)‖q_S(I))；
- cov 为保形覆盖率；K_ok = [K_S ∈ K_safe^EEIS]；J_exec 为第 59 轮执行证书；
- **有效性**：δ_z≤Δ_z ∧ δ_K≤Δ_K ∧ δ_I≤Δ_I ∧ cov≥1−α ∧ K_ok ∧ J_exec.valid；
- 无效→回退慢路径（异步教师）或保守域 K_conservative；
- DCC 作为「语义层」证书并入 J_exec，形成**双层证书**（语义一致性 + 物理合规性）。

**定义 167（场景漂移驱动的主动蒸馏 ASD）** 新颖度 ν(o)=−log max_z q_S(z|o)；漂移 κ_scene 来自第 60 轮 SSM。触发条件：ν(o)>θ_novel ∨ κ_scene>θ_shift。采集函数：
```
a(o) = H(q_S(·|o)) − E_{q_T}[H(q_S(·|o,label))] + λ_n·ν(o)     # 信息增益 + 新颖度
```
仅当 a(o)>θ_gain 且 B_TQ 未耗尽才查询教师；查询结果进入 D 供 ECD 使用。

**定义 168（VLA-执行协同蒸馏闭环 VECL）** 算子 VECL(M,o,l,δ_f^req)：
```
① SIS 前向 → (q_S(z), π_S(K), q_S(I))
② EEIS 编译 → K_safe（以 π_S 为场景先验）
③ DCC 校验；无效 → 保守回退 / 异步教师慢路径
④ ERTC 锁定 ϕ_S(q_S(I))
⑤ 执行 → EV-exec（含哈希/因果/证书）
⑥ 证据门控 ρ(e) → ECD 更新学生
⑦ 漂移/新颖 → ASD 查询教师 → 扩充 D
⑧ RKD 更新教师 LoRA 适配器
⑨ DPB 更新；返回 (K_safe, EV-exec, DCC)
```

## 2. 关键算法伪代码

### IP-161 VST（VLA 语义-动作教师）

```python
class VLATeacher:
    def __init__(self, vlm, action_head, cache_size=256):
        self.E_v, self.E_l = vlm.vision_encoder, vlm.lang_encoder
        self.H_s, self.H_I, self.H_K = vlm.scene_head, vlm.intent_head, vlm.imp_head
        self.D_a = action_head
        self.cache = LRUCache(cache_size)

    @torch.no_grad()
    def query(self, obs, lang):
        key = (obs.frame_id, lang)
        if key in self.cache:
            return self.cache[key]
        h_v, h_l = self.E_v(obs), self.E_l(lang)
        q_z = softmax(self.H_s(h_v, h_l), dim=-1)
        q_I = softmax(self.H_I(h_v, h_l), dim=-1)
        mu, Sigma = self.H_K(h_v, h_l)
        a_chunk = self.D_a(h_v, h_l, obs.state)
        label = TeacherLabel(
            q_z=q_z, q_I=q_I, pi_K=(mu, Sigma), a_chunk=a_chunk,
            unc=(entropy(q_z), trace(Sigma), entropy(q_I)))
        self.cache[key] = label
        return label
```

### IP-162 SIS（语义-阻抗学生）

```python
class SemanticImpedanceStudent(nn.Module):
    def __init__(self, in_dim, n_scenes, n_intents, K_dim=6):
        self.enc = nn.Sequential(nn.Linear(in_dim, 256), nn.GELU(),
                                 nn.Linear(256, 128), nn.GELU())
        self.H_z = nn.Linear(128, n_scenes)
        self.H_K = nn.Linear(128, 2 * K_dim)     # mu, log_var
        self.H_I = nn.Linear(128, n_intents)

    def forward(self, obs):
        h = self.enc(obs)
        q_z = softmax(self.H_z(h), dim=-1)
        mu, log_var = self.H_K(h).chunk(2, dim=-1)
        q_I = softmax(self.H_I(h), dim=-1)
        return q_z, (mu, exp(log_var)), q_I

    @torch.no_grad()
    def act(self, obs, ertc, eeis):
        q_z, pi_K, q_I = self.forward(obs)
        K_safe = eeis.compile_with_prior(pi_K, ertc.delta_f_req)
        return q_z, K_safe, q_I
```

### IP-163 ECD（证据门控蒸馏 + 保形校准）

```python
def evidence_gate(ev, tau_D=10.0):
    rho = 1.0
    rho *= float(ev.hash_ok and ev.causal_order_ok and ev.cert_valid)
    rho *= math.exp(-max(0.0, ev.D_plus) / tau_D)
    return rho

def ecd_loss(student, batch, teacher):
    total = 0.0
    for (obs, lang, ev) in batch:
        rho = evidence_gate(ev)
        if rho < RHO_MIN:          # 物理未验证的标签直接丢弃
            continue
        qT_z, qT_I, (muT, ST) = teacher.query(obs, lang).semantic()
        qS_z, (muS, SS), qS_I = student(obs)
        total += rho * (
            LAMBDA_Z * kl(qT_z, qS_z) +
            LAMBDA_K * gaussian_kl(muT, ST, muS, SS) +
            LAMBDA_I * kl(qT_I, qS_I))
    return total / max(1, len(batch))

def conformal_calibrate(student, calib_set, teacher, alpha=0.05):
    scores = [nonconformity(student(o), teacher.query(o, l))
              for (o, l, _) in calib_set]
    qhat = np.quantile(scores, 1 - alpha, method="higher")
    return ConformalSet(qhat=qhat, alpha=alpha)
```

### IP-164 RKD（反向蒸馏 / 物理梯度）

```python
def reverse_distill(teacher, student, evidence_buffer, budget, drift):
    if len(evidence_buffer) < N_MIN or not drift.triggered():
        return False
    if budget.used["RD"] >= budget.B_RD:
        return False
    for (obs, lang, ev) in evidence_buffer.sample(B_RD):
        rho = evidence_gate(ev)
        if rho < RHO_MIN:
            continue
        mu_T, Sigma_T = teacher.predict_impedance(obs, lang)
        residual = ev.K_exec_actual - mu_T
        loss = rho * ((residual ** 2) / (Sigma_T.diag() + 1e-6)).mean()
        loss.backward()
        teacher.adapter_optimizer.step()   # 只更新 LoRA 参数
        teacher.adapter_optimizer.zero_grad()
    budget.used["RD"] += 1
    return True
```

### IP-165 DPB（蒸馏预算）

```python
class DistillationBudget:
    def __init__(self, B_TQ=1000, B_SC=1e8, B_CF=500, B_RD=20, B_exec=None):
        self.B_TQ, self.B_SC, self.B_CF, self.B_RD = B_TQ, B_SC, B_CF, B_RD
        self.B_exec = B_exec or ExecBudget()
        self.used = dict(TQ=0, SC=0, CF=0, RD=0)

    def mode(self):
        if self.used["TQ"] >= self.B_TQ: return "student_only"
        if self.used["SC"] >= self.B_SC: return "pruned_student"
        if self.used["CF"] >= self.B_CF: return "conservative_conformal"
        if self.used["RD"] >= self.B_RD: return "freeze_teacher"
        return "normal"
```

### IP-166 DCC（蒸馏一致性证书）

```python
def build_dcc(student_out, teacher_out, conf_set, K_safe, exec_cert):
    dcc = DCC(
        delta_z=kl(teacher_out.q_z, student_out.q_z),
        delta_K=wasserstein2(teacher_out.pi_K, student_out.pi_K),
        delta_I=kl(teacher_out.q_I, student_out.q_I),
        coverage=conf_set.coverage,
        K_ok=K_safe.contains(student_out.K),
        exec_cert=exec_cert)
    dcc.valid = (dcc.delta_z <= DZ_MAX and dcc.delta_K <= DK_MAX
                 and dcc.delta_I <= DI_MAX and dcc.coverage >= 1 - ALPHA
                 and dcc.K_ok and exec_cert.valid)
    return dcc
```

### IP-167 ASD（场景漂移驱动的主动蒸馏）

```python
def active_distillation_step(student, teacher, obs, budget, drift):
    qS_z, _, _ = student(obs)
    novelty = -math.log(max(qS_z.max().item(), 1e-9))
    if novelty < THETA_NOVEL and not drift.triggered():
        return None
    if budget.used["TQ"] >= budget.B_TQ:
        return None
    label = teacher.query(obs, obs.lang)
    gain = entropy(qS_z) - expected_entropy_after(qS_z, label.q_z)
    if gain + LAMBDA_N * novelty < THETA_GAIN:
        return None
    budget.used["TQ"] += 1
    return label
```

### IP-168 VECL（VLA-执行协同蒸馏闭环）

```python
def vla_execution_collaborative_loop(M, obs, lang, delta_f_req):
    student = M.student
    q_z, pi_K, q_I = student.forward(obs)

    K_safe = M.eeis.compile_with_prior(pi_K, delta_f_req)
    dcc = build_dcc(student_out=student_out(q_z, pi_K, q_I),
                    teacher_out=M.last_teacher_label,
                    conf_set=M.conformal, K_safe=K_safe,
                    exec_cert=M.last_exec_cert)
    if not dcc.valid:                       # 语义不可信 → 物理兜底
        K_safe = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.Z_env)
        return conservative_dispatch(M, K_safe)

    M.ertc.lock_constraints(phi_S(q_I))
    dispatch_impedance_params(K_safe.best, dcc)

    ev = execute_and_build_evidence(M, K_safe)
    if evidence_gate(ev) >= RHO_MIN:
        M.student = ecd_update(M.student, (obs, lang, ev))
        reverse_distill(M.teacher, M.student, M.evidence_buffer, M.dpb, M.drift)

    label = active_distillation_step(M.student, M.teacher, obs, M.dpb, M.drift)
    if label is not None:
        M.student = ecd_update(M.student, (obs, lang, ev), teacher_label=label)

    M.dpb.used["SC"] += student.flops()
    return M, K_safe, ev, dcc
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VST | O(τ_T) 异步/缓存 | O(|T|) | 软标签误差 ≤ ε_T |
| SIS | O(1)/控制周期（≤5ms） | O(|θ_S|) | 师生偏差 δ_z/δ_K/δ_I ≤ Δ |
| ECD | O(B·|θ_S|)/minibatch | O(B) | 门控假接受率 ≤ ε_ρ；保形覆盖 ≥ 1−α |
| RKD | O(B·r·d) 摊销 | O(r·d) | 认证样本上物理残差单调不增 |
| ASD | O(1) 触发 + O(τ_T) 查询 | O(|D|) | 查询量下降而场景覆盖不降 |
| DCC | O(1) | O(1) | 双层证书有效性 |
| VECL | O(闭环) | 复用 | K_S ∈ K_safe 恒成立 |

**正确性定理（VEDG：VLA-Execution Distillation Guarantee）**：
假设 A66–A70 成立；**(A66)** 教师软标签对真实语义分布误差 ≤ ε_T（KL）；**(A67)** 证据门控 ρ 的假接受率 ≤ ε_ρ；**(A68)** 保形校准在场景分层内可交换，覆盖率 ≥ 1−α；**(A69)** 学生容量足够，近似误差 ≤ ε_S；**(A70)** B_distill 单调消耗，任一耗尽即触发对应降级。
则：
1. **语义一致性**：学生语义误差 ≤ ε_T+ε_S+q̂（保形半径）；当 DCC 有效时 δ_z≤Δ_z、δ_K≤Δ_K、δ_I≤Δ_I。
2. **幻觉污染上界**：被错误蒸馏的样本比例 ≤ ε_ρ，故学生不会系统性继承 VLA 幻觉。
3. **反向接地性**：RKD 在认证证据上使 E[‖r‖²_{Σ⁻¹}] 单调不增，教师获得物理接地而不遗忘语义（LoRA 低秩约束）。
4. **预算安全性**：任一 B_distill 耗尽触发对应策略，不破坏执行实时性。
5. **安全支配性**：DCC 无效即回退，EEIS 硬约束始终优先，故 K_S ∈ K_safe。

```python
        h = self.enc(obs)
        q_z = softmax(self.H_z(h), -1)
```

### IP-163 ECD（门控 + 保形）

```python
def evidence_gate(ev, tau_D=10.0):
    return (float(ev.hash_ok and ev.causal_order_ok and ev.cert_valid)
            * math.exp(-max(0.0, ev.D_plus) / tau_D))

def ecd_loss(student, batch, teacher):
    total = 0.0
    for (obs, lang, ev) in batch:
        rho = evidence_gate(ev)
        if rho < RHO_MIN: continue
        qT_z, qT_I, (muT, ST) = teacher.query(obs, lang).semantic()
        qS_z, (muS, SS), qS_I = student(obs)
        total += rho * (LAMBDA_Z * kl(qT_z, qS_z)
                        + LAMBDA_K * gaussian_kl(muT, ST, muS, SS)
                        + LAMBDA_I * kl(qT_I, qS_I))
    return total / max(1, len(batch))

def conformal_calibrate(student, calib, teacher, alpha=0.05):
    scores = [nonconformity(student(o), teacher.query(o, l)) for o, l, _ in calib]
    return ConformalSet(np.quantile(scores, 1 - alpha, method="higher"), alpha)
```

```python
def reverse_distill(teacher, student, buf, budget, drift):
    if len(buf) < N_MIN or not drift.triggered() or budget.used["RD"] >= budget.B_RD:
        return False
    for (obs, lang, ev) in buf.sample(B_RD):

        if rho < RHO_MIN: continue
        mu_T, Sigma_T = teacher.predict_impedance(obs, lang)
        loss = rho * (((ev.K_exec_actual - mu_T) ** 2) / (Sigma_T.diag() + 1e-6)).mean()
        loss.backward(); teacher.adapter_optimizer.step(); teacher.adapter_optimizer.zero_grad()

    return True
```

```python
def active_distillation_step(student, teacher, obs, budget, drift):
    qS_z, _, _ = student(obs)
    novelty = -math.log(max(qS_z.max().item(), 1e-9))
    if novelty < THETA_NOVEL and not drift.triggered(): return None
    if budget.used["TQ"] >= budget.B_TQ: return None
    label = teacher.query(obs, obs.lang)
    gain = entropy(qS_z) - expected_entropy_after(qS_z, label.q_z)
    if gain + LAMBDA_N * novelty < THETA_GAIN: return None
    budget.used["TQ"] += 1
    return label
```
