# 第 4 轮（灵感循环第 4 轮；本轮灵感：「物体泛化」×「产学研合作」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。两个新灵感各沿一条轴升级 InstructGauge；跨物体迁移与跨机构共享均为**可选增强**，任一环节不可用都必须能一键退回 InstructGauge → ToolGauge → LeanGauge → MODGAUGE。

## 0. 直觉与动机

**灵感 1（物体泛化 → 契约必须分解成「不变量 + 物体特异残差」）**
直觉：老师傅换一个杯子仍知道「先低角度掠射、反光过曝就上偏振」，但他不会把上一个杯子的具体增益值照搬。物体泛化的关键不是「一个契约打天下」，而是把契约拆成两层：**跨物体不变的那部分物理规律**（可迁移、可复用）与**只属于当前物体的残差**（必须本地测量）。如果强行整份契约迁移，已知物体上的共形覆盖会在新物体上悄悄失效——因为**物体替换破坏了校准集的可交换性**，这与第 3 轮「指令条件化破坏可交换性」是同一类病，只是这次的协变量是物体本身。所以正确接口是 `EC = (EC_inv, EC_res(o))`：只有 `EC_inv` 允许跨物体，`EC_res` 永远本地化；并用**物体签名距离 + 不变性检验**作为迁移准入，而不是用「看起来差不多」。

**灵感 2（产学研合作 → 多站点证据，但许可与激励会污染证据）**
直觉：产学研合作表面是「多搞点数据」，实质是**跨信任边界共享证据**：高校擅长表征新物体族（探索），企业握有产线大量已知物体回执（利用），双方各出一半才凑得出泛化。但有两个非技术约束必须上升为一等公民：其一，**IP / 数据许可**——一条回执能不能被用于派生契约、能派生出什么、何时失效，都是类型问题，不是合规附录；其二，**激励导致的选择性报告**——只报成功案例会让校准集不再代表总体，共形覆盖保证会以「看起来更好」的方式失效。因此本轮把「许可闭包」与「预注册 + 负结果账本」当作与能力闭包同级的结构约束，而不是事后审计。

**灵感 3（两者耦合 → 双漂移 + 复用放大，必须被「跨站点证伪」截断）**
直觉：物体泛化失败本身只是局部错误；一旦它被做成「共享不变量」并由多个机构复用，就会变成**多站点系统性偏差**——一个错误的不变量被 S 个站点同时采纳，损失随复用规模放大。这与第 3 轮「一个坏块原子性执行 K 步」同构：错误被**复用**放大，而不是被单点放大。解法同样不是禁用共享，而是引入**证伪否决点**：任一站点的本地回执都足以证伪共享不变量，触发**单调吊销**；同时用「探索/利用角色分离 + 交接门」确保探索性结论不会未经复现就直接进产线。核心结构支柱因此是四根：**不变量分解**、**迁移守卫**、**许可闭包**、**跨站点单调吊销**，再叠加 **site×object 双层共形**与**预注册负结果账本**。

## 1. 研究问题（本轮要回答什么）

- **Q1（可迁移性）**：什么样的契约成分可以跨物体迁移？能否把新物体上的风险显式分解成「不变性风险 + 残差 + 签名距离」，并给出可证伪的界？
- **Q2（证据合法性）**：跨机构共享的回执/契约，如何在类型层面保证「只用被许可的字段、只做被许可的派生」，同时不让许可约束退化成人工合规？
- **Q3（复用放大）**：当错误的不变量被多站点复用，损失如何随站点数放大？单调吊销 + 预注册能否把放大从「随复用规模线性/超线性」压回「随吊销延迟有界」？

## 2. 设计原则（雏形，正式化见产物区定义 448–464）

**P4 不变量分解（Invariant Factorization）**
任何泛化契约写成 `EC = (EC_inv, EC_res(o))`：`EC_inv` 必须通过变换群 `G_obj` 下的不变性检验并附 `InvarCert`；`EC_res(o)` 逐物体本地校准。迁移只搬运 `EC_inv`，残差绝不跨物体复制。直观：可迁移的是**规律**，不是**标定值**。

**P5 迁移守卫（Transfer Guard）**
迁移准入三条件：物体签名距离 `d_σ(σ(o), F) ≤ δ_F`、不变性风险 `r_inv ≤ η_inv`、本地样本 `n_local ≥ n_min`。任一不满足 ⇒ 拒绝迁移、退回单物体校准；单物体样本仍不足 ⇒ 退回 InstructGauge/ToolGauge 冻结契约。拒绝迁移不是失败，是**负迁移保险**。

**P6 许可闭包（License Closure）**
每条证据携带许可 `ℒ = (fields, uses, derivatives, expiry, jurisdiction)`；派生主张只能引用「允许派生」的字段，且必须沿来源链回指。类比能力闭包：**证据不能扩权**。许可不满足 ⇒ 该证据降级为不可用于校准的纯解释，绝不进数值路径。

**P7 双层联邦共形（Federated Stratified Conformal）**
按 `(site, object-family)` 双层分层校准，而不是把各站点数据一锅端。跨站点共享只共享**充分统计量 / 分位信息**（必要时加 DP 噪声），并在站点漂移或物体漂移超界时回退全局阈值。低样本 joint stratum ⇒ 回退 site 层 ⇒ 回退全局（优雅降级）。

## 3. 与基线的接口（如何退化）

- 不变量检验失败 / 签名距离超界 / 本地样本不足 ⇒ 不迁移，退回单物体校准；仍不足 ⇒ InstructGauge 冻结契约（K=1、默认目标 ι₀）。
- 许可不兼容 / 来源链断裂 ⇒ 证据降级为纯解释，校准只用本地合法证据 ⇒ 等价 InstructGauge 本地校准。
- 联邦聚合不可用 / DP 预算耗尽 / joint stratum 样本不足 ⇒ 回退单站点共形 ⇒ 回退全局共形（InstructGauge / ToolGauge）。
- 吊销总线不可用 ⇒ 关闭跨机构复用（只用本地新证），等价于「不泛化」的 InstructGauge；因此吊销是共享的**前置条件**而非附加项。
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**不变量分解 + 迁移守卫**的泛化口径，把「换物体」从整契约照搬降级为「可控部分迁移」，并给出风险-距离的线性界；
2. 一个**许可闭包类型系统**，把 IP/数据许可从事后合规提升为类型级约束，使跨机构证据共享不产生越权派生；
3. 一个**跨站点证伪 + 单调吊销**机制，把「错误不变量被多站点复用」的放大从复用规模解耦到吊销延迟；
4. 一个 **site×object 双层共形 + 预注册负结果账本**，同时处理双漂移与选择性报告偏差；
5. 一条完整可证伪路径：E457–E472 覆盖签名泛化、分解消融、迁移守卫、双层覆盖、隐私三角、许可泄漏、吊销延迟、交接门、探索-利用与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：一个错误却「通过了不变性检验」的共享不变量，会被产学研多方复用成跨站点系统性偏差；而激励驱动的选择性报告与模糊的数据许可恰好会污染校准集、让覆盖保证在「看起来更泛化」时失效——因此真正的残余风险在**共享证据的合法性与代表性**，而不在单个物体的迁移误差。

## 2. 形式化定义（要点）

**定义 448（物体签名与物体族）** `σ: O → Σ_obj`，`σ(o) = (geom, material, reflectance, scale, topology)`（归一化嵌入）。物体族 `F ⊆ Σ_obj` 为注册表中由 `InvarCert` 覆盖的签名集合；`d_σ(a,F) = min_{b∈F} ‖a−b‖_Σ`。签名注册器同时输出 `u(o)` 表示签名不确定性；`d_σ` 在 `u(o)` 超界时不可用于准入（保守拒迁）。

**定义 449（不变量分解契约）** `EC(o) = (EC_inv, EC_res(o), InvarCert, GenCert)`：`EC_inv` 为跨物体共享的规律（视角/偏振/曝光策略、物理先验、约束形状）；`EC_res(o)` 为物体特异残差（增益、阈值、偏移）。执行时先应用 `EC_inv` 再叠加 `EC_res(o)`；**只有 `EC_inv` 可跨物体/跨机构传播，`EC_res` 带物体主键，禁止解引用其它物体**。

**定义 450（不变性证书 InvarCert）** `InvarCert(EC_inv; G_obj, F) = ({T_g(EC_inv) ≈ EC_inv}_{g∈G_obj}, r_inv, ρ)`：在变换群 `G_obj`（旋转/缩放/平移/材质替换）下检验 `EC_inv` 的不变性，`r_inv` 为最大不变性偏差，`ρ = sup_o ‖EC_res(o)‖`。检验必须在**留出物体**上做，不得复用校准物体（防泄漏过拟合）。

**定义 451（迁移守卫 TransferGuard）** 对目标物体 `o` 与最近族 `F`：
`Admit(o,F) ⇔ d_σ(σ(o),F) ≤ δ_F ∧ r_inv ≤ η_inv ∧ n_local(o) ≥ n_min ∧ u(o) ≤ u_max`。
准入 ⇒ 仅加载 `EC_inv` 并用本地样本拟合 `EC_res(o)`；否则**拒迁**，执行 `FitLocal(o)`（纯本地校准）；`n_local < n_min` ⇒ 冻结契约、退回 InstructGauge 逐步探测。拒绝记录进 `GenCert.guard_margin`，供审计与主动学习。

**定义 452（site×object 双层分层）** `s = (s_site, s_obj)`，`s_site ∈ Sites`，`s_obj = family(o)`。联合层 `C_cal^{s}` 记录来自站点 `s_site`、物体族 `s_obj` 的校准回执。**不同站点、不同物体族的回执不得直接合并**，只能按定义 453 加权。

**定义 453（联邦双层共形 FS-Cal）** 设各站点按 `w_s ≥ 0, Σ_s w_s = 1` 加权，层内分数 `E_s` 以权重 `w_s` 做加权共形分位
`q = inf{ t : Σ_s w_s · (1/|E_s|) Σ_{e∈E_s} 1[score(e) ≤ t] ≥ 1−α }`。
共享的是**分数分位/直方图**（或加噪后的充分统计量），不共享原始回执。样本不足的 joint 层回退 `s_site` 层，再回退全局。

**定义 454（隐私预算与 DP 共形）** 联邦聚合满足 `(ε_dp, δ_dp)`-DP；对分数加噪 `σ_dp ∝ Δ_score/ε_dp`。DP 分位相对非私有分位的膨胀记 `Δq_dp`。`ε_dp` 是**预算资源**：探索新物体族消耗预算，预算耗尽后只能本地校准（优雅退化），不得靠无限加噪「假装覆盖」。

**定义 455（许可闭包 LCL）** 每条证据 `e` 携带 `ℒ_e = (fields, uses, derivatives, expiry, jurisdiction)`。派生主张 `c` 合法当且仅当 `fields(c) ⊆ fields(e)`、`use(c) ∈ uses(e)`、`deriv(c) ⊆ derivatives(e)`、在 `expiry` 前、且 `c ⟶ e` 沿 `Ledger` 可回指。任一违反 ⇒ `c` 被**剥离为纯解释**（沿用定义 441 的剥离投影）。

**定义 456（来源链账本）** `Ledger` 为仅追加哈希链；每条记录 `(e_id, site, time, ℒ_e, h_prev)`。`ProvCert(e)` 给出从证据到根的可验证路径。账本只保证**来源可追溯与不可篡改**；许可语义由定义 455 负责，两者分离。

**定义 457（跨站点证伪与单调吊销）** 任一站点在本地回执上发现 `EC_inv` 违反其不变性/漂移界，可签发 `RevokeCert(EC_inv, site, receipt_id, counterexample)`。吊销语义单调：`I_active ← I_active \ {EC_inv}`，重认证前不得重新加入；吊销总线不可用时，禁止跨机构复用（只允许本地新证）。`τ_rev` 为从首次可检测反例到全局生效的延迟。

**定义 458（角色协议 RoleProtocol）** `RoleProtocol = (A, I, cost_safe, cost_info)`：学术节点 `A` 负责探索新物体族（允许更高信息增益权重、必须在隔离/安全笼内、不得直接进产线）；工业节点 `I` 负责利用已知族（更紧的安全屏障、更短块长）。两者共享 `EC_inv` 与分位统计，不共享原始数据。

**定义 459（交接门 HandoffGate）** lab→production 晋级需同时满足：独立复现次数 `r ≥ r0`、效应量 `≥ Δ0`、跨站点漂移余量 `≥ margin`、许可兼容（`derivatives` 允许生产用途且未过期）。任一不满足 ⇒ 留在探索区并记负结果。

**定义 460（双漂移分解与复用放大）** `Δ_total ≤ Δ_obj + Δ_site + Δ_int`（交互项）。若共享不变量在站点间被复用，设站点采纳率 `λ`、吊销延迟 `τ_rev`，则复用放大 `A_S ≤ 1 + S(1 − e^{−λ τ_rev})`：放大由**吊销延迟**与**采纳速度**决定，而非单纯站点数 `S`。

**定义 461（泛化证书 GenCert）** `GenCert(o) = (InvarCert, neighbors_F, cov_local, guard_margin, ℒ_set, revocation_status)`：让审计可判断「这条泛化结论基于哪些物体族、本地覆盖多少、离边界多远、用了哪些许可、当前是否被吊销」。

**定义 462（选择性报告校正）** `PreReg` 预先登记校准/检验协议与分层；`NegLedger` 强制记录负结果与拒迁案例。设 `β_sel = TV(选择性样本, 目标总体)`，则覆盖下界修正为 `1−α−β_sel`。`β_sel` 由登记完整率与负结果上报率估计；未登记层一律不用于对外覆盖声明。

**定义 463（探索-利用预算分配）** 探索比例 `λ ∈ [0,1]`，探索边际信息增益 `g_e(λ)`（递减），单次探索安全代价 `cost_safe`，利用边际价值 `v`。目标 `U(λ) = λ g_e(λ) + (1−λ) v − λ cost_safe`；一阶条件 `g_e(λ*) + λ* g_e'(λ*) = v + cost_safe`。安全代价上升 ⇒ 最优探索比例下降（与直觉一致，可证伪）。

**定义 464（CoGauge 修复证书）** `RepairCert″(s) = RepairCert′(s) ∪ (GenCert(o), ℒ_set, ProvCert, revocation_status)`，把「指令→块→回执→主张」扩展到「物体签名→不变量→许可→来源→吊销」的八级证据链。

class SignatureRegistry:
    def describe(self, obj):
        sig = self.encoder(obj)                       # (geom, material, refl, scale, topo)

class InvariantFactorizer:
    def factor(self, contract, families, holdout_objs):

        inv = prune_noninvariant(inv, holdout_objs)            # 只用留出物体

class TransferGuard:
    def admit(self, osig, ec, n_local):

class FederatedSCal:
    def quantile(self, s_site, s_obj, cal, alpha):

            scores = cal.get(key, [])
            if len(scores) >= N_MIN:

# IP-332 LCL：许可闭包（类型检查，失败即剥离）
def license_closed(claim, evidence, ledger, now):
    L = evidence.license
    if not set(claim.fields) <= set(L.fields):            return False
    if claim.use not in L.uses:                            return False
    if not set(claim.derivatives) <= set(L.derivatives):   return False
    if now > L.expiry:                                     return False
    if not ledger.has_path(claim.id, evidence.id):         return False
    return True

def bind_claims_licensed(claims, evidence, ledger):
    return [Claim(c, ev) for c, ev in claims
            if license_closed(c, ev, ledger, NOW)]          # 违规直接剥离为纯解释

# IP-333 RVK：跨站点证伪 → 单调吊销
class RevocationBus:
    def report(self, counterexample):
        cert = RevokeCert(counterexample.inv_id, counterexample.site,
                          counterexample.receipt_id, counterexample.witness)
        self.ledger.append(cert)                            # append-only
        self.active_invariants.discard(counterexample.inv_id)  # 单调，不可复活
        return cert

    def usable(self, inv_id):
        return inv_id in self.active_invariants and self.bus_healthy

def handoff_gate(candidate, replications, license_set):
    return (len(replications) >= R0
            and effect_size(replications) >= DELTA0
            and drift_margin(candidate) >= MARGIN
            and license_compatible(license_set, PRODUCTION_USE))

    ec_res = fit_residual(ec.inv, cert.receipts)

        cert  = strip_unlicensed(cert)                      # 纯投影，不改数值

## 4. 推导

**引理 59（不变量分解的迁移界）** 设 `EC_inv` 在族 `F` 上的不变性风险为 `r_inv`、残差上界 `ρ`，新物体到族距离 `d = d_σ(σ(o),F)`，损失对残差与距离分别 `L_ρ`-、`L_σ`-Lipschitz。则在物体 `o` 上的期望损失
`R(o) ≤ r_inv + L_ρ·ρ + L_σ·d + O(d²)`。
即「迁移代价 = 不变性缺口 + 残差 + 距离」三项可加。*证明骨架*：把 `EC(o)` 写为 `EC_inv` 与 `EC_res(o)` 的复合，插入中间点 `EC_res(F)`，用三角不等式拆成 `‖EC_res(o)−EC_res(F)‖ ≤ ρ` 与 `‖EC_res(F) 处的规律 − EC_inv‖ ≤ r_inv`，距离项由 Lipschitz 与 `d_σ` 给出。E457/E458 检验。

**引理 60（迁移守卫的严格退化）** 若 `TransferGuard` 拒迁，则 `FitLocal(o)` 只用物体 `o` 的本地回执，契约与 InstructGauge 的单物体校准逐指令等价；若 `n_local < n_min`，则冻结契约并执行 InstructGauge 逐步探测。故守卫的引入**不会使任何无法本地校准的物体获得更差的安全性**。*证明*：拒迁分支不读取任何跨物体量（`EC_res` 带物体主键、`EC_inv` 不加载），执行路径退化为单物体校准；样本不足分支直接调用 `InstructGauge_7C`，由引理 57 回到 ToolGauge。E459/E466 检验。

**引理 61（联邦双层共形覆盖）** 在层内加权可交换下，
`P(h* ∈ H | s) ≥ 1−α − Σ_s w_s·TV_s`，
且未分层校准的 TV 可分解为 `TV ≤ TV_site + TV_obj`：单层全局校准同时承担站点漂移与物体漂移，双层校准把两项分别归入各自的层，只有交互项 `TV_int` 残留在联合层。低样本 joint 层回退 `s_site` 层 ⇒ 覆盖按 `−TV_obj` 优雅降级，再回退全局 ⇒ 再按 `−TV_site` 降级。*证明*：加权共形在加权可交换性下的标准覆盖界；TV 的次可加性给出分解。E460/E461 检验。

**引理 62（隐私-覆盖-泛化三角）** 对非一致性分数加尺度 `σ_dp` 的 DP 噪声，分位膨胀
`Δq_dp = O(σ_dp √(log(1/β)/n))`。
要把覆盖损失压在 `γ` 内，需每层样本 `n ≳ 2σ_dp² log(1/β)/γ²`。故 `(ε_dp 小, 1−α 高, n 小)` 三者不可同时满足：跨机构共享要么牺牲隐私、要么牺牲覆盖、要么积累样本。*证明*：DP 噪声的集中不等式 + 分位函数的 Lipschitz 性。E463 检验。

**引理 63（许可闭包的类型安全）** 若每条证据携带 `ℒ_e` 且派生主张经 `license_closed` 检查，则任何进入数值路径的主张只能引用其证据许可允许的字段与派生；未授权字段泄漏概率在类型层为 0。*证明*：对派生树结构归纳。基础：主张直接引用证据，`fields ⊆ fields(e)`。归纳：派生只组合已通过检查的父主张，`derivatives` 沿传递闭包传递，`uses` 在每步单调收紧。违规分支按定义 455 剥离，不参与数值。E464 检验。

**引理 64（单调吊销与陈旧不变量寿命）** `RevokeCert` 仅追加、`I_active` 只在吊销时收缩、重认证前不扩张，故活跃不变量集在两次重认证之间单调不增；任一已证伪不变量被继续采纳的时长 `≤ τ_rev`。吊销总线不可用 ⇒ 关闭跨机构复用，寿命降为 0。*证明*：由 `RevocationBus.discard` 的单调性与 `usable` 的合取条件直接得到。E465 检验。

**引理 65（复用放大界）** 设站点采纳率为 `λ`、吊销延迟 `τ_rev`，共享不变量错误时的总损失
`D_agg ≤ c_w·[1 + S(1 − e^{−λ τ_rev})]`，
即放大因子 `A_S ≤ 1 + S(1−e^{−λτ_rev})`；当 `τ_rev → 0` 时 `A_S → 1`（退化为本地错误），当 `τ_rev → ∞` 时 `A_S → 1+S`（全站点污染）。因此**控制放大的是吊销延迟，不是站点数**。*证明*：把站点按是否在 `τ_rev` 内采纳分段，未及时采纳者不受影响；采纳者至多 `S`，每站损失上界 `c_w`。E465/E466 检验。

**引理 66（探索-利用最优比例）** 对定义 463 的 `U(λ)`，若 `g_e` 凹且递减，则 `λ*` 唯一，满足 `g_e(λ*) + λ* g_e'(λ*) = v + cost_safe`；`λ*` 随 `cost_safe` 与 `v` 递减、随 `g_e` 递增。*证明*：`U''<0` 由 `g_e` 凹给出；隐函数定理给出比较静态。E468 检验。

**引理 67（选择性报告偏差的覆盖修正）** 若校准集只含成功样本，其分布相对目标总体有偏，覆盖下界失去 `β_sel = TV(选择性, 目标)`；预注册 + 负结果账本使登记层内 `β_sel = 0`，未登记层不得对外声明覆盖。*证明*：共形覆盖界对分布失配的 TV 修正；`PreReg` 使选择机制在层内可忽略，`NegLedger` 补齐被截断的负结果。E469 检验。
