# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「抓取规划」×「服务设计」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」：SSM 场景-阻抗先验、CIEC 意图-约束锁定、EPIR 因果隔离、SERC 场景感知闭环、PCE++++ 四维认知预算、SIC 三元校验。但两个新灵感暴露出**三个结构性局限**：
> 1. **有阻抗、无抓取**：SGEC 的 K_safe 是在接触配置 G（接触点、接触法向、夹爪开合、接近方向）**已默认给定**的前提下编译的。抓取几何直接决定了力旋量空间 W(G) 与可实现的阻抗流形——侧抓薄壁杯与顶抓同一只杯，可安全调节的 K_p/K_d 范围差一个量级。G 与 K 解耦后，场景先验和意图锁定只能「在错误的接触几何上更快收敛到错误的安全域」，且 EEIS 无法回答「这个 K 到底能不能被这只手、这组接触点物理实现」。
> 2. **有执行、无服务**：SGEC 把一次失败等价为 `DEGRADE_EXEC`，但真实部署中机器人交付的不是「一次抓取」，而是**一项服务**（「把药放到桌上」「把杯子递给我」）。失败是**服务蓝图中的一个 fail point**；用户感知的质量（可靠性、响应性、可解释性、是否被尊重）与物理成功率并不等价，人也不是被动接收者，而是**服务的共同生产者（co-producer）**。缺少服务蓝图，就无法区分「物理成功但服务失败」（抓到了但太慢/太粗暴）与「物理失败但服务可接受」（没抓到但及时解释并安全停下）。
> 3. **有证据、无恢复**：EPIR 的证据链服务于「合规审计」，而不是「服务恢复」。它记录了「发生了什么」，却没有前置标注「哪里可能失败」、没有「失败后按什么顺序恢复」、也没有「恢复之后信任如何变化」。一次失败后只能整体降级，浪费了「服务恢复悖论」——被妥善解释与修复的失败，可能比一次平淡成功带来更高信任。

## 0. 直觉与动机

**灵感 1（抓取规划 → 接触-阻抗联合规划 GIKP）**
直觉：抓取不是「选一个能夹住的位姿」，而是「选一个让后续阻抗控制拥有足够安全裕度的接触几何」。同样是抓杯子：侧抓接触点少、力闭合弱、可实现的阻抗范围窄且对扰动敏感；顶抓接触面积大、可调 K_p/K_d 范围宽。若先按「抓取质量最高」选了侧抓，再在其上编译高刚度 K_safe，接触面稍有偏差就打滑。关键洞见：**把场景-阻抗先验 π_scene(K|z) 投影到每个候选抓取的「可实现阻抗流形」F_GK 上，用「最坏场景下的安全裕度」而不是单独的 grasp quality 来选抓取**——即抓取规划的目标函数中显式包含 K 的可实现性。

**灵感 2（服务设计 → 服务蓝图协议 SBP）**
直觉：服务设计把系统分成三层——**前台（frontstage，用户可见的动作与语言）**、**后台（backstage，场景识别、意图推断、抓取规划、阻抗编译）**、**支持过程（support，ROS 消息、算力、证据存储）**；三条线（line of interaction / visibility / internal interaction）分隔它们。每一次人机接触是**服务时刻（moment of truth）**，每一个可能出错的位置是 **fail point**。关键洞见：**把 SGEC 的 SIC 三元判据变成服务时刻上的「质量门」，把 fail point 前置标注到蓝图上，并为每个 fail point 预置恢复路径**——使系统从「执行闭环」升级为「服务闭环」。

**灵感 3（服务恢复 → 抓取服务恢复协议 GSRP）**
直觉：抓取失败不是终点，而是服务恢复的起点。恢复树按代价从低到高排列：`re-grasp`（换一个抓取 G）→ `re-compile`（在同一 G 上放松 K）→ `re-negotiate`（置信度不足时向用户追问意图）→ `degrade`（安全停止并显式告知）。**服务恢复悖论**：一次被及时解释、并成功恢复的失败，可能比一次无波折的成功更提升信任。关键洞见：**恢复必须同时作用于前台（解释/告知）与后台（G/K/意图），且恢复动作本身要计入预算**，否则恢复会退化为「反复重试直到预算耗尽」。

**灵感 4（三灵感合流 → 服务化抓取闭环 SGRC）**
直觉：把三条线索接成闭环——**场景→意图→抓取 G→阻抗 K→执行→服务证据 EV-svc→服务质量 Q→恢复/更新→场景**。其中 G 与 K 联合规划（GIKP），失败经恢复树（GSRP）处理，每次恢复都在服务蓝图（SBP）的 fail point 上留下证据，并更新信任（TTF）。关键洞见：**抓取规划的目标不只是「抓住」，而是「可持续地交付服务」**——因此优化目标是服务成功率与信任，而非单次抓取成功率。

**灵感 5（PCE+++++ → 五维服务预算）**
直觉：第 60 轮的四维认知预算 B_scene/B_intent/B_ros/B_exec 需要增加**服务预算 B_svc =（B_recover, B_explain, B_trust）**：恢复尝试次数、前台解释带宽、信任余额。若 B_recover 耗尽 ⇒ 不允许再重试，直接进入「最小可行服务」（解释 + 安全停止）；若 B_explain 耗尽 ⇒ 禁止无声恢复，必须先告知再动作；若 B_trust 低于阈值 ⇒ 主动降低自主级别并请求人类接管。关键洞见：**恢复是有成本的资源，不能被无限透支**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（抓取-阻抗联合规划 GIKP）** 抓取配置 G = (C, N, a, w, μ)，其中 C = {c₁, …, c_k} 为物体表面接触点集，N 为对应接触法向，a 为接近方向，w 为夹爪开合，μ 为接触摩擦系数。定义：
- **力旋量空间**：W(G) = cone({(c_i − p) × f_i + τ_i})，由各接触点可施加的力/力矩锥生成（p 为物体质心）。
- **阻抗可实现映射**：ρ(G, K) ∈ {0, 1}，当且仅当存在接触力分配 {f_i} 满足 f_i ∈ FC_i(μ)（摩擦锥）且 K·Δx ∈ W(G)（所需恢复力旋量在力闭合空间内）时 ρ = 1。
- **联合可行流形**：F_GK = {(G, K) | ρ(G, K) = 1, K ∈ K_safe^scene(z)}。
- **联合规划目标**：在场景先验 z 与意图约束 C_intent 下，
  `G* = argmax_G min_{z∈Z_scene, K∈F_GK(G,z)} margin(G, K; z)`，
  其中 margin(G, K; z) = 到摩擦锥/力矩上限/刚度上限的最短归一化距离 − λ_rec·RecoveryCost(G, z)。即：**选「最坏场景下仍留最大安全裕度、且恢复代价最低」的抓取，而不是抓取质量最高的抓取**。

**定义 162（服务蓝图协议 SBP）** 服务蓝图 β = (F_s, B_s, S_s, Φ, M, ℓ, σ)。其中：
- **前台** F_s：用户可观测的动作与语言（接近、抓取、递送、解释、致歉）。
- **后台** B_s = {SSM, CIEC, GIKP, EEIS, EPIR}。
- **支持过程** S_s = {ROS 消息层, 算力, 证据存储}。
- **fail point 集** Φ = {(φ_i, stage, severity, detect_signal)}，stage ∈ {F_s, B_s, S_s}。
- **服务时刻** M ⊆ F_s，为决定用户信任的关键接触点。
- **服务水平** ℓ = (success_rate, τ_response, safety_margin, explanation_rate)。
- **质量门映射** σ: SIC × M → {pass, recover, abort}，在服务时刻把场景置信度、阻抗确定性、执行可行性翻译为「继续/恢复/中止」。

**定义 163（抓取服务恢复协议 GSRP）** 恢复策略 R = (T_r, Π_r, C_r)。恢复树 T_r 的动作按代价升序：
1. `re-grasp`：G' ∈ N(G)（邻域抓取），要求 Q_fc(G') ≥ Q_fc(G)，K 不变；
2. `re-compile`：K' ∈ F_GK，降低刚度/速度（K_p↓, v_max↓）；
3. `re-negotiate`：当意图置信度 γ_intent < τ_intent 时，向用户追问，冻结执行；
4. `degrade`：安全停止 + 显式告知（最小可行服务）。
恢复代价 `C_r(a) = λ_t·Δt(a) + λ_s·Δservice(a) + λ_e·Energy(a) + λ_trust·Risk_trust(a)`；选择 `a* = argmin_a C_r(a)` s.t. a 可行且 B_recover > 0。

**定义 164（服务质量观测器 SQO）** 由 EV-svc 与前台日志计算服务质量向量 q = (q_rel, q_res, q_ass, q_emp, q_tan) ∈ [0,1]⁵：
- **可靠性** q_rel = 窗口内服务成功率；
- **响应性** q_res = f(τ_response 分位数)；
- **保证性** q_ass = 安全证书有效率 × 安全裕度归一化；
- **同理心** q_emp = 意图-约束匹配度（含是否正确触发 re-negotiate）；
- **有形性/透明性** q_tan = 前台解释覆盖率（后台动作被用户理解的比例）。
`Q_service = Π_i q_i^{w_i}`（加权几何平均，任一维为 0 则整体为 0）。

**定义 165（服务化抓取闭环 SGRC）** 算子 SGRC(M, object, intent, δ_f_req)：
```
① SSM: z ← R_scene.update(telemetry)
② CIEC: C_intent ← ϕ(intent); ERTC.lock(C_intent)
③ GIKP: {G_i} ← sample_grasps(object)
        foreach G_i: F_GK(G_i) ← project(π_scene, G_i)
        G* ← argmax min-margin(G_i, K; z)
④ EEIS: K_safe ← compile(F_GK(G*), δ_f_req, C_intent)
⑤ SBP: gate ← σ(SIC, next_moment_of_truth); if gate=abort → DEGRADE
⑥ Execute: EV-exec ← grasp_and_move(G*, K_safe)
⑦ SVC: EV-svc ← attach(EV-exec, G*, fail_point_tag, recovery_id)
⑧ SQO: q ← observe(EV-svc); T ← TTF.update(q)
⑨ if service_failed: a* ← GSRP.select(fail_point, B_svc)
        if a* = re-negotiate: frontstage.explain(); freeze()
        elif a* ≠ degrade: goto ③ / ④
⑩ Return: (G*, K_safe, q, T, recovery_record)
```

**定义 166（服务预算 B_svc 与 PCE+++++）** B_svc = (B_recover, B_explain, B_trust)。PCE+++++ 的 VOI 扩展为：
```
voi_svc(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_svc(π)
cost_svc = λ_rec·Recovery_count(π) + λ_exp·Explanation_bandwidth(π) + λ_tr·Trust_drawdown(π)
```
安全备用策略：B_recover 耗尽 ⇒ 最小可行服务（告知 + 安全停止）；B_explain 耗尽 ⇒ 禁止无声恢复；B_trust < θ_trust ⇒ 主动降低自主级别并请求人类接管。

**定义 167（服务证据链 SVC）** EV-svc = EV-exec ⊕ (G, grasp_id, fail_point_tag, recovery_action, frontstage_explanation, q_delta)。SVC 在 EPIR 的因果链上增加**服务因果约束**：任一 recovery_action 必须因果后于其 fail_point_tag 对应的 EV-exec；任一前台解释必须因果后于触发它的后台失败。若违反，标记为「服务因果断裂」。

**定义 168（信任轨迹场 TTF）** 信任动态：
```
T_{t+1} = clip( T_t + α·success·(1−T_t)
                   − β·failure·T_t
                   + γ·recovery_gain·(1−T_t), 0, 1 )
```
其中 recovery_gain = 1{恢复成功且已解释}·q_tan。**服务恢复悖论**被形式化为：当 α·success + γ·recovery_gain > β·failure 时，一次「失败+成功恢复」可产生净正向信任增量。T < θ_trust 时触发自主级别下调。

## 2. 关键算法伪代码

### IP-161 GIKP（抓取-阻抗联合规划）

```python
class GraspImpedanceJointPlanner:
    def __init__(self, eeis, scene_model, mu=0.5):
        self.eeis = eeis
        self.scene_model = scene_model
        self.mu = mu

    def impedance_realizable(self, G, K):
        if not self._force_closure(G):
            return False
        for c in G.contacts:
            if not self._in_friction_cone(c.force, self.mu):
                return False
        wrench = K @ G.delta_x
        return self._in_wrench_space(wrench, G.gws)

    def plan(self, obj, scene_dist, intent_constraint):
        K_priors = self.scene_model.get_scene_impedance_prior(top_k=3)
        best_G, best_margin = None, -float('inf')
        for G in self._sample_grasps(obj):
            if not self._force_closure(G):
                continue
            feasible = [(z, K) for z in scene_dist for K in K_priors[z]
                        if self.impedance_realizable(G, K)
                        and self.eeis.satisfies(K, intent_constraint)]
            if not feasible:
                continue
            margin = min(self._safety_margin(G, K, z) for z, K in feasible)
            margin -= 0.1 * self._recovery_cost(G)
            if margin > best_margin:
                best_G, best_margin = G, margin
        return best_G, best_margin
```

### IP-162 SBP（服务蓝图）

```python
class ServiceBlueprint:
    def __init__(self):
        self.frontstage = ['approach', 'grasp', 'deliver', 'explain', 'apologize']
        self.backstage = ['SSM', 'CIEC', 'GIKP', 'EEIS', 'EPIR']
        self.support = ['ROS', 'compute', 'evidence_store']
        self.fail_points = {
            'grasp_slip':   {'stage': 'backstage', 'severity': 'high',   'detect': 'force_drop'},
            'scene_misid':  {'stage': 'backstage', 'severity': 'high',   'detect': 'SIC_invalid'},
            'intent_ambig': {'stage': 'backstage', 'severity': 'medium', 'detect': 'low_intent_conf'},
            'ros_loss':     {'stage': 'support',   'severity': 'medium', 'detect': 'seq_gap'},
            'user_confused':{'stage': 'frontstage','severity': 'medium', 'detect': 'no_ack'},
        }
        self.moments_of_truth = ['first_contact', 'handover', 'failure_notice']

    def gate(self, sic, moment):
        if moment not in self.moments_of_truth:
            return 'pass'
        if not sic.valid:
            return 'recover'
        return 'pass'
```

### IP-163 GSRP（抓取服务恢复）

```python
class GraspServiceRecovery:
    def __init__(self, budget):
        self.budget = budget
        self.tree = ['re-grasp', 're-compile', 're-negotiate', 'degrade']

    def select(self, fail_point, state):
        for action in self.tree:
            if action == 're-grasp' and self.budget.B_recover > 0 and state.alt_grasps:
                return action
            if action == 're-compile' and self.budget.B_recover > 0:
                return action
            if action == 're-negotiate' and self.budget.B_explain > 0:
                return action
        return 'degrade'

    def apply(self, action, state):
        if action == 're-grasp':
            self.budget.B_recover -= 1
            return state.with_grasp(state.next_grasp())
        if action == 're-compile':
            self.budget.B_recover -= 1
            return state.with_impedance(state.K.scale(0.7))
        if action == 're-negotiate':
            self.budget.B_explain -= 1
            return state.freeze().with_question()
        return state.safe_stop().with_explanation()
```

### IP-164 SQO（服务质量观测器）

```python
class ServiceQualityObserver:
    def observe(self, ev_svc_window, frontstage_log):
        q_rel = self._success_rate(ev_svc_window)
        q_res = self._responsiveness(ev_svc_window)
        q_ass = self._assurance(ev_svc_window)
        q_emp = self._intent_match(ev_svc_window, frontstage_log)
        q_tan = self._explanation_coverage(frontstage_log)
        q = np.array([q_rel, q_res, q_ass, q_emp, q_tan])
        return float(np.prod(q ** self.weights))  # 加权几何平均
```

### IP-165 SGRC（服务化抓取闭环）

```python
def service_grasp_recovery_loop(M, obj, intent, delta_f_req):
    z = M.scene_model.update(M.telem_force, M.telem_pos)
    M.intent_ctrl.receive_intent(intent)
    G, margin = M.gikp.plan(obj, M.scene_model.distribution(), M.intent_ctrl.constraint())
    if G is None:
        return M.service_blueprint.degrade('no_feasible_grasp')
    K_safe = M.eeis.compile(M.gikp.feasible_set(G), delta_f_req,
                            M.intent_ctrl.constraint())
    if M.service_blueprint.gate(M.sic, 'first_contact') == 'abort':
        return M.service_blueprint.degrade('sic_invalid')
    EV_exec, cert = M.executor.grasp_and_move(G, K_safe)
    EV_svc = M.svc.attach(EV_exec, G, cert)
    q = M.sqo.observe(M.svc.window(), M.frontstage.log)
    M.trust = M.ttf.update(q)
    if not EV_svc.success:
        action = M.gsrp.select(EV_svc.fail_point, M.state)
        M.service_blueprint.frontstage.act(action)
        return service_grasp_recovery_loop(M, obj, intent, delta_f_req) \
               if action not in ('degrade',) else M.service_blueprint.degrade(action)
    return M, G, K_safe, q, M.trust
```

### IP-166 PCE+++++（服务预算）

```python
class ServiceBudget:
    def __init__(self, recover=2, explain=5, trust=1.0, theta_trust=0.4):
        self.B_recover = recover
        self.B_explain = explain
        self.B_trust = trust
        self.theta_trust = theta_trust

    def mode(self):
        if self.B_trust < self.theta_trust:
            return 'human_takeover'
        if self.B_recover <= 0:
            return 'minimal_viable_service'
        if self.B_explain <= 0:
            return 'no_silent_recovery'
        return 'normal'
```

### IP-161 GIKP（抓取-阻抗联合规划）

```python
class GraspImpedanceJointPlanner:
    def __init__(self, eeis, scene_model, mu=0.5):
        self.eeis = eeis
        self.scene_model = scene_model
        self.mu = mu

    def impedance_realizable(self, G, K):
        if not self._force_closure(G):
            return False
        for c in G.contacts:
            if not self._in_friction_cone(c.force, self.mu):
                return False
        return self._in_wrench_space(K @ G.delta_x, G.gws)

    def plan(self, obj, scene_dist, intent_constraint):
        priors = self.scene_model.get_scene_impedance_prior(top_k=3)
        best_G, best_margin = None, -float('inf')
        for G in self._sample_grasps(obj):
            if not self._force_closure(G):
                continue
            feasible = [(z, K) for z in scene_dist for K in priors[z]
                        if self.impedance_realizable(G, K)
                        and self.eeis.satisfies(K, intent_constraint)]
            if not feasible:
                continue
            margin = min(self._safety_margin(G, K, z) for z, K in feasible)
            margin -= 0.1 * self._recovery_cost(G)
            if margin > best_margin:
                best_G, best_margin = G, margin
        return best_G, best_margin
```

### IP-162 SBP（服务蓝图 + 质量门）

```python
class ServiceBlueprint:
    def __init__(self):
        self.frontstage = ['approach', 'grasp', 'deliver', 'explain', 'apologize']
        self.backstage = ['SSM', 'CIEC', 'GIKP', 'EEIS', 'EPIR']
        self.support = ['ROS', 'compute', 'evidence_store']
        self.fail_points = {
            'grasp_slip':    {'stage': 'backstage', 'severity': 'high',   'detect': 'force_drop'},
            'scene_misid':   {'stage': 'backstage', 'severity': 'high',   'detect': 'SIC_invalid'},
            'intent_ambig':  {'stage': 'backstage', 'severity': 'medium', 'detect': 'low_intent_conf'},
            'ros_loss':      {'stage': 'support',   'severity': 'medium', 'detect': 'seq_gap'},
            'user_confused': {'stage': 'frontstage','severity': 'medium', 'detect': 'no_ack'},
        }
        self.moments_of_truth = ['first_contact', 'handover', 'failure_notice']

    def gate(self, sic, moment):
        if moment not in self.moments_of_truth:
            return 'pass'
        return 'pass' if sic.valid else 'recover'
```

### IP-163 GSRP（抓取服务恢复）

```python
class GraspServiceRecovery:
    def __init__(self, budget):
        self.budget = budget
        self.tree = ['re-grasp', 're-compile', 're-negotiate', 'degrade']

    def select(self, fail_point, state):
        if self.budget.B_recover > 0 and state.alt_grasps:
            return 're-grasp'
        if self.budget.B_recover > 0:
            return 're-compile'
        if self.budget.B_explain > 0 and fail_point == 'intent_ambig':
            return 're-negotiate'
        return 'degrade'
```

### IP-164 SQO（服务质量观测）

```python
class ServiceQualityObserver:
    weights = np.array([0.30, 0.20, 0.25, 0.15, 0.10])

    def observe(self, ev_svc_window, frontstage_log):
        q = np.array([
            self._success_rate(ev_svc_window),
            self._responsiveness(ev_svc_window),
            self._assurance(ev_svc_window),
            self._intent_match(ev_svc_window, frontstage_log),
            self._explanation_coverage(frontstage_log),
        ])
        return float(np.prod(np.maximum(q, 1e-6) ** self.weights))
```

### IP-165 SGRC（服务化抓取恢复闭环）

```python
def service_grasp_recovery_loop(M, obj, intent, delta_f_req):
    z = M.scene_model.update(M.telem_force, M.telem_pos)
    M.intent_ctrl.receive_intent(intent)
    G, margin = M.gikp.plan(obj, M.scene_model.distribution(),
                            M.intent_ctrl.constraint())
    if G is None:
        return M.service_blueprint.degrade('no_feasible_grasp')
    K_safe = M.eeis.compile(M.gikp.feasible_set(G), delta_f_req,
                            M.intent_ctrl.constraint())
    if M.service_blueprint.gate(M.sic, 'first_contact') == 'abort':
        return M.service_blueprint.degrade('sic_invalid')
    EV_exec, cert = M.executor.grasp_and_move(G, K_safe)
    EV_svc = M.svc.attach(EV_exec, G, cert)
    q = M.sqo.observe(M.svc.window(), M.frontstage.log)
    M.trust = M.ttf.update(q)
    if not EV_svc.success:
        action = M.gsrp.select(EV_svc.fail_point, M.state)
        M.frontstage.act(action)
        if action == 'degrade':
            return M.service_blueprint.degrade(action)
        return service_grasp_recovery_loop(M, obj, intent, delta_f_req)
    return M, G, K_safe, q, M.trust
```

### IP-166 PCE+++++（服务预算）

```python
class ServiceBudget:
    def __init__(self, recover=2, explain=5, trust=1.0, theta_trust=0.4):
        self.B_recover, self.B_explain = recover, explain
        self.B_trust, self.theta_trust = trust, theta_trust

    def mode(self):
        if self.B_trust < self.theta_trust:
            return 'human_takeover'
        if self.B_recover <= 0:
            return 'minimal_viable_service'
        if self.B_explain <= 0:
            return 'no_silent_recovery'
        return 'normal'

def cost_svc(action, lam):
    return (lam['rec'] * action.recovery_count +
            lam['exp'] * action.explanation_bandwidth +
            lam['tr']  * action.trust_drawdown)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GIKP | O(\|G\|·\|K\|·\|Z\|) 每次规划 | O(\|G\|·\|C\| + \|K\|) | 联合可行流形 F_GK 内编译，打滑率 ≤ 2% |
| SBP | O(\|Φ\|) 质量门 | O(\|Φ\|+\|M\|) | fail point 检出召回 ≥ 90% |
| GSRP | O(\|T_r\|) 选动作 | O(\|T_r\|) | 可恢复 fail point 覆盖率 ≥ 80% |
| SQO | O(W) / 窗口 | O(W) | Q_service 与人工评分相关 ≥ 0.8 |
| SVC | O(1) 附加 / O(N) 因果校验 | O(window) | 服务因果断裂检出 ≥ 99% |
| TTF | O(1) / 更新 | O(1) | T∈[0,1]，阈值触发确定性 |

**正确性定理（SGRC）**：
假设 A66–A70 成立；**(A66)** GIKP：力闭合度量 Q_fc 与摩擦锥 FC(μ) 保守估计，ρ(G,K) 的下界可靠，F_GK 非空当且仅当存在物理可实现的抓取-阻抗对。**(A67)** SBP：Φ 对每个已观测失败模式至少有一个 fail point 标签，σ 在服务时刻单调保守（宁 recover 不 abort）。**(A68)** GSRP：恢复树在 B_svc 内有限终止，且 `degrade` 动作总是可行（安全停止不依赖任何恢复成功）。**(A69)** SQO：五维指标均可由 EV-svc 与前台日志无偏估计，且窗口满足遍历性。**(A70)** TTF：α, β, γ ∈ [0,1]，T_t 为 [0,1] 上的压缩映射，存在唯一不动点 T*。

则：
1. **抓取安全正确性**：若 GIKP 返回 G\*，则 ∀z∈Z_scene，所编译 K_safe ∈ F_GK(G\*,z)；因此不存在「名义可行、物理不可实现」的阻抗参数被下发。
2. **服务恢复活性**：任一 φ∈Φ 若被触发且 B_svc>0，则存在恢复路径在有限步内到达 pass 或 degrade；degrade 保证安全停止与显式告知。
3. **服务质量一致性**：Q_service 对窗口内 EV-svc 的估计随窗口增大收敛到真实服务质量的加权几何均值（A69）。
4. **信任安全边界**：若 T_t < θ_trust，则自主级别下调为 human_takeover，且该降级不可被后台自动撤销。

## 5. 本轮最大风险

**一句话**：若抓取-阻抗联合可行域被过于乐观地估计（摩擦系数 μ 偏低、力旋量空间 W(G) 近似忽略接触力矩、力闭合度量高估），系统会在「看似可行」的抓取上编译高刚度并把失败全部推给服务恢复——恢复预算被快速透支、前台解释变成事后补丁，最终形成「越恢复越不可信」的信任崩塌；必须以「GWS 与摩擦锥保守下界 + 恢复次数硬上限 + B_trust 低于阈值强制降级 + 服务因果链校验」四重护栏，确保「抓取可行」永远先于「服务恢复」。
