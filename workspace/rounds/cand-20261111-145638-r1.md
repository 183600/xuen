# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「避障控制」×「轻量化结构」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书 J，并用云边闭环保证动作对齐。本轮引入两个来自控制与结构的硬约束：**避障控制**（安全集前向不变、制动/转向机动包络）与**轻量化结构**（低质量/低惯量带来敏捷性，但柔度、模态振动与时变刚度带来结构不确定性）。核心矛盾：**H22**：在名义刚体模型上认证的避障安全集，在轻量化柔性结构上会因末端偏转与模态残差而失效；**H23**：减重提升制动/转向权限，却同时抬高“安全税”，使避障证书与结构拓扑必须联合设计。一句话直觉：**轻量化不是免费的速度，而是把质量换成了需要用证书偿付的安全赤字。**

## 0. 直觉与动机

**灵感 1（轻量化的双刃：敏捷性 vs 安全税）**
直觉：质量 m 下降使最大加速度 `a_max ≈ F/m` 上升，理论制动距离 `d_b = v²/(2a_max)` 下降；但结构变轻往往意味着刚度 k 下降、阻尼比 ζ 下降、柔性模态 ω_d 落入控制带宽，末端产生不可忽略的偏转 `δ_s = J_s q`。避障真正关心的不是刚体质心到障碍的距离，而是“最坏结构偏转后的最近点距离”。于是减重带来的敏捷收益会被结构安全税部分甚至完全抵消。定义**安全税 τ_s**：为保持同一认证安全半径，轻量化后必须额外预留的屏障余量。它是“轻量化结构”与“避障控制”之间最直接的第一性耦合量。

**灵感 2（结构感知屏障：把模态能量写进 CBF）**
直觉：经典控制屏障函数用 `h(x) ≥ 0` 定义安全集。轻量化结构下应使用 `h_Σ(x) = h_0(x_r) - ε_s(ξ)`，其中 ξ 为柔性模态状态，ε_s 是结构偏转 + 模态能量 + 降阶残差 + 估计误差的鲁棒膨胀项。控制目标不是“贴着 h_0=0 走”，而是“贴着 h_Σ=0 走”。这把避障从纯几何问题变为**几何 + 模态的联合不变性问题**，也把第 54 轮的动作证书从“能执行”推进到“执行时结构上仍然安全”。

**灵感 3（避障机动包络：给技能组合图的边加上镇定时间）**
直觉：第 54 轮的技能组合图 G_S 只检查动作兼容性与转换成本；急停、左/右转、后退这些避障机动真正的可执行性取决于**结构镇定时间 t_settle**（柔性模态衰减到容差内的时间）。若 `t_exec + t_settle > t_react`，则该机动在结构上不可行，即使动作空间完全兼容。故边权必须含 `t_settle` 与安全税，形成“时间-结构可行”的避障技能图；这解释了很多“仿真里能躲、实机上躲不开”的失败：不是动作不可达，而是结构来不及稳定。

**灵感 4（结构-控制协同设计：质量-安全 Pareto 前沿）**
直觉：传统流程是先优化结构（减重）再设计控制器（避障），串行设计会让结构把安全裕度吃光，控制器只能在残羹上做保守避障。应做双层协同：外层搜索拓扑/铺层/关节刚度/质量分布，内层验证 CBF-QP 可行性与证书；输出“**质量-认证安全半径**”Pareto 前沿。协同设计的目标不是最轻，而是在给定避障规格下**最轻的可认证结构**。

**灵感 5（云边结构残差闭环）**
直觉：云端持有高保真有限元/降阶模型做全局粗规划与安全包络预算，边端只持有低阶模型做实时 CBF-QP。边端检测到的模态残差、接触/负载导致的刚度漂移，通过残差信道回传云端，云端更新安全税并重算包络。这把第 54 轮的“动作对齐闭环”扩展为“**动作-结构-安全**”三对齐闭环，避免云端用过期结构模型签发的避障证书在边端失效。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（轻量化结构状态与模态）**
结构状态 `ξ = (q, q̇)`，`q ∈ ℝ^m` 为模态坐标，满足
```
M q̈ + C q̇ + K q = B u + d
```
模态能量 `E_i = ½(q̇_i² + ω_i² q_i²)`，总柔性能量 `E_flex = Σ_i E_i`，末端结构偏转 `δ_s = J_s q`。完整状态 `x = (x_r, ξ)`，其中 `x_r` 为刚体位姿与速度。

**定义 122（结构柔度与降阶残差）**
柔度 `σ_S = ||K^{-1}||₂`（质量归一化后）；降阶残差
```
η_m = sup_{ω∈[0,ω_B]} ||G_full(jω) - G_rom(jω)||₂
```
`ω_B` 为避障控制带宽。注意 η_m 是**频带内**残差，而非全频残差；频带外的高频模态通过低通与物理阻尼隔离，但其能量仍需在 E_flex 中记账。

**定义 123（结构感知安全屏障）**
对障碍集 O，名义屏障 `h_0(x_r) = dist(x_r, O) - r_safe`。结构感知屏障
```
h_Σ(x) = h_0(x_r) - α||δ_s|| - β√E_flex - γη_m - δ_ε
```
其中 α, β, γ 为灵敏度系数，`δ_ε` 为在线模态估计误差上界。安全集 `C_Σ = {x | h_Σ(x) ≥ 0}`。**关键性质**：h_Σ 是保守屏障，`h_Σ ≥ 0 ⟹ 真实最近点距离 ≥ r_safe`。

**定义 124（轻量化安全税）**
设基准质量 m 的认证安全半径为 `r_cert(m)`，减重 Δm 后为 `r_cert(m-Δm)`。绝对安全税与归一化安全税：
```
τ_s(Δm) = r_cert(m) - r_cert(m-Δm)
T_s      = τ_s / (Δm/m)
```
`τ_s ≤ 0` 称减重是安全中性的（敏捷收益不被结构吃掉）；`τ_s > 0` 表示存在敏捷-安全权衡。T_s 是本轮的核心标量指标：**每减 1% 质量要偿付多少米安全半径**。

**定义 125（避障机动包络）**
机动 `μ ∈ M_avoid = {brake, swerve_L, swerve_R, retreat, hover}` 的包络
```
E_μ = (d_min^μ, t_exec^μ, t_settle^μ, v_max^μ, a_req^μ)
```
其中 `t_settle^μ ≈ -ln(ε_q / ||q(0)||) / (ζ ω_d)` 由主导柔性模态与容差 ε_q 决定。机动可执行当且仅当
```
d_eff ≥ d_min^μ  ∧  t_exec^μ + t_settle^μ ≤ t_react
∧ a_req^μ ≤ a_max(m)  ∧  h_Σ 沿 μ 保持 ≥ 0
```

**定义 126（结构-安全联合证书）**
```
ΣJ = (h_Σ, η_m, {E_μ}, ρ, A_cert, δ_s, evidence)
```
其中 ρ 为第 53 轮鲁棒性谱，A_cert 为第 54 轮动作占用证书，δ_s 为结构不确定性预算。部署条件：`C_Σ` 前向不变，且至少存在一条机动链 `μ_1∘…∘μ_k` 满足定义 125 与任务动作序列。

**定义 127（证书保持的模型降阶）**
若存在界 η_h 使得
```
h_Σ^rom(x) - η_h ≥ 0  ⟹  h_Σ^full(x) ≥ 0
```
且 `η_h ≤ margin_CBF`，则称 `(G_rom, η_h)` 是证书保持的。充分条件（小增益）：`||Δ(jω)||·||C(jωI-A)^{-1}B||_∞ < 1`，且 η_h 覆盖该乘积上界。

## 2. 关键算法 伪代码

### IP-121 SAB（Structure-Aware Barrier）

```python
def structure_aware_barrier(x_r, xi, obstacle, model, margin):
    d = signed_distance(x_r, obstacle)
    q, qdot = xi
    delta_s = np.linalg.norm(model.J_s @ q)
    e_flex = sum(0.5 * (qdot[i]**2 + model.omega[i]**2 * q[i]**2)
                 for i in range(model.m))
    eps_s = (margin.alpha * delta_s
             + margin.beta * np.sqrt(e_flex)
             + margin.gamma * model.eta_m
             + margin.delta_eps)
    return d - margin.r_safe - eps_s

def safety_filter(u_ref, h, Lf_h, Lg_h, lam, u_min, u_max):
    # min ||u - u_ref||^2
    # s.t. Lf_h + Lg_h·u + lam·h >= 0,  u_min <= u <= u_max
    return solve_qp(u_ref, Lf_h, Lg_h, lam, h, u_min, u_max)

def control_step(x, u_ref, obstacle, model, margin):
    h = structure_aware_barrier(x.x_r, x.xi, obstacle, model, margin)
    Lf_h, Lg_h = lie_derivatives(h, x, model)
    return safety_filter(u_ref, h, Lf_h, Lg_h,
                         margin.lam, model.u_min, model.u_max)
```

### IP-122 MAS（Modal Avoidance Set）

```python
def modal_avoidance_set(model, strain, imu, horizon):
    q_hat = observe_modes(strain, imu, model)          # 模态观测器
    e_flex = modal_energy(q_hat, model.omega)
    eps_s = (model.alpha * norm(model.J_s @ q_hat.q)
             + model.beta * sqrt(e_flex)
             + model.gamma * model.eta_m
             + model.delta_eps)
    # 用未来 horizon 内模态能量峰值做前瞻膨胀
    e_peak = predict_energy_peak(q_hat, model, horizon)
    buffer = eps_s + model.kappa * sqrt(max(0.0, e_peak - e_flex))
    return inflate(obstacle, buffer), e_flex
```

```python
def transfer_safety_certificate(rom_cert, full_model, eta_h, margin_cbf):
```

```python
def ssc_certify(rom, design, spec, eta_h):
    h = make_barrier(rom, spec, eta_h)                    # 定义 123
    mans = [mu for mu in spec.M_avoid
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SAB | O(m + \|O\|) | O(m) | 屏障保守性、模态能量上界 |
| MAS | O(m·h + \|O\|) | O(\|O\| + h) | 观测器误差 ≤ δ_ε |
| SCD | O(\|D\|·(FE + QP)) | O(\|D\| + \|A\|) | 残差证书保持、Pareto 完整 |
| ASG | O(\|M\|·\|S\| + \|E\|log\|V\|) | O(\|V\|+\|E\|) | 镇定时间上界 sound |
| RMC | O(m·n_ω) | O(m·n_ω) | 小增益 < 1、η_h 覆盖 |
| SSC | O(\|S\|·\|A\| + \|M\|·H) | O(\|A\|+\|M\|) | 前向不变性、机动可行 |

**正确性定理（Structure-Aware Avoidance Soundness, SAAS）**
承接第 53/54 轮 (A22)–(A28)；新增 **(A29)** 降阶残差在带宽内 `||Δ|| ≤ η_m` 且证书保持条件成立；**(A30)** 模态能量在线估计误差 ≤ δ_ε；**(A31)** 每条被选机动的执行+镇定时间上界可验证，且 `a_max(m)` 覆盖 `a_req`。
若 `h_Σ(x_0) ≥ η_h`，且每个控制周期 CBF-QP 可行，则对任意 t ≥ 0：
```
Pr[h_Σ(x(t)) ≥ 0] ≥ 1 - P(||Δ|| > η_m)
                       - P(|Ê_flex - E_flex| > δ_ε)
                       - P(sat(u))
```
且真实最近点距离 ≥ r_safe。

**证明要点**：由定义 123，h_Σ ≥ 0 直接推出真实距离下界；由 (A29)+(A30)，降阶模型上的屏障证书在真实系统上膨胀 η_h 后仍成立；由 (A31)，机动链在反应时间内完成且不越出 C_Σ；CBF-QP 的约束保证 h_Σ 的 Lie 导数非负，故前向不变。三项失败概率由联合界相加。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |

| 模态残差界过保守，安全税吃掉全部敏捷收益 | 高 | 自适应降阶 + 频带外能量单独记账 + 在线辨识 |
| 接触/负载/磨损导致刚度时变，证书过期 | 高 | 在线模态辨识 + 健康监测 + 定期重认证 |

## 6. 本轮最大风险

**一句话**：轻量化结构与避障控制的耦合若被压缩成一个静态“安全税”标量，就会掩盖**模态交叉耦合、负载/接触/磨损导致的时变刚度、以及降阶残差的频带依赖性**；一旦高速高频避障机动恰好激发被降阶模型丢弃的模态，证书会表现出“结构性过度自信”，在真实最危险工况下同时失去屏障与反应时间，故必须以 **在线模态辨识 + 频带分账的残差预算 + 机动包络硬前置** 三重护栏，宁可把安全税算贵，也不把降阶模型的平静当作结构的安全。

## 2. 关键算法 伪代码

### IP-121 SAB

```python
def structure_aware_barrier(x_r, xi, obstacle, model, margin):
    d = signed_distance(x_r, obstacle)
    q, qdot = xi
    delta_s = np.linalg.norm(model.J_s @ q)
    e_flex = sum(0.5 * (qdot[i]**2 + model.omega[i]**2 * q[i]**2)
                 for i in range(model.m))
    eps_s = (margin.alpha * delta_s
             + margin.beta * np.sqrt(e_flex)
             + margin.gamma * model.eta_m
             + margin.delta_eps)
    return d - margin.r_safe - eps_s

def control_step(x, u_ref, obstacle, model, margin):
    h = structure_aware_barrier(x.x_r, x.xi, obstacle, model, margin)
    Lf_h, Lg_h = lie_derivatives(h, x, model)
    return solve_qp(u_ref, Lf_h, Lg_h, margin.lam, h,
                    model.u_min, model.u_max)
```

### IP-122 MAS

```python
def modal_avoidance_set(model, strain, imu, horizon):
    q_hat = observe_modes(strain, imu, model)
    e_flex = modal_energy(q_hat, model.omega)
    eps_s = (model.alpha * norm(model.J_s @ q_hat.q)
             + model.beta * sqrt(e_flex)
             + model.gamma * model.eta_m
             + model.delta_eps)
    e_peak = predict_energy_peak(q_hat, model, horizon)
    buffer = eps_s + model.kappa * sqrt(max(0.0, e_peak - e_flex))
    return inflate(obstacle, buffer), e_flex
```

### IP-123 SCD

```python
def co_design(design_space, task, safety_spec, budget):
    front = []
    for design in sample_designs(design_space):
        M, C, K = fe_model(design)
        rom = reduce(M, C, K, band=task.omega_B)
        eta_h = certify_residual(rom, design, task.omega_B)
        if eta_h > safety_spec.margin_cbf:
            continue
        if not cbf_feasible(rom, task, safety_spec, eta_h):
            continue
        cert = ssc_certify(rom, design, safety_spec, eta_h)
        if cert.ok:
            front.append((total_mass(design),
                          cert.safety_radius,
                          design, cert))
    return pareto_front(front, key=lambda r: (r[0], -r[1]))
```

### IP-124 ASG

```python
def build_avoidance_graph(skills, M_avoid, model, theta_a, tau_e):
    G = build_composition_graph(skills, theta_a, tau_e)
    for mu in M_avoid:
        E = maneuver_envelope(mu, model)
        for s in skills:
            if E.d_min <= reachable_distance(s) and E.t_settle <= tau_e:
                G.add_edge(s.id, mu,
                           cost=E.t_exec + E.t_settle,
                           safety_tax=tau_s(E, model),
                           envelope=E)
    return G

def plan_with_settling(G, A_T, t_react, model):
    for path in k_shortest_paths(G, 'root', A_T, k=8):
        if sum(e.cost for e in path.edges) <= t_react:
            if all(e.safety_tax <= model.tax_budget for e in path.edges):
                return ('ok', path)
    return ('reject', 'no_structurally_timely_maneuver')
```

### IP-125 RMC

```python
def transfer_safety_certificate(rom_cert, full_model, eta_h, margin_cbf):
    if eta_h > margin_cbf:
        return ('reject', 'residual_exceeds_margin', eta_h)
    if small_gain(full_model, rom_cert.rom) >= 1.0:
```

### IP-126 SSC

```python
def ssc_certify(rom, design, spec, eta_h):
    h = make_barrier(rom, spec, eta_h)
    mans = [mu for mu in spec.M_avoid
            if admissible(mu, rom, h, design.mass)]
    if not mans:
        return Cert(ok=False, reason='no_admissible_maneuver')
    if not forward_invariant_check(rom, h, mans, spec.horizon):
        return Cert(ok=False, reason='invariance_fail')
    return Cert(ok=True, h=h, maneuvers=mans, eta_m=rom.eta_m,
                safety_radius=min_clearance(h),
                safety_tax=tau_s(design, spec.baseline))
```

### IP-128 LST（Lightweight Safety Tax）

```python
def lightweight_safety_tax(design, baseline, task, v_grid):
    taxes = []
    for v in v_grid:
        r_base = certified_radius(baseline, task, v)
        r_new = certified_radius(design, task, v)
        taxes.append(r_base - r_new)
    tau = max(taxes)
    T = tau / max(1e-9, (baseline.mass - design.mass) / baseline.mass)
    return Tax(tau=tau, normalized=T,
               safe_mass_reduction=(tau <= 0.0))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SAB | O(m + \|O\|) | O(m) | 屏障保守，h_Σ≥0 ⟹ 真实距离≥r_safe |
| MAS | O(m·h + \|O\|) | O(\|O\|+h) | 观测误差 ≤ δ_ε，前瞻能量上界 |
| SCD | O(\|D\|·(FE+QP)) | O(\|D\|+\|A\|) | 残差证书保持，Pareto 非支配 |
| ASG | O(\|M\|·\|S\|+\|E\|log\|V\|) | O(\|V\|+\|E\|) | 镇定时间上界 sound |
| RMC | O(m·n_ω) | O(m·n_ω) | 小增益 < 1，η_h 覆盖残差 |
| SSC | O(\|S\|·\|A\|+\|M\|·H) | O(\|A\|+\|M\|) | 前向不变、机动可行 |
| SCE | O(\|P\|·\|π\|) | O(\|V\|+\|E\|) | 残差回传收敛、无震荡 |

**正确性定理（Structure-Aware Avoidance Soundness, SAAS）**
承接第 53/54 轮 (A22)–(A28)；**(A29)** 降阶残差 `||Δ||≤η_m` 且证书保持；**(A30)** 模态估计误差 ≤ δ_ε；**(A31)** 机动时间与加速度上界可验证。
若 `h_Σ(x_0) ≥ η_h` 且每个控制周期 CBF-QP 可行，则
```
Pr[h_Σ(x(t))≥0] ≥ 1 - P(||Δ||>η_m)
                     - P(|Ê_flex-E_flex|>δ_ε)
                     - P(sat(u))
```
关键：**屏障先保守、残差可偿付、机动先过时间闸**。

## 6. 本轮最大风险

**一句话**：本轮把“避障控制”与“轻量化结构”通过安全税、模态屏障与降阶证书连成一条链，但整条链的 soundness **同时依赖模态残差界、在线模态观测误差、以及减重后时变刚度的可辨识性**；一旦高速高频机动激发降阶模型丢弃的模态，或负载/接触使刚度漂移超出 δ_s 预算，静态安全税会低估真实风险，证书在最有价值的极限工况下失效，故必须以 **频带分账残差预算 + 在线模态辨识 + 机动包络硬前置** 三重护栏，宁可承认“轻量化有安全上限”，也不签发结构性过度自信的避障证书。
