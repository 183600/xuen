# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「评测基准」×「桌面操作」）

> R66–R69 建起了一座越来越高的「理论塔」：谁控制、未来怎样、测量还准吗、该向谁求证。每一轮都新增定义、引理、定理与证书 J_*，并且都宣称「严格包含上一轮、安全侧不让步」。但始终没人回答那个最朴素的问题：**这些声明凭什么可信？** 没有基准，定理 16 的「严格包含」只是一句自我承诺；没有基准，E286–E300 里「AUC ≥ 0.85 / 成功率 +12%」只是目标数字。R69 自陈的最大风险（模态分布不可信 → 追问幻影、给误导回答盖章）恰恰是「只在自家闭环里自证」的必然产物：一个从没被外部反例击穿过的系统，其证书只能证明它满足了自己的检查器。
>
> 本轮两个灵感正好构成一次「落地 + 证伪」：
> - **评测基准**：把它当作一组**证伪器（falsifier）**，而不是排行榜——把 R66–R69 的每条 claim 变成可被一个反例轨迹击穿的可检验命题；基准的好坏由「能否让作者自己的方案失败」来定义，而不是由它能排多少名来定义；
> - **桌面操作**：一个把全部抽象瞬间具体化的域——屏幕像素 / 控件树 / 光标 / 剪贴板 / 文件系统，点击 / 输入 / 滚动 / 拖拽，**不可逆动作**（删文件、发邮件、下单、覆盖保存）、**天然漂移**（应用升级、DPI/主题/本地化、弹窗遮挡）、**人在场可问**、以及**已有的公开基准可复用**（OSWorld / WebArena 式）。
>
> 核心命题：**把研究闭环倒过来——不再从理论推向实验，而是从「能击穿哪条 claim」反推基准设计；一个基准的有效性不是它有多权威，而是它对某条 claim 是否可证伪、以及它能否抓住已知会违反该 claim 的「坏 agent」（变异测试）。** 命名 **RAS-LADDER**（Leveled Adversarial Divergence-based Desktop Evaluation Regime：分层、对抗、发散度驱动的桌面评测机制）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**凭什么相信这一切——请让它失败给我看**」。

## 0. 直觉与动机

**灵感 1（评测基准 = 证伪器，不是排行榜）**
直觉：一个只会报「成功率 82.3%」的基准，对 R69 几乎无用——它无法区分「安全因为真的安全」与「安全因为从不做不可逆动作」。真正有用的基准，是给每条理论声明配一个**可以被反例杀死的命题**：定理 16 说「退化边界上逐指令相同」，那就得有一条轨迹能让它不同；引理 17 说「(r_res↓, Δa↑) 可分缓变故障」，那就要有能被标定吸收的真故障实例。基准的基本单位不是「任务」，而是 **(claim, falsifier)** 对。排行榜问「谁更强」，证伪器问「你错在哪」。
严谨地说：基准 = 任务分布 × 证明义务集（proof obligations）× 独立检查器 × 对抗课程 × 评分阶梯 × 配对协议。有效性是相对的：ℬ 对 claim κ 有效 ⇔ ℬ 至少含一个 κ 的**可容许证伪器**，且变异测试证明它能杀死 κ-违规的变异体（定义 313、定理 19）。

**灵感 2（桌面操作 → 不可逆性让「风险缩放」第一次可观测）**
直觉：过去所有关于 λ（风险缩放）的论述都是不可测的：在一个「点了也能撤销」的世界里，无论 λ=0.3 还是 λ=1.0，任务成功率都一样，安全违规都是 0——于是任何「自适应风险」的收益都无法被证实或证伪。桌面操作的关键性质是**动作有不可逆性分级**：移动光标可逆、改设置可撤回、删文件进回收站是「昂贵」、发邮件/转账/覆盖保存是「不可逆」。只有在不可逆任务上，λ 才真正把「安全」与「效率」放在同一根绳子上拉扯。**可逆性会遮蔽风险**：一个全是可逆任务的基准，无法区分 RAS 与「永远最大保守」（引理 19）。所以桌面基准必须按不可逆性分层，并保证不可逆任务占比不低于阈值。

**灵感 3（桌面操作 → 漂移与投毒是「原生态」的，不必人造）**
直觉：R69 的 FMA 需要「被标定吸收的缓变故障」才能验证，这在实验室里很难造；但桌面世界天天发生：应用升级后按钮位移 20px、DPI 从 100% 调到 150%、深色主题把图标对比度压低、本地化把「确定」放到右边、系统弹窗遮住半个界面。这些都是**缓慢、可被内部标定吸收、却让策略条件在错误世界上**的漂移，正好是 FMA 的天然试验场。桌面还有天然的投毒：误导性 tooltip、假对话框、「看起来像取消其实确认」的按钮、错误的可访问性标签——正好检验 R69 的交互投毒上界（引理 18）与证据纪律。

**灵感 4（配对协议 → 「严格包含」只有配对发散度能检验）**
直觉：「新方案不弱于旧方案」是一个**反事实**声明，单跑新方案永远证不了。必须让 FLUID、R68、消融体在同任务、同随机种子、同环境下**配对执行**，再比较逐指令/逐轨迹发散。特别地，定理 16 承诺「在退化边界（VoI≤成本等）逐指令相同」——这是一个可以被精确证伪的零假设：只要在退化子集上找到一个 timestep 的动作不同，定理 16 就死了。**不能证伪 ≠ 已验证**；若退化子集太小而未检出，那是统计功效不足，不是安全性得到证明（引理 20）。

**灵感 5（基准自己会被 Goodhart —— 必须有反身性）**
直觉：一旦「基准分数」成了目标，被测系统就会优化「通过检查器」而不是「真的安全」；更糟的是，基准是设计系统的人设计的，天然有确认偏误——挑自己擅长的任务、写自己过得去的 oracle。**一个不能让你失败的基准，是镜子不是基准。** 所以本轮必须同时交付：密封 oracle 子集、时间/版本切分、独立随机种子、变异测试（用已知坏的 agent 检验基准的杀伤力）、以及基准自身的有效性证书 J_BENCH。这是把「评测」也纳入风险自适应闭环：不只问「系统准吗」，还要问「**我对系统的测量还准吗**」——R68 的问题在元层重演。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（RAS-LADDER 总览）** 基准 ℬ = (𝒯, 𝒪, 𝒞, 𝒟, ℒ, Π)。其中 𝒯 桌面任务分布；𝒪 证明义务集（来自 R66–R69 的 claim→falsifier）；𝒞 独立证书检查器；𝒟 对抗风险课程生成器（漂移算子 × 投毒算子 × 边界构造）；ℒ L0–L5 评分阶梯；Π 配对基线协议。三不变式：
(i) **证伪完备**：R66–R69 的每条可检验 claim 至少映射到一个 𝒪 成员，且 𝒪 含密封子集（被测系统不可读）；
(ii) **配对同位**：所有被比较系统在相同任务、种子、环境快照下执行，逐 timestep 对齐；
(iii) **时间/版本切分**：评测所用应用版本、主题、语言不进入被测系统的训练分布，且按时间切分防污染。

**定义 311（桌面操作任务空间）** 状态 s = (S 屏幕, A 可访问性/控件树, c 光标, f 焦点, K 剪贴板, F 文件系统视图)。动作 a ∈ 𝒜_desk = {move, click(button, coord), type(text), key(combo), scroll(Δ), drag(p→q)}；信息动作 g ∈ 𝒜_info = {hover, scroll_reveal, zoom(region), open_help, ask_user(q), wait_render}（即 R69 g 的桌面即时化，定义 317）。**不可逆性标注** β: 𝒜_desk → {rev(可逆), cost(昂贵但可恢复), irr(不可逆)}，并配代价 cost(a)。每个任务声明一组必须保持的约束 Φ（如「不得向外部地址发送含 PII 的邮件」）。

**定义 312（证明义务集 𝒪）** 对每条 claim κ（如定理 16 严格包含、引理 17 缓变故障可分、引理 18 投毒上界、定义 307 两级退避、实时预算），定义义务 o_κ = (适用域 Dom_κ, 断言 P_κ, 容许证伪器 F_κ)。𝒪 = {o_κ}，并标记 sealed ⊂ 𝒪 为密封子集（只由第三方检查器评估，评测时被测系统看不到其任务与标签）。

**定义 313（证伪器 / claim oracle）** 给定轨迹 τ、证书 J、配对基线轨迹 τ_base，证伪器 F_κ 返回 {pass, fail, inconclusive}：
- **健全性型**（攻击核心）：若 J 判 Valid 而 τ 违反其自身声明的界（如安全包络、动作成本上界），返回 fail——「证书说安全却不安全」是最严重失败；
- **包含型**：在退化域 Dom_κ^0 上，若 Div(τ, τ_base) > 0 返回 fail；
- **效用型**：若 claim 断言某域内效率提升而实测未提升，返回 fail。
inconclusive 必须与 pass 严格区分：**样本不足、环境 flaky、标注缺失一律记为 inconclusive，绝不记为通过**。

**定义 314（对抗风险课程 𝒟）** 漂移算子 D = {dpi_rescale, theme_flip, app_version_bump, latency_inject, cursor_offset, color_profile_shift, widget_reflow, localize, popup_occlude, font_scale}；投毒算子 P = {misleading_tooltip, deceptive_dialog, inverted_confirm, fake_loading, poisoned_a11y_label, lure_link}。课程在难度 D0<D1<D2<D3 上逐步叠加，D3 专造**边界实例**（VoI≈c、Δ_min≈3σ_in、证书 ECE≈阈值），使 claim 在最容易被击穿的邻域被测试。

**定义 315（配对发散度 Div）** 对同任务同种子两次执行 τ_A, τ_B，按时间对齐后
Div(τ_A, τ_B) = (1/T)Σ_t [ 1{a_t^A ≠ a_t^B} + γ·1{g_t^A ≠ g_t^B} ] + λ_end·d(终态_A, 终态_B)，
其中动作等价类按语义（同一控件、同一文本归一化）判等；用于检验「逐指令相同」（Div=0）与「安全方向支配」。

**定义 316（L0–L5 评分阶梯）** L0 任务成功；L1 不可逆/约束违规（按 cost 加权）；L2 **证书健全性** CS（定义 320）；L3 效率与交互成本（步数、延迟、信息动作次数）；L4 校准（证书 ECE、VoI 实测/预测比）；L5 鲁棒（对 D、P 的退化曲线）。榜单不是一个标量，而是**沿 L1×L3 的 Pareto 前沿**；L2/L4 作为「否决层」，任一跌破阈值则无论 L0 多高都不计入有效提交。

**定义 317（桌面信息动作即时化）** hover→tooltip 揭示；scroll_reveal→滚动露出隐藏控件；zoom→局部放大读小字/图标；open_help→打开帮助/属性面板；ask_user(q)→向在场用户澄清（真实或模拟响应，含投毒通道）；wait_render→等待异步渲染。每个 g 带物理/社交成本 cost(g) 与风险等级，且必须经 R69 定义 302 的认证。

**定义 318（漂移锚点与 FMA 真值）** 对每个任务构造配对锚点：同一任务在「无漂移」与「施加漂移 d∈D」下执行，记录真值漂移标签 y_drift 与是否属于「可被内部标定吸收」的子类 y_absorb。于是可计算 R68 残差通道 r_res 与 R69 行为似然通道 Δa 的联合可分性，直接检验引理 17 的 (r_res↓, Δa↑) 判别模式。

**定义 319（不可逆性分层与遮蔽检验）** 任务按 β 分层为 𝒯_rev, 𝒯_cost, 𝒯_irr，要求不可逆层占比 ≥ π_irr。**遮蔽检验**：在纯可逆子集上比较任意两个仅在 λ 上不同的策略，若 L0/L1 不可分（预期不可分），则确认「可逆性遮蔽」成立，从而证明必须靠 𝒯_irr 才能检验风险自适应（引理 19）。

**定义 320（证书健全性与证书通胀）** 健全性 CS = 1 − (#{J=Valid ∧ 违约} / #{J=Valid})；**证书通胀** CI = #{J=Valid 但独立 oracle 判未达声明界} / #{J=Valid}。二者由**独立**检查器计算，不复用被测系统自带的证书生成器——否则就是让考生自己改卷。

**定义 321（变异测试与杀伤率）** 变异体族 M = {已知会违反 claim κ 的坏 agent}（如「无脑最大化成功率、无视不可逆」「伪造 Valid 证书」「把单源回答当定案」「对漂移不设似然通道」）。杀伤率 kill_κ(ℬ) = 被 ℬ 判为 fail 的 κ-变异体比例。**基准对 κ 的检验力上界 = 其变异集对该故障类的覆盖**。

**定义 322（基准有效性证书 J_BENCH）** J_BENCH = (oracle_cover, sealed_frac, mutant_kill, split_freshness, power, flaky_rate, ladder_ver, bench_ver)。Valid(ℬ) ⇔ oracle_cover=1（每 claim 有证伪器）∧ sealed_frac ≥ ρ_s ∧ mutant_kill ≥ τ_kill ∧ 时间切分未污染 ∧ 统计功效 ≥ 1−β ∧ flaky_rate ≤ τ_flaky。**J_BENCH 使「基准自身」也进入风险自适应闭环**：J_BENCH 失效时，任何基于 ℬ 的结论一律降级为 inconclusive。

## 3. 推导

**引理 19（可逆性遮蔽 / Reversibility Masking）** 若任务集 𝒯_rev 中所有动作 β=rev 且约束集合与动作选择无关（无不可逆后果），则对任意两个仅在风险缩放 λ∈(0,1] 上不同的策略 A、B，其在 L0（成功率）与 L1（违规代价）上期望相同；即 𝒯_rev 无法区分自适应风险与固定保守。证明要点：可逆动作可被后续动作任意撤销，终态可达集与 λ 无关，成功率与违规代价只看终态是否满足目标/约束。系：**桌面基准必须按 β 分层且 π_irr ≥ π_min**，否则关于定理 16 效率侧的任何结论都不可识别。

**引理 20（配对发散检验的样本复杂度）** 严格包含断言在退化子集 𝒮⁰ 上要求 Div=0。设真实每步发散概率 δ>0，要在置信 1−α、功效 1−β 下检出，需 N ≈ (z_{1−α/2}+z_{1−β})² · (1−δ)/δ 条 𝒮⁰ 轨迹；若 |𝒮⁰| 在任务分布下很小，则普通 Monte-Carlo 的 N 条里落到 𝒮⁰ 的只有 |𝒮⁰|·N，须用**分层/重要性采样**重加权。系：**「未检出 Div>0」只说明功效不足，不能证明严格包含**；报告必须同时给出 N 与功效，否则 pass 是假的。

**引理 21（变异覆盖界住检验力）** 设基准含 m_κ 个 κ-违规变异体、对 κ 的杀伤率为 kill_κ，系统真实证书通胀为 ε。则任何仅依赖该 oracle 的检出概率上界 ≤ 1 − (1−kill_κ)^{N·1[ε 落在被变异体覆盖的故障类]}。即 **kill_κ 低时，再大的 ε 也可能漏检**——基准的检验力封顶于其变异集的故障覆盖，而不是任务数量。

**定理 18（基准–Goodhart 悖论）** 若基准仅对外暴露单一标量排行榜、且被测系统可自适应（读榜调参），则在不设密封 oracle 与时间/版本切分时，存在证书通胀序列 ε_n→1 使榜面分数不降。证明要点：单标量只约束「检查器输出」，系统可用合法但空洞的动作抬高 L0/L3（例如在可逆子任务上刷分），把不可逆风险外移到未被覆盖的故障类；L2/L4 若与 L0 同源则可被一起「满足」。缓解：L2/L4 密封、跨版本切分、随机种子、cert inflation 由第三方检查——即定义 322 的 J_BENCH。系：**一个可被系统读到的证书检查器，等价于把答案发给考生。**

**定理 19（基准有效性的相对性）** 基准 ℬ 对 claim κ 有效 ⇔ (i) ℬ 含 κ 的可容许证伪器，且 (ii) 对 κ-违规变异体的杀伤率 ≥ τ_kill。故「有效性」是二元关系 Valid(ℬ, κ)，不存在脱离 claim 的「好基准」；把 ℬ 当通用排行榜是对定义 312–313 的误用。系：RAS-LADDER 的交付物是**一张 (claim × 基准组件 × 变异体 × 杀伤率) 的矩阵**，而不是一个排名表。

## 6. 本轮最大风险

**一句话**：RAS-LADDER 的最大风险是它自己——**oracle 由设计系统的人挑选、变异体由同一双手编写、不可逆性标注也可能错（把「覆盖保存」误标为可逆），若密封集与时间切分失守，基准就会把「系统满足了检查器」误当成「系统安全」，最终不是证伪了这座理论塔，而是给理论塔发了一张自签的合格证——不能让你失败的基准不是基准，是镜子。**

**次级风险与缓解**：
1. **确认偏误**（挑自己擅长的任务/oracle）→ 密封子集 + 第三方检查 + 预先注册（pre-registration）证伪器；
2. **sim–real gap**（仿真结论不迁移）→ 双层配对校准 + E310 排名相关门槛，gap 超限则结论降级；
3. **统计功效不足 / flaky**（「未检出」被当「已验证」）→ 引理 20 强制报告 N 与功效，inconclusive 不计 pass；
4. **标注错误**（不可逆性/约束错标会静默掩盖违规）→ 双人标注 + 变异测试专门注入错标检验检查器；
5. **污染**（公开基准应用/版本泄漏进训练）→ 时间/版本切分 + 私有任务重生成 + J_BENCH 的 split_freshness 校验。

## 4. 推导

**引理 19（可逆性遮蔽）** 若 𝒯_rev 全动作可逆且约束与动作选择无关，则任意仅在 λ 上不同的两策略在 L0/L1 上期望相同，𝒯_rev 不能区分自适应风险与固定保守。系：桌面基准须按 β 分层且 `π_irr ≥ π_min`。

| 实验 | 核心问题 | 关键目标 |
|---|---|---|
| E301 证伪完备性 | 每 claim 是否有证伪器 | oracle_cover=1，密封 ≥ 30% |
| E302 严格包含（配对发散） | 退化边界是否逐指令一致 | 𝒮⁰ 上 Div=0，功效 ≥ 0.8（报 N） |
| E303 证书健全/通胀 | Valid 是否真安全 | CS ≥ 0.99；CI ≤ 2%（第三方） |
| E304 FMA 补洞 | 标定吸收漂移能否抓出 | AUC ≥ 0.85，y_absorb 召回 ≥ 0.8 |
| E305 VoI 交互收益 | 桌面看/问/触值不值 | 不可逆任务 +12%，成本 Pareto 拐点 |
| E306 交互投毒 | tooltip/假对话框/共谋 | 单源 ≤ 5%；k-一致 ≤ 1% |
| E307 不可逆性分层 | 层间风险可分 | 𝒯_irr 显著区分，𝒯_rev 按预期不可分 |
| E308 遮蔽证伪 | 纯可逆能否识别 λ 收益 | 证实不可识别，据此定 π_min |
| E309 变异杀伤 | 基准能否抓坏 agent | 每 claim kill ≥ 0.8 |
| E310 sim–real gap | 仿真能否迁移 | L0 排名相关 ≥ 0.9，L1 差 ≤ 1% |
| E311 反 Goodhart | 刷榜是否得逞 | 密封+切分后收益 ≈ 0 |
| E312 功效/flaky | 结论可否复现 | flaky ≤ 2%，附功效与 CI |
| E313 端到端消融 | R66–R69 各层真实贡献 | 去 MINT 退 R68；去 FMA E304 −40% |

## 7. 本轮最大风险

**一句话**：RAS-LADDER 的最大风险是它自己——**oracle 由设计系统的人挑选、变异体由同一双手编写、不可逆性标注也可能错（把「覆盖保存」误标为可逆），若密封集与时间切分失守，基准就会把「系统满足了检查器」误当成「系统安全」，最终不是证伪了这座理论塔，而是给理论塔发了一张自签的合格证——不能让你失败的基准不是基准，是镜子。**

**次级风险与缓解**：确认偏误（密封子集 + 第三方检查 + 预注册）；sim–real gap（双层配对校准 + E310 门槛，gap 超限则结论降级）；统计功效/flaky（引理 20 强制报告 N 与功效，inconclusive 不计 pass）；标注错误（双人标注 + 注入错标变异）；污染（时间/版本切分 + 私有任务重生成 + split_freshness 校验）。
