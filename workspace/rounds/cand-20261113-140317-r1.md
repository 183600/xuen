# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因闭环」IP-214~223；灵感循环第 1 轮；本轮灵感：「移动底盘」×「长期记忆」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其最大风险是**归因错误的复合故障**：FIR 依赖"故障属于有限假设集、且各失效源相互独立"，未知复合故障会被强行塞进最近假设，只膨胀错误的球，而系统因为"已经归因"反而更自信。更根本的是，VISTA 的整套推理是**单次、单地点、单本体**的：它假设"这一次观测足以归因，这一次归因足以安全"。一旦把机械臂装上移动底盘，这个假设立刻失效——机器人会离开、会重访，世界在两次访问之间会变，而记忆会把上一次的结论带进这一次。
>
> 本轮不增加第 6 个传感器模态，也不扩充故障假设集，而是换一个时间尺度上的问法：
>
> **第 65 轮问「这一次到底哪一层坏了、该膨胀哪个球」；本轮问「上一次学到的东西，这一次还作数吗；如果不作数，系统凭什么仍然安全」。**
>
> 核心命题：**用移动底盘的重访能力，把长期记忆从"不可证伪的先验"改造成"可复核、可过期、可隔离的先验"；让记忆只在通过当前证据复核时才收缩不确定集，过期时显式退回无记忆的 VISTA；并把"记忆是否被用于安全"写进证书。**

## 0. 直觉与动机

**灵感 1（移动底盘 → 重访是记忆唯一的"可证伪接口"，但也是可被欺骗的接口）**
直觉：如果说长期记忆是一组"以前在这里量到的东西"，那么它天然需要一个空间索引——同一张桌子、同一个工位、同一段地面。移动底盘第一次让"回到同一个地方重新量一次"成为常规动作：重访既是任务的一部分，也是记忆的复核机会。但空间索引同时引入第 65 轮没有的失效模式：**定位误差与感知别名（perceptual aliasing）**。两个长得很像的工位、走廊或货架，会让机器人把 A 处的标定、B 处的接触几何错误地搬到当前场景。此时记忆不是"稍微不准"，而是**在错误的坐标系里完全正确**——这比随机误差更危险，因为它自洽、平滑、且会随重访被不断"确认"。

**灵感 2（移动底盘 → 记忆必须记住"在哪里、以什么位姿量的"）**
直觉：第 65 轮的 F/T 零偏和接触几何默认在本体坐标系里是常量。装上移动底盘后，重力在腕部力传感器上的投影随底盘俯仰/横滚变化，底盘的加减速会在"零力窗"里注入惯性伪力，重心与支撑多边形的关系随坡度变化并决定倾覆裕度。于是同一条"F/T 偏置"记忆，如果不带底盘位姿标签，就会在另一个位姿下变成系统性错误，并被 VISTA 误归因为 $H_{\text{force}}$ 或更糟地被当成 $H_{\text{geo}}$。正确的记忆条目必须带 **位姿条件**：不是"这台机器的零偏是 $b$"，而是"在底盘位姿 $p$、负载 $m$、温度 $T$ 下量到的零偏是 $b(p,m,T)$"；离开标定凸包时必须膨胀不确定性并强制一次零力窗复核。

**灵感 3（长期记忆 → 记忆是第四条可错证据，只能与当前证据"相交"，不能"替代"）**
直觉：第 65 轮已经把视觉定位为"第三条可错证据"。长期记忆是第四条，而且它的错误结构更隐蔽：视觉错了你看得见图像，力觉错了你看得见残差，记忆错了你**只看见一个很自信的先验**。因此记忆的正确用法不是"后验初始化在记忆上"，而是：**当前证据构成可信集 $\mathcal{A}_\alpha$；记忆只有在通过本次复核时，才允许以另一个可信集 $\mathcal{M}_\beta$ 与之相交**。相交只会缩小集合，绝不放大；但相交会消耗覆盖预算（$\alpha+\beta+\delta_{\text{msd}}$）。过期、别名、冲突时不相交，直接退回 $\mathcal{A}_\alpha$。一句话：**记忆可以让你更省，但不能让它成为唯一的安全依据。**

**灵感 4（长期记忆 → 非平稳世界：记忆会过期、漂移、被污染，而且"离开的时间"无法被观测）**
直觉：重访之间的世界在变：物体被移动、桌面被更换、标定漂移、地面坡度改变。更棘手的是，**机器人不在场时没有任何观测**，因此任何在线变点检测都停摆，只剩"年龄"这一个可用的保守量。于是记忆必须自带**时效膨胀** $\Sigma_{\text{entry}}(\Delta t)=\Sigma_0+\nu\Delta t$，并在回到现场后用 anytime-valid 的 e-process 做复核，而不是用每个访问独立校准的固定阈值（那会在长部署中累积假阳性）。此外，长期记忆是一个可写的攻击面：对手可以用对抗 patch、重放、诱导示范把"危险"教成"安全"，而且污染会跨会话持久化。故必须区分**会话内的情景缓冲**与**经写入门控合并的语义记忆**，并让"负记忆"（失败与近失）只增加谨慎、绝不减少谨慎。

**灵感 5（三灵感合流 → MEMENTO：Memory-grounded Embodied Mobile ENvelope with Trusted Origins，移动具身记忆接地的可信安全包络）**
闭环：VISTA 的单次归因 → 地点索引长期记忆 PLM → 记忆锚定与别名拒绝 MAR → 记忆接地先验 MGP → 记忆时效/变点复核 MSD → 位姿条件计量学 PCM（底盘位姿相关的 F/T、重力、倾覆）→ 记忆感知的信息价值 MVI（信任 / 探针 / 重访 / 合并四选一）→ 记忆条件下的块级证书 MSC/CSC-M → 归因定向半径 RSC-M / WCV-M → 重访感知的块级规划 CSP-M → 记忆写入门控与两级合并 MCW → 对抗记忆认证 AIC-M → 证书 J_memento。一句话概括四代传承：第 64 轮「可证伪」→ 第 65 轮「可归因」→ 第 66 轮「**可记忆，但记忆必须可复核、可过期、可隔离**」。

**灵感 6（VISTA / GRIP 组件的原位升级）**
- **FIR → FIR + H_mem / H_place**：故障假设集增加"记忆失效"和"地点锚定失效"两类；用"通道间一致但与记忆冲突"的签名把它们与几何/力/视觉故障分开。
- **AFA → MVI**：探针选择从"故障假设互信息"升级为"记忆感知的决策信息价值"；新增 `revisit_anchor`、`recalibrate_null`、`consolidate` 三个动作，信任记忆本身成为一个有价格的决策。
- **CSC → MSC/CSC-M**：块级证书在"记忆有效"与"记忆无效"两套不确定集上分别验证；记忆失效时 k* 只按无记忆 VISTA 计算。
- **RSC-V → RSC-M**：不确定半径增加 $r_{\text{mem}}$，只在 $H_{\text{mem}}$ / 过期 / 别名时膨胀，绝不让记忆污染几何球或力球。
- **WCV-V → WCV-M**：搜索域用记忆做候选排序与热启动，但**认证只用当前证据 + 已验证记忆**；记忆冲突时显式回退无记忆域。
- **CSP-V → CSP-M**：在块级技能图上增加"记忆维护"元技能与重访代价；移动底盘可以把"顺路复核一个标定地标"编进任务。
- **OLP / SSB / DIR**：长期记忆只从语义流写入；实时流零写；写入门控要求溯源、版本、冲突隔离与过期。
- **AIC-V → AIC-M**：干扰集增记忆投毒、重放、感知别名、选择性遗忘、跨会话污染；并显式建模"记忆自确认"。
- **J_vista → J_memento**：证书增加 memory provenance、age、anchor covariance、place posterior、memory_valid、memory_used_for_safety、revisit plan、memory_conflict。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（MEMENTO 闭环）**：MEMENTO = (VISTA, PLM, MAR, MGP, MSD, PCM, MVI, MSC/CSC-M, RSC-M, WCV-M, CSP-M, MCW, AIC-M, J_memento)。定位：VISTA 的"跨访问记忆接地 + 移动平台计量学"升级。不变式：**记忆检索、锚定、接地、变点复核、规划、合并与证书只在语义流/低频线程；实时流只做锚点读取、残差与阶段采集、记忆条件前缀执行、早停与派发，零记忆写、零学习写。**
- **定义 234（地点索引长期记忆 PLM）**：$\mathcal{M}=\mathcal{M}_{\text{epi}}\cup\mathcal{M}_{\text{sem}}\cup\mathcal{M}_{\text{pro}}\cup\mathcal{M}_{\text{met}}\cup\mathcal{M}_{\text{neg}}$，分别为情景、语义、程序、计量、负记忆。条目 $e=(\mathrm{id},\kappa,z,o,s,\tau,\varphi,\mathrm{prov},\nu)$：类型、地点锚、物体描述、技能/块签名、时间戳、内容（先验/标定/结果/故障后验）、溯源（传感器与标定版本哈希、会话 id）、版本。检索 $\mathcal{R}(q_t)=\{e_i,w_i\}$ 按地点锚、物体与技能相似度返回混合候选，$q_t=(z_t,o_t,s_t)$。
- **定义 235（记忆锚定与感知别名 MAR）**：底盘位姿 $x_b^t$ 及协方差 $\Sigma_b$；地点后验 $p(z\mid \text{img},\text{map})=\sum_j \pi_j\delta_{z_j}+p_{\text{cont}}$。锚定协方差 $\Sigma_z=\Sigma_b+J_z\Sigma_{\text{place}}J_z^\top$，别名熵 $H_{\text{alias}}=-\sum_j\pi_j\log\pi_j$。若 $H_{\text{alias}}>\tau_{\text{alias}}$ 或 $\Sigma_z$ 超出阈值，置 `place_unobservable`，记忆不得作为安全证据（只能用于候选排序）。
- **定义 236（记忆接地先验 MGP）**：记忆覆盖集 $\mathcal{M}_\beta(q)=\{\theta:(\theta-\mu_m)^\top\Sigma_{\text{mem}}^{-1}(\theta-\mu_m)\le\chi^2_{d,1-\beta}\}$，$\Sigma_{\text{mem}}=\Sigma_{\text{entry}}(\Delta t)+J_z\Sigma_zJ_z^\top+\Sigma_{\text{alias}}$，$\Sigma_{\text{entry}}(\Delta t)=\Sigma_0+\nu\Delta t$。记忆条件不确定集
  $\mathcal{U}_m=\mathcal{A}_\alpha(\rho_t)\cap\mathcal{M}_\beta(q)$（仅当 MSD 判 valid 且地点可观测），否则 $\mathcal{U}_m=\mathcal{A}_\alpha(\rho_t)$。
  **记忆只能相交、不能替代；相交消耗覆盖预算 $\alpha+\beta+\delta_{\text{msd}}$。**
- **定义 237（记忆时效与变点复核 MSD）**：记忆给出阶段签名分布 $p_m(\rho\mid q)$。用 e-process $E_t=\prod_{i=1}^{t}\frac{p_1(\rho_i)}{p_m(\rho_i)}$ 检验 $H_0$：当前观测仍与记忆一致；Ville 不等式给出 $\mathbb{P}_{H_0}[\exists t\le T:E_t\ge 1/\delta]\le\delta$，故可 anytime-valid 地控制"假过期"。判 stale 当 $\log E_t\ge\log(1/\delta)$；平均检出延迟 $\mathbb{E}[\tau]\le\log(1/\delta)/D_{\mathrm{KL}}(p_1\|p_m)$。地点不可观测或记忆缺失时输出 `unobservable`。**离开现场期间没有观测，MSD 停摆，只有年龄膨胀 $\nu\Delta t$ 在防守。**
- **定义 238（位姿条件计量学 PCM）**：F/T 读数 $f_t=f_{\text{true}}+b(x_b,m,T)+n_t$。记忆存标定锚点 $\{(x_{b,i},m_i,T_i,b_i)\}$，用 GP/克里金预测 $\hat b(x_b,m,T)$ 与 $\sigma_b^2(x_b,m,T)$；安全用保守上界 $b_{\max}=\hat b+k_\sigma\sigma_b$。力残差用 $f-b_{\max}$。底盘倾覆裕度 $\rho_{\text{tip}}=g(\text{坡度},a_b,\text{CoM},\text{支撑多边形})$ 也按地点记忆。离开标定凸包即 `metrology_extrapolated`，强制 `null_test` 并膨胀 $r_{\text{force}}$。
- **定义 239（记忆失效假设与条件归因）**：在 VISTA 的 $\mathcal{H}$ 上增 $\mathcal{H}_m=\mathcal{H}\cup\{H_{\text{mem}},H_{\text{place}}\}$。$H_{\text{mem}}$：记忆内容过期/错误；$H_{\text{place}}$：锚定或别名错误。判别签名：**通道间一致、但整体与记忆预测冲突** → $H_{\text{mem}}$；冲突随地点后验跳变而跳变 → $H_{\text{place}}$；通道间互相冲突而记忆无预测 → 退回 VISTA 的 $H_{\text{geo}}/H_{\text{force}}/H_{\text{vis}}$。三阶段签名矩阵 $S$ 增两列，需要"重访对比"（同地点不同时间）与"地点对比"（不同地点同物体）才可辨识。
- **定义 240（记忆感知信息价值 MVI）**：状态含记忆态 $m\in\{\text{valid},\text{stale},\text{unobservable}\}$、地点态与任务。动作集 $\{\text{trust},\text{probe},\text{revisit},\text{consolidate},\text{retreat}\}$。选择
  $a^*=\arg\max_a \mathrm{VOI}_m(a)-\mathrm{Cost}(a)-\mathrm{Risk}(a)$，s.t. 预测力/形变/倾覆约束；$\mathrm{VOI}_m$ 为分辨记忆态带来的期望决策代价下降。信任记忆的门槛 $p_v>c_{\text{probe}}/(c_{\text{probe}}+c_{\text{stale}})$；不满足则按无记忆 VISTA 探测。**记忆不取消探针，只改变探针的价格。**
- **定义 241（记忆条件安全证书与认证前缀 MSC/CSC-M）**：对块 $A_t$、前缀 $k$，在记忆增强后验的支持集上逐一验证 $\rho_{\text{safe}}\ge0$，用记忆分层 conformal（按地点/物体类做 Mondrian 校准；样本不足回退全局分位数）选最小 $k$ 使 $\mathbb{P}[\exists s\le k:\text{越界}]\le\alpha_{\text{chunk}}$。记忆无效时 $k^*$ 只按无记忆 VISTA 计算；记忆有效时才允许用记忆收缩残差界。约束 $k^*\le m$。
- **定义 242（RSC-M / WCV-M 记忆定向鲁棒编译）**：新增 $r_{\text{mem}}$，融合半径 $r=\sqrt{r_{\text{geo}}^2+r_{\text{force}}^2+r_{\text{model}}^2+r_{\text{mem}}^2}$。只在 $H_{\text{mem}}$/过期/别名时膨胀 $r_{\text{mem}}$；$H_{\text{mem}}$ 时**不**动 $r_{\text{geo}}$。WCV-M 用记忆做候选排序与热启动，但认证只用 $\mathcal{A}_\alpha$（及 valid 时的 $\mathcal{M}_\beta$）；$\mathcal{U}_m=\varnothing$ 或冲突时置 `memory_conflict=True` 并回退无记忆域。
- **定义 243（CSP-M 重访感知块级规划）**：状态增记忆年龄；块边需 Valid(J_memento) 且 $k^*\ge1$。新增元技能 `revisit_anchor`、`recalibrate_null`、`memory_probe`、`consolidate`、`invalidate`；代价含导航时间、记忆维护时间与过期风险。允许规划器**顺路**经过标定地标以复核记忆。
- **定义 244（记忆写入门控与两级合并 MCW）**：情景缓冲（会话内、非安全权威、自动过期）与合并语义记忆（经门控、版本化、可作安全证据）。写入条件：仅语义流；溯源完整；与现有记忆一致性检查（冲突入隔离区不覆盖）；签名/授权；带过期时间与版本；负记忆需证据。合并时冲突只增方差、不覆盖；**冲突证据绝不降低不确定性**。
- **定义 245（记忆自确认防护与负记忆）**："免探针折扣"仅在本次访问已复核（MSD valid 且年龄 $\le\tau_{\max}$）时允许；负记忆只能增加谨慎。定义自确认风险 $\le\delta_{\text{msd}}+\mathbb{P}[\text{age}>\tau_{\max}]$，并计入安全预算。
- **定义 246（AIC-M 对抗记忆认证）**：$\mathcal{E}_M=\mathcal{E}_V\times\mathcal{E}_{\text{poison}}\times\mathcal{E}_{\text{replay}}\times\mathcal{E}_{\text{alias}}\times\mathcal{E}_{\text{forget}}$。认证要求：记忆不得单独为安全作证；写入需授权；别名必须拒绝或降级；可回滚/隔离；最坏情形下仍能退回无记忆 VISTA。
- **定义 247（MEMENTO 证书 J_memento）**：$J_{\text{memento}}=(J_{\text{vista}},\text{memory\_prov\_hash},\text{memory\_age},\text{anchor\_cov},\text{place\_posterior\_hash},\text{memory\_valid},\text{staleness\_stat},\text{memory\_used\_for\_safety},r_{\text{mem}},\text{revisit\_plan\_hash},\text{memory\_conflict},\text{aic\_m\_ver})$。
  Valid $\Leftrightarrow$ Valid($J_{\text{vista}}$) $\wedge$ ($\neg$memory\_used\_for\_safety $\vee$ (memory\_valid $\wedge$ place\_observable $\wedge$ age$\le\tau_{\max}$ $\wedge$ prov 完整)) $\wedge$ (memory\_conflict $\Rightarrow$ 已回退无记忆) $\wedge$ (place\_unobservable $\Rightarrow$ 未用记忆作安全证据) $\wedge k^*\ge1$。
- **定义 248（MEMENTO 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→FIR/H_mem→PLM 检索→MAR 锚定→MGP 接地→MSD 复核→MVI（信任/探针/重访/合并）→PCM→WCV-M→CSP-M→CSC-M→Shield→执行 $k^*$→EV_exec→RSC-M→OLP→DIR→SSB→MCW 合并→AIC-M]；实时流 [锚点读→残差/阶段采集→记忆条件早停→前馈/投影→π_σ 前缀派发→J_memento 构建]。

    if csc_m.monitor_step(a, post, memory_valid).abort:

# 写入门控：实时流绝不写；语义流合并前先隔离冲突（低频）
if session_end and provenance_ok and authorized:
    mcw.consolidate(episodes, existing=plm, on_conflict='quarantine')
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（记忆条件覆盖）**：若当前证据覆盖 $\mathbb{P}[\theta^*\in\mathcal{A}_\alpha]\ge1-\alpha$，记忆覆盖 $\mathbb{P}[\theta^*\in\mathcal{M}_\beta]\ge1-\beta$，MSD 的假有效概率 $\le\delta_{\text{msd}}$，则 $\mathbb{P}[\theta^*\in\mathcal{U}_m]\ge1-\alpha-\beta-\delta_{\text{msd}}$。故记忆不是免费信息：它从安全预算里"借"覆盖，必须在证书里显式记账。
- **引理 10（时效与变点复核的延迟下界/上界）**：Ville 保证 anytime-valid 假过期 $\le\delta$；e-process 的平均检出延迟 $\le\log(1/\delta)/D_{\mathrm{KL}}(p_1\|p_m)$。但**离开现场期间没有观测**，MSD 无法工作，只有 $\Sigma_{\text{entry}}(\Delta t)$ 的年龄膨胀在防守——这解释了为什么"重访间隔"本身是安全参数，而不只是效率参数。
- **定理 11（MEMENTO 端到端记忆接地安全）**：在 A107–A113 下，Valid($J_{\text{memento}}$) $\Rightarrow$ (i) 安全对记忆条件不确定集 $\mathcal{U}_m$ 成立；(ii) 记忆只在本次复核通过时收缩集合，过期/别名/冲突时退回无记忆 VISTA，安全性不劣于第 65 轮（模 $\delta_{\text{msd}}$）；(iii) 记忆不改变几何球与力球的归因处置，只增加 $r_{\text{mem}}$；(iv) 实时路径零记忆写，$\le2.5$ms。
- **定理 12（记忆价值与重访调度）**：设探针成本 $c_p$、过期误用风险 $c_s$、记忆有效概率 $p_v$，则使用记忆优于无记忆当且仅当 $p_v>p^*=c_s/(c_p+c_s)$。若过期风险率为常数 $\lambda$（$p_v(\tau)=e^{-\lambda\tau}$），按周期 $\tau$ 重访的长期平均代价为 $c_r/\tau+c_s\lambda\tau/2$，最优重访间隔 $\tau^*=\sqrt{2c_r/(c_s\lambda)}$；由信任门槛还可反解最大间隔 $\tau_{\max}=-\ln p^*/\lambda$。**记忆的"保鲜期"是可计算的，不是经验设定的。**
- **记忆自确认命题**：若"免探针"不要求本次复核，则一旦记忆过期且 MSD 漏检，系统将反复跳过唯一能证伪它的观测，错误随访问次数单调固化；要求"本次复核 + 年龄上限 + 负记忆只增谨慎"后，未检测过期被用于安全的概率被 $\delta_{\text{msd}}+\mathbb{P}[\text{age}>\tau_{\max}]$ 上界。
- **实时性**：PLM/MAR/MGP/MSD/MVI/PCM/CSP-M/MCW/AIC-M 全在语义流；实时流只增锚点读取（$O(1)$）、记忆条件早停（$\le0.05$ms）、前馈/投影（$\le0.3$ms），目标 $\le2.5$ms（A114 修订契约）。

## 2. 形式化定义（完整版）

**定义 233（MEMENTO 闭环）** MEMENTO 是 VISTA 的"跨访问记忆接地 + 移动平台计量学"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 PLM（地点索引长期记忆）、MAR（锚定与别名拒绝）、MGP（记忆接地先验）、MSD（时效与变点复核）、PCM（位姿条件计量学）、MVI（记忆感知信息价值）、MSC/CSC-M（记忆条件证书与前缀）、RSC-M/WCV-M（记忆定向鲁棒编译）、CSP-M（重访感知块级规划）、MCW（写入门控与两级合并）、AIC-M（对抗记忆认证），并升级 J_vista→J_memento。不变式：**记忆检索、锚定、接地、复核、规划、合并与证书只发生在语义流与低频线程；实时路径只做锚点读取、残差与阶段采集、记忆条件前缀执行、早停、投影与派发，零记忆写操作、零学习写操作。**

**定义 234（地点索引长期记忆 PLM）** 记忆库
$$\mathcal{M}=\mathcal{M}_{\text{epi}}\cup\mathcal{M}_{\text{sem}}\cup\mathcal{M}_{\text{pro}}\cup\mathcal{M}_{\text{met}}\cup\mathcal{M}_{\text{neg}},$$
分别为情景（某次访问某地的观测-动作-结果）、语义（物体刚度/摩擦/几何类先验）、程序（技能与块签名分布）、计量（F/T 偏置、重力、坡度、稳定包络）、负记忆（失败、近失、被否定条目）。条目
$$e=(\mathrm{id},\kappa,z,o,s,\tau,\varphi,\mathrm{prov},\nu),$$
其中 $z$ 为地点锚（place id + 相对位姿），$o$ 为物体描述，$s$ 为技能/块签名，$\tau$ 为时间戳，$\varphi$ 为内容（先验/标定/结果/故障后验），$\mathrm{prov}$ 为溯源（传感器与标定版本哈希、会话 id、写入签名），$\nu$ 为版本。检索
$$\mathcal{R}(q_t)=\{(e_i,w_i)\}_{i=1}^{k},\qquad q_t=(z_t,o_t,s_t),$$
$w_i$ 为地点、物体与技能相似度的归一化混合；返回的是**混合候选**而非单一答案，因为别名与物体混淆必须被保留到 MAR/MSD 处理。**负记忆的语义是"此地/此物/此技能曾经失败"，它只能增加谨慎，不能减少谨慎。**

**定义 235（记忆锚定与感知别名 MAR）** 底盘位姿 $x_b^t$ 与协方差 $\Sigma_b$（来自 LSF/SLAM）。地点后验
$$p(z\mid \text{img},\text{map})=\sum_{j}\pi_j\delta_{z_j}+p_{\text{cont}}(z),$$
锚定协方差
$$\Sigma_z=\Sigma_b+J_z\Sigma_{\text{place}}J_z^\top,$$
其中 $J_z$ 为地点坐标到当前任务坐标的雅可比。别名熵
$$H_{\text{alias}}=-\sum_j\pi_j\log\pi_j.$$
若 $H_{\text{alias}}>\tau_{\text{alias}}$ 或 $\operatorname{tr}(\Sigma_z)>\tau_{\text{anchor}}$ 或地点后验在访问间发生不连续跳变，则置 `place_unobservable=True`。此时记忆**不得作为安全证据**，仅可用于候选排序与主动重访建议。理由：在错误坐标系里，记忆可以完全自洽；它不会表现为"误差大"，而会表现为"一切都很顺"。

**定义 236（记忆接地先验 MGP）** 把检索到的混合候选按权重与溯源质量聚合成记忆先验 $(\mu_m,\Sigma_m)$，其中
$$\Sigma_{\text{mem}}=\Sigma_{\text{entry}}(\Delta t)+J_z\Sigma_zJ_z^\top+\Sigma_{\text{alias}},$$
$$\Sigma_{\text{entry}}(\Delta t)=\Sigma_0+(\Sigma_\infty-\Sigma_0)\bigl(1-e^{-\Delta t/\tau_{\text{mem}}}\bigr).$$
若漂移动力学未知，用保守线性上界 $\Sigma_0+\nu\Delta t$。记忆覆盖集
$$\mathcal{M}_\beta(q)=\Bigl\{\theta:(\theta-\mu_m)^\top\Sigma_{\text{mem}}^{-1}(\theta-\mu_m)\le\chi^2_{d,1-\beta}\Bigr\}.$$
记忆条件不确定集
$$\mathcal{U}_m=\begin{cases}\mathcal{A}_\alpha(\rho_t)\cap\mathcal{M}_\beta(q), & \text{MSD}=\text{valid}\ \wedge\ \neg\text{place\_unobservable}\ \wedge\ \text{prov 完整},\\[2pt]\mathcal{A}_\alpha(\rho_t), & \text{否则}.\end{cases}$$
关键性质：**相交只会缩小集合**，所以记忆不可能让证书比无记忆更保守；但相交会把覆盖从 $1-\alpha$ 降到 $1-\alpha-\beta-\delta_{\text{msd}}$，所以记忆必须"付费"使用。若 $\mathcal{A}_\alpha\cap\mathcal{M}_\beta=\varnothing$，置 `memory_conflict=True` 并退回 $\mathcal{A}_\alpha$，同时把冲突写入负记忆候选（不覆盖旧条目）。

**定义 237（记忆时效与变点复核 MSD）** 记忆给出阶段签名 $\rho$ 的预测分布 $p_m(\rho\mid q)$。取备择 $p_1$（例如第 65 轮离线故障注入下"已变化"的签名分布），定义 e-process
$$E_t=\prod_{i=1}^{t}\frac{p_1(\rho_i)}{p_m(\rho_i)},\qquad E_0=1.$$
在 $H_0$（记忆仍有效）下 $\mathbb{E}_{H_0}[p_1(\rho)/p_m(\rho)]=\int p_1=1$，故 $E_t$ 是非负鞅。Ville 不等式给出 anytime-valid 假过期控制：
$$\mathbb{P}_{H_0}\bigl[\exists t\le T:E_t\ge 1/\delta_{\text{msd}}\bigr]\le\delta_{\text{msd}}.$$
判 stale 当 $\log E_t\ge\log(1/\delta_{\text{msd}})$；平均检出延迟满足 $\mathbb{E}[\tau]\le\log(1/\delta_{\text{msd}})/D_{\mathrm{KL}}(p_1\|p_m)$（Wald/Shiryaev-Roberts 近似）。MSD 输出三态 $\{\text{valid},\text{stale},\text{unobservable}\}$：
- `valid`：$E_t<1/\delta_{\text{msd}}$ 且地点可观测；
- `stale`：$E_t\ge1/\delta_{\text{msd}}$；
- `unobservable`：地点不可观测、记忆缺失或预测分布未校准。

**必须强调**：离开现场期间没有观测，e-process 停摆；此时唯一防守是 $\Sigma_{\text{entry}}(\Delta t)$ 的年龄膨胀。因此"重访间隔"本身是安全参数（见定理 12），不能只当效率参数。

**定义 238（位姿条件计量学 PCM）** F/T 读数
$$f_t=f_{\text{true}}+b(x_b,m,T)+n_t,$$
其中 $b$ 为随底盘位姿（重力投影、安装角）、负载与温度变化的零偏。记忆存标定锚点
$$\mathcal{D}_{\text{met}}=\{(x_{b,i},m_i,T_i,b_i)\}_{i=1}^{n},$$
用 GP/克里金预测
$$\hat b(x_b,m,T)=\mathbf{k}^\top(K+\sigma_n^2I)^{-1}\mathbf{b},\qquad \sigma_b^2(x_b,m,T)=k(x,x)-\mathbf{k}^\top(K+\sigma_n^2I)^{-1}\mathbf{k}.$$
安全残差用区间算术取最坏：
$$e_{\text{force}}^{\max}=\max_{b\in[\hat b-k_\sigma\sigma_b,\ \hat b+k_\sigma\sigma_b]}\bigl\|\Sigma_w^{-1/2}(f_t-f_{\text{model}}-b)\bigr\|.$$
若 $(x_b,m,T)$ 落在标定凸包外，置 `metrology_extrapolated=True`，强制 `null_test`（零力窗重标定）并膨胀 $r_{\text{force}}$。倾覆裕度
$$\rho_{\text{tip}}=g(\text{坡度},a_b,\text{CoM},\text{支撑多边形})$$
用**当前 IMU/本体感觉**计算，记忆中的地点坡度只作前瞻与规划先验，绝不作安全真值。**底盘加减速会在零力窗注入惯性伪力；若不用 PCM 去偏，VISTA 的阶段化签名会被污染，H_force 与 H_geo 再次不可辨识。**

**定义 239（记忆失效假设与条件归因）** 在 VISTA 的 $\mathcal{H}$ 上增
$$\mathcal{H}_m=\mathcal{H}\cup\{H_{\text{mem}},H_{\text{place}}\}.$$
- $H_{\text{mem}}$：记忆不再匹配当前世界（过期、漂移、或世界确实变了）。**无论"记忆错了"还是"世界变了"，安全处置相同：撤销记忆的安全权威。**
- $H_{\text{place}}$：锚定/别名错误，记忆属于另一个地点。

判别签名用两个创新量：
- $e_c$：当前通道间创新（视觉 vs 力/几何）；
- $e_m$：当前观测 vs 记忆预测创新。

| 情形 | $e_c$ | $e_m$ | 归因 | 安全处置 |
|---|---|---|---|---|
| 健康 | 小 | 小 | $H_0$ | 可用记忆 |
| 几何幻觉 | 大（视觉/几何方向） | 可能大 | $H_{\text{geo}}$ | 走 VISTA 处置，不写记忆 |
| F/T 偏置 | 大（力通道） | 大（若记忆期望无偏） | $H_{\text{force}}$ | 零力窗重标定，更新 PCM |
| 视觉错 | 大（视觉通道） | 可能大 | $H_{\text{vis}}$ | 降 $w_{\text{vis}}$，不写记忆 |
| 记忆过期/世界变 | **小** | **大** | $H_{\text{mem}}$ | 撤销记忆、重访/合并 |
| 地点别名 | 可能小 | 大且随地点后验跳变 | $H_{\text{place}}$ | 拒绝记忆、主动重定位 |

**可辨识性不再要求区分"记忆错"与"世界变"**：两者都导致 $e_m$ 大而 $e_c$ 小，安全响应都是撤销记忆；区别只在后续是"合并新记忆"还是"先归因再决定是否写"。这显著降低了记忆故障的辨识负担，也避免把世界变化误判为传感器故障。

**定义 240（记忆感知信息价值 MVI）** 状态含记忆态 $m\in\{\text{valid},\text{stale},\text{unobservable}\}$、地点态与任务。动作集
$$\mathcal{A}_{\text{mem}}=\{\text{trust},\text{probe},\text{revisit},\text{consolidate},\text{retreat}\}\cup A_{\text{AFA}},$$
其中 `revisit` 为回到已知地标/ vantage 重新锚定，`consolidate` 为在当前证据一致时写入新记忆。选择
$$a^*=\arg\max_{a}\ \mathrm{VOI}_m(a)-\mathrm{Cost}(a)-\mathrm{Risk}(a),$$
s.t. 预测 $f_n\le f_{\lim}$、形变 $\le\varepsilon_{\text{strain}}$、倾覆裕度 $\ge0$、视觉/力早停可用。$\mathrm{VOI}_m(a)$ 为分辨记忆态带来的期望决策代价下降（不是故障标签的熵）。**信任门槛**：当
$$p_v=\mathbb{P}(m=\text{valid}\mid\text{证据})>\frac{c_{\text{stale}}}{c_{\text{probe}}+c_{\text{stale}}}=p^*$$
且本次访问已复核、年龄 $\le\tau_{\max}$ 时，才允许 `trust`（免探针）；否则按无记忆 VISTA 探测。**记忆不取消探针，只改变探针的价格；探针的停止权在"本次复核"，不在"历史置信度"。**

**定义 241（记忆条件安全证书与前缀 MSC/CSC-M）** 对块 $A_t$、前缀 $k$，在记忆增强后验的支持集上逐一验证 $\rho_{\text{safe}}\ge0$：
$$\rho_{\text{safe}}(k)=\min_{H\in\operatorname{supp}_\delta(\text{post})}\ \min_{s\le k}\ \min_j\ \rho_j(s;H,\mathcal{U}_m)\ge0.$$
用**分层（Mondrian）conformal** 按地点/物体类校准残差分位数 $q_{c}(\alpha)$；若某类样本 $n_c<n_{\min}$，回退全局分位数（更保守），并置 `conformal_fallback=True`。选最小 $k$ 使
$$\mathbb{P}\bigl[\exists s\le k:\text{某通道越界}\bigr]\le\alpha_{\text{chunk}},$$
约束 $k^*\le m$（不可逆视界）。记忆无效时，$k^*$ 只按 $\mathcal{A}_\alpha$ 计算；记忆有效时才允许用 $\mathcal{M}_\beta$ 收缩残差界。**记忆只能让 $k^*$ 更精确，不能让它越过 $m$。**

**定义 242（RSC-M / WCV-M 记忆定向鲁棒编译）** 维护 $r_{\text{geo}},r_{\text{force}},r_{\text{model}},r_{\text{mem}}$ 与视觉信任 $w_{\text{vis}}$。融合半径
$$r=\sqrt{r_{\text{geo}}^2+r_{\text{force}}^2+r_{\text{model}}^2+r_{\text{mem}}^2}.$$
只在 $H_{\text{mem}}$/过期/别名/`metrology_extrapolated` 时膨胀 $r_{\text{mem}}$；$H_{\text{mem}}$ 时**不**动 $r_{\text{geo}}$，$H_{\text{place}}$ 时**不**动 $r_{\text{force}}$。WCV-M 搜索域
$$\mathcal{B}(\hat\theta,r)\cap\mathcal{G}(g)\cap\mathcal{K}(\hat\mu)\cap\mathcal{F}(f_{\lim})\cap\mathcal{V}\cap\mathcal{C}_{\text{mem}},$$
其中 $\mathcal{C}_{\text{mem}}$ 为记忆可观测性约束（valid 或 `memory_conflict` 时为空）。记忆只用于候选排序/热启动；认证只用 $\mathcal{A}_\alpha$（及 valid 时的 $\mathcal{M}_\beta$）。若交集为空或冲突，回退无记忆域并置 `memory_conflict=True`。

**定义 243（CSP-M 重访感知块级规划）** 在 CSP-V 的块级图上，状态增记忆年龄与地点后验；块边需 Valid($J_{\text{memento}}$) 且 $k^*\ge1$。新增元技能：
- `revisit_anchor`：回到已知地标/多视角点，降低 $\Sigma_z$ 与 $H_{\text{alias}}$；
- `recalibrate_null`：零力窗重标定，更新 $\mathcal{D}_{\text{met}}$；
- `memory_probe`：设计一个能区分 $H_{\text{mem}}$ 与 $H_{\text{geo}}/H_{\text{force}}$ 的轻接触/视觉探针；
- `consolidate`：当前通道一致时写入新情景/语义记忆；
- `invalidate`：把冲突/失败条目降级为负记忆或隔离。

代价含导航时间、记忆维护时间与过期风险；规划器可"顺路"经过标定地标以复核记忆。**移动底盘第一次让"记忆维护"可以成为任务规划的一部分，而不是额外开销。**

**定义 244（记忆写入门控与两级合并 MCW）** 记忆分两级：
- **情景缓冲** $\mathcal{B}_{\text{epi}}$：会话内、非安全权威、自动过期；
- **合并记忆** $\mathcal{M}_{\text{con}}$：经门控、版本化、可作安全证据。

写入条件（全部满足）：
1. 只在语义流/低频线程写，实时流零写；
2. 溯源完整（传感器/标定/坐标变换哈希、会话 id、写入者签名）；
3. 与现有记忆一致性检查：冲突条目不覆盖，进入隔离区 $\mathcal{Q}$，置 `memory_conflict=True`；
4. 带过期时间与版本 $\nu$；
5. 负记忆需至少一次可复核证据（近失、失败、或明确的 $H_{\text{mem}}$ 撤销）；
6. 写入后不得降低任何安全相关半径；冲突证据只能**增大**方差。

合并规则：
$$\Sigma_{\text{new}}^{-1}=\Sigma_{\text{old}}^{-1}+\Sigma_{\text{obs}}^{-1}\quad\text{仅当一致性检验通过};$$
冲突时不融合，保留两条并提升方差，等待重访裁决。**记忆系统的正确性不取决于"记得多"，而取决于"知道哪条不该信"。**

**定义 245（记忆自确认防护与负记忆）** "免探针折扣"（no-probe discount）仅在本次访问已复核（MSD=`valid` 且年龄 $\le\tau_{\max}$ 且 `place_observable`）时允许。定义自确认风险
$$R_{\text{compl}}=\mathbb{P}[\text{stale}\wedge\text{used for safety}]\le\delta_{\text{msd}}+\mathbb{P}[\text{age}>\tau_{\max}].$$
负记忆条目只能增加谨慎：它可以把 `trust` 降级为 `probe`，不能把 `probe` 升级为 `trust`；删除负记忆需要比写入更强的证据与授权。**负记忆是安全系统的"不应期"，不是可优化的缓存。**

**定义 246（AIC-M 对抗记忆认证）** 干扰集
$$\mathcal{E}_M=\mathcal{E}_V\times\mathcal{E}_{\text{poison}}\times\mathcal{E}_{\text{replay}}\times\mathcal{E}_{\text{alias}}\times\mathcal{E}_{\text{forget}}\times\mathcal{E}_{\text{common}},$$
含对抗 patch/光照/透明/遮挡、记忆投毒（伪造成功示范、篡改标定）、重放（旧会话/旧地点）、感知别名（相似工位/货架）、选择性遗忘（只删负记忆）、共因失效（同一 OOD 物体同时骗视觉与记忆）。认证要求：
1. 记忆不得单独为安全作证；
2. 写入需授权、溯源与版本；
3. 别名必须拒绝或降级；
4. 可回滚/隔离；
5. 最坏情形下仍能退回无记忆 VISTA；
6. 共因故障下不要求归因正确，只要求判 `memory_conflict`/`place_unobservable` 并安全降级。
$J_{\text{dir}}$ 增 `memory_calib_ver`、`memory_write_auth_ver`、`memory_attack_ver`。

**定义 247（MEMENTO 证书 J_memento）**
$$J_{\text{memento}}=(J_{\text{vista}},\text{memory\_prov\_hash},\text{memory\_age},\text{anchor\_cov},\text{place\_posterior\_hash},\text{memory\_valid},\text{staleness\_stat},\text{memory\_used\_for\_safety},r_{\text{mem}},\text{revisit\_plan\_hash},\text{memory\_conflict},\text{aic\_m\_ver}).$$
验证规则：
$$\mathrm{Valid}(J_{\text{memento}})\Leftrightarrow \mathrm{Valid}(J_{\text{vista}})
\wedge\bigl(\neg\text{memory\_used\_for\_safety}\vee(\text{memory\_valid}\wedge\text{place\_observable}\wedge\text{age}\le\tau_{\max}\wedge\text{prov完整})\bigr)$$
$$\wedge(\text{memory\_conflict}\Rightarrow\text{已回退无记忆域})\wedge(\text{place\_unobservable}\Rightarrow\neg\text{memory\_used\_for\_safety})\wedge k^*\ge1\wedge\text{aic\_m\_ver 当前}.$$
审计链新增：**这条记忆从哪来、多老、锚在哪、这次复核过没有、它是否被用于安全、冲突时是否已退回**。

**定义 248（MEMENTO 闭环算子）** 语义流：
$$\text{LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→FIR}/H_{\text{mem}}
\to\text{PLM}\to\text{MAR}\to\text{MGP}\to\text{MSD}\to\text{MVI}
\to\text{PCM}\to\text{WCV-M}\to\text{CSP-M}\to\text{CSC-M}\to\text{Shield}
\to\text{执行 }k^*\to\text{EV\_exec}\to\text{RSC-M}\to\text{OLP}\to\text{DIR}\to\text{SSB}\to\text{MCW}\to\text{AIC-M}.$$
实时流：
$$\text{锚点读}\to\text{残差/阶段采集}\to\text{记忆条件早停}\to\text{前馈/投影}\to\pi_\sigma\text{ 前缀派发}\to J_{\text{memento}}\text{ 构建}.$$

class PlaceIndexedMemory:
    def __init__(self, con, max_age, nu):
        self.con = con                      # SQLite + FAISS/annoy 索引
        self.max_age, self.nu = max_age, nu

    def retrieve(self, place_id, obj_desc, skill_id, k=8):
        cand = self.con.search(place_id, obj_desc, skill_id, k)
        # 混合候选：地点/物体/技能相似度 + 溯源质量
        w = softmax([0.5*c.place_sim + 0.3*c.obj_sim + 0.2*c.skill_sim
                     + 0.1*c.prov_quality for c in cand])
        return [(c, wi) for c, wi in zip(cand, w)]

    def aged_cov(self, base_cov, age, inf_cov=None):
        # OU 饱和膨胀；未知动力学用线性上界
        if inf_cov is None:
            return base_cov + self.nu * age * np.eye(len(base_cov))
        return base_cov + (inf_cov - base_cov) * (1 - np.exp(-age / self.max_age))


class MemoryAnchor:
    def anchor(self, x_b, Sigma_b, img, place_map, entries):
        place_post = self.recognize(img, place_map)      # mixture over places
        H_alias = entropy(place_post.w)
        Sigma_place = mixture_cov(place_post)
        Jz = place_to_task_jacobian(place_post.mode, x_b)
        Sigma_z = Sigma_b + Jz @ Sigma_place @ Jz.T
        unobservable = (H_alias > TAU_ALIAS or
                        np.trace(Sigma_z) > TAU_ANCHOR or
                        self.discontinuity(place_post))
        return Anchor(place_post, Sigma_z, H_alias, unobservable)


class MemoryGrounding:
    def ground(self, entries, anchor, age, beta):
        mu, Sig = mixture_to_gaussian(entries)
        Sig_mem = self.aged_cov(Sig, age) + anchor.Jz @ anchor.Sigma_z @ anchor.Jz.T
        if anchor.H_alias > TAU_ALIAS:
            Sig_mem += SIG_ALIAS
        return mu, Sig_mem


class StalenessDetector:
    def __init__(self, p_alt, delta_msd=0.05):
        self.p_alt, self.delta_msd = p_alt, delta_msd
        self.logE = 0.0

    def test(self, rho, p_mem):
        llr = np.log(self.p_alt(rho) + 1e-12) - np.log(p_mem(rho) + 1e-12)
        self.logE += llr
        if self.logE >= np.log(1.0 / self.delta_msd):
            return 'stale', self.logE
        return 'valid', self.logE

class PoseConditionedMetrology:
    def __init__(self, anchors, k_sigma=2.5):
        self.X, self.b = anchors
        self.gp = fit_gp(self.X, self.b)      # pose(6D)+payload+temp -> bias(6D)
        self.k_sigma = k_sigma

    def predict(self, x_b, payload, temp):
        mu_b, var_b = self.gp.predict([x_b, payload, temp])
        sigma = np.sqrt(np.maximum(var_b, 1e-12))
        lo, hi = mu_b - self.k_sigma * sigma, mu_b + self.k_sigma * sigma
        extrap = not inside_convex_hull(self.X[:, :6], x_b)
        return lo, hi, extrap

    def worst_force_residual(self, f_meas, f_model, lo, hi, Sigma_w):
        W_inv = inv_sqrt(Sigma_w)
        # 区间最坏：对每个偏置分量取使残差最大的端点
        b_worst = np.where((f_meas - f_model) >= 0, lo, hi)
        return np.linalg.norm(W_inv @ (f_meas - f_model - b_worst))

    def tip_margin(self, slope, a_base, com, support):
        # 只用当前 IMU/本体感觉；记忆中的坡度只作规划先验
        com_proj = project_com(com, slope, a_base)
        return signed_distance(com_proj, support)

class MemoryValueOfInformation:
    ACTIONS = ('trust', 'probe', 'revisit', 'consolidate', 'retreat')

    def choose(self, post, U_m, memory_state, p_valid, age, probes):
        cands = []
        if (memory_state == 'valid' and age <= TAU_MAX and p_valid > self.p_star()):
            cands.append(('trust', self.voi_trust(U_m)))
        for a in probes:                          # 含 AFA 物理/视觉探针
            if self.safe(a):
                cands.append((a, self.voi_probe(post, a)))
        if self.revisit_feasible():
            cands.append(('revisit', self.voi_revisit(p_valid)))
        if self.channels_agree():
            cands.append(('consolidate', self.voi_consolidate()))
        if not cands:
            return 'retreat', 0.0
        return max(cands, key=lambda z: z[1] - self.cost(z[0]) - self.risk(z[0]))

    def p_star(self):
        return self.c_stale / (self.c_probe + self.c_stale)

def certified_prefix_m(A, post, U_m, m, alpha_chunk, memory_used, memory_valid):
    support = {h: p for h, p in post.items() if p >= DELTA_SUP}
    top = sorted(support, key=support.get, reverse=True)[:2]
    if not (memory_used and memory_valid):
        U_m = current_evidence_set()              # 记忆无效：只用当前证据
    k_best = 0
    for k in range(1, min(len(A), m) + 1):
        ok = all(safety_margin(A[s], h, U_m) >= 0
                 for h in top for s in range(k))
        if not ok:
            break
        if violation_prob(A[:k], top, U_m, stratified=True) <= alpha_chunk:
            k_best = k
        else:
            break
    return k_best


def wcv_m_compile(phi_hat, balls, post, U_m, memory_valid, n_worst=8):

def MEMENTO_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    x_b, Sigma_b = M.lsf.base_pose()
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) 检索 + 锚定：记忆先过"能不能用"这一关
    q = (M.place_id(x_b), M.object_desc(img), M.ocb_skill.current())
    entries = M.plm.retrieve(*q)
    anchor = M.mar.anchor(x_b, Sigma_b, img, M.place_map, entries)
    age = M.clock.now() - max(e.tau for e, _ in entries)
    mu_m, Sig_mem = M.mgp.ground(entries, anchor, age, beta=M.beta)
    mem_state, stat = M.msd.test(M.residual_log.signature(), M.mgp.predictive(entries))
    use_mem = (mem_state == 'valid' and not anchor.unobservable
               and not anchor.metrology_extrapolated)
    U_m = M.evidence_set() if not use_mem else intersect(M.evidence_set(), (mu_m, Sig_mem))

    # 2) VISTA 单次管线（阶段、VCV、归因）
    A = M.ach.propose(x_prime, H=M.H)
    visual = M.vpg.verify_and_predict(M.f_vis(img, depth, flow), A, M.mws.last_contacts)
    phases = M.stage.split(M.residual_log, visual)
    post, h_star, ambiguous = M.fir.attribute(phases, hypotheses=H_M,
                                              prior=M.plm.priors(entries) if use_mem else None)

    # 3) 记忆感知决策：信任 / 探针 / 重访 / 合并
    if ambiguous or not use_mem:
        a, _ = M.mvi.choose(post, U_m, mem_state, p_valid=use_mem, age=age,
                            probes=AFA_PROBES + ('memory_probe', 'recalibrate_null'))
        if a in ('revisit_anchor', 'recalibrate_null', 'memory_probe'):
            M.execute_memory_maintenance(a)
            return MEMENTO_round(M, obs, delta_f_req)      # 复核后重跑
        if a == 'retreat':
            return safe_retreat(M)

    # 4) 规划 + 记忆条件前缀
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_m.plan_chunks(goal, x_prime, post, U_m, age, anchor)
    k_star = M.csc_m.certified_prefix(tau.A, post, U_m, M.m,
                                      M.alpha_chunk, memory_used=use_mem,
                                      memory_valid=use_mem)
    K_safe, EV_exec, cert_exec = realtime_step_memento(M, tau, k_star, x_prime, U_m)

    # 5) 在线更新 + 写入门控（纯语义流）
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile, visual, post),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc_m.update(EV_exec, post, anchor, mem_state, M.balls)
    conflict = (mem_state == 'stale' and channels_agree(phases))
    M.mcw.stage(episode=build_episode(phases, post, EV_exec),
                conflict=conflict, prov=provenance(M))
    if M.session_boundary():
        M.mcw.consolidate_all(authorized=M.auth.valid(), conflict=conflict)

    rho_dir = M.aic_m.certify(tau, x_prime, post, anchor, mem_state)
    return M, K_safe, EV_exec, build_j_memento(
        cert_exec, J_vista=M.j_vista, memory_prov_hash=hash(entries),
        memory_age=age, anchor_cov=trace(anchor.Sigma_z),
        place_posterior_hash=hash(anchor.place_post), memory_valid=use_mem,
        staleness_stat=stat, memory_used_for_safety=use_mem,
        r_mem=M.balls['r_mem'], revisit_plan_hash=hash(tau.memory_plan),
        memory_conflict=conflict, aic_m_ver=AIC_M_VERSION)
```

## 4. 推导

**引理 9（记忆条件覆盖）** 设 $G_A=\{\theta^*\in\mathcal{A}_\alpha\}$、$G_M=\{\theta^*\in\mathcal{M}_\beta\}$、$G_V=\{\text{MSD 未在记忆失效时误判 valid}\}$。在 $G_A\cap G_M\cap G_V$ 上，若使用记忆则 $\theta^*\in\mathcal{U}_m=\mathcal{A}_\alpha\cap\mathcal{M}_\beta$；若记忆失效且未被误判，则不使用记忆，$\theta^*\in\mathcal{A}_\alpha=\mathcal{U}_m$。由联合界，
$$\mathbb{P}[\theta^*\in\mathcal{U}_m]\ge1-\mathbb{P}[G_A^c]-\mathbb{P}[G_M^c]-\mathbb{P}[G_V^c]\ge1-\alpha-\beta-\delta_{\text{msd}}.$$
注意 $\beta$ 只在"记忆作为概率先验"的意义上有定义；对于确定性的过期记忆，$\mathbb{P}[G_M^c]=1$，此时必须靠 MSD 与年龄膨胀把它挡在安全证据之外。**推论：记忆不是免费信息，它从安全预算里借覆盖；证书必须显式记账 $\alpha+\beta+\delta_{\text{msd}}$。** ∎

**引理 10（时效复核的 anytime-valid 性与延迟）** 在 $H_0$ 下 $E_t=\prod p_1(\rho_i)/p_m(\rho_i)$ 满足 $\mathbb{E}_{H_0}[E_t\mid\mathcal{F}_{t-1}]=E_{t-1}$，故为非负鞅。Ville 不等式给出对任意停时 $T$：
$$\mathbb{P}_{H_0}\Bigl[\sup_{t\le T}E_t\ge\frac{1}{\delta_{\text{msd}}}\Bigr]\le\delta_{\text{msd}}.$$
故长期部署中假过期率不随访问次数累积。若真实分布为 $p_1$，Shiryaev-Roberts/Wald 近似给出 $\mathbb{E}[\tau]\lesssim\log(1/\delta_{\text{msd}})/D_{\mathrm{KL}}(p_1\|p_m)$。**但离开现场期间无观测，$E_t$ 不更新**；此时只能靠 $\Sigma_{\text{entry}}(\Delta t)$ 的年龄膨胀。**因此"多久重访一次"直接进入安全预算，而不是只进入效率预算。** ∎

**定理 11（MEMENTO 端到端记忆接地安全）** 在 A107–A113 下：
1. **记忆接地**：引理 9 给出 $\mathcal{U}_m$ 的覆盖；记忆只在 valid 且地点可观测时与当前证据相交，过期/别名/冲突时退回 $\mathcal{A}_\alpha$。
2. **归因不被记忆污染**：$H_{\text{mem}}$ 的签名是"通道间一致、整体与记忆冲突"，只触发撤销记忆与重访/合并；$H_{\text{geo}}/H_{\text{force}}/H_{\text{vis}}$ 仍由 VISTA 的通道间签名判定，记忆不改变几何球/力球的膨胀规则。
3. **物理伤害受控**：$k^*\le m$；记忆无效时 $k^*$ 只按无记忆 VISTA 计算；有记忆时只用 $\mathcal{M}_\beta$ 收缩残差界，不放松约束。
4. **不劣于第 65 轮**：当 $H_{\text{mem}}$/别名/过期/冲突发生时，MEMENTO 回退到 VISTA 的 $\mathcal{A}_\alpha$ 与无记忆证书，安全性不降低（模 $\delta_{\text{msd}}$）；当记忆有效时，$\mathcal{U}_m\subseteq\mathcal{A}_\alpha$，证书只会更紧。
5. **证书链**：Valid($J_{\text{memento}}$) 显式要求"若记忆用于安全，则本次复核、锚定可观测、年龄 $\le\tau_{\max}$、溯源完整"；否则必须回退无记忆域。
6. **实时性**：实时路径只读锚点、采集残差/阶段、做记忆条件早停与投影，零记忆写、零学习写，$\le2.5$ms（A114）。 ∎

**定理 12（记忆价值与重访调度）** 设探针成本 $c_p$、过期误用风险 $c_s$、记忆有效概率 $p_v$。使用记忆的期望代价为 $(1-p_v)c_p$（无效时仍探针）加上 $(1-p_v)c_s$ 的过期风险；无记忆代价为 $c_p$。故记忆优于无记忆当且仅当
$$(1-p_v)(c_p+c_s)<c_p\iff p_v>\frac{c_s}{c_p+c_s}=p^*.$$
若过期风险率为常数 $\lambda$，按周期 $\tau$ 重访并在每次重访后复核，长期平均代价为
$$J(\tau)=\frac{c_r}{\tau}+\frac{c_s\lambda\tau}{2},$$
其中 $c_r$ 为一次重访（导航 + 复核）成本，$c_s\lambda\tau/2$ 为周期内平均过期暴露风险（$\int_0^\tau(\tau-u)\lambda e^{-\lambda u}du\approx\lambda\tau^2/2$ 除以 $\tau$）。求导
$$J'(\tau)=-\frac{c_r}{\tau^2}+\frac{c_s\lambda}{2}=0\iff\tau^*=\sqrt{\frac{2c_r}{c_s\lambda}},\qquad J''(\tau^*)=\frac{2c_r}{\tau^{*3}}>0,$$
故 $\tau^*$ 为唯一最优。由信任门槛 $p_v(\tau_{\max})=e^{-\lambda\tau_{\max}}=p^*$ 反解
$$\tau_{\max}=-\frac{\ln p^*}{\lambda}=\frac{1}{\lambda}\ln\frac{c_p+c_s}{c_s}.$$
**结论：记忆的保鲜期与重访频率是可计算的；当 $c_r$ 大、$c_s$ 小、$\lambda$ 小时，重访可以很稀疏；当世界变得快（$\lambda$ 大）或过期代价高（$c_s$ 大）时，必须频繁复核。** ∎

**命题（记忆自确认的可证伪性）** 若"免探针"不要求本次复核，则存在一个正概率事件（记忆过期且 MSD 漏检）使系统在后续访问中反复跳过唯一能证伪记忆的观测；由于写回会把当前（可能错误的）结论合并进长期记忆，错误随访问次数单调固化。反之，若免探针要求本次 MSD=`valid`、年龄 $\le\tau_{\max}$、锚定可观测，则由引理 10 与定理 12，
$$\mathbb{P}[\text{过期记忆被用于安全}]\le\delta_{\text{msd}}+\mathbb{P}[\text{age}>\tau_{\max}]\le\delta_{\text{msd}}+1-e^{-\lambda\tau_{\max}}.$$
取 $\tau_{\max}=-\ln p^*/\lambda$ 可把第二项压到 $1-p^*$，再与 $\delta_{\text{msd}}$ 一起计入安全预算。**记忆可以是先验，但"是否相信记忆"必须是这一次的观测问题，而不是上一次的结论问题。** ∎

## 7. 已知风险

**一句话**：MEMENTO 的安全性依赖"MSD 的 anytime-valid 复核 + 年龄/锚定膨胀真的覆盖了非平稳性"这一假设；但离开现场期间没有任何观测，慢变或感知别名可以低于检出阈值地篡改记忆，而"免探针折扣"恰恰移除了唯一能证伪记忆的观测，跨会话写回又会让错误自我确认并持久化——**最坏情况不是"记忆错了"，而是"记忆被验证过一次、于是被更自信地信任，同时系统不再去验证它"**，这是本轮全部记忆接地与安全证书论证共同依赖的隐藏假设（A107）。

**次级风险与缓解**：
1. **离开期间不可观测**：MSD 停摆，只有年龄膨胀；缓解：把 $\tau_{\max}$ 写入证书、按定理 12 调度重访、对高风险地点提高 $\nu$ 或强制复核。
2. **感知别名**：相似地点导致坐标系错误且自洽；缓解：地点后验保留混合、别名熵阈值、主动重访多视角、负记忆记录别名对。
3. **记忆自确认**：免探针移除证伪观测；缓解：本次复核 + 年龄上限 + "无记忆对照探针"随机插入（类似审计），并把自确认风险计入预算。
4. **跨会话投毒/重放**：写入即持久化；缓解：两级记忆、写入门控、授权/版本/溯源、隔离区、可回滚；AIC-M 显式认证。
5. **负记忆退化**：过度谨慎导致任务不可行；缓解：负记忆带证据与过期，允许重访后降级，但降级需更强证据。
6. **分层 conformal 样本不足**：长尾地点覆盖名不副实；缓解：层级部分池化、回退全局分位数并置 `conformal_fallback`、把回退计入保守度。
7. **PCM 外推与 GP 过度自信**：新位姿/新负载下预测不可靠；缓解：凸包检测、保守 $k_\sigma$、强制 `null_test`、在线校准记忆。
8. **记忆与当前证据冲突时的规划瘫痪**：$\mathcal{U}_m=\varnothing$ 频繁触发回退；缓解：冲突隔离 + 主动重访 + 允许在安全基线上"边做边学"。
9. **实时预算**：锚点读取/早停/投影逼近 2.5ms；缓解：记忆索引与地点识别全部留语义流、ROI 降采样、事件触发、与 LSF 共享坐标变换。
