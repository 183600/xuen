# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「同步定位与建图」×「语言指令」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**世界版本 + 指代接地**。v9 用 AC/MW/ID 还了算力债、集成债、叙事债，但它的证书默认「地图稳定、目标正确」。本轮两个灵感正好击中这两个隐含前提：SLAM 是被修订、带不确定性的世界模型；语言指令是把意图绑定到地图实体与时空约束上的概率接地。核心升级不是再加一层阈值，而是给每张证书补上两条**结构有效性轴**——地图纪元（世界版本）与指代接地（语义版本）。

## 0. 直觉与动机

**灵感 1（SLAM → 世界版本债：证书不能跨纪元）**
直觉：v9 的块证书 Ĉ 是在某一版地图上算出来的；只要发生一次环路闭合或重定位，局部坐标系就被刚性变换 T_ρ 改写，最近障碍的方向、中止点间的距离、甚至数据关联（哪个簇是「那个杯子」）都会变。v9 用 20 帧滑窗的 Δ_dom 去门控 K_eff，但地图跳变是**离散、瞬时**的，滑窗在结构上慢一拍——「最需要安全的时刻暴露最不可靠的证书」由此而来。核心创新：**地图纪元（Map Epoch）**。每版地图一个计数器 v_M，证书携带纪元戳；跨纪元证书立即失效，除非能证明修订变换在其支撑上是恒等（位移 < d_tol）。同时把证书余量从单一 β 扩展为「β + 位姿方向不确定度 + 接地离散度」，用 SLAM 的协方差把几何余量变成**方向相关**的保守界，而非各向同性常数。

**灵感 2（语言指令 → 指代债：目标是分布不是点）**
直觉：RoboCup@Home 的指令天然欠定（「把厨房那个杯子拿来」），指代要落到地图实体上，是一个带歧义的后验。v9 的任务目标来自符号计划（PrimitiveGraph/OTL），是点/离散目标；一旦语言接错，后续所有几何证书都「完美地为错误服务」。核心创新：**指令-地图接地场（Instruction Grounding Field）**。指令编译成指令增广位姿图，指代后验 b_ℓ 诱导一个**保形目标区域** G_ℓ（split-conformal，覆盖率 1−ε，分布无关）；证书只对 ε-可靠目标区域认证，而非点估计。更关键的严谨连接：保形覆盖率假设可交换性，而域偏移破坏可交换性——因此 Δ_dom 兼任**可交换性警报器**：越阈即暂停保形保证，把 G_ℓ 膨胀到自由空间（保守覆盖率 1）并禁用 K_eff>1。另将指令的时序约束（「先开柜门再取杯」「别洒」）编译成安全自动机，与 50Hz 中块守卫并联。

**灵感 3（v9 释放的算力 → 主动接地）**
直觉：v9 分块把决策利用率从 ~1.0 降到 ~0.3，释放的预算不应只反哺 DA/SPR，还应反哺「把话说清楚」。当接地熵 H(b_ℓ) 高时，插入**认证的信息增益动作**（转头、靠近、换视角）——但该动作本身必须先通过步级安全证书。这样形成闭环：语言歧义 → 主动感知 → SLAM 更新 → 接地确定 → K_eff 恢复。安全与主动性不冲突，因为「看」这个动作也被证书约束。

## 1. 研究问题（轮次升级版）

- **Q1（世界版本）**：如何让证书对地图修订**结构性失效**（而非统计滞后），并把失效时延压到地图更新周期量级？「可证明未受影响」的判据在什么容差下是保守的？
- **Q2（指代接地）**：如何把语言歧义与地图不确定性变成可认证的保守余量？保形目标区域在交换性被域偏移破坏时如何安全降级？
- **Q3（认证主动性）**：如何在接地不确定时用信息增益动作降低不确定性，同时保证插入的每次感知/移动都不破坏安全不变式且循环终止？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 纪元不跨证书律（No Certificate Across Epochs, MET）**
每张证书携带地图纪元戳 v_M。执行器仅允许在 `epoch == v_M` 或「修订变换在证书支撑上为恒等（位移 < d_tol）」时使用；否则证书作废，切换中止点 p* 或 K_eff←1。证书的几何语义被钉死在世界版本上。

**P14 接地-证书耦合律（Grounding-Certificate Coupling, IG）**
目标以保形区域 G_ℓ 给出（覆盖率 1−ε），证书只对 G_ℓ 认证；安全余量显式扣除接地离散度 κ_g·σ_ground。接地熵 H(b_ℓ) > τ_H 时禁止 K_eff>1 并请求主动接地；Δ_dom ≥ τ_dom 时暂停保形保证、G_ℓ 膨胀为保守自由空间。

**P15 指令时序监视律（Instruction Monitor Law, IM）**
指令的时序/安全约束编译为安全自动机 A_ℓ；块生成只接受「预测轨迹被 A_ℓ 接受」的候选；执行期 50Hz 监视器与中块守卫并联，任一违反立即中止。监视器只读廉价原子命题（地图谓词 + 指标阈值），不重跑重模型。

**P16 认证主动接地律（Certified Active Grounding, AGP）**
任何为降低接地/地图不确定性而插入的动作，必须先通过步级安全证书（引理 82 的单步特例）；信息增益低于 min_gain 不插入；预算耗尽则声明「不可判定」并请求澄清（安全停机），不得盲目执行高风险指代。

## 3. 与基线的接口（如何退化）

- IG 失效 ⇒ 接地无信息、G_ℓ 退为 v9 符号计划目标、σ_ground≡0、A_ℓ≡⊤ ⇒ 等价 v9（语言层缺席）；
- MET 失效 ⇒ 纪元冻结、无纪元门控，仅靠中块实时观测守卫 ⇒ 等价 v9；
- UBC 失效 ⇒ σ_pose≡0、σ_ground≡0，证书退回纯 β ⇒ 等价 v9（引理 82 原式）；
- IM 失效 ⇒ A_ℓ≡⊤，仅保留符号计划约束 ⇒ 等价 v9；
- AGP 失效 ⇒ 不插入主动感知，按当前信念执行计划 ⇒ 等价 v9；
- 再往下，v9 的 AC/MW/ID 与 v8 的 DA/SPR/Cal 全部失效 ⇒ 严格退回 v8 → v7 → v6 既有退化链。

## 4. 预期贡献

1. **地图纪元证书**：把「世界被修订」变成证书的一等失效条件，将 v9 的统计滞后风险压到地图更新周期量级（引理 93）；
2. **保形指令接地**：语言歧义 → 覆盖率可证的保守目标区域；并用 Δ_dom 作可交换性警报，统一 DA/SLAM/语言三条线；
3. **三重有效动作块**：几何 ∧ 纪元 ∧ 指代 ∧ 时序监视，安全论证局部化到每条轴；
4. **认证主动接地**：把 v9 释放的算力用于消歧，安全与主动性由同一套证书约束；E571–E590 覆盖修订注入、接地覆盖、时序监视、主动消歧与端到端语言任务。

## 5. 本轮最大风险

**一句话**：本轮方案的最大风险是「指代正确性的不可观测性」——所有几何/纪元证书都以「接地正确」为前提，若语言把用户意图高置信地绑定到错误的地图实体（同义词、地图标签错误、未检出的环路闭合），系统会以完美的证书安全地执行错误任务，而任何几何监测都不会报警。

**新增定义 540（指令-地图因子图 InstructionSLAMFactorGraph）** 指令 ℓ 被解析为逻辑形式 lf=(refs, rel, temporal, goal)，并与当前 SLAM 图合并为 G_ℓ：位姿节点 X_pose 与地图实体 X_map 沿用 SLAM 图；指代变量 X_ref 通过语言因子 E_lang（类别/颜色/尺寸/空间关系）连到地图实体属性；任务变量 X_task 通过 E_task 编码时序与前置条件。接地即在该图上求 X_ref 的边缘后验 b_ℓ。

**新增定义 541（保形目标区域 ConformalGoalRegion）** 取校准集 D_cal（与测试指代同类别、同关系模板），非一致性得分 s(r)=dist(r.centroid, g_true)（g_true 为校准集中人类标注的目标点）。令 q 为 {s(r)} 的 ⌈(n+1)(1−ε_ℓ)⌉/n 分位数，则
```
G_ℓ = { x ∈ free(M_t) : min_{r∈supp(b_ℓ)} dist(x, r.centroid) ≤ q }
```
满足 P(g_true ∈ G_ℓ) ≥ 1−ε_ℓ（可交换性下）。**可交换性警报**：若 Δ_dom ≥ τ_dom，令 G_ℓ ← free(M_t)（覆盖率平凡为 1，接受保守性）且禁止 K_eff>1；警报解除后用 EMA 重标定 q。

**新增定义 542（地图纪元与修订事件 MapEpoch & RevisionEvent）** v_M 初始 0；MET 每周期比较增量地图摘要 digest（拓扑 + 数据关联的有序哈希）。digest 变化即产生修订事件 ρ=(v_M→v_M+1, T_ρ, R_ρ)，其中 T_ρ 为环路闭合/重定位给出的刚体变换，R_ρ 为受影响区域。证书用生成时刻的 v_M 打戳；执行时 `epoch == v_M` 或 `T_ρ` 在证书支撑上位移 < d_tol 方可使用。

**新增定义 543（指代离散度 GroundingDispersion）**
```
σ_ground = sqrt( Σ_r b_ℓ(r)·‖centroid(r) − E_b[centroid]‖² )
```
σ_ground 是接地歧义对位置不确定度的贡献；点估计（v9）等价于 σ_ground=0。

**新增定义 544（三重有效证书 TriValidCertificate）** 沿用 v9 的块证书结构并扩展：
```
ĝ_min = min_{k≤K} [ F̂_clear(s_k) − β − κ_p·σ_pose^{dir}(s_k) − κ_g·σ_ground ]
Ĉ = (ĝ_min, ê_max, γ̂_grasp, v_M)
ok_geo   = ĝ_min ≥ d_safe ∧ ê_max ≤ τ_eff ∧ γ̂_grasp valid
ok_epoch = (v_M 当前) ∨ provably_unaffected(Ĉ.support, T_ρ, d_tol)
ok_ref   = endpoint ∈ G_ℓ ∨ progress₂(G_ℓ) ≥ π_min
ok_mon   = A_ℓ 接受 F̂ 预测轨迹
证书有效 ⇔ (ok_geo ∧ ok_epoch ∧ ok_ref ∧ ok_mon)
```
κ_p 由经验分位标定（E577），κ_g 由 E574 标定；两者均 ≥1 以保证保守。

**新增定义 545（指令监视自动机 InstructionMonitor）** A_ℓ=(Q,Σ,δ,q0,F) 为安全自动机（接受 ⇔ 永不进入坏状态），原子命题 AP 仅取廉价可判定式：`holding(x)`、`at(region)`、`clearance<τ`、`tilt>θ`、`door_open`、`grasp=valid` 等。在线监视 O(|AP|)/周期，坏状态即触发中止，等价于把时序安全约束下沉到中块守卫。

**新增定义 546（接地熵 GroundingEntropy）** H(b_ℓ) = −Σ_r b_ℓ(r) log b_ℓ(r)。H>τ_H 表示「说不清指谁」，禁止大块长并触发 AGP。

**新增定义 547（认证信息增益动作 CertifiedInfoGainAction）** 动作 a 满足：(i) 步级安全证书通过（引理 82 的 K=1 特例）；(ii) 期望信息增益 IG(a) = H(b_ℓ) − E_{o∼a}[H(b_ℓ|o)] ≥ min_gain。取满足者中 IG 最大者执行。

**新增定义 548（指令有效动作块 InstructionValidChunk）** ζ 为指令有效块 ⇔ 定义 544 的四轴成立 ∧ 端点落在 G_ℓ 或朝 G_ℓ 的进度 ≥π_min。若无指令有效块且 H(b_ℓ)≤τ_H ⇒ 沿符号计划退化为 K=1 的单步（等价 v8 决策粒度）；若 H(b_ℓ)>τ_H ⇒ 请求 AGP 或澄清。

**新增定义 549（主动接地循环 ActiveGroundingLoop）** 势函数 Φ = H(b_ℓ) + λ·|未决指代|。每步插入认证信息增益动作使 E[Φ] 至少下降 min_gain（或进入不可判定）；Φ 低于阈值或预算耗尽即退出。所有插入动作经步级证书，故主动感知不引入新的安全债务。

## 3. 关键算法骨架

```python
# IP-357 InstructionGrounder：指令-地图接地场
class InstructionGrounder:
    def __init__(self, parser, encoder, conformal_q, eps=0.05):
        self.parse, self.affinity = parser, encoder
        self.q, self.eps = conformal_q, eps          # 定义 541 校准分位数

    def ground(self, ell, slam_map, delta_dom, tau_dom):
        lf = self.parse(ell)                         # {refs, rel, temporal, goal}
        refs = {}
        for ref in lf.refs:                          # 每个指代 -> 地图实体后验
            s = {e.id: self.affinity(ref, e)
                 for e in slam_map.entities(ref.type)}
            refs[ref.id] = softmax(s)
        b = MarginalBelief(refs, slam_map)           # 定义 540 的边缘后验
        if delta_dom >= tau_dom:                     # 可交换性警报（定义 541）
            G, cov = free_space(slam_map), 1.0
        else:
            G = {x for x in free_space(slam_map)
                 if b.min_dist_to(x) <= self.q}
            cov = 1.0 - self.eps
        A = compile_safety_automaton(lf.temporal)    # 定义 545
        return Belief(b=b, G=G, cov=cov, H=entropy(b),
                      sigma_ground=b.dispersion(), A=A, lf=lf)

    def recalibrate(self, calibration_scores):
        self.q = empirical_quantile(calibration_scores, 1 - self.eps)


# IP-358 MapEpochTracker：地图纪元与修订检测
class MapEpochTracker:
    def __init__(self, slam):
        self.slam, self.epoch = slam, 0
        self.digest = slam.map_digest()              # 增量有序哈希

    def poll(self):
        d = self.slam.map_digest()                   # O(增量) 摊销

# IP-359 UncertaintyBindingCertifier：三重有效证书
class UncertaintyBindingCertifier:
    def __init__(self, F, beta, d_safe, tau_eff, kappa_p=1.2, kappa_g=1.0,
                 d_tol=0.02, pi_min=0.8):
        self.F, self.beta, self.d_safe, self.tau_eff = F, beta, d_safe, tau_eff
        self.kappa_p, self.kappa_g = kappa_p, kappa_g
        self.d_tol, self.pi_min = d_tol, pi_min

    def certify(self, state, chunk, belief, epoch, map_epoch):
        g = []
        for k, s in enumerate(chunk.pred_states):
            n = self.F.nearest_obstacle_dir(s)
            sigma_p = self.F.pose_sigma_along(s, n)  # 方向投影标准差
            g.append(chunk.pred_clear[k] - self.beta
                     - self.kappa_p * sigma_p
                     - self.kappa_g * belief.sigma_ground)
        g_min = min(g)
        ok_geo = (g_min >= self.d_safe
                  and chunk.pred_max_effort + self.beta <= self.tau_eff
                  and chunk.grasp_valid)
        ok_epoch = (epoch == map_epoch) or self._unaffected(
            chunk.support, epoch, map_epoch, self.d_tol)
        ok_ref = (chunk.endpoint in belief.G
                  or chunk.progress(belief.G) >= self.pi_min)
        ok_mon = belief.A.accepts(chunk.pred_trace)
        return Cert(g_min, ok_geo and ok_epoch and ok_ref and ok_mon,
                    epoch=epoch, axes=(ok_geo, ok_epoch, ok_ref, ok_mon))


# IP-360 InstructionMonitor：50Hz 廉价时序监视
class InstructionMonitor:
    def __init__(self, automaton):
        self.A, self.q = automaton, automaton.q0

    def step(self, live_obs, ctx):
        ap = self.A.propositions(live_obs, ctx)      # 地图谓词 + 指标阈值
        self.q = self.A.delta(self.q, ap)
        return self.A.safe(self.q)                   # False -> 立即中止

    def reset(self, new_belief):
        self.A, self.q = new_belief.A, new_belief.A.q0


# IP-361 ActiveGroundingPlanner：认证信息增益动作
class ActiveGroundingPlanner:
    def __init__(self, model, certifier, tau_H=0.6, min_gain=0.05):
        self.model, self.cert, self.tau_H, self.min_gain = \
            model, certifier, tau_H, min_gain

    def maybe_act(self, belief, state, budget_ms):
        if belief.H < self.tau_H or budget_ms <= 0:
            return None
        best = None
        for a in self.model.candidate_views(state):
            ig = self.model.expected_info_gain(a, belief)
            if ig < self.min_gain:
                continue
            if not self.cert.step_ok(state, a):      # 动作本身须安全
                continue
            if best is None or ig > best.ig:
                best = InfoAction(a, ig)
        return best                                  # None -> 请求澄清
```

## 4. 推导

**引理 87（保形接地覆盖率）** 设校准集 D_cal 与测试指代在给定地图类别/关系模板下可交换，非一致性得分如定义 541。则 P(g_true ∈ G_ℓ) ≥ 1−ε_ℓ。证明：split-conformal 分位数 q 的标准有限样本论证；G_ℓ 定义为到 supp(b_ℓ) 的距离 ≤q 的并集，故只要真实目标属于该并集即被覆盖。当 Δ_dom ≥ τ_dom 时定义 541 令 G_ℓ=free(M_t)，覆盖率平凡为 1（保守但不精确），保证安全性不以可交换性为赌注。∎

**引理 88（纪元门控安全性）** 若证书 stamped v，且执行器只允许在 `epoch=v` 或「T_ρ 在证书支撑上位移 < d_tol」时使用，则地图修订不改变证书所依赖的几何关系（间隙、障碍方向、关联），引理 82 的间隙结论继续成立。证明：修订后有效证书的几何量与 stamped 版本相差 ≤d_tol，把 d_tol 计入 d_safe 余量即可吸收；跨纪元复用是破坏保守性的唯一路径，P13 将其去除。∎

**引理 89（不确定性证书保守性）** 设每步位姿误差满足 P(|e_k·n_k| ≤ κ_p σ_k) ≥ 1−δ/K（子高斯或经验分位），且 σ_ground ≥ 真实指代位置偏差（定义 543 的加权方差下界）。由并集界，P(∀k≤K: g_k ≥ ĝ_min) ≥ 1−δ。证明：g_k = F_clear(s_k) − e_k·n_k − 接地偏差 ≥ F̂_clear(s_k) − κ_p σ_k − κ_g σ_ground ≥ ĝ_min（逐项代入）；对 k 取并集界。∎

**引理 90（三重有效块执行安全性）** 若 ζ 生成时四轴成立，且执行期 50Hz 守卫每周期重验纪元、监视器与停车不变式，则在 abort 前系统始终处于「安全 ∧ A_ℓ 接受」集合；任一轴失效即切换 p* 或保守停驻。证明：几何轴由引理 88+82 保持，指代轴由 endpoint 落 G_ℓ/进度门槛保持，监视器轴由每周期 A_ℓ 状态机保持；中块守卫的即时检查封住块生成与执行之间的观测差。∎

**引理 91（主动接地终止 / 无活锁）** 令 Φ=H(b_ℓ)+λ·|未决指代|。每次认证信息增益动作的 E[ΔΦ] ≤ −min_gain，且地图实体有限 ⇒ Φ 的期望单调下降；Φ<τ_H 或预算耗尽即退出。若预算耗尽，声明「不可判定」并请求澄清（安全停机），不执行高风险指代。每次插入动作经步级证书（引理 82 的 K=1 特例），故主动感知不引入安全违背。∎

**引理 92（退化等价 v9）** 对 IG/MET/UBC/IM/AGP 分别注入中立元（b_ℓ 无信息、epoch 冻结、σ≡0、A≡⊤、不插入动作），v10 的证书、守卫与调度读出与 v9 逐位一致：k=1 时定义 544 化为 v9 的 β-only 证书，纪元/指代/监视三轴恒为真，故可观测行为等于 v9。∎

**引理 93（修订失效时延界）** 地图修订事件被 MET 的增量摘要在一个地图更新周期 T_map 内检出；故任何跨纪元证书的最长存活时间为 T_map，与 Δ_dom 的 20 帧≈400ms 滑窗无关。对比 v9 的统计滞后，纪元门控把「最需要安全的时刻暴露最不可靠证书」的窗口从 O(20·Δt) 压到 T_map（典型 ≤100ms）。证明：digest 每周期轮询一次，任何改变拓扑/关联的修订必改变 digest；检出后立即 invalidate 现存块。∎
