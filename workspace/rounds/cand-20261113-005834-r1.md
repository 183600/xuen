# 第 1 轮迭代（灵感循环：「虚拟仿真」×「抓取规划」）—— 从“符号级重做”到“对象系抓取重锚定”

> 本轮在 research.md 现有 v2（UIP-01′~15）上做**物理层深化**，不是推倒重来。v2 的恢复逻辑停在“子目标谓词回退 → 重做”；但真正让重做失败的是**物体/支撑物被搬动后，记忆里的绝对抓取位姿已经失效**。两个灵感词各补一半：**虚拟仿真**给“物体系抓取组合 + 失败负样本”，**抓取规划**给“把组合锚定到当前场景”的几何与算法。本轮先复核事实，再给出**分解式**方案：仿真管物体系先验，感知管位姿锚定，真实示范管任务风格。

---

## 0. 思考轨迹（把过程摊开）

### 0.1 第一反应：v2 缺的不是“检测”，是“重抓”

v2 的旗舰是 RHPV-D：每个动作块后核验子目标，若 `done→undone` 就重做。这个逻辑在“人把拉链拉开”“把合上的盒子打开”这类**反向撤回**上成立；但对“人把杯子往右挪 10 cm”“把插口移开”这类**搬移**，它有两个盲点：

1. **谓词可能仍为真**：书还在书架上，只是书架整体被挪了；符号进度没回退，但所有绝对动作坐标已过期。
2. **重做 = 盲重放**：把同一条示范轨迹再发一遍，末端只会抓到空气或撞到新位置。

所以，本轮的核心不是再做一个更强的检测器，而是补一个**物理重定位 + 抓取重规划**层。人不会重放轨迹；人会**重新看一眼物体、重新决定从哪儿抓**。

### 0.2 事实复核带来的四次纠错（这是本轮最重要的部分）

**纠错 1：`human_*` 的主力不是“反向撤回”，而是“搬移/支撑物移动”。**
把 v2 §2 的 32 条摘要逐条重分类（工作分类，非原始 `info.json` 再抓取）：明确撤回型约 **8–10/32**（T14 拧回、T16 翻开、T17 再打开、T19 拉开、T24 放回起点、T27 拿走第二层、T31 不完整，另 T10/T12/T32 边缘）；而**搬移目标物或支撑物 ≥22/32**（T01–T04、T06–T09、T11、T13、T15、T18、T20–T23、T25、T26、T28–T30 等）。v2 把 T08/T11/T25/T26/T29 这类“挪架子/挪绿盒/挪底座/移插口/移外壳”也算成撤回，属于**可得性偏差**：撤回型描述更戏剧化，搬移型太平淡被忽略了。
→ **影响**：恢复机制必须优先处理“物体位姿变了、但任务语义没变”的情况。

**纠错 2：Gazebo 并不是 G1 的即用仿真。**
`unitree_ros` 的 README 明确：有完整 Gazebo 控制器配置（`xacro/robot.xacro` + `config/robot_control.yaml`）的是 laikago/aliengo/a1/b1/b2/go1/go2 等四足；**G1 只有描述与 RViz/display 启动，不在完整 Gazebo 控制器清单里**，且 Gazebo 不能做高层行走。v2 把“G1 可在 Gazebo 做低层控制”读成了“即用”，过于乐观。
→ **影响**：虚拟仿真应迁到 `unitree_sim_isaaclab`——它明确支持 **G1 29-DoF 固定底座 + Dex1**、真实同构相机、数据采集/回放/生成，并提供 `get_step_reward_value`，比 Gazebo 更贴近本赛制。

**纠错 3：动作块长度不能运行时变短。**
参考评测器 `example/example_env.py` 对每个动作键做**严格形状校验**：`shape == (action_chunk_size, *per_frame_shape)`，不是“≤ T_a”。v2 UIP-13 设想的“声明全局最大 K、每次返回更短的块”会被直接拒绝。
→ **影响**：`T_a` 必须固定。实时性只能靠**固定块内的“有意义的动作前缀 + 安全保持尾”**、投机预计算、以及全局选一个较小的 `T_a` 来实现，不能靠变长块。

**纠错 4：度量抓取并非只能靠单目猜尺度。**
数据集 `meta/info.json` 公开了相机内参：头部双目 `fx≈282 px`、`cx≈311/330`、`cy≈250/257`，且 `rectified: true`、基线 `|T_x|≈58.25 mm`；腕部彩色 `fx≈436 px`。接口恰好发送 `cam_left_high`/`cam_right_high` 两路高位图，分辨率与数据集的 `head_stereo_left/right` 一致。
→ **影响**：若评测相机与数据集同构（高置信推断，需一次回放核验），则**立体度量 + 腕部特写**可以做“粗定位在头部、精对齐在腕部”的分层抓取；这是本轮方案的技术支点，也是最大风险点（见 §6）。

### 0.3 由此得到的核心命题

> **把抓取计划存在物体坐标系里，而不是机器人基座坐标系里。**

人把杯子挪了 10 cm，贴在杯子上的“抓取便利贴”跟着杯子走；机器人只需要重新估计杯子的位姿 `T_w^o`，把物体系抓取 `T_o^g` 右乘上去，就能得到新的世界抓取 `T_w^g = T_w^o · T_o^g`。这比“从零重学一个抓取”便宜得多，也比“重放旧轨迹”稳得多。仿真最擅长的正是生成**物体系**的抓取组合与失败负样本；现实感知负责把物体重新锚定；真实示范负责告诉我们“这类任务人实际选哪种抓法”。

## 2. 直觉解释（先讲人话，再上定义）

**直觉 A：抓取计划是贴在物体上的便利贴。**
不是刻在机器人基座坐标里的钢印。物体被挪动时，便利贴跟着物体走；机器人只需要重新找到物体，不需要重新发明抓法。

**直觉 B：仿真不是“真机成败裁判”，而是“物体系几何与任务适配的沙盘”。**
它能高保真回答“在这个物体自己的坐标系里，哪种抓法在几何上闭包、不撞、且不挡下一步”；它不能可靠回答“真机的摩擦/形变/液体到底会不会让它滑”。所以要让仿真只回答它擅长的问题。

**直觉 C：任务导向抓取 ≠ 稳定抓取。**
一个抓法可能很稳，却让下一步做不了：抓住杯口导致无法倒水；抓住碗底导致无法叠放；抓住网线线缆而不是插头导致无法插入；抓住毛巾中心导致无法折叠。真正要预测的是 `Q(g | 任务, 当前计分步)`，不是单纯的力闭包。

**直觉 D：恢复的粒度应该是“抓取”，不是“子目标”。**
子目标是符号层的；抓取是物理层的。人把物体挪开后，符号层可能什么都没变，物理层的抓取计划已经全废。恢复必须能重新锚定物体、重新选抓法、重新接近。

## 3. 严谨定义（把直觉形式化）

### 3.1 物体系抓取组合

设物体坐标系为 `O`，世界（基座）坐标系为 `W`。一个平行夹爪抓取定义为

```
g = (T_o^g, w, m),   T_o^g ∈ SE(3),  w ∈ (0, w_max],  m ∈ M
```

其中 `T_o^g` 是夹爪在物体系下的位姿，`w` 是开合宽度，`m` 是抓取模式（rim/handle/body/pinch/edge/corner/top/bimanual 等）。物体系抓取组合为

```
G_o = { (g_i, q_i, r_i) }_{i=1..K}
```

`q_i` 是任务导向成功概率，`r_i` 是对扰动的保持率。运行时物体位姿为 `T_w^o`，则世界抓取候选为 `T_w^g_i = T_w^o · T_o^g_i`。

**与 v2 的差别**：v2 的动作是“基座系动作块”；这里多了一层**可复用的物体系抓取资产**，位姿变化只改一个右乘矩阵。

### 3.2 任务导向抓取质量

给定任务 `τ` 与当前计分步 `k`，定义

```
Q(g | τ, k) = E_{ξ ∼ P_physics} [ 1( z_{k+1}(τ, ξ, g) = 1 ) ]
```

即“用抓取 `g` 抓起后，执行该技能的后继脚本，能否让第 `k+1` 个计分步成立”。`R(g)` 则是在扰动集合 `D` 上的最坏情况/期望保持率：

```
R(g) = E_{δ ∼ D} [ 1( grasp_retained(g ∘ δ) ) ]
```

用仿真估计时采用**风险厌恶下界**：`q̂ = mean - β·std/√N`，避免把“偶尔成功”的抓法排到前面。

### 3.3 保真度匹配的仿真（fidelity-matched oracle）

一个仿真器 `S` 对查询 `Q` **可用**，当且仅当

```
| E_S[Q] - E_real[Q] | ≤ ε_Q
```

否则只能用它回答一个对缺失物理不敏感的代理 `Q'`。例如：Isaac Lab 对“刚性物体的对跖抓取是否几何可行/是否挡下一步”可用；对“毛巾折叠后是否到位、针管液面是否到位、网线是否插到底”不可用，只能回答“接近方向与抓取区域是否合理”。这条原则是本轮对 v2“仿真过拟合”风险的直接回应。

### 3.4 干扰的四类效果与抓取层响应

按“对物理状态的效果”而不是“人是否有恶意”分类：

| 类型 | 例子 | 符号谓词 | 抓取层正确响应 |
|---|---|---|---|
| 搬移 `M` | 水果右移、架子左移、插口移开 | 可能不变 | **重估 `T_w^o`，右乘物体系抓取** |
| 撤回 `R` | 拉上后拉开、叠好后翻开 | 1→0 | 重做 + 重新抓取被撤回的部件 |
| 移除/替换 `X` | 中途拿走锁、换未见物品 | 1→0 或对象不存在 | 切换/重识别对象组合，失败则保前置分 |
| 遮挡 `O`（待验证） | 手挡住目标 | 不可观测 | 主动视角（腕部/头部）或轻推探测 |

v2 的 `regressed` 只显式覆盖 `R`；本轮把 `M` 作为**主战场**，把 `R` 作为其特例（部件被反向移动），把 `X/O` 作为组合切换与主动感知。

### 3.5 抓取中心恢复问题

给定干扰后的观测 `o_t`、任务 `τ`、当前计分步 `k`，求一个**在有限尝试预算 `B` 内**最大化期望计分步收益的策略：

```
max_{π}  E[ Σ_{k} w_k · 1(z_k = 1) ]   s.t.  Σ attempts ≤ B,  per-call latency ≤ L
```

其中 `w_k` 是官方计分点。这个目标说明：不是“抓起所有东西”，而是“在预算内保住高分步、必要时放弃低分步”。

## 4. 瓶颈假设（更新）

- **H1（最高杠杆）**：主导干扰是**度量搬移**（≥22/32），因此“物体系抓取记忆 + 位姿重锚定”是比“训练更强的端到端策略”更小、更可验证的充分补丁。
- **H2**：失败多发生在**抓取/接触的物理层**，而不是任务语义层；任务导向抓取质量（是否挡下一步）能解释一批“抓起来了但做不下去”的失败。
- **H3**：在真实数据有限时，**“真实示范正样本 + 仿真失败负样本”**的混合标签，优于纯仿真或纯真实。
- **H4**：真正的瓶颈不是抓取头的容量，而是**30 Hz、JPEG、无线程同步保证下的位姿/接触可观测性**；因此“分解式几何 + 图像伺服”比“再端到端一个大模型”更稳、更可调试。

## 6. 本轮最大风险（一句话）

**最大风险：接口的两路高位相机未必是同步、已标定、可做稠密立体的左右目，且评测相机可能与数据集标定不一致；一旦该假设不成立，整个“对象系抓取”会退化为单目猜尺度，必须先用一次数据回放/真机 episode 验证基线、时间同步与标定，并保留“类别级尺寸先验 + 单目尺度 + 腕部图像伺服”的回退路径。**

## 2. 旗舰深潜：UIP-17 · OGR-TOGA

**全称**：Object-Grounded Regrasping with Task-Oriented Grasp Affordance
**一句话**：离线在仿真里为每个物体的**物体系**生成“抓法组合 + 任务适配分 + 失败负样本”，在线用双目/腕部把物体重新锚定，把组合右乘到当前世界，再用腕部图像伺服执行。

### 2.1 为什么是“分解式”，而不是“再训一个端到端抓取大模型”

| 方案 | 优点 | 致命问题 |
|---|---|---|
| 端到端 RGB→动作 | 简单、单模型 | 物体被挪动后，绝对动作分布外推；公开数据无失败样本；难以判断“抓起来了但下一步做不了” |
| 纯仿真抓取网络 | 标签便宜 | 真实纹理/摩擦/相机与仿真有 gap；对未见物体易崩 |
| **分解式：仿真物体系先验 + 现实位姿锚定 + 真实示范风格** | 每层只做自己保真的事；可解释、可调试、可回退 | 依赖相机标定与位姿估计；工程链更长 |

本轮选分解式，因为本赛制最大的约束是“**真机试错少、公开数据只有成功、接口是开环块**”；分解式把风险分散到三个可单独验证的模块，而不是押注一个黑箱。

### 2.2 三源标签：真实正样本 + 仿真负样本 + 仿真反事实

这是本轮方法论上最关键的组合：

1. **真实正样本（来自 32 个公开数据集）**：
   每条示范里都有“夹爪闭合”的时刻。该时刻的末端位姿就是人实际选过的、任务有效的抓取。把夹爪中心投影到腕部/头部图像，得到 `(u, v, θ, w, mode)`；`q=1`。这不需要额外标注，也天然在真实视觉域。
2. **仿真负样本（来自 UIP-16/20）**：
   在 Isaac Lab 里对正样本做**受控扰动**（平移/旋转/开合偏置/接近方向偏置），以及随机对跖采样，得到失败/滑落/碰撞/挡下一步的抓法，`q=0` 或软标签。公开数据完全没有这类样本。
3. **仿真反事实（任务导向标签）**：
   对同一物体的多个稳定抓法，各自执行“抓取后到下一计分步”的脚本化后继，记录成功与否。这样能区分“稳但挡下一步”的抓法与“稳且不挡”的抓法。只对**可仿真类别**（见 §4.2）生成。

> 一句话：**真实数据告诉我们“人怎么抓”，仿真告诉我们“哪些抓法会失败、哪些会挡下一步”。**

### 2.3 抓取表示与网络输出（仍是单模型）

共享骨干（视觉-语言-动作）之上加一个**辅助抓取头**，不引入第二个在线模型。抓取头在头部左目图像上输出逐像素多通道：

```
s(u,v)      : 可抓取性 [0,1]
c(u,v)      : 抓取模式 logits（8 类：rim/handle/body/pinch/edge/corner/top/bimanual）
cos2θ,sin2θ : 夹爪闭合轴在图像平面的角度（π 周期用倍角表示）
w(u,v)      : 需要开合宽度（米）
q(u,v)      : 任务导向成功概率
r(u,v)      : 扰动保持率
```

对每种模式，角度与宽度的定义不同（例如 rim 抓取是沿杯口切线，pinch 抓取是垂直于薄片边缘）。训练时按模式分组回归，避免多模式混在一个角度回归里。

**总损失**：

```
L = L_action(BC) + λ1 L_point + λ2 L_angle + λ3 L_width
    + λ4 L_mode + λ5 L_quality + λ6 L_robust
```

其中 `L_action` 是原行为克隆损失，保证主策略不被辅助头拖坏；辅助头只在一部分 batch 上激活（有抓取标签的帧），避免无标签帧干扰。

**在线只跑一个网络**：抓取头、动作头共享骨干；PnP/ICP/图像伺服是经典算法，不是学习模型，合规风险低。

### 2.4 离线数据管线（可直接执行）

```python
# B. 仿真负样本与反事实：物体系采样 + 扰动 + 后继脚本
def generate_sim_labels(mesh, task, skill, mu=0.7, N=2000):
    out = []
    for g in antipodal_sampling(mesh, n=N):
        if not collision_free(g) or not reachable(g):
            continue
        eps = epsilon_metric(mesh, g, mu)      # 力闭包裕度
        q_pos = 0.0
        for _ in range(R_rollouts):
            obj = reset_object(mesh, randomize_pose_friction_lighting())
            attach(obj, g)
            ok = rollout_to_next_scoring_step(task, skill, obj)
            q_pos += ok
        q_pos /= R_rollouts
        for g_neg in perturb(g, dxy=..., dtheta=..., dw=..., dapproach=...):
            out.append(dict(g=g_neg, q=0.0, mode=mode_of(g), eps=eps,
                            source="sim_negative"))
        out.append(dict(g=g, q=q_pos, mode=mode_of(g), eps=eps,
                        source="sim_counterfactual"))
    return out
```

**标签对齐的关键工程**：真实正样本在“真实图像域”，仿真反事实在“仿真图像域”。训练时用**域随机化 + 真实图像微调**（见 UIP-20）把两者拉到同一特征空间；不要求像素级一致，只要求抓取点/角度/宽度/模式在同一语义坐标下。

### 2.5 运行时状态机（与 UIP-01′ 对接）

```python
class OGRPolicy:
    def __init__(self, backbone, grasp_head, base_policy, calib):
        ...
    def reset(self):
        self.T_wo = {}          # object_id -> 世界位姿
        self.portfolio = {}     # object_id -> list[(g_o, w, mode, q, r)]
        self.pending = None     # 正在执行的抓取
        self.attempts = {}      # (object_id, candidate_id) -> (n, s)
        self.base_policy.reset()

    def get_action(self, obs):
        # 1) 每块都要重新感知：搬移型干扰的主要入口
        objs = perceive_objects(obs, self.calib)   # masks + ids + T_wo (立体/关键点PnP)
        self._update_object_poses(objs)

        # 2) 若有 pending 抓取，先验抓取状态（GRV，UIP-19）
        if self.pending is not None:
            st = grasp_state(obs, self.pending)    # contact / empty / slipping / holding
            if st == "holding":
                self.pending = None
                return self.base_policy.get_action(obs)   # 进入搬移/放置技能
            if st in ("empty", "slipping"):
                self._mark_failure(self.pending)
                self.pending = None
                # 落到下面重新选抓取

        # 3) 若当前技能是“抓取”，走物体系组选择 + 图像伺服
        if self.current_skill_is_grasp():
            o = self.target_object
            if o not in self.portfolio or self._object_relocated(o):
                self.portfolio[o] = self._make_portfolio(o, obs)
            g_w = self._select_world_grasp(o, obs)       # UIP-18
            if g_w is None:
                return self.base_policy.get_action(obs)  # 放弃该次抓取，保前置分
            self.pending = g_w
            return self._execute_grasp_chunk(g_w, obs)   # 恰好 T_a 步

        # 4) 非抓取技能：原策略
        return self.base_policy.get_action(obs)
```

**要点**：
- 每个动作块后都重新感知；这正好利用“评测端执行完整块后才再次调用”的节奏。
- 物体系组合只在物体**首次出现或位姿大幅变化**时重建；否则只做右乘更新。
- `pending` 抓取的状态由下一块的观测判定，避免在块内假设成功。

## 3. 次旗舰：UIP-18 · GPR（Grasp Portfolio Recovery）

### 3.1 为什么不是“选一个最好的抓取”

抓取质量预测 `q̂` 有噪声，仿真到现实有排序漂移。单点选择一旦错，整个子目标就失败。组合恢复的思路是：**同时准备几个“失败模式不同”的抓法，按预算依次尝试**。

把候选按预测失败模式聚类：

| 失败模式 | 典型原因 | 组合中应保留的多样性 |
|---|---|---|
| `S` slip | 摩擦不足、接触面小、物体重 | 换接触区域/夹持面 |
| `C` collision | 接近路径撞到相邻物 | 换接近方向（上/侧/斜） |
| `U` unreachable | IK/关节限位/自碰撞 | 换臂/换抓取点 |
| `T` task-blocked | 抓起后挡住下一计分步 | 换模式（如杯口→杯身） |
| `P` pose-error | 位姿估计差、物体小 | 换用腕部近景/主动视角 |

同一簇内的失败高度相关，**多试几个同簇候选几乎不增加成功率**；因此先按簇各取一个，再按分排序。

### 3.2 选择公式（风险厌恶 + 贝叶斯 UCB）

对候选 `i`，先验 `q_i`，已试 `n_i` 次、成功 `s_i` 次：

```
score_i = (s_i + α0·q_i) / (n_i + α0)  +  c·sqrt( ln(N+1) / (n_i + α0) )
```

- 第一项是后验成功率的收缩估计；`α0` 是伪计数，防止小样本爆炸。
- 第二项是探索奖励；`c` 由延迟预算决定。
- 排序时先做**模式去重**（每簇最多一个），再按 `score_i` 贪心填满本次预算 `m`。

**独立性上界**（用于设定 `m`）：若 `m` 个候选相互独立、成功率为 `p_i`，则至少一次成功的概率

```
P_success(m) = 1 - Π_{i=1..m} (1 - p_i)
```

`p_i=0.5` 时，`m=1/2/3` 分别为 `0.50/0.75/0.875`；若完全相关，则始终是 `0.50`。这就是“组合多样性”的定量价值。

### 3.3 恢复伪代码

```python
def select_and_execute(portfolio, budget_m, latency_budget):
    clusters = cluster_by_failure_mode(portfolio)
    heads = [max(c, key=lambda x: ucb(x)) for c in clusters.values()]
    chosen = []
    for _ in range(min(budget_m, len(heads))):
        i = max(heads, key=lambda x: ucb(x))
        chosen.append(i); heads.remove(i)
    for g in chosen:
        if not feasible(g):           # 碰撞/IK/开合上限
            continue
        if projected_latency(g) > latency_budget:
            continue
        yield g
    return None
```

失败后：`n_i += 1`；若 `s_i` 不变，下次该候选的 UCB 下降，自然切换到同簇下一个或别的簇。**当所有簇都失败或预算用尽**，执行“保分回退”：停止该子目标的重抓，回到 UIP-02′ 的价值调度，优先保住已得的前置分。

### 3.4 放弃策略（与步骤分对齐）

不是所有失败都值得一直重试。用计分点 `w_k`、当前已得分的“沉没价值”、以及剩余步骤分上界做一次简单决策：

```
continue_retry  iff   w_k · P_success(m_remaining)  >  w_{k+1..N} · Δrisk(重试占用时间)
```

直觉：如果当前步分值低、而后面还有高分步，宁可放弃当前步去保后面；如果当前步是高分的末步，就值得多试一次。这个判断直接复用 UIP-02′ 的 32 任务计分表。

## 4. UIP-16 · FMS（Fidelity-Matched Simulation Stack）

### 4.1 三层保真度：只问仿真能回答的问题

| 层 | 内容 | 高保真回答 | 不可信回答 | 工具 |
|---|---|---|---|---|
| **L0 几何** | 物体网格、对跖采样、碰撞、IK/可达、部件分割、相机渲染 | 抓取点/角度/宽度、接近方向、是否撞、抓哪儿 | 摩擦/形变/液体 | 解析 + 轻量渲染 |
| **L1 准静态接触** | 摩擦锥、力闭包 ε 度量、扰动保持、外 wrench 裕度 | 刚性物体的稳定性排序、失败模式 | 软体/线缆/液体 | 解析 + 采样 |
| **L2 动态** | Isaac Lab 短程抓取-抬升-搬运-放置 rollout | 刚性、铰接件的顺序/任务适配 | 布、绳、流体、细接触 | `unitree_sim_isaaclab` |
| **L3 真机锚点** | 小规模真机/回放 | 偏差校准、最终判据 | 不能替代正式评测 | 真机时段 |

**原则**：L2 的输出只作为“结构/顺序代理”，不作为“像素级成败”；L3 是唯一校准锚点。v2 已指出“仿真过拟合”风险，本轮把它变成**可执行的准入规则**：每个任务先标可仿真类别，再决定用哪层标签。

### 4.2 任务可仿真性分级（工作分类）

| 类别 | 任务（示例） | 仿真可用于 | 仿真不可用于 |
|---|---|---|---|
| **S1 刚性几何主导** | T01–T04、T06–T07、T09、T11、T13、T15、T18、T20–T23、T25、T27–T30 | 抓取位姿/宽度/模式、碰撞、可达、刚性放置的任务适配 | 精确摩擦/接触力 |
| **S2 铰接/细接触** | T05、T10、T12、T14、T19、T26、T31 | 接近方向、抓取区域、失败模式先验 | 插入/拧动/拉链的最终成败、卡滞 |
| **S3 形变/线缆/流体** | T16、T17、T24、T28、T32 | 粗抓取区域/模式、负样本先验 | 折叠/液体/线缆的动力学 |

> 对 S2/S3，**不追求仿真 Q 的绝对值**，只用它做“候选排序的先验”，再用真实正样本与腕部图像伺服兜底。

### 4.3 资产库：形状族 + 真实尺寸拟合

不追求 32 个高精度 CAD；用**参数化形状族**覆盖类别：

## 5. UIP-19 · GRV（Grasp/Contact State Verifier）

### 5.1 四个状态

```
empty    : 夹爪闭合到接近零、或观测到物体没有随夹爪移动
contact  : 夹爪开合停在物体宽度附近，但尚未确认抬升
slipping : 抬升过程中夹爪开度阶跃变大，或腕部图像中物体相对夹爪位移
holding  : 物体随夹爪稳定移动 ≥ 若干块
```

### 5.2 三个判据（由便宜到贵，短路执行）

1. **开合宽度一致性**：`w_closed` 与物体在闭合轴上的已知/估计宽度 `ŵ` 比较；`|w_closed - ŵ| ≤ ε` 判 contact；`w_closed ≈ 0` 判 empty。
2. **腕部光流一致性**：对腕部图像做稀疏光流；比较物体区域光流与夹爪/背景光流的相对运动；持续相对位移判 slipping。
3. **立体/末端一致性**：抬升后物体质心相对末端的位置应基本不变；若物体没跟着走，判 empty。

```python
def grasp_state(obs, g):
    w = obs["observation.state.left_gripper"][-1, 0]
    if w < W_EMPTY: return "empty"
    if abs(w - expected_width(g)) <= EPS_W:
        if slip_flow(obs) > FLOW_THR: return "slipping"
        if not object_moves_with_ee(obs, g): return "empty"
        return "holding" if stable_for(obs, 2) else "contact"
    return "contact"
```

GRV 的输出同时喂给 UIP-01′，把 `regressed` 扩展为 `relocated`/`replaced`/`grasp_failed`，让调度器知道“是重试、重抓、还是切换对象”。

## 6. UIP-20 · GRD（Grasp-Robustness Domain Randomization）

### 6.1 负样本课程（从易到难）

```
阶段 1：对跖采样 + 小扰动（±5 mm / ±3° / ±10% 宽度）→ 学“接近正确但不精确”
阶段 2：接近方向偏置（上/侧/斜的错配）→ 学“该换方向”
阶段 3：物体位姿大搬移（10–30 cm / ±45°）→ 学“重锚定”
阶段 4：支撑物移动 + 相邻物遮挡 → 学“换簇/主动视角”
阶段 5：未见形状族（留出族）→ 学“类别级泛化”
```

### 6.2 随机化维度（只随机化与抓取几何相关的量）

- 物体：尺寸比例、质量、质心、摩擦、表面纹理、颜色。
- 场景：桌面高度/摩擦、相邻物位置、背景、光照/色温。
- 相机：轻微内外参扰动（模拟标定误差）、JPEG 压缩、运动模糊。
- 机器人：初始关节噪声、末端执行误差。

**不随机化**：任务语义、语言指令、计分顺序。否则会把“任务适配”学成噪声。

### 6.3 与 v2 UIP-12 DRF 的合并

UIP-12′ = **GRD 生成“干扰-恢复”配对**：先由搬移/撤回/移除/遮挡四类干扰生成初始状态，再由 OGR 的抓取组合生成恢复轨迹（而不是脚本化重放）。这样恢复数据天然覆盖“新位姿 + 新抓法”，而不是“旧位姿 + 旧轨迹”。

## 7. 对 v2 条目的具体修订

### UIP-11 → UIP-16 FMS
- 平台从 Gazebo 迁到 `unitree_sim_isaaclab`（G1 29-DoF 固定底座 + Dex1，同构相机，回放/生成，`get_step_reward_value`）。
- Gazebo 只保留为“轻量几何/碰撞检查”的可选工具；不再承担 G1 动态 rollout。
- 判分谓词不变（v2 §6），但只在 S1 类任务上作为步骤分代理。

### UIP-12 → UIP-12′ 抓取感知的扰动-恢复工厂
- 干扰生成保留；恢复轨迹由 UIP-18 的抓取组合产生。
- 输出三元组从 `(干扰前 → 撤回 → 恢复)` 改为 `(抓取前 → 搬移/撤回/移除 → 重锚定+重抓)`。

### UIP-13 → UIP-13′ 固定块“技能前缀 + 安全尾”
- **不能变长**。声明一个全局 `T_a`（建议先用 4 或 8，按实测延迟定）。
- 块内编码：前 `k` 步是“接近/闭合/抬升”的有意义前缀，后 `T_a-k` 步是“保持当前位姿 + 保持夹爪”的安全尾。
- 若前缀失败，安全尾不会造成额外损害；下一块再验证并切换候选。
- 远距离搬运可用大 `T_a`；接触密集阶段用较小的全局 `T_a` 或更保守的前缀。

### UIP-01′ → 增加 `relocated` / `replaced`
- `regressed`：子目标谓词 1→0（撤回）。
- `relocated`：谓词仍真，但目标/支撑物位姿变化超过阈值（搬移）→ 重锚定。
- `replaced`：对象身份/类别变化（未见物体）→ 切换组合/重建。
- `grasp_failed`：GRV 判 empty/slipping → 换抓取候选。

### UIP-09′ → 降为 UIP-19 的前端
- 只负责“检测异常/变化”，不再承担恢复策略；避免与 GPR 职责重叠。

## 8. 关键推导（不是实验结论，是设计依据）

### 8.1 立体深度误差：为什么必须“头部粗 + 腕部精”

`Z = f·B / d`，`ΔZ ≈ Z²/(f·B)·Δd`。取数据集的 `f≈282 px`、`B≈58.25 mm`：

| 距离 `Z` | 1 px 视差误差对应 `ΔZ` | 0.25 px 亚像素对应 `ΔZ` |
|---|---|---|
| 0.4 m | ≈ 0.97 cm | ≈ 0.24 cm |
| 0.6 m | ≈ 2.19 cm | ≈ 0.55 cm |
| 0.8 m | ≈ 3.89 cm | ≈ 0.97 cm |

结论：头部双目在桌面距离只能做**厘米级**定位，足够“选区域/选模式”，不够“插入/合盖”。腕部相机距离近、分辨率等效更高，用图像伺服做最后几厘米；因此分层是必要的，不是可选的。

### 8.2 对跖 + 摩擦锥 + ε 度量

接触点 `p1,p2`，外法线 `n1,n2`，闭合轴 `a=(p2-p1)/||p2-p1||`。对跖条件：

```
n1·a ≈ +1,   n2·a ≈ -1
angle(n1,a) ≤ α,  angle(n2,-a) ≤ α,   α = atan(μ)
w = ||p2-p1|| ≤ w_max
```

力闭包：把每个接触的摩擦锥边界力映射为 wrench `[f; (p-c)×f]`，若这些 wrench 的凸包**严格包含原点**，则力闭包。实际用 `ε = dist(0, ∂conv(W))` 作为裕度；`ε` 越大越稳。对任务导向抓取，还要把“后继轨迹的惯性/接触 wrench”纳入 `W` 的对抗集，否则会选出“静态稳、一动就掉”的抓法。

### 8.3 组合成功率与多样性

独立候选：`P(m)=1-∏(1-p_i)`；完全相关：`P(m)=p`。因此 GPR 的收益来自**去相关**，不是简单多试。做法是按失败模式聚类，每簇先取一个；同簇重复尝试的边际收益接近 0。

### 8.4 位姿重锚定的误差传播

`T_w^g = T_w^o · T_o^g`。若 `T_w^o` 有平移误差 `e_t`、旋转误差 `e_R`，则世界抓取点误差一阶近似：

```
e_g ≈ e_t + ||r||·e_R
```

`r` 是物体坐标系原点到抓取点的向量。**推论**：把物体系原点放在“任务相关部件的质心”（杯口、手柄、插头本体），而不是网格原点，可以减小 `||r||`，从而降低旋转误差的杠杆效应。这是一个免费但常被忽略的工程细节。

## 12. 合规与风险

- **单模型**：抓取头是共享骨干上的辅助头；PnP/ICP/图像伺服是经典算法；在线不调用外部 VLM/大模型。离线可用外部工具做标签，但要在提交说明中写清“离线标注、在线单模型”。
- **接口红线**：每个动作键严格 `(T_a, …)`、`float32`；不能返回变长块；不能加未知键；`meta.token` 每步都要带。
- **控制空间**：建议用 `ee`（数据集有 `action.*_ee_pose_gripper_base`，便于图像伺服）；若必须 `joint`，内部做 IK，输出关节目标，二者不能运行期切换。
- **N 端口**：每端口的物体系组合、位姿缓存、失败计数必须隔离；共享的只能是只读权重。
- **延迟与可信度**：抓取头与位姿估计要批处理/投机预计算；避免某几次调用出现长尾；动作要平滑，避免统计异常。
- **仿真过拟合**：严格执行 §4.1 的保真度准入与 §4.2 的可仿真性分级；S2/S3 不相信仿真 Q 的绝对值。
- **仍未核实**：评测/控制频率、飞书手册、`cam_*_high` 官方对应关系、榜首水平。这些都可能导致参数需要重标，尤其是 `T_a` 与延迟预算。

## 14. 本轮最大风险 & 押注

**一句话**：整个方案的承重点是“评测相机的立体/标定假设”；若 `cam_*_high` 不是可用的同步立体对，对象系抓取会退化为单目尺度猜测——必须先用一次回放/真机 episode 验证，并保留单目+尺寸先验+腕部伺服的完整回退路径。

**→ 押注：UIP-17 OGR-TOGA × UIP-18 GPR**，由 **UIP-16 FMS** 提供物体系先验与失败负样本、**UIP-19 GRV** 提供抓取状态、**UIP-01′** 调度、**UIP-15 CSG** 控预算。它把“被搬动后的重做”从盲重放升级为“对象系抓取重锚定 + 组合式恢复”，对准占比最高的搬移型干扰与公开数据完全缺失的失败样本；即使立体假设失败，也能以降级形态（单目+腕部伺服）保留大部分收益。
