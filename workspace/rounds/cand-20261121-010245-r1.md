# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「产学研合作」×「能耗优化」）

> **基线**：上一轮 MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**他山之石可以提议、不可授权；能量只出不进、预留先行**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v15 的 HDST/SDE、v14 的 SCD/DSD/DCA/EDC、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。六个新组件——CAB（合作方证书准入经纪人）、FCL（联邦校准账本）、EEC（能耗包络认证器）、EBA（能耗预算仲裁器）、ELS（能耗阶梯调度器）、EPR（能耗感知排序器）——一律以**中立元接入 v17 语言层之上**，失效即严格退回 v17（引理 143），再沿 v17→v16→v15→…→v6 退化链退回。本轮只做三件事：把「产学研合作」改写为**跨组织证书的准入代数**（信任取交、风险取并），把「能耗优化」改写为**不可逆资源的包络证书与预留调度**（先保证回退、再谈省电），把「合作 × 能耗」改写为**两条单调阶梯的集合交**。

## 0. 直觉与动机

**灵感 1（产学研合作 → 证书跨组织不增值）**
直觉：产学研的默认叙事是"把各方的能力合并起来"。但在一个已完全证书化的执行栈里，**合并证书就等于合并授权**：某大学在自有硬件上测出的节点证书，若被本地直接采信，等于让外部机构获得了对本地执行器的授权；某企业提交的"能耗达标报告"若被直接当成预算，等于让供应商决定安全边界。核心创新：**合作方证书准入经纪人（Consortium Admission Broker, CAB）**。每份外部证书 `K_ext` 只是一份**主张（claim）**，不是能力；准入必须先验证溯源与有效期，再在**本地硬件/软件/数据**下重新验证，最后取外部证书与本地证书的**交（meet）**：`K_admit = K_ext ⊓ L`。关键反直觉点：**合作的价值不是"更多权限"，而是"更多候选 + 更全的校准覆盖 + 更多负知识"**——准入只会缩小可执行集，合作方越多，系统越"见多识广"，但绝不越"有权力"。

**灵感 2（产学研合作 → 校准不能池化，只能逐站点取交）**
直觉：共形预测的有效性依赖"测试计划与校准集可交换"。产学研三方的分数分布恰恰**最不可交换**（工厂是重复搬运、大学是实验室桌面、研究院是标准工况）。把三方日志倒在一起算一个 `q̂`，等于用一个隐含的"平均站点"去做保证，覆盖会静默失效。核心创新：**联邦校准账本（Federated Calibration Ledger, FCL）**。每个站点只在本地上报自己的一维分位数 `q̂_s`（原始日志不出域），联合接受规则是**逐站点取交**：`∀s: s(π,x) ≤ q̂_s(1−α/S)`；由 Bonferroni 得 `P(可交换计划被拒) ≤ Σ α/S = α`，**不需要任何跨站点可交换假设**。关键反直觉点：**"更合作"的正确形态是"更严格地各自守门"，不是"更宽松地共享一个阈值"**。

**灵感 3（能耗优化 → 能量是不可逆的守恒量，先预留、再省电）**
直觉：v17 的新鲜度阶梯之所以优雅，是因为"截断"只删除**未来**开销，不追讨过去。能量不同：**已经花掉的电永远退不回来**。要在低电量下安全，第一目标不是"平均省电"，而是"任何被接受的计划都留够了执行它自己 Fallback、并回到认证坞的能量"。核心创新：**能耗包络证书（Energy Envelope Certificate, EEC）+ 能耗预算仲裁器（Energy-Budget Arbiter, EBA）+ 能耗阶梯调度器（Energy Ladder Scheduler, ELS）+ 能耗感知排序器（Energy Pareto Ranker, EPR）**。EEC 给每个节点一对区间 `[E_lo, E_hi]`（上界带置信）；EBA 用上界做**事前可行性**并预留 `B_reserve(π)`；ELS 按剩余电量 / SoC / 热状态把系统压到 NORMAL→CONSERVE→RESERVE→DOCK 四级；EPR 只在已认证、已可行、已过缝的集合内部做能量 Pareto 排序。关键反直觉点：**能耗优化的第一性不是"最省"，而是"回得来"**；省电只能在证书与预留之内争取，**永远不能为了省电放宽任何边界**。

**三者如何统一：信任取交、风险取并、优化只排序**
统一为 **v17 语言层之上的"合作—能量层"**：v17 回答"哪些语言计划能被编译为认证行为"，v18 回答"这些计划里，哪些的外部证书可被本地准入、以及在当前剩余能量下哪些能安全跑完并回来"（`Exec_v18`）。共享状态 `ζ_ce=(B_t, SoC, κ_T, κ_age, eec_table, ladder_lvl, fcl_quantiles, partner_ledger, drift_ce, mode_ce)`。**CAB 回答"外部证书能进来多少"，FCL 回答"哪个站点都不反对才接受"，EEC/EBA 回答"这一计划还够不够电、回退够不够电"，ELS 回答"没电时退到哪一级"，EPR 回答"同等安全下哪个最省"**。五者不是补丁，而是"准入—校准—包络—预留—阶梯—排序"的实现链。其代数骨架只有一条：**信任取交（更严），风险取并（更保守），优化只排序（不授权）**，故 `Exec_v18⊆Exec_v17`。

## 1. 研究问题（轮次升级版）

- **Q1（跨组织准入的代数）**：`admit(K_ext, L)` 如何在"信任取交、风险取并"下保证可执行集单调收缩？溯源链、有效期、硬件指纹、软件版本各应作为硬门还是软分？合作方证书的 NC 语义与本地 NC 语义不对齐（同一节点名、不同前后置）时取交是否会变成空集？
- **Q2（联邦共形与异质性）**：逐站点取交的 Bonferroni 在站点数 S 增大时活性损失多大？当站点内部也漂移、站点内可交换性也不成立时，如何用滑动窗与站点权重退化？只共享分位数是否仍泄露隐私，需不需要 DP 噪声、噪声如何改变覆盖？
- **Q3（能耗包络与预留的严谨性）**：逐节点上分位包络如何合成**计划级**覆盖（相关性、长尾、热耦合）？`B_reserve(π)` 沿 Fallback→Dock 的最短路是否成环、预留本身是否递归到不可行？包络突破瞬间的 `Δ_max` 兜底能否覆盖检测延迟内的溢出？
- **Q4（双阶梯、优化与规模化）**：能耗阶梯与新鲜度阶梯如何复合而不振荡？EPR 的能量 Pareto 前沿与任务价值下界如何取舍？合作方数量 S 上升时，活性损失与安全收益如何量化与预注册？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P34）

**P31 产地无特权律（Origin as Claim, Not Capability）**
外部证书只是主张。`admit(K_ext, L) = K_ext ⊓ L`，其中 `Exec(K_ext⊓L)=Exec(K_ext)∩Exec(L)`，且 `EEC(K_ext⊓L)=[min(E_lo), max(E_hi)]`（风险取并）。准入不通过（溯源失败 / 过期 / 本地复验失败）一律 `⊥`。**任何数量的合作方证书的任意组合，新增授权基数 `|NewAuth|=0`**；合作只贡献候选、校准与失败样例，不贡献权限。

**P32 能量不可逆与预留先行律（Spend-Only, Reserve-First）**
能量在单个班次内单调不增。计划接受的必要条件为
`E^plan(π) + B_reserve(π) ≤ B_t`，其中 `E^plan(π)=Σ_i E_hi(n_i)+E_seam(π)` 用**上包络**，`B_reserve(π)=max_i [E_hi(路径: Fallback_i→Dock)] + Δ_max`。运行时用**实测值**扣账；实测突破包络立即降级，但**预留不得被计划本身挪用**。截断只减少未来开销，**不得被当作对已花能量的返还**。

**P33 能耗阶梯律（Energy Ladder, Work-Conserving Degradation）**
四级阶梯按剩余电量单调下降：`DOCK ⊆ RESERVE ⊆ CONSERVE ⊆ NORMAL`（可执行族与预算同时收紧）。每级只**删节点、降速度、缩预算**，不新增、不拼接、不跨级；阈值带迟滞以防振荡。**阶梯是集合交，故与 v17 新鲜度阶梯可交换**：两者复合等于取更严的一级。

**P34 优化无特权律（Optimization as Query, Not Authority）**
能耗优化器只能在 `Exec_v18` 内对候选做排序 / 选择，不得放宽任何证书、共形分位数、缝余量、能耗预留或里程碑门控。`π* = argmin_{π: V(π)≥v_min ∧ E-feasible} E^plan(π)` 的输出仍满足 `Exec(π*)⊆Exec_v18`。**省电是"在证书内最省"，不是"为省电而放宽证书"**。

## 3. 与基线的接口（如何退化）

- CAB 失效（溯源服务不可用）⇒ 只接受本地自签证书，外部证书全部 `⊥`——**等价 v17**；
- FCL 失效（站点账本不可达）⇒ 退回单站点共形（原 HCG 校准集）——**等价 v17**；
- EEC 失效（能耗测量缺失）⇒ 只允许"回退动作即在认证坞内"的单节点计划——**等价 v17（最保守）**；
- EBA 失效（预算仲裁不可用）⇒ 预留取保守常数、只执行单节点计划——**等价 v17（活性下降）**；
- ELS 失效（SoC 传感器缺失）⇒ 停止接受新计划，当前计划执行完后转 v17 默认策略——**等价 v17**；
- EPR 失效 ⇒ 不排序，取首个可行候选——**等价 v17**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v6 退化链退回；
- **安全继承**：CAB 只收缩证书、FCL 只收紧接受、EEC/EBA 只增能量约束、ELS 只删节点与预算、EPR 只排序——六端口互不相交，均不能新增授权或放宽阈值；`Exec_v18⊆Exec_v17` 由引理 143 保证。

## 4. 预期贡献

1. **跨组织准入代数**：首次把"产学研合作"形式化为证书偏序上的 meet——信任取交、风险取并，证明合作方数量与组合不改变授权上界，把"多方协作"从权限风险改写为候选/校准收益；
2. **联邦共形、拒绝池化**：给出逐站点分位数交集 + Bonferroni 的异质性鲁棒接受规则，证明其**无需跨站点可交换性**即可维持 `1−α` 覆盖，并量化 pooled 方案在站点异质下的覆盖缺口；
3. **能耗包络证书与预留先行**：把"电量安全"从平均功耗改写为"上包络 + 回退-dock 最短路预留 + 溢出兜底"的三段式，给出计划级覆盖与预留充分性条件；
4. **能量不可逆律**：显式区分"可截断的未来"与"不可返还的过去"，证明能耗阶梯必须以剩余电量为自变量、且与新鲜度阶梯可交换（集合交），消除双阶梯振荡；
5. **优化无特权**：把能耗优化限制为认证集内的 Pareto 排序，关闭"为省电而放松安全"的优化攻击面；
6. **六层分离再进一步**：v12 管允许、v13 管时限、v15 管扩散、v16 管全身行为、v17 管语言计划、v18 管**跨组织准入与能量可行性**，用 `Exec_v18⊆Exec_v17⊆Exec_v16⊆…⊆Exec_v12` 把"合作"和"能耗"也纳入同一退化链；E711–E730 覆盖准入、联邦覆盖、包络、预留、双阶梯、优化、端到端与消融。

## 5. 本轮最大风险

**一句话**：CAB 的准入证书与 EEC 的能耗包络依赖**同一套环境测量**（电池老化 `κ_age`、地形、热 `κ_T`）——一次未建模的分布漂移会让"信任"与"能量"两个看似独立取交/取并的保证在**同一隐变量下共模失效**，于是出现"外部证书本地复验通过、逐站点共形通过、包络可行、预留充足"却在实际地形/老化条件下同时越界并耗尽回退电量的计划，即被合作方与本地共同认证、却在共模漂移下既不安全又回不来的方案。

## 1. 关键算法骨架

```python
# IP-415 CAB：合作方证书准入（信任取交、风险取并）
class ConsortiumAdmissionBroker:
    def __init__(self, local_ncs, local_eec, attest, clock):
        self.local_ncs = local_ncs
        self.local_eec = local_eec
        self.attest = attest
        self.clock = clock

    def admit(self, K_ext):
        if not self.attest.verify(K_ext.prov, K_ext.sig):
            return None                                  # 溯源不可信 ⇒ ⊥
        if not (K_ext.valid[0] <= self.clock.now() <= K_ext.valid[1]):
            return None                                  # 过期 ⇒ ⊥
        nc_loc = self.local_ncs.reverify(K_ext.n, K_ext.NC_ext)
        if nc_loc is None:
            return None                                  # 本地复验不过 ⇒ ⊥
        eec_loc = self.local_eec.remeasure(K_ext.n)       # 本地硬件重测包络
        if eec_loc is None:
            return None
        return Certificate(
            n=K_ext.n,
            NC=meet_nc(nc_loc, K_ext.NC_ext),            # 信任取交：更严
            EEC=[min(eec_loc.E_lo, K_ext.EEC_ext.E_lo),  # 风险取并：更宽
                 max(eec_loc.E_hi, K_ext.EEC_ext.E_hi)],
            prov=K_ext.prov + [LOCAL_SEAL],
            site=K_ext.site, valid=K_ext.valid)


# IP-416 FCL：联邦共形（不池化、逐站点取交）
class FederatedCalibrationLedger:
    def __init__(self, site_logs, alpha):
        self.S = len(site_logs)
        self.alpha_s = alpha / self.S                   # Bonferroni
        self.q = {s: finite_sample_quantile(scores, 1 - self.alpha_s)
                  for s, scores in site_logs.items()}   # 只共享一维分位数

    def accept(self, score, pi, x):
        return all(score(pi, x) <= q for q in self.q.values())

    def recalibrate_site(self, s, recent, poison_filter):
        clean = poison_filter.filter(recent)
        self.q[s] = finite_sample_quantile(
            [r.score for r in clean], 1 - self.alpha_s)


# IP-417 EEC：逐节点能耗包络
class EnergyEnvelopeCertifier:
    def __init__(self, measure_fn, terrain, kappa_age):
        self.measure = measure_fn
        self.terrain = terrain
        self.kappa_age = kappa_age

    def certify(self, node, trials, delta_plan, T):
        delta = delta_plan / max(1, T)                   # union bound 分摊
        es = [self.measure(node, self.terrain) for _ in range(trials)]
        es = [e / self.kappa_age for e in es]            # 老化折算
        e_hi = empirical_quantile(es, 1 - delta) + finite_sample_correction(delta, len(es))
        e_lo = max(0.0, min(es))
        return EEC(node, E_lo=e_lo, E_hi=e_hi,
                   delta=delta, Delta=max(0.0, max(es) - e_hi))


# IP-418 EBA：事前可行性 + 预留（预留不得被计划挪用）
class EnergyBudgetArbiter:
    def __init__(self, eec_table, anchor_graph, fallback_of, dock):
        self.eec = eec_table
        self.graph = anchor_graph                         # 以 E_hi 为权
        self.fallback_of = fallback_of
        self.dock = dock

    def plan_energy(self, nodes):
        return sum(self.eec[n].E_hi for n in nodes) + self.seam_energy(nodes)

    def reserve(self, nodes):
        worst = 0.0
        for n in nodes:
            fb = self.fallback_of(n)
            worst = max(worst, self.graph.shortest_energy(fb, self.dock)
                        + self.eec[n].Delta)             # 单次未记账溢出兜底
        return worst

    def feasible(self, nodes, B_t):
        return self.plan_energy(nodes) + self.reserve(nodes) <= B_t


# IP-419 ELS：能耗阶梯（只删/降/缩，带迟滞）
class EnergyLadderScheduler:
    LEVELS = ('NORMAL', 'CONSERVE', 'RESERVE', 'DOCK')
    def __init__(self, soc_conserve, soc_reserve, soc_dock, hyst=0.02):
        self.soc = (soc_conserve, soc_reserve, soc_dock)
        self.hyst = hyst
        self.lvl = 'NORMAL'

    def level(self, B_t, soc, thermal):
        raw = ('DOCK' if soc <= self.soc[2]
               else 'RESERVE' if (soc <= self.soc[1] or thermal.throttled)
               else 'CONSERVE' if soc <= self.soc[0]
               else 'NORMAL')
        # 迟滞：升档需越过阈值 + hyst，防抖
        if self.LEVELS.index(raw) > self.LEVELS.index(self.lvl):
            if soc > self.soc[self.LEVELS.index(self.lvl) - 1] + self.hyst:
                return self.lvl
        self.lvl = raw
        return raw

    def filter(self, plan, lvl):
        if plan is None:
            return None
        if lvl == 'NORMAL':
            return plan
        if lvl == 'CONSERVE':
            return drop_optional(plan)                    # 只删不增
        if lvl == 'RESERVE':
            return [n for n in plan if n in FALLBACK_FAMILY]
        return [DOCK]                                     # 单一认证目标


# IP-420 EPR：能耗 Pareto 排序（只排序，不授权）
class EnergyParetoRanker:
    def __init__(self, eba, value_fn):
        self.eba = eba
        self.value = value_fn

    def select(self, candidates, v_min, B_t):
        feas = [p for p in candidates
                if p.certified and self.value(p) >= v_min
                and self.eba.feasible(p.nodes, B_t)]
        if not feas:
            return None
        return min(feas, key=lambda p: (self.eba.plan_energy(p.nodes),
                                        -self.value(p)))
```

## 2. 推导

**引理 143（准入不可扩性 / 产地无特权）** 设 `admit(K_ext,L)=K_ext⊓L` 满足 `Exec(K_ext⊓L)=Exec(K_ext)∩Exec(L)`、`EEC` 取风险并（`E_lo` 取 min、`E_hi` 取 max），且未通过溯源/有效期/本地复验者返回 `⊥`。则对任意数量与组合的外部证书，`Exec_v18⊆Exec_v17`，且新增授权 `|NewAuth|=0`。证明：由定义 690，准入结果的可执行集是外部与本地可执行集之交，故 `⊆Exec(L)⊆Exec_v17`；能耗上界取 max 只会使 `Feas_E` 更难满足，故可行性集只会收缩；`⊥` 退回 v17。外部证书的任意并/交/重复都不能产生不在 `Exec(L)` 中的元素。∎ 推论：**合作只增"候选与校准覆盖"，不减"授权上界"；合作方被攻陷的最坏后果是活性下降**。

**引理 144（站点级共形覆盖，无需跨站点可交换）** 设测试计划在每个站点 s 内与其校准集 `D_s` 可交换，接受规则为 `∀s: s(π,x)≤q̂_s(1−α/S)`。则 `P(接受可交换计划) ≥ 1−Σ_s α/S = 1−α`。若改用池化分位数 `q̂_pool`，当站点异质性 `Het>0` 时其覆盖可低至 `1−α−C·Het`（C 为分数分布 Lipschitz 常数）。证明：站点内标准共形秩论证给出 `P(s>q̂_s)≤α/S`；并集界得同时被所有站点拒绝的概率 `≤α`。池化把多个不同分布混为一个，秩均匀性被打破，总变差界给出覆盖缺口 `O(Het)`；构造两站点分数支撑近乎不交的反例即可达到该界。∎ 推论：**合作越异质，越应"各自守门、取交"，而不是"共享一个阈值"**；站点数 S 增大时活性损失单调上升、安全覆盖不变——这是产学研规模化的真实代价。

**引理 145（能耗包络的计划级覆盖与预留充分性）** 设逐节点 `P(E_n>E_hi_n)≤δ_n`，取 `δ_n=δ_plan/T`。则 `P(E(π)>Σ_n E_hi_n)≤Σ_n δ_n=δ_plan`（无需独立性）。进一步，若 `Feas_E(π)` 成立且 `B_reserve` 含 `Δ_max`，则即使单个在飞节点突破包络，执行其 Fallback 并到达 Dock 的能量仍充分。证明：第一式由并集界。第二式：同一时刻至多一个节点在飞，故未记账溢出至多 `Δ_max`；预留 `max_i E_hi(Fallback_i→Dock)+Δ_max` 覆盖"回退路径 + 溢出"，而 `Feas_E` 保证该预留未被计划挪用。∎ 推论：**上包络不保证"永不超支"，但保证"超支也在预留里"**；检测延迟需计入 `Δ_max` 的测量窗。

**引理 146（能量不可逆律 / 截断不返还）** 对任意前缀截断 `π→π[:k]`，有 `spent` 不变、`B_t` 不增；截断仅减少 `E^plan(π[:k]→Dock)` 这类**未来**开销，绝不增加 `B_t`。故可行剩余计划集 `{π':Feas_E(π')}` 关于时间单调收缩。证明：`dB_t/dt=−power(t)≤0`，截断不改变历史功率积分；`Feas_E` 只依赖剩余量与未来上界。∎ 推论：**新鲜度阶梯可以"事后截短"止损，能耗阶梯必须"事前预留"防损**；任何把"截断"当作"电量返还"的调度都会在低电量下失稳。

**引理 147（能耗阶梯单调且与新鲜度阶梯可交换）** 设阈值 `B_DOCK≤B_RESERVE≤B_CONSERVE≤B_NORMAL`、允许族 `F_DOCK⊆F_RESERVE⊆F_CONSERVE⊆F_NORMAL`，`Exec(ELS_j)=Exec_v18∩{Feas_E(π;B_j)}∩F_j`。则 `Exec(ELS_{j+1})⊆Exec(ELS_j)`。且对新鲜度阶梯 `Ladder_fresh`，`Exec(ELS_i)∩Exec(Ladder_k)=Exec(Ladder_k)∩Exec(ELS_i)`，复合结果取两者更严一级且仍单调。证明：预算与允许族同时收紧，交集收缩；两级阶梯都只做"与某个可执行集取交"，交运算可交换且幂等，故复合不依赖顺序、不振荡。∎ 推论：**双阶梯的"可交换"来自它们都是集合交，而不是因为它们相似**；这解释了为何混合降级不会产生越级或拼接。

**引理 148（优化无特权 / 能耗排序不可扩）** 设 EPR 仅在 `Exec_v18∩{V≥v_min}∩{Feas_E}` 上按 `E^plan` 排序并返回 `π*`，不修改锚集、FCL 分位数、PSV 余量、EEC 包络或预留。则 `Exec(π*)⊆Exec_v18⊆Exec_v17`，`|NewAuth|=0`；且 EPR 只可能降低能耗、不可能放宽任何可行性约束。证明：选择函数的值域是输入可行集的子集；可行性约束未被修改。∎ 推论：**能耗优化的全部收益都来自"在证书内挑更省的"，一旦优化器获得改阈值权限，引理 143 立即失效**——故 EPR 必须与 CAB/FCL/EEC 进程隔离、只读访问。

## 6. 已知风险与失效模式

1. **准入门槛过严导致"合作即失活"**：`⊓` 后 NC 语义若不一致可能为空，外部能力全部 ⊥。缓解：证书本体对齐、语义映射校验、允许"族级"准入而非节点级。
2. **共模失效（本轮首要）**：CAB 与 EEC 共享同一环境测量，电池老化/地形/热漂移同时污染"信任"与"能量"。缓解：独立双通道测量（电量计+功率积分+模型残差）、共模漂移检测、漂移时同时收紧准入与包络。
3. **FCL Bonferroni 过度保守**：S 大时 `α/S` 使 FRR 急升，系统长期退 v17。缓解：加权 Bonferroni、站点聚类共享、层次化共形。
4. **分位数共享的隐私泄露**：一维分位数仍可能反推分布。缓解：DP 噪声、分位数区间上报、安全聚合；并重新推导噪声下的覆盖界（引理 144 需加噪声项）。
5. **能耗包络的分布漂移**：E_hi 在训练地形外失效，透支。缓解：在线包络更新、OOD 地形检测、突破即降级 + `Δ_max` 兜底。
6. **预留递归不可行**：`B_reserve` 依赖 Fallback→Dock 的可行路径，若 Dock 本身不可达则预留无穷大、系统冻结。缓解：预计算多坞可达性、预留失败时切机械急停/求救。
7. **热耦合使能耗与时延同时恶化**：κ_T 下调会同时抬高 E_hi 与延长执行，双阶梯同向下压。缓解：热优先降级、任务价值重加权、主动散热窗口。
8. **双阶梯振荡**：SoC 在阈值附近抖动导致 NORMAL/CONSERVE 反复切换。缓解：迟滞（已设 hyst）、锁定窗、降级不可逆到本次任务结束。
9. **优化器越权**：EPR 若被工程实现赋予"改阈值"旁路，引理 143/148 失效。缓解：EPR 只读、进程隔离、权限最小化、代码审计。
10. **合作方证书格式/本体不对齐**：同名不同义（"抓取"在工厂与实验室语义不同），取交后隐藏语义错配。缓解：证书带本体版本哈希、跨域映射表、准入沙箱回放。
11. **电池模型误差**：κ_age 估计偏差使 E_hi 系统性偏低。缓解：定期满充满放标定、残差监控、保守老化上限。
12. **站点评分不可比**：不同站点的 `s(π,x)` 定义不一致，取交失去意义。缓解：统一分数契约、站点级校准对齐、跨站点 A/B 审计。

## 7. 本轮最大风险

**一句话**：CAB 的准入证书与 EEC 的能耗包络依赖**同一套环境测量**（电池老化 `κ_age`、地形、热 `κ_T`）——一次未建模的分布漂移会让"信任"与"能量"两个看似独立取交/取并的保证在**同一隐变量下共模失效**，于是出现"外部证书本地复验通过、逐站点共形通过、包络可行、预留充足"却在实际地形/老化条件下同时越界并耗尽回退电量的计划，即被合作方与本地共同认证、却在共模漂移下既不安全又回不来的方案。
