# 第 5 轮（灵感循环第 5 轮；本轮灵感：「成本控制」×「电池管理」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。第 3 轮 InstructGauge、第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承。
> 本轮纪律：**增量升级 + 严格退化 + 安全地板**。成本与电池只允许分配**可自由支配**的资源，任何情况下不得买断安全验证；任一能量组件失效都必须退化为第 4 轮的保守固定参数版本。

## 0. 直觉与动机

**灵感 1（成本控制 → 预算不是一个数字，而是一个影子价格）**
直觉：工程里真正的成本控制不是「少花钱」，而是「把每一分钱花在能最大降低失败概率的地方」。因此成本应当被升格为**对偶变量 λ**，而不是硬砍预算的剪刀：它给「多验证一次」「多拍一帧」「把块缩短一步」标价，再让规划器在风险-成本前沿上选点。关键区别是**期权价值**：一次看似昂贵的验证，可能在不可逆动作前避免一次无法追回的失败；把验证当纯开销做近视优化，会系统性地低估它。成本控制因而是一个 constrained-MDP 的对偶问题，而不是一个会计问题。

**灵感 2（电池管理 → 电量不是油量表，而是改变被控对象的状态）**
直觉：电池管理在机器人里从来不只是剩余电量百分比。SoC/SoH/电压/温度同时改变**动力学可用包线**（扭矩、加速度）、**传感质量**（掉帧、曝光）与**热约束**。同一个动作在 80% 与 15% 电量下的风险并不相同；所以契约、阈值、可采纳集都必须**电池状态条件化**，且随电量下降只能收紧、不能放松。更进一步，电池在一个回合内单调消耗，使校准分布**非平稳**——共形覆盖不再自动成立，必须按电池制度分段校准，并为制度切换显式记账覆盖损失。

**灵感 3（两者耦合 → 省电最便宜的方式，恰好是关掉第 4 轮的安全件）**
直觉：如果让一个纯能量优化器自由决策，它发现的最优省电策略往往是：关腕部相机、跳过 SpatialCert、拉长块长、少做交叉验证——也就是精确地把第 4 轮刚建立的安全增强逐个拆掉。危险在于这些代价**不在当期能量表上**，只以稀有的灾难性失败体现。因此耦合处的正确结构不是「更聪明的节能」，而是**双账本 + 安全电量下限 + 有序降级**：安全验证不进入可支配预算；电量不足时按固定优先序削减**非安全**组件，安全件只会触发 K=1 / 安全停机，而不会被「省掉」。

## 1. 研究问题（本轮要回答什么）

- **Q1（成本能否不买断安全）**：把成本升格为对偶变量后，能否证明存在一个与 λ 无关的安全地板，使成本压力只能在前沿上移动、不能缩小安全可行域？
- **Q2（电池状态如何进入契约）**：SoC/SoH/电压/温度以什么方式进入可采纳集、漂移界与共形阈值，才能既真实反映能力退化、又保持单调性并继承第 4 轮的引理？
- **Q3（耦合是否单调劣化）**：当节能压力与指令分块耦合，能否用「安全电量下限 + 有序降级 + 不可逆屏障」把失败模式压成**可预测的单调退化**，而不是随机的安全件被裁撤？能量-风险前沿如何量化？

## 2. 四条设计原则（正式化见产物区定义 468–487）

**P4 双账本与安全电量下限（Two-Ledger + Safety Floor）**
总预算拆成 `B = B_floor + B_disc`。`B_floor` 预留给安全关键验证与不可逆动作的安全停机/交叉验证，是硬约束；成本优化只在 `B_disc` 上做。形式化：任何会侵入 `B_floor` 的计划直接判为不可行，而不是加罚项。这样「省钱」在类型上就无法买断安全。

**P5 电池状态条件化（Battery-Conditioned Contract）**
可采纳集、漂移界、`ε_vis`、最大块长都写成电池状态的函数：`A(a|b_bat)`, `drift_bound(s,b_bat)`, `ε_vis(b_bat)`, `K_max(b_bat)`。要求**单调降额**：电量越低，可采纳集越小、阈值越紧、块长越短，绝不反向放松。

**P6 有序降级、安全最后（Monotone Shedding, Safety-Last）**
预注册一个按关键性排序的组件偏序 `≤_shed`。降级只能按该序裁撤**前缀**；安全证书类组件排在最后且不可裁撤——当只剩安全件时，系统改为 K=1、拒绝不可逆动作或安全停机，而不是继续关传感器。

**P7 成本-风险对偶与分段校准（Option-Aware Dual + Regime Conformal）**
规划目标：在 `cost ≤ B_disc` 下最小化风险，用 λ 做对偶上升；成本要计入**期权价值**（失败代价与验证收益），不是近视能量。校准按电池制度（nominal / derated / reserve / critical）分段，制度内可交换、制度间不可交换；样本不足回退全局阈值并显式记账覆盖损失。

## 3. 与基线的接口（如何退化）

- 电池估计失效 ⇒ 使用**保守下界** SoC（只会更保守地降额），等价于第 4 轮参数但更安全；
- 成本模型不可用 ⇒ 令 λ=0、`B_disc` 取均匀预算，退回 ToolGauge 的固定预算规划；
- 能量下限不足以支撑不可逆动作 ⇒ 禁止该类动作、强制 K=1，退回 InstructGauge-WR 的安全子集；
- 分段校准样本不足 ⇒ 回退全局共形阈值并记录覆盖损失；
- 所有能量增强失效 ⇒ InstructGauge-WR v4 ⇒ InstructGauge v3 ⇒ ToolGauge ⇒ LeanGauge / MODGAUGE 原样。

## 4. 预期贡献

1. 一个**双账本预算**与「安全地板不变性」命题：成本压力（任意 λ）不能移动安全可行域；
2. 一族**电池状态条件化契约**（可采纳集 / 漂移界 / 时空阈值 / 块长上界），带单调降额引理并保持对第 4 轮引理的继承性；
3. 一个**安全最后的有序降级阶梯**，把「省电=拆安全件」压成可审计的固定顺序，并给出不可逆动作的能量预留充分条件；
4. 一条可证伪路径：E473–E488 覆盖预留不越界、降额单调、SoC 分段覆盖、降级序对抗、能量-分块最优、单位修复能耗与尾部失败率。

## 5. 本轮最大风险

**一句话**：成本与电池优化会以「当期能量指标变好」的方式奖励**近视地裁撤安全验证**，而这类裁撤的代价只以稀有尾部失败出现，因此最容易出现的失败不是算错电量，而是优化器悄悄把安全地板也算进了可支配预算——除非地板是硬约束、且安全件的实际使用频率被持续测量而不是假设。

## 2. 形式化定义（要点）

**定义 468（电池状态与不确定区间）** 电池状态 `b_bat(t) = (SoC, SoH, V, T)`。估计器输出区间 `[b⁻(t), b⁺(t)]`，满足真实状态 `b_bat(t) ∈ [b⁻, b⁺]` 的概率至少 `1-δ_b`。**安全相关计算一律使用 `b⁻`**（能力最悲观），能量核算使用同一 `b⁻`（可用能量最悲观），从而保证不会「低估退化」。

**定义 469（双账本预算）**
```
B_total = B_floor + B_disc
B_floor = E_stop_max + E_verify_max + E_retract_max
ledger = (u_floor, u_disc)
可行 ⇔ u_floor ≤ B_floor ∧ u_disc ≤ B_disc
```
安全关键支出（不可逆动作的交叉验证、安全停机预留、SpatialCert 复核）先记入 `u_floor`；成本优化器只能看到并支配 `B_disc`，且**禁止从 `B_floor` 借用**。若某项安全支出使 `u_floor > B_floor`，该计划不可行而非被罚。

**定义 470（电池条件化可采纳集）**
```
A(a | b) = { a ∈ A₀ :
             IK(a) 在关节限制内
             ∧ τ_req(a) ≤ τ_max(b)
             ∧ v_req(a) ≤ v_max(b)
             ∧ 冲突检测通过
             ∧ 热约束 T_req(a) ≤ T_limit(b) }
```
其中 `A₀` 为第 4 轮定义 449 的标称可采纳集。由此恒有 `A(a|b) ⊆ A₀`。

**定义 471（单调降额映射）** `derate(b)` 满足：若 SoC 或 SoH 下降、或温度偏离安全区，则 `v_max` 与 `τ_max` 不增、`ε_vis` 不减、`K_max` 不增。形式化：`b₁ ≼ b₂ ⇒ derate(b₁)` 的每个分量都不比 `derate(b₂)` 宽松。此处 `≼` 表示「电池更弱」。

**定义 472（综合成本模型）**
```
c(π) = Σ_{a∈π} E_exec(a) + E_sense(π) + E_compute(π)
     + E_verify(π) + c_wear(π) + λ_T · T(π)
```
各分项可由 EnergyReceipt 逐项审计；`c_wear` 为不可逆动作的磨损当量。

**定义 473（风险模型与期权价值）**
```
R(π) = E[ C_fail(π) ] + Q_{1-α}( score(π) )
```
`C_fail` 为失败代价（含不可逆损失），第二项为共形尾界。定义验证的**期权价值**为 `V_verify = R(π∖verify) - R(π)`：只有当 `V_verify > c(verify)` 时，节省验证才是真节约。

**定义 474（成本-风险对偶问题）**
```
π*(λ) = argmin_{π∈Π, 安全可行} [ R(π) + λ · max(0, c(π) - B_disc) ]
λ ← [ λ + η · (c(π*) - B_disc) ]₊ ，并做上界截断
```
`λ` 只对 `B_disc` 的价格起作用，不进入 `B_floor`。

**定义 475（安全电量下限的硬语义）** `B_floor` 是**预留容量**而非软目标：对任意计划，安全支出先扣 `B_floor`；若 `u_floor > B_floor`，计划被拒绝并进入降级阶梯。预算压力通过 λ 改变 `B_disc` 上的选择，**不能改变** `B_floor` 的数值或扣费顺序。

**定义 476（有序降级序）** 预注册全序 `C₁ ≤_shed C₂ ≤_shed … ≤_shed C_n`，并标记安全集 `S_safe`（SpatialCert 复核、运动学前缀验证、不可逆交叉验证）。不变量：`∀ i∈S_safe, ∀ j∉S_safe: j ≤_shed i`，且 `S_safe` 元素不可裁撤。

**定义 477（降级算子）**
```
shed(level) = { 前 level 个可裁撤组件 }        if level < |可裁撤|
              Fallback(K=1 / 禁不可逆 / 安全停机) if level ≥ |可裁撤|
```
降级只能裁撤该序的前缀；一旦触及安全区，系统切换为更保守的执行模式，而不是继续关闭安全件。

**定义 478（能量证书）**
```
E_receipt(claim) = ( claim_id, E_expected, E_actual,
                     SoC_start, SoC_end, regime,
                     reserve_ok, λ_at_commit )
```
每个 claim 绑定一张收据；`Σ E_actual + overhead = 实测总能耗`（在计量覆盖范围内）。

**定义 479（电池制度）** 由 SoC/SoH 阈值把状态空间划分为 `N`（nominal）、`D`（derated）、`R`（reserve）、`C`（critical）。制度函数 `r(b)` 分片常值；切换时记录 `(t, r→r')` 事件。

**定义 480（制度分段共形校准）** 对每个制度 `r`，用该制度内的校准分数 `S_r` 计算 `q_r = Quantile_{1-α}(S_r)`；预测集 `C_r(x) = {y : score(x,y) ≤ q_r}`。当 `|S_r| < n_min` 时回退 `q_global`，并记覆盖损失上界 `Δ_r = sup |F_r - F_global|`。

**定义 481（能量-风险前沿）**
```
F = { (E(π), R(π)) : π 安全可行 }
F* = Pareto 前沿
π* = argmin_{π∈F*} E(π)   s.t.  R(π) ≤ R_max
```
`R_max` 为预注册风险上限；若不存在满足 `R_max` 的点，进入降级而非越过风险上限。

**定义 482（摊销决策能量与最优块长）**
```
E(π_K) = E_dec / K + E_exec(K) + E_verify(K)
K* = argmin_K E(π_K)  s.t.  R(π_K) ≤ R_max  ∧  K ≤ K_max(b)  ∧  不可逆屏障
```
不可逆动作强制 `K=1`，因此 `K*` 的分段常数在不可逆处退化。

**定义 483（不可逆能量预留充分条件）** 对任意含不可逆动作的块 `C`，要求
```
B_floor ≥ E_stop(C) + E_verify(C) + E_retract(C)
```
否则禁止该不可逆动作并回退 K=1。

**定义 484（对偶更新与解释）** `λ` 是「再花一单位可支配预算所能降低的风险」的影子价格。`λ` 大表示预算紧、验证贵；`λ` 小表示预算松。λ 仅在 `B_disc` 上更新，且不改变 `B_floor`。

**定义 485（安全优先成本序）** 对两个计划 `π₁, π₂`，若 `c(π₁) < c(π₂)`，只有在 `安全等级(π₁) ≥ 安全等级(π₂)` 时，成本序才被允许用于选择；任何「以裁撤安全件换成本下降」的差异被定义为**不可比**，直接排除。

**定义 486（单位修复能耗）**
```
E_per_repair = Σ E_actual / N_success
E_per_repair_tail = Σ E_actual / N_success(τ)   # τ 为尾部风险截断
```
同时报告均值口径与尾部口径，防止用均值掩盖尾部失败。

**定义 487（电池感知漂移界）** `drift_bound(s, b)` 随电池退化单调不减，并满足 `drift_bound(s, b) ≥ drift_bound(s, nominal)`；用于约束块长与提交边界。

## 3. 关键算法骨架

```python
# IP-334 BudgetLedger
class BudgetLedger:
    def __init__(self, e_total, e_stop, e_verify, e_retract):
        self.B_floor = e_stop + e_verify + e_retract
        self.B_disc = max(0.0, e_total - self.B_floor)
        self.u_floor = 0.0
        self.u_disc = 0.0

    def reserve_ok(self, e_needed):
        return self.u_floor + e_needed <= self.B_floor

    def spend_safety(self, e):
        if not self.reserve_ok(e):
            return False
        self.u_floor += e
        return True

    def spend_disc(self, e):
        if self.u_disc + e > self.B_disc:
            return False
        self.u_disc += e
        return True

    def audit(self):
        return {
            "floor_used": self.u_floor, "floor_cap": self.B_floor,
            "disc_used": self.u_disc, "disc_cap": self.B_disc,
            "floor_violated": self.u_floor > self.B_floor,
        }

# IP-335 BatteryStateEstimator
class BatteryStateEstimator:
    def __init__(self, model, delta_b=0.05):
        self.model = model
        self.delta_b = delta_b

    def estimate(self):
        nominal = self.model.read()
        lower = BatteryState(
            soc=max(0.0, nominal.soc - self.delta_b),
            soh=max(0.0, nominal.soh - self.delta_b),
            v=max(0.0, nominal.v - self.delta_b * nominal.v_nominal),
            temp=nominal.temp + self.delta_b * nominal.temp_nominal,
        )
        return nominal, lower   # 规划只用 lower

# IP-336 DeratingContract
def derate(b):
    s = clamp01((b.soc - SOC_CRITICAL) / (SOC_NOMINAL - SOC_CRITICAL))
    return Derating(
        v_max=V_MAX * s,
        tau_max=TAU_MAX * s,
        eps_vis=EPS_VIS_0 * (2.0 - s),
        K_max=max(1, int(K_MAX_NOMINAL * s)),
    )

def battery_conditioned_admissible(action, b_lower, robot):
    d = derate(b_lower)
    if robot.required_torque(action) > d.tau_max:
        return False
    if robot.required_speed(action) > d.v_max:
        return False
    if robot.thermal_load(action) > d.thermal_limit:
        return False
    return robot.kinematically_valid(action)   # 继承第 4 轮

# IP-337 RegimeConformal
class RegimeConformal:
    def __init__(self, alpha=0.1, n_min=200):
        self.alpha, self.n_min = alpha, n_min
        self.q = {}

    def calibrate(self, scores_by_regime, scores_global):
        self.q_global = quantile(scores_global, 1 - self.alpha)
        for r, scores in scores_by_regime.items():
            if len(scores) >= self.n_min:
                self.q[r] = quantile(scores, 1 - self.alpha)
            else:
                self.q[r] = self.q_global   # 显式回退，记录覆盖损失

    def threshold(self, regime):
        return self.q.get(regime, self.q_global)

# IP-338 CostRiskDualPlanner
def plan_cost_risk_dual(M, s, iota, H, b_lower, ledger, lam):
    d = derate(b_lower)
    candidates = []
    for K in range(1, d.K_max + 1):
        C = M.iac.plan_chunk(iota, H, M.tools, K, M.budget_left(s))
        if C is None:
            continue
        if not M.kloop.verify_prefix_closed(C)[0]:
            continue
        if not all(battery_conditioned_admissible(a, b_lower, M.robot)
                   for a in C.actions):
            continue
        if has_irreversible(C) and K > 1:
            continue                       # 不可逆屏障：强制 K=1
        if has_irreversible(C) and not ledger.reserve_ok(C.reserve_energy):
            continue                       # 预留不足：拒绝不可逆
        cost = estimate_cost(C, d)
        if cost > ledger.B_disc:
            continue
        risk = estimate_risk(C, d)
        score = risk + lam * max(0.0, cost - ledger.B_disc)
        candidates.append((score, risk, cost, K, C))
    if not candidates:
        return None
    return min(candidates, key=lambda t: t[0])[4]

# IP-339 SheddingLadder
SHED_ORDER = [
    "beauty_render", "redundant_sensing", "wristcam_fps",
    "spatial_cert_rate", "kinematic_samples",
]
SAFE_SET = {"spatial_cert_verify", "kinematic_prefix_verify",
            "irreversible_cross_verify"}

def apply_shedding(level, components):
    shedable = [c for c in SHED_ORDER if c in components]
    assert all(c not in SAFE_SET for c in shedable)
    if level >= len(shedable):
        return "FALLBACK_K1_OR_ABORT"
    return set(shedable[:level])

# IP-340 主闭环
def econ_gauge_repair(M, s, ell=None):
    _, b_lo = M.battery.estimate()
    if not M.ledger.reserve_ok(M.safety.reserve_needed(s)):
        M.shedding.apply("FALLBACK_K1_OR_ABORT")

    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota

    if C is None:
        M.shedding.apply(M.shedding.next_level())
        return None
    C, spatial_cert, claims = instructgauge_wr_core(M, s, ell, C)
    overhead = M.energy_meter.overhead_since(C.start_time)
    M.ledger.spend_disc(estimate_cost(C, derate(b_lo)))
    receipt = EnergyReceipt(
        claim_id=C.id,
        E_expected=C.expected_energy,
        E_actual=M.energy_meter.actual_since(C.start_time) + overhead,
        SoC_start=C.soc_start, SoC_end=b_lo.soc,
        regime=r(b_lo), reserve_ok=M.ledger.reserve_ok(0),
        lam_at_commit=M.dual.lam,
    )
    attach_receipt(claims, receipt)
    M.dual.update(cost=receipt.E_actual, budget=M.ledger.B_disc)
```

## 4. 推导

**引理 63（双账本安全不变性）** 设 `B_floor` 与扣费顺序固定。对任意 `λ ≥ 0`，对偶问题 474 的可行解都满足 `u_floor ≤ B_floor`，且 `B_floor` 的扣费与 `B_disc` 的分配互不借用。因此成本压力只能改变 `B_disc` 上的选择，不能缩小安全可行域。证明：由定义 469 与 475，安全支出先扣 `B_floor`，`λ` 只出现在 `B_disc` 的松弛项中；若安全支出超过 `B_floor`，计划在进入 λ 目标前即被可行性判定拒绝。故安全可行域 `Π_safe` 与 λ 无关。∎

**引理 64（降额单调性）** 若 `b₁ ≼ b₂`（电池更弱），则 `A(a|b₁) ⊆ A(a|b₂)`，`ε_vis(b₁) ≥ ε_vis(b₂)`，`K_max(b₁) ≤ K_max(b₂)`。证明：定义 471 要求每个降额分量在更弱电池下不更宽松；定义 470 的可采纳集由这些上界逐项取交集，上界收紧只会删元素，不会增元素。∎

**引理 65（安全最后降级的正确性）** 若 `≤_shed` 把所有安全件排在所有非安全件之后并标记为不可裁撤，则对任意降级级别 `level`，在被裁撤集合触及 `S_safe` 之前，`shed(level) ∩ S_safe = ∅`；一旦只能裁撤安全件，系统按定义 477 进入 Fallback，而不是裁撤安全件。证明：对全序长度归纳。由于可裁撤集合是 `≤_shed` 的前缀且 `S_safe` 位于末尾，任何仍存在非安全可裁撤件的前缀都不含 `S_safe`；当非安全件耗尽时 `level ≥ |可裁撤|`，进入 Fallback 分支。∎

**引理 66（制度内共形覆盖）** 在制度 `r` 内，若校准分数与测试分数可交换，则由定义 480 的 `q_r` 给出的预测集满足 `P(Y ∈ C_r(X)) ≥ 1-α`。跨制度不保证；回退全局阈值时，覆盖差被 `Δ_r = sup|F_r - F_global|` 界定。证明：制度内是标准 split-conformal 设定；跨制度时分布不同，可交换性失效，覆盖损失由分布差异上界控制。∎

**引理 67（块长摊销的有限最优）** 若 `E_exec(K)` 与 `E_verify(K)` 关于 K 凸且增长，失败风险 `R(K)` 关于 K 超线性增长，则 `E(π_K) = E_dec/K + E_exec(K) + E_verify(K)` 在 `R(K) ≤ R_max` 下有有限最优 `K*`；不可逆动作强制 `K=1` 只会在分段边界引入常数下界。证明：`E_dec/K` 随 K 下降，`E_exec+E_verify` 随 K 上升，二者平衡给出有限 K；风险约束与 `K_max(b)` 进一步截断可行域。∎

**引理 68（对偶解的 Pareto 性）** 若 `R` 与 `c` 在 `B_disc` 上凸，则对每个 `λ ≥ 0`，问题 474 的解落在能量-风险前沿 `F*` 上；若问题非凸，则只能保证得到**支撑点**（supported point），可能漏掉非支撑的 Pareto 点。证明：凸情形由拉格朗日对偶的标准支撑超平面论证；非凸情形存在无法被任何正 λ 支撑的 Pareto 点，这是本方案需要显式承认的局限。∎

**引理 69（能量证书可审计性）** 若计量覆盖了执行、传感、计算与验证能耗，且 overhead 有界可测，则 `Σ E_receipt + Σ overhead = 实测总能耗`；不存在未记账的「隐藏能量」。证明：由能量守恒与账本逐项求和直接得到；若某分项未被计量，则收据不完备，审计结论只能限定在已计量域。∎

**引理 70（退化等价性）** 关闭电池估计器并令 `b⁻ = b_nominal` 时，`derate` 返回第 4 轮固定参数；令 `B_floor=0`、`B_disc=B_total` 时，双账本退化为单账本；令 `λ=0` 时，对偶规划退化为固定预算规划。三者同时成立时，EconGauge 在接口上精确退化为 InstructGauge-WR。证明：逐项代入定义 468–487，所有新增项取中性值，目标与约束回到第 4 轮形式。∎

**引理 71（对第 4 轮前缀封闭的继承性）** 因 `A(a|b) ⊆ A₀`，若块在电池条件化可采纳集下逐前缀合法，则它在标称可采纳集 `A₀` 下也逐前缀合法；因此第 4 轮定义 449 的前缀封闭验证器对 EconGauge 仍然**可靠**（可能拒绝更多，但不会放过更少）。证明：集合包含关系对逐元素逐前缀成立，可靠性的单向包含直接传递。∎

**引理 72（不可逆预留充分性）** 若 `B_floor ≥ E_stop(C) + E_verify(C) + E_retract(C)` 对任意被允许的不可逆块 `C` 成立，则即使块在执行中触发最坏情形，系统仍有足够能量完成安全停机、交叉验证与安全回撤。证明：由定义 483 的预留覆盖最坏情形所需能量，且能量消耗非负单调，预留只会被高估而不会被低估。∎

## 8. 本轮最大风险

**一句话**：成本与电池优化会以「当期能量指标变好」的方式奖励**近视地裁撤安全验证**，而这类裁撤的代价只以稀有尾部失败出现，因此最容易出现的失败不是算错电量，而是优化器悄悄把安全地板也算进了可支配预算——除非地板是硬约束、且安全件的实际使用频率被持续测量而不是假设。
