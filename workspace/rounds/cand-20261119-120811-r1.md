# 第 14 轮（新灵感循环第 5 轮；本轮灵感：「仿真训练」×「机械臂抓取」）

> **基线**：第 13 轮 MetricVoiceGauge-NCD-HUTDH v15（技能扩散版；定义 607–626；引理 125–130；实验 E661–E670）。
> **本轮纪律**：不推倒 v15。v6–v15 的九个不变式、v13 的 AIO/CPD/DDL/RTCR、v15 的 SCD/DSD/DCA/EDC 全部保留。四个新组件——SRG（仿真—现实间隙证书，含 GC）、CDR（可证域随机化集成，含 δ-网）、SGC（仿真引导主动校准，含 ACI 修正）、DTS（数字孪生漂移监督）——一律以**中立元**接入，失效即严格退回 v15，再沿 v15→v14→…→v6 退化链回收。本轮只做三件事：把"仿真训练"从数据扩增改写为**间隙证书下的经验授权补全**；把"机械臂抓取"从末端任务改写为**接触流形上的可证域迁移**；把二者合成"仿真扩覆盖、现实认证间隙、漂移即塌缩"的双域闭环。

## 0. 直觉与动机

**灵感 1（仿真训练 → 仿真只补经验空白，不越语义边界）**
直觉：v15 的语义层 `Exec_v15` 已经回答"理论上哪些抓取/组合被允许"，但真实校准集受限于抓取成本与破坏风险，接触边界附近几乎采不到样本，于是**经验授权集** `Acc_v15^real` 往往远小于 `Exec_v15`——系统不是不许可，而是不敢放行。仿真能把接触边界廉价铺满，但 sim-to-real 存在间隙。核心创新：**仿真—现实间隙证书（Sim-to-Real Gap Certificate, SRG）+ 间隙校正授权（Gap-Corrected Authorization, GCA）**。SRG 用两样本 IPM 与有限样本置信界给出真实风险差的上界 `Ĝ`；GCA 只在 `m_ens(a,x) − Ĝ ≥ U_d` 时授权。关键反直觉点：**仿真的价值不是"让模型平均上更像现实"，而是"把稀缺的真实校准预算花在缩小区间上"**；仿真授权必须是 gap-corrected 的**下界**，绝不使用平均成功率或平均 sim2real 误差。

**灵感 2（机械臂抓取 → 接触不确定集，而非单一名义仿真）**
直觉：抓取的安全边界不是一条光滑曲面，而是一族受摩擦锥、接触几何、关节柔顺与传感/控制延迟共同决定的薄流形。单点"高保真仿真"再准，也只是该流形上的一个样本；真实工件的 μ、质心、表面状态一变，名义仿真就可能把"临界夹持"误判为"稳定夹持"。核心创新：**可证域随机化集成（Certified Domain Randomization, CDR）+ 接触不确定集 δ-网**。我们声明一个接触不确定集 `U_contact`（μ、e、τ_d、K_c 等），用 δ-网离散成 K 个仿真器，授权取**交集** `Acc_ens = ⋂_k Acc_k`，余量取下确界 `m_ens = min_k m_k`。关键区别：普通域随机化优化**平均鲁棒性**，CDR 把随机化范围写进证书声明，交集直接给出"声明域内的最坏情形"，并用并集界控制 δ-网外推误差。**不是把仿真调得更真，而是把"真"定义成一个可证集合。**

**灵感 3（仿真×抓取 → 双域闭环、主动校准与漂移塌缩）**
直觉：既然仿真便宜、真实昂贵且危险，就不该"先在仿真练好再一次性迁移"，而应让两者结成闭环：仿真负责**探索与排序**（哪些接触区域值得试、哪些候选最可能安全且信息量大），现实负责**认证与封顶**（只用真实抓取样本收紧 `Ĝ` 与共形分位）。核心创新：**仿真引导主动校准（Simulation-Guided Calibration, SGC）+ 数字孪生漂移监督（Digital Twin Supervisor, DTS）**。SGC 只从"可回退安全区"里选真实探针，采集函数是"单位风险的间隙信息增益"；DTS 在线辨识孪生参数 `θ̂_t`，一旦真实分布偏离声明的 `U_contact` 或残差 CUSUM 越界，立刻把模式切到 `real-only`，禁止任何 i≥1 的仿真授权。**仿真买来的是覆盖与排序，现实买来的是授权；两者用 `Ĝ` 这一种货币结算。**

**三者如何统一**
统一为 **v15 语义/实现层之上的"域层"**：v15 回答"哪些动作在语义上被允许、且在本帧时限内能执行多少"（`Exec_v15`）；v16 回答"在声明域 `U_contact` 内、经间隙校正后，这些动作里哪些可以被经验授权"（`Acc_v16`）。包含关系是硬约束：

```
Acc_v15^real  ⊆  Acc_v16  ⊆  Exec_v15
```

左边界保证"仿真不会比真实校准更保守地丢掉已证动作"，右边界保证"仿真永远不会越过语义层新增权限"。共享状态 `ζ_sim = (Ĝ, Θ_K, m_ens, U_d, B_cal, Δ_twin, θ̂_t, mode)`。**SRG 回答"仿真与现实差多少、这个差的上界够不够薄"，CDR 回答"声明域内最坏情形还安全吗"，SGC 回答"下一颗真实抓取该花在哪"，DTS 回答"现实是否已经跑出声明域、要不要塌缩"。**

## 1. 研究问题（轮次升级版）

- **Q1（间隙证书的可证性与可算性）**：如何用有限真实样本给出 `sup_h |R_real(h) − R_sim(h)|` 的置信上界？IPM/Wasserstein 界在接触损失（滑移、掉落、碰撞的指示函数）非 Lipschitz 处如何修正？`Ĝ` 的紧致性与保守性如何权衡，样本量 n 与间隙 `Ĝ` 的收敛率是什么？
- **Q2（接触不确定集与认证域随机化）**：如何构造既覆盖真实接触模式、又不至于大到清空授权集的 `U_contact`？δ-网规模 K 与并集界、在线开销、保守性如何折衷？当真实参数落在网眼或集合外时，DTS 能否在有限步内检出并塌缩？"认证 DR"与普通 DR 的收益差如何定量？
- **Q3（主动校准与共形交换性）**：主动选择真实抓取会破坏校准样本的交换性，如何在选择偏差下仍保持覆盖率？采集函数如何同时惩罚风险、成本与信息重叠？SGC 能否保证"每颗真实样本都不降低安全性，且期望收紧 `Ĝ`"？
- **Q4（与 v15 的兼容、活性和退化）**：如何保证 `Acc_v16 ⊆ Exec_v15` 不被仿真旁路？`Ĝ` 与 v13 的 `U_d`、v15 的 `ρ_cov`、`τ` 是否会误差叠加而在新场景共同低估？塌缩到 real-only 或第 0 档是否会长时清空可行集？新增域层能否守住 50Hz/p99≤22ms，并严格退回 v15？

## 2. 设计原则（在 P22–P24 基础上新增 P25–P27）

**P25 仿真只扩候选、不授权限律（Simulation Expands Candidates, Never Grants Authority）**
仿真输出只能进入"候选排序"与"经验授权补全"两个通道，且必须经 SRG 的 `Ĝ` 校正；任何未经间隙校正的仿真成功/失败统计不得直接放行动作。仿真授权集的每一点都必须同时属于 v15 语义层 `Exec_v15`，禁止用仿真结果覆盖、放宽或旁路 v15 的 TGC/UC/四重证书。

**P26 间隙单调保守律（Gap-Monotone Conservatism）**
授权集对间隙上界单调收缩：若 `Ĝ₁ ≤ Ĝ₂`，则 `Acc(Ĝ₂) ⊆ Acc(Ĝ₁)`；对真实校准样本单调扩张：在固定校准抽取下，样本增加只会收紧 `Ĝ`、不会松动任一已证阈值。`U_contact` 只允许在"真实覆盖检验通过"后扩张；任何扩张都必须重算 `Ĝ` 与 `Acc`，不得沿用旧证书。

**P27 双域非对称与可塌缩律（Dual-Domain Asymmetry and Collapsibility）**
真实失败（滑移、掉落、碰撞、越界）的代价严格大于仿真失败与假拒绝；训练/排序的非对称代价只影响候选次序，不得改写证书阈值。SGC 的真实探针必须落在"失败可被回退/柔顺/急停吸收"的 `SafeProbe` 内。DTS 一旦判定真实参数越出声明域、残差超界或 ACI 长期欠覆盖，必须**安全塌缩到 real-only**，禁止继续用仿真授权"赌一把"。

## 3. 与基线的接口（如何退化）

- SRG 失效 ⇒ `Ĝ ≡ +∞`，间隙校正授权集为空，仿真退化为纯可视化/排序工具，**等价 v15 的 real-only 经验授权路径**；
- CDR 失效 ⇒ `K=1` 单一名义仿真且 `U_contact` 收缩为点集，并集界消失、间隙上界按最坏情形放大，**等价"v15 + 单仿真 SRG"**；
- SGC 失效 ⇒ 真实校准退回被动/随机采样，`Ĝ` 收敛变慢但每条已证边界不变，**等价"v15 校准路径 + SRG"**；
- DTS 失效 ⇒ 无在线漂移监督，只能使用离线固定的保守 `Ĝ` 与 `U_contact`，**等价"静态域证书 + v15"**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH v15（技能扩散版），再沿 v15→v14→v13→v12→…→v6 退化链回收；
- **安全继承**：SRG 只做间隙校正，CDR 只做声明域内取交，SGC 只做探针选择，DTS 只做塌缩。四端口均不能新增授权或放宽阈值；`Acc_v16 ⊆ Exec_v15` 由引理 138 保证，运行时再与 v15 的时限/守卫结果取交，得到 `Exec_v16`。

## 4. 预期贡献

1. **仿真—现实间隙证书**：把 sim-to-real 从"平均迁移精度"改写为"可校准的风险差上界 `Ĝ`"，并给出 `m_ens − Ĝ ≥ U_d` 的授权规则，使仿真数据第一次可以在安全关键授权链里被**有界地**使用；
2. **认证域随机化**：把域随机化从"提升平均鲁棒性"改写为"声明不确定集上的最坏情形证书"，用 δ-网 + 并集界把连续接触参数的不确定性纳入可证框架；
3. **仿真引导的主动校准**：在真实抓取昂贵且危险的前提下，把"下一颗样本采哪里"变成"单位风险的间隙信息增益最大化"，并给出选择偏差下的共形覆盖修正；
4. **双域退化语义**：建立 `Acc_v15^real ⊆ Acc_v16 ⊆ Exec_v15` 的补全关系与"域漂移即塌缩"的监督器，使仿真只买覆盖、不买权限；E671–E690 覆盖间隙有效性、接触集覆盖、主动校准、漂移塌缩、端到端与消融。

## 5. 本轮最大风险

**一句话**：间隙证书只在"真实接触模式落在声明不确定集 `U_contact` 内、且 IPM 上界足够紧"时成立；若真实抓取出现未建模的接触模式（微滑、黏滑转换、局部塑性形变、夹爪卡滞），`Ĝ` 会系统性低估真实间隙，于是仿真授权的抓取在"统计上已校准、域内看起来可证"的表象下执行了一个接触模式外的危险动作——即**校准过、域内自洽、却在建模边界外失效的安全决定**。

# IP-402 Sim-to-Real Gap Certificate：两样本 IPM 置信上界
class SimToRealGapCertificate:
    def __init__(self, loss_lipschitz=1.0, delta=0.05):
        self.L = loss_lipschitz      # 损失对特征/余量的 Lipschitz 常数
        self.delta = delta

    def ipm_upper_bound(self, D_S, D_R):
        # 1) 判别器/核两样本估计 d_IPM
        d_hat = self._discriminator_ipm(D_S, D_R)
        # 2) 有限样本置信项（Hoeffding/VC 或 bootstrap 上分位）
        n = min(len(D_S), len(D_R))
        conf = self._vc_confidence(n, self.delta / 2)
        return d_hat + conf

    def certify(self, D_S, D_R):
        d_ub = self.ipm_upper_bound(D_S, D_R)
        G_hat = self.L * d_ub
        # 3) 增益检查：间隙过宽则证书失效（返回 +inf）
        if self.L * d_ub > self.max_useful_gap:
            return float('inf'), 0.0
        return G_hat, 1.0 - self.delta

    def _discriminator_ipm(self, D_S, D_R):
        # 训练域判别器 f，d_IPM ≈ sup_{f∈F} |E_S f − E_R f|；F 与 H 的复杂度匹配
        f = self._fit_discriminator(D_S, D_R)
        return abs(self._mean(f, D_S) - self._mean(f, D_R))

    def _vc_confidence(self, n, delta):
        return self._vc_radius(n) + np.sqrt(np.log(1.0 / delta) / (2.0 * n))


# IP-403 Certified Domain Randomization：声明域内取交集
class CertifiedDomainRandomization:
    def __init__(self, U_contact, delta_net=0.05, K_max=16):
        self.U = U_contact
        self.delta = delta_net
        self.theta_net = self._build_delta_net(U_contact, K_max)
        self.sims = [ContactSimulator(theta) for theta in self.theta_net]

    def _build_delta_net(self, U, K_max):
        # 在声明盒/椭球上做贪心覆盖，返回 <= K_max 的 δ-网
        return greedy_cover(U, target_delta=self.delta, max_points=K_max)

    def margins(self, a, x):
        return np.array([sim.margin(a, x) for sim in self.sims])

    def ensemble_margin(self, a, x):
        return float(np.min(self.margins(a, x)))   # m_ens

    def certify_cell(self, a, x):
        # 并集界：网外点的余量下界 = m_ens − L_θ·δ
        m_ens = self.ensemble_margin(a, x)
        return m_ens - self.L_theta * self.delta      # 声明域内的保守余量

    def contract(self, U_new):
        # 只在真实覆盖检验通过后收缩（禁止无证据扩张）
        assert self._real_coverage_ok(U_new), "未通过覆盖检验，禁止改域"
        self.U = U_new
        self.theta_net = self._build_delta_net(U_new, len(self.theta_net))
        self.sims = [ContactSimulator(theta) for theta in self.theta_net]


# IP-406 Gap-Corrected Authorization：授权补全（只补经验空白）
class GapCorrectedAuthorization:
    def __init__(self, gap_cert, cdr, v15_semantic, v15_real_cert):

        self.cdr = cdr
        self.Exec_v15 = v15_semantic      # 语义允许集（只读，不可改）

    def authorize(self, x, U_d, G_hat):
        if np.isinf(G_hat):
            return set(self.Acc_real)     # 无间隙证书：严格退回 real-only
        out = set()
        # 只在 Exec_v15 内遍历；仿真永远不能越语义边界
        for a in self.Exec_v15.actions_at(x):
            margin = self.cdr.certify_cell(a, x)     # m_ens − L_θ·δ
            if margin - G_hat >= U_d:                # 间隙校正 + 共形余量
                out.add(a)
        out |= set(self.Acc_real)                    # 永不丢失已证动作
        return out & set(self.Exec_v15)              # 右边界硬保证


# IP-404 Simulation-Guided Calibration：主动校准 + ACI
class SimulationGuidedCalibration:
    def __init__(self, srg, safe_probe, budget, gamma=0.05):
        self.srg = srg
        self.SafeProbe = safe_probe       # 失败可回退/柔顺/急停吸收的探针集
        self.B = budget
        self.gamma = gamma
        self.alpha_t = 0.05               # ACI 动态风险水平

    def acquisition(self, x, posterior):
        best, best_score = None, -np.inf
        for q in self.SafeProbe.candidates(x):
            ig = posterior.expected_gap_reduction(q)     # 期望缩小 Ĝ
            risk = self.SafeProbe.risk_upper(q)          # 失败代价上界
            score = ig / (risk + 1e-6)                   # 单位风险的间隙增益
            if score > best_score:
                best, best_score = q, score
        return best

    def step(self, x, posterior, execute_probe):
        if self.B.remaining <= 0 or not posterior.gap_is_actionable():
            return None
        q = self.acquisition(x, posterior)
        y = execute_probe(q)                  # 真实执行；q ∈ SafeProbe
        self.B.spend(risk=self.SafeProbe.risk_upper(q))
        # ACI：用真实覆盖误差动态调整 α，抵御主动选择带来的交换性破坏
        err = 1.0 - y.covered
        self.alpha_t = np.clip(self.alpha_t + self.gamma * (0.05 - err), 0.01, 0.5)
        posterior.update(q, y, alpha_t=self.alpha_t)
        return q, y


# IP-405 Digital Twin Supervisor：在线辨识 + 漂移塌缩
class DigitalTwinSupervisor:
    def __init__(self, cdr, gap_hat, kappa=0.5, cusum_h=4.0):
        self.cdr = cdr
        self.G = gap_hat
        self.kappa = kappa
        self.cusum_h = cusum_h
        self.S = 0.0
        self.theta_hat = cdr.theta_net[0]

    def update(self, real_residual, x):
        # 1) 在线参数辨识（残差最小二乘/滤波），估计 θ̂_t
        self.theta_hat = self._identify(real_residual, x)
        # 2) 域外检验：θ̂_t 是否仍在声明集内
        in_domain = self.cdr.U.contains(self.theta_hat)
        # 3) 残差 CUSUM
        self.S = max(0.0, self.S + real_residual - self.kappa * self.G)
        drift = (not in_domain) or (self.S > self.cusum_h * max(self.G, 1e-6))
        if drift:
            return 'collapsed', self.theta_hat
        if real_residual > self.G / 2.0:
            return 'real-only', self.theta_hat   # 收窄但不全塌缩
        return 'sim-assisted', self.theta_hat


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v16（仿真—现实证书版）
def metricvoicegauge_round_16_sim2real(M, s, obs, v15_ctx, domain_ctx):
    # ---- v15 主路径原样保留（MW→NGE→HCC→HDT→HATD→NCP→SCD→守卫）----
    v15_out = v15_ctx.run_cycle(obs)
    Exec_v15 = v15_out.semantic_set          # 语义允许集
    Acc_real = v15_out.real_certified_set    # v15 真实已证集
    U_d = v15_out.U_d

    # ---- SRG：间隙证书（低频刷新，非关键路径）----
    srg = SimToRealGapCertificate(loss_lipschitz=domain_ctx.L, delta=domain_ctx.delta)
    G_hat, conf = srg.certify(domain_ctx.D_S, domain_ctx.D_R)

    # ---- CDR：声明域内取交----
    cdr = CertifiedDomainRandomization(domain_ctx.U_contact,
                                       delta_net=domain_ctx.delta_net,
                                       K_max=domain_ctx.K_max)

    # ---- DTS：先判模式，后授权----
    dts = DigitalTwinSupervisor(cdr, G_hat)
    residual = domain_ctx.twin_residual(obs)
    mode, theta_hat = dts.update(residual, obs)

    # ---- GCA：只有非 collapsed 才用仿真授权----
    gca = GapCorrectedAuthorization(srg, cdr, Exec_v15, Acc_real)
    if mode == 'collapsed':
        Acc_v16 = set()                       # 只允许 Fallback / a_ask
    elif mode == 'real-only':
        Acc_v16 = set(Acc_real)               # 不看仿真
    else:
        Acc_v16 = gca.authorize(obs, U_d, G_hat)

    # ---- 与 v15 时限/守卫结果取交：Exec_v16 ⊆ Exec_v15 ----
    Exec_v16 = Acc_v16 & v15_out.within_deadline_set & v15_out.guard_ok_set
    if not Exec_v16:
        execute_fallback_or_ask(v15_out.fallback, obs)
        return v15_out

    # ---- SGC：用剩余预算选真实探针（异步、低频）----
    if mode == 'sim-assisted' and domain_ctx.calibration_due:
        sgc = SimulationGuidedCalibration(srg, domain_ctx.SafeProbe, domain_ctx.B_cal)
        sgc.step(obs, domain_ctx.gap_posterior, domain_ctx.execute_probe)

    # ---- 低频重认证：刷新 Ĝ、U_contact、U_d ----
    if domain_ctx.recalib_due:
        domain_ctx.D_R = domain_ctx.real_buffer.snapshot()
        G_hat, _ = srg.certify(domain_ctx.D_S, domain_ctx.D_R)
        if domain_ctx.real_coverage_ok():
            cdr.contract(domain_ctx.U_contact_new)
    return v15_out.rebind(Exec_v16=Exec_v16, mode=mode, G_hat=G_hat)

## 2. 定义（607 续编号）

**定义 627（双域风险与间隙）** 设 `P_S, P_R` 为仿真/真实域分布，`ℓ∈[0,1]` 为抓取损失，`H` 为共享策略类。定义风险 `R_D(h)=E_{P_D}ℓ(h(x),x)` 与真实间隙
```
G = sup_{h∈H} |R_R(h) − R_S(h)| .
```

**定义 628（仿真—现实间隙证书 SRGC）** 三元组 `(Ĝ, 1−δ, F)` 是 `(H,ℓ,P_S,P_R)` 的间隙证书，若对校准抽取有
```
Pr[ G ≤ Ĝ ] ≥ 1−δ ,
```
且 `Ĝ = L·\hat d_F(D_S,D_R) + c_F(n,δ)`，其中 `F` 为与 `H` 复杂度匹配的判别器类，`\hat d_F` 为经验 IPM，`c_F` 为有限样本置信项。实现中取 `\hat d_F` 为域判别器的最优间隔、`c_F` 为 VC/覆盖数半径加 Hoeffding 项。

**定义 629（接触不确定集与 δ-网）** 接触参数 `θ=(μ,e,τ_d,K_c,c_x)`，声明集 `U_contact = ∏_i [θ_i^-,θ_i^+]`。`Θ_K` 是 `U_contact` 的 δ-网，若 `∀θ∈U_contact, ∃θ_k∈Θ_K: ‖θ−θ_k‖∞ ≤ δ`。**假设 A1**：真实接触参数 `θ_R^*∈U_contact`（DTS 负责证伪该假设）。

**定义 630（认证域随机化 CDR）** 给定 `Θ_K`，对动作 `a` 定义
```
m_ens(a,x) = min_{k≤K} m_k(a,x) ,      Acc_ens(x) = ⋂_{k≤K} Acc_k(x) ,
```
并对网外点使用 Lipschitz 外推 `m_dom(a,x) = m_ens(a,x) − L_θ·δ`。

**定义 631（间隙校正授权集 GCA）** 以 v15 语义集为硬边界：
```
Acc_v16(x) = { a ∈ Exec_v15(x) : m_dom(a,x) − Ĝ ≥ U_d } ∪ Acc_v15^real(x) .
```
其中 `U_d` 沿用 v13/v15 的共形余量定义，本层不重新估计。

**定义 632（执行集）** 运行时执行集
```
Exec_v16(x) = Acc_v16(x) ∩ DeadlineSet_v15(x) ∩ GuardOK_v15(x) .
```
由构造直接有 `Exec_v16 ⊆ Exec_v15`。

**定义 633（授权补全率与间隙样本效率）**
```
ρ_fill = |Acc_v16| / |Exec_v15| ,    ρ_fill^0 = |Acc_v15^real| / |Exec_v15| ,
GSE = (ρ_fill − ρ_fill^0) / n_real .
```

**定义 634（主动校准采集函数 SGC）** 真实探针 `q` 的信息增益与风险比
```
IG(q) = H(Ĝ | D) − E_{y∼P_R(·|q)} H(Ĝ | D ∪ {(q,y)}) ,
q* = argmax_{q ∈ SafeProbe ∩ Exec_v15} IG(q) / (r(q)+ε) ,
```
其中 `r(q)` 为失败/碰撞/掉落代价的保守上界，`SafeProbe` 为失败可被柔顺/急停/回退吸收的探针集。

**定义 635（选择偏差下的共形修正 ACI）** 设目标风险 `α`、第 t 步覆盖误差 `err_t`，采用
```
α_{t+1} = Π_{[α_min,α_max]} ( α_t + γ(α − err_t) ) ,
```
并在留出的交换性校准集上复算 `U_d`，主动集只用于探索、不直接进入最终分位。

**定义 636（孪生漂移 DTS）** 在线辨识 `θ̂_t`，定义
```
Δ_twin = d_F( P_R^t , P_S^{θ̂_t} ) ,   S_t = max(0, S_{t−1} + r_t − κ·Ĝ) ,
```
触发条件：`θ̂_t ∉ U_contact` 或 `S_t > h` 或 `Δ_twin > Ĝ/2`。

**定义 637（域层模式）**
```
mode = collapsed     若 DTS 触发域外/漂移；
       real-only     若 Δ_twin ∈ (Ĝ/2, Ĝ] 或 Ĝ=+∞；
       sim-assisted  否则。
```

**定义 638（双域状态）** `ζ_sim = (Ĝ, Θ_K, m_ens, U_d, B_cal, Δ_twin, θ̂_t, mode)`，与 v15 的 `ζ_comb` 正交组合：`ζ_v16 = ζ_v15 ⊗ ζ_sim`。

**定义 639（接触安全余量）** `m_k(a,x) = min{ m_slip, m_closure, m_reach, m_force }`，各项为归一化到 `[0,1]` 的最小裕度：抗滑裕度 `(f_t − |f_n|·μ)/f_max`、力闭合裕度、可达裕度与夹持力裕度。`m ≥ 0` 表示在该仿真器下物理可行。

**定义 640（保守增益）** 记 `Δρ = ρ_fill − ρ_fill^0`，仿真训练的净收益为
```
Net = Δρ·V_task − λ_R·n_real·c_real − λ_S·|Θ_K|·c_sim − λ_risk·P_collapse ,
```
只在 `Net > 0` 且 `P_collapse ≤ ε` 时允许启用 sim-assisted。

## 3. 推导（引理 131–138）

**引理 131（间隙校正迁移安全）** 若 `m_dom(a,x)` 对 `ℓ` 是 `L`-Lipschitz、`G ≤ Ĝ`，且 `m_dom(a,x) − Ĝ ≥ U_d`，则真实域上该动作的失败概率满足 `P_R(fail|a,x) ≤ α_d`。证明：`m_R ≥ m_S − G ≥ m_dom − Ĝ ≥ U_d`；由 v13 DGC 的共形构造，余量达到 `U_d` 即覆盖率 `≥1−α_d`。∎ 推论：**仿真买到的每一点授权，都要先支付 `Ĝ` 的"关税"**；间隙越宽，授权集越小，但已授权的每一点都保留真实域保证。

**引理 132（集成交集的保守性即覆盖）** 若 `Θ_K` 是 `U_contact` 的 δ-网且假设 A1 成立，则对任意 `θ∈U_contact`，
```
m_dom(a,x) = m_ens(a,x) − L_θδ ≤ m_θ(a,x) ,
```
故 `Acc_ens(x) ⊆ Acc_θ(x)`，且 `Acc_ens` 随 `K` 增大单调收缩（`K₁≤K₂ ⇒ Acc_{K₂}⊆Acc_{K₁}`）。证明：`m_ens` 是有限下确界，网内点直接取 min；网外点由 `L_θ`-Lipschitz 与 δ-覆盖得 `m_θ ≥ m_ens − L_θδ`。单调性由 min 的定义。∎ 推论：**"更细的随机化"不是更激进，而是更保守**；`K` 是安全与活动性之间的显式旋钮，且其保守性有并集界兜底。

**引理 133（间隙与校准的双单调性）** 固定校准抽取，(i) `Ĝ₁ ≤ Ĝ₂ ⇒ Acc(Ĝ₂) ⊆ Acc(Ĝ₁)`；(ii) 增加真实样本只会降低 `Ĝ`，从而 `Acc` 单调不减；(iii) 有 `Acc_v15^real ⊆ Acc_v16 ⊆ Exec_v15`。证明：(i)(ii) 由定义 631 的阈值形式直接得；(iii) 左包含由定义 631 的并项与定义 632 的取交，右包含由 `a∈Exec_v15` 的过滤条件。∎ 推论：**仿真只能把 `ρ_fill` 从 `ρ_fill^0` 推向 1，永远不能推到 1 以外**——语义边界是天花板，真实校准是地板。

**引理 134（主动校准的安全性与覆盖修正）** 若 `SafeProbe ⊆ Exec_v15` 且每个探针失败可由 `Fallback` 吸收，则 SGC 的每一步执行不降低已证安全下界；在用 ACI 或留出交换性校准集复算 `U_d` 时，长期覆盖率满足 `limsup_{T} (1/T)Σ_t err_t ≤ α + O(γ)`。证明：探针只产生新的真实标签，不直接修改 `Acc`；ACI 的标准长期覆盖界给出后一式，选择偏差由留出集隔离。∎ 推论：**主动采样能加速收紧 `Ĝ`，但必须用"额外留出 + ACI"为交换性付费**；否则越主动越会低估风险。

**引理 135（双域三难下界）** 记真实样本 `n`、声明域体积 `Vol(U_contact)=∏(θ_i^+−θ_i^-)`、网规模 `K`。若要求同时满足：(a) 覆盖体积 `Vol(U_contact)`；(b) 间隙上界 `Ĝ ≤ g`；(c) 真实校准 ≤ `n`，则存在接触参数族使
```
g ≥ Ω( L·(K^{-1/d} + n^{-1/2}) )   或   K = Ω( (L/g)^d ) ,
```
其中 `d` 为接触参数维数。证明：δ-网覆盖需 `K=Ω((L/g)^d)`；IPM 有限样本项以 `n^{-1/2}` 收敛；两类误差在 `g` 处相遇，取反即得下界。∎ 推论：**"覆盖大域 + 薄间隙 + 少真实样本"三者不可兼得**；仿真省下的是 `n`，付出的是 `K` 的离线成本与更宽的 `Ĝ`，必须用定义 640 的净收益显式核算。

**引理 136（摩擦/质心不确定性的余量传播）** 设抗滑裕度 `m_slip = (f_t − μ f_n)/f_max`，质心偏移 `δc` 引起法向力变化以 `L_c` 为界。则
```
|m_slip(θ) − m_slip(θ')| ≤ (f_n/f_max)|Δμ| + L_c|δc − δc'| .
```
证明：对 `μ` 与 `c_x` 分别取一阶展开并取绝对值上界，`f_t/f_max ≤ 1`。∎ 推论：**接触参数的不确定度可直接折算成余量区间**，因此 `U_contact` 的半径与 `Ĝ` 不是两笔独立开销，而是同一笔保守预算的两个投影，必须合并计算（定义 640）。

**引理 137（DTS 塌缩的安全继承）** 若 DTS 在 `θ̂_t ∉ U_contact`、`S_t > h` 或 `Δ_twin > Ĝ/2` 时切入 `real-only/collapsed`，则在触发时刻之后
```
Acc_v16 ⊆ Acc_v15^real ⊆ Exec_v15   (real-only) ,
Acc_v16 = ∅                          (collapsed) ,
```
且物理硬违规概率不高于 v15 的对应回退。证明：模式切换后不再调用 GCA 的仿真分支，授权只来自 v15 真实已证集；`collapsed` 只允许 `Fallback / a_ask`，由 v15 的物理构造保证安全。∎ 推论：**DTS 的职责不是"更准地估间隙"，而是"在间隙假设失效前及时放弃仿真授权"**；误检只损失活动性，漏检才会伤安全。

**引理 138（与 v15 的合成与严格退化）** 定义运行时执行集 `Exec_v16 = Acc_v16 ∩ DeadlineSet_v15 ∩ GuardOK_v15`。则
```
Exec_v16 ⊆ Exec_v15 ,
```
且当 `Ĝ=+∞`（SRG 失效）时 `Exec_v16 = Acc_v15^real ∩ DeadlineSet_v15 ∩ GuardOK_v15`，即严格退回 v15 的 real-only 路径；当 `K=1`（CDR 失效）时退化为单名义仿真 SRG；当 SGC/DTS 失效时授权集合不变、仅收敛速度或监控能力下降。证明：由定义 631 的 `a∈Exec_v15` 过滤、定义 632 的交集、以及各失效分支对参数的取值逐项代入。∎ 推论：**v16 的四个组件都是"可拔插的保守补丁"**：拔掉任何一项都不会放大 `Exec`，只会缩小收益或收窄授权，九不变式与 v15 的时限语义原样保留。

## 7. 已知风险与失效模式

1. **接触模式越出声明集**：微滑、黏滑转换、局部塑性形变、夹爪卡滞等未建模模式会使 `θ_R^*∉U_contact`，`Ĝ` 系统性低估。缓解：DTS 域外检验 + 残差 CUSUM、扩大 `U_contact`、接触模式分类器、`collapsed` 强制 `a_ask`。

2. **IPM 上界不紧**：判别器类与 `H` 不匹配、样本量不足、尾部事件稀疏，都会使 `Ĝ` 过松（授权集清空）或过紧（安全受损）。缓解：复杂度匹配、bootstrap/VC 上分位、EVT 尾部、保守 `L`。

3. **δ-网维数灾难**：接触参数 `d` 稍大，`K` 指数增长，在线查表内存与离线成本爆炸；粗网又使 `L_θδ` 过大。缓解：低维有效参数化、稀疏网/自适应细分、分层 `U_contact`、只在临界接触区加密。

4. **主动选择的交换性破坏**：SGC 越主动，校准样本越不独立，共形分位越可能低估。缓解：留出交换性校准集与探索集分离、ACI 动态 α、分裂共形、长期覆盖审计。

5. **共线误差叠加**：`Ĝ`、v13 的 `U_d`、v15 的 `ρ_cov`/`τ` 可能同向低估，形成"处处都保守、合起来不保守"。缓解：联合三角界、预算可加性检查、任一间隙超界即触发最低档、双重漂移检测。

6. **仿真器相关失效**：K 个仿真器共享同一物理引擎/接触求解器缺陷时，交集无法提供独立性，单点缺陷会同时击穿全族。缓解：异构求解器（解析/学习/商业引擎）、真实留出抽查、故障注入、关键工件保留纯 real-only 路径。

7. **真机执行风险与 SafeProbe 失真**：被判定"可回退"的探针在高速/重载下可能仍不可逆。缓解：`SafeProbe` 由物理约束与急停包络构造、速度/力限制、双通道 watchdog、失败注入测试。

8. **间隙证书的非平稳性**：工件批次、磨损、润滑、温度变化使 `P_R` 漂移，离线 `Ĝ` 过期。缓解：DTS 在线监控、滑动窗口重认证、域外即 `real-only`、定期全量重校准。

9. **WCET 与在线预算**：K 路查表、GCA 全量遍历、SGC 采集函数可能挤占 50Hz 预算。缓解：预计算查表、候选剪枝、SGC 异步化、预算不足时优先降 `K`/冻结 `Ĝ`，不冻结 DTS 与守卫。

10. **补全的收益幻觉**：`ρ_fill` 提升可能集中在低价值动作，`Net` 为负却被平均值掩盖。缓解：定义 640 的净收益核算、按任务价值加权、预注册主指标、消融定位。

## 8. 本轮最大风险

**一句话**：间隙证书只在"真实接触模式落在声明不确定集 `U_contact` 内、且 IPM 上界足够紧"时成立；若真实抓取出现未建模的接触模式（微滑、黏滑转换、局部塑性形变、夹爪卡滞），`Ĝ` 会系统性低估真实间隙，于是仿真授权的抓取在"统计上已校准、域内看起来可证"的表象下执行了一个接触模式外的危险动作——即**校准过、域内自洽、却在建模边界外失效的安全决定**。
