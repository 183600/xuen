# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「需求洞察」×「跌倒恢复」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**从"听见指标"到"听见需求"，从"安全停下"到"安全回来"**。两个灵感分别治理 v9 的两种债：
> - **代理债**：六层指标与 5 维 MetaWeight 只是人类真实需求的*代理*；代理在常态下够用，在危机（跌倒、求助）时会系统性失真。
> - **终局债**：v9 的分块中止只保证"停下"，把 STOP 当作吸收态；但跌倒后的系统必须回来——停住不是安全，停住只是被推迟的不安全。
> 新模块继续沿用中立元/契约退化链：FR 失效严格退回 v9 的 AC 安全停驻；NI 失效退回固定元权重（等价 v9）；NRA 失效退回字典序安全优先（等价 v8/v7）。

## 0. 直觉与动机

**灵感 1（需求洞察 → 潜在需求的可辨识推断）**
直觉：系统一直在优化"指标"，但指标不是目的，人的需求才是。一个严谨的系统必须把"需求"显式化，并且承认自己可能看错。核心创新：**需求洞察器（NeedInsightEstimator, NI）**。它把需求分成两路：**声明需求** d_t（人说的话/下的命令）与**显露需求** r_t（人实际纠正行为、注视、犹豫、情感 5 维轨迹反推的偏好权重），用逆规划（inverse planning）从行为史反解需求向量 n_t = E[θ | 行为史]，并给出**可信集** C_t。关键设计（P13）：只有 diam(C_t) ≤ ε_n 时才允许依据 n_t 优化；不可辨识时要么**主动探询**（最大化信息增益的提问/微动作），要么在 C_t 上做 **minimax 鲁棒决策**。更进一步，推断有**决策截止期** D_need：危机中来不及辨识，就必须放弃点估计直接走鲁棒策略——把 HCI 的"需求 elicitation"与实时系统的 deadline 第一次接上。

**灵感 2（跌倒恢复 → 安全停驻的证书化逆转）**
直觉：v9 的安全论证终点是 STOP，但现实里机器人会摔倒、被撞倒、踩空。把 STOP 当吸收态，等于"遇到不会处理的情况就永远别动"——对家庭中长期运行的机器人，这不是安全，是另一种失效。核心创新：**跌倒恢复证书器（FallRecoveryCertifier, FR）**。它把"停"升级为"停—恢复—交接"三段：跌倒检测 → 恢复证书 RecCert=(R_set, π_rec, T_rec, h_max, Z_human) → 回到名义模式。恢复不是任意动作，而是从**可恢复集** R_set 出发、在时限 T_rec 内回到直立稳定、且伤害指标 ≤ h_max 的**认证策略**；并且自扶正禁止在人类接触排除区 Z_human 内进行（保护人，而不只保护自己）。数学上，v9 的 STOP 是 v10 恢复策略的**退化特例**（π_rec ≡ hold, T_rec = ∞），故 FR 失效可严格回落到 v9。

**灵感 3（交叉：跌倒是最强的需求洞察压力测试）**
直觉：人在摔倒时，"帮我把水拿来"的声明需求会瞬间让位于"先别压到我、先帮我起来"的显露需求，声明-显露冲突 δ_t 在这一刻最大。核心创新：**需求-能力-恢复仲裁器（NeedRecoveryArbiter, NRA）**：把 n_t、恢复模式、能力上界放进同一个可行动集合 A_adm，先安全后任务；当自身跌倒而人需要帮助时，系统必须承认"我现在帮不了"，**升级呼救而不是硬做**——能力诚实（capability honesty）是需求满足的一部分，不是失败。

## 1. 研究问题（轮次升级版）

- **Q1（可辨识性与时效）**：在观测预算 m 与决策截止期 D_need 的双约束下，需求后验可信集如何收缩？不可辨识时，主动探询与鲁棒策略的切换判据是什么？
- **Q2（需求覆盖安全）**：如何保证需求误判（甚至被恶意误导）永远不能击穿安全下界？跌倒事件下的需求硬覆盖与恢复后的渐进解冻如何形式化？
- **Q3（恢复证书）**：在人类非被动、环境非结构化的条件下，恢复证书 (R_set, T_rec, h_max, Z_human) 如何定义与验证？STOP 作为退化恢复的可组合性如何证明？
- **Q4（需求-恢复仲裁）**：什么样的可行动集合与升级规则，使"帮人"与"自救"冲突时的决策既可解释又不违背安全？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 需求可辨识律（Identifiable Need, NI）**
只在需求可信集足够小（diam(C_t) ≤ ε_n）且未超过决策截止期时，才以点估计 n_t 驱动权重；否则用 C_t 上的 minimax 鲁棒决策，或在安全预算内主动探询。安全维度有硬下界 n_safety ≥ n_min，永不参与"学习式下调"；跌倒等危机事件把 n_safety 硬置为 1（覆盖、非学习）。禁止在人无法表达/无法观察时臆断其需求。

**P14 恢复证书律（Certified Recovery, FR）**
STOP 不是终局，而是恢复的入口。任何恢复动作必须携带 RecCert：从 R_set 内出发，π_rec 在 T_rec 内到达直立稳定，伤害 ≤ h_max；人类进入接触排除区 Z_human 时立即中止恢复、转 SAFE_POSE 并升级。恢复完成必须经过后跌倒重定位与不变式复核，才允许交接回名义控制器。

**P15 需求-能力-恢复仲裁律（Capability-Honest Arbitration, NRA）**
a ∈ A_adm(s) ⇔ 满足安全包络 ∧ 不超出当前能力上界；在 A_adm 上按需求的鲁棒下界排序。A_adm = ∅ 时必须显式升级（呼救/放弃任务并告知），不得静默降级；恢复债超过阈值时必须显式放弃任务而不是无限续命。

## 3. 与基线的接口（如何退化）

- NI 失效/不可辨识且无时间探询 ⇒ n_t ← n_prior（仅声明需求 + 固定 MetaWeight），等价 v9；
- FR 失效或 s ∉ R_set ⇒ π_rec ← hold（安全停驻），STOP 重新成为吸收态，等价 v9 Level-1；
- NRA 失效 ⇒ 字典序安全优先（先 M₀ 硬检查、再 v8 五维），等价 v8/v7；
- 跌倒检测失效 ⇒ IMU 看门狗 + 保守停驻（不自动自扶正），等价 v9 STOP；
- 恢复后重定位失败 ⇒ 停留 DEGRADED_NAV（局部任务），不回到全速名义模式；
- 全部失效 ⇒ 完整退回 v9 ACMD，再退回 v8/v7/v6。

## 4. 预期贡献

1. **可辨识需求推断**：声明/显露双通道 + 可信集 + 截止期感知的鲁棒/探询切换，把"需求洞察"从产品口号变成可证伪的估计问题；
2. **恢复证书与认证收缩**：把安全停驻升级为可认证的"停—恢复—交接"，并证明 v9 STOP 是其退化特例（可组合退化）；
3. **能力诚实仲裁**：需求-能力-恢复三角的可行动集合与显式升级规则，治理"为了完成任务而假装能行"的叙事债；
4. **恢复债与需求漂移**：把反复跌倒的长期代价与需求非平稳性纳入指标，E571–E590 覆盖辨识、恢复、仲裁、对抗与长跑。

## 5. 本轮最大风险

**一句话**：恢复证书的伤害界 h_max 建立在"环境被动、接触对象刚性"的假设上，而跌倒场景恰恰把脆弱的人类拉进机器人的接触动力学；需求洞察越确信"人需要帮助"，机器人越可能靠近并接触——认证的恢复与接触安全在同一时刻相互矛盾。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| n_t ∈ Δ⁴ | 潜在需求向量：分量 (task, safety, autonomy, social, efficiency)，单纯形上的偏好权重 |
| d_t, r_t ∈ Δ⁴ | 声明需求（命令/语言解析）与显露需求（行为逆规划反推） |
| δ_t = ‖d_t − r_t‖₁ | 声明-显露需求冲突度 |
| C_t ⊆ Δ⁴ | 需求可信集：后验对数密度 ≥ log p_max − χ 的水平集 |
| ε_n, D_need | 可辨识阈值（C_t 的 L1 直径）与决策截止期（ms） |
| A_adm(s) | 可行动集合：满足安全包络 ∧ 当前能力上界 |
| m_t ∈ M | 运行模式：NOMINAL/STUMBLE/FALLEN/RIGHTING/RECOVERED/DEGRADED_NAV/SAFE_POSE |
| RecCert = (R_set, π_rec, T_rec, h_max, Z_human) | 恢复证书：可恢复集、恢复策略、时限、伤害界、人类接触排除区 |
| D_rec(t) | 恢复债：停驻与恢复累积的时间/任务偏离代价 |
| ρ : SAFE_POSE ⇀ NOMINAL' | 认证收缩（certified retraction）：仅在人离开排除区且证书成立时定义 |

**新增定义 540（潜在需求向量 Latent Need Vector）** 人的行为被建模为对五项需求的加权优化：R_θ(s,a)=Σ_i θ_i φ_i(s,a)，θ∈Δ⁴，φ 由 v8 的六层指标与 5 维 MetaWeight 张成。需求向量 n_t=E[θ|hist_t]。安全分量有硬件下界 n_safety ≥ n_min=0.9，任何学习/推断都不得下调。

**新增定义 541（声明需求 vs 显露需求）** d_t 由命令解析器把语言/界面输入映射到 Δ⁴；r_t 由逆规划后验均值给出。δ_t=‖d_t−r_t‖₁。δ_t > δ_max 且 diam(C_t) ≤ ε_n 判定为**真实需求冲突**（需要重排序/澄清）；δ_t > δ_max 而 diam(C_t) > ε_n 判定为**推断不足**（需要探询或鲁棒，不得直接改权重）。

**新增定义 542（需求可辨识性与可信集）** 给定行为史 hist_t 与人类策略模型 π_h(a|s;θ)∝exp(βQ_θ(s,a))，后验 p(θ|hist_t)∝p(θ)∏_τ π_h(a_τ|s_τ;θ)。可信集 C_t={θ: log p(θ|hist_t) ≥ log p_max−χ}。**可辨识** ⇔ diam(C_t)=max_{θ,θ'∈C_t}‖θ−θ'‖₁ ≤ ε_n。

**新增定义 543（截止期感知推断 Deadline-Aware Inference）** 设单次观测耗时 Δ_o、达到 ε_n 所需样本数 m*(ε_n,δ)。若剩余决策时间 D_remain < m*·Δ_o，则点辨识在时限内不可行，必须：
```
a* = argmax_{a∈A_adm} min_{θ∈C_t} U(a,θ)          （鲁棒模式）
```
否则若信息增益正且探询安全，则选探询 q* = argmax_q EIG(q) − λ·cost(q)；EIG(q)=H(C_t)−E[H(C_{t+1}|q)]。三模式（point / elicit / robust）由 (diam(C_t), D_remain) 唯一决定。

**新增定义 544（跌倒状态机 FallAutomaton）** 由 IMU（线加速度、角速度、姿态翻转）与本体感觉给出跌倒概率 p_fall。状态转移：
```
NOMINAL --p_fall≥τ1--> STUMBLE --p_fall≥τ2--> FALLEN
NOMINAL --p_fall≥τ2------------------------> FALLEN
STUMBLE --p_fall<τ0--> NOMINAL
FALLEN --s∈R_set ∧ Z_human 空--> RIGHTING
FALLEN --否则------------------> SAFE_POSE + escalate
RIGHTING --human∈Z_human ∨ ¬cert_valid--> SAFE_POSE
RIGHTING --recovered(s)--------> RECOVERED
RECOVERED --relocalization_ok--> NOMINAL
RECOVERED --否则---------------> DEGRADED_NAV
```
τ0<τ1<τ2 构成双阈迟滞，避免抖动。

**新增定义 545（恢复证书 RecoveryCertificate）** RecCert=(R_set, π_rec, T_rec, h_max, Z_human)。语义：∀s0∈R_set，在 [0,T_rec] 内无人类进入 Z_human 的条件下，执行 π_rec 可到达直立稳定集 U，且伤害指标 H(s_{0:T_rec}) ≤ h_max。R_set 由离线可达性采样 + 简化动力学上的障碍证书（barrier certificate）双重给出；在线只做成员检查与证书有效性检查，保证 50Hz 廉价。

**新增定义 546（人类接触排除区 Human Exclusion Zone）** Z_human(s)={x: ‖x−p_human‖ < d_human ∨ 预测接触锥与人体相交}，d_human 取机器人最大肢段长度 + 安全余量。RIGHTING 期间若 Z_human 非空，立即转 SAFE_POSE。**这是把"保护人"置于"恢复自己"之上的硬约束**。

**新增定义 547（恢复债 Recovery Debt）**
```
D_rec(t+1) = γ·D_rec(t) + c_stop·1[m_t∈{STOP,SAFE_POSE}] + c_rec·1[m_t=RIGHTING]
```
γ∈(0,1]，c_stop/c_rec 为时间与任务偏离代价。D_rec > D_max ⇒ 必须显式放弃任务并告知（能力诚实），禁止无限"僵尸任务"。

**新增定义 548（需求-能力-恢复仲裁 Need-Recovery Arbitration）**
```
A_adm(s) = { a : Safe(a,s) ∧ Capable(a,s) }
a* = argmax_{a∈A_adm} min_{θ∈C_t} U(a,θ)      （鲁棒下界排序）
```
若 m_t∈{FALLEN,RIGHTING}：冻结学习需求，硬覆盖 n_safety=1，任务类需求权重清零；若 A_adm=∅：escalate("capability_honest")；若 D_rec>D_max：escalate("drop_task")。

**新增定义 549（认证收缩 Certified Retraction）** ρ: SAFE_POSE ⇀ NOMINAL' 是从安全停驻回到名义模式的**部分映射**，仅在 (i) 人已离开 Z_human、(ii) 恢复后重定位置信 ≥ τ_loc、(iii) 恢复证书仍成立时定义。ρ 不是恒等元也不是吸收元，而是保持安全不变式 I(s)（最小间隙、无接触、力矩上界）的 retraction；ρ∘ρ=ρ 在 RECOVERED 后成立（幂等），保证不会反复"恢复-崩溃-再恢复"。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v8 不变。
**升级定义 496（软证书，v10）** v9 五条件 δ_trigger 保持不变（安全方向不放松）；需求向量只作用于**软层权重** τᵢ(t) 的非安全分量，且必须满足 P13 的可辨识前提。形式化：
```
τᵢ^{v10}(t) = τᵢ^{v9}(t) · (1 + η·(n_t,i − n_min,i))   仅 i ∉ {safety, M₀}
```
η 为权重灵敏度，安全层 i=safety 与 M₀ 不参与重加权。
**升级定义 521（DA-OTL）** 继承 v9；需求重加权只改变软层阈值，不改变 DA-OTL 的退化语义。
**升级定义 531（软硬约束衔接）** M₀ 判据增加模式入口：任一步 m_t ∉ {NOMINAL, DEGRADED_NAV} ⇒ M₀ 硬检查触发恢复仲裁，不等块边界。
**升级定义 536（中立元退化表）** 新增两行：NI → n≡n_prior（等价 v9）；FR → π_rec≡hold（等价 v9 STOP）。hold 是"恢复端口"的退化值，且是吸收的（后续恢复动作不再执行），与 v9 对 AC 端口 a^⊥ 的处理一致。

# IP-357 NeedInsightEstimator：需求洞察器
NEED = ('task', 'safety', 'autonomy', 'social', 'efficiency')

class NeedInsightEstimator:
    def __init__(self, prior, eps_n=0.08, n_min_safety=0.9,
                 delta_max=0.35, D_need_ms=1500.0, beta=5.0):
        self.prior, self.eps_n = prior, eps_n
        self.n_min_safety, self.delta_max = n_min_safety, delta_max
        self.D_need, self.beta = D_need_ms, beta
        self.n = dict(prior)

    def inverse_plan_posterior(self, history):
        # p(theta|hist) ∝ p(theta) * prod_t softmax(beta*Q_theta(s_t,.))
        post = self.prior
        for (s, a_h) in history:
            post = self._bayes_update(post, s, a_h)
        return post

    def credible_set(self, post, chi=2.0):
        lmax = max(post.logp.values())
        return {th for th, lp in post.logp.items() if lp >= lmax - chi}

    def update(self, history, declared):
        post = self.inverse_plan_posterior(history)
        C = self.credible_set(post)
        n = post.mean()
        n['safety'] = max(n['safety'], self.n_min_safety)   # 硬下界
        self.n = n
        return n, C, l1_diameter(C)

    def conflict(self, d, r):
        return sum(abs(d[k] - r[k]) for k in NEED)

    def decide_mode(self, C, D_remain_ms):
        if l1_diameter(C) <= self.eps_n:
            return 'point', C
        if D_remain_ms >= self.est_elicit_time(C):
            return 'elicit', self.best_probe(C)   # argmax EIG - cost
        return 'robust', C                        # minimax over C

    def robust_action(self, C, admissible, U):
        return max(admissible, key=lambda a: min(U(a, th) for th in C))


# IP-358 FallRecoveryCertifier：跌倒恢复证书器
class FallRecoveryCertifier:
    def __init__(self, R_set, pi_rec, T_rec, h_max, d_human, tau0, tau1, tau2):
        self.R_set, self.pi_rec = R_set, pi_rec
        self.T_rec, self.h_max = T_rec, h_max
        self.d_human = d_human
        self.tau0, self.tau1, self.tau2 = tau0, tau1, tau2

    def fall_prob(self, imu, pose):
        return self._p_fall(imu, pose)

    def human_in_zone(self, s, humans):
        return any(dist(s, h) < self.d_human
                   or swept_volume_hits(s, h) for h in humans)

    def cert_valid(self, s):
        return (s in self.R_set
                and self.elapsed <= self.T_rec
                and self.harm_so_far <= self.h_max)

    def step(self, m, s, imu, pose, humans, elapsed):
        p = self.fall_prob(imu, pose)
        if m == 'NOMINAL':
            if p >= self.tau2: return 'FALLEN'
            if p >= self.tau1: return 'STUMBLE'
            return 'NOMINAL'
        if m == 'STUMBLE':
            if p >= self.tau2: return 'FALLEN'
            if p < self.tau0:  return 'NOMINAL'
            return 'STUMBLE'
        if m == 'FALLEN':
            if s not in self.R_set:              return 'SAFE_POSE', 'escalate'
            if self.human_in_zone(s, humans):    return 'SAFE_POSE', 'escalate'
            return 'RIGHTING'
        if m == 'RIGHTING':
            if self.human_in_zone(s, humans) or not self.cert_valid(s):
                return 'SAFE_POSE', 'escalate'
            if self.recovered(s):                return 'RECOVERED'
            return 'RIGHTING'
        if m == 'RECOVERED':
            return 'NOMINAL' if self.relocalization_ok(s) else 'DEGRADED_NAV'
        return m   # SAFE_POSE 需外部 ρ 才能离开


# IP-359 NeedRecoveryArbiter：需求-能力-恢复仲裁器
class NeedRecoveryArbiter:
    def __init__(self, D_max, eps_n):
        self.D_max, self.eps_n = D_max, eps_n

    def admissible(self, s, cap):
        return [a for a in actions(s) if safe(a, s) and cap.allows(a)]

    def act(self, n, C, m, s, cap, D_rec, U):
        if m in ('FALLEN', 'RIGHTING'):
            n = {k: 0.0 for k in NEED}
            n['safety'] = 1.0                      # 危机硬覆盖
            mode = 'robust'                        # 学习需求冻结
        else:
            mode = 'point' if l1_diameter(C) <= self.eps_n else 'robust'
        A = self.admissible(s, cap)
        if not A:
            return escalate('capability_honest')   # 诚实升级，不硬做
        if D_rec > self.D_max:
            return escalate('drop_task')           # 恢复债超限，显式放弃
        if mode == 'point':
            return max(A, key=lambda a: U(a, n))
        return max(A, key=lambda a: min(U(a, th) for th in C))

## 4. 推导

**引理 87（需求可信集收缩与截止期下界）** 设观测噪声 σ-次高斯、后验收缩系数 λ>0，则 m 次观测后 diam(C_{m}) ≤ diam(C_0)e^{−λm} + cσ√((d+log(1/δ))/m)。故达到 diam ≤ ε_n 所需样本数 m* = Θ(σ²(d+log(1/δ))/ε_n²)。若 D_need < m*·Δ_o，则任何点辨识都不可能按时完成，**必须**采用定义 543 的 minimax 鲁棒策略；此时系统的安全由鲁棒下界保证，而非由 n_t 的点估计保证。∎

**引理 88（安全下界单调覆盖）** 仲裁算子按字典序先安全后需求：A_adm 中的动作先通过安全包络过滤，n_safety 有硬下界且被跌倒事件硬置为 1，需求只重加权非安全软层（定义 496 升级）。因此对任意推断/被误导/对抗的 θ，只要 a 违反安全包络就有 a∉A_adm；需求误判只能改变软层排序，作用幅度被 η 与软层值域共同界定。安全不变式 I(s) 与需求推断解耦。∎

**引理 89（STOP 是恢复的退化特例 / 严格扩展）** 令 π_rec^⊥≡hold、R_set=∅、T_rec=∞、h_max=0。则 FALLEN→SAFE_POSE 后无任何 RIGHTING 迁移，SAFE_POSE 永不收缩回 NOMINAL，即精确复现 v9 "STOP 为吸收态"的 Level-1 语义。故 FR 失效（或其证书不可用）⇒ 注入 π_rec^⊥ ⇒ 与 v9 逐位等价；v10 的恢复分支是 v9 STOP 的**严格扩展**，继承链无断裂。∎

**引理 90（恢复证书可靠性、接触安全与认证收缩）** 若 s0∈R_set、且 [0,T_rec] 内无人类进入 Z_human，则由 RecCert 的离线可达性/障碍证书，π_rec 在 T_rec 内到达直立稳定集 U 且 H≤h_max；若人类进入 Z_human，立即转 SAFE_POSE，而 SAFE_POSE 对恢复动作是吸收的（幂等：SAFE_POSE∘SAFE_POSE=SAFE_POSE），不会产生二次碰撞。认证收缩 ρ 仅在 (R_set, 重定位, 证书) 三条件同时成立时定义，沿整条 停—恢复—交接 轨迹保持安全不变式 I(s)。∎

**引理 91（恢复债单调有界与诚实放弃）** 在无任务完成事件时 D_rec 单调不减，单步增量 ≤ c_stop+c_rec，故连续失败恢复次数 ≤ D_max/(c_stop+c_rec)；超过 D_max 强制 escalate("drop_task")。因此系统不会陷入无限"僵尸任务"，恢复失败对任务层的影响有界且可解释。∎

**引理 92（需求非平稳、跌倒变点与残余混淆风险）** 把跌倒视为需求分布的变点：检测延迟内沿用旧 n 只会影响软层排序，因跌倒后 n_safety 硬覆盖且学习需求冻结，故不改变安全轨迹（引理 88）。残余风险不是安全违背，而是**事件混淆**：把人的跌倒误判为机器人任务失败（或反之），导致救济对象错误；该风险由检测召回/精确率刻画，不能由鲁棒性消除，只能由 E576/E588 的混淆矩阵审计。∎
