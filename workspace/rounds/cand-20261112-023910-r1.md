# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「异常检测」×「双臂协调」）

> 第 57 轮把安全赌注从"模型置信"移到"证据质量"，又用元先验+共形带把先验质量兜底，似乎已把"看不到的世界"隔离；但它有一个未命名的结构性盲点：**整套机制只能对"在它已经建模的通道里留下签名"的故障反应**。一个既不触发 OOD、又不造成跨模态分歧、也不改变裕度的故障方向，会被系统以最高置信度判为安全——这不是"先验错"，而是"看不见"。本轮两个灵感恰好从两侧戳中同一个对象——**可观测性（observability）**：**异常检测**是"注意未被建模之物"的技艺，**双臂协调**是"用物理约束把两路测量耦合起来"的冗余；它们的共同敌人是**共模盲区**：一个方向，正常模型看不见、闭链耦合又把它从两臂之差里结构性抵消掉，于是系统"高置信地说一切正常"。本轮引入 **可观测性核算**：每个安全承诺必须携带"证据覆盖了哪些故障方向（行空间秩）以及哪些方向结构上不可见（零空间）"；异常检测器必须携带**检测契约 + 金丝雀审计**；双臂耦合升级为一类**声明盲子空间**的证据；且出现活异常时耦合只能放松、永不准收紧。核心命题从"证据说可信"升级为 **"证据说可信，且说得出它看不见什么"**。

核心矛盾：
- **H29（异常检测的自我指涉：谁监视监视者）**：异常检测依赖"正常"模型，而正常模型与被监视的证据装置共享同一盲区；检测器自身的漂移恰恰是它检测不到的那类漂移。"无警报"不等于"安全"——它只覆盖检测契约声明的可检类；把"没看见"洗成"没问题"，就是把消极证据当成正面证据。
- **H30（协调的冗余-能力悖论）**：闭链双臂获得力闭合、更大负载与刚性约束，代价是消耗可观测性——一只臂的故障可被另一只臂的补偿静默吸收，系统看起来健康；耦合越紧，能力越强、越盲。一致（两臂都说好）≠ 正确（滑移常躲在闭链零空间里）。
- **H31（警报疲劳 vs 异常敏感度）**：调高敏感度抓到更多异常，也制造更多警报；警报疲劳降低操作者警觉，而警觉下降正是它想抓的"人的异常"（橡皮章）——异常检测会**制造**它要检测的异常，形成自我实现回路。

## 0. 直觉与动机

**灵感 1（异常检测 → 检测契约 + 金丝雀审计）**
直觉：异常检测最危险的不是漏报，而是**把漏报认证成清白**。要打破"谁监视监视者"的无限回溯，不能再学一个元检测器（它必然继承同一盲区），而要引入**外生于正常模型的地面真值**：金丝雀探针（已知效应的人工扰动）周期性注入证据装置，用它们的实际被检出率估计检测器当前的漏检率；漏检率超界则检测器**自降级**——失去签发"清白证明"的资格，只能输出"未知"。同时每个检测器必须公开**检测契约** 𝒦=(可检类、盲类、时延、误报上限)：它的"正常"只覆盖声明过的方向。清白是有限额的，不是全称命题。

**灵感 2（双臂协调 → 双边冗余 + 声明式盲子空间）**
直觉：两臂夹持同一物体，物理上给了两路独立测量，也给了闭链约束。把局部故障模型线性化 y=Hf+ε，闭链把故障投影到约束一致子空间：**有效可观测 H_eff^κ = H·P_κ，秩下降**，可见子空间 𝒪(κ)=row(H_eff^κ)、盲子空间 ℬ(κ)=null(H_eff^κ)。两臂之差 B(r) 只在 𝒪(κ) 内是证据；落在 ℬ(κ) 的故障——典型如"刚性夹持掩盖的滑移/摩擦锥退化"——两臂会高度一致地错。因此 EV-coord 不仅要说"我一致"，还必须公开"我在 ℬ(κ) 里看不见"；风险相关方向一旦落在盲子空间，必须由独立探针补盲，且内力求 w_int 必须落在 [w_min,w_max]（夹得过松会滑、过紧会碎）。

**灵感 3（两灵感合流 → 可观测性核算）**
直觉：异常检测的"可检类/盲类"与双臂的"可见/盲子空间"是同一个数学对象的两副皮——**证据的秩核算**。于是把第 56–57 轮的"证据门"从"有没有证据 / 证据多强"升级为"证据覆盖了哪些故障方向"：每类证据携带覆盖集 Cov(e)，承诺要求 Cov(∪e) ⊇ F_req（风险模型给出的必须可见方向）。纵深第一次变成**方向维度的覆盖问题**，而不是标量置信的堆叠。"清白"这类消极证据的覆盖集天然有限，绝不能单独支撑不可逆接触。

**灵感 4（耦合-可观测性调节器 + 单向下耦合）**
直觉：既然耦合买能力、卖可观测性，就把 κ 当成受约束的决策变量：在满足 F_req ⊆ 𝒪(κ)、内力求可行、同步时延达标的前提下取能力最大的 κ。关键安全律是**单向**：一旦出现活异常（SAD 报警或可观测子空间内出现超阈分歧），κ 只能向"更松"方向走，直到故障被消解并重新认证才允许复耦合——系统永远可以"拆开看清楚"，绝不能"锁死来掩盖"。这既是交互单调性在耦合维度上的延伸，也封死了"两臂投票把自己锁得更紧"的协同通胀。

**灵感 5（PCE++ 与警报经济学）**
直觉：异常检测进入闭环后，最大的系统性风险从"漏检"变成"用警报把人的注意力烧穿"。所以检测阈值不按"最大化召回"选，而按**警报预算**选：分层 {静默日志/自愈/通知/升级}，每层误报率有上限；疲劳状态 f_o 由确认加权的警报率更新，vig 随之下降并自动降低人类证据权重。探-诺-演循环里 SAD 只能**增加**探针/解耦/升级，永不能删除它们——检测器带来的只能是保守方向的作用。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（自审计异常检测 SAD 与检测契约）** 证据装置遥测 z_t=(传感残差, q_φ 漂移, 地图版本差, 跨模态依赖度, 时钟偏斜, 信任跳变)。局部线性化故障 f∈ℝ^d，观测 y=H_det f+ε。检测器 D_sad: z↦{clear,alarm,unknown}，检测契约 𝒦=(𝒜_see,𝒜_blind,τ_det,r_fa^max)，𝒜_see=row(H_det)∪声明可检类，𝒜_blind 为补集。金丝雀集 {c_i} 的**真实效应独立测量**、且**不参与正常模型训练**；用金丝雀被检出结果估计漏检率 FNR̂。规则：(R1) clear 仅认证 𝒜_see（**无警报≠安全**）；(R2) FNR̂>δ_can ⇒ 检测器自降级，禁止签发 EV-anom-clear，只能 'unknown'；(R3) alarm 命中决策的风险相关方向 ⇒ 冻结承诺并下耦合。

**定义 140（双臂耦合与双边证据 DAC）** q=(q_L,q_R)，κ∈{chain,shared,loose}，闭链约束 C(q,u)=0、约束 Jacobian J_c；故障投影 P_κ=I−J_c⁺J_c，有效可观测 H_eff^κ=H_bilat·P_κ，𝒪(κ)=row(H_eff^κ)，ℬ(κ)=null(H_eff^κ)。双边差 B(r)=‖Proj_{𝒪(κ)}(y_L−T·y_R)‖，内力求 w_int=W(q,u)。EV-coord ⇔ B(r)≤θ_B ∧ 查询方向∈𝒪(κ) ∧ w_int∈[w_min,w_max] ∧ 同步完整性（时钟偏斜≤τ_sync）。EV-coord 必须随证公开盲基 ℬ(κ)；任一 F_req 方向落入 ℬ(κ) ⇒ 不可用 EV-coord 顶替，须独立探针补盲（**一致≠正确**）。

**定义 141（耦合-可观测性调节器 COR）** 给定风险模型要求的故障方向集 F_req，κ\*=argmax_κ Cap(κ) s.t. F_req⊆𝒪(κ)、w_int 可行、同步时延≤τ_sync。单调律：若 SAD 报警或 𝒪(κ) 内出现超阈分歧，κ 只能迁往更松级别（能力不升），直到故障消解且经新鲜金丝雀+证据重新认证，方允许复耦合；两臂不得"投票"把自己锁更紧（协同通胀禁令）。

**定义 142（警报经济学与疲劳 AFM，升级 PTM）** 警报分层 ℓ∈{log,self-heal,notify,escalate}，每层预算 b_ℓ 与误报率上限 r_fa^ℓ。疲劳状态 f_o 由确认加权警报率更新，vig_o 对 f_o 单调不增；θ_sad 在误报预算约束下最大化 E[VOI]（而非最大化召回）。vig_o<θ_vig ⇒ 人类证据权重自动下调、L2 默认保守停。目标：切断"误报↑⇒疲劳↑⇒橡皮章↑⇒真异常被漏"的自我实现回路。

**定义 143（可观测性证据门 OEG 与证书 J_a，升级 FSE）** 每类证据 e 携带覆盖集 Cov(e)。新证据类：EV-anom-clear（Cov=𝒜_see∩相关类，且金丝雀合格）、EV-coord（Cov=𝒪(κ)，且内力求与同步合规）。承诺可采纳 ⇔ Cov(∪e)⊇F_req 且过硬律：(i) EV-anom-clear **不得单独**支撑不可逆接触（消极证据）；(ii) EV-coord 仅限 L0/L1 且仅在 𝒪(κ) 内；(iii) F_req∩ℬ(κ)≠∅ ⇒ 必须独立探针；(iv) FNR̂>δ_can ⇒ 无 anom-clear；(v) 耦合单调性（定义 141）。J_a=J_p∪(sad_log,canary_log,det_contract,coord_log,κ,𝒪/ℬ 证书,w_int_log,alert_log,fatigue_state)。

**定义 144（探-诺-演++ PCE++）** 每检查点：①元推断（第 57 轮）；②SAD：clear→仅得 𝒜_see 覆盖；alarm/金丝雀降级→冻结、κ↓、金丝雀复测；③COR 定 κ；④DAC 采双边证据并补盲；⑤OEG 覆盖核算；⑥承诺 ⇔ Cov⊇F_req ∧ 过门，否则探询/解耦/绕行/L2/安全停。单调性：SAD 只能增加探针、解耦与升级，永不能减少。终止界 k_probes+k_cons+k_canary。

## 2. 关键算法伪代码（完整版见产物区）

```python
def sad_check(app):
    st = app.det.detect(app.telemetry())              # clear/alarm/unknown
    fnr = app.canary.fnr_estimate()                   # 外生金丝雀
    if fnr > delta_can:                               # 检测器自降级
        return 'unknown', set(), app.det.contract.A_blind
    if st == 'clear':
        return 'clear', app.det.contract.A_see, app.det.contract.A_blind
    return st, set(), app.det.contract.A_blind

def observability_gate(evs, F_req, k, irreversible):
    cov = union(e.Cov for e in evs)
    if not F_req <= cov: return ('reject','uncovered', F_req - cov)
    if irreversible and len(evs) == 1 and evs[0].ev == 'EV-anom-clear':
        return ('reject','absence_of_evidence', None)  # 清白≠安全
    if k == 'chain' and F_req & blind(k):
        return ('reject','blind_subspace', F_req & blind(k))
    return ('ok', None, None)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|

**正确性定理（SACS 概要）**：在 A33–A40 上加 (A41) 金丝雀外生且真实效应独立可测、检测契约对 𝒜_see/𝒜_blind 自报诚实；(A42) DAC 盲基公开且内力求∈[w_min,w_max]、同步完整；(A43) 警报预算与疲劳单调（vig 下降只降低人类证据权重）；(A44) 耦合单向下迁。则：(i) 若 F_req⊆Cov(∪e)，承诺对 F_req 内故障的失效率 ≤ δ_f+ε_meta+δ_probe+δ_det+δ_coord+ε_h；(ii) **盲区不被默认安全**：F_req∩(𝒜_blind∪ℬ(κ))≠∅ 时系统只能补盲或拒绝，不存在"清白即承诺"路径；(iii) 交互单调性强化：SAD 与 COR 只能经"加探针/解耦/降低人类权重"作用于系统；(iv) PCE++ 在 k_probes+k_cons+k_canary 内终止。

## 6. 本轮最大风险

**一句话**：本轮把"安全"建立在"系统能诚实说出自己看不见什么"之上，最大风险因此是**被认证的无知**——若检测契约与故障模型 H 的自报本身有偏（声称覆盖了其实没覆盖的方向），系统会以"覆盖⊇F_req"的证书给出比第 57 轮更硬的自信，而故障恰好落在它自认为看得见、实际看不见的方向上；必须用外生金丝雀、H 的可证伪化与盲区保守化三重机制，把"清白"永远降格为有限额的消极证据。

## 2. 关键算法伪代码

### IP-139 SAD（自审计异常检测，含检测契约与金丝雀）

```python
def sad_check(app):
    z = app.telemetry()                         # 残差/漂移/版本/依赖度/时钟/信任
    st = app.det.detect(z)                      # clear / alarm / unknown
    contract = app.det.contract                 # (A_see, A_blind, tau_det, r_fa)
    fnr = app.canary.fnr_estimate()             # 外生金丝雀，真值独立测量
    if fnr > delta_can:                         # 检测器自身已不可信 → 自降级
        app.det.authority = 0.0
        return 'unknown', set(), contract.A_blind, fnr
    cover = contract.A_see if st == 'clear' else set()   # 清白只覆盖可检类
    return st, cover, contract.A_blind, fnr

def canary_audit(app, budget_k):
    for c in sample_canaries(app.canary, budget_k):      # 已知效应的注入
        true_effect = c.true_effect                      # 独立测量，非模型推断
        detected = app.det.detect(c.apply(app)) == 'alarm'
        app.canary.record(true_effect, detected)         # 更新 FNR̂
    return app.canary.fnr_estimate()
```

### IP-140 DAC（双臂耦合与双边证据）

```python
def observability(k):
    Jc = constraint_jacobian(k)                  # 闭链约束 Jacobian
    P = I - pinv(Jc) @ Jc                        # 投影到约束一致子空间
    Heff = H_bilat @ P
    O = row_space(Heff); B = null_space(Heff)    # 可见 / 盲
    return Heff, O, B

def dac_evidence(app, k, prop):
    yL, yR, w = read_bilateral(app)
    _, O, B = observability(k)
    if prop.direction in basis(B):               # 查询方向结构上不可见
        return ('probe_required', B)             # 必须独立探针补盲
    if norm(project(yL - T(yR), O)) > theta_B:   # 只在可见子空间里算差
        return ('alarm', B)
    if not (W_MIN <= w <= W_MAX):                # 力闭合不能靠夹碎换取
        return ('internal_force_violation', B)
    if not sync_ok(app, k):                      # 时钟偏斜破坏闭链
        return ('sync_violation', B)
    return ('EV-coord', O, B)
```

### IP-141 COR（耦合-可观测性调节器，活异常单向下耦）

```python
def choose_coupling(app, F_req):
    if app.live_anomaly:                         # 单调：出现活异常只能更松
        return max_looser(app.kappa, F_req)      # chain → shared → loose
    for k in ('chain', 'shared', 'loose'):       # 能力从高到低试
        _, O, B = observability(k)
        if F_req <= basis(O) and internal_force_feasible(app, k) \
           and sync_ok(app, k) and sync_delay(k) <= TAU_SYNC:
            return k
    return 'loose'                               # 兜底：拆开看清楚
```

### IP-143 OEG（可观测性证据门 + 证书 J_a）

```python
def observability_gate(evs, F_req, k, irreversible):
    cov = union(e.Cov for e in evs)
    if not F_req <= cov:
        return ('reject', 'uncovered_fault_dir', F_req - cov)
    if irreversible and len(evs) == 1 and evs[0].ev == 'EV-anom-clear':
        return ('reject', 'absence_of_evidence', None)      # 清白≠安全
    if evs.has('EV-coord') and k == 'chain' and (F_req & blind(k)):
        return ('reject', 'blind_under_coupling', F_req & blind(k))
    if evs.has('EV-anom-clear') and sad.fnr > delta_can:
        return ('reject', 'detector_degraded', None)
    if evs.has('EV-coord') and not evs.get('EV-coord').internal_force_ok:
        return ('reject', 'internal_force_violation', None)
    return ('ok', None, None)

def observability_certificate(sched, log, M, ood_reg, sad_log, canary_log,
                              coord_log, alert_log, fatigue):
    for c in contacts(sched):
        st = observability_gate(evclasses(c), F_req(c), k_of(c), c.irreversible)
        if st[0] != 'ok': return st
    if not all(couplings_monotone(coord_log)):  return ('reject','coupling_inflation')
    return ('ok', Ja(M.core, probe_log, consent_log, j_p,
                     sad_log, canary_log, det_contracts, coord_log, kappa,
                     obs_blind_cert, w_int_log, alert_log, fatigue))
```

### IP-144 PCE++（探-诺-演++）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, app):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)   # v57
        M.b[cp.region] = inf.post if inf.cls == 'ID' else worst_in(inf.belt)
        F_req = risk_model.required_directions(cp)
        st, cover, blind, fnr = sad_check(app)
        if st == 'alarm' or fnr > delta_can:        # 活异常：冻结 + 下耦 + 复测
            app.live_anomaly = True
            app.kappa = choose_coupling(app, F_req)
            canary_audit(app, budget.k_canary)
        k = choose_coupling(app, F_req)             # COR
        evs = [xmodal_evidence(M.b[cp.region], D(cp), M.rho, cp.level)]
        coord = dac_evidence(app, k, cp.property)
        if coord[0] == 'EV-coord': evs.append(ev(coord))
        if st == 'clear': evs.append(anom_clear(cover))
        if coord[0] == 'probe_required':            # 盲子空间强制补盲
            budget.force(admissible_probe(cp, M, F_abs, dir=coord[1]))
        while observability_gate(evs, F_req, k, cp.irreversible)[0] != 'ok' \
              and budget.probes_left > 0:
            p = argmax(admissible_probes(cp, M, F_abs),
                       key=lambda q: voi_meta_pessimistic(q, M, inf) - cost(q))
            if voi_meta_pessimistic(p, M, inf) < theta_voi: break
            M, _, D = xmodal_fuse(M, cp.region, execute_probe(p, cap=F_abs))
            evs = refresh_evidence(evs, M, cp)      # 只会更保守
            budget.spend(p)
        g = select_gait(schedule_risk(foothold_schedule(x0, cp, M), M))
        if g != 'halt' and observability_gate(evs, F_req, k, cp.irreversible)[0] == 'ok':
            sched.append(commit(cp, g)); log.append(evs); app.live_anomaly = False
            continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, evs, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SAD | O(d_sad)/帧 + O(N_can)/审计 | O(d_sad+\|𝒦\|) | 金丝雀外生、契约诚实（A41） |
| DAC | O(d_b·rank)/区域 | O(\|𝒪\|·d_b) | 盲基公开、内力求界（A42） |
| COR | O(\|κ\|·rank)/子任务 | O(1) | 单向下耦合（A44） |
| AFM | O(1) + O(H_op) | O(\|操作者\|) | 误报预算、疲劳单调（A43） |
| OEG | O(\|e\|·d) | O(\|e\|·d) | 覆盖⊇F_req、消极证据禁用 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_can)·(C_VOI+d_φ+rank)) | O(\|V\|+\|σ\|) | 探针单调、终止、四态完备 |

**正确性定理（Self-Audited Coupled Soundness, SACS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 金丝雀外生：金丝雀的真实效应独立于正常模型可测，且不参与其训练；检测契约对 𝒜_see/𝒜_blind 的自报诚实，FNR̂ 由金丝雀无偏估计；**(A42)** 双臂耦合的盲基公开且正确，EV-coord 仅在 𝒪(κ) 内使用，内力求始终 ∈[w_min,w_max]、同步完整；**(A43)** 警报经济学：每层误报率受预算约束，vig 对疲劳单调不增，vig 下降只降低人类证据权重、不提高任何参数；**(A44)** 耦合单调：存在活异常时 κ 只向更松级别迁移，复耦合须经新鲜金丝雀与证据再认证。则：

1. **可观测承诺健全性**：若 F_req⊆Cov(∪e) 且硬律全过，承诺对 F_req 内故障的失效率 ≤ δ_f+ε_meta(k)+δ_probe+δ_det+δ_coord+ε_h(w_max)。
2. **盲区不被默认安全**：F_req∩(𝒜_blind∪ℬ(κ))≠∅ 时，OEG 只允许"补盲探针"或"拒绝/解耦/L2/安全停"，不存在"clear⇒commit"这类把消极证据当正面证据的路径。
3. **交互单调性强化**：SAD 只能增加探针/解耦/升级；COR 在活异常时只能下耦；AFM 疲劳只能降低人类权重与触发保守停。三者均无升险路径。
4. **终止性**：每检查点金丝雀 ≤k_canary、常规探针 ≤k_probes、共识探针 ≤k_cons，PCE++ 在 k_probes+k_cons+k_canary 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + δ_det + δ_coord + ε_h + δ_ood·α_conf)
             − P(F_req ⊄ Cov 却未被 OEG 检出)          # 自报偏差项（A41/A42）
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(κ 复耦合认证失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**清白是有限额的消极证据**（只认证 𝒜_see，且不得单独支撑不可逆接触）；**一致≠正确**（EV-coord 只在 𝒪(κ) 内成立，盲子空间强制补盲）；**耦合买能力、卖可观测性**（活异常单向下耦，永不靠锁死掩盖）；**警报预算优先于召回**（切断疲劳自我实现回路）。

## 6. 本轮最大风险

**一句话**：本轮把"安全"建立在"系统能诚实说出自己看不见什么"之上，最大风险因此是**被认证的无知**——若检测契约与故障模型 H 的自报本身有偏（声称覆盖了其实没覆盖的方向），系统会以"覆盖⊇F_req"的证书给出比第 57 轮更硬的自信，而故障恰好落在它自认为看得见、实际看不见的方向上；必须用外生金丝雀、H 的可证伪化与盲区保守化三重机制，把"清白"永远降格为有限额的消极证据。
