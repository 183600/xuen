# 第 13 轮 · GESTALT：手势原语 + 柔顺调度 + 技术路线图——把 CHUNK-SERVO 的「视觉闭环」升级为「接触闭环」

> 检索/复核日期：**2026-11-02（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮是灵感循环第 1 轮，三个词是「手势识别」「柔顺控制」「技术路线图」。**不推倒第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO**，而是在 CHUNK-SERVO 的控制层上再加一层「接触层」。本轮不新增外部网络检索，赛事/接口/数据事实沿用第 12 轮已核实的 A/B 级结论；凡属推断的新内容一律标为 C 级假设，并写进实验门。

## 0. 一句话押注

**CHUNK-SERVO 解决「看懂意图并走到目标附近」；GESTALT 解决「贴上去以后，在视觉被夹爪挡住、接触落在 chunk 内部时，靠手势原语 + 变柔顺把最后 1–3 毫米做完」。**

一句话展开：

> 用官方 WLA 做 30 步语义规划（保留）；用 5 步闭环块做视觉伺服（保留）；在每个块边界用**确定性手势识别器**判断当前是「接近 / 预对齐 / 插入 / 就位 / 旋拧 / 挂 / 叠 / 拉 / 释放 / 撤退」中的哪一种，并同时判断**人手是否正在介入**；用识别出的手势**调度 6×6 刚度/阻尼矩阵**，把接触方向变软、把自由方向保持硬；在每个块内部用**手势条件化的柔顺轨迹模板**（螺旋插入、旋拧斜坡、下压搜索）让物理接触自己找正。全程不新增学习模型——手势识别是 DTW + Viterbi + 有限状态机，柔顺是解析导纳控制。

三个词各落一处：

| 灵感词 | 落点 | 不做什么 |
|---|---|---|
| **手势识别** | 两层词表：① 操作手势（机器人自己的接触原语，11 类）；② 交互手势（人为干扰时人手意图，5 类）。用多视图几何残差 + 本体信号 + DTW/Viterbi/FSM 做确定性识别 | 不训练手势分类 CNN；不做 30Hz 全身手势追踪；不把「手势」理解成遥操作指令 |
| **柔顺控制** | 手势 → 接触坐标系下的 6×6 柔顺掩码 + 导纳增益；块间用「指令位姿 − 实测位姿」做外力代理；块内用柔顺轨迹模板；能量罐保证延迟下无源 | 不假装有 F/T 传感器；不做 30Hz 力闭环（接口不允许）；不改底层硬件阻抗 |
| **技术路线图** | 把 L0 观测层 → L1 规划层 → L2 接触层 → L3 组合层排成 12 周 DAG；每一层有门、有 kill criteria、有「做什么/不做什么」 | 不把路线图写成愿望清单；不在未过门时烧正式 320 trials |

## 1. 直觉与动机：第 12 轮已经把「看得见」的部分做完了，剩下的是「看不见」的部分

第 12 轮 CHUNK-SERVO 的贡献是把 30 步开环 chunk 切成 5 步闭环块，用演示检索的相对位姿做视觉伺服。它在**接近段**是对的：头双目 58 mm 基线、0.5–1 m 工作距离、焦距约 282 px，像素级对齐能到几毫米。但它有一个结构性上限：

1. **夹爪自己会挡住目标**。越接近插入，腕部相机越看不见孔/槽/杯架；头部视角又被手臂遮挡。视觉伺服在最后 1 cm 恰恰最不可靠。
2. **透明/反光/细线目标**（药瓶、注射器、网线、拉链、锁孔）在双目和特征匹配上都不稳定。
3. **接触事件发生在视觉刷新之间**。第 12 轮的反馈周期是 `H_c/f_c + τ`；`H_c=5`、30 Hz、RTT=50–150 ms 时约 217–317 ms。在这 200–300 ms 里，物体可能已被顶偏、卡住、滑脱，或者被人挪走。
4. **视觉只能给几何，给不了「顶住了没有、进去多深、是不是卡了、是不是滑了」**。而这四个量恰好是插入/挂/拧/拔的成败判据。

人类的做法不是「看得更准」，而是「摸」：视觉把销钉送到孔上方 3–5 mm，剩下的靠**柔顺 + 接触事件**——销钉被倒角一推就自己找正；力突然下降说明进孔；力持续上升而深度不动说明卡死；切向力与位移不一致说明滑移。GESTALT 要补的就是这一层。

但接口是硬的：挑战赛 API 只给四路 RGB、双臂关节、EE 位姿、夹爪、下身体、语言；**没有 depth、没有 F/T、没有触觉，且 chunk 内没有新观测**。所以本轮的三个关键翻译是：

- **手势 = 离散接触原语**。连续的低层控制很难识别，但「现在处于哪个接触阶段」是一个低维离散量；它既能被演示数据定义，又能直接映射到控制参数。这比让 VLA 直接回归 6D 刚度稳得多。
- **力 = 命令与实际的残差**。我们发出的 EE 目标位姿已知，下一块观测的 EE 实测位姿已知；在位置控制下，两者的差就是环境反作用力的一阶代理。自由空间里这个差是重力下垂/摩擦/稳态误差，可以标定掉；接触时它会突然变大，方向与运动受阻方向一致。
- **技术路线图 = 把「再做一个模型」的冲动换成「按层集成 + 过门」的纪律**。比赛只给 320 trials，任何未过门的想法都不配上正式评测。

## 2. 为什么是「手势」，而不是「又一个相位分类器」

FACT-VLA（第 10 轮）已经有相位化 BC，GEO-RESIDUAL（第 11 轮）已经有 `d_t, n_t, r_static, r_grasp` 和编辑检测。本轮的「手势」不是换名字，而是把三件事统一到一个可执行对象上：

1. **操作手势是控制参数的索引**。识别出 `INSERT`，才允许把横向刚度降到 0.1、轴向限速、启用螺旋搜索；识别出 `SEAT`，才允许全轴变硬、锁死位置。手势是「控制模式」的离散标签，不是语义标签。
2. **交互手势是安全策略的索引**。人为干扰占 20%（64/320 trials）；识别出 `H_REACH` 就先软停/撤退，识别出 `H_RETREAT` 再重定位恢复。它不要求识别「人是谁」，只要求识别「人正在做什么」。
3. **手势是跨任务共享的**。32 个任务不需要 32 套控制器；它们共享 11 个操作手势。规则要求单模型，但**控制器可以跨任务共享**——这正好是「跨任务泛化」在合规边界内的落点。

所以 GESTALT 的手势词表分两层：

| 层 | 词表 | 用途 | 识别信号 |
|---|---|---|---|
| 操作手势 `G_M` | `APPROACH, PREALIGN, INSERT, SEAT, TWIST, PULL, HANG, STACK, ZIP, RELEASE, RETREAT`（+`UNKNOWN`） | 调度柔顺掩码、块内轨迹、速度/力限 | `d_t, n_t, r_static, r_grasp`、EE 速度/旋量、夹爪开度与变化率、目标相对位姿误差、遮挡比例 |
| 交互手势 `G_H` | `H_REACH, H_MOVE, H_TAKE, H_PLACE, H_RETREAT`（+`H_NONE`） | 触发软停/让位/重定位/恢复 | 头双目运动残差（扣除机器人自身投影）、手部 blob 质心/速度/面积、目标区域位移 |

注意：`G_H` 的识别**不用手部关键点模型**。用「运动残差里不属于机器人自身运动的那一簇像素」+ 头双目三角化，就能得到手的三维 blob 与运动方向。这既避开了第二个学习模型，也避开了 RGB 单手姿态在遮挡下不可靠的问题。

## 3. 形式化：先把符号、手势、柔顺、力代理定义清楚

### 3.1 时间与接口模型

设控制频率 `f_c`（沿用 30 Hz 假设，G0 实测），提交块长 `H_c`（固定），网络 + 推理等效延迟 `τ`。块率 `f_b = f_c/H_c`，块时长 `T_b = H_c/f_c`（`H_c=5` 时 167 ms）。一次 `get_action` 后 evaluator 开环执行 `H_c` 步，然后才把新观测交回策略：

```math
T_{\mathrm{fb}} = T_b + \tau = \frac{H_c}{f_c} + \tau .
```

块边界索引 `k = \lfloor t/H_c \rfloor`。块内步索引 `j = 0,\dots,H_c-1`。

### 3.2 符号表

| 符号 | 含义 | 维度 |
|---|---|---|
| `o_t` | 观测（4 路 RGB + 本体 + 语言） | — |
| `x_t \in SE(3)` | 实测 EE 位姿（base 系） | 6 |
| `x_k^{\mathrm{cmd}}` | 上一块最后一步下发的目标位姿 | 6 |
| `\xi_t \in \mathbb R^6` | EE 旋量（线速度 + 角速度） | 6 |
| `w_t` | 夹爪开度 | 1 |
| `d_t, n_t` | 到局部表面的米制距离、法向 | 1, 3 |
| `r_{\mathrm{static}}, r_{\mathrm{grasp}}` | 静止/随夹爪刚体假设残差（第 11 轮） | 1 |
| `e_t \in \mathbb R^6` | DG-KEYFRAME 相对目标误差（第 12 轮） | 6 |

### 3.3 操作手势的转移约束

手势不是任意跳变。定义允许转移矩阵 `A \in \{0,1\}^{|G|\times|G|}`（手工指定，离线用演示统计做一次合理性检查，不做学习）：

```text
APPROACH → PREALIGN → INSERT → SEAT → RELEASE → RETREAT
                     ↘ TWIST ↗        ↘ PULL
HANG → RELEASE → RETREAT
STACK → RELEASE → RETREAT
ZIP → RELEASE → RETREAT
任意 → UNKNOWN → 最近合法手势
任意 → H_*（交互手势可打断）
```

`A` 的作用是给 Viterbi 一个硬约束，避免「插入」被单帧噪声识别成「叠放」。

### 3.4 识别器：DTW 模板 + Viterbi + 迟滞

**特征**（每帧，全部来自已有信号，`O(1)` 计算）：

```math
\phi_t = \mathrm{Norm}\Big[
d_t,\ \dot d_t,\ w_t,\ \dot w_t,\ \|\xi_t\|,\ \angle(\xi_t,n_t),\
r_{\mathrm{static}},\ r_{\mathrm{grasp}},\ \|e_t^p\|,\ \|e_t^r\|,\
\mathrm{occ}_t
\Big].
```

`occ_t` 是腕部 ROI 被夹爪/目标遮挡的比例；它本身是「视觉快失效」的先验。

**模板库**：对每个手势 `g`，从成功演示的对应相位段取若干条特征序列，用 DTW 平均（barycenter）或取 medoid 得到原型 `P_g`。这一步是**离线系统辨识/数据整理**，不是训练策略；模板数量控制在每手势 1–3 条，避免过拟合。

**逐帧距离**：

```math
D_g(t) = \mathrm{DTW}\big(\phi_{t-W+1:t},\ P_g\big),
```

`W` 为窗口（建议 15 帧 = 0.5 s）。用 Sakoe–Chiba 带把复杂度从 `O(Wm)` 降到 `O(Wb)`。

**发射概率**：

```math
\log p_t(g) = -\frac{D_g(t)}{\sigma} + \log \pi_g,
```

`π_g` 是手势先验（由任务阶段给，不从数据学）。

**Viterbi 解码**：

```math
\delta_t(g) = \max_{g': A_{g'g}=1}\Big[\delta_{t-1}(g') + \log A_{g'g}\Big] + \log p_t(g),
```

回溯得 `\hat g_t`。**迟滞**：只有新标签连续 `K` 帧（建议 3 帧 = 100 ms）且分数领先当前标签 `η` 才切换；否则保持。置信度 `κ_t = softmax` 的 top-1 与 top-2 间隔。

**交互手势**用另一个更轻的 FSM，不走 DTW：

```text
hand_blob = 运动残差中扣除机器人投影后的最大连通簇（头双目三角化）
若 hand_blob 存在且向目标区域运动、面积增大 → H_REACH
若 hand_blob 与目标重叠后目标位移 > 5mm      → H_MOVE / H_TAKE
若手带物体接近受器                          → H_PLACE
若 hand_blob 远离且面积减小                  → H_RETREAT
否则                                         → H_NONE
```

### 3.5 力代理：没有 F/T，就用「命令 − 实测」

块边界：

```math
\hat f_k = K_e\big(x_k^{\mathrm{cmd}} - x_k^{\mathrm{meas}}\big) - \hat f_0,
```

`K_e` 是环境刚度（标定），`\hat f_0` 是自由空间偏置（重力下垂 + 摩擦 + 稳态误差）。**只在块边界采样**，因为块内没有新观测；采样率 `f_b = 6 Hz`，足以检测接触/卡死/滑移，但不足以做 30 Hz 力控——这一点必须诚实。

接触坐标系 `C_t = (t_1,t_2,n)` 由第 11 轮的 `n_t` 构造，`t_1,t_2` 为切向正交基。把力代理转到接触系：

```math
\hat f_k^{c} = \mathrm{Ad}_{R_c}^{\top}\hat f_k,\qquad
\tilde f_k = S(g_k)\,\hat f_k^{c}.
```

`S(g)` 是柔顺掩码：`S_{ii}=1` 表示该轴「允许力推动」（软），`S_{ii}=0` 表示「忽略力、跟踪位置」（硬）。**这正是手势识别与柔顺控制的接口。**

### 3.6 手势条件导纳

```math
M_g\,\dot v + D_g\,v + K_g\big(x^{\mathrm{ref}} - x^{\mathrm{des}}\big) = \tilde f,
```

离散化（块率，前向 Euler）：

```math
v_{k+1} = v_k + T_b\,M_g^{-1}\Big(\tilde f_k - D_g v_k - K_g(x^{\mathrm{ref}}_k - x^{\mathrm{des}}_k)\Big),
```

```math
x^{\mathrm{ref}}_{k+1} = x^{\mathrm{ref}}_k + T_b\,v_{k+1},
\qquad
\|x^{\mathrm{ref}}_{k+1}-x^{\mathrm{des}}_{k+1}\| \le \delta_{\max}.
```

`x^{\mathrm{des}}` 是第 12 轮 VLA + 视觉伺服给出的期望位姿；`x^{\mathrm{ref}}` 是柔顺后的参考。

手势到掩码的映射（先验，G9/G10 更新）：

| 手势 | 软轴（`S=1`） | 硬轴（`S=0`） | 块内模板 |
|---|---|---|---|
| `APPROACH` | 无 | 全轴 | 直线，限速 |
| `PREALIGN` | 横向 `t_1,t_2` + 两个倾斜旋转 | 轴向 `n`、绕 `n` 偏航 | 微步靠近 |
| `INSERT` | 横向 + 倾斜 | 轴向（限速）、偏航 | 螺旋搜索 |
| `SEAT` | 无 | 全轴 | 小步压入 |
| `TWIST` | 绕 `n` 旋转 | 轴向预压、横向 | 旋拧斜坡 |
| `PULL` | 横向 | 轴向 | 直线拔出 |
| `HANG` | 横向 | 竖直 | 下压 + 横向微扫 |
| `STACK` | 竖直 | 横向 | 下压 + 对齐保持 |
| `ZIP` | 法向 | 沿路径 | 沿路径拖拽 |
| `RELEASE` | 无 | 全轴保持 | 张爪 |
| `RETREAT` | 无 | 全轴 | 直线后退 |
| `H_REACH/H_MOVE/H_TAKE/H_PLACE` | 全轴（软停） | 无 | 原地保持或后退 |
| `H_RETREAT` | 无 | 全轴 | 重定位 |

**无源性/能量罐**：导纳 + 延迟可能注入能量。维护能量罐

```math
E_{k+1} = \min\!\Big(E_{\max},\ E_k + T_b\,v_k^{\top}\tilde f_k\Big).
```

若 `E_{k+1}<0`，把 `\tilde f_k` 按比例缩到使 `E_{k+1}=0`（或直接冻结柔顺轴）。这给出**对任意有界延迟的无源保证**，比精确建模 `τ` 更稳。

### 3.7 块内柔顺轨迹：没有反馈，就把动作本身设计成「会自己找正」

块内 evaluator 开环执行，所以不能承诺块内力控。能做的是让块内轨迹**天然抗错位**：

```math
x_{k,j} = x^{\mathrm{ref}}_k \oplus \Psi_{g_k}\!\left(j/f_c\right),\qquad j=0,\dots,H_c-1.
```

`Ψ_g` 是手势条件轨迹生成器（接触系）：

- `INSERT`（螺旋搜索）：
  ```math
  \Psi(s) = \big[r\cos(2\pi\nu s/T_b)-r,\ r\sin(2\pi\nu s/T_b),\ v_z s,\ 0,0,0\big],
  ```
  `r \approx 0.5–1.5 mm`，`ν \approx 1–2` 圈/块，`v_z \approx 2–5 mm/s`。
- `TWIST`（旋拧斜坡）：`Ψ(s) = [0,0,v_z s,0,0,\omega s]`，`ω` 线性升到限幅。
- `HANG/STACK`（下压 + 微扫）：`v_z s` 叠加 `±r` 的横向方波/正弦。
- `ZIP`（沿路径拖拽）：沿演示检索的路径切向给速度，法向给小幅抖动。
- `APPROACH/RELEASE/RETREAT`：直线，限速。

这样即使块内看不到新观测，接触几何也会把误差「推」回可插入的范围内；块边界再用导纳和力代理做事件判定。

### 3.8 状态机

```text
INIT ──obs──▶ APPROACH ──d_t<d_far──▶ PREALIGN ──d_t<d_c──▶ INSERT
                                                              │
                                         ┌────────────────────┘
                                         ▼
                                      SEAT ──成功──▶ RELEASE ──▶ RETREAT ──▶ DONE
                                         │
                                         ├─ r_grasp 突变 ──▶ SLIP ──▶ 重抓
                                         └─ edit/hand ────▶ YIELD ──▶ 重定位 ──▶ 恢复
任意状态 ──H_REACH/H_MOVE/H_TAKE──▶ YIELD（软停）
YIELD ──H_RETREAT + 场景稳定 K 帧──▶ 重定位 ──▶ 恢复或 VLA 重规划
```

## 4. 复杂度与工程可行性

- **识别**：每帧 `O(|G| W b d)`；`|G|=12, W=15, b=3, d=12` → 约 6.5k 次乘加，NumPy 下 <0.1 ms。若只在块边界识别（6 Hz），开销可忽略。
- **导纳**：6×6 矩阵运算，`O(1)`，<0.05 ms。
- **块内模板**：每步一次 SE(3) 复合，`O(H_c)`。
- **内存**：模板库 `O(|G| m d)`，百 KB 级；不随端口线性增长（只读共享）。
- **CPU**：单端口伺服 + 识别 + 导纳 < 1 ms/块；N 端口可线性扩展，不抢 GPU。
- **合规**：识别器无神经权重，导纳是解析控制律；VLA 仍是唯一学习模型。

## 5. 技术路线图：把四层能力排成 12 周 DAG

| 层 | 能力 | 来自 | 本轮动作 | 门 |
|---|---|---|---|---|
| **L0 观测层** | 相位、接触几何、编辑检测 | 第 10/11 轮 | 冻结；只提供 `d_t,n_t,r_*,edit` | 继承 |
| **L1 规划层** | 30 步 VLA + 5 步视觉伺服 + DG-KEYFRAME | 第 12 轮 | 冻结；提供 `x^{des}` 与 5 步块 | G0–G3 继承 |
| **L2 接触层** | 手势识别 + 力代理 + 变柔顺 + 块内模板 | **本轮** | 全量实现 | **G8–G11** |
| **L3 组合层** | 单任务 A/B + 320 trials 组合 | 第 12 轮 | 用 L2 的边际收益重排 `q_t×Δ/cost` | G12 |

**12 周排期**（依赖：L2 依赖 L0/L1 的接口稳定）：

```text
W0–W1  P0  继承基线；力代理标定（K_e, f_0）；确认「无第二模型」合规
W1–W3  P1  手势模板库；识别器 F1≥0.8；接触系构造；离线回放
W3–W5  P2  导纳 + 能量罐；仿真扫 τ/H_c/增益；G8/G10
W5–W7  P3  集成进 5 步块；块内模板；5 任务单任务 A/B；G9/G11
W7–W9  P4  人为干扰 YIELD/恢复；G4 扩展；32 任务干跑；G12
W9–W10 P5  全量提交；回滚开关；合规说明
```

**Kill criteria**（每条都要写死，避免自欺）：

1. G8 力代理不可分（接触 AUROC <0.85）→ 放弃力代理，只保留块内柔顺模板（仍可能涨点，但别声称力控）。
2. G9 识别 F1 <0.75 → 回退 FACT-VLA 相位标签，不新增手势层。
3. G10 仿真卡死率 >10% → 降轴向速度、增大搜索半径、延长 SEAT；仍不过则只对 HANG/STACK 启用。
4. G11 真机 5 任务 <3 个 +10pp → 不提交 GESTALT 版本；保留 CHUNK-SERVO 基线。
5. G12 p99 延迟或 timeout 回归 → 降识别频率到块率、减模板、关交互手势。

**路线图的取舍原则**：先做「跨任务共享、接口已有、可离线验证」的层（识别、导纳、模板），后做「任务特定、需要真机」的层（参数微调、任务组合）。不要反过来。

## 7. 风险与合规

| 风险 | 影响 | 缓解 |
|---|---|---|
| 力代理被重力/摩擦淹没 | 误判接触/卡死 | 逐机器人标定 `f_0`；只在低速、近接触段使用；置信度低回退视觉 |
| 延迟下导纳振荡 | 不安全 | 能量罐 + 增益调度（`K_eff=K_0/(1+τ/τ_0)`）；`T_fb>300ms` 关柔顺 |
| 接触系估计错 | 软硬轴搞反 | 只在 `n_t` 置信度高时启用；否则全轴硬、只做块内模板 |
| 手势误识别 | 用错控制模式 | Viterbi 转移约束 + 迟滞 + 置信度门；低置信度回退 FACT-VLA 相位 |
| 人手检测漏检/误检 | 安全或频繁停顿 | 机器人自运动投影扣除；连续 `K` 帧确认；不动就恢复 |
| 单模型解释 | 被判定为第二模型 | 识别器无学习权重；导纳是控制律；提交材料写清 C1/C2 |
| 夹爪挡住目标 | 视觉/力代理都退化 | 这正是柔顺层的目的；块内模板 + 力代理不依赖看清 |
| 变形/透明物体 | 接触系不稳 | 只对刚体 A 档启用精确柔顺；变形任务回退 VLA |
| 评测噪声 | +1–2pp 假阳性 | 配对 A/B、bootstrap；320 trials SE≈2.4pp |

## 8. 一句话最大风险

**当前方案最大的风险是：力代理在真实接触中太脏、接触坐标系估计太飘，导致「该软的时候软错方向」，反而不如 CHUNK-SERVO 的纯视觉基线——必须用 G8/G10 先证伪，再谈涨点。**

### 1.2 第 12 轮留下的四个缺口

## 2. 形式化定义

### 2.1 时间模型

设控制频率 `f_c`（假设 30 Hz，G0 实测），块长 `H_c`（建议 5），块率 `f_b = f_c/H_c`，块时长 `T_b = H_c/f_c`。反馈周期：

```math
T_{\mathrm{fb}} = T_b + \tau = \frac{H_c}{f_c} + \tau .
```

`H_c=5, f_c=30, τ=50 ms` → `T_fb ≈ 217 ms`；`τ=150 ms` → `317 ms`。块边界索引 `k = \lfloor t/H_c\rfloor`，块内步 `j=0,\dots,H_c-1`。

1. 接触任务成功率最大化；

4. 单端口 CPU 开销 < 1 ms/块，N 端口可扩展。

## 3. 手势识别器

### 3.1 两层词表

**操作手势** `G_M`：

```text
APPROACH, PREALIGN, INSERT, SEAT, TWIST, PULL,
HANG, STACK, ZIP, RELEASE, RETREAT, UNKNOWN
```

**交互手势** `G_H`：

```text
H_REACH, H_MOVE, H_TAKE, H_PLACE, H_RETREAT, H_NONE
```

`G_M` 描述机器人自己的接触原语；`G_H` 描述人为干扰时人手在做什么。两者共享观测，但识别器不同：`G_M` 用 DTW+Viterbi，`G_H` 用几何 FSM。

### 3.2 操作手势特征

```math
\phi_t = \mathrm{Norm}\Big[
d_t,\ \dot d_t,\ w_t,\ \dot w_t,\ \|\xi_t\|,\ \angle(\xi_t,n_t),\
r_{\mathrm{static}},\ r_{\mathrm{grasp}},\ \|e_t^p\|,\ \|e_t^r\|,\
\mathrm{occ}_t
\Big]\in\mathbb R^{12}.
```

- `occ_t`：腕部 ROI 被夹爪/目标遮挡比例；它是「视觉快失效」的先验，也是 `INSERT/SEAT` 的强特征。
- 所有特征来自第 10/11/12 轮已有信号，`O(1)` 计算，无需新感知。

### 3.3 模板库与 DTW

对每个 `g∈G_M`，从成功演示的对应相位段取 `1–3` 条特征序列，构造原型 `P_g`（DTW barycenter 或 medoid）。这一步是**离线数据整理/系统辨识**，不是训练策略；模板是固定数据，不参与在线梯度更新。

DTW 距离：

```math
D_g(t) = \mathrm{DTW}\big(\phi_{t-W+1:t}, P_g\big),
```

`W=15`（0.5 s）。用 Sakoe–Chiba 带 `b=3` 把复杂度降到 `O(W b d)`。

发射概率：

```math
\log p_t(g) = -\frac{D_g(t)}{\sigma} + \log \pi_g .
```

`σ` 由一小段标定数据定；`π_g` 是任务阶段先验（例如任务文本含「插」则 `INSERT` 先验高），不从数据学。

### 3.4 Viterbi + 迟滞

转移矩阵 `A∈{0,1}^{|G|×|G|}` 手工指定（§3.5）。Viterbi：

```math
\delta_t(g) = \max_{g':A_{g'g}=1}\big[\delta_{t-1}(g')+\log A_{g'g}\big]+\log p_t(g),
```

回溯得 `\hat g_t`。迟滞：新标签需连续 `K=3` 帧（100 ms）且分数领先 `η` 才切换；否则保持。置信度 `κ_t` 取 top-1/top-2 的 softmax 间隔。

**为什么不用 HMM 学习转移概率**：单模型合规 + 数据量/标注成本；手工转移掩码已经编码了任务的物理顺序，学习转移的边际收益低、解释成本高。

### 3.5 允许转移

```text
APPROACH → PREALIGN → INSERT → SEAT → RELEASE → RETREAT
                     ↘ TWIST ↗        ↘ PULL
HANG → RELEASE → RETREAT
STACK → RELEASE → RETREAT
ZIP → RELEASE → RETREAT
任意 → UNKNOWN → 最近合法手势
任意 → H_*（交互手势可打断）
```

`A` 是硬约束，避免单帧噪声把 `INSERT` 跳到 `STACK`。

### 3.6 交互手势 FSM

**不做手部关键点模型**。用头双目 + 运动残差：

```text
1. 用 URDF + 关节角 + 相机外参，把机器人自身投影到图像，得到自运动掩码 M_robot
2. 帧差 |I_t - I_{t-1}| > θ，去掉 M_robot 膨胀区，得到候选运动掩码 M_motion
3. 取 M_motion 最大连通簇，用头双目三角化得到三维 blob B_t（质心 p_t、速度 u_t、体积 a_t）
4. 用 B_t 相对目标/受器区域的几何关系做 FSM
```

FSM：

```text
H_NONE    ── B_t 出现且向目标运动、a_t 增大 ──▶ H_REACH
H_REACH   ── B_t 与目标重叠后目标位移 >5mm ──▶ H_MOVE / H_TAKE
H_MOVE    ── 手带物体接近受器 ───────────────▶ H_PLACE
H_PLACE   ── 手撤离、a_t 减小 ───────────────▶ H_RETREAT
H_REACH/… ── B_t 消失且场景稳定 K 帧 ─────────▶ H_NONE（允许恢复）
```

阈值 `θ`、`5 mm`、`K` 由 G9 标定；不依赖人手身份/肤色。

### 3.7 识别器复杂度

- 特征：`O(1)`/帧。
- DTW：`O(|G_M| W b d)`；`12×15×3×12 ≈ 6.5k` 次乘加。
- Viterbi：`O(|G_M|^2)`/帧 ≈ 144 次比较。
- FSM：`O(#blobs)`。
- 合计 <0.1 ms（NumPy）或 <0.5 ms（纯 Python）；若只在块边界（6 Hz）识别，可忽略。

## 4. 力代理

### 4.1 定义

块边界：

```math
\hat f_k = K_e\big(x_k^{\mathrm{cmd}} - x_k^{\mathrm{meas}}\big) - \hat f_0 .
```

- `x_k^{cmd}`：上一块最后一步下发的目标位姿（已知）。
- `x_k^{meas}`：本块第一帧观测的 EE 实测位姿（已知）。
- `K_e`：环境刚度（6×6，标定）。
- `\hat f_0`：自由空间偏置（重力下垂 + 摩擦 + 稳态误差）。

**只在块边界采样**：块内没有新观测，采样率 `f_b=6 Hz`。这足以检测接触/卡死/滑移，但**不足以做 30 Hz 力控**；报告和提交材料必须写清。

### 4.2 可辨识性

准静态、线性环境假设下：

```math
x^{\mathrm{meas}} = x^{\mathrm{cmd}} - K_e^{-1} f_{\mathrm{env}},
```

于是

```math
\hat f_k = f_{\mathrm{env}} - \hat f_0 .
```

只要 `K_e` 满秩、`\hat f_0` 标定准确、噪声有界，就能恢复接触力的一阶近似。

**失效条件**（必须写进风险）：

- 自由空间偏置随姿态/负载变化 → 用分段/姿态相关偏置，或只在近接触段启用。
- 环境刚度远大于/远小于 `K_e` → 代理幅值失真，但**方向与突变**仍可用。
- 动态接触（碰撞）→ 准静态假设失效，只做事件检测，不做力幅值解释。

### 4.3 标定

1. **自由空间**：在 10–20 个姿态下执行小步运动，记录 `x^{cmd}-x^{meas}`，拟合 `\hat f_0(q)`（线性/二次）。
2. **接触刚度**：用已知柔顺物体（海绵/硅胶）做压入，测力（可用外部标定台，仅离线）与位移，回归 `K_e`；线上不依赖外部力传感器。
3. **验证**：G8：接触 AUROC ≥0.85；自由空间残差 <2 N（或接触力的 10%）。

## 5. 手势条件变柔顺

### 5.1 接触坐标系

由第 11 轮的 `n_t` 构造：

```math
R_c = [t_1,\ t_2,\ n]\in SO(3),\qquad t_1\perp n,\ t_2=n\times t_1 .
```

力代理转接触系：

```math
\hat f_k^{c} = \mathrm{Ad}_{R_c}^{\top}\hat f_k =
\begin{bmatrix} R_c^{\top} & 0\\ 0 & R_c^{\top}\end{bmatrix}\hat f_k .
```

柔顺掩码：

```math
S(g)=\mathrm{diag}(s_1(g),\dots,s_6(g)),\qquad s_i\in\{0,1\},
```

```math
\tilde f_k = S(g_k)\,\hat f_k^{c}.
```

`S_{ii}=1`：该轴允许力推动（软）；`S_{ii}=0`：忽略力、跟踪位置（硬）。

### 5.2 导纳控制律

```math
M_g\,\dot v + D_g\,v + K_g\big(x^{\mathrm{ref}} - x^{\mathrm{des}}\big) = \tilde f .
```

块率前向 Euler：

```math
v_{k+1} = v_k + T_b\,M_g^{-1}\Big(\tilde f_k - D_g v_k - K_g(x^{\mathrm{ref}}_k - x^{\mathrm{des}}_k)\Big),
```

```math
x^{\mathrm{ref}}_{k+1} = x^{\mathrm{ref}}_k + T_b\,v_{k+1},
```

```math
\|x^{\mathrm{ref}}_{k+1}-x^{\mathrm{des}}_{k+1}\|_\infty \le \delta_{\max},\qquad
\|v_{k+1}\|_\infty \le v_{\max}.
```

`x^{des}` 来自 CHUNK-SERVO；`x^{ref}` 是柔顺后的参考，最终下发。

**参数先验**（G10 扫）：

| 轴类型 | `M` | `D` | `K` | 说明 |
|---|---:|---:|---:|---|
| 硬轴 | 1 | 2√K | 200–500 | 近似位置控制 |
| 软轴（平移） | 1 | 20–40 | 5–20 | 让力推动 |
| 软轴（旋转） | 0.1 | 2–5 | 1–5 | 让力矩转动 |

比例关系 `D ≈ 2√(MK)` 给临界阻尼起点。

### 5.3 无源性：能量罐

延迟下导纳可能注入能量。维护能量罐：

```math
P_k = v_k^{\top}\tilde f_k,\qquad
E_{k+1} = \min\!\big(E_{\max},\ E_k + T_b P_k\big).
```

若 `E_k + T_b P_k < 0`（需要从空罐取能量），按

```math
\alpha = \frac{-E_k}{T_b P_k}\in[0,1]
```

缩放柔顺速度 `v_{k+1}\leftarrow\alpha v_{k+1}`（或冻结柔顺轴），使 `E_{k+1}=0`。

**结论**：`E_k≥0` 恒成立；闭环对任意无源环境、任意有界延迟无源（Hannaford–Ryu 时域无源控制的标准结论）。这比精确建模 `τ` 更稳，代价是极端情况下柔顺变慢。

### 5.4 增益调度（可选，与能量罐二选一或叠加）

```math
K_{\mathrm{eff}} = \frac{K_0}{1+\tau/\tau_0},\qquad \tau_0=50\,\mathrm{ms}.
```

`T_fb>300 ms` 时关闭柔顺，只保留块内模板 + CHUNK-SERVO 视觉伺服。

## 6. 块内柔顺轨迹

### 6.1 为什么需要

块内 evaluator 开环执行，拿不到新观测。所以块内不能做反馈；能做的是**把轨迹本身设计成抗错位的**：让接触几何把误差「推」回可插入范围。

### 6.2 生成器

```math
x_{k,j} = x^{\mathrm{ref}}_k \oplus \Psi_{g_k}\!\left(\frac{j}{f_c}\right),\qquad j=0,\dots,H_c-1.
```

`⊕` 为 SE(3) 局部复合。各手势模板（接触系）：

| 手势 | `Ψ_g(s)` | 参数 |
|---|---|---|
| `APPROACH` | `[0,0,v_z s,0,0,0]` | `v_z` 限速 |
| `PREALIGN` | 直线 + 微步 | 步长 ≤0.5 mm |
| `INSERT` | `[r cos(2πνs/T_b)-r, r sin(2πνs/T_b), v_z s,0,0,0]` | `r=0.5–1.5 mm`, `ν=1–2`, `v_z=2–5 mm/s` |
| `SEAT` | `[0,0,v_z s,0,0,0]` | `v_z≤1 mm/s` |
| `TWIST` | `[0,0,v_z s,0,0,ω s]` | `ω` 线性升至限幅 |
| `PULL` | `[0,0,-v_z s,0,0,0]` | 轴向 |
| `HANG` | `[r sin(2πνs/T_b),0,-v_z s,0,0,0]` | 下压 + 横向微扫 |
| `STACK` | `[0,0,-v_z s,0,0,0]` | 下压 |
| `ZIP` | 沿演示路径切向 + 法向小幅抖动 | 路径来自 DG-KEYFRAME |
| `RELEASE` | 张爪，无位移 | — |
| `RETREAT` | `[0,0,-v_z s,0,0,0]` | 后退 |
| `H_*` | 原地保持或小幅后退 | 软停 |

### 6.3 与导纳的关系

- 导纳在块边界修正 `x^{ref}`（低频、反馈）。
- 模板在块内生成 `x_{k,j}`（高频、开环）。
- 两者复合：`x_{k,j}=x^{ref}_k\oplus\Psi_{g_k}(j/f_c)`。

这形成「块间反馈 + 块内柔顺」的双层结构，正好对应 CHUNK-SERVO 的双频设计。

### 7.2 主循环伪代码

```python
class GestaltPolicy:
    def get_action(self, obs):
        self._tick(obs)

        # 1) block-boundary force proxy
        f_hat = self.force_proxy.estimate(obs)          # 6D, calibrated

        # 2) gesture recognition (deterministic)
        g_m, kappa_m = self.gesture_m.update(obs)        # DTW + Viterbi + hysteresis
        g_h, kappa_h = self.gesture_h.update(obs)        # FSM

        # 3) human interference has priority
        if g_h in (H_REACH, H_MOVE, H_TAKE) and kappa_h > TH_H:
            self.state = YIELD
        elif self.state == YIELD and g_h == H_RETREAT and self.scene_stable(K):
            self.state = RELOCALIZE

        # 4) desired pose from CHUNK-SERVO
        x_des = self.chunk_servo.desired(obs)

        # 5) compliance mask + admittance (only if trusted)
        if self.gesture_trusted(g_m, kappa_m) and self.contact_frame_trusted(obs):
            S = self.mask(g_m)
            f_c = self.to_contact_frame(f_hat, obs)
            f_tilde = S @ f_c
            x_ref = self.admittance.step(x_des, f_tilde, g_m)   # energy tank inside
        else:
            x_ref = x_des

        # 6) intra-block compliant template
        chunk = []
        for j in range(self.H_c):
            psi = self.template(g_m, j / self.f_c)
            chunk.append(compose(x_ref, psi))

        # 7) action adapter (WLA 54D -> API 21D)
        return self.adapter.to_api(chunk, obs, self.token)
```

```text
INIT ──obs──▶ APPROACH ──d_t<d_far──▶ PREALIGN ──d_t<d_c──▶ INSERT
                                                              │
                                         ┌────────────────────┘
                                         ▼
                                      SEAT ──成功──▶ RELEASE ──▶ RETREAT ──▶ DONE
                                         │
                                         ├─ r_grasp 突变 ──▶ SLIP ──▶ 重抓
                                         └─ edit/hand ────▶ YIELD ──▶ 重定位 ──▶ 恢复
```

### 7.4 回退链

```text
识别可信 + 接触系可信 + 力代理可信 → 全柔顺 + 模板
识别可信 + 接触系不可信           → 只块内模板（全轴硬）
识别不可信 + 接触系可信           → FACT-VLA 相位 + 导纳
都不可信                          → CHUNK-SERVO 纯视觉 + 安全 hold
```

回退不是失败：它保证任何情况下都返回合法动作；柔顺的边际收益只在 A 档接触任务。

## 9. 正确性论证

### 9.1 识别器延迟界

**假设 A1（可分离性）**：对手势真值段内的任意长度 `W` 窗口，`D_{g^*}(t) + δ < D_g(t)` 对所有 `g≠g^*` 成立，`δ>0`。

**引理 1**：在 A1 下，Viterbi + `K` 帧迟滞在真值段开始后至多 `W-1+K` 帧输出 `g^*`。

**证明**：窗口需完全落入真值段才满足 A1；最坏 `W-1` 帧。满足后 `log p_t(g^*)` 严格最大；转移矩阵 `A` 允许真值路径（假设手势序列合法），Viterbi 保持该路径。迟滞再需 `K` 帧确认。∎

工程含义：`W=15, K=3` → 最坏 170 ms 识别延迟；对块率 167 ms 约一块的延迟。这是可接受的，因为接触段本身持续数百毫秒。

### 9.2 力代理可辨识性

**假设 A2（准静态线性环境）**：接触时 `x^{meas}=x^{cmd}-K_e^{-1}f_{env}`，`K_e` 满秩，`\hat f_0` 已标定，噪声 `\epsilon` 有界。

**引理 2**：`\hat f_k = f_{env}+\epsilon`，故 `\|\hat f_k-f_{env}\|≤\|\epsilon\|`。

**证明**：直接代入。∎

**注意**：A2 在动态碰撞/大变形下不成立；此时只用 `\|\hat f\|` 的突变做事件检测，不解释幅值。

### 9.3 柔顺的自找正

**假设 A3（倒角接触、线性刚度）**：横向错位 `x`、孔心 `x_h`、指令 `x_d`；接触力 `F_env=k_c(x_h-x)`（指向孔），控制器力 `F_c=K_{lat}(x_d-x)`。

**引理 3（自找正）**：准静态平衡时

```math
x-x_h=\frac{K_{lat}}{K_{lat}+k_c}(x_d-x_h),
```

故 `K_{lat}→0` 时 `x→x_h`。

**证明**：令 `F_c+F_env=0`，解 `x`。∎

工程含义：柔顺轴刚度越低，最终横向错位越小；这就是 RCC（remote center compliance）的解析版本。**风险**：轴向力过大 + 摩擦大时，倒角可能无法推动销钉 → 卡死；需限轴向速度/力（`v_z≤5 mm/s`）并检测 `r_static`。

### 9.4 无源性

**假设 A4**：环境无源（`v^T f_env ≤ 0` 沿运动方向不注入能量），延迟有界，能量罐初值 `E_0≥0`。

**引理 4**：能量罐规则保证 `E_k≥0` 且闭环无源。

**证明**：若 `E_k+T_bP_k≥0`，更新后 `E_{k+1}≥0`；否则按 `α` 缩放使 `E_{k+1}=0`，控制器不输出超过存储的能量。由 TDPA 标准结论，无源互联稳定。∎

工程含义：不需要精确 `τ` 模型；代价是极端延迟下柔顺被冻结，退化为硬跟踪（安全但精度低）。

### 9.5 安全包络

**定理 1（安全）**：在 A1–A4 下，任意块下发动作满足：

1. `\|x^{ref}-x^{des}\|_∞≤δ_max`；
2. `\|v\|_∞≤v_max`；
3. 若识别/接触系/力代理任一不可信，退化为 CHUNK-SERVO 或安全 hold；
4. 不返回 NaN/错误形状。

**证明**：由 §5.2 的 clip、§7.4 的回退链、§7.2 的异常处理直接得到。∎

### 9.6 单模型合规

**命题 1**：GESTALT 在线不加载第二个学习模型。

**论证**：识别器使用固定模板 + 手工转移 + 阈值；导纳是解析控制律；模板库是离线数据，不是策略网络。若官方把「数据驱动的模板匹配」也视为模型，则退到 C1 模式（只用 FACT-VLA 离线相位标签）或 C2 模式（纯手工规则 + 解析导纳）。见 §12。

5. 交互手势 on/off（看 human 轴）。
6. `H_c∈{3,5,8}`。
7. 相对目标（第 12 轮）on/off（防重复归因）。
8. 单任务 5 次 vs 10 次（预算允许时）。

### 11.6 统计

320 trials 下 `p≈0.25` 的单次标准误约 `sqrt(0.25×0.75/320)=2.42pp`；配对 A/B 方差更低，但仍需 bootstrap CI。**不要用 +1–2pp 做结论**；G11 的 +10pp 门槛是为了让信号大于噪声。

## 12. 风险与合规

### 12.1 单模型合规

| 模式 | 做法 | 风险 | 建议 |
|---|---|---|---|
| C1 离线标注 | 手势/相位只离线生成标签；线上只用 VLA | 最低 | 若官方严格，退此模式 |
| C2 确定性控制器 | DTW 模板 + 手工转移 + 解析导纳，无学习权重 | 低 | 主推 |
| C3 同 checkpoint 特征 | 若需更强特征，用 VLA 同 checkpoint encoder | 中 | 仅必要时 |

**禁止**：加载第二个学习策略/残差网络/独立视觉编码器做在线决策。

### 12.2 风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| 力代理被重力/摩擦淹没 | 误判接触/卡死 | 逐机器人标定 `f_0`；只近接触/低速用；置信度低回退 |
| 延迟下导纳振荡 | 不安全 | 能量罐 + 增益调度；`T_fb>300 ms` 关柔顺 |
| 接触系估计错 | 软硬轴搞反 | 只在 `n_t` 置信度高时启用；否则全轴硬 |
| 手势误识别 | 用错控制模式 | Viterbi 转移 + 迟滞 + 置信度门；回退 FACT-VLA 相位 |
| 人手漏检/误检 | 安全/频繁停顿 | 机器人自投影扣除；连续 K 帧确认；不动就恢复 |
| 卡死 | 任务失败/损坏 | 限轴向速度/力；`r_static` 检测；螺旋搜索 |
| 透明/变形 | 接触系不稳 | 只对刚体 A 档启用精确柔顺；变形回退 VLA |
| 单模型解释 | 判违规 | C1/C2；提交材料写清；模板是数据不是策略 |
| 评测噪声 | 假阳性 | 配对 A/B、bootstrap、重复 |
| 数据泄漏 | 离线虚高 | 按 session/物体/背景分组 |
| `pivot`/adapter 语义（继承第 12 轮） | 动作被拒 | 单任务通道先验证；零 pivot 回退 |
| 提交次数限制 | 无法多次 A/B | 邮件确认；单任务通道先验证 |

## 13. 一句话押注与最大风险

**押注**：用官方 WLA 做规划、用 CHUNK-SERVO 做视觉闭环、用确定性手势识别调度变柔顺、用块内柔顺轨迹处理接触、用能量罐保证延迟安全——在不新增学习模型的前提下，把最后 3 厘米从「看得见的闭环」升级为「看不见时也能完成的接触闭环」。

**最大风险**：力代理在真实接触中太脏、接触坐标系估计太飘，导致「该软的时候软错方向」，反而不如纯视觉基线；因此必须先过 G8/G10，再谈任何涨点。
