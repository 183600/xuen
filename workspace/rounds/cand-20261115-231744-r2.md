# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「参数高效微调」×「视觉问答」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**有界适配 + 证据接地问答**。两个灵感分别治理 v9 的两种债：**适配债**（块证书把前向模型 F̂ 冻结在信任域内，域一漂移只能靠缩短 K 保守化，系统"越陌生越慢"却不"越陌生越会"）、**监督债**（16 个 IP 与 claims 很丰富，但操作员只有指标面板，缺少可追问、可审计的解释通道；自由生成式 VQA 又会幻觉，不能作数）。新组件一律**只改提议与表达、不改裁判与安全**：适配器不能放宽证书，问答不能进入控制回路；任一环节失效 ⇒ 恒等适配器 / 只读面板，严格退回 v9（引理 92）。

## 0. 直觉与动机

**灵感 1（参数高效微调 → 有界适配的"提案器"，而非"裁判"）**
直觉：PEFT 最诱人的地方是"用几百个参数就把大模型迁移到新域"，最危险的地方也是同一件事——它在悄悄改模型的判断。若把 LoRA 直接塞进证书裁判 F̂，"有界"只是权重范数有界，系统误差仍可能被放大。关键转向：**让适配只改提议分布 π，不动裁判 J=(F̂,M₀,SpatialCert)**。低秩适配器 ΔW=(α/r)BA 以 B=0 初始化（ΔW≡0，逐位等于 v9），在线用"证书即奖励模型"做偏好微调：证书通过且余量更大的块为正例——无需人工标签。核心创新：**有界适配器银行（BoundedAdapterBank, BAB）** + **谱预算（SpectralBudget）**：‖ΔW‖₂≤ε 使策略输出偏差可界；裁判冻结使"适配再激进也不可能认证一个不安全动作"。修复域偏移的裁判更新另走**影子晋升门**（IP-359），不进在线控制路径。

**灵感 2（视觉问答 → 证据接地的可追问解释）**
直觉：VQA 的自然用法是"机器人回答人关于所见的问题"，但把生成模型直接接进安全系统是灾难：它会自信地编造"路是通的"。关键转向：**把 VQA 从"生成器"降级为"语言化器"**——事实命题由确定性查询 claim 图 / SpatialCert 得出，VLM 只负责措辞；低覆盖、证据过期、措辞与命题 NLI 矛盾时一律**弃答**并给出结构化证据。核心创新：**证据接地问答桥（GroundedVQABridge, GVB）**：答案 A=(命题, 证据原子集 E, 置信度, 弃答位)。由此得到"零安全事实幻觉"的结构性保证（引理 90），残余风险从"模型幻觉"转移到可审计的"实体绑定错误"。

**灵感 3（综合 → 适配写提议、问答写证据，二者都不写安全）**
直觉：两个灵感看似无关，安全结构却同构——都是"**外部能力进入系统，但被一个不可协商的裁判挡住**"。PEFT 改变"我会提议什么"，VQA 改变"我能说清什么"，而 M₀、SpatialCert、F̂ 的证书权威保持不变。再补一个主动版：当证书处在模糊带（ĝ_min∈[d_safe,d_safe+β] 或 γ_grasp 未知）时，**自问控制器（SelfInterrogation, SIC）** 按价值信息 VOI 选一个视觉问题去消歧；答案只能**收紧**（触发复检/减速/停），永不放松硬约束（引理 91）。于是适配释放的性能与问答释放的可解释性，都被同一套退化代数收编。

## 1. 研究问题（轮次升级版）

- **Q1（有界适配的安全边界）**：低秩 + 谱范数预算能否把"适配器对输出的影响"变成可计算的证书余量增量，并证明"提案-裁判分离"下适配不可能认证不安全动作？
- **Q2（裁判更新的可信晋升）**：域偏移下如何安全地让影子裁判 F̂_a 晋升为证书权威？晋升门需要什么样的事件、验证集与回滚语义，才能避免"用局部有界性掩盖系统误差"？
- **Q3（接地问答的可靠性）**：在什么查询/证据/弃答规则下，安全类答案的幻觉率可被结构性压到 0，且弃答本身不会误导操作员？
- **Q4（主动问答的保守性）**：VOI 选择的自问/他问能否只收紧可行动作集？它与 v9 的 K_eff 门控如何协同而不产生新的抖振？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 提案-裁判分离律（Proposer-Judge Separation, PJ）**
适配器只允许挂在提议器 π、问答语言化器与特征提取器上；裁判 J=(F̂, M₀, SpatialCert, 各层阈值) 在部署期内冻结。任何块 ζ 执行前仍由**未适配的** J 复核。因此适配改变的是"采样到可行块的概率"，不是"什么叫可行"。

**P14 谱预算组合律（Spectral Budget Composition, SB）**
每适配器声明低秩 (A,B,r,α) 与层谱预算 ε；全局约束 Λ=Π_l(1+ε_l/σ_l)−1 ≤ Λ_max。路由凸组合 λ_m 满足 ‖Σ_m λ_m ΔW_m‖₂ ≤ Σ_m λ_m ε_m，故门控/混合/热插拔都在同一预算内；恒等适配器（r=0 或 B=0）为中立元。

**P15 证据接地律（Evidence-Grounded Answering, EGA）**
安全/空间类问题的命题由确定性查询 E(q) 得出，VLM 只做措辞；证据覆盖不足、过期、或措辞与命题 NLI 矛盾 ⇒ 弃答。答案必须携带证据原子 ID 供审计；operator 断言不得覆盖几何事实。

**P16 只读旁观律（Read-Only Oversight, ROO）**
GVB/SIC 运行在 50Hz 控制回路之外的观察者线程；其输出只进日志、面板与澄清请求，没有任何到执行器的边。故解释层失效只造成"说不清"，不造成"做错"。

## 3. 与基线的接口（如何退化）

- BAB 失效 / 谱预算越界 / 晋升门拒绝 ⇒ 注入恒等适配器（B=0 ⇒ ΔW≡0），提议器逐位退回 v9 基座 π₀；
- 影子裁判 F̂_a 未通过晋升 ⇒ 证书权威仍是 v9 冻结 F̂，K_eff 门控不变，等价 v9；
- GVB 失效 / 超时 / 弃答 ⇒ 回退到 v9 的确定性指标面板，控制路径不变；
- SIC 失效 ⇒ 关闭主动提问，仅被动问答；
- v9 ACMD 任一环节失效 ⇒ 沿用 v9 的五级退化链；全失效 ⇒ 退回 MetricVoiceGauge v8 / v7 / v6；
- 关键：**新增两层的退化不是"退回 v9 的控制行为"，而是"根本不在控制路径上"**——移除此轮全部模块，控制输出与 v9 逐位一致（引理 92）。

## 4. 预期贡献

1. **提案-裁判分离的有界适配**框架：把 PEFT 的影响转化为可计算余量，"适配只提高命中可行块的比率，不改变可行集"；
2. **证书即奖励**的免标注适配：用冻结证书器的余量做偏好对，避免在线 PEFT 与安全目标错位或被奖励黑客；
3. **证据接地 VQA**：确定性命题 + 受约束语言化 + 弃答 + 审计，给出安全事实零幻觉的结构性论证；
4. **证据只收紧**的主动自问：VOI 选问题，答案只触发保守复检，永不放宽硬约束；
5. E571–E590 覆盖秩/预算扫描、规避全量微调安全违例、影子晋升、幻觉审计、提示注入、适配投毒、长跑漂移与端到端竞赛。

## 5. 本轮最大风险

**一句话**：为修复域偏移，最终仍要把影子裁判 F̂_a 晋升为证书权威；谱预算只约束"适配器相对基模型的输出偏差"，却不约束"基模型自身的系统误差"，一旦晋升验证集与真实部署分布存在 DA-ML 未捕获的协变量偏移，安全论证的支点就从"证书余量"悄悄移到了"晋升门的数据代表性"。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-PAVE**（Parameter-efficient Adaptation & Verified Evidence / 有界参数高效适配与证据接地问答）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「参数高效微调」×「视觉问答」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 全部原样保留。v10 新增组件分为**提议侧**（BAB/AR）与**观察侧**（GVB/SIC）：提议侧只改"采样什么"，观察侧只改"说清什么"，两者都**不进入裁判 J 的判定函数**。移除全部新组件 ⇒ 与 v9 控制输出逐位一致（引理 92）。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| ΔW_m = (α_m/r_m) B_m A_m | 低秩适配增量；B=0 时 ΔW_m≡0（恒等适配器 a^⊥） |
| ε_m = ‖ΔW_m‖₂ | 适配器谱预算占用 |
| σ_l, ε_l | 基座第 l 层谱范数、该层适配预算 |
| Λ = Π_l(1+ε_l/σ_l)−1 | 全局相对 Lipschitz 膨胀 |
| J = (F̂, M₀, SpatialCert, {τ_i}) | 冻结裁判；适配与问答都不得改写其函数体 |
| g_θ(Δ_dom, task) ↦ λ ∈ Δ^M | 适配器路由门控（单纯形凸权重） |
| F̂_a, D_val, R_s | 影子裁判、留出验证集、安全回放集 |
| e = (id, type, val, geom, t, src, conf) | 证据原子 |
| E(q), R(q), c(E) | 证据集、所需原子集、覆盖率 |
| P(q), A = (P, E, conf, abstain) | 确定性命题、接地答案 |
| VOI(q) | 提问的期望价值信息 |
| τ_ev, c_min, τ_nli | 证据新鲜度阈、覆盖阈、NLI 一致阈 |

**新增定义 540（低秩适配器 Adapter）** 对冻结基座权重 W₀∈R^{d_out×d_in}，适配器 a=(A,B,r,α)，A∈R^{r×d_in}，B∈R^{d_out×r}，r≪min(d_in,d_out)：
```
W_a = W₀ + ΔW_a,   ΔW_a = (α/r) B A,   ε_a = ‖ΔW_a‖₂ = (α/r)‖BA‖₂
```
初始化 B=0 ⇒ ΔW_a=0，记 a^⊥。在线更新后投影到谱球：若 ε_a>ε_max，则 B←B·ε_max/ε_a（A 不变）。低秩因子给出可 O(r(d_in+d_out)) 计算的保守估计 ‖ΔW_a‖₂ ≤ (α/r)‖B‖₂‖A‖₂；需要更紧时对 r×r 的 A^T B^T B A 做主特征值估计。

**新增定义 541（谱预算与全局膨胀 SpectralBudget）** 设基座第 l 层谱范数 σ_l=‖W_l‖₂，层适配预算 ε_l。全局相对 Lipschitz 膨胀
```
Λ = Π_{l=1}^{L} (1 + ε_l/σ_l) − 1,   L_a = L₀(1+Λ),   L₀ = Π_l σ_l
```
（激活取 1-Lipschitz，如 ReLU；GELU 按斜率上界折算）。部署期静态约束 Λ≤Λ_max（默认 0.15）与路由期 Σ_m λ_m ε_{m,l}≤ε_l；运行期每次更新执行定义 540 的钳制，并以 3 步幂迭代复核每层范数（≤0.2ms）。

**新增定义 542（提案-裁判分离与证书复合 ProposerJudgeSeparation）** 裁判 J 在部署期冻结。提议器 π_a 输出候选块 ζ=(a^{1:K}, Ĉ, P)。执行判据
```
Execute(ζ) ⇔ Cert_J(ζ)=valid ∧ M₀(s,a)=pass ∧ adapter_budget_ok
```
在线适配不改变 Cert_J 与 M₀ 的函数体，只改变 ζ 的采样分布。若经晋升门允许适配裁判，则证书必须采用复合误差界
```
β_a = β₀ + Λ·M_x,   M_x = sup_{x∈D_val}‖F̂₀(x)‖
```
并以定义 544 的晋升条件替换在线更新。**默认运行态：适配器不作用于 F̂。**

**新增定义 543（适配器路由 AdapterRouter）** 门控 g_θ:(Δ_dom, task)↦λ∈Δ^M（softmax 单纯形）。推理期保留分离加法，避免逐样本重合并：
```
ΔW = Σ_m λ_m ΔW_m,   ‖ΔW‖₂ ≤ Σ_m λ_m ε_m ≤ max_m ε_m ≤ Ε
```
路由异常（NaN / 越界 / 超时 / 契约超期）⇒ λ←e_⊥（恒等），严格退回 v9。路由表随契约表（定义 535）部署，参与同一 EDF 决策预算；跨机共享时按定义 544 验证。

**新增定义 544（影子裁判与晋升门 ShadowPromotion）** 影子裁判 F̂_a 在观察者线程按 5Hz 前向，与实测转移 (ŷ,y) 配对入回放池。晋升门要求在留出验证集 D_val（DA-ML 分层：近域/远域/边界域）与安全回放集 R_s（含真实间隙/力矩标签）上同时满足：
```
(i)   误差上界：P_{D_val}( ‖F̂_a−F‖ ≤ β₀ ) ≥ 1−α_p      （保形分位上界）
(ii)  单侧保守：∀(s,a)∈R_s,  ĝ_a(s,a) ≥ g_true(s,a) − β₀   （不乐观于"真实"）
(iii) 谱预算：Λ_a ≤ Λ_max
(iv)  稳定性：连续 W_prom=5 个评估窗满足 (i)(ii)
```
全部满足才在块边界**原子换入** F̂_a，保留旧指针；后续任一窗失效 ⇒ 回滚到旧裁判。注意 (ii) 允许影子比基座更乐观（当基座过度保守时），但永不允许比真实更乐观——这是"修复"与"安全"的分界。

**新增定义 545（证据原子 EvidenceAtom）** e=(id, type, val, geom, t, src, conf)，type∈{geometry, metric, event, ontology, model_pred, operator}，src∈{sensor, claim, forward_model, operator}。权威性偏序：sensor/claim 的几何事实 ≻ operator 断言 ≻ forward_model 预测。硬谓词（间隙、包含、碰撞、M₀）只接受 geometry/claim 来源；model_pred 与 operator 断言必须标注来源，且不得覆盖几何事实。geom 指向 SpatialCert 对象/位姿/距离的可复算句柄。

**新增定义 546（接地问答 GroundedQA）** 问题 q 由分型器给出所需原子集 R(q)。检索 E(q)⊆Atoms，覆盖率 c=|resolved(E∩R)|/|R|。命题：
```
P(q) = det_query(q, E)                 若 type(q)∈{spatial, safety}
P(q) = constrained_extract(q, E)       否则，且每个事实原子必须 ∈ E
A = (P, E, conf, abstain)
```
弃答规则（任一触发）：(a) c<c_min（默认 0.8）；(b) ∃e∈E_resolved 过期：now−e.t>τ_ev（几何 0.2s，其余 2s）；(c) NLI(text,P)<τ_nli（措辞与命题矛盾）；(d) spatial/safety 类命题依赖非权威来源。弃答输出仅含 E 及"可确认/不可确认"清单；受约束解码词表 = E 中实体 ∪ 模板槽，生成器不得引入词表外事实。

**新增定义 547（自问与价值信息 SelfInterrogation）** 证书模糊带
```
B_t = { ĝ_min ∈ [d_safe, d_safe+β] } ∪ { γ_grasp = unknown }
```
候选问题 Q_t 由绑定到 R(q) 的模板生成。价值信息
```
VOI(q) = E_{a∼p(·|E)}[ U(m_{t+1}) ] − U(m_t) − c(q)
```
仅当 VOI(q)>0 且每块最多一问时提问。整合规则：答案只允许 (a) 确认（不变）或 (b) 收紧（复检/减速/停）；硬谓词不接受 operator/model_pred 放宽。形式化：**A_SIC(s) ⊆ A_v9(s)**（引理 91）。

**新增定义 548（只读旁观 ReadOnlyOversight）** GVB/SIC 运行于独立观察者线程/进程，仅通过消息队列读取状态快照、写日志/UI；无 actuator API、无提议器写权限。p99 时延预算：GVB ≤800ms、SIC VOI 计算 ≤5ms，均不进入 50Hz 的 20ms 决策预算。失效由看门狗隔离；主环只读一个"解释可用"布尔位。

# IP-357 BoundedAdapterBank：有界低秩适配（只挂提议器/语言化器）
class Adapter:
    def __init__(self, A=None, B=None, rank=0, alpha=8.0):
        self.A, self.B, self.r, self.alpha = A, B, rank, alpha

IDENTITY = Adapter(rank=0)                      # ΔW ≡ 0，逐位等于 v9

class BoundedAdapterBank:
    def __init__(self, W0_layers, eps_max=0.05, Lambda_max=0.15):
        self.W0 = W0_layers                     # frozen
        self.eps_max, self.Lambda_max = eps_max, Lambda_max
        self.adapters = {}                      # name -> Adapter

    def forward(self, l, x, ad):
        y0 = self.W0[l] @ x
        if ad.r == 0 or ad.B is None:
            return y0                           # 恒等路径 = v9
        return y0 + (ad.alpha / ad.r) * (ad.B @ (ad.A @ x))

    def clamp(self, ad):
        est = (ad.alpha / ad.r) * norm2(ad.B) * norm2(ad.A)
        if est > self.eps_max:                  # 投影到谱球
            ad.B *= self.eps_max / est
        return ad

    def certified_preference(self, chunks, judge, beta_dpo=0.1):
        # 证书即奖励：正例=证书通过且余量/任务分更高的块
        # 裁判冻结 ⇒ 偏好只重排可行块，不改变可行集（引理 88）
        pos = [c for c in chunks if judge.cert_valid(c) and judge.margin(c) >= beta_dpo]
        neg = [c for c in chunks if judge.cert_valid(c) and judge.margin(c) < beta_dpo]
        self.dpo_step(pos, neg)
        for ad in self.adapters.values():
            self.clamp(ad)


# IP-359 AdapterRouter & PromotionGate
class AdapterRouter:
    def __init__(self, gate, eps, Lambda_max=0.15):
        self.gate, self.eps, self.Lambda_max = gate, eps, Lambda_max

    def route(self, delta_dom, task):
        lam = softmax(self.gate(delta_dom, task))
        if not finite(lam) or lam.sum() <= 1e-9:
            return one_hot("identity")          # 定义 543 中立元
        used = sum(l * self.eps[m] for m, l in lam.items())
        return lam if used <= self.Lambda_max else one_hot("identity")

class PromotionGate:
    def validate(self, shadow, D_val, R_s, beta0, alpha_p=0.05):
        err_ok = conformal_upper(shadow.err(D_val)) <= beta0
        conservative = all(shadow.gap(s, a) >= true_gap(s, a) - beta0
                           for s, a in R_s)            # 单侧、不乐观于真实
        budget_ok = shadow.Lambda <= self.Lambda_max
        return err_ok and conservative and budget_ok

    def promote(self, shadow, cycle_idx):
        if cycle_idx % self.W_prom != 0 or not self._window_closed():
            return False
        if self.validate(shadow, self.D_val, self.R_s, self.beta0):
            self.old = self.judge                    # 保留回滚指针
            self.judge = shadow                      # 块边界原子换入
            return True
        return False

    def rollback(self):
        self.judge, self.old = self.old, None


# IP-358 GroundedVQABridge：确定性命题 + 受约束语言化 + 弃答
class GroundedVQABridge:
    def __init__(self, vlm, nli, c_min=0.8, tau_ev={"geom": 0.2, "default": 2.0}):
        self.vlm, self.nli = vlm, nli
        self.c_min, self.tau_ev = c_min, tau_ev

    def answer(self, q, state):
        qtype = self.classify(q)
        R = self.required_atoms(q, qtype)
        E = self.retrieve(state, R)

        if qtype in ("spatial", "safety"):
            P = self.det_query(q, state.spatial_cert, state.m0, E)  # 确定性
        else:
            P = self.constrained_extract(q, E)

        if self.coverage(E, R) < self.c_min or self.stale(E):
            return Answer(None, E, conf=0.0, abstain=True,
                          note="不确定；可确认的见证据清单")
        if qtype in ("spatial", "safety") and not self.authoritative(E):
            return Answer(None, E, conf=0.0, abstain=True)

        text = self.realize(P, E, constrained=True)   # 词表 = E 实体 ∪ 模板
        if self.nli(text, P) < self.tau_nli:          # 措辞不得篡改命题
            return Answer(None, E, conf=0.0, abstain=True)
        return Answer(P, E, conf=self.calibrate(P, E), abstain=False)


# IP-360 SelfInterrogationController：VOI 提问，只收紧
class SelfInterrogation:
    def __init__(self, gvb, templates, budget_per_chunk=1):
        self.gvb, self.templates = gvb, templates
        self.budget = budget_per_chunk

    def maybe_ask(self, cert, claims):
        if not self.in_ambiguity_band(cert):
            return None
        qs = self.templates.bind(cert, claims)
        best = max(qs, key=lambda q: self.voi(q, cert))
        return best if self.voi(best, cert) > 0 else None

    def integrate(self, ans, admissible):
        # 只收紧：确认不动，任何新证据只能触发复检/减速/停
        if ans.abstain:
            return admissible
        return admissible & self.conservative_subset(ans)   # A_SIC ⊆ A_v9

## 4. 推导

**引理 87（有界适配的偏差界）** 设激活函数 1-Lipschitz，基座第 l 层谱范数 σ_l，适配预算 ε_l。则对任意输入 x，
```
‖π_a(x) − π₀(x)‖ ≤ [ Π_l(σ_l+ε_l) − Π_l σ_l ]·‖x‖ = Λ·L₀·‖x‖
```
且当全部适配器为 a^⊥ 时取等号 0（逐位一致）。证明：对复合 Lipschitz 映射逐层望远镜展开，第 l 层偏差被放大因子 Π_{j<l}(σ_j+ε_j) 与 Π_{j>l}σ_j 夹住，求和后即得；1-Lipschitz 激活不引入额外因子。∎
**推论**：适配器对提议器输出的影响可由 Λ 先验界定；因此可把"适配引起的策略偏移"折算成重规划频率与采样覆盖的预算，而无需在线观测。

**引理 88（提案-裁判分离的安全单调性）** 固定裁判 J，适配器只改变提议分布 p_a(ζ) 而不改变判定函数 Cert_J 与 M₀。故可执行块集合
```
Ξ_J = { ζ : Cert_J(ζ)=valid ∧ M₀(s,a)=pass }
```
与 v9 完全相同。对任意适配器 a，`(ζ∈Ξ_J)` 的执行概率分布改变，但**任何被执行块仍 ∈ Ξ_J**；因此
```
P_unsafe(π_a; J) = P_unsafe(π₀; J) ≤ ε_v9
```
v9 的安全证明（引理 82 及 M₀ 硬检查）逐字适用。适配只能降低 fallback 率与 K_eff 收缩频率，不能放宽安全集。∎

**引理 89（谱预算组合与恒等元）** 路由凸组合 λ∈Δ^M 下，‖ΔW‖₂=‖Σλ_mΔW_m‖₂≤Σλ_m‖ΔW_m‖₂≤Σλ_mε_m≤Ε；逐层同理。推理期保留分离加法时合并精确（无近似），故热插拔与门控切换不改变"预算内"这一性质；a^⊥（r=0 或 B=0）满足 ΔW=0，是加法幺元。因此路由/混合/失效回退构成一个带范数预算的交换幺半群，退化正确性由代数性质给出而非枚举验证。∎

**引理 90（接地问答的零安全事实幻觉）** 对 type(q)∈{spatial,safety}，非弃答答案的命题 P(q)=det_query(q,E) 完全由 E 与几何谓词决定；受约束解码词表限制在 E 实体∪模板槽内，故文本不能引入 E 之外的事实原子。非弃答还要求 c≥c_min、证据新鲜、NLI(text,P)≥τ_nli、且来源权威。于是
```
P(答案断言某个 E 之外的安全事实) = 0
```
残余错误仅为实体绑定错误与 NLI 假接受，二者由可审计的分型器/NLI 头决定，与生成模型先验无关；弃答只返回 E，按定义 545 的来源偏序为真。∎

**引理 91（自问只收紧可行动作集）** 设 A_v9(s) 为 v9 在状态 s 的可行动作集，A_SIC(s) 为整合 SIC 答案后的集合。SIC 证据分两类：(a) 确认型，不改变谓词真值 ⇒ 集合不变；(b) 收紧型，触发复检/减速/停或新增否决 ⇒ 集合取子集。operator 与 model_pred 来源的证据不得覆盖 geometry/claim 的硬谓词（定义 545/547），故不存在"用一句话放宽 M₀/SpatialCert"的路径。逐情形得 A_SIC(s)⊆A_v9(s)，任一在 SIC 下被认证的动作在 v9 下亦被认证。∎

**引理 92（只读旁观与回滚的 v9 等价）** 令全部适配器为 a^⊥、GVB/SIC 关闭、晋升门不动作。则 BAB 的 forward 退化为 y=W₀x（定义 540），路由 λ=e_⊥，裁判 J 与 v9 相同，观察者线程不向控制路径写任何消息（定义 548）。对控制周期归纳：每周期输入相同、判定函数相同、执行器输入相同 ⇒ 控制输出与 v9 逐位一致。晋升采用块边界原子换入并保留旧指针；回滚恢复旧 J 与旧 λ，下一周期即逐位回到替换前状态。∎
