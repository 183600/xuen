# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；本轮灵感：「对话管理」×「服务设计」）

> 第 68 轮把「标定」升级为在线潜变量，用自监督 + 单模型多任务把「测量可信度」纳入闭环。但它的自陈风险不是一条尾巴，而是一句判决书：**当真实故障的带宽落在标定带宽之内，COF 会把它当漂移「标好」，系统在「测量越来越准」的假象下失去检出能力。** 这不是工程细节，而是**结构性的可辨识性失败**：被动观测下，「慢漂移」与「慢故障」产生同一残差，任何更聪明的推断都分不开——信息根本不在观测里（引理 16）。
>
> 本轮两个灵感恰好指向唯一出路：
> - **对话管理**说：当信念状态存在不可消解的歧义时，智能体不应继续「内部猜」，而应**选择沟通 / 探询动作去改变信息结构**——澄清、确认、请求、探针。对话不是交互外壳，是**主动信息获取（active information acquisition）**。
> - **服务设计**说：安全不是一个内部算法，而是一项**端到端服务**：有前台触点、后台流程、失败点、关键时刻、服务恢复与再协商。用户对系统的信任是在这些触点上一寸寸建立的。
>
> 核心命题：
>
> **把 R68 的「内部独白」升级为「人机对话 + 服务旅程」：用价值信息门控的对话管理，在结构不可辨识时主动发起探针 / 澄清（把人类反馈变成外部辨识 oracle）；用服务蓝图显式设计失败点、关键时刻与服务恢复；用强制披露与解释校准筑起反「对话式煤气灯」的安全盾——DIAL-RAS（Dialogue-managed, Identifiability-aware, Active-service RAS）。**
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「**当我自己分辨不了时，我该问谁、怎么问、问完怎么恢复信任**」——可辨识性不再靠更强的内部模型，而靠被设计出来的外部交互。

## 0. 直觉与动机

**灵感 1（对话管理 → 歧义不是要更好地猜，而是要主动地问）**
直觉：监督学习默认信息已经足够；对话系统的核心恰恰是「信息不够时怎么办」——维护信念状态（POMDP）、选择澄清问题、确认理解（grounding）、修复误解（repair）、混合主动（mixed initiative）。R68 的 COF 已经在做信念更新，但它是**独白式**的：它只会更新 `c`，不会**行动去获取信息**。接上对话管理，就得到缺失的那一半：当 `b(H_cal)` 与 `b(H_sensor^trans)` 在慢子空间上不可分时，系统应选择一个**探询动作**（问操作员、请求一次规定动作、主动激励一个模态）以最大化期望信息增益，而不是在平坦后验上赌阈值。

**灵感 2（服务设计 → 安全是一项服务，不是一段代码）**
直觉：服务设计关心端到端旅程：前台（用户看见什么）、后台（系统在算什么）、支持流程（认证 / 审计 / 追溯）、失败点、关键时刻（moment of truth）。R65–R68 全部是后台优化，前台几乎空白：系统静默降级、静默置信、静默恢复，人类既不知道它「不确定」，也不知道它「为什么不确定」。服务设计把「可解释性」从模型属性变成**服务契约**：每个前台状态都要有明确的披露、解释与恢复路径。**信任不是模型的副产品，是被设计出来的服务体验。**

**灵感 3（两灵感合流 → 可辨识性只能靠「外部信息」打破，而外部信息来自交互）**
直觉：R68 的原罪是「用内部推断解决一个信息论上无解的问题」。被动观测的 Fisher 信息在混淆方向上为零，再怎么堆数据也没用（引理 16）。唯一出路是**干预**：探针改变系统状态，使人 / 环境产生对两个假设响应不同的观测（引理 17）。而「设计并执行探针」正是对话管理；「让探针及时、低负担、可信、可恢复」正是服务设计。于是两位灵感在同一个数学对象上会师：**对话 = 主动实验设计；服务 = 实验的用户体验与失败恢复。**

**灵感 4（关键转折 → 人类不再是「监督者」，而是「外部传感器」）**
直觉：过去把人当「最终审批者」，只在系统不确定时兜底。更准确的角色是：**人类是一个低带宽、有噪声、会疲劳、可被说服的外部测量通道**。这个通道恰恰携带内部传感器没有的信息（「这个声音是正常的」「这是参考面」「我刚才碰了它一下」）。把它建模成 oracle（可靠性 β、对抗率 ρ、弃答率 κ），就能用鲁棒聚合把「问人」纳入可证明的辨识框架（引理 19），同时避免把人当成无限可靠的上帝。

**灵感 5（服务设计的安全面 → 恢复、再协商与反煤气灯）**
直觉：服务设计里最重要的不是「永不出错」，而是**服务恢复**：出错后如何承认、解释、弥补、学习。更妙的是「服务恢复悖论」——一次被妥善处理的失败，可能比从未失败更能建立信任。这对 R68 的慢故障是致命对症：系统可以把「我先前把你的故障标定掉了，现在通过探针 + 你的反馈重新识别」变成一次**可信的恢复事件**，同时获得一个免费标签。但恢复也可能异化为操纵：一个能说会道的系统可以「解释掉」真实告警。因此必须加**反煤气灯硬约束**：强制披露、解释校准、沉默预算上限（定义 304）。

**灵感 6（对 R68 风险的对症下药）**
- R68「慢故障被标定吸收」→ 引理 16 证明被动不可辨识，引理 17 用探针 / 反馈主动打破；R69 不再假装内部能解决。
- R68「标定能力越强，缓变故障越隐形」→ 服务蓝图把「过标定」设为显式失败点 F1，强制定期挑战（probe audit）。
- R66 / R67「过度放宽」→ 继承 `λ_floor`；新增**揭示优先于放行**：任何未解决的决策相关歧义 → 默认保守 + 前台披露。
- 新风险「对话式煤气灯」→ AGS 三硬约束（强制披露 / 解释校准 / 沉默预算），并让审计独立于对话策略。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（DIAL-RAS 总览）** DIAL-RAS = (SDS, DMP, ACD, HFO, GRD, SBB, SRR, SLO, AGS, RAS-CALM†)。四条不变式：
(i) **继承不变式**：R68 全部实时流零学习写操作、标定红线、速率限制原样保留；DIAL 层不修改 COF 的物理防线。
(ii) **安全不阻塞（no-blocking safety）**：急停 / 降级 / 移交等安全级动作有硬时限 `T_hard`，**绝不等待人类回复**；对话只能在安全动作之后或并行进行。
(iii) **强制披露（mandatory disclosure）**：高严重度故障的披露是硬约束，任何学习到的对话策略都不得抑制。
(iv) **解释校准（calibrated explanation）**：对外解释的置信度 `≤` 内部后验置信度，且每个解释必须附带**可反证条件（falsifier）**——不许只给不可检验的安抚。

**定义 294（安全对话状态 SDS）** `b_t = P(x_t, h_t, c_t, e_t, m_t, T_t | o_{1:t}, u_{1:t}, a^{comm}_{1:t})`。其中 `x` 世界状态、`h` 故障假设、`c` 标定潜变量（继承 R68）、`e` 情绪、`m` 人类心智模型 / 意图、`T` 信任状态。因子化 `b = b_world × b_fault × b_cal × b_emo × b_human × b_trust`，但标定与故障通过慢子空间**耦合因子**连接（不可简单相乘，见定义 307）。

**定义 295（对话-控制联合动作）** `a_t = (a^{ctrl}_t, a^{comm}_t)`，`A^{comm} = {SILENT, INFORM, CONFIRM, CLARIFY, PROBE, WARN, HANDOVER, RECOVER, HOLD}`。控制与沟通对偶：每个控制动作 `a^{ctrl}` 有**沟通足迹** `comm(a^{ctrl})`（例如一次降级隐含「我不确定」的语义），服务设计要求足迹与后验一致，禁止「动作保守但话术自信」。

**定义 296（服务蓝图 SBB）** 五阶段 × 三层：
- 阶段：`Normal → Ambiguous → Probing → Resolution → Recovery → Normal`；
- 层：前台（人机触点）、后台（标定 / 归因 / 世界模型）、支持（认证 / 审计 / 追溯台账）。
前台状态由压缩映射给出：`φ_front: b_t → S_front ∈ {Normal, Ambiguous, Probing, Degraded, Handover, Recovering}`。
失败点 `F = {F1 过标定吸收慢故障, F2 静默降级, F3 误报致信任崩塌, F4 探针本身不安全, F5 恢复被感知为操纵}`；关键时刻 `MoT = {M1 首次歧义披露, M2 首次降级, M3 首次移交, M4 首次恢复}`，每个 MoT 有独立 SLO。

**定义 297（信念更新与人类响应模型）** 
`b_{t+1}(s') ∝ O(o_{t+1} | s') · Σ_s T(s' | s, a^{ctrl}_t) · b_t(s) · H(u_{t+1} | a^{comm}_t, m_t)`，
其中 `H` 是人类响应模型（含响应延迟分布 `τ_resp`、可靠性 `β`、弃答率 `κ`）。沟通动作只通过 `H` 影响 `b_human / b_fault / b_cal`，不直接篡改 `b_world`。

**定义 298（共同基础与 grounded 动作判据）** 共同基础 `CG_t = {h : b_t(h) > 1 − δ_g ∧ human_agrees(h)}`。一个高风险 / 不可逆动作 `a` 允许执行，当且仅当 `CG_t` 覆盖其**决策相关假设集** `D(a)`（即所有会改变 `a` 最优性的假设）；否则必须走 GRD（确认 / 澄清 / 修复）或降级为可逆动作。

**定义 299（VOI 门控对话触发）** 记决策后悔 `Δ(b) = max_{a} U(a;b) − U(a^{default};b)`，期望信息增益 `IG(u) = E_{o∼u}[D_KL(b' ‖ b)]`。则
`VOI(u) = λ_s · Δ(b) · IG(u) / (H(b) + ε) − c_burden(u) − c_delay·E[τ_resp]`。
仅当 `VOI(u*) > 0` 且 `Δ(b) > τ_amb` 时触发沟通；否则 `SILENT`，并把 `(D, Δ)` 作为 **open question** 写入后台（供后续探针或长时程复核）。这样避免「逢歧义必打扰」。

**定义 300（主动标定探针 ACD）** 探针 `a_p ∈ A_probe`（请人做规定动作、改变位姿、触摸参考面、遮挡 / 敲击测试、切换照明）。选择
`a_p* = argmax_{a_p} I(c, h ; r(a_p), b) / (c_burden(a_p) + c_risk(a_p) + ε)`，`s.t. a_p ∈ SafetyEnvelope`。
其线性化等价于 **D-optimal 实验设计**：在混淆子空间上最大化 `det(v^T F(a_p) v)`，其中 `F(a_p) = J_p^T (I − P_A) J_p`。

**定义 301（人类反馈 oracle 与可靠性）** 人类对二元歧义问题给标签 `y ∈ {drift, fault, unknown}`，正确率 `β`、污染（对抗 / 误报）率 `ρ`、弃答率 `κ`。用污染模型聚合：`β_eff = (1−ρ)·β + ρ/2`；仅当 `β_eff > 1/2` 时该操作员可作为 oracle 使用，否则标记为「不可用通道」并退回探针 / 保守策略。

**定义 302（服务恢复与再协商 SRR）** 当检测到误降级 / 误放行 / 解释失败，执行恢复序列 `Acknowledge → Explain → Restore → Compensate → Reflect`：承认、校准解释、恢复安全态、补偿信任、更新模型与策略。恢复受 `SLO-R` 时限。再协商：按后验不确定度与信任校准误差重新分配权威等级 `A ∈ {A0 全自主, A1 建议, A2 共决, A3 人工}`，且**只允许向更保守方向即时切换，向更自主方向需冷静期**。

**定义 303（服务等级契约 SLO）** 五条可测承诺：
- `SLO-D` 高严重度披露延迟 `≤ 200ms`；
- `SLO-C` 歧义澄清延迟 `≤ 2s` 或升级移交；
- `SLO-E` 每次降级附校准解释 `≤ 300ms`；
- `SLO-R` 恢复启动 `≤ 1s`；
- `SLO-B` 正常运行交互负担 `≤ k` 次 / 小时（`k=6`）。
违约记入 `ℰ_service`，与 R68 证书链合并。

**定义 304（反煤气灯约束 AGS）** 三条硬约束（不可被学习目标交易掉）：
1. **披露不可压制**：`b_t.high_severity ⇒ a^{comm} ∉ {SILENT, HOLD}`；
2. **解释校准**：`conf(explanation) ≤ b_t.conf + ε_e`，且解释必须给出 `falsifier`（什么观测会推翻它）；
3. **沉默预算**：`sup Σ_t 1[a^{comm}_t = SILENT ∧ Δ(b_t) > τ_amb] ≤ B_silence`（例如每小时 3 次）。
任一违反 → 触发独立审计（不由 DMP 自己裁决）。

**定义 305（信任校准 TCA）** 信任 `T_t ∈ [0,1]`，理想值 `T*_t = R_t`（系统真实可靠度）。校准误差 `e_T = |T_t − R_t|`；over-trust（`T > R`）与 under-trust（`T < R`）代价不对称：`cost = λ_over·max(0,T−R) + λ_under·max(0,R−T)`，`λ_over ≫ λ_under`（过度信任更危险）。

**定义 306（联合目标 J_DIAL）** 
`J_DIAL = E[Σ_t U_safety(a^{ctrl}_t) − λ_b·c_burden − λ_d·c_delay − λ_g·e_T − λ_m·manip_penalty]`，
`s.t.` R68 安全不变式 `∧` AGS 三硬约束 `∧` SLO。`manip_penalty` 度量「解释置信 / 动作保守度 / 内部后验」三者不一致。

**定义 307（主动可辨识性）** 残差线性化 `r = A c + B h + ε`，`c` 标定、`h` 慢故障。被动观测下对 `h` 的有效 Fisher 信息 `F_pass = B^T (I − P_A) B`，`P_A` 为到 `range(A)` 的投影。混淆子空间 `𝒩 = null(F_pass) = {u : B u ∈ range(A)}`。若 `dim 𝒩 > 0`，则沿 `𝒩` 的被动估计 **Cramér–Rao 下界为 ∞**。若存在探针 `a_p` 使 `v^T F(a_p) v ≥ ε_I > 0`（`v ∈ 𝒩`），则该对在该探针下**可辨识**；`n` 次独立探针后判别错误率 `≤ exp(−n ε_I / (8σ²))`。

**定义 308（干扰集 ℰ_DIAL）** `ℰ_DIAL = ℰ_CALM × ℰ_dial × ℰ_service`。
`ℰ_dial = {误解, 沟通延迟, 人类错误反馈, 恶意 / 欺骗人类, 策略性沉默, 确认疲劳}`；
`ℰ_service = {静默失败, 恢复失败, 信任崩塌, 探针扰动, 隐私泄露, 恢复被感知为操纵}`。

**定义 309（证书 J_DIAL）** `J_DIAL = (J_CALM, dialogue_policy_hash, sds_ver, probe_log, human_feedback_audit, slo_vec, disclosure_log, trust_cal_err, dial_ver)`。
`Valid ⇔ Valid(J_CALM) ∧ SLO 未违约 ∧ AGS 三约束成立 ∧ disclosure_log 完整 ∧ β_eff > 1/2（若使用人类 oracle）`。

**定义 310（管线）** 离线：在 R68 预训练模型上，用离线人类交互日志 + 仿真人类模型训练对话策略（保守离线 RL / 点基 Q），并用 ACD 生成探针课程。在线：感知 → R68 标定归因 → SDS → VOI 门控 → (`SILENT` | `PROBE` / `CLARIFY`) → 安全控制（继承 R68）→ SBB 失败点监控 → SRR 恢复 → 独立审计。人类反馈进 HFO 更新 `b_cal / b_fault` 与对话策略。

```python
# IP-253 SDS：因子化安全对话信念
class SafetyDialogueState:
    def __init__(self):
        self.f = {k: None for k in
                  ('world', 'fault', 'cal', 'emo', 'human', 'trust')}

    def update(self, obs, u_prev, a_comm_prev):
        self.f['world'] = self._bayes_world(obs, self.f['world'])
        self.f['cal']   = self.cof.belief()                 # 继承 R68 COF
        self.f['fault'] = self._bayes_fault(obs, self.f['cal'])
        self.f['human'] = self.human_model.update(u_prev, a_comm_prev)
        self.f['trust'] = self.trust_model.update(obs.feedback, a_comm_prev)
        return self.f

    def decision_regret(self, D):
        return max(self.value(a) for a in D) - min(self.value(a) for a in D)


# IP-254/299 DMP：VOI 门控的对话-控制联合策略
class DialogueManager:
    ACTS = ('SILENT', 'INFORM', 'CONFIRM', 'CLARIFY', 'PROBE',
            'WARN', 'HANDOVER', 'RECOVER', 'HOLD')

    def act(self, b, D, deadline):
        a_ctrl = self.control_policy(b)                     # 先算安全动作
        if deadline < T_HARD:                               # 安全不阻塞
            return a_ctrl, 'WARN', {}
        best, best_voi = 'SILENT', 0.0
        for u in self.ACTS[1:]:
            ig     = self.expected_info_gain(b, u, D)
            regret = self.decision_regret(b, D)
            voi = (LAM_S * regret * ig / (self.entropy(b) + EPS)
                   - self.burden(u) - self.delay_cost(u))
            if voi > best_voi:
                best, best_voi = u, voi
        if best_voi <= 0 or self.decision_regret(b, D) < TAU_AMB:
            return a_ctrl, 'SILENT', {'open_question': D}   # 记后台，不打扰
        return a_ctrl, best, {'target': D}


# IP-255/263 ACD：主动标定探针 = 在线实验设计
class ActiveCalibrationDialogue:
    def choose_probe(self, b, safety_envelope):
        cands = [p for p in PROBES if p.safe(safety_envelope)]
        if not cands:
            return None
        return max(cands, key=lambda p: self.fisher_gain(p, b)
                   / (self.burden(p) + self.risk(p) + EPS))

    def fisher_gain(self, p, b):        # 混淆方向 v 上的 v^T F(a_p) v
        J = self.probe_jacobian(p, b)
        v = self.confound_direction(b)
        return float(v @ (J.T @ (np.eye(len(J)) - self.P_A(b)) @ J) @ v)


# IP-256/301 HFO：人类反馈作为外部辨识 oracle（鲁棒聚合）
class HumanFeedbackOracle:
    def update(self, b, query, answer):
        beta_eff = (1 - self.rho) * self.beta + 0.5 * self.rho
        if beta_eff <= 0.5:
            return b                                    # 通道不可用，退回探针
        L = {h: beta_eff if h == answer
             else (1 - beta_eff) / (len(b) - 1) for h in b}
        return normalize({h: b[h] * L[h] for h in b})


# IP-257 GRD：共同基础 + 修复
class GroundingRepair:
    def grounded(self, b, D):
        return all(b[h] > 1 - DELTA_G or self.human_agrees(h) for h in D)

    def repair(self, b, conflict):
        return 'CONFIRM' if conflict == 'misheard' else 'CLARIFY'

# IP-261 AGS：反煤气灯安全盾（硬约束，独立于策略）
def anti_gaslight(b, a_comm, explanation, silence_budget):
    assert not (b.high_severity and a_comm in ('SILENT', 'HOLD'))
    assert explanation.conf <= b.conf + EPS_E        # 解释不许更自信
    assert explanation.falsifier is not None         # 必须可反证
    assert silence_budget.used <= B_SILENCE
    return True


# IP-264 主闭环：DIAL-RAS round（R68 后台 + 对话 / 服务层）
def DIAL_RAS_round(M, obs, human):
    # 1) R68 后台：标定 / 归因 / 前瞻——不阻塞安全路径
    z, o = M.mtm.forward(obs.pack, M.a_prev, M.scene_ctx)
    c, U, thr = M.cof.step(o['cal'], residuals(o), sigma_stat(M))
    post = M.cfa(o['rho'], o['pi'], c, U)

    # 2) SDS + 决策相关歧义
    b = M.sds.update(obs, human.last_utt, human.last_act)
    D = decision_relevant_hypotheses(post, b, M.ach)

    # 3) VOI 门控（安全硬时限优先）
    a_ctrl, a_comm, payload = M.dmp.act(b, D, deadline=M.t_hard)
    if a_comm == 'PROBE':
        a_probe = M.acd.choose_probe(b, M.safety_envelope)
        human.request(a_probe)                       # 前台触点：请求规定动作
        obs = obs.augment(wait_probe(obs, a_probe, T_PROBE))
    elif a_comm in ('CLARIFY', 'CONFIRM'):
        ans = human.ask(payload['target'])
        b = M.hfo.update(b, payload['target'], ans)  # 人类反馈 = 外部 oracle

    # 4) 安全控制（继承 R68，加「揭示优先于放行」）
    k = M.c_ras_wm.certified_prefix(
        M.ach.propose(o.x), post, M.m_as, M.alpha, o.wm)
    lam = max(M.efs.risk_scale(post), thr['lam_floor'],
              LAMBDA_REVEAL if M.sds.decision_regret(D) > TAU_AMB else 0.6)
    tau = M.pi_sigma.prefix_dispatch(o.A[:k]) * lam

    # 5) 服务蓝图 + 恢复 + 反煤气灯
    M.sbb.tick(b, M.front_state(b), a_comm)
    M.ags.check(b, a_comm, M.explainer(b, a_ctrl), M.silence_budget)
    if M.sbb.failed():
        M.authority = M.srr.on_failure(M.sbb.last_fp, b)
    M.audit.log(b, D, a_comm, payload, M.slo.snapshot())   # 独立审计
    return a_ctrl, a_comm, tau, b
```

## 3. 推导

**引理 16（被动不可辨识界）** 设残差线性化 `r = A c + B h + ε`。被动标定先验下，对 `h` 的有效 Fisher 信息为 `F_pass = B^T (I − P_A) B`，其中 `P_A = A(A^T A)^† A^T` 是到标定可达空间 `range(A)` 的投影。混淆子空间 `𝒩 = null(F_pass) = {u ≠ 0 : B u ∈ range(A)}`。若 `dim 𝒩 > 0`，则沿 `𝒩` 的任一估计量满足 `Var(û) ≥ [v^T F_pass v]^{-1} = ∞`（Cramér–Rao），且对任意 `u ∈ 𝒩`，`(c, h)` 与 `(c + A^† B u, h − u)` 产生**完全相同**的似然。故 R68 的慢故障 / 漂移判别在 `𝒩` 上是**结构性不可辨识**的，被动后验只能是先验的复制——这解释了为何 R68 的 canary 关也救不了未覆盖的慢故障。

**引理 17（主动可辨识性）** 若探针 `a_p` 使 `v^T F(a_p) v ≥ ε_I > 0`（`v ∈ 𝒩`），则混淆方向被激励出来。设每次探针观测噪声方差 `σ²`、判别统计量取对数似然比，则 `n` 次独立探针的指数族 Chernoff 界给出 `P(error) ≤ exp(−n ε_I / (8σ²))`。因此：**被动无解的问题，在主动探针下以指数速率变为可解**；且 ACD 的 D-optimal 选择正是最大化 `ε_I / (c_burden + c_risk)`，把「问什么」变成可计算的实验设计。

**引理 18（VOI 门控的近优性）** 对单步（myopic）POMDP，动作 `u*` 最大化 `E[U] − cost`；选择 `SILENT` 当且仅当所有 `u` 的 VOI `≤ 0`。故 VOI 门控在单步上**精确最优**。对 `H` 步有限视野，若用 `H` 步 rollout 估计 VOI，则相对最优策略的次优性 `≤ γ^H·U_max/(1−γ)`；`τ_amb` 门控进一步剔除「信息不影响动作」的无效询问，故不损失决策质量、只降低交互负担。

**引理 19（人类 oracle 的鲁棒聚合）** 在污染模型下，人类以概率 `1−ρ` 给正确率 `β` 的答案、以概率 `ρ` 给任意答案，则有效正确率 `β_eff = (1−ρ)β + ρ/2`。若 `β_eff > 1/2`，多数 / 鲁棒似然聚合的错误率 `≤ exp(−2n(β_eff − 1/2)²)`；若 `β_eff ≤ 1/2`，该通道不含信息，必须弃用（退回探针）。这把「人类不可靠」从定性担忧变成可检验的准入条件。

**引理 20（强制披露下的漏报界）** 设 R68 的故障检出召回为 `r_det`。AGS 第 1 条把「高严重度披露」设为硬约束（不可被策略抑制），故 `P(高严重度故障从未被披露) ≤ 1 − r_det = ε_det`，与对话策略无关。**对话层不增加漏报**；它只可能改善「识别」与「体验」，不会恶化「是否说」的门槛（这是防煤气的结构性保证）。

**定理 16（DIAL-RAS 端到端：可辨识—安全—负担三向一致）** 在 A87–A94、A95–A97（人类响应模型有界、探针在安全包络内、`β_eff > 1/2`）下：
1. **可辨识**：慢故障 / 漂移在 `N ≤ O((σ²/ε_I)·log(1/δ))` 次探针或等价人类反馈后判别错误 `≤ δ`（引理 17、19），R68 的 `α_cal` 由不可辨识常数替换为指数小项 `α_active(N)`。
2. **安全**：安全级动作走硬时限旁路，`P(τ_cmd 延迟 > T_hard) ≤ ε_block`，且 `P(高严重度未披露) ≤ ε_det`（引理 20）；端到端风险界继承 R68 定理 14。
3. **负担**：`E[交互次数] ≤ B_silence + SLO-B`（定义 303、304），VOI 门控保证只在决策相关歧义上花预算（引理 18）。
4. **可信**：`e_T` 在恢复成功后不增；若恢复被判定为操纵，触发 AGS 审计并强制降级。

**定理 17（服务恢复—信任动力学）** 设信任更新 `T_{t+1} = clip(T_t + α·(1 − e_T) − γ·1[manip], 0, 1)`，`α > 0`，`γ ≫ α`。若恢复的解释—动作一致（`conf` 校准、`falsifier` 成立），则 `T` 单调回升至 `R`（真实可靠度）；若审计判定操纵，则 `T` 以 `γ` 的速率超线性跌落并触发 `A3` 人工接管。**推论**：服务恢复悖论成立的前提是「可反证的解释」；没有 falsifier 的安抚不是恢复，是煤气灯。

## 6. 本轮最大风险

**一句话**：DIAL-RAS 把「慢故障不可辨识」的解药押在人类反馈与探针上，但人类是低带宽、会疲劳、可被说服的通道——**一个足够流畅的对话/解释策略可能把真实故障「聊」成漂移（对话式煤气灯），而服务设计的顺滑体验会让这种说服比 R68 的沉默更隐蔽、更危险**。

**次级风险与缓解**：
1. **人类反馈污染 / 对抗**：`β_eff ≤ 1/2` 即弃用该通道，退回探针 + 保守（引理 19）；
2. **安全被对话阻塞**：`T_hard` 硬旁路，安全动作永不等待人类（定义 293-ii）；
3. **探针本身不安全 / 扰民**：安全包络过滤 + 负担惩罚 + `SLO-B` 预算（定义 300、303）；
4. **策略性沉默 / 解释过度自信**：AGS 三硬约束 + 独立审计，不交给 DMP 自裁（定义 304、引理 20）；
5. **恢复被感知为操纵**：解释必须带 falsifier；审计判定操纵即 `γ` 惩罚并切 `A3`（定理 17）；
6. **服务蓝图变成「事后合理化」**：失败点日志与披露日志进 `J_DIAL` 证书链，支持离线追溯（定义 309）。

**定义 297（信念更新）** `b_{t+1} ∝ O·T·b_t·H(u_{t+1}|a^comm,m_t)`；人类响应只影响 `b_human/b_fault/b_cal`，不篡改 `b_world`。**定义 298（共同基础）** 高风险动作允许执行 ⇔ `CG_t` 覆盖 `D(a)`，否则 GRD / 降级。

**定义 299（VOI 门控）** `VOI = λ_s·Δ·IG/(H+ε) − c_burden − c_delay·E[τ_resp]`；仅 `VOI>0 ∧ Δ>τ_amb` 才沟通，否则 SILENT + open question。**定义 300（主动探针）** `a_p* = argmax I(c,h;r(a_p),b)/(c_burden+c_risk)`，线性化即 D-optimal。

**定义 301（人类 oracle）** 污染模型，`β_eff=(1−ρ)β+ρ/2`；`β_eff>1/2` 才可用。**定义 302（服务恢复）** `Acknowledge→Explain→Restore→Compensate→Reflect`；权威 `A0..A3` 只可即时向保守切换。**定义 303（SLO）** D≤200ms、C≤2s、E≤300ms、R≤1s、B≤6/h。

**定义 304（反煤气灯 AGS）** (1) `high_severity ⇒ a^comm∉{SILENT,HOLD}`；(2) `conf(expl)≤b.conf+ε_e` 且带 falsifier；(3) 沉默预算 `≤B_silence`；独立审计。**定义 305（信任校准）** `e_T=|T−R|`，`λ_over≫λ_under`。**定义 306（联合目标）** `J_DIAL` 含安全、负担、延迟、信任、操纵惩罚，受 R68 不变式 + AGS + SLO 约束。

**定义 307（主动可辨识性）** `r=Ac+Bh+ε`，`F_pass=B^T(I−P_A)B`；`dim null>0` ⇒ 被动 CRB=∞；存在探针使 `v^T F(a_p)v≥ε_I>0` ⇒ 可辨识，`n` 次后错误 `≤exp(−nε_I/(8σ²))`。**定义 308（干扰集）** `ℰ_DIAL=ℰ_CALM×ℰ_dial×ℰ_service`。**定义 309（证书）** `J_DIAL` 含策略哈希、探针日志、人类反馈审计、SLO、披露日志、信任校准误差。**定义 310（管线）** 离线对话策略（日志 + 仿真人类模型，保守离线 RL）→ 在线感知→标定归因→SDS→VOI→(SILENT|探针/澄清)→安全控制→SBB→SRR→独立审计。

```python
# IP-253 SDS：因子化安全对话信念
class SafetyDialogueState:
    def update(self, obs, u_prev, a_comm_prev):
        self.f['world'] = self._bayes_world(obs, self.f['world'])
        self.f['cal']   = self.cof.belief()                 # 继承 R68 COF
        self.f['fault'] = self._bayes_fault(obs, self.f['cal'])
        self.f['human'] = self.human_model.update(u_prev, a_comm_prev)
        self.f['trust'] = self.trust_model.update(obs.feedback, a_comm_prev)
        return self.f
    def decision_regret(self, D):
        return max(self.value(a) for a in D) - min(self.value(a) for a in D)

# IP-254/299 DMP：VOI 门控
class DialogueManager:
    ACTS = ('SILENT','INFORM','CONFIRM','CLARIFY','PROBE','WARN','HANDOVER','RECOVER','HOLD')
    def act(self, b, D, deadline):
        a_ctrl = self.control_policy(b)
        if deadline < T_HARD: return a_ctrl, 'WARN', {}     # 安全不阻塞
        best, best_voi = 'SILENT', 0.0
        for u in self.ACTS[1:]:
            voi = (LAM_S*self.decision_regret(b,D)*self.expected_info_gain(b,u,D)
                   /(self.entropy(b)+EPS) - self.burden(u) - self.delay_cost(u))
            if voi > best_voi: best, best_voi = u, voi
        if best_voi <= 0 or self.decision_regret(b,D) < TAU_AMB:
            return a_ctrl, 'SILENT', {'open_question': D}
        return a_ctrl, best, {'target': D}

# IP-255/263 ACD：主动探针 = 在线实验设计
class ActiveCalibrationDialogue:
    def choose_probe(self, b, envelope):
        cands = [p for p in PROBES if p.safe(envelope)]
        return max(cands, key=lambda p: self.fisher_gain(p,b)
                   /(self.burden(p)+self.risk(p)+EPS)) if cands else None
    def fisher_gain(self, p, b):
        J = self.probe_jacobian(p,b); v = self.confound_direction(b)
        return float(v @ (J.T @ (np.eye(len(J)) - self.P_A(b)) @ J) @ v)

# IP-256/301 HFO：人类反馈鲁棒聚合
class HumanFeedbackOracle:
    def update(self, b, query, answer):
        beta_eff = (1-self.rho)*self.beta + 0.5*self.rho
        if beta_eff <= 0.5: return b
        L = {h: beta_eff if h==answer else (1-beta_eff)/(len(b)-1) for h in b}
        return normalize({h: b[h]*L[h] for h in b})

# IP-258 SBB：服务蓝图失败点
class ServiceBlueprintMonitor:
    def tick(self, b, front_state, a_comm):
        for fp, detect in self.detectors.items():
            if detect(b, front_state, a_comm): self.emit(fp)

# IP-259 SRR：服务恢复 + 再协商
class ServiceRecovery:
    def on_failure(self, kind, b):
        self.acknowledge(kind); self.explain_calibrated(b)
        self.restore_safe_state(); self.compensate_trust(kind)
        self.reflect_update_models(kind)
        self.authority = self.renegotiate(b)   # 只可即时向保守切换
        return self.authority

# IP-261 AGS：反煤气灯硬约束
def anti_gaslight(b, a_comm, explanation, silence_budget):
    assert not (b.high_severity and a_comm in ('SILENT','HOLD'))
    assert explanation.conf <= b.conf + EPS_E
    assert explanation.falsifier is not None
    assert silence_budget.used <= B_SILENCE
    return True

# IP-264 主闭环
def DIAL_RAS_round(M, obs, human):
    z, o = M.mtm.forward(obs.pack, M.a_prev, M.scene_ctx)   # R68 后台
    c, U, thr = M.cof.step(o['cal'], residuals(o), sigma_stat(M))
    post = M.cfa(o['rho'], o['pi'], c, U)
    b = M.sds.update(obs, human.last_utt, human.last_act)
    D = decision_relevant_hypotheses(post, b, M.ach)
    a_ctrl, a_comm, payload = M.dmp.act(b, D, deadline=M.t_hard)
    if a_comm == 'PROBE':
        a_probe = M.acd.choose_probe(b, M.safety_envelope)
        human.request(a_probe); obs = obs.augment(wait_probe(obs, a_probe, T_PROBE))
    elif a_comm in ('CLARIFY','CONFIRM'):
        b = M.hfo.update(b, payload['target'], human.ask(payload['target']))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(o.x), post, M.m_as, M.alpha, o.wm)
    lam = max(M.efs.risk_scale(post), thr['lam_floor'],
              LAMBDA_REVEAL if M.sds.decision_regret(D) > TAU_AMB else 0.6)
    tau = M.pi_sigma.prefix_dispatch(o.A[:k]) * lam
    M.sbb.tick(b, M.front_state(b), a_comm)
    M.ags.check(b, a_comm, M.explainer(b, a_ctrl), M.silence_budget)
    if M.sbb.failed(): M.authority = M.srr.on_failure(M.sbb.last_fp, b)
    M.audit.log(b, D, a_comm, payload, M.slo.snapshot())
    return a_ctrl, a_comm, tau, b
```

## 4. 推导

**引理 16（被动不可辨识界）** `r=Ac+Bh+ε`，被动 `F_pass=B^T(I−P_A)B`，`𝒩=null(F_pass)`。若 `dim 𝒩>0`，沿 `𝒩` 的估计 `Var≥[v^T F_pass v]^{-1}=∞`；且 `(c,h)` 与 `(c+A^†Bu, h−u)` 似然相同 ⇒ 慢故障/漂移**结构性不可辨识**。这解释了 R68 的 canary 关为何救不了未覆盖的慢故障。

**引理 17（主动可辨识性）** 若探针使 `v^T F(a_p)v ≥ ε_I>0`，则 `n` 次独立探针后 `P(error) ≤ exp(−n ε_I/(8σ²))`。**被动无解的问题在主动探针下指数级可解**；ACD 的 D-optimal 选择即最大化可辨识信息 / 成本比。

**引理 18（VOI 门控近优性）** 单步 POMDP 下，`SILENT` 最优 ⇔ 所有 `u` 的 VOI ≤ 0，故门控**精确最优**；`H` 步 rollout 的次优性 `≤ γ^H U_max/(1−γ)`，`τ_amb` 只剔除无效询问、不损决策质量。

**引理 19（人类 oracle 鲁棒聚合）** 污染模型下 `β_eff=(1−ρ)β+ρ/2`；`β_eff>1/2` 时多数/鲁棒似然错误率 `≤ exp(−2n(β_eff−1/2)²)`；否则该通道无信息，退回探针。

**引理 20（强制披露漏报界）** 高严重度披露为硬约束，`P(从未披露) ≤ 1−r_det = ε_det`，与策略无关。**对话层不增加漏报**，只改善识别与体验。

**定理 16（端到端三向一致）** A87–A94、A95–A97 下：(1) 慢故障/漂移 `N=O((σ²/ε_I)log(1/δ))` 次探针后判别错误 ≤ δ，`α_cal` 替换为指数小 `α_active(N)`；(2) 安全动作走 `T_hard` 旁路，`P(延迟>T_hard)≤ε_block`，`P(未披露)≤ε_det`，风险界继承 R68 定理 14；(3) `E[交互]≤B_silence+SLO-B`；(4) `e_T` 恢复后不增，操纵触发 AGS 审计并降级。

**定理 17（服务恢复—信任动力学）** `T_{t+1}=clip(T_t+α(1−e_T)−γ·1[manip],0,1)`，`γ≫α`。解释可反证、动作一致 ⇒ `T` 回升至 `R`；审计判定操纵 ⇒ `T` 超线性跌落并切 `A3`。**推论：没有 falsifier 的安抚不是恢复，是煤气灯。**

## 7. 本轮最大风险

**一句话**：DIAL-RAS 把「慢故障不可辨识」的解药押在人类反馈与探针上，但人类是低带宽、会疲劳、可被说服的通道——**一个足够流畅的对话/解释策略可能把真实故障「聊」成漂移（对话式煤气灯），而服务设计的顺滑体验会让这种说服比 R68 的沉默更隐蔽、更危险**。

**次级风险与缓解**：人类反馈污染/对抗（`β_eff≤1/2` 弃用，退回探针+保守）；安全被对话阻塞（`T_hard` 硬旁路）；探针不安全/扰民（安全包络 + 负担惩罚 + `SLO-B`）；策略性沉默/解释过度自信（AGS 三硬约束 + 独立审计）；恢复被感知为操纵（falsifier 必填 + 判定即 `γ` 惩罚并切 `A3`）；服务蓝图事后合理化（失败点与披露日志进 `J_DIAL` 证书链，可离线追溯）。
