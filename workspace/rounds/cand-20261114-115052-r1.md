# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；灵感循环第 1 轮；本轮灵感：「社会影响」×「联邦学习」）

> R73 把「证据」做成了可组合的契约，但它默认了三件在现实中都不成立的事：
> - **单一主体**：J_MOD = ⊗_i J(module_i) 假设模块图有唯一所有者、唯一注册权威。真实机器人是车队、多站点、多组织——没有谁能单方面认证整张图。
> - **单一分布**：DPEM 的 conformal 覆盖率校准在 SEAL（一个站点的分布）上。换站点、换材质谱、换光照，交换性失效，覆盖率静默跌落；D_depth 只是单站点的域。
> - **单一风险承担者**：证书只说「系统风险 ≤ ε」，不说「谁承担 ε」。平均风险可以下降而最差群体风险上升——这是**风险转移**，R73 的证书对此完全失明。
>
> 本轮两个灵感正好补这三块：
> - **联邦学习** → **FedEC（联邦证据契约）+ FCCA（联邦组合代数）**：不共享原始深度帧，只共享「校准后的证据参数 + 不确定度 + 溯源 + 隐私预算」；鲁棒聚合（截尾均值/几何中位数）给出拜占庭断点，跨站点分组 conformal 给出逐层覆盖率，异质性缺口显式进契约。核心：**数据的联邦变成校准的联邦，但聚合不能偷偷造出比本地更好的确定性**。
> - **社会影响** → **SIA（社会影响记账）+ SVETO（社会否决）+ 问责缺口**：社会影响不是一个标量，而是利益相关者群体上的**风险-收益-能动性向量 SIV**；组合必须满足**社会单调性**（不得把风险静默转嫁给无同意能力的群体）；证书必须满足**代表性条件**（被审计的群体 ⊇ 承担风险的群体）。
> - **二者交叉** → **聚合洗白（aggregation laundering）**：联邦聚合让服务器只看到平均指标，从而把站点级伤害平均掉；这正是社会影响在联邦场景下最隐蔽的失效模式，也是本轮核心攻击面。
>
> 核心命题：**不再问「证据契约能否组合」，而问「当证据、数据与风险承担者分布在多个利益不一致的主体时，组合定理能否在非 IID、对抗参与者与分配正义约束下保持——并说清谁受益、谁承担风险、谁来问责？」** 把 R73 的单主体计量契约代数重构为 **FEDGAUGE-RAS**（FEDerated metrological evidence contracts with GAUGE audits and Social-impact accounting for RAS）——**联邦计量契约 × 社会影响记账**。

## 0. 直觉与动机（先直觉，后定义）

### 0.1 联邦学习：联邦的是「校准」，不是「数据」

直觉：机器人车队里，一台机器在仓库的透明塑料箱上把深度噪声摸得很准，另一台在冷库的黑色吸光垫上把同一套噪声模型摸得很准。如果各自只用自己的站点数据，模型永远在另一个站点上系统性低估不确定度。但原始深度帧不能集中：带宽、隐私、数据主权、责任边界都不允许。**能联邦的不是数据，而是「证据的校准」**——噪声模型参数、conformal 分位数、材质先验、失效签名、自标定漂移曲线；它们小、可加噪、可溯源、可版本化。这与 R73 的 EC 天然同构：EC 里本来就存着校准引用、有效域和不确定度预算，联邦只是把「一个站点内的校准」升级为「跨站点的校准协商」。

但联邦学习有三个必须写进契约的失败模式：

1. **非独立同分布（non-IID）**。站点 A 的交换性与站点 B 不同，全局 conformal 分位数在 B 上失效。覆盖率不是「一次校准、处处成立」，而是**逐层（per-stratum）成立**。若某层在联邦里没有足够校准样本，该层只能退回本地模型或显式加宽，而不能被平均掉。
2. **对抗参与者（poisoning）**。更危险的不是把均值投毒，而是**把不确定度投毒**：恶意客户端上报「我的深度很准、u 很小」，聚合后系统对最危险的模态过度自信。因此鲁棒聚合必须同时作用于**点估计与不确定度**，并且每个客户端有不可被聚合取消的 **u_floor**。这是「置信投毒（confidence poisoning）」这一新威胁面，R73 的威胁模型没有它。
3. **隐私**。保护数据主体的隐私本身是一种社会善，但 DP 噪声会抬高 u，从而抬高下游风险。隐私、精度、安全三者不是独立的，契约必须声明工作点以及**剩余风险由谁承担**。

关键不对称：**聚合点估计容易，聚合不确定度危险**。平均两个乐观的 u 会得到一个更乐观的 u，但真实误差不会因此减少。所以本轮的组合单调性要加一条联邦版本：**聚合后的不确定度不能低于「通过逐层审计的最优本地不确定度」**；若跨站点审计不通过，宁可进入「委员会模式」（保留各本地模型，只在决策层做 VETO 组合），也不生成一个假装统一的全局模型。

### 0.2 社会影响：是「分布」，不是「均值」

直觉：一个抓取策略把平均碰撞率从 3% 降到 2%，但把夜班工人所在区域的碰撞率从 4% 升到 6%，同时在办公室区域从 2% 降到 0.1%——平均值变好了，伤害却转移给了最没有议价能力的人。R73 的证书会为这个策略盖章，因为它的风险标量确实下降了。**社会影响的核心不是总量，而是分布与问责**。

形式化直觉：
- **利益相关者划分 Π = {G_1,…,G_K}**：工人、旁观者、操作员、维护者、未来用户……不同群体对同一系统的暴露不同。
- **SIV = (R_g, B_g, A_g)_{g∈Π}**：每群体的风险、收益、以及**能动性 A_g**（能否知情、申诉、退出、拒绝）。能动性是关键：同样 +1% 风险，对能动性高的群体是可协商的，对能动性低的群体是强加的。
- **社会福利函数 W_φ 是一个价值判断**，不是技术事实。φ=1（功利）会把少数群体牺牲掉，φ→∞（Rawls 最大化最差群体）不会。**契约必须显式声明 φ，并接受审计者在另一个 φ 下重算**；把 φ 藏起来就是「社会洗白」的第一步。
- **风险转移 RT**：平均福利改善但存在群体风险上升。**社会单调性**要求：任何群体的风险上升要么在该群体预注册的容差 δ_g 内，要么有该群体的显式同意，否则触发 **SVETO**（社会否决，非补偿）。
- **问责缺口**：谁被审计、谁承担风险。若审计样本只覆盖办公室场景而伤害发生在夜班场景，证书在形式上完美、在实质上失明。**代表性条件**要求：每一个承担风险的群体，都必须有被授权代表它的审计客户端或被直接纳入的审计集。

联邦让这一切更糟，也更可测：数据所有者（站点）不等于风险承担者（该站点的工人/路人）；服务器只看到聚合指标，站点级伤害被平均掉。这就是 **aggregation laundering**：**聚合是最优雅的风险转移装置**。但它也给了修复的抓手：如果每个客户端必须声明它代表哪些群体（rep_map），聚合就必须是「代表加权的」，而不是「样本加权的」。

### 0.3 合成：四维证书

直觉：R73 的 J_MOD 是一个「统计有效性」证书。联邦 + 社会后，它必须裂成四维：

- **J_stat（统计有效）**：鲁棒聚合断点、逐层 conformal 覆盖率、置信投毒防线；
- **J_dom（域有效）**：联邦后的有效域是各站点域的交；交集为空就要委员会模式，不能假装有全局模型；
- **J_soc（社会有效）**：社会单调性、SVETO、代表性条件、问责缺口为空；
- **J_priv（隐私有效）**：DP 预算闭合、目的限制（purpose limitation）、同意谓词。

四维中任何一维失败，证书只能降级为「条件证书」，且必须在部署界面上显式标注缺失维度与受影响群体。**安全不是唯一的社会价值，隐私与分配正义也不能被安全预算一票补偿**——这是本轮对 R73「安全侧只增不减」的修正：安全、隐私、分配是三轴，不可互相补偿。

## 1. 形式化定义（增量：定义 383–396）

**定义 383（联邦证据契约 FedEC）** FedEC = (EC, D_pop, π_agg, u_priv, SIV, consent, rep_map, contrib)：
- EC：R73 证据契约（类型/预算/通道/域/否决/追溯/时序/密封引用）；
- D_pop：站点/人群分布域（材质谱、光照、场景、人群构成），是站点级 D 的总体版本；
- π_agg：可联邦的校准载荷（噪声模型参数、conformal 分位数、材质先验、失效签名、自标定曲线）+ 本地不确定度；
- u_priv = (ε, δ)：该客户端允许消耗的隐私预算；
- SIV：本地社会影响向量（定义 387）；
- consent：目的限制与同意谓词——哪些聚合用途被授权、哪些被禁止；
- rep_map：本客户端被授权代表哪些利益相关者群体（**参与 ≠ 代表**）；
- contrib：贡献证明（用于账簿与搭便车检测，定义 392）。

**定义 384（联邦图 FG）** FG = (C, A, T, Π)：客户端集 C（各带 FedEC）、聚合拓扑 A ∈ {star, hierarchical, peer}、信任关系 T（谁可信、谁需要交叉验证）、利益相关者划分 Π。联邦图的每条边是一个**联邦契约实例**，不是数据管道。

**定义 385（鲁棒聚合 Agg_ρ）** 给定本地更新 {Δ_i}、权重 {w_i}、容恶比例 ρ：Agg_ρ 取坐标截尾均值（trimmed mean，截去 ρn 两端）或几何中位数，并对每个客户端施加范数裁剪 Clip_C 与 **u_floor**。输出 (Δ_agg, u_agg, h_gap, excluded)：
- **断点**：f ≤ ρn 个拜占庭客户端时，Δ_agg 的偏差有界（引理 39）；
- **u_agg ≥ max_i u_floor^i**：客户端不能通过「自称很准」把系统不确定度压到物理下限以下；
- **h_gap**：聚合不确定度相对最优本地层的**异质性缺口**，显式入账（引理 38）。

**定义 386（跨站点分组 conformal 审计）** 校准集按层 s ∈ S（站点 × 材质 × 距离段）划分；对每层用 Mondrian conformal 得 q_s，保证 **P(Y ∈ C_s | s) ≥ 1−α**（层内交换性）。跨站点留出（leave-site-out）检验：若某站点覆盖率低于预注册下界，则该站点**不得使用全局分位数**，只能本地校准或加宽。**禁止跨层池化后宣称全局覆盖率**。

**定义 387（社会影响向量与利益相关者划分）** Π = {G_1,…,G_K} 为可审计的群体划分；对部署 d 与群体 g：
- R_{d,g} = E[ℓ | d,g]（群体风险），B_{d,g} = E[benefit | d,g]，A_{d,g} ∈ [0,1]（能动性：知情/申诉/退出）；
- **SIV_d = (R_{d,g}, B_{d,g}, A_{d,g})_{g∈Π}**；
- **社会福利函数 W_φ** 由部署方在契约中声明，审计方在 Φ = {φ_1,…,φ_m} 上**重算**（防价值隐藏）；
- **社会支配** SIV ≽ SIV′ ⇔ ∀g: R_g ≤ R′_g ∧ B_g ≥ B′_g。

**定义 388（社会算子与风险转移）** 在 CCA 的 SER/PAR/VETO 之外新增：
- **COMP-SVETO（社会否决）**：若 ∃g：R_g > τ_g ∧ A_g ≥ a_min（该群体有能力否决），则部署/组合被拒，**非补偿**；
- **社会单调性**：一个组合变化被允许 ⇔ ∀g：R′_g ≤ R_g + δ_g（δ_g 预注册），或存在该群体的显式同意 consent_g；
- **风险转移指示** RT = 1[W_φ 改善] ∧ 1[∃g：R_g 上升]；契约要求 RT=1 时必须进入协商或 SVETO，不得静默通过。

**定义 389（问责缺口与代表性条件）** 对每个承担风险的群体 g，定义 rep(g) = 被授权代表/审计 g 的客户端集合。**问责缺口** A_gap = {g ∈ Π : rep(g)=∅ 或没有任何审计客户端覆盖 g}。**代表性条件**：A_gap = ∅，且每个 g 有非空的校准/审计集。若 A_gap ≠ ∅，证书只能标记为「有条件」并列出未覆盖群体——**未覆盖≠无风险**。

**定义 390（隐私契约与隐私-效用-风险三角）** 联邦契约声明 DP 机制（本地/中心/分布式）、总预算 (ε_tot, δ_tot)、目的限制谓词。聚合消耗按 DP 组合定理累计。**三角**：在固定数据与模型表达力下，不能同时最大化隐私（ε→0）、最小化 u、最小化群体风险；契约必须声明工作点与**剩余风险的承担者**。隐私预算是一种社会资源，不是一个可无限透支的技术参数。

**定义 391（联邦组合代数 FCCA）** 在 SER/PAR/VETO 上新增 **FED** 与 **SVETO**：
- **FED（联邦聚合）**：D_pop,out = ∩_i D_pop^i；若为空 ⇒ **委员会模式**（保留本地模型，只在决策层 VETO 组合），不生成全局模型。u_out ≥ Agg_ρ 的界，且 u_out ≥ 最优本地层 u（除非逐层跨站点审计全通过）；SIV_out 按**部署质量**（不是样本量）加权合并；ε_out = DP 组合；贡献账簿合并。
- **SVETO**：validity = ∧_g (R_g ≤ τ_g ∨ consent_g)；任一群体否决 ⇒ 整体否决。
- **组合单调性（联邦版）**：不存在一条路径，在聚合后同时（i）降低 u、（ii）未被逐层审计覆盖、（iii）未被 u_floor 约束——即「联邦不产生认知免费午餐」。

**定义 392（贡献账簿与搭便车）** L = {(i, Δ_i, contrib_i, verify_i)}；contrib_i 用 Shapley/影响函数估计并交叉验证。搭便车 = 消费聚合收益但 contrib_i 低于阈值。账簿同时用于**收益分配**（社会影响的 B 侧）与**责任追溯**（谁的数据/校准导致了伤害）。

**定义 393（联邦四维证书 FedJ）** FedJ = (J_MOD^local, J_stat, J_dom, J_soc, J_priv)：
- J_stat：鲁棒断点、逐层覆盖率、置信投毒防线；
- J_dom：域交非空或委员会模式被显式声明；
- J_soc：社会单调性 ∧ SVETO ∧ A_gap=∅ ∧ 多 φ 重算一致；
- J_priv：DP 预算闭合 ∧ 目的限制满足。
**Valid(FedJ) ⇒ 总体风险与逐群体风险有界**（定理 30），但仅当 A114–A117 成立。

**定义 394（联邦级降级）** 客户端失效 ⇒ 剔除并重加权（quorum 保持）；quorum 丢失 ⇒ **本地模式**（各站点用自身 EC）；聚合器被攻陷 ⇒ 最小信任聚合 / 多聚合器交叉校验；检出投毒 ⇒ 剔除 + 其历史贡献进入审计；社会否决 ⇒ **阻止部署**（不是降级，因为降级会把伤害留给最弱势群体）。

**定义 395（社会影响基准 SBench）** SB1（非 IID 联邦深度校准：多站点 × 材质谱 × 距离段）、SB2（对抗与搭便车：投毒/置信投毒/女巫/贡献伪造）、SB3（社会影响：群体风险-收益-能动性 × 多福利函数 × 代表性与问责缺口）。预注册脚本、固定种子、密封保持集 SEAL-FED，各 ≤4 小时单卡/单机可复现。

**定义 396（严格退化）** 当 |C|=1、Π={all}、ε=∞、无 FED 算子时，FedEC→EC、FCCA→CCA、FedJ→J_MOD，FEDGAUGE 逐指令退化为 R73；再退化到 R72/R71/R68。

def federated_calibrate(clients, agg_rule, rho, alpha):
    updates, floors = [], []
    for c in clients:
        assert c.consent.allows('calibration')           # 目的限制
        d = c.agg_payload.local_update()
        updates.append(clip_norm(d, C))
        floors.append(c.agg_payload.u_floor)              # 不可被聚合取消的下限
    agg, h_gap, excluded = agg_rule(updates, rho)         # 截尾均值/几何中位数
    u_agg = max(agg.u, max(floors), agg.u + h_gap)
    # 逐层 conformal：禁止跨层池化
    per_stratum = {s: mondrian_quantile(clients, s, alpha) for s in strata(clients)}
    for s in per_stratum:
        if not leave_site_out_covers(clients, s, alpha):
            per_stratum[s] = LOCAL_ONLY                      # 该层退回本地
    return agg, u_agg, per_stratum, excluded

def social_audit(siv_list, weights, Pi, phi_set, delta, tau):

    report = {}
    for phi in phi_set:                                       # 防价值隐藏：多 phi 重算
        report[phi] = welfare(SIV, phi)

    for g in Pi:
        if SIV.R[g] > tau[g] and SIV.A[g] >= A_MIN:
            return VETO(g, SIV)                               # 社会否决，非补偿
        if SIV.R[g] > SIV.prev_R[g] + delta[g] and not SIV.consent[g]:
            return VETO(g, SIV)                               # 静默风险转移
    a_gap = {g for g in Pi if not SIV.represented(g)}         # 问责缺口
    return SocialCertificate(SIV, report, risk_transfer, a_gap)

# IP-305 FCCA：联邦组合代数（SER/PAR/VETO + FED/SVETO）
def federated_compose(a, b, op, ctx):
    if op in ('SER', 'PAR', 'VETO'):
        return compose(a, b, op, ctx.audit)                   # 继承 R73 CCA
    if op == 'FED':
        d = a.ec.d_pop & b.ec.d_pop
        if d.is_empty():
            return CommitteeMode(a, b)                        # 委员会：不造全局模型
        u = robust_bound(a, b, ctx.rho, ctx.h_gap)
        if not ctx.cross_site_audit.covered(a, b):
            u = max(u, a.u, b.u)                              # 无审计 → 不缩窄
        return FedEv(u=u, D=d, siv=merge_siv([a.siv, b.siv]),
                     priv=dp_compose(a.priv, b.priv),
                     contrib=merge_ledger(a.contrib, b.contrib))
    if op == 'SVETO':
        if social_audit([a.siv, b.siv], ctx).vetoed:
            return Ev(valid=False, veto={'SOCIAL'})
        return FedEv(valid=True, siv=merge_siv([a.siv, b.siv]))

# IP-306 FEDGAUGE 主闭环（单站点内沿用 R73 三域；联邦层异步）
def FEDGAUGE_round(node, fleet, obs, depth_img):

    # === 联邦层（低频：分钟级/事件触发，非实时控制路径）===

        node.outbox.push(payload)                             # 只发校准载荷，不发原始帧

            node.publish(agg, u_agg, per_s, soc, excluded, J=FedJ(...))  # IP-305

## 3. 推导

**引理 38（异质性缺口与逐层覆盖率）** 设站点分布 P_i 与校准池 P_cal 的总变差距离为 d_i，则池化 conformal 在站点 i 上的覆盖率损失不超过 d_i（至多常数因子）。⇒ 全局分位数不能直接用于站点 i；必须逐层校准或把 u 加宽至少 q_{1−α+d_i}。系：**非 IID 下「联邦提升覆盖率」是一个需要逐层审计才能兑现的主张，不是自动收益。**

**引理 39（鲁棒聚合与置信投毒）** 截尾均值在 f ≤ ρn 个拜占庭客户端下，点估计偏差有界；但若不对 u 施加 u_floor，恶意客户端可把 u_agg 压到任意小（置信投毒）。⇒ 鲁棒聚合必须作用于 (Δ, u) 对，且 u_agg ≥ max_i u_floor^i。系：**联邦的安全界不能由客户端自报的不确定度单独决定。**

**引理 40（群体条件覆盖）** 若校准与测试在群体 g 内可交换，则 Mondrian conformal 给 P(R_g 的区间覆盖) ≥ 1−α；跨群体池化在分布漂移下无此保证。⇒ 社会影响的群体风险界必须建立在**群体条件**的校准上，而不是全局校准。

**引理 41（社会单调性）** 若 SVETO 被遵守且 δ_g 预注册，则任何组合路径都不能在未获同意的情况下把群体风险转嫁出去。证明按算子分情形：SER/PAR/FED 的风险单调性 + SVETO 的非补偿性。系：**「平均变好」不再足以让一个组合通过。**

**引理 42（问责与代表性）** 若代表性条件与逐层审计覆盖成立，则每个群体风险估计都有具名审计者；否则缺口可被显式界定并随证书发布。⇒ **未覆盖的群体必须被标记，而不能被默认视为安全。**

**定理 30（联邦组合可靠性）** 在 A114（站点异质性有界：d_i ≤ d_max）、A115（拜占庭比例 f ≤ ρn）、A116（代表性条件与逐层审计覆盖成立）、A117（DP 机制与组合记账正确）下：Valid(FedJ) ⇒ 对每个部署 d 与群体 g，R_{d,g} ≤ ε_g 以概率 ≥ 1−α 成立，且隐私保证 (ε_tot, δ_tot) 成立。**证明重量落在 A114（真实分布漂移是否在 d_max 内）与 A116（谁被代表）上。**

**定理 31（严格退化）** |C|=1、Π={all}、ε=∞、无 FED 时，FedEC→EC、FCCA→CCA、FedJ→J_MOD；由引理 35，FEDGAUGE 逐指令退化为 R73，再退化为 R72/R71/R68。**安全侧不变，新增维度只在联邦/社会语义下激活。**

**定理 32（同意下无洗白）** 若代表性条件、逐层审计与 SVETO 均成立，则不存在一条组合路径在严格改善 W_φ 的同时使某群体 R_g 上升超过 δ_g 且未触发 SVETO。证明：由引理 40/41，任何此类上升要么被逐层审计检出、要么被 SVETO 阻断。**一旦群体划分本身被操纵或群体标签缺失，本定理的前提即失效——这是本方案最大的社会风险。**

## 6. 本轮最大风险

**一句话**：FEDGAUGE 把社会影响的证明交给了「群体划分 Π、福利函数 φ、代表性映射 rep_map」这三个**由部署方填写**的字段——如果群体可以被拆分（把受害群体拆成若干都低于阈值的小组）、φ 可以被选成功利主义以隐藏少数群体、rep_map 可以自称代表却未经该群体授权，那么系统会产出一份四维齐全、DP 闭合、逐层覆盖、SVETO 无触发的「社会合规证书」，而证书所证明的只是**部署方自己定义的合规**：聚合洗白没有被消除，只是被形式化进了契约——审计日志会证明每一步都合法，却无法证明没有人被静默地牺牲。

次级风险与缓解：
1. **非 IID 超出 d_max**（分布漂移假设失效）→ 逐层留出检验 + 超界即本地回退 + 把 d_i 作为一等审计量发布。
2. **置信投毒/女巫**（u 被压到物理下限以下）→ u_floor 不可聚合取消 + 设备指纹/信任拓扑 + 交叉聚合器校验。
3. **群体划分操纵（gerrymandering）** → 群体划分需外部伦理/工会/监管多方签署；审计方在多个备选 Π 上重算；拆分检测（子群体合并风险）。
4. **φ 选择偏置（价值隐藏）** → 契约强制声明 φ + 审计方在 Φ 上重算 + 结论不一致即降级为条件证书。
5. **代表性与同意造假** → rep_map 需可验证授权（不是自我声明）；未授权即计入 A_gap；A_gap 非空不得发布「社会有效」。
6. **DP 预算长期泄漏** → 总预算硬上限 + 目的限制 + 预算耗尽即冻结联邦更新（回退本地）。
7. **贡献账簿被操纵（收益分配不公）** → Shapley 交叉验证 + 不可篡改日志 + 随机抽检。
8. **社会影响测量效度**（SIV 本身是代理）→ 预注册构念 + 与真实利益相关者共同设计 + 只声称「所测维度」而非「全部社会影响」。
9. **联邦层滞后于实时风险** → 联邦层只改「下一轮校准」，紧急风险仍由本地 1kHz 链路与 SVETO 硬阻断处理。
10. **基准过拟合** → 密封保持集 SEAL-FED + 预注册 + 三方复现（E407）。

**本方案当前的最大风险**：社会影响的三个定义权（划分、福利函数、代表权）仍握在部署方手里——若不引入**外部的、可对抗部署方的**审计与授权，联邦计量契约只能保证「形式合规」，挡不住把伤害精确地平均进聚合值里的社会洗白。

| `SB1/SB2/SB3` | SBench：非 IID 校准 / 对抗与搭便车 / 社会影响与代表性 |
| `CommitteeMode` | 域交为空时的委员会模式：保留本地模型，仅决策层 VETO 组合 |

## 2. 形式化定义（要点版）

**定义 383（FedEC）** FedEC 在 EC 上增加：D_pop（站点/人群分布）、π_agg（噪声参数/conformal 分位数/材质先验/失效签名/自标定曲线）、u_priv、SIV、consent（目的限制）、rep_map（**参与≠代表**）、contrib。原始数据不离开客户端。

**定义 384（联邦图 FG）** FG=(C,A,T,Π)；每条边是联邦契约实例，不是数据管道。聚合拓扑可为 star/hierarchical/peer。

**定义 385（鲁棒聚合 Agg_ρ）** 坐标截尾均值或几何中位数 + 范数裁剪 Clip_C + u_floor。输出 (Δ_agg, u_agg, h_gap, excluded)；f≤ρn 拜占庭时偏差有界；u_agg ≥ max_i u_floor^i；u_agg 含 h_gap。

**定义 386（逐层 conformal）** 层 s = 站点×材质×距离段；Mondrian conformal 得 q_s，层内覆盖 ≥1−α；leave-site-out 检验失败则该层退回本地。**禁止跨层池化后宣称全局覆盖。**

**定义 387（SIV）** SIV=(R_g,B_g,A_g)_{g∈Π}；W_φ 由部署方声明，审计方在 Φ 上重算；社会支配逐群体定义。

**定义 388（社会算子）** SVETO：∃g 使 R_g>τ_g ∧ A_g≥a_min ⇒ 拒绝（非补偿）。社会单调性：∀g，R′_g≤R_g+δ_g 或 consent_g；RT=1 必须协商或 SVETO。**手段（SER/PAR/FED）不得让目的（群体风险）静默恶化。**

**定义 389（代表性条件）** A_gap={g: rep(g)=∅ 或无审计覆盖}；要求 A_gap=∅。缺口非空时证书仅「有条件」，且必须列出未覆盖群体——**未覆盖≠无风险**。

**定义 390（隐私契约）** 声明 DP 机制与 (ε_tot,δ_tot)；DP 组合累计；隐私-效用-风险三角不可同时最优；契约声明工作点与剩余风险承担者。

**定义 391（FCCA）** FED：D_pop,out=∩_i D_pop^i，空则 CommitteeMode；u_out≥Agg_ρ 界且不得低于最优本地层（除非逐层审计全通过）；SIV 按部署质量加权；ε 组合；贡献账簿合并。SVETO：非补偿否决。联邦单调性：不存在同时降 u、无审计覆盖、无 u_floor 的路径。

**定义 392（贡献账簿）** contrib 用 Shapley/影响函数估计并交叉验证；搭便车=消费收益而 contrib 低于阈值；账簿用于收益分配与伤害归因。

**定义 393（FedJ）** FedJ=(J_MOD^local,J_stat,J_dom,J_soc,J_priv)。Valid ⇒ 总体与逐群体风险有界且隐私保证（定理 30）。

**定义 394（联邦降级）** 掉线→剔除重加权；quorum 丢失→本地模式；聚合器被攻陷→多聚合器交叉校验；投毒→剔除+历史审计；社会否决→阻止部署（不可降级，否则伤害留给最弱势群体）。

**定义 395（SBench）** SB1 非 IID 校准；SB2 投毒/置信投毒/女巫/搭便车；SB3 社会影响×多 φ×代表性。预注册+固定种子+SEAL-FED，各 ≤4h 单机可复现。

**定义 396（严格退化）** |C|=1、Π={all}、ε=∞、无 FED ⇒ FedEC→EC、FCCA→CCA、FedJ→J_MOD，逐指令退化为 R73/R72/R71/R68。

## 3. 关键算法伪代码

```python
# IP-302 FedEC
@dataclass(frozen=True)
class FedEvidenceContract:
    ec: EvidenceContract                    # R73 单站点契约
    d_pop: PopulationDomain                 # 站点人群/材质/光照分布
    agg_payload: CalibrationPayload         # 可联邦校准载荷（非原始数据）
    u_priv: Tuple[float, float]             # (epsilon, delta)
    siv: SocialImpactVector                 # (R_g, B_g, A_g)_{g in Pi}
    consent: ConsentPredicate               # 目的限制/同意
    rep_map: FrozenSet[StakeholderGroup]    # 被授权代表的群体（参与≠代表）
    contrib: ContributionProof

# IP-303 鲁棒联邦校准（断点 + 置信投毒防线 + 逐层 conformal）
def federated_calibrate(clients, agg_rule, rho, alpha):
    updates, floors = [], []
    for c in clients:
        assert c.consent.allows('calibration')           # 目的限制
        d = clip_norm(c.agg_payload.local_update(), C)
        updates.append(d); floors.append(c.agg_payload.u_floor)
    agg, h_gap, excluded = agg_rule(updates, rho)         # 截尾均值/几何中位数
    u_agg = max(agg.u, max(floors), agg.u + h_gap)        # 不可被聚合取消的下限
    per_stratum = {}
    for s in strata(clients):
        per_stratum[s] = (mondrian_quantile(clients, s, alpha)
                          if leave_site_out_covers(clients, s, alpha)
                          else LOCAL_ONLY)                # 该层退回本地
    return agg, u_agg, per_stratum, excluded

# IP-304 社会影响记账（多福利函数重算 + SVETO + 问责缺口）
def social_audit(siv_list, weights, Pi, phi_set, delta, tau):
    SIV = merge_siv(siv_list, weights)                    # 按部署质量加权，非样本量
    report = {phi: welfare(SIV, phi) for phi in phi_set}  # 防价值隐藏
    rt = any(SIV.R[g] > SIV.prev_R[g] for g in Pi)
    for g in Pi:
        if SIV.R[g] > tau[g] and SIV.A[g] >= A_MIN:
            return VETO(g, SIV)                           # 社会否决
        if SIV.R[g] > SIV.prev_R[g] + delta[g] and not SIV.consent[g]:
            return VETO(g, SIV)                           # 静默风险转移
    a_gap = {g for g in Pi if not SIV.represented(g)}     # 问责缺口
    return SocialCertificate(SIV, report, rt, a_gap)

# IP-305 FCCA（继承 R73 CCA + FED/SVETO）
def federated_compose(a, b, op, ctx):
    if op in ('SER', 'PAR', 'VETO'):
        return compose(a, b, op, ctx.audit)               # R73 CCA
    if op == 'FED':
        d = a.ec.d_pop & b.ec.d_pop
        if d.is_empty():
            return CommitteeMode(a, b)                    # 不造全局模型
        u = robust_bound(a, b, ctx.rho, ctx.h_gap)
        if not ctx.cross_site_audit.covered(a, b):
            u = max(u, a.u, b.u)                          # 无审计→不缩窄
        return FedEv(u=u, D=d, siv=merge_siv([a.siv, b.siv]),
                     priv=dp_compose(a.priv, b.priv),
                     contrib=merge_ledger(a.contrib, b.contrib))
    if op == 'SVETO':
        soc = social_audit([a.siv, b.siv], ctx)
        return Ev(valid=not soc.vetoed, veto={'SOCIAL'} if soc.vetoed else set())

# IP-306/309 FEDGAUGE 主闭环（本地三域不变；联邦层异步）
def FEDGAUGE_round(node, obs, depth_img):
    local_ev = MODGAUGE_round(node.M, obs, depth_img)     # R73 三域，硬实时不受影响
    if node.clock.due_federation():                       # 分钟级/事件触发，非控制路径
        node.outbox.push(node.fedec.agg_payload.local_update(local_ev))
        if node.is_aggregator:
            agg, u_agg, per_s, excluded = federated_calibrate(
                node.inbox.drain(), node.agg_rule, node.rho, node.alpha)
            soc = social_audit([c.siv for c in node.clients], node.weights,
                               node.Pi, node.phi_set, node.delta, node.tau)
            if soc.vetoed:
                node.deploy_gate.block(soc.veto_group)    # 社会否决→阻止部署
            node.publish(agg, u_agg, per_s, soc, excluded)
    node.apply_remote_calibration(node.inbox.latest(), local_only=per_s)  # 逐层落地
    return local_ev, node.cert.write(FedJ(...))           # 定义 393
```

## 4. 推导

**引理 38（异质性缺口）** 站点分布与校准池总变差距离 d_i ⇒ 池化 conformal 在站点 i 的覆盖率损失 ≤ d_i。全局分位数不可直接用于站点；必须逐层校准或加宽 ≥ q_{1−α+d_i}。系：**非 IID 下联邦提升覆盖率需逐层审计兑现，不是自动收益。**

**引理 39（置信投毒）** 截尾均值在 f≤ρn 时点估计偏差有界；但无 u_floor 时恶意端可把 u_agg 压到任意小。故鲁棒聚合必须作用于 (Δ,u) 对，且 u_agg≥max_i u_floor^i。系：**安全界不能由客户端自报不确定度单独决定。**

**引理 40（群体条件覆盖）** 群体内可交换 ⇒ Mondrian conformal 给 P(R_g 覆盖)≥1−α；跨群体池化无此保证。⇒ 社会影响的群体风险界必须群体条件校准。

**引理 41（社会单调性）** SVETO 遵守 + δ_g 预注册 ⇒ 任何组合路径都不能在未获同意时转嫁群体风险。证明按 SER/PAR/FED 分情形。系：**「平均变好」不再足以让组合通过。**

**引理 42（问责与代表性）** 代表性条件 + 逐层审计 ⇒ 每个群体风险均有具名审计者；否则缺口显式界定并随证书发布。

**定理 30（联邦组合可靠性）** 在 A114（d_i≤d_max）、A115（f≤ρn）、A116（代表性+逐层覆盖）、A117（DP 记账正确）下：Valid(FedJ) ⇒ ∀部署 d、群体 g，R_{d,g}≤ε_g 以概率≥1−α 成立，且 (ε_tot,δ_tot) 隐私成立。证明重量在 A114 与 A116。

**定理 31（严格退化）** |C|=1、Π={all}、ε=∞、无 FED ⇒ 逐指令退化为 R73，再退化为 R72/R71/R68；安全侧不变。

**定理 32（同意下无洗白）** 代表性条件 + 逐层审计 + SVETO ⇒ 不存在路径在严格改善 W_φ 的同时使某群体 R_g 上升超 δ_g 且未触发 SVETO。**前提：群体划分与标签可信；一旦被操纵，定理失效——本轮最大社会风险。**

## 7. 本轮最大风险

**一句话**：社会影响的三个定义权——群体划分 Π、福利函数 φ、代表权 rep_map——仍由部署方掌握；若 Π 可被拆分、φ 可选成功利主义、rep_map 可自我声明，系统就会产出四维齐全、DP 闭合、逐层覆盖、SVETO 无触发的「社会合规证书」，而它证明的只是**部署方自己定义的合规**：聚合洗白没有被消除，只是被形式化进了契约，审计日志会证明每一步合法，却无法证明没有人被静默牺牲。

次级风险与缓解：
1. **非 IID 超出 d_max** → 逐层留出 + 超界本地回退 + d_i 作为一等审计量发布。
2. **置信投毒/女巫** → u_floor 不可聚合取消 + 信任拓扑/设备指纹 + 多聚合器交叉校验。
3. **群体划分操纵（gerrymandering）** → Π 需外部伦理/工会/监管多方签署；审计方在多个备选 Π 上重算；子群体合并风险检测。
4. **φ 选择偏置** → 强制声明 φ + 在 Φ 上重算 + 不一致即降级为条件证书。
5. **代表性与同意造假** → rep_map 需可验证授权，非自我声明；未授权计入 A_gap；A_gap 非空不得发布「社会有效」。
6. **DP 预算长期泄漏** → 总预算硬上限 + 目的限制 + 耗尽即冻结联邦更新（回退本地）。
7. **贡献账簿操纵** → Shapley 交叉验证 + 不可篡改日志 + 随机抽检。
8. **SIV 构念效度** → 预注册构念 + 与真实利益相关者共同设计 + 只声称所测维度。
9. **联邦层滞后** → 联邦层只改下一轮校准；紧急风险由本地 1kHz 与 SVETO 处理。
10. **基准过拟合** → SEAL-FED + 预注册 + 三方复现（E407）。

**最大风险（一句话）**：只要群体划分、福利函数与代表权仍由部署方单方面定义，FEDGAUGE 就只能保证「形式合规」，挡不住把伤害精确地平均进聚合值里的社会洗白——**联邦计量契约需要外部的、可对抗部署方的审计与授权，否则它会成为最精致的合规剧场。**
