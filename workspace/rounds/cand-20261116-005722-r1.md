# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「迁移学习」×「关节驱动」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（v9；定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**执行器可行、迁移误差可证、快慢通道正交**。v9 的块证书把安全论证放在「几何间隙 + 前向模型误差 β」上，却默认了两件没有被证明的事：(i) 机器人真的能在剩余距离内产生证书所假设的减速度；(ii) β 在域偏移发生的那个瞬间仍然成立。本轮的「关节驱动」补 (i)，「迁移学习」补 (ii)，并用**快通道只收缩、不扩张**的非对称合成把两者接起来；任何新环节失效都必须退回 v9 的几何证书，而不是行为漂移。

## 0. 直觉与动机

**灵感 1（关节驱动 → 可执行证书，而不只是几何证书）**
直觉：v9 的中止点集问的是「离障碍够不够远」，但能不能在剩余距离内停下来，取决于关节能不能在力矩-速度包络内产生足够减速度。真实驱动器至少有四条 v9 没建模的硬约束：力矩上限随关节速度下降（torque-speed droop）、力矩变化率/指令延迟有限、摩擦与负载随域变化、以及热降额。于是同一张笛卡尔证书在轻载高减速比机器人上成立，在重载低减速比机器人上可能根本不成立。核心创新：**关节驱动签名（JointDriveSignature, JDS）+ 力矩可行证书（TorqueFeasibilityCert, TFC）**——把中止点集从几何不变式升级为**力矩可行的停车包络**，并给出 v9 常数减速度假设的系统性高估。

**灵感 2（迁移学习 → 快速残差证书，而不只是视觉域偏移检测）**
直觉：域偏移不只发生在像素里。改变负载、地面或换一台机器人时，**关节一步预测残差会在 1 个控制周期内跳起来**；而 v9 的 DA-ML 要 20 帧滑窗（50Hz 下 ≈400ms）。迁移学习给的不是「复用模型」这么弱的东西，而是「源域误差 + 迁移差异」的**误差可加界**：只要用目标域无标签的一步残差估计迁移差异 ρ_t，就能得到目标域前向模型的 anytime-valid 误差上界 β_t。核心创新：**迁移残差监视器（TransferResidualMonitor, TRM）**——用 e-process 把一步残差变成 β_t 的置信上界，直接决定证书视界 K_β；它在因果上对应真正被使用的模型，而不是一个滞后的代理指标。

**灵感 3（迁移学习 × 关节驱动 → 跨体态证书搬运）**
直觉：换机器人不该从零重新标定安全包络。若目标机器人在**力矩包络上支配**源机器人（同样的关节状态能提供 ≥κ 倍的归一化力矩、且延迟不更大），源机器人的证书就能按速度 v/κ 搬运到目标；反之只能自辨识或进入保守模式。核心创新：**执行器支配搬运（ActuationDominanceTransport, ADT）**——把「安全证书可迁移」从口号变成一个可验证的偏序 ≽_κ，且搬运后的证书必须由目标机上的 TFC 重新验证，绝不凭源机结论直接放行。

## 1. 研究问题（轮次升级版）

- **Q1（执行器可行性）**：如何在力矩-速度-延迟约束下定义停车不变式，使 P_t^τ 的每个中止点在物理上真的可执行？v9 的常数减速度假设何时、以多大幅度高估安全余量？
- **Q2（迁移误差可证）**：如何用一步关节残差给出 anytime-valid 的 β_t，并把证书视界 K_β 与 v9 的 K_DA 门控正交合成，保证快通道只收缩不扩张？
- **Q3（跨体态搬运）**：在什么支配关系下，源机证书能以速度/负载缩放无损搬运？非支配时如何安全降级而不产生「证书假搬运」？
- **Q4（等价退化）**：JDS/TFC/TRM/ADT 任一失效时，如何注入保守默认并精确退回 v9 几何证书，使引理 82/84 的结论原样成立？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 执行器可行律（Actuation-Feasible Certificate, TFC）**
中止点必须在执行器包络内可刹停：p ∈ P_t^τ 当且仅当从 p 起的安全停驻轨迹满足逆动力学力矩约束 |τ_req| ≤ (1−α)·τ_max(q̇)、力矩变化率约束与热预算，且 d_brake^τ(v_p) + d_safe ≤ dist(s_p,O) − |traj_{p:K}|。只满足几何条件、不满足力矩条件的 p 不进入 P_t^τ；禁止使用常数减速度 d_brake^const 作为最终判据。

**P14 迁移残差证书律（Transfer-Residual Bound, TRM）**
任何被移植或被使用的目标域前向模型都必须携带由一步可观测残差构造的 anytime-valid 上界 β_t（e-process / Ville），禁止使用跨域静态 β。块长必须同时受证书视界 K_β 约束；β_t 升高只能缩短 K_eff，不能延长。

**P15 执行器支配搬运律（Actuation Dominance Transport, ADT）**
跨体态证书搬运只沿支配偏序 ≽_κ 进行，并按 v/κ 缩放；κ<κ_min 时禁止搬运。搬运输出只是「候选包络」，必须由目标机 TFC 与 TRM 重新验证；支配关系提供的是快速初始化，不是豁免权。

**P16 快慢通道非对称合成律（Asymmetric Fast/Slow Composition）**
信任域取慢语义通道（DA-ML/SPR）与快物理通道（TRM/TFC）的交集：K_eff = min(K_DA, K_β, K_τ, K_thermal)。快通道只能收缩权限；即使残差很小也不得放宽 DA-ML 已给出的收缩。反之，任一快通道越限必须立即触发 M₀ 硬检查或中止，不必等待块边界。

## 3. 与基线的接口（如何退化）

- TFC/JDS 失效或辨识不可信 ⇒ 使用保守默认 σ^⊥（最小力矩、最大延迟、最大摩擦），等价于给 v9 的 d_brake 乘安全系数 s_⊥ ≥ 1；若仍不可行 ⇒ K_eff ← 1 并限速 v_safe；
- TRM 失效/残差不可信 ⇒ β_t ← β_v9（v9 静态标定值）× 保守上浮因子，证书退回 v9 几何形式；
- ADT 失效/非支配 ⇒ κ ← 1，禁止跨体态速度放大，按单机自辨识；
- TFC+TRM+ADT 全部失效 ⇒ **精确退回 v9 MetricVoiceGauge-ACMD**（几何证书 + DA/SPR 门控 + 动作分块）；
- v9 自身失效 ⇒ 按 v9 的契约化五级链退回 v8/v7/v6。

## 4. 预期贡献

1. **执行器可行分块证书**：力矩-速度 droop、指令延迟与热预算进入中止点构造，修补 v9 几何证书的 soundness 缺口；
2. **迁移误差快通道**：一步残差 + e-process 得到 β_t 与证书视界 K_β，与视觉慢通道正交，专门治理 v9「DA 滞后」最大风险；
3. **跨体态证书搬运**：支配偏序 ≽_κ 与速度缩放，使换机器人不必从零标定，且不产生无根据的权限放大；
4. **实验 E571–E590**：力矩包络标定、droop 修正、负载突变、跨体态搬运、快慢通道消融、形式化与端到端。

## 5. 本轮最大风险

**一句话**：一步残差能直接证明的只是单步误差，把它外推成多步证书视界 K_β 依赖收缩性与持续激励假设——在欠激励（负载只在加速时才显现）或非收缩（接触前自由空间）的机动中，β_t 可以在真正危险之前一直很小，于是「快通道」的盲区恰好与最需要它的时刻重合。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

| σ_R | 关节驱动签名：(力矩-速度包络, 反射惯量, 摩擦, 指令延迟, 力矩变化率上限, SEA 刚度, 热降额) |

**新增定义 540（关节驱动签名 JointDriveSignature）** σ_R=(T_R(·), I_r, b(q̇), d_act, τ̇_max, k_SEA, D_th(·))。其中 T_R(q̇)={τ : |τ_i| ≤ τ_i^max(q̇_i)}，τ_i^max 关于 |q̇_i| 单调不增（torque-speed droop）；I_r 为反射惯量；b 为摩擦；d_act 为指令到力矩的等效延迟；τ̇_max 为力矩变化率上限；k_SEA 为串联弹性刚度；D_th 为热降额映射。辨识由短激励回合完成（频率扫描 + 阶跃 + 负载已知/未知各一），输出 σ̂ 与辨识置信区间。

**新增定义 541（力矩可行轨迹证书 TorqueFeasibleCertificate）** 对轨迹 ξ=(q,q̇,q̈)_{1:K}，A(ξ)=true 当且仅当 ∀k：|τ_req(k)| ≤ (1−α)T(q̇(k))、|τ̇_req| ≤ τ̇_max、q̇ ∈ Q̇、且热预算 ∫|τ_req|² ≤ H。裕度 m_τ(ξ)=min 松弛量；m_τ<0 即证书无效，无论几何间隙多大。

**新增定义 542（力矩受限停车包络 TorqueLimitedStoppingEnvelope）**
```
a_max(v; q, payload) = min_{可行刹车力矩方向} 可实现减速度
d_brake^τ(v) = ∫_0^v v′/a_max(v′) dv′ + v·d_act
```
线性 droop 特例 τ_i^max(ω)=τ_0(1−ω/ω_0)（ω=v/r，忽略摩擦）给出闭式：
```
d_brake^τ(v) = (v_0/a_0)·[−u − ln(1−u)],  u=v/v_0,  a_0=τ_0/(m r)
```
该式在 u→1 时发散，正确表达「高速时力矩-速度包络收缩、可能刹不住」这一 v9 完全没有的失效模式。

**新增定义 543（执行器可行中止点集 ActuationFeasibleAbortSet）**
```
p ∈ P_t^τ  ⇔  从 p 起的安全停驻序列 A(·)=true
               ∧ d_brake^τ(v_p) + d_safe ≤ dist(s_p,O) − |traj_{p:K}|
```
由定义 542 的单调性得 P_t^τ ⊆ P_t。若 P_t 非空而 P_t^τ 为空，则 v9 的几何证书是执行器不可行的，必须拒绝该候选块（而非「无点可退」时也接受）。

**新增定义 544（一步迁移残差 OneStepResidual）** e_t = ||W(x_{t+1} − F̂_t(x_t,a_t))||_∞，W 为按测量噪声与状态 Lipschitz 尺度做的逐维归一化。在测量噪声有界 ν 下，真实一步误差 ≤ e_t + ν。e_t 只依赖本周期观测量，故延迟 = 1 个控制周期。

**新增定义 545（迁移误差上界 TransferResidualBound）** 对残差流构造 e-process
```
E_t = Π_{s≤t} exp(λ_s e_s − λ_s² c²/2)
```
由 Ville 不等式，在「模型误差 ≤ μ 时残差为有界超鞅」的原假设下，P(∃t: μ_t > β_t) ≤ δ。工程化形式：β_t = max_{s∈W_t} e_s + c·√(log(1/δ)/|W_t|)，并按 (1−ε) 遗忘因子滑窗。β_t 单调升时只用保守上界，不做平滑，避免「漂亮曲线掩盖漂移」。

**新增定义 546（证书视界 CertifiedHorizon）** 鲁棒管道 r_0=β_t，r_{k+1}=γ r_k + β_t（γ<1 为收缩率；γ=1 为无收缩）：
```
r_k = β_t(1−γ^k)/(1−γ)   (γ<1)      r_k = k·β_t   (γ=1)
K_β(t) = max{ k ≤ K_max : g_min^pred(k) − r_k ≥ d_safe + d_brake^τ(v_k) }
```
K_β 是「误差管道仍装得进安全余量」的最大步数；它把「β 小」与「能走多远」用一个可算的几何-误差联合条件连起来，而不是像 v9 那样只用 Δ_dom 缩放 K_max。

**新增定义 547（执行器支配 ActuationDominance）** R_t ≽_κ R_s 当且仅当存在 κ≥1，使得对源机证书可达的所有 (q,q̇)，目标机在时间膨胀 κ 后的轨迹 ξ_κ（q̇→q̇/κ，q̈→q̈/κ²）上满足 A_t(ξ_κ)=true，且 d_act^t ≤ d_act^s、q̇_max^t ≥ κ q̇_max^s、τ̇_max^t ≥ κ τ̇_max^s。操作化充分条件：∀(q,q̇)，(1−α_t)τ_max^t(q̇) ≥ κ·[(1−α_s)τ_max^s(q̇) + Δg]，其中 Δg 覆盖目标机重力/负载差。支配是**偏序**：≽_1 自反，≽_{κ1}∘≽_{κ2} ⇒ ≽_{κ1κ2}，但一般不反对称。

**新增定义 548（证书搬运 CertificateTransport）** 若 R_t≽_κR_s、Cert_s 在 (v_s, payload_s, K) 上有效、且 β_t ≤ β_bud，则提出候选 Cert_t(v_s/κ, payload_s, K)；该候选**必须**经目标机 TFC 与 TRM 重新验证（m_τ≥0、β_t 覆盖目标误差）才生效。非支配时取 κ*=max 可行缩放；κ*<κ_min ⇒ 禁止搬运，转自辨识或保守模式。搬运只降低速度上限，绝不提高。

**新增定义 549（迁移感知信任域与蒸馏 TransferAwareTrust）**
```
U_t^XAT = (Δ_dom<τ_dom) ∧ (risk_SLAM<τ_SLAM) ∧ (β_t≤β_bud) ∧ (m_τ≥0) ∧ (κ≥κ_min)
K_eff(t) = min( K_DA(t), K_β(t), K_τ(t), K_thermal(t) )
φ^elig_XAT(m) = φ^elig(m) ∧ φ^trans(m)
```
φ^trans(m)：源域贡献 c_m^s 与目标域短探针 c_m^t 无显著负迁移（c_m^t ≥ c_m^s − ε_trans），且迁移误差在预算内；否则该模块不参与蒸馏（保持 active），防止「在源域有用、在目标域有害」的模块被休眠。

## 2. 形式化定义的升级（相对 v9）

**升级定义 496（软证书，v10）** δ_trigger 在 v9 五条件上增加两个快物理条件：
```
δ_trigger = {σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM
             ∧ Ĉ_t valid ∧ β_t≤β_bud ∧ m_τ≥0}
```
快条件与慢条件同尺度：任一失效都在下一个 50Hz 守卫触发 M₀ 硬检查，不必等块边界。

**升级定义 531（软硬约束衔接，v10）** M₀ 判据增加两个块级入口：TFC 报告 m_τ<0，或 TRM 报告 β_t>β_bud ⇒ 立即切换到 ≤ 当前执行步的最大 p*∈P_t^τ 或安全停驻；若 P_t^τ 为空，则执行预注册的保守停驻（限速 + 最大制动），并记录一次「执行器不可行」事件。

**升级定义 533/534（块证书与中止点，v10）** 余量 β 替换为 β_t（定义 545）；d_brake 替换为 d_brake^τ（定义 542）；P_t 替换为 P_t^τ（定义 543）。其余（前向模型、块生成节拍、5Hz/50Hz 分工）不变。

**升级定义 538（提炼状态机，v10）** 在 v9 迁移条件上增加：β_t>β_bud、m_τ<0、κ<κ_min 任一成立 ⇒ wake_all；φ^trans=false 的模块禁止进入 dormant；跨域先验只允许作为 c_m 的**悲观下界**（取 min(c_m^s, c_m^t)），不允许把源域的高贡献直接当作目标域证据。

**升级定义 539（有效块长，v10）** K_eff = min(K_DA, K_β, K_τ, K_thermal)，其中 K_τ 由力矩裕度与 droop 决定，K_thermal 由热预算决定；K_DA 公式保持 v9 不变。

# IP-357 JointDriveSignature：关节驱动签名与辨识
@dataclass
class JointDriveSignature:
    tau_max: Callable[[np.ndarray], np.ndarray]   # torque-speed envelope
    inertia_ref: np.ndarray                        # reflected inertia
    friction: Callable[[np.ndarray], np.ndarray]   # b(qdot)
    latency: float                                 # d_act [s]
    tau_dot_max: float                             # torque rate limit
    sea_stiffness: float                           # k_SEA
    thermal: Callable[[float], float]              # derate factor in [0,1]

CONSERVATIVE_SIGMA = JointDriveSignature(
    tau_max=lambda qd: np.full_like(qd, TAU_MIN),
    inertia_ref=np.full(N_JOINTS, I_MAX),
    friction=lambda qd: B_MAX * np.sign(qd),
    latency=LAT_MAX, tau_dot_max=TAUDOT_MIN,
    sea_stiffness=K_MIN, thermal=lambda e: 1.0)

def identify_signature(robot, n_chirp=3, n_step=2, duration=1.0):
    """短激励辨识：频率扫描辨识惯量/摩擦/延迟，阶跃辨识力矩包络与 droop。"""
    data = []
    for _ in range(n_chirp):
        data += robot.excite_chirp(duration)
    for _ in range(n_step):
        data += robot.excite_step(duration)
    sig = fit_joint_drive(data)                    # 返回参数 + 置信区间
    return sig if sig.confidence >= CONF_MIN else CONSERVATIVE_SIGMA


# IP-358 TorqueFeasibilityCertifier：力矩可行证书与 droop 停车包络
class TorqueFeasibilityCertifier:
    def __init__(self, sigma, alpha=0.2, d_safe=0.15, v0=None):
        self.sig, self.alpha, self.d_safe = sigma, alpha, d_safe
        self.v0 = v0 or robot_spec.base_speed

    def torque_margin(self, q, qd, qdd):
        tau_req = inverse_dynamics(q, qd, qdd)     # M qdd + C qd + g + b
        lim = (1 - self.alpha) * self.sig.tau_max(qd)
        return float(np.min(lim - np.abs(tau_req)))

    def brake_distance(self, v, q, payload=0.0):
        if v <= 0:
            return 0.0
        # 线性 droop 闭式；一般包络用数值积分
        a0 = self.sig.tau_max(np.zeros_like(q))[0] / (eff_mass(q, payload) * WHEEL_R)
        u = min(v / self.v0, 0.999)
        d = (self.v0 / a0) * (-u - np.log(1 - u))
        return d + v * self.sig.latency          # 指令延迟内继续前进

    def feasible(self, traj):
        for q, qd, qdd in zip(traj.q, traj.qd, traj.qdd):
            if self.torque_margin(q, qd, qdd) < 0:
                return False, -1.0
            if np.max(np.abs(self.sig.thermal_derate(qd) * self.sig.tau_max(qd))) \
               < np.max(np.abs(inverse_dynamics(q, qd, qdd))):
                return False, -1.0
        return True, min(self.torque_margin(q, qd, qdd)
                         for q, qd, qdd in zip(traj.q, traj.qd, traj.qdd))

    def abort_set(self, pred, state):
        pts = []
        for p in range(1, len(pred.actions)):
            if not self.feasible(stop_trajectory(pred, p)):
                continue
            margin = (pred.clearance[p] - self.d_safe
                      - self.brake_distance(pred.speed[p], pred.q[p], state.payload))
            if margin >= pred.path_len[p:]:
                pts.append(p)
        return pts


# IP-359 TransferResidualMonitor：一步残差 → anytime-valid β_t → K_β
class TransferResidualMonitor:
    def __init__(self, W, delta=1e-3, c=0.05, window=50, gamma=0.9):
        self.W, self.delta, self.c = W, delta, c
        self.window, self.gamma = window, gamma
        self.buf, self.logE = [], 0.0

    def update(self, x, a, x_next, F_hat, lam=0.5):
        e = float(np.max(np.abs(self.W * (x_next - F_hat(x, a)))))
        self.logE += lam * e - 0.5 * lam * lam * self.c ** 2
        self.buf = (self.buf + [e])[-self.window:]
        beta = max(self.buf) + self.c * np.sqrt(
            np.log(1 / self.delta) / len(self.buf))
        return e, beta

    def certified_horizon(self, beta, pred, tfc, d_safe):
        r, k_ok = 0.0, 0
        for k in range(1, len(pred.actions) + 1):
            r = self.gamma * r + beta              # 鲁棒管道递推
            need = d_safe + tfc.brake_distance(pred.speed[k], pred.q[k])
            if pred.clearance[k] - r < need:
                break
            k_ok = k
        return k_ok


# IP-360 ActuationDominanceTransport：支配偏序与证书搬运
class ActuationDominanceTransport:
    def __init__(self, src_sig, tgt_sig, kappa_min=1.05):
        self.src, self.tgt, self.kappa_min = src_sig, tgt_sig, kappa_min

    def kappa(self, q, qd, payload):
        num = (1 - ALPHA_T) * self.tgt.tau_max(qd)
        den = (1 - ALPHA_S) * self.src.tau_max(qd) + GRAVITY_DELTA(q, payload)
        k_tau = float(np.min(num / np.maximum(den, 1e-9)))
        k_vel = self.tgt.vel_max / max(self.src.vel_max, 1e-9)
        k_rate = self.tgt.tau_dot_max / max(self.src.tau_dot_max, 1e-9)
        if self.tgt.latency > self.src.latency:
            return 0.0                              # 延迟不支配 ⇒ 禁止搬运
        return min(k_tau, k_vel, k_rate)

    def transport(self, cert_src, q, qd, payload):
        k = self.kappa(q, qd, payload)
        if k < self.kappa_min:
            return None                             # 非支配：自辨识或保守模式
        return Cert(v_max=cert_src.v_max / k,     # 只降速，不升速
                    payload=cert_src.payload,
                    K=cert_src.K,
                    beta_budget=cert_src.beta_budget)


# 主闭环集成：在 v9 的 AC 上插入快物理通道
def metricvoicegauge_round_1(M, s, obs, audio_stream=None, ell=None, ...):
    # ... v9 的 MW 感知侧与 v8 继承路径保持不变 ...
    sigma = jds.current_or(CONSERVATIVE_SIGMA)
    tfc = TorqueFeasibilityCertifier(sigma)
    trm = TransferResidualMonitor(W=normalize_matrix(M))

    # 5Hz 块生成：候选先过 TFC，再过 TRM 视界
    if current_chunk is None or current_chunk.exhausted:
        cand = chunker.generate_chunk(
            ctx.state, ctx.delta_dom, ctx.tau_dom,
            trust_ok=(ctx.delta_dom < ctx.tau_dom
                      and ctx.risk_slam < M.tau_slam))
        # ADT 仅提出候选速度上限；目标机 TFC 重新验证
        moved = adt.transport(cand.cert, s.q, s.qd, s.payload)
        if moved is not None:
            cand = cand.with_speed_cap(moved.v_max)
        ok_tau, m_tau = tfc.feasible(cand.trajectory)
        abort_pts = tfc.abort_set(cand.pred, s) if ok_tau else []
        _, beta_t = trm.update(s.x_prev, s.a_prev, s.x, M.F_hat)
        K_beta = trm.certified_horizon(beta_t, cand.pred, tfc, D_SAFE)
        K_eff = min(cand.K, K_beta, k_from_torque(m_tau), k_thermal(sigma))
        current_chunk = cand.trim(K_eff, abort_pts)

    # 50Hz 守卫：v9 廉价检查 + 快物理条件
    e_t, beta_t = trm.update(s.x_prev, s.a_prev, s.x, M.F_hat)
    verdict, k_next = chunker.midchunk_guard(current_chunk, k_exec, live_obs)
    if verdict == 'abort':
        current_chunk.execute_safe_stop_at(k_next)
        current_chunk = None
    elif beta_t > M.beta_bud or not tfc.feasible(current_chunk.step(k_exec))[0]:
        # 快通道越限：立即收缩，不等块边界，也不等 DA-ML
        current_chunk.execute_safe_stop_at(nearest_abort(current_chunk, k_exec))
        current_chunk = None
    else:
        execute(current_chunk.actions[k_next])

    distiller.step(cycle_idx, ctx, beta_t=beta_t, m_tau=m_tau)
    return M.inherited_v8_path(ctx)

## 4. 推导

**引理 87（droop 停车包络的保守性，修补 v9 定义 534）** 设 a_max(v) 关于 v 单调不增，且 a_max(v) ≤ a_0 := a_max(0)。则
```
d_brake^τ(v) = ∫_0^v v′/a_max(v′) dv′ + v·d_act  ≥  v²/(2a_0) = d_brake^const(v)
```
故 v9 的常数减速度停车不变式是**必要而非充分**条件，P_t^τ ⊆ P_t。对线性 droop，比值 R(u)=2[−u−ln(1−u)]/u²，u=v/v_0，且 R 在 [0,1) 上严格单调递增（见 §5 数值）。证明：a_max 单调不增 ⇒ 1/a_max(v′) ≥ 1/a_max(0)=1/a_0，积分保序；线性特例直接积分并求导验证 R′>0。∎

**引理 88（执行器可行中止的可靠性）** 若 p∈P_t^τ，则从 p 起存在满足 |τ_req|≤(1−α)τ_max、|τ̇_req|≤τ̇_max、热预算与 q̇∈Q̇ 的安全停驻轨迹，且其刹停终点距障碍 ≥ d_safe。证明：定义 541 的可行性 + 定义 542 的积分包络 + 定义 543 的不等式；三项分别保证力矩可产生、距离足够、延迟被计入。∎

**引理 89（支配搬运的安全性）** 若 R_t≽_κR_s、Cert_s 在 (v_s,payload_s,K) 上有效，且搬运候选经目标机 TFC 重新验证通过（m_τ≥0），则 Cert_t(v_s/κ,payload_s,K) 在 R_t 上有效。证明：支配定义给出时间膨胀轨迹 ξ_κ 上的力矩可行性；TFC 复验把「签名建模误差」也纳入判据；速度只降不升，v_s/κ ≤ v_s。若 TFC 复验失败则候选不生效（定义 548），故无「假搬运」。∎

**引理 90（anytime-valid 迁移上界）** 在测量噪声有界 ν、残差对模型误差为有界超鞅的原假设下，定义 545 的 e-process 满足 P(∃t: μ_t>β_t) ≤ δ；进一步，若动力学在证书集上以 γ<1 收缩，则 k 步状态偏差 ≤ r_k=β_t(1−γ^k)/(1−γ)，否则 ≤ kβ_t。证明：Ville 不等式给任意停时的第一结论；对 r_{k+1}=γr_k+β_t 归纳得第二结论。∎

**引理 91（快通道只收缩且领先 DA 慢通道）** K_eff = min(K_DA,K_β,K_τ,K_thermal) 关于每个自变量单调不增，故 TRM/TFC 只能降低 K_eff；在域变化可由一步转移观测到的条件下（激励条件），β_t 在 1 个周期内越限，而 DA-ML 需 L_DA=20 帧，故 K_β 至多提前 L_DA−1=19 个周期（380ms）把 K_eff 压到 1。若域变化不体现在关节一步转移中（纯几何/遮挡变化），该领先性不成立——这由 v9 的几何守卫与慢通道负责。∎

**引理 92（迁移感知退化与 v9 等价）** 当 TFC/TRM/ADT 全部失效时，σ←σ^⊥、β_t←β_v9·s_⊥、κ←1，K_eff=min(K_DA,K_β^v9,K_τ^⊥)；由于 σ^⊥ 的 a_max 不大于标称值，d_brake^τ 不小于 v9 的 d_brake^const，故该模式是 v9 几何证书的保守放大，绝不比 v9 更冒险。蒸馏侧 φ^elig_XAT≤φ^elig，wake_all 条件的增加只会增加 active 模块；dormant 仍等价注入 v^⊥（v9 引理 83），故行为仍在 v9 退化格点内。∎

**引理 93（跨域负迁移防护）** 若 φ^trans(m)=false（目标域短探针显示 c_m^t < c_m^s−ε_trans 或迁移误差超预算），则 m 不进入 dormant，且其贡献先验取 min(c_m^s,c_m^t)。因此跨域先验不会导致比目标域实测证据更早的休眠；结合引理 92，系统行为不劣于 v9 的全模块常开。∎

| 多域（E584） | 收敛 ≤3 回合 | 加域指纹检索、预热辨识 |
| 端到端（E585） | ≥v9+10% | 回调 v_safe、增大 β_bud |
| 能耗（E586） | ≤25W、任务不劣化 >10% | 优化限速曲线、减少复验 |
| 接触（E587） | 力 ≤阈值 | 降刚度、增停驻距离 |
| 消融（E588） | 双通道不劣于单通道、误停不升 | 调 β_bud、改 e-process 参数 |
| 泛化（E589） | 覆盖 ≥99% | 增大 β 安全系数、加域随机化 |
| 竞赛（E590） | ≥v9+15% | 综合调参、分析失分瓶颈 |

## 9. 本轮最大风险

**一句话**：一步残差能直接证明的只是单步误差，把它外推成多步证书视界 K_β 依赖收缩性与持续激励假设——在欠激励（负载只在加速时才显现）或非收缩（接触前自由空间）的机动中，β_t 可以在真正危险之前一直很小，于是「快通道」的盲区恰好与最需要它的时刻重合。
