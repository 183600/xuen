# 第 10 轮（承接 v9；本轮灵感：「零样本泛化」×「鲁棒性」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 493–539；引理 69–86；实验 E531–E570）。
> **本轮纪律**：**证书的统计有效性**。v9 把安全押在一句假设上——「信任域内前向模型误差 ≤ β」。但 β 是已知域上标定的**经验常数**，且在时间上静止。两个灵感正好攻击这个常数的两个前提：零样本泛化攻击「域已知」，鲁棒性攻击「平均误差即最坏误差」。本轮把 β 从**常数**升级为**带有限样本覆盖保证、随漂移自适应、对最坏扰动保守的随机过程 β_t**，并保留「任一环节失效即注入保守回退、逐位等价 v9」的继承纪律。

## 0. 直觉与动机

**灵感 1（零样本泛化 → 证书必须自带覆盖保证）**
直觉：一个新房间、新光照、新物体类别，没有标签、不许重训，v9 的 β 仍然照用——这不是泛化，这是赌博。真正可迁移的不是模型，而是**不确定性的统计结构**：共形预测（conformal prediction）只用校准残差的分位数，就能对任意黑箱前向模型给出分布无关的有限样本覆盖。零样本部署时，用**漂移加权共形**把旧域校准集重加权到新域；权重不可靠（重叠不足）时，退回最坏分数，并由 K_eff=1 承担后果。
严谨表述：覆盖事件 P(g ≥ ĝ_min) ≥ 1−α 由共形分位数保证，而非由 β 的域内标定假设保证（定义 541–543；引理 87–88）。

**灵感 2（鲁棒性 → 从平均误差到认证最坏界）**
直觉：β 是 |F̂−F| 的经验上界，平均意义成立；对抗扰动、传感器噪声、遮挡会让真实误差在个别状态远超 β。鲁棒性要求把证书按**认证半径**膨胀：前向模型的 Lipschitz 常数 L 与输入扰动上界 ε 给出 Lε，随机平滑（randomized smoothing）给出可证明的平滑半径。证书先膨胀再判定，M₀ 硬检查直接消费膨胀后的界。
严谨表述：Ĉ_rob = Ĉ ⊖ (Lε + β_t)，覆盖在 1−α 下成立，扰动项由认证界而非经验均值承担（定义 544；引理 89）。

**灵感 3（漂移先行 → 把检测滞后本身当作安全参数）**
直觉：v9 自陈最大风险是 Δ_dom 的 20 帧滑窗滞后于真实跳变。鲁棒性不只是「抗噪」，更是「早报」。对域不变表征的残差做 CUSUM 变点检测，把跳变检测从「滑窗平均」变成「累积证据」，检测延迟由 O(窗口长度) 降为 O(h/(δ−k))。
严谨表述：检测延迟的期望上界与虚警率均可界（定义 545；引理 90）。

**灵感 4（零样本适配 → 只动可回滚的参数）**
直觉：零样本不该等于「什么都不学」。可以学，但只能学**末层与阈值**，且每次提交前必须在影子校准缓冲上复核覆盖；覆盖掉下界就回滚。安全关键模块（M₀、SpatialCert、FaultCert、证书检查器、MW、AC guard）永不进入可适配集。
严谨表述：适配受信任域 + 影子覆盖约束 + O(1) 快照回滚三重约束（定义 546；引理 91）。

## 1. 研究问题（轮次升级版）

- **Q1（零样本证书）**：在无标签、不许重训的新域，如何给出有限样本覆盖保证，同时不让 M₀ 硬安全依赖任何统计松弛？共形分位数与认证膨胀能否替代 v9 的固定 β 而不改变 50Hz 预算？
- **Q2（鲁棒-可用性权衡）**：把平均 β 升级为最坏界会让 K_eff 更频繁塌缩到 1。如何用漂移加权与变点先行把「统计怀疑」与「真实陌生」区分开，避免鲁棒性以可用性为代价？
- **Q3（继承与退化）**：v10 四个新模块任一超时/失效时，如何保证证书与决策逐位退回 v9（再由引理 83 退回 v8/v7），使新增统计机制不引入行为漂移？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 分布无关证书律（Conformal Certification, ZSC）**
证书的误差余量 β_t 不作为常数声明，而是由逐层共形分数 q_l(α_t) 导出；β_t = max_l q_l(α_t)。校准集与部署域的关联通过漂移加权显式建模；权重重叠失败时降级为最坏分数，并由 K_eff=1 承担保守代价。

**P14 最坏情况膨胀律（Robust Inflation, RCI）**
证书判定前先做认证膨胀：对 L-Lipschitz 前向模型与输入扰动上界 ε，间隙减 (Lε+β_t)、代价加 (Lε+β_t)；随机平滑提供可认证半径 R 作为 ε 的上界。M₀ 与 SpatialCert 只消费膨胀后的界，绝不消费裸预测。

**P15 漂移先行律（Change-point First, IRC）**
域偏移检测不只来自 20 帧滑窗的 Δ_dom，还来自域不变表征残差的 CUSUM 累积证据。检测量取 Δ_dom^eff = max(Δ_dom^ML, Δ_dom^CUSUM)，以「先报」换安全；误报由迟滞与 ACI 覆盖率反馈共同抑制。

**P16 适配可回滚律（Rollback-safe Adaptation, STA）**
在线零样本适配只允许作用于 θ_adapt（感知末层 + 逐层阈值 τ_i）；每次提交前必须在影子校准缓冲上验证覆盖 ≥ 1−α−η，否则回滚到最近快照。适配永不触碰证书检查器与安全不变式。

## 3. 与基线的接口（如何退化）

- ZSC 失效/校准集不可用 ⇒ β_t ← β_fixed（v9 常数），等价 v9 证书；
- WCP 重叠失败或 ACI 报警 ⇒ K_eff←1 且取最坏分数（保守但可用，不产生错误乐观）；
- IRC 失效 ⇒ Δ_dom 退回 v8 的 20 帧滑窗，等价 v9 检测；
- RCI 失效 ⇒ ε=0 ⇒ 等价 v9 证书；
- STA 失效或回滚 ⇒ θ 冻结为 θ₀ ⇒ 等价 v9 无适配；
- 全失效 ⇒ 逐位退回 v9（引理 92），再由 v9 引理 83 退回 v8，再退回 v7/v6。

**关键不对称**：新增模块的失效方向一律指向「更保守」（更大余量、更短块长、更早报警），而非「更乐观」；这是本轮相对 v9 的安全风格转变。

## 4. 预期贡献

1. **漂移感知鲁棒共形证书（DRCC）**：把 v9 的经验 β 替换为「WCP + ACI + 认证膨胀」三层证书，给出零样本部署下的有限样本 / 长程覆盖保证（引理 87–89）；
2. **认证最坏界替代经验均值**：Lipschitz 与随机平滑把对抗扰动纳入证书，使 v9 引理 82 成为 ε=0 的特例；
3. **变点先行的域偏移检测**：用域不变残差 CUSUM 把 v9 的最大风险（20 帧滑窗滞后）转化为可界检测延迟（引理 90）；
4. **安全回滚的零样本适配**：影子覆盖 + 快照回滚，使「学会新域」不触碰安全不变式；E571–E590 覆盖覆盖率、扰动、检测延迟、退化等价与端到端任务。

## 5. 本轮最大风险

**一句话**：ACI 只保证**长程边际覆盖**，不保证**条件覆盖**；在持续漂移下「覆盖率预算」会被持续消耗，恰在罕见高危状态出现时失效——系统名义上平均安全，尾部却不安全。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-ZSCR**（Zero-Shot Conformal Robustness）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 493–539；引理 69–86；实验 E531–E570）。
> 本轮灵感：「零样本泛化」×「鲁棒性」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 三模块（AC/MW/ID）全部保留；v10 只把「证书的误差余量 β」从常数升级为统计随机过程，并把退化方向统一钉死为「更保守」。任一新增环节不可用 ⇒ 注入 v9 回退值，逐位等价退回 v9（引理 92），再经引理 83 退回 v8。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| α, α_t | 名义误覆盖率与 ACI 在线误覆盖率；覆盖目标 1−α（默认 α=0.05） |
| q_l(α_t) | 第 l 层共形分位数（逐层非符合性分数的加权分位数） |
| β_t = max_l q_l(α_t) | 时变证书余量，取代 v9 的常数 β |
| w(x) = p_test(x)/p_cal(x) | 漂移加权似然比，由域分类器估计并裁剪 |
| ρ_ess = ESS/n | 有效样本比；低于 ρ_min（0.3）判为重叠失败 |
| err_t = 1[s_t > q_t] | 在线覆盖错误指示，驱动 ACI |
| L, ε, R | 前向模型 Lipschitz 常数、输入扰动上界、随机平滑认证半径 |
| Ĉ_rob = (ĝ_min^rob, ê_max^rob) | 膨胀后的鲁棒块证书 |
| z_inv = E_inv(x) | 域不变表征；r_t 为其残差，C_t 为 CUSUM 统计量 |
| Δ_dom^eff | 有效域偏移 = max(Δ_dom^ML, Δ_dom^CUSUM) |
| θ_adapt, θ₀, ρ | 可适配参数子集、其初始值、信任域半径 |
| cov_shadow | 影子校准缓冲上的经验覆盖率，提交门槛 1−α−η |

**新增定义 540（零样本部署协议 Zero-Shot Deployment Protocol）** 给定有标签校准域 D_cal 与无标签部署域 D_test（D_test ≠ D_cal，不重训练），系统仅可使用 D_cal 的共形分数与 x_t 的在线无标签观测。要求：(i) 长程覆盖率 ≥ 1−α；(ii) 安全关键层 M₀ 使用保守包络（最坏分数或认证膨胀），不接受统计松弛；(iii) 不改变 v9 的 50Hz 控制节拍与 5Hz 块生成预算。

**新增定义 541（逐层共形分数与分位数 Conformal Score）** 对安全相关层 l（间隙、代价、抓取置信），非符合性分数 s_l(x,y)=|y_l−ŷ_l|/σ_l（σ_l 为尺度归一）。校准集 S_cal={(x_i,y_i)}_{i=1}^n，取
```
q_l(α) = 排序后的第 ⌈(n+1)(1−α)⌉ 个 s_l   （n 为校准样本数）
β_t    = max_l q_l(α)
```
交换性下 P(s_{n+1} ≤ q_l(α)) ≥ 1−α，即证书余量具有有限样本覆盖保证，而非经验假设。

**新增定义 542（漂移加权共形 Weighted Conformal, WCP）** 权重 w(x)=p_test(x)/p_cal(x)，由域分类器 g(x) 经概率校准后取 w=ĝ/(1−ĝ)，裁剪到 [w_min,w_max] 以控方差。加权分位数按归一化累积权重取 1−α 处。有效样本比
```
ESS = (Σ_i w_i)² / Σ_i w_i²,   ρ_ess = ESS/n
```
若 ρ_ess < ρ_min=0.3，判为**重叠失败**（目标域落在校准支撑之外），放弃加权、取 q_l^max= max_i s_l，并强制 K_eff=1。加权交换性下覆盖仍 ≥1−α；重叠失败时覆盖保证退化为空但**方向保守**。

**新增定义 543（自适应共形推断 Adaptive Conformal Inference, ACI）** 用在线覆盖误差反馈调整 α_t，使长程覆盖在无交换性时仍受控：
```
err_t   = 1[ s_t > q_t ]
α_{t+1} = Π_{[α_min,α_max]}( α_t + γ(α − err_t) ),   γ∈(0,1)
```
覆盖偏高（err_t<α）时收紧 α_t 以缩小证书，偏低时放宽以扩大证书。ACI 不依赖交换性；代价是只保证长程**边际**覆盖（引理 88），这正是本轮最大风险的来源。

**新增定义 544（鲁棒证书膨胀 Robust Certificate Inflation, RCI）** 设前向模型 F̂ 对 (s,a) 满足 L-Lipschitz，输入扰动 ‖δ‖_∞ ≤ ε。则膨胀证书
```
ĝ_min^rob = ĝ_min − (L·ε + β_t),     ê_max^rob = ê_max + (L·ε + β_t)
```
随机平滑给出可认证半径 R=(σ/2)(Φ⁻¹(p_A)−Φ⁻¹(p_B))（p_A,p_B 为 top-2 类的下界/上界概率），取 ε ≤ R。M₀ 与 SpatialCert 只消费 Ĉ_rob：任何裸预测不得进入硬判定。

**新增定义 545（域不变残差与 CUSUM 检测 Invariant Residual CUSUM, IRC）** 由 IRM/V-REx 训练的域不变编码器给出 z_inv=E_inv(x)。无标签残差取相邻表征漂移（或一步预测残差）：
```
r_t = ‖z_inv(x_t) − z_inv(x_{t−1})‖₂
C_t = max(0, C_{t−1} + r_t − μ₀ − k)     （μ₀ 标称残差均值，k 容忍漂移）
alarm_t = 1[C_t > h]
Δ_dom^eff = max(Δ_dom^ML, Δ_cp·alarm_t)   （Δ_cp 为变点映射增益）
```
CUSUM 累积证据而非滑窗平均，强漂移下检测延迟从 20 帧量级降到个位数（引理 90）。

**新增定义 546（安全测试时适配器 Safe Test-Time Adapter, STA）** 可适配参数 θ_adapt ⊆ θ 仅含感知末层与逐层阈值 τ_i；安全关键集 Θ_safe={M₀ 硬检查、SpatialCert、FaultCert、证书检查器、MW、AC guard} 冻结。候选 θ' 满足 ‖θ'−θ₀‖₂ ≤ ρ 且影子覆盖 cov_shadow(B_shadow; θ') ≥ 1−α−η 才提交，否则回滚 snapshot。回滚为 O(1) 指针恢复。

**新增定义 547（证书合成与有效块长门控 v10，升级定义 539）**
```
trust_t = (¬overlap_failed) ∧ (¬aci_alarm) ∧ (Δ_dom^eff < τ_dom)
          ∧ (risk_SLAM < τ_SLAM) ∧ Ĉ_t^rob valid
K_eff(t) = 1                                  if ¬trust_t
         = max(1, ⌊K_max·(1 − min(1, Δ_dom^eff/τ_dom))⌋)   otherwise
```
注意不对称：**统计怀疑（重叠失败/ACI 报警）与真实陌生同等触发 K_eff=1**——宁可短块，不可错信。

**新增定义 548（零样本鲁棒退化格，升级定义 536/引理 83）** 每模块失效到 v9 回退值的映射：

| v10 组件 | 失效模式 | 注入回退 | 等价 |
|---|---|---|---|
| ZSC | 校准集不可用 / 超时 | β_t ← β_fixed | v9 常数证书 |
| WCP | 重叠失败 | w≡1 或 q_max | 保守 v9 变体 |
| ACI | 超时 / 发散 | α_t ← α 固定 | v9 固定覆盖 |
| IRC | 编码器不可用 | Δ_dom^eff ← v8 20 帧 | v9 检测 |
| RCI | 认证不可用 | ε ← 0 | v9 证书 |
| STA | 影子覆盖不达标 | θ ← θ₀ | v9 无适配 |

**新增定义 549（鲁棒-零样本审计协议 ZRA）** 红队测试套件注入：(a) 合成协变量偏移（光照/纹理/布局/噪声）；(b) ε 内对抗扰动；(c) 标签偏移；(d) 持续漂移；(e) 伪造域分类器。审计指标：边际覆盖、条件/尾部覆盖、最坏安全违背、检测延迟、K_eff 收缩率、任务成功率。ZRA 不参与在线决策，只产出证据。

## 2. 形式化定义（要点与升级）

**定义 493/495/521/524** 继承 v9 不变（六层指标、MetaWeight/情感、DA-OTL、DA-ML）。
**升级定义 496（软证书，v10）** δ_trigger 中的 β 替换为 β_t，并新增两项：`¬overlap_failed ∧ ¬aci_alarm`。五条件升为七条件，任何一项不满足都触发 M₀ 硬检查。

# IP-357 ZeroShotConformalCalibrator：零样本共形校准器
class ZeroShotConformalCalibrator:
    def __init__(self, alpha=0.05, gamma=0.01, T_conf=50,
                 alpha_min=0.01, alpha_max=0.20, ess_min_ratio=0.30):
        self.scores = {}                      # layer -> sorted calibration scores
        self.alpha, self.gamma = alpha, gamma
        self.alpha_t = alpha
        self.T_conf, self.tick = T_conf, 0
        self.ess_min_ratio = ess_min_ratio
        self.overlap_failed = False
        self.q = {}

    def set_calibration(self, layer_scores):
        for l, vals in layer_scores.items():
            self.scores[l] = sorted(vals)

    @staticmethod
    def conformal_quantile(vals, alpha):
        n = len(vals)
        j = min(n - 1, math.ceil((n + 1) * (1 - alpha)) - 1)
        return vals[j]

    @staticmethod
    def weighted_quantile(vals, weights, alpha):
        order = sorted(range(len(vals)), key=lambda i: vals[i])
        v = [vals[i] for i in order]
        w = np.asarray([weights[i] for i in order], float)
        w = w / w.sum()
        cdf = np.cumsum(w)
        j = min(len(v) - 1, int(np.searchsorted(cdf, 1 - alpha)))
        return v[j]

    def calibrate(self, weights=None):
        self.overlap_failed = False
        for l, vals in self.scores.items():
            if weights is None:
                self.q[l] = self.conformal_quantile(vals, self.alpha_t)
            else:
                w = np.clip(np.asarray(weights, float), 1e-6, 1e6)
                ess = (w.sum() ** 2) / (w ** 2).sum()
                if ess / len(w) < self.ess_min_ratio:      # 定义 542
                    self.overlap_failed = True
                    self.q[l] = vals[-1]                   # 最坏分数，保守
                else:
                    self.q[l] = self.weighted_quantile(vals, w, self.alpha_t)
        return self.q

    def aci_update(self, err_t):                            # 定义 543
        self.alpha_t = float(np.clip(
            self.alpha_t + self.gamma * (self.alpha - err_t),
            self.alpha_min, self.alpha_max))

    def step(self, weights=None):
        self.tick += 1
        if self.tick % self.T_conf == 0:
            return self.calibrate(weights)
        return self.q


# IP-358 RobustCertificateInflation：鲁棒证书膨胀器
class RobustCertificateInflation:
    def __init__(self, lipschitz_L, epsilon_input):
        self.L, self.eps = lipschitz_L, epsilon_input

    @staticmethod
    def smoothing_radius(sigma, p_a, p_b):
        Phi_inv = lambda p: statistics.NormalDist().inv_cdf(min(max(p, 1e-9), 1 - 1e-9))
        return (sigma / 2.0) * (Phi_inv(p_a) - Phi_inv(p_b))   # 定义 544

    def inflate(self, g_min, e_max, beta_t):
        delta = self.L * self.eps + beta_t
        return g_min - delta, e_max + delta


# IP-359 InvariantResidualCUSUM：域不变残差变点检测器
class InvariantResidualCUSUM:
    def __init__(self, mu0, k=0.5, h=4.0, gain=1.0, warmup=5):
        self.mu0, self.k, self.h, self.gain = mu0, k, h, gain
        self.C, self.z_prev, self.n = 0.0, None, 0
        self.warmup = warmup

    def update(self, z_inv):
        if self.z_prev is None:
            self.z_prev, self.n = z_inv, 1
            return 0.0
        r = float(np.linalg.norm(z_inv - self.z_prev))
        self.z_prev = z_inv
        self.n += 1
        self.C = max(0.0, self.C + r - self.mu0 - self.k)   # 定义 545
        if self.n < self.warmup:
            return 0.0
        return self.gain if self.C > self.h else 0.0


# IP-360 SafeTestTimeAdapter：安全测试时适配器
class SafeTestTimeAdapter:
    def __init__(self, theta0, rho=0.05, eta=0.02):
        self.theta0 = theta0.copy()
        self.theta, self.snapshot = theta0.copy(), theta0.copy()
        self.rho, self.eta = rho, eta

    def propose(self, grad, lr):
        cand = self.theta - lr * grad
        d = cand - self.theta0
        if np.linalg.norm(d) > self.rho:                      # 信任域
            cand = self.theta0 + self.rho * d / np.linalg.norm(d)
        return cand

    def commit(self, cand, shadow_coverage, alpha):
        if shadow_coverage >= 1 - alpha - self.eta:           # 影子覆盖门槛
            self.snapshot = self.theta.copy()
            self.theta = cand
            return True
        self.theta = self.snapshot                            # O(1) 回滚
        return False

## 4. 推导

**引理 87（加权共形覆盖）** 若校准点与测试点在权重 w 下满足加权交换性，且 w 有界（重叠成立），则 WCP 分位数满足 P(s_{n+1} ≤ q̂_w) ≥ 1−α。证明：加权交换性给出测试点在校准序列加权秩中的均匀性，取归一化累积权重 1−α 处即为标准加权共形论证。若重叠失败（w 无界或 ρ_ess<ρ_min），不存在有限覆盖保证；此时取 q^max 使覆盖事件退化为「最坏校准误差」，结论为空但**不产生错误乐观**。∎

**引理 88（ACI 长程覆盖界）** 设 α_t∈[α_min,α_max]，更新 α_{t+1}=Π(α_t+γ(α−err_t))。则对任意（可对抗的）误差序列，长程平均误覆盖满足
```
| (1/T)Σ_{t=1}^T err_t − α | = O( (α_max−α_min) / (γT) )
```
即 ACI 在无交换性下仍无**永久性**系统性欠覆盖。证明要点：把更新式对 t 求和并望远镜消去，投影项每次至多改变 α 一个区间宽度，均摊到 T 步即得 O(1/(γT)) 项（标准 ACI 结论）。关键限制：该界是**边际**的，允许在任意有限窗口内显著偏离 α——这直接给出定理 5 的风险。∎

**引理 89（鲁棒证书可靠性，升级引理 82）** 设 F̂ 对 (s,a) 为 L-Lipschitz，真实输入扰动 ‖δ‖≤ε，且共形界 |F−F̂|≤β_t 以概率 ≥1−α 成立。则对块内任意 k：
```
g_k ≥ ĝ_min^rob = ĝ_min − (Lε+β_t),    e_k ≤ ê_max^rob = ê_max + (Lε+β_t)
```
以概率 ≥1−α 成立，故块证书保守有效；结合定义 534 的停车不变式，中块突变仍可切换到 p*∈P_t 安全停驻。证明：|F−F̂| ≤ |F−F̂(x̂)| + |F̂(x̂)−F̂(x)| ≤ β_t + L‖δ‖ ≤ β_t+Lε；对间隙取下界、代价取上界即得。v9 引理 82 是 ε=0、β_t≡β 的特例。∎

**引理 90（CUSUM 检测延迟与虚警）** 设漂移前后残差均值 μ₀<μ₁，容忍参数 k<(μ₁−μ₀)/2，阈值 h。则期望检测延迟 ≤ h/(μ₁−μ₀−k)+O(1)，虚警平均运行长度随 h 指数增长。对比 v9 的 20 帧滑窗：强漂移下 IRC 可在 3–6 个控制周期报警，而滑窗版本存在约半窗（~10 周期）的固有平滑滞后。故 Δ_dom^eff 把 v9 最大风险中的「检测滞后」从结构性问题降为可调参数问题。∎

**引理 91（STA 安全回滚不变式）** STA 仅改 θ_adapt，Θ_safe 冻结；候选提交受信任域与影子覆盖双重约束，回滚恢复 snapshot。故在任一提交点，部署参数的影子覆盖 ≥1−α−η；回滚后参数逐位等于上次已接受快照。当适配不活动或回滚时，系统行为与 v9 无适配路径逐位一致；安全关键的证书检查器未被修改，故 v8/v9 的安全引理原样传递。注意影子覆盖是**经验证据**而非定理，其代表性由 B_shadow 的采样策略保证（见风险）。∎

**引理 92（零样本退化格与 v9 逐位等价，升级引理 83）** 定义 548 给出 v10 每个组件到 v9 回退配置的映射：ZSC→β_fixed、WCP→w≡1、ACI→α 固定、IRC→v8 滑窗、RCI→ε=0、STA→θ₀。逐项代入后证书 Ĉ→Ĉ_v9、决策→v9 决策，故可观测日志逐位等价；再由 v9 引理 83 退回 v8。由于每个组件在失效时输出其回退值（而非任意值），退化格是**乘积偏序**且底元素为 v9，故 v10 任意失效组合的行为 ∈ v9 退化格。∎

**推论 93（端到端安全传递）** 若安全关键链（M₀、SpatialCert、FaultCert、MW、AC guard）完整，则 v10 任一运行状态或与 v9 逐位等价（引理 92），或持有覆盖 ≥1−α 的膨胀证书（引理 87+89）；M₀ 只消费膨胀界（定义 544/升级 531），因此 v8 的安全不变式在所有 v10 状态下成立。∎
