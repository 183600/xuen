# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「运动控制」×「泛化能力」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"——MFSL 摊销先验 + 共形保底、XMC 分账对账、PTM 单向信任、FSE 五类证据门，使单点坏证据难以独力产生承诺；但它的风险自陈指向两个尚未闭合的缺口：**(a) 证据是静态的，动作是动态的**——所有证据都在检查点上回答"世界是否如我所信"，却从不回答"是否存在一个反馈控制律，能在扰动、跟踪误差、接触切换与执行器饱和下，把这条承诺真正安全地走完"；一个点态安全的落点可能动态不可行（滑移、翻边、载荷转移），而步态选择只在事后降档，无法把"运动裕度"当作证据来花；**(b) 泛化是边际的，覆盖是平均的**——摊销先验与共形覆盖只对校准分布平均成立（可交换性假设），一旦部署发生"支撑集内漂移"（新载荷、磨损、季节、地形配比变化），最需要保证的最差组条件覆盖可能恰好崩塌；OOD 门只识别"分布外"，识别不了"分布内但已漂移"，于是"泛化"始终是一个未经证伪的不变性假设。更危险的是二者相乘：泛化省下的探针预算，最终要靠运动控制的鲁棒裕度去吸收；若世界模型与动力学模型由同一份有限语料辨识，二者的误差会同源、同向、同时失效。本轮两个灵感各补一条腿：**运动控制**把"动作"变成可验证的执行证书与连续的运动整形旋钮；**泛化能力**把"泛化"变成群条件、可在线证伪的不变性契约。核心命题由"证据说可信"升级为 **"动作可执行、泛化可证伪的证据说可信"**。

核心矛盾：
- **H32（静态证据 vs 动态可行）**：点态世界证据 ≠ 轨迹级安全。静止时安全的接触可能动态不可行（滑移/翻边/载荷转移）；证据门量化的是"世界信念错没错"，从不量化"执行这条承诺会不会因跟踪误差、扰动与模型误差而出界"。安全被证明在一个点上，却被消耗在一条轨迹上。
- **H33（边际覆盖 vs 条件泛化）**：共形覆盖是边际的、依赖可交换性；支撑集内漂移可让最差组条件覆盖崩塌。元先验越敢泛化，越是在赌"不变性成立"，而不变性从未被在线检验；OOD 门与漂移门是两件事。
- **H34（泛化省探针 vs 执行耗裕度）**：泛化减少探针，运动消耗裕度；若世界模型与动力学模型同源辨识，两个安全层会因同源误差而一起失效。简单 union bound 在误差相关时是乐观的——"多层纵深"可能只是同一层被数了两遍。

## 0. 直觉与动机

**灵感 1（运动控制 → 执行证书与连续运动整形）**
直觉：第 57 轮的"承诺"是一个离散落点，像一个点；真实的承诺是一条闭环轨迹，像一根管（tube）。世界证据只保证"这个点看起来能踩"，运动控制才回答"从当前状态出发，是否存在一个反馈律，使整根管子在扰动与模型误差内都不越出安全集"。于是把"可执行性"升级为一类证据：用鲁棒控制屏障函数（CBF）/管道 MPC/可达性分析，给出**执行证书** E_dyn=(管半径 ρ_tube, 衰减 γ, 扰动界 𝒲, 模型误差界 ℰ, 控制律类 Π)，并定义**运动裕度** μ_dyn 为整条管到安全边界的最近距离减去扰动/误差膨胀。μ_dyn≥0 才允许承诺。运动控制还送来第 57 轮没有的一组**连续旋钮**：降速、加宽支撑/步距、提高阻抗、缩短步长、降低重心——不是"承诺/绕行"的二值选择，而是在保持任务的同时把 μ_dyn 买回来。于是"降档"从离散动作变成"运动整形"这一连续安全通道。

**灵感 2（泛化能力 → 群条件泛化证书）**
直觉：共形带回答"平均覆盖多少"，但安全关心"最差那一组覆盖多少"。泛化能力给的正确问法不是"模型能否迁移"，而是"在哪些群上、以多大置信度、迁移结论可以被证伪"。把环境按**声明的群** 𝒢（地形物理类型×载荷×磨损/季节）分层，用 Mondrian/群条件共形给出每组覆盖 ≥1−α_g，再用分布鲁棒优化（DRO）在显式模糊集 𝒫_ε 上约束最差组风险 sup_{P∈𝒫_ε} E_P[ℓ]≤ε_g。证书是一份**对群生效的契约**，不是对平均生效的口号。关键是从"相关性特征"退到**不变性特征** z_inv（地形物理量而非外观纹理），因为只有跨环境稳定的特征才配被泛化。

**灵感 3（泛化门 → 区分分布外与分布内漂移）**
直觉：OOD 门像"你不在我的城市"，真正的危险常是"你还在我的城市，只是这条街变了"。泛化门 DGG 用密度比/MMD 把状态分三档：ID（分布内且无漂移，可用摊销先验+群证书）、SHIFT（分布内但漂移，禁止跨区域泛化、加宽管、退回局部重证）、OOD（分布外，退回第 57 轮共形带）。更进一步，每条"不变性声明"都配一个**在线证伪器**：监控不变性残差与环境标签的相关性是否非平稳；检验拒绝即吊销受影响群的泛化证书。泛化从此不是静态假设，而是必须持续通过检验的假设。

**灵感 4（合流 → 承诺可行域 = 证据有效域 ∩ 动态可行域）**
直觉：把两个新机制写成同一个几何对象。**证据有效域** Ω_ev：世界证据成立且所在群有证书的状态集；**动态可行域** Ω_dyn：存在控制律使鲁棒不变式成立的状态集；**承诺可行域** Ω_commit=Ω_ev∩Ω_dyn。承诺合法 ⇔ 初始状态与整条管都留在 Ω_commit。泛化只在"不变性通过证伪"时扩大 Ω_ev，运动整形只在"保守方向"扩大 Ω_dyn——两者都是**有条件的、可撤销的扩张**。若同源误差同时收缩两者，交集会超线性收缩，这正是 H34 的几何表述。

**灵感 5（PCE+++ → 双不确定性 VOI 与动态探针）**
直觉：探询预算现在分两种不确定性：认识不确定性（世界是什么）与执行不确定性（动力学参数/扰动界是多少）。**动态探针** DProbe 用小幅、可逆、带力/能量包络的激励运动辨识摩擦、柔顺、载荷，直接收缩 ρ_tube；VOI 相应分成 VOI_world 与 VOI_dyn，并泛化感知地优先探"最差组"的区域。三种预算（探针 k_p、动态探针 k_dyn、运动裕度 μ_dyn）同向保守、有限终止。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（执行证书与承诺可行域 EDC）** 离散动力学 x_{t+1}=f(x_t,u_t)+w_t，w_t∈𝒲，模型误差 e=f̂−f∈ℰ；安全集 𝒮={x:h_i(x)≥0} 同时含几何（落点/越障）与动态（摩擦锥、支撑多边形/ZMP、滑移裕度、关节力矩上限）约束。鲁棒 CBF 条件 h_i(x_{t+1})≥(1−γ)h_i(x_t)−b_i(𝒲,ℰ)。执行证书 E_dyn=(ρ_tube,γ,𝒲,ℰ,Π)：存在 π∈Π 使鲁棒不变式在时域 H 内成立；运动裕度 μ_dyn(r,π)=min_{t≤H} h_min(x_t)−b(𝒲,ℰ)。承诺可行域 Ω_commit=Ω_ev∩Ω_dyn，Ω_dyn={x:∃π, μ_dyn≥0}。承诺合法 ⇔ x_0∈Ω_commit 且管 {x_t} 全程留在 Ω_commit；E_dyn 失效概率上界 δ_dyn。

**定义 140（群条件泛化证书 GRC）** 声明群 𝒢=地形物理类型×载荷×磨损/季节；不变性特征 z_inv；模糊集 𝒫_ε={P:D_f(P‖P̂)≤ε 或 W_1(P,P̂)≤ε}。群条件共形：∀g∈𝒢，P_g(ℓ≤q_g)≥1−α_g（有限样本、按 |g| 校正）；DRO 最差组风险 sup_{P∈𝒫_ε}E_P[ℓ]≤ε_g。证书 GRC=(𝒢,{α_g},{ε_g},𝒫_ε,z_inv)，只对已声明且有校准数据的群签发；未声明群无证书。

**定义 141（泛化门与不变性证伪 DGG）** 漂移统计 S(o)=密度比 p_deploy/p_cal 或 MMD(z_inv)；三档：ID（n(o)≤θ_ood ∧ S≤θ_shift）用摊销后验+GRC；SHIFT（n≤θ_ood ∧ S>θ_shift）禁跨区域泛化、加宽 ρ_tube、局部重证；OOD（n>θ_ood）退回共形带（第 57 轮）。不变性证伪器：对每条 z_inv 监控残差 r_inv 与环境标签的相关性检验，拒绝 ⇒ 吊销受影响群 GRC 并审计。泛化证书因此是"可在线撤销"的。

**定义 142（动态探针 DProbe）** 可逆激励 u_exc(t) 满足包络 |τ|≤τ_exc、位移≤d_exc、时长≤Δt_exc、且 μ_dyn≥μ_min；用于辨识摩擦 μ、柔顺 k、载荷 m，更新 (𝒲,ℰ) 以收缩 ρ_tube。预算 k_dyn/区域，能量 E_exc 计入总预算。**安全接触与辨识分离**：承诺运动与激励运动不得混用；激励若处于柔顺遮蔽段，其观测不得作为刚度/不可逆证据。

**定义 143（执行-泛化证据门 EGG / FSE++）** 证据类 = 第 57 轮 {EV-probe\*,EV-visit,EV-margin,EV-xmodal(限 L1),EV-human} + **EV-dyn**（须 E_dyn 且 μ_dyn≥0）+ **EV-gen**（群证书，仅可减少所需探针数，永不豁免世界/执行证据）。不可逆接触必要证据集 = 世界证据 ∧ EV-dyn ∧ (群 g 有 GRC 或已切局部重证)。证书 J_g=(J_p 全部字段, dyn_cert_log, tube_log, disturbance_log, group_cert_log, shift_log, invariance_log, dprobe_log, motion_margin_log, corr_audit_log)。

**定义 144（运动-泛化算子 MGP / PCE+++）** 每检查点：①世界推断（MFSL/XMC）；②泛化门（ID/SHIFT/OOD）与群证书；③执行证书与 μ_dyn；④若 μ_dyn<0 先做**运动整形**（降速/加宽/增阻抗/降重心），再考虑绕行/降档；⑤承诺 ⇔ 世界证据 ∧ E_dyn ∧ 群证书过；否则按双不确定性 VOI 选探针（含 DProbe）或整形/绕行/L2；⑥预算 (k_p,k_dyn,E_exc) 与整形幅度有界，有限终止。

## 2. 关键算法伪代码（完整版见产物区）

```python
def exec_cert(x0, plan, M, W, E):                   # IP-139
    tube = robust_tube(x0, plan, W, E)              # CBF / tube-MPC
    mu = min(safe_margin(x) for x in tube) - inflate(W, E)
    return Cert(tube, mu, ok=(mu >= 0)), mu

def gen_gate(obs, meta, g):                          # IP-140/141
    if ood_score(obs, meta) > theta_ood:
        return 'OOD', conformal_belt(meta, obs)
    if shift_stat(obs, meta, z_inv) > theta_shift or not falsifier_ok(g):
        revoke(GRC[g]); return 'SHIFT', local_only(meta, g)
    return 'ID', GRC[g]

def motion_generalization_commit(x0, M, task, budget):   # IP-144
    for cp in route.checkpoints:
        world = world_infer(M, cp)                  # 第 57 轮 MFSL/XMC
        reg, cert = gen_gate(M.obs[cp], M.meta, cp.group)
        dc, mu = exec_cert(x0, plan(cp), M, M.W, M.E)
        while mu < 0 and budget.shape_left > 0:     # 先整形，再绕行
            plan[cp] = conservative_reshape(plan[cp]); dc, mu = exec_cert(x0, plan[cp], M, M.W, M.E)
        if world.ok and dc.ok and cert.ok: commit(plan[cp]); continue
        p = argmax(cands, key=lambda q: voi_dual(q, world, dc) - cost(q))
        M = run_probe_or_dprobe(p, M); budget.spend(p)
    return schedule(M)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| EDC | O(H·n_x²) 每规划；管 O(H·N_tube) | O(H·n_x) | μ_dyn 为下界、膨胀不低估（A41） |
| GRC | O(\|𝒢\|·N_cal) 每证书 | O(N_cal) | 群覆盖诚实、模糊集包含或漂移被检出（A42） |
| DGG | O(d·N_ref) 密度比/MMD | O(N_ref) | 漂移漏检≤δ_shift、证伪即吊销（A43） |
| DProbe | O(1)/tick；O(k_dyn) | O(k_dyn) | 包络内、可逆、证据分离（A44） |
| EGG | O(\|σ\|) | O(\|σ\|) | 无证据类即拒、EV-gen 不豁免世界/执行 |
| MGP | O(\|CP\|·((k_p+k_dyn)·C_VOI+H·n_x²)+\|CP\|·A\*) | O(\|V\|+H·n_x) | 双不确定性 VOI、预算终止 |

**正确性定理（Motion-Generalization Provable Soundness, MGPS 概要）**：在 A33–A40 上加 (A41) E_dyn 诚实、管膨胀不低估、μ_dyn 为下界；(A42) GRC 诚实：群划分覆盖真实部署群、群条件覆盖有限样本成立、模糊集 𝒫_ε 含真实漂移或 DGG 检出；(A43) DGG/不变性证伪器可靠，漂移漏检 ≤δ_shift；(A44) DProbe 在包络内、可逆且不作不可逆/刚度遮蔽证据；(A45) 运动整形只向保守，世界/动力学残差相关性 ρ_corr 可在线估计。则：
(i) **世界路径**沿用第 57 轮界 δ_world=δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]；
(ii) **执行路径**贡献 ≤δ_dyn（w∉𝒲、e∉ℰ 或管逃逸）；
(iii) **泛化路径**贡献 ≤δ_gen+δ_shift（群覆盖缺口 + 漂移/证伪漏检）；
(iv) **相关修正（新）**：简单相加只在残差独立时成立；当 ρ_corr>θ_corr，以 δ_world+δ_dyn+δ_corr 取代二者之和，或强制局部重证并改用 DProbe 的独立数据辨识动力学；
(v) **单调性**：泛化只减少所需探针或加宽不确定性，执行只增加约束，运动整形只向保守，三机制均无升险路径；
(vi) **终止性**：k_p、k_dyn、E_exc 与整形幅度有界，MGP 有限步终止于 {承诺, 整形后承诺, 绕行, L2, 安全停}。

## 6. 本轮最大风险

**一句话**：本轮把安全从"证据正确"推进到"动作可执行且泛化可证伪"，但执行证书与泛化证书都建立在同一份有限语料辨识出的动力学模型与模糊集上——当真实世界落在未声明的群或模糊集之外时，世界信念、动力学模型与泛化证书会同时错误并互相印证，使系统自信地执行一个动态不可行或条件覆盖已失效的动作；唯一兜底是让证书在线可证伪、让运动整形只向保守、并坚持"未声明群一律退回局部重证、动力学辨识数据与世界语料分离"。

### IP-139 EDC（执行证书与承诺可行域）

```python
def execution_certificate(x0, plan, M, W, E, Pi, H):
    tube = robust_reachable_tube(x0, plan, W, E, horizon=H)   # 反向可达集 / tube-MPC
    mu = min(safe_margin(x, M.S) for x in tube) - inflate(W, E)
    ok = (mu >= 0) and cbf_feasible(tube, W, E, Pi)
    return E_dyn(tube=tube, mu=mu, W=W, E=E, Pi=Pi, ok=ok), mu

def conservative_reshape(plan, knob, bounds):
    # 只向保守：降速、加宽支撑、提阻抗、缩步长、降重心
    p = plan.with_(speed=plan.speed*(1-alpha_s),
                   stance=plan.stance+delta_st,
                   K_imp=plan.K_imp*(1+alpha_k),
                   step=plan.step*(1-alpha_l),
                   com_h=plan.com_h*(1-alpha_c))
    return p if within_bounds(p, bounds) else None

def commit_viable(x0, plan, M):
    cert, mu = execution_certificate(x0, plan, M, M.W, M.E, M.Pi, M.H)
    return cert.ok and all(x in M.Omega_commit for x in cert.tube), cert
```

### IP-140 GRC（群条件泛化证书）

```python
def group_certificate(cal, groups, alpha_g, eps_g, P_eps, z_inv):
    GRC = {}
    for g in groups:
        if len(cal[g]) < n_min:            # 未声明/样本不足：不签发
            continue
        q_g = mondrian_quantile(cal[g], level=1-alpha_g)      # 按 |g| 有限样本校正
        dro = dro_dual_bound(cal[g], P_eps, loss)             # sup_{P in P_eps} E_P[loss]
        GRC[g] = Cert(g=g, q=q_g, alpha=alpha_g,
                      eps=max(dro, eps_g), z_inv=z_inv, valid=True)
    return GRC

def group_conditional_risk(GRC, sched):
    # 承诺前取所有涉事群的最差组，而不是样本平均
    return max((GRC[c.group].eps for c in sched if c.group in GRC), default=INF)
```

### IP-141 DGG（泛化门与不变性证伪）

```python
def generalization_gate(obs, meta, g):
    n = ood_score(obs, meta)
    S = max(density_ratio(obs, meta.cal, z_inv=meta.z_inv),
            mmd(obs, meta.cal, z_inv=meta.z_inv))
    if n > theta_ood:                                    # 分布外
        return Regime('OOD', belt=conformal_belt(meta.res, sim=ctx(obs),
                                                 alpha=alpha_conf))
    if S > theta_shift or not invariance_falsifier(meta, g):
        meta.GRC.pop(g, None)                            # 吊销证书
        meta.audit.log(('revoke', g, t_now, S))
        return Regime('SHIFT', local_only=True, widen_tube=True)
    return Regime('ID', grc=meta.GRC[g])

def invariance_falsifier(meta, g):
    r = meta.inv_residuals[g]
    # 不变性残差必须平稳且与外观/环境标签不相关，否则不变性被证伪
    return stationarity_test(r) and not label_corr_test(r, meta.env_labels)
```

### IP-142 DProbe（动态探针与独立系统辨识）

```python
def dynamic_probe(region, M, budget):
    u_exc = design_excitation(freq=M.exc_freq, amp=M.exc_amp, duration=M.dt_exc)
    if not within_envelope(u_exc, tau_exc, d_exc, dt_exc):
        return None

    if mu < mu_min:                                      # 探针本身也必须安全
        return None
    obs = execute(u_exc)

    return Evidence('EV-dprobe', obs, theta, independent=True)
```

### IP-143 EGG（执行-泛化证据门 + 证书 J_g）

```python
def executable_generalization_gate(c, M, persona, ood_reg, GRC):
    if c.ev == 'EV-dyn':
        ok = c.dyn.ok and c.dyn.mu >= 0
    elif c.ev == 'EV-gen':
        ok = (c.group in GRC and GRC[c.group].valid)     # 只减探针，不豁免
    elif c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round57_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok:
        return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev == 'EV-gen':
        return ('reject', 'gen_cannot_waive', c)         # 泛化永不单独充分
    return ('ok', c)

def certificate_jg(sched, log, M, consent_log, auth_log, ood_reg):
    for c in contacts(sched):
        st = executable_generalization_gate(c, M, persona_of(c), ood_reg, M.GRC)
        if st[0] != 'ok':
            return st
    for c in irreversible(sched):                        # 不可逆接触三重必要条件
        world = has_world_evidence(c, M)

        gen   = (c.group in M.GRC and M.GRC[c.group].valid) or local_only(c, M)
        if not (world and dyn and gen):
            return ('reject', 'commit_viability', c)
    if rho_corr(M) > theta_corr:                         # 相关失效显式记账
        M.corr_audit.flag('correlated_world_dyn')
        if not independent_dynamics_data(M):
            return ('reject', 'correlation_unaccounted', None)
    if not all(l2.resolved for l2 in consent_log):
        return ('reject', 'consent_open', None)
    return ('ok', Jg(M.Omega_commit, M.dyn_cert_log, M.tube_log, M.group_cert_log,
                     M.shift_log, M.invariance_log, M.dprobe_log, M.corr_audit_log,
```

### IP-144 MGP（探-诺-演+++：双不确定性 VOI × 运动整形 × 泛化门）

```python
def motion_generalization_probe_commit_evolve(x0, M, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        world = meta_infer_and_fuse(M, cp.region, M.obs[cp.region], M.meta)   # IP-133/134
        reg = generalization_gate(M.obs[cp.region], M.meta, cp.group)         # IP-141
        plan_cp = foothold_schedule(x0, cp, M)
        cert, mu = execution_certificate(x0, plan_cp, M, M.W, M.E, M.Pi, M.H) # IP-139

        while mu < 0 and budget.shape_left > 0:          # 先整形，再绕行/降档
            plan_cp = conservative_reshape(plan_cp, next_knob(M), M.bounds)
            if plan_cp is None: break
            budget.spend_shape()
            cert, mu = execution_certificate(x0, plan_cp, M, M.W, M.E, M.Pi, M.H)

        committed = (world.ok and cert.ok and
                     ((reg.regime == 'ID' and reg.grc.valid) or
                      (reg.regime == 'SHIFT' and local_evidence_ok(cp, M))))
        if committed:
            sched.append(commit(plan_cp, tube=cert.tube)); log.append((world, cert, reg))
            continue

        while budget.probes_left > 0 or budget.dyn_left > 0:   # 双不确定性探询
            cands = admissible_probes(cp, M, F_abs) + admissible_dprobes(cp, M)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_dual(q, world, cert) - cost(q))
            if voi_dual(p, world, cert) < theta_voi: break
            if is_dprobe(p):
                M, ev = dynamic_probe(cp.region, M, budget)        # IP-142
            else:
                M, ev = run_static_probe(p, M)                     # 第 57 轮
            world = meta_infer_and_fuse(M, cp.region, M.obs[cp.region], M.meta)
            cert, mu = execution_certificate(x0, plan_cp, M, M.W, M.E, M.Pi, M.H)

        alt = reroute(M, cp, risk_model)
        if alt and commit_viable(x0, alt, M)[0]:
            route = alt; continue
        return negotiate_or_stop(cp, M, plan_cp, cert, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EDC | O(H·n_x²) 每规划；管 O(H·N_tube) | O(H·n_x) | μ_dyn 为下界、膨胀不低估（A41） |
| GRC | O(\|𝒢\|·N_cal) 每证书 | O(N_cal) | 群覆盖诚实、模糊集包含或漂移被检出（A42） |
| DGG | O(d·N_ref) 密度比/MMD | O(N_ref) | 漂移漏检 ≤δ_shift、证伪即吊销（A43） |
| DProbe | O(1)/tick；O(k_dyn) | O(k_dyn) | 包络内、可逆、证据分离（A44） |
| EGG | O(\|σ\|) | O(\|σ\|) | 无证据类即拒、EV-gen 不豁免世界/执行 |
| MGP | O(\|CP\|·((k_p+k_dyn)·C_VOI+H·n_x²)+\|CP\|·A\*) | O(\|V\|+H·n_x) | 双不确定性 VOI、预算终止、四态完备 |

**正确性定理（Motion-Generalization Provable Soundness, MGPS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 执行证书诚实：鲁棒不变式对 ∀w∈𝒲、e∈ℰ 成立，管计算不低估膨胀，μ_dyn 为下界；**(A42)** 泛化证书诚实：群划分覆盖真实部署群、群条件覆盖有限样本成立、模糊集 𝒫_ε 含真实漂移或 DGG 检出；**(A43)** DGG 与不变性证伪器可靠：漂移漏检 ≤δ_shift，证伪拒绝即吊销；**(A44)** DProbe 在力/能量/位移包络内、可逆，且其观测不作不可逆接触或刚度遮蔽段证据；**(A45)** 运动整形只向保守，世界/动力学残差相关性 ρ_corr 可在线估计。则：

1. **世界路径**：非执行、非泛化承诺失效率沿用第 57 轮
   `δ_world = δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]`。
2. **执行路径**：轨迹级失效（w∉𝒲 ∨ e∉ℰ ∨ 管逃逸）概率 ≤δ_dyn；μ_dyn≥0 且管留 Ω_commit 时，动态失效被证书吸收。
3. **泛化路径**：最差组失效 ≤δ_gen+δ_shift，其中 δ_gen=max_g(1−(1−α_g)) 的联合修正，δ_shift 为漂移/证伪漏检。
4. **相关失效修正（本轮关键）**：简单 union bound 仅当世界残差与动力学残差独立时成立；当 ρ_corr>θ_corr，以 `δ_world+δ_dyn+δ_corr` 取代二者之和（δ_corr=f(ρ_corr)），或强制局部重证并改用 DProbe 的独立数据辨识动力学。**"多层纵深"只有在误差独立时才是多层。**
5. **交互单调性强化**：泛化只减少所需探针或加宽不确定性，执行只增加约束，运动整形只向保守；不存在升险路径；OOD/SHIFT 只会让 L2 更快落入保守默认。
6. **终止性**：k_p、k_dyn、E_exc 与整形幅度有界，MGP 在有限步内终止于 {承诺, 整形后承诺, 绕行, L2 协商, 安全停}。

**部署界**（对检查点取联合界，相关项显式写出）：

```
P_safe ≥ 1 − Σ_cp [ δ_world(cp) + δ_dyn(cp) + δ_gen(cp) + δ_shift(cp) + δ_corr(cp) ]
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(tube 计算/时延失败) − P(整形失效 ∧ 安全停失效)
```

关键：**世界给信念、运动给可执行性、泛化给条件契约**——三者各自有独立数据与独立证伪通道，安全不再押在"世界判断永远正确"上，而押在"错误被哪条独立通道先发现、且其代价被哪条通道封顶"上。

## 6. 本轮最大风险

**一句话**：本轮把安全从"证据正确"推进到"动作可执行且泛化可证伪"，但执行证书与泛化证书都建立在同一份有限语料辨识出的动力学模型与模糊集上——当真实世界落在未声明的群或模糊集之外时，世界信念、动力学模型与泛化证书会同时错误并互相印证，使系统自信地执行一个动态不可行或条件覆盖已失效的动作；唯一兜底是让证书在线可证伪、让运动整形只向保守、并坚持"未声明群一律退回局部重证、动力学辨识数据与世界语料分离"。
