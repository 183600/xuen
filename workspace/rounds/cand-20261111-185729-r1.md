# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「材料选型」×「鲁棒性」）

> 第 54 轮把技能组合推进为动作-鲁棒性双证书 `(α_S, A_cert, γ_ce, δ_a, ρ)`。但整套证书默认了一个未言明的前提：**硬件材料是固定、标称、不退化、可替换的**。本轮把材料显式提升为一等变量：材料选型不是采购环节，而是鲁棒性证书的**前提条件**。核心矛盾：H22：`α_S(a)` 实为 `α_S(a|m)`，同一技能换材料后动作可行域与鲁棒谱同时漂移，第 54 轮证书在批次角点与磨损后系统性失效；H23：按数据手册标称值做成本最优选型，会在材料不确定集角点上把“认证通过”变成“实物失效”。

## 0. 直觉与动机

**灵感 1（材料是动作剖面的隐藏变量）**
直觉：第 54 轮把技能看成动作空间 `A` 上的占用剖面 `α_S`，好像这是技能的固有属性。但“能不能抓起来”取决于摩擦系数 `μ` 是否落在摩擦锥内，“能不能插进去”取决于材料刚度 `E` 决定的接触力带宽与形变时序。因此 `α_S(a)` 只是某个标称材料 `m0` 下的一张切片，真实对象是 **材料条件剖面 `α_S(a|m)`**。材料一换，动作可行域先变，鲁棒谱随后跟着变；第 54 轮证书不是“错了”，而是“缺了量词”：它只证明了 `∃m0`，没有证明 `∀m∈U`。

**灵感 2（材料选型 = 最坏情况约束优化，而非标称最优）**
直觉：工程师按数据手册标称值挑最便宜且“参数达标”的材料，这在单件样机上常常成立；但量产时批次公差、温度漂移、供应商换料会让真实材料落在不确定集 `U` 的角点上。鲁棒选型要做的不是最大化标称性能，而是 **在 `U` 上取最坏情况后仍然满足动作覆盖、鲁棒谱与寿命约束**。这天然是一个带约束的 robust optimization：成本在目标里，鲁棒性在约束里，动作空间在可行域里。

**灵感 3（材料退化 = 鲁棒性的时间维度）**
直觉：材料不是常量。摩擦系数随磨损衰减 `μ(t)=μ0·e^{-ẇt}`，弹性模量随热循环与疲劳漂移，涂层会剥落。于是第 54 轮的“永久证书”在物理上是错的：每张证书都应带一个 **有效寿命 `T_exp`**，到期必须重认证或降额。把 `T_exp` 纳入选型，会把“稳态最优”推向“寿命内最优”，这正是材料选型与鲁棒性真正耦合的地方。

**灵感 4（材料替换 = 带距离度量的证书迁移，不能信局部梯度）**
直觉：供应链换料/国产替代时，最诱人的做法是“在标称点算一下局部敏感度，发现鲁棒谱只掉 0.02，于是放行”。但鲁棒谱对材料属性往往是非线性、甚至分段单调的（摩擦锥、屈曲、热失配），局部梯度会在角点严重低估风险。正确的做法是定义 **材料距离 `D_M`** 与 **全局 Lipschitz 上界 `L_M`**，用区间/角点给出替换后的鲁棒裕度上界；只有上界也在预算内才允许迁移。材料替换本质上是第 54 轮 JTC 的一个新维度，而不是一次“重新标定”。

**灵感 5（云边材料闭环）**
直觉：云端有材料数据库、数据手册、批次证书与接触仿真；边端有力/力矩、滑移、温度、振动传感。边端可以在线辨识当前材料状态 `m(t)` 与磨损率 `ẇ`，把证据回传云端，云端据此收缩/平移不确定集 `U` 并触发重选型或降额。这把第 54 轮的“云规划-边校验-反向解释-重剖分”闭环，扩展为 **材料辨识-不确定集更新-重选型** 的第二条闭环。

**灵感 6（材料金字塔层 𝕄）**
直觉：材料不是单一标量，而是分层对象：`𝕄_0` 原料本征属性，`𝕄_1` 批次/供应商波动，`𝕄_2` 装配界面（胶层、涂层、摩擦垫、热处理），`𝕄_3` 在役退化。跨层传递证书时必须同时传播 `(ρ, A_cert, m, U, T_exp)`，否则会出现“原料合格、界面失效、在役漂移”的三重断层。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（材料属性空间与不确定集）**
材料属性向量 `m = (μ, E, ν, k_th, α_t, ẇ, ...) ∈ M ⊆ ℝ^p`，分别对应摩擦系数、弹性模量、泊松比、热导率、热膨胀系数与磨损率。给定候选材料 `m0`，其批次-环境不确定集
```
U(m0) = { m ∈ B(m0) : (m-m0)^T Σ^{-1} (m-m0) ≤ ε² }
```
其中 `B(m0)` 为数据手册与工艺给出的盒约束（如 `μ∈[μ_lo,μ_hi]`、`E∈[E_lo,E_hi]`），`Σ` 为批次协方差。记 `diam_M(U) = max_{m,m'∈U} ||m-m'||_Σ`。**假设 (A29)**：真实材料 `m_true ∈ U` 的概率至少 `1-α_M`。

**定义 122（材料条件动作剖面与鲁棒覆盖）**
技能 `S` 的材料条件动作剖面 `α_S(a|m) ∈ [0,1]`，`α_S(a|m)=1` 当且仅当在材料 `m` 下动作 `a` 可执行且接触力/热/形变约束全部满足。材料鲁棒覆盖
```
cover_rob(S, A_T, U) = 1  ⇔  ∀ m∈U, ∀ a∈A_T : α_S(a|m) ≥ θ_cov
```
第 54 轮的 `α_S(a)` 只是 `α_S(a|m0)` 的标称切片，缺少 `∀m∈U` 量词。

**定义 123（材料条件鲁棒性谱与鲁棒组合）**
材料条件鲁棒谱 `ρ_S(d|m)`；材料最坏谱 `ρ_S^-(d) = inf_{m∈U} ρ_S(d|m)`。由于第 54 轮的耦合矩阵现在也依赖材料，记为 `K(m)`。组合鲁棒谱
```
ρ_comp^-(d) = inf_{m∈U} compose( ρ_{S_1}(·|m), ..., ρ_{S_k}(·|m); K(m) )
```
只有当 `∀d: ρ_comp^-(d) ≥ ρ_min(d)` 时，组合才在材料不确定意义下成立。

**定义 124（鲁棒材料选型问题 RMSS）**
```
m* = argmin_{m∈M_cand} [ cost(m) + λ · CVaR_β( lifecycle_loss(m) ) ]
s.t.  cover_rob(S, A_T, U(m)) = 1
      ∀d: ρ_comp^-(d|m) ≥ ρ_min(d)
      T_exp(m) ≥ T_req
      δ_a(m) ≤ Θ_a
```
记可行集为 `F_rob`。若 `F_rob = ∅`，不返回“无解”，而返回降额建议 `derate = (load↓, A_T↓, 界面升级, 增加纹理垫)`，把不可行转化为可执行的设计修改。

**定义 125（材料退化与有效寿命）**
退化算子 `D_t : M → M`，`m(t) = D_t(m0; load, env)`。标量示例：`μ(t)=μ0·e^{-ẇt}`，`E(t)=E0·(1-βt)`。有效寿命
```
T_exp(m) = inf { t ≥ 0 : ∃d, ρ_comp(d|m(t)) < ρ_min(d)  ∨  ¬cover_rob(S,A_T,{m(t)}) }
```
证书只在 `[0, T_exp]` 内有效；`T_exp` 之外必须重认证，禁止把“出厂证书”当作“永久证书”。

**定义 126（材料替换迁移证书 MST）**
材料距离（Mahalanobis）`D_M(m_s,m_t) = sqrt( Δm^T Σ_M^{-1} Δm )`。全局敏感度上界
```
L_M = sup_{m ∈ conv(U_s ∪ U_t)} || ∂ρ_comp/∂m ||_{Σ_M}
```
替换鲁棒裕度上界 `Δρ_ub = L_M·D_M + ½·L'_M·D_M²`（含曲率项）。迁移可行当且仅当 `Δρ_ub ≤ B_ρ` 且目标材料角点验证通过。定义 **材料汇率** `E_M = B_ρ / L_M`，即每单位鲁棒预算可容忍的材料距离；`D_M > E_M` 时任何“局部看起来没事”的替换都必须拒绝。

**定义 127（材料-动作-鲁棒性联合证书）**
```
J_M = ( J, m*, U, T_exp, L_M, E_M, evidence_M )
```
其中 `J` 为第 54 轮联合证书 `(ρ, A_cert, γ_ce, δ_a)`；`evidence_M` 至少包含数据手册、批次抽检、边端在线辨识与加速老化实验。**可部署条件**：
```
dom_J(T)=in  ∧  δ_a < Θ_a  ∧  T_req ≤ T_exp  ∧  Δρ_ub ≤ B_ρ
```

## 2. 关键算法伪代码

### IP-121 MSC（Material Space Characterization）

```python
def material_characterize(skill, cand, datasheet, lot_tests, env_range, theta_cov):
    U = box_union(datasheet.tolerance, lot_stats(lot_tests, 0.01, 0.99), env_range)
    Omega = (corners(U)                                # 盒角点，单调属性取上下界
             | quantile_scenarios(lot_tests, [0.01, 0.5, 0.99])
             | eps_net(U, n_samples))                  # 非单调维补 eps-net
    prof, spec = {}, {}
    for m in Omega:
        prof[m] = {a: skill.can_execute(a, m) for a in A_T}
        spec[m] = {d: robustness_spectrum(skill, d, m) for d in D}
    alpha_min = {a: min(prof[m][a] for m in Omega) for a in A_T}
    rho_minus = {d: min(spec[m][d] for m in Omega) for d in D}
    return MaterialEnvelope(U, Omega, alpha_min, rho_minus,
                            L_M=lipschitz_upper_bound(spec, Omega))
```

### IP-122 RMSS（Robust Material Selection Solver）

```python
def robust_material_select(cands, skill_seq, A_T, rho_min, T_req, theta_cov, K):
    feasible = []
    for m in sorted(cands, key=lambda x: x.cost):
        env = material_characterize_multi(skill_seq, m)      # 联合剖面/谱
        if not all(env.alpha_min[a] >= theta_cov for a in A_T):
            continue                                          # 动作覆盖剪枝
        rho_c = compose_robust_chain([s.rho for s in skill_seq], K, env.Omega)
        if any(rho_c[d] < rho_min[d] for d in rho_min):
            continue                                          # 鲁棒谱剪枝
        T_exp = effective_lifetime(m, skill_seq.load_profile, env, rho_min)
        if T_exp < T_req:
            continue                                          # 寿命剪枝
        feasible.append((m, env, rho_c, T_exp))
    if not feasible:
        return ('infeasible', derating_options(cands, A_T, rho_min, T_req))
    return min(feasible, key=lambda x: lifecycle_cost(x[0]))
```

### IP-123 MDT（Material Degradation Tracking）

```python
def material_state_update(state, obs, wear_model, dt, rho_min, T_req):
    # state = (m_t, w_t, P)；obs = 力/力矩/滑移/温度/振动
    m_t, w_t, P = bayes_update(state, obs)
    m_next = wear_model.predict(m_t, w_t, dt)
    rho_pred = predict_robustness(m_next, P)
    T_exp = time_to_threshold(m_next, w_t, rho_min, P)
    if margin(rho_pred) < buffer or (T_exp - t_now) < T_req:
        return ('re_certify', m_next, T_exp, explain_material_drift(state, obs))
    return ('ok', m_next, T_exp)
```

### IP-124 MST（Material Substitution Transfer）

```python
def material_transfer_cert(J_src, m_src, m_tgt, Sigma_M, B_rho, A_T):
    D_M = mahalanobis(m_src, m_tgt, Sigma_M)
    delta_ub = J_src.L_M * D_M + 0.5 * J_src.curvature * D_M**2
    if delta_ub > B_rho:
        return ('reject', 'budget_exceeded', delta_ub, E_M=J_src.B_rho / J_src.L_M)
    env_t = material_characterize_multi(J_src.skill_seq, m_tgt)
    if not corner_validate(env_t, J_src.rho_minus, B_rho):
        return ('reject', 'corner_fail', env_t.rho_minus)
    T_exp = min(J_src.T_exp, effective_lifetime(m_tgt, J_src.load_profile, env_t,
                                                J_src.rho_min))
    return ('ok', J_M(J_src.J, m_tgt, env_t.U, T_exp, J_src.L_M,
                      E_M=J_src.B_rho / J_src.L_M, evidence_M=env_t.evidence))
```

### IP-125 MRP（Material Robust Portfolio）

```python
def robust_material_portfolio(cands, k, supply_dist, A_T, rho_min, T_req):
    best = None
    for P in combinations(cands, k):
        worst = 0.0
        for scenario in supply_dist:                 # 供应商缺货/批次漂移情景
            if not any(mst_valid(src, sub) for src in P for sub in P if src is not sub):
                worst = float('inf'); break
            worst = max(worst, lifecycle_cost(P, scenario))
        if best is None or worst < best.worst:
            best = Portfolio(P, worst)
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MSC | O(|Ω|·(|A|+|D|)) | O(|Ω|·(|A|+|D|)) | 角点 + eps-net 对 U 的极值覆盖 |
| RMSS | O(|M|·|Ω|·(|A|+|D|)+|S|²) | O(|M|·|Ω|) | 最坏情况约束、寿命约束闭合 |
| MDT | O(|obs|·p²) / 更新 | O(p²) | 退化模型保守、观测可辨识 |
| MST | O(|Ω|·|D|) | O(|Ω|·|D|) | 全局 Lipschitz 上界、角点验证 |
| MRP | O(C(|M|,k)·|Σ_supply|·|M|²) | O(C(|M|,k)) | 替换边 MST 有效、情景覆盖 |

**正确性定理（Material-Robust Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：**(A29)** `m_true ∈ U(m*)` 的概率 ≥ `1-α_M`；**(A30)** `ρ_comp` 在 `U` 上 `L_M`-Lipschitz 且曲率有界；**(A31)** 退化模型保守，即 `T_exp` 是真实失效时间的下界；**(A32)** 情景集 `Ω` 覆盖 `U` 的盒极值（单调维必取上下界，非单调维 eps-net 误差 `β_Ω`）。则当 `m*` 满足定义 124 的四条约束时：
```
P_success ≥ 1 - Σ_d (1-ρ_min(d)) - β_E - P(δ_a > Θ_a) - α_M - β_Ω
```
关键点：**材料不确定集把“点证书”升级为“集合证书”**；**寿命约束把“稳态证书”升级为“区间证书”**；**全局 Lipschitz 把“替换猜测”升级为“可验证迁移”**。

**合成 sanity check（玩具模型，仅验证机制，非真实实验）**
取 `μ_req=0.45`、`E*=110`、`ρ_min=0.85`，鲁棒谱 `ρ_d1=min(1,μ/μ_req)`、`ρ_d2=exp(-|ln(E/E*)|)`；三候选材料及批次方差如下：

| 材料 | 成本 | 标称 `(ρ_d1,ρ_d2)` | 最坏角点 `(ρ_d1,ρ_d2)` | 鲁棒可行 |
|---|---|---|---|---|
| M1 高端（var 5%） | 3.00 | (1.000, 0.982) | (1.000, 0.935) | 是 |
| M2 标准（var 10%） | 1.60 | (1.000, 1.000) | (1.000, 0.900) | 是 |
| M3 低价（var 18%） | 0.70 | (1.000, 0.982) | (0.875, 0.805) | **否** |

- 标称最优选 **M3（0.70）**；鲁棒最优选 **M2（1.60）**。低价材料在最坏批次角点上 `ρ_d2=0.805 < 0.85`，正是“标称合格、实物失效”。
- 替换 `M2 → M3`：标称/局部敏感度预测鲁棒谱仅掉 `0.018`，最坏角点实际掉 `0.195`，**局部梯度低估 10.7 倍**；若按局部梯度放行，必然踩坑。
- 加 30 天、`ẇ=0.0025/day` 的寿命约束：M2 最坏初始 `μ=0.450` 恰好等于 `μ_req`，`T_exp=0`；M1 最坏初始 `μ=0.494`，`T_exp=37.3d`，于是选型从 M2 上移到 M1。**稳态鲁棒 ≠ 寿命鲁棒**。

## 6. 本轮最大风险

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-MatRob++（MSC×RMSS×MDT×MST×MRP）

> 承接第 54 轮产物 v31。本轮在“动作-鲁棒性双证书”之上增加 **材料维度**，把材料选型从采购问题变为鲁棒性证书的前提条件。五个新增算子：
> - **MSC（Material Space Characterization）**：材料属性不确定集 `U` 与材料条件动作/鲁棒剖面；
> - **RMSS（Robust Material Selection Solver）**：最坏情况约束下的鲁棒选型（含寿命）；

> - **MST（Material Substitution Transfer）**：材料替换的区间/Lipschitz 迁移证书；
> - **MRP（Material Robust Portfolio）**：供应不确定下的多材料鲁棒组合。
>
> IP 编号：IP-121~IP-125（共 5 个新增），升级 IP-115/118/120 以纳入材料条件量词。

### IP-121 MSC

```python
def material_characterize(skill_seq, cand, datasheet, lot_tests, env_range):
    U = box_union(datasheet.tolerance, lot_stats(lot_tests, .01, .99), env_range)
    Omega = corners(U) | quantile_scenarios(lot_tests, [.01,.5,.99]) | eps_net(U, n)
    prof = {m: {a: all(s.can_execute(a, m) for s in skill_seq) for a in A_T}
            for m in Omega}
    spec = {m: {d: robustness_spectrum(skill_seq, d, m) for d in D} for m in Omega}
    alpha_min = {a: min(prof[m][a] for m in Omega) for a in A_T}
    rho_minus = {d: min(spec[m][d] for m in Omega) for d in D}
    return MaterialEnvelope(U, Omega, alpha_min, rho_minus,
                            L_M=lipschitz_upper_bound(spec, Omega),
                            evidence=datasheet + lot_tests)
```

### IP-122 RMSS

```python
def robust_material_select(cands, skill_seq, A_T, rho_min, T_req, theta_cov, K):
    feasible = []
    for m in sorted(cands, key=lambda x: x.cost):
        env = material_characterize(skill_seq, m, ...)
        if not all(env.alpha_min[a] >= theta_cov for a in A_T):
            continue
        rho_c = compose_robust_chain([s.rho for s in skill_seq], K, env.Omega)
        if any(rho_c[d] < rho_min[d] for d in rho_min):
            continue
        T_exp = effective_lifetime(m, skill_seq.load_profile, env, rho_min)
        if T_exp < T_req:
            continue
        feasible.append((m, env, rho_c, T_exp))
    if not feasible:
        return ('infeasible', derating_options(cands, A_T, rho_min, T_req))
    return min(feasible, key=lambda x: lifecycle_cost(x[0]))
```

### IP-124 MST

```python
def material_transfer_cert(J_src, m_src, m_tgt, Sigma_M, B_rho):
    D_M = mahalanobis(m_src, m_tgt, Sigma_M)
    delta_ub = J_src.L_M * D_M + 0.5 * J_src.curvature * D_M**2
    if delta_ub > B_rho:
        return ('reject', 'budget_exceeded', delta_ub, E_M=J_src.B_rho / J_src.L_M)
    env_t = material_characterize(J_src.skill_seq, m_tgt, ...)
    if not corner_validate(env_t, J_src.rho_minus, B_rho):
        return ('reject', 'corner_fail', env_t.rho_minus)
    T_exp = min(J_src.T_exp,
                effective_lifetime(m_tgt, J_src.load_profile, env_t, J_src.rho_min))
    return ('ok', J_M(J_src.J, m_tgt, env_t.U, T_exp, J_src.L_M,
                      E_M=J_src.B_rho / J_src.L_M, evidence_M=env_t.evidence))
```

### IP-125 MRP

```python
def robust_material_portfolio(cands, k, supply_dist, A_T, rho_min, T_req):
    best = None
    for P in combinations(cands, k):
        worst = 0.0
        for sc in supply_dist:
            if not any(mst_valid(src, sub) for src in P for sub in P if src is not sub):
                worst = float('inf'); break
            worst = max(worst, lifecycle_cost(P, sc))
        if best is None or worst < best.worst:
            best = Portfolio(P, worst)
    return best
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MSC | O(\|Ω\|·(\|A\|+\|D\|)) | O(\|Ω\|·(\|A\|+\|D\|)) | 角点覆盖盒极值，eps-net 误差 `β_Ω` |
| RMSS | O(\|M\|·\|Ω\|·(\|A\|+\|D\|)+\|S\|²) | O(\|M\|·\|Ω\|) | 最坏约束 + 寿命约束闭合，剪枝 sound |
| MDT | O(\|obs\|·p²) / 更新 | O(p²) | 后验校准、退化模型保守 |
| MST | O(\|Ω\|·\|D\|) | O(\|Ω\|·\|D\|) | 全局 `L_M` 上界 + 角点验证，不低估 |
| MRP | O(C(\|M\|,k)·\|Σ_supply\|·\|M\|²) | O(C(\|M\|,k)) | 供应情景与替换边覆盖 |

**正确性定理（Material-Robust Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `m_true∈U` 概率 ≥`1-α_M`；**(A30)** `ρ_comp` 在 `U` 上 `L_M`-Lipschitz 且曲率有界；**(A31)** 退化模型保守，`T_exp` 为真实失效下界；**(A32)** 情景集覆盖盒极值（非单调维 eps-net 误差 `β_Ω`）。则当 `m*` 满足定义 124 约束时：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a > Θ_a) - α_M - β_Ω
```
与第 54 轮相比，新增的 `α_M + β_Ω` 是材料维度的“诚实成本”：它显式承认材料不确定性与情景离散化误差，而不是把标称材料点当成真值。
