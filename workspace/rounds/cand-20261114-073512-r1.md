# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「手眼标定」×「桌面操作」）

> R69 学会了向外求证：看不清就看、拿不准就问、质感不明就摸。但它仍默默假设：**“看”和“动”共享一个已经校准好的坐标系**，而且这个坐标系一旦标定就是常量。桌面操作恰恰把这条假设推到极限——相机往往固定在桌面或头顶（eye-to-hand），机械臂、夹爪、桌面与物体构成一条长长的运动学链；一次碰撞、热漂、换夹爪、相机被碰歪，都会让手眼外参 `T_HE` 漂移。更隐蔽的是：**桌面任务本身会让标定退化**。反复做俯视抓取、平面推动，旋转轴近乎单一，某些外参方向永远不被激励，于是误差不产生残差，R68 的 COF 与 R69 的 FMA 都看不见它。
>
> 但桌面也给了前几轮没有的两件东西：
> - **桌面是标定参照物**：支撑平面、重力方向、已知的接触几何，以及抓取/放置/推动时自然发生的接触，都是免费且高精度的几何证据；
> - **任务决定哪些误差才要紧**：同一个 5mm 外参误差，对大块积木抓取无关痛痒，对 0.5mm 轴孔装配却是灾难。**标定不是“我准不准”，而是“对这次动作，我够不够准”。**
>
> 核心命题：**把手眼标定从一次性常数升级为 SE(3) 上的任务加权信念；用桌面支撑面与接触作为“接触锚点”持续更新它；用任务雅可比把标定不确定性投影到“这次动作真正在乎的子空间”；只有该子空间内的误差超出阈值且可被接触锚点辨识时，才主动做小幅接触标定；否则把不可辨识的残余并回 R68 的保守退避。当标定信念任务无关、完全可信或永不主动标定时，逐指令退化为 FLUID-RAS / R68。** 命名 **TABLE-RAS**（Task-Aware Belief over Lie-group Errors）。
>
> 一句话定位：R66 问“谁控制”，R67 问“未来怎样”，R68 问“我的测量还准吗”，R69 问“我该向谁求证”，R70 问“**我和这张桌子的几何关系，对眼前这个动作到底够不够准；桌面给我的证据是真的吗**”——桌面既可以是标尺，也可以是骗子。

## 0. 直觉与动机

**灵感 1（手眼标定 → 不确定性长在李群上，有方向、有相关、会漂）**
直觉：R68/R69 把“标定”当成一个标量残差或一个可收紧的 λ，但手眼外参 `T ∈ SE(3)` 的误差不是标量：它有一个 6 维协方差，某些方向大、某些方向小，而且相机噪声、运动学误差、接触误差会让这些方向相关。经典 AX=XB 告诉我们：只有当配对运动在旋转轴上足够丰富，X 才可辨识；只在桌面上做俯视抓取，旋转轴近乎单一，某些方向就落进零空间。于是“外参误差”不是均匀的雾，而是一根根有方向的“盲刺”：看不见，却会在特定动作上刺穿任务。

**灵感 2（桌面操作 → 桌子是天然的标定台，但也是退化源）**
直觉：桌面任务有两个相反的面。正面：桌面是已知的支撑平面，重力给出法向，接触点给出法向距离，夹爪/物体/桌面的接触是高频、廉价、精确的几何约束；固定相机（eye-to-hand）又让外参直接连到桌面坐标系。反面：桌面任务高度重复、运动受限（俯视、平面推、垂直放），激励不足；物体遮挡、反光、透明、纹理缺失让视觉在桌面附近最不可靠。**桌面的“可标定性”不是一个常数，而是任务、物体与运动共同决定的函数。** 这正好是前几轮没有的“任务诱导可观测性”。

**灵感 3（视觉与触觉互补 → 一个管切向，一个管法向）**
直觉：视觉在桌面平面内定位很好（切向），但对深度/法向的误差大；接触对法向距离极其敏感（压没压到、压多深），但对切向位置不敏感（在平面上滑一点看不出来）。把两者放在同一个几何约束里：视觉提供切向锚，接触提供法向锚；它们张成的子空间互补，合起来才把手眼外参的 6 个自由度逐步钉住。**R69 的“多模态交互”是选择看/问/触来消歧；R70 的“接触锚定”是把触觉当成标定的测量通道，而不只是任务的反馈。**

**灵感 4（任务相对标定 → 不需要全准，只需要对这次动作准）**
直觉：工程上追求“把外参标到 0.1mm”往往是错的。真正决定成败的是**任务雅可比**：抓大块积木时，外参的某些旋转误差只改变夹爪姿态几个毫弧度，任务不在乎；轴孔装配时，同一误差直接决定卡不卡。把标定协方差投影到任务敏感子空间，得到“有效标定不确定性” `U_cal^task = tr(Π_task Σ_T Π_task)`。这把“标定”从全局认证变成**按动作签发局部证书**：同一个信念，对不同动作可以一个放行、一个拦截。**resolution bonus 也随之任务化：不是“我标定了”，而是“这次动作所需的那个方向被锚住了”。**

**灵感 5（标定是双刃剑 → 错误的锚会制造自信）**
直觉：如果桌面先验是错的——桌面上铺了软布、桌面有坡度、玻璃/镜面产生鬼影平面、有人放了一个假标定板、或者接触点其实是物体而不是桌面——那么视觉与接触会在**错误的世界模型**里彼此一致。残差很小，协方差收缩得很快，系统于是“自信地错”。R69 的最大风险是“问错人比不问更危险”；R70 的对应风险是“**锚错地方比不锚更危险**，因为它把不确定变成了确定的错误”。所以本轮必须同时交付：接触数据关联与多模型判别、桌面先验的 provenance 与交叉验证、标定动作的安全认证，以及“单次接触不得单独定案”的证据纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TABLE-RAS 总览）** TABLE-RAS = (SE3B, TOM, CGA, CAD, CAA, ACC, COI, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **任务相对认证**：任何动作 a 只需其任务敏感子空间内的标定不确定性满足阈值，不要求全局标定；
(iii) **锚点证据纪律**：单次接触/单帧视觉/单次主动标定不得单独更新全局外参，须由至少两个正交几何证据源（视觉切向 + 接触法向 + 重力/支撑面）一致，或由已知标定物直接验证；
(iv) **严格包含**：当标定信念任务无关、被认证、或主动接触标定 VoI ≤ 成本时，逐指令退化为 FLUID-RAS；再无交互/无标定需求时退化为 R68。

**定义 311（SE(3) 标定信念 SE3B）** 手眼/工具外参 `T ∈ SE(3)`，信念 `p(T)` 取 SE(3) 上的集中高斯（或以 `T̂` 为均值、`Σ_T ∈ ℝ^{6×6}` 的矩阵 Fisher 近似），并带 provenance `π_T`（出厂/上次认证/上次接触更新）。`Σ_T` 各向异性且允许相关；维护 `(T̂, Σ_T, π_T)`，而非标量残差。对移动机械臂，标定图还包含“基座—桌面”边；对 eye-in-hand，还包含“相机—夹爪/工具”边。

**定义 312（任务加权标定信息 TOM）** 任务输出/可负担性 `y = g(T, o_t, q_t)`（如抓取位姿、孔轴对齐、放置接触点）。标定雅可比 `J_T = ∂y/∂ξ |_{ξ=log(T̂^{-1}T)} ∈ ℝ^{m×6}`；任务权重 `W_task ≻ 0`。任务加权信息矩阵 `M_task = J_T^T W_task J_T`；**有效标定不确定性** `U_cal^task = tr(W_task^{1/2} J_T Σ_T J_T^T W_task^{1/2})`。`U_cal^task` 小但 `tr Σ_T` 大是允许的：那说明误差落在任务不在乎的方向。

**定义 313（桌面可观测性与锚定 Gramian）** 视觉锚雅可比 `J_v`、接触锚雅可比 `J_c`、支撑面/重力锚雅可比 `J_π`。锚定信息
`O = J_v^T Σ_v^{-1} J_v + J_c^T Σ_c^{-1} J_c + J_π^T Σ_π^{-1} J_π`。
可观测谱 `{λ_i(O)}`，零空间 `N = ker(O)` 为当前证据无法锚定的方向。定义“任务相关可观测性” `λ_min^task = λ_min(Π_task O Π_task)`；它是“这次动作所需的标定方向是否被钉住”的度量。经典手眼退化（所有配对运动绕同一螺旋轴）对应 `N` 非平凡。

**定义 314（支撑面与接触测量模型）** 桌面支撑面 `π = (n_π, d_π)`，`n_π` 由重力/IMU 给出（世界系），`d_π` 由多点接触估计。接触事件在时刻 t 给出接触点 `c_t`（末端/夹爪坐标系）与法向力 `f_t`。测量模型：
`c_world = T ⊗ FK(q_t) ⊗ c_t = h(T, q_t, c_t)`，约束 `n_π^T c_world = d_π`（法向 1 维），切向由视觉/已知物体几何提供。接触残差 `r_c = n_π^T h(T, q_t, c_t) − d_π`；视觉残差 `r_v =` 观测到的夹爪/物体位姿 `−` 预测位姿。二者协方差分别为 `Σ_c`、`Σ_v`，且**法向/切向互补**。

**定义 315（接触锚定更新 CGA）** 用鲁棒李群滤波（SE(3) EKF / UKF / 位姿图）融合 `(r_v, r_c, r_π)`：
`T̂ ← T̂ ⊞ K_v r_v ⊕ K_c r_c`，`Σ_T ← (I − K O)Σ_T(I − K O)^T + K Σ_meas K^T`。
用 Huber/χ² 门控剔除离群接触；按定义 310-iii 至少两个正交源一致才允许显著收缩 `Σ_T`。

**定义 316（标定—物体—桌面纠缠 COI）** 联合潜变量 `(T, p_o, π)`，其中 `p_o` 为物体位姿。仅凭视觉—接触，存在规范自由度：外参的某个方向可由物体位姿的相反方向抵消，使观测似然不变。用桌面平面 + 重力 + 已知支撑关系固定规范；定义可辨识条件
`rank(∂(r_v, r_c, r_π)/∂(T, p_o, π)) = dim(T) + dim(p_o) + dim(π) − g`，
`g` 为剩余规范维数。**不可辨识时不得单独更新 T，只能更新其可辨识子空间。**

**定义 317（任务相对标定阈值与 resolution bonus）** 对动作 a，定义认证判据 `U_cal^task(a) ≤ τ_task(a)` 且 `λ_min^task ≥ λ_min`。满足则动作获得 resolution bonus：R69 中 λ 只用 `(U_ale + 未消解 U_epi)`；不满足则把**任务相关、当前不可辨识**的标定不确定性 `U_cal^unres` 并入保守项（定义 325）。**注意：不是所有 Σ_T 都进保守，只有投影到任务子空间且无法锚定的部分。**

**定义 318（标定感知可负担性 CAA）** 用 `Σ_T` 对物体/桌面/夹爪几何做保守膨胀：`𝒢_inflate = 𝒢 ⊕ ε(Σ_T, W_task)`；抓取/放置/推动的成功概率下界 `p_succ^LB(a)` 由膨胀后的接触可行性给出。过滤掉 `p_succ^LB(a) < p_min` 或“标定敏感度过高”的动作；对剩余动作按风险调整后的收益排序。**这把外参不确定性从“感知噪声”变成“可负担性约束”。**

**定义 319（主动接触标定 ACC）** 候选接触动作 `g_c ∈ 𝒜_contact`（桌面轻触、已知平面刮擦、非抓取式点触、末端多角度轻放），它们不改变任务目标状态但产生接触锚。信息增益
`IG_cal(g_c) = H(T | ℰ) − E_{r_c}[H(T | ℰ, r_c)]`，
`VoI_cal(g_c) = IG_cal(g_c) − c_cal(g_c) − c_task(g_c)`，
其中 `c_cal` 为时间/磨损，`c_task` 为对任务状态的扰动成本。选择 `g_c* = argmax VoI_cal`，s.t. 安全认证、桌面净空、任务松弛窗口。`VoI_cal ≤ 0` 则不标定、走定义 325 的保守分支。

**定义 320（标定故障判别 TDM）** 多模型假设：`H_HE`（手眼漂移）、`H_obj`（物体位姿错误）、`H_table`（桌面坡度/变形/鬼影）、`H_slip`（接触滑移）、`H_sensor`（力/深度偏置）。各模型给出残差签名 `(r_v, r_c, r_π, Δa)` 与可观测性签名；用贝叶斯因子/似然比判别。**不得把 `H_slip` 误判为 `H_HE`**：滑移通常有切向位移与力突变，而外参漂移在静止接触前后一致。

**定义 321（漂移模型与事件触发）** `T` 随随机游走 `dT = T · exp(η dt + γ dW)`，`η` 为已知热漂/磨损项；接触事件、夹爪更换、碰撞检测、视觉重投影误差突增为触发事件。事件触发时才允许高成本主动标定；常规帧只做廉价更新与门控。provenance 记录“谁在何时用什么证据改过 T”。

**定义 322（参与式审计 VQAuditor-T）** 审计：接触是否被正确关联到桌面而非物体、是否单源采纳、`Σ_T` 是否被过度收缩、主动标定是否真的提升了任务相关可观测性、是否在错误先验下自洽。结论回灌 AuditBuf，成为下一轮 ACC 的成本/信任先验。

**定义 323（桌面干扰集 ℰ_table）** 软布/可变形支撑、坡度、玻璃/镜面鬼影、透明物体、反光、纹理缺失、假标定物、接触投毒（在标定接触点放置柔性物）、遮挡导致错误关联。并入 AIC：`ℰ_TABLE = ℰ_FLUID × ℰ_anchor × ℰ_table_geom`。

**定义 324（证书 J_TABLE）** `J_TABLE = (J_FLUID, U_cal^task, λ_min^task, tr Σ_T, anchor_rank, contact_consistency, provenance_chain, calib_log_hash, table_ver)`。Valid ⇔ Valid(J_FLUID) ∧ `U_cal^task ≤ τ_task` ∧ 锚点证据纪律满足 ∧ 主动标定预算未越界。

**定义 325（三级退避与严格包含）**
- 若 `U_cal^task ≤ τ_task`（任务已够准）：λ 只按 R69 的 `(U_ale, U_epi)` 计算，获得标定 resolution bonus；
- 若 `U_cal^task` 超阈但 `λ_min^task ≥ λ_min` 且可主动接触标定：先 ACC，再重判；
- 若不可辨识/超预算/被投毒/先验不可信：`λ = λ_floor(U_ale + 未消解 U_epi + U_cal^unres)`，回到 R68 最保守。
⇒ TABLE-RAS 是 FLUID-RAS 在“标定任务无关或永久完全可信”边界上的退化；R68 是再退化边界。

**定义 326（实时预算与门控）** 常规帧只做 `Σ_T` 传播 + 任务投影 + 门控（< 0.1ms）；视觉锚更新为 O(1) SE(3) 滤波；接触更新仅在接触事件触发；主动接触标定仅在事件触发且预算允许时执行。P99 不超过 R69 的 K=1 路径 + 0.3ms。

```python
# IP-264 SE3B：任务各向异性的手眼标定信念
class SE3CalibrationBelief:
    def __init__(self, T0, Sigma0, provenance):
        self.T, self.Sigma, self.prov = T0, Sigma0, provenance

    def propagate(self, dt, drift_rate):
        self.Sigma = self.Sigma + drift_rate**2 * dt * np.eye(6)   # 随机游走

    def task_uncertainty(self, J_task, W_task):
        A = W_task @ J_task
        return float(np.trace(A @ self.Sigma @ A.T))               # U_cal^task

# IP-265 TOM：任务加权可观测性
def task_observability(J_task, W_task, J_vis, J_con, J_plane,
                       S_vis, S_con, S_plane, Pi_task):
    M_task = J_task.T @ W_task @ J_task
    O = (J_vis.T @ np.linalg.inv(S_vis) @ J_vis
         + J_con.T @ np.linalg.inv(S_con) @ J_con
         + J_plane.T @ np.linalg.inv(S_plane) @ J_plane)
    O_task = Pi_task @ O @ Pi_task
    return np.linalg.eigvalsh(O_task)[0], O          # lambda_min^task, 锚定 Gramian

# IP-266 CGA：接触锚定更新（鲁棒、双源门控）
def contact_grounded_update(belief, r_vis, r_con, J_vis, J_con,
                            S_vis, S_con, provenance_ok, k_sources):
    if not provenance_ok or k_sources < 2:           # 证据纪律：单源不得定案
        return belief
    if chi2(r_con, S_con) > TAU_CHI2:                # 滑移/错误关联门控
        return belief
    r = np.concatenate([r_vis, r_con])
    J = np.vstack([J_vis, J_con])
    S = block_diag(S_vis, S_con)
    K = belief.Sigma @ J.T @ np.linalg.inv(J @ belief.Sigma @ J.T + S)
    belief.T = belief.T @ se3_exp(K @ r)
    belief.Sigma = (np.eye(6) - K @ J) @ belief.Sigma
    belief.prov.append(('contact', provenance_ok))
    return belief

# IP-269 ACC：主动接触标定（VoI − 成本，且必须在任务松弛窗口内）
def choose_contact_calibration(belief, candidates, budget, slack, J_task, W_task):
    best = None
    for g in candidates:
        if not budget.allow(g) or not c_ras_wm.certify_calib(g): continue
        if not within_clearance(g, slack):           continue
        U_before = belief.task_uncertainty(J_task, W_task)
        U_after  = expected_task_uncertainty(belief, g, J_task, W_task)
        score = (U_before - U_after) - cost_cal(g) - cost_task(g)
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None  # 无利可图 → 不标定

# IP-268 CAA：标定感知可负担性过滤
def calibration_aware_filter(actions, belief, W_task):
    keep = []
    for a in actions:
        J = task_jacobian(a)
        U_task = belief.task_uncertainty(J, W_task)
        if U_task > tau_task(a):                     continue
        if p_success_lower_bound(a, belief) < p_min: continue
        keep.append((a, risk_adjusted_score(a, U_task)))
    return sorted(keep, key=lambda x: -x[1])

    # R69 外部交互层
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # R70 标定层：传播 + 任务投影
    M.se3b.propagate(M.dt, M.drift_rate)
    a_cand = M.ach.propose(x_prime, M.vista.H)
    J_T = M.tom.task_jacobian(a_cand, o)
    U_task = M.se3b.task_uncertainty(J_T, M.W_task)
    lam_min, O = M.tom.observability(J_T, M.W_task, M.J_vis, M.J_con,
                                     M.J_plane, M.S_vis, M.S_con, M.S_plane, M.Pi_task)
    # 接触事件：先关联与判别，再更新
    if M.has_contact:
        H = M.tdm.classify(M.r_vis, M.r_con, M.r_plane, M.delta_a)
        if H in ('HE', 'table') and M.anchor_ok:
            M.se3b = M.cga.update(M.se3b, M.r_vis, M.r_con,
                                  M.J_vis, M.J_con, M.S_vis, M.S_con,
                                  M.prov_ok, M.k_sources)
    # 任务不够准且可锚定 → 主动接触标定；否则保守
    calib_g = None
    if U_task > M.tau_task and lam_min >= M.lam_min:
        calib_g = M.acc.choose(M.se3b, M.contact_candidates, M.budget,
                               M.slack, J_T, M.W_task)
    if calib_g is not None:
        M.acc.execute_safe(calib_g)                  # 过 C-RAS-WM + 净空认证
        U_task = M.se3b.task_uncertainty(J_T, M.W_task)
    # 三级退避：任务相关未消解项并入 lambda floor
    U_unres = max(0.0, U_task - M.tau_task)
    U_floor = U_ale + (U_epi if M.g is None else 0.0) + U_unres
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 标定感知动作过滤
    a_safe = M.caa.filter([a_cand], M.se3b, M.W_task)
    if not a_safe:
        lam, a_safe = 1.0, [M.min_risk_action]
    k = M.c_ras_wm.certified_prefix(a_safe[0], ..., M.wm_preds)
    tau = M.pi_sigma.prefix_dispatch(a_safe[0][:k]) * lam
    M.vqa_t.submit_async(calib_g, U_task, M.se3b, M.anchor_ok)
    return k, lam, a_safe[0], (U_ale, U_epi, U_task)
```

## 3. 推导

**引理 19（视觉—接触互补与条件数界）** 设视觉雅可比 `J_v` 在切向子空间满秩、在法向近奇异；接触雅可比 `J_c` 在法向满秩、在切向近零。则 `rank(J_v) + rank(J_c) ≥ rank([J_v; J_c])`；当两子空间正交时，组合锚定 Gramian `O` 的条件数满足 `κ(O) ≤ κ(J_v)κ(J_c)/(1−ρ²)`，其中 `ρ` 为两子空间主角度余弦。要点：**视觉管切向、接触管法向；单靠任何一路都有盲区，合起来才把 6 自由度钉住。** 系：桌面操作中“看得清”不等于“标得准”，必须让接触参与标定。

**引理 20（接触锚的秩与可辨识性）** 已知桌面平面 `π` 与重力 `n_π` 时，一次点接触提供 1 维法向约束（rank 1）；`k` 次非共线、法向独立的接触最多提供 `min(k, 6)` 维约束；仅靠同一平面上的接触无法观测绕平面法向的偏航与沿平面的部分平移组合，需视觉切向或非平面接触补秩。系：**“多摸几下”不必然更好；接触点的几何分布决定秩，重复同一位置的接触信息量为零。**

**引理 21（任务相对标定与 resolution bonus）** 设任务权重 `W_task` 的像空间为 `𝒯`，`Π_task` 为到 `𝒯` 的投影。则（在 `W_task` 可对角化时）`U_cal^task = tr(Π_task Σ_T Π_task)`，且存在正交分解 `Σ_T = Σ_∥ + Σ_⊥`，`Σ_⊥` 对任务输出无影响。若 `U_cal^task ≤ τ_task` 而 `tr Σ_⊥` 任意大，动作仍可放行。系：**标定认证应针对任务子空间签发，而不是针对全局 Σ_T；这给出比 R69 更细的 resolution bonus，且不降低该任务的安全裕度。**

**引理 22（错误锚点的污染上界）** 设桌面先验 `π̃` 与真实 `π` 的偏差为 `δ_π`，接触关联错误率为 `δ_a`。则标定更新后的外参误差满足 `‖T̂ − T*‖ ≤ ‖K‖(δ_π + δ_a) + 残余噪声`，且 `Σ_T` 会被错误地收缩。若 `δ_π` 不在可观测子空间内，残差可能为零而误差任意大。系：**低残差不是正确性的证据；错误锚点可以制造“自洽的自信”。** 必须用独立证据（重力、已知标定物、跨任务一致性）做交叉验证。

**定理 18（TABLE 严格包含 FLUID 与 R68）** 在 A99–A102 下，TABLE-RAS 的任意状态期望风险 ≤ FLUID-RAS；当 `U_cal^task ≤ τ_task` 且不触发主动标定时，两者逐指令相同；当进一步无交互需求（R69 的 VoI ≤ 成本）时退化为 R68。安全侧不做让步，效率侧获得任务相对标定的 resolution bonus。

**定理 19（标定感知安全与无突变）** 用 `Σ_T` 对几何做保守膨胀（定义 318）后，动作的接触可行性下界 `p_succ^LB` 对真实 `Σ_T` 单调；主动接触标定经 C-RAS-WM 与桌面净空认证（定义 319），只改变 `T` 的估计、不扩大任务安全包络；标定失败/超时/投毒时 λ 单调不降地退回 R68。故控制连续、无突变。

**定理 20（故障判别与错误锚点检测）** 在 `H_HE/H_obj/H_table/H_slip` 的残差签名两两可分的条件下（A103），多模型后验误差随接触事件数指数下降；错误桌面先验可由“重力方向 vs 视觉平面法向”与“跨接触点一致性”两条独立检验以至少 `1−ε` 的概率检出，除非扰动同时伪造这两条通道。系：**桌面可以骗过接触，但很难同时骗过重力与跨任务一致性。**

## 3. 关键算法伪代码

```python
# IP-264 SE3B：任务各向异性的手眼标定信念
class SE3CalibrationBelief:
    def propagate(self, dt, drift_rate):
        self.Sigma += drift_rate**2 * dt * np.eye(6)

    def task_uncertainty(self, J_task, W_task):
        A = W_task @ J_task
        return float(np.trace(A @ self.Sigma @ A.T))       # U_cal^task

# IP-265 TOM：任务加权可观测性
def task_observability(J_task, W_task, J_v, J_c, J_p, S_v, S_c, S_p, Pi_task):
    O = (J_v.T @ np.linalg.inv(S_v) @ J_v
         + J_c.T @ np.linalg.inv(S_c) @ J_c
         + J_p.T @ np.linalg.inv(S_p) @ J_p)
    return np.linalg.eigvalsh(Pi_task @ O @ Pi_task)[0], O

# IP-266 CGA：接触锚定更新（双源纪律 + 鲁棒门控）
def contact_grounded_update(b, r_v, r_c, J_v, J_c, S_v, S_c, prov_ok, k_src):
    if not prov_ok or k_src < 2 or chi2(r_c, S_c) > TAU_CHI2:
        return b                                            # 单源/离群不更新
    r = np.concatenate([r_v, r_c]); J = np.vstack([J_v, J_c])
    S = block_diag(S_v, S_c)
    K = b.Sigma @ J.T @ np.linalg.inv(J @ b.Sigma @ J.T + S)
    b.T = b.T @ se3_exp(K @ r)
    b.Sigma = (np.eye(6) - K @ J) @ b.Sigma
    return b

# IP-269 ACC：主动接触标定（无利可图 → 不标定）
def choose_contact_calibration(b, cands, budget, slack, J_t, W):
    best = None
    for g in cands:
        if not budget.allow(g) or not c_ras_wm.certify_calib(g): continue
        if not within_clearance(g, slack):                   continue
        U0 = b.task_uncertainty(J_t, W)
        U1 = expected_task_uncertainty(b, g, J_t, W)
        score = (U0 - U1) - cost_cal(g) - cost_task(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-275 主闭环（继承 R69）
def TABLE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    M.se3b.propagate(M.dt, M.drift_rate)
    a_cand = M.ach.propose(x_prime, M.vista.H)
    J_T = M.tom.task_jacobian(a_cand, o)
    U_task = M.se3b.task_uncertainty(J_T, M.W_task)
    lam_min, O = M.tom.observability(J_T, M.W_task, M.J_vis, M.J_con,
                                     M.J_plane, M.S_vis, M.S_con, M.S_plane, M.Pi_task)
    if M.has_contact:
        H = M.tdm.classify(M.r_vis, M.r_con, M.r_plane, M.delta_a)
        if H in ('HE', 'table') and M.anchor_ok:
            M.se3b = M.cga.update(M.se3b, M.r_vis, M.r_con, M.J_vis, M.J_con,
                                  M.S_vis, M.S_con, M.prov_ok, M.k_sources)
    calib_g = None
    if U_task > M.tau_task and lam_min >= M.lam_min:
        calib_g = M.acc.choose(M.se3b, M.contact_candidates, M.budget,
                               M.slack, J_T, M.W_task)
    if calib_g is not None:
        M.acc.execute_safe(calib_g)
        U_task = M.se3b.task_uncertainty(J_T, M.W_task)
    U_unres = max(0.0, U_task - M.tau_task)
    U_floor = U_ale + (U_epi if M.g is None else 0.0) + U_unres
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    a_safe = M.caa.filter([a_cand], M.se3b, M.W_task)
    if not a_safe: lam, a_safe = 1.0, [M.min_risk_action]
    k = M.c_ras_wm.certified_prefix(a_safe[0], ..., M.wm_preds)
    tau = M.pi_sigma.prefix_dispatch(a_safe[0][:k]) * lam
    M.vqa_t.submit_async(calib_g, U_task, M.se3b, M.anchor_ok)
    return k, lam, a_safe[0], (U_ale, U_epi, U_task)
```

## 4. 推导

**引理 19（视觉—接触互补）** 视觉雅可比在切向满秩、法向近奇异；接触雅可比在法向满秩、切向近零。则组合锚定 Gramian `O` 的秩严格大于单路，且两子空间正交时 `κ(O) ≤ κ(J_v)κ(J_c)/(1−ρ²)`。系：**桌面操作里“看得清”不等于“标得准”，接触必须参与标定。**

**引理 20（接触锚秩与可辨识性）** 已知桌面平面与重力时，一次点接触仅提供 1 维法向约束；`k` 次法向独立的非共线接触最多提供 `min(k,6)` 维；同一平面重复接触无法观测绕法向偏航与部分平移组合，需视觉切向或非平面接触补秩。系：接触的几何分布决定信息量，重复同一位置为零。

**引理 21（任务相对标定与 resolution bonus）** `U_cal^task = tr(Π_task Σ_T Π_task)`（`W_task` 可对角化时）；分解 `Σ_T = Σ_∥ + Σ_⊥`，`Σ_⊥` 不影响任务输出。若 `U_cal^task ≤ τ_task`，即使 `tr Σ_⊥` 很大也可放行。系：**标定认证应按任务子空间签发，而非全局 Σ_T。**

**引理 22（错误锚点污染上界）** 桌面先验偏差 `δ_π`、接触关联错误率 `δ_a` 下，`‖T̂−T*‖ ≤ ‖K‖(δ_π+δ_a)+残余噪声`，且 Σ_T 被错误收缩；若 `δ_π` 落在可观测子空间外，残差可为零而误差任意大。系：**低残差不是正确性证据；错误锚点可以制造“自洽的自信”。**

**定理 18（TABLE 严格包含 FLUID 与 R68）** A99–A102 下，TABLE 任意状态期望风险 ≤ FLUID；当 `U_cal^task ≤ τ_task` 且不主动标定时逐指令相同；当 R69 的 VoI ≤ 成本时进一步退化为 R68。安全不让步，效率得任务相对 resolution bonus。

**定理 19（标定感知安全与无突变）** 用 Σ_T 保守膨胀几何后，接触可行性下界对真实 Σ_T 单调；主动接触标定经 C-RAS-WM 与桌面净空认证，只改 T 的估计、不扩大任务安全包络；失败/超时/投毒时 λ 单调不降退回 R68；换装不变式保持 ⇒ 控制连续、无突变。

**定理 20（故障判别与错误锚点检测）** 在 HE/object/table/slip 残差签名两两可分（A103）时，多模型后验误差随接触事件数指数下降；错误桌面先验可由“重力 vs 视觉平面法向”与“跨接触点一致性”两条独立检验以至少 `1−ε` 概率检出，除非扰动同时伪造这两条通道。系：**桌面可以骗过接触，但很难同时骗过重力与跨任务一致性。**

## 7. 本轮最大风险

**次级风险与缓解**：接触关联错误（CAD 门控 + 多模型 + 双源纪律）；退化运动致任务相关方向不可观测（TOM + ACC 补秩 + 不可解则保守）；主动标定扰动任务/碰撞（C-RAS-WM + 净空认证 + 松弛窗口）；透明/反光/软桌面（ℰ_table + 重力/跨任务交叉验证 + provenance）；过拟合特定桌面（跨桌面 OOD + sim2real）；实时预算（事件触发 + 廉价任务投影）。

**一句话**：TABLE-RAS 的全部收益押在“桌面/接触这个锚是真的”上——**若桌面先验错误（软布、坡度、玻璃鬼影、假标定物）或接触被错误关联到物体，视觉与接触会在错误的世界里彼此一致、残差归零、Σ_T 被错误收缩，系统于是以极高置信度执行一个几何上错误的世界；锚错地方比不锚更危险，因为它把 R69 的“诚实的不知道”升级成“有证据的确定错误”。**
