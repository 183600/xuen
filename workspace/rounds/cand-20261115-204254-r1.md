# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「技术融合」×「迁移学习」）

> R69 把不确定性一分为二：aleatoric 走 R68 的保守铁律，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去消解。它的效率收益押在一个前提上——**流模型的模态分布可信**。但 R69 仍隐含两个更深的假设：**(a) 这套系统是一个在单一目标域里从头可信的整体；(b) 它的各个部件本来就是为这个域造的。** 真实部署两点都不成立。
>
> 本轮两个灵感正好戳破这两个假设：
> - **技术融合**：我们不会再造一个更大的单体，而是把来自**不同来源、各自在各自领域认证过**的专家技术（源域流策略、视觉专家、标定器、交互策略、世界模型）组合起来。融合之所以诱人，正因为它承诺「不必从零重新认证」——而这正是陷阱。
> - **迁移学习**：每个专家都要从源域迁到目标域。迁移从不免费：域差把「已验证」降级成「条件已验证」，还可能负迁移。
>
> 核心命题：**证书不能继承，只能重算；迁移缺口不能假设为零，只能显式记账并支付。** 技术融合的安全 = 每个专家各自的迁移契约 **∧** 融合本身重新证明的联合证书；迁移缺口是一类**可支付的认识论不确定性**，能用 R69 的交互/VoI 去「买」目标域证据来缩小；买不起就退回单源——也就是 R69。命名 **FUSE-RAS**（Fusion-aware, Uncertainty-preserving, Source-transferable Expert RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**把这套东西搬到新场景、再把不同来源的零件拼起来，还能不能信**」——**证书的并置不等于证书的合成，迁移的成功不等于融合的成功。**

## 0. 直觉与动机

**灵感 1（技术融合 → 组合是必然，但组合会改写每个零件的证书）**
直觉：现代具身系统不是单块芯片，而是「感知专家 + 策略专家 + 标定专家 + 语言专家 + 世界模型」的拼装。技术融合（乃至范式融合：模型驱动 × 数据驱动、符号 × 神经、形式化 × 统计）的吸引力在于**复用**：每个零件都带着自己那份证据与保证。但证书是**条件句**——「若输入落在我的有效域，则我保证 G_i」。融合改变了每个零件看到的输入分布（下游漂移、上游误差、共模故障），于是「每个零件都合格」不再蕴含「整机合格」。融合必须**重新证明**，不能**继承证明**。

**灵感 2（迁移学习 → 域差把「已验证」变成「条件已验证」）**
直觉：源域里校准良好的流策略，搬到光照/材质/动力学都变了的现场，可能立刻失准。迁移学习告诉我们：目标风险 ≤ 源风险 + 域差项 + 理想联合误差。所以每份证书都应附一份**迁移契约**：(δ, κ, R)——域差不超过 δ 时，保证从 G 松弛到 G^κ，R 是失效见证。契约没说「能不能迁移」，只说「迁移到什么程度还算数」。

**灵感 3（融合×迁移的陷阱 → 证书并置 ≠ 证书合成）**
直觉：最危险的不是单个零件坏，而是**所有零件都「各自合格」，拼起来却整体越界**。三种机制：(i) **共模故障**——一个传感器坏了，同时污染多个专家，误差正相关，融合的「平均抵消」红利消失，风险线性叠加；(ii) **级联漂移**——视觉专家在目标域微调过、策略没微调，策略就被喂进一个「错的世界」；(iii) **模态先验污染**——源域策略的多峰先验把 R69 的模态权重拉向源域习惯，让系统问错问题。这三者都躲在单组件证书的盲区里。

**灵感 4（迁移缺口是可支付的认识论不确定性 → 复用 R69 的交互去「买」证据）**
直觉：域差里有一部分是**可约的**（协变量漂移、可自标定的统计偏移、少量标注就能锚定的标签漂移），另一部分是**不可约的**（支撑集不重叠、概念漂移、本质动力学差）。可约的那部分，正是 R69 的 VoI 机制最擅长的事：花极小的目标域证据预算，去把缺口缩到契约可接受。**R69 会「问人」，R70 让它「问新世界」**——自标定、少量查询、边界探针，都是同一个信息动作空间的扩展。

**灵感 5（负迁移 → 融合可能是负收益；需要在线「去融合」）**
直觉：不是所有零件都该拼进来。一个在源域很强的专家，在目标域可能**帮倒忙**（负迁移）。更糟的是，它的危害会被融合「抹匀」，从指标上看不出来。所以必须有**负迁移检测器**：用反事实影子评估每个专家的净贡献，一旦持续为负就**去融合**（un-fusion），并重新认证。融合必须是**可逆、单调安全**的插拔，而不是一次性的缝合。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（FUSE-RAS 总览）** FUSE-RAS = (TCM, FCA, NTD, TGB, MINT†, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **证书可追溯**：每个参与融合的专家必须携带「源域证书 + 迁移契约」，缺一即不得融合；
(iii) **融合安全必须重证**：融合系统有效当且仅当重算的联合风险上界 ≤ 目标预算；「各组件分别 Valid」只是必要条件，不是充分条件；
(iv) **缺口显式记账**：任何跨域/跨组件引入的残余缺口 Δ_trans 必须记为未消解 epistemic，只有被 R69 交互支付或去融合清零后，才可解除保守。

**定义 311（专家技术单元）** 专家 E_i = (f_i, C_i, D_i, G_i, L_i)：模型 f_i、源域证书 C_i（在源域 D_i 内 Valid）、保证谓词 G_i、接口 Lipschitz 常数 L_i。技术融合算子 F = ⊕_{i≤n} E_i 是级联/并行/仲裁的复合。

**定义 312（迁移契约）** 把 E_i 从源域 D_i^src 迁到目标 D_i^tgt，契约 T_i = (δ_i, κ_i, R_i)：当 d(D_i^src, D_i^tgt) ≤ δ_i 时，风险_T(f_i) ≤ 风险_S(f_i) + κ_i（Ben-David 型域适应界，κ_i 吸收域差与理想联合误差），保证从 G_i 松弛为 G_i^{κ_i}；R_i 是失效见证（峰值风险、margin 塌缩模式）。d ≤ δ_i 时契约 Valid。

**定义 313（融合证书间隙）** 令组件有效域交集 D_∩ = ∩_i D_i，融合实际输入分布 D_comp。**融合间隙** Λ_fuse = Σ_i L_i · d(D_comp, D_i)。融合证书按「编译规则」重算：Cert(F) Valid ⇔ (∀i Cert(E_i) Valid) ∧ (∀i T_i Valid) ∧ Λ_fuse ≤ δ_fuse ∧ 交叉条件（定义 314）成立。⊕ 在条件不成立时返回 ⊥（未认证），禁止「静默融合」。

**定义 314（交叉条件）** 三个可计算不等式：
(a) **误差解耦**：融合权重 w、组件误差相关阵 Σ_e，联合方差 wᵀΣ_e w ≤ ε_budget²（ρ_cross↑ ⇒ 平均红利↓）；
(b) **级联稳定**：Σ_i L_i·‖Δ输入_i‖ ≤ δ_cascade（上游漂移经接口放大后仍收敛）；
(c) **先验一致**：模态先验 KL(p_src_mode ‖ p_tgt_mode) ≤ δ_prior（防模态先验污染）。任一破坏 ⇒ 融合进入未认证，走 MINT† 或去融合。

**定义 315（迁移缺口预算 TGB）** Δ_trans = Λ_fuse + Σ_i κ_i + cross(Σ_e)（保守可加上界）分解为可支付认识论部分 Δ_epi^tr 与不可约部分 Δ_ale^tr。Δ_ale^tr 进 λ_floor；Δ_epi^tr 交给 MINT†；记账规则：未支付部分等价于未消解 epistemic。

**定义 316（迁移感知交互 MINT†）** 复用 R69 的 VoI，候选信息动作扩展为目标域自标定（统计对齐）、少量主动查询/标注、边界探针（以及 R69 原有的注视/触觉/问句）。VoI_tr(g) = H(Δ_epi^tr) − E_{y~p(·|g)}[H(Δ_epi^tr|y)]。选 g* = argmax[VoI_tr − c]，s.t. 认证与预算；仅当 E[Δ_epi^tr after g*] ≤ δ_trans^OK 时才支付（否则支付也无意义）。支付后更新 T_i 的 κ_i 与 C_i。

**定义 317（负迁移检测器 NTD）** 对每个融合专家定义反事实净贡献 c_i(t) = R(F) − R(F ↓_i)（↓_i 为移除 E_i 后的重认证融合）。用目标域 held-out 探针 + R69 的 FMA 行为似然做低成本影子估计 ĉ_i。若 ĉ_i < −τ_nt 持续 W 步 ⇒ 判负迁移，签名入审计缓冲。

**定义 318（去融合与重认证）** 触发去融合得 F' = F ↓_{N}（移除负迁移集 N）。安全单调：在 A101 下 R(F') ≤ R(F)；最坏 N = 全部非主源 ⇒ F' 退化为单源 = R69 闭环。去融合可逆：条件恢复后按定义 313 重认证可再融合。

**定义 319（迁移-融合证书 J_FUSE）** J_FUSE = (⊕_i J_i, Λ_fuse, Δ_trans_before/after, cross_ok, NTD_flags, un_fusion_log, target_evidence_lineage, fuse_ver)。Valid ⇔ 所有 J_i Valid ∧ Λ_fuse ≤ δ_fuse ∧ 交叉条件全过 ∧ Δ_epi^tr 已支付 ∧ 无未处理 NTD 告警 ∧ 目标证据血统合法。

**定义 320（融合仲裁与安全包络 RAS-WM‡）** 多专家并行出动作时，先走 R66 仲裁、再过 R68/R69 的 C-RAS-WM 前缀认证；融合动作必须落在各组件安全包络交集内，越界即降级为单专家包络。融合改变动作分布但不改变安全包络。

**定义 321（融合干扰集 ℰ_FUSE）** ℰ_FUSE = ℰ_FLUID × ℰ_domain_shift × ℰ_neg_transfer × ℰ_fusion_coupling：源域过拟合专家的「自信错误」、共模故障（单传感器同时污染多专家）、融合接口错配、后门迁移（源域干净、迁移后触发）、目标证据污染/泄漏。

**定义 322（迁移证据纪律）** 支付缺口的证据必须来自与源训练集不相交的目标样本（血统审计防泄漏），且单次证据不得定案（继承 R69 的 k-正交一致纪律）；禁止用源域数据或合成数据冒充目标域证据。

**定义 323（迁移-融合对偶）** 域差有两路观测：(a) 可计算的统计距离估计 d̂（便宜，但会被「看起来像源域」的目标骗过）；(b) 融合系统在目标上的行为似然差 Δa_fuse（贵，但只能被真实部署暴露）。二者联合可分离「真迁移成功」与「表面相似」——这是 R69 标定-策略密度对偶在域层面的镜像。

**定义 324（嵌套退化监控）** 三边界逐指令退化为 R69：d=0（源=目标）；n=1（单源，融合为空操作）；Δ_epi^tr 不可支付/血统非法/交叉条件破坏。⇒ 安全侧永不弱于 R69，R69 再退化到 R68。运行时监控当前处于哪一层，并写进 J_FUSE。

## 2. 关键算法骨架

```python
# IP-264/265 TCM+FCA：迁移契约 + 融合证书代数
class FusionCertificate:
    def transfer_ok(self, E, d_src_tgt):                     # E.T = (δ, κ, R)
        return d_src_tgt <= E.T.delta

    def fuse(self, experts, D_comp, A):                      # A = 假设 A99-A102
        for E in experts:
            if not E.cert.valid or not self.transfer_ok(E, d_hat(E)):
                return None                                  # 缺证 → 禁止融合
        lam_fuse = sum(E.L * dist(D_comp, E.D) for E in experts)  # 定义 313
        cross_ok = (var(w, Sigma_e) <= A.eps_budget**2            # 解耦
                    and cascade_bound(experts) <= A.delta_cascade # 级联
                    and prior_kl(experts) <= A.delta_prior)       # 先验
        if lam_fuse > A.delta_fuse or not cross_ok:
            return None                                  # ⊕ = ⊥，未认证
        return Compose(experts, bound=recompile(experts, lam_fuse))

# IP-266 NTD：负迁移检测（影子反事实）
def negative_transfer(F, probe_set):
    flags = []
    for i, E in enumerate(F.experts):
        c_hat = risk(F, probe_set) - risk(F.without(i), probe_set)   # 净贡献
        if c_hat < -TAU_NT and stable(i, W): flags.append(i)
    return flags

# IP-268 MINT†：迁移感知交互（复用 R69 VoI，扩展候选）
def choose_transfer_action(F, d_hist, budget):
    best = None
    for g in (self_calib(), active_query(), boundary_probe(), *r69_info_actions()):
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi = entropy(d_hist) - expected_entropy(d_hist, g)
        if best is None or voi - cost(g) > best.score:
            best = (g, voi - cost(g))
    return best if best and best.score > 0 else None    # 买不起 → 不支付

# IP-274 FUSE 主闭环（严格包含 R69）
def FUSE_RAS_round(M, obs):
    # 1) 迁移/融合证书重算（不继承！）
    F = M.fca.fuse(M.experts, M.D_comp, M.assumptions)
    if F is None or not M.tcm.all_contracts_valid():
        return R69_round(M, obs)                     # 边界：退化为 R69
    # 2) 缺口二分与支付
    d_ale, d_epi = M.tgb.split(M.transfer_gap(F))
    g = (M.mint_t.choose_transfer_action(F, d_epi, M.budget)
         if d_epi > TAU_TR else None)
    if g is not None and M.tgb.pays(g):
        d_epi = M.tgb.apply(F, M.execute(g))         # 更新 κ_i / C_i
        F = M.fca.rerecertify(F)                     # 重认证
    # 3) 负迁移检测 → 去融合 → 重认证
    bad = M.ntd.negative_transfer(F, M.probe_set)
    if bad:
        F = M.fca.unfuse(F, bad)                     # 单调安全（引理 21）
        F = M.fca.rerecertify(F) or R69_round(M, obs)
    # 4) R69 闭环在融合后的安全包络内运行
    k, lam, mode, U = R69_round(F, obs)
    # 5) 记账：未支付缺口视同未消解 epistemic，只收紧
    lam = max(lam, lam_floor(d_ale + (d_epi if not M.tgb.paid else 0.0)))
    M.vqa_f.submit_async(F, d_ale, d_epi, bad, M.tgb.lineage)
    return k, lam, mode, (d_ale, d_epi), F.cert
```

## 3. 推导

**引理 19（融合收益 = 误差解耦）** 融合误差 e_F = Σ_i w_i e_i。若独立（ρ_cross=0），Var(e_F)=Σ_i w_i²σ_i²，相对单专家方差下降；若正相关 ρ_cross→1，Var(e_F)→(Σ_i w_i σ_i)²，无平均红利，风险线性叠加。系：**技术融合的收益恰是误差解耦的量；融合的风险恰是误差共谋的量**——共模故障把「融合红利」直接变成「融合负债」。

**引理 20（迁移缺口的证据价格）** 若目标域证据预算 B 使可约缺口按 Δ_epi^tr(B) ≤ Δ_0/√B 收缩（标准主动学习/自标定速率），则存在有限 B* = (Δ_0/δ_trans^OK)² 使融合证书重新 Valid。系：迁移缺口不是免费午餐——它有明确「价格」B*；预算 < B* 时不应强行融合，应退 R69。

**引理 21（去融合单调安全）** 若 NTD 在 A101（ĉ 估计误差 ≤ ε_det）下正确识别负迁移集 N，则 R(F ↓_N) ≤ R(F) + ε_det；ε_det 被证书显式记账。最坏 N = 全部非主源 ⇒ F' 退化为单源 R69，风险等于 R69。

**定理 18（FUSE 严格包含 R69）** 在 A99–A102 下，FUSE 在目标域的期望风险 ≤ R69 单源策略；且当 d=0、n=1、或 Δ_epi^tr 不可支付/交叉条件破坏/血统非法时，两者**逐指令相同**（定义 324）。故 R69 是 FUSE 在「零迁移、单源」边界上的退化：安全不让步，融合只买效率。

**定理 19（融合-迁移的安全无突变）** 迁移契约 + 交叉条件 + 去融合单调性 ⇒ 融合/去融合切换时风险连续、无突变；提交/换装不变式（R68 定理 15、R69 定理 17）保持 ⇒ 在线插拔专家不破坏安全包络。

**定理 20（技术融合的收益条件）** 融合净收益 > 0 ⇔ 组件误差解耦（ρ_cross 足够低）且迁移证据便宜（B* 足够小）且 Λ_fuse ≤ δ_fuse。否则融合是负收益，应保持单源（R69）+ 保守。⇒ **不是所有技术融合都值得做；可证明「不该融合」本身是一个有效结论。**

## 6. 本轮最大风险

**一句话**：FUSE-RAS 的全部安全论证押在「融合代数与耦合估计是诚实的」这一前提上——但**证书合成幻觉**恰恰是最隐蔽的失败模式：每个源专家都带着在自己领域内真有效的证书，迁移契约也各自成立，可融合后的耦合误差（共模、级联、模态先验污染）正落在所有单组件证书的盲区；若 Λ_fuse/ρ_cross 被系统性低估（共模故障让误差看起来不相关、目标证据被泄漏污染、d̂ 被「表面像源域」骗过），系统就会**拿着一叠真证书，签发一张假的融合许可证**——**融合越顺滑，越可能把若干个「各自安全」的零件拼成一个「整体不安全」的系统；证书的并置，从来不是证书的合成。**

**次级风险与缓解**：
1. **共模故障让融合红利变负债** → 交叉条件(a) + 共模注入实验 E310 + 保守可加上界（宁可高估 ρ_cross）；
2. **负迁移被融合抹匀而隐形** → NTD 反事实影子 + 去融合单调性（引理 21）+ E307；
3. **迁移契约被「表面相似」骗过** → 迁移-融合对偶（定义 323）+ 行为似然通道 + E305；
4. **目标证据泄漏/污染** → 血统审计（定义 322）+ E312；
5. **融合证书重算击穿实时预算** → 仅变更/告警时重算 + 缓存域统计 + 复杂度表。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** FUSE-RAS=(TCM,FCA,NTD,TGB,MINT†,RAS-WM‡)；零学习写操作继承；证书可追溯（缺迁移契约不得融合）；**融合安全必须重证**（各组件分别 Valid 只是必要条件）；缺口显式记账（未支付 = 未消解 epistemic，只收紧）。

**定义 311–312（专家单元与迁移契约）** `E_i=(f_i,C_i,D_i,G_i,L_i)`；`T_i=(δ_i,κ_i,R_i)`：`d(D_src,D_tgt)≤δ_i ⇒ 风险_T ≤ 风险_S+κ_i`（Ben-David 型域适应界），保证松弛为 `G^κ_i`；`d≤δ` 才 Valid。

**定义 313–314（融合间隙与交叉条件）** 融合输入 `D_comp`，`Λ_fuse=Σ_i L_i·d(D_comp,D_i)`；`Cert(F)` 重算：全组件 Valid ∧ 全契约 Valid ∧ `Λ_fuse≤δ_fuse` ∧ 交叉条件。交叉条件 = 误差解耦（`wᵀΣ_e w≤ε²`）+ 级联稳定 + 先验一致（`KL(p_src_mode‖p_tgt_mode)≤δ_prior`）；任一破坏 ⇒ `⊕=⊥`。

**定义 315–316（缺口预算与 MINT†）** `Δ_trans` 分为 `Δ_ale^tr`（进 λ_floor）与 `Δ_epi^tr`（交 MINT†）；`g*=argmax[VoI_tr−c]`，候选含自标定/主动查询/边界探针/注视/触觉/问句；仅当支付后 `E[Δ_epi^tr]≤δ_trans^OK` 才支付，支付后更新 `κ_i,C_i`。

**定义 317–318（NTD 与去融合）** `c_i=R(F)−R(F↓_i)`，影子估计 `ĉ_i<−τ_nt` 持续 W 步判负迁移；去融合 `F'=F↓_N` 满足 `R(F')≤R(F)`（A101），最坏退化为单源 R69；可逆重认证。

**定义 319–320（证书与仲裁）** `J_FUSE` 汇总 `⊕_i J_i`、`Λ_fuse`、`Δ_trans` 前后、`cross_ok`、`NTD_flags`、`un_fusion_log`、证据血统；融合动作过 R66 仲裁 + C-RAS-WM 前缀认证，且落在各组件安全包络交集内。

**定义 321–322（干扰集与证据纪律）** `ℰ_FUSE=ℰ_FLUID×ℰ_domain_shift×ℰ_neg_transfer×ℰ_fusion_coupling`；支付缺口的证据须与源训练集不相交（血统审计防泄漏），单次不得定案（k-正交一致）。

**定义 323–324（对偶与嵌套退化）** `(d̂, Δa_fuse)` 对偶分离「真迁移」与「表面相似」；三边界逐指令退化为 R69：`d=0` / `n=1` / `Δ_epi^tr` 不可支付或血统非法。运行时监控所处层级并写入 J_FUSE。

## 3. 关键算法伪代码

```python
# IP-264/265 TCM+FCA：迁移契约 + 融合证书代数（重算，不继承）
class FusionCertificate:
    def transfer_ok(self, E, d_src_tgt): return d_src_tgt <= E.T.delta
    def fuse(self, experts, D_comp, A):
        if any((not E.cert.valid) or (not self.transfer_ok(E, d_hat(E)))
               for E in experts):
            return None                                     # 缺证 → 禁止融合
        lam_fuse = sum(E.L * dist(D_comp, E.D) for E in experts)
        cross_ok = (var(w, Sigma_e) <= A.eps_budget**2          # 误差解耦
                    and cascade_bound(experts) <= A.delta_cascade
                    and prior_kl(experts) <= A.delta_prior)
        if lam_fuse > A.delta_fuse or not cross_ok:
            return None                                     # ⊕ = ⊥
        return Compose(experts, bound=recompile(experts, lam_fuse))

# IP-266 NTD：影子反事实净贡献
def negative_transfer(F, probe_set):
    return [i for i, E in enumerate(F.experts)
            if risk(F, probe_set) - risk(F.without(i), probe_set) < -TAU_NT
            and stable(i, W)]

# IP-268 MINT†：迁移感知交互（复用 R69 VoI）
def choose_transfer_action(F, d_hist, budget):
    best = None
    for g in (self_calib(), active_query(), boundary_probe(), *r69_info_actions()):
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = (entropy(d_hist) - expected_entropy(d_hist, g)) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None        # 买不起 → 不支付

# IP-274 主闭环（严格包含 R69）
def FUSE_RAS_round(M, obs):
    F = M.fca.fuse(M.experts, M.D_comp, M.assumptions)      # 1) 重算证书
    if F is None or not M.tcm.all_contracts_valid():
        return R69_round(M, obs)                            # 边界：退 R69
    d_ale, d_epi = M.tgb.split(M.transfer_gap(F))           # 2) 缺口二分
    g = (M.mint_t.choose_transfer_action(F, d_epi, M.budget)
         if d_epi > TAU_TR else None)
    if g is not None and M.tgb.pays(g):
        d_epi = M.tgb.apply(F, M.execute(g)); F = M.fca.rerecertify(F)
    bad = M.ntd.negative_transfer(F, M.probe_set)           # 3) 负迁移去融合
    if bad:
        F = M.fca.unfuse(F, bad); F = M.fca.rerecertify(F) or R69_round(M, obs)
    k, lam, mode, U = R69_round(F, obs)                     # 4) R69 闭环
    lam = max(lam, lam_floor(d_ale + (d_epi if not M.tgb.paid else 0.0)))  # 5) 记账
    M.vqa_f.submit_async(F, d_ale, d_epi, bad, M.tgb.lineage)
    return k, lam, mode, (d_ale, d_epi), F.cert
```

## 4. 推导

**引理 19（融合收益 = 误差解耦）** `Var(e_F)=Σ_i w_i²σ_i²`（独立）→ 有平均红利；`ρ_cross→1` 时 `Var(e_F)→(Σ_i w_iσ_i)²` → 红利归零、风险线性叠加。系：融合收益恰是误差解耦的量，融合风险恰是误差共谋的量；共模故障把红利变负债。

**引理 20（迁移缺口的证据价格）** 可约缺口按 `Δ_epi^tr(B)≤Δ_0/√B` 收缩，则存在 `B*=(Δ_0/δ_trans^OK)²` 使证书重新 Valid。系：缺口有明确价格；预算 `<B*` 时不应强行融合。

**引理 21（去融合单调安全）** NTD 在 A101（`|ĉ−c|≤ε_det`）下正确识别 `N`，则 `R(F↓_N)≤R(F)+ε_det`；最坏 `N`=全部非主源 ⇒ 退化为单源 R69。

**定理 18（FUSE 严格包含 R69）** A99–A102 下，FUSE 目标域期望风险 ≤ R69 单源；且 `d=0`、`n=1` 或 `Δ_epi^tr` 不可支付/交叉条件破坏/血统非法时**逐指令相同**。R69 = 「零迁移、单源」边界。

**定理 19（融合-迁移安全无突变）** 迁移契约 + 交叉条件 + 去融合单调性 ⇒ 融合/去融合切换风险连续、无突变；R68 定理 15 / R69 定理 17 的换装不变式保持 ⇒ 在线插拔不破坏安全包络。

**定理 20（技术融合的收益条件）** 净收益 > 0 ⇔ 误差解耦（ρ_cross 低）∧ 迁移证据便宜（B* 小）∧ `Λ_fuse≤δ_fuse`；否则融合负收益，应保持单源 R69 + 保守。⇒ 可证明「不该融合」本身是有效结论。

## 7. 本轮最大风险

**一句话**：FUSE-RAS 的全部安全论证押在「融合代数与耦合估计是诚实的」这一前提上——但**证书合成幻觉**恰恰是最隐蔽的失败模式：每个源专家都带着在自己领域内真有效的证书，迁移契约也各自成立，可融合后的耦合误差（共模、级联、模态先验污染）正落在所有单组件证书的盲区；若 `Λ_fuse/ρ_cross` 被系统性低估（共模故障让误差看起来不相关、目标证据被泄漏污染、`d̂` 被「表面像源域」骗过），系统就会**拿着一叠真证书，签发一张假的融合许可证**——**融合越顺滑，越可能把若干个「各自安全」的零件拼成一个「整体不安全」的系统；证书的并置，从来不是证书的合成。**

**次级风险与缓解**：共模故障让融合红利变负债（交叉条件(a) + E310 + 保守高估 ρ_cross）；负迁移被融合抹匀而隐形（NTD + 引理 21 + E307）；迁移契约被「表面相似」骗过（定义 323 对偶 + 行为似然 + E305）；目标证据泄漏/污染（血统审计 + E312）；证书重算击穿实时预算（仅变更/告警时重算 + 缓存域统计 + 复杂度表）。
