# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「路径规划」×「力觉传感」）

> R69 问「我该向谁求证、还能问什么」，把 epistemic 歧义交给主动交互（看/问/触）。但它的「触」只是**消歧一个动作模态**：摸一下是为了决定「走左还是走右」。它默认地图是已知的，接触只用来确认「我该选哪个动作」。
>
> 本轮两个灵感把这个默认假设翻过来：**路径规划**的输入从来不是真地图，而是一个信念；**力觉传感**既是唯一的接触级测量通道，又是把「测量」变成「承诺」的执行通道——你一旦伸进去，就承担了卡死、夹持、不可逆的风险。于是 R70 问：**当地图只能靠摸来读，怎样规划一条「摸得够多以致能读懂、又退得出来」的路径？**
>
> 核心命题：**把「接触作为测量」与「接触作为承诺」显式分离；在潜在约束场（摩擦/柔顺/关节类型/局部法向）的信念上规划可达流形图；每条边必须同时过「力限鲁棒管」与「可逆性证书」；同伦类在获得出口证据前不得提交。** 命名 **FORCE-RAS**（Feasibility-Observing Reachability under Contact Envelopes）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我敢摸到哪一步，才知道该往哪走**」——接触不是终点，是地图的边缘。

## 0. 直觉与动机

**灵感 1（路径规划 → 地图是信念，不是几何）**
直觉：经典路径规划把世界当成静态障碍集合 O，求一条避障曲线。但操作任务里「能不能过去」不由几何单独决定，而由**约束流形**决定：摩擦力够不够、孔有没有倒角、门是铰接还是滑轨、表面是刚的还是软的。同一个几何路径，在 μ=0.2 和 μ=0.8 的世界里一个是通途一个是死路。所以规划对象应是**潜在约束场 C(x)=(n, μ, κ, A) 的后验**，而不是一张点云。R69 在「动作模态」的信念上规划；R70 在「约束流形」的信念上规划——从「选哪个动作」上升到「世界允许哪种运动」。

**灵感 2（力觉传感 → 接触是唯一的局部真值，也是不可逆的承诺）**
直觉：视觉会骗你（透明、反光、遮挡、过期地图），但接触不会：手摸到的那一下是真实的法向与切向。这使力/触觉成为 R69「标定不可吸收第二意见」的物理版。但接触有代价：**它是局部的**（只告诉你指尖这一小块），而且**常常不可逆**（伸进窄缝、抓住物体、压上薄壁之后，退路可能已经消失）。所以「摸」同时是信息动作与承诺动作——R69 把它们混为一谈，R70 必须分开：**探针要可逆，承诺要有退路。**

**灵感 3（局部-全局裂隙 → 接触会给出「过度自信的局部正确」）**
直觉：摸一圈都很顺，不代表这条路走得通——可能是个死胡同，只是死胡同的入口很宽。更糟的是，越往里摸越确信「局部可行」，而退路在变窄。这是本轮最重要也最危险的洞见：**力觉是一个局部 oracle，局部一致性会被误读为全局可行性。** 因此必须引入同伦类信念：拿到「出口证据」前同时保留多条拓扑假设，绝不因为「摸得顺」就提交。

**灵感 4（柔顺与偏置的对偶 → 力传感器的慢漂移会被柔顺吸收）**
直觉：R68 的缓变故障被标定吸收；R70 有它的镜像——**力传感器慢偏置会被环境柔顺吸收**：硬物被读成「有点软」，传感器偏置被读成「接触很轻」。单频率、单预压的接触分不开这两者。解决与 R69 同构：用**双频/双预压激励**做刚度辨识，让 κ 与 bias 可分辨；把 (力残差, 几何-接触不一致) 作为对偶通道。

**灵感 5（可逆性是新的安全维度 → 三包络）**
直觉：R68/R69 的安全是「力不超限、位不越界」。接触丰富任务还差一条：**退得出来**。一条路径即使瞬时力/位都安全，若它把系统带进「只能进不能退」的楔形，它就不是安全的。R70 把安全扩成三包络：力包络 ∩ 位包络 ∩ 可逆图。可逆不是保守，而是把「未来的选择权」当作必须守恒的资源。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（FORCE-RAS 总览）** FORCE-RAS = (CFB, RMG, FTT, CAP, TCI, JAM, HTC, CBC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **力包络不变式**：执行轨迹在信念支撑集的最坏情形下仍满足 w(t) ∈ W_adm(C) 且留裕度 ε_f；
(iii) **可逆性不变式**：任何承诺性接触动作必须有经认证的退回策略，能在剩余预算内回到已知自由构型；
(iv) **提交纪律**：在获得 ≥k 个独立探针一致、或显式出口证据前，不得提交单一同伦类/约束假设（R69 证据纪律的拓扑版）。

**定义 311（潜在约束场 CFB）** 环境不是障碍集 O，而是约束场 C(x) = (n(x), μ(x), κ(x), A(x))：局部法向/切向约束、摩擦系数、法向刚度（柔顺）、关节类型（转动/移动/固定）。视觉给几何信念 Ĝ 与先验 p(C|Ĝ)；接触观测 y_t = (w_t, {p_i^c}, I_t^tac) 给似然 p(y|C,a)。规划在 b(C)=p(C|Ĝ,y_{1:t}) 上进行。

**定义 312（接触模式与可达流形图 RMG）** 接触模式 m = 活动接触集合（连杆-物体对 + 接触点）。RMG 节点 = (q, m, b(C))；边 = 柔顺运动原语（guarded move / 混合力位 / 转动-移动切换），边可行当且仅当存在满足摩擦锥且裕度 ≥ ε_f 的扳手解。与几何 PRM 不同，**边有效性是概率的、依赖 b(C) 的**，且接触模式随运动改变（hybrid 切换）。

**定义 313（力限鲁棒管 FTT）** 给定名义扳手轨迹 w̄(t)，对 b(C) 支撑集中概率 ≥ 1−δ 的任意 C，要求 w(t) ∈ W_adm(C) 且保持裕度 ε_f。管半径 ρ_f 为 w̄ 到 ∂W_adm(C) 的最坏情形距离之补；称计划**管可行**当 ρ_f ≤ ε_f。这是把鲁棒 tube-MPC 从状态空间搬到**扳手空间**：扰动不再是噪声，而是「我还不知道的约束」。

**定义 314（测量接触 vs 承诺接触）** 动作分解 a=(a_task, a_probe)。探针接触须满足：冲量 ≤ I_max、可逆、且不改变 C（无塑性变形、物体位移 ≤ δ_x）；承诺接触允许改变世界状态、可产生不可逆构型。**R70 的核心概念分离**：探针是「问地图」，承诺是「改地图」。

**定义 315（接触可辨识性）** 接触扳手是 6 维，而接触状态（点、法向、摩擦、柔顺）维度更高，故存在**力不可分辨**的假设对 (C1,C2)：对所有可行 a，TV(p(y|C1,a), p(y|C2,a)) ≤ ε_id。主动探针选 a 最大化对这些对的判别信息——R69 模态分解在接触域的对应物。

**定义 316（约束场 VoI 与 CAP）** VoI_probe(a_p)=H(C|h)−E_y[H(C|h,a_p,y)]；净收益 = VoI − λ_jam·P_jam(a_p) − c_probe − λ_h·ΔH_homotopy；仅当净收益 > 0 且 JAM 裕度通过时探测。R69 是「C 已知、探针零成本」的退化边界。

**定义 317（卡滞裕度 JAM）** 依楔形/摩擦锥判据定义卡滞锥边界，卡滞裕度 j(x)=dist(w, ∂W_jam(x))；执行要求 j ≥ j_min。**退回证书**：存在反向柔顺运动，在力包络内把系统带回已知自由构型，且 P(成功) ≥ 1−δ_rev。

**定义 318（可逆性证书）** 承诺边 e 仅在存在退回策略 π_rev、满足 P(回到已知自由|e,b) ≥ 1−δ_rev 且期望退回时间 ≤ 预算时才被接纳；否则标记为不可逆边，**除非**有全局出口证明（已知间隙拓扑/感知到的出口），否则禁止进入。

**定义 319（同伦类与拓扑覆盖 HTC）** 路径按同伦类 [γ] 划分。局部接触无法区分同伦类，故信念含拓扑指标 H([γ])。规划在获得「出口证据」前保持 ≥2 条 live 同伦类；提交条件为某类可行裕度超阈值**且**带退回证书。这是对「局部 oracle 过度自信」的正面防御。

**定义 320（接触-几何一致性 TCI）** 几何预测接触 r_ct=‖w_meas − w_pred(Ĝ,b)‖；接触隐含局部面与深度隐含面的偏差 Δ_geo。**Δ_geo 高而视觉残差低 ⇒ 地图过期/被移动/深度偏置**（接触是接触级真值）。这是 R69 引理 17 的物理版。

**定义 321（柔顺-偏置对偶 SID）** 力传感器偏置 b_f 与环境柔顺 κ 在单次接触中不可分：w=κ·δ+b_f。用双频 (ω1,ω2)/双预压 (δ1,δ2) 激励，使 (κ,b_f) 的辨识矩阵满秩，从而 **κ 不能吸收慢偏置**——R68 反吸收引理在接触域的镜像。

**定义 322（三包络复合安全）** 可行集 = 力包络 W_adm ∩ 位包络 𝒳_adm ∩ 可逆图 𝒢_rev。C-RAS-WM 认证扩展为三包络联合认证；探针动作同样要过（探针不得把系统带入不可逆区）。

**定义 323（参与式审计 VQAuditor-F）** 审计：探针是否改变了世界（应无）、是否用单次局部成功证据提交全局承诺、卡滞近失、live 同伦类数量、退回证书是否真实。结论回灌接触预算先验。

**定义 324（对抗接触干扰集 ℰ_contact）** 隐藏低摩擦/粘滞斑块、力/触觉欺骗注入、执行器饱和攻击、以柔顺表面为诱饵的探询陷阱、被柔顺吸收的慢力偏置。AIC-FORCE = AIC-FLUID × ℰ_contact。

**定义 325（证书 J_FORCE）** J_FORCE=(J_FLUID, force_margin_p05, jam_margin_min, reversibility_rate, homotopy_live_count, probe_world_change, contact_calibration_ece, force_cert_ver)。Valid ⇔ Valid(J_FLUID) ∧ 三包络裕度满足 ∧ 无「无出口证明的不可逆提交」。

**定义 326（两级退化：FLUID/CALM 是边界）** C 已知且探针预算为 0 ⇒ 退化为 R69（纯动作模态消歧）；再无 epistemic 交互 ⇒ 退化为 R68。形式上 FORCE 在「已知接触地图」边界上逐指令包含 FLUID，进而包含 CALM；安全侧因三包络 ⊇ 双包络而永不更弱。

**定义 327（双速率分层）** 慢环（10–50Hz）：CFB 更新、RMG 重规划、HTC 同伦维护、CAP/VoI；快环（1kHz）：FTT 跟踪、JAM 反射、退回策略执行。接触丰富控制必须在快环里有「卡滞反射」，不能等慢环规划。

# IP-264 CFB：潜在约束场信念（GP / particle over n, mu, kappa, articulation）
class ConstraintFieldBelief:
    def update(self, y, a):                     # y=(w, contacts, tactile)
        self.b = bayes_update(self.b, y, a)     # p(C | y, a)
        return self.b

    def support(self, delta):                   # 概率 >= 1-delta 的支撑集
        return credible_set(self.b, delta)

# IP-265 RMG：接触模式可达流形图（增量 D* lite，边概率可行）
def build_rmg(q0, b, eps_f):
    G = Graph(); frontier = [(q0, contact_mode(q0))]
    while frontier:
        q, m = frontier.pop()
        for prim in compliant_primitives(q, m):
            if exists_wrench_in_cone(prim, b, margin=eps_f):
                G.add_edge((q, m), (prim.q1, prim.m1), w=prim.cost,
                           p=feasible_prob(prim, b))
                frontier.append((prim.q1, prim.m1))
    return G

# IP-266 FTT：力限鲁棒管（扳手空间 tube）
def tube_feasible(w_nominal, b, eps_f, delta):
    rho = max(dist_to_boundary(w_nominal, C) for C in b.support(delta))
    return rho <= eps_f, rho

# IP-267 CAP：约束场 VoI 探针（无利可图 / 卡滞风险高则不探）
def choose_probe(C_belief, b, budget):
    best = None
    for ap in probe_candidates(C_belief):
        if not budget.allow(ap) or not retreat_certifiable(ap, b): continue
        if jam_margin(ap, b) < J_MIN: continue
        score = voi(C_belief, ap) - LAM_JAM*jam_prob(ap, b) \
                - cost(ap) - LAM_H*homotopy_uncertainty(b)
        if best is None or score > best.score: best = (ap, score)
    return best if best and best.score > 0 else None

# IP-268 JAM：卡滞裕度 + 1kHz 反射
def jam_reflex(w, b):
    j = dist(w, boundary_of_jam_cone(b))
    if j < J_MIN:
        return BACKOFF_RETREAT          # 立即执行已认证退回策略
    return None

# IP-269 HTC：同伦类拓扑覆盖（出口证据前保持 >=2 live）
def homotopy_update(classes, contact_obs, exit_evidence):
    live = [c for c in classes if posterior(c) > P_LIVE]
    if exit_evidence is not None:
        live = [c for c in live if consistent(c, exit_evidence)]
    if len(live) < 2 and exit_evidence is None:
        return RESAMPLE_HOMOTOPY(classes)   # 不提交，补采拓扑假设
    return live

# IP-270 TCI：接触-几何一致性（地图过期的第二意见）
def contact_geometry_check(w_meas, G_hat, b):
    w_pred = predict_wrench(G_hat, b)
    delta_geo = surface_mismatch(w_meas, G_hat)
    return norm(w_meas - w_pred), delta_geo    # delta_geo高 + 视觉残差低 = 地图过期

# IP-271 CBC：探针预算 + k-独立一致提交纪律
def may_commit(evidence, b):
    return independent_agree(evidence, k=2) and homotopy_resolved(b) \
           and retreat_certified(b)

# IP-276 主闭环（继承 R69，插入接触层）
def FORCE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); M.cof.step(obs)          # R68/R69 标定
    M.cfb.update(o.contact, o.action)                    # 约束场信念
    r_ct, d_geo = M.tci.check(o.wrench, M.geometry, M.cfb.b)
    stale_map = (d_geo > TAU_GEO) and (M.last_r_res < TAU_RES)
    # 早停：地图过期 -> 先保守/重感知，不承诺
    if stale_map:
        return M.conservative_replan(M.cfb.b, reason='stale_geometry')
    G = M.rmg.build(o.q, M.cfb.b, EPS_F)                 # 可达流形图
    classes = M.htc.update(M.homotopy, o.contact, o.exit_evidence)
    # 探针：仅在 VoI 正、卡滞裕度足、可退回时
    ap = None if not classes else M.cap.choose_probe(M.cfb, M.cfb.b, M.budget)
    if ap is not None:
        ok = M.jam.guard(ap, M.cfb.b)                    # 1kHz 反射守护
        if ok: M.execute_probe(ap)                       # 只测量，不改变世界
    # 规划：力限管可行的候选边，且带可逆性证书
    path = M.rmg.search(G, M.goal, tube=M.ftt, rev=M.retreat)
    if not M.cbc.may_commit(path.evidence, M.cfb.b):
        return M.hold_and_replan(classes)                # 出口证据不足，保持多假设
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_residual))
    return M.execute(path, lam, guard=M.jam.reflex)

## 3. 推导

**引理 19（局部接触的拓扑盲区）** 设探针区域 R 内不含任何「拓扑见证」（环、出口、自由边界）。则无论 R 内采样多少接触点，同伦类后验熵 H([γ]|y_R) ≥ H_0 > 0：局部接触信息无法把全局拓扑不确定性降到零。系：局部力一致性不构成全局可行性证据；任何仅凭局部探针提交同伦类的策略必有正的死胡同概率。→ 直接支撑 HTC 与最大风险。

**引理 20（力限管的鲁棒可行性）** 若 b(C) 的支撑在约束场度量下直径 ≤ ε_b，W_adm(·) 对该度量 L_W-Lipschitz，则当 ρ_f ≤ ε_f − L_W ε_b 时，执行满足 w ∈ W_adm(C) 的概率 ≥ 1−δ。给出信念精度与力裕度的可交易关系：**要么测得准，要么留裕度**。

**引理 21（可逆承诺的成本不劣）** 令 P_jam 为不可逆进入的卡死概率、C_jam 为其代价，可逆性证书的额外成本 ≤ c_rev。当 P_jam·C_jam ≥ c_rev 时，带证书策略的期望成本不高于裸承诺。系：可逆性是「便宜的保险」，不是保守税。

**引理 22（柔顺-偏置可辨识性）** 双频/双预压激励下辨识矩阵 J=[[δ1,1],[δ2,1]] 满秩 ⇒ (κ,b_f) 可辨识；单次接触 rank(J)=1 ⇒ 只有其组合可辨。故「柔顺吸收慢偏置」仅在单次接触时成立，双激励即破除。→ R69 引理 17 的镜像。

**定理 18（FORCE 严格包含 FLUID 与 CALM）** 在「C 已知、探针预算 0」边界，FORCE 逐指令退化为 FLUID；在「无 epistemic 交互」边界进一步退化为 CALM。安全侧因三包络 ⊇ 双包络 ⇒ 任意状态期望风险不高于前两者；效率侧获得 contact resolution bonus（消解约束不确定性后更敢走）。R68/R69 是 FORCE 的边界，不是被替代。

**定理 19（局部-全局分离）** 由引理 19，存在环境族使任意仅用局部探针的策略全局成功率 < 1；HTC 保持 ≥2 live 类并只在出口证据下提交，则在该族上避免死胡同。因此**同伦维护不是可选项，而是局部接触规划的必要条件**。这是本轮理论核心。

**定理 20（探测净收益门槛）** 探针最优当且仅当 VoI > c_probe + λ_jam P_jam + λ_h ΔH_homotopy：正的信息价值必须超过「承诺风险 + 拓扑未决的继续代价」。当 j < j_min 时 P_jam 发散 ⇒ 不探测，退化为保守/等待/换路。⇒ 探测不是越多越好。

## 6. 本轮最大风险

**一句话**：FORCE-RAS 把安全性押在「可逆性证书」上，而**可逆性只能由同一个被柔顺/偏置污染的接触通道去自证**——系统可能用被 κ 吸收的力读数证明「我退得出来」，实际退路已经很窄；于是最危险的失效是**证书自证**：**摸得越准、越确信、越退不出来**，用一条自证的退路把不可逆的进入合法化。

**次级风险与缓解**：
1. **局部成功被误读为全局可行** → HTC 强制 ≥2 live 同伦类 + 出口证据提交（引理 19、定理 19）；
2. **柔顺吸收慢偏置** → SID 双频/双预压辨识（引理 22）+ TCI 对偶通道；
3. **力限管被信念误差击穿** → 引理 20 的 ρ_f ≤ ε_f − L_W ε_b 可交易关系 + FTT 最坏情形支撑；
4. **卡滞反射与规划冲突** → 双速率分层（定义 327），快环独立守护，慢环只接收反射事件；
5. **对抗接触表面/力欺骗** → ℰ_contact 对抗训练 + k-独立一致提交 + E309–E310。

# IP-264 CFB：潜在约束场信念
class ConstraintFieldBelief:
    def update(self, y, a):                     # y=(w, contacts, tactile)
        self.b = bayes_update(self.b, y, a)     # p(C | y, a)
        return self.b
    def support(self, delta):
        return credible_set(self.b, delta)      # 概率 >= 1-delta 的支撑集

# IP-265 RMG：接触模式可达流形图（概率边 + hybrid 切换）
def build_rmg(q0, b, eps_f):
    G, frontier = Graph(), [(q0, contact_mode(q0))]
    while frontier:
        q, m = frontier.pop()
        for prim in compliant_primitives(q, m):
            if exists_wrench_in_cone(prim, b, margin=eps_f):
                G.add_edge((q, m), (prim.q1, prim.m1),
                           w=prim.cost, p=feasible_prob(prim, b))
                frontier.append((prim.q1, prim.m1))
    return G

# IP-266 FTT：扳手空间力限鲁棒管
def tube_feasible(w_nominal, b, eps_f, delta):
    rho = max(dist_to_boundary(w_nominal, C) for C in b.support(delta))
    return rho <= eps_f, rho

# IP-267 CAP：约束场 VoI 探针（无利可图 / 卡滞风险高则不探）
def choose_probe(C_belief, b, budget):
    best = None
    for ap in probe_candidates(C_belief):
        if not budget.allow(ap) or not retreat_certifiable(ap, b): continue
        if jam_margin(ap, b) < J_MIN: continue
        score = voi(C_belief, ap) - LAM_JAM*jam_prob(ap, b) \
                - cost(ap) - LAM_H*homotopy_uncertainty(b)
        if best is None or score > best.score: best = (ap, score)
    return best if best and best.score > 0 else None

# IP-268 JAM：卡滞裕度 + 1kHz 反射
def jam_reflex(w, b):
    j = dist(w, boundary_of_jam_cone(b))
    return BACKOFF_RETREAT if j < J_MIN else None

# IP-269 HTC：同伦拓扑覆盖（出口证据前保持 >=2 live）
def homotopy_update(classes, contact_obs, exit_evidence):
    live = [c for c in classes if posterior(c) > P_LIVE]
    if exit_evidence is not None:
        live = [c for c in live if consistent(c, exit_evidence)]
    if len(live) < 2 and exit_evidence is None:
        return RESAMPLE_HOMOTOPY(classes)   # 不提交，补采拓扑假设
    return live

# IP-270 TCI：接触-几何一致性（地图过期第二意见）
def contact_geometry_check(w_meas, G_hat, b):
    w_pred = predict_wrench(G_hat, b)
    return norm(w_meas - w_pred), surface_mismatch(w_meas, G_hat)

# IP-271 CBC：探针预算 + k-独立一致提交纪律
def may_commit(evidence, b):
    return independent_agree(evidence, k=2) \
           and homotopy_resolved(b) and retreat_certified(b)

# IP-276 主闭环（继承 R69，插入接触层）
def FORCE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); M.cof.step(obs)          # R68/R69 标定
    M.cfb.update(o.contact, o.action)                    # 约束场信念

    stale_map = (d_geo > TAU_GEO) and (M.last_r_res < TAU_RES)
    if stale_map:
        return M.conservative_replan(M.cfb.b, reason='stale_geometry')
    G = M.rmg.build(o.q, M.cfb.b, EPS_F)                 # 可达流形图
    classes = M.htc.update(M.homotopy, o.contact, o.exit_evidence)
    ap = None if not classes else M.cap.choose_probe(M.cfb, M.cfb.b, M.budget)
    if ap is not None and M.jam.guard(ap, M.cfb.b):
        M.execute_probe(ap)                              # 只测量，不改变世界
    path = M.rmg.search(G, M.goal, tube=M.ftt, rev=M.retreat)
    if not M.cbc.may_commit(path.evidence, M.cfb.b):
        return M.hold_and_replan(classes)                # 出口证据不足，保持多假设
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_residual))
    return M.execute(path, lam, guard=M.jam.reflex)

## 4. 推导

**引理 19（局部接触的拓扑盲区）** 探针区域 R 内无拓扑见证（环/出口/自由边界）时，无论采样多少接触点，H([γ]|y_R) ≥ H_0 > 0。系：局部力一致性不构成全局可行性证据；仅凭局部探针提交同伦类的策略必有正的死胡同概率。

**引理 20（力限管的鲁棒可行性）** b(C) 支撑直径 ≤ ε_b、W_adm(·) L_W-Lipschitz 时，ρ_f ≤ ε_f − L_W ε_b ⇒ 执行满足 w ∈ W_adm(C) 的概率 ≥ 1−δ。给出「测得准」与「留裕度」的可交易关系。

**引理 21（可逆承诺成本不劣）** P_jam·C_jam ≥ c_rev 时，带可逆性证书的期望成本不高于裸承诺。系：可逆性是便宜保险，不是保守税。

**引理 22（柔顺-偏置可辨识性）** 双频/双预压辨识矩阵 J=[[δ1,1],[δ2,1]] 满秩 ⇒ (κ,b_f) 可辨识；单次接触 rank(J)=1 ⇒ 仅组合可辨。故「柔顺吸收慢偏置」可被双激励破除（R69 引理 17 镜像）。

**定理 18（FORCE 严格包含 FLUID 与 CALM）** 「C 已知、探针预算 0」边界下 FORCE 逐指令退化为 FLUID；「无 epistemic 交互」边界下退化为 CALM。三包络 ⊇ 双包络 ⇒ 任意状态期望风险不高于前两者；效率侧获 contact resolution bonus。

**定理 19（局部-全局分离）** 由引理 19，存在环境族使任意仅用局部探针的策略全局成功率 < 1；HTC 保持 ≥2 live 类并只在出口证据下提交，可在该族上避免死胡同。故同伦维护是局部接触规划的必要条件，而非可选项。

**定理 20（探测净收益门槛）** 探针最优当且仅当 VoI > c_probe + λ_jam P_jam + λ_h ΔH_homotopy。j < j_min 时 P_jam 发散 ⇒ 不探测，退化为保守/等待/换路。

## 7. 本轮最大风险

**一句话**：FORCE-RAS 把安全性押在「可逆性证书」上，而**可逆性只能由同一个被柔顺/偏置污染的接触通道去自证**——系统可能用被 κ 吸收的力读数证明「我退得出来」，实际退路已经很窄；最危险的失效是**证书自证**：**摸得越准、越确信、越退不出来**，用一条自证的退路把不可逆的进入合法化。

**次级风险与缓解**：局部成功误读为全局可行（HTC + 出口证据，引理 19/定理 19）；柔顺吸收慢偏置（SID 双激励 + TCI，引理 22）；力限管被信念误差击穿（引理 20 可交易关系 + FTT 最坏支撑）；卡滞反射与规划冲突（双速率分层，快环独立）；对抗接触面/力欺骗（ℰ_contact 对抗训练 + k-独立一致 + E309–E310）。
