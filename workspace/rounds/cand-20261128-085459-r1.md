### 第 8 轮灵感驱动研究记录（新循环 · 第 1 轮）

**灵感词**：语音交互、应用落地

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）把系统从「指令响应」推进到「需求意图推导」，用 DIM/DRC/DAC 在七硬门之外引入 η_demand/η_affect 软因子，并新增 kc_demand 硬门。但 v7 仍有两条悬空边界：(i) **输入边界**——它默认指令 L 已是干净、确定的文本，而真实用户是通过「语音」下达指令的；(ii) **运行边界**——它默认部署环境与离线训练同分布，而「应用落地」后分布会漂移、长尾会暴露。本轮聚焦「**边界不确定性**」：在不推翻 v7 的前提下，新增语音交互前端（VIF）、主动澄清策略（PAC）、运行漂移哨兵（ODS），升级为 EFA-v8；同时修正 v7 软因子可能把阈值「越乘越低」的单调性缺陷。核心原则仍是「硬门只收紧、不放松」。

**直觉与动机**：

1. **语音交互 → 从「文本指令」到「带不确定性的语音证据」**。语音不是文本的透明管道：ASR 给出的是 n-best 而不是单一字符串，口音、噪声、语速、韵律都会改变「同一句话」的可信度。关键洞见是：**不要把 ASR top-1 当成事实，而要把整条 n-best 分布当成证据**。VIF 输出命令分布 π_L、置信度 η_voice 与韵律一致性 η_pros，让下游「知道自己有多不确定」，而不是假装确定。

2. **语音交互 → 从「猜一个」到「问一句」**。v7 在需求不一致时回退到「历史典型行为」，本质仍是「猜」。第 8 轮把「主动澄清」提升为一等动作：当 η_voice 或 η_demand 偏低时，系统先估计「问一句能带来多少信息收益」（VOI），只有当收益超过澄清成本（时间、用户负担）时才提问。关键洞见是：**澄清是一种安全的 fail-closed 行为——它把「不确定下执行」换成「不确定下询问」**。

3. **应用落地 → 从「离线证书」到「在线可运维」**。七硬门证明的是「给定分布内输入，执行是安全的」；落地后输入分布会漂移（新口音、新任务、新环境、传感器老化）。关键洞见是：**部署本身需要一个系统级准入闸**——ODS 用序贯变点检测监控嵌入、ASR 置信度、硬门拒绝率、回退率的漂移，一旦超阈值就进入影子模式或遥操作，而不是继续自动执行。这把「安全」从「单条轨迹的性质」扩展为「整套自治是否被允许开启」的性质。

4. **应用落地 → 从「一次性发布」到「灰度—影子—回滚」**。新策略先在影子模式下与在役基线并行、只观测不执行；当一致率、安全裕度、时延预算同时达标才提升为 canary，异常则自动回滚。关键洞见是：**部署的默认状态应是「不自动执行」**。

**关键洞见**：第 7 轮回答「系统该做什么」；第 8 轮回答「系统凭什么敢在真实语音与真实现场里做」。七硬门 kc_evidence_forged_v5 与 v7 的 kc_demand 记号原样复用；本轮新增的只有：
- IP-505 VIF（语音交互前端），
- IP-506 PAC（主动澄清策略，VOI 驱动），
- IP-507 ODS（运行漂移哨兵），
- IP-508 EFA-v8（风险单调软因子链 + 系统级部署准入闸 kc_deploy）。

**形式化目标（增量）**：

1. **VIF（Voice Interaction Front-end）**：<br>
   - ASR 产生 n-best：H = {(L_i, p_i)}_{i=1}^{N}，Σ_i p_i = 1（p_i 经温度标定）；<br>
   - 语义投影到命令码本 C = {c_1,...,c_M}：π_L ∈ Δ^{M-1}；<br>
   - 语音置信度：η_voice = 1 - H(π_L)/log M ∈ [0,1]；<br>
   - 韵律一致性：η_pros = P(congruent | prosody, semantics) ∈ [0,1]；<br>
   - 综合语音证据：η_v = λ·η_voice + (1-λ)·η_pros，默认 λ=0.6。

2. **PAC（Proactive Ask / Clarification）**：<br>
   - 动作空间 A = A_exec ∪ A_ask，澄清问题 q ∈ Q；<br>
   - 价值信息：VOI(q) = E_{a~P(a|q,b)}[U(b')] - U(b) - c_ask(q)，b 为意图后验、b' 为回答 a 后的后验；<br>
   - 决策：仅当 η_v ≥ τ_voice 且 η_demand ≥ τ_demand 才 act；否则若 max_q VOI(q) > 0 且预算 b_t > 0 且耐心 ≠ 低，则 ask(argmax VOI)；否则回退 v7；<br>
   - 用户耐心 s_patience ∈ {高,中,低} 随连续提问递减，调制 c_ask；<br>
   - **紧急例外**：当环境风险高于安全立即动作收益时，禁止提问，直接走保守回退（活性优先于信息）。

3. **ODS（Operational Drift Sentinel）**：<br>
   - 监控特征 z_t = [e_t, conf_t, reject_t, fallback_t, latency_t]；<br>
   - 参考分布 P_0，能量距离 D_t = D_E(z_{t-w:t}, P_0)（或 MMD）；<br>
   - 序贯检测：CUSUM S_t = max(0, S_{t-1} + D_t - k)，S_t > h 告警，h 由 bootstrap 控制误报 ARL0；<br>
   - 健康度：η_drift = exp(-λ_d·max(0, D_t - D_ref)) ∈ (0,1]；<br>
   - 准入：η_drift ≥ τ_drift ∧ calibrated ∧ ¬incident 才允许自动执行，否则 kc_deploy 关闭自治（影子/遥操作）。

4. **EFA-v8（风险单调软因子链 + 部署准入闸）**：<br>
   - **修正 v7 缺陷**：不直接乘 η_i（η_i<1 会把阈值乘低、放松 fail-closed），而是把每个软因子转成安全裕度 s_i ∈ [0,1]、风险 r_i = 1 - s_i，用风险权重 w_i ≥ 0、Σ w_i ≤ 1 定义阈值倍率 m_i = (1+ε_max)^{w_i·r_i}；<br>
   - 则 Π_i m_i = (1+ε_max)^{Σ_i w_i r_i} ∈ [1, 1+ε_max]，默认 ε_max = 0.3，恒有 Π_i m_i ≤ 1.3；<br>
   - 阈值：τ_i^v8 = γ_i·τ_i^v7·Π_i m_i，只升不降；<br>
   - 排序分数：ECS_v8 = ECS_v7 · Π_i (1 - δ_i·r_i)，δ_i ∈ [0,1]，仅用于排序、不放松硬门；<br>
   - 系统级前置硬闸 kc_deploy：η_drift 不达标则整套自治不开启。

5. **形式化定义**：给定语音输入 S、现场流 Z：<br>
   - (π_L, η_v) = VIF(S)；<br>
   - η_demand = DIM/DRC(v7)（以 E[π_L] 为指令证据）；<br>
   - 若 kc_deploy(η_drift) = false：返回 SHADOW/TELEOP，不执行；<br>
   - 否则若 η_v < τ_voice 或 η_demand < τ_demand：q* = argmax VOI；若 VOI(q*)>0 且预算>0：ASK(q*)；否则走 v7 回退；<br>
   - 否则按 EFA-v8 软因子链生成并验证轨迹。

**本轮最大风险**：**「澄清即安全」的假设**——PAC 把提问当作不确定性的兜底，但澄清依赖用户能听懂、愿回答、答得对；在噪声车间、老人、紧急场景中，用户可能无法或不愿回答，系统就会卡在「等待澄清」与「冒险执行」之间，而七硬门无法为这种交互级不确定性签发证书。

## 2. 关键算法骨架

### IP-505 VIF：语音交互前端

```python
@dataclass
class VoiceInteractionFrontend:
    """VIF：把语音流变成命令分布 + 置信度，而不是单一文本。"""
    asr: ASR
    stm: SemanticTrajectoryMapper
    codebook: Tensor               # C ∈ R^{M×d}，命令码本
    prosody_scorer: nn.Module      # 韵律-语义一致性打分
    tau: float = 0.1               # 码本 softmax 温度
    lam: float = 0.6

    def transcribe(self, audio) -> list[tuple[str, float]]:
        nbest = self.asr.nbest(audio, N=5)
        ps = temperature_calibrate([s for _, s in nbest])   # 分数→概率
        return [(L, p) for (L, _), p in zip(nbest, ps)]

    def command_distribution(self, nbest) -> Tensor:
        e = torch.stack([self.stm.embed(L) for L, _ in nbest])      # N×d
        logits = -torch.cdist(e, self.codebook).pow(2) / self.tau  # N×M
        p_code = torch.softmax(logits, dim=-1)                     # N×M
        w = torch.tensor([p for _, p in nbest])                    # N
        return (w[:, None] * p_code).sum(0)                        # π_L ∈ Δ^{M-1}

    def observe(self, audio, prosody) -> tuple[Tensor, float, float]:
        nbest = self.transcribe(audio)
        pi_L = self.command_distribution(nbest)
        H = -(pi_L * (pi_L + 1e-8).log()).sum()
        eta_voice = 1.0 - (H / math.log(pi_L.numel())).item()
        eta_pros = self.prosody_scorer(prosody, self.stm.embed(nbest[0][0]))
        eta_v = self.lam * eta_voice + (1.0 - self.lam) * eta_pros
        return pi_L, eta_voice, eta_v

    def expected_command(self, pi_L: Tensor) -> str:
        j = int(pi_L.argmax())
        return self.codebook.decode(j)
```

### IP-506 PAC：主动澄清策略

```python
@dataclass
class ProactiveClarifier:
    """PAC：VOI 驱动的『问一句 vs 做一步』。ASK 返回空轨迹 = 不执行。"""
    dim: DemandIntentModel
    drc: DemandReasoningChain
    question_gen: Callable
    utility: Callable                # U(x, ρ) 代理效用
    tau_voice: float = 0.6
    tau_demand: float = 0.7

    def decide(self, pi_L, eta_v, eta_demand, rho_demand, context, b_t, patience):
        if eta_v >= self.tau_voice and eta_demand >= self.tau_demand:
            return Decision("ACT", None)

        # 紧急例外：活性优先于信息，禁止提问
        if context.risk_level == "紧急":
            return Decision("FALLBACK_V7", None)

        Q = self.question_gen(pi_L, rho_demand, context, top_k=3)
        best_q, best_voi = None, -math.inf
        for q in Q:
            voi = self.voi(q, pi_L, rho_demand, context, patience)
            if voi > best_voi:
                best_q, best_voi = q, voi

        if best_voi > 0.0 and b_t > 0 and patience != "低":
            return Decision("ASK", best_q, best_voi)
        return Decision("FALLBACK_V7", None)

    def voi(self, q, pi_L, rho_demand, context, patience) -> float:
        b = Belief(pi_L, rho_demand)
        u_before = max(self.utility(x, r) for x, r in b.support())
        u_after = 0.0
        for a, pa in self.answer_model(q, b):        # 用户可能的回答及概率
            b_post = b.update(a, q)
            u_after += pa * max(self.utility(x, r) for x, r in b_post.support())
        return u_after - u_before - self.cost(q, patience)

    def cost(self, q, patience) -> float:
        base = self.time_cost(q) + self.burden(q)
        return base * {"高": 1.0, "中": 1.5, "低": 3.0}[patience]
```

### IP-507 ODS：运行漂移哨兵

```python
@dataclass
class OperationalDriftSentinel:
    """ODS：部署期分布漂移的序贯检测 + 系统级准入。"""
    ref: Tensor                    # 参考窗口 P_0
    k: float = 0.5                 # CUSUM 松弛量
    h: float = 8.0                 # 告警阈值（bootstrap 标定 ARL0）
    lam_d: float = 2.0
    tau_drift: float = 0.5
    ref_D: float = 0.0
    S: float = 0.0

    def energy_distance(self, z: Tensor) -> float:
        return (2.0 * torch.cdist(z, self.ref).mean()
                - torch.cdist(z, z).mean()
                - torch.cdist(self.ref, self.ref).mean()).clamp_min(0.0)

    def update(self, z_new: Tensor) -> tuple[float, bool]:
        D = self.energy_distance(z_new)
        self.S = max(0.0, self.S + D - self.k)
        alarm = self.S > self.h
        eta_drift = math.exp(-self.lam_d * max(0.0, D - self.ref_D))
        return eta_drift, alarm

    def admission(self, eta_drift, calibrated: bool, incident: bool) -> bool:
        return (eta_drift >= self.tau_drift) and calibrated and not incident
```

### IP-508 EFA-v8：风险单调软因子链 + 部署准入闸

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：kc_deploy 前置；软因子链只收紧（风险加权幂律）。"""
    v7: EvidenceForgingAssemblerV7
    vif: VoiceInteractionFrontend
    pac: ProactiveClarifier
    ods: OperationalDriftSentinel
    eps_max: float = 0.3
    weights: dict = field(default_factory=lambda: {
        "g": 0.15, "topo": 0.15, "interp": 0.20,
        "cmd": 0.20, "demand": 0.15, "voice": 0.10, "drift": 0.05,
    })

    def risk_multiplier(self, margins: dict[str, float]) -> float:
        # margins[j] = s_j ∈ [0,1]，1 表示最安全
        exponent = sum(self.weights[j] * (1.0 - m)
                       for j, m in margins.items())
        exponent = max(0.0, min(1.0, exponent))     # Σ w_j ≤ 1 ⇒ ≤ 1
        return (1.0 + self.eps_max) ** exponent     # ∈ [1, 1.3]

    def select(self, audio, t_now, context):
        # 1) 语音证据
        pi_L, eta_voice, eta_v = self.vif.observe(audio, context.prosody)
        # 2) 部署健康 + 系统级准入闸（不健康则不自动执行）
        eta_drift, alarm = self.ods.update(context.z_window)
        if not self.ods.admission(eta_drift, context.calibrated, context.incident):
            return False, None, "KC_DEPLOY_SHADOW_OR_TELEOP"

        # 3) 需求推断（v7），以期望指令为证据
        L_star = self.vif.expected_command(pi_L)
        rho_demand, eta_demand = self.v7.dim.forward(
            history=self.v7.lmem.get_history(), context=context.__dict__,
            env=context.env, L=L_star)

        # 4) 澄清决策（ASK 不产生轨迹）
        dec = self.pac.decide(pi_L, eta_v, eta_demand, rho_demand,
                              context, context.budget, context.patience)
        if dec.kind == "ASK":
            return False, None, f"ASK:{dec.question}"
        if dec.kind == "FALLBACK_V7":
            return self.v7.select(L_star, t_now, context)

        # 5) 风险单调软因子链
        margins = {
            "g": self.v7.ggc.safety_margin(context),
            "topo": self.v7.mctm.safety_margin(context),
            "interp": self.v7.stm.interp_margin(L_star),
            "cmd": self.v7.stm.cmd_margin(L_star),
            "demand": eta_demand,
            "voice": eta_v,
            "drift": eta_drift,
        }
        m = self.risk_multiplier(margins)
        # v7.select 扩展参数 m：τ_i^v8 = γ_i·τ_i^v7·m，只收紧
        ok, x, tag = self.v7.select_with_scale(L_star, t_now, context, m)
        if not ok:
            return False, None, "V8_TIGHTENED_FAIL_CLOSED"
        return True, x, f"{tag}_V8"
```

### 集成流水线（v7 → v8）

```
离线/慢时域：
  VIF 训练：n-best + 码本投影 + 温度标定 + 韵律一致性分类
  PAC 标定：用离线对话日志拟合 answer_model 与代理效用 U
  ODS 标定：在参考数据上 bootstrap 选 k、h，使 ARL0 ≥ 1e4
  联邦下发：VIF/PAC 权重、码本、τ_voice/τ_drift、风险权重 w_j → 站内签名分发

在线准入（亚秒级，位于 v7 之前）：
  VIF.observe(audio) ──▶ π_L, η_v
  ODS.update(z_window) ──▶ η_drift
  if not kc_deploy: return SHADOW/TELEOP          # 默认不自动执行
  if η_v<τ_voice or η_demand<τ_demand:
      q* = argmax VOI; if VOI(q*)>0 and budget>0: return ASK(q*)
      else: return v7 fallback
  else: EFA-v8 软因子链（只收紧）× v7 七硬门

在线控制环（目标 < 1.0 ms，ASR 流式另计）：
  VIF 流式增量解码，码本投影 O(N·M·d)
  ODS 用子采样 MMD 近似，O(w·m·d)，每 256 帧一次
  risk_multiplier 仅 O(7) 幂运算
```

## 4. 正确性论证（增量更新）

### 定理 13（风险单调收紧 / Monotone Tightening）

**陈述**：设安全裕度 s_j ∈ [0,1]、风险 r_j = 1 - s_j、权重 w_j ≥ 0 且 Σ_j w_j ≤ 1、ε_max = 0.3，定义 m = (1+ε_max)^{Σ_j w_j r_j}。则 m ∈ [1, 1.3]，且 τ_i^v8 = γ_i·τ_i^v7·m ≥ τ_i^v7。于是：

- Exec_CADVS-v8 ⊆ Exec_CADVS-v7 ⊆ … ⊆ Exec_CADVS-v5；
- 与 v7 不同，**任何** η<1 的软因子都不会把阈值乘低（v7 直接乘 η_j 会在 η_j<1 时放松 fail-closed）。

**证明**：r_j ∈ [0,1] 且 w_j ≥ 0 ⇒ 指数 e = Σ_j w_j r_j ∈ [0, Σ_j w_j] ⊆ [0,1]。故 m = (1.3)^e ∈ [1, 1.3]。阈值随 m 单调不减；硬门判定 1[s ≥ τ] 在 τ 增大时结果不变或更严格，故执行集只缩不扩。v7 的缺陷在于 η_j 本身可小于 1，乘积可小于 1 使 τ 下降；本构造用「风险非负指数」消除了该路径。∎

### 定理 14（澄清决策的最优性与预算界）

**陈述**：单步决策下，最大化期望效用的策略为：当且仅当 max_q VOI(q) > 0 时提问。若 VOI 作为集合函数在问题集上子模且预算为 B，则贪心提问达到 (1-1/e) 的近似最优。

**证明**：单步情形由 Bellman 最优性直接得到：ask 的期望效用比 act 多出 VOI(q)，故 ask 优于 act 当且仅当 VOI(q)>0。预算情形引用 Nemhauser–Wolsey–Fisher 的子模最大化贪心近似界。**注意**：该结论以「代理效用 U 与 answer_model 校准良好」为前提；若 U 失准，最优性不成立（见诚实声明）。∎

### 定理 15（部署准入的 fail-closed）

**陈述**：若 kc_deploy = false，则 EFA-v8 不返回任何自动执行轨迹，系统仅处于影子模式或遥操作；因此七硬门的安全性质在「自治开启」期间保持不变。

**证明**：select 在 kc_deploy=false 时直接返回 (False, None, "KC_DEPLOY_SHADOW_OR_TELEOP")，不进入 v7/v8 提议与执行链。故自动执行集为空，七硬门约束空真成立。**代价是活性**：任务可能停滞，需人工介入。∎

### 定理 16（澄清的安全-活性权衡）

**陈述**：ASK 动作不产生执行轨迹，故不引入新的安全违规；但它把「误执行风险」转化为「任务停滞风险」。在紧急场景中，PAC 的紧急例外保证活性优先。

**证明**：ASK 返回 (False, None, "ASK:q")，执行集为空；紧急例外在 risk_level="紧急" 时直接走 v7 回退而非提问。∎

### 诚实声明

- **VOI 代理效用的校准风险**：U 与 answer_model 是离线拟合的代理，真实用户效用不可观测；若代理偏差大，VOI>0 可能对应「问了也没用」。
- **ODS 的检测延迟**：变点检测存在固有延迟，告警前的窗口内可能已发生漂移下的执行；η_drift 是「事后健康度」而非「事前保证」。
- **语音置信度未必校准**：不同口音、信噪比下 η_voice 的可靠性不同；温度标定只能缓解，不能消除。
- **澄清的交互不确定性**：用户可能答非所问、沉默或改变主意；answer_model 无法覆盖这些情况。
- **软因子链仍是启发式**：定理 13 只保证「不放松」，不保证「收紧得恰到好处」；过度收紧会降低任务成功率。

## 5. 实验设计与验证计划（仿真 → 实机 → 小规模现场）

### 5.1 实验设计（MuJoCo 3.x + MJX + 语音合成/识别）

- **平台**：UR10e（6DOF）+ 移动底盘（2DOF）+ 流式 ASR + 麦克风阵列 + 摄像头。
- **数据集**：
  - 语音：LibriSpeech + Common Voice + 领域指令集；叠加车间噪声（babble/machinery）于 SNR ∈ {20, 10, 5, 0} dB；用 TTS 合成多口音。
  - 澄清：用 LLM 用户模拟器生成回答，注入回答错误率 ∈ {0%, 10%, 30%} 与沉默率 ∈ {0%, 20%}。
  - 漂移：注入口音切换、光照偏移、传感器偏置、任务长尾扩展。
- **对照**：v7-top1（ASR top-1）、v8-full、消融 A21（无 VIF，用 top-1）、A22（无 PAC，总是 v7 回退）、A23（无 ODS，总是允许自治）、A24（v7 原始非单调软因子）、A25（无影子模式，直接 canary）。
- **场景**：
  - (a) 噪声语音：「把那个红的拿过来」在 5 dB 下 n-best 分散 → η_v 低 → 澄清「是左边红盒还是右边红瓶？」。
  - (b) 长尾指令：码本外新物体 → π_L 高熵 → 澄清或请求人工标注。
  - (c) 用户答错：模拟器给错误回答 → 后验仍低 → 第二次澄清或回退。
  - (d) 漂移注入：新口音上线后 ASR 置信度整体下移 → ODS 告警 → 影子模式 + 人工复核。
  - (e) 紧急场景：人靠近机械臂 → risk_level="紧急" → 禁止提问，直接保守回退。
- **指标**：
  - VIF：η_voice 的 ECE（校准误差）、n-best 覆盖率。
  - PAC：澄清精度（改变动作的提问占比）、不必要提问率、VOI 校准、用户负担（提问数/任务）。
  - ODS：检测延迟、ARL0、误报率、回滚时间。
  - 整体：噪声下任务成功率、七硬门通过率、安全违规（目标 0）、控制环 P99、SUS 可用性评分。
- **部署协议**：离线验证 → 影子模式 2 周（只观测）→ 10% canary 1 周 → 逐步放量；任一安全指标退化即自动回滚。

## 7. 本轮最大风险（最终确认）

**一句话**：**「澄清即安全」的假设**——PAC 把提问当作不确定性的兜底，但澄清依赖用户能听懂、愿回答、答得对；在噪声车间、老人、紧急场景中，用户可能无法或不愿回答，系统就会卡在「等待澄清」与「冒险执行」之间，而七硬门无法为这种交互级不确定性签发证书。
