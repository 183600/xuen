# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「异常检测」×「常识推理」）

> R69 把不确定性一分为二：aleatoric 交给 λ_floor 收紧，epistemic 交给「看/问/触」的主动交互去消解，并用流似然给出标定不可吸收的第二意见。它问出了「我该向谁求证、还能问什么」。但 R69 有两个从未写进证书的隐含前提：
> - **（H1）模型类是良定的（well-specified），且观测落在它的支撑域内。** 模态分解 `H_mode·g(Δ_min)`、VoI、ECE、流似然，全部只在「o 是训练分布里那种世界」时才有意义。R69 从不问「我是否在一个自己能描述的世界里」。当 o 是分布外（OOD）样本时，流策略仍会吐出 K 个模态、仍会算出一个熵、仍会选出一个「信息量最大」的问题——但这个问题是关于一个不存在的世界的；问得越准，错得越自信。**这比 R69 自陈的「模态权重没校准」更根本：不是权重错了，是根本没有对应的模态。**
> - **（H2）三条证据通道彼此独立。** 但传感器残差、流似然、跨模态环一致性全都建立在同一个表征 `z_t=Φ(o)` 上，且流似然与策略共享 trunk。若一个连贯偏置 δ 落在 `DΦ` 的零空间里，三条通道不是「各自被骗」，而是**从一开始就看不见 δ**。R69 的「第二意见」只在偏置方向能被 Φ 看见时才成立。
>
> 本轮两个灵感正好补上这两块缺失：
> - **异常检测**给出**支撑域检验**：用共形预测把「统计上没见过」变成一个带有限样本保证的门，并用一个与策略解耦的冻结编码器去看 Φ 的盲区；它引入第三类不确定性 `U_nov`（模型错误指定），这类不确定性**不可由 VoI 消解**，只能升级、弃权或留给离线学习。
> - **常识推理**给出**关系不变量**：支撑、重力、接触因果、客体永久性、可供性、社交规范、数值一致性。它看的不是特征向量，而是**结构**，因此对零空间偏置敏感；它还能对异常做分诊（良性新颖 vs 危险错误指定），并生成「可证伪的探针」、审查人类回答的合理性。
>
> 核心命题：**在问「问谁」之前，先问「我是否在一个我的模型能描述的世界里」。** 三分不确定性 `(U_ale, U_epi, U_nov)`：支撑检验先于一切推理；支撑外 `U_epi` 置为未定义、禁止交互；支撑内仍走 R69，但常识不变量拥有一票**否决权**。权限必须不对称：共形通道有「有限否决 + 受 α 约束的有限许可」，常识通道**只有否决权、没有许可权**——因为前者有分布无关的有限样本保证，后者只是一个会幻觉的生成先验。命名 **CANARY-RAS**（Conformal ANomaly-aware Reasoning with commonsense invariants：共形异常门控 × 常识不变量推理的矿灯金丝雀）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我怎么知道自己没有在问一个不存在的世界**」——在学会提问之前，先学会怀疑自己的本体论。金丝雀不负责挖煤，它只负责在空气变坏时先倒下。

## 0. 直觉与动机

**灵感 1（异常检测 → 支撑域是先于一切推理的前提）**
直觉：R69 像一个只会在已知选项里做选择题的考生：A、B 两个模态都合理时，它去问哪一个更对；但如果正确答案是 C——一个它从未见过的世界——它既不会选 C，也不会意识到题出错了。异常检测补的正是这个「题目本身是否在我的考纲内」的判断。技术上不是简单加一个 OOD 分数：要有**有限样本保证**，就得用共形预测（用一组认证过的校准样本给出 p 值，`p≤α` 即判定越出 `1−α` 支撑），而不是拍一个 softmax 阈值。更关键的是，机器人数据流不是独立同分布的，一次性的共形保证会在漂移中失效，所以需要时序共形（自适应共形推断 / 共形鞅）把「误报率 ≤ α」从单次检验扩展为长程保证。

**灵感 2（常识推理 → 结构不变量是特征空间之外的证据）**
直觉：一个偏置若恰好落在共享编码器 Φ 的零空间，特征看起来毫无异常，残差为零，策略也觉得「在这个错世界里这样走很顺」。但世界的关系结构变了：杯子悬空、物体穿过桌面、门关着却伸手去拿后面的东西、回答者说「我把它放在桌上」但桌上没有。**关系不变量是在图上定义的谓词，不是特征向量上的距离**，所以它能看见特征看不见的东西。常识在这里不是「让 LLM 说一句像不像人话」，而是一组带管辖范围的、可审计的谓词：支撑关系、重力、接触因果、客体永久性、可供性、社交规范、数值一致。它粗糙，但它的错误模式与统计异常检测器**不同**——这正是做「第二意见」所需要的。

**灵感 3（三分法 → 新颖不是歧义，门控顺序必须反转）**
直觉：R69 的 VoI 公式 `H(M|o) − E[H(M|o,y)]` 有一个隐藏前提：`M` 的取值集合是正确且完备的。分布外时，这个前提破裂，plug-in VoI 可以很大，但真实信息增益为零——系统会追问一个幻影，并把「问到了」当成「确认了」。所以本轮第一件事是把门控顺序反过来：**先做支撑检验，`p≤α` 时不计算 VoI、不交互、直接进入升级流程**；只有在支撑内，R69 的二分才重新有意义。三分法因此不是给不确定性再加一个标量，而是给「不确定性属于哪一类」加一个前置判别：aleatoric 可收紧，epistemic 可询问，novelty 只能升级/弃权/离线学习。

**灵感 4（共形时序 → 把一次性保证变成机器人可用的长程保证）**
直觉：实验室里「校准集与测试集可交换」是一个强假设，真实机器人会换房间、换光照、换物体、换人。若直接用固定 α，漂移之后误报率会悄悄升高，最后系统要么天天报警（疲劳），要么被运维关掉（更危险）。自适应共形推断用在线反馈更新 `α_t`：`α_{t+1}=α_t+γ(α−err_t)`，使长程误报率仍贴近 α；共形鞅/e-value 则给出「是否发生了分布漂移」的可选停止检验。这把「异常检测」从一次性离线阈值，变成可以写进实时证书的、带时间语义的量。

**灵感 5（双刃剑 → 常识会幻觉，异常检测会被投毒，所以权限必须不对称）**
直觉：一旦把「常识」接进安全回路，就等于请了一个会一本正经胡说八道的专家；一旦把「异常分数」接进证书，就等于给校准集加了一个新的攻击面（投毒几个校准样本就能把支撑域撑大）。所以本轮最重要的设计不是再加一个模块，而是**给每个证据源规定权限**：共形异常通道可以有「有限许可」，因为它的许可是「在支撑内」这种弱主张，且有 α 预算可计；常识通道**只能投否决票**，它的缺席（没发现违反）**不能**用来授权任何更激进的动作。这样即使常识模型完全幻觉，系统最多更保守，不会更危险——安全证明因此不需要相信常识，只需要相信「它不能放松任何东西」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CANARY-RAS 总览）** CANARY-RAS = (NAD, SGT, TRI, CIG, AAG, RAS-WM†)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；新颖事件只进审计缓冲，不改在线参数）；
(ii) **支撑先于推理**：R69 的 VoI/epistemic 推理仅在共形支撑内有效；支撑外 `U_epi := ⊥`，禁止交互；
(iii) **权限不对称**：共形通道有有限否决权与受 α 约束的有限许可权；常识通道只有否决权，无许可权；
(iv) **证据独立性与校准完整性**：异常编码器与策略 trunk 解耦并做独立性审计；校准集须带来源哈希，投毒检验失败即回退到 R69。

**定义 311（共形支撑检验 NAD）** 冻结编码器 `ψ`（与 Φ 异构、训练数据不相交），非一致性分数 `s(o) = −log p_ψ(o)`（或嵌入空间距离）。认证校准集 `D_cal = {o_i}` 的分数升序为 `s_(1)≤…≤s_(n)`。新观测 p 值
`p_t = (1 + #{i : s_i ≥ s(o_t)}) / (n+1)`。支撑域 `S_α = {o : p_t > α}`；新颖标志 `n_t = 1[p_t ≤ α]`。在可交换性下 `P(n_t=1 | o_t ∈ 𝒟) ≤ α`。

**定义 312（时序共形 CCT）** 非可交换流上用自适应共形：`err_t = 1[p_t ≤ α_t]`，`α_{t+1} = clip(α_t + γ(α − err_t), α_lo, α_hi)`，给出长程误报率 `(1/T)Σ err_t ≤ α + O(γ)`。另维护共形鞅 `E_t = Π_{i≤t} e_i`（e-value）用于「分布是否已漂移」的可选停止检验；`E_t` 越界 ⇒ 立即提升保守级别并触发校准复核。

**定义 313（三分不确定性）** `U_ale = Σ_k ŵ_k tr(Σ_k)`（模态内，不可约）；`U_epi = H_mode·g(Δ_min)`（模态间，可约）；`U_nov = 1 − p_t ∈ [0,1]`（模型错误指定，非 VoI 可解）。三者不进同一个标量：`U_ale` 进 λ floor，`U_epi` 进交互通道，`U_nov` 进升级/弃权通道（定义 314、324）。

**定义 314（新颖门 NG，修正 R69 定义 298 的顺序）** 每步先算 `(n_t, p_t)`。若 `n_t=1`：**不**计算 VoI、**不**调用 MINT，直接进入 TRI 分诊；若 `n_t=0`：按 R69 正常流程。形式化有效 VoI：`VoI_eff(g) = 1[p_t>α_t]·[VoI(g)−c(g)]`，支撑外定义为「不可识别」（`−∞`），而非「零」。

**定义 315（关系抽象与不变量 SGT）** 由冻结 VLM/解析器得到带类型的场景图 `G_t=(V,E,τ)`。常识不变量库 `ℐ = {(φ_j, κ_j, c_j)}`：`φ_j(G)∈{−1,0,+1}`（违反/未知/满足），`κ_j(G)∈{0,1}` 为管辖条件（不适用时不投票），`c_j>0` 为违反代价。覆盖支撑/重力/包含/客体永久性/接触因果/可供性/社交规范/数值一致八类。违反集 `V_t={j : κ_j=1, φ_j=−1}`，未知集 `K_t={j : κ_j=1, φ_j=0}`。

**定义 316（不变量证据与软罚）** 不变量不是硬过滤器。定义校准后的对数似然比 `ℓ_j = log[p(φ_j | M)/p(φ_j | ¬M)]`（在留出集上校准，不直接采用 LLM 置信度）与软罚 `pen(m_k) = Σ_j c_j·1[φ_j(m_k)=−1]`。常识对模态只做**减分**：`score_k = log ŵ_k − β·pen(m_k)`，`β` 有上界且不随常识置信度增大而释放更多许可。

**定义 317（四象限分诊 TRI）** 以 `(n_t, v_t)` 为轴，`v_t = 1[Σ_{j∈V_t} c_j ≥ C_min]`：
| | `v_t=0` | `v_t=1` |
|---|---|---|
| `n_t=0` | **N** 名义：走 R69 | **S** 静默语义异常：R69 看不见的连贯偏置 |
| `n_t=1` | **B** 良性新颖：需验证探针 | **M** 错误指定：禁止社交交互 |

`S` 是本轮的核心新格子：统计上完全在支撑内、残差与流似然都正常，但世界的关系结构已经错了。`B` 不是「安全」，只是「暂未发现结构违反」，因此仍需验证探针，不能直接授权激进动作。

**定义 318（常识约束仲裁 CCA）** 可采纳模态集 `M_cs = {m_k : pen(m_k)=0}` 仅用于**收缩**候选；若 `M_cs=∅`，不得强行选一个「最不坏」的模态，直接升级到 Level-1。任何情况下 `pen` 只降低 `score_k`，不提高；常识缺失（`K_t` 大）不产生任何正面证据。

**定义 319（可证伪探询 CIG）** 问句/探针不仅要最大化关于模态身份的 VoI，还要最大化关于**分诊格子** `q∈{N,B,S,M}` 的信息：`VoI_tri(g)=H(q|o)−E[H(q|o,y)]`。可证伪条件：`g` 必须能以非零概率把当前格子变成至少另一个格子；否则不发出（避免「问了也不可能改变判断」的无效提问）。归因探针优先选非社交、结构化动作（注视、轻触、改变视角），社交提问只在 `q=N/B` 且证据纪律满足时使用。

**定义 320（回答合理性门 CQE）** 人类/外部回答 `a_h` 先过两道：与 `V_t` 高代价不变量一致；与至少一个独立非社交证据源一致。任一不过 ⇒ 回答作废并计入审计（可能是撒谎、误解或社交工程）。通过也只能作为 R69 的 k 源之一，**永不单独定案**。

**定义 321（解耦异常编码器与独立性审计）** `ψ` 冻结，训练目标（密度/距离）与数据划分均与策略 trunk 不相交；审计量：`CKA(ψ,Φ) ≤ ρ_max` 且条件互信息 `I(ψ;z|o) ≤ ι_max`。任一越界 ⇒ 关闭异常通道、退回 R69（fail-safe），并在证书中标注 `anomaly_channel=disabled`。**理由**：与策略共享盲区的「第二意见」比没有第二意见更危险，因为它提供虚假的安心。

**定义 322（校准完整性）** `D_cal` 带采集批次、时间、场景、操作者哈希；每次启动做可交换性/漂移检验（定义 312 的 e-value），并用留出污染检验估计「需多少投毒样本才能翻转支撑判定」。检验失败 ⇒ `α_t` 自动收紧（而不是放宽），证书标记 `cal_untrusted`。

**定义 323（权限格 AAG）** 每个证据源 `e` 有两个权限：`Veto(e)`（能否提升保守级别）与 `Permit(e)`（能否降低保守级别或放宽证据纪律）。组合算子 `meet`：保守级别取所有证据的最大值；许可取交集。默认配置：共形 `Veto=✓, Permit=仅撤销由 FMA/新颖性引起的升级（概率预算 α）`；常识 `Veto=✓, Permit=∅`；人类回答 `Veto=✓, Permit=需 k 源一致`；R69 原有通道保持原权限。故「证据越多，保守性单调不降」是默认行为；任何放松都必须显式记在 α 预算或 k 源纪律上。

**定义 324（三级升级阶梯与严格包含）**
- **Level-0（N/B）**：R69 正常闭环 + 常识软罚；`λ = max(risk_scale, λ_floor(U_ale + 未消解 U_epi))`。
- **Level-1（S，或 FMA 高但支撑内）**：禁止社交提问；只允许结构化归因探针；`λ = λ_floor(U_ale + U_epi) ∧ λ_floor(U_ale + U_epi + Δ_cs)`（`Δ_cs` 由违反代价给出）。
- **Level-2（M，或 e-value 越界，或校准不可信）**：`U_epi := ⊥`，不做任何交互；`λ = max(λ_floor(U_ale), λ_ood)`，其中 `λ_ood` 由 `U_nov` 给出的最坏情形界确定；必要时安全停机并显式声明「未知」。
包含关系：若所有不变量都不适用（`ℐ=∅` 或 `κ_j=0`）且 `p_t>α_t` 且使用定义 314 的有效 VoI，则 Level-0 **逐指令等于 R69**；再令交互预算为零，则等于 R68。

**定义 325（新颖记忆与告警疲劳治理）** 新颖/静默异常事件写入离线缓冲 `𝒩_buf`（特征、格子、归因、处理结果、哈希），**不在线更新任何参数**。重复出现的同型事件只允许做一件事：提高该类事件的进入代价/收紧 τ，使系统更快升级；不允许因为「上次没事」而降低警戒。这样既守住零学习写操作，又避免报警疲劳导致运维关闭系统。

**定义 326（证书 J_CANARY）** `J_CANARY = (J_FLUID, α_t, p_t, n_t, V_t, K_t, triage_cell, authority_audit, cal_integrity_hash, escalation_level, ψ_version, canary_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ 权限格未越权 ∧ 异常通道独立性审计通过（或已显式关闭）∧ 校准完整性通过（或已收紧）∧ 升级级别与分诊一致`。

## 2. 关键算法骨架

```python
# IP-264 NAD：共形新颖性检测（与策略 trunk 解耦的冻结 ψ）
class ConformalNovelty:
    def __init__(self, psi, cal_scores, alpha, gamma=0.01):
        self.psi, self.cal = psi, sorted(cal_scores)   # 带来源哈希的认证校准集
        self.alpha, self.alpha_t, self.gamma = alpha, alpha, gamma

    def p_value(self, s):
        n = len(self.cal)
        return (1 + (n - bisect_left(self.cal, s))) / (n + 1)

    def step(self, o):
        s = self.psi.nonconformity(o)                  # -log p_psi(o) 或嵌入距离
        p = self.p_value(s)
        novel = (p <= self.alpha_t)
        self.alpha_t = clip(self.alpha_t + self.gamma * (self.alpha - float(novel)),
                            1e-3, 0.3)                 # IP-265 ACI：误报多则收紧
        return novel, p, self.alpha_t

# IP-266/267 SGT + TRI：关系不变量分诊（低频、可缓存）
def triage(G, invariants):
    V = [j for j, (phi, kappa, c) in enumerate(invariants)
         if kappa(G) and phi(G) < 0]
    K = [j for j, (phi, kappa, c) in enumerate(invariants)
         if kappa(G) and phi(G) == 0]
    v = sum(invariants[j][2] for j in V) >= C_MIN
    return v, V, K

def cell_of(novel, v):
```

## 3. 推导

**引理 19（共形支撑的有效性）** 若校准样本与测试样本可交换且 `s` 可测，则 `P(p_t ≤ α) ≤ α`。在非可交换流上，定义 312 的 ACI 给出 `(1/T)Σ err_t ≤ α + O(γ)`；共形鞅在「无漂移」原假设下 `E_t` 为上鞅，故 `P(∃t: E_t ≥ 1/δ) ≤ δ`。系：**误升级概率有界**，且这个界不依赖异常检测器的准确性，只依赖校准与更新规则。

**引理 20（新颖—歧义不可识别）** 设模型类 `𝓜` 不含真实机制 `P*`，`o` 落在 `𝓜` 支撑外。则 plug-in VoI 使用的后验 `p_θ(M|o)` 不是 `P*(M|o)` 的相合估计，且存在一个「幻影问题」`g_φ` 使 `VoI_plug(g_φ)` 任意大而真实信息增益 `I(M*;Y|o,g_φ)=0`。构造：`𝓜` 含两个相距很远的模态 A、B，真实机制为第三个模态 C；「是 A 还是 B」的 plug-in 熵最大，但对 C 零信息。故 VoI 必须在支撑检验之后计算，不能把 `p≤α` 当成「高不确定」继续询问。

**引理 21（静默语义异常的可分性）** 存在连贯偏置 `δ` 使 `δ ∈ ker DΦ`（共享编码器对 δ 一阶不敏感），因此 R68 残差 `r_res≈0`、R69 流似然差 `Δa≈0`；但若 `δ` 改变场景图的关系结构（如支撑边、包含边、接触边），则某个 `φ_j(G)=−1`。反之存在统计上新颖（`n_t=1`）但所有已建模不变量满足（`v_t=0`）的良性新颖。故 `(n_t, v_t)` 四象限的两个通道**互不支配**：没有哪一个单独足够。

**引理 22（常识否决权的安全性）** 若常识证据只做两件事——删除候选模态、提高 λ——则其可达风险集是 R69 可达风险集的子集；即使常识判断任意错误，最坏情形也只是过度保守。系：**常识不需要被信任，只需要被限制**。效率不能来自常识的「许可」，只能来自共形通道的 α 预算与更好的探针定向。

**定理 18（三级严格包含，veto-only 模式）** 在 A99–A102 下，CANARY 默认（veto-only、无共形许可）在任意状态 `s` 的期望风险 ≤ R69 ≤ R68；且在 `p_t>α_t`、`ℐ` 不适用、交互预算与 R69 相同的边界上，两者**逐指令相同**。若启用共形许可（允许用「支撑内」撤销 FMA 升级），则额外风险 ≤ `α·Δ_gap`，其中 `Δ_gap = R_R69 − R_R68` 为保守回退的风险差；该预算必须写进证书，不能默认开启。

**定理 19（升级单调性）** 保守级别 `L_t` 是 `(1−p_t, v_t, E_t, cal_untrusted)` 的单调非减函数；常识与人类回答只能提高 `L_t`，不能降低。故系统不会在安全/激进之间来回翻转；任何降级只能经由显式的共形许可预算发生，且该预算单调消耗、周期重置并留痕。

**定理 20（可证伪探询的预算与幻影抑制）** CIG 只发出满足「存在非零概率改变分诊格子」的 `g`；在 R69 的交互预算约束下，单位时间交互次数有界，且「对幻影模态追问」的比例被 `P(p_t>α_t)` 与可证伪门槛双重压制。若预算内不存在可证伪的 `g`，则不发问、直接按定义 324 升级——**问不出区别的问题，不问**。

## 6. 本轮最大风险

**一句话**：CANARY 的全部安全增益押在两个经验假设上——「两条证据通道真的独立」与「常识不变量库真的覆盖了危险」；但独立性只是审计阈值下的近似，不变量库是一个有限、受具体身体与文化的先验，于是最强的攻击不是制造统计异常，而是**制造一个统计上平常、常识上完美的假世界**：此时共形说「在支撑内」、常识说「没违反」、流似然说「很自洽」，三路证据一致地错，证书只是给幻觉盖了章——金丝雀没叫，不是因为空气好，而是因为毒气恰好是它闻不到的那种。

**定义 324–326（升级阶梯/记忆/证书）** Level-0 走 R69 + 软罚；Level-1 禁社交提问、只允许结构化归因探针；Level-2 `U_epi:=⊥`、安全停机并声明「未知」；新颖记忆只收紧不放松；证书并入 α、分诊与权限审计。

## 3. 关键算法伪代码

```python
# IP-264/265 NAD+CCT：共形支撑检验（冻结 ψ，解耦）
class ConformalNovelty:
    def __init__(self, psi, cal_scores, alpha, gamma=0.01):
        self.psi, self.cal = psi, sorted(cal_scores)
        self.alpha, self.alpha_t, self.gamma = alpha, alpha, gamma

    def p_value(self, s):
        n = len(self.cal)
        return (1 + (n - bisect_left(self.cal, s))) / (n + 1)

    def step(self, o):
        p = self.p_value(self.psi.nonconformity(o))
        novel = (p <= self.alpha_t)
        self.alpha_t = clip(self.alpha_t + self.gamma * (self.alpha - float(novel)),
                            1e-3, 0.3)                 # 误报多 → 收紧
        return novel, p, self.alpha_t

# IP-268/269 SGT+TRI：关系不变量四象限分诊（低频、可缓存）
def triage(G, invariants):
    V = [j for j,(phi,kappa,c) in enumerate(invariants) if kappa(G) and phi(G) < 0]
    K = [j for j,(phi,kappa,c) in enumerate(invariants) if kappa(G) and phi(G) == 0]
    v = sum(invariants[j][2] for j in V) >= C_MIN
    return v, V, K

def cell_of(novel, v):
    return {(False,False):"N", (True,False):"B",
            (False,True):"S",  (True,True):"M"}[(novel, v)]

# IP-270 CIG：只发能改变分诊格子的探针（可证伪性门槛）
def invariant_probe(q, V, K, budget):
    best = None
    for g in info_action_candidates(V, K):              # 注视 / 轻触 / 换视角
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        if not can_change_cell(g, q): continue
        score = voi_triage(q, g) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-274 主闭环：门控顺序反转 + 权限合成
def CANARY_RAS_round(M, obs):
    o, z = M.mtm.forward(obs)
    novel, p, a_t = M.nad.step(o)
    v, V, K = triage(M.sgt.graph(o), M.sgt.invariants)
    q = cell_of(novel, v)

    if q == "M" or M.aag.cal_untrusted or M.nad.e_value_alarm:      # Level-2
        return M.ras68.stop_or_hold(o, lam_ood(1 - p), level=2, cell=q)

    if q == "S":                                                     # Level-1
        U_ale, U_epi, modes, _ = M.fluid.decompose(o, K=2)
        g = M.cig.invariant_probe(q, V, K, M.budget)                 # 非社交归因
        if g is not None: M.cia.execute(g)
        lam = max(lam_floor(M.last_U_ale + U_epi),
                  lam_floor(M.last_U_ale + U_epi + delta_cs(V)))
        return M.ras69.conservative(o, lam, level=1, cell=q)

    U_ale, U_epi, modes, _ = M.fluid.decompose(o, K=M.adaptive_K(z))  # Level-0
    g = (M.mint.choose_interaction(modes, o, M.budget)               # N：问人/看
         if q == "N" else M.cig.invariant_probe(q, V, K, M.budget))  # B：验证探针
    if g is not None:
        ans = M.cia.execute(g)
        if M.cqe.plausible(ans, V, modes): U_epi = M.cia.update_belief(modes, ans)
        else: g, ans = None, None                                    # 回答作废
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    M.vqa.submit_async(q, V, K, p, a_t, g, ans)
    return k, lam, level=0, cell=q
```

## 4. 推导

**引理 19（共形支撑有效性）** 可交换性下 `P(p_t≤α)≤α`；非可交换流上 ACI 给出长程 `(1/T)Σ err_t ≤ α+O(γ)`，共形鞅在无漂移原假设下为上鞅，`P(∃t:E_t≥1/δ)≤δ`。系：误升级概率有界，且该界不依赖异常检测器本身准不准。

**引理 20（新颖—歧义不可识别）** 若真实机制不在模型类内，`o` 越出支撑，则 plug-in VoI 所依赖的后验不相合；存在幻影问题 `g_φ` 使 `VoI_plug(g_φ)` 任意大而真实增益为零。故 VoI 必须在支撑检验之后计算。

**引理 21（静默语义异常可分性）** 存在 `δ∈ker DΦ` 使 R68 残差与 R69 流似然差同时趋零，但 `δ` 改变场景图关系结构 ⇒ 某 `φ_j(G)=−1`；反之存在统计新颖而结构一致的良性新颖。故 `(n_t,v_t)` 两通道互不支配。

**引理 22（常识否决权安全性）** 若常识只删候选、只升 λ，则其可达风险集 ⊆ R69 的可达风险集；即使常识任意错误，最坏也只是过度保守。系：常识无需被信任，只需被限制；效率只能来自共形 α 预算与更好的探针定向。

**定理 18（三级严格包含，veto-only）** A99–A102 下，默认 CANARY 风险 ≤ R69 ≤ R68；在 `p_t>α_t`、`ℐ` 不适用、预算相同的边界上逐指令等于 R69。启用共形许可时额外风险 ≤ `α·(R_R69−R_R68)`，且必须显式计入证书。

**定理 19（升级单调性）** `L_t` 对 `(1−p_t, v_t, E_t, cal_untrusted)` 单调非减；常识与回答只能升不能降；系统不在安全/激进间振荡，降级只能经共形许可预算并留痕。

**定理 20（可证伪探询预算）** CIG 仅发出存在非零概率改变分诊格的 `g`，故单位时间交互次数有界，幻影追问被「支撑检验 × 可证伪门槛」双重压制；无可用探针则不发问、直接升级。

## 7. 本轮最大风险

**一句话**：CANARY 的安全增益押在「两条证据通道真的独立」与「常识不变量库真的覆盖危险」两个经验假设上；最强攻击不是制造统计异常，而是**制造一个统计上平常、常识上完美的假世界**——共形说「在支撑内」、常识说「没违反」、流似然说「很自洽」，三路证据一致地错，证书只是给幻觉盖章：金丝雀没叫，不是空气好，而是毒气恰好是它闻不到的那种。

**次级风险与缓解**：常识幻觉（否决权不对称 + 留出集校准 + E306）；编码器共享盲区（独立性审计，越界即关闭通道）；校准投毒（来源哈希 + e-value + E308）；非平稳流（ACI/共形鞅 + E302）；低频常识阻塞实时环（双速率 + 缓存陈旧即升级）；告警疲劳（新颖记忆只收紧不放松 + E312）。
