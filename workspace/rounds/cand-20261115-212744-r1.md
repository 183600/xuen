# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「同步定位与建图」×「热管理」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**几何化不确定 + 热感知预算**。两个灵感各自拆掉 v9 的一个隐含常数：SLAM 把"不确定性"从标量 risk_SLAM 升级为协方差几何 + 帧级新息时序，直接治理 v9 自陈的"Δ_dom 20 帧滞后"风险；热管理把"20ms 预算 / 常数 WCET"升级为带惯性的热状态，治理引理 86 从未写下的前提。任一增强失效必须注入中立元、逐位退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（SLAM → 不确定性有形状，也有时间）**
直觉：v9 只把 SLAM 压成一个标量 risk_SLAM 当门控，这丢掉了两样最值钱的东西。其一是**形状**：走廊里"沿轴"不确定可以很大，但安全间隙只关心障碍法向 n 上的投影 n^T Σ n；用各向同性 β，要么在横轴本就安全的场景白白保守（浪费块长），要么把沿轴的松弛误当成横轴也安全（漏掉真实风险）。其二是**时间**：SLAM 的测量新息（观测与地图预测之差）在分布跳变的第一帧就会异常，而 DA-ML 要攒 20 帧滑窗才报 Δ_dom——v9 的最大风险正是"最需要安全时证书最不可靠"。核心创新：**不确定性几何证书器（UGC）** 用方向投影余量替换标量余量，且用 split-conformal 分位数给出有限样本覆盖；**新息哨兵（IS）** 用 NIS-CUSUM 提供帧级前导失效信号，抢在 Δ_dom 之前把 K_eff 压到 1。一句话：**不确定性的形状决定余量该多大，不确定性的时间决定余量该多早生效。**

**灵感 2（热管理 → 预算是天气，不是常数）**
直觉：v9 的引理 86 默认 Ŵ_m 与决策预算 20ms 是常数。真实机器人芯片不是恒速机器：50Hz 主环 + 5Hz 块生成 + 消融回合持续放热，DVFS 降频会让同一段代码的 WCET 膨胀 1.3–2×；更阴险的是，0.3ms 的中块守卫本身也会被节流拖慢——安全层在最热时最慢。热管理告诉我们：算力是带惯性、带记忆的"天气"，可以用热信用预支与预冷来治理。核心创新：**热预算治理器（TBG）**：热参数化 WCET Ŵ_m(T)=Ŵ_m^0·θ_m(T) 做 EDF 准入；**安全守卫热屏蔽**（绑核 + 频率地板 + 预留切片）把 0.3ms 守卫从背景节流中解耦；块长再乘热余量（越热块越短）形成负反馈；**热信用**在已知重负载前预先留空。一句话：**不能给安全承诺分配一个会被天气改写的截止期。**

**灵感交叉（双储备）**
两个灵感其实是同一类对象：**慢储备**。信息储备 R_info（由 Δ_dom 与新息 CUSUM 共同决定）和热储备 R_th（由结温余量、热信用决定）都会随环境消耗、都滞后于真实物理、都只能"少给"不能"多给"。提出 **双储备门控（RG）**：安全承诺只在两本账都有余额时准入；任一本余额不足，沿 v9 的中立元链退化。关键复合设计：热节流可能拖慢 SLAM 管线，使新息变旧——所以**过期的信息必须按"未知"处理（fail-safe 触发告警），而不是按"无告警"处理**；否则两个滞后会相乘。

## 1. 研究问题（轮次升级版）

- **Q1（方向化证书的可靠性）**：如何把位姿/地图协方差一阶传播到间隙证书，使方向化余量在给定块级误覆盖率 ε 下 sound，同时不因各向异性而过度保守？conformal 覆盖在信任域内近似成立、在域外被新息哨兵截断的论证是否闭合？
- **Q2（热-时预算的 soundness）**：当 θ(T) 使 WCET 随温度膨胀、且热遥测存在"结温-壳温"梯度时，热校正 EDF 准入、守卫热屏蔽与陈旧块拒绝三者能否同时成立？热降载能否只借用 ID 的 φ^elig 白名单而不破坏"不删码"？
- **Q3（双储备的相关失效）**：信息储备与热储备并非独立——热节流会延迟 SLAM 管线，使新息变旧。在相关滞后下，双储备门控如何保持"子系统各自健全即复合健全"的合成论证，并在任一增强失效时逐位退回 v9？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 几何证书律（Covariance-Projected Certificate, UGC）**
证书余量不是标量，而是沿间隙法向投影的分位数：ĝ_min = min_k [ F̂_g − β_model − q̂_{1−ε/K}·σ_n(k) ]，其中 σ_n²(k) = n_k^T (J_p Σ_t J_p^T + J_m Σ_map J_m^T) n_k；q̂ 由校准集 split-conformal 给出。各向异性只允许在"安全方向"省余量，绝不沿危险方向省。

**P14 新息前导律（Innovation Sentinel, IS）**
用测量级新息 NIS 的 CUSUM 作为信任域的快通道：C_t = max(0, C_{t−1} + d_t² − (m + k_c))，C_t > h_c 即在同一控制周期判证书失效、K_eff=1，不等 Δ_dom 的 20 帧窗口。新息年龄 a_t^IS > T_is 视为"未知"并触发同样的失效（fail-safe），而非默认安全。

**P15 热预算律（Thermal Budget & Shield, TBG）**
WCET 是温度的函数：Ŵ_m^+(T)=Ŵ_m^0·θ_m^+(T)，θ^+ 为校准上界；准入用热校正后的 Σ Ŵ_m^+ ≤ B_dec·ρ(T^+_{t:H_T})。安全守卫集合 G（中块守卫、M₀ 硬检查、SpatialCert、FaultCert）跑在绑核 + 频率地板 + 预留切片上，其 WCET 与背景节流解耦；频率地板无法维持即触发安全停驻。热降载只允许强制休眠 φ^elig=true 的模块（借用 ID 白名单），安全模块永不被降载。

**P16 双储备复合律（Dual-Reserve Gate, RG）**
R_info=min(1−Δ_dom/τ_dom, 1−C_t/h_c)，R_th=clip((Q_t−Q_res)/Q_nom, 0, 1)；K_eff^v10 = min(K_eff^v9, max(1, ⌊K_max·min(R_info,R_th)⌋))，低于 ρ_min 直接 K_eff=1，并用进入/退出双阈 + 驻留时间防抖。任一门控失效注入中立元：UGC→q̂≡0、IS→C≡0 且回退 DA-ML 窗口、TBG→θ≡1/屏蔽关闭/R_th≡1、RG→K_eff=K_eff^v9。

## 3. 与基线的接口（如何退化）

- UGC 失效（校准退化 / 协方差不可用）⇒ q̂≡0，证书退回 v9 标量 β，等价 v9 定义 533；
- IS 失效（新息不可得 / CUSUM 关闭）⇒ C_t≡0 且用 DA-ML 20 帧窗口门控，等价 v9 定义 539；
- TBG 失效（热遥测丢失 / θ 不可信）⇒ θ≡1、热屏蔽关闭、静态 20ms 准入，等价 v9 引理 86 的常数假设；
- RG 失效（门控异常）⇒ K_eff 取 v9 公式、余量取 max(v9, v10)，等价 v9；
- v9 的 AC/MW/ID 任一失效 ⇒ 沿用 v9 定义 536 的中立元表退回 v8；
- 全部失效 ⇒ v9 → v8 → MetricVoiceGauge-OTL-GC-ER v7 → v6。

## 4. 预期贡献

1. **方向化 + conformal 证书**：把安全余量从"一个数"变成"沿间隙法向的分位数"，在不放宽安全的前提下削减各向异性导致的过度保守；给出块级误覆盖率的有限样本论证；
2. **新息前导失效**：用 SLAM 测量新息把信任域失效的检测延迟从 DA-ML 的 20 帧降到 1–2 帧（大漂移时），正面对冲 v9 自陈的最大风险，并给出"检测延迟 vs 漂移幅度"的显式界；
3. **热-时预算 soundness**：热参数化 WCET + 守卫热屏蔽 + 陈旧块拒绝 + 热信用，补上引理 86 的常数前提；热降载复用 ID 白名单，两个模块互相加固而非叠加复杂度；
4. **双储备复合与"过期即未知"**：给出相关滞后下的合成论证与中立元退化等价，把"两个慢储备"统一为一个可验证的准入代数；E571–E590 覆盖校准、延迟、热准入、屏蔽、相关失效与长跑。

## 5. 本轮最大风险

**一句话**：两本储备都以"慢变量可被及时观测"为前提——热节流恰会同时拖慢 SLAM 管线与热遥测，使"信息变旧"和"温度读数偏低（结温-壳温梯度）"在同一时刻发生；若"过期即未知"的 fail-safe 覆盖不完整，系统会在最热、最陌生的一帧上同时用旧新息和旧温度做准入，即「双储备在相关滞后下同时虚报余额」。

**新增定义 540（位姿-地图不确定性地形 PoseUncertaintyTerrain）** 每个控制时刻 SLAM 后端导出位姿协方差 Σ_t 与局部地图协方差 Σ_map。对第 k 步预测位置的间隙函数 g_k，取其距离场单位法向 n_k 与对位姿、地图的雅可比 J_p、J_m，定义方向化方差与标准差：
```
σ_n²(k) = n_k^T ( J_p Σ_t J_p^T + J_m Σ_map J_m^T ) n_k
```
UGC 消费 (Σ_t, Σ_map, n_k)，而非标量 risk_SLAM。Σ 的特征分解只每帧做一次；n_k 由距离场梯度给出。

**新增定义 541（方向化一致性证书 Covariance-Projected Certificate）** 在信任域内收集校准集 D_cal={(s,a), g_true − F̂_g}，以方向化残差 r=(g_true−F̂_g)/σ_n 做 split-conformal，取块级误覆盖率 ε 经 Bonferroni 分摊到 K 步（ε_k=ε/K）后的分位数 q̂_{1−ε/K}。块证书升级为：
```
ĝ_min = min_{k≤K} [ F̂_g(s,a^{1:k}) − β_model − q̂_{1−ε/K} · σ_n(k) ]
ê_max = max_{k≤K} [ F̂_effort(s,a^{1:k}) + β_model ]
证书有效 ⇔ ĝ_min ≥ d_safe ∧ ê_max ≤ τ_eff ∧ γ̂_grasp=valid
        ∧ (C_t ≤ h_c) ∧ (a_t^IS ≤ T_is)
```
注意：q̂ 只对方向化残差拟合，因此各向异性进入的是 σ_n(k) 而非分位数本身；这一分解是"只在安全方向省余量"的代数来源。

**新增定义 542（新息哨兵 InnovationSentinel）** 每次 SLAM 测量更新计算
```
ν_t = z_t − h(x̂_t),   S_t = H_t Σ_t H_t^T + R_t,   d_t² = ν_t^T S_t^{-1} ν_t
C_t = max(0, C_{t−1} + d_t² − (m + k_c)),   alarm ⇔ C_t > h_c
```
CUSUM 只消费测量级量，不经过 DA-ML 特征管线，故其延迟与 Δ_dom 的滑窗无关。**新鲜度条款**：若最近一次新息的年龄 a_t^IS > T_is（例如节流拖慢了 SLAM 计算），置 alarm=TRUE 且原因记为 `stale`——过期信息按"未知"处理，是 P16 复合论证的关键。

**新增定义 543（快慢双通道信任域）**
```
U_t^v10 = {Δ_dom < τ_dom} ∧ {risk_SLAM < τ_SLAM} ∧ {C_t ≤ h_c} ∧ {a_t^IS ≤ T_is}
```
快通道优先：C_t>h_c 或 a_t^IS>T_is 时，证书在当前控制周期立即失效、K_eff=1，不等块边界、不等 DA-ML 窗口。定义前导时间 τ_lead = t_DA − t_IS（IS 先触发时为正）。

**新增定义 544（热参数化 WCET 与准入 Thermal-Adjusted Admission）** 离线标定 θ_m(T) 并取保守上界 θ_m^+(T)，满足 θ_m^+(T) ≥ θ_m(T) 于 [T_amb, T_max]。热校正 WCET 为 Ŵ_m^+(T)=Ŵ_m^0·θ_m^+(T)。准入在使用热模型预测的horizon 上界 T^+_{t:H_T} 下检查：
```
Σ_{m∈active} Ŵ_m^+(T^+_{t:H_T}) ≤ B_dec · ρ(T^+_{t:H_T})
```
不满足时依次：(i) 强制休眠 φ^elig=true 的模块（借用 ID 白名单，按贡献 c_m 升序）；(ii) 缩短 K_eff；仍不满足则拒绝生成新块并保持既有已认证块/安全停驻。**永不对 φ^elig=false 的模块降载**。

**新增定义 545（热状态、热信用与热余量）** 一阶 RC 热模型：
```
T_{t+1} = T_t + (Δt/C_th)·[ P_t − (T_t − T_amb)/R_th ]
P_t = P_0 + Σ_{m∈active} p_m
Q_t = C_th·(T_max − T_t)           # 距热上限的焦耳数
Q_res = 安全停驻 + 守卫 G 在 T_stop 内所需能量
R_th(t) = clip( (Q_t − Q_res)/Q_nom, 0, 1 )
```
功耗 P_t 随 active 集变化，而 active 集又受 ID/TBG 影响——热与调度构成闭环。预冷策略在已知重负载窗口前提高 R_th 目标（降频/留空），用热信用换取未来的 WCET 确定性。

**新增定义 546（安全守卫热屏蔽 ThermalShield）** 守卫集合 G={AC 中块守卫, M₀ 硬检查, SpatialCert, FaultCert} 运行于绑核 c_g、频率地板 f_min、预留切片 s_g；运动期间 DVFS 不得低于 f_min。于是守卫 WCET 上界 Ŵ_g^shield 与背景负载/背景降频无关，仅受 T≤T_max 约束。若地板无法维持（功耗墙/温度墙），屏蔽失效 ⇒ **安全停驻**，不得静默继续。这是对"守卫自己会迟到"的结构性修复。

**新增定义 547（双储备门控 Dual-Reserve Gate）**
```
R_info(t) = min( 1 − Δ_dom(t)/τ_dom, 1 − C_t/h_c )   # clip 到 [0,1]
R_th(t)   = clip( (Q_t − Q_res)/Q_nom, 0, 1 )
r(t)      = min(R_info(t), R_th(t))
K_eff^v10(t) = 1                                  若 r(t) < ρ_min
             = min( K_eff^v9(t),
                    max(1, ⌊K_max·r(t)⌋) )         否则
```
进入低储备态阈 ρ_min、退出阈 ρ_min+δ，且低储备态需驻留 T_dwell 才允许退出（防抖，引理 94）。K_eff^v10 永远不超过 K_eff^v9，故 v10 是 v9 的单调保守细化。

# IP-357 UncertaintyGeometryCertifier：方向化一致性证书
class UncertaintyGeometryCertifier:
    def __init__(self, forward_model, calibrator, d_safe, beta_model):
        self.F, self.cal = forward_model, calibrator
        self.d_safe, self.beta = d_safe, beta_model

    def directional_std(self, Sigma, Jp, Jm, n):
        Sp = Jp @ Sigma.pose @ Jp.T
        Sm = Jm @ Sigma.map @ Jm.T
        return float(np.sqrt(n @ (Sp + Sm) @ n))

    def cert(self, state, actions, Sigma, K):
        pred = self.F.rollout(state, actions)
        eps_k = self.eps / max(1, K)                  # Bonferroni（定义 541）
        q = self.cal.conformal_quantile(1 - eps_k)
        g_min, e_max = np.inf, 0.0
        for k in range(K):
            s = self.directional_std(Sigma, pred.Jp[k], pred.Jm[k],
                                     pred.normals[k])
            g_min = min(g_min, pred.clearance[k] - self.beta - q * s)
            e_max = max(e_max, pred.effort[k] + self.beta)
        return ChunkCert(g_min, e_max, q, pred.sigma_n,
                         gamma=pred.grasp_valid)


# IP-358 InnovationSentinel：NIS-CUSUM + 新鲜度 fail-safe
class InnovationSentinel:
    def __init__(self, m, k_c=0.5, h_c=9.0, T_is=5):
        self.m, self.k_c, self.h_c, self.T_is = m, k_c, h_c, T_is
        self.C, self.alarm, self.reason = 0.0, False, ''

    def update(self, nu, S, stamp, now):
        if now - stamp > self.T_is:                   # 过期即未知（定义 542）
            self.alarm, self.reason = True, 'stale'
            return self.alarm
        d2 = float(nu @ np.linalg.solve(S, nu))
        self.C = max(0.0, self.C + d2 - (self.m + self.k_c))
        self.alarm = self.C > self.h_c
        self.reason = 'cusum' if self.alarm else ''
        return self.alarm


# IP-359/360 ThermalBudgetGovernor：热参数化 WCET、屏蔽、降载
class ThermalBudgetGovernor:
    def __init__(self, theta_plus, rc, B_dec, rho, Q_nom, Q_res,
                 rho_shed, f_min, core_g):
        self.theta, self.rc, self.B, self.rho = theta_plus, rc, B_dec, rho
        self.Q_nom, self.Q_res, self.rho_shed = Q_nom, Q_res, rho_shed
        self.f_min, self.core_g = f_min, core_g

    def predict_T_upper(self, T, P_hi, H):
        Tt = T
        for _ in range(H):                            # 保守：取 P 上界
            Tt += self.rc.dt / self.rc.C * (
                P_hi - (Tt - self.rc.T_amb) / self.rc.R)
        return Tt

    def admit(self, active, T, H):
        T_hi = self.predict_T_upper(T, self.P_hi(active), H)
        load = sum(c.wcet0 * self.theta[c.name](T_hi) for c in active)
        return load <= self.B * self.rho(T_hi), T_hi

    def shed(self, active, T, H, distiller):
        if self.thermal_reserve(T) >= self.rho_shed:
            return active
        order = sorted((m for m in active if m.eligible),  # φ^elig 白名单
                       key=lambda m: distiller.c[m])       # 低贡献先停
        for m in order:
            distiller.force_dormant(m, reason='thermal')
            if self.admit(active - {m}, T, H)[0]:
                break
        return active

    def shield_ok(self):
        return dvfs.freq() >= self.f_min and pinned(self.core_g)


# IP-361 ReserveGate：双储备门控 + 双阈驻留
class ReserveGate:
    def __init__(self, K_max, rho_min=0.35, delta=0.1, T_dwell=25):
        self.K_max, self.rho_min = K_max, rho_min
        self.delta, self.T_dwell = delta, T_dwell
        self.low, self.dwell = False, 0

    def gate(self, K_v9, R_info, R_th):
        r = min(R_info, R_th)
        if self.low:
            self.dwell += 1
            if r > self.rho_min + self.delta and self.dwell >= self.T_dwell:
                self.low, self.dwell = False, 0
            else:
                return 1
        elif r < self.rho_min:
            self.low, self.dwell = True, 0
            return 1
        return min(K_v9, max(1, int(self.K_max * r)))

## 4. 推导

**引理 87（方向化 conformal 证书 soundness）** 设校准集与部署样本在信任域内可交换，方向化残差 r 的分布连续，q̂_{1−ε/K} 为 split-conformal 分位数；前向模型一致误差 ≤β_model。则对整块（K 步）有
```
P( ∃k≤K : g_k < ĝ_min ) ≤ ε + O(1/|D_cal|)
```
证明：对固定 k，由 split-conformal 的边际覆盖，P(g_k − F̂_g,k < −q̂ σ_n(k)) ≤ ε/K（单边）。对 k=1..K 取联合界，得 ≤ε。注意 σ_n(k) 只依赖 SLAM 协方差与几何，不含标签泄漏；q̂ 对所有方向共用，故各向异性通过 σ_n 进入而不破坏覆盖。∎
> 关键限定：可交换性是**假设**，域偏移会破坏它——这正是 IS/Δ_dom 门控存在的理由（引理 88、92）；v10 不声称域外 sound。

**引理 88（新息哨兵的前导性与检测延迟）** 设偏移后 NIS 的期望增量为 δ（以 CUSUM 单位/帧计）。则 CUSUM 的期望告警时间满足
```
E[τ_IS] ≤ (h_c + C_0)/(δ − k_c)     （δ > k_c）
```
故当 δ > (h_c + C_0)/W_DA + k_c 时，IS 先于 DA-ML 的 W_DA=20 帧窗口告警；δ 越大越接近 1 帧。虚警方面，CUSUM 的平均运行长度 ARL0 随 h_c 指数增长（Wald 近似 ARL0 ≈ exp(2h_c·k_c/σ²)/…），h_c 可按 E574 标定为可接受水平。
证明要点：CUSUM 每步期望漂移为 δ−k_c，越过 h_c 的期望步数至多 (h_c+C_0)/(δ−k_c)；与 DA-ML 固定 W_DA 窗口比较即得前导条件。∎
> 诚实边界：小漂移时 IS 未必领先，甚至可能晚于 DA-ML；v10 只主张"大漂移帧级、微小漂移不劣于 v9"，不主张普遍领先。

**引理 89（热校正准入的 soundness）** 若 θ_m^+(T) ≥ θ_m(T) 对一切 T≤T_max 成立，且热模型预测的 T^+_{t:H_T} ≥ 实际温度上界，则准入条件 Σ Ŵ_m^+(T^+_{t:H_T}) ≤ B_dec·ρ(T^+_{t:H_T}) 蕴含实际执行时间 Σ Ŵ_m(T_t) ≤ B_dec，从而周期内 EDF 可行（引用经典 EDF 可行性）。
证明：Ŵ_m(T_t)=Ŵ_m^0θ_m(T_t) ≤ Ŵ_m^0θ_m^+(T_t) ≤ Ŵ_m^0θ_m^+(T^+_{t:H_T})，求和即得。温度上界由 P_hi 与 RC 模型的单调性保证；若热模型失配，见最大风险。∎

**引理 90（守卫热屏蔽的隔离性）** 若守卫 g∈G 独占绑核 c_g、频率不低于 f_min、且持有预留切片 s_g，则其响应时间上界 Ŵ_g^shield 与背景任务负载、背景降频无关；当 Ŵ_g^shield ≤ D_g 时守卫截止期恒满足。若频率地板失守，屏蔽显式失效并触发安全停驻，故不存在"守卫静默迟到"。
证明：绑核排除迁移与跨核争用；频率地板排除 DVFS 降频；预留切片排除排队延迟。三者共同把守卫的 WCET 从"依赖系统状态"变为"常数上界"。∎

**引理 91（陈旧块不可执行）** 块携带生成时刻 t_g、有效期 T_fresh、证书字段（含 q̂、σ_n^{1:K}、C_t、a_t^IS）。执行第 k 步要求：(i) age=t−t_g ≤ T_fresh；(ii) 中块守卫用活 Σ 与 IS 重验通过；(iii) 停车不变式（定义 534 v10）成立。若 TBG 因过热拒绝生成新块，旧块只在 (i)(ii)(iii) 全真时继续；否则安全停驻。故热致生成延迟不可能导致执行未认证动作——前提是守卫本身按时（引理 90）。
证明：执行路径对所有条件做合取守卫，任一失败即转入 `safe_stop` 或最近中止点；生成延迟只影响"是否有新块"，不影响"旧块是否仍被检查"。∎

**引理 92（双储备单调细化与 v9 逐位等价）** 对任意部署，K_eff^v10(t) ≤ K_eff^v9(t)，且证书有效域 v10 ⊆ v9（余量更大、额外要求 IS 与新鲜度）。对表 548 任一行注入中立元，系统读数与 v9 对应级别逐位一致；全部注入即完整 v9。因此 v10 不引入任何比 v9 更乐观的行为，安全性由 v9 引理 82–86 沿包含关系继承。
证明：K_eff 取 min、余量取 max、有效性取合取，三者均为单调收紧；中立元使被移除项恒等于 v9 的对应量（q̂=0、C=0、θ=1、R_th=1、K=K^v9），故逐位一致。∎

**引理 93（相关滞后下的复合 soundness）** 设热节流使 SLAM 管线延迟，导致新息年龄 a^IS 增大。因定义 542 的陈旧条款在 a^IS>T_is 时**强制**置 alarm，IS 的失效是 fail-safe 而非 fail-open；同时 TBG 的准入使用温度上界、守卫受热屏蔽。则只要 (a) 至少一条信任通道（Δ_dom 或 CUSUM）未过期且未告警 与 (b) 热屏蔽在线 同时成立，v10 的安全论证即可由引理 87–91 合成；反之系统进入 K=1 + 安全停驻，不进入"用旧信息做乐观决策"的状态。
证明：对 (a)，v10 的证书有效性要求所有通道合取，(b) 保证守卫按时。若信息全过期，陈旧条款触发 alarm 使证书失效、K=1；若守卫失守，引理 90 触发停驻。两条失败路径都退化为保守路径，故不存在"两个滞后相乘导致乐观"的路径。∎
> 限定：该引理不覆盖"热遥测本身低估结温"——那是观测器误差，不是时间戳问题，见第 8 节风险。

**引理 94（储备门控无 Zeno）** RG 使用进入阈 ρ_min 与退出阈 ρ_min+δ（δ>0），且退出需驻留 T_dwell；两次迁移间隔 ≥ T_dwell·Δt 个控制周期，故有限时间内迁移次数有限、翻转率 ≤ 1/(T_dwell·Δt)。
证明：低储备态只能经"持续 T_dwell 且 r>ρ_min+δ"退出；进入与退出阈值不同保证不因噪声在阈值附近反复穿越。∎

## 8. 本轮最大风险

**一句话**：两本储备都以"慢变量可被及时观测"为前提——热节流恰会同时拖慢 SLAM 管线与热遥测，使"信息变旧"和"温度读数偏低（结温-壳温梯度）"在同一时刻发生；若"过期即未知"的 fail-safe 覆盖不完整，系统会在最热、最陌生的一帧上同时用旧新息和旧温度做准入，即「双储备在相关滞后下同时虚报余额」。
