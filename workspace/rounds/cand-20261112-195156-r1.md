# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮；本轮灵感：「闭环控制」×「动力学」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「场景语义」和「认知意图」接进了执行闭环，并用 SIC 三元组（场景置信度×阻抗确定性×执行可行性）守住「认知先行不超过执行安全」。但它把「阻抗 K_safe」当成**静态标量**，把「闭环」当成**离散事件序列**。这两个隐含假设在真实接触里都会破：
> 1. **阻抗不是标量，而是端口传递函数**：K_safe 只描述低频刚度，忽略了操作空间惯性 Λ(q)、阻尼 D、控制时延 τ_d 与环境阻抗 Z_e(s)。同一个 K，在手臂伸展（Λ 小）时自然频率高、易抖振；在刚性环境（K_e 大）下可能越过增益/相位裕度——**静态安全的 K 在闭环里可能不稳定**。
> 2. **场景切换不是标签切换，而是能量注入**：第 60 轮用 κ_scene 检测「换场景」，却没建模切换瞬间的相对速度与冲击。桌面→墙面、地面→楼梯的过渡带来动量突变 F_imp≈Λ·Δv/Δt；K 先验切换得越快，冲击越大。**「提前收敛」若忽略动力学，就是在提前注入能量**。
> 3. **认知回路本身没有被证明稳定**：SERC 是「场景→意图→约束→阻抗→执行→证据→场景」的慢回路，却没有收缩性/收敛性保证。当意图更新频率接近执行频率时，外层认知与内层动力学可能互相激励，产生「认知抖动」或极限环——第 60 轮只给了 τ_response 时延上界，没有给**稳定性**证明。
>
> 本轮把「闭环控制」与「动力学」作为两把尺子，把第 60 轮的**静态阻抗安全**升级为**动态闭环安全**：端口阻抗安全包络 PISE、动力学接地上界 DGIB、冲击-动量闭环 IMC、收缩闭环证书 CCC、能量罐预算 ETB、动力学感知场景先验 DSP、PCE+++++ 双时间尺度动态闭环 DCC。

## 0. 直觉与动机

**灵感 1（闭环控制 → 端口阻抗安全包络 PISE）**
直觉：阻抗控制里机器人向环境「呈现」的不是一个刚度数，而是一个**端口阻抗** `Z_r(s)=Λ(q)s² + D s + K`。它与环境阻抗 `Z_e(s)` 在接触端口耦合，接触力为
`F(s) = Z_r(s)Z_e(s)/(Z_r(s)+Z_e(s)) · v_ref(s)`。
关键洞见：**无源性只看实部**，而 `Re Z_r(jω) = K − Λ(q)ω²`——只要 `ω > √(K/Λ(q))`，实部就变负，机器人开始向环境「输出能量」。于是「这个 K 安不安全」根本不是一个标量问题，而是一个**频带问题**：环境能量集中的频段必须落在 `Z_r` 的无源带内，否则高刚度会与刚性环境共振。第 60 轮的 `K_safe` 等于只检查了 `ω→0` 这一个点。

**灵感 2（动力学 → 动力学接地刚度上界 DGIB）**
直觉：高刚度会抬高闭环自然频率 `ω_n=√(K/Λ(q))`。控制时延 τ_d 在 `ω_n τ_d` 接近 π/2 时吃掉相位裕度，系统从「刚性」跌进「抖振」。所以刚度是被惯性与时延**反向定价**的：
`K_p ≤ Λ(q) · ((π/2 − φ_m)/τ_d)²`。
关键洞见：**同一份 K_safe 不能跨构型通用**——手臂伸出时 Λ 下降数倍，原本安全的 K 立刻越界。第 60 轮把 K_safe 写进证书，却把 Λ(q) 留在了证书之外，这是「执行合规、动力学失效」的根。

**灵感 3（场景切换 → 冲击-动量闭环 IMC）**
直觉：换场景时真正危险的是**相对速度**。桌面→墙面过渡，`F_imp ≈ Λ(q)·|v⁻−v⁺|/Δt_c + K_e·x_pen`。如果 SSM 检测到场景变化就瞬时把 K 从柔性切到刚性，等于在接触瞬间给系统注入 `½ΔK‖x−x_d‖²` 的弹性能。关键洞见：**场景先验的切换必须由动量观测器门控**——先估 `p̂`、预测 `F_peak`，再用受能量罐约束的混合系数 `α(t)` 渐变，且 `α` 的上界由 `F_peak ≤ F_tol` 与 `E_tank ≥ 0` 共同决定。

**灵感 4（认知回路 → 收缩闭环证书 CCC）**
直觉：SERC 慢回路是一个映射 `χ_{k+1}=Φ(χ_k)+w`，其中 `χ=(场景信念 b, 阻抗 K, 意图约束 c)`。要它「越跑越稳」，需要收缩性：存在度量 M 与速率 ρ∈(0,1) 使 `(DΦ)ᵀM(DΦ) ≤ (1−ρ)M`。更关键的是**两时间尺度分离**：外层更新周期 `T_o` 必须显著大于内层闭环整定时间 `T_i`（`T_o ≥ κT_i, κ≈3~5`），否则外层改 K 的速度接近内层动力学速度，慢回路会把内环推入极限环。关键洞见：**τ_response ≤ 2s 只保证「按时」，收缩证书才保证「不振荡」**。

**灵感 5（合流 → 双时间尺度动态闭环 DCC 与 PCE+++++）**
直觉：把内环（力矩/阻抗，亚毫秒）与外环（场景/意图，百毫秒）分层，各持一份证书：内环持 PISE+DGIB 的**硬安全证书**，外环持 CCC 的**软收敛证书**。冲突时内环优先，外环必须重新线性化后再提交。预算从第 60 轮的四维认知预算扩为**认知-动力学预算** `B_dyn=(B_energy, B_obs, B_switch, B_cog)`：能量罐见底就降刚度/加阻尼，观测器跟不上就用保守动量界，切换预算耗尽就冻结 K。关键洞见：**「认知先行」必须给「动力学安全」让路，且让路的方式是可预算、可证明的**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（端口阻抗安全包络 PISE）** 给定机器人端口阻抗 `Z_r(s)=Λ(q)s² + D s + K` 与环境阻抗 `Z_e(s)`，安全包络为
`K_pise(q) = { (K,D) | (i) ∀ω∈Ω_e: Re[Z_r(jω)] = K − Λ(q)ω² ≥ −ε_pas; (ii) 相位裕度 φ_m ≥ φ_min 且增益裕度 g_m ≥ g_min; (iii) 时延 τ_d 下 Nyquist 曲线不包围 −1; (iv) sup F_contact ≤ F_tol }`。
其中 `Ω_e` 为环境能量集中频带（由 DSP 的场景类给出）。**PISE 是频带化的，不是单点的**：同一 K 在 `ω<√(K/Λ)` 内无源，在更高频段必须靠环境带宽或附加低通「虚拟耦合」隔离。

**定义 162（动力学接地刚度上界 DGIB）** 对构型流形上的采样 `q∈Q`，
`K_max(q) = Λ(q)·ω_c²,  ω_c = (π/2 − φ_m)/τ_d`；
`D_min(q) = 2ζ_min√(Λ(q)K_p)`。
全局安全上界 `K_ground = min_{q∈Q_任务} K_max(q)`。它显式把「刚度」与「惯性 Λ(q)」「时延 τ_d」耦合：手臂伸出/负载变化导致 Λ 下降时，K 必须同步下降，否则抖振。DGIB 与第 60 轮的 `K_safe` 取交：`K_safe^{dyn} = K_safe ∩ K_ground ∩ K_pise`。

**定义 163（冲击-动量闭环 IMC）** 动量观测器
`p̂(t) = ∫₀ᵗ (F_cmd − μ̂ + r)dτ,  r = K_o(p − p̂)`；
冲击预测 `F_peak(v_rel, K) = Λ(q)|v_rel|/Δt_c + √(K)|x_pen|`；
场景切换用受门控的混合 `K(t)=(1−α(t))K_old+α(t)K_new`，其中
`α_max = sup{ α∈[0,1] | F_peak(α) ≤ F_tol ∧ ½α(K_new−K_old)‖x−x_d‖² ≤ E_tank }`。
**切换不是赋值，是一次受能量与力上限约束的插值**；若 `α_max = 0`，则推迟切换并先减速（降低 v_rel）。

**定义 164（收缩闭环证书 CCC）** 外环状态 `χ=(b,K,c)`，更新 `χ_{k+1}=Φ(χ_k)+w`。证书 `C_cc=(M,ρ,κ)` 满足：
- **收缩性**：`(DΦ)ᵀM(DΦ) ≤ (1−ρ)M`，`0<ρ<1`（增量指数稳定，速率 ρ 每拍）；
- **两时间尺度分离**：`T_o ≥ κ·T_i`，`κ ≥ 3`，`T_i` 为内环闭环整定时间；
- **时延裕度**：`ρ·T_o + τ_d ≤ τ_deadline`。
若不满足，外环必须降频（增大 `T_o`）或冻结 K（`B_switch` 耗尽路径）。

**定义 165（能量罐/无源性预算 ETB）** 虚拟能量罐 `E(t)`：
`Ė(t)=P_inj(t) − P_diss(t) + P_task(t),  0 ≤ E(t) ≤ E_cap`；
变刚度注入 `ΔE_K = ½ΔK‖x−x_d‖²`，只有 `ΔE_K ≤ E(t)` 才允许升刚度；只有 `ζ>0` 的耗散调制或任务做功才能回充。安全不变式：`E(t) ≥ E_min ∧ ν(t) ≥ 0`，其中 `ν` 为端口无源裕度。**「加紧一点」这类意图在能量语义下就是一次有预算的升刚度请求**。

**定义 166（动力学感知场景先验 DSP）** 场景先验从 `π_scene(K|z)` 扩展为
`π_scene(K, Z_e, Λ | z) = N((K, Z_e, Λ); μ_dyn(z), Σ_dyn(z))`。
每个场景携带动力学指纹：`z → (K_e,z 环境刚度, μ_z 摩擦系数, σ_f,z 力噪声, ω_e,z 环境带宽)`。例如湿滑地面不只降 K，还降可用切向力上界并抬升滑移风险；刚性墙面则把 `ω_e` 推高，直接压缩 PISE 的无源带。SSM 的后验更新因此同时更新**动力学模型**，而不只是标签。

**定义 167（认知-动力学预算 PCE+++++ / B_dyn）**
`B_dyn = (B_energy, B_obs, B_switch, B_cog)`：
- `B_energy`：能量罐容量与最小保留 `E_min`；
- `B_obs`：动量观测器采样率与残差容忍（决定 `F_peak` 估计可信度）；
- `B_switch`：单位时间的场景/阻抗切换次数上限（防止抖振式切换）；
- `B_cog`：第 60 轮四维认知预算 `(B_scene,B_intent,B_ros,B_exec)`。
`voi_dyn(π) = VOI_meta(π) − cost_cog(π) − cost_dyn(π)`，
`cost_dyn = λ_E·E_used + λ_stab·max(0, ν_min − ν(π)) + λ_sw·Switch_count(π)`。
耗尽策略：`B_energy↓`⇒降 K/加 D；`B_obs↓`⇒用保守动量界；`B_switch↓`⇒冻结 K；`B_cog↓`⇒沿用第 60 轮降级。

**定义 168（双时间尺度动态闭环 DCC 与证书仲裁）** 内环 `F_cmd = Z_r(q, K, D)∘(x_d − x)`（亚毫秒），外环 `SERC+`（百毫秒）。仲裁规则：
```
K_adm = K_safe^scene ∩ K_ground ∩ K_pise ∩ {K | E ≥ E_min}
if K_adm = ∅:      K ← K_low 且 D ← D_high（能量罐兜底）, 外环重新线性化
elif C_cc 不成立:   T_o ← κT_i（外环降频），冻结 B_switch
else:              K ← argmin_{K∈K_adm} (λ·ω_traj − (1−λ)K_p)
```
**内环硬证书永远优先于外环软证书**；外环只能在 `K_adm` 内做偏好排序。

## 2. 关键算法伪代码

### IP-161 PISE（端口阻抗安全包络）

```python
def certify_port_impedance(K, D, Lambda, env, tau_d,
                           phi_min=0.35, zeta_min=0.7, eps_pas=0.0):
    omega_n = math.sqrt(K / Lambda)
    zeta = D / (2.0 * math.sqrt(Lambda * K))
    omega_c = (math.pi / 2 - phi_min) / max(tau_d, 1e-6)
    passive = (K - Lambda * env.omega_max**2) >= -eps_pas
    stable = (omega_n <= omega_c) and (zeta >= zeta_min)
    gain_margin = _nyquist_margin(K, D, Lambda, env, tau_d)
    return Certificate(ok=passive and stable and gain_margin >= 1.0,
                       omega_n=omega_n, zeta=zeta, omega_c=omega_c,
                       passive=passive, gm=gain_margin)
```

### IP-162 DGIB（动力学接地上界）

```python
def dynamics_grounded_bound(robot, q_grid, tau_d, phi_margin=0.35):
    omega_c = (math.pi / 2 - phi_margin) / max(tau_d, 1e-6)
    k_max = float('inf')
    for q in q_grid:
        Lambda = robot.operational_inertia(q)
        k_max = min(k_max, Lambda * omega_c**2)
    return k_max

def ground_impedance(K_nom, robot, q_now, tau_d, zeta_min=0.7):
    Lambda = robot.operational_inertia(q_now)
    K_hi = dynamics_grounded_bound(robot, robot.reachable_q(), tau_d)
    K = min(K_nom, K_hi)
    D = max(2.0 * zeta_min * math.sqrt(Lambda * K), K_nom_D(K_nom))
    return K, D
```

### IP-163 IMC（冲击-动量闭环）

```python
class MomentumImpactClosure:
    def __init__(self, robot, K_o=8.0, F_tol=40.0):
        self.robot, self.K_o, self.F_tol = robot, K_o, F_tol
        self.p_hat = 0.0

    def observe(self, p, F_cmd, mu_hat, dt):
        self.p_hat += (F_cmd - mu_hat + self.K_o * (p - self.p_hat)) * dt
        return self.p_hat

    def safe_blend(self, K_old, K_new, x_err, v_rel, tank):
        Lambda = self.robot.operational_inertia(self.robot.q)
        dt_c = self.robot.contact_time
        def peak(alpha):
            K = (1 - alpha) * K_old + alpha * K_new
            return Lambda * abs(v_rel) / dt_c + math.sqrt(K) * abs(x_err)
        alpha = 1.0
        while alpha > 0.0:
            dE = 0.5 * alpha * (K_new - K_old) * x_err**2
            if peak(alpha) <= self.F_tol and dE <= tank.E:
                break
            alpha *= 0.5
        return (1 - alpha) * K_old + alpha * K_new, alpha
```

### IP-164 CCC（收缩闭环证书）

```python
def contraction_certificate(Phi, jacobian, M, T_o, T_i, tau_d, rho_min=0.05):
    DPhi = jacobian(Phi)
    contraction = max_eig(DPhi.T @ M @ DPhi) <= (1 - rho_min)
    timescale = T_o >= 3.0 * T_i
    delay_ok = rho_min * T_o + tau_d <= 0.5 * T_o
    return Certificate(ok=contraction and timescale and delay_ok,
                       rho=rho_min, kappa=T_o / max(T_i, 1e-9))
```

### IP-165 ETB（能量罐）

```python
class EnergyTank:
    def __init__(self, E0, E_cap, E_min):
        self.E, self.E_cap, self.E_min = E0, E_cap, E_min

    def inject(self, P_inj, P_diss, dt):
        self.E = min(self.E_cap, max(0.0, self.E + (P_inj - P_diss) * dt))

    def can_stiffen(self, dK, x_err):
        return 0.5 * dK * x_err**2 <= self.E - self.E_min

    def safe(self):
        return self.E >= self.E_min
```

class DynamicScenePrior:

    def prior(self, z):

### IP-167 PCE+++++（认知-动力学预算）

```python
class CognitiveDynamicBudget:
    def __init__(self, cog_budget, E_cap, E_min, obs_rate, switch_limit):
        self.B_cog = cog_budget
        self.B_energy = (E_min, E_cap)
        self.B_obs = obs_rate
        self.B_switch = switch_limit
        self.switches = 0

    def mode(self, tank, obs_ok):
        if not tank.safe():
            return 'stiffness_down_damping_up'
        if not obs_ok:
            return 'conservative_momentum_bound'
        if self.switches >= self.B_switch:
            return 'freeze_K'
        return 'normal'
```

### IP-168 DCC（双时间尺度动态闭环）

```python
def dynamic_closed_loop(M, scene_obs, intent, delta_f_req):
    z = M.scene_model.update(scene_obs)
    fp = M.dyn_prior.prior(z)                       # DSP 动力学指纹

    K_scene = M.eeis.compile_with_scene_prior(fp['K_prior'], delta_f_req)
    K_ground = dynamics_grounded_bound(M.robot, M.robot.reachable_q(), M.tau_d)
    env = EnvironmentModel(fp['K_e'], fp['mu'], fp['omega_e'])
    K, D = ground_impedance(K_scene.best.K, M.robot, M.robot.q, M.tau_d)

    cert_pise = certify_port_impedance(K, D, M.robot.operational_inertia(M.robot.q),
                                       env, M.tau_d)
    K_adm = K if (cert_pise.ok and K <= K_ground) else K_ground

    if intent:
        c_intent = M.intent_ctrl.receive_intent(intent)
        M.ertc.lock_constraints(c_intent)

    p_hat = M.imc.observe(M.robot.momentum, M.F_cmd, M.mu_hat, M.dt)
    K_new, alpha = M.imc.safe_blend(M.K_cur, K_adm, M.x_err, M.v_rel, M.tank)

    if not contraction_certificate(M.outer_phi, M.outer_jac, M.M_metric,
                                   M.T_o, M.T_i, M.tau_d).ok:
        M.T_o = 3.0 * M.T_i
        M.budget.switches = M.budget.B_switch      # 冻结切换

    M.F_cmd = impedance_law(M.robot, K_new, D, M.x_d)
    EV = execute_and_build_evidence(M, M.F_cmd, M.x_d)
    M.tank.inject(P_inj=-(M.F_cmd * M.robot.v), P_diss=M.robot.dissipation, dt=M.dt)
    M.K_cur = K_new
    return M, EV, cert_pise, alpha, M.tank.E
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PISE | O(W) 频点扫描/周期 | O(W) | 认证频带内无源，增益/相位裕度达标 |
| DGIB | O(|Q|) 构型采样（可缓存） | O(|Q|) | K ≤ Λ(q)ω_c²，任意任务构型下不抖振 |
| IMC | O(1) 观测 + O(log 1/α) 混合 | O(1) | 冲击峰值 ≤ F_tol，能量不变式 E≥0 |
| CCC | O(n²) 雅可比每外环拍 | O(n²) | ρ-收缩 + 两时间尺度分离 |
| ETB | O(1) | O(1) | E(t)∈[0,E_cap] 且 ν≥0 |
| DSP | O(N) 场景后验 | O(N·d) | 场景→动力学指纹一致映射 |

**正确性定理（DCS, Dynamics-Certified Safety）**：
假设 A66–A70 成立：
- **(A66)** 在认证频带 `Ω_e` 内，端口阻抗线性模型 `Z_r=Λs²+Ds+K` 与环境阻抗 `Z_e` 有界；
- **(A67)** 操作空间惯性 `Λ(q)` 已知到误差 `ε_Λ`，控制时延 `τ_d ≤ τ_d^max`；
- **(A68)** 动量观测器在可观测、有界扰动下收敛（`‖p−p̂‖→0`）；
- **(A69)** 外环收缩成立（`ρ<1`）且 `T_o ≥ κT_i`；
- **(A70)** 能量罐记账精确，`E(0)≥E_min`。
则：
1. **闭环稳定性**：若 `K∈K_pise∩K_ground`，则耦合接触在 `Ω_e` 内无源，Nyquist 不包围 −1，接触力有界；`K_safe^{dyn}` 保证「静态安全」不早于「动态安全」。
2. **冲击安全**：IMC 的 `α(·)` 由 `F_peak≤F_tol` 与 `ΔE_K≤E_tank` 共同裁剪，故场景切换瞬间 `sup F≤F_tol` 且 `E≥0`。
3. **认知环收敛**：CCC 的 ρ-收缩与 `T_o≥κT_i` 保证外环增量收敛到唯一轨迹，不产生由认知更新驱动的极限环。
4. **仲裁安全**：DCC 的 `K_adm` 只含同时通过内环硬证书与外环软证书的阻抗，故任何认知/意图更新都不能越权提升刚度。
5. **预算安全**：任一 `B_dyn` 分量耗尽，触发对应的降刚度/保守观测/冻结切换/认知降级策略。

### IP-161 PISE（端口阻抗安全包络）

```python
def certify_port_impedance(K, D, Lambda, env, tau_d,
                           phi_min=0.35, zeta_min=0.7, eps_pas=0.0):
    omega_n = math.sqrt(K / Lambda)
    zeta = D / (2.0 * math.sqrt(Lambda * K))
    omega_c = (math.pi / 2 - phi_min) / max(tau_d, 1e-6)
    passive = (K - Lambda * env.omega_max**2) >= -eps_pas
    stable = (omega_n <= omega_c) and (zeta >= zeta_min)
    gain_margin = _nyquist_margin(K, D, Lambda, env, tau_d)
    return Certificate(ok=passive and stable and gain_margin >= 1.0,
                       omega_n=omega_n, zeta=zeta, omega_c=omega_c,
                       passive=passive, gm=gain_margin)
```

### IP-162 DGIB（动力学接地上界）

```python
def dynamics_grounded_bound(robot, q_grid, tau_d, phi_margin=0.35):
    omega_c = (math.pi / 2 - phi_margin) / max(tau_d, 1e-6)
    k_max = float('inf')
    for q in q_grid:
        Lambda = robot.operational_inertia(q)
        k_max = min(k_max, Lambda * omega_c**2)
    return k_max

def ground_impedance(K_nom, robot, q_now, tau_d, zeta_min=0.7):
    Lambda = robot.operational_inertia(q_now)
    K_hi = dynamics_grounded_bound(robot, robot.reachable_q(), tau_d)
    K = min(K_nom, K_hi)
    D = max(2.0 * zeta_min * math.sqrt(Lambda * K), K_nom_D(K_nom))
    return K, D
```

### IP-163 IMC（冲击-动量闭环）

```python
class MomentumImpactClosure:
    def __init__(self, robot, K_o=8.0, F_tol=40.0):
        self.robot, self.K_o, self.F_tol = robot, K_o, F_tol
        self.p_hat = 0.0

    def observe(self, p, F_cmd, mu_hat, dt):
        self.p_hat += (F_cmd - mu_hat + self.K_o * (p - self.p_hat)) * dt
        return self.p_hat

    def safe_blend(self, K_old, K_new, x_err, v_rel, tank):
        Lambda = self.robot.operational_inertia(self.robot.q)
        dt_c = self.robot.contact_time
        def peak(alpha):
            K = (1 - alpha) * K_old + alpha * K_new
            return Lambda * abs(v_rel) / dt_c + math.sqrt(K) * abs(x_err)
        alpha = 1.0
        while alpha > 0.0:
            dE = 0.5 * alpha * (K_new - K_old) * x_err**2
            if peak(alpha) <= self.F_tol and dE <= tank.E:
                break
            alpha *= 0.5
        return (1 - alpha) * K_old + alpha * K_new, alpha
```

def contraction_certificate(Phi, jacobian, M, T_o, T_i, tau_d, rho_min=0.05):
    DPhi = jacobian(Phi)
    contraction = max_eig(DPhi.T @ M @ DPhi) <= (1 - rho_min)

    delay_ok = rho_min * T_o + tau_d <= 0.5 * T_o
    return Certificate(ok=contraction and timescale and delay_ok,
                       rho=rho_min, kappa=T_o / max(T_i, 1e-9))

### IP-165 ETB（能量罐）

class EnergyTank:
    def __init__(self, E0, E_cap, E_min):
        self.E, self.E_cap, self.E_min = E0, E_cap, E_min

    def inject(self, P_inj, P_diss, dt):
        self.E = min(self.E_cap, max(0.0, self.E + (P_inj - P_diss) * dt))

    def can_stiffen(self, dK, x_err):
