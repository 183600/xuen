# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「群体智能」×「深度相机」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570；IP-340–356）。
> 本轮纪律：**群体冗余不假装独立 + 深度证据可证 + 共识不承重**。两个灵感分别治理 v9 的两种债：**协调债**（AC/MW/ID 全是单机闭环；块证书的 `dist(s,O)` 只对本机负责，在多机/人机共享工位里，“我有中止点”可能正是另一机的碰撞点）与**感知债**（v9 把深度相机的几何当作精确真值，`d_safe` 是常数；透明/反光/遮挡/远距/运动模糊会让“看起来空”的区域其实是未知或危险，而“未知=可通行”会直接击穿 SpatialCert）。新模块一律为可选增强：失效即注入群体侧/深度侧中立元，严格等价退回 v9（引理 92），而非行为漂移。

## 0. 直觉与动机

**灵感 1（群体智能 → 证书场、分离律与共识中止）**
直觉：群体智能最有用的部分不是“很多机器人一起做”，而是“个体只遵守局部规则，却能得到全局可证的秩序”。v9 的单机 AC 在共享空间里有一个盲点：它把其他智能体当成“环境”或“噪声”，而不是“会移动、会犯错、会失联的安全约束”。蚁群的信息素给出第一个类比：把“哪里可走、哪里危险、哪条块曾经成功”沉积到一个**带时间衰减与出处的共享证书场**，后来的个体不必重新探测；鸟群的分离律给出第二个类比：每对个体维持 `d_brake(v_i)+d_brake(v_j)+d_safe` 的时空分离不变式；共识/法定人数给出第三个类比：中止与否可以由邻居 ack 决定，但**安全绝不能依赖 ack**——失联时每个个体必须能单方面安全停驻。核心创新：**群体深度证书场（SDF）** + **共识中止协议（CAP）**。关键纪律：共享证据只降低不确定性，不降低保守性；`N_eff` 而不是 `N` 才是冗余。

**灵感 2（深度相机 → 不确定性证书与主动探针）**
直觉：深度相机不是“测距仪”，而是一个有系统误差的传感器：误差随距离增长、随入射角增大，在透明/镜面/黑色/远距/快速运动时爆炸；更严重的是，遮挡后的空间根本没有测量。v9 的 `dist(s,O)` 默认所有像素都是真值，这在干净仿真里成立，在真实场景里是“把未知当自由”。正确做法是把深度误差显式传播到 clearance 的下置信界，并把**未知空间当作占据**（unknown=occupied）；当未知比例过高或透明/镜面被多视角一致性检测出来时，不是“更保守地继续”，而是**主动改变视角/曝光去测量**。核心创新：**深度不确定性证书（DUC）** + **主动深度探针（ADP）**。深度相机的多视角冗余正好与群体智能耦合：不同个体从不同视角看同一遮挡区，但前提是证据独立性被正确计价。

**灵感 3（耦合 → 群体块证书与集体蒸馏）**
直觉：如果 SDF 把“别人说这里空”当成独立证据，误差方差会被错误地除以 N，群体在最需要冗余时反而共享同一个盲区——这是**共模失效**。因此耦合的核心不是“共享越多越好”，而是“共享必须携带出处、相关性与未知”：自由空间需要所有活证据一致，障碍/未知一票否决；`N_eff` 低于阈值时降级为单源、限速或主动探测。另一个耦合点是 ID：v9 的模块休眠是单机决定的，但在群体里，一个模块可能是别人的安全依赖；因此**集体休眠需要依赖者全体同意 + 法定人数**，否则保持 active——**集体不静默删码律**。

## 1. 研究问题（轮次升级版）

- **Q1（深度证据的可证性）**：在何种标定与未知空间语义下，逐像素深度误差界能转化为 clearance 的保守下界？透明/镜面/遮挡的检测失败如何被“未知=占据”兜底？主动探针的信息增益与安全预算如何界定？
- **Q2（群体证据的独立性与共模）**：如何用出处类别与视角重叠估计有效冗余 `N_eff`，使共享深度证据只按独立信息量降低不确定性？保守合并与隔离能否在拜占庭/过期证据下保证“零假自由”？
- **Q3（共识不承重的多机中止）**：如何设计时空预留与中止协议，使安全在通信丢失、分区、Byzantine 邻居下仍由单机不变式保证，而共识只影响效率？中止延迟与活性如何界定？
- **Q4（集体蒸馏的安全边界）**：集体休眠在什么依赖关系与法定人数下不会静默删除别人的安全模块？free-riding 的信用机制如何只影响信任/优先级而不影响安全地板？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 证据独立律（Evidence Independence, EI）**
跨个体/跨视角的证据只有在**独立出处类别**下才降低不确定性；同一相机型号、同一标定、同一视角簇视为同一出处，只计一次。有效冗余 `N_eff = N/(1+(N−1)ρ̄)`；`N_eff<2` 只能单源限速，`N_eff<1` 视为未知。自由空间要求所有活证据一致，障碍/未知一票否决；禁止“多数投票把未知变自由”。

**P14 共识不承重律（Consensus-Not-Load-Bearing, CNL）**
安全不变式必须由每个个体**单方面**可检查、可执行：即使所有邻居失联、ack 丢失、共识失败，个体也能基于“最坏影子预留”安全停驻。共识/法定人数只用于减少保守性、提高吞吐，不得作为安全的必要条件。无 quorum ⇒ 不进入争议体积 + K_eff=1 + 安全停驻，而不是“等待共识”。

**P15 深度可证律（Depth-Evidenced, DE）**
任何进入证书的 clearance 必须携带标定的深度误差界与未知比例；未知空间按占据处理；透明/镜面/遮挡必须由多视角一致性或主动探针显式处理；未标定/标定过期的深度不得生成证书。宁可弃权（K_eff=1/停驻），不得用未证深度“看起来空”。

**P16 集体不静默删码律（Collective Distill-Not-Delete, CDND）**
共享模块的休眠需要其所有安全依赖者一致低贡献 + 法定人数 + 无安全不变式依赖；任一依赖者需要它，它就保持 active（需求的 OR）。free-riding 信用只影响证据权重、探针分配与 quorum 权重，绝不触碰 φ^elig=false 的安全地板。

## 3. 与基线的接口（如何退化）

- SDF 失效/过期/被隔离 ⇒ 退回本机深度场（v9 SpatialCert），跨机项为空；等价 v9 单机感知；
- DUC 失效/未标定 ⇒ 退回 v9 的常数 `d_safe` 与原始深度；未知仍按占据（保守），等价 v9 的安全边界；
- CAP 失效/无 quorum/分区 ⇒ 关闭预留，按“最坏影子=全工作空间”单方面停驻/绕行，K_eff=1；等价 v9 单机中止语义；
- ADP 失效 ⇒ 停止主动探针，未知=占据并绕行；等价 v9 保守路径；
- SD 失效 ⇒ 退回每机 v9 ID，共享模块恒 active；等价 v9 单机蒸馏；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 五级链继续退化至 v8/v7；全失效 ⇒ v6。

## 4. 预期贡献

1. **群体深度证书场**：带出处/时间衰减/保守合并的 stigmergic 共享证据，首次把“别人的深度”纳入可证安全边界；
2. **深度不确定性证书**：逐像素误差界 + 未知=占据 + 透明/镜面检测，把 v9 的精确几何假设替换为可证下界；
3. **共识中止协议**：时空预留 + 分离不变式 + 最坏影子，安全单方面可证、共识只提效；
4. **有效冗余与共模防御**：`N_eff` 与出处类别把“群体冗余”从口号变成可计价的独立信息；
5. **集体蒸馏**：依赖者法定人数 + 反 free-riding 信用，防止共享模块被静默删除；
6. **实验 E571–E590**：深度标定/透明检测、SDF 健全性/污染、N_eff 校准、CAP 分区/延迟、主动探针、集体蒸馏、共模对抗与端到端。

## 5. 本轮最大风险

**一句话**：群体共享深度证据的最大危险不是“证据不够多”，而是“证据不独立”——若 SDF 把同型号相机、同标定、同视角的 N 个个体当成 N 份独立冗余，`N_eff` 会被高估，群体在最需要冗余时恰好共享同一个盲区（共模失效），而共识延迟又会把中止推迟到该盲区被撞上的那一刻。

**新增定义 540（群体深度证书场 SDF）** 工作空间离散为体素 x∈X。每个个体 i 在时刻 t 沉积
```
e_i(x,t) = (kind, f_i, o_i, u_i, ε_i, ℓ_i, h_i, stamp)
kind ∈ {free, obs, unknown}
```
`free` 表示在误差界内看到可通行自由空间，`obs` 表示看到占据，`unknown` 表示无回波/被遮挡/被判透明镜面/过期。合并规则（保守）：
```
o_t(x) = 1   若存在未过期 obs 沉积
f_t(x) = 1   否则若所有覆盖 x 的未过期沉积均为 free
u_t(x) = 1   否则（无覆盖 / 任一 unknown / 过期）
```
自由层级：
- **tier A**：至少 2 个独立出处类一致 free 且 `N_eff(x) ≥ 2`；
- **tier B**：仅 1 个独立出处类 free 且 `N_eff(x) ≥ 1`，限速 `v_single`、余量 `β_single`；
- **tier U**：`u=1`，禁止进入（除非主动探针或 K=1 的已验证逃逸）。

时间衰减：free 证据超过 `τ_stig` 退化为 unknown（**绝不退化为 free**）；obs 证据超过 `τ_obs` 仍保留为 obs（安全不对称）。

**新增定义 541（深度不确定性证书 DUC）** 对每个有效像素 u，深度 z(u) 的误差界 ε(u) 由分层保形校准给出，`P(|z_true(u)−z(u)| ≤ ε(u)) ≥ 1−α_pix`。反投影 `p(u)=z(u)K^{-1}[u,1]^T`，协方差 `Σ(u)=JΣ_zJ^T+Σ_pix`。clearance 下界：
```
d̲(s) = min_{u∈Valid} [ ||s−p(u)|| − κ·sqrt(λ_max(Σ(u))) − ε(u) ]
```
未知集 U（无效/遮挡/透明镜面/低置信）按占据处理：
```
d_U(s) = min_{x∈∂U} ||s−x||
```
证书有效 ⇔ `d̲(s) ≥ d_safe + d_brake(v)` ∧ `d_U(s) ≥ d_safe + d_brake(v)` ∧ `unknown_fraction(C) ≤ η_u`。透明/镜面：多视角一致性残差 `r(u)=min_j |z_i(u)−z_{j→i}(u)|`；`r(u)>τ_r` 或置信 `<τ_c` ⇒ `u∈U`。

**新增定义 542（出处类别与有效冗余 N_eff）** 出处类别 `ℓ=(sensor model, calibration id, viewpoint cluster, algorithm version)`。同类相关性 ρ=1；异类相关性
```
ρ_ℓℓ' = ρ_0 · overlap(ℓ,ℓ')
```
`ρ_0∈[0,1]` 为最大跨类相关，`overlap` 为两视角/标定共享的像素-几何比例。对覆盖 x 的 N 个独立类：
```
ρ̄(x) = (1/(N(N−1))) · Σ_{ℓ≠ℓ'} ρ_ℓℓ'
N_eff(x) = N / (1 + (N−1)·ρ̄(x))
```
融合不确定度按 `σ²/N_eff` 计。`N_eff<2 ⇒ tier B`（限速），`N_eff<1 ⇒ tier U`（未知）。`ρ_0` 由 E574 标定，且取上界（保守）。

**新增定义 543（群体空间预留与共识中止 CAP）** 个体 i 的意图块 ζ_i 给出时空走廊 `C_i(τ)`（τ∈[t,t+KΔt]）与中止点集 P_i。预留 `R_i=(C_i,P_i,[t_i^s,t_i^e],π_i,sig_i)`。分离不变式：
```
Sep(i,j,τ) ⇔ dist(C_i(τ),C_j(τ)) ≥ d_brake(v_i)+d_brake(v_j)+d_safe
```
最坏影子：
```
Ŝ_j(t) = R_j 的走廊按 v_max^j·(t−t_j^last) 向各方向膨胀
Ŝ_j(t) = 整个工作空间            若 t−t_j^last > T_silence
```
本地安全谓词：
```
Safe_i(t) ⇔ 单机中止不变式
          ∧ ∀j: dist(traj_i, Ŝ_j(t)) ≥ d_brake(v_i)+d_brake(v_j^max)+d_safe
```
协议：propose → ack/quorum → commit；无 quorum/冲突 ⇒ yield 或单方面停驻。**安全只依赖 Safe_i（本地可查）；共识只把 Ŝ_j 替换为精确 R_j，减少保守性。**

**新增定义 544（群体块证书 SCC）**
```
Ĉ_i^swarm = (Ĉ_i^DUC, R_i, {tier(x),N_eff(x)}_{x∈C_i}, κ_i^compat)
```
`κ_i^compat` 为与所有重叠邻居的兼容性证据。有效条件：
1. DUC 有效（定义 541）；
2. ∀x∈C_i：tier(x)=A，或 tier=B 且 v≤v_single 且余量 β_single；
3. ∀j∈Nbr(C_i)：Sep(i,j,τ) 成立，或 i 的中止点 p* 可在冲突前停驻；
4. `unknown_fraction(C_i) ≤ η_u`；
5. P_i 联合安全（对每个 p∈P_i 检查与 Ŝ_j 的分离）。

任一失败 ⇒ K_eff 收缩；仍失败 ⇒ 退出争议体积 + 安全停驻。

**新增定义 545（主动深度探针 ADP）** 探针 `a=(viewpoint, exposure, illumination)` 作用在未知/透明簇 Z⊆U。信息增益：
```
IG(a) = H(Z | D_{1:t}) − E_{z_a}[ H(Z | D_{1:t}, z_a) ]
```
按 `IG(a)/cost(a)` 选 a*，约束：视角可达且路径 tier A；探针不进入争议体积；预算 `B_probe ≤5ms/次、≤1 次/控制周期`。群体分配：每个未知簇至多一个探针者；个体按 gain/cost 竞价，信用 `κ_i^credit` 低者降权；PSO 在安全视角流形上搜索 a*。熵对独立簇可加 ⇒ IG 对簇集合单调子模 ⇒ 贪心 `(1−1/e)` 近似。

**新增定义 546（群体蒸馏账本 SD）** 模块 m 的依赖集 `Dep(m)={i: m 属于个体 i 的安全论证}`。集体休眠条件：
```
φ^elig(m)=true ∧ ∀i∈Dep(m): c_{i,m}<τ_off 持续 H_off 轮
∧ quorum(m) ≥ q ∧ SDF/CAP 均有效
```
任一依赖者需要 m ⇒ m 保持 active（需求 OR）。信用：
```
κ_i^credit ← EMA(贡献沉积 + 探针 + 算力 − 消费共享证据)
```
`κ_i^credit < τ_credit` ⇒ 其沉积降权、探针竞价降权、quorum 权重降权；但 `φ^elig=false` 的安全地板与 active 状态不受信用影响。

**新增定义 547（中立元与退化表 v10）**

| 新模块 | 中立元 v^⊥ | 注入后等价 |
|---|---|---|
| SDF | 本机深度场；跨机项=∅ | v9 SpatialCert |
| DUC | 常数 `d_safe` + 原始深度（ε=0） | v9 安全边界 |
| CAP | 无预留；`Ŝ_j=全工作空间` | v9 单机中止 |
| ADP | 不探针；未知=占据 | v9 保守路径 |
| SCC | 单机 v9 块证书 | v9 AC |
| SD | 每机 v9 ID；共享模块 active | v9 ID |

注：SDF 的中立元不是传统恒等元，而是“吸收跨机项、保留本机项”的截断算子；其正确性由引理 88 与 92 联合保证。

# IP-358 DepthUncertaintyCertifier：深度不确定性证书
class DepthUncertaintyCertifier:
    def __init__(self, K, alpha=0.01, kappa=3.0, d_safe=0.15,
                 eta_unknown=0.05, tau_r=0.03, tau_c=0.5):
        self.K, self.alpha, self.kappa = K, alpha, kappa
        self.d_safe, self.eta_u = d_safe, eta_unknown
        self.tau_r, self.tau_c = tau_r, tau_c
        self.eps_table = {}                      # (range_bin, angle_bin, material) -> quantile

    def calibrate(self, calib_set):
        for (s, z, mat, z_true) in calib_set:
            self.eps_table[(s.range_bin, s.angle_bin, mat)] = \
                conformal_quantile(abs(z - z_true), self.alpha)

    def lower_clearance(self, s, depth, conf, pose):
        p, cov, valid = backproject(depth, conf, pose, self.K)
        resid = multi_view_residual(depth, pose)
        unknown = (~valid) | (resid > self.tau_r) | (conf < self.tau_c)
        terms = []
        for u in where(valid & ~unknown):
            eps = self.eps_table.lookup(s.range(u), s.angle(u), s.material(u))
            terms.append(norm(s.pos - p[u]) - self.kappa * sqrt(eigmax(cov[u])) - eps)
        d_known = min(terms) if terms else 0.0
        d_unknown = distance_to_frontier(s.pos, unknown, pose)
        return min(d_known, d_unknown), unknown.mean()

    def certificate(self, s, v, corridor, depth, conf):
        d, u_frac = self.lower_clearance(s, depth, conf, s.pose)
        ok = (d >= self.d_safe + d_brake(v)) and (u_frac <= self.eta_u)
        return Cert(ok, d, u_frac, self.eps_table.snapshot())


# IP-357 StigmergicDepthField：群体深度证书场
class StigmergicDepthField:
    def __init__(self, voxel=0.05, tau_stig=2.0, tau_obs=30.0, rho0=0.6):
        self.cells = defaultdict(list)           # x -> [Deposit]
        self.voxel, self.tau_stig, self.tau_obs, self.rho0 = voxel, tau_stig, tau_obs, rho0

    def deposit(self, agent_id, free, obs, unknown, eps, klass, stamp):
        for x in free:
            self.cells[x].append(Deposit('free', agent_id, eps, klass, stamp))
        for x in obs:
            self.cells[x].append(Deposit('obs', agent_id, eps, klass, stamp))
        for x in unknown:
            self.cells[x].append(Deposit('unknown', agent_id, eps, klass, stamp))

    def merge(self, x, now):
        live = [d for d in self.cells[x]
                if now - d.stamp < (self.tau_obs if d.kind == 'obs' else self.tau_stig)]
        if any(d.kind == 'obs' for d in live):
            return OBSTACLE, 'U', 0.0
        if not live or any(d.kind == 'unknown' for d in live):
            return UNKNOWN, 'U', 0.0
        classes = {d.klass for d in live if d.kind == 'free'}
        n_eff = self.effective_redundancy(classes)
        if n_eff >= 2.0:
            return FREE, 'A', n_eff
        if n_eff >= 1.0:
            return FREE, 'B', n_eff
        return UNKNOWN, 'U', n_eff

    def effective_redundancy(self, classes):
        n = len(classes)
        if n <= 1:
            return float(n)
        rho = sum(self.rho0 * overlap(l, l2) for l in classes for l2 in classes if l != l2)
        rho /= n * (n - 1)
        return n / (1 + (n - 1) * rho)

    def clearance(self, s, corridor):
        tiers = [self.merge(x, now()) for x in corridor]
        if any(t == 'U' for _, t, _ in tiers):
            return 0.0, 1.0
        return distance_transform_clearance(corridor, tiers), 0.0


# IP-359 ConsensusAbortProtocol：共识不承重的中止
class ConsensusAbortProtocol:
    def __init__(self, comm, d_safe, a_max, T_lease=100, T_silence=0.5):
        self.comm, self.d_safe, self.a_max = comm, d_safe, a_max
        self.T_lease, self.T_silence = T_lease, T_silence
        self.last = {}                            # j -> Reservation

    def shadow(self, j, now):
        r = self.last.get(j)
        if r is None or now - r.stamp > self.T_silence:
            return WHOLE_WORKSPACE             # 失联 = 最坏
        return r.expand(v_max[j] * (now - r.stamp))

    def compatible(self, i, R_i, now):
        for j in self.neighbors(i, R_i):
            if not pairwise_sep(R_i, self.shadow(j, now), self.d_safe, self.a_max):
                return False, j
        return True, None

    def commit_block(self, i, chunk, now):
        R_i = Reservation(chunk.corridor, chunk.abort_pts, priority(i), now)
        ok, j = self.compatible(i, R_i, now)
        if not ok:
            return self.yield_or_stop(i, j)     # 本地安全，不等共识
        acks = self.comm.broadcast_collect(R_i, deadline=now + T_comm)
        if acks.all and acks.overlap_compatible:
            self.lease[i] = R_i
            return chunk
        return self.yield_or_stop(i, None)       # 共识失败 ≠ 不安全


# IP-360 ActiveDepthProber：主动深度探针
class ActiveDepthProber:
    def __init__(self, safe_viewpoints, budget_ms=5.0):
        self.viewpoints, self.budget_ms = safe_viewpoints, budget_ms

    def gain(self, vp, unknown_clusters):
        return entropy(unknown_clusters) - expected_entropy_after(vp, unknown_clusters)

    def choose(self, unknown_clusters):
        return max(self.viewpoints, key=lambda vp: self.gain(vp, unknown_clusters) / cost(vp))

    def swarm_allocate(self, agents, clusters, sdf):
        bids = [(a, c, self.gain(a.viewpoint, c) / cost(a.viewpoint) * a.credit)
                for a in agents for c in clusters]
        return greedy_submodular_dedup(bids, clusters)   # 每簇至多一个探针者


# IP-362 SwarmDistiller：集体蒸馏（扩展 v9 ID）
class SwarmDistiller:
    def __init__(self, tau_off=0.01, H_off=3, quorum=0.67, tau_credit=0.05):
        self.c, self.credit = {}, {}
        self.tau_off, self.H_off, self.quorum, self.tau_credit = \
            tau_off, H_off, quorum, tau_credit

    def collective_step(self, agents, modules):
        for m in modules:
            deps = [i for i in agents if m in agents[i].safety_case]
            if not deps:
                continue
            low = all(self.c[i][m] < self.tau_off for i in deps)
            quorate = len(deps) / len(agents) >= self.quorum
            if low and quorate and self.sdf_ok and self.cap_ok and self.phi_elig(m):
                self.set_collective_dormant(m)          # ≡ 注入 v^⊥
            else:
                self.set_active(m)                      # 需求 OR / 安全地板

    def credit_update(self, i, contributed, consumed, used_by_others):
        self.credit[i] = 0.9 * self.credit.get(i, 0.0) + 0.1 * (
            contributed + used_by_others - consumed)

## 4. 推导

**引理 87（DUC 保守性）** 设 (A1) 对每个有效像素 `P(|z_true−z|≤ε)≥1−α_pix`；(A2) 未知/遮挡/透明像素按占据处理；(A3) `Σ_true⪯Σ`。则 w.p. `≥1−α`（`α=α_pix·|Valid|` 的 union bound）有 `d̲(s) ≤ d_true(s)`；故 `d̲ ≥ d_safe+d_brake(v)` ⇒ `d_true ≥ d_safe+d_brake(v)`。证明：对任意 u，三角不等式给出
```
||s−p_true|| ≥ ||s−p|| − ||p_true−p||
             ≥ ||s−p|| − ε(u) − κ·sqrt(λ_max(Σ(u)))
```
对 u 取 min 保持不等号；未知集按占据只会减小 `d_U`，故不会高估 clearance。∎

**引理 88（SDF 保守合并与零假自由）** 若每个 free 沉积在其误差界内真实自由，obs 沉积真实占据或未知，且合并规则为“free 需所有覆盖 x 的活沉积一致，obs/unknown 一票否决，过期 free→unknown”，则 `f_t(x)=1 ⇒ x 真实自由`；任何未知/矛盾只会把 x 降为 tier U，不会升为 free。故 SDF 的 clearance 下界 ≤ 真实 clearance。证明：对沉积数与时间归纳；free 的合取条件比真实自由更严；obs/unknown 的析取条件比真实占据更宽；衰减只移除 free 支持。∎

**引理 89（N_eff 与共模保守性）** 设 N 个类间误差相关矩阵 R 的非对角元 ≤ ρ̄。等权融合的误差方差
```
Var(mean) = σ²/N² · 1ᵀR1 ≤ σ²/N² · (N + N(N−1)ρ̄) = σ²/N_eff
```
因此用 `N_eff` 作为有效样本数的不确定度界是保守的；当 ρ̄=1 时 `N_eff=1`，共享证据不产生任何方差缩减。若 ρ̄ 的估计取上界，则证书不会低估不确定性。∎

**引理 90（CAP 安全不依赖共识）** 若每个个体在执行前检查 `Safe_i(t)`（对最坏影子 Ŝ_j），且 Ŝ_j(t) 包含邻居 j 的真实可达集（膨胀 `v_max·Δt`；失联→全工作空间），则无论消息丢失、分区、共识失败，均无碰撞。共识把 Ŝ_j 替换为精确 R_j 只会收紧可达集，不会扩大。证明：`Safe_i` 对包含真实轨迹的影子成立 ⇒ 真实轨迹间距离 ≥ 刹车和 + `d_safe`；失联影子是全工作空间 ⇒ 个体不会进入任何可能被占的区域。∎

**引理 91（CAP 活性与有界中止延迟）** 在优先级全序、租约到期、单方面停驻可用的条件下，协议无死锁；中止延迟 `≤ T_comm + T_lease + d_brake(v_max)`。证明：停驻在争议体积外总是满足 `Safe_i` 并释放租约；优先级全序无环；租约到期强制重新协商；无 quorum 时立即走单方面停驻，故不会无限等待。∎

**引理 92（v10 退化等价）** 对表 547 的每个中立元，注入后所有跨机/深度不确定性项消失，SCC 退化为 v9 AC 的单机块证书，SD 退化为 v9 ID，故系统端口读数与 v9 ACMD 逐位一致；v9 的引理 82–86 全部适用。证明：逐行检查中立元；SDF 的跨机项为空、DUC 的 ε=0/常数 margin、CAP 的邻居集为空、ADP 关闭、SD 每机独立；组合后与 v9 定义 532–539 相同。∎

**引理 93（集体蒸馏不静默删码）** 集体休眠仅在依赖者全体低贡献、quorum、且无安全依赖时允许；休眠行为等于 v^⊥ 注入（v9 引理 84）。因此任意集体状态下的安全性由 v9 引理 80–81/84 传递；任一依赖者需要 m 时 m 保持 active，故没有个体能静默删除他人的安全模块。信用机制只改变权重，不改变 active/φ^elig。∎

**引理 94（拜占庭/过期证据隔离）** 若沉积与本地深度证据矛盾超过 θ 则隔离；free 需所有活沉积一致；因此恶意沉积最多把 free 降为 unknown（一票否决），不能把 unknown/obs 升为 free。若独立出处类少于 q，cell 降为 tier U；故假自由率为 0，可用性优雅降级。证明：合并规则中 free 是合取、obs/unknown 是析取；隔离只移除矛盾沉积，剩余仍满足保守性；降级路径由引理 88。∎

## 8. 本轮最大风险

**一句话**：群体共享深度证据的最大危险不是“证据不够多”，而是“证据不独立”——若 SDF 把同型号相机、同标定、同视角的 N 个个体当成 N 份独立冗余，`N_eff` 会被高估，群体在最需要冗余时恰好共享同一个盲区（共模失效），而共识延迟又会把中止推迟到该盲区被撞上的那一刻。
