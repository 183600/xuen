# 第 61 轮（承接第 60 轮 SGEC；新一轮灵感循环第 1 轮；本轮灵感：「抓取」×「姿态估计」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」（SSM×CIEC×EPIR×SERC×PCE++++），但该闭环只连接了**宏观场景语义**与**微观阻抗参数**，跳过了中尺度的**几何姿态**，于是留下三个结构性缺口：
> 1. **场景→阻抗映射丢失几何中尺度**：SSM 把「桌面/楼梯/湿滑」映射为 π_scene(K|z)，却把被抓物体当作无位姿的点。真实抓取中，**1 cm 的 6D 姿态误差足以让正确场景先验下的抓取失败**；缺「姿态估计→抓取→阻抗」的中尺度桥梁。
> 2. **证据链缺少感知根节点**：J_exec 证明「执行合规」，却不证明「执行所依据的位姿是对的」。一个位姿错误但执行完美的抓取，J_exec 仍会签发合规证书——这正是**证据层自洽、感知层灾难**的抽象泄漏。
> 3. **抓取被当作纯消费而非探测**：第 60 轮沿用「先感知后执行」（perceive-then-act），但接触丰富的抓取本身携带位姿信息——**抓取接触可以降低姿态不确定性**（act-to-perceive）；姿态估计与抓取执行被错误地切成单向两段。

## 0. 直觉与动机

**灵感 1（抓取 → 姿态信念场 GPBF）**
直觉：位姿不是一个点 μ∈SE(3)，而是一片**概率云** b(ξ)=N_se3(μ,Σ)。抓取成功与否不问「位姿是多少」，而问「在这片云里，有多大概率仍能形成力闭合」。于是抓取规划从 μ 上的确定性几何，变成 b(ξ) 上的**机会约束优化**：max_g P_{ξ~b}[force_closure(g∘ξ)]。关键洞见：**姿态协方差是抓取可执行性的第一等公民**，而不是估计器丢弃的副产物。

**灵感 2（姿态估计 → 姿态不确定性-阻抗映射 PUI）**
直觉：若位姿在某方向不确定，就在该方向「软」一点，避免位姿误差被高刚度放大成破坏性接触力；在确定的方向「硬」一点，维持抓取稳定。即阻抗椭球要与姿态不确定椭球**共轴、反向缩放**。关键洞见：**用各向异性阻抗把姿态不确定性「吸收」进机械柔顺性**，而不是让不确定性直接变成力误差。

**灵感 3（抓取即探测 GaP）**
直觉：指尖接触力/力矩是位姿的观测。一次受控的「轻触—加载—卸载」就是一次贝叶斯实验。抓取动作有双重效用：任务推进 + 姿态信息增益，U(a)=U_task(a)+λ_voi·I(ξ; w_a | b)。关键洞见：**把抓取从「消费信息」升级为「生产信息」**——主动选择能最大化解歧义的接触点与刚度。

**灵感 4（三灵感合流 → 抓取-姿态接地闭环 GPGL）**
直觉：视觉先验 b_0 → GPBF 机会约束选 g* → PUI 生成 K* → 执行接触 → GaP 得到力/力矩 → CPEL 贝叶斯更新 b_1 → 若姿态漂移超阈值则重规划 → 写入 J_grasp → EPIR 保序回传。闭环：**姿态→抓取→阻抗→接触→姿态更新**，与第 60 轮的「场景→约束→执行→证据」闭环正交耦合。

**灵感 5（语义-几何先验链 GSPIC + PCE+++++）**
直觉：第 60 轮是 scene→K；本轮补上 scene→object→grasp→K 的**语义-几何-执行三级先验链**：场景 z 推断物体类 o，o 给出抓取位姿先验 P(g|o,z)（来自抓取数据集），g 给出阻抗先验 π(K|g)。预算扩展为 B_pose（姿态推断/校准）、B_grasp（抓取搜索/重抓），与 B_scene/B_intent/B_ros/B_exec 统一调度。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（抓取姿态信念场 GPBF）** 姿态信念 b(ξ)=N_se3(ξ; μ, Σ)，其中 ξ=log(μ⁻¹T)∈se(3)≅R⁶，μ∈SE(3)，Σ∈R⁶ˣ⁶≻0。物体坐标系抓取 g∈SE(3) 经 b 传播到世界系后，抓取成功泛函：
```
S(g) = P_{ξ~b}[ FC(g∘ξ) ≥ m_c ]
g* = argmax_{g∈G} S(g)   s.t.  K*(g) ∈ K_safe
```
其中 FC 为力闭合判定，m_c 为闭合裕度阈值。关键：**位姿以分布进入优化，而非以点估计进入几何**。

**定义 162（姿态不确定性-阻抗映射 PUI）** 给定姿态协方差 Σ（接触系），对其平移块做特征分解 Σ_t=U diag(σ_i²) Uᵀ。各向异性阻抗 K=U diag(k_i) Uᵀ，其中
```
k_i = clip( c / σ_i² , k_min, k_max ),   c = F_max / sqrt( χ²_{3,1-α} · Σ_i 1/σ_i² )
```
该式保证力误差预算 P(‖K δx‖ ≤ F_max) ≥ 1-α，同时最大化总刚度 Σk_i。结论：**越不确定的方向越软，且软硬不以拍脑袋系数决定，而由力上限与置信水平解析给定**。

**定义 163（抓取即探测 GaP）** 动作 a 的双重效用与接触信息增益：
```
U(a) = U_task(a) + λ_voi · I(ξ; w_a | b)
I(ξ; w_a | b) = ½ log det(I + Σ · F_a),   F_a = J_aᵀ R⁻¹ J_a
```
其中 J_a 为接触力对姿态的雅可比，R 为力测量噪声协方差。GaP 选择接触点/刚度以最大化 I，同时受滑脱风险与 K_safe 约束。

**定义 164（抓取证据证书 J_grasp）** 
```
J_grasp = ( b(ξ), g, K, p_fc, p_cone, p_slip, τ_stamp, sig )
valid  ⇔ p_fc ≥ 1-δ ∧ p_cone ≥ 1-δ ∧ p_slip ≤ ε_slip ∧ K ∈ K_safe
```
证据链扩展为 **J_grasp ⤳ J_exec ⤳ EV-exec**：执行证书不再悬空，而是挂在姿态信念这个「感知根」上。

**定义 165（接触姿态估计闭环 CPEL）** 贝叶斯更新与漂移触发：
```
b_{t+1} ∝ b_t · L(w_t | ξ, K)
若 ‖μ_{t+1} ⊖ μ_t‖_{Σ} > γ  或  KL(b_{t+1} ‖ b_t) > θ：
    K ← PUI(Σ_{t+1});  g ← chance_constrained_replan(b_{t+1})
```
接触力既是执行结果，也是下一次姿态估计的观测。

**定义 166（抓取-姿态接地闭环 GPGL）** 算子 GPGL(M, object, scene, δ_f_req)：
```
① b_0 ← PoseEstimator.observe(rgbd)                     # 视觉姿态先验
② o ← GSPIC.infer_object(scene, visual)                  # 场景→物体类
③ g ← argmax_{g∈G} P_{ξ~b_0}[FC(g∘ξ)] s.t. K∈K_safe      # GPBF 机会约束
④ K ← PUI(Σ_0) ∩ EEIS.compile_with_scene_prior(π(K|g))   # 几何×场景双先验
⑤ w ← execute_contact(g, K)                              # 接触（含 GaP 主动探测）
⑥ b_1 ← CPEL.bayes_update(b_0, w, K)                     # 接触姿态更新
⑦ 若漂移超阈：g,K ← replan(b_1)，回到 ⑤
⑧ J_grasp ← certify(b_1, g, K); J_grasp ⤳ J_exec          # 证据链挂根
⑨ EPIR.append(J_grasp); XMC++ 融合视觉/触觉/本体
⑩ Return (b_1, g, K, J_grasp, CPEL.status)
```

**定义 167（抓取语义-姿态-阻抗先验链 GSPIC）** 
```
P(o|z) → P(g|o,z) → π(K|g)
K_safe^grasp = EEIS.compile(π(K|g), δ_f_req) ∩ K_safe^scene
```
把第 60 轮的 `π_scene(K|z)` 细化为 `π(K|g,o,z)`：场景决定先验的粗粒度，几何决定先验的细粒度。

**定义 168（抓取可执行性判定 GEC）** 
```
GEC_valid(g) = [p_fc ≥ 1-δ] ∧ [pose_conf ≥ τ_pose] ∧ [K ∈ K_safe] ∧ [B_pose>0 ∧ B_grasp>0]
```
失败时三级回退：①主动重扫（花 B_pose 降低 Σ）；②柔顺探索抓取（GaP，花 B_grasp 换信息）；③放弃/释放（绝不带错误信念硬抓）。

**定义 169（抓取认知预算 PCE+++++）** B=(B_pose, B_grasp, B_scene, B_intent, B_ros, B_exec)。价值：
```
voi_grasp(π) = U_task(π) + λ_voi·I(ξ; w | a_π) − cost_pose(π) − cost_grasp(π) − cost_exec(π)
```
B_pose 耗尽 ⇒ 用通用各向同性阻抗并降至保守抓取；B_grasp 耗尽 ⇒ 禁止探索性接触、仅确定性抓取；B_exec 耗尽 ⇒ 原有降级。任一耗尽都在 GEC 处显式暴露，而非静默继续。

## 2. 关键算法伪代码

### IP-161/162 GPBF + PUI（姿态信念驱动的抓取规划）

```python
class GraspPoseBelief:
    def __init__(self, mu, Sigma):
        self.mu = mu          # 4x4 SE(3) 均值
        self.Sigma = Sigma    # 6x6 se(3) 协方差

    def sample(self, n=64):
        L = np.linalg.cholesky(self.Sigma + 1e-9*np.eye(6))
        return [self.mu @ exp_se3(L @ z) for z in np.random.randn(n, 6)]

def pose_uncertainty_to_impedance(Sigma, k_min=200., k_max=3000.,
                                  F_max=40., alpha=0.95):
    St = Sigma[:3, :3]
    w, U = np.linalg.eigh(St)
    w = np.clip(w, 1e-8, None)
    chi2 = chi2.ppf(alpha, df=3)
    c = F_max / np.sqrt(chi2 * np.sum(1.0 / w))
    k = np.clip(c / w, k_min, k_max)
    return U @ np.diag(k) @ U.T
```

### IP-163/165 GaP + CPEL（接触姿态闭环）

```python
def grasp_information_gain(belief, contact_model, g, K, R):
    J = contact_model.jacobian(g)
    F = J.T @ np.linalg.inv(R) @ J
    Sigma_post = np.linalg.inv(np.linalg.inv(belief.Sigma) + F)
    return 0.5 * (np.linalg.slogdet(belief.Sigma)[1]
                  - np.linalg.slogdet(Sigma_post)[1])

def contact_pose_estimation_loop(belief, g, K, cm, max_iters=3,
                                 drift_tol=0.008):
    for _ in range(max_iters):
        w = execute_contact(g, K)
        belief = bayes_update_se3(belief, w, cm)
        if np.linalg.norm(belief.mu[:3, 3] - g[:3, 3]) > drift_tol:
            K = pose_uncertainty_to_impedance(belief.Sigma)
            g = chance_constrained_replan(belief)
        else:
            break
    return belief, g, K
```

### IP-164 J_grasp（抓取证据证书）

```python
def issue_grasp_certificate(belief, g, K, n_mc=256):
    xs = belief.sample(n_mc)
    p_fc = np.mean([force_closure(g, xi) for xi in xs])
    p_cone = np.mean([wrench_in_cone(g, xi, K) for xi in xs])
    slip = estimate_slip_risk(belief, g, K)
    valid = p_fc >= 0.95 and p_cone >= 0.95 and slip <= 0.02
    return {'p_fc': p_fc, 'p_cone': p_cone, 'slip': slip,
            'trace_Sigma': float(np.trace(belief.Sigma)), 'valid': valid}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GPBF | O(1) 变换 / O(N) 采样 | O(1)+O(N) | 姿态可信域覆盖率 ≥ 1-α（校准前提下） |
| PUI | O(1)（3×3 特征分解） | O(1) | 力超限概率 ≤ α |
| GaP | O(k³)（6×6 求逆） | O(k²) | 信息增益非负 |
| CPEL | O(iters·k³) | O(k²) | 姿态误差在可观测子空间单调收缩 |
| J_grasp | O(N_mc·closure) | O(N_mc) | 证书覆盖率 ≥ 99% |
| GSPIC | O(|O|·|G|) 查表 | O(|O|·|G|) | 先验链相容 |

**正确性定理（GPG）**：假设 A71–A75 成立——**(A71)** 姿态信念已校准，真实位姿以概率 ≥1-α 落在可信域，NEES 处于 χ² 界内；**(A72)** PUI 满足力误差预算且 K*∈K_safe；**(A73)** 接触测量无偏，Fisher 信息正定；**(A74)** CPEL 贝叶斯更新一致，接触可观测子空间内误差单调收缩；**(A75)** J_grasp 将 b(ξ) 绑定到 J_exec，证据链有感知根。则：
1. **姿态可证性**：P(ξ_true ∈ 可信域) ≥ 1-α。
2. **阻抗安全性**：P(‖K δx‖ ≤ F_max) ≥ 1-α，且闭合裕度 ≥ m_c。
3. **探测收益性**：I(ξ;w|a) ≥ 0，后验熵在正确模型下不增。
4. **抓取成功率**：若 p_fc ≥ 1-δ 且信念已校准，则 P(抓取成功) ≥ 1-δ-o(δ)。
5. **证据链有根性**：任一 EV-exec 均可回溯到签发它的 J_grasp 与对应姿态信念。

## 5. 本轮最大风险

**一句话**：若姿态估计器**过度自信**（Σ 报得过小），PUI 会在恰恰错误的方向上给高刚度、GaP 又会基于错误信念规划「探测」，两者叠加会把一次本可恢复的位姿误差放大成滑脱或压碎——因此必须把「协方差在线校准（NEES 监控）+ 力锥硬约束 + 刚度下限 + 超阈放弃重抓」当作硬护栏，绝不能让「几何自信」越过「接触安全」。

## 2. 关键推导

**推导 1（力误差预算下的各向异性阻抗水填充）**
设接触系姿态误差 δx~N(0,Σ̂)，线性接触力误差 δf=Kδx，取 K=U diag(k)Uᵀ 与 Σ̂=U diag(σ_i²)Uᵀ 共轴。要求
```
P(‖δf‖ ≤ F_max) ≥ 1-α  ⇔  Σ_i k_i²σ_i² ≤ F_max² / χ²_{3,1-α}
```
在约束下最大化总刚度 Σ_i k_i（抓取稳定性代理），拉格朗日
```
L = Σ k_i − λ( Σ k_i²σ_i² − F_max²/χ² )
∂L/∂k_i = 1 − 2λ k_i σ_i² = 0  ⇒  k_i ∝ 1/σ_i²
```
代入约束得 `c = F_max/√(χ²·Σ1/σ_i²)`，再夹到 [k_min,k_max]。**结论：不确定越大的方向越软；各向同性刚度会把力预算浪费在低不确定方向，从而在高不确定方向留下最大力误差——这正是位姿误差导致抓取失败的力学根源。**

**推导 2（闭合概率的一阶尾界）**
对闭合裕度 m(ξ) 一阶展开 `m(ξ)≈m_0+∇m·δξ`，δξ~N(0,Σ)。若 ‖∇m‖σ_max ≤ m_0，则高斯尾界给出
```
P[m(ξ)<0] ≤ ½·exp( −m_0² / (2‖∇m‖²σ²) )
```
令右边 ≤ δ，得证书阈值 `m_0 ≥ σ_max·√(2 ln(1/(2δ)))`。**这把「抓取位姿要留多少裕度」从经验常数变成可计算的证书条件。**

**推导 3（GaP 的后验熵收缩）**
在线性高斯接触模型下，后验协方差 `Σ⁺=(Σ⁻¹+F_a)⁻¹`，故
```
H(b) − H(b⁺) = ½ logdet(I+ΣF_a) = I(ξ;w_a|b) ≥ 0
```
即受控接触在正确测量模型下**不可能增加**姿态不确定性；当 F_a 沿某子空间退化（滑动/无摩擦接触）时该方向增益为 0，CPEL 必须显式标记该方向「不可观测」，不得假装收敛。

```python
class GraspPoseBelief:
    def __init__(self, mu, Sigma):
        self.mu = mu          # 4x4 SE(3) 均值
        self.Sigma = Sigma    # 6x6 se(3) 协方差

    def sample(self, n=64):
        L = np.linalg.cholesky(self.Sigma + 1e-9 * np.eye(6))
        return [self.mu @ exp_se3(L @ z) for z in np.random.randn(n, 6)]

def chance_constrained_grasp(belief, G, m_c=0.03, n_mc=128):
    xs = belief.sample(n_mc)
    best, best_p = None, -1.0
    for g in G:
        p = np.mean([force_closure(g, xi, m_c) for xi in xs])
        if p > best_p:
            best, best_p = g, p
    return best, best_p

def pose_uncertainty_to_impedance(Sigma, k_min=200., k_max=3000.,
                                  F_max=40., alpha=0.95):
    St = Sigma[:3, :3]
    w, U = np.linalg.eigh(St)
    w = np.clip(w, 1e-8, None)
    chi2 = chi2.ppf(alpha, df=3)
    c = F_max / np.sqrt(chi2 * np.sum(1.0 / w))
    k = np.clip(c / w, k_min, k_max)
    return U @ np.diag(k) @ U.T
```

### IP-163/165 GaP + CPEL

```python
def grasp_information_gain(belief, contact_model, g, K, R):
    J = contact_model.jacobian(g)
    F = J.T @ np.linalg.inv(R) @ J
    Sigma_post = np.linalg.inv(np.linalg.inv(belief.Sigma) + F)
    return 0.5 * (np.linalg.slogdet(belief.Sigma)[1]
                  - np.linalg.slogdet(Sigma_post)[1])

def contact_pose_estimation_loop(belief, g, K, cm, max_iters=3,
                                 drift_tol=0.008):
    for _ in range(max_iters):
        w = execute_contact(g, K)               # 受控加载/卸载
        belief = bayes_update_se3(belief, w, cm)
        drift = np.linalg.norm(belief.mu[:3, 3] - g[:3, 3])
        if drift > drift_tol:
            K = pose_uncertainty_to_impedance(belief.Sigma)
            g, _ = chance_constrained_grasp(belief, grasp_candidates())
        else:
            break
    return belief, g, K
```

## 6. 本轮最大风险

**一句话**：若姿态估计器**过度自信**（Σ 报得过小），PUI 会在恰恰错误的方向上给高刚度、GaP 又会基于错误信念规划「探测」，两者叠加会把一次本可恢复的位姿误差放大成滑脱或压碎；必须以「协方差在线校准（NEES 监控）+ 力锥硬约束 + 刚度下限 + 超阈放弃重抓」四重护栏，确保「几何自信」永不越过「接触安全」。
