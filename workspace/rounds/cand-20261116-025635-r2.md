# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「长程任务」×「轻量化设计」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**任务级证书 + 误差预算会计 + 证书化轻量代理**。两个灵感分别治理 v9 的两种债：视界债（证书只覆盖 200ms 单块，没有任务级语义，误差无跨块预算）、结构算力债（仍假定全量 LSTM-MPC + 64 候选，轻量化只是调度而非结构）。必须沿用**中立元退化链**：任一新增模块失效即注入中立元、严格退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（长程任务 → 任务级鲁棒度证书与误差预算会计）**
直觉：v9 的块证书回答的是"这 200ms 安全吗"，长程任务要回答的是"接下来 30 分钟、几十个子目标串起来，整体还满足任务规范吗，模型误差会不会在无人注意时复利增长"。核心创新是**任务视界证书器（MissionHorizonCertifier, MHC）**：用有界视界 STL 的鲁棒度 ρ 作为可组合标量，把每块的局部证书在时间轴上组合出任务级下界；并用**误差预算账本（ErrorBudgetLedger, EBL）**把"模型一步误差 ε_step、量化误差 q、稀疏更新陈旧度 ε_stale、状态误差收缩率 λ"记成一笔账。关键洞察：**重锚定把无界视界的误差增长截断为有界 episode**——只要重锚定间隔有界，任意长的任务也能维持可证的每块误差界。进度信念只维护子目标 DAG 的活跃前沿，内存不随视界 H 增长。

**灵感 2（轻量化设计 → 证书约束的代理级联与 anytime 退出）**
直觉：轻量化常被误写成"换个更小的网络"，但在安全关键系统里，小模型只有在**其误差被证书化地界住**时才可被采纳。核心创新是**证书化轻量代理级联（LightweightSurrogateCascade, LSC）**：tiny→medium→heavy 三级代理，各自携带由 split conformal 给出的有限样本误差包络 ε_τ，运行期选"误差包络仍在剩余预算内"的最便宜一级（anytime 早退）；heavy 级即 v9 的 LSTM-MPC。再叠两条结构性减负：**证书化量化**（位宽选择受误差预算约束，而非拍脑袋）与**事件驱动稀疏更新**（无触发就保持输出，陈旧度计入账本）。轻量化因此不是"白拿"，而是从全局预算里**明码付费**的近似。

**两者的耦合点**：长程任务的误差预算正是轻量代理的"准入门槛"，轻量代理又为长程所需的重锚定腾出算力——预算-安全-算力形成闭环，而非三个独立补丁。

## 1. 研究问题（轮次升级版）

- **Q1（长程证书可组合性）**：在有界视界 STL 下，块级鲁棒度证书能否组合出紧致的任务级下界？跨块时序算子（Always/Eventually/Until）的边界如何处理才既不漏检也不过度保守？
- **Q2（误差预算与重锚定）**：状态误差在闭环中如何传播？重锚定能否把无界视界的误差增长截断为有界 episode，且重锚定代价可摊销？
- **Q3（轻量化的证书边界）**：conformal 误差包络在非平稳长程部署中何时失效？anytime 选级、量化与稀疏更新如何在不侵蚀安全预算的前提下把结构算力降一个量级？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 任务视界证书律（Mission-Horizon Certificate, MHC）**
任务 M=(G, ψ, H, E_budget)：G 为子目标 DAG，ψ 为**有界视界 STL**公式，H 为任务视界。块 k 的证书为 (ρ̂_k, β_k, E_k, κ_k)，其中 κ_k 为跨块时序算子的前瞻填充。块可采纳当且仅当组合花费后仍留 margin。任务鲁棒度下界 = min_k（局部下界），对 Always/Eventually 的组合是可靠的。

**P14 误差预算会计律（Error-Budget Accounting, EBL）**
记 E_{t+1} = λE_t + ε_step(t) + ε_quant + ε_stale（锚定后 E←ε_obs）。任一计算决策（选级、量化、跳算）都必须先"记支出"再到账本扣减；不许存在不记账的近似。账本超支即触发重锚定、降 K_eff 或升代理级，而非硬闯。

**P15 证书化轻量律（Certified-Lightweight, LSC）**
轻量代理仅在 ε_τ ≤ 剩余预算 B_t 且状态在有效域 V_τ 内时被采纳；无任何一级满足则升 heavy；heavy 仍不满足则 K_eff←1（等价 v9 逐步）。量化位宽与稀疏更新周期同为预算变量，不允许独立于证书调参。

## 3. 与基线的接口（如何退化）

- MHC 失效 ⇒ 不施加任务级约束，退回 v9 的逐块证书（定义 496/531），等价 v9；
- EBL 失效 ⇒ E_t≡0、E_budget≡∞、β 固定为 v9 标定值，逐块判定，等价 v9；
- LSC 失效 ⇒ 永远选 heavy 级（=v9 的 LSTM-MPC + 64 候选），等价 v9；
- 量化/稀疏更新失效 ⇒ 全精度、逐周期计算，等价 v9 的每周期路径；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 五级退化链注入中立元，退回 v8；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

## 4. 预期贡献

1. **任务视界证书**：把 STL 鲁棒度的 1-Lipschitz 性变成可组合的安全下界，使长程任务的安全论证从"逐块经验"升级为"最小下界 + 预算会计"；
2. **重锚定截断定理**：证明有界重锚定间隔足以把任意长视界的误差增长压成有界 episode，给出 T_anchor 的显式选取条件；
3. **证书化轻量化**：conformal 包络 + anytime 选级 + 证书化量化 + 事件驱动稀疏更新，把"轻量"从经验调参变成受约束的预算优化；
4. **预算-安全-算力三闭环**：E571–E590 覆盖长程组合、账本校准、重锚定扫描、级联覆盖率、稀疏陈旧度、量化证书、8h 漂移与端到端竞赛。

## 5. 本轮最大风险

**一句话**：conformal 包络与误差账本都建立在"校准分布与部署分布可交换/同分布"的假设上，而长程非平稳恰恰破坏可交换性——慢漂移期间最便宜的代理级会被选中，其真实误差却系统性越过包络，账本因锚点处观测不到已发生的物理漂移而低估 E_t，于是安全下界在最需要保守的时刻最乐观。

## 1. 符号体系增量（定义 540–551）

**新增定义 540（长程任务 LongHorizonTask）** 任务 M=(G, ψ, H, E_budget)：G 为子目标 DAG，每个 g∈G 带完成谓词与前置依赖；ψ 为**有界视界 STL**公式（所有时序算子带有限区间，禁止无界 Until）；H 为任务视界；E_budget 为任务级状态误差预算。任务完成 ⇔ ρ(ψ, w_{0:H}) > 0 且 G 中所有必需子目标被判定完成。

**新增定义 541（STL 鲁棒度 STL Robustness）** 原子谓词 μ: f(w)≥c 的鲁棒度 ρ_μ = f(w)−c；ρ(φ∧ψ)=min、ρ(¬φ)=−ρ(φ)、ρ(φ ∨ ψ)=max、ρ(□_{[a,b]}φ)=min_{t∈[a,b]}ρ_φ(t)、ρ(◇_{[a,b]}φ)=max_{t∈[a,b]}ρ_φ(t)。ρ_M = ρ(ψ, w_{0:H})。本定义仅用于**有界视界**片段，保证分块组合可判定（定义 543）。

**新增定义 542（状态误差传播与视界膨胀 PropagatedErrorBound）** 闭环模型一步误差 ≤ ε_step，状态误差递归 e_{k+1} ≤ λe_k + ε_step，故
```
e_K ≤ λ^K e_0 + ε_step · Γ_λ(K),
Γ_λ(K) = (1−λ^K)/(1−λ)  λ<1;   K  λ=1;   (λ^K−1)/(λ−1)  λ>1。
```
λ>1 时 Γ 指数发散：此时**禁止**在无重锚定的情况下跨视界外推，必须由定义 545 截断。

**新增定义 543（任务鲁棒度证书 MissionCertificate）** 块 k（长度 K）的证书为 (ρ̂_k, β_k, E_k, κ_k)。令 L_ρ 为 STL 鲁棒度对信号的最大 Lipschitz 常数（有界片段下 L_ρ=max_f L_f），L_s 为信号对状态的 Lipschitz 常数。块可采纳当且仅当：
```
ρ̂_k − L_ρ L_s (λ^K E_k + ε_step Γ_λ(K)) − β_k − κ_k ≥ margin_chunk。
```
κ_k 为跨块时序算子的前瞻填充：对 `□`/`◇` 窗口跨越块边界的部分，按算子区间宽度在某侧块内复算（padding），保证边界不漏检。

**新增定义 544（误差预算账本 ErrorBudgetLedger）** 账本按控制周期维护
```
E_{t+1} = clip( λ E_t + ε_step(t) + ε_quant + ε_stale , 0, E_budget )
```
其中 ε_quant = L_q·q，ε_stale = max_m ℓ_m·s_m（ℓ_m 为模块输出漂移率，s_m 为陈旧周期数）。定义两个子账户：epistemic E^e（可由重锚定压缩）与 aleatoric E^a（物理漂移下界，重锚定不可消除）。安全不变式要求 E^e+E^a ≤ E_budget。任何计算决策先记支出、再扣预算；超支即执行定义 545 或降级。

**新增定义 545（重锚定 Re-anchoring）** 触发条件（任一）：t mod T_anchor=0；E_t ≥ θ_anchor；块证书连续失效 r 次。动作：获取新观测/重定位/重标定，令 E_t ← ε_obs，并用最新残差**重标定代理级 conformal 包络**（定义 547）。重锚定代价 c_anchor 计入摊销账本；两次重锚定间隔下界 T_min，避免 Zeno（引理 92）。

**新增定义 546（进度信念 ProgressBelief）** 对子目标 g 维护 b_g∈[0,1] 与不确定度 u_g。观测似然更新 b_g；子目标完成当且仅当对应 STL 子公式鲁棒度符号稳定为正且 b_g≥1−δ。仅维护 DAG 的活跃前沿 frontier(G)⊆G，故内存 O(|frontier|)，与视界 H 无关。当 u_g>θ_prog 或符号翻转 ⇒ 触发重观测/重规划。

**新增定义 547（证书化轻量代理级联 LightweightSurrogateCascade）** 三级代理 τ∈{0,1,2}，各自 (c_τ, ε_τ, V_τ)。ε_τ 由 split conformal 在标定集上按覆盖率 1−α 给出；并按难度特征（速度、杂乱度、Δ_dom）分箱给出**条件包络** ε_τ(s)。V_τ 为包络有效的特征区域。heavy 级 τ=2 即 v9 的冻结 LSTM-MPC。级联对同一决策问题共享状态-动作接口，保证可替换。

**新增定义 548（anytime 证书约束选级 AdmissibleTier）** 给定剩余预算 B_t 与状态 s：
```
τ*(t) = argmin_{τ} c_τ  s.t.  s∈V_τ ∧ ε_τ(s) ≤ B_t。
```
若无 τ 满足 ⇒ 直接 heavy；heavy 仍不满足 ⇒ K_eff←1（等价 v9 逐步）。选择单调：预算收紧只会升不降级。

**新增定义 549（证书化量化 CertifiedQuantization）** 量化算子 Q 满足 ‖Q(x)−x‖≤q；指标误差增加 ≤ L_q·q 并计入 ε_quant。位宽 b 的选择受预算约束：
```
b* = min{ b : L_q·q(b) + 其余支出 ≤ B_t }，
```
而非固定位宽；仿真期用 q(b) 的经验上界标定。

**新增定义 550（事件驱动稀疏更新 EventDrivenRecompute）** 模块 m 仅在触发集
```
Trigger_m = { |Δobs|>θ_obs ∨ Δ_dom>τ_dom ∨ 证书将过期 ∨ t mod T_refresh(m)=0 }
```
成立时重算，否则保持上次输出。陈旧度 s_m ≤ T_refresh(m)，输出漂移 ≤ ℓ_m T_refresh(m) 计入 ε_stale。T_refresh(m) 由 ℓ_m T_refresh(m) ≤ ε_stale^max 反解，作为预算变量而非经验常数。

**新增定义 551（长程退化中立元 LongHorizonNeutral）** MHC⊥：不施加任务级约束（ρ_M 不参与判定），退回 v9 逐块证书；EBL⊥：E_t≡0、E_budget≡∞、β 固定为 v9 标定值；LSC⊥：永远 τ=2（heavy），全精度、逐周期计算。三个中立元在各自端口上为恒等作用，注入后系统输出与 v9 逐周期一致（引理 93）。

## 3. 关键算法骨架

```python
# IP-357 MissionHorizonCertifier：任务视界证书器
class MissionHorizonCertifier:
    def __init__(self, task, L_rho=1.0, L_s=1.0, margin_chunk=0.05):
        self.G, self.psi, self.H = task.G, task.psi, task.H
        self.L_rho, self.L_s, self.margin = L_rho, L_s, margin_chunk
        self.frontier = self.G.roots()

    def chunk_lower_bound(self, cert, K, E_k, lam, eps_step):
        spend = self.L_rho * self.L_s * (lam**K * E_k
                                        + eps_step * gamma(lam, K))
        return cert.rho_hat - spend - cert.beta - cert.kappa

    def compose_mission_bound(self, chunk_bounds):
        # 有界视界 STL：□/∧ 组合取 min；◇ 组合取 max of window bounds
        return compose_stl_lower_bound(self.psi, chunk_bounds)   # 定义 543

    def admissible(self, cert, K, E_k, lam, eps_step):
        return self.chunk_lower_bound(cert, K, E_k, lam, eps_step) >= self.margin

    def update_progress(self, obs, ctx):
        for g in list(self.frontier):
            self.belief[g].update(obs)
            if self.belief[g].done() and deps_done(g):
                self.frontier = self.frontier - {g} | self.G.children(g)
            elif self.belief[g].uncertainty() > self.theta_prog:
                return "reobserve"
        return "continue"


# IP-358 ErrorBudgetLedger：误差预算账本
class ErrorBudgetLedger:
    def __init__(self, lam, eps_step, budget, epsilon_obs):
        self.lam, self.eps_step, self.budget = lam, eps_step, budget
        self.E, self.eps_obs = epsilon_obs, epsilon_obs
        self.epistemic = 0.0

    def step(self, eps_quant=0.0, eps_stale=0.0):
        self.E = min(self.budget,
                     self.lam * self.E + self.eps_step + eps_quant + eps_stale)
        return self.E

    def remaining(self, margin):
        return max(0.0, margin - self.L_spend(self.E))

    def spend_ok(self, projected_spend, margin):
        return self.L_spend(self.E) + projected_spend <= margin

    def should_anchor(self, t, T_anchor, theta):
        return (t % T_anchor == 0) or (self.E >= theta) or self.consecutive_fail >= 3

    def anchor(self, eps_obs_new):
        self.E = eps_obs_new          # 观测不可消除的 aleatoric 下界
        self.eps_obs = eps_obs_new
        return self.E


# IP-359 LightweightSurrogateCascade：证书化轻量级联
class SurrogateCascade:
    def __init__(self, tiers, alpha=0.05):
        self.tiers = tiers            # {0:tiny, 1:medium, 2:heavy(v9)}
        self.alpha = alpha
        self.envelopes = {t: ConformalEnvelope(alpha) for t in tiers}

    def select_tier(self, state, B_t):
        for t in sorted(self.tiers, key=lambda t: self.tiers[t].cost):
            env = self.envelopes[t].query(state)     # 条件包络 ε_τ(s)
            if state.features in self.tiers[t].valid_region and env <= B_t:
                return t
        return 2                                     # heavy；仍不满足 → K=1

    def predict(self, state, actions, B_t):
        t = self.select_tier(state, B_t)
        if t == 2:
            return self.tiers[2].rollout(state, actions)   # = v9 LSTM-MPC
        return self.tiers[t].rollout(state, actions)

    def recalibrate(self, residuals, state_bins):
        for t in self.tiers:
            self.envelopes[t].update(residuals[t], state_bins)   # 重锚定时调用
```

## 4. 推导

**引理 87（STL 鲁棒度的 Lipschitz 性）** 对任意有界视界 STL 公式 φ 与两条信号 w₁、w₂，有 |ρ(φ,w₁)−ρ(φ,w₂)| ≤ L_ρ‖w₁−w₂‖∞，其中 L_ρ=max_f L_f，L_f 为原子谓词的 Lipschitz 常数（仿射谓词 L_f=1）。证明：对公式结构归纳。原子：|f(w₁)−f(w₂)| ≤ L_f‖·‖∞。min/max 均为 1-Lipschitz，且 1-Lipschitz 函数在 min/max 复合下常数相乘：若 g,h 分别 L_g、L_h-Lipschitz，则 |min(g,h)(x)−min(g,h)(y)| ≤ max(L_g,L_h)|x−y|；否定保号。时间算子不改变 sup 范数。时域有界保证 min/max 作用于紧集，取到极值。∎

**引理 88（视界膨胀与重锚定截断）** 在定义 542 下 e_K ≤ λ^K E_k + ε_step Γ_λ(K)。若每 T_anchor 周期重锚定且 E←ε_obs，则对任意视界 H，sup_{t≤H} E_t ≤ max( θ_anchor, λ^{T_anchor}θ_anchor + ε_step Γ_λ(T_anchor), ε_obs ) =: E*，与 H 无关。证明：两条重锚定之间的误差由递归展开给出；由触发条件 E≥θ_anchor 或周期到达，段长 ≤T_anchor；段末误差 ≤λ^{T_anchor}θ_anchor+ε_stepΓ(T_anchor)；锚定后重置为 ε_obs。取三者上界即 E*，归纳于段数得与 H 无关。∎

**引理 89（任务证书组合下界）** 若 ψ 为有界视界 STL，每块按定义 543 可采纳且 κ 填充覆盖跨块算子区间，则真实任务鲁棒度满足
```
ρ_M(w_true) ≥ compose_stl_lower_bound(ψ, {ρ̂_k − spend_k − β_k − κ_k}_k) ≥ margin。
```
证明：由引理 87、88，块 k 内信号 sup 误差 ≤ spend_k（含 λ^K E_k 与 ε_step Γ）；故真实块内鲁棒度 ≥ 局部下界。`□`/`∧` 在整段上取 min，故全局下界 = 各块局部下界之 min（边界由 κ 补算）；`◇` 在全段取 max，而 max 在全段的取值 ≥ 任一子窗口下界，故各窗口下界仍为全局下界；有界 Until 按区间宽度 κ 填充后同理。取组合值即得。∎

**引理 90（账本不超支 ⇒ 安全不变式）** 若每个采纳的块满足 spend_k + 历史支出 ≤ margin，且 E^e+E^a ≤ E_budget，则任务执行期间不违反 M₀ 硬约束与 ψ 的安全子式。证明：由引理 89，块可采纳性直接推出 ρ_M^LB≥margin>0；账本单调性（锚定仅把 E 重置到 ε_obs≤E，不增加）保证超支不会在两次锚定间被掩盖；超支触发定义 545 或降 K/升 heavy，从而任何继续执行的块仍满足预算约束。∎

**引理 91（anytime 级联的证书保持）** 若代理级 τ 的误差满足 ε_τ(s) ≤ B_t 且 s∈V_τ，则使用 τ 生成/复核的块仍满足定义 543；若 split conformal 的标定样本与部署可交换，则 P(真实误差 ≤ ε_τ) ≥ 1−α。选择单调：B_t 减小只会使可采纳集合缩小（选级只升不降）。证明：定义 548 的约束正是定义 543 的预算项；conformal 覆盖由秩统计量给出有限样本保证；单调性由约束集合的包含关系直接得。∎

**引理 92（稀疏更新陈旧度安全与重锚定无 Zeno）** 若 T_refresh(m) 满足 ℓ_m T_refresh(m) ≤ ε_stale^max 且 ε_stale 计入账本，则保持陈旧输出不破坏块证书；触发集保证 s_m≤T_refresh(m)。又 T_anchor≥T_min 且事件触发需连续 r 次证书失效，故单位时间重锚定次数 ≤ 1/T_min + r 次失效事件，有限时间内有限，无 Zeno。证明：陈旧误差上界由 Lipschitz 漂移率给出，代入定义 544 即被预算吸收；间隔下界由调度器强制，计数有界。∎

**引理 93（长程退化与 v9 逐周期等价）** 注入 MHC⊥/EBL⊥/LSC⊥ 后：LSC⊥ ⇒ 恒选 heavy τ=2，即 v9 的冻结 LSTM-MPC 与 64 候选；EBL⊥ ⇒ E≡0、E_budget≡∞、β=v9 固定值，定义 543 退化为 v9 定义 533 的块证书；MHC⊥ ⇒ 不施加任务约束，判定退化为 v9 定义 496/531。三者在其端口上为恒等作用，v9 的 MW/AC/ID 路径不变，故对每个控制周期输出与 v9 一致（逐位等价审计见 E584）。∎

## 8. 本轮最大风险

**一句话**：conformal 包络与误差账本都建立在"校准分布与部署分布可交换/同分布"的假设上，而长程非平稳恰恰破坏可交换性——慢漂移期间最便宜的代理级会被选中，其真实误差却系统性越过包络，账本因锚点处观测不到已发生的物理漂移而低估 E_t，于是安全下界在最需要保守的时刻最乐观。
