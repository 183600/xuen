# 第 72 轮（承接第 71 轮「FLEET-RAS」IP-275~288；灵感循环新循环第 2 轮；本轮灵感：「具身智能大模型」×「UniBot世界挑战赛」）

> R71（FLEET-RAS）把不确定性推到空间与机队，但它仍默认两件事：**（a）执行动作的策略本身是一个能力边界大体已知、可被安全认证器约束的模块；（b）用来证明「这策略行」的评估是诚实的、非对抗的**。具身智能大模型（VLA）出现后，这两个默认同时破裂：执行者变成一个能力极广、边界未知、不可形式验证、会「物理幻觉」的黑箱；UniBot 世界挑战赛又让评估本身变成一场竞赛——被测者与出题者、与其他参赛者是对抗关系，排行榜优化的不是部署可靠性，而是榜单名次。
>
> 于是出现 R71 无法回答的新问题：**当执行者是一个能力边界未知、不可验证、且被排行榜激励扭曲的通用大模型时，我们凭什么相信它能做这件事？如果它不能，我们能不能在它动手之前就知道，并优雅地放弃？**
>
> 本轮两个灵感正好补上两块缺失：
> - **具身智能大模型**把 epistemic 从「世界是什么」推进到「**我自己能不能做到**」：需要能力后验、能力包络、物理幻觉门与弃权；
> - **UniBot 世界挑战赛**把「评估」本身变成一个需要被审计的对象：榜单不等于证书，公开分布不等于部署分布，污染与 Goodhart 过拟合必须被显式度量。
>
> 核心命题：**把 ARENA-RAS 建在「非委托 + 能力自知 + 评估诚实」三根柱子上：大模型只提议、认证技能才执行（安全与模型能力解耦）；用校准的能力后验 q(c) 与共形能力包络判断「它能不能」，不足即弃权/移交；用基准保真度 D_eval、污染检测与 Goodhart 指数把「榜单项」降级为「待验证假设」。安全侧永不比 R71 弱。** 命名 **ARENA-RAS**（Adversarial-Regulated Epistemic Non-delegation Assurance for Risk-Aware Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我相信哪个世界状态」，R71 问「去哪里取证、信多少别车」，R72 问「**执行者自己到底会不会，且它的成绩单可不可信**」——前几轮把「世界的不确定」和「他者的不确定」一层层剥开，这一轮第一次把刀口对准「我自己的能力」和「证明我能力的标准」。

## 0. 直觉与动机

**灵感 1（具身大模型 → 能力是一种与 b_t 正交的新不确定性）**
直觉：R70/R71 的 b_t 描述「世界可能是什么」，但 VLA 的黑箱失效常常与世界的真实状态无关——世界很清楚，是「我不知道怎么处理」。同一块桌面，抓杯子它很熟，抓一个没见过的透明软袋就可能把水打翻；同样的门，推过一百次，换成人形构型它仍可能找错把手。于是必须有一个独立的「自我模型」：在当前上下文 c（任务、指令、物体、机器人构型、观测特征）下，我成功率多少、我是否在训练分布内。这个后验不能由世界后验推出（多状态同模态、同世界不同能力的反例很多），必须单独校准。**epistemic 因此第一次分裂成「关于世界的」与「关于我的」两个正交轴。**

**灵感 2（具身大模型 → 幻觉从语言变成物理）**
直觉：文本幻觉说错话；具身幻觉会「看到不存在的把手」「相信抽屉没锁」「规划一条穿过玻璃的路径」，而且说得非常自信、非常连贯。更危险的是，它可能把语言先验凌驾于感知之上：因为「杯子通常有把手」，就无视眼前这个没有把手。因此每条技能执行前必须做**前置条件接地**：把语言/视觉断言与 R70 信念、R68 标定、独立传感器三源交叉验证；接不上就弃权，而不是「先做了再说」。**在具身系统里，幻觉不是输出错误，而是信念对感知的越权。**

**灵感 3（UniBot 世界挑战赛 → 榜单不是证书）**
直觉：比赛只测它测的那部分；更糟的是，参赛者会针对榜单优化。一个模型可以在挑战赛上拿第一，因为（a）见过类似任务（污染），（b）过拟合了评测器或场景生成器，（c）在公开分布上很强但部署分布不同。**排行榜度量的是「在考纲内的名次」，不是「在你家厨房里的可靠性」。** 于是需要一个评估诚实层：基准–部署分布距离、污染检测、公开/私有榜差（Goodhart 指数）、轮换隐藏任务。把「榜第一」写进部署准入，等同于把「模拟考满分」当成「能主刀手术」。

**灵感 4（世界挑战赛 → 对手就是最好的红队，但红队也会过拟合）**
直觉：竞赛生态天然产生大量「专门打败当前模型」的策略。把它们当作红队课程，可以高效估计能力边界（在哪些任务上必然失败）。但红队也会过拟合：如果只用公开对手训练/评估，能力边界会退化成「对这批对手的边界」。所以红队课程必须与隐藏轮换集分离，能力声明只在合并分布（公开×隐藏）上有效。**红队是探针，不是驾照。**

**灵感 5（非委托 → 安全必须对大模型的能力「免疫」）**
直觉：既然无法形式验证 VLA，最稳的办法是不让它的输出直接变成电机指令。它输出的是**技能名/参数/计划**，由一组有证书的技能契约执行；技能契约有前置条件、后置条件、控制器与安全包络。大模型可以荒谬、被越狱、被投毒，但它能造成的物理风险上界只由技能库的最大证书风险决定。这叫「安全非委托」：**安全权永远不交给模型**。能力提升只扩大「能成功完成的任务集」，不自动扩大「被允许的物理包络」——后者的扩张只能靠离线认证。

**灵感 6（弃权是一等动作，不是失败）**
直觉：R69 的交互是「世界不明 → 去问」；R72 的弃权是「能力不明 → 不接」。弃权可以表现为：请求人类示范、切换到保守认证技能、安全停止、拒绝指令。把弃权与执行放进同一个期望损失比较，就能得到明确的阈值。**会弃权的通用模型，比永不弃权的通用模型更可用**，因为它把灾难性失败换成了可恢复的移交。拒绝不是能力缺陷的暴露，而是校准良好的证据。

## 1. 形式化定义（增量：定义 347–362）

**定义 347（ARENA-RAS 总览）** ARENA-RAS = (ELM†, CMP, CAP, SCB, NDG, ABST, GGH, BFA, CDG, GHX, RCHA, VQAuditor-IV, AIC-ARENA, J_ARENA)。四不变式：
(i) **实时流零学习写操作**（继承 R71 定义 331-i）；
(ii) **安全非委托**：ELM 只产生「提议」（技能引用/参数/计划），任何物理动作必须由带证书的技能契约执行；ELM 不得写安全头、不得绕过前置条件、不得直接下发力矩；
(iii) **能力自知与弃权**：当能力后验低于阈值、或 OOD/物理幻觉被触发时，必须弃权/移交，禁止「抱着希望执行」；
(iv) **评估诚实**：基准分数只是假设，任何能力声明必须通过分布保真、污染检测与私有轮换验证，否则不得进入部署信任。

**定义 348（具身大模型策略 ELM）** 将 ELM 视为冻结黑箱 F_ELM：输入 (o_t, ℓ)，输出技能序列或动作块 plan = (σ_1,…,σ_n)，σ_j 可为技能 token、技能参数或连续动作块。无梯度回传；语言指令 ℓ 与问句沿用 R69 的冻结 LLM 接口，符号接地与安全过滤在解码侧。**关键边界**：ELM 的输出是「意图」，不是「执行」。

**定义 349（能力后验 CMP）** 上下文 c = (ℓ, task_type, object/scene descriptor, robot_config, o_t 的分布特征)。能力后验
`q(c) = P(success within spec | c, D)`，
经可靠图/温度/等张回归校准；并由分裂共形给出集合 Ĉ_α(c)，使 `P(success ∈ Ĉ_α(c)) ≥ 1−α`（可交换性下）。**q 与 b_t 正交**：b_t 是「世界是什么」，q 是「我能否在这个世界上做到」。两者可同时很高或很低，不能互相替代。

**定义 350（能力包络 CAP）** `C_ε = { c : q_lower(c) ≥ 1−ε }`，即「可承诺区」。按 R71 的 SEF 建索引：`C_ε(x)` 为地点/任务/物体组合上的能力区域；移动或联邦可把能力证据带到新地点（覆盖信任仍按 R71 定义 337 落地，自报不计）。包络外的上下文一律弃权，或先做 R69 式试探（看/问/触）后再判定。

**定义 351（元不确定性三分解）** 把决策相关不确定性拆成互不混算的三源：
`U_world = H[b_t]`（世界，R70）；`U_comp = h(q(c)) = −q log q − (1−q)log(1−q)`（能力，自我）；`U_eval = D_eval`（评估可信度/分布差）。
三者语义不同、消解手段不同：U_world 用看/问/触消解，U_comp 用练习/示范/弃权消解，U_eval 用审计/私有评测/污染检测消解；**不存在一个标量把它们简单相加**（加和会掩盖「世界清楚但我不会」与「世界模糊但我很熟」的差别）。

**定义 352（技能契约 SCB）** 技能 σ = (pre, post, controller, J_σ, env_σ)：前置条件 pre（可被 b_t 与独立感知验证的谓词集）、后置条件 post、认证控制器 controller、证书 J_σ（含风险上界 ε_σ 与作用包络 env_σ）。技能库 Σ = {σ}。ELM 只能引用 Σ 中的 σ，或要求新增技能；**新增技能必须离线认证，不得在实时环里即兴生成并执行**。

**定义 353（计划编译与投影）** 把 plan 编译为 Σ 上的技能序列。若 plan 含未认证技能，投影到最近认证技能 σ'，投影距离 `d_proj = dist(plan, σ')`。`d_proj > τ_proj` ⇒ 判定「ELM 想做一件不可认证的事」，拒绝并弃权。**投影距离是可测的「越界意图」信号**：它把「安全拒绝」从二进制变成可审计的连续量。

**定义 354（物理幻觉门 GGH）** 对每个技能前置条件 p_i，用三源交叉验证：信念 b_t、标定后感知、独立传感器通道；得分 `g_i = min(sources)`。若任一 `g_i < τ_pre`，技能不可执行（幻觉/断言不接地）。GGH 与 R69 的跨模态对偶同构，但对象是「ELM 的断言」而非「世界状态」：**先验证它说的是不是真的，再讨论它想做的对不对。**

**定义 355（弃权与移交控制器 ABST）** 元动作 `𝒜_meta = {execute, ask_human, request_demo, switch_certified, safe_stop, refuse}`。按期望损失选择：
`L_exec = q·L_s + (1−q)·L_f`（L_s 成功损失，L_f 失败损失，L_f ≫ L_s）；
`L_abs` 为弃权/移交损失（由认证兜底、人类接管或安全停止给出，通常 `L_s ≤ L_abs < L_f`）。
选择 argmin ⇒ **执行当且仅当 `q ≥ q* = (L_f − L_abs)/(L_f − L_s)`**，否则弃权/移交。

**定义 356（基准保真度 BFA）** 设部署分布 P_dep、基准 P_bench，散度 `D_eval`（TV/JS 的可测估计）。传递证书要求 `D_eval ≤ τ_eval` 且污染可分；否则基准结论只对 P_bench 有效，**不对部署作任何承诺**。

**定义 357（污染检测与 Goodhart 指数）** CDG：近邻检索、损失异常、复述/扰动不变性检测训练–评测重叠，输出污染比例 `m̂`。GHX：`G = S_public − S_private`（公开榜与隐藏私有榜之差的滑动估计），并监控「优化压力↑ ⇒ G↑」；`G > τ_ghx` 判定榜单过拟合，能力声明按 `m̂` 与 G 打折。

**定义 358（红队共演化 RCHA）** 用对抗课程生成「专门击穿 ELM」的任务族；每轮把新对手分入公开集/隐藏集；能力边界只在合并（公开×隐藏）分布上估计，隐藏集轮换防止对红队过拟合。红队收益与过拟合风险同时记账，形成「探针收益 / 泛化损失」曲线。

**定义 359（非委托门 NDG 与风险缩放）** 执行提议必须同时通过：(a) 计划可编译为认证技能；(b) 每个前置条件过 GGH；(c) `q ≥ q*`（或 c ∈ C_ε）；(d) 该上下文评估诚实（D_eval 与污染达标）；(e) 预算未越界。否则降级为弃权/认证兜底。风险缩放
`λ = max(λ_task, λ_floor(U_world + β·U_comp + γ·U_eval))`；
只有 (a)–(e) 全部通过才获得 resolution bonus（把 U_comp、U_eval 从保守项移除）。β、γ 只增不减，除非有独立实证。

**定义 360（评估参与纪律 / UniBot 参赛协议）** 比赛成绩写入证书时必须携带：私有集版本、污染报告、GHX、能力包络覆盖、失败任务清单。**禁止把「公开榜名次」直接作为部署准入**；只有「通过传递证书的能力子集」可进入部署信任。这是 R71 定义 343 证据纪律在评估维度的延伸：单次比赛成绩不得单独定案。

**定义 361（AIC-ARENA 威胁模型）** `ℰ_ARENA = ℰ_FLEET × ℰ_halluc × ℰ_ground × ℰ_bench × ℰ_deleg × ℰ_emerge × ℰ_redteam`：物理幻觉、断言不接地、基准过拟合/污染/分布差、安全委托漂移/越狱、未验证的涌现能力、红队过拟合、以及继承自 R71 的联邦/移动/拜占庭/隐私风险。每类须映射到可测门控。

**定义 362（J_ARENA 证书）** `J_ARENA = (J_FLEET, competence_ECE, conformal_coverage, C_ε_hash, D_eval, contamination_report, GHX, abstention_log, skill_contract_hashes, non_delegation_attest, redteam_report, arena_ver)`。Valid ⇔ Valid(J_FLEET) ∧ 能力校准达标 ∧ 包络覆盖达标 ∧ 评估诚实达标 ∧ 非委托审计通过 ∧ 弃权链完整。

```python
# IP-289 CMP：校准能力后验 + 共形能力集 + OOD
class CompetenceModel:
    def __init__(self, feat, calib, ood, conf):
        self.feat, self.calib, self.ood, self.conf = feat, calib, ood, conf

    def posterior(self, c):
        z = self.feat(c)
        q = self.calib(z)                 # 校准成功率
        o = self.ood.score(z)             # OOD / 训练分布外分数
        S = self.conf.set(z)              # 分裂共形集，覆盖 >= 1-alpha
        return q, o, S

# IP-290 CAP：能力包络（可承诺区）
def in_envelope(c, cmp, eps):
    q, o, S = cmp.posterior(c)
    return (cmp.lower(q) >= 1.0 - eps) and (o <= TAU_OOD)

# IP-291 SCB：把 ELM 计划编译/投影到认证技能库
def compile_plan(plan, skill_lib, tau_proj):
    seq, worst = [], 0.0
    for name, params in plan.skills:
        if name in skill_lib:
            seq.append(skill_lib[name])
        else:
            sig, d = nearest_skill(name, params, skill_lib)
            worst = max(worst, d)
            if d > tau_proj:
                return None, d          # 越界意图：拒绝
            seq.append(sig)
    return seq, worst

# IP-294 GGH：物理幻觉门（ELM 断言须被三源接地）
def grounded(skill, b_t, percept, indep, tau_pre):
    return all(min(score(p, b_t), score(p, percept), score(p, indep)) >= tau_pre
               for p in skill.pre)

# IP-292/359 NDG：非委托门（安全不交给模型）
def non_delegation_gate(plan, c, b_t, percept, indep, eval_ok, budget):
    seq, d = compile_plan(plan, SKILLS, TAU_PROJ)
    if seq is None:                          return Decision("refuse", d)
    q, ood, S = CMP.posterior(c)
    if ood > TAU_OOD:                        return Decision("abstain", q)
    if not eval_ok:                          return Decision("downgrade", q)  # 只走认证兜底
    for sig in seq:
        if not grounded(sig, b_t, percept, indep, TAU_PRE):
            return Decision("abstain", q)    # 幻觉 / 不接地
    if q < q_star():                         return Decision("abstain", q)    # 能力不足
    if not budget.allow(seq):                return Decision("abstain", q)
    return Decision("execute", q, seq)       # 只有认证技能序列能落地

# IP-293 ABST：期望损失意义下的弃权/移交
def choose_meta_action(dec, fallback):
    L_exec = dec.q * dec.L_s + (1.0 - dec.q) * dec.L_f
    L_abs  = fallback.bounded_loss()         # 认证兜底 / 人类接管 / 安全停止
    if dec.kind == "execute" and L_exec < L_abs:
        return ("execute", dec.sequence)
    return ("handoff", fallback.route())     # 问人/要示范/降级/停止/拒绝

# IP-274 ARENA 主闭环：ELM 低频提议，认证技能高频执行
def ARENA_RAS_round(M, obs, instruction):
    b_t = M.bse.step(M.b_prev, obs, M.last_action, M.last_g, M.last_y)
    E   = M.sef.update(b_t, M.fleet.belief, M.attest)
    c   = M.ctx(obs, instruction)
    q, ood, S = M.cmp.posterior(c)

    # 评估诚实：榜单项不能直接变成部署信任
    D_eval  = M.bfa.dist_to_deployment(c)
    contam  = M.cdg.contamination(c)
    honest  = (D_eval <= TAU_EVAL) and (contam.m_hat <= TAU_M)
    ghx     = M.ghx.index(c)                  # public - private
    eval_ok = honest and (ghx <= TAU_GHX)

    # ELM 只提议（可异步/低频，不在实时环）
    plan = M.elm.propose(obs, instruction) if M.elm.available() else None
    if plan is None:
        dec = Decision("abstain", q)
    else:
        dec = M.ndg.decide(plan, c, b_t, M.percept, M.indep, eval_ok, M.budget)

    kind, payload = M.abst.choose(dec, M.fallback)
    U_world = M.aud.world_entropy(b_t)
    if kind == "execute":
        seq = payload
        U_comp = 0.0 if eval_ok else M.aud.comp_entropy(q)
        U_eval = 0.0 if honest else D_eval
        lam = max(M.efs.risk_scale(...),
                  lam_floor(U_world + BETA * U_comp + GAMMA * U_eval))
        for sig in seq:                       # 逐技能、逐前缀认证后执行
            k = M.c_ras_wm.certified_prefix(sig, b_t, ..., wm_preds)
            execute_prefix(sig.controller, k)
    else:
        U_comp, U_eval = M.aud.comp_entropy(q), D_eval
        lam = max(M.efs.risk_scale(...),
                  lam_floor(U_world + BETA * U_comp + GAMMA * U_eval))
        M.abst.execute_handoff(payload)       # 认证兜底/人类接管/安全停止
    M.audit.submit_async(c, q, ood, dec, eval_ok, ghx, lam, U_comp, U_eval)
    M.fleet.stage_dp_update(M.ftm.local_update())
    return kind, lam, (q, U_comp, U_eval)
```

## 3. 推导

**引理 27（弃权的期望损失阈值与风险单调）** 设成功损失 L_s、失败损失 L_f、弃权/兜底损失 L_abs，且 `L_s ≤ L_abs < L_f`，q 为校准成功率。则执行与弃权的期望损失比较给出阈值
`q* = (L_f − L_abs)/(L_f − L_s)`，
执行当且仅当 `q ≥ q*`。最优规则的风险关于 q 单调不增；弃权把「高方差、可能灾难」的执行分支替换为有界兜底分支。系：**弃权不是保守主义的退让，而是当前信息下的最优动作**；q 越低，弃权收益越大。

**引理 28（非委托安全：模型无关上界）** 若每个被执行的动作都是技能库 Σ 中带证书技能的序列，且每技能风险 ≤ ε_σ，GGH 前置接地假阴率 ≤ δ_g，实时执行误差 ≤ ε_rt，则对**任意** ELM 输出（含幻觉、越狱、投毒、对抗样本），实际风险满足
`Risk ≤ max_σ ε_σ + L_δ·δ_g + ε_rt`。
ELM 的能力/意图只影响「选择哪些认证任务、任务成功率」，**不改变安全包络**。系：提升 ELM 能力只能提高包络内的成功率，不能自行扩张包络；包络扩张只能走离线认证。这是本轮的核心遏制定理。

**引理 29（基准–部署传递差与污染放大）** 设风险泛函 L-Lipschitz，则
`|R_dep(π) − R_bench(π)| ≤ L·√(D_eval/2) + m̂·Δ_mem`，
其中 Δ_mem 为记忆带来的乐观偏差。故榜单分数只有在 `D_eval → 0` 且 `m̂ → 0` 时才是部署性能的上界；否则可任意乐观。系：`G = S_public − S_private` 是这种乐观偏差的可测代理；G 显著非零即意味着「能力声明不可传递」。

**引理 30（共形能力覆盖与分布漂移失效）** 在可交换性下，分裂共形给出 `P(success ∈ Ĉ_α) ≥ 1−α`，因此弃权策略的漏判率 ≤ α + ε_est。协变量漂移下覆盖率至多下降 `ε_shift`（可由密度比加权共形在密度比可估时恢复）；**若 OOD 不可检测，则 q 恰恰在模型最危险的地方「自信地错」**。系：能力包络以可交换性为条件，OOD 检测是包络的守卫，不是可选附加项。

**定理 23（ARENA 严格包含 FLEET 严格包含 R70）** 在 A106–A109 下——A106 技能库完备且证书可靠、A107 GGH 接地低假阴、A108 能力后验在部署分布上校准或 OOD 门有效、A109 评估诚实门有效——ARENA 的期望风险 ≤ FLEET ≤ R70；且当 ELM 不可用、`q<q*`、OOD 触发、GGH 失败、评估不诚实或全部提议可认证且高置信时，ARENA 与 FLEET **逐指令相同**。安全侧不因大模型能力或榜单成绩让步；resolution bonus 只在能力与评估同时被验证时发放。

**定理 24（排行榜 Goodhart 的可检测性）** 在只对公开分施加优化压力时，若私有分不同步提升，则 `G = S_pub − S_priv` 随优化步数单调增大直至容量饱和；采用隐藏集轮换可保持私有估计无偏，因此持续非零的 G 是基准过拟合的一致检测器。系：**公开榜单不能认证部署**，只有传递证书能；把「榜第一」当准入，等价于用被优化的尺子量自己。

```python
def ARENA_RAS_round(M, obs, instruction):
    b_t = M.bse.step(M.b_prev, obs, M.last_action, M.last_g, M.last_y)
    E   = M.sef.update(b_t, M.fleet.belief, M.attest)
    c   = M.ctx(obs, instruction)
    q, ood, S = M.cmp.posterior(c)

    # 评估诚实门：榜单项 ≠ 部署证书
    D_eval = M.bfa.dist_to_deployment(c)
    m_hat  = M.cdg.contamination(c).m_hat
    honest = (D_eval <= TAU_EVAL) and (m_hat <= TAU_M)
    ghx    = M.ghx.index(c)
    eval_ok = honest and (ghx <= TAU_GHX)

    plan = M.elm.propose(obs, instruction) if M.elm.available() else None
    dec = (M.ndg.decide(plan, c, b_t, M.percept, M.indep, eval_ok, M.budget)
           if plan is not None else Decision("abstain", q))
    kind, payload = M.abst.choose(dec, M.fallback)

    U_world = M.aud.world_entropy(b_t)
    if kind == "execute":
        U_comp = 0.0 if eval_ok else M.aud.comp_entropy(q)
        U_eval = 0.0 if honest else D_eval
        lam = max(M.efs.risk_scale(...),
                  lam_floor(U_world + BETA * U_comp + GAMMA * U_eval))
        for sig in payload:                        # 逐技能逐前缀认证执行
            k = M.c_ras_wm.certified_prefix(sig, b_t, ..., wm_preds)
            execute_prefix(sig.controller, k)
    else:
        U_comp, U_eval = M.aud.comp_entropy(q), D_eval
        lam = max(M.efs.risk_scale(...),
                  lam_floor(U_world + BETA * U_comp + GAMMA * U_eval))
        M.abst.execute_handoff(payload)            # 认证兜底/人类接管/安全停止

    M.audit.submit_async(c, q, ood, dec, eval_ok, ghx, lam, U_comp, U_eval)
    M.fleet.stage_dp_update(M.ftm.local_update())  # 安全边界上传，实时环不等待
    return kind, lam, (q, U_comp, U_eval)
```

## 5. 推导（结论与用途）

**引理 27（弃权阈值）** 在 `L_s ≤ L_abs < L_f` 下，执行 iff `q ≥ q*=(L_f−L_abs)/(L_f−L_s)`；最优规则风险关于 q 单调不增。用途：弃权不需要人为拍阈值，q* 由损失结构给出，可随任务族重新推导。

**引理 28（非委托模型无关上界）** 任意 ELM 输出下 `Risk ≤ max_σ ε_σ + L_δ δ_g + ε_rt`；ELM 能力只改变包络内成功率，不改变安全包络。用途：这是「大模型可以随便坏、系统物理上仍安全」的正式依据，也是 NDG 存在的理由。

**引理 29（基准–部署传递差）** `|R_dep−R_bench| ≤ L√(D_eval/2)+m̂Δ_mem`；`D_eval→0` 且 `m̂→0` 时榜单才是部署上界。用途：BFA/CDG/GHX 三者共同构成「榜单→部署」的传递证书，缺一不可。

**引理 30（共形覆盖与漂移失效）** 可交换性下覆盖 ≥1−α；协变量漂移下至多降 `ε_shift`，OOD 不可检测时 q 会在最危险处自信地错。用途：能力包络以可交换性为条件，OOD 门是包络的守卫，不是可选件。

**定理 23（ARENA ⊃ FLEET ⊃ R70）** A106–A109 下期望风险层层不升；在 ELM 不可用/`q<q*`/OOD/GGH 失败/评估不诚实等边界逐指令等价于 FLEET。用途：ARENA 可作为 R71 的**可选增强**上线，任何能力/榜单收益都不能削弱安全侧。

**定理 24（Goodhart 可检测）** 只在公开分上施压时，若私有分不同步提升，则 G 随优化步数单调增大（直至容量饱和）；隐藏集轮换保持私有估计无偏，持续非零 G 是基准过拟合的一致检测器。用途：把「榜第一」降级为待验证假设，为参赛协议提供可执行判据。

## 10. 本轮最大风险

**一句话**：ARENA-RAS 的最大风险是**「能力自评 × 榜单独白」的双重幻觉**——非委托层能保证「大模型无论怎么坏，物理动作都不越证书包络」，但它保证不了「这个任务本来就不该由它接」；一旦能力后验在部署分布上失校准、或评测被污染/Goodhart 过拟合，系统就会在「q 很高、榜单第一、接地通过」的三重自信下，把从未被任何证据覆盖的情境当作可承诺区，并亲手把一次本可移交的任务变成一次被认证背书的失败；**安全的边界可以由证书保证，但能力的边界只能由诚实且未被优化的证据保证——把成绩单当能力，就是本轮最危险的错误。**
