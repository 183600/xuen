# 第 75 轮（承接第 74 轮「SENTGAUGE-RAS 契约异常哨兵 × 物体证据计量 × 约定计量适应 × 门控组合代数」IP-303~309；本轮灵感：「专利布局」×「运动控制」）

> R74 用 anytime-valid 哨兵把「自信地组合一个错误世界」改造为「诚实地发现并退出错误世界」。但 R74 留下两个**未被认证的退出前提**：
> - **退出动作本身没有控制证书**：哨兵可以把证据流 stub 化、把门控从 GREEN/YELLOW 推到 RED，但「退出之后控制器做什么、切换瞬间闭环是否稳定、执行器饱和/接触冲击/能量注入是否有界」仍落在 R72 的 `certified_prefix` 与一个标量 λ 里。λ 只是把风险数字调大，不是控制证书——证据突变会让状态估计跳变（控制器看到的 plant 变了），阻抗/接触模式切换可能在切换瞬间注入能量，1kHz 控制域没有任何对应混合模式的 Lyapunov/ISS 证书。R74 的「安全退化」在证据侧成立，在执行侧只是希望。
> - **主张没有作用域（scope）**：CPB 把 C1–C4 绑到基准与消融，却没有把主张绑到**使用范围**。一条主张被写成全局真，实际只在有效域 D、校准集 SEAL 与一组假设内成立；模块组合时会「借用」超出作用域的主张，热替换时会把旧 scope 的证书带到新本体上。专利法把这种缺陷叫**权利要求缺乏支持 / 不能被实施（lack of enablement）**。没有 scope，J_SENT 无法区分「认证了部署区域」与「认证了某个被访问子集」。
>
> 本轮两个灵感正好补这两块，而且它们共享同一个词——**范围**：
> - **运动控制** → **作用域即控制包络**。主张不是一句话，而是（控制器，控制不变集，ISS/Lyapunov 证书）三件套；哨兵/接触/证据可用性构成混合自动机，模式切换需要**驻留时间 + 多 Lyapunov + 能量槽**证书；规划器停留在**退化感知鲁棒生存核**中，使任何哨兵触发的切换在发生之前就是安全的；证据不确定度经 ISS 增益变成跟踪误差与约束余量，而不是一个拍脑袋的 λ。
> - **专利布局** → **主张组合代数与权利要求图**。主张对象化成（作用域，优先序，实施证据，依赖，自由实施）；作用域**只可交不可并**（no-broadening），扩宽必须新版本 + 新证据 + 再认证；重叠主张形成「认证丛林」，一律按合取义务处理，冲突即未认证；论文主张 C1–C6 用专利式 claim chart 映射 prior art、enablement 与 scope，杜绝孤悬组件与范围蔓延。
>
> 核心命题：**不再只问「证据是否在契约内」，而问「每条安全主张被哪个控制器在哪个作用域内实施，作用域的交、并、切换与组合是否仍被同一张证书覆盖？」** 把 SENTGAUGE 重构为 **CLAMP-RAS**（CLaim-scoped, Lyapunov-certified Adaptive Motion with Metrological Proof portfolio for RAS）——**作用域感知的控制证书 × 权利要求的证明组合**。

## 0. 直觉与动机

### 灵感 1（运动控制 → 安全退化是一个切换系统问题，不是一个 λ 问题）

直觉：把 R74 想成一家会「及时关门」的工厂。哨兵是门卫，检测到异常就关门（stub）。但门关上之后，里面高速运转的机器（闭环控制器）不会因为门关了而自动安全：它可能因为突然失去视觉而状态估计跳变，可能因为从阻抗模式切到位置保持而把储存的弹性能量瞬间释放，可能因为执行器饱和进入极限环。**「退出」本身是一个控制动作，必须被认证。** 标量 λ 相当于「把机器转速调低一点」，它不是稳定性证明，也无法保证切换瞬间的约束满足。

严谨化：机器人是一个混合系统 H = (Q, X, U, f, Init, Dom, E, G, R)，模式 q ∈ Q 由（哨兵三态 × 接触模式 × 证据可用性）给出。安全退化要求：
1. 每个模式 q 内有一个控制不变集 K_q 与 Lyapunov/ISS 函数 V_q；
2. 每次切换 q→q′ 满足跳变不等式 V_{q′}(x⁺) ≤ μ_{q→q′} V_q(x⁻) + κ，且驻留时间足够长（平均驻留时间框架）；
3. 接触/阻抗切换满足能量槽非负（passivity budget），不允许自由注入能量；
4. 切换后的状态经过 reset map 后仍落在 K_{q′} 内，否则必须进入专用的 fallback 模式（受控停止 / 柔顺保持 / 重力补偿冻结），而不是假装 stub 天然安全。
这四点合起来就是**模式切换证书 MSC**。它把 R74 的「RED ⇒ stub」从证据语义升级为控制语义。

### 灵感 2（专利布局 → 主张的作用域、优先序与自由实施）

直觉：专利文件的核心不是「我发明了什么」这句话，而是**权利要求（claim）**：每一项权利要求用若干限制条件划出一个集合；保护范围就是这个集合。专利法还要求 **enablement**（本领域技术人员能照着实施）、**priority**（谁先申请）、**dependencies**（从属权利要求引用独立权利要求）、**freedom-to-operate**（不落在别人权利要求范围内）。作用域在审查/无效程序中**只能缩小，不能扩大**——扩大等于新申请。

严谨化：把每条安全主张 c 写成 c = (φ, S, E, π, K, J, p, Dep, A)：
- φ 是断言的性质（安全 / 活性 / 性能）；
- S 是**作用域**（状态–动作–环境三元组集合），主张在 S 外**不成立**；
- E 是实施证据（SEAL 报告、MB 基准、conformal 校准）；
- π 是实施该主张的控制器，K ⊆ S 是控制不变集，J 是证书；
- p 是版本/优先序，Dep 是依赖的主张，A 是使用的假设集合。
**Enablement** 就是「π 在 K 上使 φ 成立且有 J 可复核」；**no-broadening** 就是「新证据只能令 S ← S ∩ S_new，扩宽必须产生新版本并重新 enable」；**FTO** 就是「模块用的每条假设都被某条已 enable 的主张覆盖，且不与其冲突主张重叠」。这样，R73 的 CPB 从一张「主张–实验」对照表，升级为一张**可组合、可审计、可缩不可扩**的权利要求图。

### 灵感 3（两者的交汇 → scope 是共同货币）

直觉：没有控制证书的主张是「纸面专利」，没有作用域的控制证书是「无限范围的许可证」。两者都是不可信的。真正的安全对象是**作用域三元组**：
- 证据作用域 D（契约在哪些物理条件下有效）；
- 主张作用域 S（安全性质在哪些状态–动作–环境下被断言）；
- 控制不变集 K（控制器从哪些初始状态出发能一直留在 S 内）。
必须成立 **K ⊆ S ⊆ D**。R74 只显式管 D，S 和 K 都是隐式的；本轮把三者都变成一等公民。控制侧负责「K 真的不变」，专利侧负责「S 真的不越界、不重叠、不悬空」。

### 灵感 4（认证丛林与合取义务）

直觉：多个模块/主张同时覆盖同一片工作区时，专利上会形成 thicket（丛林）：不是选一个遵守，而是**所有覆盖你的权利要求都必须满足**。安全上更严格：重叠区的义务是合取，不是析取。如果两条主张的假设互斥（例如「接触力可控」与「保持 5cm 净空」在同一状态同时被要求），该重叠区就**没有可认证的操作**，只能通过缩小作用域或增加复合主张来消除。把 thicket 显式化，可以防止「在每个模块各自安全、组合起来互相拆台」的经典失败。

### 灵感 5（热替换 = 权利要求延续，而不是重新发明）

直觉：专利里可以用 continuation 在保留优先权的前提下扩展/细化权利要求；但新范围必须有新证据支持。机器人换手/换本体/换控制器时，正确做法不是「全系统重审」，也不是「直接沿用旧证书」，而是**主张延续**：保留主张 id 与优先序，重新验证新实现是否在同一 scope 上 enable；scope 只能收不能放。这把 R73 的热替换定理从「同契约实现可换」推进到「同 scope 可延续，scope 变化必须显式申报」。

### 灵感 6（研究主张的 claim chart：防御「工程堆叠」质疑）

直觉：审稿人问「这是不是一堆工程的堆叠？」时，最有力的回答不是再列组件，而是像专利审查员一样给出 claim chart：每条主张对应哪些 prior art、差异限制是什么、由哪个最小实验 enable、作用域到哪里为止、哪些组件只是实施例（工程附件）。这同时是一张**自由实施图**：我们用的每条假设（conformal 交换性、ISS、passivity、材质离散化）都必须被某条已 enable 的主张覆盖，否则就是未申报的依赖。

## 1. 形式化定义（增量：定义 398–414）

**定义 398（CLAMP-RAS 总览与七不变式）** CLAMP-RAS = (CCE, MSC, RVK, M3, CPA, CPL, CLAMP-QP, J_CLAMP, SENTGAUGE†)。七不变式：
(i) **主张完备**：每条主张声明 (φ, S, E, π, K, J, p, Dep, A)，缺一不可；
(ii) **作用域单调**：同一主张世系上 S 只能收缩，扩宽必须是新版本并重新 enable（定义 402）；
(iii) **包络包含**：K ⊆ S ⊆ D（D 为证据契约有效域）；
(iv) **切换安全**：模式图的每条边都有 MSC 守卫、驻留时间与能量约束（定义 406）；
(v) **鲁棒生存**：规划器始终停留在退化感知鲁棒生存核 K_robust 内（定义 407）；
(vi) **组合健全**：部署区域内每条轨迹至少被一条已 enable 主张覆盖；重叠区按合取义务处理，冲突即未认证（定义 401/404）；
(vii) **严格退化**：CLAMP → SENTGAUGE → MODGAUGE → EMBODIED → R71 → R68 逐指令等价，安全侧只增不减。

**定义 399（主张 Claim）** c = (φ, S, E, π, K, J, p, Dep, A)：
- φ：断言性质（不变安全 / 可达 / 跟踪误差上界）；
- S ⊆ X × U × Θ_env：**作用域**，主张在 S 外无效；
- E：实施证据集合（SEAL 校准、MB 基准、conformal 覆盖率、许可证）；
- π：实施控制器；K ⊆ S：控制不变集；J：该主张的证书；
- p：版本与优先序；Dep：依赖主张（DAG）；A：假设集合（每个假设必须可追溯到契约或已 enable 主张）。

**定义 400（Enablement / 主张有效）** Valid(c) ⇔
(i) S ⊆ D_EC ∩ D_plant（证据与模型有效域）；
(ii) K 在 π 下控制不变：∀x∈K, ∃u=π(x) 使 f(x,u)∈K；
(iii) J 可复核（Lyapunov/ISS/CBF/SEAL/conformal）；
(iv) E 对 S 有覆盖（不是只在被访问子集上）；
(v) A 中每条假设都被某条已 enable 的主张覆盖（无循环借用）。
**Valid(c) 的语义是「c 在 S 上被实施」，不是「φ 全局为真」。**

**定义 401（主张组合与覆盖）** 主张集 C 带优先序 ≺（无环）。部署区域 R 的**活跃主张** C_R = {c : S_c ∩ R ≠ ∅}。
- **覆盖**：Cov(C,R) ⇔ R ⊆ ∪_{c∈C_R} S_c；
- **空洞**：Hole(C,R) = R \ ∪_{c∈C_R} S_c，空洞内一律 uncertified；
- **认证丛林**：O(C) = {(x,c,c′) : x ∈ S_c ∩ S_{c′}, A_c ∪ A_{c′} 不可满足或 K_c ∩ K_{c′} = ∅}；
- **合取义务**：重叠区若无复合主张 c⊗c′ 同时 enable，则视为 O(C) 冲突，必须缩窄或显式拒绝。
**健全性要求**：Cov(C,R) ∧ O(C)=∅ ⇒ 部署区域内每条轨迹至少被一条有效主张覆盖，且重叠区义务相容。

**定义 402（主张代数与 no-broadening）** 主张上的两种基本运算：
- **交（narrow）** c₁ ⊓ c₂ = (φ₁∧φ₂, S₁∩S₂, E₁∪E₂, π 取更保守者, K₁∩K₂, J 合并, p=max, Dep 合并, A 合并)；
- **复合（continuation）** c′ = cont(c; S_new, E_new, J_new)，要求 p′>p，S′ ⊆ S，且只有 S_new ⊆ S 时才允许；若需要扩宽，必须新建独立主张并重新 enable。
**引理 42（no-broadening）**：沿同一主张世系，作用域测度 µ(S) 单调不增；任何使用未重新 enable 的扩宽 scope 出具的证书无效。系：**认证不能「洗白」——新数据只能把主张收窄，不能把旧结论推广到新区域。**

**定义 403（自由实施 FTO）** 模块 m 的假设集合 A_m 是**已清偿**的，若 ∀a∈A_m，存在已 enable 主张 c 使 a∈A_c 且 m 的工作点落在 S_c 内，并且不存在 c′ 与 c 在 m 的工作点重叠且 A_c′ 与 A_c 冲突。否则 m 必须「取得许可」：补充证据契约、增加校准或缩小工作域。**这就是把「自由实施」翻译成「假设依赖审计」。**

**定义 404（混合模式自动机）** H = (Q, X, U, f, Init, Dom, E, G, R)，Q = Q_sent × Q_contact × Q_evid。每个 q 有控制器 π_q、控制不变集 K_q、Lyapunov/ISS 函数 V_q、屏障函数 B_q。边 e=(q,q′)∈E 的守卫 G_e 由哨兵状态、接触检测与证据可用性给出；reset map R_e 必须是确定的。若 R_e(G_e) ⊄ K_{q′}，则边必须指向 fallback 模式 q_stop，而不是普通模式。

**定义 405（模式切换证书 MSC）** MSC = {(V_q, α_q, β_q, μ_{q→q′}, τ_d, ΔE_{q→q′}, E_tank)}，条件：
- **模式内**：V̇_q ≤ −α_q V_q + β_q‖e_evid‖²（ISS，e_evid 为证据误差）；
- **跳变**：V_{q′}(x⁺) ≤ μ_{q→q′} V_q(x⁻) + κ_{q→q′}；
- **驻留**：平均驻留时间 τ_a ≥ ln μ_max / α_min（μ>1 时）；
- **能量**：接触/阻抗切换满足 E_tank(t) ≥ 0，切换消耗 ΔE_{q→q′} ≤ E_tank + E_dissipated；低能量时强制降低刚度/进入充电动作。
满足 MSC 的混合轨迹对证据误差 ISS，且 ∪_q K_q 前向不变。

**定义 406（退化感知鲁棒生存核 RVK）** 对模式图与检测+切换延迟 τ_lat，定义前驱算子
Pre_q(K) = {x ∈ K : ∃u∈U_q(x), f_q(x,u) ∈ K}。
K_robust 是以下集合方程的**最大不动点**：
K_robust = {x ∈ ∩_{q 可达} K_q : ∀q′ 在 τ_lat 内可达, ∃u∈U_q(x), f_q(x,u) ∈ Pre_{q′}(K_{q′})}。
**关键性质**：只要 x_t ∈ K_robust，无论哨兵在何时把系统切到哪个可达模式，切换后的状态都仍在对应 K 内——**不需要预测切换，只需要待在鲁棒核里**。这是「退化在发生前就安全」的形式化。

**定义 407（证据–运动余量 M3）** 记证据误差 ‖e_evid‖ ≤ u（由 R74 的 u 归一化），跟踪误差 e_trk，外部扰动 d，模型误差 δ。ISS 上界
‖e_trk‖ ≤ γ_evid u + γ_dist d + γ_model δ。
定义约束余量 m(x) = dist(x, ∂S_active)。**运行时约束**：γ_evid u + γ_dist d + γ_model δ ≤ m(x)。这把「不确定度」从 λ 里的一个加数，变成运动可行域上的一个**硬约束**；λ 仍可保留为偏好，但不再是唯一安全旋钮。

**定义 408（作用域约束的安全滤波器 CLAMP-QP）** 每个控制步求解
u* = argmin_u ‖u − u_nom‖²
s.t. x_{k+1} ∈ K_robust，
     B_q(x_{k+1}) ≥ 0（当前模式屏障），
     活跃主张的约束（φ_c 的 CBF/集合形式），
     执行器饱和与速率限制，
     M3 余量约束，
     R74 的反作用预算。
**不可行时不得「调大 λ 直到可行」**：必须进入 fallback 主张 c_stop（受控停止/柔顺保持/重力补偿冻结），并记录不可行证书。这是把 R74 的 RED 从证据事件升级为**受认证的控制事件**。

**定义 409（接触切换的能量预算）** 能量槽 E_tank 随阻抗参数与接触模式切换演化：
E_tank⁺ = E_tank⁻ − ΔE_switch + E_regen，且 E_tank⁺ ≥ 0。
ΔE_switch 由切换前后势能/动量与阻抗参数差的上界给出；接触冲量按法向速度与恢复系数上界记账。**主张 S_c 中显式包含「可用刚度 ≤ f(E_tank, 接触模式)」**；能量不足时收窄 scope，而不是继续执行。

**定义 410（作用域感知退化 CSD）** 
- YELLOW：S ← S ∩ S_γ，K ← K ∩ K_γ，γ_evid 上调（更保守），K_robust 收缩；不产生新主张，仅收窄当前主张；
- RED：当前主张暂停（suspend），切换到 fallback 主张 c_stop；证据 stub 只是必要条件，不是充分条件；
- 恢复：必须经过再认证事件 + 新版本主张 c′（p′>p）+ 稳定窗；**禁止自动恢复到旧 scope**。这与专利的 reissue/reexam 同构：修正必须留下新权利要求版本。

**定义 411（J_CLAMP 证书）** J_CLAMP = J_SENT ⊗ (⊗_{c∈C_active} J_c) ⊗ MSC ⊗ RVK ⊗ 组合审计（覆盖/空洞/丛林/FTO）⊗ 模式日志 ⊗ CSD 日志。
**作用域相对语义**：Valid(J_CLAMP) ⇒ 「在 Cov(C,R) 覆盖的区域内」R74 定理 31 的全部结论 + 控制前向不变 + ISS + 无作用域外主张；区域外显式标注 uncertified，不作为安全断言。

**定义 412（CPB 扩展 C5/C6 与 MB5/MB6）**
- **C5（作用域认证的运动）** ← (CCE, MSC, RVK, M3, CLAMP-QP) ← MB5 ← AB5（作用域认证 vs 仅 λ 缩放 vs 固定保守控制器）←（约束违反率、ISS 增益拟合误差、恢复时间、可认证区域体积）；
- **C6（主张组合的完备性）** ← (CPA, CPL, CSD) ← MB6 ← AB6（权利要求图审计 vs 临时主张清单）←（空洞率、丛林冲突检出、FTO 违规、再认证成本）。

## 2. 关键算法骨架

```python
# IP-310 CCE：作用域控制包络（主张 = 控制器 + 不变集 + 证书）
@dataclass(frozen=True)
class Claim:
    phi: Predicate                    # 断言性质
    scope: Region                     # S：状态×动作×环境
    evidence: EvidenceSet             # E：SEAL/MB/conformal
    controller: Controller            # π
    invariant: Region                 # K ⊆ S
    cert: Cert                        # J
    version: int; deps: Tuple[str,...]
    assumptions: FrozenSet[str]       # A
    def enabled(self, D, covered_assumptions):
        return self.scope <= D and self.invariant <= self.scope \
           and self.cert.valid and self.assumptions <= covered_assumptions

# IP-314 CPA：主张组合代数（交/延续/no-broadening/丛林）
class ClaimPortfolio:
    def narrow(self, c1, c2):          # 只可交
        return Claim(phi=c1.phi & c2.phi, scope=c1.scope & c2.scope,
                     evidence=c1.evidence | c2.evidence,
                     controller=more_conservative(c1.controller, c2.controller),
                     invariant=c1.invariant & c2.invariant,
                     cert=merge_cert(c1.cert, c2.cert),
                     version=max(c1.version, c2.version),
                     deps=c1.deps | c2.deps, assumptions=c1.assumptions | c2.assumptions)
    def continue_claim(self, c, scope_new, evidence_new):
        if not subset(scope_new, c.scope): raise ScopeBroadening(c)
        return replace(c, scope=scope_new, evidence=c.evidence | evidence_new,
                       version=c.version + 1)
    def audit(self, R):
        active = [c for c in self.claims if intersects(c.scope, R)]
        holes = R - union(c.scope for c in active)
        thicket = [(x,c1,c2) for x in R for c1,c2 in pairs(active)
                   if x in c1.scope and x in c2.scope
                   and not compatible(c1, c2)]
        return AuditReport(holes=holes, thicket=thicket,
                           ft_o=[m for m in self.modules if not self.fto(m)])

# IP-311 MSC：模式切换证书（预计算，运行时查表）
def check_msc(modes, edges):
    for q in modes:
        assert lyap_iss(q.V, q.alpha, q.beta)          # 模式内
    for (q, q2) in edges:
        assert q2.V_after_reset <= q2.mu * q.V_before + q2.kappa   # 跳变
        assert q.tau_d >= log(max_mu) / min_alpha                  # 驻留
        assert energy_switch(q, q2) <= q.E_tank + q.E_dissipated   # passivity
    return MSC(modes, edges)

# IP-312 RVK：退化感知鲁棒生存核（离线最大不动点，运行时 O(1) 成员判定）
def compute_rvk(mode_graph, K, tau_lat):
    Krob = {q: K[q] for q in mode_graph.nodes}
    while True:
        new = {}
        for q in mode_graph.nodes:
            safe = Krob[q]
            for q2 in mode_graph.reachable(q, tau_lat):
                safe &= pre(q, Krob[q2])       # 存在 u 使 f_q(x,u) ∈ Pre_{q2}(K[q2])
            new[q] = Krob[q] & safe
        if new == Krob: return Krob
        Krob = new

# IP-313 M3：证据–运动余量（ISS）
def motion_margin(x, u_evid, gamma, active_claims):
    m = min(distance_to_boundary(x, c.scope) for c in active_claims)
    return m - (gamma.evid * u_evid + gamma.dist * dist_bound + gamma.model * model_err)

# IP-316 CLAMP-QP：作用域约束安全滤波（1kHz；不可行即 fallback）
def clamp_qp(x, u_nom, mode, claims, msc, Krob):
    cons = [in_set(x_next, Krob[mode]),
            barrier(mode.B, x, u_nom),
            *[claim_cbf(c, x, u_nom) for c in claims if active(c, x)],
            actuator_limits(), rate_limits(),
            margin_constraint(motion_margin(x, u_evid, gamma, claims)),
            budget_constraint(mode.reflex_budget)]
    u = solve_qp(objective=‖u - u_nom‖², constraints=cons)
    if u is None:
        return fallback(c_stop, x), InfeasibleCert(cons)
    return u, None

# IP-317 CLAMP 主闭环（叠加 R74；模式切换由哨兵/接触/证据驱动）
def CLAMP_round(M, obs, audio, tac_frame, depth_img, det_set, tracks):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    o_ev = M.oem.update(det_set, tracks, d_ev, rgb, M.tac_blobs)
    for ev, mod in ((d_ev, M.dpe), (o_ev, M.oem)):
        st, E = mod.sent.step(ev.resid, M.hist); ev.sent_state = st
        if st == 'RED': ev = stub(mod)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    if M.clock.due_metric():
        M.kappa = M.ncm.adapt(M.interact_window)
        b_t = M.bse.step_full(..., d_ev=d_ev, o_ev=o_ev, t_ev=t_ev)
        # 主张作用域随证据收窄（只交不并）
        M.portfolio.narrow_by_evidence(d_ev, o_ev, t_ev)
        mode = M.mode_automaton.current(d_ev, o_ev, t_ev, M.last_g)
        M.msc.check(mode, M.portfolio.active_claims)
        M.pvop = viewpoint_aware_plan(b_t, M.mods, M.risk_params,
                                      Krob=M.rvk[mode])       # 只在鲁棒核内规划
        g = M.ervoi.choose(...)
        if g:
            s2, cost = sent_reflex_step(M.mods, g, M.state, M.budget)
            if s2 is not None: M.last_g, M.state = g, s2
        M.mreg.audit(); M.ecg_edge_sentinels.step()
        M.cert = write_clamp_cert(M)                          # J_CLAMP
    snap = M.snapshot.read_latest()
    u_nom = M.ach.propose_ctrl(..., pvop_bias=snap.pvop)
    u, infeas = clamp_qp(snap.x, u_nom, snap.mode, snap.claims,
                         M.msc, M.rvk)
    if infeas: M.csd.enter_fallback(infeas)                   # 受认证的退出
    M.envelope.check0(u, snap.mode)                           # 第 0 层不可 stub
    return u, J_CLAMP(M)
```

## 3. 推导

**引理 42（no-broadening 单调性）** 由定义 402，narrow 只做交，continuation 要求 S′⊆S 且版本递增；主张世系上的作用域测度单调不增。任何把 certificate 用于 S′⊄S 的路径都缺少新版本的 enablement 证据，故 J_CLAMP 无效。系：**「新数据只能收窄结论」是可审计的——scope 的每一次变化都有版本与证据。**

**引理 43（主张组合健全性）** 若 Cov(C,R) 且 O(C)=∅（无不可满足重叠），则 R 内每条轨迹至少被一条 Valid(c) 覆盖；在重叠区，取 c₁⊓c₂ 的合取义务，其控制器与不变集仍 enable。证明：覆盖给出存在性；O(C)=∅ 保证交集上假设可同时满足、K 交非空；定义 402 的交运算保持 K⊆S⊆D。系：**权利要求图不会「各自安全、组合拆台」——组合失败被显式变成空洞或丛林冲突。**

**引理 44（MSC 的切换稳定性）** 若每个模式内 V̇_q ≤ −α_qV_q + β_q‖e_evid‖²，每次切换 V_{q′} ≤ μV_q + κ，且平均驻留时间 τ_a ≥ ln μ/α，则混合轨迹对 e_evid 是 ISS 的；若进一步每个 K_q 前向不变且 reset 满足 R_e(G_e)⊆K_{q′}，则 ∪K_q 前向不变。能量槽非负条件保证接触切换不注入净能量。证明：多 Lyapunov 函数 + 平均驻留时间（Hespanha–Morse）逐段拼接；passivity 项由定义 409 吸收。

**引理 45（RVK 的退化预期性）** 若 x_t∈K_robust，则对任意在 τ_lat 内可达的模式 q′，存在容许控制使 x_{t+τ_lat}∈K_{q′}。证明：K_robust 是前驱算子的最大不动点；对每个可达 q′，定义中的 Pre_{q′}(K_{q′}) 条件给出一步前驱，归纳至 τ_lat。系：**不需要预测哨兵何时触发——鲁棒核把「所有可能的退出」提前算进了约束。**

**引理 46（CLAMP-QP 的递归可行性与安全滤波）** 若 x_0∈K_robust，且 fallback 主张 c_stop 的 K_stop 非空、模式切换满足 MSC，则 CLAMP-QP 在不可行时进入 c_stop 后仍满足前向不变；在可行时，QP 的解保持 x_{k+1}∈K_robust 与活跃主张约束，故递归可行。证明：QP 显式约束 x_{k+1}；fallback 的不变集由定义 400/405 保证；M3 约束由定义 407 给出。系：**「安全退化」第一次有了控制层构造，而不是证据层的口号。**

**定理 32（CLAMP 严格包含 SENTGAUGE）** 当所有主张的 scope 取 D、模式图单点、MSC 取 R72 的 certified prefix 证书、K_robust=K、portfolio 单主张、CSD 退化为 R74 的 stub 语义时，CLAMP 逐指令等于 SENTGAUGE；再退化等于 MODGAUGE/R72/R71/R68。安全单调不减，性能仅在 scope 约束满足时获益。系：**R74 是 CLAMP 在「无模式切换、无作用域管理」处的投影。**

**定理 33（作用域认证安全）** 在 A121–A124 下：Valid(J_CLAMP) ⇒ (i) 在 Cov(C,R) 覆盖的区域内，R74 定理 31 全部成立；(ii) 闭环满足 K_robust 前向不变、ISS 与约束满足；(iii) 每条活跃主张在其 S 内被 enable，S 外不被断言；(iv) 任何未覆盖区、丛林冲突或 FTO 违规都被显式标为 uncertified，而不是静默放行。**证明重量落在 A121/A123（模型与能量界在 S 内成立）和 A124（claim chart 完备）——这些仍是不可完全检验的，但作用域让它们可以被缩小、被审计、被版本化。**

**定理 34（作用域–性能–切换频率三角）** 在固定证据/执行预算下，不可能同时由构造保证：
1. **大作用域**（S 覆盖部署区域的大部分）；
2. **高运动性能**（跟踪误差/任务时间接近无约束最优）；
3. **高切换频率**（任意哨兵/接触模式可频繁切换）。
形式化：扩大 S 需放松约束（M3 余量下降）；提高性能需收紧约束或增大增益（ISS 增益/能量消耗上升）；提高切换频率需更小 μ 或更长驻留（与性能冲突）。至少有一项只能作为显式假设或显式缺口。系：**CLAMP 不承诺三者兼得；它承诺不再偷偷地三者兼得。**

## 6. 本轮最大风险

**一句话**：CLAMP 把认证从「全局断言」改成「作用域断言」，但作用域本身仍由**我们自己的模型、我们自己的 claim chart、我们自己的 RK 近似**画出——如果某个未建模的接触冲量、未申报的假设或某个 coarse grid 漏掉的边界点恰好落在声称的 S 内，系统就会持有一份**完全合规、版本正确、no-broadening 无违例、每条主张都 enable** 的证书，在真实世界已经越出包络时继续宣称安全；专利式审计会证明「每一项权利要求都写得无懈可击」，而机器人正在执行一个**只存在于近似模型中的权利要求的实施例**。

次级风险与缓解：
1. **RVK 维数灾难/近似误差** → 多面体/椭球保守近似 + 运行时第 0 层包络兜底 + 网格加密敏感性分析（E414）。
2. **模式检测延迟与抖动** → 滞回 + 平均驻留时间 + fallback 主张；检测延迟进入 τ_lat 的显式预算（A122/E413/E424）。
3. **passivity 被未建模接触破坏** → 能量槽 + 接触冲量上界 + 低能量降刚度 + 第 0 层力/温升熔断（定义 409/E417）。
4. **claim chart 自指/自证** → 独立红队 + prior-art registry + 密封部署区域 + 第三方 claim audit（定义 413/E421）。
5. **scope 通过合法重校准被悄悄放大** → no-broadening + 新版本 + 新证据 + 再认证；扩宽事件全链追溯（定义 402/E412）。
6. **丛林爆炸/组合不可判定** → 结构上限（|C|≤24、重叠类≤6）+ 预计算兼容图 + 冲突即 uncertified 的保守策略（定义 401/E423）。
7. **MB5/MB6 过拟合** → SEAL-MB5/6 密封保持集 + 预注册 + 三方复现 + 只认预注册指标（E425）。

> - **运动控制** → 作用域即控制包络：CCE（主张=控制器+不变集+证书）、MSC（驻留时间+多 Lyapunov+能量槽）、RVK（退化感知鲁棒生存核）、M3（证据误差→跟踪误差的 ISS 余量）、CLAMP-QP（不可行即受认证 fallback，禁止 λ 硬撑）。
> - **专利布局** → 主张组合代数与权利要求图：CPA（交/延续/no-broadening/FTO/丛林冲突）、CPL（C1–C6 的 claim chart 与独立/从属权利要求树），把「论文主张」与「运行时主张」统一到同一套 scope 词汇。
>
> 核心命题：**安全主张 = 在作用域 S 内被控制器 π 实施、由不变集 K 支撑、经证书 J 复核的权利要求；S 只能收窄不能扩宽，切换必须在发生前就落在鲁棒核里。** 把 SENTGAUGE 重构为 **CLAMP-RAS**——**作用域感知的控制证书 × 证明组合**。
>
> IP 编号：IP-310~317（共 8 个）+ R74 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化（scope 取全域、模式取单点、MSC 取 R72 证书时逐指令等价），安全侧只增不减。**

## 2. 形式化定义（要点版）

**定义 398（总览与七不变式）** CLAMP-RAS = (CCE, MSC, RVK, M3, CPA, CPL, CLAMP-QP, J_CLAMP, SENTGAUGE†)。七不变式：主张完备 / 作用域单调 / 包络包含 K⊆S⊆D / 切换安全 / 鲁棒生存 / 组合健全 / 严格退化。

**定义 399（主张）** c=(φ,S,E,π,K,J,p,Dep,A)；S⊆X×U×Θ_env；S 外主张无效；A 中每个假设可追溯到契约或已 enable 主张。

**定义 400（Enablement）** Valid(c) ⇔ S⊆D_EC∩D_plant ∧ K 在 π 下控制不变 ∧ J 可复核 ∧ E 对 S 有覆盖 ∧ A 无循环借用。语义是「c 在 S 上被实施」，不是「φ 全局为真」。

**定义 401（组合与覆盖）** C_R={c:S_c∩R≠∅}；Cov ⇔ R⊆∪S_c；Hole=R\∪S_c；O(C)=重叠且 A_c∪A_c′ 不可满足或 K 交空的点。健全性：Cov ∧ O=∅ ⇒ R 内每条轨迹至少被一条有效主张覆盖。

**定义 402（主张代数）** 交 c₁⊓c₂ 逐字段取交/并/更保守；continuation 要求 S′⊆S、p′>p、E′⊇E；扩宽禁止。**引理 42**：作用域测度沿世系单调不增。

**定义 403（FTO）** A_m 已清偿 ⇔ 每条假设被已 enable 主张覆盖且无冲突重叠；否则补契约/校准/缩域（取得「许可」）。

**定义 404（混合模式自动机）** H=(Q,X,U,f,Init,Dom,E,G,R)；每模式有 π_q,K_q,V_q,B_q；reset 后不在 K_{q′} 的边必须指向 c_stop。

**定义 405（MSC）** 模式内 V̇_q≤−α_qV_q+β_q‖e_evid‖²；跳变 V_{q′}≤μV_q+κ；平均驻留 τ_a≥ln μ_max/α_min；能量槽 E_tank≥0 且 ΔE_switch≤E_tank+E_dissipated。

**定义 406（RVK）** Pre_q(K)={x∈K:∃u,f_q(x,u)∈K}；K_robust 为 `x∈∩K_q` 且对 τ_lat 内每个可达 q′ 有一步前驱进入 Pre_{q′}(K_{q′}) 的最大不动点。

**定义 407（M3）** ‖e_trk‖≤γ_evid u+γ_dist d+γ_model δ；运行时要求该上界 ≤ m(x)。λ 仍可为偏好，但不再是唯一安全旋钮。

**定义 408（CLAMP-QP）** 每步求 u*；约束含 K_robust、CBF、活跃主张、执行器/速率、M3、R74 反作用预算。不可行 ⇒ c_stop + InfeasibleCert，禁止「调大 λ 直到可行」。

**定义 409（能量预算）** E_tank⁺=E_tank⁻−ΔE_switch+E_regen≥0；ΔE 由阻抗差与接触冲量上界给出；低能量时 scope 收窄（可用刚度下降）。

**定义 410（CSD）** YELLOW：S←S∩S_γ、K←K∩K_γ、γ_evid↑；RED：暂停当前主张、切 c_stop；恢复须再认证+新版本+稳定窗，禁止自动扩回旧 scope。

**定义 411（J_CLAMP）** J_SENT⊗(⊗J_c)⊗MSC⊗RVK⊗组合审计⊗模式/CSD 日志。Valid ⇒ 在 Cov(C,R) 上 R74 定理 31 + 控制前向不变 + ISS + 作用域不越界；区域外 uncertified。

**定义 412（C5/C6）** C5←(CCE,MSC,RVK,M3,CLAMP-QP)←MB5←AB5←（约束违反率、ISS 拟合误差、恢复时间、可认证区域体积）；C6←(CPA,CPL,CSD)←MB6←AB6←（空洞率、丛林冲突检出、FTO 违规、再认证成本）。

**定义 413（Claim Chart）** c↦(prior art, 差异限制, enabling benchmark, scope, 否证实验, FTO 假设)；C1–C6 每行非空；工程附件不占行。

**定义 414（A121–A124）** S 内 plant/ISS/Lyapunov 成立；τ_lat 有界且守卫覆盖可达切换；能量/接触冲量界成立；claim chart 对 R 完备。

## 3. 关键算法伪代码

```python
# IP-315 CPL：claim chart 审计（论文主张与运行时主张同一套 scope）
CLAIM_CHART = {
 'C1': dict(scope='D_phys', prior='generic heteroscedastic UQ',
            enable='MB1', falsify='AB1: ECE/collision', ft_o=['noise model']),
 'C2': dict(scope='D_reflex', prior='single-layer VOI',
            enable='MB2', falsify='AB2: interactions/stop', ft_o=['KL budget']),
 'C3': dict(scope='D_module', prior='ROS component models',
            enable='MB3', falsify='AB3: hot-swap diff', ft_o=['contract types']),
 'C4': dict(scope='D_sentinel', prior='SPRT/CUSUM',
            enable='MB4', falsify='AB4: false alarm/delay', ft_o=['e-process']),
 'C5': dict(scope='D_motion', prior='lambda-scaling / robust MPC',
            enable='MB5', falsify='AB5: violations/ISS', ft_o=['ISS','passivity']),
 'C6': dict(scope='D_portfolio', prior='ad-hoc claim lists',
            enable='MB6', falsify='AB6: holes/thicket/FTO', ft_o=['claim algebra']),
}

# IP-314 CPA：组合审计（只交不并；冲突即 uncertified）
def audit_portfolio(P, R):
    active = [c for c in P.claims if intersects(c.scope, R)]
    holes = R - union(c.scope for c in active)
    thicket, fto = [], []
    for x in R:
        cover = [c for c in active if x in c.scope]
        if len(cover) >= 2 and not all(compatible(a, b) for a, b in pairs(cover)):
            thicket.append((x, cover))
        for m in P.modules_at(x):
            if not all(any(a in c.assumptions and x in c.scope for c in active)
                       for a in m.assumptions):
                fto.append((m, x))
    return Audit(holes=holes, thicket=thicket, fto=fto,
                 cert=('uncertified' if holes or thicket or fto else 'ok'))

# IP-312 + IP-316：RVK 成员判定 + 作用域 QP（1kHz，只读快照）
def control_step(x, u_nom, mode, claims, rvk, msc):
    if x not in rvk[mode]:                       # 已越出鲁棒核
        return c_stop.control(x), FallbackCert('RVK_EXIT')
    cons = [x_next in rvk[mode], mode.B(x, u_nom),
            *[claim.CBF(c, x, u_nom) for c in active_claims(claims, x)],
            actuator_limits(), rate_limits(),
            motion_margin(x, u_evid, gamma, claims) >= 0,
            reflex_budget(mode)]
    u = solve_qp(u_nom, cons)
    return (u, None) if u is not None else (c_stop.control(x), InfeasibleCert(cons))

# IP-317 CSD：作用域感知退化（不做「静默 stub」）
def degrade(claim, sentinel_state, ev):
    if sentinel_state == 'YELLOW':
        return narrow(claim, scope=claim.scope & gamma_scope(ev),
                      invariant=claim.invariant & gamma_inv(ev),
                      gamma_evid=claim.gamma_evid * 1.2)      # 只收窄
    if sentinel_state == 'RED':
        suspend(claim); activate(c_stop); return c_stop      # 受认证 fallback
    return claim

def recover(claim, recert, stable_window):
    if recert.valid and stable_window.ok:
        return continue_claim(claim, scope=claim.scope,
                              evidence=claim.evidence | recert.evidence)  # 不扩宽
    return claim
```

## 4. 推导

**引理 42（no-broadening 单调性）** narrow 只做交；continuation 要求 S′⊆S 且版本递增；故同一世系上 µ(S) 单调不增。使用 S′⊄S 而无新 enablement 的证书无效。系：**新数据只能收窄结论，scope 变化有版本与证据可追溯。**

**引理 43（组合健全性）** Cov(C,R) ∧ O(C)=∅ ⇒ R 内每条轨迹至少被一条 Valid(c) 覆盖；重叠区取 c₁⊓c₂ 的合取义务仍 enable。证明：覆盖给出存在性；O=∅ 保证假设可同时满足、K 交非空；定义 402 的交保持 K⊆S⊆D。

**引理 44（MSC 切换稳定性）** 模式内 ISS + 跳变 μ/κ + 平均驻留 τ_a≥ln μ/α ⇒ 混合轨迹对 e_evid ISS；若 K_q 前向不变且 reset 落在 K_{q′}，则 ∪K_q 前向不变；能量槽非负 ⇒ 接触切换无净能量注入。证明：多 Lyapunov + Hespanha–Morse 驻留时间逐段拼接；passivity 项由定义 409 吸收。

**引理 45（RVK 退化预期性）** x_t∈K_robust ⇒ 对任意 τ_lat 内可达 q′，存在容许控制使 x_{t+τ_lat}∈K_{q′}。证明：K_robust 是前驱算子最大不动点，定义逐模式给出一步前驱，归纳至 τ_lat。系：**不必预测哨兵何时触发，鲁棒核把「所有可能退出」提前算进约束。**

**引理 46（CLAMP-QP 递归可行/安全滤波）** x_0∈K_robust 且 c_stop 的 K_stop 非空、切换满足 MSC ⇒ 不可行时进入 c_stop 后前向不变；可行时 QP 显式约束 x⁺∈K_robust，故递归可行。

**定理 32（CLAMP 严格包含 SENTGAUGE）** scope=D、单模式、MSC=R72 certified prefix、K_robust=K、单主张、CSD=R74 stub 语义时逐指令等于 SENTGAUGE；再退化等于 MODGAUGE/R72/R71/R68。安全单调不减。

**定理 33（作用域认证安全）** A121–A124 下 Valid(J_CLAMP) ⇒ (i) Cov(C,R) 内 R74 定理 31 全部成立；(ii) 闭环 K_robust 前向不变、ISS、约束满足；(iii) 每条活跃主张在其 S 内 enable，S 外不断言；(iv) 未覆盖/丛林/FTO 违规显式 uncertified。**证明重量在 A121/A123（S 内模型与能量界）与 A124（claim chart 完备）。**

**定理 34（作用域–性能–切换频率三角）** 固定证据/执行预算下，{大作用域, 高运动性能, 高切换频率} 至多二者由构造保证。扩大 S 放松约束；提高性能收紧约束/增大增益；提高切换频率需更小 μ 或更长驻留。至少一项只能作显式假设或显式缺口。系：**CLAMP 不承诺三者兼得，只承诺不再偷偷三者兼得。**

## 7. 本轮最大风险

**一句话**：CLAMP 把认证从「全局断言」改成「作用域断言」，但作用域本身由我们的模型、claim chart 与 RVK 近似画出——若某个未建模接触冲量、未申报假设或 coarse grid 漏掉的边界点恰落在声称的 S 内，系统会持有一份作用域无懈可击、版本正确、no-broadening 无违例、每条主张都 enable 的证书，在真实世界已越出包络时继续宣称安全；专利式审计证明「每项权利要求都写得合规」，而机器人执行的是一个只存在于近似模型中的实施例。

次级风险与缓解：
1. **RVK 维数灾难/近似误差** → 多面体/椭球保守近似 + 第 0 层包络兜底 + 网格敏感性分析（E414）。
2. **模式检测延迟/抖动** → 滞回 + 平均驻留 + fallback；τ_lat 进入显式预算（A122/E413/E424）。
3. **passivity 被未建模接触破坏** → 能量槽 + 冲量上界 + 低能量降刚度 + 第 0 层力/温升熔断（定义 409/E417）。
4. **claim chart 自指** → 独立红队 + prior-art registry + 密封部署区域 + 第三方审计（定义 413/E421）。
5. **scope 经合法重校准被悄悄放大** → no-broadening + 新版本 + 新证据 + 再认证；扩宽全链追溯（定义 402/E412）。
6. **丛林爆炸** → 结构上限（|C|≤24、重叠类≤6）+ 预计算兼容图 + 冲突即 uncertified（定义 401/E423）。
7. **MB5/MB6 过拟合** → SEAL-MB5/6 密封保持集 + 预注册 + 三方复现 + 只认预注册指标（E425）。
