# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多模态交互」×「阻抗控制」）

> R69 教会闭环「问」：把 epistemic 歧义变成注视、探针、问句，用 VoI−成本决定值不值得问。但 R69 的整个交互层有**一个从没被说破的前提——交互发生在自由空间、是离散的、单向的**：机器人先「看 / 问 / 触」拿到答案，再执行；信息动作 g 与任务动作 a 只是在动作空间里拼接，安全靠 C-RAS-WM 的硬包络（力上限 f_max）逐点认证。一旦真的进入接触（递物、搀扶、装配、人被夹在机器人与墙之间），这个前提同时塌掉三处：
> 1. **测量有共轭力**：你不可能「问」而不「施力」。探针不是免费的传感器，它是一个**能量端口**——获取信息的那只手同时在注入/抽取能量。R69 把信息动作当查询，等于假装测量不需要用力。
> 2. **力上限不是稳定性**：硬包络只保证逐点力/位不越界，不保证**耦合稳定**。面对阻抗未知的人或环境，固定刚度会激起极限环、抖振；「包络内合规」的轨迹照样能把人夹伤。
> 3. **证据源不独立**：R69 的「k 个正交源一致」假设证据互相独立；但在接触里，你摸到的力取决于你自己的阻抗——**观测者在回路里**，于是五个「源」可能一起错。
>
> 本轮两个灵感正好补上这三处，而且它们其实是同一件事的两面：
> - **阻抗控制**把交互从「一次查询」重写为「一个能量端口」：机器人不是问一句，而是维持一个动力学关系 Z_d=(M_d,D_d,K_d)，它**既是执行器也是传感器**；
> - **多模态交互**在接触里新增了 **触觉/力** 这一被 R69 忽略、却最难伪造的模态：语言可以说谎，身体的反抗要花真实的能量。
>
> 核心命题（也是本轮最重要的姿态）：**保守的方向在接触下反转。** R66–R69 有一条隐含铁律是「不确定 ⇒ 更硬、更慢、更短视界」——自由空间里对（缩回、收紧、降速），接触里**恰好错**：更硬意味着同样的扰动产生更大的力，更容易夹伤；接触中真正保守的动作是**让、软、耗散**。更精确地说：**耗散是普适的保守，刚度是区制相关的保守**。于是安全层不能再是单一方向的「只会收紧」，而必须**先判定身处哪个区制（自由 / 接触 / 人主动），再按区制选择保守方向**；阻抗控制正是让这个反转可连续、可认证、可无跳变地实现的唯一自然语言。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的手该有多硬**」——不确定性不只是刹车或提问，也是一个可调的刚度。

## 0. 直觉与动机

**灵感 1（阻抗控制 → 交互是一个端口，不是一个查询）**
直觉：R69 的 `g_probe=(方向, 力度)` 看起来已经有「力」了，但那只是一个**标量上限**：力不超过 f_max 就算安全。真正的接触不是「用力不超过多少」，而是「用什么样的动力学关系去接触」：同样是 5N，弹簧很软地顶住、和刚性硬顶，对人的危险与对信息的暴露完全不同。阻抗控制用 Z_d=(M_d,D_d,K_d) 描述「位/速/加速度误差 → 力」的映射，于是「多硬」成为一个连续控制量，而不是事后检查的阈值。更关键：**这个量同时是传感器旋钮**——刚度调低（更顺从），对方的力就更多体现在你的位移上，你就更容易从位移反推对方的阻抗。执行与感知由同一个 Z_d 决定。这正是 R69 缺失的：它把「感知」和「执行」当成两条通道再拼接，而物理上它们是**同一个端口的两个共轭量**（力与流）。

**灵感 2（多模态交互 → 触觉是最贵的谎言）**
直觉：R69 最大的自陈风险是「问错比不问更危险」——语言回答几乎零成本就能说谎，一个误导性回答会被盖上「已验证」的章。但**物理交互有能量账**：要让测得的力/位移轨迹看起来像另一种意图，欺骗者必须真的注入或吸收相应能量（热力学第一定律不是可选的）。语言造假成本≈0，触觉造假成本 ≥ 某个正的能量下界。于是多模态融合不再是「加权平均几个一样可信的源」，而是**按各通道的造假价格定权**：贵的那条（力）在多源冲突时应被优先采信，并可对语言/视觉做**能量一致性复核**——「你说放手，但你的身体在拉」，这个矛盾只有力气会说真话。

**灵感 3（保守方向反转 → R69 是刚性/自由空间极限）**
直觉：把 R69 的 C-RAS-WM 硬包络看成 K_d→∞ 的**刚性极限**：机器人无限硬时，它与环境的接触退化为运动学约束，交互退化为「在约束下选轨迹」，这正是 R69 的设定。一旦允许有限刚度，就出现 R69 无法表达的自由度：**顺从**。而顺从恰恰是接触里唯一的稳定/安全来源。于是得到本轮理论骨架：**R69 = PORT-RAS 在 K_d→∞、无接触时的退化边界**；正如 R69 包含 R68，R70 把 R69 包含为「刚性 / 自由空间」边界。安全侧依旧不让步：自由空间退化为 R69，接触则用更强的（passivity-based）保证替代更弱的（envelope-only）保证。

**灵感 4（对偶控制 → VoI 的物理货币是能量）**
直觉：R69 的 `VoI−c(g)` 里 `c(g)` 是人为设定的「社交/物理成本」，量纲含混。接触里成本有了唯一正确的货币：**注入环境的能量**。而「调低刚度去学对方阻抗」正是经典对偶控制（dual control）：控制动作同时是学习动作。刚度 K_d 就是这个对偶旋钮——K 大则调节好、辨识差（你压着对方，对方阻抗被你的刚度淹没）；K 小则辨识好、调节差（你顺着对方，任务精度下降）。于是 R69 的离散「问 / 不问」升级为连续的「硬 / 软」优化：在 passivity 与安全约束下最大化「辨识增益 − 能量代价 − 任务 regret」。VoI 从「标量信息增益 / 标量成本」变成「方向性辨识增益 / 能量」。

**灵感 5（新威胁模型 → 区制欺骗与能量槽耗尽）**
直觉：一旦安全依赖「当前是自由还是接触」的判断，就有了新攻击面。人可以**主动施力伪造接触**（让你变软），再突然撤力（让你软着撞上去）；也可以反复推挤**耗尽能量槽**，逼你进入 fallback 并制造功耗瞬态。R69 的投毒是多模态的语义投毒；R70 多了**物理层的区制投毒（regime spoofing）与能量耗尽攻击（tank draining）**。必须把区制判定做成带滞回、多证据、最坏情况迟滞的，并为「托举载荷」预留不可动用的能量储备。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PORT-RAS 总览）** PORT-RAS = (PII, DCC, HMI, ETL, CEC, RD, PAC, AIC-PORT)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i，接触内环亦不例外）；
(ii) **能量不变式**：对外净注入能量 ≤ E_budget，能量槽 E_tank 恒 ≥ E_reserve（载荷保持预留），且任何时刻不得向环境净注入未经认证的能量；
(iii) **阻抗连续性**：Z_d(t) 连续且 ‖Ż_d‖ ≤ ρ_max，区制切换与 fallback 必须经无跳变混合（定义 321），不得瞬时刚性化；
(iv) **区制相关保守**：自由空间沿用 R69 收缩；接触/人主动时保守方向反转为「增阻尼、降刚度、保载荷」，两者在区制判据上互斥且滞回（定义 319–320）。

**定义 311（交互端口 PII）** 机器人在交互端口的 port-Hamiltonian 形式
`ẋ = (J − R)∇H(x) + G u + G_int F_ext`，`y = G_intᵀ∇H = v`，功率 `P = vᵀF_ext`。接口渲染目标阻抗 `Z_d(s) = M_d s² + D_d s + K_d`（按自由度分块的对角+耦合项）。接口同时输出 `(v, F)`，故**执行与测量共用同一端口**；记端口能量 `E_port(t)=∫₀ᵗ P dτ`，`E_port>0` 为净注入环境。

**定义 312（阻抗调度 DCC）** 任务阻抗 `Z_task`（由 R69 策略动作块给出，决定跟踪精度）与信息阻抗 `Z_info`（低刚度、高顺从、用于辨识）按标量 `κ∈[0,1]` 混合：
`Z_d = Blend(Z_task, Z_info, κ)`，κ=1 刚性（≈R69 硬包络），κ=0 最软（仅保 K_min 与载荷）。K_d(κ) 关于 κ 单调不减、连续可微。**κ 是本轮的对偶控制旋钮**。

**定义 313（第三类不确定性 U_int 与三分）** 在 R69 的 (U_ale, U_epi) 之外新增 **交互不确定性**：`U_int = H(θ_h | (v,F) history)`，即对人或环境阻抗参数 `θ_h=(M_h,D_h,K_h)`（或其低阶等效）的后验熵。三分：
- `U_ale`：模态内噪声，→ R68 铁律；
- `U_epi`：动作模态歧义，→ R69 交互消解；
- `U_int`：**只能通过顺从/激励辨识来消解，且消解本身必须注入能量**；不能靠「问」消除。
三者不做简单加和；`U_int` 的可约性受能量预算与持续性激励（PE）约束。

**定义 314（对偶控制目标 J_dual）** 在窗口 T 上选 `(κ, g)`：
`J_dual(κ,g) = VoI_h(κ) − β·E_inj⁺(κ) − γ·Regret_task(κ) − c_social(g)`，
s.t. 定义 310-(ii)(iii)(iv)、PAC 通过、预算未超。`VoI_h(κ) = H(θ_h|o) − E_{y~p(·|κ)}[H(θ_h|o,y)]`，`E_inj⁺` 为净注入能量（只计正值），`Regret_task` 为相对 Z_task 的跟踪退化。**κ 由一维搜索求最优**；当无接触（F_ext≡0）时 κ 不可辨识、退化为 κ=1，J_dual 退化为 R69 的 MINT。

**定义 315（触觉阻抗估计 HMI）** 用递归最小二乘/卡尔曼在线估计 `θ_h`，其可辨识性由 Fisher 信息 `ℐ_h(θ_h; Z_d)` 度量，持续性激励指标 `ρ_pe = λ_min(ℐ_h)`。核心事实：`∂ρ_pe/∂K_d ≤ 0`（刚度越高、端口位移激励越小、辨识越差），`∂Regret_task/∂K_d ≤ 0`（刚度越高、跟踪越好）——二者构成**单调权衡**（引理 19）。

**定义 316（能量账本 ETL）** `Ė_tank = P_diss − P_out`，裁剪到 `[E_reserve, E_max]`；仅当 `E_tank−E_reserve ≥ E_req` 才允许净能量输出；只允许从**耗散动作**（阻尼、制动、重力势能受控释放）回充，禁止凭空回充；`E_reserve` 专用于载荷保持，任何 fallback/攻击响应都不得动用。

**定义 317（触觉欺骗能量下界 HDC）** 设真实意图产生端口能量轨迹 `E*(t)`，欺骗意图要求测得 `Ê(t)`；若二者在窗口内的能量差为 ΔE，则任何实现该欺骗的物理装置必须**净注入至少 |ΔE|** 的能量（工作–能定理）。定义通道造假价格 `π_c = dE_dec/dδ`（δ 为欺骗分布的可分辨偏差）：**π_haptic > 0 有正下界，π_language ≈ 0**。推论：在能量受限对手（A99）下，触觉证据的单位可信度严格高于语言。

**定义 318（跨模态能量一致性 CEC）** 对语言/视觉给出的意图断言 `c`，由 `c` 预测端口应有的力/能量剖面 `Ê_c(t)`，与实测 `E_port(t)` 计算
`D_E = W₁(Ê_c, E_port)`（或窗口内能量残差）。
- 若断言为「被动/放手」而实测净抽取能量超过阈值 ⇒ **语言—力矛盾**；
- 若断言为「我在推」而实测 `E_port≈0` ⇒ 同样矛盾。
`D_E` 超过阈值时，**降低语言/视觉证据权重、提高触觉权重**，并把矛盾作为 VQAuditor-I 的新审计项；单次矛盾不得单独定案（继承 R69 证据纪律）。

**定义 319（区制判定器 RD）** 区制 `c ∈ {free, contact, human-active}`，由多证据判定：`F_ext` 幅值与方向持续性、`E_port` 符号、`θ̂_h` 的置信区间、视觉接近度。判据带**滞回**（进入/退出阈值不同）与**最小驻留时间**；人主动（`E_port>0` 且非自运动）需两条正交证据。区制误判代价不对称（free→contact 与 contact→free 各有专属惩罚），故取最坏情况迟滞判定。

**定义 320（区制相关保守映射 FallbackMap）** 保守动作由区制决定：
- `free`：`λ↑`（缩短认证前缀）、`v↓`、`κ→1`（R69 行为）；
- `contact`：`κ→0`（软化）、`D_d↑`（增阻尼）、`K_d ≥ K_min_load`（保持载荷所需的最小刚度）、`E_tank` 保留 `E_reserve`；
- `human-active`：以阻尼耗散为主、禁止与人力对抗（不得用刚度硬顶），必要时沿人力方向顺从并制动。
统一表述：**增阻尼/增耗散在所有区制都保守；增刚度只在 free 保守，在 contact 可能危险**。

**定义 321（无跳变阻抗混合 Bumpless）** 任意两个阻抗 `Z_a→Z_b` 经一阶/二阶混合 `Z(τ)=Blend(Z_a,Z_b,σ(τ))`，`σ` 为 C¹ 时间标度，且 `‖Ż_d‖≤ρ_max`；切换期间同时施加 `F_feedforward = Z(τ)v` 以消除力阶跃。**禁止**从 `Z_info` 或 fallback 直接跳到 `Z_rigid`；刚性必须经连续路径到达。

**定义 322（passivity 感知证书 PAC）** `Valid_PAC ⇔` (i) 离散 passivity observer `E_obs[k] ≥ −ε_p` 且 `E_tank ≥ E_reserve`；(ii) 力/位包络（R69 C-RAS-WM）满足；(iii) `K_d ≥ K_min_load`（非压伤、可托举）；(iv) `‖Ż_d‖ ≤ ρ_max`；(v) 对人主动区制，`E_port ≤ E_budget`。PAC 是**联合证书**：passivity 给耦合稳定，包络给瞬态安全，`K_min_load` 给不塌陷，三者不可互相替代。

**定义 323（交互预算与证据纪律 IBG†）** 继承 R69 定义 293-ii/iii，升级两点：(a) 预算的物理量改为**能量预算** `E_budget`（取代标量社交成本），并区分可动预算与 `E_reserve`；(b) 证据纪律新增「力证据优先于语言证据」的默认序，且**能量一致性矛盾必须由第二正交源复核**方可定案。

**定义 324（威胁模型 AIC-PORT）** `ℰ_PORT = ℰ_FLUID × ℰ_regime × ℰ_tank`：
- `ℰ_regime`：区制欺骗（施力伪造接触后撤力）、边界抖动诱发反复切换；
- `ℰ_tank`：能量槽耗尽攻击（反复推挤/诱导主动动作耗尽预算，逼出 fallback 瞬态）；
- 其余继承 ℰ_poison（语义投毒）、ℰ_flow（流采样故障）、ℰ_CALM（标定欺骗）。

**定义 325（证书 J_PORT）** `J_PORT = (J_FLUID, passivity_margin, tank_min, k_min_margin, E_inj_p95, pe_index, deception_price_hat, impedance_rate_max, regime_log_hash, port_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ Valid_PAC ∧` 四不变式 ∧ 区制判定未被审计标记。

**定义 326（与 R69 的退化映射）** 退化函子 `D: PORT-RAS → FLUID-RAS`：令 `K_d→∞`、`F_ext≡0`（free）、`E_budget→∞`，则 `Z_d→` 运动学约束、`U_int→` 不可辨识（并入 U_epi 的不可约部分）、`J_dual→` R69 的 `VoI−c`、`FallbackMap→λ↑`。即 **R69 恰为 PORT-RAS 的刚性/自由空间边界**。

**定义 327（双时间尺度时序）** 内环（阻抗渲染、passivity observer、能量账本）1kHz 硬实时，不调用任何学习模块；外环（FLUID 认知环 + DCC/RD + CEC）沿用 R69 的 <2.6ms 预算。`κ`、`Z_d` 由外环低频下发，内环只做连续插值与安全检查——保证定义 310-i。

## 2. 关键算法骨架

```python
# IP-264 PII：端口阻抗接口（执行与测量共用端口）
class PortImpedanceInterface:
    def __init__(self, robot, tank, K_min_load, rho_max=5.0):
        self.r, self.tank, self.Kmin, self.rho = robot, tank, K_min_load, rho_max

    def render(self, Z_d, dt):                       # 1kHz 内环
        Z_prev = self.Z_d
        self.Z_d = bumpless_blend(Z_prev, Z_d, self.rho*dt)  # 定义 321
        v, F = self.r.port_state()                   # 同端口测量
        F_cmd = self.Z_d.apply(self.r.pose_error(), v) \
                + self.r.gravity_comp()              # 载荷由重力补偿承担，而非刚度
        ok = self.tank.admit(F_cmd.dot(v), dt)       # 能量/储备许可
        if not ok: F_cmd, self.Z_d = self.fallback(self.Z_d, self.tank)
        return self.r.command(F_cmd), v, F

    def fallback(self, Z_d, tank):                   # 定义 320：接触中软，自由中刚
        c = self.regime()
        if c == 'free':    return soften_to_rigid(Z_d)
        return soften_damping_dominant(Z_d, self.Kmin, tank.reserve)

# IP-265 ETL：能量账本 + 载荷预留
class EnergyTank:
    def __init__(self, E_max, reserve): self.E, self.Emax, self.reserve = E_max, E_max, reserve
    def admit(self, p_out, dt):                      # 只允许在储备之上支出
        if p_out > 0 and self.E - p_out*dt < self.reserve: return False
        self.E = min(self.Emax, self.E - p_out*dt)
        return True
    def recharge(self, p_diss, dt):                  # 仅耗散回充
        if p_diss >= 0: self.E = min(self.Emax, self.E + p_diss*dt)

# IP-266 DCC：对偶控制刚度选择（一维搜索，能量货币）
def choose_kappa(theta_post, budget, Z_task, Z_info):
    best = None
    for kappa in linspace(0, 1, 11):
        Z_d   = blend_z(Z_task, Z_info, kappa)
        if min_stiffness(Z_d) < K_MIN_LOAD:      continue   # 定义 322-iii
        voi   = expected_info_gain(theta_post, Z_d)          # 定义 314
        e_inj = expected_injected_energy(Z_d)
        regr  = task_regret(Z_d, Z_task)
        score = voi - BETA*max(0, e_inj) - GAMMA*regr
        if best is None or score > best.score: best = (kappa, score)
    return best[0] if best else 0.0

# IP-267 HMI：触觉阻抗估计 + 持续性激励指标
def haptic_estimate(port_hist, theta_prior):

    pe = lambda_min(fisher_info(port_hist, theta_hat))      # 定义 315
    return theta_hat, P, pe

# IP-268 RD：带滞回与最坏情况迟滞的区制判定
def detect_regime(F_ext, E_port, theta_hat, vision):

          ('contact' if contact_evidence(F_ext, E_port, theta_hat) else 'free')

# IP-269 CEC：跨模态能量一致性复核
def energy_consistency(claim, port_hist):

    D_E    = wasserstein1(E_pred, port_hist.E)

# IP-275 主闭环（继承 FLUID-RAS，替换/插入接触层）
```

## 3. 推导

**引理 19（对偶控制的刚度—辨识单调权衡）** 设人/环境为线性定常阻抗 `θ_h=(M_h,D_h,K_h)`，接口为 `Z_d`，端口受平稳激励。则 `θ_h` 的 Fisher 信息 `ℐ_h` 随端口导纳幅值 `|Y_d(jω)|²` 增大而增大，而 `|Y_d|` 关于 `K_d` 单调不增；故 `∂ρ_pe/∂K_d ≤ 0`。同时跟踪误差 `E_task ∝ 1/|Z_d|`（对同一位移扰动），故 `∂Regret_task/∂K_d ≤ 0`。二者构成单调权衡，`κ*` 为某个标量凹问题的一维解。系：**歧义（U_int）越大、能量越充裕，越应偏离刚性；反之应贴回刚性（R69）**。这与 R69 引理 16 的「可分的歧义才值得交互」同构，但这里的「可分辨性」是**可激励性**（PE），而非模态间距。

**引理 20（passivity 给出耦合稳定；硬包络是刚性极限）** 在 A100（接口与人为被动端口、采样足够快、混合连续）下，端口互联的 L2 增益有界，耦合系统稳定；而 R69 的 C-RAS-WM 只约束逐点 `(F,x)`，对未知 `θ_h` 不能排除由刚度引发的自激。令 `K_d→∞`，端口退化为运动学约束，PAC 的可容许集收敛到 R69 的前缀认证集，passivity 条件被包络条件蕴含。故 **C-RAS-WM = PORT-RAS 的 K_d→∞ 边界**（定义 326）。

**引理 21（触觉欺骗的能量下界，以及对 R69 投毒上界的强化）** 任何使测得端口能量轨迹偏离真实轨迹 ΔE 的物理装置，其净做功 ≥ |ΔE|（工作–能定理），故 `π_haptic ≥ π_0 > 0`，而 `π_language ≈ 0`。在能量受限对手（A99：总能量 ≤ E_adv）下，可实现的欺骗幅度 `δ ≤ E_adv/π_0` 有上界；于是把 R69 引理 18 中「源间欺骗相关 ρ<1」替换为**由物理强制的独立下界** `ρ_h ≤ 1 − π_0 δ/E_adv < 1`，k 源多数一致的错误率上界随之严格降低。系：**触觉是 R69「问错」风险的物理对冲**——不是因为力传感器更准，而是因为**造假要付能量**。

**定理 18（区制相关保守与 R69 的严格包含）** 在 A95–A100 下：(a) 自由空间（`F_ext≡0`）中 PORT-RAS 的可容许动作集与 R69 相同，行为逐指令一致；(b) 接触中 PORT-RAS 的可容许集包含 R69 的（多出顺从方向），且其 fallback 满足 `E_port ≤ 0`、`K_d ≥ K_min_load`、`‖Ż_d‖≤ρ_max`，故不会因保守动作本身造成压伤或掉载；(c) 任意 `κ`、任意区制切换的期望风险不高于「按 R69 刚性执行 + 事后包络」策略（后者在 `θ_h` 未知时无耦合稳定保证）。因此 R70 在安全侧严格强于 R69，在效率侧获得「用顺从换辨识」的收益。

**定理 19（无跳变与能量安全）** 由定义 321 的 C¹ 混合与速率上界，任意阻抗切换（task↔info、free↔contact、fallback、κ 更新）产生的力/加速度瞬态有界，R67/R68 的提交/换装不变式保持 ⇒ 无突变。由定义 316 的储备约束与 passivity observer，任何 fallback 与攻击响应都不会使 `E_tank < E_reserve`，也不会命令低于载荷保持所需的力；故「能量槽耗尽攻击」至多使系统进入**阻尼主导的顺从态**，不会触发刚性突变。

## 6. 本轮最大风险

**一句话**：PORT-RAS 把安全性押在「自由 / 接触 / 人主动」这一区制判定的正确性上，而**保守方向恰好在区制边界两侧相反**——把接触误判为自由会让系统该软不软（按 R69 收紧、刚性化而压伤），把自由误判为接触会让系统该硬不硬（软化而掉载/漂移），且最危险的瞬态正好发生在判定边界，还能被一次外部力注入（区制欺骗）有意触发；**判错区制，比不判更危险**。

**次级风险与缓解**：
1. **passivity 只保证稳定、不保证安全**（被动系统也能缓慢压伤）→ PAC 三件套（passivity + 包络 + `K_min_load`）+ 定理 18(b)；
2. **能量槽被耗尽逼出 fallback** → `E_reserve` 载荷预留 + 阻尼主导的顺从 fallback（定理 19），并显式纳入 ℰ_tank；
3. **区制欺骗 / 边界抖振** → 滞回 + 最小驻留 + 双证据 + 最坏情况迟滞（定义 319），E302/E309；
4. **`U_int` 不可辨识时误当可辨识** → `ρ_pe` 门控：激励不足即令 `U_int` 保持未消解并贴回刚性（R69 边界）；
5. **阻抗切换瞬态** → C¹ 混合 + 速率上界 + 前馈力补偿（定义 321，定理 19）；
6. **语言接地幻觉仍在** → 继承 R69 冻结 LLM + 解码过滤 + 新增 CEC 物理复核。

**定义 311–312（端口与阻抗调度）** port-Hamiltonian `ẋ=(J−R)∇H+Gu+G_int F_ext`，`y=v`；执行与测量共用端口。`Z_d=Blend(Z_task,Z_info,κ)`，`K_d(κ)` 单调连续；κ 为对偶旋钮。

**定义 313–314（U_int 与对偶目标）** 三分 `(U_ale,U_epi,U_int)`，`U_int=H(θ_h|hist)`；`J_dual=VoI_h−βE_inj⁺−γRegret_task−c_social`，s.t. PAC/预算；无接触时 κ 不可辨识、退化 `κ=1` 与 R69 MINT。

**定义 315（HMI）** RLS/KF 估 `θ_h`；`ρ_pe=λ_min(ℐ_h)`；`∂ρ_pe/∂K_d≤0`、`∂Regret/∂K_d≤0`（引理 19）。

**定义 316–317（ETL 与触觉欺骗下界）** 能量账本只在储备之上支出、只从耗散回充；任何能量轨迹欺骗须净做功 ≥|ΔE|，故 `π_haptic≥π₀>0`、`π_language≈0`。

**定义 318（CEC）** 断言 c 预测 `Ê_c`，与实测 `E_port` 求 `D_E=W₁`；矛盾则降语言/视觉权重、升触觉权重，并交审计；单次矛盾不定案。

**定义 319–320（RD 与保守反转）** 三区制 + 滞回 + 驻留 + 双证据；保守映射：free→`λ↑,v↓,κ→1`；contact→`κ→0,D_d↑,K_d≥K_min_load`；human-active→阻尼耗散、禁止用刚度硬顶。**增阻尼普适保守，增刚度仅自由空间保守**。

**定义 321（无跳变混合）** `Z(τ)=Blend(Z_a,Z_b,σ(τ))`，`σ` 为 C¹、`‖Ż_d‖≤ρ_max`，切换期加前馈 `Z(τ)v`；禁止直跳刚性。

**定义 322（PAC 联合证书）** (i) `E_obs≥−ε_p ∧ E_tank≥E_reserve`；(ii) 力/位包络；(iii) `K_d≥K_min_load`；(iv) `‖Ż_d‖≤ρ_max`；(v) human-active 下 `E_port≤E_budget`。passivity=稳定、包络=瞬态安全、`K_min_load`=不塌陷，不可互替。

**定义 323–325（预算/威胁/证书）** 预算改为能量货币并分可动/预留；证据纪律「力证据默认优先于语言」；`ℰ_PORT=ℰ_FLUID×ℰ_regime×ℰ_tank`；`J_PORT` 并入 passivity_margin、tank_min、k_min_margin、pe_index、π_c、Ż_max、regime_log_hash。

**定义 326–327（退化与时序）** `K_d→∞,F_ext≡0,E_budget→∞` 时 PORT-RAS 逐项退化为 FLUID-RAS（`J_dual→VoI−c`，`FallbackMap→λ↑`）；内环 1kHz、外环 <2.75ms 双时间尺度。

## 3. 关键算法伪代码

```python
# IP-264 PII：端口阻抗接口（执行与测量共用端口）
class PortImpedanceInterface:
    def render(self, Z_d, dt):                        # 1kHz 内环
        self.Z_d = bumpless_blend(self.Z_d, Z_d, self.rho*dt)   # 定义 321
        v, F = self.robot.port_state()                # 同端口测量
        F_cmd = self.Z_d.apply(self.robot.pose_error(), v) \
                + self.robot.gravity_comp()           # 载荷由重力补偿承担
        if not self.tank.admit(F_cmd.dot(v), dt):     # 能量/储备许可
            F_cmd, self.Z_d = self.fallback(self.Z_d, self.tank)
        return self.robot.command(F_cmd), v, F

    def fallback(self, Z_d, tank):                    # 定义 320：区制相关
        if self.regime == 'free': return soften_to_rigid(Z_d)
        return soften_damping_dominant(Z_d, K_MIN_LOAD, tank.reserve)

# IP-265 ETL：能量账本 + 载荷预留
class EnergyTank:
    def admit(self, p_out, dt):
        if p_out > 0 and self.E - p_out*dt < self.reserve: return False
        self.E = min(self.Emax, self.E - p_out*dt); return True
    def recharge(self, p_diss, dt):
        if p_diss >= 0: self.E = min(self.Emax, self.E + p_diss*dt)

# IP-266 DCC：对偶控制刚度选择（一维，能量货币）
def choose_kappa(theta_post, E_budget, Z_task, Z_info):
    best = None
    for kappa in linspace(0, 1, 11):
        Z_d = blend_z(Z_task, Z_info, kappa)
        if min_stiffness(Z_d) < K_MIN_LOAD: continue
        score = (expected_info_gain(theta_post, Z_d)
                 - BETA*max(0, expected_injected_energy(Z_d))
                 - GAMMA*task_regret(Z_d, Z_task))
        if best is None or score > best.score: best = (kappa, score)
    return best[0] if best else 0.0

# IP-267 HMI：触觉估计 + 持续性激励
def haptic_estimate(port_hist, theta_prior):
    theta_hat, P = rls_update(theta_prior, port_hist)
    return theta_hat, P, lambda_min(fisher_info(port_hist, theta_hat))

# IP-268 RD：带滞回的区制判定
def detect_regime(F_ext, E_port, theta_hat, vision):
    raw = ('human-active' if (E_port > 0 and sustained_push(F_ext)) else
           ('contact' if contact_evidence(F_ext, E_port, theta_hat, vision) else 'free'))
    return hysteresis(raw, self.prev, enter_thr, exit_thr, min_dwell)

# IP-269 CEC：跨模态能量一致性
def energy_consistency(claim, port_hist):
    D_E = wasserstein1(expected_energy_under(claim), port_hist.E)
    return D_E, (D_E > TAU_E)                         # 矛盾 => 触觉优先

# IP-275 主闭环（继承 FLUID-RAS，替换/插入接触层）
def PORT_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    c_reg = M.rd.update(M.last_F, M.tank.E_port, M.theta_hat, vision(o))
    theta_hat, P, pe = M.hmi.update(M.port_hist); U_int = entropy_of(P)
    if c_reg == 'free': kappa, g = 1.0, M.mint.choose(modes, o, M.budget)  # R69 边界
    else:               kappa, g = M.dcc.choose(U_int, M.tank, M.Z_task, M.Z_info), None
    Z_d = blend_z(M.Z_task, M.Z_info, kappa)
    D_E, contradict = M.cec.check(M.last_claim, M.port_hist)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if contradict: lam = max(lam, 0.6)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if c_reg != 'free': Z_d = M.fallback_map(c_reg, Z_d, M.tank)   # 定义 320
    F_cmd, v, F = M.pii.render(Z_d, dt=1e-3)          # 1kHz 内环
    M.vqa_i.submit_async(g, kappa, D_E, U_int, M.tank)
    return k, lam, Z_d, mode_select(modes, U_epi, lam), (U_ale, U_epi, U_int)
```

## 4. 推导

**引理 19（刚度—辨识单调权衡）** 线性定常 `θ_h`、平稳激励下，Fisher 信息 `ℐ_h` 随端口导纳 `|Y_d(jω)|²` 增大；`|Y_d|` 关于 `K_d` 单调不增 ⇒ `∂ρ_pe/∂K_d≤0`；跟踪误差 `E_task∝1/|Z_d|` ⇒ `∂Regret/∂K_d≤0`。二者构成单调权衡，`κ*` 为一维解。系：**`U_int` 越大、能量越充裕，越应偏离刚性；反之贴回刚性（R69）**——与 R69 引理 16 同构，但可分辨性换成可激励性（PE）。

**引理 20（passivity 稳定；包络是刚性极限）** A100 下端口互联 L2 增益有界、耦合稳定；R69 包络只约束逐点 `(F,x)`，对未知 `θ_h` 不能排除刚度自激。`K_d→∞` 时端口退化为运动学约束，PAC 可容许集收敛到 R69 前缀认证集 ⇒ **C-RAS-WM = PORT-RAS 的 K_d→∞ 边界**。

**引理 21（触觉欺骗能量下界 → 强化 R69 投毒上界）** 使端口能量轨迹偏离 ΔE 的物理装置净做功 ≥|ΔE|，故 `π_haptic≥π₀>0`、`π_language≈0`。能量受限对手（A99）下欺骗幅度 `δ≤E_adv/π₀`；把 R69 引理 18 的「源相关 ρ<1」替换为物理强制下界 `ρ_h≤1−π₀δ/E_adv<1`，k 源多数一致错误率上界严格降低。系：**触觉是「问错」风险的物理对冲——不是力传感器更准，而是造假要付能量**。

**定理 18（区制相关保守与 R69 严格包含）** A95–A100 下：(a) 自由空间 `F_ext≡0` 时与 R69 逐指令一致；(b) 接触中可容许集包含 R69 的（多出顺从方向），fallback 满足 `E_port≤0`、`K_d≥K_min_load`、`‖Ż_d‖≤ρ_max`，不因保守动作压伤或掉载；(c) 任意 κ 与切换的风险不高于「R69 刚性执行 + 事后包络」。安全侧严格强于 R69，效率侧获「顺从换辨识」收益。

**定理 19（无跳变与能量安全）** C¹ 混合 + 速率上界 ⇒ 任意阻抗切换的力/加速度瞬态有界，R67/R68 提交/换装不变式保持 ⇒ 无突变。储备约束 + passivity observer ⇒ fallback/攻击响应不会使 `E_tank<E_reserve`，也不会命令低于载荷保持所需的力；能量槽耗尽攻击至多使系统进入阻尼主导的顺从态，不触发刚性突变。

## 7. 本轮最大风险

**一句话**：PORT-RAS 把安全性押在「自由 / 接触 / 人主动」这一区制判定的正确性上，而**保守方向恰好在区制边界两侧相反**——把接触误判为自由会让系统该软不软（按 R69 刚性化而压伤），把自由误判为接触会让系统该硬不硬（软化而掉载/漂移），且最危险的瞬态正发生在边界，还能被一次外部力注入（区制欺骗）有意触发；**判错区制，比不判更危险**。

**次级风险与缓解**：passivity 只保证稳定不保证安全（PAC 三件套 + 定理 18b）；能量槽耗尽逼出 fallback（`E_reserve` 载荷预留 + 阻尼主导顺从，定理 19，ℰ_tank）；区制欺骗/边界抖振（滞回 + 驻留 + 双证据 + 最坏情况迟滞，E302/E309）；`U_int` 不可辨识时误当可辨识（`ρ_pe` 门控，激励不足即贴回刚性）；阻抗切换瞬态（C¹ 混合 + 速率上界 + 前馈，定理 19）；语言接地幻觉（继承 R69 冻结 LLM + 解码过滤 + CEC 物理复核）。
