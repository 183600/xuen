# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「机器人」×「目标检测」）

> R69 问「我该向谁求证、还能问什么」，并把不确定性拆成 aleatoric / epistemic；但它整座大厦压在一个未经审视的输入上：`z_t = MTM trunk(o_t)`。**它默认世界已经被解析成「对象」了**——可那些对象从哪来？从一个检测器。整条 R66–R69 谱系把目标检测当作"眼睛"甚至"神谕"：闭集标签、点估计框、NMS 抑制后的峰、未校准的分数。于是出现一个范畴错误：**计划器以为自己在对"世界"做安全认证，其实只在对"检测器的意见"做认证**。检测输出是假设，不是事实；分数不是概率；NMS 不是贝叶斯。
>
> 本轮两个灵感正好从两个方向刺入这个缺口：
> - **目标检测**暴露它最危险的失败模式——漏检（存在性错误）、开集未知（有物无类）、类别混淆、范围/定位误差、重复抑制、跨帧身份切换；这些都不是"精度再高一点"能解决的，而是**证书必须显式消费的假设集**；
> - **机器人**给出一个被动检测器永远没有的自由度——**身体**：视角、位姿、光照、遮挡、自身运动都在机器人控制之内。机器人可以"走过去看清楚"，也可以"慢下来不糊"。检测因此不是一条只读的感知馈送，而是**可与任务动作联合规划、认证、审计的闭环动作**。
>
> 核心命题：**把检测从「点估计」升级为「控制证书相关的假设集」；让机器人用具身信息动作去缩小那些"会改变认证安全动作"的假设；缩不小、超预算、或覆盖率不可信时，逐指令退化到 R69 / R68 的保守。** 命名 **SIGHT-RAS**（Set-valued, Information-Gated, Hypothesis-Tracking Risk-Adaptive Safety）——sight 双关「看」与「视力」：**不是看得更准，而是知道自己看得有多清、并为此负责。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问 **「那里到底有什么」**——检测不是一个框，而是一组被证书消费的假设；因为机器人会动，"看清"本身就是一个可规划、可认证、可审计的动作。

## 0. 直觉与动机

**灵感 1（检测输出是假设，不是事实）**
直觉：检测器吐出的是「NMS 之后还剩的几个框 + 分数」。0.9 不是 P(有物体)，只是"这个候选比别的更像训练集正样本"。两个真实的重叠物体可能被 NMS 合成一个；一个小目标可能因分数低被删掉；一个新奇物体可能被强行塞进最近的已知类。下游计划器却把这份 `list[obj]` 当世界真值用。安全认证最怕的不是"框偏了 5 像素"，而是**真实存在的危险物体根本不在列表里**——这是单侧的、灾难性的存在性错误，被 mAP 的平均掩盖得一干二净。

**灵感 2（机器人 → 检测是具身的、可控的）**
直觉：对一台真实机器人，"检测"不是一个固定相机上的被动函数。相机在云台上/在头上/在手腕上；机器人能转头、能靠近、能绕到另一侧、能开灯、能停下等运动模糊消失、甚至能伸臂拨开遮挡。同一时刻，这些动作也在改变碰撞风险和任务进度。于是检测与控制的耦合是双重的：**动作既推进任务，也改变"我能看清什么"**。这把 R69 的「信息动作」从"问/看/触"推进到"移动到能看见的位置"——next-best-view 不再是感知模块的小技巧，而是安全闭环的一等公民。

**灵感 3（控制等价 → 精度是错的度量）**
直觉：IoU 高不代表安全，IoU 低不代表不安全。一个"儿童 vs 墙"的分类错，框可能几乎重合但安全动作完全不同；而两个框差 30 厘米的同一堵墙，可能对避障决策完全等价。安全真正在乎的是：**在这个假设下，认证的安全动作集合 / 最坏风险是否改变**。定义控制等价距离 d_ctrl 后，共形预测应在 d_ctrl 上校准，而不是在 IoU 上校准。结果是：**预测集的大小随局部控制敏感度自适应**——近碰撞、高动态、遮挡区自动给出更大的假设集、更多审视；空旷区则最小化。

**灵感 4（存在性是最危险的维度）**
直觉：检测误差有四种——存在性、身份、范围、运动；它们的危险程度极不对称。**漏检是单侧灾难**：一个真实存在的物体不在假设集里，任何基于"假设集覆盖真值"的认证都失效。开集未知更糟：物体存在，但没有类。用闭集 argmax 处理未知，等于把"我不知道"强行翻译成"它是某个已知类"，这是把诚实的不知道升级成自信的错误——正是 R69 自陈的最大风险在感知层的翻版。所以 OSM 必须把未知实体升格为**有界的最坏情形假设类**，而不是一个标签。

**灵感 5（时间：检测频率 ≠ 控制频率）**
直觉：检测常在 10–30Hz，控制在 100–1000Hz。两次检测之间，物体状态靠世界模型外推；外推误差、身份切换（ID switch）、检测时滞，都会以"看起来像运动"的方式变成不安全。检测不是每帧都有的事实，而是**带时间戳的、会过期的证据**。所以需要一本"时间-检测账本"：谁在什么时候被看见、身份置信如何、漂移界多大、何时必须重新检测。这与 R68 的标定时间窗是同一类结构，只不过对象从"传感器偏置"变成"物体状态"。

**灵感 6（反馈回 R69：检测既是交互的输入端，也是输出端）**
直觉：R69 的 VoI 是在"动作模态分布"上算的，可那些模态是**以检测为条件**的。如果检测集漏了物体/身份错了，VoI 就在一个幻影世界上计算，越算越自信地做错事。反过来，R69 的看/问/触恰好可以用来消解检测歧义：那是"看它到底是不是那个东西"，是"再换个角度确认它在不在"。**SIGHT 把检测集喂给 R69，R69 的信息动作再回来缩小检测集**。两层消歧共享同一个预算与证据纪律。

**灵感 7（机器人特有的一刀：速度也是感知变量）**
直觉：机器人动得越快，运动模糊越重、检测越糊、覆盖率越差——但"慢"本身不是免费的，它偷走任务时间，也可能让动态障碍更危险。于是存在一个**感知保真速度包络**：在遮挡/拥挤/纹理贫乏区，为了保住检测覆盖率，机器人必须把速度压到某个 v_max 以下；这不是碰撞约束，而是**认识论约束**。如果这个包络把速度压得太低，正确的反应不是"慢慢挪"，而是"换条路 / 先停下看清楚 / 主动重新感知"。这把 R68 的 λ 风险缩放扩展成一条"速度即感知"的耦合约束。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SIGHT-RAS 总览）** SIGHT-RAS = (DHG, CCS, APX, OSM, TDL, PFE, SDK, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **集合消费**：任何安全/风险计算必须对证书检测集 Ĉ 中的**所有**假设成立，或显式退化；禁止只对 argmax 检测认证；
(iii) **检测不可自证**：检测置信/自洽不得用来证明自身覆盖；覆盖只能来自留出共形校准，且一旦分布漂移或过期即失效；主动重新检测只有在"机制独立性"被认证时才算新证据；
(iv) **预算与认证继承**：具身信息动作（换视角/靠近/照明/减速停等）与任务动作共用 R69 的交互预算与 C-RAS-WM 认证，不得越出物理/社交包络。

**定义 311（检测假设空间 DHG）** 一个物体假设 h = (e, ℓ, B, v, τ)：存在性 e∈{0,1}、标签 ℓ∈L∪{⊥}（⊥=未知）、范围/位姿 B、运动 v、时间戳 τ。场景 ω 是物体假设的集合（含机器人自身）。检测器 D: o ↦ {(h_i,s_i)}；**s_i 不被解释为概率**。下游消费的不是 argmax，而是候选假设集 H(o)。引入候选生成器 Gen(o)（低阈值 + 测试时增强 + 开集提议），以保证 H(o) 尽量包含真值，但**其完备性本身是未验证假设**（见本轮最大风险）。

**定义 312（控制等价距离）** 给定状态 s、认证风险 R(a|ω)（由 RAS-WM/R68/R69 给出）与安全动作集 A_safe，
d_ctrl(ω, ω') = sup_{a∈A_safe} |R(a|ω) − R(a|ω')|
（可按任务重要性加权）。ω,ω' ε-控制等价 ⇔ d_ctrl ≤ ε。到集合的距离 d_ctrl(ω, Ĉ) = min_{h∈Ĉ} d_ctrl(ω, h)。**这是替代 IoU 的"安全相关"误差度量。**

**定义 313（控制相关共形检测集 CCSet）** 留出校准集 {(ω_i, o_i)}，非一致性分 s_i = d_ctrl(ω_i, D(o_i))（不可直接算时用单调代理，如"该假设是否改变认证安全动作"的 0/1 或风险差上界）。阈值 q̂ 取 ⌈(n+1)(1−α)⌉/n 分位。Ĉ_α(o) = {h ∈ H(o) : d_ctrl(h, D(o)) ≤ q̂}。在可交换性下：
P( d_ctrl(ω, Ĉ_α(o)) ≤ q̂ ) ≥ 1−α。
注意：覆盖是在**控制度量**下的覆盖，不是 IoU 覆盖；集合大小随局部控制敏感度自适应。

**定义 314（检测不确定性分解）** U_det = (U_exist, U_ident, U_extent, U_kin)，每维标注 aleatoric/epistemic 并乘以控制权重 w_ctrl：传感器噪声→aleatoric；开集/遮挡/身份歧义→epistemic（可由主动感知约减）。映射到 R69 的 (U_ale, U_epi)：检测的不确定性不直接加进 λ，而是经**认证间隙**（定义 320）进入。

**定义 315（存在性与漏检风险）** R_miss(ω) = 对所有"存在但不在 Ĉ 中"的真实物体取其最坏控制风险。单侧证书：危险失败是 e=1 却不在假设集。故检测评价应使用**控制关键严重度下的最坏召回**，而不是 mAP。

**定义 316（信息导向具身视角规划 APX）** 信息动作在 R69 的 𝒜_info 上增广视角/照明/停等：g = (g_gaze, g_probe, g_ask, v_view, g_light, g_hold)。VoI_ctrl(g) = E[d_ctrl(ω, Ĉ)|o] − E[d_ctrl(ω, Ĉ)|o,g]。选 g* = argmax[VoI_ctrl(g) − c(g)]，s.t. C-RAS-WM 认证、可达性/遮挡/运动模糊可行、预算未超。若 max ≤ 0：不主动感知，退化 R69。

**定义 317（开集未知 OSM）** 当 ℓ=⊥ 或 OOD 分超阈，用**有界最坏情形假设类** 𝒲_⊥（物理可行动范围/尺寸/动力学上下界）替换未知实体，对 𝒲_⊥ 计算风险。若最坏风险 > ε，必须"获取信息或停/退"，**"未知"不等于"可忽略"**。已知类不得吞并未知：标签必须可拒绝。

**定义 318（时间-检测账本 TDL）** 检测频率 f_det、控制频率 f_ctrl。两次检测间用 WM 外推，漂移界 δ(Δτ)（引理 23）；身份是带切换罚的隐变量；当预测控制风险区间越阈或身份熵越界时触发**重检测**。时滞 τ_stale 映射到 U_kin 与证书（定义 320）。

**定义 319（感知保真速度包络 PFE）** 检测覆盖随自运动模糊/角速度/纹理/遮挡下降；定义 v_max(o) 使经验覆盖 ≥ 1−α，得"覆盖率保持速度包络" v_cov(s)。控制器速度 v ≤ min(v_collision, v_cov)。若 v_cov 过低，触发"主动重感知/改道/停等"，而不是无限减速。

**定义 320（检测-控制闭环证书 J_SIGHT）** J_SIGHT = (J_FLUID, coverage_{1−α}, coverage_emp, set_size, d_ctrl_margin, R_miss_bound, ood_flag, τ_stale_bound, drift_bound, vel_cov_ok, apx_log_hash, sight_ver)。Valid ⇔ Valid(J_FLUID) ∧ 覆盖率已被留出校准认证 ∧ R_miss ≤ ε_miss ∧ τ_stale ≤ τ_max ∧ 无未处理未知 ∧ 速度在感知保真包络内。

**定义 321（两级退避继承）** 若覆盖不可认证（漂移）、未知不可界、或主动感知预算耗尽：U_det 视为未消解，λ = λ_floor(U_ale + U_det_unresolved)，退化 R69；若 R69 的 VoI 也不划算，退化 R68。当 Ĉ 为单例、控制等价间隙为 0、且无未知时，SIGHT 与 R69 **逐指令相同**（定理 18）。

**定义 322（检测不可自证禁令）** 一个检测假设不得作为自身正确性的证据；覆盖只能来自留出校准。主动重新检测只有在视角/机制被独立认证为"信息性"时才算独立证据；否则"我又看了一眼，检测器还是这么说"是感知版的回音室。此即 R69 证据纪律在感知层的落地。

**定义 323（对抗与投毒威胁 ℰ_SIGHT）** 对抗贴片（同时隐藏真物与伪造幻影）、LiDAR/相机欺骗、开集伪装（把 OOD 物体装饰成已知类）、共形校准集投毒（毒化 q̂ 使覆盖虚假）。ℰ_SIGHT = ℰ_FLUID × ℰ_patch × ℰ_open × ℰ_calpoison。校准集完整性本身需审计。

**定义 324（参与式审计 VQAuditor-S）** 审计检测决策：真值是否被 NMS 抑制、低分真物是否被丢、未知是否被强行归类、主动感知是"真获取信息"还是"重确认偏置"、覆盖率是否在漂移后仍被宣称。结论回灌 AuditBuf，成为下一轮校准与 APX 成本先验。

**定义 325（覆盖率漂移与撤回）** 可交换性是覆盖保证的承重墙。定义漂移检验与**在线重校准 + 弃权**：一旦检出漂移，证书立即撤回覆盖声明并转保守（R69/R68），绝不"悄悄沿用旧保证"。这与 R68 的标定抗漂移同构，对象从传感器换成检测分布。

**定义 326（本体自模型与遮挡 SDK）** 机器人自身既是遮挡体，也是唯一有精确先验的"物体"：本体感知给出自由、无检测误差的自身假设，必须在检测中排除、在碰撞检查中纳入。自模型与"被检测到的自己"不一致，是独立故障信号（本体/外参/同步）。

```python
# IP-264 DHG：把任意检测器包成"候选假设集 + 不可信分数"
def detection_hypotheses(detector, o, tau_low=0.05, tta=4):
    raw  = detector(o, score_thresh=tau_low)          # 低阈值，不压成单峰
    raw += detector.tta(o, n=tta)                     # 多尺度/翻转/低阈值
    raw += detector.open_set_proposals(o)             # 开集提议
    return dedup(raw, iou=0.9)                        # 只去重，不取 argmax

# IP-265 CCS：控制相关共形集（在 d_ctrl 上校准，而非 IoU）
def calibrate_ccs(calib, alpha):
    scores = [d_ctrl(omega, detector(o)) for omega, o in calib]
    return quantile(scores, ceil((len(scores) + 1) * (1 - alpha)) / len(scores))

def control_set(H, D_hat, q_hat):                      # 定义 312–313
    return [h for h in H if d_ctrl(h, D_hat) <= q_hat]

# IP-266 APX：具身 next-best-view + 停等/照明，VoI 不够就不动
def choose_apx(H, o, budget):
    best = None
    for g in info_action_candidates(H):               # 视角/照明/停等/靠近
        if not budget.allow(g):                    continue
        if not c_ras_wm.certify_info(g, o):        continue   # R69 定义 302
        if not feasible_view(g, o):                continue   # 遮挡/可达/模糊
        score = (expected_dctrl(H, o) - expected_dctrl(H, o, g)) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 无利可图 → R69

# IP-267 OSM：未知实体 → 有界最坏情形类，绝不吞并成已知类
def open_set_envelope(H):
    out = []
    for h in H:
        out += [h] if h.label != UNKNOWN else worst_case_class(h.bounds)
    return out                                         # 对类上界算风险

# IP-268 TDL + IP-269 PFE：时间账本与感知保真速度
def temporal_ledger(track, wm, dt):
    track.propagate(wm, dt)
    if track.risk_interval_crosses(TAU) or track.ident_entropy > TAU_ID:
        trigger_redetect(track)                        # 定义 318
    v_cov = coverage_preserving_speed(track, alpha)    # 定义 319
    return track, v_cov

# IP-270 SDK：本体自模型（排除自身 + 自检故障）
def self_model(o_det):
    self_h  = proprioception_as_object()               # 精确先验
    det_self = nearest(o_det, self_h)
    fault   = self_h.mismatch(det_self)                # 外参/同步/本体故障
    return self_h, fault

# IP-274 主闭环（继承 R69，把"检测点估计"换成"证书集合"）
def SIGHT_RAS_round(M, o):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    self_h, fault = M.sdk.step(o)
    H = M.dhg.hypotheses(o)
    H = [h for h in H if not h.overlaps_self(self_h)]  # 排除自身遮挡/自检
    H = M.osm.envelope(H)                              # 未知 → 最坏界
    C_hat = M.ccs.filter(H)                            # 控制相关共形集
    # 1) 集合而非点估计进入 R69 的二分
    samples = M.fmp.sample(o, K=adaptive_K(C_hat))
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    # 2) 集合风险高 → 主动具身感知（看/靠近/停/照明）
    g = (M.apx.choose(C_hat, o, M.budget)
         if (set_risk(C_hat) > TAU_SET and not fault) else None)
    if g is not None:
        o2 = M.embodied_execute(g)
        C_hat = M.ccs.filter(M.dhg.hypotheses(o2))
        U_epi = M.cia.update_belief(modes, C_hat)      # 集合收缩 = 消歧
    # 3) 时间账本：时滞/漂移 + 重检测触发
    track, v_cov = M.tdl.step(C_hat)
    # 4) 证书：集合内所有假设都要安全，否则退化
    if (not M.ccs.coverage_valid()) or fault or set_risk(C_hat) > TAU_SET:
        lam = lam_floor(U_ale + U_epi); k = k_safe_min(...)   # 退化 R69/R68
    else:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))
        k = M.c_ras_wm.certified_prefix(M.ach.propose(...),
                                        H=C_hat, wm_preds=...)
    v = min(M.speed_cmd, v_cov)                        # 感知保真速度包络
    # 5) 审计 + 证书（集合而非单点）
    M.vqa_s.submit_async(g, C_hat, set_risk(C_hat), M.ccs.coverage_stat())
    return clip_speed(v), lam, k, C_hat, J_SIGHT(...)
```

## 3. 推导

**引理 19（控制相关共形覆盖）** 在可交换性下，定义 313 的 Ĉ_α 满足 P(d_ctrl(ω, Ĉ_α) ≤ q̂) ≥ 1−α；且集合期望大小随局部控制敏感度（d_ctrl 的尾部厚薄）单调增加。系：**在不该省的地方给大集合，在该省的地方给单例**——覆盖的是"控制相等"，不是"框相等"。

**引理 20（集合 → 风险上界）** 若真实 ω 与某 h∈Ĉ 满足 d_ctrl ≤ ε，且对所有 h∈Ĉ 有 R(a|h) ≤ ρ，则 R(a|ω) ≤ ρ + ε。系：证书必须对集合量化；扩大集合在提高覆盖的同时提高保守度，二者构成可显式权衡的预算曲线。

**引理 21（APX 的 VoI 单调与退化）** 对关于假设的贝叶斯后验，任一信息动作的期望 d_ctrl 不增（期望 VoI ≥ 0）；若 VoI_ctrl(g*) ≤ c(g*)，则不动是局部最优，且 SIGHT 的决策层与 R69 逐指令一致。注意实现值可为负，故须预算与认证兜底。

**引理 22（开集单侧界）** 以最坏类 𝒲_⊥ 替换未知，得 R(a|ω) ≤ sup_{w∈𝒲_⊥} R(a|w)；代价是保守。系：强行为未知贴已知标签时，若真实类几何/动力学与所贴类不同，风险无界；"未知"必须被处理或回避，不能被平均掉。

**引理 23（检测时滞漂移界）** 若物体状态 L_v-Lipschitz、最大检测间隔 Δ，则运动学不确定度增长 ≤ L_v·Δ + σ_0；在 Δ* ≤ (τ_max−σ_0)/L_v 处触发重检测可保证书有效。系：**检测频率由证书反推，而不是调参旋钮。**

**引理 24（感知保真速度）** 若在有限曝光下覆盖率随速度/模糊单调下降，则存在 v_cov(α) 使覆盖 ≥ 1−α；裁剪 v ≤ v_cov 保持检测证书。系：当 v_cov 低于任务可行速度时，"主动重感知/改道/停等"严格优于无限减速——慢也会把风险变成另一种风险。

**定理 18（SIGHT 严格包含 R69）** 在 A99（Ĉ 为覆盖已认证的单例）、A100（控制等价间隙 = 0）、A101（无未知、无时滞越界）下，SIGHT 与 R69 逐指令相同；一般情况下，SIGHT 在集合上认证只会更保守，主动感知成功时获得 resolution bonus，失败时按定义 321 单调退回 R69/R68。故安全侧永不弱于 R69，效率侧只在可验证的消歧上获利。

**定理 19（具身交互安全与无突变）** APX 信息动作经 C-RAS-WM 认证 ⇒ 物理风险 ≤ ε_int；检测丢失/时滞越界/覆盖率撤回/未知不可界，全部映射为 λ 非降、速度被裁剪、安全前缀被缩短；由于最终仍走"认证前缀 + 裁剪速度"，控制连续、无突变，继承 R69 定理 17 与 R68 定理 15。

## 6. 本轮最大风险

**一句话**：SIGHT 的覆盖保证是**条件于"候选生成器已经把真值放进了 H(o)"**的——可这正是它想保证的东西：若真物因遮挡、过小、OOD、NMS 抑制或对抗贴片而**从未成为候选**，共形校准对它完全无效，覆盖率仍会漂亮地停在 1−α，而系统恰恰错在"它根本不在集合里"；机器人也无法主动去看一个它不知道存在的东西——**于是 SIGHT 的证书可能只是"覆盖剧场"：在可交换的校准集上完美，对真正致命的漏检零保证。**

**次级风险与缓解**：
1. **校准集投毒/可交换性破坏**（对抗贴片、共形毒化）→ 定义 323/325：漂移检验 + 校准集完整性审计 + 检出即撤回覆盖声明、转保守；
2. **d_ctrl 依赖同一套风险模型**（用被检验的 RAS-WM 去定义"控制等价"）→ 用无模型见证/保守包络做下界，保留 R68 的保守兜底，绝不把 d_ctrl 当绝对真值；
3. **主动感知把机器人带到危险处/耗尽预算** → C-RAS-WM 认证 + VoI−成本 + 定理 19 无突变；
4. **未知最坏界过度保守 → 任务瘫痪** → OSM 有界类 + 主动获取信息 + 预算外退化，而非永久停；
5. **速度包络把速度压得过低** → 引理 24 的"主动重感知/改道"优先于无限减速，避免用慢制造新的动态风险；
6. **NMS/分数仍泄漏进候选生成** → 只降阈不去峰 + NMS-aware 去重 + E313 专门压测重叠真值。

```python
    raw  = detector(o, score_thresh=tau_low)

    samples = M.fmp.sample(o, K=adaptive_K(C_hat))
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    g = (M.apx.choose(C_hat, o, M.budget)
         if (set_risk(C_hat) > TAU_SET and not fault) else None)
    if g is not None:
        C_hat = M.ccs.filter(M.dhg.hypotheses(M.embodied_execute(g)))
        U_epi = M.cia.update_belief(modes, C_hat)
    track, v_cov = M.tdl.step(C_hat)
    if (not M.ccs.coverage_valid()) or fault or set_risk(C_hat) > TAU_SET:
        lam = lam_floor(U_ale + U_epi); k = k_safe_min(...)   # 退化 R69/R68
    else:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))
        k = M.c_ras_wm.certified_prefix(M.ach.propose(...), H=C_hat, wm_preds=...)
    M.vqa_s.submit_async(g, C_hat, set_risk(C_hat), M.ccs.coverage_stat())
    return clip_speed(min(M.speed_cmd, v_cov)), lam, k, C_hat, J_SIGHT(...)
```

## 4. 推导

**引理 19（控制相关共形覆盖）** 可交换性下 `P(d_ctrl(ω,Ĉ_α)≤q̂)≥1−α`；集合期望大小随局部控制敏感度单调增。系：在不该省处给大集合、该省处给单例。

**引理 20（集合 → 风险上界）** 若 ω 与某 h∈Ĉ 满足 `d_ctrl≤ε`，且 ∀h∈Ĉ 有 `R(a|h)≤ρ`，则 `R(a|ω)≤ρ+ε`。系：证书必须对集合量化；集合大小与保守度构成显式预算曲线。

**引理 21（APX 的 VoI 单调与退化）** 贝叶斯后验下信息动作的期望 d_ctrl 不增；若 `VoI_ctrl(g*)≤c(g*)`，不动局部最优，决策层与 R69 逐指令一致。

**引理 22（开集单侧界）** 以 `𝒲_⊥` 替换未知得 `R(a|ω)≤sup_{w∈𝒲_⊥}R(a|w)`；若强行贴已知类且真实类几何/动力学不同，风险无界。

**引理 23（检测时滞漂移界）** 物体状态 L_v-Lipschitz、最大间隔 Δ 时不确定度增长 `≤L_vΔ+σ_0`；在 `Δ*≤(τ_max−σ_0)/L_v` 重检测可保证书有效。系：检测频率由证书反推。

**引理 24（感知保真速度）** 覆盖率随速度/模糊单调下降时存在 `v_cov(α)` 使覆盖 ≥ 1−α；裁剪 `v≤v_cov` 保持检测证书；当 v_cov 低于任务可行速度，"主动重感知/改道/停等"严格优于无限减速。

**定理 18（SIGHT 严格包含 R69）** 在 A99（Ĉ 为覆盖已认证的单例）、A100（控制等价间隙=0）、A101（无未知、无时滞越界）下与 R69 逐指令相同；一般情形在集合上认证只会更保守，主动感知成功给 resolution bonus，失败按定义 321 单调退回 R69/R68 ⇒ 安全侧永不弱于 R69。

**定理 19（具身交互安全与无突变）** APX 信息动作过 C-RAS-WM 认证 ⇒ 物理风险 ≤ ε_int；检测丢失/时滞越界/覆盖撤回/未知不可界均映射为 λ 非降、速度裁剪、前缀缩短；最终仍走"认证前缀+裁剪速度"，控制连续、无突变（继承 R69 定理 17、R68 定理 15）。

## 7. 预期结果与验收口径

- **严格包含**：E309 必须在「单例集合 / 零控制等价间隙 / 无未知 / 无时滞越界」四条件下给出逐指令零差异；否则 R70 是替换而非扩展，方案作废。
- **覆盖不是覆盖剧场**：E301 的覆盖必须在**对抗候选集**（遮挡、小目标、OOD、重叠）上仍成立；若只在干净校准集漂亮、在危险子集崩掉，说明完备性前提未被守住。
- **控制度量优先**：E302 必须显示 d_ctrl 比 IoU/mAP 更早预测下游任务失败，否则"控制共形"退化为普通共形。
- **具身真有红利**：E305 应显示主动视角显著缩小控制关键集合且不增加违规；E306 必须证明无利可图时严格不动。
- **漂移即弃权**：E312 中一旦分布漂移被检出，系统必须撤回覆盖声明并回退保守；任何"悄悄沿用旧覆盖"都判失败。
- **时延**：常规路径不得突破 3.0ms；歧义路径允许一次性 < 3.8ms，超出即触发 K=1 + APX 关闭降级。

## 8. 本轮最大风险

**一句话**：SIGHT 的覆盖保证**条件于"候选生成器已把真值放进 H(o)"**——可这正是它想保证的东西：若真物因遮挡、过小、OOD、NMS 抑制或对抗贴片而**从未成为候选**，共形校准对它完全无效，覆盖率仍会漂亮地停在 1−α，而系统恰恰错在"它根本不在集合里"；机器人也无法主动去看一个它不知道存在的东西——**SIGHT 的证书因此可能只是"覆盖剧场"：在可交换校准集上完美，对真正致命的漏检零保证。**

**次级风险与缓解**：校准集投毒/可交换性破坏（漂移检验 + 校准集完整性审计 + 检出即撤回覆盖声明，定义 323/325）；d_ctrl 依赖同一套被检验的风险模型（无模型见证做下界 + R68 保守兜底）；主动感知把机器人带入危险或耗尽预算（C-RAS-WM 认证 + VoI−成本 + 定理 19）；未知最坏界过度保守致任务瘫痪（有界类 + 主动获取信息 + 预算外退化）；速度包络把速度压得过低（引理 24：重感知/改道优先于无限减速）；NMS/分数泄漏进候选生成（只降阈不去峰 + NMS-aware 去重 + E313）。
