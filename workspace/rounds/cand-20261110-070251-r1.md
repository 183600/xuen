# 第 43 轮（新循环第 3 轮） · 激光雷达 × 创新点：以「创新残差」为证书时钟、以主动询证为紧致性来源（五层架构 v8）

> 承接第 42 轮 v19（RCE × WLEA × CSL）。v19 成功把「证书紧致性」变成了可定价的资本效率，却留下两个根本问题：**（Q1）紧致性从哪里来？** 现有证书仍主要来自离线训练界与 LIO 漂移界，几何证据是被动、间接、与决策无关的。**（Q2）紧致性何时过期？** v19 的证书是一个「值 + 置信度」，却没有「保质期」，一次模型漂移或一个新增障碍就可能让一张漂亮证书悄悄失真。本轮两个灵感词恰好互补：**激光雷达**是一台可主动提问、逐束可证的测距仪，为 Q1 提供物理级、方向性的证据；**创新点**在估计论里就是 innovation（新息/创新残差），是唯一能告发「证书已过期」的观测量，为 Q2 提供时钟。二者合起来，把证书从「静态空间对象」升级为「带新鲜度的时空对象」。

## 0. 直觉与动机

**灵感 1（激光雷达 → 可主动提问的「测距证书机」，而非被动感知器）**：把一束激光想成一次**单边测距证明**：若某束在误差内于 r⁻ 之前无回波（且该束确有有效回波），则其角锥内、半径 r⁻ 上**物理上不存在表面**——这是一条「空无」证据，直接给出间隙（clearance）的**下界**；若回波落在 [r⁻,r⁺]，则给出表面的**存在**证据。与相机不同，LiDAR 同时具备三件事：**度量直接**（米制、无尺度歧义）、**方向可控**（固态/MEMS 可 ROI 扫描，机体可转向）、**逐束可证**（每条射线自带 provenance）。于是感知不必再「扫一遍再祈祷」，而可以像数据库查询一样**针对某个待定守卫去取证**：*这条边到底安不安全？往那里多打几束。* 这把第 41 轮的决策等价集 U_b 从「证书内部概念」变成了「可以花能量去消灭的物理对象」。

**灵感 2（创新点 → 研究的新颖性 = 估计论的新息残差）**：在 Kalman/因子图里，新息 e=z−h(x̂) 是「观测与预测之差」；正常时它是零均值小噪声，**一旦持续偏大就说明模型/地图/状态错了**。这恰是证书最缺的东西：一个**独立于证书自身**的失效探测器。于是本轮最重要的双关是：**研究意义上的「创新点」，落地为工程意义上的「innovation 残差」**——不是再堆一个模块，而是把证书的新鲜度定义在「预测还解释得了观测吗」之上。无法被状态后验解释的新息就是**新颖性（novelty）**：它可能是真障碍、可能是地图漂移、也可能是对抗欺骗，但无论哪种，都必须先让证书**降级**再谈信任。

**耦合（本轮关键）**：主动询证负责**在决策发生前便宜地消灭不确定**（把 U_b 缩空），创新监控负责**在证书静默过期时立刻发现**（把「未知的未知」变成「可观测的降级」）。前者是进攻（用能量买紧致性），后者是防守（用残差买新鲜度）。二者都被第 42 轮的经济层统一计价：**紧致性定价已有，本轮再加一条「新鲜度定价」**——证书越旧越便宜也越不可承保，于是「多久重证一次」第一次成为可优化的经济量，而非拍脑袋的固定频率。

## 1. 形式化定义

**定义 38（激光射线证书 LRC）**：一束激光 b=(o,d,r⁻,r⁺,ε_ang,ε_r,I,κ,t,δ)。设锥 C_b={p: ∠(p−o,d)≤ε_ang, |p−o|≤r⁻}。若该束有有效回波且 r⁻=r−k_rσ_r，则**自由空间证书**为：C_b 内无表面（置信 1−δ）；对任意 p∈C_b，其到最近表面的距离下界 d(p)≥r⁻−|p−o|−ε_ang|p−o|。若回波落在 [r⁻,r⁺]，则**占据证书**为：该环带内存在表面。**约定**：无回波、强度异常（镜面/透明/吸光）、或超量程的束**不得**签发自由空间证书（无证据 ≠ 无物）。

**定义 39（证书间隙场与融合）**：给定射线证书集 B，定义点 x 的**认证间隙** d̃(x)=max_{b∈B, x∈C_b}(r⁻_b−|x−o_b|−ε_ang|x−o_b|)，无覆盖时取先验下界（可为 −∞）。**声音性**：若所有射线证书 sound，则真间隙 d(x)≥d̃(x)。融合取 max 即「最紧的保守下界」；与 ESDF 先验取 max 不破坏声音性。守卫的几何边际用 m_geo=d̃(x)−r_inflate 替换原 ESDF 点估计。

**定义 40（证书创新残差与新鲜度）**：在状态 x̂_k 与地图 M 下预测第 k 束 r̂_k=h(x̂_k,M;b_k)，观测 z_k=r_k。归一化新息 η_k=(z_k−r̂_k)/√S_k，S_k=H P Hᵀ+σ_r²。**证书创新统计** N_k=Σ_{i∈窗口}η_i²（χ²），单边 CUSUM C_k=max(0,C_{k−1}+|η_k|−ν)。**失效判据**：N_k>τ_χ² 或 C_k>τ_C ⟹ 证书标记 stale。**新鲜度**定义为自上次未报警认证以来的年龄 a=t−t_lastGood；证书对象扩展为 c=(值,有效区间,档位,δ,**a,创新证明**)。

**定义 41（新颖性证书 NC）**：令 U 为「无法被状态后验解释的新息」对应的空间支撑（把超阈值射线反投影到占据/自由网格，得未建模区域集）。**新颖性质量** ν_δ = 置信 1−δ 下未建模区域体积的上界（由保守计数/覆盖界给出）。语义风险上界：在 ν_δ 区域内发生未建模碰撞的概率 ≤ ν_δ·ρ_max/Vol，ρ_max 为单位体积最大风险密度。NC 是「地图还敢不敢信」的定量凭据。

**定义 42（主动证书探测 ACP 与决策价值）**：动作 a 为一组待发射束/ROI/视角，成本 c(a)=能量+时延。设当前守卫区间 I_e=[lo,hi]，**决策价值** VOI(a)=E_{z(a)}[L(I_e)−L(I_e|z(a))]，L 为区间宽度诱导的期望损失（可用第 42 轮货币化：SLA 违约损失 + 保守档位的机会成本）。**目标**：max_{a₁..a_m} Σ VOI(a_i) s.t. Σc(a_i)≤Γ_probe，且探测期间的运动受**旧证书**门控（look-before-you-leap）。**性质**：在区间证据模型下 VOI 为次模函数，贪心达到 (1−1/e) 近似；通常 1–3 束即可消去一个待定守卫。

**定义 43（新鲜度感知合约 FRC）**：在定义 32 上给证书加年龄 a，失败率上界 p̄_cert(c,a) 关于 a 单调不减；合约增加最大年龄 A_max。**保费** π(a)=(1+η(a))(c_exec+L·p̄_cert(c,a))+η₀，η(a) 随 a 增大。**定理（新鲜度—紧致度二重性）**：在创新过程平稳且 CUSUM 检测延迟有界 D 的前提下，证书在 [t_lastGood, t_lastGood+A_max] 内的真实失效概率被 p̄_cert(c,A_max)+P(检测延迟>D) 控制；因此「更频繁重证」与「更紧证书」在资本效率上可互换——二者都在降低 p̄，应按每元人民币的 p̄ 降幅统一调度。

**设计约束**：
- (D1) **无回波不签自由空间**：缺失证据只能降级为未知，不能升级为安全。
- (D2) **单边保守**：射线证书只提供间隙下界；任何需要上界的推断必须走独立通道。
- (D3) **探测自门控**：探测动作（转向/靠近/扫描）本身必须由当前有效证书授权，禁止「为了看得更清而先冒险」。
- (D4) **新鲜度单调**：证书价值随年龄不增；超过 A_max 一律 stale，禁止用旧证书跨过创新报警。

## 2. 三大产出设计

### 2.1 IP-57 LIDAR-CERTIFICATE-ORACLE（激光证书神谕 LCO）
1. 逐束证书化：把每束（含多回波）编译成（自由空间/占据/未知）三值证书，附 provenance (b,t,δ)；镜面/透明/弱回波强制归入未知。
2. 间隙场融合：射线证书与 ESDF/LIO 先验取 max 得 d̃(x)，输出给 IP-46/49/51；同时给出每条守卫几何边际及其置信。
3. 多回波/强度证书：用首末回波跨度给出植被/遮挡的「可穿透但不可信」标记；用强度做材质分类的置信证书（仅作降级依据，不作安全升级）。
4. 对抗与欺骗检测：回波一致性（多视角、强度-距离物理模型）检查；不一致即降级，接 IP-59。

### 2.2 IP-58 ACTIVE-CERTIFICATE-PROBING（主动证书探测 ACP）
1. 待定守卫优先：从 IP-52 的 U_b 取出待定守卫，映射为其空间支撑（哪段轨迹/哪条边），生成候选束/ROI/视角。
2. VOI/焦耳调度：用次模贪心在 Γ_probe 内选束；把第 42 轮的货币损失作为 L，天然把「这一束值不值」算成钱。
3. 探测即制度：在 IP-51 增加 Probe 自环与 Look→Decide 转移；探测期间沿用旧证书并保持安全驻留，超时或失败即 SafeStop。
4. 视角选择：当固定扫描无法消歧（遮挡/掠射），允许小幅、已认证的转向/后退以获得更好几何，仍受 (D3)。
5. 与课程联动：IP-50 增加「探测课程」，先学在关键守卫上少打束，再学在动态场景中预判何时必须探。

### 2.3 IP-59 INNOVATION-NOVELTY-LEDGER（创新-新颖性-新鲜度账本 INL）
1. 新息监控器：逐束 η、χ²/CUSUM，超阈即 stale，并把证据写入可审计账本。
2. 新颖性证书：把无法解释的新息反投影成未建模区域，输出 ν_δ 供 IP-51 收窄 Inv(Nominal) 或转 Degraded。
3. 新鲜度时钟：维护 a=t−t_lastGood，驱动 IP-52 重认证调度与 IP-54 动态再定价。
4. 闭环：stale/新颖性 → RCA 重颁（IP-50）→ 新证书 → 账本结算；账本同时保留「当时为什么信」与「后来为何不信」。

## 4. 实验设计 E85–E90（硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E85 射线证书声音性 | 假自由空间率（真值有物却签自由）；守卫覆盖率 | **0 起**；Nominal 下≥95% |
| E86 创新检测 | stale/动态障碍检测延迟 median/p99；误报率 | p99<300ms；误报<1% |
| E87 主动探测效率 | 每焦耳/每毫秒的守卫区间降幅 vs 均匀扫描；决策翻转召回 | 效率≥3x；召回≥95% |
| E88 新鲜度有效性 | 声明新鲜期内真实失效比率；平均重证间隔 | **0 起**；间隔≥0.5s |
| E89 新鲜度经济 | vs v19 的毛利/SLA 违约/资本占用 | 毛利≥+10%；违约不升 |
| E90 端到端 | 不安全事件、Nominal 占比、成功率、探测能耗占比、恢复时间 | 0 起；≥70%；≥85%；≤15%；<2s |

回退：E85 不过（射线证书不可靠）→ 退回 ESDF 保守膨胀 + 禁用自由空间证书；E87 不过（探测不划算）→ 固定 ROI + 只保留创新监控；E86 误报过高 → 提高阈值并把「可解释动态」纳入新息模型，而非放弃新鲜度机制。

## 5. 本轮最大风险

**一句话**：激光雷达既是证书最硬的物理根基，也恰是最容易被物理世界（镜面、透明、吸光、雨雾、对抗回波）欺骗的传感器——一次被伪造的「自由空间」会直接签发一张不安全证书，把感知失效静默翻译成安全失效；因此 (D1) 无回波不签自由空间与跨模态独立交叉验证，是 v8 能否成立的生死门。

| VOI(a) | 探测决策价值 | E[L(I_e)−L(I_e\|z(a))]，用第 42 轮货币损失度量 |
| Γ_probe | 探测预算 | 能量+时延；探测动作受旧证书门控 |
| π(a,ν) | 新鲜度感知保费 | (1+η(a))(c_exec+L·p̄_cert(c,a))+η₀，关于 a 单调增 |
| A_max | 合约最大证书年龄 | 超过即不可承保，强制重证或拒单 |

## 2. 关键算法（伪代码）

### IP-57 LCO：逐束证书与间隙融合
```
def beam_cert(b, z, sigma, delta):
    if z is None or z.out_of_range or z.intensity_anomalous:
        return UNKNOWN_CERT                  # (D1) 无回波不签自由空间
    r_lo = z.r - k*sigma
    r_hi = z.r + k*sigma
    return [FreeSpace(cone(b, r_lo), delta),         # 锥内无表面
            Occupied(annulus(b, r_lo, r_hi), delta)] # 环带内存在表面

def fuse_clearance(x, B, prior):
    d = prior.lower(x)                       # ESDF/LIO 先验下界
    for bc in B:
        if x in bc.cone:
            d = max(d, bc.r_lo - dist(bc.o, x) - bc.eps_ang*dist(bc.o, x))
    return d                                 # 恒有 d ≤ true clearance（sound）
```

### IP-58 ACP：VOI/焦耳 主动询证
```
def probe(guards, U, budget, cert):
    cands = beams_targeting(support(U))       # 待定守卫 -> 束/ROI/视角
    chosen = []
    while budget > 0 and U:
        a = argmax_{a in cands} VOI(a) / cost(a)     # 次模贪心
        if VOI(a) <= 0: break
        chosen.append(a)
        budget -= cost(a)
        U = update_expected(a, U)                    # 预期区间收缩
    assert probing_is_gated_by(cert)          # (D3) 旧证书门控
    return chosen
```

### IP-59 INL：新息闸门与新鲜度
```
def innovation_gate(z, xhat, M, S, state):
    eta = (z - h(xhat, M, z.beam)) / sqrt(S)
    state.N += eta**2
    state.C  = max(0, state.C + abs(eta) - nu)
    if state.N > tau_chi or state.C > tau_C:
        region = backproject(z, state.window)        # 不可解释回波
        return STALE, NoveltyCert(region, delta)
    state.t_lastGood = z.t
    return FRESH, None

def freshness_ok(cert, now, A_max):
    a = now - cert.t_lastGood
    return a <= A_max, a                         # 不满足即强制重证/降级
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| IP-57 逐束证书 | O(1)/束，O(N_beam)/帧（可并行） | 仅有效回波签自由空间；r⁻ 保守 ⟹ 锥内空无；d̃ 为下界 |
| IP-57 间隙融合 | 查询 O(覆盖束数)，空间索引近 O(1) | max 融合保单调；与先验取 max 不破 sound |
| IP-58 探测调度 | O(\|A\|·\|U\|·轮数)，通常 1–3 轮，<1ms | VOI 次模 ⟹ 贪心 (1−1/e)；旧证书门控 ⟹ 探测不新增安全风险 |
| IP-59 新息监控 | O(1)/束；新颖性反投影 O(窗口) | 平稳创新下 CUSUM 检测延迟有界 D；超阈 ⟹ 降级，不漏报 |
| IP-52 T0.5 档 | 复用一帧扫描，低于 T1 | 射线证书 sound ⟹ 该档与精确证书同符号时决策等价 |
| IP-54 新鲜度定价 | O(1)（缓存 p̄(a)） | p̄ 关于 a 单调 ⟹ 越旧保费越高，激励按时重证 |
| 全局 | — | 新鲜度—紧致度二重性：重证与更紧档可等价换算为 p̄ 降幅 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 镜面/透明/吸光/雨雾导致假自由空间 | 高 | (D1) 无回波不签自由空间；多回波；强度-距离物理一致性；跨模态独立交叉验证 |
| 对抗回波/激光欺骗 | 高 | 多视角回波一致性；强度物理模型；异常即降级；账本留证 |
| 合法动态物体被判为新奇 → 频繁 stale/重证 | 高 | 区分「模型内可解释动态」与「不可解释」；空间局部化降级；滞回；E86 守门 |
| 主动探测能耗/时延挤占任务 | 中 | VOI/焦耳；1–3 束；Γ_probe 预算；Probe 自环设时间上界 |
| 探测运动本身不安全 | 高 | (D3) 旧证书门控；最小驻留；失败即 SafeStop |
| 稀疏/远距对薄障碍欠采样 | 高 | 保守膨胀；多视角；与视觉融合；覆盖率门槛 E85 |
| 新鲜度模型与真实失效相关（定理假设不成立） | 中 | 独立通道校准；保守 δ；经验覆盖率检验 E88 |

## 6. 本轮最大风险

**一句话**：激光雷达是证书最硬的物理根基，也恰是最容易被物理世界欺骗的传感器——镜面、透明、吸光、雨雾或对抗回波都能让一条本不该签发的「自由空间」证书被签发，把感知失效静默翻译成安全失效；因此 (D1) 无回波不签自由空间与跨模态独立交叉验证，是 v8 能否成立的生死门。
