# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「谐波减速器」×「碰撞检测」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**传动透明 + 物理通道 + 零背隙交接**。两个灵感分别治理 v9 的一个隐含假设和一个已知软肋：v9 的块证书把安全押在"前向模型在信任域内可信"上（**模型依赖**），又用 Schmitt 迟滞换来防抖（**迟滞＝模式切换时的背隙/失动**）。谐波减速器给出两件事——(a) 传动链的非线性刚度、迟滞、失动、跳齿，是"看起来连续、实际有死区"的典型；(b) 它的齿啮合谐波是碰撞残差的固有噪声底。碰撞检测给出一件武器——(c) 广义动量残差是一个**不经过前向模型**的物理安全通道。
> **关键自觉**：碰撞检测是**保护型**模块，它的"中立元"不能取 no-op（失效＝永不报警＝不安全），这迫使我们对 v9 的中立元代数做一次原则性修补（P13）；并且"独立通道"只是可证伪假设，不是卖点。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 传动不再是一条透明管道）**
直觉：v9 整个栈默认执行器是理想力矩源——块证书预测抽象"动作"，退化链交换模块，守卫读几何间隙。但控制器与世界之间横着一个谐波减速器：柔轮靠受控弹性变形传力，刚度三区（低刚度失动区 / 过渡 / 高刚度），叠加迟滞、摩擦、随转角的齿啮合力矩脉动，过载时跳齿（ratcheting）。由此三后果：(1) 命令力矩 ≠ 输出力矩，从电机电流反推外部力矩必须先把传动**透明化**；(2) 齿啮合谐波（阶次 n·N，N 为减速比）是任何碰撞残差的固有噪声底；(3) 更哲学的一点——谐波减速器"号称零背隙"，实际有失动与迟滞，是一个"名义连续、实际有死区"的传动。v9 的 Schmitt 迟滞、以及 K_eff 从 10 突降到 1 的交接，恰恰是控制系统里同一种"背隙"。

**灵感 2（碰撞检测 → 一条不经过前向模型的物理安全通道）**
直觉：v9 最大软肋是块证书 Ĉ 依赖冻结前向模型 F̂ 与信任域 U_t，而域偏移既是 F̂ 最不准的时刻，也是 DA-ML 滑窗最滞后的时刻（v9 风险原话）。碰撞检测绕开整条链：用广义动量观测器从关节编码器 + 电机力矩估计外部力矩残差 r(t)，在 1kHz 上跑，只依赖机器人自身动力学（远比环境模型可靠），响应的是"物理已经撞上了"而非"模型预测可能会撞"。它天然是**另一个模态**（不同传感器、不同频率、不同模型），正对 v9 的"证书在最需要时最不可靠"。

**灵感 3（谐波减速器 × 碰撞检测 → 所谓冗余可能是假的）**
直觉：碰撞残差恰恰被谐波减速器的非线性刚度、迟滞与齿啮合谐波污染；而补偿这些又需要一个传动模型。一旦用"传动模型 + 刚体动力学模型"去得到碰撞残差，这条"独立通道"就重新变成模型依赖的通道——它与前向模型证书共享同一个失效驱动量：**域偏移下的未建模动力学（负载、摩擦漂移、温升、磨损）**。因此本轮最重要的不是"再加一个模块"，而是先诚实回答：这条通道在什么条件下真的独立？我们把"独立性"当作**可证伪假设**来设计实验，而不是当作卖点。

## 1. 研究问题（轮次升级版）

- **Q1（传动透明化）**：如何仅用编码器 + 电机电流，用"三区刚度 + 迟滞 + 角域阶次陷波"把谐波传动透明化，使外部力矩残差在高速、变负载下仍能区分碰撞与齿啮合脉动？
- **Q2（独立性与相关失效）**：碰撞通道与前向模型证书的失效事件在域偏移下是否正相关？能否用"角域阶次残差"这种与场景无关的量作为独立性检验的锚？
- **Q3（保护型模块的退化语义）**：碰撞检测是保护型模块，其"中立元"若取 no-op 即为不安全。如何定义**保守中立元** v^⊥_safe 与确定性包络，使保护型模块失效时系统退化到 v9 的**安全集**而非 v9 的性能点？
- **Q4（零背隙交接）**：如何用"预紧双波"式影子控制器 + 混合证书，使 K_eff 突降、active↔dormant、chunk↔step 三种模式切换在命令空间 C⁰ 连续，且切换过程中本身就始终持证？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 保护型残差律与保守中立元（Protective Residual & Conservative Neutral, PR）**
模块分两类：操作型（enhancing，失效可 no-op，退回 v9 性能）与保护型（protective：碰撞/棘轮/超力，失效**不可** no-op）。保护型模块输出一个"否决/降级触发"信号 v；聚合为 `abort = geom ∨ collision ∨ ratchet ∨ conservative`。其失效中立元定义为 **v^⊥_safe = 强制保守包络**（速度 ≤ v_cons、|τ| ≤ τ_cons、K_eff ← 1），而**不是**布尔假。形式化：v^⊥_safe ∈ SafeSet，且对任意状态 s，一旦保护通道不可用，系统轨迹仍属于 v9 引理 80–81 的认证安全集。操作型模块沿用 v9 的恒等元 v^⊥。→ 这条修补了 v9"中立元＝no-op"在保护型模块上的隐性不安全假设。

**P14 传动透明律（Transmission Transparency, TT）**
在电机力矩与外部力矩之间插入显式传动模型 HTO：τ_out = K_t(ε) + τ_f(θ̇) + τ_h(ε,history)，ε = θ_m/N − θ_l；并在**角域**用阶次陷波 HCN 扣除齿啮合谐波 Σ_n A_n(τ)cos(nNθ_l+φ_n)。任何外部力矩估计必须先过 HTO/HCN；未经补偿的原始残差**不得**作为安全依据。

**P15 零背隙交接律（Backlash-Free Handoff, BFH）**
任何模式切换（chunk↔step、K_eff 突变、active↔dormant）前，影子控制器持续热运行并与主控制器状态对齐（预紧）；切换准入条件为命令残差 ‖u_new−u_old‖ ≤ ε_h 且状态残差 ≤ ε_s，否则保持旧命令并请求降级。切换期间的混合命令必须携带"混合证书"，禁止出现"两端都在证书内、混合点却在证书外"的空洞。

## 3. 与基线的接口（如何退化）

- HCN 失效 ⇒ 角域陷波旁路，MRCD 阈值抬升到保守值（灵敏度下降但仍工作），**不**退回 v9；
- HTO/MRCD 失效 ⇒ 保护型中立元 v^⊥_safe：K_eff ← 1 + 速度/力矩包络收紧，碰撞通道整体旁路，系统进入 v9 的 K=1 逐步模式（等价 v9 决策语义且更保守）；
- BFH 失效 ⇒ 直接切换（v9 原行为），接受可能的命令跳变（现有 E564 的风险回归）；
- 全部 HC² 新模块失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9（再沿 v9 链退回 v8/v7）。

## 4. 预期贡献

1. **无传感器、传动透明化的碰撞检测**：三区刚度 + 迟滞 + 角域阶次陷波，把谐波减速器的"噪声底"变成可建模、可扣除的量；
2. **保护型模块的中立元理论**：区分 fail-operational 与 fail-safe 两类退化，修补 v9 中立元代数的隐性不安全假设（P13）；
3. **零背隙交接**：把机械"预紧双波"的思想搬到模式切换，为 K_eff 收缩 / 休眠唤醒的"命令连续性"给出可证条件（P15）；
4. **诚实的独立性分析**：把"碰撞通道 ⊥ 前向模型证书"从卖点降格为可证伪假设，用 E581–E584 直接检验相关失效；
5. **E571–E590** 覆盖传动辨识、碰撞检测/定位/分类、阶次陷波、零背隙交接、棘轮、疲劳、相关失效与端到端。

## 5. 本轮最大风险

**一句话**：碰撞残差为了实现"独立"必须先减去一个谐波传动模型，而传动模型误差与场景前向模型误差在**同一个域偏移/变负载变量上同向增长**——于是两条"独立"安全通道很可能只是同一个盲点的两种表述，检测概率不能按 (1−p₁)(1−p₂) 复合，冗余是假的。

**新增定义 540（谐波传动观测器 HTO）** 传动误差 ε = θ_m/N − θ_l。输出侧力矩模型：
```
τ_out = K_t(ε) + τ_f(θ̇_l) + τ_h(ε, history)
K_t(ε) = sgn(ε)·[ K₁·a,                       a ≤ δ_b
                  K₁δ_b + K₂(a−δ_b),          δ_b < a ≤ δ_s
                  K₁δ_b + K₂(δ_s−δ_b) + K₃(a−δ_s),  a > δ_s ]   (a=|ε|)
τ_f(v) = [F_c + (F_s−F_c)e^{−|v|/v_s}]sgn(v) + F_v·v        （Stribeck）
τ_h    = B_h(ε)   （带半宽 h 的 Preisach 迟滞算子，载荷历史相关）
```
参数 (K₁,K₂,K₃,δ_b,δ_s,F_c,F_s,F_v,v_s,h) 由台架静态刚度扫描 + 动态迟滞回线用递推最小二乘辨识；辨识残差给出 δ_model 初值。

**新增定义 541（角域阶次陷波 HCN）** 齿啮合脉动是**输出角 θ_l 的周期函数**而非时间周期函数：
```
τ_ripple(θ_l) = Σ_{n=1}^{N_h} A_n(τ) cos(nNθ_l + φ_n)
```
故先按等角度 Δθ 重采样（order tracking），再在**角域**对阶次 {N,2N,…,N_hN} 做梳状陷波，最后逆变换回时域得 τ_clean = τ_out − τ̂_ripple。时域固定频率陷波在变速时会展宽/失效，角域方法对此免疫。碰撞冲激非 θ 周期，故在陷波后存活。

**新增定义 542（广义动量残差碰撞检测 MRCD）** 刚体动力学 M(q)q̈ + C(q,q̇)q̇ + g(q) = τ_clean + τ_ext，动量 p = M(q)q̇。观测器：
```
r(t) = K_O [ p(t) − ∫₀ᵗ ( τ_clean + Cᵀ(q,q̇)q̇ − g(q) + r(s) ) ds ]
⇒  ṙ = K_O ( τ_ext − r )
```
r 是带宽为 K_O 的一阶低通外部力矩估计。碰撞事件 ⇔ ‖r‖ > τ_col 持续 ≥ T_col。1kHz ISR 锁存 collision_flag、时间戳与方向 d̂=r/‖r‖。分类：冲激（上升时间 t_r<T_r 且峰值>τ_col_strict 且接触方向 ∉ 计划接触流形 Π_t）判为碰撞；缓升、持续、方向 ∈Π_t 判为有意接触。定位：j* = argmax_j |r_j|/τ_col,j（或按连杆雅可比匹配残差方向）。

**新增定义 543（棘轮/跳齿检测 RDFI）** 跳齿判据：|ε| 单步跳变 ≥ γ·Δ_tooth（γ=0.8），且 τ_clean 接近力矩上限。触发硬事件：力矩切除 + 安全停驻 + 疲劳尖峰计数。与之配套的疲劳模型：对 τ_s 循环做雨流计数，Miner 损伤 D(t)=Σ n_i/N_i；磨损使脉动幅值 Â_n 漂移，令 δ_model(t)=δ₀(1+λD+μ|ΔÂ|)，并按同向膨胀 MRCD 阈值 τ_col(t)，防止磨损静默转化为误报上升（引理 92）。

**新增定义 544（保护型保守中立元 v^⊥_safe）** 保护型集合 P={MRCD,RD,HTO 自检}。其失效中立元为确定性包络：
```
v^⊥_safe = E_cons = { v ≤ v_cons, |τ| ≤ τ_cons, K_eff = 1, a ∈ StopCompatible }
```
聚合 `abort = geom ∨ collision ∨ ratchet ∨ (∀p∈P 不可用 ⇒ E_cons)`。与 v9 恒等元不同，E_cons 是**动作约束**而非空操作；安全性由"E_cons ⊂ v9 安全包络 ∪ K_eff=1 模式"保证（引理 89）。

**新增定义 545（零背隙交接 BFH）** 模式 m ∈ {chunk, step, active, dormant}。影子控制器 S_{m'} 在 1kHz 热运行并与主控制器状态对齐（预紧）。交接准入：
```
h_cmd = ‖u_{m'} − u_m‖ ≤ ε_h  ∧  h_state = ‖x_{m'} − x_m‖ ≤ ε_s  ∧  MixedCert(u(α)) ∀α∈[0,1]
u(α) = (1−α)u_m + α u_{m'}，α 在 T_blend 内由 0 升到 1
```
若准入失败 ⇒ 保持 u_m（旧证书继续有效）并请求 Level-2/3 降级；若混合路径某点跳出证书 ⇒ 同样保持旧命令（禁止"两端持证、中点失证"的空洞）。

**新增定义 546（碰撞触发中块中止 CTA）** AC 中块守卫增补：若自上次守卫以来 MRCD 锁存（t_stamp > last_guard_time），立即升级中止：p* = 满足**碰撞后**停车不变式的最大中止点 ≤ k_exec，其中用 r 冲量与等效惯量估计碰撞后速度 v⁺；若无可行 p*，执行紧急柔顺停驻（力矩斜坡到零，即 v^⊥_safe）。目标延迟 ≤ τ_d + 1 个守卫拍。

# IP-357 HTO：三区刚度 + 迟滞 + 摩擦，把电机力矩还原为输出侧力矩
class HarmonicTransmissionObserver:
    def __init__(self, ratio, stiff, delta_b, delta_s, friction, hyst_h):
        self.N = ratio
        self.K1, self.K2, self.K3 = stiff           # 三区刚度
        self.db, self.ds = delta_b, delta_s
        self.Fc, self.Fs, self.Fv, self.vs = friction
        self.hist = PreisachBacklash(hyst_h)
        self.delta_model = 0.0

    def stiffness(self, eps):
        a, s = abs(eps), (1.0 if eps >= 0 else -1.0)
        if a <= self.db:
            tau = self.K1 * a
        elif a <= self.ds:
            tau = self.K1 * self.db + self.K2 * (a - self.db)
        else:
            tau = (self.K1 * self.db + self.K2 * (self.ds - self.db)
                   + self.K3 * (a - self.ds))
        return s * tau

    def friction(self, v):
        fs = self.Fc + (self.Fs - self.Fc) * math.exp(-abs(v) / self.vs)
        return fs * np.sign(v) + self.Fv * v

    def observe(self, theta_m, theta_l, vel_l):
        eps = theta_m / self.N - theta_l
        tau_out = (self.stiffness(eps - self.hist(eps))
                   + self.friction(vel_l) + self.hist.bias())
        return TransmissionState(eps=eps, tau_out=tau_out,
                                 err=self.delta_model)


# IP-358 HCN：角域等角度重采样 + 阶次梳状陷波
class HarmonicCombNotch:
    def __init__(self, ratio, n_h=4, dtheta=1e-3):
        self.N, self.n_h = ratio, n_h
        self.buf = OrderBuffer(dtheta)          # 按等角度 Δθ 缓存

    def update(self, theta_l, tau_out):
        self.buf.push(theta_l, tau_out)
        ripple = 0.0
        for n in range(1, self.n_h + 1):        # 角域阶次辨识 + 重建
            A, phi = self.buf.order(n * self.N)
            ripple += A * np.cos(n * self.N * theta_l + phi)
        self.ripple_hat = ripple
        return tau_out - ripple


# IP-359 MRCD：广义动量残差碰撞检测（1kHz ISR）
class MomentumResidualCollisionDetector:
    def __init__(self, dyn, K_O=300.0, tau_col=5.0, T_col=2):
        self.dyn = dyn                          # M(q), C(q,qd), g(q)
        self.K_O, self.tau_col, self.T_col = K_O, tau_col, T_col
        self.r = np.zeros(dyn.n); self.integral = np.zeros(dyn.n)
        self.flag = False; self.t_stamp = -1; self.dhat = None
        self._count = 0

    def step_1khz(self, q, qd, tau_clean, dt=1e-3):
        p = self.dyn.M(q) @ qd
        integrand = (tau_clean + self.dyn.C(q, qd).T @ qd
                     - self.dyn.g(q) + self.r)
        self.integral += integrand * dt
        self.r = self.K_O * (p - self.integral)     # r=K_O(p−∫(...))
        if np.linalg.norm(self.r) > self.tau_col:
            self._count += 1
            if self._count >= self.T_col:
                self.flag = True
                self.t_stamp = now()
                self.dhat = self.r / (np.linalg.norm(self.r) + 1e-9)
        else:
            self._count = 0
        return self.r


# IP-361 RDFI：跳齿检测 + 疲劳—不确定性膨胀
class RatchetFatigueMonitor:
    def __init__(self, ratio, teeth, gamma=0.8, lam=2.0, mu=1.0):
        self.d_tooth = 2 * np.pi / (ratio * teeth)
        self.gamma, self.lam, self.mu = gamma, lam, mu
        self.prev_eps, self.D = None, 0.0

    def check(self, eps, tau_clean, ripple_amp_drift):
        ratchet = False
        if self.prev_eps is not None:
            ratchet = abs(eps - self.prev_eps) >= self.gamma * self.d_tooth
        self.prev_eps = eps
        self.D += rainflow_damage_delta(tau_clean)
        delta_model = self.lam * self.D + self.mu * ripple_amp_drift
        return ratchet, delta_model, self.D


# IP-360 BFH：预紧影子控制器 + 混合证书
class BacklashFreeHandoff:
    def __init__(self, eps_h=0.02, eps_s=0.01, T_blend=5):
        self.eps_h, self.eps_s, self.T_blend = eps_h, eps_s, T_blend
        self.shadow = {}

    def keep_warm(self, mode, state, controller):
        self.shadow[mode] = (controller.step(state), state.copy())  # 预紧

    def try_switch(self, m_from, m_to, u_from, x_from, cert):
        u_to, x_to = self.shadow[m_to]
        if (np.linalg.norm(u_to - u_from) <= self.eps_h
                and np.linalg.norm(x_to - x_from) <= self.eps_s):
            return ('switch', u_to)
        for alpha in np.linspace(0.0, 1.0, self.T_blend):
            u = (1 - alpha) * u_from + alpha * u_to
            if not cert.holds(u):               # 混合点必须逐点持证
                return ('hold', u_from)
        return ('blend', (u_from, u_to))

## 4. 推导

**引理 87（HTO 残差可观测性与最小可检外部力矩）** 设传动/动力学模型误差为 δ_H、阶次陷波后残余为 δ_rip，则外部力矩在水平 τ_col ≥ δ_H + δ_rip + r_bias 上可检；一阶观测器给出检测延迟 τ_d ≤ ln(τ_col/(τ_col−τ_ext))/K_O + T_col。证明：ṙ=K_O(τ_ext−r) 的解为 r(t)=τ_ext(1−e^{−K_O t})（常值近似），令 r 达 τ_col 解出 t；再加确认窗 T_col。δ_H+δ_rip 是 r 的直流偏置下界，故低于此二者的碰撞不可区分于模型误差。∎

**引理 88（相关失效的诚实上界 / 独立性判据）** 设前向模型误差 e_F=‖F̂−F‖、传动/动力学模型误差 e_H，共同由域偏移与负载偏离变量 ξ 单调驱动。则联合漏检 P(miss)=P(miss_F ∧ miss_H)。当 miss_F、miss_H 关于 ξ 正相关（Cov>0）时 P(miss_F ∧ miss_H) ≥ P(miss_F)P(miss_H)，故"两通道冗余"不能按 1−(1−p₁)(1−p₂) 复合，独立性增益上界被相关项吃掉。**判据**：仅当残差交叉相关 ρ(e_F,e_H;ξ)≈0 时可视作独立，E581–E584 直接测量 ρ。∎（这是"负结果"引理，刻意把冗余做成可证伪假设。）

**引理 89（保守中立元的退化安全性）** 保护型集合 P 任一不可用时注入 v^⊥_safe=E_cons。因 E_cons 强制的 K_eff=1 恰是 v9 Level-1 模式，且 v_cons≤v8 认证速度上界、τ_cons≤τ_limit、StopCompatible⊂v9 停驻动作集，故产生的轨迹包含于 v9 认证安全集 S_v9。对比 no-op（"永不报警"）在保护通道失效时会把碰撞暴露给未降级的 v9，E_cons 无此安全缺口。∎

**引理 90（零背隙交接 C⁰ 连续与混合证书无空洞）** 若交接准入 h_cmd≤ε_h 且对 ∀α∈[0,1] MixedCert(u(α)) 成立，则切换前后命令 ‖u(t⁺)−u(t⁻)‖≤ε_h（C⁰ 连续），且混合路径每点满足停车不变式与 SpatialCert，故不存在"两端持证、中点失证"的空洞。准入失败时保持 u_m，其原证书由归纳假设继续成立，安全不变式不破。∎

**引理 91（棘轮检测先于结构过载）** 取 γ·Δ_tooth 小于"达到结构力矩上限所需 ε"，则任何真实跳齿（ε 跳变≥Δ_tooth>γΔ_tooth）必被检出，且急停力矩切除把峰值传递力矩限制在 τ_limit 内。证明由跳齿定义（ε 单步跨过整齿距）与阈值序关系直接得到。∎

**引理 92（疲劳—不确定性膨胀的误报稳定性）** 令 δ_model(t)、τ_col(t) 关于损伤 D(t) 与脉动漂移单调不减。若膨胀策略满足 dτ_col/dD ≥ dσ_r/dD（阈值增长不慢于残差标准差增长），则误报概率 P_fp(t)≤exp(−τ_col(t)²/2σ_r(t)²) 关于 t 不减，即磨损不会静默转化为误报上升；同时 τ_col 上升使漏检风险由 RDFI 的维护告警接管（到达 D 阈值触发离线重辨识）。∎

## 8. 本轮最大风险

**一句话**：碰撞残差为了实现"独立"必须先减去一个谐波传动模型，而传动模型误差与场景前向模型误差在**同一个域偏移/变负载变量上同向增长**——于是两条"独立"安全通道很可能只是同一个盲点的两种表述，检测概率不能按 (1−p₁)(1−p₂) 复合，冗余是假的。
