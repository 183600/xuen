## 1. 两个灵感的第一性原理

### 灵感 1 ·「抓取」→ 抓取是 142 项任务里覆盖面最广的「跨任务接触原语」

**直觉**：几乎所有桌面操作任务，无论后续是折叠、插入、倾倒还是堆叠，都从「抓住一个物体」开始。任务决定的是**抓住之后往哪放**，而**怎么抓稳**由物体几何 + 夹爪 + 接触力学决定，与下游任务弱相关。所以若要找一样能从 110 个兄弟任务迁移到 32 个挑战任务的东西，最该迁移的不是整条策略，而是**抓取**。

**严谨化**：
- **抓取的物理本质是约束**：平行夹爪抓取 = 两个接触点把物体相对夹爪的自由度约束住。经典判据是**对跖（antipodal）+ 摩擦锥**：两接触点连线落在两接触法向的摩擦锥内，即力封闭（force closure）的一个充分条件。据此可定义**力封闭裕度** q（U20）——纯几何、物体无关、可即时计算。
- **抓取事件的统计本质是分布**：一段成功示范里，夹爪闭合时刻的位姿 `(p_c, R_c, w_c)` 就是一次成功抓取样本。从 110×200 + 32×1000 ≈ 5.4 万条 episode 中可自动挖掘出约 10 万级抓取事件（U19）——这是官方白送的「抓取先验库」。
- **抓取先验的迁移性**（L14）：固定物体类别 + 固定夹爪时，成功抓取位姿分布近似与下游任务无关；任务只通过「可达/可接近」约束（如书架上只能侧抓）裁剪可行集。故抓取先验可跨任务迁移，偏差 = 落在任务可行集之外的先验质量。
- **预抓取几何 vs 抓后确认 vs 运输滑移**：第 2 轮 IP-02 是**抓后**确认，第 3 轮 IP-14 是**运输中**滑移监测；本轮补上**抓前**的抓取候选生成与排序（IP-16）。三者构成完整的「抓取三段论」：抓前选点 → 抓后确认 → 运输防滑。

**策略含义**：把「最后一厘米」的失败拆成三段归因——抓前选错点（本轮 IP-16）、抓后没确认（IP-02）、运输中滑了（IP-14）。抓取从「端到端策略的隐式副产品」升级为「显式的、可迁移的、可验证的一等原语」。

### 灵感 2 ·「产学研合作」→ 竞争不在公地，而在「吸收能力 + 贡献」

**直觉**：当主办方（产业）把 110 + 32 个任务、5 万级 episode 全部公开在 HF 上时，数据本身成了**公地**——人人都有，人人一样。此时胜负不取决于「你手里有什么数据」，而取决于两件事：①**吸收能力**：你能多快把公地里的多样性转成目标任务的能力（任务图迁移、抓取先验）；②**贡献**：你能否回馈公共品（开源评测/负样本/任务图），从而获得声誉、协作与信息优势。

**严谨化**：
- **公地定理（工程版）**：若资产 A 对所有竞争者可得且同质，则 A 不构成护城河；护城河只能来自「把 A 转成 B 的转换函数」或「别人没有的 C」。这里 A = 原始语料，B = 任务图 + 抓取先验，C = 状态层/评测栈（第 3 轮）。第 3 轮把 A 误判为「零护城河」，本轮修正为：**A 是零，但 A→B 的转换是正**。
- **任务迁移图（U21 / IP-17）**：节点 = 142 个任务；边 = 抓取分布散度 + 物体类别重叠 + 动作轨迹相似 + 视觉/语言相似。名字字符串强匹配只能给出 5/32（本轮实测），而语义兄弟明显更多（StackBowls↔Stack_Block、OrganizeStationery↔Take_Stationery、ZipUp↔Unzip）——证明**任务图必须从行为/抓取/视觉算，不能从名字抄**，这本身就是一道工程护城河。
- **负迁移界**（L15）：域适应的标准界 `R_t ≤ R_a + ½ d_{HΔH} + λ` 告诉我们，用辅助任务 a 帮目标任务 t，收益来自样本量（方差下降），代价来自分布散度。**当目标任务已有约 1000 episode 时，收益项变小、代价项不变**，故必须设「负迁移闸门」：只有代理评测确认增益 > δ 才接纳辅助任务。
- **贡献即研究腿**：把 IP-06 代理评测 + 任务图开源，是「研究腿」的产出；它同时是声誉资产（吸引协作）与信息资产（别人用你的协议，你最先知道哪里会崩）。

**策略含义**：本轮不追「更多数据」（数据已过剩），而追「更好的公地转换器」——用抓取这一跨任务不变量 + 任务图这一公地→私产转换器，把 110 任务的多样性定向输送到 32 个挑战任务，并用负迁移闸门防止「帮倒忙」。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（抓取先验的可迁移性）**：从公共 110 任务挖掘的抓取先验，迁移到 32 项挑战任务时，相对「任务内先验」与「无先验」的增益各是多少？物体实例偏移造成的偏差有多大？（E634）
- **Q14（力封闭几何的预测力）**：纯几何的力封闭裕度 q 对真实抓取成功/失败的判别力（AUROC）有多高？加入挖掘先验后能提升多少？（E635）
- **Q15（任务图与负迁移）**：从行为/抓取/视觉构建的任务图，其 top-k 辅助任务选择能否在代理评测上稳定为正增益？负迁移闸门 δ 应设多少？（E636/E637）

## 3. 设计原则（新增 P13–P14，接第 1–3 轮 P1–P12）

- **P13（抓取三段论）**：任何抓取必须经过「抓前候选（IP-16）→ 抓后确认（IP-02）→ 运输防滑（IP-14）」三段；任一段不可用时按退化链降级，但不得跳过「抓前候选」直接盲抓（盲抓仅作 Level-1.7 兜底）。
- **P14（公地转换优先 + 负迁移闸门）**：优先用公共语料提升泛化，而非堆私有数据；任何辅助任务/外部数据进入训练，必须先过代理评测的负迁移闸门（增益 > δ），否则只作离线分析、不入训练。

## 5. 本轮最大风险

**任务图误配导致的负迁移**：32 项挑战任务每项已有约 1000 episode，目标任务本身数据充足；此时若把「名字/语义相近但动力学不同」的公共任务当作辅助训练（例如把 `Stack_Block` 硬迁移到 `StackBowls`、把 `Color_Category` 硬迁移到 `FruitSorting`），方差收益很小而分布偏移代价很大，可能**系统性地把策略拉偏**——而且因为挑战数据大，这种拉偏在训练集上不可见，只在留出泛化上暴露。对冲：①负迁移闸门（P14：代理评测增益 ≤ δ 一律不接纳）；②只取 top-1 最保守辅助任务起步；③任务图边权必须含「抓取分布散度」这一行为证据，不能只靠名字/文本；④抓取先验分层（挑战任务自身先验为主、公共先验为辅）。次要风险：公共与挑战的物体实例偏移使抓取先验失真；力封闭几何在可变形物体（毛巾/袋子）上失效。

## 3. 新增 IP 详述

### IP-16 · GraspAffordance 抓取先验 + 力封闭几何（P0，新）

- **动机**：抓取是 142 项任务覆盖面最广的跨任务接触原语；「最后一厘米」的抓前失败（选错点/接近方向撞物）此前无显式组件。挑战明确「涵盖抓取」，且平行夹爪使力封闭模型适用。
- **与现有差异**：IP-02 是抓后确认、IP-14 是运输防滑，本 IP 补抓前候选生成与排序；候选来自「几何力封闭 q」+「从 110+32 语料挖掘的抓取先验」，而非端到端隐式输出。
- **技术可行性**：高。力封闭裕度是纯几何计算（掩码边界 + 法向 + 摩擦系数）；抓取事件从夹爪宽度信号自动切分；先验用低维参数化（物体系抓点 2D + 接近角 + 宽度）做 KDE。
- **资源**：数据=公共 110×~200 + 挑战 32×~1000 语料（HF 匿名可取）；算力=小；接口=无新增字段。
- **落地步骤**：①夹爪宽度信号切分抓取事件（E638）；②力封闭 q 实现与摩擦系数标定；③低维抓取先验 KDE（分层：任务内为主、公共为辅）；④候选排序 = α·q + β·先验密度 − γ·碰撞惩罚；⑤接入 IP-09 预抓取位与 IP-02 闭合确认（预测宽度作残差基线）；⑥未见物体留出评测（DiverseManip + 公共非挑战任务）。
- **风险**：可变形物体（毛巾/袋子）力封闭模型失效；公共/挑战物体实例偏移；抓取先验在罕见物体上样本不足（退化到纯几何）。

### IP-17 · TaskTransferGraph 任务迁移图（P1，新）

- **动机**：公共 110 与挑战 32 同属 Dex1 家族，但名字字符串强匹配只有 5/32（本轮实测），语义兄弟明显更多（StackBowls↔Stack_Block、OrganizeStationery↔Take_Stationery、ZipUp↔Unzip）→ 任务相似度必须从行为/抓取/视觉算；这是「公地→私产」的转换器。
- **差异**：不做「全量混合训练」（易负迁移），而是「按图选 top-k 辅助 + 负迁移闸门」；边权含抓取分布散度这一行为证据。
- **可行性**：中高。节点 142、边特征五类（抓取分布 / 物体类别 / 动作轨迹 / 视觉 / 语言），规模小、可离线算。
- **资源**：复用 IP-16 抓取先验 + IP-06 代理评测；算力小。
- **步骤**：①五类边特征计算与归一化；②边权组合（先验权重 + 小规模学习）；③top-k 辅助选择；④负迁移闸门（代理评测增益 > δ 才接纳，E637）；⑤接入 IP-12 课程配比与 IP-01 专家路由先验；⑥开源任务图作为「研究腿」贡献。
- **风险**：边权误配 → 负迁移（闸门兜底）；代理评测与真机相关性不足（IP-06 既有风险）；任务图过拟合公开集。

## 5. 符号与定义（新增 U19–U21；U1–U18 沿用）

- **定义 U19（抓取事件）**：`g = (t_c, p_c, R_c, w_c, o)`；t_c=夹爪闭合时刻（宽度降至平台）、p_c/R_c=闭合时夹爪位姿、w_c=闭合宽度、o=物体身份。从 episode 的夹爪宽度信号自动切分。
- **定义 U20（力封闭裕度）**：接触点 c1,c2、指向物体内部（夹爪施力方向）的接触法向 n1,n2、摩擦锥半角 θ_μ=arctan μ；对跖条件 `angle(n1, c2−c1) ≤ θ_μ` 且 `angle(n2, c1−c2) ≤ θ_μ`；裕度 `q = θ_μ − max(angle1, angle2)`，归一化 `q̂ = clip(q/θ_μ,0,1)`。
- **定义 U21（任务迁移图）**：`G = (V, E, W)`；V=142 任务；边特征 `e_ij = (d_grasp, o_obj, d_traj, s_vis, s_lang)`；`W_ij = f_θ(e_ij)`；对每个挑战任务 t，`A(t) = top-k_{j∈公共} W_tj`，仅在代理评测增益 > δ 时接纳。

## 6. 关键算法骨架

```python
# ===== IP-16: 抓取事件挖掘 + 力封闭候选排序 =====
def mine_grasps(episodes):
    grasps = []
    for ep in episodes:
        w = ep.gripper_width            # 30 Hz 标量序列
        t_c = detect_closure_plateau(w) # 宽度下降后平台起点
        if t_c is None: continue
        grasps.append(GraspEvent(t_c, ep.tcp_pos[t_c],
                                 ep.tcp_rot[t_c], w[t_c], ep.object_id))
    return grasps                          # U19

def force_closure_q(c1, n1, c2, n2, mu):
    th = math.atan(mu)
    a1 = angle(n1, c2 - c1)
    a2 = angle(n2, c1 - c2)
    if a1 > th or a2 > th: return 0.0
    return min(1.0, (th - max(a1, a2)) / th)   # U20

def rank_grasp_candidates(mask, depth, prior, feasible):
    cands = sample_antipodal_pairs(mask, depth)   # 边界点对 + 法向
    scored = []
    for c in cands:
        if not feasible(c): continue              # IP-13 任务可行集
        q = force_closure_q(c.c1, c.n1, c.c2, c.n2, MU)
        dens = prior.kde(c.lowdim())              # 挖掘先验（分层）
        scored.append((ALPHA*q + BETA*dens - GAMMA*c.collision, c))
    return sorted(scored, reverse=True)
```

```python
# ===== IP-17: 任务图 + 负迁移闸门 =====
def build_task_graph(public, challenge, grasp_priors):
    V = public + challenge
    E = {}
    for a, b in pairs(V):
        E[(a,b)] = {
            "d_grasp": wasserstein(grasp_priors[a], grasp_priors[b]),
            "o_obj":   jaccard(obj_labels(a), obj_labels(b)),
            "d_traj":  frechet(norm_traj(a), norm_traj(b)),
            "s_vis":   cos(vis_embed(a), vis_embed(b)),
            "s_lang":  cos(txt_embed(a), txt_embed(b)),
        }
    return V, E

def select_aux(t, graph, proxy, delta):
    ranked = sorted(public, key=lambda a: edge_weight(graph, t, a), reverse=True)
    accepted = []
    for a in ranked:
        if proxy.improvement(t, accepted + [a]) > delta:   # 负迁移闸门
            accepted.append(a)
        if len(accepted) >= K: break
    return accepted
```

## 7. 推导（新增引理 L14–L16）

**引理 L14（抓取先验的跨任务不变性，条件性）** 设下游任务 T 只条件化「抓取之后」的策略 `π_T(a_{t>t_c} | ·)`，而抓取是否成功由物体-夹爪接触力学决定，则成功抓取位姿分布满足 `p(g | object, T) = p(g | object)`；任务只通过可达/可接近约束给出可行集 `F_T ⊂ SE(3)`，故迁移偏差 = `p(g|object)` 落在 `F_T` 之外的质量。⇒ 抓取先验可跨任务迁移，但必须与 IP-13 的任务可行集求交。∎（条件性假设，E634 检验）

**引理 L15（负迁移的选择界）** 由域适应标准界 `R_t(h) ≤ R_a(h) + ½ d_{HΔH}(D_a,D_t) + λ_a`：用辅助任务 a 的收益来自样本量带来的方差下降（约 `C/√n_a`），代价来自分布散度项。当目标任务已有 `n_t ≈ 10³` 时，方差收益递减，而散度代价不随 n_t 下降。故 a 有益 ⇔ `方差收益 > ½ d_{HΔH} + Δλ`；据此设负迁移闸门：仅当代理评测实测增益 > δ 才接纳。⇒ **数据充足时，辅助任务的默认答案应是「不接纳」，除非有实测增益**（P14）。∎

**引理 L16（抓取挖掘的样本充分性）** 抓取事件数 `N_g ≈ N_task · N_ep · k_g`，取 `110·200·2 + 32·1000·2 ≈ 10.8 万`。把抓取参数化为低维 `(抓点 2D, 接近角 1D, 宽度 1D)`（d≈4），核密度估计的 MISE 约 `O(n^{-4/(d+4)}) = O(n^{-1/2})`；每物体类别 `n≈10³` 时先验误差可控。⇒ 抓取先验库在样本量上可行，瓶颈在类别划分与实例偏移而非绝对数量。∎
