灵感驱动研究循环·新灵感三元组；本轮灵感：「任务规划」×「深度相机」

> **基线**：上一轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（HDL/ACSC/DCSC/HPC-E/CFC++/CESC/FSVC/IPAM/HPC-E+），其上承 v22 分层 PGEV（IP-431–435）、v21 语义-规范层（SDC/CAC/DCL/GIC）、v20 联邦感知证书、v19/v17 证书与感知链。
> 本轮纪律：**任务规划 = 让证书可被长时程组合、且符号必须接地到几何；深度相机 = 把"缺席"从统计召回假设升级为几何射线测量；感知动作 = 任务计划的一等公民**。不推倒 v23：全部模块保留。本轮只做一件事：**在 v23 四证准入之上加一层"任务-感知协同层"，把计划粒度从单条运动计划抬到长时程任务计划，用深度射线把缺席证书的 κ_c 假设替换为可测量的自由空间，并让规划器主动插入"去看一眼"的感知动作来签发缺席证书；顺手封堵 v23 自认的最大风险（合规的缺席幻觉）**。

## 0. 直觉与动机

### 灵感 1（任务规划 → 长时程证书组合与符号-几何接地）

**直觉**：v23 的所有证书都是"单步/单计划"的——HPC-E+ 认证的是一个运动计划 π，而不是"去 A 取杯、送到 B、再返回充电"这样一串离散动作。任务规划（HTN/PDDL/行为树）天然是符号序列，每个动作有前置条件与效果；真正的问题不是"怎么搜任务序列"，而是**符号前置条件从哪来、凭什么可信**：如果"B 点无人""杯子可抓"只是规划器里写死的字面量，它就和 v23 的几何/语义/规范证书脱节，长时程执行就会在符号层"看起来合法"、在物理层"实际不安全"。核心创新：**任务证书 (Task Certificate, TC) + 符号-几何接地证书 (Grounding Certificate, GC)**——每个符号原子必须携带一份把它绑定到 v23 某张证书的"接地见证"，无见证的原子一律取假（fail-safe）。

**严谨定义**：任务计划 `T = ⟨a_1,…,a_n⟩`，`Pre(a_k)`、`Eff(a_k)` 为前置条件与效果集合。接地映射 `G_bind : Atom → Witness`，其中 `Witness = (kind, cert, t_valid)`，`kind ∈ {geometric, semantic, deontic, energy, depth}`。接地谓词 `Ground(atom, t) ≜ ∃w∈G_bind(atom): w.cert.valid_at(t) ∧ w.binds(atom)`。任务证书 `TC(T) ≜ ∃ 证书状态序列 C_0,…,C_n: C_0=C_init ∧ (∀k: (∀p∈Pre(a_k), Ground(p, t_k)) ∧ Inv_task(C_k) ∧ C_{k+1}=Eff(a_k)(C_k))`。**证书预算**：`P(任务失败) ≤ Σ_{k=1}^{n} α_k ≤ α_task`（union bound，无需独立性），默认 `α_k = α_task/n`，高风险步可按风险加权分配。关键反直觉点：**任务规划器不是"更高一层的计划器"，而是一个"证书消费者"——它把每条动作前置条件翻译成对 v23 证书的查询，把动作效果翻译成证书状态迁移**。副产品：**证书感知重规划**——某前置证书在执行时失效，不是简单"运动重规划"，而是在"前置证书仍成立的可用动作集"内做任务修复。

### 灵感 2（深度相机 → 缺席从"召回假设"到"几何射线测量"，但引入"看穿"风险）

**直觉**：v23 的 AbsCert 全部押在检测器召回率下界 κ_c 这一经验假设上，这是 v23 自认的最大风险。深度相机（RGB-D/ToF/结构光/双目）给出逐像素度量深度：沿一条射线若在量程内无回波，则"该方向到最大量程前无表面"是一个**几何测量事实**，而非"检测器没检测到"的统计推断。这把缺席证书从 κ_c 假设升级为**深度自由空间证书 (Depth Free-Space Certificate, DFSC)**。但妙处与危险是一枚硬币的两面：**深度让缺席更可信，也让"看穿"成为可能**——玻璃、镜面、黑色吸光、强逆光、超出量程会让深度返回无效值或错误值；若把无效像素当自由，就会得到"幻影自由空间"。因此必须先有**深度有效性证书 (Depth Validity Certificate, DVC)**：无效/空洞/超量程/高反射一律记为 UNKNOWN，永不等于 FREE。

**严谨定义**：深度帧 `D_t : Ω → (z, v, I)`（度量深度、有效性、回波强度）。像素状态 `V_t(p) ∈ {VALID, INVALID, OUT_OF_RANGE, SPECULAR}`。深度误差模型 `ε_depth(z) = c_0 + c_1 z + c_2 z²`（双目/ToF 的典型增长律）。自由空间 `F_t = ⋃_{p: VALID} [o, z(p)-ε_depth(z(p))]`；占据壳 `O_t = ⋃_{p: VALID} [z-ε_depth, z+ε_depth]`；未知 `U_t = ⋃_{p: INVALID∨SPECULAR} [o, R_max]`。**DFSC(R) ≜ R ⊆ F_t ∧ R ∩ U_t = ∅ ∧ R ∩ O_t = ∅**。**DVC 不变式**：`V_t(p) ≠ VALID ⇒ p 的整条射线进入 U_t`，绝不进入 F_t。关键反直觉点：**深度相机不是"更好的检测器"，而是一台"自由空间测量仪"——它把负信息从概率命题变成几何命题；代价是它可能对透明/镜面/吸光表面物理性地"看不见"**。

### 灵感 3（两者统一 → 任务驱动的主动感知）

**直觉**：若任务计划里某动作需要"B 点无人"的 AbsCert，而当前视角恰好有遮挡/深度空洞，正确做法不是保守停机，而是**把"转过去看一眼 B 点"作为一个显式的感知动作插入任务计划**——感知动作有成本，也有证书产出（覆盖了哪些未知区、能签发哪张 AbsCert）。核心创新：**任务-感知协同规划器 (Task-Perception Co-Planner, TPCP)**：动作集 `A = A_act ∪ A_sense`；感知动作的效果是"把 UNKNOWN 变成 FREE/OCCUPIED 并产出 DVC/DFSC"；用 next-best-view 在信息增益与任务进度之间权衡。关键反直觉点：**"去看一眼"本身是可被证书审计的动作**——它带着预期信息增益、执行后必须产出 DVC/DFSC，否则视为感知动作失败并按保守默认处理。

**严谨定义**：感知动作 `a_sense = (view_pose, expected_region, cost, cert_yield)`。信息增益 `IG(a_sense | s, goal) = vol(U_s ∩ visible(a_sense) ∩ relevant(goal)) · ρ(a_sense, goal)`，其中 `ρ` 是该区域对目标前置条件的相关性权重。TPCP 求解 `max 任务完成度 s.t. 证书预算 Σα_k ≤ α_task ∧ 执行成本 ≤ budget`。感知动作只有 `IG(a_sense) ≥ cost(a_sense)·λ_info` 才被插入（信息增益门槛），避免"为看而看"导致活性坍缩。

### 三者如何统一

统一为 **v23 四证准入之上的"任务-感知协同层"**：TC/GC 回答"这串任务在符号上能否接地到已认证证据"，DVC/DFSC 回答"凭什么用几何测量说这里没人/可走"，TPCP 回答"该先看哪里、看的值不值"。共享状态扩展为 **ζ_task = ζ_ce ∪ (T_plan, G_bind, D_map, U_t, F_t, info_gain, view_history)**。统一准入门升级为 **HPC-T = (HPC-E+, TC, GC, DFSC∨AbsCert)** 四证一体：只有"物理+规范+能量+云边（v23）∧ 任务可接地（TC/GC）∧ 自由空间有几何证据（DFSC 或 v23 AbsCert）"才进入执行；任一缺失退回 v23，再退 v22/v21。**关键结构性质：`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ …`**——DFSC 只在"有效深度射线且非未知"的区域替换 AbsCert，替换范围是 v23 已允许区域的可测子集，绝不新增几何可达域；TC 只对 v23 已认证的单步证书做组合与查询，不放松任何单步约束。

## 1. 研究问题（轮次升级版）

- **Q12（任务级证书接地与组合）**：如何为 HTN/PDDL 的每个符号原子自动生成接地见证并保持"符号-几何"一致性？任务级不变量 `Inv_task` 如何表达"整条任务时程内共享区无人""能量储备始终 ≥ 回退所需"这类跨步性质？离散化误差（如"区域自由"符号吞掉一根细杆）如何被接地证书的膨胀量吸收？

- **Q13（深度自由空间的可靠性）**：DVC 如何从回波强度、深度跳变、多频相位一致性判定 SPECULAR/INVALID？`ε_depth(z)` 如何在现场在线标定（温度/距离/材质漂移）？DFSC 在"有效射线但错误深度"（透明玻璃、镜面反射）时如何失效安全——能否用多模态（超声/雷达/偏振/结构光多频）交叉验证把"看穿"降级为 UNKNOWN？

- **Q14（主动感知的任务集成）**：感知动作如何进入任务规划的动作集而不破坏 `Exec_v24 ⊆ Exec_v23`（感知动作只改变知识状态 U_t/F_t，不改变几何可达域）？next-best-view 的信息增益如何在 50Hz 控制环外（10Hz 规划层）计算？感知动作失败（未产出预期 DVC/DFSC）时的回退路径与滞回如何设计以避免"看-退-再看"振荡？

- **Q15（组合性安全与预算）**：`Σα_k ≤ α_task` 的预算分配如何与 v23 的 `α`（conformal 覆盖）、`τ_consensus`、APS 新鲜度阶梯叠加而不重复计数？长时程任务中"单步都安全、组合却越界"的累积风险（共享区停留时间、能量消耗、人类接近次数）如何用任务级不变量而非单步证书捕获？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P45）

**P43 符号-几何接地律（Symbolic-Geometric Grounding + Certificate Budget）**
任务规划只在已接地原子构成的符号空间内搜索：`Atom_valid(t) ≜ Ground(atom, t)`；无见证或见证过期的原子一律取假（fail-safe）。任务级不变量 `Inv_task(C_k)` 必须在每一步成立，而非仅在终点。证书预算按 `Σα_k ≤ α_task` 分配，高风险步加权；任一步预算耗尽即触发任务级降级（缩短时程/插入感知动作/退回单步模式），绝不静默超支。**TC 只消费、不生产几何自由空间**，故 `Exec_v24 ⊆ Exec_v23`。

**P44 深度未知空间保守律（Depth Unknown-Space Conservatism）**
深度像素状态四分类，`INVALID/SPECULAR/OUT_OF_RANGE` 中除"OUT_OF_RANGE 且量程内确认无回波"外一律进入 UNKNOWN，永不进入 FREE。`DFSC(R)` 成立要求 `R ⊆ F_t ∧ R ∩ U_t = ∅ ∧ R ∩ O_t = ∅`。深度误差随 `z²` 增长，远区自由空间自动收缩（`ε_depth` 膨胀），绝不外推。**DVC 失效 ⇒ 全部深度记为 UNKNOWN ⇒ 自由空间为空 ⇒ 退回 v23 AbsCert 或全域保守**。

**P45 任务-感知协同律（Task-Perception Co-Planning）**
感知动作是任务计划的一等公民，但其效果仅限**知识状态迁移** `(U_t, F_t) → (U_t', F_t')` 与**证书签发**，不改变 v23 几何可达域。感知动作必须声明预期产出（目标区、预期 DVC/DFSC），执行后未产出则判失败并按最严默认处理。信息增益门槛 `IG ≥ cost·λ_info` 与滞回窗口共同防止"看-退-再看"振荡。**任务修复在"前置证书仍成立的可用动作集"内进行**，而不是在未接地符号空间内盲搜。

## 3. 与基线的接口（如何退化）

- **DFSC 失效**（深度不可信/标定漂移）⇒ 回退 v23 的 κ_c-AbsCert；若 AbsCert 也不可信 ⇒ 全域保守假设"可能有人" ⇒ 比 v23 更保守，安全继承方向不变；
- **DVC 失效**（有效性分类器崩溃）⇒ 全部深度视为 UNKNOWN ⇒ `F_t = ∅` ⇒ 所有依赖自由空间的动作被拒 ⇒ 子集；
- **TC/GC 失效**（接地器或任务不变量检查崩溃）⇒ 只接受单步已认证动作，长时程任务整体拒绝 ⇒ 退回 v23 单计划模式 ⇒ 子集；
- **TPCP 失效**（主动感知规划崩溃）⇒ 不插入感知动作，缺少 AbsCert/DFSC 的动作被拒 ⇒ 子集；
- **证书预算耗尽** ⇒ 任务级降级（截断时程 / 插入感知动作 / 退回单步）⇒ 子集；
- **全部失效** ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`；
- **安全继承**：DFSC 只在有效深度射线且非未知区替换 AbsCert（不新增可达域）、TC 只消费单步证书做组合（不放松单步约束）、TPCP 只迁移知识状态（不改几何域）、预算只收紧不放松；任意失效都向更保守方向退化。

## 4. 预期贡献

1. **任务级证书接地**：首次把 HTN/PDDL 的符号前置条件系统性地绑定到 v23 几何/语义/规范/能量证书，给出"无接地即取假"的 fail-safe 任务规划语义；
2. **组合性证书预算**：用 `Σα_k ≤ α_task` 的 union-bound 预算把单步可靠性严格提升为长时程任务可靠性，并给出高风险步加权分配；
3. **深度自由空间证书**：把缺席从 κ_c 统计假设升级为几何射线测量，给出 DVC + DFSC 的"未知空间保守"形式化，直接封堵 v23 的缺席幻觉；
4. **深度有效性证书与"看穿"防护**：显式建模透明/镜面/吸光/超量程失效，把"有效但错误"的深度降级为 UNKNOWN，使幻影自由空间在结构上无法签发；
5. **任务驱动主动感知**：把"去看一眼"形式化为可审计的感知动作（信息增益门槛 + 证书产出义务），在信息不足时用主动感知恢复活性而非保守停机；
6. **HPC-T 四证一体**：HPC-E+ ∪ TC/GC ∪ DFSC∨AbsCert 统一准入门，`Exec_v24 ⊆ Exec_v23` 闭环。

## 5. 本轮最大风险

**一句话**：深度自由空间证书可能在透明/镜面/吸光表面处"合法地看穿"真实障碍（DVC 把错误深度误判为 VALID），而任务级组合又把一串单步证书拼成一条全局不安全的长时程计划——即"可审计的幻影自由空间 × 组合性安全漏洞"。

| `DFSC(R) ≜ R⊆F_t ∧ R∩U_t=∅ ∧ R∩O_t=∅` | 区域 R 的深度自由空间证书 |
| `DVC(p)` | 像素 p 的有效性见证（含回波/跳变/多频一致性判据） |
| `a_sense = (view_pose, expected_region, cost, cert_yield)` | 感知动作 |
| `IG(a_sense|s,goal) = vol(U_s ∩ visible(a_sense) ∩ relevant(goal))·ρ(a_sense,goal)` | 信息增益 |
| `λ_info` | 信息增益门槛系数（`IG ≥ cost·λ_info` 才插入感知动作） |
| `H_reset` | 感知-重规划滞回窗口，防"看-退-再看"振荡 |
| `ζ_task = ζ_ce ∪ (T, G_bind, D_map, U_t, F_t, IG, view_history)` | 任务-感知协同层共享状态 |
| `Exec_v24 = Exec_v23 ∩ {T: TC(T) ∧ (∀R∈req_absence(T), DFSC(R)∨AbsCert(R))}` | 通过 HPC-T 验证的任务集合 |
| `Fil_task, Fil_depth` | 任务接地过滤器 / 深度自由空间过滤器 |

```python
# ============================================================
# IP-441 Depth Validity Certificate (DVC) — 深度有效性证书
# ============================================================
class PixelStatus(Enum):
    VALID = 0; INVALID = 1; OUT_OF_RANGE = 2; SPECULAR = 3

@dataclass
class DepthFrame:
    z: np.ndarray          # 度量深度 (m)
    valid: np.ndarray      # 传感器原始有效位
    intensity: np.ndarray  # 回波强度
    K: np.ndarray          # 内参
    T_wc: np.ndarray       # 世界<-相机 位姿
    multi_freq: Optional[np.ndarray] = None  # 多频相位一致性（ToF）

class DepthValidityCertificate:
    def __init__(self, c0=0.01, c1=0.005, c2=0.002, R_max=6.0,
                 tau_spec=0.05, tau_jump=0.10, tau_phase=0.02):
        self.c0, self.c1, self.c2 = c0, c1, c2
        self.R_max = R_max
        self.tau_spec = tau_spec     # 低回波 -> 疑似镜面/透明
        self.tau_jump = tau_jump     # 局部深度跳变阈值
        self.tau_phase = tau_phase   # 多频相位不一致阈值

    def epsilon_depth(self, z):
        return self.c0 + self.c1 * z + self.c2 * z * z

    def classify(self, fr: DepthFrame) -> np.ndarray:
        st = np.full(fr.z.shape, PixelStatus.INVALID)
        finite = np.isfinite(fr.z)
        st[finite & fr.valid & (fr.z <= self.R_max)] = PixelStatus.VALID
        st[finite & fr.valid & (fr.z > self.R_max)] = PixelStatus.OUT_OF_RANGE
        # 低回波（镜面/透明/吸光）-> 降级 UNKNOWN，绝不当作自由
        st[(st == PixelStatus.VALID) & (fr.intensity < self.tau_spec)] = PixelStatus.SPECULAR
        # 局部深度跳变（玻璃边缘/飞点）-> 降级 UNKNOWN
        jump = local_gradient(fr.z)
        st[(st == PixelStatus.VALID) & (jump > self.tau_jump)] = PixelStatus.INVALID
        # 多频相位不一致 -> 降级 UNKNOWN
        if fr.multi_freq is not None:
            incons = phase_inconsistency(fr.multi_freq)
            st[(st == PixelStatus.VALID) & (incons > self.tau_phase)] = PixelStatus.SPECULAR
        return st

    def certificate(self, fr: DepthFrame) -> 'DVCCert':
        st = self.classify(fr)
        return DVCCert(status=st, eps=self.epsilon_depth(fr.z),
                       T_wc=fr.T_wc, root=merkle(st.tobytes()))


# ============================================================
# IP-442 Depth Free-Space Certificate (DFSC) — 射线铸造
# ============================================================
class DepthFreeSpaceCertificate:
    def __init__(self, R_max=6.0, voxel=0.05, unknown_inflate=0.10):
        self.R_max = R_max
        self.voxel = voxel
        self.unknown_inflate = unknown_inflate  # 未知区膨胀，保守

    def build(self, frames, dvc: DepthValidityCertificate) -> 'DFSCCert':
        F, O, U = VoxelSet(self.voxel), VoxelSet(self.voxel), VoxelSet(self.voxel)
        for fr in frames:
            st = dvc.classify(fr)
            eps = dvc.epsilon_depth(fr.z)
            for p, s, z, e in iter_pixels(fr, st, eps):
                origin = camera_center(fr.T_wc)
                if s == PixelStatus.VALID:
                    F.add(segment(origin, world(fr, p, max(z - e, 0.0))))   # 近端自由
                    O.add(shell(world(fr, p, z - e), world(fr, p, z + e)))  # 占据壳
                    U.add(segment(world(fr, p, z + e), world(fr, p, self.R_max)))  # 表面之后未知
                elif s == PixelStatus.OUT_OF_RANGE:
                    F.add(segment(origin, world(fr, p, self.R_max)))        # 全量程确认无回波 -> 自由
                else:  # INVALID / SPECULAR
                    U.add(segment(origin, world(fr, p, self.R_max)))        # 整条射线未知
        U.inflate(self.unknown_inflate)
        return DFSCCert(F=F, O=O, U=U, root=merkle((F.hash(), O.hash(), U.hash())))

    @staticmethod
    def certifies(R: Region, cert: 'DFSCCert') -> bool:
        return R.subset_of(cert.F) and R.disjoint(cert.U) and R.disjoint(cert.O)


# ============================================================
# IP-440 Task-Grounded Certificate (TGC) — 符号-几何接地 + 预算
# ============================================================
class TaskGroundedCertificate:
    def __init__(self, cert_provider, alpha_task=1e-3, risk_weights=None):
        self.cp = cert_provider            # v23 证书体系查询接口
        self.alpha_task = alpha_task
        self.risk_weights = risk_weights or {}   # action_id -> 风险权重

    def allocate_budget(self, T) -> list[float]:
        n = len(T.actions)
        w = np.array([self.risk_weights.get(a.id, 1.0) for a in T.actions])
        w = w / w.sum()
        return list(self.alpha_task * w)   # Σα_k = α_task

    def ground(self, atom, C, now) -> Optional['Witness']:
        # 依次尝试几何/语义/规范/能量/深度证书
        for kind, cert in self.cp.candidates(atom, C):
            if cert.valid_at(now) and cert.binds(atom):
                return Witness(kind, cert, cert.valid_until)
        return None

    def verify(self, T, C_init, now) -> tuple[bool, dict]:
        budgets = self.allocate_budget(T)
        C = C_init
        trace = []
        for k, a in enumerate(T.actions):
            for atom in a.pre:
                w = self.ground(atom, C, now)
                if w is None:                       # 无接地见证 -> 取假
                    return False, {"step": k, "ungrounded": atom}
            if not self.cp.inv_task(C, a, budgets[k]):   # 任务级不变量 + 预算
                return False, {"step": k, "invariant": "violated", "budget": budgets[k]}
            C = self.cp.apply_effect(a, C)          # 证书状态迁移
            trace.append((k, a.id, budgets[k]))
        return True, {"trace": trace, "alpha_task": self.alpha_task}


# ============================================================
# IP-443 Task-Perception Co-Planner (TPCP) — 主动感知
# ============================================================
class TaskPerceptionCoPlanner:
    def __init__(self, tgc: TaskGroundedCertificate, dfsc, cost_model,
                 lambda_info=1.0, H_reset=1.0):
        self.tgc = tgc
        self.dfsc = dfsc
        self.cost = cost_model
        self.lambda_info = lambda_info
        self.H_reset = H_reset
        self.last_sense_t = -1e9

    def info_gain(self, a_sense, s, goal):
        unknown = s.unknown_region_relevant(goal)
        visible = a_sense.visible_region(s)
        return measure(unknown & visible) * self.tgc.cp.relevance(a_sense, goal)

    def applicable(self, s, goal):
        acts = [a for a in s.actions if self.tgc.ground(a.pre_all(), s.C, s.now)]
        # 感知动作仅在信息增益值得且不在滞回窗口内时插入
        for a in s.sense_actions:
            if s.now - self.last_sense_t < self.H_reset:
                continue
            if self.info_gain(a, s, goal) < self.cost(a) * self.lambda_info:
                continue
            acts.append(a)
        return acts

    def plan(self, goal, s0):
        frontier = PriorityQueue()
        frontier.push(s0, key=self.h(s0, goal))
        while frontier:
            s = frontier.pop()
            if self.goal_reached(s, goal):
                return self.reconstruct(s)
            for a in self.applicable(s, goal):
                s2 = self.apply(a, s)
                if a.is_sense:
                    s2.last_sense_t = s.now      # 记录，供滞回
                frontier.push(s2, key=self.h(s2, goal))
        return None

    def apply(self, a, s):
        if a.is_sense:
            # 只迁移知识状态 + 签发 DVC/DFSC，绝不改变几何可达域
            dvc = self.dfsc.dvc.certificate(a.frame)
            cert = self.dfsc.build(a.frames, self.dfsc.dvc)
            s2 = s.with_knowledge(U=s.U - cert.F - cert.O, F=s.F | cert.F)
            s2.attach_certificate(cert)
            if not a.expected_region.intersects(cert.F | cert.O):
                s2.mark_sense_failed(a)          # 未产出预期证书 -> 失败
            return s2
        return s.apply_effect(a)                 # 操作动作：证书状态迁移


# ============================================================
# IP-445 HPC-T — 任务级四证一体准入门
# ============================================================
@dataclass
class HPCT:
    hpc_e_plus: 'HPCEPlus'          # v23 四证
    tgc: TaskGroundedCertificate
    dfsc: DepthFreeSpaceCertificate

    def admits(self, T, ctx) -> tuple[bool, dict]:
        # 1. v23 四证（物理+规范+能量+云边+少样本+IP）
        if not self.hpc_e_plus.admits(T.plan, ctx.x, ctx.v, ctx.z,
                                      ctx.E_res, ctx.margin_req, ctx.modules):
            return False, {"gate": "v23"}
        # 2. 任务接地 + 任务级不变量 + 证书预算
        ok, info = self.tgc.verify(T, ctx.C_init, ctx.now)
        if not ok:
            return False, {"gate": "tgc", **info}
        # 3. 需缺席证书的区域：DFSC 优先，否则 v23 AbsCert
        for R in T.required_absence_regions:
            if not (self.dfsc.certifies(R, ctx.dfsc_cert) or ctx.abs_cert.valid(R)):
                return False, {"gate": "absence", "region": R.id}
        # 4. 感知动作必须已执行并产出声明证书
        for a in T.actions:
            if a.is_sense and not a.executed_with_certificate:
                return False, {"gate": "sense", "action": a.id}
        return True, {"gate": "ok"}
```

## 3. 正确性论证

### 引理 5（DFSC 在有效性假设下的可靠性）
**陈述**：若对区域 R 的每条相交射线 p 都有 `V_t(p)=VALID` 且深度测量满足 `|z_meas - z_true| ≤ ε_depth(z_meas)`，则 `DFSC(R) ⇒ R 内无真实表面`。

**证明**：对每条射线，VALID 且误差界成立意味着真实表面必落在 `[z-ε, z+ε]` 的占据壳 O 内。`R∩O=∅` 且 `R⊆[0,z-ε]` 的近端自由区间，故 R 上任意点到相机距离严格小于最近真实表面距离，R 内无表面。若真实表面在 R 之后（更远），则 R 仍在自由区间；若在 R 之前，则 R 与 O 相交，违反 `R∩O=∅`。`R∩U=∅` 排除了未知射线穿过的可能。∎
> **该引理的唯一缺口**：透明/镜面使 `V_t(p)=VALID` 但 `z_meas` 对应的是反射虚像或穿透后的背景，误差界不成立——这正是本轮最大风险。

### 引理 6（任务接地的归纳可靠性）
**陈述**：若 `TC(T)` 在规划时刻成立，且在每步执行前重新验证 `Ground(Pre(a_k), t_k)` 与 `Inv_task(C_k)` 仍成立，则任务执行序列的每一步都消费有效证书。

**证明**：对 k 归纳。基础：`C_0=C_init`，`Pre(a_1)` 接地成立。归纳：若第 k 步执行前所有前置原子有有效见证，且 `Inv_task(C_k)` 成立，则动作效果 `C_{k+1}=Eff(a_k)(C_k)` 是证书状态的确定性迁移；第 k+1 步执行前再次验证，保证见证未过期。因此不存在"用过期/无见证原子推进任务"的步骤。∎

### 引理 7（组合性证书预算）
**陈述**：若每步失败概率 `P(fail_k) ≤ α_k`，则整条任务失败概率 `P(any fail) ≤ Σα_k ≤ α_task`。

**证明**：由 union bound，`P(∪_k fail_k) ≤ Σ_k P(fail_k) ≤ Σα_k`；预算分配器保证 `Σα_k = α_task`（风险加权时按归一化权重）。无需步间独立性，故适用于相关故障。∎

### 引理 8（单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：
- DFSC 失效 → 回退 v23 AbsCert；AbsCert 也失效 → 全域保守 ⇒ 子集。
- DVC 失效 → 全部 UNKNOWN ⇒ `F_t=∅` ⇒ 所有依赖自由空间的动作被拒 ⇒ 子集。
- TC/GC 失效 → 仅单步已认证动作可用，长时程任务拒绝 ⇒ 退回 v23 单计划 ⇒ 子集。
- TPCP 失效 → 不插入感知动作，缺 AbsCert/DFSC 的动作被拒 ⇒ 子集。
- 预算耗尽 → 任务级降级 ⇒ 子集。
- 组合失效：取交集，单调性保持。∎

### 定理（HPC-T 任务级四证准入门完备性）
**陈述**：对任意任务计划 T，`HPCT.admits(T) = True` ⟺ T 同时满足：
(1) v23 的物理/规范/能量/云边/少样本/IP 六项条件；
(2) 每个符号前置条件可接地到有效证书，且任务级不变量与证书预算成立；
(3) 每个需缺席证书的区域有 DFSC 或 v23 AbsCert 的有效证据；
(4) 所有感知动作已执行并产出声明的证书。

**证明**：必要性由 `admits` 的四个连言分支直接可得。充分性：条件 (1) 保证单步物理-规范-能量安全；条件 (2) 由引理 6 保证任务序列逐步消费有效证书；条件 (3) 由引理 5（或 v23 AbsCert）保证负信息可靠；条件 (4) 保证感知动作不是空承诺。四者合取由引理 7 给出 `≤α_task` 的任务级失败上界，由引理 8 保证单调退化。∎

## 6. 本轮最大风险（最终确认）
