# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰联合闭环」IP-193~203；灵感循环 III 第 2 轮；本轮灵感：「需求洞察」×「语言指令」）

> 第 63 轮 LIRO 把「几何—技能—干扰」三层物理安全做到了可认证：LSF 补稠密几何、USL/CSP 补技能抽象、DIR/AIC 补四类干扰。但它仍把「人」压缩成两个东西：DMS 一次性解析出的一段语言 `L`，以及 Shield-Skill 越界时的一次 `ask_clarify`。`J_liro` 是给机器看的物理安全证书，不是对「人到底要什么」的承诺。三个盲区随之暴露：
> 1. **需求是隐变量却被当成常量**：`goal`、`C_exec`、偏好权重 `w` 从话语中解析一次后冻结。可「轻一点」「别碰那里」「你看着办」只是真实需求的稀疏、有损投影；力度上限、可接受路径、时间容忍、风险厌恶、授权程度，大量藏在犹豫、注视、回撤、纠正力与事后反应里。LIRO 没有需求信念，也没有需求漂移模型。
> 2. **语言指令是证据却被当成真理**：ICR 的目标解析默认「一种话语 = 一个逻辑式」。指代歧义（「那个」）、量级歧义（「轻一点」是 5N 还是 15N）、否定作用域（「别把左边那个放上去」）、条件与先后（「等它凉了再拿」）、言外之力（请求/建议/授权/试探）都没有被显式表示。Shield-Skill 只检查技能前置的**物理**条件，于是出现「机制安全、语义错误」：漏掉一个否定，投影算子会把一个错误约束集投影得完美无缺。
> 3. **交互是异常处理，不是一等动作**：`ask_clarify` 只在投影距离超阈值时触发，没有信息增益、打断代价、提问诱导偏差、指令优先级与拒绝语义。系统不会算「这一问值不值得」，也不会防「问什么、用户就以为要什么」的操纵性伪需求。
>
> 本轮核心主张：**把语言指令降格为对隐需求的有损、可策略性失真的报告；把需求洞察升格为带覆盖保证的贝叶斯反问题；把「问/演示/确认/警告/让行/拒绝」变成与抓取、插入同级的动作；把合规证书从机制安全扩展到语义安全。** LIRO 保证「做过的事物理上安全」，LINGO 追加保证「做的事是用户真正要的，且系统说得清、可退出、可纠正」。

## 0. 直觉与动机

### 直觉 0（两个灵感词是同一个反问题的两端）

「语言指令」是正向信道：隐需求 `n` → 意图 → 话语 `L`，中间经过省略、模糊、礼貌、策略性保留。「需求洞察」是逆向问题：从 `L` 加上行为证据 `B`（犹豫、注视、回撤、纠正力、接受/拒绝、接管）反推 `n`。把它们分开做，就会得到两个坏结果：只做语言 → 把话语当真理，精确地执行错误需求；只做需求 → 猜心式家长主义，绕过用户授权。**正确做法是把二者合成一个闭环：语言给出候选解释与先验，行为给出似然，交互主动买信息，执行结果反过来校准信念。**

### 灵感 1（需求洞察 → NIBM + N-CSP：从「解析一次」到「带覆盖的信念」）

直觉：用户的需求不是一个待解析的常量，而是一个会漂移、会被提问塑造、且只能通过有限证据观察的隐状态。系统不应输出「需求 = 这个」，而应输出「需求在这个可信集合里，置信度为 1−α」，并据此做鲁棒规划。

严谨：定义隐需求 `n = (g, C_hard, C_soft, w, ρ_risk, τ_time, δ_social, α_auth)`，其中 `α_auth` 是用户授予的自主度/委托程度。维护信念 `b_t(n) = P(n | L_{1:t}, B_{1:t}, E_{1:t})`，用神经编码器 + 粒子滤波/贝叶斯滤波更新；用**分组保形预测（Mondrian conformal）**给出可信需求集 `N_δ = {n : s(n) ≤ q_δ}`，保证 `P(n* ∈ N_δ) ≥ 1−α`；用自适应保形（ACI）应对需求漂移。规划器 N-CSP 在 `N_δ` 上做鲁棒/机会约束优化，而不是在单点 `n̂` 上优化。

### 灵感 2（语言指令 → ICR + SCM：从「一个逻辑式」到「带歧义后验的契约」）

直觉：一句话不是一条命令，而是一组候选解释及其概率。人话里的否定、量词、指代、条件、时序、言外之力，任何一个作用域错位，都会让机器人「合法地」做错事。正确做法是把指令编译成**可执行契约**，并把歧义显式留在契约里，而不是在解析时偷偷消歧。

严谨：`ICR(L, scene, USL) → κ`，`κ = (speech_act, goal, refs, C_hard^L, C_soft^L, w^L, temporal, scope, conditions, A, precedence, authority)`。其中 `A = {(κ_i, p_i)}` 是候选解释集与后验，`p_i = P(κ_i | L, context)`；未解析/不可解析也作为一个显式候选（abstention）。每个 `κ_i` 编译为信号时序逻辑（STL）监控器 `φ_i`，运行时计算鲁棒度 `ρ_{φ_i}(τ)`（正=满足，负=违反，绝对值=裕度）。**SCM 的语义合规裕度**取所有高后验解释与可信需求上的最坏值：`ρ_sem(τ) = min_{n∈N_δ} min_{i: p_i≥ε} ρ_{φ_i}(τ; n)`。

### 灵感 3（交互 → AEP + 非诱导询问：把「问一句」变成有预算的实验设计）

直觉：提问不是免费的，也不是中性的。问「你是不是想让我轻一点？」会把「轻一点」塞进用户脑子；问「要 5N 还是 15N？」会把连续偏好压成二选一。所以交互要同时优化**信息增益、打断代价、安全风险与诱导偏差**，只在「问的价值 > 不问的代价」时开口。

严谨：交互动作 `a ∈ A_int = {ask, demo, probe, confirm, warn, yield, handover, wait, refuse}`。价值 `VoE(a) = E[IG_n(a) + IG_κ(a)] − λ_int·c_int(a) − λ_risk·risk(a) − λ_lead·lead(a)`；只有当 `VoE(a) > τ_ask` 且不触发更高优先级安全约束时才执行。非诱导约束：提问模板限定在中性集合 `A_neutral`，并要求预测的偏好偏移 `‖Δŵ(a)‖ ≤ ε_lead`；超限的问题直接剔除。对 `ask` 的候选问题用贪心贝叶斯实验设计（在自适应子模假设下具 `(1−1/e)` 近似）。

### 灵感 4（合流 → LINGO：语言—需求—物理三层闭环）

直觉：LIRO 的内环是「几何→技能→干扰→物理证书」；LINGO 在它外面套一层「语言/行为→需求信念→指令契约→主动询问→需求条件规划→语义监控→语义证书」。语言不再直接驱动阻抗，而是先变成**关于需求的证据**，再与行为证据融合，最后才进入物理规划。执行结果与用户纠正又反过来更新需求信念和技能先验。

严谨：`LINGO = (LIRO, NIBM, ICR, NCI, AEP, N-CSP, Shield-N, SCM, OLP-N, OCB-N, J_lingo)`。闭环：`[语言/行为 → NIBM → ICR/A → NCI 一致性 → AEP 询问 → N-CSP 规划 → Shield-N 优先级投影 → LIRO 物理执行 → SCM 语义监控 → 用户反馈/纠正 → NIBM/ICR 校准 → OLP-N 更新 → J_lingo]`。`J_lingo` 与 `J_liro` 是**两条独立的失效链**：物理证书有效不蕴含语义证书有效。

### 灵感 5（LIRO 组件的原位升级）

- **DMS → DMS-N**：从「解析意图」升级为「维护需求信念 + 指令契约 + 歧义后验」，输出 `(b_t, κ, A, χ_t)`。
- **Shield-Skill → Shield-N**：从「技能前置条件投影」升级为「优先级感知投影」——安全约束 ≻ 系统约束 ≻ 用户硬指令 ≻ 用户软偏好 ≻ 默认；不可满足时返回 `cannot_comply` 并解释，而不是偷偷违反高优先级。
- **CSP → N-CSP**：技能序列在「可信需求集 × 高后验解释集」上做鲁棒规划，目标含需求满足、语义合规、交互预算与打断代价。
- **OLP-Geo → OLP-N**：输入扩为 `x_lingo = [x'; z_need; z_instr]`，并因需求漂移改用动态遗憾/重启机制，给出切换遗憾界。
- **AIC → AIC-N**：干扰集增入「语言信道干扰」（ASR 噪声、否定吞音、指代缺失、对抗性歧义），认证 `ρ_sem` 与 `ρ_dir` 的联合下界。
- **SSB → SSB-N**：场景签名增入「需求—指令上下文」指纹（授权等级、歧义类型、纠正历史），使场景银行能检索「同类误解」。
- **OCB-Skill → OCB-N**：臂空间增入交互模式 `{passive, ask_only, demo_first, confirm_before_commit, refuse_over_risk}`，奖励扣除打断与诱导代价。
- **USL → USL-L**：技能的前置/后置谓词增加自然语言锚点与可学习谓词分类器，使 ICR 能把「轻一点/别碰/等一等」接地到具体技能参数与约束。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（LINGO 闭环）**：`LINGO = (LIRO, NIBM, ICR, NCI, AEP, N-CSP, Shield-N, SCM, OLP-N, OCB-N, J_lingo)`。定位：LIRO 的「需求—语言—交互」外层，不改变 LIRO 的物理接口与时序契约。
- **定义 202（隐需求过程）**：`n_t = (g_t, C_t^hard, C_t^soft, w_t, ρ_t^risk, τ_t^time, δ_t^social, α_t^auth) ∈ 𝒩`。需求按分段平稳切换过程演化：`n_{t+1} = n_t` 以概率 `1−β_t`，否则 `n_{t+1} ∼ Q(· | n_t)`；切换次数 `S_T` 未知，用于动态遗憾分析。
- **定义 203（NIBM 需求信念）**：`b_t(n) = P(n | L_{1:t}, B_{1:t}, E_{1:t}) ∝ b_{t-1}(n)·P(L_t, B_t | n)·P(E_t | n)`。`B_t` 为行为证据（注视、犹豫时长、手部回撤、纠正力、接管、接受/拒绝），`E_t` 为执行结果证据。神经编码器给似然，粒子滤波做多峰保持；语言可信度按一致性 `χ_t` 重加权：`λ_L = 1/(1+χ_t)`。
- **定义 204（可信需求集）**：`N_δ = {n : s(n) ≤ q_δ}`，`s` 为需求非一致性分数，`q_δ` 为分组保形分位数（按用户簇/任务族分组）。漂移下用 ACI 更新 `α_t`，保证长程覆盖率 `(1/T)Σ 1[n_t* ∈ N_δ] ≥ 1−α−o(1)`。
- **定义 205（指令契约）**：`κ = (speech_act, goal, refs, C^hard_L, C^soft_L, w^L, temporal, scope, conditions, authority, precedence)`。`refs` 为指代及其接地分数；`temporal` 为时序/因果骨架（before/after/until/if）；`authority` 为请求/建议/授权/试探；`precedence` 为与系统安全约束的优先级关系。
- **定义 206（歧义集与解释后验）**：`A = {(κ_i, p_i)}_{i=1}^{K} ∪ {(⊥, p_⊥)}`，`p_i = P(κ_i | L, context)`，`⊥` 表示不可解析/需澄清。歧义质量 `m_ε = Σ_{p_i<ε} p_i`；`m_ε > δ_amb` 时禁止直接执行硬约束，必须先询问或保守降级。
- **定义 207（语义合规裕度）**：对技能序列 `τ`，`ρ_sem(τ) = min_{n∈N_δ} min_{i: p_i≥ε} min_{t} ρ_{φ_i}(τ_{0:t}; n)`，其中 `φ_i` 是 `κ_i` 编译出的 STL 公式，`ρ_φ` 为 STL 鲁棒度。`ρ_sem ≥ 0` 表示在可信需求与高后验解释下均满足契约。
- **定义 208（主动询问价值）**：`VoE(a) = E[IG_n(a) + IG_κ(a)] − λ_int c_int(a) − λ_risk risk(a) − λ_lead lead(a)`，`IG_n = H(b_t) − E[H(b_{t+1})]`，`IG_κ = H(A) − E[H(A')]`。仅当 `VoE(a) > τ_ask` 且 `lead(a) ≤ ε_lead` 时执行。
- **定义 209（需求—指令一致性）**：`χ_t = D(b_t^{L}(n), b_t^{B}(n))`，即仅用语言与仅用行为得到的两个需求后验的差异（如 Jensen–Shannon 散度）。`χ_t > χ_max` 时标记 `semantic_conflict`：降低语言权重、触发确认而非静默覆盖。
- **定义 210（N-CSP 需求条件规划）**：`τ*, θ* = argmin E_{n∼b_t, κ_i∼A}[Σ cost(σ,θ;n,κ_i) + λ_sem·[ρ_{φ_i}<0] + λ_risk·risk]`，约束：`∀n∈N_δ, ∀i:p_i≥ε` 硬约束成立、`Shield-N` 优先级可行、交互预算 `Σc_int ≤ B_int`。实时仅展开首技能，后续重规划。
- **定义 211（OLP-N 需求条件在线投影）**：`K_W(x_lingo) = Π_0(x_lingo) + h(x_lingo)^T W`，`x_lingo = [x'; z_need; z_instr] ∈ ℝ^{d_lingo}`。需求漂移下目标为动态遗憾 `R_T = Σ_t [ℓ_t(W_t) − min_W ℓ_t(W)]`，采用重启/自适应步长，界 `O(√(T(1+S_T)))`（凸、Lipschitz、漂移有界时）。
- **定义 212（Shield-N 优先级屏蔽）**：优先级 `safety ≻ system ≻ user_hard ≻ user_soft ≻ default`。`θ* = argmin_{θ'∈Θ_pre(σ,φ̂,r,n,κ)} ‖θ'−θ‖`；若高优先级可行集为空，返回 `cannot_comply(violated, explanation)`，绝不把低优先级偏好投影进高优先级约束。
- **定义 213（SCM 语义合规监控器）**：将 `κ_i` 编译为 STL `φ_i`，在线计算 `ρ_{φ_i}(τ_t)`；原子谓词覆盖：禁入区域、力/速度上限、目标位置、朝向、接触模式、时序先后、条件触发、数量/身份约束。输出 `(ρ_sem, 违反谓词, 最早违反时刻, 责任解释候选)`。
- **定义 214（J_lingo 语义合规证书）**：`J_lingo = (J_liro, b_hash, κ_hash, coverage, ρ_sem, m_ε, χ_t, elicitation_log, precedence_ok, consent_ok)`。`Valid(J_lingo) ⇔ Valid(J_liro) ∧ coverage ≥ 1−α ∧ ρ_sem ≥ 0 ∧ m_ε ≤ δ_amb ∧ χ_t ≤ χ_max ∧ precedence_ok ∧ consent_ok`。
- **定义 215（OCB-N 交互感知预算老虎机）**：臂 `= {USL 模式} × {MEL 模式} × {交互模式} × {对齐开关}`，交互模式 `{passive, ask_only, demo_first, confirm_before_commit, refuse_over_risk}`；奖励 `progress − κ_c·compute − κ_i·c_int − κ_l·lead − κ_s·skill_switch`。
- **定义 216（非诱导约束）**：提问模板集合 `A_neutral` 满足：不引入话语中未出现的属性/量级/比较级；不把开放偏好压成二元选择；不暗示系统偏好。对 `a∈A_neutral`，要求 `lead(a) = sup_{u} ‖P(n|do(a),u) − P(n|u)‖ ≤ ε_lead`；否则剔除此问题。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（可信需求覆盖）**：若校准样本与部署样本在用户簇内可交换，则 `P(n* ∈ N_δ) ≥ 1−α`；漂移下 ACI 给出长程覆盖率 `≥ 1−α−o(1)`。**需求信念从点估计升级为可审计的集合。**
- **引理 6（语义合规传递）**：若 `ρ_sem(τ) ≥ 0`，且 STL 鲁棒度对需求参数 Lipschitz（常数 `L_n`），则真实需求满足概率 `≥ 1−α−δ_m`，其中 `δ_m` 为保形集合外风险。**语义证书把「在信念上合规」传递为「以概率合规」。**
- **引理 7（询问信息增益）**：对候选问题 `a`，`IG_n(a)` 等于需求后验与观测的互信息；在中性模板与自适应子模假设下，贪心选择达到 `(1−1/e)` 近似最优；加入打断代价后，仅在 `IG/c_int > λ_int` 时询问不劣于被动等待。
- **定理 4（LINGO 语义遗憾分解）**：`R_T^lingo ≤ R_T^liro + R_T^need + R_T^instr`，其中 `R_T^need = O(B·√(T·H(n)))` 来自需求信念熵，`R_T^instr = O(B·√(T·H(A)))` 来自解释集在线学习；需求漂移 `S_T` 次时物理/语义项各加 `O(√(T S_T))`。**语言与需求的不确定性被拆成可分别优化的遗憾项。**
- **定理 5（优先级安全）**：Shield-N 下，任何用户指令都不能使执行突破 `safety` 与 `system` 约束；若指令与高优先级约束冲突，系统必须返回 `cannot_comply` 并在 `J_lingo` 标记，而非静默违规。**语言不能覆盖安全，但可以触发解释与退出。**
- **命题（机制安全 ≠ 语义安全）**：存在指令 `L` 与策略 `τ`，使 `Valid(J_liro) = True` 而 `Valid(J_lingo) = False`（如否定作用域漏解析、指代接错物体、量级把「轻」当成「快」）。因此 `J_lingo` 不是 `J_liro` 的装饰，而是独立的失效链。
- **实时性**：实时路径新增 SCM 轻量监控（<0.15ms）、NIBM/契约嵌入查表（<0.05ms）、OLP-N 前向（<0.1ms），总计仍 ≤ 2ms；昂贵推理（ICR、AEP、N-CSP、保形校准）全部在语义流。

## 2. 形式化定义（完整版）

**定义 201（LINGO 闭环）** LINGO 是 LIRO 的「需求—语言—交互」外层：`LINGO = (LIRO, NIBM, ICR, NCI, AEP, N-CSP, Shield-N, SCM, OLP-N, OCB-N, J_lingo)`。不变式：
1. **语言不直接产生阻抗**：`L` 先变成需求证据 `(b_t, N_δ)` 与指令契约 `(κ, A)`，再经 N-CSP/Shield-N 进入 LIRO 的物理规划；
2. **两条证书链独立**：`Valid(J_liro)` 只保证物理执行安全，`Valid(J_lingo)` 额外保证语义合规与需求覆盖；任一失败都必须显式标记；
3. **时序隔离继承第 63 轮**：ICR/保形校准/AEP/N-CSP/OCB-N 全在语义流；实时流只做 SCM 轻量监控、嵌入查表、OLP-N 前向与 Shield-N 的小规模投影。

**定义 202（隐需求过程）** `n_t = (g_t, C_t^hard, C_t^soft, w_t, ρ_t^risk, τ_t^time, δ_t^social, α_t^auth) ∈ 𝒩`：
- `g_t`：目标（可由多个子目标组成）；
- `C_t^hard/C_t^soft`：硬约束/软约束（如禁入区域、最大力、可接受路径）；
- `w_t`：偏好权重（速度 vs 平稳、接近方式、交互风格）；
- `ρ_t^risk`：风险容忍；`τ_t^time`：时间容忍；`δ_t^social`：社交/礼貌约束；
- `α_t^auth`：用户授予的自主度/委托等级（0=逐步确认，1=完全授权）。
需求演化服从分段平稳切换过程：以概率 `1−β_t` 保持不变，否则 `n_{t+1} ∼ Q(·|n_t)`；切换次数 `S_T` 未知，用于动态遗憾。

**定义 203（NIBM 需求信念）** `b_t(n) ∝ b_{t-1}(n) · P(L_t, B_t | n) · P(E_t | n)`。
- 语言似然 `P(L_t|n)` 由指令编码器与 ICR 的候选解释近似：`P(L_t|n) ≈ Σ_i p_i · 1[n ⊨ κ_i]`（软化为核密度）；
- 行为似然 `P(B_t|n)` 由行为编码器给出（注视/犹豫/回撤/纠正力/接管/接受-拒绝）；
- 结果似然 `P(E_t|n)` 由执行结果与事后反馈给出。
- 语言可信度按一致性重加权：`λ_L = 1/(1+χ_t)`，`b_t ∝ b_{t-1}·[P(L_t|n)^{λ_L}·P(B_t|n)^{1−λ_L}]·P(E_t|n)`。
- 实现：神经编码器给粒子似然，粒子滤波保留多峰（例如「想要快」与「想要稳」两峰），避免早期错误消歧不可恢复。

**定义 204（可信需求集与漂移覆盖）** 非一致性分数 `s(n) = −log b_t(n) + λ_c·d(n, n̂_t)`（密度 + 距离）。在用户簇/任务族分组校准集上取 `q_δ`，使 `P(s(n*) ≤ q_δ) ≥ 1−α`。漂移下用 ACI：`α_{t+1} = α_t + γ(α − 1[n_t* ∉ N_δ])`，给出长程覆盖 `(1/T)Σ 1[n_t*∈N_δ] ≥ 1−α−o(1)`。`N_δ` 以粒子集/椭球并集表示，供 N-CSP 做鲁棒约束。

**定义 205（指令契约 ICR）** `ICR(L, scene, USL, b_t) → κ`：
- `speech_act ∈ {request, command, suggestion, permission, question, warning, delegation, smalltalk}`；
- `goal`：一阶逻辑目标谓词（与 USL 的 eff 对齐）；
- `refs = [(mention, entity_id, grounding_score)]`：指代接地，保留多个候选（「那个」→ {杯子 A:0.5, 杯子 B:0.3, 瓶子:0.2}）；
- `C^hard_L / C^soft_L`：语言中的硬/软约束（must/never vs prefer/gently）；
- `w^L`：语言偏好权重；`temporal`：before/after/until/while/if 的时序因果骨架；
- `scope`：否定/量词/条件的作用域树；`conditions`：条件触发；
- `authority`：请求/建议/授权/试探；`precedence`：与系统安全约束的关系（通常 user < safety）；
- 解析器：类型化 DSL + 语义解析模型 + 场景图约束；输出候选 `A` 而非单一逻辑式。

**定义 206（歧义集与解释后验）** `A = {(κ_i, p_i)}_{i=1}^{K} ∪ {(⊥, p_⊥)}`，`p_i = P(κ_i|L, context)` 由语义解析器、LLM 候选生成（仅生成候选，不直接执行）与场景图一致性重排序给出。`m_ε = Σ_{p_i<ε} p_i`。执行规则：
- `m_ε ≤ δ_amb` 且 `max_i p_i ≥ p_min`：可在高后验解释上规划；
- `m_ε > δ_amb` 或 `max_i p_i < p_min`：禁止直接执行硬约束，必须 AEP 询问或保守降级（如只执行可逆子技能）；
- `⊥` 后验最高：进入 `ask_clarify` 或 `refuse`。

**定义 207（语义合规裕度）** 将 `κ_i` 编译为 STL 公式 `φ_i`（原子谓词覆盖禁入、力/速上限、目标位置、朝向、接触模式、时序、条件、数量/身份）。对技能序列 `τ`：
`ρ_sem(τ) = min_{n∈N_δ} min_{i:p_i≥ε} min_{t∈[0,H]} ρ_{φ_i}(τ_{0:t}; n)`。
`ρ_{φ}` 为 STL 鲁棒度：正=满足且裕度为该值；负=违反。`ρ_sem` 是「在可信需求与高后验解释下的最坏语义裕度」。若 `ρ_sem` 不可计算（谓词不可微/不可观测），回退到离散监控 + 保守下界。

**定义 208（主动询问 AEP）** `A_int = {ask, demo, probe, confirm, warn, yield, handover, wait, refuse}`：
`VoE(a) = E[IG_n(a) + IG_κ(a)] − λ_int c_int(a) − λ_risk risk(a) − λ_lead lead(a)`，
`IG_n(a) = H(b_t) − E_{o∼P(·|a)}[H(b_{t+1})]`，`IG_κ(a) = H(A) − E[H(A')]`。
选择 `a* = argmax_{a∈A_int} VoE(a)`，仅当 `VoE(a*) > τ_ask` 且 `lead(a*) ≤ ε_lead`；否则 `a*=none`（继续执行/保守等待）。`c_int` 含时间、社交打断、信任损耗；`risk` 含询问期间的暂停风险与隐私风险。

**定义 209（需求—指令一致性 NCI）** `χ_t = D_JS(b_t^L, b_t^B)`，其中 `b_t^L` 仅用语言证据更新，`b_t^B` 仅用行为/结果证据更新。`χ_t > χ_max` 时：
1. 降低语言权重 `λ_L`；
2. 标记 `semantic_conflict`；
3. 触发 `confirm` 或 `probe`（不静默覆盖用户话语）；
4. 在 `J_lingo` 中记录冲突与处理方式。
不把「行为与语言不一致」直接解释为「用户口是心非」——也可能是行为噪声、习惯性回撤或系统误读；NCI 只负责提出假设并买信息。

**定义 210（N-CSP 需求条件规划）** 
`τ*, θ* = argmin_{τ,θ} E_{n∼b_t, κ_i∼A}[Σ_{j} cost(σ_j,θ_j; n, κ_i) + λ_sem·1(ρ_{φ_i}(τ;n)<0) + λ_risk·risk(τ;n)]`
约束：
1. `∀n∈N_δ, ∀i:p_i≥ε`，硬约束 `C^hard` 与 LIRO 的 ERTC/WCV 约束成立；
2. `Shield-N` 优先级可行；
3. 交互预算 `Σ_j c_int(a_j) ≤ B_int`；
4. 技能可行 `π_{σ_j} ∈ 𝒫_feas(φ̂,r)`（继承定义 200）。
求解：场景树/粒子上的鲁棒 A* + 参数 L-BFGS；实时只展开首技能，后续滚动重规划。若鲁棒可行集为空，返回「最小违反 + 显式询问/拒绝」而非强行执行。

**定义 211（OLP-N 需求条件在线投影）** `x_lingo = [x'; z_need; z_instr] ∈ ℝ^{d_lingo}`，`z_need = E_need(b_t)`（信念摘要），`z_instr = E_instr(κ,A)`（契约与歧义摘要）。`K_W(x_lingo) = Π_0(x_lingo) + h(x_lingo)^T W`。在线更新：
`W_{t+1} = P_𝒲(W_t − η_t ∇ℓ_t(W_t))`，`η_t = D/(G_lingo√(1+t))`。
因需求漂移，采用滑动窗/重启：当检测到 `χ_t` 或需求后验熵突变超过阈值时重启步长。目标为动态遗憾 `R_T = Σ_t[ℓ_t(W_t) − min_W ℓ_t(W)]`，在凸、Lipschitz、漂移有界假设下 `O(√(T(1+S_T)))`。

**定义 212（Shield-N 优先级屏蔽）** 令优先级 `safety ≻ system ≻ user_hard ≻ user_soft ≻ default`。对提案 `θ` 与技能 `σ`：
`θ* = argmin_{θ'∈Θ_pre(σ,φ̂,r,n,κ)} ‖θ'−θ‖₂`，`Θ_pre` 为所有高优先级可行约束的交（凸松弛为 QP/QCQP）。若交集为空：返回 `cannot_comply(violated_preds, explanation)`，并把冲突写入 `J_lingo`（`precedence_ok=False`）。**绝不把低优先级偏好投影进高优先级约束**；也绝不用「用户说了」覆盖安全。

**定义 213（SCM 语义合规监控器）** 将 `κ_i` 编译为 STL：`φ_i = G_{[0,H]}(ψ_1 ∧ ... ∧ ψ_m)`，其中原子谓词如 `dist(EE, region) ≥ d_safe`、`‖f‖ ≤ F_max`、`‖q − q_goal‖ ≤ ε_pos`、`contact_mode = grasp`、`before(pick, place)`、`if(temp<40°C, ¬grasp)`、`count(objects)=1`。在线计算鲁棒度 `ρ_{φ_i}(t)`（min-plus 语义），输出：
- `ρ_sem(t)`：对 `N_δ` 与 `p_i≥ε` 的最坏值；
- `violated_preds`：最早/最小鲁棒度的原子谓词；
- `violation_time`：最早可能违反时刻；
- `blame_candidates`：用于解释的候选原因（约束漏解析 / 需求变化 / 执行扰动 / 感知错误）。

**定义 214（J_lingo 语义合规证书）** `J_lingo = (J_liro, b_hash, κ_hash, coverage, ρ_sem, m_ε, χ_t, elicitation_log, precedence_ok, consent_ok)`。
`Valid(J_lingo) ⇔ Valid(J_liro) ∧ coverage ≥ 1−α ∧ ρ_sem ≥ 0 ∧ m_ε ≤ δ_amb ∧ χ_t ≤ χ_max ∧ precedence_ok ∧ consent_ok`。
- `coverage`：校准集上的可信集覆盖率与 ACI 长程覆盖率下界；
- `consent_ok`：用户在需要授权/隐私/接管时的同意状态；
- 审计链：`b_hash` 追溯需求证据，`κ_hash` 追溯指令解析与歧义集，`elicitation_log` 追溯问了什么/为什么问，`precedence_ok` 追溯是否发生过「语言 vs 安全」冲突。

**定义 215（OCB-N 交互感知预算老虎机）** 臂 `= USL_模式 × MEL_模式 × interaction_模式 × align`，`interaction_模式 ∈ {passive, ask_only, demo_first, confirm_before_commit, refuse_over_risk}`。为控制样本复杂度，实际聚合为 `K=20`（USL 4 × MEL 4 × interaction 5，align 由硬规则决定或并入 USL 模式）。奖励：
`r_t = progress_t − κ_c·compute_t − κ_i·c_int,t − κ_l·lead_t − κ_s·skill_switch_t`，归一化到 `[0,1]`。EXP3 更新 `w_a ∝ w_a·exp(η·r̂_t)`；硬降级规则继承 PCE+++++：交互模式不得突破当前安全/算力允许的最高等级。

**定义 216（非诱导约束）** 对提问模板 `a`：
1. 不引入话语中未出现的属性、量级、比较级（除非作为显式候选并标注）；
2. 不把开放偏好压成二元选择；
3. 不暗示系统偏好或社会期望；
4. `lead(a) = sup_u ‖P(n | do(a), u) − P(n | u)‖ ≤ ε_lead`。
不满足者从 `A_neutral` 剔除；AEP 只在 `A_neutral` 内搜索。`lead` 由离线偏好偏移实验估计，并在线用 A/B 校准。

### IP-204 NIBM（需求推断与信念）

```python
class NeedInferenceBeliefModel:
    """隐需求 n 的粒子信念 + 分组保形可信集 + 漂移 ACI。"""
    def __init__(self, n_particles=256, alpha=0.05, gamma_aci=0.01):
        self.particles = init_particles(n_particles)      # n ~ 先验
        self.weights = np.ones(n_particles) / n_particles
        self.enc_L = LanguageEvidenceEncoder()
        self.enc_B = BehaviorEvidenceEncoder()
        self.enc_E = OutcomeEvidenceEncoder()
        self.alpha, self.gamma = alpha, gamma_aci
        self.q_delta = {cluster: 1.0 for cluster in CLUSTERS}  # 保形分位数

    def update(self, L, B, E, chi):
        lam_L = 1.0 / (1.0 + chi)                          # 语言可信度
        for p in self.particles:
            lik_L = self.enc_L.likelihood(L, p.n) ** lam_L
            lik_B = self.enc_B.likelihood(B, p.n) ** (1 - lam_L)
            lik_E = self.enc_E.likelihood(E, p.n)
            self.weights[p.id] *= lik_L * lik_B * lik_E
        self.weights = normalize(self.weights)
        self.particles = resample_if_needed(self.particles, self.weights)
        return self._belief()

    def credible_set(self, cluster):
        scores = [-np.log(w + 1e-12) + LAMBDA_C * dist(p.n, self.mean()) 
                  for p, w in zip(self.particles, self.weights)]
        return [p.n for p, s in zip(self.particles, scores) 
                if s <= self.q_delta[cluster]]

    def calibrate(self, calib_pairs):
        # 分组保形：每个用户簇单独取分位数
        for cluster, pairs in group_by_cluster(calib_pairs).items():
            scores = [self.nonconformity(n_star, evidence) for n_star, evidence in pairs]
            self.q_delta[cluster] = np.quantile(scores, 1 - self.alpha)

    def aci_update(self, covered: bool):
        self.alpha = np.clip(self.alpha + self.gamma * (self.alpha - (not covered)), 1e-3, 0.5)

    def entropy(self):
        return -np.sum(self.weights * np.log(self.weights + 1e-12))
```

### IP-205 ICR（指令契约与歧义集）

```python
class InstructionContractRepresentation:
    """语言 → 类型化契约 κ + 歧义集 A；LLM 只生成候选，不直接执行。"""
    def __init__(self, parser, grounder, usl):
        self.parser, self.grounder, self.usl = parser, grounder, usl

    def ground(self, L, scene_graph, b_t):
        # 1) 句法/语义解析：言外之力、作用域树、时序骨架
        parse = self.parser.parse(L)
        # 2) 指代/实体接地：保留多候选
        refs = self.grounder.ground_mentions(parse.mentions, scene_graph)
        # 3) 候选解释生成（规则 + LLM rerank，仅候选）
        candidates = self._generate_candidates(parse, refs, b_t)
        A = self._posterior(candidates, L, scene_graph, b_t)
        # 4) 编译为契约
        kappa = InstructionContract(
            speech_act=parse.speech_act,
            goal=self._to_logic(parse.goal, refs),
            refs=refs,
            C_hard_L=parse.must_constraints,
            C_soft_L=parse.prefer_constraints,
            w_L=parse.preference_weights,
            temporal=parse.temporal_graph,
            scope=parse.scope_tree,
            conditions=parse.conditions,
            authority=parse.authority,
            precedence=self._precedence(parse))
        return kappa, A

    def _posterior(self, candidates, L, scene, b_t):
        logits = [self._score(k, L, scene, b_t) for k in candidates]
        return softmax_with_abstention(logits)          # {(κ_i,p_i)} ∪ {(⊥,p_⊥)}

    def compile_to_stl(self, kappa, delta=0.0):
        # 硬约束→G(ψ)；软偏好→加权鲁棒度；时序→Until/Since；条件→Implies
        return STLFormula.from_contract(kappa, margin=delta)
```

### IP-207 AEP（主动询问）

```python
class ActiveElicitationPlanner:
    """VoE = 信息增益 − 打断 − 风险 − 诱导；只在价值足够时开口。"""
    def __init__(self, lambdas, tau_ask=0.05, eps_lead=0.05):
        self.lam, self.tau_ask, self.eps_lead = lambdas, tau_ask, eps_lead

    def choose(self, b_t, A, budget, risk_state):
        best, best_voe = None, -np.inf
        for a in INTERACTION_ACTIONS:
            if a.type == 'ask' and a not in NEUTRAL_TEMPLATES: 
                continue
            ig = mutual_information(b_t, a) + mutual_information(A, a)
            lead = estimate_leading(a, b_t)
            if lead > self.eps_lead:
                continue                                   # 非诱导硬约束
            voe = (ig - self.lam['int'] * interrupt_cost(a)
                      - self.lam['risk'] * risk(a, risk_state)
                      - self.lam['lead'] * lead)
            if voe > best_voe:
                best, best_voe = a, voe
        if best_voe <= self.tau_ask or budget <= 0:
            return InteractionAction('none')
        return best
```

```python
class NeedConditionedSkillPlanner:

        # 场景树：每个粒子需求 × 每个高后验解释

            if not self._robust_feasible(tau, scenarios, phi_hat, r):

            if obj < best_obj:
```

### IP-209 Shield-N（优先级屏蔽）

```python
def shield_priority_aware(theta_prop, skill, phi_hat, r, n, kappa):
    """优先级 safety ≻ system ≻ user_hard ≻ user_soft ≻ default。"""
    levels = build_priority_constraints(skill, phi_hat, r, n, kappa)
    theta = theta_prop
    for level in ['safety', 'system', 'user_hard', 'user_soft', 'default']:
        if not levels[level]: 
            continue
        feasible = intersect_constraints(levels[level], theta)
        if feasible.is_empty():
            if level in ('safety', 'system'):
                return ShieldResult('cannot_comply',
                                    violated=feasible.violated,
                                    explanation=explain(level, feasible))
            # 低优先级不可行：记录并放弃该层，不侵入高优先级
            continue
        theta = solve_qp_min_norm(theta, feasible)
    if norm_inf(theta - theta_prop) > DELTA_SKILL:
        return ShieldResult('ask_clarify', theta_star=theta,
                            violated=identify_violated(theta_prop, levels))
    return ShieldResult('lock', theta_star=theta, shielded=True)
```

## 4. 推导

**引理 5（可信需求覆盖）** 设校准集与部署样本在用户簇 `c` 内可交换，非一致性分数 `s` 固定。分组保形取 `q_δ^{(c)} = Quantile_{1−α}({s(n_i*, E_i)}_{i∈c})`，则 `P(n* ∈ N_δ | c) ≥ 1−α`。漂移下 ACI 更新 `α_{t+1}=α_t+γ(α−1[n_t*∉N_δ])`，在 `γ→0`、有界损失下长程覆盖 `(1/T)Σ 1[n_t*∈N_δ] ≥ 1−α−o(1)`（Gibbs–Candès 型结论）。**需求不再是点估计，而是带覆盖保证的集合。** ∎

**引理 6（语义合规传递）** 设 `ρ_sem(τ) ≥ 0`，且 STL 鲁棒度对需求参数 `n` 是 `L_n`-Lipschitz：`|ρ_φ(τ;n) − ρ_φ(τ;n')| ≤ L_n‖n−n'‖`。若 `n* ∈ N_δ`，则 `ρ_φ(τ;n*) ≥ ρ_φ(τ;n̂) − L_n·diam(N_δ) ≥ −L_n·diam(N_δ)`。要使真实需求满足，需要 `ρ_sem ≥ L_n·diam(N_δ)`（保守裕度）；若只保证 `≥0`，则满足概率至少 `1−α−δ_m`，`δ_m` 为 `N_δ` 外风险。**语义证书的强度由可信集直径与鲁棒度 Lipschitz 常数共同决定。** ∎

**引理 7（询问信息增益与贪心）** 对候选交互 `a`，`IG_n(a) = I(n; O_a | evidence) = H(b_t) − E[H(b_{t+1})]`。若观测模型条件独立且 `IG_n` 对候选集自适应子模，则贪心选择在 `k` 次询问内达到 `(1−1/e)` 最优。加入打断代价后，目标变为 `IG − λ_int c_int`；当且仅当 `IG/c_int > λ_int` 时询问优于等待。非诱导约束把可行集限制为 `A_neutral`，只会降低可达信息增益，不破坏安全。∎

**定理 4（LINGO 语义遗憾分解）** 令 `a_t^*(n*)` 为已知真实需求与真实解释下的最优动作。则
`R_T^lingo = Σ_t [ℓ(n_t*, a_t) − ℓ(n_t*, a_t^*(n_t*))]`
`= Σ_t [ℓ(n_t*,a_t) − ℓ(n̂_t,a_t)] + Σ_t [ℓ(n̂_t,a_t) − ℓ(n̂_t,a_t^*(n̂_t))] + Σ_t [ℓ(n̂_t,a_t^*(n̂_t)) − ℓ(n_t*,a_t^*(n_t*))]`
`= R_T^need + R_T^liro/N-CSP + R_T^instr`。
- 第一项由需求估计误差驱动，`≤ L_ℓ·Σ_t ‖n_t*−n̂_t‖`；若 `n*∈N_δ` 且 `diam(N_δ)≤Δ_n`，则 `R_T^need ≤ L_ℓ·Δ_n·T`；在在线学习视角下可做到 `O(B√(T·H(n)))`。
- 第二项是 N-CSP 在信念上的规划/执行遗憾，继承 LIRO 定理 2 与 CSP 的 anytime 界；在可信集上做鲁棒规划，最坏多付 `O(L_n·Δ_n·T)`。
- 第三项是解释误差，用指数权重在 `A` 上在线学习，`R_T^instr ≤ B√(2T log|A|)`。
需求漂移 `S_T` 次时，第一/二项加动态遗憾 `O(√(T(1+S_T)))`。**语言与需求的不确定性被拆成可分别优化的项；这是 LINGO 相对 LIRO 的净增遗憾。** ∎

**定理 5（优先级安全）** Shield-N 按 `safety ≻ system ≻ user_hard ≻ user_soft ≻ default` 逐层投影，且在高优先级不可行时返回 `cannot_comply` 而不降级违反。归纳：每层投影后的 `θ` 满足所有已处理层的约束；高优先级层从不被后续层修改（后续层只在剩余自由度上做最小范数投影）。故最终 `θ*` 满足 `safety ∧ system` 约束；若不可行，则执行停止且证书标记。**语言不能覆盖安全，但能触发解释、退出与人工接管。** ∎

**命题（机制安全 ≠ 语义安全）** 构造：场景中有左、右两个杯子；指令 `L =「别把左边那个放上去」`。若 ICR 漏掉否定作用域，得到 `κ' =「把左边那个放上去」`；LIRO 在 `κ'` 下可完美满足物理约束并输出 `Valid(J_liro)=True`，但 `Valid(J_lingo)=False`。因此 `J_lingo` 必须独立校验 `κ` 与 `ρ_sem`，不能用 `J_liro` 替代。∎

**命题（非诱导询问的偏好偏移界）** 若每个问题 `a` 满足 `lead(a) ≤ ε_lead`，且偏好更新对问题是 `1`-Lipschitz 的，则 `k` 次询问后累计诱导偏移 `≤ k·ε_lead`。把 `k` 纳入交互预算 `B_int`，可得 `‖ŵ_T − ŵ_0‖ ≤ (B_int/c_min)·ε_lead`。**这是「问得越多越可能塑造需求」的显式预算，而不是无约束的主动学习。** ∎

**正确性定理（LINGO-Complete）** 假设第 63 轮 A61–A82 及：
- **(A83)** 需求过程分段平稳，切换次数 `S_T` 有限；用户簇内校准样本与部署样本可交换（或 ACI 长程覆盖成立）。
- **(A84)** 真实指令解释 `κ*` 属于候选解释集 `A`（无解析器盲点）；`p(κ*) > 0`。
- **(A85)** STL 鲁棒度对需求参数 `L_n`-Lipschitz，且监控原子谓词可观测或可由传感器保守下界估计。
- **(A86)** 行为证据 `B` 与需求 `n` 条件独立于语言给定（或 NCI 能检测其偏离并降权）。
- **(A87)** 非诱导模板集 `A_neutral` 覆盖必要澄清问题，且 `lead(a) ≤ ε_lead`。
- **(A88)** Shield-N 的优先级约束可凸松弛为 QP/QCQP，且高优先级可行集可判定。
- **(A89)** OLP-N 损失凸、Lipschitz，漂移有界；重启机制可检测需求突变。
- **(A90)** 实时路径新增组件总延迟 ≤0.3ms，无学习写操作。

则：
1. **需求可覆盖**：`P(n*∈N_δ) ≥ 1−α`（引理 5）；语义合规在真实需求上的概率 `≥1−α−δ_m`（引理 6）。
2. **语义可认证**：`Valid(J_lingo) ⇒` 物理安全 ∧ 语义合规 ∧ 歧义受控 ∧ 一致性可接受 ∧ 优先级正确（定义 214 + 定理 5）。
3. **语言不能越权**：任何用户指令都不能突破 `safety/system`；冲突时显式 `cannot_comply`（定理 5）。
4. **交互有预算**：询问只在 `VoE>τ_ask` 且 `lead≤ε_lead` 时发生；累计诱导偏移有界（引理 7 + 命题）。
5. **遗憾可分解**：`R_T^lingo ≤ R_T^liro + R_T^need + R_T^instr`；需求漂移加 `O(√(T S_T))`（定理 4）。
6. **两条证书链独立**：存在 `Valid(J_liro) ∧ ¬Valid(J_lingo)` 的反例（命题），故不能相互替代。
7. **实时性可控**：实时路径 ≤2.0ms，语义推理全部在语义流（表 + A90）。

## 7. 已知风险

**一句话**：若 ICR 的候选解释集 `A` 漏掉了真实解释（否定/量词/指代/条件的作用域错误，或解析器系统性盲点），NIBM 就在错误的假设空间上做贝叶斯推断、SCM 在错误的契约上监控、`J_lingo` 会自洽而高置信地证明一个错误需求的合规性——**语义证书从「保证做对」反变为「精确地做错」，这是本轮所有需求—语言论证共同依赖的单点假设（A84）。**

**次级风险与缓解**：
1. **需求不可识别**：有限证据下多个需求后验等价 → 保留多峰粒子，不强行点估计；`m_ε` 或后验熵过高时只执行可逆技能并主动询问。
2. **行为证据隐私/误读**：注视/生理信号可能侵犯隐私或误判 → 最小化采集、端侧处理、显式同意；NCI 只提出假设，不直接断言「用户口是心非」。
3. **提问操纵与伪需求**：AEP 可能通过提问塑造偏好 → 非诱导硬约束（定义 216）+ 提问日志审计 + 偏好偏移预算；E230 专门测操纵感知。
4. **语言信道对抗**：ASR 噪声、否定吞音、注入指令 → AIC-N 扩展干扰集；低置信时要求确认或拒绝；优先级屏蔽保证安全不被语言覆盖。
5. **保形覆盖失效**：用户簇漂移/样本非交换 → ACI + 分组校准 + 覆盖率在线监控；覆盖不足时证书标记 `coverage_degraded`，禁止高自主度执行。
6. **语义监控不可观测**：部分谓词（意图、社交规范）无法直接观测 → 只对可观测子集给硬保证，其余降级为软偏好并在 `J_lingo` 标注 `partial_semantics=True`。
7. **计算预算超支**：ICR/N-CSP/AEP 在语义流可能超时 → anytime 解析/规划 + 硬时间预算；超时回退到保守解释（`⊥`）与 `ask/refuse`，而不是猜。
8. **用户自主度被系统侵蚀**：Shield-N 以安全为名过度拒绝 → 所有 `cannot_comply` 必须附可理解的解释与人工接管路径；`consent_ok` 与 `authority` 进入证书，支持用户申诉与策略调整。
