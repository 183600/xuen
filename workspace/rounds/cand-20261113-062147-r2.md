# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因闭环」IP-214~223；灵感循环第 2 轮；本轮灵感：「具身智能大模型」×「事件相机」）

> 第 65 轮把"几何可证伪"升级为"故障可归因"，其自述的最大风险是致命的：**VISTA 的归因能力依赖"故障属于有限假设集、且视觉与几何的失效相互独立"这两个假设；真实故障常是未知类型的组合，且透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——系统因"已经归因"而更自信地继续执行。** 第 66 轮不更换闭环骨架，而是正面攻击这两个假设：
>
> **用「事件相机」引入一个物理正交的瞬态通道，把"视觉-几何共因"从统计假设变成可被物理分离的对照实验；用「具身智能大模型」做"假设生成器"而非"假设选择器"，让未知故障不再被强行塞进最近假设，而是先被承认"没见过"、再用新鲜物理证据决定是否准入。**

## 0. 直觉与动机

**灵感 1（事件相机 → 不是"更好的相机"，而是"物理正交的瞬态显微镜"）**
直觉：第 65 轮把视觉当第三条可错证据，但它的视觉是**帧式 RGB**，失效结构与几何高度相关：透明、镜面、静态对抗 patch、强光饱和，会同时污染"视觉足迹"和"几何先验的视觉校正"，这正是第 65 轮最怕的**共因故障**。事件相机（DVS/DAVIS）的物理原理完全不同：每个像素只在**对数亮度变化超过阈值 C 时**才异步输出一个 `(x,y,t,sign)` 事件。由此得到三个别人没有的性质：(i) **微秒级延迟**——能在力传感器建立接触读数之前抓到接触起始与初始滑移；(ii) **~120–140 dB 高动态范围**——强光/反光下不饱和；(iii) **只对时间变化响应**——一个**静止的**对抗 patch、贴纸、透明膜产生的**事件数≈0**。第 (iii) 点至关重要：当帧式视觉与几何同时报"异常"、而事件通道在**静止**时保持沉默，这本身就是"静态外观伪故障（H_vis/H_common）"而非"真实物理几何错（H_geo）"的**物理证据**，而不是又一条需要相信的学习特征。必须诚实：事件相机在**准静态**段失明（无亮度变化就没有事件）、在无纹理处有孔径问题、低光噪声大；所以它只能当"**瞬态显微镜**"，不能当稳态观测器。

**灵感 2（具身智能大模型 → 做"假设生成器"，绝不"假设选择器"）**
直觉：第 65 轮闭集 FIR 的固有缺陷是 `ℋ={H0,H_geo,H_force,H_model,H_vis,H_policy}` 之外的一切都会坍缩到最近假设。具身智能大模型（VLA / 机器人基础模型）的真正价值不是"更强的动作策略"，而是它能把**多模态残差摘要 + 语言任务上下文**翻译成一句"我怀疑发生的是 X"的**自然语言故障描述**和一个**可检验的签名模板**（哪些传感器、哪个阶段、什么方向、跨模态耦合该是什么符号）。它天生能处理**开放集**：没见过的东西它至少能用语言近似描述。但它是黑箱、会幻觉、非确定、延迟百毫秒到秒级。因此正确的架构是：**大模型只负责"长出新的故障头（假设）"，事件/力/几何负责"用新鲜物理证据决定这个头该不该被承认"**。它是"提案者（proposer）"，不是"裁决者（selector）"，更不是控制器——它**永远不能**授权动作、不能直接选球、不能进实时环。

**灵感 3（三灵感合流 → HYDRA：Hypothesis-Yielding Discrepancy-driven Residual Attribution，开源式故障归因闭环）**
直觉：Hydra 每被砍掉一个头就长出两个——正是"未知故障不会被强行塞进旧头，而是长出新头"的隐喻。闭环：事件瞬态接地（EEG）→ 跨模态共因分离检验（CCT，用事件沉默区分静态伪故障与真实物理故障）→ 闭集 FIR 先试归因 → 若**新颖性检验**判定"没有已知假设能解释"→ 触发开放集假设生成（OHG，VLA 用语言提出新故障 + 签名模板）→ 事件 only 的**零接触运动视差探针**（AFA-O，不碰易损物）→ **开放集假设准入**（OFA：必须同时满足模板相容、已知集仍不解释、物理安全、耦合符号匹配）→ 准入则定向处理新球 `r_open`，不准入则**开放集弃权**（保守联合膨胀 + `k*=0` 安全待机）。第 65 轮是"几何-技能-干扰-接触-归因"五层，HYDRA 在"归因"这一层上再加一条**开放集边界**，并让"承认不知道"成为一个**受认证的一等状态**。

**灵感 4（VISTA 组件的原位升级）**
- **VPG → VPG-E / EEG**：视觉世界模型之外增设事件点过程模型，用 Hawkes 自激发分支比检测初始滑移、用首事件时刻标定接触起始。
- **VCV → VCV-E**：接触验证增"事件沉默"判据；事件沉默**只在有诱导运动的可观测窗内**才算证据，静止时 `event_unobservable` 不得否决接触。
- **FIR → FIR-O**：闭集后验之外增**新颖性分数**与**开放集出口**；不再"argmax 最近假设"。
- **OHG（新增）**：VLA 假设生成器，输出语言描述 + 签名模板 + 溯源哈希 + 过期时间。
- **OFA（新增）**：开放集假设准入，四条件联合门，带误准入预算 `β_adm`。
- **AFA → AFA-O**：探针目标从"分辨已知故障"升级为"分辨'是否为新故障'"，优先事件 only 零接触探针。
- **CSC → CSC-O**：开放集弃权时 `k*=0`（安全待机/柔顺撤退），把"不执行"也纳入证书。
- **RSC-V → RSC-O / WCV-V → WCV-O**：增 `r_open` 与 `w_evt`；弃权时联合膨胀含 `r_open_max`。
- **AIC-V → AIC-O**：干扰集增**事件注入**（闪烁 LED 伪造滑移）、事件噪声/去同步、以及**VLA 提示注入/幻觉**作为显式故障源。
- **J_vista → J_hydra**：证书增 `hypothesis_set_version`、`novelty_pvalue`、`admitted_hypothesis_hash`、`event_grounding_hash`、`event_obs_window`、`vla_provenance_hash`、`vla_staleness`、`adm_test_ver`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（HYDRA 闭环）**：HYDRA = (VISTA, EEG, CCT, FIR-O, OHG, OFA, AFA-O, CSC-O, RSC-O/WCV-O, AIC-O, J_hydra)。定位：VISTA 的"开放集 + 物理正交证据"升级。不变式：**事件世界模型、共因检验、新颖性、VLA 假设生成、准入判定、证书只在语义流；实时流只做事件 ROI 触发、阶段化残差采集、安全前缀执行与早停，零学习写操作；VLA 只许生成假设，不许选择假设或授权动作。**
- **定义 234（事件流与事件任务观测量）**：事件流 `E={(x_k,y_k,t_k,s_k)}`，当 `|L(x,y,t)−L(x,y,t_last)|≥C` 时触发，`L=log intensity`，`s_k∈{+1,−1}`。事件任务观测量 `y_evt(t)` =（运动掩码 `M_t`、事件法向/切向流 `(u_n,u_t)`、接触起始时刻 `τ_c`、滑移指示 `β_t`、形变率 `u̇`）。与定义 218 的帧式 `y_t` 并列，构成第三条**物理独立**观测。
- **定义 235（事件点过程残差与保形校准）**：事件世界模型 `g_evt` 给出条件强度 `λ(x,t|y_t,A_t)`（自由空间用非齐次泊松，滑移段用 Hawkes 自激发），对数似然 `ℓ(E)=Σ_k log λ(e_k) − ∫λ`。用时间重整化残差 `r_k=1−exp(−(Λ(t_k)−Λ(t_{k−1})))` 应服从 U(0,1)；取非一致性分数 `s_evt = sup_t|F̂(t)−t|`（时间重整化 KS 距离），split-conformal 得 `q_evt(α)`，`e_evt>q_evt(α)` 即"事件与预测不符"。**滑移**由 Hawkes 分支比 `β=∫h(τ)dτ → 1⁻` 且切向事件率爆发共同判定。
- **定义 236（事件失明域与可观测窗）**：事件失明域 `Blind = {(x,t): |∂L/∂t| < C/Δt}`，即准静态/无纹理/饱和前。事件可观测窗 `W_evt = {t: 预测时间对比度 > C/Δt}`。只有 `t∈W_evt` 时事件残差才进入签名；`t∉W_evt` 标记 `event_unobservable`，**不得据此否决接触/滑移**。事件是"瞬态显微镜"，不是稳态观测器。
- **定义 237（故障假设集的开放集结构）**：闭集已知集 `ℋ_K={H0,H_geo,H_force,H_model,H_vis,H_policy}`（定义 221）；生成集 `ℋ_?` 为 OHG 产生的候选，每个 `h` 带签名模板 `T_h`；准入集 `ℋ_A⊆ℋ_?` 为本回合被 OFA 承认的新故障。`hypothesis_set_version = H(ℋ_K∪ℋ_A)`。**未知故障的默认归宿是 `ℋ_?` 或弃权，而不是 `argmax_{ℋ_K}`。**
- **定义 238（开放集新颖性检验）**：混合密度 `p_K(ρ)=Σ_{h∈ℋ_K∪ℋ_A} π_h p_h(ρ)`，新颖性分数 `n(ρ)=−log p_K(ρ)`。仅在**已知故障**标定残差上算 `n_i`，取保形阈值 `q_nov(α)`；`n(ρ)>q_nov(α)` 即"没有已知假设能解释"，输出 p 值 `p_nov=(1+Σ_i 1[n_i≥n(ρ)])/(N+1)`。**注意：该检验的标定集默认代表"已知世界"，这是本轮的自指盲点（见风险）。**
- **定义 239（跨模态共因分离检验 CCT）**：令 `a_frame,a_geo,a_evt,a_force` 为各通道块内异常分数，`κ_cross = partialcorr(a_frame, a_evt | a_force, 预测运动)`。核心物理命题：(i) **静态外观伪故障**（透明/镜面/静止 patch/强光）只污染帧式外观，事件在静止时不响应，故 `κ_cross≈0`；(ii) **真实物理故障**（几何幻觉导致真实刮蹭/形变）同时驱动帧式与事件，故 `κ_cross>0`。判据：`κ_cross>κ₀` 且力残差高 → 物理（H_geo/H_model）；`κ_cross≈0` 且事件正常、帧式异常 → 外观伪故障（H_vis/H_common），**不得膨胀几何球**；`κ_cross` 模糊 → 开放集弃权。这把 VISTA 的"独立性假设"换成了**符号可检验的物理对照**。
- **定义 240（大模型假设生成器 OHG）**：`G_ψ` 输入结构化摘要 `S_t=(ρ, y_frame, y_evt, 力迹, 语言任务, 当前 ℋ)`，输出 `(z, T_h)`：`z` 为自然语言故障描述，`T_h=(传感器子集, 阶段局部性, 期望方向/符号, 期望跨模态耦合符号 κ_expected, 期望事件签名)`。附溯源 `h_prov=H(模型权重, 提示, S_t)` 与过期时间 `T_stale`。**`G_ψ` 是生成沙箱：不输出动作、不输出安全判决、不进入实时环。**
- **定义 241（大模型语义易损先验与安全预算）**：VLA 由语言+图像给出易损先验 `p_fragile` 与语义安全力 `f̂_safe_sem`。融合规则**只允许收紧、不允许放宽**：`f_safe = min(f_safe_phys, f̂_safe_sem)`。于是 VLA 幻觉在力预算上**只能更保守**，天然失效安全；但仍须事件/力探针确认，不得仅凭语义放行。
- **定义 242（开放集假设准入 OFA）**：给定提案 `h`（模板 `T_h`）与新鲜探针签名 `ρ_p`，`Admit(h)` 当且仅当四条件全满足：(A1) 模板相容 `log p(ρ_p|T_h) ≥ τ_comp`；(A2) 已知集仍不解释 `∀h'∈ℋ_K∪ℋ_A, p_nov^{h'}(ρ_p)<α_nov`；(A3) 物理安全且**该探针确实激励了所假设的通道**（`f≤f_safe`、`strain≤ε_strain`、`ρ_p` 对应的 `W_evt` 或力通道活跃）；(A4) 耦合符号匹配 `|κ_cross−κ_expected|≤ε_κ`。误准入率预算 `P[Admit|h 非真]≤β_adm`（在注入新故障标定上校准 `τ_comp,α_nov`）。四缺一即回退开放集弃权。
- **定义 243（开放集归因后继处置）**：三出口——(i) 闭集定向（同 VISTA）；(ii) 准入新故障 `H_new`：只膨胀新球 `r_open` 并绑定模板处置；(iii) **开放集弃权**：`r=√(r_geo²+r_force²+r_model²+r_open_max²)` 联合膨胀、`k*=0`、`safe_idle`/`compliant_retreat`，并把 `novelty_pvalue` 与 `hypothesis_set_version` 写证。**绝不再"强行 argmax 最近已知假设"。**
- **定义 244（开放集判别探针 AFA-O）**：`a*=argmax_a [ I(是否为新故障; ρ_probe|ρ_past) + λ·I(ℋ;ρ_probe) ]`，s.t. `f≤f_safe`、`strain≤ε`、且 `W_evt` 被激励。探针集 `A={event_parallax, event_null_test, visual_probe, light_touch, press, rub}`：**前两个零接触**——`event_parallax` 让相机做相对平移诱导运动视差、用事件恢复几何（尤其高动态/反光/无纹理但有边缘的物体）；`event_null_test` 在自由空间运动，若力读数偏移而事件安静 → 判 H_force（力传感器说谎，因为真接触必产生运动/形变事件）。易损物体禁用接触探针。
- **定义 245（开放集认证前缀 CSC-O）**：弃权态 `k*=0`（除单独认证的柔顺撤退微前缀）；准入态支持集含 `H_new` 的模板最坏界。风险预算扩为 `P[越界] ≤ α_chunk + β_adm + α_evt + α_vis + δ_fi`。执行器只执行 `k*` 步即强制重规划与再归因。
- **定义 246（RSC-O / WCV-O）**：维护 `r_geo,r_force,r_model,r_open` 与 `w_vis,w_evt`。只对被承认者定向膨胀；`H_vis` 且 `κ_cross≈0` 时降 `w_vis` 但**不动** `r_geo`；事件注入被识别时降 `w_evt`。WCV 搜索域增 `𝒱_evt`（事件可观测窗约束），弃权时用含 `r_open_max` 的联合膨胀。CVaR `n_worst=8`。
- **定义 247（开放集对抗认证 AIC-O）**：`ℰ_O=ℰ_V×ℰ_evt×ℰ_vla`。`ℰ_evt` 含**闪烁 LED 事件注入**（伪造滑移爆发）、低光事件噪声、事件去同步/丢包；`ℰ_vla` 含**场景文字提示注入**、幻觉提案（披着合理语言的错误假设）、模型版本漂移、延迟尖峰。要求：事件注入下不得越过 `α_chunk`；幻觉提案因不满足 A3（无对应物理通道激励）或 A4（耦合符号不符）而**不可被准入**。`n_cert 128→160`，新增 32 给事件/VLA。
- **定义 248（HYDRA 证书 J_hydra 与闭环算子）**：`J_hydra=(J_vista, hypothesis_set_version, novelty_pvalue, admitted_hypothesis_hash, event_grounding_hash, event_obs_window, vla_provenance_hash, vla_staleness, adm_test_ver, aic_o_ver)`。`Valid(J_hydra) ⇔ Valid(J_vista) ∧ (闭集归因 ∨ (新颖性触发 ∧ (H_new 已准入 ∨ 开放集弃权且 k*=0)) ) ∧ VLA 提案仅用于生成 ∧ event_unobservable 未被用于否决接触 ∧ 准入检验版本当前 ∧ vla_staleness≤T_stale`。语义流 `[…→EEG→CCT→FIR-O→(新颖?→OHG→AFA-O→OFA)→RSC-O→WCV-O→CSP-V→CSC-O→…]`；实时流 `[事件 ROI 触发→阶段判定→CSC-O 早停→派发→J_hydra 构建]`。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（事件瞬态可分离性）**：在可观测窗 `W_evt` 内，事件残差对故障假设的条件互信息 `I(ℋ;ρ_evt|ρ_frame,ρ_force)>0`；线性化下它给签名矩阵 `S` 增加一列，且该列与力/几何列近正交，故 `κ_fi` 严格增大——事件通道不是重复信息，而是**新增可辨识维度**。
- **引理 10（共因分离）**：静态外观伪故障下 `κ_cross→0`，真实物理故障下 `κ_cross>0`；给定估计方差，符号检验把"H_vis/H_common vs H_geo"的误判率压到 `2Φ(−κ₀/σ_κ)` 量级。**这把第 65 轮"视觉与几何独立"的不可证假设，换成了可证伪的物理符号检验。**
- **引理 11（准入误报界）**：若标定可交换、新颖性保形有效，则 `P[Admit(h)|h 非真]≤β_adm`；结合 A3（物理通道必须被真实激励）与 A4（耦合符号），幻觉提案被准入的概率不超过 `β_adm`。
- **定理 9（HYDRA 开放集安全）**：在 A94–A99 下，`Valid(J_hydra)` ⇒（闭集正确 ∨ 新故障已准入并定向处置 ∨ 开放集弃权保守降级），且任一块的风险 `≤ R_abstain(VISTA) + β_adm·Δ_risk`。**开放集生成相对"弃权"是安全的单调改进，唯一代价是 `β_adm` 的误准入预算。**
- **定理 10（两时钟）**：事件延迟 μs、VLA 延迟 ≫ 实时 deadline；只要 VLA 仅扩充支持集、准入必须新鲜物理证据且过期即作废，则实时路径延迟不变（`≤2.6ms`），开放集推理全部留在语义流。
- **命题（开放集的分辨率极限）**：有限已知集标定下，若新故障签名与已知混合分布总变差 `≤ε`，则任何检验在水平 `α` 下都无法可靠标新；故"承认不知道"的能力**本质上被已知集代表性所限**，这正是本轮的自指盲点。

## 2. 形式化定义（完整版）

**定义 233（HYDRA 闭环）** HYDRA 是 VISTA 的"开放集 + 物理正交证据"升级：在 VISTA 的语义流/实时流骨架上挂载 EEG（事件瞬态接地）、CCT（共因分离）、FIR-O（开放集归因）、OHG（大模型假设生成）、OFA（开放集准入）、AFA-O（零接触事件探针）、CSC-O（开放集认证前缀），并原位升级 RSC-V→RSC-O、WCV-V→WCV-O、AIC-V→AIC-O、J_vista→J_hydra。不变式：**事件世界模型、共因检验、新颖性判定、VLA 假设生成、准入与证书只在语义流；实时流只做事件 ROI 触发、阶段化残差采集、安全前缀执行与早停，零学习写操作；VLA 仅生成假设，不得选择假设、输出动作或授权执行。**

**定义 234（事件流与事件任务观测量）** 事件相机像素 `(x,y)` 在对数亮度变化超阈值时异步触发：`|L(x,y,t)−L(x,y,t_last)|≥C`，输出 `(x_k,y_k,t_k,s_k)`，`s_k=sign(ΔL)`。事件观测量 `y_evt(t)=(M_t, u_n, u_t, τ_c, β_t, u̇)`：`M_t` 为独立运动掩码，`(u_n,u_t)` 为事件法向/切向流，`τ_c` 为预测接触 ROI 的首个事件爆发时刻，`β_t` 为 Hawkes 分支比，`u̇` 为事件形变率。**与定义 218 的帧式 `y_t` 并列：两者物理失明域不同，这是共因分离的前提。**

**定义 235（事件点过程残差与保形校准）** 事件世界模型 `g_evt` 给出条件强度 `λ(x,t|y_t,A_t)`：自由空间用非齐次泊松（预测由动作块诱导的事件率），接触/滑移用 Hawkes 自激发 `λ(t)=μ(t)+∫h(t−s)dN(s)`。对数似然 `ℓ(E)=Σ_k log λ(e_k) − ∫_0^T λ(t)dt`。时间重整化残差 `r_k=1−exp(−(Λ(t_k)−Λ(t_{k−1})))` 在模型正确时应为 U(0,1)；取 `s_evt=sup_t|F̂(t)−t|`（KS 距离）为非一致性分数，split-conformal 得 `q_evt(α)`，`e_evt>q_evt(α)` 判"事件与预测不符"。**初始滑移**判定：切向事件率爆发且 Hawkes 分支比 `β=∫h(τ)dτ→1⁻`（自激发趋于临界 = 微振动/滑移前兆）。事件通道提供的是**点过程证据**，不是强度真值。

**定义 236（事件失明域与可观测窗）** 事件失明域 `Blind={(x,t):|∂L/∂t|<C/Δt}`：准静态、均匀纹理、饱和前。事件可观测窗 `W_evt={t: 预测时间对比度>C/Δt}`（由动作块与当前场景预测）。只有 `t∈W_evt` 的事件残差进入签名；`t∉W_evt` 标 `event_unobservable`，**不得据此否决接触或滑移**。推论：事件相机看不到"稳态载荷"（H_model 后期），它的信息集中在**瞬态**（接触起始、初始滑移、形变起始）——因此它是瞬态显微镜，必须与力/几何的稳态信息互补。

**定义 237（故障假设集的开放集结构）** `ℋ_K={H0,H_geo,H_force,H_model,H_vis,H_policy}` 为闭集已知假设（定义 221）。`ℋ_?` 为 OHG 生成的候选，每个 `h` 带签名模板 `T_h`。`ℋ_A⊆ℋ_?` 为本回合经 OFA 准入的新故障。`hypothesis_set_version=H(ℋ_K∪ℋ_A)` 随准入单调增长。**未知故障的默认归宿是 `ℋ_?` 或开放集弃权，而非 `argmax_{ℋ_K}`**——这是与第 65 轮最本质的差别。

**定义 238（开放集新颖性检验）** 混合密度 `p_K(ρ)=Σ_{h∈ℋ_K∪ℋ_A}π_h p_h(ρ)`，新颖性分数 `n(ρ)=−log p_K(ρ)`。仅用**已知故障**标定残差计算 `n_i`，保形阈值 `q_nov(α)` 为其 `⌈(N+1)(1−α)⌉/N` 分位；`n(ρ)>q_nov(α)` 判"没有已知假设能解释"，p 值 `p_nov=(1+Σ_i 1[n_i≥n(ρ)])/(N+1)`。**该检验把"已知世界代表性"当作隐含前提：若新故障在签名空间里贴近某个已知故障，则它检测不到——这是本轮的自指盲点。**

**定义 239（跨模态共因分离检验 CCT）** 设 `a_frame,a_geo,a_evt,a_force` 为块内各通道异常分数（标准化残差）。定义跨模态耦合
`κ_cross = partialcorr(a_frame, a_evt | a_force, motion)`。
物理命题：(i) **静态外观伪故障**（H_common：透明/镜面/静止对抗 patch/强光饱和）只污染帧式外观；事件在静止时 `a_evt≈0`，且给定运动后帧式与事件无残余相关 → `κ_cross≈0`；(ii) **真实物理故障**（H_geo：真实几何错导致刮蹭/形变；H_model：真实接触异常）同时驱动帧式与事件 → `κ_cross>0`。判据：
- `κ_cross>κ₀` 且力残差高 → 归因物理（H_geo/H_model），允许膨胀几何/模型球；
- `|κ_cross|≤κ₀` 且帧式异常、事件在 `W_evt` 内正常 → 归因外观伪故障（H_vis/H_common），**不膨胀几何球**，降 `w_vis`；
- 其余 → `attribution_conflict=True`，开放集弃权。
这把 VISTA 的"视觉与几何独立失效"从**不可证的统计假设**换成**可证伪的物理符号检验**。

**定义 240（大模型假设生成器 OHG）** VLA `G_ψ` 输入结构化摘要 `S_t=(ρ, y_frame, y_evt, 力迹, 语言任务, 当前 ℋ)`，输出 `(z, T_h)`：`z` 为自然语言故障描述；`T_h=(传感器子集, 阶段局部性, 期望方向/符号, κ_expected, 期望事件签名)`。附 `h_prov=H(权重, 提示, S_t)` 与过期时间 `T_stale`（环境/任务变化或超时即作废）。**`G_ψ` 是生成沙箱**：不输出动作、不输出安全判决、不进实时环；其输出只是**待检验的假设**。

**定义 241（大模型语义易损先验与安全预算）** VLA 由语言+图像输出易损先验 `p_fragile∈(0,1)` 与语义安全力 `f̂_safe_sem`。融合**只收紧不放宽**：
`f_safe=min(f_safe_phys, f̂_safe_sem)`，`f_min_probe=max(f_min_probe_phys, f_min_probe_sem if p_fragile>τ_fragile)`。
于是 VLA 幻觉在力预算上只能更保守（失效安全方向），但**仍不得仅凭语义放行**——必须事件/力探针物理确认（OFA 的 A3）。

**定义 242（开放集假设准入 OFA）** 给定提案 `h`（模板 `T_h`）与新鲜探针签名 `ρ_p`（来自 AFA-O，`W_evt` 或力通道被激励），
`Admit(h) ⇔ A1 ∧ A2 ∧ A3 ∧ A4`：
- **A1 模板相容**：`log p(ρ_p|T_h)≥τ_comp`（探针结果与语言/模板描述一致）；
- **A2 已知集仍不解释**：`∀h'∈ℋ_K∪ℋ_A`，`p_nov^{h'}(ρ_p)<α_nov`（新故障不能退化为已知故障的极端参数）；
- **A3 物理安全且通道被激励**：`f≤f_safe`、`strain≤ε_strain`，且确实激励了 `T_h` 所指通道（例如假设"事件可见的滑移"则 `W_evt` 必须活跃并有切向事件爆发）——**纯语言/纯帧式的"证据"不满足 A3**；
- **A4 耦合符号匹配**：`|κ_cross−κ_expected|≤ε_κ`。
误准入率 `P[Admit|h 非真]≤β_adm`，由注入新故障标定集校准 `τ_comp,α_nov`。四缺一即回退开放集弃权。**A3+A4 是"反幻觉闸门"：没有真实物理通道响应与正确耦合符号，语言再自洽也不能准入。**

**定义 243（开放集归因后继处置）** 三个出口：
1. **闭集定向**（同 VISTA 定义 221）：`max_H P(H|ρ)≥1−δ_fi` 且新颖性未触发；
2. **准入新故障 `H_new`**：`H_new=Admit` 的提案，只膨胀 `r_open`（按模板最坏界），处置与该语言描述绑定的安全策略（如"疑似线缆勾挂"→ 反向微撤退 + 视觉复核）；
3. **开放集弃权**：`r=√(r_geo²+r_force²+r_model²+r_open_max²)` 联合膨胀、`k*=0`、`safe_idle`/`compliant_retreat`，写 `novelty_pvalue`、`hypothesis_set_version`。
**不变式：绝不再把未知故障强行 argmax 到最近已知假设。**

**定义 244（开放集判别探针 AFA-O）** 探针集 `A={event_parallax, event_null_test, visual_probe, light_touch, press, rub}`。选择
`a*=argmax_{a∈A} [ I(1[新故障]; ρ_probe | ρ_past) + λ·I(ℋ;ρ_probe) ]`，
s.t. `f_n≤f_safe`、`strain≤ε_strain`、`W_evt` 被激励。两种**零接触**探针优先：
- **event_parallax**：相机相对平移诱导运动视差，用事件恢复几何（对高动态/反光/无纹理但有边缘的物体尤佳）——不接触即可检验几何幻觉；
- **event_null_test**：自由空间运动，若力读数偏移而事件在 `W_evt` 内安静 → 判 H_force（真接触必产生运动/形变事件，力传感器在说谎）。
易损物体（`p_fragile>τ_fragile`）禁用接触探针。探针的首要目的从"估参数"（第 64 轮）→"分辨已知故障"（第 65 轮）→"**分辨是否为新故障**"（本轮）。

**定义 245（开放集认证前缀 CSC-O）** 弃权态：`k*=0`（除单独认证的柔顺撤退微前缀 `k_retreat`）。准入态：支持集含 `H_new` 的模板最坏界，沿用 `ρ_safe` 验证并取 `k*≤m`。风险预算扩为
`P[块内越界] ≤ α_chunk + β_adm + α_evt + α_vis + δ_fi`。
执行器只执行 `k*` 步即强制重规划与再归因；弃权时实时流直接进入安全待机。

**定义 246（RSC-O / WCV-O）** 维护 `r_geo,r_force,r_model,r_open` 与 `w_vis,w_evt`。定向膨胀规则：H_geo→`r_geo↑`；H_force→`r_force↑` 且零力窗重标定、不动几何；H_model→`r_model↑` 且柔顺；H_vis 且 `κ_cross≈0`→`w_vis↓` 但**不动 `r_geo`**；准入 `H_new`→`r_open↑`；事件注入被识别→`w_evt↓`。融合半径 `r=√(r_geo²+r_force²+r_model²+r_open²)`；弃权时 `r_open=r_open_max`。WCV 搜索域增 `𝒱_evt`（仅用可观测窗内事件证据），CVaR `n_worst=8`，弃权时按联合最坏采样。

**定义 247（开放集对抗认证 AIC-O）** `ℰ_O=ℰ_V×ℰ_evt×ℰ_vla`。`ℰ_evt`：**闪烁 LED 事件注入**（伪造滑移爆发，`s_evt` 与力/几何矛盾即可识别）、低光事件噪声、事件去同步/丢包；`ℰ_vla`：**场景文字提示注入**（把攻击指令藏进环境文字）、幻觉提案（语言自洽但物理错误）、模型版本漂移、延迟尖峰/过期。`ρ_dir` 在 `ℰ_O` 上重算（`n_cert 128→160`，其中 32 给事件/VLA）；`ρ_force` 取最坏偏置与最坏事件失明下的最坏。**要求：事件注入下越界率 ≤α_chunk；幻觉提案必须因 A3（无物理通道响应）或 A4（耦合符号不符）而不可准入。**

**定义 248（HYDRA 证书 J_hydra 与闭环算子）**
`J_hydra=(J_vista, hypothesis_set_version, novelty_pvalue, admitted_hypothesis_hash, event_grounding_hash, event_obs_window, vla_provenance_hash, vla_staleness, adm_test_ver, aic_o_ver)`。
`Valid(J_hydra) ⇔ Valid(J_vista)`
`∧ (闭集归因 ∨ (新颖性触发 ∧ (H_new 已准入 ∨ (开放集弃权 ∧ k*=0))) )`
`∧ VLA 提案仅用于生成（未直接选球/授权动作）`
`∧ (event_unobservable ⇒ 未以事件否决接触) ∧ (event_obs_window 显式记录)`
`∧ adm_test_ver 当前 ∧ vla_staleness≤T_stale ∧ aic_o_ver 当前`。
审计链新增：为什么长出新头（novelty_pvalue + z）、为什么承认它（A1–A4 证据 + h_prov）、事件是否可观测、VLA 提案是否过期。

class EventTransientGrounding:
    """事件点过程接地：接触起始 τ_c、初始滑移 β、形变率 u̇；只在可观测窗内出证据。"""
    def __init__(self, g_evt, contrast=C0, ks_alpha=0.05):
        self.g_evt, self.C, self.alpha = g_evt, contrast, ks_alpha

    def observe(self, events, roi, y_frame, A, motion_pred):

        ev = events.in_roi(roi)
        onset = first_burst_time(ev, delta_n=N0)               # τ_c（微秒级）
        flow = event_normal_flow(ev)                           # (u_n, u_t)
        beta = hawkes_branching_ratio(flow.tangential)          # →1⁻ 判初始滑移
        lam = self.g_evt.intensity(y_frame, A)                 # 非齐次泊松/Hawkes
        s_evt = time_rescaling_ks(ev, lam)                     # 非一致性分数
        observed = bool(w_evt.any())
        return {'tau_c': onset, 'beta': beta, 'flow': flow, 'u_dot': flow.normal_rate,
                'e_evt': s_evt, 'observed': observed, 'W_evt': w_evt,
                'event_unobservable': not observed}

### IP-225 CCT：共因物理分离

```python
def common_cause_test(a_frame, a_geo, a_evt, a_force, motion, kappa0=0.3):
    """κ_cross>0 → 真实物理故障；κ_cross≈0 且帧式异常、事件正常 → 静态外观伪故障。"""
    kappa = partial_corr(a_frame, a_evt, cond=[a_force, motion])
    if kappa > kappa0 and a_force > CHI2_6:
        return 'physical', kappa            # H_geo / H_model 方向
    if abs(kappa) <= kappa0 and a_frame > CHI2_6 and a_evt <= Q_EVT:
        return 'appearance', kappa          # H_vis / H_common：不得膨胀几何
    return 'conflict', kappa                # 开放集弃权
```

class OpenSetFaultIsolation(FaultIsolation):

class OpenSetHypothesisGenerator:

class OpenSetFaultAdmission:
    def __init__(self, tau_comp, alpha_nov, eps_kappa, beta_adm):
        self.tau_comp, self.alpha_nov = tau_comp, alpha_nov
        self.eps_kappa, self.beta_adm = eps_kappa, beta_adm

    def admit(self, proposal, rho_p, post, kappa_cross, probe_meta):
        A1 = template_loglik(rho_p, proposal['T']) >= self.tau_comp
        A2 = all(known_conformal_pvalue(h, rho_p) < self.alpha_nov for h in KNOWN)
        A3 = (probe_meta['forced_channel_active'] and probe_meta['safe'])   # 通道被真实激励

def choose_probe_open(post, proposal, f_safe, fragile, W_evt):
    if fragile:
        cands = ('event_parallax', 'event_null_test', 'visual_probe')   # 零接触优先
    else:
        cands = ('event_parallax', 'event_null_test', 'visual_probe',
                 'light_touch', 'press', 'rub')
    best, best_ig = None, -np.inf
    for a in cands:
        traj = predict_probe_traj(a)
        if a != 'event_parallax' and np.max(traj.f) > f_safe:
            continue
        if np.max(traj.strain) > EPS_STRAIN or not induces_events(traj, W_evt):
            continue
        ig = expected_mutual_info_open(post, proposal, a)   # I(新故障; ρ_new)
        if ig > best_ig:
            best, best_ig = a, ig
    return best, best_ig

### IP-230 CSC-O：开放集认证前缀

```python
def certified_prefix_open(A, post, state, m, alpha, beta_adm):
    if state == 'open_set_abstain':
        return 0, 'safe_idle'                        # 弃权：不执行
    if state == 'admitted':
        support = {**top_support(post, 2), 'H_new': template_worst(post)}
    else:
        support = top_support(post, 2)               # 闭集定向
    budget = alpha + beta_adm                        # 风险预算含误准入
    k_best = 0
    for k in range(1, min(len(A), m) + 1):
        if any(safety_margin(A[s], h) < 0 for h in support for s in range(k)):
            break
        if violation_prob(A[:k], support) <= budget:
            k_best = k
        else:
            break
    return k_best, 'execute'
```

### IP-233 HYDRA 闭环算子（整合）

```python
def HYDRA_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow, events, A = obs
    # ———— 语义流（10–100Hz）————
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_frame = M.f_vis(img, depth, flow)
    y_evt = M.eeg.observe(events, M.contact_roi, y_frame, A, motion_pred=None)

    # 1) 闭集先试 + 事件签名
    phases = M.stage.split(M.residual_log, y_frame, y_evt)
    post, h_star, ambiguous, novelty, p_nov = M.fir_o.triage(phases, y_evt)

    # 2) 共因分离：静态伪故障不得膨胀几何
    cause, kappa = common_cause_test(
        a_frame_of(phases), a_geo_of(phases), y_evt['e_evt'],
        a_force_of(phases), motion_of(y_evt))
    if cause == 'appearance':
        M.w_vis *= KAPPA_VIS; h_star = 'H_vis' if not ambiguous else h_star

    # 3) 开放集：生成 → 零接触探针 → 准入
    state, prop = 'closed_set', None
    if novelty:
        prop = M.ohg.propose(summary(phases, y_frame, y_evt, W_meas, M.task), M.vla, M.now)
        a, ig = choose_probe_open(post, prop, M.f_safe, M.p_fragile > TAU_FRAG, y_evt['W_evt'])
        probe_meta = M.execute_probe(a)              # 优先 event_parallax / event_null_test
        prop = M.ohg.invalidate(prop, M.now, T_STALE)
        if (not prop['stale']) and M.ofa.admit(prop, probe_meta['rho'], post, kappa, probe_meta):
            M.balls['r_open'] = template_bound(prop['T']); state = 'admitted'
            M.bind_policy(prop['z'])
        else:
            M.balls['r_open'] = R_OPEN_MAX; state = 'open_set_abstain'

    # 4) 定向或弃权处置
    if state == 'closed_set' and not ambiguous:
        M.balls, M.w_vis, M.H = M.fir.directed_demote(h_star, M.balls, M.w_vis, M.H)
    elif state == 'open_set_abstain':
        M.balls = joint_inflate(M.balls, r_open_max=R_OPEN_MAX)

    # 5) 规划（块级）+ 认证前缀
    goal = M.dms.parse_goal((M.usr.U_ep, M.usr.U_al))
    tau = M.csp_v.plan_chunks(goal, x_prime, M.phi_hat, M.balls, post)
    k_star, mode = certified_prefix_open(tau.A, post, state, M.m, M.alpha_chunk, M.beta_adm)

    # 6) 实时执行或安全待机
    K_safe, EV_exec, cert_exec = realtime_step_hydra(
        M, delta_f_req, tau, k_star, mode, x_prime, y_evt)

    # 7) 在线更新（纯语义流）
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile, y_frame, y_evt, post),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc_o.update(EV_exec, W_meas, M.phi_hat, post, M.balls)
    rho_dir = M.aic_o.certify(tau, x_prime, M.phi_hat, M.balls, post, prop if novelty else None)
    return M, K_safe, EV_exec, build_j_hydra(
        cert_exec, J_vista=M.j_vista, hypothesis_set_version=M.hsv,
        novelty_pvalue=p_nov, admitted_hypothesis_hash=hash(prop) if state == 'admitted' else None,
        event_grounding_hash=hash(y_evt), event_obs_window=y_evt['W_evt'].signature(),
        vla_provenance_hash=prop.get('prov') if novelty else None,
        vla_staleness=(M.now - prop['t0']) if novelty else 0,
        adm_test_ver=ADM_VERSION, aic_o_ver=AIC_O_VERSION)
```

## 4. 推导

**引理 9（事件瞬态可分离性）** 设可观测窗 `W_evt` 内事件残差 `ρ_evt` 由真实物理状态驱动，且与帧式/力残差在给定真实故障下条件独立（不同物理通道）。则 `I(ℋ;ρ_evt|ρ_frame,ρ_force)≥I(ℋ;ρ_evt)−I(ρ_evt;ρ_frame,ρ_force)`。在 `W_evt` 内后者小（物理正交），故事件通道带来正的条件信息增益。线性化 `E[ρ|θ]=Sθ` 时，事件列 `S_evt` 与力/几何列近正交，`J_fi=SᵀΣ⁻¹S` 的分块行列式满足 `det(J_fi^{aug})=det(J_fi^{old})·(S_evt^⊥ᵀΣ_evt⁻¹S_evt^⊥)>0`，故 `κ_fi` 严格增大——事件通道是**新增可辨识维度**，不是重复采样。∎

**引理 10（共因分离）** 在 H_common（静态外观伪故障）下，事件率 `λ(x,t)` 只依赖真实运动，与帧式外观扰动无共同驱动，故给定运动后 `a_frame⊥a_evt`，`κ_cross→0`。在真实物理故障下，帧式与事件同受物理状态驱动，`κ_cross>0`。设 `κ_cross` 估计方差 `σ_κ²`，符号判据 `κ_cross>κ₀` 的两类误判率由 `2Φ(−κ₀/σ_κ)` 界定。因此第 65 轮"视觉与几何独立失效"的**不可证假设**被替换为**可证伪的物理符号检验**。∎

**引理 11（准入误报界）** 设已知故障标定可交换、新颖性检验保形有效，则对非真提案 `h`，`p_nov` 在真假设下均匀分布，A2 的通过概率 `≤α_nov`；A3 要求物理通道被真实激励，A4 要求耦合符号匹配，二者独立地进一步压缩误准入。故 `P[Admit|h 非真]≤β_adm`，`β_adm` 由注入新故障标定联合校准。∎

**定理 9（HYDRA 开放集安全）** 在 A94–A99 下：
1. **不再强行归类**：`novelty` 触发时进入生成-准入或弃权，`Valid(J_hydra)` 强制三出口之一，杜绝 `argmax_{ℋ_K}` 硬塞。
2. **共因可分离**：CCT 在 `κ_cross≈0` 时禁止膨胀几何（引理 10），直接对冲第 65 轮"在正确几何上误降级"。
3. **幻觉不可授权**：OFA 的 A3/A4 要求真实物理通道响应与耦合符号，纯语言/帧式幻觉不可准入（引理 11）。
4. **安全单调**：准入前系统处于弃权保守态；准入后定向处置的风险 `≤R_abstain+β_adm·Δ_risk`。开放集生成相对弃权是**安全单调改进**，代价是 `β_adm`。
5. **物理伤害受限**：易损物体禁用接触探针，零接触 `event_parallax/null_test` 优先；`f_safe` 只收紧不放宽（定义 241）；`k*=0` 弃权。∎

**定理 10（两时钟）** 事件延迟 μs、VLA 延迟 `L_vla≫D`（实时 deadline）。因 VLA 仅扩充支持集、准入必须新鲜物理证据且 `vla_staleness>T_stale` 即作废，实时路径不调用任何大模型，延迟保持 `≤2.6ms`；开放集推理、共因检验、VLA 生成全部在语义流。故"长预测、短执行"（第 65 轮定理 8）与"大模型只提议"可同时成立。∎

**命题（开放集的分辨率极限）** 设新故障签名分布 `P_new` 与已知混合 `P_K` 的总变差 `TV(P_new,P_K)≤ε`，则任何检验在水平 `α` 下区分二者的功效 `≤α+ε`（由 Le Cam 两点下界）。故"承认不知道"的能力**被已知集代表性所限**：签名越接近已知故障的新故障越检测不到。这解释了为何 OHG 的生成必须与 OFA 的新鲜物理证据绑定，而不能仅靠残差 novelty。∎

**命题（事件-帧式互补的信息守恒）** 事件通道在稳态（`W_evt` 空）信息为零，帧式通道在强光饱和/静态对抗下信息退化。二者失明域互补：`Blind_frame∩Blind_evt` 显著小于各自失明域。故双通道联合在最坏单通道失效场景仍保留可用证据——这是"第三物理通道"（第 65 轮未来工作）的最低成本实现。∎

## 7. 已知风险

**一句话**：HYDRA 的"开放集"依赖一个自指假设——未知故障必须在残差上表现为"与所有已知假设显著不符"才会被标为新，而大模型生成假设的分布本身未被认证、事件相机在准静态段又会失明，于是系统可能把大模型的**幻觉假设**当成新故障，并用探针为它"补"出一条错误通路——**开放集从"安全弃权"退化为"为幻觉颁发许可证"，且授权流程因"经过准入检验"而更难被人质疑。**

**次级风险与缓解**：
1. **新颖性分辨率极限**：新故障贴近已知混合分布时检测不到（命题）；缓解：用 OHG 的**语义**补充残差 novelty、离线持续扩充故障库、把 `hypothesis_set_version` 与弃权率纳入运行监控。
2. **VLA 幻觉/提示注入**：语言自洽但物理错误；缓解：A3 强制真实物理通道激励、A4 强制耦合符号匹配、`h_prov` 溯源与 `T_stale` 过期、生成沙箱不接触实时环；场景文字注入由 AIC-O 显式建模。
3. **事件相机准静态失明**：稳态载荷/慢接触无事件，H_model 后期不可见；缓解：`W_evt` 门控 + `event_unobservable` 不得否决、稳态仍由力/几何主导、主动 `event_parallax` 诱导运动。
4. **事件注入伪造滑移**：闪烁 LED/对抗光源制造假事件；缓解：事件与力/几何的一致性检验（假滑移无对应力/形变）、多相机事件几何校验、`w_evt` 可下调。
5. **共因符号检验的统计功效**：`κ_cross` 在小样本/低信噪下不稳；缓解：块级聚合、保形阈值、`attribution_conflict` 时弃权。
6. **准入条件 A1 模板过于宽松/严格**：模板由语言生成，可能过拟合或过泛；缓解：模板作为**软先验**、以注入数据校准 `τ_comp`、A2 防止退化为已知故障。
7. **两时钟的过期窗口**：`T_stale` 过长会用过期假设、过短则永远来不及准入；缓解：按任务变化率自适应、过期即回退弃权、不冒险利用陈旧提案。
8. **实时事件带宽**：高动态场景事件洪泛；缓解：ROI 触发、事件降采样/去噪、与 LSF 共享编码、世界模型全留语义流。
