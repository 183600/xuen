# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动交互不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「运动控制」×「实时控制」）

> R69 让闭环第一次学会「问」：把 epistemic 歧义交给看/问/触，用 VoI 判断值不值得问，用「k 个正交证据一致」防止单源定案。但它有一个从未被审视的默认前提——**思考不花时间，或者只花一点「平均延迟」**。K 个模态的采样、轨迹聚类、VoI 枚举、交互执行，在 R69 里被当成近似瞬时的事件；复杂度表里的「<2.6ms / <3.4ms」是**平均/软预算**，不是**最坏执行时间（WCET）**；`cost(g)` 只减物理与社交成本，从不减「我思考的这段时间里世界已经变了」。
>
> 本轮两个灵感正好击中这两个盲点：
> - **运动控制**告诉我们：**执行不是选择一个离散动作块，而是让一条动力学可行的轨迹在时间上真正发生**。你思考时，被控对象不会暂停——一个在歧义中多停留 3ms 的决定，可能换来熵的一点下降，却已经让系统沿不稳定方向滑出了更多距离；而且信息动作本身必须是一条耗能、改变状态、受力矩/摩擦/接触约束的运动。
> - **实时控制**告诉我们：**deadline 不是性能指标，而是安全约束**。真正要命的不是「平均算得慢」，而是「在最需要思考的歧义峰值，恰好最没有时间思考」——K 越大、交互越多，恰恰发生在安全裕度最小、抖动最敏感的时候；一次超时本身就可能是一次事故。
>
> 核心命题：**把 R69 的「不确定性预算」扩成「时间预算」——任何 epistemic 消解（多采样、聚类、VoI、交互、重规划）都必须用同一份 deadline slack 付费，并且执行层永远保留一条不依赖学习、经 CBF/无源性认证的硬实时兜底；信息动作从「快照式看/问」升级为「沿动力学可行轨迹的运动式探询」；而动力学可行性本身就是最便宜、无需校准的模态先验。** 命名 **TEMPO-RAS**（Time-aware Epistemic Motion Policy & cOntrol for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在还来得及之前问得完吗——而我思考的时候，世界已经走到哪里了**」。不确定性不仅可以是提问，也可以是一次**必须在下一个控制周期前交割的限时决策**。

## 0. 直觉与动机

**灵感 1（运动控制 → 思考有价格，而且按 τ² 计息）**
直觉：R69 的 `VoI(g) − cost(g)` 把交互当成「先暂停世界，问完再继续」。但运动控制系统里没有暂停键。以倒立摆/足式平衡为例：你在「该往左迈还是往右迈」之间多采样、多聚类、多算一次 VoI，这段时间里被控对象仍按重力继续演化；兜底动作（保持上一指令）相对「立刻做对」的累计代价不是常数，而随失稳程度增长——越接近失稳，代价越像 `½ατ²`。因此存在一个**有限的最优思考时长**：再多算一步的信息收益已经饱和（模态熵最多降到 0），而迟疑的代价仍在二次增长。R69 的 VoI 因为把 `A(τ)` 当成 0，会系统性地**过度思考**——歧义越大越想多算，而歧义峰值恰恰最不该多想。这不是参数调优问题，而是目标函数漏了一项。

**灵感 2（实时控制 → deadline 是硬约束，最坏情况不是平均值）**
直觉：R69 用 `mode_head` 门控把常规路径压到 <2.6ms，压力大时升 K=4 到 <3.4ms。这是**期望延迟**的叙事。实时控制的第一原则恰恰相反：**可调度性由 WCET 和抖动上界决定，而不是由平均值决定**；而流匹配 ODE 的迭代次数、聚类规模、候选交互数都依赖输入内容，天然带**数据相关的最坏执行时间**。更糟的是，歧义越大 → 采样/聚类/校验越多 → WCET 越大，而歧义越大同时意味着安全裕度越小、系统越经不起超时。这构成一个**相关失效**（correlated failure）：系统最脆弱时最忙。R70 必须把这条相关性显式打断：分层、可抢占、随时随地可退，且硬实时内环永不等待认知层。

**灵感 3（动力学可行性 = 免费的模态先验）**
直觉：R69 最大的恐惧是流模型幻觉出不存在的模态，把系统骗去追问一个幻影。运动控制提供了一个**不依赖学习、不依赖校准**的物理剪枝器：一个模态若无法在力矩/速度/摩擦锥/接触互补约束内被真正执行，它就不是「一个假设」，而是「一个幻觉」。用一个小 QP 做鲁棒可行性检查，比训练模态校准器便宜几个数量级，而且它约束的是物理而不是分布。于是「模态是否可信」这个 R69 的核心风险，被拆成两问：**它物理上做得到吗（DFT，硬约束）** 与 **它在数据上有多可信（ECE，统计约束）**。前者可以做到近乎零误杀，后者才需要校准。物理先验先剪一刀，统计风险面就小得多。

**灵感 4（信息动作是运动，不是快照）**
直觉：R69 的 g ∈ {gaze, probe, ask} 是快照式动作：看一帧、触一下、问一句。运动控制里，这些都必须展开成**一条轨迹**：注视要伴随头部/躯干的可行转动，探针要有一段受力的接触轨迹，甚至连「等一等」也是保持姿态的一段控制。它们消耗能量、产生动量、扰动被控对象，并且**改变你下一步要决策的那个状态**。所以 VoI 不能只在 o_t 上算一次，而要沿 `g_{t:t+h}` 积分：`H(M|o_t) − E[H(M|o_{t+h})]`，并扣掉 `c_dyn`（能量/动量/扰动）与这段轨迹占用的时间预算。R69 的快照式提问只是 h→0、`c_dyn`→0 的退化情形。

**灵感 5（时间的可储蓄性 → 算力信用）**
直觉：实时控制里，任务不是每周期都必须满负荷；有闲周期就有**可储蓄的算力**。R69 每步独立决定 K=1 还是 4，等于每周期从零开始。R70 允许把闲时的 slack 存成**算力信用** `C_t`，在真正需要（歧义峰值但仍有物理余量）时一次性花掉；但信用必须有上限、有保质期，否则系统会「用一笔陈旧的算力去买一个过期的答案」。这对应一条纪律：**可以借时间，不能借事实**——算力可复用，但过期信念必须重验。

**灵感 6（时间本身是新的攻击面）**
直觉：R69 的威胁模型里有投毒、共谋、幻影模态，但没有「让系统算不完」。一个对抗性输入（极端观测、触发 ODE 步长爆炸、制造缓存抖动、让聚类退化到最坏规模）可以把「安全地慢」变成「超时的悬崖」。**拒绝服务攻击在实时控制里就是物理攻击**。所以 R70 必须把时间故障（overrun / jitter / staleness / desync / compute-DoS）纳入 AIC，并用一个不依赖学习的看门狗与预算审计来兜住它。

## 1. 形式化定义（增量：定义 310–324）

**假设**
- **A99（内环安全底）**：存在硬实时内环控制器与安全集 𝒮，其在零阶保持（ZOH）下对任意认证指令前向不变（CBF/无源性可证）。
- **A100（迟疑的代价）**：存在风险泛函 ℓ 使思考 τ 期间的**控制权威损失** `A(τ)` 非降、`A(0)=0`；在失稳平衡附近 `A(τ) ≥ ½ατ²`（α>0），在稳定且兜底安全时 `A(τ)≈0`。
- **A101（任意时刻流）**：流采样可在任意整步处截断，截断样本经可行集投影后仍是可执行动作；`E‖x_1−x_s‖ ≤ (1−s)·v̄`。
- **A102（WCET 可测有界）**：每个认知子任务的 WCET 与抖动上界可离线测量并被运行时监视；固定步长、无动态分配的实现使界可复现。
- **A103（保守可行性判定）**：鲁棒可行性 oracle `F_ε` 是**可靠**的：`F_ε(m)=false ⇒ m` 在扰动界内确实不可执行（允许有 ε 裕度，但不得误杀真正可执行的模态）。
- **A104（信念随时间的漂移）**：在无新观测时，模态信念的漂移（熵/KL 意义的低估量）随 age 至少线性增长，系数 `κ_age>0`。

**定义 310（TEMPO-RAS 总览）** TEMPO-RAS = (TAV, AFS, DFT, DAS, MRC, TCB, RAS-WM§)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **硬实时不可阻塞**：内环（含兜底）独立于 epistemic 层调度；任意超时/抢占/失败下，每个控制周期 `T_c` 都能给出一个经认证的可执行指令；
(iii) **时间预算守恒**：任何认知动作（多采样/聚类/VoI/交互/重规划）只能花 deadline slack，且必须先扣除兜底 WCET 与抖动上界；
(iv) **安全单调退化**：超时/失败/过期/被攻击时，沿退化阶梯只降级、不升级，且每级可审计；恢复需滞回，防止抖动。

**定义 311（多速率时间模型）** 内环周期 `T_c`（如 1kHz，`T_c=1ms`），硬期限 `D_c=T_c`；认知层周期 `T_e = N·T_c`（如 100Hz），期限 `D_e`；抖动上界 `J_p99`。第 t 周期可用**松弛**为
`σ_t = D_e − elapsed_t − WCET_fb − J_p99`（截断到 ≥0），
其中 `WCET_fb` 是兜底路径的保留预算。关键约定：`σ_t` 是**唯一**可被认知层花费的时间资源；内环的 `T_c` 永不向认知层出借。

**定义 312（控制权威损失）** 设思考 τ 期间执行兜底/保持指令 `a_hold`，闭合回路反事实为 `a_closed`：
`A(τ) = ∫_0^τ [ℓ(x_hold(t), a_hold(t)) − ℓ(x_closed(t), a_closed(t))] dt`。
性质：非降、`A(0)=0`；失稳附近二次增长；稳定且兜底安全时近似 0。**注意 `A` 与 `VoI` 单位不同，必须先折算到同一风险泛函再比较**（定义 313）。

**定义 313（时间感知信息价值 TAV）** 对候选信息动作 g（含其计算与执行的总延迟 `τ_g`）：
`TAV(g) = VoI(g) − c_phys(g) − c_soc(g) − A(τ_g) − κ_s·max(0, age − TTL)`，
可行性要求 `τ_g ≤ σ_t` 且 `g ∈ M_feas`（定义 315）。选择
`g* = argmax_{g} TAV(g)`，仅当 `max TAV > 0` 才交互；否则不交互、走 R69 兜底。
对**增量采样**定义最优停时：继续多算一步当且仅当 `∂VoI/∂τ > ∂A/∂τ`；等价于存在有限最优思考时长 `τ*`（引理 19）。R69 的 `argmax[VoI−c]` 是 `A≡0、σ_t=∞` 的退化。

**定义 314（任意时刻流采样器 AFS）** 给定计算预算 b（固定步数/flops），AFS 可在整步边界被抢占，返回粗动作 `x_{s(b)}` 与其提炼的草稿模态；分辨率 `ρ(b)=1−s(b)`，误差
`e(b) ≤ (1−s(b))·v̄ + dist(x_{s(b)}, C)`（C 为动力学可行集）。
要求：固定步长（**用确定性换平均精度**）、预分配缓冲、量化网络；`b1<b2 ⇒ e(b1)≥e(b2)`（期望意义），且任意前缀都可在投影后执行。

**定义 315（动力学可行性剪枝 DFT）** 对模态 m，鲁棒可行性 oracle
`F_ε(m) ⇔ ∃ τ(·)` 满足力矩/速度/关节限位、摩擦锥、接触互补与 CBF 约束（扰动界内）。
可行集 `M_feas = {m : F_ε(m)=true}`。若 `ŵ_m` 高而 `F_ε(m)=false` 且与所有可行模态 W₂ 距离 ≥ Δ_min，判为**物理幻影**（phantom），记录但禁用。
纪律：只在**鲁棒不可行**时剪枝（A103），宁可漏剪不可误杀。

**定义 316（时序一致性信念与算力信用 TCB）** 信念跨周期递推 `b_t = τ(b_{t−1}, o_t)`，假设带年龄 `age`。算力信用
`C_t = min(C_max, η·C_{t−1} + max(0, σ_{t−1} − used_{t−1}))`（η∈(0,1] 为折旧）。
`age > TTL` 的假设**不得**驱动不可逆动作，必须重验。陈旧不确定性按
`U_epi^age = U_epi^0 + κ_age·min(age, TTL)`
膨胀（A104）——**低估 age 就是低估风险**。

**定义 317（多速率契约与退化阶梯 MRC）** 内环契约：参考动作先过 CBF/无源性滤波，任何外环输出都只能作为**参考**而非直接力矩。退化阶梯
`L0` 完整 FLUID → `L1` 减 K → `L2` mode_head 单样本 → `L3` R69 保守 → `L4` R68 λ_floor → `L5` 内环安全停/保持。
每级有 `(WCET_ℓ, 安全性, 性能)`；不变量：每个周期存在某级 `ℓ` 使 `WCET_ℓ ≤ D_c`，且调度器**必须**为 `L5` 预留时间。

**定义 318（期限感知调度 DAS）** 认知任务集 `{(WCET_i, value_i)}`，value 为期望风险下降（由 TAV 折算）。每周期在
`Σ_{i∈S} WCET_i ≤ σ_t`、且兜底已预留的约束下，选择使 `Σ value_i` 最大的子集 S（0/1 背包；按 value/WCET 贪心）。
任务以整步/整聚类为抢占粒度。可调度性条件见引理 23。

**定义 319（运动式探询 MET）** 信息动作展开为动力学可行轨迹段 `g_{t:t+h} ∈ M_feas`，其
`VoI_met(g) = H(M|o_t) − E_{y~p(·|g)}[H(M|o_{t+h})]`，
净价值再扣 `c_dyn(g)`（能量、动量、扰动）与 `A(h)`，并须通过 C-RAS-WM§ 的**前缀与终端**双重认证。R69 的快照式 `g` 是 `h→0`、`c_dyn→0` 的退化。

**定义 320（时间看门狗与预算攻击检测）** 运行时统计检验：`WCET_t > WCET_p99 + k·MAD`、连续 deadline miss、`σ_t` 异常归零、ODE 步数分布偏移，任一触发即判**预算异常**，强制降级到 `L5` 并记录。看门狗本身不依赖学习，只用计时器与计数器。

**定义 321（时序故障模型）** `ℰ_time = ℰ_overrun × ℰ_jitter × ℰ_stale × ℰ_desync × ℰ_dos`（超时/抖动/陈旧/时戳失配/算力拒绝服务）。并入 AIC：
`ℰ_TEMPO = ℰ_FLUID × ℰ_time`。特别地，`ℰ_dos` 是一类**新的对抗面**：让系统算不完，而不是算错。

**定义 322（证书 J_TEMPO）** `J_TEMPO = (J_FLUID, WCET_p99, J_p99, miss_count, fallback_activations, dft_reject_rate, A_hat, staleness_max, C_t, tempo_ver)`。
Valid ⇔ `Valid(J_FLUID) ∧ miss_count=0 ∧ WCET_p99 ≤ D_e−J_p99−WCET_fb ∧ dft_reject_rate ≤ τ_dft ∧ staleness_max ≤ TTL`。
注意：`miss_count` 计的是**认知层** miss；内环不允许 miss（由定义 317 保证）。

**定义 323（最优思考停时）** 定义贝尔曼价值
`V(b) = max{ execute(x_{s(b)}), −Δτ + E[V(b+1)] }`，
在 `b` 上做最优停时；阈值 `b*` 由 `∂VoI/∂b = ∂A/∂τ·dτ/db` 给出。这是「算到什么时候该动手」的形式化，也是 `DAS` 与 `TAV` 的共同停止准则。

**定义 324（退化/恢复滞回）** 降级立即生效；升级须满足 `σ_t ≥ σ↑` 连续 `m` 个周期且 `age ≤ TTL`。定义停留时间 `dwell`，避免在 `L2/L3` 间高频抖动造成控制不连续。

```python
# IP-264 AFS：任意时刻、可抢占、固定步长的流采样（确定性优先）
class AnytimeFlowSampler:
    def __init__(self, velocity_net, trunk, max_steps, proj):
        self.v, self.trunk, self.max_steps, self.proj = velocity_net, trunk, max_steps, proj

    def sample(self, o_t, budget_steps, deadline):        # 预算 b 与硬期限
        z  = self.trunk(o_t)                              # 复用 R69 trunk
        xs = self._preallocated_noise()
        b  = 0
        while b < min(budget_steps, self.max_steps):
            if time_left(deadline) < self.wcet_step + WCET_FB:   # 预留兜底
                break
            xs = xs + (1.0 / self.max_steps) * self.v(xs, b / self.max_steps, z)
            b += 1
        return self.proj(xs), resolution(b)               # 任意前缀都可执行

# IP-265 TAV：时间感知 VoI（迟疑 A(τ) 与陈旧惩罚）
def time_aware_value(modes, w, o, deadline_slack, age):
    best = None
    for g in info_action_candidates(modes):
        tau = wcet_compute(g) + latency_exec(g)
        if tau > deadline_slack:                 continue          # 来不及
        if not dft.feasible(g):                  continue          # 物理不可行
        if not c_ras_wm_s.certify(g, o):         continue          # 安全认证
        val = (entropy(w) - expected_entropy(w, g, o)) \
              - cost(g) - authority_loss(tau) - kappa_s * max(0, age - TTL)
        if best is None or val > best.val: best = (g, val)
    return best if best and best.val > 0 else None                # 无利可图 → R69

# IP-266 DFT：动力学可行性剪枝（物理先验，零学习）
def feasibility_trim(modes, o):
    feasible, phantom = [], []
    for m in modes:
        if robust_qp_feasible(m, o, margin=EPS):  feasible.append(m)
        else:                                     phantom.append(m)   # 记录但不驱动 VoI
    return feasible, phantom

# IP-267 DAS：期限感知调度（保留兜底，按价值密度装包）
def deadline_schedule(tasks, slack):
    assert reserved_fallback_wcet <= slack            # 先扣兜底
    cap   = slack - WCET_FB
    tasks = sorted(tasks, key=lambda t: t.value / t.wcet, reverse=True)
    chosen, used = [], 0.0
    for t in tasks:                                   # 可抢占到整步粒度
        if used + t.wcet <= cap: chosen.append(t); used += t.wcet
    return chosen

# IP-268 MRC：退化阶梯 + 滞回（安全单调）
def degrade(level, status):
    if status.deadline_miss or status.watchdog or status.stale > TTL:
        return max(level, L5)                         # 立即降，永不升级
    if status.slack >= SIGMA_UP and status.age <= TTL:
        return level - 1 if level > L0 else L0        # 滞回恢复
    return level

# IP-269 TCB：算力信用 + 信念时效
def carry_over(C_prev, slack_prev, used_prev, age):
    C = min(C_MAX, ETA * C_prev + max(0.0, slack_prev - used_prev))
    if age > TTL:  C = 0.0                            # 过期信用清零，必须重验
    return C

# IP-270 MET：运动式探询（沿轨迹积分 VoI、计入动力学成本）
def motion_probe(modes, o_t, horizon):
    best = None
    for g in trajectory_candidates(modes, horizon):   # 看/触/移动式注视
        if not dft.feasible(g) or not c_ras_wm_s.certify(g, o_t): continue
        voi = entropy(modes) - expected_entropy_after(modes, g)
        val = voi - dyn_cost(g) - authority_loss(len(g)) - cost(g)
        if best is None or val > best.val: best = (g, val)
    return best if best and best.val > 0 else None

# IP-274 主闭环（继承 R69，插入时间预算与兜底）
def TEMPO_RAS_round(M, obs, level=L0):
    ts = M.clock.tick()
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)   # R68 标定
    slack = deadline_slack(ts, WCET_FB, J_p99)
    age   = M.tcb.age()
    # 0) 超时/陈旧/预算异常 → 直接走兜底，不学习、不加重
    if M.watchdog.tripped() or slack <= 0:
        return M.mrc.exec_level(max(level, L5), o, z)
    # 1) 预算内采样：K 由 slack 与 mode_head 共同决定（不是只看歧义）
    k_wcet = max_k_within_budget(slack, M.afs.step_wcet)
    K = min(k_wcet, 1 if M.fmp.mode_head(z) < TAU_MODE else MAX_K)
    b = budget_for(K, slack)
    xi, rho = M.afs.sample(o, b, ts.deadline)
    modes, w = M.aud.decompose(xi)                    # 复用 R69 AUD
    # 2) 物理先验剪枝（零学习，先剪幻影）
    modes_f, phantom = M.dft.trim(modes, o)
    # 3) 时间感知 VoI：交互前先问「来得及吗 / 值得吗」
    g = M.tav.choose(modes_f, w, o, slack, age) if modes_f else None
    if g is not None and not M.das.can_afford(g, slack):
        g = None                                      # 预算不够则不交互
    if g is not None:
        ans = M.met.execute(g)                        # 运动式探询 + 认证
        w   = M.cia.update_belief(w, ans)             # 继承 R69 证据纪律
    U_ale, U_epi = M.aud.split(modes_f, w, age)       # 含 stale 膨胀
    # 4) 风险缩放 + 安全底
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A   = M.ach.propose(...); k = M.c_ras_wm_s.certified_prefix(A, ...)
    if M.tav.authority_loss(ts.elapsed) > TAU_AUTH:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))   # 迟疑过大 → 保守
    # 5) 内环只把结果当参考；任何超时由 L5 兜底
    ref = M.pi_sigma.prefix_dispatch(modes_f, k, lam)
    cmd = M.mrc.inner_contract(ref, o, ts)            # CBF/无源性滤波，永不阻塞
    M.audit.submit_async(g, U_epi, rho, A, slack)     # 参与式审计 + 时间审计
    return M.mrc.exec(cmd, level)
```

## 3. 推导

**引理 19（思考的边际收益必然衰减，迟疑的代价不衰减 → 存在最优停时）** 在 A100 下，设熵下降 `ΔH(τ)=H_max(1−e^{−τ/τ0})`、权威损失 `A(τ)=½ατ²`。净收益 `N(τ)=ΔH(τ)−A(τ)` 的驻点满足 `(H_max/τ0)e^{−τ/τ0}=ατ`，左端单调降到 0，右端单调增，故**存在唯一有限最优 `τ*`**；`τ>τ*` 后继续计算严格有害。系：R69 的 `A≡0` 版本会让 `N(τ)` 单调增加到 `H_max`，即**永远想再算一步**——过度思考是目标函数缺失，不是调参失误；歧义越大、失稳越近，`τ*` 越小，正确行为是**少想、先稳住**。

**引理 20（任意时刻截断的误差界）** 在 A101 下，`e(s)=E‖x_1−x_s‖ ≤ ∫_s^1 E‖v_θ‖du ≤ (1−s)v̄`；可行集投影是非扩张的，故投影后 `e_proj ≤ e + dist(x_s,C)`。于是分辨率 `ρ(b)` 单调、误差界可先验计算，`AFS` 的每一次整步截断都对应一个**可认证的粗动作**，而不是「半成品」。

**引理 21（保守物理剪枝不损真模态）** 若 `F_ε` 可靠（A103），则任何被剪掉的模态在扰动界内确实不可执行；执行不可行模态的后果是硬约束违反（视为最大风险），故剪枝**不会增大**期望任务风险，同时移除了 R69 需要靠 ECE 才能识别的物理幻影。系：DFT 把「模态可信度」中的**物理分量**从统计校准里剥离，MCG 只需处理剩余的数据分量。

**引理 22（陈旧即低估）** 在 A104 下，无新观测时信念相对真值的熵增至少 `κ_age·age`，故未加膨胀地复用 age 大的信念，会系统性低估 `U_epi`。`U_epi^age` 的线性膨胀与 TTL 截断保证：要么在可信期内复用，要么付出重验成本——**可以借时间，不能借事实**。

**引理 23（可调度性充分条件）** 若 `Σ_{i∈mandatory} WCET_i + WCET_fb ≤ D_e − J_p99`，且可选任务以整步抢占，则 `DAS` 不会错过硬期限；按价值密度贪心选取的可选任务集，其价值不低于最优 0/1 背包的 `1/2`（分数背包的 `(1−1/e)` 界在子模价值下成立）。系：把「多采样」做成**可选任务**而非必需任务，是可调度性的关键。

**定理 18（TEMPO 严格包含 FLUID/R69）** 当 `σ_t→∞`、`A≡0`、所有模态 `F_ε` 可行、内环退化为恒等、无时序故障时，TEMPO 的 `TAV/MET/DFT/TCB` 逐项退化为 R69 的 `VoI/cost/—/—`，两阶段策略在任意状态上的动作分布相同。一般情况下，TEMPO 的可行动作集包含 R69 的最保守策略与 `L5` 兜底，故期望风险 ≤ R69；安全侧不做任何让步，性能侧通过 anytime、算力信用与运动式探询获得收益。

**定理 19（分层安全与无突变）** 在 A99、A102 下：(i) 内环对任意外环输出经 CBF/无源性滤波后仍在 𝒮 内，且 ZOH 下前向不变，故认知层超时**不改变**内环安全集；(ii) 退化阶梯只降不升、恢复带滞回与 dwell，切换次数有限且相邻控制指令差有界，故无 ZOH 突变引发的抖振；(iii) `λ` 在任意降级路径上单调不降，R69 的换装不变式（定理 15）保持。系：**deadline miss 在内环是性能事件，只有在兜底预算被侵占时才升级为安全事件**——这正是 `WCET_fb` 必须硬预留的原因。

## 6. 本轮最大风险

**一句话**：TEMPO-RAS 的全部安全性押在「WCET 有界、抖动可测、兜底永远可调度」这条**实时假设**上——一旦数据相关的 ODE、缓存抖动或对抗性输入把最坏执行时间击穿，最需要思考的歧义峰值恰是兜底预算被挤掉的时刻，系统会从「安全地慢」直接跌成「超时的悬崖」；**实时控制里最危险的谎言，不是『我算得慢』，而是『我知道最坏有多慢』**。

**次级风险与缓解**：
1. **权威损失模型错误**（`A(τ)` 低估、世界比模型更快）→ 保守上界 + 失稳检测优先于信息收益 + E303；
2. **物理剪枝误杀**（`F_ε` 不可靠，删掉真正可行的罕见模态）→ A103 鲁棒余量 + 只剪鲁棒不可行 + E304；
3. **算力信用与陈旧信念**（借了时间又借了事实）→ TTL 强制重验 + 信用折旧 + 引理 22 + E309；
4. **多速率耦合失稳**（认知层频繁切换参考引发抖振）→ 内环 CBF/无源滤波 + 退化滞回/dwell + 定理 19；
5. **时序拒绝服务**（对抗输入制造 overrun）→ 时间看门狗 + 预算审计 + ℰ_dos 对抗测试 + 定义 320/321。

**与 R69 的关系**：R69 的最大风险是「模态权重不可信 → 自信地追问幻影」；R70 用 DFT 把其中**物理不可行**的一类幻影免费剪掉，并用 TAV 抑制过度追问。但 R70 引入了新的单点故障——**时间模型**。这是本轮必须诚实承认的交换：**用一个可测量的物理约束（时间）替换一个难测量的统计假设（模态可信度），但测量时间本身也可能撒谎**。

**定义 310（总览与四不变式）** TEMPO-RAS 由 TAV/AFS/DFT/DAS/MRC/TCB/RAS-WM§ 组成；零学习写操作继承；内环硬实时不可阻塞；时间预算守恒（认知动作只花 slack，且先扣兜底 WCET 与抖动）；超时/失败/过期/被攻击时沿退化阶梯安全单调下降。

**定义 311–312（时间模型与权威损失）** `σ_t` 为唯一可花费预算；`A(τ)=∫_0^τ[ℓ(x_hold,a_hold)−ℓ(x_closed,a_closed)]dt`，非降、`A(0)=0`、失稳附近二次增长、稳定时≈0。**思考有价格，且按失稳程度计息。**

**定义 313（TAV）** `TAV(g)=VoI(g)−c_phys−c_soc−A(τ_g)−κ_s·(age−TTL)_+`，约束 `τ_g≤σ_t` 且 `g∈M_feas`；仅当 `max TAV>0` 才交互。增量采样停时：继续 iff `∂VoI/∂τ>∂A/∂τ`。R69 是 `A≡0、σ_t=∞` 的退化。

**定义 314（AFS）** 整步可抢占；`e(b)≤(1−s(b))v̄+dist(x_s,C)`；固定步长 + 预分配 + 量化，任何前缀投影后可执行。

**定义 315（DFT）** `F_ε(m)` 鲁棒满足力矩/速度/摩擦锥/接触互补/CBF；`M_feas={m:F_ε(m)}`；只剪**鲁棒不可行**，高权重不可行者为物理幻影，记录但禁用。

**定义 316（TCB）** 信念递推 + `C_t=min(C_max, ηC_{t−1}+max(0,σ_{t−1}−used_{t−1}))`；`age>TTL` 不得驱动不可逆动作；`U_epi` 随 age 膨胀。**借时间可以，借事实不行。**

**定义 317–318（MRC 与 DAS）** 内环只接受经 CBF/无源滤波的参考；L0–L5 每级带 WCET/安全/性能，必须为 L5 预留。认知任务在 `ΣWCET≤σ_t` 下按价值密度装包，可选任务整步抢占。

**定义 319（MET）** `g_{t:t+h}∈M_feas`；`VoI_met=H(M|o_t)−E[H(M|o_{t+h})]`，再扣 `c_dyn` 与 `A(h)`；前缀与终端双认证。R69 快照是 `h→0` 退化。

**定义 320–321（时间看门狗与时序故障）** 统计检验 WCET/步数/连续 miss/σ 异常，触发即强制 L5；`ℰ_time` 含 compute-DoS——**让系统算不完是一种物理攻击**。并入 `ℰ_TEMPO=ℰ_FLUID×ℰ_time`。

**定义 322–324（证书、停时、滞回）** `J_TEMPO` 增列实时量；最优停时 `V(b)=max{execute, −Δτ+E[V(b+1)]}`；降级立即、恢复带 `σ↑`、`m` 个周期与 dwell，防抖振。

## 3. 关键算法伪代码

```python
# IP-264 AFS：固定步长、可抢占、任意前缀可执行
class AnytimeFlowSampler:
    def sample(self, o_t, budget_steps, deadline):
        z, xs, b = self.trunk(o_t), self.noise(), 0
        while b < min(budget_steps, self.max_steps):
            if time_left(deadline) < self.wcet_step + WCET_FB:  # 先保兜底
                break
            xs = xs + (1.0/self.max_steps) * self.v(xs, b/self.max_steps, z)
            b += 1
        return self.proj(xs), resolution(b)                     # 粗但可执行

# IP-265 TAV：时间感知 VoI（迟疑 + 陈旧）
def time_aware_value(modes, w, o, slack, age):
    best = None
    for g in info_action_candidates(modes):
        tau = wcet_compute(g) + latency_exec(g)
        if tau > slack or not dft.feasible(g) or not c_ras_wm_s.certify(g, o):
            continue
        val = (entropy(w) - expected_entropy(w, g, o)) - cost(g) \
              - authority_loss(tau) - kappa_s * max(0, age - TTL)
        if best is None or val > best.val: best = (g, val)
    return best if best and best.val > 0 else None              # 无利可图 → R69

# IP-266 DFT：物理先验剪枝（零学习）
def feasibility_trim(modes, o):
    feas, phantom = [], []
    for m in modes:
        (feas if robust_qp_feasible(m, o, EPS) else phantom).append(m)
    return feas, phantom

# IP-267 DAS：slack 上装包，兜底硬预留
def deadline_schedule(tasks, slack):
    cap = slack - WCET_FB
    chosen, used = [], 0.0
    for t in sorted(tasks, key=lambda t: t.value/t.wcet, reverse=True):
        if used + t.wcet <= cap: chosen.append(t); used += t.wcet
    return chosen

# IP-268 MRC：退化阶梯 + 滞回（安全单调）
def degrade(level, st):
    if st.miss or st.watchdog or st.stale > TTL: return max(level, L5)
    if st.slack >= SIGMA_UP and st.age <= TTL:   return max(L0, level - 1)
    return level

# IP-269 TCB：算力信用 + 时效
def carry_over(C_prev, slack_prev, used_prev, age):
    C = min(C_MAX, ETA*C_prev + max(0.0, slack_prev - used_prev))
    return 0.0 if age > TTL else C                            # 过期信用清零

# IP-270 MET：运动式探询（沿轨迹积分 VoI，计动力学成本）
def motion_probe(modes, o_t, horizon):
    best = None
    for g in trajectory_candidates(modes, horizon):
        if not dft.feasible(g) or not c_ras_wm_s.certify(g, o_t): continue
        val = (entropy(modes) - expected_entropy_after(modes, g)) \
              - dyn_cost(g) - authority_loss(len(g)) - cost(g)
        if best is None or val > best.val: best = (g, val)
    return best if best and best.val > 0 else None

# IP-274 主闭环（继承 R69，插入时间预算与兜底）
def TEMPO_RAS_round(M, obs, level=L0):
    ts = M.clock.tick(); z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    slack = deadline_slack(ts, WCET_FB, J_p99)
    if M.watchdog.tripped() or slack <= 0:
        return M.mrc.exec_level(max(level, L5), o, z)          # 超时 → 兜底
    K = min(max_k_within_budget(slack, M.afs.step_wcet),
            1 if M.fmp.mode_head(z) < TAU_MODE else MAX_K)      # K 受预算约束
    xi, rho = M.afs.sample(o, budget_for(K, slack), ts.deadline)
    modes, w = M.aud.decompose(xi)
    modes_f, phantom = M.dft.trim(modes, o)                     # 先剪物理幻影
    g = M.tav.choose(modes_f, w, o, slack, M.tcb.age()) if modes_f else None
    if g is not None and not M.das.can_afford(g, slack): g = None
    if g is not None:
        w = M.cia.update_belief(w, M.met.execute(g))            # 运动式探询
    U_ale, U_epi = M.aud.split(modes_f, w, M.tcb.age())         # 含陈旧膨胀
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(...); k = M.c_ras_wm_s.certified_prefix(A, ...)
    if M.tav.authority_loss(ts.elapsed) > TAU_AUTH:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal)) # 迟疑过大 → 保守
    ref = M.pi_sigma.prefix_dispatch(modes_f, k, lam)
    cmd = M.mrc.inner_contract(ref, o, ts)                      # CBF，永不阻塞
    M.audit.submit_async(g, U_epi, rho, A, slack)
    return M.mrc.exec(cmd, level)
```

## 4. 推导

**引理 19（存在最优停时）** `ΔH(τ)=H_max(1−e^{−τ/τ0})`、`A(τ)=½ατ²`，净收益 `N=ΔH−A` 的驻点唯一有限；`τ>τ*` 继续计算严格有害。系：R69 的 `A≡0` 使 `N` 单调增，系统性**过度思考**；越接近失稳，`τ*` 越小。

**引理 20（任意时刻误差界）** `e(s)≤(1−s)v̄`；投影非扩张，故 `e_proj≤e+dist(x_s,C)`，分辨率单调、误差可先验计算；每次整步截断对应一个可认证粗动作。

**引理 21（保守剪枝不损真模态）** A103 下，`F_ε(m)=false ⇒` 扰动界内确实不可执行；执行不可行模态视为最大风险，故剪枝不增期望风险，并把物理幻影从统计校准中剥离。

**引理 22（陈旧即低估）** A104 下无观测漂移至少 `κ_age·age`；不加膨胀会低估 `U_epi`；线性膨胀 + TTL 保证要么可信复用，要么付出重验成本。

**引理 23（可调度性）** `Σ_{mandatory}WCET+WCET_fb ≤ D_e−J_p99` 且可选任务整步抢占 ⇒ 无硬期限 miss；价值密度贪心 ≥ 最优 0/1 背包的 1/2（子模下 (1−1/e)）。系：多采样必须是**可选**任务。

**定理 18（严格包含 R69）** `σ→∞、A≡0、全模态可行、内环恒等、无时序故障` 时逐项退化为 R69，动作分布相同；一般情形可行动作集包含 R69 最保守策略与 L5，期望风险 ≤ R69。安全不让步，效率由 anytime/算力信用/运动式探询获得。

**定理 19（分层安全与无突变）** 内环 CBF/无源滤波 + ZOH 前向不变 ⇒ 认知层超时**不改变**内环安全集；退化只降不升、恢复带滞回/dwell ⇒ 切换有限、指令差有界、无抖振；`λ` 沿降级路径单调不降，R69 换装不变式保持。系：**认知层 miss 是性能事件，只有兜底预算被侵占才是安全事件**。

## 7. 本轮最大风险

**一句话**：TEMPO-RAS 的全部安全性押在「WCET 有界、抖动可测、兜底永远可调度」这条**实时假设**上——一旦数据相关的 ODE、缓存抖动或对抗性输入击穿最坏执行时间，最需要思考的歧义峰值恰是兜底预算被挤掉的时刻，系统会从「安全地慢」直接跌成「超时的悬崖」；**实时控制里最危险的谎言，不是『我算得慢』，而是『我知道最坏有多慢』**。

**次级风险与缓解**：权威损失 `A(τ)` 低估 → 保守上界 + 失稳优先（E303）；`F_ε` 误杀真模态 → 鲁棒余量 + 只剪鲁棒不可行（A103/E304）；算力信用借了时间又借事实 → TTL 强制重验 + 折旧（引理 22/E309）；多速率耦合抖振 → 内环 CBF + 滞回 dwell（定理 19）；时序拒绝服务 → 看门狗 + 预算审计 + ℰ_dos 对抗测试（定义 320/321/E308）。

**与 R69 的关系**：R69 的风险是「模态权重不可信 → 自信地追问幻影」；R70 用 DFT 免费剪掉**物理不可行**的一类幻影，用 TAV 抑制过度追问。但 R70 引入新的单点故障——**时间模型**。这是一次诚实的交换：**用一个可测量的物理约束（时间）替换一个难测量的统计假设（模态可信度），但测量时间本身也可能撒谎。**
