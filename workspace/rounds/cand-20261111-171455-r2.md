# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「安全交互」×「SLAM」）

> 第 54 轮把技能组合从“能力匹配”推进为“动作空间剖面 + 鲁棒性谱”的联合证书 J。但 J 仍隐含一个危险前提：**位姿与地图是已知且稳定的**。本轮引入「安全交互」与「SLAM」，把这个前提拆开：安全证书必须在 **位姿信念 + 地图信念** 上签发，SLAM 的协方差与地图不确定性直接消耗安全裕度，回环闭合与云边帧失配则会让旧证书瞬间失效。核心矛盾：H22：安全交互是状态相关的硬约束，而 SLAM 位姿误差使“安全集”在真实执行时发生漂移，产生假安全；H23：云端全局地图与边端局部地图在帧与分辨率上不一致，云端签发的安全证书在边端坐标系中可能不再 sound。

## 0. 直觉与动机

**灵感 1（安全不是动作的属性，而是“动作 × 位姿信念 × 地图信念”的联合属性）**
直觉：传统安全交互把安全写成 `h(x,a) ≥ 0`，默认 `x` 是真实状态。但机器人只有估计 `μ` 和协方差 `Σ`。若在 `μ` 处 `h` 刚好为正、而 `Σ` 很大，真实状态可能落在 `h<0` 的区域。正确对象是 **安全交互包络（SIE）**：在所有“信念内可能状态”上都不违反约束的动作集合。动作是否安全，不再由单点决定，而由置信集上的最坏值决定。

**灵感 2（SLAM 协方差 → 可消耗的安全预算）**
直觉：位姿不确定性等价于“安全裕度的税”。定义安全预算 `B_safe = h(μ,a) - L_h·r_ε - δ_map - δ_contact`，其中 `L_h` 是安全函数对位姿的 Lipschitz 常数，`r_ε` 是置信椭球半径。机器人不是“安全/不安全”二值，而是在花预算：漂移越大、地图越糊、接触扰动越强，预算消耗越快。当 `B_safe < 0` 时证书失效，必须切换到安全动作（减速、绕行、柔顺或安全停止）。

**灵感 3（地图不确定性 → 未知区保守化与语义可交互性）**
直觉：SLAM 地图不是“已知自由/已知障碍”的二值图，而是带占用熵的信念场。安全交互不能把“未知”当“自由”。因此把未知/高熵区域按障碍处理（保守化），并在语义 SLAM 上增加“可交互性”标签：可推、可抓、可倚靠的物体有不同接触力与形变约束。安全函数同时包含几何净空与接触力/力矩裕度。

**灵感 4（云边安全证书的帧对齐 → 回环闭合是证书的“跳变事件”）**
直觉：云端维护全局位姿图与全局地图，边端维护滑窗局部地图。安全证书一定绑定在某个坐标系上。云端签发的 `Cert_c` 通过帧变换 `T_c^e` 传到边端；若 `T_c^e` 的残差超预算，或云端/边端地图的语义占据差异过大，则证书不可迁移。更关键的是：**回环闭合会让位姿图发生非连续修正**，历史安全集随之跳变，旧证书必须原子化失效并重验证，不能“渐逝”。

**灵感 5（安全主动 SLAM → 探索与安全的可判定权衡）**
直觉：当不确定性过高、任何任务动作的安全预算都为负时，最安全的动作不是“硬做任务”，而是“获取信息”。主动 SLAM 选择下一最佳视角/动作，使信息增益最大，同时把安全预算作为 **硬约束** 而非软惩罚。这样机器人会先“看一眼”降低协方差，再执行交互；形成 **信息采集 → 预算恢复 → 安全交互** 的闭环。

**灵感 6（金字塔扩展：在动作层之上加安全-SLAM 层 𝕊）**
直觉：在第 54 轮动作协同层 `𝔸` 之上叠加安全层 `𝕊`：`𝕊_0` 物理接触/力极限，`𝕊_1` 位姿-地图信念，`𝕊_2` 安全交互包络 SIE，`𝕊_3` 云边帧对齐证书，`𝕊_4` 任务级安全契约与安全回退。跨层传递的联合证书必须同时携带 `(ρ, A_cert, B_safe, FAC)`，形成 **动作-鲁棒-安全** 三证书体系。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（位姿-地图信念 / Pose-Map Belief）**
时刻 `t` 的信念 `b_t = (μ_t, Σ_t, M_t, U_t, c_t)`：
- `μ_t ∈ SE(3)` 位姿估计，`Σ_t ∈ R^{6×6}` 位姿协方差；
- `M_t : R^3 → {free, occupied, unknown}` 占据地图，`U_t : R^3 → R_{≥0}` 地图不确定性场（如占用熵）；
- `c_t` 标定状态（协方差尺度、传感器外参）。
置信集 `χ_ε(b_t) = { T ∈ SE(3) : e^T Σ_t^{-1} e ≤ κ_ε }`，`e = Log(μ_t^{-1}T)`，`κ_ε = χ²_{6,1-ε}`，半径 `r_ε = sqrt(κ_ε·λ_max(Σ_t))`。
同时定义地图置信集 `𝔐_ε(b_t) = { M : d_M(M, M_t) ≤ δ_M(ε) }`，`d_M` 为占据差异度量。

**定义 122（安全交互包络 / Safe Interaction Envelope, SIE）**
给定安全函数 `h(x,a)`（几何净空与接触力裕度的下包络），信念 `b` 下的安全交互包络：
```
E_ε(b) = { a ∈ A : min_{x∈χ_ε(b), M∈𝔐_ε(b)} h_M(x,a) ≥ 0 }
```
其中 `h_M(x,a) = min( d_obs^M(x,a) - d_safe , (F_max - ||F(x,a)||)/k_F , (T_max - ||τ(x,a)||)/k_T )`，未知区在 `d_obs^M` 中按障碍处理。若 `a∈E_ε(b)`，称 `a` 在信念 `b` 下 **ε-安全**。

**定义 123（定位感知安全裕度与预算）**
若 `h_M` 对位姿 `L_h`-Lipschitz、对地图误差 `L_M`-Lipschitz，则最坏值有下界：
```
h_min(a,b) ≥ h_{M_t}(μ_t,a) - L_h·r_ε - L_M·δ_M(ε) - δ_contact
```
定义 **安全预算** `B_safe(a,b) = h_min(a,b)`。证书签发条件为 `B_safe(a,b) ≥ B_min ≥ 0`；执行中预算按
```
B_safe(t+1) = B_safe(t) - (L_h·Δr_ε + L_M·Δδ_M + Δh_drift)
```
递减。若 `B_safe < B_min`，触发安全回退（减速/绕行/柔顺/安全停止）。

**定义 124（云边帧对齐证书 / Frame Alignment Certificate, FAC）**
`FAC = (T_c^e, Σ_c^e, d_M^{ce}, θ_T, θ_M)`：
- `T_c^e` 云端到边端的帧变换，`Σ_c^e` 其协方差；
- `d_M^{ce} = 1 - IoU(M_c|_{T_c^e}, M_e)` 为对齐后地图差异；
- 有效条件：`||Log((T_c^e)^{-1}T̂_c^e)||²_{Σ_c^e} ≤ θ_T` 且 `d_M^{ce} ≤ θ_M`。
证书迁移 `τ: Cert_c → Cert_e` 仅当 `FAC` 有效且 `B_safe` 在边端重算后仍 `≥ B_min`。

**定义 125（安全交互联合证书 / Safe Interaction Certificate, SIC）**
`J_safe = (E_ε, B_safe, FAC, drift_state, fallback, evidence)`：
- `E_ε` 为安全包络（或其保守内近似）；
- `B_safe` 为当前安全预算；
- `FAC` 为云边帧对齐证书；
- `drift_state` 记录回环闭合与协方差跳变；
- `fallback` 为可执行的安全回退策略（安全停止必须可达）；
- `evidence` 至少含协方差校准记录、回环日志、接触力轨迹、地图差异快照。
若 `B_safe ≥ B_min ∧ FAC valid ∧ drift_state stable ∧ fallback reachable`，则 `J_safe` 可部署。

**定义 126（安全主动 SLAM 目标）**
在信念 `b` 上，规划控制序列 `u_{0:H-1}`：
```
u* = argmax_u  E[ Σ_{t=0}^{H-1} I(b_t,u_t) ] - λ·E[ Σ Risk(b_t,u_t) ]
     s.t.      B_safe(a_t,b_t) ≥ B_min,  ∀t
               fallback_reachable(b_t),  ∀t
```
其中 `I` 为信息增益（如互信息/熵减），`Risk` 为残余交互风险。可行域为空时，退化为“纯信息采集”子问题。定义 **安全-信息 Pareto 前沿** `𝒫_safe`，只有落在前沿上的计划才可签发 `J_safe`。

## 2. 关键算法 伪代码

### IP-121 PMB（Pose-Map Belief Characterization）

```python
def update_belief(slam, sensors, map_model):
    mu, Sigma = slam.pose_graph.estimate()
    Sigma = calibrate_covariance(Sigma, sensors, slam.residuals)
    M, U = map_model.update(sensors)
    c = calibrate_extrinsics(sensors, slam)
    return Belief(mu, Sigma, M, U, c)

def confidence_radius(Sigma, eps, dof=6):
    kappa = chi2_ppf(1 - eps, dof)
    return sqrt(kappa * max_eigenvalue(Sigma))
```

### IP-122 SIE（Safe Interaction Envelope）

```python
def safe_margin(belief, action, h, L_h, L_M, delta_M, delta_contact):
    r_eps = confidence_radius(belief.Sigma, eps)
    h_nom = h(belief.mu, belief.M, action)      # 未知区视为 occupied
    return h_nom - L_h*r_eps - L_M*delta_M - delta_contact

def safe_envelope(belief, actions, h, budgets):
    E = []
    for a in actions:
        B = safe_margin(belief, a, h, **budgets)
        if B >= budgets['B_min'] and fallback_reachable(belief, a):
            E.append((a, B))
    return E
```

### IP-123 LASC（Localization-Aware Safety Certificate）

```python
def certify_action(belief, action, spec, budget):
    if not spec.within_workspace(belief.mu, action):
        return ('reject', 'workspace')
    B = safe_margin(belief, action, spec.h, spec.L_h, spec.L_M,
                    budget.delta_M, budget.delta_contact)
    if B < budget.B_min:
        return ('reject', 'safety_budget', B)
    if not spec.fallback_reachable(belief, action):
        return ('reject', 'no_fallback')
    return ('ok', SafeCert(B, E_approx=[action], evidence=spec.trace(belief, action)))
```

### IP-124 FAC（Frame Alignment Certificate）

```python
def frame_alignment(cloud_map, edge_map, T_ce, Sigma_ce, thetas):
    T_hat = estimate_transform(cloud_map, edge_map)
    r = mahalanobis(Log(inv(T_ce) @ T_hat), Sigma_ce)
    dM = 1 - iou(transform(cloud_map, T_ce), edge_map)
    if r > thetas.theta_T or dM > thetas.theta_M:
        return ('invalid', r, dM)
    return ('valid', FAC(T_ce, Sigma_ce, dM, thetas))
```

### IP-125 SAS（Safe Active SLAM）

```python
def safe_active_slam(belief, task, horizon, lam):
    candidates = sample_controls(belief, horizon)
    feasible = []
    for u in candidates:
        b = belief
        ok, info, risk = True, 0.0, 0.0
        for t in range(horizon):
            a = task.map_control(u[t], b)
            if safe_margin(b, a, **params) < B_min or not fallback_reachable(b, a):
                ok = False; break
            info += mutual_information(b, u[t])
            risk += residual_risk(b, a)
            b = predict_belief(b, u[t])
        if ok:
            feasible.append((u, info - lam*risk))
    if not feasible:
        return pure_information_gathering(belief)
    return max(feasible, key=lambda x: x[1])
```

### IP-126 SIC（Safe Interaction Contract）

```python
def issue_safe_contract(skill_seq, cloud_cert, edge_belief, fac):
    if fac.status != 'valid':
        return ('reject', 'frame_misaligned', fac)
    edge_cert = revalidate(cloud_cert, edge_belief)   # 用边端信念重算 B_safe
    if edge_cert.B < B_min:
        return ('reject', 'budget_edge', edge_cert)
    drift = detect_loop_closure_jump(edge_belief)
    if drift.jump > theta_LC:

    return ('ok', SIC(edge_cert.E, edge_cert.B, fac, drift, fallback_safe_stop,

```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PMB | O(|P|·|L|) 位姿图 + O(|V|) 地图体素 | O(|P|+|V|) | 协方差校准覆盖、外参一致 |
| SIE | O(|A|·|V|) | O(|A|) | Lipschitz 界有效、未知区保守化 |
| LASC | O(|A|·(|V|+C_fallback)) | O(|A|) | `B_min` 闭合、回退可达 |
| FAC | O(|V_c|·|V_e|) 匹配 | O(|V_c|+|V_e|) | 帧变换可观测、地图差异可度量 |
| SAS | O(|U|·H·(|A|+|V|)) | O(|U|·H) | 预测信念校准、硬约束可行 |
| SIC | O(|S|·(|V|+C_fallback)) | O(|V|) | 边端重算、回环跳变检测 |

**正确性定理（Belief-Conditioned Safe Interaction Soundness）**
假设第 54 轮 (A26)–(A28) 承接；**(A29)** 真实位姿以概率 `≥ 1-ε_p` 落入 `χ_ε(b)`；**(A30)** 地图误差以概率 `≥ 1-ε_m` 不超过 `δ_M`；**(A31)** `FAC` 以概率 `≥ 1-ε_f` 有效；**(A32)** 底层跟踪误差有界且 `h` 对控制扰动 `L_u`-Lipschitz，控制器离散化误差为 `ε_u`。则执行期发生不安全交互的概率满足：
```
P(unsafe) ≤ ε_p + ε_m + ε_f + ε_u + P(B_safe < B_min | cert issued)
```
证书签发时最后一项为 0。关键：**信念内最坏值认证、未知区保守化、帧对齐可迁移、回环跳变原子失效、回退始终可达**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 协方差欠校准导致假安全 | 高 | 在线分位数校准 + 温度缩放 + 红队注入漂移 |
| 回环闭合导致安全集跳变 | 高 | 原子失效 + 重验证 + 安全停止兜底 |
| 未知区保守化导致机器人“冻结” | 中 | 主动 SLAM 降不确定性 + 分级保守阈值 |
| 云边地图语义/分辨率断层 | 高 | 共享语义本体 + 多分辨率 FAC + 差异预算 |
| 鲁棒 CBF 计算开销 | 中 | Lipschitz 下界 + 动作预筛 + GPU 批量评估 |
| 安全回退本身不可达 | 高 | 回退可达性作为硬约束 + 形式化验证子集 |

## 6. 本轮最大风险

**一句话**：把安全从“状态已知的硬约束”升级为“位姿-地图信念上的最坏值认证”在逻辑上更诚实，但其 soundness **同时依赖协方差的在线可校准、地图未知区的保守化、以及云边帧对齐与回环跳变的原子处理**；一旦协方差被系统性低估，`B_safe` 会给出“假安全”，而回环闭合又会在一个控制周期内让安全集跳变，故必须以 **在线协方差校准 + 未知区按障碍处理 + 回环触发的安全停止** 三重护栏，宁可暂时不动作，也绝不把“信念内的乐观估计”当作物理安全。

### IP-122 SIE

```python
def safe_margin(belief, action, h, L_h, L_M, delta_M, delta_contact):
    h_nom = h(belief.mu, belief.M, action)          # unknown 视为 occupied
    return h_nom - L_h*belief.r_eps - L_M*delta_M - delta_contact

def safe_envelope(belief, actions, h, budgets):
    E = []
    for a in actions:
        B = safe_margin(belief, a, h, budgets.L_h, budgets.L_M,
                        budgets.delta_M, budgets.delta_contact)
        if B >= budgets.B_min and fallback_reachable(belief, a):
            E.append((a, B))
    return E
```

### IP-123 LASC

```python
def certify_action(belief, action, spec, budget):
    if not spec.within_workspace(belief.mu, action):
        return ('reject', 'workspace')
    B = safe_margin(belief, action, spec.h, spec.L_h, spec.L_M,
                    budget.delta_M, budget.delta_contact)
    if B < budget.B_min:
        return ('reject', 'safety_budget', B)
    if not spec.fallback_reachable(belief, action):
        return ('reject', 'no_fallback')
    return ('ok', SafeCert(B, E_approx=[action],
                           evidence=spec.trace(belief, action)))
```

### IP-124 FAC

def frame_alignment(cloud_map, edge_map, T_ce, Sigma_ce, thetas):
    T_hat = estimate_transform(cloud_map, edge_map)
    r = mahalanobis(Log(inv(T_ce) @ T_hat), Sigma_ce)
    dM = 1 - iou(transform(cloud_map, T_ce), edge_map)
    if r > thetas.theta_T or dM > thetas.theta_M:
        return ('invalid', r, dM)
    return ('valid', FAC(T_ce, Sigma_ce, dM, thetas))

### IP-125 SAS

```python
def safe_active_slam(belief, task, horizon, lam, params):
    feasible = []
    for u in sample_controls(belief, horizon):
        b, info, risk, ok = belief, 0.0, 0.0, True
        for t in range(horizon):
            a = task.map_control(u[t], b)
            if safe_margin(b, a, **params) < params.B_min \
               or not fallback_reachable(b, a):
                ok = False; break
            info += mutual_information(b, u[t])
            risk += residual_risk(b, a)
            b = predict_belief(b, u[t])
        if ok:
            feasible.append((u, info - lam*risk))
    return max(feasible, key=lambda x: x[1]) if feasible \
           else pure_information_gathering(belief)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PMB | O(|P|·|L|+|V|) | O(|P|+|V|) | 协方差覆盖、外参一致 |
| SIE | O(|A|·|V|) | O(|A|) | Lipschitz 下界、未知区保守 |
| LASC | O(|A|·(|V|+C_fb)) | O(|A|) | 预算闭合、回退可达 |
| FAC | O(|V_c|·|V_e|) | O(|V_c|+|V_e|) | 帧可观测、差异可度量 |
| SAS | O(|U|·H·(|A|+|V|)) | O(|U|·H) | 硬约束可行、预测校准 |
| SIC | O(|S|·(|V|+C_fb)) | O(|V|) | 边端重算、回环原子失效 |

**正确性定理（Belief-Conditioned Safe Interaction Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 真实位姿以概率 `≥1-ε_p` 落入 `χ_ε(b)`；**(A30)** 地图误差以概率 `≥1-ε_m` 不超过 `δ_M`；**(A31)** `FAC` 以概率 `≥1-ε_f` 有效；**(A32)** 跟踪误差有界、`h` 对控制扰动 `L_u`-Lipschitz，离散化误差 `ε_u`。则：
```
P(unsafe interaction | cert issued)
   ≤ ε_p + ε_m + ε_f + ε_u + P(B_safe < B_min | cert issued)
```
证书签发时末项为 0。关键：**信念内最坏值、未知区保守、帧对齐可迁移、回环原子失效、回退可达**。

## 6. 本轮最大风险

**一句话**：安全-SLAM 耦合把安全从“状态已知的硬约束”变成“位姿-地图信念上的最坏值认证”，逻辑更诚实，但其 soundness **同时依赖协方差的在线可校准、未知区保守化、以及云边帧对齐与回环跳变的原子处理**；一旦协方差被系统性低估，`B_safe` 会签发“假安全”，而回环闭合会在一个控制周期内让安全集跳变，故必须以 **在线协方差校准 + 未知区按障碍处理 + 回环触发的安全停止** 三重护栏，宁可暂时不动作，也绝不把“信念内的乐观估计”当作物理安全。
