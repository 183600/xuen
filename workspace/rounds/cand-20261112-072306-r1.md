> 第 59 轮把「证据承诺」一路接地到电机电流环与阻抗证书，但它默认了三个更底层的「免费午餐」：**观测在本地即时可得、所有证据共享同一时基与坐标系、视觉位姿近似真值**。本轮两个灵感正好从「时空」维度把这个假设撕开：**通信延迟**说明证据有「事件时间」与「到达时间」两套时间，延迟不是加性噪声而是**时空错位**——你拿来决策的观测描述的是另一个时刻的世界；**视觉定位**说明位姿不是真值，而是**多假设、漂移、退化、别名、且依赖地图版本**的估计，把 GMM 平均成一个点再配高斯协方差，是系统级的「坍缩幻觉」。本轮核心命题：**每条证据都必须携带它在时空中的有效域；每次承诺都必须落在「证据有效域 ∩ 动作执行窗口 ∩ 坐标系可溯源域」之内；估计器在不可辨识、别名或多假设分歧时必须拒绝坍缩。** 即从「执行接地」升级为**时空接地（Spatio-Temporal Grounding, STG）**。

核心矛盾：
- **H32（延迟即错位，不是噪声·DAE）**：把通信延迟当作「额外高斯噪声」会让 UKF/共形带严重低估误差——延迟观测的似然描述的是 t_e 时刻的世界，而承诺发生在 t_c+Δ；正确做法是按**事件时间**传播（前向预测 / 固定滞后平滑 / OOSM 回溯），误差随 Δ=t−t_e 增长，并在超过保鲜期时**拒绝用于承诺**、只用于历史校准。
- **H33（定位即假设集，不是点·VLR）**：视觉定位在长走廊、弱纹理、重复纹理、光照突变、动态遮挡下会出现**退化方向、感知别名（多峰）、绑架（跳变）**；点估计 + 各向同性协方差是坍缩幻觉。必须输出 **SE(3) 上的 GMM + 可靠性证书（退化方向、有效模态数、时序一致性、地图新鲜度、内点率、绑架概率）**，并按「决策等价性」决定能否合并。
- **H34（坐标系不确定传染·FPC）**：相机→基座→世界→地图的每一段外参 / 里程计 / 对齐都有误差；小角度误差经杠杆臂线性放大（σ_p ≈ r·σ_θ），地图版本不一致会让「同一物理点」在不同帧里变成不同点。必须做**变换链溯源 + 伴随（adjoint）误差传播 + 版本一致性检查**。
- **H35（分布式证据不同步·DEC+）**：多机器人各自在不同延迟、不同地图版本下「看到」世界；对陈旧数据做一致性平均不是共识，**过时多数可能压过新鲜少数**。必须做**事件时间对齐的有界共识 + 时间队列分区 + 分区降级**。

## 0. 直觉与动机

**灵感 1（通信延迟 → 延迟感知证据代数 DAE）**
直觉：延迟不是「把信息变糊」，而是「把信息挪到另一个时刻」。一条带时间戳 t_e 的观测，是对 t_e 时刻世界的一个断言；它到达 t_a 时，世界已经演化 Δ=t_a−t_e；若再等到 t_c+Δ_exec 执行，总错位更大。正确语义是**事件时间语义**：把证据看作时空中的一个「证据锥」，用运动模型把它前向传播到决策时刻，并让不确定性随传播时程增长；乱序到达的测量不能直接覆盖当前状态，而要**回溯插入**到事件时间序，再重放到当前（固定滞后平滑 / OOSM retrodiction）。超过保鲜期 τ_0 的证据不参与承诺，只参与离线校准——否则就是「用旧地图指挥新世界」。此外，跨机时间戳必须带**时钟偏斜界** θ_sync：事件时间不是点，而是区间 [t_e−θ_sync, t_e+θ_sync]。

**灵感 2（视觉定位 → 定位可靠性证书 VLR）**
直觉：视觉定位不是一个「带误差的点」，而是一个**带假阳性的假设集**。可观测性差的方向（白墙、长廊）上，Fisher 信息最小特征值趋近于零，位姿在该方向上几乎无约束；重复纹理会产生多个几乎等价的位姿峰；绑架 / 重定位会造成时序连续性断裂；地图更新（回环）会造成参考系跳变。关键洞见：**不要用一个均值掩盖多峰**；先判断「这些峰在决策相关谓词上是否等价」，等价才允许合并，否则保留混合或直接拒绝承诺。退化必须是**方向性的**：不是把整个协方差均匀吹大，而是沿退化方向吹大、沿可观测方向保持锐利。

**灵感 3（合流 → 时空证据证书 STEC）**
直觉：把每条证据写成 `e = (位姿分布, 参考帧, 地图版本, 事件时间区间, 到达时间, 时钟偏斜界, 帧溯源链, 陈旧度函数)`。它不是一个标量观测，而是时空中的一个「带有效期的区域」。查询「e 是否支持在 (x, W) 处执行动作」于是变成三个交集判断：**时间可连接**（事件时间经 τ_0 保鲜期可达动作窗口）、**空间可覆盖**（前向传播后的分布落在动作位姿的 χ² 椭球内）、**坐标系可溯源**（帧链可复合且地图版本一致）。任一为空 ⇒ 不支持。

**灵感 4（合流 → 延迟补偿承诺 DCC）**
直觉：承诺的安全边界不再只是「力不超限」，而是「**执行窗口内的世界仍在我证据支撑的时空锥里**」。DCC 在提交前把信念传播到动作时刻，检查几何漂移是否在 δ_f 对应的界内；若不在，可以选择**等待一次新鲜观测**（但等待会让世界继续变化）、**降速 / 缩短预测时程 / 减小动作幅度**、**改为局部探针**或**停止**。这是一个显式的「新鲜度 vs 速度」权衡：动作越快，执行时程越短，但证据越可能陈旧；等待越久，证据越新，但世界漂移越多。

**灵感 5（合流 → 通信预算 B_comm 与分布式有界共识 DEC+ / PCE++++）**
直觉：通信带宽、时延、时钟同步精度、丢包率都是新的**预算维度**。VOI 必须乘上**陈旧度折扣**并扣除**通信成本**：越晚到达的信息价值越低，越贵。多智能体融合时必须做**事件时间有界共识**：只有事件时间差 ≤ δ_t 的证据才允许融合；否则按时间队列分区，只信最新队列；最新队列不足法定人数则退化为本地保守。**过时多数不能压过新鲜少数**——这是安全单向性在分布式场景的延伸。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（时空证据证书 STEC）** 证据 `e = ⟨b_e, F_e, m_e, I_e=[t_e^−, t_e^+], t_a^e, θ_sync^e, Π_e, w_e(·)⟩`，其中：`b_e` 是参考帧 `F_e` 中的位姿 / 特征分布（Gaussian 或 SE(3) 上的 GMM）；`m_e` 是地图版本号；`I_e` 是事件时间有效区间（含曝光 / 积分窗口）；`t_a^e` 是到达时间；`θ_sync^e` 是时钟偏斜上界；`Π_e` 是帧溯源链（有序变换边 id）；`w_e(τ)=exp(−max(0,τ)/τ_0)` 是陈旧度权重，`τ=t_use−t_e^+`。时空有效域 `V(e)=supp(b_e) × I_e × {由 Π_e 可复合的帧} × {m_e}`。查询 `q=(x,W,F_q,m_q)`，`W=[t_c,t_c+Δ_exec]`。**时空支撑谓词** `e ≽ q` 当且仅当：
```
(i)  时间可连接：∃ t_e∈I_e, t_act∈W，使 t_act−t_e ≤ τ_0（且 t_e ≤ t_act，未来证据不得支撑过去动作）
(ii) 坐标可溯源：Π_e 可复合到 F_q，且 m_e 与 m_q 版本兼容（或已显式配准）
(iii) 空间可覆盖：把 b_e 从 t_e^+ 前向传播到 t_act，叠加时钟/延迟协方差后，
       在动作相关子空间上的马氏距离 ≤ χ²_{d,1−δ_f/κ}
(iv) 可靠性可接受：VLR(e) 在动作相关方向上未退化、未别名冲突、未绑架
```
支撑集 `Supp(q)={e | e≽q}`；承诺允许当且仅当 `Σ_{e∈Supp} w_e ≥ w_min` 且至少存在一条新鲜证据链。

**定义 154（延迟感知融合 DAF / 事件时间固定滞后平滑）** 维护以事件时间排序的因子图，固定滞后 `L_retro`。测量 `y_e` 带事件时间 `t_e`、到达延迟 `d_e=t_a^e−t_e`。若 `d_e ≤ L_retro`：按事件时间插入因子，并对受影响窗口**回溯重放**（retrodiction）；若 `d_e > L_retro`：仅进入校准日志，不重写在线信念。前向传播：
```
x̂(t|t_e) = Φ(t−t_e)·x_e
Σ(t|t_e) = Φ(t−t_e)·Σ_e·Φ(t−t_e)ᵀ + Q(t−t_e)
```

### IP-152 STEC（时空证据证书与支撑判定）

```python
@dataclass
class EventTimeInterval:
    t_lo: float          # 事件时间下界
    t_hi: float          # 事件时间上界（含曝光/积分）
    t_arrival: float     # 到达时间
    sync_bound: float    # 时钟偏置+速率误差上界

    def age_at(self, t):
        return max(0.0, t - self.t_hi)

@dataclass
class SpacetimeEvidence:
    belief: object        # Gaussian 或 PoseGMM
    frame: str
    map_version: int
    time: EventTimeInterval
    provenance: object    # FrameProvenanceChain
    delay_model: object
    source: str

def staleness_weight(ev, t_use, tau0):
    return math.exp(-ev.time.age_at(t_use) / tau0)

def spacetime_supports(ev, x_query, W, frame_q, map_q, env, delta_f):
    # (i) 时间可连接
    if ev.time.t_hi < W.t_lo - env.tau0:
        return False
    if ev.time.t_lo > W.t_hi:
        return False
    # (ii) 坐标可溯源
    if not ev.provenance.composable_to(frame_q):
        return False
    if not version_compatible(ev.map_version, map_q):
        return False
    # (iii) 空间可覆盖（取动作窗口最不利端点）
    t_act = W.t_lo
    b = propagate_belief(ev.belief, ev.time.t_hi, t_act, ev.provenance, frame_q)
    b = inflate(b, clock_and_delay_cov(ev, t_act))
    d = decision_relevant_mahalanobis(b, x_query, delta_f)
    # (iv) 可靠性交由 VLR 门（在 DCC 中统一检查）
    return d <= chi2_thresh(delta_f)
```

### IP-153 DAF（事件时间固定滞后平滑 + OOSM）

```python
class DelayAwareFusion:
    def __init__(self, motion, fixed_lag=1.0, tau0=0.2):
        self.motion = motion
        self.fixed_lag = fixed_lag
        self.tau0 = tau0
        self.factors = []          # 按事件时间排序
        self.calibration_log = []

    def ingest(self, ev, t_now):
        age = t_now - ev.time.t_hi
        self.factors.insert_by_event_time(ev)
        if age > self.fixed_lag:
            # 太晚：只作历史校准，绝不重写在线信念
            self.calibration_log.append(ev)
            return self.current_belief(), "calibration_only"
        # 回溯：从固定滞后窗口起点重放
        t0 = max(ev.time.t_lo - 1e-6, t_now - self.fixed_lag)
        x = self.keyframe_at_or_before(t0)
        for f in self.factors.within(t0, t_now):
            x = self.motion.predict(x, f.time.t_hi - x.t)
            w = staleness_weight(f, t_now, self.tau0)
            infl = delay_inflation(f, self.motion)
            x = fuse(x, f, w=w, cov_infl=infl)
        return x, "retrodicted"

    def predict_to(self, t_future):
        x = self.current_belief()
        return self.motion.propagate(x, t_future - x.t)   # 协方差随时程增长
```

### IP-154 VLR（视觉定位可靠性）

```python
@dataclass
class LocReliability:
    lambda_min: float
    degenerate_dir: object
    n_eff: float
    decision_conflict: bool
    temporal_consistency: float
    map_freshness: bool
    inlier_ratio: float
    p_kidnap: float

class VisualLocalizationReliability:
    def assess(self, obs, prior, motion_pred, map_version, map_current, predicate):
        vals, vecs = np.linalg.eigh(obs.fim)
        lam_min = float(vals[0])
        deg_dir = vecs[:, 0] if lam_min < self.lambda_deg else None

        n_eff = effective_modes(obs.pose_gmm)
        conflict = (n_eff > 1 + self.eps_mode and
                    not all_decision_equivalent(obs.pose_gmm, predicate))

        innov = mahalanobis(obs.pose_mean, motion_pred.mean,
                            motion_pred.cov + obs.pose_cov)
        p_kidnap = sigmoid((innov - self.chi2_kidnap) / self.temp)

        return LocReliability(
            lam_min, deg_dir, n_eff, conflict,
            temporal_consistency(obs, prior),
            map_version == map_current,
            obs.inlier_ratio, p_kidnap)

    def gate(self, rel, action_dir):
        if rel.p_kidnap > self.p_max:      return False
        if not rel.map_freshness:          return False
        if rel.decision_conflict:          return False
```

```python
        T = np.eye(4)
        S = np.zeros((6, 6))
        for e in path:
            Ad = adjoint(T)
            T = T @ e.T
            S = S + Ad @ e.cov @ Ad.T
```

```python
def degrade(M, cp, reason, W):
    options = []
    # 等待一次新鲜观测
    options.append(("WAIT_FRESH", voi_fresh(M, cp, W) - M.budget.comm.cost(cp.fresh_probe)))
    # 本地探针（短距、低风险）
    options.append(("PROBE_LOCAL", voi_meta_pessimistic(cp.local_probe, M) - cost_exec(cp.local_probe, M)))

    # 绕行 / 停止
    options.append(("REROUTE", voi_reroute(M, cp)))
    options.append(("STOP", 0.0))
    best = max(options, key=lambda x: x[1])
```

```python
from dataclasses import dataclass, field
import math
import numpy as np

TAU0 = 0.20              # 证据保鲜期 (s)
W_MIN = 0.30             # 支撑集总权重阈值
KAPPA_RISK_SPLIT = 5     # 风险预算在 C2/C3/C4 间分配的分母

@dataclass
class EventTimeInterval:
    t_lo: float
    t_hi: float
    t_arrival: float
    sync_bound: float

    def age_at(self, t):
        return max(0.0, t - self.t_hi)

    def dilated(self):
        return EventTimeInterval(self.t_lo - self.sync_bound,
                                 self.t_hi + self.sync_bound,
                                 self.t_arrival, self.sync_bound)

@dataclass
class SpacetimeEvidence:
    belief: object
    frame: str
    map_version: int
    time: EventTimeInterval
    provenance: object
    delay_model: object
    source: str
    ev_id: str = ""

def staleness_weight(ev, t_use, tau0=TAU0):
    return math.exp(-ev.time.age_at(t_use) / tau0)

def spacetime_supports(ev, x_query, W, frame_q, map_q, env, delta_f):
    # (i) 时间可连接（用膨胀后的事件时间，保守）
    I = ev.time.dilated()
    if I.t_hi < W.t_lo - env.tau0:
        return False, "stale_beyond_tau0"
    if I.t_lo > W.t_hi:
        return False, "future_evidence"
    # (ii) 坐标可溯源
    if not ev.provenance.composable_to(frame_q):
        return False, "frame_not_composable"
    if not version_compatible(ev.map_version, map_q):
        return False, "map_version_conflict"
    # (iii) 空间可覆盖：取动作窗口最不利端点 t_act
    t_act = W.t_lo
    b = propagate_belief(ev.belief, ev.time.t_hi, t_act, ev.provenance, frame_q)
    b = inflate(b, clock_and_delay_cov(ev, t_act))
    d = decision_relevant_mahalanobis(b, x_query, delta_f)
    if d > chi2_thresh_1d(1 - delta_f / KAPPA_RISK_SPLIT):
        return False, "spatial_drift"
    return True, "ok"

def build_stec(obs, frame_chain, clock, map_version):
    I = EventTimeInterval(
        t_lo=obs.t_event - obs.integration_window / 2,
        t_hi=obs.t_event + obs.integration_window / 2,
        t_arrival=obs.t_arrival,
        sync_bound=clock.offset_bound + clock.rate_error * (obs.t_arrival - clock.last_sync))
    return SpacetimeEvidence(
        belief=obs.pose_dist,
        frame=frame_chain.leaf,
        map_version=map_version,
        time=I,
        provenance=frame_chain,
        delay_model=obs.link_delay_model,
        source=obs.source,
        ev_id=obs.id)
```

### IP-153 DAF（事件时间固定滞后平滑 / OOSM）

```python
class EventTimeFactorGraph:
    """按事件时间排序的因子；固定滞后窗口内可回溯重放。"""
    def __init__(self):
        self.factors = []

    def insert_by_event_time(self, ev):
        i = 0
        while i < len(self.factors) and self.factors[i].time.t_hi <= ev.time.t_hi:
            i += 1
        self.factors.insert(i, ev)
        return i

    def within(self, t0, t1):
        return [f for f in self.factors if t0 <= f.time.t_hi <= t1]

class DelayAwareFusion:
    def __init__(self, motion, fixed_lag=1.0, tau0=TAU0):
        self.motion = motion
        self.fixed_lag = fixed_lag
        self.tau0 = tau0
        self.graph = EventTimeFactorGraph()
        self.keyframes = []          # (t, belief) 稀疏关键帧
        self.calibration_log = []
        self.retrodiction_log = []

    def keyframe_at_or_before(self, t):
        candidates = [k for k in self.keyframes if k[0] <= t]
        return max(candidates, key=lambda k: k[0]) if candidates else self.keyframes[0]

    def ingest(self, ev, t_now):
        self.graph.insert_by_event_time(ev)
        age = t_now - ev.time.t_hi
        if age > self.fixed_lag:
            # 超过固定滞后：只用于离线校准，不重写在线信念
            self.calibration_log.append((ev, age))
            return self.current_belief(), "calibration_only"
        t0 = max(ev.time.t_lo - 1e-6, t_now - self.fixed_lag)
        x = self.keyframe_at_or_before(t0)
        replay = self.graph.within(t0, t_now)
        for f in replay:
            x = self.motion.predict(x, f.time.t_hi - x.t)
            w = staleness_weight(f, t_now, self.tau0)
            x = fuse(x, f, w=w, cov_infl=delay_inflation(f, self.motion))
        self.retrodiction_log.append({
            "ev": ev.ev_id, "age": age,
            "replayed": len(replay), "t0": t0})
        self._maybe_keyframe(x)
        return x, "retrodicted"

    def predict_to(self, t_future):
        x = self.current_belief()
        return self.motion.propagate(x, t_future - x.t)   # Σ 随时程增长

    def _maybe_keyframe(self, x):
        if not self.keyframes or x.t - self.keyframes[-1][0] >= 0.1:
            self.keyframes.append((x.t, x))
            self.keyframes = self.keyframes[-64:]
```

```python
@dataclass
class LocReliability:
    lambda_min: float
    degenerate_dir: object
    n_eff: float
    decision_conflict: bool
    temporal_consistency: float
    map_freshness: bool
    inlier_ratio: float
    p_kidnap: float

class VisualLocalizationReliability:
    def __init__(self, lambda_deg=1e-3, eps_mode=0.2, cos_deg=0.8,
                 p_max=0.05, chi2_kidnap=None):
        self.lambda_deg = lambda_deg
        self.eps_mode = eps_mode
        self.cos_deg = cos_deg
        self.p_max = p_max
        self.chi2_kidnap = chi2_kidnap or chi2_ppf(0.999, df=6)

    def assess(self, obs, prior, motion_pred, map_version, map_current, predicate):
        vals, vecs = np.linalg.eigh(obs.fim)
        lam_min = float(vals[0])
        deg_dir = vecs[:, 0] if lam_min < self.lambda_deg else None

        n_eff = effective_modes(obs.pose_gmm)
        conflict = (n_eff > 1 + self.eps_mode and
                    not all_decision_equivalent(obs.pose_gmm, predicate))

        innov = mahalanobis(obs.pose_mean, motion_pred.mean,
                            motion_pred.cov + obs.pose_cov)
        p_kidnap = sigmoid((innov - self.chi2_kidnap) / 1.0)

        return LocReliability(
            lambda_min=lam_min,
            degenerate_dir=deg_dir,
            n_eff=n_eff,
            decision_conflict=conflict,
            temporal_consistency=temporal_consistency(obs, prior),
            map_freshness=(map_version == map_current),
            inlier_ratio=obs.inlier_ratio,
            p_kidnap=float(p_kidnap))

    def gate(self, rel, action_dir):
        if rel.p_kidnap > self.p_max:       return False, "kidnap"
        if not rel.map_freshness:           return False, "map_stale"
        if rel.decision_conflict:           return False, "alias_conflict"
        if rel.degenerate_dir is not None:
            if abs(np.dot(action_dir, rel.degenerate_dir)) > self.cos_deg:
                return False, "degenerate_along_action"
        return True, "ok"

    def fuse_pose(self, prior, obs, rel):
        if rel.p_kidnap > self.p_max:
            return REJECT_POSE, "require_relocalization"
        if rel.n_eff > 1 + self.eps_mode and rel.decision_conflict:
            # 保留多假设，不平均、不坍缩
            return mix_mixture(prior, obs.pose_gmm), "mixture_preserved"
        if rel.degenerate_dir is not None:
            obs.pose_cov = inflate_along(obs.pose_cov, rel.degenerate_dir, INFLATE_DEG)
        return bayes_update(prior, Gaussian(obs.pose_mean, obs.pose_cov)), "fused"
```

```python
@dataclass
class TransformEdge:
    parent: str
    child: str
    T: np.ndarray       # 4x4
    cov: np.ndarray     # 6x6
    version: int
    timestamp: float

def adjoint(T):
    R, p = T[:3, :3], T[:3, 3]
    A = np.zeros((6, 6))
    A[:3, :3] = R
    A[3:, 3:] = R
    A[:3, 3:] = skew(p) @ R
    return A

def skew(p):
    return np.array([[0, -p[2], p[1]],
                     [p[2], 0, -p[0]],
                     [-p[1], p[0], 0]])

class FrameProvenanceChain:
    def __init__(self, edges, pinned_versions, map_alignment_version):
        self.edges = {(e.parent, e.child): e for e in edges}
        self.pinned = pinned_versions
        self.map_alignment_version = map_alignment_version

    def compose(self, frm, to):
        path = self._find(frm, to)
        T = np.eye(4)
        S = np.zeros((6, 6))
        for e in path:
            Ad = adjoint(T)
            T = T @ e.T
            S = S + Ad @ e.cov @ Ad.T
        return T, S

    def propagate_point(self, p, frm, to, Sigma_p):
        T, S = self.compose(frm, to)
        p_out = T[:3, :3] @ p + T[:3, 3]
        J = np.hstack([np.eye(3), -skew(p)])      # 3x6，含杠杆臂
        return p_out, J @ S @ J.T + T[:3, :3] @ Sigma_p @ T[:3, :3].T

    def composable_to(self, frame):
        try:
            self._find(self._leaf(), frame)
            return True
        except KeyError:
            return False

    def versions_match(self, frame, map_version):
        path = self._find("world", frame)
        if any(e.version != self.pinned.get(e.parent, e.version) for e in path):
            return False
        return self.map_alignment_version == map_version

    def hash(self, frame):
        path = self._find("world", frame)
        return stable_hash([(e.parent, e.child, e.version) for e in path])
```

```python
def delay_compensated_commit(M, cp, delta_f_req):
    W = TimeInterval(time_now(), time_now() + cp.delta_exec)
    x_des = cp.target_pose
    frame_q, map_q = cp.frame, M.map.version

    support, reasons = [], []
    for ev in M.stec.active(cp.region, frame_q):
        ok, why = spacetime_supports(ev, x_des, W, frame_q, map_q, M.env, delta_f_req)
        (support if ok else reasons).append(ev if ok else (ev.ev_id, why))

    total_w = sum(staleness_weight(e, W.t_hi, M.env.tau0) for e in support)
    if total_w < M.env.w_min:
        return degrade(M, cp, "spacetime_support_insufficient", W, reasons)

    # 传播到最不利动作时刻并叠加帧链协方差
    b_act = M.daf.predict_to(W.t_hi)
    b_act = add_frame_uncertainty(b_act, M.fpc.compose(cp.frame, frame_q))
    drift = decision_relevant_mahalanobis(b_act, x_des, delta_f_req)
    if drift > chi2_thresh_1d(1 - delta_f_req / KAPPA_RISK_SPLIT):
        return degrade(M, cp, "geometric_drift_exceeds_bound", W, reasons)

    rel = M.vlr.assess_latest(cp.region, predicate=cp.predicate)
    ok, why = M.vlr.gate(rel, cp.contact_dir)
    if not ok:
        return degrade(M, cp, f"localization_unreliable:{why}", W, reasons)

    if not M.fpc.versions_match(cp.frame, map_q):
        return degrade(M, cp, "frame_or_map_version_mismatch", W, reasons)

    cert = DCCCertificate(
        x_des=x_des, window=W, support=[e.ev_id for e in support],
        support_weight=total_w, drift_bound=drift, reliability=rel,
        frame_hash=M.fpc.hash(cp.frame), map_version=map_q,
        delta_f=delta_f_req, t_commit=time_now())
    M.stec.mark_consumed(support)
    return commit(cp, x_des, W, cert)

def degrade(M, cp, reason, W, reasons):
    options = [
        ("WAIT_FRESH",  voi_fresh(M, cp, W) - M.budget.comm.cost(cp.fresh_probe)),
        ("PROBE_LOCAL", voi_meta_pessimistic(cp.local_probe, M) - cost_exec(cp.local_probe, M)),
        ("SLOW_DOWN",   -M.risk_model.drift_penalty(cp, W)),
        ("REROUTE",     voi_reroute(M, cp)),
        ("STOP",        0.0),
    ]
    action, score = max(options, key=lambda x: x[1])
    if score <= 0:
        action = "STOP"
    M.degradation_log.append({
        "cp": cp.id, "reason": reason, "action": action,
        "support_rejects": reasons, "window": (W.t_lo, W.t_hi)})
    return ExecDegrade(cp, reason, action, W, M.budget.snapshot())
```

### IP-157 DEC+（分布式有界共识）

```python
def bucket_by_event_time(events, width):
    if not events:
        return []
    events = sorted(events, key=lambda e: e.time.t_hi)
    buckets, cur = [], [events[0]]
    for e in events[1:]:
        if e.time.t_hi - cur[0].time.t_hi <= width:
            cur.append(e)
        else:
            buckets.append(cur)
            cur = [e]
    buckets.append(cur)
    return buckets

def delay_bounded_consensus(agents, region, t_now, quorum=2,
                            delta_t=0.05, delta_map=2):
    batches = {a.id: a.evidence(region) for a in agents if a.reachable()}
    if len(batches) < quorum:
        return local_conservative(region), "quorum_lost"

    events = [e for batch in batches.values() for e in batch]
    cohorts = bucket_by_event_time(events, delta_t)
    cohorts = [c for c in cohorts if len({e.source for e in c}) >= quorum]
    if not cohorts:
        return local_conservative(region), "no_temporal_quorum"

    newest = max(cohorts, key=lambda c: max(e.time.t_hi for e in c))
    if not map_versions_reconcilable(newest, delta_map):
        return local_conservative(region), "map_version_conflict"
    # 过时多数不得否决：只在最新队列内融合
    fused = weighted_fuse(newest, w=lambda e: staleness_weight(e, t_now, TAU0))
    return fused, "consensus"
```

```python
        R = schedule_risk(sigma, M)
        while select_gait(R) == "halt" and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            if not cands:
                break
            p, voi = max(((p, voi_with_comm(p, M, budget, time_now())) for p in cands),
                         key=lambda x: x[1])
            if voi < theta_voi:
                break
            M, fused, D_plus, EV_exec, _ = closed_loop_exec_probe(M, cp, delta_f_req, budget)
            budget.probe_spend()
            if EV_exec.degraded_flag:
                break
            sigma = reselect_footholds(x0, cp, M)
            R = schedule_risk(sigma, M)
        ev = tag_evidence_ppp(sigma, M, ops.active, M.ood_reg,
                              EV_exec, cert_eeis, result.cert)
        gate = evidence_gate_ppp(ev, M, ops.active, M.ood_reg, EV_exec)
        if select_gait(R) != "halt" and gate[0] == "ok":
            sched.append(commit_with_dcc(cp, result.cert))
            log.append(ev)
            continue
        alt = reroute(M, cp, M.risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != "halt":
            route = alt
            continue
        return negotiate_or_stop_ppp(cp, M, sigma, R, consent,
                                     tau_int=ops.active.consent_timeout(),
                                     mu_mis=ops.active.mu_mis)
    return sched, log, M
```

**正确性定理（Spatio-Temporal Grounding Soundness, STGS）**
假设 A22–A55（第 53–59 轮）成立；追加 **(A56)** STEC 事件时间区间/时钟偏斜界/帧溯源链诚实且完整；**(A57)** DAF 固定滞后内运动模型一致上界、OOSM 偏差 ≤ε_oosm、超滞后证据不进在线信念；**(A58)** VLR 退化/别名/绑架检测漏检率分别 ≤δ_deg/δ_alias/δ_kidnap，决策等价判定音完备；**(A59)** FPC 边协方差诚实、一阶伴随传播保守、地图对齐版本一致或已签发新证书；**(A60)** DCC 四前置条件真实成立才 commit，降级集穷尽；**(A61)** DEC+ 法定人数/δ_t/δ_map 诚实、最新队列规则严格、分区被检测；**(A62)** PCE++++ 五预算单调互不挪用、cost_comm 与陈旧度折扣诚实；**(A63)** J_st 日志完整不可篡改、版本单增。则：

1. **时空接地校准健全性**：`ECE_k ≤ ε_meta(k) + δ_delay(τ/τ_0) + δ_loc(σ_pose, rσ_θ)`；相对第 59 轮，新增误差可显式归因到延迟、定位与帧链。
2. **延迟感知一致性**：任意到达顺序下 DAF 后验与事件时间 oracle 后验差异 ≤ε_oosm；超过 τ_0 的证据不改变在线后验（不出现「旧证据指挥新世界」）。
3. **承诺时空安全性**：若 DCC 返回 commit 并签发 `Cert_dcc`，则真实动作落在证据有效域外或几何漂移超界的概率 ≤ `δ_f + δ_delay + δ_loc + δ_frame + δ_map + δ_consensus`。
4. **不坍缩性质**：多峰且决策冲突时 VLR 不返回单峰承诺；退化方向不确定性只能沿该方向膨胀。
5. **分布式保守单向性**：分区/版本冲突/同步不可信时退化为本地保守；过时多数不能降低保守性、不能否决新鲜队列。
6. **终止性**：PCE++++ 在 `k_probes+k_cons+k_ft+k_ux+k_exec+k_comm` 内终止于 {带 Cert_dcc 承诺, 绕行, 降档, L2 协商, 安全停, 时空降级停}。
7. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ertc·1[契约违例] + δ_eeis·1[μ分析漏报]
                   + δ_delay·1[τ>τ_0] + δ_loc·1[VLR退化/别名] + δ_frame·1[帧链不可溯源]
                   + δ_map·1[地图版本冲突] + δ_consensus·1[分区/陈旧多数])
         − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
         − P(固件回滚失败) − P(时钟同步失效 ∧ 跨机融合未被禁用)
```

要点：**延迟不是噪声而是错位（DAF）；定位不是点而是假设集（VLR）；坐标不是约定而是误差链（FPC）；承诺不是动作而是时空交集内的可验证契约（DCC）；多机不是平均而是有界共识（DEC+）；通信不是免费管道而是第五重预算（PCE++++）。** 三条安全单向通道继续成立并新增一条分布式的：**信念更准、不确定性更大、动作更保守、过时多数不压新鲜少数。**

## 6. 本轮最大风险

**一句话**：本轮把「通信延迟 × 视觉定位」纳入时空接地，但 STEC 的有效域、DAF 的运动模型、VLR 的退化/别名阈值、FPC 的变换协方差全部是**模型给出的界**——一旦这些界本身有偏（延迟长尾被截断、地图回环未被版本化、退化阈值过松、杠杆臂协方差低估），系统就会得到一套「时空上自洽、却把真实世界挡在证书之外」的假安全感；必须用独立物理锚点、对抗性延迟注入、留出地图版本与人工退化场景持续审计这些界，否则最危险的不是不知道自己在哪，而是「带着时空证书地不知道」。
