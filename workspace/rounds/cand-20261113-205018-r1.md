# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「常识推理」×「行为克隆」）

> R69 教会系统**向外求证**：不确定就问、就看、就触。但它有一个没有说破的前提——那些模态、权重与「epistemic 不确定性」，本质上都是**行为克隆**的统计产物：策略学到的是「在观测 o 下专家做了 a」，而不是「专家为什么做 a」。于是 R69 的 `H(M)` 只问「我处于哪个动作簇」，从不问「我依据的理由对不对」。这留下一个比 R69 自陈风险更深的洞：**行为克隆可以在低熵、高置信、模态校准完美的情况下系统性地错**——专家每次遇到红灯都左转，真实原因却是路边的障碍物；策略把「红灯」学成了原因，R69 只会说「这个模态很确定，不用问」。
>
> 更糟的是，R69 的「k 个正交证据源一致」只检查**一致性**，不检查**有效性**：如果多个表面线索都被同一个虚假相关驱动，它们会一致地错。**一致可以是共谋，流畅可以是幻觉，置信可以是无知。**
>
> 本轮两个灵感正好补上「为什么」这一层：
> - **行为克隆**是模态的来源，也是要被审计的对象：它擅长复制「怎么做」，天然缺少「为什么」；
> - **常识推理**提供唯一一种不依赖奖励与仿真器的「为什么」：前置条件、因果顺序、可供性、社会规范、预期后果。它能把动作模态标注成**理由假设**，也能以**物理/因果/规范不变式**否决一个统计学上很自信、却根本讲不通的动作。
>
> 核心命题：**行为克隆回答「怎么做」，常识回答「为什么」；把理由做成可证伪的不变式与解释准入证，而不是奖励或新控制器。** 一个动作只有在统计上被策略支持、在常识上不被否决、并且在反事实干预下「理由确实被使用」时，才获得执行许可；否则退化为 FLUID-RAS 或更保守。常识是开世界、有覆盖漏洞、会幻觉的，因此全程使用**三值逻辑**：SAT / VIOL / UNKNOWN，且 **UNKNOWN ≠ SAT**。命名 **CIRCLE-RAS**（Commonsense-Invariant Reason-Consistent LEarning & Execution）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我为什么这么做，这个理由经得起反事实吗**」——不是问出答案就算完，答案必须通过常识与干预的双重承兑。

## 0. 直觉与动机

**灵感 1（行为克隆的盲点：它学的是相关性，不是理由）**
直觉：行为克隆最小化 `P(a|o)` 的似然，只要训练分布里某个干扰特征 S 与真实原因 R 高度相关，策略完全可以靠 S 达到 99% 的拟合，却在 R 与 S 解耦的分布外瞬间崩塌。这就是因果混淆/捷径学习：**策略看对了动作，看错了世界**。R69 的模态聚类只在动作空间做文章，低 `H(M)` 被视为「确定」；但低熵恰恰可能是捷径最自信的时候——它根本不知道自己依赖了一个不该依赖的特征。行为克隆缺少的不是数据量，而是**理由监督**：专家示范里没有标注「我因为障碍物而左转，不是因为红灯」。

**灵感 2（常识推理补上「为什么」）**
直觉：常识推理提供的是一张**类型化的理由图**：物体、可供性、物理机制、因果关系、社会规范、任务目标，以及它们之间的 enables / prevents / causes / requires 边。给定一个动作模态，常识可以提出一个理由假设 `ρ = (前置条件 P, 机制 Φ, 预期后果 E, 规范 N)`；给定一条预测轨迹，常识可以判断它是否违反「抓取需要接触」「支撑先于抬升」「不可穿透」「人机舒适距离」这类不变式。关键是：**这些不变式不依赖策略权重，因此与流模型的模态分布是正交证据**——一个由流模型幻觉出来的「幻影模态」，往往首先在常识上就讲不通。

**灵感 3（常识是不完美的：必须三值，且必须能退化）**
直觉：常识是开世界的。它有覆盖空洞（没有规则覆盖当前情境）、有校准误差（说得很肯定但错了）、也会被对抗性规范提示欺骗。若把「不知道」当成「没问题」，就是把系统交给一个沉默的乐观主义者；若把「不知道」当成「违规」，常识就变成一座牢笼，会否决合法的专家新行为。因此采用**强 Kleene 三值逻辑**：任一硬不变式为 VIOL 即否决；否则任一关键不变式为 UNKNOWN 即**不签发许可**；只有全部 SAT 才通过。UNKNOWN 的代价是可用性，而不是安全性——这是本轮最重要的工程姿态：**常识的沉默不是许可，也不是否决，而是回到已被证明安全的基线。**

**灵感 4（反事实自探针：先问自己的策略，再问世界）**
直觉：解释最大的骗局是**事后合理化**——先做动作，再让语言模型编一个听起来对的理由。要防它，解释必须变成**干预**：理由保持（reason-preserving）的编辑（换颜色、换纹理、换无关物体身份、保可供性关系的平移）不应改变动作模态；理由改变（reason-altering）的编辑（移除/插入障碍、反转规范线索、改变可供性或目标）必须改变动作模态。前者高 = 捷径/虚假相关；后者低 = 因果盲。这个探针不需要人、不需要社交成本，只在想象中借助 R67 的世界模型 VISTA 回放即可；只有自探针证据不足时，才升级到 R69 的看/问/触。**最便宜的交互，是先问自己的策略。**

**灵感 5（理由级不确定性可以迁移）**
直觉：R69 的 `H(M)` 是情境特定的：这个岔口的左/右两个簇，换一个岔口就重新编号。理由 R 则是跨情境共享的：「前方有障碍」在走廊、车间、餐桌都成立。因此理由级证据具有**迁移系数** `κ_R`：一次理由级探询可以同时消解多个表面模态。`H(R) ≤ H(M)`（R 是 M 的粗化），但决定损失的是 R 时，粗化反而更值钱。反过来，若损失还依赖同一理由下的精细执行（`H(M|R)`），模态级证据仍不可省——所以 CIRCLE 不是用理由取代模态，而是把两者按成本与迁移性排序。

**灵感 6（解释是准入证，不是装饰）**
直觉：一个解释若不能被证伪，就不是解释，而是故事。CIRCLE 要求解释在**动作提交之前**生成，并通过三重检验：必要性（移除理由图中的原因节点，动作应当改变）、充分性（把原因节点插入一个被抽空理由的情境，动作应当出现）、稳定性（在理由保持编辑与复述下理由不变）。三者同时通过，才签发**理由-解释准入证（REL）**。这把 R69 的「多源一致」升级为「多源一致、各自可兑现、且理由被因果使用」；单源回答仍不得定案。

**灵感 7（最大的诱惑：把常识当奖励或控制器）**
直觉：一旦让常识直接生成动作或给出奖励，就会引入奖励黑客、规范漂移与控制论保证的全面失效。CIRCLE 明确禁止：常识**只能**做三件事——否决（硬不变式）、降权（软不变式）、签发/拒绝许可；动作始终由被认证的行为克隆策略生成，物理安全始终由 R69 的 C-RAS-WM 包络兜底。这是「新层不夺权」原则：**新层只能在有证时放宽，不能在无证时放宽。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CIRCLE-RAS 总览与四不变式）** CIRCLE-RAS = (RGM, RAL, CIV, BCS, RCR, MINT-R, REL, TCL, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **无证不放宽**：任何模态的执行要么持有有效 REL 许可，要么走「至少与 FLUID 同样保守」的降级路径（定义 326）；
(iii) **常识不夺权**：常识只能否决/降权/许可，不得直接合成任务动作、不得生成奖励、不得改写 C-RAS-WM 安全包络；
(iv) **三值诚实**：关键不变式 UNKNOWN 不得当作 SAT；许可必须在动作提交前签发。

**定义 311（常识理由图 RGM）** 类型化有向图 `G = (V, E, τ)`：V 含物体、区域、可供性、物理机制、社会规范、任务目标；E 含 enables / prevents / causes / requires / violates 等类型边；τ 为类型与作用域。`Retrieve(o, m)` 返回与观测 o、模态 m 相关的候选子图。部署时常识器冻结；实时路径只跑蒸馏理由头与缓存子图，LLM/VLM 仅离线建图与版本更新。图带 `g_ver` 与签名。

**定义 312（理由假设与理由归因）** 对模态 `m_k`，理由假设 `ρ_k = (P_k, Φ_k, E_k, N_k)`：前置条件、机制、预期后果、规范约束；它是 G 的极小子图。理由变量 `R ∈ {ρ_k} ∪ {⊥}`，⊥ 表示未覆盖/无理由。RAL 输出每个模态的后验 `q_k(ρ)` 与未覆盖质量 `q_k(⊥)`；理由归因有效需同时满足 `q_k` 校准且 `ρ_k` 在 G 中可兑现（类型一致、作用域匹配）。

**定义 313（理由级不确定性与「自信但无据」）** `U_epi^R = H(R|o) = −Σ_ρ q(ρ) log q(ρ)`。定义「自信但无据」（Confident-But-Unlicensed, CBU）：
`CBU(o) ⇔ H(M|o) < τ_conf ∧ ( H(R|o) > τ_R ∨ q(⊥) > τ_⊥ ∨ S_short > τ_s ∨ ¬Licensed(m*) )`。
CBU 是 R69 完全看不见的一类风险：模态熵很低，但理由未定/未覆盖/被捷径污染。CIRCLE 的触发条件不是「动作不确定」，而是「**动作很确定，但理由不确定**」。

**定义 314（常识不变式与三值 Kleene 求值）** `C = C_hard ∪ C_soft`，`C_hard` 含物理/安全/因果序（不可穿透、接触约束、力/位包络、支撑先于抬升等），`C_soft` 含社会规范/礼仪/偏好。每个 `c ∈ C` 在 VISTA 回放下的模态上取值 `{sat, viol, unk}`。强 Kleene 合取：有 VIOL 则 VIOL；否则有 UNK 则 UNK；否则 SAT。关键集 `C* ⊆ C` 由任务与风险等级声明。

**定义 315（覆盖与理由器校准）** `δ_cov = P(c = unk)`；`ECE_R` 为理由器置信度与理由正确率之间的期望校准误差。常识器获准驱动运行时许可，当且仅当 `δ_cov ≤ τ_cov ∧ ECE_R ≤ τ_ER`；否则 CIRCLE 只保留可由解析式直接判定的硬物理不变式，并关闭理由级交互（见定义 326）。

**定义 316（理由保持 / 理由改变反事实算子）** `T_keep` 为理由保持编辑群：换色/换纹理/换无关物体身份、保持可供性关系的平移、无关背景替换、语言复述。`T_flip` 为理由改变编辑：移除/插入障碍、反转规范线索、改变可供性、改变目标、交换因果前件。每个编辑必须过 `CertEdit`：用冻结 VLM + 理由图验证「语义改动如声明发生，且关键理由未被意外改动」；不通过的编辑不得用于检验，只能标记为 unk。

**定义 317（捷径分与因果盲分）** 令 `d` 为模态/轨迹散度：
`S_short(o) = E_{g∈T_keep} d(π(·|o), π(·|g·o))`；
`S_blind(o) = E_{g∈T_flip} [1 − d(π(·|o), π(·|g·o))]`。
`S_short` 高 ⇒ 策略依赖了理由之外的干扰特征（捷径）；`S_blind` 高 ⇒ 策略对真实原因不敏感（因果盲）。`S_causal = (S_short, S_blind)`。

**定义 318（理由一致性）** 策略在 `(o, R)` 上 `(τ_s, τ_b)`-理由一致，当且仅当 `S_short ≤ τ_s ∧ S_blind ≥ τ_b`。RCR 在训练期用 `T_keep/T_flip` 配对样本强制该性质；BCS 在运行时用当前观测审计该性质。两者共享同一套编辑群，保证训练目标与审计口径一致。

**定义 319（理由感知 VoI 与迁移系数）** 候选探针 `Π = Π_self ∪ Π_reason ∪ Π_world`：`Π_self` 为反事实自探针；`Π_reason` 为理由图检索/常识器追问；`Π_world` 为 R69 的注视/触/问人。`VoI_R(g) = H(R|o) − E_{y~p(·|g,o)}[H(R|o,y)]`；
`score(g) = κ_R·VoI_R(g) − c(g) − λ_edit·risk_edit(g)`，`κ_R ∈ [0,1]` 为理由跨情境复用系数，`risk_edit` 为编辑失效/世界模型不可信的风险。若 `max score ≤ 0`：不探询，退回 R69 的保守兜底。

**定义 320（理由-解释准入证 REL）** 对模态 m 与理由 ρ，定义三重检验：
- **必要性 Nec**：在 `T_flip` 中移除 ρ 的任一关键原因节点，m 的预测概率显著下降；
- **充分性 Suf**：把 ρ 的关键原因节点插入一个理由被抽空的情境，m 的预测概率显著上升；
- **稳定性 Stab**：在 `T_keep` 与语言复述下，ρ 与选择 m 的决策保持不变。
`Licensed(m, ρ, o) ⇔ Nec ∧ Suf ∧ Stab ∧ ρ ≠ ⊥ ∧ 关键不变式无 VIOL/UNK`，且三个检验的边际均超过校准阈值。许可在动作提交前签发，事后只能撤销、不能补发。

**定义 321（许可门与硬/软否决）** 硬不变式 `C_hard`：任一 VIOL ⇒ 该模态被移除，不进入候选。软不变式 `C_soft`：VIOL ⇒ 该模态降权并记审计，但不直接移除；若全部候选被软否决，进入保守降级。关键不变式 UNKNOWN ⇒ 不签发许可。许可门只作用于**模态提交边界**（模态选择 / 前缀派发），不进入力矩内环。

**定义 322（理由对比行为克隆 RCR）** 训练目标
`L_RCR = E‖π(o) − a‖² + α·E_{g∈T_keep} d(π(o), π(g·o)) + β·E_{g∈T_flip} max(0, τ_b − d(π(o), π(g·o))) + γ·L_reason(q(ρ|o), ρ̂)`
第一项为行为克隆，第二项为理由保持不变性，第三项为理由改变敏感性边际，第四项为弱理由监督/自监督一致性。训练期可用 VISTA 生成配对的反事实样本，不需要新的专家动作标签；部署时策略冻结、零写操作。

**定义 323（理由漂移与事后合理化）** `D_reason = E_{t,t'}[1 − sim(ρ_t, ρ_{t'}) | same mode]`。若理由在 `T_keep` 或复述下改变，或解释在动作之后才生成，则判为事后合理化。VQAuditor-R 监测两者，并把「理由-动作时间戳顺序」写入审计缓冲。

**定义 324（威胁模型 AIC-CIRCLE）** `ℰ_CIRCLE = ℰ_FLUID × ℰ_shift × ℰ_cs × ℰ_launder × ℰ_graph × ℰ_cf`：
- `ℰ_shift`：虚假相关漂移、反因果测试、捷径迁移；
- `ℰ_cs`：常识幻觉、看似合理但错误的理由、对抗性规范提示；
- `ℰ_launder`：解释洗白、事后合理化、挑选反事实、理由复述攻击；
- `ℰ_graph`：理由图投毒、检索投毒、版本回滚；
- `ℰ_cf`：反事实世界模型利用（VISTA 在编辑分布外失真，制造虚假的 Nec/Suf）。

**定义 325（证书 J_CIRCLE）** `J_CIRCLE = (J_FLUID, g_ver, δ_cov, ECE_R, license_rate, S_short, S_blind, invariant_status, reason_drift, audit_hash, circle_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ (Licensed ∨ ConservativeFallback) ∧ 关键不变式无 VIOL/UNK ∧ ECE_R ≤ τ_ER ∧ 许可先于动作`。

**定义 326（降级契约：无证不放宽，新层可整体旁路）**
(a) **精确退化**：若常识器未获准（`δ_cov > τ_cov` 或 `ECE_R > τ_ER`）、或用户显式关闭 CIRCLE 层，则 REL/CIV/BCS/MINT-R 全部旁路，CIRCLE 与 FLUID-RAS **逐指令相同**（不引入任何新硬约束，物理安全仍由 R69 C-RAS-WM 负责）。
(b) **保守降级**：若常识器获准但没有任何模态持有有效许可，则**不执行无证模态**；调用 R69 的保守升级（`λ ↑`、`k ↓`、必要时停等），保证不比 FLUID 更激进。
(c) **有证执行**：持证模态在 R69 安全包络内执行；理由层只能放宽「理由级 epistemic」项，不得低于 R69 的 aleatoric floor。

```python
def CIRCLE_RAS_round(M, obs):

    base = M.fluid_round(obs)                     # 与 R69 逐指令一致
    # Phase B：门控。常识器未获准则精确退回 R69
    if not M.tcl.licensed():
        return base
    H_M, U_epi = M.aud.mode_entropy(M.last_samples)
    q, uncovered = M.ral.attribute(M.last_modes, obs)
    H_R = entropy(q)
    inv = M.civ.eval(M.last_modes, obs, M.vista)
    s_short, s_blind, st = M.bcs.probe(M.fmp, obs, q, M.vista)
    cbu = (H_M < TAU_CONF) and (H_R > TAU_R or uncovered > TAU_BOT
                                or s_short > TAU_S or s_blind < TAU_B)
    if not cbu and H_R < TAU_R:
        return base
    # Phase C：理由级探询，最省钱优先（self -> reason -> world）
    g = M.mint_r.choose(M.last_modes, q, obs, M.budget,
                        candidates=[M.self_probe, M.reason_query, M.world_query])
    if g is not None:
        q, uncovered = M.mint_r.execute_and_update(g, q, obs)
    # Phase D：因果自检 + 常识不变式 + 许可（全部在提交前）
    inv = M.civ.eval(M.last_modes, obs, M.vista)
    M.last_modes = hard_veto(M.last_modes, inv)
    licensed = [m for m in M.last_modes
                if M.rel.license(m, q[m.id], obs, inv, M.vista)]
    if not licensed:
        return M.conservative_degrade(base)         # 只收紧，不放宽
    # Phase E：在持证模态中选最安全者；安全包络仍由 R69 负责
    mode = M.select_licensed(licensed, q, U_epi)
    k, lam = M.r69_scale_and_certify(mode, base)
    # Phase F：审计理由漂移、许可时序与编辑可信度
    M.vqa_r.submit_async(mode, q, inv, (s_short, s_blind), st)
    return k, lam, mode
```

## 3. 推导

**引理 19（理由充分性下的 VoI 迁移）** 设损失近似只依赖理由：`|ℓ(a,o) − ℓ_R(a,R(o))| ≤ ε_0`（A99），且理由在上下文间的复用系数为 `κ_R`。则任一探针 g 带来的期望损失下降满足
`Eℓ − E[ℓ|g] ≥ κ_R·L_R·(1 − e^{−VoI_R(g)}) − 2ε_0`。
要点：`H(R) ≤ H(M)`，理由级不确定性更粗，但粗化恰好丢掉了与决策无关的模态细节；一次理由级证据可通过 `κ_R` 复用到多个表面模态。系：当 `κ_R` 高（理由跨场景共享）时，理由级探询比逐个模态探询更值钱；当 `H(M|R)` 本身影响损失时，模态级探询仍不可省。

**引理 20（三值覆盖的「假许可 vs 可用性」权衡）** 若把 UNKNOWN 当作 SAT，则假许可概率至少为 `δ_cov·P(wrong | unk)`；若 UNKNOWN 一律阻止许可，则来自未覆盖的假许可为 0，可用性最多下降 `δ_cov`。故**三值诚实的代价是可用性，不是安全性**；把沉默翻译成许可才会把覆盖漏洞变成安全事故。系：常识器的 `δ_cov` 与 `ECE_R` 必须作为证书字段公开，而不是藏在模型内部。

**引理 21（反事实检测捷径的可靠性与不完全性）** 在 `CertEdit` 有效的理由保持群 `T_keep` 上，若 `S_short > τ_s`，则策略的动作分布在理由之外发生了变化，存在一个理由保持情境使其行为不一致；在 A99 下，这种不一致对应期望 OOD 误差下界 `≥ c·Δ_S·τ_s`。对偶地，`S_blind` 高说明策略对真实原因不敏感。但 `S_short = 0` 只证明在编辑群张成的空间内不变，不证明全局因果性——因此 BCS 是**可靠但不完全**的检验，必须由 REL 的 Nec/Suf/Stab 与不确定性门槛共同兜底。

**引理 22（事前许可阻断事后合理化）** 若许可在动作提交前签发，且 Suf 要求「把原因节点插入理由抽空的情境后动作出现」、Nec 要求「移除原因节点后动作消失」，则在世界模型对编辑分布忠实（A102）且编辑通过 CertEdit 的条件下，纯文本的事后合理化通过许可的概率为 0——因为它没有改变任何干预分布，无法伪造 Suf。残余风险只剩世界模型失真、编辑覆盖不足与理由图投毒（ℰ_cf/ℰ_graph）。

**定理 18（CIRCLE 是 FLUID 的保守扩张）** 在 A99–A102 下：
(i) 常识器未获准或用户关闭时，CIRCLE 与 FLUID-RAS **逐指令相同**（定义 326a）；
(ii) 常识器获准但无持证模态时，CIRCLE 只在 FLUID 基础上收紧（`λ` 不降、`k` 不增），风险 ≤ FLUID；
(iii) 有持证模态时，执行仍受 R69 C-RAS-WM 包络约束，物理风险 ≤ FLUID；理由级错误由许可可靠性上界控制。
故 CIRCLE **安全侧永不弱于 FLUID**，效率侧只在拿到许可后获得理由迁移红利；R69 的「永不交互」边界仍是其精确退化。

**定理 19（理由准入的可靠性上界）** 在 A102 与 `ECE_R ≤ τ_ER` 下，一个持证模态的真实理由与证书理由不一致的概率不超过 `p_edit + p_reason + p_cf`，其中 `p_edit` 为编辑语义偏移、`p_reason` 为理由器错误、`p_cf` 为世界模型反事实失真。该上界是**证书级**的：一旦超过阈值，`J_CIRCLE` 直接失效，系统退回保守路径，而不是带着错误证书继续执行。

**定理 20（最省交互序）** 在 A99 与成本序 `c_self < c_reason < c_world` 下，若 `κ_R·VoI_R(self)/c_self > VoI_R(world)/c_world`，则先自探针后世界探询的顺序在单位成本期望信息增益上最优；只有当自探针的编辑覆盖不足（`st = edit_unk`）或 `S_short/S_blind` 仍越界时，才升级到理由器或人。该序不改变安全性，只改变「向谁求证」的成本；在 `κ_R` 低或 A99 失效时，理由级自探针不能替代世界证据。

## 6. 本轮最大风险

**一句话**：CIRCLE-RAS 的最大风险是「理由空间」的**覆盖幻觉**——当真实原因落在常识本体之外时，行为克隆的捷径会被一个讲得通、可审计、且能通过弱反事实检验的错误理由合法化；系统不是不知道，而是「知道得理直气壮」，而**被解释的错误比未被解释的错误更难被发现**。

**次级风险与缓解**：
1. **常识牢笼**（合法专家新行为被误否决）→ 硬/软不变式分离、软否决可恢复、E309 误否决预算；
2. **常识幻觉与理由器失准** → `δ_cov`/`ECE_R` 门控 + 三值 UNKNOWN + 定义 326 精确退化；
3. **事后合理化/解释洗白** → 许可先于动作 + Nec/Suf/Stab 干预检验 + VQAuditor-R 时序审计；
4. **反事实世界模型被利用**（VISTA 在编辑分布外失真）→ CertEdit 认证 + 仅信任支持域内编辑 + 周期性真实探针校准；
5. **理由图/检索投毒** → 图版本签名 + 检索来源审计 + ℰ_graph 红队；
6. **一致性共谋**（多个证据源共享同一虚假特征）→ 理由保持编辑专门做正交化 + 解析硬不变式 + 不许单源定案；
7. **实时预算被理由层击穿** → 蒸馏理由头 + 子图缓存 + CBU 门控 + 只在模态提交边界签发许可。

**定义 316–318（反事实编辑与理由一致性）** `T_keep` 为理由保持编辑，`T_flip` 为理由改变编辑，均须过 `CertEdit`；`S_short=E_{T_keep}d`，`S_blind=E_{T_flip}(1−d)`；`(τ_s,τ_b)`-理由一致 ⇔ `S_short≤τ_s ∧ S_blind≥τ_b`。RCR 训练与 BCS 运行时共享同一编辑群。

**定义 319（理由感知 VoI）** `Π=Π_self ∪ Π_reason ∪ Π_world`；`score(g)=κ_R·VoI_R(g)−c(g)−λ_edit·risk_edit(g)`；`max score≤0` ⇒ 不探询、退回 R69 兜底。

**定义 320–321（解释准入与许可门）** `Licensed ⇔ Nec ∧ Suf ∧ Stab ∧ ρ≠⊥ ∧ 无关键 VIOL/UNK`；Nec=移除原因则动作消失，Suf=插入原因则动作出现，Stab=理由保持编辑/复述下不变。许可在模态提交边界签发，事后只能撤销不能补发。硬 VIOL ⇒ 移除模态；软 VIOL ⇒ 降权 + 审计；关键 UNK ⇒ 不签发。

**定义 322（RCR）** `L_RCR = BC + α·不变性(T_keep) + β·敏感性边际(T_flip) + γ·理由监督`；训练期可用 VISTA 生成配对反事实样本，不需要新专家动作标签；部署冻结。

**定义 323（理由漂移/事后合理化）** `D_reason=E[1−sim(ρ_t,ρ_{t'}) | same mode]`；理由在 `T_keep`/复述下改变，或解释晚于动作，即判为事后合理化。

**定义 324（威胁模型）** `ℰ_CIRCLE=ℰ_FLUID×ℰ_shift×ℰ_cs×ℰ_launder×ℰ_graph×ℰ_cf`：捷径漂移 / 常识幻觉 / 解释洗白 / 图与检索投毒 / 反事实世界模型利用。

**定义 325–326（证书与降级契约）** `J_CIRCLE` 并入理由覆盖率、校准、许可率、捷径分、不变式状态、理由漂移与审计哈希。降级：(a) 常识器未获准/关闭 ⇒ 与 FLUID **逐指令相同**；(b) 获准但无持证模态 ⇒ **只收紧**（`λ↑, k↓`，必要时停等）；(c) 持证 ⇒ 在 R69 安全包络内执行，理由层只放宽理由级 epistemic，不得低于 aleatoric floor。

```python
class ReasonGraphMemory:
    def retrieve(self, o, mode):
        return self.cache.get((o.scene_id, mode.id)) or self.graph.query(o, mode)

class ReasonAttributionLayer:
    def attribute(self, modes, o):
        q = [self.reason_head(m, self.rgm.retrieve(o, m)) for m in modes]
        return normalize_with_uncovered(q)              # q(ρ), q(⊥)

class CommonsenseInvariantVerifier:
    def eval(self, modes, o, wm):
        out = []
        for m in modes:
            roll = wm.rollout(o, m.a)                   # 复用 R67 VISTA
            vals = {c: c.eval(roll, o) for c in self.invariants}
            out.append(kleene_and(vals))                # sat / viol / unk
        return out

class CounterfactualSelfProbe:
    def probe(self, policy, o, R, wm):
        keep, flip = certified_edits(o, R, self.rgm, wm)
        if not keep or not flip:
            return None, None, "edit_unk"
        s_short = mean(divergence(policy(o), policy(g)) for g in keep)
        s_blind = mean(1 - divergence(policy(o), policy(g)) for g in flip)
        return s_short, s_blind, "ok"

class ExplanationLicense:
    def license(self, mode, rho, o, inv, wm):
        if rho is None or inv["critical_unk"] or inv["hard_viol"]:
            return False
        return (self.test_removal(mode, rho, o, wm)      # Nec
                and self.test_insertion(mode, rho, o, wm)  # Suf
                and self.test_stability(mode, rho, o, wm)) # Stab

def CIRCLE_RAS_round(M, obs):
    base = M.fluid_round(obs)                            # Phase A：R69 精确基线
    if not M.tcl.licensed():                             # Phase B：常识器未获准
        return base                                      # 逐指令退回 FLUID
    H_M, U_epi = M.aud.mode_entropy(M.last_samples)
    q, uncovered = M.ral.attribute(M.last_modes, obs)
    H_R = entropy(q)
    inv = M.civ.eval(M.last_modes, obs, M.vista)
    s_short, s_blind, st = M.bcs.probe(M.fmp, obs, q, M.vista)
    cbu = (H_M < TAU_CONF) and (H_R > TAU_R or uncovered > TAU_BOT
                                or s_short > TAU_S or s_blind < TAU_B)
    if not cbu and H_R < TAU_R:
        return base
    g = M.mint_r.choose(M.last_modes, q, obs, M.budget,
                        candidates=[M.self_probe, M.reason_query, M.world_query])
    if g is not None:
        q, uncovered = M.mint_r.execute_and_update(g, q, obs)
    inv = M.civ.eval(M.last_modes, obs, M.vista)
    M.last_modes = hard_veto(M.last_modes, inv)
    licensed = [m for m in M.last_modes
                if M.rel.license(m, q[m.id], obs, inv, M.vista)]
    if not licensed:
        return M.conservative_degrade(base)              # 无证只收紧
    mode = M.select_licensed(licensed, q, U_epi)
    k, lam = M.r69_scale_and_certify(mode, base)         # 安全包络仍由 R69 负责
    M.vqa_r.submit_async(mode, q, inv, (s_short, s_blind), st)
    return k, lam, mode
```

## 4. 推导

**引理 19（理由充分性下的 VoI 迁移）** 若 `|ℓ(a,o)−ℓ_R(a,R(o))|≤ε_0`（A99），则 `Eℓ−E[ℓ|g] ≥ κ_R·L_R·(1−e^{−VoI_R(g)})−2ε_0`。`H(R)≤H(M)`，理由级更粗，但粗化丢掉的正是与决策无关的模态细节；`κ_R` 把一次理由证据复用到多个表面模态。系：`κ_R` 高时理由级探询更值钱；`H(M|R)` 影响损失时模态级探询仍不可省。

**引理 20（三值覆盖的假许可 vs 可用性）** UNKNOWN 当 SAT ⇒ 假许可至少 `δ_cov·P(wrong|unk)`；UNKNOWN 阻断许可 ⇒ 未覆盖导致的假许可为 0，可用性最多降 `δ_cov`。**三值诚实的代价是可用性，不是安全性。**

**引理 21（反事实检测的可靠性与不完全性）** 在 `CertEdit` 有效的 `T_keep` 上，`S_short>τ_s` ⇒ 策略在理由之外发生了变化，A99 下对应 OOD 误差下界 `≥c·Δ_S·τ_s`；对偶地 `S_blind` 高 ⇒ 因果盲。但 `S_short=0` 只证明编辑群张成空间内不变，不证明全局因果性——BCS 可靠但不完全，须由 REL 与不确定性门槛兜底。

**引理 22（事前许可阻断事后合理化）** 许可先于动作，且 Suf/ Nec 均基于干预分布；在 A102 与 CertEdit 有效下，纯文本事后合理化伪造 Suf 的概率为 0。残余风险为世界模型失真、编辑覆盖不足、理由图投毒（`ℰ_cf/ℰ_graph`）。

**定理 18（CIRCLE 是 FLUID 的保守扩张）** A99–A102 下：(i) 常识器未获准/关闭 ⇒ 与 FLUID 逐指令相同；(ii) 获准但无持证模态 ⇒ 只收紧（`λ` 不降、`k` 不增），风险 ≤ FLUID；(iii) 持证模态仍在 R69 安全包络内，物理风险 ≤ FLUID。故安全侧永不弱于 FLUID，效率侧只在拿到许可后获得理由迁移红利。

**定理 19（理由准入可靠性上界）** A102 且 `ECE_R≤τ_ER` 下，持证模态的真实理由与证书理由不一致概率 ≤ `p_edit+p_reason+p_cf`；越界则 `J_CIRCLE` 失效并退回保守路径，而不是带错证书继续执行。

**定理 20（最省交互序）** A99 与 `c_self<c_reason<c_world` 下，若 `κ_R·VoI_R(self)/c_self > VoI_R(world)/c_world`，则 self → reason → world 的顺序在单位成本期望信息增益上最优；自探针编辑覆盖不足或 `S_short/S_blind` 越界时才升级。该序只改成本，不改安全性。

## 7. 本轮最大风险

**一句话**：CIRCLE-RAS 的最大风险是「理由空间」的**覆盖幻觉**——当真实原因落在常识本体之外时，行为克隆的捷径会被一个讲得通、可审计、且能通过弱反事实检验的错误理由合法化；系统不是不知道，而是「知道得理直气壮」，而**被解释的错误比未被解释的错误更难被发现**。

**次级风险与缓解**：常识牢笼（硬/软分离 + 软否决可恢复 + E309）；常识幻觉与理由器失准（`δ_cov`/`ECE_R` 门控 + 三值 UNKNOWN + 定义 326 精确退化）；事后合理化（许可先于动作 + Nec/Suf/Stab + VQAuditor-R）；反事实世界模型被利用（CertEdit + 支持域内编辑 + 周期真实探针校准）；理由图/检索投毒（图版本签名 + 来源审计 + ℰ_graph 红队）；一致性共谋（理由保持编辑正交化 + 解析硬不变式 + 不许单源定案）；实时预算（蒸馏理由头 + 子图缓存 + CBU 门控 + 仅在模态提交边界签发许可）。
