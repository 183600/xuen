# 第 56 轮（承接第 55 轮语义-接触体系；本轮灵感：「多模态大模型」×「数据规模」）

> 第 55 轮把“动作依赖的接触在语义上是否可信”写进了证书，但留下一个未回答的前提：**证书里的置信与可供性凭什么可信？** 本轮用「多模态大模型」与「数据规模」把这个前提正面化。核心矛盾：**H24（双规模错配）**——多模态大模型（MLLM）拥有互联网级预训练规模 `N_pre`，却几乎没有本体的接触动力学数据 `N_rob`；它能开放词汇地说“这是扶手、可抓”，但这种断言是“预训练先验”，不是“接触事实”，其校准在具身接触数据稀缺处系统性失效。**H25（规模-风险不可外推）**——接触可供性风险不随数据量线性下降，而呈 `R(N)=R_∞+A·N^{-β}` 的幂律并存在不可约地板 `R_∞`；把“预训练规模大”误当作“接触支撑足”，等于用错的规模变量去外推风险。

## 0. 直觉与动机

**灵感 1（MLLM → 开放词汇接触可供性，但它是“断言”不是“事实”）**
直觉：MLLM 能把 RGB-D + 语言提示映射到开放词汇的接触可供性 `κ_LLM(l,c | 场景, 指令)`，这是第 55 轮分割标签所没有的语义广度。但它的输出是 **基于预训练先验的断言**，断言的可信度必须由“本体是否真的见过类似接触”来担保，而不能由模型的流畅度担保。因此 MLLM 只能当“候选生成器”，不能当“接地裁判”。

**灵感 2（数据规模 → 两条不同的规模轴）**
直觉：必须把“数据规模”拆成 **预训练规模 `N_pre`** 与 **具身接触规模 `N_rob`**。前者决定语义广度，后者决定接触校准。二者不可相加为一句“数据很多”；真正决定部署风险的是 **有效接地支撑 `N_g`**，它由 `N_rob` 主导、由 `N_pre` 经一个可学习的迁移可信度 `λ_t` 补偿。规模轴用错，证书就对着错误的变量做保证。

**灵感 3（规模-风险律 → 用风险预算反推所需数据量）**
直觉：与其问“数据够不够多”，不如问“要压到风险预算 `R_target` 以下，还差多少条**同类接触**数据”。若每个材质×接触类型分层 `s` 满足 `R_s(N)=R_∞s + A_s N^{-β_s}`，则可直接解出 **需求规模** `N_req(s) = (A_s/(R_target-R_∞s))^{1/β_s}`，把数据采集从“拍脑袋扩充”变成“按证书反解”。这是把“数据规模”从训练超参变成部署判据的关键一步。

**灵感 4（支撑条件化校准 → 置信下界而非点置信）**
直觉：第 55 轮直接用了 `conf(Σ(p))`。本轮改为 **数据支撑条件化的置信下界**：对支撑 `N_eff` 下的接触成功经验，用二项分布下界（Clopper–Pearson）给出 `κ_LB(N_eff)`；`N_eff` 越小，下界越低、要求裕度越大。这样“低数据区”不是被模型自信掩盖，而是被统计下界显式暴露。

**灵感 5（证书驱动采集 + 规模自适应护盾 → 数据是可执行决策）**
直觉：当 `N_eff < N_req` 时，系统有三条合法出路：**(i) 提高保守度**（膨胀语义边界裕度 `θ_m`）、**(ii) 安全探针接触**（在低后果场景主动采集一条真值接触）、**(iii) 拒绝该接触**。选哪条由 **采集价值** `V(q)=ΔRisk·consequence/cost` 决定。于是“数据规模”第一次成为护盾与证书里的**可执行动作**，而不只是训练时的超参。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（双尺度数据支撑与有效接地支撑）**
样本库 `D = D_pre ∪ D_rob`，`D_rob` 为带接触真值的具身数据。对查询 `q=(p,l,c)`（接触点、语义、接触类型），联合嵌入 `φ(·)` 下
`N_rob(q) = ESS{w_i : ||φ(d_i)-φ(q)|| ≤ r, d_i∈D_rob}`，`N_pre(q)` 同理；
**有效接地支撑** `N_g(q) = N_rob(q) + λ_t·N_pre(q)`，其中 `λ_t∈[0,1]` 为迁移可信度（由跨域校准集估计：预训练支撑每增加一单位能换来多少具身正确率）。`ESS=(Σw)²/Σw²` 为 Kish 有效样本量。

**定义 128（规模-风险律与需求规模）**
按分层 `s = (材质, 接触类型)`，风险（校准误差或接触失败率）
`R_s(N) = R_∞s + A_s·N^{-β_s}`，`A_s,β_s>0`，`R_∞s` 为不可约地板。
给定预算 `R_target > R_∞s`，**需求规模**
`N_req(s) = (A_s/(R_target - R_∞s))^{1/β_s}`；若 `R_∞s ≥ R_target`，记 `N_req=∞`（该分层不可由扩数据达标，必须改机构或拒绝）。

**定义 129（支撑条件化可供性下界）**
对接触事件的经验成功数 `k`、试验数 `n=N_g(q)`，取单侧下界 `κ_LB(q)=BetaInv(α; k, n-k+1)`（Clopper–Pearson）。**支撑条件化可供性**
`κ_N(q) = min(κ_LLM(q), κ_LB(q))`，且有效显著性 `α_eff(N_g)` 随 `N_g` 减小而放大，使低支撑区自动更保守。

**定义 130（规模自适应保守接触集）**
`C^+_N(Σ) = {(p,c) ∈ C(Σ) | κ_N(p,c) ≥ θ_κ ∧ m_s(p) ≥ θ_m(N_g(p,c))}`，
`θ_m(N) = θ_m0·(1 + η·(1 - log(1+N)/log(1+N_0))_+)`，即支撑越低、要求的语义边界裕度越大。与第 55 轮 `C^+` 的关系：`N_g→∞` 时 `θ_m→θ_m0`，退化为第 55 轮。

**定义 131（证书驱动采集价值）**
候选查询 `q` 的采集价值
`V(q) = [R̂_s(N_g(q)) - R̂_s(N_g(q)+1)] · consequence(q) / cost(q)`，
`consequence(q)` 为该接触被误判后的不可逆代价（承重比例、离地高度、是否可回退）。批量采集选 `TopB` 并使分层覆盖 `s` 的剩余需求 `N_req(s)-N_g(s)` 单调下降。

**定义 132（数据规模-接触联合证书）**
`J_d = (Σ_core, C_core, N_g, R̂_s(·), N_req, ρ_sem, δ_s, Π_acq, evidence)`：
- `N_g` 为每个核心接触的有效接地支撑；`R̂_s(·)` 为拟合的规模-风险律；
- `N_req` 为按预算解出的需求规模；`Π_acq` 为残余缺口对应的采集计划；
- `ρ_sem, δ_s` 承接第 55 轮语义鲁棒性谱与扰动预算。
**可部署判据**：对每个 `(p,c)∈C_core`，要么 `N_g(p,c) ≥ N_req(s)`，要么 `κ_N(p,c) ≥ θ_κ` 且护盾已按 `θ_m(N_g)` 膨胀；且规模律外推误差 `≤ ε_law`、`ρ_sem ≥ ρ_min`；否则拒绝并返回 `Π_acq`。

## 2. 关键算法 伪代码

### IP-127 SDA（Support Density Assessment）

```python
def support_density(q, D_rob, D_pre, phi, r, lam_t):
    n_rob = ess([w for d in D_rob if norm(phi(d) - phi(q)) <= r])
    n_pre = ess([w for d in D_pre if norm(phi(d) - phi(q)) <= r])
    return n_rob + lam_t * n_pre, n_rob, n_pre

def ess(weights):
    return (sum(weights) ** 2) / sum(w * w for w in weights) if weights else 0.0
```

### IP-128 SRL（Scale-Risk Law）

```python
def fit_scale_risk(stratum_data):            # [(N_i, R_i)]
    (R_inf, A, beta), ok = robust_fit(
        lambda N, p: p[0] + p[1] * N ** (-p[2]), stratum_data)
    return ScaleLaw(R_inf, A, beta) if ok else None

def required_scale(law, R_target):
    if law.R_inf >= R_target:
        return float('inf')                  # 扩数据不可达标
    return (law.A / (R_target - law.R_inf)) ** (1.0 / law.beta)
```

### IP-129 MCA（Multimodal Contact Affordance）

```python
def mca_affordance(scene, prompt, mllm, D_rob, D_pre, phi, lam_t):
    claims = mllm.open_vocab_affordance(scene, prompt)   # {(p,l,c,score)}
    out = []
    for (p, l, c, score) in claims:
        n_g, n_rob, n_pre = support_density((p, l, c), D_rob, D_pre, phi, r, lam_t)
        k, n = grounded_counts((p, l, c), D_rob, radius=r)
        kappa_lb = clopper_pearson_lower(k, int(max(n, n_g)))
        kappa = min(score, kappa_lb)         # 断言不得高于数据下界
        out.append((p, l, c, kappa, n_g))
    return out
```

### IP-130 SAS（Scale-Adaptive Shield）

```python
def scale_adaptive_shield(u_nom, x, Sigma, contacts, laws, budgets, consequence):
    C = []
    for (p, c) in contacts:
        n_g = support_density((p, label(p), c), D_rob, D_pre, phi, r, lam_t)[0]
        if margin(p) < margin_threshold(n_g, theta_m0, eta, N0):
            continue                          # 低支撑 -> 膨胀裕度后不满足
        if n_g < required_scale(laws[stratum(p, c)], budgets.R_target):
            if consequence(p, c) > c_max or probing_unsafe(x):
                continue                      # 高后果且不可探针 -> 拒绝
        C.append((p, c))
    return semantic_shield(u_nom, x, Kernel, C, W)   # 复用第 55 轮 IP-123
```

### IP-131 CDA（Certificate-Driven Acquisition）

```python
def certificate_driven_acquisition(cert, B, cost_model):
    gaps = [(q, cert.N_req[stratum(q)] - cert.N_g[q]) for q in cert.queries]
    scored = [(value(q, cert.laws, cert.consequence, cost_model), q)
              for q, gap in gaps if gap > 0]
    batch, covered = [], defaultdict(int)
    for v, q in sorted(scored, reverse=True):
        if v <= 0 or len(batch) >= B:
            break
        s = stratum(q)
        if covered[s] < cert.N_req[s]:
            batch.append(q); covered[s] += 1
    return batch
```

### IP-132 DCC（Data-Scale Contact Certificate）

```python
def data_scale_certificate(traj, Sigma, laws, budgets, D_rob, D_pre):
    Sigma_core = core_semantics(traj, Sigma)
    C_core = contacts_used(traj)
    Ng = {q: support_density(q, D_rob, D_pre, phi, r, lam_t)[0] for q in C_core}
    unmet = [q for q in C_core
             if Ng[q] < required_scale(laws[stratum(q)], budgets.R_target)
             and kappa_N(q) < budgets.theta_kappa]
    if unmet and not shield_can_inflate(unmet, Ng):
        return ('reject', 'insufficient_grounded_support', unmet,
                acquisition_plan(unmet, laws, budgets))
    if scale_law_extrapolation_error(laws) > budgets.eps_law:
        return ('reject', 'scale_law_unreliable')
    if semantic_robustness(Sigma_core) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', DataScaleCert(Sigma_core, C_core, Ng, laws, budgets, evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SDA | O((n_rob+n_pre)·d) | O(1) 每次 | 嵌入度量与半径 r 标定、ESS 无偏 |
| SRL | O(n_strata·m·iter) | O(m) | 幂律拟合稳健、外推区间有界 |
| MCA | O(n_claims·(n_D·d+n_C)) | O(n_claims) | 下界覆盖率 1-α、MLLM 断言可证伪 |
| SAS | O(n_contacts·QP) | O(n_C) | 缺口接触被剔除或有界膨胀 |
| CDA | O(n_Q log n_Q + B) | O(n_Q) | 采集价值排序、分层覆盖单调 |
| DCC | O(n_traj·n_C + n_strata) | O(n_C) | 判据 sound、外推误差入证书 |

**正确性定理（Data-Scale-Aware Contact Soundness）**
在第 55 轮 (A29)–(A32) 成立的基础上，追加：**(A33)** `κ_LB` 为真实接触成功率的 `1-α` 下界且 `N_g` 系统性高估不超过 `ε_N`；**(A34)** 分层风险满足幂律 `R_s(N)=R_∞s+A_sN^{-β_s}`，其外推误差 `≤ ε_law`；**(A35)** 采集不引入不可逆接触（探针接触在 `𝒳_safe` 内且后果有界）。
则部署后单步安全概率：
```
P_safe ≥ 1 - P(||Σ-Σ̂||_∞>ε_s) - P(κ_LB 失效) - P(N_g 高估>ε_N)
           - P(规模律外推误差>ε_law) - P(shield fallback fails)
```
关键：**证书不再只用模型的置信，而用“数据支撑 × 统计下界 × 外推误差”三者共同担保**；MLLM 提供广度，数据规模提供接地，二者缺一即可部署性归零。

## 4. 实验设计 E167–E171

| 实验 | 指标 | 目标 |
|---|---|---|
| E167 支撑度估计 | `N_g` 估计 vs 留出覆盖的相对误差 | ≤ 10% |
| E168 规模-风险律 | log-log 拟合 R²、外推误差 | R² ≥ 0.95，外推 ≤ 15% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 规模律跨材质非平稳、外推失效 | 高 | 分层拟合 + 外推区间 + 在线重拟合；超界直接拒绝 |
| 嵌入空间支撑度 ≠ 真实接触覆盖 | 高 | 用接触真值回测校准 r 与 φ；支撑高估纳入 `ε_N` 预算 |
| MLLM 开放词汇过度断言（幻觉） | 高 | 断言必须配可证伪探针；`κ=min(score, κ_LB)` 强制下界 |
| 探针接触本身不可逆 | 高 | 仅在 `𝒳_safe`、低后果场景探针；否则退化为拒绝 |
| 低数据区过度保守导致“冻结” | 中 | 主动采集 + 分层回退 + 保守度预算 |

## 6. 本轮最大风险

**一句话**：把“多模态大模型的语义广度”和“数据规模”接进证书，本质上是用 **规模-风险律的外推** 去为未见过接触担保；一旦幂律在跨材质时非平稳、或嵌入空间的 `N_g` 系统性高估真实接地支撑，证书就会把“预训练见过的相似物”误判为“本体接触过的支撑面”，在最需要保守的长尾场景放出最自信的动作——因此必须以 **接触真值回测的支撑校准 + 外推误差硬预算 + 可证伪探针** 三重护栏，宁可显式承认“数据不足”，绝不把预训练规模当作接地事实。

# 第 56 轮产物 · 创新点清单 v32：ScaleGround-Contact（SDA×SRL×MCA×SAS×CDA×DCC）

> 承接第 55 轮语义-接触体系（IP-121~126）与第 54 轮动作-协同层（IP-115~120）。本轮把“数据规模”从训练超参提升为**部署判据与可执行动作**：
> - **SDA（Support Density Assessment）**：双尺度数据支撑 `N_g`，区分预训练规模与具身接触规模；
> - **SRL（Scale-Risk Law）**：分层规模-风险幂律 `R_s(N)=R_∞s+A_sN^{-β_s}` 与需求规模反解；
> - **MCA（Multimodal Contact Affordance）**：MLLM 开放词汇可供性 + 支撑条件化置信下界；
> - **SAS（Scale-Adaptive Shield）**：低支撑区膨胀裕度 / 安全探针 / 拒绝三选一；
> - **CDA（Certificate-Driven Acquisition）**：由风险预算反推“还差多少、采哪条”；
> - **DCC（Data-Scale Contact Certificate）**：把支撑、下界、外推误差写进联合证书。
>
> IP 编号：IP-127~IP-132（共 6 个新增），升级 IP-121/123/124 以纳入数据规模维度。

```python
        n_g, _, _ = support_density((p, l, c), D_rob, D_pre, phi, r, lam_t)
        k, n = grounded_counts((p, l, c), D_rob, radius=r)
        kappa_lb = clopper_pearson_lower(k, int(max(n, n_g)))
        out.append((p, l, c, min(score, kappa_lb), n_g))
    return out
```

### IP-131 CDA

```python
def certificate_driven_acquisition(cert, B, cost_model):
    gaps = [(q, cert.N_req[stratum(q)] - cert.N_g[q])
            for q in cert.queries if cert.N_req[stratum(q)] > cert.N_g[q]]
    scored = [(value(q, cert.laws, cert.consequence, cost_model), q) for q, _ in gaps]
    batch, covered = [], defaultdict(int)
    for v, q in sorted(scored, reverse=True):
        if v <= 0 or len(batch) >= B:
            break
        s = stratum(q)
        if covered[s] < cert.N_req[s]:
            batch.append(q); covered[s] += 1
    return batch
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SDA | O((n_rob+n_pre)·d) | O(1) 每次 | 半径 r 与 φ 用接触真值标定，ESS 无偏 |
| SRL | O(n_strata·m·iter) | O(m) | 稳健幂律拟合，外推区间有界 |
| MCA | O(n_claims·(n_D·d+n_C)) | O(n_claims) | 下界覆盖 1-α，断言可证伪 |
| SAS | O(n_contacts·QP) | O(n_C) | 缺口接触剔除或有界膨胀，QP 回退 |
| CDA | O(n_Q log n_Q + B) | O(n_Q) | 价值排序，分层覆盖单调 |
| DCC | O(n_traj·n_C+n_strata) | O(n_C) | 判据 sound，外推误差入证书 |

**正确性定理（Data-Scale-Aware Contact Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** `κ_LB` 为真实接触成功率的 `1-α` 下界，且 `N_g` 系统性高估 ≤ `ε_N`；**(A34)** 分层风险满足 `R_s(N)=R_∞s+A_sN^{-β_s}`，外推误差 ≤ `ε_law`；**(A35)** 探针采集仅在 `𝒳_safe` 内、后果有界。则部署后单步安全概率：
```
P_safe ≥ 1 - P(||Σ-Σ̂||_∞>ε_s) - P(κ_LB 失效) - P(N_g 高估>ε_N)
           - P(规模律外推误差>ε_law) - P(shield fallback fails)
```
关键：**MLLM 供广度、数据供接地、下界供保守、护盾供兜底**；任一环节缺失，可部署性归零。

## 5. 本轮最大风险

**一句话**：数据规模感知把“预训练很大”纠正为“接地支撑是否足够”，但整套判据 **双重依赖规模-风险幂律的可外推性与嵌入支撑度对真实接触覆盖的忠实性**；一旦跨材质幂律非平稳、或 `N_g` 高估长尾支撑，证书会在最缺数据的场景给出最乐观的部署结论——因此必须以 **接触真值回测的支撑校准 + 外推误差硬预算 + 可证伪探针** 三重护栏，宁可显式拒绝，绝不把预训练规模当作接地事实。
