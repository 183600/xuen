# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 2 轮；本轮灵感：「因果推理」×「多模态融合」）

> R72 把 GAUGE 从「认知层算法」下沉为「具身实时系统」：REG 实时执行图把「计量不阻塞控制」变成调度级定理；IRL 把意图 z 引入联合后验 b_t(s,z)；DMEM 把灵巧手触觉升级为接触模式条件的计量证据；EREFLEX/ERVOI/E-RISK 把情感、意图、接触三层反作用合算；S2R-UQ 把 sim2real 残差传播到 WCET 与 λ_floor。R72 的姿态是：**「在实时调度下，面对意图模糊的人、用灵巧手触摸世界，我的测量链仍能逐指令兑现风险界。」**
>
> 但 R72 有一个贯穿全局、却从未写进证书的隐含假设：**「关联即证据」**。它的 MIB 校准、IVG 不变性、四分量 u_tac、p(z'|z,a_robot)、p(c'|c,u_ctrl) 全部是在**行为策略产生的观测日志**上估计的。于是 R72 能证明「我的测量链在观测分布上自洽」，却不能证明两件更根本的事：
> - **因果有效性**：这条证据边测的是目标变量本身，还是某个共同原因（光照、说话人风格、任务语境、机器人自己的动作、环境温度）的伴随物？两个模态「同时变化」可能只是因为它们被同一个混淆变量驱动。
> - **融合有效性**：多模态似然按条件独立相乘时，数的是**独立证据**，还是把同一个原因**重复计数**？条件在「只记录成功回合」的选择变量上，还会打开碰撞路径，凭空制造模态间相关。
>
> 本轮两个灵感正好补两块：
> - **因果推理**：给测量链加上**因果测量图（CMG）**、**do-证据算子**、**后门/前门调整**、**因果可辨识性证书（CIC）**、**干预校准（CCE/IGG）**、**反事实风险**与**安全因果探针**。把「测量链可信」升级为「测量链在测量原因、且其证书在干预下仍成立」。
> - **多模态融合**：把「加权融合」升级为**因果融合（CAF）**：先按 d-分离与部分信息分解（PID）判定模态关系（互补/冗余/协同/敌对），再决定证据如何计入；区分**观测可靠性**与**干预可靠性**；核心证据预算只计 unique + synergistic 信息，冗余信息只用于鲁棒性、不用于抬置信。
>
> 核心命题：**不再只问「我的测量链可信吗」，而问「我的测量链在测量原因吗？我的融合只数因果独立的证据吗？我的风险界在 do(动作) 下还成立吗？」** 把 R72 的「具身计量审计」推进为 **CAUSAL-GAUGE-RAS**（Causal, Active, Uncertainty-aware, Structural, Auditable, Learning GAUGE for RAS）——**因果计量审计闭环**。

## 0. 直觉与动机

**灵感 1（因果推理 → 两个模态一起变，不等于目标在变）**
直觉：摄像头看到「红色的杯子」，语音也听到「红色的」，如果这两路证据被同时驱动于**「场景里恰好有一盏红灯光」**或**「说话人习惯先复述颜色」**，那么它们的一致并不提供双倍关于「目标物体」的信息——它们只是同一混淆变量的两个影子。更隐蔽的是**机器人自己的动作**：控制指令 u_ctrl 同时改变接触模式 c 和触觉读数 y_tac，于是「控制器一动，触觉就变」会被误读成「世界状态变了」。**do() 是唯一能切断混淆的操作**；机器人本来就拥有 do() 的能力（它能主动改变自己的动作、问一个问题、做一次轻触），因此**主动交互不仅是信息采集，更是因果识别实验**。

**灵感 2（多模态融合 → 证据不是投票，独立才可相加）**
直觉：把 m 个模态的 log-likelihood 直接相加，等价于假设它们条件独立。若两个模态共享一个未观测共同原因，它们的**冗余信息被数了两遍**，后验会过度自信。正确的做法是先用**部分信息分解（PID）**把联合信息拆成 unique / redundant / synergistic：只有 unique（某模态独有）与 synergistic（必须联合才出现，如「视觉是杯身、触觉是杯柄」的互补约束）才应计入新证据；redundant 只能用于**鲁棒性投票**，不能用于**抬置信**。更极端的是 **synergy/XOR 型**：单看每个模态都无信息，联合才有信息——此时任何「按模态加权」的融合都会系统性低估证据。**融合算子的类型必须由因果/信息结构决定，而不是由超参数决定。**

**灵感 3（计量审计 → 观测校准 ≠ 干预校准）**
直觉：一个意图识别器在历史日志上 ECE=0.03，看起来完美校准；但日志里的动作 a 是行为策略选的，模型从未见过「它自己主动做一次探针动作后，人如何反应」。于是它对 **p(z'|do(a))** 的预测可以完全错误。R72 的 IVG 检查的是「跨已观测域的不变性」，不是「跨干预的不变性」。我们定义**干预校准误差 CCE** 与**干预-观测校准间隙 IGG = CCE − ECE**：**一个模型可以观测上高度校准、干预上系统性失准**。这解释了为什么「所有指标都在有效域内」仍会撞人：审计本身是在行为策略的**选择偏差**下完成的。

**灵感 4（反作用 → 策略内生性让反作用模型自身被混淆）**
直觉：R72 的 L2/L3 反作用模型 p(z'|z,a_robot,ψ)、p(c'|c,u_ctrl) 是从日志拟合的。但 a_robot 不是随机分配的：机器人**因为**相信「人想递交」才伸手，而人**因为**机器人伸手才改变主意。观测到的 (a, z') 相关里混入了**信念 b 的混淆**（policy-induced confounding）。要估计 do(a) 的因果效应，必须要么有随机化探针，要么用工具变量/倾向性加权，要么做**安全干预实验**。**反作用层不是「拟合一条转移曲线」，而是「估计一个干预效应」。**

**灵感 5（反事实风险 → 风险界要在 do(动作) 下成立）**
直觉：R72 的 λ 用的是当前后验的熵和不确定度，是「我对世界有多不确定」；但安全真正关心的是「**如果我执行这个动作，最坏会发生什么**」。这需要**反事实/干预分布**下的风险：R_cf(a) = E[loss | do(a)]，而不是 E[loss | 观测到 a]。当因果图不可辨识时，不能假装有一个点估计；要对**观测等价类**取**最坏上界**，并把**可辨识性间隙**直接塞进 λ_floor。**不可辨识 = 必须更保守，而不是更自信。**

## 1. 形式化定义（增量：定义 366–386）

**定义 366（CAUSAL-GAUGE-RAS 总览）** CAUSAL-GAUGE-RAS = (CMG, CAF, CIC, ICM, CFR, CVP, CSS, GAUGE-RAS†)。六不变式：
(i) **因果边优先**：测量图中每条证据边必须标注 causal / associational；只有 causal 边可作为主证据，associational 边只能作为需去混淆的候选证据；标注缺失即拒绝入融合；
(ii) **融合不重复计数**：多模态证据按 PID 分解后的 unique + synergistic 信息计入证据预算；redundant 信息不得抬高后验置信，只可用于一致性/鲁棒性投票；
(iii) **可辨识性显式**：任何进入风险缩放的因果效应必须携带 CIC（可辨识/部分可辨识/不可辨识）；不可辨识时使用等价类最坏上界，并触发降级；
(iv) **干预校准**：所有进入闭环的预测器（意图、接触、反作用、风险）必须报告 (ECE, CCE, IGG)；IGG 超阈即视为「观测自洽但干预失准」，禁止用于 do 决策；
(v) **反事实风险单调**：λ_floor 必须覆盖 R_cf 的等价类上界，且随可辨识性间隙 Δ_id 单调不减；
(vi) **严格逐指令退化**：CMG 不可信 ⇒ 退化为「保守单模态 + R72」；CAF 失效 ⇒ 退化为 R72 加权融合；CIC 不可辨识 ⇒ 最坏上界 + R72；全部失效 ⇒ R68。**安全侧只增不减。**

**定义 367（因果测量图 CMG）** CMG = (V, E, F, P_U, 𝒟, λ_e)：
- V = V_tgt ∪ V_conf ∪ V_obs ∪ V_int：目标变量（s, z, c）、混淆变量（环境 e、传感器健康 h、任务语境 κ、行为策略 π_b）、观测模态 y_1..y_m、干预变量 a（机器人动作/提问/探针）；
- E ⊆ V×V，每条边 e=(u→v) 带类型 λ_e ∈ {causal, associational} 与机制 f_{v|Pa(v)}；
- F = {f_v} 结构方程（含噪声项 ε_v）；
- P_U 外生分布（含未观测混淆的等价类）；
- 𝒟 允许的干预集合（安全动作、可提问、可轻触），带安全包络。
**语义**：CMG 是「测量链」的因果版本——R72 的测量链是路径，R73 的 CMG 是**带方向的图**。观测数据的分布只在 CMG 上诱导出**观测等价类**；所有因果量必须在该等价类上定义。

**定义 368（结构证据模型与 do-证据算子）** 对目标变量 X（如 s、z 或 c）与模态观测 y_k，**因果证据**定义为干预似然比
Λ_k^do(y_k; X) = p(y_k | do(X=x_1)) / p(y_k | do(X=x_0))，
而非观测似然比 p(y_k|x_1)/p(y_k|x_0)。由 do-演算，
p(y_k | do(X=x)) = Σ_{z∈𝒵} p(y_k | X=x, z) p(z)（后门调整，z 为满足后门准则的调整集），
或在前门结构下用前门公式。**do-证据算子** ℰ^do 把观测分布 + CMG 映射为因果似然；只有 ℰ^do 输出的证据可进入主证据预算。

**定义 369（混淆感知多模态融合 CAF）** 设模态 y_1..y_m，目标 X，共享混淆集 C（可观测部分 C_o，不可观测部分 C_u）。CAF 输出
p^CAF(X | y_1..y_m) ∝ p(X) · Π_{k∈U∪S} [Λ_k^do(y_k;X)]^{w_k} · Π_{k∈R} [Λ_k^do(y_k;X)]^{w_k^rob}，
其中 U/S/R 分别为 PID 判定的 unique / synergistic / redundant 模态组；w_k 为有效证据权重，w_k^rob ≤ w_k 且 redundant 组权重的总贡献被限制为**一致性投票**（只影响方差，不影响均值/置信上限）。若 C_u 非空且不可调整，则对 C_u 的后验取**部分可辨识界**，融合结果输出为后验区间而非点后验。**有效证据量**定义为
ESS = (Σ_k w_k)² / Σ_k w_k²（Kish 有效样本量），且必须满足 ESS ≤ m·(1−ρ̄)，ρ̄ 为平均混淆相关度。

**定义 370（模态因果关系分类）** 给定 CMG 与目标 X，模态对 (y_i,y_j) 的关系由 d-分离与 PID 判定：
- **互补（complementary）**：y_i ⊥ y_j | X，且各自含 unique 信息；证据可近似相加；
- **冗余（redundant）**：存在共同原因 C 使 y_i ⊥̸ y_j | X 且联合信息不增；证据需去混淆/降权；
- **协同（synergistic）**：I(y_i;y_j;X) 的协同分量 > 0（单模态均无、联合才有）；必须保留交互项；
- **敌对（adversarial）**：存在被投毒的共同原因，使两模态在错误方向上一致；触发 CSS + 单源不定案。
**融合算子必须显式类型化**：对互补用加权和，对冗余用去混淆后的独立分量，对协同用交互项，对敌对用非补偿性否决。**「按模态调权重」是把结构问题误当参数问题。**

**定义 371（碰撞与选择偏差哨兵 CSS）** 设 S 为选择变量（如「只记录成功回合」「只保留被采纳的交互」），S 是模态 y_k 与结果 r 的共同效应。条件在 S 上会打开 y_k ↔ r 的碰撞路径。CSS 定义为
CSS = Î(y_i; y_j | X, S) − Î_expected(y_i; y_j | X; CMG)，
其中 Î 为条件互信息估计，Î_expected 为在 CMG 下假设无碰撞时的期望。**CSS 显著为正 ⇒ 检测到碰撞/选择偏差 ⇒ 该审计集失效，禁止用于因果校准。** CSS 需在审计集上离线评估，在线只读通过位（SEAL-Causal）。

**定义 372（因果可辨识性证书 CIC）** CIC = (graph_hash, query, adjust_set, method, status, bounds)：
- query 形如 P(Y | do(X=x)) 或 ACE(X→Y)；
- method ∈ {backdoor, frontdoor, IV, do-calculus, partial-identification, none}；
- status ∈ {identifiable, partially_identifiable, unidentifiable}；
- bounds = [L, U]（可辨识时为点质量）。
**规则**：status=unidentifiable 时，任何「点估计 + 精确 λ」均非法；必须使用 U 作为风险上界，并把 Δ_id = U − L 计入 λ_floor。**可辨识性不是预处理，是安全证书的一部分。**

**定义 373（干预校准 ICM）** 对预测器 q_θ(Y|do(X))：
- **观测校准误差** ECE = E_{x∼p_obs}[ |q_θ(ŷ|x) − p_obs(ŷ|x)| ]；
- **干预校准误差** CCE = E_{x∼p_do}[ |q_θ(ŷ|do(x)) − p_do(ŷ|do(x))| ]；
- **干预-观测间隙** IGG = CCE − ECE。
**引理**（见 §3）存在模型使 ECE→0 而 CCE 任意大。**R72 的审计只覆盖 ECE；R73 必须覆盖 CCE。** 干预校准数据只能来自随机化探针/自然实验/显式干预集，不能用行为日志冒充。

**定义 374（因果接触不确定度）** R72 的 u_tac² = Σ_i u_i² 假设四分量正交。因果版本：
u_tac² = Σ_i u_i² + 2 Σ_{i<j} Cov(u_i,u_j)，
其中协方差项由**共同原因**解释：u_force 与 u_slip 同受 u_ctrl 驱动；u_sens 与 u_geom 同受温度/磨损驱动。协方差符号决定 R72 是高估还是低估：若 Cov>0（同向漂移），R72 低估；若 Cov<0（补偿），R72 高估。**定义因果接触不确定度 u_tac^causal = sqrt(u^T Σ_C u)，Σ_C 为带混淆结构的协方差矩阵**；当协方差不可辨识时，取最大特征值上界（最保守）。

**定义 375（反事实风险缩放 CFR）** 对候选动作 a，反事实风险
R_cf(a) = E_{p(·|do(a))}[ L(s,z,c; a) ]，
其等价类上界 R_cf^max(a) = sup_{M ∈ [M]_obs} R_cf(a; M)。风险缩放
λ_cf = max( λ_risk(U_ale, U_epi, R_cf^max), λ_floor(U_ale + U_epi + Δ_id + u_tac^causal) )。
**关键**：λ 的分母包含**结构不确定度 Δ_id**（因果图/机制的不确定），而不仅是统计不确定度。**「图不确定」必须让机器人更软，而不是更懵。**

**定义 376（因果 VoI 与安全探针 C-VoI）** 对候选干预 g（提问、轻触、改变阻抗、主动展示）：
VoI^C(g) = IG_causal(g) + η_id · IG_id(g) − c_intervene(g) − γ · ConfoundingRisk(g)，
其中 IG_causal 为对目标因果效应的信息增益，IG_id 为**可辨识性增益**（等价类体积收缩/Δ_id 下降），c_intervene 为交互与反作用成本，ConfoundingRisk 为探针本身引入新混淆的风险（如探针动作改变人的意图 z）。选择 g* = argmax VoI^C s.t. g ∈ 𝒟_safe、三层稳态满足、预算未超。**「问一个能打破混淆的问题」优先于「问一个已知答案的问题」。**

**定义 377（策略内生性与反作用去混淆）** 设行为策略 π_b(a|b) 依赖机器人信念 b。观测转移 p(z'|z,a) 与因果转移 p(z'|do(a),z) 一般不等；偏差由 b 的混淆给出。去混淆方法：
- **随机化探针**：以概率 ε 执行与当前信念无关的安全探针，获得 do(a) 的无偏样本；
- **倾向性加权/IPW**：w = 1/π_b(a|b)，做加权估计；
- **工具变量**：用与 a 相关、与 z' 仅通过 a 相关的安全变量作 IV。
**R72 的 L2/L3 反作用模型必须升级为 do 版本** p(z'|do(a),z)、p(c'|do(u_ctrl),c)，否则「反作用」拟合的是「策略自证」。

**定义 378（因果计量指标 C-MIB）** 在 R72 E-MIB 基础上新增：
- **因果族**：confounding bias（调整前后似然比之差）、ESS、Δ_id、CIC status、CSS、ACE 置信区间；
- **干预族**：CCE、IGG、探针覆盖率、倾向性重叠度（positivity）、策略偏差估计；
- **融合族**：unique/redundant/synergistic 信息分解、模态关系类型分布、敌对检出率、协同漏检率；
- **反事实族**：R_cf 上界紧度、等价类体积、反事实后悔。
所有指标同遵循 R71 定义 332 六元组 (φ,m,u,D,τ,I⊥) 与定义 333 DAG 分层。

**定义 379（因果 IVG 门控 C-IVG）** 在 E-IVG 上新增失效条件：
- **图**：CMG 版本不匹配、结构漂移检测触发、关键边方向不可辨识；
- **可辨识**：query 的 status=unidentifiable 且 Δ_id > τ_id；
- **校准**：CCE > τ_cce 或 IGG > τ_igg；
- **融合**：CSS > τ_css（碰撞）、敌对模态被检出、ESS 低于预算下限；
- **策略**：倾向性重叠度 < τ_pos（positivity 失败）、探针覆盖率不足。
任一成立 ⇒ **相关因果量失效**：意图因果失效 ⇒ 固定先验 + R72；接触因果失效 ⇒ 视觉/语言 + R72；风险因果失效 ⇒ 最坏上界 + R72；图整体失效 ⇒ 保守单模态 + R68。

**定义 380（因果证书 J_CAUSAL）** J_CAUSAL = (J_EMB, cmg_hash, cic_set, caf_pid_hash, cce_igg_report, css_report, cf_risk_bounds, seal_causal, ver)。
Valid ⇔ Valid(J_EMB) ∧ CMG 哈希匹配 ∧ 所有 veto query 的 CIC 非 unidentifiable ∧ C-IVG 全过 ∧ CSS 全过 ∧ CCE/IGG 在阈内 ∧ SEAL-Causal 通过。

**定义 381（威胁模型 AIC-CAUSAL）** ℰ_CAUSAL = ℰ_EMB × ℰ_graph × ℰ_confound × ℰ_collider × ℰ_intervene：
- ℰ_graph = {图结构投毒、机制方程漂移、等价类伪装、版本回滚攻击}；
- ℰ_confound = {混淆注入/伪装（同时伪造视觉与语音使其一致）、共同原因操控、隐藏混淆不可检出}；
- ℰ_collider = {选择偏差投毒（只喂成功样本）、碰撞变量操控、审计集选择攻击}；
- ℰ_intervene = {探针响应伪造（假装干预有效）、干预预算耗尽攻击、探针诱导意图漂移}。

**定义 382（因果审计域与流水线集成）** 不改变 R72 的三域分离，新增**因果审计子域（Causal Audit Domain）**：优先级与计量域同层（50–70），运行 CMG 维护、CIC 查询、CCE/IGG 监控、PID 分解；**绝不在控制域同步执行 do-演算或图结构学习**。控制域只读快照中的 (R_cf^max, Δ_id, λ_floor)。**因果推理是慢思考，控制是快反射；慢思考不得阻塞快反射。**

**定义 383（严格退化包含链）** CAUSAL 在以下条件下逐指令等价：
- CMG 有效 + 全可辨识 + CAF 有效 ⇒ CAUSAL 完整形态；
- CMG 有效 + 部分不可辨识 ⇒ 最坏上界 + CAF（保守）；
- CMG 有效 + CAF 失效 ⇒ R72 加权融合 + 最坏上界（冗余重复计数但安全侧保守）；
- CMG 失效 ⇒ 保守单模态（取各模态最保守似然）+ R72；
- CMG 失效 + R72 层失效 ⇒ R68（纯视觉/本体开环）。
**安全单调不减：所有退化都保留 R72 的 λ_floor 与 R68 的硬安全包络。**

**定义 384（因果复杂度与模块上限）** |V_CMG| ≤ 32、|E| ≤ 64、|𝒟| ≤ 16、|pid 模态组| ≤ 6、CIC 查询缓存 ≤ 128；do-演算在部署期离线完成，在线只查缓存；结构学习只在因果审计域周期性执行。**复杂度本身纳入审计指标：因果推理不得把实时系统拖垮。**

**定义 385（SEAL-Causal 密封因果审计集）** 隐藏跨混淆结构、跨选择机制、跨干预响应的场景集；离线评估 CCE/IGG/CSS/敌对检出；在线只暴露通过位。**审计集本身必须防碰撞：其选择机制与部署选择机制独立。**

**定义 386（与 R72 的严格泛化关系）** 若 CMG 中所有证据边均为 causal 且无未观测混淆、所有模态条件独立、所有 query 可辨识、且行为策略随机化，则 CAF ≡ R72 加权融合、CIC 恒为 identifiable、CCE=ECE、R_cf=E[R]、J_CAUSAL ≡ J_EMB。**R73 是 R72 在「存在混淆/选择偏差/策略内生性」时的严格泛化，而不是替换。**

```python
# IP-295 CMG：因果测量图注册表（离线构建，在线只读哈希）
@dataclass
class CausalEdge:
    src: str; dst: str
    kind: Literal['causal', 'associational']
    mechanism: Callable          # f_{v|Pa(v)} 或参数化形式
    identifiable: bool

@dataclass
class CMG:
    nodes: Dict[str, NodeSpec]
    edges: Dict[Tuple[str,str], CausalEdge]
    interventions: Set[str]
    hash: bytes
    def is_valid(self) -> bool:
        return self.hash == recompute_hash(self) and validate_acyclic(self)

# IP-296 CAF：混淆感知 + PID 类型化融合
class CausalFusion:
    def __init__(self, cmg, pid_estimator, backdoor_solver):
        self.cmg, self.pid, self.bd = cmg, pid_estimator, backdoor_solver
    def fuse(self, X, modalities, obs):
        rel = self.pid.classify(X, modalities, self.cmg)   # unique/redundant/synergistic/adversarial
        terms, ess = [], []
        for k, y in modalities.items():
            if rel[k] == 'adversarial':
                return Veto(reason='adversarial_modality')   # 非补偿性否决
            if rel[k] == 'redundant':
                # 只用去混淆后的独立分量，权重仅作鲁棒投票
                adj = self.bd.adjust(y, X, self.cmg, obs)
                terms.append(('rob', adj)); ess.append(0.25)
            elif rel[k] == 'synergistic':
                terms.append(('syn', self.bd.causal_lr(y, X, obs)))  # 保留交互项
                ess.append(1.0)
            else:  # unique / complementary
                terms.append(('main', self.bd.causal_lr(y, X, obs))); ess.append(1.0)
        ess_eff = (sum(ess)**2) / sum(e*e for e in ess)
        return CausalPosterior(terms=terms, ess=ess_eff,
                               interval=self.bd.partial_bounds(X, obs))

# IP-297 CIC：可辨识性证书
class IdentifiabilityChecker:
    def __init__(self, cmg): self.cmg = cmg; self.cache = {}
    def query(self, X, Y):
        key = (X, Y)
        if key in self.cache: return self.cache[key]
        for method in ('backdoor', 'frontdoor', 'iv'):
            s = getattr(self, f'_{method}')(X, Y)
            if s: return self._cert(X, Y, method, 'identifiable', s)
        if (bounds := self._partial(X, Y)) is not None:
            return self._cert(X, Y, 'partial', 'partially_identifiable', bounds)
        return self._cert(X, Y, 'none', 'unidentifiable', (0.0, 1.0))

# IP-298 ICM：干预校准监控
class InterventionalCalibration:
    def __init__(self, predictors, probe_log):
        self.pred, self.log = predictors, probe_log
    def report(self):
        out = {}
        for name, q in self.pred.items():
            ece = obs_ece(q, self.log.observational)
            cce = do_ece(q, self.log.interventional)   # 只来自随机探针/自然实验
            out[name] = Calib(ece=ece, cce=cce, igg=cce - ece)
        return out

# IP-299 CFR：反事实风险缩放
def counterfactual_risk_scale(a, b_t, cmg, cic, u_tac_causal, params):
    R_cf = expected_loss_do(a, b_t, cmg)              # E[L | do(a)]
    R_up = cic.worst_case_over_equivalence_class(R_cf) # 等价类上界
    delta_id = cic.identifiability_gap()
    denom = R_up + delta_id + u_tac_causal
    lam = max(params.lam_base * (1 + denom / params.lam_scale),
              params.lam_floor * (1 + denom))
    return lam, R_up, delta_id

# IP-300 C-VoI：安全因果探针规划
def causal_voi(b_t, cmg, cic, budget, safe_set):
    best = None
    for g in sample_probes(cmg, safe_set, top_k=4):
        if not budget.allow(g): continue
        ig_c  = expected_causal_ig(b_t, g, cmg)
        ig_id = expected_identifiability_gain(cic, g)       # Δ_id 收缩
        cost  = intervention_cost(g) + expected_reflex_cost(g)
        conf  = expected_new_confounding(g, cmg)
        score = ig_c + ETA_ID * ig_id - cost - GAMMA * conf
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-301 CSS：碰撞/选择偏差哨兵
def collider_sentinel(audit_set, cmg):
    for (yi, yj, X, S) in audit_set.triples():
        mi_obs = conditional_mi(audit_set, yi, yj, given=(X, S))
        mi_exp = expected_conditional_mi(cmg, yi, yj, given=(X, S))
        if mi_obs - mi_exp > TAU_CSS:
            return SentinelHit(pair=(yi, yj), css=mi_obs - mi_exp)
    return None

# IP-302 C-IVG + J_CAUSAL：因果门控与证书
def causal_gate(cmg, cic, calib, css, fusion, emb_gate):
    if not cmg.is_valid():                     return Fallback('R68+single_modality')
    if any(c.status == 'unidentifiable' and c.delta_id > TAU_ID for c in cic.veto):
        return Fallback('R72+conservative_bounds')
    if calib.igg > TAU_IGG:                    return Fallback('R72')
    if css is not None:                        return Fallback('R72')
    if not emb_gate.valid:                     return Fallback('R71')
    return Full(J_CAUSAL(cmg, cic, calib, css, fusion))

# IP-303 CAUSAL 主闭环（嵌入 R72 三域；因果审计子域异步）
def CAUSAL_GAUGE_RAS_round(M, obs, audio, tac_frame):
    snap = M.snapshot.read_latest()                     # 控制域只读
    # --- 控制域（1kHz，硬实时，无 do-演算）---
    R_up, delta_id = snap.cf_bounds(a=snap.candidate)
    lam = counterfactual_risk_scale(snap.candidate, snap.b_t, snap.cmg,
                                    snap.cic, snap.u_tac_causal, M.risk_params)[0]
    k = M.ctrl.publish_certified(snap.candidate, lam, R_up, delta_id)
    # --- 因果审计子域（50Hz，异步）---
    if M.clock.due_causal():
        cic = M.cic.query_targets(M.cmg)
        cal = M.icm.report()
        css = M.css.check(M.audit_set, M.cmg)
        gate = causal_gate(M.cmg, cic, cal, css, M.caf, M.emb_gate)
        if not gate.valid: M.mode = gate.fallback; M.registry.freeze(gate.reason)
        M.snapshot.write_causal(cic, cal, css, gate, M.cmg.hash)
    # --- 感知/交互域 ---
    rel = M.caf.classify(M.target, M.modalities)
    ev  = M.caf.fuse(M.target, M.modalities, obs)
    if M.mode == 'FULL' and (ev.ess < TAU_ESS or cic.delta_id > TAU_ID):
        g = M.cvoi.choose(M.b_t, M.cmg, cic, M.budget, M.safe_set)
        if g:
            M.probe_log.record_randomized(g)            # 随机化探针，供 CCE/IV
            M.last_g = g
    return k, lam, J_CAUSAL(M)

## 3. 推导

**引理 33（共享混淆下的证据膨胀）** 设 y_1,y_2 由共同原因 C 与目标 X 生成，且 y_1 ⊥ y_2 | (X,C)。若融合使用观测似然比之积而不调整 C，则其对数证据相对真实因果证据的期望膨胀量为
Δ = I(y_1;y_2 | X) ≥ 0，
当 C 对两模态均有正影响时严格为正。系：**乘积专家在共享混淆下系统性过度自信；PID 的 redundant 分量正是 Δ 的可计算代理。**

**引理 34（后门调整下的因果证据一致性）** 若调整集 Z 满足后门准则、positivity 成立、机制稳定，则 Σ_z p(y|X,z)p(z) 一致估计 p(y|do(X))。因此 CAF 的 unique 项在互补/独立模态上等于 R72 的加权似然，且不重复计数。系：**CAF 严格泛化 R72，而非另起炉灶。**

**引理 35（碰撞/选择偏差的可检出性）** 设 S 为 y_i 与结果 r 的共同效应。条件在 S 上诱导的伪相关满足
I(y_i;r | X,S) ≥ I(y_i;r | X) + δ_collider，
δ_collider > 0 当且仅当 S 的入边强度非零。故用审计集上观测条件互信息与 CMG 期望之差（CSS）可检出选择偏差；检出率随样本量与 δ_collider 单调。系：**「只记录成功」是最常见的因果污染，必须显式检测。**

**引理 36（不可辨识 ⇒ 必须保守）** 设观测等价类为 [M]_obs。对任意 a，R_cf(a;M) 在 [M]_obs 上未必为常数。使用等价类上界 R_cf^max 构造 λ，可保证对**所有**与观测一致的 SCM 均满足风险界；使用点估计则存在某个 M 使风险界失效。系：**可辨识性间隙 Δ_id 不是「精度损失」，而是安全余量的直接来源。**

**引理 37（策略内生性偏差）** 设行为策略 a ∼ π_b(·|b)，b 为机器人信念且 b 同时影响 a 与 z'。则
p(z'|a) − p(z'|do(a)) = Σ_b [p(z'|a,b) − p(z'|a)] p(b|a)，
一般非零；当 b 不可观测时该偏差不可由观测数据无偏估计。随机化探针（ε-greedy）使 π_b 与 b 解耦，从而恢复 do 效应。系：**R72 的反作用模型若不做随机化/IPW/IV，只是在拟合策略的自证循环。**

**引理 38（观测校准不足）** 存在两个 SCM M_1、M_2，它们诱导相同的观测分布（故 ECE 相同），但 p(y|do(x)) 不同（故 CCE 不同，IGG 任意大）。构造：令 X→Y 的观测关联在 M_1 中由 X 因果产生、在 M_2 中由一个与 X 相关的隐藏混淆产生。系：**R72 的 ECE/IVG 通过不能推出因果有效；R73 必须引入 CCE/IGG。**

**引理 39（协方差修正的保守性）** 对 u_tac 的四分量，若真实协方差矩阵为 Σ_C，R72 的 Σ_i u_i² 在 Σ_C 非对角元为正时严格低估、为负时高估。取 λ_max(Σ_C) 作为上界可保证不低估；当 Σ_C 不可辨识时，λ_max 的上界由 Gershgorin 圆盘给出。系：**R72 的「正交四分量」是一个未被检验的因果假设。**

**定理 27（因果严格包含与风险单调）** 在 A111–A116（CMG 无未观测混淆或已调整、所有 query 可辨识、干预校准有效、positivity 成立、结构稳定）下：CAUSAL 在定义 383 的退化条件下逐指令等于 R72/R71/R68；且对任意有效执行，风险界 ≤ R72 的风险界。**安全单调不减，效率只在「图可信、可辨识、干预校准」时获益。**

**定理 28（J_CAUSAL 有效性 ⇒ 因果风险界）** 若一次执行通过 J_CAUSAL，则：(i) CMG 哈希匹配且结构稳定 ⇒ 所用机制在审计窗口内成立；(ii) 所有 veto query 可辨识/部分可辨识且使用上界 ⇒ 因果效应有界；(iii) CCE/IGG 在阈内 ⇒ 预测器可用于 do 决策；(iv) CSS 通过 ⇒ 审计集无碰撞污染；(v) J_EMB 有效 ⇒ 具身层风险界成立。综上，**对真实 SCM（在等价类内）物理风险 ≤ ε_causal**。**证明重量落在「CMG 正确」与「审计集无碰撞」上。**

**定理 29（CAF 的融合可靠性）** 在定义 369–370 下，CAF 的证据预算不超过联合分布中 unique + synergistic 信息；对互补模态等于 PoE；对共享混淆模态严格小于 PoE；对 XOR 型协同模态严格大于任何按模态加权融合。系：**模态关系类型化是信息论上必要的，不是工程偏好。**

**定理 30（安全探针的有限停止与安全不变）** 设探针集合 𝒟_safe 有界、单次可辨识性增益有正下界或为零、干预预算有限。则 C-VoI 在有限步停止；且由于所有探针受三层稳态与 λ_floor 约束，执行探针的风险不超过当前安全包络。若等价类内所有 SCM 的风险已低于阈值，则停止且无需进一步探针。**主动因果识别是可证明安全的，但只在「探针不动摇安全包络」时。**

## 6. 本轮最大风险

**一句话**：CAUSAL-GAUGE-RAS 把安全从「相信测量链在观测上自洽」进一步转移到「相信 **CMG 这张因果图本身正确**、相信 **审计集没有碰撞污染**、相信 **未观测混淆真的不存在或已被调整**」——**如果图结构在部署中漂移，或关键混淆根本不可观测，或审计集与部署共享同一个选择机制，那么系统会用一套「通过了 do-演算、拿着因果证书」的算法，把「共同原因造成的模态一致」当成「双倍证据」、把「策略自证的反作用」当成「人的真实意图变化」、把「不可辨识的点估计」当成「因果效应」，在真机上更自信地撞人、捏碎物体、透支信任；事后审计发现「每条边都标注了 causal、每个 query 都返回 identifiable、每个指标都在有效域内」，这就是**因果层面的「自信地错自己的因果模型」**。

次级风险与缓解：
1. **CMG 错/漂移** → **结构漂移检测器 + 图版本哈希 + 最小可证伪边集**：每条 causal 边配一个可在线检验的证伪实验；漂移即降级到 R72 + 最坏上界。
2. **未观测混淆** → **敏感性分析（E-value / Rosenbaum bounds）+ 部分辨识上界**：报告「需要多强的混淆才能推翻结论」，超过阈值即拒绝因果声明。
3. **审计集碰撞** → **SEAL-Causal 独立选择机制 + CSS 哨兵 + 双审计集交叉验证**：审计集与部署集的选择变量必须 d-分离。
4. **探针诱导新反作用** → **探针安全包络 + 三层稳态约束 + 探针预算**：探针也在 EREFLEX 预算内，不得为可辨识性牺牲安全。
5. **因果推理拖垮实时** → **离线 do-演算 + 在线查表 + 因果审计子域异步**：控制域只读 (R_cf^max, Δ_id, λ)，绝不执行图学习。
6. **PID/ESS 估计不可靠** → **小样本置信区间 + 保守下限**：ESS 取下界、redundant 权重取上限，宁少算证据不多算。
7. **复杂度爆炸** → **|V_CMG|≤32、|E|≤64、|𝒟|≤16、CIC 缓存≤128**，每个 veto 一条可复算证明，复杂度纳入审计。

## 2. 形式化定义（要点版）

**定义 366（CAUSAL-GAUGE-RAS 总览与六不变式）** 因果边优先、融合不重复计数、可辨识性显式、干预校准、反事实风险单调、严格逐指令退化。**新层只在「图可信、可辨识、干预校准、审计无碰撞」时启用。**

**定义 367（CMG 因果测量图）** V = 目标(s,z,c) ∪ 混淆(e,h,κ,π_b) ∪ 观测(y_1..y_m) ∪ 干预(a)；边分 causal/associational；结构方程 F 带噪声；未观测混淆以等价类 P_U 表示。**所有因果量定义在观测等价类上，而非单一图上。**

**定义 368（do-证据算子）** Λ_k^do(y;X) = p(y|do(X=x₁))/p(y|do(X=x₀))；后门调整 p(y|do(x))=Σ_z p(y|x,z)p(z)，前门用于隐藏混淆；只有 do-证据进主预算。

**定义 369（CAF 混淆感知融合）** 按 PID 分解分组：unique/synergistic 用主权重，redundant 用鲁棒权重（只影响方差），adversarial 直接非补偿否决；不可观测混淆给后验区间；ESS 必须校准且 ≤ m(1−ρ̄)。**证据不是投票，独立才可相加。**

**定义 370（模态因果分类）** 互补：y_i⊥y_j|X 各自 unique；冗余：共享原因使证据不增；协同：I 的协同分量>0，必须保留交互项；敌对：被投毒的共同原因使错误方向一致，单源不定案。**融合算子由结构决定，不由超参数决定。**

**定义 371（CSS 碰撞哨兵）** S 为 y_k 与结果的共同效应；条件在 S 上打开碰撞路径。CSS 为正即检测到选择偏差，审计集失效。**「只记录成功」是最常见的因果污染。**

**定义 372（CIC 可辨识性证书）** 每个 query 携带 method/status/bounds；unidentifiable 时禁止点估计，必须用 U 作风险上界，Δ_id 计入 λ_floor。**可辨识性不是预处理，是安全证书的一部分。**

**定义 373（ICM 干预校准）** ECE 为观测校准，CCE 为 do 校准，IGG = CCE−ECE。干预数据只来自随机探针/自然实验/显式干预集。**观测校准不能推出因果有效。**

**定义 374（因果接触不确定度）** u_tac² = Σu_i² + 2ΣCov_ij；Cov 由共同原因（u_ctrl、温度、磨损）解释；不可辨识时取最大特征值/Gershgorin 上界。**R72 的正交四分量是未被检验的因果假设。**

**定义 375（CFR 反事实风险缩放）** R_cf(a)=E[L|do(a)]；λ_cf 用等价类上界 R_cf^max，分母含 Δ_id 与 u_tac^causal。**图不确定必须让机器人更软。**

**定义 376（C-VoI 安全探针）** VoI^C = IG_causal + η_id·IG_id − c_intervene − γ·ConfoundingRisk；g∈𝒟_safe、三层稳态满足、预算未超。**「打破混淆的干预」优先于「确认已知的提问」。**

**定义 377（策略内生性去混淆）** p(z'|z,a) ≠ p(z'|do(a),z)；偏差来自信念 b 的混淆。用随机化探针、IPW、IV 恢复 do 效应。**R72 的反作用模型若不做随机化，只是在拟合策略自证。**

**定义 378（C-MIB）** 因果族（confounding bias、ESS、Δ_id、CIC、CSS、ACE CI）、干预族（CCE、IGG、探针覆盖、positivity、策略偏差）、融合族（PID 分解、关系类型、敌对检出、协同漏检）、反事实族（上界紧度、等价类体积、反事实后悔）。同遵循六元组与 DAG 分层。

**定义 379（C-IVG）** 图失效（版本/漂移/方向不可辨识）、可辨识失效（unidentifiable 且 Δ_id 超阈）、校准失效（CCE/IGG 超阈）、融合失效（CSS 超阈/敌对/ESS 过低）、策略失效（positivity 失败/探针覆盖不足）。任一失效 ⇒ 相关因果量降级；图整体失效 ⇒ 保守单模态 + R68。

**定义 380（J_CAUSAL）** Valid ⇔ J_EMB 有效 ∧ CMG hash 匹配 ∧ veto query 非 unidentifiable ∧ C-IVG 全过 ∧ CSS 全过 ∧ CCE/IGG 在阈内 ∧ SEAL-Causal 通过。

**定义 381（AIC-CAUSAL 威胁模型）** ℰ_CAUSAL = ℰ_EMB × ℰ_graph × ℰ_confound × ℰ_collider × ℰ_intervene。新增：图结构投毒、机制漂移、混淆注入/伪装、选择偏差投毒、探针响应伪造、预算耗尽攻击。

**定义 382（因果审计子域）** 与计量域同优先级（50–70），异步运行 CMG/CIC/ICM/PID；控制域只读快照，**绝不执行 do-演算或图学习**。**慢思考不得阻塞快反射。**

**定义 383（严格退化包含链）** 全有效⇒CAUSAL；部分不可辨识⇒最坏上界+CAF；CAF 失效⇒R72+最坏上界；CMG 失效⇒保守单模态+R72；再失效⇒R68。**安全单调不减。**

**定义 384（复杂度与模块上限）** |V_CMG|≤32、|E|≤64、|𝒟|≤16、PID 组≤6、CIC 缓存≤128；do-演算离线、在线查表；复杂度纳入审计。

**定义 385（SEAL-Causal）** 密封因果审计集：隐藏跨混淆/跨选择/跨干预场景，离线评估 CCE/IGG/CSS；审计集选择机制必须与部署集 d-分离。

**定义 386（严格泛化关系）** 无混淆、条件独立、全可辨识、策略随机化时：CAF≡R72、CIC≡identifiable、CCE=ECE、R_cf=E[R]、J_CAUSAL≡J_EMB。**R73 是 R72 在「混淆/选择偏差/策略内生性」下的严格泛化。**

# IP-295 CMG：因果测量图（离线构建，在线只读 hash）
@dataclass
class CausalEdge:
    src: str; dst: str
    kind: Literal['causal', 'associational']
    mechanism: Callable
    identifiable: bool

@dataclass
class CMG:
    nodes: Dict[str, NodeSpec]
    edges: Dict[Tuple[str, str], CausalEdge]
    interventions: Set[str]
    hash: bytes
    def is_valid(self) -> bool:
        return self.hash == recompute_hash(self) and validate_acyclic(self)

# IP-296 CAF：混淆感知 + PID 类型化融合
class CausalFusion:
    def __init__(self, cmg, pid_estimator, backdoor_solver):
        self.cmg, self.pid, self.bd = cmg, pid_estimator, backdoor_solver
    def fuse(self, X, modalities, obs):
        rel = self.pid.classify(X, modalities, self.cmg)   # unique/redundant/synergy/adversarial
        terms, ess = [], []
        for k, y in modalities.items():
            if rel[k] == 'adversarial':
                return Veto(reason='adversarial_modality')   # 非补偿性否决
            if rel[k] == 'redundant':
                adj = self.bd.adjust(y, X, self.cmg, obs)    # 去混淆后的独立分量
                terms.append(('rob', adj)); ess.append(0.25) # 只作鲁棒投票
            elif rel[k] == 'synergistic':
                terms.append(('syn', self.bd.causal_lr(y, X, obs))); ess.append(1.0)
            else:
                terms.append(('main', self.bd.causal_lr(y, X, obs))); ess.append(1.0)
        ess_eff = (sum(ess) ** 2) / sum(e * e for e in ess)
        return CausalPosterior(terms=terms, ess=ess_eff,
                               interval=self.bd.partial_bounds(X, obs))

# IP-297 CIC：可辨识性证书
class IdentifiabilityChecker:
    def __init__(self, cmg): self.cmg = cmg; self.cache = {}
    def query(self, X, Y):
        key = (X, Y)
        if key in self.cache: return self.cache[key]
        for method in ('backdoor', 'frontdoor', 'iv'):
            s = getattr(self, f'_{method}')(X, Y)
            if s: return self._cert(X, Y, method, 'identifiable', s)
        if (bounds := self._partial(X, Y)) is not None:
            return self._cert(X, Y, 'partial', 'partially_identifiable', bounds)
        return self._cert(X, Y, 'none', 'unidentifiable', (0.0, 1.0))

# IP-298 ICM：干预校准监控（只吃随机探针/自然实验）
class InterventionalCalibration:
    def __init__(self, predictors, probe_log):
        self.pred, self.log = predictors, probe_log
    def report(self):
        out = {}
        for name, q in self.pred.items():
            ece = obs_ece(q, self.log.observational)
            cce = do_ece(q, self.log.interventional)
            out[name] = Calib(ece=ece, cce=cce, igg=cce - ece)
        return out

# IP-299 CFR：反事实风险缩放（控制域查表，<0.08ms）
def counterfactual_risk_scale(a, b_t, cmg, cic, u_tac_causal, params):
    R_cf = expected_loss_do(a, b_t, cmg)                 # E[L | do(a)]
    R_up = cic.worst_case_over_equivalence_class(R_cf)  # 等价类上界
    delta_id = cic.identifiability_gap()
    denom = R_up + delta_id + u_tac_causal
    lam = max(params.lam_base * (1 + denom / params.lam_scale),
              params.lam_floor * (1 + denom))
    return lam, R_up, delta_id

# IP-300 C-VoI：安全因果探针规划
def causal_voi(b_t, cmg, cic, budget, safe_set):
    best = None
    for g in sample_probes(cmg, safe_set, top_k=4):
        if not budget.allow(g): continue
        ig_c  = expected_causal_ig(b_t, g, cmg)
        ig_id = expected_identifiability_gain(cic, g)    # 等价类体积收缩
        cost  = intervention_cost(g) + expected_reflex_cost(g)
        conf  = expected_new_confounding(g, cmg)
        score = ig_c + ETA_ID * ig_id - cost - GAMMA * conf
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-301 CSS：碰撞/选择偏差哨兵（离线审计）
def collider_sentinel(audit_set, cmg):
    for (yi, yj, X, S) in audit_set.triples():
        mi_obs = conditional_mi(audit_set, yi, yj, given=(X, S))
        mi_exp = expected_conditional_mi(cmg, yi, yj, given=(X, S))
        if mi_obs - mi_exp > TAU_CSS:
            return SentinelHit(pair=(yi, yj), css=mi_obs - mi_exp)
    return None

# IP-302 C-IVG + J_CAUSAL：因果门控与证书
def causal_gate(cmg, cic, calib, css, fusion, emb_gate):
    if not cmg.is_valid():                    return Fallback('R68+single_modality')
    if any(c.status == 'unidentifiable' and c.delta_id > TAU_ID for c in cic.veto):
        return Fallback('R72+conservative_bounds')
    if calib.igg > TAU_IGG:                   return Fallback('R72')
    if css is not None:                       return Fallback('R72')
    if not emb_gate.valid:                    return Fallback('R71')
    return Full(J_CAUSAL(cmg, cic, calib, css, fusion))

# IP-303 CAUSAL 主闭环（嵌入 R72 三域；因果审计子域异步）
def CAUSAL_GAUGE_RAS_round(M, obs, audio, tac_frame):
    snap = M.snapshot.read_latest()                     # 控制域只读
    # --- 控制域（1kHz，硬实时，无 do-演算）---
    R_up, delta_id = snap.cf_bounds(a=snap.candidate)
    lam = counterfactual_risk_scale(snap.candidate, snap.b_t, snap.cmg,
                                    snap.cic, snap.u_tac_causal, M.risk_params)[0]
    k = M.ctrl.publish_certified(snap.candidate, lam, R_up, delta_id)
    # --- 因果审计子域（50Hz，异步）---
    if M.clock.due_causal():
        cic = M.cic.query_targets(M.cmg)
        cal = M.icm.report()
        css = M.css.check(M.audit_set, M.cmg)
        gate = causal_gate(M.cmg, cic, cal, css, M.caf, M.emb_gate)
        if not gate.valid: M.mode = gate.fallback; M.registry.freeze(gate.reason)
        M.snapshot.write_causal(cic, cal, css, gate, M.cmg.hash)
    # --- 感知/交互域 ---
    rel = M.caf.classify(M.target, M.modalities)
    ev  = M.caf.fuse(M.target, M.modalities, obs)
    if M.mode == 'FULL' and (ev.ess < TAU_ESS or cic.delta_id > TAU_ID):
        g = M.cvoi.choose(M.b_t, M.cmg, cic, M.budget, M.safe_set)
        if g:
            M.probe_log.record_randomized(g)            # 随机化探针，供 CCE/IV
            M.last_g = g
    return k, lam, J_CAUSAL(M)
```

## 4. 推导

**引理 33（共享混淆下的证据膨胀）** 设 y_1,y_2 由共同原因 C 与目标 X 生成，y_1⊥y_2|(X,C)。不调整 C 的观测似然比之积，其相对因果证据的期望膨胀 Δ = I(y_1;y_2|X) ≥ 0。系：**乘积专家在共享混淆下系统性过度自信；PID 的 redundant 分量是 Δ 的可计算代理。**

**引理 34（后门调整下因果证据一致性）** Z 满足后门准则、positivity 成立、机制稳定时，Σ_z p(y|X,z)p(z) 一致估计 p(y|do(X))；CAF 的 unique 项在互补模态上等于 R72 加权似然。系：**CAF 严格泛化 R72。**

**引理 35（碰撞/选择偏差可检出）** S 为 y_i 与结果 r 的共同效应，条件在 S 上诱导伪相关 I(y_i;r|X,S) ≥ I(y_i;r|X)+δ_collider；δ>0 当且仅当 S 入边强度非零。CSS 用观测与 CMG 期望之差检出。系：**「只记录成功」必须显式检测。**

**引理 36（不可辨识 ⇒ 必须保守）** 观测等价类 [M]_obs 上 R_cf(a;M) 未必为常数。用等价类上界 R_cf^max 构造 λ 可对所有与观测一致的 SCM 保证风险界；点估计则存在某个 M 失效。系：**Δ_id 不是精度损失，是安全余量来源。**

**引理 37（策略内生性偏差）** a∼π_b(·|b)，b 同时影响 a 与 z'，则 p(z'|a)−p(z'|do(a)) = Σ_b[p(z'|a,b)−p(z'|a)]p(b|a) 一般非零；随机化探针/IPW/IV 可恢复 do 效应。系：**不做随机化的反作用拟合只是策略自证。**

**引理 38（观测校准不足）** 存在 M_1、M_2 诱导相同观测分布（ECE 相同）但 p(y|do(x)) 不同（IGG 任意大）。构造：M_1 中 X→Y 为因果，M_2 中由隐藏混淆产生。系：**R72 的 ECE/IVG 通过不能推出因果有效。**

**引理 39（协方差修正保守性）** 真实协方差 Σ_C 非对角元为正时 R72 的 Σu_i² 严格低估，为负时高估；λ_max(Σ_C) 保证不低估，不可辨识时用 Gershgorin 上界。系：**正交四分量是未检验的因果假设。**

**定理 27（因果严格包含与风险单调）** 在 A111–A116（无未观测混淆或已调整、全 query 可辨识、干预校准有效、positivity、结构稳定）下：CAUSAL 按定义 383 逐指令等于 R72/R71/R68；有效执行的风险界 ≤ R72。**安全单调不减。**

**定理 28（J_CAUSAL ⇒ 因果风险界）** 通过 J_CAUSAL ⇒ (i) CMG 匹配且结构稳定；(ii) veto query 可辨识/部分可辨识且用上界；(iii) CCE/IGG 在阈内；(iv) CSS 通过；(v) J_EMB 有效。综上，对等价类内真实 SCM，物理风险 ≤ ε_causal。**证明重量落在「CMG 正确」与「审计集无碰撞」上。**

**定理 29（CAF 融合可靠性）** 证据预算不超过 unique+synergistic 信息；互补模态等于 PoE；共享混淆模态严格小于 PoE；XOR 协同模态严格大于任何按模态加权融合。系：**模态关系类型化是信息论必要的。**

**定理 30（安全探针有限停止与安全不变）** 探针集有界、单次可辨识性增益非负、预算有限 ⇒ C-VoI 有限步停止；所有探针受三层稳态与 λ_floor 约束 ⇒ 风险不超安全包络；等价类内所有 SCM 风险低于阈值时停止。**主动因果识别可证安全，但只在探针不动摇安全包络时。**

## 7. 本轮最大风险

**一句话**：CAUSAL-GAUGE-RAS 把安全从「相信测量链在观测上自洽」进一步转移到「相信 **CMG 这张因果图本身正确**、相信 **审计集没有碰撞污染**、相信 **未观测混淆真的不存在或已被调整**」——**如果图结构在部署中漂移，或关键混淆根本不可观测，或审计集与部署共享同一个选择机制，那么系统会用一套「通过了 do-演算、拿着因果证书」的算法，把「共同原因造成的模态一致」当成「双倍证据」、把「策略自证的反作用」当成「人的真实意图变化」、把「不可辨识的点估计」当成「因果效应」，在真机上更自信地撞人、捏碎物体、透支信任；事后审计发现「每条边都标注了 causal、每个 query 都返回 identifiable、每个指标都在有效域内」，这就是**因果层面的「自信地错自己的因果模型」**。

次级风险与缓解：
1. **CMG 错/漂移** → 结构漂移检测器 + 图版本哈希 + 最小可证伪边集（每条 causal 边配在线证伪实验），漂移即降级到 R72 + 最坏上界。
2. **未观测混淆** → 敏感性分析（E-value / Rosenbaum bounds）+ 部分辨识上界，报告「需多强混淆才能推翻结论」，超阈拒绝因果声明。
3. **审计集碰撞** → SEAL-Causal 独立选择机制 + CSS 哨兵 + 双审计集交叉验证；审计集与部署集选择变量必须 d-分离。
4. **探针诱导新反作用** → 探针纳入 EREFLEX 预算与三层稳态，不得为可辨识性牺牲安全。
5. **因果推理拖垮实时** → 离线 do-演算 + 在线查表 + 因果审计子域异步；控制域只读 (R_cf^max, Δ_id, λ)。
6. **PID/ESS 估计不可靠** → 小样本置信区间 + 保守下限：ESS 取下界、redundant 权重取上限，宁少算证据不多算。
7. **复杂度爆炸** → |V_CMG|≤32、|E|≤64、|𝒟|≤16、CIC 缓存≤128；每个 veto 一条可复算证明，复杂度纳入审计。
