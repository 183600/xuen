# 第 44 轮（新循环第 4 轮） · Grasp-Cert × Afford-Cert：把「接触丰富抓取」与「多模态接地」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形条件覆盖 + 多用户契约空集」，但它把视觉、几何、人格、并发都纳入证书后，仍压着两个关于**物理末端**与**语义先验**的未言明假设：**(H1) 抓取 = 末端位姿到达且不碰撞**——证书只证明「不撞」，不证明「抓得住、抬升后不打滑、且不把物体捏碎」；**(H2) 多模态大模型只是语义提议器**——它输出的可抓取区域、接近方向、材质与力度先验从不进入证书链，模型幻觉可直接变成接触力错误。本轮灵感词「机械臂抓取」「多模态大模型」精确命中这两个假设：**机械臂抓取**迫使我们把证书从「位置安全」推进到「接触闭包的物理 soundness」，并直面稳定性与温和性的双目标、非单调；**多模态大模型**迫使我们把可抓取性先验从「点猜」升级为「分层共形集合 + 可认证扩张」。二者耦合处是本轮真正的新问题：**接触不确定 × 先验误差**——单看每个都保守，叠起来却可能同时产生「证书说稳定、实机掉落/压损」的静默失效。

## 0. 直觉与动机

**灵感 1（机械臂抓取 → 「抓得住」和「不捏碎」是两张证书，不是一个分数）**：学习式抓取质量分数把「成功概率」和「安全」揉成一个标量，这是最危险的偷换。真实抓取是接触力学问题：力闭合决定「抓得住」，接触压力/形变决定「不捏碎」，而这两者对着夹持力是**反向单调**的——夹得更紧更不容易掉，却更容易压损。于是把抓取证书拆成两张独立谓词：**稳定证书** C_stab（在外部旋量扰动集内存在摩擦锥内的力分配，力闭合裕度 η_stab≥η_min）与**温和证书** C_gentle（接触压力与形变不超过物体损伤阈值）。可执行抓取集 A_g = C_stab ∧ C_gentle，它是两个约束的交，通常**非凸**，且不能由任何标量分数替代。一句话：**分数只能在 A_g 内部排序，绝不能拿来判定 A_g 的成员资格。**

**灵感 2（多模态大模型 → 先验只能是集合，且要按对象类别分层共形）**：MLLM 能给出「抓杯子把手、侧面接近、轻握」这类丰富的可抓取性先验，但它会幻觉——把易碎件当塑料、把可抓区域指到不可达侧。正确用法不是让 MLLM 输出一个点再取 argmax，而是输出**可抓取性集合** Â^α：按（对象类别 × 场景）Mondrian 分层共形校准，使真实 affordance 以 ≥1−α 概率落入集合。抓取必须对 Â^α 中每个 a 都**存在**一组满足双证书的接触方案，这叫 affordance-robust。与 v20 的语义扩张同构：**不给模型发证书，给「对模型误差的鲁棒性」发证书；扩张必须持证。**

**灵感 3（耦合 → 接触模式自动机 + 双目标协商 + 双臂合成）**：抓取不是瞬时动作，而是 APPROACH→CONTACT→CLOSE→LIFT→TRANSPORT→PLACE→RELEASE 的接触模式迁移。每一模式有各自的不变式；最脆弱的是 LIFT 的瞬间打滑与 PLACE 的释放。模式切换必须只做**单调降级**（重抓、放回、停机），绝不能为了完成任务而放松 θ。双臂任务里，两只手共享物体旋量：两个各自稳定的单臂抓取，合成后可能因内力冲突/位姿估计不一致而互相抵消——**单臂证书不能推出双臂证书**，必须显式做合成检查。一句话：**接触模式迁移要像并发模式切换一样被证书门控；双臂不是两个单臂相加。**

**耦合升级**：GCE（抓取证书引擎）把接触几何编译成稳定/温和双证书与接触租约；MAC（多模态可抓取性认证器）把 MLLM 先验变成分层共形集合，并以三重闸门控制「可抓集扩张」；CTV（接触-触觉验证器）在仿真里注入滑移、形变、触觉噪声、摩擦漂移与 MLLM 幻觉，检验证书与实机的接触鸿沟。四层架构由 v8 的「仿真-检索-边缘飞轮 + 人格 + 并发」升级为 v9 的「+ 接触抓取证书层 + 多模态可抓取性证书层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（接触抓取证书与双目标可容许集）**：接触配置 κ={(p_i, n_i, A_i)}_{i=1..n} 给出接触点、法向与接触面积；摩擦锥 K_i={f_i : f_{n,i}≥0, ‖f_{t,i}‖≤μ_i f_{n,i}}；抓取映射 G=[G_1…G_n]∈R^{6×3n} 把接触力映射为物体旋量。外部扰动集 W={w : ‖w‖≤w_max}（重力+惯性+任务扰动界）。**稳定裕度** η_stab = sup{η≥0 : ∀w∈(1+η)W, ∃f∈∏K_i, Gf=−w}；**稳定证书** C_stab sound 当 η_stab≥η_min。**温和性** g_i(f)=max(f_{n,i}/(A_i p_max), δ_i(f)/δ_max)，**温和证书** C_gentle sound 当存在同时满足稳定平衡的 f 使 max_i g_i(f)≤1。**可执行抓取集** A_g={g : ∃f∈∏K_i, Gf=−w ∀w∈W, max_i g_i≤1}。**命题（不可标量化）**：不存在一个标量质量分 q(g) 同时等价于 C_stab∧C_gentle，因为夹持力对稳定与温和反向单调；任何把二者折成单一分数并用于准入的做法，必在某个物体上要么放行压损、要么误拒可抓——q 只能用于 A_g 内部的偏好排序。

**定义 45（抓取鲁棒域与不确定性收缩）**：设不确定性 θ=(ε_pose, μ, m)∈Θ_g（位姿误差、摩擦系数、质量），η_stab(θ) 对 θ 满足 Lipschitz 常数 L_g。**鲁棒抓取证书**要求 ∀θ∈Θ_g 双证书成立。**收缩界**：若 Θ_g 含于以 θ̂ 为心、半径 r 的球，则 min_{θ∈Θ_g} η_stab(θ) ≥ η_stab(θ̂) − L_g·r。**推论**：真实不确定性集必须被 Θ_g 覆盖到置信 1−β；覆盖不足时只能报告「证书在 Θ_g 上成立」，禁止外推为「在任意物体上都成立」。这使抓取证书成为**域条件化断言**，而不是永久真值。

**定义 46（多模态可抓取性先验与共形集合）**：MLLM 输出 affordance a=(R, v, f*, c, d)：可抓区域、接近方向、标称力度、材质类别、损伤先验。按分层 s=(对象类别, 场景) 维护非一致性分数，取分位数 q_{1−α}，定义 **Â^α(x)={a : score(a,x)≤q_{1−α}^s}**；可交换性下 P(a_true∈Â^α)≥1−α。**affordance-robust 抓取**要求 ∀a∈Â^α，∃g∈A_g 与 a 一致（接触区相交、接近角‖v(g)−v(a)‖≤δ_v、力度不超过 f*(a) 的温和上限）。**认证扩张闸门**：仅当条件覆盖校准通过、影子证书零违例、A/B 无回归时，才允许用 Â^α 扩张可抓集，并从信任预算 τ_a 扣费；否则 τ_a→0，退回「仅几何保守抓取」Â_0（顶抓/对跖/低力）。

**定义 47（接触租约与滑移新鲜度）**：抓取证书携带接触租约 ℓ_g=(m_slip, τ, λ_slip, κ)，m_slip=min_i(μ_i f_{n,i}−‖f_{t,i}‖) 为归一化滑移裕度，λ_slip 由摩擦漂移率 v_μ 与外部旋量变化率 v_w 经 Lipschitz 常数 L_slip 界出。**新鲜度判据**：m_slip−λ_slip·(t−τ)≥θ_slip 且触觉采样延迟 T_tac 计入租约年龄时才可用于接触守卫。**命题**：若真实滑移裕度漂移满足 |m_slip(t)−m_slip(τ)|≤L_slip(v_μ+v_w)(t−τ)，取 λ_slip=L_slip(v_μ+v_w) 时过期判据 sound（绝不误用陈旧滑移裕度）。这把 v20 定义 41 的「度量/语义租约」扩展到**接触租约**，与并发运行时统一调度。

**定义 48（抓取接触模式自动机与单调降级）**：模式集 M={APPROACH, CONTACT, CLOSE, LIFT, TRANSPORT, PLACE, RELEASE, REGRASP, ABORT}，每模式 m 带不变式 I_m（如 LIFT：C_stab∧C_gentle∧m_slip≥θ_slip；TRANSPORT：位姿误差≤e_max 且滑移租约有效）。**证书迁移** m→_cert m′ 仅当目标不变式 I_{m′} 可证且守卫成立；**降级迁移**到 {REGRASP, PLACE, ABORT} 恒允许。**定理（模式迁移安全）**：若入口满足 I_{m0}，所有证书迁移保持目标不变式，且降级迁移只缩小可行动作集、不放松任何阈值，则任意可达模式都满足其不变式；特别地，不存在一条路径在 C_stab 无效时进入 LIFT。**滑移时间界**：设检测时延 T_det、从当前滑移裕度到掉落的保守时间下界 T_drop，要求 T_det<T_drop；否则滑移证书不 sound，必须提高伺服频率或降低负载。

**定义 49（双臂抓取的证书合成）**：单臂抓取 g_L,g_R，合成抓取映射 G=[G_L G_R]，力 f=(f_L,f_R)。**合成证书** C_bi=C_stab^L⊗C_stab^R 仅当共享约束同时成立：(i) 两臂对共享物体的位姿估计在容差内一致；(ii) 合内力可抵消、合力满足 Gf=−w；(iii) 两臂工作空间无干涉；(iv) 各自接触力满足温和证书。**rely-guarantee 语义**：每臂 guarantee「维持自身接触且不超力预算」，rely「另一臂维持接触」；一旦对方接触丢失本臂只能进入 HOLD/ABORT。**命题（不可加性）**：两个各自稳定的单臂抓取，其合成未必稳定——内力冲突可使合成摩擦锥有效交集为空；因此 C_bi 必须显式检查，不能由 C_stab^L∧C_stab^R 推出。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 GRASP-CERT-ENGINE（抓取证书引擎 GCE）
1. **接触几何编译**：由抓取位姿、物体网格/点云与摩擦估计构造接触点、法向、接触面积与摩擦锥，编译 G 与 K_i。
2. **双证书求解**：计算鲁棒力闭合裕度 η_stab 与最小挤压内力 f_int；同时校验稳定与温和，两者缺一即拒绝签发。
3. **鲁棒域标注**：估计位姿/摩擦/质量不确定集 Θ_g，按定义 45 做 Lipschitz 收缩，证书显式声明有效域 D_g。
4. **接触租约与模式守卫**：签发 ℓ_g，生成各模式不变式与降级阶梯（REGRASP→PLACE→ABORT）；滑移检测触发单调降级。

### 2.2 IP-61 MULTIMODAL-AFFORDANCE-CERTIFIER（多模态可抓取性认证器 MAC）
1. **分层共形集合**：按对象类别 × 场景维护非一致性分数，输出 Â^α，绝不 argmax 取点。
2. **跨模态一致性**：用深度/点云/触觉验证 affordance 的几何可达性与材质合理性；不一致即标记幻觉、禁止进入安全关键规划。
3. **affordance-robust 选择**：对 Â^α 逐元素生成候选抓取并经 GCE 双证书过滤，输出稳定-温和 Pareto 前沿，空集则协商/重抓。
4. **认证扩张与信任预算**：条件覆盖 + 影子证书 + A/B 三重闸门通过才扩张可抓集；覆盖失效即 τ_a→0 退回几何保守抓取。

### 2.3 IP-62 CONTACT-TACTILE-VALIDATOR（接触-触觉验证器 CTV）
1. **接触富仿真**：在 Isaac Sim 注入滑移、形变、接触噪声、摩擦漂移、质量/质心偏差，度量证书声称稳定与实机结果的一致率。
2. **触觉噪声与延迟**：模拟触觉采样延迟/漂移，验证定义 47 滑移租约与 T_det<T_drop 判据。
3. **MLLM 幻觉对抗**：注入错误材质、错误可抓区、错误接近方向，测 MAC 的幻觉检出率与扩张后违例。
4. **双臂合成压力测试**：非对称负载、共享物体位姿冲突、臂间干涉，验证 C_bi 合成与 rely-guarantee 失效处理。

### IP-60 GCE：双证书、鲁棒域与接触租约
```
def compile_grasp_certificate(g, obj, W, theta):
    contacts = build_contacts(g, obj)                 # 点/法向/接触面积
    K = friction_cones(contacts, mu_hat, mu_radius)   # 含摩擦不确定半径
    G = grasp_map(contacts)
    eta = robust_force_closure(G, K, W, mu_radius)    # 定义 44 稳定裕度
    if eta < theta.eta_min:
        return None                                   # 稳定不过 => 绝不执行
    f_int = solve_internal_force(K, G, W, eta)        # 最小挤压内力
    if contact_damage(f_int, obj) > 1.0:
        return None                                   # 温和不过 => 绝不执行
    D = robust_domain(eta, obj.uncertainty, L_g)      # 定义 45 有效域
    lease = contact_lease(f_int, contacts, mu_hat, kappa=SAFETY)
    return GraspCert(G, K, f_int, eta, D, lease, mode_guards(g, f_int))

def robust_force_closure(G, K, W, mu_radius):
    eta = 0.0
    while wrench_feasible(G, K, scale(W, 1 + eta + step), mu_radius):
        eta += step                                  # 保守步进，取可行下界
    return eta

def contact_lease(f, contacts, mu_hat, kappa):
    m = min(mu_i * f_n_i - norm(f_t_i) for i in contacts)   # 滑移裕度
    lam = L_slip * (v_mu_bound + v_w_bound)                 # 定义 47
    return Lease(m=m, tau=monotonic_now(), lam=lam, kappa=kappa)
```
