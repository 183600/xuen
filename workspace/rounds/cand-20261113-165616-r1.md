# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「评测指标」×「谐波减速器」）

> 第 65 轮把"几何可证伪"升级为"故障可归因"，其自述的最大风险是：归因依赖"故障属于有限假设集 + 视觉与几何失效相互独立"，共因故障会让系统"错误归因后更自信地继续执行"。本轮不再往 ℋ 里塞第六类"看起来像的故障"，而是去审计两个**被默认可信、却从未被审计过的测量通道**：
>
> - **动作通道**：CSC 认证的是**指令轨迹** A[:k*]，默认"执行 = 指令"。但谐波减速器把指令变成运动的过程是**非可逆、历史相关**的：有迟滞、lost-motion 死区、随角度周期变化的传动误差、非线性扭转刚度，以及柔轮里**储存的弹性能在停止之后才释放**。
> - **评测通道**：每一轮都报"成功率 +25%、违规 =0"，默认"分数 = 能力"。但指标是**稀疏、延迟、可被策略博弈**的测量：Goodhart、基准污染、选择偏差、分布漂移下 conformal 失效，使"0 违规"既可能是真安全，也可能只是没测到。
>
> 本轮核心命题：
>
> **把「故障可归因」升级为「测量可审计」：动作的落地不是指令，分数的涨落不是能力；用同一个迟滞算子把两者统一为"非可逆、历史相关、必须双向激励才能辨识"的测量通道，让安全证书与指标证书互相证伪、双向归因。**

## 0. 直觉与动机

**灵感 1（谐波减速器 → 执行器本身就是一个被漏掉的故障假设 H_act）**
直觉：谐波减速器用柔轮弹性变形传动，优点是零背隙、大减速比、高扭矩密度；代价是**柔**。而它的误差不是随机噪声，是**结构化、确定性、可辨识**的：
- **迟滞 / lost motion**：同一指令角，正转与反转的输出角不同；扭矩-转角构成一个**迟滞环**，环面积 = 摩擦与弹性能耗。
- **可控死区**：小指令落在 lost-motion 带内，输出**几乎不动**。安全回路想"微调后退"，减速器把它吃掉——这恰是最需要响应的时刻。
- **扭转储能与释放（windup）**：柔轮在负载下扭转蓄能，**指令停止后**弹性能继续把关节往前推。"停在第 k* 步"不等于"停在安全点"。
- **周期传动误差**：波发生器是椭圆，输出每转出现以 2 阶为主的周期性运动误差，并随磨损/温度漂移。
- **非线性刚度**：低载区软、高载区硬——机器人**自己身上就有一个"软接触模型"**，而第 65 轮的 H_model 只建模了外部接触。
结论：VISTA 的 H_geo/H_force/H_model/H_vis/H_policy 中，**没有一个能解释"指令对了、动作没到位"**。这正是第 65 轮风险节点名要补的"第三个物理独立通道（本体感觉）"。而它比视觉/几何更可爱：**确定、周期、可标定**，用电机端/输出端双编码器 + 电流 + 关节力矩即可在线辨识。

**灵感 2（评测指标 → 指标也是一个带迟滞的测量仪器）**
直觉：把"能力 → 分数"也看成一个仪器。它和减速器惊人同构：
- **迟滞**：同样的能力，分数取决于历史（基准是否见过、任务顺序、是否 cherry-pick）——**Goodhart 就是评测的迟滞环**。
- **死区**：能力提升低于噪声底就看不见；"0 违规 / N 次"只是**上界约 3/N**（rule of three），不是 0。
- **储能释放**：训练期"蓄"的过拟合，会在**评测结束之后**的分布漂移里释放——指标 windup。
- **周期误差**：基准难度按周期轮换，分数随之起伏。
所以指标**不是真值，是第三个可错传感器**。第 65 轮用 conformal 给视觉残差上了分布无关的界，却对自己论文里的实验指标用了点估计 + 单次评测——这是方法论上的双标。

**灵感 3（两灵感合流：同一个数学对象——Preisach 迟滞算子）**
直觉：减速器的 lost motion 与评测的 Goodhart 都是**率无关、路径相关、非可逆**的映射。物理学早给了标准模型：**Preisach 算子**——输出是对一族"play 算子"按密度 μ(α,β) 的二重积分。识别它的标准实验是 **FORC（一阶反转曲线）**：把输入升到某点再反转，描出一族小环。于是：
- 对减速器：在**自由空间**做小幅往返（不接触物体！）扫 FORC，辨识 μ_act 与传动误差谐波；
- 对指标：做**能力/难度的双向扫描**（易→难→易、train/eval 互换）扫 FORC，辨识 μ_met 与"博弈指数"（环面积）。
**"双向激励"是共同钥匙**：单向数据永远分不清迟滞与漂移，正如第 65 轮没有零力窗就分不清偏置与几何。

**灵感 4（合流 → METAGEAR：Metric–Execution Twin-hysteresis Audited Gearing，双迟滞可审计测量闭环）**
闭环：本体感觉辨识传动（TAM）→ 可达管 RTT（证书在**落地集**上验证，不在指令上）→ 失动探针 LMP（自由空间 FORC，AFA 增 `hysteresis_sweep`）→ 迟滞感知前缀 CSC-H（扣死区 + 储能释放）→ FIR 增 H_act → 指标证书 MC（e-value 置信序列，任意时刻有效）→ 指标迟滞审计 MHA（FORC + 博弈指数 + 指标 windup）→ 双向归因 MA（系统坏了还是指标坏了？）→ 对抗指标认证 AIC-M（永远拒绝/永远 ambiguous 的博弈策略）→ J_metagear。
一句话：**第 65 轮问"哪一层坏了"；本轮问"我们用来判断坏没坏的尺子，本身准不准、会不会被历史和后门带偏"。**

**灵感 5（VISTA/GRIP 组件的原位升级）**
- **CSC → CSC-H**：认证前缀必须扣除可控死区 d_dead 与储能释放 d_windup；要求 k*·v·Δt + d_eff ≤ m。
- **FIR → FIR-A**：新增 H_act；其签名是**速度反号奇对称**（迟滞/摩擦）与卸载回滞，与 H_force 的对称 DC 偏置**正交可分**。
- **APP/AFA → AFA-F**：增 `hysteresis_sweep`（自由空间 FORC）与 `release_test`（卸载看回弹）。
- **RSC-V → RSC-T**：新增 r_act（传动不确定半径），与 r_geo/r_force/r_model 并列。
- **AIC-V → AIC-M**：干扰集增"指标博弈策略"（永远拒绝、永远 ambiguous、只挑简单样本）、基准污染、选择偏差；并加**负对照/金丝雀系统**检验指标敏感度。
- **J_vista → J_metagear**：证书增 transmission_ver、reachable_tube_hash、metric_cert、gaming_index、meta_attribution。
- **评测协议 → FORC 评测协议**：双向难度扫描 + 预注册因果 estimand + 任意时刻有效置信序列。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（METAGEAR 闭环）**：METAGEAR = (VISTA, TAM, RTT, LMP, CSC-H, FIR-A, MC, MHA, MA, AIC-M, J_metagear)。定位：VISTA 的"测量可审计"升级。不变式：**传动辨识、指标证书、双向归因、FORC 审计只在语义流/离线；实时流只做落地状态投影、死区/释放监视与安全前缀派发，零学习写操作。**
- **定义 234（谐波传动模型 TAM）**：q_real = (1/N)q_cmd + e_tr(θ) + δ_lm(τ, sign θ̇, hist) + C(τ)。e_tr(θ)=Σ_k a_k sin(kθ+φ_k) 为周期传动误差（主谐波 k=2）；δ_lm 为率无关 lost motion（Preisach）；C(τ) 为扭转柔度，非线性刚度 K(τ) 在低载区小、高载区大。参数集 Θ_T=(N,{a_k,φ_k},μ_lm,K,温度/磨损漂移)。
- **定义 235（Preisach 迟滞算子，共享）**：H_μ[u](t)=∬_{α≥β} μ(α,β) γ_{αβ}[u](t)dαdβ，γ_{αβ} 为阈值 play 算子。环面积 A(μ)=∬μ(α,β)(α−β)dαdβ（能耗/博弈耗散）。**可表示性判据**（Mayergoyz）：满足同余性（同一极值间的小环合同）与擦除性（历史被更大极值擦除）⇔ 可被 Preisach 表示。该判据本身是**可证伪检验**：不满足即"模型类失效"，交给 MA 归因。
- **定义 236（传动可达管 RTT）**：给定校准类 𝒯（参数不确定集 Θ_T⊕误差 ε_T）与动作前缀 A[:k]，落地状态集 R_T(A[:k])={q_real(s): T∈𝒯, s≤k}。安全裕度必须在 R_T 上取最坏，而非在指令轨迹上。RTT 是 CSC-H 的验证域。
- **定义 237（可控死区与储能释放视界）**：d_dead=max{q: |T(q)−T(0)|<ε}（lost-motion 带内指令被吞掉的最大位移）；t_rel 为指令停止后输出仍因柔轮储能继续运动的时间，d_windup=∫_{t_k}^{t_k+t_rel} v_release dt。有效停止距离 d_eff=d_cmd+d_dead+d_windup。**证书若忽略 d_dead/d_windup 即不健全**。
- **定义 238（执行故障假设 H_act 与本体签名）**：ℋ 扩为 {H0,H_geo,H_force,H_model,H_vis,H_policy,**H_act**}。本体签名 ρ_act=[双编码器差, 电流-力矩残差, 速度反号奇分量, 卸载回滞面积, 传动误差谐波残差, 温漂]ᵀ。关键分离性：H_act 对速度反号**奇对称**、在自由空间即可激励；H_force 是**偶对称 DC 偏置**；H_model 只在接触/加载段出现。
- **定义 239（失动探针 LMP / FORC 激励）**：在自由空间（零接触）执行小幅往返 a_sweep：升到 u_r 再反转、多点反转，扫出 FORC 族，拟合 μ_act 与 {a_k,φ_k}；再叠加 release_test（快速卸载看回弹）。探针安全约束沿用 AFA：f_n≤f_safe、形变≤ε_strain；因为零接触，物理伤害风险≈0，代价是时间与磨损。
- **定义 240（迟滞感知认证前缀 CSC-H）**：k* = min{ k : ∀s≤k, ∀T∈𝒯, ρ_safe(q_real(s))≥0 ∧ k·v·Δt + d_eff ≤ m }。即在**落地管**上验证，并把死区/释放计入停止距离；执行 k* 步即重规划。若 k*=0（连一步都不安全）→ safe_idle + compliant retreat。
- **定义 241（指标的 estimand/estimator 与 e-value 置信序列）**：预注册因果 estimand τ（如"相对基线的安全违规率下降"），estimator τ̂ 允许任意时刻查看；用 e-value/置信序列构造 (1−α) 任意时刻有效区间 [L_n,U_n]，避免 p-hacking 与 optional stopping 膨胀。
- **定义 242（指标证书 MC）**：M=(estimand, estimator, CS_{1−α}, bias_bound, coverage_under_shift, canary_sensitivity, gaming_exposure)。**指标只有带证书才可被引用**；"0 违规"必须写成 U_n 上界，而非 0。
- **定义 243（指标迟滞 MHA）**：把"能力/难度驱动量 u → 报告分数 S"视为 Preisach 迟滞 H_{μ_met}。用 FORC 评测协议（定义 245）辨识 μ_met；**博弈指数 g=A(μ_met)/A_ref**（归一化环面积）；**指标死区** d_met=低于噪声底的不可辨能力增量；**指标 windup** = train/eval 互换后分数回落量（过拟合释放）。
- **定义 244（博弈指数、指标死区、指标 windup）**：g 度量"同样的能力，分数随历史摆动的幅度"；d_met 度量分辨率；windup 度量"评测结束后才释放的虚高"。三者共同构成指标的"失真三元组"，并进入 MA 的似然。
- **定义 245（FORC 评测协议）**：双向难度扫描（易→难→易）＋反转点族＋预注册＋金丝雀穿插；对每个反转点记录分数，估计 μ_met 与同余性残差；同余性被拒即判"指标非 Preisach/被污染"，拒绝据此下结论。
- **定义 246（双向归因 MA）**：给定证书声称 Valid(J) 与观测到的指标结果，差异 D；后验 P(系统坏|D) vs P(指标坏|D) vs P(协议坏|D) vs P(分布漂移|D)，由金丝雀似然标定。**双侧证伪**：不能同时声称"证书健全"且"指标有效"而观察到超界差异。
- **定义 247（对抗指标集与金丝雀）**：ℰ_M 含"永远拒绝/永远 ambiguous/只挑简单样本/基准污染/选择性报告"等博弈策略；金丝雀 = 已知安全性与已知坏系统，用于测指标的敏感度/特异度，并给 MA 提供标定似然。
- **定义 248（J_metagear 与算子）**：J_metagear=(J_vista, transmission_ver, reachable_tube_hash, d_dead, d_windup, metric_cert, gaming_index, meta_attribution, forc_ver)。Valid ⇔ Valid(J_vista) ∧ 落地管验证通过 ∧ 死区/释放已计入 ∧ 指标带证书且同余性未被拒 ∧ MA 未把差异归给指标 ∧ 金丝雀敏感度达标。算子：语义流 [本体辨识 TAM→FORC LMP→FIR-A 增 H_act→CSC-H→MC/MHA→MA→AIC-M]；实时流 [落地投影→死区/释放监视→安全前缀派发→J_metagear 构建]。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（落地管健全性）**：若真传动 T∈𝒯 且 RTT 覆盖误差 ≤ε_T，则在 R_T 上验证安全裕度 ⇒ 真实落地轨迹安全。反例：只要 d_dead>0 或 d_windup>0，仅在指令轨迹上认证即不健全（构造"指令后退但输出不动/停后回弹"的反例）。这直接推翻第 65 轮 CSC"认证指令即认证执行"的隐含前提。
- **引理 10（H_act 的可辨识与可分离）**：自由空间 FORC 激励下，残差按速度符号分解，H_act 落在**奇分量**、H_force 落在**偶 DC 分量**，故签名矩阵近似块对角，J_fi≻0；H_model 只在加载段出现，与 H_act 的阶段支撑不重叠。自由空间是第 65 轮三阶段之外新增的、隔离 H_act 的第四阶段。
- **引理 11（Preisach 可表示性检验）**：同余性/擦除性给出可证伪的模型类检验；被拒时 MA 得到"模型类失效"证据，禁止用 μ 做外推。
- **定理 9（METAGEAR 端到端测量-安全）**：Valid(J_metagear) ⇒ 落地管安全 ∧ 死区/释放已计入 ∧ H_act 已辨识或 ambiguous ∧ 指标任意时刻有效且博弈指数有界 ∧ MA 未归因指标 ∧ VISTA/GRIP 有效。
- **定理 10（双侧证伪）**：在金丝雀标定有效下，若观测差异超出指标证书置信界，则 {证书不健全} 与 {指标无效} 至少一真；MA 后验在两者间可辨识。**你无法既宣称证书健全、又宣称指标有效，还同时看到超界失败。**
- **命题（Goodhart 界）**：报告分数 S = 能力 C + g·effort + noise；则因果下界 C ≥ S − g·B − noise，B 为博弈预算，g 由 FORC 环面积上界。故对外只报因果下界与置信序列，不报点估计 S。
- **实时性**：落地投影/死区监视/释放计时全在实时流（<0.3ms）；FORC 辨识、MC/MHA、MA、AIC-M 全在语义流或离线。

## 5. 本轮最大风险

**一句话**：本轮把"传动迟滞"与"评测迟滞"统一到同一个 Preisach 算子上，这个统一目前是**结构类比而非物理同一**——减速器的 lost motion 是率无关、被动、可重复的材料/机构迟滞，而评测博弈是**有策略、会自适应审计、非率无关**的对抗过程；若指标根本不满足 Preisach 的同余性/擦除性（或博弈方学会针对 FORC 协议反向优化），则博弈指数、Goodhart 界与 MA 似然会一起失效，而系统却因为"已经审计过指标"而更放心地引用虚高分数。

## 2. 形式化定义（完整版）

**定义 233（METAGEAR 闭环）** METAGEAR 是 VISTA 的"测量可审计"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 TAM（传动辨识）、RTT（落地可达管）、LMP（失动探针）、CSC-H（迟滞感知前缀）、MC（指标证书）、MHA（指标迟滞审计）、MA（双向归因），并原位升级 FIR→FIR-A（增 H_act）、RSC-V→RSC-T（增 r_act）、AIC-V→AIC-M、J_vista→J_metagear。不变式：**传动辨识、Preisach 拟合、指标证书、双向归因、FORC 审计只在语义流或离线；实时路径只做落地状态投影、死区/释放计时、安全前缀派发，零学习写操作。**

**定义 234（谐波传动模型 TAM）** 设电机端指令角 q_cmd、输出角 q_real、输出扭矩 τ。谐波减速器（柔轮 flexspline、波发生器 wave generator、刚轮 circular spline）的输出满足
q_real = (1/N)·q_cmd + e_tr(θ) + δ_lm(τ, sign θ̇, hist) + C(τ) + η,
- 周期传动误差 e_tr(θ)=Σ_{k=1}^{K} a_k sin(kθ+φ_k)，主谐波 k=2（波发生器每转两个波峰），高阶来自齿形与装配；
- lost motion δ_lm 用 Preisach 算子建模（定义 235），率无关、方向相关、历史相关；
- 扭转柔度 C(τ) 由非线性刚度 K(τ) 积分给出：低载区 K=K_low（lost-motion 带内），啮合后 K=K_high，τ=K(τ)·(q_real−(1/N)q_cmd−e_tr)；
- η 为温漂/磨损引起的慢变项。
参数集 Θ_T=(N,{a_k,φ_k}_{k≤K},μ_lm,K_low,K_high,η)。**注意：这是机器人"自身的软接触"，与第 65 轮的 H_model（外部接触模型）不同。**

**定义 235（Preisach 迟滞算子，共享）** 对输入 u（传动中为扭矩/指令角，评测中为难度/能力驱动量），
H_μ[u](t)=∬_{α≥β} μ(α,β)·γ_{αβ}[u](t) dα dβ,
其中 γ_{αβ} 为阈值 α≥β 的 play 算子。环面积 A(μ)=∬ μ(α,β)(α−β)dαdβ 等于一个加载-卸载循环的耗散。**Mayergoyz 表示定理**：一个迟滞非线性可被 Preisach 表示 ⇔ 满足
- 同余性（congruency）：输入在相同两极值间往返形成的次环互相合同；
- 擦除性（wiping-out）：输入超过历史极值时旧历史被擦除。
该定理把"类比是否成立"变成**可证伪检验**：同余性/擦除性被拒 ⇒ 模型类失效，禁止外推，交 MA 归因。这是本轮把"结构类比"降级为"可检验假设"的关键。

**定义 236（传动可达管 RTT）** 给定校准类 𝒯={T(·;Θ_T):Θ_T∈Θ_T^cal⊕ε_T}，动作前缀 A[:k] 的落地状态集
R_T(A[:k]) = { q_real(s) : T∈𝒯, s∈{1,…,k} }。
安全裕度 ρ_safe 必须在 R_T 上取最坏：
ρ_safe^tube(A[:k]) = min_{q∈R_T(A[:k])} ρ_safe(q)。
第 65 轮 CSC 实际计算的是 ρ_safe(q_cmd)，即隐式假设 R_T={q_cmd}。RTT 把该假设显式化并推翻。

**定义 237（可控死区与储能释放视界）** 
- 可控死区 d_dead = max{ q : |T(q)−T(0)| < ε }，即落在 lost-motion 带内、指令被吞掉的最大位移；
- 储能释放：指令在 t_k 停止后，柔轮储存的弹性能继续驱动输出，释放时间 t_rel 与释放位移 d_windup = ∫_{t_k}^{t_k+t_rel} v_release dt；一阶近似 d_windup ≈ C(τ_stored)/c_damp；
- 有效停止距离 d_eff = d_cmd + d_dead + d_windup。
**命题（忽略即不健全）**：只要 d_dead>0 或 d_windup>0，"在第 k 步停止"就不保证停在安全点；安全证书必须把 d_eff 计入停止距离。

**定义 238（执行故障假设 H_act 与本体签名）** 故障假设集扩为
ℋ = {H0, H_geo, H_force, H_model, H_vis, H_policy, **H_act**}。
本体签名 ρ_act 由以下可实时/近实时获得量构成：
ρ_act = [ q_motor/N − q_out （双编码器差）, i_motor·k_t − τ （电流-力矩残差）, 
          ½(ρ(θ̇>0) − ρ(θ̇<0)) （速度反号奇分量）, 
          A_hyst （卸载回滞面积）, {残差在 2k 阶谐波的能量}, ΔT （温漂） ]ᵀ。
**分离性核心**：
- H_act 的迟滞/摩擦项对速度反号**奇对称**（θ̇→−θ̇ 变号），且在**自由空间**即可激励；
- H_force 的偏置/漂移是**偶对称 DC 项**（与速度符号无关）；
- H_model 只在**外部接触/加载**段出现。
故 ρ_act 在奇/偶分解下与 H_force 正交，在阶段支撑上与 H_model 不重叠。

**定义 239（失动探针 LMP / FORC 激励）** 在**自由空间**（零接触、f_n≈0）执行小幅往返激励 a_sweep：从负饱和升到反转点 u_r，再降到下一反转点，形成一族 FORC；对每个反转点记录 (q_cmd, q_out, τ)。由 FORC 数据拟合 μ_act（Preisach 密度）与 {a_k,φ_k}（传动误差谐波）；再执行 release_test：快速卸载并观测输出回弹，估计 d_windup 与 c_damp。安全约束：零接触 ⇒ 物理伤害风险≈0；代价是时间预算与机械磨损（每次往返计入磨损预算 W_budget）。若磨损预算耗尽或温漂过快，降级为被动辨识（仅用日常运动的自然反转）。

**定义 240（迟滞感知认证前缀 CSC-H）** 对块 A_t 与前缀长度 k，定义
k*(A_t) = min{ k : (∀s≤k)(∀T∈𝒯) ρ_safe(q_real(s)) ≥ 0 且 k·v·Δt + d_eff ≤ m },
其中 m 为不可逆视界。执行器只执行 k* 步即强制重规划与再归因。若 k*=0（连一步都不满足），进入 safe_idle + compliant retreat。与第 65 轮 CSC 的差别：验证域从 q_cmd 换成 R_T；停止距离从 d_cmd 换成 d_eff。

**定义 241（指标的 estimand/estimator 与 e-value 置信序列）** 预注册因果 estimand τ（例：相对基线的安全违规率下降、或"故障归因正确率"的真实值），估计量 τ̂ 允许在数据累积过程中**任意时刻查看**。用 e-value 构造置信序列 CS_{1−α}=(L_n,U_n)，满足对任意停时 T，P(τ∈CS_T)≥1−α（任意时刻有效，anytime-valid）。这直接对冲 optional stopping、p-hacking 与"看到显著就停"的膨胀。

**定义 242（指标证书 MC）** 一个指标只有携带证书才可被引用：
M = (estimand, estimator, CS_{1−α}, bias_bound, coverage_under_shift, canary_sensitivity, gaming_exposure)。
- bias_bound：选择偏差/测量偏差的上界；
- coverage_under_shift：分布漂移下的经验覆盖率（而非名义覆盖）；
- canary_sensitivity：对已知坏系统的检出率（负对照）；
- gaming_exposure：由 MHA 给出的博弈指数 g。
**报告规则**：禁止报"0 违规"；必须报"违规率 ≤ U_n（1−α 置信上界）"。N 次 0 违规时 U_n≈3/N（rule of three）。

**定义 243（指标迟滞 MHA）** 把"能力/难度驱动量 u → 报告分数 S"视为 Preisach 迟滞 H_{μ_met}：
S(t) = H_{μ_met}[u](t) + β·u + noise。
用 FORC 评测协议（定义 245）辨识 μ_met。定义
- 博弈指数 g = A(μ_met)/A_ref（归一化环面积，A_ref 为标定参照）；
- 指标死区 d_met = 使 |ΔS| 低于噪声底的最小 |Δu|；
- 指标 windup = train→eval 互换后分数的回落量（过拟合在评测后释放）。
g 越大，说明"同样的能力，分数随历史摆动越大"，即指标越容易被博弈。

**定义 244（博弈指数、指标死区、指标 windup）** 三者构成指标的"失真三元组"：g 度量历史依赖（Goodhart 迟滞），d_met 度量分辨率（看不见小改进），windup 度量延迟释放（评测后才暴露的虚高）。三元组进入 MA 的似然：观测到"分数大幅上升但 g 大、windup 大"时，MA 更倾向归因"指标坏/博弈"，而非"系统真的变好"。

**定义 245（FORC 评测协议）** 
1. 预注册 estimand 与停止规则；
2. 双向难度扫描：易→难→易，在若干反转点 u_r 处反转，记录分数；
3. 每个反转点估计次环是否合同（同余性）、历史是否被擦除（擦除性）；
4. 穿插金丝雀（已知好/坏系统）标定指标敏感度；
5. 估计 μ_met、g、d_met、windup，写入 MC。
同余性被拒 ⇒ 判"指标非 Preisach 或被污染"，**拒绝据此下结论**，转 MA。

**定义 246（双向归因 MA）** 设证书声称 Valid(J_metagear)（即系统安全），观测到指标结果（可能有失败）。定义差异
D = |证书安全声称 − 观测结果| / σ_obs。
在四类原因上做后验：
P(系统坏|D) ∝ p(D|系统坏)·P(系统坏)，
P(指标坏|D)，P(协议坏|D)，P(分布漂移|D)，
似然由金丝雀标定（指标对已知坏系统的敏感度、对已知好系统的特异度）。**双侧证伪**：若 D 超出指标证书的置信界，则 {证书不健全} 与 {指标无效} 至少一真；不能既声称证书健全、又声称指标有效。

**定义 247（对抗指标集与金丝雀）** 指标干扰集
ℰ_M = { 永远拒绝, 永远 ambiguous, 只挑简单样本, 基准污染, 选择性报告, 训练/评测泄漏, 延迟报告 }。
金丝雀 = 一组已知安全性（好/坏）的合成系统与合成故障，用于测指标的敏感度/特异度，并为 MA 提供标定似然。**共因风险**：若金丝雀与真实系统同分布，则指标可能对二者一起失效；故金丝雀需覆盖分布外。

**定义 248（J_metagear 与算子）** 
J_metagear = (J_vista, transmission_ver, reachable_tube_hash, d_dead, d_windup,
              metric_cert, gaming_index, meta_attribution, forc_ver)。
验证规则：
Valid(J_metagear) ⇔ Valid(J_vista)
  ∧ 落地管验证通过（CSC-H 在 R_T 上安全）
  ∧ d_dead/d_windup 已计入停止距离
  ∧ 指标携带证书且同余性未被拒
  ∧ MA 未把差异归因给指标（或已显式标注 `metric_suspect`）
  ∧ 金丝雀敏感度 ≥ 1−β。
算子：
- 语义流：[双编码器/电流/力矩 → TAM 辨识 → FORC LMP → FIR-A（增 H_act）→ RSC-T → CSC-H → MC/MHA → MA → AIC-M]；
- 实时流：[落地状态投影 → 死区/释放计时 → 安全前缀派发 → J_metagear 构建]。

## 3. 关键算法伪代码

### IP-224 TAM（谐波传动辨识）

```python
class HarmonicTransmissionModel:
    """q_real = q_cmd/N + e_tr(theta) + Preisach_lm(tau) + C(tau)."""
    def __init__(self, N, K_harm=4):
        self.N, self.K_harm = N, K_harm

    def transmission_error(self, theta, coeffs):
        # coeffs: [(a_k, phi_k)]，主谐波 k=2
        return sum(a * np.sin(k * theta + p)
                   for k, (a, p) in enumerate(coeffs, start=1))

    def lost_motion(self, tau_hist, mu_lm):
        # Preisach play-operator 二重积分（离散化）
        return preisach_eval(tau_hist, mu_lm)

    def forward(self, q_cmd, tau_hist, theta, params):
        return (q_cmd / self.N
                + self.transmission_error(theta, params['harm'])
                + self.lost_motion(tau_hist, params['mu_lm'])
                + params['C'](tau_hist[-1])
                + params['eta'])          # 温漂/磨损

    def fit_preisach(self, forc_data):
        # FORC: 每个反转点 u_r 的升/降支 → 二阶差分得 mu
        mu = forc_density(forc_data)
        ok = mayergoyz_test(forc_data)     # 同余性 + 擦除性
        return mu, ok
```

class ReachableTransmissionTube:
    def __init__(self, tam, theta_lo, theta_hi, eps_T, n_mc=256):

## 4. 推导

**引理 9（落地管健全性）** 设真传动 T*∈𝒯，且 RTT 的区间外扩覆盖 sup_{T∈𝒯}|T−T*|≤ε_T。若 ∀q∈R_T(A[:k]) 有 ρ_safe(q)≥0，则真实落地轨迹 q_real=T*(A[:k])∈R_T(A[:k])，故 ρ_safe(q_real)≥0，安全。反之，若只在 q_cmd 上认证，构造反例：取 d_dead>0，指令从 q0 后退 δ<d_dead，则 q_real≈q0 未后退，若 q0 已接近力限，认证"后退安全"为假；取 d_windup>0，指令停止后 q_real 继续前进 d_windup，越过 m。故"指令认证 = 执行认证"不健全。∎

**引理 10（H_act 的可辨识与可分离）** 将残差 r(θ̇)=ρ_obs−ρ_model 按速度符号奇偶分解：r=r_odd+r_even，r_odd(θ̇)=½(r(θ̇)−r(−θ̇))，r_even=½(r(θ̇)+r(−θ̇))。迟滞与摩擦满足 δ_lm(τ,−θ̇)=−δ_lm(τ,θ̇)（奇），F/T 偏置 b 与速度符号无关（偶）。自由空间 FORC 同时激励 ±θ̇，故 r_odd 只含 H_act、r_even 只含 H_force 的 DC 分量；H_model 的签名需外部接触载荷，在自由空间为零。因此签名矩阵 S 在 (H_act, H_force, H_model) 子块上近似块对角，J_fi=SᵀΣ⁻¹S 的对应子块正定，κ_fi>0。若缺少方向反转（单向激励），r_odd 不可观测，H_act 与 H_force 混叠——正如第 65 轮缺零力窗时 H_force 与 H_geo 混叠。∎

**引理 11（Preisach 可表示性检验）** 由 Mayergoyz 定理，Preisach 可表示 ⇔ 同余性 ∧ 擦除性。FORC 族天然给出次环与擦除轨迹：若同一极值区间 [u1,u2] 的两次次环不合同，或历史未被更大极值擦除，则检验拒绝。拒绝后 μ 的任何外推无保证，MA 得到"模型类失效"证据，CSC-H 退化为保守的最坏情形包络（不做 μ 外推）。∎

**定理 9（METAGEAR 端到端测量-安全）** 在 A94–A98 下：
1. **落地安全**：引理 9 ⇒ 证书在落地管上验证，故指令与执行的错位被覆盖；
2. **死区/释放安全**：CSC-H 把 d_dead/d_windup 计入 d_eff，且 k*·v·Δt+d_eff≤m，故停止承诺有效；
3. **传动故障可归因**：引理 10 ⇒ H_act 与 H_force/H_model 可分；自由空间是隔离 H_act 的第四阶段；
4. **指标可审计**：MC 给任意时刻有效置信序列，MHA 给博弈指数与失真三元组；同余性被拒则拒绝引用分数；
5. **双侧证伪**：定理 10 ⇒ 差异超界时不能同时宣称证书健全与指标有效；
6. **优雅降级**：传动模型类失效→保守包络；指标模型类失效→只报因果下界/不下结论；磨损预算耗尽→被动辨识；视觉/力失效→沿用 VISTA 降级。
∎

**定理 10（双侧证伪）** 设金丝雀标定给出指标对已知坏系统的敏感度 ≥1−β、对已知好系统的特异度 ≥1−γ。若观测差异 D 超出 MC 的 (1−α) 置信界，假设"证书健全 ∧ 指标有效"同时成立。证书健全意味着真实系统安全；指标有效意味着以 ≥1−α 概率真实安全系统不会被判失败。但观测到 D 超界，即被判失败，概率 ≤α；与"指标有效"矛盾（在 α 显著性下）。故至少一个假设为假。MA 的后验由金丝雀似然 p(D|系统坏) 与 p(D|指标坏) 决定，若二者可区分（敏感度/特异度均 >½），则后验可辨识。∎

**命题（Goodhart 界）** 设报告分数 S 与真实能力 C 满足 S = C + g·e + ε，其中 e 为博弈努力（0≤e≤B），g 为博弈指数，ε 为有界噪声 |ε|≤ν。则因果下界
C = S − g·e − ε ≥ S − g·B − ν。
FORC 环面积给出 g 的上界 ĝ≥g，故可报告保守下界 C ≥ S − ĝ·B − ν。当 g 大（指标迟滞环大）时，报告的分数上升大部分可被博弈努力解释，因果增益被压缩——这正是"分数涨了不等于能力强了"的定量版本。∎

## 7. 已知风险

**一句话**：本轮把"传动迟滞"与"评测迟滞"统一到同一个 Preisach 算子上，这个统一目前是**结构类比而非物理同一**——减速器的 lost motion 是率无关、被动、可重复的材料/机构迟滞，而评测博弈是**有策略、会自适应审计、非率无关**的对抗过程；若指标根本不满足 Preisach 的同余性/擦除性（或博弈方学会针对 FORC 协议反向优化），则博弈指数、Goodhart 界与 MA 似然会一起失效，而系统却因为"已经审计过指标"而更放心地引用虚高分数。

**次级风险与缓解**：
1. **Preisach 类比失效**：指标/传动可能不满足同余性/擦除性；缓解：把同余性检验作为强制门，被拒即拒绝外推、退化为保守包络与"不下结论"；只把 Preisach 当**可证伪假设**而非公理。
2. **博弈方自适应**：评测博弈是有策略的，会针对 FORC 协议与金丝雀反向优化；缓解：随机化反转点、隐藏 holdout、金丝雀分布外化、把 MA 当作对抗博弈而非静态后验；引入博弈论的 Stackelberg 视角作为未来工作。
3. **在线 FORC 的磨损与时间成本**：频繁往返加速柔轮疲劳；缓解：磨损预算 W_budget + 被动自然反转优先 + 只在语义流/停机窗口做完整 FORC。
4. **传动模型外推风险**：温漂/磨损使 Θ_T 漂移；缓解：在线慢变参数跟踪 + 区间外扩 + 温漂前馈；超出校准域即判 ambiguous。
5. **H_act 与 H_force 的残余混叠**：若电流-力矩标定本身漂移，奇偶分解会漏；缓解：双编码器为主、电流为辅，加独立关节力矩传感器交叉校验。
6. **d_windup 估计依赖阻尼模型**：柔轮阻尼难辨识；缓解：只取保守上界、release_test 直接测量而非模型外推。
7. **e-value 功效**：任意时刻有效通常比固定样本检验更保守，区间更宽；缓解：预注册、分层报告、把功效损失计入样本量设计。
8. **金丝雀共因失效**：金丝雀与真实系统同分布时，指标可能一起被骗；缓解：分布外金丝雀、对抗金丝雀、第三方审计；共因下只要求判 `metric_suspect` 而非给出正确归因。
9. **实时预算**：落地投影 + 死区/释放逼近 2.8ms；缓解：预编译区间、查表、把 TAM/MHA 全留语义流。
