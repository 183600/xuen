# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「轻量化设计」×「数据规模」）

> R69 问「我该向谁求证、还能问什么」，把不确定性一分为二，并用一条**重路径**（K 采样流匹配 + VoI 枚举 + 冻结 LLM 解码 + k 源证据纪律）去主动消歧。但 R69 自陈的最大风险恰好戳中这条路径的结构性弱点：全部效率收益押在「流模型的模态分布可信」上，而这条路径**又重又不可自证**——K=4 采样、Hutchinson 似然、轨迹聚类、VoI、LLM 解码，每一环都要求一个在部署分布上校准良好的大模型。R69 的补救是再加一层（MCG 校准门），可校准本身同样要数据、要算力、要信任。
>
> 本轮两个灵感把「加层」的思路**反过来**：
> - **轻量化设计**：不是把安全剪掉，而是把闭环拆成「常驻的否决核」与「按需的建议层」——安全常驻，效率按需付费；
> - **数据规模**：epistemic 里很大一部分根本不必在线问——它在离线数据规模增长后被「学掉」了。数据规模的真正作用，是把「需要交互的歧义」压成「已有覆盖的先验」，只留下不可约的语义/OOD 歧义。
>
> 核心命题：**轻量化只轻「建议」，绝不轻「否决」；数据规模只买「已覆盖的歧义」，买不到「语义的歧义」。** 命名 **LITE-RAS**（Lightweight Interaction-aware Trustworthy Epistemic closed loop，数据规模蒸馏的轻量化可信不确定性闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这份『不确定』本身，配得上多大算力和多少次提问？**」

## 0. 直觉与动机

**灵感 1（轻量化设计 → 把闭环分成否决核与建议层）**
直觉：R69 的每一层几乎都在同一算力等级上，于是「变轻」最省事的做法就是砍模块——而最先被砍掉的往往不是冗余，是**否决权**。正确的轻量化对象是「建议」：学生网络一次前向给出 `(Û_ale, Û_epi, 该不该问)`，但「信息动作是否越界」「能否单源定案」「何时退回 R68」这三个否决，必须交给确定性、可审计、冻结哈希的 **NCK 否决核**执行。一句话：**建议可以便宜，否决必须昂贵地可信**；把两者混在一起，轻量化就会顺手剪掉否决，事故率随之上升。

**灵感 2（数据规模 → epistemic 的离线可约性）**
直觉：R69 默认 epistemic 都丢给在线交互，忽略了它有两种来源——一种来自「没见过」（数据规模可消解），一种来自「本质上多解」（语义歧义，再多数据也消解不了）。引入覆盖度 `cov(c,N)`：只有**未被覆盖**的残余 `U_epi` 才值得在线支付。于是交互频率应随 N 单调下降并收敛到一个非零下界，这个下界就是「语义歧义」。数据规模不是万能的，但它能把「问」变成「先验」——这是本轮对 R69 交互预算最实质的松绑。

**灵感 3（蒸馏 → 轻量化必须带误差界，而不是近似）**
直觉：从重教师蒸馏到单前向学生，若只说「性能差不多」就是不负责任。本轮要求**保守蒸馏**：学生可以高估不确定性（多问无害），但不许系统性低估（少问致命）。用非对称损失 + 标定集上的风险包络 `ε_d`，证明学生风险 ≤ 教师 + `L_λ·ε_d`。轻量化的严谨版本不是「压缩」，而是**带证书的压缩**——否则你只是把一个大黑箱换成了一个小黑箱。

**灵感 4（数据规模悖论 → 大数据会伪造歧义）**
直觉：数据越多，flow 模型越可能把长尾样本「记住」成多峰：`H_mode` 虚高、`Δ_min` 很小——这不是可约歧义，而是记忆噪声。若直接喂给 VoI，系统会为一个幻影问个不停。更隐蔽的是校准漂移：大模型在部署分布上去校准，而轻量学生根本没有能力自查。故需要两个守卫：**OMG**（抑制伪模态）与 **CDW**（分布无关漂移监视，把信任交还给 conformal 覆盖而非神经网络自信度）。

**灵感 5（轻量化的新威胁 → 便宜的错更危险）**
直觉：R69 的错误是「偶尔问错」；LITE 的错误是「每个时刻都在用一个便宜的、没人复核的默认判断」。轻量化的风险不是单次更糟，而是**错误变成系统性默认且难以审计**。因此证书必须记录 `nck_hash`、师生 gap、`drift_p`；审计对象从「这次交互对不对」升级为「**这个默认判断还配不配被信任**」。这也决定了本轮的理论姿态：轻量路径的每一次「不升级」都必须留下可复核的理由，而不是一句「模型觉得没事」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LITE-RAS 总览）** LITE-RAS = (TDS, IDS, NCK, CAG, OMG, CDW, LFL, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **否决核不可轻量化**：NCK 的三个模块在轻量路径上始终精确执行，确定性代码、冻结哈希、禁止蒸馏/近似/跳过；
(iii) **蒸馏保守性**：学生的风险下界不得低于教师超过证书 `ε_d`（定义 319），否则一律回退到教师或 R68。

**定义 311（计算-信任预算）** 每步预算 B = B_0 + B_1·1[gate open]。轻量路径成本 ≤ B_0；重路径仅在 gate 开时支付「歧义税」τ = C_heavy / C_light。目标：min E[C] s.t. Risk ≤ Risk_R68 + δ。要点：**安全常驻（B_0 里含 NCK），效率按需（B_1 只在真歧义时花）**。

**定义 312（师生分解与保守蒸馏 TDS）** 教师 T = R69 FLUID-RAS，输出 `(U_ale^T, U_epi^T, g*^T, a_score^T)`；学生 `S_φ: z_t → (Û_ale, Û_epi, q̂, ĉ)`，单次前向。损失
`L_TDS = E[w_ale·ρ(Û_ale−U_ale^T) + w_epi·ρ(Û_epi−U_epi^T) + CE(q̂, 1[g*^T≠∅])]`，
其中 ρ 为**非对称**算子：低估罚重、高估罚轻。学生不含 LLM 解码器——问句解码属于建议层之外、必须经 NCK 放行。

**定义 313（交互-数据替代律 IDS）** 对歧义类 c，在线交互频率 `f_int(c,N)`，覆盖度 `cov(c,N)`，残余 `U_epi^res(c,N) = U_epi(c)·(1−cov(c,N))`。替代律：
`f_int(c,N) = f_floor(c) + (f_0(c) − f_floor(c))·exp(−κ·N·cov′(c))`，
其中 `f_floor(c)` 为不可约部分（语义/OOD）。数据规模只买断「已覆盖」的部分，买不到 `f_floor`。

**定义 314（覆盖集与不可约核）** 令 𝔐_cov 为数据流形覆盖的歧义类集合，𝔐_irr 为残余。在线需消解的仅是
`U_epi^online = Σ_{c∈𝔐_irr} ŵ_c·U_epi(c)`；`c∈𝔐_cov` 的歧义已在离线被学成先验，不进入在线交互。

**定义 315（否决核 NCK）** NCK = (𝔙_safe 安全包络认证, 𝔙_evid 证据纪律, 𝔙_fb R68 退避)。要求：对任意输入，NCK 返回与重路径**逐位相同**的判定；实现为确定性规则/查表，哈希 `nck_hash` 进证书。轻量化只作用于建议层 `𝒜_advice`，不作用于否决层 `𝔙`。

**定义 316（conformal 弃权门 CAG）** 在标定集上计算非一致性分数 `s(z)=Û_epi(z)`；阈值 `τ_α` 取 `⌈(n+1)(1−α)⌉/n` 经验分位。gate open ⇔ `s(z) > τ_α`。在可交换性下给出有限样本保证 `P(U_epi^T > τ | gate closed) ≤ α`。α 随数据规模收紧——**门是统计承诺，不是模型自信**。

**定义 317（过度模态化守卫 OMG）** 过度模态化分数 `Ω = H_mode·√N_eff / (Δ_min·σ_in + ε)`。若 `Ω > τ_Ω` 且 `Δ_min < 3σ_in`，判为大数据记忆长尾产生的伪模态，强制 `Û_epi ← ρ_Ω·Û_epi`（衰减），并升级到教师复核。

**定义 318（校准漂移监视 CDW）** 在线维护标定残差序列的 conformal p-value `p_t`；若 `p_t` 连续低于 `α_d` 或秩检验拒绝交换性，则判定漂移 ⇒ 冻结学生、强制 LFL 升级。CDW **不依赖训练分布**，因此不受数据规模欺骗。

**定义 319（蒸馏证书 DCE）** `ε_d = sup_{s∈S_cal} [λ_T(s) − λ_S(s)]_+`，即学生相对教师的最大风险放松。部署允许 ⇔ `ε_d ≤ ε_max` ∧ `J_FLUID†` 有效。注意：证书只在标定集上成立，必须由 CDW 持续守护（这是它唯一但致命的边界）。

**定义 320（轻量化退避阶梯 LFL）** L0 = 学生单前向；L1 = 学生 + CAG；L2 = 教师重路径（R69 FLUID）；L3 = R68 纯保守。升级条件单调：CAG 开 / OMG 触发 / CDW 告警 / NCK 否决 ⇒ 升级；降级需连续 m 步平稳且证书有效。安全等级 L0 ≺ L1 ≺ L2 ≺ L3。

**定义 321（数据规模感知审计 VQAuditor-L）** 审计：学生弃权是否与真实歧义相关、师生 gap 是否随 N 单调收缩、伪模态比例、投毒子集对 `ε_d` 的放大。结论回灌 TDS 的样本权重与 CAG 的 α 调度。

**定义 322（AIC-LITE 干扰集）** `ℰ_LITE = ℰ_FLUID × ℰ_scale`，新增：长尾记忆、过度模态化、毒化大数据（用大量「看起来一致」的样本压低 `ε_d`）、校准漂移。

**定义 323（证书 J_LITE）** `J_LITE = (J_FLUID†, ε_d, cov_α, drift_p, P99_compute, nck_hash, lite_ver)`。Valid ⇔ `J_FLUID†` 有效 ∧ `ε_d ≤ ε_max` ∧ 覆盖检验通过 ∧ LFL 未越级。

**定义 324（数据规模风险单调性）** 记部署风险 Risk(N)。主张：在 𝔐_cov 上 Risk(N) 非增（数据收益）；在 𝔐_irr 上有下界 `Risk_floor`（不可约）；整体单调仅当 OMG/CDW 生效。

**定义 325（轻量安全支配）** 对任意状态 s，若 NCK 精确且 `ε_d` 有界，则
`Risk_LITE(s) ≤ Risk_R69(s) + L_λ·ε_d + L_Ω·Ω_spurious`。

**定义 326（学生-教师一致域）** `𝒞_ε = {s : |Û_ale−U_ale^T| + |Û_epi−U_epi^T| ≤ ε}`。域外学生不得单独决策，必须升级（LFL）。一致域是学生被允许「便宜地说话」的唯一地带。

## 2. 关键算法骨架

```python
# IP-264 TDS：保守蒸馏（非对称损失，低估重罚）
class LiteStudent:
    def __init__(self, trunk, heads):
        self.trunk, self.heads = trunk, heads          # z -> (ale, epi, ask)
    def forward(self, z):
        h = self.trunk(z)
        return (self.heads.ale(h), self.heads.epi(h), self.heads.ask(h))

def distill_loss(stu, tea):
    ua, ue, q = stu
    Ua, Ue, has_ask = tea
    return (W_ALE * asym(ua - Ua)         # 低估罚重、高估罚轻
            + W_EPI * asym(ue - Ue)
            + CE(q, has_ask))

# IP-267 CAG：conformal 弃权门（有限样本覆盖，替代不可信的 mode_head）
def conformal_gate(s, cal_scores, alpha):
    n = len(cal_scores)
    tau = sorted(cal_scores)[min(n, ceil((n + 1) * (1 - alpha))) - 1]
    return s > tau                                 # open ⇔ 歧义"真到值得付税"

# IP-268 OMG：过度模态化守卫（大数据记忆长尾 → 伪模态）
def over_modality_guard(H_mode, delta_min, sigma_in, N_eff):
    Omega = H_mode * sqrt(N_eff) / (delta_min * sigma_in + EPS)
    if Omega > TAU_OMG and delta_min < 3 * sigma_in:
        return DECAY * H_mode                     # 抑制伪模态，并升级教师复核
    return H_mode

# IP-275 LITE-RAS 主闭环：单前向学生 + 否决核 + 按需升级
def LITE_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                      # R68 一次前向
    c, U_cal, thr = M.cof.step(...)                # R68 标定
    # 1) 建议层：一次前向，不再 K 采样
    Ua_hat, Ue_hat, q_hat = M.student.forward(z)
    # 2) 否决核：确定性、不可蒸馏、始终精确执行
    if M.nck.veto_safe(z, o):                      # 信息动作/任务动作越界
        return M.nck.fallback_R68(z, o, U_cal)     # L3
    # 3) conformal 门：统计承诺决定"是否值得付歧义税"
    if not conformal_gate(Ue_hat, M.cag.cal, M.cag.alpha):
        lam = max(M.efs.risk_scale(...), lam_floor(Ua_hat))
        return M.nck.dispatch(z, lam, level=0)     # L0/L1：便宜且安全
    # 4) 门开 ⇒ 歧义真实存在，但先查它是不是"伪歧义"
    Ue_hat = over_modality_guard(Ue_hat, M.omg.delta_min(z), M.omg.sigma(z), M.N_eff)
    if M.cdw.alarm() or M.omg.spurious(Ue_hat):
        return M.lfl.escalate(level=2, z=z, o=o)   # 教师重路径 R69
    # 5) 交互仍需 NCK 认证 + 证据纪律（学生只提建议，不掌否决）
    if not M.nck.evidence_discipline_ok(z, o):
        return M.lfl.escalate(level=2, z=z, o=o)
    g = M.mint.choose_interaction_from_student(q_hat, z, o, M.budget)
    if g is None:
        return M.nck.dispatch(z, lam_floor(Ua_hat + Ue_hat), level=1)
    if not M.nck.certify_info(g, o):               # 否决：信息动作也过安全包络
        return M.lfl.escalate(level=2, z=z, o=o)
    ans = M.cia.execute(g)
    Ue_after = M.cia.update_belief_student(q_hat, ans)
    lam = max(M.efs.risk_scale(...), lam_floor(Ua_hat))
    M.vqa_l.submit_async(z, q_hat, Ue_hat, Ue_after, M.cdw.p_value)
    return M.nck.dispatch(z, lam, level=1)
```

## 3. 推导

**引理 19（蒸馏误差 → 风险放大）** 设学生低估 `U_epi` 至多 `ε_d`、NCK 与蒸馏不相交，则风险增量 ≤ `L_λ·ε_d`，`L_λ` 为 `λ_floor` 对不确定度的 Lipschitz 常数。要点：轻量化的安全性是**可定价的**——`ε_d` 就是它的价格，证书负责把价格写在标签上。系：只要 `ε_d ≤ ε_max`，学生路径的风险不超过教师一个可审计的常数。

**引理 20（交互-数据替代）** 若覆盖集随 N 单调增长、覆盖类上的残余 `U_epi` 按指数衰减，则期望交互率单调下降并收敛到 `f_floor`；极限由 `𝔐_irr` 的测度给出，与 N 无关。系：**数据规模买不到语义歧义**——这既是收益的边界，也是「数据越多越该少问」这一直觉的严格版本。

**引理 21（conformal 弃权有效性）** 在可交换性下，CAG 的漏报率 ≤ α；CDW 的秩检验在漂移下以趋于 1 的概率拒绝，power 随漂移幅度上升。故轻量门不是「信任神经网络」，而是「**信任有限样本的覆盖**」；一旦交换性被破坏，CDW 把信任从学生手里收回。

**定理 18（LITE 在成本-风险平面的支配）** 设 `ε_d→0` 且 OMG/CDW 无误报，则 LITE 的期望计算成本 ≤ R69（轻量路径），风险 ≤ R69 + `L_λ ε_d`；当 gate 关闭或处于一致域外，逐指令退化为 R69；当 CDW/NCK 否决，退化为 R68。因此 LITE 是 **R69 的代价受控近似 + R68 的严格安全下界**。

**定理 19（否决核不可轻量化）** 因 NCK 三模块确定性且不受蒸馏影响，轻量化无法弱化 (a) 信息动作安全、(b) 单源不定案、(c) 单调退避。任何把 NCK 替换为学生学习近似的方案，都存在对抗输入使违规率 > 0（构造性反例：在训练分布外让学生的否决头趋近 0）。系：**否决权不是性能指标，不能进入蒸馏损失**。

**定理 20（数据规模的单调-非单调二重性）** 在覆盖集上 Risk(N) 非增（数据收益）；在长尾伪模态上 Risk(N) 可暂时增（过度模态化），但 OMG 把伪模态的 `U_epi` 衰减后恢复单调。故「更多数据」只有在**配守卫**时才是安全收益——无守卫的数据规模会同时提高能力与虚警。

## 5. 实验设计 E301–E315

# IP-264 TDS：保守蒸馏（非对称损失，低估重罚）
class LiteStudent:
    def forward(self, z):
        h = self.trunk(z)
        return self.heads.ale(h), self.heads.epi(h), self.heads.ask(h)

def distill_loss(stu, tea):
    ua, ue, q = stu
    Ua, Ue, has_ask = tea
    return (W_ALE * asym(ua - Ua)          # 高估轻罚、低估重罚
            + W_EPI * asym(ue - Ue)
            + CE(q, has_ask))

# IP-267 CAG：conformal 弃权门（有限样本覆盖）
def conformal_gate(s, cal_scores, alpha):
    n = len(cal_scores)
    tau = sorted(cal_scores)[min(n, ceil((n + 1) * (1 - alpha))) - 1]
    return s > tau                          # open ⇔ 歧义真到值得付税

# IP-268 OMG：抑制大数据伪造的伪模态
def over_modality_guard(H_mode, delta_min, sigma_in, N_eff):
    Omega = H_mode * sqrt(N_eff) / (delta_min * sigma_in + EPS)
    return DECAY * H_mode if (Omega > TAU_OMG and delta_min < 3 * sigma_in) else H_mode

# IP-275 主闭环：单前向学生 + 否决核 + 按需升级
def LITE_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    Ua, Ue, q = M.student.forward(z)                    # 建议层：一次前向

        return M.nck.fallback_R68(z, o, U_cal)          # L3
    if not conformal_gate(Ue, M.cag.cal, M.cag.alpha):

        return M.nck.dispatch(z, lam, level=0)          # L0/L1
    Ue = over_modality_guard(Ue, M.omg.delta_min(z), M.omg.sigma(z), M.N_eff)
    if M.cdw.alarm() or M.omg.spurious(Ue):
        return M.lfl.escalate(level=2, z=z, o=o)        # L2：教师 R69
    if not M.nck.evidence_discipline_ok(z, o):
        return M.lfl.escalate(level=2, z=z, o=o)
    g = M.mint.choose_interaction_from_student(q, z, o, M.budget)
    if g is None:
        return M.nck.dispatch(z, lam_floor(Ua + Ue), level=1)
    if not M.nck.certify_info(g, o):                    # 信息动作也过安全包络

    ans = M.cia.execute(g)

    lam = max(M.efs.risk_scale(...), lam_floor(Ua))

## 4. 推导

**引理 19（蒸馏误差 → 风险放大）** 学生低估 `U_epi` 至多 `ε_d`、NCK 与蒸馏不相交，则风险增量 ≤ `L_λ·ε_d`。系：轻量化安全性**可定价**，`ε_d` 是价格，证书把价格写在标签上；`ε_d≤ε_max` 时学生风险不超教师一个可审计常数。

**引理 20（交互-数据替代）** 覆盖集随 N 单调增长、覆盖类残余 `U_epi` 指数衰减 ⇒ 期望交互率单调下降并收敛到 `f_floor`，极限由 `𝔐_irr` 测度给出、与 N 无关。系：**数据规模买不到语义歧义**，这正是「数据越多越该少问」的严格版本。

**引理 21（conformal 弃权有效性）** 可交换性下 CAG 漏报率 ≤ α；CDW 秩检验在漂移下拒绝概率趋于 1，power 随漂移幅度上升。故轻量门信任的是**有限样本覆盖**而非神经网络自信；交换性一破，CDW 把信任收回。

**定理 18（LITE 在成本-风险平面的支配）** `ε_d→0` 且 OMG/CDW 无误报时，期望成本 ≤ R69、风险 ≤ R69 + `L_λ ε_d`；gate 关闭或一致域外逐指令退化为 R69；CDW/NCK 否决退化为 R68。⇒ LITE = **R69 的代价受控近似 + R68 的严格安全下界**。

**定理 19（否决核不可轻量化）** NCK 三模块确定性且不受蒸馏影响，轻量化无法弱化 (a) 信息动作安全、(b) 单源不定案、(c) 单调退避。把 NCK 换成学生学习近似，必存在对抗输入使违规率 > 0（在分布外令否决头趋 0 的构造性反例）。系：**否决权不是性能指标，不能进入蒸馏损失**。

**定理 20（数据规模的单调-非单调二重性）** `𝔐_cov` 上 Risk(N) 非增；长尾伪模态上可暂增（过度模态化），OMG 衰减后恢复单调。⇒ 「更多数据」只有在配守卫时才是安全收益；无守卫的数据规模同时提高能力与虚警。
