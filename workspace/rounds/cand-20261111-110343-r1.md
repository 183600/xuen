# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「ROS2」×「灵巧操作」）

> 第 54 轮把技能组合提升为「动作空间剖面 α_S + 云边映射 γ_ce + 动作-鲁棒性联合证书 J」。但 α_S 仍把动作视为「可达/不可达」的几何占位，**忽略了灵巧操作的本质：同一关节动作在不同接触模态下语义完全不同**。本轮引入 **ROS2 的 QoS / 生命周期 / Action 语义**，把动作空间升级为 **接触模态动作空间 A×ℳ**，把组合可行性升级为 **接触连续性 + QoS request/offer 匹配**。核心矛盾：H22：α_S 的边缘化会抹掉接触模态，导致「运动学可达但接触不可行」的假兼容；H23：云端承诺的接触可靠性与延迟，在边端 ROS2 中间件与实时控制预算下无法兑现，形成 QoS 过度承诺。

## 0. 直觉与动机

**灵感 1（ROS2 QoS → 接触服务质量契约）**
直觉：ROS2/DDS 中两个节点能否通信，不取决于「话题名相同」，而取决于 **QoS offer 是否满足 request**（reliability、deadline、durability、liveliness）。灵巧操作里，技能能否组合也不只取决于动作交集，而取决于 **接触质量承诺**：力闭合能否保持、接触迁移延迟是否够短、触觉历史能否跨技能保留、滑移监测心跳是否够快。于是把 QoS 逐项映射为接触量：`R ↔ 力闭合保持率/摩擦锥裕度 ε_fc`，`D ↔ 接触模态迁移延迟 τ_ct`，`DUR ↔ 触觉历史深度`，`L ↔ 滑移心跳`。这把第 54 轮的「动作占用」升级为「接触质量契约」。

**灵感 2（接触模态剖面 → 把 α_S(a) 细化为 α_S(a,m)）**
直觉：灵巧手的动作 a 在 `free/touch/stick/grasp/slip` 等接触模态 m 下具有不同可行性与风险。第 54 轮的 `α_S(a)=max_m α_S(a,m)` 是**粗化**，会把「抓取时可行、滑动时不可行」的动作误判为全覆盖。组合必须显式检查 **模态连续性** `Exit(S_i)∩Pre(S_j)≠∅` 或存在低风险模态迁移路径，而非仅做集合交。

**灵感 3（ROS2 request/offer 匹配 → 组合是 QoS 协商而非集合交）**
直觉：把每个技能看作一个 ROS2 **Action Server**，声明 `Q_offer`；任务/上游技能是 **Action Client**，声明 `Q_req`。组合 `S_i⊗S_j` 的 offer 取 meet（可靠性取 min、延迟取 max），request 取 join（可靠性取 max、延迟取 min）。只有当 `Q_offer ⪰ Q_req` 时边才成立。这把第 54 轮的 `compat≥θ_a` 从「几何重叠」升级为「几何重叠 ∧ 模态连续 ∧ QoS 可兑现」。

**灵感 4（ROS2 生命周期 → 接触模态的准入闸门）**
直觉：灵巧操作最危险的是「未准备好就进入 stick/grasp」。ROS2 lifecycle（configure→activate→deactivate→error）正好给出确定性闸门：只有技能节点处于 ACTIVE，且触觉/力传感器 liveliness 正常，才允许进入高接触模态；一旦滑移事件或心跳丢失，立即 deactivate 并重新协商 QoS。这把接触模态迁移变成**可审计的状态机**，而不是隐式代码路径。

**灵感 5（灵巧接触证书 → 力闭合 + 滑移界 + 触觉证据）**
直觉：第 54 轮的 `A_cert` 只记录动作占用，不记录**接触物理可行性**。本轮增加 **接触证书 `C_ct=(M_core, ε_fc, σ_slip, τ_ct, evidence)`**：核心接触模态集合、最小摩擦锥裕度、滑移上界、迁移延迟界、触觉证据哈希。`ε_fc>0` 表示严格力闭合；`σ_slip` 给出扰动下最大切向滑移。这样证书从「动作能到」变成「接触能稳」。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（接触模态动作空间）**
设接触模态集合 `ℳ = {free, approach, touch, stick, grasp, slip, release}`，偏序 `free ⊑ touch ⊑ stick ⊑ grasp` 表示接触强度。接触模态动作空间 `A^ℳ = A × ℳ`。技能 `S` 的接触剖面 `α_S : A×ℳ → [0,1]`，`α_S(a,m)=P(m 在执行 a 期间保持)`。第 54 轮剖面为其边缘化 `α_S^{54}(a)=max_m α_S(a,m)`。

**定义 122（模态连续性与迁移代价）**
模态迁移关系 `T_ℳ ⊆ ℳ×ℳ`，迁移代价 `c_mode(m→m') = settle_time + λ_slip·slip_risk`。技能 `S` 的入口/出口模态集为 `Pre(S), Exit(S)`。组合 `S_i⊗S_j` **模态连续** 当且仅当
```
∃ m∈Exit(S_i), m'∈Pre(S_j): dist_{T_ℳ}(m,m') ≤ τ_mode
```
其中 `dist` 为迁移图上的最短路代价。

**定义 123（接触 QoS 剖面与 request/offer 匹配）**
技能 QoS `Q_S=(R,D,DUR,L)`：
- `R`：力闭合保持率（或摩擦锥裕度 `ε_fc` 的下界）；
- `D`：接触迁移最大延迟 `τ_ct`；
- `DUR`：可跨技能保留的触觉历史深度；
- `L`：滑移监测心跳间隔。

匹配关系 `Q_offer ⪰ Q_req` 当且仅当
```
R_offer ≥ R_req ∧ D_offer ≤ D_req ∧ DUR_offer ≥ DUR_req ∧ L_offer ≤ L_req
```
组合语义：`Q_offer(S_i⊗S_j)=meet(Q_i,Q_j)`（R、DUR 取 min，D、L 取 max），`Q_req(S_i⊗S_j)=join(Q_i,Q_j)`（R、DUR 取 max，D、L 取 min）。含义：**组合只会削弱 offer、只会加强 request**，因此匹配是单调可判定的，不会出现「组合后 offer 反而变强」的悖论。

**定义 124（QoS 感知技能组合图）**
`G_S^Q=(V,E)`，边集
```
E = {(i,j) | compat_a ≥ θ_a ∧ 模态连续 ∧ Q_j^{offer} ⪰ Q_{i⊗j}^{req} ∧ c_trans + c_mode ≤ τ_e}
```
边证书 `C_comp^Q = (A_overlap, M_cont, QoS_witness, ρ_comp, C_ct)`。

**定义 125（灵巧接触证书）**
`C_ct=(M_core, ε_fc, σ_slip, τ_ct, evidence)`：
- `M_core = ⋂_S (Pre(S)∪Exit(S))` 为组合保证的核心接触模态；
- `ε_fc = min_i(μ_i‖f_{i,n}‖ - ‖f_{i,t}‖) > 0` 为严格力闭合裕度；
- `σ_slip` 为扰动下切向滑移上界；
- `τ_ct` 为实测模态迁移延迟；
- `evidence` 为触觉/力日志哈希。

**定义 126（云边 QoS 协商契约与生命周期闸门）**
`C_ce^Q=(Q_c^{req}, Q_e^{offer}, Q^*, Lifecycle_gate)`，其中 `Q^*` 为协商结果（逐分量取较强者），`Lifecycle_gate` 要求：进入 `{stick,grasp}` 前节点必须 `ACTIVE` 且 liveliness 正常；滑移事件或心跳超时触发 `ACTIVE→INACTIVE` 并重协商。若 `Q^* ≺ Q_c^{req}` 则 **拒绝** 或 **降级计划**（删除依赖强 QoS 的模态），并附风险标注。

**定义 127（接触-QoS 联合证书）**
`J^Q=(ρ, A_cert, γ_ce, δ_a, C_ct, Q^*, evidence)`。部署条件：
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ ε_fc≥ε_min ∧ σ_slip≤σ_max ∧ Q^* ⪰ Q_c^{req}
```

## 2. 关键算法 伪代码

### IP-121 CMS（Contact Mode Spectrum）

```python
def contact_profile(skill, A, M, sampler):
    alpha = {}
    for a in A:
        for m in M:
            if not sampler.mode_feasible(skill, a, m):
                alpha[(a, m)] = 0.0
            else:
                conf = sampler.confidence(skill, a, m)
                slip = sampler.estimate_slip(skill, a, m)
                alpha[(a, m)] = conf * (1.0 - slip)   # 滑移惩罚
    return alpha

def marginal_alpha(alpha, a):
    # 第 54 轮粗化剖面，仅用于兼容旧证书
    return max((v for (aa, m), v in alpha.items() if aa == a), default=0.0)

def mode_continuous(si, sj, tau_mode):
    d = shortest_path(si.mode_graph, sources=si.exit_modes,
                      targets=sj.pre_modes)
    return d <= tau_mode, d
```

### IP-122 CQM（Contact QoS Matching）

```python
def qos_match(offer, req):
    ok = (offer.R   >= req.R   and
          offer.D   <= req.D   and
          offer.DUR >= req.DUR and
          offer.L   <= req.L)
    witness = {'R': (offer.R, req.R), 'D': (offer.D, req.D),
               'DUR': (offer.DUR, req.DUR), 'L': (offer.L, req.L)}
    return ok, witness

def compose_offer(q1, q2):
    return QoS(R=min(q1.R, q2.R), D=max(q1.D, q2.D),
               DUR=min(q1.DUR, q2.DUR), L=max(q1.L, q2.L))

def compose_request(q1, q2):
    return QoS(R=max(q1.R, q2.R), D=min(q1.D, q2.D),
               DUR=max(q1.DUR, q2.DUR), L=min(q1.L, q2.L))
```

### IP-123 QSC（QoS-aware Skill Composition Graph）

```python
def build_qos_graph(skills, theta_a, tau_e, tau_mode, K):
    G = nx.DiGraph()
    for i, si in skills:
        for j, sj in skills:
            if i == j:
                continue
            compat = jaccard(si.alpha, sj.alpha)
            m_ok, c_mode = mode_continuous(si, sj, tau_mode)
            c_trans = transition_cost(si, sj)
            q_ok, wit = qos_match(sj.qos_offer,
                                  compose_request(si.req, sj.req))
            if compat >= theta_a and m_ok and q_ok \
               and c_trans + c_mode <= tau_e:
                G.add_edge(i, j, compat=compat, c_mode=c_mode,
                           qos_witness=wit,
                           rho_comp=compose_robustness(si.rho, sj.rho, K),
                           C_ct=contact_certificate([si, sj],
                                                    budgets.tactile_log,
                                                    budgets.mu, budgets))
    return G
```

### IP-124 DCC（Dexterous Contact Certificate）

```python
def contact_certificate(skill_seq, tactile_log, mu, budgets):
    M_core = reduce(intersection,
                    [s.pre_modes | s.exit_modes for s in skill_seq])
    eps_fc = min(e for (_, e) in friction_cone_margins(tactile_log, mu))
    sigma_slip = max_slip_velocity(tactile_log)
    tau_ct = measure_mode_transition_latency(skill_seq)
    ok = (eps_fc >= budgets.eps_min and
          sigma_slip <= budgets.sigma_max and
          tau_ct <= budgets.tau_ct)
    return ContactCert(M_core, eps_fc, sigma_slip, tau_ct,
                       hash(tactile_log)), ok
```

### IP-125 QNC（QoS Negotiation & Lifecycle Gate）

```python
def negotiate_and_gate(P_c, edge, Q_req):
    Q_offer = edge.advertise_qos()
    if not qos_match(Q_offer, Q_req)[0]:
        Q_soft = edge.best_effort_qos()
        if not qos_match(Q_soft, relax(Q_req))[0]:
            return ('reject', 'qos_mismatch', Q_offer, Q_req)
        P_c = degrade_plan(P_c, Q_soft)          # 删除强 QoS 依赖模态
        risk = annotate_degradation(P_c, Q_soft, Q_req)
    else:
        risk = None
    for node in P_c.nodes:
        if node.modes & {STICK, GRASP}:
            edge.configure(node)                 # on_configure
            edge.activate(node)                  # on_activate
            if not edge.liveliness_ok(node):
                edge.deactivate(node)            # ACTIVE -> INACTIVE
                return ('renegotiate', node, 'liveliness_lost')
        fb = edge.run(node)                      # goal / feedback / result
        if fb.slip_event:
            edge.deactivate(node)
            return ('renegotiate', node, fb, tighten(Q_req, fb))
    return ('ok', P_c, risk)
```

### IP-126 JQC（Joint Contact-QoS Certificate）

```python
def joint_contact_qos_certificate(skill_seq, gamma_ce, edge, budgets):
    base = joint_certificate(skill_seq, gamma_ce,
                             budgets.delta_a, budgets.rho_min)
    if base[0] != 'ok':
        return base
    C_ct, ct_ok = contact_certificate(skill_seq, budgets.tactile_log,
                                      budgets.mu, budgets)
    if not ct_ok:
        return ('reject', 'contact_fail', C_ct)
    Q_req = compose_request_all([s.req for s in skill_seq])
    Q_star, q_ok, wit = negotiate_contract(edge, Q_req)
    if not q_ok:
        return ('reject', 'qos_fail', Q_star, wit)
    return ('ok', JointQoSCert(base[1], C_ct, Q_star, wit))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CMS | O(\|S\|·\|A\|·\|ℳ\|) | O(\|A\|·\|ℳ\|) | 模态采样覆盖、滑移估计无偏 |
| CQM | O(\|Q\|) | O(1) | 偏序 sound、meet/join 单调 |
| QSC | O(\|S\|²·(\|A\|\|ℳ\|+\|ℳ\|²+\|Q\|)) | O(\|S\|²) | 模态连续、QoS 匹配、成本单调 |
| DCC | O(\|S\|·\|ℳ\|+\|tactile\|) | O(\|tactile\|) | ε_fc>0、触觉证据可复核 |
| QNC | O(\|P\|·(τ_neg+τ_life)) | O(\|P\|) | 协商收敛、生命周期原子 |
| JQC | O(\|S\|·\|A\|\|ℳ\|+\|tactile\|+\|Q\|) | O(\|A\|\|ℳ\|+\|tactile\|) | 联合证书 sound |

**正确性定理（Contact-QoS Composition Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** 接触剖面由结构化仿真 + 触觉校准，模态 macro-F1 ≥ 0.85，滑移估计误差 ≤ δ_s；**(A30)** 摩擦锥裕度估计误差 ≤ δ_fc 且触觉日志可复核；**(A31)** QoS 协商在 τ_neg 内收敛，生命周期迁移原子。则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(模态错配) - P(ε_fc<ε_min)
              - P(Q^*≺Q_req) - β_E
```
其中 `P(模态错配) ≤ (1-F1_mode) + δ_s`。关键：**组合前先验模态连续**，**offer 只降不升、request 只升不降**，**进入高接触模态前必须通过生命周期闸门**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 稀有 stick-slip 模态欠采样 | 高 | 触觉主动探索 + 对抗采样 + 模态覆盖下界 |
| 边端 QoS 过度承诺（best-effort 冒充 reliable） | 高 | 实测力闭合/延迟回归校验 + 契约违约罚分 |
| Sim-to-Real 接触鸿沟主导误差 | 高 | 域随机化 + 在线触觉校准 + 保守 ε_fc |
| lifecycle 抖动 / 协商震荡 | 中 | 滞回 + 最小驻留时间 + 锚点回滚 |
| 摩擦系数 μ 时变导致 ε_fc 失真 | 高 | μ 在线辨识 + ε_fc 置信下界 |

## 6. 本轮最大风险

**一句话**：把 ROS2 QoS 语义注入灵巧操作后，组合证书的 soundness **同时押注在接触模态剖面的采样完备性、摩擦锥裕度/滑移界的触觉可观测性、以及边端 QoS 承诺的真实兑现**；一旦稀缺 stick-slip 模态漏采或边端以 best-effort 冒充力闭合可靠，系统会认证出一批「几何与 QoS 都通过、真实接触却滑移」的组合，故必须以 **模态覆盖下界 + 实测力闭合回归 + 保守 ε_fc 置信下界** 三重护栏，宁可降级到 free/touch 模态，也不把接触质量的「纸面承诺」当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-DexQoS（CMS×CQM×QSC×DCC×QNC×JQC）

> 承接第 54 轮产物 v31。本轮把 **ROS2 的 QoS / 生命周期 / Action 语义**注入灵巧操作，在「动作-鲁棒性双证书」之上增加 **接触模态维与接触质量契约**：
> - **CMS（Contact Mode Spectrum）**：接触模态动作剖面 `α_S(a,m)`，修复第 54 轮边缘化导致的假兼容；
> - **CQM（Contact QoS Matching）**：ROS2 式 request/offer 匹配，定义组合语义 meet/join；
> - **QSC（QoS-aware Skill Composition）**：模态连续 + QoS 可兑现的组合图 `G_S^Q`；
> - **DCC（Dexterous Contact Certificate）**：力闭合裕度 / 滑移界 / 触觉证据证书 `C_ct`；
> - **QNC（QoS Negotiation & Lifecycle Gate）**：云边协商 + configure/activate/deactivate 准入闸门；
> - **JQC（Joint Contact-QoS Certificate）**：接触-QoS 联合证书 `J^Q`。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/117/118/120。

## 0. ROS2 → 方案映射（本轮跨学科桥）

| ROS2 / DDS 概念 | 本文对应量 | 在灵巧操作中的作用 |
|---|---|---|
| QoS `reliability` | 力闭合保持率 `R` / 摩擦锥裕度 `ε_fc` | 组合后接触能否保持 |
| QoS `deadline` | 接触模态迁移延迟 `τ_ct` | 接触切换实时性契约 |
| QoS `durability` | 触觉历史深度 `DUR` | 跨技能保留接触状态 |
| QoS `liveliness` | 滑移监测心跳 `L` | 失联/滑移即退避 |
| Request/Offer matching | `Q_offer ⪰ Q_req` | 组合可行性判定 |
| Lifecycle node | `configure→activate→deactivate→error` | 高接触模态准入闸门 |
| Action goal/feedback/result | 任务目标 / 滑移反馈 / 结果 | 长时程灵巧操作分段 |
| Executor / callback group | 边端实时控制回调 | 控制周期与优先级保障 |
| `ros2_control` hardware interface | 关节 + 触觉硬件抽象 | 1kHz 级控制与传感 |
| TF2 | 接触坐标系 | 接触位姿一致性 |

> 设计原则：**ROS2 的 QoS 是「声明式契约」，本方案把它变成「可判定 + 可审计的接触证书」**；ROS2 的 lifecycle 是「确定性状态机」，本方案把它变成「接触模态的安全闸门」。

## 3. 关键算法 伪代码

### IP-121 CMS

```python
def contact_profile(skill, A, M, sampler):
    alpha = {}
    for a in A:
        for m in M:
            if not sampler.mode_feasible(skill, a, m):
                alpha[(a, m)] = 0.0
            else:
                conf = sampler.confidence(skill, a, m)
                slip = sampler.estimate_slip(skill, a, m)
                alpha[(a, m)] = conf * (1.0 - slip)
    return alpha

def marginal_alpha(alpha, a):
    return max((v for (aa, m), v in alpha.items() if aa == a), default=0.0)

def mode_continuous(si, sj, tau_mode):
    d = shortest_path(si.mode_graph, sources=si.exit_modes,
                      targets=sj.pre_modes)
    return d <= tau_mode, d
```

### IP-122 CQM

```python
def qos_match(offer, req):
    ok = (offer.R   >= req.R   and
          offer.D   <= req.D   and
          offer.DUR >= req.DUR and
          offer.L   <= req.L)
    witness = {'R': (offer.R, req.R), 'D': (offer.D, req.D),
               'DUR': (offer.DUR, req.DUR), 'L': (offer.L, req.L)}
    return ok, witness

def compose_offer(q1, q2):
    return QoS(R=min(q1.R, q2.R), D=max(q1.D, q2.D),
               DUR=min(q1.DUR, q2.DUR), L=max(q1.L, q2.L))

def compose_request(q1, q2):
    return QoS(R=max(q1.R, q2.R), D=min(q1.D, q2.D),
               DUR=max(q1.DUR, q2.DUR), L=min(q1.L, q2.L))
```

### IP-123 QSC

```python
def build_qos_graph(skills, theta_a, tau_e, tau_mode, K, budgets):
    G = nx.DiGraph()
    for i, si in skills:
        for j, sj in skills:
            if i == j:
                continue
            compat = jaccard(si.alpha, sj.alpha)
            m_ok, c_mode = mode_continuous(si, sj, tau_mode)
            c_trans = transition_cost(si, sj)
            q_ok, wit = qos_match(sj.qos_offer,
                                  compose_request(si.req, sj.req))
            if compat >= theta_a and m_ok and q_ok \
               and c_trans + c_mode <= tau_e:
                G.add_edge(i, j, compat=compat, c_mode=c_mode,
                           qos_witness=wit,
                           rho_comp=compose_robustness(si.rho, sj.rho, K),
                           C_ct=contact_certificate([si, sj],
                                                    budgets.tactile_log,
                                                    budgets.mu, budgets))
    return G
```

### IP-124 DCC

```python
def contact_certificate(skill_seq, tactile_log, mu, budgets):
    M_core = reduce(intersection,
                    [s.pre_modes | s.exit_modes for s in skill_seq])
    eps_fc = min(e for (_, e) in friction_cone_margins(tactile_log, mu))
    sigma_slip = max_slip_velocity(tactile_log)
    tau_ct = measure_mode_transition_latency(skill_seq)
    ok = (eps_fc >= budgets.eps_min and
          sigma_slip <= budgets.sigma_max and
          tau_ct <= budgets.tau_ct)
    return ContactCert(M_core, eps_fc, sigma_slip, tau_ct,
                       hash(tactile_log)), ok
```

### IP-125 QNC

```python
def negotiate_and_gate(P_c, edge, Q_req):
    Q_offer = edge.advertise_qos()
    if not qos_match(Q_offer, Q_req)[0]:
        Q_soft = edge.best_effort_qos()
        if not qos_match(Q_soft, relax(Q_req))[0]:
            return ('reject', 'qos_mismatch', Q_offer, Q_req)
        P_c = degrade_plan(P_c, Q_soft)
        risk = annotate_degradation(P_c, Q_soft, Q_req)
    else:
        risk = None
    for node in P_c.nodes:
        if node.modes & {STICK, GRASP}:
            edge.configure(node)
            edge.activate(node)
            if not edge.liveliness_ok(node):
                edge.deactivate(node)
                return ('renegotiate', node, 'liveliness_lost')
        fb = edge.run(node)
        if fb.slip_event:
            edge.deactivate(node)
            return ('renegotiate', node, fb, tighten(Q_req, fb))
    return ('ok', P_c, risk)
```

### IP-126 JQC

```python
def joint_contact_qos_certificate(skill_seq, gamma_ce, edge, budgets):
    base = joint_certificate(skill_seq, gamma_ce,
                             budgets.delta_a, budgets.rho_min)
    if base[0] != 'ok':
        return base
    C_ct, ct_ok = contact_certificate(skill_seq, budgets.tactile_log,
                                      budgets.mu, budgets)
    if not ct_ok:
        return ('reject', 'contact_fail', C_ct)
    Q_req = compose_request_all([s.req for s in skill_seq])
    Q_star, q_ok, wit = negotiate_contract(edge, Q_req)
    if not q_ok:
        return ('reject', 'qos_fail', Q_star, wit)
    return ('ok', JointQoSCert(base[1], C_ct, Q_star, wit))
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CMS | O(\|S\|·\|A\|·\|ℳ\|) | O(\|A\|·\|ℳ\|) | 模态覆盖 ≥ 95%，滑移估计无偏 |
| CQM | O(\|Q\|) | O(1) | 偏序 sound，meet/join 单调 |
| QSC | O(\|S\|²·(\|A\|\|ℳ\|+\|ℳ\|²+\|Q\|)) | O(\|S\|²+\|E\|) | 模态连续、QoS 匹配、路径最优 |
| DCC | O(\|S\|·\|ℳ\|+\|tactile\|) | O(\|tactile\|) | ε_fc>0，触觉证据可复核 |
| QNC | O(\|P\|·(τ_neg+τ_life)) | O(\|P\|) | 协商收敛、生命周期原子 |
| JQC | O(\|S\|·\|A\|\|ℳ\|+\|tactile\|+\|Q\|) | O(\|A\|\|ℳ\|+\|tactile\|) | 联合证书 sound，预算闭合 |

**正确性定理（Contact-QoS Composition Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** 接触剖面由结构化仿真 + 触觉校准，模态 macro-F1 ≥ 0.85，滑移估计误差 ≤ δ_s；**(A30)** 摩擦锥裕度估计误差 ≤ δ_fc 且触觉日志可复核；**(A31)** QoS 协商在 τ_neg 内收敛，生命周期迁移原子。则部署成功概率
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(模态错配) - P(ε_fc<ε_min)
              - P(Q^*≺Q_req) - β_E
```
其中 `P(模态错配) ≤ (1-F1_mode) + δ_s`。

关键三点：
1. **组合前先验模态连续**（`dist_{T_ℳ}(Exit(S_i),Pre(S_j)) ≤ τ_mode`）；
2. **offer 只降不升、request 只升不降**，保证 QoS 匹配单调可判定；
3. **进入 stick/grasp 前必须通过 lifecycle 闸门**，滑移即降级重协商。

## 6. 本轮最大风险

**一句话**：把 ROS2 QoS 语义注入灵巧操作后，组合证书的 soundness **同时押注在接触模态剖面的采样完备性、摩擦锥裕度/滑移界的触觉可观测性、以及边端 QoS 承诺的真实兑现**；一旦稀缺 stick-slip 模态漏采或边端以 best-effort 冒充力闭合可靠，系统会认证出一批「几何与 QoS 都通过、真实接触却滑移」的组合，故必须以 **模态覆盖下界 + 实测力闭合回归 + 保守 ε_fc 置信下界** 三重护栏，宁可降级到 free/touch 模态，也不把接触质量的「纸面承诺」当作部署前提。
