# 第 44 轮（新循环第 4 轮） · Reward-Cert × Semantic-Cert：把「奖励设计」与「语义建图」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但它仍压着两个更深、更基础的假设：**(H1) 语义地图被当作事实输入**——VLM/分割给出的「门 / 可通行 / 可抓取」标签被直接喂给几何证书与规划，标签错一个「可通行」，几何证书就会在一个错误的世界模型上 sound；**(H2) 奖励被当作证书之外的标量目标**——学习与规划只在证书允许集里最大化 r，却从不审计 r 是否正把策略拽向证书的**语义盲区**。本轮灵感词「奖励设计」「语义建图」精确命中这两个假设：语义建图决定「世界是什么」，奖励设计决定「什么值得做」，二者相乘正是 reward hacking 的新温床——策略学会的不是任务，而是**标签的漏洞**。本轮的核心原则只有一句：**按证取酬——奖励只能在证书可证实的语义事实上取值。**

## 0. 直觉与动机

**灵感 1（语义建图 → 标签不是事实，是可证集合）**：直觉上，机器人看到「一扇玻璃门」，错误的点标签会让它撞上去；但人也不是把「门」当绝对事实，而是带着不确定性地使用它。于是把语义地图从「每格一个标签」升级为「每格一个**校准标签集** C_sem(x)」，再把它转成**可负担性证书**（affordance certificate）：A_core(x) = ⋂_{l∈C_sem(x)} SafeActions(l)。若标签集里「玻璃墙」与「门」的可用动作没有公共核，则该区域判为**证书禁区**，无论 VLM 多有信心。这与第 43 轮「收缩免费、扩张持证」同构：标签集求交只会收缩可行域，天然保 sound；想扩张，必须拿覆盖率与漂移证据来换。

**灵感 2（奖励设计 → 奖励是假设，不是真理；证书才是裁判）**：直觉上，奖励设计者写「到达目标 +10、碰撞 −100」，以为在教任务，实际可能在教「如何绕开验证器」。因此把奖励拆成三部分：任务项 r_task、**证书化势函数塑形** PBRS(Φ_cert)、以及违规罚项。关键约束是 Φ_cert 只能定义在**被语义证书证实的事实**上（例如「已证实的可通行区域连通性」），且在**歧义/禁区上取常值或保守值**——这样势函数塑形不改变证书化子 MDP 的最优策略，只加速学习；奖励永远不能买来安全域。对个性化，偏好只能在 C_u 内部**重排序**动作，不能扩大 C_u，这是第 43 轮「人格契约」在奖励空间的对偶。

**灵感 3（耦合 → 语义-奖励证书飞轮 + 语义租约）**：语义地图会漂移（门开/关、物体被移动、光照变化），而奖励特征恰恰建立在这些语义事实上，于是漂移会让「已经学会的高奖励行为」变成「利用过期标签的投机行为」。解法是复用第 43 轮的租约机制：每条语义事实携带 (label, τ, λ_sem)，过期即降级为「未知」再降级为「禁区」；同时用一个**证书奖励比** CRR = E[r_cert]/E[r] 与**盲区收益占比** BS 来审计 reward hacking——高奖励若大量来自低证书置信区域，即红牌。反例回灌语义地图修复与奖励修复，形成「语义→奖励→证书→语义」的新飞轮。

**耦合升级**：SCM（语义证书层）把 VLM 输出编译成带覆盖率与租约的可用性证书；CRE（奖励证书引擎）把奖励规格编译成证书化势函数 + 受约束目标 + 反作弊监控；SRV（语义-奖励验证器）在仿真里做标签投毒、语义漂移与 reward hacking 搜索。四层架构由 v8 的「仿真-检索-边缘 + 人格 + 并发」升级为 v9 的「仿真-检索-边缘 + 人格 + 并发 + **语义证书 + 奖励证书**」。

## 1. 形式化定义（增量：定义 44–50）

**定义 44（证书化语义地图）**：语义地图 M: X→2^L 给出区域标签集。**证书化语义地图** M̂^α = (C_sem, L_sem) 对每个区域 x 输出标签预测集 C_sem(x) ⊆ L，并声称区域型条件覆盖 P(l*(x) ∈ C_sem(x) | region_type(x)=g) ≥ 1−α_g。由于空间标签强相关、可交换性在像素/栅格上不成立，这里**显式声明假设**：覆盖由「按区域类型分层的加权共形 / 分块共形」或「风险控制预测集 RCPS」在留出地图上校准得到；E95 必须验证该假设，否则退回「语义全未知」的几何兜底。**语义租约** ℓ_sem=(l, τ, λ_sem, x)，新鲜度判据与定义 41 同构。

**定义 45（可负担性证书与语义禁区）**：把标签经本体 O 映射为动作可用性 SafeActions(l) ⊆ A（可通行、可支撑、可抓取、危险）。区域 x 的**可用性证书**为公共核 A_core(x) = ⋂_{l∈C_sem(x)} SafeActions(l)。**命题（收缩 sound）**：若真实标签 l*(x) ∈ C_sem(x)，则任何 a ∈ A_core(x) 在真实语义下安全；反之 A_core(x)=∅ 时该区域为**证书禁区**，必须按障碍/未知处理。**推论**：语义歧义只会让可行域收缩，绝不产生虚假通行；其代价是可用性下降，必须由 E96 度量并允许协商。

**定义 46（语义漂移与租约 sound 性）**：设语义事实的真实变化率满足每单位时间最多以 λ_sem 的概率翻转（由占用栅格 churn、场景类别转移统计给出界）。**语义新鲜度判据**：事实在 τ 签发、时刻 t 使用时，仅当 t−τ ≤ T_sem(λ_sem, δ) 且未触发漂移检测（page-Hinkley / 贝叶斯变点）才可用；否则降级 ambiguous→forbidden。**注**：语义租约与定义 41 的边际租约是同一代数结构在不同对象上的实例化——这是把「新鲜度」提升为跨层通用契约的关键一步。

**定义 47（证书化奖励设计）**：奖励规格 R=(r_task, Φ_cert, d_cert, ε_h)。**证书化奖励**定义为 r^cert(s,a) = r_task(s,a) + γΦ_cert(s′) − Φ_cert(s)，其中势函数 Φ_cert 只依赖**已证实的语义事实**（C_sem 的条件可满足部分与 A_core），并在 ambiguous/forbidden 区域取常值。**受限 PBRS 引理**：若把状态空间按证书划分为 certified / ambiguous / forbidden 三类、且策略被禁止进入 forbidden、Φ_cert 在 ambiguous 上为常数，则在 certified 子 MDP 上势函数塑形不改变最优策略（标准 PBRS 不变性成立），故塑形只加速学习、不改变「证书允许集内何为最优」。奖励永远不能扩大 C_global∩Π_u。

**定义 48（语义可利用性与 reward hacking 证书）**：对策略 π 定义**证书奖励比** CRR(π) = E_{s∼d_π}[r^cert]/E_{s∼d_π}[r] 与**盲区收益占比** BS(π) = 来自 ambiguous 区域（且可被误导动作到达）的期望收益 / 总期望收益。**可审计判据**：策略 π 被接受，当且仅当 CRR(π) ≥ 1−ε_h 且 BS(π) ≤ ε_h 且安全证书违例 = 0。**命题**：若所有被计酬的语义事实都在证书覆盖范围内，则 BS=0；因此 BS 是「奖励是否已经跑到证书之外取值」的直接证据，而不只是一个软指标。

**定义 49（受约束的个性化奖励）**：人格化奖励 r_u = r_task + w_u·φ_pref(·; u)，其中 φ_pref 由成对偏好学习得到并做校准。**约束保持命题**：个性化只允许在证书允许集 C_u = C_global∩Π_u 内对动作**重排序**；若 argmax_{a∈C_u} r_u 与安全最优解冲突，则以证书为准（安全优先于偏好）。即偏好可以改变「先做哪个安全动作」，不能改变「哪些动作安全」。这把第 43 轮的「收缩免费、扩张持证」精确搬到奖励空间：**偏好免费重排，扩张必须持证**。

**定义 50（语义-奖励联合证书与闭环）**：联合证书 SRC = (C_sem 覆盖率, A_core sound 性, PBRS 不变性, CRR/BS 反作弊, 语义租约新鲜度)。训练闭环：语义证书 → 势函数塑形 → 策略改进 → 影子证书 → 语义对抗反例（投毒/漂移/歧义诱导）→ **语义地图修复 + 奖励规格修复** → 重训。**定理（闭环可靠性）**：若每次发布的策略都满足 SRC 且语义租约未过期，则闭环不产生「由语义错误或奖励投机导致」的新增不安全行为；反例只能收紧 C_sem 或修改 r，不能放宽证书。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 SEMANTIC-CERTIFIED-MAPPING（语义证书地图 SCM）
1. **标签集化建图**：VLM/分割输出从点标签改为校准标签集 C_sem(x)，按区域类型分层共形/RCPS 校准，输出覆盖率证据。
2. **可负担性证书**：经本体 O 把标签集编译为 A_core(x)，空核即证书禁区；向几何证书与规划导出「certified / ambiguous / forbidden」三态语义层。
3. **语义租约与漂移检测**：每条事实带 (l, τ, λ_sem, x)，变点检测 + 租约过期即降级，防止过期标签被当作事实。
4. **地图修复接口**：接收 SRV 的投毒/漂移反例，最小代价地收缩标签集或把区域降级，绝不无证据地扩张。

### 2.2 IP-61 CERTIFIED-REWARD-ENGINE（奖励证书引擎 CRE）
1. **奖励规格编译**：R=(r_task, Φ_cert, d_cert, ε_h) → 证书化势函数 + 受约束（CMDP）目标；势函数只读证书化语义事实。
2. **受限 PBRS 塑形**：在 certified 子 MDP 上保证策略不变性；ambiguous 上取常值、forbidden 不可达。
3. **反 reward hacking 监控**：在线计算 CRR、BS、证书影子价格；超阈值即冻结塑形或回退稀疏任务奖励。
4. **受约束偏好/人格奖励**：偏好学习只在 C_u 内重排序，输出「偏好-安全冲突」审计记录；绝不把偏好写进安全阈值。

### 2.3 IP-62 SEMANTIC-REWARD-VALIDATOR（语义-奖励验证器 SRV）
1. **标签投毒与语义漂移注入**：把「玻璃墙标成门」「可抓取标成危险」等对抗标签注入仿真，测 A_core 与几何证书的 sound 性。
2. **reward hacking 搜索**：用进化/梯度搜索策略在语义盲区刷分，度量 CRR/BS 与真实任务完成度的背离。
3. **反事实地图评估**：同一策略在 M̂^α 的多个采样地图上跑，测收益方差与最坏情况安全违例。
4. **联合证书回归**：每次语义地图/奖励规格更新跑 E95–E102，把反例回灌 SCM 与 CRE。

回退：E95 覆盖失效 → 语义全未知，退回纯几何（v8 行为）；E96 空核识别失败 → 语义标签仅用于提示，不进入证书；E97 不变性被破坏 → 关闭塑形，只用稀疏任务奖励；E98 hacking 无法界定 → 冻结奖励学习、仅用固定成本约束；E99 反事实最坏违例 → 缩小语义可用区域并提高几何保守度；E100 偏好扩域 → 关闭人格奖励，仅保留契约收缩；E101 漂移过快 → 缩短语义租约并在线重标注；任何红线失败 → 熔断回退 v20。

## 5. 本轮最大风险

**一句话**：语义覆盖的空间相关性与非可交换性会让定义 44 的覆盖率假设在真实漂移下静默失效，而奖励设计恰恰会主动搜索证书未覆盖的语义盲区——最危险的不是策略学错任务，而是**奖励把「验证器没覆盖的语义」变成高收益区，使证书体系被自己的标签本体（label ontology）从内部攻破**；因此 E95（覆盖）与 E98（CRR/BS）必须设为红线，并默认回退到「语义全未知 + 纯几何 + 稀疏奖励」这条不依赖语义与奖励假设的底线。

# 第 44 轮产物 · 创新点清单 v21：Reward-Cert × Semantic-Cert（SCM × CRE × SRV）× 「按证取酬」的语义-奖励证书闭环（四层架构 v9）

> 承接第 43 轮产物 v20。本轮**增量插入** IP-60/61/62，并升级 IP-35/44/45/47/49/50/51/52/54/55/56/58；不推倒既有层级。核心是把 v20 的「人格 + 并发」证书闭环，升级为同时满足 **语义可信（标签集收缩免费、扩张持证）** 与 **奖励可信（塑形不变、按证取酬）** 的可验证闭环。一句话主线：**语义建图回答「世界是什么」，奖励设计回答「什么值得做」，证书负责保证两者都不能越界。**

## 0. 核心 IP 设计

## 1. 符号体系（增量：定义 44–50 符号）

| 符号 | 含义 | 定义 |
|---|---|---|
| C_sem(x) ⊆ L | 校准标签集 | 区域型条件覆盖 ≥ 1−α_g；由分层/分块共形或 RCPS 校准 |
| ℓ_sem=(l,τ,λ_sem,x) | 语义租约 | 标签、签发时刻、语义漂移率、区域 |
| SafeActions(l) | 标签→可用动作 | 本体 O 映射：可通行/可支撑/可抓取/危险 |
| A_core(x)=⋂_{l∈C_sem(x)} SafeActions(l) | 可用性证书 | 公共核；空核 ⇒ 证书禁区 |
| SemMode | 三态语义层 | certified / ambiguous / forbidden |
| Φ_cert(s) | 证书化势函数 | 只依赖已证实语义事实；ambiguous 取常值 |
| r^cert = r_task + γΦ_cert(s′)−Φ_cert(s) | 证书化奖励 | 塑形不改变 certified 子 MDP 最优策略 |
| CRR(π)=E[r^cert]/E[r] | 证书奖励比 | 越高越可信；低 ⇒ 奖励跑到证书外 |
| BS(π) | 盲区收益占比 | 来自 ambiguous 区域的可被误导收益比例 |
| SRC=(cov, A_core, PBRS, CRR/BS, lease) | 语义-奖励联合证书 | 五元联合发布门槛 |

## 2. 关键算法（伪代码）

### IP-60 SCM：标签集建图、可用性证书与语义租约
```
def build_certified_semantic_map(obs, calib, alpha_g):
    labels = vlm_label_sets(obs)                 # 每区域返回候选标签与分数
    C_sem  = {}
    for x in regions(obs):
        g = region_type(x)                       # 走廊/门口/桌面/...
        q = conformal_quantile(calib[g], 1 - alpha_g)   # 分层/分块/RCPS
        C_sem[x] = prediction_set(labels[x], q)
    return SemanticMap(C_sem, evidence=coverage_audit(C_sem, calib))

def affordance_certificate(C_sem, ontology):
    A_core = {}
    for x, Lx in C_sem.items():
        core = set(actions_all)
        for l in Lx:
            core &= ontology.SafeActions(l)      # 求交 => 只收缩，天然 sound
        A_core[x] = core
    mode = {x: ('forbidden' if not A_core[x]
                else 'certified' if len(C_sem[x]) == 1
                else 'ambiguous') for x in C_sem}
    return A_core, mode

def issue_semantic_lease(fact, churn_estimate):  # 定义 46
    lam = semantic_drift_rate(churn_estimate)    # 由占用 churn/类别转移估计
    return SemLease(l=fact.label, tau=monotonic_now(), lam=lam, x=fact.region)

def semantic_fresh(lease, t, drift_detector):
    return (t - lease.tau) <= T_sem(lease.lam, delta) and not drift_detector.triggered

def repair_map(C_sem, counterexample):           # 只收缩，不无证扩张
    x = counterexample.region
    if counterexample.kind == 'poison':
        C_sem[x] = tighten(C_sem[x], counterexample.exclude_label)
    elif counterexample.kind == 'drift':
        C_sem[x] = set(L)                        # 降级为未知 => 禁区/几何兜底
    return C_sem
```

### IP-61 CRE：受限 PBRS、受约束目标与反作弊
```
def compile_reward(reward_spec, sem_map, A_core):
    r_task = reward_spec.r_task
    Phi = lambda s: certified_potential(s, sem_map.C_sem, A_core)  # 只读证书事实
    Phi = make_constant_on(Phi, sem_map.ambiguous_regions)         # 定义 47
    F   = lambda s, a, s2: gamma * Phi(s2) - Phi(s)                # PBRS
    r_cert = lambda s, a: r_task(s, a) + F(s, a, next_state(s, a))
    return r_cert, Phi, reward_spec.eps_h

def constrained_policy_opt(r_cert, cost_cert, C_u, d_max):
    # CMDP：最大化证书化奖励，硬约束安全成本（证书）与人格契约
    return solve_cmdp(objective=r_cert,
                      cost=cost_cert, cost_limit=d_max,
                      action_mask=C_u)             # 偏好只能重排，不能扩域

def reward_hacking_monitor(traj, r_cert, sem_map):
    r  = sum(traj.rewards)                         # 真实计酬（含未证书化语义）
    rc = sum(r_cert(s, a) for s, a in traj)
    CRR = rc / (r + eps)
    BS  = sum(reward for (s, a, reward) in traj
              if sem_map.mode[s.region] == 'ambiguous') / (r + eps)
    return Audit(CRR=CRR, BS=BS,
                 flag = (CRR < 1 - eps_h) or (BS > eps_h))
```

### IP-62 SRV：投毒、hacking 搜索与反事实地图
```
def adversarial_semantic_validation(policy, sem_map, budget):
    # 1) 标签投毒：把危险目标标成可通行/可抓取，测 A_core sound 性
    poisoned = inject_label_poison(sem_map, allowed=budget.labels)
    v1 = safety_violations(policy, poisoned)
    # 2) reward hacking 搜索：在语义盲区最大化 r
    hacker = search_policy(objective=lambda pi: reward_in_blindspots(pi, sem_map),
                           steps=budget.steps)
    v2 = reward_hacking_monitor(rollout(hacker), sem_map)
    # 3) 反事实地图：同一策略在 M̂ 的多个采样地图上评估
    losses = [eval_policy(policy, sample_map(sem_map)) for _ in range(budget.maps)]
    return Report(poison_violations=v1, hacking=v2,
                  worst_case_loss=max(losses), counterexamples=collect(...))

def certify_release(policy, sem_map, reward_audit, SRC_thresholds):
    return (coverage_ok(sem_map)             and
            affordance_sound(sem_map)        and
            PBRS_invariant(policy)           and
            not reward_audit.flag            and
            semantic_leases_fresh(sem_map))
```

### IP-49/51 升级：语义守卫与几何求交
```
def car_transition_guard_v9(e, x, cert_obj, persona, lease, sem_map, t):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m = min(cert_obj.lookup(x).m_lo[e],
            lease.m - lease.lam * (t - lease.tau),
            persona_cap[e](persona))
    mode = sem_map.mode[x.region]
    if mode == 'forbidden':                       # 证书禁区硬禁入
        return False
    if mode == 'ambiguous' and action[e] not in sem_map.A_core[x.region]:
        return False                              # 歧义区只允许公共核
    return m >= theta and lease_valid(lease, theta, t)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-60 标签集建图 | O(#区域 × |L|) | 地图 O(#区域×|C_sem|) | 区域型覆盖 ≥1−α_g（依赖校准假设，E95 验证） |
| IP-60 可用性证书 | O(#区域 × |C_sem| × |A|) | O(#区域×|A|) | A_core=⋂SafeActions ⟹ 标签不确定时只收缩，sound |

| IP-61 奖励编译 | O(1) 编译 + O(|Φ|) 评估 | O(|Φ|) | Φ 只读证书事实 ⟹ 塑形不越界 |
| IP-61 受限 PBRS | O(1)/步 | O(1) | certified 子 MDP 上最优策略不变（标准 PBRS） |
| IP-61 受约束优化 | CMDP 求解（离线/近线） | 策略+对偶变量 | 动作掩码 C_u ⟹ 偏好不能扩域 |

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 语义覆盖依赖空间可交换性，真实漂移下条件覆盖静默失效 | 高 | E95 红线；按区域类型分块/加权共形 + RCPS；漂移即降级为未知；默认几何兜底 |
| 奖励主动搜索证书盲区（reward hacking），标签本体成为攻击面 | 高 | E98 红线；CRR/BS 在线审计；塑形只读证书事实；超阈冻结塑形 |

| PBRS 用近似地图势函数，实际改变 MDP 最优策略 | 中-高 | 只在 certified 子 MDP 声明不变性；ambiguous 取常值；E97 实测策略差异 |

## 6. 本轮最大风险

**一句话**：语义覆盖的空间相关性与非可交换性会让定义 44 的覆盖率假设在真实漂移下静默失效，而奖励设计恰恰会主动搜索证书未覆盖的语义盲区——最危险的不是策略学错任务，而是**奖励把「验证器没覆盖的语义」变成高收益区，使证书体系被自己的标签本体（label ontology）从内部攻破**；因此 E95（覆盖）与 E98（CRR/BS）必须设为红线，并默认回退到「语义全未知 + 纯几何 + 稀疏奖励」这条不依赖语义与奖励假设的底线。
