# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「单模型多任务」×「安全交互」）

> 第 60 轮把执行层升级为「认知驱动的场景-执行闭环」：SSM 场景语义、CIEC 认知意图、EPIR 因果隔离、SERC 闭环、SIC 三元校验、CESC 联合决策。但其**三个结构性局限**在本轮被放大：
> 1. **多模型拼装的「集成税」**：SSM 的 Kalman 后验、CIEC 的意图映射、EEIS 的阻抗编译、EPIR 的序列恢复是四套独立模型/模块，各有独立参数、独立时延、独立阈值（0.7 / 2s / 99.5%）。当「湿滑地面」与「请加速」给出矛盾判断时，闭环里没有裁决者，只能把矛盾后验加权拼接。**「单模型多任务」** 提示：用共享骨干 + 多任务头替代四套模型，共享表征、降低总时延，并使跨任务一致性成为结构性质而非事后拼接。
> 2. **共享即互扰（负迁移）**：一旦把安全（risk/阻抗安全）与性能（速度/场景覆盖）放进同一模型，任务梯度会互相污染——场景头的高置信错误会顺带腐蚀安全头。第 60 轮的护栏是外挂式阈值与超时，缺乏**结构性隔离**。
> 3. **安全交互 ≠ 约束锁定**：第 60 轮 CIEC 把意图确定性映射为约束并锁定 2s，只保证「快」，不保证「对」。当意图歧义（「快点」在湿滑地面 vs 桌面）或与人冲突（「加速」但场景判定危险）时，正确行为既不是继续执行，也不是静默降级，而是**可逆的澄清/拒绝/回滚**。安全交互本质是**契约**：预条件、不变式、后置证据、可回滚。

## 0. 直觉与动机

**灵感 1（单模型多任务 → 统一安全交互模型 USIM）**
直觉：把 SSM/CIEC/EEIS/EPIR 从「四个专家投票」改成「一个共享大脑 + 多个安全头」。共享骨干把力/位遥测、语言意图、ROS 证据统一编码为潜变量 `z_s`；五个头分别解码场景、意图约束、阻抗先验、证据一致性、安全风险。关键洞见：**共享是为了「一致」，多任务是为了「同时」**——但必须把「安全」从共享表征里切出一个受保护子空间，否则共享就变成污染通道。

**灵感 2（安全交互 → 可逆交互契约 RIC）**
直觉：人类说「轻一点」时，机器人真正安全的动作往往不是「立刻轻」，而是「确认你指接触力还是速度」；说「快点」而地面湿滑时，正确反应是「拒绝并说明原因」。把交互形式化为四态契约：`Act / Clarify / Refuse / Rollback`。关键洞见：**安全交互 = 可逆 + 可解释 + 可拒绝**；一个不能被回滚的「安全约束」只是更精致的失控。

**灵感 3（共享骨干的安全子空间 → 受保护安全子空间 PSS）**
直觉：神经网络里任务共享特征，但「风险」必须由一组**只能被安全目标写入、对任务损失不可见**的维度承载。把 `z_s` 分解为 `z_safe ⊕ z_task`；安全头只读 `z_safe`，任务头只写 `z_task`；跨任务更新对 `z_safe` 做正交投影（安全梯度投影 SGP）。关键洞见：**安全不是共享出来的，是隔离出来的；共享只发生在非安全部分**。

**灵感 4（安全仲裁门 SAG）**
直觉：单模型多任务最大的危险不是单个头错，而是**头与头矛盾**（场景头说湿滑、意图头说加速；风险头说 0.8、阻抗头说可行）。确定性拼接会放大矛盾。SAG 把「一致性」当作一等公民：先算跨头一致性 `C_cross` 与联合风险 `R_joint`，再用**约束交集**（而非平均）构造安全包络；不满足一致性就升级到 RIC（澄清/拒绝），而不是硬压成一个数继续执行。

**灵感 5（跨任务干扰账本 CIL + 多任务安全预算 PCE+++++）**
直觉：共享容量有限，任务会争抢；把「干扰」显式记账：`I_ij` = 任务 i 的更新对任务 j（尤其安全输出）的影响。预算从第 60 轮四维认知预算扩展为 `B_mt = (B_cap, B_gate, B_confirm, B_exec)`：容量、门控、澄清、执行。若「澄清的 VOI」高于「执行的 VOI」，就**主动问**——这是「安全交互」的经济学表达；澄清预算耗尽则默认 `Refuse`（安全侧）。

**灵感 6（合流 → USIM 闭环）**
直觉：E（共享编码）→ 分解（PSS）→ 多头（MTH）→ 门控（SAG）→ 契约（RIC）→ 干扰账本（CIL）→ 预算（PCE+++++）→ 证书（UMC），构成 **USIM（Unified Safe Interaction Model）** 闭环。第 60 轮的 SSM/CIEC/EPIR/SIC 从独立模型降为「单模型里的头/子过程」，SERC 被 USIM-CL 吸收：**不是把四个模型接起来，而是让一个模型在安全约束下同时做四件事**。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（统一安全交互模型 USIM）** `USIM = (E, Π, H, G, Q, C)`。输入空间 `X = X_force × X_pos × X_lang × X_ros`；`E` 为共享编码器，`Π` 为子空间分解，`H` 为多任务安全头，`G` 为安全仲裁门，`Q` 为可逆交互契约，`C` 为统一证书。输出为决策 `d`（含 `K`）与证据证书 `Cert_umt`。

**定义 162（共享潜变量骨干 SLB）** 编码器 `E_θ: X → Z`，`z_s = E_θ(x_force, x_pos, x_lang, x_ros) ∈ R^d`。多模态 token 经跨注意力融合：`z_s = CrossAttn(Tok_f, Tok_p, Tok_l, Tok_r)`。共享参数 `θ_sh` 同时服务所有任务头，因而任务间**天然共享表征与延迟**。

**定义 163（多任务安全头 MTH）** `H = {h_scene, h_intent, h_imp, h_evid, h_risk}`，输出 `y = (p_scene, C_intent, π_imp, e_evid, r)`：
- `h_scene: z_task → Δ(Z_scene)`（场景后验，取代 SSM）
- `h_intent: z_task → C_intent`（意图约束，取代 CIEC 映射）
- `h_imp: z_task → π_imp(K|z)`（阻抗先验，供 EEIS）
- `h_evid: z_task → [0,1]`（证据一致性，取代 EPIR 校验打分）
- `h_risk: z_safe → [0,1]`（安全风险，**只读安全子空间**）

**定义 164（受保护安全子空间 PSS 与安全梯度投影 SGP）** 分解 `z_s = z_safe ⊕ z_task`，`z_safe = P_safe z_s`，`z_task = (I − P_safe) z_s`，且 `r = h_risk(z_safe)`。安全梯度投影：
```
g_task = ∇_θ L_task
g_leak = J_safe^T (J_safe J_safe^T)^{-1} J_safe g_task     # 会改变 z_safe 的分量
g_task^⊥ = g_task − g_leak
θ ← θ − η·g_task^⊥        # 任务更新对 z_safe 无一阶影响
θ_safe ← θ_safe − η_s·∇ L_safe
```
**安全单调性（SMT）**：对任意任务扰动 `Δθ_task`（`||Δθ_task|| ≤ δ`），`||h_risk(x; θ+Δθ) − h_risk(x; θ)|| ≤ L_P·||P_safe Δθ|| = O(δ²)`；即**增加任务不会一阶改变安全头**。

**定义 165（安全仲裁门 SAG）** `G: y → d`。先由各头生成风险意见 `ρ_k ∈ [0,1]`，定义
```
R_joint = max_k ρ_k
C_cross = 1 − std_k(ρ_k) / (1/2)          # 跨头一致性 ∈ [0,1]
S_env   = { K | K ∈ h_imp 先验 ∧ C_intent 约束 ∧ r ≤ r_max }   # 交集，非平均
```
决策规则：
```
if R_joint > τ_risk or C_cross < τ_cons:   d = Q.escalate(...)   # → Clarify / Refuse
elif S_env = ∅:                            d = Q.refuse("empty_envelope")
else:  K* = argmin_{K∈S_env} (λ·ω_traj − (1−λ)·K_p);  d = Q.act(K*)
```
关键性质：**任何任务都不能放宽另一个任务的安全约束**（交集单调），这是 SMT 在决策层的对应物。

**定义 166（可逆交互契约 RIC）** `Q = (Pre, Inv, Post, Rollback, δ_Q)`，状态 `q ∈ {Idle, Act, Clarify, Refuse, Rollback}`：
- **预条件** `Pre`：`ambiguity ≤ τ_amb` 且 `intent_conf ≥ τ_conf` 且 `C_cross ≥ τ_cons`。
- **不变式** `Inv`：任意时刻 `r ≤ r_max`；**人类最新覆盖指令优先级最高**。
- **后置** `Post`：动作后必须产出 `Cert_umt` 并写入 EPIR 影子副本。
- **回滚** `Rollback`：从 EPIR 恢复最近一次经证书认证的安全状态 `s_safe`，可逆窗口 `H_rb ≥ max(执行时延, 人类覆盖时延)`。
- **澄清** `Clarify`：在 `N_q` 次提问内选择使期望 VOI 最大的问题（如「力还是速度？」）。

**定义 167（跨任务干扰账本 CIL）** 成对干扰
```
I_ij = E_x[ |⟨∇_θ L_i, ∇_θ L_j⟩| / (||∇_θ L_i||·||∇_θ L_j|| + ε) ]
L_ledger = [I_ij]
```
容量分配：`min Σ_i w_i·ε_i(I)` subject to `Σ_i d_i ≤ B_cap`；安全任务约束 `I_{safe,j} = 0`（由 PSS 结构性保证）。CIL 的在线读数用于 SAG 的保守度调节与 PCE+++++ 的容量预算。

**定义 168（多任务安全预算 PCE+++++）** `B_mt = (B_cap, B_gate, B_confirm, B_exec)`：容量、门控、澄清、执行预算。
```
voi_mt(π) = VOI_meta_pessimistic(π) − cost_cap(π) − cost_gate(π) − cost_confirm(π) − cost_exec(π)
clarify ⇔ VOI_clarify = E[Δrisk] − cost_confirm  >  VOI_act
```
降级策略：`B_cap < θ_cap` ⇒ 冻结共享更新、仅运行安全头；`B_gate < θ_gate` ⇒ 采用最保守包络；`B_confirm` 耗尽 ⇒ 默认 `Refuse`（绝不放行）；`B_exec` 耗尽 ⇒ 沿用第 59 轮执行降级。

**定义 169（统一多任务证书 UMC）** `Cert_umt = (p_scene, conf_intent, π_imp, e_evid, r, C_cross, R_joint, d, q, max I_ij, (P_safe, ε), B_mt)`。验证谓词
```
Verify(Cert_umt) = [r ≤ r_max] ∧ [C_cross ≥ τ_cons ∨ d ≠ Act] ∧ [I_safe,j ≤ ε] ∧ [B_mt ≥ 0]
```
只有 `Verify = true` 的动作才允许下发到执行层。

### IP-161/162 SLB（共享潜变量骨干）

```python
class SharedLatentBackbone(nn.Module):
    def __init__(self, d_model=256, d_safe=64):
        super().__init__()
        self.tok_force = MLP(32, d_model)
        self.tok_pos   = MLP(16, d_model)
        self.tok_lang  = TextEncoder(d_model)
        self.tok_ros   = MLP(24, d_model)
        self.cross     = CrossAttention(d_model, heads=8)
        self.d_safe    = d_safe

    def forward(self, x):
        toks = torch.stack([
            self.tok_force(x.force), self.tok_pos(x.pos),
            self.tok_lang(x.lang),   self.tok_ros(x.ros)
        ], dim=1)                              # (B, 4, d)
        z_s = self.cross(toks).mean(dim=1)     # (B, d)
        z_safe = z_s[..., :self.d_safe]        # 受保护子空间
        z_task = z_s[..., self.d_safe:]        # 共享任务子空间
        return z_safe, z_task
```

### IP-163 MTH（多任务安全头）

```python
class MultiTaskSafetyHeads(nn.Module):
    def __init__(self, d_task, d_safe, N_scene, N_intent, d_K):
        super().__init__()
        self.scene  = nn.Linear(d_task, N_scene)
        self.intent = nn.Linear(d_task, N_intent)
        self.imp    = nn.Linear(d_task, d_K)
        self.evid   = nn.Linear(d_task, 1)
        self.risk   = nn.Sequential(nn.Linear(d_safe, 32), nn.ReLU(),
                                    nn.Linear(32, 1), nn.Sigmoid())  # 只读 z_safe

    def forward(self, z_safe, z_task):
        return {
            'p_scene':  softmax(self.scene(z_task)),
            'C_intent': self.intent(z_task),
            'pi_imp':   self.imp(z_task),
            'e_evid':   torch.sigmoid(self.evid(z_task)),
            'r':        self.risk(z_safe).squeeze(-1),
        }

def safety_gradient_projection(g_task, jac_safe):
    # g_leak = Jᵀ(JJᵀ)⁻¹J g
    jj = jac_safe @ jac_safe.T + 1e-8 * torch.eye(jac_safe.shape[0])
    g_leak = jac_safe.T @ torch.linalg.solve(jj, jac_safe @ g_task)
    return g_task - g_leak
```

### IP-165 SAG（安全仲裁门）

```python
class SafetyArbitrationGate:
    def __init__(self, tau_risk=0.7, tau_cons=0.6):
        self.tau_risk, self.tau_cons = tau_risk, tau_cons

    def _risk_opinion(self, y, k):
        return {'scene': y['p_scene'][..., -1], 'intent': y['C_intent'].risk,
                'imp': 1.0 - y['pi_imp'][..., 0], 'evid': 1.0 - y['e_evid']}[k]

    def arbitrate(self, y, contract):
        rho = {k: float(self._risk_opinion(y, k)) for k in ('scene','intent','imp','evid')}
        rho['safe'] = float(y['r'])
        R_joint = max(rho.values())
        C_cross = 1.0 - (np.std(list(rho.values())) / 0.5)
        if R_joint > self.tau_risk or C_cross < self.tau_cons:
            return contract.escalate(y, R_joint, C_cross)
        S_env = intersect_envelope(y)          # 约束交集；任一空则整体空
        if not S_env:
            return contract.refuse('empty_safety_envelope')
        K = min(S_env, key=lambda k: 1.0 * k.omega_traj - 0.2 * k.K_p)
        return contract.act(K, R_joint, C_cross)
```

### IP-166 RIC（可逆交互契约）

```python
class ReversibleInteractionContract:
    STATES = ('Idle', 'Act', 'Clarify', 'Refuse', 'Rollback')

    def __init__(self, shadow, tau_amb=0.35, tau_conf=0.5, n_q=2):
        self.shadow, self.tau_amb, self.tau_conf = shadow, tau_amb, tau_conf
        self.n_q, self.state, self.questions = n_q, 'Idle', 0

    def act(self, K, R_joint, C_cross):
        self.state = 'Act'
        return Decision('ACT', K=K, R_joint=R_joint, C_cross=C_cross)

    def escalate(self, y, R_joint, C_cross):
        amb = float(y['p_scene'].entropy() / np.log(len(y['p_scene'])))
        if amb > self.tau_amb or C_cross < 0.4:
            return self.clarify()
        return self.refuse(f'joint_risk={R_joint:.2f}')

    def clarify(self):
        if self.questions >= self.n_q:
            return self.refuse('clarify_budget_exhausted')
        self.questions += 1
        self.state = 'Clarify'
        return Decision('CLARIFY', question=self._best_question())

    def refuse(self, reason):
        self.state = 'Refuse'
        return Decision('REFUSE', reason=reason)

    def rollback(self):
        self.state = 'Rollback'
        return self.shadow.restore_last_certified()   # 复用第 60 轮 EPIR 影子副本
```

### IP-167/168 CIL + PCE+++++

```python
class InterferenceLedger:
    def __init__(self, tasks):
        self.I = {(i, j): 0.0 for i in tasks for j in tasks}

    def update(self, grads, eps=1e-8):
        for i, gi in grads.items():
            for j, gj in grads.items():
                self.I[(i, j)] = abs(torch.dot(gi, gj)) / (
                    gi.norm() * gj.norm() + eps)

    def safety_leak(self):
        return max(self.I[('task', 'safe')], self.I[('safe', 'task')])

class MultiTaskSafetyBudget:
    def __init__(self, B_cap=1.0, B_gate=1.0, B_confirm=3, B_exec=None):
        self.B_cap, self.B_gate = B_cap, B_gate
        self.B_confirm, self.B_exec = B_confirm, B_exec or ExecBudget()

    def choose(self, voi_act, voi_clarify):
        if self.B_confirm <= 0:
            return 'REFUSE'                       # 澄清不可用 → 安全侧
        return 'CLARIFY' if voi_clarify > voi_act else 'ACT'
```

### IP-161 USIM-CL（统一安全交互闭环）

```python
def usim_loop(M, x):
    z_safe, z_task = M.backbone(x)                 # ① SLB
    y = M.heads(z_safe, z_task)                    # ② MTH
    d = M.gate.arbitrate(y, M.contract)            # ③ SAG
    if d.action == 'CLARIFY':
        return d, M.umc.issue_partial(y, d, M.contract.state)
    if d.action == 'REFUSE':
        return d, M.umc.issue(y, d, M.contract.state)
    K = d.K                                        # ④ Act
    M.ertc.lock(y['C_intent'])
    ev = execute(K)                                # ⑤ 执行
    M.epir.append(ev)                              # ⑥ EPIR 影子副本
    r_post = M.heads.risk(M.heads.encode(ev))      # ⑦ 执行后风险
    if r_post > r_max:
        return M.contract.rollback(), M.umc.issue(y, d, 'Rollback')
    M.cil.update(M.last_grads)                     # ⑧ 干扰账本
    M.budget.consume(scene=0.1, intent=0.1, confirm=0.0, exec=1.0)
    cert = M.umc.issue(y, d, M.contract.state)     # ⑨ UMC
    M.backbone.safe_update(M.last_grads)           # ⑩ SGP 安全更新
    return d, cert
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SLB | O(1) 前向（单骨干） | O(d_model) | 四任务共享表征，总时延较 4 独立模型 −30% |
| MTH | O(1) 多头并行 | O(Σ head) | 各头独立校准，ECE ≤ 5% |
| PSS/SGP | O(d·d_safe) 投影/更新 | O(d_safe²) | 安全头一阶不受任务更新影响（SMT） |
| SAG | O(1) 门控 | O(1) | 冲突场景不安全下发 = 0 |
| RIC | O(N_q) 澄清 | O(1) | 可逆窗口内回滚成功 ≥ 99.9% |
| CIL | O(T²) 账本更新 | O(T²) | 安全-任务干扰 ≤ ε |

**假设 A66–A70**：A66 安全子空间维度 `d_safe ≥ d_min`；A67 任务梯度可正交投影（`J_safe` 满秩）；A68 各风险头已校准（ECE ≤ δ）；A69 安全包络可精确/保守可计算；A70 回滚窗口覆盖执行与人类覆盖时延。

**定理 1（安全单调性 SMT）**：在 A66–A70 下，对任意任务集 `T' ⊇ T` 与任意有界任务扰动 `Δθ_task`，有 `||r(x;θ+Δθ) − r(x;θ)|| ≤ ε_safe`，且下发阻抗 `K ∈ S_env^{T'} ⊆ S_env^{safe-only}`。故 `UnsafeRate(USIM) ≤ UnsafeRate(safe-only) + ε_cal`——**增加任务不会提高不安全动作率**。

**定理 2（矛盾裁决完备性）**：若 `C_cross < τ_cons` 或 `R_joint > τ_risk`，则 SAG 绝不返回 `Act`，只能进入 `Clarify/Refuse/Rollback`。在 A69 下，冲突场景的「不安全下发率」为 0。

**定理 3（可逆性）**：若 `H_rb ≥ max(执行时延, 人类覆盖时延)`，则任一 `Act` 均可在窗口内回到最近一次认证安全状态，且证据链经 EPIR 保持连续（承接第 60 轮 A63）。

```python
class SharedLatentBackbone(nn.Module):
    def __init__(self, d_model=256, d_safe=64):
        super().__init__()
        self.tok_force, self.tok_pos = MLP(32, d_model), MLP(16, d_model)
        self.tok_lang,  self.tok_ros = TextEncoder(d_model), MLP(24, d_model)
        self.cross, self.d_safe = CrossAttention(d_model, heads=8), d_safe

    def forward(self, x):
        toks = torch.stack([self.tok_force(x.force), self.tok_pos(x.pos),
                            self.tok_lang(x.lang), self.tok_ros(x.ros)], dim=1)
        z_s = self.cross(toks).mean(dim=1)
        return z_s[..., :self.d_safe], z_s[..., self.d_safe:]   # (z_safe, z_task)

class MultiTaskSafetyHeads(nn.Module):
    def __init__(self, d_task, d_safe, N_scene, N_intent, d_K):
        super().__init__()
        self.scene  = nn.Linear(d_task, N_scene)
        self.intent = nn.Linear(d_task, N_intent)
        self.imp    = nn.Linear(d_task, d_K)
        self.evid   = nn.Linear(d_task, 1)
        self.risk   = nn.Sequential(nn.Linear(d_safe, 32), nn.ReLU(),
                                    nn.Linear(32, 1), nn.Sigmoid())   # 只读 z_safe

    def forward(self, z_safe, z_task):
        return {'p_scene': softmax(self.scene(z_task)),
                'C_intent': self.intent(z_task),
                'pi_imp':   self.imp(z_task),
                'e_evid':   torch.sigmoid(self.evid(z_task)),
                'r':        self.risk(z_safe).squeeze(-1)}
```

### IP-164 PSS/SGP（安全子空间与梯度投影）

```python
def safety_gradient_projection(g_task, jac_safe):
    jj = jac_safe @ jac_safe.T + 1e-8 * torch.eye(jac_safe.shape[0])
    g_leak = jac_safe.T @ torch.linalg.solve(jj, jac_safe @ g_task)
    return g_task - g_leak          # 对 z_safe 无一阶影响 ⇒ SMT

def safe_update(optimizer, g_task, g_safe, jac_safe):
    optimizer.zero_grad()
    (safety_gradient_projection(g_task, jac_safe) + g_safe).backward()
    optimizer.step()
```

### IP-165 SAG（安全仲裁门）

```python
class SafetyArbitrationGate:
    def __init__(self, tau_risk=0.7, tau_cons=0.6):
        self.tau_risk, self.tau_cons = tau_risk, tau_cons

    def arbitrate(self, y, contract):
        rho = {'scene': float(y['p_scene'][..., -1]),
               'intent': float(y['C_intent'].risk),
               'imp': 1.0 - float(y['pi_imp'][..., 0]),
               'evid': 1.0 - float(y['e_evid']),
               'safe': float(y['r'])}
        R_joint = max(rho.values())
        C_cross = 1.0 - np.std(list(rho.values())) / 0.5
        if R_joint > self.tau_risk or C_cross < self.tau_cons:
            return contract.escalate(y, R_joint, C_cross)
        S_env = intersect_envelope(y)             # 交集；任一空则整体空
        if not S_env:
            return contract.refuse('empty_safety_envelope')
        K = min(S_env, key=lambda k: 1.0 * k.omega_traj - 0.2 * k.K_p)
        return contract.act(K, R_joint, C_cross)
```

```python
class ReversibleInteractionContract:
    def __init__(self, shadow, tau_amb=0.35, tau_conf=0.5, n_q=2):
        self.shadow, self.tau_amb, self.tau_conf = shadow, tau_amb, tau_conf
        self.n_q, self.state, self.questions = n_q, 'Idle', 0

    def act(self, K, R_joint, C_cross):
        self.state = 'Act'; return Decision('ACT', K=K, R_joint=R_joint)

    def escalate(self, y, R_joint, C_cross):
        amb = float(y['p_scene'].entropy() / np.log(len(y['p_scene'])))
        if amb > self.tau_amb or C_cross < 0.4:
            return self.clarify()
        return self.refuse(f'joint_risk={R_joint:.2f}')

    def clarify(self):
        if self.questions >= self.n_q:
            return self.refuse('clarify_budget_exhausted')
        self.questions += 1; self.state = 'Clarify'
        return Decision('CLARIFY', question=self._best_question())

    def refuse(self, reason):
        self.state = 'Refuse'; return Decision('REFUSE', reason=reason)

    def rollback(self):
        self.state = 'Rollback'
        return self.shadow.restore_last_certified()   # 复用第 60 轮 EPIR 影子副本
```

```python
class InterferenceLedger:
    def __init__(self, tasks):
        self.I = {(i, j): 0.0 for i in tasks for j in tasks}

    def update(self, grads, eps=1e-8):
        for i, gi in grads.items():
            for j, gj in grads.items():
                self.I[(i, j)] = abs(torch.dot(gi, gj)) / (gi.norm()*gj.norm() + eps)

    def safety_leak(self):
        return max(self.I[('task', 'safe')], self.I[('safe', 'task')])

class MultiTaskSafetyBudget:
    def __init__(self, B_cap=1.0, B_gate=1.0, B_confirm=3, B_exec=None):
        self.B_cap, self.B_gate, self.B_confirm = B_cap, B_gate, B_confirm
        self.B_exec = B_exec or ExecBudget()

    def choose(self, voi_act, voi_clarify):
        if self.B_confirm <= 0:
            return 'REFUSE'                     # 澄清不可用 → 安全侧
        return 'CLARIFY' if voi_clarify > voi_act else 'ACT'
```

```python
def usim_loop(M, x):
    z_safe, z_task = M.backbone(x)                 # ① SLB
    y = M.heads(z_safe, z_task)                    # ② MTH
    d = M.gate.arbitrate(y, M.contract)            # ③ SAG
    if d.action in ('CLARIFY', 'REFUSE'):
        return d, M.umc.issue(y, d, M.contract.state)
    M.ertc.lock(y['C_intent']); ev = execute(d.K)  # ④ Act
    M.epir.append(ev)                              # ⑤ 证据落影子副本
    if M.heads.risk(M.heads.encode(ev)) > r_max:   # ⑥ 执行后风险
        return M.contract.rollback(), M.umc.issue(y, d, 'Rollback')
    M.cil.update(M.last_grads)                     # ⑦ 干扰记账
    M.budget.consume(scene=.1, intent=.1, confirm=0., exec=1.)
    cert = M.umc.issue(y, d, M.contract.state)     # ⑧ UMC
    M.backbone.safe_update(M.last_grads)           # ⑨ SGP 安全更新
    return d, cert
```

**正确性定理（USIM-Safe）**：
1. **安全单调性 SMT**：A66–A70 下，任意 `T' ⊇ T` 与有界扰动 `Δθ_task`，`||r(x;θ+Δθ) − r(x;θ)|| ≤ ε_safe`，且 `K ∈ S_env^{T'} ⊆ S_env^{safe-only}` ⇒ 增加任务不提高不安全率。
2. **矛盾裁决完备性**：`C_cross < τ_cons ∨ R_joint > τ_risk ⇒ d ≠ Act`；冲突场景不安全下发 = 0。
3. **可逆性**：`H_rb ≥ max(执行时延, 人类覆盖时延) ⇒` 任一 Act 可回滚至认证安全态，证据链经 EPIR 连续。
4. **预算安全降级**：任一 `B_mt` 分量耗尽 ⇒ 触发对应保守策略；`B_confirm=0 ⇒ Refuse`，绝不放行。
