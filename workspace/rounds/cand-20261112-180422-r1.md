# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC；灵感循环第 7 轮；本轮灵感：「文化适应性」×「基准测试」）

> 第 60 轮把「执行层→证据层」升级为场景感知闭环：SSM 场景语义建模、CIEC 认知意图约束、EPIR 执行感知隔离区、SERC 场景感知闭环、SIC/CESC 三元校验与联合决策。但仍留下**三个核心局限**：
> 1. **场景语义的文化盲区**：SSM 的 π_scene(K|z) 只刻画物理场景（桌面/楼梯/湿滑），把「同一场景」视为跨家庭、跨机器人、跨法规域同质；然而「桌面」在 A 家庭意味着轻触慢移，在 B 家庭意味着快速夹取；同一台机器人在不同地区的接触力与个人空间规范也不同。文化被当作噪声，导致「物理正确、社会失礼」的系统性偏差。
> 2. **意图约束的文化歧义**：CIEC 的 ϕ_intent→constraint 是固定映射表。中文「轻一点」、英文 "easy"、手势示意的力度基线随文化/embodiment 漂移；在 A 文化标定的 K_p 换到 B 文化可能过猛。意图落地缺少**文化条件化**。
> 3. **基准测试的缺失与偏差**：E187–E191 全部是单站点、单文化、单 embodiment 的测量；指标定义未做**测量不变性**检验，无法区分「能力差异」与「文化差异」；也没有留出文化银行，存在典型的过拟合与 Goodhart 风险——在一个家庭刷到 85%，换一个家庭可能骤降。

## 0. 直觉与动机

**灵感 1（文化适应性 → 文化剖面 CPS）**
直觉：机器人不是进入一个空的物理场景，而是进入一个**规范性世界**。文化不是模糊标签，而是一组可计算的**参数先验**：递物距离、接触力上限、移动速度、响应延迟、任务代劳边界、错误容忍度。把它写成 c = (c_H, c_E, c_R)：人机社会规范、embodiment 约定、法规域。关键洞见：文化应被建模为**参数分布族** Π_c 而非单点——这样文化适应就是「后验更新」，而不是「切换配置」。

**灵感 2（文化适应性 → 文化边界包络 CBE）**
直觉：文化适应最危险的诱惑是「拿安全换贴心」。因此把阻抗空间切成两层：**不可协商的安全内核 K_inv**（由 ERTC/EEIS 与物理极限证书给出）与**可文化化的外壳**。适应只允许发生在 CAE(c) = K_inv ∩ Ball(K_cult(c), ρ_c) 内。关键洞见：**适应的自由，必须是「被证明的安全半径内的自由」**；ρ_c 由可达性/风险上界证书给出，而不是调参得到。

**灵感 3（基准测试 → 文化基准矩阵 CBM）**
直觉：若只在一种文化上测 85%，那不是能力而是过拟合。基准必须**文化分层**且**测量不变**：把观测分解为 m(τ,c) = m_intrinsic(τ) + b(c) + ε；只有 b(c) 被估计并检验后，跨文化比较才成立。否则排行榜会把文化差异误读为能力差异。于是引入心理测量学的 **DIF（差异题项功能）检验**与**文化分层排行榜**。

**灵感 4（基准测试 → 基准驱动校准 BAC 与 Goodhart 护栏）**
直觉：基准不是终点，而是控制信号。用分层结果反推文化先验 c 与包络半径 ρ_c，但只接受**帕累托改进 + 非劣性**的校准：目标文化提升 ≥ δ，任何其他文化不得劣化超过 ε；用 Holm 控制 FWER，防止「挑一个好看的分层」。再留出**文化银行 C_holdout** 做盲测，报告 train–test gap，抵御 Goodhart。

**灵感 5（合流 → 文化基准闭环 CBCL 与 PCE+++++）**
直觉：CPS 给出文化剖面 → CBE 把适应关进安全包络 → CAO 在线自适应 → CBC 给每次执行附文化基准证书 → CBM 做分层不变性测量 → BAC 只接受非劣校准 → 回写文化先验。同时把基准成本纳入预算：B_bench（试验数、人工评分、跨站点、标注）、B_cult（适应算力）；预算耗尽⇒代理指标 / 冻结保守文化剖面。形成「**文化→包络→适应→执行→证书→基准→校准→文化**」的闭环。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（文化剖面 CPS）** 文化剖面 c = (c_H, c_E, c_R)，取值于文化空间 C：
- c_H ∈ R^{d_H}：人机社会规范（个人空间、接触力期望、速度期望、响应延迟容忍、代劳边界）
- c_E ∈ R^{d_E}：embodiment 约定（关节零位、力矩标定、传感时延、坐标系约定）
- c_R ∈ Δ^{d_R}：法规域（ISO/GB/EN 等安全规范族；simplex 约束）
- 文化先验 Π_c = N(c; μ_c, Σ_c)；文化距离 d_C(c,c') = sqrt((c−c')ᵀ M (c−c'))。
文化剖面不是单点配置，而是「以 Π_c 为中心、以 CAE 为界的可适应族」。

**定义 162（文化边界包络 CBE）** 给定文化 c：
- **安全内核**：K_inv ⊆ K_safe（由 ERTC/EEIS + 物理极限给出的硬约束，跨文化不可变更）
- **文化名义**：K_cult(c) = E_{K∼π_scene(·|c)}[K]
- **包络**：CAE(c) = { K ∈ K_inv : d_Φ(K, K_cult(c)) ≤ ρ_c }，d_Φ 为加权 log-Euclidean 度量
- **包络证书**：ρ_c 由风险上界给出：sup_{K∈CAE(c)} Risk(K,c) ≤ R_max
- **安全投影**：Π_CAE(K;c) 用 Dykstra 交替投影到 K_inv ∩ Ball(K_cult(c),ρ_c)（两者均凸）
性质：CAE(c) ⊆ K_inv，故**任何**文化适应都在硬安全内；文化只能改变「在安全内偏向哪一侧」，不能改变「安全边界本身」。

**定义 163（文化适应算子 CAO）** 在线更新与安全护栏：
```
c_{t+1} = Proj_{B(c_t, ρ_cult)}( c_t − η ∇_c L(evidence_t; c_t) )
K_{t+1} = Π_CAE( K_candidate(c_{t+1}) ; c_{t+1} )
```
- **信赖域**：‖c_{t+1} − c_t‖_M ≤ ρ_cult，防止一次交互把文化剖面带偏
- **漂移检测**：对残差序列做 CUSUM/变点检测；漂移时**扩大 Π_c 的认知不确定性**（widen epistemic），而**绝不扩大 K_inv**
- **安全单调引理**：CAO 只允许「在 CAE 内移动」，任何试图放宽 K_inv 的梯度方向被投影截断；故 ∀t, K_t ∈ K_inv。

**定义 164（文化基准矩阵 CBM）** 基准 B = (T, C, Met, R)：T 任务、C 文化分层、Met 指标、R 重复试验。测量模型：
```
m_ij = m_intrinsic(τ_i) + b_j(c_j) + b_ij(τ_i,c_j) + ε_ij
```
- **测量不变性**：若 b_j 在选定参考文化下可标定为 0 且交互项 b_ij 不显著，则指标**文化不变**；用 DIF 似然比统计量检验（effect ≤ δ_inv, p > α_inv）
- **分层估计**：按 c 分层做 cluster bootstrap，给出每层置信区间与覆盖率
- **排行榜稳定性**：在分层重采样下计算 Kendall τ，衡量排名是否被文化构成改变
- **覆盖率约束**：每层样本 n_j ≥ n_min，文化层数 |C| ≥ S_min

**定义 165（基准驱动校准 BAC）** 给定分层结果与候选更新 Δc，仅当同时满足：
1. **目标提升**：m_target(after) − m_target(before) ≥ δ_target
2. **非劣性**：∀ 文化层 j：m_j(after) ≥ m_j(before) − ε
3. **多重比较控制**：Holm 校正后 FWER ≤ α
4. **Goodhart 护栏**：留出文化银行 gap = |m_holdout(after) − m_calib(after)| ≤ δ_goodhart
才接受 Δc，并在可行集中取目标提升最大者。这本质是**带非劣性约束的多目标优化**。

**定义 166（文化基准证书 CBC）** 每次执行附证书：
```
CBC = (c, ρ_c, B_ref, coverage, conf_int, violations, holdout_gap)
```
有效谓词 CBC_valid = coverage ≥ 0.9 ∧ violations = 0 ∧ holdout_gap ≤ δ_goodhart ∧ conf_int 下界 ≥ 阈值。
CBC 作为 EV-exec 的文化伴随证据，由 EPIR 一起回传云端校验。

**定义 167（五维预算 PCE+++++）** B_cog5 = (B_scene, B_intent, B_ros, B_exec, B_bench, B_cult)：
- **B_bench** = (Trials, Human_raters, Cross_site, Annotation)
- **B_cult** = (Adapt_ops, Profile_memory, Drift_checks)
```
voi_cog5(π) = VOI_meta_pessimistic(π) − cost_cog5(π) − cost_exec(π)
cost_cog5 = cost_cog + λ_bench·Trials(π) + λ_rate·Raters(π) + λ_site·Sites(π) + λ_cult·Adapt(π)
```
降级：B_bench 耗尽⇒代理指标 + 保守置信；B_cult 耗尽⇒冻结到保守文化剖面 c_cons。

**定义 168（文化基准闭环 CBCL）** 算子 CBCL(M, task, intent, B)：
```
① CPS: c ← M.cps.current；π_scene(·|c) 由联合先验生成
② CBE: CAE(c) ← envelope(c; K_inv, ρ_c)
③ CAO: c ← trust_region_update(c, evidence)
④ Compile: K ← Π_CAE( EEIS.compile_with_culture(π_scene, task) ; c )
⑤ Execute: EV-exec ← closed_loop_exec_probe(M, K)
⑥ CBC: cert ← build_cbc(c, CAE(c), EV-exec, B)
⑦ CBM: results ← B.evaluate(task, c, EV-exec)   # 分层、不变性检验
⑧ BAC: if accept(c, results): (c, ρ_c) ← calibrate(c, results)
⑨ Guard: if holdout_gap > δ: reject & rollback; return (c, K, cert, results)
```

### IP-161 CPS（文化剖面）

```python
class CulturalProfileSchema:
    def __init__(self, d_H=8, d_E=6, d_R=4):
        self.d_H, self.d_E, self.d_R = d_H, d_E, d_R
        d = d_H + d_E + d_R
        self.mu = np.zeros(d)
        self.Sigma = np.eye(d) * 0.1
        self.M = np.eye(d)                # 文化距离度量

    def split(self, c):
        return (c[:self.d_H],
                c[self.d_H:self.d_H + self.d_E],
                c[self.d_H + self.d_E:])

    def project(self, c):
        c_H, c_E, c_R = self.split(c)
        c_R = simplex_projection(c_R)     # 法规域是分布
        return np.concatenate([c_H, c_E, c_R])

    def distance(self, c1, c2):
        d = c1 - c2
        return float(np.sqrt(d @ self.M @ d))

    def update_prior(self, c_obs):
        S = self.Sigma + np.eye(len(c_obs)) * 1e-6
        gain = self.Sigma @ np.linalg.inv(S)
        self.mu = self.mu + gain @ (c_obs - self.mu)
        self.Sigma = (np.eye(len(c_obs)) - gain) @ self.Sigma
```

### IP-162 CBE（文化边界包络）

```python
class CulturalBoundaryEnvelope:
    def __init__(self, K_inv, metric_Phi, risk_bound):
        self.K_inv = K_inv        # 硬安全凸集
        self.phi = metric_Phi     # 加权 log-Euclidean
        self.R_max = risk_bound

    def radius(self, c):
        # 由风险上界证书反解最大可行半径；失败则回退 0（只允许保守）
        rho = self._certify_radius(c)
        return rho if rho is not None else 0.0

    def contains(self, K, c, rho):
        return self._in_set(K, self.K_inv) and \
               self.phi(K, self.K_cult(c)) <= rho

    def project(self, K, c, rho):
        # Dykstra 交替投影到两个凸集的交集
        A = lambda x: self._proj_inv(x)
        B = lambda x: self._proj_ball(x, self.K_cult(c), rho)
        return self._dykstra(K, A, B, tol=1e-6, max_iter=50)
```

### IP-163 CAO（文化适应算子）

```python
class CulturalAdaptationOperator:
    def __init__(self, schema, eta=0.05, rho_cult=0.2, drift_window=50):
        self.schema, self.eta = schema, eta
        self.rho_cult = rho_cult
        self.residuals = deque(maxlen=drift_window)

    def step(self, c, evidence):
        g = self._grad_loss(c, evidence)          # ∇_c L
        cand = c - self.eta * g
        cand = self._proj_trust(cand, c, self.rho_cult)
        if self._drift_detected(evidence):        # CUSUM
            self.schema.Sigma *= 1.5              # 扩大认知不确定性，不动 K_inv
        return self.schema.project(cand)

    def guard_impedance(self, K_cand, c, envelope):
        rho = envelope.radius(c)
        K = envelope.project(K_cand, c, rho)
        assert envelope.contains(K, c, rho)       # 安全单调
        return K
```

### IP-164 CBM（文化基准矩阵）

```python
class CulturalBenchmarkMatrix:
    def __init__(self, tasks, cultures, metrics, n_min=30, S_min=3):
        self.T, self.C, self.Met = tasks, cultures, metrics
        self.n_min, self.S_min = n_min, S_min
        self.cells = defaultdict(list)

    def add(self, task, culture, metric, value):
        self.cells[(task, culture, metric)].append(value)

    def invariance_test(self, metric):
        # 加性模型 vs 交互模型的似然比检验（DIF）
        ll_add = self._fit_additive(metric)
        ll_int = self._fit_interaction(metric)
        stat = 2 * (ll_int - ll_add)
        p = chi2.sf(stat, df=self._df())
        effect = self._dif_effect_size(metric)
        return {'p': p, 'effect': effect,
                'invariant': p > 0.05 and effect <= 0.1}

    def stratified_report(self):
        out = {}
        for j in self.C:
            vals = self._stratum(metric='success', culture=j)
            out[j] = bootstrap_ci(vals, cluster=True)
        return out
```

### IP-165 BAC（基准驱动校准）

```python
class BenchmarkAwareCalibration:
    def __init__(self, delta_target=0.03, epsilon=0.01,
                 alpha=0.05, delta_goodhart=0.03):
        self.dt, self.eps = delta_target, epsilon
        self.alpha, self.dg = alpha, delta_goodhart
        self.target = None

    def accept(self, before, after, holdout):
        raw = {j: after[j] - before[j] for j in before}
        target_gain = raw[self.target]
        non_inferior = all(raw[j] >= -self.eps for j in raw)
        pvals = {j: paired_permutation_p(before[j], after[j]) for j in raw}
        fwer_ok = holm_reject(pvals, self.alpha, self.target)
        gap = abs(holdout['after'] - holdout['calib'])
        return (target_gain >= self.dt and non_inferior
                and fwer_ok and gap <= self.dg)

    def calibrate(self, c, results):
        candidates = self._candidate_updates(results)
        feasible = [d for d in candidates
                    if self.accept(results.before, results.after(d),
                                   results.holdout)]
        return max(feasible, key=lambda d: results.gain(d), default=None)
```

```python
def cultural_benchmark_closed_loop(M, task, intent, benchmark):
    c = M.cps.current
    envelope = M.cbe
    rho = envelope.radius(c)

    if intent:
        M.intent_ctrl.receive_intent(intent)
    c = M.cao.step(c, M.last_evidence)

    K_scene = M.eeis.compile_with_culture(M.scene_model, c, task)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPS | O(d) 更新 | O(d²) 先验协方差 | 文化后验可辨识到包络粒度 |
| CBE | O(1/ε²) Dykstra 投影 | O(1) | CAE ⊆ K_inv，风险 ≤ R_max |
| CAO | O(d log(1/ε)) / 步 | O(drift_window) | 信赖域 + 安全单调，0 边界穿越 |
| CBM | O(|T||C||Met|) | O(分层样本) | DIF 不变性 effect ≤ δ_inv |
| BAC | O(|C| log|C|) Holm | O(|C|) | 非劣性 + FWER ≤ α + 留出 gap |
| CBCL | O(闭环) | 复用 | 端到端文化适应成功率 ≥ 80% |

**正确性定理（CABEC）**：
假设 A22–A70 成立；新增 **(A66)** 文化剖面在 d_C 度量下可辨识到包络粒度、Π_c 正则可估；**(A67)** 风险上界证书给出 ρ_c 使 CAE(c) ⊆ K_inv 且 sup Risk ≤ R_max；**(A68)** CAO 信赖域 + Π_CAE 投影，任何更新不扩大 K_inv；**(A69)** CBM 通过 DIF 不变性检验（effect ≤ δ_inv）且覆盖率达标；**(A70)** BAC 只接受非劣 + FWER 控制 + 留出 gap 满足的更新。

则：
1. **安全保持**：∀t，K_t ∈ CAE(c_t) ⊆ K_inv，文化适应不触碰硬安全边界。
2. **基准有效性**：在参考文化标定下，跨文化比较偏差 ≤ δ_inv，排行榜不是文化差异的伪影。
3. **非劣性**：BAC 接受的任何校准不会使任何文化层劣化超过 ε。
4. **泛化/反 Goodhart**：留出文化银行 gap ≤ δ_goodhart（概率 ≥ 1−β）；若适应只讨好基准，gap 触发回滚。
5. **预算安全**：B_bench/B_cult 耗尽即降级为代理指标或冻结保守剖面。

### IP-161 CPS（文化剖面）

```python
class CulturalProfileSchema:
    def __init__(self, d_H=8, d_E=6, d_R=4):
        self.d_H, self.d_E, self.d_R = d_H, d_E, d_R
        d = d_H + d_E + d_R
        self.mu = np.zeros(d)
        self.Sigma = np.eye(d) * 0.1
        self.M = np.eye(d)

    def split(self, c):
        return (c[:self.d_H],
                c[self.d_H:self.d_H + self.d_E],
                c[self.d_H + self.d_E:])

    def project(self, c):
        c_H, c_E, c_R = self.split(c)
        c_R = simplex_projection(c_R)
        return np.concatenate([c_H, c_E, c_R])

    def distance(self, c1, c2):
        d = c1 - c2
        return float(np.sqrt(d @ self.M @ d))

    def update_prior(self, c_obs):
        S = self.Sigma + np.eye(len(c_obs)) * 1e-6
        gain = self.Sigma @ np.linalg.inv(S)
        self.mu = self.mu + gain @ (c_obs - self.mu)
        self.Sigma = (np.eye(len(c_obs)) - gain) @ self.Sigma
```

### IP-162 CBE（文化边界包络）

```python
class CulturalBoundaryEnvelope:
    def __init__(self, K_inv, metric_Phi, risk_bound):
        self.K_inv = K_inv
        self.phi = metric_Phi
        self.R_max = risk_bound

    def radius(self, c):
        rho = self._certify_radius(c)
        return rho if rho is not None else 0.0

    def contains(self, K, c, rho):
        return self._in_set(K, self.K_inv) and \
               self.phi(K, self.K_cult(c)) <= rho

    def project(self, K, c, rho):
        A = lambda x: self._proj_inv(x)
        B = lambda x: self._proj_ball(x, self.K_cult(c), rho)
        return self._dykstra(K, A, B, tol=1e-6, max_iter=50)
```

### IP-163 CAO（文化适应算子）

```python
class CulturalAdaptationOperator:
    def __init__(self, schema, eta=0.05, rho_cult=0.2, drift_window=50):
        self.schema, self.eta = schema, eta
        self.rho_cult = rho_cult
        self.residuals = deque(maxlen=drift_window)

    def step(self, c, evidence):
        g = self._grad_loss(c, evidence)
        cand = c - self.eta * g
        cand = self._proj_trust(cand, c, self.rho_cult)
        if self._drift_detected(evidence):
            self.schema.Sigma *= 1.5
        return self.schema.project(cand)

    def guard_impedance(self, K_cand, c, envelope):
        rho = envelope.radius(c)
        K = envelope.project(K_cand, c, rho)
        assert envelope.contains(K, c, rho)
        return K
```

### IP-165 BAC（基准驱动校准）

```python
class BenchmarkAwareCalibration:
    def __init__(self, delta_target=0.03, epsilon=0.01,
                 alpha=0.05, delta_goodhart=0.03):
        self.dt, self.eps = delta_target, epsilon
        self.alpha, self.dg = alpha, delta_goodhart
        self.target = None

    def accept(self, before, after, holdout):
        raw = {j: after[j] - before[j] for j in before}
        target_gain = raw[self.target]
        non_inferior = all(raw[j] >= -self.eps for j in raw)
        pvals = {j: paired_permutation_p(before[j], after[j]) for j in raw}
        fwer_ok = holm_reject(pvals, self.alpha, self.target)
        gap = abs(holdout['after'] - holdout['calib'])
        return (target_gain >= self.dt and non_inferior
                and fwer_ok and gap <= self.dg)

    def calibrate(self, c, results):
        candidates = self._candidate_updates(results)
        feasible = [d for d in candidates
                    if self.accept(results.before, results.after(d),
                                   results.holdout)]
        return max(feasible, key=lambda d: results.gain(d), default=None)
```
