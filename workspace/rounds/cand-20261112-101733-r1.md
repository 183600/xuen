# 第 59 轮（承接第 58 轮「可审查泛化」IP-139~144；新灵感循环第 1 轮；本轮灵感：「指令泛化」×「中间件」）

> 第 58 轮把"泛化"从统计口号变成有条件的机构承诺：管辖域内给移位感知保证、域外构造性拒绝，且每张主张必须经独立审查。但它默认了一件从未被审查的事——**"指令"本身如何变成一个可被这些门检查的动作**。现实中的指令来自自然语言、任务规划器、学习策略，甚至环境里的文字；把这四类东西翻译成动作的"解释器"，是一个巨大的、未被中介的黑箱。第 58 轮审查的是"系统能不能在某个区域泛化"，却没有审查"一次新说法的指令有没有被正确地泛化"。这留下两条互补的裂缝：**(a) 指令泛化不受控**——新说法被"合理地"编译成某个已知安全模板，动作合法而意图已被偷换（语义漂移 / 规格博弈）；**(b) 中介不唯一**——每个守卫各自嵌在组件里，新增指令源或紧急旁路可以绕过整摞门，纵深防御在"少调用一次函数"处归零。本轮两个灵感正好各补一刀：**指令泛化**要求把"解释"从黑箱变成可类型推导、带漂移证书、可就地拒绝的编译过程；**中间件**要求把所有动作收束到一个必经的引用监视器，并把策略本身变成可审计、可版本化、经审查的数据。合流命题：**「语义可以泛化，授权不能泛化；一切动作必经唯一中介，跨指令累积必须被计价」**——把第 58 轮"一切泛化主张走审查"再推一层为"**一切指令解释走编译、一切解释结果走中介、一切中介策略走审查**"。

核心矛盾：
- **H32（泛化 vs 授权）**：泛化是必需的（新指令千变万化），但泛化恰恰是把"没见过的意图"翻译成"见过的权限"的通道；语义越灵活，越容易把越权意图洗成一个动作合法的模板。若解释器同时握有解释权与授权权，它就能"泛化"出新权限。
- **H33（中介 vs 单点）**：统一中介能消灭旁路，但自身立刻成为最大可信基与实时瓶颈；fail-closed 在危险地形可能表现为"安全地卡死"，而越强的中介越有动机被人以"紧急遥操作/性能优化/第三方插件"为名绕过。
- **H34（单步安全 vs 组合安全）**：每条指令都过门，不代表指令序列安全。"萨拉米"式组合可以每步合法、整体越界；而指令泛化恰恰把可用的小指令空间做大，组合爆炸使逐条检查既不完备也不经济。

## 0. 直觉与动机

**灵感 1（指令泛化 → 编译而非猜测）**
直觉：人听到新指令不是"自由发挥"，而是在一套语法与常识上做**组合**：把"绕过结冰的那块、停到蓝箱子旁边"拆成 移动 + 避让(谓词:结冰) + 定位(指称:蓝箱) + 停止。泛化能力来自组合，而不是来自"对整句未知指令的一次整体猜测"。所以把解释做成 **schema 代数上的类型推导**：原子 schema 是已验证的意图片段，组合子只允许 seq/choice/param/iterate；推不出来，就明确"我不懂"，去澄清，而不是硬挑一个"最像"的安全动作。关键是把"泛化"从**模型能力**变成**可检查的推导证书** g_cert：推导深度、语义漂移 δ_g、未绑定指称 u_refs、来源 schema 及其覆盖。泛化只允许在语义层发生，且只产出"候选意图"，绝不产出"新权限"。

**灵感 2（中间件 → 引用监视器 + 双平面）**
直觉：中间件不是"多包一层代码"，而是**唯一强制点**：所有请求都穿过同一条链，链上每站只做一件可验证的事（规范化/落地/鉴权/能力/证据/累积/签发/审计）。它带来三个系统级好处：(i) **完全中介**——执行边只认中介签发的意图令牌，没有令牌就不动，旁路从"隐形 bug"变成"可检测事件"；(ii) **策略即数据**——门顺序、阈值、schema 集都是带版本签名的配置，动作令牌绑定 policy_version，任何一次执行都可复现审计；(iii) **控制/数据平面分离**——策略与元模型更新走控制平面（签名 + 影子 + 校准回归 + 审查），实时动作走数据平面，二者不互相污染。代价是中介层成为最大可信基与实时瓶颈，所以链必须短、每站 O(1)、fail-closed 且可旁路检测。

**灵感 3（两词合流 → 语义平面与授权平面分离）**
直觉：把所有东西塞进一个"安全中间件"是危险的：一个越强的解释器若同时能授权，它就能"泛化"出新权限。正确切法是两个平面：**语义平面**（IGC，可泛化、可学习、可能错、只提案）与**授权平面**（CPM，闭世界、有限能力格、只批准、绝不泛化）。语义平面越灵活越好，授权平面越死板越好。二者之间是一道**类型边界**：语义推导只能消耗能力格中已存在的能力，且组合取"交"（cap(A∘B)=cap(A)⊓cap(B)），权限层级取"最小"（authority=min leaves）。于是"泛化"再强，也不可能把"观察"泛化成"不可逆接触"。

**灵感 4（组合安全 → 累积计价与意图漂移）**
直觉：单步都安全不等于序列安全。攻击者可以用一串各自合法的小指令，累积出一次越界（萨拉米攻击）。更糟的是，指令泛化让可用的小指令空间变大，组合空间爆炸。中间件必须在**签发令牌之前**就对"这条指令叠加到全局状态上会怎样"计价：累计接触冲量、窗口内 L2 次数、累计偏离已声明目标、累计探针预算……这就是 CEM。它把安全从"每条指令一个谓词"升级为"整个会话一组不变量"。因为不可逆效果不能靠事后回滚，计价必须发生在承诺之前，而不是事后。

**灵感 5（与第 58 轮审查衔接 → schema 本身也是一种泛化主张）**
直觉：既然每个 schema 都声称"满足这个模板的任意指令都保持这个意思"，它本身就是一条**泛化主张**！于是第 58 轮的 GCR/IRB 自动适用：schema 先注册 κ_schema（覆盖域 ℰ_schema、语言变体 𝒮_schema、漂移界、见证集），经独立审查才可被加载；中间件控制面只加载 Valid 的 schema 集；一旦用户说"我不是这个意思"（语义证伪事件），就触发 CR 式收缩，只缩不扩。这样"指令泛化"没有引入新的、免审的信任源，而是被既有的审查机器接管。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（意图中间表示与指令泛化编译 IGC）** 指令来源 `I = I_text ⊎ I_task ⊎ I_policy ⊎ I_env`，每条指令带来源权限 `a_src ∈ A`（定义 147）。意图中间表示 `ι=(op, refs, pre, eff, cap, prov, a_src)`：`op∈𝒪`（操作代数：移动/接触/抓取/观察/询问/停止…），`refs` 为指称项（必须可绑定到地图实体 𝓜 或本体类型谓词），`pre/eff` 取自本体而非自由文本，`cap⊆Cap` 为所需能力，`prov` 为来源轨迹。schema 代数 `𝒮=(Σ0, ∘, ⊕, ⊗, ^*)`；编译是类型推导 `C_Σ: I → 2^{ι}`，只有能推出类型 `τ` 的候选进入候选集。每条候选附 `g_cert=(π, δ_g, u_refs, κ_schema)`：`π` 推导树，`δ_g` 语义漂移（原指令与 IR 反译的受限语言距离 + 歧义质量），`u_refs` 未绑定指称数。泛化门：`δ_g≤θ_g ∧ u_refs=0 ∧ Cov 查证通过`，否则进澄清/拒绝，**绝不选"最像"的候选**。

**定义 146（安全中介链 SMC / 引用监视器）** 链 `Π=(μ_norm, μ_ground, μ_auth, μ_cap, μ_evid, μ_cem, μ_mint, μ_audit)`，固定顺序、全为偏函数，任一返回 reject 则 fail-closed。执行边 `E` 的状态转移仅在持有有效意图令牌 `τ` 时允许：`τ=Sign(K_mw, (H(ι*), cap_used, auth, policy_version, subject, nonce, exp))`。**完全中介不变量**：`∀a∈Executed: ∃τ, Verify(τ,a)=1`。审计链每站追加 `h_i=H(h_{i-1}‖in‖out‖policy_version)`，可检测跳站/改序/伪造。控制平面中 schema/阈值/元模型/门顺序均为数据，须签名、版本化、影子运行、校准回归（假接受不增、OOD 检出率不降、旁路检测不降）后方可加载；令牌绑定 policy_version，故任何历史动作可复现。

**定义 147（闭世界能力膜与指令权限层级 CPM）** 能力格 `ℒ_cap=(Cap,⊑,⊓,⊔,⊥,⊤)`；`cap_req(ι)=⊓_{x∈leaves(π)} cap(x)`，`authority(ι)=min_{x∈leaves(π)} a_src(x)`，其中 `A_hard ≻ A_op ≻ A_plan ≻ A_learn ≻ A_env`。组合单调性保证泛化不放大任何权限。硬约束 `A_hard`（物理安全包络、最大接触力、L2 不可逆边界）不在语义平面内，任何指令都不能作为其操作数，也不能修改它。**非干涉**：低权限输入不得影响高权限授权参数——`∀s,t: a_src(s)≤A_learn ⇒ f_auth(s)=f_auth(s')` 对只改动该输入的 `s'` 成立（信息流不变量），因此环境文本/学习策略无法"把操作者的 auth 说大"。令牌不可转移、不可放大、可预算化。

**定义 148（泛化证书与覆盖 GCE）** 覆盖矩阵 `Cov: 𝒪×场景×语言变体×具身 → 支持度`，schema 覆盖完备性必须披露（盲区显式）。δ_g 校准契约：覆盖集上 `P(真实语义漂移>δ_g)≤α_sem`（留出改写集经验校准，并承认其分布性）；**非统计兜底是新颖性门 + 澄清**，不是更小的 α。指称幻觉：ref 未绑定到 𝓜 实体、或无证据谓词见证 ⇒ `u_refs>0` ⇒ 禁不可逆动作。反译一致性：`clamp(IR)` 由独立检查器（或经权限层级校验的人）与原指令比对，不一致使 δ_g↑。过泛化/欠泛化双指标：**假接受**（危险意图编译成安全模板）与**假拒绝**（合法新指令被拒）分开计量，不能用一个"正确率"掩盖。

**定义 149（累积效应监视 CEM / 组合安全）** 全局状态 `y_t`（累计接触冲量、窗口内 L2 次数、累计越界距离、剩余风险预算、与已声明目标的漂移度）。令牌签发前检查 `Admissible(y_t, eff(ι))` 且 `y_{t+1}=T(y_t,eff(ι))` 满足不变量集 `Inv`。累积计价：序列 `σ=ι_1…ι_T` 的 `cap_seq=⊓_t cap(ι_t)`，但 `cost_seq=Σ_t cost(ι_t;y_t)` 随状态累积——**单步 cap 合法不蕴含序列 cost 合法**。萨拉米检测：运行意图的语义趋势与高权限来源声明的目标之间的漂移 `drift_t` 超阈 ⇒ 链式降档/澄清/停。由于不可逆效果不可回滚，CEM 必须在 `μ_mint` 之前前置计价，而非事后。

**定义 150（中介化探-诺-演 MCPS）** 每个检查点的动作请求都经 SMC；澄清是一种带成本的探询：泛化门触发时，向**权限层级允许的最高来源**发澄清（`A_hard`→物理约束只读、`A_op`→操作者、`A_plan`→规划器；`A_env/A_learn` 不得作为澄清回答者），澄清有 VOI 与超时 `τ_clar`，超时→保守默认（绕行/L2/安全停）。澄清消耗 CEM 预算，防止"无限问人"或"用澄清拖过风险"。终止性：每指令在 `(compile, clarify, probe, reroute, stop)` 的有限深度内落到确定出口。

## 2. 关键算法伪代码（完整版见产物区）

```python
def compile_intent(instr, onto, schemas, src):
    forest = schemas.derive(instr, onto)            # schema 代数类型推导
    cands = [f for f in forest if f.well_typed]
    if not cands:
        return None, GCert(novel=True, delta_g=INF)
    for f in sorted(cands, key=lambda f: drift(f, instr)):
        u = unbound_refs(f.ir, onto)
        dg = roundtrip_drift(f.ir, instr, onto)
        if dg <= theta_g and u == 0 and schemas.covered(f.ir):
            return f.ir, GCert(f, dg, u, f.schema_claim)
    return None, GCert(novel=True, delta_g=min(drift(f, instr) for f in cands))

def mediate(instr, ctx, policy):                    # 链路 + 令牌（IP-146/147/149）
    ir, gc = compile_intent(instr, ctx.onto, policy.schemas, instr.src)
    if ir is None:                    return clarify_or_stop(instr, gc, ctx)  # 不猜
    if not noninterference(ir, ctx.subject, policy): return reject('authority')
    cap = cap_meet(ir.cap)                          # 组合取交：不放大
    if not cap_le(cap, ctx.subject.cap): return reject('capability')
    if not evidence_gate(ir, ctx, policy): return reject('evidence')  # 第 58 轮 FSE
    if not cem.admit(ir.eff, ctx.session): return reject('cumulative')
    return mint(ir, cap, ir.authority, policy.version, ctx.subject, ctx.mw)

def execute_edge(a, tok, mw):
    if not mw.verify(tok, a): return refuse(a)      # fail-closed，唯一强制点
    return actuate(a)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| IGC | O(\|F\|·d_schema)/指令，深度×宽度剪枝 | O(K_schema) | δ_g 校准、覆盖审计、非统计兜底 |
| SMC | O(#pass)=O(1)/令牌；哈希链 O(1) | O(1) | 完全中介、fail-closed、令牌防伪 |
| CPM | O(\|Cap\|) 格交 | O(\|Cap\|) | 单调不放大、权限层级非干涉 |
| GCE | O(\|refs\|)（索引绑定） | O(\|V\|) | 未绑定即拒、反译一致 |
| CEM | O(\|Inv\|)/令牌 | O(H) 窗口 | 前置计价、时序不变量 |
| MCPS | PCE++ + O(#clarify·C_VOI) | O(\|V\|+\|σ\|) | 澄清有界、四态终止 |

**正确性定理（Instruction-Mediated Generalization Soundness, IMGS 概要）**：在 A33–A44 上加 `(A45)` 语义漂移诚实：覆盖域内 δ_g 是真实语义漂移上界，覆盖外必进新颖性门；`(A46)` SMC 完全中介、防篡改、fail-closed，旁路概率 ≤δ_bypass；`(A47)` CPM 格单调与非放大成立、权限层级非干涉成立；`(A48)` CEM 不变量覆盖所有已声明约束、检测延迟 ≤1 令牌或 ≤τ_cem。则：(i) **泛化不提权**：任意指令（含未见组合）`cap(ι) ⊑ ⊓_{leaf} cap(leaf)` 且 `authority=min`，语义可泛化而权限不可泛化；(ii) **中介完备**：`P(执行未经有效令牌的动作)≤δ_bypass`，且所有执行动作已过 FSE 与 JUR；(iii) **解释健全**：覆盖内 `P(意图错)≤δ_int+α_sem`，覆盖外由新颖性门漏检 ≤δ_nov 且漏检路径只进澄清/停、不进不可逆承诺；(iv) **组合安全**：若每令牌过 CEM 且 Inv 覆盖全部约束，则序列越界概率 ≤δ_cem；(v) 部署界 `P_safe ≥ 1 − Σ_ι[δ_int+α_sem+δ_nov·(1−clarify)+δ_bypass] − Σ_cp R_stat(cp) − P(CEM 漏检) − R_ind`。

## 6. 本轮最大风险

**一句话**：本轮把系统的安全命脉押在一个"既解释又守门"的统一中介层上——它越强，越是最大可信基与实时瓶颈，也越诱使人在紧急时为性能绕过它；而语义漂移证书终究是分布性的，真正的非统计兜底只有"不猜、去问、域外拒绝"，一旦澄清被跳过或中介被旁路，泛化就会以动作合法的形式把越权意图送进不可逆接触。

### IP-145 IGC（指令泛化编译与泛化证书）

```python
def compile_intent(instr, onto, schemas, src):
    forest = schemas.derive(instr, onto)              # schema 代数类型推导森林
    cands = [f for f in forest if well_typed(f, onto)]
    if not cands:
        return None, GCert(novel=True, delta_g=INF, u_refs=INF)
    best = None
    for f in sorted(cands, key=lambda f: drift(f, instr, onto)):
        u = unbound_refs(f.ir, onto)                  # 指称必须绑定地图/本体
        dg = roundtrip_drift(f.ir, instr, onto)       # 独立反译一致性
        cert = GCert(pi=f, delta_g=dg, u_refs=u, schema_claim=f.schema.claim)
        if dg <= theta_g and u == 0 and covered(f.ir, f.schema):
            return f.ir, cert
        best = better(best, cert)
    return None, best or GCert(novel=True, delta_g=INF)

def drift(f, instr, onto):
    return lang_dist(denorm(f.ir), instr) + ambiguity_mass(f.ir, onto)

def schema_derive(instr, onto, schemas):
    # 只允许 seq/choice/param/iterate；原子 schema 必须引用 Valid κ_schema
    return [p for p in schemas.parse(instr, onto)
            if all(s.claim.valid for s in p.leaves)]
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IGC | O(\|F\|·d_schema)/指令，深度×宽度有界剪枝 | O(K_schema) | δ_g 诚实、覆盖查证（A45） |
| SMC | O(#pass)=O(1)/令牌；哈希链 O(1) | O(1) 链状态 | 完全中介、防篡改、fail-closed（A46） |
| CPM | O(\|Cap\|) 格交 | O(\|Cap\|) | 单调不放大、权限非干涉（A47） |
| GCE | O(\|refs\|) 索引绑定 | O(\|V\|) | 未绑定即拒、过/欠泛化分账（A45） |
| CEM | O(\|Inv\|)/令牌 | O(H) 窗口 | 前置计价、时序不变量（A48） |
| MCPS | PCE++ 加 O(#clarify·(C_VOI+C_eval)) | O(\|V\|+\|σ\|) | 澄清有界、四态终止 |

**正确性定理（Instruction-Mediated Generalization Soundness, IMGS）**
假设 A22–A32、A33–A40、A41–A44 成立；**(A45)** IGC 语义漂移诚实：覆盖域内 δ_g 是真实语义漂移上界，覆盖外必进新颖性门；**(A46)** SMC 完全中介、防篡改、fail-closed，旁路概率 ≤δ_bypass；**(A47)** CPM 格单调、组合不放大、权限层级非干涉成立；**(A48)** CEM 不变量覆盖所有已声明约束、检测延迟 ≤1 令牌或 ≤τ_cem。则：

1. **泛化不提权（No privilege amplification）**：对任意指令（含未见过的组合），`cap(ι) = ⊓_{x∈leaves(π)} cap(x) ⊑ cap(x)` 且 `authority(ι)=min leaves`。故"语义可以泛化、权限不能泛化"由代数归纳与 A47 **构造性**成立，不依赖任何统计假设。
2. **中介完备（Complete mediation）**：`P(∃ 执行动作 a 无有效令牌) ≤ δ_bypass`；且由 A46 与第 58 轮 FSE/JUR，所有执行动作同时满足证据门与管辖门。旁路从"隐形"变为"可检测事件"。
3. **解释健全（Interpretation soundness）**：覆盖域内 `P(意图错) ≤ δ_int + α_sem`；覆盖域外新颖性门漏检 ≤ δ_nov，且漏检路径只进入澄清或安全停，**不进入不可逆承诺**（硬边界由 IP-148 的 u_refs 与 IP-150 的澄清源层级保证）。
4. **组合安全（Compositional safety）**：若每令牌过 CEM 且 Inv 覆盖全部已声明约束，则序列 `σ` 违反全局约束的概率 ≤ `δ_cem + Σ_t δ_step(ι_t)`；萨拉米攻击（每步合法、整体越界）检出概率 ≥1−δ_cem，因为 `cost_seq=Σ cost(ι_t;y_t)` 在承诺前被计价。
5. **风险分解（承接第 58 轮）**：`P(unsafe) = R_stat + R_ind + R_instr`，新增的 `R_instr` 明确拆为 `δ_int+α_sem+δ_nov·(1−clarify)+δ_bypass`——**解释误差、语义覆盖、澄清失效、中介旁路**四种不同性质的失效，而不是笼统的"模型置信低"。
6. **部署界**：

```
P_safe ≥ 1 − Σ_ι [δ_int(ι) + α_sem + δ_nov·(1−clarify) + δ_bypass]
             − Σ_cp R_stat(cp) − P(CEM 漏检) − R_ind
（权限放大项由 CPM 构造性置零，不计入概率和）
```

关键：**权限不放大由代数构造保证（免费）**，安全性真正需要靠统计/运行时的只剩"解释是否正确""中介是否被绕过""累积是否越界"三项；把这三项显式拆开，才能对每一项配不同性质的护栏（证书 / 引用监视器 / 不变量），而不是继续往一个 δ 上堆。

云边协议 CEB-R → **CEB-M**（Mediated）：云端可以下发更强的 schema 集、门策略与元模型，但**任何 schema 的扩域、任何新门顺序、任何阈值放宽都必须先注册为泛化主张并过独立审查**，边端不得自批；更新须影子运行并通过"假接受不增 / OOD 检出不降 / 旁路检测不降"三项回归，令牌绑定新的 policy_version 后旧令牌全部失效。边端回传语义证伪（"我不是这个意思"）、旁路尝试、CEM 越界与澄清记录，作为审查方收缩 schema 覆盖域与更新对抗集的输入。第 58 轮"一切泛化主张走独立审查"在本轮推广为"**一切指令解释走编译、一切解释结果走唯一中介、一切中介策略走审查；中介自身的审计链不可旁路**"。

## 6. 本轮最大风险

**一句话**：本轮把系统的安全命脉押在一个"既解释又守门"的统一中介层上——它越强，越是最大可信基与实时瓶颈，也越诱使人在紧急时为性能绕过它；而语义漂移证书终究是分布性的，真正的非统计兜底只有"不猜、去问、域外拒绝"，一旦澄清被跳过或中介被旁路，泛化就会以动作合法的形式把越权意图送进不可逆接触。
