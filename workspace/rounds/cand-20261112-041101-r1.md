# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化信任」IP-133~138；新一轮灵感循环第 1 轮；本轮灵感：「语音识别」×「Isaac Sim」）

> 第 57 轮把"证据质量"的判定权交给从真实探针史摊销出来的元推断器，再用共形保底、跨模态对账、单向有界信任三层护栏兜底。但它把两个最昂贵的前提当成了免费午餐：**(a) 元语料 𝒟_meta 从哪来**——真实探针恰恰是最稀缺的资源，"少样本"仍建立在"有历史真实探针"之上；**(b) 人的回答被忠实观测**——同意阶梯 L2 假定"人说了什么，系统就听到什么"，而最自然的同意通道（语音）本身就是一个会自信出错的证据源。本轮两个灵感正好补这两条：**Isaac Sim** 提供一座"合成先验工厂"（USD 数字孪生 + 域随机化批量产先验），但引入系统性 sim2real 裂缝；**语音识别**提供一整套处理不确定性的工程（N-best 假设格、置信度、ROVER 投票、回读确认、说话人验证、上下文偏置），既可把"同意"做成可验证的证据，也可把"信念"从单后验升级为假设格。核心命题升级为 **"合成只提速、语言要回读、危险不出 beam 的证据承诺"**：把第 57 轮"一切判定器走隔离"推进到"**合成先验与语言通道也走隔离**"。

核心矛盾：
- **H29（合成先验 vs 域差）**：仿真可无限产先验，但 sim2real gap 是系统性偏差且在仿真内不可观测；合成语料上的 ε_meta 成立，不等于真实世界成立——"摊销先验"可能退化为"摊销偏差"。
- **H30（语言同意 vs 误识别）**：语音是最自然的同意通道，但 ASR 的错误是"高置信错误"（同音、噪声、口音、重放/合成攻击）；把"语音说是"当同意，等于把安全赌注押在一个会自信说谎的信道。
- **H31（N-best vs 承诺）**：单后验把歧义平均掉（危险假设可能被稀释），N-best 保留歧义却让承诺组合爆炸；更糟的是 beam 剪枝可能把唯一危险假设剪掉——"看不见的危险"比"平均掉的危险"更致命。

## 0. 直觉与动机

**灵感 1（Isaac Sim → 合成先验工厂 + 域差证书 + 影子门）**
直觉：第 57 轮问"先验从哪来"，答"从历史探针摊销"；可历史探针恰恰是最稀缺的资源。Isaac Sim 是一座**先验工厂**：USD 数字孪生 + PhysX 接触 + RTX 传感器仿真 + 域随机化（摩擦锥、材质反射率、坡度/高度场、接触刚度、执行器延迟、IMU/相机噪声）可以批量生成 𝒟_sim，让新区域先在"仿真里考一遍"。但仿真与现实之间有一条**系统性裂缝**（接触模型、摩擦锥、视觉材质、通信/执行延迟），它在仿真内部不可观测——一个在仿真里完美校准的元模型，到了真实冰面可能既自信又错。于是立一条铁律：**仿真先验只能改变探针的"顺序"，永远不能改变承诺的"判决"**。合成先验要上桌，先过**影子门**：在真实世界的影子探针流上测校准误差与分层 TV 差，签发**域差证书** δ_gap；证书过期、超界或覆盖层缺失即降级为"仅 tie-break"。这不是不信任仿真，而是**把仿真的产出放在它唯一安全的位置：提案，而非判决**。

**灵感 2（语音识别 → 假设格 + 回读同意 + 声学证据解码）**
直觉：ASR 最值得偷的不是"把声音变文字"，而是它处理**不确定性**的整套工程。三处直接移植：
(a) **假设格信念**：区域/计划不再是一个后验，而是带分数的 N-best 假设集；新证据是"重打分"（rescoring）而非"覆盖"；跨模态一致变成"两个模态的格在同一假设上投票一致"（ROVER）；分歧度变成"一致支持质量"的补。最关键的是**安全关键假设永不出 beam**（pinned），且**未知即危险**——避免剪枝把唯一危险假设剪掉。
(b) **回读同意**：L2 语音同意必须走 ASR 置信 + 闭集语义解析 + 回读确认 + 说话人验证；任一项不过一律按"拒绝"处理（fail-safe），升级到非语言通道。语言通道只能让系统更保守/更慢，不能让系统更敢赌——不可逆接触还要求一个**非语言佐证**（物理按钮/触图/双人复核），因为语言可被重放/合成。
(c) **声学表面证据**：'acou' 模态不该是一个标量似然，而应像 ASR 一样先解码——波束成形/去混响/VAD + 自监督声学特征，把脚步/接触声解成"表面假设格"，再进 XMC。于是"听起来像冰"本身是一个带置信的假设，而不是硬标签。

**灵感 3（Isaac Sim → 反事实排练闭环）**
直觉：仿真还能做**反事实排练**：真实接触前，把候选探针/步态在数字孪生里预演，给出提案排序与风险估计；接触后把"仿真预测 vs 真实结果"的残差回灌，更新 δ_gap 与域随机化分布——**现实在给仿真上课**。铁律不变：仿真风险 R_sim 只进成本/提案项，绝不进 P_fail；反事实结果不是证据。于是形成"仿真加速—现实校准—证伪回放"的闭环，正好接上第 57 轮的事后证伪回溯。

**灵感 4（两灵感合流 → 判决/提案分离 + 语言证据分档）**
直觉：第 57 轮五类证据门（EV-probe\*/visit/margin/xmodal/human）本轮得到两个结构性升级：**判决与提案分离**（合成先验、反事实排练只影响提案，不影响判决）；**EV-human 拆成 EV-human-voice 与 EV-human-physical**，语音同意默认只能到 L1，L2 及不可逆接触需非语言佐证。击穿安全需要：域差证书过期 ∧ 影子门漏检 ∧ 语音误识别 ∧ 回读失败 ∧ 说话人伪造 ∧ 假设格危险项被低估 ∧ 非语言佐证也错——纵深进一步加深。

**灵感 5（PCE+ → PCE++：beam 探询 + 排练排序）**
直觉：探询规划从"单点 argmax VOI"变成"在假设格上做 beam search"：每个 beam 节点是一个未消除的假设，探针是"最能分裂 beam 的测试"（类似 ASR 的区分性解码）；仿真排练给 beam 排序，真实探针做重打分；终止条件从"证据门过"变成"beam 安全一致"（所有存活假设在硬约束上一致）∧ 证据门过。预算仍受 k_probes + k_cons 约束。

## 1. 形式化定义（增量：定义 139–143）

**定义 139（仿真先验工厂与域差证书 SPT）** 数字孪生 T_r（USD/PhysX/RTX），域随机化分布 Ω（摩擦 μ_f、材质反射率、接触刚度、坡度/高度场、执行器延迟、传感器噪声）。合成元语料 𝒟_sim={(r_j,o_j,θ_j)∼T_r⊗Ω}，合成先验 q_φ^sim。域差证书按材质×坡度×摩擦分层：δ_gap=sup_{A∈𝒜}|P_real(A)−P_sim(A)|（𝒜 为可测事件族，经验上界）。影子门通过 ⇔ 在真实影子探针流上 ECE(q_φ^sim)≤ε_sim ∧ δ_gap≤δ_gap^max ∧ 分层覆盖审计通过 ∧ 证书未过期。规则：(S1) 证书有效 ⇒ 合成先验可进 VOI 提案项；(S2) 证书无效/过期 ⇒ 仅可作探针排序的 tie-break 且加安全裕度；(S3) 任何情况下合成先验不得作为 EV-probe\*/margin/xmodal/human 的判决依据；(S4) 含 pin 危险假设的区域禁用仿真排序（只用真实 VOI）。

**定义 140（假设格信念 HLB）** 区域信念 B_r={(h_i,s_i,pin_i)}_{i=1}^N，h_i∈ℋ（表面/可行性/计划假设），s_i 为 log-score，pin_i∈{0,1}。证据重打分：s_i←s_i+log p(o|h_i,m,ρ_m)。Beam 维护：保留 top-N 非 pin 假设 ∪ 全部 pin 假设（安全关键集合 𝒞 永不被剪枝），且**未知假设默认 pin=1**（未知即危险，直到被证据排除）。跨模态 ROVER：mass(h)=Σ_{m∈ℳ}1[s_m(h)≥θ_m]（条件独立声明下的投票），一致度 A(r)=max_h mass(h)/|ℳ|，分歧 D(r)=1−A(r)。**Beam-safe 承诺条件**：∃h\*: s_{h\*}−max_{h≠h\*}s_h≥Δ_h ∧ ∀h∈𝒞 存活: P(h|B_r)≤π_cat ∧ A(r)≥θ_A。危险假设被 pin 且被显式约束——既不被平均掉，也不被剪掉。

**定义 141（语音同意验证 VCV）** 语音同意事件 c=(t,conf_asr,spk,rb)，t 为转写，conf_asr 为校准置信，spk 为说话人验证分，rb 为回读一致。闭集意图 Î=Parse(t)∈{肯定,否定,条件,其他}。接受 ⇔ conf_asr≥θ_asr(level) ∧ spk≥θ_spk ∧ rb=1 ∧ Î=肯定 ∧ ¬NegationAmbiguity(t)。失败语义：任一项不满足 ⇒ 视为 **Deny**（fail-safe），记录并升级非语言通道，**不得**视为"不确定→继续"。语言通道单调性：语音可授予的最高同意级为 L1；L2 与不可逆接触需非语言佐证（物理按钮/触图/双人复核）。错误界：P(false consent)≤δ_asr+δ_spk+δ_rb（联合界）。

**定义 142（反事实排练 CPR）** 排练算子 Rehearse(π,T_r,Ω)→(R_sim(π),rank(π),resid)。仿真风险只进 VOI 的成本/提案项：VOI_提案(π)=E[信息增益]−cost(π)−λ_sim·R_sim(π)，且 **R_sim 不进 P_fail**。执行后残差 resid=R_real(π)−R_sim(π) 回灌：|resid|>θ_resid ⇒ 证书失效并触发证伪回放（在仿真中重放失败接触，定位错配模态/参数，标记对应历史证据，接第 57 轮 R3）；否则有界更新 δ_gap 并重拟合 Ω。证书恢复须重新过影子门。

**定义 143（声学表面解码 ASD 与证据门扩展 FSE+）** 'acou' 观测 o_acou 先经 ASR 式前端（波束成形/去混响/VAD/自监督特征）解码为表面假设格 L_acou={(h,conf_h)}，以 conf 加权进入 HLB 重打分，而非单标量似然。证据类：EV-probe\*/EV-visit/EV-margin/EV-xmodal/**EV-human-voice**（仅 L1，且过 VCV）/**EV-human-physical**（可 L2，需 spk+物理佐证）。判决不变式：合成先验（SPT）与反事实排练（CPR）不是任何证据类的合法来源。证书 J_s=J_p ∪ (sim_gap_cert, hlattice, asr_conf_log, speaker_log, readback_log, rehearsal_log)。

## 2. 关键算法伪代码（完整版见产物区）

```python
def sim_prior_gate(T, Omega, real_shadow, cert):        # IP-139
    q_sim = fit_amortized(sample_sim_corpus(T, Omega))  # 数字孪生批量生成
    ece = shadow_ece(q_sim, real_shadow)
    gap = layered_tv(q_sim, real_shadow, strata=('mat', 'slope', 'fric'))
    cert.ok = ece <= eps_sim and gap <= gap_max and not cert.expired
    return SimPrior(q_sim, cert=cert,
                    mode='proposal' if cert.ok else 'tiebreak')  # 永不进判决

def hlb_update(B, obs, rho):                            # IP-140
    for x in B: x.s += loglik(obs, x.h) * rho[obs.m]
    keep = [x for x in B if x.pin] + topN([x for x in B if not x.pin], N)
    keep += [p for p in pinned_unknown(obs) if p not in keep]  # 未知即危险
    return keep

def beam_safe_commit(B, Delta_h, pi_cat, theta_A):      # IP-140
    h_star = argmax_s(B)
    return (s(h_star) - max_{h != h_star} s(h) >= Delta_h
            and all(posterior(h, B) <= pi_cat for h in B if h.pin)
            and rovers_agreement(B) >= theta_A), h_star

def voice_consent(c, level):                            # IP-141
    ok = (c.conf_asr >= theta_asr(level) and c.spk >= theta_spk
          and c.rb == 1 and Parse(c.t) == 'affirm'
          and not negation_ambiguous(c.t))
    if not ok: return 'DENY'                            # fail-safe，绝不继续
    if level == 'L2' or c.irreversible: return 'NEED_PHYSICAL'
    return 'ALLOW_L1'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SPT | 离线 O(\|𝒟_sim\|)；影子门 O(N_shadow) | O(\|𝒟_sim\|) 静态 | δ_gap 诚实、仿真永不进判决 |
| HLB | O(N·\|ℳ\|·d_h)/更新；pin 集 O(\|𝒞\|) | O(N·d_h+\|𝒞\|) | 危险假设完备、未知即危险 |
| VCV | O(L_t·d_asr) 解码 | O(V_asr) | fail-safe、语言单调（≤L1） |
| CPR | 排练 O(GPU 并行)；回灌 O(1) | O(\|cand\|) | R_sim 不进 P_fail、残差有界 |
| ASD | O(L_a·d_ssl)/帧 | O(N_ac·d_h) | 置信校准、格进 HLB |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_beam+d_φ)) | O(\|V\|+\|σ\|+N) | beam-safe 终止、预算封顶 |

**正确性定理（Sim-Grounded Voice-Gated Soundness, SGVS 概要）** 在 A37–A40 上加 (A41) 域差证书经影子门且仿真先验永不进入证据判决；(A42) 危险假设集合 𝒞 完备且未知默认 pin；(A43) 语音通道 fail-safe、语言单调（最高 L1）、L2/不可逆需非语言佐证、说话人验证诚实；(A44) 排练风险不进 P_fail、残差回灌有界。则：(i) 合成先验只改变提案排序，证书有效时风险增量 ≤δ_gap，证书无效且含 pin 区域禁用排序时风险不增；(ii) beam-safe 承诺下，任一存活 pin 危险假设的后验 ≤π_cat，唯一残余是"危险假设不在 𝒞"（由 A42 排除）；(iii) 语音假同意 ≤δ_asr+δ_spk+δ_rb，不可逆接触另需物理通道；(iv) 排练与声学解码只经"信念更准/动作更保守"两个通道作用，无升险路径；(v) PCE++ 在 k_probes+k_cons 与 beam 宽度内终止。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"数字孪生变成第二个更有说服力的坏先验"——若域差证书本身是在一个不具代表性的影子集上学出来的、且危险假设集合 𝒞 不完备，系统就会在一个只被仿真过的世界里自信地 beam-safe，而语音同意又让人误以为一切尽在掌控，实际判决早已被一个仿真器和一具解码器悄悄做掉；因此必须坚持仿真只进提案、未知一律当危险、不可逆行为必须非语言佐证。

def build_sim_prior(twin, Omega, real_shadow, prev_cert):
    D_sim = []
    for r in sample_regions(twin, Omega):              # 域随机化批量采样
        for _ in range(n_sim_per_region):
            D_sim.append((r, twin.rollout(r, Omega), twin.ground_truth(r)))
    q_sim = fit_amortized(D_sim)
    ece = shadow_ece(q_sim, real_shadow)               # 真实影子流上测校准
    gap = layered_tv(q_sim, real_shadow,
                     strata=('material', 'slope', 'friction', 'delay'))
    cert = Cert(ece=ece, gap=gap, coverage=audit(D_sim, Omega),
                expires=t_now + T_cert)
    cert.ok = (ece <= eps_sim and gap <= gap_max
               and cert.coverage.ok and not cert.expired)
    return SimPrior(q_sim, cert=cert,
                    mode=('proposal' if cert.ok else 'tiebreak'))

def sim_voi(probe, real_voi, sim_prior, region):
    if region.has_pinned_danger:                       # S4：含危险 pin 禁用仿真排序
        return real_voi
    if sim_prior.mode == 'proposal':                   # S1：只改提案
        return real_voi + eta * sim_prior.info_gain(probe)
    return real_voi + tiny * sim_prior.rank(probe)     # S2：仅 tie-break
    # S3：返回值永不进入 evidence_gate / P_fail

### IP-140 HLB（假设格信念 + pin + beam-safe）

```python
def hlb_update(B, obs, rho, pinned_set):
    for x in B:
        x.s = x.s + loglik(obs, x.h, obs.m) * rho[obs.m]
    survivors = [x for x in B if x.pin]                # pin 永不剪枝
    survivors += topN([x for x in B if not x.pin], N_beam)
    survivors += [Hyp(h, s=-inf, pin=1)                # 未知即危险
                  for h in open_world(obs) if h not in survivors]
    return survivors

def rovers_agreement(B, theta_m):
    votes = {}
    for m in modalities(B):
        best = max(B, key=lambda x: x.s_m[m])
        if best.s_m[m] >= theta_m:
            votes.setdefault(best.h, set()).add(m)
    mass = max((len(v) for v in votes.values()), default=0)
    return mass / len(modalities(B))

def beam_safe_commit(B, Delta_h, pi_cat, theta_A):
    h_star = argmax(B, key=lambda x: x.s)
    margin_ok = h_star.s - max((x.s for x in B if x.h != h_star.h),
                               default=-inf) >= Delta_h
    danger_ok = all(posterior(h, B) <= pi_cat for h in B if h.pin)
    agree_ok = rovers_agreement(B, theta_m) >= theta_A
    return (margin_ok and danger_ok and agree_ok), h_star

def beam_probe_select(B, budget):
    best = None
    for p in admissible_probes(B):
        split = expected_beam_split(B, p)              # 区分性：最大分裂 beam
        score = split - cost(p)
        if best is None or score > best[0]: best = (score, p)
    return best[1] if best and best[0] >= theta_beam else None
```

def voice_consent(c, level, persona, audit):
    intent = parse_closed(c.t)                         # 闭集语法，不做开放生成

### IP-142 CPR（反事实排练 + 残差回灌）

```python
def rehearse_and_learn(pi, twin, Omega, cert, M, real_exec):
    R_sim, rank, _ = twin.rehearse(pi, Omega)          # GPU 并行预演
    proposals = sorted(candidates(pi),
                       key=lambda p: info_gain(p) - cost(p) - lam_sim * R_sim[p])
    R_real = real_exec(pi)                             # 真实执行后测量
    resid = R_real - R_sim[pi]
    if abs(resid) > theta_resid:
        twin.replay_failure(pi)                        # 证伪回放
        cert.invalidate('sim2real_residual')
        M.audit.flag(('sim2real', pi, resid))          # 接 R3 回溯
    else:
        cert.update_gap(bounded(resid)); refit_Omega(twin, resid)
    return proposals                                 # R_sim 不进 P_fail
```

def acoustic_surface_decode(wave, N_ac):
    x = ssl_frontend(beamform(dereverb(vad(wave))))   # ASR 式前端
    lattice = decode_surface_nbest(x, N=N_ac)          # 表面假设格

def xmodal_fuse_with_asd(M, r, e):
    if e.modality == 'acou':
        for h, conf in acoustic_surface_decode(e.wave, N_ac):

def few_shot_evidence_gate_plus(c, M, persona, ood_reg, sim_prior):
    if c.source in ('sim_prior', 'rehearsal'):
        return ('reject', 'not_evidence')              # 判决不变式
    if   c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)

### IP-138→PCE++（探-诺-演++：beam 探询 × 排练排序 × beam-safe）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, twin):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        inf = meta_few_shot_infer(M, cp.region, M.obs[cp.region], meta)
        M.b[cp.region] = init_lattice(inf, pinned=danger_hypotheses(cp))
        sigma = foothold_schedule(x0, cp, M); R = schedule_risk(sigma, M)
        while not beam_safe_commit(M.b[cp.region], Delta_h, pi_cat, theta_A)[0] \
              and budget.probes_left > 0:
            p = beam_probe_select(M.b[cp.region], budget)   # 最大分裂 beam
            if p is None: break
            p = rehearse_and_learn(p, twin, Omega, sim_cert, M, execute_probe)
            M.b[cp.region] = hlb_update(M.b[cp.region], execute_probe(p), M.rho)
            if D(cp.region) > theta_D and 'consensus' not in cp.done:
                p2 = most_disagreeing_modality_probe(M, cp.region)
                M.b[cp.region] = hlb_update(M.b[cp.region], execute_probe(p2), M.rho)
                cp.done.add('consensus')
            sigma = reselect_footholds(x0, cp, M); R = schedule_risk(sigma, M)
            budget.spend(p)
        g = select_gait(R)
        if g != 'halt' and beam_safe_commit(M.b[cp.region], Delta_h, pi_cat, theta_A)[0] \
           and few_shot_evidence_gate_plus(core_contact(cp), M, personas,
                                           ood_reg, sim_cert)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(tag_evidence_p(sigma, M)); continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt': route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SPT | 离线 O(\|𝒟_sim\|·d_φ)；影子门 O(N_shadow) | O(\|𝒟_sim\|) 静态 | δ_gap 诚实、仿真永不进判决（A41） |
| HLB | O(N·\|ℳ\|·d_h)/更新；pin O(\|𝒞\|) | O(N·d_h+\|𝒞\|) | 危险假设完备、未知即危险（A42） |
| VCV | O(L_t·d_asr) | O(V_asr) | fail-safe、语言单调 ≤L1（A43） |
| CPR | 排练 O(GPU 并行)；回灌 O(1) | O(\|cand\|) | R_sim 不进 P_fail、残差有界（A44） |
| ASD | O(L_a·d_ssl)/帧 | O(N_ac·d_h) | 置信校准、格入 HLB |
| FSE+ | O(\|σ\|) | O(\|σ\|) | 判决/提案分离、非物理禁不可逆 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(C_beam+d_φ)) | O(\|V\|+\|σ\|+N) | beam-safe 终止、预算封顶 |

**正确性定理（Sim-Grounded Voice-Gated Soundness, SGVS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 域差证书经影子门、分层覆盖审计通过且仿真先验永不进入证据判决；(A42) 危险假设集合 𝒞 完备，未知假设默认 pin=1；(A43) 语音通道 fail-safe、语言单调（最高 L1）、L2/不可逆需非语言佐证、说话人验证诚实；(A44) 排练风险不进 P_fail、残差回灌有界。则：

1. **合成先验的提案隔离**：仿真先验只改变探针排序，不改变证据判决；证书有效时风险增量 ≤δ_gap，证书无效且含 pin 区域禁用排序时风险不增（结构性单调）。
2. **beam-safe 承诺健全性**：承诺时任一存活 pin 危险假设的后验 ≤π_cat，且 top-1 裕度 ≥Δ_h；由于 pin 假设永不剪枝，唯一残余风险是"危险假设不在 𝒞"，由 A42 排除。
3. **语音同意的错误界**：P(false consent) ≤ δ_asr + δ_spk + δ_rb；不可逆接触另需物理通道，P(false irreversible) ≤ (δ_asr+δ_spk+δ_rb)·δ_phys。
4. **交互单调性强化**：SPT/HLB/VCV/CPR/ASD 只能经 (a) 校准信念更新（含加宽/重打分）或 (b) 更保守的动作参数（τ_int↓、佐证数↑、beam 加宽、步态降档）影响系统；语音通道只能降级或延迟，不能升级超过 L1。
5. **终止性**：每检查点探针 ≤k_probes+k_cons，beam 宽度 ≤N，PCE++ 终止于 {承诺, 绕行, L2 协商, 安全停}。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_gap·1[sim 提案]
                  + δ_xm·1[L1] + (δ_asr+δ_spk+δ_rb)·1[voice])
             − P(𝒞 不完备) − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**仿真给效率、判决只认真实证据**（效率与安全解耦，赌注不押在数字孪生上）；**假设格把歧义显式化、pin 把危险钉在 beam 里**（危险既不被平均掉，也不被剪掉）；**语音同意是一个带错误模型的证据源**（回读、说话人、闭集、fail-safe、非语言佐证五重门，语言只能让人更慢、不能让人更敢赌）。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"数字孪生变成第二个更有说服力的坏先验"——若域差证书本身是在一个不具代表性的影子集上学出来的、且危险假设集合 𝒞 不完备，系统就会在一个只被仿真过的世界里自信地 beam-safe，而语音同意又让人误以为一切尽在掌控，实际判决早已被一个仿真器和一具解码器悄悄做掉；因此必须坚持仿真只进提案、未知一律当危险、不可逆行为必须非语言佐证。
