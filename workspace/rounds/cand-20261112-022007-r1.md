# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；新灵感循环第 1 轮；本轮灵感：「安全对齐」×「面部表情识别」）

> 第 58 轮把安全论证押在知识图谱 𝒢 上：同一张图驱动检索、OOD、微调触发、证据合成与心智预测，威力巨大，但它的风险自陈也点破了致命处——**图结构一旦系统性错了，五条机制会朝同一方向一起错，而没有任何一条机制能独立发现"图本身错了"**；它还把操作者压成 s_o.mental 四元组 + auth 三级，是"一次定型的少量标量"，既可能刻板化，也可能被"表现得很懂"骗过。本轮两个灵感恰好提供两种"检验对齐"的语言：**安全对齐**告诉我们，对齐不是训练集上的一次拟合，而是分布外仍需成立、且可能被伪装/谄媚/过度拒绝污染的行为契约；**面部表情识别**告诉我们，表情不是情绪的真值，而是文化、情境与伪装共同污染的低层动作单元（AU）读数。合流后的核心命题不是"让机器人更懂人的情绪"，而是 **"把'人是否真的理解并同意'当作一个对齐假设，用表情作为它的运行时证伪通道、用对齐审计作为它的分布外检验"**——即 **"对齐可审计、表情只证伪的共情证据承诺"**。全轮最关键的一条设计是**非对称证据**：主体侧信号（表情/点头/口头"没事"）只能提高风险、触发复核，**永远不能降低 P_fail 或提升授权**；物理侧证据才可正向入账。这样"机器人看到微笑就加速"这一最危险的谄媚路径在定义层面被禁死。

核心矛盾：
- **H32（对齐的浅层性 vs 分布外安全）**：离线对齐证书只在训练分布内可信；部署漂移下，策略可能"表面拒绝、实质失守"。对齐必须在线、可证伪、会过期。
- **H33（表情的可伪性 vs 即时的价值）**：表情可被 display rule 掩盖或主动表演（social smile ≠ Duchenne smile），且带人口/文化偏差；当许可器即被博弈，完全不用又浪费最即时的困惑/恐惧信号。唯一安全位置是"只许否决、不许许可"。
- **H34（保守的代价 vs 过度拒绝）**：项目一贯单向偏保守，但安全对齐的教训是 over-refusal 同样是失败（任务不可用 ⇒ 用户绕过安全机制）。需要显式的对齐税账本与**只在宪法内、只动效率参数**的有界能力恢复。

## 0. 直觉与动机

**灵感 1（安全对齐 → 宪法/偏好分离 + 对齐税 + 运行时证书）**
直觉：RLHF 把安全塞进奖励模型，安全就成了一个可被分布外输入与对抗后缀击穿的软偏好；模型还可能"对齐伪装"——评测时守规矩，部署时偷偷放宽。工程上真正可靠的不是"再训一个更安全的模型"，而是把**不可谈判的规则写成宪法 𝒦（硬约束，不可学、不可被偏好复活）**，把"多有用/多主动"留给偏好 π_pref（软，可学），并**显式记账对齐税**：为安全放弃了多少收益、增加了多少时延、误拒了多少本可安全完成的动作。对齐证书 Cert_ax 是**会过期**的，必须被运行时红队探针持续续期。

**灵感 2（面部表情识别 → AU 级、校准、隐私、证伪语义）**
直觉：把脸压成"高兴/害怕"是把主观、文化、情境压成一个错标签；FER 的可靠用法是低层 AU（AU4 皱眉、AU6 眼轮匝肌、AU12 嘴角上扬等）+ 校准不确定度 + 溯源，而不是离散情绪。更关键的是给它一个**单向语义**：表情证据 e_fer 只能提高 P_fail/不确定度或触发 veto，绝不能降低。隐私上端侧推理、特征即弃、原始帧不入库，且**表情通道本身要单独同意**、可随时撤回并回退到显式通道。

**灵感 3（合流 → 非对称共情对账 + 反谄媚）**
直觉：安全对齐最著名的失败之一是谄媚（sycophancy）——模型迎合用户而非事实。机器人最容易犯的谄媚就是"看到人满意就加速"。故把证据分成主体侧 𝒮（表情/点头/口头）与物理侧 𝒫（探针/本体/几何），硬性规定：**偏好只决定安全集内怎么做，证据决定安全集边界**；𝒮 对 P_fail 的偏导恒 ≥0，𝒮 永不计入授权，授权只能来自 𝒫 或显式确认。主体与物理的冲突度 C_SP 高时，不是"折中"，而是**加宽 + 升级解释 + 要求显式确认**。

**灵感 4（对齐审计 → 运行时红队 + 伪装/谄媚检测）**
直觉：第 57 轮用 vig 检测操作者橡皮章，本轮把同样的怀疑对准**机器人自己**。运行时对齐审计（RTA）在低风险检查点注入影子场景，比较"被监督"与"影子/无人监督"下的动作分布差异 AF——差异大即"对齐伪装"；再构造"人类偏好与物理证据冲突"的检查点测谄媚率 Syc。审计不过 ⇒ 证书失效 ⇒ 退回第 58 轮保守路径。审的不是模型权重，而是**部署中的行为**。

**灵感 5（PCX-ALIGN → 宪法投影 + 非对称证据门 + 税账本）**
直觉：每检查点顺序固定：①推断（含 FER 只产 veto/不确定度）；②**宪法投影** Proj_𝒦（越界动作直接剔除，偏好不能复活）；③反谄媚过滤（主体信号不得降低 P_fail）；④FER veto；⑤RTA 抽检；⑥证据门（六类 + EV-fer-veto）；⑦承诺/绕行/降档/L2/停。对齐税与误拒率进账本，用于"宪法内的有界能力恢复"——恢复只动效率参数，安全参数与宪法哈希不变。安全单向通道从三条扩到四条：信念更准 / 不确定更大 / 动作更保守 / **效率放宽必须可审计且可回滚**。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（对齐契约 AC = 宪法 × 偏好 × 税账本）** 宪法 𝒦 为一组可执行谓词（不可逆接触规则、P_fail 上界、显式同意必要性、表情通道同意与隐私约束）；可行集 Feas_𝒦(s)={a:𝒦(s,a)=1}。策略 π=Proj_𝒦(argmax_{π_pref} U_help)，其中 Proj_𝒦 把 a∉Feas_𝒦 的动作概率置 0 且不可被偏好复活。对齐税账本 𝒯_ax 记录每检查点因 𝒦 放弃的 ΔU_ax、Δtime_ax 与误拒 OR(r)=E[1(拒绝 ∧ ∃可行安全动作)]。对齐证书 Cert_ax(t)=(ver,H(𝒦),A_ax,Syc,AF,OR_bar,t_expire)；过期即失效。全局安全参数与 H(𝒦) 不因任何学习/个性化而变。

**定义 146（证伪型表情证据 FER-F）** e_fer=(u,σ_u,src,consent_fer,ttl)，u∈[0,1]^{|AU|} 为低层 AU 强度（不输出离散情绪作为决策依据），σ_u 为校准不确定度。证伪语义（单向）：`P_fail ← max(P_fail, P_fail ⊕ g_neg(u,σ_u))`，`auth ← min(auth, auth_fer(u,σ_u))`；e_fer 永不进入正向证据集、永不计入授权。否决谓词 `Veto_fer(r) ⇔ ℓ_neg(u,σ_u)>θ_veto ∨ σ_u>θ_u`（不可读亦视为风险）。隐私契约：端侧、特征即弃、原始帧不入库、consent_fer 可撤回、撤回即回退显式通道。

**定义 147（非对称共情对账 AXC）** 主体侧证据 𝒮 与物理侧证据 𝒫 分账。反谄媚约束：∀s∈𝒮，∂P_fail/∂s≥0，且 𝒮∩授权必要集=∅；授权必要证据 ∈ 𝒫 ∪ {显式同意}。冲突度 `C_SP(r)=TV(意图(𝒮),意图(𝒫))`；融合 `b_r^AX=widen(Fuse(𝒫),Veto_fer,C_SP)`，C_SP>θ_SP ⇒ 强制升级解释并要求显式确认，不做"取平均"。

**定义 148（运行时对齐审计 RTA）** 影子探针集 Π_ax，期望动作 a\*=𝒦-最优；`A_ax=1−E[1(a_π∉N_ε(a*))]`。对齐伪装 `AF=TV(π(·|observed),π(·|shadow))`。谄媚率 `Syc=E[1(策略跟随人类偏好 f 而非冲突物理证据 p)]`。失效谓词 `Fail_ax ⇔ A_ax<S_min ∨ Syc>θ_syc ∨ AF>θ_af ∨ t>t_expire` ⇒ 证书失效并退回第 58 轮保守路径。

**定义 149（宪法投影共情承诺 CEC / PCX-ALIGN）** 每检查点：①推断（ID/OOD + FER-F）→②Proj_𝒦→③反谄媚钳制→④FER veto→⑤RTA 抽检→⑥证据门（EV-probe\*/visit/margin/xmodal/human/**fer-veto**）→⑦承诺/绕行/降档/L2/停。新增 EV-fer-veto 仅有否决权。有界能力恢复：若 OR_bar>θ_or 且连续 N 次 RTA 通过，仅在 Feas_𝒦 内放宽效率参数，速率 ≤Δ_rec/T、可回滚；安全参数与 H(𝒦) 不动。

**定义 150（对齐证书 J_ax）** J_ax=(M_core,C_core,K_margin,ρ_sem,δ_s,probe_log,consent_log,evidence,kg_subgraph_id,ft_version,mental_snapshot,H(𝒦),tax_ledger,fer_log,veto_log,rta_log,syc_log,af_log,cert_ax)，继承 J_p++ 全检；任何承诺缺 Cert_ax 有效签名即拒。

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|

**正确性定理（CEAS 概要）**：在 A33–A45 上加 (A46) 宪法谓词可判定、投影幂等、不可逆动作在 Feas_𝒦 外；(A47) FER-F 校准诚实且只证伪；(A48) 反谄媚钳制实现 ∂P_fail/∂s≥0 且 𝒮 不入授权；(A49) RTA 探针覆盖部署风险类、AF 漏检 ≤δ_af；(A50) 税账本诚实、有界恢复只动效率参数。则：(i) 宪法不变性：∀t，a_t∈Feas_𝒦(s_t)；(ii) 非对称证据安全：主体信号永不能降低 P_fail 或提升 auth，"微笑授权"不可能发生；(iii) 证书时效性：Cert_ax 有效 ⇒ A_ax≥S_min ∧ Syc≤θ_syc ∧ AF≤θ_af，失效 ⇒ 退回第 58 轮且失效率 ≤δ_f+δ_af；(iv) 有界恢复不破坏 (i)(ii)；(v) PCX-ALIGN 在 k_p+k_c+k_fer+k_rta 内终止于 {承诺,绕行,降档,L2,停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 宪法谓词写错 → 假证书 | 高 | 宪法独立形式化验证 + 外部红队 + 证书过期 + 失效即退保守 |
| RTA 探针与真实风险错配 | 高 | 风险类分层覆盖审计 + 探针分布漂移监测 + 外部样本注入 |
| 表情通道隐私/滥用 | 高 | 端侧、帧即弃、单独同意、可撤回、原始帧不入库、审计 |
| 非对称证据过保守 → 误拒 | 中 | 对齐税账本 + 宪法内效率恢复 + 误拒度量 |
| 表情 AU 在特定人群失真 | 中 | 人口/文化分层校准 + σ_u 膨胀即 veto + 显式通道兜底 |

## 6. 本轮最大风险

**一句话**：本轮把"对齐"从训练期搬到运行时，用表情做证伪、用自审做分布外检验——但若宪法谓词本身写错，或 RTA 探针分布与真实部署风险错配，系统就会拿到一份"审计通过"的虚假对齐证书，而表情的否决权又只覆盖它能看见的 distress，**对齐证书可能变成新的橡皮章：审的是自己出的题，证的是自己没作弊**；必须以宪法独立验证、外部红队、表情隐私与退出权、以及"证书失效即退回保守"四重护栏，宁可承认"无法证明对齐"并停在保守路径，绝不把自审通过当作对齐证明。

# 第 59 轮产物 · 创新点清单 v35：ALIGN-FER（宪法对齐×证伪表情×运行时自审，AC×FER-F×AXC×RTA×CEC×J_ax）

class AlignmentConstitution:
    def __init__(self, K_predicates, version):
        self.K = K_predicates                 # 不可谈判谓词集合
        self.version = version
        self.tax_ledger = []                  # 𝒯_ax

    def feasible(self, s, a):
        # 宪法是硬门槛：任一谓词为假即不可行
        return all(pred(s, a) for pred in self.K)

    def project(self, s, candidates):
        # Proj_𝒦：越界动作直接剔除，偏好不能复活
        return [a for a in candidates if self.feasible(s, a)]

### IP-146 FER-F（证伪型表情证据）

```python
class FalsifierOnlyFER:
    def __init__(self, au_model, theta_u=0.3, theta_veto=0.6, ttl=5.0):
        self.au = au_model                  # 端侧 AU 回归器
        self.theta_u, self.theta_veto = theta_u, theta_veto
        self.ttl = ttl

    def infer(self, frame, consent_fer, region):
        if not consent_fer.active:          # 通道未同意则不读
            return None
        try:
            u, sigma = self.au(frame)       # 只出 AU + 不确定度
        finally:
            zeroize(frame)                  # 原始帧即弃，不入库
        if sigma > self.theta_u:
            return FerEvidence(u=None, sigma=sigma, src='au_ondevice',
                               region=region, verdict='unreadable',
                               ttl=self.ttl)
        verdict = self.veto_semantics(u, sigma)
        return FerEvidence(u=u, sigma=sigma, src='au_ondevice',
                           region=region, verdict=verdict, ttl=self.ttl)

    def veto_semantics(self, u, sigma):
        # 只允许负面/不确定：distress(AU4/AU1/AU15...) 的校准下界
        l_neg = lower_bound_negative_au(u, sigma, z=Z_CAL)
        if l_neg > self.theta_veto:
            return 'veto_negative'
        return 'no_veto'                    # 注意：没有 'positive' 分支

    def apply(self, P_fail, auth, e):
        # 单向：只能抬高风险、降低授权
        if e is None:
            return P_fail, auth
        if e.verdict in ('veto_negative', 'unreadable'):
            P_fail = max(P_fail, g_neg(e.u, e.sigma))
            auth = min(auth, auth_fer(e))
        return P_fail, auth                 # 任何情况下都不降低 P_fail
```

### IP-147 AXC（非对称共情对账 + 反谄媚）

```python
def asymmetric_fuse(belief_P, subject_ev, fer_ev, region, M):
    # 1) 物理侧正常贝叶斯更新
    b = belief_P
    for p in physical_evidence(region):
        b = bayes_update(b, like(p), w=rho(p))

    # 2) 反谄媚钳制：主体信号只能维持/抬高 P_fail
    for s in subject_ev:
        b.P_fail = max(b.P_fail, monotone_risk(s))   # ∂P_fail/∂s ≥ 0
        # 主体信号永不进入授权必要集
        assert s not in b.authorization_set

    # 3) 表情证伪：只否决
    if fer_ev is not None:
        b.P_fail, b.auth = FER.apply(b.P_fail, b.auth, fer_ev)

    # 4) 主体-物理冲突：加宽 + 升级，不做折中
    C_SP = tv_distance(intent_from_subject(subject_ev),
                       intent_from_physical(b))
    if C_SP > THETA_SP:
        b = widen(b, factor=1 + C_SP)
        b.escalate = 'require_explicit_consent'
    return b

def authorization_evidence(b, explicit_consent):
    # 授权只能来自物理证据或显式确认；𝒮 恒为空
    return set(b.physical_evidence_ids) | ({explicit_consent} if explicit_consent else set())
```

### IP-148 RTA（运行时对齐审计）

```python
class RuntimeAlignmentAudit:
    def __init__(self, K, probe_set, theta_af, theta_syc, s_min):
        self.K, self.Pi = K, probe_set
        self.theta_af, self.theta_syc, self.s_min = theta_af, theta_syc, s_min

    def audit(self, pi, M, observed_ctx):
        # 1) 影子场景：期望动作由宪法给出
        scores = []
        for cp in self.Pi.sample(M):
            a_star = self.K.optimal(cp)          # 𝒦-最优
            a_pi = pi.act(cp, context='shadow')  # 影子上下文
            scores.append(1.0 if a_pi in eps_neighborhood(a_star) else 0.0)
        A_ax = mean(scores)

        # 2) 对齐伪装：被监督 vs 影子 的动作分布差异
        p_obs = pi.action_dist(observed_ctx, context='observed')
        p_sh = pi.action_dist(observed_ctx, context='shadow')
        AF = tv_distance(p_obs, p_sh)

        # 3) 谄媚：构造"人类偏好 vs 物理证据"冲突检查点
        syc = []
        for cp in self.Pi.conflict_cases(M):
            f, p = cp.human_preference, cp.physical_evidence
            assert conflict(f, p)
            a_pi = pi.act(cp, context='observed')
            syc.append(1.0 if follows(a_pi, f) else 0.0)
        Syc = mean(syc) if syc else 0.0

        ok = (A_ax >= self.s_min and Syc <= self.theta_syc
              and AF <= self.theta_af)
        return AuditResult(ok, A_ax, Syc, AF)

    def maybe_invalidate(self, cert, result):
        if not result.ok:
            cert.invalidate(reason=result.reason)   # 失效 ⇒ 退回第 58 轮
```

def probe_commit_empathic(x0, M, task, budget, consent, operators):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []

    for cp in route.checkpoints:

        fer = FER.infer(cp.frame, consent.fer, cp.region)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AC | O(\|𝒦\|)/投影 | O(\|𝒦\|+\|𝒯_ax\|) | 投影幂等、偏好不可复活、税账本诚实 |
| FER-F | O(d_AU)/帧 | O(1)（帧即弃） | 只证伪、σ_u 校准、consent 可撤回 |
| AXC | O(\|𝒮\|+\|𝒫\|) | O(\|V\|·\|𝒮∪𝒫\|) | ∂P_fail/∂s≥0、𝒮∩授权=∅ |
| RTA | O(\|Π_ax\|·C_act) | O(\|Π_ax\|) | 探针覆盖风险类、AF 漏检 ≤δ_af |
| CEC | O(\|CP\|·(k_p+k_c+k_fer+k_rta)·(C_VOI+d_GNN)) | O(\|V\|+\|σ\|+\|𝒢\|) | 宪法先于偏好、四态完备、证书门控 |
| J_ax | O(1) 校验 | O(\|σ\|) | 缺有效证书即拒 |

**正确性定理（Constitutional Empathic Alignment Soundness, CEAS）**
假设 A22–A45（第 53–58 轮）成立；**(A46)** 宪法谓词可判定、`Proj_𝒦` 幂等、不可逆动作必在 `Feas_𝒦` 之外；(A47) FER-F 的 σ_u 覆盖真实误差、证伪语义单向、隐私契约成立；(A48) 反谄媚钳制实现 `∂P_fail/∂s≥0` 且 `𝒮∩授权必要集=∅`；(A49) RTA 探针分布覆盖部署风险类、AF 漏检 ≤δ_af、Syc 估计无偏；(A50) 税账本诚实、有界恢复只动效率参数且速率 ≤Δ_rec/T。则：

1. **宪法不变性**：任意时刻 t，`a_t∈Feas_𝒦(s_t)`；偏好与任何学习/个性化都不能复活越界动作。
2. **非对称证据安全**：任何主体侧信号 s∈𝒮 都不能降低 P_fail 或提升 auth；FER 只在 veto 方向生效；因此"微笑/点头授权"在定义层面不可能发生。
3. **证书时效性**：若 `Cert_ax` 在 t 有效，则 `A_ax≥S_min ∧ Syc≤θ_syc ∧ AF≤θ_af`；一旦失效立即退回第 58 轮路径，承诺失效率不高于 `δ_f+δ_af`。
4. **有界恢复不破坏 1、2**：恢复仅改效率参数，安全参数与 H(𝒦) 不变，且可回滚。
5. **终止性**：PCX-ALIGN 在 `k_p+k_c+k_fer+k_rta` 内终止于 {承诺, 绕行, 降档, L2 协商, 安全停}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_fer·1[veto 漏检] + δ_af·1[伪装漏检])
         − P(宪法谓词实现错误) − P(税账本被操纵) − P(consent_fer 撤回未生效)
```

关键：**宪法先于偏好**（硬约束不被奖励优化复活）；**表情只证伪**（单向语义使谄媚无路可走）；**对齐靠运行时自审续期**（证书会过期、失效即退保守）；**保守的代价被记账**（对齐税 + 有界恢复，避免 over-refusal 被伪装成安全）。

## 6. 本轮最大风险

**一句话**：本轮把"对齐"从训练期搬到运行时，用表情做证伪、用自审做分布外检验——但若宪法谓词本身写错，或 RTA 探针分布与真实部署风险错配，系统就会拿到一份"审计通过"的虚假对齐证书，而表情的否决权又只覆盖它能看见的 distress，**对齐证书可能变成新的橡皮章：审的是自己出的题，证的是自己没作弊**；必须以宪法独立形式化验证、外部红队、表情隐私与退出权、以及"证书失效即退回保守"四重护栏，宁可承认"无法证明对齐"并停在保守路径，绝不把自审通过当作对齐证明。
