# 第 63 轮（承接第 62 轮「ROSE 鲁棒在线场景进化闭环」IP-183~192；本轮灵感：「语音识别」×「材料选型」）

> 第 62 轮 ROSE 把 ESEC 从「静态语义-执行闭环」推进为「学习-鲁棒-场景动态闭环」，但它自述的最大风险是一个单点假设（A72）：RSC 用灵敏度 Jacobian J_φ 把外力矩残差反演为球半径 r_t。一旦 J_φ 病态，或残差被控制回路自身吸收（真实物理偏差不体现在残差里），r_t 就系统性低估，WCV 的 CVaR 球「覆盖失效」，引理 2 与整个 ROSE-Complete 第 2 条退化为纸面承诺。
>
> 本轮从两个看似无关的领域取经，专门拆掉这个单点假设：
> - **语音识别**教我们「不要相信单一硬对齐与单点置信度」：ASR 用 beam search 维护 N-best 假设、用 CTC 边缘化全部对齐、用置信度/拒识（garbage model）与双讲检测（double-talk detection）判断证据是否可用。对应到具身：把单点 φ̂ 换成**材料假设 beam**，把硬相位分段换成**接触相位边缘化对齐**，把「残差一定可信」换成**可观测性检测 + 拒识**。
> - **材料选型**教我们「不确定性不是各向同性的球，而是受材料类别与 Ashby 物性域约束的结构化集合」：材料库给出物理可实现支撑（Ashby 多面体 / 材料单纯形），材料许用值（A/B-basis allowables）给出带统计置信度的安全裕度，材料替代/复合给出假设扩张的物理先验。对应到具身：把 L2 球换成**材料约束椭球**，把 EWMA 半径换成**共形/许用值标定**。
>
> 合流为 **AMBER（Adaptive Material-Beam Estimation for Robustness）**。核心不变量：**覆盖率不再依赖 J_φ 良态**——可观测时由共形标定给 1−α 覆盖；不可观测时 DTA 拒识并回退到材料先验支撑 𝒫（覆盖 1）。J_φ 只影响「效率与保守度」，不再影响「正确性」。

## 0. 直觉与动机

**灵感 1（语音识别 → 从「单点解码」到「Beam × CTC × 拒识」）**

直觉：ASR 面对的是「声学观测有噪、音素边界不唯一、必须在线出词」的问题，它的工程答案不是更准的单点分类器，而是一整套**多假设 + 边缘化 + 置信度管理**机制。具身的物理推断是同构的：观测（外力矩/触觉）有噪、接触相位边界不唯一、必须在线出阻抗。四个可迁移机制：
1. **Beam / N-best**：ASR 从不把 1-best 当唯一真理。物理上，单点 φ̂ 一旦因 sim2real 有偏，整个下游就错；维护 K 个（材料类, 连续物性）假设，后验加权可让正确材料在证据累积后胜出。
2. **CTC 边缘化对齐**：ASR 对所有对齐求和而非硬切分。物理上，把残差归因到「稳态接触」需要知道相位；硬分段一错，J_φ 就在错误相位上估计，反演直接失真。边缘化相位后验把「归因错误」变成可控的软权重。
3. **拒识 / garbage model**：ASR 对低置信、词表外输入拒识。物理上，当残差不可信（被吸收、相位不明、OOV 材料）时，正确动作是**拒绝更新并回退保守**，而不是把噪声灌进 r_t。
4. **双讲检测（AEC 的 double-talk detector）**：这是对 A72 最直接的解药。残差 = 控制回路可吸收分量（回声）+ 真实物理偏差（近端）+ 噪声。双讲检测用相干性/能量比判断「近端是否存在」；对应地，DTA 判断「真实物理偏差是否可从残差中辨识」。

**灵感 2（材料选型 → 从「各向同性球」到「Ashby 多面体 × 许用值」）**

直觉：材料选型从来不是「估计一个材料的密度」，而是「在一个受材料类别约束的可行域里做决策」。这给出三个更结构化的工具：
1. **物性域与 Ashby 多面体**：每种材料有物性区间 P_m（如铝合金的 E、ρ、ν 范围），物理可实现集合是这些区间的凸包/单纯形 𝒫。用它做不确定支撑，比各向同性球更紧（不把「不可能的材料组合」算进最坏情形），且可解释、可审计。
2. **材料许用值（allowables）**：结构设计的安全裕度来自 A-basis/B-basis 统计下界（给定置信度的容差限），而不是拍脑袋系数。对应地，r_t 应由**共形/容差标定**给出，带有限样本覆盖率，而非 EWMA 手调。
3. **材料替代与复合**：相邻材料类、混合体积分数是天然的假设扩张先验。对应地，beam 的扩张用「替代核 κ(m,m′) + 材料单纯形内的凸混合」驱动，而不是随机扰动。

**灵感 3（合流 → AMBER：把「正确性」从 J_φ 上卸下来）**

直觉：第 62 轮的问题不是「r_t 不够大」，而是「r_t 的正确性挂在一个可能不可观测的量上」。AMBER 用两条互不依赖的路径兜底：
- **可观测路径**：MBE 维护材料 beam → CTC-A 保证残差归因正确 → DTA 确认残差含可辨识的近端分量 → CAL 用共形分数给出 r_t^conf，覆盖率由分数可交换性/ACI 保证，**与 J_φ 条件数无关**（J_φ 只用于生成候选方向，不用于保证覆盖率）。
- **不可观测路径**：DTA 判定残差被吸收/相位不明 → 拒识 → 不确定集直接膨胀到材料先验支撑 𝒫（或 OOV 新域）→ 实时流回退保守基线。此时覆盖率 = 1（在 φ*∈𝒫 前提下），代价是保守。
- **两条路径的切换是显式的**：abstain 标志进入证书 J_amber，审计可查「这一周期是靠证据还是靠先验」。

于是 A72 从「覆盖率前提」降级为「beam 扩张与候选生成的效率前提」；覆盖率的主证明转移到 CAL 的共形定理与 DTA 的拒识安全引理。

## 1. 形式化定义（增量：定义 193–204）

- **定义 193（AMBER 闭环）**：AMBER = (ROSE, MPS, MBE, CTC-A, DTA, CAL, NWR, SLM, RAA, J_amber)。定位：在 ROSE 的「语义流 ∘ 实时流」骨架上，把单点物理估计升级为「材料 beam + 相位边缘化 + 拒识 + 共形」；语义流承担全部 beam/标定/适配写操作，实时流仍零学习写，只做 beam 前向、NWR 编译与拒识回退。
- **定义 194（材料物性域与 Ashby 多面体 MPS）**：材料库 𝔐 = {(m, P_m, c_m)}；P_m ⊂ ℝ^p 为材料 m 的物性域（Ashby 图箱式/椭球域，经 E=3G(1−2ν)、μ,k,c>0 等物理约束裁剪）。物理先验支撑 𝒫 = conv(∪_m P_m) = {φ = Σ_m λ_m φ_m : λ∈Δ^{M−1}, φ_m∈P_m}（材料单纯形）。附材料类先验 π_m 与替代核 κ(m,m′)。
- **定义 195（材料 Beam 估计器 MBE）**：B_t = {(φ_k, w_k, m_k)}_{k=1}^{K}，Σ w_k = 1。观测模型 z_t = τ_ext^obs − τ_ext^pred(φ_k, K_t)。更新 w_k⁺ ∝ w_k·p(z_t|φ_k,m_k)·π_{m_k}；扩张按替代核 κ(m_k,·) 生成邻近材料子假设并在 P_{m′} 内以 J_φ 反演方向细化；剪枝取 top-K 并施加类别多样性约束。输出后验矩 φ̄_t、Σ_t^beam，取代单点 φ̂_t 与各向同性球。
- **定义 196（接触相位边缘化对齐 CTC-A）**：相位格 𝓛={approach, make, slip, steady, break}；单调对齐路径 π。前向 α_t(j)=Σ_{π:π_t=j}∏_{s≤t} p(z_s|φ_{π_s})a_{π_{s−1},π_s}，后向 β_t(j) 同理；相位后验 γ_t(j)=α_t(j)β_t(j)/Σ_{j′}α_t(j′)β_t(j′)。所有依赖 J_φ 的量（CAL 分数、RAA 梯度）只在 γ_t(steady)≥τ_ph 的样本上计算并以 γ_t 加权；硬分段是 γ_t 为 one-hot 的特例。
- **定义 197（残差可观测性与双讲检测 DTA）**：z_t = S_c u_t + J_φ δφ_t + n_t，S_c 为控制回路吸收映射，u_t 为控制指令。可观测子空间 𝒪 = range(J_φ) ∩ null(S_c)^⊥。双讲统计量 DT_t = ‖P_{𝒪^⊥}z_t‖²/(‖P_𝒪z_t‖²+‖P_{𝒪^⊥}z_t‖²+ε)，吸收相干度 coh_t = |⟨z_t,S_c u_t⟩|/(‖z_t‖‖S_c u_t‖)。若 DT_t>τ_dt 或 coh_t>τ_coh 判为 uninformative：禁止更新 r/适配，不确定集膨胀到 𝒫（或 OOV 新域）。
- **定义 198（共形许用层 CAL）**：非一致性分数 s_t = d(φ_t^*, S_{t−1})（φ_t^* 由受控探针/高置信标定获得）。分裂共形半径 r_t^conf = Quantile_{1−α}({s_i}∪历史)。非平稳下用自适应共形推断 ACI：α_{t+1}=clip(α_t+γ(α−𝟙[φ_t^*∉S_t]), α_min, α_max)。集合 S_t = {φ∈𝒫 : d_{Σ_t^beam}(φ, φ̄_t) ≤ r_t^conf}（Mahalanobis 白化 ⇒ 各向异性椭球）。安全关键场景取 B-basis 型容差下界 r_t^allow ≥ r_t^conf。
- **定义 199（N-best 加权鲁棒编译 NWR）**：ℓ̃_t(K) = Σ_k w_k·sup_{φ∈S_t∩P_{m_k}} CVaR_ε[ℓ(K;φ)]；保守版 ℓ̃_t^rob(K)=sup_{φ∈S_t} CVaR_ε[ℓ(K;φ)]。K_safe = argmin_{K∈𝒦} ℓ̃_t^rob(K)（实时用活跃 beam 近似），ρ_rob = min_{φ∈S_t} dist(K_safe, ∂𝒦_unsafe(φ))。因 w_k≥0 且每项对 K 凸，ℓ̃_t 对 K 仍凸。
- **定义 200（材料语法与场景词典 SLM）**：场景词典 L={σ=(材料类 m, 任务 τ, 地形 g, 动态 d)}；材料语法 G 为概率文法 p_G(σ_{t+1}|σ_{≤t})。SBR 的 Mine/Mut 由 G 先验加权（候选先验 = p_G·κ）；SHC 的 Hedge 权重做语法重打分 w_c ∝ exp(ηĜ_c)·p_G(c|当前材料类)。若所有材料类的 p(z|φ_k)·p_G 均低于 τ_oov，触发开放世界材料发现（定义 204）。
- **定义 201（拒识感知适配 RAA）**：MEL-OA 门控升级为 g_t = 𝟙[U_ep>τ_u] ∧ 𝟙[DT_t<τ_dt] ∧ 𝟙[γ_t(steady)≥τ_ph] ∧ 𝟙[s_t≤τ_conf]。即「不确定、可观测、相位对齐、非 OOV」才适配；被拒识样本进「待验证池」，由低幅安全主动探针获取标签后再定；防止从被吸收的伪残差中学习。
- **定义 202（AMBER 证书 J_amber）**：J_amber = (J_rose, {φ_k,w_k}_{k≤K}, m_top, r_t^conf, α_t, DT_t, γ_t(steady), coverage_hat, abstain, oov_flag, material_ver)。Valid ⇔ Valid(J_rose) ∧ (abstain ⇒ K_safe=K_prior(𝒫)) ∧ (¬abstain ⇒ coverage_hat ≥ 1−α_t−δ) ∧ beam 非退化。
- **定义 203（AMBER 闭环算子）**：语义流 [MBE 更新 → CTC-A 相位后验 → DTA 判定 → CAL 标定 → SLM 重打分 → RAA 门控适配 → NWR 前向]；实时流 [ARA 读 → beam 加权 OLP 前向 → DTA 判不可观测则 K_prior(𝒫)，否则 NWR 编译 → 派发 → J_amber]。
- **定义 204（开放世界材料发现 OOV）**：OOV 触发时，以观测指纹在 𝒫 外拟合新物性域 P_new（约束于物理可行域），将 m_new 加入 𝔐，临时不确定集设为 P_new 的膨胀邻域；在主动探针给出证据前，K_safe 一律回退保守基线。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# MBE：材料 beam（语义流维护；实时流只取活跃 top-k 前向）
for k: w[k] *= likelihood(z_t, phi[k]) * pi[m[k]];  w = normalize(w)
expand_by_substitution(w, kappa);  prune_topK_with_diversity()
phi_bar, Sigma_beam = weighted_moments(phi, w)
# CTC-A：相位边缘化后验
gamma_t = phase_posterior_forward_backward(z_t, transitions)
# DTA：残差可观测性
informative = (double_talk_stat(z_t, S_c, u_t) < tau_dt) and (coherence(z_t, S_c*u_t) < tau_coh)
# CAL：共形/ACI 半径（不依赖 J_phi 条件数）
r_conf = conformal_quantile(scores, 1 - alpha);  alpha = aci_update(alpha, covered)
# NWR：beam 后验加权 CVaR 编译
loss_tilde(K) = sum_k w[k] * sup_{phi in S_t ∩ P_mk} CVaR_eps[loss(K; phi)]
# 拒识：不可观测则回退材料先验支撑
K_safe = conservative_prior(P) if not informative else argmin_K loss_tilde(K)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 1（NWR 保凸）**：每项 sup_{φ∈S_k} CVaR_ε 对 K 凸（第 62 轮引理 1），非负权重和保凸 ⇒ ℓ̃_t 对 K 凸；OLP 的 OGD 遗憾分析原样成立，只需把梯度上界改为 G̃′ = G·L_h·(1+κ_φ·r_max^conf)。
- **引理 2（共形覆盖）**：分数可交换时 P[φ*∈S_t] ≥ 1−α；非平稳下 ACI 给长期覆盖率 ≥ 1−α（有界分数）。**该保证不需要 J_φ 良态**，只需分数可交换/可在线校准。
- **引理 3（拒识安全）**：若 DTA 判 uninformative 并回退 S_t=𝒫，则 φ*∈𝒫 时覆盖率为 1；故「可观测⇒1−α，不可观测⇒1」，无条件覆盖率 ≥ 1−α（模 OOV）。
- **定理 1（AMBER 覆盖定理）**：在 φ*∈𝒫 前提下，AMBER 的 K_safe 对真实 φ* 安全概率 ≥ 1−α，**与 A72 的 J_φ 条件数解耦**——第 62 轮单点风险被结构性拆解。
- **定理 2（beam 收缩，条件性）**：正确模型 + 可观测观测下，beam 后验以 Fisher 信息速率收缩到真值邻域；拒识阻止了在不可观测样本上的有偏收缩。
- **命题（保守度下降）**：材料对齐时，Mahalanobis 椭球（Σ_t^beam 白化）在最坏 CVaR 上不劣于等覆盖率的各向同性球；以 E213/E215 实证校验。
- **实时性**：实时流用活跃 beam K_rt≤2、n_worst≤8，前向仍 <1ms 且零学习写；完整 K=8 beam 与标定只在语义流。

## 2. 形式化定义（完整版）

**定义 193（AMBER 闭环）** AMBER 是在 ROSE 骨架上挂载 MPS、MBE、CTC-A、DTA、CAL、NWR、SLM、RAA、OOV 的鲁棒估计闭环。不变式：①语义流承担全部 beam 更新、共形标定、语法重打分、适配写操作；②实时流（1–10kHz）零学习写，只做活跃 beam 前向、NWR 编译、拒识回退、派发；③**覆盖率的主证明由 CAL 共形定理与 DTA 拒识安全引理承担，J_φ 仅用于候选方向生成**。

**定义 194（材料物性域与 Ashby 多面体 MPS）** 材料 m 的物性域 `P_m = {φ : φ_i ∈ [p_i^−, p_i^+], g_j(φ) ≤ 0}`，区间来自 Ashby 图，约束 `g_j` 编码物理关系（正定、E=3G(1−2ν)、μ,k,c>0、热-力耦合界等）。物理先验支撑
`𝒫 = conv(∪_{m∈𝔐} P_m) = {φ = Σ_m λ_m φ_m : λ ∈ Δ^{M−1}, φ_m ∈ P_m}`。
复合材料解释为 λ 为体积分数的凸混合。材料类先验 `π_m` 由任务/场景词典给出；替代核 `κ(m,m′) ∝ exp(−d_Ashby(m,m′)/T_κ)`。

**定义 195（材料 Beam 估计器 MBE）** 设 beam `B_t = {(φ_k, w_k, m_k)}_{k=1}^K`。
- **预测**：`ẑ_k = τ_ext^pred(φ_k, K_t)`；似然 `L_k = p(z_t | φ_k, m_k)`（残差高斯/学生-t，尺度由 CAL 校准）。
- **更新**：`w_k⁺ ∝ w_k · L_k · π_{m_k}`，归一化。
- **扩张**：对权重高于 `τ_exp` 的项，按 `κ(m_k, m′)` 采样邻近材料类；在 `P_{m′}` 内以局部灵敏度 `J_φ` 反演方向 `δ = J_φ⁺(z_t − S_c u_t)` 细化，并做物理投影 `Proj_{P_{m′}}`；复合项沿 `φ_k + s·(φ_{k′}−φ_k), s∈[0,1]` 生成。
- **剪枝**：取 top-K，施加类别多样性（每材料类至少 1 项，若 |𝔐|≤K；同类最多 `n_max` 项）。
- **输出**：`φ̄_t, Σ_t^beam`；若 beam 塌缩（有效类别数 < K_min）则标记退化，交 DTA/CAL 处理。

**定义 196（接触相位边缘化对齐 CTC-A）** 相位格 `𝓛={approach, make, slip, steady, break}`，转移矩阵 `a_{ij}`（只允许单调前进或停留）。前向/后向递推
`α_t(j) = Σ_i α_{t−1}(i) a_{ij} p(z_t | φ_{π_t=j})`，`β_t(j) = Σ_i a_{ji} p(z_{t+1}|φ_i) β_{t+1}(i)`；
`γ_t(j) = α_t(j)β_t(j) / Σ_{j′} α_t(j′)β_t(j′)`。
**仅当 `γ_t(steady) ≥ τ_ph`** 时，样本才允许进入 CAL 标定、RAA 适配与 `J_φ` 估计；所有 `J_φ` 相关量以 `γ_t(steady)` 加权。硬分段（round-62 的隐式做法）是 `γ_t` 为 one-hot 的退化特例，故 CTC-A 严格更一般。

**定义 197（残差可观测性与双讲检测 DTA）** 残差分解 `z_t = S_c u_t + J_φ δφ_t + n_t`，`S_c` 为控制回路吸收映射（由闭环灵敏度/执行器权限张成，离线辨识或解析给出）。可观测子空间 `𝒪 = range(J_φ) ∩ null(S_c)^⊥`。
- 双讲统计量 `DT_t = ‖P_{𝒪^⊥}z_t‖² / (‖P_𝒪z_t‖² + ‖P_{𝒪^⊥}z_t‖² + ε)`；
- 吸收相干度 `coh_t = |⟨z_t, S_c u_t⟩| / (‖z_t‖‖S_c u_t‖)`。
判定：`informative_t = (DT_t < τ_dt) ∧ (coh_t < τ_coh)`。若 `¬informative_t`：`z_t` 标记 uninformative，**禁止** RSC/CAL 更新与 RAA 适配，`S_t ← 𝒫`（或 OOV 新域），并置 `abstain=True`。该判据把「残差被控制吸收」显式检测出来，而不是假设它不存在（A72 的正面拆解）。

**定义 198（共形许用层 CAL）** 非一致性分数 `s_t = d_{Σ_t^beam}(φ_t^*, S_{t−1})`，其中 `φ_t^*` 来自受控探针/高置信离线标定（见风险 2 的获取协议）。分裂共形：`r_t^conf = Quantile_{1−α}({s_1..s_n})`。非平稳下 ACI：
`α_{t+1} = clip(α_t + γ_aci(α − 𝟙[s_t > r_t^conf]), α_min, α_max)`。
集合 `S_t = {φ∈𝒫 : d_{Σ_t^beam}(φ, φ̄_t) ≤ r_t^conf}`。安全关键任务用 B-basis 容差下界 `r_t^allow` 取代 `r_t^conf`（`r_t^allow ≥ r_t^conf`）。**关键**：`r_t^conf` 的覆盖率来自分数分布的可交换性/ACI 的在线校准，不来自 `J_φ` 的条件数；`J_φ` 只影响分数尺度（进而保守度），不影响覆盖率成立与否。

**定义 199（N-best 加权鲁棒编译 NWR）** 
`ℓ̃_t(K) = Σ_k w_k · sup_{φ∈S_t∩P_{m_k}} CVaR_ε[ℓ(K;φ)]`，
保守版 `ℓ̃_t^rob(K) = sup_{φ∈S_t} CVaR_ε[ℓ(K;φ)]`。
`K_safe = argmin_{K∈𝒦} ℓ̃_t^rob(K)`（实时用活跃 beam `K_rt` 项与 `n_worst` 个球面候选近似），`ρ_rob = min_{φ∈S_t} dist(K_safe, ∂𝒦_unsafe(φ))`。
性质：`w_k ≥ 0`，每项对 K 凸 ⇒ `ℓ̃_t` 对 K 凸（第 62 轮引理 1 的加权推广）。实时只对 `S_t` 内候选求 sup，**不再对固定半径球求 sup**，故同覆盖率下更紧。

**定义 200（材料语法与场景词典 SLM）** 场景词典 `L={σ=(m,τ,g,d)}`；材料语法 `G` 为变阶 n-gram 或 PCFG，`p_G(σ_{t+1}|σ_{≤t})` 由部署数据在线更新（增量计数 + 回退平滑）。
- **SBR 先验**：`Mine` 的候选入行概率、`Mut` 的算子选择由 `p_G·κ(m,m′)` 加权；材料类成为银行一级索引。
- **SHC 重打分**：`w_c ∝ exp(η Ĝ_c) · p_G(c | 当前材料类)`；即「亏钱 + 语法上可能出现」的场景优先。
- **OOV**：若 `max_k p(z_t|φ_k,m_k)·π_{m_k} < τ_oov` 且 `p_G` 对所有已知类极低，判 OOV（定义 201→204）。

**定义 201（拒识感知适配 RAA）** `g_t = 𝟙[U_ep>τ_u] ∧ 𝟙[informative_t] ∧ 𝟙[γ_t(steady)≥τ_ph] ∧ 𝟙[s_t≤τ_conf]`。`g_t=1` 时才更新 LoRA 子集 θ_A；损失沿用第 62 轮 `L_OA`，但 batch 只取 informative + 相位对齐样本，回放按 SLM 重打分权重采样。被拒识样本进入待验证池 `Q`，由低幅安全探针（激励能量 ≤ 安全包络）获取 `φ*` 标签后，再决定是否入 bank/适配。此机制使 MEL-OA 不在「被吸收的伪残差」上学习，修复第 62 轮风险 2 的次级隐患。

**定义 202（AMBER 证书 J_amber）** 
`J_amber = (J_rose, {φ_k,w_k}_{k≤K}, m_top, r_t^conf, α_t, DT_t, γ_t(steady), coverage_hat, abstain, oov_flag, material_ver)`。
验证：`Valid(J_amber) ⇔ Valid(J_rose) ∧ (abstain ⇒ K_safe=K_prior(𝒫)) ∧ (¬abstain ⇒ coverage_hat ≥ 1−α_t−δ) ∧ (有效材料类数 ≥ K_min) ∧ (oov_flag ⇒ K_safe=K_baseline)`。
审计：`material_ver`（材料库版本）、`adapter_ver`（模型版本）、`r_t^conf/α_t`（标定状态）共同回答「这一周期凭什么安全、凭先验还是凭证据」。

**定义 203（AMBER 闭环算子）** 见 IP-202 伪代码。语义流：`[MBE 更新 → CTC-A 相位后验 → DTA 判定 → CAL 标定 → SLM 重打分 → RAA 门控适配 → NWR 前向]`；实时流：`[ARA 原子读 → 活跃 beam 加权 OLP 前向 → DTA 判不可观测则 K_prior(𝒫) 否则 NWR 编译 → 派发 → J_amber]`。

**定义 204（开放世界材料发现 OOV）** 若 OOV 触发，以观测指纹在 `𝒫` 外拟合新物性域 `P_new`（约束于物理可行域，含 `μ,k,c>0` 等），将 `m_new` 加入 `𝔐` 并更新 `π,κ`；在主动探针给出证据前，不确定集设为 `P_new` 的膨胀邻域且 `K_safe=K_baseline`。OOV 检测把「先验支撑可能失配」从静默失败升级为可观测事件。

### IP-194 MBE（材料 Beam 估计器）

```python
class MaterialBeamEstimator:
    """K 项材料假设 beam。语义流 update()；实时流只用 active_forward()。"""
    def __init__(self, materials, K=8, K_min=2, tau_exp=0.1, n_max_per_class=3):
        self.M = materials                 # 𝔐 = {(m, P_m, c_m)}
        self.K, self.K_min = K, K_min
        self.tau_exp, self.n_max = tau_exp, n_max_per_class
        self.beam = self._init_from_prior(materials, K)

    def update(self, z_t, K_t, S_c, u_t, J_phi_fn):
        for e in self.beam:
            e.w *= gaussian_likelihood(z_t, e.phi, K_t) * self.pi[e.m]
        self.beam = normalize(self.beam)
        # 扩张：高权重项按替代核生成邻近材料/复合子假设
        children = []
        for e in [x for x in self.beam if x.w > self.tau_exp]:
            for m2 in sample_by_kernel(self.kappa, e.m, n=2):
                phi0 = project_P(self.M[m2].P, e.phi)
                phi1 = project_P(self.M[m2].P, phi0 + J_phi_fn(e.phi, K_t).pinv()
                                 @ (z_t - S_c @ u_t))
                children.append(Hyp(phi=phi1, m=m2, w=e.w * self.kappa(e.m, m2) * 0.5))
                children.append(Hyp(phi=0.5 * (e.phi + phi1), m=m2, w=e.w * 0.25))
        self.beam = self._prune(self.beam + children)   # top-K + 类别多样性
        phi_bar = sum(e.w * e.phi for e in self.beam)
        Sigma = sum(e.w * np.outer(e.phi - phi_bar, e.phi - phi_bar) for e in self.beam)
        return phi_bar, Sigma

    def _prune(self, beam):
        beam.sort(key=lambda e: e.w, reverse=True)
        out, per_class = [], {}
        for e in beam:
            if per_class.get(e.m, 0) >= self.n_max: continue
            out.append(e); per_class[e.m] = per_class.get(e.m, 0) + 1
            if len(out) == self.K: break
        return normalize(out)

    def active_forward(self, k_rt=2):                  # 实时流：只取 top-k_rt
        return [(e.phi, e.w) for e in self.beam[:k_rt]]
```

### IP-195 CTC-A（相位边缘化对齐）

```python
PHASES = ['approach', 'make', 'slip', 'steady', 'break']

def phase_posterior(z_seq, phi_seq, trans):
    """前向-后向相位后验。z_seq/phi_seq 对齐到同长度 T。"""
    T, J = len(z_seq), len(PHASES)
    emit = np.array([[gaussian_likelihood(z_seq[t], phi_seq[t], None)
                      for j in range(J)] for t in range(T)])
    alpha = np.zeros((T, J)); beta = np.zeros((T, J))
    alpha[0] = emit[0] * trans.prior
    for t in range(1, T):
        alpha[t] = (alpha[t-1] @ trans.A) * emit[t]
    beta[-1] = 1.0
    for t in range(T-2, -1, -1):
        beta[t] = trans.A @ (emit[t+1] * beta[t+1])
    gamma = alpha * beta
    gamma /= gamma.sum(axis=1, keepdims=True) + 1e-12
    return gamma                                     # gamma[t, j] = P(phase_t=j | z)

def steady_weight(gamma, tau_ph=0.6):
    j = PHASES.index('steady')
    return np.where(gamma[:, j] >= tau_ph, gamma[:, j], 0.0)   # 仅稳态段可进入标定/适配
```

### IP-196 DTA（双讲 / 可观测性检测）

```python
def residual_observability(z_t, u_t, S_c, J_phi, eps=1e-9):
    """直接检测「残差里是否还有可辨识的近端物理分量」。"""
    # 控制可吸收子空间 = range(S_c)；正交补 = 控制吸收不到的残差方向
    P_perp = null_space(S_c.T)                    # 吸收不到的方向
    e_perp = np.linalg.norm(P_perp @ z_t) ** 2
    e_obs = np.linalg.norm(J_phi @ np.linalg.pinv(J_phi) @ z_t) ** 2
    DT = e_perp / (e_obs + e_perp + eps)
    echo = S_c @ u_t
    coh = abs(np.dot(z_t, echo)) / (np.linalg.norm(z_t) * np.linalg.norm(echo) + eps)
    informative = (DT < TAU_DT) and (coh < TAU_COH)
    return informative, DT, coh
```

### IP-197 CAL（共形 / ACI 许用层）

```python
class ConformalAllowableLayer:
    def __init__(self, alpha=0.05, gamma_aci=0.01, alpha_min=0.01, alpha_max=0.2):
        self.alpha = alpha; self.gamma = gamma_aci
        self.alpha_min, self.alpha_max = alpha_min, alpha_max
        self.scores = deque(maxlen=500)

    def radius(self):
        return np.quantile(self.scores, 1 - self.alpha) if self.scores else self.r0

    def update(self, phi_star, phi_bar, Sigma, informative):
        if not informative:                        # 拒识：不消耗分数预算
            return self.radius()
        r = self.radius()
        d = mahalanobis(phi_star, phi_bar, Sigma)  # s_t
        covered = d <= r
        self.scores.append(d)                      # 分裂共形（简化：滚动标定集）
        self.alpha = np.clip(self.alpha + self.gamma * (self.alpha - (1 - int(covered))),
                             self.alpha_min, self.alpha_max)   # ACI
        return self.radius()

    def allowable(self, safety_critical=False):
        r = self.radius()
        return max(r, self.r_b_basis) if safety_critical else r
```

def nwr_compile(mbe, olp, eeis, S_t, eps=0.05, n_worst=8, k_rt=2):
    """把 beam 后验灌进 WCV：非负加权保凸，且只对 S_t 求 sup。"""
    candidates = []
    for phi_k, w_k in mbe.active_forward(k_rt):
        for i in range(n_worst):
            phi = sample_sphere(S_t, center=phi_k)        # S_t 内球面/椭球面候选
            K = olp.project(PHI_TO_X(phi))
            K_c = eeis.compile_with_phys_constraint(K, phi)
            loss_i = execution_loss_estimate(K_c, phi)
            margin = safety_margin(K_c, phi)
            candidates.append((phi_k, w_k, K_c, loss_i, margin))
    candidates.sort(key=lambda c: c[3], reverse=True)
    tail = candidates[:max(1, int(eps * len(candidates)))]
    K_safe = intersect_shrink([c[2] for c in tail])
    rho_rob = min(c[4] for c in tail)
    return K_safe, rho_rob

### IP-199 SLM（材料语法 / 场景词典）

```python
class MaterialGrammar:
    def __init__(self, order=2):
        self.counts = defaultdict(Counter); self.order = order

    def prior(self, token, history):
        ctx = tuple(history[-self.order:])
        c = self.counts[ctx]
        return (c[token] + ALPHA_SMOOTH) / (sum(c.values()) + ALPHA_SMOOTH * len(c) + 1e-9)

    def observe(self, token, history):
        self.counts[tuple(history[-self.order:])][token] += 1

    def rescore(self, hedge_w, clusters, current_material):
        # Hedge 权重 × 材料语法先验
        p = np.array([self.prior(c, [current_material]) for c in clusters])
        w = hedge_w * p
        return w / w.sum()
```

### IP-200 RAA（拒识感知适配）

```python
def reject_aware_adapt(mel, bank, hedge_w, grammar, U_ep, informative,
                       gamma_steady, s_t, tau_u=0.7, tau_ph=0.6, tau_conf=Q_95):
    gate = (U_ep > tau_u) and informative and (gamma_steady >= tau_ph) and (s_t <= tau_conf)
    if not gate:
        bank.defer_to_probe(mel.last_sample)       # 进待验证池，等安全探针标签
        return None
    fail_batch = [x for x in bank.recent_failures(k=32) if x.informative]
    w = grammar.rescore(hedge_w, bank.cluster_ids, mel.current_material)
    replay = bank.sample_by_weight(w, k=int(0.5 * 32))
    loss = cvar_tail_loss(mel.predict_phys(fail_batch + replay), ...) + ewc_penalty(mel)
    mel.lora_theta -= LR_ADAPT * autograd(loss, mel.lora_theta)
    mel.adapter_ver += 1
    return mel.adapter_ver
```

def realtime_step(M, delta_f_req):

    K_prior = weighted_olp_forward(M.olp, beam, anchor) if anchor else K_BASELINE
    r_conf = M.cal.allowable(safety_critical=M.task.safety_critical)
    S_ball = ellipsoid(M.mbe.phi_bar, M.mbe.Sigma, r_conf)          # 材料约束椭球

    if M.last_DT >= TAU_DT:
        K_safe = conservative_prior(M.materials.P)                  # 拒识回退
    else:
        K_safe, rho_rob = nwr_compile(M.mbe, M.olp, M.eeis, S_ball)
    cert_exec = M.ertc.dispatch(K_safe)

## 4. 推导

**引理 1（NWR 保凸）** 由第 62 轮引理 1，对固定 φ，`CVaR_ε[ℓ(K;φ)]` 对 K 凸；对 `S_t∩P_{m_k}` 取上确界是凸函数族的逐点 sup，仍凸。`w_k ≥ 0` 且 `Σw_k=1`，故 `ℓ̃_t(K)=Σ_k w_k·(凸)` 为凸函数的非负凸组合，仍凸。∎

**引理 2（共形覆盖）** 分裂共形：若分数 `s_1..s_n` 与待测分数 `s_{n+1}` 可交换，则 `P[s_{n+1} ≤ Quantile_{1−α}] ≥ 1−α`（有限样本、分布无关）。非平稳下 ACI 的长期覆盖率 `(1/T)Σ_t 𝟙[s_t ≤ r_t] → 1−α`，前提是分数有界且步长 γ_aci 足够小。**证明不涉及 J_φ**：J_φ 只进入分数定义 `d` 的度量，不改可交换性。∎（关键：这替换了第 62 轮引理 2 中「EWMA 收敛到真值带」这一未证假设。）

**引理 3（拒识安全）** 若 `¬informative_t`，算法置 `S_t=𝒫`。由定义 `φ^*∈𝒫`（材料库覆盖真值），故 `φ^*∈S_t`，覆盖率 1。结合引理 2：可观测分支覆盖 `≥1−α`，不可观测分支覆盖 1，故无条件覆盖 `≥1−α`。∎

**定理 1（AMBER 覆盖定理）** 在 `φ^*∈𝒫` 前提下，`K_safe` 对真实 `φ^*` 安全的概率 `≥1−α`，且该结论的证明只用到引理 2/3，不依赖 A72 中 `σ_min(J_φ)>0`。因此第 62 轮「RSC 覆盖失效」单点风险被拆为两个独立失效模式：①`φ^*∉𝒫`（OOV，由 OOV 检测暴露）；②共形分数不可交换（由 ACI 在线自适应缓解）。∎

**定理 2（beam 收缩，条件性）** 设似然模型正确、观测 informative 且相位可辨（`γ_t(steady)` 近 1）。则 beam 后验的 Fisher 信息 `I_t = Σ_k w_k I_{φ_k}` 随 info 样本累积，`E‖φ̄_t−φ^*‖² ≲ tr(I_t^{−1}) → 0`。拒识分支使「被吸收样本」不进入后验，避免有偏收缩。定量速率依赖材料类间可分性与似然正确性（见风险 1）。∎

**命题（保守度下降）** 设材料对齐（`φ^*∈P_{m^*}`）。Mahalanobis 椭球 `S_t` 沿 `Σ_t^beam` 主轴分配半径，而等覆盖率各向同性球在三轴上取同一最大半径。故 `vol(S_t) ≤ vol(ball)` 且 `sup_{S_t} CVaR ≤ sup_{ball} CVaR`（在两者含 `m^*` 且覆盖同一后验质量时）。保守度收益正比于 `Σ_t^beam` 的各向异性（E215 校验）。∎

**定理 3（OLP 遗憾保持）** 由引理 1 保证 `ℓ̃_t` 对 K 凸、且 `‖∇_W ℓ̃_t‖ ≤ G̃′ = G·L_h·(1+κ_φ·r_max^conf)`，第 62 轮定理 1 的 OGD 平方和推导原样成立：`R_T ≤ D·G̃′·√T`。故 AMBER 不破坏在线投影的遗憾保证。∎

**命题（实时性）** 实时流每周期只做：K_rt≤2 次 OLP 前向 + `K_rt·n_worst`（≤16）次 NWR 候选 + 一次 DTA 查询 + 一次 CAS 读。FLOPs 与第 62 轮同量级（WCV 从 n_worst=16 变为 ≤16），仍满足 ≤1ms、零学习写。完整 K=8 beam 更新、共形标定、语法更新只在语义流。∎

**正确性定理（AMBER-Complete）** 假设 A61–A71、A73–A76（第 62 轮），并以 A77–A80 取代 A72：
- **(A72′ 退役)** 不再要求 `σ_min(J_φ)>0` 作为覆盖率前提；J_φ 仅需可计算候选方向。
- **(A77 材料支撑覆盖)** `φ^* ∈ 𝒫`（或 OOV 检测在 `τ_oov` 内触发并回退）。这是本轮的新单点假设。
- **(A78 残差可交换/可校准)** informative 样本的共形分数在标定窗口内可交换，或 ACI 步长满足有界漂移条件。
- **(A79 相位可辨)** 存在 `τ_ph` 使稳态相位后验可分离；瞬态段被 `γ_t` 正确降权。
- **(A80 吸收映射已知/可辨识)** `S_c` 由闭环辨识或解析模型给出，且 `𝒪` 非空（否则全时段拒识，退化为纯保守，仍是安全的）。

则：
1. **鲁棒覆盖（核心）**：`P[K_safe 在 φ^* 下安全] ≥ 1−α`，证明只依赖 A77–A79 与共形引理，不依赖 J_φ 条件数——第 62 轮单点风险被结构性拆解（可观测⇒共形，不可观测⇒先验）。
2. **偏差免疫**：材料 beam + 共形椭球把系统性 sim2real 偏差吸收进后验/标定，而非靠固定 ×0.8/×1.2。
3. **对齐正确性**：CTC-A 相位后验使 J_φ 与适配只在稳态接触上生效，消除「错误相位反演」导致的假偏差。
4. **不学坏**：DTA 拒识 + RAA 门控使被控制吸收的伪残差不能污染 r_t 与 LoRA（E217 校验）。
5. **保守度与可解释性**：Ashby 椭球比等覆盖球更紧且每维可解释为材料物性区间；材料类成为场景银行一级索引。
6. **开放世界可见**：OOV 从静默失败升级为显式事件与保守回退，代价是覆盖率前提被明确暴露而非隐藏。
7. **兼容性**：NWR 保凸，OLP 遗憾界 `R_T ≤ D·G̃′·√T` 保持；实时路径零学习写、≤1ms 契约不变。

## 7. 已知风险

**一句话**：AMBER 的全部覆盖率论证都建立在 A77「真实材料落在材料库支撑 𝒫 内」这一先验支撑假设上；一旦部署环境出现库外新材料（开放世界 OOV）而 OOV 检测又未在 `τ_oov` 内触发，beam 与共形集都会结构性错误设定，定理 1 与 AMBER-Complete 第 1 条在模型失配下失效——这是本轮所有安全论证共同依赖的新单点假设（比 A72 更隐蔽，因为它通常以「传感器故障」或「负载突变」的形式伪装）。

**次级风险与缓解**：
1. **共形分数的标签来源**：`φ_t^*` 需可靠标签；若标签本身来自有偏 MEL，则共形会「证明错误的东西」（garbage-in）。→ 只用受控安全探针/离线标定标签，探针样本独立于在线 MEL；分数来源版本进入 J_amber 审计。
2. **相位后验退化**：接触瞬态短、`γ_t(steady)` 长期低于 `τ_ph` 时样本被大量拒识，系统退化为纯保守（安全但低效）。→ 监控拒识率，超阈值时降低 ARM 采样频率/请求人机澄清（接 DMS），而非放宽 `τ_ph`。
3. **beam 塌缩/膨胀**：似然过度自信导致 beam 早期塌缩到错误材料；或复合扩张导致类别爆炸。→ 类别多样性剪枝 + 温度平滑似然 + beam 熵监控（熵过低时强制保留次优类）。
4. **`S_c` 失配**：吸收映射随磨损/温变漂移，DTA 误判。→ 周期性闭环辨识 `S_c`，并把辨识残差计入 CAL 分数（保守化）。
5. **计算预算**：实时 NWR 的 `K_rt·n_worst` 候选在复杂 EEIS 下可能超 1ms。→ 候选共享 + 早停 + 只在材质切换窗口放大 beam；否则回退单活跃假设。
6. **材料库维护成本**：Ashby 域需人工/离线维护，新工艺材料滞后。→ OOV 自动候选 + 人工确认的「材料库 CI」，material_ver 变更需回归 E218。
