# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；本轮灵感：「抓取位姿估计」×「自适应控制」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述最大风险 A88 点破了两个隐藏假设：故障属于**有限已知集合**、视觉与几何的失效**相互独立**。继续往下追，会看到 VISTA 还有两个更基础、却从未被正面处理的前提：
>
> **(i) 几何被当成一个静态、可点估计的绝对参数 φ。** 但在抓取里，几何的真正载体是**抓取位姿**——它活在 SE(3) 的**对称商空间**上。同一个圆柱绕自身轴转 90°、同一只平行夹爪交换两指、绕接近轴自旋，物理抓取完全等价，可 VISTA 的 e_vis（绝对残差）会爆炸，并把「规范等价」误判成「几何幻觉」。这与 6D 位姿估计里 ADD 指标在对称物体上的失败是同一个病；业界早已用 MSSD/MSPD/VSD 这类**对称感知**指标替代，而 VISTA 用的正是 ADD 式残差。
>
> **(ii) 故障被当成离散标签，归因一次就结束。** 但摩擦系数、接触刚度、力偏置、物体质量/惯量、抓取位姿的缓慢滑移都是**连续参数**，会随温度、磨损、姿态漂移。把连续量塞进 {H_force, H_model} 两个离散桶，等于用直方图拟合曲线；而若改用自适应去吸收它们，又会出现自适应控制最危险的失败模式——**结构性损伤伪装成参数变化被吸收**，残差归零、证书齐全，系统却在不安全地继续抓取。
>
> 本轮不往 VISTA 上叠加新模态，而是换掉它的两个「坐标系」：**几何从绝对参数换成商空间等价类，故障从离散标签换成「可辨识方向上的连续参数 + 不可辨识方向上的诚实拒绝」**。核心命题：
>
> **只在可辨识的方向上相信，只在有扳手裕度的方向上膨胀，只在被激励的方向上自适应，其余方向诚实标为不可观合并安全降级。**

## 0. 直觉与动机

**灵感 1（抓取位姿估计 → 几何不是点，是商空间上的等价类）**
直觉：6D 位姿估计界早就承认对称性：对圆柱/球/对称盒子，naive ADD 误差会因为绕对称轴多转 90° 而爆炸，于是有了 MSSD、MSPD、VSD 这些对称感知指标。VISTA 的 e_vis 正是 ADD 式的绝对残差，于是它会对着一个「物理上完全等价的抓取」大喊几何幻觉。抓取位姿比物体位姿更甚：除了物体对称群 G_obj，还有夹爪的**换指对称**（左右指互换）、绕接近轴的自旋、平行夹爪开合方向翻转。这些变换下，接触集、力闭合、扳手空间可以完全不变。正确做法：**在商空间 SE(3)/G_sym 上定义残差，把不可观的对称方向显式分离出来，只在任务相关可观测子空间里做判断。** 但必须诚实：并非所有对称都无害——纹理对齐、线缆走向、按键朝向是任务相关的。所以商掉的是 ker(π_task)，不是全部对称。

**灵感 2（抓取位姿估计 → 真正该认证的是扳手空间，不是欧氏位姿球）**
直觉：VISTA 用「位姿球 B(φ̂,r_geo)」表达几何不确定。但对抓取而言，位姿误差本身不伤人，**它通过接触雅可比 J_g 映射到扳手空间，才决定力闭合是否还成立、能抵抗多大外力**。同样的 5mm 位姿误差，在力臂长/接触法向差时可能让 ε 裕度归零，在另一些方向上完全无害。所以不确定性的正确坐标是**抓取扳手空间（GWS）的 ε 裕度**，而位姿球应该被 J_g 拉过去、按方向加权。一个近奇异抓取（ε 很小）即使位姿很准也危险；一个深力闭合抓取即使位姿有点偏也安全。**用 ε 认证，而不是用 r 认证。**

**灵感 3（自适应控制 → 连续参数应该被自适应，而不是被离散归因）**
直觉：摩擦、刚度、力偏置、质量是**连续量**，而且会随温度、磨损、抓取姿态缓慢变化。把它们塞进 {H_force, H_model} 两个离散桶，等于用直方图拟合一条连续曲线。自适应控制提供了成熟工具：**投影自适应律**保证参数有界，**死区**防止噪声漂移，**集合隶属（set-membership）**给出与所有测量一致的可行参数集，**并发学习（concurrent learning）**用历史数据栈在缺乏持续激励时仍能收敛。映射到本轮：**把 VISTA 的「归因后只膨胀某个球」升级为「只在被激励方向上更新参数、在未被激励方向上冻结并鲁棒化」。** 这不是换汤不换药，而是把「离散后验」变成「连续可行集 + 激励掩码」。

**灵感 4（自适应控制的残酷教训 → 自适应会吸收故障，PE 与边界应力是一等安全信号）**
直觉：自适应控制最著名的失败模式不是不收敛，而是**参数漂移/ bursting**：没有持续激励（PE）时，参数会沿不可观方向乱走；更糟的是，系统可能把**结构性故障**（单指卡滞、传动打滑、连杆碰限位）解释成「摩擦/偏置变了」，残差被压到零，控制性能看起来正常，实际安全裕度已经没了。这是本轮要正面迎战的风险。对策有三层：(i) **PE/激励监控**：每个参数方向的条件信息矩阵特征值低于阈值就冻结该方向；(ii) **投影 + 集合隶属**：参数只能在物理可行集内，且必须与所有历史测量一致；一旦可行集为空，判**模型不一致（开放集异常）**，不允许「硬归因」；(iii) **边界应力**：参数长期贴边或投影频繁激活，就是「自适应在硬撑结构损伤」的证据，强制降级。**能吸收不等于该吸收；吸收得越干净，越要怀疑。**

**灵感 5（合流 → GRACE：Gauge-Reduced Adaptive Certified grasp Envelope）**
直觉：抓取位姿的等价类（商空间）× 扳手空间的认证裕度 × 连续参数的自适应 × 激励感知的诚实拒绝，四者刚好对应 VISTA 的四个盲区：几何球、离散故障集、一次性归因、绝对残差。闭环：对称感知抓取位姿商空间（GQP）→ 扳手空间方向敏感裕度（GWS-C）→ 连续参数可行集（CPS）→ 投影自适应律（PAAL）→ 激励监控 + 并发学习（PE-CL）→ L1 瞬态界（L1-AS）→ 连续优先归因（CAFIR，开放集拒绝）→ 自适应认证前缀（ACSC）→ 规范打破探针（GBP）→ RSC-G/WCV-G/CSP-G/AIC-G → J_grace。VISTA 是「已知故障里选一个、膨胀对应的球」；GRACE 是「**先问这个量在商空间里是否可辨识、在扳手空间里是否敏感、在参数空间里是否被激励，再决定相信、适应还是拒绝**」。

- **定义 245（CAFIR 连续优先归因与开放集拒绝）** 给定残差 r=(e_gauge,e_pose,e_θ,e_model,e_chunk)，按顺序判定：(1) 残差全在任务无关规范方向 → `H0_gauge`；(2) 残差在 g 的可辨识方向 → `H_pose`（重估抓取位姿，不判几何故障）；(3) 残差在 θ 的条件可辨识方向且 Θ_t 非空 → `H_adapt`（连续参数更新）；(4) Θ_t 为空或残差超出模型类 conformal 界 → `H_open`（开放集异常，安全降级，不分类）；(5) 残差落在 g/θ 混淆或未激励方向 → `H_unobservable`（冻结 + GBP）；(6) 真离散事件（接触丢失、饱和、滑移冲量）→ 原 VISTA 离散假设。**不再对有限 ℋ 做 argmax；只有真正离散的事件才允许离散标签。**
- **定义 246（规范打破主动探针 GBP）** 候选 P={rotate_about_axis, tilt, regrasp, lift, null_test, active_vision}。选择 a*=argmax_{a∈P} I(π_task; o(a) | U_α)/(c_damage(a)+λc_time(a))，s.t. 预测扳手扰动 ≤ε_budget、无掉落、f_n≤f_safe。对连续对称，绕轴旋转或倾斜以打破规范；对多模态抓取，轻抬/换指以消歧。无安全探针时输出 `gauge_hazard` 并 safe_idle。**这是 AFA 的几何对偶：不是问「谁坏了」，而是问「哪个方向根本看不见，怎么用最小扰动把它变成看得见」。**
- **定义 247（RSC-G 方向证书与自适应 CBF）** 不确定性拆为 r_gauge（任务无关不可观，单独标记，不进安全球）、r_pose,sens（按 s_j 加权的位姿敏感分量）、r_param（Θ_t 直径）、r_model（未建模）。只膨胀任务相关且敏感的方向：r_safe=‖diag(s)·δg_sens‖⊕r_param⊕r_model。搜索域 B_Q([ĝ],r_safe)∩𝒢(g)∩K(μ̂)∩ℱ(f_lim)∩𝒱∩𝒲(ε_cert)，其中 𝒲 为扳手裕度约束。自适应 CBF：h(x)=ε(g,θ̂)−ε_req−L_εη，要求 ḣ+αh≥0；投影与 L1 界保证 h 在自适应期间不越界。
- **定义 248（J_grace 与 GRACE 算子）** J_grace=(J_vista, gauge_class, gauge_hazard, wrench_margin, margin_uncertainty, theta_hat, Theta_diam, condition_number, pe_index, unexcited_basis, boundary_stress, l1_bound, k*, open_set_flag, gbp_ver)。Valid ⇔ 原 J_vista 的物理安全项 ∧ CAFIR 未强行归因 ∧ (gauge_unobservable⇒未膨胀几何球) ∧ ε_cert−L_εη≥ε_req ∧ 无 adaptation_stress ∧ k*≥1 ∧ PE/未激励方向已显式处理。语义流：[VISTA 语义流→GQP→GWS-C→CPS→PE-CL→CAFIR→GBP→ACSC→CSP-G]；实时流：[锚点读→规范残差→预计算支撑函数验 ε→有界投影自适应→L1 滤波→自适应 CBF→前缀执行/早停→J_grace 组装]。

```python
# 1) GQP：对称感知的抓取位姿残差
def gauge_residual(g_hat, g_pred, G_sym, Sigma):
    xi = se3_log(g_hat.inv() @ g_pred)
    xi_par = project_lie(xi, G_sym)        # 连续闭式 / 离散取轨道最小
    xi_perp = xi - xi_par
    e_gauge = xi_perp @ inv(Sigma) @ xi_perp
    task_hazard = changes_task_observable(xi_par, G_sym)
    return e_gauge, norm(xi_par) > EPS_G, task_hazard

# 2) GWS-C：扳手空间认证裕度
def wrench_certificate(g, theta, contacts, U_alpha, eps_req):
    G = grasp_matrix(g, contacts)
    eps = epsilon_radius(G, friction_cone(theta.mu, contacts))
    J = grasp_jacobian(g, contacts)
    delta_w = max(norm(J @ dg) for (dg, _) in U_alpha)
    eps_cert = eps - L_EPS * delta_w
    return eps_cert, eps_cert >= eps_req

# 3) PE-CL + 投影自适应
def adaptive_step(theta_hat, Theta_t, Y_g, Y_t, e, dt, M_pe):
    cond_info = schur_complement(Y_g, Y_t)        # Λ_{θ|g}
    M_pe = (eigvalsh(cond_info) >= LAMBDA_PE) & M_pe
    grad = -GAMMA * M_pe * (Y_t.T @ e)
    theta_hat = project(theta_hat + dt * grad, Theta_t)

# 4) CAFIR：连续优先归因
def attribute(res):
    if res.gauge_only and not res.hazard:      return 'H0_gauge'
    if res.pose_identifiable:                  return 'H_pose'
    if res.theta_identifiable and res.Theta_nonempty: return 'H_adapt'
    if res.Theta_empty or res.open_score > Q_OPEN:    return 'H_open'
    if res.discrete_event:                     return res.discrete_event
    return 'H_unobservable'

# 5) ACSC：自适应认证前缀
def certified_prefix(A, eps_cert, eta, m, alpha):
    k = 0
    for s in range(1, min(len(A), m) + 1):
        if eps_cert[s] - L_EPS * eta[s] < EPS_REQ: break
        if violation_prob(A[:s]) > alpha: break
        k = s
    return max(k, K_ROB if pe_ok else 0)

# 6) GBP：规范打破探针
def choose_gbp(modes, U_alpha, damage_budget):

    for a in PROBES:
        if predict_damage(a, U_alpha) > damage_budget: continue
        ig = mutual_info_task(modes, a)
        score = ig / (disturbance(a) + EPS)
        if score > best_score: best, best_score = a, score
    return best
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（规范不变性消除伪故障）**：若 h∈G_safe 任务无关，则 π_task(g·h)=π_task(g) 且 ε(g·h,θ)=ε(g,θ)；故规范等价抓取的 e_gauge=0，CAFIR 返回 `H0_gauge`，不膨胀几何球。VISTA 的绝对残差 e_vis=e_gauge+‖ξ_⊥‖²；商掉 dim 𝔤_sym 个自由度后，几何伪故障的误报率从 χ²_{d} 降到 χ²_{d−dim 𝔤_sym}，对称物体上严格下降。
- **引理 10（扳手空间方向界）**：ε 对扳手 Lipschitz，故 |ε(g+δg)−ε(g)|≤L_ε‖J_gδg‖。于是位姿不确定性的安全影响只由 J_g 的**大奇异方向**决定；J_g 近零的方向可以自由，J_g 近奇异（抓取本身近奇异）的方向必须收紧。位姿球对所有方向统一膨胀，既不必要又可能不足；扳手证书按方向给界。
- **引理 11（集合隶属的一致性与开放集）**：若模型类正确、θ*∈Θ₀、噪声≤δ_noise，则 θ*∈Θ_t 对所有 t 成立（归纳）；若 Θ_t=∅，则模型类错误或噪声界被破坏。因此空集是**开放集异常的充分信号**，而不是数值故障。投影保证 θ̂∈Θ_t，自适应不可能漂出物理可行域。
- **引理 12（条件 PE 与并发学习）**：若 λ_min(Λ_{θ|g})≥λ_pe，标准投影自适应律使 ‖θ̃‖ 指数收敛到 O(δ_noise/λ_pe)；并发学习栈满秩时无需持续 PE 也指数收敛。未激励/混淆方向不可辨识，只能保持先验界——这正是「只膨胀对的球」的连续版本。**联合可辨识性必须用 Schur 补，否则位姿误差会被误吸收成摩擦变化。**
- **引理 13（L1 一致瞬态界）**：在 A94 下，块内力/扳手跟踪误差 ≤η(Γ,ω_f,Θ_t)+指数衰减项，且 η 与参数不确定幅度弱相关。故「边适应边执行」的瞬态可由 η 事先界定，ACSC 可以据此选取 k*。
- **定理 9（GRACE 端到端归因-安全）**：在 A94–A99 下，Valid(J_grace) ⇒ (i) 无规范诱导的几何误降级；(ii) 自适应始终在 Θ_t 内且有界；(iii) 未知复合故障要么被吸收到**可认证安全**的 θ∈Θ_t，要么触发 `H_open`/`H_unobservable` 并安全降级，绝不强行归入有限假设；(iv) 自适应期间由 CBF 与 L1 界保安全；(v) 若结构故障恰好等价于一个安全参数变化，GRACE **无法区分**（A96），只能靠边界应力、PE 异常或独立锚点——证书的强度以模型类为界，绝不假装超越它。
- **定理 10（自适应前缀的近最优性）**：风险 R(k)=c₁σ_π²/H+c₂·1[k>m]+c₃·P[PE lost]·1[k>k_rob]。PE 良好且 η≤η_max 时 k*≥k_rob 且越界概率≤α_chunk；PE 丢失时 k*=k_rob，退回 VISTA 的保守前缀。故「长预测、短执行」升级为「长预测、**由可辨识性决定的动态短执行**」。

G_sym = G_obj ⋉ G_gripper，
其中 G_obj 是物体几何对称子群（圆柱绕轴 SO(2)、球 SO(3)、盒子的 180° 离散旋转群），G_gripper = S₂（左右指互换）× SO(2)（平行夹爪绕接近轴自旋）。规范等价定义为 g ~ g·h（h∈G_sym），商空间 Q=SE(3)/G_sym，投影 [g]=G_sym·g。商距离

ξ = ξ_∥ + ξ_⊥，ξ_∥=Π_{𝔤_sym}ξ，ξ_⊥=(I−Π_{𝔤_sym})ξ。
规范不变残差 e_gauge=‖ξ_⊥‖²_{Σ⁻¹}。若 ‖ξ_∥‖>ε_g 且 e_gauge≤q（q 为 conformal 阈值），输出 `gauge_unobservable`，不得据此膨胀几何球、不得判 H_geo。对连续对称，ξ_∥ 是沿对称轴/球心方向的分量；对离散对称，取轨道内使 ‖ξ‖ 最小的 Log。**规范方向不是误差，是坐标系选择的自由度。**

**定义 237（抓取扳手空间裕度与方向敏感度）** 接触集 C={(p_i,n_i)}，摩擦锥线性化后抓取矩阵 G_g∈R^{6×m}，扳手空间 W(g,θ)={G_gλ : λ∈FC(θ), λ≥0}，Ferrari–Canny 裕度 ε(g,θ)=max{ε : B_ε(0)⊆W}。接触雅可比 J_g=∂w/∂g，ε 对扳手的 Lipschitz 常数为 L_ε。方向敏感度 s_j=L_ε·σ_j(J_g)。一阶界：

U_α={(g,θ) : s_conformal(g,θ)≤q_α}，
用 K 个粒子 {(g_k,θ_k,w_k)} 表示；先按 G_sym 做对称感知聚类（同一轨道合并为一个模式），再在商空间内更新权重。认证裕度
ε_cert(U_α)=inf_{(g,θ)∈U_α} ε(g,θ)，
安全条件 ε_cert≥ε_req。粒子权重由视觉/力/触觉证据在线更新，split-conformal 给分布无关覆盖；按模式（而非单粒子）做 CVaR 尾部。

**定义 239（连续接触参数模型）** θ=[μ,k_c,c_c,b_f,m_o,I_o]ᵀ：摩擦系数、法向接触刚度、阻尼、F/T 偏置、物体质量、惯量。线性参数化测量模型
w_t=Y_tθ*+b_noise，
Y_t 由接触几何、法向力、加速度与抓取矩阵构成；接触力 f_n=k_cδ+c_cδ̇，摩擦 f_t=μf_n，F/T 读数 w_m=w_true+b_f。质量/惯量通过刚体动力学线性参数化进入。**模型类与噪声界必须显式声明，后续所有保证都以它为前提。**

**定义 240（集合隶属可行参数集）** 初集 Θ₀ 为物理可行盒（μ∈[0,1.5]、k_c>0、b_f 有界、m_o>0 等）。给定历史测量栈，
Θ_t=Θ_{t−1}∩{θ : ‖w_{m,s}−Y_sθ‖≤δ_noise, ∀s∈stack_t}，
用外椭球近似保持可计算性。若 Θ_t=∅，输出 `model_inconsistent`（开放集异常），禁止硬归因到最近的离散假设。**可行集为空是模型类错误的证据，不是数值故障。**

**定义 241（投影自适应律、死区与边界应力）** 自适应律
θ̂̇=Proj_{Θ_t}(−ΓM_tY_tᵀe_t)，e_t=w_m−Y_tθ̂，
M_t=diag(M_pe) 为激励掩码；‖e_t‖≤δ_dz 时 θ̂̇=0（死区防噪声漂移）。边界应力
β_t=滑窗内[1{投影激活}+1{dist(θ̂,∂Θ_t)<ε_b}] 的比例；
β_t>β_max 输出 `adaptation_stress`，冻结自适应、切鲁棒模式并请求语义流重识别。**边界应力是「自适应在硬撑」的告警器；参数长期贴边比参数变化本身更可疑。**

**定义 242（激励监控与并发学习数据栈）** 联合回归量 Y=[Y_g,Y_θ]，联合信息 Λ=ΣY Yᵀ。θ 的条件信息（Schur 补）
Λ_{θ|g}=Λ_{θθ}−Λ_{θg}Λ_{gg}⁻¹Λ_{gθ}；
仅当 λ_min(Λ_{θ|g})≥λ_pe 时允许 θ 在该方向自适应，否则冻结并用先验界鲁棒化。并发学习栈保留信息量最大的历史对 (Y_s,w_s)；若 rank(Σ_sY_sY_sᵀ)=d_θ，则无需持续 PE 也能指数收敛；秩亏方向即不可辨识方向，写入 `unexcited_subspace`。**联合可辨识性必须用 Schur 补：否则位姿误差会被误吸收成摩擦变化。**

**定义 243（L1 自适应壳与一致瞬态界）** 状态预测器
x̂̇=Ax̂+B(ω̂+u)，ω̂̇=ΓProj(ω̂,−PBᵀx̃)，x̃=x̂−x；
控制 u=−Kx̂−LPF(ω̂)。由标准 L1 自适应结论，存在可计算界 η(Γ,ω_f,Θ_t) 使块内
‖w_m(t)−w_ref(t)‖ ≤ η(Γ,ω_f,Θ_t)+γ₀‖θ̃(0)‖e^{−λt}，
且 η 与参数不确定幅度弱相关。η 是 ACSC 的直接输入。**瞬态界让「边适应边认证」第一次有据可依。**

**定义 244（自适应认证前缀）** 对块 A_t 与前缀 k，要求 ∀s≤k：
ε_cert(s)−L_εη(s)≥ε_req，f_n(s)≤f_lim，slip_margin(s)≥0，
且 conformal 越界概率 ≤α_chunk。选最大可行 k*≤min(H,m)。PE 良好且 η 下降时允许 k* 扩展至 m；PE 丢失、边界应力或 Θ_t 膨胀时收缩至 k_rob（VISTA 的鲁棒前缀）。输出 (k*,ε_cert,η,PE 证据,Θ 直径)。**长预测仍可长，但「短执行」的长度现在由自适应质量动态决定。**

**定义 245（CAFIR 连续优先归因与开放集拒绝）** 给定残差 r=(e_gauge,e_pose,e_θ,e_model,e_chunk)，按顺序判定：
1. 残差全在任务无关规范方向 → `H0_gauge`（健康，仅规范固定）；
2. 残差在 g 的可辨识方向 → `H_pose`（重估抓取位姿，不判几何故障）；
3. 残差在 θ 的条件可辨识方向且 Θ_t 非空 → `H_adapt`（连续参数更新）；
4. Θ_t=∅ 或残差超出模型类 conformal 界 → `H_open`（开放集异常，安全降级，不分类）；
5. 残差落在 g/θ 混淆或未激励方向 → `H_unobservable`（冻结 + GBP）；
6. 真离散事件（接触丢失、饱和、滑移冲量）→ 原 VISTA 离散假设。
**不再对有限 ℋ 做 argmax；只有真正离散的事件才允许离散标签。** 这直接消解 A88 的「未知复合故障被强行归入最近假设」。

**定义 246（规范打破主动探针 GBP）** 候选 P={rotate_about_axis, tilt, regrasp, lift, null_test, active_vision}。选择
a*=argmax_{a∈P} I(π_task; o(a)|U_α)/(c_damage(a)+λc_time(a))，
s.t. 预测扳手扰动≤ε_budget、无掉落、f_n≤f_safe。对连续对称，绕轴旋转或倾斜以打破规范；对多模态抓取，轻抬/换指以消歧；对易损物体只允许 null_test/active_vision。无安全探针时输出 `gauge_hazard` 并 safe_idle。**这是 AFA 的几何对偶：不是问「谁坏了」，而是问「哪个方向根本看不见，怎么用最小扰动把它变成看得见」。**

**定义 247（RSC-G 方向证书与自适应 CBF）** 不确定性拆为 r_gauge（任务无关不可观，单独标记，不进安全球）、r_pose,sens（按 s_j 加权的位姿敏感分量）、r_param（Θ_t 直径）、r_model（未建模）。只膨胀任务相关且敏感的方向：
r_safe=‖diag(s)·δg_sens‖⊕r_param⊕r_model。
搜索域
B_Q([ĝ],r_safe) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ 𝒲(ε_cert)，
𝒲 为扳手裕度约束。自适应 CBF：h(x)=ε(g,θ̂)−ε_req−L_εη，要求 ḣ+αh≥0；投影与 L1 界保证 h 在自适应期间不越界。归因模糊时对模式后验做边缘化尾部。

**定义 248（J_grace 与 GRACE 算子）** 
J_grace=(J_vista, gauge_class, gauge_hazard, wrench_margin, margin_uncertainty, theta_hat, Theta_diam, condition_number, pe_index, unexcited_basis, boundary_stress, l1_bound, k*, open_set_flag, gbp_ver)。
验证规则：
Valid(J_grace) ⇔ 原 J_vista 的物理安全项
∧ CAFIR 未强行归因 ∧ (gauge_unobservable ⇒ 未膨胀几何球)
∧ ε_cert−L_εη≥ε_req ∧ 无 adaptation_stress
∧ k*≥1 ∧ PE/未激励方向已显式处理 ∧ 模型类版本一致。
语义流：[VISTA 语义流→GQP→GWS-C→CPS→PE-CL→CAFIR→GBP→ACSC→CSP-G→CSC→AIC-G]；实时流：[锚点读→规范残差→预计算支撑函数验 ε→有界投影自适应→L1 滤波→自适应 CBF→前缀执行/早停→J_grace 组装]。审计链新增：为何认为这是规范等价（gauge_class）、为何安全（ε_cert）、为何可以适应（条件 PE）、为何拒绝归因（H_open）。

### IP-224 GQP（对称感知抓取位姿残差）

```python
class GaugeQuotient:
    """对称群作用下的抓取位姿商空间；残差只在可辨识子空间计算。"""
    def __init__(self, G_obj, gripper_sym=(2, 'axis'), Sigma=None, eps_g=1e-3):
        self.G_obj = G_obj                 # 连续 SO(2)/SO(3) 或离散群
        self.gripper_sym = gripper_sym     # 换指 S2 × 绕接近轴 SO(2)
        self.Sigma = Sigma
        self.eps_g = eps_g

    def grasp_matrix_lie(self):
        return [axis_of(self.G_obj), *gripper_generators(self.gripper_sym)]

    def equiv_residual(self, g_hat, g_pred):
        xi = se3_log(g_hat.inv() @ g_pred)
        xi_par = project_onto(self.grasp_matrix_lie(), xi)  # 连续闭式/离散最小
        xi_perp = xi - xi_par
        e = float(xi_perp @ inv(self.Sigma) @ xi_perp)
        gauge_unobs = norm(xi_par) > self.eps_g
        hazard = changes_task_observable(xi_par, self.G_obj)
        return {'e_gauge': e, 'gauge_unobs': gauge_unobs, 'gauge_hazard': hazard,
                'xi_par': xi_par, 'xi_perp': xi_perp}

    def mode_cluster(self, particles):
        # 轨道内粒子合并，避免同一抓取被当成多个模式
        return group_by_orbit(particles, self.G_obj, self.gripper_sym)
```

```python
class WrenchCertificate:
    def __init__(self, L_eps, eps_req):
        self.L_eps, self.eps_req = L_eps, eps_req

    def margin(self, g, theta, contacts):
        G = grasp_matrix(g, contacts)
        FC = linearized_friction_cone(theta['mu'], contacts)
        return epsilon_radius(G, FC)       # LP / support-function

    def directional_bound(self, g, theta, U_alpha, contacts):
        J = grasp_jacobian(g, contacts)
        delta_w = max(norm(J @ dg) for (dg, _) in U_alpha)
        return self.margin(g, theta, contacts) - self.L_eps * delta_w

    def certify(self, U_alpha, contacts):
        eps_min = min(self.margin(g, th, contacts) for (g, th) in U_alpha)
        return {'eps_cert': eps_min, 'safe': eps_min >= self.eps_req}
```

```python
class L1AdaptiveShell:
    def __init__(self, A, B, P, Gamma, omega_f, K):
        self.A, self.B, self.P = A, B, P
        self.Gamma, self.omega_f, self.K = Gamma, omega_f, K

            omega_hat, -self.B.T @ self.P @ x_tilde)
```

```python
class AdaptiveChunkCertificate:
    def __init__(self, L_eps, eps_req, alpha_chunk, k_rob):
        self.L_eps, self.eps_req = L_eps, eps_req
        self.alpha, self.k_rob = alpha_chunk, k_rob

    def certified_prefix(self, A, eps_cert, eta, m, pe_ok):
        k = 0
        for s in range(1, min(len(A), m) + 1):
            if eps_cert[s] - self.L_eps * eta[s] < self.eps_req:
                break
            if violation_prob(A[:s]) > self.alpha:
                break
            k = s
        if not pe_ok:
            k = min(k, self.k_rob)
        return k
```

```python
class GaugeBreakingProbe:

              'null_test', 'active_vision')

        for a in self.PROBES:

            if predict_force(a, U_alpha) > f_safe:
```

```python
def GRACE_round(M, obs):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流 ————
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    g_hat, modes = M.gqp.estimate(img, depth, flow, M.mws.grasp_proposals)
    U = M.cps.particles(g_hat, modes)                  # 商空间粒子后验

    # 1) 规范残差 + 扳手认证
    res_g = M.gqp.equiv_residual(g_hat, M.mws.predicted_grasp)
    eps_cert = M.gws.certify(U, M.mws.last_contacts)

    # 2) 连续参数可行集 + 条件 PE
    Theta, status = M.cps.membership.update(M.last_Y, M.last_w)
    if status == 'model_inconsistent':
        h_star, action = 'H_open', {'action': 'safe_idle'}
    else:
        mask, unexcited, pe_index = M.pe.mask(M.joint_info)
        M.theta_hat, beta = M.paal.step(
            M.theta_hat, Theta, M.last_Y, M.last_e, mask, M.dt)
        eta = M.l1.bound()

    # 3) CAFIR 连续优先归因
    if status == 'ok':
        h_star, action = M.cafir.attribute({
            'gauge_only': res_g['gauge_unobs'] and res_g['e_gauge'] < Q_VIS,
            'gauge_hazard': res_g['gauge_hazard'],
            'pose_identifiable': M.joint.is_pose_identifiable(),
            'theta_identifiable': M.joint.theta_identifiable(),
            'Theta_empty': False,
            'open_score': M.open_test.score(),
            'discrete_event': M.discrete.detect()})

    # 4) 不可观 / 规范危险 → 最小扰动探针
    if h_star in ('H_unobservable', 'H_open') or res_g['gauge_hazard']:
        a = M.gbp.choose(modes, U, M.damage_budget, M.f_safe)
        if a is not None:
            M.execute_probe(a)
            return GRACE_round(M, M.next_obs())

    # 5) 块规划 + 自适应认证前缀
    A = M.ach.propose(x_prime, H=M.H)
    k_star = M.acsc.certified_prefix(
        A, eps_cert, eta, M.m, pe_ok=(pe_index >= M.lambda_pe))

    # 6) 实时执行：有界自适应 + L1 + CBF + 早停
    K_safe, EV_exec, cert_exec = realtime_step_grace(
        M, A, k_star, M.theta_hat, Theta, eta)

    # 7) 语义流在线更新与证书
    M.olp.online_step(M.olp.fuse_evidence(x_prime, W_meas, tactile, res_g),
                      execution_loss_grad(K_safe, EV_exec, M.balls))
    M.rsc_g.update(EV_exec, W_meas, g_hat, M.theta_hat, Theta)
    M.aic_g.certify(A, x_prime, g_hat, Theta, M.theta_hat)
    return M, K_safe, EV_exec, build_j_grace(
        cert_exec, J_vista=M.j_vista, gauge_class=res_g, wrench_margin=eps_cert,
        theta_hat=M.theta_hat, Theta_diam=diam(Theta), pe_index=pe_index,
        unexcited=unexcited, boundary_stress=beta, l1_bound=eta,
        k_star=k_star, open_set=(h_star == 'H_open'))
```

## 4. 推导

**假设 A94–A99（证书的前提，必须显式声明）**
- **A94（L1 瞬态界）**：存在可计算 η(Γ,ω_f,Θ_t)，使块内跟踪误差满足定义 243 的界。
- **A95（模型类与噪声）**：真实 θ*∈Θ₀；测量噪声有界 δ_noise；Y_t 可测且线性参数化成立。
- **A96（结构故障可观测性）**：任何能导致不安全的**结构故障**，要么使 Θ_t 为空，要么在所有 θ∈Θ_t 下违反扳手/力限，要么产生离散事件；若某结构故障恰好等价于一个**安全**的 θ∈Θ_t，则它与该参数变化不可区分——这是根本极限，GRACE 不假装解决。
- **A97（任务相关对称）**：操点处 G_safe⊆ker(dπ_task)；任何任务相关对称方向被标 `gauge_hazard`，绝不被商掉。
- **A98（扳手 Lipschitz）**：ε 对扳手 Lipschitz（常数 L_ε），J_g 有界。
- **A99（conformal）**：标定集与新样本可交换，U_α 覆盖 ≥1−α。

**引理 9（规范不变性消除伪故障）** 设 h∈G_safe 任务无关。由定义 236，π_task(g·h)=π_task(g)；由定义 237，抓取矩阵与摩擦锥在 g↦g·h 下只做同一正交变换，扳手空间半径不变，故 ε(g·h,θ)=ε(g,θ)。于是规范等价抓取的 ξ_⊥=0，e_gauge=0，CAFIR 返回 `H0_gauge`，r_geo 不膨胀。VISTA 的绝对残差 e_vis=e_gauge+‖ξ_∥‖²；商掉 dim 𝔤_sym 个自由度后，几何伪故障的误报从 χ²_d 降为 χ²_{d−dim 𝔤_sym}。对圆柱连续对称，dim 𝔤_sym=1（绕轴）或 2（含换指/自旋），误报率严格下降。∎

**引理 10（扳手空间方向界）** ε 对扳手 Lipschitz 且 w=G_gλ，故 |ε(g+δg,θ)−ε(g,θ)|≤L_ε‖J_gδg‖+o(δg)。取 U_α 上最坏 δg，得 ε_cert≥ε(g,θ)−L_ε max_{U_α}‖J_gδg‖。因此安全影响只由 J_g 的大奇异方向决定；J_g 近零方向可自由（不应膨胀），J_g 近奇异方向必须收紧。位姿球对全部方向统一膨胀，既可能不必要（小奇异方向）又可能不足（近奇异抓取、σ_max 大）。∎

**引理 11（集合隶属的一致性与开放集）** 若 A95 成立、θ*∈Θ₀、噪声≤δ_noise，则对任意 t，θ* 满足所有历史约束，故 θ*∈Θ_t；由归纳 Θ_{t+1}⊆Θ_t。若 Θ_t=∅，则不存在任何 θ 能同时解释历史测量，故模型类错误或噪声界被破坏——这正是开放集异常的定义。投影保证 θ̂∈Θ_t，因此自适应不可能漂出物理可行域；死区保证零激励/纯噪声时 θ̂ 不动，避免参数漂移。∎

**引理 12（条件 PE 与并发学习）** 联合回归 Y=[Y_g,Y_θ]，联合信息 Λ。对 θ 做 Schur 补得 Λ_{θ|g}，它等于把 g 边缘化后 θ 的 Fisher 信息。若 λ_min(Λ_{θ|g})≥λ_pe，标准投影梯度自适应律满足 ‖θ̃(t)‖≤κe^{−λt}‖θ̃(0)‖+κ′δ_noise/λ_pe；若并发学习栈满足 rank(ΣY_sY_sᵀ)=d_θ，则可用历史数据构造正定信息阵，无需持续 PE 也指数收敛。未激励/混淆方向（Λ_{θ|g} 小特征方向）不可辨识，只能保持先验界——这正是「只膨胀对的球」的连续版本。若不做 Schur 补，位姿误差会通过 Y_g 混入 θ 的更新，把几何偏差误吸收成摩擦变化。∎

**引理 13（L1 一致瞬态界）** 在 A94 下，L1 状态预测器 + 低通滤波控制使块内跟踪误差满足定义 243 的 η 界；由标准 L1 结果，该界与参数不确定幅度弱相关，主要由自适应增益 Γ 与滤波器带宽 ω_f 决定，且可通过增大 ω_f、Γ 收紧。故「边适应边执行」的瞬态可由 η 事先界定，ACSC 可据此选 k*。∎

**定理 9（GRACE 端到端归因-安全）** 在 A94–A99 下，Valid(J_grace) ⇒
1. **无规范伪故障**：任务无关规范等价的抓取不被判 H_geo、不膨胀几何球（引理 9）；
2. **自适应有界**：θ̂∈Θ_t 且 Θ_t 单调不增、含 θ*；边界应力与死区防止漂移（引理 11）；
3. **开放集诚实**：Θ_t 为空或残差超出模型类 conformal 界时判 `H_open`/`H_unobservable`，不强行归入有限 ℋ（定义 245）；这直接消解 A88 的「未知复合故障被迫分类」；
4. **自适应期间安全**：CBF h=ε−ε_req−L_εη 配合 L1 界与投影，使 ε_cert−L_εη≥ε_req、f_n≤f_lim、滑移裕度≥0（引理 10、13）；
5. **故障掩蔽极限**：若结构故障等价于安全 θ∈Θ_t，GRACE 无法区分（A96）；此时证书强度以模型类为界，只能靠边界应力、PE 异常、残差白度检验或独立锚点（IMU/本体感觉/已知标定物）来暴露。∎

**定理 10（自适应前缀的近最优性）** 设块长 H 使动作方差 ∼σ_π²/H，故障不可逆视界 m，鲁棒前缀 k_rob，PE 丢失概率 p_pe。风险
R(H,k)=c₁σ_π²/H+c₂·1[k>m]+c₃·p_pe·1[k>k_rob]。
对 k≤m 且 PE 保持时，第三项为 0，R 关于 k 不变、关于 H 单调不增，故 k* 可扩展至 m；PE 丢失时 k*≤k_rob，第三项消失但保守性上升。故最优策略是 H 取计算允许最大值、k* 由 η、ε_cert 与 PE 质量动态决定。这把第 65 轮「长预测、短执行」升级为「长预测、**由可辨识性决定的动态短执行**」。∎

**命题（扳手证书优于位姿球）** 位姿球要求 sup_{δg∈B_r}L_ε‖J_gδg‖≤ε−ε_req，即 r≤(ε−ε_req)/(L_εσ_max(J_g))；当 σ_max(J_g) 大（近奇异抓取）时 r 必须极小，位姿球过保守；当某方向 σ_j≈0 时位姿球又无谓膨胀。扳手证书按 s_j=L_εσ_j(J_g) 加权，只在敏感方向收紧，并显式保留规范自由度。对 ε 很小的近奇异抓取，位姿球可能「位姿很准但仍不安全」；扳手证书直接测 ε，能正确报警。∎

## 7. 已知风险

**一句话**：GRACE 的安全证书只对「真实世界落在所声明的参数模型类 Θ 内」负责；当**结构损伤恰好能被一个安全参数变化解释**（单指卡滞→摩擦变大、传动打滑→阻尼变化、连杆碰限位→偏置变化）时，投影自适应会把残差压到零、把扳手裕度「证明」为达标，而边界应力与集合隶属都可能保持安静——**故障被自适应吸收，系统在证书齐全的情况下继续抓取**，这是本轮全部商空间、连续化与开放集论证共同依赖的隐藏假设（A96）。

**次级风险与缓解**：
1. **故障掩蔽（最高风险）**：自适应吸收结构损伤；缓解：边界应力、PE 异常、残差白度/结构检验、独立锚点（IMU/本体感觉/已知刚度探针）、对 θ 施加物理单调性/守恒约束；一旦边界应力超阈，强制退出自适应并开放集拒绝。
2. **模型类错配**：Θ 本身错了，集合隶属永远非空但模型不对；缓解：模型验证集、残差白度检验、在线模型选择、把 `model_class_version` 写入 J_grace，模型变更必须重认证。
3. **任务相关对称被误商**：把纹理/线缆/按键朝向当规范自由度商掉；缓解：π_task 显式审计、`gauge_hazard` 硬门、对任务相关方向禁用商、GBP 探针强制规范固定。
4. **g/θ 混淆**：位姿误差被吸收成摩擦变化；缓解：Schur 补条件信息、联合可辨识性检验、GBP 先消歧 g 再适应 θ、混淆时判 `H_unobservable`。
5. **PE 饥饿 / 并发学习秩亏**：未激励方向不可辨识；缓解：冻结该方向、用先验界鲁棒化、主动设计激励轨迹、并发学习栈保持满秩、显式输出 `unexcited_subspace`。
6. **扳手裕度计算**：LP/凸包在接触点多时变慢且 ε 非光滑；缓解：线性化摩擦锥、预计算支撑函数、语义流精算 + 实时流保守插值、GP/NN 代理需带 Lipschitz 证书。
7. **L1 界保守**：η 过大会使 k* 退化到 1；缓解：按块分视界标定 η、自适应滤波器带宽、把 η 的经验分位数与理论界取小并做 conformal 校准。
8. **实时自适应新攻击面/WCET**：实时写参数破坏确定性；缓解：只允许预认证紧集内、有界速率、固定迭代次数的投影更新；参数集重识别与结构判定全部留在语义流；硬件看门狗与回滚快照。
9. **共因故障仍不可观**：透明/镜面/对抗 patch 同时骗视觉与几何时，残差可能仍为零；缓解：AIC-G 显式建模共因、要求判 `H_open`/`H_unobservable` 而非强行归因、引入物理独立锚点；GRACE 的承诺是「不更自信」，不是「一定看得见」。
10. **conformal 漂移**：分布漂移使 U_α 覆盖失真；缓解：在线重校准 + 漂移检测（e_gauge/ε 分位数漂移即触发重标定）+ 按模式分层的 conformal。
