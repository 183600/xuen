# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「6D位姿估计」×「热管理」）

> R69 把不确定性一分为二，教会系统「开口去问」：aleatoric 收紧扣安全，epistemic 主动交互去消解。但它有一个未言明的前提——**系统问到的答案，题面本身是成立的**。也就是说，R69 假定「多模态」来自世界（对象确实对称、意图确实两可、动作确实多峰），因此「换个视角/再问一句」必然带来信息。真实世界里还有另一类多模态：它不在世界，而在**仪器**。相机内参随温度漂移、外参随结构热膨胀偏转、IMU 零偏随结温爬升——一个本不对称的物体，会因为热漂移被估计成「两个都像」的位姿。于是 R69 最优雅的动作（凑近看、多采几个视角、加大算力）恰恰是**最发热**的动作；系统越努力消歧，越把自己的仪器推向更歧义的状态。
>
> 本轮两个灵感正好戳中这个盲点：
> - **6D 位姿估计**把「歧义」从抽象标量变成**有几何结构的对象**：SE(3) 上的有限个对称模态（对称群轨道）+ 模态内连续噪声。它让「歧义」第一次可以被问「你是哪来的」。
> - **热管理**把「仪器自身的慢变量」变成**可建模、可约束、可支付代价**的状态：温度是慢变量，既污染标定，又是有限资源，而且每一次「看」都在给它充值。
>
> 核心命题：**多模态位姿后验存在一个「归因」问题——是世界真的对称，还是我自己被热偏置了？** 两者在单帧观测里是**混淆（confounding）**的，不可直接分辨。TP-RAS 的做法是先做**热-位姿联合辨识**（Fisher 信息 Schur 补 + 幻影模态比 κ），只有归因到「世界」且热学上可辨识时，才允许 R69 式交互；归因到「仪器」则走**热条件标定 + 冷却/降载**；归因不了则**禁止交互**并保守退避。因为信息不是免费的：**每消解一比特歧义，都要以焦耳计的热为代价，而热又会给未来的歧义充值。**
>

>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个歧义到底在世界里，还是在我自己身上——我付得起消解它的热价吗**」。

## 0. 直觉与动机

**灵感 1（6D 位姿估计 → 歧义有几何，也有两种来源）**
直觉：6D 位姿不是一串数，它是 SE(3) 上的一个点。对称物体（圆柱、方盒、带对称轴的零件）天然产生**有限个等价模态**——同一个观测，`p` 和 `p·g`（`g ∈ G_sym`）都自洽；遮挡与自相似又补上另外几个离散模态。所以位姿歧义不是一个高斯方差，而是「几个群轨道代表 + 每个轨道内的连续抖动」。这恰好是 R69 流匹配模态分解的**几何化版本**：R69 的模态来自策略采样聚类，本轮模态来自对称群与位姿流形，语义更硬、可解释、可在 se(3) 上度量间距。
更重要的是：同一种「两个模态」的表象，可能来自**世界**（真对称），也可能来自**仪器**（热偏置把位姿整体推偏了半个模态间距）。观测一样，成因不同——这就是混淆。

**灵感 2（热管理 → 慢变量、资源、以及「感知的热价」）**
直觉：热是典型的慢变量，时间常数远大于控制周期，因此它不像噪声那样可以平均掉；它更像 R68 最担心的那种「被标定悄悄吸收的缓变故障」。但它比故障更「讲道理」：温度可测、动力学可建模、对传感器的影响（内参/外参/零偏）是光滑函数，因而**可预测、可补偿、可预算**。
关键反转：主动感知不是免费的。多视角、长时间曝光、加大算力做多假设推理，都会增加功耗与结温；而结温上升又会让位姿估计变差。于是「用动作消除歧义」与「用动作制造未来歧义」是同一枚硬币的两面。

**灵感 3（合起来 → 归因是第一性问题）**
直觉：R69 直接问「要不要交互」，TP-RAS 必须先问「**这个歧义配不配被交互**」。若把热漂移误判成世界对称，系统会自信地多视角/加算力去「消解」，越消解越热、越热越漂，最后得到一个被自身加热推着走的、永远追不上的位姿——**追着自己的热漂移跑**。若反过来把真对称误判成热漂移，系统会无谓地冷却/降载，牺牲任务效率去治一个不存在的病。所以需要一个**交互前的归因门**：先做热-位姿可辨识性检验，再决定问不问。

**灵感 4（信息的守恒式 → 「信息有温度」）**
直觉：R69 的 VoI 只减社会/物理成本，没减**热成本**，更没减「这笔热会抬高未来 U_th」的跨期成本。把能量、温升、以及热致位姿误差一起记进账，会得到一个漂亮的结论：净收益随信息投入先升后降，存在有限的最优信息预算 E*；位姿-热耦合越强，E* 越小。用一句话说：**知识不是免费的，它有一个结温。**

**灵感 5（可逆 vs 不可逆 → 正面回应 R68 的隐忧）**
直觉：R68 怕「慢变故障被标定吸收而隐形」。热漂移正好是这类慢变分量的代表，但它其实是**可逆**的——按温度补偿它是对的，不该报警。真正该报警的是**不可逆退化**（超过临界温度、Arrhenius 热剂量累积）。于是 TP-RAS 把「标定吸收」拆成两半：可逆热漂移交 TCC 预测补偿，不可逆损伤交 Arrhenius 剂量监测。R68 的洞不是被补上一块砖，而是被**在物理上分清了两种砖**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TP-RAS 总览）** TP-RAS = (TSE, SPM, ACA, TIC, TBG, TCC, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **热-信息双硬预算**：任意预测时域内 `P(T_{t+k} > T_crit) ≤ δ_T`、窗口能耗 `E ≤ E_max`，信息动作与热管理动作都计入能耗；
(iii) **归因纪律**：一个多模态位姿后验，只有在「热替代假设被拒绝或显式边缘化」且 `μ_id ≥ μ_c` 时，才可被当作「世界可消歧」并交给交互；否则禁止交互，只允许冷却/观测热状态/保守退避。

**定义 311（热状态潜变量 TSE）** 热状态 `τ_t ∈ 𝒯 ⊂ ℝ^m`（结温/板温/光机温度）。慢动力学 `τ_{t+1} = f_θ(τ_t, u_t, T_amb) + w_t`，`u_t` 为计算与执行功耗，时间常数 `T_th ≫` 控制周期。观测含热敏电阻与间接代理（零偏漂移）。估计器 TSE 给出 `(τ̂_t, Σ_τ)`。

**定义 312（热-位姿耦合观测）** 位姿 `p_t ∈ SE(3)`；观测 `o_t = h(p_t, τ_t, e_t) + η_t`，其中标定参数 `c(τ) = (K(τ), E(τ), b(τ))`（内参、外参、IMU 零偏）是温度的光滑函数。定义热-位姿雅可比 `J_{pτ} = ∂p/∂τ`（在 se(3) 坐标下），把温升线性映射为位姿漂移。

**定义 313（对称位姿模态 SPM）** 物体对称群 `G_sym`；位姿模态 `p_k = p_0 · g_k`，`g_k ∈ G_sym`（遮挡/自相似模态并入）。得模态集 `{m_k}`、权重 `w_k`、原型 `p̄_k`、模态内协方差 `Σ_k^pose`（se(3)）。模态间距 `Δ_min = min_{i≠j} d_SE3(p̄_i, p̄_j)/σ_in`，A95 下要求 `Δ_min ≥ 3`。

**定义 314（热幻影模态与混淆比 κ）** 热漂移 `Δτ` 诱发位姿位移 `Δp_τ = J_{pτ} Δτ`。定义**混淆比** `κ = ‖Δp_τ‖_{se3} / Δ_min`。当 `κ ≥ κ_c` 时，热漂移与模态间距同量级：单假设位姿估计器会在对称轨道间「跳变」，此时观测到的多模态**不可归因于世界对称**，称为**热幻影模态（thermal phantom mode）**。

**定义 315（四分解不确定性）** 在 R69 二分基础上加入热与归因两项：
`U_ale = Σ_k w_k tr(Σ_k^pose)`（模态内噪声，不可约）；
`U_epi = H(w)·g(Δ_min)`（世界歧义，可交互消解）；
`U_th = tr(J_{pτ} Σ_τ J_{pτ}^⊤)`（热致、慢变、可冷却/可补偿）；
`U_conf = I(M; τ | o)`（模态身份与热状态的互信息，即**归因歧义**，本轮新对象）。
四者语义不同、分通道处置：`U_epi→`交互（R69），`U_th→`冷却/热补偿，`U_conf→`先归因、未归因禁止行动，`U_ale→`R68 收紧。

**定义 316（热-信息价值 VoI-T）** 对信息动作 `g` 与热动作 `h`：
`VoI_T(g,h) = VoI(g) − c(g) − λ_E·E(g,h) − λ_T·ΔT(g,h) − λ_conf·U_conf(after)`，
其中 `ΔT(g,h)` 由 `f_θ` 预测，`E` 为能耗，`c` 为物理/社交成本，最后一项惩罚「越问越分不清归因」。
选 `(g*,h*) = argmax VoI_T`，s.t. 双预算、C-RAS-WM 认证、热包络（定义 321）。若 `max VoI_T ≤ 0`：不交互，退 R69/R68。

**定义 317（热增广动作空间与 TAF）** 动作 `ξ = (a, g, h) ∈ 𝒜_task × 𝒜_info × 𝒜_th`，`h ∈ {cool, throttle, dwell, recalibrate}`。R69 的流匹配策略扩展到在增广空间上采样；「降温后再看」「先问一句再摸」都是 `ξ` 的合法模态，且共享同一安全前缀认证。

**定义 318（热条件标定 TCC）** 以估计温度参数化标定 `c(τ̂)`，分解为可预测可逆部分 `r_rev = c(f_θ(τ̂)) − c_0`（补偿）与不可预测残差 `r_irr = c_obs − c_pred`（非热或不可逆）。判据：`r_irr` 大且 `Σ_τ` 小 ⇒ 非热故障，退回 R68 报警；`r_irr` 小 ⇒ 热漂移，补偿而非报警。

**定义 319（热-位姿可辨识性与归因门 ACA）** 对 `(p, τ)` 的 Fisher 信息分块 `F = [[F_pp, F_pτ],[F_τp, F_ττ]]`，取 Schur 补 `S = F_pp − F_pτ F_ττ^{-1} F_τp`，定义可辨识裕度 `μ_id = λ_min(S)/λ_max(F_pp)`。交互可消歧**当且仅当** `μ_id ≥ μ_c` 且 `κ ≤ κ_c`：模态判别方向不得落在「热可解释」的近零空间里。这是 R69 缺少的**交互前自检**。

**定义 320（热-信息联合预算与 Pareto）** 可行域 `ℱ = {(g,h): E ≤ E_max, P(T_pred ≥ T_crit) ≤ δ_T, 信息预算未越界}`。在 `(期望误差, 峰值温度, 能耗)` 三维上定义 Pareto 前沿；策略运行在拐点而非任一端点。

**定义 321（预测热包络 TBG）** 用 `f_θ` 前推 `T̂_{t+k}` 及置信区间；动作可行当且仅当 `∀k ≤ H: P(T_{t+k} > T_crit) ≤ δ_T`。该包络并入 C-RAS-WM 的前缀认证，成为热学版安全护栏。

**定义 322（可逆/不可逆判据）** Arrhenius 热剂量 `D(t) = ∫_0^t exp(−E_a/(k_B T(s))) ds`。可逆区：`T ≤ T_crit` 且 `D ≤ D_crit`；不可逆：`D > D_crit` 或 `T > T_crit`。不可逆一旦触发 ⇒ 永久降载 + 报警，**绝不用标定「补偿」掉**。

**定义 323（热-位姿证书 J_THERMO）** `J_THERMO = (J_FLUID, τ̂, Σ_τ, T_peak_margin, κ, μ_id, D_arrhenius, E_used, attribution_label, thermo_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 热包络满足 ∧ 归因纪律满足 ∧ 双预算未越界。

**定义 324（参与式审计 VQAuditor-T）** 审计归因决策：world/thermal 标签事后是否正确、冷却是否掩盖了真故障、能耗是否如实记账、是否出现「越问越漂」的追问链；结论回灌 ACA/TIC 先验与 TCC 残差模型。

**定义 325（干扰集 ℰ_THERMO）** `ℰ_THERMO = ℰ_FLUID × ℰ_thermal`，`ℰ_thermal` 含：对抗性加热/移除散热（诱导热漂移）、热伪装（把 κ 推到门限附近制造错误归因）、热敏传感器欺骗、冷却剥夺（迫使系统在过热区感知）。

**定义 326（保守退避延伸）** 若 `μ_id < μ_c` 或 `κ ≥ κ_c` 或热包络余量为负或接近 `T_crit` ⇒ 禁止交互，优先 `h = cool/throttle`，并取 `λ = λ_floor(U_ale + U_epi + U_th + U_conf)`（未归因项整体视同不可约）。当 `τ` 恒定、无热动作、`κ=0, μ_id=1` 时逐指令退化为 R69。⇒ 安全侧永不弱于 R69/R68。

```python
# IP-264 TSE：慢热动力学 EKF（热敏电阻 + 零偏代理）
class ThermalStateEstimator:
    def step(self, u, T_amb, y_thermal):
        self.pred = self.f(self.tau, u, T_amb)
        self.P    = self.A @ self.P @ self.A.T + self.Q
        K = self.P @ self.H.T @ inv(self.H @ self.P @ self.H.T + self.R)
        self.tau  = self.pred + K @ (y_thermal - self.H @ self.pred)
        self.P    = (I - K @ self.H) @ self.P
        return self.tau, self.P                         # τ̂, Σ_τ

# IP-265 SPM：对称感知 6D 位姿模态（轨道 + 模态内协方差）
def pose_modes(o):
    p0, Sigma0 = pose_estimator(o)
    return [(p0 @ g, weight(g), cov_se3(g)) for g in G_sym(Obj)]  # p_k, w_k, Σ_k

# IP-266 ACA：混淆比 + Fisher-Schur 可辨识性 + 归因
def confusion_ratio(modes, dtau, J_ptau):
    return norm_se3(J_ptau @ dtau) / min_mode_separation(modes)

def identifiability(F_pp, F_ptau, F_tt):
    S = F_pp - F_ptau @ inv(F_tt) @ F_ptau.T            # Schur 补
    return lambda_min(S) / lambda_max(F_pp)             # μ_id

def attribute(modes, tau_hat, dtau, Sigma_tau, J_ptau):
    kappa = confusion_ratio(modes, dtau, J_ptau)
    mu    = identifiability(fisher_pp(modes), fisher_ptau(modes), fisher_tt(Sigma_tau))
    if kappa >= KAPPA_C or mu < MU_C:
        return "confounded", kappa, mu                  # 禁止交互
    # 世界对称 vs 热偏置：比较两者对观测的边际似然
    return argmax_evidence({"world": world_ll(modes),
                            "thermal": thermal_ll(tau_hat, J_ptau)}), kappa, mu

# IP-267 TIC：带热价与归因罚的 VoI
def thermo_info_control(modes, g_cands, h_cands, tau_hat, budget, label):
    best = None
    if label == "confounded": return None               # 归因未定，不许问
    for g in g_cands:
        for h in h_cands:
            if not budget.allow(g, h):                      continue
            if not c_ras_wm.certify_info(g, o_t):            continue
            if not tbg.envelope_ok(tau_hat, h):              continue
            dT   = thermal_model.delta_T(g, h)
            voi  = entropy(modes_w) - expected_entropy(modes, g)
            uconf_after = predict_confusion(modes, g, tau_hat)
            score = (voi - cost(g) - lam_E * energy(g, h)
                     - lam_T * dT - lam_conf * uconf_after)
            if best is None or score > best.score: best = (g, h, score)
    return best if best and best.score > 0 else None     # 热价过高 → 不交互

# IP-268 TBG：预测热包络 + Arrhenius 剂量 + 降载/冷却
class ThermalBudgetGovernor:
    def dose(self, T_hist):
        return integrate(exp(-E_a / (k_B * T_hist)))
    def envelope_ok(self, tau, h, H):
        return max(prob_over(T_pred(tau, h, k), T_crit) for k in range(H)) <= delta_T
    def risk_breach(self, tau):
        return self.dose(T_hist) > D_crit or tau.max() > T_crit - m_T

# IP-269 TCC：热条件标定，分可逆/不可逆
def thermal_calibrate(o, tau_hat):
    c_pred = c_of_temperature(f(tau_hat))
    r_irr  = c_obs(o) - c_pred                           # 不可预测残差
    o_comp = apply_calibration(o, c_pred)                # 补偿可逆热漂移
    return o_comp, r_irr

    tau_hat, Sig_tau = M.tse.step(M.last_u, M.T_amb, M.thermal_sensors)

    U_epi_after = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    # 3) 保守退避：未消解 epistemic + 热 + 归因歧义一起进 floor
    U_floor = U_ale + (0.0 if g else U_epi_after) + U_th + U_conf
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(label, kappa, mu, g, U_conf, M.tbg.dose(T_hist))
    return k, lam, mode, (U_ale, U_epi_after, U_th, U_conf)
```

## 3. 推导

**引理 19（热-位姿混淆与幻影模态）** 在 `o = h(p,τ)+η` 下，映射 `(p,τ) ↦ o` 的雅可比在「存在对称运动 `Δp ∈ Lie(G_sym)` 与热扰动 `Δτ` 使 `∂h/∂p Δp = −∂h/∂τ Δτ`」的集合上秩亏；沿该规范轨道，单帧观测无法区分「世界把位姿转了一个对称等价」与「仪器把位姿热偏了半个模态间距」。定义 `κ = ‖J_{pτ}Δτ‖/Δ_min`，当 `κ ≥ κ_c` 时最大似然位姿可在对称叶间跳变而似然代价有界 ⇒ **幻影模态**。证明要点：线性化后对称方向落入 `(p,τ)` 联合雅可比的近零空间。

**引理 20（信息的热价 / 热-信息守恒）** 能量 `E` 的信息动作在热容 `C_th` 下使温度上升 `ΔT ≥ η_E E/C_th − cooling`；由 `‖J_{pτ}‖ ≤ L_τ`，热致位姿误差期望上升 `≥ L_τ ΔT`。而信息动作最多把期望误差按后验熵降低 `ΔH Δ_min`。故净误差下降
`ΔJ(E) = ΔH·Δ_min·(1 − e^{−E/E_0}) − L_τ·E/C_th`，
凹函数，在有限 `E*` 处最大。系 1：**无界主动感知是热力学自伤的**；系 2：位姿-热耦合越强（`L_τ` 越大），最优信息预算 `E*` 越小。这是「知识有结温」的严格版本。

**引理 21（热条件标定分离可逆与不可逆）** 若可逆热漂移分量 `r_rev` 能被 `f_θ(τ̂)` 以误差 `ε_pred` 预测，则补偿后残差 `r_irr` 的方差 `≤ Var(r_res)` 且不再含可逆分量；因此 R68/R69 的缓变故障检测器对**热漂移**的误报下降，而真正的不可逆退化（不在 `f_θ` 张成空间内、且 Arrhenius 剂量超阈）仍可检出。系：R68 的「标定吸收」隐忧被分成「该吸收的可逆热漂移」与「不该吸收的不可逆损伤」两类。

**定理 18（严格包含 R69/R68）** 当 `τ` 恒定、无热动作、`κ=0、μ_id=1` 时，`U_th=U_conf=0` 且热成本为零，TP-RAS 逐指令退化为 FLUID-RAS；所有新增项是**非负约束与惩罚**，故可行动作集 `⊆` R69 的可行集，安全单调不降。⇒ R69/R68 是 TP-RAS 在「无热、无归因歧义」边界上的退化，安全侧不做任何让步。

**定理 19（热安全与无热失控）** 若每个动作都通过预测热包络（定义 321），且余量为负时冷却/降载优先，同时监测 Arrhenius 剂量，则系统不会热失控，且不可逆损伤在 `D_crit` 前报警。取 Lyapunov 函数 `V = max(0, T − T_crit)^2 + (D/D_crit)`，在可行动作下 `V` 单调不增。配合 R68 的换装/提交不变式（定理 15），控制连续、无突变。

**定理 20（归因门控的阈值最优性）** 在单调耦合假设（温度越高位姿越差；信息越多产热越多）下，最优策略在 `(κ, μ_id, T)` 空间中是**阈值策略**：仅当 `κ<κ_c`、`μ_id≥μ_c`、`T<T_int` 且 `VoI_T>0` 时交互；否则先冷却/降载或保守退避。故 TP-RAS 落在热-信息 Pareto 前沿的拐点。系：**不存在同时最大化信息与最小化热耗的策略**——超过 `E*` 后两者严格冲突。

## 6. 本轮最大风险

**一句话**：TP-RAS 的全部判断都押在「热-位姿耦合模型 `f_θ` 与雅可比 `J_{pτ}` 是对的」这一前提上——**若真实漂移的主因不是热（而是机械磨损、湿度、老化的外参松动），归因器会把世界歧义或非热故障误判成「可冷却的自伤」，于是冷却/降载会系统性地掩盖真正的错误：归因错，比不归因更危险。**

**次级风险与缓解**：
1. **热模型误设**（热时间常数/耦合系数错）→ 在线辨识 `f_θ` + 残差监控 + 包络保守裕度；
2. **归因门过严导致效率塌陷**（把真对称也判成 confounded）→ `μ_c` 校准 + E303 给出误拒/误受权衡曲线；
3. **热伪装攻击**（对抗加热把 κ 推到门限）→ ℰ_thermal 对抗训练 + 热状态的独立物理冗余（多热敏点）；
4. **冷却动作本身影响任务**（降载延迟、能耗）→ 联合预算 Pareto + 定理 20 阈值策略；
5. **不可逆损伤被「可逆」标签掩盖** → Arrhenius 剂量独立监测，绝不进入标定补偿通道，触发即永久降载并报警。

```python
# IP-264 TSE：慢热动力学 EKF
class ThermalStateEstimator:
    def step(self, u, T_amb, y_thermal):
        pred = self.f(self.tau, u, T_amb)
        P    = self.A @ self.P @ self.A.T + self.Q
        K    = P @ self.H.T @ inv(self.H @ P @ self.H.T + self.R)
        self.tau = pred + K @ (y_thermal - self.H @ pred)
        self.P   = (I - K @ self.H) @ P
        return self.tau, self.P                              # τ̂, Σ_τ

# IP-265 SPM：对称感知位姿模态
def pose_modes(o):
    p0, S0 = pose_estimator(o)
    return [(p0 @ g, weight(g), cov_se3(g)) for g in G_sym(Obj)]

# IP-266 ACA：混淆比 + Fisher-Schur 可辨识性 + 归因
def confusion_ratio(modes, dtau, J_ptau):
    return norm_se3(J_ptau @ dtau) / min_mode_separation(modes)

def identifiability(F_pp, F_ptau, F_tt):
    S = F_pp - F_ptau @ inv(F_tt) @ F_ptau.T               # Schur 补
    return lambda_min(S) / lambda_max(F_pp)                # μ_id

def attribute(modes, tau_hat, dtau, Sigma_tau, J_ptau):
    kappa = confusion_ratio(modes, dtau, J_ptau)
    mu    = identifiability(fisher_pp(modes), fisher_ptau(modes), fisher_tt(Sigma_tau))
    if kappa >= KAPPA_C or mu < MU_C:
        return "confounded", kappa, mu                      # 禁止交互
    return argmax_evidence({"world": world_ll(modes),
                            "thermal": thermal_ll(tau_hat, J_ptau)}), kappa, mu

# IP-267 TIC：热价 + 归因罚的 VoI
def thermo_info_control(modes, g_cands, h_cands, tau_hat, budget, label):
    if label == "confounded": return None                  # 归因未定，不许问
    best = None
    for g in g_cands:
        for h in h_cands:
            if not budget.allow(g, h) or not c_ras_wm.certify_info(g, o_t): continue
            if not tbg.envelope_ok(tau_hat, h): continue
            score = (VoI(modes, g) - cost(g) - lam_E*energy(g, h)
                     - lam_T*thermal_model.delta_T(g, h)
                     - lam_conf*predict_confusion(modes, g, tau_hat))
            if best is None or score > best.score: best = (g, h, score)
    return best if best and best.score > 0 else None       # 热价过高 → 不交互

# IP-268 TBG：预测包络 + Arrhenius 剂量
class ThermalBudgetGovernor:
    def dose(self, T_hist): return integrate(exp(-E_a / (k_B * T_hist)))
    def envelope_ok(self, tau, h, H):
        return max(prob_over(T_pred(tau, h, k), T_crit) for k in range(H)) <= delta_T
    def risk_breach(self, tau):
        return self.dose(T_hist) > D_crit or tau.max() > T_crit - m_T

# IP-269 TCC：热条件标定
def thermal_calibrate(o, tau_hat):
    c_pred = c_of_temperature(f(tau_hat))
    return apply_calibration(o, c_pred), c_obs(o) - c_pred  # o_comp, r_irr

# IP-274 主闭环（继承 R69，插入热-位姿归因门）
def TP_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    tau_hat, Sig_tau = M.tse.step(M.last_u, M.T_amb, M.thermal_sensors)
    o, r_irr = M.tcc.thermal_calibrate(o, tau_hat)
    modes = M.spm.pose_modes(o); dtau = M.tse.trend()

    U_ale, U_epi, U_th, U_conf = M.aca.decompose(modes, tau_hat, Sig_tau, M.J_ptau)
    if M.tbg.risk_breach(tau_hat) or r_irr > TAU_IRR:        # 热安全优先
        h = M.tbg.cool_or_derate()
        return M.apply_thermal(h), lam_floor(U_ale+U_epi+U_th+U_conf), None, \
               (U_ale, U_epi, U_th, U_conf)
    g = (M.tic.thermo_info_control(modes, g_cands, h_cands, tau_hat, M.budget, label)
         if (label == "world" and mu >= MU_C and kappa <= KAPPA_C
             and U_epi > TAU_EPI) else None)
    if g: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (0.0 if g else U_epi) + U_th + U_conf
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    M.vqa_t.submit_async(label, kappa, mu, g, U_conf, M.tbg.dose(T_hist))
    return k, lam, mode, (U_ale, U_epi, U_th, U_conf)
```

## 4. 推导

**引理 19（热-位姿混淆与幻影模态）** 映射 `(p,τ)↦o` 的雅可比在「对称运动 `Δp∈Lie(G_sym)` 与 `Δτ` 使 `∂h/∂p Δp = −∂h/∂τ Δτ`」处秩亏，沿该规范轨道单帧不可区分世界对称与热偏置；`κ≥κ_c` 时最大似然位姿可跨对称叶跳变而似然代价有界 ⇒ 幻影模态。

**引理 20（信息的热价 / 热-信息守恒）** `ΔT ≥ η_E E/C_th − cooling`，热致误差 `≥ L_τ ΔT`，信息收益 `≤ ΔH Δ_min`，故 `ΔJ(E)=ΔH Δ_min(1−e^{−E/E_0}) − L_τ E/C_th` 单峰，存在有限 `E*`。系：无界主动感知热力学自伤；`L_τ` 越大 `E*` 越小。

**引理 21（TCC 分离可逆/不可逆）** 可逆热漂移被 `f_θ(τ̂)` 以 `ε_pred` 预测并补偿后，残差 `r_irr` 不含可逆分量，热漂移误报下降；不可逆退化不在 `f_θ` 张成空间且 Arrhenius 剂量超阈，仍可检出。

**定理 18（严格包含 R69/R68）** `τ` 恒定、无热动作、`κ=0、μ_id=1` 时 `U_th=U_conf=0`、热成本为零，逐指令退化为 FLUID-RAS；新增项均为非负约束/惩罚，可行动作集单调缩小，安全单调不降。

**定理 19（热安全、无热失控）** 动作过预测热包络且余量为负时冷却/降载优先，取 `V=max(0,T−T_crit)^2 + D/D_crit` 在可行域单调不增；不可逆损伤在 `D_crit` 前报警；配合 R68 换装/提交不变式，控制连续、无突变。

**定理 20（归因门控阈值最优性）** 单调耦合下最优策略在 `(κ,μ_id,T)` 中为阈值策略：仅在 `κ<κ_c、μ_id≥μ_c、T<T_int、VoI_T>0` 时交互，否则先冷却/降载或保守退避；故 TP-RAS 位于热-信息 Pareto 拐点，超过 `E*` 后信息与热耗严格冲突。

## 7. 本轮最大风险

**一句话**：TP-RAS 的全部判断都押在「热-位姿耦合模型 `f_θ` 与雅可比 `J_{pτ}` 正确」这一前提上——**若真实漂移主因不是热（机械磨损、湿度、外参松动），归因器会把世界歧义或非热故障误判成「可冷却的自伤」，于是冷却/降载系统性地掩盖真正的错误：归因错，比不归因更危险。**

**次级风险与缓解**：热模型误设（在线辨识 + 残差监控 + 保守裕度）；归因门过严（`μ_c` 校准 + 误拒/误受曲线）；热伪装攻击（ℰ_thermal 对抗训练 + 多热敏点物理冗余）；冷却影响任务（联合 Pareto + 阈值策略）；不可逆损伤被标定掩盖（Arrhenius 独立监测，触发即永久降载并报警）。
