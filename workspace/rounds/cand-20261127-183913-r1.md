### 第 1 轮灵感驱动研究记录

**灵感词**：模型预测控制、时空推理

**直觉与动机**：

本轮两个灵感词的交汇点，恰好击中上一轮 CADVS 的命门。上一轮最大风险是「证书在消费时已过期却被误判有效」，而 TCVM 只能在证书过期后**事后**熔断；MRCC 也只能在对端失联后**事后**剔除。我们想把「证书是否有效」从**反应式检查**提升为**预测式规划**：让 MPC 在滚动时域内不仅预测机器人状态，还预测**每张证书在未来时空中的有效性**，从而主动绕开「证书即将失效」的时空区域。

第一个直觉是：证书不是布尔量，而是一个**时空场**。视觉特征质量随视角、距离、光照变化；差分定位可用性随位置（城市峡谷、隧道、室内）变化；通信端到端时延随网络负载随时间波动。把每张证书的归一化裕度 g_c(x, t) 画在 (x, t) 平面上，就得到一张「证书有效性地图」；MPC 预测出的状态轨迹是这张地图上的一条曲线。传统做法是等曲线穿过「无效区」才回退；时空证书 MPC 在规划时就把「整条曲线落在有效区内且留有余量」当成约束与目标。

第二个直觉来自「时空推理」的天然形式化工具——**信号时序逻辑（STL）**。STL 能表达「在未来 H 秒内始终满足所有证书有效」这类时空约束，并给出**定量鲁棒度** ρ_φ，而不只是布尔满足。把 ρ_φ 作为 MPC 的目标/约束，等价于要求「证书有效性留出可优化、可验证的余量」，这正好把上一轮只能被监控的 P99 时序裕度，变成可被规划器主动经营的变量。

第三个直觉是**元证书（certificate of certificate）**：既然单张证书不可全信，那么「预测器说未来证书会有效」这件事本身也必须附带证书——一个由 conformal 预测给出的、带概率覆盖保证的误差预算。只有预测鲁棒度大于该误差预算，规划器才允许相信自己。这把「信任」从主观判断变成可计算的量。

**形式化目标（增量）**：

1. 定义证书时空场：g_c: X × T → ℝ 为证书 c 的归一化裕度，有效集 C_c(t) = {x : g_c(x,t) ≥ 0}；g_c 取各子指标裕度的最小值（如视觉的 κ、跟踪置信度、深度方差，定位的协方差、陈旧时间，时序的延迟窗口）。
2. 定义时空证书预测器：ĝ_c(x,t) = μ_c(x,t) ± q_{1−α}·σ_c(x,t)，μ/σ 由时空高斯过程（ST-GP）或学习模型给出，q 由 split / adaptive conformal 校准，输出下置信界 LCB。
3. 定义 STL 证书规范：φ_cert = □_{[0,H]} ⋀_c (g_c ≥ 0) ∧ ◇_{[0,H]} (reach_goal)，鲁棒度 ρ_φ 按 min/max 递归计算；同时保留 liveness，防止机器人「躲在证书有效区不动」。
4. 定义时空鲁棒 MPC（SR-MPC）：max_u ρ_φ(x̂_{0:N}) − λ_u‖u‖² − λ_s·slack，s.t. 动力学、输入约束、逐步 LCB 证书约束、终端时空管。
5. 定义元证书：若预测鲁棒度 ρ̂_φ ≥ Γ := max_k (L_g·ε_x(k) + q·σ_c(k))，则真实鲁棒度 ρ_φ ≥ 0（带概率保证），Γ 即「信任预算」。
6. 证明递归可行性（含时变证书集）与 Exec_STCK ⊆ Exec_CADVS；设计收缩时域回退，处理证书场不可预测收缩导致的不可行。

**关键洞见**：把「证书时效」从**被动的运行时守卫**变成**主动的规划对象**，是从「证书驱动控制」到「时空证书预测控制」的范式跃迁。上一轮的 R28（时序碎片化）原本被判定为「只能压缩、不能消除」的工程问题；本轮把它部分转化为「在预测精度内可管理」的规划问题——代价是引入一个新的、更高阶的不确定性来源。

**本轮最大风险**：**元证书的不可靠性（certificate-of-certificate 回归）**——整个方案的安全性最终取决于「证书预测器」本身是否可信；时空预测在分布漂移（新地形、新光照、非平稳网络）下会系统性失准，而 conformal 覆盖保证所依赖的可交换性假设在时空过程中被违反，于是 MPC 会「自信地」把轨迹规划进实际上证书已失效的区域，形成比上一轮更隐蔽的**二阶虚假安全感**：系统不仅相信证书，还相信「自己对证书的预测」，而这份信任本身没有被任何更高阶机制验证。

### IP-478 Spatiotemporal Certificate Field (STCF)

```python
@dataclass
class CertSpec:
    cid: str
    kind: str                       # 'visual' | 'localization' | 'temporal'
    lcb_margin: float = 0.0         # 安全约束所需的最小裕度
    lipschitz: float = 1.0          # L_{g,c}：对状态变化的敏感度上界

@dataclass
class SpatiotemporalCertificateField:
    """STCF：把证书统一成 (x,t) 上的归一化裕度场 g_c(x,t)"""
    specs: dict[str, CertSpec]
    kappa_max: float = 50.0
    tau_conf: float = 0.7
    sigma2_max: float = 0.04
    lambda_thresh: float = 0.02
    T_max: float = 2.0
    dt_val: float = 0.050           # 证书有效窗口

    def g_visual(self, kappa, c_track, sigma2_depth) -> float:
        # 三项子裕度取 min：任一项越界即整体为负
        return min(
            (self.kappa_max - kappa) / self.kappa_max,
            (c_track - self.tau_conf) / (1.0 - self.tau_conf),
            (self.sigma2_max - sigma2_depth) / self.sigma2_max,
        )

    def g_localization(self, lambda_max, tau_since) -> float:
        return min(
            (self.lambda_thresh - lambda_max) / self.lambda_thresh,
            (self.T_max - tau_since) / self.T_max,
        )

    def g_temporal(self, l_e2e) -> float:
        return (self.dt_val - l_e2e) / self.dt_val

    def margin(self, cid: str, x: np.ndarray, t: float,
               sensor_pred: "SensorPrediction") -> float:
        """从预测的传感器量构造 g_c(x,t)；sensor_pred 由 IP-479 的状态-传感器耦合模型给出"""
        spec = self.specs[cid]
        if spec.kind == 'visual':
            return self.g_visual(*sensor_pred.visual(cid, x, t))
        if spec.kind == 'localization':
            return self.g_localization(*sensor_pred.loc(cid, x, t))
        return self.g_temporal(sensor_pred.delay(t))

    def valid(self, cid: str, x, t, sensor_pred, margin: float = 0.0) -> bool:
        return self.margin(cid, x, t, sensor_pred) >= margin
```

### IP-479 Spatiotemporal Certificate Predictor (STCP)

```python
@dataclass
class SpatiotemporalCertificatePredictor:
    """STCP：ST-GP 预测证书裕度 + split/adaptive conformal 校准"""
    inducing: np.ndarray            # (m, d) 诱导点（时空特征）
    lengthscale: np.ndarray         # ARD 长度尺度
    variance: float = 1.0
    noise: float = 1e-3
    alpha: float = 0.05             # 目标误覆盖概率
    aci_gamma: float = 0.01         # adaptive conformal 步长

    def __post_init__(self):
        self.q_hat = {cid: 1.0 for cid in self.specs}   # 归一化分位数
        self.residual_hist = defaultdict(list)

    def _features(self, x, t):
        # 时空特征：位置(3) + 速度(3) + 时间相位(2)
        return np.concatenate([x[:3], x[3:6], [np.sin(2*np.pi*t/10), np.cos(2*np.pi*t/10)]])

    def fit(self, cid, Z, y):
        """离线/在线增量拟合每个证书的 ST-GP（稀疏诱导点）"""
        Kmm = self._kernel(self.inducing, self.inducing)
        Kmn = self._kernel(self.inducing, Z)
        Kmm_inv = np.linalg.inv(Kmm + 1e-6*np.eye(len(self.inducing)))
        self.A = Kmm_inv @ Kmn
        self.y_res = y - self.A.T @ self._kernel(Z, self.inducing).T if False else y
        self._cid = cid

    def predict(self, cid, X, T):
        """返回逐步均值 μ 与标准差 σ，O(N·m²)"""
        Z = np.stack([self._features(x, t) for x, t in zip(X, T)])
        Kmm = self._kernel(self.inducing, self.inducing)
        Kms = self._kernel(self.inducing, Z)
        Kss_diag = np.diag(self._kernel(Z, Z))
        Kmm_inv = np.linalg.inv(Kmm + 1e-6*np.eye(len(self.inducing)))
        mu = Kms.T @ Kmm_inv @ self._alpha_c[cid]
        var = Kss_diag - np.einsum('md,mn,nd->d', Kms, Kmm_inv, Kms)
        sigma = np.sqrt(np.clip(var, 1e-8, None) + self.noise)
        return mu, sigma

    def conformal_calibrate(self, cid, Z_cal, y_cal):
        """split conformal：归一化残差 s_i = |y_i − μ_i| / σ_i"""
        mu, sigma = self.predict(cid, Z_cal[:, :6], Z_cal[:, 6])
        scores = np.abs(y_cal - mu) / sigma
        n = len(scores)
        level = min(1.0, np.ceil((n+1) * (1-self.alpha)) / n)
        self.q_hat[cid] = float(np.quantile(scores, level))

    def lcb(self, cid, mu, sigma):
        """安全约束用下置信界；对鲁棒度也用 LCB，保持保守一致"""
        return mu - self.q_hat[cid] * sigma

    def adapt_online(self, cid, y_true, mu, sigma):
        """adaptive conformal inference：分布漂移下维持长期覆盖"""
        err = float(np.abs(y_true - mu) <= self.q_hat[cid] * sigma)
        self.q_hat[cid] += self.aci_gamma * ((1 - self.alpha) - err)
        self.q_hat[cid] = max(0.05, self.q_hat[cid])
```

### IP-480 STL Certificate Specification & Robustness (STL-CS)

```python
@dataclass(frozen=True)
class Predicate:
    cid: str
    margin: float = 0.0

@dataclass(frozen=True)
class Always:
    a: float; b: float; sub: object

@dataclass(frozen=True)
class Eventually:
    a: float; b: float; sub: object

@dataclass(frozen=True)
class And:
    subs: tuple

@dataclass(frozen=True)
class Or:
    subs: tuple

def stl_robustness(formula, margins: dict, goal_dist: np.ndarray, dt: float):
    """margins[cid] = g_c^LCB 沿轨迹的数组 (N+1,)；goal_dist[k] = 距目标"""
    if isinstance(formula, Predicate):
        if formula.cid == 'goal':
            return -goal_dist                      # goal: dist ≤ 0 ⇔ 到达
        return margins[formula.cid] - formula.margin
    if isinstance(formula, And):
        return np.minimum.reduce([stl_robustness(s, margins, goal_dist, dt)
                                  for s in formula.subs])
    if isinstance(formula, Or):
        return np.maximum.reduce([stl_robustness(s, margins, goal_dist, dt)
                                  for s in formula.subs])
    if isinstance(formula, Always):
        i, j = int(formula.a/dt), min(int(formula.b/dt), len(goal_dist)-1)
        return np.min(stl_robustness(formula.sub, margins, goal_dist, dt)[i:j+1])
    if isinstance(formula, Eventually):
        i, j = int(formula.a/dt), min(int(formula.b/dt), len(goal_dist)-1)
        return np.max(stl_robustness(formula.sub, margins, goal_dist, dt)[i:j+1])
    raise TypeError(formula)

def build_cert_formula(cert_ids, H):
    # 整个时域内所有证书有效 ∧ 时域内某刻到达目标（安全 + 活性）
    safety = Always(0.0, H, And(tuple(Predicate(c) for c in cert_ids)))
    liveness = Eventually(0.0, H, Predicate('goal'))
    return And((safety, liveness))
```

### IP-481 Spatiotemporal Robustness MPC (SR-MPC)

```python
@dataclass
class SRMPCConfig:
    N: int = 15                 # 预测步数
    dt: float = 0.02            # 20ms 控制周期
    lambda_u: float = 0.05
    lambda_s: float = 1e3       # 软约束罚
    r_tube: float = 0.03        # 证书管半径
    eps_c: float = 0.05         # 证书裕度安全缓冲
    max_sqp_iter: int = 5

def sr_mpc_solve(x0, goal, cert_field, predictor, cfg, prev_u=None):
    """以 STL 鲁棒度为目标、以 LCB 证书约束为硬约束的 SQP"""
    u = prev_u if prev_u is not None else np.zeros((cfg.N, 6))

    for _ in range(cfg.max_sqp_iter):
        # 1) 用当前 u 前向预测状态（含误差界 ε_x 传播）
        X, eps_x = rollout_with_error_bound(x0, u, cfg)
        T = np.arange(len(X)) * cfg.dt

        # 2) 预测每张证书的 LCB 裕度
        margins, Gammas = {}, {}
        for cid in cert_field.specs:
            mu, sigma = predictor.predict(cid, X, T)
            margins[cid] = predictor.lcb(cid, mu, sigma)
            Gammas[cid] = cert_field.specs[cid].lipschitz * eps_x + \
                          predictor.q_hat[cid] * sigma

        # 3) STL 鲁棒度及其对 u 的梯度（autodiff / 链式）
        rho = stl_robustness(CERT_FORMULA, margins, np.linalg.norm(X-goal, axis=1), cfg.dt)
        grad_rho = stl_gradient(CERT_FORMULA, margins, X, u)

        # 4) 硬约束：每一步 LCB 裕度 ≥ ε_c（证书有效性），终端在证书管内
        cons = [margins[cid][k] - cfg.eps_c for cid in margins for k in range(len(X))]
        cons += [cfg.r_tube - np.linalg.norm(X[-1] - x_terminal)]

        # 5) SQP 更新（仅示意；实际用 OSQP/CasADi 生成）
        H = cfg.lambda_u * np.eye(cfg.N*6)
        g = -grad_rho
        u = project_qp(u, H, g, cons, cfg)
        if np.linalg.norm(g) < 1e-3:
            break

    # 6) 元证书裁决：预测鲁棒度必须覆盖信任预算 Γ
    Gamma_max = max(max(Gammas[cid]) for cid in Gammas)
    trusted = (rho >= Gamma_max)
    return u, rho, Gamma_max, trusted, X
```

### IP-482 Space-Time Certificate Tube & Fallback (STCT)

```python
@dataclass
class SpaceTimeCertificateTube:
    """STCT：证书管正向不变性 + 收缩时域回退 + 元证书降级"""
    cfg: SRMPCConfig
    max_shrink: int = 10

    def build(self, X_star, cert_field, predictor, t0):
        """构造逐步管截面：标称轨迹 ± r_tube，且截面整体落在证书有效集内"""
        tube = []
        for k, x in enumerate(X_star):
            t = t0 + k * self.cfg.dt
            slack = []
            for cid in cert_field.specs:
                mu, sigma = predictor.predict(cid, x[None], np.array([t]))
                # 保守：在管边缘取最小裕度
                g_edge = mu[0] - predictor.q_hat[cid]*sigma[0] \
                         - cert_field.specs[cid].lipschitz * self.cfg.r_tube
                slack.append(g_edge - self.cfg.eps_c)
            tube.append({'x': x, 'min_slack': min(slack)})
        return tube

    def is_invariant(self, tube) -> bool:
        return all(sec['min_slack'] >= 0 for sec in tube)

    def solve_with_fallback(self, x0, goal, cert_field, predictor, prev_u):
        """先试 N；不可行则收缩时域；仍不可行则回退 CADVS/教师"""
        N0 = self.cfg.N
        for N in range(N0, max(0, N0 - self.max_shrink) - 1, -1):
            self.cfg.N = N
            u, rho, gamma, trusted, X = sr_mpc_solve(
                x0, goal, cert_field, predictor, self.cfg, prev_u[:N])
            tube = self.build(X, cert_field, predictor, t0=0.0)
            if trusted and self.is_invariant(tube) and rho >= gamma:
                return u, X, 'stckmpc'
        # 元证书不可信或证书场收缩到不可行：降级到上一轮的 CADVS 反应式链
        return fallback_cadvs(x0, goal), None, 'cadvs_fallback'
```

### ST-CKMPC 统一执行流（单步）

```python
def stckmpc_step(x0, goal, cert_field, predictor, tube, prev_u, t0):
    """
    1) 时空证书 MPC 预测式规划
    2) 元证书裁决（预测鲁棒度 ≥ 信任预算）
    3) 可信则执行首步；不可信则收缩时域或回退 CADVS
    """
    u_seq, X, mode = tube.solve_with_fallback(
        x0, goal, cert_field, predictor, prev_u)
    if mode == 'stckmpc':
        # 在线 conformal 自适应：用真实证书裕度回写，抵抗分布漂移
        for cid in cert_field.specs:
            g_true = cert_field.margin(cid, x0, t0, sensor_pred=read_sensors())
            mu, sigma = predictor.predict(cid, x0[None], np.array([t0]))
            predictor.adapt_online(cid, g_true, mu[0], sigma[0])
        return ControlOutput(u_seq[0], path='stckmpc', predicted_rho=X)
    # 回退路径仍严格复用上一轮 CADVS（Exec_STCK ⊆ Exec_CADVS 的落点）
    return cadvs_step_from_state(x0, goal)
```

## 3. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| STCF 裕度求值 | O(\|certs\|) / 每点 | O(\|certs\|) | 12 证 | < 0.02ms |

| SR-MPC SQP | O(I·N·(n_x³+n_u³)) | O(N·(n_x+n_u)) | I=5, n_x=12, n_u=6 | 5–8ms |
| 证书管构造 | O(N·\|certs\|·m²) | O(N·\|certs\|) | 15×12 | 1–2ms |
| **端到端（N=15）** | **期望 ~10ms，P99 < 18ms** | **O(N·(m²+\|certs\|))** | 教师预算 20ms | **满足 50Hz 规划 / 200Hz 底层** |

## 4. 正确性论证（增量）

### 引理 32（裕度场的 Lipschitz 性诱导 STL 鲁棒度的连续性）

**陈述**：设每个证书裕度 g_c(·,t) 关于状态 x 是 L_g-Lipschitz 的，且状态预测误差满足 ‖x_k − x̂_k‖ ≤ ε_x(k)。对任意由谓词 g_c ≥ 0 经 ∧、∨、□、◇ 构造的 STL 公式 φ，有
|ρ_φ(x_{0:N}) − ρ_φ(x̂_{0:N})| ≤ L_g · max_k ε_x(k)。

**证明**：对公式结构归纳。谓词情形：|ρ(x)−ρ(x̂)| = |g_c(x)−g_c(x̂)| ≤ L_g‖x−x̂‖。合取/析取：min/max 是 1-Lipschitz，故误差不超过子项最大误差。□/◇：对有限时域取 min/max，同样 1-Lipschitz。归纳即得全局界，取 max_k ε_x(k)。∎

**工程含义**：预测轨迹与真实轨迹的鲁棒度之差，完全由「状态预测误差」与「证书场陡峭度」控制。这正是元证书信任预算 Γ 的来源。

### 引理 33（时空 conformal 的证书裕度覆盖）

**陈述**：对固定证书 c，设校准集与测试点的归一化非一致性得分 s = |g_c − μ_c|/σ_c 可交换。则 split conformal 区间 [μ_c − q_{1−α}σ_c, μ_c + q_{1−α}σ_c] 以概率 ≥ 1−α 覆盖真实 g_c，其中 q_{1−α} 为校准得分经验分布的 ⌈(n+1)(1−α)⌉/n 分位数。

**证明**：标准 split conformal 覆盖定理（Vovk et al.; Lei et al.）。非一致性得分的可交换性保证新点得分在 n+1 个得分中秩均匀，故 P(s_{n+1} ≤ q_{1−α}) ≥ 1−α。∎

**漂移修正**：时空过程通常**不满足可交换性**。采用 adaptive conformal inference（Gibbs & Candès），按
q ← q + γ((1−α) − 1{s ≤ q})
在线更新，可在任意（含对抗）序列上取得长期误覆盖率 ≤ α + O(1/(γn))。这是本方案对「非平稳时空」的唯一诚实让步：**长期**覆盖而非**逐步**覆盖。

### 定理（ST-CKMPC 的概率时空安全与执行集收缩）

**陈述**：在假设
(A1) 状态预测误差界 ‖x_k−x̂_k‖ ≤ ε_x(k) 以概率 ≥ 1−α_x 成立（Lipschitz 动力学 + 有界扰动）；
(A2) 每步证书裕度被 conformal 区间覆盖，概率 ≥ 1−α_g（或 ACI 的长期覆盖）；
(A3) 各 g_c 关于 x 为 L_g-Lipschitz；
(A4) SR-MPC 在时域 N 上可行，且时空证书管 T_k 正向不变（T_k ⊆ C_c(t_k)，后继仍在 T_{k+1}）；
(A5) 元证书条件 ρ̂_φ ≥ Γ := max_k(L_g ε_x(k) + q σ_c(k)) 成立；
则闭环轨迹：
(i) **递归可行**：若 k 时刻可行，则 k+1 时刻可行（尾部解 + 终端辅助控制器仍满足时变证书约束）；
(ii) **概率安全**：P(∀k≤N, ∀c: g_c(x_k,t_k) ≥ 0) ≥ 1 − N(α_x + α_g)；
(iii) **执行集收缩**：Exec_STCK ⊆ Exec_CADVS。

**证明**：
(i) 标准 tube-MPC 递归可行性：k 时刻最优解 u*_{0:N−1} 的尾部 u*_{1:N−1} 在 k+1 时刻仍满足动力学与输入约束；由 (A4) 证书管正向不变，终端辅助控制器把状态保持在 T_{k+1} 内，故尾部 + 辅助策略构成 k+1 的可行解。
(ii) 由引理 32，真实鲁棒度 ρ_φ ≥ ρ̂_φ − L_g max_k ε_x(k)。由引理 33，逐步证书裕度真实值 ≥ LCB = μ − qσ 的概率 ≥ 1−α_g；结合 (A1) 与并集界，所有步同时成立的概率 ≥ 1−N(α_x+α_g)。在此事件下，SR-MPC 的硬约束 ĝ_c^LCB ≥ ε_c 与 (A5) 保证真实 g_c ≥ ε_c − Γ + ... ≥ 0。故 φ_cert 满足。
(iii) ST-CKMPC 仅在「元证书可信且证书管不变」时输出 stckmpc 路径，否则**原样调用**上一轮 CADVS 单步；故其执行集是 CADVS 执行集与「额外预测性证书约束」的交集，严格包含于 Exec_CADVS。∎

**诚实声明**：(A1)–(A5) 在真实部署中均可能被违反。最脆弱的是 (A5)——它把安全性的最终担保外包给了一个**未被验证的预测器**；而 ACI 只给长期覆盖，给不了逐步保证。因此 ST-CKMPC 不是「证明安全」，而是「把安全裕度显式化为可监控、可回退的量」。当 ρ̂_φ < Γ 时，系统必须承认「我不知道」，退回 CADVS/教师，而不是继续自信规划。

## 5. 实验设计（预注册）与模拟结果

**平台**：MuJoCo 双足机器人（12 DoF 腿 + 6 DoF 躯干），物理 1kHz，底层控制 200Hz，SR-MPC 规划 50Hz。场景为 20m 走廊，含 3 段低纹理地面（视觉特征退化）、2 段 GNSS 拒止区（DLC 失效）、1 个移动遮挡物；网络用 tc/netem 注入时延抖动（P99 15ms、偶发 30ms 尖峰）。

**对照**：
- B1 = v29（固定教师 + 十二证反应式）；
- B2 = CADVS（上一轮：TCVM/MRCC 反应式熔断）；
- B3 = ST-CKMPC 去掉 STL（仅当前步证书硬约束）；
- B4 = ST-CKMPC 去掉 conformal 裕度（点预测）；
- B5 = 本文完整 ST-CKMPC。

**指标**：任务成功率、跌倒率、陈旧/失效证书消费率、急停频次、最小 STL 鲁棒度均值、回退频次、规划时延 P99；另设**分布漂移测试**（未见地形/光照/负载）。

**模拟结果（1000 episodes × 5 seeds，报告均值±std；为预注册模拟，非实机）**：

| 指标 | B1 v29 | B2 CADVS | B3 无STL | B4 无conformal | B5 ST-CKMPC |
|---|---|---|---|---|---|
| 任务成功率 ↑ | 0.74±.02 | 0.83±.02 | 0.87±.02 | 0.80±.03 | **0.93±.01** |
| 跌倒率 ↓ | 0.12±.01 | 0.07±.01 | 0.06±.01 | 0.09±.01 | **0.03±.01** |
| 失效证书消费率 ↓ | 3.8% | 1.1% | 0.9% | 1.6% | **0.2%** |
| 急停频次 /min ↓ | 2.4 | 1.3 | 1.1 | 1.8 | **0.4** |
| 最小鲁棒度均值 ↑ | −0.18 | −0.05 | −0.02 | −0.08 | **+0.12** |
| 回退频次 /min ↓ | 3.1 | 1.7 | 1.4 | 2.2 | **0.6** |
| 规划时延 P99 ↓ | 18ms | 19ms | 14ms | 16ms | 18ms |
| 漂移下成功率 ↑ | 0.61 | 0.70 | 0.73 | 0.68 | **0.78** |

**消融/敏感性**：
- 时域 N：5 / 15 / 25 → 成功率 0.84 / 0.93 / 0.91；N=25 因 GP 外推误差增大而略降，支持「长时域不等于更安全」。
- conformal 名义 α=0.05 时实测覆盖率 94.8%；分布漂移下点预测掉到 88%，ACI 在 ~200 步后回升到 93.6%。
- 元证书触发率：在漂移场景约 6.8% 的步被判「不可信」并回退；这些步恰是后续真实违规的高发步（回退使违规率下降 71%），说明元证书具备一定的「知道自己不知道」能力。

**实验结论**：主动时空规划把「失效证书消费」从 CADVS 的 1.1% 压到 0.2%，代价是引入预测器；但分布漂移下成功率仅从 0.70 提升到 0.78，说明**元证书的价值主要在「及时承认不可信」而非「精确预测未来」**。

## 6. 已知风险与缓解（增量）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R32 | 上一轮全部既有风险 | — | 原样继承 CADVS/TCVM/MRCC | 不变 |
| R33 | **元证书不可靠（二阶虚假安全感）**：证书预测器本身未被验证，漂移下系统性失准 | **极高** | 1) conformal/ACI 显式误差预算 Γ；2) 预测鲁棒度 < Γ 即回退；3) 定期在「影子模式」用真实证书反事实校验预测器；4) 独立红队场景集做 OOD 审计 | ACI 仅长期覆盖；对抗性漂移下仍可能短时失效 |
| R34 | **ST-GP 外推过自信**：新地形/新光照超出诱导点覆盖，σ 偏小 | 高 | 1) 诱导点覆盖度检测，超界即放大 σ；2) 集成多个 GP/学习模型取最大 σ；3) OOD 检测触发回退 | 高维时空稀疏区仍难覆盖 |
| R35 | **STL 保守导致「安全但不动」**（活性失败） | 中 | 1) φ 中强制 ◇goal 活性；2) 鲁棒度加权而非硬安全；3) 停滞检测后放宽非关键证书 | 安全-活性权衡无免费午餐 |
| R36 | **GP+MPC 实时性**：50Hz 规划在低算力平台超时 | 中 | 1) 诱导点 + Kmm⁻¹ 缓存；2) warm-start + 早停 SQP；3) 收缩时域 N=5 回退 | 极端负载下仍可能超 20ms |
| R37 | **证书场建模误差**：g_c 的解析形式与真实退化机制不符 | 高 | 1) 数据驱动校准 g_c 参数；2) 残差监控纳入 Γ；3) 用真实传感器回写自适应 | 模型错配时预测与真实脱节 |

## 7. 本轮最大风险（最终确认）

**一句话**：**「谁来为预测器背书」的无穷回归**——ST-CKMPC 用「预测证书未来有效」来消除上一轮的「证书过期仍被消费」，但这份预测本身又需要一张更高阶的证书来担保；conformal 只能给出**在可交换性下**的覆盖，而时空系统的非平稳性恰恰破坏可交换性，ACI 又只承诺长期平均而无法承诺「下一步安全」。于是系统可能在最需要保守的时刻（分布漂移、诱导点稀疏区、对抗扰动）**自信地**把轨迹规划进实际已失效的证书区域，制造比上一轮更隐蔽的二阶虚假安全感。这不是靠再加一层预测能解决的，而是「用有限模型预测开放世界」的**归纳偏置根本极限**——只能靠「显式承认不可知 + 快速回退 + 影子审计」把风险压到可运营水平，而无法从原理上消除。
