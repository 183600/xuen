## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（传感器融合 → 你最缺的力传感器，可以从已有通道里「免费」解出来）**
直觉：赛题没有力/触觉通道（F8/F20），但每个控制周期同时下发「目标」并回传「实测」。在位置伺服下，外部接触会把实测位置从目标位置推开——**目标与实测之差，本质上就是外部力经过控制器柔顺度后的投影**。除以等效刚度，就得到虚拟力；再叠加「夹爪指令开度 vs 实测开度」的残差和腕部相机里「物体 vs 夹爪」的相对运动，就得到一个零硬件、零额外带宽的虚拟力觉/滑移检测器。反直觉点：**误差通常被当作要被消除的噪声，这里被重新解释成唯一的力传感信号——大多数队伍会把它当控制误差扔掉，这正是不对称机会。** 同时，四路相机（2 全局 + 2 腕部）与 joint/ee 双表示提供了冗余：正运动学可交叉校验末端位姿，多视角可交叉校验物体运动——融合不只是「多加一路」，而是「用冗余互相证伪」。

**灵感 2（低成本方案 → 不是「便宜地做同样的事」，而是「让昂贵模块大部分时间不运行」）**
直觉：第 2 轮把 I7 世界模型前瞻列为高成本缓行项，I5 的 WMA 合成也贵。低成本的正确姿势不是砍功能，而是**分级触发**：用上面几乎免费的虚拟传感器做「哨兵」，平时只走单次前向（落在 15Hz/≈66ms 预算内），只有检测到接触异常、滑移或卡滞时才升级到重规划、恢复原语，必要时才动用世界模型短 rollout。计算花在信息增益最高的时刻。反直觉点：**最省算力的方法不是把模型做小，而是让昂贵推理「大部分时间不运行」。** 这与 I4 的自适应 chunk、I8 的分级消融天然同构——都是「按需付费」。

**两者统一**：传感器融合回答「用什么信号判断危险」，低成本方案回答「判断出危险后花多少算力」。合起来是一条**「廉价感知 → 分级计算」的运行时经济学**：把被浪费的控制残差变成感知，把感知结果变成算力调度。第 2 轮结论是「数据决定上限」；本轮补上另一半——**运行时经济性决定把上限兑现多少**。

## 2. 对第 2 轮痛点的增量修订

- P4（无触觉）：从「只能靠视觉/关键点缓解」升级为「可低成本合成虚拟力觉」；但可辨识性受控制器刚度限制（产物区 §1.4 玩具验证：k=5000 N/m 时 2N 接触只剩 0.4mm 残差），必须与视觉滑移互补，不能单独承重。
- P5（时间压力）：虚拟力觉提供「早期失败检测」→ 早停早重试，把有限时间预算从「在错误轨迹上耗尽」转为「多一次重试」，直接服务步骤分。
- P6（部署预算）：4 相机全开可能压垮带宽/延迟；本轮把 obs 子集、分辨率、堆叠长度列为显式预算变量（F21），并给出低成本默认配置。
- P7（先手窗口）：虚拟力觉是零硬件先手；在 Base 月下载仅 252（F19）的社区密度下，更容易形成差异化。
- 新增 P9（虚拟传感可辨识性）：残差 ≈ 接触力/刚度 + 速度滞后 + 噪声；刚度未知且随控制器/负载变化，必须辨识自由空间残差模型（优先离线/接触探针标定，推理期冻结，避免触碰「在线适应」红线），否则误报。
- 新增 P10（信号自证）：没有真值力标签，虚拟力只能靠「视觉滑移 + 任务成败」间接验证；存在自指偏差与标签噪声自我强化的风险。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

- **Q9（虚拟力可辨识性）**：在仅有 joint/ee 目标与实测、无电流/力矩的条件下，「指令-观测残差 + 夹爪残差 + 腕部视觉滑移」能在多大刚度、速度、延迟范围内可靠区分 free/contact/slip/stuck？误报-漏报曲线与可辨识下界是什么？
- **Q10（最低成本融合子集）**：4 相机 + 本体 + 语言中，哪一最小子集（含分辨率、帧率、历史长度）达到检测目标？如何用 `obs_delta_indices`/`image_resize` 把带宽预算优先分配给接触段最需要的腕部相机？
- **Q11（辅助信号的价值与泄漏）**：接触相位/滑移标签作为训练期辅助监督与数据筛选（I2/I5），能否在零推理成本下提升成功率与步骤分？如何避免虚拟标签误差自我强化？

## 4. 设计原则（新增 PR6–PR7，PR1–PR5 保留）

- **PR6 虚拟传感律**：缺失的传感通道优先用「已有通道 + 物理先验」合成；合成信号默认只作**软门控/训练期辅助**，禁止直接硬接管动作；进入控制回路前必须在 I8 注册表里验证其与真实事件/任务结果的相关性。
- **PR7 报警预算律**：昂贵推理（重规划、世界模型、多候选）只在廉价哨兵报警时触发；每任务维护「报警→升级」的算力预算，升级路径必须能在 p99 内降级回退，回退时保持动作连续。
- PR1–PR5 保留（第 1/2 轮 §4）。

## 6. 本轮最大风险

**一句话**：虚拟力觉的核心假设「指令-观测残差 ∝ 接触力」在真实位置控制器上会被速度滞后、刚度变化与通信延迟严重污染（产物区玩具验证：自由运动残差 RMS 4.4mm，远大于 2N 接触在 k=1000 时的 2mm 信号）；若自由空间模型辨识不准，哨兵会频繁误报，触发无谓恢复反而拉低成功率——这是必须先过「接触探针 L1」、并用视觉滑移双通道证伪的点。

# UniBot-V1 参赛创新点清单（第 3 轮 v1.2）

> 检索日期：2026-11-26（第 1 轮）、2026-11-27（第 2/3 轮）；来源见 §5。承接 v1.1：新增 I10/I11，深化 I2/I3/I4/I5/I6/I8/I9，I1 维持、I7 并入 I11。清单只增改不重置。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I1 v2 考纲校准五轴增广引擎 ★★★★★（维持，微增）
- 六要素同第 2 轮：按官方考纲卡采样增广，把零样本泛化转成分布内泛化。
- 本轮微增：多视角一致性（I10 的副产品）可作为外观/背景轴的**低成本质检**——若增广后的多视角几何不自洽，则该样本不进训练集，替代部分人工抽检。
- 风险维持：考纲卡偏差；位置重拼接物理不可行（L0「不可行动作占比 >5% 即降级」判据不变）。

### I2 v3 数据引擎 3.0：孪生迁移 + 物理一致性筛选 ★★★★★
- **动机**：第 2 轮的质量分（进度效率/平滑度/成功裕度）仍是手工启发式；遥操作数据可能存在「动作与实测运动不一致」（掉帧、遥操作延迟、标定漂移），这类样本教给策略的是错误的因果。
- **本轮深化（传感器融合 → 数据侧）**：新增**物理一致性分** `q_phys`（§1.5）——用「动作-本体残差 + 夹爪相位 + 视觉运动」三项互相校验：
  1. 自由空间段：`|r_t - r_free|` 应小；大残差说明动作与执行不同步。
  2. 接触段：夹爪闭合指令与实测开度变化应符合物体厚度/滑移物理。
  3. 视觉段：动作导致的物体位移方向应与腕部/全局视觉流一致；不一致则降权。
- **与现有方案差异**：别人按「成功/失败」或人工看视频筛数据；本点用零标注的物理一致性做 per-episode / per-segment 加权，且与 I10 共用同一套残差计算，边际成本近零。
- **技术可行性**：高（纯离线，CPU 可跑；有 GPU 时并行）。
- **所需资源**：1 GPU 日全量扫描；无需新数据。
- **落地步骤**：①在 110 语料 + 32 任务上抽 2% 做一致性分布；②定阈值（保留率目标 85–90%）；③与第 2 轮质量分加权融合；④L0 验证「筛后训练 vs 筛前」的留出集 Δprog；⑤负迁移家族仍按 v2 的 L0 止损。
- **风险**：把「合法的柔顺/接触变形」误判为不一致 → 误剪真数据（缓解：只在自由空间段做强判定，接触段只做弱降权；人工抽检 5%）。

### I3 v3 接触任务族关键点视觉伺服回退 ★★★★（↑）
- 六要素同 v1.0/v2；**本轮升级触发机制**：不再由固定阶段或纯视觉接近度触发，而由 I10 的虚拟力觉给出**接触起点**（`c_t` 越阈 + 夹爪近物），视觉伺服只在接触段启用——接近段仍走通用 chunk，减少伺服误触发与算力。
- 本轮补充：腕部相机（`cam_*_wrist`）提供接触段近景，关键点检测在接触段用腕部 ROI，精度高于全局相机。
- 降级预案 I3' 不变：若混合推理被判违规，改为训练时辅助监督（伺服关键点作辅助标签），推理纯端到端。
- 风险：虚拟力在硬控制器下灵敏度不足（§1.4）→ 触发以「虚拟力 OR 腕部视觉接近」双通道，任一满足即进入接触段。

### I4 v3 人手干预感知门控 + 自适应 chunk ★★★★（↑）
- 六要素同 v1.0/v2；**本轮升级**：人手检测之外增加**非预期接触判别**——若 I10 报告 contact/slip，但全局相机未见人手、且当前任务阶段不应有接触，则进入「外部扰动」状态：停持 → 重估 → 续做（PR3）。这覆盖了「人没有入镜但碰了机器人/物体」的盲区。
- chunk 策略：干预/异常态短 chunk（4–6 步），稳定态 8–16 步（沿用 F12 参照）。
- 风险：人手检测与虚拟力同时误报 → 双重确认 + 短时迟滞，避免抖动。

### I5 v3 非标称示教合成 + 得分点对齐恢复 ★★★★★（↑）
- 动机同 v2：数据集全成功、无失败示教（P8）；恢复能力只能靠合成「偏离→修正」。
- **本轮深化（低成本替代重合成）**：
  1. **虚拟力自动标注**：用 I10 的 contact/slip/stuck 状态给成功 eps 打相位标签；「偏离」= slip/contact-loss 起点，「修正」= 残差回到标称 + 物体重新进入夹爪视野。
  2. **门禁自动化**：只有「偏离被检出、修正后物理一致性恢复」的合成段才保留——替代 v2 中较贵的 WMA 续写 + 人工抽检。
  3. **WMA 降级为后备**：仅当扰动重放/跨段缝合无法覆盖某类偏离时，才用 WMA 生成；I7 的资产继续服务此路径。
- 与现有方案差异：v2 用「达成下一得分点」做门禁（需要逆向得分点、检测器有误差）；v3 增加一条不依赖得分点的物理门禁，二者取交集更稳。
- 技术可行性：中-高（扰动重放 + 虚拟力标注是纯数据工程；WMA 可选）。
- 所需资源：1×24GB GPU；数据工程 1–2 人周。
- 落地步骤：①在 3 个接触弱任务（PlugCharger/ZipUp/PourOutMedicine）跑通虚拟力相位标注；②生成「偏离→修正」段；③物理门禁过滤；④LoRA 增量；⑤单任务通道 A/B（恢复成功率、步骤分、误触发率）。
- 风险：虚拟力标签本身有误（P10）→ 与视觉滑移/得分点检测取交集；合成偏离分布与考纲不符 → 扰动幅度从 I1 考纲卡采样。

### I6 v3 确定性低延迟部署服务 ★★★★（↑）
- 六要素同 v1.0/v2；**本轮新增「带宽预算」**（F21）：`obs_delta_indices` 决定发什么、`image_resize` 决定多大。
  - 默认低成本配置（待 A/B）：全局相机 240×320、腕部相机 160×120；图像只取当前帧 `[0]`，本体取 `[-4,-2,0]` 历史栈。
  - 粗算：全分辨率 4 相机 480×640×3 ≈ 3.69MB/帧，15Hz ≈ 55MB/s/机器人；上述配置约 0.58MB/帧 ≈ 8.7MB/s/机器人（约 6× 降）。腕部保持低分辨率只服务滑移检测，VLA 主输入用全局相机；若 VLA 需要腕部，再单独加一路中等分辨率并重测 p99。
  - 端口级状态隔离 + 共享 backend（F24）：每端口独立 `reset`/历史/预算计数器，禁止跨 episode 共享。
- 本轮修正：分级推理（I11）默认只走一次前向；接触/滑移态才增加光流与恢复，p99 目标仍 <40ms。
- 风险：降分辨率伤 VLA 精度 → L0/L2 消融选配置，不盲目省带宽。

### I7 v1 世界模型测试时前瞻 ★（缓，并入 I11）
- 不再常驻：WMA-0 短 rollout 只作为 I11 的**最高级升级路径**（连续 slip/stuck 且廉价恢复失败时触发，O(1) 次）。
- 修剪判据：若第 3 轮基线在 15Hz 下 p99 余量 <10ms，则彻底移出推理路径，资产只服务 I5 后备。
- 保留理由：极端卡滞（插头对不准、物体卡死）时，短前瞻仍可能比盲试省时间；但默认不付费。

### I8 v3 评测运营闭环 + 分级消融注册表 ★★★★（↑）
- 动机同 v2：真机预算稀缺、组合爆炸。
- **本轮深化（传感器融合 → 消融）**：
  1. **传感器消融**：对 I10 做 leave-one-modality-out（去腕部视觉 / 去 ee 残差 / 去夹爪残差 / 去 joint 残差 / 只留全局相机），量化每路对 contact/slip 检测的边际贡献，直接回答 Q10「最小子集」。
  2. **虚拟传感器代理入注册表**：`Δcontact_acc`、`Δslip_f1`、`Δresidual_sep` 作为 L0 代理，与真机 Δsuccess/Δstep 做滚动 Spearman；相关性 >0.6 才允许单独准入 L2（PR6 门禁）。
  3. **报警经济性指标**：每 episode 的升级次数、误升级率、升级带来的成功率增量/算力增量（ROI），纳入 L1 决策。
- 技术可行性：高（离线）。
- 所需资源：代理实现 1 人周；注册表 = 表格 + 脚本。
- 落地步骤：①代理指标；②传感器消融矩阵；③首个真实用例 = I10 接触探针 + I2 物理筛选；④滚动复盘相关性。
- 风险：代理与真机相关性建立慢 → 先用接触探针的已知事件回填对齐点。

### I9 v3 reset 期检索类比迁移 ★★★★（↑）
- 六要素同 v2；**本轮升级**：
  1. 检索表示加入**腕部近景**（接触前最后一段）与**多视角一致性特征**，缓解 VLM 嵌入对「同类不同外观」不敏感。
  2. 检索目标从「物体→动作参数」扩展为「物体→动作参数 + 接触相位先验」（由 I10 标注），使检索结果能直接给 I3/I5 用。
  3. 止损：多视角一致性低于阈值或检索距离超阈 → 退回无先验（沿用 v2 软偏置 + 阈值门控）。
- 资源：嵌入 1 GPU 日 + FAISS；1 人周。
- 风险：误检索、合规确认（reset 期一次性检索 + episode 内缓存）不变。

### I10 v1 虚拟力觉融合（Virtual Force Sensing, VFS）★★★★★（新）
- **动机**：赛题无力/触觉通道（F8/F20），但 6–8 个接触任务（PlugCharger、PlugInEthernet、SyringeWaterTransfer、Unlock、ZipUp、PourOutMedicine、PickOutBatteries、ToolboxStorage）的成败高度依赖接触/滑移感知；I3/I5 都缺一个「现在是否接触/打滑/卡住」的信号。
- **与现有方案差异**：别人要么纯视觉（接触瞬间被遮挡、力信息缺失），要么加硬件（违规/昂贵）；本点把**位置伺服的控制残差**重新解释为力代理，融合夹爪开度残差与腕部视觉滑移，**零硬件、零额外带宽**。默认用解析规则 + 迟滞（无独立网络，规避 PR2 单模型边界）；可选把融合头作为同一模型的辅助头联合训练。
- **技术可行性**：中-高。信号齐全（F20/F22）：`ee` 控制可直接用 `action.ee_pose - obs.ee_pose`；`joint` 控制可经 FK 转任务空间；夹爪有指令/实测；腕部有近景。主要未知是控制器刚度/延迟（P9），用接触探针标定。
- **所需资源**：0 新硬件；推理 <3ms/步（光流仅在接触态算）；1 人周；可选普通电子秤（约几十元）做已知力标定；1 GPU 日（可选学习融合头）。
- **落地步骤**：①记录自由空间 action-obs 对，拟合 `r_free` 与延迟 τ*；②定义 contact/slip/stuck 分数（§1.1–1.2）；③接触探针采集已知事件（§2）；④定阈值 + 多帧投票 + 迟滞；⑤作为软哨兵接入 I3/I4/I5/I11；⑥L1 在 2–3 个接触任务 A/B；⑦L2 再上计分通道。
- **风险**：残差被速度滞后主导 → 自由空间模型；硬控制器下力信号弱 → 视觉滑移补位；遮挡/反光导致光流失效 → 多视角 + 夹爪残差；误报触发无谓恢复 → 保守阈值 + 软门控 + 预算上限；episode 内更新参数可能被视作在线适应 → 默认冻结模型，更新仅离线（合规确认项）。

### I11 v1 报警触发分级计算（Alert-Triggered Compute, ATC）★★★★（新）
- **动机**：I7 世界模型、I5 重合成、多候选重规划都贵；真机单步预算 ≈66ms（15Hz 参照，F12），不能常驻。
- **与现有方案差异**：常驻大模型/常开多候选 vs **按危险等级付费**：平时单次前向，哨兵报警才升级，且升级路径有预算上限与 p99 降级回退。
- **升级阶梯（默认）**：
  - L0 基础：一次 VLA 前向 + 规则 guard（零额外）。
  - L1 接触：I10 报 contact → 启用 I3 关键点伺服（+2–3ms）。
  - L2 异常：报 slip/stuck → 早停当前 chunk，调用 I5 恢复（重抓/重接近）。
  - L3 极端：连续失败且 L2 无效 → 可选 WMA 短 rollout（I7），仅当预算与延迟允许。
- **技术可行性**：高（调度逻辑 + 计数器）。
- **所需资源**：1 人周；无新模型。
- **落地步骤**：①定义每任务报警→升级映射与预算上限；②实现降级回退（超预算/超时 → 安全停持或保守重试）；③记录升级 ROI；④L1 消融「常驻 vs 按需」的算力/成功率；⑤L2 验证。
- **风险**：报警延迟导致升级过晚；频繁升级抖动；恢复动作比原轨迹更差 → 预算 + 迟滞 + 只在高置信时升级 + 失败即回退。

## 1. 关键推导与伪代码

### 1.1 虚拟力扰动观测器（VFS 核心）

位置伺服下，任务空间近似满足

```
x_obs(t) ≈ x_cmd(t-τ) + K^{-1} w_ext(t) + lag(ẋ_cmd) + ε
```

其中 `w_ext` 是外部接触力/力矩，`K` 是等效刚度，`lag` 是速度相关的跟踪滞后，`ε` 是噪声。于是定义残差与自由空间模型：

```python
# 每台机器人、每个控制空间（ee 或 joint+FK）各一套
r_t      = x_target(t - tau_star) - x_obs(t)          # 指令-实测残差
r_free_t = A @ [xdot_cmd, xddot_cmd, gripper_cmd, 1]  # 自由空间残差模型（岭回归）
c_t      = || r_t - r_free_t || / sigma_free          # 归一化接触分数
w_hat_t  = K_hat * (r_t - r_free_t)                    # 可选：虚拟力（需标定 K）
```

- `tau_star ∈ {1,2,3}`：用自由空间段搜索使残差方差最小的延迟。
- `A` 的拟合只用**明确自由**的段（夹爪张开、目标物不在夹爪附近、无接触事件）；默认离线拟合后冻结，推理期不更新（合规）。
- `K_hat` 可选：用普通电子秤施加已知力做接触探针标定，或直接用 `c_t`（无需 K）。
- `joint` 控制时，`x_obs` 由 `observation.state.*_arm` 经 FK 得到；同时可与 `observation.state.*_ee_pose_gripper_base` 交叉校验（F23），偏差大则标记传感器异常。

### 1.2 夹爪滑移与多视角融合

```python
g_res  = g_cmd - g_obs                          # 夹爪指令-实测残差
# 腕部 ROI 光流/特征跟踪（只在 contact 态计算）
f_obj, f_grip = optical_flow(wrist, obj_roi), optical_flow(wrist, grip_roi)
s_t = || f_obj - f_grip || / scale              # 视觉滑移分数

state = HMM/threshold(state_prev, c_t, g_res, s_t, dg_obs)
# 迟滞 + 多帧投票：
#   free    -> contact : c_t > θ_c 连续 n_c 帧
#   contact -> slip    : s_t > θ_s 连续 n_s 帧 或 (g_res > θ_g 且 dg_obs/dt > 0)
#   any     -> stuck   : c_t > θ_c 且 ||ẋ_obs|| < ε 连续 n_k 帧
#   slip    -> contact : s_t 回落且 g_obs 稳定
```

多视角一致性：用全局相机与腕部相机的特征匹配/对极误差做交叉校验；在 reset 与接触起点各算一次，用于（a）传感器健康检查，（b）I9 检索置信度门控，（c）I1 增广质检。全程解析规则，无独立网络。

### 1.3 报警触发分级计算

```python
def get_action(self, obs):
    chunk = self.vla.propose_chunk(obs)                 # L0：一次前向
    st = self.vfs.update(obs, self.last_action)         # <3ms
    if st == FREE:
        return self.guard(chunk)
    if st == CONTACT:
        return self.contact_servo(chunk, obs)           # L1：I3
    if st in (SLIP, STUCK):
        if self.budget.take("recovery"):
            return self.recovery(obs)                   # L2：I5
        return self.safe_hold(chunk)                    # 预算耗尽：安全回退
    if st == REPEAT_FAIL and self.budget.take("wm") and self.latency_ok():
        return self.wm_foresight(obs)                   # L3：I7（可选）
    return self.guard(chunk)
```

预算与回退：每 episode 限制恢复次数与 WMA 次数；升级路径若预计超 p99，直接走低一级；所有分支返回前过动作健康度门禁（界内/平滑/统计正常）。

### 1.4 玩具验证（1-DOF 弹簧-质量-阻尼，非真机）

模型：`m x'' = -k(x - x_cmd) - b x' + F_ext`，`m=1, b=25`，观测噪声 `σ=0.2mm`，采样 15Hz。目的是验证「残差 ∝ 力」的数学与主要污染项，不是替代真机。

**A. 稳态残差 = -F/k（mm）**

| k (N/m) | F=1N | F=2N | F=5N | F=10N |
|---:|---:|---:|---:|---:|
| 200 | -4.90 | -10.08 | -24.99 | -49.92 |
| 500 | -1.98 | -3.96 | -9.98 | -19.88 |
| 1000 | -1.00 | -1.99 | -5.11 | -9.93 |
| 2000 | -0.43 | -1.00 | -2.31 | -5.00 |
| 5000 | -0.19 | -0.39 | -0.79 | -2.01 |

**B. 运动自由空间（无接触）**：正弦指令下 `corr(e, v)=0.986`，原始残差 RMS=4.38mm；拟合 `e ≈ a·v + c` 后 RMS=0.67mm（降 6.5×），`a=21.35 mm/(m/s)`。→ **速度滞后是主要污染，必须建自由空间模型。**

**C. 运动中加 F=2N（k=1000，阈值 0.6mm）**：接触前 `mean|res|=0.28mm`、`p99=0.64mm`；接触后 `mean|res|=1.40mm`；单帧检测率 84.2%，误报率 9.1%。→ **需多帧投票 + 迟滞 + 双通道才能压误报。**

**D. 可辨识下界（F=2N）**

| k (N/m) | 残差 (mm) | 相对 0.2mm 噪声的 SNR |
|---:|---:|---:|
| 200 | 10.00 | 50.0 |
| 1000 | 2.00 | 10.0 |
| 5000 | 0.40 | 2.0 |
| 10000 | 0.20 | 1.0 |

**结论**：①静态下残差严格等于 `F/k`，可标定；②运动滞后必须建模；③硬控制器（k≥5000）会藏住小力，必须用腕部视觉滑移补位；④单帧阈值不够，用多帧 + 迟滞；⑤以上是玩具数字，真机必须做 §2 的接触探针。

### 1.5 物理一致性数据筛选（I2 v3）

```python
def q_phys(ep):
    # 只在明确自由/明确接触的段分别判定，避免把柔顺变形误判
    free_ok = mean( sigmoid((theta_f - |r_t - r_free_t|) / sigma_f) for t in free_segs )
    phase_ok = mean( gripper_phase_consistent(g_cmd, g_obs, contact_state) )
    vis_ok  = mean( direction_agree(action_delta, visual_flow) )
    return free_ok * phase_ok * vis_ok          # 0..1

# 与第 2 轮质量分融合：
w_ep = (0.2 + 0.8 * q_quality) * (0.5 + 0.5 * q_phys)
# 只对最低分位做裁剪（默认剪最差 10%），避免误剪
```

**2.1 接触探针（低成本真机标定，关键新增）**

用 30–60 分钟采集短片段并打事件标签：
1. **自由**：夹爪张开，在工作空间慢/中/快三档移动（拟合 `r_free` 与延迟）。
2. **已知接触**：夹爪闭合并轻压桌面/电子秤（用电子秤读已知力，可选标定 `K`）。
3. **抓取**：夹爪闭合抓住不同厚度物体后抬升（夹爪残差与成功/失败）。
4. **滑移**：抓住后轻拉/侧推，使物体相对夹爪移动（视觉滑移正样本）。
5. **卡滞**：顶住不可动障碍继续发指令（stuck 正样本）。

每类 10–20 段，共约 50–100 段；据此定 `θ_c/θ_s/θ_g`、多帧窗口、迟滞。探针只用自有机器人，不接触评测集。

**2.2 消融矩阵（L1）**

| 配置 | 腕部视觉 | ee/joint 残差 | 夹爪残差 | ATC | 关注指标 |
|---|---|---|---|---|---|
| A0 | - | - | - | - | 基线 |
| A1 | - | ✓ | - | - | 力残差单独 |
| A2 | ✓ | - | - | - | 视觉滑移单独 |
| A3 | ✓ | ✓ | - | - | 力+视觉 |
| A4 | ✓ | ✓ | ✓ | - | 全融合 |
| A5 | ✓ | ✓ | ✓ | ✓ | 全融合+分级计算 |

判据：A4 vs A3 看夹爪残差边际；A5 vs A4 看 ATC 的成功率/算力 ROI；所有配置在非接触任务上不得退步。

## 6. 本轮最值得押注（一句话）

**押 I10 虚拟力觉 + I11 报警预算：用零硬件的「指令-观测残差 + 夹爪残差 + 腕部滑移」做接触/滑移哨兵，只在报警时升级算力——它同时服务成功率（早停重试）、步骤分（接触任务）与部署成本（大部分时间单次前向），是第 2 轮数据引擎之外唯一不增加硬件的乘性收益。**

## 7. 本轮最大风险

**一句话**：虚拟力觉的最大风险是残差被控制器速度滞后主导（玩具仿真自由运动残差 4.4mm，大于 2N 接触在 k=1000 时的 2mm 信号），自由空间模型辨识一旦不准，哨兵误报触发的恢复会比不恢复更伤——必须先过接触探针 L1、并用腕部视觉滑移双通道证伪，再上计分通道。
