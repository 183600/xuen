# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；灵感循环第 8 轮；本轮灵感：「本体感知」×「动力学」）

> 第 61 轮构建了「语义先行」的 ESEC：USR 把场景/意图/阻抗/证据映射到共享表征空间、MEL 做零样本物理属性推断、DMS 做执行接地多轮对话、SRT-Dual 用双流解耦大模型时序、PCE+++++ 兜底六维预算。但**四个新暴露的盲点**都指向同一个被忽略的对象——**机器人自己的身体**：
> 1. **身体模型缺失（Body-Model Blindness）**：`Enc_p` 只把本体感受压成一个特征向量并入 MEL，**没有显式刚体动力学模型**。φ_phys 描述的是环境（摩擦/刚度/脆性），但机器人自身的质量矩阵 M(q)、科氏项 C(q,q̇)、重力 G(q)、关节摩擦、执行器带宽、力传感零偏都未建模——**环境先验再准，身体模型错了照样失控**。
> 2. **变阻抗稳定性未证（Variable-Impedance Stability Gap）**：EEIS 每周期输出 K_safe，K_p(t)/K_d(t) 时变，叠加 1~10kHz 采样抖动、接触切换与语义锚点延迟，会像参数泵一样向接触环**注入能量**。第 61 轮只有投影误差 e_proj 与语义一致性 C_sem，**这是表征层指标，不是能量层稳定性证明**。
> 3. **本体感知未被用作独立快回路（Proprioception Underused）**：本体感受（q, q̇, τ, F_ext）是唯一**直接、低延迟**观测交互的模态，却只被当作 MEL 的一路输入，**没有形成「本体感知→在线辨识→阻抗先验校正」的毫秒级回路**。
> 4. **语义锚点与身体状态解耦（Anchor-Body Disagreement）**：第 61 轮 Anchor 只含 scene/intent/phys_prior/version，**不含构型、速度、接触态、能量状态**。可能出现「语义说轻触、身体却在高速运动」的矛盾，安全约束必须依赖**语义 × 动力学的联合可行域**。

## 0. 直觉与动机

**灵感 1（本体感知 → 本体动力学残差流 PRS）**
直觉：人不需要"看懂"地面也知道自己快滑倒了——**本体感受是最早的报警器**。第 61 轮的 `Enc_p` 把本体感受当成给大模型的"又一路特征"，浪费了它最宝贵的东西：**毫秒级、可解释、物理可核算的动力学残差**。构建 **本体动力学残差流 PRS (Proprioceptive Residual Stream)**：用广义动量观测器（不依赖二次微分 q̈，抗噪）实时估计外部力矩 r_ext，并计算名义动力学残差 r_dyn = τ_meas − (M̂q̈ + Ĉq̇ + Ĝ + τ̂_f)。**关键洞见：r_dyn 是「身体-世界不一致」的物理量纲信号**——残差阶跃=碰撞/负载突变，残差振荡=接触不稳，残差缓漂=摩擦/磨损/零偏漂移，残差方向沿接触切向=滑移前兆。它比视觉早 30~100ms，比语言早一个数量级。

**灵感 2（动力学 → 动力学-无源阻抗整形 DIPS）**
直觉：阻抗控制就是"虚拟弹簧-阻尼"，而**把弹簧突然放松/拉紧，等于往系统里灌/抽能量**；再叠加延迟，就可能自激振荡。构建 **动力学-无源阻抗整形 DIPS (Dynamics-Informed Passivity Shaping)**：在 port-Hamiltonian / 能量 tank 框架下，把 K_safe(t) 的时变轨迹约束为满足**无源性**——系统从环境净吸收的能量不超过耗散，能量 tank T_e(t) ≥ 0 恒成立。**关键洞见：给实时流加一个「能量层安全证书」，它比表征层的 e_proj 更接近失稳的物理本质**；当 tank 逼近下限时，自动注入虚拟阻尼 D_virt 并限幅刚度的下降速率 |K̇_p| ≤ γ_pass。

**灵感 3（本体感知 × 语义 → 本体-语义联合锚点 PU-Anchor）**
直觉：同一个「轻点一下」的意图，在手臂高速运动时和静止时应该给出**不同的阻抗**——"量力而行"。构建 **本体-语义联合锚点 PU-Anchor**：Anchor_t 扩展为 (scene_emb, intent_emb, phys_prior, **body_state, θ̂_cov, r_dyn_feat, contact_state, T_e**, version, ts)；投影头升级为**条件投影** Π(· | q, q̇)：同一语义融合向量在不同身体状态下投影出不同 K_prior（高速⇒更软更阻尼）。**关键洞见：让本体状态直接调制语义先验，把"语义忠实"升级为"语义忠实且物理可实现"**。

**灵感 4（动力学残差 → 事件触发的语义-动力学问询 DDA）**
直觉：残差突增是"身体在报警"，但**报警的原因需要解释**——是环境变了、还是自己坏了、还是任务意图本身矛盾？构建 **动力学驱动仲裁 DDA (Dynamics-Driven Arbitration)**：把残差模式 ψ_dyn 分类为 {steady, step_load, oscillation, slip_precursor, friction_drift, collision}，据此触发**定向**动作：重辨识、定向 MEL 重推理（带 query 而非泛泛重算）、提议对话、保守收缩、继续。**关键洞见：本体感知提供可解释的因果证据，使 DMS 能说"我感觉到抓取在缓慢滑动，可能摩擦估计偏高"，而不是只会说"环境不确定"**。

**灵感 5（身体-环境解耦 BED + 三层闭环 PDEC）**
直觉：残差是"身体误差 + 环境误差"的叠加，**不能把所有异常都甩锅给环境**。构建 **身体-环境解耦辨识 BED**：r_dyn = Y(q,q̇,q̈)Δθ_body + JᵀΔF_ext，在激励充分（组合回归矩阵列满秩）时联合求解，列秩不足时冻结对应分量（避免病态）。再把一切合流为 **PDEC (Proprioception-Dynamics Embodied Consistency Loop)** 三层闭环：快层 1kHz（PRS+ODD+DIPS 保身体稳定）、中层 100~500Hz（DDA 仲裁）、慢层 10~100Hz（MEL+DMS+USR 保语义正确）。

**灵感 6（八维预算 PCE++++++ + 零样本动力学自适应 ZSDA + 本体叙事 PSN）**
直觉：在线辨识需要"激励"（会消耗能量与扰动）、无源整形需要"裕度"（会牺牲跟踪性能），二者都应进入预算。把六维预算扩展为**八维 B_cog7 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_body, B_stab)**：B_body = (激励能量, 辨识频率, 遗忘因子, 参数协方差容忍)；B_stab = (能量 tank 下限, 无源裕度, 延迟预算, 阻尼注入预算)。VOI 增加「动力学激励信息增益」。同时 **ZSDA** 用 θ̂ + r_dyn 在线自适应未见负载/材质，**PSN** 把残差事件翻译成自然语言证据注入 DMS。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（本体感受流与动力学残差 PRS）** 本体感受观测与残差引擎：
- **观测**：o_p(t) = (q, q̇, τ_meas, F_ext^meas, contact_flag, imu) ∈ ℝ^{n_p}（**不显式使用 q̈**，避免二次微分噪声）
- **广义动量**：p(t) = M̂(q) q̇
- **动量观测器残差**（De Luca 型，抗噪）：
  ```
  r(t) = K_O · [ p(t) − ∫₀ᵗ ( τ_meas + Ĉᵀ(q,q̇)q̇ − Ĝ(q) + r(s) − τ̂_f(q̇) ) ds ]
  ```
  理想情形 r(t) → Jᵀ(q) F_ext(t)（外部力矩的滤波估计），K_O ≻ 0 为观测器增益
- **残差特征**：ψ_dyn = (‖r‖, d‖r‖/dt, 主频 f_peak, 自相关衰减 τ_ac, 沿接触切向分量 r_∥, 沿法向分量 r_⊥)
- **残差分类**：c_dyn = classify(ψ_dyn) ∈ {steady, step_load, oscillation, slip_precursor, friction_drift, collision}
- **原始动力学残差**（辨识用）：e_dyn(t) = τ_meas − [ M̂(q)q̈_f + Ĉ(q,q̇)q̇ + Ĝ(q) + τ̂_f(q̇) ]，其中 q̈_f 为滤波后的加速度

**定义 174（在线动力学辨识 ODD）** ODD = (Y, θ̂, P, λ, E_exc)。其中：
- **惯性参数向量**：θ_body ∈ ℝ^{n_θ}（各连杆质量、质心一阶矩、惯性张量、关节摩擦参数、执行器增益/偏置）
- **动力学回归形式**（对惯性参数线性）：τ = Y(q, q̇, q̈) θ_body + τ_fric(q̇; θ_f)
- **带遗忘因子的递归最小二乘**：
  ```
  K(t)   = P(t−1) φ(t) / ( λ + φ(t)ᵀ P(t−1) φ(t) )
  θ̂(t)   = θ̂(t−1) + K(t) ( y(t) − φ(t)ᵀ θ̂(t−1) )
  P(t)   = ( I − K(t) φ(t)ᵀ ) P(t−1) / λ,   λ ∈ (0,1]
  ```
- **激励条件**：仅当 λ_min( Σ_{s=t−W}^{t} φ(s)φ(s)ᵀ ) ≥ ε_exc 时更新；否则**冻结** θ̂（防止病态、防止把噪声学进身体）
- **物理投影**：θ̂ ← Proj_phys(θ̂)，约束 M̂(q) ≻ 0、M̂ 对称、三角不等式（惯性张量可行性）
- **输出**：(θ̂_body, Σ_θ = σ²P, e_dyn)；辨识收敛判据 ‖θ̂(t)−θ̂(t−W)‖_Σ ≤ ε_conv

**定义 175（动力学-无源阻抗整形 DIPS）** DIPS = (H, T_e, K̇ 约束, D_virt)。其中：
- **系统能量**：H(q,q̇) = ½ q̇ᵀ M̂(q) q̇ + ½ eᵀ K_p e，e = q − q_d
- **无源性定义**：对任意 T ≥ 0，∫₀ᵀ q̇ᵀ τ_ext dt ≥ H(T) − H(0)（系统不从环境净吸能）
- **能量 tank 动力学**（标准变阻抗 tank 记账）：
  ```
  Ṫ_e = q̇ᵀ τ_ext − q̇ᵀ D q̇ − ½ eᵀ K̇_p e − P_delay
  P_delay = ½ ‖q̇‖² · κ_delay · τ_d        # 延迟导致的泄漏上界
  约束：T_e(t) ≥ 0  ∀t（离散实现用 T_e(t+Δ) ≥ T_min > 0）
  ```
  约定：刚度增大（K̇_p > 0，"上紧"）从 tank 取能，刚度减小（"松开"）向 tank 回能；符号由 tank 记账约定保证
- **时变速率限幅**：|λ_max(K̇_p)| ≤ γ_pass，避免刚度突释导致的能量冲击
- **虚拟阻尼注入**：若 T_e(t) < T_min，则
  ```
  D_virt = clip( κ_v · max(0, −Ṫ_e) / (‖q̇‖² + ε), 0, D_max )
  K_p ← K_p · (T_e / T_min)^α   (α>0，向软方向收缩)
  ```
- **无源见证**：W_pass = (T_e^min, ∫ q̇ᵀτ_ext, ∫ q̇ᵀDq̇)，用于证书 J_dyn_exec

**定义 176（本体-语义联合锚点 PU-Anchor）** Anchor_t 扩展为：
```
Anchor_t = ( scene_emb, intent_emb, phys_prior,
             body_state = (q, q̇, ẑ_ext, contact_state),
             Σ_θ, ψ_dyn, T_e,
             version ∈ ℕ₆₄, timestamp, checksum )
```
- **条件投影头**：Π(· | q, q̇): ℝ^{d_us} × ℝ^{n_body} → K_safe，采用 FiLM 条件化：
  ```
  h = σ( W₁ fused + W_b [q; q̇; ψ_dyn] + b₁ )
  K_prior = W₂ h + b₂
  ```
  并施加谱归一化保证 Lipschitz 常数 L_Π
- **速度相关软化（物理直觉的形式化）**：K_p^des = K_p^sem · exp(−β‖q̇‖²)，K_d^des = 2ζ√(K_p^des · M_eff(q))（保持目标阻尼比 ζ）
- **联合可行域**：K_feasible = K_sem(语义约束) ∩ K_dyn(动力学/执行器约束) ∩ K_stab(无源约束)，实时流只在交集内取 K

**定义 177（动力学驱动仲裁 DDA）** DDA = (ψ_dyn → e_dyn, A_dyn)。仲裁映射：
| 残差模式 c_dyn | 触发条件 | 仲裁动作 a_dyn |
|---|---|---|
| steady | ‖e_dyn‖ < ε_0 | continue |
| step_load | |Δ‖r‖| > θ_step | conservative_shrink + re_identify |
| oscillation | f_peak ∈ [f_lo, f_hi] ∧ 幅值增 | inject_damping + request_mel(query='contact_stability') |
| slip_precursor | r_∥ / ‖r⊥‖ > θ_slip | propose_dialogue('reduce_Kp') + shrink |
| friction_drift | d‖r‖/dt 缓正 ∧ 方向稳定 | re_identify(θ_f) |
| collision | ‖r‖ > θ_coll ∧ 突变 | abort/retreat + freeze_anchor |
- **定向问询**：DDA 生成 query 而非盲目重推理，MEL.infer(query) 仅重算相关头（物理属性/接触语义），节省 B_mel
- **可审计**：每次仲裁记录 (c_dyn, ψ_dyn, a_dyn, 触发阈值, 决策来源)，写入 J_dyn_exec

**定义 178（本体感知-动力学一致性闭环 PDEC）** 三层异步闭环 PDEC = Slow ∘ Mid ∘ Fast：
```
Fast (≈1 kHz):   PRS → ODD → DIPS → EEIS/ERTC → 执行 → 本体感受
Mid  (100–500 Hz): DDA(ψ_dyn, e_dyn, U_mel, budget) → {shrink, re_identify, request_mel, dialogue}
Slow (10–100 Hz): MEL → DMS → USR → PU-Anchor.commit → 语义锚点
```
- **跨层同步**：Fast 只读 PU-Anchor 的 (K_sem, body_state, T_e)；Slow 只写版本号单调递增的锚点；Mid 是唯一能触发 Slow 重算的层
- **失效隔离**：Fast 在 Slow 超时时按 DIPS 保守扩展；Slow 在 Fast 报告 collision 时冻结锚点并降级任务

**定义 179（身体-环境解耦辨识 BED）** 把残差分解为身体项与环境项：
```
e_dyn = Y(q,q̇,q̈) Δθ_body + Jᵀ(q) ΔF_ext
联合回归： [Y  Jᵀ] [Δθ_body; ΔF_ext] ≈ e_dyn
可辨识条件： rank([Y  Jᵀ]) = n_θ + n_env（列满秩）
```
- 列秩不足（如静止接触、激励未覆盖接触方向）⇒ **冻结不可辨识分量**，只用满秩子空间更新，避免"环境误差被错记到身体"或反之
- 输出：θ̂_body 更新、接触参数 φ_contact = (μ̂, k̂_c, ẑ_c) 更新、解耦置信度 χ_bed

**定义 180（动力学-语义联合证书 J_dyn_exec）** 扩展第 61 轮 J_sem_exec：

```
J_dyn_exec = ( J_sem_exec,

验证规则：
Valid(J_dyn_exec) ⇔ Valid(J_sem_exec)
                    ∧ T_e^min ≥ 0

```

**定义 181（八维认知-动力学预算 PCE++++++）** B_cog7 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_body, B_stab)：

- **降级**：
  - B_body 耗尽 ⇒ 冻结辨识，回到名义 θ̂（并放宽 ε_dyn 但**不放宽 T_e ≥ 0**）
  - B_stab 耗尽 ⇒ 强制刚度冻结（K̇_p = 0）+ 最大阻尼 + 任务降速；**稳定性优先级高于任务与语义**

```
    K_d ← 2ζ√(K_p · M_eff(q))
```

- **泛化目标**：未见负载质量误差 < 20%、接触刚度误差 < 25%、零样本抓取成功率 ≥ 85%（vs 第 61 轮 80%）

**定义 183（可解释本体感知叙事 PSN）** 把动力学事件映射为语言证据：

- 叙事作为 DMS 的 `grounded_evidence` 进入 H_diag，形成"本体感受→语言"的可审计接地

## 2. 关键算法伪代码

### IP-183 PRS（本体动力学残差流）

```python
class ProprioceptiveResidualStream:
    def __init__(self, model, K_obs=diag(20.0), W=50):
        self.model = model            # 名义动力学：M, C, G, tau_fric
        self.K_obs = K_obs            # 观测器增益
        self.r = 0.0                  # 残差积分状态
        self.W = W
        self.hist = deque(maxlen=W)

    def step(self, q, dq, tau_meas, dt):
        M = self.model.M(q); C = self.model.C(q, dq)
        g = self.model.G(q); tau_f = self.model.friction(dq)
        # 广义动量
        p = M @ dq
        # 动量观测器积分项（抗噪，不用 qdd）
        integrand = tau_meas + C.T @ dq - g + self.r - tau_f
        self.r = self.K_obs @ (p - (self.p_prev if hasattr(self,'p_prev') else p)
                               - integrand * dt) + (self.r if hasattr(self,'r') else 0)
        self.p_prev = p
        self.hist.append((q, dq, self.r.copy()))
        return self.r

    def features(self):
        r_norm = np.linalg.norm(self.r)
        r_dot = (r_norm - self.hist[-2][2].__abs__().sum()) if len(self.hist) > 1 else 0.0
        f_peak = dominant_frequency([np.linalg.norm(h[2]) for h in self.hist])
        return dict(norm=r_norm, dot=r_dot, f_peak=f_peak,
                    r_par=project_tangent(self.r), r_perp=project_normal(self.r))

    def classify(self, psi):
        if psi['norm'] > COLL:              return 'collision'
        if psi['r_par'] > SLIP * psi['r_perp']: return 'slip_precursor'
        if F_LO <= psi['f_peak'] <= F_HI and psi['dot'] > 0: return 'oscillation'
        if psi['dot'] > STEP:               return 'step_load'
        if 0 < psi['dot'] and psi['direction_stable']: return 'friction_drift'
        return 'steady'
```

```python
class OnlineDynamicsIdentifier:
    def __init__(self, n_theta, lam=0.98, eps_exc=0.05, W=100):
        self.theta = np.zeros(n_theta)
        self.P = np.eye(n_theta) * 1e3

        self.buffer = deque(maxlen=W)

        y = tau_meas - friction_baseline(dq)
        self.phi_hist.append(phi)
        if self._excited():
            K = self.P @ phi / (self.lam + phi @ self.P @ phi)
            self.theta = self.theta + K * (y - phi @ self.theta)
            self.P = (np.eye(len(self.theta)) - np.outer(K, phi)) @ self.P / self.lam
            self.theta = self._project_phys(self.theta)   # M>0, 对称, 惯性可行

        if len(Phi) < 10: return False
        return np.linalg.eigvalsh(Phi.T @ Phi)[0] >= self.eps_exc

        # 三角不等式 / 正定投影，保证物理可实现
```

```python
class DynamicsInformedPassivityShaping:
    def __init__(self, T_e0=1.0, T_min=0.05, gamma=2.0, kappa_v=0.5, D_max=50.0):
        self.T_e = T_e0
        self.T_min = T_min
        self.gamma = gamma            # |Kdot| 上限
        self.kappa_v = kappa_v
        self.D_max = D_max
        self.K_prev = None

    def shape(self, K_des, e, dq, tau_ext, D, dt):
        K = K_des.copy()
        # 1) 刚度变化速率限幅
        if self.K_prev is not None:
            dK = K - self.K_prev
            scale = self.gamma * dt / (np.linalg.norm(dK) + 1e-9)
            if scale < 1.0:
                K = self.K_prev + dK * scale
        dK = (K - self.K_prev) if self.K_prev is not None else 0.0
        # 2) 能量 tank 记账
        P_ext   = dq @ tau_ext
        P_diss  = dq @ D @ dq
        P_stiff = 0.5 * (e @ (dK @ e)) if np.ndim(dK) else 0.0
        P_delay = 0.5 * np.linalg.norm(dq)**2 * self.kappa_delay * dt
        self.T_e += (-P_diss - P_stiff - P_delay + P_ext) * dt
        # 3) 裕度不足：注入虚拟阻尼 + 向软方向收缩
        D_virt = 0.0
        if self.T_e < self.T_min:
            D_virt = min(self.D_max, self.kappa_v * max(0.0, -P_stiff) / (np.linalg.norm(dq)**2 + 1e-9))
            K = K * (max(self.T_e, 0.0) / self.T_min) ** 0.5
            self.T_e = self.T_min
        # 4) 保证 K 对称正定
        K = 0.5 * (K + K.T)
        self.K_prev = K
        return K, D + D_virt * np.eye(len(dq)), dict(T_e=self.T_e, D_virt=D_virt)
```

```python
    def __init__(self, n_theta, n_env, rho=1e-2):
        self.rho = rho
    def solve(self, Y, Jt, e_dyn):
        A = np.hstack([Y, Jt])                 # [n_theta + n_env]
        if np.linalg.matrix_rank(A) < A.shape[1]:
            # 只解满秩子空间，冻结其余分量
            U, s, Vt = np.linalg.svd(A, full_matrices=False)
            keep = s > 1e-6 * s[0]
            x = Vt[keep].T @ (U[:, keep].T @ e_dyn / s[keep])
            chi = keep.sum() / len(keep)
        else:
            x = np.linalg.solve(A.T @ A + self.rho * np.eye(A.shape[1]), A.T @ e_dyn)
            chi = 1.0
        return x[:n_theta], x[n_theta:], chi     # Δθ_body, ΔF_env, 置信度
```

### IP-183 PRS（本体动力学残差流）

```python
class ProprioceptiveResidualStream:
    def __init__(self, model, K_obs=diag(20.0), W=50):
        self.model = model; self.K_obs = K_obs
        self.r = np.zeros(model.n); self.p_prev = None
        self.hist = deque(maxlen=W)

    def step(self, q, dq, tau_meas, dt):
        M = self.model.M(q); C = self.model.C(q, dq)
        g = self.model.G(q); tau_f = self.model.friction(dq)
        p = M @ dq
        if self.p_prev is None: self.p_prev = p
        integrand = tau_meas + C.T @ dq - g + self.r - tau_f
        self.r = self.K_obs @ (p - self.p_prev - integrand * dt) + self.r
        self.p_prev = p
        self.hist.append(self.r.copy())
        return self.r

    def features(self):
        rn = [np.linalg.norm(x) for x in self.hist]
        r = self.hist[-1]
        return dict(norm=rn[-1],
                    dot=(rn[-1]-rn[-2]) if len(rn) > 1 else 0.0,
                    f_peak=dominant_frequency(rn),
                    r_par=project_tangent(r), r_perp=project_normal(r))

    def classify(self, psi):
        if psi['norm'] > COLL: return 'collision'
        if psi['r_par'] > SLIP * psi['r_perp']: return 'slip_precursor'
        if F_LO <= psi['f_peak'] <= F_HI and psi['dot'] > 0: return 'oscillation'
        if psi['dot'] > STEP: return 'step_load'
        if psi['dot'] > 0 and stable_direction(self.hist): return 'friction_drift'
        return 'steady'
```

### IP-184 ODD（在线动力学辨识）

```python
class OnlineDynamicsIdentifier:
    def __init__(self, n_theta, lam=0.98, eps_exc=0.05, W=100):
        self.theta = np.zeros(n_theta); self.P = np.eye(n_theta) * 1e3
        self.lam, self.eps_exc = lam, eps_exc
        self.phi_hist = deque(maxlen=W)

    def update(self, q, dq, ddq_f, tau_meas):
        phi = regressor(q, dq, ddq_f)          # Y 行，对惯性参数线性
        y = tau_meas - friction_baseline(dq)
        self.phi_hist.append(phi)
        if self._excited():
            K = self.P @ phi / (self.lam + phi @ self.P @ phi)
            self.theta += K * (y - phi @ self.theta)
            self.P = (np.eye(len(self.theta)) - np.outer(K, phi)) @ self.P / self.lam
            self.theta = physical_projection(self.theta)   # M>0, 对称, 惯性可行
            return self.theta, self.P, True
        return self.theta, self.P, False        # 激励不足：冻结，不污染身体模型

    def _excited(self):
        if len(self.phi_hist) < 10: return False
        Phi = np.array(self.phi_hist)
        return np.linalg.eigvalsh(Phi.T @ Phi)[0] >= self.eps_exc
```

### IP-185 DIPS（动力学-无源阻抗整形）

```python
class DynamicsInformedPassivityShaping:
    def __init__(self, T_e0=1.0, T_min=0.05, gamma=2.0, kappa_v=0.5,
                 kappa_delay=0.2, D_max=50.0):
        self.T_e = T_e0; self.T_min = T_min; self.gamma = gamma
        self.kappa_v = kappa_v; self.kappa_delay = kappa_delay; self.D_max = D_max
        self.K_prev = None

    def shape(self, K_des, e, dq, tau_ext, D, dt):
        K = K_des.copy()
        # 1) 刚度变化速率限幅，避免参数泵注入能量
        if self.K_prev is not None:
            dK = K - self.K_prev
            n = np.linalg.norm(dK)
            if n > self.gamma * dt:
                K = self.K_prev + dK * (self.gamma * dt / n)
        dK = K - self.K_prev if self.K_prev is not None else 0.0
        # 2) 能量 tank 记账
        P_ext   = dq @ tau_ext
        P_diss  = dq @ D @ dq
        P_stiff = 0.5 * (e @ dK @ e) if np.ndim(dK) else 0.0
        P_delay = 0.5 * np.linalg.norm(dq)**2 * self.kappa_delay * dt
        self.T_e += (-P_diss - P_stiff - P_delay + P_ext) * dt
        # 3) 裕度不足：注入虚拟阻尼 + 向软方向收缩
        D_virt = 0.0
        if self.T_e < self.T_min:
            D_virt = min(self.D_max, self.kappa_v * max(0.0, -P_stiff)
                         / (np.linalg.norm(dq)**2 + 1e-9))
            K = K * (max(self.T_e, 0.0) / self.T_min) ** 0.5
            self.T_e = self.T_min
        K = 0.5 * (K + K.T)
        self.K_prev = K
        return K, D + D_virt * np.eye(len(dq)), dict(T_e=self.T_e, D_virt=D_virt)
```

```python
class ProprioceptiveUnifiedAnchor:
    def __init__(self, d_us=256, n_body=16, d_h=128):
        self.projector = ConditionalProjector(d_us, n_body, d_h)
        self.anchor = None; self.version = 0

    def commit(self, scene_emb, intent_emb, phys_prior, body_state, Sigma, psi, T_e):
        self.version = (self.version + 1) & ((1 << 64) - 1)   # 64 位单调
        self.anchor = SemanticAnchor(
            scene_emb=scene_emb, intent_emb=intent_emb, phys_prior=phys_prior,
            body_state=body_state, Sigma=Sigma, psi=psi, T_e=T_e,
            version=self.version, timestamp=time.time(),
            checksum=hash_of(scene_emb, intent_emb, body_state))
        return self.anchor

    def project(self, anchor):
        fused = anchor.scene_emb + anchor.intent_emb
        K = self.projector(fused, anchor.body_state)      # Π(·|q, q̇)
        K['K_p'] *= np.exp(-BETA * np.linalg.norm(anchor.body_state['dq'])**2)
        K['K_d'] = 2 * ZETA * np.sqrt(K['K_p'] * M_eff(anchor.body_state['q']))
        return K

class ConditionalProjector(nn.Module):
    def __init__(self, d_us, n_body, d_h):
        super().__init__()
        self.w1 = spectral_norm(nn.Linear(d_us, d_h))
        self.wb = spectral_norm(nn.Linear(n_body, d_h))
        self.w2 = spectral_norm(nn.Linear(d_h, N_IMP))
    def forward(self, fused, body_state):
        h = torch.relu(self.w1(fused) + self.wb(body_state_vector(body_state)))
        return self.w2(h)
```

```python
class BodyEnvironmentDisentangler:
    def __init__(self, n_theta, n_env, rho=1e-2):
        self.rho = rho
    def solve(self, Y, Jt, e_dyn):
        A = np.hstack([Y, Jt])
        if np.linalg.matrix_rank(A) < A.shape[1]:
            U, s, Vt = np.linalg.svd(A, full_matrices=False)
            keep = s > 1e-6 * s[0]
            x = Vt[keep].T @ (U[:, keep].T @ e_dyn / s[keep])
            chi = keep.sum() / len(keep)
        else:
            x = np.linalg.solve(A.T @ A + self.rho*np.eye(A.shape[1]), A.T @ e_dyn)
            chi = 1.0
        return x[:n_theta], x[n_theta:], chi     # Δθ_body, ΔF_env, χ_bed
```

```python
class CognitiveDynamicsBudget:
    def __init__(self, b_cog5, exc_energy=1.0, ident_freq=200, param_cov_tol=0.1,
                 tank_min=0.05, passivity_margin=0.1,
                 delay_budget=2e-3, damping_budget=20.0):
        self.b5 = b_cog5
        self.B_body = dict(exc_energy=exc_energy, ident_freq=ident_freq,
                           param_cov_tol=param_cov_tol, exc_used=0.0)
        self.B_stab = dict(tank_min=tank_min, passivity_margin=passivity_margin,
                           delay_budget=delay_budget, damping_budget=damping_budget,
                           damping_used=0.0)
    def b_body_exhausted(self):
        return self.B_body['exc_used'] >= self.B_body['exc_energy']
    def cost_cog7(self, x):
        return (self.b5.cost_cog5(x)
                + L_BODY * (self.B_body['exc_used']/self.B_body['exc_energy']
                            + trace_sigma()/self.B_body['param_cov_tol'])
                + L_STAB * (1 - self.dips.T_e/self.B_stab['tank_min']
                            + self.B_stab['damping_used']/self.B_stab['damping_budget']))
    def voi_cog7(self, action, IG_dyn):
        return (self.b5.voi_meta_pessimistic(action)
                - self.cost_cog7(action) + K_INFO * IG_dyn)
    def degrade(self):
        if self.b_body_exhausted():
            return 'freeze_identification'          # 不放宽 T_e >= 0
        if self.dips.T_e < self.B_stab['tank_min']:
            return 'freeze_stiffness_max_damping_slow_task'
        return 'normal'
```
