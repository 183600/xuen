# 第 8 轮（新灵感循环第 1 轮；本轮灵感：「社会规范理解」×「流匹配策略」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525；IP-340–IP-350）。
> 本轮纪律：**规范可辨识 + 多峰策略 + 分布级证书**。两个灵感不叠加成两个补丁，而合成一个命题：**社会规范天然是多峰的，流匹配是保留多峰的生成式策略**；最大风险是规范不可辨识与 ODE 采样延迟，故必须双速率 + 严格退化链。

## 0. 直觉与动机

**灵感 1（社会规范理解 → 规范不是标量惩罚，而是可条件化的状态与场）**
直觉：现有系统把“得体”当作一个奖励项 $\lambda\cdot\text{norm}$，这默认规范是一维可加的。但社会规范至少有三层结构：(i) **状态相关**——同一动作在拥挤/空旷、熟人/陌生人下得体性不同；(ii) **多峰**——让左、让右、停步等待都可能得体；(iii) **有优先级**——安全 > 个人空间 > 轮流 > 效率，冲突时按字典序放松。因此规范应被形式化为：规范状态 $n(s)$、规范违背裕度场 $\phi_k(a,s)$、以及可行集 $\mathcal A_{\text{norm}}(s)$。

**灵感 2（流匹配策略 → 用生成式速度场保留多峰行为）**
直觉：流匹配学习 $v_\theta(a,t\mid s,n)$，把高斯噪声沿近直线路径输运到动作轨迹分布。它不输出“平均动作”，而是输出**样本**；多个 socially-valid 模态各自保峰。更关键的是，条件 $n$ 与可微规范场可以在**采样时**（而非仅在训练时）施加引导，从而在推理阶段就压掉违规模态。

**合成命题（本轮核心）**：*标量化奖励把多峰社会行为平均成“中间的不合规行为”；规范条件流匹配既保留多峰，又能通过可微规范场引导到可行流形，并用分布级证书认证。*

## 1. 研究问题（轮次升级版）

- **Q1（规范可辨识）**：如何从多模态感知构造低维、可校准的规范状态 $n(s)$ 及其不确定度 $\sigma_n$，使下游策略对文化/情境变化可响应而非过拟合？
- **Q2（多峰规范策略）**：如何训练规范条件流匹配策略，使 $\pi_\theta(a\mid s,n)$ 覆盖多个规范可行模态，并在推理时以可微规范场引导 + 投影保证 $\varepsilon$-可行性？
- **Q3（随机策略的证书与退化）**：如何对随机策略出具**分布级**软证书，并保证 NSE / 流策略 / 引导 / 证书任一失效时严格退化到 v7 确定性闭环？

## 2. 设计原则（升级为 P10–P14）

**P10 规范状态估计（NormStateEstimator, NSE）**
从人体距离、朝向、注视、语音礼貌度、密度、紧迫度估计
$$n(s)=(n_{\text{prox}},n_{\text{turn}},n_{\text{ang}},n_{\text{pace}},n_{\text{urg}})\in[0,1]^5,\qquad \sigma_n(s)$$
其中 $\sigma_n$ 为逐维校准不确定度；$\sigma_n$ 越大，引导强度 $\lambda$ 越大（保守偏置）。

**P11 规范场与冲突消解（NormField + Lexicographic Resolution）**
定义违背裕度 $\phi_k(a,s)$（$\phi_k\le 0$ 为满足），
$$C_{\text{norm}}(a,s)=\max_{k\in K}\phi_k(a,s),\qquad \mathcal A_{\text{norm}}(s)=\{a:C_{\text{norm}}(a,s)\le 0\}$$
冲突（无解）时按字典序 $M_0 \succ \text{prox} \succ \text{turn} \succ \text{ang} \succ \text{pace}$ 最小放松低优先级约束，解最小松弛量 $\varepsilon^\*=\min\{\varepsilon:\mathcal A^\varepsilon_{\text{norm}}\ne\varnothing\}$。

**P12 规范条件流匹配策略（Norm-Conditioned Flow Policy, NCFP）**
$$a_t=(1-t)a_0+t a_1,\quad a_0\sim\mathcal N(0,I),\ a_1\sim q(a\mid s,n)$$
$$\mathcal L_{\text{NCFP}}(\theta)=\mathbb E_{t,a_0,a_1}\big\|v_\theta(a_t,t\mid s,e(n))-(a_1-a_0)\big\|^2$$
采样：$a_0\sim\mathcal N(0,I)$，积分 $\dot a=v_\theta(a,t\mid s,e(n))$ 从 $t{=}0$ 到 $1$。

**P13 规范引导采样（Norm-Guided Sampler, NGS）**
$$v_{\text{guided}}(a,t)=v_\theta(a,t\mid s,e(n))-\lambda(t)\,\nabla_a \tilde C_{\text{norm}}(a,s)$$
末尾投影 $a\leftarrow\Pi_{\mathcal A_{\text{norm}}}(a)$；$\tilde C$ 为 smooth-max，保证可微。$\lambda(t)$ 采用“先弱后强”调度，避免早期引导破坏多峰性。

**P14 分布级软证书（Distributional SoftCert, DSC）**
抽 $K$ 个样本 $\{a^{(k)}\}$，出证书
$$\text{Cert}_\alpha=\big(q_{1-\alpha}(C_{\text{norm}}(a^{(k)})),\ \widehat P_{\text{viol}}+ \sqrt{\tfrac{\ln(1/\delta)}{2K}}\big)$$
仅当分位数 $\le 0$ 且违背概率上界 $\le \alpha$ 时判“规范通过”；否则降级或重采样。

## 3. 与基线的接口（严格退化）

- NSE 失效 ⇒ $n\leftarrow n_{\text{cons}}$（最大个人空间、严格轮流、最低步速），$\sigma_n=\infty$，$\lambda$ 取上界；规范场仍可用，策略仍安全但更保守；
- NCFP 失效 ⇒ 退回 v7 的确定性动作选择（MetricVoiceGauge-OTL-GC-ER 主闭环）；
- 引导采样失效 ⇒ 纯流采样 + 证书拒绝采样；若拒绝率 $>\rho_{\max}$ ⇒ 退回 v7；
- DSC 失效 ⇒ 直接投影到 $n_{\text{cons}}$ 默认可行集 + v7 硬约束检查；
- 任一退化均为**单跳**，不产生级联。

## 4. 预期贡献

1. **规范状态—场—证书**三层形式化，把“社会得体”从标量惩罚升级为可条件化、可认证的结构；
2. **规范条件流匹配策略**，在保留社会行为多峰性的同时以推理期引导保证可行性；
3. **分布级软证书 + 双速率架构**，使随机生成式策略仍满足 50Hz 实时闭环；
4. 完整 **感知—规范—生成—证书—退化** 闭环：E526–E548 覆盖规范估计、多峰覆盖、冲突消解、分布证书、退化等价与实时性。

## 5. 本轮最大风险

**一句话**：低维规范状态可能不可辨识（把文化/情境差异压成同一向量），导致策略生成“形式合规、语义错误”的多峰行为；叠加流匹配 ODE 采样延迟，系统可能为“社交得体”同时牺牲语义正确性与实时安全。

| 符号 | 含义 |

| `C̃_norm` | smooth-max 可微版本 |
| `v_θ(a,t∣s,e(n))` | 规范条件流速度场 |
| `λ(t)` | 引导强度调度 |
| `Π_{Ã}` | 到规范可行集的投影算子 |

| `Cert_α` | 分布级软证书（分位数 + 违背概率上界） |
| `ρ_max` | 允许的最大拒绝采样率 |

**定义 530（规范状态估计 NSE）** 感知 $\omega$ 到规范状态与不确定度：
```
(n, σ_n) = E_norm(ω),  n ∈ [0,1]^5
```

**定义 531（规范违背裕度 NormField）**
```
φ_prox(a,s)  = r_min(n) − min_{h∈H} ||p(a) − p_h||
φ_turn(a,s)  = turn_budget(s) − turn_cost(a)
φ_ang(a,s)   = |θ_approach(a) − θ_desired(n)| − θ_max
φ_pace(a,s)  = ||v(a)|| − v_max(n)
C_norm(a,s)  = max_{k∈K} φ_k(a,s)
Ã_norm(s)    = { a : C_norm(a,s) ≤ 0 }
```

**定义 532（规范冲突与字典序消解）** 若 $\mathcal A_{\text{norm}}(s)=\varnothing$：
```
ε* = min{ ε ≥ 0 : Ã^ε_norm(s) ≠ ∅ },  Ã^ε_norm = {a : C_norm(a,s) ≤ ε}
```
按优先级 $M_0 \succ \text{prox} \succ \text{turn} \succ \text{ang} \succ \text{pace}$ 只放松最低优先级约束。

**定义 533（规范条件流匹配策略 NCFP）**
```
a_t = (1−t)·a_0 + t·a_1,  a_0 ~ N(0,I),  a_1 ~ q(a | s, n)
L_NCFP(θ) = E_{t,a_0,a_1} || v_θ(a_t, t | s, e(n)) − (a_1 − a_0) ||²
采样：a_0 ~ N(0,I),  da/dt = v_θ(a, t | s, e(n)),  t : 0 → 1
```

**定义 534（规范引导采样 NGS）**
```
v_guided(a,t) = v_θ(a,t | s,e(n)) − λ(t) · ∇_a C̃_norm(a,s)
a ← Π_{Ã_norm}( a + h·v_guided )
```

**定义 535（分布级软证书 DSC）** 对 $K$ 个样本：
```
Cert_α = ( q_{1−α}({C_norm(a^(k),s)}),  P̂_viol + sqrt( ln(1/δ) / (2K) ) )
P̂_viol = (1/K) Σ_k 1[ C_norm(a^(k),s) > 0 ]
规范通过 ⇔ 分位数 ≤ 0 ∧ 违背概率上界 ≤ α
```

**定义 536（规范退化标识）**
```
Φ_v8 = { n estimated, C_norm checked, π_θ sampled, Cert_α valid }
Φ_v7 = { n := n_cons, C_norm via fixed radii, deterministic action, point SoftCert }
```

**定义 537（双速率调度 DualRate）**
```
规划线程 (≈10Hz)：NSE → NGS(K 样本) → DSC → 选样 plan
控制线程 (50Hz)：track(plan) → M_0 硬约束 → 发布证书
```

**定义 538（规范层指标 MetricLadder 扩展）** $M_{\text{soc}}$ 作为 $M_1$ 的从属层，其阈值由 $n(s)$ 参数化：$\tau_{\text{soc}}=\tau_{\text{soc}}(n)$；$M_{\text{soc}}$ 违背不直接跳 $M_0$，而先触发 NGS 重采样。

**定义 539（最小松弛合法性）** $\varepsilon^*$ 是使可行集非空的最小松弛，且松弛顺序由字典序决定；硬约束 $M_0$ 永不参与放松。

**定义 540（v8 主闭环）**
```
Φ_NormFlowGauge = (n,σ_n) → C_norm → {a^(k)} ~ π_θ(·|s,n) → Cert_α → plan → track → M_0
任一环节失效 ⇒ Φ_v7（单跳）
```

```python
import torch, math

class NormStateEstimator:
    """IP-351：感知 -> 规范状态 (n, sigma_n)"""
    def __init__(self, model, default=None):
        self.model = model
        self.default = default or torch.tensor([1., 1., .5, .3, .5])

    @torch.no_grad()
    def estimate(self, perception):
        if self.model is None:
            return self.default, torch.full((5,), float('inf'))
        n, log_var = self.model(perception)      # n in [0,1]^5
        return n.clamp(0, 1), torch.exp(0.5 * log_var)


class NormField:
    """IP-352：规范违背裕度 + 字典序冲突消解"""
    ORDER = ['prox', 'turn', 'ang', 'pace']      # 由高到低优先级

    def margins(self, a, s):
        return {
            'prox': self.r_min(s) - self.min_human_dist(a, s),
            'turn': self.turn_budget(s) - self.turn_cost(a),
            'ang':  self.angle_margin(a, s),
            'pace': self.speed(a) - self.v_max(s),
        }

    def C(self, a, s, kappa=10.0):
        phi = self.margins(a, s)
        vals = torch.stack(list(phi.values()), dim=-1)
        return torch.logsumexp(kappa * vals, dim=-1) / kappa, phi

    def project(self, a, s, eps=0.0, iters=5):
        for _ in range(iters):
            c, _ = self.C(a, s)
            if bool((c <= eps).all()):
                break
            g = torch.autograd.grad(c.sum(), a)[0]
            a = a - 0.1 * g
        return a

    def min_slack(self, s, lo=0.0, hi=5.0, iters=20):
        # 二分求最小松弛 eps*，硬约束 M0 不参与
        for _ in range(iters):
            mid = 0.5 * (lo + hi)
            if self.has_feasible(s, eps=mid):
                hi = mid
            else:
                lo = mid
        return hi


class NormConditionedFlowPolicy:
    """IP-353：条件流匹配策略"""
    def __init__(self, v_theta, embed, d_a):
        self.v, self.embed, self.d_a = v_theta, embed, d_a

    def loss(self, a1, s, n):
        a0 = torch.randn_like(a1)
        t = torch.rand(a1.shape[0], 1, device=a1.device)
        at = (1 - t) * a0 + t * a1
        target = a1 - a0
        pred = self.v(at, t.squeeze(-1), s, self.embed(n))
        return ((pred - target) ** 2).mean()

    @torch.no_grad()
    def sample(self, s, n, K=8, steps=8):
        a = torch.randn(K, self.d_a, device=s.device)
        h = 1.0 / steps
        for i in range(steps):
            a = a + h * self.v(a, torch.full((K,), i * h, device=a.device),
                               s, self.embed(n))
        return a


class NormGuidedSampler:
    """IP-354：规范引导 + 投影 + 拒绝采样兜底"""
    def __init__(self, field, lambda_max=1.0, rho_max=0.5):
        self.field, self.lambda_max, self.rho_max = field, lambda_max, rho_max

    def _lam(self, t, sigma_n):
        # 先弱后强，不确定度越大越保守
        ramp = t ** 2
        conf = 1.0 if sigma_n is None else min(1.0, float(sigma_n.mean()))
        return self.lambda_max * ramp * conf

    def sample(self, policy, s, n, sigma_n, K=8, steps=8):
        a = torch.randn(K, policy.d_a, device=s.device).requires_grad_(True)
        h = 1.0 / steps
        for i in range(steps):
            t = i * h
            v = policy.v(a, torch.full((K,), t, device=a.device),
                         s, policy.embed(n))
            c, _ = self.field.C(a, s)
            g = torch.autograd.grad(c.sum(), a, retain_graph=False)[0]
            lam = self._lam(t, sigma_n)
            a = (a + h * (v - lam * g)).detach().requires_grad_(True)
        a = self.field.project(a, s, eps=0.0).detach()

        # 拒绝采样兜底：拒绝率过高则交回 v7
        c, _ = self.field.C(a, s)
        reject = float((c > 0).float().mean())
        if reject > self.rho_max:
            return None, reject
        return a, reject


class DistributionalSoftCert:
    """IP-355：分布级软证书"""
    def __init__(self, alpha=0.05, delta=0.05):
        self.alpha, self.delta = alpha, delta

    def certify(self, field, actions, s):
        c, _ = field.C(actions, s)
        c = c.detach().cpu()
        q = torch.quantile(c, 1 - self.alpha).item()
        p_hat = float((c > 0).float().mean())
        ucb = p_hat + math.sqrt(math.log(1 / self.delta) / (2 * len(c)))
        ok = (q <= 0.0) and (ucb <= self.alpha)
        return {'quantile': q, 'viol_ucb': ucb, 'ok': ok,
                'n': len(c), 'mode_cover': self._mode_cover(c)}


def normflow_gauge_step(s, perception, low_rate, nse, field, policy, ngs, dsc, v7):
    """IP-356/357：双速率主闭环（规划线程 low_rate=True 时执行生成）"""
    n, sigma_n = nse.estimate(perception)

    if low_rate:
        eps_star = field.min_slack(s) if not field.has_feasible(s, 0.0) else 0.0
        actions, reject = ngs.sample(policy, s, n, sigma_n, K=8, steps=8)
        if actions is None:                     # 拒绝率过高 -> v7
            return v7.plan(s), {'source': 'v7_reject_fallback'}
        cert = dsc.certify(field, actions, s)
        if not cert['ok']:                      # 证书不过 -> v7
            return v7.plan(s), {'source': 'v7_cert_fallback', **cert}
        plan = actions[0]                       # 由样本级奖励排序择优
        return plan, {'source': 'ncfp', 'eps_star': eps_star, **cert}

    plan, meta = s.get('plan'), {}
    action = v7.track(plan)                     # 50Hz 高频跟踪
    if not v7.check_hard(s, action):            # M0 硬约束永不放松
        action, meta = v7.safe(s), {'source': 'v7_hard_veto'}
    return action, meta
```

## 3. 推导（引理 77–81）

**引理 77（多峰保持性 vs 标量化的均值坍塌）** 设目标策略 $\pi(a\mid s,n)$ 为 $M$ 个规范可行模态的混合，各模态支撑 $\mathcal A_m\subseteq\mathcal A_{\text{norm}}$ 且互不连通。标量化期望策略返回 $\bar a=\sum_m w_m a_m$；由于 $\mathcal A_{\text{norm}}$ 一般非凸，$\bar a$ 可能落在 $\overline{\mathrm{conv}}(\cup_m\mathcal A_m)\setminus\mathcal A_{\text{norm}}$（即“每个峰都不像”的中间违规点）。精确流匹配学到 $\pi$ 的速度场，采样以概率 $w_m$ 落入各模态，故 $\mathrm{ModeCoverage}\ge 1-\varepsilon$。**例**：两扇门之间的“让左/让右”，均值策略会径直撞向中间立柱。

**引理 78（引导采样的 $\varepsilon$-可行性）** 若 $\tilde C_{\text{norm}}$ 关于 $a$ 为 $L$-光滑，步长 $h$ 与引导强度满足 $\lambda Lh<1$，则带投影的引导 Euler 迭代在 $O(1/\varepsilon)$ 步内进入 $\{\tilde C_{\text{norm}}\le\varepsilon\}$；末端投影 $\Pi_{\mathcal A_{\text{norm}}}$ 进一步保证严格可行（当作 QP 精确求解时）。

**引理 79（分布级证书的可靠性）** 对 $K$ 个 i.i.d. 样本，Hoeffding 不等式给出
$$\Pr\big(P_{\text{viol}}\le \widehat P_{\text{viol}}+\sqrt{\ln(1/\delta)/(2K)}\big)\ge 1-\delta$$
分位数项由经验分位数的一致性保证；因此当 $K\to\infty$ 时证书以概率 1 收敛到真实违背率，且有限 $K$ 下为保守（上界）证书。

**引理 80（规范冲突消解的最优性）** 若 $\mathcal A_{\text{norm}}(\varepsilon)=\{a:C_{\text{norm}}\le\varepsilon\}$ 关于 $\varepsilon$ 单调不减，则二分所得 $\varepsilon^*$ 是使可行集非空的最小松弛；字典序保证只放松最低优先级约束，硬约束 $M_0$ 的放松量恒为 0。

**引理 81（单跳退化正确性）** 若 NSE / NCFP / NGS / DSC 任一失效，按退化链分别置为 $n_{\text{cons}}$、v7 动作选择、纯采样+拒绝、默认可行集投影，则闭环行为等价于 v7 或 v7 的保守实例；各失效分支互不触发，故不产生级联退化，满足 v7 的严格退化纪律。
