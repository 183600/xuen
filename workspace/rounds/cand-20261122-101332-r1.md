# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「触觉感知」×「中间件」）

> **基线**：上一循环产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（PCA/CTS/CFC/HPC/CFCtrl）。
> 本轮纪律：**接触是边界见证、证书是 QoS 契约、融合是双格求交/求并**。不推倒 v20：v20 的感知层（PCA/CTS/CFC/HPC/CFCtrl）与 v19 的 CCV/OGCC 全部保留。本轮只做一件事：**把触觉的"接触真值"经中间件的"证书消息"安全地注入 v20 的感知证书，形成 v21 触觉见证层**。

## 0. 直觉与动机

**灵感 1（触觉感知 → 接触是边界见证，不是几何测量）**
直觉：深度相机回答"表面大概在哪"，触觉回答"边界此刻确切在哪、朝哪边是自由空间"。一次接触事件天然携带三样东西：一个边界点、一个法向（哪边是物体、哪边是自由空间）、一个力/穿透量（边界有多硬、误差有多大）。它不给体积，只给一个**单侧的、局部的**边界见证。传统做法把触觉当"碰撞检测器"（碰到=不安全），这浪费了它最有价值的信息：**法向给出的自由侧**。核心创新：**接触见证证书 (Contact-Witness Certificate, CWC)**。每个接触事件被编码为签名见证 `w=(θ_c, x_c, n_c, f_c, δ_c, sensor_id, t_c)`，经局部 Lipschitz 界与方向导数下界，转化为参数空间中的**安全锥 (Safe Cone)**——只在"背离物体"的一侧成立，物体侧永不被认证。关键反直觉点：**触觉的价值不在"接触越多越安全"，而在"每次接触只证明一条单侧射线"**；证书的活性增益来自**证伪**（触觉证明某个被感知判为障碍的 θ 其实自由），而不是来自"覆盖"。

**灵感 2（中间件 → 证书是发布/订阅的 QoS 契约，不是同步函数调用）**
直觉：安全栈里有异构传感器（视觉/深度/触觉/力）、不同频率的控制器、多个节点。把证书内联在单体管线里，会让一个慢触觉驱动阻塞 50Hz 控制环；而中间件（DDS/ROS2 式 pub/sub）把证书变成**带类型、带 QoS、带版本**的消息。核心创新：**证书中间件总线 (Certificate Middleware Bus, CMB)**。证书是不可变、内容寻址、带时间戳的消息，发布在 `/cert/geom_hard`、`/cert/geom_soft`、`/cert/tactile`、`/cert/fused` 等类型化主题上；每条证书携带**有效区间、来源证明 (Merkle)、置信等级、降级策略**。融合被定义为**几何取交、触觉取并的证书双格**，两者都满足结合/交换/幂等，因而消息乱序、重复、迟到不影响认证集合。关键反直觉点：**安全中间件不要"可靠重传过期证书"**——重传一条过期的触觉证书是危险的；正确语义是**过期即撤销 (expiry = revocation)**，失效即退回保守基线。QoS 的 deadline/liveliness 不是性能参数，而是**安全证明的一部分**。

**统一：v20 感知层之上的触觉见证层**
v20 回答"给定几何与分布式感知，θ 是否安全"，v21 回答"给定一次真实接触，θ 附近的哪一侧、多大范围可被物理见证为自由"。CWC 是见证侧（接触→安全锥），CMB 是传输侧（证书→QoS 消息 + 双格融合），WGF 是融合侧（安全锥 ⊓/⊔ v20 证书）。共享状态 `ζ_tac = (witness_set, cone_set, cert_bus_state, expiry_clock, calibration_state, mode_tac)`。统一接口：**若某 θ 被至少一个有效见证锥覆盖，或落在 v20 的软证书内，且对应证书未过期，则 CCV 的窄相位返回 SAFE；否则退回 v20 基线**。v21 允许**有见证的扩张**（相对 v20 的过度保守），但**禁止无见证的扩张**——这由 P34/P36 保证。

## 1. 研究问题（轮次升级版）

- **Q1（见证锥的可靠性）**：单次接触如何从 (法向、力、穿透、标定误差) 推出一个 sound 的安全锥？Lipschitz 常数 `L_φ` 与方向下界 `μ_φ` 如何在线估计/离线标定？局部曲率未知或接触落在棱/角上时，锥如何保守收缩？

- **Q2（异构证书的双格融合）**：CWC 的安全锥（二阶锥/半空间）与 v20 的 HPC Hull（凸包/体积）如何求交而不引入不可判定？当"感知判障碍、触觉见证自由"冲突时，如何以可审计方式裁决（硬约束 vs 软约束）与回滚？

- **Q3（QoS 与安全语义）**：在丢包/乱序/分区/迟到加入下，证书融合如何保持结合/交换/幂等？deadline/liveliness 如何映射为撤销事件？不同证书类（几何长 TTL、触觉短 TTL）如何分层过期，且保证过期只导致收缩？

- **Q4（见证有效性的在线校验）**：标定漂移、力饱和、软/可变形障碍、法向估计符号错误如何被检测？检测到异常时如何只撤销受影响见证而不整体失效？被撤销见证所支撑的扩张如何完整回滚？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P37）

**P34 见证单向律（Witness One-Sidedness）**
见证 `w` 只认证自由侧锥 `C(w) = { θ_c + s·u_c + v : s ≥ κ‖v‖ + ε_0 }`，其中 `u_c = n_c` 指向自由侧，`κ = L_φ/μ_φ`，`ε_0 = (ε_δ + ε_cal)/μ_φ`。物体侧（`u_c·(θ-θ_c) < 0`）恒不认证。任何 `θ ∈ S_21 \ S_20` 必须被至少一个有效 `C(w)` 覆盖。**无见证不扩张**。

**P35 过期即撤销律（Expiry-as-Revocation）**
每条证书 `c` 有有效区间 `[t_pub, t_pub + TTL(kind)]`。超过 TTL、liveliness 丢失、或来源不可验证 ⇒ `c` 自动降为 `REVOKED`，融合时贡献空集，退回 v20 基线。**禁止重传过期安全数据**；QoS 的 deadline 违约是撤销事件而非重试事件。

**P36 双格融合律（Certificate Bi-Lattice）**
融合建立在两个无序集合运算上：几何证书取**交**（meet），触觉证书取**并**（join）。二者均满足结合、交换、幂等，故融合结果只依赖"活证书集合"，与到达顺序、重复次数无关。冲突裁决：**硬约束不可被触觉推翻**，只有感知派生的软约束可被有效见证锥覆盖。默认取更小集合。

**P37 校准前置律（Calibration Precondition）**
见证有效的前提是 CCM 判定：标定新鲜、力量程未饱和、穿透 `δ ≤ δ_max`、接触对象与几何模型一致、法向符号自洽。任一不满足 ⇒ 该见证作废；系统性失准则整体回退 v20。

## 3. 与基线的接口（如何退化）

- 触觉不可用/未标定 ⇒ 无见证锥，`S_21 = S_hard ∩ S_soft = S_20` ⇒ 等价 v20；
- CMB 不可用（总线分区）⇒ 本地证书直接用，跨节点融合退化为 v20 的 CFC ⇒ 等价 v20；
- 所有证书过期 ⇒ `S_tac = ∅` ⇒ `S_21 = S_20`；
- CCM 触发 ⇒ 撤销受影响见证并由 FL 回滚其扩张，其余保留；最坏全撤销 ⇒ 等价 v20；
- **安全语义修正**：v20 把"收敛盲区"与 `Exec_v20 ⊆ Exec_v19` 混在一起。本轮显式区分**认证集 (Cert)** 与**障碍域保守性**：v21 的规则是"**无见证不扩张**"，`S_21 = S_hard ∩ (S_soft ∪ S_tac)`，其中 `S_tac` 是有效见证锥之并。若所有见证失效，`S_21 = S_20`；任何扩张都可追溯到一条可审计见证（引理 161）。

## 4. 预期贡献

1. **接触见证证书**：把触觉从"碰撞开关"升级为"单侧边界见证"，给出安全锥的构造、Lipschitz/方向导数的界与曲率收缩规则；
2. **证书中间件**：把证书建模为 QoS 类型化消息与证书双格，证明融合对乱序/重复/分区鲁棒，把 deadline/liveliness 提升为安全撤销语义；
3. **有见证的保守性回收**：给出"感知障碍 vs 触觉自由"的可审计裁决与回滚，量化活性增益的见证覆盖率；
4. **在线见证校验**：标定漂移/力饱和/软障碍/法向符号错误的检测与局部撤销；
5. **分层证书代数**：几何（长 TTL）与触觉（短 TTL）证书分层过期，形成 v21 的触觉见证格。

## 5. 本轮最大风险

**一句话**：CWC 的全部扩张能力都押在"见证有效"上，而法向符号/标定偏差一旦翻转自由侧，安全锥会**把物体侧认证为自由**——此时系统"有见证、有签名、有 Merkle 证明、通过中间件 QoS"，却系统性地产生**被签名的碰撞授权**（"触觉伪证"）。

@dataclass(frozen=True)
class ContactWitness:
    theta_c: np.ndarray
    x_c: np.ndarray
    n_c: np.ndarray
    force: float
    delta: float
    sensor_id: str
    t_c: float


# IP-425 Contact-Witness Certificate
class ContactWitnessCertificate:
    def __init__(self, L_phi, mu_phi, eps_delta, eps_cal,
                 delta_max, force_range, cone_ttl=0.2):
        self.L = L_phi
        self.mu = mu_phi
        self.eps_delta = eps_delta
        self.eps_cal = eps_cal
        self.delta_max = delta_max
        self.f_min, self.f_max = force_range
        self.cone_ttl = cone_ttl

    def validate(self, w, calib, obj_model, now):
        # 校准前置律 P37：任一条件不满足即撤销该见证
        if not calib.fresh(w.sensor_id, w.t_c, now):
            return Revocation("STALE_CALIB")
        if not (self.f_min <= w.force <= self.f_max):
            return Revocation("FORCE_RANGE")
        if w.delta > self.delta_max:
            return Revocation("PENETRATION")
        if not obj_model.consistent(w.x_c, w.n_c, tol=3.0 * self.eps_cal):
            return Revocation("UNMODELED_OBJECT")
        return ValidWitness(w)

    def cone(self, vw):
        w = vw.w
        u = normalize(w.n_c)                      # 自由侧
        kappa = self.L / self.mu
        eps0 = (self.eps_delta + self.eps_cal) / self.mu
        return SafeCone(
            apex=w.theta_c.copy(),
            axis=u,
            kappa=kappa,
            eps0=eps0,
            t_expire=w.t_c + self.cone_ttl,
            witness_cid=content_id(w),
        )

    def covers(self, cone, theta):
        # 二阶锥隶属：s >= kappa*||v|| + eps0
        d = theta - cone.apex
        s = float(dot(d, cone.axis))
        v = d - s * cone.axis
        return s >= cone.kappa * norm(v) + cone.eps0


# IP-426 Certificate Middleware Bus
@dataclass(frozen=True)
class Certificate:
    cid: str
    kind: str                  # GEOM_HARD | GEOM_SOFT | TACTILE
    payload: object            # SafeSet / SafeCone
    t_pub: float
    ttl: float
    confidence: str            # CERTIFIED | PROVISIONAL | REVOKED
    provenance: str            # Merkle root
    degrade: str               # 降级策略 ID

    def alive(self, now):
        return (self.confidence != "REVOKED"
                and now <= self.t_pub + self.ttl)


class CertificateMiddlewareBus:
    def __init__(self, clock, baseline):
        self.clock = clock
        self.baseline = baseline           # S_20
        self.retained = {}                 # cid -> Certificate（内容寻址，可回放）
        self.topics = defaultdict(set)     # topic -> {cid}

    def publish(self, topic, cert):
        # 总线不可信：先验证内容哈希与 Merkle 来源，再入册
        if content_id(cert) != cert.cid or not verify_merkle(cert):
            return Revocation("BAD_PROVENANCE")
        self.retained[cert.cid] = cert
        self.topics[topic].add(cert.cid)
        return "OK"

    def revoke(self, cid, reason):
        c = self.retained.get(cid)
        if c is not None:
            self.retained[cid] = replace(c, confidence="REVOKED")
        return reason

    def live(self, topic):
        now = self.clock.now()
        return [self.retained[c] for c in self.topics[topic]
                if self.retained[c].alive(now)]

    def fuse(self, now):
        # 双格：几何取交（meet），触觉取并（join）
        hard = self.live("cert/geom_hard")
        soft = self.live("cert/geom_soft")
        tac = self.live("cert/tactile")

        S_hard = meet_all([c.payload for c in hard]) if hard else UNIVERSE
        S_soft = meet_all([c.payload for c in soft]) if soft else self.baseline
        S_tac = join_all([c.payload for c in tac]) if tac else EMPTY

        fused = WitnessGatedFusion.fuse(S_hard, S_soft, S_tac)
        return Certificate(
            cid=content_id((S_hard, S_soft, S_tac)),
            kind="FUSED",
            payload=fused,
            t_pub=now,
            ttl=min((c.ttl for c in hard + soft + tac), default=0.0),
            confidence="CERTIFIED" if tac else "PROVISIONAL",
            provenance=merkle_root([c.cid for c in hard + soft + tac]),
            degrade="V20_BASELINE",
        )


# IP-427 Witness-Gated Fusion
class WitnessGatedFusion:
    @staticmethod
    def fuse(S_hard, S_soft, S_tac):
        # 硬约束永不被触觉推翻；软约束可被有效见证锥覆盖
        return intersect(S_hard, union(S_soft, S_tac))

    @staticmethod
    def verdict(theta, S_hard, S_soft, S_tac):
        if not contains(S_hard, theta):
            return "HARD_UNSAFE"          # 触觉无权推翻硬约束
        if contains(S_soft, theta):
            return "SAFE_SOFT"
        if contains(S_tac, theta):
            return "SAFE_WITNESSED"       # 有见证的扩张（须记入 FL）
        return "UNSAFE"


# IP-428 Certificate Expiry & Degradation Controller
class CertificateExpiryDegradationController:
    TTL = {"GEOM_HARD": 10.0, "GEOM_SOFT": 2.0, "TACTILE": 0.2}

    def __init__(self, aps):
        self.aps = aps
        self.deadlines = {}               # cid -> t_expire

    def register(self, cert):
        self.deadlines[cert.cid] = cert.t_pub + self.TTL[cert.kind]

    def sweep(self, now, bus):
        expired = [cid for cid, t in self.deadlines.items() if now > t]
        for cid in expired:
            bus.revoke(cid, reason="TTL")     # 过期即撤销 P35
            del self.deadlines[cid]
        if not bus.live("cert/tactile"):
            return self.aps.force_mode("V20_BASELINE")
        return self.aps.current_mode()

    def on_deadline_miss(self, subscription, now):
        # QoS deadline 违约 = 安全撤销事件，而非重传事件
        subscription.revoke_all(older_than=now - subscription.deadline)
        return "REVOKED_BY_DEADLINE"


# IP-429 Contact Calibration Monitor
class ContactCalibrationMonitor:
    def __init__(self, obj_model, normal_tol_deg=5.0,
                 residual_tol=2e-3, window=50):
        self.obj_model = obj_model
        self.normal_tol = math.radians(normal_tol_deg)
        self.residual_tol = residual_tol
        self.window = window
        self.buf = deque(maxlen=window)
        self.revoked_sensors = set()

    def observe(self, w, predicted_contact):
        if w.sensor_id in self.revoked_sensors:
            return "REVOKED"
        r_pos = norm(w.x_c - predicted_contact.x)
        r_ang = angle(w.n_c, predicted_contact.n)
        self.buf.append((r_pos, r_ang))
        if self._drift_detected():
            self.revoke_sensor(w.sensor_id, "CALIB_DRIFT")
            return "REVOKED"
        return "OK"

    def check_sign(self, w_prev, w_next, displacement):
        # 沿自由侧退让时接触力应下降；若反而上升，则法向符号反了
        if dot(displacement, w_prev.n_c) > 0 and w_next.force > w_prev.force:
            self.revoke_sensor(w_prev.sensor_id, "SIGN_FLIP")
            return "SIGN_FLIP"
        return "OK"

    def _drift_detected(self):
        if len(self.buf) < self.window:
            return False
        r_pos = [b[0] for b in self.buf]
        r_ang = [b[1] for b in self.buf]
        return (mean(r_pos) > self.residual_tol
                or mean(r_ang) > self.normal_tol)

    def revoke_sensor(self, sensor_id, reason):
        self.revoked_sensors.add(sensor_id)
        return reason


# IP-430 Falsification Ledger
class FalsificationLedger:
    def __init__(self):
        self.entries = []                 # 追加式
        self.root = EMPTY_MERKLE

    def record(self, witness_cid, falsified_soft_cid, cone_cid, t):
        e = LedgerEntry(witness_cid, falsified_soft_cid, cone_cid, t)
        self.entries.append(e)
        self.root = merkle_append(self.root, e)
        return e

    def rollback(self, witness_cid, bus):
        # 撤销该见证支撑的所有扩张；其余见证锥仍可独立覆盖
        affected = [e for e in self.entries if e.witness_cid == witness_cid]
        for e in affected:
            bus.revoke(e.cone_cid, reason="WITNESS_ROLLBACK")
            bus.restore_soft(e.falsified_soft_cid)
        self.entries = [e for e in self.entries
                        if e.witness_cid != witness_cid]
        self.root = merkle_rebuild(self.entries)
        return len(affected)

## 3. 推导

**引理 157（见证锥可靠性）** 设见证 `w` 有效，`g` 为 `L_φ`-Lipschitz，沿自由侧 `u_c` 满足 `∂g/∂u ≥ μ_φ > 0`，且 `|g(θ_c)| ≤ ε_δ`、标定误差 `≤ ε_cal`。则 `C(w) ⊆ S*`。
证明：对任意 `θ = θ_c + s·u_c + v ∈ C(w)`，
`g(θ) ≥ g(θ_c) + μ_φ·s − L_φ‖v‖ ≥ −(ε_δ+ε_cal) + μ_φ·s − L_φ‖v‖`。
由 `s ≥ κ‖v‖ + ε_0 = (L_φ/μ_φ)‖v‖ + (ε_δ+ε_cal)/μ_φ` 得 `μ_φ·s ≥ L_φ‖v‖ + (ε_δ+ε_cal)`，故 `g(θ) ≥ 0`。∎

**引理 158（单侧性与非体积性）** `C(w)` 落在闭半空间 `{u_c·(θ−θ_c) ≥ ε_0}` 内，物体侧 `u_c·(θ−θ_c) < 0` 永不被认证；若去掉锥模型，单次见证只认证测度为零的锚点 `θ_c`。故触觉不能凭"接触过"认证一个体积邻域，必须借助 `L_φ/μ_φ` 模型才能把锚点扩张为锥。∎

**引理 159（双格顺序无关性）** `S_hard = ⋂_{i∈H} S_i`，`S_soft = ⋂_{j∈S} S_j`，`S_tac = ⋃_{k∈T} C_k`。交与并均满足结合、交换、幂等，故 `S_21 = S_hard ∩ (S_soft ∪ S_tac)` 只依赖活证书集合 `H, S, T`，与到达顺序、重复次数、重放无关。∎

**引理 160（过期收缩性）** 若所有触觉证书过期/撤销，则 `S_tac = ∅`，`S_21 = S_hard ∩ S_soft ⊆ S_20`；即 v21 退化为 v20（或更严格）。故过期只会收缩认证集。∎

**引理 161（无见证不扩张）** `S_21 \ S_20 ⊆ S_tac`。
证明：若 `θ ∈ S_21 \ S_20`，则 `θ ∈ S_hard` 且 `θ ∈ S_soft ∪ S_tac`。若 `θ ∈ S_soft ⊆ S_20`，矛盾；故 `θ ∈ S_tac`，即被某条有效 `C(w)` 覆盖。∎

**引理 162（v21 整体可靠性）** 若所有活见证有效且 `S_hard, S_soft ⊆ S*`，则 `S_21 ⊆ S*`。由引理 157 及交/并的子集封闭性立得。∎

**引理 163（回滚可靠性）** FL 为每条 `(witness, 被证伪软证书, 锥)` 建立边；`rollback(w)` 撤销 `w` 的全部锥并恢复被证伪软约束，等价于在 `S_tac` 中删除 `w` 的贡献后重算。仅被 `w` 覆盖的点被移除，被其他有效见证覆盖的点保留。故回滚不会引入无见证点。∎

**引理 164（QoS 降级安全）** 丢包/分区只会减少活证书数，故 `S_tac` 与 `S_soft` 单调缩小；乱序/重复由引理 159 消解；过期由引理 160 收缩。故任何 QoS 退化路径都满足 `S_21(QoS 退化) ⊆ S_21(无退化) ⊆ S*`。∎

## 7. 已知风险与失效模式

1. **触觉伪证（法向符号/标定翻转）**：`n_c` 符号错误或标定偏差使锥指向物体侧，系统"有见证、有签名"却认证碰撞。缓解：CCM 符号一致性检查、双次接触验证、硬约束兜底。
2. **`L_φ/μ_φ` 低估/高估**：`L_φ` 偏小或 `μ_φ` 偏大都会放大锥。缓解：离线最坏情形标定 + 在线保守上界 + 曲率修正。
3. **未建模柔顺障碍**：软线缆/织物接触力低，可能被误判为"安全接触"。缓解：力-位移曲线、对象一致性、柔顺性分类器。
4. **中间件来源伪造**：总线不可信，恶意/故障节点发布伪造证书。缓解：内容哈希 + Merkle 来源链 + 发布者签名。
5. **QoS 过度降级**：短 TTL + 高丢包导致频繁回退 v20，活性坍塌。缓解：分层 TTL、预测性续签、本地缓存。
6. **锥并集不连通**：`S_tac` 为多锥之并，可能出现"点安全但路径不安全"。缓解：规划器在 `S_21` 上做连通性检查，不假设凸性。
7. **回滚依赖不完整**：一个点被多锥覆盖时，撤销单锥的语义需重算而非简单删除。缓解：按集合重算 `S_tac`，FL 记录完整依赖边。
8. **接触几何退化**：棱/角处法向不唯一，平面假设失效。缓解：检测法向方差，退化时收缩为球锥或直接禁用。
9. **传感器迟滞/长期漂移**：触觉膜随时间蠕变，`δ` 与力关系漂移。缓解：定期空载归零、在线基线跟踪。
10. **账本膨胀**：高频接触导致 FL 无界增长。缓解：按 TTL 归档、Merkle 检查点、冷存储。

## 8. 本轮最大风险

**一句话**：CWC 的全部扩张能力都押在"见证有效"上，而法向符号/标定偏差一旦翻转自由侧，安全锥会**把物体侧认证为自由**——此时系统"有见证、有签名、有 Merkle 证明、通过中间件 QoS"，却系统性地产生**被签名的碰撞授权**（"触觉伪证"）。
