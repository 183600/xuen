## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（动作空间 → 模型该学的不是「物体在哪」，而是「相对物体怎么做」）**
直觉：接口把动作空间钉成「基座系 EE xyz+rpy」，于是大多数队伍让网络直接从图像回归基座系绝对位姿。可位置泛化轴（物体在工作空间内随机摆放）改变的正是这个基座系坐标——网络被迫用容量记「物体在哪」，而不是学「怎么抓」。真正反直觉的点：**动作空间是表示，不是约束**。同一个物理动作可写成基座系、躯干系、夹爪系或物体/任务系；换参考系不改变策略能做什么，却改变它需要学什么。把动作写成「相对被操作物体（或目标容器）的位姿」，物体平移/旋转就从回归目标里被解析地消掉了——位置轴从「需要泛化的分布偏移」变成「一次 SE(3) 坐标变换」。

**灵感 2（点云配准 → RGB 接口里其实藏着免费的几何测量）**
直觉：接口没有 depth，看似点云无望；但训练数据卡白纸黑字写着 head 是「已校正双目」，挑战接口的 `cam_left_high/right_high` 正对应左右头相机。若二者同源，**立体匹配就能在推理期零额外传感器地恢复米制点云**。点云配准于是提供了一种与 VLM 互补的测量：VLM 擅长语义（这是什么、该做什么），配准擅长几何（它在哪、差多少、怎么对齐）。对插充电器、插网线、叠碗、试管排列、倒药这类接触/对齐任务，几何测量比语义先验更可靠，且天然给出可解释的误差信号。核心反直觉点：**在只有 RGB 的接口里，位置轴最便宜的解不是更好的图像增广，而是用双目几何把「物体在哪」直接测出来。**

**两者合流：几何等变的动作空间**
把动作定义在由配准得到的物体/任务坐标系 F 里：策略输出 `T_FE`（末端相对 F 的位姿），执行时用当前 `T_WF` 映回世界系。物体被挪动 g，则 `T_WF → g·T_WF`，而同一 `T_FE` 仍给出正确的世界系末端位姿——**策略对物体位姿在标签层面严格等变**，无需见过该摆放。这把「零样本位置泛化」变成「配准精度问题」；把 I1 的近似图像增广升级为精确的 SE(3) 重标注；把 I9 的「检索动作参数」升级为「配准后整条轨迹重定向」；把 I3 的稀疏关键点伺服升级为稠密配准伺服。

**统一结论**：前两轮的胜负手在数据引擎，本轮把胜负手推进到**表示引擎**——**不换模型、不加策略模块，只换动作参考系 + 加一个可门控的几何测量前端，就能同时改善位置轴、接触对齐与示教迁移。**

## 2. 严谨定义（先直觉，后形式化）

### 2.1 动作空间 = 参考系选择

设世界/基座系为 W，末端（夹爪基座）位姿 `T_WE ∈ SE(3)`，参考系 F 的位姿 `T_WF ∈ SE(3)`。

- **接口动作**：每臂返回 `(p, rpy)`，即 `T_WE^cmd`；另有 `gripper`、`pivot`。
- **基线原生相对动作**（F24）：`a_t = T_{E_t}^{-1} T_{E_{t+1}}`（或在 W 对齐的增量）。
- **物体系动作（本方案）**：策略输出目标末端相对 F 的位姿

```text
b_t = T_F^{-1} · T_{E_{t+1}}          （T_FE：末端在参考系 F 中的位姿）
执行：T_WE^cmd = T_WF · b_t
```

关键区别只在「乘在左边的是 `T_WE^t` 还是 `T_WF`」。前者把物体全局位姿留在回归目标里，后者把它解析消去。

### 2.2 标签层面的等变性（命题 + 证明 + 边界）

**命题**：若物体与期望末端同时被 `g ∈ SE(3)` 变换，即 `T_WF' = g T_WF`、`T_WE' = g T_WE`，则物体系目标不变：

```text
T_F'E' = (T_WF')^{-1} T_WE' = (g T_WF)^{-1}(g T_WE) = T_WF^{-1} T_WE = T_FE
```

即策略只需学 `T_FE`，与物体在工作空间中的摆放无关。**这是标签层面的精确等变**，不依赖数据增广。

**边界（必须写进实验，否则是过度声称）**：
1. 机器人基座固定、相机固定，物体移动会改变可达性/关节限位/自遮挡——所以是**部分等变**，只在工作空间可达域内近似成立；
2. 重力、支撑面、插入轴等任务语义定义在 W 中，纯物体系可能把「该往哪个方向用力」也一并旋转掉——所以引入**任务系**（见 2.5），而非一律用物体系；
3. 视觉编码器仍看到物体在不同像素位置；若要拿到完整收益，需把配准位姿/物体中心裁剪作为额外观测 token（I10b），或做物体中心化裁剪。

### 2.3 点云配准作为测量

**立体深度**（仅当 F27 成立）：对已校正双目，视差 `d(u,v)` 与米制深度

```text
Z(u,v) = f · B / d(u,v)          f=焦距(px)，B=基线(m)
X_cam  = Z · K^{-1} [u, v, 1]^T
X_W    = T_WC · X_cam            T_WC 由 FK/标定/state_d435 得到
```

**配准**：给定物体模板点云 `P={p_i}`（物体系）与当前观测点云 `Q={q_j}`（世界系），求

```text
T_WO = argmin_{T∈SE(3)} Σ_i ρ( dist(T p_i, Q) )
```

`ρ` 为鲁棒核；先粗配准（学习特征/FPFH）再 point-to-plane ICP 精配。单视角、部分遮挡 → 只对可见部分求对应，输出**置信度**

```text
c = inlier_ratio · exp(-RMSE/σ) · overlap
```

`c < τ` 时禁止使用物体系动作，退回基座系（I10 的止损闸）。

**对称性**：物体常有连续对称群 `S ⊂ SE(3)`（如杯子绕竖直轴）。此时配准只在商空间 `SE(3)/S` 上可辨识：`T_WO` 与 `T_WO·s`（s∈S）等价。处理：只固定任务相关轴（插入轴/重力轴/抓取轴），对其余自由度做规范化，或直接在商空间定义动作。

### 2.4 配准轨迹重定向（one-shot imitation）

示教 d：物体系 P、示教物体位姿 `T_WP^d`、末端轨迹 `T_WE^d(t)`。先写成物体相对轨迹：

```text
T_PE^d(t) = (T_WP^d)^{-1} · T_WE^d(t)
```

当前场景配准得到 `T_OP`（P→当前物体系 O 的变换）与 `T_WO`。则示教物体系在当前世界中的位姿为 `T_WO · T_OP`，重定向轨迹：

```text
T_WE^new(t) = T_WO · T_OP · T_PE^d(t)
```

用途：作为扩散/流匹配动作头的**先验轨迹/候选初值**，或高置信时直接作为回退轨迹。对未见物体轴，只要配准能在类别模板上成功，轨迹即可迁移。

### 2.5 相位相关参考系（PR6）

被操作物体会动，物体系不是静止参考系。按相位选 F：

| 相位 | 参考系 F | 理由 |
|---|---|---|
| approach / grasp | 被操作物体 O | 抓取前物体静止；消去摆放 nuisance |
| transport | 躯干 T（或 EE） | 物体随手动，物体系变成非惯性系；躯干近似静止 |
| place / insert | 目标容器/插座 R | 目标静止，误差直接对应任务成功 |
| release | R | 同上 |

相位由夹爪开合、进度头、配准残差/接触代理共同判定；切换需滞回，切换失败退回基座系。

## 3. 创新点详表

### I10 配准等变动作空间 ★★★★★（新）

- **动机**：位置轴（物体随机摆放）是 32 任务 × 全部评测的全局乘性损失；基线原生相对动作仍以基座/上一 chunk 为参考，物体全局位姿留在回归目标中（F24）。
- **与现有方案差异**：别人换更大模型/更多数据；本点**不换模型**，只换动作参考系（物体系/任务系）+ 内部 6D 旋转表示，并用配准提供参考系。与 I1 互补：I1 补外观/背景/干扰物，I10 精确消位置。
- **技术可行性**：中-高。核心是动作标签重写（离线、免费）+ 推理期几何变换（确定性、<1ms）+ 配准前端（见 §4）。前提 F27。
- **所需资源**：无新增训练数据；离线伪 GT 物体位姿 1×GPU 日；配准前端 CPU/GPU 均可。
- **落地步骤**：①E0 验证双目与标定；②先做「躯干系 vs 基座系」低风险消融（F26 有现成标签）；③离线用双目 + 分割 + 配准造物体伪 GT；④把训练标签改写到物体系，内部 6D 旋转、输出转 rpy；⑤推理加配准与置信门控；⑥L0 动作空间消融 → L2 真机。
- **三闸**：计分轴对齐=位置轴直接命中（★★★★★）；单模型边界=动作重参数化 + 确定性几何变换，另有 I10b（配准结果当观测 token）纯单模型保底，仍需书面确认；部署预算=配准 reset + 每 K chunk 更新，摊销 <5ms/步。
- **风险**：F27 证伪 → 降级单目；配准错 → 置信门控 + 基座系回退；对称物体 → 商空间/任务轴；相位选错参考系 → PR6 + 滞回。

### I1 v3 考纲校准五轴增广（位置轴改为精确重标注）★★★★★

- **本轮修剪**：v1.1 的「位置轴图像重拼接」有物理不可行风险。I10 的物体系标签已解析消去物体全局位姿，**位置轴不再需要高风险图像拼接**——把位置轴交给 I10，I1 专注外观/背景/干扰物/光照，风险下降。
- **精确 SE(3) 增广**：若需显式位置增广，用官方 Isaac Lab 仿真（F14）把物体放到采样位姿重渲染，动作标签按 `g·T_WE` 精确变换；这比图像 inpainting 物理一致。
- **维持**：考纲卡、剂量-响应、轴间析因；判据不变。

### I2 v3 数据引擎 2.0（参考系对齐的孪生迁移）★★★★★

- **本轮微调**：孪生示教入训前先对齐到任务系/物体系再共训——消除「不同摆放」这一伪方差，让同一技能的多条示教在动作空间里真正重叠，提升流匹配多模态覆盖。
- **不解决的问题**：ZipUp↔Unzip 这类**动力学方向相反**的负迁移不会因换系而消失；家族级 L0 消融仍是放量前置（v1.1 风险保留）。
- 加权 patch、质量加权、远任务低权重维持。

### I3 v3 接触任务族稠密配准伺服 ★★★★

- **升级**：v1.0 稀疏关键点 → **稠密点云配准**。对插入/对齐任务（PlugCharger、PlugInEthernet、StackBowls、ArrangeTestTubes、PourOutMedicine、Unlock）配准物体与目标容器，得到相对位姿误差，叠加到策略 chunk 上做最后几毫米闭环。
- **视觉接触代理**：配准残差不再下降 ≈ 已接触；据此降速/停推，部分替代缺失的力觉（P4）。
- **触发**：仅在配准置信度高、残差进入阈值带时启用，滞回退出；低置信回退 I3 关键点或纯策略。
- **单模型边界**：几何伺服是控制器，仍按 v1.1 的 I3' 预案（若被判违规，改为训练时辅助监督，推理纯端到端）。

### I4 人手干预感知门控 + 自适应 chunk ★★★★（维持）

- 维持 v1.1 六要素；新增联动：配准每 K 个 chunk 更新，K 与干预态 chunk 长度一起自适应（稳定态长 chunk、干预态短 chunk + 立即重配准）。

### I5 非标称示教合成 + 得分点恢复 ★★★★（维持）

- 维持 v1.1；新增：合成示教也统一写到物体系再训练，扰动重放（物体位姿 ±δ）在物体系里等价于「同一相对动作 + 不同摆放」，标签更一致，减少合成/真实分布失配。

### I6 确定性低延迟部署 ★★★★（维持）

- 维持 v1.1；新增算力项：立体深度 + 分割 + 配准。预算：深度/分割/配准在 reset 与每 K chunk 执行；K≥4 时摊销 <5ms/步。若超预算，降级顺序：配准降频 → 深度分辨率减半 → 单目深度 → 关闭 I10 主路径。

### I7 世界模型测试时前瞻 ★★（缓）（维持）

- 维持待裁撤观察；新增用途：世界模型/WMA-0 可离线生成多视角/多摆放数据，用于配准模板补全与 I5 合成，裁撤推理路径不等于废弃资产。

### I8 v3 评测运营 + 分级消融（新增动作空间轴）★★★★

- **新增消融轴**：动作空间/参考系作为一等公民（A0–A6，见 §5 E2）；这是本轮最便宜、信息量最大的离线实验。
- **配准置信度校准**：画 reliability diagram，只有「置信度–真实误差」校准良好的区间才允许自动使用先验；注册表新增「配准置信度 → 真机增益」条目。
- L0/L1/L2 分级与注册表机制维持。

### I9 v2 配准轨迹重定向（one-shot imitation）★★★★

- **升级**：v1.1 检索「动作参数」→ 检索「整条示教轨迹」并用配准 warp 到当前场景（§2.4）。
- **门控**：配准置信度 + IK 可达性 + 轨迹平滑度三重过滤；任一失败退回 VLA 原动作。
- **对未见物体轴**：用类别模板或同任务示教物体云做配准；几何差异大时自然低置信 → 回退，不伤标称。

## 4. 关键伪代码

### 4.1 双目点云 + 物体配准 + 置信门控

```python
def stereo_cloud(obs, K, B, f):
    L = obs["observation.images.cam_left_high"][-1]     # 480x640x3, rectified
    R = obs["observation.images.cam_right_high"][-1]
    d = stereo_matcher(L, R)                            # horizontal disparity
    Z = f * B / np.maximum(d, 1e-3)                     # metric depth (F27 前提)
    return backproject(Z, K)                            # HxWx3, camera frame

def estimate_object(obs, task, template_P, T_WC):
    Q = transform(T_WC, stereo_cloud(obs, task.K, task.B, task.f))
    mask = open_vocab_segment(obs, task.object_prompt)  # SAM2 / detector
    Q = Q[mask]
    T0 = coarse_register(Q, template_P)                 # learned feat / FPFH
    T_WO, info = icp_point_to_plane(Q, template_P, T0, robust="gm")
    conf = info.inlier_ratio * np.exp(-info.rmse / SIGMA) * info.overlap
    T_WO = canonicalize_symmetry(T_WO, task.symmetry)   # 商空间/任务轴
    return T_WO, conf

def template_from_demos(task, demos):
    clouds = []
    for ep in demos:
        for t in keyframes(ep):
            Q = transform(ep.T_WC[t], stereo_cloud(ep.obs[t], ep.K, ep.B, ep.f))
            clouds.append(Q[open_vocab_segment(ep.obs[t], task.object_prompt)])
    P_world = fuse(clouds)                              # 多帧融合
    return transform(inv(task.T_WO_canonical), P_world) # 物体系模板
```

### 4.2 等变动作空间：训练标签与推理执行

```python
def encode_rot(R):  return R[:, :2].reshape(-1)         # 连续 6D 表示
def decode_rot(v):  return gram_schmidt(v)              # -> SO(3)
def pose_vec(T):    return np.r_[T[:3, 3], encode_rot(T[:3, :3])]

def action_label(T_WE_future, T_WF):
    T_FE = inv(T_WF) @ T_WE_future                      # 目标末端在参考系 F 中
    return pose_vec(T_FE)                               # 训练回归目标（标签层面等变）

class EquivariantPolicy:                                # 仍是单个 PolicyService
    def get_action(self, obs, phase):
        T_WF, conf = self.select_frame(obs, phase)      # §4.4, PR6
        if conf < TAU_REG:                              # 止损闸
            T_WE = self.model(obs, frame_token=None)    # 基座系回退（同一模型）
        else:
            frame_token = encode_pose(T_WF)             # I10b：配准结果当观测 token
            T_FE = self.model(obs, frame_token=frame_token)
            T_WE = T_WF @ T_FE                          # 确定性几何映射
        return to_interface(T_WE, gripper=..., pivot=...)   # xyz+rpy 转换，rpy 连续展开
```

### 4.3 配准轨迹重定向 + 三重门控

```python
def retarget(demo, T_WO_cur, T_OP, conf, ik):
    if conf < TAU_REG:
        return None
    T_WP_cur = T_WO_cur @ T_OP                          # 示教物体系在当前世界的位姿
    traj = [T_WP_cur @ (inv(demo.T_WO) @ T) for T in demo.T_WE]
    traj = [T for T in traj if ik.reachable(T)]
    if len(traj) < 0.8 * len(demo.T_WE):                # 可达率门控
        return None
    return smooth_traj(traj)                            # 先验 / 候选初值

# 用法：prior = retarget(...); chunk = model.propose_chunk(obs, prior=prior)
```

### 4.4 相位相关参考系选择 + 配准自校验

```python
def select_frame(obs, phase):
    T_WO, cO = estimate_object(obs, ...)                # 被操作物体
    T_WR, cR = estimate_receptacle(obs, ...)            # 目标容器/插座
    T_WT = fk.torso(obs)                                # 躯干，来自 lower_body
    if phase in ("approach", "grasp"):     return T_WO, cO
    if phase == "transport":               return T_WT, 1.0
    if phase in ("place", "insert", "release"): return T_WR, cR

def registration_selfcheck(ep):
    # 抓取稳定段：物体位姿应 = 夹爪位姿 ∘ 固定抓取偏移 T_EG
    errs = [log(inv(T_WE @ T_EG) @ T_WO) for T_WE, T_WO in grasp_interval(ep)]
    return rmse(errs)                                   # 无标签的配准精度校验
```

## 9. 本轮最大风险（一句话）与最值得押注

**最大风险**：整套方案把命押在「`cam_left_high/right_high` 就是训练数据里那对已校正、基线已知的 head stereo」这一未核实假设（F27）上——若标定/基线不符，立体深度尺度就错，配准随之错，物体系动作与轨迹重定向全盘失效，而且配准前端还可能触碰「单模型」红线。

**最值得押注**：**押「换参考系」而不是「换模型」——I10（配准等变动作空间）+ I3 v3（配准伺服）**；用同一套双目几何同时吃掉位置轴、接触对齐与示教重定向三块分数，并以 I10b（配准结果当观测特征）作为单模型合规的保底实现。
