# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「创新点挖掘」×「创新点提炼」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**可辨识挖掘 + 证据化提炼 + 防自证**。两个近义灵感不是重复，而是一个闭环的两端：挖掘负责"从残差与历史里找到候选机制"，提炼负责"把候选压缩成最小充分且可证伪的创新集"。它们共同治理 v9 最深的一笔债——**叙事债**：14 个 IP 里究竟哪些真正挣得了算力与论证，系统从未给出可检验的答案。必须保证：挖掘/提炼/证据闸任一失效都注入中立元（空集 / 恒等提炼 / 冻结分级），严格等价退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（创新点挖掘 → 残差与语料双源挖掘）**
直觉：真正的创新点不写在标题里，而藏在"现有模块解释不了的残差"里。v9 已有完整的六层指标账本与消融信号，却只把它们用于逐模块 EMA（ID）。若把残差 r(t)=观测−当前机制组合的预测，对一组"机制签名"做稀疏编码，非零、稳定、可复现的支持集就是**创新机会**；再从跨轮语料中挖掘结构化机制原子，扩充字典并去重。核心创新：**创新原子挖掘器（InnovationAtomMiner, IAM）**——残差稀疏编码 + 语料谱系挖掘，输出带谱系、证据位、证伪条件的候选原子。与 v9 ID 的关键区别：ID 只在**已知模块**上做边际归因，IAM 要发现**尚不在当前组合里**的机制候选。

**灵感 2（创新点提炼 → 最小充分创新集 MSIS）**
直觉：候选原子越多不等于创新越多，常常是同一机制的多次改名。提炼 = 在安全约束与证据门槛下，解一个"最小集合覆盖最大已解释残差"的问题，并对高相似原子做保守合并（证据取 min）。核心创新：**创新提炼器（InnovationDistiller, ID²）**——子模覆盖的约束贪心，输出**最小充分创新集（MSIS）**与冗余商；被提炼掉的原子"退役不删除"，保留签名与证据，随时可检索复活（延续 v9 的 P12 提炼不删码律）。

**灵感 3（两者的耦合 → 挖掘-提炼-证伪闭环与反通胀）**
直觉：挖掘和提炼若共用同一批数据、且自己给自己打分，就会自证。核心创新：**证据闸与预注册账本（EvidenceLedger & Falsification Gate, EFG）**——每个原子在观测结果前先哈希提交证伪判据，证据只在外部、预注册测试后单调升级；"改名/套皮重述"必须被结构新颖度（依赖子图同构）识破。三件套合起来把"创新点"从修辞变成可审计对象：**可挖、可压、可杀**。

## 1. 研究问题（轮次升级版）

- **Q1（可辨识挖掘）**：在模块激活与上下文强相关的观测数据下，残差挖掘能否把"真实边际贡献"与"相关/混杂"分开？需要多少随机开关探测预算才能达到给定置信？
- **Q2（安全提炼）**：丢弃/合并/退役在什么条件下保证不触碰 v9 九不变式？最小充分集与全集的残差解释差如何界定，贪心的 (1−1/e) 界在带安全硬约束时是否仍成立？
- **Q3（反自证）**：如何设计证据格、预注册与结构新颖度，使账本无法通过"重新命名 / 挑选数据 / 事后解释"自我升级？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 挖掘可辨识律（Mining Identifiability, IAM）**
创新点必须是**可辨识**的：观测性边际贡献只有在混淆界 Γ ≤ Γ_max 时才被采信；否则必须用随机开关探测（interventional probe）估计，探测预算 T 由目标误差 ε_c、置信 δ、候选数 |A| 显式给出（引理 89）。不可辨识的原子只能标记为"相关物"，不得进入创新账本。

**P14 提炼保核律（Distill-Preserve-Core, ID²）**
提炼只允许三类操作：丢弃 φ^elig=true 的原子、合并**不变式标签完全相同**的原子、退役（保留可检索）。安全不变式集是硬约束而非软罚项；MSIS 必须满足 f(S) ≥ (1−ε)·f(A) 的覆盖下界，且按反向删除取最小。任何触碰安全不变式的原子永不进入提炼候选，其贡献记为 ∞。

**P15 证据单调律（Evidence Monotonicity, EFG）**
证据级 ε ∈ {E0 轶事, E1 同数据消融, E2 预注册留出, E3 独立复现, E4 形式化+实证}。升级只能通过**结果观测前哈希提交**的外部测试；合并取 min；证伪只降级、不删除。结构新颖度用依赖子图同构计算，"改名"（语义相似高、结构同构、证据无增）一律判为旧点重述。

## 3. 与基线的接口（如何退化）

- IAM 失效 ⇒ 原子集置为 v^⊥=∅（集合并的恒等元），仅保留 v9 ID 逐模块 EMA，等价 v9；
- ID² 失效 ⇒ 恒等提炼（全集保留、不合并），等价 v9 全模块常开；
- EFG 失效 ⇒ 证据分级冻结、不升不降，模块配置不变，等价 v9；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 表 536 注入中立元，等价 v8；
- 全部失效 ⇒ 完整退回 v9 ACMD → v8 → v7 → v6。

## 4. 预期贡献

1. **残差-语料双源创新挖掘**：把"新机制从哪来"变成可复现的稀疏支持集 + 谱系图，而非头脑风暴；
2. **最小充分创新集（MSIS）**：带安全硬约束与覆盖下界的创新组合压缩，附冗余商、"退役可复活"；
3. **证据闸 + 预注册哈希 + 结构新颖度**：可证伪、抗改名、抗 HARKing 的防自证账本；
4. **自应用预注册审计**：用 E579/E580 对 v9 的 14 个 IP 做承重测试，预注册地判定哪些是真机制、哪些是叙事合成。

## 5. 本轮最大风险

**一句话**：挖掘与验证共用同一残差/消融信号、且候选字典来自对自身历史语料的检索，选择偏差与字典闭环会把噪声蒸馏成"创新点"、把套皮重述认成新机制——账本越自洽，越可能只是自证。

## 1. 符号体系增量（定义 540–547）

| 符号 | 含义 |

**新增定义 540（创新原子 InnovationAtom）** α = (μ_α, ι_α, σ_α, D_α, ε_α, κ_α, h_α)。μ 为机制规范（可执行描述），ι⊆{CVC,SpatialCert,RT-CVC,FaultCert,PrimitiveGraph,退化链,OTL,GCT,ER} 为其触及的不变式集，σ 为残差字典基，D 为依赖的原子集合（谱系 DAG），ε 为证据级，κ 为预注册证伪判据（写死的数值门槛），h 为结果前哈希承诺。

**新增定义 541（残差-机制字典 ResidualMechanismDictionary）** 给定字典 Φ，稀疏编码
```
z(r) = argmin_z  ½‖r − Φz‖² + λ‖z‖_{2,1}
```
用分组 Lasso 得到稀疏支持；再以 W 个自举窗做稳定性选择，选择频率 ≥ π_stab 的原子进入候选。残差字典的**离线端**由语料挖掘扩充：从跨轮文本抽取结构化三元组 (机制, 不变式, 证据) 并建谱系图，避免"只挖已知库"的闭环退化。

**新增定义 542（创新点挖掘 Mining / 可辨识性）** 候选原子 α 升格为**创新点**当且仅当三条件同时成立：
```
(i)   选择频率 freq(α) ≥ π_stab                    （稳定，非噪声）
(ii)  |ĉ_α − c_α| ≤ ε_c，由随机开关探测达成          （可辨识，非相关）
(iii) n_struct(α) ≥ θ_N 且无同构旧原子              （结构新颖，非改名）
```
仅满足 (i) 者为"相关物(correlate)"，仅满足 (i)(ii) 但结构同构者为"重述(restatement)"，二者均不入账本。

**新增定义 543（创新点提炼 Distillation / MSIS）** 在安全硬约束下求
```
S* = argmax_{S⊆A_adm} f(S)
     s.t. |S| ≤ B,  D-闭包,  safety-admissible(S),
          ε_α ≥ E2  ∀α∈S,  f(S) ≥ (1−ε)·f(A_adm)
```
其中 A_adm 为通过安全谓词与证据门槛的候选集，f(S)=Σ_{i∈∪_{α∈S}R_α} w_i（加权残差分量覆盖，单调子模），R_α 为 α 解释的残差分量集。最小性：对 S* 做反向删除，直到任一原子删除都会使覆盖低于下界。输出 MSIS、冗余商 R(S*)、退役集 A_adm\S*（保留签名与证据，可复活）。**v9 ID 是它的单模块特例**：当 |A_adm|=1、f 退化为单模块 EMA 时，定义 543 与 v9 定义 537/538 一致。

**新增定义 544（冗余与新颖度 Redundancy / Novelty）**
```
sim(α,β) = λ_s·cos(emb(μ_α),emb(μ_β)) + λ_g·subgraph_iso(D_α,D_β) + λ_i·Jaccard(ι_α,ι_β)
```
合并规则：sim ≥ θ_red 且 ι_α=ι_β ⇒ 合并为新原子，证据取 min(ε_α,ε_β)，证伪判据取合取。语义新颖度 n_sem=1−max_{β∈prior}cos；结构新颖度 n_struct 以依赖子图非同构为准。**改名判据**：n_sem 高（措辞不同）但 subgraph_iso≈1、ι 相同、ε 无增 ⇒ 判为重述而非创新。

**新增定义 545（证据格与预注册 EvidenceLattice）** 全序 E0≺E1≺E2≺E3≺E4。部署准入门槛为 E2。升级协议：测试前将 h_α=H(κ_α‖预测效应‖分析计划) 写入只追加账本并公开；测试后若 κ 触发则降一级（只降不删），否则升一级（每次仅一级）。合并取 min；任何"看到结果再改判据"的升级一律无效。该机制把 v9 P12 的"提炼不删码"从代码层推进到**研究主张层**。

**新增定义 546（可辨识性与混淆界 Identifiability / Confounding）** 观测估计的偏差满足 b_α ≤ Γ·‖φ_α‖·κ_Γ；若 Γ ≥ Γ_max 则禁止观测性归因，必须用随机开关探测。T 个独立探测下，Hoeffding + 并集界给出
```
Pr( max_{α∈A} |ĉ_α − c_α| > ε_c ) ≤ 2|A|·exp(−2Tε_c²/σ²)
⇒ T ≥ (σ²/(2ε_c²))·ln(2|A|/δ)
```
故"分离创新与相关"的代价是可计算的探测预算，而不是口号。

**新增定义 547（创新账本状态机 InnovationLedgerFSM）** st_α: candidate→mined（稳定支持）→identifiable（探测通过）→admitted（ε≥E2）→kept（∈MSIS）或 retired（被提炼掉，保留可检索）；任一状态在独立复现失败时→falsified（ε 降级、代码/签名保留）。迁移需迟滞：admitted 需连续 H_mine 个挖掘窗稳定，retired 需连续 H_ret 个提炼周期判冗余，falsified 需 E3 复现失败；防止账本抖动（引理 92）。

## 2. 形式化定义（要点与升级）

## 3. 关键算法骨架

```python
# 账本数据类
@dataclass
class InnovationAtom:
    id: str
    mechanism: str            # μ
    invariants: frozenset     # ι
    signature: np.ndarray     # σ (T×d)
    deps: frozenset = frozenset()   # D
    grade: int = 0            # ε ∈ {0..4} = {E0..E4}
    kill: str = ""            # κ
    commit: str = ""          # h

# IP-357 IAM：残差 + 语料双源挖掘
class InnovationAtomMiner:
    def __init__(self, dictionary, lam=0.05, W=12, pi_stab=0.8,
                 theta_N=0.3, eps_c=0.02, probe_budget=400):
        self.dic = dictionary
        self.lam, self.W, self.pi_stab = lam, W, pi_stab
        self.theta_N, self.eps_c = theta_N, eps_c
        self.T_probe = probe_budget

    def residual_code(self, ledger, S_active):
        r = ledger.y - ledger.predict(S_active)          # 定义 541
        z = group_lasso(r, self.dic.Phi, self.lam)
        freq = bootstrap_support_freq(r, self.dic.Phi, self.W)
        return {a.id: (z_a, freq[a.id])
                for a, z_a in zip(self.dic.atoms, z)}

    def corpus_mine(self, rounds):                        # 离线端：扩充字典
        claims = extract_claims(rounds)                   # (机制, 不变式, 证据, 依赖)
        return build_lineage_and_dedupe(claims)           # 定义 544

    def identify(self, atom, probe):                      # 定义 542(iii)/546
        c_hat, half = probe.marginal(atom.id, T=self.T_probe)
        return abs(half) <= self.eps_c and self.is_structurally_novel(atom)

    def mine(self, ledger, S_active, probe):
        code = self.residual_code(ledger, S_active)
        cand = []
        for a in self.dic.atoms:
            z_a, freq = code[a.id]
            if freq >= self.pi_stab and z_a != 0.0:       # 条件 (i)
                if self.identify(a, probe):               # 条件 (ii)(iii)
                    cand.append(a)                         # 升格：创新点
        return cand

# IP-358 ID²：安全硬约束的子模覆盖约束贪心
class InnovationDistiller:
    def __init__(self, eps=0.05, theta_red=0.75):
        self.eps, self.theta_red = eps, theta_red

    def distill(self, cand, B, safety_oracle):
        A = [a for a in self.merge_redundant(cand)        # 定义 544
             if a.grade >= 2 and safety_oracle.admissible(a)]
        S = self.safe_greedy(A, B, safety_oracle)         # 引理 88
        floor = (1 - self.eps) * self.coverage(A)
        for a in sorted(S, key=lambda a: self.marginal(S, a)):
            if self.coverage(S - {a}) >= floor:           # 反向删除求最小
                S.remove(a)
        return MSIS(S, redundancy_quotient=self.ratio(S),
                    retired=set(A) - set(S))              # 退役不删除

    def safe_greedy(self, A, B, oracle):
        S = set()
        while len(S) < B:
            feasible = [a for a in A - S
                        if oracle.admissible(S | {a})]    # 安全硬约束
            if not feasible:
                break
            best = max(feasible, key=lambda a: self.marginal(S, a))
            if self.marginal(S, best) <= 0:
                break
            S.add(best)
        return S

    def merge_redundant(self, cand):
        out = list(cand)
        changed = True
        while changed:
            changed = False
            for i, j in combinations(range(len(out)), 2):
                a, b = out[i], out[j]
                if (sim(a, b) >= self.theta_red
                        and a.invariants == b.invariants):
                    out[i] = merge(a, b)                  # 证据取 min
                    out.pop(j); changed = True; break
        return out

# IP-359 EFG：预注册 + 单调证据
class EvidenceGate:
    def commit(self, atom, kill, predicted_effect, plan):
        atom.kill = kill
        atom.commit = sha256(f"{kill}|{predicted_effect}|{plan}")
        return atom

    def evaluate(self, atom, external_result):
        if external_result.triggers(atom.kill):
            atom.grade = max(0, atom.grade - 1)            # 证伪降级，不删
        else:
            atom.grade = min(4, atom.grade + 1)            # 单调升级，一次一级
        return atom
```

## 4. 推导

**引理 87（提炼保核与 v9 位级等价）** 若 S* 仅由定义 543 的合法操作得到（丢弃 φ^elig=true 原子、合并 ι 相同的原子、退役保留可检索），则 v9 九不变式仍成立；且所有安全端口上的读数与 v9 对应配置逐位一致。证明：φ^elig=false 的原子（含 M₀ 硬检查、SpatialCert、FaultCert、MW、AC 证书检查）永不进入 A_adm，故安全端口计算图不变；合并仅发生在 ι 完全相同的原子，其 |ι| 与语义不变，输出端口聚合算子与中立元按表 536 保持，故安全端口读数不变；退役在运行期等价于 dormant ≡ 注入 v^⊥（v9 引理 83/84），退役原子签名保留可检索。由 v9 引理 80–81 传递得安全。∎

**引理 88（受约束贪心覆盖界）** f 为单调子模函数，约束 |S|≤B、D-闭包、safety-admissible 均为向下封闭（若 S 可行，则任意子集可行）。则 safe_greedy 返回的 S 满足 f(S) ≥ (1−1/e)·f(S*_adm)，且反向删除不破坏可行性。证明：子模最大化在基数约束下的标准 (1−1/e) 界；安全约束因是"剔除型"向下封闭谓词，safe_greedy 每步只在可行超集上选最大边际元，等价于在可行拟阵外再筛，边际递减性质保持，界不劣化；反向删除只删元素，向下封闭保证仍可行，覆盖率按 floor 校验。∎

**引理 89（可辨识性与探测预算）** 在 σ²-次高斯残差与随机开关探测下，若
```
T ≥ (σ²/(2ε_c²))·ln(2|A|/δ)
```
则 max_α|ĉ_α−c_α|≤ε_c 以概率 ≥1−δ；若观测混淆 Γ≥Γ_max，则观测性归因不可采信，必须用探测。证明：Hoeffding 单侧界 + 对 |A| 个原子并集界；观测偏差 b_α≤Γ‖φ_α‖κ_Γ 由定义 546，Γ 超阈时偏差不可被 ε_c 吸收，故排除观测性估计。∎

**引理 90（证据单调与反自证）** 在 h_α 于结果前提交且账本只追加的假设下，任何原子无法通过改名或事后调整判据升级 ε；"重述"被结构新颖度判据拦截。证明：升级函数只读取 (κ,h,external_result)，h 绑定分析计划，若结果后改 κ 则 h 不匹配、升级被拒；改名原子与旧原子 subgraph_iso≈1 且 ε 无增，按定义 544 判为重述，不入账本。∎

**引理 91（预算中性 / 50Hz 守恒）** IAM/ID²/EFG 全部运行在后台契约（周期 500ms，优先级最低，Ŵ_bg≤50ms），其 v^⊥ 为"本周期不产出新原子/恒等提炼/冻结分级"。因此单控制周期总执行仍 ≤ v9 的感知 2ms + 决策 20ms，50Hz 不变；账本仅在块边界影响 dormant 集合，影响频率 ≤5Hz。∎

**引理 92（账本稳定性 / 无 Zeno）** 定义 547 的迟滞（H_mine、H_ret）与"每次只升降一级"使相邻状态迁移间隔 ≥ H·T_bg；在固定证据下迁移次数有限；复现失败只降一级且不会在同一证据下反弹。故账本在有限时间内的升降次数有界，不出现 promotion/demotion 抖振。∎
