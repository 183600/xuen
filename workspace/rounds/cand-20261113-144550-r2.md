# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 2 轮；本轮灵感：「边缘计算」×「决策规划」）

> 第 67 轮 SimRAS 把闭环升级为「离线仿真预训练 + 在线世界模型 + 视觉问答审计」，但它默默假设了三件事：**算力是集中的、通信是可靠的、决策是单层的**。真实部署里，机器人本体（MCU/NPU）、边缘网关、云节点构成异构三级算力；规划必须在 10ms 级抖动、带宽受限、随时可能断连的条件下，做出从「几十秒的子目标」到「几十毫秒的力矩」的分层决策。
>
> 本轮的核心命题是：
>
> **把「集中式仿真增强闭环」升级为「边缘分布式分层决策闭环（EDGE-RAS）」，用可移植证书信封（PCE）把「云端的长期规划」与「本体端的实时安全」在延迟/带宽/能量约束下焊接起来。**
>
> EDGE-RAS 问的不是「未来风险是什么」，而是「**这份关于未来的结论，在一个会延迟、会断连、会版本错配的分布式系统里，还能被信任多久、被谁执行、以多少代价执行**」。

## 0. 直觉与动机

**灵感 1（边缘计算 → 算力分层，决策必须解耦）**
直觉：SimRAS 的在线环路虽然号称 <3ms，但它把 WM 推理、风险缩放、认证前缀都压在本体端，实际是把「云级模型」硬塞进「端级算力」。边缘计算的常识相反：**让每一层只做它算得起、也等得起的那部分决策**。云端算力充裕但延迟高，适合长时程子目标规划与大规模 WM；边缘网关有中等算力与低延迟，适合动作块规划与跨节点一致性校验；本体只有微秒级预算，适合执行「已被认证的前缀」+ 本地安全兜底。

**灵感 2（决策规划 → 契约化分层，而非轨迹传递）**
直觉：经典分层规划传的是「轨迹」或「子目标点」，但轨迹在传输中一旦过期就毫无意义。决策规划的正确抽象是**契约**：上层承诺「在未来 D 秒内、在区域 V 内、以风险预算 b 完成子目标 g」，下层承诺「在截止前执行完一个认证前缀」。契约 = 载荷 + 有效期 + 有效区域 + 风险界 + 来源证明。这样，**延迟不再破坏正确性，只是消耗契约的剩余有效期**——这正是把「时间」从敌人变成可定价资源的关键。

**灵感 3（边缘计算 → 延迟是新的风险维度，而非噪声）**
直觉：SimRAS 的 C-RAS 是同步认证：在 t 时刻算出的 k* 默认在 t 时刻执行。但边缘系统里，云端结论到达本体时已经是 t+δ；δ 还是重尾的。一个在 t 时刻安全的前缀，到 t+δ 可能已经越界。于是必须定义**延迟不变认证前缀**：对最坏延迟 δ_max 仍成立的安全前缀。它给出一条可计算的「安全长度随延迟线性收缩」的规律，而不是让系统在延迟稍大时直接失效。

**灵感 4（决策规划 → 通信与探针本身就是决策）**
直觉：第 66 轮 FAS 的「情绪探针」和第 67 轮的上云审计，本质上是同一类动作——**花钱买信息**。决策规划应把它们统一进动作空间：`query_cloud / probe_emotion / wait_for_plan / switch_tier`。是否发起，由信息价值（VoI）决定：只有当「预期风险下降」超过「延迟代价 + 能量代价 + 失败概率」时才做。这把「通信」从被动约束升级为主动规划变量。

**灵感 5（边缘计算 × 决策规划 → EDGE-RAS：可移植证书信封）**
合流：用分层决策规划（HDP：L3 云 / L2 边 / L1 端）产出**可移植证书信封（PCE）**；用延迟感知认证（LAC）让前缀在重尾延迟下仍安全；用跨节点一致性（CNC）检测边云 WM/情绪模型漂移；用分层退化阶梯（TGD）在断连时逐级降档；用随时调度（EAS）在固定预算下最大化认证前缀质量。核心不变式只有一条：**低层执行高层契约时，风险界只会更紧，不会更松**。

## 1. 形式化定义（增量：定义 266–288）

- **定义 266（EDGE-RAS 总览）**：`EDGE-RAS = (HDP, PCE, LAC, CNC, VoI, TGD, EAS, J_EDGE)`。定位：把 SimRAS 的集中式「仿真预训练 + 在线 WM + VQA」展开到「云—边—端」三级。不变式：L1 实时环路只读证书信封、只做常数时间校验；L2/L3 全部异步；任何跨节点消息必须携带 provenance 与 deadline。
- **定义 267（分层决策规划 HDP）**：`HDP = (L3, L2, L1)` 是一个半马尔可夫（semi-MDP）层级。L3（云）：长时程子目标规划，视界 `H3 ∈ [5s, 60s]`，输出子目标契约序列；L2（边）：中时程动作块规划，视界 `H2 ∈ [0.3s, 2s]`，且 `H2 ≤ m_ras`；L1（端）：短时程反应控制，视界 `H1 ≤ 50ms`。时间尺度满足 `H1 ≪ H2 ≪ H3`。
- **定义 268（子目标契约）**：`G = (g, V_g, D_g, b_g, σ_g)`：`g` 子目标（位姿/区域/交互模式），`V_g` 有效区域，`D_g` 截止时刻，`b_g` 风险预算，`σ_g` 来源签名。
- **定义 269（块契约）**：`C = (A_{1:m}, k*, E, D_c, λ_c)`：动作块、已认证前缀长度、证书信封、截止时刻、风险上界。
- **定义 270（可移植证书信封 PCE）**：`E = (payload, V, D, λ, prov, tier)`。`prov = (node_id, model_hash, sim_pretrain_ver, vqa_audit_hash, clock_sig)`。**可移植性不变式**：任何节点在 `now ∈ [t_issue, D]` 且 `state ∈ V` 时执行 `payload`，实际风险 `≤ λ`。
- **定义 271（边缘延迟模型）**：通信延迟 `δ ~ D_delay`，支撑 `[0, δ_max]`，允许重尾。定义 `deadline slack = D - (now + δ̂)`，其中 `δ̂` 为高分量（如 P99）。
- **定义 272（延迟不变认证前缀 LAC）**：
  ```
  k_edge(t) = max{ k : ∀δ ∈ [0, δ_max], ∀i ≤ k,  λ_risk(t+δ+i)·ρ_safe(t+δ+i) ≥ 0 }
  ```
  用 `ρ_safe` 的 Lipschitz 常数 `L_ρ` 和 `λ_risk` 的变化率 `L_λ` 做保守闭式近似。
- **定义 273（跨节点一致性 CNC）**：`d_cn(t) = KL(π^{cloud}_t ‖ π^{edge}_t) + ‖z^{cloud}_t − z^{edge}_t‖`。若 `d_cn > τ_cn`，标记 `cross_node_drift = True`，云端结论不得进入 L2，强制降级到 edge-only。
- **定义 274（通信即动作）**：`A_edge = A_ctrl ∪ A_info`，`A_info = {query_cloud, probe_emotion, wait_for_plan, switch_tier}`。信息动作改变的是「信念」，不是「位置」。
- **定义 275（信息价值 VoI）**：
  ```
  VoI(a) = E_{o~a}[ R_emotion(π_t) − R_emotion(π_{t+δ_a} | o) ] − c_lat·δ_a − c_eng·e_a − c_fail·P(a fails)
  ```
  仅当 `VoI(a) > τ_voi` 才执行信息动作。
- **定义 276（分层退化阶梯 TGD）**：Tier-0 = 云+边+端；Tier-1 = 边+端；Tier-2 = 端-only。触发条件：`RTT > τ_rtt`、断连、`cross_node_drift`、电量 `< β_batt`、计划过期。每降一层施加证书收紧 `Δ_tier`。
- **定义 277（证书单调性与限制映射）**：`R_{j→j−1}(E_j) = E_{j−1}` 满足 `λ_{j−1} ≤ λ_j − Δ_tier`、`V_{j−1} ⊆ V_j`、`D_{j−1} ≤ D_j`。即高层证书一定能在低层「降档执行」，且只会更保守。
- **定义 278（边缘随时调度 EAS）**：预算 `B_t`（cycles/能量）在 `{ERG, WM rollout, L2 planning, VQA}` 间分配。认证前缀质量 `q(k)` 关于预算单调、凹；超时则返回「最后一次已认证的 `k`」。
- **定义 279（边缘联合代价）**：`J_edge = R_risk + γ_lat·E[δ] + γ_eng·E[energy] + γ_sw·switch_freq`。用滞回避免 tier flapping。
- **定义 280（分层不确定性传播）**：`σ²_{L1} = σ²_{L2,exec} + σ²_model + (L_ρ·δ_max)² + σ²_abs`，其中 `σ²_abs` 为子目标抽象误差，层间加性累积。
- **定义 281（边云 WM 蒸馏）**：`WM_edge = Distill(WM_cloud, D_sim)`，蒸馏误差 `ε_dist`；在线用 CNC 校验，漂移时回退 SimRAS 单节点模式。
- **定义 282（AIC-EDGE 干扰扩充）**：`ℰ_EDGE = ℰ_SimRAS × {网络分区, 时钟漂移, 陈旧计划, 握手失败, 电量骤降, 边云模型版本错配}`。
- **定义 283（J_EDGE 证书）**：`J_EDGE = (J_SimRAS, tier, pce_hash, k_edge, δ_max_obs, cn_drift_flag, voi_trace_hash, eas_budget_trace)`。
- **定义 284（在线部署不变式）**：L1 实时环路 `≤ 1ms` 常数时间；只消费 PCE 与本地安全检查；任何网络/云调用必须异步，且不得阻塞控制周期。
- **定义 285（离线标定流程）**：`SimEngine → D_sim → 训练 cloud WM → 蒸馏 edge WM → 标定 λ/δ 参数 → 注入三级延迟仿真 → 标定 TGD 阈值与 τ_voi → 导出版本化模型清单`。
- **定义 286（滞回与振荡防护）**：tier 切换需连续 `N` 个周期满足条件，且把 `J_sw` 计入切换判据；否则维持当前 tier。
- **定义 287（规划—执行一致性检查）**：L1 执行前检查 `state ∈ V`、`now ≤ D`、`clock_sig` 匹配；任一不满足则触发 TGD 降级或请求重规划。
- **定义 288（时钟同步与陈旧检测）**：时钟偏移 `|t_local − t_msg| ≤ ε_clk`、消息年龄 `age ≤ τ_stale`；超限即作废该计划并标记 `stale_plan`。

## 2. 关键算法骨架

```python
# ---------- L3：云端长时程子目标规划（异步） ----------
class CloudSubgoalPlanner:
    def plan(self, belief, wm_cloud, budget):
        # 半 MDP：长视界子目标序列，每个子目标带风险预算
        seq = wm_cloud.long_horizon_plan(belief, H3=30.0, budget=budget)
        return [GoalContract(g=go, V_g=vo, D_g=dg, b_g=bg,
                             sig=self.sign(go)) for (go, vo, dg, bg) in seq]


# ---------- L2：边缘动作块规划 + 延迟不变认证 ----------
class EdgeChunkPlanner:
    def __init__(self, efs_wm, csc, delta_max, L_rho, L_lambda, tau_cn):
        self.efs_wm, self.csc = efs_wm, csc
        self.delta_max, self.L_rho, self.L_lambda = delta_max, L_rho, L_lambda
        self.tau_cn = tau_cn

    def plan(self, goal, x_prime, wm_edge, face_gate, now):
        A = propose_chunks(goal, x_prime, m=min(self.m_ras, len_proposal(goal)))
        rho = signature(x_prime)
        joint_post, _ = self.efs_wm.synthesize(rho, face_gate, x_prime, A)

        # 延迟不变认证：对最坏延迟 δ_max 仍成立
        k_sync = self.csc.certified_prefix_ras_wm(A, joint_post, now)
        shrink = ceil((self.L_rho + self.L_lambda) * self.delta_max / max(self.margin(A), 1e-6))
        k_edge = max(0, k_sync - shrink)

        E = CertificateEnvelope(
            payload=A[:k_edge], V=goal.V_g, D=now + horizon(A[:k_edge]),
            λ=risk_bound(joint_post, k_edge),
            prov=provenance(node='edge', wm_hash=wm_edge.hash, clock_sig=clock()),
            tier=1)
        return E, k_edge


# ---------- L1：本体执行器（常数时间） ----------
class RobotExecutor:
    def __init__(self, safety_controller):
        self.safe = safety_controller
        self.E = None
        self.idx = 0

    def install(self, E):
        self.E, self.idx = E, 0

    def step(self, state, now):
        if self.E is None or now > self.E.D or not inside(state, self.E.V):
            return self.safe.stop(), 'INVALID_ENVELOPE'
        a = self.E.payload[self.idx]
        self.idx = min(self.idx + 1, len(self.E.payload) - 1)
        return a, 'CERTIFIED'


# ---------- VoI：把「通信/探针/等待」当作决策 ----------
def choose_info_action(candidates, tau_voi):
    best, best_voi = None, tau_voi
    for a, (delta, energy, p_fail, risk_drop) in candidates.items():
        voi = risk_drop - 0.3 * delta - 0.1 * energy - 0.5 * p_fail
        if voi > best_voi:
            best, best_voi = a, voi
    return best  # None 表示不查询，直接执行本地证书


# ---------- 主环路：EDGE-RAS ----------
def EDGE_RAS_round(M, obs, now):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    # 0) 分层退化判据 + 滞回
    tier = M.tgd.update(rtt=M.net.rtt(), drift=M.cn.last_drift,
                        battery=M.power.level(), stale=M.stale)
    if tier == 2:
        return M.robot_only_round(obs, now)   # 端-only：退化为安全控制器 + 本地反应

    # 1) 情绪网关 + 跨节点一致性
    face_gate = M.erg_wm.recognize(img, x_prime)
    M.cn.check(face_gate['pi'], M.wm_edge)

    # 2) 取上层契约（可能来自缓存；过期则降级重规划）
    goal = M.pce_cache.get_valid(now)
    if goal is None:
        if tier == 0 and M.voi(VoI_query_cloud) > 0:
            M.async_query_cloud(x_prime)      # 异步，不阻塞
        goal = M.tgd.fallback_goal(x_prime)   # 本地保守子目标

    # 3) L2：生成块 + 延迟不变认证
    E, k_edge = M.edge_planner.plan(goal, x_prime, M.wm_edge, face_gate, now)

    # 4) 安装到 L1，并做一致性自检
    M.executor.install(E)
    if not M.consistency_check(E, now):
        M.tgd.force_downgrade('INCONSISTENT_PCE')

    # 5) 异步：VQA 审计 + 云端重规划回填
    M.vqa_auditor.submit_async(E.payload, {'tier': tier, 'pce': E.hash})

    return E, k_edge, tier

## 3. 推导

**引理 13（延迟鲁棒前缀的线性退化）** 设 `ρ_safe` 关于时间 `L_ρ`-Lipschitz，`λ_risk` 变化率不超过 `L_λ`，块内最小安全裕度为 `m_0 > 0`。则最坏延迟 `δ_max` 下的认证前缀满足
```
k_edge ≥ k_sync − ⌈(L_ρ + L_λ)·δ_max / m_0⌉
```
即：**认证前缀随延迟线性收缩，而不是在延迟稍大时整体失效**。这给边缘系统一条可预算的「安全-延迟」折中曲线。

**引理 14（证书信封的组合与限制）** 若 `E_j` 在 tier `j` 有效，则限制映射 `R_{j→j−1}` 产生的 `E_{j−1}` 满足 `λ_{j−1} ≤ λ_j − Δ_tier` 且 `V_{j−1} ⊆ V_j`、`D_{j−1} ≤ D_j`。因此高层证书能在低层「降档执行」，且只会更保守，不会更松。

**定理 14（EDGE-RAS 端到端风险界）** 在 A87–A91 及延迟有界 `δ_max`、CNC 一致、TGD 单调的前提下，
```
P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_net(δ_max) + α_abs(H3, H2)
```
其中 `α_net(δ_max) = 1 − exp(−(L_ρ+L_λ)·δ_max / m_0)` 为网络延迟引入的风险，`α_abs` 为跨层抽象误差。注意 `α_net` 会随 `δ_max` 线性增长，这解释了为什么必须让 tier 在延迟过大时主动降档。

**定理 15（VoI 查询的最优停止）** 若信息动作的收益函数 `risk_drop(a)` 是子模的，则贪心 VoI 策略达到最优的 `(1−1/e)` 倍；且存在阈值 `τ_voi`，使策略等价于「收益/代价比超过阈值才发起查询」。这把 FAS 探针、云端审计、等待计划统一为同一个最优停止问题。

**定理 16（分层退化的安全性保持）** 若 (i) 证书单调性（定义 277）成立，(ii) Tier-2 的本体安全控制器在不变集内安全，(iii) tier 切换具滞回（定义 286），则任意切换序列不会引入新的不安全状态。证明思路：每次切换只可能收紧 `λ`，而 Tier-2 的兜底控制器保证最后一道防线。

**定理 17（边云蒸馏误差传播）** 蒸馏误差 `ε_dist` 使在线滚动误差满足 `ε_π^{edge} ≤ ε_π^{cloud} + C·ε_dist`；CNC 阈值 `τ_cn` 可将漂移漏报率控制在 `δ_cn`。若 `ε_dist` 与 `δ_max` 同时增大，则 `α_net + α_abs` 超出预算，系统应自动降档到 Tier-1。

**引理 15（随时调度的预算—质量折中）** 认证前缀长度 `k(B)` 关于预算 `B` 单调非减且凹；在随机到达的超时约束下，期望质量满足 `E[k] ≥ (1 − p_timeout)·k_full − c·Var(B)`。因此 EAS 应采用「先算最不确定项、可随时截断」的顺序。

| CNC 跨节点一致性 | +0.2ms | O(1) | 定理 14：漂移触发降档 |

| EAS 随时调度 | <0.1ms 调度开销 | O(1) | 引理 15：预算—质量折中 |

## 6. 本轮最大风险

**一句话**：EDGE-RAS 把安全证书变成了跨节点的「社会契约」，但延迟模型、时钟同步与边云一致性都只是**估计量**——一旦真实延迟重尾超出 `δ_max` 标定、边云模型版本错配而 CNC 未检出、或分层抽象误差不可加性累积，PCE 就可能在「看起来仍在有效期内」的情况下放行一份**陈旧或降档不充分**的计划；这是本轮全部理论依赖的核心假设：**延迟有界、跨节点一致性可检、分层抽象误差可加性可控**。

**次级风险与缓解**：
1. **延迟标定失准**：用在线分位数估计动态更新 `δ_max`，并保留 Tier-2 兜底；
2. **CNC 漏检**：用模型哈希 + 版本清单做硬一致性，而非只靠 KL 软检测；
3. **抽象误差非加性**：在层间插入「契约一致性断言」，不满足即重规划；
4. **PCE 伪造/重放**：provenance 签名 + 单调时钟 nonce，见 E288；
5. **降档抖动**：滞回 + 切换代价计入 `J_edge`，见 E276。

## 2. 形式化定义（完整版）

**定义 266（EDGE-RAS 总览）** EDGE-RAS 是 SimRAS 的「云—边—端」分布式展开：
```
EDGE-RAS = (HDP, PCE, LAC, CNC, VoI, TGD, EAS, J_EDGE)
```
不变式：L1 实时环路只读证书信封、只做常数时间校验；L2/L3 全部异步；任何跨节点消息必须携带 provenance 与 deadline。

**定义 267（分层决策规划 HDP）** `HDP = (L3, L2, L1)` 为半马尔可夫层级：
- L3（云）：长时程子目标规划，`H3 ∈ [5s, 60s]`；
- L2（边）：中时程动作块规划，`H2 ∈ [0.3s, 2s]` 且 `H2 ≤ m_ras`；
- L1（端）：短时程反应控制，`H1 ≤ 50ms`。
满足 `H1 ≪ H2 ≪ H3`；每层是一个 option，持续时长由契约 deadline 界定。

**定义 268（子目标契约）**
```
G = (g, V_g, D_g, b_g, σ_g)
```
`g` 子目标，`V_g` 有效区域，`D_g` 截止时刻，`b_g` 风险预算，`σ_g` 来源签名。

**定义 269（块契约）**
```
C = (A_{1:m}, k*, E, D_c, λ_c)
```
动作块、认证前缀、证书信封、截止时刻、风险上界。

**定义 270（可移植证书信封 PCE）**
```
E = (payload, V, D, λ, prov, tier)
prov = (node_id, model_hash, sim_pretrain_ver, vqa_audit_hash, clock_sig)
```
可移植性不变式：任意节点在 `now ∈ [t_issue, D]` 且 `state ∈ V` 时执行 `payload`，实际风险 `≤ λ`。

**定义 271（边缘延迟模型）** `δ ~ D_delay`，支撑 `[0, δ_max]`，允许重尾。`deadline slack = D − (now + δ̂)`，`δ̂` 取 P99。

**定义 272（延迟不变认证前缀 LAC）**
```
k_edge(t) = max{ k : ∀δ ∈ [0, δ_max], ∀i ≤ k, λ_risk(t+δ+i)·ρ_safe(t+δ+i) ≥ 0 }
```
闭式保守近似（`L_ρ`、`L_λ` 为 Lipschitz 常数，`m_0` 为最小安全裕度）：
```
k_edge ≥ k_sync − ⌈(L_ρ + L_λ)·δ_max / m_0⌉
```

**定义 273（跨节点一致性 CNC）**
```
d_cn(t) = KL(π^{cloud}_t ‖ π^{edge}_t) + ‖z^{cloud}_t − z^{edge}_t‖
```
`d_cn > τ_cn ⇒ cross_node_drift = True`，云端结论不得进入 L2。

**定义 274（通信即动作）** `A_edge = A_ctrl ∪ A_info`，`A_info = {query_cloud, probe_emotion, wait_for_plan, switch_tier}`。

**定义 275（信息价值 VoI）**
```
VoI(a) = E_{o~a}[R_emotion(π_t) − R_emotion(π_{t+δ_a}|o)] − c_lat·δ_a − c_eng·e_a − c_fail·P(a fails)
```
`VoI(a) > τ_voi` 才执行信息动作。

**定义 276（分层退化阶梯 TGD）** Tier-0 = 云+边+端；Tier-1 = 边+端；Tier-2 = 端-only。触发：`RTT > τ_rtt`、断连、`cross_node_drift`、电量 `< β_batt`、`stale_plan`。每降一层施加证书收紧 `Δ_tier`。

**定义 277（证书单调性与限制映射）** `R_{j→j−1}(E_j) = E_{j−1}` 满足
```
λ_{j−1} ≤ λ_j − Δ_tier,  V_{j−1} ⊆ V_j,  D_{j−1} ≤ D_j
```

**定义 278（边缘随时调度 EAS）** 预算 `B_t` 在 `{ERG, WM rollout, L2 planning, VQA}` 间分配；认证前缀质量 `q(k)` 关于预算单调、凹；超时返回最后已认证的 `k`。

**定义 279（边缘联合代价）** `J_edge = R_risk + γ_lat·E[δ] + γ_eng·E[energy] + γ_sw·switch_freq`。

**定义 280（分层不确定性传播）**
```
σ²_{L1} = σ²_{L2,exec} + σ²_model + (L_ρ·δ_max)² + σ²_abs
```
`σ²_abs` 为子目标抽象误差，层间加性累积。

**定义 281（边云 WM 蒸馏）** `WM_edge = Distill(WM_cloud, D_sim)`，蒸馏误差 `ε_dist`；在线用 CNC 校验，漂移时回退 SimRAS 单节点模式。

**定义 282（AIC-EDGE 干扰扩充）**
```
ℰ_EDGE = ℰ_SimRAS × {网络分区, 时钟漂移, 陈旧计划, 握手失败, 电量骤降, 边云模型版本错配}
```

**定义 283（J_EDGE 证书）**
```
J_EDGE = (J_SimRAS, tier, pce_hash, k_edge, δ_max_obs, cn_drift_flag, voi_trace_hash, eas_budget_trace)
```

**定义 284（在线部署不变式）** L1 实时环路 `≤ 1ms` 常数时间；只消费 PCE 与本地安全检查；网络/云调用异步且不得阻塞控制周期。

**定义 285（离线标定流程）** `SimEngine → D_sim → 训练 cloud WM → 蒸馏 edge WM → 标定 λ/δ → 注入三级延迟仿真 → 标定 TGD 阈值与 τ_voi → 导出版本化模型清单`。

**定义 286（滞回与振荡防护）** tier 切换需连续 `N` 个周期满足条件，且 `J_sw` 计入判据；否则维持当前 tier。

**定义 287（规划—执行一致性检查）** L1 执行前检查 `state ∈ V`、`now ≤ D`、`clock_sig` 匹配；任一不满足则降档或重规划。

**定义 288（时钟同步与陈旧检测）** `|t_local − t_msg| ≤ ε_clk` 且 `age ≤ τ_stale`；超限即作废计划并标记 `stale_plan`。

class EdgeChunkPlanner:
    def __init__(self, efs_wm, csc, m_ras, delta_max, L_rho, L_lambda):

            λ=risk_bound(joint_post, k_edge),
            prov=provenance(node='edge', model_hash=wm_edge.hash, clock_sig=clock()),
            tier=1)
        return E, k_edge

    def _min_margin(self, A):
        return min(self.csc.safety_margin(a, 'H0') for a in A)


# ---------- IP-246 CNC：跨节点一致性 ----------
class CrossNodeConsistency:
    def __init__(self, tau_cn=0.3):
        self.tau_cn, self.last_drift = tau_cn, False

    def check(self, pi_edge, wm_edge, pi_cloud=None, z_cloud=None):

            return True
        d = kl_div(pi_edge, pi_cloud) + l2(wm_edge.z, z_cloud)

        return not self.last_drift


# ---------- IP-247 VoI：信息动作决策 ----------
def choose_info_action(candidates, tau_voi, weights=(0.3, 0.1, 0.5)):
    best, best_voi = None, tau_voi
    for a, (delta, energy, p_fail, risk_drop) in candidates.items():
        voi = risk_drop - weights[0]*delta - weights[1]*energy - weights[2]*p_fail
        if voi > best_voi:
            best, best_voi = a, voi
    return best  # None = 不查询，直接执行本地证书


# ---------- IP-248 TGD：分层退化（带滞回） ----------
class TieredGracefulDegradation:
    def __init__(self, tau_rtt=120, beta_batt=0.15, N=3):
        self.tier, self.counter, self.N = 0, 0, N
        self.tau_rtt, self.beta_batt = tau_rtt, beta_batt

    def update(self, rtt, drift, battery, stale):
        bad = (rtt > self.tau_rtt) or drift or battery < self.beta_batt or stale
        self.counter = self.counter + 1 if bad else 0
        if self.counter >= self.N:
            self.tier = min(2, self.tier + 1)
            self.counter = 0
        elif self.counter == 0 and self.tier > 0:
            self.tier -= 1  # 恢复也需滞回，实际实现用独立计数
        return self.tier

    def force_downgrade(self, reason):
        self.tier = min(2, self.tier + 1)
        return reason


# ---------- IP-249 EAS：随时调度 ----------
def allocate_budget(B, priorities):
    # priorities 按「边际质量增益/成本」降序
    alloc = {}
    for name, cost, marginal_gain in priorities:
        if B <= 0:
            break
        take = min(cost, B)
        alloc[name] = take
        B -= take
    return alloc

    # 1) 情绪网关 + 跨节点一致性

```

## 4. 推导

**引理 13（延迟鲁棒前缀的线性退化）** 设 `ρ_safe` 关于时间 `L_ρ`-Lipschitz，`λ_risk` 变化率 `≤ L_λ`，块内最小安全裕度 `m_0 > 0`。则
```
k_edge ≥ k_sync − ⌈(L_ρ + L_λ)·δ_max / m_0⌉
```
证明：延迟 δ 使每个时刻的安全裕度最多下降 `(L_ρ+L_λ)δ`；要维持 `≥0`，需砍掉至多 `(L_ρ+L_λ)δ/m_0` 个块步。∎

**引理 14（证书信封的组合与限制）** 若 `E_j` 在 tier `j` 有效，则 `R_{j→j−1}(E_j)` 满足 `λ_{j−1} ≤ λ_j − Δ_tier`、`V_{j−1} ⊆ V_j`、`D_{j−1} ≤ D_j`。因此高层证书可在低层降档执行，且只会更保守。

**定理 14（EDGE-RAS 端到端风险界）** 在 A87–A91 及延迟有界 `δ_max`、CNC 一致、TGD 单调下：
```
P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_net(δ_max) + α_abs(H3, H2)
α_net(δ_max) = 1 − exp(−(L_ρ+L_λ)·δ_max / m_0)
```

**定理 15（VoI 查询的最优停止）** 若 `risk_drop(a)` 子模，则贪心 VoI 策略达到最优的 `(1−1/e)`；存在阈值 `τ_voi` 使策略等价于「收益/代价比超阈值才查询」。因此 FAS 探针与云端审计可统一为同一最优停止问题。

**定理 16（分层退化的安全性保持）** 若 (i) 证书单调性成立，(ii) Tier-2 本体安全控制器不变集安全，(iii) tier 切换具滞回，则任意切换序列不引入新的不安全状态。证明：每次切换只可能收紧 `λ`，Tier-2 兜底控制器保证最后防线。∎

**定理 17（边云蒸馏误差传播）** `ε_π^{edge} ≤ ε_π^{cloud} + C·ε_dist`；CNC 阈值 `τ_cn` 将漂移漏报率控制在 `δ_cn`。若 `ε_dist` 与 `δ_max` 同时增大导致 `α_net + α_abs` 超预算，系统自动降档到 Tier-1。

**引理 15（随时调度的预算—质量折中）** `k(B)` 关于预算 `B` 单调非减且凹；在随机超时约束下 `E[k] ≥ (1 − p_timeout)·k_full − c·Var(B)`。故 EAS 应按「边际质量增益/成本」降序分配预算。

## 7. 本轮最大风险

**一句话**：EDGE-RAS 把安全证书变成了跨节点的「社会契约」，但延迟模型、时钟同步与边云一致性都只是**估计量**——一旦真实延迟重尾超出 `δ_max` 标定、边云模型版本错配而 CNC 未检出、或分层抽象误差不可加性累积，PCE 就可能在「看起来仍在有效期内」的情况下放行一份**陈旧或降档不充分**的计划；这是本轮全部理论依赖的核心假设：**延迟有界、跨节点一致性可检、分层抽象误差可加性可控**。
