# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；新灵感循环第 1 轮；本轮灵感：「数据质量」×「视觉伺服」）

> R72 把 GAUGE 从「认知层」下沉为「具身闭环」：REG 实时执行图、IRL 意图隐变量、DMEM 接触计量、EREFLEX 三层反作用、S2R-UQ 仿真-实机桥接。它回答了「测量链在调度、意图、接触约束下能否兑现风险界」。
> 但 R72 有一根从未被审计的支柱：**数据本身**。而且它默认「视觉只是又一个观测模态」。
> - **数据质量视角**：R72 审计的是「测量」（instrument），没审计「数据供应链」（provenance、完整性、时效、一致性、唯一性）。数据质量问题大多是**结构性的**（遮挡=缺失、过期=时序、特征退化=冗余、标定漂移=准确度），把它们压成一个协方差，等于把「缺了一半的特征」误当成「噪声大」——估计器会用平滑先验把遮挡「脑补」成连续，得到一个平滑但错误的信念。数据质量是**多维、任务相关、偏序的 fitness-for-use 剖面**，不是方差的别名。
> - **视觉伺服视角**：视觉伺服不是被动感知，而是**控制器本身就是传感器的执行器**。IBVS 的 `v = -λ L̂_e⁺ e` 里，`L̂_e` 是从数据估的交互矩阵、`e` 是从图像提的特征误差；**控制动作改变相机位姿 → 改变视角/距离/运动模糊/光照 → 改变下一帧的数据质量 → 改变 L̂_e 与 e 的质量**。这构成一条比 R72「经人/经物」更直接、**毫秒级、确定性、可建模**的反作用：**L4 数据质量反作用**。数据质量既是控制的输入，也是控制的输出。
>
> 核心命题：**不再只问「我的测量链可信吗」，而问「我的数据供应链，在我自己用视觉伺服去驱动相机时，还能持续向我交付 fitness-for-use 吗？」** 把 R72 的「具身计量审计」继续下沉一层，建立 **DQ-SERVO-GAUGE**（Data-Quality-conditioned, Servo-aware GAUGE：数据质量条件 × 视觉伺服感知的计量审计闭环）。

## 0. 直觉与动机

**灵感 1（数据质量 → 不确定度 ≠ 质量；质量是结构不是方差）**
直觉：R72 把一切都塞进「不确定度」（U_ale/U_epi/Σ）。但真实的数据质量问题经常**不是随机的**：目标被遮挡 = **completeness 缺失**；画面是上一帧 = **timeliness 过期**；特征点全共线 = **uniqueness/冗余退化**；相机标定漂了 2mm = **accuracy 偏移**；运动模糊/压缩块 = **precision 下降**；视觉说「红」语言说「蓝」 = **consistency 矛盾**；目标出视野 = **validity 失效**。用同一个高斯协方差描述这七种故障，会犯两个错：(i) 把「缺失」当「高噪声」，融合时「用先验补」，产生**平滑的幻觉**；(ii) 把「过期」当「高噪声」，均值对但**相位滞后**，闭环直接失稳。**数据质量必须升格为独立的、多维的、带 provenance 的一等对象。**

**灵感 2（视觉伺服 → 控制器是传感器的执行器，质量是内生的）**
直觉：IBVS 的稳定性依赖 `L̂_e L_e⁺ ≻ 0`。但只要特征退化/深度错/标定漂，`L̂_e` 就会错；`L̂_e` 错到一定程度，`L̂_e L_e⁺` 某特征值变号，闭环从稳定翻成振荡。更关键：**修复质量的动作本身会制造新的质量损失**。模糊 → 控制器想「靠近点看清」 → 距离近、速度大 → 运动模糊更重 & 视野更窄 → 更看不清。这是 L4 坏循环，与 R71「越问越烦」、R72「越抓越滑」同构，但它发生在**传感器-控制器最短回路**里，延迟只有一帧。**主动感知不是免费的：移动相机有质量成本，而且该成本要被预算化。**

**灵感 3（交互矩阵证书 → 视觉伺服的「测量链」其实是条件数 κ(L_e)）**
直觉：视觉伺服精度不由「图像多清晰」单独决定，而由**交互矩阵的可逆性/条件性**决定。特征共线、深度未知、接近奇异位形时，`κ(L_e)` 爆炸，`L̂_e⁺` 把微小特征噪声放大成巨大速度指令。所以视觉伺服真正该发证书的对象是 **交互矩阵证书** `(L̂_e, Σ_L, D_L, κ, u_Z, τ)`，而非「图像噪声 σ」。**「图像好看」不等于「伺服可解」——这是视觉伺服版的「裸奔数字」。**

**灵感 4（质量反作用预算 → 质量维度不同向，不能用标量调度）**
直觉：靠近提升 resolution（precision/accuracy ↑）但牺牲 FOV（validity/completeness ↓）；变焦提升 resolution 但降低景深与光量；提高曝光降噪但增加运动模糊。**质量维度之间是 trade-off 而非同向叠加**。因此调度必须基于**偏序**：动作 a 只有在「所有关键维不劣化，且至少一维严格改善」时才被允许（Pareto 改进），否则进入质量预算核算。用一个标量 DQ-score 去优化，必然 Goodhart。

**灵感 5（数据供应链 → 训练数据质量是有证书的，测试 OOD 首先是质量 OOD）**
直觉：学到的视觉伺服策略只在**训练数据质量分布**内被认证。实机上一抖（运动模糊）、一挡（遮挡）、一压（压缩）、换相机（标定域变），这不是普通状态 OOD，而是**质量 OOD（quality-OOD）**。训练集全是清晰图，实机一模糊，策略会「高置信地错」，而且**在线任何滤波都补不回源端丢掉的信息**（数据处理不等式）。所以质量必须在**源端计量并否决**，并给数据集发**质量卡 / provenance / 质量债**。这与 R72 的「意图 OOD / 接触 OOD」同构，但发生在更底层：**数据层 OOD 会伪装成"状态罕见"，被误当成"探索不足"而不是"数据坏了"。**

## 1. 形式化定义（增量：定义 366–379）

**定义 366（数据质量剖面 DQP）** 对数据流 d 在时刻 t 的质量剖面
q_t(d) = (q_completeness, q_accuracy, q_precision, q_timeliness, q_consistency, q_validity, q_uniqueness) ∈ 𝒬 = ∏_{j∈J} ([0,1] ∪ {⊥})。
每个分量 q_j 携带六元组 (φ_j, m_j, u_j, D_j, τ_j, I⊥_j)（同 R71 定义 332）。**⊥ 表示"该维不可得/未定义"，是吸收元**：q_j = ⊥ ⇒ 任何下游融合不得使用该维，且不得用其它维"补偿"。质量偏序：q ⪯ q' ⇔ ∀j, q_j ≤ q'_j（⊥ 与任何值不可比）。**fitness-for-use** 是任务条件的单调泛函 F_task: 𝒬 → ℝ（对偏序单调，不要求线性可加）。**禁止把 q 压成标量**（见引理 33）。

**定义 367（质量条件观测模型）** 观测模型写作
p(y | s, q) = ∫ p(y | s, θ) p(θ | q) dθ · m_q(y; s)，
其中 q 以三种方式进入：(i) **尺度**：Σ(q) 改变噪声大小（precision）；(ii) **支撑集**：m_q 为缺失机制（completeness/validity，可为 MNAR），决定"哪些观测根本不存在"；(iii) **观测函数**：h_q(s) 偏移（accuracy/consistency）。**质量是结构，不是方差**：仅用 trace(Σ) 无法区分"高噪声"与"缺失/偏移"（引理 34）。

**定义 368（交互矩阵证书 VSM-Cert）** 对图像特征 s 与深度 Z，交互矩阵 L_s(s,Z) ∈ ℝ^{k×6}。证书
C_VS = (L̂_s, Σ_L, D_L, κ(L̂_s), u_Z, τ_L)，
其中 Σ_L 由相机内参不确定度、u_Z、特征噪声与 q_precision/q_accuracy 传播；D_L 为有效域（FOV、深度区间、特征几何非退化）；κ = σ_max(L̂_s)/σ_min(L̂_s) 为条件数。**有效 ⇔ κ ≤ κ_max ∧ Z ∈ D_L ∧ Σ_L ⪯ Σ_budget**。使用 L̂_s⁺ 前必须验证 C_VS；未验证即用视为"裸奔控制"。

**定义 369（L4 数据质量反作用）** 质量转移
q_{t+1} ~ p(q_{t+1} | q_t, a_t, ξ_scene)，
a_t 为相机/机械臂动作（速度、视角、距离、曝光、变焦），ξ_scene 为场景（纹理、光照、遮挡）。质量成本
c^q_t = d_𝒬(q_t, q_{t+1}) + λ_q · 𝟙[¬(q_{t+1} ⪰ q_safe)]，
其中 d_𝒬 为偏序一致的距离（Pareto 距离）。质量预算 Σ_t c^q_t ≤ B_quality。**关键：各维不同向**，故 p 的转移是向量值，不可用单标量近似（灵感 4）。

**定义 370（质量环收缩性）** 记联合状态 x_t = (q_t, e_t)（质量+伺服误差）。称质量感知闭环**γ-收缩**若存在度量 μ 使 E[μ(x_{t+1})] ≤ γ·μ(x_t) 对某 γ < 1 成立。**QAV 必须同时满足（i）伺服局部稳定 L̂ L⁺ ≻ 0；（ii）质量环 γ-收缩。两者冲突时安全侧优先。**

**定义 371（质量感知视觉伺服 QAV）** 控制律
v_t = − g(q_t, κ_t, Σ_L,t) · L̂_s⁺ e_t，
增益调度 g ∈ [0, g_max]，并满足：
- **结构性缺失优先**：若 q_completeness < τ_c 或 q_validity 失效（目标出 FOV）⇒ **不注入新视觉反馈**，退化为 PBVS 的 last-known-good 位姿或 R68 开环；
- **时序失效**：若 q_timeliness < τ_t ⇒ 冻结增益/降速，禁止用过期 e 做高增益反馈；
- **退化否决**：若 κ(L̂_s) > κ_veto ⇒ g = 0，退出 IBVS；
- **IBVS/PBVS/混合切换**由 q 与 D_L 决定。
**非补偿性**：高 precision 不能补偿低 completeness（缺一半特征）；高 accuracy 不能补偿 timeliness（再准也是过期的）。这与 R71「非补偿性安全否决」同构。

**定义 372（Q-IVG 质量否决）** 在 R72 E-IVG 上新增失效条件：任一关键维 q_j < τ_j；质量 OOD 分 > τ_qood；κ(L̂_s) > κ_veto；跨模态一致性 < τ_cons；provenance 断链；质量债 QD_t > τ_debt。**任一成立 ⇒ 视觉伺服相关模块分层降级（QAV → PBVS → R68），但不连带降级已通过的意图/接触层**（保持 R72 的分层降级哲学）。

**定义 373（质量感知 VoI：QVoI）**
VoI^Q(g) = c(ψ)·IG_s + η·IG_z + β·[F(q_t) − E_{q'}[F(q_{t+1})]]
          − c_reflex^ψ − c_reflex^z − c_reflex^c − c^q(g) − γ·E[ΔQD_{future}]。
第三项为**质量信息增益**；c^q 为 L4 质量反作用成本；末项为**远期质量债**。主动动作（移动相机、请人保持静止、换曝光/变焦）只在「质量净增益 > 质量反作用成本 + 伺服风险增量」时执行；max VoI^Q ≤ 0 ⇒ 停止交互/回退。有限停止继承引理 31（质量边际增益递减 + 成本正下界）。

**定义 374（数据供应链审计 DSCA）** 对训练集 D_train 与在线流 D_online：
- **质量卡** QC(d) = (q 的经验分布、采集条件、传感器型号、标定版本、provenance 哈希、已知失效模式)；
- **质量债** QD_t = Σ_{缺陷 e} P(e 触发) · Impact(e)（如"训练无标定版本"的期望影响）；
- **质量 OOD**：q_online 是否落在训练 q 分布的 α-分位之外（逐维 + 联合）；
- **provenance 链** τ_data 与 R71 TCHAIN 同构，**断链即降级**。
**认证域**：策略只在 q ∈ QC.q_dist 的支撑域内被认证；出域即触发 Q-IVG。这条把「训练数据质量」从口号变成**可审计契约**。

**定义 375（数据质量进风险缩放 Q-RISK）**
λ = max( risk_scale(U_ale, U_epi, H_z, u_tac, u_VS, q_t⁻),
         λ_floor(U_ale + U_epi + H_z + u_tac + u_VS(q_t) + w_q·q_t⁻) )，
其中 q_t⁻ = 1 − min_{j∈J_crit} q_j（**最差关键维，非补偿**），u_VS = √(tr(Σ_L) + w_Z·u_Z²)。**质量不是"权重"，而是分母中的独立项，并额外抬高 λ_floor。**

**定义 376（质量证书 J_DQ）** J_DQ = (J_EMB, dq_profile_hash, vsm_cert_hash, quality_ood, provenance_ok, quality_debt, qav_switch_log, qav_version)。Valid ⇔ J_EMB 有效 ∧ C_VS 有效 ∧ q ∈ 认证域 ∧ 质量 OOD 未触发 ∧ provenance 完整 ∧ 质量债 ≤ 阈值。

**定义 377（威胁模型 AIC-DQ）** ℰ_DQ = {训练数据投毒/低质注入、质量指标 Goodhart（刷 completeness 但数据过期）、重放攻击（高"质量"旧帧）、传感器欺骗（注入干净但有系统偏移的图）、provenance 伪造、运动模糊对抗、相机标定漂移诱导、质量 OOD 伪装成状态新颖}。**注意：质量度量本身可能与被审计管线同源相关失效**（见本轮最大风险）。

**定义 378（严格退化包含链扩展）** 
- DQM/VSM 失效 ⇒ 退化到 R72（无 L4、无视觉伺服证书，仅用 R72 的 u_tac/意图/调度）；
- L4 失效（质量环不收缩）⇒ 关闭主动感知，固定视角 + R72；
- QAV 失效 ⇒ PBVS/R68 视觉伺服；
- 多层同时失效 ⇒ R71/R68。
**安全侧只增不减，逐指令等价。**

**定义 379（质量源端不可逆性）** 由数据处理不等式，沿处理链信息不增：对任意下游处理器 f，I(s; f(y)) ≤ I(s; y)，且 completeness/validity 的缺失（支撑集收缩）无法由 f 恢复。**故质量必须在源端计量与否决，下游"修复/补全"不能作为安全依据。**

## 2. 关键算法骨架

```python
# IP-295 DQM：数据质量计量（感知域，源端；七维剖面 + provenance）
@dataclass
class QualityProfile:
    q: Dict[str, float]              # 7 dims, higher=better, ⊥ for undefined
    u: Dict[str, float]              # per-dim uncertainty
    support: Dict[str, bool]         # completeness/validity masks
    tchain: bytes                    # provenance
    def dominates(self, other, crit): # Pareto: q ⪰ other on critical dims
        return all(self.q[j] >= other.q[j] for j in crit)

class DataQualityMetrology:
    def __init__(self, det, calib, prov):
        self.det, self.calib, self.prov = det, calib, prov
    def measure(self, frame, meta, ctrl_state):
        q = {'completeness': self.det.occlusion(frame),
             'accuracy':     self.calib.calib_conf(meta),
             'precision':    self.det.blur_noise(frame),
             'timeliness':   self.det.staleness(meta),
             'consistency':  self.det.cross_modal(frame, meta),
             'validity':     self.det.fov_valid(frame, meta),
             'uniqueness':   self.det.feat_degeneracy(frame)}
        return QualityProfile(q, self.det.uncertainty(), self.det.masks(),
                              self.prov.hash(frame, meta, ctrl_state))

# IP-296 VSM：交互矩阵证书（计量域，软实时）
class VisualServoMetrology:
    def certify(self, s, q, Z_prior):
        Z, u_Z = self.depth(s, Z_prior)
        L      = interaction_matrix(s, Z)
        SigmaL = propagate(self.K, u_Z, q['precision'], q['accuracy'])
        kappa  = cond(L)
        ok     = (kappa <= KAPPA_MAX and in_domain(s, Z)
                  and meets(SigmaL, SIGMA_BUDGET))
        return VSCert(L=L, SigmaL=SigmaL, kappa=kappa, u_Z=u_Z,
                      domain=ok, tchain=self.calib.tchain)

# IP-297 DQREFLEX：L4 质量反作用 + 收缩性检查（计量/感知域交界）
def dq_reflex_step(q, a, scene, budget):
    q2   = quality_transition(q, a, scene)          # p(q'|q,a), vector-valued
    cost = pareto_distance(q, q2) + LAM_Q * (not q2.dominates(Q_SAFE, CRIT))
    # 局部收缩性：∂q'/∂a 与动作雅可比合成的谱半径
    gamma = spectral_radius(dq_da(q, a) @ control_jacobian(a))
    feasible = (gamma < 1.0 and budget.spent + cost <= budget.B_quality)
    return q2, cost, feasible

# IP-298 QAV：质量感知视觉伺服（控制域，硬实时）
def quality_aware_servo(q, cert, e, last_good):
    # (1) 结构性缺失/出域：绝不拿先验补
    if q['completeness'] < TAU_C or not q['validity'] or not cert.domain:
        return pbvs_or_openloop(last_good)
    # (2) 时序失效：过期反馈禁止高增益
    if q['timeliness'] < TAU_T:
        return hold_or_degrade()
    # (3) 退化否决：条件数太大直接退出 IBVS
    if cert.kappa > KAPPA_VETO:
        return zero_gain()
    # (4) 质量/条件数调增益（单调、有界）
    g = G_MAX * fitness(q) / (1.0 + cert.kappa / KAPPA_REF)
    return -g * pinv(cert.L) @ e

# IP-299 Q-IVG：质量否决并入 E-IVG
def q_ivg(q, cert, qood, prov, debt):
    r = [('q_'+j, q.q[j]) for j in CRIT if q.q[j] < TAU[j]]
    if cert.kappa > KAPPA_VETO: r.append(('kappa', cert.kappa))
    if qood > TAU_QOOD:        r.append(('qood', qood))
    if not prov.ok:            r.append(('provenance',))
    if debt > TAU_DEBT:        r.append(('debt', debt))
    return Gate(valid=not r, reasons=r,
                fallback='R68' if len(r) >= 2 else 'PBVS')

# IP-300 QVOI：质量感知主动感知 + 有限停止
def quality_voi(b_t, q, cert, budget, acts, scene):
    best = None
    for a in acts:
        if not budget.allow(a): continue
        q2, cq, feasible = dq_reflex_step(q, a, scene, budget)
        if not feasible: continue
        ig_s   = c(psi) * (H(b_t) - E[H(b_t_next)])
        ig_z   = ETA * (z_ent - z2_ent)
        q_gain = BETA * (fitness(q2) - fitness(q))
        score  = ig_s + ig_z + q_gain - cq - GAMMA * future_quality_debt(q2)
        if best is None or score > best.score: best = (a, score)
    return best if best and best.score > 0 else None

# IP-301 DSCA：数据供应链审计（离线 + 在线监控）
def supply_chain_audit(dataset, q_online, policy_card):
    qc     = dataset.quality_card                  # q-dist, conditions, sensor, calib
    qood   = quality_ood_score(q_online, qc.q_dist)
    debt   = sum(d.p_trigger * d.impact for d in dataset.defects)
    prov   = provenance.verify(dataset.chain) and q_online.tchain in qc.lineage
    return SupplyReport(qood=qood, debt=debt, prov_ok=prov,
                        certified_domain=qc.q_dist)

# IP-302 Q-RISK：质量进风险缩放（控制域，硬实时 <0.05ms）
def quality_risk_scale(U_ale, U_epi, H_z, u_tac, q, cert, p):
    q_neg = 1.0 - min(q.q[j] for j in CRIT)        # worst critical dim, non-compensatory
    u_vs  = sqrt(trace(cert.SigmaL) + p.wZ * cert.u_Z**2)
    base  = U_ale + U_epi + H_z + u_tac + u_vs + p.wq * q_neg
    lam_r = p.lam_base * (1.0 + base / p.lam_scale)
    lam_f = p.lam_floor * (1.0 + base)
    if cert.kappa > p.kappa_soft:
        lam_f = max(lam_f, p.kappa_scale * cert.kappa / p.kappa_ref)
    return max(lam_r, lam_f)

# IP-303 Q-CERT：质量证书
def J_DQ(M):
    return Cert(emb=J_EMB(M), dq=hash_q(M.dqm.last),
                vsm=M.vsm.last_hash, qood=M.dsca.qood,
                prov=M.dsca.prov_ok, debt=M.dsca.debt,
                qav=M.qav.switch_log, ver='DQ-1')
```

## 3. 推导

**引理 33（数据质量沿处理链单调不增 ⇒ 源端否决必要）** 设 y 为源观测，f 为任意下游处理。由数据处理不等式 I(s; f(y)) ≤ I(s; y)；且支撑集收缩（completeness/validity 缺失）在确定性 f 下不可逆。故下游融合不可能"修复"源端质量损失。系：**质量否决必须在源端（传感器边界）执行；把 DQ 当作"事后去噪"是类别错误。**

**引理 34（把质量压成标量的不可辨识性）** 存在 q₁ ≠ q₂ 使 trace(Σ(q₁)) = trace(Σ(q₂))，但 p(y|s,q₁) ≠ p(y|s,q₂)（因支撑集/观测函数不同）。故任何只依赖标量噪声尺度的估计器无法区分"高噪声"与"缺失/偏移/过期"，其后验在结构退化下系统性有偏。系：**DQP 必须是向量；"质量分数"是 Goodhart 的温床。**

**引理 35（交互矩阵条件数 → 伺服稳定性裕度）** IBVS 局部渐近稳定需 L̂ L⁺ ≻ 0。设真实 L，估计误差 ΔL = L̂ − L，则 λ_min(L̂ L⁺) ≥ λ_min(L L⁺) − ‖ΔL‖·‖L⁺‖。当 ‖ΔL‖ 超过鲁棒裕度 ρ(L) 时，某特征值可穿零 ⇒ 振荡/失稳。而 ‖ΔL‖ 直接由 q_accuracy、u_Z、q_precision 决定。系：**数据质量通过 ‖ΔL‖ 直接进入闭环稳定性，不是"精度指标"而是"稳定裕度"。**

**引理 36（L4 质量环可正反馈）** 若速度增大同时降低 precision、距离减小同时降低 validity（FOV），则朴素"质量差就加速靠近"控制律 a_t = k(1 − F(q_t)) 可使 Q_{t+1} < Q_t 且 dQ/dt < 0，质量单调塌缩。存在阈值 k* 与收缩条件（定义 370）使闭环不发散。系：**主动感知需要质量预算 + 收缩性检查，否则"越努力越瞎"。**

**引理 37（QVoI 有限停止）** 质量边际增益 ∂F/∂动作随已获信息递减（同引理 31），质量成本 c^q 有正下界 ε_q ⇒ 存在有限 n* 使边际净收益 ≤ 0。**"何时停止主动感知"仍可证明，不靠调参。**

**定理 27（质量-伺服联合稳定与风险单调）** 在 A111–A115（DQP 七维可测、C_VS 有效、L4 Lipschitz 且 γ-收缩、provenance 完整、Q-IVG 门控）下，QAV 闭环局部稳定且风险界 ≤ R72 的具身风险界。**安全单调不减；效率只在"数据质量可计量、交互矩阵可解、质量环收缩"时获益。**

**定理 28（质量证书有效性 ⇒ 数据可信执行）** 若一次执行通过 J_DQ，则 (i) C_VS 有效 ⇒ 交互矩阵在有效域且伺服稳定裕度充足；(ii) q ∈ 认证域且质量 OOD 未触发 ⇒ 数据不在训练分布外；(iii) provenance 完整 ⇒ 数据来源未被篡改；(iv) J_EMB 有效 ⇒ 具身风险界成立。综上，**执行风险 ≤ ε_DQ（相对数据质量模型）**。**证明重量落在"质量度量本身未被同源污染"上。**

**定理 29（质量非补偿否决的必要性）** 由引理 33/34，若允许高 precision 补偿低 completeness（或高 accuracy 补偿 timeliness），则存在一个"看起来分数很高、但信息已丢"的样本被判为合格，其对下游估计的 Fisher 信息严格低于阈值，导致风险界失效。故 **质量否决必须按维（Pareto/非补偿）执行**，这与 R71 的非补偿安全否决是同一原理在数据层的再现。

## 6. 本轮最大风险

**一句话**：DQ-SERVO-GAUGE 把安全又下移了一层，从「相信测量链」变成「相信 **数据质量度量本身**、相信 **交互矩阵证书**、相信 **质量转移模型 p(q'|q,a)**」——而这套度量、证书与转移模型，恰恰是**跑在同一条被审计的数据管线上、用同一批可能有缺陷的传感器与标定来测自己的**；一旦发生**同源相关失效**（例如运动模糊同时让 `q_precision` 的估计偏高、`κ(L̂)` 偏低，或 provenance 根被俘获、质量 OOD 检测器在 4K 压缩流上系统性失明），系统会拿着一份「七维全绿、条件数漂亮、来源可追溯」的 J_DQ 证书，在视觉伺服闭环已经进入正反馈的那个瞬间，**自信地、可审计地、逐帧地把相机对准并撞向目标**，而事后回放发现「当时所有质量维度都在有效域内、所有证书都通过验证」——这就是**数据层「自信地错自己的数据质量」**。

次级风险与缓解：
1. **质量度量与被测管线同源** → **独立测量路径（双传感器/双曝光）+ 交叉见证（cross-witness）**：任一关键维必须由至少两条独立路径确认；单源不定案。
2. **质量维度 Goodhart** → **fitness-for-use 由下游任务闭环实测（伺服误差/失稳率）校准，而非由质量指标自证**；引入对抗性质量审计集。
3. **L4 正反馈发散** → **质量预算 + γ-收缩在线检查**；任何动作若使谱半径 ≥1 直接否决，降速/冻结。
4. **交互矩阵证书在极端位形仍漏判** → **在线微扰探测（dither）估计局部 L 的秩与条件**，并把探测成本纳入质量预算。
5. **质量 OOD 检测器域偏移** → **多检测器集成 + 仅在新相机/新压缩域上用少量无标注数据做在线校准**，校准不确定度进 u_VS。
6. **provenance 根被俘获** → **硬件根信任 + 多哈希锚点 + 离线密封审计**；断链默认降级而非继续。
7. **复杂度/延迟爆炸** → **DQM 七维只保留 3 个关键维用于硬实时（completeness/timeliness/uniqueness），其余在计量域异步算**；|J_crit| ≤ 3，|质量转移采样| ≤ 64。

## 2. 形式化定义（要点版）

**定义 366（数据质量剖面 DQP）** q_t(d) 为 7 维向量，每维带六元组 (φ,m,u,D,τ,I⊥)。⊥ 为吸收元（不可得），不得用其它维补偿。质量偏序 q⪯q'。F_task 对偏序单调但不要求可加。**禁止压成标量。**

**定义 367（质量条件观测模型）** p(y|s,q) 中 q 以三种方式进入：尺度 Σ(q)、支撑集 m_q（缺失/MNAR）、观测函数 h_q（偏移/对应错）。**质量是结构不是方差。**

**定义 368（交互矩阵证书 VSM-Cert）** C_VS=(L̂_s,Σ_L,D_L,κ,u_Z,τ_L)。有效 ⇔ κ≤κ_max ∧ Z∈D_L ∧ Σ_L⪯Σ_budget。**使用 L̂⁺ 前必须验证。**

**定义 369（L4 数据质量反作用）** q'~p(q'|q,a,ξ_scene)；c^q=d_𝒬(q,q')+λ_q·𝟙[¬(q'⪰q_safe)]；Σc^q≤B_quality。**各维不同向（靠近提精度降视野），转移是向量值。**

**定义 370（质量环收缩性）** x=(q,e)，若 E[μ(x')]≤γμ(x)，γ<1 称 γ-收缩。**QAV 须同时满足伺服稳定（L̂L⁺≻0）与质量环收缩；冲突时安全侧优先。**

**定义 371（质量感知视觉伺服 QAV）** v=−g(q,κ,Σ_L)L̂⁺e；结构性缺失→PBVS/R68，时序失效→冻结，κ>κ_veto→退出 IBVS；非补偿（precision 不补 completeness，accuracy 不补 timeliness）。

**定义 372（Q-IVG 质量否决）** 关键维 q_j<τ_j、质量 OOD>τ_qood、κ>κ_veto、跨模态一致性<τ_cons、provenance 断链、质量债>τ_debt，任一成立 ⇒ QAV→PBVS→R68 分层降级，不连带意图/接触层。

**定义 373（质量感知 VoI：QVoI）** VoI^Q = c(ψ)IG_s + ηIG_z + β[F(q)−E F(q')] − Σc_reflex − c^q − γ·E[ΔQD]。max≤0 ⇒ 停止/回退；有限停止继承引理 31。

**定义 374（数据供应链审计 DSCA）** 质量卡 QC(d)、质量债 QD_t、质量 OOD、provenance 链 τ_data。**策略只在 q∈QC.q_dist 认证域内有效；出域触发 Q-IVG。**

**定义 375（数据质量进风险缩放 Q-RISK）** q⁻=1−min_{J_crit}q_j（非补偿）；u_VS=√(tr(Σ_L)+w_Z u_Z²)；λ=max(risk_scale(U_ale,U_epi,H_z,u_tac,u_VS,q⁻), λ_floor(Σ+u_VS+w_q q⁻))。**质量是独立分母项，并抬升 λ_floor。**

**定义 376（质量证书 J_DQ）** Valid ⇔ J_EMB 有效 ∧ C_VS 有效 ∧ q∈认证域 ∧ 质量 OOD 未触发 ∧ provenance 完整 ∧ 质量债≤阈值。

**定义 377（威胁模型 AIC-DQ）** 训练数据投毒、质量指标 Goodhart、重放攻击、传感器欺骗、provenance 伪造、运动模糊对抗、标定漂移诱导、质量 OOD 伪装成状态新颖。

**定义 378（严格退化包含链扩展）** DQM/VSM 失效→R72；L4 失效→固定视角+R72；QAV 失效→PBVS/R68；多层失效→R71/R68。**安全侧只增不减。**

**定义 379（质量源端不可逆性）** 数据处理不等式 ⇒ 下游不可修复源端质量损失（completeness/validity 尤甚）。**质量否决必须在源端执行。**

## 3. 关键算法伪代码

```python
# IP-295 DQM：七维质量剖面（感知域，源端）
@dataclass
class QualityProfile:
    q: Dict[str, float]        # J -> [0,1], ⊥ for undefined
    u: Dict[str, float]
    support: Dict[str, bool]   # completeness/validity masks
    tchain: bytes
    def dominates(self, other, crit):
        return all(self.q[j] >= other.q[j] for j in crit)

class DataQualityMetrology:
    def measure(self, frame, meta, ctrl):
        q = {'completeness': self.det.occlusion(frame),
             'accuracy':     self.calib.calib_conf(meta),
             'precision':    self.det.blur_noise(frame),
             'timeliness':   self.det.staleness(meta),
             'consistency':  self.det.cross_modal(frame, meta),
             'validity':     self.det.fov_valid(frame, meta),
             'uniqueness':   self.det.feat_degeneracy(frame)}
        return QualityProfile(q, self.det.uncertainty(), self.det.masks(),
                              self.prov.hash(frame, meta, ctrl))

# IP-296 VSM：交互矩阵证书（计量域）
def certify(self, s, q, Z_prior):
    Z, u_Z = self.depth(s, Z_prior)
    L      = interaction_matrix(s, Z)
    SigmaL = propagate(self.K, u_Z, q['precision'], q['accuracy'])
    kappa  = cond(L)
    ok     = (kappa <= KAPPA_MAX and in_domain(s, Z)
              and meets(SigmaL, SIGMA_BUDGET))
    return VSCert(L, SigmaL, kappa, u_Z, ok, self.calib.tchain)

# IP-297 DQREFLEX：L4 质量反作用 + 收缩性
def dq_reflex_step(q, a, scene, budget):
    q2   = quality_transition(q, a, scene)
    cost = pareto_distance(q, q2) + LAM_Q * (not q2.dominates(Q_SAFE, CRIT))
    gamma = spectral_radius(dq_da(q, a) @ control_jacobian(a))
    feasible = gamma < 1.0 and budget.spent + cost <= budget.B_quality
    return q2, cost, feasible

# IP-298 QAV：质量感知视觉伺服（硬实时）
def quality_aware_servo(q, cert, e, last_good):
    if q['completeness'] < TAU_C or not q['validity'] or not cert.domain:
        return pbvs_or_openloop(last_good)      # 结构缺失：绝不脑补
    if q['timeliness'] < TAU_T:
        return hold_or_degrade()                # 过期：禁止高增益
    if cert.kappa > KAPPA_VETO:
        return zero_gain()                      # 退化：退出 IBVS
    g = G_MAX * fitness(q) / (1.0 + cert.kappa / KAPPA_REF)
    return -g * pinv(cert.L) @ e

# IP-299 Q-IVG：质量否决
def q_ivg(q, cert, qood, prov, debt):
    r = [('q_'+j, q.q[j]) for j in CRIT if q.q[j] < TAU[j]]
    if cert.kappa > KAPPA_VETO: r.append(('kappa', cert.kappa))
    if qood > TAU_QOOD:        r.append(('qood', qood))
    if not prov.ok:            r.append(('provenance',))
    if debt > TAU_DEBT:        r.append(('debt', debt))
    return Gate(valid=not r, reasons=r,
                fallback='R68' if len(r) >= 2 else 'PBVS')

# IP-300 QVOI：质量感知主动感知
def quality_voi(b_t, q, cert, budget, acts, scene):
    best = None
    for a in acts:
        if not budget.allow(a): continue
        q2, cq, feasible = dq_reflex_step(q, a, scene, budget)
        if not feasible: continue
        score = (c(psi) * ig_s(b_t, a) + ETA * ig_z(b_t, a)
                 + BETA * (fitness(q2) - fitness(q)) - cq
                 - GAMMA * future_quality_debt(q2))
        if best is None or score > best.score: best = (a, score)
    return best if best and best.score > 0 else None

# IP-301 DSCA：数据供应链审计
def supply_chain_audit(dataset, q_online, policy_card):
    qc   = dataset.quality_card
    qood = quality_ood_score(q_online, qc.q_dist)
    debt = sum(d.p_trigger * d.impact for d in dataset.defects)
    prov = provenance.verify(dataset.chain) and q_online.tchain in qc.lineage
    return SupplyReport(qood, debt, prov, qc.q_dist)

# IP-302 Q-RISK：质量进风险缩放
def quality_risk_scale(U_ale, U_epi, H_z, u_tac, q, cert, p):
    q_neg = 1.0 - min(q.q[j] for j in CRIT)
    u_vs  = sqrt(trace(cert.SigmaL) + p.wZ * cert.u_Z**2)
    base  = U_ale + U_epi + H_z + u_tac + u_vs + p.wq * q_neg
    lam_r = p.lam_base * (1.0 + base / p.lam_scale)
    lam_f = p.lam_floor * (1.0 + base)
    if cert.kappa > p.kappa_soft:
        lam_f = max(lam_f, p.kappa_scale * cert.kappa / p.kappa_ref)
    return max(lam_r, lam_f)

# IP-303 Q-CERT
def J_DQ(M):
    return Cert(emb=J_EMB(M), dq=hash_q(M.dqm.last),
                vsm=M.vsm.last_hash, qood=M.dsca.qood,
                prov=M.dsca.prov_ok, debt=M.dsca.debt,
                qav=M.qav.switch_log, ver='DQ-1')
```

## 4. 推导

**引理 33（质量沿处理链单调不增）** 数据处理不等式 I(s;f(y))≤I(s;y)，且支撑集收缩不可逆 ⇒ 下游无法修复源端质量损失。系：质量否决必须在源端。

**引理 34（压成标量的不可辨识性）** 存在 q₁≠q₂ 使 trace(Σ) 相同但 p(y|s,q₁)≠p(y|s,q₂)（支撑集/观测函数不同）⇒ 标量噪声模型在结构退化下系统性有偏。系：DQP 必须是向量。

**引理 35（κ → 稳定性裕度）** 鲁棒稳定需 λ_min(L̂L⁺) ≥ λ_min(LL⁺) − ‖ΔL‖‖L⁺‖ > 0；‖ΔL‖ 由 q_accuracy、u_Z、q_precision 决定。系：数据质量直接进入闭环稳定裕度，不是"精度指标"。

**引理 36（L4 可正反馈）** 速度↑→precision↓、距离↓→validity↓（FOV），朴素"差就加速靠近"律可使质量单调塌缩；γ-收缩条件可阻断。

**引理 37（QVoI 有限停止）** 质量边际增益递减 + c^q 有正下界 ⇒ 存在有限 n* 使边际净收益≤0。

**定理 27（质量-伺服联合稳定与风险单调）** 在 A111–A115 下，QAV 闭环局部稳定且风险界 ≤ R72；效率仅在"质量可测、L̂ 可解、质量环收缩"时获益。

**定理 28（J_DQ 有效性 ⇒ 数据可信执行）** C_VS 有效 + q∈认证域 + provenance 完整 + J_EMB 有效 ⇒ 执行风险 ≤ ε_DQ。**重量落在"质量度量本身未被同源污染"。**

**定理 29（非补偿质量否决必要性）** 由引理 33/34，允许跨维补偿会放行"分数高但信息已丢"的样本，Fisher 信息低于阈值 ⇒ 风险界失效。故必须按维（Pareto）否决。

**新增假设 A111–A115**：A111 DQP 七维可测且维间近似正交；A112 C_VS 在有效域内保守（Σ_L 覆盖真实 L 误差）；A113 L4 转移 Lipschitz 且可 γ-收缩；A114 provenance 根可信；A115 质量 OOD 检测器在认证域内校准有效。

## 7. 本轮最大风险

**一句话**：DQ-SERVO-GAUGE 把安全又下移一层，从「相信测量链」变成「相信 **数据质量度量本身**、相信 **交互矩阵证书**、相信 **质量转移模型 p(q'|q,a)**」——而这三者恰恰跑在**同一条被审计的数据管线**上、用**同一批可能有缺陷的传感器与标定**来测自己；一旦发生**同源相关失效**（运动模糊同时让 q_precision 偏高、κ(L̂) 偏低；或 provenance 根被俘获、质量 OOD 检测器在压缩流上系统性失明），系统会举着一份「七维全绿、条件数漂亮、来源可追溯」的 J_DQ 证书，在闭环已进入正反馈的那一帧，**自信地、可审计地、逐帧地把相机对准并撞向目标**——这就是**数据层「自信地错自己的数据质量」**。

次级风险与缓解：
1. **质量度量与被测管线同源** → 双传感器/双曝光独立路径 + 交叉见证；关键维单源不定案。
2. **质量维度 Goodhart** → fitness-for-use 由下游闭环实测（伺服误差/失稳率）校准，不靠质量指标自证；引入对抗性质量审计集。
3. **L4 正反馈发散** → 质量预算 + γ-收缩在线检查；谱半径 ≥1 即否决。
4. **交互矩阵极端位形漏判** → 在线微扰探测（dither）估局部 L 秩与条件，成本入质量预算。
5. **质量 OOD 检测器域偏移** → 多检测器集成 + 新相机/新压缩域少量无标注在线校准，校准不确定度入 u_VS。
6. **provenance 根被俘获** → 硬件根信任 + 多哈希锚点 + 离线密封审计；断链默认降级。
7. **复杂度/延迟爆炸** → 硬实时只用 3 个关键维（completeness/timeliness/uniqueness），其余异步；|J_crit|≤3，转移采样 ≤64。
