# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「联邦学习」×「点云配准」）

> R69 给闭环装上了「嘴巴和眼睛」——它学会了问、看、触，并把不确定性二分为 aleatoric / epistemic。但 R69 有一个从没被追问的隐含前提：**它只有一个「可信的自己」，以及一个「大家默认共享的世界坐标系」**。于是 R69 自陈的最大风险（流模型的模态分布不可信 → 在错误的信念上算 VoI → 自信地追问一个幻影）在单机内其实无解：**你无法用同一个可能被骗的模型，去校准它自己的模态**。
>
> 本轮两个灵感正好各补一块：
> - **联邦学习**给出「不确定性是可以跨机互证的资产」——多台设备/机器人/传感器把**认知摘要**而非原始观测**汇聚**，用异质数据覆盖单机校准不到的区域；代价是非 IID、拜占庭、隐私、通信与陈旧度。
> - **点云配准**给出「互证的前提是几何上真的在同一个世界」——跨机证据必须先估计相对位姿 T_ij ∈ SE(3)，而配准自身有**重叠率、退化、外点**，这些是 R69 完全没有的**新 epistemic 源**；更狠的是，配准错误会让「一致」变成「共同错误」。
>
> 核心命题：**把 R69 的「单机自省」升级为「多机互证」，但互证必须过两道门——配准门（我们是否在同一个可对齐的世界里？）与拜占庭门（有没有一个说了算的坏人？）；并且互证只允许收紧、不允许单独放宽（只有独立锚点才能放宽）。** 命名 **FEDRA-RAS**（Federated Epistemic Disambiguation with Registration-based Alignment）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我该信谁的不确定性、我们是否在同一个世界坐标系里**」——求证之前先对表；对不上表的共识，比孤独更危险。

## 0. 直觉与动机

**灵感 1（联邦学习 → 校准是联邦的，信任不是）**
直觉：R69 的模态校准门 MCG（ECE ≤ τ_ece）用的是单机自己的验证集。但「幻觉模态」恰恰最容易出现在**单机没见过的区域**：我这台机器从没在雨夜见过反光地面，我的流模型就可能在雨夜幻觉出一个不存在的模态，而我的 ECE 在本地看起来很好。联邦的价值不是「数据更多」，而是**校准覆盖更宽**：另一个 client 的失败样本正是我的盲区。所以应该交换的不是原始点云/图像，而是**认知摘要**：模态权重、模态内协方差、间距、ECE、位姿协方差、时间戳。这就是「不确定性的联邦化」。但交换一多，信任就散了：有人给假摘要、有人被攻陷、有人只是环境不同（non-IID）。**联邦学习给的是工具，不是信任。**

**灵感 2（点云配准 → 对表是一个有不确定度的动作）**
直觉：跨机残差要比较，先要问「我们的点云能不能对上」。配准给出 T_ij，但它自己也是估计：重叠区域小（partial overlap）时位姿漂；平面/对称场景在某些自由度上**退化**（沿平面平移、绕法向旋转不可观）；动态物体是外点。**一个错误的 T_ij 会把两个不同的世界强行叠成一个，让本来对不上的证据显得严丝合缝。** 所以配准门必须显式携带不确定度（Σ_T、重叠率 ρ、退化指标 D），并决定「可融合 / 弃权」。这把 R69 的「证据可信吗」往前推了一层：「**证据是否在同一个坐标系里**」。

**灵感 3（非 IID → 联邦平均会抹掉真实的本地模态）**
直觉：R69 的模态是「本地语境的歧义」。若把各机的模态分布直接平均，某个只对 A 机成立、但对 B/C 机不成立的真实模态会被平均掉——这叫**模态抹除**，是 client drift 在认知层的版本。所以联邦不能是「一个大平均」，必须是**分层贝叶斯**：全局共识只做先验，本地后验拥有最终解释权；相似环境的 client 才聚类共享。否则联邦不是帮我消歧，而是逼我信一个不属于我的世界。

**灵感 4（共模失效 → 越一致，越自信，越错）**
直觉：拜占庭鲁棒对付的是「少数坏人」。但联邦最深的病是「多数一起错」：所有 client 用同一套标定流程、同一个锚点、同一种系统性偏置，或者被同一束激光/同一种天气骗过。此时它们高度一致，鲁棒聚合会把这种一致当成高置信，**一致性本身伪造了正确性**。这不是统计学能救的（样本再多，共同偏置也不会被平均掉），必须引入**外部独立锚点**——一个不在联邦内、不共享同一偏置的物理或逻辑证据源。这是对 R69 最大风险的正面回应：**光靠问，问不出所有人都错的那件事。**

**灵感 5（隐私与审计 → 摘要也会泄露，也要被审）**
直觉：认知摘要看起来「去标识化」，但位姿协方差 + 模态结构足以做成员推断甚至场景重建；恶意聚合方还能从梯度/摘要反推。联邦的安全不能只靠「没传原图」这句口号，必须：摘要加 DP 噪声、只发布相对位姿而非绝对位姿、审计聚合是否越权、证书里带隐私预算。否则 R70 是把 R69 的数据主权，换成了一张看起来很干净的泄露单。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FEDRA-RAS 总览）** FEDRA-RAS = (FEC, REG, RG, RBA, TSL, CFE, FQI, ARP, PAA, RAS-WM‡)。三不变式：
(i) **原始数据不出域**：跨机只交换认知摘要 s_i（定义 312），且经 PAA 加噪、审计；
(ii) **无配准不融合**：任一跨机证据进入本地后验前，必须通过配准门 RG（定义 314），携带 T_ij、Σ_T、ρ_ij、D_ij；
(iii) **非对称融合**：跨机一致性**只允许收紧** λ（增加保守），**放宽**必须同时满足「配准认证 + 至少一个联邦外独立锚点」（定义 324）；否则退化为 R69 纯本地。

**定义 311（客户端与本地模型）** 客户端集合 𝒞 = {1,…,n}，第 i 个客户端持有本地观测流 o_i、本地流策略 π_{θ_i}（继承 R69 FMP）、本地标定器 COF_i、本地证据集 ℰ_i。无中央假设：聚合可为中心式或 gossip；聚合方与客户端都可能被攻陷。

**定义 312（认知摘要 / 联邦对象）** s_i = (ŵ_{i,k}, ξ̄_{i,k}, Σ_{i,k}, H_mode,i, Δ_min,i, ECE_i, P_i^{pose}, t_i, env_i)，即 R69 的模态分解 + 校准误差 + 局部位姿协方差 + 时间戳 + 环境指纹。**不含原始观测、不含像素/点云**。s_i 经 PAA 加噪后发布。

**定义 313（带不确定度的配准）** 由点云/特征对应估计相对位姿 T_ij ∈ SE(3)，附：
- 重叠率 ρ_ij = |inliers| / min(|P_i|,|P_j|)；
- 位姿协方差 Σ_{ij} ≈ σ²(JᵀWJ)^{-1}（或 bootstrap / RANSAC 重采样）；
- 退化指标 D_ij = λ_min(H_ij)/λ_max(H_ij)（H 为配准信息矩阵）；平面/对称场景 D→0 表示某些自由度不可观。
配准目标：T_ij* = argmin_{T} Σ_{(p,q)∈𝒞_ij} ρ_r(‖T p − q‖)，ρ_r 为鲁棒核（Geman-McClure），外点由 RANSAC/图割剔除。

**定义 314（配准门 RG）** 证据可跨机融合当且仅当：ρ_ij ≥ ρ_min ∧ D_ij ≥ D_min ∧ tr Σ_{ij} ≤ τ_T ∧ t 差 ≤ τ_stale。任一不满足 ⇒ **弃权**：视为「坐标系未对齐」，该客户端证据不得进入本地后验（但可作为「未知」记录）。

**定义 315（证据传输）** 将 client j 的残差/证据 e_j 用 T_ij 变换到本地帧，并按 Σ_{ij} 传播协方差：e_{j→i} = T_ij ⊗ e_j，Σ_{e,j→i} = J_T Σ_{ij} J_Tᵀ + T_ij Σ_{e,j} T_ijᵀ。未通过 RG 的证据不传输（不是传了再丢）。

**定义 316（分层联邦校准 FEC）** 全局共识只作先验：p_cons(M) ∝ p_0(M) · Π_{j∈N(i)} p_j(M | s_j)^{w_ij}；本地后验 p_i(M | o_i, {s_j}) ∝ p_cons(M) · p_i(o_i | M)。邻居权重 w_ij = trust_j · reg_quality_ij · staleness_ij。环境指纹 env_i 相近者优先聚类（Mixture-of-Federations），避免跨异质环境的模态抹除。

**定义 317（信任与陈旧度账本 TSL）** 每个 client 维护信任分 t_j ∈ [0,1]，由历史 ECE_j、配准一致性、审计命中、陈旧度更新：t_j ← (1−β)t_j + β·φ(ECE_j, reg-consistency, audit)。t_j < t_min ⇒ 降权或隔离。

**定义 318（鲁棒拜占庭聚合 RBA）** 对摘要的每个坐标做坐标级截尾均值（trimmed mean，截尾比例 α）或几何中位数；并加**配准一致性过滤**：若 client j 报告的位姿/几何无法与 ≥ k 个其他 client 在 Σ 容差内配准一致，则剔除。输出 Byzantine 比例估计 α̂，用于证书与退避判定。

**定义 319（共模失效检测 CFE）** 监测两个量：共识置信度 c̄ 与意见多样性 div = 1 − (max_k ŵ_k 的集中度 / 跨 client 熵)。若 c̄↑ 而 div↓ 且所有 client 的偏置方向高度相关（残差协方差谱秩 ≈ 1），判为**共模可疑**；此时强制启用**外部独立锚点** a_ext（不同物理原理的传感器 / 未参与联邦的本地残差通道 / 人工校验），并把共识置信度封顶。

**定义 320（联邦查询作为信息动作 FQI）** 在 R69 的增广动作空间 𝒜_+ 上再加一类信息动作 g_fed：向邻居请求摘要/定向观测。代价 c(g_fed) = 通信 + 时延 + 隐私预算消耗。FedVoI(g_fed) = H(M|o_i) − E[H(M|o_i, s_j)]，进入 R69 的 VoI−成本最优选择。**「问机器」与「问人」同框，只是成本项不同。**

**定义 321（主动配准探测 ARP）** 用当前 Σ_{ij} 与退化方向选择下一视角/探针：g_reg* = argmax_g IG(T_ij; y(g)) / cost(g)，即优先补足退化自由度的观测（如绕平面法向移动、增加纹理区域重叠）。这是「为对表而看」，是 R69 的「为消歧而看」在几何层的对应物。

**定义 322（隐私审计聚合 PAA）** 发布摘要前加 DP 机制（对连续量加高斯/拉普拉斯噪声，对模态权重用指数机制），隐私预算 ε_dp 逐轮记账；只发布相对位姿（组内），绝对位姿不出域；离线做成员推断审计，命中即收紧发布粒度。隐私预算耗尽 ⇒ 停止联邦，走 R69。

**定义 323（三层退避塔）** 若配准门不过 / α̂ > α_max / 共模可疑且无外部锚点 / ε_dp 耗尽 / 通信超时 ⇒ 退化为 R69（本地流策略 + 本地交互）；R69 再在 VoI≤成本或 ECE 越界时退化为 R68。形式：FEDRA ⊇ FLUID ⊇ CALM。

**定义 324（非对称融合规则）** 设本地保守水平为 λ_i（继承 R69 定义 307）。跨机证据更新后：
- 若证据要求**更保守**（λ↑）：允许，无需额外条件；
- 若证据要求**放宽**（λ↓，即 resolution bonus）：必须同时满足「RG 通过」∧「外部独立锚点 a_ext 同向」∧「非共模可疑」，否则**不放宽**，取 λ = max(λ_consensus, λ_i)。
即：**一致只能收紧；要放宽，得有一个不属于这个联邦的证据点头。**

**定义 325（证书 J_FEDRA）** J_FEDRA = (J_FLUID, reg_quality = {ρ,D,trΣ}_min, α̂_byz, diversity_div, common_mode_flag, anchor_used, ε_dp_spent, comm_staleness_p95, fedra_ver)。Valid ⇔ Valid(J_FLUID) ∧ RG 质量达标 ∧ 非共模（或有锚点） ∧ 隐私预算未越界。

**定义 326（威胁模型 ℰ_FEDRA 与预算）** ℰ_FEDRA = ℰ_FLUID × ℰ_client（投毒摘要 / 女巫 client / 重放旧摘要）× ℰ_reg（退化的对称几何 / 伪造点云 / 部分重叠误导）× ℰ_common（共模偏置）× ℰ_privacy（成员推断 / 位姿反演）。通信预算：单位时间摘要交换 ≤ B_comm、RTT ≤ τ_rtt、允许陈旧度 ≤ τ_stale。

```python
# IP-264 FEC：分层联邦校准（全局先验 + 本地后验；环境聚类避免模态抹除）
class FederatedEpistemicCalibrator:
    def consensus(self, local, summaries, env_id):
        peers = [s for s in summaries
                 if env_similar(s.env, env_id) and s.trust >= T_MIN]     # 非 IID：先聚类
        prior = local.prior.clone()
        for s in peers:
            w = s.trust * reg_quality(s) * staleness_weight(s.t)
            prior = bayes_prior_update(prior, s.modes, s.weights, w)      # 全局仅作先验
        return bayes_posterior(prior, local.obs_likelihood)              # 本地拥有最终解释权

# IP-265/266 REG + RG：带协方差的配准与配准门
def register_and_gate(pc_i, pc_j):
    T, inliers = robust_registration(pc_i, pc_j)        # RANSAC + Geman-McClure + ICP refine
    rho = len(inliers) / min(len(pc_i), len(pc_j))
    Sigma_T = pose_covariance(T, inliers)               # (J^T W J)^-1 σ^2
    D = degeneracy(pc_i, pc_j, inliers)                 # λ_min(H)/λ_max(H)
    ok = (rho >= RHO_MIN) and (D >= D_MIN) and (trace(Sigma_T) <= TAU_T)
    return T, Sigma_T, rho, D, ok

def transport(evidence_j, T, Sigma_T):
    return transform(evidence_j, T), propagate_cov(evidence_j, T, Sigma_T)

# IP-267 RBA：鲁棒聚合 + 配准一致性过滤
def robust_aggregate(summaries):
    consistent = reg_consistency_filter(summaries, k=K_CONSIST)   # 空间上说谎会被抓
    agg = coordinate_trimmed_mean(consistent, alpha=ALPHA_TRIM)   # 或 geometric_median
    alpha_hat = estimate_byzantine_fraction(summaries, agg)
    return agg, alpha_hat, consistent

# IP-269 CFE：共模失效检测 + 外部锚点
def common_mode_guard(consensus_conf, diversity, residual_spectrum):
    correlated = effective_rank(residual_spectrum) < RANK_MIN
    if consensus_conf > C_HIGH and diversity < DIV_LOW and correlated:
        anchor = query_external_anchor()                # 独立物理原理/非联邦通道
        return True, anchor, min(consensus_conf, C_CAP) # 封顶共识置信度
    return False, None, consensus_conf

# IP-275 主闭环（继承 R69，仅在证据来源与风险缩放入口插入 FEDRA 层）
def FEDRA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)      # R68 标定
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4                    # R69 自适应 K
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, K), z)
    # 0) 是否值得向联邦/邻居求证（FQI 进入 R69 的 VoI 选择）
    g_fed = M.fqi.choose(M.modes, M.budget) if U_epi > TAU_EPI else None
    # 1) 拉取摘要 + 逐对配准门控
    summaries = M.fec.fetch(g_fed) if g_fed else M.fec.cached()
    fused = []
    for s in summaries:
        T, SigT, rho, D, ok = M.reg.register_and_gate(M.local_pc, s.pose, s.cloud_proxy)
        if not ok: continue                                         # 弃权，不传不过门证据
        e, Se = M.reg.transport(s.evidence, T, SigT)
        fused.append((e, Se, s.trust))
    # 2) 鲁棒聚合 + 共模检测
    agg, alpha_hat, peers = M.rba.aggregate(fused)
    cm, anchor, conf_cap = M.cfe.guard(agg.conf, agg.diversity, agg.resid_spec)
    # 3) 分层后验：全局仅先验，本地定音（防模态抹除）
    U_epi_fed = M.fec.posterior(modes, agg, anchor if cm else None)
    # 4) 非对称融合：一致只收紧，放宽要独立锚点
    lam_local = M.efs.risk_scale(...) ; lam_fed = lam_floor(U_ale + U_epi_fed)
    allow_loosen = (not cm) and (anchor is not None) and all_reg_ok
    lam = min(lam_fed, lam_local) if allow_loosen else max(lam_fed, lam_local)
    # 5) 退避塔：任一不可信 → R69 → R68
    if alpha_hat > ALPHA_MAX or M.paa.exhausted() or M.tsl.distrusted():
        return FLUID_RAS_round_69(M, obs)                            # 严格退化 R69
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if cm and anchor is None:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))           # 共模未锚定 → 最保守
    mode = select_mode(modes, U_epi_fed, lam)
    M.vqa_fed.submit_async(g_fed, J_FEDRA(...))                      # 审计 + 隐私预算记账
    return k, lam, mode, (U_ale, U_epi_fed)
```

## 3. 推导

**引理 19（配准门的保守性）** 仅融合通过 RG 的跨机证据时，本地后验方差满足 tr Σ_{post} ≤ tr Σ_{local}；且可获得的方差下降量上界由 Σ_{ij} 与证据信息量共同决定：ΔtrΣ ≤ tr[(Σ_{local}^{-1} + (Σ_{e,j→i}+Σ_{ij})^{-1})^{-1}] 相对衰退。直观：**配准不确定度是证据的「自付成本」，它先吃掉一部分信息增益**——重叠小、退化重时，融合几乎不带来收益，RG 自动弃权。

**引理 20（非 IID 下的模态抹除与个性化必要性）** 设真实模态 m* 只在环境 e_i 中出现（对邻居为低概率）。若用各 client 权重简单平均得共识后验，则 P_cons(m*) → 0（随 n 增大）；改用分层后验 p_i ∝ p_cons · p_i(o_i) 且邻居按 env 聚类时，P_i(m*) 保持有界远离 0。系：**联邦平均会杀死本地真实歧义；只有「先验联邦化、后验本地化」才能在获得覆盖的同时不抹除本地模态**。

**引理 21（拜占庭—配准联合鲁棒）** 设恶意 client 比例 α < 1/2，坐标截尾均值/几何中位数的共识偏差 ≤ g(α, σ)（标准鲁棒统计界）。再叠加配准一致性过滤：恶意 client 要同时伪造摘要**且**与 ≥ k 个诚实 client 在 Σ 容差内几何一致；若伪造方向偏离真实几何，则其被配准门剔除的概率 ≥ 1 − δ_reg。故联合错误率 ≤ α·(1−δ_reg)^k + ε_σ。系：**几何一致性是一张诚实 client 免费获得的「防伪签名」，说谎在空间上会露馅**。

**引理 22（共模不可辨识性）** 若所有 client 共享同一偏差 b（同标定流程 / 同锚点 / 同环境偏置），则任何只依赖 client 间一致性的估计器都满足 argmin 偏差 = b；共识置信度随 n 上升，但其极限是 b，而非真值 0。因此**共模偏置在联邦内部不可辨识**，必须由外部独立锚点 a_ext 打破。这是 R70 最大风险的数学形式。

**定理 18（三层严格包含）** 在 A99–A102 下，FEDRA 在任意状态的期望风险 ≤ R69 ≤ R68；当 RG 全部弃权 / α̂ > α_max / 共模可疑且无锚点 / 隐私预算耗尽时，FEDRA 与 R69 **逐指令相同**；R69 再在 VoI≤成本或 ECE 越界时与 R68 逐指令相同。故 FEDRA 是把 R69 的「单机边界」扩成「多机边界」，安全侧不做任何让步。

**定理 19（非对称融合的安全性与无突变）** 在定义 324 规则下：跨机证据只在「RG 认证 ∧ 外部锚点同向 ∧ 非共模」时允许 λ 下降；其余一律 λ 不降。于是联邦带来的「放宽」永远有一个联邦外见证；结合 R69 定理 17 的认证前缀与换装不变式，λ 的变化对任一跨机事件单调不增（保守性），控制连续、无突变。

## 6. 本轮最大风险

**一句话**：FEDRA-RAS 把「可信」从单机扩展到了联邦，但**共识不是真理**——当所有 client 共享同一套标定偏置、同一锚点偏差、同一环境欺骗，或都被配准到了同一个**错误的公共坐标系**时，它们会**高度一致**；鲁棒聚合与配准门都会把这种一致性当成高置信的证据，于是**越一致越自信、越自信越错**。配准不但救不了，还会把这种共同错误在几何上抹平，让「互相印证」变成「集体幻觉」——这就是 R69「问错比不问更危险」的多机版本：**一起错，比独自错更难发现**。

**次级风险与缓解**：
1. **非 IID 模态抹除**（联邦平均杀死本地真实歧义）→ 分层后验 + 环境聚类（引理 20）；
2. **拜占庭摘要 / 女巫 client** → 截尾均值/几何中位数 + 配准一致性过滤 + 信任账本（引理 21）；
3. **配准退化与错误对表**（平面/对称/低重叠）→ D/ρ/Σ_T 三重配准门，弃权优先（引理 19）；
4. **隐私泄露**（摘要反演位姿/场景）→ DP 摘要 + 相对位姿 + 成员推断审计 + 预算耗尽即停（定义 322）；
5. **实时预算被配准拖垮** → 配准异步低频、热环只做门控、ARP 单次预算外；
6. **共模漏检**（最大风险本身）→ CFE 多样性监测 + 强制外部独立锚点 + 共识置信封顶 + 无锚点即退 R69 最保守。

```python
class FederatedEpistemicCalibrator:
    def consensus(self, local, summaries, env_id):
        prior = local.prior.clone()
        for s in summaries:
            if not env_similar(s.env, env_id) or s.trust < T_MIN: continue
            w = s.trust * reg_quality(s) * staleness_weight(s.t)
            prior = bayes_prior_update(prior, s.modes, s.weights, w)   # 只更新先验
        return bayes_posterior(prior, local.obs_likelihood)             # 本地定音

# IP-265/266 REG + RG：带协方差/退化度的配准与门控
def register_and_gate(pc_i, pc_j, t_j):
    T, inliers = robust_registration(pc_i, pc_j)      # RANSAC + Geman-McClure + ICP
    rho = len(inliers) / min(len(pc_i), len(pc_j))
    Sigma_T = pose_covariance(T, inliers)             # (J^T W J)^-1 σ^2
    D = degeneracy(pc_i, pc_j, inliers)               # λ_min(H)/λ_max(H)
    ok = (rho >= RHO_MIN) and (D >= D_MIN) and (trace(Sigma_T) <= TAU_T) \
         and (abs(now - t_j) <= TAU_STALE)
    return T, Sigma_T, rho, D, ok                     # 不过门 -> 弃权，不传

# IP-267 RBA：配准一致性过滤 + 坐标截尾均值

    return agg, estimate_byzantine_fraction(summaries, agg), peers

    return False, None, conf

    U_epi_fed = M.fec.posterior(modes, agg, anchor if cm else None)
    # 4) 非对称融合：一致只收紧；放宽需配准认证 + 外部锚点 + 非共模
    lam_local = M.efs.risk_scale(...); lam_fed = lam_floor(U_ale + U_epi_fed)
    allow_loosen = (not cm) and (anchor is not None) and all_reg_ok
    lam = min(lam_fed, lam_local) if allow_loosen else max(lam_fed, lam_local)
    # 5) 退避塔：任一不可信即严格退化 R69（再退化 R68）
    if alpha_hat > ALPHA_MAX or M.paa.exhausted() or M.tsl.distrusted():
        return FLUID_RAS_round_69(M, obs)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if cm and anchor is None:                         # 共模未锚定 -> 最保守
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, U_epi_fed, lam)
    M.vqa_fed.submit_async(g_fed, J_FEDRA(...))       # 审计 + 隐私预算记账
    return k, lam, mode, (U_ale, U_epi_fed)
```

## 4. 推导

**引理 19（配准门的保守性）** 仅融合通过 RG 的跨机证据时 `trΣ_post ≤ trΣ_local`；可得方差下降 ≤ `tr[(Σ_local⁻¹+(Σ_{e,j→i}+Σ_ij)⁻¹)⁻¹]` 相对衰退。诱因：**配准不确定度是证据的「自付成本」**，重叠小/退化重时融合几乎无收益，RG 自动弃权。

**引理 20（非 IID 模态抹除与个性化必要性）** 真实模态 `m*` 只在环境 `e_i` 出现。简单平均的共识后验 `P_cons(m*)→0`（随 n）；分层后验 `p_i∝p_cons·p_i(o_i)` 且邻居按 env 聚类时 `P_i(m*)` 保持有界远离 0。系：**先验联邦化、后验本地化**才能既获覆盖又不抹除本地歧义。

**引理 21（拜占庭—配准联合鲁棒）** 恶意比例 `α<1/2` 时截尾均值/几何中位数偏差 ≤ `g(α,σ)`；叠加配准一致性过滤后，恶意 client 需同时伪造摘要且与 ≥k 个诚实 client 几何一致，偏离真实几何时被剔除概率 ≥ `1−δ_reg`，联合错误率 ≤ `α(1−δ_reg)^k + ε_σ`。系：**几何一致性是诚实 client 免费的防伪签名**。

**引理 22（共模不可辨识性）** 若全部 client 共享偏差 `b`，任何仅依赖 client 间一致性的估计器偏差极限为 `b`，共识置信度随 n 上升却收敛到错误；故共模在联邦内部不可辨识，必须由外部独立锚点打破。这是 R70 最大风险的数学形式。

**定理 18（三层严格包含）** A99–A102 下，FEDRA 期望风险 ≤ R69 ≤ R68；当 RG 全弃权 / `α̂>α_max` / 共模可疑无锚点 / `ε_dp` 耗尽时，FEDRA 与 R69 逐指令相同；R69 再在 `VoI≤c` 或 `ECE>τ` 时与 R68 逐指令相同。

**定理 19（非对称融合安全与无突变）** 按定义 324：跨机证据仅在「RG ∧ 外部锚点同向 ∧ 非共模」时允许 λ↓，否则 λ 不减。故联邦带来的放宽永远有联邦外见证；结合 R69 定理 17 的认证前缀与换装不变式，λ 对任一跨机事件单调不增，控制连续无突变。

## 7. 本轮最大风险

**一句话**：FEDRA-RAS 把「可信」从单机扩展到联邦，但**共识不是真理**——当所有 client 共享同一套标定偏置、同一锚点偏差、同一环境欺骗，或都被配准到同一个**错误的公共坐标系**时，它们会高度一致；鲁棒聚合与配准门会把这种一致当成高置信证据，于是**越一致越自信、越自信越错**。配准不但救不了，还会把共同错误在几何上抹平，让「互相印证」变成「集体幻觉」——R69「问错比不问更危险」的多机版：**一起错，比独自错更难发现**。

**次级风险与缓解**：非 IID 模态抹除（分层后验 + 环境聚类，引理 20）；拜占庭摘要/女巫（截尾均值/几何中位数 + 配准一致性过滤 + 信任账本，引理 21）；配准退化/错误对表（D/ρ/Σ_T 三重配准门，弃权优先，引理 19）；隐私泄露（DP 摘要 + 相对位姿 + 成员推断审计 + 耗尽即停，定义 322）；实时预算被配准拖垮（配准异步低频、热环只门控、ARP 单次预算外）；共模漏检（CFE 多样性监测 + 强制外部锚点 + 置信封顶 + 无锚点退 R69 最保守，引理 22）。
