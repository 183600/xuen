# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「避障控制」×「竞品分析」）

> 第 66 轮 RAS 把「被动故障响应闭环」升级为「主动意图感知闭环」，但它仍是一个**单专家系统**：一个归因器、一个认证前缀、一个控制律。这正是它的天花板——**在开放世界里，没有任何单一避障器在所有场景最优**：CBF-QP 可证但保守，MPC 敏捷但依赖模型，学习策略灵活但不可证。
>
> 本轮灵感的核心命题是：
>
> **把「单专家认证闭环」升级为「竞品组合的竞争性认证闭环」：让一组异构避障专家在影子模式里互相竞争，用竞争比与遗憾界做在线调度，用专家分歧探测新颖障碍，用权重无关的安全护盾兜底，构成「竞品避障（CAPO: Competitive Avoidance Portfolio with Online Certification）」。**
>
> CAPO 问的既不是「故障该去哪儿」（VISTA），也不是「谁该控制、控制多少」（RAS），而是：
>
> **「此刻哪一个竞品最可信、可信到什么程度、当它们吵起来时该听谁的」。**

## 0. 直觉与动机

**灵感 1（避障控制 → 从「单滤波器」到「专家组合」）**
直觉：避障控制的核心矛盾是**保守性 vs 敏捷性**，而这个矛盾无法被单一控制器同时解决。CBF-QP 的安全集是几何的、可证的；MPC 的预测是模型的、前瞻的；学习策略是数据的、分布的。三者失效的方式**互不重叠**——这恰恰是组合（portfolio）能赢的根本原因。把它们压成一个「最优控制器」，等于主动丢弃「多重模型分歧」这一最有信息量的信号。

**灵感 2（竞品分析 → 竞争比与遗憾，而不是 PPT）**
直觉：商业上的「竞品分析」问三件事——市场份额、优劣势、在哪些场景会被击败。技术上的 **competitive analysis** 恰好给了这三件事的严格版本：
- **份额** ↔ 在线学习权重 `w_t`（Hedge / EXP3）；
- **优劣势** ↔ 每个专家的反事实损失曲线 `ℓ_t(e_i)`；
- **失效场景** ↔ 对抗基准生成器搜出的 regret 尖峰。

于是「竞品分析」不是修辞，而是**带后悔界（regret bound）的在线组合选择**。

**灵感 3（三种「竞品」必须同时被分析）**
直觉：本轮把「竞品」分成三层，缺一不可：
1. **外部竞品**：CBF-QP、MPC、HJ 可达集、学习避障策略——技术对标；
2. **内部竞品**：VISTA（第 65 轮）、RAS（第 66 轮）——必须诚实证明新框架在指定指标上不劣，否则研究循环就是自说自话；
3. **影子竞品（shadow competitors）**：真实系统里没被选中的专家，在回放状态上做**反事实推演**——这是竞争分析的燃料，也是最大风险源（见第 6 节）。

**灵感 4（合流 → CAPO：Competitive Avoidance Portfolio with Online Certification）**
闭环从 RAS 的「ERG→EFS→C-RAS→ERS」升级为：
1. **EAB Expert Avoidance Bench**：维护异构避障专家池，每个专家自带安全集与证书谓词；
2. **CAE Competitive Analysis Engine**：影子回放 + 反事实成本，Hedge 重加权，输出竞争比/遗憾；
3. **CAD Competitor-Aware Disagreement**：专家分歧度 `D_t`，作为新颖障碍与模型失配的探测器；
4. **PS Portfolio Shield**：把组合动作投影到 top-k 专家的安全集交集，安全性**与权重无关**；
5. **CAP Competitor Arbitration Protocol**：分歧超阈 → Flight-to-Safety（转移到最保守的已认证专家）；
6. **RCB Red-team Competitor Benchmark**：对抗搜索让组合「输给最优专家」的障碍配置，产出竞争比画像；
7. **CAA Competitor Attribution**：用 Shapley 分解遗憾尖峰，做「竞品归因」——接回 VISTA 的故障归因。

**灵感 5（与前作的接口，而不是替代）**
- **与 VISTA 的接口**：`D_t` 是新的故障证据通道；RCB 是新的干扰集生成器 `ℰ_comp`；
- **与 RAS 的接口**：`λ_risk` 不再直接缩放控制量，而是作为**避险套利信号**——风险上升时把组合权重「逃向安全」（flight-to-safety），即 `w_t ← (1-λ_risk)·w_t + λ_risk·e_{i_conservative}`；
- **安全解耦**：RAS 的认证前缀保证「单专家可执行性」，CAPO 的护盾保证「组合可行性」，两者相乘而非相加，避免保守性叠加。

## 1. 形式化定义（增量：定义 245–256）

- **定义 245（CAPO 总览）**：CAPO = (EAB, CAE, CAD, PS, CAP, RCB, CAA, J_CAPO)。定位：把 VISTA/RAS 的「单专家认证闭环」升级为「多竞品组合认证闭环」。不变式：实时流只做专家前向、护盾 QP 投影与安全停机；语义流做影子回放、竞争分析、分歧归因、权重更新与证书构建；在线权重是可审计的带界更新，**不做梯度学习写操作**。
- **定义 246（避障专家）**：专家 `e_i = (π_i, S_i, C_i)`，其中 `π_i: X×O→A` 为避障策略，`S_i ⊆ X` 为宣称安全集，`C_i: X×A→{0,1}` 为证书谓词。称 `e_i` 在 `(x,o)` 上**已认证**，当且仅当 `C_i(x, π_i(x,o)) = 1`。
- **定义 247（影子竞品）**：在状态 `x_t` 上对所有专家并行前向，得动作集 `𝔞_t = {a_i^t = π_i(x_t, o_t)}_{i=1..n}`，称为影子动作。称 `(x_t, o_t)` 的回放流为影子流；影子流与执行流的时间差记作 `Δ_shadow`。
- **定义 248（安全调整损失）**：`ℓ_t(e_i) = w_s·𝟙[a_i^t ∉ Safe(x_t)] + w_e·d(a_i^t, a_t^*) + w_c·c_i^t`，其中 `a_t^*` 为事后最优安全动作，`c_i^t` 为计算成本。组合损失 `ℓ_t(w) = Σ_i w_{t,i} ℓ_t(e_i)`。
- **定义 249（竞争比与遗憾）**：累计 `J_i(T)=Σ_t ℓ_t(e_i)`，事后最优 `J^*(T)=min_i J_i(T)`。遗憾 `R_T = J_port(T) − J^*(T)`；安全竞争比 `ρ_safe(T) = V_port(T) / (min_i V_i(T) + ε)`，其中 `V` 为累计违规量。
- **定义 250（竞品分歧度）**：`D_t = max_{i≠j} d(a_i^t, a_j^t) / scale`。若 `D_t > τ_dis`，标记 `competitor_disagreement = True`；在共享名义动力学与 Lipschitz 策略下，`D_t` 是障碍离训练流形距离的下界代理。
- **定义 251（组合安全护盾）**：`ā_t = Σ_i w_{t,i} a_i^t`；护盾解 `a_t^safe = argmin_{a∈A} ||a − ā_t||²` s.t. 对所有权重 `w_{t,i} ≥ w_min` 的专家 `C_i(x_t,a)=1` 且 CBF 约束 `B_i(x_t,a) ≥ 0`。若 QP 不可行，返回 `⊥`，触发安全停机。
- **定义 252（Flight-to-Safety 仲裁）**：若 `D_t > τ_dis`，`w_t ← (1−λ_risk)·w_t + λ_risk·δ_{i_cons}`，其中 `i_cons = argmin_{i: C_i=1} risk_i(x_t)` 为最保守的已认证专家；若无已认证专家，转 VISTA 故障重归因。
- **定义 253（竞争认证前缀）**：`k*CAPO` 为最大 `k`，使 `∀s≤k`：护盾在块 `A[s]` 上可行、竞争边际 `Δ_s = ℓ_s(w)−ℓ_s^* ≤ τ_comp`、且 `λ_risk(s)·ρ_safe(s) ≥ 0`；并满足 `k*CAPO ≤ min(m_VISTA, m_emotion, m_comp)`。
- **定义 254（对抗竞品基准）**：`μ_adv = argmax_{μ∈M} E_{scene∼μ}[R_T(μ)]`，`M` 为障碍位置/尺寸/速度的可行族；用 CEM / 贝叶斯优化在可微仿真中求解，输出各场景族上的**竞争比画像**。
- **定义 255（竞品归因）**：遗憾尖峰处，用 Shapley 值 `φ_i = Σ_{S⊆ℰ\{i}} (|S|!(n−|S|−1)!/n!)·[R(S∪{i})−R(S)]` 分解「哪个竞品的缺席最能解释本次遗憾」，输出 `(i*, cause)`。
- **定义 256（J_CAPO 证书）**：`J_CAPO = (J_RAS, w_t snapshot, ρ_safe(T), D_t trace, RCB_version, arbitration_log)`。Valid ⇔ `Valid(J_RAS) ∧ ρ_safe(T) ≤ ρ_max ∧ shield_feasible ∧ benchmark_covered`。

## 2. 关键算法骨架

```python
# EAB：避障专家池（异构接口 + 影子模式）
class ExpertAvoidanceBench:
    def __init__(self, experts):
        self.experts = experts            # [(name, policy, safe_set, certificate)]
    def shadow_actions(self, x, o):
        return {e.name: e.policy(x, o) for e in self.experts}
    def cost(self, x, o, a, a_star):
        return (self.ws * (not self.in_safe(x, a))
                + self.we * self.dist(a, a_star)
                + self.wc * self.experts[a.name].last_cost)

# CAE：竞争分析引擎（Hedge + 竞争比/遗憾）
class CompetitiveAnalysisEngine:
    def __init__(self, n, T):
        self.w = [1.0 / n] * n
        self.eta = math.sqrt(8 * math.log(n) / T)
    def update(self, losses):
        z = sum(w * math.exp(-self.eta * l) for w, l in zip(self.w, losses))
        self.w = [w * math.exp(-self.eta * l) / z
                  for w, l in zip(self.w, losses)]
    def metrics(self, J_port, J_star):
        return {'regret': J_port - J_star,
                'rho': J_port / max(J_star, 1e-9)}

# CAD：竞品分歧探针
class CompetitorAwareDisagreement:
    def score(self, actions):
        vals = list(actions.values())
        return max(self.dist(a, b) for a, b in combinations(vals, 2)) / self.scale
    def novel(self, D):
        return D > self.tau_dis

# PS：组合安全护盾（权重无关）
class PortfolioShield:
    def project(self, a_bar, x, top_experts):
        cons = [e.cbf(x) for e in top_experts]
        try:
            return self.solve_qp(a_bar, cons)   # min ||a-a_bar||^2
        except Infeasible:
            return None                          # 触发安全停机

# CAP：竞品仲裁（Flight-to-Safety）
class CompetitorArbitration:
    def arbitrate(self, w, actions, D, lambda_risk, x):
        if D <= self.tau_dis:
            return w
        certified = [i for i, e in enumerate(self.experts)
                     if e.certificate(x, actions[e.name])]
        if not certified:
            return None                          # 转 VISTA 重归因
        i_cons = min(certified, key=lambda i: self.experts[i].risk(x))
        return [(1 - lambda_risk) * wi + lambda_risk * (i == i_cons)
                for i, wi in enumerate(w)]

# RCB：对抗竞品基准（CEM 搜索遗憾尖峰）
class RedTeamCompetitorBenchmark:
    def search(self, family, budget):
        mu = family.prior()
        best = -inf
        for _ in range(budget):
            scenes = family.sample(mu, N)
            regs = [self.regret(s) for s in scenes]
            mu = self.elite_update(mu, scenes, regs)
            best = max(best, max(regs))
        return mu, best

# CAA：竞品归因（Shapley 遗憾分解）
def competitor_attribution(experts, regret_fn, t):
    n = len(experts)
    phi = {e: 0.0 for e in experts}
    for e in experts:
        for S in subsets(set(experts) - {e}):
            coef = math.factorial(len(S)) * math.factorial(n-len(S)-1) / math.factorial(n)
            phi[e] += coef * (regret_fn(S | {e}, t) - regret_fn(S, t))
    return max(phi, key=phi.get), phi

# 主闭环
def CAPO_round(M, x, obstacles, img):
    # 1) 影子竞品
    acts = M.eab.shadow_actions(x, obstacles)
    losses = [M.eab.cost(x, obstacles, a, M.a_star) for a in acts.values()]

    # 2) 竞争分析
    M.cae.update(losses)
    w = M.cae.w
    a_bar = weighted_mean(acts, w)

    # 3) 分歧探测 + RAS 避险套利
    D = M.cad.score(acts)
    lambda_risk = M.ras.risk_scale(M.ras.joint_post)
    w = M.cap.arbitrate(w, acts, D, lambda_risk, x)
    if w is None:
        return M.vista.re_attribute(M.ras.joint_post)

    # 4) 组合安全护盾（权重无关兜底）
    top = topk(w, M.m_top)
    a_safe = M.ps.project(weighted_mean(acts, w), x, top)
    if a_safe is None:
        return M.ras.safe_stop()

    # 5) 竞争认证前缀 + 证书
    k_capo = M.csc.certified_prefix_capo(M.blocks, w, D, lambda_risk)
    J = M.j_capo.build(w, M.cae.metrics(M.J_port, M.J_star), D)
    return a_safe, k_capo, J
```

## 3. 推导

**引理 11（影子竞品反事实的无偏性）** 若状态分布平稳、专家策略确定，则影子损失是执行损失的**无偏估计**；当影子流与执行流的分布差异为 `TV(P_shadow, P_exec)` 时，偏差满足 `|E[ℓ_shadow − ℓ_exec]| ≤ 2·L_ℓ·TV`。推论：`Δ_shadow` 越小、回放越稳，竞争分析越可信。

**引理 12（护盾使安全与权重解耦）** 若护盾 QP 在每步可行，则对任意权重 `w_t` 有 `P(违规) ≤ P(护盾不可行)`。证明：护盾把动作投影到 top-k 专家安全集交集的凸子集内，该集合不含违规点；权重只改变投影的「目标点」`ā_t`，不改变约束集。故安全性由约束集而非权重决定。

**引理 13（分歧度下界新颖性）** 设专家共享名义动力学、各策略 Lipschitz 常数为 `L_π`，近似误差上界 `ε_approx`。则障碍离训练流形距离 `dist(o_t, M_train)` 满足
`D_t ≥ (1/scale)·[2·L_π·dist(o_t, M_train) − 2·ε_approx]_+`。
即分歧度尖峰是新颖障碍的**可证代理信号**——「竞品吵架」意味着「有人没见过这个场景」。

**定理 11（CAPO 端到端安全-竞争一致性）** 在引理 11–13 与护盾可行下，取 Hedge 步长 `η = sqrt(8 ln n / T)`：
1. `P(违规) ≤ α_chunk + δ_fi + α_emotion + P(护盾不可行)`；
2. `J_port(T) ≤ J^*(T) + sqrt((T/2)·ln n) + T·P(护盾不可行)`；
3. 于是 `ρ_safe(T) ≤ 1 + [sqrt((T/2)·ln n) + T·P_不可行] / J^*(T) = 1 + O(sqrt(ln n / T))`。
解读：安全性由护盾兜底，竞争性由 Hedge 保证；两者「相乘」而非「相加」，避免了保守性叠加。

**定理 12（对抗竞品基准的覆盖保证）** 若 RCB 返回场景族的 `ε`-覆盖，且对抗最大遗憾为 `R_adv`，则真实场景族上的最坏遗憾 `≤ R_adv + L_R·ε`（`L_R` 为遗憾对场景参数的 Lipschitz 常数）。即 RCB 是一个**合法的可证伪 oracle**（在 `ε` 分辨率内）。

## 6. 本轮最大风险

**一句话**：CAPO 的全部安全-竞争保证都建立在「影子竞品能忠实反演未选中专家的反事实」这一假设上——一旦状态分布偏移使影子回放失真，竞争分析会**系统性地淘汰最保守的那个专家**，而护盾又恰在新颖障碍上最可能不可行，于是「组合」在最需要它的场景里静默退化为单点故障。

**次级风险与缓解**：
1. **反事实失真**：用重要性采样 + 保守回放池；TV 超阈时冻结权重并切最保守专家；
2. **护盾不可行**：定义 `⊥ → safe_stop` 的硬保证，并把不可行率作为证书必填项；
3. **竞品同质化**：专家池多样性约束（失效模式距离 ≥ δ），否则组合退化为「同一专家的多个副本」；
4. **RCB 过拟合场景族**：保留 held-out 场景族，只报告未参与搜索的竞争比画像；
5. **内部竞品不公**：VISTA/RAS 必须在相同感知预算、相同安全护盾下比较，禁止「给自己开小灶」。

# 第 67 轮产物 · 创新点清单 v1：CAPO（Competitive Avoidance Portfolio with Online Certification：竞品避障组合；EAB×CAE×CAD×PS×CAP×RCB×CAA）

> 承接第 66 轮 IP-224~233（RAS：情绪驱动闭环）与第 65 轮 IP-214~223（VISTA：故障可归因闭环）。前两轮各自把「单点」做到了极致：VISTA 解决「哪一层坏了」，RAS 解决「谁该控制、控制多少」。本轮补上最后一块：**没有哪个单一避障器永远可信，因此必须让多个「竞品」在影子中竞争，并让安全性独立于竞争结果。**

> IP 编号：IP-234~IP-243（共 10 个），全部为 CAPO 的核心组件。

## 2. 形式化定义（完整版）

**定义 245（CAPO 总览）**
```
CAPO = (EAB, CAE, CAD, PS, CAP, RCB, CAA, J_CAPO)
```
不变式：实时流只做专家前向、护盾 QP 投影、安全停机；语义流做影子回放、竞争分析、分歧归因、权重更新、证书构建。在线权重是带界、可审计的乘性更新，**不做梯度学习写操作**。

**定义 246（避障专家）**
```
e_i = (π_i, S_i, C_i),  π_i: X×O→A,  S_i ⊆ X,  C_i: X×A→{0,1}
```
`e_i` 在 `(x,o)` 上已认证 ⇔ `C_i(x, π_i(x,o)) = 1`。

**定义 247（影子竞品）**
```
𝔞_t = { a_i^t = π_i(x_t, o_t) }_{i=1..n}
```
影子流与执行流的时间差 `Δ_shadow`；`Δ_shadow` 越小，反事实越可信（引理 11）。

**定义 248（安全调整损失）**
```
ℓ_t(e_i) = w_s·𝟙[a_i^t ∉ Safe(x_t)] + w_e·d(a_i^t, a_t^*) + w_c·c_i^t
ℓ_t(w)   = Σ_i w_{t,i}·ℓ_t(e_i)
```

**定义 249（竞争比与遗憾）**
```
J_i(T) = Σ_{t≤T} ℓ_t(e_i),   J^*(T) = min_i J_i(T)
R_T = J_port(T) − J^*(T)
ρ_safe(T) = V_port(T) / (min_i V_i(T) + ε)
```

**定义 250（竞品分歧度）**
```
D_t = max_{i≠j} d(a_i^t, a_j^t) / scale
```

**定义 251（组合安全护盾）**
```
ā_t = Σ_i w_{t,i}·a_i^t
a_t^safe = argmin_{a∈A} ||a − ā_t||²
           s.t. ∀i: w_{t,i} ≥ w_min ⇒ C_i(x_t,a)=1 ∧ B_i(x_t,a) ≥ 0
```
不可行时返回 `⊥`，触发安全停机。

**定义 252（Flight-to-Safety 仲裁）**
```
若 D_t > τ_dis:
   i_cons = argmin_{i: C_i=1} risk_i(x_t)
   w_t ← (1−λ_risk)·w_t + λ_risk·δ_{i_cons}
若 {i: C_i=1} = ∅: 转 VISTA 重归因
```

**定义 253（竞争认证前缀）**
```
k*CAPO = max k  s.t. ∀s≤k:
   护盾可行(A[s])
   Δ_s = ℓ_s(w) − ℓ_s^* ≤ τ_comp
   λ_risk(s)·ρ_safe(s) ≥ 0
且 k*CAPO ≤ min(m_VISTA, m_emotion, m_comp)
```

**定义 254（对抗竞品基准）**
```
μ_adv = argmax_{μ∈M} E_{scene∼μ}[ R_T(μ) ]
```
`M` 为障碍位置/尺寸/速度可行族；CEM / 贝叶斯优化求解，输出竞争比画像。

**定义 255（竞品归因）**
```
φ_i = Σ_{S⊆ℰ\{i}} (|S|!(n−|S|−1)!/n!)·[R(S∪{i}) − R(S)]
(i*, cause) = argmax_i φ_i
```

**定义 256（J_CAPO 证书）**
```
J_CAPO = (J_RAS, w_t snapshot, ρ_safe(T), D_t trace, RCB_version, arbitration_log)
Valid ⇔ Valid(J_RAS) ∧ ρ_safe(T) ≤ ρ_max ∧ shield_feasible ∧ benchmark_covered
```

## 3. 关键算法伪代码

```python
# IP-235 EAB：专家池 + 影子前向
class ExpertAvoidanceBench:
    def __init__(self, experts):
        self.experts = experts
    def shadow_actions(self, x, o):
        return {e.name: e.policy(x, o) for e in self.experts}
    def cost(self, x, o, name, a, a_star):
        e = self.by_name[name]
        return (self.ws * (not e.in_safe(x, a))
                + self.we * self.dist(a, a_star)
                + self.wc * e.last_cost)


# IP-236 CAE：Hedge 竞争分析
class CompetitiveAnalysisEngine:
    def __init__(self, n, T):
        self.w = [1.0 / n] * n
        self.eta = math.sqrt(8 * math.log(n) / T)
    def update(self, losses):
        z = sum(w * math.exp(-self.eta * l) for w, l in zip(self.w, losses))
        self.w = [w * math.exp(-self.eta * l) / z
                  for w, l in zip(self.w, losses)]
    def metrics(self, J_port, J_star):
        return {'regret': J_port - J_star,
                'rho': J_port / max(J_star, 1e-9)}


# IP-237 CAD：竞品分歧探针
class CompetitorAwareDisagreement:
    def score(self, actions):
        vals = list(actions.values())
        return max(self.dist(a, b)
                   for a, b in itertools.combinations(vals, 2)) / self.scale
    def novel(self, D):
        return D > self.tau_dis


# IP-238 PS：权重无关的组合安全护盾
class PortfolioShield:
    def project(self, a_bar, x, top_experts):
        cons = [e.cbf(x) for e in top_experts]
        try:
            return solve_qp(a_bar, cons)       # min ||a − a_bar||²
        except Infeasible:
            return None                         # → safe_stop


# IP-239 CAP：Flight-to-Safety 仲裁
class CompetitorArbitration:
    def arbitrate(self, w, actions, D, lambda_risk, x):
        if D <= self.tau_dis:
            return w
        certified = [i for i, e in enumerate(self.experts)
                     if e.certificate(x, actions[e.name])]
        if not certified:
            return None                         # → VISTA 重归因
        i_cons = min(certified, key=lambda i: self.experts[i].risk(x))
        return [(1 - lambda_risk) * wi + lambda_risk * (i == i_cons)
                for i, wi in enumerate(w)]


# IP-241 RCB：对抗竞品基准
class RedTeamCompetitorBenchmark:
    def search(self, family, budget):
        mu, best = family.prior(), -float('inf')
        for _ in range(budget):
            scenes = family.sample(mu, self.N)
            regs = [self.regret(s) for s in scenes]
            mu = self.elite_update(mu, scenes, regs)
            best = max(best, max(regs))
        return mu, best


# IP-242 CAA：Shapley 竞品归因
def competitor_attribution(experts, regret_fn, t):
    n = len(experts)
    phi = {e: 0.0 for e in experts}
    for e in experts:
        rest = set(experts) - {e}
        for r in range(len(rest) + 1):
            for S in itertools.combinations(rest, r):
                coef = (math.factorial(len(S))
                        * math.factorial(n - len(S) - 1) / math.factorial(n))
                phi[e] += coef * (regret_fn(set(S) | {e}, t)
                                  - regret_fn(set(S), t))
    return max(phi, key=phi.get), phi


# IP-243 主闭环
def CAPO_round(M, x, obstacles, a_star):
    acts = M.eab.shadow_actions(x, obstacles)
    losses = [M.eab.cost(x, obstacles, name, a, a_star)
              for name, a in acts.items()]

    M.cae.update(losses)
    w = M.cae.w

    D = M.cad.score(acts)
    lambda_risk = M.ras.risk_scale(M.ras.joint_post)
    w = M.cap.arbitrate(w, acts, D, lambda_risk, x)
    if w is None:
        return M.vista.re_attribute(M.ras.joint_post)

    top = topk(w, M.m_top)
    a_bar = weighted_mean(acts, w)
    a_safe = M.ps.project(a_bar, x, top)
    if a_safe is None:
        return M.ras.safe_stop()

    k_capo = M.csc.certified_prefix_capo(M.blocks, w, D, lambda_risk)
    J = M.j_capo.build(w, M.cae.metrics(M.J_port, M.J_star), D)
    return a_safe, k_capo, J
```

## 4. 推导

**引理 11（影子竞品反事实的无偏性）** 平稳状态分布 + 确定策略下，影子损失是执行损失的无偏估计；分布差异 `TV(P_shadow, P_exec)` 导致偏差 `|E[ℓ_shadow−ℓ_exec]| ≤ 2·L_ℓ·TV`。故 `Δ_shadow` 与回放稳定性是竞争分析可信度的上界来源。

**引理 12（护盾使安全与权重解耦）** 若护盾 QP 每步可行，则对任意 `w_t`：`P(违规) ≤ P(护盾不可行)`。证明：投影目标落在 top-k 专家安全集交集的凸子集内，权重仅改目标点 `ā_t`，不改约束集。

**引理 13（分歧度下界新颖性）** 共享名义动力学、策略 Lipschitz 常数 `L_π`、近似误差 `ε_approx`：
```
D_t ≥ (1/scale)·[ 2·L_π·dist(o_t, M_train) − 2·ε_approx ]_+
```

**定理 11（CAPO 端到端安全-竞争一致性）** 取 `η = sqrt(8 ln n / T)`，护盾可行时：
1. `P(违规) ≤ α_chunk + δ_fi + α_emotion + P(护盾不可行)`；
2. `J_port(T) ≤ J^*(T) + sqrt((T/2)·ln n) + T·P(护盾不可行)`；
3. `ρ_safe(T) ≤ 1 + O(sqrt(ln n / T))`。

**定理 12（对抗竞品基准覆盖保证）** 若 RCB 给出场景族 `ε`-覆盖、对抗最大遗憾 `R_adv`，则真实最坏遗憾 `≤ R_adv + L_R·ε`。RCB 是 `ε` 分辨率内的合法可证伪 oracle。

## 6. 本轮最大风险

**一句话**：CAPO 的全部安全-竞争保证都建立在「影子竞品能忠实反演未选中专家的反事实」这一假设上——一旦状态分布偏移使影子回放失真，竞争分析会系统性地淘汰最保守的那个专家，而护盾又恰在新颖障碍上最可能不可行，于是「组合」在最需要它的场景里静默退化为单点故障。

**次级风险与缓解**：
1. **反事实失真**：重要性采样 + 保守回放池；`TV` 超阈即冻结权重并切最保守专家；
2. **护盾不可行**：`⊥ → safe_stop` 作为硬保证，不可行率列为证书必填；
3. **竞品同质化**：强制失效模式距离 `≥ δ`，否则组合退化为「同一专家的多个副本」；
4. **RCB 过拟合**：保留 held-out 场景族，只报告未参与搜索的竞争比；
5. **内部竞品不公**：VISTA/RAS 与 CAPO 必须在相同感知预算、相同护盾下比较，禁止给自己开小灶。
