# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「力矩控制」×「本体感知」）

> 第 54 轮把技能从能力黑箱提升为动作空间占用 `α_S`，并用云边契约把组合证书化。但动作空间 `A` 仍是**运动学**的：它只问“能否到达”，不问“能否在接触中施加并承受所需的力”。本轮用**力矩控制**把动作空间从位形提升到力/阻抗，用**本体感知**给边端一个可在线校验的自我状态估计。核心矛盾：H22：运动学兼容的技能在力矩域可能不相容（执行器饱和、阻抗突变导致失稳）；H23：本体感知给出的“自洽”可能是自信错误（自由空间准、接触/负载下盲），从而伪造可部署性。

## 0. 直觉与动机

**灵感 1（动作空间 → 力矩-阻抗空间）**
直觉：机器人真正的执行变量不是关节位置，而是力矩/阻抗。技能 `S` 的“动作”应是在时间上的一条力矩-阻抗轨迹 `(τ(t), Z(t))`，`Z=(K,D)`。一个位形上可达的抓取，若所需 `τ` 超出执行器上限、或阻抗从刚性突变为柔性，边端就不可执行。故把 `α_S` 升级为 **`β_S : T → [0,1]`**，`T` 为力矩-阻抗空间；兼容性不再只是集合重叠，而是“力矩可行域交集 + 阻抗过渡连续 + 裕度非负”。

**灵感 2（本体感知作为运行时见证）**
直觉：动作剖面是离线承诺，本体感知是运行时证人。关节编码器、力矩传感器、IMU、接触估计给出历史 `h_t`，自模型 PSM 预测 `ŝ_t` 与不确定度 `Σ_t`。残差 `r_t` 小则“身体按合同在动”，`r_t` 大则说明合同失效——这正是把静态证书变成**可动态证伪的证书**的关键。没有本体感知，`A_cert` 只是纸面承诺；有了它，才有可触发的绊线。

**灵感 3（力矩裕度：从“可行”到“有裕度地可行”）**
直觉：贴边界的技能在组合意义上是不可用的，因为任何扰动都会越界。定义力矩裕度 `m_τ = min_t (τ_max - |τ_S(t)|)/τ_max`，要求 `m_τ ≥ μ_min`。裕度是组合的第一类风险预算：两个各自 `m_τ=0.05` 的技能串联，转换瞬间往往 `m_τ<0`。这条把第 54 轮“可行即证书”修正为“留余量才证书”。

**灵感 4（本体感知的可观测性，而非精度）**
直觉：本体感知的致命问题不是噪声大，而是某些状态**不可观测**（无力矩传感时接触力方向、未知负载质量）。定义可观测性下界 `δ_obs` 与最小可检测力 `δ_τ`；若组合任务所需的力差 `< δ_τ`，则“自模型看起来准”也没有判定力。证书必须携带 `δ_obs`，而不是只携带标定误差 `ε_p`。这是本轮最反直觉的一点：**自模型的高精度可能来自对不可观测维度的先验填充，而非真实感知**。

**灵感 5（力矩-本体感知契约与反射）**
直觉：云边契约 `C_ce` 增加力矩层：云端下发力矩/阻抗轨迹与裕度预算，边端用本体感知残差与力矩裕度做在线监控，越界时触发**反射**（软化阻抗、卸力、回传 `Explain`），而不是等任务失败。反射是本体感知闭环的“断路器”，必须短于系统失稳时间尺度。

**灵感 6（金字塔再叠两层）**
直觉：在第 54 轮动作协同层 `𝔸` 之上加 **`𝕋` 力矩-阻抗层**（T0 执行器极限、T1 技能力矩剖面、T2 云边阻抗映射、T3 任务力序列）与 **`ℙ` 本体感知层**（P0 传感器、P1 自模型、P2 残差监控、P3 反射）。跨层证书需同时携带 `ρ、A_cert、β_S、PSM_cert`，形成**动作-力-自身感知三证书体系**。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（力矩-阻抗动作剖面）**
力矩-阻抗空间 `T = {(τ, Z) | τ ∈ ℝ^n, Z=(K,D) ⪰ 0}`。技能 `S` 的剖面 `β_S : T × [0,T_h] → [0,1]`。**力覆盖** `cover_τ(S, T_T)=1` 当且仅当 `∀t, β_S(τ_T(t), Z_T(t), t) ≥ θ_τ`，`T_T` 为任务力/阻抗轨迹。

**定义 122（力矩裕度）**
`m_τ(S) = min_t min_j (τ_j^max - |τ_{S,j}(t)|)/τ_j^max`。组合可行需 `m_τ(S) ≥ μ_min`，且沿组合轨迹的裕度不得低于 `μ_min`（转换段单独计）。

**定义 123（阻抗连续性与转换成本）**
阻抗 Lipschitz 常数 `Lip(Z_S) = sup_{t≠t'} ||Z_S(t)-Z_S(t')|| / |t-t'|`。力矩转换成本
`c_τ(S_i,S_j) = ||Z_i(T_h)-Z_j(0)|| + λ·max_t |τ_{S_i}(T_h)-τ_{S_j}(0)|`，要求 `c_τ ≤ τ_τ`。

**定义 124（本体感知自模型 PSM）**
`f_p : h_{t-k:t} → (ŝ_t, Σ_t)`，`h` 为关节角/角速度/力矩/IMU/接触估计历史。残差
`r_t = (s_t - ŝ_t)^T Σ_t^{-1} (s_t - ŝ_t)`。标定误差 `ε_p` 满足 `P(r_t ≤ ε_p) ≥ 1-α`（标定集上界，非分布外保证）。在线用 CUSUM 检测漂移。

**定义 125（本体感知可观测性证书）**
`PSM_cert = (ε_p, δ_obs, δ_τ, cover_obs)`：
- `δ_obs`：在给定传感器配置下状态/接触模式的可观测性下界（Fisher 信息最小特征值的倒数）；
- `δ_τ`：最小可检测外力矩差；
- `cover_obs`：标定集覆盖的接触模式比例。
**判定规则**：若任务所需力差 `Δτ_T < δ_τ`，则 PSM 对该任务无判定力，证书降级为 `unknown` 而非 `in`。

**定义 126（力矩-本体感知契约）**
`C_tp = (β_S, m_τ, Z(t), PSM_cert, reflex, Explain_ch)`：
- `β_S, m_τ, Z(t)` 为力矩层承诺；
- `PSM_cert` 为运行时证人；
- `reflex = (κ_r, κ_τ, action)`：残差或裕度越界时执行的软化/卸力动作；
- `Explain_ch`：反射事件回传云端的反向解释通道。

**定义 127（力感知联合证书）**
`J⁺ = (ρ, A_cert, β_S, m_τ, PSM_cert, γ_ce, δ_a, δ_τ, evidence)`。
若 `dom_{J⁺}(T)=in`、`m_τ ≥ μ_min`、`δ_a < Θ_a`、`Δτ_T ≥ δ_τ`，且标定集上 `P(r_t ≤ ε_p) ≥ 1-α`，则组合可部署。

**力域兼容性**：`compat_τ(S_i,S_j) = ∫ min(β_i,β_j) / ∫ max(β_i,β_j)`（在交集力矩-阻抗域上），边条件为 `compat_τ ≥ θ_τ ∧ m_τ ≥ μ_min ∧ Lip(Z) ≤ L_Z ∧ c_τ ≤ τ_τ`。

## 2. 关键算法 伪代码

### IP-121 TIP（Torque-Impedance Profile）

```python
def torque_profile(skill, T_grid, dyn_model, tau_max):
    beta, margins = {}, {}
    for (tau_traj, Z) in sample_torque_trajectories(skill, T_grid):
        tau = dyn_model.inverse_dynamics(skill.q, skill.qd, skill.qdd, Z)
        feas = all(abs(tau[j]) < tau_max[j] for j in range(n))
        conf = 1.0 - model_error(skill, tau)
        beta[(tau_traj, Z)] = conf if feas else 0.0
        margins[(tau_traj, Z)] = min((tau_max[j]-abs(tau[j]))/tau_max[j] for j in range(n))
    return beta, margins

def torque_cover(beta, T_T, theta_tau=0.8):
    return all(beta.get((tau_t, Z_t), 0.0) >= theta_tau for tau_t, Z_t in T_T)
```

### IP-122 PSM（Proprioceptive Self-Model）

```python
def fit_psm(histories, states, alpha=0.05):
    f = train_regressor(histories, states)            # 输入 h_{t-k:t}
    resid = [mahalanobis(s, f(h).mean) for h, s in zip(histories, states)]
    eps_p = quantile(resid, 1-alpha)                  # 标定误差上界
    return f, eps_p

def psm_monitor(f, h, s, eps_p, cusum_state):
    s_hat, Sigma = f(h)
    r = mahalanobis(s, s_hat, Sigma)
    cusum_state = max(0.0, cusum_state + (r - eps_p))
    return (r, cusum_state, 'alarm' if cusum_state > k_cusum else 'ok')
```

### IP-123 TCC（Torque-Coupled Composition）

```python
def build_torque_graph(skills, theta_tau, mu_min, L_Z, tau_tau):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            comp = torque_jaccard(s1.beta, s2.beta)
            m = min(s1.m_τ, s2.m_τ, transition_margin(s1, s2))
            lip = impedance_lipschitz(s1.Z, s2.Z)
            c = torque_transition_cost(s1, s2)
            if comp >= theta_tau and m >= mu_min and lip <= L_Z and c <= tau_tau:
                G.add_edge(i, j, compat=comp, m_tau=m, cost=c,
                           rho_comp=compose_robustness(s1.rho, s2.rho, K))
    return G
```

### IP-124 TMB（Torque Margin Budget）

```python
def margin_budget(path, skills, mu_min):
    # 沿组合轨迹传播裕度，转换段单独扣减
    m = float('inf'); witness = []
    for k in range(len(path)-1):
        s1, s2 = skills[path[k]], skills[path[k+1]]
        m_seg = min(s1.m_τ, transition_margin(s1, s2), s2.m_τ)
        witness.append((path[k], path[k+1], m_seg))
        m = min(m, m_seg)
        if m < mu_min:
            return ('reject', 'margin_violation', witness)
    return ('ok', m, witness)
```

### IP-125 PRM（Proprioceptive Reflex Monitor）

```python
def reflex_loop(f, skill, tau_max, eps_p, mu_min, kappa_r, kappa_tau):
    cusum = 0.0
    while executing(skill):
        h, s = read_proprioception()
        r, cusum, flag = psm_monitor(f, h, s, eps_p, cusum)
        m = current_torque_margin(read_torque(), tau_max)
        if flag == 'alarm' or r > kappa_r:
            soften_impedance(); return ('reflex', 'proprioception_drift', r)
        if m < mu_min or m < kappa_tau:
            unload_torque(); return ('reflex', 'torque_saturation', m)
    return ('ok', 'nominal', None)
```

### IP-126 PTC（Proprioceptive-Torque Contract）

```python
def build_contract(skill, psm_cert, mu_min, tau_max, delta_tau):
    if skill.m_τ < mu_min: return ('reject', 'insufficient_margin')
    if psm_cert.delta_tau > delta_tau: return ('degrade', 'unobservable_wrench')
    if psm_cert.cover_obs < COVER_MIN: return ('degrade', 'contact_mode_uncovered')
    return ('ok', TorqueContract(skill.beta, skill.m_τ, skill.Z,
                                 psm_cert, reflex=(kappa_r, kappa_tau, 'soften'),

```

### IP-127 FJC（Force-aware Joint Certificate）

```python
def force_joint_certificate(seq, gamma_ce, budgets):
    stat = margin_budget(seq, budgets.mu_min)
    if stat[0] == 'reject': return stat
    A_core = reduce(intersection, [s.alpha for s in seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    delta_tau = max_force_gap(seq, gamma_ce)
    psm_ok = all(s.psm_cert.cover_obs >= COVER_MIN for s in seq)
    if delta_a > budgets.delta_a or delta_tau > budgets.delta_tau:
        return ('reject', 'force_alignment_mismatch', delta_a, delta_tau)
    for s in seq:
        if s.m_τ < budgets.mu_min:
            return ('reject', 'margin')
    return ('ok', JointCertPlus(rho=compose_robustness_chain(seq),
                                A_cert=(A_core, buffer_zone(A_core, delta_a)),
                                beta=[s.beta for s in seq], m_tau=stat[1],
                                psm_cert=[s.psm_cert for s in seq],
                                gamma_ce=gamma_ce, delta_a=delta_a,
                                delta_tau=delta_tau))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TIP | O(|S|·|T|·n) | O(\|T\|) | 逆动力学误差有界、采样覆盖接触模式 |
| PSM | O(N·d) 训练 / O(d) 在线 | O(N·d) | 标定集覆盖、残差分布外检测 |
| TCC | O(|S|²·|T|) | O(|S|²) | 力矩兼容阈值 sound、裕度单调 |
| TMB | O(|P|) | O(|P|) | 转换段裕度不遗漏 |
| PRM | O(1) 每步 | O(1) | 反射延迟 < 失稳时间 |
| FJC | O(|S|·|T|) | O(|T|) | 三证书一致、δ_τ 可观测 |

**正确性定理（Torque-Proprioceptive Composition Soundness）**
承接第 54 轮 (A22)–(A28)；新增 **(A29)** `β_S` 由逆动力学标定，力矩模型误差 `≤ ε_τ`；**(A30)** PSM 残差在标定分布内满足 `P(r≤ε_p) ≥ 1-α`，且 `δ_obs/δ_τ` 可量化；**(A31)** 力矩裕度观测延迟 `≤ τ_m`；**(A32)** 反射执行延迟 `≤ τ_reflex` 且软化后阻抗保持无源。
则：
```
P_success ≥ 1 - Σ_d (1-ρ_min(d))
              - P(m_τ < μ_min) - P(sup_t r_t > ε_p)
              - P(Δτ_T < δ_τ) - P(δ_a > Θ_a) - β_E
```
关键：**力域可行且有裕度**、**本体感知在任务力尺度上可观测**、**反射快于失稳**。三项缺一，`J⁺` 不得输出 `in`。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 自模型自信错误（分布外接触） | 高 | 分布外检测 + 主动激励 + `cover_obs` 降级 |
| 力矩裕度估计偏乐观 | 高 | 保守 `ε_τ` 上界 + 在线力矩观测 + 硬限幅 |
| 可观测性不足导致虚假 `in` | 高 | `Δτ_T < δ_τ` 强制 `unknown`，禁止升级 |
| 反射抖动/极限环 | 中 | 滞回 + 无源阻抗 + 最小驻留时间 |
| 云边阻抗映射非单调 | 中 | Lipschitz 约束 + 转换段单独验证 |

## 6. 本轮最大风险

**一句话**：把动作空间推进到力矩-阻抗域、并用本体感知做运行时证人，确实把“纸面可组合”变成了“可动态证伪”，但整套 soundness 压在**本体感知在任务力尺度上可观测**这一条上；一旦自模型在接触/负载维度不可观测却仍输出低残差（自信错误），`J⁺` 会把“感觉良好”误判为“力域可部署”，故必须以 **可观测性门控（`Δτ_T < δ_τ` 直接降级）+ 力矩裕度硬预算 + 分布外反射** 三重护栏，宁可在力域保守拒绝，也绝不把本体感知的“自洽假象”当作力的真相。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（TIP×PSM×TCC×TMB×PRM×PTC×FJC）

> 承接第 54 轮产物 v31。本轮在动作空间剖面 + 云边协同之上，增加 **力矩-阻抗域、本体感知自模型、力域组合、反射监控** 四个算子层：
> - **TIP（Torque-Impedance Profile）**：技能从运动学占用 `α_S` 升级为力矩-阻抗剖面 `β_S`；
> - **PSM（Proprioceptive Self-Model）**：边端自模型 + 标定误差 + 可观测性证书；
> - **TCC（Torque-Coupled Composition）**：力域兼容图，边条件含裕度、阻抗连续性、转换成本；
> - **TMB（Torque Margin Budget）**：沿组合轨迹传播力矩裕度，转换段单独扣减；
> - **PRM（Proprioceptive Reflex Monitor）**：残差/裕度越界触发软化—卸力反射；
> - **PTC（Proprioceptive-Torque Contract）**：力-感知契约，可部署/降级/拒绝三态；
> - **FJC（Force-aware Joint Certificate）**：把 `ρ、A_cert、β_S、m_τ、PSM_cert` 合成联合证书 `J⁺`。

def torque_profile(skill, T_grid, dyn_model, tau_max):
    beta, margins = {}, {}
    for (tau_traj, Z) in sample_torque_trajectories(skill, T_grid):
        tau = dyn_model.inverse_dynamics(skill.q, skill.qd, skill.qdd, Z)
        feas = all(abs(tau[j]) < tau_max[j] for j in range(n))
        conf = 1.0 - model_error(skill, tau)
        beta[(tau_traj, Z)] = conf if feas else 0.0
        margins[(tau_traj, Z)] = min(
            (tau_max[j]-abs(tau[j]))/tau_max[j] for j in range(n))
    return beta, margins

def torque_cover(beta, T_T, theta_tau=0.8):
    return all(beta.get((tau_t, Z_t), 0.0) >= theta_tau for tau_t, Z_t in T_T)

### IP-122 PSM

```python
def fit_psm(histories, states, alpha=0.05):
    f = train_regressor(histories, states)          # h_{t-k:t} -> (mean, Sigma)
    resid = [mahalanobis(s, f(h)[0], f(h)[1])
             for h, s in zip(histories, states)]
    eps_p = quantile(resid, 1-alpha)
    return f, eps_p

def psm_monitor(f, h, s, eps_p, cusum, k_cusum):
    s_hat, Sigma = f(h)
    r = mahalanobis(s, s_hat, Sigma)
    cusum = max(0.0, cusum + (r - eps_p))
    return r, cusum, ('alarm' if cusum > k_cusum else 'ok')
```

### IP-123 TCC

```python
def build_torque_graph(skills, theta_tau, mu_min, L_Z, tau_tau, K):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            comp = torque_jaccard(s1.beta, s2.beta)
            m = min(s1.m_τ, s2.m_τ, transition_margin(s1, s2))
            lip = impedance_lipschitz(s1.Z, s2.Z)
            c = torque_transition_cost(s1, s2)
            if comp >= theta_tau and m >= mu_min and lip <= L_Z and c <= tau_tau:
                G.add_edge(i, j, compat=comp, m_tau=m, cost=c,
                           rho_comp=compose_robustness(s1.rho, s2.rho, K))
    return G
```

### IP-124 TMB

```python
def margin_budget(path, skills, mu_min):
    m, witness = float('inf'), []
    for k in range(len(path)-1):
        s1, s2 = skills[path[k]], skills[path[k+1]]
        m_seg = min(s1.m_τ, transition_margin(s1, s2), s2.m_τ)
        witness.append((path[k], path[k+1], m_seg))
        m = min(m, m_seg)
        if m < mu_min:
            return ('reject', 'margin_violation', witness)
    return ('ok', m, witness)
```

def reflex_loop(f, skill, tau_max, eps_p, mu_min, kappa_r, kappa_tau):
    cusum = 0.0
    while executing(skill):
        h, s = read_proprioception()

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TIP | O(\|S\|·\|T\|·n) | O(\|T\|) | 逆动力学误差 `≤ε_τ`，接触模式采样覆盖 |
| PSM | O(N·d) 训练 / O(d) 在线 | O(N·d) | 标定覆盖率 `1-α`，CUSUM 漂移报警 |
| TCC | O(\|S\|²·\|T\|) | O(\|S\|²+\|E\|) | `compat_τ` sound，边的裕度非负 |
| TMB | O(\|P\|) | O(\|P\|) | 转换段裕度不遗漏 |
| PRM | O(1)/步 | O(1) | `τ_reflex < τ_instability` |
| FJC | O(\|S\|·\|T\|) | O(\|T\|) | 三证书一致，`δ_τ` 门控 |

**正确性定理（Torque-Proprioceptive Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** `β_S` 逆动力学标定误差 `≤ε_τ`；**(A30)** PSM 残差在标定分布内 `P(r≤ε_p)≥1-α` 且 `δ_obs/δ_τ` 可量化；**(A31)** 裕度观测延迟 `≤τ_m`；**(A32)** 反射延迟 `≤τ_reflex` 且软化后无源。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(m_τ<μ_min)
              - P(sup_t r_t > ε_p) - P(Δτ_T < δ_τ)
              - P(δ_a > Θ_a) - β_E
```
**证明要点**：TMB 保证组合轨迹全程 `m_τ≥μ_min`，排除饱和越界；PRM 把 PSM 残差越界转为可恢复反射，故残余失败仅来自“残差在界内但状态已偏”的不可观测部分，其概率由 `δ_τ` 门控上界；FJC 要求 `Δτ_T≥δ_τ`，把不可观测力差从 `in` 域移除。

## 5. 本轮最大风险

**一句话**：力矩-阻抗域 + 本体感知让技能组合从“动作可对齐”进化到“力域可证伪”，但整套 soundness 压在本体感知于任务力尺度可观测这一条上；一旦自模型在接触/负载维度不可观测却仍输出低残差（自信错误），`J⁺` 会把“感觉良好”误判为“力域可部署”，故必须用 **可观测性门控（`Δτ_T<δ_τ` 直接降级）+ 力矩裕度硬预算 + 分布外反射** 三重护栏，宁可在力域保守拒绝，也绝不把本体感知的“自洽假象”当作力的真相。
