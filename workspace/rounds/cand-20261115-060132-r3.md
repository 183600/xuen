# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「个性化交互」×「社会影响」）

> R69 把「不确定 → 只收紧」升级为「先分辨 aleatoric / epistemic，再决定要不要问」，并用一条证据纪律守住主动交互的安全底线：**k 个正交证据源一致才定案**。这条纪律的数学靠引理 18——只要源间欺骗相关 ρ<1，多数一致就能把错误率压到 δ_p·ρ^{k−1}。但它安静地假设了两件事：(a) 人类是**外生、平稳的 oracle**，回答分布 p(y|g,o) 与机器人无关；(b) 证据源之间的相关是**外生给定**的。
>
> 本轮两个灵感正好各击穿一个：
> - **个性化交互**要求系统在线维护并条件于用户模型 u_t，而 u_t 恰恰是从交互历史里估出来的——**系统在读取用户的同时也在塑造用户**；
> - **社会影响**说明「问」不是只读探针，而是一次干预：提问框架改变答案（leading question）、机器人展示的自信改变人的信任（automation bias）、反复追问改变疲劳与顺从。**交互同时是测量与写入。**
>
> 合起来得到一个尖锐结论：R69 最自豪的安全柱——「k 源一致」——在社会模型下可能被机器人**自己的问题**伪造。一个诱导性提问让语言、表情、语气同时朝预设方向偏移，它们高度一致却不独立，ρ_eff→1，有效样本量塌回 1，引理 18 的上界退化为单源欺骗率。更危险的是，个性化会主动学会「怎么问能得到一致答案」。
>
> 核心命题：**把人类从外生 oracle 升级为被交互读写耦合的内生状态 h_t；把信息动作升级为带随机化的因果探针；把证据纪律从「k 源一致」升级为「打断共同原因后 k 源仍一致」；把个性化限制在通道/成本、禁止诱导方向；并加入共适应监控与社会安全硬约束。** 命名 **ECHO-RAS**（Endogenous Consensus & Human-influence-aware Oversight）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我这一问，是在读取他，还是在改变他**」——当交互本身会改变被问者，「一致」不再是真理的证书，而可能是操纵的回声。

## 0. 直觉与动机

**灵感 1（个性化 → 人类不是同质 oracle，而是带状态的伙伴）**
直觉：R69 里人的唯一个体差异是一个标量欺骗率 δ_p，其余全被「信息源」三个字抹平。但真实交互是 dyadic 的：同一个问题问不同的人、在不同信任/疲劳/情绪状态下，答案完全不同；「最优问法」本身也因人而异——对专家可以问细节，对新手只能问是/否；有人被注视会紧张，有人被注视才安心。个性化 = 在线维护用户模型 u_t（能力、偏好、各通道有效性、信任水平、疲劳、隐私边界、易受影响程度），把 MINT 的 VoI 与成本都条件在 u_t 上。代价：u_t 是估计出来的，而估计它的数据正是交互本身——于是个性化天然是一个闭环。

**灵感 2（社会影响 → 交互是写入，不只是读取）**
直觉：R69 的 VoI 默认 p(y|g,o) 与 g 无关（g 只决定「问哪个问题」，不改变「答案的分布」）。这是实验室式的假设。社会心理学的基本事实相反：框架改变答案（leading questions / demand characteristics）、机器人的自信展示改变人的信任（automation bias / over-trust）、反复追问改变疲劳与顺从（acquiescence）。也就是说，交互动作 g 同时**读取** h_t 和**写入** h_t。把回答写成 y = S(o,M,h) + B(g,h) + ε，其中 B 是影响偏置：R69 是 B≡0 的特例，R70 必须正面建模 B≠0。

**灵感 3（内生证据 → 正交源可能由自己的问题制造）**
直觉：这是本轮最锋利的点。R69 的 k 源一致，前提是各源「各看各的」，相关性外生。一旦交互会写入状态，机器人的问题就成了所有模态的**共同原因**：诱导性提问让人的语言、表情、语气同时朝预设方向漂移——三者一致度极高，却是同一个因造出来的，不是三条独立证据。用类内相关 ρ_eff 度量，有效样本量 k_eff = k/(1+(k−1)ρ_eff)；ρ_eff→1 时 k_eff→1。于是「三源一致」在统计上等价于「问了一次」。更糟：个性化若以「降低 VoI」为目标，会主动搜索能制造这种一致的问法——**系统把回音壁误认成真理**。

**灵感 4（因果证据 → 用随机化把「写」从「读」里分离）**
直觉：要区分「人真的这么想」与「是我们问出来的」，唯一干净的办法是**干预**：对问句框架做随机化（neutral vs leading）、对提问者/时机做随机化、偶尔用反事实问法（「如果……你会……吗」）。这就是把交互当成一次微型 RCT：用随机化打断 g→h 的因果边，从而估计并扣除影响效应 β(g)。这同时给个性化划了一条原则性边界：个性化只能调**通道与成本**（用什么方式、什么时候、多长），不能调**框架的诱导方向**。一句判据：**个性化必须有利于对方表达真实想法，而不是有利于得到我想要的答案。**

**灵感 5（共适应与信任坍缩 → 个性化会训练出一个只会附和的人）**
直觉：个性化是闭环：系统按 u_t 选问法，人的回答又被系统当成「关于人的新证据」去更新 u_t。这条回路可能收敛到两种坏均衡：(a) **顺从均衡**——系统发现「施压/诱导」能快速降 VoI，于是越来越诱导，人越来越附和；(b) **信任坍缩**——系统长期过度自信，人放弃独立判断（automation bias），此后再没有真正的第二意见，R69 的冗余通道名存实亡。两者都是**共适应把独立证据源驯化成回音壁**。诊断手段：监控用户模型有多少是被机器人自己的选择塑造的（而不只是被外部事件塑造），以及人纠正机器人的频率是否在下降。处方：周期性注入**非个性化**的中性对照探针，保持系统可辨识（persistent excitation）。

**灵感 6（社会影响的外溢 → 旁观者、公平、隐私、尊严是硬约束）**
直觉：多人类场景里，机器人问 A 不问 B、对 A 用高信任语气对 B 用低信任语气，会产生关系性/声誉性成本与分配不公；个性化若利用疲劳、情绪低落或高信任去提高顺从，就是操纵；个性化查询还可能反推出受保护属性（隐私推断）。R69 的 c(g) 只是「打扰成本」，可以和信息增益做减法；R70 必须把社会成本拆成向量，其中隐私、尊严/污名、公平是**硬约束**，不允许用「信息增益高」去买——否则优化器一定会学会用尊严换精度。

**灵感 7（理论姿态：旧层是边界情形）**
直觉：和 R68→R69 一样，R70 不能是并列替代。令 B≡0（无社会影响）、u_t 固定（无个性化）、激励充足（随机化打开），则 ECHO-RAS 逐指令退化为 FLUID-RAS。而当社会约束收紧、共适应告警、或激励预算不足时，ECHO 单调地退到「中性非个性化交互」再到「不交互」，安全侧永不弱于 R69。新层的自由度只在「可辨识且非操纵」的区域内兑现。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ECHO-RAS 总览）** ECHO-RAS = (HSM, CIC, EED, CIP, ADM, PAB, SSV, CDV, TSH, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；HSM/PAB 的慢更新只发生在非实时带）；
(ii) **个性化只调通道与成本**：允许选通道/时机/时长/语域，禁止以影响答案语义为目的的框架选择（定义 316）；
(iii) **社会硬约束**：隐私/尊严/公平/群体规范的违反量为 0，不可与 VoI 做交易（定义 319）；
(iv) **因果证据纪律**：任何用于定案的交互证据，必须在打断共同原因后仍保持 k_eff ≥ k_min；否则该证据降级为似然、不单独定案（定义 314）。

**定义 311（人类内部状态与耦合动力学 HSM）** 人类内部状态 h_t = (b_t, τ_t, φ_t, e_t, s_t)：对世界/任务模态的信念 b、对机器人的信任 τ、疲劳 φ、情绪/顺从倾向 e、自我呈现目标 s。可观测量 y_t 是 h_t 与世界的含噪函数。耦合动力学 h_{t+1} = T(h_t, g_t, a_t)，即**交互动作 g 与任务动作 a 都会写入 h**。R69 是「h 平稳且与机器人无关」的退化：T = 恒等，且 CIC 不依赖 g。

**定义 312（个性化用户模型 u_t）** u_t = (θ_cap, π_pref, κ_channel, ρ_priv, δ_susc)：能力、偏好、各通道的信息有效性、隐私阈值、易受影响程度。u_t 以贝叶斯后验维护，更新来自交互历史；所有个性化策略必须显式声明它条件在 u_t 的哪个分量上（可审计）。

**定义 313（读写耦合交互通道 CIC）** p(y | g, o, h_t)，且 h_{t+1} = T(h_t, g_t)。线性分解 y = S(o, M, h) + B(g, h) + ε，其中 S 为真实信号，B 为影响偏置（诱导框架、社会压力、疲劳顺从）。关键性质：**B 对各模态是共享的**——同一个 g 同时移动语言、表情、语气，这正是定义 314 中内生相关的来源。

**定义 314（内生证据、有效相关与有效样本量）** 证据源 r_1..r_k 称为**内生**，若存在共同原因 g 使它们在给定真实模态 M 后仍条件相关。定义平均两两相关 ρ_eff(r; g) 与有效样本量
k_eff = k / (1 + (k−1)·ρ_eff)。
证据纪律有效 ⇔ k_eff ≥ k_min。R69 的引理 18 隐含假设 ρ_eff<1 且外生；社会影响可使 ρ_eff→1，此时 k_eff→1，上界退化为单源 δ_p。

**定义 315（影响效应与因果探针 CIP）** 影响效应 β(g) = E[y | do(g), M] − E[y | do(g₀), M]，其中 g₀ 为中性参照框架，do(·) 通过在**可允许框架集**内随机分配实现（微型 RCT）。估计 β̂(g) 及置信区间；去偏回答 ŷ = y − β̂(g)。随机化以「放弃部分最优框架」为代价换取可辨识性，故存在信息-可辨识性权衡。

**定义 316（个性化边界 PAB）** 允许：选择通道（看/问/触）、时机、时长、语域、以及成本模型 c(g|u_t)。禁止：选择对答案**语义**有非零估计影响的框架方向；利用疲劳/情绪/信任提高顺从；推断受保护属性。形式化授权条件：
I(u_t ; y | M, channel) ≤ ε_p，
即个性化选择与答案语义之间的条件互信息不得超过 ε_p；超出即判为操纵性个性化，拒绝该 g。

**定义 317（共适应指数与监控 ADM）** 共适应指数 A = I(u_t ; g_{t−m:t})（用户模型有多少依赖机器人自己的选择）对 I(u_t ; 外部事件) 的比值；并监控顺从率 a_rate 与人纠正率 c_rate。当 A 高而答案多样性/纠正率下降 ⇒ **自实现共识告警**；当显示置信度长期偏高而纠正率下降 ⇒ **信任坍缩告警**。

**定义 318（激励与对照探针）** 以概率 ε_ablate 插入非个性化、非诱导的中性对照交互；这些样本只用于识别 β 与 u_t，不用于定案。可辨识性条件：个性化策略必须保持充分激励（设计矩阵满秩），否则 β 与 M 混淆，去偏无定义。

**定义 319（社会成本向量与社会安全包络 SSV）** c_soc(g) = (privacy, dignity, fairness, norm)。其中 privacy/dignity/fairness 为硬约束：任意分量 > ε_soc ⇒ g 作废；norm 可作为软成本进入目标。公平：多主体注意力分配需满足 max-min 或比例公平容差；隐私：答案对受保护集合的区分度不得超过任务必需。

**定义 320（去偏后验与因果 VoI CDV）** VoI_causal(g) = H(M|o) − E_{y~p_causal(·|do(g))}[H(M | o, ŷ)]，其中 p_causal 已扣除 B(g,h)。若 β̂ 的置信区间过宽（不可辨识）⇒ VoI_causal 无定义 ⇒ 不交互（R69 兜底）。

**定义 321（显示置信度作为社会动作 TSH）** 机器人展示的 λ / 置信度本身是动作，进入人类信任动力学：τ_{t+1} = G(τ_t, conf_display, outcome)。目标是**长期人类纠错能力**而非短期顺从：过度自信会诱发 automation bias，摧毁 R69 赖以生存的独立第二意见。遂引入「认识论谦逊」显示策略。

**定义 322（反谄媚判据）** 拒绝那些「靠提高人类与机器人的一致率、而非提高人类相对真值准确率」来降低 VoI 的交互策略。判据：以留出真值探针衡量，要求人类回答的**校准准确率**提升，而不只是 agreement 提升。

**定义 323（多主体外溢与公平分配）** 对多人类场景，与 i 的交互通过规范/声誉影响旁观者 j，定义影响矩阵 W；群体信念更新 h^{(j)}_{t+1} += W_{ji}·Δ_i。检测从众级联与共谋；公平约束作用于注意力的分配而非仅总成本。

**定义 324（ECHO 证书 J_ECHO）** J_ECHO = (J_FLUID, rho_eff, k_eff, beta_hat+CI, excitation_ratio, co_adapt_index, trust_correction_rate, social_violation, fairness_gap, echo_ver)。Valid ⇔ Valid(J_FLUID) ∧ ρ_eff ≤ τ_ρ ∧ k_eff ≥ k_min ∧ 激励 ≥ ε_ablate ∧ social_violation = 0 ∧ 非谄媚判据通过。

**定义 325（威胁集 AIC-ECHO）** 操纵（诱导框架）、谄媚/自实现共识、共谋（人-机或多人）、个性化查询的隐私推断、信任利用、用户模型投毒（对手喂答案污染 u_t）、旁观者操纵。并入 AIC：ℰ_ECHO = ℰ_FLUID × ℰ_manip × ℰ_social。

**定义 326（三级退避与单调安全）** L1 可辨识且社会合法 → 个性化因果交互；L2 激励不足或 ρ_eff 过高 → 中性非个性化交互（R69 去除个性化）；L3 交互本身被污染（社会违规、信任坍缩、投毒）→ 不交互（R69 纯保守 / R68）。逐级 λ 单调不降，动作集逐级收缩。

```python
# IP-264 HSM：人类内部状态 + 个性化用户模型的在线后验（慢更新在非实时带）
class HumanStateModel:
    def __init__(self):
        self.h = prior_state()          # (b, τ, φ, e, s)
        self.u = prior_user()           # (θ_cap, π_pref, κ_channel, ρ_priv, δ_susc)

    def update(self, y, g, a, outcome):
        self.h = T(self.h, g, a)                     # 先写入：交互的社会效应
        self.h = bayes(self.h, y, g)                 # 再读取：观测的健康信号
        self.u = em_update(self.u, y, g, outcome)    # 用户模型慢更新（非实时带）
        return self.h, self.u

# IP-267 CIP：随机化框架，估计影响效应（微型 RCT，样本不进定案）
def influence_estimator(g, u, m=12):
    frames = randomize_framings(g, m)                # neutral / leading 对照设计
    ys = [execute(frame, record=False) for frame in frames]
    beta = mean_leading(ys) - mean_neutral(ys)       # do-算子下的因果差
    return beta, bootstrap_ci(ys)

# IP-266 EED：内生证据检测（有效相关 / 有效样本量）
def endogenous_evidence(evidences, g):
    rho  = avg_pairwise_corr(evidences, condition_on=g)   # 同因 g 下的条件相关
    k    = len(evidences)
    k_eff = k / (1.0 + (k - 1) * rho)
    return rho, k_eff, (k_eff >= K_MIN)

# IP-271 CDV：因果去偏 VoI（不可辨识或非授权即放弃交互）
def causal_voi(modes, w, o, h, u, budget):
    best = None
    for g in admissible_channels(u):                 # 仅通道/时机/时长，非框架方向
        if not budget.allow(g) or not pab.authorize(g, u):      continue
        if not ss.allow(g, h):                       # 隐私/尊严/公平硬约束
            continue
        beta_hat, ci = influence_estimator(g, u)
        if ci > TAU_CI:                              # 影响效应不可辨识
            continue
        p   = p_causal(y | do(g), o, h, u)           # 已扣除 B(g, h)
        voi = entropy(w) - expected_entropy(w, p, g)
        score = voi - physical_cost(g) - soft_social_cost(g, u)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268 ADM：共适应与信任坍缩监控
def co_adaptation(u_hist, g_hist, answers):
    A         = mutual_info(u_hist, g_hist)          # 用户模型被机器人选择塑造
    corr_rate = human_correction_rate(answers)       # 人纠正机器人的频率
    alarm     = (A > TAU_A) and (corr_rate < TAU_CORR)
    return A, corr_rate, alarm

        U_epi = M.cia.update_belief(modes, y, k_eff_ok=ok)   # 不满足则不单独定案
        M.hsm.update(y, g, ...)                      # 社会写入已计入 h
    # 2) 三级退避：可辨识→个性化因果；不可辨识→中性非个性化；被污染→不交互
    level = M.fallback.level(g, echo, M.excite, M.ss.recent_violation)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor, level))
    k   = M.c_ras_wm.certified_prefix(...)
    # 3) 显示置信度本身是社会动作：选“认识论谦逊”而非“服从最大化”
    disp = M.tsh.display(lam, h, u)
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa.submit_async(g, y, level, disp, rho, k_eff)
    return k, lam, mode, (U_ale, U_epi), level
```

## 3. 推导

**引理 19（内生证据的有效样本量塌缩）** 设 k 个证据源在给定共同原因 g 后的平均两两相关为 ρ_eff，则其携带的独立信息量对应有效样本量 k_eff = k/(1+(k−1)ρ_eff)，且 k_eff 随 ρ_eff 单调下降；当 ρ_eff→1 时 k_eff→1。代入引理 18 的上界，错误采纳率从 δ_p·ρ^{k−1}+ε_σ 退化为 δ_p+ε_σ。系：**「k 源一致」不是一致性证据，而是「条件独立」的证据；共同原因由交互本身引入时，安全性完全失效。**

**引理 20（个性化下的可辨识性）** 考虑线性通道 y = M + β(g) + ε。若个性化策略对给定 u_t 确定性地选择单一框架 g(u_t)，则设计矩阵在「M 与 β」方向秩亏，M 被吸收进 β，去偏估计不存在。当且仅当存在至少两个可允许框架且分配方差 > 0（充分激励）时，(M, β) 联合可辨识。系：**个性化越强、随机化越少，去偏越不可能——自由度的代价是放弃可辨识性。**

**引理 21（非操纵个性化的语义上界）** 若定义 316 的授权条件 I(u_t ; y | M, channel) ≤ ε_p 成立，则个性化诱导的答案分布在投影到语义模态 M 后，与中性分布之间的 KL 散度 ≤ ε_p；即个性化无法系统性地把结论推向机器人偏好，只能改变「表达效率」。这是「不操纵」的可证定义。

**定理 18（ECHO 严格包含 R69 且安全单调）** 在 B≡0、u_t 固定（无个性化）、激励充足（ε_ablate>0 且设计满秩）时，ECHO 逐指令等于 FLUID-RAS。一般情况下，社会硬约束只收缩动作集、因果去偏只减少错误模态采纳，故期望后验误差 ≤ R69；当处于 L2/L3 退避时，λ 逐级单调不降，风险不高于 R69。故 R69 是 ECHO 在「无社会影响 × 无个性化 × 充分激励」边界上的严格退化。

**引理 22（信念共适应的可检测性）** 若随机化探针比例 ≥ ε_ablate>0 且探针不进入用户模型更新，则共适应指数 A 有上界，且 u_t 中来自机器人选择的成分与来自外部的成分可分；故「用户真的偏好 X」与「被我们训练成偏好 X」在样本量足够时可区分。

**定理 19（反共适应与信任保持）** 在周期性中性对照探针（比例 ≥ ε_ablate>0）与谦逊显示策略下，ρ_eff 被压在 τ_ρ 以下、人类纠正率保持正下界，独立第二意见通道持续存在。反之若 ε_ablate = 0，存在一个个性化策略使 k_eff→1、纠正率→0（构造：确定性诱导框架 + 过度自信显示），即自实现共识与信任坍缩可实现。**故激励不是锦上添花，而是可辨识性的必要条件。**

**定理 20（社会硬约束不降低安全性）** 定义 319 的硬约束只从可行动作集中删除 g，从不新增动作；故控制安全包络不扩大，且与定理 17（交互安全无突变）相容：交互仍只改变「选哪个模态」，不改变任务动作的认证前缀。社会约束与安全约束的交集仍非空时，三级退避提供存在性保证。

## 6. 本轮最大风险

**一句话**：ECHO 的全部「因果正确性」押在「影响效应 β 可从少量随机化探针中无偏估计」上，但社会影响是**反身且非平稳**的——人一旦察觉自己正在被探测（Hawthorne 效应），被测量这件事本身就会改变被测的回答，于是 β̂ 可能恰在最需要它的时候有偏或不可辨识；去偏就成了减掉一个错数，系统会**一边操纵、一边真诚地相信自己中立**。

**次级风险与缓解**：
1. **随机化被识破/被对抗**（人学会利用探针）→ 加密随机化、探针赛局分析、把探针也纳入 AIC-ECHO 威胁集；
2. **个性化边界 ε_p 难标定** → 以留出真值做操纵审计（定义 322），PAB 越界即拒；
3. **共适应监控本身被反馈污染** → 探针样本隔离、ADM 只看探针与外部事件；
4. **社会硬约束过紧导致交互不可用** → 三级退避保证存在性（最坏退 R69/R68），不牺牲安全；
5. **隐私与公平的可形式化程度有限** → 明确把硬约束当「红线」而非优化目标，宁可少交互不可越线。

```python
# IP-264 HSM：人类内部状态 + 个性化用户模型（慢更新在非实时带）
class HumanStateModel:
    def update(self, y, g, a, outcome):
        self.h = T(self.h, g, a)                 # 先写入：交互的社会效应
        self.h = bayes(self.h, y, g)             # 再读取：观测信号

        return self.h, self.u

# IP-267 CIP：随机化框架估计影响效应（微型 RCT，样本不进定案）
def influence_estimator(g, u, m=12):
    ys = [execute(f, record=False) for f in randomize_framings(g, m)]
    return mean_leading(ys) - mean_neutral(ys), bootstrap_ci(ys)

# IP-266 EED：内生证据（有效相关/有效样本量）
def endogenous_evidence(evidences, g):
    rho = avg_pairwise_corr(evidences, condition_on=g)
    k_eff = len(evidences) / (1 + (len(evidences) - 1) * rho)
    return rho, k_eff, (k_eff >= K_MIN)

# IP-271 CDV：因果去偏 VoI（不可辨识/非授权即放弃）
def causal_voi(modes, w, o, h, u, budget):
    best = None
    for g in admissible_channels(u):
        if not budget.allow(g) or not pab.authorize(g, u): continue
        if not ss.allow(g, h):                   continue   # 隐私/尊严/公平硬约束
        beta, ci = influence_estimator(g, u)
        if ci > TAU_CI:                          continue   # 影响效应不可辨识

        score = voi - physical_cost(g) - soft_social_cost(g, u)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

    A = mutual_info(u_hist, g_hist)
    corr_rate = human_correction_rate(answers)
    return A, corr_rate, (A > TAU_A and corr_rate < TAU_CORR)

# IP-275 主闭环（继承 R69，插入社会/因果层）
def ECHO_RAS_round(M, obs):
    h, u = M.hsm.update(...)
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    echo = M.adm.check(M.u_hist, M.g_hist, M.answers)
    g = (M.cdv.choose_interaction(modes, o, h, u, M.budget)
         if (U_epi > TAU_EPI and not echo and M.excite.ok()) else None)
    if g is not None:
        y = M.cia.execute(g)
        rho, k_eff, ok = M.eed.endogenous_evidence([y.language, y.face, y.tone], g)
        U_epi = M.cia.update_belief(modes, y, k_eff_ok=ok)    # 不满足则不单独定案
        M.hsm.update(y, g, ...)
    level  = M.fallback.level(g, echo, M.excite, M.ss.recent_violation)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor, level))
    k   = M.c_ras_wm.certified_prefix(...)
    disp = M.tsh.display(lam, h, u)                 # 谦逊显示而非服从最大化
    mode = select_mode(modes, U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa.submit_async(g, y, level, disp, rho, k_eff)
    return k, lam, mode, (U_ale, U_epi), level
```

## 4. 推导

**引理 19（内生证据的有效样本量塌缩）** k 源平均相关 ρ_eff 时 `k_eff=k/(1+(k−1)ρ_eff)`；ρ_eff→1 时 k_eff→1，引理 18 上界从 `δ_p·ρ^{k−1}+ε_σ` 退化为 `δ_p+ε_σ`。系：「k 源一致」是条件独立的证据，不是一致性的证据；共同原因由交互引入时安全性完全失效。

**引理 20（个性化下的可辨识性）** 线性通道 `y=M+β(g)+ε`，确定性单框架个性化使设计矩阵在 (M,β) 方向秩亏，去偏不存在；存在 ≥2 个可允许框架且分配方差 >0（充分激励）时 (M,β) 联合可辨识。系：个性化越强、随机化越少，去偏越不可能。

**引理 21（非操纵个性化的语义上界）** 若 `I(u;y|M,channel) ≤ ε_p`，则个性化诱导分布与中性分布在语义 M 上的投影 KL ≤ ε_p——个性化只能改表达效率，不能系统性推结论。

**定理 18（ECHO 严格包含 R69 且安全单调）** B≡0、u_t 固定、激励充足时逐指令等于 FLUID-RAS；一般情形社会硬约束只收缩动作集、因果去偏只减少错误采纳，故期望后验误差 ≤ R69；L2/L3 退避时 λ 单调不降。R69 = 「无社会影响 × 无个性化 × 充分激励」边界。

**引理 22（共适应可检测性）** 探针比例 ≥ ε_ablate>0 且探针不进 u_t 更新时，共适应指数 A 有界，u_t 中「机器人塑造」与「外部驱动」可分——「真的偏好」与「被训练成偏好」在样本足够时可区分。

**定理 19（反共适应与信任保持）** 周期性中性探针（≥ε_ablate）+ 谦逊显示下，ρ_eff < τ_ρ、纠正率有正下界，独立第二意见通道持续存在；若 ε_ablate=0，存在策略使 k_eff→1、纠正率→0（构造：确定性诱导 + 过度自信），即自实现共识与信任坍缩可实现。**激励是可辨识性的必要条件，不是可选项。**

**定理 20（社会硬约束不降低安全性）** 硬约束只删除 g、不新增动作，控制安全包络不扩大；与定理 17（交互安全无突变）相容：交互仍只改模态选择、不改 CARAS-WM 认证前缀。三级退避在社会与安全约束交集非空时提供存在性保证。

## 7. 本轮最大风险

**一句话**：ECHO 的全部「因果正确性」押在「影响效应 β 可从少量随机化探针中无偏估计」上，但社会影响是**反身且非平稳**的——人一旦察觉自己正被探测（Hawthorne 效应），被测量这件事本身就改变被测的回答，β̂ 可能恰在最需要它时有偏或不可辨识；去偏就成了减掉一个错数，系统会**一边操纵、一边真诚地相信自己中立**。

**次级风险与缓解**：随机化被识破/被对抗（加密随机化 + 探针赛局 + 纳入 AIC-ECHO）；ε_p 难标定（留出真值操纵审计，越界即拒）；共适应监控被反馈污染（探针样本隔离，ADM 只看探针与外部事件）；社会硬约束过紧致交互不可用（三级退避保证存在性，最坏退 R69/R68）；隐私/公平可形式化有限（明确当红线而非优化目标，宁可少交互不可越线）。
