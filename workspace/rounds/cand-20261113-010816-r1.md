# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰联合闭环」IP-193~202；灵感循环 II 第 3 轮；本轮灵感：「抓取规划」×「虚实迁移」）

> 第 63 轮 LIRO 用 LSF 补齐稠密几何、用 USL/CSP 补齐技能抽象、用 DIR/AIC 补齐四类干扰。但它自述的最大风险（几何幻觉 → 错误 φ̂₀）暴露了两个被「符号化」掩盖的根基假设：
> 1. **抓取只是符号，不是规划**：USL 中的 `σ_grasp` 只有手写 pre/eff 谓词（摩擦锥、进近方向），没有真正的**抓取合成、力闭合（force closure）、抓取质量（GWS / ε-metric）**——「抓取规划」要求对候选抓取位姿做 6-DoF 合成与可证明的力闭合验证，而不是把抓取当成一个原子符号。
> 2. **虚实差异只是常数，不是可测量对象**：GeoInit/MEL 的 φ̂ 与 WCV 球 B(φ̂,r) 默认来自仿真预训练，`δ_geo/δ_bias` 把 sim-to-real gap 藏在常数里。而第 63 轮最大风险（几何幻觉）本质就是 sim-to-real gap——「虚实迁移」要求把 gap 显式分解、测量、用真实交互收缩、并给出可认证的迁移界，而不是假设它小。
>
> 本轮核心洞见：**抓取既是待规划的技能，也是辨识虚实差异的最佳探针**。一次真实抓取的成功/滑移直接揭示摩擦 μ 与接触法向——因此「抓取规划」与「虚实迁移」不是两个问题，而是一个**对偶控制（dual control）**问题：在安全约束下选择信息量最大的抓取，既完成任务，又收缩 sim-to-real 不确定球。

## 0. 直觉与动机

**直觉 0（把两个灵感词读成一个对偶问题）**
「抓取规划」问：给定物体几何与手爪，怎样合成一个**力闭合、抗扰动、可执行**的抓取？「虚实迁移」问：仿真里成立的抓取，凭什么在真实世界成立？两者在 LIRO 的物理参数球 B(φ̂,r) 上迎头相撞：力闭合完全由摩擦 μ 与接触法向决定，而 μ 正是仿真最不可信、真实最需要测量的参数。**一次真实抓取 = 一次对 μ 的实验**。所以本轮不把抓取当成 USL 的符号 `σ_grasp`，也不把虚实迁移当成 `δ_bias` 常数，而是把抓取规划变成**带安全约束的主动系统辨识**。

**灵感 1（抓取规划 → GSP + GWS-R：把力闭合从点估计升级为球上最坏情形）**
直觉：经典抓取质量 ε(G,φ) 只在**一个** φ̂ 上算力闭合内切球；但真值 φ* 在 B(φ̂,r) 里。我们要的不是「在 φ̂ 处力闭合」，而是「对球里所有 φ 都力闭合」。
严谨：ε_rob(G) = min_{φ∈B(φ̂,r)∩𝒢} ε(G,φ)。Coulomb 摩擦下 ε 对 μ 单调、对法向误差 Lipschitz，故得可计算下界 ε_rob ≥ ε(G,φ̂) − L_ε·r。抓取规划因此变成**带裕度的可行性问题**：ε(G,φ̂) ≥ ε_min + L_ε·r。6-DoF 候选由抓取位姿检测网络给出，GWS-R 做最坏情形验证与重排序。

**灵感 2（虚实迁移 → SGM + RBC：把 gap 拆成可辨识与不可辨识两部分）**
直觉：sim-to-real gap 不是一团雾。有些是**参数错**（摩擦、质量、阻尼——真实抓一次就能修正），有些是**结构错**（刚性点接触 vs 软指面接触、Coulomb vs LuGre、可变形物体——再多的 μ 也补不上），还有些是**不可约随机**（微观粗糙、微滑）。
严谨：Δ = φ* − φ̂_sim = Δ_epi + Δ_ale + Δ_struct。前两者落在参数空间，用可信球 B 覆盖；Δ_struct 落在参数空间之外，必须用**函数空间残差** r_struct(x') 单独建模。**关键教训：不要靠放大 r 去吞掉结构误差**——那会把 ε_rob 压到 0，抓取全不可行。

**灵感 3（把抓取当探针 → IDG：安全主动辨识）**
直觉：并非所有抓取都同样「有信息」。一个接近滑移边界的抓取能精确标定 μ，但也最容易掉件。**在保证不摔的前提下，挑信息量最大的抓取去试**。
严谨：后验 p(φ|o_{1:t})，Fisher 信息 I(G) = J_μ(G)ᵀ Σ_o⁻¹ J_μ(G)；IDG 选 G_{t+1} = argmax IG(G)/cost(G) s.t. ε_rob(G) ≥ ε_min。这正是 SafeOpt 在「抓取成功」约束下的实例：安全集随 B_t 收缩而扩张，信息增益与执行代价显式折中。

**灵感 4（合流 → GRAFT：抓取-迁移一体闭环）**
GSP 给候选与 ε_rob，GWS-R 在可信球上验证，IDG 选探针，RBC 用真实结果收缩球，CDR 用收缩后的球做域随机化，PTS 补结构残差，GTC 出迁移证书。闭环：ε_rob↑ ⇒ 敢抓 ⇒ 真实数据↑ ⇒ r↓ ⇒ ε_rob 更紧 ⇒ …；与第 63 轮 LIRO 的「几何→技能→干扰」闭环正交咬合：LIRO 管「能不能安全地做」，GRAFT 管「抓得成不成、换到真实还成不成」。

**灵感 5（LIRO 组件原位升级）**
- **USL σ_grasp → σ_grasp^GWS**：pre/eff 由 GWS-R 与真实抓取结果实例化（pre: ε_rob ≥ ε_min；eff: 触觉/力/位姿确认 grasp_established），不再是手写谓词。
- **WCV-Geo → WCV-Grasp**：最坏情形搜索的「安全」判据从阻抗裕度换成抓取 ε_rob，球 B_t 由 RBC 维护，候选剪枝用 GWS-R。
- **SSB → GSB (Grasp Scenario Bank)**：场景签名增入「抓取结果指纹」（抓取位姿、滑移方向、接触力曲线），变异算子增加「摩擦梯度/法向偏置/软指刚度」。
- **OCB-Skill → OCB-Grasp**：臂空间增入「探针抓取预算」，奖励含信息增益项。
- **AIC → AIC-T**：认证从「干扰下安全」扩到「迁移下抓取成功概率下界」。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（GRAFT 闭环）**：GRAFT = (LIRO, GSP, GWS-R, IDG, SGM, RBC, CDR, PTS, GTC, J_graft)。定位：LIRO 的「抓取落地 × 虚实迁移可认证」升级，新增组件全部挂载在 LIRO 骨架上，`σ_grasp` 与 WCV 做原位升级。
- **定义 202（GSP 抓取合成规划器）**：GSP: (P_cloud, x', φ̂, r) → {(G_i, ε_rob(G_i))}。候选由 6-DoF 抓取检测网络给出（位姿 T、接触点集 C、进近方向 a、开口 w）；对每个候选算 GWS-R 质量并过滤 ε_rob ≥ ε_min；输出按 ε_rob/cost 排序的抓取集。
- **定义 203（GWS-R 鲁棒抓取扳手空间）**：单接触 i 的摩擦扳手锥 W_i(μ) = {[f; p_i×f] : f = n_i + β₁t_i1 + β₂t_i2, √(β₁²+β₂²) ≤ μ, f_n ≥ 0}；GWS(C,μ) = Σ_i W_i(μ)。ε(G,φ) 为 GWS 内最大内切球半径；**ε_rob(G) = min_{φ∈B(φ̂,r)∩𝒢} ε(G,φ) ≥ ε(G,φ̂) − L_ε·r**。
- **定义 204（IDG 信息导向抓取）**：G_{t+1} = argmax_{G∈𝒢_cand, ε_rob(G)≥ε_min} IG(G)/cost(G)，IG(G) ≈ ½ log det(I + Σ_t·I(G))，I(G) = J_μ(G)ᵀΣ_o⁻¹J_μ(G)。安全集 S_t = {φ: ∃G 安全, ε(G,φ) ≥ ε_min} 随 B_t 收缩而单调扩张（SafeOpt）。
- **定义 205（SGM 虚实差异模型）**：Δ = φ* − φ̂_sim = Δ_epi + Δ_ale + Δ_struct。B(φ̂,r) 以 1−α 覆盖 Δ_epi+Δ_ale；Δ_struct ∉ 参数空间，由残差网络 r_struct(x', w_contact) 建模，‖r_struct‖ ≤ δ_s。
- **定义 206（RBC 真实到仿真贝叶斯校准）**：后验 p(φ|o_{1:t}) ∝ p(φ)Π p(o_i|φ,G_i)；可信球 B_t = {φ: (φ−φ̂_t)ᵀΣ_t⁻¹(φ−φ̂_t) ≤ χ²_{d,1−α}}，Σ_t⁻¹ = Σ_0⁻¹ + Σ_i I_i(G_i)，r_t = √(χ²_{d,1−α}·λ_max(Σ_t))。
- **定义 207（CDR 认证域随机化）**：训练时 φ_sim ~ B_t ∩ 𝒢（而非固定区间）；WCV-Grasp 在 B_t 上取最坏 φ。因为 B_t 是校准可信集，域随机化从「拍脑袋」变为「有覆盖率保证」。
- **定义 208（PTS 特权教师-学生 + 结构残差）**：教师 π_T(a|x', φ_sim) 用特权参数；学生 π_S(a|x') 仅用可观测量，蒸馏 min E[KL(π_T‖π_S)] + λ·不变性；执行 a_real = π_S(x') + R_ψ(x', w_contact)，R_ψ 在真实残差上训练。
- **定义 209（GTC 抓取迁移证书）**：J_graft = (ε_rob, r_t, α, δ_s, dr_ver, real_n, grasp_seq_hash, calib_ver)。Valid ⇔ ε_rob ≥ ε_min ∧ r_t ≤ r_max ∧ δ_s ≤ δ_max ∧ dr_fresh ∧ real_n ≥ n_min。
- **定义 210（接地抓取原语 σ_grasp^GWS）**：σ_grasp = (pre: ε_rob(G,φ̂,r) ≥ ε_min ∧ approach ∈ 𝒞_approach；eff: grasp_established ∧ ‖w_ext‖ ≤ w_max；π_σ: 抓取位姿+握力轨迹；cost；𝒫_feas)，可直接被 CSP 组合（reach → grasp → hand-over）。
- **定义 211（主动探针集与安全扩张）**：探针集 𝒫_t ⊆ 𝒢_cand 满足 ε_rob ≥ ε_min；扩张算子 Expand(S_t, B_t) 在球收缩后纳入此前不安全但现安全的抓取；Exploit/Explore 由 SafeOpt 指数 max_G min(ε_rob−ε_min, IG) 决定。
- **定义 212（抓取迁移成功下界）**：若 G 在 B_t 上 ε_rob-力闭合、P[φ*∈B_t] ≥ 1−α、结构残差 ‖r_struct‖ ≤ δ_s，则 P[success_real] ≥ (1−α)·(1 − exp(−(ε_rob − L_εδ_s)²/(2σ_slip²)))。
- **定义 213（校准新鲜度与覆盖率）**：calib_ver 每次 RBC 更新递增；覆盖率 cov_t = 经验成功落在 B_t 内的频率，要求 |cov_t − (1−α)| ≤ η_cov，否则判定球失校准并强制增采。
- **定义 214（结构残差算子）**：r_struct(x', w_contact) = 真实接触扳手 − 参数模型预测扳手；用 PTS 的 R_ψ 拟合，δ_s = sup‖r_struct‖，进入 GTC 与迁移下界。
- **定义 215（抓取条件 φ 可辨识性）**：抓取 G 对 φ 的 Fisher 信息 I(G) 的秩与条件数决定可辨识子空间；若 rank(I(G)) < d，则部分 φ 分量不可由该抓取辨识，IDG 需组合多个抓取张成满秩。
- **定义 216（J_graft 有效性）**：Valid(J_graft) ⇔ Valid(J_liro) ∧ ε_rob ≥ ε_min ∧ r_t ≤ r_max ∧ δ_s ≤ δ_max ∧ dr_fresh ∧ calib_fresh ∧ cov_t ∈ [1−α−η_cov, 1−α+η_cov]。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# GSP + GWS-R：候选抓取合成 + 球上最坏情形力闭合
cands = grasp_detector(P_cloud, x')                 # 6-DoF 候选
for G in cands:
    eps_hat = gws_epsilon(G, phi_hat)               # 点估计质量
    eps_rob = eps_hat - L_eps * r                   # 球上最坏情形下界
    if eps_rob >= eps_min: keep(G, eps_rob)
# IDG：安全主动辨识（语义流）
G_next = argmax_{G safe} IG(G) / cost(G)            # SafeOpt 指数
# RBC：真实抓取结果 → 收缩可信球
phi_hat, Sigma, r = bayes_update(phi_hat, Sigma, G_next, outcome)
# CDR + PTS：认证域随机化 + 结构残差
train_student(phi_sim ~ B(phi_hat, r), residual=R_psi)
# GTC：迁移证书
J_graft = (eps_rob, r, alpha, delta_s, dr_ver, real_n, ...)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（GWS-R 下界）**：ε(G,φ) 对 μ 单调、对接触法向 Lipschitz（常数 L_ε），故 ε_rob ≥ ε(G,φ̂) − L_ε·r；取 ε(G,φ̂) ≥ ε_min + L_ε·r 即得球上力闭合。**抓取从"点估计可行"升级为"球上可证可行"**。
- **引理 6（RBC 收缩率）**：每次真实抓取注入 Fisher 信息 I(G)，Laplace 后验协方差 Σ_t⁻¹ = Σ_0⁻¹ + Σ_{i≤t}I_i，故 r_t = O(r_0/√t)（当 I_i 满秩且可比）。**真实抓取越多，球越紧，ε_rob 越敢逼近 ε_min**。
- **定理 4（迁移成功下界）**：在定义 212 条件下，P[success_real] ≥ (1−α)(1 − exp(−(ε_rob−L_εδ_s)²/(2σ_slip²)))。结构残差 δ_s 与球半径 r_t 是仅有的两个"漏气口"——**分别对应结构错与参数错，必须分开治理**。
- **定理 5（IDG 安全探索的近最优性）**：在安全集 S_t 与 Lipschitz 假设下，SafeOpt 型 IDG 的累积遗憾 ≤ O(√(T·γ_T))（γ_T 为最大信息增益），且探索全程 ε_rob ≥ ε_min。**抓取探针不会以掉件为代价**。
- **命题（CDR 优于固定 DR）**：B_t 收缩时，CDR 采样域体积按 det(Σ_t)^{1/2} 缩小，同等训练步数下覆盖真实 φ* 的样本密度提升，零样本迁移成功率随 r_t 单调上升。
- **实时性**：GWS-R 候选验证在语义流（<30ms/候选）；实时流仅执行已认证抓取的阻抗/握力轨迹，不新增学习写操作，≤ 2ms 契约继承。

## 5. 本轮最大风险

**一句话**：若真实抓取样本稀少且带标签噪声，RBC 的后验会**过度自信**（r_t 收缩过快），GWS-R 于是在「错误的小球」上认证出看似力闭合的抓取，而 IDG 又恰好偏好这些「高信息但假安全」的边界抓取，形成「球越小→越敢探边界→真实滑移→若滑移被误判为成功则球更小」的**正反馈误校准**；由于力闭合质量在滑移边界处不连续，一次误校准即可让 GTC 系统性高估迁移成功率，这是本轮所有迁移保证共同依赖的单点假设（可信球校准正确）。

## 2. 形式化定义（完整版）

**定义 201（GRAFT 闭环）** GRAFT 是 LIRO 的「抓取落地 × 虚实迁移可认证」升级。在第 63 轮「语义流 ∘ 实时流」骨架上挂载 GSP/GWS-R（抓取合成与鲁棒验证）、IDG（安全主动辨识）、SGM/RBC（gap 分解与贝叶斯校准）、CDR/PTS（认证域随机化与结构残差）、GTC（迁移证书），并原位升级 `σ_grasp`（USL）与 OCB-Skill。不变式：**抓取候选合成、GWS-R 验证、IDG 选择、RBC 更新、CDR 训练、GTC 认证全部在语义流/低频线程；实时路径只执行已认证抓取的握力/阻抗轨迹，零学习写操作**。

**定义 202（GSP 抓取合成规划器）** GSP: (P_cloud, x', φ̂, r) → {(G_i, ε_rob(G_i))}_{i=1}^{K}。流程：
1. 6-DoF 抓取检测：以 LSF 的几何嵌入 g 与 x' 为输入，输出候选位姿 T_i ∈ SE(3)、接触点集 C_i、进近方向 a_i、开口 w_i（N_cand ≈ 256）；
2. 碰撞/可达性/接近方向过滤（沿用 USL `pre_reach` 与 `𝒞_approach`）；
3. GWS-R 验证（定义 203）：保留 ε_rob(G_i) ≥ ε_min 的候选；
4. 按 ε_rob / cost 排序输出。cost = 时间 + 能耗 + 碰撞风险。
检测器离线训练（仿真 + 少量真实抓取），部署后冻结；仅 GWS-R 的 φ 球随 RBC 在线更新。

**定义 203（GWS-R 鲁棒抓取扳手空间）** 对接触 i，单位法向 n_i、切向基 {t_i1, t_i2}、接触点 p_i：
- 摩擦扳手锥 `W_i(μ) = {[f; p_i×f] : f = n_i + β₁t_i1 + β₂t_i2, √(β₁²+β₂²) ≤ μ, f_n ≥ 0}`；
- 抓取扳手空间 `GWS(C,μ) = Σ_i W_i(μ)`（Minkowski 和）；
- 抓取质量 `ε(G,φ) = max{ε : ε·𝔹 ⊂ GWS(C,μ(φ))}`，即原点处最大内切球半径（Ferrari-Canny）。
**鲁棒版本**：`ε_rob(G) = min_{φ∈B(φ̂,r)∩𝒢} ε(G,φ)`。由于 ε 对 μ 单调递增、对接触法向误差 Lipschitz 连续，取 `L_ε = sup_φ ‖∇_φ ε(G,φ)‖`，则
`ε_rob(G) ≥ ε(G,φ̂) − L_ε·r`。
因此 GSP 的可行性判据为 `ε(G,φ̂) ≥ ε_min + L_ε·r`——**这是保守但可计算的球上力闭合充分条件**。精确最坏值可由 GWS 多面体 + μ 线性缩放求解（小规模 LP），Lipschitz 界作为快速剪枝。

**定义 204（IDG 信息导向抓取）** 维护后验 p(φ|o_{1:t}) 与可信球 B_t。每个语义步：
`G_{t+1} = argmax_{G∈𝒢_cand, ε_rob(G)≥ε_min} IG(G)/cost(G)`，
其中 `IG(G) ≈ ½ log det(I + Σ_t I(G))`，`I(G) = J_μ(G)ᵀΣ_o⁻¹J_μ(G)`，J_μ = ∂o/∂φ 为抓取结果对 φ 的敏感度（由 GWS 与接触模型解析或有限差分得到）。
安全集 `S_t = {φ: ∃G∈𝒢_cand, ε(G,φ) ≥ ε_min}`。采用 SafeOpt 指数在「利用（最大 ε_rob）」与「探索（最大 IG）」间切换：`index(G) = max(min(ε_rob(G)−ε_min, IG(G)), ...)`。当 B_t 收缩，此前不安全的边界抓取进入 S_t，实现**安全集单调扩张**。

**定义 205（SGM 虚实差异模型）** sim-to-real gap 分解为
`Δ = φ* − φ̂_sim = Δ_epi + Δ_ale + Δ_struct`：
- `Δ_epi`：参数先验误差（仿真 μ、质量、阻尼与真实不符），**可**由真实交互辨识；
- `Δ_ale`：不可约接触随机性（微观粗糙、微滑），只能被概率覆盖；
- `Δ_struct`：结构错配（刚性点接触 vs 软指面接触、Coulomb vs LuGre、可变形物体、传感器偏置），**不落在参数空间**。
可信球 B_t 以 1−α 覆盖 `Δ_epi + Δ_ale`；`Δ_struct` 由函数空间残差 `r_struct(x', w_contact)` 单独建模，上界 δ_s。**设计原则：不得通过放大 r_t 覆盖 Δ_struct**——否则 ε_rob = ε(G,φ̂) − L_ε r_t 被压至 0，所有抓取判为不可行。

**定义 206（RBC 真实到仿真贝叶斯校准）** 真实抓取试验给出结果 o_i ∈ {success, slip, drop, force_anomaly}。似然 p(o_i|φ,G_i) 由接触力学 + 噪声模型给出。后验
`p(φ|o_{1:t}) ∝ p(φ) Π_{i=1}^t p(o_i|φ,G_i)`。
Laplace 近似：`Σ_t⁻¹ = Σ_0⁻¹ + Σ_i I_i(G_i)`，`φ̂_t = Σ_t(Σ_0⁻¹φ̂_0 + Σ_i I_i(G_i)φ̂_i)`。
可信球 `B_t = {φ: (φ−φ̂_t)ᵀΣ_t⁻¹(φ−φ̂_t) ≤ χ²_{d,1−α}}`，半径 `r_t = √(χ²_{d,1−α}·λ_max(Σ_t))`。每次更新 `calib_ver += 1`。

**定义 207（CDR 认证域随机化）** 训练学生策略时，仿真参数采样自 `φ_sim ~ B_t ∩ 𝒢`（而非固定区间）。WCV-Grasp 在 `B_t ∩ 𝒢` 上搜索最坏 φ 做 CVaR 收缩。因为 B_t 由 RBC 以覆盖率 1−α 校准，域随机化的分布是「有据可依」的：**DR 分布 = 当前可信参数集**。B_t 收缩时 DR 采样域体积按 `det(Σ_t)^{1/2}` 缩小，样本密度上升。

**定义 208（PTS 特权教师-学生 + 结构残差）** 教师 `π_T(a|x', φ_sim)` 在仿真中可用特权 φ_sim；学生 `π_S(a|x')` 仅用可观测量。蒸馏目标
`L_PTS = E[KL(π_T(·|x',φ_sim) ‖ π_S(·|x'))] + λ_inv·L_inv`，
其中 L_inv 沿用 DIR 的干扰不变正则，防止学生死记仿真专属纹理/光照。
真实执行加入结构残差补偿：`a_real = π_S(x') + R_ψ(x', w_contact)`，R_ψ 在真实（或高保真）残差样本上训练，`‖R_ψ‖ ≤ δ_s` 由 Lipschitz 正则约束。

**定义 209（GTC 抓取迁移证书）** `J_graft = (ε_rob, r_t, α, δ_s, dr_ver, real_n, grasp_seq_hash, calib_ver)`。
验证规则：
`Valid(J_graft) ⇔ Valid(J_liro) ∧ ε_rob ≥ ε_min ∧ r_t ≤ r_max ∧ δ_s ≤ δ_max ∧ dr_fresh ∧ calib_fresh ∧ cov_t ∈ [1−α−η_cov, 1−α+η_cov]`。
其中 dr_fresh 表示 dr_ver 与当前 RBC 版本差 ≤ 1，calib_fresh 表示 calib_ver 在最近 n_fresh 步内更新过。

**定义 210（接地抓取原语 σ_grasp^GWS）** 把 USL 的 `σ_grasp` 实例化：
- `pre_σ(φ,x') ≡ ε_rob(G,φ̂,r) ≥ ε_min ∧ a ∈ 𝒞_approach ∧ reachable(T) ∧ ¬collision(T)`；
- `eff_σ(φ,x') ≡ grasp_established ∧ ‖w_ext‖ ≤ w_max`（grasp_established 由触觉阵列 + 腕部力矩 + 位姿一致性判定）；
- `π_σ(x';θ_σ)` 输出抓取位姿 T、握力 f_grip 轨迹、腕部阻抗关键帧；
- `cost = α_t·t_exec + α_e·E + α_r·risk`；
- `𝒫_feas` 用 GWS-R 采样验证（∀φ∈B_t 力闭合）。
由此 `σ_grasp` 可被 CSP 与 reach/push/hand-over 组合，抓取不再是黑箱符号。

**定义 211（主动探针集与安全扩张）** 探针集 `𝒫_t = {G∈𝒢_cand : ε_rob(G) ≥ ε_min}`。扩张算子 `Expand(S_t, B_t) = {φ: ∃G∈𝒫_t, ε(G,φ) ≥ ε_min}`。每次 RBC 更新后 S_{t+1} = Expand(S_t, B_{t+1})。SafeOpt 决策：以指数 `index(G) = max(min(ε_rob(G)−ε_min, IG(G)/c), κ·IG(G)/c)` 选择利用或探索。**安全集随球收缩单调扩张**：r_{t+1} ≤ r_t ⇒ 𝒫_{t+1} ⊇ 𝒫_t。

**定义 212（抓取迁移成功下界）** 设 G 在 B_t 上 ε_rob-力闭合，`P[φ* ∈ B_t] ≥ 1−α`，结构残差 `‖r_struct‖ ≤ δ_s`。有效力闭合裕度 `ε_eff = ε_rob − L_ε·δ_s`。设滑移概率随裕度指数衰减 `P[slip|ε_eff] ≤ exp(−ε_eff²/(2σ_slip²))`，则
`P[success_real(G)] ≥ (1−α)·(1 − exp(−(ε_rob − L_εδ_s)²/(2σ_slip²)))`。
该式把两个「漏气口」分开：r_t（参数/随机不确定，进 α 与 ε_rob）与 δ_s（结构错配，进 ε_eff）。**治理结构误差不能靠扩大球，只能靠残差补偿 R_ψ**。

**定义 213（校准新鲜度与覆盖率）** `cov_t = (1/N_val)Σ 𝟙[真实结果与 B_t 预测一致]`（可用交叉验证或在线结果滑窗估计）。要求 `|cov_t − (1−α)| ≤ η_cov`。若越界，判定 B_t 失校准（过窄或过宽），强制 `real_n += n_recalib` 并暂停 GTC 认证（降级为「探索模式」只执行 ε_rob 远大于 ε_min 的保守抓取）。

**定义 214（结构残差算子）** `r_struct(x', w_contact) = w_contact^real − w_contact^model(φ̂, G, x')`，其中 w_contact 为六维接触扳手。R_ψ 拟合该残差，`δ_s = sup_{x'}‖R_ψ(x', w_contact)‖`，通过谱范数正则与验证集分位数估计。残差进入 GTC 与迁移下界。

**定义 215（抓取条件 φ 可辨识性）** 抓取 G 的 Fisher 信息 `I(G) = J_μ(G)ᵀΣ_o⁻¹J_μ(G)`。若 `rank(I(G)) < d`，则存在不可辨识的 φ 子空间（如单一正抓无法区分 μ 与法向偏置）。IDG 需组合多个抓取使 `Σ_i I(G_i)` 满秩；GTC 要求 `rank(Σ_t⁻¹) = d` 或显式声明未辨识子空间并按保守上界处理。

**定义 216（J_graft 有效性）** `Valid(J_graft) ⇔ Valid(J_liro) ∧ ε_rob ≥ ε_min ∧ r_t ≤ r_max ∧ δ_s ≤ δ_max ∧ dr_fresh ∧ calib_fresh ∧ cov_t ∈ [1−α−η_cov, 1−α+η_cov] ∧ rank(Σ_t⁻¹) = d`。任一不满足则 GTC 标记 `graft_status ∈ {degraded, exploring, invalid}`，系统退回 LIRO 的保守抓取（大握力、慢接近、浅接触）。

### IP-205 GWS-R（鲁棒抓取扳手空间）

```python
def gws_epsilon(G, phi):
    """Ferrari-Canny 质量：GWS 内以原点为心的最大内切球半径。"""
    mu = phi.mu
    ws = minkowski_sum([friction_wrench_cone(c, mu) for c in G.contacts])
    return max_inscribed_ball_radius(ws)          # 小规模 LP / QP

def robust_epsilon(G, phi_hat, r, L_eps=None):
    """球上最坏情形力闭合质量的下界。"""
    eps_hat = gws_epsilon(G, phi_hat)
    if L_eps is None:
        L_eps = lipschitz_epsilon(G, phi_hat)     # 解析/有限差分上界
    return eps_hat - L_eps * r, eps_hat, L_eps

def is_robust_force_closure(G, phi_hat, r, eps_min):
    eps_rob, eps_hat, L_eps = robust_epsilon(G, phi_hat, r)
    # 快速剪枝；必要时用精确 LP 求 min_{phi in B} eps
    if eps_hat < eps_min:
        return False, eps_rob
    if eps_rob >= eps_min:
        return True, eps_rob
    return exact_min_epsilon_over_ball(G, phi_hat, r) >= eps_min, eps_rob
```

### IP-204 GSP（抓取合成规划器）

```python
class GraspSynthesisPlanner:
    def __init__(self, detector, eps_min=0.02, n_cand=256):
        self.detector, self.eps_min, self.n_cand = detector, eps_min, n_cand

    def synthesize(self, P_cloud, x_prime, phi_hat, r):
        raw = self.detector(P_cloud, x_prime)[: self.n_cand]   # 6-DoF 候选
        feasible = []
        for G in raw:
            if not reachable(G.T) or collides(G, P_cloud):
                continue
            if not approach_in_cone(G.a, x_prime):
                continue
            ok, eps_rob = is_robust_force_closure(G, phi_hat, r, self.eps_min)
            if ok:
                feasible.append((G, eps_rob))
        feasible.sort(key=lambda z: z[1] / z[0].cost, reverse=True)
        return feasible
```

### IP-206 IDG（信息导向抓取 / 安全主动辨识）

```python
class InformationDirectedGrasping:
    def __init__(self, eps_min=0.02, kappa=0.5):
        self.eps_min, self.kappa = eps_min, kappa

    def information_gain(self, G, Sigma):
        J = grasp_sensitivity(G)                      # do/dphi
        I = J.T @ np.linalg.inv(Sigma_o) @ J
        return 0.5 * np.log(np.linalg.det(np.eye(len(Sigma)) + Sigma @ I))

    def select(self, candidates, phi_hat, r, Sigma):
        safe = [(G, e) for G, e in candidates
                if is_robust_force_closure(G, phi_hat, r, self.eps_min)[0]]
        best, best_idx = None, -np.inf
        for G, eps_rob in safe:
            ig = self.information_gain(G, Sigma)
            exploit = eps_rob - self.eps_min
            idx = max(min(exploit, ig / G.cost), self.kappa * ig / G.cost)
            if idx > best_idx:
                best, best_idx = G, idx
        return best                                     # 无安全候选则返回 None
```

### IP-208 RBC（真实到仿真贝叶斯校准）

```python
class RealToSimBayesianCalibration:
    def __init__(self, phi_0, Sigma_0, alpha=0.05):
        self.phi_hat, self.Sigma = phi_0.copy(), Sigma_0.copy()
        self.alpha, self.calib_ver, self.real_n = alpha, 0, 0

    def update(self, G, outcome, Sigma_o):
        J = grasp_sensitivity(G)
        I = J.T @ np.linalg.inv(Sigma_o) @ J            # Fisher 信息
        self.Sigma = np.linalg.inv(np.linalg.inv(self.Sigma) + I)
        # 简化：以观测残差做 Laplace 均值更新
        self.phi_hat = self.phi_hat + self.Sigma @ J.T @ np.linalg.inv(Sigma_o) @ residual(outcome, G)
        self.calib_ver += 1
        self.real_n += 1
        return self.phi_hat, self.Sigma

    def credible_radius(self):
        d = len(self.phi_hat)
        chi2 = chi2_ppf(1 - self.alpha, d)
        return np.sqrt(chi2 * np.linalg.eigvalsh(self.Sigma).max())

    def coverage_ok(self, cov_t, eta_cov=0.02):
        return abs(cov_t - (1 - self.alpha)) <= eta_cov
```

```python
def build_graft_certificate(eps_rob, rbc, delta_s, dr_ver, grasp_seq, cov_t,
```

```python
def GRAFT_round(M, obs, task):

    phi_hat, z_scene, pi_int, (U_ep, U_al) = M.mel.infer_by_mode(
        M.ocb_grasp.choose().mel_mode, V, T, P, L, x_prime)
    M.anchor = M.ara.commit(x_prime, phi_hat, r=M.rbc.credible_radius(), ...)

    # ———— 抓取规划（GSP + GWS-R）————
    cands = M.gsp.synthesize(P_cloud, x_prime, M.rbc.phi_hat, M.rbc.credible_radius())
    # ———— 技能组合（USL 中 σ_grasp 已接地）————
    goal = M.dms.parse_goal((U_ep, U_al))
    tau, theta_bind = M.csp.plan(goal, x_prime, M.rbc.phi_hat, M.rbc.credible_radius(),
                                 grasp_candidates=cands)
    # ———— IDG：若规划含抓取且需要辨识，选探针；否则执行最优抓取 ————
    if task.needs_probe(M.rbc.credible_radius()):
        G = M.idg.select(cands, M.rbc.phi_hat, M.rbc.credible_radius(), M.rbc.Sigma)
    else:
        G = cands[0][0] if cands else None
    if G is None:
        return M, None, None, build_graft_certificate(0.0, M.rbc, np.inf, -1, [], 0.0,
                                                      EPS_MIN, R_MAX, DELTA_MAX, ALPHA, ETA_COV)

    # ———— 执行（实时流只跑已认证抓取轨迹）————
    K_safe, EV_exec, cert_exec = realtime_step_graft(M, G, x_prime, tau, theta_bind)
    # ———— RBC：真实结果 → 收缩球 ————
    outcome = classify_grasp_outcome(EV_exec)
    M.rbc.update(G, outcome, Sigma_o=contact_noise_cov(EV_exec))
    cov_t = M.rbc.update_coverage(EV_exec)
    # ———— PTS / CDR（低频）————
    if M.step % CDR_PERIOD == 0:
        certified_domain_randomization(M.student, M.rbc.phi_hat,
                                       M.rbc.credible_radius(), n_steps=CDR_STEPS)
    delta_s = M.pts.estimate_residual_bound()
    # ———— GSB 记账 + GTC ————
    M.gsb.mine(EV_exec, G)
    cert = build_graft_certificate(
        eps_rob=cands[0][1] if cands else 0.0, rbc=M.rbc, delta_s=delta_s,
        dr_ver=M.cdr.version, grasp_seq=[G], cov_t=cov_t,
        eps_min=EPS_MIN, r_max=R_MAX, delta_max=DELTA_MAX, alpha=ALPHA, eta_cov=ETA_COV)
    return M, K_safe, EV_exec, cert
```

## 4. 推导

**引理 5（GWS-R 下界）** 抓取质量 `ε(G,φ)` 由 GWS(C,μ(φ)) 的内切球半径给出。对 Coulomb 摩擦，μ 增大使每个摩擦锥变宽，GWS 单调扩张，故 ε 对 μ 单调递增；对接触法向 n_i 的扰动，GWS 顶点连续移动，内切球半径对顶点位置的扰动 Lipschitz 连续（多面体内切球半径是顶点坐标的 Lipschitz 函数）。因此存在 `L_ε = sup_φ‖∇_φ ε(G,φ)‖ < ∞`，且对任意 φ ∈ B(φ̂,r)，
`ε(G,φ) ≥ ε(G,φ̂) − L_ε‖φ − φ̂‖ ≥ ε(G,φ̂) − L_ε r`。
取右端 ≥ ε_min 即保证球上所有 φ 力闭合。∎

**引理 6（RBC 收缩率）** Laplace 后验精度 `Σ_t⁻¹ = Σ_0⁻¹ + Σ_{i≤t}I_i`。若每次抓取 Fisher 信息 `I_i ⪰ c·I`（满秩、一致下界 c>0），则 `Σ_t⁻¹ ⪰ Σ_0⁻¹ + c·t·I`，从而 `λ_max(Σ_t) ≤ 1/(λ_min(Σ_0⁻¹) + c t)`，故
`r_t = √(χ²_{d,1−α} λ_max(Σ_t)) = O(r_0/√t)`。
且 IDG 选 `I(G)` 最大的抓取，使 c 尽量大，收缩更快。∎

**定理 4（迁移成功下界）** 由全概率公式，
`P[fail] = P[φ*∉B_t]·P[fail|φ*∉B_t] + P[φ*∈B_t]·P[fail|φ*∈B_t]`
`≤ α·1 + (1−α)·P[fail|φ*∈B_t]`。
在 φ*∈B_t 时，G 力闭合且 ε_eff = ε_rob − L_εδ_s（结构残差经 R_ψ 补偿后的剩余）。按滑移模型 `P[slip|ε_eff] ≤ exp(−ε_eff²/(2σ_slip²))`，故
`P[success_real] ≥ (1−α)(1 − exp(−(ε_rob−L_εδ_s)²/(2σ_slip²)))`。∎
**解读**：α 由 RBC 覆盖率控制（参数/随机不确定），δ_s 由 PTS 残差控制（结构错配）；两者不可互相替代。

**定理 5（IDG 安全探索的近最优性）** 将抓取成功约束 `ε(G,φ) ≥ ε_min` 视为 SafeOpt 的约束函数 g(φ)，信息增益为目标函数。在 g Lipschitz、目标函数为 sub-Gaussian 的假设下，SafeOpt 的累积遗憾满足 `R_T ≤ O(√(T·γ_T))`，且任意步所选 G 满足 `ε_rob(G) ≥ ε_min`（由选择约束保证）。因此**探索全程安全，且渐近达到信息最优**。∎

**命题（CDR 优于固定 DR）** 设固定 DR 在区间 `[φ_lo,φ_hi]` 采样，CDR 在 B_t 采样。B_t 体积 `Vol(B_t) = V_d·r_t^d·√det(Σ_t)/...`，随 r_t 按 `r_t^d` 缩小。在真实 φ* ∈ B_t 的条件下，CDR 的采样密度在 φ* 邻域提升 `∝ (Vol_fixed/Vol(B_t))`，同等训练步数下覆盖真实参数的样本更多。由 PAC 界，学生策略在 φ* 的泛化误差随有效样本密度下降，故零样本迁移成功率随 r_t 收缩单调上升。∎

**命题（安全集单调扩张）** `𝒫_t = {G: ε_rob(G; r_t) ≥ ε_min}`。r_{t+1} ≤ r_t ⇒ `ε(G,φ̂) − L_ε r_{t+1} ≥ ε(G,φ̂) − L_ε r_t`，故若 G ∈ 𝒫_t 则 G ∈ 𝒫_{t+1}，即 `𝒫_{t+1} ⊇ 𝒫_t`。∎（**注意：此单调性依赖 φ̂ 不漂移过大；若 Δ_epi 重估导致 φ̂ 跳变，需重置安全集，见风险 4。**）

## 7. 已知风险

**一句话**：若真实抓取样本稀少且带标签噪声，RBC 后验会**过度自信**（r_t 收缩过快），GWS-R 在「错误的小球」上认证出看似力闭合的抓取，而 IDG 又偏好这些「高信息但假安全」的边界抓取，形成「球越小 → 越敢探边界 → 真实滑移 → 若滑移被误判为成功则球更小」的**正反馈误校准**；由于力闭合质量在滑移边界处不连续，一次误校准即可让 GTC 系统性高估迁移成功率，这是本轮所有迁移保证共同依赖的单点假设（A84）。

**次级风险与缓解**：
1. **力闭合不连续**：ε(G,φ) 在接触丢失/滑移边界处跳变，Lipschitz 界局部失效 → 用区间算术/精确 LP 在最坏点复核，并在边界附近提高采样密度；GTC 对 ε_rob 接近 ε_min 的抓取标注 `near_boundary=True`。
2. **RBC 过自信 / 误校准**：小样本 + 标签噪声 → 采用 Student-t 稳健似然、覆盖率在线检验（定义 213）、失校准时冻结认证并强制增采；对成功/滑移标签做多传感器交叉验证（触觉 + 腕力矩 + 视觉）。
3. **结构残差不可辨识**：Δ_struct 与 Δ_epi 混淆（软指刚度可被误当摩擦） → 设计解耦实验（同材质变刚度、同刚度变摩擦），PTS 残差与 RBC 参数联合但分块更新。
4. **安全集重置**：φ̂ 大幅跳变时单调扩张失效 → 以 `‖φ̂_{t+1}−φ̂_t‖ > r_t` 为触发条件重置 S_t 并回退保守抓取。
5. **检测器覆盖不足**：6-DoF 检测器漏掉可行抓取 → 用 GWS-R 引导的局部采样补候选（以接触点对合成 antipodal 抓取），并记录检测召回。
6. **IDG 探索代价**：探针抓取占用真实试次 → 预算化（OCB-Grasp 的 probe budget），仅在预期信息增益超过阈值时探索。
7. **教师-学生分布漂移**：CDR 分布随 B_t 变化导致学生遗忘 → 经验回放保留历史 B_t 样本 + EWC 正则（继承第 63 轮 DIR 缓解）。
