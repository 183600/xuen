# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「状态隔离」×「桌面操作」）

> 第 57 轮用元少样本、跨模态对账、个性化有界信任把"证据承诺"升级为"少样本可校准、跨模态可对账、个性化有界"，但它自己的风险自陈暴露了三个结构性裂缝：**(a)** 元先验是跨全体区域摊销的——摊销既是少样本效率的来源，也是系统性污染的通道，一个语料盲区足以让"坏先验普遍"；**(b)** 个性化信任跨会话累积，却没有"哪些状态属于哪个会话/操作者/区域"的边界，授权与声誉可以越界复用；**(c)** 全部证据与判定都长在"地形/落脚点"上，一旦进入**桌面操作**这种对象多、接触富、遮挡重的场景，"未观测"与"未改变"无法区分，旧证据会以"一致"的假象通过证据门。本轮两个灵感各给一把手术刀：**状态隔离**把读写路径拆开——写只在作用域影子内、读只读已提交快照、提交是带版本校验的事务、证伪可按来源 DAG 回退；**桌面操作**给出最自然的压力测试——对象中心状态、遮挡即幻读、操作即事务、干扰边即跨对象耦合。核心命题由"证据说可信"升级为 **"写可隔离、读可快照、诺可事务、错可回滚的证据说可信"**。

核心矛盾：
- **H29（隔离 vs 复用）**：完全隔离杀死跨区域摊销，退化成每区域手工先验；完全不隔离则一条坏证据/一次坏元更新污染全局。隔离与共享必须同时成立——只能靠"**写隔离、读共享已提交**"的读写分离，而不是二选一。
- **H30（遮挡 vs 一致性）**：桌面操作中，被遮挡对象"没看见"与"没变化"不可区分；旧快照上局部自洽的两个作用域，可能在新观测下互相矛盾——这正是数据库里的**幻读/写偏斜**，不是普通噪声。
- **H31（事务 vs 实时）**：隔离级别越高越安全越慢，但控制回路不能阻塞；锁会死锁，乐观并发会重试，而打翻杯子这类动作根本没有回滚——事务语义必须区分"可补偿"与"不可逆"。

## 0. 直觉与动机

**灵感 1（状态隔离 → 读写分离、作用域、快照与版本）**
直觉：第 57 轮的污染问题不是"证据错了"，而是"错证据和好证据被写进了同一个信念变量"。数据库早就解决过同构问题：**写进影子/日志，读读已提交快照，提交时校验版本**。于是每个作用域（区域/对象/操作者/会话/元模型版本）各有 committed core 与 copy-on-write shadow；决策规则只能读 committed 的不可变快照，provisional 证据只能经"加宽不确定度"影响动作，永远不能直接进入承诺。跨区域摊销仍然保留，但它只读**已提交且带版本**的证据，元模型更新本身也先写影子作用域——"坏先验普遍"被降级为"坏版本可隔离"。

**灵感 2（桌面操作 → 对象中心、遮挡即幻读、干扰边）**
直觉：桌面不是一张连续地形，而是一张**对象图**：每个对象有自己的位姿、支撑、可见性与可抓性；搬动 A 可能碰倒 B、抽走 C 的支撑面。把遮挡当作幻读处理：旧快照里"B 没出现/没变化"不能证明 B 未变，L2（不可逆或高代价）操作必须先在可串行化快照上重观测遮挡区与支撑闭包。操作 α 是事务：read_set 含对象、支撑面与干扰闭包，write_set 含被移动对象与受影响邻居；可补偿的推移用 undo 回滚，不可补偿的（打翻、压碎）在承诺前就被标为不可逆。

**灵感 3（合流 → 证据账本 + 事务化承诺门）**
直觉：第 57 轮的 J_p 证书只是一次性快照，无法回答"这条证据是谁、在哪个作用域、基于哪个元版本、后来有没有被证伪"。把它升级成**隔离证据账本**：每条证据带 (scope, version, provenance, status)，状态在 provisional→committed→retracted 之间迁移；承诺门从"检查一堆证据类"变成"在一个一致快照上执行一个事务"，证据门过的前提是它读到的证据全部已提交且版本未变。

**灵感 4（证伪 → 污点回溯而非全局重训）**
直觉：证伪不再是"把某模态 ρ 降一点"这种局部补丁，而是沿 provenance DAG 找子孙证据、把受影响作用域回退到 savepoint、把触及的元模型版本整体隔离。回退是有界的：污点超过 B_taint 就保守停并请人，而不是让一次证伪引发雪崩式重训。

**灵感 5（PCE++ → 乐观事务化的探-诺-演）**
直觉：控制回路里不拿锁，拿快照与版本号。探针写影子、对账、乐观版本校验，冲突就重试/降档/绕行，重试超过 R_max 就进 L2 或安全停；桌面模式在每次操作后额外做干扰闭合检查（邻居与支撑面是否仍一致）。事务化不是给系统加锁，而是给"承诺"加一个可验证、可撤销的边界。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（作用域状态隔离 SIS）** 状态按作用域 ξ∈{区域 r, 对象 o, 操作者 op, 会话 ses, 元模型版本 v_φ} 分区；每作用域维护不可变 committed core 与 copy-on-write shadow。写只能落 shadow；决策规则只能读 committed 的冻结快照 freeze(core, ver)；provisional 写只允许经"加宽 P_fail"通道影响动作。跨作用域引用必须携带 (ξ, ver, prov) 三元组；未携带来源的写入即拒绝。

**定义 140（事务化承诺 TCS）** 承诺事务 T=(read_set, write_set, E, iso, t_c)，在快照 S=snapshot(committed, t_c) 上求值。提交条件：∀x∈read_set: ver(x)=S.ver(x)（乐观并发校验）∧ E⊆committed(S) ∧ iso≥iso_min(risk)。风险级映射：L0=read-committed（探索可读脏，但不得承诺）、L1=snapshot（禁脏读，容忍写偏斜）、L2=serializable（禁幻读，干扰闭包全读）。冲突 ⇒ 有界重试（≤R_max）→ 降档/绕行/安全停，全程不阻塞控制环。

**定义 141（对象中心桌面状态 OCS）** 桌面对象图 G=(O, E_int)，对象 o 的隔离状态 s_o=(pose, support, visibility, grasp, ver)，干扰边 (o,o')∈E_int 表示接触/支撑/遮挡耦合。遮挡等价幻读：隐藏对象的状态变化在旧快照不可见 ⇒ L2 必须 refresh(closure(o)) 后重读。操作 α 为状态转移 s←do(α,s)，其 read_set=closure(o)∪{支撑面}，write_set={o}∪affected(closure(o))；irreversible(α) ⇔ 无补偿子 comp(α) 能把可观测量恢复到 ε_comp 内。

**定义 142（隔离证据账本 IEL）** 账本 L 为追加式证据序列 e=(id, ξ, ver, prov, cls, status)，status∈{provisional, committed, retracted}；prov 为来源 DAG（探针/模态/操作者/元版本/上层证据）。替换 J_p 为 J_t=(L, commit_log, txn_log, closure_log, snapshot_ver)。读规则：decision_view(L)={e:status=committed}；provisional 只能加宽；retracted 只从读视图移除、不物理删除（审计与回滚依据）。跨作用域摊销只读 committed 且固定元版本。

**定义 143（证伪回溯事务 RCL）** 证伪 f 在 prov DAG 上传播 taint(f)=descendants(f)。回退：受影响作用域 restore 到最近 savepoint，相关 committed 证据置 retracted，重算读视图；若 taint 触及元版本 v_φ，则隔离该版本并回退到影子接管前版本。对已执行的受影响动作执行 comp(α)；若存在不可补偿动作或 |taint|>B_taint，则升级为安全停/人工，不尝试部分回滚。

**定义 144（探-诺-演++ PCX2）** 每检查点：①取快照 S 与隔离级 iso(risk)；②探针与对账写入影子并记入 L（provisional）；③构造承诺事务 T 并在 S 上做版本校验与证据门；④提交⇒merge 并推进版本；冲突⇒有界重试，耗尽⇒降档/绕行/L2/安全停；⑤桌面模式追加干扰闭合复检，遮挡未消则 L2 前强制重观测。不可逆且不可补偿动作必须 iso=serializable 且有人工/共识佐证。

## 2. 关键算法伪代码（完整版见产物区）

```python
def scoped_commit(S, L, txn, risk):                 # IP-139/140/142
    snap = snapshot(S.committed, txn.t_c)
    if any(S.ver[x] != txn.read_ver[x] for x in txn.read_set):
        return ('conflict', bounded_retry(txn))      # 乐观并发，不阻塞
    if isolation_rank(txn.iso) < iso_min(risk):
        return ('reject', 'isolation_too_weak', txn)
    if not decision_view(L).covers(txn.E, snap.ver):
        return ('reject', 'evidence_not_committed', txn)
    S.commit(txn); L.commit(txn.E)
    return ('committed', S, L)

def desk_step(S, L, o, alpha):                       # IP-141/143
    clo = interference_closure(S.G, o)
    if occluded(o) and irreversible(alpha):
        reobserve(clo)                               # 遮挡=幻读，先消幻读
    if phantom(S.snapshot, clo):
        return ('reject', 'phantom', refresh(clo))
    txn = mk_txn(read=clo | support(o), write={o} | affected(clo),
                 iso='serializable', E=evidence(o, alpha))
    st = scoped_commit(S, L, txn, risk(alpha))
    if st[0] == 'committed' and not compensable(alpha):
        S.mark_irreversible(alpha)                   # 不可逆：只允许成功
    return st

def falsify(S, L, f):                                # IP-143
    taint = descendants(L.prov, f)
    if len(taint) > B_TAINT:
        return ('safe_stop', 'taint_unbounded')
    for xi in scopes(taint): S.restore(xi, S.savepoint(xi))
    L.retract(taint)
    if touches_meta_version(taint): S.quarantine(meta_ver(taint))
    return ('rolled_back', S, L)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SIS | O(\|changed\|) COW/写；O(1) 版本校验 | O(Σ\|ξ\|) 持久化结构 | 未提交写不进读视图（A41） |
| TCS | O(\|read_set\|+\|write_set\|)/事务；重试≤R_max | O(\|txn_log\|) | 快照一致、无丢失更新（A42） |
| OCS | O(deg(G)+\|closure\|)/操作 | O(\|O\|+\|E_int\|) | 干扰闭合完整（A43） |
| IEL | O(1) 追加；O(\|L\|) 物化读视图 | O(\|L\|) 追加式 | 状态迁移单向可审计 |
| RCL | O(\|taint\|) ≤ O(B_taint) | O(\|prov DAG\|) | 污点精确、补偿正确（A44） |
| PCE++ | 原 PCE+ × O(R_max) | 同 PCE+ | 乐观终止、不阻塞 |

**正确性定理（Isolated Transactional Soundness, ITS 概要）**：在 A37–A40 上新增 (A41) 作用域隔离与来源诚实：写只经 shadow、committed 不可变、provenance DAG 覆盖全部证据；(A42) 快照/版本完整：承诺均在不可变快照求值、版本校验无丢失更新、决策规则不读脏；(A43) 干扰闭合：可操作对象的接触/支撑/遮挡耦合边缺失率 ≤δ_int；(A44) 补偿正确且有界：可补偿动作恢复到 ε_comp、污点 |taint|≤B_taint 否则安全停。则：(i) **无脏读承诺**：任何承诺只依赖其快照内 committed 证据，单条坏 provisional 证据在验证前无法进入承诺；(ii) **污点遏制**：一次证伪只回退其 DAG 子孙，不相关作用域不受影响——隔离与复用同时成立；(iii) **L2 无幻读**：可串行化快照+遮挡重观测使幻读致承诺概率 ≤δ_obs+δ_int；(iv) **活性**：乐观并发无死锁，重试有界，超限必降档/停；(v) 部署失效率按检查点取联合界，新增项为 δ_int+δ_obs+R_max 超限安全停项。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 干扰边/作用域耦合漏建 → 写偏斜 | 高 | 干扰闭合审计；未建模耦合默认不可逆；L2 全量重观测 |
| 隔离与版本开销进入实时回路 | 中 | COW + 持久化数据结构；仅关键作用域全隔离；影子异步合并 |
| 乐观重试风暴/尾延迟 | 中 | 自适应 R_max + 指数退避 + 快照预取 |
| 不可补偿动作无法回滚 | 高 | 承诺前不可逆分类；serializable+人工；仅在 L1 允许补偿式快进 |
| 跨会话授权隔离导致声誉不可用或被套利 | 中 | 只读已提交 verdict；有界跨作用域共享；审计 |

## 6. 本轮最大风险

**一句话**：状态隔离把"全局污染"换成了"局部自洽而全局矛盾"——一旦遮挡/接触/支撑的干扰边漏建或跨作用域耦合被当成无关，两个各自通过快照校验的作用域就能同时自信地提交互相矛盾的状态（写偏斜/幻读漏检），而事务语义只会让这类矛盾更难被察觉；因此必须把"未建模耦合"一律降为不可逆风险、L2 强制可串行化重观测，并对干扰闭合本身做独立审计。

# 第 58 轮产物 · 创新点清单 v34：Isolated-Xact-Desktop（作用域状态隔离×事务化承诺×对象中心桌面，SIS×TCS×OCS×IEL×RCL×PCE++）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界"升级为 **"写可隔离、读可快照、诺可事务、错可回滚"**：读写分离的作用域隔离阻断跨区域污染，事务化承诺把"证据门"从一次静态检查变成一致快照上的可验证事务，对象中心桌面状态把遮挡建模为幻读，证伪回溯把"坏证据长寿"升级为"坏版本隔离 + 污点回退"。第 57 轮"一切判定器走隔离"在本轮细化成"**一切状态写入走影子，一切承诺读已提交快照**"。

## 2. 关键算法伪代码

### IP-139 SIS（作用域状态隔离，COW + 只读快照）

```python
class Scope:
    __slots__ = ('sid', 'core', 'shadow', 'ver', 'savepoints', 'parent')
    def __init__(self, sid, parent=None):
        self.sid, self.parent = sid, parent
        self.core, self.shadow = {}, {}          # committed / provisional
        self.ver, self.savepoints = 0, []

def scoped_write(S, xi, key, val, prov):
    assert prov is not None                       # 无法源不写（A41）
    sh = S.shadow[xi]
    if key not in sh:
        sh[key] = clone(S.core[xi].get(key))      # copy-on-write
    sh[key] = Versioned(val, ver=S.ver[xi] + 1,
                        prov=prov, status='provisional')
    return S

def snapshot(S, t):                               # 承诺求值用的不可变视图
    return {xi: ImmutableView(sc, S.ver[xi])
            for xi, sc in S.scopes.items()}

def shared_read(S, xi, ver):                      # 跨作用域摊销唯一入口
    return ImmutableView(S.scopes[xi], ver)       # 只读 committed，不碰 shadow

def merge(S, write_set):                          # 原子提交：shadow -> core
    for xi, kv in write_set.items():
        S.core[xi].update(kv)
        S.ver[xi] += 1
        S.shadow[xi].clear()
    return S
```

### IP-140 TCS（事务化承诺语义，乐观并发 + 风险分级隔离）

```python
ISO_RANK = {'read_committed': 0, 'snapshot': 1, 'serializable': 2}
RISK_ISO = {'L0': 'read_committed', 'L1': 'snapshot', 'L2': 'serializable'}

def scoped_commit(S, L, txn, risk):
    snap = snapshot(S, txn.t_c)
    lost = [x for x in txn.read_set                       # 乐观并发校验
            if S.ver[x] != txn.read_ver[x]]
    if lost:
        return ('conflict', lost)                         # 不阻塞，交由上层重试
    if ISO_RANK[txn.iso] < ISO_RANK[RISK_ISO[risk]]:
        return ('reject', 'isolation_too_weak')
    if not all(e.status == 'committed' and e.ver <= snap[e.scope].ver
               for e in txn.E):                           # 只认已提交证据
        return ('reject', 'evidence_not_committed')
    if risk == 'L2' and not closure_complete(txn.read_set, S.G):
        return ('reject', 'interference_closure')         # 防幻读/写偏斜
    S = merge(S, txn.write_set)                           # 原子写 core
    L = L.commit(txn.E)
    S.log.append(txn)
    return ('committed', S, L)

def bounded_retry(txn, attempt):
    return attempt < R_MAX and (sleep(backoff(attempt)) or True)
```

### IP-141 OCS（对象中心桌面状态，遮挡即幻读）

```python
def interference_closure(G, o):
    return support(o) | contacts(o) | occluders(o)        # 支撑/接触/遮挡

def desk_manipulate(S, L, o, alpha):
    clo = interference_closure(S.G, o)
    if visibility(S, o) < VIS_TH and irreversible(alpha):
        reobserve(clo)                                    # 触觉/侧视消幻读
    if phantom(S.snap, clo):                              # 快照外对象出现
        return ('reject', 'phantom', refresh(S, clo))
    read = clo | {support_surface(o)}
    write = {o} | affected(clo)                           # 受影响邻居也写
    txn = Txn(read_set=read, write_set=write, t_c=S.now,
              read_ver={x: S.ver[x] for x in read},
              E=evidence_for(o, alpha), iso='serializable')
    st = scoped_commit(S, L, txn, risk(alpha))
    if st[0] == 'committed' and irreversible(alpha):
        S.irreversible.add(alpha)                         # 只允许成功，失败即停
    return st

def affected(clo):                                        # 接触/支撑耦合邻居
    return {o2 for o2 in clo if coupled(o2, move_dir, support)}
```

### IP-142 IEL（隔离证据账本，替代 J_p）

```python
def ledger_append(L, e, prov, xi):
    return L.append(Evidence(id=fresh(), scope=xi,
                             ver=L.next_ver(xi), prov=prov,
                             cls=e.cls, status='provisional'))

def commit_evidence(L, txn):
    return L.map(lambda e: e.as_committed() if e.id in txn.E else e)

def decision_view(L, ver):                                # 决策只读已提交
    return [e for e in L if e.status == 'committed' and e.ver <= ver]

def retract(L, taint):
    return L.map(lambda e: e.as_retracted() if e.id in taint else e)

def provenance_ok(L, e):
    return e.prov is not None and acyclic(L.prov, e)      # 来源 DAG 无环

def transaction_certificate_p(sched, L, M, consent_log, closure_log):
    for c in contacts(sched):
        if not closure_complete(c.read_set, M.G):
            return ('reject', 'closure')
        if not decision_view(L, c.snapshot_ver).covers(c.E):
            return ('reject', 'evidence_not_committed')
        if c.irreversible and c.iso != 'serializable':
            return ('reject', 'irreversible_needs_serializable')
    if not all(l2.resolved for l2 in consent_log):
        return ('reject', 'consent_open')
    return ('ok', Jt(L, sched.commit_log, sched.txn_log,
                     closure_log, sched.snapshot_ver))
```

### IP-143 RCL（证伪回溯事务，污点遏制）

```python
def falsify_rollback(S, L, f):
    taint = descendants(L.prov, f)
    if len(taint) > B_TAINT:                              # 污点有界
        return ('safe_stop', 'taint_unbounded')
    bad = performed_actions(taint)
    if any(irreversible(a) for a in bad):                 # 不可补偿不可回退
        return ('escalate', 'irreversible_taint', bad)
    for xi in {e.scope for e in taint}:
        S.restore(xi, S.savepoint(xi)); S.ver[xi] += 1
        S.rho[xi] = downgrade(S.rho[xi])                  # 可靠性同步降级
    L = retract(L, taint)
    for v in meta_versions(taint):
        S.quarantine_meta(v)                              # 坏先验按版本隔离
    for a in bad:
        compensate(a)                                     # 可补偿 undo
    return ('rolled_back', S, L)
```

### IP-144 PCE++（乐观事务化的探-诺-演）

```python
def probe_commit_evolve_txn(x0, M, L, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        retries = 0
        while True:
            snap = snapshot(M, now())
            sigma = foothold_schedule(x0, cp, snap)
            R = schedule_risk(sigma, snap)
            while select_gait(R) == 'halt' and budget.probes_left > 0:
                cands = admissible_probes(cp, snap, F_abs)
                p = argmax(cands, key=lambda q:
                           voi_meta_pessimistic(q, snap) - cost(q))
                if voi_meta_pessimistic(p, snap) < theta_voi: break
                e = execute_probe(p, cap=F_abs)
                L = ledger_append(L, e, prov=[p.id], xi=cp.region)
                M = scoped_write(M, cp.region, 'probe', e, prov=[p.id])
                if disagreement(M, cp) > theta_D:               # 共识探针
                    p2 = most_disagreeing_modality_probe(M, cp.region)
                    e2 = execute_probe(p2, cap=F_abs)
                    L = ledger_append(L, e2, prov=[p.id, p2.id], xi=cp.region)
                    M = scoped_write(M, cp.region, 'probe', e2, prov=[p2.id])
                budget.spend(p)
                snap = snapshot(M, now())
                sigma = reselect_footholds(x0, cp, snap)
                R = schedule_risk(sigma, snap)
            txn = mk_commit_txn(cp, sigma, snap, L, RISK_ISO[risk(cp)])
            st = scoped_commit(M, L, txn, risk(cp))
            if st[0] == 'committed':
                sched.append(commit(sigma, select_gait(R))); break
            if st[0] == 'conflict' and retries < R_MAX:
                retries += 1; continue                          # 乐观重试
            if st[0] == 'conflict':
                return downgrade_or_stop(cp)                    # 重试耗尽
            alt = reroute(M, cp, risk_model)
            if alt and schedule_risk(alt, M) != 'halt':
                route = alt; break
            return negotiate_or_stop(cp, M, sigma, R, consent,
                                     tau_int=tau_int(personas.active.auth))
        if task.domain == 'desk' and not closure_consistent(M):
            return safe_stop('interference_closure_violated')   # 桌面复检
    return sched, L, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SIS | O(\|changed\|) COW/写；O(1) 版本校验 | O(Σ\|ξ\|) 持久化结构 | 未提交写不进读视图（A41） |
| TCS | O(\|read_set\|+\|write_set\|)/事务；重试≤R_max | O(\|txn_log\|) | 快照一致、无丢失更新（A42） |
| OCS | O(deg(G)+\|closure\|)/操作 | O(\|O\|+\|E_int\|) | 干扰闭合完整（A43） |
| IEL | O(1) 追加；O(\|L\|) 物化读视图 | O(\|L\|) 追加式 | 三态迁移单向、来源可审计 |
| RCL | O(\|taint\|) ≤ O(B_taint) | O(\|prov DAG\|) | 污点精确、补偿正确（A44） |
| PCE++ | 原 PCE+ × O(R_max) | 同 PCE+ | 乐观终止、无死锁、不阻塞 |

**正确性定理（Isolated Transactional Soundness, ITS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；新增 **(A41)** 作用域隔离与来源诚实：所有写仅经 shadow、committed core 不可变、provenance DAG 覆盖全部证据且无环；**(A42)** 快照/版本完整：承诺均在不可变快照求值，版本校验保证无丢失更新，决策规则不读 provisional/retracted；**(A43)** 干扰闭合：可操作对象的接触/支撑/遮挡耦合边缺失率 ≤δ_int，L2 使用全闭包；**(A44)** 补偿正确且有界：可补偿动作恢复到 ε_comp 内，污点 |taint|≤B_taint，否则安全停。则：

1. **无脏读承诺（污染遏制）**：任何已提交承诺只依赖其快照内的 committed 证据；单条坏 provisional 证据在验证前无法进入承诺，第 57 轮"坏先验普遍"被限定为可隔离的元版本作用域。
2. **污点遏制（隔离与复用并存）**：一次证伪只回退 prov DAG 的子孙作用域，未关联作用域零回退；跨区域摊销因只读 committed 而保留，写污染不越过 shadow 边界。
3. **L2 无幻读**：可串行化快照 + 遮挡重观测 + 干扰闭包使"遮挡对象已变而旧快照仍自洽"导致 L2 承诺的概率 ≤ δ_obs + δ_int。
4. **活性与实时性**：采用乐观并发而非锁，无死锁；每检查点重试 ≤R_max，超限必降档/绕行/安全停；事务只加在承诺点，不阻塞探针-控制内环。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                  + δ_int + δ_obs·1[L2] + δ_comp)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(R_max 耗尽 ∧ 安全停失效)
```

关键：**隔离给卫生、快照给一致、事务给边界、回滚给纠错**——四件事互相独立，任何一件失效都被其余三件限制在小范围；读写分离是"隔离 vs 复用"这一矛盾的唯一解，而不是在两者间取折中。

## 6. 本轮最大风险

**一句话**：状态隔离把"全局污染"换成了"局部自洽而全局矛盾"——一旦遮挡/接触/支撑的干扰边漏建或跨作用域耦合被当成无关，两个各自通过快照校验的作用域就能同时自信地提交互相矛盾的状态（写偏斜/幻读漏检），而事务语义只会让这类矛盾更难被察觉；因此必须把"未建模耦合"一律降为不可逆风险、L2 强制可串行化重观测，并对干扰闭合本身做独立审计。
