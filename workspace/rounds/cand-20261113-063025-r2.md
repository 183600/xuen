# 第 3 轮迭代（灵感循环 v3：「奖励设计」×「论文发表」）—— 从"抢分策略"转向"对奖励本身的辨识、塑形与可发表验证"

> **承接 v2 的 UIP-01′~15，但换一个更根本的提问方式。** 前两轮我们一直在**优化一个被猜出来的奖励**：默认"失败也保留步骤分""撤回会扣分""重做必然划算"。可是赛制公开的只有每任务 100 分的**静态分值表**，并没有给出步骤分的**判定语义**（首次达成即锁存？终态快照？仅成功才计？）、干扰的**注入时机**与**是否自适应于策略**。用「奖励设计」的视角看，这不是细节，而是**目标函数未定义**；用「论文发表」的视角看，这恰恰是最该被形式化、也最容易发表的那个缺口。本轮把研究重心从"怎么多拿分"前移为"**我们到底在优化什么奖励，以及如何证明我们的优化没有被代理奖励劫持**"。

---

## 0. 被 v2 忽略的"奖励规范缺口"（本轮的核心发现）

### 0.1 直觉解释
v2 的 UIP-02′ 说"保前置、搏末步"，UIP-09′ 说"检测撤回就重做"。这两句话其实都**依赖一个未验证的奖励语义**。如果步骤分是"首次达成即永久锁存"，那么撤回根本不扣分，重做只是为了解锁后续步；如果步骤分是"终态快照"，撤回会直接吞掉已得分，重做才是刚需；如果步骤分"仅在最终成功时结算"，那么中途"保分"完全无意义，最优策略应是全力搏成功。同一套观察，三种奖励语义会导出**三种不同的最优策略**。在没做奖励辨识之前，v2 的很多"必然成立"其实是**条件成立**。

### 0.2 严谨定义（把缺口写成可检验对象）
设子目标谓词 $p_k(s)\in\{0,1\}$，$k=1..K$，分值向量 $w=(w_1,\dots,w_K)$，$\sum_k w_k=100$。定义已达集合 $A_t=\{k: \exists \tau\le t,\ p_k(s_\tau)=1\}$。候选奖励语义：

| 语义 | 步骤分定义 | 撤回的后果 | 直接推论 |
|---|---|---|---|
| **M1 锁存**（latch） | $\sum_{k\in A_T} w_k$ | 不扣分，只延后后续步 | "保分"无风险，继续尝试弱占优 |
| **M2 终态快照**（state） | $\sum_k w_k\,p_k(s_T)$ | 直接丢已得分 | 撤回检测-重做是刚需 |
| **M3 成功门控**（gated） | $1[\text{success}]\cdot 100$（步骤分仅作诊断） | 全部归零 | 中途保分无意义，应全力搏成功 |

还有一个 v2 未区分的维度：**判定时点是"曾经达到"还是"结束时仍为真"**（即 $A_T$ 与 $\{k:p_k(s_T)=1\}$ 的差别），以及**多 attempt 的聚合方式**（取最好/取平均/仅首次）。这些都应进入我们的"奖励卡片"。

### 0.3 为什么这是最高优先级
在强化学习里，**错误指定的奖励比没有奖励更危险**，因为它会稳定地训练出一个高分的错误行为（reward hacking）。我们完全可能花两个月把"终态快照"假设下的恢复机制打磨到极致，结果真机评测用的是 M1 锁存，边际收益骤降。因此本轮把 **UIP-17 RID（黑箱奖励辨识）** 提到所有工程之前：先用**受控探针策略**把官方评测端当作黑箱奖励神谕，反解出奖励语义，再决定押注哪条技术路线。

## 1. 上轮清单在"奖励设计"视角下的再诊断

- **UIP-01′ / UIP-09′（验证-重做）**：机制方向对，但把"进度"当成了一个临时启发式。应升级为**奖励机（Reward Machine）**：进度是一个离散状态 $u\in\{u_0,\dots,u_K\}$，前向事件给分、后向事件表示进度被撤回。验证器不再只是"检查器"，而是**奖励事件检测器**；这使"检测-重做"从策略补丁变成对**非马尔可夫奖励**的正确建模。
- **UIP-02′（步骤分安全网）**：v2 的"保前置、搏末步"其实是一个**最优停止**结论，而它的阈值完全取决于 M1/M2/M3。必须把结论改写成**语义条件式**，并给出可证的停止判据（见 §3.3），而不是一句口号。
- **UIP-11 GSO（Gazebo 计分神谕）**：它现在是一个**代理奖励**。奖励设计视角要求两件事：① 明确代理与真奖励的**差距界**；② 用留出任务 + 真机锚点做**校准**，并把校准误差计入模型选择，而不是把 GSO 分数当真值。
- **UIP-12 DRF（扰动-恢复数据工厂）**：它只造了轨迹，没造**奖励标签**。应补上 done/regressed 事件标注，否则训练恢复策略时仍然在用一个隐式、未定义的奖励。
- **UIP-13 ACS / UIP-15 CSG（实时性）**：延迟与可信度应进入**约束**而不是奖励项，形成约束 MDP（CMDP）：最大化步骤分，满足延迟预算、重做次数预算与可信度下界。
- **UIP-14 MSGR（技能图）**：技能图天然就是奖励机的**转移标签**。v3 把"技能图"与"奖励机"合并，避免两套状态机互相打架。

## 2. 两个灵感词的解读

### 2.1 「奖励设计」= 四个层次，而不是一个技巧
1. **外层奖励（赛制）**：非马尔可夫、有序、且被一个可能自适应的对手修改。这是要被**辨识**的对象（UIP-17），不是被假定的常数。
2. **内层奖励（训练）**：用势函数塑形 $\Phi(u)=\sum_{k\le u}w_k$ 提供稠密信号；但必须处理**对抗性撤回**导致的塑形失效与"隐藏进度"式刷分（UIP-19）。
3. **奖励稳健性**：奖励语义本身不确定 ⇒ 在歧义集上做稳健/后验 CVaR 优化，而不是赌单一语义（UIP-18）。
4. **奖励与可信度的耦合**：延迟/抖动/动作规律性会影响结果可信度，等价于一个**约束**，把"多拿分"和"被判无效"放在同一个优化里（UIP-13/15 升级）。

### 2.2 「论文发表」= 把"能跑"改造成"可证伪、可复现、可被审稿"
- **主张先行**：每个 UIP 必须写成一条可证伪主张（claim）＋一个最强基线＋一个消融＋一个指标＋一个统计检验；否则它只是工程笔记，不是研究。
- **可发表的三件套**：① 形式化（对抗性进度回归 + 奖励语义敏感性）；② 基准（DRB：Disturbance-Recovery Benchmark，含奖励卡片与探针协议）；③ 方法（RMR + ARS + RARP）。"我们榜上有名"不是贡献，"我们能解释为什么有效、并在公开基准上复现"才是。
- **可复现性**：所有离线结论必须能在无官方服务器时复现；种子、配置、判定谓词、探针脚本全部开源。
- **合规与伦理**：单模型约束、外部 VLM 可能违规、"探针策略"是否被赛规允许——都要在论文与参赛前确认。
- **审稿防御**：奖励机、过程奖励模型、稳健 RL、对抗扰动恢复都已有大量文献，新颖性必须精确定位在"**奖励语义未定 + 对手自适应**"这一交叉点上，而不是泛泛的"鲁棒机器人"。

## 3. 核心新形式化（直觉 → 定义 → 推论）

### 3.1 直觉：这不是一个 MDP，而是一个"策略改变对手"的双人博弈
普通设定：环境固定，策略最优反应。真实赛制里，人为干扰往往**看进度触发**（"叠好后再翻开""拉上后再拉开"）。也就是说，**我的策略会改变对手的行为分布**。严格做法是把它写成带对抗扰动的稳健 MDP / 双人随机博弈，而不是单智能体 MDP 加噪声。

**定义（对抗性进度回归博弈）**：$\mathcal{G}=(\mathcal S,\mathcal A,\mathcal U,P,r,\Theta)$，策略 $\pi(a\mid s,u)$，对手 $D_\theta(u'\mid s,a)$ 从歧义集 $\Theta$ 选扰动；奖励由奖励机给出：
$$
\max_{\pi}\ \min_{\theta\in\Theta}\ \mathbb E_{\pi,D_\theta}\Big[\sum_{t}\gamma^t r(u_t,\sigma_t)\Big],\qquad
r(u_k,\sigma=e^+_{k+1})=w_{k+1}.
$$
后向事件 $\sigma=e^-_k$ 的奖励按 §0.2 的语义取 $0$（M1）或 $-w_k$（M2），M3 则在终局再乘成功指示。

### 3.2 直觉：进度不是"分数"，而是一台有记忆的机器
**定义（奖励机）**：$M=(\mathcal U,u_0,\Sigma,\delta,R)$，$\mathcal U=\{u_0,\dots,u_K\}$，$\Sigma=\{e_k^+,e_k^-,e_{\text{timeout}}\}$，
$$
\delta(u_k,e_{k+1}^+)=u_{k+1},\qquad \delta(u_k,e_k^-)=u_{k-1},\qquad \delta(u_k,e_{\text{timeout}})=u_k,
$$
$R(u_k,e_{k+1}^+)=w_{k+1}$，$R(u_k,e_k^-)=0\text{ 或 }-w_k$（依语义）。策略需从观测**推断** $u_t$（部分可观测），验证器即事件检测器。这样，v2 的 verifier 与 skill-graph 被统一成"奖励机状态跟踪 + 技能执行"。

### 3.3 直觉：最后一步不是"勇敢"，是一道期望值题
**定义（停止判据）**：设在当前 episode 已锁定得分 $S$，剩余步若全成功能到 $W$；继续尝试的即时成本为 $c$（时间/延迟/可信度）。在**M3 成功门控**下，继续的期望收益为 $p\,W$，停止为 $S$，故
$$
\text{继续} \iff p>\frac{S}{W}\quad(\text{无成本});\qquad
\text{继续} \iff p\,W-(1-p)\cdot 0-c>S \iff p>\frac{S+c}{W}\ (\text{有成本}).
$$
在**M1 锁存**下，失败不抹掉 $S$，继续弱占优（除非重启能换来更多 episode，即全局时间预算下要比较"继续"与"重开"的索引值）；在**M2 终态快照**下，阈值还要加上"已得分被撤回的概率"。**结论：v2 的"搏末步"只在 M1/M2 下成立，在 M3 下反而可能该放弃低概率末步。必须先用 RID 判定语义。**

### 3.4 直觉：塑形在单智能体里安全，在会看你的对手面前会失效
**命题（势函数塑形的边界）**：令 $\Phi(u)=\sum_{k\le u}w_k$，$F=\gamma\Phi(u')-\Phi(u)$。若环境转移核 $P(s'\mid s,a)$ **固定**，则势函数塑形不改变最优策略（标准结论）。但若对手 $D_\theta(u'\mid s,a)$ 是**对策略的最佳反应**，则转移核本身随 $\pi$ 变化，上述不变性论证失效：塑形可能奖励"让对手看不见进度"的行为，而不是"完成任务"。于是可能出现**进度隐藏（progress concealment）**：策略学会遮挡/放慢/绕路以降低被撤回概率，牺牲真实进度换取塑形收益。这正是本轮要专门用实验检验的刷分模式。

### 3.5 直觉：奖励没定，就别赌单一奖励
**定义（奖励歧义稳健目标）**：用 RID 探针得到语义后验 $b(\theta)$，求解
$$
\max_\pi\ \mathrm{CVaR}_\alpha\Big(\mathbb E_{\theta\sim b}[R_\theta(\pi)]\Big)\quad \text{s.t. } \mathbb E[\text{latency}]\le B,\ \mathbb E[\text{redo}]\le R_{\max}.
$$
这是**贝叶斯自适应 + CVaR 稳健**的组合：既不盲目赌 M1，也不做过度保守的 min-max。

## 4. 候选合并 → v3 清单（详见产物区）

围绕「奖励设计」发散 9 个草案、围绕「论文发表」发散 5 个，合并去重后得到：**新增 UIP-16~20**（RMR 奖励机回归、RID 奖励辨识、RARP 歧义稳健策略、ARS 反刷分塑形、PGP 论文级协议+DRB 基准），**升级** UIP-01″/02″/09″/11″/12″/13″，保留 05/08″/14/15。旗舰从 v2 的"扰动恢复闭环"前移为 **UIP-17 RID → UIP-16 RMR → UIP-19 ARS** 的"先认清奖励、再正确塑形、最后防刷分"链条；恢复执行仍是 UIP-09″，但它的价值现在**条件于 RID 的结论**。

## 5. 瓶颈假设（v3）

- **H1（最高杠杆）**：步骤分语义极可能不是 v2 默认的 M2。若为 M1，则"检测撤回-重做"的**分值收益**被高估，价值主要在"解锁后续步"；若为 M3，则"保分"整条线要重写。RID 是回报最高的第一件事。
- **H2**：干扰是**按进度触发**的，因此朴素势函数塑形会诱发"进度隐藏"式刷分；必须让塑形对手感知（adversary-aware）并加反循环约束。
- **H3**：GSO 代理与真奖励的差距在接触密集步（插网线/合盖/拉链）**异方差**更大，均匀加权会系统性高估这些步；应按校准方差加权。
- **H4**：恢复样本极度长尾，过程奖励模型/事件检测器会退化为"永远 ongoing"；需要事件中心损失、类别重加权与**校准弃权**。
- **H5（发表侧）**：可辩护的论文是"形式化 + DRB + 稳健方法"，不是"私有榜名次"；把榜单名次当主结果，会在审稿与复现两处同时失分。

## 6. 本轮最大风险

**一句话**：整套 v3 建立在"奖励语义可被黑箱探针在预算内辨识"这一前提上——若官方评测端长期不开放、或赛规禁止探针式提交，我们可能把两个月投在一个无法证伪的奖励假设上，因此必须先用离线仿真 + 公开文档把 M1/M2/M3 的政策差异算清楚，并把 RID 失败作为**显式退出条件**。

## 1. 新旗舰深潜：UIP-17 · RID（Reward Identification by Design）

- **直觉**：把官方评测端当成一个**黑箱奖励神谕**。我们无法读代码，但可以**设计动作序列**去刺激它，观察返回的成功率/步骤分，从而像做实验一样反解奖励语义。
- **探针族（probe family）**：对每个代表任务 $j$，构造策略 $\pi^{(j)}_{m}$：恰好完成前 $m$ 步后**冻结/超时**（$m=0..K_j$），以及 $\pi^{(j)}_{m,\text{reg}}$：完成前 $m$ 步后**主动制造可撤回状态**（若可）再冻结。每个探针跑 $n$ 个种子。
- **判别逻辑**：令观测到的步骤分为 $\hat s_{j,m}$。
  - M1 锁存预测 $\hat s_{j,m}\approx\sum_{k\le m}w_k$，且 $\hat s_{j,m,\text{reg}}\approx$ 同值（不扣分）；
  - M2 终态预测 $\hat s_{j,m,\text{reg}}$ 显著低于 $\hat s_{j,m}$（扣分）；
  - M3 门控预测所有未成功探针的步骤分为 0（或仅诊断通道可见）。
  用**成对对比** $\Delta_{\text{reg}}=\hat s_{m}-\hat s_{m,\text{reg}}$ 与 $\Delta_{\text{stop}}(m)$ 做模型选择（BIC/贝叶斯因子），并给出后验 $b(\theta)$ 供 UIP-18 使用。
- **与 v2 差异**：v2 直接假设"撤回扣分/重做有利"；v3 把该假设变成**第一个实验的输出**。这是一次"先测量、后设计"的范式切换。
- **可行性**：中（依赖官方 run 配额与赛规允许）。**离线先行**：用 GSO 与自建评测器预演整套辨识流程，确保真开放时一次跑对。
- **资源**：探针次数 $O(K\cdot n\cdot |\Theta|)$，优先选 $K$ 少且干扰类型已知的任务（如 T19 拉链、T16 折叠、T27 叠碗），降低预算。
- **风险**：探针被赛规视为滥用/刷分 ⇒ 预先申请或改用"正常策略的天然对照"；样本少导致后验不可辨 ⇒ 用信息增益选任务（主动实验设计）。

## 2. 核心形式化：UIP-16 · RMR（Reward-Machine Regression）

**定义**：$M=(\mathcal U,u_0,\Sigma,\delta,R)$，$\mathcal U=\{0..K\}$，符号 $\Sigma=\{e_k^+,e_k^-,e_{\text{to}}\}$，
$$
\delta(k,e^+_{k+1})=k+1,\quad \delta(k,e^-_k)=k-1,\quad \delta(k,e_{\text{to}})=k,
$$
$R(k,e^+_{k+1})=w_{k+1}$，$R(k,e^-_k)\in\{0,-w_k\}$（由 RID 决定）。观测只能看到 $o_t$，故需信念 $b_t(u)$；验证器输出事件的后验，而不是硬标签。

- **与 v2 差异**：v2 的 verifier 是四态硬分类；RMR 让"撤回"成为**机器转移**，天然支持"重做后再次被撤回"的多轮情形，并能与技能图（UIP-14）对齐。
- **落地**：① 用 UIP-12″ 的事件标签训练事件检测器；② 用前向/后向转移的一致性做自监督（若 $e^-_k$ 后 $p_{k-1}$ 为假而 $p_k$ 也为假，标签自洽）；③ 在 UIP-01″ 中用信念门限触发重做。
- **风险**：部分可观测导致状态混淆 ⇒ 保留"未观测/不确定"状态并允许**校准弃权**（UIP-15）。

## 3. 奖励塑形：UIP-19 · ARS（Anti-hacking Reward Shaping）

训练用复合奖励（**约束 MDP** 视角）：
$$
r^{\text{train}}_t=\underbrace{\Delta\Phi_t}_{\text{势函数稠密信号}}+\lambda_1\underbrace{\mathbb 1[\text{首次恢复且外部致因}]\,\min(1,\Delta\Phi/\Delta\Phi_{\text{ref}})}_{\text{恢复奖励，可证伪地只给一次}}
-\lambda_2\,\mathbb 1[\text{redo}>R_{\max}]-\lambda_3\,[\text{latency}-B]_+-\lambda_4\,\|\Delta a_t\|^2 .
$$
- **为什么这样设计**：$\Delta\Phi$ 是势函数差，**沿闭环求和为零**，天然禁止"来回刷"；恢复奖励是非势函数项，因此必须**只给首次**并用"外部致因检测器"门控，否则策略会自己制造撤回再恢复来刷奖励。延迟/重做进入**约束/罚项**，与可信度对齐。
- **要检验的刷分模式**：① 进度隐藏（见想法区 §3.4）；② 自造撤回刷恢复奖励；③ 反复重做刷"努力感"；④ 动作抖动导致统计异常。
- **与 v2 差异**：v2 只有"重做最多两次"这种工程护栏；ARS 给出**塑形不变性 + 反循环**的机制性约束，并把刷分模式写成可测假设。

## 4. 稳健决策：UIP-18 · RARP（Reward-Ambiguity Robust Policy）

- **目标**：$\max_\pi \mathrm{CVaR}_\alpha(\mathbb E_{\theta\sim b}[R_\theta(\pi)])$ s.t. $\mathbb E[\text{latency}]\le B,\ \mathbb E[\text{redo}]\le R_{\max}$。
- **直觉**：RID 给出的是**后验**而非确定答案；用 CVaR 惩罚最坏的分位结果，避免"赌 M1 结果真机是 M3"的灾难。
- **与 v2 差异**：v2 的 UIP-02′ 是单语义下的贪心停止；RARP 是**语义不确定下的稳健停止 + 约束优化**，并用 UIP-17 的后验做贝叶斯自适应。
- **可行性**：高（离线可用；推理期只是查表/阈值）。**风险**：过度保守损失均值 ⇒ 用后验熵自适应调节 $\alpha$（熵大→更稳健，熵小→更进取）。

## 5. 可发表基座：UIP-20 · PGP + DRB（Paper-Grade Protocol + Disturbance-Recovery Benchmark）

- **DRB（基准）**：在 Gazebo/离线环境发布 32 任务的**扰动注入协议**（时机、频率、类型均参数化）+ 三套奖励语义（M1/M2/M3）+ 事件级标签 + 官方风格评测脚本。它让"扰动恢复"从私有技巧变成**可复现基准**。
- **PGP（协议）**：预注册假设 → 固定种子集（≥5）→ 报告均值±95% CI → 配对检验（Wilcoxon/自助法）→ 消融全覆盖 → 负结果也报告 → 代码/配置/探针脚本开源。
- **与 v2 差异**：v2 的 E101–E108 是工程对比；v3 要求每个实验对应一条**可证伪主张**，并区分"离线 DRB 结果"与"官方榜单结果"两条证据链。
- **风险**：基准自建自评会被质疑"自导自演" ⇒ 引入≥2 个公开/第三方基线（如开环 BC、无恢复的 chunk 策略、标准 VLA 微调），并报告跨基线排名稳定性。

## 6. 关键算法伪代码

```python
# UIP-16 RMR + UIP-01″ + UIP-13″ + UIP-15
class RewardMachinePolicy:
    def __init__(self, policy, event_detector, rm, K_MAX=8,
                 conf_thr=0.6, max_redo=2, lat_budget_ms=200):
        self.policy, self.det, self.rm = policy, event_detector, rm
        self.K_MAX, self.conf_thr = K_MAX, conf_thr
        self.max_redo, self.lat_budget_ms = max_redo, lat_budget_ms

    def reset(self):
        self.policy.reset()
        self.b = self.rm.prior()          # belief over u_0..u_K
        self.redo, self.buf = 0, []

    def get_action(self, obs):
        # 1) 事件检测 -> 奖励机信念更新（前向 e+/后向 e-）
        ev, conf = self.det(obs)          # {e_k^+, e_k^-} 或 None
        if conf >= self.conf_thr:
            self.b = self.rm.update(self.b, ev)
            if ev.is_backward and self.redo < self.max_redo:
                self.redo += 1
                self.buf = []             # 清空旧块，重做当前子目标
            if ev.is_forward:
                self.redo = 0
        # 2) 当前子目标 = 信念众数
        u = self.b.argmax()
        # 3) 约束式块长（UIP-13″）：接触密集步用小 k
        k = self._pick_k(u, latency_budget=self.lat_budget_ms)
        # 4) 开环块执行，且每次调用至多返回 k 步
        if not self.buf:
            self.buf = list(self.policy.get_action(obs, k, subgoal=u))[:k]
        return self.buf.pop(0)
```

```python
# UIP-17 RID: 探针 -> 语义后验
def rid_probe(task, server, n_seeds=5):
    K, w = task.scoring_steps, task.weights
    obs = {}
    for m in range(K + 1):
        obs[(m, "stop")] = [server.run(stop_after(task, m)) for _ in range(n_seeds)]
        obs[(m, "reg")]  = [server.run(stop_after_regress(task, m)) for _ in range(n_seeds)]
    # 三个候选语义的预测
    pred = {
        "M1": lambda m, reg: sum(w[:m]),
        "M2": lambda m, reg: sum(w[:m]) - (w[m-1] if reg and m > 0 else 0),
        "M3": lambda m, reg: 0.0,          # 未成功 -> 0（或仅诊断通道）
    }
    ll = {name: log_likelihood(obs, f) for name, f in pred.items()}
    return softmax(ll)                     # 语义后验 b(theta)
```

```python
# UIP-19 ARS: 反刷分塑形
def train_reward(prev_u, u, event, first_restore, redo, latency, da):
    phi = lambda u: sum(W[:u])
    r = GAMMA * phi(u) - phi(prev_u)                 # 势函数差，闭环为 0
    r += L1 * first_restore * min(1, (phi(u) - phi(prev_u)) / dphi_ref)
    r -= L2 * max(0, redo - R_MAX)
    r -= L3 * max(0, latency - B)
    r -= L4 * (da ** 2).sum()
    return r
```

## 8. 论文蓝图（用「论文发表」倒逼严谨性）

- **暂定标题**：*When Progress Is Undone: Reward Machines and Robust Recovery for Adversarial Long-Horizon Manipulation*。
- **投稿定位**：CoRL / ICRA / RSS（benchmark & method track）；核心新颖性 = "奖励语义未定 + 对手按进度自适应"的交叉，而非泛泛鲁棒性。
- **四条主张**：
  - C1（形式化）：提出对抗性进度回归博弈与三套奖励语义，证明语义选择改变最优策略（E302）。
  - C2（辨识）：RID 用 $O(K)$ 探针恢复黑箱奖励语义，显著降低策略后悔（E301/E309）。
  - C3（方法）：RMR + ARS 抑制"进度隐藏"与恢复刷分，恢复成功率优于无塑形基线（E303/E304/E305）。
  - C4（基准）：发布 DRB 与事件级标签，跨基线可复现（E310–E312）。

## 9. 风险登记册（按杀伤力排序）

1. **奖励语义不可辨识**（官方不开放/探针被禁）→ 预设退出条件：只发表形式化 + DRB，不声称官方结论。
2. **代理奖励劫持**（GSO 刷分）→ 留出任务 + 真机锚点 + 校准误差入模。
3. **自适应对手导致塑形失效**（进度隐藏）→ ARS + E303 专项检验。
4. **恢复数据长尾导致检测器退化**→ 事件中心损失 + 弃权 + 校准。
5. **合规**：单模型、外部模型、探针用途 → 赛前书面确认。
6. **时间**：RID 依赖官方开放，先离线跑通全链路，避免空等。

## 11. 本轮最大风险 & 押注

**一句话**：整套 v3 的前提是"奖励语义能在预算内被辨识"；若这个前提不成立，所有恢复机制都只是在优化一个假想奖励，因此必须把 UIP-17 当作**门控实验**（go/no-go），而不是清单里普通的一项。
