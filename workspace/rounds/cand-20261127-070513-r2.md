### 第 2 轮灵感驱动研究记录

**灵感词**：抓取规划、运动学

**直觉与动机**：
前几轮把证书链从「感知-合规-能量」推到「结构-力学」，再推到「语义-重构-多机协同」，但机械臂真正与世界发生因果接触的最后一厘米——抓取——始终是开放的。抓取是整条证书链的「落地动作」：此前所有证书都在回答「能不能安全地靠近并握住」。抓取规划的本质不是采样一个末端位姿，而是生成一张**接触扳手可达性证书**：每个接触力必须落在摩擦锥内，合成扳手必须覆盖任务所需扳手集，且接触在扰动下具有正稳定裕度。运动学在此不是几何约束的背景噪声，而是证书的**前置条件生成器**：目标位姿是否存在 IK 解（可达性）、雅可比最小奇异值是否足够（可操作性）、关节/速度是否有裕度、相邻时刻是否停留在同一 IK 分支（连续性），共同决定一张抓取证书能否被物理执行。核心洞见：**抓取证书是「接触层扳手覆盖」与「运动学层可实现性」的合取；摩擦闭合但够不着的抓取、够得着但握不住的抓取，都应被准入门拒绝。**

**形式化目标**：
1. 定义抓取证书（GC）：接触集 C={(p_i,n_i,μ_i)}、抓取映射 G、摩擦锥 FC_i、广义力旋量空间 GWS=Σ_i G_i(FC_i)；证书要求任务扳手球 W_req 含 ε 裕度地被 GWS 覆盖，且 0∈int(GWS)（ε-力闭合）。
2. 定义运动学证书（KC）：存在 IK 见证 q* 使 FK(q*)=T* 且残差≤δ_ik；方向可操作性 σ_min(J_τ)≥σ_req；关节裕度 q∈[q_min+m, q_max-m]；分支连续性 ‖q(t+1)-q(t)‖≤δ_branch；静态扳手容量 W_arm={F: JᵀF+g(q)∈T_max}。
3. 定义抓取-运动学耦合证书（GKCC）：同一任务旋量方向上，接触可行域 GWS 与运动可行域 W_arm 同时含 W_req，即 min(h_GWS(u), h_Warm(u)) ≥ h_Wreq(u)+ε_gk。
4. 构建九证准入门（GKUC/TS-USC）：SRC-USC ∪ GC ∪ KC ∪ GKCC，Exec_v26 = Exec_v25 ∩ Fil_grasp ∩ Fil_kin ⊆ Exec_v25。
5. 证明九位一体单调退化链在接触滑移/运动学奇异/IK 分支跳变/可达性丢失下的保持性，并给出单边可靠的离散化下界修正。

# ============================================================
# IP-448 Grasp Certificate (GC) — 抓取证书
# ============================================================
@dataclass
class ContactSpec:
    p: Tensor            # 接触点 (3,)，世界/物体系一致
    n: Tensor            # 物体外法向 (3,)，指向物体内部
    mu: float            # 摩擦系数下界（不是名义值，需 robust 标定）
    t1: Optional[Tensor] = None
    t2: Optional[Tensor] = None

    def basis(self) -> Tensor:
        """返回 [6,3] 扳手基，列为 (n,t1,t2) 对应的 [f; p×f]"""
        n = self.n / torch.norm(self.n)
        if self.t1 is None:
            t1 = torch.linalg.cross(n, torch.tensor([0., 0., 1.]))
            if torch.norm(t1) < 1e-6:
                t1 = torch.linalg.cross(n, torch.tensor([0., 1., 0.]))
            t1 = t1 / torch.norm(t1)
        else:
            t1 = self.t1
        t2 = torch.linalg.cross(n, t1)
        F = torch.stack([n, t1, t2], dim=1)             # [3,3]
        B = torch.zeros(6, 3)
        B[:3, :] = F
        B[3:, :] = torch.linalg.cross(self.p.unsqueeze(0), F.T).T  # p×f
        return B


@dataclass
class GraspCertificate:
    """摩擦锥 + GWS 覆盖 + ε-力闭合证书"""
    contacts: list[ContactSpec]
    r_req: float = 1.0              # 任务扳手球半径（按法向力量纲归一）
    eps_w: float = 0.1             # 力闭合/覆盖裕度
    n_dirs: int = 512              # S^5 方向采样数
    covers_net: bool = True        # 是否做 Lipschitz 下界修正

    def _wrench_bases(self) -> Tensor:
        return torch.stack([c.basis() for c in self.contacts], dim=0)  # [k,6,3]

    def _support_one(self, u: Tensor, B_i: Tensor, mu: float) -> Tensor:
        """h_{B_i(FC_i)}(u) = max(0, a_n + mu*||a_t||)，a=B_i^T u"""
        a = torch.einsum('j,jk->k', u, B_i)
        return torch.clamp(a[0] + mu * torch.norm(a[1:]), min=0.0)

    def gws_support(self, u: Tensor) -> Tensor:
        """GWS = Σ_i B_i(FC_i) 的支撑函数（Minkowski 和可加）"""
        Bs = self._wrench_bases()
        return sum(self._support_one(u, Bs[i], self.contacts[i].mu)
                   for i in range(len(self.contacts)))

    def _directions(self) -> Tensor:
        g = torch.randn(self.n_dirs, 6)
        return g / torch.norm(g, dim=1, keepdim=True)

    def _lipschitz_radius(self) -> float:
        """L_GWS = Σ_i (1+μ_i)√(1+‖p_i‖²)"""
        return sum((1.0 + c.mu) * float(torch.sqrt(1.0 + torch.dot(c.p, c.p)))
                   for c in self.contacts)

    def _net_radius(self) -> float:
        # S^5 随机 ε-net 覆盖半径 ~ N^{-1/5}，乘 2 保守
        return 2.0 * self.n_dirs ** (-1.0 / 5.0)

    def certified_support_min(self) -> tuple[Tensor, Tensor]:
        """返回 (采样最小支撑, 修正后的可靠下界)"""
        us = self._directions()
        h = torch.stack([self.gws_support(u) for u in us])
        h_min = h.min()
        if not self.covers_net:
            return h_min, h_min
        corrected = h_min - self._lipschitz_radius() * self._net_radius()
        return h_min, corrected

    def verify_force_closure(self) -> bool:
        """0 ∈ int(GWS) ⟺ h_GWS(u) > 0 ∀u∈S^5"""
        _, lb = self.certified_support_min()
        return bool(lb > 0.0)

    def verify_wrench_coverage(self) -> bool:
        """W_req ⊕ B_{ε_w} ⊆ GWS ⟺ h_GWS(u) ≥ r_req+ε_w ∀u"""
        _, lb = self.certified_support_min()
        return bool(lb >= self.r_req + self.eps_w)

    def verify_all(self) -> bool:
        return (len(self.contacts) >= 2 and
                self.verify_force_closure() and
                self.verify_wrench_coverage())


# ============================================================
# IP-449 Kinematic Certificate (KC) — 运动学证书
# ============================================================
@dataclass
class KinematicCertificate:
    """可达见证 + 可操作性 + 关节裕度 + 分支连续性 + 扳手容量"""
    target_pose: 'SE3'
    fk_fn: Callable                     # q -> SE3
    jac_fn: Callable                    # q -> [6,n]
    q_min: Tensor
    q_max: Tensor
    q_witness: Optional[Tensor] = None  # 数值 IK 给出的存在见证
    q_prev: Optional[Tensor] = None     # 上一时刻关节（分支连续性）
    task_dirs: Optional[Tensor] = None  # [m,6] 任务方向投影
    tau_max: Optional[Tensor] = None    # [n]
    gravity_fn: Optional[Callable] = None
    delta_ik: float = 1e-4
    sigma_req: float = 0.05
    sigma_sing: float = 0.01
    joint_margin: float = 0.05          # rad
    delta_branch: float = 0.2           # rad

    def verify_reachability(self) -> bool:
        """见证式：找到 q* 即证明可达；找不到只说明需保守拒绝"""
        if self.q_witness is None:
            return False
        residual = self.target_pose.distance(self.fk_fn(self.q_witness))
        return residual <= self.delta_ik

    def verify_joint_margin(self) -> bool:
        if self.q_witness is None:
            return False
        q = self.q_witness
        return bool(torch.all(q >= self.q_min + self.joint_margin) and
                    torch.all(q <= self.q_max - self.joint_margin))

    def verify_directional_manipulability(self) -> bool:
        if self.q_witness is None:
            return False
        J = self.jac_fn(self.q_witness)
        J_eff = J if self.task_dirs is None else self.task_dirs @ J
        s = torch.linalg.svdvals(J_eff)
        return bool(s.min() >= self.sigma_req)

    def verify_singularity(self) -> bool:
        if self.q_witness is None:
            return False
        s = torch.linalg.svdvals(self.jac_fn(self.q_witness))
        return bool(s.min() >= self.sigma_sing)

    def verify_branch_continuity(self) -> bool:
        if self.q_prev is None:
            return True
        return bool(torch.norm(self.q_witness - self.q_prev) <= self.delta_branch)

    def arm_wrench_support(self, u: Tensor) -> float:
        """h_{W_arm}(u) = max uᵀF s.t. -τ_max ≤ JᵀF+g(q*) ≤ τ_max（LP）"""
        if self.tau_max is None or self.q_witness is None:
            return -float('inf')
        from scipy.optimize import linprog
        J = self.jac_fn(self.q_witness).detach()
        g = (self.gravity_fn(self.q_witness) if self.gravity_fn is not None
             else torch.zeros(J.shape[1])).detach()
        A = torch.cat([J.T, -J.T], dim=0).numpy()
        b = torch.cat([self.tau_max - g, self.tau_max + g], dim=0).numpy()
        res = linprog(c=-u.detach().numpy(), A_ub=A, b_ub=b,
                      bounds=[(None, None)] * J.shape[0], method='highs')
        return -float(res.fun) if res.success else -float('inf')

    def verify_all(self) -> bool:
        return (self.verify_reachability() and
                self.verify_joint_margin() and
                self.verify_directional_manipulability() and
                self.verify_singularity() and
                self.verify_branch_continuity())


# ============================================================
# IP-450 Grasp-Kinematic Unified Certificate (GKUC / TS-USC) — 九证门
# ============================================================
@dataclass
class GraspKinematicUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # 七证
    gc: GraspCertificate
    kc: KinematicCertificate
    eps_gk: float = 0.05

    def verify_coupling(self) -> bool:
        """min(h_GWS, h_Warm)(u) ≥ h_Wreq(u)+ε_gk ∀u（充分保守）"""
        us = self.gc._directions()
        r_need = self.gc.r_req + self.eps_gk
        # 复用 GC 的可靠离散下界，避免采样高估
        lb_gws = self.gc.certified_support_min()[1]
        if lb_gws < r_need:
            return False
        for u in us:
            h_arm = self.kc.arm_wrench_support(u)
            if not (h_arm >= r_need):
                return False
        return True

    def admits(self, multi_plan: 'MultiRobotPlan',
               sensor_data: dict,
               grasp_data: dict,
               kin_data: dict) -> bool:
        # 1. 七证 SRC-USC
        if not self.src_usc.admits(
            multi_plan, sensor_data,
            gt_entities=sensor_data.get('gt_entities'),
            queries=sensor_data.get('queries'),
            retrieved=sensor_data.get('retrieved')):
            return False
        # 2. 抓取证书（每台执行抓取的机器人）
        self.gc.contacts = grasp_data['contacts']
        if not self.gc.verify_all():
            return False
        # 3. 运动学证书
        self.kc.q_witness = kin_data['q_witness']
        self.kc.q_prev = kin_data.get('q_prev')
        if not self.kc.verify_all():
            return False
        # 4. 抓取-运动学耦合
        if not self.verify_coupling():
            return False
        return True

            self.ts_usc.gc.contacts = cand.contacts

                valid.append(cand)

            return False, {'stage': 'GC', 'reason': 'no_force_closure_grasp'}

        return True, {

            'q': q_best,
            'gws_margin': float(self.ts_usc.gc.certified_support_min()[1]

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| GC 单方向支撑函数 | O(k) | O(k) | k≤8 接触点 |
| GC GWS 覆盖/力闭合 | O(N_dir·k) | O(N_dir) | N_dir=512, k≤8 |
| GC 方向 ε-net 修正 | O(k) | O(1) | L_GWS 解析可算 |
| KC 数值 IK 见证 | O(I_ik·n·n_iter) | O(n) | I_ik≤16 起点, n≤7 |
| KC 可操作性/奇异 | O(n³) SVD | O(6n) | n≤7 |
| KC 扳手容量支撑 | O(N_dir·LP(n)) | O(n) | 每方向一个 2n 约束 LP |
| GKCC 耦合验证 | O(N_dir·(k+LP(n))) | O(N_dir) | 与 GC/KC 共享方向集 |
| 九证门准入 | 七证 + O(N_dir·(k+LP)) | 七证 + O(N_dir) | 抓取候选数 M≤64 |
| 端到端单步（增量） | +O(M·N_dir·(k+LP(n))) | +O(M·N_dir) | M=32,N_dir=256→约 +8ms |

**实时性保证**：抓取规划属任务级（0.5–2Hz）而非控制环；GC 与 KC 可在候选采样阶段并行，九证门只在候选集合上做一次。运动学证书的 IK 见证用热启动（q_prev）+ 多起点，最坏情况可降级为「仅验证当前抓取」的 O(N_dir·k)+O(n³)。控制频率仍由七证 SRC-USC 保证，抓取层不进入 50Hz 内环。

## 3. 正确性论证（增量）

### 引理 13（抓取证书的覆盖-闭合二重保证，含离散化单边可靠性）
**陈述**：设 `GC.verify_all()=True`，则存在 ε'_w ≥ 0，使对一切单位方向 u∈S⁵ 有 h_GWS(u) ≥ r_req+ε'_w，且 0∈int(GWS)。反之若真实支撑最小值 < r_req+ε_w−L_GWS·δ_net，则证书必为 False。

**证明**：
1. GWS=Σ_i B_i(FC_i) 为紧集的 Minkowski 和，支撑函数可加：h_GWS(u)=Σ_i h_{B_i(FC_i)}(u)（Rockafellar 共轭理论）。
2. 单接触有界摩擦锥的支撑函数有闭式：记 a=B_iᵀu=(a_n,a_t)，则 h_i(u)=max_{f_n∈[0,1],‖f_t‖≤μf_n} a_n f_n+a_t·f_t=max(0,a_n+μ‖a_t‖)。实现中的 `_support_one` 即此式，故单点支撑精确。
3. 方向离散给出采样最小值 ĥ；由于 h_GWS 关于 u 是 L_GWS-Lipschitz（L_GWS=Σ_i ‖B_i‖·max‖f‖ ≤ Σ_i(1+μ_i)√(1+‖p_i‖²)），对任意 u 存在采样点 u_j 使 |h(u)−h(u_j)|≤L_GWS·δ_net。故 ĥ−L_GWS·δ_net 是真实最小值的**可靠下界**，不会把不安全抓取误判为安全（单边可靠）。
4. 0∈int(GWS) ⟺ h_GWS(u)>0 ∀u≠0（凸紧集原点内点的支撑函数判据），由下界 >0 推出。
5. 第 3 步的保守性意味着：真实覆盖存在但采样未捕获时会被拒证，属安全侧误拒，不破坏执行集包含关系。∎

### 引理 14（运动学证书的可达-可操作-连续-容量四重保证）
**陈述**：`KC.verify_all()=True` ⇒ 存在关节配置 q*，使 (1) FK(q*)=T*（残差≤δ_ik），(2) 任务方向 σ_min(J_τ(q*))≥σ_req，(3) q* 含关节裕度且在非奇异区，(4) 与上一时刻同一 IK 分支 ‖q*−q_prev‖≤δ_branch，(5) 静态扳手容量 W_arm(q*) 非空。反之 `verify_all()=False` **不证明**不可达，只表明「未找到满足全部条件的见证」。

**证明**：
1. 可达性是存在性命题，数值 IK 返回的 q* 是构造性见证：直接把 q* 代入 FK 校验残差，故 True 可靠（sound）。
2. 可操作性与奇异阈值为 q* 处 Jacobian 的局部性质，SVD 给出 σ_min 的精确值，验证即证明。
3. 关节裕度是盒约束的直接检查；分支连续性以 q_prev 热启动并限制步长，排除 IK 分支跳变导致的轨迹不连续。
4. W_arm 由静态平衡 τ=JᵀF+g(q) 与 |τ_j|≤τ_max 定义，是 ℝ⁶ 中多面体；support LP 可行即非空。
5. 单向性来自 IK 的非凸与非完备：找不到见证只能保守拒绝（安全侧），因此 KC 过滤器不满足「完备」但满足「可靠」，这与证书链的一贯安全语义一致。∎

### 引理 15（抓取-运动学耦合的充分性）
**陈述**：若对一切 u∈S⁵ 有 min(h_GWS(u), h_Warm(u)) ≥ r_req+ε_gk，则对任意 w∈W_req，存在接触力 λ∈FC_1×…×FC_k 与关节力矩 τ∈T_max，使 Gλ=w 且 τ=Jᵀw+g(q*)（忽略手-物坐标系刚性变换误差），并保留 ε_gk 的联合裕度。

**证明**：
1. W_req⊆GWS 保证存在 λ 实现任意 w∈W_req（GWS 定义即 G 作用于摩擦锥盒的像）。
2. W_req⊆W_arm 保证存在 τ∈T_max 静态平衡该 w（W_arm 定义）。
3. 交集条件用 min(h_A,h_B) 是 h_{A∩B} 的**上界**（h_{A∩B}(u)≤min(h_A,h_B)），故 min≥r_req+ε_gk 是 W_req⊕B_{ε_gk}⊆A∩B 的充分（偏保守）条件。
4. GWS 与 W_arm 分属「物体接触扳手」与「末端扳手」；在刚性抓取且手-物变换已知时二者同构，坐标一致性由 ζ_gkuc 中统一的世界系保证。∎

### 引理 16（九位一体单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加四条退化路径：
- 接触滑移/摩擦锥失配/覆盖不足 → `GC.verify_all=false` → 九证门拒证 → 退回 `Exec_v25`：放弃当前抓取，降级为推拨/吸附等非抓取操作，或重新采样抓取。
- 运动学奇异/关节裕度不足/IK 无见证 → `KC.verify_all=false` → 九证门拒证 → 退回 `Exec_v25`：重新选基座位姿或改换 IK 分支，仍不可行则仅执行无需该末端位姿的七证计划。
- IK 分支跳变 → `verify_branch_continuity=false` → 拒证 → 保持上一构型或沿零空间平滑过渡，禁止跨分支突跳。
- 耦合容量不足（够得着但推不动）→ `verify_coupling=false` → 拒证 → 降低要求扳手（轻拿轻放）或双臂/换手，仍不足则退回 `Exec_v25`。
- 组合失效取交集，单调性保持（每层过滤器只会缩小集合）。∎

### 定理（GKUC 九证准入门的安全-合规-可部署-可保护-结构-语义-重构-协同-抓取-运动学完备性）
**陈述**：对任意多机计划 Π={π_1..π_N} 与抓取-运动学参数 (C,q*)，`GKUC.admits(Π)=True` ⟺ Π 同时满足第 1 轮定理的 (1)–(10)，外加：
(11) 接触层：C 满足 ε-力闭合且 GWS 覆盖 W_req；
(12) 运动学层：存在 IK 见证 q*、方向可操作性/关节裕度/分支连续性/奇异回避达标，且 W_arm 与 GWS 在任务方向上共同覆盖 W_req。

**证明**：`admits` 是 SRC-USC 十条件与 GC/KC/GKCC 三条件的合取。必要性：任一条件缺失即拒证，对应抓取滑移或运动学不可执行风险未被缓解。充分性：由引理 13–15，三条件全满足即可构造出「握得住且够得着、推得动」的可执行动作；由引理 16，九证链在任一层失效时仍单调回退到前一层，构成从群体语义到单机接触的完整闭环。∎
