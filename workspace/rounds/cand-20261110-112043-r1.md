# 第 43 轮（新循环第 3 轮） · 体验证书 × 认证避障：把「好用」写进安全证书（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮把证书做成「可进化的资产」，但其自陈风险是仿真偏差与检索幻觉造成的**静默失效**；更早第 41 轮的痛点是**可用性崩塌**。两者都指向同一个被忽略的维度：证书只回答了「安不安全」，没回答「好不好用」。本轮灵感词「用户体验」「避障控制」正好补上这一维。避障是安全与体验冲突最尖锐的场景：最保守的 CBF 会急刹、犹豫、画大圈、在障碍边界来回抖；最顺滑的轨迹又可能贴着障碍擦过。核心主张：**把舒适、可预测、可解释、不冻结变成可验证的证书维度，让避障控制在同一套证书栈里同时满足安全与体验**；并复用 IP-53/56 的区间/INT8 基础设施，使「体验」不是事后打分，而是运行时可检查、可编译、可审计的硬约束。

## 0. 直觉与动机

**灵感 1（用户体验 = 证书的第四维，而非锦上添花）**：v19 的证书向量是（soundness, 可用性/Nominal, 成本）。体验不是再加一个主观评分，而是发现很多「体验病」本质是**证书病**：CBF 在障碍边界反复激活/退出是「守卫抖动」；机器人停在原地不动是「活性/liveness 失败」；最后一刻急刹是「证书时域太短」；突然从 Nominal 掉到 SafeStop 的顿挫是「降级不连续」。因此体验可以被形式化为对轨迹与控制器的一族约束：jerk/加速度有界、TTC 有下界、意图可推断、模式切换连续、前进不停滞。把「舒适包络」和「安全障碍」并列，才是完整的证书。

**灵感 2（避障控制 = 安全与体验的应力测试场）**：传统 CBF-QP 是「最小干预」的，天然晚、硬、抖：只在即将越界时才动，动起来又可能来回切。人要的不是「最后一毫米安全」，而是「早早、平滑、有意图地让开」。动态障碍把矛盾放大：预测误差要求更大安全裕度，而大裕度又意味着更早、更大的绕行。我们的直觉是把避障控制从「单层安全 QP」升级为「**三层联合 QP**」：安全层（高阶/指数 CBF，相对度 3，控制输入取 jerk）+ 舒适层（|a|、|jerk|、|a_lat| 包络）+ 活性层（progress barrier 防冻结）。三层同时可行时，机器人既安全又顺滑；不可行时，进入「舒适降级格」，而不是直接硬停。

**灵感 3（体验证书可编译进现有边缘运行时）**：第 42 轮的 IP-53 CMC 已能把证书编译成区间电路、再蒸馏成 INT8；IP-56 ECR 已能在 5–100μs 内查表/推理。体验约束（jerk 上界、TTC 下界、legibility flag）与安全边际同构，完全可以走同一条编译链：**体验证书编译器 XCC** 把舒适包络编译成与安全监控器并联的区间/INT8 电路，L0 表的值结构从 (j*, m_lo, T_hold, θ) 扩展为 (j*, m_lo, u_slack, comfort_tier, legibility)。这样「体验」只增加增量成本，不引入第二套栈。

**灵感 4（体验遥测反哺飞轮，但必须防 Goodhart）**：在线采集 jerk RMS、a_lat p95、TTC_p05、stop-go 次数、路径偏移、意图推断时延、接管/纠正事件，形成**体验账本 UXL**。稀疏人类反馈只用来**校准**代理指标的权重与阈值，而不是直接当优化目标——否则会出现「为了分数好看而牺牲安全」的奖励黑客。体验分布漂移（用户群体、场景、负载变化）与安全漂移一样触发 SCV 重跑与 CKB 更新。

**耦合**：安全证书定义「不许碰」，体验证书定义「怎么不碰还让人舒服」，避障控制器是二者的联合执行体；SCV 在仿真里用「舒适违规 + 冻结 + 人类评分代理」做压力测试；CKB 存「避障风格模板」与体验画像；ECR 同时检查安全边际与体验 slack。v19 的 Sim→RAG→Edge→Sim 飞轮升级为 **Sim→RAG→Edge→Human→Sim** 的体验闭环。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（体验特征与体验包络）**：对轨迹 ξ 定义体验特征
ψ_ux(ξ) = (j_rms, a_lon^max, a_lat^max, TTC_p05, N_stopgo, Δ_path, τ_infer, s_surprise) ∈ R^8。
体验包络 U = {ψ : j_rms ≤ j̄, a_lon^max ≤ ā_lon, a_lat^max ≤ ā_lat, TTC_p05 ≥ ttc_min, N_stopgo ≤ n̄, Δ_path ≤ δ̄, τ_infer ≤ τ̄, s_surprise ≤ s̄}。**体验合格率** UXRate = P_{ξ∼D}(ψ_ux(ξ) ∈ U)。注意 U 的每个分量都是**单边**的（多为上界，TTC 为下界），因此可以像安全边际一样做保守放大。

**定义 39（体验证书 E-Cert）**：E-Cert = (C_safe, U, π_fb) 三元组，满足
(1) C_safe 是第 42 轮意义下 sound 的安全证书；
(2) 控制器 π 在 C_safe 约束下产生的轨迹以概率 ≥ 1−δ_ux 落入 U：P_{ξ∼D_π}[ξ ⊨ C_safe ∧ ψ_ux(ξ) ∈ U] ≥ 1−δ_ux；
(3) π_fb 是**舒适降级**策略，其降级路径的舒适度单调不增，且任意相邻档位切换的 jerk 冲击 ≤ j_switch。
E-Cert 有效 ⟺ (1)(2)(3) 同时成立。与 v19 的 C_sim 不同，E-Cert 显式包含「人怎么感受」的可检验代理。

**定义 40（舒适类高阶 CBF 与联合可行集 CCBF）**：取增广状态 x̃ = (p, v, a)，控制 u = ȧ（jerk）。安全障碍 h_0(x) = d(x, O) − d_min。定义指数 CBF（相对度 3）：
Φ_0 = h_0, Φ_1 = Φ̇_0 + α_1 Φ_0, Φ_2 = Φ̇_1 + α_2 Φ_1, Φ_3 = Φ̇_2 + α_3 Φ_2 ≥ 0。
舒适障碍向量 b_c(x̃) = (ā_lon − |a_lon|, ā_lat − |a_lat|, j̄ − |u|, ttc_min − TTC(x̃))，逐分量做 CBF：ḃ_c,i + γ_i b_c,i ≥ 0。活性障碍 h_prog = 沿目标方向的剩余进度 − ε_prog ≥ 0，满足 ḣ_prog + β h_prog ≥ 0。**联合可行控制集**
K_ccbf(x̃) = {u : Φ_3(x̃,u) ≥ 0, ḃ_c + γ⊙b_c ≥ 0, ḣ_prog + β h_prog ≥ 0}。
**命题 1**：若 K_ccbf(x̃) ≠ ∅，则闭环同时满足安全、舒适与活性（不冻结）。**命题 2**：K_ccbf 非空性对动态障碍预测误差 ε_pred 单调——ε_pred 越大，安全裕度必须越大，舒适可行域越小，故存在「安全-舒适不可兼得」的临界 ε_pred*。

**定义 41（舒适降级格与切换代价）**：降级级别 ℓ ∈ {L0 Nominal, L1 减速避让, L2 保守绕行, L3 舒适停车, L4 紧急 SafeStop}。每级有舒适剖面（速度/加速度/jerk 上限）与安全裕度；转移受 jerk 预算约束：切换瞬间 |jerk| ≤ j_switch，且降级单调（除非连续 τ_recover 时间无违规才允许回升）。**舒适停车**定义为最小 jerk 制动剖面（jerk 有界、停车点距障碍 ≥ d_min、纵向减速度 ≤ ā_brake），替代 v19 的硬 SafeStop。降级代价 J_deg = Σ_t |jerk_t|·1[切换] + λ_s·surprise(mode_t)。**命题 3**：若每个档位的安全集非空且相邻档位的安全集嵌套，则沿任意降级路径安全不变式保持；舒适性由 j_switch 与最小 jerk 剖面保证。

**定义 42（可读性与可预测性约束）**：给定观测前缀 ξ_{0:t}，人类对目标/意图的后验为 P(g | ξ_{0:t})。**可读性时延** τ_infer = min{t : max_g P(g|ξ_{0:t}) ≥ p_conf}；**可读性** L(π) = E[−log P(g*|ξ_{0:τ_infer})]（越小越易读）。**可预测性**用轨迹熵 H(ξ_{t:T}|ξ_{0:t}) 或与「社会规范名义轨迹」的 KL 散度 D_KL(π_actual ‖ π_norm) 度量。约束：τ_infer ≤ τ̄ 且 D_KL ≤ ε_leg。直觉：可读性要求「早点给出让行/绕行信号」（可能偏离最短路径），可预测性要求「别做人类预期外的动作」；两者与最小干预 CBF 存在张力，需要联合优化而非硬叠加。

**定义 43（体验-安全联合 Pareto 证书与体验漂移）**：证书向量 z = (m_safe, u_slack, UXRate, availability, COT)，其中 u_slack = min_i(U_i − ψ_i) 为体验包络的最小裕度。**Pareto 证书** = 在 (m_safe, UXRate, COT) 上不被支配的 (C_safe, U, π) 集合。**体验漂移** S_t^ux = W_1(Ê_t^ux, D_ux^sim)，其中 D_ux^sim 为仿真/历史体验特征分布；若 S_t^ux > τ_ux 或人类接管率突增，触发飞轮。**信任校准缺口** G_trust = E[接管延迟 | 潜在风险] − E[接管延迟 | 显式降级]；G_trust 过大意味着「过度信任」，是比显式不安全更隐蔽的风险。

## 2. 产出设计（新增 IP-57/58/59 + 升级 IP-51/52/53/54/55/56/49/50/45/47）

### 2.1 IP-57 UX-CERT-AVOID（UCA，体验认证避障控制器）
1. **三层联合 QP**：安全层（指数 CBF，相对度 3，jerk 为控制）、舒适层（a/jerk/a_lat/TTC 包络）、活性层（progress barrier）；用 slack 变量 + 可行性恢复（先放松舒适、再放松活性、最后降级）避免 QP infeasible 直接硬停。
2. **动态障碍**：预测轨迹 + 有界误差管（tube），用鲁棒 CBF 保证对 ε_pred 的 sound；TTC 下界作为舒适约束；RSS 式责任划分用于多智能体让行。
3. **抖动抑制**：CBF 激活/退出加滞回与 smooth-min 混合；把激活次数计入体验证书（N_switch）。
4. **可读性整形**：在安全裕度允许时，选择「早让/早绕」的横向偏移，最小化 τ_infer；左右让行偏好由社会规范与场景决定。
5. **舒适降级**：定义 41 的档位格；L3 用最小 jerk 制动，禁止 L0→L4 直接跳变；每档都有独立的安全不变式。

### 2.2 IP-58 UX-LEDGER（UXL，体验账本与遥测）
1. **在线特征提取**：jerk（差分+低通）、a_lat、TTC_p05、stop-go、路径偏移、意图推断时延代理、surprise（预测误差）。
2. **稀疏人类校准**：成对偏好/评分 → 学习代理指标权重（保持单边保守），并做跨用户方差估计；禁止直接把人类评分当 RL 奖励，避免 Goodhart。
3. **体验报告**：每 episode 生成 (ψ_ux, 违规分量, 降级轨迹)，入 CKB；作为偏移监控新维度。
4. **信任校准监控**：接管率、接管延迟、近失事件、降级时是否接管；输出 G_trust 告警。

### 2.3 IP-59 XCC（体验证书编译器）
1. **编译**：把 U 的每个单边约束编译成与 IP-53 CMC 同构的区间电路，再经 QAT 蒸馏为 INT8；与安全监控器并联成「联合监控器」。
2. **L0 表扩展**：值结构增加 (u_slack[8], comfort_tier, legibility_flag, N_switch)；查表同时得安全边际与体验 slack。
3. **证明义务**：区间算术给出 (m_lo, u_slack_lo) 的联合下界；体验约束同样单边保守，保证「不虚报舒适」。
4. **SCV 集成**：压力测试增加舒适违规率、冻结率、τ_infer、人类评分代理；反例按「安全/舒适/活性」三类归因入 CKB。

## 3. 四层架构 v8

```
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + jerk/加速度估计 → 体验特征原始量
L2: CTC + VLM + 动态障碍预测(误差管) + IP-35 仲裁 → R_φ + 意图/目标后验 P(g|ξ)
L3: IP-57 UCA 三层联合 QP(安全 CBF + 舒适包络 + progress) → 舒适降级格(定义 41)
    ← IP-56 ECR(L0 联合查表 + L1 联合 INT8 监控) + IP-59 XCC(体验证书编译)
    → IP-47 组合(UX 冲突消解) → IP-39 规划(CBF margin=m_lo, u_slack) → IP-45(UX 遥测)
L4: IP-55 CKB(体验画像/风格模板) ← IP-54 SCV(UX 压力测试 + 人类评分代理 + 冻结/抖动注入)
    → IP-58 UXL(体验账本 + 信任校准) → IP-50 课程 → RCA 重颁 E-Cert → 热更新
运行期: L0 联合查表(安全+体验) + L1 联合监控 + 体验漂移/信任缺口 → 飞轮
```

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 安全-舒适 Pareto | jerk RMS、a_lat p95、安全违例率 | jerk RMS < 1.0 m/s³；a_lat p95 < 2.5 m/s²；安全违例 0 |
| E88 可读性/可预测性 | τ_infer、意图识别准确率、主观评分 | τ_infer ≤ 0.8s；准确率 ≥ 85%；评分 ≥ 4/5 |
| E89 动态避障 | 成功率、最小 TTC、冻结率 | ≥ 99%；≥ 0.5s；< 1% |
| E90 舒适降级 | 切换 jerk、停车距离误差、顿挫投诉 | ≤ 2 m/s³；≤ 10%；0 |
| E91 E-Cert soundness | 体验包络违规率、联合监控漏报 | ≤ 1%（δ_ux）；0 |
| E92 代理指标有效性 | 与人类评分 Spearman ρ、跨用户方差 | ρ ≥ 0.7；方差可控 |
| E93 体验飞轮 | 连续 3 轮后 UXRate/Nominal/舒适违规 | UXRate +10pp；Nominal ≥ 80%；违规下降 |
| E94 长时程信任校准 | 100h 近失、过度信任事件、接管延迟 | 0 起；0 起；处于合理区间 |

回退：E87 安全-舒适不可兼得 → 放宽 U 或回退纯安全证书；E88 可读性与安全冲突 → 关闭 legibility 整形，保安全优先；E89 冻结 → 引入主动绕行/远程协助；E90 降级顿挫 → 加档位滞回或只保 L3 舒适停车；E91 体验违规 → 收紧 U 或回退 v19；E92 代理无效 → 弃用代理，改用直接人类评分 + 更保守包络。

## 5. 本轮最大风险

**一句话**：体验证书的最大风险是**代理指标错位叠加过度信任**——一旦 jerk/TTC 等可测代理与真实人类感受脱节，系统会为「漂亮数字」侵蚀安全裕度，并让用户在本该警惕时放松，这比显式的不安全更隐蔽、更危险；因此 E87（安全-舒适红线）与 E92（代理有效性审计）必须作为熔断实验。

### IP-57 UCA：三层联合避障控制

```
def uca_control(x_aug, goal, obstacles, pred_tube, cert):
    # x_aug = (p, v, a); 控制 u = jerk
    # 1) 安全层：相对度 3 指数 CBF，动态障碍用预测误差管膨胀
    obs_inflated = inflate(obstacles, pred_tube.radius + cert.m_safe_margin)
    phi3 = exp_cbf_3rd_order(x_aug, obs_inflated, alphas=cert.alpha)
    # 2) 舒适层：a/jerk/a_lat/TTC 单边包络
    b_c = comfort_barrier(x_aug, obstacles, pred_tube, cert.ux_envelope)
    # 3) 活性层：progress barrier 防冻结
    h_prog = progress_barrier(x_aug, goal, cert.eps_prog)
    # 4) 可读性整形：偏好早让/早绕（安全裕度允许时才生效）
    J = legibility_cost(x_aug, goal, cert.legibility) + jerk_cost(u)
    hard = [phi3 >= 0]
    soft = [bdot(b_c, u) + gamma * b_c >= 0,
            hdot(h_prog, u) + beta * h_prog >= 0]
    u_star, slack = solve_qp_with_recovery(J, hard, soft)
    if u_star is None:
        return comfort_degrade(x_aug, cert.degradation_lattice)
    return u_star, slack

def solve_qp_with_recovery(J, hard, soft):
    # 先解全约束；不可行则依次放松：舒适 slack → 活性 slack → 降级
    u, s = solve_qp(J + mu * sum(slack), hard + soft)
    if u is not None:
        return u, s
    u, _ = solve_qp(J, hard + soft[:1])        # 只放松活性
    if u is not None:
        return u, infeasible_marker('liveness')
    u, _ = solve_qp(J, hard)                   # 只保安全
    if u is not None:
        return u, infeasible_marker('comfort')
    return None, infeasible_marker('safety')

def comfort_degrade(x_aug, lattice):
    # 定义 41：单调降级，切换 jerk <= j_switch；L3 为最小 jerk 制动
    lvl = lattice.current
    while not lattice.feasible(lvl, x_aug):
        lvl = lattice.next_down(lvl)
    if lvl == 'L3':
        return min_jerk_brake(x_aug, a_brake_max, j_switch)
    return lattice.policy[lvl](x_aug)

def dynamic_obstacle_cbf(x_aug, obs_pred, tube, alpha):
    # 鲁棒 CBF：对预测误差管内的最坏位置求 h_0，保证 sound
    h = min(distance(x_aug.p, o + e)
            for o in obs_pred for e in tube.extreme_points())
    return h - tube.radius - d_min
```

### IP-58 UXL：体验账本与信任校准

```
def ux_features(traj, goal_posterior):
    jerk = lowpass(derivative(traj.a, traj.dt), fc=5.0)
    return {
        'j_rms': rms(jerk),
        'a_lon_max': max(abs(traj.a_lon)),
        'a_lat_max': max(abs(traj.a_lat)),
        'ttc_p05': quantile(ttc(traj, traj.obstacles), 0.05),
        'n_stopgo': count_stopgo(traj.v),
        'delta_path': deviation(traj.p, traj.p_nominal),
        'tau_infer': infer_time(goal_posterior, p_conf=0.9),
        's_surprise': mean(prediction_error(traj))
    }

def calibrate_proxy(human_pairs, features, prior_weights):
    # 人类反馈只用于校准权重/阈值，保持单边保守；禁止直接当 RL 奖励
    w = fit_ranking(features, human_pairs, monotone=True)
    rho = spearman(score(features, w), human_ratings)
    # 跨用户方差过大则退回先验权重，避免个性化碎片化
    if cross_user_var(features, w) > var_max:
        w = prior_weights
    return w, rho

def trust_gap(episodes):
    lat_risk = mean([e.takeover_delay for e in episodes if e.latent_risk])
    lat_expl = mean([e.takeover_delay for e in episodes if e.explicit_degrade])
    return lat_risk - lat_expl   # > 0 且大 => 过度信任告警

def ux_drift(window_trajs, D_ux_sim_hist):
    feat = [ux_features(t, None) for t in window_trajs]
    return wasserstein_1d_approx(feat, D_ux_sim_hist)
```

| 实验 | 指标 | 门槛 |

## 6. 本轮最大风险

**一句话**：体验证书的最大风险是**代理指标错位叠加过度信任**——一旦 jerk/TTC 等可测代理与真实人类感受脱节，系统会为「漂亮数字」侵蚀安全裕度，并让用户在本该警惕时放松，这比显式的不安全更隐蔽、更危险；因此 E87（安全-舒适红线）与 E92（代理有效性审计）必须作为熔断实验。
