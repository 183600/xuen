# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「人机交互」×「双足机器人」）

> 第 54 轮把技能组合从“能力匹配”推进到“动作-鲁棒性双证书”（`α_S`、`G_S`、`γ_ce`、`J`）。但那套体系仍隐含两个假设：机器人是**静态接触/准静态**的，且**没有人类在闭环内**。本轮引入双足与人机交互，核心矛盾是：
> **H22（接触相位假兼容）**：双足技能的动作空间是混合的（连续关节动作 × 离散接触模式 × 周期步态相位），第 54 轮的静态 `α_S` 会把“关节重叠高、但接触相位冲突”的两个技能判为兼容，执行时表现为垫步、绊脚或失稳。
> **H23（交互-平衡预算竞争）**：人机交互不是外挂的一层，而是与平衡控制争夺同一动作/时间预算的第二通道；为可读性、解释、让行而夸张的动作会直接吃掉稳定裕度。
> **H24（内生的非平稳人类）**：人类是闭环中的扰动源，且其行为会被机器人的解释与权威分配内生改变（解释→信任→更冒险的输入）；在“合作人”假设下校准的证书，会在过度信任/恐慌下失效。
> **H25（跌倒可达集盲区）**：双足会“倒”。第 54 轮证书只回答“能不能做到”，不回答“倒向哪里”；而人类安全取决于跌倒可达集与人类占位的交集，而非仅取决于任务成功率。

## 0. 直觉与动机

**灵感 1（把动作空间升级为“接触-相位”混合空间）**
直觉：双足技能不是一组关节轨迹，而是一台**混合自动机**：连续关节/质心动作 `a`，离散支撑模式 `c`（左支撑/右支撑/双支撑/腾空），以及循环相位 `φ ∈ S¹`。同一段关节动作在“左支撑”与“双支撑”下含义完全不同。因此技能剖面应从 `α_S(a)` 升级为 `α_S(a,c,φ)`，并附带**接触时序** `σ_S : φ ↦ c`。两个技能能否组合，首先取决于接触时序能否经过一个合法过渡（双足通常必须经过双支撑），且过渡期间捕获点/发散分量（DCM）仍在支撑多边形内。这样，“关节轨迹相似”不再等于“可以接上”。

**灵感 2（可读性不是装饰，而是有代价的动作）**
直觉：HCI 常要求机器人“可读、可预测、会解释”。但可读性需要夸张轨迹、减速、停顿、转头、手势、语音——这些都是**真实动作**，与行走/平衡共享关节、力矩与时间预算。于是“可读性—平衡”不是两个独立指标，而是一条 Pareto 前沿：提高人类理解度往往降低平衡裕度。必须把交互动作纳入同一个动作约束，而不是当作规划后的后处理。

**灵感 3（人类安全 = 跌倒可达集，而非成功率）**
直觉：一个成功率 99% 的双足机器人，仍可能在 1% 的失败里**倒向人类**。对人类而言，灾难来自“倒在哪”，而不是“任务有没有完成”。因此要为每个技能/组合维护一个**跌倒包络** `F_S`（在给定失效模式与有界关节力矩下，可能落地的区域分布），并把“`F_S` 与人类占位在未来 `T_fall` 内相交的概率”作为硬约束。双足特有的抓手是：跌倒方向大致由 DCM 离开支撑多边形的方向决定，因此 `F_S` 是**方向性锥**而非各向同性圆。

**灵感 4（共享权威 = 带人类扰动的鲁棒控制屏障）**
直觉：人机交互中的“谁说了算”不能靠拍脑袋的权重。把人类输入 `u_h` 视为有界但最坏情况未知的扰动，机器人权威 `λ ∈ [0,1]`，混合控制 `u = λu_r + (1-λ)u_h`。用控制屏障函数 `h` 同时编码“平衡裕度”和“与人类的安全距离”。若存在 `λ` 与 `u_r` 使鲁棒 CBF 在最坏 `u_h` 下成立，则共享控制安全；若可容许权威集 `Λ(x) = ∅`，则必须触发**保护性回退**（受控下蹲/扶撑/急停），而不是继续硬撑。这把“该不该接管”“该不该求助”变成可判定的可行性问题。

**灵感 5（双向意图对齐：机器人懂人，也要让人懂机器人）**
直觉：HCI 的意图问题是对称的。机器人要对人类意图有后验 `b_r`，人类也要对机器人目标有后验 `b_h`。前者靠交互历史，后者靠**可读性**。只优化一边，会造成“机器人自以为懂了”或“人自作多情地懂了”。把两者都写成证书：意图识别置信 `b_r ≥ 1-ε_r`、可读时延 `τ_leg`、可预测性下界。若任一侧不达标，机器人应执行**澄清/询问动作**，而不是猜。

**灵感 6（解释是干预，不是告示）**
直觉：解释会改变人的行为，因此它是闭环中的一次**干预**，带有“表演性”（performative）风险：过度自信的解释诱发过度信任，过度保守的解释导致弃用。面向人的解释还必须**因果充分**（照做能避免失败）、**认知有界**（不超过人的工作记忆/阅读时间预算）、**可执行**（落在人的动作空间里）。这三条缺一，解释就只是“说了什么”，而不是“改变了什么”。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（接触-相位混合动作空间与技能剖面）**
双足动作空间 `A^b = A_j × M × S¹`，其中 `A_j` 为关节/质心动作，`M ⊆ 2^{L,R}` 为合法支撑模式集，`φ ∈ S¹` 为归一化步态相位。技能 `S` 的接触-相位剖面
```
α_S : A_j × M × S¹ → [0,1],      σ_S : S¹ → M
```
其中 `σ_S` 为分段常值的**接触时序**。覆盖判定为 `∀(a,c,φ) ∈ A_T : α_S(a,c,φ) ≥ θ_cov`。

**定义 122（接触-相位兼容性）**
组合 `S_i ⊗ S_j` 可判定，当且仅当存在相位偏移 `δφ` 与过渡模式 `c_tr`，使
```
∀φ : T(σ_i(φ), c_tr) ∧ T(c_tr, σ_j(φ+δφ))
min_φ m_bal(φ) ≥ m_min
ov_j(S_i,S_j; δφ) ≥ θ_a
c_trans(S_i,S_j; δφ,c_tr) ≤ τ_e
```
其中 `T` 为合法接触转移谓词（双足通常强制经过双支撑），`ov_j` 为关节动作剖面的相位对齐 Jaccard 重叠。记该谓词为 `CompCP(S_i,S_j)`。**关键点**：`ov_j` 高并不蕴含 `CompCP`。

**定义 123（双足平衡鲁棒性）**
质心 `x`、速度 `ẋ`，`ω = √(g/z_com)`，发散分量 `ξ = x + ẋ/ω`。支撑多边形 `P(c)`，平衡裕度
```
m_bal(x,c) = dist(ξ, ∂P(c))
```
技能 `S` 的平衡鲁棒性 `ρ_bal(S) = inf_{δ∈Δ} Pr[m_bal(x+δ,c) ≥ m_min]`，`Δ` 为第 53 轮扰动族。把 `ρ_bal` 并入鲁棒性谱 `ρ`。

**定义 124（人类占位与跌倒包络）**
人类占位 `H(t) = ∪_k B(h_k(t), r_h)`，在 `[t, t+T_fall]` 上用有界速度预测。技能/组合 `S` 的跌倒包络 `F_S(t)` 为：对所有失效模式与有界关节力矩，可能落地位置在 `T_fall` 内的**校准过近似**，附带概率测度 `μ_S`。跌倒安全要求
```
sup_t μ_S( F_S(t) ∩ H(t) ≠ ∅ ) ≤ ε_F
```

**定义 125（人类感知 CBF 与权威分配）**
安全函数 `h(x) = min{ m_bal(x,c), dist(F_S(t), H(t)) }`。人类输入 `u_h ∈ U_h`，机器人权威 `λ ∈ [0,1]`，`u = λu_r + (1-λ)u_h`。鲁棒 CBF 条件
```
∀u_h ∈ U_h :  ḣ = L_f h + L_g h · (λu_r + (1-λ)u_h) ≥ -α h
```
可容许权威集 `Λ(x) = { λ ∈ [0,1] : ∃u_r s.t. 上式成立 }`。若 `Λ(x) ≠ ∅`，按效用选 `λ*`；若为空，触发保护性回退技能 `S_safe`。

**定义 126（双向意图与可读性证书）**
机器人对人类意图后验 `b_r`，人类对机器人目标后验 `b_h`。可读性
```
L(ξ_0:t) = E_{g*}[ log b_h(g*|ξ_0:t) / Σ_{g≠g*} b_h(g|ξ_0:t) ]
```
可读时延 `τ_leg(π) = min{ t : b_h(g*|ξ_0:t) ≥ 1-ε_h }`。双向意图证书 `I_int = (b_r, b_h, L, τ_leg, ε_r, ε_h)`，要求 `b_r ≥ 1-ε_r` 且 `τ_leg ≤ τ_leg^max`。

**定义 127（面向人的解释证书）**
解释 `e = (c*, a', Δ_suf, κ(e), γ_e)`：根因、反事实补救动作、采纳后成功率增益、认知复杂度、校准置信。`e` 合格当且仅当
```
Δ_suf ≥ Δ_min,  κ(e) ≤ B_h,  actionable(a') ∈ A_h,  |γ_e - Rel(e)| ≤ ε_trust
```
记合格解释为 `E_cert`。它是对第 54 轮机器侧 `Explain` 的**人侧投影**，二者不可互相替代：机器侧解释用于重规划，人侧解释用于改变人类行为。

**定义 128（人-双足联合证书）**
联合证书
```
J+ = (ρ, A_cert, F_S, Λ, I_int, E_cert, evidence)
```
部署条件（六者同时成立）：
```
dom_J(T) = in                       # v54 动作-鲁棒性条件
CompCP 成立                          # 接触相位可行
μ_S(F_S ∩ H) ≤ ε_F                   # 不会倒到人身上
Λ ≠ ∅                                # 权威可分配
I_int = ok                           # 双向理解
E_cert = ok                          # 解释可执行、校准
```

## 2. 关键算法伪代码

### IP-121 CPAP（Contact-Phase Action Profile）
```python
def contact_phase_profile(skill, A_j, phases, sampler):
    alpha, sigma = {}, {}
    for phi in phases:
        c = skill.contact_schedule(phi)
        sigma[phi] = c
        for a in A_j:
            ok, conf = sampler.query(skill, a, c, phi)
            alpha[(a, c, phi)] = conf if ok else 0.0
    return ContactProfile(alpha, sigma)

def balance_margin(x, contact_set):
    xi = com(x) + com_vel(x) / omega(x)      # DCM / capture point
    return signed_dist(xi, support_polygon(contact_set))
```

### IP-122 CPSC（Contact-Phase Skill Composition）
```python
def contact_phase_compatible(Si, Sj, theta_a, m_min, tau_e):
    for dphi in phase_offsets(Si, Sj):
        for c_tr in legal_transition_sets():
            if not all_feasible_transitions(Si.sigma, Sj.sigma, dphi, c_tr):
                continue
            if min_balance_margin(Si, Sj, dphi, c_tr) < m_min:
                continue
            ov = phase_aligned_jaccard(Si.alpha, Sj.alpha, dphi)
            cost = transition_cost(Si, Sj, dphi, c_tr)
            if ov >= theta_a and cost <= tau_e:
                yield CompositionEdge(dphi, c_tr, ov, cost)
```
只有 `yield` 出的边才进入第 54 轮的 `G_S`；**显式拒绝“高重叠但相位冲突”的假边**。

### IP-123 HAFE（Human-Aware Fall Envelope）
```python
def fall_envelope(x0, u_box, T_fall, failure_modes):
    F = EmptySet()
    for mode in failure_modes:
        R = reachable_set(x0, u_box, T_fall, mode)   # 有界力矩可达集
        F = F | ground_projection(R, direction=dcm_direction(x0))
    return calibrate(F, fall_data)                    # 过近似 + 概率测度

def fall_safe(F, H_pred, eps_F):
    return prob_intersects(F, H_pred) <= eps_F
```

### IP-124 HACBF（Human-Aware CBF + 权威分配）
```python
def admissible_authority(x, u_r, U_h, h, alpha_cbf):
    Lf, Lg = lie_derivatives(h, x)
    worst = max(Lg @ u_h for u_h in over_approx(U_h))
    # ḣ = Lf + Lg(λu_r + (1-λ)worst) ≥ -αh  ⇒ 关于 λ 的仿射不等式
    return solve_affine_interval(Lf + Lg * (lam*u_r + (1-lam)*worst) + alpha_cbf*h)

def shared_control(x, u_r, u_h, h):
    Lam = admissible_authority(x, u_r, U_h, h, alpha_cbf)
    if Lam.is_empty():
        return ('protective_fallback', safe_collapse(x))
    lam = select_authority(Lam, human_pref=u_h)
    return ('ok', lam * u_r + (1 - lam) * clip(u_h, U_h), lam)
```

### IP-125 BIL（Bidirectional Intent & Legibility）
```python
def legibility(trajectory, goal_set, observer):
    post = observer.posterior(trajectory, goal_set)
    L = expected_log_ratio(post, goal_true)
    t_leg = first_time(lambda t: post[t][goal_true] >= 1 - eps_h)
    return L, t_leg

def bil_certificate(pi, history, robot_model, human_model):
    br = robot_model.infer_human_intent(history)
    L, t_leg = legibility(pi.prefix, pi.goal_set, human_model)
    if br.confidence < 1 - eps_r or t_leg > tau_leg_max:
        return ('clarify', clarification_action(history))
    return ('ok', IntentCert(br, L, t_leg))
```

### IP-126 HEX（Human-facing Explanation）
```python
def human_explanation(failure, human_model, B_h, delta_min):
    c_star = intervention_root_cause(failure)
    remedy = contrastive_counterfactual(c_star)
    e = Explanation(c_star, remedy, calibrated_gain(c_star),
                    cognitive_chunks(remedy), calibrated_conf(c_star))
    if e.complexity > B_h:
        e = compress(e, budget=B_h)            # 保因果、降细节
    if e.gain < delta_min or not actionable(e.remedy, human_model):
        return ('insufficient', e)
    if abs(e.conf - reliability(e)) > eps_trust:
        return ('miscalibrated', e, trust_repair(e))
    return ('ok', e)
```

### IP-127 JISC（Joint Interaction-Safety Certificate）
```python
def joint_interaction_certificate(seq, gamma_ce, budgets):
    J = joint_certificate(seq, gamma_ce, budgets.delta_a, budgets.rho_min)  # v54
    if J.status != 'ok':
        return J
    if not contact_phase_compatible_seq(seq):
        return ('reject', 'contact_phase')
    F = fall_envelope(seq.x0, seq.u_box, budgets.T_fall, failure_modes(seq))
    if not fall_safe(F, predict_humans(seq), budgets.eps_F):
        return ('reject', 'fall_onto_human', F)
    Lam = admissible_authority(seq.x0, seq.u_r, U_h, h, alpha_cbf)
    if Lam.is_empty():
        return ('reject', 'no_safe_authority', Lam)
    I = bil_certificate(seq.pi, seq.history, robot_model, human_model)
    E = human_explanation(seq.failure_hint, human_model, budgets.B_h, budgets.delta_min)
    if I.status != 'ok' or E.status != 'ok':
        return ('reject', 'interaction', I, E)
    return ('ok', JointInteractionCert(J, F, Lam, I, E))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CPAP | `O(|A_j|·|M|·|Φ|·|S|)` | `O(|A^b|)` | 接触时序与剖面对齐采样 |
| CPSC | `O(|S|²·|Φ|·|M|²)` | `O(|S|²+|E|)` | 转移谓词 sound、相位偏移完整 |
| HAFE | 离线 `O(|modes|·|R|)`；在线查表 | `O(|R|)` | 可达集是真实跌倒的过近似 |
| HACBF | `O(|∂U_h|·QP)` | `O(1)` | `U_h` 为人类输入过近似，QP 可行 |
| BIL | `O(|G|·|ξ|)` | `O(|G|)` | 观测者模型校准、先验不退化 |
| HEX | `O(|E_exp|)`（预算截断） | `O(B_h)` | 因果充分性与校准 |
| JISC | 上述之和 | 上述之和 | 六个子条件全部 sound |

**正确性定理（Interaction-Grounded Bipedal Composition Soundness）**
在 v54 的 (A22)–(A28) 之外，假设：
**(A29)** 接触-相位剖面由结构化仿真校准，`sup|α_S - α_real| ≤ ε_c`；
**(A30)** 跌倒包络 `F_S` 是真实落点的校准过近似，漏包概率 `≤ ε_F`；
**(A31)** HACBF 的重解周期 `≤ τ_react`，且 `U_h` 是真实人类输入的过近似；
**(A32)** 可读性证书在承诺前成立（`τ_leg ≤ τ_leg^max`），人类意图识别误差 `≤ ε_r`，人侧解释的因果充分性误差 `≤ ε_x`。
则一次满足 `J+` 的部署，其“任务成功且不与人发生危险接触”的概率至少为
```
1 - [ Σ_d(1-ρ_min(d)) + β_E + P(δ_a > Θ_a)
      + ε_c + ε_F + P(Λ = ∅) + ε_r + ε_h + ε_x ]
```
这是**并集界**，不要求各失效通道独立；其意义不是把数字做漂亮，而是把 v54 隐含忽略的“跌倒/交互/权威”通道显式计入。

**数值演练（示意，非实测）**：取 `Σ_d(1-ρ_min)=0.03, β_E=0.01, P(δ_a>Θ_a)=0.01, ε_c=0.01, ε_F=0.005, P(Λ=∅)=0.01, ε_r=0.01, ε_h=0.01, ε_x=0.005`，则下界 `≥ 0.90`。v54 若只报 `0.95`，多出的 `0.05` 恰是被忽略的交互/跌倒通道——**更低的诚实界优于更高的虚假界**。

**接触相位假兼容的数值演练（示意）**：设 `S_walk` 与 `S_turn` 的关节剖面 Jaccard `ov_j = 0.82 ≥ θ_a = 0.80`，v54 的 SCOM 接受该边；但两者在衔接处都要求右腿支撑，合法转移必须经双支撑，过渡能量代价 `c_trans = 1.7 τ_e > τ_e`，CPSC 拒绝该边。若强行拼接，预期出现一次垫步或 20%–30% 的失稳率（示意值，需 E162 实测）。

## 6. 本轮最大风险

### IP-121 CPAP

```python
def contact_phase_profile(skill, A_j, phases, sampler):
    alpha, sigma = {}, {}
    for phi in phases:
        c = skill.contact_schedule(phi)
        sigma[phi] = c
        for a in A_j:
            ok, conf = sampler.query(skill, a, c, phi)
            alpha[(a, c, phi)] = conf if ok else 0.0
    return ContactProfile(alpha, sigma)

def balance_margin(x, contact_set):
    xi = com(x) + com_vel(x) / omega(x)
    return signed_dist(xi, support_polygon(contact_set))
```

### IP-122 CPSC
```python
def build_contact_phase_graph(skills, theta_a, m_min, tau_e, K):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j:
                continue
            for dphi in phase_offsets(s1, s2):
                for c_tr in legal_transition_sets():
                    if not all_feasible_transitions(s1.sigma, s2.sigma, dphi, c_tr):
                        continue
                    if min_balance_margin(s1, s2, dphi, c_tr) < m_min:
                        continue
                    ov = phase_aligned_jaccard(s1.alpha, s2.alpha, dphi)
                    cost = transition_cost(s1, s2, dphi, c_tr)
                    if ov >= theta_a and cost <= tau_e:
                        rho_comp = compose_robustness(s1.rho, s2.rho, K)
                        G.add_edge(i, j, dphi=dphi, c_tr=c_tr, compat=ov,
                                   cost=cost, rho_comp=rho_comp)
    return G
```

### IP-123 HAFE

```python
def fall_envelope(x0, u_box, T_fall, failure_modes):
    F = EmptySet()
    for mode in failure_modes:
        R = reachable_set(x0, u_box, T_fall, mode)
        F = F | ground_projection(R, direction=dcm_direction(x0))
    return calibrate(F, fall_data)

def fall_safe(F, H_pred, eps_F):
    return prob_intersects(F, H_pred) <= eps_F
```

### IP-124 HACBF
```python
def admissible_authority(x, u_r, U_h, h, alpha_cbf):
    Lf, Lg = lie_derivatives(h, x)
    worst = max(Lg @ u_h for u_h in over_approx(U_h))
    return solve_affine_interval(
        Lf + Lg * (lam * u_r + (1 - lam) * worst) + alpha_cbf * h)

def shared_control(x, u_r, u_h, h, U_h):
    Lam = admissible_authority(x, u_r, U_h, h, alpha_cbf)
    if Lam.is_empty():
        return ('protective_fallback', safe_collapse(x))
    lam = select_authority(Lam, human_pref=u_h)   # 效用最大且满足 CBF
    return ('ok', lam * u_r + (1 - lam) * clip(u_h, U_h), lam)
```

```python
def joint_interaction_certificate(seq, gamma_ce, budgets):

    if J.status != 'ok':
        return J
    if not contact_phase_compatible_seq(seq):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPAP | `O(|A_j|·|M|·|Φ|·|S|)` | `O(|A^b|)` | 接触时序与剖面采样覆盖 |
| CPSC | `O(|S|²·|Φ|·|M|²)` | `O(|S|²+|E|)` | 转移谓词 sound、相位偏移完备 |
| HAFE | 离线 `O(|modes|·|R|)`，在线查表 | `O(|R|)` | 可达集为真实跌倒的过近似 |
| HACBF | `O(|∂U_h|·QP)` | `O(1)` | `U_h` 过近似、QP 可行 |
| BIL | `O(|G|·|ξ|)` | `O(|G|)` | 观测者模型校准、先验不退化 |
| HEX | `O(|E_exp|)` 预算截断 | `O(B_h)` | 因果充分、认知有界、校准 |
| JISC | 上述之和 | 上述之和 | 六个子条件全部 sound |

**正确性定理（Interaction-Grounded Bipedal Composition Soundness）**
假设 v54 的 (A22)–(A28) 成立，且
**(A29)** `sup|α_S - α_real| ≤ ε_c`；**(A30)** 跌倒包络漏包概率 `≤ ε_F`；**(A31)** HACBF 重解周期 `≤ τ_react` 且 `U_h` 为人类输入过近似；**(A32)** `τ_leg ≤ τ_leg^max`、意图识别误差 `≤ ε_r`、解释因果充分性误差 `≤ ε_x`。
则满足 `J+` 的部署，其“任务成功且不与人发生危险接触”的概率至少为
```
P_safe_task ≥ 1 - [ Σ_d(1-ρ_min(d)) + β_E + P(δ_a>Θ_a)
                   + ε_c + ε_F + P(Λ=∅) + ε_r + ε_h + ε_x ]
```
**推导要点**：六个子证书各自给出一个坏事件上界；坏事件分别为动作剖面失真、跌倒包络漏包、权威集为空、意图识别错误、可读性未达标、解释无效。任一坏事件发生都可能导致失败或危险接触，故用并集界相加；并集界不要求独立，只要求各上界可校准。**诚实性**：交互项使名义下界低于 v54，但它把 v54 隐含忽略的失效通道计入，避免“虚假高界”。

**数值演练（示意，非实测）**：`0.03 + 0.01 + 0.01 + 0.01 + 0.005 + 0.01 + 0.01 + 0.01 + 0.005 = 0.10`，故 `P_safe_task ≥ 0.90`。若 E163/E164/E166 实测发现 `ε_F`、`P(Λ=∅)`、`ε_x` 被低估，则下界自动收紧，而不是被隐藏。
