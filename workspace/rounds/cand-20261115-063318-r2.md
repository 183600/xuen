# 第 4 轮（灵感循环第 4 轮；本轮灵感：「力矩控制」×「意图识别」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化 + 安全口径不降级**。力矩控制与意图识别都是**可选增强**，任一不可用都必须能一键退回：WDC/CG/IIR 关 ⇒ 等价 InstructGauge 位置契约；意图不可辨识 ⇒ 最柔顺仍可运行；InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。

## 0. 直觉与动机

**灵感 1（力矩控制 → 把「位置承诺」换成「力域契约」）**
直觉：第 3 轮把错误当作必须精确阻断的对象，因此用位置契约、前缀截断、不可逆屏障去「防错」。力矩控制换了一个问题：与其保证「位置绝对正确」，不如保证「即使位置错了，施加的力也有界、可回退」。柔顺控制让机器手像人的指尖——摸错地方只是轻轻压一下，而不是撞上去。这把安全从「定位精度」解耦为「交互力包线」，并让一部分原本不可逆的接触（压、刮）变成力矩受限、可回退的接触。
严谨方向：把位置前置条件 `φ` 升级为**力矩域契约** `W = (𝒲_env, Z_adm, Ẇ_max, retract)`，安全不变式 `Inv_W` 直接约束实测外力 `τ_ext` 与其变化率，而不是约束位置误差。

**灵感 2（意图识别 → 从物理信号推断「隐式接触意图」）**
直觉：第 3 轮的意图是**显式自然语言**；但接触任务里操作者常常不说话，手上「用力方式」本身泄露意图：贴表面轻推 = 探测，持续加压 = 就位，快速回撤 = 避碰。意图识别的价值不在于直接产生动作，而在于决定**多柔顺、能否继续、能否启用不可逆工具**。因此正确的接口是「力矩证据 → 意图后验 `b_t`」，后验只进入柔顺门与分块条件，绝不进入执行器的自由通道——延续「objective 与 shield 分离」。
严谨方向：在力矩/本体证据上做贝叶斯滤波 `b_t`，但与第 3 轮的关键区别是：**证据依赖控制器**（柔顺参数会改变力矩签名），所以意图识别天然是一个闭环辨识问题。

**灵感 3（两者耦合 → 必须防「自信地错误」的自确认回路）**
直觉：最危险的耦合不是「识别错」，而是「识别错还被闭环强化」：意图从力矩里学，力矩又被柔顺设置塑形。如果错误意图让控制器变硬，接触被推入签名退化区，反而强化错误意图；再叠加第 3 轮的分块 K 步，错误意图会被连续执行。解法是四根结构支柱：**置信度-柔顺门**（越不确定越软，让错误后果有界）、**意图持久性约束块长**（意图不稳就缩短块）、**可辨识性证书 + 有界安全激励**（先辨识、后自信，打破观察-动作混淆）、**力矩速率屏障**（高速/粘滑处强制单步）。力矩控制负责「错了也不至于撞坏」，意图识别负责「尽量别错」，可辨识性负责「别把错当成对」。

## 1. 研究问题（本轮要回答什么）

- **Q1（力域安全）**：力矩域契约能否在保持任务精度的同时，把「定位错误 / 不可逆损伤」转换成有界、可回退的力风险？
- **Q2（意图可辨识）**：仅凭物理信号识别隐式意图的可辨识边界在哪？如何用证书与有界激励避免「自我确认」？
- **Q3（耦合夹紧）**：柔顺门与意图条件分块能否把「意图错误 × 刚度 × 时长」的乘积压回有界，并在不可辨识时优雅退化为最柔顺？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–461）

**P1 力域优先（Wrench Before Position）**
安全约束是 `τ_ext ∈ 𝒲_env ∧ ‖τ̇_ext‖ ≤ τ̇_max`；位置精度是任务指标，不是安全前提。位置错了可以被力包线接住，力超了不能。

**P2 不确定即柔顺（Uncertainty ⇒ Compliance）**
刚度 `K_p` 与力上限 `W_cap` 是意图熵 `H(b)` 的**单调非增**函数：越不确定越软；`b ∈ A_τ`（放弃集）⇒ 最柔顺 + 禁用不可逆工具。「未知 = 软」把意图错误的最坏后果夹住。

**P3 先辨识后自信（Identify Before Exploit）**
任何提高刚度、延长块长、启用不可逆工具的决定，都必须持有**可辨识性证书** `IDC`，或已施加**有界安全激励**。禁止未经验证的自信——这是打破「意图 ← 力矩 ← 柔顺 ← 意图」自确认回路的充分条件。

**P4 屏障重定义（Wrench-Relative Barrier）**
不可逆集由「ε-力矩可逆」重新定义：能被 `retract` 在力矩包线内以 `ε` 误差撤回的动作移出不可逆集；剩余不可逆动作仍强制 `K=1` + 独立回执验证。力矩控制是**有条件地**松弛屏障，不是取消屏障。

## 3. 与基线的接口（如何退化）

- 力矩传感 / 力矩内环不可用 ⇒ `WDC/CG/IIR` 全关，等价 **InstructGauge**（位置契约 + 显式指令）；
- 意图不可辨识或 `b ∈ A_τ` ⇒ 最大柔顺、缩短 `K`、禁不可逆工具，**降级为「软模式」但仍在安全包线内运行**；
- 意图识别不可用 ⇒ 以第 3 轮指令 `ι` 的显式意图作先验 `b₀`，等价 InstructGauge 的指令条件化；
- 力矩可逆性不可证 ⇒ 恢复第 3 轮 `Barrier`（跨不可逆强制 `K=1`）；
- `IDC` 缺失且激励不可行 ⇒ 禁止进入高刚度档，强制 `K=1`；
- InstructGauge 失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE 原样。

## 4. 预期贡献

1. 一个**力矩域契约**，把安全从「位置误差」改成「有界交互力 + 力矩速率界」，并给出「失效模式从碰撞冲量转为有界力」的论证；
2. 一个**置信度-柔顺门**，使「意图错误」的最坏后果被意图熵夹住——不确定性在结构上变得安全；
3. 一个**可辨识性证书 + 有界安全激励**的对偶控制方案，显式处理「证据依赖动作」造成的自确认伪不动点；
4. 一个**力矩-意图条件分块**与**力矩回执**审计链，把第 3 轮的语义-时间放大进一步压到「意图 × 刚度 × 时长」的有界乘积；
5. 一条完整可证伪路径：`E457–E470` 覆盖力域安全、意图校准、柔顺单调性、自确认、持久性、可逆性、分层覆盖、双环时序与 sim→real 迁移。

## 5. 本轮最大风险

**一句话**：意图识别从被自身柔顺塑形的力矩中学习，可能形成「自信的错误」自确认回路；一旦该回路把控制器锁在错误的高刚度档，分块会把错误意图连续放大，而力域包线只能保证「不撞坏」，不能保证「做对」。

## 2. 形式化定义（要点）

**定义 448（交互状态与力矩域契约 WDC）** `σ_t = (q, q̇, τ_ext, τ_cmd)`；`𝒲_env = {τ : ‖τ‖_∞ ≤ τ_max, ‖τ̇‖_∞ ≤ τ̇_max}`；`Z = (K_p, K_d) ∈ Z_adm`。力矩域契约 `W = (𝒲_env, Z_adm, τ̇_max, retract)`；安全不变式
`Inv_W(σ) ≡ (τ_ext ∈ 𝒲_env) ∧ (‖τ̇_ext‖_∞ ≤ τ̇_max)`，安全状态集 `C_W = {σ : Inv_W(σ)}`。控制律取阻抗/导纳形式 `τ_cmd = K_p(q_d−q) + K_d(q̇_d−q̇) + τ_ff`，并硬夹 `‖τ_cmd‖_∞ ≤ τ_max`。与位置契约 `φ` 的关系：`φ` 仍保留为**任务**前置，`Inv_W` 是**安全**前置；二者不可互相替代。

**定义 449（隐式意图与信念滤波 IIR）** 意图模式 `M = {m₁…m_L}`（探测表面 / 贴合就位 / 沿边滑移 / 退避避碰 / 保持）。证据 `e_t = (τ_ext,1:t, q_1:t, receipts, c_1:t)`，其中控制器上下文 `c_t` 显式入证据——因为力矩签名由柔顺设置塑形。信念递推
`b_t(m) ∝ p(τ_ext,t | m, c_t, σ_t) · Σ_{m'} T(m|m') b_{t−1}(m')`。
放弃集 `A_τ = {b : H(b) > H_τ ∨ (b_(1) − b_(2)) < margin}`。**IIR 的输出不直接驱动执行器**；它只被定义 450/451/455 消费。初值 `b₀` 可由第 3 轮显式指令 `ι` 提供（退化接口）。

**定义 450（置信度-柔顺门 CG）** `H(b) = −Σ_m b(m) log b(m)`，`H_max = log L`。
`K_p^*(b) = K_min + (K_max − K_min)·(1 − H(b)/H_max)`，
`W_cap(b) = W_min + (W_max − W_min)·(1 − H(b)/H_max)`。
硬夹：`K_p ← min(K_p^*(b), K_p^{env})`，`W_cap ← min(W_cap(b), τ_max)`；其中 `K_p^{env}` 由「最大预期定位误差下仍不超包线」反解。若 `b ∈ A_τ`，强制 `(K_p, W_cap) = (K_min, W_min)` 且禁用不可逆工具。两函数关于 `H(b)` 单调非增——**不确定性在结构上变得安全**。

**定义 451（意图持久性与意图条件块长）** 意图危险率 `h(m) = sup_{1≤k≤K} P(m_{t+k} ≠ m_t | m_t)`；意图条件块长 `K_int(m) = ⌊η_int / h(m)⌋`。执行块须满足
`K ≤ min(K_MAX(ι), K_int(m), ⌊K₀/(1+κ_int)⌋)`（后两项定义 458），其中 `K_MAX(ι)` 继承第 3 轮定义 440。

**定义 452（ε-力矩可逆与力域相对屏障）** 动作 `a` 是 ε-力矩可逆的，若存在撤回原语 `r` 使
`W(a) ∪ W(r) ⊆ 𝒲_env`、`‖s_{a∘r} − s‖ ≤ ε`、且全程 `‖τ̇‖ ≤ τ̇_max`；记可逆集 `A_rev(ε)`。力域相对不可逆集 `I_irr^W = A \ A_rev(ε) ⊆ I_irr`（第 3 轮不可逆集）。屏障（松弛版定义 445）：块跨 `I_irr^W` ⇒ 强制 `K=1` + 独立回执交叉验证。力矩限制可把动作从 `I_irr` 移入 `A_rev(ε)`，故屏障是**有条件松弛**。

**定义 453（可辨识性证书 IDC）** 控制器上下文 `c` 诱导签名分布 `p(τ_ext | m, c)`。证书有效当且仅当
`min_{m≠m'} D_KL(p(τ|m,c) ‖ p(τ|m',c)) ≥ δ_id`。
证书缺失 ⇒ 禁止据此提高刚度或延长块长；必须按定义 454 施加激励，或退回 `(K_min, W_min)` 并令 `K=1`。IDC 在每个控制上下文切换/证书刷新点重算并缓存。

**定义 454（有界安全激励 / 对偶控制）** 激励 `d_t ∈ argmax_d I(M; τ_ext(d))`，约束 `‖W(d)‖_∞ ≤ W_exc(b_t)`、`W(d) ⊆ 𝒲_env`、`d ∈ A_rev(ε)`；激励预算 `W_exc(b) = ρ·min(W_cap(b), W_safe)`，`0<ρ<1`。激励是**安全包线的子预算**，任务始终保留 `(1−ρ)W_safe`；屏障触发期间禁用激励。

**定义 455（力矩-意图条件分块目标，扩展定义 436）**
`C* = argmax_C [ ΔH(C) + w_int·A_int(b,C) + w_ens·smooth(C) − λ_cost·c(C) − λ_id·risk_id(C) ]`
`s.t. |C| ≤ min(K_MAX(ι), K_int(m), ⌊K₀/(1+κ_int)⌋)`，`W(C) ⊆ 𝒲_env`，`IDC` 有效或已挂接激励，`Barrier(C)`，`B_chunk ≤ B_left`；`A_int(b,C)` 为块预测后验满足当前意图模式的概率，`risk_id(C)` 为块内签名可分性不足的惩罚。

**定义 456（力矩回执与意图-证据绑定 WRS，扩展定义 441）** `WrenchReceipt = (τ_{t:t+K} 摘要, Z, W_cap, b_t, IDC_id)`。每条意图主张 `c` 必须绑定 `(receipt_id, chunk_cert_id, wrench_receipt_id)`；`bind_claims` 仅保留可命中回执的主张，未绑定者序列化时**剥离**。剥离是纯投影，不改变数值行为（沿用 ToolGauge 定义 423 / InstructGauge 定义 441）。

**定义 457（力矩速率屏障与粘滑守卫）** 若预测或实测 `‖τ̇‖_∞ > τ̇_max`，或粘滑检测量 `SSG = |Δτ/Δq|` 在接触点超过 `θ_stick` 且符号翻转，则强制 `K=1`、dwell 一个整定周期、重新接地，并禁止激励。速率屏障是硬实时内环逻辑，不进入异步分块。

**定义 458（意图歧义预算 κ_int）** `κ_int = K·(H_cal(b_t) + h(m_t))`，`H_cal` 为**校准后**的意图熵（定义 460/引理 64）。约束 `K ≤ K₀/(1+κ_int)`：意图越含糊、越易漂移，块越短。与第 3 轮 `κ_sem = K·H(ι|ℓ)` 并列，形成「语义 × 意图」双预算。

**定义 459（意图安全盾 IVB）** `M_safe = {退避避碰, 碰撞, 急停} ⊆ M` 为安全模式集。若 `Σ_{m∈M_safe} b(m) ≥ θ_safe`，立即将 `(K_p, W_cap)` 夹到 `(K_min, W_min)`，禁止任何增大接触深度的动作，并将安全模式视为吸收态，直到独立回执确认脱离接触。安全盾优先于任何任务收益。

**定义 460（交互分层共形校准，扩展定义 438）** `stratum_W(σ, b) = (wrench 区制 ∈ {free, contact, high-force}, 校准后 belief 分箱, 意图模式 m)`。每层用校准集 `C_cal^s` 取分位 `q_s`，使层内覆盖 `P(h* ∈ H_s | s) ≥ 1−α`；`|C_cal^s| < n_min` ⇒ 回退全局阈值。分箱必须使用**校准后**的 `b`，否则层错配导致覆盖失效。

**定义 461（扩展修复解释证书 RepairCert″）** `RepairCert″(s) = (ι, b_t 轨迹, WrenchReceipt, C, ChunkCert, IDC, receipts, claims)`，使人类审计可沿「指令/意图 → 柔顺档位 → 块 → 逐步力矩回执 → 主张」五级证据链复现一次修复，并可核验「刚度是否与意图置信度相符」。

## 3. 关键算法骨架

```python
# IP-329 IIR：隐式意图贝叶斯滤波（100Hz；内环只查表，不在此处）
class IIR:
    def update(self, b_prev, tau_seg, ctx):
        pred = {m: sum(T(m, mp) * b_prev[mp] for mp in M) for m in M}
        lik  = {m: p_tau(tau_seg, ctx, m) for m in M}      # 以 ctx=c_t 为条件
        b    = normalize({m: lik[m] * pred[m] for m in M}) # 证据依赖动作
        return b
    def abstain(self, b):
        return entropy(b) > H_TAU or top2_margin(b) < MARGIN

# IP-330 CG：置信度-柔顺门（内环 O(L) 夹紧）
class ComplianceGate:
    def regulate(self, b):
        if self.iir.abstain(b):
            return K_MIN, W_MIN, {"irreversible": False}   # 未知 ⇒ 最软
        H = entropy(b)
        kp   = K_MIN + (K_MAX - K_MIN) * (1 - H / H_MAX)
        wcap = W_MIN + (W_MAX - W_MIN) * (1 - H / H_MAX)
        return min(kp, K_P_ENV), min(wcap, TAU_MAX), {"irreversible": True}

# IP-332 IDC：可辨识性证书 + 有界安全激励
class IDC:
    def certify(self, ctx):
        sep = min(kl(p_tau(ctx, m), p_tau(ctx, mp))
                  for m, mp in pairs(M))
        return sep >= DELTA_ID
    def safe_excitation(self, b, ctx):
        if self.certify(ctx):
            return None                                    # 已可分 ⇒ 不激励
        budget = RHO * min(W_cap(b), W_SAFE)                # 子预算，ρ<1
        d = argmax_info_gain(M, b, budget)                 # 互信息最大
        if d is None or not reversible(d, EPS):
            return None                                    # 不可辨识 ⇒ 最柔顺
        assert norm_inf(W(d)) <= budget and W(d) in W_ENV
        return d

# IP-331 ICC：意图条件分块（继承 IAC，叠加意图持久性/歧义预算）
class ICCPlanner:
    def plan_chunk(self, iota, b, H_s, tools, budget, drift_bound):
        K = min(self.chunk_len(iota, drift_bound),       # 第 3 轮 K_MAX(ι)
                int(ETA_INT / max(hazard(b), 1e-9)),      # 意图持久性
                int(K0 / (1 + kappa_int(b, K))))          # 意图歧义预算
        C = self.vla.plan_chunk(iota, H_s, tools, max(1, K))
        if not prefix_closed(C):          return self.per_step(iota, H_s, tools)
        if crosses_irreversible(C, I_IRR_W):  C = truncate_at_barrier(C, I_IRR_W)
        return C

# IP-334 IVB：意图安全盾（内环，1kHz，O(1)）
def intent_shield(b, kp, wcap):
    if sum(b[m] for m in M_SAFE) >= THETA_SAFE:
        return K_MIN, W_MIN, HOLD                  # 安全模式吸收
    return kp, wcap, OK

# IP-335 TorqueGauge-8C 闭环
def torquegauge_8c(M, s, ell):
    # 1) 继承第 3 轮：显式指令接地（可选，提供 b₀ 先验）
    out  = M.nlib.ground(ell, M.scene, M.ontology)
    iota = out[0] if out else M.default_iota
    # 2) 隐式意图信念（来自力矩；证据依赖当前柔顺上下文）
    b = M.iir.update(M.belief[s], M.tau_window(s), M.ctx(s))
    # 3) 柔顺门 + 意图安全盾：不确定 ⇒ 软；安全模式吸收
    kp, wcap, mode = M.cg.regulate(b)
    kp, wcap, flag = intent_shield(b, kp, wcap)
    if flag == HOLD:
        return M.max_compliance_and_hold(s)
    # 4) 先辨识后自信：证书 / 有界激励 / 最柔顺回退
    if not M.idc.certify(M.ctx(s)):
        d = M.idc.safe_excitation(b, M.ctx(s))
        if d is None:
            kp, wcap = K_MIN, W_MIN                 # 不可辨识 ⇒ 最柔顺
            C = M.per_step(iota, M.hypotheses(s), M.tools)   # 且强制 K=1
        else:
            M.apply_excitation(d)
            b = M.iir.update(b, M.tau_window(s), M.ctx(s))
            C = M.icc.plan_chunk(iota, b, M.hypotheses(s), M.tools,
                                 M.budget_left(s), M.drift_bound(s))
    else:
        C = M.icc.plan_chunk(iota, b, M.hypotheses(s), M.tools,
                             M.budget_left(s), M.drift_bound(s))
    # 5) 继承第 3 轮分块校验
    if not M.tcv.verify(C.as_program(), M.budget_left(s))[0]:
        C = M.numeric_fallback(M.hypotheses(s))
    # 6) 在力矩契约下执行（CVC + 速率/粘滑屏障）
    cert = M.cvc.commit(C, M.env, iota, kp=kp, wcap=wcap)
    if M.wrb.tripped(cert):                        # 速率 / 粘滑
        return M.wrb.dwell_and_reground(s)
    # 7) 继承：校准、交叉验证、静默点热替换
    receipts = cert.receipts
    if len(receipts) < n_min(s):
        return stub_and_red(s, "insufficient")
    mu, Sig = M.apcal.calibrate(receipts, M.hypotheses(s), s)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace_at_quiescence(M.dpe, new_ec, cert.boundary)
    # 8) 力矩回执 + 意图主张绑定（纯投影）
    M.wrs.bind(cert, b, iota, receipts)
    M.pquar.record(M.apcal.last_gain, realized_gain(receipts))
    return True

def TorqueGauge_round(M, obs, audio, tac, depth, det, ell=None):
    M.wdc.start(rate=1e3)          # 内环：WDC + CG + IVB + 速率屏障（O(1)）
    M.iir.set_rate(100)            # 意图滤波降频，内环只查表
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            submit_async(torquegauge_8c, M, s, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)   # 50Hz 路径不变
```

## 4. 推导

**引理 59（力域契约的失效模式转换）** 在 `Inv_W` 成立且所有动作满足 `W(a) ⊆ 𝒲_env` 时，任意定位误差 `e` 引起的接触力满足 `‖F‖ ≤ τ_max`（在控制律下更紧：`‖F‖ ≤ min(τ_max, K_p‖e‖ + K_d‖ė‖ + ‖τ_ff‖)`）。因此定位误差不再转化为碰撞冲量，而转化为「作用在错误位置的有界力」。推论：安全与定位精度解耦；但该界只约束力矩**幅值与速率**，不约束「力的位置 / 持续时间 / 热效应」，故不可逆屏障不可省。
*证明骨架*：控制律给出 `τ_cmd = K_p e + K_d ė + τ_ff`，硬夹与 `Inv_W` 保证 `τ_ext ⊆ 𝒲_env`；碰撞冲量对应 `∫F dt` 的尖峰，而速率界 `‖τ̇‖ ≤ τ̇_max` 排除冲量型尖峰。

**引理 60（柔顺门的最坏情形夹紧）** 若 `b` 经校准（`H_cal(b)` 为真实意图不确定度的上界），在定义 450 与 459 下，任意意图错误造成的最坏接触力矩 `≤ W_cap(b)`，且 `W_cap` 关于 `H_cal` 单调非增；`b ∈ A_τ` 时 `≤ W_min`。故**错误代价被意图熵夹住，而不是被意图正确性夹住**。
*反例警示*：若 `b` 过度自信（`H` 被低估），门会被错误打开，界失效；因此 `W_cap` 必须以校准熵为输入（定义 460、引理 64）。

**引理 61（意图持久性 + 分块一致性）** 若 `K·h(m) ≤ η_int` 且块受第 3 轮 CVC 与前缀封闭约束，则一个块内意图保持不变的概率 `≥ 1−η_int`；若块内似然突变超过阈值（检测到意图切换），CVC 将其视为漂移并截断到最后安全前缀。合计块内语义-意图失败概率 `≤ P_cvc + η_int`。
*证明*：对块内步数用 union bound；切换事件被 CVC 的 `still_grounded`/漂移项捕获，前缀封闭保证截断后仍是合法程序（引理 52）。

**引理 62（自我确认与可辨识性）——核心** 在闭环 `c_t = g(b_t)`、`b_{t+1} = Φ(b_t, τ_{t+1}(c_t))` 中：
(i) 若在 `c = g(b)` 处 `p(τ|m,c)` 不可分（`min D_KL < δ_id`），则 `Φ` 可能以错误 `m` 为中心存在**伪不动点**，且信念更新非收缩；
(ii) 若 `IDC` 成立（`min D_KL ≥ δ_id`）或施加满足定义 454 的激励（互信息 `≥ I_min`），则后验 odds 每步被推离 1，`Φ` 在 TV 度量下收缩到真意图邻域，伪不动点不存在。
故「先辨识后自信」是打破自确认回路的充分条件。
*证明骨架*：由 KL 分离得似然比有界远离 1；Bayes 更新使对数 odds 单调漂移，收缩性由 Dobrushin 系数 < 1 给出；无分离时构造一个似然近似对称的 `c=g(b)` 即可得伪不动点。

**引理 63（力矩可逆性收缩不可逆集与屏障松弛）** 在 WDC 下 `I_irr^W ⊆ I_irr`；若 `a ∈ A_rev(ε)` 且 `W(a) ≤ W_rev`，则 `a` 可移出屏障、允许分块，其期望损失 `≤ p_err·W_cap + ε`（`p_err` 为意图错误率，`ε` 为 retract 残差）。若条件不满足，则恢复第 3 轮 Barrier（`K=1` + 独立验证）。故松弛是**有条件的**，不是无条件的。
*证明*：`I_irr^W` 的定义直接排除 `A_rev(ε)`；损失由「错误执行一次的力界」加「撤回残差」分解。

**引理 64（意图条件分层共形覆盖）** 以 `(wrench 区制, 校准后 belief 分箱, m)` 分层，层内可交换下覆盖 `P(h*∈H_s | s) ≥ 1−α`；边缘覆盖 `≥ 1−α − Σ_s π_s·TV_s`；低样本层回退全局阈值，覆盖按 `−2η_global` 优雅降级。**注意**：分箱必须使用校准后的 `b`，否则层错配导致覆盖失效（与引理 60 的警示同源）。

**引理 65（双环实时性与 50Hz 保全）** 力矩内环 `f_τ ≥ 1kHz`，`WDC + CG + IVB + 速率屏障` 的 WCET `≤ 1ms`；意图滤波 IIR 降频到 `f_b = 100Hz`，内环只做 `O(1)` 查表与夹紧；外环 50Hz 不变、新增 `< 0.2ms`；WDC 的执行延迟 `≤ 1` 个内环周期。继承 ToolGauge 引理 50 的硬实时结论。

**引理 66（激励预算与安全裕度不互斥）** 令 `W_exc(b) = ρ·min(W_cap(b), W_safe)`，`0<ρ<1`。激励最多消耗安全包线的 `ρ` 比例，任务始终保留 `(1−ρ)W_safe`；互信息关于激励幅值在 `[0, W_exc]` 上单调非减且有饱和，故存在 `ρ* ∈ (0,1)` 使「信息增益 / 安全裕度」最优。故主动辨识与安全不是零和。
*证明骨架*：由约束优化与互信息的凹性/单调性；预算分离保证任务子包线不被侵占。

## 8. 本轮最大风险

**一句话**：`IIR` 的意图后验从被 `CG` 柔顺设置塑形的力矩中学习，形成「观察依赖动作」的闭环——一旦校准失效或 `IDC` 漏检，错误意图会通过「提高刚度 → 签名退化 → 强化错误」的路径自我确认，并被 `ICC` 的分块连续执行；力域契约只能保证「不撞坏」，不能保证「做对」，因此真正的残余风险是**意图-柔顺自确认**，而非单个模块。
