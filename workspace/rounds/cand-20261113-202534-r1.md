# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「语音识别」×「激光雷达」）

> 第 68 轮 CALM-RAS 把「测量可信度」提升为一等公民，但它自陈的最大风险暴露了下一个元失败：**它把「不确定（uncertainty）」当成了「不可辨（non-identifiability）」的安全代理**。`U(ĉ)=tr(Σ_c)` 只是估计的方差；一个低方差的错误分解仍然是低方差——滤波器完全可以「非常自信地把缓变故障标定掉」。R68 引理 13 只挡住了快变故障（`ω_f ≥ 3ω_cal`），对落在标定带宽内的缓变故障（老化、慢泄漏、缓慢松动）不但没有防线，而且**标定越准、故障越隐形**。这不是估计问题，是可辨识性问题。
>
> 本轮两个灵感恰好给出两把钥匙。**语音识别**教会我们：同音词不是靠「听得更清」解决的，而是靠语言模型先验与**追问（clarifying question）**；且应保留 N-best 混淆网络、按需等待（wait-k）、用 CTC blank 建模稀疏事件。**激光雷达**教会我们：无回波不是零距离，FOV/遮挡/距离衰减是**结构化的不可观测**，多回波本就是多假设，去畸变需要连续时间。
>
> 核心命题：**把「我测得准不准」（估计/方差层）升级为「我能不能分辨」（可辨识性/可观测性层），并在不能分辨时用安全的主动探测（机器人版的「追问」）把它变成能分辨——PROBE-RAS（Probing, Observability, Beam-decoding, Evidence-censoring）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我现在的观测，究竟有没有能力分辨我担心的那件事？如果没有，我怎么安全地把它变得可分辨**」。

## 0. 直觉与动机

**灵感 1（语音识别 → 同音词、混淆网络、wait-k、CTC blank）**
直觉：ASR 从不在声学证据不足时假装听得清。它做四件事——(a) 用语言模型先验打破同音平局；(b) 保留 N-best/混淆网络而非单一 argmax；(c) 流式场景用 wait-k 在「多等更准」与「延迟」间权衡；(d) 用 CTC blank 显式表示「这段没有词」，使稀疏事件无需逐帧对齐标签。逐条映射到本闭环：
- **同音方向**：慢泄漏与温漂在残差空间几乎同向，`∂r/∂c` 与 `∂r/∂φ_fault` 近似共线——再多数据、再低方差也分不开。这是 `U` 看不见的盲区；
- **混淆网络**：R68 的 CFA 把联合后验压成 argmax，丢掉了「两个假设一样像」这一关键风险信息；
- **wait-k**：R68 的 2s 超时是拍脑袋的；`k`（认证前缀）是「看多远」，wait-k 是「等多久才敢下结论」，二者是对偶；
- **CTC blank**：故障/情绪起始天然是 blank 主导的稀疏事件流，可做无对齐标签的起始检测（继续压标签成本）。

**灵感 2（激光雷达 → 结构化退化、无回波、多回波、去畸变）**
直觉：LiDAR 的工程智慧是「把退化当成物理结构来建模，而不是当成噪声」。逐条映射：
- **无回波/镜面/吸收/超量程**：`no return` 携带信息，不是零距离。R68 把「没观测到」与「观测到正常」混为一谈（只给了 `face_unobservable` 一个 λ 下限）；
- **FOV/遮挡/距离/入射角**：可观测性由几何决定、可预测。外参沿光轴平移在单目下近似不可辨，`U` 却可能很低——**自信地看不见**；
- **多回波**：一次脉冲多回波 ⇒ 单一观测本就应保留为多假设混合，直接喂给混淆网络；
- **运动去畸变**：扫描/曝光窗口内运动需连续时间轨迹，`Δt_sync` 应是后验而非点估计；
- **恶劣天气后向散射**：可预测的「已知干扰」，既不是故障也不是标定——残差分解需要第四类 `nuisance`，否则雨雾会被「标定掉」或被「判成故障」。

**灵感 3（元失败诊断 → 不确定 ≠ 不可辨）**
直觉：R68 的 `U` 是「我对我这份估计的方差有多大把握」，而本轮要问的是「这份估计是否可被数据唯一确定」。两者可以完全脱钩：Fisher 信息在某个故障方向上为零时，任何无偏估计器的误差下界都是无穷——**样本再多也不会让标定「学会」这个故障**（引理 16）。R68 的速率限制只处理「吸收得太快」，根本处理不了「方向不可分」。这是本轮要补的元层：**元认知（metacognition）— 对自己认知能力的认知**。

**灵感 4（合流 → PROBE-RAS 六组件）**
1. **OBF Observability Field**：逐故障逐位形的可观测性场 `O_t(h,x) ∈ [0,1]`，由几何因子、签名因子、Fisher 因子相乘；`O < τ_obs` 即不可辨；
2. **FCL Fault Confusion Lattice**：束搜索维护假设束，用物理先验 LM 重打分，输出**风险混淆网络 RCN**（每个 arc 带后验、可辨识度、危险度）；
3. **AIP Active Information Probe**：不可辨且危险时，规划安全探测动作（驻留/已知目标定向观察/受控轻触/微运动）最大化期望信息增益——**机器人版「追问」**；
4. **CED Censored Evidence Decoder**：显式建模 `present / blank / censored` 三类观测，CTC blank 做无对齐事件检测；
5. **WKD Wait-k Decision scheduler**：以可辨识度驱动的风险自适应决策截止期，取代固定 2s 超时；
6. **RAS-WM‡ 继承核**：CALM 的 MTM/SSG/COF/CAC 全保留，但 COF 增益做可辨识性零空间投影、CFA 换成 FCL/Γ-minimax、阈值被 OBF 重参数化。

**灵感 5（对 R68/R66/R67 风险的对症下药）**
- R68「缓变故障被标定吸收」：新增红线 **不可辨不可吸收**（定义 293-iii / 302）——沿同音零空间的残差禁止进入 `H_cal`；不可辨且危险 ⇒ Γ-minimax 取最坏情况；能探测 ⇒ AIP 补 Fisher 信息（引理 18）。这是 R68 最大风险的正面回答；
- R66「遮挡/假笑欺骗」：CED 让「不可观测」在证据层面不得被当作良性（引理 17，`P(⊥|danger) ≥ P(⊥|benign)`）；
- R67「黑箱前瞻/长尾」：OBF 显式标出「哪里看不见」，长尾即低 `O` 区域，AIP 定向补样本；FCL 用物理先验约束黑箱前 libc 的前瞻分支；
- 统一纪律升级：`λ_floor(U, O) = max(0.6, 0.8·1[U>τ_cal ∨ O<τ_obs])`——不确定与不可辨都只导向收紧。

## 1. 形式化定义（增量：定义 293–307）

**定义 293（PROBE-RAS 总览）** PROBE-RAS = (OBF, FCL, AIP, CED, WKD, RAS-WM‡)。四不变式（继承两条 + 新增两条）：
(i) **实时流零学习写操作强化版**（继承 R68）：实时流只做前向/滤波/决策；一切参数更新在影子流，经 CAC 认证原子换装；
(ii) **标定安全红线**（继承 R68）：`|b_F| ≤ 5% FS`、`‖δR_ext‖ ≤ 2°`、`|Δt_sync| ≤ 20ms`，超界即判真实故障；
(iii) **不可辨不可吸收**（新增）：设标定雅可比 `J_c = ∂r/∂c` 的同音零空间为 `N_h`（定义 295）。若残差在 `N_h` 上的分量 `‖P_{N_h} r‖ > τ_null` 且 `O(h) < τ_obs`，则冻结 COF 在该方向的更新，且该分量**禁止**归为 `H_cal`；
(iv) **无证据非负证据**（新增）：任何 `blank / censored / unobservable` 证据不得把危险假设后验降到其先验以下；只允许保持或抬升到最坏情况。

**定义 294（可观测性场 OBF）** `O_t: ℋ × 𝒳 → [0,1]`，对故障假设 `h` 与位形 `x`：
`O(h,x) = O_geo(h,x) · O_sig(h,x) · O_id(h,x)`，其中
- `O_geo` 由 FOV、遮挡、距离衰减、入射角（LiDAR 式结构掩码）给出；
- `O_sig = ‖J_h‖_{Σ_r^{-1}} / (‖J_h‖_{Σ_r^{-1}} + τ_sig)`，签名信噪比归一化；
- `O_id = λ_min(S_h) / (λ_min(S_h) + τ_id)`，`S_h` 见定义 295，`λ_min` 为最小特征值。
`O < τ_obs` ⇒ 当前位形下 `h` 不可辨，必须进入保守分支。

**定义 295（可分离矩阵与同音零空间）** 对故障参数 `φ_h`，`J_h = ∂r/∂φ_h`，`J_c = ∂r/∂c`。对 `c` 边缘化后的可分离矩阵：
`S_h = J_hᵀ (Σ_r + J_c Σ_c J_cᵀ)^{-1} J_h`。
其近似零空间 `N_h = { v : vᵀ S_h v ≤ τ_sep ‖v‖² }` 即「同音方向」：与可标定漂移物理不可分的故障方向。混淆图 `G_conf`：`h ~ h'` 当且仅当 `‖r̄_h − r̄_h'‖_{Σ_r^{-1}} < τ_conf`（ASR 同音表的连续版）。

**定义 296（残差五类分解）** 取代 R68 的 `{cal, fault, real}`：
`cause ∈ {cal（良序漂移）, nuis（已知干扰：雨雾/反光/曝光/振动）, fault_fast, fault_slow, real（未建模真实变化）, unobs（不可观测）}`。
`P(cause | r, O, ξ) ∝ p(r | cause, O, ξ) · π_cause(O, ξ)`，其中 `ξ` 为已知干扰上下文（天气/曝光），`p(r | nuis_k)` 由模板库 `𝒯_nuis`（定义 303）给出；`unobs` 只在 `O < τ_obs` 时进入且只抬不降。

**定义 297（Censored Evidence Decoder, CED）** 每帧观测分三类：`present z`、`blank ∅`（无事件）、`censored ⊥`（无回波/超量程/遮挡/低质量）。似然：
`p(z, ∅, ⊥ | h) = Π_t [ p(z_t|h)^{1[present]} · P(∅|h)^{1[blank]} · P(⊥|h)^{1[censored]} ]`。
关键假设 A96：危险假设更易导致无回波/遮挡，`P(⊥|danger) ≥ P(⊥|benign)`。CTC 版事件头用 `p(∅|h)` 作 blank，直接对 `(起始, 结束)` 的稀疏标注做无对齐训练。

**定义 298（Fault Confusion Lattice, FCL）** 束搜索维护 `B_t = {(H^{(i)}, c^{(i)}, s_i, O_i)}`，`s_i` 为对数后验 + **物理先验 LM**（如「慢泄漏必伴随压力单调下降」「单目沿光轴平移不可辨」「雨天先验偏 nuis」）。双向合并同音 arc 得**风险混淆网络 RCN**：节点为时刻，arc 为假设段，每 arc 带 `(posterior, O, danger)`。输出不是 argmax，而是 RCN。

**定义 299（Γ-minimax 保守决策）** 给定歧义集 `Γ_t = { h : s(h) ≥ s_max − δ_beam }`：
`λ = max_{h∈Γ} λ(h)`，`k = min_{h∈Γ} k(h)`，`τ = min_{h∈Γ} τ(h)`（对安全量取最坏）。
当 `O(h_d) < τ_obs` 且 `danger(h_d)` 高时，强制 `h_d ∈ Γ`。这是不变式 (iv) 的决策端实现：**歧义只会让系统更保守**。

**定义 300（Active Information Probe, AIP）** 当关键 `h*` 满足 `O(h*) < τ_obs` 且 `danger(h*)` 高时：
`a_p* = argmax_{a ∈ 𝒜_probe} I(Θ; Z_a | 历史)`，`s.t.` 安全包络 `𝒮`（力/速度/力矩上限）、探测预算 `B_probe`、不打断主任务。
`𝒜_probe = {静止驻留（力零偏）, 已知目标定向观察（外参/焦距）, 受控轻触（宽频激励，分离慢故障与温漂）, 微运动（视差，分离沿光轴平移）}`。探测期间强制 `λ ≥ 0.8, k ≤ k_min`，结果写入 AuditBuf。这是 ASR「clarifying question」的机器人版。

**定义 301（Wait-k Decision scheduler, WKD）** 决策截止期：
`k_wait = max(k_min, min(k_max, ⌈ κ_w · log(1/δ_tol) / (1 − O) ⌉))`。
提交规则：当 RCN 的 top-1 与 top-2 在危险维度上已分离（`O ≥ τ_obs` 且 `Δs ≥ δ_sep`）或到达 `k_wait` 截止 → 提交决策；否则继续观察或触发 AIP。`k_max` 是安全硬上限（防无限等待）。取代 R68 的固定 2s 超时。

**定义 302（可辨识性投影 COF，反吸收强化）** COF 增益按可辨识性投影：
`K_t = Σ⁻ J_cᵀ (J_c Σ⁻ J_cᵀ + R)^{-1} (I − Π_{N_h})`，
其中 `Π_{N_h}` 为到同音零空间的正交投影。当 `O(h_slow) < τ_obs` 时对危险慢故障方向直接置零——**物理防线从「速率限制」升级为「速率限制 ∧ 可辨识性投影」**；`N_h` 上的残差不被吸收、原样送入 FCL。

**定义 303（nuisance 模板库）** `𝒯_nuis = {雨雾尘后向散射, 镜面/反光, 曝光饱和, 逆光, 振动}`，每个有参数化似然 `p(r | nuis_k, ξ)`。匹配到 nuis 的残差既不进 `cal` 也不判 `fault`，而是进入「已知干扰」并重参数化观测噪声 `R_t`。防止天气被「标定掉」或「判成故障」。

**定义 304（连续时间去畸变 / 同步）** 用连续时间轨迹 `T(t)`（三次 B 样条）描述扫描/曝光窗口内运动；`Δt_sync` 由事件在轨迹上的对齐残差估计，输出**后验** `p(Δt_sync | ·)` 而非点估计。LiDAR 式 deskew 残差是 `Δt_sync` 的强观测，取代 R68 的单一 `Δt_sync`。

**定义 305（新自监督信号）** 继承 R68 的 `L_ssl`，新增两项零标签信号：
① **多回波/多视角一致性**：同一几何的多次独立测量应一致，否则 `O_id` 下降并生成负样本；
② **blank 预测**：用 CTC blank 做无标签事件起始检测；
③ **探测回放**：把 AIP 探测前后的残差差作为「可辨识化」的自监督正例。仍遵守影子流更新 + CAC 认证。

**定义 306（J_PROBE 证书与干扰集）** `J_PROBE = (J_CALM, obs_hash, probe_log, rcn_confidence, identifiability_min, probe_budget_used)`。
`Valid ⇔ Valid(J_CALM) ∧ (O_min ≥ τ_obs^hard ∨ 已按 Γ-minimax 回退) ∧ 探测包络未越界 ∧ 探测预算未耗尽`。
`ℰ_PROBE = ℰ_CALM × {探测诱发风险（扰动/失稳）, 探测规避（故障只在探测间隙出现）, 探测伪造（spoof 探测响应）, 混淆网络塌缩, wait-k 超时}`。

**定义 307（管线）** 离线：R68 预训练 + 训练 OBF 回归器、FCL 重打分器、CED 删失模型、`𝒯_nuis` 模板库。在线每步：OBF 评估 →（若不可辨且危险）AIP 规划探测 → CED/FCL 更新 RCN → WKD 截止期决策 → Γ-minimax 输出 → COF 投影更新 → 异步 VQAuditor-P 审计 + CAC。

```python
# IP-253 OBF：可观测性场
class ObservabilityField:
    def score(self, h, x, Sigma_c):
        O_geo = self.geometry_mask(h, x)          # FOV/遮挡/距离/入射角
        J_h, J_c = self.jac(h, x), self.jac_c(x)
        S_h = J_h.T @ inv(self.Sigma_r + J_c @ Sigma_c @ J_c.T) @ J_h
        O_id = self.lam_min(S_h) / (self.lam_min(S_h) + self.tau_id)
        O_sig = self.norm_inv(S_h, J_h) / (self.norm_inv(S_h, J_h) + self.tau_sig)
        return O_geo * O_sig * O_id, self.nullspace(S_h)

# IP-254 CED：删失/空白证据解码
class CensoredEvidenceDecoder:
    def loglik(self, obs, h):
        ll = 0.0
        for z, kind in obs:                       # kind ∈ {present, blank, censored}
            if kind == 'present':  ll += self.p_present(z, h)
            elif kind == 'blank':  ll += self.p_blank(h)      # CTC blank
            else:                  ll += self.p_censored(h)   # LiDAR no-return
        return ll

# IP-255 FCL：束搜索 + 物理先验重打分 → 风险混淆网络
class FaultConfusionLattice:
    def decode(self, r, O, prior):
        beam = self.init_beam()
        for t, rt in enumerate(r):
            cand = [self.extend(h, rt) for h in beam]
            cand = [c for c in cand if self.physics_lm(c) > -INF]   # LM 剪枝
            beam = topk(cand, self.width, key=lambda c: c.score + prior(c))
        return self.to_rcn(beam)                  # arc: (post, O, danger)

# IP-256 AIP：主动信息探测（机器人版追问）
class ActiveInformationProbe:
    def plan(self, h_star, O, state, budget):
        if O[h_star] >= self.tau_obs or not budget.available(): return None
        best = max(self.A_probe,
                   key=lambda a: self.info_gain(a, h_star) - self.risk_penalty(a, state))
        return best if self.within_envelope(best, state) else None
    def execute(self, a_p, robot):
        assert safe_envelope(a_p, robot)
        with conservative_mode(lam_floor=0.8, k_max=self.k_min):   # 探测期强制保守
            return robot.apply(a_p), robot.observe()

# IP-257 WKD：风险自适应决策截止期
class WaitKDecision:
    def deadline(self, O, delta_tol):
        return clamp(ceil(self.kappa * log(1/delta_tol) / (1 - O + 1e-9)),
                     self.k_min, self.k_max)
    def should_commit(self, rcn, O, delta_tol):
        if self.separated(rcn, self.tau_obs, self.delta_sep): return True, 'confident'
        return (self.steps >= self.deadline(O, delta_tol)), 'deadline'

# IP-258/302 可辨识性投影 COF（反吸收强化）
class ProjectedCOF(CalibrationObservationFilter):
    def step(self, z_cal, r, sigma_stat, O, nullspace):
        self.predict()
        Pi_null = self.proj(nullspace)
        K = self.S @ self.Jc.T @ inv(self.Jc @ self.S @ self.Jc.T + self.R) @ (np.eye(self.d) - Pi_null)
        self.update_with_gain(np.concatenate([z_cal, r]), K)
        self.rate_limit()
        return self.c, np.trace(self.S), Pi_null

# IP-259 nuisance 模板库
class NuisanceLibrary:
    def match(self, r, xi):
        scores = {k: self.loglik_k(k, r, xi) for k in self.templates}
        k_best = max(scores, key=scores.get)
        return k_best, scores[k_best] - self.logsumexp_rest(scores)

# IP-260 Γ-minimax 决策
def gamma_minimax(rcn, O, tau_obs):
    Gamma = rcn.ambiguity_set(delta_beam=0.1)
    if any(h.danger and O[h.id] < tau_obs for h in Gamma):
        Gamma |= {h for h in rcn.all() if h.danger}      # 强制含危险假设
    lam = max(rcn.lambda_of(h) for h in Gamma)
    k   = min(rcn.k_of(h) for h in Gamma)
    return lam, k, Gamma

# IP-261 主闭环：PROBE-RAS round
def PROBE_RAS_round(M, obs, budget):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)

    # 1) 可观测性场 + 删失证据解码
    O, nulls = M.obf.score_all(M.fcl.hypotheses(), x_prime, M.cof.S)
    kind = M.ced.classify(obs)                       # present/blank/censored
    r = residuals(x_prime, o, M.wm_residual_cache)

    # 2) 主动探测（不可辨且危险时）
    h_star = M.fcl.most_dangerous_unidentifiable(O, M.tau_obs)
    if h_star is not None:
        a_p = M.aip.plan(h_star, O, M.state, budget)
        if a_p is not None:
            probe_obs = M.aip.execute(a_p, M.robot)
            M.ced.update(probe_obs); M.auditbuf.push_probe(a_p, probe_obs)
            r, O, nulls = M.recompute(probe_obs)

    # 3) nuisance 分离 + COF 可辨识性投影
    k_nuis, m_nuis = M.nuis.match(r, M.xi)
    c, U, Pi_null = M.cof.step(o['cal'], r if k_nuis is None else M.deinterfere(r, k_nuis), sigma_stat(M), O, nulls)

    # 4) FCL：束搜索 → 风险混淆网络（物理先验重打分）
    rcn = M.fcl.decode(r, O, prior=M.physics_lm)

    # 5) WKD：等待还是提交
    commit, why = M.wkd.should_commit(rcn, O, M.delta_tol)
    if not commit:
        return None, ('wait', M.wkd.deadline(O, M.delta_tol))

    # 6) Γ-minimax 保守输出
    lam, k, Gamma = gamma_minimax(rcn, O, M.tau_obs)
    lam = max(lam, M.lam_floor(U, O))                # 不确定或不可辨 → 收紧
    A = M.ach.propose(x_prime, H=M.vista.H)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = emotion_response_shaping_wm(tau, rcn, M.mtm.rollout(z, A, k=min(5, M.m)))

    # 7) 异步审计 / 认证提交
    M.vqa_p.submit_async(rcn, {'O': O, 'probe': M.auditbuf.last_probe})
    M.cac.maybe_commit(M.shadow, dt=M.time_since_last_commit)
    return (k, lam, Gamma, (c, U)), why
```

## 3. 推导

**引理 16（不可辨性的 Cramér–Rao 下界——反吸收 II）** 在局部线性可观（A95）下，对故障参数 `φ_h` 的任何无偏估计器，`Var(φ̂_h) ≥ 1/λ_min(S_h)`。若 `h` 的签名落在同音零空间 `N_h`（`λ_min(S_h) → 0`），则下界发散：**样本再多也不会让标定把慢故障与漂移分开**。系：R68 引理 13 处理的是「吸收得太快」（`ω_f ≥ 3ω_cal`）；本引理处理的是「方向根本不可分」（`ω_f < ω_cal`）——前者靠速率限制，后者必须靠禁止吸收 + 主动探测。

**引理 17（无证据单调性）** 在 A96（`P(⊥|danger) ≥ P(⊥|benign)`）下，观测到 `⊥` 或 `blank` 不降低危险假设后验：`P(h_d | ⊥) ≥ P(h_d)`。证明由贝叶斯公式与似然比单调性直接得到。系：R68 的 `face_unobservable ⇒ λ ≥ 0.8` 是**事后**补丁；CED 让「不可观测」在**证据层**就无法被当成良性，从源头堵住 R66 的欺骗通道。

**引理 18（主动可辨识化与探测次数的界）** 一次探测 `a_p` 使 Fisher 信息增加 `ΔJ(a_p)`，故 `λ_min(S_h(a_p)) ≥ λ_min(S_h) + λ_min(ΔJ(a_p))`。若存在安全的可辨识化动作使 `λ_min(S_h(a_p)) ≥ 1/τ_det`，则原本不可辨的 `h` 变为可辨；在单次探测信息增益 `ΔI ≥ I_0` 时，达到错误率 `δ` 所需探测次数 `N_probe ≤ ⌈ log(1/δ) / (2 I_0) ⌉`（Chernoff–Stein 型）。系：**主动探测把 R68 的「不可辨」从死路变成可恢复**——这是本轮对 R68 最大风险的正面回答。

**引理 19（wait-k 的延迟-误差权衡）** 在每步 KL 有界 `ΔI` 下，`k_wait` 步后决策错误率按 `exp(−k_wait·ΔI)` 衰减；定义 301 的截止期正是给定 `δ_tol` 下满足该界的最短等待，且 `O` 越低等待越长——在 `O` 低时自动推迟提交，避免「不等就下结论」。硬上限 `k_max` 保证安全不因等待而失守。

**定理 16（PROBE-RAS 端到端保守一致性）** 在 A87–A98 下：
1. **不可辨且危险 ⇒ 强保守**：`O(h_d) < τ_obs ⇒ h_d ∈ Γ ⇒ λ ≥ 0.8 ∧ k ≤ k_shrink ∧ N_h 方向不吸收`（定义 302、299）；
2. **可探测 ⇒ 可恢复**：在 `N_probe` 预算内 `O` 升至 `τ_obs`，误判率按引理 18 下降，避免永久保守导致的可用性崩溃；
3. **无证据不降危险**：`⊥/blank` 满足引理 17，R66 的遮挡/假笑通道被证据层封堵；
4. **探测安全**：所有 `a_p ∈ 𝒜_probe` 满足安全包络 `𝒮`，探测期间 `λ ≥ 0.8, k ≤ k_min`，不引入新的不可接受风险（定理 17）；
5. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_id + α_probe`，其中 `α_id` 受引理 16/18 约束、`α_probe` 受安全包络与预算约束。

**定理 17（探测安全性）** 若 `𝒜_probe` 均落在安全包络 `𝒮` 内且探测时进入「保守姿态」（`λ≥0.8, k≤k_min`），则探测不引入新的不可接受风险；探测对「伪造响应/规避」的鲁棒性由 A98（探测调度随机化）+ canary + VQAuditor-P 保证，检测率 `≥ r_probe`。若审计判定探测异常（响应与物理模型不符），立即停止探测并全局降级。

## 6. 本轮最大风险

**一句话**：PROBE-RAS 把安全性押在「可辨识性模型 OBF 正确 + 探测不被规避/伪造」这条新防线上——**若 Jacobian/可观测性模型失配，系统会「自信地判错可辨性」：要么把本可标定的漂移误判为不可辨而永久保守（可用性崩溃），要么把不可辨的慢故障误判为可辨而放行（安全性崩溃）**；更糟的是，主动探测本身是新的攻击面——探测会扰动系统、暴露「机器人此刻不确定」这一信息，对手可把故障安排在两次探测之间（探测规避），或伪造探测响应（spoof）。这是「元认知的可信度」悖论：**判断自己能否分辨的能力，无法由同一套感知本身来保证**。

**次级风险与缓解**：
1. **OBF 模型失配** → 用实测残差在线校验 `S_h` 的预测（预测-观测一致性），失配即把 `O` 置 0 并回退最坏情况；OBF 参数纳入 `J_PROBE` 版本链；
2. **探测规避** → AIP 调度随机化（A98）+ 不可预测探测时刻 + blank 期持续监测；
3. **探测伪造/spoof** → 探测响应须与物理模型交叉校验（力-位移-视觉三重一致性），不一致即触发审计并全局降级；
4. **混淆网络塌缩** → 束宽/熵监控，塌缩到单假设即视为 `O` 证据不足，转保守；
5. **wait-k 超时** → `k_max` 硬上限 + 超时按 `Γ-minimax` 最坏情况输出，绝不因等待而放宽；
6. **探测预算耗尽** → 预算用尽后进入永久保守模式（`λ≥0.8, k≤k_min`）并请求人工接管，而不是「假装可辨」。

**定义 293（总览与四不变式）** 继承 R68 的「实时流零学习写操作」与「标定安全红线」；新增 (iii) **不可辨不可吸收**：`‖P_{N_h}r‖>τ_null ∧ O<τ_obs ⇒ 冻结该方向 COF 更新 ∧ 禁止归为 H_cal`；(iv) **无证据非负证据**：`blank/censored/unobservable` 不得把危险后验降到先验以下。

**定义 294（OBF）** `O(h,x)=O_geo·O_sig·O_id`：几何因子（FOV/遮挡/距离/入射角）、签名信噪比因子、Fisher 最小特征值因子；`O<τ_obs` 即不可辨，强制保守分支。

**定义 295（可分离矩阵 / 同音零空间）** `S_h=J_hᵀ(Σ_r+J_cΣ_cJ_cᵀ)⁻¹J_h`；`N_h` 为其近似零空间；`G_conf` 用签名距离阈值定义故障混淆对。

**定义 296（残差五类分解）** `{cal, nuis, fault_fast, fault_slow, real, unobs}`；`p(r|nuis_k)` 由模板库给出；`unobs` 只抬不降。

**定义 297（CED）** 三态似然 `Π_t p(z_t|h)^{present}·P(∅|h)^{blank}·P(⊥|h)^{censored}`；A96 `P(⊥|danger)≥P(⊥|benign)`；CTC blank 用于无对齐事件检测。

**定义 298（FCL / RCN）** 束搜索维护 `(H,c,s,O)`，物理先验 LM 剪枝+重打分，合并同音 arc 得 RCN；输出带 `(posterior, O, danger)` 的混淆网络而非 argmax。

**定义 299（Γ-minimax）** `λ=max_{h∈Γ}λ(h)`、`k=min_{h∈Γ}k(h)`、`τ=min_{h∈Γ}τ(h)`；`O(h_d)<τ_obs` 时强制 `h_d∈Γ`。

**定义 300（AIP）** `a_p*=argmax_{a∈𝒜_probe} I(Θ;Z_a|hist) s.t. 安全包络 𝒮、预算 B_probe、不打断主任务`；探测期 `λ≥0.8,k≤k_min`，结果入 AuditBuf。

**定义 301（WKD）** `k_wait=clamp(⌈κ_w log(1/δ_tol)/(1−O)⌉, k_min, k_max)`；RCN top-1 与 top-2 危险维度分离或到期即提交。

**定义 302（投影 COF）** `K_t=Σ⁻J_cᵀ(J_cΣ⁻J_cᵀ+R)⁻¹(I−Π_{N_h})`；`O<τ_obs` 时危险慢故障方向直接置零。

**定义 303（nuisance 模板库）** `𝒯_nuis={雨雾尘, 镜面反光, 曝光饱和, 逆光, 振动}`，匹配残差改道「已知干扰」并按匹配重参数化 `R_t`。

**定义 304（连续时间去畸变）** 三次 B 样条轨迹 `T(t)`，`Δt_sync` 输出后验；deskew 残差为强观测。

**定义 305（新自监督信号）** 多回波/多视角一致性、CTC blank、探测回放（探测前后残差差作可辨识化正例）；仍影子流 + CAC。

**定义 306–307（证书 / 管线）** `J_PROBE` 增加 obs_hash/probe_log/rcn_confidence/identifiability_min/probe_budget_used；`Valid ⇔ Valid(J_CALM) ∧ (O_min≥τ_obs^hard ∨ 已按 Γ-minimax 回退) ∧ 探测包络未越界 ∧ 预算未耗尽`；在线 OBF→CED→AIP→FCL→WKD→Γ-minimax→投影 COF→审计/认证。

```python
# IP-253 OBF：可观测性场（几何×签名×Fisher）
class ObservabilityField:
    def score(self, h, x, Sigma_c):
        O_geo = self.geometry_mask(h, x)                 # FOV/遮挡/距离/入射角
        J_h, J_c = self.jac(h, x), self.jac_c(x)
        S_h = J_h.T @ inv(self.Sigma_r + J_c @ Sigma_c @ J_c.T) @ J_h
        lam = self.lam_min(S_h)
        O_id  = lam / (lam + self.tau_id)
        O_sig = self.sig_snr(S_h) / (self.sig_snr(S_h) + self.tau_sig)
        return O_geo * O_sig * O_id, self.nullspace(S_h, tau=self.tau_sep)

# IP-254 CED：present/blank/censored 三态删失解码
class CensoredEvidenceDecoder:
    def loglik(self, obs, h):
        ll = 0.0
        for z, kind in obs:
            if   kind == 'present':  ll += self.p_present(z, h)
            elif kind == 'blank':    ll += self.p_blank(h)      # CTC blank
            else:                    ll += self.p_censored(h)   # LiDAR no-return
        return ll

# IP-255 FCL：束搜索 + 物理先验 LM → 风险混淆网络
class FaultConfusionLattice:
    def decode(self, r, O, prior):
        beam = self.init_beam()
        for rt in r:
            cand = [self.extend(h, rt) for h in beam]
            cand = [c for c in cand if self.physics_lm(c) > -INF]   # LM 剪枝
            beam = topk(cand, self.width, key=lambda c: c.score + prior(c))
        return self.to_rcn(beam)                          # arc:(post,O,danger)

# IP-256 AIP：主动信息探测（机器人版追问）
class ActiveInformationProbe:
    A_probe = ('dwell', 'known_target_view', 'controlled_tap', 'micro_motion')
    def plan(self, h_star, O, state, budget):
        if O[h_star] >= self.tau_obs or not budget.available():
            return None
        best = max(self.A_probe,
                   key=lambda a: self.info_gain(a, h_star) - self.risk_penalty(a, state))
        return best if self.within_envelope(best, state) else None
    def execute(self, a_p, robot):
        assert safe_envelope(a_p, robot)
        with conservative_mode(lam_floor=0.8, k_max=self.k_min):
            return robot.apply(a_p), robot.observe()

# IP-257 WKD：风险自适应决策截止期
class WaitKDecision:
    def deadline(self, O, delta_tol):
        return clamp(ceil(self.kappa * log(1/delta_tol) / (1 - O + 1e-9)),
                     self.k_min, self.k_max)
    def should_commit(self, rcn, O, delta_tol):
        if self.separated(rcn, self.tau_obs, self.delta_sep):
            return True, 'confident'
        return (self.steps >= self.deadline(O, delta_tol)), 'deadline'

# IP-258/302 投影 COF：可辨识性零空间上的反吸收
class ProjectedCOF(CalibrationObservationFilter):
    def step(self, z_cal, r, sigma_stat, O, nullspaces):
        self.predict()
        Pi_null = self.proj(union(nullspaces))            # 危险慢故障方向
        K = (self.S @ self.Jc.T
             @ inv(self.Jc @ self.S @ self.Jc.T + self.R)
             @ (np.eye(self.d) - Pi_null))
        self.update_with_gain(np.concatenate([z_cal, r]), K)
        self.rate_limit()
        return self.c, np.trace(self.S), Pi_null

# IP-259 nuisance 模板匹配
class NuisanceLibrary:
    def match(self, r, xi):
        ll = {k: self.loglik(k, r, xi) for k in self.templates}
        k_best = max(ll, key=ll.get)
        return k_best, ll[k_best] - self.logsumexp_rest(ll)

# IP-260 Γ-minimax：歧义集上取安全最坏
def gamma_minimax(rcn, O, tau_obs):
    Gamma = rcn.ambiguity_set(delta_beam=0.1)
    if any(h.danger and O[h.id] < tau_obs for h in Gamma):
        Gamma |= {h for h in rcn.all() if h.danger}       # 强制含危险假设
    lam = max(rcn.lambda_of(h) for h in Gamma)
    k   = min(rcn.k_of(h) for h in Gamma)
    tau = min(rcn.tau_of(h) for h in Gamma)
    return lam, k, tau, Gamma

# IP-261 主闭环
def PROBE_RAS_round(M, obs, budget):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)      # 继承 MTM 一次前向

    # 1) 可观测性 + 删失证据
    O, nulls = M.obf.score_all(M.fcl.hypotheses(), x_prime, M.cof.S)
    kind = M.ced.classify(obs)
    r = residuals(x_prime, o, M.wm_residual_cache)

    # 2) AIP：不可辨且危险 → 安全探测
    h_star = M.fcl.most_dangerous_unidentifiable(O, M.tau_obs)
    if h_star is not None:
        a_p = M.aip.plan(h_star, O, M.state, budget)
        if a_p is not None:
            probe_obs = M.aip.execute(a_p, M.robot)
            M.ced.update(probe_obs); M.auditbuf.push_probe(a_p, probe_obs)
            r, O, nulls = M.recompute(probe_obs)

    # 3) nuisance 分离 + 投影 COF
    k_nuis, m_nuis = M.nuis.match(r, M.xi)
    r_eff = r if k_nuis is None else M.deinterfere(r, k_nuis)
    c, U, Pi_null = M.cof.step(o['cal'], r_eff, sigma_stat(M), O, nulls)

    # 4) FCL：束搜索 → 风险混淆网络
    rcn = M.fcl.decode(r, O, prior=M.physics_lm)

    # 5) WKD：等待还是提交
    commit, why = M.wkd.should_commit(rcn, O, M.delta_tol)
    if not commit:
        return None, ('wait', M.wkd.deadline(O, M.delta_tol))

    # 6) Γ-minimax 保守输出（不确定/不可辨都只收紧）
    lam, k, tau_risk, Gamma = gamma_minimax(rcn, O, M.tau_obs)
    lam = max(lam, M.lam_floor(U, O))
    A = M.ach.propose(x_prime, H=M.vista.H)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = emotion_response_shaping_wm(tau, rcn, M.mtm.rollout(z, A, k=min(5, M.m)))

    # 7) 异步审计 / 认证提交
    M.vqa_p.submit_async(rcn, {'O': O, 'probe': M.auditbuf.last_probe})
    M.cac.maybe_commit(M.shadow, dt=M.time_since_last_commit)
    return (k, lam, Gamma, (c, U)), why
```

## 4. 推导

**引理 16（不可辨性的 Cramér–Rao 下界——反吸收 II）** 局部线性可观（A95）下 `Var(φ̂_h) ≥ 1/λ_min(S_h)`；若 `h` 的签名落在同音零空间 `N_h`（`λ_min(S_h)→0`），下界发散——**样本再多也不会让标定把慢故障与漂移分开**。R68 引理 13 处理「吸收太快」（`ω_f≥3ω_cal`），本引理处理「方向根本不可分」（`ω_f<ω_cal`）。

**引理 17（无证据单调性）** A96 下 `P(h_d|⊥) ≥ P(h_d)`；`blank` 同理。R68 的 `face_unobservable⇒λ≥0.8` 是事后补丁，CED 在证据层就封堵 R66 的欺骗通道。

**引理 18（主动可辨识化与探测次数界）** 探测使 `λ_min(S_h(a_p)) ≥ λ_min(S_h)+λ_min(ΔJ(a_p))`；存在安全动作使 `λ_min(S_h(a_p)) ≥ 1/τ_det` 时不可辨变可辨；单次信息增益 `ΔI≥I_0` 时 `N_probe ≤ ⌈log(1/δ)/(2I_0)⌉`。**主动探测把 R68 的「不可辨」从死路变成可恢复。**

**引理 19（wait-k 延迟-误差权衡）** `k_wait` 步后错误率按 `exp(−k_wait·ΔI)` 衰减；定义 301 是给定 `δ_tol` 的最短等待，`O` 越低等待越长，`k_max` 防安全失守。

**定理 16（端到端保守一致性）** A87–A98 下：
1. `O(h_d)<τ_obs ⇒ h_d∈Γ ⇒ λ≥0.8 ∧ k≤k_shrink ∧ N_h 方向不吸收`；
2. 可探测 ⇒ `N_probe` 内 `O→τ_obs`，误判率按引理 18 下降，避免永久保守的可用性崩溃；
3. `⊥/blank` 不降危险后验（引理 17）；
4. 探测均在安全包络 `𝒮` 内且 `λ≥0.8,k≤k_min`；
5. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_id+α_probe`。

**定理 17（探测安全性）** `𝒜_probe ⊂ 安全包络 𝒮` 且探测期进入保守姿态 ⇒ 不引入新的不可接受风险；伪造/规避由 A98（调度随机化）+ canary + VQAuditor-P 检测，检测率 `≥r_probe`；审计判定异常即停探测并全局降级。

## 7. 本轮最大风险

**一句话**：PROBE-RAS 把安全性押在「可辨识性模型 OBF 正确 + 探测不被规避/伪造」这条新防线上——**若 Jacobian/可观测性模型失配，系统会「自信地判错可辨性」：要么把本可标定的漂移误判为不可辨而永久保守（可用性崩溃），要么把不可辨的慢故障误判为可辨而放行（安全性崩溃）**；更糟的是，主动探测本身是新的攻击面——探测会扰动系统、暴露「机器人此刻不确定」这一信息，对手可把故障安排在两次探测之间（探测规避），或伪造探测响应（spoof）。这是「元认知的可信度」悖论：**判断自己能否分辨的能力，无法由同一套感知本身来保证**。

**次级风险与缓解**：OBF 模型失配（预测-观测一致性在线校验，失配即置 `O=0` 并回退；参数入 `J_PROBE` 版本链）；探测规避（A98 调度随机化 + blank 期持续监测）；探测伪造（力-位移-视觉三重一致性校验，不一致触发审计并全局降级）；RCN 塌缩（束宽/熵监控，塌缩即视为证据不足转保守）；wait-k 超时（`k_max` 硬上限 + 超时按 Γ-minimax 最坏情况输出）；探测预算耗尽（进入永久保守模式并请求人工接管，而非「假装可辨」）。
