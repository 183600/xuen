# 第 4 轮（灵感驱动研究循环·新灵感二元组第 1 轮；本轮灵感：「联邦学习」×「多机评测」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21+IP-425–430（SDC/CAC/DCL/GIC/HPC+/CFC+），其上承 v20（PCA/CTS/CFC/HPC）与 v19/v17 证书/感知体系。
> 本轮纪律：**标定是分布式估计、评测是统计认证**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 与 v20/v19/v17 全部保留。本轮只做一件事：把 v21 最薄弱的经验参数（ε_loc、κ_c、conformal 分位、类先验）从"单机拍脑袋点估计"升级为**跨机群、隐私保护、拜占庭鲁棒、方向正确的统计置信界**，并用**多机评测**为"放宽保守性"这一动作**赚取**可审计的统计证书。

## 0. 直觉与动机

### 灵感 1（联邦学习 → 标定本身是可以联邦估计、也必须防投毒的资产）
直觉：v21 的全部可靠性压在少数经验参数上——尤其 κ_c（召回下界）与 ε_loc（定位误差界）。单台机器在单一环境采集的标定样本既少又有偏，"合规的缺席幻觉"正是这一点的直接后果。联邦学习的核心不是"把数据集中起来"，而是**只共享充分统计量/模型更新、原始数据不出域**（v21 的 E794 已承诺原始图像零出域），同时**对恶意/漂移客户端鲁棒**（拜占庭容错）、**可隐私放大**（DP/安全聚合）。关键反直觉点：**标定不是一次性离线步骤，而是一个持续被投毒攻击的分布式估计问题**——一个谎报"我什么都检测得到、κ=0.99"的客户端，若被简单平均进全局标定，就能悄悄把整个机群的缺席证书放宽成"杀人许可证"。因此联邦聚合必须**带方向**：召回下界只能取**下置信界（LCB）**、定位误差界只能取**上置信界（UCB）**、conformal 分位只能取保守侧——**让拜占庭客户端在结构上只能把系统推向更保守，而不能推向更激进**。

### 灵感 2（多机评测 → "很多机器"不等于"很多独立证据"）
直觉：v21 的 E771–E800 是单机/单环境的评测，但 v21 的所有可靠性主张（κ_c 下界、CFC+ 拦截相关故障、安全继承）本质是**总体性（population）主张**。多机评测把它变成可认证的统计命题：预注册、分层、标定-评测隔离、分布无关置信界、对抗机群场景、可离线复放的机群审计账本。关键反直觉点（本轮最重要的洞察）：**多机评测的说服力来自"独立"而非"数量"**。若机群共享同一感知盲区（同模型/同厂商/同训练数据），N 台机器会就同一个错误"达成共识"，有效独立样本量 `n_eff = N / (1+(N-1)ρ̄)` 在 ρ̄→1 时坍缩为 1——**多机认证会变成集体幻觉的统计学洗白**。所以多机评测必须显式估计误差相关性 ρ̄，用 n_eff（而非 N）去做置信界与样本量，并在机群同质化时**诚实地拒绝过度认证**。

### 二者如何统一
统一为 **v21 之上的"联邦标定-多机认证层 (Federated Calibration & Certification Layer, FCL)"**：
- **FCP + SMRA** 回答"θ 应该取多少"——隐私保护地交换充分统计量，按安全方向做鲁棒置信界聚合，产出 θ_fed；
- **FAC** 回答"缺席证书凭什么可靠"——用**分层总体召回下置信界**替换 v21 的局部 κ_c 点估计；
- **CFC++** 回答"谁的票算数"——在 CFC+ 的模态多样性之外再加**客户端谱系多样性**与几何一致性隔离；
- **MMCH + FSC** 回答"凭什么相信 θ_fed 在机群上成立"——标定/评测客户端与环境不相交、预注册、分层最差情形、按 n_eff 的分布无关置信界、机群 merkle 审计账本。

共享状态 ζ_sem 扩展为 **ζ_fed2 = ζ_sem ∪ (T_i, θ_fed, ρ̄, n_eff, FSC)**。准入门升级为 **HPC++ = (HPC+, FSC)**，并提供**两种模式**：`CONSERVATIVE`（θ_fed ≼_safe θ_local ⇒ `Exec_v22 ⊆ Exec_v21`，严格继承）与 `CERTIFIED_TIGHTENING`（在隔离的机群外留出集上认证通过后，允许把"过度保守的局部界"换成"更紧但仍有效的总体界"——此时安全主张从"子集"变为"对真实安全集以 ≥1-β 覆盖"，这是本轮真正的研究赌注）。

## 1. 研究问题（轮次升级版）

- **Q1（方向正确的联邦聚合）**：如何形式化参数的安全序 ≼_safe 与安全方向 d_p，使鲁棒聚合 `Agg_safe` 对任意 |B|≤f_max 的拜占庭联盟满足"不安全方向不可被抬升超过 DP 松弛"？鲁棒次序统计量（trimmed/median/Krum）与单侧置信界（LCB/UCB）如何组合，才能同时得到有效覆盖与有界影响？
- **Q2（联邦缺席证书与异质性）**：如何由分层充分统计量导出 κ_{c,s}^{LCB}(1-β) 并把 v21 的 δ_abs 与统计置信 β 做并集（δ_abs+β）？对**未见层**如何用保守地板而非插值？标定与部署非交换（分布漂移）时如何检测并回落？
- **Q3（有效独立样本量与 monoculture）**：ρ̄ 如何估计才不会被机群自身的相关性污染（自证悖论）？n_eff 如何进入 Clopper-Pearson/Hoeffding 的样本量与置信界？当机群是 monoculture 时，认证协议如何**拒绝**签发超出单机证据的结论？
- **Q4（标定-评测隔离与两种模式的治理）**：如何保证 CalClients∩EvalClients=∅、Env_cal∩Env_eval=∅ 且预注册先于留出集访问？CERTIFIED_TIGHTENING 的"放宽额度"如何被多机认证**赚取**、被治理**封顶**（bounded loosening）、并全程可离线复放？

## 2. 设计原则（新增 P37–P39）

**P37 保守方向聚合律（Conservative-Direction Aggregation）**
每个安全关键参数 p 有安全方向 d_p ∈ {↑安全, ↓安全}（κ_c↓、ε_loc↑、conformal 分位↑、先验收紧仅在 intersect 内）。联邦聚合 `Agg_safe` 对 p 取**安全侧单侧置信界**（↓安全取 LCB、↑安全取 UCB），并以鲁棒次序统计量（trimmed/median）与 DP 噪声抑制 |B|≤f_max 的拜占庭联盟。结论：拜占庭客户端在结构上只能把 θ_fed 推向更保守，不能推向更激进。

**P38 标定-评测隔离律（Calibration-Evaluation Isolation）**
联邦标定所用的客户端与环境集合，必须与多机评测所用的客户端与环境集合**不相交**；评测协议（样本量、分层、指标、停止规则）必须先**预注册**再访问留出集。任何评测样本不得回流进标定，反之亦然。违反隔离即认证无效。

**P39 分层最差情形认证律（Stratified Worst-Case Certification）**
机群安全声明 = 各层单侧下界之**最小值**（最差层），并同时报告 pooled 界仅供审计对照；绝不以 pooled 均值替代最差层（抗 Simpson 悖论）。未见层一律用保守地板。置信界样本量一律用 `n_eff = N/(1+(N-1)ρ̄)` 而非 N；ρ̄ 无法被机群内数据无偏估计时，必须引入机群外独立探针并取更保守上界。

## 3. 与基线的接口（两种模式与退化）
- FCP/SMRA 失效 ⇒ 回退 v21 局部标定 θ_local ⇒ 等价 v21；
- FAC 失效（分层数据不足/漂移）⇒ 未知层用保守地板、Cov 收缩 ⇒ 比 v21 更保守；
- CFC++ 谱系多样性不足（单一厂商）⇒ 退回 CFC+（模态多样性）⇒ 等价 v21；
- MMCH 失效（无法隔离/无法估计 ρ̄）⇒ 强制 `CONSERVATIVE` 模式 ⇒ `Exec_v22 ⊆ Exec_v21`；
- 全失效 ⇒ 完全回退 v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ …`（保守模式，引理 168）。
- **两模式安全语义**：`CONSERVATIVE` 维持严格子集继承；`CERTIFIED_TIGHTENING` 只在隔离留出集上以 ≥1-β 认证后生效，其主张是"对真实安全集的覆盖"，**不**声称 ⊆ v21（可能合法更大）。放宽额度有硬上限 Δ_max 且需治理签核（bounded loosening）。
- 联邦层**离线/低频**运行（如 1/小时），只在安全同步点原子切换 θ_fed；控制路径仍 ≤12ms、O(1) 查询，与 v19/v20/v21 不变。

## 4. 预期贡献
1. **方向感知的联邦安全标定**：首次把"标定"建模为可被投毒的分布式估计，给出安全序 ≼_safe 与"拜占庭只能更保守"的结构性保证；
2. **联邦缺席证书**：把 v21 的 κ_c 点估计升级为分层总体 LCB，δ_abs 与 β 并集，直接打击"合规的缺席幻觉"；
3. **有效独立样本量认证**：给出 n_eff 设计效应校正，证明"多机 ≠ 多证据"，并让认证在 monoculture 下**诚实拒绝过度声明**；
4. **标定-评测隔离 + 两模式治理**：把"放宽保守性"从任意调参变成需隔离留出集认证、有硬上限、可审计复放的受控动作；
5. **客户端谱系多样性共识 CFC++**：把 CFC+ 的模态多样性扩展到机群谱系多样性，封堵跨机相关故障与合谋；
6. **HPC++ 与机群审计账本**：把单机证书链扩展为可离线复放的机群 merkle 认证根。

## 5. 本轮最大风险
**一句话**：联邦学习与多机评测会**互为对方的"独立性"背书**，但若整个机群共享同一感知盲区（同模型/同厂商/同训练分布），则 ρ̄ 被机群自身低估、n_eff 被高估为 N，联邦标定与多机评测将彼此印证一个系统性错误的召回下界——**机群用 N 台机器的"共识"为一台机器的盲区签发认证，多机认证沦为集体幻觉的统计学洗白**。

## 1. 关键算法骨架

```python
# 安全方向：+1 = "越大越保守(安全)"；-1 = "越小越保守(安全)"
SAFETY_DIR = {
    "eps_loc":        +1,   # 定位误差界：越大越保守 → UCB
    "kappa_c":        -1,   # 召回下界：越大越危险 → LCB
    "conformal_q":    +1,   # conformal 分位：越大预测集越大越保守 → UCB
    "prior_strength": -1,   # 先验强度：仅在 intersect 内生效，永不扩张（v21 已保证）
}


# IP-431 Federated Calibration Protocol
class FederatedCalibrationProtocol:
    def __init__(self, aggregator, dp_eps=1.0, dp_delta=1e-6, beta=0.01):
        self.agg = aggregator            # SMRA
        self.dp_eps, self.dp_delta = dp_eps, dp_delta
        self.beta = beta

    def local_stats(self, client_data, stratum):
        """本地计算充分统计量，原始样本永不出域（E794 延续）"""
        return SufficientStats(
            err_quantiles=score_conditioned_error_quantiles(client_data),
            recall_counts=recall_trials(client_data),      # (n_i, k_i) 按类
            nonconformity=nonconformity_sketch(client_data),
            prior_moments=class_prior_moments(client_data),
            stratum=stratum,
        )

    def federated_round(self, clients, strata):
        # 1) 安全聚合 + DP：服务器只见到加噪的充分统计量
        noisy = {cid: self._dp_noise(c.local_stats(c.data, c.stratum))
                 for cid, c in clients.items()}
        # 2) 按层、按参数、按安全方向做鲁棒聚合（IP-432）
        theta_fed = {}
        for name in SAFETY_DIR:
            theta_fed[name] = self.agg.aggregate(name, noisy, strata, beta=self.beta)
        return theta_fed          # θ_fed，仅在安全同步点原子切换

    def _dp_noise(self, stats):
        return add_laplace_or_gaussian(stats, eps=self.dp_eps, delta=self.dp_delta)


# IP-432 Safety-Monotone Robust Aggregation
class SafetyMonotoneAggregator:
    def __init__(self, f_max=1/3, min_clients_per_stratum=3):
        self.f_max = f_max
        self.min_per = min_clients_per_stratum

    def aggregate(self, name, stats_by_client, strata, beta):
        # 1) 鲁棒预筛：剔除几何/时序一致性最差的至多 f_max 比例（IP-434 佐证）
        kept = self._trim_inconsistent(stats_by_client, self.f_max)
        out = {}
        for s in strata:
            vals = [st.stratum_estimate(name, s) for st in kept.values()
                    if st.has_stratum(s)]
            if len(vals) < self.min_per:
                out[s] = self._conservative_floor(name)   # 数据不足 → 最保守
                continue
            # 2) 方向正确的单侧置信界 + 层间异质性惩罚
            mu, var_between = robust_mean_var(vals)       # trimmed/median 有界影响
            se = inflated_se(var_between, len(vals))      # 异质性越大 → 界越宽
            d = SAFETY_DIR[name]
            if d > 0:   # 越大越安全 → UCB（对"被压低"的恶意值鲁棒）
                out[s] = mu + t_quantile(1 - beta, len(vals) - 1) * se
            else:       # 越小越安全 → LCB（对"被抬高"的恶意值鲁棒）
                out[s] = mu - t_quantile(1 - beta, len(vals) - 1) * se
        return out

    def _trim_inconsistent(self, stats, f_max):
        # 用跨机几何一致性/时序新鲜度打分，剔除最不一致的至多 ⌊f_max·N⌋ 个
        return trim_by_consistency_score(stats, floor(f_max * len(stats)))

    def _conservative_floor(self, name):
        return CONSERVATIVE_FLOOR[name]   # κ→0, ε_loc→+∞, q_α→最大分位


# IP-433 Federated Absence Certificate（替换 v21 局部 κ_c）
class FederatedAbsenceCertificate:
    def __init__(self, trials, beta=0.01, delta_abs=0.01, rho_bar=1.0):
        self.trials = trials          # trials[cls][stratum] = [(cid, n_i, k_i)]
        self.beta = beta
        self.delta_abs = delta_abs
        self.rho_bar = rho_bar        # 由 IP-436 估计，默认取最保守 1.0

    def recall_lcb(self, cls, stratum):
        if stratum not in self.trials.get(cls, {}):
            return CONSERVATIVE_FLOOR["kappa_c"]      # 未见层 → 保守地板
        tr = self.trials[cls][stratum]
        n_eff = effective_n(len(tr), self.rho_bar)    # 设计效应校正
        k_eff = sum(k for _, _, k in tr)
        return clopper_pearson_lower(k_eff, max(n_eff, 1.0), self.beta)

    def issue(self, cov, cls, stratum, detections, gestures, gic):
        # 手势在场优先条款（v21 引理 158 原样保留）
        if any(gic.is_valid_human_evidence(g) for g in gestures):
            return None, "HUMAN_PRESENT_BY_GESTURE"
        if not any(d.in(cov) for d in detections):
            kappa = self.recall_lcb(cls, stratum)
            # δ_abs 与统计置信并集：总假缺席 ≤ δ_abs + β（引理 164）
            return FAC(cov=cov, kappa_lcb=kappa,
                       delta=self.delta_abs + self.beta), "OK"
        return None, "DETECTION_IN_COV"


# IP-434 Client-Diverse Consensus：CFC+ 之上再加客户端谱系多样性
class ClientDiverseConsensus(CertificateFederatedConsensusPlus):
    MIN_LINEAGES = 2

    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            count_ok = len(votes) >= self.N - self.F
            mods = {v.modality for v in votes.values()}
            lineages = {v.lineage for v in votes.values()}   # 模型/厂商/训练谱系
            if count_ok and len(mods) >= 2 and len(lineages) >= self.MIN_LINEAGES:
                results[key] = self._majority_with_outlier_filter(votes)
            else:
                results[key] = "CI"     # 谱系同质 → 视作相关证据 → 保守
        return results


# IP-435 Multi-Machine Certification Harness
class MultiMachineCertHarness:
    def __init__(self, protocol, strata, beta=0.01, n_min=3, delta_max=0.05):
        self.protocol = protocol     # 预注册：样本量/分层/指标/停止规则
        self.strata = strata
        self.beta = beta
        self.n_min = n_min
        self.delta_max = delta_max   # 放宽额度硬上限（bounded loosening）

    def certify(self, eval_trials, machine_errors, external_probe=None):
        # 1) 标定-评测隔离断言（P38）
        assert disjoint(self.protocol.cal_clients, self.protocol.eval_clients)
        assert disjoint(self.protocol.env_cal, self.protocol.env_eval)
        assert self.protocol.preregistered_before(eval_trials)
        # 2) 估计 monoculture 相关性：外部探针给出保守上界（P39）
        rho = estimate_rho(machine_errors, external_probe)
        # 3) 每层单侧下界，样本量用 n_eff 而非 N（引理 166）
        per = {}
        for s in self.strata:
            k, n = count_success(eval_trials, s)
            n_eff = effective_n(n_machines(eval_trials, s), rho)
            per[s] = clopper_pearson_lower(k, max(n_eff, 1.0), self.beta)
        # 4) 机群声明 = 最差层（抗 Simpson，P39/引理 167）
        fleet = min(per.values())
        return FleetSafetyCertificate(
            per_stratum_lcb=per,
            fleet_lcb=fleet,
            pooled_lcb=pooled_bound(eval_trials, self.beta),  # 仅供审计
            rho_bar=rho,
            n_eff=effective_n(n_machines(eval_trials), rho),
            audit_root=merkle(eval_trials, self.protocol.rule_root),
        )


def effective_n(N, rho_bar):
    """设计效应：DE = 1+(N-1)ρ̄；n_eff = N/DE ≤ N（ρ̄→1 时 →1）"""
    return N / (1.0 + (N - 1.0) * rho_bar)


def estimate_rho(machine_errors, external_probe=None):
    """机群自估可能低估（自证悖论）；有外部独立探针时取更保守上界"""
    self_est = average_pairwise_corr(machine_errors)
    if external_probe is None:
        return self_est          # 无独立探针 → 记为已知残余风险
    return max(self_est, corr_with_external(machine_errors, external_probe))

@dataclass
```

## 3. 推导

**引理 163（方向正确鲁棒聚合的有效性与有界影响）** 设诚实客户端集合 H 满足 |H| ≥ (1-f_max)N，拜占庭集合 B 满足 |B| ≤ f_max N。`Agg_safe` 对每个参数取安全侧单侧界，以 trimmed/median 鲁棒统计量估计中心与层间方差，再叠加 (ε_dp,δ_dp)-DP 噪声。则在标准假设（有界影响、DP 机制正确、诚实客户端在层内可交换）下：对 ↓安全参数（如 κ_c），`P(θ_fed > κ_true) ≤ β + δ_dp`；对 ↑安全参数（如 ε_loc），`P(θ_fed < ε_true) ≤ β + δ_dp`；且 |B|≤f_max 的联盟使不安全方向界的移动不超过 `O(f_max·spread + DP 松弛)`。即拜占庭在结构上只能更保守。∎

**引理 164（联邦缺席证书覆盖）** FAC 在层 s 使用 κ_{c,s}^{LCB}(1-β)。若层内可交换且样本充足，则 v21 缺席事件与 LCB 失效事件的并集给出 `P(层 s 假缺席) ≤ (1-κ_{c,s}^{LCB}) + β = δ_abs + β`。未见层用保守地板 `κ_min = min_s κ_{c,s}^{LCB}` 并收缩 Cov，故假缺席不高于已知最差层。∎

**引理 165（标定-评测隔离的无泄漏性）** 若 CalClients∩EvalClients=∅、Env_cal∩Env_eval=∅ 且预注册先于留出集访问，则 MMCH 的每层下界是留出机群性能的诚实 (1-β) 下界；不存在由标定复用或事后停止导致的乐观偏差（标准预注册/选择性推断论证）。∎

**引理 166（有效独立样本量与 monoculture 退化）** 令 ρ̄ 为机群逐对误差相关均值，DE=1+(N-1)ρ̄，n_eff=N/DE。则 n_eff 关于 ρ̄ 单调不增、n_eff ≤ N，且 ρ̄→1 ⇒ n_eff→1。以 n_eff 代入 Clopper-Pearson 所得下界，仅当 ρ̄<1 时随 N 增加而收紧；当机群共享盲区（ρ̄≈1）时，增加机器数**不能**收紧认证界——"多机 ≠ 多独立证据"。∎

**引理 167（分层最差情形抗 Simpson）** 机群声明取 `fleet_lcb = min_s LCB_s`。存在 pooled 界高而某层 LCB_s 低的构造（Simpson 悖论），故仅 pooled 界不足以支持机群安全；min-over-strata 是机群最差情形声明的充分统计。∎

**引理 168（v22 两模式安全语义）**
- **CONSERVATIVE**：θ_fed ≼_safe θ_local（逐参数不更激进），FCL 只收紧 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ …`。
- **CERTIFIED_TIGHTENING**：θ_fed 为总体 (1-β) 单侧界，且在隔离留出机群上认证 `fleet_lcb ≥ 门槛`、`n_eff ≥ n_min`、放宽额度 ≤ Δ_max；此时 `Exec_v22` 对真实安全集以 ≥1-β 覆盖，但**不**保证 ⊆ `Exec_v21`（可能合法更大）。安全主张由"子集"转为"覆盖有效"，其代价是对可交换性、独立性、f_max 的依赖——即本轮最大风险所在。∎

## 7. 已知风险与失效模式

1. **相关性自证悖论 / 机群 monoculture**（最大风险，见第 8 节）：ρ̄ 由机群自身数据估计会低估、n_eff 被高估，认证自我印证。缓解：外部独立探针取保守上界（E821–E822）、谱系多样性强制（E808）、无探针时强制 ρ̄=1。
2. **非交换性破坏 conformal/统计覆盖**：标定与部署分布漂移时 1-β 失效。缓解：漂移检测 + 分层 + 未见层保守地板（E813）。
3. **拜占庭比例超 f_max**：超过 1/3 合谋时鲁棒界失效。缓解：客户端谱系/几何一致性隔离（E809）、治理层限制单厂商占比。
4. **DP 噪声侵蚀认证紧致度**：隐私预算大→界宽→活性低。缓解：DP-鲁棒联合调参（E824）、按参数敏感度分配预算。
5. **分层定义主观 / 覆盖不到未知层**：错误分层掩盖危险子群。缓解：未见层保守地板、层发现监控。
6. **CERTIFIED_TIGHTENING 的活性诱惑侵蚀安全边界**：为性能而放宽。缓解：放宽硬上限 Δ_max、治理签核、隔离留出集认证（E817）。
7. **联邦参数切换的时序一致性**：在线机器人使用过期 θ_fed。缓解：安全同步点原子切换 + 版本号 + APS 新鲜度阶梯（v17）。
8. **标定统计量的隐私泄露**：充分统计量仍可能被成员推断。缓解：DP + 安全聚合 + 特征最小化（E811）。

## 8. 本轮最大风险

**一句话**：联邦学习与多机评测会**互为对方的"独立性"背书**，但若整个机群共享同一感知盲区（同模型/同厂商/同训练分布），则 ρ̄ 被机群自身低估、n_eff 被高估为 N，联邦标定与多机评测将彼此印证一个系统性错误的召回下界——**机群用 N 台机器的"共识"为一台机器的盲区签发认证，多机认证沦为集体幻觉的统计学洗白**。
