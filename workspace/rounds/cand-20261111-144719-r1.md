# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「语义分割」×「动作分块」）

> 第 54 轮把技能从“能力”升级为“动作占用剖面 α_S”，并把组合提升为动作-鲁棒性双证书。本轮把 `α_S` 从**逐点标量占用**升级为**带标签、边界与校准置信的语义分割**，把逐步动作升级为**带承诺窗口与拼接证书的动作分块**；二者是同一个“动作语义场”的空间切片与时间切片。核心矛盾：**H22**：动作有效性掩码的全局精度（如 mIoU）会掩盖细窄边界上的错误，而语义边界恰是组合切换与分块拼接的高危区；**H23**：动作分块用一次性承诺多步动作换取时序一致与低延迟，但承诺窗口会放大复合误差，且一旦分块跨越语义边界，“跨界块”会在语义切换处系统性失效，使云端下发的证书在边端执行中途过期。

## 0. 直觉与动机

**灵感 1（动作空间的语义分割 → 从占用度到带边界的区域判定）**
直觉：第 54 轮的 `α_S(a)` 只回答“动作 a 是否可达”，回答不了“这块动作属于哪种语义、边界在哪、置信多少”。把动作空间 `A` 分割为语义区 `{R_k}`，每个动作点带标签 `L_A(a)` 与校准置信 `c(a)`。技能的适用性从“逐点覆盖”变成“**区域可判**”：`S` 在 `R_k` 上整体可用，而不是碎点可用。这把技能从“散点能力表”变成“有形状的能力领地”。

**灵感 2（边界优先 → 度量盲区就是失效热点）**
直觉：语义分割的经验是——全局 mIoU 可以很高，而误差几乎全挤在物体边界那几像素上；动作失效同理，几乎都发生在语义转折带。因此必须把边界 `∂L_A` 单独升格为**高风险带**，进入第 54 轮的 `A_buffer`，并用 boundary-F1 而非仅 mIoU 来验收。**全局指标好，不等于要执行的那条边界可靠。**

**灵感 3（动作分块 → 从逐步决策到窗口承诺）**
直觉：ACT / 扩散策略一次性预测未来 `ℓ` 步动作块，时序一致、推理频率低、抖动小；代价是块内误差会复合，块间需要重叠拼接。分块把“逐步可判定”变成了“**窗口承诺**”：部署时承诺执行整块，因而证书必须在整块上成立，而非只在上一步成立。这直接改变了鲁棒性的合成算子。

**灵感 4（语义-分块对齐 → 块长由语义稳定时长决定）**
直觉：最优分块边界应与语义边界重合，块长不应固定，而应由所处语义区的**稳定时长 `T_stable(R)`** 决定：语义越稳定，块可越长；一旦块要跨出当前语义区，就应切分或重规划。于是块长选择从超参数变成**可判定的语义约束**：`ℓ·Δt ≤ T_stable(R) - margin`。

**灵感 5（云边分块契约 → 带 TTL 的证书）**
直觉：云端按语义区产出粗块 `χ^c`，边端按细动作拼接并校验，形成第 54 轮 CEC 的“块级版本”。但云端承诺的块有**生命周期**：证书必须携带 `(ℓ, overlap, ρ_χ, align, T_stable, TTL)`。若边端执行到一半语义漂移或拼接冲突，TTL 到期即触发重规划，避免“陈旧证书”继续授权。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（动作语义分割）**
动作语义分割是一个标签映射 `L_A : A → 𝒦 ∪ {∅}`，`𝒦={1,…,K}` 为语义类别（如“抓取/推移/旋转/不可达”），`∅` 表示弃权。语义区 `R_k = {a | L_A(a)=k}`，边界 `∂L_A = {a | ∃a'∈N(a), L_A(a) ≠ L_A(a')}`。每个动作点带校准置信 `c(a)∈[0,1]`，满足 `P(L_A(a)≠L_true(a) | c(a)≥θ_u) ≤ β_b`。技能 `S` 的有效掩码 `M_S(a)=1[L_A(a)=k_S]`，核心区 `A_core={a | M_S(a) ∧ c(a)≥θ_u}`，边界带 `A_bnd = ∂L_A ∩ N_r(A_core)`。
分割质量用双指标：`mIoU_S = (1/K)Σ_k |R_k^pred∩R_k^true| / |R_k^pred∪R_k^true|`，`BF1_S = 2·P_b·R_b/(P_b+R_b)`（边界精确率/召回率的调和均值）。

**定义 122（动作分块）**
轨迹 `τ=(a_1,…,a_n)` 的一个分块是区间族 `χ = {χ_j=[t_j,t_j+ℓ_j)}`，块长 `ℓ_j`，重叠 `o_j = t_j+ℓ_j - t_{j+1} ≥ 0`，覆盖约束 `∪_j χ_j = [1,n]`。拼接缝 `s_j = (a_{t_j+ℓ_j}, a_{t_{j+1}})`，缝成本 `seam(s_j) = ||a_{end(χ_j)} - a_{start(χ_{j+1})}||`。分块算子记为 `chunk(τ)`。

**定义 123（语义-分块对齐度）**
块 `χ` 的语义纯度 `pur(χ) = (1/|χ|)Σ_{t∈χ} 1[L_A(a_t)=mode_k(χ)]`；边界对齐率 `BA(χ) = |∂χ ∩ ∂L_A| / |∂χ|`；跨界率 `cross(χ)=1[χ 覆盖的语义类别数 > 1]`。语义对齐分块要求 `pur(χ) ≥ θ_p ∧ BA(χ) ≥ θ_b ∧ cross(χ)=0`。

**定义 124（分块鲁棒性与承诺窗口）**
块级鲁棒性 `ρ_χ(d) = (Π_{t∈χ} ρ(a_t,d))^{1/|χ|} · exp(-λ_s·seam)`（几何平均 + 缝惩罚）。块内误差上界 `E(χ) ≤ Σ_{t∈χ} ε(a_t)·(1+α_s·seam)`。**承诺窗口约束**：
```
ℓ·Δt ≤ T_stable(R(χ)) - margin ∧ E(χ) ≤ ε_budget
```
其中 `T_stable(R)` 为语义区 `R` 在任务分布下的最小持续时长。该约束是块长可判定性的核心。

**定义 125（分块拼接证书）**
相邻块拼接证书 `S_cert = (o, discrep, w, fallback)`：
- `o=|χ_j ∩ χ_{j+1}|` 为重叠长度，要求 `o>0` 且 `gap=0`；
- `discrep = max_{t∈overlap} ||a_t^{(j)} - a_t^{(j+1)}||` 为重叠区不一致度；
- `w` 为时间集成权重（指数加权，越近权重越大）；
- `fallback` 为拼接失败时的回退块（保守缩短块长）。
接受条件：`gap=0 ∧ discrep ≤ δ_s`；否则拒绝并回退到 `fallback`。

**定义 126（云边分块契约）**
块级云边契约 `C_chunk = (χ^c, γ_ce, ℓ, o, ρ_χ, align, T_stable, TTL)`：
- `χ^c` 云端语义区级粗块，`γ_ce` 第 54 轮的粗→细动作映射；
- `align = (pur, BA, cross)` 语义-分块对齐证据；
- `TTL = T_stable(R) - ℓ·Δt - margin` 为证书剩余有效期；
- 边端执行时 `TTL ≤ 0` 或 `discrep > δ_s` 即判定证书过期，触发重规划 `reprofile(R)`。

## 2. 关键算法 伪代码

### IP-121 SASS（Semantic-Action Space Segmentation）

```python
def segment_action_space(skill, A, sampler, theta_u):
    pts, labels, conf = [], [], []
    for a in sample_grid(A):
        l, c = sampler.query(skill, a)        # 语义类别（含 ∅）与置信
        pts.append(a); labels.append(l); conf.append(c)
    regions = region_grow(pts, labels, radius=r_a)          # 区域生长
    boundary = {a for a in pts
                if label_disagree(a, regions, r_a) or conf[pts.index(a)] < theta_u}
    calib = temperature_scale(conf, labels)                  # 置信校准
    return SegMap(regions, boundary, calib)

def validity_mask(seg, k_S, theta_u):
    return {a for a,k in seg.labels.items() if k == k_S and seg.calib[a] >= theta_u}
```

### IP-122 SAC（Semantics-Aligned Chunking，动态规划）

```python
def semantics_aligned_chunking(traj, seg, T_stable, max_len, w):
    n = len(traj); dp = [inf]*(n+1); cut = [None]*(n+1); dp[0] = 0
    for j in range(1, n+1):
        for i in range(max(0, j-max_len), j):
            chi = traj[i:j]; L = len(chi)
            if L*dt > T_stable(seg.region_of(chi)) - margin:   # 承诺窗口越界
                continue
            cost = w.cross*cross_penalty(chi, seg) \
                 + w.seam*seam_cost(traj, i, j) \
                 + w.rho*(1 - min_rho(chi))
            if dp[i] + cost < dp[j]:
                dp[j] = dp[i] + cost; cut[j] = i
    return backtrack(cut, n)
```

### IP-123 CHC（Chunk Horizon Certificate）

```python
def chunk_horizon_certificate(chi, rho_fn, T_stable, eps_budget):
    rho_chunk = geometric_mean([rho_fn(a) for a in chi])
    err_upper = sum(eps(a)*(1 + alpha_s*seam) for a in chi)
    if len(chi)*dt > T_stable or err_upper > eps_budget:
        return ('reject', 'horizon', err_upper, T_stable)
    return ('ok', ChunkCert(rho_chunk, err_upper, len(chi), T_stable))
```

### IP-124 CSC（Chunk Stitching Certificate）

```python
def stitch_chunks(chi_prev, chi_next, delta_s, weights):
    o = overlap(chi_prev, chi_next)
    if o == 0:
        return ('reject', 'gap', chi_next.start - chi_prev.end)
    discrep = max_dist(chi_prev[-o:], chi_next[:o])
    if discrep > delta_s:
        return ('reject', 'seam_disagreement', discrep,
                fallback=shorten(chi_next))
    blended = temporal_ensemble(chi_prev, chi_next, weights)  # w_t 指数加权
    return ('ok', blended, StitchCert(o, discrep))
```

### IP-125 SFC（Semantic Failure Certificate）

```python
def failure_mask_certificate(seg, real_mask, miou_min, bf1_min):
    miou = mean_iou(seg.mask, real_mask)
    bf1  = boundary_f1(seg.boundary, real_mask.boundary)
    if miou < miou_min or bf1 < bf1_min:      # 双指标，禁止只看 mIoU
        return ('reject', 'mask_quality', miou, bf1)
    return ('ok', MaskCert(miou, bf1, seg.calib))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SASS | O(|A|·(K + log|A|)) | O(|A|) | 置信校准、边界召回 |
| SAC | O(n·max_len) | O(n) | 承诺窗口约束、代价单调 |
| CHC | O(|χ|) | O(1) | 误差上界不松、T_stable 有裕度 |
| CSC | O(o·|a|) | O(o) | 无 gap、discrep 阈值 |
| SFC | O(|A|) | O(|A|) | mIoU 与 BF1 双达标 |

**正确性定理（Boundary-Aware Chunked Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 边界置信校准：`P(L_A(a)≠L_true(a) | c(a)≥θ_u) ≤ β_b`；**(A30)** 语义稳定时长估计有裕度：`T̂_stable ≤ T_stable`；**(A31)** 拼接不一致度被缝惩罚覆盖：`seam ≤ δ_s ⇒ 缝误差 ≤ λ_s^{-1}`。
则块级部署成功满足：
```
P_success ≥ 1 - Σ_χ (1-ρ_χ) - β_b - P(cross>0) - P(TTL≤0) - P(discrep>δ_s)
```
关键：**先保证分块不跨语义边界**，再谈块内鲁棒性；边界置信与稳定时长是把“点证书”提升为“窗口证书”的两根承重柱。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 动作语义分割质量 | mIoU / boundary-F1 / ECE | mIoU ≥ 0.85，BF1 ≥ 0.75，ECE ≤ 0.05 |
| E163 边界盲区检验 | 全局 mIoU vs 边界误差占比 | 证明误差 ≥ 60% 集中于 ∂L_A |
| E164 语义对齐分块 vs 固定分块 | 缝误差 / 成功率 / 重规划率 | 成功率提升 ≥ 12%，缝误差降 ≥ 30% |
| E165 承诺窗口-鲁棒性曲线 | ρ_χ 随 ℓ 衰减、最优 ℓ* 与 T_stable 关系 | ℓ* ∝ T_stable，R² ≥ 0.8 |
| E166 分块拼接与 TTL | discrep 分布、过期率、P95 反应延迟 | 过期率 ≤ 5%，P95 ≤ 50ms |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 边界置信欠校准，跨界块静默失效 | 高 | 温度缩放 + 边界专测 + 保守弃权 |
| T_stable 估计偏乐观，TTL 虚高 | 高 | 裕度 margin + 在线漂移监测 + 提前重规划 |
| 分割类别体系与任务语义错位 | 高 | 共享本体 + 类别可解释性审计 |
| 分块过短导致抖动/推理开销回升 | 中 | 自适应块长 + 重叠时间集成 |
| 重叠拼接冲突引发动作跳变 | 中 | discrep 阈值 + 保守回退块 + 平滑 |

## 6. 本轮最大风险

**一句话**：语义分割把动作能力变成“有边界的领地”，动作分块把逐点决策变成“有承诺窗口的契约”，但整套 soundness 卡在**边界置信校准**与**语义稳定时长估计**这两个最容易被乐观假设污染的环节——一旦边界置信虚高、或 `T_stable` 被高估，跨界块与过期证书会在执行中途静默失效，而全局 mIoU 仍一派祥和，故必须以 **边界专测 + 校准弃权 + TTL 提前重规划** 三重护栏，宁短块、勿跨界。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SASS×SAC×CHC×CSC×SFC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书之上，增加**动作语义分割、语义对齐动作分块、承诺窗口证书、分块拼接证书、失败掩码证书**五大算子：
> - **SASS（Semantic-Action Space Segmentation）**：把 `α_S` 升级为带标签/边界/校准置信的语义分割；
> - **SAC（Semantics-Aligned Chunking）**：块边界对齐语义边界，块长受 `T_stable` 约束；
> - **CHC（Chunk Horizon Certificate）**：块内误差上界与承诺窗口的可判定证书；
> - **CSC（Chunk Stitching Certificate）**：重叠拼接的不一致度校验与时间集成；
> - **SFC（Semantic Failure Certificate）**：mIoU + boundary-F1 双指标的失败掩码证书。
>
> IP 编号：IP-121~IP-125（共 5 个新增），升级 IP-115/116/117/118/120 以纳入分割与分块维度。

```python
    discrep = max_dist(chi_prev[-o:], chi_next[:o])
    if discrep > delta_s:
        return ('reject', 'seam_disagreement', discrep,
                fallback=shorten(chi_next))
    blended = temporal_ensemble(chi_prev, chi_next, weights)
    return ('ok', blended, StitchCert(o, discrep))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SASS | O(|A|·(K+log|A|)) | O(|A|) | 置信校准，边界召回 ≥ 0.75 |
| SAC | O(n·max_len) | O(n) | 窗口约束 sound，代价单调 |
| CHC | O(|χ|) | O(1) | 误差上界不松，T_stable 有裕度 |
| CSC | O(o·|a|) | O(o) | gap=0，discrep ≤ δ_s |
| SFC | O(|A|) | O(|A|) | mIoU 与 BF1 双达标 |

**正确性定理（Boundary-Aware Chunked Composition Soundness）**
假设 (A22)–(A28) 承接第 54 轮；**(A29)** `P(L_A(a)≠L_true(a) | c(a)≥θ_u) ≤ β_b`；**(A30)** `T̂_stable ≤ T_stable`；**(A31)** `seam ≤ δ_s ⇒ 缝误差 ≤ λ_s^{-1}`。则：
```
P_success ≥ 1 - Σ_χ(1-ρ_χ) - β_b - P(cross>0) - P(TTL≤0) - P(discrep>δ_s)
```
关键：**先切语义边界，再管块内鲁棒；先证 TTL 未过期，再授权执行。**

## 6. 本轮最大风险

**一句话**：语义分割把动作能力变成“有边界的领地”，动作分块把逐点决策变成“有承诺窗口的契约”，但整套 soundness 卡在**边界置信校准**与**语义稳定时长估计**这两个最容易被乐观假设污染的环节——一旦边界置信虚高、或 `T_stable` 被高估，跨界块与过期证书会在执行中途静默失效，而全局 mIoU 仍一派祥和；故必须以 **边界专测 + 校准弃权 + TTL 提前重规划** 三重护栏，宁短块、勿跨界。
