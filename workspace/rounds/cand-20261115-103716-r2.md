# 第 5 轮（灵感循环第 5 轮；本轮灵感：「模型预测控制」×「个性化交互」）

> **基线**：第 4 轮 InstructGauge-WR（IP-328–333；定义 448–467；引理 59–62；实验 E457–E472）。第 3 轮 InstructGauge 的五不变式、CVC 闭环与严格退化链继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。MPC 只改「何时重规划、执行多长」，个性化只改「目标权重、执行节奏、置信水平与交互模态」；二者都**不得触碰硬约束、能力闭包与不可逆屏障**。

## 0. 直觉与动机

**灵感 1（模型预测控制 → 把「证据陈旧窗口」从块长里解耦出来）**
上一轮的痛点是：块长 K 同时承担两件事——摊销决策开销，又决定一次决策的证据要陈旧多久。MPC 提供了一个干净的分离：**用 K_plan 步做预测，只执行前 K_exec 步就重规划**。规划长可以保留前瞻、平滑与跨障碍绕行；执行短则把反馈频率拿回来。于是「摊销」与「陈旧」不再被同一个 K 绑死，真正要付的代价是每步都要解一次带约束的优化——所以执行器必须是 anytime 的：算不完就退回上一条可行解的首动作，最差退化为单步执行。
再深一层：第 4 轮的最大风险是腕部相机的遮挡/光照/TF 抖动，会让名义预测与真实状态产生偏差。标准控制做法不是等偏差发生后再截断，而是用 SpatialCert 的残差构造**不确定集**，在规划期把约束收紧一个裕度，得到 tube-MPC——把「视觉误差沿 K 步放大」从**事后截断**前移成**事前收紧**。

**灵感 2（个性化交互 → 只改目标与节奏，不改可行域）**
不同操作者对风险的容忍、对确认的耐心、对解释详略的偏好都不同；用一套固定阈值对所有人「安全但不好用」。然而个性化最容易走偏的地方，是让用户把系统「调松」。因此正确的分工是：**个性化只参数化目标 J_π、执行步长 K_exec、置信水平 α 与交互模态 m，且这些参数被限制在预注册的安全包络 Π_safe 内；硬约束、能力闭包、不可逆屏障对所有人完全相同。** 这和第 3 轮「语言只改偏好、不改能力」是同一条分层原则的延续。
个性化还带来统计问题：一旦按人/任务分层，共形预测的可交换性被破坏，全局阈值会系统性覆盖不足。必须做**画像分层的共形校准**，并对冷启动用户诚实回退到全局阈值并标记「覆盖未认证」。

**灵感 3（耦合 → 个性化 MPC 的「包络投影 + 画像不确定性」）**
最危险的耦合是「一个被估计得很激进的画像 + 一个被拉长的执行步长」。解法不是禁止个性化，而是三重结构：**(i) 包络投影**——任何画像先投影到 Π_safe，越界即夹回；**(ii) 偏好影响界**——画像变化对动作序列的扰动有界，且**不可能扩大可行集**；**(iii) 画像不确定性下的管道 MPC**——未知/冷启动画像用保守不确定集，随交互证据增多才允许收紧到认证裕度。这样个性化得到的是「同一安全骨架上的不同驾驶风格」，而不是「不同安全等级」。

## 1. 研究问题（本轮要回答什么）

- **Q1（MPC 的分离）**：规划域 K_plan 与执行域 K_exec 解耦后，决策摊销与证据陈旧能否被分别度量？最优 K_exec 由什么决定？
- **Q2（个性化的安全性）**：在画像只改目标/节奏、不改硬约束的包络约束下，能否证明个性化不降低硬安全下界？画像误估与对抗偏好注入的影响是否有界？
- **Q3（统计有效性）**：画像分层破坏可交换性后，如何恢复覆盖保证？冷启动与跨画像泛化如何退化？
- **Q4（鲁棒耦合）**：由腕部相机残差驱动的 tube 收紧，能否把视觉不确定性从「事后截断」变成「事前可行性」？

## 2. 四条设计原则（雏形，正式化见产物区定义 468–489）

**P4 执行域独立（Execution-Horizon Independence）**
`K_exec ≤ min(K_plan, τ_max)`，证据陈旧窗口只由 `K_exec` 决定；不可逆动作强制 `K_exec = 1`。规划前瞻与执行反馈由此解耦。

**P5 画像安全包络（Profile Envelope）**
画像 `π_u = (w_u, K_exec, α_u, γ_u, m_u)` 必须属于预注册集合 `Π_safe`；投影 `Proj_{Π_safe}` 先于任何使用。硬约束集 `C_hard` 与画像无关。

**P6 偏好影响界（Bounded Preference Influence）**
对任意 `π, π' ∈ Π_safe`，有 `||u*(π) − u*(π')|| ≤ ρ||π − π'||` 且 `Feas(π) = Feas(π')`；个性化只能移动目标的最优解，不能扩张可行域。

**P7 画像分层校准（Profile-Stratified Calibration）**
覆盖率按画像簇 `q` 条件化；`n_q < n_min` 时回退全局阈值，并把该画像标记为「覆盖未认证」，同时保守化（`K_exec ↓` 或 `γ_u ↑`）。

## 3. 与基线的接口（如何退化）

- MPC 不可用 / 求解超时 ⇒ 执行 `K_exec = 1`（等价 ToolGauge 逐步），或退回 v4 的分块截断路径；
- tube 不确定集失效 / 残差不可用 ⇒ 名义 MPC，但保留 CVC 前置检查与不可逆屏障；
- 画像不可得 / 未知用户 ⇒ 默认保守画像 `π_0`（等价全局校准，即 InstructGauge-WR）；
- 分层样本不足 ⇒ 全局共形阈值 + 覆盖未认证标记；
- InstructGauge-WR 失效 ⇒ InstructGauge v3；InstructGauge 失效 ⇒ ToolGauge。

## 4. 预期贡献

1. 一个**规划域/执行域解耦**的滚动时域执行器，把摊销—陈旧权衡显式参数化并给出最优 `K_exec`；
2. 一个由 SpatialCert 残差驱动的 **tube-MPC**，把视觉不确定性从执行期前移到规划期；
3. 一个**安全包络 + 偏好影响界**，证明个性化不修改硬约束、不扩张可行域；
4. 一个**画像分层共形校准与冷启动回退**，修正条件化导致的覆盖失效；
5. 可证伪路径 E473–E488，覆盖摊销 Pareto、管道可行性、安全不变、分层覆盖、对抗注入与实时性。

## 5. 本轮最大风险

**一句话**：个性化画像是在稀疏、非平稳、可能被对抗操纵的交互数据上估计的，真正的残余风险不是 MPC 求解器，而是**画像估计误差在分布漂移下被滚动重规划反复放大**——安全包络只保证「模型内安全」，并不保证「模型失配下画像仍然准确」。

## 2. 形式化定义（要点）

**定义 468（个性化画像）**
```
π_u = (w_u ∈ Δ^{d-1}, K_exec ∈ ℕ, α_u ∈ (0,1), γ_u ≥ 1, m_u ∈ M_reg)
```
其中 `w_u` 是目标权重（单纯形上），`α_u` 是目标误覆盖率，`γ_u` 是不确定度膨胀因子，`m_u` 是交互模态（确认频率、解释粒度）。画像只条件化目标与节奏，**不进入硬约束**。

**定义 469（安全包络与投影）**
```
Π_safe = { π : 1 ≤ K_exec ≤ τ_max, α_u ∈ [α_min, α_max],
           w_u ∈ W_reg, γ_u ∈ [1, γ_max], m_u ∈ M_reg }
Proj_{Π_safe}(π) = argmin_{π' ∈ Π_safe} ||π − π'||²
```
硬约束集 `C_hard`、能力闭包 `T₀` 与不可逆屏障对 `π ∈ Π_safe` 全部不变。注意 `γ_u ≥ 1`：个性化**只能加大**不确定裕度，不能低于认证残差。

**定义 470（滚动时域规划与执行）**
```
C_t^{mpc} = argmin_{u_{0:K_plan-1}} J_{π_u}(x_t, u)
            = Σ_{k=0}^{K_plan-1} w_u^T φ(x_k, u_k) + V_f(x_{K_plan})
s.t.  x_{k+1} = f(x_k, u_k),  u_k ∈ U_hard,
      g(x_k) + margin(β_t) ≤ 0,  x_k ∈ X_trust
```
执行 `u_{0:K_exec-1}`，观测 `x_{t+K_exec}`，然后重解。`K_exec` 是**证据陈旧窗口**；`K_plan` 只影响前瞻与平滑，不影响两次反馈之间的时长。

**定义 471（残差管道）**
由 SpatialCert 的残差序列 `{r_i}` 取 `β_t = Quantile_{1-δ}(||r_i||)`，定义
```
W_t = { w ∈ ℝ^n : ||w||₂ ≤ γ_u · β_t }
margin(β_t) = L_g · γ_u · β_t
```
其中 `L_g` 是约束函数 `g` 的 Lipschitz 常数。管道把「视觉/时空不确定性」转成规划期的**约束收紧**，而不是执行期的被动截断。

**定义 472（摊销—陈旧综合代价）**
```
U(K_exec) = c_solve / K_exec + c_exec + λ · L^{K_exec}
```
第一项是求解开销的摊销，第二项是单步执行开销，第三项是证据陈旧 `K_exec` 步导致的误差增长（`L > 1`）。最优执行步长
```
K_exec* = argmin_{1 ≤ K ≤ τ_max} U(K)
```
由一阶条件 `-c_solve/K² + λ L^K ln L = 0` 给出，且 `K_exec*` 随 `c_solve` 增大、随 `λ, L` 减小。

**定义 473（画像分层共形校准）**
设画像嵌入 `q = embed(π_u)`，校准集 `D_q`，非一致性分数 `s`。对每个簇
```
q̂_q = Quantile_{⌈(n_q+1)(1-α_u)⌉/n_q}({s_i}_{i∈D_q})
```
当 `n_q ≥ n_min` 时，簇内可交换性下条件覆盖 `P(Y ∈ C_{q̂_q} | q) ≥ 1 − α_u`；当 `n_q < n_min` 时回退 `q̂_0`（全局），此时**只保证边缘覆盖**，必须把该画像标记为 `coverage_uncertified` 并保守化（`K_exec ↓` 或 `γ_u ↑`）。

**定义 474（偏好影响界）**
对任意 `π, π' ∈ Π_safe`，
```
||u_{0:K_exec}(π) − u_{0:K_exec}(π')|| ≤ ρ ||π − π'||,
Feas(π) = Feas(π') = U_hard ∩ G
```
若在线监测到 `||Δu|| > ρ||Δπ||`，判定为偏好影响越界并触发 `π ← π_0` 回退。

**定义 475（退化映射 `Deg`）**
```
Deg(off_mpc)      = K_exec := 1
Deg(off_tube)     = β_t := 0, 保留 CVC 前置
Deg(off_profile)  = π_u := π_0
Deg(off_strat)    = q̂_q := q̂_0
Deg(all_off)      = InstructGauge-WR v4 → InstructGauge v3 → ToolGauge
```

## 3. 关键算法骨架

```python
# IP-336 画像投影
def project_profile(pi, env):
    pi.K_exec = min(max(pi.K_exec, 1), env.tau_max)
    pi.alpha  = min(max(pi.alpha, env.alpha_min), env.alpha_max)
    pi.gamma  = min(max(pi.gamma, 1.0), env.gamma_max)
    pi.w      = project_to_simplex(pi.w, env.W_reg)
    pi.m      = pi.m if pi.m in env.M_reg else env.default_mode
    return pi

# IP-334 Receding-Horizon-Executor
class RecedingHorizonExecutor:
    def __init__(self, solver, model, tau_max):
        self.solver, self.model, self.tau_max = solver, model, tau_max
        self.prev = None

    def step(self, x, pi, beta, deadline):
        plan = self.solve_anytime(x, pi, beta, deadline)
        if plan is None:
            return self.model.single_step(x), None      # 退化 K_exec=1
        k = min(pi.K_exec, self.tau_max, len(plan.actions))
        if self.model.crosses_irreversible(plan.actions[:k]):
            k = 1                                       # 不可逆屏障
        self.prev = plan
        return plan.actions[:k], plan

    def solve_anytime(self, x, pi, beta, deadline):
        warm = self.prev.shift() if self.prev else None
        try:
            return self.solver.solve(J=pi.w, horizon=self.model.K_plan,
                                     tube=beta, warm_start=warm,
                                     deadline=deadline)
        except (Timeout, Infeasible):
            return self.prev.feasible_prefix() if self.prev else None

# IP-335 / IP-337 / IP-338 组合闭环
def persistogauge_step(M, x, user, ell=None):
    # 1. 画像：估计 → 投影 → 分层共形阈值
    pi = project_profile(M.profiles.get(user, M.profile_default), M.env)
    if not M.conformal.certified(pi):
        pi = M.conformal.conservative(pi)               # 覆盖未认证 ⇒ 保守化
    # 2. 基线接地与假设
    iota = M.nlib.ground(ell, M.scene, M.ontology) if ell else M.default_iota
    H = M.lbox.hypothesize(x, M.dbox.R, iota)
    # 3. 残差管道
    cert = M.wristcam.spatial_cert(M.env.time() - M.window, M.env.time())
    beta = M.tube.radius(cert, delta=M.delta, gamma=pi.gamma)
    # 4. 滚动时域执行
    actions, plan = M.rhe.step(x, pi, beta, deadline=M.deadline)
    executed = []
    for a in actions:
        if not M.cvc.joint_pre(a) or not still_grounded(iota, M.env):
            break
        M.env.apply(a); executed.append(a)
        if M.pim.violates_influence(pi, a):             # IP-338
            pi = M.profile_default; plan = None; break
        if plan is not None and not M.spatial_cert_ok(M.wristcam, plan):
            break                                        # 回到重规划
    if plan is not None:
        M.ros_cvc.publish_cvc(plan.id, executed, cert, pi)
    M.profiles.update(user, pi, executed, slow_timescale=True)  # 只改画像，不改硬约束
    return executed, cert, pi

# IP-340 主闭环：50Hz 路径不变，MPC 异步
def PersoMPC_Gauge_round(M, obs, audio, tac, depth, det, ell=None, user=None):
    for s in M.dbox.detect_blind_spot():
        if s not in M.inflight:
            M.inflight.add(s)
            spawn_async(persistogauge_step, M, M.state, user, ell)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 63（执行域分离与摊销—陈旧权衡）** 固定 `K_plan`，则每个执行动作的决策开销为 `c_solve/K_exec + c_exec`（随 `K_exec` 递减），而证据陈旧窗口为 `K_exec` 步、误差增长被 `L^{K_exec}` 界住。综合代价 `U(K) = c_solve/K + c_exec + λL^K` 在 `K ≥ 1` 上离散凸，故 `K_exec*` 唯一；`K_exec*` 关于 `c_solve` 单调不减、关于 `λ, L` 单调不增。特别地，跨不可逆动作或 `L` 过大时 `K_exec* = 1`。
*证明*：对 `K` 作一阶差分，`U(K+1) − U(K) = c_solve(1/(K+1) − 1/K) + λL^K(L−1)`；第一项单调上升趋零、第二项单调上升，故差分单调，`U` 离散凸；极小点由差分符号变化唯一确定。∎

**引理 64（管道递归可行与约束满足）** 若初始收紧问题可行，且真实扰动满足 `||w_t|| ≤ γ_u β_t`（`β_t` 为残差 `1−δ` 分位），则在 `margin(β_t) = L_g γ_u β_t` 的约束收紧下，滚动问题递归可行，且所有已执行步满足 `g(x_k) ≤ 0`，概率至少 `1−δ`。
*证明*：标准 tube-MPC 归纳：收紧裕度覆盖一步扰动传播，可行域在扰动下前向不变；分位定义保证扰动以 `1−δ` 概率落在管道内。∎

**引理 65（个性化安全不变性）** 对任意 `π ∈ Π_safe`，`Feas(π) = U_hard ∩ G` 与 `π` 无关；不可逆屏障、能力闭包、CVC 前置对 `π` 不变。故任何经 `Proj_{Π_safe}` 投影的画像，其执行计划与 InstructGauge-WR 满足同一组硬约束。
*证明*：定义 469 中 `Π_safe` 不包含任何修改 `C_hard, T₀` 的分量；定义 470 的约束集除 `β_t` 外不含 `π`，而 `γ_u ≥ 1` 只收紧。∎

**引理 66（画像分层覆盖）** 若簇内可交换且 `n_q ≥ n_min`，则 `P(Y ∈ C_{q̂_q} | q) ≥ 1−α_u`。若回退全局阈值，则只保证边缘覆盖 `≥ 1−α_0`，不能保证簇条件覆盖；系统必须把该画像标记为 `coverage_uncertified` 并保守化。
*证明*：簇内共形预测的标准有限样本覆盖；回退情形由「边缘覆盖不蕴含条件覆盖」的反例直接给出，故只能声明边缘保证。∎

**引理 67（偏好影响有界）** 若 `J_π` 关于 `u` 强凸、约束满足 LICQ，则最优解映射 `π ↦ u*(π)` 局部 Lipschitz，常数 `ρ` 存在；于是 `||Δu|| ≤ ρ||Δπ||`，且 `Feas(π)` 不随 `π` 扩张。
*证明*：由 Berge 极大值定理得上半连续，强凸 + LICQ 给出隐函数定理条件，解映射可微且导数有界。∎

**引理 68（退化等价）** 按定义 475 逐级关闭组件：`off_mpc ⇒ K_exec=1` 与 ToolGauge 逐步等价；`off_profile ⇒ π_0, γ=1` 复现 v4 的名义分块 + 截断；`off_strat ⇒ q̂_0` 复现 v4 全局阈值。故退化链在行为上逐级等价。
*证明*：逐项代入定义 468–475，各退化分支与对应基线算法在动作序列与证书上一致。∎

## 8. 本轮最大风险

**一句话**：个性化画像从稀疏、非平稳且可被对抗操纵的交互数据中估计，安全包络只能保证「模型内硬约束不扩张」，却无法保证「分布漂移下画像估计仍然准确」；一旦画像与真实偏好/动力学错配，滚动重规划会把这一误差在每个 `K_exec` 边界反复注入，形成比单次分块错误更隐蔽的**慢性偏置**。
