# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；本轮灵感：「可扩展性」×「实时推理」）

> R69 问出了整条主线里最像人的一句话：「我该向谁求证、还能问什么」。但它是在**一张单机、单智能体、预算宽松的桌子**上问的：K≤4、一次只打扰一个人、推理总能算完、P99 < 2.6ms 被当成硬约束而不是状态变量。把这张桌子放大 100 倍，三个前提同时碎掉：
> - **规模**：N 个智能体共享算力、共享模型、共享同一个操作员。R69 的「每个智能体 ≤1 次信息动作/单位时间」在车队长就变成一场对稀缺注意力的踩踏；每个智能体各自 argmax(VoI−成本)，但「成本」是**内生**的——你问的时候别人也在问，注意力被拥塞、信息因重复提问而贬值。
> - **实时**：截止期可能落在推理**中途**。半截 ODE、K 个样本只回来 2 个、VoI 还在枚举——R69 假设这些总能算完，现实是世界不等你算完。
> - **可信**：R69 的全部收益押在「流模型的模态分布可信」上（这是它自陈的最大风险）。而为了实时，工业界第一反应就是蒸馏/一致性模型做 1 步采样——**这恰恰是最容易坍缩模态、最不可信的那类模型**。于是「更快」直接攻击了「可信」。
>
> 核心命题：**把「计算」从隐形假设变成一等资源与一等不确定性来源。** 用**分级随时执行器**（Tiered Anytime Executor）在任何中断点都给出合法且可证的计划；用**计算诱导不确定性 U_comp** 把「没算完」折算成 λ 的收紧；用**两速策略 + 抽样统计认证**，让便宜的快路径只有在被慢路径的随机审计证明「分布等价」时才被信任；用**车队注意力拍卖 + 事后 VoI 审计**把单机 argmax 升级为跨智能体的稀缺注意力配置。命名 **TEMPO-RAS**（Tiered Epistemic Monitoring with Preemptible Options）。
>
> 一句话定位：R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」——R70 问「**我只有 2 毫秒，先算什么、后算什么、什么可以先不信**」：把 R68/R69 串成一条**由时间预算索引的策略族**，预算最紧处逐指令退回 R68，预算最宽处才是完整的 R69。

## 0. 直觉与动机

**灵感 1（可扩展性 → 单机预算表在车队长失效，且交互成本是内生的）**
直觉：R69 的复杂度表是「一个智能体、一个 tick、一个操作员」。当 N 个智能体共用同一个操作员，交互的「成本」不再是每个智能体可以各自评估的常数，而是**由所有人共同决定的内生量**：你问的时候别人也在问，边际成本随拥塞上升、信息增益随重复提问下降。更微妙的是标定：单机 ECE 门在样本少时噪声大，池化到车队能显著降方差，但池化引入**跨智能体污染**——一个被投毒的智能体可以把整个车队的校准拉偏。可扩展性因此不是「同样的东西算得快」，而是**信息经济学（注意力稀缺）与校准统计学（池化 vs 污染）同时改变**。

**灵感 2（实时推理 → 完成度本身就是一种不确定性）**
直觉：R69 把「P99 < 2.6ms」当约束，好像推理一定来得及。但实时的真实含义是：**截止期可能在你算到一半时到点**。Anytime 算法把这个失败变成旋钮：任何中断点都返回一个有误差界的合法答案。关键洞见：**半截推理 = epistemic 未消解**，而 R69 的 λ_floor 本来就会给未消解的 U_epi 收紧。所以「没算完」不需要新的安全机制，只需要**如实记账**：定义 U_comp（计算诱导的残差），它随完成的 tier 单调下降，并在任何中断点进入 λ_floor。截止期于是不是「违约」，而是「本 tick 的 U_comp 停在了较高的值」——安全侧自动收紧。

**灵感 3（两速推理 → 越快越像 R69 最怕的东西）**
直觉：要实时就得蒸馏、缓存、1 步采样；可这些正是**模态坍缩与权重幻觉**的温床——恰好是 R69 的最大风险。二者是直接的矛盾：速度攻击可信度。解法不是「相信快路径」，而是**不假设、只证明**：用慢路径（完整 FLUID + FMA）在**随机抽检的 tick** 上做审计，用置信序列给出「快慢路径分布差 ≤ ε」的统计证书。便宜是因为抽检率 p 很小且可后台并行；可扩展是因为审计可跨智能体池化（但池化又有污染风险——这是本轮反复出现的核心张力）。**快路径的可信度不是构造成立的，是被持续测量出来的。**

**灵感 4（共享注意力 → 交互预算要从 argmax 升级为拍卖）**
直觉：车队里真正稀缺的是**操作员的注意力**（人类会累、会烦、会漏）。R69 的 MINT 让每个智能体独立 argmax(VoI−c)，这是「原子化竞争」，会踩踏。正解是把少量注意力槽位（M slots/interval）做成**全局拍卖**：各智能体提交「我最想问的那一问值多少 VoI」的报价，调度器在槽位与公平约束下最大化总 VoI。新攻击面随之出现：**报价通胀**（谎报高 VoI 抢注意力 = 注意力 DoS）。因此必须配**事后 VoI 审计**与**可信度权重 κ**：你上次说值 10 结果只值 1，下次你的报价就打折。

**灵感 5（统一 → 用时间预算把 R68/R69 串成连续谱）**
直觉：回看整条主线，每一轮都在用**更多计算**换安全/鲁棒（标定、多采样、交互、似然审计）。R70 把这笔账挑明并**定价**：给一个时间预算 B_t，把 B_t 分配到各 tier 上以最小化期望风险。于是 R68 是 B 最小时的端点（最便宜的合法路径），R69 是 B 充足时的端点（完整 FLUID + 交互），中间是一条**预算索引的策略族 Π_B**。要证的核心性质是**单调性**：B 增大，期望风险不增、执行计划是前一个的细化；且任何中断都落在**回退格**里并有证书。这样一来，安全保证不再依赖「我们有足够算力」这个脆弱前提，而是**对任意算力都成立**。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TEMPO-RAS 总览）** TEMPO-RAS = (TAE, DES, TSP, SRM, FAA, VQA-F, RPC, RAS-WM†)。四条不变式：
(i) **实时路径零学习写操作**（继承 R68 定义 276-i）；
(ii) **硬截止**：每个控制 tick 在 B_t 内返回一个带证书的计划；「超时」本身是安全事件，计入证书，不得静默；
(iii) **单调降级**：预算收紧时策略只能更保守；对任意中断/超时/攻击，返回计划必落在回退格中（定义 321）；
(iv) **审计独立性**：快路径的可信度只能由**与快路径独立的慢路径**抽样得出，绝不允许快路径自证。

**定义 311（分级推理）** Tier T0–T3：T0 = trunk + 1 步蒸馏快提议器（必选）；T1 = +K 采样模态分解（FLUID，定义 296）；T2 = +FMA 似然第二意见（定义 301）；T3 = +MINT 交互与 CIA 主动探询（定义 298–300）。每个 tier i 有最坏执行时间 w_i 与抖动 j_i（A99）。计划 σ ⊆ {T1,T2,T3} 是 T0 之上完成的有序子集，cost(σ)=Σw_i，须满足 cost(σ)+Σj_i ≤ B_t。

**定义 312（计算诱导不确定性 U_comp）** 在中断点，U_comp(σ) = U_epi^res(σ) + ε_ode(σ) + ε_cert(σ)：分别为未完成 tier 遗留的 epistemic 残差、ODE 步数截断误差、抽检证书的统计误差。性质：σ ⊆ σ' ⇒ U_comp(σ') ≤ U_comp(σ)（多做一层不会更不确定）。

**定义 313（随时风险缩放）** λ_t = max(EFS, λ_floor(U_ale + U_epi^unresolved + U_comp(σ_t)))。这是定义 307 的严格扩展：预算不足导致的中断被折算进 λ，而不是被忽略。U_comp → 0 时退化为 R69。

**定义 314（截止调度 DES）** 给定 B_t 与各 tier 的预测风险收益 r_i 与成本 w_i，选 σ* = argmax_{σ: cost≤B_t} Σ_{i∈σ} r_i，按价值密度 r_i/w_i 贪心（或小规模精确 DP）；并预留 headroom 吸收抖动（A99）。预测 r_i 由 mode_head（定义 308）与近期审计统计给出。

**定义 315（两速策略与分布差）** 快策略 π_f（蒸馏/1 步）与慢策略 π_s（完整 FLUID+FMA）。分布差 d(π_f, π_s) = 模态权重 TV 距离 + 似然分位差 + 模态校准 ECE 差的加权；真值 d*。部署只用 π_f，但须维持证书 d* ≤ ε_cert。

**定义 316（抽样认证 SRM）** 以**秘密种子**的哈希 (tick_id, agent_id) 挑出比例 p 的 tick 走慢路径，计算 gap 估计并更新**置信序列**（empirical Bernstein）。若置信上界 > τ_cert ⇒ 暂停快路径，回退慢路径或 R68。种子保密是 A101：审计 tick 必须对攻击者不可预知、不可事后挑选。

**定义 317（车队注意力拍卖 FAA）** N 个智能体、每 interval 有 M 个操作员注意力槽。智能体 i 报 b_i = max_g VoI_i(g)（定义 298），带可信度 κ_i；调度器解 max Σ x_i κ_i b_i s.t. Σx_i ≤ M 且公平约束（单机连续中标 ≤ C、最小份额轮转）。κ_i 初值 1，随事后审计更新（定义 318）。

**定义 318（事后 VoI 审计与可信度账本 VQA-F）** 交互后测量**实际信息增益** ΔH_real（后验熵实际下降）与报价 b_i 之比 ρ_i = ΔH_real / b_i；κ_i 乘性更新 κ_i ← κ_i·exp(−η(1−ρ_i)_+)。持续虚报高 VoI 的智能体 κ 指数衰减 ⇒ 长期注意力份额被压低。结论回灌 AuditBuf，成为 MINT 成本先验。

**定义 319（鲁棒池化标定 RPC）** 车队池化样本做校准以降方差，但用 median-of-means / 截尾均值，并对每个智能体的残差做一致性检验；若池化估计与鲁棒估计偏差超阈，隔离可疑智能体，其样本不进池。ECE 门（定义 306）在池化后生效，但门槛须含污染裕度 α_max（引理 22）。

**定义 320（共享缓存与确定性）** 共享推理缓存键 = (model_version, hash(z_t), 输入摘要)；命中须过确定性检查（逐位或差 ≤ ε_cache）；版本钉死。缓存是跨智能体的**共模故障点**：一个被污染的 z→mode 缓存可同时误导所有命中者，故缓存条目也须被抽样审计（并入 SRM）。

**定义 321（回退格与预算索引策略族）** 定义计划偏序：R68 ⊑ R69-partial(σ) ⊑ R69-full ⊑ TEMPO-full，越靠右越「激进但收益高」。策略族 Π_B，B ∈ [B_min, B_max]：Π_{B_min} = R68，Π_{B_max} = R69+审计+拍卖。保证：对任意 B，E[Risk(Π_B)] 关于 B 单调不增；plan(B) 是 plan(B')（B≤B'）的细化；任何中断点返回格中某元素并标出其身份。

**定义 322（多资源预算）** 预算向量 B_t = (τ_time, e_energy, m_attention)；可行域是这些资源的联合多面体。调度在联合约束下求最大收益；能量/热约束（移动平台）与注意力约束（人类）同构——都是「用一点少一点」的稀缺量。

**定义 323（威胁模型 ℰ_TEMPO）** 在 ℰ_FLUID 之外新增：注意力 DoS（报价通胀、刷请求）、审计规避（在可预知/可识别的审计 tick 表现良好、其余作恶）、共享缓存投毒（跨智能体共模）、池化标定投毒（单点污染全队）、截止期挤压攻击（构造输入触发最贵 tier 以制造超时）。ℰ_TEMPO = ℰ_FLUID × ℰ_attention × ℰ_audit × ℰ_cache × ℰ_pool × ℰ_deadline。

**定义 324（证书 J_TEMPO）** J_TEMPO = (J_FLUID, deadline_miss_rate, U_comp_p95, cert_gap_ucb, cert_confidence, attention_slot_usage, bid_realization_ratio, pool_robust_gap, cache_determinism, tempo_ver)。Valid ⇔ Valid(J_FLUID) ∧ cert_gap_ucb ≤ τ_cert ∧ miss ≤ ε_dm ∧ 池化鲁棒检验通过 ∧ 审计种子新鲜。

**定义 325（异构与版本漂移）** 车队可能同时跑多版本模型（灰度/回滚）。证书须版本钉死；跨版本可比性靠**锚定映射**（在重叠分布上用少量联合样本把版本 A 的 ECE/模态权重映射到版本 B 的坐标系）。这既防「静默换版」，也允许渐进升级；但锚定映射本身是新的攻击面（定义 323）。

```python
# IP-264 TAE：分级随时执行器（中断即停，不清空已完成的层）
class TieredAnytimeExecutor:
    TIERS = [T1, T2, T3]
    def run(self, o_t, B_t):
        deadline = now() + B_t
        plan  = DES.schedule(B_t, self.mode_head_hat)     # 预算内选 tier 子集
        out   = self.t0(o_t)                              # T0 必选：1 步快提议
        done  = {T0}
        for t in plan:                                    # 价值密度降序
            if now() + WCET[t] > deadline - HEADROOM:     # anytime：来得及才算
                break
            out = merge(out, self.tier[t](o_t, out))
            done.add(t)
        out.U_comp = u_comp(done, plan)                   # 未完成层 → 残差
        return out, done

# IP-266 DES：价值密度贪心背包 + 抖动余量
def schedule(B_t, mode_head_hat):
    r = predict_risk_reduction(mode_head_hat)             # 各 tier 预期收益
    sigma, spend = [], 0.0
    for t in sorted(TIERS, key=lambda t: r[t] / WCET[t], reverse=True):
        if spend + WCET[t] + JITTER[t] <= B_t and r[t] > 0:
            sigma.append(t); spend += WCET[t] + JITTER[t]
    return sigma

# IP-265 BRC：把 U_comp 计入 λ（随时安全，定义 313）
def anytime_lam(M, U_ale, U_epi_unres, U_comp):
    return max(M.efs.risk_scale(...),
               lam_floor(U_ale + U_epi_unres + U_comp))

# IP-268 SRM：抽样认证（关掉关键路径，后台）
def sampled_certify(tick_id, agent_id, fast_out, o_t):
    seed = secret_rotate()                                # A101：不可预知
    if not h(seed, tick_id, agent_id) < P_AUDIT:
        return None
    slow = SLOW.full_run(o_t)                             # 完整 FLUID + FMA
    return update_confidence_sequence(gap(fast_out, slow))

# IP-269 FAA：车队注意力拍卖（κ 加权、公平约束）
def auction(bids, kappa, M_slots, fairness):
    winners = []
    for i in sorted(range(N), key=lambda i: kappa[i]*bids[i], reverse=True):
        if len(winners) >= M_slots: break
        if not fairness.allow(i): continue                # 连续中标上限/最小份额
        winners.append(i)
    return winners

# IP-270 VQA-F：事后 VoI 审计 → κ 乘性更新（反注意力 DoS）
def audit_and_update(i, claimed, realized):
    rho = realized / max(claimed, EPS)
    kappa[i] *= exp(-ETA * max(0.0, 1.0 - rho))           # 持续虚报 → 份额被压
    return kappa[i]

# IP-276 TEMPO-RAS 主闭环（继承 R69，插入预算调度/认证/拍卖/回退）
def TEMPO_RAS_round(M, o_t, B_t):
    out, done = M.tae.run(o_t, B_t)                       # T0 必选；T1–T3 按预算
    U_ale, U_epi, modes = out.U_ale, out.U_epi, out.modes
    a_hat = M.fma.flow_anomaly(...) if T2 in done else None
    slow  = (a_hat is not None) and a_hat > TAU_FMA and M.last_r_res < TAU_RES
    # 交互先向车队拍买槽位，中标才 MINT
    g = None
    if T3 in done and U_epi > TAU_EPI and not slow:
        if M.faa.win(M.agent_id, bid=best_voi(modes)):
            g = M.mint.choose_interaction(modes, o_t, M.budget)
    U_epi_after = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    lam = anytime_lam(M, U_ale, U_epi_after, out.U_comp)  # 未算完也安全
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    if M.srm.requires_fallback():                         # gap 证书越界
        lam, k, g = M.r68.fallback(...)                   # 回退格端点
    M.srm.observe(M.agent_id, out); M.vqa_f.log(g, U_epi, a_hat)
    return k, lam, select_mode(modes, U_epi_after, lam), M.j_tempo(...)
```

## 3. 推导

**引理 19（随时单调性与中断安全）** 设 A99 成立。对任意计划 σ 与任意中断点，执行器返回 σ_done ⊆ σ 的结果，且 U_comp(σ_done) ≥ U_comp(σ)。则：(a) 完成层越少，λ_t 越大（单调不降）；(b) C-RAS-WM 认证前缀 + λ_floor 在每个中断点都构成合法安全包络（收紧只会更安全）；(c) Risk(Π_{σ_done}) ≤ Risk(Π_σ) + O(U_comp(σ_done) − U_comp(σ))。故**中断只可能略微增加风险，永不破坏安全**。系：E[Risk(Π_B)] 是 B 的非增阶梯函数。

**引理 20（抽样认证的样本复杂度与车队并行）** 对 gap g ∈ [0,1]，empirical Bernstein 置信序列在 n 个样本后满足 |ĝ−g*| ≤ ε，若 n = O((σ̂² log(1/δ))/ε² + log(1/δ)/ε)。抽检率 p 下，认证墙钟延迟 = n/p 个 tick。若跨 N 个智能体**池化**审计（共享同一快模型），每智能体摊薄成本 = n/N ⇒ 近似与 N 无关。**但池化仅在「各智能体 (快,慢) 分布可交换」时成立**；异构/版本漂移（定义 325）破坏可交换性 ⇒ 必须逐智能体认证。这是「规模红利」与「异构代价」的精确分界。

**引理 21（注意力拍卖的近似与反 DoS 界）** (i) κ 加权 VoI 对槽位数量是单调子模的（边际递减），贪心给 (1−1/e) 近似；(ii) 用指数权重更新 κ，对最优固定分配的累计后悔 ≤ O(√(T log N))；(iii) 若某智能体把报价通胀 γ 倍且在 p 的审计率下被核对，其 κ 以 exp(−η(1−1/γ)pT) 衰减 ⇒ 长期注意力份额被公平上限 C·M 截断，累计浪费槽位有界（每 interval ≤ (γ/(γ−1))·C·M + O(√(T log N))）。故**不存在注意力 DoS 崩溃**，只有可测的、有界的低效。

**引理 22（鲁棒池化标定的污染界）** 设池中 α 比例样本被对抗、样本有界。用 K 块 median-of-means（K=⌈8 log(1/δ)⌉），只要 α < 1/2，估计误差 ≤ 3σ_b + Cα。故 ECE_pooled 误差 ≤ C(σ√(log(1/δ)/n) + α)。⇒ ECE 门须抬高至少 Cα_max；一旦 α ≥ 1/2，MoM 失效，必须隔离。系：**池化只有配鲁棒聚合与显式污染裕度才安全**；朴素平均会被 α 任意拉偏。

**定理 18（预算索引的严格包含与单调性）** 在 A99–A100 下，对任意 B：(i) Π_{B_min} 与 R68 逐指令相同；(ii) Π_{B_max} 在证书有效时与 R69（+认证器）逐指令相同；(iii) B ↦ E[Risk(Π_B)] 单调不增；(iv) 任何中断返回回退格元素并附 J_TEMPO。证明：引理 19 + 定义 321 的格 + R69 定理 16。故 R68 与 R69 不再是两个并列系统，而是同一条预算谱的两个端点。

**定理 19（实时安全与对抗挤压）** 在 A99、A101 下，对任意输入序列（含 ℰ_deadline 的截止期挤压攻击），执行器在 B_t 内返回带证书的计划，miss 率 ≤ ε_dm；一次 miss 只能把计划推向**更保守**的格元素（绝不更激进）；R68 定理 15 的控制连续性保持。**对抗性截止期压力只会单调增加保守性，不能造成不安全动作。**（依赖 WCET 界与预留 headroom；A99 失效时 miss 界退化为实测 P99。）

**定理 20（车队爆炸半径）** 在 A99–A102 下，若被攻陷智能体比例 ≤ α：(i) 池化标定偏差 ≤ τ_ece + Cα（引理 22）；(ii) 任一智能体的注意力份额 ≤ C·M，累计浪费有界（引理 21）；(iii) 除非总需求超过容量，任何智能体不能造成他人截止期 miss；超容量时全体优雅降级到 R68 端点。故**单个被攻陷智能体的爆炸半径有界且被写进每个受影响证书**。残余漏洞：共享快模型/共享缓存是**共模通道**，不在逐智能体鲁棒性覆盖内——这正是本轮最大风险。

## 6. 本轮最大风险

**一句话**：TEMPO 的可信度全押在「**被抽检的 tick 与真正影响安全的 tick 同分布**」这一平稳性假设上（A101）——一旦部署非平稳、或审计种子可被推断（攻击者在被审计时表现良好、其余时刻作恶），统计证书覆盖的就是**错误的分布**；而快路径、池化标定、共享缓存又是**车队共模**的，于是 R69「问错」只是单个智能体问错一次，TEMPO「问错」会让整支车队在同一秒一起自信地问错——**可扩展性把一个局部错误放大成一场系统性事故**。

**次级风险与缓解**：
1. **A99 失效（WCET 抖动超界）→ 截止期保证变弱** → 实测 P99 兜底 + headroom 自适应 + miss 计入证书，绝不静默；
2. **快路径分布漂移** → SRM 置信序列持续监控 + gap 越界即回退慢路径/R68（定义 316）；
3. **注意力拍卖被操纵** → 事后 VoI 审计 + κ 乘性衰减 + 公平上限（引理 21）；
4. **池化标定被单点污染** → median-of-means + 残差一致性检验 + 隔离（引理 22）；
5. **共享缓存共模故障** → 版本钉死 + 确定性校验 + 缓存条目抽样审计（定义 320），但仍是最难消除的残余风险。

```python
    rho = realized / max(claimed, EPS)
    kappa[i] *= exp(-ETA * max(0.0, 1.0 - rho)); return kappa[i]

# IP-276 主闭环（继承 R69，插入预算/认证/拍卖/回退）
def TEMPO_RAS_round(M, o_t, B_t):
    out, done = M.tae.run(o_t, B_t)
    U_ale, U_epi, modes = out.U_ale, out.U_epi, out.modes
    a_hat = M.fma.flow_anomaly(...) if T2 in done else None
    slow  = (a_hat is not None) and a_hat > TAU_FMA and M.last_r_res < TAU_RES
    g = None
    if T3 in done and U_epi > TAU_EPI and not slow:
        if M.faa.win(M.agent_id, bid=best_voi(modes)):
            g = M.mint.choose_interaction(modes, o_t, M.budget)
    U_epi = M.cia.update_belief(modes, M.cia.execute(g)) if g else U_epi
    lam = anytime_lam(M, U_ale, U_epi, out.U_comp)
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    if M.srm.requires_fallback(): lam, k, g = M.r68.fallback(...)
    M.srm.observe(M.agent_id, out); M.vqa_f.log(g, U_epi, a_hat)
    return k, lam, select_mode(modes, U_epi, lam), M.j_tempo(...)
```

## 4. 推导

**引理 19（随时单调性与中断安全）** A99 下，任意中断点返回 σ_done⊆σ 且 U_comp 更大；完成层越少 λ 越大；C-RAS-WM 认证前缀 + λ_floor 在每个中断点都合法；`Risk(Π_{σ_done}) ≤ Risk(Π_σ)+O(ΔU_comp)`。⇒ **中断只微增风险、永不破坏安全**；E[Risk] 是 B 的非增阶梯函数。

**引理 20（抽样认证复杂度与车队并行）** gap∈[0,1] 的 empirical-Bernstein 需 `n=O(σ̂²log(1/δ)/ε²+log(1/δ)/ε)` 样本；抽检率 p 下认证延迟 = n/p tick；跨 N 智能体池化审计则每智能体摊薄 n/N、近似与 N 无关——**但仅在 (快,慢) 分布可交换时成立**，异构/版本漂移破坏可交换性 ⇒ 必须逐智能体认证。

**引理 21（拍卖近似与反 DoS）** κ 加权 VoI 对槽位单调子模 ⇒ 贪心 (1−1/e) 近似；指数权重更新下累计后悔 `O(√(T log N))`；报价通胀 γ 倍者在审计率 p 下 κ 以 `exp(−η(1−1/γ)pT)` 衰减 ⇒ 长期份额被公平上限 C·M 截断，累计浪费槽位有界。⇒ **无注意力 DoS 崩溃，只有可测且有界的低效**。

**引理 22（鲁棒池化污染界）** 池中 α 比例对抗样本、样本有界，K 块 median-of-means（K=⌈8log(1/δ)⌉）在 α<1/2 时误差 ≤ `3σ_b+Cα`，故 `ECE_pooled ≤ C(σ√(log(1/δ)/n)+α)`。⇒ ECE 门须抬高 Cα_max；α≥1/2 时 MoM 失效必须隔离；朴素平均可被任意拉偏。

**定理 18（预算索引严格包含与单调性）** A99–A100 下：Π_{B_min} 与 R68 逐指令相同；Π_{B_max} 在证书有效时与 R69 逐指令相同；B↦E[Risk(Π_B)] 单调不增；任意中断落回退格并有 J_TEMPO。⇒ **R68/R69 是同一条 Π_B 谱的两个端点，而非并列系统**。

**定理 19（实时安全与对抗挤压）** A99、A101 下，任意输入（含截止期挤压）都在 B_t 内返回带证书计划，miss ≤ ε_dm；miss 只把计划推向更保守格元素；控制连续性（R68 定理 15）保持 ⇒ **对抗性截止期压力只单调增加保守性，不能造成不安全动作**。

**定理 20（车队爆炸半径）** A99–A102 下，若被攻陷智能体 ≤ α：池化偏差 ≤ τ_ece+Cα；单机注意力份额 ≤ C·M 且累计浪费有界；除非总需求超容量，任何智能体不能造成他人 miss，超容量则全体优雅降级到 R68。⇒ **单点攻陷的爆炸半径有界且写入每个受影响证书**；残余共模通道（共享快模型/缓存）是本轮最大风险。

## 7. 本轮最大风险

**一句话**：TEMPO 的可信度全押在「**被抽检的 tick 与真正影响安全的 tick 同分布**」这一平稳性假设上（A101）——一旦部署非平稳、或审计种子可被推断（攻击者在被审计时表现良好、其余时刻作恶），统计证书覆盖的就是**错误的分布**；而快路径、池化标定、共享缓存又是**车队共模**的，于是 R69「问错」只是单个智能体问错一次，TEMPO「问错」会让整支车队在同一秒一起自信地问错——**可扩展性把一个局部错误放大成一场系统性事故**。

**次级风险与缓解**：WCET 抖动超界（实测 P99 兜底 + 自适应 headroom + miss 计入证书）；快路径分布漂移（SRM 置信序列持续监控，越界回退慢路径/R68）；注意力拍卖被操纵（事后 VoI 审计 + κ 乘性衰减 + 公平上限）；池化标定被单点污染（median-of-means + 残差一致性隔离）；共享缓存共模故障（版本钉死 + 确定性校验 + 缓存条目抽样审计，仍是最难消除的残余风险）。
