# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「情感语音」×「虚实迁移」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**情感探针 + 间隙担保 + 迁移台账**。两个灵感不是两个补丁，而是一条闭合回路：**情感语音是虚实间隙的低成本、无标签探针；虚实间隙又是迁移证书的在线担保来源**。新模块一律为可选增强：语音缺失/质量不足 ⇒ 注入真空证据（log-odds≡0），严格等价退回 v9（引理 93），而非行为漂移。

## 0. 直觉与动机

**灵感 1（情感语音 → 不识别"情绪"，而测量"模型错得多离谱"）**
直觉：v9 最大的风险是前向模型在域偏移时最不可靠。我们一直用物理传感器去找偏移，却忽略了一个信息量极高、几乎零成本的通道——人的情感语音。人会在机器人做错事时惊讶、紧张、退缩（韵律：基频、语速、能量、停顿、紧张性发声），在机器人做对时放松。关键洞察：**我们不需要给情感贴"开心/愤怒"的绝对标签，只需要问"人的反应是否偏离了仿真人模型预测的反应"**。偏离量 r_aff 就是一个**无标签的虚实间隙探针**。它绕开了情感识别最脆弱的环节（跨文化绝对标签），只保留最稳健的环节（个体内相对残差），并获得一个可证伪的"领先性假设" H_lead：情感残差应当先于物理域偏移越阈出现。

**灵感 2（虚实迁移 → 证书不能"凭空"从仿真搬进现实）**
直觉：v9 的块证书由仿真/离线数据训练的前向模型给出，但证书的**管辖权**只在仿真分布内。虚实迁移的教训是：任何 sim 产物进入 real 必须携带"间隙担保"。因此把"迁移"做成证书的一等属性：每张证书带 provenance ∈ {sim, real, mixed} 与间隙膨胀项 β_real = β_sim + λG_t，其中 G_t 是**共形**（conformal）间隙上界。间隙越大，证书越"缩水"（K_eff↓、信任域↓），直至退回 v9 单步。迁移不再是"训练完就部署"，而是**在线、可审计、可回滚的证书再担保**。

**合成：一条 A→G→C / S→R→S 回路**
情感残差（A）→ 间隙估计（G）→ 证书再担保（C）；仿真（S）→ 现实（R）→ 仿真影子验证（S）。情感通道给间隙提供**领先指标**，间隙给迁移提供**担保尺度**，迁移台账又反过来校准情感探针的个体基线。三者互为因果，闭环自校准；任一环缺失则注入真空元，退回 v9 对应退化级。

## 1. 研究问题（轮次升级版）

- **Q1（情感探针可辨识性）**：在什么条件下，个体内情感残差 r_aff 能一致估计 sim-real 间隙而不被文化/个体/任务混淆？"领先性假设"H_lead（情感残差先于物理域偏移越阈）是否可证伪、且在领先失效时是否仍不影响安全？
- **Q2（间隙担保的统计有效性）**：共形间隙上界 G_t 在非平稳、非可交换的人机交互中能否维持 1−α 覆盖？交换性失效时如何用块级/加权共形补救，并把残余风险折进 λ？
- **Q3（迁移安全与抗操纵）**：间隙膨胀后的证书能否把 v9 引理 82 的块安全论证从仿真搬到现实而不累积"证书债务"？情感输入（含对抗伪造）能否被证明为**安全单调**——只能更保守，永不放宽？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 情感即探针律（Affect-as-Probe）**
情感语音只以**残差**形式进入系统：r_aff(t) = d(x_aff(t), Ĥ_sim(交互上下文))，经个体基线归一化。不做绝对情绪分类、不把情感直接映射为安全阈值；探针的价值在"模型错了"而非"人怎么了"。

**P14 迁移证书律（Gap-Inflated Transfer）**
每张证书携 provenance 与间隙担保：β_real = β_sim + λG_t，G_t 来自共形上界。sim-only 证书为**临时证书**，只能授权 K=1 或必须经 M₀ 硬检查；升格为 mixed/real 需 ≥N 次真实影子验证且零违背（引理 92）。间隙越界 ⇒ 证书降级、K_eff 收缩、信任域腐蚀。

**P15 情感安全单调律（Affective Safety Monotonicity）**
情感信号只可调制**社会性权重**（接近距离偏好、语速/音量、节奏）于有界集内，永不调制 τ_safe、d_safe、K 门控与 M₀ 判据。故任意情感输入（含伪造）下可行动作集 ⊆ v9 可行集（引理 91）；伪造"开心"锁不开危险动作，伪造"痛苦"至多导致保守停驻。

## 3. 与基线的接口（如何退化到 v9）

- 无语音 / 语音质量 q_t=0 ⇒ 情感证据 e_aff=0（log-odds 真空元），间隙仅由 r_phys/Δ_dom 构成 = v9；
- PRP 失效 ⇒ r_aff≡0，情感期望 Â 退化为常数，等价 v9 块；
- RGF 失效 ⇒ G_t≡0，证书不退火也不膨胀，等价 v9 的 β，P14 自动关闭；
- TCL 失效 ⇒ 所有证书按 v9 单一 provenance 处理，台账停写，等价 v9；
- ASG 失效 ⇒ 丢弃情感调制，社会权重取 v9 默认，等价 v9 ER；
- v9 的 AC/MW/ID 任一失效 ⇒ 各自中立元，退回 v8；全部失效 ⇒ v7 → v6。

## 4. 预期贡献

1. **情感即探针**：把情感语音从"情绪识别任务"重新表述为"世界模型残差探测"，给出无标签可辨识条件与可证伪的领先性实验（E571–E572）；
2. **共形虚实间隙 + 迁移证书**：分布无关的间隙上界，使 v9 块证书的安全论证可**在线再担保**地跨 sim→real（引理 88–89）；
3. **情感安全单调性**：证明情感通道（含对抗伪造）只能收紧、不能放宽安全包络，正面破解"情感操纵"攻击面（引理 91）；
4. **迁移台账与证书债务审计**：把"多少安全裕度其实押在仿真上"变成可量化指标（定义 546，E581）。

## 5. 本轮最大风险

**一句话**：情感残差以仿真人模型 Ĥ_sim 为参照，而 Ĥ_sim 与被检测的物理前向模型共享同一套仿真假设——若二者同源同错，则"情感探针"与"被探的间隙"一起失明，形成**自指盲区**；叠加情感可伪造、文化特异，r_aff 可能把"个体怪癖"误判为"世界变了"。

**新增定义 540（情感语音状态 AffectiveSpeechState）** 在 10Hz 帧上，冻结的纯韵律编码器 E_aff 输出 x_aff(t)=(v̂,â,û,ê)：效价-唤醒二维情感核 + 认知不确定性 û + 社会投入度 ê，并给出质量 q_t。**仅用声学韵律，不做 ASR/词法解码**（隐私与跨语言泛化）；û 由轻量深度集成/分位数头估计。

**新增定义 541（情感残差 AffectiveResidual）** 设 Ĥ_sim 为仿真/离线先验训练的人反应模型。对交互窗 [t+1,t+H]（H=1s）：
```
r_aff(t) = || W_t^{-1/2}·( x_aff(t+1:t+H) − b_u − Ĥ_sim(a^{1:K}, c_t) ) ||
```
b_u 为用户个体基线（滑窗中位数，冷启动取群体先验）；W_t 为逐用户/逐场景残差协方差。**残差而非分类**：只问"偏离预测多少"，不问"是什么情绪"。

**新增定义 542（物理残差 PhysicalResidual）** 复用 v9 已有量并归一：
```
r_phys(t) = ||F̂(s_t,a_t) − s_{t+1}||_Q + ||e_visual||/σ_v + ||ν_SLAM||/σ_s
```
它既是 v9 AC 的前向模型误差，也是虚实间隙的物理侧证据；与 r_aff 独立采样、可异步。

**新增定义 543（虚实间隙证据 GapEvidence）** 在 log-odds 域线性融合，使"无证据"恰为加法恒等元 0：
```
e_t = w_aff·ρ_aff(r_aff/q_proxy) + w_phys·ρ_phys(r_phys) + w_dom·logit(clip(Δ_dom/τ_dom,ε,1−ε)) + b
ĝ_t = σ(e_t)
```
ρ 为单调有界（如 tanh）的标准化。**真空元**：q_t<q_min ⇒ e_aff 项取 0（而非负值），保证"没有麦克风"不被误读为"世界正常"。

**新增定义 544（共形间隙上界 ConformalGapBound）** 维护按 regime（场景/用户群/光照/地面材质）分层的校准集 D_cal={(上下文, 真实间隙)}，真实间隙由离线 sim-real 配对（数字孪生回放、动捕真值）或影子执行差值给出。采用**块共形**以对抗时间相关：
```
G_t = ĝ_t + Q_{1−α}( { g_i − ĝ_i : i ∈ 同 regime 的校准块 } )
```
在块内可交换假设下 P(g_t ≤ G_t) ≥ 1−α；非平稳越出块长时，覆盖率退化量被显式折入 λ（引理 88）。校准集按时间滑窗更新，防止"陈旧的间隙分布"。

**新增定义 545（迁移证书 TransferCertificate）** 证书不再是无来源的断言，而是带管辖域的对象：
```
cert = (id, content, p ∈ {sim, real, mixed}, β_p, G_issue, V, provisional)
```
迁移算子 T_λ：β 膨胀 β_real = β_p + λ·G_issue（λ≥1），有效域腐蚀 V_real = V ⊖ G_issue（距离/间隙维度各减 G）。p=sim ⇒ provisional=true，**禁止授权 K>1、禁止绕过 M₀**。

**新增定义 546（迁移台账 TransferLedger）** 只增、哈希链（hash_prev）防篡改的记录：entry=(cert_id, p, G_issue, shadow_outcome, ts, hash_prev)。升格规则：sim→mixed 需 N=30 次真实影子执行零违背；mixed→real 需 M=200 次且覆盖 ≥3 个 regime。证书债务：
```
D = Σ_cert weight(cert)·1[p=sim]·β_cert
```
D 的上升意味着系统安全裕度越来越依赖未经验证的仿真假设，触发离线重标定。

**新增定义 547（情感安全门 AffectiveSafetyGate）** 情感仅写入社会性参数 s_social（接近距离偏好、语速/音量、节奏、停顿）：
```
u_social = clip(K_s·x_aff, −Δ_social_max, +Δ_social_max)
s_social ← clip(s_social^v9 + u_social, S_bounds)
```
**不变式 φ_aff**：τ_safe、d_safe、K_eff 门控、信任域 U_t、M₀ 判据对 x_aff 的偏导恒为 0。情感因此只能改"怎么做得更舒服"，不能改"什么算安全"。

**新增定义 548（情感-物理一致性 AffectPhysicsConsistency）**
```
cons_t = ½( sign(r_aff) == sign(r_phys) ) + ½·exp(−|r_aff−r_phys|/σ_c)
w_aff(t) ← w_aff^0·(γ + (1−γ)·cons_t)
```
仅情感大而物理静 ⇒ cons 低 ⇒ 降权（判为个体怪癖/表演）；情感与物理同向大 ⇒ cons 高 ⇒ 增权（判为真实间隙）。阻断"用怪癖冒充世界变化"。

**新增定义 549（情感期望块 AffectiveExpectationChunk）** 把 v9 动作块扩为 ζ_t^aff=(a^{1:K},Ĉ_t,P_t,Â_t)，Â_t 为 Ĥ_sim 预测的情感轨迹 + 置信带。若 P(Â 越出舒适集)>η ⇒ 在块内插入社会性暂停或缩短 K（仅改社会节奏，不放松安全）。

        if q < self.q_min:
            return AffectEvidence(vacuous=True)              # e_aff ≡ 0（定义 543）
        x = self.head(self.E(audio))                         # (v,a,u,e) @10Hz
        b_u = self.baseline.get(ctx.user_id, prior_baseline())
        pred = self.Hmodel.predict(ctx.last_chunk, ctx.context)   # Ĥ_sim 轨迹
        r = mahalanobis(x - b_u, pred, self.W)               # 定义 541
        return AffectEvidence(r=r, x=x, q=q,
                              logodds=rho_aff(r / q_proxy(q)))


# IP-358 RealityGapFusion：虚实间隙融合器
class RealityGapFusion:
    def __init__(self, calibrator, alpha=0.05, lam=1.2):
        self.cal, self.alpha, self.lam = calibrator, alpha, lam
        self.w_aff, self.w_phys, self.w_dom, self.b = 1.0, 1.0, 1.0, 0.0

    def fuse(self, ev, r_phys, delta_dom, tau_dom, regime):
        e_aff = 0.0 if ev.vacuous else self.w_aff * ev.logodds   # 真空元
        e = (e_aff
             + self.w_phys * rho_phys(r_phys)
             + self.w_dom * logit(clip(delta_dom / tau_dom, 1e-3, 1 - 1e-3))
             + self.b)
        ghat = sigmoid(e)
        q = self.cal.block_quantile(self.alpha, regime)      # 定义 544
        return Gap(ghat=ghat, G=ghat + q, e=e)

## 4. 推导

**引理 87（情感残差的无标签可辨识性）** 设加性模型 x_aff = b_u + Ĥ_sim(a,c) + δ_gap + ε，E[ε]=0，b_u 已由个体基线减除，W_t 为残差协方差。则 E[r_aff²] = ‖δ_gap‖²_{W^{-1}} + tr(I)（噪声项），故 r_aff 是间隙**幅度**的一致估计；但它不能识别 δ_gap 的符号/方向与绝对情绪，只能识别"条件偏离"。证明：展开平方期望，交叉项因 E[ε]=0 消失；符号不可辨识由 δ_gap→−δ_gap 与 ε→−ε 同分布构造。故 r_aff 只做探针、不做情绪分类，且需 cons_t 与 Ĥ_sim 校准才可用。∎

**引理 88（共形间隙上界的覆盖）** 若校准块与测试块在同一 regime 内（块）可交换，split/块共形给出 P(g_t ≤ G_t) ≥ 1−α。若过程仅 β-混合而非可交换，覆盖率下界退化为 1−α−O(β_block)；选择块长 ≥ 混合时间并把退化折入 λ（或增大 α 修正）可恢复保守性。故 G_t 是**分布无关**上界，其有效性以 regime 划分为前提。∎

**引理 89（迁移证书的安全性传递）** 设 v9 引理 82 的仿真证书满足 ĝ_min = min F̂ − β_sim ≤ 真实仿真间隙；由引理 88 以概率 ≥1−α 有真实间隙 ≤ G。取 β_real = β_sim + λG（λ≥1），则真实间隙下界 = min F̂ − β_real ≤ min F̂ − β_sim − 真实间隙 ≤ 真实现实间隙。于是 v9 的块证书保守性与中止安全性（引理 82）逐条搬到现实，概率损失仅 1−α。∎

**引理 90（领先性不影响安全，只影响性能）** 情感与间隙只经两条路径进入系统：① 收缩 K_eff/信任域（单调收紧）；② 插入社会暂停（不改安全判据）。是否 τ_lead>0 只改变"提前多久收缩"，不改变收缩本身的保守性。故 H_lead 为假时最坏退化到 v9 的检测时延，安全不变；领先性只提升性能与舒适度。∎

**引理 91（情感安全单调性与抗操纵）** ASG 写集仅为 S_bounds 内的社会参数；安全约束 τ_safe、d_safe、K 门控、U_t、M₀ 对 x_aff 的偏导为 0（φ_aff）。可行动作集 A(s; x_aff) = {a : M₀(a) ∧ SpatialCert(a) ∧ stop_inv(a)} 与 x_aff 无关，故 A(s;x_aff) ⊆ A_v9(s)。任意伪造情感（效价拉满或痛苦满格）只能改 S 内分量；"开心"不增大 A，"痛苦"至多诱导保守停驻。∎

**引理 92（证件升格健全性）** 临时证书被 can_authorize 禁止授权 K>1；升格需 N 次真实影子零违背。若真实违背率 p，则漏检概率 (1−p)^N，取 N=30 可保证 p≥0.1 时漏检 ≤4.2%。哈希链使历史不可回改，故不存在"超出 provenance 被使用"的证书。注：这是统计保证而非绝对保证，需台账持续审计（E581）。∎

**引理 93（v10→v9 逐位退化）** 令 e_aff=0（真空元）、G≡0、provenance 单一、ASG 恒等：则 RGF 输出 e = w_phys·ρ_phys + w_dom·logit(Δ_dom/τ_dom)+b 与 v9 的间隙/偏移判据一致（b 标定为 v9 等效阈值）；TCL β=β_base=v9 β、can_authorize 恒真；K 门控=v9 K_eff；社会参数=v9 默认。逐项代入即 v10 方程组逐项等于 v9，再由 v9 引理 83 的中立元复合得日志逐位等价。∎

**命题 94（回路收敛性，弱形式）** 在 Ĥ_sim 与 F̂ 误差有界、校准集按块更新且 b_u 估计一致的前提下，A→G→C 回路的不动点满足：间隙上界 G* 与证书裕度 β* 互为单调有界映射，由 Brouwer 不动点定理存在（未必唯一）；双阈值与块共形保证回路迭代不会无界振荡。唯一性与收敛速率留作开放问题。∎
