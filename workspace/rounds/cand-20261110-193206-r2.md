# 第 48 轮（承接第 47 轮产物 v24；本轮灵感：数据集构建 × 任务分解） · Decomp-Data-Cert：任务分解树上的组合证书与主动数据集构建（六层架构 v12）

> 承接第 47 轮产物 v24 Sim-Real Grasp-Cert。v24 用 Gazebo 证伪、模式感知抓取证书与 sim-to-real 许可证把「仿真绿 → 实机红」的证书洗白显式化，但仍站在两个隐含假设上：**H6a「校准证书的数据是被动日志形成的固定数据集，天然可交换，且可跨查询/跨场景复用」**；**H6b「任务是原子查询，证书只需对单次姿态/抓取负责，组合性由下游自然继承」**。**数据集构建**精确击中 H6a：证书宽度本质上由数据覆盖决定，被动采集永远覆盖不到 `Ω_deg × 对称类型 × 摩擦档` 的稀有失效层，而跨场景复用数据又会破坏共形/统计保证的可交换性。**任务分解**击中 H6b：长程任务必须拆成子任务，每个子任务各自持证，最朴素的并集界 `Σα_v` 会把全局失败预算迅速烧穿，且子任务切换处的 handoff 状态根本不在任何单叶数据集中。三者耦合出新问题：**如何联合选择任务分解粒度与每节点的数据集构建方案，使「叶证书有效 + 数据充分 + 复用无偏 + handoff 覆盖」能推出组合证书 soundness；若分解边界切错或复用偏差被漏计，每个叶证书都成立，整任务却在切换处静默失效**。

## 0. 直觉与动机

**灵感 1（数据集构建 → 证书的数据充分性，而非数据数量）**
直觉：证书不是被算法证明出来的，而是被数据“撑”出来的。与其继续被动记录，不如把数据采集变成**面向证书失败模式的主动构建**：给定节点 v 的失败预算 `α_v` 与场景网格 `X_v`，先算每格最少样本 `n_v^min`，再在配额、能量与时间约束下主动补最欠覆盖/最高不确定/最能复现反例的样本。关键不是「有多少帧」，而是「每一层是否达到可签发证书的样本下界」。数据护照记录来源（sim/real）、上下文、时间、种子与泄漏标签。

**灵感 2（任务分解 → 证书预算的分解与 handoff 覆盖）**
直觉：整任务安全不是单叶安全的简单相加。分解树 `T` 的叶节点各分一份失败预算 `α_v`，组合失败由并集界 `Σα_v` 控制（对任意相关性都成立，代价是保守）。粒度是一个真实的权衡：切得细，单叶证书半径小、易校准，但叶数与切换态变多、并集界变松、数据需求膨胀；切得粗，叶证书难、半径大、下游抓取/姿态更易越界。此外，叶与叶之间还有 **handoff 分布** `P_handoff`，它既不属于前叶也不属于后叶，必须单独建数据集并单独持证。

**灵感 3（耦合 → 分解-数据联合可行性证书）**
直觉：分解与数据不是两步串行，而是双向约束。分解决定数据需求，数据预算不足又反过来迫使分解粗化或提高单叶 `α_v`。因此要解一个双层问题：外层选分解/切点，内层在预算下做数据构建；若联合不可行，则粗化分解、补采，或直接 fail-closed。任何「叶证书都绿」都不等于「组合证书绿」——组合证书必须显式携带并集界、复用偏差 `b_{uv}`、数据覆盖误差与 handoff 覆盖状态。

**耦合升级**：在 v11 根信任 + L1–L5 上新增 **L6 任务-数据层（Task-Data Plane）**，并把 L4 DCL 从「采集带护照」升级为「按分解树节点配额主动构建数据集」。根信任层新增 **分解-数据联合租约 `ℓ_d`**，与 `ℓ_p,ℓ_e,ℓ_s` 并列：`ℓ_d` 记录分解版本、各节点数据充分性、复用边与偏差上界。六层 v12：根信任（`ℓ_p,ℓ_e,ℓ_s,ℓ_d`）+ L1 几何/抓取 + L2 上下文/gap + L3 CAR/抓取安全 + L4 DCL/主动数据构建 + L5 SFL/S2R + L6 TDC/DRC/联合可行性。

## 1. 形式化定义（增量：定义 65–70）

**定义 65（任务分解树与证书预算）**
任务 `τ` 分解为树 `T=(V,E)`，根为 `τ`，叶为原子技能；每条边 `(u,v)` 携带 handoff 分布 `P_handoff(u→v)`。节点 `v` 分配失败预算 `α_v>0`，全局预算约束
`Σ_{v∈V} α_v ≤ α_task`。
沿真实执行路径 `S⊆V`，组合失败满足**无分布并集界**
`P(∪_{v∈S} A_v) ≤ Σ_{v∈S} α_v`。
**粒度权衡**：`α_v` 越小单叶越难但组合界越紧；切分越细叶数 `|S|` 越大，`Σα_v` 与 handoff 数同步膨胀。

**定义 66（证书-数据需求函数）**
节点 `v` 的场景网格 `X_v`（层 × 对称类型 × 材质 × 摩擦档），每格目标覆盖容差 `ε_v`、置信 `δ_v`。每格最少样本
`n_v^min = ⌈ ln(2|X_v|/δ_v) / (2 ε_v^2) ⌉`（Hoeffding + 网格并集界；共形场景用分位数反解）。
需求向量 `d_v=(n_v^min, {q_{v,c}}_{c∈X_v})`，其中 `q_{v,c}` 为分层配额。**数据充分性** `S_v = 1[∀c: n_{v,c} ≥ q_{v,c}]`。handoff 边 `(u,v)` 同样有需求 `d_{uv}` 与 `S_{uv}`。

**定义 67（主动数据集构建）**
采集池 `P`，采集策略 `π_D` 逐条选 `x∈P`，最大化
`U(x)=λ_c·1[cell(x) 未达配额] + λ_u·uncertainty(x) + λ_f·1[x 复现反例] − λ_e·energy(x)`。
数据护照 `p(x)=(source, time, context, sim/real, seed, leakage_tags)`，数据集 `D_v={x_i,p_i}`。
在配额约束下 `U` 的覆盖项近似次模，贪心达到 `(1−1/e)` 近似；**数据充分性证书** `S_v(D_v)` 只在配额全达标时签发。

**定义 68（数据复用与可交换性）**
复用图 `R`，边 `(u,v)` 表示把 `D_u` 用于节点 `v`。复用许可需通过可交换性检验（MMD 或域分类器，显著性 `γ_r`、AUC 阈 `τ_r`）。不通过时估计偏移 `b_{uv}`，并令
`b(D_v) = max_{(u,v)∈R_used} b_{uv}`。
**无偏复用**要求 `b(D_v) ≤ b_max` 且检验不拒绝；否则视为新增失败预算项。

**定义 69（分解-数据联合证书）**
`J_t=(T, {D_v}, {P_v}, {ℓ_p,ℓ_e,ℓ_s,ℓ_d}, b, S_edge)`。**联合 soundness**：
`P(composed task safe) ≥ 1 − Σ_{v∈S} α_v − Σ_{(u,v)∈R_used} b_{uv} − e_data`，
其中 `e_data` 为覆盖估计的有限样本误差。有效性要求：`S_v=1`、`S_edge=1`、复用检验通过、`b≤b_max`、各租约有效。任一项为假 ⇒ fail-closed 或重规划，不得以其他项强补偿。

**定义 70（分解-数据联合分配）**
选择 `T` 与各节点采集量 `{n_v}`：
`min_{T,{n_v}} E[cost(T,{D_v})]  s.t.  Σ_v α_v ≤ α_task,  Σ_v cost(D_v) ≤ B_data,  S_v=1, S_edge=1, b≤b_max`。
外层离散搜索分解/切点，内层贪心数据构建；不可行时依次尝试：粗化分解 → 提高单叶 `α_v` → 补采 → fail-closed。

## 2. 新增产出与既有 IP 升级

**IP-72 TDC（Task Decomposition Certifier）**
- 任务规划器 + 技能库 → 分解树 `T`，检查前后置条件与可执行性
- 按 `hardness(v)` 加权分配 `α_v`，控制 `Σα_v ≤ α_task`
- 识别 handoff 边并生成 `d_{uv}, S_{uv}` 义务
- 粒度搜索：在组合界与数据可行性间选折中；预算耗尽则显式报告不可行

**IP-73 ADC（Active Dataset Constructor）**
- 分层场景网格与配额管理器
- 采集效用 `U(x)`：覆盖增益 + 不确定性 + 反例复现 − 能量成本
- 次模贪心选样，输出数据护照与数据充分性证书
- sim 数据先采、按 `ε(c)` 折扣后并入；real 数据优先补 `Ω_deg` 层

**IP-74 DRC（Dataset Reuse & Exchangeability Checker）**
- 维护复用图 `R` 与每个数据集的上下文/来源元数据
- 边级两样本可交换性检验，估计偏移 `b_{uv}`
- 拒绝不安全复用；漂移超阈触发重采并吊销 `ℓ_d`

**既有 IP 升级**
IP-61 DCL：从「采集带护照」升为「按分解节点配额主动构建数据集」，计入能量与 handoff 数据
IP-62 CCA：新增分解切点红队、并集预算耗尽测试、复用泄漏/分布漂移检测
IP-51 CAR：守卫扩展为联合证书 `J_t`，数据不充分或 handoff 未覆盖即 fail-closed
IP-60 PSE：按节点签发姿态证书，向抓取层传播；节点数据不足则拒绝签发
IP-63 ECPS：为数据构建预留能量租约；能量紧张时推迟非关键采集并切保守证书
IP-45 总线：新增 task-tree / data-quota / reuse-edge / data-passport / handoff-cert 话题

## 3. 算法骨架

每个任务周期：
1. TDC 由任务 `τ` 生成分解树 `T`，分配 `α_v`，算出需求 `{d_v}` 与 handoff 边义务
2. DRC 查询可复用数据集，检验可交换性并累计偏差 `Σb_{uv}`
3. ADC 在剩余能量/时间预算下补齐缺失节点与 handoff 数据
4. 若数据不充分或预算不可行 → 粗化分解/补采；仍不可行 → fail-closed
5. 逐叶签发姿态/抓取证书 `P_v`，检查 handoff 覆盖 `S_edge`
6. 组装 `J_t`，CAR 守卫 `J_t`；SAB 绑定失败入安全队列
7. 执行结果与采集样本写回 DCL，更新覆盖、复用图与 `ℓ_d`

## 4. 本轮最大风险

**一句话**：分解最容易在 handoff 边界切错——每个叶节点的数据集只覆盖该叶的状态分布，却不覆盖叶间切换分布，于是所有叶证书都有效、并集界也满足，整任务却在切换瞬间静默失效；因此必须为 handoff 单独建模/采集/持证，并让组合证书显式守卫切换覆盖，而不是仅逐叶校验。

## 2. 关键算法伪代码

### IP-72 TDC

```
def build_decomp(task, skill_lib, planner, alpha_task, eps_max):
    T = planner.decompose(task, skill_lib)          # 前后置条件校验
    leaves = T.leaves()
    w = softmax([hardness(v) for v in leaves])      # 难度→预算权重
    alphas, demands = {}, {}
    for v, wv in zip(leaves, w):
        alphas[v] = alpha_task * wv
        X_v = scenario_grid(v)
        d_v = (min_samples(alphas[v], eps_max, delta, len(X_v)),
               quotas(X_v, alphas[v]))
        demands[v] = d_v
    edges = [(u, v) for (u, v) in T.edges
             if is_handoff(u, v)]                     # 切换边
    for (u, v) in edges:
        demands[(u, v)] = handoff_demand(u, v, alphas[v])
    return T, alphas, demands, edges

def min_samples(alpha, eps, delta, n_cells):
    return ceil(log(2 * n_cells / delta) / (2 * eps**2))

def feasible_budget(T, alphas, alpha_task, B_data, cost):
    if sum(alphas.values()) > alpha_task + 1e-12:
        return False
    if sum(cost(v) for v in T.nodes) > B_data:
        return False
    return True
```

### IP-73 ADC

```
def acquisition_utility(x, D, quotas, calib, lam=(1.0, 0.5, 0.7, 0.2)):
    lc, lu, lf, le = lam
    cover = 1.0 if quotas[cell(x)] - count(D, cell(x)) > 0 else 0.0
    unc = predictive_entropy(calib, x)
    rep = 1.0 if reproduces_known_counterexample(x) else 0.0
    return lc * cover + lu * unc + lf * rep - le * energy(x)

def construct(pool, demand, budget, quotas, calib):
    D = []
    while budget > 0 and not quotas_met(D, quotas):
        # 次模贪心：边际覆盖增益最大者优先
        x = max(pool, key=lambda z: acquisition_utility(z, D, quotas, calib))
        D.append((x, passport(x)))
        pool.remove(x)
        budget -= energy(x)
    return D, quotas_met(D, quotas)

def data_sufficient(D, demand):
    n_min, quotas = demand
    if len(D) < n_min:
        return False
    return all(count(D, c) >= q for c, q in quotas.items())
```

### IP-74 DRC

```
def reuse_check(D_u, D_v_features, gamma_r=0.01, tau_r=0.1):
    if len(D_u) < MIN_REUSE_N:
        return False, float('inf')
    test = two_sample_test(features(D_u), D_v_features)   # MMD / 域分类器
    auc = domain_auc(features(D_u), D_v_features)
    if test.pvalue < gamma_r or auc > 0.5 + tau_r:
        b = estimate_shift(features(D_u), D_v_features)   # 偏移上界
        return False, b
    return True, 0.0

def resolve_reuse(T, demands, DR):
    used, bias = {}, 0.0
    for v in T.nodes:
        hit, b = DR.lookup(v, demands[v])
        if hit is not None and hit.exchangeable and b <= B_MAX:
            used[v] = hit.D
        else:
            bias += b
    return used, bias
```

### 全局决策集成

```
def decomp_data_decision(task, c_t, B_t, v_t, calib, DR, pool):
    T, alphas, demands, edges = build_decomp(task, skill_lib, planner, alpha_task, eps_max)
    used, bias = resolve_reuse(T, demands, DR)

    missing = [v for v in list(T.nodes) + edges if v not in used]
    if energy_lease_invalid(B_t, reserved=sum(data_cost(v) for v in missing)):
        return 'fail-closed', 'energy'

    for v in missing:
        D_v, ok = construct(pool, demands[v], energy_to_budget(B_t), demands[v][1], calib)
        if not ok:
            if can_coarsen(T):                      # 粗化分解，减少叶数与数据需求
                T, alphas, demands, edges = replan_coarser(T)
                continue
            return 'fail-closed', 'data-insufficient'
        used[v] = D_v

    for v in T.leaves:
        if not data_sufficient(used[v], demands[v]):
            return 'fail-closed', 'data-insufficient'
        P_v = pse_certify(obs_at(v), c_t, used[v])  # 数据不足会拒绝签发

    if not all(handoff_covered(used[e], demands[e]) for e in edges):
        return 'fail-closed', 'handoff-gap'

    J = joint_cert(T, used, alphas, bias)
    if sum(alphas.values()) + bias + J.e_data > alpha_task:
        return 'fail-closed', 'budget-exhausted'
    if not J.valid:
        return 'fail-closed', 'joint-cert'
    if safety_bind(v_t, J) < theta_safe:
        return 'queue', J
    return 'execute', J
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TDC 分解与预算 | `O(|V| + |E|)` | `O(|V|)` | `Σα_v≤α_task`；缺叶子/环则拒绝分解 |
| ADC 主动构建 | `O(|P|·|X_v|·T_eval)` 每轮贪心 | `O(|X_v|)` | 配额全达标才签发 `S_v`；次模贪心 `(1−1/e)` |
| DRC 复用检验 | `O(n_u·d + T_test)` | `O(n_u·d)` | 检验拒绝或 `b>b_max` 时禁止复用 |
| 全局决策 | `O(|V|·|P|)` | `O(|V|+|D|)` | 任一数据/handoff/租约项失效即 fail-closed |

**正确性定理（组合 soundness）**：在（i）分解树 `T` 覆盖真实执行路径且 handoff 切点包含真实切换；（ii）各叶证书满足 `P(¬A_v)≤α_v`；（iii）各节点与 handoff 数据充分 `S_v=S_{uv}=1`；（iv）复用边通过可交换性检验且 `b_{uv}` 覆盖真实偏移；（v）能量与 sim-to-real 租约有效 的条件下，组合证书失败概率满足
`P(¬S_safe_composed) ≤ Σ_{v∈S} α_v + Σ_{(u,v)∈R_used} b_{uv} + e_data`。
并集界对任意相关性成立，因此不需要独立性假设；但**逐叶有效不能推出组合有效**：若 handoff 未覆盖或分解切点错误，上式右端不成立，必须 fail-closed 或重规划。粗化分解通过减少叶数降低 `Σα_v` 与数据需求，代价是单叶半径增大、`α_v` 内更易失败。

## 4. 实验设计 E121–E126

| 实验 | 指标 | 门槛 |
|---|---|---|
| E121 分解粒度与组合预算 | 组合失败经验值 vs `Σα_v`；预算利用率 | 经验失败 ≤ `Σα_v+2%`；无预算超发 |
| E122 数据充分性 | 每格配额达标率；`S_v` 签发率 | 达标率 ≥ 95%；误签发 ≤ 1% |
| E123 主动构建效率 | 达覆盖所需样本数（vs 被动日志） | 样本数下降 ≥ 40% |
| E124 复用可交换性 | 复用误接受率；`b_{uv}` 低估率 | 误接受 ≤ 1%；低估 ≤ 2% |
| E125 分解边界/handoff | handoff 覆盖率；整任务成功率 | handoff 覆盖 ≥ 95%；任务成功 ≥ 90%；静默切换失效 0 |
| E126 100h 全局闭环 | 组合任务成功率；静默不 sound 次数；数据能耗占比 | 成功率 ≥ 90%；静默违例 0；数据能耗 ≤ 15% |

**回退策略**：E121 经验界超标 → 粗化分解或收紧 `α_v`；E122 配额不可达 → 放宽 `ε_v` 或直接 fail-closed；E123 效率低 → 先用 sim 数据并按 `ε(c)` 折扣；E124 误接受 >1% → 关闭复用、全部新采；E125 handoff 缺口 → 插入显式 handoff 子任务节点；E126 数据能耗过高 → 预留能量预算并推迟非关键采集。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 分解切点错误、handoff 未覆盖 | 高 | 显式 handoff 数据集 + 边级充分性证书 + 组合守卫 |
| 并集界过松导致单叶 `α_v` 太小、数据不可行 | 高 | 自适应预算分配、粗化分解、报告不可行而非硬签 |
| 数据复用破坏可交换性 | 高 | DRC 两样本检验 + 偏移惩罚 + 超阈禁用复用 |
| 主动采集引入选择偏差 | 高 | 分层配额 + 独立 held-out 审计 + 数据护照 |
| sim/real 数据泄漏与护照造假 | 高 | 严格来源隔离 + 独立审计集 + 哈希/签名护照 |
| 数据构建挤占能量与时间 | 中 | ECPS 预留租约、sim 优先、非关键采集可推迟 |

## 6. 本轮最大风险

**一句话**：最大风险是分解在 handoff 边界切错——每个叶节点的数据集只覆盖本叶状态分布，未覆盖叶间切换分布，于是所有叶证书都有效、并集界也满足，整任务却在切换瞬间静默失效；必须把 handoff 分布作为一等公民单独建模、采集与持证，并让组合证书守卫切换覆盖，而不是仅逐叶校验。
