# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；本轮灵感：「轻量化设计」×「价值对齐」）

> 第 65 轮用 VISTA 把"几何可证伪"升级为"故障可归因"，其自述最大风险是：**归因建立在"故障属于有限假设集、且视觉与几何失效相互独立"之上；真实故障常是未知复合类型，透明/镜面/对抗 patch 会让视觉与几何共享同一 OOD 失效源，FIR 强行归因、只膨胀错误的球，系统因"已经归因"更自信地继续执行（A88）。** 本轮不再扩假设集，也不再加第 6 个模态，而是追问一个被所有前序轮次默认、却从未被证书覆盖的工程前提：
>
> **安全基础设施是免费的。**
>
> 视觉世界模型、6 假设故障库、逐假设 conformal 标定、主动判别探针、块级认证前缀——VISTA 的每一项保证都假定算力、传感器、标定样本与物理探测预算充足。但在低成本/边缘算力/少传感器/易损物体的真实部署里，这个前提不成立，于是"全量 VISTA（部署不起）"与"裸策略（不安全）"成了假两难。更关键的是：**"轻量化"本身就是一个价值决策**——你牺牲了哪个保证、为谁牺牲、在什么包络内牺牲，必须对得上人的价值，而不能被工程默认值悄悄决定。
>
> 本轮核心命题：
>
> **把 VISTA 的"重证书"编译成"轻内核"：价值对齐不是给安全加一个奖励项，而是把安全决策压缩到"价值相关粗化类"（灾难 / 可恢复 / 良性）上，用价值剖面决定风险预算与降级顺序，用证书蒸馏、两级级联、预算化故障集与价值信息探针在有限资源下保留硬约束，并把每一次"轻量化放弃的保证"显式记账。**

## 0. 直觉与动机

**灵感 1（轻量化设计 → 安全决策不需要全部信息）**
直觉：VISTA 在语义流算 6 类故障后验，但真正进入安全决策的不是"是哪一类故障"，而是"这一步会不会导致不可逆后果"。把 6 类后验按当前上下文粗化成三个价值类 {灾难 C, 可恢复 E, 良性 B} 后，硬约束只需要一个标量 p_C(ρ,x)=Σ_{H:v(H,x)=C}P(H|ρ)。这意味着轻量化的目标不是"用更小的模型去近似 6 分类"，而是"用更少的信息去校准一个灾难概率"。**目标一变小，可裁的信息就变多**——这是本轮全部压缩论证的支点，也是"价值对齐使轻量化成为可能"的严格来源。
严谨接口：见定义 235、引理 9、引理 10、命题（对齐放宽压缩）。

**灵感 2（轻量化设计 → 级联与事件触发：把重计算搬到离线/语义流）**
直觉：轻量化不是把每个模块都做小，而是让昂贵模块"大多数时候不运行"。两级级联：Tier 0 用最便宜的标量门（力阈值 + 几何裕度 + 可逆性 + 人机距离）做保守判定；只有落在模糊带（near-boundary）才触发 Tier 1 的 VISTA 全量归因。Tier 0 必须"宁可误报"（对 C 高召回），Tier 1 只在边界处精修。这样平均算力由触发率决定，而安全性由 Tier 0 的保守上界决定；重计算可以留在离线蒸馏与语义流，实时环只剩一次比较。
严谨接口：见定义 242、引理 11。

**灵感 3（价值对齐 → 非对称损失与词典序，而不是又一个 reward）**
直觉：第 65 轮的 δ_fi 对所有故障一视同仁；但"漏放一个灾难故障"和"多降级一次可恢复故障"在人类价值里根本不等价。价值对齐在这里的正确形态是：硬约束（不伤人、不毁不可逆物体、不越权）以词典序优先，软偏好（任务成功、速度、能耗、轻柔、舒适）在硬约束之后用有界损失权衡。价值剖面不是把安全与效率加权求和——那必然被 Goodhart——而是决定风险预算 ε_cat 与接受阈值：动作越不可逆、人越近、物体越易损，ε_cat 越小。安全不是可交换的项，而是约束。
严谨接口：见定义 234、236。

**灵感 4（价值对齐 → 可问责的降级与"放弃账本"）**
直觉：轻量化必然放弃一些保证。危险不在于放弃，而在于"悄悄放弃还宣称安全"（certification washing）。因此每一次压缩都必须留下账本：放弃了哪个通道/假设/标定、换来了多少算力、剩余保证的包络是什么、价值后悔上界是多少。当预算低到连硬约束都无法认证时，系统按价值顺序降级（硬约束 > 可逆性 > 任务成功 > 速度 > 能耗 > 舒适），而不是随机砍功能。价值多元时（不同标注者/文化/场景），硬约束取并集、软偏好取最坏后悔——这与第 41 轮"价值可信集"同源，但这里价值不是采样倾斜，而是**预算分配与降级顺序的约束**。
严谨接口：见定义 243、244。

**灵感 5（两灵感合流 → LARK：Lightweight Aligned Risk Kernel，轻量价值对齐风险内核）**
闭环：VISTA 全量证据 → 价值相关粗化 H^V / p_C → 价值预算化故障集 VBS → 证书蒸馏 CSA（教师=全量 VISTA，学生=标量/小树/查表）→ 预算-价值分配 BVA → 两级证书级联 ECC → 节俭价值信息探针 FVOI → 价值对齐降级 VAD + 放弃账本 → AIC-L → J_lark。关键合流点不是"既要轻又要对齐"的折衷，而是互为使能：**价值对齐让轻量化有方向——只需保留价值相关信息，而不是全部故障信息；轻量化让价值对齐可部署——把安全从"离线语义流的重归因"搬到"在线标量的轻门控 + 边界处的重验证"。**
严谨接口：见定义 233、247 与定理 9。

**一句话押注**：第 65 轮让系统"证得住故障可归因"，本轮让系统"证得住便宜、且便宜得对"。

## 1. 形式化定义（增量：定义 233–247）

- **定义 233（LARK 闭环）**：LARK = (VISTA, VWP, H^V/VWR, CSA, VBS, BVA, ECC, FVOI, VAD, AIC-L, J_lark)。定位：VISTA 的"轻量化部署 + 价值对齐"升级。不变式：**价值剖面、证书蒸馏、预算-价值分配、故障集裁剪、放弃账本只在语义流/离线；实时流只做标量门控、边界触发、校准查表、价值阈值比较与安全回退，零学习写操作。**
- **定义 234（价值剖面 VWP 与词典序损失）**：价值剖面 λ=(C_hard, ≻_soft, λ_soft)。硬约束 C_hard 是禁止的（决策, 后果）对集合（伤人、不可逆毁物、越权、隐私泄露）；软损失 ℓ_soft≥0 有界 L；决策按词典序 (V_hard, E[ℓ_soft]) 最小化。上下文 x 含可逆性 r(a)、人机距离、物体易损度、任务阶段。价值剖面不是标量奖励；硬约束不可被效率补偿。
- **定义 235（价值相关粗化 H^V 与灾难概率）**：映射 v(H,x)∈{C,E,B} 把每个故障假设按当前上下文归入灾难/可恢复/良性；p_C(ρ,x)=Σ_{H:v(H,x)=C}P(H|ρ)。**硬约束只依赖 p_C，而不依赖 6 类后验的完整形状。** 同一 H_model 在小力下可为 B、在易损物体上可为 C，故粗化是上下文相关的。
- **定义 236（价值加权风险 VWR 与价值多元）**：R_val(π;x) 取词典序对 (P[V_hard=1], E[ℓ_soft])；价值可信集 Λ_δ 给出一族剖面，硬约束取并集（对所有 λ 成立的最保守集），软偏好取最坏后悔。对齐目标：V_hard≤ε_cat(x) 且 R_soft≤R_soft(VISTA)+ε_val。
- **定义 237（证书充分统计量与轻核）**：统计量 T=T_B(ρ)（通道子集/量化/低维投影/树叶子）称为 (ε,x)-充分，若 E[TV(P(H^V|ρ,x), P(H^V|T(ρ),x))]≤ε。轻核 κ_T: T→{accept, slow, abort, fallback} 是 VISTA 安全决策的压缩代理。
- **定义 238（证书蒸馏 CSA）**：离线用故障注入 + 真实日志采样 ρ，教师 d*=VISTA(ρ,x) 与 p_C，学生 κ_T 学 p̂_C 与阈值决策；用 split-conformal/PAC 在操作包络上给校准界 q_cal 与价值后悔界，输出 kernel_hash、calib_ver、envelope。
- **定义 239（值预算与可行包络）**：预算 B=(算力, 通道数, 标定样本, 探测力/时间, 内存)。ε_cat(x,r(a)) 由价值剖面给出（越不可逆/越近人/越易损越小）。操作包络 O_B 是校准界成立的上下文集合；可行性 ⇔ 存在 κ_T 使 V_hard≤ε_cat 且 R_soft 后悔≤ε_val；不可行则收缩包络或降级。
- **定义 240（价值预算化故障集 VBS）**：活动故障集 A_B⊆ℋ 按"单位成本的价值相关信息"选取；低价值相关假设合并为聚合类（benign/unknown），保留未知质量 m_unk。被裁假设只允许在其价值类为良性、或其后验质量被界定时裁掉；不可将潜在灾难假设并入良性类。
- **定义 241（预算-价值分配 BVA）**：把 B 分给通道数、标定样本、故障库大小、探针、算力五个模块；按单位成本的价值加权风险边际下降 Δ_m/c_m 贪心分配。在 Δ_m 关于预算是凹的（边际递减）且预算可分的条件下，贪心即最优；离散时给 (1−1/e) 或曲率界。
- **定义 242（两级证书级联 ECC）**：Tier 0 廉价门 g(φ,x)（力阈值/几何裕度/可逆性/人机距离）以保守阈值给出 C 的假阴率 ≤ε_gate；只有 g 落在模糊带才调用 Tier 1（VISTA 全量或 CSA 重核）精修。级联误差 ≤ε_gate+ε_1；平均成本 ≤c_0+P(ambiguous)·c_1。
- **定义 243（节俭价值信息探针 FVOI）**：a*=argmax_a EVSI(a)/(c_comp(a)+c_phys(a)+λ_r·risk(a))，EVSI 为价值加权风险期望下降（不是假设熵），s.t. f_n≤f_safe、形变≤ε_strain、易损物体仅非接触探针；仅当 EVSI 超过阈值且可能翻转价值相关决策时才探测。
- **定义 244（价值对齐降级 VAD 与放弃账本）**：预算不足/OOD 时按价值顺序 硬约束 > 可逆性 > 任务成功 > 速度 > 能耗 > 舒适 逐级降级；每一步是显式模式、有证书、有账本条目。硬约束无法认证 ⇒ safe_idle/柔顺撤离，绝不静默丢弃。
- **定义 245（轻量证书 J_lark）**：J_lark=(J_vista^{restricted}, value_profile_hash, kernel_hash, calib_ver, envelope, retained_guarantees, dropped_ledger, value_regret_bound, budget_vector, ood_flag)。Valid ⇔ 硬约束在包络内成立 ∧ 价值后悔≤ε_val ∧ 放弃账本完整 ∧ 未越包络 ∧ 校准未过期。审计链回答：为什么便宜、还剩哪些保证、丢了哪些、丢了以后谁负责。
- **定义 246（预算/价值对抗认证 AIC-L）**：ℰ_L=ℰ_V×ℰ_budget×ℰ_value；ℰ_budget 含预算耗尽、通道掉线、标定漂移、包络越界；ℰ_value 含价值剖面误设、对抗性偏好操纵、标注冲突。鲁棒认证取最坏价值加权风险；价值误设时硬约束须对剖面并集成立，否则回退。
- **定义 247（LARK 闭环算子）**：语义/离线流 [VISTA→H^V/VWR→VBS→CSA 蒸馏→ECC 编译→BVA 分配→VAD 策略→J_lark 模板]；实时流 [廉价门控→(模糊? Tier1)→p̂_C 查表→价值阈值比较→accept/slow/abort/fallback→账本累积→J_lark 构建]。

## 2. 关键算法骨架

```python
# CSA：把全量 VISTA 蒸馏成价值相关的标量/级联轻核（离线 + 语义流）
teacher = VISTA(evidence)                       # 重：6 假设后验 + 认证前缀
pC = sum(P[H] for H in HYP if value_class(H, x) == 'C')
# 学生只需校准 p_C 与决策阈值，而不是复刻 6 分类
kernel = distill(teacher_logs, target='pC', budget=B,
                 monotone=True, max_depth=D)     # 小树/查表/单调标量
q_cal = split_conformal(kernel, calib_set)       # 校准误差上界

# 通道裁剪：价值相关条件互信息（对齐使轻量化成为可能）
prune = [j for j in channels
         if I(H_value; rho[-j] | rho[others]) <= 2 * eps**2]

# BVA：单位成本的价值加权风险边际下降（凹 ⇒ 贪心）
while budget_left > 0:
    m = argmax_marginal(delta_VWR[m] / cost[m])
    allocate(m); budget_left -= cost[m]

# ECC + FVOI：实时标量门 + 边界处才探测/重归因
if gate_T0(phi, x) < theta_gate:                # 远低于边界
    decision = 'accept'
elif gate_T0(phi, x) > theta_stop:
    decision = 'abort'
else:                                            # 模糊带
    d = kernel.lookup(T(rho), q_cal)
    if EVSI(d, post) > c_probe + lam_r * risk(d):
        d = fvoi.probe(d)
    decision = d
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（价值相关压缩的价值后悔界）**：若 T 对 H^V 的 TV 误差 ≤ε，则软后悔 ≤2Lε，硬违规概率差 ≤2ε。故压缩目标只需保留"灾难/可恢复/良性"的可分性，而非全部 6 类故障形状。
- **引理 10（通道预算的互信息界）**：丢弃通道集 S 后，E[TV(P(H^V|ρ),P(H^V|ρ_{-S}))] ≤ √(½·I(H^V;ρ_{-S}|ρ_S))。于是"可裁"的严格判据是价值相关条件互信息，而不是经验精度。
- **引理 11（级联安全性）**：Tier 0 对 C 的假阴率 ≤ε_gate、Tier 1 在模糊带误差 ≤ε_1，则级联误差 ≤ε_gate+ε_1，平均成本 ≤c_0+P(ambiguous)c_1；把重计算放到不常触发的分支即可"便宜且不漏"。
- **定理 9（LARK 端到端价值-安全）**：在包络、校准、硬约束保留与账本完整假设下，Valid(J_lark) ⇒ P[灾难违规]≤ε_cat+ε_cal+ε_gate+δ_ood，软价值后悔 ≤VISTA+2Lε+ε_val，且降级严格遵循价值顺序。
- **定理 10（预算分配的近最优性）**：风险下降对预算凹时，贪心 BVA 最优；离散时 (1−1/e) 或曲率界。故"把预算给边际价值最高的模块"不是启发式，而是有界的近似。
- **命题（对齐放宽压缩）**：因 H^V 是 H 的粗化，I(H^V;·)≤I(H;·)，故价值对齐**单调地**扩大了可裁通道集合；对齐越贴近"只关心不可逆后果"，轻量化空间越大。这把"价值对齐"从伦理附加项变成压缩增益的来源。
- **命题（EVSI 优于熵）**：非对称损失下，最大化 I(ℋ;ρ) 的探针可能 EVSI=0（区分两个都良性的假设），而低熵探针可能有高 EVSI（区分良性 vs 灾难）。故第 65 轮 AFA 的互信息目标在价值加权下应替换为 EVSI。
- **实时性**：实时流只增标量门（<0.02ms）、查表决策（<0.01ms）、阈值比较与账本（<0.01ms）；重归因与蒸馏全在语义流/离线，目标 ≤0.5ms（远低于 VISTA 的 2.5ms），为低成本边缘平台留出余量。

## 5. 本轮最大风险

**一句话**：LARK 把安全证书压缩成一个由特定价值剖面训练、在特定包络内校准的标量内核；一旦价值剖面本身误设或分布悄悄移出包络，这个内核会以"我已经对齐"的自信在包络外继续执行，而被裁掉的冗余通道恰恰是唯一能发现"价值错了 / 包络破了"的证据——**轻量化省掉的不是算力，而是系统发现自己错了的能力**。

## 2. 形式化定义（完整版）

**定义 233（LARK 闭环）** LARK 是 VISTA 的"轻量化部署 + 价值对齐"升级：保留 VISTA 的故障归因能力作为**教师/边界验证器**，在其上挂载价值剖面 VWP、价值相关粗化 H^V、证书蒸馏 CSA、两级级联 ECC、预算化故障集 VBS、预算-价值分配 BVA、节俭价值信息探针 FVOI、价值对齐降级 VAD 与账本，并原位升级 AIC-V→AIC-L、J_vista→J_lark。不变式：**价值剖面、证书蒸馏、预算分配、故障集裁剪、放弃账本只在语义流/离线；实时路径只做标量门控、边界触发、校准查表、价值阈值比较、账本累积与安全回退，零学习写操作。**

**定义 234（价值剖面 VWP 与词典序损失）** 价值剖面
λ=(C_hard, ≻_soft, λ_soft)，
其中 C_hard 是禁止的（决策, 后果）对集合（伤人、不可逆毁物、越权、隐私泄露等）；ℓ_soft(d,H,x)≥0 有界 L，覆盖任务成功、速度、能耗、轻柔、舒适等软偏好；≻_soft 给出软偏好的词典序或权重。决策规则按
d*(ρ,x)=lexmin_d (V_hard(d,x), E[ℓ_soft(d,H,x)|ρ,x])
选择，V_hard(d,x)=1[∃(d,后果)∈C_hard]。**关键：硬约束是不可补偿的约束，不是大权重项；把安全写成加权和会被 Goodhart。** 上下文 x 含动作可逆性 r(a)、人机距离、物体易损度、任务阶段；这些量决定同一故障是否落入灾难类。

**定义 235（价值相关粗化 H^V 与灾难概率）** 定义映射 v: ℋ×𝒳→{C,E,B}，把每个故障假设按当前上下文归入灾难 C、可恢复 E、良性 B。硬约束只依赖
p_C(ρ,x)=Σ_{H: v(H,x)=C} P(H|ρ)。
同一 H_model 在小力/刚性物体上可为 B，在易损物体/大力上可为 C；同一 H_geo 在可逆接近段可为 E，在已承载且不可逆时可为 C。于是**安全决策需要的不是 6 类后验的完整形状，而是一个上下文条件下的标量灾难概率**。这既是压缩目标，也是价值对齐的接口。

**定义 236（价值加权风险 VWR 与价值多元）** 决策 π 的价值加权风险取词典序对
R_val(π;x)=(P[V_hard(π)=1], E[ℓ_soft(π)]).
对齐目标：P[V_hard=1]≤ε_cat(x,r(a)) 且 R_soft(π)≤R_soft(VISTA)+ε_val。价值多元时给可信集 Λ_δ，硬约束取最保守并集 C_hard^∩=∪_{λ∈Λ_δ}C_hard(λ)，软偏好最小化最坏后悔
min_π max_{λ∈Λ_δ} [R_soft^λ(π)−min_{π'}R_soft^λ(π')].
**硬约束取并集而不是取平均**，避免"多数标注者同意伤人"这种伪对齐。

**定义 237（证书充分统计量与轻核）** 统计量 T=T_B(ρ)（通道子集、量化、低维投影或树叶子）称为 (ε,x)-充分，若
E[TV(P(H^V|ρ,x), P(H^V|T(ρ),x))] ≤ ε.
轻核 κ_T: T→{accept, slow, abort, fallback} 是 VISTA 安全决策的压缩代理。轻核**不需**输出故障类别；它只需输出价值相关决策。这使轻核可以小到一张阈值表。

**定义 238（证书蒸馏 CSA）** 离线以故障注入 + 真实日志采样 (ρ,x)，由教师 VISTA 计算 d*(ρ,x) 与 p_C(ρ,x)。学生 κ_T 学习 p̂_C 与阈值决策（可用单调小树、查表、逻辑回归），目标不是复制 6 类后验，而是**在价值加权损失下逼近 d***。用 split-conformal 或 PAC-Bayes 在操作包络 O_B 上给
P[|p̂_C−p_C|≤ε_cal] ≥ 1−α_cal
与软后悔上界 ε_val。输出 kernel_hash、calib_ver、envelope、dropped_ledger。蒸馏的教师-学生差距必须在包络内认证，包络外一律回退 Tier 1 或 safe_idle。

**定义 239（值预算与可行包络）** 预算
B=(c_compute, n_ch, n_cal, f_probe, mem)。
价值剖面给出 ε_cat(x,r(a))：越不可逆、人机距离越近、物体越易损，ε_cat 越小。操作包络 O_B 是校准界与硬约束界成立的上下文集合。可行性定义为：存在 κ_T 使
P[V_hard]≤ε_cat 且 R_soft(κ_T)−R_soft(VISTA)≤ε_val
（在所有 λ∈Λ_δ 下）。不可行时只有两条合法出路：收缩 O_B（明确禁止进入未认证上下文），或按 VAD 降级。**不得通过放宽 ε_cat 来"解决"不可行**——那是用价值妥协伪装成工程优化。

**定义 240（价值预算化故障集 VBS）** 活动故障集 A_B⊆ℋ 按"单位成本的价值相关信息"选取：
j* = argmax_{j∉A_B} [I(H^V; ρ_j | ρ_{A_B}) − λ_c·c_j]，迭代至预算用尽。
未被选中的假设合并为聚合类（benign/unknown），保留未知质量 m_unk。硬规则：**任何可能属于灾难类的假设不得并入良性类**；若其价值类不确定，必须保留为 unknown 并计入 p_C 的上界。VBS 是第 65 轮 FIR 的"稀疏化"版本，但稀疏化准则由价值而非似然精度决定。

**定义 241（预算-价值分配 BVA）** 将 B 分配给五个模块：证据通道数、标定样本、故障库大小、探针预算、在线算力。设模块 m 在预算 b_m 下的价值加权风险下降为 Δ_m(b_m)，成本为 c_m(b_m)。近似求解
max Σ_m Δ_m(b_m)  s.t.  Σ_m c_m(b_m) ≤ B.
若 Δ_m 关于 b_m 凹（边际递减）且预算可分，按单位成本边际收益 Δ'_m/c'_m 贪心分配即最优；离散预算下给 (1−1/e) 或曲率界。BVA 把"该买更多传感器、还是多标定、还是多探测"从经验变成可计算排序。

**定义 242（两级证书级联 ECC）** Tier 0 是廉价标量门
g(φ,x)=worst-case 安全裕度（力阈值、几何裕度、可逆性、人机距离的保守组合），
其在操作包络内对灾难类给出假阴率 ≤ε_gate。判定：
- g<θ_gate：远离危险 ⇒ accept；
- g>θ_stop：确定危险 ⇒ abort；
- 否则落在模糊带 ⇒ 调用 Tier 1（VISTA 全量归因或 CSA 重核）精修。
Tier 1 在模糊带的误差 ≤ε_1。级联误差 ≤ε_gate+ε_1；平均成本 ≤c_0+P(ambiguous)·c_1。Tier 0 的阈值 θ_gate 由价值剖面选择（非对称损失下宁可误报），Tier 1 只在边界处出现，故实时平均负载远低于全量 VISTA。

**定义 243（节俭价值信息探针 FVOI）** 探针集 A={press,rub,tap,lift,visual_probe,null_test,cross_port_probe,ask_operator}。定义探针 a 的价值信息
EVSI(a)=E_{ρ_new|a}[ min_d E_{H|ρ_new} ℓ(d,H) − min_d E_{H|ρ_old} ℓ(d,H) ]，
即**价值加权贝叶斯风险的期望下降**（不是假设熵的下降）。选择
a*=argmax_a EVSI(a)/(c_comp(a)+c_phys(a)+λ_r·risk(a)),
s.t. f_n≤f_safe、形变≤ε_strain、易损物体仅允许非接触探针。仅当 EVSI(a*)>δ_evsi 且该探针可能翻转一个价值相关决策时才执行。**与第 65 轮 AFA 的区别：AFA 最大化 I(ℋ;ρ)，会花力气区分两个都良性的假设；FVOI 只在能降低灾难概率或显著降低软损失时探测。**

**定义 244（价值对齐降级 VAD 与放弃账本）** 当 BVA 判定不可行、或 OOD/预算耗尽/校准过期时，按价值顺序逐级降级：
硬约束（不伤人/不毁不可逆/不越权） > 可逆性 > 任务成功 > 速度 > 能耗 > 舒适。
每一步降级是一个显式模式，带自己的证书与账本条目：
dropped_ledger += (guarantee_id, reason, budget_saved, remaining_bound, approver)。
若硬约束无法认证，进入 safe_idle 或柔顺撤离，**绝不静默丢弃硬约束**。降级顺序本身由价值剖面给出，且对 Λ_δ 取最保守。

**定义 245（轻量证书 J_lark）** 
J_lark=(J_vista^{restricted}, value_profile_hash, kernel_hash, calib_ver, envelope, retained_guarantees, dropped_ledger, value_regret_bound, budget_vector, ood_flag)。
验证规则：
Valid(J_lark) ⇔
J_vista 的被保留字段有效
∧ 硬约束在 envelope 内成立（对所有 λ∈Λ_δ）
∧ value_regret_bound ≤ ε_val
∧ dropped_ledger 完整（每个被裁组件都有条目）
∧ ood_flag=False（或已进入 VAD 模式）
∧ calib_ver 为当前版本。
审计链新增：**为什么可以便宜（kernel_hash / calib_ver）、还剩哪些保证（retained_guarantees）、丢了哪些（dropped_ledger）、丢了以后的价值后悔上界（value_regret_bound）、在哪个包络内成立（envelope）。**

**定义 246（预算/价值对抗认证 AIC-L）** 干扰集
ℰ_L=ℰ_V×ℰ_budget×ℰ_value，
ℰ_budget 含预算耗尽、通道掉线、标定漂移、通信延迟、包络越界；ℰ_value 含价值剖面误设、对抗性偏好操纵、标注冲突、文化/场景漂移。ρ_dir 与价值加权风险在 ℰ_L 上重算（n_cert 128→144，其中 16 给预算/价值）；**价值误设时硬约束须对 Λ_δ 的并集成立，否则回退；预算耗尽时按 VAD 降级而不是降低 ε_cat。**

**定义 247（LARK 闭环算子）** 见 IP-233 伪代码。语义/离线流：[VISTA 全量→H^V/VWR 价值粗化→VBS 预算化故障集→CSA 蒸馏/校准→ECC 编译→BVA 预算分配→VAD 策略→J_lark 模板]；实时流：[廉价门控→模糊带触发 Tier1→p̂_C 查表→价值阈值比较→accept/slow/abort/fallback→账本累积→J_lark 构建]。

## 3. 关键算法伪代码

### IP-226 CSA（证书蒸馏）

```python
class CertificateDistiller:
    """教师=全量 VISTA；学生=价值相关标量 p_C + 阈值决策。只压缩安全决策，不压缩诊断。"""

    def fit(self, logs, B, value_profile, max_depth=6):
        X, pC, dstar = [], [], []
        for rho, x in logs:
            post = VISTA.posterior(rho)                    # 6 假设后验（重）
            p = sum(post[H] for H in HYP
                    if value_class(H, x, value_profile) == 'C')
            X.append(self._features(rho, x))
            pC.append(p)
            dstar.append(VISTA.decide(rho, x, value_profile))
        # 通道裁剪：价值相关条件互信息（见 IP-231 / 引理 10）
        keep = select_channels(X, pC, budget=B.n_ch, eps=B.eps)
        self.T = Compressor(keep, quantize=B.quantize)
        self.kernel = MonotoneTree(max_depth=max_depth).fit(self.T(X), pC, dstar)
        self.q_cal = split_conformal(self.kernel, self.T(X), pC)
        self.envelope = fit_envelope(X)
        self.dropped = [c for c in range(X.shape[1]) if c not in keep]
        return self

    def predict(self, rho, x):
        if not self.envelope.contains(rho, x):
            return 'fallback'                              # 包络外一律重验证/回退
        p_hat = self.kernel.predict(self.T(rho))
        lo, hi = p_hat - self.q_cal, p_hat + self.q_cal
        eps_cat = self.value_profile.risk_budget(x)        # 越不可逆越小
        if hi <= eps_cat:
            return 'accept'
        if lo > eps_cat:
            return 'abort'
        return 'borderline'                                # 触发 Tier 1 / FVOI
```

### IP-227 ECC（两级级联）

```python
class CertificateCascade:
    def __init__(self, gate, tier1, theta_gate, theta_stop):
        self.gate, self.tier1 = gate, tier1
        self.theta_gate, self.theta_stop = theta_gate, theta_stop

    def decide(self, phi, rho, x):
        g = self.gate(phi, x)                              # Tier 0：<0.02ms
        if g < self.theta_gate:
            return 'accept', 0
        if g > self.theta_stop:
            return 'abort', 0
        d = self.tier1(rho, x)                             # Tier 1：只在边界
        return d, 1

    def expected_cost(self, p_amb):
        return self.cost0 + p_amb * self.cost1
```

### IP-228 VBS + IP-231 BVA（预算化故障集与预算分配）

```python
def value_budgeted_fault_set(rho_logs, value_profile, budget):
    active, remaining = set(), budget.n_cal
    while remaining > 0:
        best, best_gain = None, -np.inf
        for H in set(HYP) - active:
            # 价值相关信息：只保留对 H^V 起作用的部分
            gain = value_cond_mutual_info(H, active, rho_logs, value_profile)
            cost = calibration_cost(H)
            if gain / cost > best_gain:
                best, best_gain = H, gain / cost
        if best is None or best_gain <= DELTA_INFO:
            break
        active.add(best); remaining -= calibration_cost(best)
    # 硬规则：灾难相关假设不得被并入良性聚合类
    assert all(value_class(H, x, value_profile) != 'C'
               for H in set(HYP) - active)
    return active, unknown_mass(set(HYP) - active)


def budget_value_alloc(modules, B):
    alloc = {m: m.min_budget for m in modules}
    left = B - sum(alloc.values())
    while left > 1e-9:
        m = max(modules, key=lambda m: modules[m].marginal_gain() / modules[m].marginal_cost())
        step = min(modules[m].step, left)
        alloc[m] += step; left -= step
        if modules[m].marginal_gain() <= 0:
            break
    return alloc
```

### IP-229 FVOI（价值信息探针）

```python
class FrugalValueOfInformation:
    def choose(self, post, value_profile, x, f_safe, fragile):
        base = value_weighted_risk(post, value_profile, x)
        best, best_evsi = None, 0.0
        for a in PROBES:
            if fragile and a not in ('visual_probe', 'null_test', 'ask_operator'):
                continue
            traj = predict_probe(a, phi_hat, x)
            if traj.f > f_safe or traj.strain > EPS_STRAIN:
                continue
            post_new = predict_posterior(post, a)
            gain = base - value_weighted_risk(post_new, value_profile, x)  # EVSI
            cost = traj.cost + value_profile.lambda_risk * traj.risk
            if gain > 0 and gain / (cost + 1e-9) > best_evsi:
                best, best_evsi = a, gain / (cost + 1e-9)
        return best if best_evsi > DELTA_EVSI else None
```

def LARK_round(M, obs, value_profile, B):

## 4. 推导

**引理 9（价值相关压缩的价值后悔界）** 设软损失 ℓ_soft 的值域宽度 ≤L，硬违规指示函数取值 {0,1}。若统计量 T 满足对 H^V 的
E[TV(P(H^V|ρ,x), P(H^V|T(ρ),x))] ≤ ε，
则对任意 x，
|R_soft(d_T)−R_soft(d*)| ≤ 2Lε，  |P[V_hard(d_T)=1]−P[V_hard(d*)=1]| ≤ 2ε.
证明：对任意决策 a，|E_{p}ℓ(a)−E_{q}ℓ(a)| ≤ L·‖p−q‖₁ = 2L·TV(p,q)。因此
|inf_a E_pℓ − inf_a E_qℓ| ≤ sup_a |E_pℓ−E_qℓ| ≤ 2L·TV(p,q).
硬违规指示是 [0,1] 有界损失，同式取 L=1。对 (ρ,x) 取期望即得。∎
**含义**：轻量化的可证条件不是"保留全部 15 维证据"，而是"保留价值相关后验到 TV≤ε"。这直接允许把 6 分类压缩成一个校准的 p_C。

**引理 10（通道预算的互信息界）** 设 S 为被丢弃的通道集，ρ_{-S} 为保留通道。则
E[TV(P(H^V|ρ), P(H^V|ρ_{-S}))] ≤ √( ½·I(H^V; ρ_{-S} | ρ_S) ).
证明：由 Pinsker 不等式，TV ≤ √(½ KL)。对 KL 取期望并用条件互信息的链式恒等式
E_{ρ}[D_KL(P(H^V|ρ) ‖ P(H^V|ρ_{-S}))] = I(H^V; ρ_{-S} | ρ_S),
再用 Jensen 得 E[TV] ≤ √(½ E[KL]) = √(½ I(H^V;ρ_{-S}|ρ_S))。∎
**含义**：一个通道能否被裁掉，有一个**可计算的严格判据**——它对价值相关类 H^V 的条件互信息是否 ≤2ε²。这把"轻量化"从调参变成证书。

**引理 11（级联安全性）** 设 Tier 0 在包络内对灾难类的假阴率 ≤ε_gate；Tier 1 在模糊带内的决策误差 ≤ε_1。则级联的灾难漏放率 ≤ε_gate+ε_1；平均成本 ≤c_0+P(ambiguous)·c_1。证明：漏放只可能发生在 (i) Tier 0 误判安全（概率 ≤ε_gate），或 (ii) Tier 0 正确进入模糊带但 Tier 1 误判（概率 ≤ε_1）。联合界即得。成本由触发指示的期望直接给出。∎
**含义**：把重计算放到"模糊带"这一不常触发的分支，既不牺牲 Tier 0 的保守性，又把平均负载压到触发率量级。

**定理 9（LARK 端到端价值-安全）** 在以下假设下：
(A94) 校准与包络：κ_T 在 O_B 上满足 P[|p̂_C−p_C|≤ε_cal]≥1−α_cal，且 OOD 检测不漏报；
(A95) 硬约束保留：VBS 不把灾难类假设并入良性类，未知质量计入 p_C 上界；
(A96) 账本完整：每个被裁组件都有 dropped_ledger 条目，且保留字段的 J_vista 有效；
(A97) 价值剖面：硬约束对 Λ_δ 取并集，ε_cat 不被预算协商降低；
则 Valid(J_lark) ⇒
1. **灾难安全**：P[V_hard=1] ≤ ε_cat + ε_cal + ε_gate + ε_1 + δ_ood；
2. **价值对齐**：R_soft(κ_T) ≤ R_soft(VISTA) + 2Lε + ε_val（对所有 λ∈Λ_δ 的最坏后悔意义下）；
3. **可问责**：每次轻量化/降级都可追溯到 kernel_hash、budget_vector 与 dropped_ledger；
4. **优雅降级**：包络外/预算耗尽/校准过期 ⇒ VAD，按价值顺序降级，硬约束不可认证则 safe_idle；
5. **零学习写实时**：实时流只读表、比较、记账。
证明：由引理 9，TV 误差 ε 给出软后悔 2Lε 与硬违规 2ε；由定义 235，p_C 是硬约束的充分统计量；由 CSA 的校准界，p̂_C 与 p_C 的差 ≤ε_cal 以 1−α_cal 成立；由引理 11，级联额外引入 ε_gate+ε_1；OOD 检测漏报记 δ_ood。合并即得 1 与 2。3–5 由 J_lark 字段定义与 VAD 规则直接得到。∎

**定理 10（预算分配的近最优性）** 设模块 m 的风险下降 Δ_m(b) 关于预算 b 非负、非减、凹，成本 c_m(b) 线性且预算可分。则按单位成本边际收益 Δ'_m/c'_m 的贪心分配在预算 B 下达到最优总风险下降；离散预算下贪心达到 (1−1/e) 近似（或由曲率 κ 给出 1/(1+κ) 界）。证明：这是可分凹资源分配的标准结果；KKT 条件要求所有被分配模块的边际收益/成本相等，贪心逐步逼近该条件；离散情形用子模最大化的经典 (1−1/e) 界，凹性给出更强的连续最优。∎
**含义**："该把预算花在通道、标定、故障库还是探针上"有可计算的排序，而不是拍脑袋。

**命题（对齐放宽压缩）** 因 H^V=v(H,x) 是 H 的函数（给定 x），由数据处理不等式
I(H^V; ρ_{-S} | ρ_S) ≤ I(H; ρ_{-S} | ρ_S).
故按引理 10，价值粗化后的可裁通道集合**单调包含**原始可裁集合：对齐到"只关心不可逆后果"会严格扩大可压缩空间。反之，若强迫轻核保留全部 6 类故障的可分性，则把预算浪费在对安全决策无关的区分上。∎
**含义**：这是本轮的核心论点——**价值对齐不是轻量化的代价，而是轻量化的增益来源**。

**命题（EVSI 优于熵）** 考虑两个探针：(i) 区分 H_geo 与 H_force，两者在当前上下文都属良性 B，互信息 I(ℋ;ρ) 大但 EVSI=0；(ii) 区分 H0（良性）与 H_model（灾难），互信息较小但 EVSI>0。则第 65 轮 AFA 的 argmax I(ℋ;ρ) 会选择 (i)，而 FVOI 的 argmax EVSI 会选择 (ii)。故在价值加权、非对称损失下，熵最大化探针可严格次优。∎
**含义**：探针的目的不是"多知道故障的名字"，而是"少冒价值风险"；这把 AFA 从信息论目标纠正为决策论目标。

**命题（轻量化的极限形式）** 若价值剖面只含一个硬约束"避免灾难"，且软偏好可忽略，则最优轻核退化为一个标量校准器：p̂_C 与阈值 ε_cat(x) 的比较。此时安全证书的大小与故障假设数无关，只与 p_C 的校准质量有关。这解释了为什么"轻量化"可以做到接近零额外在线成本：**安全所需的全部信息被价值粗化压成了一个标量。**

## 7. 已知风险

**一句话**：LARK 把安全证书压缩成一个由特定价值剖面训练、在特定包络内校准的标量内核；一旦价值剖面本身误设或分布悄悄移出包络，这个内核会以"我已经对齐"的自信在包络外继续执行，而被裁掉的冗余通道恰恰是唯一能发现"价值错了 / 包络破了"的证据——**轻量化省掉的不是算力，而是系统发现自己错了的能力。**

**次级风险与缓解**：
1. **价值粗化隐藏诊断信息**：H_geo 与 H_force 都归入"可恢复"，但修复方式不同；缓解：把"安全通道"与"诊断通道"分离，压缩只作用于安全决策，诊断仍可调用 Tier 1/账本。
2. **p_C 校准在分布漂移下失准**：conformal 只承诺边际覆盖；缓解：分视界/分上下文校准、在线漂移检测、q_cal 过期即回退。
3. **价值剖面误设/不可形式化**：硬约束难以穷举；缓解：Λ_δ 取并集 + 人工审批 + 保守默认；高不确定时禁止自动执行。
4. **包络泄漏**：OOD 检测可能漏报，轻核在包络外仍给 accept；缓解：Tier 0 的保守门 + 运行时包络监视 + 周期全量审计心跳。
5. **蒸馏教师-学生差距**：学生可能在长尾上偏离 VISTA；缓解：包络内 PAC/conformal 认证，边界处强制 Tier 1，蒸馏集覆盖长尾故障注入。
6. **BVA 非凹/离散**：贪心可能次优；缓解：给曲率界、模块数少时可穷举、按 (1−1/e) 报告。
7. **级联漏掉慢漂移**：Tier 0 长期停在安全侧而漂移累积；缓解：周期性 Tier 1 心跳、CUSUM 漂移检测、校准过期即升级。
8. **certification washing**：账本可能被集成方忽略；缓解：把 dropped_ledger 设为 Valid 的必要字段，机器可检查；无账本不得部署。
9. **价值多元组合爆炸**：Λ_δ 过大导致过度保守；缓解：限制可信集维度、按最坏后悔排序、允许显式询问。
10. **实时预算**：Tier 0 必须极轻；缓解：标量门 + 查表 + 事件触发，重计算全部移出实时环。
