# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮（新循环）；本轮灵感：「ROS」×「多机协同」）

> 第 57 轮把单机的证据承诺做到了"少样本可校准、跨模态可对账、个性化有界"，但它默认了三件从未被检验的事：**(a) 证据的产地无关紧要**——探针由"本机"产生，来源隐含在信念里；**(b) 安全回路跑在一个确定性的本机节点上**——中间件只负责"送信"；**(c) 每个承诺只由一个身体作出**——不存在"甲的证据替乙下注"。当机器人从单机走向舰队、从裸机走向 ROS 2 图，这三条同时失效：证据跨体流动，最便宜的传输层（DDS/话题）是尽力而为且非确定的，而共享地图让"一个错误"同时污染所有机器人的信念。本轮两个灵感各补一条结构性腿：**ROS** 把中间件从"信使"降级为**不可信传输**，用 QoS 契约、证据信封、安全核隔离与可证伪回放把"送达"与"权威"拆开；**多机协同**把证据从"本机信念"升级为**带来源账本与跨体迁移证书的舰队证据图**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"来源可追溯、跨体可迁移、分布式可共识、中间件不可信的证据承诺"**。

核心矛盾：
- **H29（共享 vs 来源有效性）**：舰队共享证据能把 k≤5 的小样本凑成"大样本"，但甲的探针未必对乙有效——不同传感器、标定、足端几何、负载与位姿都会让同一观测在乙身上指向不同后验；"借来的证据"最大的危险不是缺失，而是**自信地错**。
- **H30（ROS 便利 vs 安全实时）**：DDS 的动态发现、QoS 协商、尽力而为交付让集成极快，但**送达、时序、版本一致性都不被保证**；一旦把承诺判定挂在话题回调上，中间件的抖动就直接变成安全回路的抖动，丢一帧可能等于放宽一次门。
- **H31（分布式共识 vs 共谋式相关风险）**：共识能容忍单机拜占庭故障，却引入法定人数俘获、陈旧副本与网络分区；更糟的是多机常共享固件、传感器型号与物理路径，**同一个物理欺骗会同时骗过所有机器人**——"多机一致"可能是同一个错误被复制了三份，而非三份独立证据。

## 0. 直觉与动机

**灵感 1（ROS → 证据总线，而不是信使）**
直觉：ROS 2 的图是"乐高接口"，不是"安全带"。把安全证据当成普通话题消息，等于把不可逆承诺押在"尽力而为"上。正确姿势是把 ROS 图视为**不可信传输**：证据必须装进带签名、版本、时间戳与产地的**信封**；QoS 不是调参而是**契约**——承载 K2 风险证据的话题必须满足 reliability=RELIABLE、deadline≤τ、durability=TRANSIENT_LOCAL 等最小契约（"QoS 支配"），否则该证据在安全意义上"不存在"；**安全核运行在本地确定性路径**，ROS 只提交证据、不持有权威。中间件健康 h(𝒢)（丢包、deadline 违约、QoS 不匹配、发现分区、版本倒退）成为证据门的一等输入：健康度下降只能让系统更保守。

**灵感 2（多机协同 → 分布式证据承诺 + 跨体迁移证书）**
直觉：舰队最诱人的是"别人替我先踩坑"，最危险的是"别人的坑不是我的坑"。给每条证据记全**来源三元组**（producer, sensor+calib_id, pose），把共享从"复制信念"改成"复制证据+来源"；跨体使用必须过**可迁移性证书 XTP**：传感器模型、标定偏差、足端几何、环境区域重叠、固件/驱动版本五项都在阈值内，才允许乙把甲的证据当"佐证"，且权重乘以迁移率 T；T 不够就只能当"先验提示"降低乙的探针 VOI，**绝不进入乙的承诺证据集**。这样"借证据省探针"与"借错证据"被一张证书分开。

**灵感 3（多机协同的第二面 → 真独立模态，但要证伪"共谋"）**
直觉：第 57 轮最缺的是**真正条件独立的两个模态**——同一台机器上视觉与触觉仍可能被同一物理性质同时欺骗。舰队天然提供不同物理路径（不同型号相机、不同足端、不同接触时序），可以把 XMC 的"独立性"从假设变成**可检验证书 indep**：必须不同传感器物理 ∧（不同固件/驱动 ∨ 空间分离）∧ 时序错相；同型号+同固件+同路径只算"同一问题问两遍"，不得计入 EV-xmodal。多机协同于是既能**放大**证据（更多独立样本），也能**放大**风险（共模欺骗），设计目标必须显式惩罚相关性。

**灵感 4（风险感知分配 → 把探针分给"最不该由同一台机器问"的地方）**
直觉：多机探询不是"谁空谁去"，而是**用身体多样性买信息多样性**。分配目标从"最小化探针数"改为 max ΣVOI − λ·系统风险 − μ·相关风险：同一不可逆接触点互斥（至多一个体在承诺），关键区域强制至少两条不同物理路径的模态，相关硬件对不得凑成"独立对"。分配因此同时是**安全机制**与**实验设计**：它决定舰队拿到的是三份独立证据，还是三次相同偏见。

**灵感 5（分布式承诺屏障 → 共识只到 L1，L2 必须本地或可迁移）**
直觉：分布式共识适合"要不要一起去某处""谁先探哪个角落"这类可逆协调；不可逆接触不能交给投票，因为投票解决的是"大家同不同意"，不是"证据对本机成不成立"。承诺类型分级：L0/L1 可由法定人数 Q（|Q|≥3f+1，陈旧度≤τ_stale）分布式决定；**L2 只接受"本地证据门通过"或"远端证据 + XTP≥T_min + 本地复核探针"**；分区、超时、版本不一致一律 **hold**（保守停），永不投"网络好所以乐观"的默认票。多机把安全边界从"单机纵深"扩展为"**本地纵深 + 分布式验证 + 分区安全默认**"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（证据总线与 ROS 信任边界 EBR）** ROS 2 图 𝒢=(𝒩,𝒯,𝒬)（节点/话题/服务/动作与其 QoS）。消息风险类 κ∈{K0,K1,K2}，最小 QoS 契约 𝒬_min(κ)=(reliability,deadline,durability,liveliness)。"QoS 支配"𝒬⪰𝒬_min(κ) 才允许承载该类证据。证据信封 e=(id,producer,sensor,calib_id,pose,t,region,payload,sig,ver)。安全核 𝒦 运行于本地确定性路径，ROS 仅提交证据、不持有权威；"证据不可用"（超时/版本倒退/签名失效/QoS 不匹配）是 first-class 状态，直接映射为保守默认而非异常。定义中间件健康 h(𝒢)∈[0,1] 与证据可用性 a(e)=1[𝒬⪰𝒬_min]·1[sig ok]·1[fresh]·h(𝒢)。

**定义 140（分布式证据账本 DEL）** 舰队 ℛ={R_i}，账本 L 为 append-only 的 (e, certify, dispute) 记录，带来源签名与版本向量。跨体融合 b_r=Fuse({b_r^{i,m}},{w_i},{ρ_m})，生产者信任 w_i∈[w_min,1] 由历史证实/证伪校准（与 PTM 的人类权重 w_h 正交）。舰队分歧 D_fleet(r) 同时计入跨来源分歧；冲突证据**不做平均**，而是触发 dispute、隔离冲突来源并回溯其历史条目（承接第 57 轮事后证伪回溯）。

**定义 141（跨体可迁移性证书 XTP）** 证据 e 由体 i 产生、拟用于体 j，证书 τ_{i→j}(e)=(Δ_sensor,Δ_calib,Δ_geom,Δ_env,Δ_firm)，各分量阈值 θ_*；迁移率 T_{i→j}=min_* (1−Δ_*/θ_*)∈[0,1]。仅当 T≥T_min ∧ overlap(r_i,r_j)≥o_min 时，e 可作 j 的**佐证**且权重乘 T；否则 e 只作**先验提示**（降低 j 的探针 VOI），绝不进入 j 的承诺证据集。T<T_min 的远端证据在 j 处等价于"未观测"。

**定义 142（风险感知分配与独立性证书 RAA）** 分配 π:𝓟→ℛ×ℳ（探针→机器人×模态），目标 max_π Σ_{(ρ,r,m)} VOI(ρ,r,m) − λ·Risk_sys(π) − μ·Corr(π)，Corr 惩罚相关对（同硬件/同固件/同物理路径/同时序）。约束：(C1) 同一不可逆接触点同一时刻至多一个体承诺（互斥）；(C2) 关键区域至少两条不同物理路径的模态；(C3) 相关对不得计入 EV-xmodal。独立性证书 indep(m,m')=1[不同传感器物理]·1[不同固件/驱动 ∨ 空间分离]·1[时序错相]。

**定义 143（分布式承诺屏障 DCB 与分区安全默认）** 承诺 c 分 reversible/L1/L2。L0/L1 可分布式投票：q(c)=1[|Q|≥3f+1 ∧ staleness≤τ_stale ∧ quorum_view 一致]；L2 仅当 local_gate(c)=ok ∨ (remote e ∧ T_{i→j}≥T_min ∧ local_recheck(c))。分区/超时/版本不一致 ⇒ hold，禁止乐观默认。证书 J_d=(M_core, provenance, ledger_digest, {T_{i→j}}, indep_certs, h(𝒢), quorum_log, partition_state, replay_ref)，继承 J_p 全检。

**定义 144（生命周期安全契约与可证伪回放 LSC）** ROS 生命周期态 {unconfigured,inactive,active,finalized}；进入 active 前须通过安全契约检查（QoS 支配、看门狗、校准版本、账本同步、签名密钥）。所有承诺相关消息入 rosbag；事后证伪可确定性重放（消息序 + QoS + 参数版本），用于回溯降权 ρ_m/w_i/T 并生成审计证据。节点态与 h(𝒢) 是证据门一等输入：非 active 或其健康度低于阈值 ⇒ 其证据降级/拒收。

## 2. 关键算法伪代码（完整版见产物区）

```python
def evidence_admit(e, topic, risk, graph):            # IP-139: QoS 契约 + 信封
    if not qos_dominates(graph.qos(topic), Q_MIN[risk]): return None   # 证据"不存在"
    if not verify_sig(e) or not fresh(e.t) or ver_regress(e, graph):    # 来源不可信
        return None
    return sealed(e, a=graph.health * verify_sig(e) * fresh(e.t))

def fleet_fuse(M, L, r, e, i):                        # IP-140/141: 来源 + 迁移
    for j in fleet:
        T = xtp(e, i, j)                              # 五项偏差 → 迁移率
        w = L.w[j] * (T if T >= T_MIN and overlap(r) >= O_MIN else 0.0)
        if w == 0: M.prior_hint[j][r] = hint(e); continue   # 只降 VOI，不入证据
        M.b[r][j][e.modality] = bayes_update(M.b[r][j][e.modality], e.like, w)
    return M, Fuse(M.b[r], L.w, M.rho), D_fleet(M.b[r])

def distribute_probes(regions, fleet, L, budget):     # IP-142: 风险感知 + 互斥
    pi = {}
    for r in critical(regions):
        pair = pick_independent(fleet, r, indep_cert)  # C2 + C3
        pi[r] = argmax(pair, key=lambda p: voi(p) - lambda_*risk - mu_*corr(p))
    return enforce_mutex(pi, contact_points)          # C1: 接触点互斥

def distributed_commit(c, Q, L, graph):               # IP-143: 分级 + 分区默认
    if c.level == 'L2':
        return ok if (local_gate(c, L) or
                      (c.ev.remote and xtp(c.ev, c.ev.producer, self) >= T_MIN
                       and local_recheck(c, L))) else 'reject'
    if partition(graph) or stale(Q) > TAU_STALE or ver_mismatch(Q): return 'hold'
    return 'ok' if quorum_ok(Q, 3*F+1) else 'hold'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| EBR | O(1)/消息 + O(1) QoS 比较 | O(\|𝒢\|) | QoS 支配、签名/新鲜度校验、安全核隔离 |
| DEL | O(\|ℛ\|·\|ℳ\|·d_b)/区域 | O(\|L\|) 账本 | append-only、版本向量、冲突不平均 |
| XTP | O(1)/证据对 | O(\|ℛ\|²) 证书缓存 | T 覆盖真实偏差、T<T_min 即"未观测" |
| RAA | O(\|𝓟\|·\|ℛ\|·\|ℳ\|·C_VOI) | O(\|𝓟\|) | 互斥、独立证书、相关惩罚 |
| DCB | O(\|Q\|) 每承诺 | O(\|Q\|) | 3f+1、陈旧界、分区 hold |
| LSC | O(1) 状态检查；回放 O(记录长) | O(bag) | 契约前置、可确定性重放 |

**正确性定理（Distributed Provenance-Calibrated Soundness, DPCS 概要）**：在 A33–A40 上新增 (A41) 中间件不可信/QoS 支配与安全核隔离、h(𝒢) 诚实且只能降级；(A42) 账本完备、版本向量抗篡改、w_i 校准诚实；(A43) XTP 覆盖真实跨体偏差且 T<T_min 时证据不可入承诺集；(A44) 独立性证书排除相关对、共模故障被显式建模；(A45) L2 只走本地/可迁移路径、分区/超时/版本不一致 ⇒ hold、拜占庭 ≤f 且 |Q|≥3f+1。则：(i) 分布式承诺失效率 ≤ 单机界 + δ_prov + δ_xtp + δ_byz，且 L2 不含 δ_byz 项（不投票）；(ii) 单调性扩展：ROS/多机机制只能经"来源更清（或证据被拒）"或"动作更保守（hold/降档/互斥）"影响系统，h(𝒢) 下降只有降级路径；(iii) 分区安全：分区期内 L2 承诺 ≤ 仅本地路径；(iv) 分配在预算内终止且满足 C1–C3。

## 6. 本轮最大风险

**一句话**：本轮把信任的单位从"本机的证据"换成"舰队的证据图"，最大的风险不再是单机自信地错，而是**相关性伪装的独立**——若来源账本与独立性证书本身错了（同型号传感器、共用固件/驱动缺陷、同一物理欺骗路径），整个舰队会以"多机一致"的高置信度同时承诺同一个错误；必须以 XTP 的 T<T_min 即"未观测"、独立性证书排除相关对、L2 不走分布式投票、分区一律 hold 四重护栏，宁可让舰队退化成各自为政的保守单机，也绝不让"三份相同偏见"冒充"三份独立证据"。

```python
def evidence_admit(e, topic, risk, graph):
```

```python
def fleet_fuse(M, L, r, e, i):
    for j in fleet:
        T = xtp(e, i, j)                             # (Δ_sensor,Δ_calib,Δ_geom,Δ_env,Δ_firm)
```

### IP-142 RAA（风险感知分配 + 独立性证书）

```python
def distribute_probes(regions, fleet, L, budget):
    pi = {}
    for r in critical(regions):
        cand = [(i, m) for i in fleet for m in modalities(i)]
        pi[r] = argmax(cand, key=lambda p:
                 voi(p, r) - lambda_*Risk_sys(p) - mu_*Corr(p, pi))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EBR | O(1)/消息 | O(\|𝒢\|) | QoS 支配、签名/新鲜、安全核隔离（A41） |
| DEL | O(\|ℛ\|·\|ℳ\|·d_b)/区域 | O(\|L\|) | append-only、版本向量、冲突不平均（A42） |
| XTP | O(1)/证据对 | O(\|ℛ\|²) | T 覆盖偏差、T<T_min 即未观测（A43） |
| RAA | O(\|𝓟\|·\|ℛ\|·\|ℳ\|·C_VOI) | O(\|𝓟\|) | 互斥、独立证、相关惩罚（A44） |
| DCB | O(\|Q\|)/承诺 | O(\|Q\|) | 3f+1、陈旧界、分区 hold（A45） |
| LSC | O(1) 检查；回放 O(len) | O(bag) | 契约前置、可重放 |

**正确性定理（DPCS, Distributed Provenance-Calibrated Soundness）**
假设 A22–A40 成立；新增 **(A41)** 中间件不可信：安全核与 ROS 隔离，QoS 支配可判定，h(𝒢) 诚实且只降级；**(A42)** 账本 append-only、版本向量抗篡改、w_i 校准诚实、冲突可检出；**(A43)** XTP 覆盖真实跨体偏差，T<T_min 时证据不进入承诺证据集；**(A44)** 独立性证书排除同物理/同固件/同路径相关对，共模故障显式建模；**(A45)** L2 不走分布式投票，分区/超时/版本不一致 ⇒ hold，拜占庭 ≤f 且 |Q|≥3f+1。则：

1. **分布式承诺健全性**：`P(fail) ≤ 单机界 + δ_prov + δ_xtp + δ_byz·1[L1]`；L2 无 δ_byz 项（不投票）。
2. **单调性扩展**：ROS 与多机机制只能经 (a) 来源更清/证据被拒（信念加宽）或 (b) 更保守动作（hold/降档/互斥）影响系统；h(𝒢) 下降只有降级路径；不存在"网络好就放宽"的路径。
3. **分区安全**：分区期内 L2 承诺数 ≤ 仅本地路径，且任何超时落入 hold。
4. **分配与终止**：RAA 在预算内终止且满足 C1–C3；每区域探针数 ≤ k_probes + k_cons。

**部署界扩展**：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − δ_prov − δ_xtp − δ_byz·1[L1]
             − P(h(𝒢)<θ ∧ 未降级) − P(replay 不可用)
```

关键：**中间件给连接、不给权威**（安全核在本地确定性路径）；**共享给样本、迁移给证书**（XTP 把"借证据省探针"与"借错证据"分开）；**多机给独立、但独立性要证**（indep 证书 + 共模惩罚）；**共识给协调、不给不可逆**（L2 只走本地/可迁移，分区一律 hold）。四者全部经"证据被拒/信念加宽/动作保守"三条安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把信任的单位从"本机的证据"换成"舰队的证据图"，最大的风险不再是单机自信地错，而是**相关性伪装的独立**——若来源账本与独立性证书本身错了（同型号传感器、共用固件/驱动缺陷、同一物理欺骗路径），整个舰队会以"多机一致"的高置信度同时承诺同一个错误；必须以 XTP 的 T<T_min 即"未观测"、独立性证书排除相关对、L2 不走分布式投票、分区一律 hold 四重护栏，宁可让舰队退化成各自为政的保守单机，也绝不让"三份相同偏见"冒充"三份独立证据"。
