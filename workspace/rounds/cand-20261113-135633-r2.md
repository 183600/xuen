# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 2 轮；本轮灵感：「可用性评估」×「伦理审查」）

> 第 65 轮把"可证伪"升级成"可归因"，其自述最大风险一针见血：**归因依赖"故障属于有限假设集、且视觉与几何的失效相互独立"，真实故障常是未知类型的组合；透明/镜面/对抗 patch 让视觉与几何共享同一个分布外失效源，于是 FIR 会把未知复合故障强行塞进最近假设、只膨胀错误的球——系统反而因为"已经归因"而更自信地继续执行。** 本轮不再叠加第 6 个机器模态，而是把镜头移到*证书的消费者*：一张"机器内部有效"的证书，如果操作员在不可逆视界 m 内读不懂、审计员无法复核、伦理上不可接受，它在**系统层面**就是无效的。本轮核心命题是：
>
> **把"安全证书"从"机器可验证"升级为"人可用、可复核、可抗辩、伦理可接受"：用可用性评估把人的解码误差纳入端到端安全界，用伦理审查把"物理安全"之外的价值约束变成硬门与可申诉的审议协议，并把第 65 轮的 ambiguous 从"内部状态"升级为"可执行的求助动作"。**

## 0. 直觉与动机

**灵感 1（可用性评估 → 人是安全链上被漏掉的最后一个传感器/执行器）**
直觉：前 65 轮反复说"人是最终监督者"，却一直把人当外部神谕。真实运行时，人在有限时间、有限工作记忆、有限信任下，必须完成一次**解码 → 判断 → 干预**：看到 fault_posterior 要能说出"哪坏了"；看到 k* 要能判断"该继续、缩短、还是停机"；看到置信度要能校准"该信几成"。这个过程是一个**有噪、有延迟、会疲劳的信道**。一次错误归因若被接口压成一个漂亮的绿勾，人的过信会把"机器错"放大成"人机共同错"。因此可用性评估不是 UI 打磨，而是**对解码器 h 的估计**：可理解（what is wrong）、可行动（what to do）、可校准（how much to trust）、及时（within m）、可恢复（undo/rollback）。

**灵感 2（伦理审查 → 物理安全不等于伦理可接受）**
直觉：VISTA 的动作集由力/滑移/几何定义。但一批**物理安全却伦理不可接受**的动作被系统默认放行：为了"分清谁坏了"而去主动探测活体/易损/有尊严的对象；VCV 与视觉力代理持续拍摄并留存可识别的人脸/身体；系统在操作员已明确拒绝后仍以"任务成功率更高"覆盖拒绝；把风险转嫁给未同意的旁观者；用隐私换任务收益。伦理审查不是发布前勾选框，而是**事前硬门 + 事后审计 + 对不可通约价值的审议**。关键：它必须能**拒绝**、能**要求补充信息**、能给出**带范围与期限的例外**，并能被**申诉**。

**灵感 3（两者合流 → 证书的"消费链"与"抗辩链"）**
直觉：第 65 轮造了证书的*生产链*（生成→归因→认证前缀→J_vista）。本轮补两条链：**消费链**（渲染→人之解码→人之决策→执行/求助）与**抗辩链**（冻结→留存证据→申诉→审议→先例）。这两条链恰好正面回应第 65 轮的隐藏风险：当归因后验不集中时，系统不必强行选最近假设，而是**被允许且被要求说"我不知道，这是证据，请你决定"**，并确保这句话**说得清、来得及、能生效**。把 ambiguous 变成一等公民动作，是比"提高归因准确率"更诚实的止血方式。

**灵感 4（信息论 → 可读性不是免费资源，诚实会牺牲决断）**
直觉：Fano 不等式意味着，若消息只有 b 比特、决策熵为 H(D)，则解码错误率有下界；"把所有后验都显示给人"既超出注意力预算，也不比"与决策相关的对比解释"更好。因此需要**决策相关抽象**：只渲染能改变决策的差异（"是力偏置还是几何错？看零力窗这一条"）。更微妙的是：在动作集里加入**明确弃权/求助**，会降低达到低错误率所需的消息保真度——诚实的"我不知道"其实是最省比特的安全动作。这给出"决断性 vs 校准性"的 Pareto 前沿：隐藏不确定度能提高表面决断，但会制造过信。

**灵感 5（三灵感合流 → CARE：证书的可用、可审、可辩、伦理可接受）**
闭环：VISTA 的故障后验 → **LCR** 在注意力/比特预算下渲染决策相关证书 → 人经**HCM**建模的噪声解码器给出决策 → **EAG** 对候选动作做伦理硬门 → 遇规范新颖/价值冲突触发 **ERP** 审议（结构化案卷、限时、带范围例外、可申诉）→ **CTR** 保证任何有资格者能一键冻结与复核 → **CNS** 记录同意与风险承担 → **DRP** 约束视觉证据的最小化留存 → 人的实际干预回写为**人机环路安全证据**并进入 **AIC-H** 对抗认证 → **J_care** 五层证书。CARE 不推翻 VISTA，而是给 VISTA 的证书加"消费者验收"。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（CARE 闭环）**：CARE = (VISTA, HCM, LCR, CAU, EAG, ERP, CTR, CNS, DRP, AIC-H, J_care)。定位：VISTA 的"证书消费/抗辩/伦理"升级。不变式：**机器安全、人的可操作性、伦理可接受性是三个不可互相替代的合取项；任何一项不满足，Valid(J_care)=False，系统只能安全退出或升级给人类，不得以另两项的高分补偿。**
- **定义 234（人的决策信道 HCM）**：在情境 s=(ρ,post,balls,A_t,k*) 下，人收到渲染消息 m，按策略 h(·|m) 选择决策 d∈D={go(k*), degrade(k′<k*), recalibrate_force, compliant_retreat, safe_idle, escalate_review, override_stop}。HCM 用带工作记忆上限、响应延迟与信任状态的随机解码器建模 P(d|s,m)，参数由预注册人因实验估计，允许跨会话漂移（学习/疲劳）。
- **定义 235（决策相关可读性）**：给定真值兼容决策集 D*(s)={d: 执行 d 后越界概率≤预算}，可读性 L_b(s)=P_{d∼h(·|R_b(s))}[d∈D*(s)]；R_b 为 ≤b 比特/≤c 注意力单元的渲染器。可读性只度量"能否做对"，不度量"是否被说服"。
- **定义 236（信任校准与告警负担）**：信任校准用 Brier 分数 B=E[(τ(m)−1[d∈D*])²]，τ 为人报告的信任或系统显示置信度；过信 ⇔ τ>实际可靠度，欠信 ⇔ τ<实际可靠度。告警负担 = 单位时间告警数 × 误报占比 × 确认延迟；三者共同决定"警报疲劳"下的漏检率。
- **定义 237（可用性评估 CAU）**：预注册的 within-subject、顺序平衡人因研究；主终点为可读性 L、决策时延 p95、Brier B、恢复时间 T_rec、NASA-TLX、SUS；用等效性/非劣检验而非仅看均值；场景覆盖健康、模糊归因、持续误报、真实告警洪泛。
- **定义 238（伦理可接受关系 EAG）**：情境 c=(受影响方, 同意状态, 数据敏感度, 可逆性, 脆弱性)。硬约束集 Ψ_hard={ψ_integrity, ψ_privacy, ψ_consent, ψ_non_deception, ψ_third_party_reversibility, ψ_fair_risk}；可接受动作集 A_adm(s,c)={a∈A: ∀ψ∈Ψ_hard, ψ(a,s,c)=1}。软约束用**向量值伤害**与偏序比较，**禁止未经审议的标量化**；若两动作伤害向量不可比较，判 `value_incomparable`。
- **定义 239（规范新颖性与冲突检测）**：d_norm(s,c) 为情境到先例库的最小嵌入距离；若 d_norm>τ_norm、或硬约束冲突、或软约束不可比较，则判 `normatively_novel`，禁止自动批准，必须进入 ERP。
- **定义 240（伦理审查协议 ERP）**：结构化案卷 F_case=(目标, 候选动作, 受影响方, 同意, 可逆性, 数据方案, 伤害向量, 含不作为的替代方案, 系统建议与其不确定度)；限时人类委员会裁决 ∈{approve, approve_with_constraints, reject, request_info, defer}；超时默认**不批准**（fail-closed）。
- **定义 241（带范围例外与先例）**：例外 e=(约束, 范围, 期限, 补偿控制, review_id)；先例库按规范上下文检索，带**过期与定期复核**；先例只能缩小审议成本，不能自动扩展范围——防止"伦理洗白"（ethics laundering）。
- **定义 242（可抗辩性 CTR）**：对任一自动决策 d，存在抗辩动作 cont，(i) O(1) 冻结执行，(ii) 生成防篡改（Merkle/签名）审计记录，(iii) 允许有资格者否决/覆写，(iv) 路由至 ERP，(v) 支持回滚。冻结与审计不得依赖语义流，必须在实时路径可用。
- **定义 243（同意与风险承担 CNS）**：记录谁同意了什么、在何种风险向量下、可撤回性；对未同意的第三方，系统默认**不得向其转移不可逆风险**；动态风险接受须有上限且可撤销。
- **定义 244（视觉证据最小化 DRP）**：VCV/视觉力代理所需的图像按目的限定：只提取任务相关嵌入，原始帧在设备端于 τ_ret 后删除；对外只发布哈希承诺与必要的差分隐私统计（预算 ε_dp）；可识别信息不得进入长期日志。
- **定义 245（人因/规范对抗集 AIC-H）**：在 AIC-V 之上增加 ℰ_human×ℰ_norm：告警洪泛、貌似合理但错误的解释、刻意诱导过信、社会工程绕过硬门、审查委员会被游说/俘获、先例被滥用。认证目标是**接口与制度的鲁棒性**，不要求归因正确。
- **定义 246（J_care 证书）**：J_care=(J_vista, legibility, trust_brier, latency_p95, alarm_burden, human_study_ver, adm_ver, review_id, exception_scope, consent_record, contest_available, privacy_budget, aic_h_ver)。Valid ⇔ Valid(J_vista) ∧ L≥L_min ∧ B≤B_max ∧ latency≤T_max ∧ 动作∈A_adm（或持有效例外）∧ 可抗辩 ∧ 隐私预算未超 ∧ aic_h_ver 为当前版本。
- **定义 247（人机环路安全界）**：设机器层越界概率 α_m（承接引理 8），人层误判概率 1−L，则端到端伤害概率满足 P[harm] ≤ α_m·(1−L_stop) + (1−α_m)·L_false_stop·c_stop + P[latency>m]·c_late。机器安全是必要条件而非充分条件；当 L 低时人层项主导。
- **定义 248（CARE 闭环算子）**：语义流 [VISTA → LCR 预渲染模板 → EAG 硬门审计 → ERP 新颖性检测/审议 → J_care 组装 → AIC-H 认证]；实时流 [锚点读 → 模板选择（不生成）→ 人机双通道确认 → 冻结/抗辩钩子 → k* 前缀派发 → 证据最小化落盘]。**实时流只选模板与执行冻结，零渲染学习、零伦理推理。**

## 2. 关键算法骨架

```python
# LCR：决策相关渲染（语义流预计算，实时只选模板）
m = lcr.render(post, rho, D_star, budget_b)      # 对比解释 + 会改变结论的证据 + 弃权项
if m.fault_entropy > H_MAX: m = m.with_flag('ambiguous')   # 不强行归因

# 人机环路（实时）
d = human.decode(m)                               # HCM 估计的 P(d|m)
if d == 'escalate_review' or ctr.frozen():
    safe_idle(); case = erp.open(render_case(...))   # ambiguous 是一等动作
else:
    a = d.action
    if not eag.admissible(a, ctx):                   # 硬门先于执行
        a = eag.safe_substitute(a) or ('safe_idle', 'escalate_review')

# 抗辩（O(1)，不依赖语义流）
on contest_event(who, reason):
    hw.freeze(); audit.append(sign(merkle_leaf(state, m)))  # 防篡改
    erp.route(case); suspend_until(verdict_or_override)

# 证据最小化
keep(embed_only(evidence)); schedule_delete(raw, tau_ret); publish(hash_commitment)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（人机环路安全分解）**：P[harm] ≤ α_m(1−L_stop)+(1−α_m)L_false_stop·c_stop+P[latency>m]c_late。故"机器层越界=0"并不推出"系统安全"；若 L_stop<1，存在机器安全而系统仍伤害的路径，反之亦然。
- **引理 10（可读性—保真下界，Fano）**：|D| 个决策、消息 ≤b 比特时，P_e ≥ φ^{-1}(H(D)−b)。因此不可能既保持小消息又对所有高熵故障零误解；**把"弃权/求助"加入 D 并把 d* 定义为 abstain（当熵高），可显著降低"自信地做错"的概率**，这是比提高归因准确率更稳健的接口设计。
- **引理 11（伦理门的可达安全收缩）**：A_cert^care=A_cert^vista∩A_adm。若 A_cert^vista∩A_adm=∅，则不存在可执行的"修复"动作，系统只能 safe_idle+escalate，任务可完成性不再有保证。**这是诚实的边界：有些故障没有伦理上可接受的自我修复。**
- **定理 9（CARE 端到端三元合取）**：在 A94–A99 下，Valid(J_care) ⇒ 机器安全 ∧ 人可操作 ∧ 伦理可接受 ∧ 可抗辩；任一失效都退化到"安全退出 + 人类审议"，而非静默继续。
- **定理 10（决断—诚实不可能三角）**：在故障熵 H(ℋ|ρ)>0 时，不存在同时最大化决断性、最小化校准误差、且消息比特有限的渲染器；隐藏熵会系统性地提高过信概率。故 LCR 必须显式呈现不确定度与弃权项，接受决断性损失。
- **实时性**：渲染模板、伦理硬门、冻结/抗辩均在实时路径；ERP 审议、AIC-H、人因建模在语义流。目标实时增量 ≤0.35ms（模板选择 0.05 + 硬门查表 0.02 + 冻结钩子 0.02 + 其余同 VISTA），A99 修订契约。
- **本研究的元伦理**：可用性实验本身须过伦理审查、知情同意、参与者数据最小化——CARE 的第 0 个用户是它自己的研究协议。

## 5. 本轮最大风险

**一句话**：CARE 把"伦理可接受"形式化为硬约束与审议协议，但**约束由谁书写、委员会是否称职且未被俘获、人因参数是否只代表某一小群受试者**，这些前提无法由系统自身证明；一旦被形式化，糟糕的规范会被"已审查"洗白（ethics theater），而过度简化的可读证书又会制造虚假信任——**第 65 轮的"归因错误的复合故障"由此升级为"经过合规流程、被人机共同确认的错误"**，这是本轮全部安全界与认证论证共同依赖的隐藏假设（A96/A95）。

## 2. 形式化定义（完整版）

**定义 233（CARE 闭环）** CARE 是 VISTA 的"证书消费/抗辩/伦理"升级。它在 VISTA 的语义流/实时流骨架上挂载六件事：把证书渲染成可解码消息（LCR）、估计并纳入人的解码误差（HCM/CAU）、对候选动作施加伦理硬门（EAG）、对规范novelty与价值冲突做限时人类审议（ERP）、保证任何有资格者能冻结与申诉（CTR）、记录同意与风险承担（CNS），并约束视觉证据的留存（DRP）。不变式：**机器安全、人的可操作性、伦理可接受性是三个不可互相替代的合取项；任一不满足即 Valid(J_care)=False，系统只能安全退出或升级人类，禁止以另两项的高分补偿。** 另：所有渲染学习、伦理推理、审议与认证在语义流；实时流只做模板选择、硬门查表、冻结与派发，零学习写操作。

**定义 234（人的决策信道 HCM）** 在情境 s 下，人收到消息 m 后按 h(·|m) 选择 d∈D；HCM 为 P_θ(d|s,m) 的参数族，显式含三个瓶颈：(i) 工作记忆 W（可同时保持的证据块数，默认 4±1）；(ii) 反应时延 T_react，随消息复杂度与告警数上升；(iii) 信任状态 τ，随历史可靠度更新但有过信/欠信惯性。参数在预注册人因实验中估计，并在会话内在线更新（仅语义流写）。HCM 不用于对人的"评分"，只用于把人的误差项纳入系统安全界。

**定义 235（决策相关可读性）** 令 D*(s) 为"执行后越界概率不超过预算"的决策集。可读性
L_b(s)=P_{d∼h(·|R_b(s))}[d∈D*(s)]。
它只度量"能否做对"，不度量"是否被说服"。相应地定义**自信错误率** CE_b(s)=P[d∉D*(s) 且 τ(m)≥τ_hi]，这是比普通错误更危险的量，直接对应第 65 轮"更自信地继续执行"。

**定义 236（信任校准与告警负担）** 校准用 Brier 分数 B=E[(τ(m)−1[d∈D*])²]；另报可靠性曲线与过信率 P[τ>1−actual_violation]。告警负担 AB = λ_alert · f_false · E[T_ack]，其中 λ_alert 为单位时间告警数、f_false 为误报占比；AB 进入 HCM 的时延与漏检项。人因实验必须同时报告"平均表现"和"最差受试者"（安全不能只看均值）。

**定义 237（可用性评估 CAU）** 预注册的 within-subject、顺序平衡实验。纳入/排除标准、随机化、场景库、主/次终点、分析计划全部先于数据采集。主终点：L、p95 时延、B、T_rec（从故障到安全状态或正确求助的时间）、CES（自信错误率）。次终点：NASA-TLX、SUS、告警负担、主观可解释性。统计：对预定义裕度做非劣/等效检验，报告效应量与 95% CI；不做 p-hacking。**该实验自身须经伦理审查、知情同意，并对参与者数据做最小化。**

**定义 238（伦理可接受关系 EAG）** 给定规范上下文 c，动作 a 可接受当且仅当
a∈A_adm(s,c) ⇔ ∀ψ∈Ψ_hard, ψ(a,s,c)=1。
六个硬约束：(ψ_integrity) 不对活体/易损/有尊严对象做非必要物理探测；(ψ_privacy) 不超目的留存可识别视觉数据；(ψ_consent) 不覆盖已明确拒绝的人；(ψ_non_deception) 渲染不得为促成执行而隐藏不确定度或虚构确定性；(ψ_third_party_reversibility) 不向未同意第三方施加不可逆风险；(ψ_fair_risk) 不把风险按"谁离得近/谁没话语权"转移。软约束用**向量值伤害** h(a)∈ℝ^k（任务损失、隐私损失、尊严/自主、第三方风险、长期能力侵蚀），按偏序比较；**若两动作伤害向量不可比较，判 `value_incomparable` 并进入 ERP，禁止未经审议的加权求和。**

**定义 239（规范新颖性与冲突检测）** 设先例库嵌入为 {z_i}，d_norm(s,c)=min_i‖φ(s,c)−z_i‖。若 d_norm>τ_norm，或存在硬约束冲突（同一动作在不同受影响方上互相矛盾），或软约束不可比较，则判 `normatively_novel`。此时**禁止自动批准**，必须进入 ERP；系统可继续执行的部分仅限于"监控 + 可逆撤回"。

**定义 240（伦理审查协议 ERP）** 结构化案卷
F_case=(目标, 候选动作集, 受影响方与代表性, 同意状态, 可逆性分析, 数据方案, 伤害向量, 含"不作为"的替代方案, 系统建议及其不确定度)。
限时人类委员会裁决 ∈{approve, approve_with_constraints, reject, request_info, defer}。**超时默认 reject（fail-closed）**。裁决须附理由与有效期。ERP 是**机构过程**而非模型输出：它可以在系统"物理安全"时拒绝，也可以允许有补偿控制的例外。

**定义 241（带范围例外与先例）** 例外 e=(约束, 范围, 期限, 补偿控制, review_id)。先例库按规范上下文检索，带**过期与定期复核**；先例只能降低审议成本，**不能自动扩展范围**，且不得跨受影响方群体迁移。设置"先例漂移检测"：若连续 N 次裁决与历史同类显著不同，触发制度复核——防止"伦理洗白"（ethics laundering）与范围蠕变。

**定义 242（可抗辩性 CTR）** 对任一自动决策 d，存在抗辩动作 cont，满足：(i) O(1) 冻结执行（硬件/实时层钩子）；(ii) 生成防篡改审计记录（每步状态与所用渲染的 Merkle 叶 + 签名）；(iii) 允许有资格者否决/覆写；(iv) 路由至 ERP；(v) 支持回滚到最近安全锚点。冻结与审计**不得依赖语义流**；系统不得在申诉未决时自动恢复，除非有显式、留痕、有人签署的覆写。

**定义 243（同意与风险承担 CNS）** 记录 (谁, 同意什么, 在何种风险向量下, 是否可撤回, 期限)。对未同意的第三方，系统默认**不得向其转移不可逆风险**；动态风险接受须有上限、可撤销、且不能由受益方单方面提高。CNS 记录进入审计链，参与 EAG 的 ψ_consent/ψ_fair_risk 判定。

**定义 244（视觉证据最小化 DRP）** VCV/视觉力代理只提取任务相关低维嵌入；原始帧在设备端 τ_ret 后删除；对外只发布哈希承诺与必要的差分隐私统计，总预算 ε_dp；可识别信息（人脸、人体、住址线索）不得进入长期日志与模型再训练。任何"为改进模型而保留原始图像"的请求须走 ERP 且默认拒绝。**隐私不是可用性的对立面：不可解释的删减会破坏可读性，故需在 L 与 ε_dp 间显式报告 Pareto 前沿。**

**定义 245（人因/规范对抗集 AIC-H）** 在 AIC-V 的 ℰ_F×ℰ_vis×ℰ_time 上增加 ℰ_H=ℰ_human×ℰ_norm：告警洪泛、貌似合理但错误的解释、刻意诱导过信、社会工程绕过硬门、审查委员会被游说/俘获、先例滥用与范围蠕变、把"已审查"当作通行证。认证目标是**接口与制度的鲁棒性**，明确**不要求**归因正确；共因/未知故障下只要求能判 ambiguous、能冻结、能 fail-closed。

**定义 246（J_care 证书）** J_care=(J_vista, legibility, trust_brier, latency_p95, alarm_burden, human_study_ver, adm_ver, review_id, exception_scope, consent_record, contest_available, privacy_budget, aic_h_ver)。验证规则：
Valid(J_care) ⇔ Valid(J_vista)
∧ L≥L_min ∧ B≤B_max ∧ p95≤T_max ∧ alarm_burden≤AB_max
∧ (动作∈A_adm ∨ 持未过期、范围匹配的例外)
∧ contest_available ∧ 隐私预算未超 ∧ aic_h_ver 为当前版本。
审计链新增：为何认为人读得懂（人因版本与 L/B）、为何伦理可接受（硬约束证据 / review_id / 例外范围）、谁能抗辩、原始证据是否已最小化。

**定义 247（人机环路安全界）** 设机器层越界概率 α_m（承接引理 8 的 α_chunk+δ_fi+α_vis），人层正确停止概率 L_stop，误停代价 c_stop，时延越界概率 P_late=P[T_react>m]。则
P[harm] ≤ α_m·(1−L_stop) + (1−α_m)·L_false_stop·c_stop + P_late·c_late。
三项分别对应"机器坏且人没接住"、"机器好但人误伤"、"来不及"。**机器层越界=0 不推出系统安全；L_stop 低时人层项主导。**

**定义 248（CARE 闭环算子）** 语义流：[VISTA 全链 → HCM 更新 → LCR 预渲染模板族 → EAG 对候选动作查硬门 → ERP 规范新颖性检测/审议/例外签发 → DRP 证据最小化 → J_care 组装 → AIC-H 认证]。实时流：[锚点读 → 模板选择（不生成、不推理）→ 人机双通道确认 → 冻结/抗辩钩子 → k* 前缀派发 → 最小化证据落盘 → J_care 运行期字段更新]。

### IP-225 LCR（决策相关渲染）

```python
class LegibleRenderer:
    """语义流预计算模板；实时只选模板。目标：最大化决策价值/比特，而非显示全部后验。"""
    def render(self, post, rho, D_star, budget_b):
        h_star = max(post, key=post.get)
        entropy = -sum(p * np.log(p + 1e-12) for p in post.values())
        # 1) 高熵 → 显式 ambiguous，不追求一个"最像的答案"
        if entropy > H_MAX:
            return Message(kind='ambiguous', top=h_star,
                           top_p=post[h_star],
                           ask='fault attribution uncertain; please choose/escalate',
                           changed_by='none (entropy too high)')
        # 2) 对比解释：只显示"若换成次优假设，决策会怎么变"
        alt = sorted(post, key=post.get, reverse=True)[1]
        contrast = self._decision_flip(h_star, alt, rho)   # 会改变结论的证据
        # 3) 决策相关抽象：在比特预算内选择最有决策价值的证据子集
        items = self._rank_by_decision_value(rho, D_star)
        chosen, bits = [], 0.0
        for it in items:
            if bits + it.bits <= budget_b:
                chosen.append(it); bits += it.bits
        # 4) 可行动性：给出推荐动作 + 可逆性等级 + "什么会让我改主意"
        return Message(kind='actionable', top=h_star, top_p=post[h_star],
                       entropy=entropy, evidence=chosen,
                       recommend=self._recommend(post, D_star),
                       reversibility=self._reversibility(D_star),
                       changed_by=contrast, bits=bits)

    def _decision_flip(self, h1, h2, rho):
        # 找出使 argmax 决策在两假设间翻转的最小证据（contrastive）
        return min_evidence_flipping(h1, h2, rho)
```

### IP-227 EAG（伦理硬门）

```python
class EthicalGate:
    """硬门先于执行；软约束用向量偏序，禁止未审议标量化。"""
    HARD = ('integrity', 'privacy', 'consent', 'non_deception',
            'third_party_reversibility', 'fair_risk')

    def admissible(self, a, ctx):
        for psi in self.HARD:
            verdict = self.check[psi](a, ctx)
            if verdict is False:
                return False, psi, 'violates_hard_constraint'
            if verdict is None:                 # 信息不足/冲突
                return None, psi, 'needs_review'
        return True, None, 'ok'

    def safe_substitute(self, a, ctx):
        # 先找可逆、非接触、只读的替代动作；找不到返回 None
        for cand in self.substitutes(a):
            ok, _, _ = self.admissible(cand, ctx)
            if ok:
                return cand
        return None

    def compare_soft(self, a1, a2, ctx):
        h1, h2 = self.harm_vector(a1, ctx), self.harm_vector(a2, ctx)
        if dominates(h1, h2):
            return a2
        if dominates(h2, h1):
            return a1
        return None                            # value_incomparable → ERP
```

### IP-228 ERP（审议与例外）

```python
class EthicsReview:
    def open(self, situation, candidates, system_recommendation):
        novelty = self.novelty.distance(situation)     # d_norm
        case = CaseFile(
            goal=situation.goal, candidates=candidates,
            affected_parties=self.cns.parties(situation),
            consent=self.cns.status(situation),
            reversibility=self.analyze_reversibility(candidates),
            data_plan=self.drp.plan(situation),
            harm_vectors=[self.eag.harm_vector(a, situation.ctx) for a in candidates],
            alternatives=candidates + ['do_nothing'],
            system_advice=system_recommendation)
        if novelty <= TAU_NORM and not case.has_hard_conflict():
            return self._apply_precedent(case)          # 仅缩小成本，不扩范围
        verdict = self.board.deliberate(case, timeout=ERP_TIMEOUT)  # 超时 fail-closed
        if verdict.timeout:
            return Verdict.reject(reason='review_timeout_fail_closed')
        if verdict.kind == 'approve_with_constraints':
            return self._issue_scoped_exception(case, verdict)
        return verdict

    def _apply_precedent(self, case):
        p = self.precedent.best(case)
        if p is None or p.expired() or not p.scope_covers(case):
            return Verdict.request_info('no_valid_precedent')
        return Verdict.approve(review_id=p.review_id, precedent=p.id)
```

### IP-229 CTR（抗辩，实时可用）

```python
class Contestability:
    """不依赖语义流：冻结 + 审计 + 路由；申诉未决不自动恢复。"""
    def on_contest(self, actor, reason, state, message):
        if not self.has_standing(actor):
            return Rejected('standing_required')
        hw.freeze()                                    # O(1) 硬件/实时钩子
        leaf = merkle_leaf(canonical(state), canonical(message))
        self.audit.append(sign(leaf))
        case = self.erp.route(actor=actor, reason=reason, leaf=leaf)
        return Suspended(case_id=case.id,
                         resume_requires='verdict_or_signed_override')

    def resume(self, case_id, verdict_or_override):
        if verdict_or_override.approved and verdict_or_override.signed:
            return hw.unfreeze()
        return Suspended('not_authorized')
```

### IP-233 CARE 闭环算子（整合）

```python
def CARE_round(M, obs, human):
    # ———— 语义流 ————
    M = VISTA_round_semantic(M, obs)                 # 第 65 轮：VPG/FIR/CSC...
    post, rho, D_star = M.post, M.rho, M.decision_star()
    templates = M.lcr.render_batch(post, rho, D_star, budget_b=M.budget_b)
    ctx = M.cns.context(obs)
    admission = {a: M.eag.admissible(a, ctx) for a in M.candidate_actions()}
    if any(v[2] == 'needs_review' for v in admission.values()):
        M.review = M.erp.open(M.situation(), M.candidate_actions(), M.recommend())
    M.drp.minimize(obs.visual)

    # ———— 实时流（≤0.35ms 增量）————
    m = M.lcr.select_template(templates, M.runtime_hint)   # 只选不生成
    human.update(m)                                         # 仅本地显示
    d = human.decide(m)                                     # 人的实际决策
    if d in ('escalate_review', 'override_stop') or M.ctr.frozen():
        M.safe_idle()
        case = M.erp.open(M.situation(), M.candidate_actions(), M.recommend())
        return M, 'escalated', build_j_care(M, case)
    a = d.action
    ok, psi, why = M.eag.admissible(a, ctx)
    if not ok:
        a = M.eag.safe_substitute(a, ctx)
        if a is None:
            M.safe_idle()
            return M, 'ethically_blocked', build_j_care(M, None)
    execute_prefix(a, k_star=M.k_star)
    M.ctr.arm(a, m, M.state_snapshot())                    # 冻结/审计钩子常驻
    return M, 'executed', build_j_care(M, M.review)
```

## 4. 推导

**引理 9（人机环路安全分解）** 把系统是否伤害分解为两个互斥来源与一个时延项。(i) 机器层越界（概率 α_m）且人未正确停止（概率 1−L_stop）；(ii) 机器层未越界（1−α_m）但人误停/误操作造成代价（概率 L_false_stop，量级 c_stop）；(iii) 反应时延超过不可逆视界（P_late）。三者按全概率与联合界相加即得定义 247。注意 α_m 与 L 不独立：更复杂的证书可能降低 α_m 的误读同时提高时延，故 L 与 T_react 需联合优化。∎

**引理 10（可读性—保真下界，Fano）** 设决策 D 的熵为 H(D)，消息 m 满足 H(m)≤b（比特预算/注意力预算）。任何解码器 h 的错误率 P_e 满足 Fano：
H(D|m) ≤ H_b(P_e) + P_e·log(|D|−1)。
又 I(m;D)=H(D)−H(D|m) ≤ H(m) ≤ b，故 H(D)−b ≤ H_b(P_e)+P_e log(|D|−1)，即 P_e ≥ φ^{-1}(H(D)−b)，其中 φ 单调。**推论（弃权的价值）**：若把 D*(s) 在高熵时定义为 {escalate_review}，则"正确"不再要求区分具体故障，只要求识别"熵高→求助"，从而把需要传输的有效熵从 H(ℋ|ρ) 降到 H(1[熵高])，大幅降低对 b 的要求。这解释了为什么"诚实的我不知道"是信息效率最高的安全动作，也解释了隐藏熵（为显得决断而省略不确定度）为何会提高自信错误率 CE。∎

**引理 11（伦理门的可达安全收缩）** 由 A_adm⊆A，认证动作集 A_cert^care=A_cert^vista∩A_adm⊆A_cert^vista。若存在故障使其唯一修复动作 a_repair∈A_cert^vista 但 a_repair∉A_adm（例如对易损/活体对象的物理判别探针），则 A_cert^care∩A_repair=∅：系统无法在伦理可接受范围内自我修复，只能 safe_idle + ERP。因此 CARE 的**任务可完成性弱于 VISTA**，但**系统可接受性更强**；这是有意的权衡，不能既要求"对任何故障都能自愈"又要求"绝不触碰不可接受动作"。∎

**定理 9（CARE 端到端三元合取）** 在 A94–A99 下：
1. **机器安全**：Valid(J_care)⇒Valid(J_vista)，由 VISTA 定理 7 得几何/力/块前缀安全。
2. **人可操作**：L≥L_min、B≤B_max、p95≤T_max、AB≤AB_max 由 CAU 在预注册场景上估计并以置信下界核验；由引理 9，人层项被显式计入而非默认 0。
3. **伦理可接受**：动作∈A_adm 或持未过期、范围匹配的例外（定义 238/240/241）；规范新颖性未被自动放行（定义 239）。
4. **可抗辩**：contest_available 且冻结/审计不依赖语义流（定义 242）；申诉未决不自动恢复。
5. **失效退化**：任一项不满足→不得执行，走 safe_idle 或 ERP；不得静默继续。
六层证书链从"几何-技能-干扰-接触-归因"扩到"几何-技能-干扰-接触-归因-可用-伦理-抗辩"。∎

**定理 10（决断—诚实不可能三角）** 固定情境 s 与故障熵 H(ℋ|ρ)=h>0、消息比特上限 b、决策集 D。若渲染器 R 不呈现任何不确定度（"决断渲染"），则其显示置信度 τ_R(m) 与真实可靠度 1−actual_violation 之间存在系统性正偏；在 h 越大、b 越小时偏置越大，过信概率 P[τ_R>1−actual] 严格高于诚实渲染器。反之，诚实渲染把 h 显式传输，需 ≥H_b(h) 比特，挤占决策相关证据的预算，使可读性 L 下降（引理 10）。故不存在同时最大化决断性、最小化校准误差、且 b 有限的渲染器；LCR 必须显式选择一个 Pareto 点，并默认偏向诚实（呈现不确定度与弃权项），接受决断性损失。∎

**推论（对第 65 轮风险的对冲）** 第 65 轮的致命路径是"未知复合故障被强行归因→系统更自信"。CARE 的拦截不是提高归因，而是：(i) LCR 在 H(ℋ|ρ)>H_MAX 时输出 `ambiguous` 而非 top-1；(ii) D 含 `escalate_review`，且引理 10 说明这是信息最优的；(iii) EAG 可因"未知/价值冲突"直接阻断；(iv) CTR 让任何有资格者在执行中冻结。因此"更自信地继续执行"需要同时绕过四个独立机制，而不再依赖 FIR 单点正确。∎

## 7. 已知风险

**一句话**：CARE 把"伦理可接受"形式化为硬约束与审议协议，但**约束由谁书写、委员会是否称职且未被俘获、人因参数是否只代表某一小群受试者**，这些前提无法由系统自身证明；一旦被形式化，糟糕的规范会被"已审查"洗白（ethics theater），而过度简化的可读证书又会制造虚假信任——**第 65 轮的"归因错误的复合故障"由此升级为"经过合规流程、被人机共同确认的错误"**，这是本轮全部安全界与认证论证共同依赖的隐藏假设（A96/A95）。

**次级风险与缓解**：
1. **伦理形式化的合法性问题**：硬约束的正当性来自制度而非技术；缓解：显式声明 A96 为外部政治前提，公开约束清单与修订流程，允许受影响方参与制定，保留"制度性拒绝"通道。
2. **委员会俘获/失能**：缓解：AIC-H 红队（游说、时间压力、先例滥用），委员会多样性与轮换，裁决公开可审计，超时 fail-closed。
3. **人因参数外推失效**：实验室受试者≠真实操作员；缓解：分级部署（shadow → supervised → autonomous），在线漂移检测，最差受试者与置信下界而非均值。
4. **假信任/解释攻击**：过度简化的绿勾；缓解：强制呈现不确定度与弃权项（定理 10 的诚实侧），解释忠实性校验（ψ_non_deception），对抗训练操作员。
5. **伦理门导致任务不可完成**：可达安全集可能为空（引理 11）；缓解：明确产品定位为"可安全退出/求助"，不以任务成功率兜底，提供人机协同的合规替代。
6. **隐私与可读性冲突**：证据最小化削弱解释与复核；缓解：报告 (L, ε_dp) Pareto 前沿，用哈希承诺+可验证计算平衡审计与隐私。
7. **抗辩被滥用（恶意冻结）**：缓解：资格与频率限制、申诉分级、冻结同时自动进入安全状态，滥用留痕；但**安全优先于可用性**。
8. **先例导致伦理漂移**：缓解：先例过期、范围不扩展、漂移检测与定期制度复核。
9. **实时预算**：渲染/硬门/冻结须在实时路径；缓解：语义流预渲染模板、硬门查表、冻结用硬件钩子，目标增量 ≤0.35ms（A99，需实测）。
10. **元伦理递归**：评估研究本身可能伤害参与者；缓解：独立 IRB、知情同意、数据最小化，并把研究协议当作 CARE 的第一个受审对象。
