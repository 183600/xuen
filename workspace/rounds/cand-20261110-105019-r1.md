# 第 43 轮（新循环第 3 轮） · 标定即安全见证：把手眼标定的不确定度变成安全证书的一等公民（CalibCert × 主动标定 × 漂移监控，四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 的 Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」，本质是**证书对某个未被建模的误差源过于自信**。本轮灵感词「安全性」「手眼标定」恰好指向一个此前被默认「已经解决」、实则是安全证书最大隐藏误差源的环节：**相机—机器人外参 X**。所有感知到的障碍、抓取位姿、语义残差都活在相机坐标系里，必须经手眼变换才能进入机器人坐标系与守卫；而 X 从未进入过任何一轮的证书预算。本轮把 X 的不确定度显式化：AX=XB 的可观测性结构 → 标定证书 CalibCert → 安全裕度传播 ρ_calib → 安全驱动的主动标定 → 在线漂移作为独立安全见证。核心命题：**标定不只是精度问题，它是安全证书的必要组成部分；未进入证书的标定误差，就是一个静默的安全漏洞。**

## 0. 直觉与动机

**灵感 1（手眼标定 → 安全链上唯一一段「没有证书的连杆」）**：第 41/42 轮的证书链条极其完整——几何残差证书、CBF、L0 查表、Sim-to-Real 迁移界 W₁，每一环都被量化、被保守放大、被实验门槛约束。唯独坐标变换 X 是「白送的」：大家默认标定一次就精确。但误差是线性放大的：距离 r 处的点，外参旋转误差 ε_θ 造成的横向位置误差约 r·ε_θ；r=2m、ε_θ=0.5° 时就是 17.5mm，已经能和抓取容差、CBF 安全裕度同量级。更危险的是**它不在证书里**：证书声称「m_geom ≥ θ」，而真实的 m_real 已经被 X 的误差悄悄吃掉一块，于是系统会在「形式正确」中静默越界。直觉结论：既然 X 是安全链的一部分，它就必须像其他部分一样被测量、被定界、被写进证书、被运行时监控。

**灵感 2（安全性 → 不是「误差更小」，而是「界可证明、可审计、且标定过程本身安全」）**：安全性的严格含义不是把标定做准，而是**对做不到准的方向也给出可证明的界**。手眼标定有一个精度指标无法掩盖的结构性问题：**可观测性退化**。纯平移运动无法确定 X 的平移；所有旋转绕同一轴时，绕该轴的旋转与沿该轴的平移不可观测。这些是零空间方向——再多的数据、再小的噪声也**永远**测不出来，任何从残差协方差估出的「小方差」都是幻觉。所以安全证书必须把不确定度拆成两部分：可观测子空间上的统计椭球 Σ_obs（可用数据缩小）与不可观测零空间上的先验盒 B_null（只能来自 CAD/机械公差，**不可被数据证伪**）。此外安全还包含两层：**标定过程本身的安全**（标定时机器人要动，而此刻证书最弱，存在鸡生蛋问题）与**可审计性**（谁、何时、用什么数据、在什么硬件上标的，ISO 10218 / ISO/TS 15066 式安全档案要求可追溯）。于是「标定证书」天然是一种安全案例制品，带有工作域 W_valid 与有效期 τ_valid。

**灵感 3（耦合 → 标定误差正是第 42 轮 W₁ 里最系统性、最可测的一块）**：第 42 轮的 W₁(D_real, D_sim) 把所有 sim-to-real 偏差揉成一个数，其中**外参偏差是系统性的、非随机的**：仿真里相机外参是精确的，实机上它偏了 3mm/0.3°，这一项会稳定地污染所有感知，且不会被域随机化的光照/摩擦覆盖掉。因此把 Δ_calib 显式加进 D_sim，并用实机标定数据直接估 W₁_calib，是对第 42 轮最大风险最直接的补强。更进一步：主动标定的本质是**用有限的运动/时间买安全裕度**——这和第 42 轮「用离线预算买在线预算」同构，只是这里的货币是「标定激励（excitation）」与「安全预算 θ_calib」。标定不再是一次性运维动作，而是飞轮里一个**可被调度、可被估值、可被证书化**的决策变量。

**耦合升级（v8 一句话）**：运动证书管「不越界」，力矩/社会证书管「不施暴、不惊扰」，而本轮补上更底层的一条——**坐标证书管「上述判断所依赖的坐标系本身可信」**。标定证书是所有其他证书的前置条件：X 不可信时，任何基于相机观测的 margin 都必须打折。

## 1. 形式化定义（增量：定义 38–45）

**定义 38（手眼标定方程与相对运动集）**：设 A_i = T_ee(i+1)·T_ee(i)⁻¹ 为机器人末端在两次位姿间的相对运动（由正运动学给出），B_i = T_cam(i+1)·T_cam(i)⁻¹ 为相机相对运动（由视觉/标定板给出），未知外参 X ∈ SE(3) 满足
A_i X = X B_i, i = 1..n。
运动集 M = {(A_i, B_i, W_i)}，W_i 为相对运动噪声的信息矩阵（融合 FK 参数误差与视觉定位误差）。注意 A_i 本身也带运动学参数误差，因此严格形式是 FK 参数与外参的**联合标定**；本轮把 FK 误差作为先验项并入 W_i，主线仍聚焦外参。

**定义 39（可观测性 Gramian 与结构性零空间）**：令残差 E_i(X) = A_i X B_i⁻¹ X⁻¹（真值时 E_i = I），r_i = log(E_i) ∈ se(3)。对右扰动 X ← X·exp(ξ̂)，一阶展开给出
r_i(ξ) ≈ J_i ξ,  J_i = Ad_X · (Ad_{B_i} − I) ∈ R^{6×6}。
观测矩阵 H(M) = Σ_i J_iᵀ W_i J_i。**结构性零空间** N = ker(H) = ∩_i ker(Ad_{B_i} − I)：这些方向对任何数量的数据都不可辨识（单轴旋转 → 绕轴旋转与沿轴平移不可观测；纯平移 → 平移不可观测）。把 R⁶ = R ⊕ N 正交分解，R 为可观测子空间。**关键安全含义**：在 N 上报告的「残差协方差」没有意义，必须用先验盒替代。

**定义 40（标定证书 CalibCert）**：五元组 C_calib = (μ, Σ_obs, B_null, W_valid, τ_valid; prov)。其中 μ 为点估计；Σ_obs 为可观测子空间上的协方差（由 H_R 的伪逆与残差噪声给出）；B_null 为不可观测方向上的有界先验盒（来自 CAD/装配公差/机械限位）；W_valid 为**证书有效工作域**；τ_valid 为**证书有效期**（时间/温升/负载/碰撞事件后的失效窗口）；prov = (标定数据指纹, FK 参数版本, 硬件序列号, git_commit, 标定人/自动流程 id) 为溯源。证书断言：以概率 ≥ 1−δ，对任意 t ∈ [0, τ_valid]，
X_true ∈ U(C_calib) = { μ·exp(ξ̂) : ξ = ξ_R + ξ_N, ξ_Rᵀ Σ_obs⁻¹ ξ_R ≤ χ²_{r,1−δ}, ξ_N ∈ B_null }。
**要点**：证书不是「一次标定永久有效」，而是一个带有效域与有效期的可失效断言；触发重新标定是证书语义的一部分。

**定义 41（标定误差到安全裕度的传播）**：对相机系中的点 p（距相机光心 r = ||p||），外参扰动导致机器人系位移
δq = R·(ω × p + v) = G(p)·ξ,  G(p) = R·[−p̂, I] ∈ R^{3×6}。
**标定安全半径修正**（取不确定集 U 上的最坏情形）：
ρ_calib(p) = max_{ξ∈U} ||G(p)ξ|| = χ·sqrt(λ_max(G Σ_obs Gᵀ)) + support(G(p), B_null)，
保守闭式上界 ρ_calib(p) ≤ χ(σ_ω r + σ_v) + (b_ω r + b_v)。
证书化几何裕度 m_cert(x) = m_geom(x) − ρ_calib(p(x))。**命题（可靠性）**：若 m_geom(x) ≥ θ + ρ_calib(p(x))，则真实裕度 ≥ θ。**推论（可认证操作半径）**：若任务容差为 g（抓取/装配/接触允许的位置误差），则仅在
r ≤ r* = (g − χσ_v − b_v) / (χσ_ω + b_ω)
内可认证，W_valid = { p : ||p|| ≤ r* }；超出 r* 不是「危险」，而是「**未被证书覆盖**」，CAR 必须拒绝或降速接近，而不能假装安全。

**定义 42（安全裕度预算守恒）**：把总安全裕度视为可加预算
θ_total = θ_model + θ_est + θ_calib + θ_comm + θ_reserve，
其中 θ_calib 即由 ρ_calib 折算的占用项。前几轮只显式记账 θ_model 与 θ_est，θ_calib 一直是「隐形的、被忽略的一笔」。守恒律要求：任一项增大必须从 reserve 借或收缩可用工作域/速度；reserve 见底即触发降级。这条守恒律把「何时该重新标定」变成一个可判定条件：当 θ_calib 超过任务分配给它的份额，或 r* < 任务所需作用距离时，重新标定的收益为正。

**定义 43（在线标定漂移与单调膨胀）**：用独立闭环残差 z_t（已知标定板/工装、或视觉伺服闭环残差、或双相机交叉校验）监控外参。H0 下归一化新息 d_t = z_tᵀ S_t⁻¹ z_t ~ χ²，用 EWMA/CUSUM 得漂移统计量。检测器以虚警率 ≤ δ_fa、检测延迟 ≤ Δ_d 报警。在两次「认证重标定」之间，协方差只允许**单调膨胀**：Σ_obs(t) = Σ_obs(t_last) + Λ(t−t_last)，Λ ⪰ 0。**可靠性论证**：只要 Δ_d 小于「漂移到不安全所需时间」且膨胀模型覆盖真实漂移，则证书在检测延迟内仍成立；一旦报警，立即收缩 W_valid 或进入 SafeStop/Recalibrating，绝不在未重认证时缩小协方差。

**定义 44（安全驱动的主动标定）**：标定不再是「随便动几下手」，而是在安全约束下最大化安全收益的最优实验设计：
max_{M}  V(M) = min_{x∈X_crit} [ m_geom(x) − ρ_calib(p(x); H(M)) ]
s.t.  cost(M) ≤ B,  M ⊆ X_precert,  risk(M) ≤ R。
X_precert 为标定期间可用的**预认证安全包络**（机械限位 + 上一张证书的保守膨胀，解决「标定时证书最弱」的鸡生蛋问题）；X_crit 为对任务最关键的区域（不是全工作空间）。定义**安全标定效率** η = ΔV / (cost(M)·exposure(M))，并给出贪心算法：每步选择使「单位时间、单位风险的临界区最小裕度提升」最大的运动。**与纯精度标定的区别**：不是最小化 Σ_obs 的迹，而是最小化**安全关键点上的最坏 ρ_calib**——用 G(p) 对信息矩阵做任务加权。

**定义 45（标定进入 Sim-Cert-RAG 飞轮）**：仿真扰动分布升级为 D_sim^v2 = D_sim ⊗ Δ_calib（Δ_calib 覆盖外参偏置/漂移/温漂/装配误差）。W₁ 分解为 W₁ ≤ W₁_dyn + W₁_sens + W₁_calib + W₁_env，其中 W₁_calib 可由实机标定数据**直接估计**（这是对第 42 轮 W₁ 低估风险最可操作的补强）。KB 记录新增标定指纹与 CalibCert 模板；CAR 转移新增 CalibValid 守卫位；SCV 在每条边注入 δX ~ Δ_calib 重跑压力测试。**长期可靠性命题**：若 Δ_calib 覆盖真实外参分布、漂移检测满足定义 43，且每次重标定都重新签发 CalibCert，则证书的长期 soundness 以概率 ≥ 1−δ−δ_fa 维持。

## 2. 四大产出设计（新增 IP-57/58/59 + 升级 IP-49/51/52/54/55/56/45/50）

### 2.1 IP-57 CALIB-CERT-SYNTHESIZER（标定证书合成器 CCS）
1. **联合求解**：Tsai-Lenz 给初值 → 非线性最小二乘（同时优化 X 与 FK 参数修正量）。
2. **可观测性分解**：构造 H，特征分解，阈值截断得 rank r 与零空间基；零空间方向一律用 B_null 覆盖，**禁止**用伪逆方差冒充。
3. **证书签发**：计算 χ² 置信椭球、r*、W_valid、τ_valid（温升/负载/振动经验模型），附 prov 溯源。
4. **传播接口**：向 IP-49/ECR 输出「按距离的 ρ_calib 曲线 + 有效半径」，而非一个全局常数膨胀。

### 2.2 IP-58 SAFETY-AWARE ACTIVE CALIBRATION（安全主动标定 SAC）
1. **激励运动库**：优先多轴旋转 + 非共面平移，显式避开单轴/纯平移退化；候选运动要落在 X_precert 内。
2. **安全价值估计**：对每个候选运动，用 Fisher 信息的一步更新预估 X_crit 上 ρ_calib 的下降（value of information），按 η 排序。
3. **风险受限执行**：标定轨迹本身跑低速 + 力矩/力限 + 软限位；任何守卫触发立即中止并保留已获信息。
4. **再标定调度**：当定义 42 的 θ_calib 超份额、或 CHR 报警、或 r* < 任务半径时触发；支持增量标定（只补退化方向）。

### 2.3 IP-59 CALIB-HEALTH-RUNTIME（标定健康运行时 CHR）
1. **闭环残差源**：标定板复检、双相机/深度-视觉互检、抓取成功残差、接触落点残差（可复用后续力矩轮）。
2. **漂移检测**：NIS + EWMA/CUSUM，输出 (是否漂移, 漂移量界, 置信)。
3. **单调膨胀与降级**：只增不减地更新 Σ_obs；按超阈程度依次执行「缩小 W_valid → 限速 → 仅近场任务 → SafeStop/Recalibrating」。
4. **审计日志**：每次证书签发/膨胀/降级都写不可篡改日志，供安全档案回溯。

## 2. 关键算法（伪代码）

### IP-57 CCS：标定证书合成
```
def synthesize_calib_cert(motion_pairs, noise_info, prior_box, grasp_tol, delta=0.01):
    # 1) 联合求解：Tsai-Lenz 初值 + 非线性最小二乘（X 与 FK 参数修正）
    X0 = tsai_lenz(motion_pairs)
    X, fk_patch = refine_ax_xb(X0, motion_pairs, noise_info)

    # 2) 观测矩阵与可观测性分解
    H = zeros(6, 6)
    for (A, B, W) in motion_pairs:
        J = Ad(X) @ (Ad(B) - I)
        H += J.T @ W @ J
    lam, V = eigh(H)
    rank = count(lam > lam_max * 1e-8)
    R_basis, N_basis = V[:, :rank], V[:, rank:]
    # 零空间方向的方差一律无效，交给 prior_box
    H_R = V[:, :rank].T @ H @ V[:, :rank]
    Sigma_obs = pinv(H_R)                    # 仅在 R 上
    chi2 = chi2_quantile(rank, 1 - delta)

    cert = CalibCert(mu=X, Sigma_obs=Sigma_obs, B_null=prior_box,
                     chi2=chi2, rank=rank, fk_patch=fk_patch,
                     prov=hash(motion_pairs, fk_version, hardware_sn))
    # 3) 可认证半径与有效域（保守闭式）
    s_w, s_v = max_rot_std(Sigma_obs), max_trans_std(Sigma_obs)
    b_w, b_v = box_widths(prior_box)
    cert.r_star = (grasp_tol - chi2*s_v - b_v) / (chi2*s_w + b_w)
    cert.W_valid = ball(X.t, cert.r_star)
    cert.tau_valid = thermal_validity(load_profile, vibration_profile)
    return cert
```
> 注意：`Sigma_obs` 只在可观测子空间上参与传播；零空间方向若被错误地赋小方差，`r*` 会被高估——这是必须在代码层显式禁止的失效模式（断言 rank 与 N_basis 一致）。

### IP-57 的安全传播（供 IP-49/ECR 调用）
```
def rho_calib(p_cam, cert):
    # 精确支持函数：椭球项 + 零空间先验盒项（保守相加）
    G = np.hstack([-skew(p_cam), np.eye(3)])      # R 在范数下抵消
    ell = cert.chi2 * sqrt(max(eigvalsh(G @ cert.Sigma_obs @ G.T)))
    box = support_box(G, cert.B_null)             # 盒在各方向的支撑
    return ell + box

def certified_margin(x, m_geom, cert):
    p = project_to_cam(x)                          # 感知点映射到相机系
    return m_geom - rho_calib(p, cert)             # 传给 CBF / CAR 守卫
```

### IP-58 SAC：安全价值驱动的主动标定
```
def safety_aware_active_calibration(cert0, task, budget, R_max):
    X_pre = conservative_envelope(cert0)   # 机械限位 + 上一张证书膨胀
    cert, M = cert0, []
    while budget > 0 and min_certified_margin(cert, task) < task.target:
        cand = propose_motions(X_pre, k=32)   # 多轴旋转 + 非共面平移
        best = None
        for m in cand:
            dV = expected_margin_gain(cert, m, task.X_crit)   # Fisher 一步更新
            risk = calibration_risk(m, X_pre)                 # 力/速/接近度
            eta = dV / (time(m) * risk + 1e-9)
            if risk <= R_max and (best is None or eta > best[0]):
                best = (eta, m)
        m_star = best[1]
        cert = update_certificate(cert, m_star)   # 增量并入新运动
        M.append(m_star)
        budget -= time(m_star)
    return M, cert

def propose_motions(X_pre, k):
    # 显式规避退化：旋转轴需张成 3D，运动不得全是纯平移/单轴
    cand = []
    while len(cand) < k:
        m = sample_safe_motion(X_pre)
        if axis_rank(cand + [m]) >= 2 and not is_pure_translation(m):
            cand.append(m)
    return cand
```

def calib_health_update(z_t, cert, state):
    S = predict_residual_cov(cert, state.t)
    d = z_t.T @ inv(S) @ z_t
    state.ewma = alpha * d + (1 - alpha) * state.ewma
    state.cusum = max(0, state.cusum + state.ewma - k_drift)
