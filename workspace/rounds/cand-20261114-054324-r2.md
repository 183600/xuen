# 第 72 轮（承接第 71 轮「GAUGE-RAS 计量审计层」IP-275~286；灵感循环第 2 轮；本轮灵感：「传感器标定」×「社会规范理解」）

> R71 把问题从「我的测量准不准」升到「我的尺子可信吗、量的时候有没有把被量的人改变」。但它对「标定」的建模仍是**静态且去社会化的**：`validity_interval` 是一个盖章的过期日，参考标准被默认为实验室标注集，信息源 ψ 只是单个个体的情绪。两个隐藏假设没被检验：
>
> 其一，**尺子的参考从未被审计**。R71 的不确定度 `u=√(u_sys²+u_stat²+u_model²)` 里**没有参考标准项**——仿佛拿来作基准的那把尺子是精确的。可传感器标定的第一课是：没有仪器能凭空标定，标定是一条**溯源链**，每一环自己也是仪器、自己也会漂移，链的终点往往不是「真理」，而是一个**约定**（SI 单位如今就是由固定常数定义的约定）。
>
> 其二，**行为的含义是规范相对的**。R71 把人的回答当作世界状态 s 的含噪读数。但同一句「可以」，可能是认同、可能是礼貌性顺从、可能是畏惧、可能是没听懂——取决于一个 R71 从未建模的**社会规范语境 N**。规范正是「从可观测行为到潜在意图」的那条**标定曲线**：它分人群、靠执行（而不只是信念）维持、并且会漂移。更麻烦的是，**多数人私下不认同、却因为别人都这么做而照做**（pluralistic ignorance），于是「大家都在做 X」被误读成「大家认可 X」，机器人反过来把一条没人真心支持的规范越推越牢。
>
> 于是本轮的核心位移是：**标定不是一个可以一次性获得的属性，而是一个对着『自身也在漂移、且由社会约定构成』的参考不断维护的过程。** 不再只问「我的尺子标定过吗」，而问「**对着哪个约定标定、对谁有效、现在过期了没有、以及我是不是正在把参考本身也改变**」。
>
> 命名 **CALIBRA-RAS**（Calibrated, Anchor-independent, Latent-Norm, Bootstrapped-reference, Recalibration-scheduled Autonomy for RAS）。一句话定位：R68 问「测量准吗」，R69 问「向谁求证」，R70 问「该信哪个状态」，R71 问「尺子可信吗、量是否改变了人」，R72 问「**这把尺子对着谁的约定、那条约定自身怎么漂、我为谁而标定——以及当没有『外面』可依时，我是否诚实地说出了自己的参考系**」。

## 0. 直觉与动机

**灵感 1（传感器标定 → 标定是链、漂移是默认、固定周期是错误抽象）**
直觉：家里的温湿度计用久了会偏，工厂的力传感器有蠕变，相机的内参随温度变。计量学的应对不是「假设它一直准」，而是：参考标准 + 溯源链 + 定期/在线重标 + 漂移模型 + 一旦超出容差就判废。R71 只学了「判废」这一半（过期就回退），却没学「漂移动力学」与「何时该重标」这一半。把 `validity_interval` 当成一个静态时间戳，等价于假设漂移是确定性的、且环境不变——一旦漂移速率本身有方差，固定周期就陷入两难：慢漂时浪费校准预算，快漂/突变时静默失效。正确抽象是**失效时距的危险率（hazard）**，重标定是一个**关于「校准」的价值决策**（CalVoI），和 R71 的 RVOI 同构。

**灵感 2（社会规范理解 → N 是隐变量，且「做」与「认同」被混淆）**
直觉：行为不直接暴露意图。一个社会里「大家都不插队」可能因为都认同（injunctive 强），也可能因为有人管（enforcement 强）；机器人从行为里读出的其实只是 `f(D,I,E)` 的混合，`I` 与 `E` 不可分辨。更隐蔽的是 pluralistic ignorance：**描述性规范 D 与指令性规范 I 系统性背离**，而公开行为跟着 D+E 走。若机器人的「安全/得体」参考来自观察到的行为，它就会把「被迫的从众」标定成「被认可的规范」，并用证书把它固化。规范理解研究给出的正确姿态是：**区分描述性/指令性/执行强度/歧义度四元组，并承认从纯行为不可识别，必须靠干预（私下询问、无执行场景、违规反应）来解混。**

**灵感 3（没有「外面」→ 共识 ≠ 效度，规范内不可自举）**
直觉：物理传感器至少可以最终溯源到 SI 约定；社会规范连这个「外部」都没有——**参考系本身由社群构成**。这带来一个漂亮的计量学结论：在一个社群内部，任何标定都只能消掉「差异」，消不掉「全体共享的偏差」。一个社群可以极其精确（大家读数一致）却整体错误（共享幻觉），而这个共享偏差**在该社群内部不可识别**（一种规范性的规范自由度 / gauge freedom）。所以「计量有效」永远只能是**相对于一个被声明出来的参考系**有效，不能冒充普适真理。要越出这个局限，只能引入**独立外部锚**，或**显式声明假设**——而声明是伦理与工程的双重要求。

**灵感 4（反作用升级 → 机器人会改变规范，锚定因此是政治行为）**
直觉：R71 的反作用是个体层面的 ψ 漂移（疲劳、压力、亲和）。R72 多一层：机器人反复示范、反复请求、反复「被允许」，会改变**规范本身**（normalization / 规范侵蚀或规范创业）。于是出现一条必须硬性禁止的捷径：**先让规范改变，再声称动作合规**（norm laundering）。安全必须在**当前规范**下评估，而不是在「我希望将来会变成的规范」下评估；改变规范的预算要单独记账，且绝不能用来给当下不安全的行为背书。

**灵感 5（严格包含 → 声明范围内必须退化为 GAUGE，声明范围外必须诚实拒答）**
直觉：若 N 已知固定、漂移为零、参考理想、迁移间隙为零，CALIBRA 必须逐指令等于 GAUGE，再退化为 BELIEF/FLUID/R68。这不是装饰，而是验收底线：新层只能在**被声明且被覆盖的规范域内**提供收益；一旦走出该域，系统必须**拒绝高风险管理动作**，而不是用「看起来也差不多」的迁移猜一个证书。**「在覆盖范围内更强、在覆盖范围外更诚实」**，是本轮全部收益的代价结构。

## 1. 形式化定义（增量：定义 349–366）

**定义 349（CALIBRA-RAS 总览）** CALIBRA-RAS = (DRIFT, REFPROV, NORMB, NORMID, XCAL, TRANSCAL, ANCHOR, CALVOI, NORM-EVID, NORMSHIFT, CAL-GATE, AIC-CAL, J_CAL, GAUGE-RAS†)。五不变式：
(i) **实时零学习写操作**（继承 R71 定义 331-i）：重标定是带审计的**校准状态转移**，不是在线梯度更新；
(ii) **参考必溯源**：任何进入决策的标定映射，其参考标准必须携带 (authority, community, scope, timestamp, u_ref, independence_cert)；缺一即不得用于 veto；
(iii) **不确定度全项披露**：u 必须含参考项 u_ref、漂移项 u_drift(t)、迁移项 u_transfer、规范项 u_norm，且逐项报告，不得合并隐藏；
(iv) **规范域显式**：所有安全/得体声明都写成条件式 `Risk ≤ ε | N ∈ D_N`，未覆盖即拒答；
(v) **禁止规范洗白**：动作安全性一律在**当前** N 下评估，规范改变预算 B_norm 不得用于为当下动作背书。

**定义 350（标定映射与漂移动力学）** 通道 c 的原始读数 z_c 经标定映射 q̂_c = g_c(z_c; θ_c(t)) 得到物理/语义量。标定参数按随机过程漂移，典型取 Ornstein–Uhlenbeck：
dθ_c = −κ_c(θ_c − θ_c*)dt + σ_c dW_c，
其中 θ_c* 为缓变真值、κ_c 回复速率、σ_c 漂移强度。假设 A106：在重标定之间 |θ_c(t) − θ_c(0)| ≤ b_c(t) 以高概率成立。**R71 隐含 σ_c=0（漂移确定或不存在）。**

**定义 351（标定残差、失效时距与危险率）** 残差 e_c(t) = g_c(z_c;θ_c(t)) − r_c，容差 τ_c。失效时距 T_c = inf{t : E|e_c(t)| > τ_c}；生存函数 S_c(t)=P(T_c>t)，危险率 λ_c(t) = −d/dt log S_c(t)。**R71 的 `validity_interval` 是 S_c 的 0/1 阶跃近似**；CALIBRA 用连续 S_c，并要求在线门控满足 S_c(t) ≥ 1−α。

**定义 352（参考记录 REFPROV）** 参考 R = (r, u_ref, authority, community, scope, timestamp, method, independence_cert)。u_ref 为参考自身的不确定度；authority 为参考的授权来源（法律/行业标准/专家共识/社群实践）；community 为其适用人群；scope 为适用条件。**核心约束：标定不可能把不确定度降到参考自身之下**——`u ≥ u_ref`。

**定义 353（参考层级与约定终点）** 参考构成有向链 R_1→R_2→…→R_m，每环有自身 u_ref。链可终止于：(a) 物理约定（SI 定义常数）；(b) **社会约定**（法律、伦理框架、社群实践）。终止于约定时，链的末端值不是「真理」而是「**被声明的参考系**」。定义 `Declared(R)` 为 R 的声明性；**未声明的约定终点 = 隐藏的规范假设**，必须显式化后才能进入证书。

**定义 354（规范语境 N）** N = (D, I, E, A) ∈ 𝒩：
- D（描述性）：群体实际行为的分布；
- I（指令性）：群体认可/反对的分布；
- E（执行强度）：违规被制裁的强度与概率；
- A（歧义度）：社群内部对 N 的分歧（用熵/HHI 度量）。
安全/得体可行集 `Safe_N(a|s)` 依赖 N；**同一动作在不同 N 下可以合规也可以违规**。

**定义 355（规范信念与规范条件似然）** 系统维护规范后验 b_t^N(N)。证据模型升级为
p(y | s, ψ, N) = Σ_k π_k(ψ,N)·p_k(y | s)，
并由 b_t^N 对所有高风险判断做边际化；更新来源为观测、先验、以及**显式询问/干预**（见定义 356）。R71 的 p(y|s,ψ) 是 N 固定且已知时的退化。

**定义 356（规范识别与混杂）** 公开遵从概率近似为 h(D, I, E)。从纯行为观测只能识别 h 的像，不能识别 (I,E) 的原像：映射 (D,I,E)↦h 的 Jacobian 秩亏。要解混 (I,E) 至少需要一种干预：私下信念询问、无执行强度场景、或对制裁的差异反应。**由「大家都在做」推「大家认可」在结构上不成立。**

**定义 357（规范相对有效性域与迁移间隙）** 有效性域升级为 D_N ⊆ 𝒮×𝒜×ℬ×𝒩。在 N 与 N′ 之间的迁移间隙定义为在共同状态上安全动作集与风险差的 sup：
ι_N(N,N′) = sup_{state} ( |Risk_N − Risk_{N′}| + d_H(Safe_N, Safe_{N′}) )。
有配对小样本时可学迁移算子 T_{N→N′}；无配对数据时**取最坏界**，不得默认 ι≈0。

**定义 358（扩展不确定度预算）** 
u² = u_sys² + u_stat² + u_model² + **u_ref² + u_drift²(t) + u_transfer² + u_norm²**。
其中 u_norm 由 b_t^N 的离散度与 A 诱导。R71 的定义 332 是后四项恒为零的特例。**任何一项被省略，都必须被当作攻击面，而不是被当作零。**

**定义 359（锚点独立性与自标定退化）** 参考/锚 A 对系统 M 是 ε-独立的，若在给定外部真值时 A 与 M 的内部状态条件互信息 ≤ ε（或因果图上不存在 A→M→…→A 的有向回路）。用 M 自己的输出作参考是**退化自标定**：g 收敛到恒等，u 虚假坍缩（calibration collapse）。审计手段：注入已知扰动、检验响应增益是否被伪标定吸收。

**定义 360（交叉标定与共模失效）** 多通道交叉标定可靠性受共模失败限制。设失败相关矩阵特征值为 {λ_i}，有效独立通道数 k_eff = (Σλ_i)²/Σλ_i² ≤ k；残差共模失败下界 ≥ ρ。故交叉标定的可靠度增益 ≤ √k_eff；ρ→1 时冗余无效。**R71 的「K 个偏差独立对偶」必须被认证为独立，而不能假设独立。**

**定义 361（标定价值 CalVoI 与重标定调度）** 重标定动作 ρ 的收益是决策损失期望下降，成本含校准成本 c_cal(ρ) 与**对人类/社群的干预成本** c_intervene(ρ)（重标定可能本身扰动 ψ 或 N）。
CalVoI(ρ) = E[L(u) − L(u′)] − c_cal(ρ) − c_intervene(ρ)。
当 max_ρ CalVoI(ρ) ≤ 0 时不重标，让校准按 S_c 自然过期并回退保守层。**R71 的「到了有效期就重标」是 CalVoI 在成本与时距都不确定时的粗糙近似。**

**定义 362（规范条件证据纪律：遵从 ≠ 认同）** 关于用户意图的证据必须区分**认同**（I 一致）与**顺从**（E 驱动）。高风险同意（如进入私人空间、执行不可逆动作）要求至少一个**对 E 不敏感**的通道：私下确认、延迟复核、可撤回选项、行为测试（opt-out test）。**不得仅由顺从推断同意；单源高置信仍是提示而非证明**（承接 R71 定义 343）。

**定义 363（规范反作用与规范漂移预算）** 规范随机器人行为演化：N_{t+1} = T_N(N_t, a_t, ρ_robot, visibility, repetition)。重复、可见、被默许的行为会移动 D，并可能移动 I 与 E。规范漂移预算 Σ_t ΔN_t ≤ B_norm；并强制：**安全判定使用 N_t（当前），绝不使用期望中的 N_{t+1}**。禁止「先改变规范再让动作合规」（norm laundering）。

**定义 364（校准门 CAL-GATE / IVG†）** 若任一成立：S_c(t) < 1−α（漂移过期）、u_ref > U_REF、state ∉ D_N、ι_N > τ_ι、A > τ_A（规范歧义过高）、锚点独立性审计失败、SEAL 失败、TCHAIN 断裂——则相关标定/指标判无效，禁用其在线优化，并把依赖它的高风险管理动作**降级为带声明范围的保守回退**（R71/R68）。语义仍是「**证书过期就停用尺子**」，而非「读数偏大就调小」。

**定义 365（威胁模型 AIC-CAL）** ℰ_CAL = ℰ_GAUGE × ℰ_cal × ℰ_norm：
ℰ_cal = {参考投毒 / 参考捕获 / 漂移诱导（改变环境加速失效）/ 锚点伪造 / 自标定坍缩 / 有效期操纵 / 交叉标定共模利用}；
ℰ_norm = {规范操纵、pluralistic-ignorance 利用、跨社群剥削（对 A 标定却服务 B）、把顺从当同意、规范洗白、参考社群被少数人俘获}。

**定义 366（证书 J_CAL 与严格包含）** 
J_CAL = (J_GAUGE, calib_chains, drift_bounds, ref_provenance, norm_belief, norm_scope, transfer_gaps, anchor_independence, calvoi_log, norm_shift_budget, calibra_ver)。
Valid ⇔ Valid(J_GAUGE) ∧ 所有标定 S_c≥1−α ∧ u_ref≤U_REF ∧ state∈D_N ∧ A≤τ_A ∧ 锚点独立 ∧ 无规范洗白 ∧ 规范预算未超。当 N 固定且已知、σ_c=0、u_ref=u_transfer=u_norm=0、锚点理想、XCAL 退化为 NCA 时，CALIBRA 逐指令等于 GAUGE-RAS；再按 R71 定理 20 退化为 BELIEF/FLUID/R68。

# IP-287 DRIFT：漂移动力学 + 危险率门控（在线只读）
class DriftTracker:
    def __init__(self, kappa, sigma, tau, alpha):
        self.kappa, self.sigma, self.tau, self.alpha = kappa, sigma, tau, alpha
    def survival(self, t, theta0):
        # OU 漂移下方差随时间饱和；用解析/查表给出 S_c(t)
        return ou_survival(t, self.kappa, self.sigma, self.tau)
    def expired(self, t):
        return self.survival(t, self.theta0) < 1 - self.alpha

# IP-288 REFPROV：参考溯源链与参考不确定度
def verify_reference(R):
    ok = (R.u_ref <= U_REF and R.authority and R.community
          and R.scope and R.timestamp and tchain.verify(R.trace))
    return ok, R.u_ref

# IP-289 NORMB：规范语境后验（D,I,E,A）
class NormBelief:
    def __init__(self, prior): self.b = prior          # b_t^N over N=(D,I,E,A)
    def update(self, y, s, psi, intervention=None):
        # 仅当存在干预时才允许解混 I 与 E（见 IP-290）
        lik = norm_conditioned_likelihood(y, s, psi, self.b, intervention)
        self.b = normalize(self.b * lik)
        return self.b
    def ambiguity(self): return entropy(self.b)

# IP-290 NORMID：规范识别（行为不可识别，需干预）
def identify_norm(obs, interventions):
    if not interventions:
        return None                                    # 只报 h(D,I,E)，不报 I
    return solve_mixed(h, obs, interventions)          # 私下询问/无执行场景/违规反应

# IP-291 XCAL：交叉标定 + 共模失效上限
def cross_calibrate(channels):
    Sigma = failure_correlation(channels)
    k_eff = participation_ratio(eigvals(Sigma))        # (Σλ)²/Σλ²
    rho   = max_off_diag(Sigma)
    gain  = sqrt(k_eff) * (1 - rho)                    # 共模折扣
    return calibrate(channels, gain), k_eff, rho

# IP-292 TRANSCAL：跨规范社群迁移（无配对则取最坏界）
def transfer_gap(b_N, b_Np, paired=None):
    if paired is None:
        return WorstCaseGap()                          # 不默认 ι≈0
    T = fit_transfer(paired); return certify(T, b_N, b_Np)

# IP-293 ANCHOR：锚点独立性审计（防自标定坍缩）
def audit_anchor(M, A, probe):
    # 注入已知扰动 probe，看 M 的响应是否被伪标定吸收
    resp = M.respond(probe)
    return mutual_information(A, M.internal, given=probe.external) <= EPS_IND \
           and not absorbed(resp, probe)

# IP-294 CALVOI：标定价值与重标定调度
def calvoi(state, u, budget):
    best = None
    for rho in recalibration_candidates(state):
        u2 = predict_uncertainty_after(rho, u)
        benefit = expected_loss(u) - expected_loss(u2)
        cost = c_cal(rho) + c_intervene(rho)           # 重标可能扰动 psi/N
        if best is None or benefit - cost > best.score:
            best = (rho, benefit - cost)
    return best if best and best.score > 0 else None   # 无利可图 -> 让其过期

# IP-295 NORM-EVID：规范条件证据纪律（遵从 vs 认同）
def accept_consent(y, psi, b_N, channels):
    if b_N.ambiguity() > TAU_A: return False, 'norm_ambiguous'
    e_insensitive = any(ch.E_sensitivity < BETA for ch in channels)
    endorsement = infer_endorsement(y, b_N)            # 不是 infer_compliance
    return (endorsement >= TAU_ENDORSE and e_insensitive
            and cross_channel_consistent(channels)), 'ok'

# IP-296 NORMSHIFT：规范反作用（禁止洗白）
def norm_step(N, a, rho_robot, budget, safety):
    N2 = T_N(N, a, rho_robot)
    shift = norm_distance(N, N2)
    # 安全必须在当前 N 下评估，不能用 N2
    if not safety.valid_under(N) or budget.spent + shift > budget.B:
        return N, 0.0, 'forbidden_norm_laundering'
    return N2, shift, 'ok'

# IP-297 CAL-GATE：校准门（过期/参考大/越域/迁移大/歧义/锚点失败 -> 回退）
def cal_gate(state, b_N, refs, drift, anchors, seal):
    bad = []
    for c in drift:
        if c.expired(now()): bad.append(('drift', c.id))
    for R in refs:
        ok, u_ref = verify_reference(R)
        if not ok: bad.append(('ref', R.id))
    if state not in D_N(b_N): bad.append(('domain', None))
    if transfer_gap_exceeds(b_N): bad.append(('transfer', None))
    if b_N.ambiguity() > TAU_A: bad.append(('ambiguity', None))
    if not anchors.all_independent(): bad.append(('anchor', None))
    if seal.failed: bad.append(('seal', seal.failed))
    return Gate(valid=not bad, reason=bad, fallback='GAUGE→R68',
                scope=b_N.declared_scope())

# IP-298 CALIBRA 主闭环：控制 / 计量 / 标定-规范 三环，标定环永不阻塞控制环

              M.gauge.lam_floor(U + M.cal_u.extra()))  # u_ref/u_drift/u_transfer/u_norm
    A = M.gauge.ach.propose(...); k = M.gauge.certified_prefix(A, ...)
    M.mib.update(b_t, M.bN, g_gauge, g_cal)
    M.vqa.submit_async(b_t, g, M.bN, g_cal)
    return k, lam, U, J_CAL(M)

## 3. 推导

**引理 28（共识 ≠ 效度：社群内不可自举）** 设目标 φ 在某社群 C 内的共识参考为 r_C = E_{π_C}[φ] + δ_C，δ_C 为共享规范偏差。社群内所有仪器与参考都是 C 约定的函数，故测量在规范变换 φ ↦ φ + δ（对所有读数与参考同时加同一常数）下不变；任何内部数据似然只依赖差值。于是：Fisher 信息对 δ_C 为零，δ_C 不可从社群内部任何测量识别。系：(i) 标定只能压方差、压不掉共享偏差；(ii) 社群可**极端精确且系统性错误**（共享幻觉）；(iii) 越出宿命只能靠**外部独立锚**或**显式声明假设**。这正是 R71 的盲点：它审计了「尺子」，却没审计「尺子所对的那条约定」。——**规范性 gauge 自由度。**

**引理 29（漂移危险率与固定周期二难）** 在假设 A106（有界/OU 漂移）下 S_c(t) 单调不增。固定周期 T 的期望损失 = 慢漂时的过度校准浪费 + 快漂/突变时的欠校准风险；当漂移速率方差 σ_c²>0 时，按危险率 λ_c(t) 的自适应到期在期望损失上占优。系：**R71 的 `validity_interval` 是 σ_c=0 的零方差特例**，它把一个随机失效问题偷偷换成了确定性时间问题。

**引理 30（冗余的共模上限）** k 个通道失败概率 p、等相关系数 ρ，则有效独立数 k_eff=(Σλ)²/Σλ² ≤ k，残余共模失败 ≥ ρ；交叉标定可靠度增益 ≤ √k_eff。ρ→1 时冗余完全失效。系：**「两个独立对偶」必须被认证为独立；R71 未认证，只是假设。**

**引理 31（规范识别的混杂）** 遵从概率 h(D,I,E) 对 I 与 E 都单调，则从公开遵从分布无法唯一分解 (I,E)（Jacobian 秩亏）；至少一种干预才能识别。系：**由「人人如此」推「人人认可」在结构上无效**；机器人会据此把被强制执行的规范误标为被认可的规范，并在定义 363 的反作用里把它越推越牢（pluralistic ignorance 陷阱）。

**引理 32（迁移间隙的风险放大）** 若在 N_0 上标定的风险为 ε，迁移到 N 的间隙为 ι_N，则 N 上期望风险 ≥ ε + ι_N·(决策敏感度)；无重叠假设时最坏间隙可无界。系：**未声明规范范围的证书是一个假的全称命题**；正确写法只能是 `Risk ≤ ε | N ∈ D_N`。这把「安全」从绝对量变成**条件量**。

**引理 33（CalVoI 的最优调度存在且有限）** 重标定收益随频率边际递减（u_drift 有界、参考不确定度不可消除），成本非负，则 CalVoI 随频率单调不增，存在有限最优频率；若 c_cal + c_intervene 超过最大收益，最优是**不重标**、任其过期并回退。**与 R71 引理 25 的最优停止同构：该停就停，而不是「到点就标」。**

**定理 23（严格包含链）** 在 N 固定且已知、σ_c=0、u_ref=u_transfer=u_norm=0、锚点理想、XCAL 退化为 NCA 的条件下，CALIBRA 逐指令等于 GAUGE-RAS；而 GAUGE ⊃ BELIEF ⊃ FLUID ⊃ R68（R71 定理 20）。故**在声明范围内**安全侧不弱于 R71，效率侧只在「校准有效且规范覆盖」时获得收益。

**定理 24（条件风险界，而非无界安全）** 若 J_CAL 有效，则在声明规范域 N∈D_N 内，风险 ≤ ε_cert（R71 定理 21） + u_ref + u_drift(t) + u_transfer；在 D_N 之外，CALIBRA 拒绝高风险动作并回退保守层，其风险界由 R71/R68 **在其各自声明的假设下**保证——**但那些假设未必覆盖眼前这个社群**。因此本定理诚实地说：**不存在无条件的风险界；存在的是「带范围与失效模式说明的条件界」。**

**定理 25（禁止规范洗白与无发散）** 由不变式 (v) 与定义 363，动作安全性只在当前 N_t 下评估，规范漂移预算有界，重标定只改变 θ 不改变安全包络，回退时 λ 单调不降。故不存在一段交互序列，能通过「让规范漂移」或「让校准漂移」使原本不安全的动作被认证为安全（在 T_N 与漂移模型正确的范围内）。**但不保证 T_N 与 N 模型正确——这正是本轮风险所在。**

## 6. 本轮最大风险

**一句话**：CALIBRA-RAS 把安全的最后一块地基从「尺子可信」挪到「尺子所对的参考系与规范域可信」——但参考系由社群约定构成、且社群内部的**共享偏差不可自识别**，于是系统可能**精确地、带着完整证书地错**：它校准得非常一致，只是对错了人；证书越干净，恰恰越说明那个能揭穿它的误差项（u_ref / u_norm）被它自己省略了。

**次级风险与缓解**：
1. **规范相对主义坍缩（对错社群标定）** → 强制 `Risk ≤ ε | N∈D_N` 的条件式声明 + 覆盖审计 + 越域拒答（定义 349-iv、357、定理 24）；不得宣称普适。
2. **共识当真理 / 共享幻觉** → 外部独立锚优先 + 无锚时**如实标注不可识别**（引理 28、E344），绝不伪造效度。
3. **规范识别混杂（顺从当同意）** → 强制 E-不敏感通道 + 私下/延迟/可撤回确认（定义 356、362；E345/E346）。
4. **参考被投毒/捕获** → REFPROV 溯源 + SEAL + 锚点独立性审计 + 多源交叉（定义 352/359/360；E348/E352）。
5. **漂移与迁移被低估** → 危险率门控 + 无配对取最坏界 + CalVoI 调度（定义 350/357/361；E341/E342/E347）。
6. **规范洗白（先改规范再合规）** → 不变式 (v) + 规范漂移预算 + 只在当前 N 下判定（定义 363、定理 25；E351/E359）。
7. **系统过度复杂/难以审计** → |I|≤32、参考与规范各一条可复算链、复杂度本身纳入审计（承接 R71 风险 6）。

# 第 72 轮产物 · 创新点清单 v2：CALIBRA-RAS（Calibrated, Anchor-independent, Latent-Norm, Bootstrapped-reference, Recalibration-scheduled Autonomy for RAS：标定感知 × 独立锚 × 隐规范 × 重标定调度；DRIFT×REFPROV×NORMB×NORMID×XCAL×TRANSCAL×ANCHOR×CALVOI×NORM-EVID×NORMSHIFT×CAL-GATE×AIC-CAL×J_CAL×GAUGE-RAS†）

## 2. 形式化定义（要点版）

**定义 349（总览与五不变式）** CALIBRA 继承 GAUGE 全部组件（† 升级），新增标定层（DRIFT/REFPROV/XCAL/TRANSCAL/ANCHOR/CALVOI）与规范层（NORMB/NORMID/NORM-EVID/NORMSHIFT）。五不变式：(i) 实时零学习写操作；(ii) 参考必溯源；(iii) 不确定度全项披露；(iv) 规范域显式（条件式声明）；(v) 禁止规范洗白。

**定义 350（漂移）** q̂_c=g_c(z_c;θ_c(t))；θ_c 按 OU 漂移，A106 给出重标之间 |θ_c−θ_c0|≤b_c(t)。R71 隐含 σ_c=0。

**定义 351（失效时距/危险率）** e_c=g_c−r_c；T_c=inf{t:E|e_c|>τ_c}；S_c(t)=P(T_c>t)，λ_c=−d/dt log S_c。门控要求 S_c(t)≥1−α。**R71 的 validity_interval 是 S_c 的 0/1 阶跃近似。**

**定义 352（参考记录）** R=(r,u_ref,authority,community,scope,timestamp,method,independence)。硬约束 `u ≥ u_ref`：标定不可能优于参考。

**定义 353（参考层级/约定终点）** 参考链终止于物理约定或**社会约定**；终止于约定时链尾是「被声明的参考系」而非真理。**未声明的约定终点 = 隐藏的规范假设。**

**定义 354（规范语境）** N=(D,I,E,A)：实际行为 / 认可态度 / 执行强度 / 歧义度。`Safe_N(a|s)` 随 N 变化；同一动作可合规也可违规。

**定义 355（规范信念/似然）** b_t^N(N)；p(y|s,ψ,N)=Σ_k π_k(ψ,N)p_k(y|s)；高风险判断对 b_t^N 边际化。R71 的 p(y|s,ψ) 是 N 固定特例。

**定义 356（规范识别）** 公开遵从 h(D,I,E) 对 I,E 都单调 ⇒ Jacobian 秩亏，纯行为不可识别原像；须干预解混。**「人人如此」≠「人人认可」。**

**定义 357（规范相对域/迁移间隙）** D_N⊆𝒮×𝒜×ℬ×𝒩；ι_N(N,N′)=sup_state(|ΔRisk|+d_H(Safe_N,Safe_N′))；无配对取最坏界。

**定义 358（扩展预算）** u² 上式七项；逐项报告。R71 是后四项为零的特例。**省略任一项即攻击面。**

**定义 359（锚点独立性）** A 与 M 在给定外部真值时条件互信息 ≤ε（或因果无回路）。自标定 → g→恒等、u 虚假坍缩（calibration collapse），须注入扰动审计。

**定义 360（交叉标定/共模）** 失败相关矩阵特征值 {λ_i}；k_eff=(Σλ)²/Σλ²≤k；残余共模失败 ≥ρ；增益 ≤√k_eff。**冗余必须被认证为独立。**

**定义 361（CalVoI）** CalVoI(ρ)=E[L(u)−L(u′)]−c_cal(ρ)−c_intervene(ρ)。max≤0 则不重标、任其过期回退。**「到点就标」只是粗糙近似。**

**定义 362（规范条件证据纪律）** 区分认同（I）与顺从（E）；高风险同意需至少一个 E-不敏感通道（私下确认/延迟复核/可撤回/行为测试）；不得仅由顺从推断同意；单源不定案。

**定义 363（规范反作用）** N_{t+1}=T_N(N_t,a,ρ_robot,visibility,repetition)；ΣΔN≤B_norm；安全只在**当前** N 下判定；禁止「先改规范再合规」。

**定义 364（CAL-GATE）** S_c<1−α、u_ref>U_REF、state∉D_N、ι_N>τ_ι、A>τ_A、锚点失败、SEAL 失败、TCHAIN 断裂任一成立 ⇒ 判无效、禁用在线优化、带声明范围保守回退。**证书过期就停用尺子，而非把读数调小。**

**定义 365（AIC-CAL）** ℰ_CAL=ℰ_GAUGE×ℰ_cal×ℰ_norm。ℰ_cal={参考投毒/捕获、漂移诱导、锚点伪造、自标定坍缩、有效期操纵、共模利用}；ℰ_norm={规范操纵、pluralistic-ignorance 利用、跨社群剥削、顺从当同意、规范洗白、参考社群俘获}。

**定义 366（J_CAL/严格包含）** Valid ⇔ Valid(J_GAUGE) ∧ S_c≥1−α ∧ u_ref≤U_REF ∧ state∈D_N ∧ A≤τ_A ∧ 锚点独立 ∧ 无规范洗白 ∧ 规范预算未超。N 固定已知、σ=0、u_ref=u_transfer=u_norm=0、锚点理想、XCAL=NCA 时逐指令等于 GAUGE，再退化 BELIEF/FLUID/R68。

def cal_gate(state, b_N, refs, drift, anchors, seal):
    bad = []
    bad += [('drift', c.id) for c in drift if c.expired(now())]
    bad += [('ref', R.id) for R in refs if not verify_reference(R)[0]]
    if state not in D_N(b_N): bad.append(('domain', None))

    if not anchors.all_independent(): bad.append(('anchor', None))
    if seal.failed: bad.append(('seal', seal.failed))
    return Gate(valid=not bad, reason=bad, fallback='GAUGE→R68',

## 4. 推导

**引理 28（共识≠效度/社群内不可自举）** 参考 r_C=E_{π_C}[φ]+δ_C；内部测量在 φ↦φ+δ 下不变，对 δ_C 的 Fisher 信息为零 ⇒ 标定只压方差、不消共享偏差；社群可**精确且系统性错误**；越界须外部独立锚或显式声明。——**规范性 gauge 自由度。**

**引理 29（漂移危险率与固定周期二难）** S_c(t) 单调不增；σ_c²>0 时危险率自适应到期优于固定周期。**R71 的 validity_interval 是 σ_c=0 特例。**

**引理 30（冗余共模上限）** k_eff=(Σλ)²/Σλ²≤k，残余共模 ≥ρ，冗余增益 ≤√k_eff；ρ→1 时无效。**「独立对偶」须认证。**

**引理 31（规范识别混杂）** h(D,I,E) 对 I,E 单调 ⇒ 秩亏，(I,E) 不可由公开遵从唯一分解；须干预。**「人人如此」≠「人人认可」。**

**引理 32（迁移间隙放大风险）** N 上风险 ≥ ε+ι_N·(敏感度)；无重叠时最坏间隙可无界。**未声明范围的证书是假全称命题；正确写法 `Risk≤ε | N∈D_N`。**

**引理 33（CalVoI 最优调度）** 收益随频率边际递减、成本非负 ⇒ CalVoI 单调不增，存在有限最优频率；若成本超收益则最优为不重标、任其过期。**与 R71 引理 25 同构：该停就停。**

**定理 23（严格包含）** N 固定已知、σ=0、u_ref=u_transfer=u_norm=0、锚点理想、XCAL=NCA ⇒ 逐指令等于 GAUGE；GAUGE⊃BELIEF⊃FLUID⊃R68。

**定理 24（条件风险界）** J_CAL 有效 ⇒ 在 N∈D_N 内风险 ≤ ε_cert+u_ref+u_drift(t)+u_transfer；在 D_N 外拒绝高风险并回退，其界由 R71/R68 在各自假设下给出——**但未必覆盖眼前社群**。故**不存在无条件风险界，只存在带范围与失效模式说明的条件界。**

**定理 25（禁止规范洗白、无发散）** 安全只在当前 N_t 下判定，规范漂移预算有界，重标定只改 θ 不改安全包络，回退 λ 单调不降 ⇒ 不存在交互序列靠「规范/校准漂移」把不安全动作认证为安全（在 T_N 与漂移模型正确范围内）。**不保证 T_N 与 N 模型正确。**

## 7. 本轮最大风险

**一句话**：CALIBRA-RAS 把安全的最后地基从「尺子可信」挪到「尺子所对的参考系与规范域可信」——但参考系由社群约定构成、社群内部的**共享偏差不可自识别**，于是系统可能**精确地、带着完整证书地错**：它校准得极其一致，只是对错了人；而证书越干净，恰恰越说明那个能揭穿它的误差项（u_ref / u_norm）被它自己省略了。

次级风险与缓解：
1. **规范相对主义坍缩（对错社群标定）** → 强制条件式声明 `Risk≤ε|N∈D_N` + 覆盖审计 + 越域拒答（定义 349-iv/357、定理 24）。
2. **共识当真理/共享幻觉** → 外部独立锚优先；无锚时如实标注不可识别（引理 28、E344），绝不伪造效度。
3. **规范识别混杂（顺从当同意）** → 强制 E-不敏感通道 + 私下/延迟/可撤回确认（定义 356/362；E345/E346）。
4. **参考被投毒/捕获** → REFPROV + SEAL + 锚点独立性 + 多源交叉（定义 352/359/360；E348/E352）。
5. **漂移与迁移被低估** → 危险率门控 + 无配对取最坏界 + CalVoI 调度（定义 350/357/361；E341/E342/E347）。
6. **规范洗白（先改规范再合规）** → 不变式 (v) + 规范漂移预算 + 只在当前 N 下判定（定义 363、定理 25；E351/E359）。
7. **系统过度复杂/难审计** → |I|≤32、参考与规范各一条可复算链、复杂度本身纳入审计（承接 R71 风险 6）。
