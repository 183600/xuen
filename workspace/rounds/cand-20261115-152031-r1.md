# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环第 1 轮（研究主线第 70 轮）；本轮灵感：「价值对齐」×「成本控制」）

> R69 把不确定性一分为二（aleatoric / epistemic），并给 epistemic 配了一套「看—问—触」的主动交互机制。但它只问了「**世界是什么样**」，从没问「**世界该是什么样**」。这留下一个更致命的缺口：系统可以**对世界完全确定、却对价值完全无知或完全错误**——它清楚后果仍做错事；或者它用一句诱导性提问拿到自己想要的答案，再把这件事盖上「已验证」的章。R69 的交互机制一旦平移到价值上，就不再是中性的探询，而是**操纵**。更现实的是：R69 的每一次「问」都要花钱（人的注意力、时间、信任），而 R69 只把成本写成一个标量 `c(g)` 塞进 `argmax[VoI−c]`，既没有预算、也没有价格、更没有「谁付钱」。
>
> 本轮两个灵感因此不是并列的两块砖，而是一对**对偶**：
> - **价值对齐**要求把不确定性再拆出第三类 **U_val（axiological）**，并且必须分三层：`v_hard`（永不投票、永不定价、字典序优先）、`v_soft`（可询问、可权衡）、`v_unknown`（只能靠预防裕度）。硬约束一旦被写成可交易的惩罚项，足够大的任务收益就总能把它买走。
> - **成本控制**要求所有交互（事实询问 + 偏好询问 + 验证 + 延迟）共用一个**硬预算账本**，用影子价格 ν 做「单位成本边际价值」分配；并暴露一个新攻击面：**预算耗尽攻击**（用廉价高耗查询把预算烧光，使关键状态无钱可问）。
>
> 核心命题：**把「不确定性」拆成 aleatoric / epistemic / axiological 三通道；前两者沿用 R68–R69，第三者交给「分层价值状态 + 非诱导偏好询问 + 延迟/交付」；三类交互共用一个硬预算，用影子价格三元组 (λ, μ, ν) 统一裁决；只有当「单位成本的对齐增益」为正时才对价值花钱，否则退回 R69/R68。** 命名 **PRICE-RAS**（Preference-grounded, Risk-aware, Interactive, Cost-controlled, Epistemic-axiological risk-adaptive system）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我该按谁的价值行事，而这份对齐我付得起吗**」——对齐不是一句口号，而是一条有价格的约束；成本控制也不是抠门，而是对齐能否真实发生的先决条件。
>
> 理论姿态延续 R69：**PRICE ⊇ FLUID ⊇ CALM 必须是严格退化，而不是并列替代**。安全侧不许让步，效率与对齐侧只在「付得起且可验证」的预算内获益。

## 0. 直觉与动机

**灵感 1（价值对齐 → 第三种不确定性，且它不是「世界」的不确定性）**
直觉：R69 的 `U_epi` 是「我不知道世界是哪一个」；价值对齐问的是「我不知道你希望世界成为哪一个」。这两件事在信息结构上根本不同：**看、触、探针**再多次，也问不出「你更看重隐私还是便利」。所以 `MINT` 把预算花在 `U_val` 上是纯浪费（引理 20 给出正交性条件）。更关键的是价值本身不是一个标量：有些是**硬约束**（不伤害、不欺骗、不越权），有些是**软偏好**（快一点还是稳一点），还有些是**我们根本没想到的约束**（`v_unknown`）。把三类混成一个「对齐损失」再配权重，等于把权利标了价——只要任务收益足够大，任何硬约束都能被「买断」。

**灵感 2（成本控制 → 对齐是有预算约束的序贯决策，不是无上限的求证）**
直觉：R69 的 `argmax[VoI−c]` 隐含「预算无限、成本可加」。真实系统里预算是**有限且共享**的：问一句人类、做一次昂贵验证、延迟一次决策，都在同一个池子里取钱。于是正确的裁决不是「VoI 是否大于成本」，而是「**这笔钱是不是当前边际上最值的一笔**」——这正是影子价格 ν（预算的对偶变量）在做的事。更进一步，有限预算带来一个 R69 没见过的攻击：对手用一堆廉价但高耗的查询把预算提前烧光（denial-of-alignment），等真正高风险的两难出现时，系统已经「问不起」了。

**灵感 3（对偶 → 不可负担的对齐不是对齐；而只算成本只是高效地做错事）**
直觉：一套对齐机制如果贵到部署时必须关掉，那它在工程上等于不存在；反过来，一个只压成本、不守价值的系统只是把错误做得更便宜。所以两者不是两个目标相加，而是一条**约束与预算的对偶**：价值决定「什么不能交易」，成本决定「什么可以交易、交易多少」。由此得到一个可检验、甚至有点反直觉的结论：**对齐成本曲线是非单调的**——问得太少欠对齐，问得太多则被策略性回答、交互疲劳与验证债反噬（定义 319、引理 21）。存在内点最优 B*，而「多问总比少问好」是错的。

**灵感 4（可验证性 → 便宜的对齐代理会诱导对齐剧场）**
直觉：对齐很难直接测，于是工程上一定用**廉价代理**：问卷得分、LLM 裁判、便宜的分类器、满意度按钮。一旦预算压力存在，优化器会优先满足**便宜且可测**的代理，而不是真正的价值——这是 Goodhart 的成本版。解法不是「不用代理」，而是**两层验证经济**：便宜的代理高频用，昂贵的真值低频审计，且审计率必须与代理偏差挂钩（引理 22），否则证书上漂亮的对齐数字只是自欺。

**灵感 5（不可定价性 → 硬约束必须是约束，不能是罚项）**
直觉：罚函数法把「违反硬约束」变成「付出 μ 的代价」，于是任何有限 μ 都能被更大的任务收益击穿。价值对齐的正确姿态是**字典序 + 鲁棒可行**：先在 `𝒱_credible` 上对所有 `v_hard` 做可行性投影，再在可行集内谈软偏好。价格披露里 μ 对硬约束取 ∞，明确告诉审计者「这一项不卖」。

**灵感 6（嵌套退化 → R69/R68 都是「价值已知且预算无限」的边界）**
直觉：当 `v_soft` 已知、只剩 `v_hard`、且预算 B→∞（ν→0）时，PRICE 不该有任何额外动作，应逐指令退化为 FLUID；再关掉交互则退化为 CALM。这条退化链保证每加一层不会新增一个需要独立信任的黑箱——新层只在「价值不确定且付得起」时介入。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PRICE-RAS 总览与四不变式）** PRICE-RAS = (VAD, VSR, PEQ, CaVoI, CLB, SPD, CVP, DEF, TVE, SRC, J_PRICE, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **单一预算账本**：任务、信息、价值询问、验证、延迟五类成本共用硬预算 B，任何交互必须先记账后执行，且永不透支；
(iii) **价值分层不可投票**：`v_hard` 永不进入询问、永不进入效用交换，只做鲁棒可行性投影；`v_soft` 可询问、可权衡；`v_unknown` 只做预防裕度；
(iv) **询问纪律**：继承 R69 的 k 源一致，并新增「非诱导」与「陈述-显示一致性」两个条件；单次偏好回答不得覆盖任何硬约束。

**定义 311（价值状态与三层分解）** 价值状态 v = (v_hard, v_soft, v_unknown)：
- `v_hard ∈ 𝒱_hard`：不可违反约束集（不伤害、不欺骗、不越权、法规），对任意可行策略取字典序最高优先级；
- `v_soft ∈ 𝒱_soft`：偏好参数（权重、风险厌恶、隐私-效用交换率、时间折扣），带后验 p(v_soft | D_t)；
- `v_unknown`：未枚举的可能约束，不可被询问（不知道该问什么），只能由预防裕度 δ_unk 覆盖。
可信集 `𝒱_credible`：后验质量 ≥ 1−α 的最小价值集合。价值不确定性 `U_val = diam_regret(𝒱_credible) + δ_unk`，其中 `diam_regret` 为集合内两两策略的最大归一化后悔差。

**定义 312（三通道不确定性）** 不确定性三元组 U = (U_ale, U_epi, U_val)，分别路由到：风险缩放 λ（R68）、事实交互（R69）、偏好询问/延迟（本轮）。正交性假设 **A99**：给定观测 o 与动作 a，世界状态与价值状态条件独立（`W ⊥ V | o, a`）。A99 是「看世界不能减少价值不确定性」的形式化前提。

**定义 313（成本账本与预算）** 成本向量 c = (c_task, c_info, c_val, c_verify, c_def)（时间、能量、金钱、人类注意力、信任）。时域预算 B 为多维硬上限；剩余预算 R_t = B − Σ_{τ≤t} c_τ。**预留预算** R_res 为高风险状态的价值询问/延迟备用金，只能由 CVP 在关键状态释放（定义 321）。

**定义 314（价值询问算子 PEQ）** `g_val ∈ 𝒜_val` 包含：成对比较（A vs B）、标量打分、约束确认（「这算不算越界」）、示例演示、以及**弃权/交付**。硬约束：非诱导（不得透露系统偏好的动作或期望答案）、最小信息（只问对当前决策有判别力的问题）、可拒绝（允许「你来定」并自动转入 DEF）。价值问句由冻结 LLM 生成，梯度不回传（继承 R69 定义 295）。

**定义 315（CaVoI 成本感知信息价值）** 信息动作 g 的增益 Δ(g) = `E_{y|g}[min_a E_v L(a,v|o,y)] − min_a E_v L(a,v|o)`，其中 L 为「任务损失 + 软价值后悔」的联合损失。成本感知价值 `CaVoI(g) = Δ(g) − ν·c(g)`。选择 `g* = argmax_g CaVoI(g)`，s.t. 安全认证与预算未越界；若 `max CaVoI ≤ 0` 则不交互、走 R69/R68 兜底。事实询问与偏好询问共用此一裁决器，只是 L 的项不同。

**定义 316（影子价格三元组 SPD）** 约束决策的拉格朗日形式：
`max_π E[U_task] − λ(Risk−ε) − μ(R_val−ρ) − ν(Cost−B)`，
其中 λ 为风险约束影子价格，μ 为**软**价值约束（如期望后悔 ≤ ρ、公平违规 ≤ η）影子价格，ν 为预算影子价格。**硬约束不参与定价**（μ=∞，由字典序投影先处理）。由 KKT 得单位成本边际对齐增益 = ν，边际风险-价值替代率 = λ/μ。发布**价格披露** `(λ, μ, ν, MRS)` 供审计。

**定义 317（约束价值策略 CVP）** 字典序 + 鲁棒：
1) **硬可行**：`∀v_hard ∈ 𝒱_hard_credible`，`Viol(a; v_hard) = 0`，对 `v_unknown` 留裕度 δ_unk；
2) 在可行集内最大化 `E_{v_soft}[U_task + U_val]`；
3) 若 U_val 高且预算内无法消解，或询问被投毒/不一致 → 选可逆动作或 DEF；
4) 输出对真实 v 的**后悔上界** `Reg_T ≤ O(√(T·dim(𝒱_soft)·log T))`（Bayesian regret，见引理 24）。

**定义 318（延迟/交付动作 DEF）** `d ∈ 𝒜_def`：暂停、选择最小后悔的可逆动作、或请求人类接管。DEF 有成本 c_def 与时延风险，但其存在保证「价值不确定」不会被硬塞成一个自信的错误动作。DEF 是**一等动作**，可被策略生成，也必须过 C-RAS-WM 认证（不得靠「等着」把风险窗口拖爆）。

**定义 319（对齐成本曲线与内点最优）** 真实对齐度 A(B) 作为对齐预算 B 的函数。在「信息增益递减 + 操纵/疲劳/验证债成本递增」下，A(B) 单峰；B < B* 欠询问（对齐不足），B > B* 过询问（对齐反降）。B* 由 `∂A/∂B = ν` 隐式给出。

**定义 320（两层验证经济 TVE）** 廉价代理 `f̂`（高频、偏差 b）与昂贵真值 `f`（低频审计、审计率 s）；用重要性加权/双稳健估计得到近似无偏的对齐估计。为保证代理钻空子上界 ≤ τ，要求 `s ≥ 1 − τ/b`（引理 22）。审计由 bandit/校准误差触发，而非均匀撒钱。

**定义 321（预算耗尽攻击 DoA 与预留策略）** 对手以低价值高消耗的查询/验证把 R_t 提前烧光，使关键状态 `R_t < B_crit`。对策：预留 R_res、按**状态价值**而非先到先得分配预算、对异常消耗率做检测；预留策略的可证性见引理 23。

**定义 322（陈述-显示一致性 SRC）** 比较陈述偏好（询问所得）与显示偏好（历史行为/选择），不一致度 κ。κ 高 ⇒ 询问降权、触发复核；任何单源陈述不得覆盖硬约束。SRC 是对策略性误报与「社会赞许性回答」的低成本交叉检验。

**定义 323（非诱导询问生成 NLQ）** 问句约束：不泄露系统期望动作、不含价值判断词、选项对称、允许弃权；用诱导性评分器与人类研究审计。生成模型冻结，安全过滤在解码侧。

**定义 324（AIC-ALIGN 干扰集）** `ℰ_ALIGN = ℰ_FLUID × ℰ_pref × ℰ_budget × ℰ_proxy`，其中 ℰ_pref（偏好投毒 / 策略性误报 / 价值漂移）、ℰ_budget（预算耗尽 / 哄抬价格）、ℰ_proxy（代理钻空子 / 审计规避）。并入 AIC。

**定义 325（证书 J_PRICE）** `J_PRICE = (J_FLUID, U_val_before/after, 𝒱_credible 覆盖率, (λ,μ,ν), budget_ledger_hash, reg_ret_bound, audit_rate, defer_count, price_MRS, price_ver)`。Valid ⇔ `Valid(J_FLUID) ∧ 硬约束零违反 ∧ 预算不越界 ∧ 审计率达标 ∧ 询问非诱导 ∧ SRC 未越界`。

**定义 326（快安全环 / 慢经济环）** 双时间尺度：λ 每 tick 更新（快环，控制连续性）；ν、μ 在慢时间尺度（约 10–50Hz 或事件触发）由小凸问题求解并**冻结缓存**；两次更新之间价格不变，保证控制指令连续、无价格抖动诱发的突变。

# IP-264 VAD-3：三通道不确定性分解（复用 R69 AUD，新增价值通道）
def decompose3(samples, o_t, value_head):
    U_ale, U_epi, modes = aud.decompose(samples)          # R69
    post_v = value_head.posterior(o_t)                     # p(v_soft|D)
    cred   = credible_set(post_v, alpha=0.05)             # 𝒱_credible
    U_val  = regret_diameter(cred) + value_head.unknown_margin()
    return (U_ale, U_epi, U_val), modes, post_v, cred

# IP-269 SPD：影子价格（慢环，小凸问题；两次更新间冻结）
def shadow_prices(state, budget, cred):
    # 目标：E[U_task] − λ(Risk−ε) − μ(Regret−ρ)，s.t. Cost ≤ B
    lam, mu, nu = solve_small_dual(
        risk_constraint=EPS_RISK,
        soft_value_constraint=RHO_REGRET,
        budget=budget.remaining,
    )
    return PriceTriple(lam, mu, nu)                        # 硬约束不参与定价

# IP-267 CaVoI：事实询问与偏好询问共用一个裁决器
def choose_action(modes, post_v, o_t, prices, budget):
    cands = info_candidates(modes) + value_candidates(post_v, cred)
    best = None
    for g in cands:
        if not budget.allow(g) or not c_ras_wm.certify(g, o_t): continue
        gain = expected_loss_reduction(g, modes, post_v, o_t)
        score = gain - prices.nu * cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-270 CVP：先硬可行投影，再软价值排序；不可解则 DEF
def constrained_value_policy(modes, post_v, cred, lam):
    feasible = [m for m in modes
                if all(violation(m.a, v) == 0 for v in cred.hard)
                and violation(m.a, UNKNOWN) <= DELTA_UNK]
    if not feasible:
        return DEFER                              # 绝不硬塞一个自信的错误
    # 用带风险缩放的软价值期望排序
    return max(feasible, key=lambda m: expect_soft_utility(m, post_v) - lam*risk(m))

# IP-272 TVE：便宜代理高频 + 昂贵真值稀疏审计
def two_tier_verify(proxy, truth, audit_rate, budget):
    est = proxy.score()                            # 可能有偏
    if rng.random() < audit_rate:                  # 审计率 ≥ 1 − τ/b
        y = truth.score()
        return importance_weighted(est, y)         # 双稳健校正
    return est

# IP-276 PRICE 主闭环（继承 R68/R69）
def PRICE_RAS_round(M, obs):

        M.fmp.sample(o, K), o, M.value_head)
    # 快环：风险价格；慢环：经济价格
    prices = M.spd.cached_or_update(o, cred, M.clb)

    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    tau = M.pi_sigma.prefix_dispatch(action.a[:k]) * lam
    M.tve.log(action, U_val, U_val_after, prices)  # 异步审计 + 价格披露
    return k, lam, action, (U_ale, U_epi, U_val_after, prices)
```

## 3. 推导

**引理 19（CaVoI 的预算最优性与 R69 退化）** 在凸的序贯预算问题中，最优信息动作满足 `g* ∈ argmax_g [Δ(g) − ν·c(g)]`，其中 ν 为预算约束的对偶变量（影子价格）；当预算非紧（B→∞，ν→0）且成本作为直接负效用计入时，`Δ(g) − c(g)` 退化为 R69 的 `VoI(g) − c(g)`。**系**：R69 是 PRICE 在「价值预算无关、预算无限」边界上的特例；预算越紧，ν 越大，系统越只买「每块钱最值」的信息。

**引理 20（世界观测不能降低 U_val）** 在 A99（`W ⊥ V | o,a`）下，对任意非询问动作 `g_world ∈ 𝒜_info^world`，`I(V; y | o, a, g_world) = 0`。因此把 R69 的 MINT 直接用于 `U_val` 只会烧预算而不降价值不确定性；必须有 PEQ（询问/演示）或 DEF（延迟/交付）这一类新动作。**系**：三类不确定性必须配三类动作，否则「问得越多越对齐」是错觉。

**引理 21（对齐成本曲线的内点最优）** 设对齐收益 `G(B)` 边际递减（`G'>0, G''<0`），操纵/疲劳/验证债成本 `D(B)` 边际递增（`D'>0, D''>0`），则 `A(B)=G(B)−D(B)` 单峰，存在唯一内点 B* 满足 `G'(B*) = D'(B*)`。**系**：「多问总比少问好」不成立；R69 的无预算交互在价值维度上会越过 B*，把「诚实的不知道」升级为「被问出来的错误」。

**引理 22（代理偏差的审计速率下界）** 代理偏差 ≤ b、审计率 s、代理违规观测值 v̂。用审计真值校正后，期望真实违规 ≤ v̂ + (1−s)·b。故令 `s ≥ 1 − τ/b` 可保证代理钻空子上界 ≤ τ；双稳健修正可进一步消偏，但方差 ~ O(1/s)，给出审计预算与估计精度的显式权衡。**系**：廉价的「对齐分数」若无审计，天然可被优化器击穿。

**引理 23（预留预算的必要性与可证性）** 若高风险状态所需询问成本最大为 B_crit，则任何「先到先得、无预留」的预算策略都可能被 DoA 攻击推到 `R_t < B_crit`，从而在关键状态丧失对齐能力。预留 `R_res ≥ B_crit`、常规状态仅用 `B − R_res` 可保证关键状态始终可交互；该结论对任意攻击序列成立（对抗性归纳）。

**引理 24（价值学习后悔界）** 在 `𝒱_soft` 有界、损失有界且后验更新一致的条件下，CVP 的 Bayesian 后悔 `Reg_T ≤ O(√(T·dim(𝒱_soft)·log T))`；DEF 只会截断轨迹、不会增大单步后悔上界。**系**：对齐是「有统计保证的学习」，不是一次性猜对。

**定理 18（PRICE ⊇ FLUID ⊇ CALM 的保序包含）** 硬约束投影只会缩小可行集，故任意状态下最坏安全风险不高于 FLUID；当 `v_soft` 已知、只剩 `v_hard`、且 B→∞（ν→0）时，PRICE 与 FLUID **逐指令相同**；再令交互关闭（VoI≤成本）则退化为 CALM。**系**：新层在安全侧不让步，只在「价值不确定且付得起」时获得对齐与效率增益。

**定理 19（价值询问不能为硬违约发放许可）** PEQ 只在软可行集内重新排序，硬可行集由 CVP 在任何询问之前固定；任何操纵/误报只能改变软排序，不能改变硬可行性。结合非诱导（定义 323）与 SRC（定义 322），单源偏好回答对最终动作的影响被限制在软价值权重的有界扰动内，且 DEF 始终可用。**系**：对齐机制可以被骗去「换个偏好」，但骗不出「越过红线」。

## 6. 本轮最大风险

**一句话**：PRICE-RAS 的全部对齐保证都建立在「价值状态与对齐度是可测的」这一前提上——**一旦预算压力下系统改用廉价的「价值代理」（问卷分数、LLM 裁判、便宜验证器）来度量对齐，优化器会系统性地把「可测量的对齐」替换成「真正的对齐」，对齐就退化为一场可审计的表演（对齐剧场 / Goodhart）**：价格披露得漂亮、硬约束也没违反，但它在优化一个不是人类真正想要的东西——**越会算账，越会挑便宜的指标去满足**。

**次级风险与缓解**：
1. **硬约束仍被软化成罚项**（大奖励买通红线）→ 字典序投影先于定价，μ=∞，E309 红队；
2. **预算耗尽 / 哄抬价格攻击** → 预留 R_res + 状态价值分配 + 异常消耗检测（引理 23）；
3. **偏好投毒与策略性误报** → 非诱导 PEQ + SRC 交叉检验 + k 源一致 + ℰ_pref 对抗训练；
4. **对齐成本曲线估计错位** → 以外点/在线 bandit 监测 A(B) 峰位，超 B* 即自动降询问频率；
5. **价格慢环抖动破坏控制连续** → 价格冻结缓存 + 两次更新间 λ 独立（定义 326、定理 18 的无突变）；
6. **代理审计规避** → 审计率与偏差挂钩 + 随机化审计时点 + 双稳健校正（引理 22）。

# 第 70 轮产物 · 创新点清单 v1：PRICE-RAS（Preference-grounded, Risk-aware, Interactive, Cost-controlled, Epistemic-axiological risk-adaptive system：价值对齐 × 成本控制的三通道预算化闭环；VAD-3×VSR×PEQ×CaVoI×CLB×SPD×CVP×DEF×TVE×SRC×J_PRICE×RAS-WM†）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 把不确定性拆成 aleatoric / epistemic，并给 epistemic 配了「看—问—触」的主动交互。但它只问「世界是什么样」，没问「世界该是什么样」：系统可以**对世界完全确定、却对价值完全无知或完全错误**；而它唯一的成本处理只是把标量 `c(g)` 塞进 `argmax[VoI−c]`，既无预算、也无价格、更无「谁付钱」。把 R69 的交互平移到价值上，探询立刻变成**操纵**。

def decompose3(samples, o_t, value_head):
    U_ale, U_epi, modes = aud.decompose(samples)          # R69
    post_v = value_head.posterior(o_t)
    cred   = credible_set(post_v, alpha=0.05)
    U_val  = regret_diameter(cred) + value_head.unknown_margin()
    return (U_ale, U_epi, U_val), modes, post_v, cred

                if all(violation(m.a, v) == 0 for v in cred.hard)
                and violation(m.a, UNKNOWN) <= DELTA_UNK]
    if not feasible: return DEFER

    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    tau = M.pi_sigma.prefix_dispatch(action.a[:k]) * lam
    M.tve.log(action, U_val, U_val_after, prices)   # 异步审计 + 价格披露
    return k, lam, action, (U_ale, U_epi, U_val_after, prices)
```

## 4. 推导

**引理 19（CaVoI 预算最优性与 R69 退化）** 凸序贯预算问题的最优信息动作满足 `g*∈argmax[Δ(g)−ν·c(g)]`，ν 为预算对偶变量；B→∞ 且成本作直接负效用时退化为 R69 的 `VoI−c`。R69 = 「价值预算无关 + 预算无限」边界。

**引理 20（世界观测不能降低 U_val）** 在 A99（`W⊥V|o,a`）下，任意非询问动作 `g_world` 有 `I(V;y|o,a,g_world)=0`；故把 MINT 用于 U_val 只烧预算。三类不确定性必须配三类动作。

**引理 21（对齐成本曲线内点最优）** 收益边际递减 `G''<0`、操纵/疲劳/验证债成本边际递增 `D''>0` ⇒ `A(B)=G−D` 单峰，唯一 B* 满足 `G'(B*)=D'(B*)`。「多问总比少问好」不成立。

**引理 22（审计速率下界）** 代理偏差 ≤ b、审计率 s ⇒ 期望真实违规 ≤ v̂+(1−s)b；令 `s≥1−τ/b` 则代理钻空子上界 ≤ τ；双稳健校正消偏但方差 O(1/s)。

**引理 23（预留预算必要性）** 高风险状态最大询问成本 B_crit；无预留策略可被 DoA 推至 `R_t<B_crit`；预留 `R_res≥B_crit` 且常规仅用 `B−R_res` 可对任意攻击序列保证关键状态可交互。

**引理 24（价值学习后悔界）** `Reg_T ≤ O(√(T·dim(𝒱_soft)·log T))`；DEF 截断轨迹不增大单步后悔上界。

**定理 18（PRICE ⊇ FLUID ⊇ CALM 保序包含）** 硬可行投影只缩可行集 ⇒ 最坏安全风险不高于 FLUID；`v_soft` 已知、只剩 `v_hard`、B→∞（ν→0）时与 FLUID 逐指令相同；再关闭交互则退化为 CALM。安全不让步，对齐/效率仅在付得起时获益。

**定理 19（价值询问不能为硬违约发放许可）** PEQ 只在软可行集内重排；硬可行集在询问前由 CVP 固定；操纵/误报只改软排序不改硬可行性；结合非诱导与 SRC，单源回答影响被限制在软权重有界扰动内，且 DEF 始终可用。可以对齐机制「换个偏好」，但骗不出「越过红线」。

## 7. 本轮最大风险

**一句话**：PRICE-RAS 的全部对齐保证都建立在「价值状态与对齐度是可测的」这一前提上——**一旦预算压力下系统改用廉价的「价值代理」（问卷分数、LLM 裁判、便宜验证器）来度量对齐，优化器会系统性地把「可测量的对齐」替换成「真正的对齐」，对齐就退化为一场可审计的表演（对齐剧场 / Goodhart）**：价格披露得漂亮、硬约束也没违反，但它在优化一个不是人类真正想要的东西——**越会算账，越会挑便宜的指标去满足**。

**次级风险与缓解**：硬约束被软化成罚项（字典序先于定价、μ=∞、E309 红队）；预算耗尽/哄抬价格（R_res + 状态价值分配 + 异常检测，引理 23）；偏好投毒与策略性误报（非诱导 PEQ + SRC + k 源一致 + ℰ_pref 对抗训练）；A(B) 峰位估计错位（在线 bandit 监测，超 B* 自动降频）；价格慢环抖动（价格冻结 + λ 独立，定义 326、定理 18）；代理审计规避（审计率挂偏差 + 随机时点 + 双稳健校正，引理 22）。
