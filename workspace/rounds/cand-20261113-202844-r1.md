# 第 69 轮（承接第 68 轮「CALM-RAS」IP-243~252；本轮灵感：「动作空间」×「数据配比」）

> R68 的自陈风险是一句判词：**标定能力越强，缓变故障越隐形**。它把安全押在「频率可分 + 静态段可分」上，却回避了一个更根本的问题——**可分性不是估计器的性质，而是整条闭环轨迹与训练分布的性质**。若一个缓变故障的方向落在标定雅可比的像空间里，且闭环从未运动到能把它与漂移分开的工况，则再好的 EKF、再全的 canary 也无法把它辨识出来：这是**可辨识性（identifiability）**层面的盲，而不是精度层面的盲。
>
> 本轮两个灵感正好补上「轨迹」与「分布」这两半：
> - **「动作空间」**：把动作从「执行任务的工具」升级为「采集证据的探针」——主动设计能照亮标定零空间的机动，让故障在标定解释不了的方向上显影；
> - **「数据配比」**：把影子流的采样比例从「默认均匀」升级为「受安全约束的因果杠杆」——用 canary 下限、去混杂上限、反事实配对，阻止模型学会「一切都由标定解释」。
>
> 核心命题：**可辨识性由动作轨迹决定，模型可信度由数据配比决定；把二者提升为一等公民并互相闭环——PRISM-RAS（Probe-action, Ratio-certified, Identifiability-Separation Metrology）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我有没有能力看出它不准**」——当系统无法区分漂移与缓变故障时，它必须承认「不知道」，而不是宣布「已标定」。

## 0. 直觉与动机

**灵感 1（动作空间 → 可辨识性是轨迹的属性，不是估计器的属性）**
直觉：R68 的 COF 在「机器人+场景静止」时标定，但静止时许多参数根本不可观（力零偏可观，焦距/外参在某些方向上不可观），而缓变故障恰恰在静态段最容易被吸收。工程直觉：想知道一个参数有没有漂，你得**动起来、加载荷、换视角**——这正是经典系统辨识里的持续激励（persistent excitation）。于是把动作空间扩成 𝒜 = 𝒜_task ⊕ 𝒜_probe：探针动作是**受控的、有限的、带安全回退的激励**，其唯一目的是让残差在新工况下产生「标定流形之外」的分量。选择探针的判据不是任务收益，而是**可辨识性增益**：让 P_null(J_c)·J_f 的最小奇异值 κ 变大——κ 就是「故障能否从标定中被认出来」的量化指标。κ→0 时，任何估计器都无法分辨漂移与故障（引理 16）。

**灵感 2（数据配比 → 配比是因果杠杆，不是调参旋钮）**
直觉：R68 的 SSG 把五类自监督信号混在一起，配比默认；但模型最终相信什么，由配比决定。若训练流里「漂移样本」远多于「故障样本」，模型会学到最省力的解释：**一切残差都是标定**。这不是容量问题，是**混杂（confounding）**问题——当标定变量 c 与故障变量 f 在数据中总是共同出现，模型无法把二者因果分离。于是配比变成安全变量：canary 下限保证故障模式永不断供；去混杂上限 I(c;f) ≤ ε 保证「标定解释」不是统计捷径；反事实配对（只改 c / 只改 f）提供因果识别所需的对照；再叠加 DRO，使配比在分布漂移下仍有最坏情况保证。

**灵感 3（双灵感合流 → 探针为配比供证据，配比为探针供判据）**
直觉：单独主动探针会被「自己设计的故障模型」骗——你只激励了你想到的方向；单独配比约束会被「没见过的故障」绕过——canary 只覆盖已知模式。二者闭环才稳：**SCC 证书决定「现在缺哪类证据」→ AIP 生成能补该证据的探针 → 影子流用 ADS 把探针产生的边界样本按可行配比喂给模型 → CMX/CDF 用反事实配对防止模型把探针证据误读成漂移 → CAC 用 κ 证书与配比可行性做最后闸门**。证据链与学习链互锁，任何一环声称「已解释」都必须先过可辨识性证书。

**灵感 4（PRISM-RAS 七组件）**
1. **AIP Active Identifiability Probe**（IP-253）：探针动作集 + 信息增益/风险比排序，选择能最大化 P_null J_f 奇异值的机动；
2. **SCC Separability & Controllability Certificate**（IP-254）：滑窗估计 κ 及置信下界，输出可辨识性证书；
3. **CMX Certified Mixture**（IP-255）：canary 下限、去混杂上限、反事实平衡、漂移预算四约束下的 DRO 配比；
4. **ADS Ambiguity-Directed Sampler**（IP-256）：向 cal/fault 边界样本定向加权，并投影回可行域；
5. **CDF Counterfactual Data Fabricator**（IP-257）：仿真中制造「只改 c / 只改 f」匹配对，并做可交换性校验；
6. **DCC Dual-Control Coordinator**（IP-258）：任务探索 vs 信息探索的风险预算分配，探针期间冻结 λ；
7. **RAS-WM‡ 继承核**：R68 的 MTM/SSG/COF/CFA/CAC 全部保留，仅把「可信」的定义从 U(ĉ) 扩展到 (U, κ)。

**灵感 5（对 R68 原罪的对症下药）**
- R68「缓变故障落进标定带宽 → 被标好」：κ 证书在归因前判定「此刻轨迹能否分开二者」，κ 低则**禁止** H_cal 后验 > 0.5，λ_floor 抬到 0.8——**先证可辨识，再谈已标定**；
- R68「canary 不可修复性依赖金标覆盖」：配比 canary 下限 + 反事实配对把「覆盖」从偶然变成约束；
- R68「标定能力越强越隐形」：探针主动制造标定解释不了的分量，把「越强越隐形」反转为「越强越会主动去证伪自己」。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（PRISM-RAS 总览）** PRISM-RAS = (AIP, SCC, CMX, ADS, CDF, DCC, RAS-WM‡)。在 R68 三不变式之上追加三条：
(i) **探针守恒**：探针只在认证安全包络内执行，每小时探针预算 B_probe 有界，探针期间 k*RAS 冻结、λ 更新冻结，任何一次安全越界即永久禁用探针并记入 ℰ_probe；
(ii) **可辨识性红线**：κ_LB(t) < κ_min 持续 T_amb 时，禁止把残差归因为 H_cal（P(H_cal) ≤ 0.5），λ_floor 抬至 ≥ 0.8，k 追加收缩——**不可辨识永远导向保守**；
(iii) **配比可行性**：影子流训练配比 μ 必须落在 M_feasible；μ ∉ M_feasible 时 CAC 一票否决，禁止提交。

**定义 294（可辨识性裕度 κ）** 设标定观测模型 r = h(c, f) + ε，其中 c 为 R68 的标定潜变量、f 为故障潜变量。记雅可比 J_c = ∂h/∂c ∈ ℝ^{m×d_c}、J_f = ∂h/∂f ∈ ℝ^{m×d_f}，标定零空间投影 P_null = I_m − J_c J_c^{+}。定义
**κ = σ_min(P_null J_f)**，
即「故障效应中完全无法被标定解释」的最弱方向强度。κ 越大，故障越难被标定吸收；κ = 0 ⇔ 存在 δc 使 J_c δc = J_f f（一阶完全可吸收）。κ 由当前工况/动作决定，而非由估计器决定。

**定义 295（被动不可辨识与吸收方向）** 被动策略 π₀（只用任务动作、不做探针）下，若 f 的谱含量 ≤ ω_cal 且 P_null J_f f = 0，则称 f 沿**吸收方向**。此时存在 δc = J_c^{+} J_f f 使一阶观测分布相同：p(r | c, f) = p(r | c+δc, 0)。因此任何仅凭 r_t 的被动检测器在虚警率 α 下检出功率 ≤ α；且标定头会吸收该故障，吸收量 ‖δĉ‖ ≈ ‖J_c^{+} J_f f‖。这形式化了 R68 的「原罪」（引理 16）。

**定义 296（探针动作与信息价值）** 动作空间 𝒜 = 𝒜_task ⊕ 𝒜_probe。探针 a ∈ 𝒜_probe 是一段有界机动（受控接触/已知载荷/已知运动/已知光照/主动多视角），其作用是改变工作点从而改变 (J_c, J_f)。定义信息价值
V(a) = Δκ(a) − λ_R·Risk(a) − λ_T·Cost(a)，
Δκ(a) = E[κ(t+1) − κ(t) | a]，Risk(a) 为预测的最坏控制偏差，Cost(a) 为时间/磨损成本。选择
a* = argmax_{a ∈ 𝒜_probe, Risk(a) ≤ B_probe(t)} V(a)。
**正交激励**：优先选择使 ‖P_null(a) J_f(a)‖ 增大（而非仅增大 ‖J_f‖）的 a——只激励「标定解释得了」的方向对可辨识性无贡献。

**定义 297（SCC 可辨识性证书）** 在滑窗 W 上估计 Ĵ_c、Ĵ_f，得 κ̂ 与自助法置信下界 κ_LB（或用 Davis–Kahan 子空间扰动界）。证书 SCC_t = (κ̂_t, κ_LB, rank(P_null Ĵ_f), probe_coverage_t)。**Valid ⇔ κ_LB ≥ κ_min**。SCC 无效时 CFA 不得偏好 H_cal；Valid 才允许把残差判为可标定漂移。

**定义 298（可辨识性红线归因）** CFA 后验修正：
P(H_cal | r, ĉ, κ) ≤ 0.5 + 0.5·1[κ_LB ≥ κ_min]·σ(κ̂/κ_min)，
即 κ 不达标时 H_cal 后验被硬性压到 ≤ 0.5，剩余质量分配给 H_sensor^trans 与 unknown。λ_floor 同时取与 R68 的 max。

**定义 299（数据分层与配比）** 影子数据分五层：D_stat（静态正常）、D_dyn（动态正常）、D_fault（故障 canary）、D_amb（cal/fault 边界歧义样本）、D_cf（反事实匹配对）。配比 μ ∈ Δ⁵，训练分布 p_μ = Σ_s μ_s p_s。

**定义 300（可行配比集 M_feasible）** 四类安全约束：
(a) **canary 下限** μ_fault ≥ ρ_min（如 0.05）——故障模式永不断供；
(b) **去混杂上限** Î(c; f) ≤ ε_I（如 0.05 nats）——标定与故障不得统计共现；
(c) **反事实平衡** μ_cf ≥ ρ_cf 且匹配对中「只改 c」「只改 f」严格 1:1；
(d) **漂移预算** W₁(p_μ, p_live) ≤ ε_shift，标注成本 ≤ B_label。
M_feasible = {μ ∈ Δ⁵ : (a)∧(b)∧(c)∧(d)}。

**定义 301（风险感知配比优化）** 在可行域内解分布鲁棒问题
μ* = argmin_{μ ∈ M_feasible} sup_{Q ∈ 𝒬} E_Q[L_fault + L_cal]，
𝒬 为以 p_μ 为球心、半径 ε_shift 的 Wasserstein 不确定集。用投影指数梯度/注水法在线求解。该目标同时压制两种退化：把一切解释为 cal（L_cal 坍塌）与只拟合正常样本（L_fault 尾部失守）。

**定义 302（ADS 歧义定向采样）** 样本权重
w ∝ softmax(β_d·κ̂^{-1}·difficulty + β_u·H(π_cal, π_fault))，
向 κ 小、cal/fault 后验接近 0.5 的边界样本加权；随后投影到 M_feasible（欧氏投影或 KL 投影），保证定向采样不破坏定义 300 的约束。

**定义 303（CDF 反事实数据）** 对每个场景用同一随机种子生成匹配元组
{y(c+δc, f), y(c, f+δf), y(c+δc, f+δf), y(c, f)}，
并校验可交换性残差 ‖y(c+δc, f+δf) − y(c+δc, f) − y(c, f+δf) + y(c, f)‖ ≤ δ_cf（一阶可加性）。超界样本标记为非线性混杂，不得进入 D_cf。

**定义 304（DCC 双环协调）** 每控制步：
1. 读 SCC：(κ̂, κ_LB)；
2. 若 κ_LB < κ_min 且安全，按 V(a) 提升探针优先级；
3. 在预算 B_probe 内由约束 bandit / 对偶控制分配 a_task 与 a_probe；
4. 探针激活时输出 probe_flag，冻结 λ 与前缀更新，启用安全回退 k_min；
5. 把 (κ_LB, probe_flag) 传给 CFA，把 M_feasible 传给 SSG/ADS。
目标：max E[Δκ] s.t. 任务成功率 ≥ 1−α_task 且风险 ≤ B_risk。

**定义 305（探针安全包络与观察者效应预算）** 探针仅在认证安全集 S_safe 内执行：预测最坏 τ 在限内、k*RAS ≥ k_min 回退可用、状态偏差 ≤ δ_safe。定义观察者效应预算：探针本身引起的磨损/退化计入累计风险 R_obs，且 R_obs ≤ ε_obs·T。任一次越界 → 永久禁用探针 + 事件记录 + 全局 λ 抬升。

**定义 306（PRISM 损失）** L_PRISM = L_MT + λ_amb·L_amb + λ_cf·L_cf + λ_sep·L_sep：
- L_amb：在 D_amb 上最小化 cal/fault 头的边界混淆（与 κ 一致的间隔最大化）；
- L_cf：反事实等变/不变——cal_head 只响应 c，fault_head 只响应 f，交叉响应加罚；
- L_sep：惩罚 fault 表征落入 cal 表征张成空间（表示解耦，配合定义 294 的几何）。

**定义 307（AIC-PRISM 干扰集）** ℰ_PRISM = ℰ_CALM × ℰ_probe × ℰ_mix × ℰ_cf；ℰ_probe = {探针诱发失稳、探针信息泄漏/过拟合、预算耗尽};ℰ_mix = {配比投毒、canary 饥饿、混杂回流、分布偏移};ℰ_cf = {反事实失配、仿真器混杂}。

**定义 308（J_PRISM 证书）** J_PRISM = (J_CALM, κ_LB, SCC_hash, probe_budget_used, μ_mixture_vec, mixture_feasible, cf_consistency, prism_ver)。Valid ⇔ Valid(J_CALM) ∧ (κ_LB ≥ κ_min 或已按红线保守降级) ∧ mixture_feasible ∧ cf_consistency。

**定义 309（管线）** 离线：CDF 生成反事实匹配集 → PRISM 预训练 → 标定 κ 估计器并校准其置信下界。在线：每窗口 SCC 评估 → DCC 决定是否探针 → κ 感知 CFA → 影子流 ADS + CMX 训练 → CAC 追加「配比可行 + κ 证书」两关后原子换装。

**定义 310（可辨识性感知阈值）** τ_risk(κ) = τ⁰_risk·(1 + κ_r·U + κ_amb·max(0, 1 − κ/κ_min))。关键：R68 的保守性只绑定 U(ĉ)，本轮再绑定 κ——**即使标定置信很高（U 小），只要轨迹分不开漂移与故障（κ 小），系统仍必须收紧**。这填补了 R68「U 小而 κ 也小」的致命盲区。

```python
# IP-254 SCC：可辨识性证书（滑窗雅可比 + 零空间投影 + 置信下界）
class SeparabilityCertificate:
    def update(self, window):
        Jc = jacobian_cal(window)                 # m×d_c
        Jf = jacobian_fault(window)               # m×d_f
        Pn = np.eye(Jc.shape[0]) - Jc @ np.linalg.pinv(Jc)
        M  = Pn @ Jf
        sv = np.linalg.svd(M, compute_uv=False)
        kappa = sv.min() if sv.size else 0.0
        return kappa, self.bootstrap_lower_bound(M, sv)


# IP-253 AIP：主动可辨识探针（正交激励优先）
class ActiveIdentifiabilityProbe:
    def __init__(self, probe_set, B_probe_per_h=0.01):
        self.probes, self.B, self.spent = probe_set, B_probe_per_h, 0.0

    def info_value(self, a, state, Jc, Jf):
        dk = expected_margin_gain(a, Jc, Jf)      # E[Δσ_min(P_null J_f)]
        return dk - LAM_R*risk(a, state) - LAM_T*a.cost

    def select(self, state, Jc, Jf, risk_budget):
        cand = [a for a in self.probes if a.in_safe_envelope(state) and a.risk(state) <= risk_budget]
        if not cand or self.spent >= self.B: return None
        a = max(cand, key=lambda a: self.info_value(a, state, Jc, Jf))
        self.spent += a.cost
        return a


# IP-255/256 CDF + CMX + ADS：认证配比与歧义定向采样
class CertifiedMixture:
    def feasible(self, mu, live):
        return (mu['fault'] >= RHO_MIN
                and mutual_info(mu) <= EPS_I
                and mu['cf'] >= RHO_CF
                and wasserstein(mu, live) <= EPS_SHIFT)

    def solve(self, loss_fn):
        mu = self.uniform()
        for _ in range(T_mix):
            g = grad_DRO(loss_fn, mu)             # 内层 sup_Q
            mu = project_simplex(mu - eta*g)
            mu = project_to_feasible(mu, self)    # 定义 300
        return mu


class AmbiguityDirectedSampler:
    def weights(self, strata, kappa):
        w = softmax(BETA_D*(1.0/max(kappa, 1e-6))*difficulty(strata)
                    + BETA_U*entropy_ratio(strata))
        return project_to_feasible(w, self.cmx)

            M.cac.reject(reason='mixture_infeasible'); M.log_emix(batch.mu)
    M.a_prev = a
    return a, k, lam, joint, (c, U, kappa_lb, probe_flag)
```

## 3. 推导

**引理 16（被动不可辨识下界）** 若故障 f 沿吸收方向（P_null J_f f = 0），则存在 δc = J_c^{+} J_f f 使一阶观测分布相同。由 Le Cam 两点法，任何被动检测器在虚警率 α 下检出功率 ≤ α；标定头吸收量 ‖δĉ‖ ≤ ‖J_c^{+} J_f f‖。即 R68 的「缓变故障被标好」不是调参失误，而是 κ = 0 时的必然结果——**估计器再强也补不回缺失的激励**。

**引理 17（探针可辨识增益与 √ 累积）** 对探针 a，其正交激励使 κ 增加 Δκ(a) = σ_min(P_null(a) J_f(a)) − σ_min(P_null J_f)。在独立噪声下，m 次正交探针的 Fisher 信息可加，故 κ_m ≥ κ₀ + c·√(Σ_a Δκ(a))。因此只要故障方向不落在所有探针下 span(J_c(a)) 的交集中，存在有限探针预算使 κ_LB ≥ κ_min。系：**可辨识性可被「主动购买」，且收益随激励能量次线性增长**——这给出了探针预算的边际收益曲线。

**引理 18（配比去混杂界）** 若训练配比满足 I(c; f) ≤ ε_I 且反事实平衡，则标定头对故障的伪吸收满足 E[‖∂ĉ/∂f‖] ≤ C·√(ε_I) + δ_cf。证明要点：互信息界控制 c、f 的统计可预测性，反事实对把「只改 f」的效应从「只改 c」中剥离；残余由可交换性残差 δ_cf 界定。系：**「一切解释为标定」的捷径被配比约束可量化地堵死**。

**引理 19（canary 覆盖与尾部界）** 在 canary 下限 μ_fault ≥ ρ_min 与 DRO 半径 ε_shift 下，最坏故障漏检率满足
FN_worst ≤ C/√(ρ_min·N) + ε_shift·L_max。
即 canary 比例直接进入尾部风险的分母；配比不是效率参数，而是安全半径。

**定理 16（PRISM 端到端风险一致性）** 在 R68 的 A87–A94 与新增 A95–A98（探针安全包络、配比可行性、反事实可加性、κ 可估计）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_probe + α_mix**，其中 α_probe 受引理 17 的 κ_LB 支配、α_mix 受引理 18–19 支配；
2. **κ_LB < κ_min ⇒ P(H_cal) ≤ 0.5 ∧ λ_risk ≥ 0.8 ∧ τ_risk 收紧 ∧ k 收缩**——不可辨识永远导向保守，绝不以「已标定」放行；
3. 探针预算 B_probe 下，任何满足 ‖P_null J_f‖ ≥ ε_f 的缓变故障可在 T_det(B_probe) 内被检出（引理 17）；
4. 提交适配器同时满足 R68 五关 + 配比可行 + SCC 有效；有害上线概率 ≤ 0.05·p_h 不劣化。
**净效果**：R68 中「ω_f ≤ ω_cal 且投影小」的必盲区，被 κ 证书显式标为「不知道」，并被探针主动照亮。

**定理 17（探针安全性与配比鲁棒性）** 探针限定在 S_safe 内 ⇒ 任务约束违反概率 ≤ α_safe；越界即永久禁用并全局抬升 λ。配比在 DRO 球内最坏损失有界，canary 饥饿被 ρ_min 阻断，投毒被 ε_shift 限制；不可行配比直接阻断提交。探针的边际信息收益递减（引理 17 的 √ 律）而风险线性增长，故最优预算 B*_probe 由「边际信息 = 边际风险」唯一确定。

## 6. 本轮最大风险

**一句话**：PRISM 用「自己设计的探针 + 自己定义的故障模型」去证明「自己可辨识」，一旦真实缓变故障位于所有探针张成的标定像空间交集之内（或属模型外的新型故障），κ 证书会给出**虚假的可辨识自信**，系统便在「我已主动证伪过」的更强理由下放行——从 R68 的「被动盲」升级为「主动地、有证书地盲」，这是元计量（meta-metrology）的原罪：**用于证明可辨识性的探针与判据，本身无法被同一套框架证明**。

**次级风险与缓解**：
1. **探针诱发退化/观察者效应**：主动激励本身磨损系统 → 观察者效应预算 R_obs ≤ ε_obs·T + 越界即永久禁用；
2. **探针过拟合已知故障族**：κ 只对模型内故障有效 → 保留模型外残差监测 + κ 不达标即保守（定义 298），probe_set 定期由 AuditBuf 对抗扩充；
3. **配比约束下的样本饥饿**：canary/反事实下限挤压正常数据 → 分层容量规划 + 合成增广，且以 DRO 而非硬删样本实现；
4. **配比投毒/回放污染**：攻击者伪造 canary → 配比可行域投影 + AuditBuf 指纹 + CAC 金标关；
5. **κ 估计的滑窗偏差**：小窗口估计不稳 → 自助法下界 + Davis–Kahan 界 + 窗口自适应；κ 不确定时按红线取保守分支。

**定义 293（总览与三不变式）** 探针守恒（安全包络 + 预算 + 失败永久禁用）；可辨识性红线（κ_LB<κ_min 禁止 H_cal 放行，λ≥0.8）；配比可行性（μ∉M_feasible 一票否决提交）。

**定义 298（红线归因）** `P(H_cal|r,ĉ,κ) ≤ 0.5 + 0.5·1[κ_LB≥κ_min]·σ(κ̂/κ_min)`；κ 不达标时后验硬压 ≤0.5，剩余给 H_sensor^trans/unknown。

```python
class SeparabilityCertificate:
    def update(self, window):
        Jc = jacobian_cal(window); Jf = jacobian_fault(window)
        Pn = np.eye(Jc.shape[0]) - Jc @ np.linalg.pinv(Jc)
        sv = np.linalg.svd(Pn @ Jf, compute_uv=False)
        return (sv.min() if sv.size else 0.0), self.bootstrap_lower_bound(Pn @ Jf)

# IP-253 AIP：正交激励探针
class ActiveIdentifiabilityProbe:
    def select(self, state, Jc, Jf, risk_budget):
        cand = [a for a in self.probes
                if a.in_safe_envelope(state) and a.risk(state) <= risk_budget]
        if not cand or self.spent >= self.B: return None
        a = max(cand, key=lambda a: expected_margin_gain(a, Jc, Jf)
                                      - LAM_R*a.risk(state) - LAM_T*a.cost)
        self.spent += a.cost; return a

                and mu['cf'] >= RHO_CF and wasserstein(mu, live) <= EPS_SHIFT)
```

## 4. 推导

**引理 16（被动不可辨识下界）** 吸收方向 P_null J_f f=0 ⇒ ∃δc=J_c⁺J_f f 使一阶观测同分布；Le Cam 两点法给出被动检测功率 ≤ 虚警率，标定吸收量 ‖δĉ‖≤‖J_c⁺J_f f‖。R68 的「缓变故障被标好」是 κ=0 的必然，不是调参失误。

**引理 17（探针增益与 √ 累积）** 单探针增益 Δκ(a)=σ_min(P_null(a)J_f(a))−σ_min(P_null J_f)；独立噪声下 Fisher 信息可加 ⇒ κ_m ≥ κ₀ + c·√(ΣΔκ)。只要故障方向不在所有探针下 span(J_c(a)) 的交集，有限预算即可达 κ_min——可辨识性可被「主动购买」，收益次线性。

**引理 18（配比去混杂界）** I(c;f)≤ε_I + 反事实平衡 ⇒ E[‖∂ĉ/∂f‖] ≤ C√ε_I + δ_cf；「一切解释为标定」的统计捷径被可量化堵死。

**引理 19（canary 覆盖与尾部界）** μ_fault≥ρ_min 且 DRO 半径 ε_shift ⇒ FN_worst ≤ C/√(ρ_min·N) + ε_shift·L_max；配比直接进入安全半径。

**定理 16（PRISM 端到端风险一致性）** A87–A94 + A95–A98 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_probe+α_mix`（α_probe 受 κ_LB 支配，α_mix 受引理 18–19 支配）；
2. `κ_LB<κ_min ⇒ P(H_cal)≤0.5 ∧ λ_risk≥0.8 ∧ τ_risk 收紧 ∧ k 收缩`——不可辨识永远导向保守；
3. 探针预算 B_probe 下，‖P_null J_f‖≥ε_f 的缓变故障在 T_det(B_probe) 内可检出；
4. 提交同时过 R68 五关 + 配比可行 + SCC 有效，有害上线 ≤0.05·p_h 不劣化。
**净效果**：R68 的必盲区（ω_f≤ω_cal 且投影小）被 κ 证书显式标为「不知道」并被探针照亮。

**定理 17（探针安全性与配比鲁棒性）** 探针限于 S_safe ⇒ 违规概率 ≤α_safe，越界即永久禁用 + 全局抬 λ；DRO 球内最坏损失有界、canary 饥饿被 ρ_min 阻断、投毒被 ε_shift 限制、不可行配比阻断提交。信息收益 √ 递减 vs 风险线性增长 ⇒ 最优预算 B*_probe 由「边际信息 = 边际风险」唯一确定。

## 7. 本轮最大风险

**一句话**：PRISM 用「自己设计的探针 + 自己定义的故障模型」去证明「自己可辨识」，一旦真实缓变故障位于所有探针张成的标定像空间交集之内（或属模型外的新型故障），κ 证书会给出**虚假的可辨识自信**，系统便在「我已主动证伪过」的更强理由下放行——从 R68 的「被动盲」升级为「主动地、有证书地盲」，这是元计量（meta-metrology）的原罪：**用于证明可辨识性的探针与判据，本身无法被同一套框架证明**。

**次级风险与缓解**：探针诱发退化/观察者效应（R_obs≤ε_obs·T + 越界永久禁用）；探针过拟合已知故障族（模型外残差监测 + probe_set 由 AuditBuf 对抗扩充）；配比约束下的样本饥饿（分层容量规划 + 合成增广，以 DRO 而非硬删实现）；配比投毒/回放污染（可行域投影 + AuditBuf 指纹 + 金标关）；κ 滑窗估计偏差（自助法下界 + Davis–Kahan 界 + 自适窗口，不确定即走保守分支）。
