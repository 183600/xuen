# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC × IP-153~160；本轮灵感循环第 7 轮；灵感：「能耗优化」×「视觉问答」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「场景语义→意图→实时约束→阻抗→执行→证据」闭了起来。但它把三个前提当成了「免费资源」：
> 1. **感知零成本假设**：场景后验、意图推断、证据同步都默认「多看一次、多算一遍」不付代价。真实系统里，一次视觉问答（VQA/VLM）推理可能是焦耳级，一次接触的机械功也是焦耳级——两者争的是同一块电池。
> 2. **视觉只被当标签，没被当问题**：第 60 轮的视觉是「预定义场景分类器的输入」。执行真正需要的是随状态动态生成、且能接地的问题：「布下面有没有液体？」「握把是否在摩擦锥内？」「刚才那一下是滑移还是黏着？」标签是封闭答案空间，问题是开放世界的。
> 3. **信息收益与能量代价未联合定价**：多问一题可降 D⁺、放宽安全裕度、允许更省力的阻抗；但问题本身的算力/通信/热代价可能超过省下的机械能。没有以焦耳计价的「信息价格」，系统只能在「过度看（费电）」与「闭眼省（不安全）」之间二选一。

## 0. 直觉与动机

**灵感 1（能耗优化 → 执行能耗模型 EECM）**
直觉：机器人的能耗不是一块电表，而是四本账：机械账 E_mech（力矩²铜损 + 重力/接触做功）、计算账 E_comp（场景后验、意图推断、VQA 级联推理）、通信账 E_comm（ROS 消息、重传、云边同步）、热账 E_therm（结温/可持续功率约束）。关键洞见：**E_mech 对阻抗 K 通常呈 U 形（拟凸）**——K 太低→跟踪误差大→对抗重力/扰动做功多；K 太高→力矩纹波、过冲、接触抖振→铜损大。于是存在一个由场景与不确定性共同决定的能量最优点 K^E(D⁺)；**不确定性越大，安全约束要求的裕度越大，K^E 被推离舒适区，机械能上升**。不确定性第一次有了「焦耳价格」。

**灵感 2（视觉问答 → 执行接地 VQA，EGVQA）**
直觉：把 VQA 从「图像→答案」改造成「执行不确定性→问题→带接地的答案」。问题不是人问的，而是由执行状态生成的：SSM 场景后验熵高时问「这是什么表面」；接触力残差异常时问「接触点是否滑移」；安全裕度逼近阈值时问「障碍物边界在哪里」。答案不是自由文本，而是**结构化接地对象**（场景增量 + 约束增量 + 证据 ROI + 置信度），必须能落到 SSM/CIEC/EEIS 的某个变量上。关键洞见：**好问题不是信息量最大的问题，而是「每焦耳最能放宽安全裕度」的问题**。

**灵感 3（两灵感合流 → 不确定性的影子价格与 VOI/Joule）**
直觉：把「能耗-安全帕累托编译」写成约束优化
```
V(D⁺) = min_{K∈K_EE} E_mech(K; ξ̂)   s.t.   m(K, D⁺) ≥ g(D⁺)
```
其中 m 是安全裕度，g 是不确定性要求的保守裕度且单调不降。由包络定理，
```
dV/dD⁺ = -μ*·g'(D⁺),   μ* = 安全约束的拉格朗日乘子 ≥ 0   （单位：焦耳/裕度）
```
所以把 D⁺ 降低 ΔD⁺ 的期望机械能收益约为 μ*·g'(D⁺)·ΔD⁺。问一次问题花 E_cost(q) 焦耳、期望降低 ΔD⁺(q)，定义
```
benefit(q) = μ*·g'(D⁺)·E[ΔD⁺(q)] + λ_s·E[ΔD⁺(q)]
ρ(q) = benefit(q) / E_cost(q)
```
**只有当 ρ(q) ≥ 1（或高于阈值 ρ_min）才值得看**。这把「视觉问答」与「能耗优化」统一到同一个货币：焦耳。

**灵感 4（多保真级联与事件门控，AEG）**
直觉：不是所有问题都值得上大模型。先花极少的能量做 ROI 裁剪 + 小分类器，回答「是否需要细看」；只有当边际 VOI/Joule 仍高、且安全临界性 κ>0 时才升级到大 VLM。场景突变、接触异常、D⁺ 超阈值才触发查询；平稳执行期**主动闭嘴**。关键洞见：**能耗优化首先是不算，其次才是算得快**——事件触发替代周期轮询，级联早退替代一次性大模型。

**灵感 5（合流闭环 → EIVL 与 PCE+++++）**
直觉：形成「D⁺ → 影子价格 μ* → 提问调度 VQS → 级联推理 AEG → 接地校验 GCV → 场景/约束更新 → 能量-安全帕累托编译 EPC → 执行 → 新证据 → D⁺ 更新」的闭环。PCE+++++ 在 B_scene/B_intent/B_ros/B_exec 之外新增 **B_energy（机械/计算/通信/热）** 与 **B_vqa（查询数/视觉 token/时延）**，并设置**不可挪用的安全储备**（E_res、N_res）：再省也不能省掉「会揭示危险的那一问」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（执行接地视觉问答 EGVQA）** 五元组 `E = (Q, g_Q, VQA, γ, δ_m)`：
- **问题空间** `Q = Q_scene ∪ Q_constraint ∪ Q_evidence`，每个问题 `q=(target, predicate, roi, fidelity, critical)`；
- **问题生成器** `g_Q: (D⁺, π_scene, r_contact, margin) → Q_t`：只在不确定性/接触异常/裕度逼近时生成问题；
- **答案结构** `a = (text, c, ROI, Δπ_scene, ΔC, h_ev, E_cost)`，c 为置信度，h_ev 为证据哈希；
- **接地算子** `γ: a → (π_scene', C_intent', m')`，把答案落到场景后验、意图约束、安全裕度；
- **语义收缩上限** `δ_m`：任何 VQA 接地满足 `m' ≥ max(m_hard, m − δ_m)`，且 `m_hard` 为**物理硬限，任何答案都不能突破**；
- **执行相关性** `Rel(q) = E[ΔD⁺(q)] / (1 + H(π_scene))`，用于问题生成时的初筛。

**定义 162（执行能耗模型 EECM）** 总能耗
```
E_total(K, q, m) = E_mech(K; ξ) + E_comp(q) + E_comm(m)
E_mech(K; ξ) = ∫_0^T [ τᵀ R τ + |τ·q̇| ] dt,   τ = Jᵀ(K_p e + K_d ė) + τ_ff
E_comp(q)    = Σ_{ℓ=0}^{L} (Π_{j<ℓ} p_j) · c_ℓ(q)        （级联期望能耗）
E_comm(m)    = Σ_msg (e_tx·bytes + e_rtx·retransmits)
```
热约束 `∫ P(t) dt ≤ Q_th`（或结温 ≤ T_max）。能量预算
`B_energy = (E_mech^B, E_comp^B, E_comm^B, Q_th)`，并设**安全储备 E_res**（不参与普通任务分配）。
EECM 的 U 形/拟凸性由在线标定校验；若标定不成立，EPC 退回无模型的保守偏序而非错误的解析最优。

**定义 163（视觉查询调度 VQS）** 给定候选问题集 Q_t、剩余能量 E_rem、剩余查询数 N_rem：
```
maximize   Σ_{q∈S} benefit(q)
s.t.       Σ_{q∈S} E_cost(q) ≤ E_rem,   |S| ≤ N_rem,   F_crit(D⁺) ⊆ S
```
其中 `F_crit(D⁺) = { q : risk(q) ≥ τ_risk }` 为**安全地板查询**（D⁺ > D_crit、接触异常、裕度低于 τ_m 时强制提问），其能耗从保留 E_res 支出。信息增益对问题集是次模的（互信息的次模性），故基数约束下贪心达到 `1−1/e` 近似；背包约束下用 cost-benefit 贪心并给出常数近似；安全地板集合始终精确保留。

**定义 164（能量-安全帕累托编译 EPC）**
- 安全裕度 `m(K, D⁺) = min{ 力限裕度, 接触稳定裕度, 热裕度, 跟踪误差裕度 }`；
- 能量最优阻抗 `K^E(D⁺) = argmin_{K∈K_EE} E_mech(K) s.t. m(K,D⁺) ≥ g(D⁺)`；
- **影子价格** `μ* = −∂V/∂g`，由 KKT 对偶变量给出；`g'(D⁺)` 是保守裕度对不确定性的敏感度；
- **帕累托前沿** `P = { K : ∄K' 使 E_mech(K') ≤ E_mech(K) 且 m(K',D⁺) ≥ m(K,D⁺)（至少一严格） }`，`Pareto_gap(K) = (E_mech(K)−E_min)/(E_max−E_min)`；
- **能耗证书** `Cert_energy = (E_mech, E_comp, E_comm, E_total, μ*, m, Pareto_gap, K_version, hash)`，与第 60 轮的 `Cert_eeis` 并列签发。

**定义 165（自适应能量门控 AEG）** 级联 `L = {(f_ℓ, c_ℓ, p_ℓ, ROI_ℓ)}_{ℓ=0..L}`，c_ℓ 为单次能耗、p_ℓ 为升级概率。触发集 `E_trig = {场景突变 κ_scene>τ_κ, 接触残差 > τ_r, D⁺ > τ_D, 裕度 < τ_m}`。停止规则：
`posterior_conf ≥ τ_c` 或 `marginal_VOI/Joule < ρ_min` 或 `ℓ = L`。
ROI 显著性 `s(R) = E[ΔD⁺ | R] − λ_area·area(R)`，只处理 `s(R) > 0` 的区域，避免整帧大模型。

**定义 166（接地一致性校验 GCV）** 对答案 a 做三重校验：
- `G_phys`：a 隐含的接触/场景状态与力位遥测不矛盾（力上界、速度上界、滑移特征）；
- `G_scene`：`KL(π_scene^VQA ‖ π_scene^SSM) ≤ τ_KL`（与既有场景信念不能突变）；
- `G_evid`：改写/微扰下答案自洽率 `≥ τ_rep`（抑制采样幻觉）。
判定 `V(a) ∈ {ACCEPT, ESCALATE, REJECT}`。**只有 ACCEPT 能改约束**；ESCALATE 升一档保真度重问；REJECT 丢弃答案并回退第 60 轮保守编译，且**不减少 D⁺**。假设假接受率 ≤ δ_g。

**定义 167（六维预算 PCE+++++）** `B = (B_scene, B_intent, B_ros, B_exec, B_energy, B_vqa)`，其中
`B_vqa = (N_q, N_tokens, T_vqa)`。`E_res/N_res` 为不可挪用安全储备。
信息-能量价值函数：
```
voi_ei(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_energy(π)
cost_energy(π) = λ_mech·E_mech(π) + λ_comp·E_comp(π) + λ_comm·E_comm(π) + λ_th·max(0, P(π)−P_th)
```
降级顺序固定为：**热超限先砍 VQA → B_vqa 耗尽只留安全地板问题 → B_energy 低于 E_res 降保真/降通信 → B_exec 耗尽回退第 60 轮执行降级**；任何情况下安全裕度不低于 m_hard。

**定义 168（能耗-信息视觉闭环 EIVL）** 算子 `EIVL(M, intent, Δf_req)`：
```
① 观测：obs ← perceive()；D⁺ ← XMC++.uncertainty(M)
② 定价：μ*, g'(D⁺) ← EPC.shadow_price(D⁺, M)
③ 提问：Q_t ← EGVQA.generate(D⁺, π_scene, r_contact, m)
④ 调度：S, E_spent ← VQS.select(Q_t, D⁺, μ*, g', λ_s, B_rem)
⑤ 级联：for q∈S: (a, π_scene', e) ← AEG.run(obs.image, q)
⑥ 校验：if GCV.verify(a) = ACCEPT: 更新 π_scene / C_intent；elif ESCALATE: 升档重问
⑦ 编译：K^E, Cert_energy ← EPC.compile(D⁺−ΣΔD⁺, π_scene', Δf_req, E_rem)
⑧ 执行：EV-exec ← execute(K^E)；EPIR.append(EV-exec)；XMC++.fuse(EV-exec, a)
⑨ 记账：B.consume(E_spent, Cert_energy)；更新 μ* 与 D⁺
⑩ 返回：(K^E, Cert_energy, EV-exec, D⁺, B.status)
```

## 2. 关键算法伪代码

### IP-163 VQS（影子价格驱动的查询调度）

```python
class VisualQueryScheduler:
    def __init__(self, rho_min=1.0):
        self.rho_min = rho_min

    def _benefit(self, q, D_plus, mu_star, g_prime, lam_s):
        dD = q.expected_delta_D
        return mu_star * g_prime * dD + lam_s * dD

    def select(self, Q, D_plus, mu_star, g_prime, lam_s, E_rem, E_res, N_rem):
        floor = [q for q in Q if q.critical]
        rest = [q for q in Q if not q.critical]
        chosen = list(floor)
        spent = sum(q.energy_j for q in floor)
        if spent > E_rem + E_res:          # 连安全地板都付不起 -> 保守停机
            return [], spent, 'FLOOR_UNPAYABLE'
        rest.sort(key=lambda q: self._benefit(q, D_plus, mu_star, g_prime, lam_s)
                  / max(q.energy_j, 1e-9), reverse=True)
        for q in rest:
            if len(chosen) >= N_rem:
                break
            b = self._benefit(q, D_plus, mu_star, g_prime, lam_s)
            if b / max(q.energy_j, 1e-9) < self.rho_min:
                break
            if spent + q.energy_j > E_rem:
                break
            chosen.append(q)
            spent += q.energy_j
        return chosen, spent, 'OK'
```

### IP-164 EPC（能量-安全帕累托编译）

```python
class EnergyParetoCompiler:
    def compile(self, D_plus, scene_prior, delta_f_req, E_rem):
        Ks = self.eeis.enumerate(scene_prior, delta_f_req)
        feasible = [K for K in Ks if self.margin(K, D_plus) >= self.g(D_plus)]
        if not feasible:
            return None, None, 'INFEASIBLE'
        energy = {K: self.eecm.mechanical(K, self.traj_hat, self.xi_hat) for K in feasible}
        K_E = min(feasible, key=lambda K: energy[K])
        mu_star = self.shadow_price(feasible, energy, D_plus)   # KKT 对偶变量
        frontier = self.pareto(feasible, energy)
        cert = EnergyCertificate(
            E_mech=energy[K_E], E_comp=self.cascade_eta, E_comm=self.comm_eta,
            E_total=energy[K_E] + self.cascade_eta + self.comm_eta,
            mu_star=mu_star, margin=self.margin(K_E, D_plus),
            pareto_gap=self.pareto_gap(K_E, frontier),
            K_version=self.version, hash=self.digest())
        return K_E, cert, 'OK'
```

### IP-168 EIVL（闭环算子）

```python
def energy_info_visual_loop(M, intent, delta_f_req):
    obs = M.perceive()
    D_plus = M.xmc.uncertainty(M)
    mu_star, g_prime = M.epc.shadow_price_estimate(D_plus, M)

    Q_t = M.egvqa.generate_questions(D_plus, M.scene_post, M.contact_residual, M.margin)
    S, E_spent, status = M.vqs.select(
        Q_t, D_plus, mu_star, g_prime, M.lam_s,
        M.budget.E_rem, M.budget.E_res, M.budget.N_rem)

    accepted, dD_total = [], 0.0
    for q in S:
        a, scene_post, e = M.aeg.run(obs.image, q, M.scene_post)
        verdict = M.gcv.verify(a, obs.telemetry, M.scene_post, M.hard_limits)
        if verdict == 'ACCEPT':
            M.scene_post = scene_post
            M.apply_constraint(a.implied_constraint)
            accepted.append(a); dD_total += a.delta_D
        elif verdict == 'ESCALATE':
            a2 = M.egvqa.ask(obs.image, q.escalate())
            if M.gcv.verify(a2, obs.telemetry, M.scene_post, M.hard_limits) == 'ACCEPT':
                M.scene_post = a2.scene_post
                accepted.append(a2); dD_total += a2.delta_D
        # REJECT: 不更新信念、不减少 D⁺

    D_post = max(0.0, D_plus - dD_total)
    K_E, cert_energy, st = M.epc.compile(D_post, M.scene_post, delta_f_req, M.budget.E_rem)
    if st != 'OK':
        K_E, cert_energy = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.Z_env), None

    M = execute_with_evidence(M, K_E, cert_energy)
    M.xmc.fuse_plus(M, M.epir.latest(), accepted)
    M.budget.consume(E_spent, cert_energy)
    return M, K_E, cert_energy, D_post, M.budget.status()
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EGVQA | O(\|Q\|·\|ROI\|) / 决策点 | O(\|Q\|) | 问题接地率 ≥ 90%，关键问题召回 ≥ 95% |
| EECM | O(1) / 控制拍；O(\|K\|) 单次评估 | O(1) | 能耗预测相对误差 ≤ ε_E |
| VQS | O(\|Q\| log\|Q\|) 贪心；O(\|Q\|·B) DP 小规模精确 | O(\|Q\|) | 次模 (1−1/e)，安全地板精确保留 |
| EPC | O(\|K\|·iter) 凸求解 | O(\|K\|) | KKT 最优，Pareto_gap ≤ ε_P |
| AEG | O(L) 级联 | O(1) | 早退精度损失 ≤ δ_e |
| GCV | O(1) + 哈希 | O(1) | 假接受率 ≤ δ_g，硬限零突破 |
| PCE+++++ | O(1) | O(1) | 储备不变式、降级序固定 |
| EIVL | O(闭环) | 复用 | 端到端安全 + 能量不劣化 |

**正确性定理（EEVC）**：设 A66–A70 成立——
- **(A66)** EECM 相对误差有界：`|Ê_total − E_total| ≤ ε_E·E_total`；
- **(A67)** VOI 校准：`|E[ΔD⁺] − ΔD̂⁺| ≤ ε_V`，且不同问题的信息增益次模；
- **(A68)** GCV 假接受率 ≤ δ_g，且安全地板查询在储备未耗尽时必被执行；
- **(A69)** EPC 的 `E_mech` 在 K_EE 上拟凸、Slater 条件成立，影子价格估计误差 ≤ ε_μ；
- **(A70)** 六维预算单调消耗，`E_res/N_res` 不被普通任务挪用。

则：
1. **安全不变量**：任一被 ACCEPT 的 VQA 答案对安全裕度的收缩不超过 δ_m 且不低于 m_hard；REJECT/ESCALATE 失败时回退第 60 轮保守编译。因此 VQA 幻觉导致不安全约束的概率 ≤ δ_g。
2. **能量效率**：当 `ρ_min ≥ 1` 时，VQS 的期望净收益非负；EPC 给出的 K^E 满足 `E_total(K^E) ≤ E_total(K^conservative)`，且 `Pareto_gap(K^E) ≤ ε_P`。
3. **查询近似**：基数约束下贪心达到最优收益的 `(1−1/e)`；背包约束下 cost-benefit 贪心为常数近似；`F_crit` 由储备保证可行。
4. **预算安全**：任一 B 维度耗尽，按固定降级序触发对应备用策略，且安全裕度始终 ≥ m_hard。

| 实验 | 指标 | 目标 |

```python
@dataclass
class GroundedAnswer:

    text: str
    confidence: float
    roi: tuple

class ExecutionGroundedVQA:
    TEMPLATES = {
        'surface_type':  ('区域{roi}的表面材质是什么？',          'scene'),
        'liquid_present':('区域{roi}是否有液体/油污？',            'scene'),
        'grasp_axis':    ('物体{roi}的可抓取轴与摩擦面在哪里？',   'constraint'),

        'obstacle_bound':('障碍物{roi}的安全边界在哪里？',         'constraint'),

        self.vlm = vlm
        self.est = estimator
        self.delta_m = delta_m

    def generate_questions(self, D_plus, scene_post, contact_residual, margin):

        if self.est.slip_score(contact_residual) > self.tau_slip:
            qs.append(self._bind('contact_state', self.est.contact_roi(), critical=True))
        if margin < self.tau_m:
            qs.append(self._bind('obstacle_bound', self.est.margin_roi(), critical=True))
        return qs

        return GroundedAnswer(
            q_id=q.id, text=raw.text, confidence=raw.conf, roi=q.roi,
            delta_scene=raw.to_scene_delta(),
            delta_constraint=raw.to_constraint_delta(cap=self.delta_m),
```

### IP-162 EECM（执行能耗模型）

```python
class EnergyExecutionModel:
    def __init__(self, R_motor, T_max, e_tx_per_kb):
        self.R, self.T_max, self.e_tx = R_motor, T_max, e_tx_per_kb

    def mechanical(self, K, traj, xi):
        e = 0.0
        for t in traj:
            tau = traj.J[t].T @ (K.Kp * traj.err[t] + K.Kd * traj.derr[t]) + traj.tau_ff[t]
            e += (tau @ self.R @ tau + abs(tau @ traj.qdot[t])) * traj.dt
        return e

    def compute(self, cascade):
        e, survive = 0.0, 1.0
        for level in cascade.levels:
            e += survive * level.cost_j
            survive *= level.escalate_prob
        return e

    def communication(self, n_msgs, bytes_per_msg, retries):
        return n_msgs * (bytes_per_msg / 1024.0) * self.e_tx * (1 + retries)

    def total(self, K, traj, xi, cascade, comm):
        E_mech = self.mechanical(K, traj, xi)
        E_comp = self.compute(cascade)
        E_comm = self.communication(**comm)
        return {'mech': E_mech, 'comp': E_comp, 'comm': E_comm,
                'total': E_mech + E_comp + E_comm}

    def thermal_ok(self, power, dt, Q_used, Q_th):
        return Q_used + power * dt <= Q_th and power <= self.T_max
```

### IP-163 VQS（视觉查询调度）

```python
class VisualQueryScheduler:
    def __init__(self, rho_min=1.0):
        self.rho_min = rho_min

    def benefit(self, q, D_plus, mu_star, g_prime, lam_s):
        dD = q.expected_delta_D
        return mu_star * g_prime * dD + lam_s * dD

    def select(self, Q, D_plus, mu_star, g_prime, lam_s, E_rem, E_res, N_rem):
        floor = [q for q in Q if q.critical]
        rest  = [q for q in Q if not q.critical]
        chosen, spent = list(floor), sum(q.energy_j for q in floor)
        if spent > E_rem + E_res:
            return [], spent, 'FLOOR_UNPAYABLE'      # 保守停机，绝不裸奔
        rest.sort(key=lambda q: self.benefit(q, D_plus, mu_star, g_prime, lam_s)
                  / max(q.energy_j, 1e-9), reverse=True)
        for q in rest:
            if len(chosen) >= N_rem:
                break
            b = self.benefit(q, D_plus, mu_star, g_prime, lam_s)
            if b / max(q.energy_j, 1e-9) < self.rho_min:
                break
            if spent + q.energy_j > E_rem:
                break
            chosen.append(q)
            spent += q.energy_j
        return chosen, spent, 'OK'
```

### IP-164 EPC（能量-安全帕累托编译）

```python
class EnergyParetoCompiler:
    def margin(self, K, D_plus):
        return min(self.force_margin(K), self.stability_margin(K, D_plus),
                   self.thermal_margin(K), self.track_margin(K, D_plus))

    def compile(self, D_plus, scene_prior, delta_f_req, E_rem):
        Ks = self.eeis.enumerate(scene_prior, delta_f_req)
        feasible = [K for K in Ks if self.margin(K, D_plus) >= self.g(D_plus)]
        if not feasible:
            return None, None, 'INFEASIBLE'
        energy = {K: self.eecm.mechanical(K, self.traj_hat, self.xi_hat) for K in feasible}
        K_E = min(feasible, key=lambda K: energy[K])
        mu_star = self.shadow_price(feasible, energy, D_plus)   # KKT 对偶变量
        frontier = self.pareto(feasible, energy)
        cert = EnergyCertificate(
            E_mech=energy[K_E], E_comp=self.cascade_eta, E_comm=self.comm_eta,
            E_total=energy[K_E] + self.cascade_eta + self.comm_eta,
            mu_star=mu_star, margin=self.margin(K_E, D_plus),
            pareto_gap=self.pareto_gap(K_E, frontier),
            K_version=self.version, hash=self.digest())
        return K_E, cert, 'OK'

    def shadow_price(self, feasible, energy, D_plus):
        # 对偶可行性：μ* = −∂V/∂g；无解析式时用相邻 g 的有限差分
        g0 = self.g(D_plus)
        V1 = min(energy[K] for K in feasible if self.margin(K, D_plus) >= g0)
        V2 = min(energy[K] for K in feasible if self.margin(K, D_plus) >= g0 + self.dg)
        return max(0.0, (V2 - V1) / self.dg)
```

```python
class AdaptiveEnergyGate:
    def __init__(self, levels, tau_conf, rho_min):
        self.levels, self.tau_conf, self.rho_min = levels, tau_conf, rho_min

    def trigger(self, ev):
        return (ev.kappa_scene > self.tau_k or ev.contact_residual > self.tau_r
                or ev.D_plus > self.tau_D or ev.margin < self.tau_m)

    def run(self, image, q, prior):
        if not self.trigger(q.ev):
            return None, prior, 0.0, 'NO_TRIGGER'
        post, spent, ans = prior, 0.0, None
        for l, level in enumerate(self.levels):
            if not self.roi_is_informative(image, q.roi, level):
                continue
            ans = level.infer(image, q, roi=q.roi)
            spent += level.cost_j
            post = self.bayes_update(post, ans)
            if post.conf >= self.tau_conf:
                return ans, post, spent, 'CONFIDENT'
            if self.marginal_voi_per_joule(post, q) < self.rho_min:
                return ans, post, spent, 'LOW_VOI'
        return ans, post, spent, 'MAX_FIDELITY'
```

### IP-166 GCV（接地一致性校验）

```python
class GroundingConsistencyVerifier:
    def verify(self, ans, telemetry, scene_post, hard_limits):
        if ans is None:
            return 'REJECT'
        if not self.physically_consistent(ans, telemetry):
            return 'REJECT'                       # 力/速度/滑移特征矛盾
        if self.kl_scene(ans.delta_scene, scene_post) > self.tau_KL:
            return 'REJECT'                       # 与 SSM 先验突变
        if self.self_consistency(ans) < self.tau_rep:
            return 'ESCALATE'                     # 采样不稳定，升档重问
        if self.contraction(ans, hard_limits) > self.delta_m:
            return 'ESCALATE'                     # 试图过度收紧安全裕度
        return 'ACCEPT'

    def contraction(self, ans, hard_limits):
        target = self.apply(ans.delta_constraint, hard_limits)
        return max(0.0, hard_limits.margin - target.margin)
```

```python
class EnergyInfoBudget:
    def __init__(self, B_scene, B_intent, B_ros, B_exec, B_energy, B_vqa,
                 E_res, N_res):
        self.B_scene, self.B_intent, self.B_ros = B_scene, B_intent, B_ros
        self.B_exec, self.B_energy, self.B_vqa = B_exec, B_energy, B_vqa
        self.E_res, self.N_res = E_res, N_res
        self.thermal_ok = True

    def mode(self):
        if not self.thermal_ok:
            return 'SHED_VQA'                 # 热优先：先砍计算
        if self.B_vqa.N_q <= self.N_res:
            return 'FLOOR_ONLY'               # 只保留安全地板问题
        if self.B_energy.remaining <= self.E_res:
            return 'LOW_ENERGY'               # 降保真/降通信，不动安全裕度
        if self.B_exec.exhausted:
            return 'EXEC_FALLBACK'            # 回退第 60 轮执行降级
        return 'NORMAL'

    def consume(self, E_spent, cert_energy):
        self.B_vqa.N_q -= self._queries_used
        self.B_energy.remaining -= (E_spent + cert_energy.E_total)
        self._assert_reserve_invariant()

    def _assert_reserve_invariant(self):
        assert self.E_res >= 0 and self.N_res >= 0
```

### IP-168 EIVL（能耗-信息视觉闭环）

```python
def energy_info_visual_loop(M, intent, delta_f_req):
    obs = M.perceive()
    D_plus = M.xmc.uncertainty(M)
    mu_star, g_prime = M.epc.shadow_price_estimate(D_plus, M)

    Q_t = M.egvqa.generate_questions(D_plus, M.scene_post, M.contact_residual, M.margin)
    S, E_spent, status = M.vqs.select(
        Q_t, D_plus, mu_star, g_prime, M.lam_s,
        M.budget.B_energy.remaining, M.budget.E_res, M.budget.B_vqa.N_q)
    if status == 'FLOOR_UNPAYABLE':
        return M.eeis.compile_conservative(delta_f_req), None, D_plus, 'SAFE_STOP'

    accepted, dD_total = [], 0.0
    for q in S:
        a, scene_post, e, st = M.aeg.run(obs.image, q, M.scene_post)
        verdict = M.gcv.verify(a, obs.telemetry, M.scene_post, M.hard_limits)
        if verdict == 'ACCEPT':
            M.scene_post = scene_post
            M.apply_constraint(a.delta_constraint)
            accepted.append(a); dD_total += a.delta_D
        elif verdict == 'ESCALATE':
            a2 = M.egvqa.ask(obs.image, q.escalate())
            if M.gcv.verify(a2, obs.telemetry, M.scene_post, M.hard_limits) == 'ACCEPT':
                M.scene_post = a2.scene_post
                M.apply_constraint(a2.delta_constraint)
                accepted.append(a2); dD_total += a2.delta_D
        # REJECT: 不更新信念、不减少 D⁺，保持保守

    D_post = max(0.0, D_plus - dD_total)
    K_E, cert_energy, st = M.epc.compile(
        D_post, M.scene_post, delta_f_req, M.budget.B_energy.remaining)
    if st != 'OK':
        K_E, cert_energy = M.eeis.compile(
            delta_f_req, M.fused, M.xi_exec, M.Z_env), None

    M = execute_with_evidence(M, K_E, cert_energy)
    M.epir.append(M.last_ev_exec)
    M.xmc.fuse_plus(M, M.last_ev_exec, accepted)
    M.budget.consume(E_spent, cert_energy)
    return M, K_E, cert_energy, D_post, M.budget.mode()
```

1. **安全不变量**：VQA 对安全裕度的收缩 ≤ δ_m 且 ≥ m_hard；REJECT/ESCALATE 失败回退第 60 轮保守编译，故 VQA 幻觉引发不安全约束的概率 ≤ δ_g。
2. **能量效率**：`ρ_min ≥ 1` 时 VQS 期望净收益非负；`E_total(K^E) ≤ E_total(K^conservative)` 且 `Pareto_gap ≤ ε_P`。
3. **查询近似**：基数约束贪心达 `(1−1/e)`；背包约束 cost-benefit 贪心为常数近似；`F_crit` 由 `E_res/N_res` 保证可行。
4. **预算安全**：任一预算耗尽按固定序降级，安全裕度始终 ≥ m_hard。

**证明要点**：(1) 由 GCV 三态与 γ 的收缩上限直接得；REJECT 分支不改 π_scene、不减 D⁺，故回退路径与第 60 轮等价。(2) 由 V(D⁺) 对 g 的单调性与包络定理，EPC 的 KKT 点在全可行域最优；VQS 的阈值规则保证每笔支出 benefit ≥ E_cost。(3) 互信息在问题集上次模，标准贪心界；安全地板从储备支付，不受背包约束影响。(4) 由 A70 的单调性与降级序归纳。

## 5. 与既有轮次的衔接

- **对第 60 轮**：`SSM` 的 π_scene 新增 VQA 接地更新通道；`CIEC` 的意图约束可由 `contact_state` 问题交叉验证；`SERC` 的闭环升级为 `EIVL`，多一层「能量-信息」记账；`EPIR` 的 EV-exec 增加 `evidence_hash` 以绑定 VQA 证据。
- **对第 59 轮**：`J_exec` 执行证书旁增 `Cert_energy`，形成「执行合规 + 能耗可核」双证书；`PCE+++` 的预算升级为 `PCE+++++`。
- **对 UniBot 场景**：直接落到「电池供电移动操作 + 边缘/云端 VLM」；事件触发 VQA 与 ROS 2 lifecycle 节点天然对齐；安全查询储备可在电量低时仍保证危险问题不被裁掉。

## 6. 本轮最大风险

**一句话**：视觉问答的幻觉成本极低而安全代价极高，能耗优化又天然激励系统少看，最终可能以「能耗最优、证据链完整」的姿态买到错误信息并自信地收敛到错误阻抗——必须以安全查询储备、影子价格 VOI、跨模态接地校验与语义收缩上限四重护栏，保证「省电」永远不能越过「物理硬限」。
