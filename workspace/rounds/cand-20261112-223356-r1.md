# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；新灵感循环第 1 轮；本轮灵感：「目标检测」×「世界模型」）

> 第 61 轮用 USR×MEL×DMS×SRT-Dual×PCE+++++ 把场景、意图、阻抗、证据统一到共享嵌入空间 ℝ^d_us，并以语义-实时双流解耦大模型推理与 1kHz 控制。但回看「感知→执行」链路，仍有五个根本性缺口：
> 1. **检测被压成一次全局池化**：MEL 的 ViT 编码器输出 scene_emb，本质是「图像块特征的全局池化」，没有显式的物体假设集——没有存在性概率、位姿协方差、遮挡状态、开放词汇任务相关性；遮挡/反光/透明物体下，检测要么漏检，要么给出无协方差的自信框，无法进入 USR 的贝叶斯更新。
> 2. **系统只会「反应」，不会「预演」**：ESEC 依据当前观测生成先验并执行，缺少「如果我这样施加阻抗，接下来会发生什么」的动作条件预测；接触瞬态、滑移、碰撞、物体被推走只能在发生后由 EV-exec 触发 EFGP 补救，属于事后反应而非事前预判。
> 3. **检测与世界模型没有互相校正**：检测是瞬时、无记忆的测量，世界模型是时序、可外推的预测；缺少「预测-测量」新息对账，导致世界模型漂移无人发现（幻觉被当真）、检测漏检时无物体永久性推断（把杯子当成消失）、二者冲突时不知道信谁。
> 4. **语义锚点是「点」不是「管」**：SRT-Dual 只在低频语义流写入一个静态 anchor，实时流在两次更新之间只能保守扩展；无法表达「未来 200ms 内接触力/位姿的可行包络」，大模型延迟期间控制只能变保守，错失动态任务的窗口。
> 5. **反事实能力没有进入对话与证书**：DMS 的澄清/协商依赖规则触发（滑移、振动、力超限），无法用「如果当时把 K_p 降到 0.7 倍会怎样」的反事实证据解释决策、说服用户或验证约束；J_sem_exec 也不包含「预测是否被测量支持」的证书。

## 0. 直觉与动机

**灵感 1（目标检测 → 任务条件接触中心检测器 TCD）**
直觉：检测的价值不是画出框，而是产生可进入贝叶斯更新的「接触中心测量包」：开放词汇类别、掩码、SE(3) 位姿、尺寸、存在概率、位姿协方差、遮挡状态、可供性与接触相关性。关键洞见：检测必须「任务条件化」以缩小假设空间，但必须保留一条「任务无关的安全头」——专门看边缘、缝隙、透明物、运动物、形变物等负障碍；前者可被预算裁剪，后者不可。这个非对称性是安全的第一道保险。

**灵感 2（目标检测 → 概率物体假设集 POH）**
直觉：单个 argmax 检测在遮挡和杂乱场景里是一个谎言。维护概率物体假设集：每个假设带存在概率、位姿协方差、速度、遮挡状态、最后观测时刻与来源；世界模型给先验，检测给似然，贝叶斯更新得到后验。物体被遮挡时不是「消失」，而是存在概率缓慢衰减、位姿协方差随时间增长；这给抓取中的「杯子被手挡住」提供物体永久性。

**灵感 3（世界模型 → 潜空间动作条件世界模型 LAWM）**
直觉：世界模型不是视频生成器，而是「动作条件的潜在预测器」：输入当前潜在状态 z_t 与候选阻抗动作 a_t，预测未来接触力、物体位姿、失败概率与认知不确定性。它只在语义流/想象流中运行，绝不进入 1kHz 实时环；它输出的是分布而非真值，必须用集成方差显式表达「我不知道」。

**灵感 4（互为校正 → 检测-世界模型互校正 DWMC 与「只收紧不放松」安全门 ISG）**
直觉：检测短视但接地，世界模型远视但会幻觉，二者应互为校正：预测-测量新息大 ⇒ 模型漂移，触发潜在重置；检测无预测支持 ⇒ 惊喜，按安全优先级处理。最关键的安全非对称：世界模型只能用来「否决/收紧」动作，不能用来「授权/放松」动作。形式化为 ISG：𝒦_adm ⊆ 𝒦_det ∩ 𝒦_hard。于是幻觉最多让系统更保守或任务失败，不会直接造成力/速度越界。

**灵感 5（世界模型 → 预测锚点管 PAT 与反事实诊断对话 CFD）**
直觉：用「预测锚点管」替代静态锚点：世界模型在提交时预计算未来 H 步的时间索引安全包络，实时流按当前时刻取切片，从而把 200ms 的语义延迟变成「管内的预测推进」。同一套反事实 rollout 还能为 DMS 生成可验证解释：「若 K_p=0.7×，预测滑移概率从 0.62 降到 0.12，支持度 0.91」；但只有当反事实可信度 CFR 足够高时才允许断言，否则必须说「不确定」并请求澄清。

**灵感 6（合流 → 检测-世界模型具身闭环 DWEC）**
直觉：把 TCD、POH、LAWM、DWMC、PAT、ISG、CFD 嵌入 ESEC，形成「检测-想象-执行」闭环：检测-想象流（10–30Hz）维护物体假设与预测管；语义流（5–30Hz）运行 MEL/DMS/CFD；实时流（1–10kHz）只消费管切片与 O(1) 安全门；执行证据反向校准检测器与世界模型。核心命题：感知不是为语义提供一个静态输入，而是为控制提供「被测量锚定、被想象预演、被安全门裁剪」的时序先验。

## 1. 形式化定义（增量：定义 173–186）

**定义 173（任务条件接触中心检测器 TCD）** TCD = (Θ_det, Q_task, Q_safe, Head_exist, Head_pose, Head_unc, Head_aff)。给定多视角 RGB-D 观测 I_t、任务查询 q_task = E_intent(b_intent)、世界模型候选 B_wm，输出检测集 Y_t = {y_i}：
- **测量包**：y_i = (c_i ∈ C_open, m_i, T_i ∈ SE(3), b_i ∈ ℝ³, p_i ∈ (0,1), Σ_i ∈ Sym⁺(6), o_i ∈ {visible, partial, occluded}, a_i ∈ [0,1]^A, r_i ∈ [0,1])，其中 p_i 为存在概率，Σ_i 为位姿协方差，o_i 为遮挡状态，a_i 为可供性，r_i 为与当前任务的接触相关性。
- **双头非对称**：Q_task 由 q_task 条件化，做开放词汇高分辨率检测，可被 B_det 裁剪；Q_safe 为任务无关安全头，固定查询「边缘/缝隙/透明/高反/运动/形变」等负障碍，拥有独立保留预算与召回下限 r_min，**永不被任务相关性裁剪**。
- **校准要求**：存在概率 ECE(p) ≤ ε_cal；位姿协方差保守 Σ_i ⪰ Σ_true；安全头召回 ≥ r_min；输出的是测量分布 p(y_i | s_t)，不是标签。
- **接触相关性**：r_i = cos(E_det(y_i), E_intent(q_task))，E_det 与 USR 共享嵌入空间。

**定义 174（概率物体假设集 POH）** H_t = {h^i_t}，h^i = (id_i, c_i, T_i, Σ_i, e_i, v_i, o_i, last_seen_i, provenance_i)：
- **先验**：H_t^- = WM.predict(H_{t-1}, a_{t-1})，对未被观测的假设做常速度外推，Σ_i ← Σ_i + Q_proc·Δt（协方差随时域增长）。
- **存在性更新**：e_i^+ = σ(logit(e_i^-) + log[p(y_t | h_i) / p(y_t | ¬h_i)])；未匹配假设按 e_i^+ = γ_d·e_i^- 衰减（γ_d≈0.98/帧），不立即删除。
- **位姿更新**：对匹配检测做 EKF/粒子更新；位姿协方差叠加检测协方差，保持 Σ_i ⪰ Σ_true。
- **物体永久性**：遮挡时 e_i 缓慢衰减、Σ_i 增长；再次被观测时按新息重置协方差，但保留 track_id 防止身份切换。
- **接触相关子集**：H^c_t = {h ∈ H_t : e_i ≥ e_min ∧ r_i ≥ r_min}，只有 H^c_t 进入 USR 与控制先验。

**定义 175（潜空间动作条件世界模型 LAWM）** LAWM = (Enc, Trans, Dec_o, Dec_c, Head_fail, Ens)：
- **潜在状态**：z_t = Enc(o_t, H^c_t) ∈ ℝ^{d_z}；动作 a_t = (K_p, K_d, F_max, Δx_des) 或潜动作。
- **转移**：z_{t+1} ~ p_θ(z_{t+1} | z_t, a_t)；观测/接触解码：p(o_{t+1} | z_{t+1})，p(F_{t+1}, T_{t+1} | z_{t+1})。
- **失败头**：p_fail^{(k)}(z_t, a_{t:t+τ}) 分别预测滑移、碰撞、力超限、掉落；聚合 p_fail(τ) = 1 − ∏_k (1 − p_fail^{(k)})。
- **集成不确定性**：Ens = {θ_m}_{m=1..M}，认知不确定性 U_wm = Var_m(ẑ, F̂, p̂_fail)，偶然不确定性由解码器方差给出。
- **Rollout**：R(z_t, a_{t:t+H}) = {(ẑ_{t+τ}, F̂_{t+τ}, p̂_fail(τ), U_{t+τ})}_{τ=0..H}；只作为分布使用，不作为真值。
- **训练**：ELBO + 接触力/位姿重建损失 + 失败分类损失 + 校准损失（PIT / ECE），并用域随机化覆盖未见材质与动力学。

**定义 176（预测-测量新息与检测-世界模型互校正 DWMC）** 对每个 WM 预测物体 i 与检测 j：
- **新息**：ν_ij = y_j − ŷ_i，S_ij = Σ_i^wm + Σ_j^det，d²_ij = ν_ijᵀ S_ij⁻¹ ν_ij。
- **支持度**：s_i = max_j [ IoU(m_i, m_j) · exp(−d²_ij/2) · p_j ]；幻觉分 h_i = 1 − s_i；惊喜分 u_j = 1 − max_i support(i→j)。
- **信任**：β_t = σ(α_0 + α_1·mean(s) − α_2·mean(d²) − α_3·hallucination_rate) ∈ [0,1]。
- **仲裁规则（测量优先）**：
  1. 支持度 s_i < s_min 的预测为「无支撑」，**不得作为控制先验**；仅可作为遮挡假设保留，且 Σ_i 放大；
  2. 惊喜分 u_j > u_surprise 的检测为「意外测量」，安全头命中的负障碍按真实处理并立即收紧控制，普通物体则新建假设；
  3. 连续 k 帧 d² > χ²_{1−α} ⇒ 触发「现实鸿沟告警」，重置 WM 潜在状态、放大所有协方差、触发重检测；
  4. β < β_min ⇒ 世界模型降级为「仅解释」，控制回退到检测/物理保守集。

**定义 177（预测锚点管 PAT）** 在语义提交时刻 t0，LAWM + ISG 生成时间索引的安全管：
```
𝒯_{t0} = { (τ, 𝒦_set(τ), F_env(τ), Σ_tube(τ), support(τ), valid(τ)) : τ ∈ [0, H] }
```
- 𝒦_set(τ) 为 τ 时刻经 ISG 认证的阻抗集合；F_env(τ) 为接触力包络；Σ_tube(τ) 为管不确定性，要求 ρ(τ) = √tr(Σ_tube(τ)) 单调不减，support(τ) 期望单调不增。
- **实时切片**：t 时刻取 τ = t − t0；若 τ ≤ H ∧ valid(τ) ∧ support(τ) ≥ s_min，则 K_safe(t) = argmax_{K ∈ 𝒦_set(τ)} U_task(K) 再按 Σ_tube(τ) 保守膨胀；否则用上一有效切片 + 保守扩展。
- **破管（breach）**：实测力/位姿落在 F_env(τ)/预测位姿管之外 ⇒ 立即切换到安全回退核 K_⊥，触发语义流重算并记录 breach，绝不继续沿管外推。

**定义 178（反事实风险 WCR 与想象安全门 ISG）** 对候选阻抗 K：
- **反事实风险**：用 M 条集成 rollout 得 R_K = {r^(m)}，r 含滑移/力超限/掉落/碰撞/任务进度；risk 用 CVaR_α(R_K) 与安全概率 P_safe(K) = (1/M)Σ_m 1[无违规] 表示。
- **认证集**：𝒦_det 为由检测/POH/物理下界认证的安全阻抗集；𝒦_hard 为 ERTC 硬约束；𝒦_wm = {K ∈ 𝒦_det ∩ 𝒦_hard : P_safe(K) ≥ 1−δ ∧ CVaR_α(K) ≤ ε}。
- **想象安全门 ISG**：
```
if β_t ≥ β_min:  𝒦_adm = 𝒦_wm
else:            𝒦_adm = 𝒦_det ∩ 𝒦_hard           # WM 只解释，不参与收紧
if 𝒦_adm = ∅:    K_safe = K_⊥                       # 安全回退核，必须非空
else:            K_safe = argmax_{K ∈ 𝒦_adm} U_task(K)
```
- **只收紧不放松**：恒有 𝒦_adm ⊆ 𝒦_det ∩ 𝒦_hard；世界模型只能删元素，不能加元素。K_⊥ 为预认证的「低刚度、高阻尼、低力限」动作，由检测/物理界保证安全。
- **非空假设**：K_⊥ ∈ 𝒦_det ∩ 𝒦_hard；若该假设不成立（检测本身失效），系统必须 abort，而不是继续想象。

**定义 179（反事实诊断对话 CFD）** 给定已执行动作 K 与候选 K'：
- **反事实查询**：do(K=K') 的 rollout 给出 Δp_fail = p̂_fail(K') − p̂_fail(K)，ΔF_env 与任务进度变化。
- **反事实可信度 CFR**：CFR(K') = support(K') · exp(−U_wm/σ_wm) · 1[K' ∈ 训练动作支撑集]。
- **断言门**：仅当 CFR ≥ c_min 时，DMS 才允许生成带区间的反事实解释；否则只能表达「无法可靠预测」并请求澄清/探针。
- **动作扩展**：A += {explain_counterfactual, propose_constraint_from_cf, ask_preference, request_probe}；解释必须附带 support、U_wm、CFR 与预测区间，进入 B_diag 审计。

**定义 180（世界模型增强的统一语义空间 USR^wm）** USR^wm = (E_scene, E_det, E_wm, E_intent, E_impedance, E_evidence, Π, Anchor^wm)：
- **物体编码**：object_emb = E_det(H^c_t)，含存在性、位姿协方差与遮挡状态。
- **世界模型摘要**：WM_summary = (F_env, p_fail, U_wm, support, β) ∈ ℝ⁶；只把低维风险摘要送入 USR，不把高维潜变量塞进实时环。
- **锚点扩展**：Anchor^wm = (scene_emb, object_emb, intent_emb, phys_prior, U_mel, WM_summary, tube_id, tube_version, det_version, wm_version, timestamp, version, checksum)。
- **投影与安全分离**：K_prior = Π(scene_emb ⊕ object_emb ⊕ intent_emb ⊕ WM_summary) 只是**提案**；实际 K_safe 必须再过 ISG 与 EEIS 编译，投影头不能绕过安全门。

**定义 181（检测-世界模型具身闭环 DWEC）** 三条异步流水线 + 一条校准回路：
- **检测-想象流**（10–30Hz）：obs → TCD(Q_task + Q_safe) → POH.update → LAWM.rollout → DWMC.arbitrate → PAT.commit；写入 object_emb、WM_summary、tube。
- **语义流**（5–30Hz）：MEL.infer(..., object_emb, WM_summary) → DMS/CFD（反事实解释与协商）→ USR^wm.commit；必要时请求探针。
- **实时流**（1–10kHz）：读 PAT 切片 → Π 投影 → ISG 裁剪 → EEIS.compile → ERTC.dispatch → EV_exec → 回写 POH/LAWM 校准。
- **校准回路**（0.01–1Hz）：用 EV_exec 校准检测器（ECE/协方差）与 LAWM（PIT/集成方差），更新 β_min、s_min、χ² 阈值；校准结果写入 J_dw。
- **一致性**：det_version、wm_version、tube_version、anchor_version 单调递增；管过期用保守扩展；破管立即 K_⊥；世界模型与检测器任一失准时，安全门不降级。

**定义 182（八维认知-检测-想象预算 PCE+++++++ / B_cog8）** 在第 61 轮六项预算上新增 B_det、B_wm：
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_det, B_wm)
B_det = (resolution, N_proposals, open_vocab_queries, safe_head_freq, safe_head_reserve)
B_wm  = (rollout_horizon H, ensembles M, latent_dim d_z, rollout_freq, imagination_budget)
cost_det = λ_res·(1/res) + λ_prop·N_prop/N_max + λ_q·q/q_max
         + λ_safe·1[safe_head skipped]        # 跳过安全头代价 = +∞
cost_wm  = λ_H·H/H_max + λ_M·M/M_max + λ_f·f/f_max + λ_z·d_z/d_z,max
voi_cog8 = VOI_meta − cost_mel − cost_usr − cost_det − cost_wm − cost_exec

- **降级链（安全项永不降级）**：B_wm 耗尽 ⇒ 全集成→单模型→短视界→关闭 rollout（退化为第 61 轮静态锚点 + 保守扩展）；B_det 耗尽 ⇒ 降分辨率/减 proposal/减开放词汇查询，但 **Q_safe 保留预算与频率不变**；若连安全头都无法维持，则强制降低速度/力上限并缩短任务视界。
- **VOI 门控**：是否做一次额外 rollout / 额外检测查询，由 voi_cog8 ≥ 0 决定；安全头与 ISG 不计入可裁剪成本。

**定义 183（检测-世界模型对账 XMC-dw）** 在 USR^wm 空间做「预测-测量-执行」三方对账：
```
D_dw = λ1·(1 − mean(support)) + λ2·mean(d²) + λ3·hallucination_rate
     + λ4·surprise_rate + λ5·ECE_det + λ6·|P_safe^pred − 1[EV 无违规]|
```
- D_dw > τ_dw 时按主导项分流：support 低 ⇒ 模型漂移，重置 WM 潜在；surprise 高 ⇒ 检测异常，重检测/安全优先；ECE 高 ⇒ 检测器失准，扩大 Σ 并降低 r_i；预测-执行偏差高 ⇒ 现实鸿沟，强制保守。
- 与第 61 轮 XMC+++ 的语义对账 D⁺_sem 并联：语义、几何、预测三层对账共同决定是否重推理/重检测/重规划。

**定义 184（检测-世界模型-执行联合证书 J_dw）** 扩展第 61 轮 J_sem_exec：
```
J_dw = (J_sem_exec, det_version, wm_version, tube_version,
        support_min, innovation_p95, hallucination_rate, surprise_rate,
        ECE_det, P_safe_cf, CFR_cf, tube_coverage, breach_flag, beta_min_seen)
Valid(J_dw) ⇔ Valid(J_sem_exec)

其中 P_safe_cf 为反事实 rollouts 的安全概率，CFR_cf 为对应可信度；任何一项不满足即拒绝签发证书，控制只能走 K_⊥。

**定义 185（世界模型幻觉安全分离 WMHB）** 在测量优先 + ISG + 非空安全回退核下，对任意世界模型输出（包括对抗性幻觉）：
```
K_safe ∈ 𝒦_det ∩ 𝒦_hard  或  K_safe = K_⊥
```

**定义 186（反事实可信度与断言门 CFR）** 对反事实动作 K'：
```
CFR(K') = support(K') · exp(−U_wm(K')/σ_wm) · 1[K' ∈ supp(D_train)] · 1[|Δrisk| ≥ Δ_min]
```
- CFR ≥ c_min：允许 DMS 断言「若…则…」，并给出预测区间与证书哈希；

class LatentActionWorldModel:
    def __init__(self, d_z=128, d_a=8, M=5, H=16):
        self.enc = LatentEncoder(d_z)
        self.trans = ActionConditionedTransition(d_z, d_a)
        self.dec_o = ObservationDecoder()
        self.dec_c = ContactDecoder()                 # 力/位姿
        self.head_fail = FailureHead(n_kinds=4)       # slip/collision/force/drop
        self.ensemble = [copy.deepcopy(self) for _ in range(M)]
        self.d_z, self.H = d_z, H

    def encode(self, obs, Hc):
        return self.enc(obs.images, obs.depth, obs.proprio, Hc)

    def rollout(self, z0, actions):
        # actions: [a_0, ..., a_{H-1}]，a 为阻抗/运动命令
        rollouts = []
        for model in self.ensemble:
            z = z0
            traj = []
            for tau, a in enumerate(actions):
                z = model.trans.sample(z, a)
                F, T = model.dec_c(z)
                p_fail = model.head_fail(z, a)
                traj.append(RolloutStep(tau, z, F, T, p_fail))
            rollouts.append(traj)
        # 集成统计：均值 + 认知不确定性（保守取上分位）
        return aggregate(rollouts, conservative=True)

    def risk(self, K, z0, H):
        # 候选阻抗 K 的反事实 rollout：返回 CVaR 与安全概率
        actions = expand_impedance_to_actions(K, H)
        R = self.rollout(z0, actions)
        violations = [any(step.p_fail > TAU_FAIL for step in traj)
                      for traj in R.members]
        P_safe = 1.0 - np.mean(violations)
        losses = [self.loss(traj) for traj in R.members]
        cvar = mean(sorted(losses)[-max(1, int(ALPHA * len(losses))):])
        return P_safe, cvar, R.uncertainty

class ImaginationSafetyGate:
    def __init__(self, wm, alpha=0.1, delta=0.05, eps=0.01,
                 beta_min=0.6, margin_extra=1.2):
        self.wm = wm
        self.alpha, self.delta, self.eps = alpha, delta, eps
        self.beta_min, self.margin_extra = beta_min, margin_extra

    def admissible_set(self, z, K_det, K_hard, wm, beta=1.0):
        # K_det 由检测/POH/物理下界给出，且恒有 K_det ⊆ K_hard
        base = intersect(K_det, K_hard)
        if beta < self.beta_min:
            # WM 不可信：只解释，不参与收紧；额外安全裕度
            return tighten(base, factor=self.margin_extra)
        wm_set = []
        for K in base:
            P_safe, cvar, U = wm.risk(K, z, H=wm.H)
            if P_safe >= 1 - self.delta and cvar <= self.eps:
                wm_set.append(K)
        # 只收紧不放松：一定是 base 的子集
        return intersect(base, wm_set)

    def filter(self, K_prior, z, tube_stage, K_det, K_hard, K_fallback):
        adm = self.admissible_set(z, K_det, K_hard,
                                  self.wm, beta=tube_stage.beta)
        if K_prior in adm:
            return K_prior
        if adm:
            return argmax_utility(adm)
        return K_fallback                              # 非空安全回退核

### IP-189 CFD（反事实诊断对话）

```python
class CounterfactualDialogueDiagnosis:
    def __init__(self, c_min=0.7, sigma_wm=0.5, delta_min=0.05):
        self.c_min, self.sigma_wm, self.delta_min = c_min, sigma_wm, delta_min

    def cfr(self, K_prime, support, U_wm, in_support, delta_risk):
        return (support * np.exp(-U_wm / self.sigma_wm)
                * float(in_support) * float(abs(delta_risk) >= self.delta_min))

    def explain(self, K_exec, K_prime, wm, z, support):
        p0, _, _ = wm.risk(K_exec, z)
        p1, cvar, U = wm.risk(K_prime, z)
        delta = p1 - p0
        cf = self.cfr(K_prime, support, U, in_support=True, delta_risk=delta)
        if cf < self.c_min:
            return DialogueAction('ask_clarify',
                                  question='我无法可靠预测该改动，建议先做一次低风险探针，确认？',
                                  evidence={'CFR': cf})
        text = (f'若将 K 调整为 {K_prime}，预测滑移概率 '
                f'{p0:.2f}→{p1:.2f}（区间 [{p1 - U:.2f},{p1 + U:.2f}]），'
                f'支持度 {support:.2f}，CFR {cf:.2f}。')
        return DialogueAction('explain_counterfactual', text=text,
                              evidence={'CFR': cf, 'U_wm': U, 'CVaR': cvar})

        self.B_det = DetBudget(det_points, proposals, queries,

        self.B_wm = WMBudget(H, M, d_z)
        self.det_mode = 'full'       # full / low_res / task_only / frozen
        self.wm_mode = 'full'        # full / single / short / off

    def can_detect(self, use_safe_head=False):
        return (self.B_det.safe_left > 0 if use_safe_head
                else self.B_det.left > 0)

    def can_rollout(self):
        return self.B_wm.left > 0 and self.wm_mode != 'off'

    def degrade(self):
        # 安全头永不降级；仅裁剪任务头与世界模型
        if self.B_det.exhausted:
            self.det_mode = 'low_res'
            self.B_det.proposals = max(10, self.B_det.proposals // 2)
            if self.B_det.exhausted:
                self.det_mode = 'task_only'
        if self.B_wm.exhausted:
            self.wm_mode = 'single' if self.wm_mode == 'full' else \
                           'short' if self.wm_mode == 'single' else 'off'
        # 若连安全头都难以维持：降低速度/力上限，缩短视界
        if self.B_det.safe_left <= 0:
            self.global_speed_cap = 0.5
            self.global_force_cap *= 0.7

    def voi_cog8(self, action):
        return (self.voi_meta_pessimistic(action)
                - self.cost_mel(action) - self.cost_usr(action)
                - self.cost_det(action) - self.cost_wm(action)
                - self.cost_exec(action))
```

def build_Jdw(cert_exec, dw_stats, det_stats, tube, wm_stats,

### IP-192 DWEC（检测-世界模型具身闭环）

```python
def DWEC(robot, obs, L, delta_f_req):
    # ---------------- 检测-想象流 10-30Hz ----------------
    q_task = robot.usr.intent_query(L, robot.dms.b_intent)
    H_prior = robot.poh.predict(robot.dt, robot.lawm, robot.last_action)
    Y = robot.tcd.detect(obs, q_task, proposals=H_prior.proposals())
    Hc = robot.poh.update(Y, robot.dwmc)
    z = robot.lawm.encode(obs, Hc)
    dw_stats = robot.dwmc.arbitrate(H_prior, Y, robot.wm_sigma)
    if robot.dwmc.pending_reset:
        z = robot.lawm.encode(obs, Hc)                # 潜变量重置
        robot.dwmc.pending_reset = False
    tube = robot.pat.build(now(), z, Hc, robot.lawm, robot.isg,
                           robot.det_bounds(Hc), robot.hard_bounds)
    robot.usr.commit_wm(Hc, z, dw_stats, tube)

    # ---------------- 语义流 5-30Hz ----------------
    phi, z_scene, pi, U = robot.mel.infer(
        obs.V, obs.T, obs.P, L,
        robot.usr.object_emb(Hc), robot.usr.wm_summary(tube, dw_stats))
    a_diag, C_pending, b_intent = robot.dms.step(
        U, dw_stats, robot.cfd, robot.usr.wm_summary(tube, dw_stats))
    if a_diag.type in ('explain_counterfactual', 'propose_constraint_from_cf'):
        robot.dms.audit(a_diag, cf=robot.cfd.last_certificate)

    # ---------------- 实时流 1-10kHz ----------------
    stage = robot.pat.slice(now(), tube, robot.last_stage)
    if stage is None:
        K_safe = robot.K_fallback                     # 非空安全回退核
    else:
        K_prior = robot.usr.project_wm(robot.usr.anchor, stage)
        K_safe = robot.isg.filter(K_prior, z, stage,
                                  robot.det_bounds(Hc),
                                  robot.hard_bounds,
                                  robot.K_fallback)
        K_safe = robot.eeis.compile_with_prior(
            delta_f_req, K_safe, stage.F_env, phi)

    cert = robot.ertc.dispatch(K_safe)
    EV = robot.wait_contact()
    if tube.breached(EV):
        robot.pat.mark_breach(tube)
        robot.dwmc.request_recompute()
        K_safe = robot.K_fallback
        cert = robot.ertc.dispatch(K_safe)

    # ---------------- 校准回路（低频） ----------------
    robot.poh.update_from_evidence(EV)
    robot.lawm.calibrate(EV)                          # PIT / 集成方差
    robot.tcd.calibrate(EV)                           # ECE / 协方差
    J = build_Jdw(cert, dw_stats, robot.tcd.stats(), tube,
                  robot.lawm.stats(), robot.cfd.stats(), EV, K_safe)
    return K_safe, EV, J
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TCD | 骨干 O(N_pix·d)；双头 O(N_q·d) | 骨干 + proposal 缓存 ~1–2GB | 安全头召回 ≥ r_min；存在概率 ECE ≤ ε_cal；协方差保守 |
| POH | 匹配 O(N_h·N_y)（匈牙利小规模）；更新 O(N_h) | O(N_h·d) | 存在性贝叶斯更新；遮挡不立即删除；Σ 随未观测时间增长 |
| LAWM | rollout O(H·M·(d_z²+d_z d_a)) | M×模型 ~0.5–1.5GB | 集成不确定性覆盖真实误差（校准）；失败概率有界 |
| DWMC | O(N_h·N_y) | O(N_h) | 支持度/新息一致；无支撑预测不作控制先验；现实鸿沟告警 |
| PAT | 构建 O(H·|𝒦|·M)；实时切片 O(1) | O(H·|𝒦|) | 管不确定度随时域单调不减；破管必回退 K_⊥ |
| ISG | O(|𝒦_det|·M·H)（离线/低频）；实时 O(1) | O(|𝒦|) | 𝒦_adm ⊆ 𝒦_det ∩ 𝒦_hard；非空回退核 |
| CFD | O(M·H) 反事实 | O(1) | CFR < c_min 禁止断言；解释可追溯 |
| PCE+++++++ | O(1) 预算检查 | O(1) | 安全头保留预算；降级不降低安全约束 |
| J_dw | O(1) 组装 | O(1) | 所有门控项可审计；任一失败拒绝签发 |

**正确性定理（DWEC-Complete）**：
假设第 61 轮 A61–A70 成立，并新增：
- **(A71) 检测校准**：TCD 的存在概率与位姿协方差校准良好（ECE ≤ ε_cal，Σ_pred ⪰ Σ_true），安全头召回 ≥ r_min，且安全头保留预算永不被裁剪；
- **(A72) POH 一致性**：存在性/位姿更新为贝叶斯/ EKF 形式，未匹配假设按 γ_d 衰减，协方差随未观测时间单调增长；
- **(A73) LAWM 校准**：集成模型对真实下一状态的可信集覆盖率 ≥ 1−γ，认知不确定性 U_wm 上界真实模型误差，失败头 PIT 校准；
- **(A74) DWMC 仲裁**：支持度/新息按定义计算，测量优先规则严格执行，现实鸿沟告警在连续 k 帧 d² > χ² 后触发；
- **(A75) ISG 安全**：𝒦_det ⊆ 𝒦_hard，K_⊥ ∈ 𝒦_det ∩ 𝒦_hard 且非空；β < β_min 时世界模型不参与收紧；
- **(A76) PAT 有效性**：管切片满足 ρ(τ) 单调不减与 support(τ) 期望单调不增；破管检测覆盖力/位姿/接触事件；
- **(A77) CFR 断言门**：CFR ≥ c_min 才允许反事实断言，且 CFR 计算中的 support、U_wm、训练支撑集可审计；
- **(A78) 预算安全**：B_cog8 单调消耗，B_det 的安全头与 ISG 永不降级，B_wm 耗尽只影响预演质量。

则：
1. **检测接地与物体永久性**：对遮挡/短暂漏检，POH 的存在概率与位姿误差有界（A71+A72）；物体不会因单帧漏检被当作消失，接触相关子集 H^c 的误删率 ≤ δ_poh。
2. **想象-安全分离（WMHB）**：对任意世界模型输出（包括对抗性幻觉），dispatched K_safe ∈ 𝒦_det ∩ 𝒦_hard 或 K_safe = K_⊥（A74+A75）。因此世界模型幻觉不直接转化为力/速度违规；安全违规概率由检测校准、安全头召回与 K_⊥ 非空性界定，而非由 LAWM 精度界定。
3. **预测-测量互校**：若真实动力学在集成可信集内（A73），则无支撑预测被识别为幻觉、未解释检测被识别为惊喜（A74）；现实鸿沟告警的漏报率 ≤ γ，模型漂移不会被静默吸收。
4. **延迟鲁棒性**：实时流只消费 PAT 的 O(1) 切片，不调用 LAWM/MEL（定义 177）；语义流延迟 ≤ H·DT 时，管以单调增长的 Σ_tube 保守推进；延迟超过 H 或用尽时回退到上一有效切片 + 保守扩展；破管立即 K_⊥（A76）。
5. **反事实对话可靠性**：当 CFR ≥ c_min 时，反事实解释的预测区间以 ≥ 1−γ 概率覆盖真实风险变化；当 CFR < c_min 时，DMS 必不断言，只能请求澄清/探针（A77）。
6. **预算安全**：任一 B_cog8 维度耗尽触发对应降级；B_wm 耗尽退化为第 61 轮静态锚点 + 保守扩展，B_det 耗尽仍保留安全头并降低速度/力上限；ISG 与 K_⊥ 始终生效（A78）。

**推论（安全-性能分离）**：在 A71–A78 下，DWEC 的安全违规率不随 LAWM 规模/精度单调恶化；加大世界模型只可能提升任务成功率与前瞻性，不会降低安全下界。这为「大模型可以更激进地想象，但不能更激进地执行」提供了形式依据。

**消融设计**：
1. 去掉 POH（单帧 argmax 检测）⇒ 预期遮挡下物体永久性崩溃、抓取重试率上升；
2. 去掉 LAWM（无预演）⇒ 预期动态任务与接触瞬态成功率下降，延迟注入下退化最明显；
3. 去掉 DWMC（无条件信任 WM 或无条件信任检测）⇒ 预期幻觉/惊喜检测 AUROC 降至随机附近；
4. 去掉 ISG（允许 WM 扩展安全集）⇒ 预期对抗性幻觉注入下出现力违规，直接验证「只收紧不放松」的必要性；
5. 去掉 PAT（退回静态 anchor）⇒ 预期 200–500ms 延迟下接触力超调与破管率显著上升；
6. 去掉安全头保留预算 ⇒ 预期透明/反光/缝隙场景负障碍漏检率上升，验证双头非对称设计。

**统计与可复现**：每个实验 ≥ 5 个随机种子；报告均值 ± 95% CI；对安全指标（力违规、破管、不安全断言）使用单侧置信上界；所有 rollout 与阈值、证书字段写入 J_dw 审计日志，保证可回放。

## 5. 本轮最大风险

**一句话**：检测器与世界模型在分布外场景中可能同时失准（检测漏掉透明/反光/缝隙障碍，世界模型又自信地预测安全），而 DWMC 的支持度/信任估计若被系统性高估、或 PAT 在延迟与遮挡下破管却未触发 K_⊥，就会形成「想象-现实合谋」——这是本轮方案的最大风险；必须以检测安全头的独立保留、测量优先仲裁、只收紧不放松的 ISG、非空安全回退核与 J_dw 硬门控把想象限制在安全边界之内。
