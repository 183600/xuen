# 第 1 轮（UniBot 线 · 第 1 轮；本轮灵感：「移动操作」×「课程学习」）

> **基线声明**：本文件此前承载 MetricVoiceGauge（RoboCup@Home 导航 / 语音方向）研究线，与本轮任务域（宇树 UniBot 世界挑战赛 · 桌面泛化操作）不同源，旧编号封存。本轮起基线化到 UniBot 线，启用 U1–U12 / L1–L7 / E601–E618。已核实事实与来源清单沿用上一版（检索日期 2026-11-17）；本轮只补充与「移动操作」「课程学习」直接相关的推理，并把上一版未测的假设显式改写成**可零成本证伪的探针**。

## 0. 先立住一句话

**上一版把桌面任务当成"固定底座的机械臂 + 隐变量抓握"问题；本轮换一个更第一性的视角：桌面任务首先是"站在哪里、用身体的哪个自由度"的问题，其次才是"手怎么动"的问题。移动操作负责把"站位 / 全身姿态"变成显式慢变量，课程学习负责在固定算力下把"任务 × 泛化轴"练出来。**

## 1. 直觉解释（先直觉，后形式化）

### 1.1 「移动操作」：桌面任务的第一个决策不是抓取，而是站位

**直觉**：人做桌面任务时，第一步几乎总是"挪一下身子"——太远够不到就靠近，太近看不清就后退，角度不对就侧身。G1 是人形机器人，不是固定在桌边的机械臂；但当前主流 VLA 基线几乎都把基座当成常量，只输出手臂 + 夹爪（pivot 常被写成常量或被忽略）。这等于**主动放弃了一个慢速、低维、却决定"可达性 × 可见性"的自由度**。

更关键的是：UniBot 的 5 类泛化场景（位置 / 干扰物 / 背景 / 未见物品 / 人为干扰）恰好都会改变**最优站位**。位置泛化让物体离开默认工作空间；干扰物和背景改变可见性；未见物品改变几何与可达性；人为干扰要求让位或换角度。也就是说，**固定基座策略系统性地脆弱于评测真正考的那 5 条轴**。这不是一个"锦上添花"的自由度，而是与评测分布直接对齐的缺口。

**对 Dex1 单自由度夹爪的正确读法**：身体不能凭空造出"手指内的灵巧度"，所以"用身体补手"不能被误读成"身体替代手指"。身体真正能补的是三件事：
1. **补工作空间**：把手臂从够不到的位置搬到够得到的位置；
2. **补条件数**：让手臂远离奇异位形与关节限位，使同样的末端微调更可控（插入 / 旋转最吃这个）；
3. **补力与稳定**：用躯干 / 下肢提供支撑与柔顺，把"手臂硬怼"变成"全身顺应"。

**形式化草图**：末端位姿由手臂与身体共同决定，
`x_ee = FK(q_arm, q_body)`，微分形式 `ξ_ee = J_arm·q̇_arm + J_body·q̇_body`。
基座位姿 `b`（pivot / lower_body 的慢变量）先选，手臂再在其条件数良好的区域内做快速闭环。于是"移动操作"被写成两个时间尺度上的联合优化：慢尺度选 `b` 最大化"可达 × 可见 × 稳定"，快尺度在给定 `b` 下解冗余。

### 1.2 「课程学习」：不是"先易后难"的口号，而是"固定算力下把梯度花在可学的地方"

**直觉**：32 个任务 × 5 条泛化轴，一次性均匀训练会有两类浪费：一是**梯度干扰**（不同技能的梯度互相拉扯），二是**算力错配**（已经饱和的节点继续占算力，怎么练都学不会的节点也在占算力）。课程学习的本质不是"排序"，而是**在固定算力预算下重新分配样本**：先修节点先练，学习进度高的节点多练，已掌握的节点用 replay 防遗忘。

UniBot 的 5 条泛化轴天然有**先修结构**：
- 位置泛化是"利用基座移动"的先修——物体不动时，基座移动没有收益信号；物体一动，站位才成为变量；
- 干扰物 / 背景是"主动换视角"的先修——先会站位，才会为了看清而换位；
- 未见物品是"可抓性推理"的先修——先见过形状变化，才会判断"这种抓法是否物理可行"；
- 人为干扰是"失败恢复"的先修——先有稳定的阶段验证，才谈得上被打断后回退。

所以课程不应该是"按任务名从易到难"，而应该是**在 (任务 × 泛化轴) 的二维网格上，按先修 DAG 和学习进度推进**。

**必须说清的一个陷阱**：上一版用 Kendall τ≈0.064 说明"模型强弱在任务间准正交"，但**性能准正交不等于梯度兼容**。两个任务可以"谁强谁弱互不相关"，同时梯度方向高度冲突。课程学习是否有用，必须直接测**梯度余弦 / 迁移矩阵**，不能从 τ 推断。这是本轮把"课程"从口号变成可证伪假设的关键。

### 1.3 合成：MoCu =「用身体补手，用课程补数据」

两层灵感不是并列的，而是**互相提供难度轴与训练信号**：

- **移动操作提供新的难度轴**：站位 / 全身姿态是课程应该 ramp 的那一维；
- **课程学习提供训练调度**：先练"站位 + 可达"，再练"抓取 + 插入"，最后练"干扰 / 未见物体 / 人为打断"；
- **课程的副产物是技能亲和图**：哪些任务共享同一套身体补偿技能，应该在同一个专家里学——这比按任务名硬分 32 个专家更有依据。

四层栈：
1. **探针层**（先证伪，再投入）：基座是否可控、身体覆盖率是否足够、梯度冲突是否真实；
2. **移动层**：BasePlace（慢尺度站位）+ BodyComp（快尺度全身冗余补偿）；
3. **课程层**：PreC（先修课程调度）+ CurriRoute（课程诱导的专家路由）+ StageCurric（推理期子目标课程）；
4. **工程层**：chunk 缝合、延迟整形、多端口隔离、可审计。

## 2. 形式化（第一版；完整定义见产物区 §3）

- **U1 基座位姿** `b_t = (pivot_t, lower_body_t)`，慢时间尺度变量；对应动作记为 `a^b`。
- **U2 身体贡献比** `β = ‖Δx_ee^body‖ / (‖Δx_ee^body‖ + ‖Δx_ee^arm‖)`，其中 `Δx_ee^body = J_body·Δq_body`、`Δx_ee^arm = J_arm·Δq_arm`。`β` 回答"这个任务里，末端位移有多少是身体贡献的"。
- **U3 可达 / 可见 / 稳定** `R(b), V(b), S(b) ∈ [0,1]`：分别表示在站位 `b` 下目标在关节限位与工作空间内、在相机视野内且未被遮挡、以及质心 / 支撑多边形留有余量。
- **U4 站位目标** `J(b) = R(b)·V(b)·S(b)`（乘积，因为三者是"与"关系；优化时取对数避免下溢）。
- **U5 身体补偿** 给定期望末端旋量 `ξ*`，解
  `min_{q̇_arm,q̇_body} ‖J_arm·q̇_arm + J_body·q̇_body − ξ*‖² + λ‖q̇_body‖² + 安全惩罚`；
  覆盖率 `κ = ‖Π_col(J_body)·ξ*‖ / ‖ξ*‖`，`Π` 为到 `J_body` 列空间的投影。`κ` 回答"这个任务需要的末端运动，身体能分担多少"。
- **U6 任务亲和矩阵** `A_{ij}`：在任务 `i` 上训练后迁移到任务 `j` 的零样本收益，或用小模型的梯度余弦。
- **U7 先修 DAG** `G=(V,E)`，节点 `V = (task, axis)`，边 `E` 表示"必须先掌握"。
- **U8 学习进度** `LP_i = Δm_i / Δc_i`，`m_i` 为掌握度（留出集成功率），`c_i` 为消耗算力。
- **U9 课程调度** `σ`：在满足先修约束下，按 `p_i ∝ exp(η·LP_i)` 采样节点，并保留 replay。
- **U10 算力匹配基线**：同样的总样本数 / FLOPs，均匀覆盖全部节点；任何课程收益必须在此基线上比较。
- **U11 推理期子目标课程**：`reach → grasp → lift → transport → align → insert → release`，每个子目标有验证器，通过才推进，卡住则回退一级。
- **U12 安全包络**：对 `q̇_body`、质心偏移、关节限位设硬约束；越界即回退到固定基座。

## 3. 瓶颈再分析（teaser 榜 + 接口约束）

| 证据 | 数值 | 推出的设计 |
|---|---|---|
| `step ≈ 1.337·succ + 0.09`，`R²=0.9955` | 两项指标近乎共线 | 只优化终态成功；步骤分无独立杠杆 |
| 8 个模型跨任务 Kendall τ 均值 0.064 | 强弱在任务间准正交 | 技能异质性真实；课程分组 / 路由有依据，但不能据此推断梯度兼容 |
| per-task oracle 33.96 vs 最好单模型 29.70 | +4.26（+14.3%） | 技能路由有上界；课程诱导的专家划分值得做 |
| 最难 6 任务均值约 21.4（Plug In Ethernet 17.7、Unlock 20.1、Spell robot 21.8、Organize Stationery 22.5、Open Pill Bottle 22.7、Pick Out Battery 23.3） | 比榜首整体 29.7 低约 8.3 分；6/6 都是插入 / 旋转 / 细粒度摆放 | 火力应集中在"对齐 + 插入 + 旋转"；这正是身体补偿与站位最可能产生边际收益的地方 |
| 任务内 corr(dur, succ) 均值 −0.011 | 做得快没有红利 | 为站位 / 全身补偿多花时间是**可接受**的，只要终态成功率上升 |
| 跨模型任务内标准差均值 5.60 | 任务难度分层真实 | 课程应按"难度 × 学习进度"分配算力，而不是平均用力 |
| 接口只暴露 1 维夹爪；`pivot` / `lower_body` 在观测中 | 手内灵巧度不可得，但全身自由度可能可用 | 身体补偿的方向是"条件数 / 工作空间 / 力"，不是"手指灵巧度" |

**三个未测但可零成本测的假设（本轮的核心，先证伪再投入）**：

- **H1（基座可控性）**：官方数据中成功 episode 的 `pivot / lower_body` 有显著、任务相关的运动，且 `β` 不为零。**杀死条件**：所有任务 `β ≈ 0`，或 `pivot` 动作对末端几乎无影响 → 移动操作线整体降级。
- **H2（身体覆盖率）**：最难 6 个插入 / 旋转任务所需的末端旋量，有相当比例落在 `J_body` 列空间内。**杀死条件**：多数任务 `κ < 0.2` → BodyComp 不值得做，只保留 BasePlace。
- **H3（课程冲突）**：逐任务梯度余弦存在可观负质量，且按先修图排序能降低冲突。**杀死条件**：梯度冲突可忽略，或课程排序不降低冲突 → 退回均匀采样 + 难例挖掘。

## 4. 研究问题（轮次版）

- **Q1（移动操作的可兑现性）**：评测接口到底允许策略控制哪些身体自由度？`pivot` / `lower_body` 是否真的被执行？成功 episode 的身体贡献比 `β` 是多少，是否任务相关？
- **Q2（身体补偿的边界）**：在 Dex1 单自由度约束下，身体能补的是工作空间、条件数、力，还是也能补一部分旋转？覆盖率 `κ` 与任务成功率的关系是什么？
- **Q3（课程是否真的有用）**：在**固定算力**下，先修课程是否优于均匀采样？收益来自"减少梯度干扰"还是"更好的探索 / 难例分配"？哪种排序（任务优先 / 轴优先 / 联合）最好？
- **Q4（课程诱导路由）**：课程迁移矩阵是否呈块结构？用它划分专家是否比按任务名划分更好？是否仍然满足"单 checkpoint、单 API"的合规要求？
- **Q5（工程与安全）**：慢尺度站位 + 快尺度手臂的双时间尺度控制，能否在官方延迟 / 多端口 / 可信度口径下稳定运行？身体运动会否引入抖动、失衡或碰撞？

## 5. 设计原则

- **P1 单一计分货币**：所有创新必须能写成"提升某任务终态成功率"的因果链；不能映射到终态成功的一律降级。
- **P2 站位优先于抓取**：先问"站在哪里"，再问"怎么抓"；基座 / 全身姿态是显式慢变量，不是常量。
- **P3 身体补的是条件与力，不是手指**：明确区分"工作空间 / 条件数 / 力传递"与"手内灵巧度"，不承诺做不到的事。
- **P4 课程必须算力匹配**：任何"课程更好"的结论都必须在同等算力下与均匀采样比较；否则视为混淆。
- **P5 先证伪再投入**：H1 / H2 / H3 各有一个零成本探针和杀死条件；探针失败就砍线，不靠信念推进。
- **P6 合规与安全优先**：单 checkpoint、单 API；不硬编码任务分支；身体运动受安全包络约束；准备"固定基座 + 单专家"的降级形态。

## 6. 最小可提交闭环（MVP）与退化链

**MVP = IP-06（探针 + 代理评测） + IP-01（BasePlace） + IP-07（工程层） + 通用 VLA 基线。**
理由：IP-06 用官方数据就能回答 H1 / H2 / H3，决定后续是否值得投入；IP-01 是移动操作里最低风险、最可能直接涨点的一环；IP-07 是任何提交都必须过的工程门槛。IP-02（BodyComp）与 IP-03（PreC）分别由 H2 / H3 的探针结果决定是否升级为 P0。

**严格退化链（任一环节不可用 ⇒ 行为回退而非漂移）**：
- Level-0 基座 / 全身动作不可用 ⇒ 退回固定基座 + 手臂策略；
- Level-1 BasePlace 置信度低或安全包络越界 ⇒ 退回默认站位；
- Level-2 BodyComp 使条件数变差或抖动超限 ⇒ 退回纯手臂冗余解；
- Level-3 课程调度失效（节点不可学 / 遗忘严重）⇒ 退回均匀采样 + replay；
- Level-4 技能路由不合规或错配 ⇒ 退回单专家 + 任务 token；
- Level-5 整条新链路失效 ⇒ 退回纯基线策略（永远保留一份能跑通、可信度合规的最小提交）。

## 7. 预期贡献（可验收）

1. **首个"身体贡献比 β"的量化**：用官方 32 个数据集测出成功 episode 中基座 / 全身运动的占比与任务分布，把"移动操作缺口"变成一个可比较的数，而不是一句直觉。
2. **BasePlace + BodyComp 的联合设计**：慢尺度站位 + 快尺度冗余补偿，直接对准最难 6 个插入 / 旋转任务；给出覆盖率 `κ` 与成功率的经验关系。
3. **算力匹配的课程学习证据**：在同等算力下比较先修课程与均匀采样，并分离"梯度干扰减少"与"难例分配"两种机制；给出任务亲和图。
4. **一套可复用的探针协议**：H1 / H2 / H3 三个零成本探针 + 杀死条件，让后续轮次不必靠信念决定是否继续投入。
5. **工程与审计交付**：chunk 缝合、延迟预算、N 端口隔离、安全包络、可导出报告。

## 8. 本轮最大风险

**一句话**：本方案把分数押在"基座 / 全身自由度真的可控、且真的能改善最难任务的插入 / 旋转"上；若评测接口根本不让策略控制底盘，或 `pivot` 的语义被评测端忽略，移动操作这条线会整体归零，课程学习也随之失去其最主要的难度轴。

## 9. 下一轮迭代计划（深化与修剪）

- **深化**：把 BasePlace 从"离散候选站位打分"升级为"任务条件化的站位分布 + 主动换位"；把 BodyComp 从"静态冗余解"升级为"相位相关的准静态调度"（抓取 / 插入相位才启用大范围身体运动）。
- **修剪预案**：H1 失败 ⇒ 砍掉 BasePlace / BodyComp，保留课程 + 路由 + 工程；H2 失败 ⇒ 只保留 BasePlace；H3 失败 ⇒ 用均匀采样 + 难例挖掘替代课程；代理评测与真机相关性 `|r| < 0.3` ⇒ 砍掉一切依赖代理指标的微调。
- **保留项**：IP-06（探针 + 代理评测）、IP-07（工程确定性）在任何情况下不砍。

## 0. 本轮结论摘要

**一句话路线**：先用三个零成本探针回答"身体是否可控、能补多少、课程是否真的降冲突"，再把资源投到
**移动层**（BasePlace 慢尺度站位 + BodyComp 快尺度冗余补偿）→ **课程层**（PreC 先修调度 + CurriRoute 课程诱导路由 + StageCurric 推理期子目标课程）→ **工程层**（chunk 缝合 / 延迟整形 / 多端口隔离 / 可审计）。

**为什么是这个组合（证据表，均来自 teaser 榜 n=256 个 model-task 点与官方接口事实）**：

| 证据 | 数值 | 推出的设计 |
|---|---|---|
| `step_score ≈ 1.337·success + 0.09`（`R²=0.9955`） | 两指标近乎共线 | 只优化终态成功；步骤分无独立杠杆 |
| 8 个模型跨任务 Kendall τ 均值 0.064（28 对里仅 1 对 `|τ|>0.2`） | 强弱在任务间准正交 | 技能异质性真实；课程分组 / 路由有依据 |
| per-task oracle 33.96 vs 最好单模型 29.70 | `+4.26`（`+14.3%`） | 路由有上界；课程诱导的专家划分值得做 |
| 最难 6 任务均值约 21.4（Plug In Ethernet 17.7、Unlock 20.1、Spell robot 21.8、Organize Stationery 22.5、Open Pill Bottle 22.7、Pick Out Battery 23.3） | 比榜首整体 29.7 低约 8.3 分；6/6 都是插入 / 旋转 / 细粒度摆放 | 火力集中在"对齐 + 插入 + 旋转"；身体补偿与站位最可能在此产生边际收益 |
| 任务内 `corr(dur, succ)` 均值 −0.011 | 做得快没有红利 | 为站位 / 身体补偿多花时间可接受 |
| 跨模型任务内标准差均值 5.60 | 任务难度分层真实 | 课程按"难度 × 学习进度"分配算力 |
| 接口仅 1 维夹爪；`pivot`(7) / `lower_body`(15) 在观测中 | 手内灵巧度不可得，但全身自由度可能可用 | 身体补的是工作空间 / 条件数 / 力，不是手指 |

**合规红线**：单一 checkpoint、单一 API；不硬编码任务分支；不读评测侧私有信息；身体运动受安全包络约束；始终保留"固定基座 + 单专家"降级形态。

## 2. 创新点详述

### IP-01 · BasePlace 基座 / 全身放置策略（P0）

- **动机**：人形机器人做桌面任务时，第一个决策是站位；但主流 VLA 把基座当常量。5 类泛化场景都会改变最优站位，固定基座因此系统性脆弱于评测真正考的分布偏移。成功 episode 中 `pivot / lower_body` 的运动是一个**免费标签**：数据已经告诉我们"哪些站位能成功"。
- **与现有方案的差异**：现有做法是"固定基座 + 更大 VLA"；我们把站位做成**慢时间尺度的离散 / 连续决策**，用数据学习 `R(b)·V(b)·S(b)` 的打分器，并在相位边界（而非每步）更新，避免逐帧抖动与延迟。
- **技术可行性**：中–高。`pivot` 与 `lower_body` 在观测中；官方数据提供成功 episode 的基座轨迹；URDF 可算可达性与条件数；可见性可用相机外参 + 目标点云近似。风险是**评测端是否真的执行 `pivot`**——这必须先由 H1 探针回答。
- **所需资源**：数据 = 官方 32 数据集；算力 = 小（站位打分器可用轻量 MLP / GBDT + 几何特征）；接口 = 复用 `action.pivot`（若可用）或只做"站位建议"给手臂策略。
- **落地步骤**：
  1. **H1 探针**：解析 32 个数据集，统计成功 episode 的 `pivot / lower_body` 轨迹；用 URDF 正运动学分解末端位移，计算每任务 `β` 与其方差。**杀死条件**：`β ≈ 0` 或 `pivot` 对末端几乎无影响。
  2. 构建候选站位集合 `B`（yaw × 距离 × 高度 × 躯干俯仰的离散网格，约 48–96 个）。
  3. 用成功 episode 的"站位 → 结果"训练打分器 `Ĵ(b)`；特征含目标点云质心 / 包围盒、可达性、可见性、质心余量。
  4. 在相位边界（reach 前 / transport 前）重新选 `b`，用最小 jerk 轨迹执行；若执行超时或越界则回退默认站位。
  5. 与固定基座基线做真机 A/B（E604）。
- **风险**：①评测端不执行 `pivot` ⇒ 收益为 0，故先用 H1 探针；②站位运动引入抖动 / 失衡 ⇒ 只在相位边界更新 + 安全包络；③站位打分器在未见物品上外推失败 ⇒ 用几何特征而非纯视觉特征，并保留默认站位兜底。

### IP-02 · BodyComp 全身冗余补偿（P1，H2 通过后升 P0）

- **动机**：最难 6 任务全是插入 / 旋转 / 细粒度摆放。这些任务需要末端在**小范围内做高精度姿态调整**，而手臂在接近工作空间边缘或奇异位形时条件数很差；Dex1 又只有 1 维开合，无法靠手指补。身体自由度可以改善"手–臂联合"的条件数、工作空间与力传递条件。
- **与现有方案的差异**：现有方案把身体当常量，只在手臂空间解 IK；我们把身体作为**冗余自由度**，解一个带安全约束的 QP：在完成期望末端旋量的同时，最大化手臂条件数、远离限位、保持质心稳定。
- **技术可行性**：中。微分 IK + URDF 即可；难点是"准静态调度"——身体运动慢，不能每步大动，否则抖动 / 失衡。覆盖率 `κ` 可从数据与 URDF 直接算，先于训练就能判断值不值得做。
- **所需资源**：数据 = 官方数据 + URDF；算力 = 小（QP 求解器）；接口 = `action.pivot` / `lower_body`（若可用）。
- **落地步骤**：
  1. **H2 探针**：对最难 6 任务，从数据估计每个阶段的期望末端旋量 `ξ*`，计算 `κ = ‖Π_col(J_body) ξ*‖ / ‖ξ*‖`。**杀死条件**：多数任务 `κ < 0.2`。
  2. 实现带约束的冗余解：`min ‖J_arm q̇_arm + J_body q̇_body − ξ*‖² + λ‖q̇_body‖²`，约束含关节限位、速度上限、质心余量、自碰撞。
  3. 准静态调度：只在抓取 / 对齐 / 插入相位启用较大身体运动；其余相位冻结身体，退回纯手臂。
  4. 与"纯手臂 IK"做 A/B（E605）；记录条件数、jerk、成功率。
- **风险**：①身体运动导致失衡 / 抖动 ⇒ 安全包络 + 准静态调度 + 默认冻结；②评测端忽略 `pivot` ⇒ 与 IP-01 同源风险，H1 先判；③过度补偿破坏手臂原有的精细控制 ⇒ 只在条件数低于阈值时启用，并限幅。

### IP-03 · PreC 先修课程调度器（P0，训练）

- **动机**：32 任务 × 5 泛化轴一次性均匀训练，存在梯度干扰与算力错配。5 条轴有天然先修结构（位置 → 干扰 / 背景 → 未见物品 → 人为干扰），适合用课程 ramp。
- **与现有方案的差异**：常见做法是"全域随机化 + 均匀采样"；我们做**先修 DAG + 学习进度**调度，并强制**算力匹配**比较。课程不是按任务名从易到难，而是在 `(task, axis)` 节点上推进。
- **技术可行性**：中–高。先修 DAG 可由数据统计 + 人工先验构建；学习进度用留出集掌握度估计；梯度冲突可用小模型直接测。
- **所需资源**：数据 = 官方 32 数据集 + 自建 OOD 变体；算力 = 中（课程本身不增加总算力，只改变分配）；接口 = 无。
- **落地步骤**：
  1. **H3 探针**：在小模型上逐任务计算梯度余弦 / 迁移矩阵，估计负冲突质量。**杀死条件**：冲突可忽略或课程不降冲突。
  2. 构建先修 DAG：节点 `(task, axis)`，边表示"先掌握"。示例：`(task, canonical) → (task, position) → (task, distractor/background) → (task, unseen) → (task, human)`。
  3. 实现学习进度 `LP_i = Δm_i/Δc_i` 与指数权重采样；保留 replay 防遗忘。
  4. 与均匀采样在**同等算力**下比较（E606）；做排序消融（任务优先 / 轴优先 / 联合 / 随机）（E607）。
  5. 输出任务亲和矩阵 `A` 给 IP-04。
- **风险**：①课程可能有害（错误先修 / 遗忘）⇒ replay + 单调推进 + 算力匹配 + 随时回退均匀；②学习进度估计噪声大 ⇒ 用滑动窗口 + 置信区间；③课程收益被"更多算力"混淆 ⇒ 预注册算力匹配。

### IP-04 · CurriRoute 课程诱导技能路由（P1）

- **动机**：teaser 榜 oracle `+4.26`、top-2 `+2.52`，说明技能路由有真实上界；但按任务名硬分 32 个专家容易过拟合，也不一定符合"单模型"合规叙述。课程训练过程天然产生"哪些任务共享技能"的迁移矩阵。
- **与现有方案的差异**：用**迁移矩阵 / 梯度亲和**聚类出 K 个专家，而不是 32 个 ad hoc 专家；每个专家必须在至少 2 个任务上被复用（防止退化）。
- **技术可行性**：中。迁移矩阵可在小模型上测得；聚类与门控是标准 MoE；合规形态可退化为单专家 + 任务 token。
- **所需资源**：数据 + 算力（+20–30%）；接口 = 无（仍是单 `get_action`）。
- **落地步骤**：①从 IP-03 得到 `A`；②谱聚类 / 层次聚类成 K 组；③训练共享主干 + K 个轻动作头；④门控用任务 token + 阶段 token；⑤与按任务名划分、随机划分做 A/B（E609）；⑥准备单专家降级形态并实测损失。
- **风险**：①`A` 不呈块结构 ⇒ 路由无收益，退回单专家；②多专家被判定"非单模型" ⇒ 先书面确认，保留单专家形态；③专家坍缩 ⇒ 复用约束 + 输出多样性监控。

### IP-05 · StageCurric 推理期子目标课程（P2）

- **动机**：失败集中在"最后一环"；如果能在 episode 内按子目标验证推进，就能在早期发现"没抓住 / 没对齐"并及时回退，而不是一路执行到超时。
- **与现有方案的差异**：把训练期课程思想搬到推理期：`reach → grasp → lift → transport → align → insert → release` 逐级验证，卡住则回退一级；复用 IP-06 的阶段标注器与抓握验证器。
- **技术可行性**：中。阶段验证器可用几何规则 + 轻量分类器；主要风险是误判导致过度回退、时间成本上升。
- **落地步骤**：①定义每级子目标的验证信号（腕部几何、夹爪开合、EE 速度、物体相对位移）；②实现推进 / 回退状态机；③设最大回退次数与时间预算；④真机 A/B（E610）。
- **风险**：①验证器误判 ⇒ 高阈值 + 最多回退 2 次；②回退浪费时间 ⇒ 只在关键相位启用；③与评测端超时冲突 ⇒ 时间预算硬约束。

### IP-06 · MoCuBench 代理评测 + 基座因子分解（P0）

- **动机**：真机时段稀缺，官方榜单尚未正式发布；没有可信内部标尺，一切创新无法迭代。且现有六因子分解没有"站位"这一项，无法评估移动操作的边际贡献。
- **与现有方案的差异**：把六因子扩展为**七因子**：
  `P(success) ≈ P(base)·P(reach|base)·P(grasp|reach)·P(transport|·)·P(align|·)·P(insert/place|·)·P(release|·)`。
  其中 `P(base)` 是"所选站位使任务可行"的概率，直接量化移动操作贡献。
- **技术可行性**：中–高。官方 32 数据集齐备；阶段标签用 VLM 批量打标 + 腕部几何规则交叉验证；真机锚点用少量时段标定相关性。
- **所需资源**：数据 = 官方 32 份；算力 = 中；接口 = 无。
- **落地步骤**：①统一下载 / 解码管线（AV1 → 帧）；②阶段标注器 + 人工抽检 5%；③七因子指标 + OOD 切分（留出物体 / 背景 / 位置 / 干扰物）；④真机锚点标定（每轮 2–3 个时段，Spearman）；⑤把分解结果作为其他 IP 的边际收益排序器。
- **风险**：代理指标与真机相关性不足（最大风险）⇒ 预注册 `|r|<0.3` 即砍掉依赖代理指标的微调；阶段标签噪声 ⇒ 双标注器一致性检查。

### IP-07 · ChunkStitch 工程层（P0）

- **动机**：接口逐 chunk 调用，chunk 边界不连续会在抓取 / 插入瞬间产生机械尖峰；官方采集 per-step 延迟与动作统计规律性。
- **与现有方案的差异**：chunk 长度随相位自适应（抓取 / 对齐用短 chunk，搬运用长 chunk）；边界做 C0 连续 + 一阶外推；延迟超预算时返回安全延拓并标记降级。
- **技术可行性**：中–高，但**必须先用官方 `run_client.py` 复刻评测语义**（chunk 如何执行、是否插值、是否重置控制器），未验证前不做"利用未声明行为"的优化。
- **落地步骤**：①复刻评测闭环，测真实延迟分布与 chunk 语义；②实现缝合器（一阶外推 + 数据回归残差）；③相位自适应 chunk；④延迟兜底；⑤审计看板（p50/p99、jerk、边界失配计数）。
- **风险**：①评测端自带插值 ⇒ 缝合叠加抖动 ⇒ 默认可关，真机 A/B 决定；②短 chunk 增加调用次数 ⇒ 并发压测；③过度平滑降低成功率 ⇒ 只作用残差，不改均值。

### IP-08 · AuditLayer 可审计提交层（P2，审计并入 IP-07）

- **动机**：官方明示会采集延迟波动与动作统计规律性并据此评估可信度；在成功率接近时，可审计性是相对优势。
- **落地步骤**：①延迟 / jerk 埋点；②N 端口 × 8 h 并发与状态隔离自检；③动作离群检测与限幅；④产出自证报告。
- **风险**：过度平滑 / 限幅压低成功率 ⇒ 阈值由数据分布定；动作"过于规律"可能被视为脚本化 ⇒ 保留策略固有随机性。

## 3. 符号与定义（U1–U12）

| 符号 | 含义 |
|---|---|
| `π` | 策略：观测 + 语言指令 → 动作块（单一 checkpoint） |
| `b_t` | 基座 / 全身慢变量 `(pivot, lower_body)` |
| `a^b` | 基座 / 全身动作（若接口可用） |
| `R(b), V(b), S(b)` | 可达性 / 可见性 / 稳定性 |
| `β` | 身体贡献比 |
| `ξ*` | 期望末端旋量 |
| `κ` | 身体覆盖率 |
| `A` | 任务亲和矩阵 |
| `G` | 先修 DAG |
| `LP_i` | 学习进度 |
| `σ` | 课程调度 |
| `m_i` | 掌握度 |

**定义 U1（基座位姿）** `b_t = (pivot_t, lower_body_t)`，在慢时间尺度（相位边界）更新；`a^b` 为其动作。若接口不支持，则 `b_t ≡ b_0` 为常量，本定义退化为空操作。

**定义 U2（身体贡献比）** `β = ‖Δx_ee^body‖ / (‖Δx_ee^body‖ + ‖Δx_ee^arm‖)`，其中 `Δx_ee^body = J_body·Δq_body`、`Δx_ee^arm = J_arm·Δq_arm`；`β ∈ [0,1]`。当分母为 0 时定义 `β = 0`。

**定义 U3（可达 / 可见 / 稳定）**
`R(b) = P(target ∈ W(b) 且 q ∈ [q_min,q_max])`；
`V(b) = P(target 在至少一路相机视野内且未被遮挡)`；
`S(b) = P(质心投影在支撑多边形内且余量 ≥ δ)`。三者均由几何 + 数据估计。

**定义 U4（站位目标）** `J(b) = R(b)·V(b)·S(b)`；优化时用 `log J(b) = log R + log V + log S`。乘积形式表达"三者缺一不可"。

**定义 U5（身体补偿）** 给定期望末端旋量 `ξ*`，解
`min_{q̇_arm,q̇_body} ‖J_arm·q̇_arm + J_body·q̇_body − ξ*‖² + λ‖q̇_body‖² + μ·φ_safety(q)`，
其中 `φ_safety` 惩罚接近限位 / 奇异 / 质心越界。覆盖率
`κ = ‖Π_col(J_body)·ξ*‖ / ‖ξ*‖`（`ξ*=0` 时定义 `κ=0`）。

**定义 U6（任务亲和矩阵）** `A_{ij} = m_j(θ_i) − m_j(θ_0)`：在任务 `i` 上训练后，任务 `j` 的零样本掌握度相对基线的增量；或用小模型梯度余弦 `cos(g_i, g_j)` 作为替代。

**定义 U7（先修 DAG）** `G=(V,E)`，`V = {(task, axis)}`，`axis ∈ {canonical, position, distractor, background, unseen, human}`；`(u,v) ∈ E` 表示"必须先掌握 `u` 才能有效学习 `v`"。

**定义 U8（学习进度）** `LP_i(t) = (m_i(t) − m_i(t−Δ)) / (c_i(t) − c_i(t−Δ))`，用滑动窗口估计。

**定义 U9（课程调度）** 在满足先修约束的可用节点集合 `A(t) = {i : pred(i) 已掌握}` 上，按
`p_i ∝ exp(η·LP_i)` 采样；以概率 `ε` 均匀探索；已掌握节点以固定比例进入 replay。

**定义 U10（算力匹配基线）** 均匀采样基线 `σ_uniform`，与课程 `σ` 使用相同的总样本数 / FLOPs / 训练步数；比较 `E[succ | σ, C]` 与 `E[succ | σ_uniform, C]`。

**定义 U11（推理期子目标课程）** 子目标序列 `s_1..s_K`（reach, grasp, lift, transport, align, insert, release），验证器 `v_k(o_t) ∈ {0,1}`；当 `v_k=1` 推进，连续 `n_fail` 次失败则回退一级；最大回退次数 `R_max` 与时间预算 `T_max` 为硬约束。

**定义 U12（安全包络）** 对 `q̇_body`、`q̈_body`、质心偏移、关节限位、自碰撞设硬约束；任一项越界则冻结身体、退回固定基座，并记录一次 `body_fallback`。

```python
def base_motion_probe(datasets, urdf):
    """H1: 成功 episode 中身体贡献比 β 的分布。"""
    for task, ds in datasets.items():
        for ep in ds.successful_episodes():
            q_arm, q_body = ep.arm_joints(), ep.body_joints()
            dx_body = urdf.jacobian_body(q_body) @ diff(q_body)
            dx_arm  = urdf.jacobian_arm(q_arm)  @ diff(q_arm)
            beta = norm(dx_body) / (norm(dx_body) + norm(dx_arm) + 1e-9)
            record(task, beta)
    return per_task_beta  # 若所有任务 β≈0 → 杀死 IP-01/IP-02

def body_coverage_probe(tasks, urdf):
    """H2: 最难 6 任务所需末端旋量被身体列空间覆盖的比例 κ。"""
    for task in tasks:
        for phase in task.phases:
            xi = estimate_required_twist(task, phase)   # 从数据估计
            Jb = urdf.jacobian_body(task.mean_body_q(phase))
            kappa = norm(project(Jb, xi)) / (norm(xi) + 1e-9)
            record(task, phase, kappa)
    return per_task_kappa  # 若多数 κ<0.2 → 只保留 IP-01，砍 IP-02

def gradient_conflict_probe(model, tasks):
    """H3: 逐任务梯度余弦的负质量 + 课程排序能否降低冲突。"""
    grads = {t: task_gradient(model, t) for t in tasks}
    neg_mass = mean([max(0.0, -cos(grads[i], grads[j]))
                     for i, j in pairs(tasks)])
    ordered = order_by_prerequisite(tasks)
    neg_mass_ordered = mean([max(0.0, -cos(grads[ordered[i]], grads[ordered[i+1]]))
                             for i in range(len(ordered)-1)])
    return neg_mass, neg_mass_ordered  # 若无显著下降 → 退回均匀采样
```

```python
# ===== 移动层：慢尺度站位 + 快尺度身体补偿 =====
class BasePlace:
    def __init__(self, scorer, candidates, safety):
        self.scorer = scorer            # Ĵ(b): 可达×可见×稳定
        self.candidates = candidates    # 48–96 个离散站位
        self.safety = safety

    def plan(self, obs, task, phase):
        if phase not in ("pre_reach", "pre_transport"):
            return None                 # 只在相位边界更新，避免逐帧抖动
        target = estimate_target_point(obs, task)
        best, best_j = None, -1.0
        for b in self.candidates:
            if not self.safety.within_envelope(b):
                continue
            j = self.scorer(b, target, obs)
            if j > best_j:
                best, best_j = b, j
        return best if best_j > self.scorer.default_threshold else None

class BodyComp:
    def __init__(self, urdf, lam=1e-2, kappa_min=0.2):
        self.urdf, self.lam, self.kappa_min = urdf, lam, kappa_min

    def resolve(self, xi_star, q, phase):
        J_arm, J_body = self.urdf.jacobians(q)
        kappa = self.coverage(J_body, xi_star)
        if kappa < self.kappa_min or phase not in ("grasp", "align", "insert"):
            return solve_arm_only(J_arm, xi_star, q), None, kappa
        qd_arm, qd_body = solve_qp(J_arm, J_body, xi_star, q,
                                   lam=self.lam, safety=self.urdf.safety)
        return qd_arm, qd_body, kappa
```

```python
# ===== 课程层：先修 DAG + 学习进度 + replay =====
class CurriculumScheduler:
    def __init__(self, dag, mastery, lp_window=5, eta=1.0, eps=0.1):
        self.dag, self.mastery = dag, mastery
        self.lp_window, self.eta, self.eps = lp_window, eta, eps
        self.replay = []

    def available(self):
        return [v for v in self.dag.nodes
                if all(self.mastery.is_mastered(p) for p in self.dag.pred(v))]

    def lp(self, node):
        hist = self.mastery.history(node)[-self.lp_window:]
        return (hist[-1].m - hist[0].m) / max(1e-9, hist[-1].c - hist[0].c)

    def sample(self):
        avail = self.available()
        if not avail:
            return self.dag.terminal_nodes()
        if random.random() < self.eps:
            return random.choice(avail)
        logits = np.array([self.eta * self.lp(v) for v in avail])
        p = softmax(logits)
        node = np.random.choice(avail, p=p)
        if self.mastery.is_mastered(node):
            self.replay.append(node)
        return node

    def step(self, node, delta_m, delta_c):
        self.mastery.update(node, delta_m, delta_c)
        if self.mastery.is_mastered(node):
            self.replay.append(node)
```

```python
def failure_taxonomy(episode, labels):

    factors = ["base", "reach", "grasp", "transport", "align", "insert", "release"]

    alive = True
    for f in factors:
        ok = bool(labels.get(f, False))
        if alive and not ok:
            alive = False
        out[f] = 1.0 if ok else 0.0
```

## 5. 推导（引理 L1–L7）

**引理 L1（身体贡献比的可定义性）** 设末端位姿 `x_ee = FK(q_arm, q_body)` 可微，则在任意轨迹上末端位移可分解为
`Δx_ee = J_arm·Δq_arm + J_body·Δq_body + O(‖Δq‖²)`；
忽略二阶项时 `β = ‖J_body Δq_body‖ / (‖J_body Δq_body‖ + ‖J_arm Δq_arm‖) ∈ [0,1]` 良定义。若 `pivot` 不被执行，则 `Δq_body ≡ 0`，`β ≡ 0`，H1 被直接证伪。∎

**引理 L2（站位必要性的单调性）** 若存在任务 `τ` 与目标点 `x`，使得默认站位 `b_0` 有 `R(b_0)=0`（不可达），而某候选 `b*` 有 `R(b*)>0`，则 `J(b_0)=0 < J(b*)`；因此对这类任务，任何不改变站位的策略成功率上界为 0。推论：若官方数据中存在"成功 episode 的站位显著偏离默认值"的样本，则固定基座假设在这些任务上必然损失成功率。∎

**引理 L3（身体补偿的覆盖率与条件数）** 给定期望旋量 `ξ*`，若 `ξ* ∈ col(J_body)`，则 `κ=1`，存在 `q̇_body` 使 `J_body q̇_body = ξ*`，手臂无需出力；若 `ξ* ⊥ col(J_body)`，则 `κ=0`。一般情况下 `0<κ<1`。又因 `col([J_arm, J_body]) ⊇ col(J_arm)`，加入身体自由度**弱单调地扩大**可达旋量集合，故联合系统的任务空间可操作度不低于纯手臂系统（在相同任务空间度量下）。∎

**引理 L4（replay 下课程不改变极限分布）** 若课程调度满足：(a) 每个节点被采样的概率下界 `p_min>0`；(b) 已掌握节点以固定比例进入 replay；(c) 训练步数 `T→∞`，则训练分布的支持收敛到全部节点，课程只改变**采样顺序**，不改变极限支持。因此课程不可能通过"漏掉某类数据"获得虚假收益；其收益只能来自优化路径 / 梯度干扰 / 探索。∎

**引理 L5（算力匹配的可识别性）** 设 `C` 为总算力，`σ` 为课程，`σ_u` 为均匀采样。若在 `C` 下观察到 `E[succ|σ,C] > E[succ|σ_u,C]`，则收益不能由"更多样本"解释；若两者算力不同，则差异与算力混淆，不可归因于课程。故所有课程实验必须预注册 `C` 相同。∎

**引理 L6（学习进度调度的渐近性）** 若 `LP_i` 的估计无偏、奖励平稳，则指数权重采样 `p_i ∝ exp(η·LP_i)` 等价于对"单位算力边际收益"做指数加权 bandit，随 `η` 增大收敛到当前最优节点；非平稳时用折扣 `LP` 可跟踪。该引理只保证**算力分配**的合理性，不保证课程一定优于均匀采样（后者取决于冲突结构）。∎

**引理 L7（亲和路由的块结构条件）** 若任务亲和矩阵 `A` 可近似为 `K` 块对角（块内亲和高、块间接近 0），则 `K` 个专家可做到块间零干扰，路由上界由块内最优决定；若 `A` 满秩（无块结构），则任何硬划分都会把高亲和任务拆开，路由不能优于单专家。故 IP-04 必须先测 `A` 的块结构，再决定 `K`。∎

| **评测器语义未知**（chunk 执行 / 插值） | 中 | 中 | 先用官方 client 复刻，再决定缝合 |
| **接口工程事故**（端口 / 并发 / token） | 中 | 高 | 提交前自动化体检脚本 |
| **过拟合 teaser 数据** | 中 | 中 | teaser 仅作结构参考；一切调参以本地 OOD 与真机 A/B 为准 |

- **条件推进**：IP-01（H1）、IP-02（H2）、IP-03（H3）。
