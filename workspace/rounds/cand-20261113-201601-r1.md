# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务」IP-243~252；本轮灵感：「研究空白」×「多模态交互」）

> 第 68 轮用计量层回答了「**我的测量还准吗**」，却留下一句谶语：**标定能力越强，缓变故障越隐形**。这句话的病根不在标定层，而在一个更普遍的元失败——**自适应系统会把自己「解释掉」的东西从可见世界里删除，并且再也看不见这个删除动作**。R68 的 COF 把慢故障吸收成漂移，就是「一次成功的解释同时制造了一个不可见空白」。
>
> 本轮两块灵感把这个病根提升为可设计的对象：
>
> **研究空白**——科研的进展不只是累积正面结论，更是绘制负空间：哪些问题没被回答、为什么没被回答（没采到 / 测不到 / 被自己的解释压掉了）。搬进闭环，系统必须维护一张显式的「空白账本」，并区分三类空白：采样空白、结构空白、**吸收空白（A-gap：系统自己制造、因适应而不可见的空白）**。
>
> **多模态交互**——交互不是把多路信号加权融合，而是有语法、有指称、有冗余/互补/矛盾关系的**协议**。互补性可以填结构空白，矛盾性本身是信息；但前提是**独立性**——共享失效模式的两路模态只能提供「相关确认」，那不是补盲，而是把无知重复计票。
>
> 核心命题：**GEM-RAS（Gap-Explicit Multimodal RAS）——把「研究空白」显式化为可观测、可审计、可主动填补的空白账本；把「多模态交互」从融合算子升级为带独立性证书的补盲协议；并用「盲点守恒」约束每一条自适应：任何解释都必须交代无知被搬到了哪里。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我还有什么不知道，而且我刚刚是不是把它藏起来了**」。

## 0. 直觉与动机

**灵感 1（研究空白 → 从「知识清单」到「无知账本」）**
直觉：人类研究者写综述，最有价值的一节往往是「open problems」；但一个在线自适应系统通常只有知识（后验、模型、阈值），没有「无知」的表示。它的置信度只覆盖已建模的不确定性，对「没有被任何假设覆盖的区域」不施加任何惩罚。R68 恰是如此：故障被标定吸收后，后验看起来更干净，系统反而更自信。于是第一原则是**先记账，再解释**——任何时刻都要能回答「在当前工作点，哪些决策相关方向我没有独立证据覆盖」。

**灵感 2（研究空白 → 三类空白，不能用同一种方式填）**
直觉：采样空白可以靠多采填；结构空白（当前传感/驱动拓扑的零空间）靠多采填不了，只能靠新增独立测量通道或改变动作；吸收空白最麻烦——它由系统自己的适应产生，用系统自己的残差去查必然查不到（残差已经被抹平了），只能靠外部 canary 或全新通道审计。把三类混为一谈，必然出现两种自欺：**往结构盲区里堆数据**，以及**用被吸收后的残差证明「没有发生吸收」**（循环论证）。

**灵感 3（多模态交互 → 交互是协议，不是融合）**
直觉：现有多模态融合默认通道同步、同指称、噪声独立，然后加权求和。真实人机交互里，眼睛看 A、手指 B、嘴说 C 是常态；矛盾不是该被平均掉的噪声，而是需要解释的信号（指称错位？欺骗？某通道进入盲区？）。所以交互需要语法：**指称绑定 + 时态 + 通道间冗余/互补/矛盾关系**。多模态的价值不在「多」，而在**互补覆盖**——一个通道的结构盲区，恰好落在另一个通道的灵敏区。

**灵感 4（多模态交互 → 独立性既补盲也反噬；共模相关是双刃剑）**
直觉：R68 引理 15 故意让各头共享 trunk 提高噪声相关 ρ_c，用共模抵消提高漂移检出 SNR。但那笔账有代价：同一份相关性让这些头**一起盲**；若再把它们当成独立通道去计算补盲覆盖，就会把同一份信息重复计票，产生**覆盖率膨胀**——后验方差被压到信息论下界以下，系统过度自信。于是必须给多模态交互配一张「独立性证书」：只有失效模式可分离的通道对，才允许把证据记入补盲；否则只能记为「相关确认」，不得减少空白质量。

**灵感 5（合流 → GEM-RAS 六组件与对 R68 的对症下药）**
1. **GOM Gap Observatory Model**：空白账本 + S/B/A 三分类 + 吸收监视器；
2. **MIP Multimodal Interaction Protocol**：类型化交互 act（指/说/示/触/看）、指称绑定、矛盾信号、协议语法；
3. **IDC Independence Certificate**：失效模式独立性 + 带宽重叠 + 共享退化检测，输出有效独立性 ι；
4. **GFA Gap-Filling Attribution**：交叉模态证据按 ι 折扣后入账，升级 R68 的 CFA；
5. **AEG Active Epistemic Gap-filling**：以 A-gap 加权 EVOI 调度交互，优先「新增测量行」而非「再解释一遍」；
6. **GAC Gap-Aware Certification**：CAC 五关扩为七关（+ gap canary + coverage certificate），保留 RAS-G† 全部继承核。
对症：R68 的「缓变故障被吸收」→ 吸收监视器把「解释增益 A」与「信息通量 ΔF」分开记账，gap canary 强制盲区保持可见；R68 的「单 trunk 共模」→ 独立性证书把 ρ 从补盲预算中扣除；R68 的「U_cal 高仍可能放宽」→ 空白质量 g_t 并入 λ 下限，**未覆盖即保守**。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（GEM-RAS 总览与四不变式）** GEM-RAS = (GOM, MIP, IDC, GFA, AEG, GAC, RAS-G†)。四条不变式：
(i) **实时流零学习写操作**（继承 R68：更新只在影子流，经认证原子换装）；
(ii) **空白诚实（gap honesty）**：在存在未解决 A-gap（g^A_t > τ_A）或结构盲区未被独立覆盖的操作区域内，系统不得输出「正常/放行」级裁决；输出必须携带空白质量 g_t，并把 λ_risk 抬到 ≥ 0.8、前缀 k 收缩；
(iii) **禁止盲认证（no blind self-certification）**：任何适应/标定若在某决策相关方向上显著降低残差（A_d > a_0）却未引入新的独立信息（ΔF_d ≤ 0），该方向必须记入 G^A，且不得以这次残差下降作为放行证据；
(iv) **无独立性即沉默（independence-or-silence）**：未通过独立性证书的跨模态证据只能作为「相关确认」，不得减少任何空白质量。

**定义 294（空白账本）** 空白空间 𝒢 = ℋ × ℳ × 𝒞（假设 × 模态覆盖 × 上下文）。空白账本 G_t = (G^S_t, G^B_t, G^A_t) 是 ℋ 上的三个非负测度；空白质量
g_t = ∫ w(h) d(G^S_t + G^B_t + G^A_t)(h)，
w(h) 为决策相关权重（在 h 上判错的期望代价归一化）。账本每步由三点更新：(i) 观测计数与后验熵；(ii) Fisher 信息 / 可观测 Gramian；(iii) 吸收监视器。

**定义 295（空白三分类与结构盲子空间）** 在当前工作点，测量模型对潜方向 d 的 Fisher 信息 F_t(d) = E[−∂² log p(y | h) / ∂d²]（或等价的局部可观测 Gramian）。给定阈值 ε_B：
- **结构盲子空间** B_t = {d : F_t(d) < ε_B}，G^B_t = 决策相关先验在 B_t 上的投影；
- **采样空白** G^S_t = 在 F_t(d) ≥ ε_B 但有效样本 n_eff(d) < n_0 的方向上的后验熵；
- **吸收空白** G^A_t 见定义 296。
关键区分：S 可由「同通道更多采样」降低；B 只能由「新增独立测量行（新模态/新动作）」降低；A 只能由「外部 canary 或全新通道审计」降低——**用被吸收后的残差去检验 A-gap 是循环论证**。

**定义 296（吸收算子与 A-gap）** 设残差 r_t(θ)，适应 δθ。方向 d 上的吸收增益与信息通量：
A_d(δθ) = 1 − ‖r_t(d; θ+δθ)‖ / ‖r_t(d; θ)‖，  ΔF_d(δθ) = F_{t+1}(d) − F_t(d)。
若 A_d > a_0 且 ΔF_d ≤ 0，则 d 处残差下降没有新信息支撑，称为**吸收**；记
G^A_t = 加权测度{ d : A_d > a_0, ΔF_d ≤ 0, w(d) > 0 }。
R68 的缓变故障吸收是特例：COF 速率限制使 A_d 高（抑制增益 ω_cal/ω_f），但未新增独立测量 ⇒ ΔF_d ≤ 0 ⇒ 该方向必然进入 G^A。**吸收监视器**：对滑动窗口统计 (A_d, ΔF_d) 的联合异常，A 升而 ΔF 不升即告警。

**定义 297（多模态交互 act 与协议）** 交互 act u_t = (m_1,…,m_k; ρ; τ)，其中 m_i ∈ ℳ 为通道（视觉/语音/手势/注视/触觉/力/时序），ρ 为指称（对象/区域/意图变量），τ 为时序结构。每个通道携带 (φ_m 换能物理, ω_m 带宽, c_m 标定状态, ℱ_m 失效模式集)。协议 Π 是 act 上的类型化语法，含三类通道间关系：
- 冗余 Rel_red(m,n)：两通道约束同一潜变量；
- 互补 Rel_comp(m,n)：n 的灵敏区覆盖 m 的盲区；
- 矛盾 Rel_con(m,n)：两通道对同一指称的后验预测分歧超过 κ_0。
指称绑定置信 β_m(ρ) ∈ [0,1]；grounding 置信 β(u) = min_i β_{m_i}(ρ)。**矛盾事件不平均掉**，作为一级信号送入 GFA。

**定义 298（独立性证书与有效独立性）** 通道对 (m,n) 的独立性证书 I_{mn} = (ρ_f^{mn}, D_{mn}, O_{mn})：失效模式相关、共享退化指标、带宽重叠。有效独立性
ι_{mn} = (1−ρ_f^{mn})·(1−D_{mn})·(1−O_{mn}) ∈ [0,1]。
当且仅当 ρ_f < ρ_0、D < d_0 且失效模式在物理上不相交（不同换能器 / 不共享 trunk / 不共享标定与电源温度等隐藏共因）时证书通过。**同 trunk 多任务头、同一标定状态的两路、同一教师的两次示范，一律不通过。**

**定义 299（覆盖率膨胀与补盲证据）** 对共享方向 d 等噪、失效相关 ρ_f 的两通道，若系统误当独立，其宣称信息相对真实信息被放大
CI_{mn} = 1 + ρ_f^{mn}，
即真实独立信息 I_true = I_naive / (1 + ρ_f)。补盲证据（对 d 的空白质量下降）须用折扣后信息记账：
Δg_d = ι_{mn} · I(d; y_n | y_m) / H(d)。
未过证书（ι < ι_0）⇒ Δg_d = 0，只记入「相关确认池」。

**定义 300（GFA 补盲证据门控）** 交叉模态证据 E_{m→n} 仅在下列条件全部满足时记入空白账本：(i) 证书通过且 ι ≥ ι_0；(ii) 目标方向 d 落在 m 的盲子空间 B_m（真互补而非冗余）；(iii) 指称绑定 β ≥ β_0；(iv) 无未解释矛盾。否则证据进入确认池、不减少 g_t。GFA 升级 R68 的 CFA：联合后验的似然按 ι 折扣，且先验含 G^A 惩罚（对吸收方向上的「正常」解释降权）。

**定义 301（空白感知阈值与 λ 下限，CAR-G）** 记 g_t = g^S_t + g^B_t + g^A_t（加权）。
λ_floor^G(g_t, U_cal) = max(0.6, 0.8·1[U_cal > τ_cal], 0.8·1[g^A_t > τ_A], 0.9·1[g^B_t 未覆盖])；
τ_risk(G) = τ⁰_risk·(1 − κ_g·g_t)；k ← min(k, k_gap·(1 − c_g·g_t))。
语义：**空白越大越只许收紧**；结构盲区未覆盖时最严（0.9），因为它连「测不到」都不自知。

**定义 302（主动补盲调度，AEG）** 交互 act 的 A-gap 加权信息价值
EVOI(u) = E_{y | do(u)}[ g_t − g_{t+1} ]_{w_A}，权重 w_A > w_B > w_S（A-gap 不可见，必须先花代价审计）。
调度：
u* = argmax_{u ∈ Π_safe} [ EVOI(u) − λ_c·C(u) − λ_r·Risk(u) ] / Δt，
并加两条硬约束：(a) **新测量行约束**：u 的测量算子在 B_t 上必须有非零支撑（否则再采样不降 B-gap）；(b) **安全优先**：暂停/询问/观察类 act 优先于运动类 act，Risk(u) 高时自动降级为保守 abstain。

**定义 303（gap canary 与覆盖证书）**
- **gap canary**：在 B_t 与 G^A 方向注入合成扰动，适应后校验残差未被「修好」：若 ‖r_canary(δ̂′)‖ < 0.3·‖r_canary(δ̂)‖ ⇒ 一票否决（继承 R68 canary 并推广到盲区）；
- **coverage certificate**：对当前操作区域输出裁决 Cov_verdict ∈ {COVERED, ABSTAIN, UNCOVERED}：
COVERED ⇔ g^A_t < τ_A ∧ B_t 的每个决策相关方向都有 ι ≥ ι_0 的独立通道覆盖；
ABSTAIN ⇔ 可安全暂停/询问且 AEG 已排程；
UNCOVERED ⇔ 其余。
除 COVERED 外，决策必须按定义 301 收缩，且不得声明「无故障」。

**定义 304（交互污染与 do-校正）** 主动交互是对被测量系统的干预：证据服从 P(y | do(u)) 而非自然分布 P(y)。污染度 δ_contam(u) = TV(P(· | do(u)), P(·))。覆盖率证据必须用 do-校正权重 w = P(y) / P(y | do(u))（或显式干预模型）入账；若 δ_contam(u) > δ_0，该 act 的证据**只能用于探索，不能用于关闭空白**。N 次未校正查询的累积覆盖偏差 ≤ 1 − (1 − δ_contam)^N。

**定义 305（J_GEM 证书）** J_GEM = (J_CALM, gap_map_hash, (g^S,g^B,g^A), ι_matrix_hash, evoi_trace, cov_verdict, contamin_correction, gem_ver)。
Valid ⇔ Valid(J_CALM) ∧ Cov_verdict ≠ UNCOVERED（或已 ABSTAIN 且 λ ≥ 0.9）∧ 无未记账吸收（G^A 与吸收监视器一致）∧ gap canary 通过 ∧ δ_contam 已校正。

**定义 306（AIC-GEM 干扰集）** ℰ_GEM = ℰ_CALM × ℰ_gap × ℰ_interact；ℰ_gap = {A-gap 漏记、空白账本污染、结构盲区误判、覆盖率膨胀}；ℰ_interact = {指称错绑、矛盾误合并、交互污染、canary 欺骗、观察者效应}。

**定义 307（管线）** 离线：在 ℰ_CALM 上预训练，并用合成盲区标定 Fisher/可观测估计器、为独立性证书建模失效模式；在线：每步更新 G_t → AEG 决定是否交互 → GFA 记账 → CAR-G 收缩 → GAC 七关认证；异步 VQAuditor-G 审计「这次适应把无知搬到了哪里」。

**定义 308（覆盖裁决格与决策收缩）** 裁决格 UNCOVERED ≺ ABSTAIN ≺ COVERED，对应收缩向量 (λ_min, k_scale)：
UNCOVERED → (0.9, 0.0)、ABSTAIN → (0.8, 0.5)、COVERED → R68 默认。
单调性：证据增加（且证书通过）只能使裁决沿 ≺ 反方向移动，**绝不跳级**。

# IP-253 GOM：空白账本 + S/B/A 三分类 + 吸收监视器
class GapObservatory:
    def update(self, h, F, n_eff, absorb):
        self.G_B = {d for d in dirs(h) if F[d] < EPS_B}                 # 结构盲区
        self.G_S = {d: entropy(h, d) for d in dirs(h)
                    if F[d] >= EPS_B and n_eff[d] < N0}                 # 采样空白
        self.G_A = {d for d in dirs(h)
                    if absorb.A[d] > A0 and absorb.dF[d] <= 0}          # 吸收空白
        g = weighted_mass(self.G_S, self.G_B, self.G_A, w=decision_cost)
        return GapState(g, self.G_S, self.G_B, self.G_A)

    def probe_new_row(self, act):
        return support(act.measurement_op, self.G_B) > 0    # 必须在盲区有支撑

    def coverage_verdict(self, g):
        if g.A > TAU_A or uncovered(self.G_B): return 'UNCOVERED'
        if self.aeg_scheduled:                 return 'ABSTAIN'
        return 'COVERED'


# IP-254/255 MIP + IDC：交互协议 + 独立性证书
class InteractionProtocol:
    def ground(self, act):
        return min(beta(m, act.referent) for m in act.channels)

    def relation(self, m, n):
        if self.predictive_div(m, n, kappa0=K0) > K0: return 'CONTRADICTION'
        return 'REDUNDANT' if self.same_latent(m, n) else 'COMPLEMENTARY'


class IndependenceCertificate:
    def iota(self, m, n):
        rho, D, O = self.estimate(m, n)      # 失效相关 / 共享退化 / 带宽重叠
        if not physically_disjoint(m, n):    # 同 trunk / 同标定 / 同电源温度
            return 0.0
        return (1 - rho) * (1 - D) * (1 - O)

    def passed(self, m, n):
        return self.iota(m, n) >= IOTA0


# IP-256 GFA：补盲证据门控（按 ι 折扣，未过证书记 0）
def gap_gated_evidence(E, gap, idc, act, cic):
    m, n, d = act.source, act.target, act.referent_latent
    if not (idc.passed(m, n) and d in gap.blind_of(m)): return 0.0   # 真互补
    if act.grounding < BETA0:                           return 0.0
    E = cic.debias(E, act)                              # do-校正（IP-261）
    return idc.iota(m, n) * mutual_info(E, d) / entropy_prior(d)

def schedule_interaction(gap, protocol, budget, cic):
    best = None
    for u in protocol.safe_acts():                      # 暂停/询问/观察优先
        if not gap.probe_new_row(u):        continue    # 再采样填不了 B-gap

              - C_COST * cost(u) - C_RISK * risk(u)

    return best.u if best and budget > 0 else None

def GEM_RAS_round(M, obs):

## 3. 推导

**引理 16（共模相关的二重性）** R68 引理 15 给出共模相关 ρ 对漂移检测的 SNR 增益 1/√(1−ρ)；但同一对通道对共享方向 d 的独立信息只有其宣称值的 1/(1+ρ)（定义 299）。因此相关性**不能既用于抵消又用于补盲**：若把 ρ 用于共模抵消（R68 的做法），则这对通道计入补盲的独立性预算必须扣减，ι ≤ 1−ρ。系：R68 的 ρ_c=0.75 在检测上换来 SNR×2，在补盲上只剩 25% 的独立信息额度——**同一个 ρ 是一笔只能花一次的预算**。

**引理 17（盲点守恒）** 线性高斯情形：测量 y = Hh + ε，适应只改变估计器/参数（即只改 θ，不改测量算子 H，也无新增独立测量行），则后验在零空间 N(H) 上的协方差不变：Σ_{t+1}|_{N(H)} = Σ_t|_{N(H)}。任何使 row(H) 上残差下降的适应，只是把不确定性从 row(H) 转移到 N(H)，总决策相关不确定度满足
tr(WΣ_{t+1}) ≥ tr(WΣ_t) − I_new，
I_new 为新增独立信息量。无新测量行 ⇒ I_new = 0 ⇒ 盲点质量不降，且 G^A 至少增加被吸收方向的权重。系（对 R68 的直接解释）：**慢故障吸收不是「消除了不确定性」，而是「把故障不确定性搬进了不可见子空间」**；要清零只能靠新模态或 canary。非线性情形在局部 Fisher 近似下同结论。

**引理 18（覆盖率膨胀界）** 若把失效相关 ρ_f 的两通道误当独立并做贝叶斯更新，则后验方差被低估至少 (1+ρ_f) 倍，等价地过度自信 z 分数膨胀 √(1+ρ_f)。若证书按 ι=(1−ρ_f) 折扣入账（定义 299），则实际后验方差回到真实信息界以上，膨胀被消除；残余膨胀仅来自 ρ_f 估计误差 e_ρ，上界为 1 + e_ρ/(1−ρ_f)。要「零膨胀」，须用 ρ̂_f 的置信上界参与折扣（保守取 ι = 1 − ρ̂_f^upper）。

**定理 16（GEM-RAS 端到端风险一致性）** 在 R68 的 A87–A94 与新增 A95–A98（A95 空白账本可估；A96 独立性证书可听；A97 交互污染可测；A98 canary 覆盖盲区）下：
1. P(|τ_cmd − τ*| > ε) ≤ [R68 各项] + α_gap + α_interact，其中 α_gap ≤ P(A-gap 漏记) + P(覆盖率膨胀未折扣) 受引理 17/18 约束，α_interact ≤ 1 − (1 − δ_contam)^N（定义 304）；
2. **空白诚实**：g^A_t > τ_A 或 B_t 未覆盖 ⇒ λ_risk ≥ 0.8（结构未覆盖 ≥ 0.9）∧ k 收缩 ∧ 不得声明「无故障」——由定义 301/303/308 的构造保证，概率为 1；
3. 对非盲方向 d ∉ B_t，检出不劣于 R68：新增证据只收紧不放宽，ι 折扣只削减证据、不抬高风险；
4. 若 gap canary 灵敏度 r_gap ≥ 0.95、证书声呐 ≥ 1−δ_I，则错误覆盖认证概率 ≤ δ_I + (1 − r_gap) + δ_contam。

**定理 17（认证与交互安全）** 七关认证下，坏适配器上线概率 ≤ (1−r_canary)(1−r_gap)·p_h ≤ 0.0025·p_h（r_canary, r_gap ≥ 0.95）；换装仍用 R68 双缓冲，无控制突变；交互污染未校正时禁止关闭空白（定义 304），故「自证覆盖」概率被压到 δ_contam 量级。

## 6. 本轮最大风险

**一句话**：GEM-RAS 把「研究空白」变成可计算、可调度的对象，但空白账本与独立性证书都由系统自己（且可能与待查盲区同源）的模型估计，而主动交互又是对被测量对象的干预——**当系统用自己生成的、非独立的、被干预污染的证据宣布「空白已填」时，它完成的不是补盲，而是把 R68 的「故障被标定吸收」升级为「无知被交互伪造」**：越主动，越可能亲手制造一个看起来已被覆盖的盲区。

**次级风险与缓解**：
1. **空白账本被同一盲区污染**：FIM/可观测估计器若与待查模型同源，会一起盲 → 用异构估计器 + 合成盲区回归 + VQAuditor-G 交叉审计；
2. **独立性证书被隐藏共因欺骗**（共享电源/温度/时钟）→ 主动注入共因探针 + 物理失效模式台账 + ι 取置信下界；
3. **交互污染（观察者效应）**→ do-校正 + δ_contam > δ_0 时禁止关闭空白（定义 304）；
4. **矛盾误合并/指称错绑** → 矛盾作为一级信号、指称绑定置信门槛 β_0、错绑即不记账；
5. **查询成本与安全** → EVOI 减去 cost/risk、暂停/询问优先、预算受限、无法安全查询时直接 ABSTAIN 而非冒险。

**定义 301（CAR-G）** `λ_floor^G=max(0.6, 0.8·1[U_cal>τ_cal], 0.8·1[g^A>τ_A], 0.9·1[g^B未覆盖])`；`τ_risk=τ⁰(1−κ_g g)`；`k←min(k,k_gap(1−c_g g))`——空白越大只许收紧。

**定义 302（AEG）** `u*=argmax[EVOI_wA(u)−λ_c C(u)−λ_r Risk(u)]`，w_A>w_B>w_S；硬约束：新测量行必须在 B_t 有支撑；暂停/询问/观察优先于运动；不安全则 abstain。

**定义 303（gap canary 与覆盖证书）** 盲区注入扰动，适应后 `‖r_canary(δ̂′)‖<0.3‖r_canary(δ̂)‖` 一票否决；Cov_verdict: COVERED ⇔ A-gap<τ_A 且 B_t 全被 ι≥ι_0 独立覆盖；ABSTAIN ⇔ 可安全暂停/询问；其余 UNCOVERED。

**定义 304（交互污染）** 证据服从 P(·|do(u))；`δ_contam=TV(P(·|do u),P(·))`；必须 do-校正；δ_contam>δ_0 的证据只能探索、不能关闭空白；N 次未校正累积偏差 ≤ 1−(1−δ_contam)^N。

**定义 305–308（证书 / 干扰集 / 管线 / 裁决格）** J_GEM 增加空白、ι、EVOI、裁决、污染字段；ℰ_GEM=ℰ_CALM×ℰ_gap×ℰ_interact；在线循环「记账→交互→折扣入账→收缩→七关」；裁决格 UNCOVERED≺ABSTAIN≺COVERED 对应 (0.9,0)/(0.8,0.5)/R68 默认，证据只能反向移动、绝不跳级。

# IP-253 GOM：空白账本 + 三分类 + 吸收监视
class GapObservatory:
    def update(self, h, F, n_eff, absorb):
        self.G_B = {d for d in dirs(h) if F[d] < EPS_B}
        self.G_S = {d: entropy(h, d) for d in dirs(h)
                    if F[d] >= EPS_B and n_eff[d] < N0}
        self.G_A = {d for d in dirs(h)
                    if absorb.A[d] > A0 and absorb.dF[d] <= 0}
        return GapState(weighted_mass(self.G_S, self.G_B, self.G_A),
                        self.G_S, self.G_B, self.G_A)

    def probe_new_row(self, act):
        return support(act.measurement_op, self.G_B) > 0

    def coverage_verdict(self, g):
        if g.A > TAU_A or uncovered(g.G_B): return 'UNCOVERED'
        if self.aeg_scheduled:             return 'ABSTAIN'
        return 'COVERED'

# IP-254/255 MIP + IDC：协议指称/矛盾 + 独立性证书
class InteractionProtocol:
    def ground(self, act): return min(beta(m, act.referent) for m in act.channels)
    def relation(self, m, n):
        if self.predictive_div(m, n) > K0: return 'CONTRADICTION'
        return 'REDUNDANT' if self.same_latent(m, n) else 'COMPLEMENTARY'

class IndependenceCertificate:
    def iota(self, m, n):
        rho, D, O = self.estimate(m, n)
        if not physically_disjoint(m, n): return 0.0
        return (1 - rho) * (1 - D) * (1 - O)
    def passed(self, m, n): return self.iota(m, n) >= IOTA0

# IP-256 GFA：补盲证据按 ι 折扣（未过证书记 0）
def gap_gated_evidence(E, gap, idc, act, cic):
    m, n, d = act.source, act.target, act.referent_latent
    if not (idc.passed(m, n) and d in gap.blind_of(m)): return 0.0
    if act.grounding < BETA0:                           return 0.0
    E = cic.debias(E, act)                              # IP-261 do-校正
    return idc.iota(m, n) * mutual_info(E, d) / entropy_prior(d)

# IP-257 AEG：A-gap 加权 EVOI + 新测量行硬约束
def schedule_interaction(gap, protocol, budget, cic):
    best = None
    for u in protocol.safe_acts():
        if not gap.probe_new_row(u): continue
        val = gap.evoi(u, wA=3, wB=2, wS=1) \
              - C_COST * cost(u) - C_RISK * risk(u)
        if best is None or val > best.val: best = (val, u)
    return best.u if best and budget > 0 else None

# IP-258 GAC：七关认证 + 原子换装
class GapAwareCertification:
    GATES = [gold_regression, auditbuf_replay, tv_bound, risk_bound,
             canary_unfixable, gap_canary, coverage_certificate]
    def maybe_commit(self, shadow, dt):
        if dt < self.T_commit: return None
        verdict = {g.__name__: g(shadow) for g in self.GATES}
        if all(verdict.values()): atomic_swap(self.live_ptr, shadow); return 'PASS'
        log_to_ecac(verdict); return 'REJECT'

# IP-262 主闭环
def GEM_RAS_round(M, obs):

        if act is not None and M.mip.safe(act):

    joint   = M.cfa_gap(M.fir_signature(z, M.residual_log), o['pi'], c, U, g)
    verdict = M.gom.coverage_verdict(g)
    lam_min, k_scale = VERDICT_TABLE[verdict]
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'], lam_min)
    A   = M.ach.propose(x_prime, H=M.vista.H)
    k   = min(M.c_ras_wm.certified_prefix(A, joint, M.m_ras,
                                         M.alpha_chunk, M.wm_preds),
              int(k_scale * len(A)))
    tau = emotion_response_shaping_wm(
        M.pi_sigma.prefix_dispatch(A[:k]) * lam, joint, M.wm_preds)
    M.vqa_g.submit_async(M.wm_preds, {'gap': g, 'verdict': verdict, 'cal': (c, U)})
    M.gac.maybe_commit(M.shadow, M.time_since_last_commit)

## 4. 推导

**引理 16（共模相关的二重性）** 共模相关 ρ 对检测的 SNR 增益为 1/√(1−ρ)，但对补盲的独立信息只剩 1/(1+ρ)（定义 299）。相关性是只能花一次的预算：用于抵消（R68 做法）则必须把 ι 扣到 ≤1−ρ。ρ_c=0.75 ⇒ 检测 SNR×2，但补盲独立额度只剩 25%。

**引理 17（盲点守恒）** 线性高斯 y=Hh+ε，适应只改 θ 不改 H（无新独立测量行）⇒ 后验在 N(H) 上协方差不变；任何 row(H) 残差下降只是把不确定性搬进 N(H)：`tr(WΣ_{t+1}) ≥ tr(WΣ_t) − I_new`，无新测量行则 I_new=0，盲点质量不降、G^A 增。系：R68 的慢故障吸收不是消除不确定性，而是把它搬进不可见子空间。

**引理 18（覆盖率膨胀界）** 把失效相关 ρ_f 的两通道误当独立 ⇒ 后验方差低估 ≥(1+ρ_f) 倍，过度自信膨胀 √(1+ρ_f)。按 ι=(1−ρ_f) 折扣入账可消除膨胀；残余上界 1+e_ρ/(1−ρ_f)；取 ρ̂_f 置信上界可做到零膨胀。

**定理 16（端到端风险一致性）** A87–A98 下：`P(|τ_cmd−τ*|>ε) ≤ [R68 各项] + α_gap + α_interact`；**空白诚实**（未解决 A-gap / 未覆盖结构盲区 ⇒ λ≥0.8/0.9、k 收缩、不得声明无故障）由构造保证概率 1；非盲方向检出不劣于 R68；错误覆盖认证概率 ≤ δ_I+(1−r_gap)+δ_contam。

**定理 17（认证与交互安全）** 七关下坏适配器上线概率 ≤ (1−r_canary)(1−r_gap)p_h ≤ 0.0025 p_h；双缓冲换装无控制突变；未校正污染的证据禁止关闭空白，故「自证覆盖」被压到 δ_contam 量级。

## 7. 本轮最大风险

**一句话**：GEM-RAS 把「研究空白」变成可计算、可调度的对象，但空白账本与独立性证书都由系统自己（且可能与待查盲区同源）的模型估计，而主动交互又是对被测量对象的干预——**当系统用自己生成的、非独立的、被干预污染的证据宣布「空白已填」时，它完成的不是补盲，而是把 R68 的「故障被标定吸收」升级为「无知被交互伪造」**：越主动，越可能亲手制造一个看起来已被覆盖的盲区。

**次级风险与缓解**：空白账本被同一盲区污染（异构估计器 + 合成盲区回归 + VQAuditor-G 交叉审计）；独立性证书被隐藏共因欺骗（共因探针 + 物理失效台账 + ι 取置信下界）；交互污染（do-校正 + δ_contam 超界禁止关闭空白）；矛盾误合并/指称错绑（矛盾一级信号 + β_0 门槛 + 错绑不记账）；查询成本与安全（EVOI 减 cost/risk + 暂停询问优先 + 不安全直接 ABSTAIN）。
