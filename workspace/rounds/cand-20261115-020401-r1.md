# 第 70 轮（承接第 69 轮 FLUID-RAS 的 IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「状态机」×「谐波减速器」）

> R69 把不确定性拆成 aleatoric / epistemic，并让系统学会「看、问、触」。但 R69 与它之前所有轮次共享一个未言明的假设：**被控对象（尤其执行器与传动）在关注的时间尺度上是一个「连续、单模、缓变」的对象**——迟滞、间隙、齿面接触、预紧、磨损都只是要标定掉的「残差」或要收紧的「噪声」。谐波减速器恰恰是反例：它近乎零背隙，却以**迟滞回线、扭转变形、摩擦状态、与分阶段的疲劳/磨损退化**著称；它的输入输出关系**不是无记忆的增益，而是路径依赖的**——同一组 (θ_in, τ) 在不同负载历史下对应不同的 θ_out。用一个连续单模控制器去「标定」它，等于假设一个内部有离散状态、且状态会不可逆迁移的系统没有状态。
>
> 本轮两个灵感正好补上这块：
> - **谐波减速器**给出一个真实、普遍、且安全关键的「执行器自身就是迟滞混合系统」的实例：迟滞回线是**隐藏的绕曲状态**，磨损/疲劳是**物理有序的退化阶段**；
> - **状态机**给出描述「隐藏离散状态 + 守卫迁移 + 不变式」的严格语言：混合自动机、监督控制、模式鲁棒认证。
>
> 核心命题：**在 R68（传感器可信吗）与 R69（该向谁求证）之外，补上「我的传动/身体现在处于哪个离散状态、还能撑多久」；用迟滞感知的混合自动机把执行器建成一个可观测、可认证、可预测寿命的状态机，并把迟滞回线升级为一条不依赖分布的确定性安全包络。** 命名 **HYDRA-RAS**（HYbrid-automaton Drive-state Risk-Adaptive Safety：混合自动机 × 谐波传动的风险自适应闭环）。
>
> 一句话定位：R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「**我的身体在哪个状态、这个状态还安全吗、还剩多少寿命**」——不确定性不只在观测与决策里，也藏在减速器的迟滞回线和磨损阶段里。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 执行器是一个迟滞的机械状态机）**
直觉：谐波减速器的柔轮在波发生器作用下产生可控弹性变形，靠齿啮合传力；这带来高减速比、轻量、近零背隙，但也带来扭转柔度、迟滞与「失动量（lost motion）」。当负载反向时，输出不会立刻跟随，而是先在迟滞带内「空走」；迟滞带内的实际位置取决于**上一次受力方向、预紧和载荷历史**——这正是「有隐藏状态」的定义。更关键：齿面接触、润滑、预紧、磨损是若干**离散工作域**，域内的连续动力学（刚度 k_q、迟滞半宽 h_q、摩擦 μ_q）不同。把减速器当无记忆增益，会把「换域」误判成「噪声变大」，于是 R68 的标定会把一次真实的模式迁移吸收成残差，R69 的模态分解会把机械迟滞误读成策略歧义。

**灵感 2（状态机 → 混合自动机给离散安全一个可验证的骨架）**
直觉：连续控制器擅长「在当前模式下把误差压低」，但不擅长「保证永远不会在不该换域的时候换域」。状态机/混合自动机把迁移显式化：守卫（guard）规定何时允许从 A 域进入 B 域，不变式（invariant）规定域内必须保持的包络；监督控制（Ramadge–Wonham 式）在离散层否决危险迁移。于是安全不再只是「每个动作都小」，而是「**任何被允许的轨迹都不会触发未认证的模式迁移**」。这把 R69「只改选哪个模态、不改安全包络」升级为「**只改离散状态、且迁移本身被认证**」——安全语义从「动作级」上升到「状态迁移级」。

**灵感 3（迟滞回线 → 一条不依赖分布的确定性包络）**
直觉：R69 的 U_epi 是概率性的（模态权重、协方差、VoI）。但迟滞给出一种更强的东西：在给定扭矩 τ 下，真实输出与编码器读数之差**必然**落在 [−h(τ), +h(τ)] 内（play/Preisach 类算子 + 有界摩擦）。这是一条**集合隶属（set-membership）**的硬界，不需要相信任何分布、不需要 ECE 校准。概率界在分布漂移时失效，确定性界只在「迟滞模型本身不成立」时失效——而后者可被在线 play 残差检验。于是 R70 给安全层加一条「不可被概率幻觉绕过」的确定性护栏：概率约束可以被更小的噪声估计放宽，确定性包络不行。

**灵感 4（磨损/疲劳是物理有序的状态机 → 结构化 RUL 与可解释告警）**
直觉：谐波减速器的退化不是任意漂移，而是有物理次序的阶段链：健康 → 润滑劣化 → 齿面磨损/微点蚀 → 柔轮疲劳 → 裂纹/失效。每个阶段有不同发射特征（回差增长、效率下降、温升、振动谐波、迟滞带变宽），且迁移单调（不可回退，或有明确的维修重置）。把这建成**半马尔可夫退化自动机**，R68 的「缓变故障」就从「一个异常分变高」变成「**我正处于哪一段、下一段何时到来**」——直接给出剩余寿命分布与可解释根因。R69 的 FMA 似然第二意见可以从「异常检测」升级为「阶段定位」；两者观测通道不同（行为似然 vs 退化发射），可做正交证据。

**灵感 5（R69 的 probe 信息动作 → 物理模式辨识探针，跨轮复合）**
直觉：R69 已经允许 `g_probe`（方向/力度）作为信息动作。HYDRA 把它专门化：施加一个**有界能量的双向微扭矩**，测迟滞回线的斜率与宽度，从而辨识「当前处于哪个接触/预紧/磨损模式」。这不是新动作，而是 R69 动作空间的一个**语义特化**——R69 问「该探什么」，R70 说「探迟滞回线可以读出隐藏的机械模式」。两轮在此**复合而非并列**：R69 的 VoI 决定值不值得探，R70 的 THA 给出探针的观测模型与安全包络。

**灵感 6（对 R68/R69 的严格包含 → 新层必须是旧层的交集扩展）**
直觉：R68 是「只收紧」的保守主义，R69 是「先分清再决定问不问」。HYDRA 若只是再叠一个独立的黑箱，就又多了一个要单独信任的模块。正确姿态是：**HYDRA 的安全约束 = R69 约束 ∩ 确定性迟滞包络**；当包络退化为零、模式后验单峰、退化处于健康段时，交集退回 R69 本身。这样新层只可能更保守，不可能更激进——延续 R69 定义 307 的「安全侧永不弱于旧层」原则。

**灵感 7（新的风险：错误先验比没有先验更危险）**
直觉：退化自动机的「有序阶段」是一个强先验。如果制造缺陷导致早期裂纹（跳过磨损段），或维修把阶段重置了但观测器不知道，**结构化先验会把真实异常解释成「还没到那一段」**，从而延迟告警。同理，迟滞包络的「确定性」只在摩擦模型正确时成立；若存在速率相关摩擦（Stribeck）、热软化或未建模绕曲，硬界会被击穿——**假严谨（false rigor）比诚实的不确定更危险**，因为它移除了保守退避的理由。本轮必须同时交付：先验违背检测、包络在线自检、Zeno/抖振守卫。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（HYDRA-RAS 总览）** HYDRA-RAS = (THA, DMO, HSE, SCS, DGA, PIM, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69/R68 定义 276-i）；
(ii) **确定性护栏优先**：当 HSE 包络有效时，安全约束取「概率约束 ∩ 确定性包络」的交，绝不用概率约束放宽确定性界；
(iii) **迁移认证**：任何离散模式迁移必须满足已认证守卫，且监督器可在离散层否决；
(iv) **证据纪律继承**：模式判定同样需要 ≥2 正交证据源，单次探针不得单独定案（继承 R69 定义 293-iii）。

**定义 311（传动混合自动机 THA）** H = (Q, X, E, f, Inv, Guard, Reset, Init)，其中
- Q = Q_load × Q_deg，Q_load = {q⁺ 正向驱动, q⁰ 驻留, q⁻ 反向驱动} 为负载/接触域，Q_deg = {S₀ 健康, S₁ 润滑劣化, S₂ 磨损, S₃ 疲劳, S₄ 裂纹} 为退化域；
- X ⊂ ℝⁿ 连续状态（关节角 θ、角速度、扭矩 τ、柔轮绕曲 w、温度 T）；
- f_q 为域内动力学，参数 θ_q = (k_q 扭转刚度, h_q 迟滞半宽, μ_q 摩擦, …)；
- E 为带守卫的迁移；Inv_q 为域内不变式；Reset 在迁移时更新绕曲状态 w 与驻留计数器。

**定义 312（迟滞/绕曲隐藏状态）** 输入 θ_in、减速比 N、输出 θ_out = θ_in/N − w。绕曲 w 服从 play 算子：以 τ 为输入，w ∈ [w⁻, w⁺]，w 仅在 |τ| 增大或方向反转时更新；等价地 θ_out 与 τ 的关系形成一个宽度为 2h(τ) 的迟滞回线。**w 是不可直接测量的隐藏状态**——这是「机械状态机」的连续部分，也是它不能被「无记忆标定」消除的根本原因。

**定义 313（迟滞区间包络 HSE）** 在 τ∈[−τ_max, τ_max] 与给定模式 q 下，真实输出偏差的确定性界：
|θ_out^true − θ_out^enc| ≤ h_q(τ) + ε_enc + ε_model(ν)，
其中 ε_model(ν) 为速率/温度引起的模型松弛项，由在线 play 残差检验给出。HSE 输出的是**区间**而非分布；当 ε_model 不可信（残差持续越界）时 HSE 标记 invalid，退回 R69 概率通道。

**定义 314（迟滞感知模式观测器 DMO）** 维护模式后验 b_t(q) = P(q_t = q | y_{1:t})。观测模型 = 编码器/扭矩/温度/振动发射 + **play 一致性残差** r_play = dist(观测对, 迟滞回线允许带)。迁移先验由定义 311 的 Guard 约束（只有守卫可能满足时才允许迁移），实现「观测驱动 + 物理守卫约束」的混合滤波（类 IMM / 混合粒子滤波）。输出边缘模式概率与**模式混淆度** χ_t = 1 − max_q b_t(q)。

**定义 315（模式混淆与不可辨识对）** 若两模式 q_i, q_j 的发射分布满足 D_KL(p(·|q_i)‖p(·|q_j)) ≤ δ_em 且守卫可同时满足，称其为**不可辨识对**。χ_t 高、或不可辨识对质量显著时，模式判定不成立，HSE 取最保守模式 q_worst = argmin_q safe_envelope(q)。

**定义 316（状态机认证监督 SCS）** 监督器是一个离散安全自动机 S = (Q, Σ_cmd, δ, Q_safe)。对连续控制器提议的动作/迁移，SCS 检查：
(1) 目标模式 q′ 与当前 q 之间的迁移边存在且守卫在当前估计下可满足；
(2) 迁移满足**驻留/迟滞裕度**（禁止在迟滞带内直接反向，必须经 q⁰ 驻留 ≥ d_min）；
(3) q′ 的 Inv 在当前连续状态下可保持（前向可达性）。
任一不满足 ⇒ 否决迁移，仅允许保持当前模式或走已认证的保守迁移。

**定义 317（模式鲁棒前缀认证）** 把 R69/R68 的 certified_prefix 升级：对最坏情形模式 q ∈ Q_belief = {q : b_t(q) ≥ δ_b}（或 HSE 的最坏端点），前缀 (a_{1:k}, g_{1:k}) 必须对**所有** q ∈ Q_belief 安全：
safe_prefix ⇔ ∀q∈Q_belief: prefix_safe_q ∧ 所有前缀内迁移 guard_certified ∧ Inv 保持。
当 Q_belief 单元素时退化为 R69 的单模认证。

**定义 318（退化自动机 DGA）** D = (Q_deg, Λ, A, Π) 为半马尔可夫链：迁移矩阵 A 仅允许 S_i → S_{i+1} 或自环（含停留时间分布），维修迁移允许返回 S₀ 但需显式维修事件；Π 为各阶段发射模型（回差、效率、温升、振动谱、迟滞宽度增长 Δh）。退化观测与 R69 的 FMA 行为似然共享特征，但 DGA 额外要求发射**有序单调**（A95′：阶段可分且不可回退，除维修）。

**定义 319（结构化剩余寿命 RUL）** 给定后验 b_t(q_deg) 与停留时间分布，RUL 为到达吸收态 S₄ 的首达时间分布：p(RUL ≤ t) = P(∃s≤t: q_{deg,s}=S₄)。输出分位数（P50/P90）与阶段置信；RUL 只在模式后验与先验一致时发布，先验违背后置为「未定」。

**定义 320（物理模式辨识探针 PIM）** 复用 R69 g_probe，特化为有界能量双向探针：施加 |τ_p| ≤ τ_p,max、位移 ≤ ε_g、时长 ≤ t_p 的对称微扭矩序列，观测迟滞回线的斜率 k̂、宽度 ĥ、不对称度 â。信息增益 IG(q; y_probe) 与安全约束（不与任务动作冲突、力学包络内）均过 C-RAS-WM。等效于定义 300 的一个物理特化实例。

**定义 321（模式混淆监控器 MCM）** 检测三类故障：(a) 模式后验长期高 χ 或振荡（抖振）；(b) 守卫触发频率过高（Zeno 风险）；(c) 退化发射与阶段先验冲突（先验违背）。任一触发 ⇒ 冻结自动迁移、提高 HSE 保守度、上报 R69 VQAuditor-I 的扩展。

**定义 322（三类不确定性融合）** 最终安全约束取三者交：
- U_ale（R69 模态内噪声）→ R69 λ_floor；
- U_epi（R69 决策歧义）→ R69 MINT；
- **P_plant = HSE 确定性包络 ∪ 模式混淆**→ 本轮硬护栏。
若 P_plant 有效：风险约束用交集；若 P_plant invalid：退回 R69，并**不允许**用 R69 的较小 U 去「抵消」本应更保守的包络。

**定义 323（按模式的安全降额）** 每个模式 q 有降额表 derate(q)（如 S₂ 以上扭矩上限 ×0.85，S₃ 以上速度上限 ×0.7，迟滞带内禁用高频反向）。降额是模式后验的单调平滑函数，避免模式跳变导致指令跳变（对 b 而非 argmax 做平滑）。

**定义 324（威胁模型 ℰ_HYDRA）** ℰ_HYDRA = ℰ_FLUID × ℰ_mode，其中 ℰ_mode 含：模式混淆攻击（注入使两模式发射重合的扰动）、守卫欺骗（伪造传感器使守卫误判可迁移）、先验违背（早期裂纹/维修未登记/换装不同减速器）、迟滞包络击穿（速率相关摩擦被利用）。

**定义 325（证书 J_HYDRA）** J_HYDRA = (J_FLUID, mode_posterior_hash, mode_confusion_χ, hse_valid, hse_width_p95, degradation_stage, rul_p90, guard_certificate_hash, zeno_count, hydra_ver)。Valid ⇔ Valid(J_FLUID) ∧ SCS 未否决 ∧ HSE 有效（或已退回 R69 并记录）∧ MCM 未触发冻结。

**定义 326（先验违背检测 PVD）** 定义阶段-发射一致性分 c_t = 1 − D(p_obs, Π_{q̂})；若 c_t 在 q̂ 下持续低于阈值，而某「非相邻/更晚」阶段解释力更高，判为先验违背，转入开放式阶段估计（不强制有序链），并禁用 RUL 发布直到重新登记。

## 2. 关键算法骨架

```python
# IP-264 THA + IP-266 HSE：迟滞混合自动机与确定性包络
class TransmissionHybridAutomaton:
    def __init__(self, params):              # params[q] = (k_q, h_q, mu_q, ...)
        self.params = params
    def envelope(self, tau, q, eps_enc, eps_model):
        h = self.params[q].h(tau)            # play / Preisach 半宽
        return h + eps_enc + eps_model       # 确定性半界（非分布）
    def guard(self, q, q2, x, b):            # 驻留 + 迟滞裕度 + 可达性
        return (q2 in self.succ(q)) and dwell_ok(q) and margin_ok(q, x)
    def derate(self, b):                     # 对后验平滑降额，防指令跳变
        return sum(b[q] * DERATE[q] for q in b)

# IP-265 DMO：迟滞感知混合滤波（观测驱动 × 守卫约束）
def mode_observer(b_prev, y, H):
    b_pred = H.predict_guarded(b_prev)                  # 只保留守卫允许的迁移
    lik = {}
    for q in H.Q:
        r_play = H.play_residual(y, q)                  # 与迟滞允许带的距离
        lik[q] = H.emission(y, q) * exp(-r_play**2 / (2 * H.params[q].sigma**2))
    b = normalize({q: b_pred[q] * lik[q] for q in H.Q})
    chi = 1 - max(b.values())                           # 模式混淆度
    return b, chi

# IP-267 SCS：状态机认证监督（离散层否决）
def supervise(q, q_next, x, b, H):
    if q_next not in H.succ(q):                return q, False
    if not H.guard(q, q_next, x, b):           return q, False   # 守卫/驻留
    if not invariant_reachable(q_next, x, H):  return q, False
    return q_next, True

# IP-268 / IP-271 DGA：有序退化自动机与结构化 RUL
def degrade_update(b_deg, y_deg, D):
    b = D.predict(b_deg)                                # 允许 S_i->S_{i+1} 或自环
    return normalize(b * D.emission(y_deg))

def rul_posterior(b_deg, D):
    return first_passage_distribution(b_deg, D, absorbing='S4')

# IP-269 PIM：物理模式辨识探针（复用 R69 g_probe，有界能量）
def identify_probe(H, budget, b, c_ras_wm):
    tau_seq = symmetric_micro_torque(tau_max=TAU_P, du_max=EPS_G)
    if not budget.allow(tau_seq):                   return None
    if not c_ras_wm.certify_info(tau_seq, x):       return None
    if info_gain('mode', tau_seq) <= cost(tau_seq): return None
    return tau_seq                                  # 观测后回灌 DMO

# IP-274 主闭环（继承 R69，叠加混合自动机层）
def HYDRA_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                           # R69 一次前向
    # 1) R69 FLUID 层：决策歧义（保持不变）
    U_ale, U_epi, modes = M.fluid.decompose(...)
    # 2) 传动层：模式观测 + 确定性包络
    b, chi = M.dmo.step(M.b_prev, obs, M.tha)
    q_belief = [q for q in M.tha.Q if b[q] >= DELTA_B]
    hse = M.tha.envelope(M.tau, worst_mode(q_belief, M.tha),
                         M.eps_enc, M.eps_model)
    hse_valid = (M.eps_model_ok and chi < TAU_CHI)
    # 3) 模式迁移必须过 SCS；不过则保持
    q_safe, ok = M.scs.supervise(M.q, M.policy.mode_target(modes), M.x, b, M.tha)
    # 4) 退化层：阶段后验 + 先验违背检测 + RUL
    b_deg = M.dga.update(M.b_deg, M.deg_features(obs))
    pvd   = M.pvd.check(obs, b_deg)
    rul   = M.dga.rul(b_deg) if (not pvd and M.dga.converged(b_deg)) else None
    # 5) 模式鲁棒认证：对 q_belief 全体求前缀
    k = M.c_ras_wm.certified_prefix_mode_robust(
            M.ach.propose(...), q_belief, hse if hse_valid else None)
    # 6) 安全融合：确定性包络取交，绝不被概率项放宽
    if hse_valid:
        tau = clip_to_envelope(M.pi_sigma.prefix_dispatch(modes, k), hse)
        tau = tau * M.tha.derate(b)                     # 平滑降额
    else:
        tau = M.fluid.risk_scaled_dispatch(modes, k, U_ale, U_epi)  # 退回 R69
    # 7) 模式不清时用物理探针（走 R69 VoI + 认证）
    if chi > TAU_CHI and not pvd:
        g = M.pim.identify_probe(M.tha, M.budget, b, M.c_ras_wm)
        if g is not None: M.dmo.inject_probe(g)
    # 8) 审计 + 证书
    M.vqa_i.submit(M.q, q_safe, b, chi, hse, rul, pvd)
    return k, tau, q_safe, (b, b_deg, rul)

## 3. 推导

**引理 19（迟滞包络的确定性）** 若真实的输入-输出迟滞关系被定义 312 的 play 算子加有界摩擦（|f_fric| ≤ f_max）与有界编码误差包住，则对任意负载历史，|θ_out^true − θ_out^enc| ≤ h_q(τ) + f_max/k_q + ε_enc。此界**不依赖任何概率分布**，故对分布漂移免疫；只在模型假设被违背（速率相关摩擦、未建模绕曲）时失效，且失效可由定义 314 的 play 残差在线检出。系：HSE 与 R69 的 U_epi 是**不可互抵**的两类界（确定性 vs 概率），必须取交而非取小。

**引理 20（模式鲁棒前缀的跨模式安全）** 若前缀 (a,g) 对每个 q ∈ Q_belief 的域内动力学安全，且每段连续轨迹都未触发未认证迁移，则对真实模式 q* ∈ Q_belief 安全。证：按 q* 的归属分情形，用定义 317 的 ∀q 认证与定义 316 的迁移否决。系：当 Q_belief 含「不可辨识对」时，认证必须对**两个模式同时成立**，这自动把模式混淆转化为更保守（而非错误）的前缀。

**引理 21（监督无 Zeno / 无抖振）** 若迁移守卫含最小驻留 d_min > 0 且相邻域不变式在边界有迟滞裕度 δ_h > 0，则任意有限时间区间内迁移次数有限（无 Zeno），且模式指令对后验做平滑降额后对时间连续。证：每次迁移强制 d_min 的域内停留；迟滞裕度阻止边界反复穿越。

**定理 18（HYDRA 严格包含 FLUID / R68）** 当模式后验退化为单模（χ→0）、迟滞宽度 h→0、且退化自动机处于 S₀ 时，HYDRA 的确定性包络收紧为 0、模式鲁棒认证退化为单模认证、降额表为恒等，故 HYDRA 与 R69 逐指令相同；一般情形下 HYDRA 的风险约束是 R69 约束与 HSE 的交集，故期望风险 ≤ R69。**安全侧只增不减**。⇒ R69、R68 均为 HYDRA 的边界特例。

**定理 19（退化阶段可辨识性与 RUL 界）** 设各阶段发射满足分离条件 D_KL(Π_i‖Π_j) ≥ δ_em > 0（i≠j），且迁移有序（后续阶段不可被跳过观测），则 DMO 的阶段后验在 O(log(1/ε)/δ_em) 帧内收敛到真阶段 ε-邻域；在此条件下 RUL 的 P90 分位数误差 ≤ 停留时间分布的分位数估计误差 + 阶段误判概率 × 相邻阶段期望停留时间。系：**阶段分离越大、停留时间越长，RUL 越可信**；分离不足时 MCM 触发，RUL 置「未定」而非给错值。

**引理 22（探针的信息-安全权衡）** 有界能量双向探针的能量 E_p ≤ τ_p,max·ε_g；其模式辨识信息增益 IG(M; y_probe) 随迟滞宽度 h_q 增大而增大（宽回线给出更可分的斜率/面积特征），故探针只在「模式本就不清」时最值钱；且因能量有界，物理风险 ≤ ε_probe（定理 17 继承）。系：R69 的 VoI 决策在传动层获得一个**物理可执行、可认证**的观测算子。

**定理 20（假严谨的不可接受性——反面刻画）** 若 HSE 的模型项 ε_model 系统性偏低（例如忽略速率相关摩擦），则存在轨迹使真实误差越过 HSE 而安全层仍报告 Valid；此时「确定性护栏」的实际保证弱于一个诚实的、更宽的 R69 概率界。故必须满足定义 313 的在线残差检验：**一旦 play 残差持续越界，HSE 必须置 invalid 并退回 R69 的保守分支**——确定性界只允许「保守地错」，不允许「自信地错」。

## 6. 本轮最大风险

**一句话**：HYDRA 的确定性安全包络只在其 play/摩擦模型**保守**时成立——一旦真实减速器存在速率相关摩擦（Stribeck）、热软化、未建模绕曲，或退化自动机的「有序阶段」先验被早期裂纹/未登记维修违背，系统就会用一条**自信但错误**的硬界替代诚实的概率不确定（假严谨），把「保守地慢下来」偷换成「自信地越界」——**确定性保证一旦不成立，比概率保证更致命，因为它连退避的理由都取消了**。

**次级风险与缓解**：
1. **模式混淆（不可辨识对）** → DMO + χ 度量 + 最保守模式包络 + 物理探针；
2. **假严谨（包络被击穿）** → 在线 play 残差检验 + ε_model 自适应抬高 + 越界即 HSE invalid 退回 R69；
3. **退化先验违背** → PVD 开放式阶段估计 + RUL 置「未定」+ 维修事件显式登记；
4. **Zeno / 抖振** → 最小驻留 + 迟滞裕度守卫 + 对后验平滑降额；
5. **探针本身不安全** → 有界能量 + 位移包络 + C-RAS-WM 认证（继承 R69 定理 17）；
6. **模式鲁棒前缀计算膨胀** → 仅对 b ≥ δ_b 的小模式集认证 + 失效即退回单模 R69。

# IP-264 / IP-266 THA + HSE：迟滞自动机与确定性包络
class TransmissionHybridAutomaton:
    def envelope(self, tau, q, eps_enc, eps_model):
        return self.params[q].h(tau) + eps_enc + eps_model   # 确定性半界
    def guard(self, q, q2, x, b):
        return q2 in self.succ(q) and dwell_ok(q) and margin_ok(q, x)
    def derate(self, b):
        return sum(b[q] * DERATE[q] for q in b)              # 平滑降额

# IP-265 DMO：观测驱动 × 守卫约束
def mode_observer(b_prev, y, H):
    b_pred = H.predict_guarded(b_prev)
    lik = {q: H.emission(y, q) *
              exp(-H.play_residual(y, q)**2 / (2*H.params[q].sigma**2))
           for q in H.Q}
    b = normalize({q: b_pred[q]*lik[q] for q in H.Q})
    return b, 1 - max(b.values())                            # b, χ

# IP-267 SCS：离散层否决危险迁移
def supervise(q, q_next, x, b, H):
    if q_next not in H.succ(q):                return q, False
    if not H.guard(q, q_next, x, b):           return q, False
    if not invariant_reachable(q_next, x, H):  return q, False
    return q_next, True

# IP-268 / IP-271 DGA：有序退化与 RUL
def degrade_update(b_deg, y_deg, D):
    return normalize(D.predict(b_deg) * D.emission(y_deg))

def rul_posterior(b_deg, D):
    return first_passage_distribution(b_deg, D, absorbing='S4')

# IP-269 PIM：有界能量模式辨识探针
def identify_probe(H, budget, b, c_ras_wm):
    seq = symmetric_micro_torque(tau_max=TAU_P, du_max=EPS_G)
    if not budget.allow(seq) or not c_ras_wm.certify_info(seq, x): return None
    if info_gain('mode', seq) <= cost(seq): return None
    return seq                                # 观测后回灌 DMO

# IP-274 主闭环（继承 R69）
def HYDRA_RAS_round(M, obs):
    U_ale, U_epi, modes = M.fluid.decompose(...)              # R69 层不变
    b, chi = M.dmo.step(M.b_prev, obs, M.tha)
    q_belief = [q for q in M.tha.Q if b[q] >= DELTA_B]
    hse = M.tha.envelope(M.tau, worst_mode(q_belief, M.tha),
                         M.eps_enc, M.eps_model)
    hse_valid = (M.eps_model_ok and chi < TAU_CHI)
    q_safe, ok = M.scs.supervise(M.q, M.policy.mode_target(modes), M.x, b, M.tha)
    b_deg = M.dga.update(M.b_deg, M.deg_features(obs))
    pvd = M.pvd.check(obs, b_deg)
    rul = M.dga.rul(b_deg) if (not pvd and M.dga.converged(b_deg)) else None
    k = M.c_ras_wm.certified_prefix_mode_robust(
            M.ach.propose(...), q_belief, hse if hse_valid else None)
    if hse_valid:
        tau = clip_to_envelope(M.pi_sigma.prefix_dispatch(modes, k), hse)
        tau = tau * M.tha.derate(b)                            # 交集 + 平滑降额
    else:
        tau = M.fluid.risk_scaled_dispatch(modes, k, U_ale, U_epi)  # 退回 R69
    if chi > TAU_CHI and not pvd:
        g = M.pim.identify_probe(M.tha, M.budget, b, M.c_ras_wm)
        if g is not None: M.dmo.inject_probe(g)
    M.vqa_i.submit(M.q, q_safe, b, chi, hse, rul, pvd)
    return k, tau, q_safe, (b, b_deg, rul)
```

## 4. 推导

**引理 19（迟滞包络的确定性）** play 算子 + 有界摩擦（|f_fric| ≤ f_max）+ 有界编码误差下，任意负载历史都满足 `|θ_out^true−θ_out^enc| ≤ h_q(τ)+f_max/k_q+ε_enc`；不依赖分布故对漂移免疫，只在模型假设被违背时失效，且可由 play 残差在线检出。系：HSE 与 U_epi 是确定性/概率两类不可互抵的界，必须取交。

**引理 20（模式鲁棒前缀跨模式安全）** 前缀对每个 `q∈Q_belief` 安全且不触发未认证迁移 ⇒ 对真实 q* 安全。系：不可辨识对迫使认证同时对两模式成立，把模式混淆转成更保守的前缀。

**引理 21（监督无 Zeno/无抖振）** 守卫含最小驻留 `d_min>0` 且域边界有迟滞裕度 `δ_h>0` ⇒ 有限时间迁移次数有限；对后验平滑降额 ⇒ 指令连续。

**定理 18（HYDRA 严格包含 FLUID/R68）** 当 `χ→0、h→0、stage=S₀` 时包络收紧为 0、模式鲁棒认证退化为单模、降额为恒等，HYDRA 与 R69 逐指令相同；一般情形风险约束是 R69 与 HSE 的交集，故风险 ≤ R69，安全侧只增不减。

**定理 19（阶段可辨识与 RUL 界）** 阶段发射分离 `D_KL(Π_i‖Π_j) ≥ δ_em` 且迁移有序 ⇒ 阶段后验 `O(log(1/ε)/δ_em)` 帧内收敛；RUL P90 误差 ≤ 停留时间分位数误差 + 阶段误判概率 × 相邻阶段期望停留时间。分离不足时 RUL 置「未定」。

**引理 22（探针信息-安全权衡）** 探针能量 `E_p ≤ τ_p,max·ε_g`，信息增益随迟滞宽度增大而增大（宽回线特征更可分），故只在模式不清时最值钱；能量有界 ⇒ 物理风险 ≤ ε_probe（继承定理 17）。

**定理 20（假严谨的不可接受性）** 若 ε_model 系统性偏低（如忽略 Stribeck），存在轨迹使真实误差越过 HSE 而仍报 Valid，此时确定性保证弱于诚实更宽的 R69 概率界。故 play 残差持续越界必须使 HSE invalid 并退回 R69——确定性界只允许「保守地错」，不允许「自信地错」。

## 7. 本轮最大风险

**一句话**：HYDRA 的确定性安全包络只在其 play/摩擦模型**保守**时成立——一旦真实减速器存在速率相关摩擦（Stribeck）、热软化、未建模绕曲，或退化自动机的「有序阶段」先验被早期裂纹/未登记维修违背，系统就会用一条**自信但错误**的硬界替代诚实的概率不确定（假严谨），把「保守地慢下来」偷换成「自信地越界」——**确定性保证一旦不成立，比概率保证更致命，因为它连退避的理由都取消了**。

**次级风险与缓解**：模式混淆（DMO + χ + 最保守包络 + 探针）；假严谨（play 残差检验 + ε_model 自适应 + 越界退回 R69）；退化先验违背（PVD 开放式阶段 + RUL 置「未定」）；Zeno/抖振（最小驻留 + 迟滞裕度 + 平滑降额）；探针安全（有界能量 + 位移包络 + C-RAS-WM 认证）；鲁棒前缀计算膨胀（仅对小支撑集认证 + 失效退单模）。
