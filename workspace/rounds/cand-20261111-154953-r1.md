# 第 56 轮（承接第 55 轮 v31.5 语义-接触接地；新一轮灵感循环第 1 轮；本轮灵感：「实例分割」×「原型验证」）

> 第 55 轮回答了“接触语义是否可信、全身耦合下是否可行”；本轮再往下追问一层：**这些语义与接触究竟绑定到哪一个具体对象，而该对象所依据的原型是否已被真实验证？** 核心矛盾：**H24**：分割给出的是“杯子”这个类，操作需要的是“这只杯子”这个个体；同形实例、遮挡、掩码合并/分裂与 ID 交换制造的是组合式绑定错误，第 55 轮的像素扰动球无法覆盖。**H25**：原型（外观-部件-可供性-物理属性）只是来自训练分布的假设，而物理原型验证昂贵且可能不可逆；把“长得像”当作“证据可复用”，等于把长尾实例的验证成本转嫁给一次不可逆操作。**H26**：原型不是常量，物体状态（打开、装满、破损）与场景关系会漂移，一次性的系统级原型验证会制造“已验证”的假安全感。

## 0. 直觉与动机

**灵感 1（实例分割 → 从“语义标签”到“个体绑定”）**
直觉：语义分割说“这里有杯子”，实例分割说“这是 3 号杯子，那是 4 号杯子”。机器人抓取、放置、倒水、开柜门，动作从来不是作用在类上，而是作用在个体上。于是失败模式从“像素分类错”升级为“身份绑定错”：两个同形杯子交换 ID、遮挡后重识别错、两个物体被掩码合并成一个、一个物体被拆成两个。这些是组合式错误，靠扩大语义扰动半径无法补救；必须把实例 ID、掩码、嵌入与轨迹作为一等公民。

**灵感 2（原型验证 → 从“一次性系统验证”到“对象证据账本”）**
直觉：原型验证不该只是在交付前跑一遍整机测试，而应变成每个对象档案上的**证据账本**。原型 `π_k` 是对“这只对象能被怎样使用”的一组可伪证断言：可抓、刚性、可盛液体、可开启、重量档位。每条断言有来源、时间戳、支持证据与反例。验证不是“训练集上准确率多少”，而是“在物理样机上，针对该断言做了哪些可复现试验、其 anytime-valid 证据比是多少”。系统级原型验证由此被分解为实例级、可按需增量执行的验证。

**灵感 3（实例边界与遮挡 → “绑定裕度”，而非只是语义裕度）**
直觉：第 55 轮用语义边界裕度防止把脚掌压在标签边界上；实例层面还有更危险的边界：掩码边界、遮挡边界、以及“两个物体之间的接触边界”。在掩码边界附近，身份本身可能属于相邻实例；在遮挡区，实例可能整体不存在或只露出一部分。因此除了语义裕度 `m_s`，还需要**绑定裕度** `m_b(p)=` 接触点到“身份不确定区”的距离，并增加**拓扑一致性**检查：实例计数、面积突变、掩码连通分量分裂，都是身份可能出错的信号。

**灵感 4（主动原型验证 → “先探后做”，探针是一等动作）**
直觉：既然验证需要真实交互，就不要把探针当作调试手段，而应把它写进策略：轻推一下测可动性、短提一下测刚性、换视角看一眼解遮挡、空抓一次测可达性。探针的选择标准不是“最像任务”，而是**单位风险的信息增益**：在可逆、低风险的前提下，优先消除会阻塞后续不可逆动作的关键不确定性。验证感知的护盾只放行“假设已验证或动作可撤销”的动作；放行不了时，输出探针子目标而不是硬做。

**灵感 5（原型聚类与漂移 → “同型共用证据，异型必须分裂”）**
直觉：同一型号的杯子可以共享一部分证据，但共享必须有校准的边界：外观嵌入相近不等于物理属性相同。若把“同形异质”实例并进同一簇，系统就会拿别处的验证结果给未验证对象背书。因此证据池只允许在**统计同质**的原型簇内合并：用分层模型估计簇内实例间方差，异质性超阈值就分裂簇；同时用外观、部件拓扑与状态变化监测原型漂移，任何显著变化都让旧验证证据**过期**并要求重验。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（实例-原型场）**
实例分割与跟踪输出 `I: Ω → {0} ∪ [K]`，其中 `0` 为背景。对每个实例 `k`：
`Π_k = (Ω_k, l_k, e_k, τ_k, π_k)`，`Ω_k⊆Ω` 为掩码，`l_k∈Δ(L)` 为类别分布，`e_k∈R^d` 为实例嵌入，`τ_k` 为轨迹 ID，`π_k=(s_k, parts_k, κ_k, {p_k^φ}, E_k, t_k)` 为原型（形状描述、部件分解、接触可供性、属性后验、证据集、时间戳）。
实例图 `G_I=(V_I,E_I)`，边类型 `{part-of, support, same-track, co-move}`。绑定置信
`b_k(p) = min( mask_post_k(p), temporal_consistency_k, multiview_agreement_k )`。

**定义 128（原型等价类与可迁移证据）**
`k ~ k'` 当且仅当：类别相容、`sim(e_k,e_{k'}) ≥ θ_e`、部件拓扑距离 `d_top(parts_k,parts_{k'}) ≤ θ_t`、且属性相容检验通过。等价类 `𝒞=[k]`。
对属性 `φ`，簇内采用分层模型 `θ_k^φ ~ N(μ_𝒞^φ, (σ_𝒞^φ)²)`，实例层噪声另行估计。证据池 `E_𝒞=∪_{k'∈𝒞}E_{k'}` 只在簇内异质性 `τ_𝒞^φ ≤ τ_max` 时允许合并，否则先分裂簇。迁移权重 `w_{k→𝒞}^φ∈[0,1]` 由共形校准给出，满足
`P( φ(k')=φ(k) | k'~k, w ) ≥ 1-γ(w)`。

**定义 129（属性断言与 anytime-valid 验证状态）**
断言 `c=(k,φ,θ)` 表示“实例 `k` 的属性 `φ` 属于集合 `θ`”。对探针观测序列 `y_{1:t}`，证据过程
`E_t^c = ∏_{i=1}^t [ p(y_i | c 成立) / p(y_i | c 不成立) ]`。
验证状态
```
state(c) = validated   若 E_t^c ≥ 1/α 且无活跃反例
         = falsified   若 E_t^c ≤ α
         = undetermined 其他
```
该判据对任意停时有效，避免“边看边测”导致的显著性膨胀。另记 `t_c` 为证据时间戳，`fresh(c)=1[t-t_c ≤ τ_fresh]`。

**定义 130（探针与信息-风险比）**
探针动作 `a∈A_probe` 携带成本向量 `(t(a), r(a), irr(a))`，观测模型 `y~O(·|c,a)`。期望信息增益
`IG(a)=H(belief(c))-E_{y}[H(belief(c)|y)]`，
信息-风险比 `VoI(a)=IG(a)/(λ_t t(a)+λ_r r(a)+∞·1[irr(a)∧¬pre_validated(a)])`。
只有可逆探针，或其前置断言已 validated 的探针，才允许进入候选集。

**定义 131（验证感知的实例可行性）**
动作 `u` 消费的断言集 `A(u)⊆{c}`（由技能前置条件、接触计划与对象引用生成）。定义
```
V(x) = { u∈A_WB | ∀c∈A(u): state(c)=validated ∨ (Rev(u) ∧ risk(u)≤ε_r)
                    ∧ 第55轮语义-接触约束成立 }
```
验证感知护盾
`u* = argmin_{u∈V(x)} ||u-u_nom||²_W`；若 `V(x)=∅`，输出探针子目标 `a* = argmax VoI(a)` 或安全等待，禁止执行不可逆名义动作。

**定义 132（实例-原型证书）**
`C_ip = (I_core, Π_core, 𝒞_map, V_states, E_log, δ_bind, ρ_proto, τ_fresh, X_counter)`：
- `I_core,Π_core` 为轨迹涉及的核心实例与原型；
- `𝒞_map` 为实例到原型簇的映射及迁移权重；
- `V_states` 为被消费断言的验证状态快照；
- `δ_bind = sup_{p∈Ω_core}(1-b_k(p))` 绑定误差上界；
- `ρ_proto` 为原型扰动球内属性保持概率；
- `X_counter` 为反例集。
若 `δ_bind≤Θ_b`、所有被消费断言 `validated` 或动作可撤销、簇异质性 `≤τ_max`、`fresh(c)=1`、`ρ_proto≥ρ_min` 且 `X_counter=∅`，则实例-原型层面可部署。

## 2. 关键算法 伪代码

### IP-127 IPG（Instance-Prototype Graph）

```python
def instance_prototype_field(rgbd_seq, inst_model, tracker, embed):
    frames = [inst_model.predict(f) for f in rgbd_seq]
    tracks = tracker.associate(frames)                 # multi-frame IDs
    P, mismatch = {}, []
    for k in tracks:
        masks = [m for f in frames for m in f.instances if m.id == k]
        topo_ok, reason = topology_check(masks)        # count/merge/split/area jump
        if not topo_ok:
            mismatch.append((k, reason))
        b = binding_confidence(masks, embed, frames)   # multi-view agreement
        P[k] = Prototype(mask=consensus_mask(masks), emb=embed.mean(masks),
                         parts=part_segment(masks[-1]), conf=b, track=k)
    G = build_instance_graph(P, edge_types=['part-of','support','same-track','co-move'])
    return P, G, mismatch

def topology_check(masks):
    if abs(area(masks[-1]) - area(masks[-2])) / area(masks[-2]) > 0.4:
        return False, 'area_jump'
    if connected_components(masks[-1]) != expected_parts(masks[-1]):
        return False, 'merge_or_split'
    return True, 'ok'
```

### IP-128 PBC（Prototype Belief Calibration）

```python
def update_prototype_belief(claim, y, E_prev, alpha):
    lr = likelihood_ratio(claim, y)
    E_t = E_prev * lr
    if E_t >= 1/alpha and not active_counterexample(claim):
        return 'validated', E_t
    if E_t <= alpha:
        return 'falsified', E_t
    return 'undetermined', E_t

def calibrate_cluster(instances, claims, conformal_q):
    sims = [sim(i.emb, j.emb) for i, j in pairs(instances)]
    labels = [same_physical_property(i, j, claims) for i, j in pairs(instances)]
    w = conformal_transfer_weights(sims, labels, q=conformal_q)
    tau = between_instance_variance(claims)          # hierarchical random effects
    clusters = split_if_heterogeneous(instances, tau, tau_max)
    return w, clusters, tau
```

### IP-129 APV（Active Prototype Validation）

```python
def plan_validation(frontier, A_probe, belief, budget, epsilon_r):
    best = None
    for a in A_probe:
        if not (reversible(a) or all(pre_validated(c) for c in pre(a))):
            continue
        if risk(a) > epsilon_r:
            continue
        ig = expected_information_gain(belief, a)
        voi = ig / (lam_t * time_cost(a) + lam_r * risk(a))
        if best is None or voi > best.voi:
            best = Probe(a, voi, ig)
    if best is None or best.voi < voi_min:
        return 'defer_or_ask'
    return best

def sequential_validate(claims, probe_policy, budget, alpha):
    for c in claims:
        while state(c) == 'undetermined' and budget.left > 0:
            a = probe_policy(c)
            y = execute_reversible_probe(a)          # physical prototype trial
            state(c), E = update_prototype_belief(c, y, E(c), alpha)
            budget.charge(a)
        if state(c) == 'undetermined':
            return ('reject', 'validation_budget_exhausted', c)
    return ('ok', states(claims))
```

### IP-130 IVS（Instance Viability Shield）

```python
def instance_viability_shield(u_nom, x, claims_of, V_states, Rev, risk):
    A_u = claims_of(u_nom)
    blocked = [c for c in A_u if V_states[c] != 'validated'
               and not (Rev(u_nom) and risk(u_nom) <= eps_r)]
    if blocked:
        a = plan_validation(blocked, PROBES, beliefs, budget, eps_r)
        if a == 'defer_or_ask':
            return safe_wait(x), 'validation_blocked'
        return probe_subgoal(a), 'probe_required'
    u = qp_project(u_nom, x, semantic_contact_constraints())   # 第55轮约束
    return u, 'ok'
```

### IP-131 PVC（Prototype Validity Certificate）

```python
def prototype_certificate(traj, P, clusters, V_states, budgets):
    used = instances_referenced(traj)
    delta_bind = max(1 - P[k].conf for k in used)
    if delta_bind > budgets.Theta_b:
        return ('reject', 'binding_uncertain', delta_bind)
    for c in consumed_claims(traj):
        if V_states[c] != 'validated' and not action_reversible(traj, c):
            return ('reject', 'unvalidated_irreversible', c)
        if not fresh(c, budgets.tau_fresh):
            return ('reject', 'stale_prototype', c)
    if heterogeneity(used, clusters) > budgets.tau_max:
        return ('reject', 'cluster_contaminated')
    rho = prototype_robustness(P, used, budgets.eps_proto)
    if rho < budgets.rho_min or active_counterexamples(used):
        return ('reject', 'prototype_unsound', rho)
    return ('ok', InstanceCert(used, clusters, V_states, delta_bind, rho))
```

### IP-132 PCT（Prototype Cluster Transfer & Drift Monitor）

```python
def transfer_and_monitor(k_new, clusters, evidence, state_history):
    C = nearest_homogeneous_cluster(k_new, clusters)
    if C is None or sim(k_new.emb, C.prototype.emb) < theta_e:
        return 'probe_required', None                  # no evidence reuse
    w = calibrated_weight(k_new, C)
    if w < w_min:
        return 'probe_required', C
    pooled = pool_evidence(evidence[C], k_new, w)      # weighted, not naive union
    drift = change_detect(state_history[k_new], C.state_model)
    if drift:
        invalidate(C, k_new)                           # freshness reset
        if residual_heterogeneity(C) > tau_max:
            clusters = split_cluster(C)                # 异型必须分裂
        return 'revalidate', clusters
    return 'reuse', pooled
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| IPG | O(T·|Ω| + K² + K·d) | O(T·|Ω| + K·d) | 多视图一致、拓扑检查完备 |
| PBC | O(|E|·|Φ| + K²·d) | O(K·|Φ|) | 共形迁移校准、异质性检验 |
| APV | O(|A_probe|·(|C|+rollout)) | O(|C|) | 探针可逆、VoI 估计无偏 |
| IVS | O(QP + |A(u)|) | O(|A_WB|) | 不可逆动作闸门 sound |
| PVC | O(|轨迹|·|C|) | O(|C|+|E|) | 断言集合完备、时间戳新鲜 |
| PCT | O(K²·d + |E|) | O(K·d) | 证据加权而非朴素并集 |

**正确性定理（Instance-Prototype Validation Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 实例掩码与跟踪经校准，核心区绑定误差 `δ_bind≤Θ_b` 的概率至少 `1-α_b`；**(A34)** 原型簇相似度到属性一致性的迁移由共形校准给出，且簇内异质性 `τ_𝒞≤τ_max`；**(A35)** 探针观测模型诚实、证据过程为任意停时有效的 e-process，且可逆探针无未建模副作用；**(A36)** 原型新鲜度在 `τ_fresh` 内，或漂移被监测并触发重验。
则部署后单步安全概率：
```
P_safe ≥ 1 - P(δ_bind>Θ_b) - P(cluster transfer error) - P(∃c: undetermined ∧ acted)
          - P(drift undetected) - P(shield fallback fails) - P(第55轮语义失守)
```
关键：**绑定有界、证据按簇校准、不可逆动作只信已验证断言、漂移使证据过期**；任何一层失守都不允许把“看起来是同一类”当作“已被验证的这一个”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 同形异质导致证据交叉污染 | 高 | 共形迁移权重 + 簇内异质性检验 + 异型强制分裂/探针 |
| 实例合并/分裂与 ID 交换 | 高 | 多视图与运动一致性 + 拓扑检查 + 绑定裕度 + 主动重识别 |
| 探针自身不可逆或有副作用 | 高 | 只允许可逆探针 + 风险预算 + 仿真预检 + 人工确认兜底 |
| 原型漂移漏检导致旧证据继续放行 | 高 | 新鲜度时间戳 + 状态变化检测 + 定期重验 |
| 验证成本造成任务超时或“冻结” | 中 | VoI 调度 + 同质簇证据复用 + 可撤销降级动作 + 预算感知规划 |

## 6. 本轮最大风险

**一句话**：本方案的 soundness 最终压在“同形即同质”的原型聚类假设上——一旦实例嵌入把外观相似但物理属性不同的对象并入同一证据池，系统就会用别处的验证结果为未验证个体背书、跳过探针直接执行不可逆接触；因此必须以共形校准的迁移权重、簇内异质性检验/分裂、以及不可逆动作闸门三重护栏，宁可多探一次，也绝不让相似性冒充已验证。

| 符号 | 含义 |

| `π_k=(s_k,parts_k,κ_k,{p_k^φ},E_k,t_k)` | 原型内容：形状、部件、接触可供性、属性后验、证据、时间戳 |

**定义 127（实例-原型场）** 见 IPG 输出；绑定置信 `b_k(p)=min(mask_post_k(p),temporal_consistency_k,multiview_agreement_k)`。

**定义 128（原型等价类与可迁移证据）** `k~k'` 需类别相容、`sim(e_k,e_{k'})≥θ_e`、部件拓扑距离 `≤θ_t`、属性相容检验通过。簇内分层模型 `θ_k^φ~N(μ_𝒞^φ,(σ_𝒞^φ)²)`；仅当 `τ_𝒞^φ≤τ_max` 才允许合并证据，否则先分裂。

**定义 129（属性断言与验证状态）** `c=(k,φ,θ)`；`E_t^c=∏ p(y_i|c)/p(y_i|¬c)`；`E_t≥1/α⇒validated`，`E_t≤α⇒falsified`，否则 `undetermined`。`fresh(c)=1[t-t_c≤τ_fresh]`。

**定义 130（探针与信息-风险比）** 候选探针必须可逆或前置已验证；`VoI=IG/(λ_t t+λ_r r)`。

**定义 131（验证感知实例可行性）**
```
V(x)={u∈A_WB | ∀c∈A(u):state(c)=validated ∨ (Rev(u)∧risk(u)≤ε_r)
                 ∧ 第55轮语义-接触约束成立}
```
`V(x)=∅` 时输出 `argmax VoI` 探针子目标或安全等待，不执行不可逆名义动作。

**定义 132（实例-原型证书）** 可部署当且仅当：`δ_bind≤Θ_b`、被消费断言全部 validated 或动作可撤销、簇异质性 `≤τ_max`、`fresh=1`、`ρ_proto≥ρ_min`、`X_counter=∅`。

## 2. 关键算法 伪代码

### IP-127 IPG（Instance-Prototype Graph）

```python
def instance_prototype_field(rgbd_seq, inst_model, tracker, embed):
    frames = [inst_model.predict(f) for f in rgbd_seq]
    tracks = tracker.associate(frames)
    P, mismatch = {}, []
    for k in tracks:
        masks = [m for f in frames for m in f.instances if m.id == k]
        topo_ok, reason = topology_check(masks)
        if not topo_ok:
            mismatch.append((k, reason))
        b = binding_confidence(masks, embed, frames)
        P[k] = Prototype(mask=consensus_mask(masks), emb=embed.mean(masks),
                         parts=part_segment(masks[-1]), conf=b, track=k)
    G = build_instance_graph(P, edge_types=['part-of','support','same-track','co-move'])
    return P, G, mismatch

def topology_check(masks):
    if abs(area(masks[-1]) - area(masks[-2])) / area(masks[-2]) > 0.4:
        return False, 'area_jump'
    if connected_components(masks[-1]) != expected_parts(masks[-1]):
        return False, 'merge_or_split'
    return True, 'ok'
```

### IP-128 PBC（Prototype Belief Calibration）

```python
def update_prototype_belief(claim, y, E_prev, alpha):
    E_t = E_prev * likelihood_ratio(claim, y)
    if E_t >= 1/alpha and not active_counterexample(claim):
        return 'validated', E_t
    if E_t <= alpha:
        return 'falsified', E_t
    return 'undetermined', E_t

def calibrate_cluster(instances, claims, conformal_q, tau_max):
    sims   = [sim(i.emb, j.emb) for i, j in pairs(instances)]
    labels = [same_physical_property(i, j, claims) for i, j in pairs(instances)]
    w      = conformal_transfer_weights(sims, labels, q=conformal_q)
    tau    = between_instance_variance(claims)
    clusters = split_if_heterogeneous(instances, tau, tau_max)
    return w, clusters, tau
```

### IP-129 APV（Active Prototype Validation）

```python
def plan_validation(frontier, A_probe, belief, budget, epsilon_r):
    best = None
    for a in A_probe:
        if not (reversible(a) or all(pre_validated(c) for c in pre(a))):
            continue
        if risk(a) > epsilon_r:
            continue
        ig  = expected_information_gain(belief, a)
        voi = ig / (lam_t * time_cost(a) + lam_r * risk(a))
        if best is None or voi > best.voi:
            best = Probe(a, voi, ig)
    if best is None or best.voi < voi_min:
        return 'defer_or_ask'
    return best

def sequential_validate(claims, probe_policy, budget, alpha):
    for c in claims:
        while state(c) == 'undetermined' and budget.left > 0:
            a = probe_policy(c)
            y = execute_reversible_probe(a)
            state(c), E = update_prototype_belief(c, y, E(c), alpha)
            budget.charge(a)
        if state(c) == 'undetermined':
            return ('reject', 'validation_budget_exhausted', c)
    return ('ok', states(claims))
```

### IP-130 IVS（Instance Viability Shield）

```python
def instance_viability_shield(u_nom, x, claims_of, V_states, Rev, risk, eps_r):
    A_u = claims_of(u_nom)
    blocked = [c for c in A_u if V_states[c] != 'validated'
               and not (Rev(u_nom) and risk(u_nom) <= eps_r)]
    if blocked:
        a = plan_validation(blocked, PROBES, beliefs, budget, eps_r)
        if a == 'defer_or_ask':
            return safe_wait(x), 'validation_blocked'
        return probe_subgoal(a), 'probe_required'
    u = qp_project(u_nom, x, semantic_contact_constraints())   # IP-123/126
    return u, 'ok'
```

### IP-131 PVC（Prototype Validity Certificate）

```python
def prototype_certificate(traj, P, clusters, V_states, budgets):
    used = instances_referenced(traj)
    delta_bind = max(1 - P[k].conf for k in used)
    if delta_bind > budgets.Theta_b:
        return ('reject', 'binding_uncertain', delta_bind)
    for c in consumed_claims(traj):
        if V_states[c] != 'validated' and not action_reversible(traj, c):
            return ('reject', 'unvalidated_irreversible', c)
        if not fresh(c, budgets.tau_fresh):
            return ('reject', 'stale_prototype', c)
    if heterogeneity(used, clusters) > budgets.tau_max:
        return ('reject', 'cluster_contaminated')
    rho = prototype_robustness(P, used, budgets.eps_proto)
    if rho < budgets.rho_min or active_counterexamples(used):
        return ('reject', 'prototype_unsound', rho)
    return ('ok', InstanceCert(used, clusters, V_states, delta_bind, rho))
```

### IP-132 PCT（Prototype Cluster Transfer & Drift Monitor）

```python
def transfer_and_monitor(k_new, clusters, evidence, state_history):
    C = nearest_homogeneous_cluster(k_new, clusters)
    if C is None or sim(k_new.emb, C.prototype.emb) < theta_e:
        return 'probe_required', None
    w = calibrated_weight(k_new, C)
    if w < w_min:
        return 'probe_required', C
    pooled = pool_evidence(evidence[C], k_new, w)      # 加权，不做朴素并集
    if change_detect(state_history[k_new], C.state_model):
        invalidate(C, k_new)
        if residual_heterogeneity(C) > tau_max:
            clusters = split_cluster(C)
        return 'revalidate', clusters
    return 'reuse', pooled
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| IPG | O(T·|Ω| + K² + K·d) | O(T·|Ω| + K·d) | 多视图一致；拓扑检查覆盖 merge/split/ID swap |
| PBC | O(|E|·|Φ| + K²·d) | O(K·|Φ|) | 共形迁移校准；异质性检验阻止跨界合并 |
| APV | O(|A_probe|·(|C|+rollout)) | O(|C|) | 探针可逆；anytime-valid 无显著性膨胀 |
| IVS | O(QP + |A(u)|) | O(|A_WB|) | 不可逆动作闸门 sound |
| PVC | O(|轨迹|·|C|) | O(|C|+|E|) | 断言集完备、证书可独立重放 |
| PCT | O(K²·d + |E|) | O(K·d) | 证据加权；漂移使旧证据失效 |

**正确性定理（Instance-Prototype Validation Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 实例掩码/跟踪校准，核心区 `P(δ_bind≤Θ_b)≥1-α_b`；**(A34)** 原型簇相似度→属性一致性的迁移由共形校准，且 `τ_𝒞≤τ_max`；**(A35)** 探针观测模型诚实、证据过程为任意停时有效的 e-process，可逆探针无未建模副作用；**(A36)** 原型新鲜度在 `τ_fresh` 内或漂移监测触发重验。
则：
```
P_safe ≥ 1 - P(δ_bind>Θ_b) - P(cluster transfer error) - P(∃c: undetermined ∧ acted)
          - P(drift undetected) - P(shield fallback fails) - P(第55轮语义失守)
```
**关键**：绑定有界、证据按同质簇校准、不可逆动作只信已验证断言、漂移使证据过期。任一层失守，都不允许把“看起来同类”当作“已被验证的这一个”。

## 7. 本轮最大风险

**一句话**：v32 的 soundness 最终压在“同形即同质”的原型聚类假设上——一旦实例嵌入把外观相似但物理属性不同的对象并入同一证据池，系统就会用别处的验证结果为未验证个体背书、跳过探针直接执行不可逆接触；因此必须以共形校准的迁移权重、簇内异质性检验/分裂、以及不可逆动作闸门三重护栏，宁可多探一次，也绝不让相似性冒充已验证。
