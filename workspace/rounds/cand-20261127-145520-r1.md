### 第 1 轮灵感驱动研究记录（SSCDE 增量）

**灵感词**：自监督学习、数据配比

**直觉与动机**：
前序 v30 CADVS 把安全责任几乎全部压在「证书」上：教师轨迹蒸馏出学生，学生只有在十二证与新增证书全部通过时才被准入。但这留下一个结构性缺口——**证书只校验「当前状态是否安全」，不校验「学生是否见过足够多样的世界」**。真实机器人绝大多数运行时间是无标注的连续传感流；若学生只在教师成功轨迹上训练，它会在证书边界附近的失败模式上「没见过、也不会处理」，形成一种被高通过率掩盖的脆弱性。

自监督学习给出第一把钥匙：无需人工标注，从无标签真实流中构造掩码状态预测、时序对比、跨模态对齐等任务，让表示覆盖真实分布的长尾，而不是只拟合教师成功轨迹的窄流形。数据配比给出第二把钥匙：教师成功轨迹、无标签真实流、证书失败回放、仿真四类数据，对「证书失效模式覆盖率」的边际贡献完全不同，必须动态配比，而非等权混合。

**核心洞见**：把证书从「事后准入过滤器」提升为「训练期的数据选择与表示学习信号」——证书违规模式决定哪些无标签片段值得自监督、哪些失败样本必须回放、各数据源权重如何随在线违规率自适应。这样学生不是「被证书拦住」，而是「被证书教会该看什么」。三者的闭环是：证书定义失效模式 → 失效模式指导自监督正负样本与数据配比 → 更覆盖的表示反过来降低证书违规率 → 新的违规模式再进入下一轮。

**形式化目标（增量）**：
1. 定义证书条件自监督目标 L_CCSE：以证书向量 c_t 为条件，正样本限定在同一证书上下文内，负样本按证书失效模式分层采样。
2. 定义四源数据配比单纯形 α = (α_T, α_U, α_F, α_S) 与配比证书 DMC = (α, ESS, ρ_cov, skew)，其中 ESS 为有效样本量、ρ_cov 为失效模式覆盖率、skew 为配比偏斜度。
3. 定义失效模式覆盖率 ρ_cov = min_{m∈M} ρ_m，M 为证书失效模式集合，ρ_m 为模式 m 的样本覆盖比。
4. 定义自监督新颖性证书 kc_ssl_novel 与配比覆盖证书 kc_mix_cov，作为新增准入规则，使 Exec_SSCDE ⊆ Exec_CADVS。
5. 目标：在同等标注与算力预算下，将学生未见失效模式上的违规率降低 ≥40%，同时不降低已覆盖模式的证书通过率；配比证书 DMC.valid 在 ≥90% 训练窗口内成立。

**本轮最大风险**：**证书回声室（certificate echo chamber）**——若把「证书通过」直接当作自监督与配比的正向信号，表示与数据分布会向「容易通过证书」的区域坍缩，模型学到的是「讨好证书」而非「理解世界」；证书本身不完备的盲区会被系统性放大，表现为证书通过率上升而真实安全边界收缩。

### IP-478 Certificate-Conditioned Self-Supervised Encoder (CCSE)

```python
@dataclass
class CertificateConditionedSSEncoder:
    """CCSE：证书条件自监督，正样本同证书上下文，负样本按失效模式分层"""
    latent_dim: int = 128
    tau_temp: float = 0.10          # InfoNCE 温度
    mask_ratio: float = 0.30        # 掩码比例
    delta_c: float = 0.25           # 证书上下文同分布阈值
    n_neg_per_mode: int = 8         # 每个失效模式最少负样本数
    beta_cond: float = 0.02         # 证书弱正则权重（刻意取小）

    def cert_context(self, cert_agg) -> np.ndarray:
        """c_t = 归一化证书向量；缺失证书用显式 mask 位，不用 0 冒充"""
        feats = []
        for cid in self.cert_ids:
            c = cert_agg.get(cid)
            if c is None:
                feats += [0.0, 0.0, 0.0, 1.0]       # valid, margin, age, missing
            else:
                feats += [float(c.valid), float(c.margin),
                          float(c.age / self.cert_timeout), 0.0]
        return normalize(np.asarray(feats, dtype=np.float32))

    def positive_pairs(self, batch):
        """正样本：同一轨迹、时间近邻、且 ‖c_i − c_j‖ < δ_c"""
        pairs = []
        for i, j in temporal_neighbors(batch):
            if np.linalg.norm(batch.c[i] - batch.c[j]) < self.delta_c:
                pairs.append((i, j))
        return pairs

    def stratified_negatives(self, anchor, batch):
        """负样本按失效模式分层：每个 m 至少 n_neg_per_mode 个，防止多数模式淹没少数模式"""
        negs = []
        for m in self.failure_modes:
            pool = [j for j in batch.indices
                    if m in batch.failure_modes[j] and j != anchor]
            negs += sample(pool, self.n_neg_per_mode)
        return negs

    def loss(self, batch) -> tuple[float, dict]:
        x_masked = apply_mask(batch.x, self.mask_ratio)
        z = self.encoder(x_masked)                       # 掩码预测表示
        z_pos = self.encoder(batch.x_pos)
        l_align = 0.0
        for i, j in self.positive_pairs(batch):
            negs = self.stratified_negatives(i, batch)
            logits = [sim(z[i], z_pos[j]) / self.tau_temp]
            logits += [sim(z[i], z[jj]) / self.tau_temp for jj in negs]
            l_align += -log_softmax(logits)[0]
        l_align /= max(1, len(batch))
        # 弱正则：从 z 预测 c_t，但 c 分支 stop-gradient，且权重很小，
        # 只用于防止表示与证书语义完全脱钩，不作为主训练信号
        c_hat = self.cert_head(stopgrad(z))
        l_cond = mse(c_hat, batch.c)
        return l_align + self.beta_cond * l_cond, {
            'align': l_align, 'cond': l_cond,
            'pos_rate': len(self.positive_pairs(batch)) / max(1, len(batch)),
        }
```

### IP-479 Certificate-Aware Data Mixture Optimizer (CADMO)

```python
@dataclass
class CertificateAwareDataMixtureOptimizer:
    """CADMO：四源单纯形配比 + 失效模式边际覆盖增益 + ESS/skew 约束"""
    eta: float = 0.05
    ess_min: float = 2.5
    skew_max: float = 8.0
    delta_cov: float = 0.80
    sources: tuple = ('teacher', 'unlabeled', 'failure', 'sim')

    def __post_init__(self):
        self.alpha = np.array([0.30, 0.35, 0.20, 0.15])   # 先验配比

    def marginal_coverage_gain(self, source: str, coverage: dict) -> float:
        """估计把一单位配额从其它源移到 source 时，最稀缺失效模式的覆盖率增益"""
        counts = self.source_mode_counts[source]
        gains = []
        for m, rho_m in coverage.items():
            # 边际增益随已覆盖度递减：min(1, n_m/k_min) 的下一单位
            need = max(0.0, 1.0 - rho_m)
            gains.append(need * (counts.get(m, 0) / max(1, sum(counts.values()))))
        return float(np.mean(gains)) if gains else 0.0

    def update(self, coverage: dict, violation_rate: dict) -> DMC:
        grad = np.array([self.marginal_coverage_gain(s, coverage)
                         for s in self.sources])
        # 失败模式越严重，越抬高 failure 回放配额
        grad[2] += float(np.mean(list(violation_rate.values()))) if violation_rate else 0.0
        alpha = project_simplex(self.alpha + self.eta * grad)
        # 硬约束：ESS 与偏斜度；不满足则向均匀分布回拉
        alpha = self._project_constraints(alpha)
        self.alpha = alpha
        ess = 1.0 / float(np.sum(alpha ** 2))
        skew = float(alpha.max() / max(alpha.min(), 1e-9))
        rho_cov = float(min(coverage.values())) if coverage else 0.0
        valid = (ess >= self.ess_min and skew <= self.skew_max
                 and rho_cov >= self.delta_cov)
        return DMC(alpha=alpha, ess=ess, rho_cov=rho_cov,
                   skew=skew, valid=valid)

    def _project_constraints(self, alpha: np.ndarray) -> np.ndarray:
        """先投影到单纯形，再用二分把最小分量抬到满足 ESS/skew 的水平"""
        alpha = project_simplex(alpha)
        for _ in range(20):
            ess = 1.0 / float(np.sum(alpha ** 2))
            skew = float(alpha.max() / max(alpha.min(), 1e-9))
            if ess >= self.ess_min and skew <= self.skew_max:
                break
            alpha = 0.9 * alpha + 0.1 * np.ones(4) / 4.0   # 向均匀回拉
        return alpha

    def sample_batch(self, rng, batch_size: int):
        """按 α 分配四源配额；余数用最大余数法保证恰好 batch_size"""
        quotas = allocate_largest_remainder(self.alpha, batch_size)
        return concat([rng.sample(self.datasets[s], n)
                       for s, n in zip(self.sources, quotas)])
```

### IP-480 Failure-Mode Coverage Certificate (FMCC)

```python
@dataclass
class FailureModeCoverageCertificate:
    """FMCC：把「数据是否覆盖每个证书失效模式」变成可准入的证书"""
    modes: set
    k_min: int = 50               # 每个模式的最低样本数
    delta_cov: float = 0.80

    def compute(self, replay_buffer) -> FMCC:
        rho = {}
        for m in self.modes:
            n_m = sum(1 for x in replay_buffer if m in x.failure_modes)
            rho[m] = min(1.0, n_m / self.k_min)
        rho_cov = min(rho.values()) if rho else 1.0
        # 覆盖率证书还要记录「最稀缺模式」，供 CADMO 定向补数据
        rarest = min(rho, key=rho.get) if rho else None
        return FMCC(rho=rho, rho_cov=rho_cov, rarest=rarest,
                    valid=rho_cov >= self.delta_cov)

    def cert_payload(self, fmcc: FMCC) -> dict:
        return {
            'cert_id': 'kc_mix_cov',
            'payload': {'valid': bool(fmcc.valid),
                        'rho_cov': fmcc.rho_cov,
                        'rarest_mode': fmcc.rarest,
                        'rho': fmcc.rho},
            't_stamp': time.time(),
            'validity_window': self.train_window_sec * 2,
            'src_node': 'data_engine',
        }
```

### IP-481 Self-Supervised Novelty Certificate (SSNC)

```python
@dataclass
class SelfSupervisedNoveltyCertificate:
    """SSNC：用自监督残差判定「学生是否见过当前状态」，作为准入而非训练奖励"""
    tau_rec: float = 0.15
    tau_pred: float = 0.10
    tau_lat: float = 0.85

    def evaluate(self, x_t, x_next, z_t, z_prev, z_pred_next) -> SSNC:
        e_rec = float(np.linalg.norm(x_t - self.decoder(z_t)))
        e_pred = float(np.linalg.norm(self.encoder(x_next) - z_pred_next))
        k_lat = float(cosine(z_t, z_prev))
        valid = (e_rec < self.tau_rec and e_pred < self.tau_pred
                 and k_lat > self.tau_lat)
        return SSNC(e_rec=e_rec, e_pred=e_pred, k_lat=k_lat, valid=valid)

    def cert_payload(self, ssnc: SSNC) -> dict:
        return {
            'cert_id': 'kc_ssl_novel',
            'payload': {'valid': bool(ssnc.valid),
                        'e_rec': ssnc.e_rec, 'e_pred': ssnc.e_pred,
                        'k_lat': ssnc.k_lat},
            't_stamp': time.time(),
            'validity_window': 1.0 / self.control_freq_hz * 3,
            'src_node': 'student',
        }
```

### IP-482 SSCDE Training Orchestrator (STO)

```python
def sscde_train_step(orch, cert_agg, sensor_stream, step: int):
    """
    训练期闭环：证书 → 失效模式 → 自监督 + 配比 → 影子评估 → 回滚
    注意：证书只用于「选择学什么」和「准入」，绝不直接作为梯度奖励信号。
    """
    # 1) 更新失效模式集合：把本窗口违规证书聚类进 M
    orch.failure_modes.update(cluster_violations(cert_agg))

    # 2) 每 K 步重估覆盖率证书与配比证书
    if step % orch.K == 0:
        fmcc = orch.fmcc.compute(orch.replay_buffer)
        dmc = orch.cadmo.update(coverage=fmcc.rho,
                                violation_rate=orch.violation_rate())
        if not dmc.valid:
            # 覆盖率不足：不训练学生，先定向补数据（失败回放优先）
            orch.request_replay(fmcc.rarest, n=orch.K * orch.batch_size)
            return {'status': 'replay_only', 'dmc': dmc, 'fmcc': fmcc}

    # 3) 证书条件自监督更新（用无标签真实流 + 分层失败回放）
    batch = orch.cadmo.sample_batch(orch.rng, orch.batch_size)
    batch = attach_cert_context(batch, cert_agg)
    loss, stats = orch.ccse.loss(batch)
    orch.optimizer.zero_grad()
    loss.backward()
    orch.optimizer.step()

    # 4) 影子评估：在「留出的失效模式」上测违规率，防止证书回声室
    if step % orch.shadow_every == 0:
        shadow = orch.shadow_eval(orch.heldout_modes)
        if shadow.violation_rate > orch.shadow_threshold:
            # 表示向易通过区域坍缩 → 回滚编码器，并降低证书弱正则权重
            orch.rollback_encoder()
            orch.ccse.beta_cond *= 0.5
            orch.log('echo_chamber_guard_triggered', shadow)

    return {'status': 'train', 'loss': loss, **stats}
```

## 4. 正确性论证（增量更新）

### 引理 32（证书条件对比表示的一致性）

**陈述**：设正样本对满足 ‖c_i − c_j‖ < δ_c，负样本按失效模式分层且每个模式至少 n_neg 个，InfoNCE 温度 τ > 0。则训练收敛后，对任意证书上下文距离 ‖c_i − c_j‖ ≥ Δ > δ_c 的样本对，其潜表示距离满足下界
‖z_i − z_j‖ ≥ g(Δ) > 0，
其中 g 随 Δ 单调递增，且 g(Δ) 不依赖失效模式的样本频率。

**证明（思路）**：分层负采样保证每个失效模式 m 在分母中贡献期望 ≥ n_neg / (K · n_neg) 的固定比例，故少数模式的负样本不会被多数模式淹没。InfoNCE 的最优解满足 p(pos|c) ∝ exp(sim/τ)；当证书条件可区分时，证书距离大的样本对无法同时成为彼此的高相似正样本，否则与分层负样本的对比项矛盾。对潜空间做局部利普希茨假设（编码器 Lipschitz 常数 L_f），即可把证书空间间隔 Δ 映射为表示空间间隔下界 g(Δ) ≥ σ_min(J_c) · Δ / L_f。∎

**工程含义**：证书条件化 + 分层负采样，正是为了不让「常见失效模式」压垮「稀有但致命失效模式」的表示；这也是对证书回声室的结构性防御（稀有模式不会因样本少而被表示遗忘）。

### 引理 33（配比覆盖率的指数收敛）

**陈述**：设混合分布 D(α) 下每个失效模式 m 的单样本命中概率 p_m ≥ p_min > 0，回放缓冲采样 N 个样本。若每模式最低要求 k_min，则
P(∃m: n_m < k_min) ≤ |M| · exp(−2N(p_min − k_min/N)²)。
当 N ≥ 2k_min / p_min 时，覆盖率不足的概率随 N 指数衰减。

**证明**：n_m ~ Binomial(N, p_m)，由 Chernoff/Hoeffding 界，P(n_m < k_min) ≤ exp(−2N(p_m − k_min/N)²)。对 |M| 个模式取并集界即得。∎

**工程含义**：CADMO 的 ESS/skew 约束保证 α 不会退化为单源，从而 p_min 有正下界；FMCC 的 ρ_cov 正是该引理的可观测代理。二者合起来把「配比坍缩导致某失效模式被遗忘」的概率压到可接受范围。

### 定理（SSCDE 执行集收缩与未见失效模式违规率下降）

**陈述**：在以下假设下：
(A1) 推理期两道新门 kc_ssl_novel、kc_mix_cov 均按定义执行；
(A2) CCSE 满足引理 32 的表示一致性下界；
(A3) CADMO 满足引理 33 的覆盖率条件，且训练窗口内 DMC.valid 成立；
(A4) 影子评估使用与训练集不相交的留出失效模式；
则
1. Exec_SSCDE ⊆ Exec_CADVS（新增门只会进一步收缩执行集）；
2. 在留出失效模式上，学生违规率相对「仅教师蒸馏 + 均匀配比」基线下降，下降幅度由表示间隔 g(Δ) 与覆盖率 ρ_cov 共同界定。

**证明**：
- 包含性：sscde_admit 在 cert_agg.all_passed（CADVS 已有）之上追加两个合取项，合取只会减少被准入的动作集合，故 Exec_SSCDE ⊆ Exec_CADVS。
- 违规率：由引理 33，留出模式在训练分布中的支持被 ρ_cov 下界保证；由引理 32，表示对证书距离大的样本保持间隔，故学生在留出模式附近不会因表示坍缩而误判为「已覆盖」。把学生违规事件分解为「表示不可分」与「数据未覆盖」两部分，分别由 g(Δ) 与 ρ_cov 控制，即得下降界。∎

**诚实声明**：(A1)–(A4) 在工程中并非恒真。CCSE 可能学到与证书无关的捷径特征（如背景纹理），使引理 32 的利普希茨假设失效；FMCC 的失效模式集合 M 本身由聚类得到，可能漏掉尚未被观测到的模式；影子评估的留出集若与真实部署分布不一致，回声室检测会失灵。SSCDE 通过「证书只做准入与数据选择、不做梯度奖励」「留出模式影子评估」「覆盖率不足即停止训练并补数据」三道机制管理这些风险，但无法证明其完全消除。

## 5. 实验设计（本轮新增）

### 5.1 数据与基线

- **数据源**：真实双足机器人 40h 无标签日志（D_U）；教师 KT-MPC 成功轨迹 8h（D_T）；注入/历史证书违规回放 1.2h（D_F，覆盖 14 类失效模式）；仿真 20h（D_S）。
- **基线**：
  1. B1：仅教师蒸馏（v30，无 SSL、无配比）。
  2. B2：教师蒸馏 + 均匀配比四源（无证书条件）。
  3. B3：教师蒸馏 + SSL（普通 InfoNCE，无证书条件、无分层负采样）。
  4. B4：本文 SSCDE（证书条件 SSL + CADMO + FMCC/SSNC 门）。
- **留出**：从 14 类失效模式中留出 3 类（打滑、突发侧向推力、单腿传感器短暂失效）完全不参与训练，仅用于影子评估。

### 5.2 指标

| 指标 | 定义 | 期望方向 |
|---|---|---|
| U-VR | 留出失效模式上的违规率 | ↓ ≥40% vs B1 |
| C-PR | 已覆盖模式上的证书通过率 | 不下降（≥ B1 − 1%） |
| ρ_cov | 最稀缺失效模式覆盖率 | ≥ 0.8 |
| SafetyMargin | 真实安全边界（最小支撑面积/最大倾角裕度） | ↑ |
| EchoScore | 证书通过率上升但留出模式违规率同时上升的窗口占比 | ↓（回声室早期信号） |
| TrainCost | 每万步训练墙钟时间 | ≤ 1.6× B1 |

### 5.3 预期结果（待验证）

| 方法 | U-VR | C-PR | ρ_cov | EchoScore | TrainCost |
|---|---|---|---|---|---|
| B1 教师蒸馏 | 0.31 | 0.94 | — | — | 1.00× |
| B2 均匀配比 | 0.26 | 0.93 | 0.41 | 0.18 | 1.15× |
| B3 普通 SSL | 0.22 | 0.95 | 0.44 | 0.27 | 1.42× |
| B4 SSCDE | **0.17** | **0.94** | **0.83** | **0.07** | 1.55× |

**关键消融**：
1. 去掉分层负采样 → 预期 U-VR 回升，稀有模式表示退化。
2. 去掉 CADMO 的 ESS/skew 约束 → 配比坍缩到 failure 源，已覆盖模式通过率下降（灾难性遗忘）。
3. 去掉影子评估 → EchoScore 上升，证书通过率虚高。
4. 把证书直接当奖励（而非仅准入/数据选择）→ 预期 EchoScore 显著上升，用于验证回声室机制。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R32 | v30 全部既有风险 | — | 原样继承 | 不变 |
| R33 | **证书回声室**（以证书通过为训练信号导致表示与配比向易通过区域坍缩） | **极高** | 1) 证书只用于准入与数据选择，不作梯度奖励；2) 证书弱正则 stop-gradient 且 β_cond≤0.02；3) 留出失效模式影子评估 + EchoScore 监控；4) 触发即回滚编码器并衰减 β_cond | 留出集与真实部署分布不一致时检测失灵；回声室可能是渐进的，早期难察觉 |
| R34 | **自监督表示坍缩 / 捷径特征**（学到背景纹理、光照等与安全无关的相关性） | 高 | 1) 分层负采样强制区分失效模式；2) 掩码预测 + 时序对比双任务；3) 潜空间一致性 κ_lat 门控；4) 定期线性探针评估表示对失效模式的区分度 | 捷径特征在分布内表现良好，跨域才暴露 |

| R36 | **覆盖率指标被博弈**（仅增加样本数而不增加模式多样性） | 中 | 1) ρ_m 用「模式 × 场景簇」二维覆盖而非单纯计数；2) 影子评估使用不同场景簇；3) 人工抽检高 ρ_cov 窗口 | 场景簇定义本身可能遗漏真实长尾 |
| R37 | **在线配比振荡**（违规率波动导致 α 频繁跳变） | 中 | 1) η_mix=0.05 且加动量；2) 配比更新每 K=500 步一次；3) 变更幅度单步上限 0.05 | 极端非平稳环境下仍可能滞后 |

## 7. 本轮最大风险（最终确认）

**一句话**：**证书回声室**——自监督与配比优化若以「证书通过」为隐性目标，会把表示与数据分布训练成「讨好证书」而非「理解世界」的形状；证书本身不完备的盲区被系统性放大，系统在证书通过率持续上升的表象下悄悄收缩真实安全边界，而这恰恰是证书框架最难自查的失效模式。
