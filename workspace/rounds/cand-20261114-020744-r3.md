# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分 × 主动交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「人机协作」×「安全交互」）

> R69 完成了一次漂亮的二分：aleatoric 收紧、epistemic 去问，并让「看/问/触」成为可通过 C-RAS-WM 认证、可被审计的动作。但它把同一个人悄悄塞进了两个极端角色——要么是**零成本、无限耐心、永远在场的信息神谕**（其回答只用于降低机器人自己的 U_epi），要么是**投毒者**（ℰ_poison 里要防的对象）。这两个角色都漏掉了「人机协作」最根本的事实：**人是共同行动者（co-agent），有自己的信念、注意力预算、意图与权威，而且身体就在同一个工作空间里。**
>
> 于是 R69 隐含了两个危险前提：
> - **单心智假设**：只管理「机器人的不确定性」，人只是消除它的工具；从不建模「人此刻认为机器人会做什么、有多信任机器人」。
> - **多验证必然更安全假设**：k 个正交源一致可以推翻单源，甚至「传感器投票」可以压过人的显式指令；保守 λ 是单方面的。真实协作里，这既可能**家长式地过度否决人**（破坏信任与效率），又可能**用合规外壳把人的错误决定洗白**（更危险）。
>
> 本轮两个灵感正好补上两块缺失：
> - **人机协作**给出第二个不确定性载体：机器人必须维护一个关于「人如何理解机器人」的模型（theory-of-mind / 信任），安全是**联合系统**的属性；不确定性因此可以**分配**——有些该机器人自己消，有些该交还给人，有些该由双方共同确认。
> - **安全交互**给出交互的**契约结构**：硬安全包络（机器不可放弃的否决）、授权/协商区（人的最终权威）、**知情且可撤回的同意**；并要求机器人不仅「问出」，还要「说出」（可读性/意图通信），因为**惊奇（surprise）本身就是协作中的一类物理风险**。
>
> 核心命题：**把不确定性从「机器人一元的标量」升级为「人—机联合的四通道 (U_R^ale, U_R^epi, U_H, U_S)」——其中 U_H 是人对机器人意图的不确定性、U_S 是双方信念的分歧；再用一个「权限—同意—信任」契约把每个不确定性单元分配到三种处置之一（机器人自解、委托给人、双方共解），并用一个权威无关的硬安全盾保证：无论人怎么想、怎么授权、是否被胁迫，硬安全包络永不破。** 命名 **PACT-RAS**（Participatory Authority, Consent & Trust：权限—同意—信任共治的联合不确定性闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们俩谁来做、谁该知道、谁说了算**」——不确定性不只是刹车、提问与注视，还是一份关于「由谁承担它」的契约。

## 0. 直觉与动机

**灵感 1（人机协作 → 有两个不确定性载体）**
直觉：R69 的世界里只有一个心智。现实里，安全取决于**成对状态**：机器人有多确定（U_R）× 人有多确定、以及在多大程度上信任机器人（U_H、τ_H）。一个「机器人很确定、但人严重误判机器人意图」的场景（人以为机器人会让行，机器人其实根本没看见人）比「机器人自己不确定」更致命。**安全不是一个心智的属性，而是两个心智及其分歧 U_S 的属性。** 因此机器人必须维护 SAM（人的心智模型）：估计 b̂_H、信任 τ_H，以及双方对同一对象的分歧 U_S。

**灵感 2（人机协作 → 不确定性可以分配，而不是全部自己扛）**
直觉：R68 的答案是「不确定就自己收紧」，R69 的答案是「不确定就自己问」。但协作的本质是**认知分工**：有些不确定性交给人更便宜（人本来就知道，或人有权决定），有些机器人自己消更便宜（人正忙、或身处危险位置），有些必须双方共同确认（不可逆且高风险）。把三者形式化为三种 sink 的「边际联合风险下降 / 成本」比，就是一个**跨界资源分配**问题。R69 恰好是「只允许机器人 sink」的约束特例——新层因此是旧层的严格泛化，而不是并列替代。

**灵感 3（安全交互 → 交互本身要立契约，而不是临时投票）**
直觉：R69 的「k 个正交证据源一致」在纯推理时没错，但用在与人协作上会出事：它允许传感器「投票否决」人的显式指令，也允许把人的一次误导性回答盖上「已验证」的章。安全交互需要的是**分层的权限结构**：一块不可侵犯的硬安全包络 H（机器不可放弃的物理否决，与人怎么想、怎么授权无关）、一块人的授权区 A（在此机器人必须尊重人的最终权威，不得过度再验证）、以及协商区 N（双方共决）。这就是「两把钥匙」：人的权威 + 机器的安全盾；任一单独不能穿透 H，但可在 A/N 内改变选择。**硬包络上机器说了算，软包络上人说了算。**

**灵感 4（安全交互 → 不只要「问出」，还要「说出」）**
直觉：R69 的信息动作全是内向的（看/问/触），目的是降低机器人的不确定性；却从不主动降低**人的**不确定性。可人在协作中最怕的往往不是机器人「不确定」，而是机器人「不可预测」——突然变向、突然加速、意图不明导致人误入包络。**惊奇（surprise）本身就是物理风险**（应激后仰、躲闪、误触）。所以本轮新增一类外向信息动作 g_comm：指向性注视、指示灯/投影、口语意图、预期性减速与让行（legibility）。关键约束是**真话**：通信只能降低人对机器人真实意图的不确定性，不能用来「制造信任」——可读性不是说服，更不是操纵。

**灵感 5（安全交互是双刃剑 → 信任可被制造，同意可被胁迫）**
直觉：一旦系统读取人的信任并影响它，就有了新的攻击面：可以**先制造 over-trust 再加以利用**（人过度依赖后主动贴近危险区），可以用社交工程诱导「同意」，也可以在胁迫下取得形式上的 consent。更隐蔽的是**责任洗白**：系统把一个人在被误导/被胁迫状态下做出的危险决定，走完流程、签上「已验证同意」，于是错误看起来像合规。所以本轮必须交付：信任校准（而不是信任最大化）、同意的新鲜/知情/可撤回/可溯源、以及权威无关的安全盾（使任何伪造同意都无法穿透硬包络）。

**灵感 6（对旧层的严格包含）**
直觉：把「人」设成 R69 假设的样子——**完美神谕（U_H=0）、无限耐心（c_att=0）、零在场（无物理风险、无惊奇）、无权限（不存在 A/H 区分）**——PACT 的每一种分配都会退化为「机器人自己问或自己收紧」，逐指令等于 FLUID。再把「不交互、不通信」加上，等于 CALM-RAS。这是本轮的理论姿态：新层必须是旧层的严格泛化，安全侧永不更弱。

## 1. 形式化定义（定义 310–327）

**定义 310（PACT-RAS 总览与四不变式）** PACT-RAS = (SAM, JUD, TAM, LIC, ACP, TCM, RAS-WM‡)，其中 SAM=共享心智模型、JUD=联合不确定性分解、TAM=跨界分配器、LIC=可读性/意图通信、ACP=权限与同意协议、TCM=信任条件防御裕度。四不变式：
(i) **实时流零学习写**（继承 R68 定义 276-i）；
(ii) **硬包络权威无关**：存在不可侵犯的硬安全集 H，其执行不依赖人的信念/授权/同意，任何人类指令（含胁迫、伪同意）都不能使系统离开 H 的 ε_hard 邻域；
(iii) **同意新鲜、知情、可撤回、可溯源**：不可逆动作必须由「新鲜且知情」的同意授权，并记录 authority provenance；过期/撤回/受胁迫的同意不得授权不可逆动作（no consent by silence）；
(iv) **信任校准而非信任操纵**：LIC 的通信必须对机器人真实信念 sound（不欺骗、只降低对真实意图的不确定性），且不得以制造 over-trust 为目的。

**定义 311（联合信念与 SAM）** b_R ∈ Δ(𝒲) 为机器人对世界/任务/人意图的信念；b_H ∈ Δ(𝒲 × Π_R) 为人类对世界与机器人策略的信念（theory-of-mind 估计）。SAM 给出 b̂_H = h_φ(o_t, 交互历史)，并以信任标量 τ_H = E_{b̂_H}[robot_competent ∧ robot_protective] 汇总。联合状态 b_J = (b_R, b̂_H)。

**定义 312（联合不确定性四通道）** U_R^ale、U_R^epi 为 R68/R69 的机器人自不确定性；U_H = H(b̂_H[robot_intent]) 为人对机器人下一步意图的不确定性；U_S = D_JS(b_R^{proj}, b̂_H[robot]) 为双方对同一对象的信念分歧。四者语义不同，分通道处置（定义 320、327），不做简单加和。

**定义 313（信任与信任校准误差 TCE）** 设人「应持有」的信任 τ* 由机器人真实能力与实际风险给定。TCE = E|τ_H − τ*|；over-trust = (τ_H − τ*)_+，under-trust = (τ* − τ_H)_+。安全带要求 τ* − δ_u ≤ τ_H ≤ τ* + δ_o，且 **over-trust 更危险**（人主动贴近、忽视告警、把安全责任外推给机器）。

**定义 314（增广信息动作）** 在 R69 的 𝒜_info 基础上加两类：
- 内向（inward）g_in：看/问/触/等待（R69 原动作）；
- 外向（outward）g_comm ∈ 𝒜_comm：指向性注视 token、指示灯/投影、口语意图、预期性减速/让行（legibility）；
- 委托（deference）g_del：把决策权交还给人（「请确认/请接管」），是一种「不行动的信息动作」。
增广 ξ = (a, g_in, g_comm, g_del)。

**定义 315（惊奇、可读性与真话约束）** 人对机器人下一步动作的预测为 p_H(a_{t+1}|历史)，惊奇 S(a) = −log p_H(a)。可读性动作 g_comm 通过提升 p_H(a*) 降低 S；联合目标含 E[S] ≤ s_max，因为 startle/不可预测性是 HRC 的一类物理风险。**真话约束** truthful(g_comm, a*)：g_comm 只提供关于真实 a* 的信息，不得引入虚假信心。

**定义 316（权限空间与两把钥匙）** 机器人可达状态空间分三块：H 硬安全集（不可侵犯、与人状态无关，由 C-RAS-WM 物理认证）；A 授权集（人的显式指令在此被尊重，机器人不得过度再验证）；N = 𝒳\(H∪A) 协商集。动作执行需 pass Shield_H(a)【机器的不可放弃否决】∧（在 A 中：有效 authority/consent；在 N 中：双方一致或保守默认）。两把钥匙 = 人的权威 + 机器的安全盾。

**定义 317（同意状态机与来源）** Consent ∈ {∅, Asked, Granted, Revoked, Expired}，附带 scope（授权哪些动作/时长）、informedness（人是否被告知风险）、freshness、provenance（谁在何时以何身份授权）。valid_consent(c,a) ⇔ c=Granted ∧ a∈scope(c) ∧ fresh(c) ∧ informed(c) ∧ ¬coerced(c) ∧ ¬revoked(c)。不可逆动作必需 valid_consent；软动作可默认。

**定义 318（权威无关安全盾）** Shield_H: 𝒜 → 𝒜 把任意指令投影到 H 内的最大安全子动作（控制屏障/最小干预）。关键：其构造只依赖物理/动力学证书，不依赖 b̂_H、τ_H 或 authority；即 ∀ 人状态、∀ 指令序列，Shield_H(a) ∈ H。

**定义 319（交互契约与仲裁）** 契约 C = (H, A, N, consent, role)。仲裁规则：
- a_H ∉ H ⇒ 机器否决并转入 LIC 解释（不可放弃）；
- a_H ∈ A 且（若需）valid_consent ⇒ 执行，不做过度再验证；
- a_H ∈ N ⇒ 机器人自评 soft_risk(a_H) ≤ ε_soft 则执行，否则请求联合确认（g_del）或保守默认。
即 **R69 的「k 源一致」只允许用于 N，绝不允许推翻 A 中带有效同意的人指令。**

**定义 320（跨界分配 TAM）** 每个不确定性单元可投入三种 sink：robot（R69 内向信息动作，成本 c_R）、human（委托/询问，成本 = 注意力 c_att + 打扰 c_soc + 自主性损失 c_auto）、joint（g_comm + 联合确认，成本 = 通信 + 同步）。定义各 sink 的边际「联合风险下降」ΔRisk_sink，分配器 max Σ ΔRisk − Σ cost s.t. 硬约束与预算（子模 → 贪心 (1−1/e)，定义见引理 19）。R69 = 只允许 robot sink 的约束特例。

**定义 321（信任条件防御裕度 TCM）** 以 τ_H 条件化人的预测轨迹（over-trust 时人更可能提前进入包络），定义最小安全分离 d_safe = d_min + β·(τ_H − τ*)₊ + γ·U_H。TCM 把 R68 的「等距分离监控」升级为「按对方信任状态预扩张的防御性分离」。

**定义 322（联合风险分解）** R_joint = R_task + λ·U_R^epi + R_phys(d_safe) + R_cog(TCE) + R_soc(U_H, S) + R_auth(violations)，其中 R_phys 含碰撞/挤压/startle，R_cog 含 over/under-trust 导致的误操作，R_soc 含操纵/隐私/尊严，R_auth 含越权与伪同意。PACT 优化的是 R_joint，而非仅机器人自风险。

**定义 323（交互失效模式分类）** 物理失效（碰撞、挤压、惊奇应激）；认知失效（over/under-trust、模式混淆、自动化偏见）；社会失效（操纵、失去尊严/隐私、强迫同意）；权威失效（越权指令、伪造同意、责任不清）。四类都并入 AIC 与审计对象。

**定义 324（参与式审计 VQAuditor-P）** 审计对象在 R69 的交互决策之上，新增：信任是否被校准（TCE 带内）、通信是否真话（无操纵）、同意是否新鲜/知情/可撤回、权威转移是否有 provenance、硬包络是否被任何指令触碰。结论回灌 AuditBuf，成为下一轮 TAM 的成本与信任先验。

**定义 325（威胁模型 ℰ_PACT）** ℰ_PACT = ℰ_FLUID × ℰ_auth × ℰ_trust，其中 ℰ_auth = 越权指令 / 伪造 / 过期同意 / 胁迫下顺从；ℰ_trust = 信任操纵（先制造 over-trust 再套利）、社会工程、伪造在场/身份。并入 AIC。

**定义 326（证书 J_PACT）** J_PACT = (J_FLUID, TCE_band, consent_provenance_hash, authority_violations, hard_envelope_intact, legibility_soundness, d_safe_margin, joint_risk_p95, pact_ver)。Valid ⇔ Valid(J_FLUID) ∧ TCE 带内 ∧ 同意全部新鲜/知情/可撤回/可溯源 ∧ 硬包络零触碰 ∧ 通信 sound ∧ 无权威失效。

**定义 327（退避阶梯与严格包含）** 消解/校准成功：λ = λ_floor(U_ale)（resolution bonus）且 R_cog/R_soc 下降；分配不可行、同意失效、TCE 越界或被投毒：λ = λ_floor(U_ale + 未消解 U_epi + U_S)，并退回 R69 保守；再禁用交互与通信则退回 R68。安全侧逐级不弱。

# IP-264 SAM：人的心智 / 信任模型（theory-of-mind）
class SharedAgentModel:
    def infer(self, o_t, hist):
        bH   = self.tom(o_t, hist)            # 人对世界/机器人策略的信念 b̂_H
        tauH = self.trust_head(bH)            # 信任标量 τ_H
        return bH, tauH

# IP-265 JUD：四通道联合不确定性（复用 R69 的 FMP/AUD）
def joint_decompose(bR, bH, samples):
    U_ale, U_epi = fluid_aud(bR, samples)     # R69：模态内 / 模态间
    U_H = entropy(bH.robot_intent)            # 人对机器人意图的不确定
    U_S = js_divergence(bR.proj_robot, bH.robot)  # 双方信念分歧
    return U_ale, U_epi, U_H, U_S

# IP-268 ACP：权威无关安全盾（只依赖物理/动力学证书）
def shield_H(a, o):
    return cbf_project(a, H_certificate(o))   # ∀ 人状态，结果恒在 H 内

# IP-268 ACP：两把钥匙的仲裁
def arbitrate(a_H, consent, o, bH, tauH):
    safe = shield_H(a_H, o)
    if not almost_equal(safe, a_H):           # 指令会出硬包络
        return veto_and_explain(a_H)          # 机器不可放弃否决 + LIC
    if in_authority_set(a_H, o):              # 授权区 A
        return a_H if valid_consent(consent, a_H) else request_consent(a_H)
    if soft_risk(a_H, o) <= EPS_SOFT:         # 协商区 N
        return a_H
    return request_joint_confirm(a_H) or conservative_default(o)

# IP-266 TAM：跨 sink 分配（机器人 / 人 / 联合）
def allocate(U, budget):
    cands = (info_actions_robot(U) + deference_actions(U) + comm_actions(U))
    # 各 sink 的 Δ联合风险 对动作子集次模 → 贪心 (1-1/e)
    return greedy_submodular(cands, score=lambda c: dRisk(c) - cost(c),
                             stop=lambda: budget.exhausted())

# IP-267 LIC：可读性 / 意图通信（真话约束）
def legible_signal(plan, bH):
    a_star = plan.next
    g = argmin_surprise(a_star, bH)           # 只降对真实意图的不确定性
    assert truthful(g, a_star)                # 不得制造虚假信心
    return g

# IP-269 TCM：信任条件防御裕度
def defensive_margin(tauH, tau_star, U_H):
    return d_min + beta * max(0.0, tauH - tau_star) + gamma * U_H

    U_ale, U_epi, U_H, U_S = joint_decompose(z, bH, samples)
    # 1) 人主动介入：走契约仲裁，而不是传感器投票
    if human_cmd is not None:
        a = M.acp.arbitrate(human_cmd, M.consent, o, bH, tauH)
        M.vqa_p.submit_async(human_cmd, M.consent, tauH, U_S)
        return a, M.lam_from(U_ale), (U_ale, U_epi, U_H, U_S)
    # 2) 跨界分配：机器人自解 / 委托 / 联合
    alloc = M.tam.allocate((U_epi, U_H, U_S), M.budget)
    if   alloc.sink == 'robot': ans = M.cia.execute(alloc.g_in)      # R69
    elif alloc.sink == 'human': ans = M.acp.request(alloc.g_del)    # 委托 + consent
    else:                       ans = M.lic.signal(alloc.g_comm) + M.acp.joint_confirm()
    # 3) 更新联合不确定性；未消解者并入保守
    U_epi, U_H, U_S = update_joint(U_epi, U_H, U_S, ans)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + unresolved(U_epi, U_S)))
    # 4) 信任条件防御裕度 → 分离监控
    d_safe = M.tcm.defensive_margin(tauH, M.tau_star, U_H)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., d_safe=d_safe)
    # 5) 硬包络最终投影：任何指令都不能穿透 H
    a_exec = M.acp.shield_H(M.select_mode(...).a[:k], o)
    M.vqa_p.submit_async(None, alloc, M.consent, tauH, U_S)
    return a_exec, lam, (U_ale, U_epi, U_H, U_S)
```

## 3. 推导

**引理 19（跨界分配的次模性与贪心界）** 设每加入一个处置动作 x 带来的期望联合风险下降 ΔRisk(x | 已选集合) 非增（信息不重复计数 + 风险凸性给出次模性），则预算约束下贪心分配满足 ΔRisk(π_greedy) ≥ (1 − 1/e)·ΔRisk(π*)。R69 是可行域被限制为「只用 robot sink」的特例，故 PACT 可行域更大、最优值不劣。系：**「该不该问」与「该问谁」是同一个次模分配问题的两个投影**。

**引理 20（信任—间距反馈的收缩性）** 设人进入机器人包络的概率 p_enter 随 over-trust=(τ_H−τ*)₊ 单调增、随防御裕度 d_safe 单调减；LIC 通信使 τ_H 向 τ* 收缩（TCE 下降）。则 TCM+LIC 的联合闭环在 |τ_H−τ*| ≤ δ 内是压缩映射：over-trust 触发 d_safe↑ 与 g_comm，二者都降低 p_enter，从而削弱「贴近→误判→碰撞」的正反馈。系：**信任不是越高越好，最优是把信任校准到真实能力**（定义 313）。

**引理 21（可读性—惊奇界与真话约束）** 对任意 g_comm，惊奇的下降满足 ΔS ≤ I(g_comm; a*)，因为通信至多提供关于真实下一动作的互信息；真话约束 truthful(g_comm,a*) 保证不引入关于 a* 的虚假信息，故可读性不会退化为「用沟通制造 over-trust」。任何以操纵为目的的通信被定义 326 的 legibility_soundness 拒绝。

**引理 22（同意时效与不可逆性）** 同意状态机对撤回/过期单调：一旦 Revoked/Expired，valid_consent 在 bounded latency L_c 内变 false。对不可逆动作集 𝒜_irr 要求 valid_consent ∧ fresh；故 stale/被撤回/受胁迫的同意都不能授权 a ∈ 𝒜_irr，最坏延迟 ≤ L_c。系：不可逆动作前必须重新确认，**沉默不构成授权**。

**定理 18（权威无关硬安全）** 在 A99（盾只依赖物理/动力学证书，不依赖 b̂_H、τ_H、authority）下，对任意人类指令序列（含胁迫、伪造同意、恶意 authority），执行动作 a_exec = Shield_H(a) 恒满足 a_exec ∈ H，物理风险 ≤ ε_hard。授权/同意只改变 A∪N 内的选择，不改变 H。⇒ **伪造同意不能穿透硬包络**；R69 的「传感器投票否决人」被限制在 N 内，绝不推翻 A 中带有效同意的人指令。

**定理 19（PACT 严格包含 FLUID 与 CALM）** 退化设置 U_H=0、c_att=0、无物理在场（ε_int=0 且 S 无风险）、A=∅ 且 H=原机器人安全集 ⇒ 所有不确定性只进 robot sink ⇒ 逐指令等于 FLUID；再加「无内向交互、无外向通信」⇒ 等于 CALM/R68。因 Shield_H 把执行投影进原安全集（H ⊆ 原安全集），安全侧不比旧层弱；效率侧靠「分配 + resolution/trust bonus」提升。R69 = PACT 在「人=完美神谕」边界上的退化。

    if   alloc.sink == 'robot': ans = M.cia.execute(alloc.g_in)
    elif alloc.sink == 'human': ans = M.acp.request(alloc.g_del)
    else:                       ans = M.lic.signal(alloc.g_comm) + M.acp.joint_confirm()
    U_epi, U_H, U_S = update_joint(U_epi, U_H, U_S, ans)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + unresolved(U_epi, U_S)))
    d_safe = M.tcm.defensive_margin(tauH, M.tau_star, U_H)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., d_safe=d_safe)
    a_exec = M.acp.shield_H(M.select_mode(...).a[:k], o)    # 硬包络最终投影
    M.vqa_p.submit_async(None, alloc, M.consent, tauH, U_S)
    return a_exec, lam, (U_ale, U_epi, U_H, U_S)
```

## 4. 推导

**引理 19（跨界分配的次模性与贪心界）** ΔRisk(x|已选) 非增（信息不重复计数 + 风险凸性）；预算约束下贪心 `ΔRisk(π_greedy) ≥ (1−1/e)ΔRisk(π*)`。R69 = 限制只用 robot sink 的特例，故 PACT 可行域更大、最优不劣。系：「该不该问」与「该问谁」是同一子模问题的两个投影。

**引理 20（信任—间距反馈的收缩性）** `p_enter` 随 over-trust 单调增、随 `d_safe` 单调减；LIC 使 τ_H 向 τ* 收缩。TCM+LIC 闭环在 `|τ_H−τ*|≤δ` 内是压缩映射。系：信任不是越高越好，最优是校准到真实能力。

**引理 21（可读性—惊奇界与真话约束）** `ΔS ≤ I(g_comm; a*)`；真话约束保证不引入关于 a* 的虚假信息，故可读性不退化为「用沟通制造 over-trust」，操纵性通信被 J_PACT 的 soundness 拒绝。

**引理 22（同意时效与不可逆性）** 撤回/过期在 bounded latency `L_c` 内使 `valid_consent` 失效；不可逆动作要求 `valid_consent ∧ fresh`。系：不可逆前必须重新确认，沉默不构成授权。

**定理 18（权威无关硬安全）** A99 下，任意人类指令序列（含胁迫/伪同意/恶意 authority），`a_exec=Shield_H(a) ∈ H`，物理风险 ≤ ε_hard；授权只改 A∪N 内的选择，不改 H。⇒ 伪造同意不可穿透硬包络；R69 的传感器投票被限制在 N。

**定理 19（PACT 严格包含 FLUID 与 CALM）** `U_H=0, c_att=0, ε_int=0, S 无风险, A=∅, H=原安全集` ⇒ 只进 robot sink ⇒ 逐指令等于 FLUID；再加「无内向交互、无通信」⇒ 等于 CALM/R68。因 `H ⊆ 原安全集`，安全侧不弱；效率侧获 resolution/trust bonus。

## 7. 本轮最大风险

**一句话**：PACT 的全部安全性都押在 SAM 与同意状态机对「人的真实状态」的估计上——**一旦它把被误导/被胁迫下的顺从误读为知情同意，或把「降低惊奇」的通信悄悄用作制造 over-trust 的工具，系统就会用一张合规的同意书把联合危险动作洗白；在人机协作里，「被认证的错误」比「诚实的不知道」更危险。**

**次级风险与缓解**：SAM 误估心智/信任（TCE 门控，带外退回 R69/R68；E302/E312）；信任操纵与社交工程（ℰ_trust + 真话约束 + 引理 21 + E311）；伪/过期/胁迫同意（状态机 + provenance + 权威无关盾，定义 317–318、定理 18）；防御裕度导致效率崩塌（TCM 下限 + E303/E308 Pareto）；盾投影实时性（CBF-QP 单次投影 + E314）。
