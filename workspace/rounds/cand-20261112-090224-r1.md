# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 1 轮；本轮灵感：「可用性评估」×「可靠性」）

> 第 59 轮把「证据承诺」下沉到执行层：BUQ 在线辨识电机结构性不确定性、ERTC 把嵌入式时序变成硬契约、EEIS 把 δ_f 编译成阻抗参数证书、CLEP 让执行实测回传为第 5 模态。但它仍有两个隐含假设：**(i) 安全是逐次接触的局部属性**——只要每个检查点 δ_f 达标即可；**(ii) 人站在系统之外**——证据请求、L2 协商、降级告警被视为“免费”的元操作，不被计入失效链。本轮两个灵感精准击中这两个漏洞：**可靠性**要求把逐次安全升级为**全生命周期、任务级、含共因与磨损的风险预算**；**可用性评估**要求把操作员注意力、工作负荷、信任校准、中断率还原为**有限的、会被耗尽的、会反噬安全的资源**。核心命题：**「单次安全 ≠ 任务可靠；系统可靠 ≠ 人机系统可用。必须把可靠性预算与可用性约束联合编译，并让人成为可靠性模型中的一等公民。」**

核心矛盾：
- **H32（纵向风险累积·逐次安全与任务可靠的量级断裂）**：第 59 轮的最强保证是逐检查点 δ_f≤10⁻⁴。若一次任务含 N=10⁴ 个接触，独立近似下任务不可靠度 ≈1−(1−10⁻⁴)^{10⁴}≈63%；若要求任务级灾难性失效 ≤10⁻⁴，则逐次灾难性 δ 必须压到 ~10⁻⁸。**这不是调参问题，而是设计问题**：必须建立「任务→阶段→检查点→基本事件」的层级风险预算、故障树最小割集分配、脆弱性（frailty）与共因修正，并在不可行时触发布局/冗余/维护/限速等**设计变更**，而不是简单“更保守地降级”。
- **H33（可用性-安全悖论·保守性反噬）**：第 59 轮的安全护栏会产生大量证据请求、L2 协商、DEGRADE_EXEC 告警。操作员是有限服务率的“人形服务器”：请求到达率 λ_req 接近服务率 μ_op 时，排队时延爆炸、请求被丢弃、告警疲劳、自动化偏见/自满（complacency）与不信任弃用（disuse）同时出现。**过度保守 → 中断过载 → 人类漏检率上升 → 任务可靠性下降**。因此“安全”与“可用性”不是两个独立指标，而是一条耦合曲线上的两个坐标；存在内点最优，必须形式化。
- **H34（可靠性证据不可测·测试独木难支）**：高保障可靠性无法靠现场试验证明。要在 95% 置信下证明 R≥1−10⁻⁶，零故障试验需 n≈3×10⁶ 次；R≥1−10⁻⁴ 也需 ~3×10⁴ 次。现场数据天然右删失、操作剖面非平稳、故障空间覆盖不足、共因失效破坏冗余独立性。**必须用故障注入覆盖率下界、加速寿命、生存分析、操作剖面加权、贝叶斯证据合成与可靠性增长模型来“拼出”可信下界**；否则 J_dep 只是统计幻觉。
- **H35（人类可靠性缺位·信任失校）**：第 59 轮的 EV-human 仍是“人类给机器作证”，而不是“人类本身会失效”。真实人机系统中，操作员的信任 T 与真实可靠度 T\*=1−δ_robot 可能系统性偏离：**过度信任→自满→不监控**，**信任不足→弃用→人工接管错误**。必须把人机依赖建成带信任动力学、信号检测、注意力分配与人类失误概率（HEP）的模型，并让监督资源按“风险削减/注意力”边际收益分配。

## 0. 直觉与动机

**灵感 1（可靠性工程 → 纵向任务可靠性与风险预算 LRM）**
直觉：可靠性不是“平均无故障时间”一个数，而是**任务剖面、失效模式、维修策略、共因与磨损共同决定的生存曲线**。四足/机械臂的灾难性失效是稀有事件，必须用故障树（FTA）的最小割集把任务级目标 Δ_mission 逐层摊到基本事件；用 Weibull/浴盆曲线描述早夭—有效寿命—磨损；用 Cox 比例风险把温度、负载、年龄、固件版本作为协变量；用 Gamma 脆弱性（frailty）刻画“同一台机器/同一批次/同一环境”的未观测相关性。关键洞见：**第 59 轮的 δ_f 只是基本事件预算的一个输入，不是任务可靠性本身**；任务级目标会反向要求更小的逐次预算，或在不可行时强制设计变更。

**灵感 2（可用性评估 → 注意力队列与可用性约束 UAM）**
直觉：ISO 9241-11 的有效性/效率/满意度只是表层；对安全机器人，最关键的可用性资源是**操作员注意力**。把证据请求/协商/告警看成到达流，把操作员看成服务台：利用率 ρ=λ_req/μ_op，等待时间 W_q 随 ρ→1 发散；超过交互期限 T_int 的请求被“丢弃/草率处理”，等价于人类漏检概率上升。可用性因此可写成约束集 U_req=(有效性、效率、满意度、可学习性、工作负荷、中断率)，并新增**注意力预算 B_attn**。关键洞见：**可用性不是软指标，而是安全证明的前置约束**；不满足可用性约束的策略，其 HEP 上界会反过来污染 δ_mission。

**灵感 3（人因工程 → 信任动力学与依赖行为 HARM）**
直觉：操作员不是“随叫随到的 oracle”，而是带信任状态 T、工作负荷 W、情境意识（SA）与响应偏置的检测器。信任随成功/失败/误报非对称更新（失败伤害大于成功修复）；自满降低监控投入，弃用则绕过自动化。用信号检测论（SDT）统一：监控注意力 a 决定 d′，信任偏置决定判据 c；漏检率 HEP_miss=1−Φ(d′/2−c)。关键洞见：**最优不是“最大信任”，而是“校准信任”**；T 偏离 T\* 的绝对值进入风险预算，并触发信任修复（解释、强制复核、降低误报）或监督模式切换。

**灵感 4（可靠性证据 → 故障注入、生存分析与证据合成 RBE）**
直觉：没有证据的可靠性声明等于零。故障注入给出“故障空间覆盖率”的保守下界；右删失生存分析给出 R(t) 的置信下界；加速寿命把高温/高负载试验折算到现场；操作剖面加权把“测试分布≠使用分布”的偏差显式化；贝叶斯/幂先验把仿真、注入、现场数据合成一个可审计的后验下界；Crow-AMSAA 增长模型判断系统到底在变好还是变坏。关键洞见：**高保障可靠性必须“多源证据合成 + 保守下界”，单靠现场零故障试验在统计上不可行**。

**灵感 5（合流 → 可靠性-可用性联合编译器 RUCC 与可依赖性闭环 DCL）**
直觉：把 H32–H35 合成一个闭环：任务目标 Δ_mission 与可用性约束 U_req 进入 **RUCC**，联合决定逐检查点风险预算 δ_i^budget、监督/自主模式 m_i、冗余度 k、维护周期 T_maint、证据计划（注入/试验/现场采样）；执行后由 **DCL** 用纵向遥测更新生存模型、信任模型与可靠性增长，重分配预算。若某检查点的 EEIS 在 δ_i^budget 下不可行，**不是简单降级，而是触发布局/冗余/限速/维护的设计反馈**。纵向证据 `EV-dep` 只用于系统级再认证与设计变更门，**不得替代单次接触的 EV-probe\*/EV-xmodal/EV-exec**——这是新的“时间尺度证据层级”，防止用“过去很可靠”为“此刻高风险接触”背书。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（纵向任务可靠性与风险预算 LRM）** 设任务剖面 q 在任务时域 H 内产生 N 个接触/检查点，第 i 个检查点的暴露量为 e_i，基本风险率为 λ_i(t)，协变量 z_i=(温度,负载,年龄,固件版本,尘污,…)，Cox 模型 λ_i(t)=λ_0(t)·exp(βᵀz_i)。用 Gamma 脆弱性 z~Gamma(1/θ,1/θ)（均值 1、方差 θ）刻画未观测共因，则
```
R_N = E_z[ exp(−z·Σ_i λ_i e_i) ] = (1 + θ·Λ)^{−1/θ},   Λ=Σ_i λ_i e_i
```
θ→0 退化为独立情形 R_N=exp(−Λ)。任务灾难性失效目标 Δ_cat 要求 Λ ≤ Λ_budget(Δ_cat,θ)=((1−Δ_cat)^{−θ}−1)/θ。将 Δ_cat 经故障树最小割集 MCS_j 分配：P(T)≤Σ_j P(MCS_j)，P(MCS_j)≈CCF_j·Π_{k∈S_j}δ_k；按 Fussell–Vesely 重要度 I_j=P(MCS_j)/Σ_jP(MCS_j) 得 Δ_j=Δ_cat·I_j，再在割集内按对数均摊 δ_k=(Δ_j/CCF_j)^{1/|S_j|}。另定义失效分类：安全停（可恢复）、降级、任务中止、灾难性；任务安全目标只约束灾难性，可用性目标约束前三类。可用性 A=MTBF/(MTBF+MTTR)，批量冗余需用 β-factor 共因修正：Q_sys ≥ βQ（β 为共因分数）。

**定义 154（可用性评估向量与注意力预算 UAM）** 可用性向量 U=(E_eff, E_effi, S_sat, L_learn, W_load, I_int)，分别对应任务完成率、归一化效率（1/E[T_task]）、满意度（SUS/UEQ）、学习斜率、NASA-TLX 负荷、每小时中断数。约束集 U_req={U | E_eff≥u₁, E_effi≥u₂, S_sat≥u₃, W_load≤u₄, I_int≤u₅}。注意力预算 B_attn 定义为操作员单位时间可处理交互的容量；证据请求按到达率 λ_req、服务时间 S 排队，ρ=λ_req·E[S]，M/G/1 等待 W_q=λ_reqE[S²]/(2(1−ρ))。若 W_q>T_int 则请求被丢弃/草率处理，丢弃概率 p_shed≈ρ·exp(−(1−ρ)T_int/E[S])（M/M/1 近似）。有效注意力 a_eff=a_max·(1−ρ)^η。可用性赤字 J_ux=Σ_k w_k·max(0,u_k^req−u_k)/scale_k；约束违例直接进入 RUCC 可行性判定。

**定义 155（人-自动机依赖模型 HARM）** 信任 T∈[0,1]，校准目标 T\*=1−δ_robot。信任动力学（非对称）：
```
T_{k+1}=clip(T_k+α_s(1−T_k)s_k−α_fT_kf_k−α_FA·fa_k, 0,1),  α_f>α_s
```
其中 s_k/f_k/fa_k 为成功、失败、误报指示。监控注意力 a_mon=a_0·(1−κ·max(0,T−T\*))·(1−W_load/W_max)，信号检测灵敏度 d′=d_0·(a_mon/a_ref)^γ·(1−c_wW_load/W_max)，判据 c=c_0+c_1(T−T\*)。漏检概率 HEP_miss=1−Φ(d′/2−c)，误报概率 P_fa=Φ(−d′/2−c)。弃用概率 p_dis=σ(θ₀−θ₁T+θ₂W_load)。人类失效上界：
```
δ_H ≤ p_dis·h_0 + (1−p_dis)·[δ_R·(1−P_hit·p_rec) + (1−δ_R)·P_fa·h_fa]
```
P_hit=1−HEP_miss。校准误差 E_cal=|T−T\*| 或其可靠性图 ECE 版本；E_cal>ε_trust 触发信任修复（解释、强制复核、降低误报）或监督模式切换。

**定义 156（可靠性证据量化 RBE）** 故障空间 F 分层为 {f}，权重 w_f 来自操作剖面 q。每层注入 n_f 次、检出并安全处置 d_f 次，覆盖率下界 c_f^L=Beta⁻¹(α/|F|; d_f, n_f−d_f+1)，总体 c_L=Σ_fw_fc_f^L（联合置信 ≥1−α）。残余风险率 λ_res=λ_fault(1−c_L)+λ_cc。现场数据 (t_i,ξ_i) 右删失（ξ_i=1 失效、0 删失），Weibull 生存函数 R(t)=exp(−(t/η)^κ)，用 MLE/剖面似然给 R_L(t,1−α)。零故障时 R_L=(1−α)^{1/n}；样本量 n≥ln(1/α)/(−ln R)。加速寿命按 Arrhenius AF=exp[(E_a/k_B)(1/T_use−1/T_stress)] 或逆幂律 AF=(V_stress/V_use)^n 折算。操作剖面偏差 TV(p_test,q)≤ε_profile，加权有效样本量 n_eff=n(1−TV)。多源合成用幂先验 Beta(a+v·n_sim·c_sim, b+v·n_sim·(1−c_sim)) 与现场二项数据更新，v 为仿真验证分。可靠性增长用 Crow-AMSAA：N(t)=λt^β，β<1 表示增长、β>1 表示退化。

**定义 157（可靠性-可用性联合编译器 RUCC）** 设计变量 θ=(δ_i^budget, m_i, k_red, T_maint, test_plan)，其中 m_i∈{AUTO, HUMAN_ON_LOOP, HUMAN_IN_LOOP, TELEOP} 为监督模式。联合优化：
```
maximize  R_mission(θ) − λ_C·Cost(θ)
s.t.      R_mission(θ) ≥ 1−Δ_mission
          U(θ) ∈ U_req
          ρ_ux(θ) ≤ ρ_max,  Σ_i a_i(θ) ≤ B_attn
          δ_i^budget ≥ δ_f,i^req(θ)（EEIS 可行性）
          T_maint ≥ T_min,  k_red ∈ {1,2,3},  TV(p_test,q)≤ε_profile
```
其中 δ_f,i^req 为该检查点扣除 ε_meta、δ_exec、δ_cc、δ_human 等后的可用预算。监督模式按拉格朗日水位分配：对每个检查点选 m 使 δ_total(m)+ν·a(m) 最小，ν 由 Σa_i≤B_attn 确定；风险削减/注意力边际收益递减时可贪心近似。若 K_safe(δ_i^budget)=∅，触发**设计反馈集** D_feedback={+1 冗余、降低 ω_traj、缩短 T_maint、扩大探测、收紧操作剖面}，而非静默降级。输出 Cert_rucc=(δ_i^budget, m_i, k_red, T_maint, test_plan, R_LB, U_vector, ρ_ux, version)。

**定义 158（可依赖性闭环 DCL）** DCL 在多时间尺度运行：
```
① Fast（每次接触，1–10 Hz）：沿用 CLEP，产出 EV-exec；
② Medium（每任务/每天）：汇总失效/近失/干预/降级/维修，更新 Weibull/Cox、HARM 信任与 HEP；
③ Slow（每次固件/硬件/维护变更）：重估 MCS、CCF、操作剖面，RUCC 重新编译，必要时重认证；
④ Design（季度/重大事故）：若 R_LB<1−Δ 或偏差持续，触发设计变更与可靠性增长试验。
```
每步满足单调保守性：证据变差 ⇒ δ_i^budget 不增、监督不降、维护不延后；任何放宽必须走再认证。输出 `EV-dep=(R_LB,c_L,profile_coverage,HEP_LB,U_vector,E_cal,MTBF,MTTR,A,growth_slope,maint_compliance,cc_bound)`。

**定义 159（依赖证据 EV-dep 与八类证据门）** 证据类扩展为八类：EV-probe\*、EV-xmodal、EV-human、EV-ft、EV-ux、EV-exec、EV-visit/EV-margin、**EV-dep**。EV-dep 仅用于三类门：(G1) 部署/再认证；(G2) 维修/固件更新后恢复运行；(G3) 监督模式/冗余度/操作剖面的变更审批。**硬规则**：EV-dep 不得替代任何单次接触证据；单次接触证据也不得外推为任务级可靠性认证。若 EV-dep 的 R_LB<1−Δ 或 HEP_LB>ε_H，则系统只允许进入受限操作剖面（限速、限载、限环境）并进入设计反馈，而不是“继续跑，反正过去没出事”。

**定义 160（依赖证书 J_dep 与 JCPS+++ 扩展）** J_dep=(survival_model_card, risk_allocation, fault_injection_report, profile_coverage, human_reliability_card, usability_report, trust_calibration, maintenance_plan, growth_analysis, design_change_log, version, signature)。JCPS+++ 在 JCPS++ 输出后追加：
```
(..., ξ_exec, C_rt, Cert_eeis, EV_exec_latest, B_exec_snapshot, M_rt_status,
 R_LB, Δ_mission, δ_i^budget, Cert_rucc, EV_dep_latest, U_vector, ρ_ux, E_cal, growth_slope, J_dep_id)
```
云边协议 CEB+++++：云端下发可靠性模型/操作剖面先验/加速寿命模型/RUCC 模板 → 边端在影子模式跑 N_shadow 任务并合成 EV-dep → 校验「R_LB≥1−Δ ∧ U∈U_req ∧ ρ_ux≤ρ_max ∧ 无共因异常」→ 通过才允许再认证；失败回滚并进入设计反馈。

## 2. 关键算法伪代码

### IP-152 LRM（纵向可靠性与风险分配）

```python
class LongitudinalReliabilityModel:
    def __init__(self, fault_tree, profile, frailty_theta_prior):
        self.ft = fault_tree                 # 最小割集 + 基本事件
        self.q = profile                     # 操作剖面相空间
        self.theta = frailty_theta_prior     # Gamma 脆弱性

    def lambda_budget(self, delta_mission, theta):
        if theta < 1e-9:
            return -np.log1p(-delta_mission)
        return ((1.0 - delta_mission)**(-theta) - 1.0) / theta

    def mission_reliability(self, lam_exposure, theta):
        # lam_exposure = Σ λ_i e_i（含 Cox 协变量）
        return (1.0 + theta * lam_exposure) ** (-1.0 / theta)

    def allocate_by_cutsets(self, delta_cat, ccf):
        # P(T) ≤ Σ_j P(MCS_j)，按重要度摊派，再在割集内对数均摊
        p_mcs = [ccf[j] * np.prod([self.ft.delta[b] for b in cs])
                 for j, cs in enumerate(self.ft.minimal_cutsets)]
        total = sum(p_mcs) + 1e-30
        budgets = {}
        for j, cs in enumerate(self.ft.minimal_cutsets):
            delta_j = delta_cat * p_mcs[j] / total
            per_event = (delta_j / ccf[j]) ** (1.0 / len(cs))
            for b in cs:
                budgets[b] = min(budgets.get(b, np.inf), per_event)
        return budgets

    def survival_update(self, durations, events, covariates):
        # Cox 部分似然估计 β；Weibull 基线；返回 R_LB(t, 1-α)
        return cox_weibull_fit(durations, events, covariates).lower_bound()
```

### IP-153 UAM（可用性评估与注意力队列）

```python
class UsabilityAttentionModel:
    def __init__(self, u_req, mu_op, T_int):
        self.u_req = u_req
        self.mu_op = mu_op
        self.T_int = T_int

    def queue_metrics(self, lam_req, service_var):
        rho = lam_req / self.mu_op
        if rho >= 1.0:
            return dict(rho=rho, Wq=np.inf, p_shed=1.0, a_eff=0.0)
        # M/G/1 Pollaczek-Khinchine
        Wq = lam_req * service_var / (2.0 * (1.0 - rho))
        p_shed = min(1.0, rho * np.exp(-(1.0 - rho) * self.T_int * self.mu_op))
        a_eff = max(0.0, 1.0 - rho) ** 1.0
        return dict(rho=rho, Wq=Wq, p_shed=p_shed, a_eff=a_eff)

    def usability_deficit(self, U):
        return sum(w * max(0.0, req - val) / scale
                   for w, req, val, scale in zip(self.w, self.u_req, U, self.scale))

    def feasible(self, U, rho):
        return self.usability_deficit(U) <= 0.0 and rho <= self.rho_max
```

### IP-154 HARM（信任、依赖与人类失误）

```python
class HumanAutomationRelianceModel:
    def __init__(self, trust0, alpha_s, alpha_f, alpha_fa, workload_max):
        self.T = trust0
        self.a_s, self.a_f, self.a_fa = alpha_s, alpha_f, alpha_fa
        self.Wmax = workload_max

    def update_trust(self, success, failure, false_alarm):
        self.T = np.clip(
            self.T + self.a_s*(1-self.T)*success
                   - self.a_f*self.T*failure
                   - self.a_fa*false_alarm, 0.0, 1.0)
        return self.T

    def hep(self, T_star, workload, a_eff, p_dis, delta_R, p_rec, h0, h_fa):
        T = self.T
        a_mon = a_eff * (1 - kappa*max(0.0, T-T_star)) * (1-workload/self.Wmax)
        d_prime = d0 * (a_mon/a_ref)**gamma * (1 - cw*workload/self.Wmax)
        c = c0 + c1*(T - T_star)
        p_hit = norm.cdf(d_prime/2 - c)
        p_fa = norm.cdf(-d_prime/2 - c)
        delta_H = (p_dis*h0 +
                   (1-p_dis)*(delta_R*(1-p_hit*p_rec) + (1-delta_R)*p_fa*h_fa))
        return min(1.0, max(0.0, delta_H)), abs(T - T_star), p_fa

    def allocate_supervision(self, checkpoints, attention_budget, nu):
        # m_i ∈ {AUTO, HUMAN_ON_LOOP, HUMAN_IN_LOOP, TELEOP}
        plan = []
        for cp in checkpoints:
            scores = [cp.delta_total(m) + nu*cp.attention(m) for m in MODES]
            plan.append(MODES[int(np.argmin(scores))])
        return plan
```

### IP-155 RBE（故障注入、生存分析与证据合成）

```python
class ReliabilityEvidenceBuilder:
    def __init__(self, fault_space, alpha):
        self.F = fault_space
        self.alpha = alpha

    def coverage_lower_bound(self, injections):
        # injections: {f: (n_f, d_f)}
        c_lb = 0.0
        for f, (n, d) in injections.items():
            c_f = beta.ppf(self.alpha/len(self.F), d, n-d+1) if n > d else 0.0
            c_lb += self.F.weight[f] * c_f
        return c_lb

    def residual_rate(self, lam_fault, c_lb, lam_cc):
        return lam_fault*(1-c_lb) + lam_cc

    def zero_failure_bound(self, n, alpha):
        return (1.0 - alpha) ** (1.0 / n)

    def required_sample_size(self, target_R, alpha):
        return np.log(alpha) / np.log(target_R)

    def combine_evidence(self, a_prior, b_prior, n_field, k_fail):
        posterior = beta(a_prior + k_fail, b_prior + n_field - k_fail)
        return beta.ppf(self.alpha, a_prior + k_fail, b_prior + n_field - k_fail)

    def growth_test(self, cumulative_failures, cumulative_time):
        # Crow-AMSAA：log N = log λ + β log t
        beta_hat = np.polyfit(np.log(cumulative_time),
                              np.log(cumulative_failures + 1e-9), 1)[0]
        return beta_hat  # <1 增长，>1 退化
```

class ReliabilityUsabilityCompiler:
    def __init__(self, lrm, uam, harm, eeis, pareto_designs):
        self.lrm, self.uam, self.harm, self.eeis = lrm, uam, harm, eeis
        self.designs = pareto_designs   # 离线预计算的设计点

    def compile(self, delta_mission, u_req, profile, budget):
        theta_U = self.lrm.theta_upper_confidence()
        lam_budget = self.lrm.lambda_budget(delta_mission, theta_U)
        feasible = []
        for d in self.designs:
            budgets = self.lrm.allocate_by_cutsets(
                delta_cat=delta_mission, ccf=d.ccf)
            delta_f = {b: budgets[b] - d.other_errors[b] for b in budgets}
            if any(v <= 0 for v in delta_f.values()):
                continue
            k_safe = [self.eeis.compile(delta_f[b], d.fused[b], d.xi_exec, d.b_r)
                      for b in delta_f]
            if any(k is None for k in k_safe):
                continue
            rho = self.uam.queue_metrics(d.lambda_req, d.service_var)['rho']
            if not self.uam.feasible(d.U, rho):
                continue
            feasible.append((d, delta_f, k_safe, rho))
        if not feasible:
            return None, design_feedback(self.lrm, delta_mission, u_req)
        best = max(feasible, key=lambda x: self.lrm.mission_reliability(
            x[0].lam_exposure, theta_U) - self.cost(x[0]))
        return cert_rucc(best, theta_U), None

### IP-152 LRM（纵向可靠性模型）

```python
import numpy as np
from scipy.stats import gamma, norm, beta
from dataclasses import dataclass, field

@dataclass
class FailureTaxonomy:
    safe_stop: float = 0.0      # 可恢复安全停
    degraded: float = 0.0       # 降级运行
    mission_abort: float = 0.0  # 任务中止
    catastrophic: float = 0.0   # 灾难性（唯一进入 Δ_mission 安全目标）

@dataclass
class MinimalCutSet:
    events: tuple               # 基本事件 id 元组
    ccf: float                  # 该割集的共因因子

class LongitudinalReliabilityModel:
    def __init__(self, cutsets, basic_events, theta_prior=(1.0, 1.0)):
        self.cutsets = cutsets
        self.delta = {b: 1e-6 for b in basic_events}   # 基本事件预算/先验
        self.theta_a, self.theta_b = theta_prior       # Gamma 先验（形状/率）
        self.history = []                              # (t, event, covariates)

    # ---------- 脆弱性 ----------
    def theta_mean(self):
        return self.theta_a / self.theta_b

    def theta_upper_confidence(self, conf=0.95):
        # Gamma 后验上分位；保守用于预算
        return gamma.ppf(conf, self.theta_a, scale=1.0/self.theta_b)

    def lambda_budget(self, delta_mission, theta):
        if theta < 1e-9:
            return -np.log1p(-delta_mission)
        return ((1.0 - delta_mission) ** (-theta) - 1.0) / theta

    def mission_reliability(self, lam_exposure, theta):
        return (1.0 + theta * lam_exposure) ** (-1.0 / theta)

    # ---------- 故障树分配 ----------
    def cutset_probabilities(self):
        probs = []
        for cs in self.cutsets:
            p = cs.ccf
            for e in cs.events:
                p *= self.delta[e]
            probs.append(p)
        return probs

    def allocate_by_cutsets(self, delta_cat):
        # P(top) ≤ Σ P(MCS)，按重要度摊派，再在割集内对数均摊
        probs = self.cutset_probabilities()
        total = sum(probs) + 1e-30
        budgets = {}
        for cs, p in zip(self.cutsets, probs):
            delta_j = delta_cat * p / total
            per_event = (delta_j / cs.ccf) ** (1.0 / max(1, len(cs.events)))
            for e in cs.events:
                budgets[e] = min(budgets.get(e, np.inf), per_event)
        return budgets

    def apply_budget(self, delta_cat):
        b = self.allocate_by_cutsets(delta_cat)
        for e, v in b.items():
            self.delta[e] = v
        return b

    # ---------- 生存数据 ----------
    def update_survival(self, durations, events, covariates):
        # Cox 部分似然 + Weibull 基线；返回参数与置信下界
        fit = cox_weibull_mle(durations, events, covariates)
        self.history.append(fit)
        return fit

    def reliability_lower_bound(self, t, alpha=0.05):
        fit = self.history[-1]
        return fit.R_lower(t, alpha)

    # ---------- 可用度 ----------
    def availability(self, mtbf, mttr):
        return mtbf / (mtbf + mttr) if (mtbf + mttr) > 0 else 0.0

    def availability_with_ccf(self, mtbf, mttr, beta_ccf):
        # 保守：共因至少贡献 β 的失效份额
        effective_failure = (1.0 / mtbf) * (1.0 + beta_ccf)
        return (1.0 / effective_failure) / (1.0 / effective_failure + mttr)
```

### IP-153 UAM（可用性评估与注意力队列）

```python
class UsabilityAttentionModel:
    def __init__(self, u_req, weights, scales, mu_op, T_int, rho_max=0.8):
        self.u_req = np.asarray(u_req, dtype=float)
        self.w = np.asarray(weights, dtype=float)
        self.scale = np.asarray(scales, dtype=float)
        self.mu_op = mu_op
        self.T_int = T_int
        self.rho_max = rho_max
        self.samples = []

    def observe(self, U_vector):
        self.samples.append(np.asarray(U_vector, dtype=float))

    # ---------- 排队 ----------
    def queue_metrics(self, lam_req, service_mean, service_var):
        rho = lam_req * service_mean / self.mu_op
        if rho >= 1.0:
            return dict(rho=rho, Wq=np.inf, p_shed=1.0, a_eff=0.0)
        # M/G/1 Pollaczek–Khinchine
        Wq = lam_req * service_var / (2.0 * (1.0 - rho))
        p_shed = min(1.0, rho * np.exp(-(1.0 - rho) * self.T_int / max(service_mean, 1e-9)))
        a_eff = max(0.0, 1.0 - rho) ** 1.0
        return dict(rho=rho, Wq=Wq, p_shed=p_shed, a_eff=a_eff)

    def usability_deficit(self, U):
        U = np.asarray(U, dtype=float)
        return float(np.sum(self.w * np.maximum(0.0, self.u_req - U) / self.scale))

    def is_feasible(self, U, rho):
        return self.usability_deficit(U) <= 0.0 and rho <= self.rho_max

    def add_ux_budget(self, budget):
        # 把注意力预算接入 PCE++++
        budget.register_budget('attn', capacity=1.0, used=0.0)
        return budget
```

### IP-154 HARM（人机依赖与人类失误）

```python
class HumanAutomationRelianceModel:
    def __init__(self, trust0=0.7, alpha_s=0.15, alpha_f=0.35,
                 alpha_fa=0.20, workload_max=100.0,
                 d0=2.0, a_ref=1.0, gamma=0.5, cw=0.5,
                 c0=0.0, c1=1.5, kappa=0.5):
        self.T = trust0
        self.a_s, self.a_f, self.a_fa = alpha_s, alpha_f, alpha_fa
        self.Wmax, self.d0, self.a_ref = workload_max, d0, a_ref
        self.gamma, self.cw, self.c0, self.c1, self.kappa = gamma, cw, c0, c1, kappa
        self.log = []

    def update_trust(self, success, failure, false_alarm):
        # 非对称：失败伤害大于成功修复
        self.T = float(np.clip(
            self.T + self.a_s * (1.0 - self.T) * success
                   - self.a_f * self.T * failure
                   - self.a_fa * false_alarm, 0.0, 1.0))
        self.log.append(self.T)
        return self.T

    def hep(self, T_star, workload, a_eff, p_dis, delta_R,
            p_rec=0.8, h0=0.1, h_fa=0.05):
        a_mon = a_eff * (1.0 - self.kappa * max(0.0, self.T - T_star)) \
                * (1.0 - workload / self.Wmax)
        d_prime = self.d0 * (max(a_mon, 0.0) / self.a_ref) ** self.gamma \
                  * (1.0 - self.cw * workload / self.Wmax)
        c = self.c0 + self.c1 * (self.T - T_star)
        p_hit = float(norm.cdf(d_prime / 2.0 - c))
        p_fa = float(norm.cdf(-d_prime / 2.0 - c))
        delta_H = (p_dis * h0 +
                   (1.0 - p_dis) * (delta_R * (1.0 - p_hit * p_rec)
                                    + (1.0 - delta_R) * p_fa * h_fa))
        return dict(delta_H=min(1.0, max(0.0, delta_H)),
                    HEP_miss=1.0 - p_hit, P_fa=p_fa,
                    E_cal=abs(self.T - T_star))

    def allocate_supervision(self, checkpoints, attention_budget):
        # 拉格朗日水位：选 m 使 δ_total(m)+ν·a(m) 最小，二分 ν 满足预算
        lo, hi = 0.0, 1e6
        for _ in range(40):
            nu = 0.5 * (lo + hi)
            plan = [min(cp.modes, key=lambda m: cp.delta_total(m) + nu * cp.attention(m))
                    for cp in checkpoints]
            used = sum(cp.attention(m) for cp, m in zip(checkpoints, plan))
            if used > attention_budget:
                lo = nu
            else:
                hi = nu
        return plan
```

### IP-155 RBE（可靠性证据）

```python
class ReliabilityEvidenceBuilder:
    def __init__(self, fault_space, alpha=0.05):
        self.F = fault_space         # {layer: weight}
        self.alpha = alpha

    # ---------- 故障注入覆盖率 ----------
    def coverage_lower_bound(self, injections):
        # injections: {layer: (n, d)}；每层 Clopper–Pearson 下界，加权求和
        m = len(self.F)
        c_lb = 0.0
        for layer, (n, d) in injections.items():
            if n <= 0:
                continue
            c_f = beta.ppf(self.alpha / m, d, n - d + 1) if d < n else 1.0
            c_lb += self.F[layer] * c_f
        return c_lb

    def residual_rate(self, lam_fault, c_lb, lam_cc=0.0):
        return lam_fault * (1.0 - c_lb) + lam_cc

    # ---------- 生存分析 ----------
    def zero_failure_bound(self, n, alpha=None):
        alpha = self.alpha if alpha is None else alpha
        return (1.0 - alpha) ** (1.0 / n)

    def required_sample_size(self, target_R, alpha=None):
        alpha = self.alpha if alpha is None else alpha
        return np.log(alpha) / np.log(target_R)

    def weibull_lower_bound(self, durations, events, t, alpha=None):
        alpha = self.alpha if alpha is None else alpha
        fit = weibull_mle(durations, events)   # 处理右删失
        return fit.R_lower(t, alpha)

    # ---------- 加速寿命 ----------
    def arrhenius_af(self, Ea, T_use_k, T_stress_k):
        kB = 8.617e-5  # eV/K
        return np.exp((Ea / kB) * (1.0 / T_use_k - 1.0 / T_stress_k))

    def inverse_power_af(self, n, V_stress, V_use):
        return (V_stress / V_use) ** n

    # ---------- 操作剖面 ----------
    def profile_tv(self, p_test, q_field):
        keys = set(p_test) | set(q_field)
        return 0.5 * sum(abs(p_test.get(k, 0.0) - q_field.get(k, 0.0)) for k in keys)

    def effective_sample_size(self, n, tv):
        return max(0.0, n * (1.0 - tv))

    # ---------- 证据合成 ----------
    def combine_beta(self, a_prior, b_prior, n_field, k_fail, conf=0.95):
        a_post = a_prior + k_fail
        b_post = b_prior + n_field - k_fail
        return beta.ppf(1.0 - conf, a_post, b_post), (a_post, b_post)

    def simulation_prior(self, n_sim, c_sim, validation_score):
        # 幂先验：用 validation_score 折算仿真有效样本
        a = 1.0 + validation_score * n_sim * c_sim
        b = 1.0 + validation_score * n_sim * (1.0 - c_sim)
        return a, b

    # ---------- 可靠性增长 ----------
    def crow_amsaa(self, cumulative_failures, cumulative_time):
        x = np.log(np.asarray(cumulative_time, dtype=float))
        y = np.log(np.asarray(cumulative_failures, dtype=float) + 1e-9)
        beta_hat = float(np.polyfit(x, y, 1)[0])
        return beta_hat   # <1 增长，≈1 平稳，>1 退化
```

### IP-156 RUCC（可靠性-可用性联合编译器）

```python
class ReliabilityUsabilityCompiler:
    def __init__(self, lrm, uam, harm, eeis, design_pareto):
        self.lrm, self.uam, self.harm, self.eeis = lrm, uam, harm, eeis
        self.designs = design_pareto

    def compile(self, delta_mission, u_req, profile, budget):
        theta_U = self.lrm.theta_upper_confidence()
        lam_budget = self.lrm.lambda_budget(delta_mission, theta_U)
        feasible = []
        for d in self.designs:
            # ① 任务风险预算 → 逐检查点预算
            if d.lam_exposure > lam_budget:
                continue
            budgets = self.lrm.allocate_by_cutsets(delta_mission)
            delta_f = {b: budgets[b] - d.other_errors.get(b, 0.0) for b in budgets}
            if any(v <= 0 for v in delta_f.values()):
                continue
            # ② EEIS 可行性
            k_safe = []
            for b, df in delta_f.items():
                ks, cert = self.eeis.compile(df, d.fused[b], d.xi_exec, d.b_r[b])
                if ks is None:
                    break
                k_safe.append((b, ks, cert))
            if len(k_safe) != len(delta_f):
                continue
            # ③ 可用性/注意力可行性
            q = self.uam.queue_metrics(d.lam_req, d.service_mean, d.service_var)
            if not self.uam.is_feasible(d.U, q['rho']):
                continue
            # ④ 人类可靠性上界
            h = self.harm.hep(d.T_star, d.workload, q['a_eff'],
                              d.p_dis, d.delta_R)
            if h['delta_H'] > d.delta_H_max or h['E_cal'] > d.eps_trust:
                continue
            feasible.append((d, delta_f, k_safe, q, h))
        if not feasible:
            return None, self.design_feedback(delta_mission, u_req, theta_U)
        best = max(feasible, key=lambda x: self.score(x))
        return self.cert(best, theta_U), None

    def score(self, x):
        d = x[0]
        r = self.lrm.mission_reliability(d.lam_exposure, self.lrm.theta_mean())
        return r - self.cost(d)

    def cost(self, d):
        return (C_MAINT * (d.horizon / max(d.T_maint, 1e-9))
                + C_RED * d.k_red + C_TEST * d.n_test
                + C_ATTN * d.total_attention + C_DOWN * d.mttr / max(d.T_maint, 1e-9))

    def design_feedback(self, delta_mission, u_req, theta_U):
        # 不可行不是“更保守地降级”，而是设计空间反馈
        return {
            'options': ['add_redundancy(k+1)', 'reduce_omega_traj(20%)',
                        'shorten_T_maint(50%)', 'expand_evidence(n_test+1x)',
                        'restrict_operational_profile(TV<=0.05)'],
            'reason': 'RUCC_infeasible',
            'delta_mission': delta_mission,
            'u_req': u_req,
            'theta_U': theta_U,
        }

    def cert(self, best, theta_U):
        d, delta_f, k_safe, q, h = best
        return DependabilityDesignCertificate(
            delta_budget=delta_f,
            supervision_plan=d.supervision_plan,
            redundancy=d.k_red,
            maintenance_interval=d.T_maint,
            test_plan=d.test_plan,
            R_LB=self.lrm.reliability_lower_bound(d.horizon),
            theta_U=theta_U,
            U_vector=d.U,
            rho_ux=q['rho'],
            p_shed=q['p_shed'],
            HEP_LB=h['delta_H'],
            E_cal=h['E_cal'],
            version=self.version,
        )
```

@dataclass
class DependabilityCertificate:
    chain: list
    version: int = 0
    timestamp: float = 0.0

    def append(self, c):
        c.version = self.version + 1
        c.timestamp = time.monotonic()
        c.signature = sign(c.payload())
        self.chain.append(c)
        self.version = c.version

    def verify_chain(self):
        versions = [c.version for c in self.chain]
        if any(b <= a for a, b in zip(versions, versions[1:])):
            return False
        if any(not (0.0 <= c.R_LB <= 1.0) for c in self.chain):

        if any(c.signature != sign(c.payload()) for c in self.chain):
            return False
        return True

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LRM | Cox/Weibull MLE O(n log n)；割集分配 O(\|MCS\|·\|B\|) | O(n+\|B\|) | Gamma 脆弱性下界、最小割集联合界、CCF β-factor 保守 |
| UAM | O(1)/交互；百分位 O(N_hist) | O(N_hist) | M/G/1 利用率约束、丢弃概率上界、可用性赤字 |
| HARM | O(1)/信任更新；监督分配 O(\|CP\|·\|M\|·log ν) | O(\|CP\|) | 非对称信任动力学、SDT 漏检/误报、HEP 上界 |
| RBE | 注入 O(n_inj)；生存 O(n log n)；合成 O(1) | O(n_inj+n) | Clopper–Pearson 覆盖率下界、右删失生存下界、幂先验可审计 |
| RUCC | 离线 Pareto O(\|D\|·cost)；在线 O(\|D\|) 查表 | O(\|D\|) | 割集风险预算、EEIS 可行性、可用性约束、设计反馈完备 |
| DCL | O(\|CP\|·CLEP + n) | 复用 + O(n) | 多时间尺度单调保守、EV-dep 不越权、终止性 |
| EV-dep/J_dep | O(1)/追加；链校验 O(k) | O(k) | 版本单增、签名、R_LB∈[0,1]、时间尺度分离 |

**正确性定理（Dependability–Usability Co-Assurance, DUCA）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** 操作剖面 q 具有代表性：TV(p_test,q)≤ε_profile，协变量 z 覆盖主要混杂；脆弱性 θ 的上置信界 θ_U 诚实。**(A57)** 故障注入分层覆盖操作剖面，覆盖率下界 c_f^L 有效；共因 β-factor 下界不低估；故障处置定义为“检出+安全响应”而非仅检出。**(A58)** HARM 在代表性用户/负荷下校准：|HEP_pred−HEP_obs|≤ε_HEP，信任动力学稳定；可用性指标以置信区间测得。**(A59)** RUCC 的 Pareto 设计集覆盖可行域；风险分配尊重最小割集与脆弱性；不可行时触发设计反馈而非静默降级。**(A60)** DCL 更新单调保守：证据变差 ⇒ 预算不增、监督不降、维护不延后；任何放宽必须再认证。**(A61)** 时间尺度证据分离：EV-dep 只做系统级门，不进入单次接触证据集。则：

1. **任务可靠性下界**：在置信度 ≥1−α_evid 下，R_mission ≥ 1−Δ_mission−ε_profile−ε_model；若使用 θ_U 与共因上界，则下界仍保守。
2. **可用性约束**：U∈U_req（置信 ≥1−α_ux），ρ_ux≤ρ_max，请求丢弃概率 ≤p_shed^U；否则 RUCC 判不可行并触发设计反馈。
3. **人类可靠性上界**：δ_H≤HEP_U，且 E_cal≤ε_trust；E_cal 超界触发信任修复/监督升级，不得以“人已确认”替代机器证据。
4. **可靠性证据健全**：R_LB 由右删失生存分析与多源证据合成得到；故障注入覆盖率 c_L 与操作剖面偏差 TV 显式进入下界；β-factor 使冗余不被高估。
5. **无时间尺度抽象泄漏**：EV-dep 与单次接触证据不可互相替代；用“历史可靠”为“当前高风险接触”背书被硬拒绝。
6. **终止性与有界设计迭代**：DCL 在 k_probes+k_cons+k_ft+k_ux+k_exec+k_design 内终止于 {承诺, 绕行, 降档, L2 协商, 安全停, 受限操作剖面, 设计变更}。
7. **部署界**（任务级，含共因与人类）：

```
P(mission safe) ≥ 1 − Δ_mission
Δ_mission ≤ Σ_i [δ_f,i + ε_meta,i + δ_probe,i + ε_h,i + δ_ood,i + δ_xm,i
                 + δ_ft,i + δ_kg,i + δ_ux,i + δ_exec,i + δ_ξood,i
                 + δ_ertc,i + δ_eeis,i + δ_cc,i + δ_human,i + δ_profile,i]
```

其中 δ_cc 由 β-factor 给出，δ_human 由 HARM 上界给出，δ_profile 由操作剖面偏差与重要性加权给出；独立近似仅在通过相关性与共因检验后允许。

**三条新增单向通道（与既有三条安全单向通道并列）**：
- **可靠性通道**：证据变差 ⇒ 任务风险预算收紧 ⇒ 逐次预算更小 ⇒ 动作更保守/设计变更；
- **可用性通道**：中断率升高 ⇒ 注意力利用率升高 ⇒ 有效注意力下降 ⇒ HEP 上界上升 ⇒ 监督升级或请求节流；
- **时间尺度通道**：EV-dep 只能否决/限制，不能为单次高风险接触放行。

**实验补充说明**
- E188 需要**受试者内设计**：同一批用户在“低保守/中保守/高保守”三档下完成任务，测量 SUS、NASA-TLX、任务时间、中断次数、请求放弃率；用混合效应模型控制学习效应。关键不是证明“越保守越差”，而是定位**总任务可靠性 = 机器可靠 × 人类可靠**的拐点。
- E189 需要**故障注入式人因实验**：在受试者不知情条件下注入自动化失效，测量漏检率与信任更新；对比 HARM 预测。严禁对真实高风险任务做欺骗性实验，必须在模拟器/影子模式中进行。
- E190 的零故障样本量必须显式报告“统计不可行区”：R≥1−10⁻⁶ 在 95% 置信下约需 3×10⁶ 次零故障试验，因此高保障声明必须由故障注入 + 形式化 + 加速寿命 + 贝叶斯合成共同支撑，不能伪造现场试验。
- E191 的“零灾难性”必须配合**负二项/贝叶斯零故障上界**报告，不能把“没观察到”直接当成“概率为零”。

## 6. 本轮最大风险

**一句话**：本轮把“逐次安全”升级为“任务级可依赖”，其最大风险是**用不具代表性的用户、任务与操作剖面把可用性和可靠性都测成“看起来达标”的统计幻觉，尤其当 HARM 的人类失效模型本身失校、共因与脆弱性被低估时，J_dep 会给出虚假的高保障，反而诱导更激进的自主与更少的人工监督**；必须以「操作剖面偏差 TV 显式进入下界」「故障注入覆盖率下界 + 共因 β-factor 保守」「人类模型校准误差超界即升级监督」「EV-dep 只做系统级门、绝不替代单次证据」「不可行即设计变更而非静默降级」五重护栏，宁可受限操作剖面与频繁再认证，也不允许用“过去很可靠”为“此刻高风险”背书。
