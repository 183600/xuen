# 第 47 轮（承接第 46 轮 v10/v23；本轮灵感：腕部相机 × 同步定位与建图） · WristSLAM-Cert：腕手运动链耦合的分层 SLAM 姿态证书与可观测性感知操作（四层架构 v11）

> 承接第 45/46 轮：v10 用能量租约把深度相机变成条件观测增强器，v23 又加入记忆/语音/安全绑定，但两者都默认感知传感器安装在稳定平台（头部/基座）且其外参静止。腕部相机打破该隐含假设 H5：传感器随机械臂运动，其全局位姿 = 关节正运动学 ⊗ 手眼外参，任一项漂移都会让「局部很准」的腕部观测在全局坐标中系统性偏移。同步定位与建图（SLAM）恰好提供反向约束：用地图/回环残差独立锚定腕部位姿，把漂移变成可检测的一致性残差；而腕部相机又能为 SLAM 提供操作区近距、高分辨、可主动规划视角的观测。新问题：**如何把腕部相机作为「运动链耦合的局部高精观测器」接入姿态证书，让局部证书与 SLAM 全局证书在变换不确定度下可复合、可互检，并利用冗余操作自由度做可观测性感知的抓取/轨迹选择**。

## 0. 直觉与动机

**灵感 1（腕部相机 → 局部精度与手眼外参不确定性）**
直觉：腕部相机贴近操作对象，对抓取/接触区域的分辨率与遮挡鲁棒性远胜头部相机；但它看到的世界在「腕部坐标系」，要进入全局姿态证书必须经过 T_bw(q_t)=T_be(q_t)·T_ew。关节编码器分辨率、连杆热变形、手眼标定残差都会进入 ||δT_bw||。因此腕部证书应被建模为**局部证书 P^w 加变换不确定度椭球 B(Σ_bw)**，而不是直接当全局证书用。局部高精不等于全局可信。

**灵感 2（同步定位与建图 → 独立全局锚点与回环一致性）**
直觉：SLAM 不只是一个位姿源，更是一个**独立于运动链的全局参考系**：地图路标匹配与回环闭合给出的残差 r_slam 可用来检验运动链预测的 T_bw。若残差超过由共形校准得到的阈值，说明手眼/关节/动态物体至少有一项异常，应冻结腕部证书。反过来，腕部相机移动视角本身可作为主动 SLAM 的观测源，其视差与近距纹理能降低地图熵。

**灵感 3（耦合 → 操作即观测）**
直觉：机械臂末端轨迹由操作任务决定，但抓取位姿与冗余零空间里仍有自由度；在这些自由度中选择「任务等价但观测更优」的解，可在不牺牲任务的前提下降低 SLAM 与姿态不确定性。这把 SLAM 从被动定位升级为**可观测性感知的操作规划**：操作动作同时是观测动作。

**耦合升级**：在 v10 四层上，L1 几何层拆为「全局层（SLAM/头部/基座）」与「腕部局部层」，用变换不确定度复合；L2 上下文层预测手眼漂移风险与动态遮挡；L3 CAR 增加三源一致性守卫；L4 DCL 采集手眼标定审计与回环负样本；根信任层新增 SLAM 一致性证书。四层 v11 = 根信任（姿态/能量/SLAM 一致性）+ L1 分层几何 + L2 上下文预测 + L3 安全守卫 + L4 覆盖驱动采集。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（腕手变换链与不确定度传播）**
腕部相机在基座系的位姿 T_bw(q)=T_be(q)·T_ew。令 Σ_q 为关节编码/连杆误差协方差，Σ_ew 为手眼标定残差协方差，J_q 为 T_be 对 q 的雅可比，则
Σ_bw = J_q Σ_q J_q^T + R_ew Σ_ew R_ew^T + Σ_model。
**变换不确定度球** B(Σ_bw)={δT : ||δT||_Σ² ≤ χ²_{1-α_T}}。

**定义 60（分层姿态证书与复合算子）**
腕部局部证书 P_t^w 只承诺对象相对腕部相机的关系。全局证书
P_t^g = P_t^w ⊕ B(Σ_bw)，其半径 rad(P_t^g)=rad(P_t^w)+L_T·λmax(Σ_bw)^{1/2}。
**复合 soundness**：P(X_b∈P_t^g) ≥ 1-α_w-α_T，其中 L_T 为变换作用的 Lipschitz 常数。

**定义 61（SLAM 一致性残差与一致性证书）**
r_slam(t)=d_SE3(T_bw^slam(t), T_bw^kin(q_t))，其中 T_bw^slam 来自路标/回环估计。
SLAM 一致性证书 S_t 有效 iff r_slam(t) ≤ q_{1-α_s}(校准残差分布)。
S_t 失效 ⇒ 冻结腕部源，全局姿态退回头部/基座证书，且不得由腕部源单独支撑安全谓词。

**定义 62（三源一致性守卫）**
三源 s∈{腕部视觉里程/路标, 正运动学, 头部 SLAM 地图匹配}。残差向量 r=(r_wk, r_ws, r_ks)，协方差 Σ_r 由校准集估计。
一致性判据 ||r||²_{Σ_r} ≤ χ²_{1-α_c}。任一源缺失时按保守规则膨胀 Σ_bw 并降低可信度，而不是直接放行。

**定义 63（可观测性感知操作选择）**
在任务等价抓取/零空间集合 G_task={g : task_cost(g)≤ε} 上选择
g* = argmax_{g∈G_task} E[ ΔH_slam(g) + β·Δrad^{-1}(g) ] - λ_task·task_cost(g)，
约束：预测三源一致性有效、能量租约 ℓ_e 有效。ΔH_slam 为视角/视差带来的 SLAM 熵减，Δrad^{-1} 为预期姿态半径缩减。

## 2. 新增产出与既有 IP 升级

**IP-69 WSC（Wrist-SLAM Cert Adapter）**
- 腕部局部证书签发：近距对象相对位姿 + 遮挡分层
- 手眼/关节不确定度在线估计与 Σ_bw 传播
- 局部→全局证书复合算子 ⊕，显式膨胀变换误差
- 手眼标定健康度监测：温漂/负载/碰撞后触发重标定

**IP-70 TCG（Tri-source Consistency Guard）**
- 三源残差监测与 Mahalanobis 一致性检验
- SLAM 回环一致性证书 S_t 与共形阈值校准
- **运动链自掩膜**：用已知连杆/夹爪几何把自身像素从 SLAM 中剔除，抑制「机械臂自己动」被误判为动态障碍
- 失效策略：冻结腕部源 → 全局退回头部/基座证书 → CAR fail-closed

**IP-71 OAM（Observability-Aware Manipulation Planner）**
- 任务等价抓取/冗余零空间集合枚举
- SLAM 熵减 + 证书半径缩减的联合效用
- 与 ECPS 能量租约联合约束：观测收益不得透支电池安全阈值
- 预测性视角规划：在进入弱纹理/遮挡区前预置可观测抓取姿态

**既有 IP 升级**
- IP-63 ECPS：模态集加入 Wrist，效用项增加 SLAM 熵减
- IP-64 DEPTH-CERT ADAPTER：增加腕部-深度联合校准，腕部近距深度单独分层
- IP-61 DCL：采集手眼标定审计样本、回环负样本、运动链自掩膜边界样本
- IP-62 CCA：新增运动链漂移红队、动态物体误入 SLAM 红队、手眼碰撞后恢复测试
- IP-51 CAR：守卫加入三源一致性 S_t 与 |δT_bw| 上界
- IP-45 总线：新增 wrist-pose / slam-residual / consistency-cert / handeye-health 话题

## 3. 算法骨架

TCG + WSC 每控制周期：
1. 读 q_t、腕部图像、头部 SLAM 位姿、ℓ_e
2. 由 q_t 算 T_bw^kin，传播 Σ_bw 与 B(Σ_bw)
3. 对路标/回环算 r_slam，并算三源残差 r 与 Mahalanobis 检验
4. 若一致性通过 → 签发 P_t^w 并复合为 P_t^g；否则冻结腕部源、膨胀全局证书
5. 若处于抓取/轨迹选择阶段 → OAM 在 G_task 上最大化联合效用，同时检查 ℓ_e
6. 结果交 CAR；任一证书过期或能量/一致性失效 → fail-closed

## 4. 本轮最大风险

**一句话**：腕部局部证书会因近距高分辨而显得非常「可信」，一旦手眼外参或连杆热变形漂移，SLAM 与运动学可能共享同一系统性偏差而无法互检，导致全局证书静默乐观；因此必须用独立地图锚点/标定板周期性重标定，并把变换不确定度显式膨胀进全局证书，禁止腕部源单独支撑全局安全谓词。

## 1. 符号体系与精化定义（增量：定义 64–68）

| 符号 | 含义 |
|---|---|
| T_bw(q) | 腕部相机在基座系位姿 = T_be(q)·T_ew |
| Σ_q, Σ_ew | 关节/连杆误差协方差、手眼标定残差协方差 |
| Σ_bw | 复合变换不确定度协方差 |
| P_t^w, P_t^g | 腕部局部证书、变换复合后的全局证书 |
| r_slam | SLAM 路标/回环位姿与运动学预测的 SE(3) 残差 |
| S_t | SLAM 一致性证书（布尔） |
| r=(r_wk,r_ws,r_ks) | 三源残差向量 |
| G_task | 任务等价抓取/零空间集合 |
| ΔH_slam | 视角/视差带来的 SLAM 熵减 |

**定义 64（手眼-关节复合不确定度椭球）**
Σ_bw = J_q Σ_q J_q^T + R_ew Σ_ew R_ew^T + Σ_model，其中 J_q=∂T_be/∂q，R_ew 为将手眼误差旋转到基座系。椭球 B(Σ_bw) 由 χ²_{1-α_T} 截断，用于替代简单球界，避免各向异性误差被过度或不足膨胀。

**定义 65（SLAM 回环残差分布与共形阈值）**
在校准集 D_cal 上计算 {r_slam}，取
τ_s = Quantile_{1-α_s}({r_slam})。
S_t=1 iff r_slam(t)≤τ_s；覆盖率保证 P(r_slam≤τ_s)≥1-α_s-ε_cal。

**定义 66（分层证书复合算子 ⊕）**
P_t^g = P_t^w ⊕ B(Σ_bw)，rad(P_t^g)=rad(P_t^w)+L_T·sqrt(λmax(Σ_bw))。
**soundness（union bound）**：P(X_b∈P_t^g) ≥ 1-α_w-α_T，只要局部证书与变换界分别成立。复合算子满足单调性：Σ_bw 增大 ⇒ P_t^g 只增不减。

**定义 67（运动链自掩膜）**
用正运动学与已知连杆/夹爪几何，将机器人自身像素投影为掩膜 M_self(q_t)，SLAM 前端只在 (1-M_self) 上提取特征。自掩膜漏检率上界 δ_mask 由几何尺寸与标定误差给出，需计入 Σ_bw 的 Σ_model 项。

**定义 68（可观测性-任务联合效用）**
U_OAM(g)=E[ΔH_slam(g)] + β·E[Δrad^{-1}(g)] - λ_task·task_cost(g) - λ_e·E_cost(g)，
约束 task_cost(g)≤ε、S_t(g)=1、E(t+Δ|m)≥E_min。β 在弱纹理/透明/近距遮挡场景上调大。

## 2. 关键算法伪代码

### IP-69 WSC
```
def wrist_cert(q_t, image_t, map_t, calib):
    T_kin = forward_kinematics(q_t) @ calib.T_ew
    Sigma_bw = jacobian_q(q_t) @ calib.Sigma_q @ jacobian_q(q_t).T \
             + rot(calib.R_ew) @ calib.Sigma_ew @ rot(calib.R_ew).T \
             + calib.Sigma_model
    obs = local_pose_estimate(image_t)          # 对象相对腕部相机
    P_w = local_certificate(obs, alpha_w)       # 局部共形证书
    radius_g = P_w.radius + L_T * sqrt(largest_eig(Sigma_bw))
    return GlobalCert(P_w.mean, radius_g, Sigma_bw), T_kin

def handeye_health(q_t, tag_residual, temperature, load):
    # 独立锚点/标定板残差 + 温漂 + 负载漂移
    return weighted_score(tag_residual, temperature, load)
```

### IP-70 TCG
```
def kinematic_self_mask(q_t, camera_model):
    proj = render_robot_geometry(q_t)           # 连杆/夹爪投影
    return dilate(proj, margin=delta_mask)

def three_source_residual(q_t, wrist_obs, head_slam):
    T_kin = forward_kinematics(q_t) @ T_ew
    T_w = wrist_obs.T_bw
    r_wk = se3_dist(T_w, T_kin)
    r_ws = se3_dist(T_w, head_slam.T_bw)
    r_ks = se3_dist(T_kin, head_slam.T_bw)
    return array([r_wk, r_ws, r_ks])

def tcg_guard(q_t, wrist_obs, head_slam, calib, alpha_c):
    mask = kinematic_self_mask(q_t, calib.camera_model)
    r = three_source_residual(q_t, wrist_obs, head_slam)
    d2 = r.T @ inv(calib.Sigma_r) @ r
    consistent = d2 <= chi2_ppf(1-alpha_c, df=len(r))
    r_slam = se3_dist(head_slam.T_bw, forward_kinematics(q_t) @ calib.T_ew)
    S_t = r_slam <= calib.tau_s
    return consistent and S_t, r, S_t, mask
```

### IP-71 OAM
```
def oam_plan(G_task, c_t, B_t, map_t, calib):
    best, best_u = None, -inf
    for g in G_task:
        if not task_feasible(g):            continue
        if not energy_lease_feasible(B_t, g): continue
        dH   = expected_slam_entropy_reduction(g, map_t, c_t)
        drad = expected_cert_radius_reduction(g, calib)
        cost = task_cost(g) + lambda_e * energy_cost(g)
        u = dH + beta(c_t) * drad - cost
        if u > best_u:
            best, best_u = g, u
    return best  # 需通过 tcg_guard 的三源一致性复核后才执行
```

### 主循环
```
def wrist_slam_loop(q_t, image_t, head_slam, B_t, G_task, calib):
    ok, r, S_t, mask = tcg_guard(q_t, local_vo(image_t, mask=None), head_slam, calib)
    if not ok:
        freeze_wrist_source()
        return head_or_base_certificate(), 'frozen_wrist'
    cert_g, T_kin = wrist_cert(q_t, image_t, map, calib)
    if G_task is not None:
        g = oam_plan(G_task, c_t, B_t, map, calib)
        return cert_g, g, 'observability_aware'
    return cert_g, 'cert_only'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| WSC 证书复合 | O(d³)（Σ_bw 求特征值） | O(d²) | 变换界成立 ⇒ 全局证书 soundness ≥1-α_w-α_T |
| TCG 三源守卫 | O(d²)（Mahalanobis） | O(1) | 一致性阈值由共形校准给出，误报率 ≤α_c |
| 运动链自掩膜 | O(H·W) 渲染/膨胀 | O(H·W) | 自身像素漏检 ≤δ_mask，δ_mask 计入 Σ_model |
| OAM 规划 | O(|G_task|·d) | O(|G_task|) | 仅在任务等价集合内部优化，不改变任务可行性 |

**正确性定理（腕部-全局证书复合）**
设腕部局部证书满足 P(X_w∈P_t^w)≥1-α_w，变换误差落在 B(Σ_bw) 内（概率 ≥1-α_T），且复合半径按定义 66 膨胀。则对任意安全谓词 φ，若 φ 在 P_t^g 上成立，则 φ 以概率 ≥1-α_w-α_T 对真实位姿成立。若 TCG 判定不一致（S_t=0 或 Mahalanobis 超阈），系统冻结腕部源并退回头部/基座证书；若退路证书也不可用，则 CAR fail-closed。因此腕部源不能单独把系统从「不安全」翻转成「安全」，只能在不一致性检验通过后收紧全局证书。

**推论（操作即观测的安全边界）**：OAM 的抓取选择不改变 task_cost≤ε 约束，因此任务层安全性不变；其收益只体现在 SLAM 熵减与证书半径缩减，且必须再次通过 TCG 复核，防止「为观测而移动到危险位姿」。

| E115 不确定度传播校准 | 预测 e_bw vs 实测手眼/关节误差 | 相对误差 ≤15%；覆盖率 ≥1-α_T-0.02 |
| E116 三源一致性守卫 | 故障检出率、误报率（注入手眼偏移/关节偏置/动态干扰） | 检出 ≥95%；误报 ≤1% |
| E117 分层证书覆盖率 | 全局 P_t^g 实际覆盖率、平均半径 | 覆盖率 ≥1-α_w-α_T-0.02；半径不劣于头部基线 +10% |
| E118 运动链自掩膜 | 自身像素剔除率、SLAM ATE 改善 | 剔除 ≥90%；ATE 改善 ≥20% |
| E119 OAM 操作选择 | 任务成功率、证书半径、SLAM 熵 | 成功率不降；半径缩减 ≥20%；SLAM 熵降 ≥15% |
| E120 100h 腕手 SLAM 闭环 | 安全违例、重标定次数、fail-closed 次数 | 安全违例 0；重标定 ≤2 次/周；fail-closed ≤1% 周期 |

回退策略：
- E115 预测误差 >30% → 关闭腕部→全局证书复合，腕部仅作对象相对抓取用，不进安全谓词。
- E116 误报 >5% → 提高 α_c 的保守度并加入运动链残差的自适应协方差；仍不达标则退化为双源守卫（腕部+头部）。
- E118 自掩膜漏检高 → 扩大掩膜膨胀 margin，并把漏检率显式加到 Σ_model。
- E119 任务成功率下降 → β 调小，OAM 仅在抓取冗余度高的任务上启用。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 手眼外参漂移导致局部证书全局乐观 | 高 | 独立标定板/地图锚点周期重标定；Σ_ew 在线膨胀；碰撞后强制失效 |
| SLAM 与运动学共享系统偏差，三源无法互检 | 高 | 引入与运动链完全独立的固定地图锚点/全局回环；禁止腕部源单独支撑安全谓词 |
| 动态物体（含机械臂自身）污染 SLAM | 中 | 运动链自掩膜 + 动态像素 RANSAC + 回环残差门控 |
| 腕部快速运动导致运动模糊/尺度漂移 | 中 | 近距低视差时提高回环权重；模糊帧降权并膨胀 Σ_bw |
| OAM 为观测移动破坏任务或耗尽能量 | 中 | 任务等价集约束 + 能量租约联合约束 + 二次 TCG 复核 |
| 腕部深度与头部深度尺度不一致 | 低 | IP-64 联合校准；尺度残差计入 Σ_model |

## 6. 本轮最大风险

**一句话**：腕部局部证书会因近距高分辨而显得非常「可信」，一旦手眼外参或连杆热变形漂移，SLAM 与运动学可能共享同一系统性偏差而无法互检，导致全局证书静默乐观；因此必须用独立地图锚点/标定板周期性重标定，并把变换不确定度显式膨胀进全局证书，禁止腕部源单独支撑全局安全谓词。
