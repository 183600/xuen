# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「避障控制」×「主动交互」）

> R69 把不确定性一分为二（aleatoric 收紧、epistemic 去问），并让「看/问/触」成为可认证、可审计的信息动作。但它对「交互」的理解是**单向的、认识论的**：交互是向世界**读取**状态——`VoI(g)=H(M|o)−E[H(M|o,y)]` 把「对方会怎么回应」当作给定的 `p(y|g,o)`。这在避障场景里从根上不成立：**避障的对象往往不是一个服从固定分布的障碍物，而是一个其未来取决于「它以为你会怎么做」的智能体**。你按喇叭、打灯、往左偏一点，不只是「获取信息」，而是在**改变对方的策略**。R69 的 VoI 给这件事定价为零。
>
> 于是 R69 在交互世界里落入两个坏结局：
> - **过度信任**：它假设「我问了，对方就会配合」，把一次信号当成已建立的默契，结果是**与一个幻影伙伴自信地协同**；
> - **过度保守**：一旦不确定就退回 `λ_floor`、退回 R68 的「只收紧」。可是在双向避障里，**双方同时「只收紧」不是安全，而是死锁（frozen robot）**；而当死锁发生在道口、救护通道、单向窄巷里，**不动的代价本身就是伤害**。
>
> 本轮两个灵感正好补上这条缺失的**第二方向**：
> - **避障控制**告诉我们：安全是**运动约束下的不变性**，而双向场景的安全不是单边属性，而是**责任分摊 + 协商**的联合属性（CBF / 责任敏感安全 / 不可避免碰撞态 ICS）；
> - **主动交互**在避障里有第二重含义：不只是「问清楚」，更是「**让对方看懂我、和我达成通行约定**」——打灯、让行、试探性前探、口头「您先请」，都是**写入**对方信念的动作。
>
> 核心命题：**在 R69 的「读取式交互（VoI）」旁边，加入对称的「写入式交互（Influence）」；把避障的安全约束升级为「责任可分摊、且可回退」的 RA-CBF 安全滤波；把交互升级为有截止时间、可验证、可反制的通行协商协议；纯保守只作为「协商失败」的边界，而不再被当成「永远更安全」的默认。** 命名 **RECON-RAS**（Reciprocal Embodied Coordination & Negotiation：互惠具身协作与协商的风险自适应闭环；RECON 亦取「reconnaissance，侦察」之意，承接 R69 的探询）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我该怎么让对方看懂我，并和我达成一个双方都敢执行的约定**」——R69 学会提问，R70 学会**谈判**。

## 0. 直觉与动机

**灵感 1（避障控制 → 安全是「约束下的不变性」，不是「预测无碰撞」）**
直觉：R68/R69 的安全是「按模型推演未来 H 步大概率不撞」。避障控制提供了一个更强的东西：**控制障碍函数（CBF）** 用 `ḣ(x,a) ≥ −α h(x)` 保证安全集的前向不变性——不是「预测大概率安全」，而是「只要约束成立，就出不去」。但标准 CBF 有一个隐含假设：**别人的轨迹是给定的**。在双向避障里，`ḣ` 同时依赖 `a_ego` 和 `a_other`，而 `a_other` 又依赖 `a_other` 对 `a_ego` 的预测。安全因此**不是单边可保证的属性**，而是一个**责任分摊的联合属性**：谁让、让多少、在多久内让。把这一点形式化，就是本轮的骨架。

**灵感 2（主动交互 → 交互有第二个方向：写入）**
直觉：R69 的信息动作是「看/问/触」，目的是**减少我的不确定性**。可人类避障里最重要的交互是反过来的：**降低对方关于我的不确定性**。打转向灯、减速、车身往一侧偏、抬手示意「你先走」——这些动作用任务效率换**可读性（legibility）**，让对方能预测我，从而让双方都能做更果断（更不保守）的动作。R69 的 `VoI` 度量「我学到的」；本轮需要一个对偶量 `VoInf`，度量「我让对方学到的、以及由此改变的联合结局」。**信息动作与通信动作共享同一个动作空间、同一份预算、同一套安全认证**——这正是「主动交互」在避障语境下的严格版本。

**灵感 3（双向 → 保守不是安全的万能默认，死锁是新的失败模式）**
直觉：R68/R69 的整套哲学是「不确定就收紧」。在单边场景这是对的（更慢=更安全）。但在双向场景里，**双方都收紧会冻结**：两车在窄路对峙、两个行人同时左右横跳、机器人与人在门口互相谦让。冻结本身不一定碰撞，却是**活性（liveness）失败**；而当外部时间压力存在（道口、消防通道、电量/药效窗口），**活性失败会转化为安全失败**。这不是要拿安全换效率，而是承认：**在互惠系统里，"什么都不做"不是零风险动作**。因此需要一个**有界、可回退、可认证的"主张"（assertion）**去打破对称——这正是主动交互的用武之地。

**灵感 4（可读性 → 说和做必须互相作证）**
直觉：R69 的证据纪律是「单源不得定案，需 k 个正交证据一致」。把它平移到通信：**一句「您先请」必须被我的运动学佐证**（真的减速、真的让出通道），否则只是噪声；反过来，**我的运动学也必须被信号解释**（为什么我突然往左偏？因为我要左转，不是要撞你）。显式信号与隐式动力学的一致性，是防止「口是心非」和「动作被误读」的唯一廉价手段。**信号不是承诺，信号+动力学才构成可验证的承诺。**

**灵感 5（互惠 → 新的威胁模型：信号可被武器化）**
直觉：一旦系统会「打灯、示意、让行」，就出现了攻击面：**假让行**（示意你过、然后加速）、**诱导性可读动作**（做出"我要让"的轨迹把你引进死角）、**共谋挤压**（两个智能体用约定把你夹住）、**约定歧义**（不同文化/不同厂商对同一手势有相反解释）、**我方虚张声势**（承诺让行却不执行，短期占便宜、长期摧毁信道可信度）。主动交互把 R69 的「被证实的错误」进一步升级为「**被双方共同执行的错误**」——协同越成功，方向错时越致命。

**灵感 6（严格姿态 → 常态恒等、危险区可回退、失败即 R69）**
直觉：RECON 必须像前几轮一样**包含 R69 而不是替代它**。做法是「**可回退责任**」：默认我承担全部避让责任（`r=1`，此时与 R69 保守路径逐指令相同）；只有当对方被观测为**响应者**、且约定被「显式信号 + 隐式动力学」双通道确认、且我保有在 `τ_react` 内退回 `r=1` 的认证回退动作时，才允许把责任部分让渡出去（`r<1`）。任一条不满足 → 立刻回到 `r=1`。于是安全侧不做让步，效率与活性来自**可撤销**的责任让渡，而不是放松安全。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（RECON-RAS 总览）** RECON-RAS = (RDM, RA-CBF, VoX, NEG, LDC, RG, DSB, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **默认全责**：未建立经确认的约定前，执行动作必须落在「我承担全部避让责任」的 RA-CBF 安全集 `S(1)` 内；
(iii) **可回退责任**：允许 `r<1` 的必要条件是存在认证回退序列，使系统在 `τ_react` 内回到 `S(1)`；不满足即刻重置 `r=1`；
(iv) **双通道作证**：任何通信/约定只有被「显式信号 + 隐式动力学」一致性（LDC）确认后才可改变 `r`、VoX 或证据权重；
(v) **失败退化**：对方非响应、约定歧义、LDC 不一致、协商超时或疑似欺骗时，RECON 逐指令退化为 R69。

**定义 311（互惠动力学模型 RDM）** 联合状态 `x=(x_e,x_j)`，对方策略 `π_j(a_j | x, b_j)`，其中 `b_j` 是**对方关于我意图的信念**。我的动作/信号通过 `b_j` 影响 `a_j`，故转移 `x' = f(x, a_e, a_j)` 是耦合的。为避免无限阶信念递归，只保留**一阶心智模型（level-1）**：我维护 `b̂_j` 的分布，并假设对方以 level-0（把我当固定分布）行动；不确定时用最坏情形 `min_{a_j∈Br(b̂_j)}` 上界。对方非响应时 `π_j` 与 `b_j` 无关，RDM 退化为固定障碍分布。

**定义 312（责任分摊与 RA-CBF 安全集）** 对每对 (e,j) 定义成对障碍 `h_{ej}(x)`（剩余安全裕度，扣除双方制动/恢复距离）。责任因子 `r∈[0,1]` 表示我承担的避让份额；联合安全集
`S(r) = { x : h_{ej}(x) ≥ (1−r)·h_req(x), ∀j }`。
**RA-CBF 条件**：存在 `a_e` 使 `ḣ_{ej} ≥ −α(h_{ej}) − r·(∂h/∂x_j)·a_j^{worst}`，即我对**最坏对方响应**仍保持 `S(r)` 前向不变。`S(1)` 是我**单边可保证**的安全集（对方任意行动都不撞）；`S(0)` 是完全依赖对方承担。`r` 只能依据「约定 + LDC」在 `S(1)` 与 `S(r*)` 之间切换。

**定义 313（第三类不确定性：约定不确定性 U_conv）** R69 的 `U_epi` 是「世界处于哪个模态」；本轮新增
`U_conv = H(r | 证据)`，即「**谁该让、让多少**」这一**共享约定**的后验熵。它既不是 aleatoric（能通过交互降低），也不是个体 epistemic（它不是关于我的观测，而是关于**两个心智之间的固定点**：我认为对方认为我会怎么做）。`U_conv` 的可约性受限于对方的**可响应性**与**诚实性**，因此只有 `U_conv` 与 R69 的 `U_epi` **分开计价、分开处置**：`U_epi` 走读取式交互，`U_conv` 走协商。

**定义 314（不可避免碰撞态与协商截止时间 ICS / T_neg）** 在 RDM 与 `S(r)` 下定义「无联合可行动作」态集 `ICS`（inevitable collision state，用离线可达集/在线采样近似）。`T_neg(x)` 为在**最坏对方响应**下从 `x` 进入 `ICS` 的剩余时间。协商必须在 `T_neg` 之前完成；交互的**时序可行性**为 `L_neg(s) + L_act ≤ T_neg`。这给 R69 的静态 VoI 加了一个硬截止：**在避障里，晚到的答案价值为零**。

**定义 315（交互总价值 VoX）** 把信息价值与影响价值相加、并用截止时间截断：
```
VoX(g,s) = VoI(g) + VoInf(s) − c(g,s) − risk(g,s)
VoI(g)   = H(M|o) − E_{y~p(·|g,o)}[ H(M|o,y) ]                 # R69：我学到了什么
VoInf(s) = E_{b̂_j'~Update(b̂_j|s)}[ U_joint ] − E_{b̂_j}[ U_joint ]  # 本轮：对方被我改变了什么
可行域   : L_neg(s)+L_act ≤ T_neg(x)
```
`VoInf` 可正可负（误读会引发过度反应/恐慌），故必须与 `VoI` 一起**过安全认证**；`VoI` 与 `VoInf` 是同一信道的两个方向，**总带宽（交互预算）共享**。选择 `(g*,s*) = argmax VoX`，若 `max VoX ≤ 0` 则不交互、直接走 `S(1)`（R69 边界）。

**定义 316（可读性—动力学一致性 LDC）** 对显式信号 `s` 与时间窗 `τ_react` 内的隐式动力学 `d`，定义一致性分 `κ(s,d) ∈ [0,1]`（信号蕴含的意图分布与动力学外推意图分布的归一化一致度）。规则：`κ ≥ τ_κ` ⇒ 信号可计入约定；`κ < τ_κ` ⇒ 信号视为噪声、不改变 `r`；**信号与动力学方向相反** ⇒ 欺骗告警 `ℰ_signal`，立即 `r=1`。含义：**说和做必须互相作证**，任一方都不能单独定案（R69 证据纪律的通信版）。

**定义 317（通行协商协议 NEG）** 约定原语集 `𝒫 = {assert_priority, yield, propose_alternative, request_confirm, hold}`。一次协商是长度 `≤ N_neg` 的原语序列，每步：发出 `s_p` → 在 `τ_react` 内观测对方响应 → 若 `LDC` 确认则得到 `(约定 c*, 责任 r*)`，否则继续/失败。每步 `s_p` 与伴随任务动作必须过 C-RAS-WM 与 RA-CBF。协商失败 ⇒ `r=1` 并进入保守（必要时安全停）。**这是 R69「问一次」到「握手」的升级：协调需要提议—观测—确认的闭环，而不是单条消息。**

**定义 318（可响应性门控 RG）** 用历史估计对方是否响应：`ρ = Î(a_j; s_e)`（互信息）。`ρ < τ_resp` ⇒ 判定对方为「障碍物式」非响应体，令 `VoInf≡0`、`U_conv` 不可约，RECON **逐指令退化为 R69**。这是防止「幻觉出合作者」的门控，对应 R69 的模态校准门 MCG：**不让不可信的可响应性假设驱动协商**。

**定义 319（死锁与对称打破 DSB）** 死锁判据：双方速度/进度低于阈值、均处于对方 `S(1)` 内、且 `TTH_social`（外部时间压力导致的伤害时间）在收缩。**对称打破主张** `a_brk` 是一个幅度/时长有界、可撤销的动作（小幅前探、侧偏、显式信号）。允许条件：(a) `a_brk` 满足「最可能对方响应」下的 RA-CBF；(b) 存在 `τ_react` 内退回 `S(1)` 的认证回退；(c) `a_brk` 不减小 `TTH_social`。三者缺一不可——**绝不允许用"打破死锁"为名，行冒进之实**。

**定义 320（两级安全滤波 SF）** 第一级（硬，永远生效）：`a ∈ S(1)`。第二级（协调，可撤销）：仅当 `RG` 判定可响应、`NEG` 给出 `LDC` 确认的 `r*<1`、且可回退条件成立时，允许 `a ∈ S(r*)`。任何时刻条件失效 → 投影回 `S(1)`。于是**个体碰撞概率上界与 R69 的最坏情形相同**，协调只改善活性与效率，不放松安全上界。

**定义 321（互惠威胁模型 ℰ_recip）** `ℰ_recip = {ℰ_spoof（假让行后加速）, ℰ_lure（可读轨迹诱导进入死角）, ℰ_collude（双体协同挤压）, ℰ_ambig（约定语义歧义）, ℰ_freeze（恶意静止阻塞）, ℰ_bluff（我方虚张）}`。并入 `ℰ_RECON = ℰ_FLUID × ℰ_recip`。

**定义 322（证书 J_RECON）** `J_RECON = (J_FLUID, r*, convention_id, confirmed, T_neg_slack, VoInf, LDC_κ, ρ_resp, deadlock_state, fallback_margin, signal_log_hash, recon_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 默认全责或可回退责任成立 ∧ 协商在预算/截止内 ∧ LDC 确认 ∧ 回退已认证`。

**定义 323（信誉—可信度账本 RCL）** 记录我方「发出信号 → 实际执行」的一致性 `cred ∈ [0,1]`：每次虚张/未兑现则衰减，且衰减后 `VoInf` 按 `cred` 打折。理由：**通信是重复博弈**，单次撒谎的收益必须被未来信道贬值抵消。审计可离线核验 `signal_log_hash` 与执行轨迹。

**定义 324（RECON 主闭环）** 在 R69 闭环的不确定性处置后插入：可响应性门控 → 协商（若 `U_conv` 高且未过截止）→ 计算 `VoX` 选 `(g,s)` → LDC 确认 → RA-CBF 两级滤波 → 死锁打破（受限）→ 执行/证书/审计。见第 2 节伪代码。

## 2. 关键算法骨架

```python
# IP-264 RDM：互惠动力学（一阶心智 + 最坏情形上界），非响应时退化为固定障碍
class ReciprocalDynamics:
    def predict(self, x, a_ego, s, H):
        b = self.belief_j.update(s, self.history)          # 我估计的"对方关于我的信念"
        worst = self.pi_j.worst_case(x, b)                 # min over admissible responses
        return self.f(x, a_ego, worst, H)
    def responsiveness(self):
        return mutual_info(self.history.a_j, self.history.s_ego)   # RG 的 ρ

# IP-265 RA-CBF：默认全责；只在"可回退 + LDC 确认"时放宽责任
def ra_cbf_filter(a_cmd, x, r_star, fallback, tau_react):
    r = 1.0
    if r_star < 1.0 and lcd_confirmed(x) and retractable(x, r_star, fallback, tau_react):
        r = r_star
    a = project_to_safe(a_cmd, safe_set(x, r), rdm=RD)
    if not in_safe_set(a, x, r):
        r = 1.0
        a = project_to_safe(a_cmd, safe_set(x, 1.0), rdm=RD)   # 硬回退
    return a, r

# IP-266 VoX：信息（读）+ 影响（写），带协商截止时间
def interaction_value(modes, x, g, s, budget):
    T_neg = M.ics.negotiation_horizon(x, worst_case=True)
    if L_neg(s) + L_act > T_neg:                       return -inf   # 太晚，问了没用
    voi   = H(modes) - expected_entropy(modes, g, x)
    voinf = expected_joint_utility(x, signal=s) - expected_joint_utility(x)  # 对方行为改变
    return voi + voinf - cost(g, s) - risk(g, s)

# IP-267 NEG：提议—观测—确认的通行握手（而非单次提问）
def negotiate(x, deadline, budget):
    for p in [ASSERT_PRIORITY, YIELD, PROPOSE_ALT, REQUEST_CONFIRM]:
        if not budget.allow(p) or L_neg(p) > deadline: break
        s = emit(p)
        if not (c_ras_wm.certify(s, x) and ra_cbf_ok(s, x)): continue
        resp = observe(horizon=tau_react)
        if lcd.kappa(s, resp) >= TAU_K:               # 显式+隐式一致，才算约定
            return Convention(p, r=responsibility_of(p)), s
```

## 3. 推导

**引理 19（VoI 是 VoX 的非响应退化）** 若对方非响应（`ρ<τ_resp`），则 `b_j` 与 `s` 无关，`VoInf≡0`、`U_conv` 不可约，`VoX=VoI−c−risk`，且 `NEG` 恒失败令 `r=1`。故 RECON 在非响应环境中的决策与 R69 **逐指令相同**。要点：R69 不是被替换，而是 RECON 在「世界不会回望我」这一边界上的特例。

**引理 20（可回退责任的安全性）** 设 `r(t)<1` 仅在 (a) 约定经 `LDC` 确认、(b) 存在 `τ_react` 内回到 `S(1)` 的认证回退时启用。若对方在 `τ_react` 内背叛，系统在离开 `S(r*)` 前已回到 `S(1)`，故轨迹保持碰撞自由；若背叛在 `τ_react` 之后才发生，则它已不属于「可检测窗口内的欺骗」，其最坏后果被 `S(1)` 的鲁棒不变性兜住。因此对任意 `a_j`，RECON 的个体碰撞概率 ≤ R69 的最坏情形上界。系：**责任让渡不降低安全上界，只提高活性**——因为它是**可撤销**的。

**引理 21（死锁的活性—安全转化）** 定义外部伤害时间 `TTH_social(x)`（不前进导致的伤害，如道口关闭、通道阻塞）。若保守策略使 `TTH_social` 单调降到 0 前仍未脱离死锁，则纯保守策略的失败概率 > 0。因此存在环境使 `Pr_fail(R69 保守) > Pr_fail(RECON 有界主张)`。要点：**这推翻了「保守永远更安全」的隐含公理**，但没有推翻「保守是安全的默认」——它只说明默认需要在有界条件下被主动打破。这是本轮最锋利的理论主张，也是最大的伦理/安全责任所在。

**引理 22（信号投毒上界）** 单用显式信号时，若对方欺骗/误读率 `δ_s`，错误约定采纳率 ≥ `δ_s`；要求 `LDC`（显式信号与隐式动力学一致，两通道相关性 `ρ<1`）后错误率 ≤ `δ_s·ρ + ε_σ`；再叠加信誉账本 `cred`，重复攻击的收益按 `cred^{k}` 衰减。系：**「说」必须被「做」背书**，与 R69 的 k-正交证据纪律同构。

**定理 18（RECON 严格包含 R69，且安全上界不降）** 在 A100–A103（有界欺骗延迟 `τ_react`、可响应性可估、RA-CBF 可解、协商预算有界）下：
(a) 非响应 ⇒ 逐指令等价 R69；
(b) 可响应 ⇒ 死锁率严格下降、联合成功率上升；
(c) 任意情形 ⇒ 个体碰撞概率 ≤ R69 最坏上界（引理 20）。
故 R69 = RECON 在 `r≡1, ρ≡0` 边界上的退化；RECON 的收益全部来自「可回退的责任让渡」，不来自安全放松。

**定理 19（协商截止时间的安全性）** 若协商在 `T_neg` 前启动、在 `L_neg+L_act ≤ T_neg` 内完成且保有认证回退，则协商阶段不提高进入 `ICS` 的概率；若 `T_neg` 到期仍无确认约定，紧急回退（最大制动/最保守 `S(1)` 投影）保持 `S(1)` 前向不变，控制连续、无突变。

## 6. 本轮最大风险

**一句话**：RECON 的全部活性收益都押在一个**关于他心的假设**上——「对方可被我看懂、也看得懂我，并且愿意按约定行动」；一旦这个假设是错的（对方非响应、文化/厂商约定相反、或故意假让行/诱导），**主动交互就不再是协调，而是与一个幻影伙伴共同执行的自信错误**，而「死锁会转化为安全失败」的论证还可能被误用来为冒进的主张背书——**协同得越漂亮，方向错时撞得越狠**。

**次级风险与缓解**：
1. **责任让渡被背叛** → 可回退责任 + `τ_react` 认证回退 + `S(1)` 硬兜底（引理 20）；
2. **把非响应体幻觉成合作者** → RG 门控（定义 318），`ρ<τ_resp` 即逐指令退回 R69；
3. **假让行 / 诱导 / 共谋** → LDC 双通道作证 + 信誉账本 + ℰ_recip 对抗训练（引理 22）；
4. **死锁论证被滥用为冒进许可** → DSB 三重限制（最可能响应下的 RA-CBF、可回退、不压缩 `TTH_social`）+ 审计；
5. **协商超时/实时预算** → `T_neg` 硬截止 + 协商 ≤3 轮 + 到期紧急回退（定理 19）。

```python
    a = project_to_safe(a_cmd, safe_set(x, r), rdm=RD)
    if not in_safe_set(a, x, r):
        r = 1.0
        a = project_to_safe(a_cmd, safe_set(x, 1.0), rdm=RD)          # 硬回退
    return a, r

# IP-266 VoX：读 + 写，带协商截止
def interaction_value(modes, x, g, s, budget):
    if L_neg(s) + L_act > M.ics.negotiation_horizon(x): return -inf   # 太晚
    voi   = H(modes) - expected_entropy(modes, g, x)
    voinf = expected_joint_utility(x, s) - expected_joint_utility(x)
    return voi + voinf - cost(g, s) - risk(g, s)

# IP-267 NEG：提议—观测—确认的通行握手
def negotiate(x, deadline, budget):
    for p in [ASSERT_PRIORITY, YIELD, PROPOSE_ALT, REQUEST_CONFIRM]:
        if not budget.allow(p) or L_neg(p) > deadline: break
        s = emit(p)
        if not (c_ras_wm.certify(s, x) and ra_cbf_ok(s, x)): continue
        resp = observe(horizon=tau_react)
        if lcd.kappa(s, resp) >= TAU_K:
            return Convention(p, r=responsibility_of(p)), s
        if lcd.contradicts(s, resp): return None, None                # 口是心非
    return None, None                                                 # → R69 保守

# IP-268/269：交叉作证 + 可响应性门控
def lcd_kappa(sig, dyn):
    return 1.0 - total_variation(intent_from_signal(sig), intent_from_dynamics(dyn))
def responsiveness_gate(hist):
    return mutual_info(hist.a_j, hist.s_ego) > TAU_RESP

# IP-270 DSB：有界、可回退、不压缩 TTH_social
def break_deadlock(x, tth_social):
    if not deadlocked(x): return None
    a = minimal_assertion(x)
    if (certified_with_fallback(a, x, tau_react)
            and tth_social - L_neg_min(a) >= 0):
        return a
    return None

# IP-274 主闭环
def RECON_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)        # R68/R69
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 1) 互惠层：值不值得谈、来不来得及谈
    rho = M.rdm.responsiveness(); x = M.state.estimate()
    r_star, s = 1.0, None
    if rho > TAU_RESP and M.ics.negotiation_horizon(x) > L_NEG_MIN:
        conv, s = M.neg.negotiate(x, M.ics.negotiation_horizon(x), M.budget)
        if conv is not None: r_star = conv.r
    # 2) 读取式交互（R69）与写入式通信共享预算
    g = None
    if U_epi > TAU_EPI or M.ics.uncertain_convention(x):
        g, s = M.vox.choose(modes, x, M.budget, s)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    # 3) 两级安全滤波（硬约束）
    A = M.ach.propose(x_prime, H=M.vista.H)
    A, r = M.ra_cbf.filter(A, x, r_star, fallback=M.emergency, tau_react=M.tau)
    # 4) 死锁：仅在外部时间压力下、且可回退时做有界主张
    if M.state.deadlocked() and M.state.tth_social() < TAU_SOC:
        a_brk = M.dsb.break_deadlock(x, M.state.tth_social())
        if a_brk is not None: A = a_brk
    # 5) 认证、调度、审计
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    lam = M.efs.risk_scale(...)                                        # R69 λ 仍生效
    M.vqa_n.submit_async(s, r, rho, M.ics.negotiation_horizon(x), A)
    return k, lam, (U_ale, U_epi), (r, s)
```

## 4. 推导

**引理 19（VoI 是 VoX 的非响应退化）** `ρ<τ_resp ⇒ b_j⊥s ⇒ VoInf≡0, U_conv` 不可约，`NEG` 恒失败令 `r=1`，故 `VoX=VoI−c−risk`，RECON 与 R69 逐指令相同。R69 = RECON 在「世界不会回望我」边界上的特例。

**引理 20（可回退责任的安全性）** `r<1` 仅在 LDC 确认 + `τ_react` 内可回 `S(1)` 时启用。`τ_react` 内的背叛在越界前已被硬回退拦截；更晚的背叛由 `S(1)` 鲁棒不变性兜底。故对任意 `a_j`，个体碰撞概率 ≤ R69 最坏上界。系：**责任让渡只提活性，不降安全上界**，因为它是可撤销的。

**引理 21（死锁的活性—安全转化）** 若保守使 `TTH_social` 在脱离死锁前降到 0，则纯保守的失败概率 > 0。故存在环境使 `Pr_fail(R69 保守) > Pr_fail(RECON 有界主张)`。要点：**「保守永远更安全」在互惠系统中不成立**；但它仍是默认，只能被有界条件主动打破。

**引理 22（信号投毒上界）** 单显式信号错误采纳 ≥ `δ_s`；加 LDC（双通道相关 `ρ<1`）后 ≤ `δ_s·ρ+ε_σ`；再乘信誉 `cred^k`。与 R69 的 k-正交证据纪律同构：**「说」必须被「做」背书**。

**定理 18（RECON 严格包含 R69，安全上界不降）** A100–A103 下：(a) 非响应 ⇒ 逐指令等价 R69；(b) 可响应 ⇒ 死锁率严格下降、联合成功率上升；(c) 任意情形 ⇒ 个体碰撞概率 ≤ R69 最坏上界。故 R69 = `r≡1, ρ≡0` 的退化边界。

**定理 19（协商截止时间安全性）** 协商在 `T_neg` 前启动、`L_neg+L_act≤T_neg` 内完成且保有认证回退 ⇒ 不提高进入 `ICS` 的概率；超期则紧急回退保持 `S(1)` 前向不变，控制连续无突变。

## 7. 本轮最大风险

**一句话**：RECON 的全部活性收益都押在一个**关于他心的假设**上——「对方可被我看懂、也看得懂我，并愿意按约定行动」；一旦假设为假（非响应、约定相反、假让行/诱导），主动交互就从协调变成**与幻影伙伴共同执行的自信错误**，而「死锁会变成安全失败」还可能被误用为冒进的借口——**协同得越漂亮，方向错时撞得越狠**。

**次级风险与缓解**：责任让渡被背叛（可回退责任 + `τ_react` 硬回退 + `S(1)` 兜底，引理 20）；幻觉合作者（RG 门控，定义 318）；假让行/诱导/共谋（LDC 双通道 + 信誉账本 + ℰ_recip，引理 22）；死锁论证被滥用（DSB 三重限制 + 审计）；协商超时（`T_neg` 硬截止 + ≤3 轮 + 到期紧急回退，定理 19）。
