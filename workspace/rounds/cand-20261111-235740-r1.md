# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「6D位姿估计」×「事件相机」）

> 第 54 轮把技能组合从“能力匹配”推进到“动作-鲁棒性双证书”，但整套证书仍隐含一个强大而不自知的假设：**位姿是同步、稠密、无时延的已知量**。真实系统里，6D 位姿是稀疏、异步、带对称歧义且会漂移的估计；事件相机给出的是“变化”而非“场景”。本轮把证书从“动作空间上的静态声明”升级为“**位姿商空间上的时空声明**”。核心矛盾：H22：现有证书把位姿当作裸 SE(3) 输入，忽略对象/动作对称，把同一物理状态的两种写法当成两种风险，也把真实的粗粒度动作等价误判为不安全；H23：事件相机只测变化，若不做自运动消解，就无法区分“机器人自己动”“物体动”与“光照变”，事件要么全是噪声、要么被当成万能触发器；H24：帧式位姿、事件流与动作指令三套时基不同步，证书最危险的失效不是“估计错了”，而是“在过期的位姿上被证明安全”。

## 0. 直觉与动机

**灵感 1（位姿是商空间上的点，不是 SE(3) 上的点）**
直觉：圆柱绕轴转 180°、方盒转 90°，外观与动作结果都可能不变。位姿估计器输出相差一个对称变换的两个解，其实可能是同一个物理状态。若证书直接吃裸 SE(3)，就会把“同一状态的两种写法”当成两种风险，白白消耗安全预算，甚至因代表元抖动而误触发。正确对象是**动作相关位姿商** `P_a = SE(3)/G_act(a)`，距离用商度量。6D 位姿因此不是“坐标”，而是“对称类 + 可观测谱”。

**灵感 2（“看起来一样”必须收紧为“动作等价”）**
直觉：对象对称群 `G_obj` 只说物体外观不变，但动作只关心 `G_act(a) ⊆ G_obj`。吸盘抓顶面可能对整圈旋转不敏感；平行夹爪只对 180° 不敏感；键槽插入对任何旋转都敏感。用 `G_obj` 做商会把 90° 的错误当等价（**不安全**），用裸 SE(3) 又会把 180° 的正确解当错误（**过度保守**）。所以证书只允许使用**保守估计** `Ĝ_act(a) ⊆ G_act(a)`：宁可商得更细，不可商得更粗。

**灵感 3（事件相机是“变化触发器”，不是第二个深度相机）**
直觉：事件相机没有绝对亮度与稠密深度，它的价值是 **微秒级时间分辨率 + 高动态范围 + 低延迟**。它最该承担的角色不是重新做一遍位姿估计，而是回答“**位姿什么时候必须重估、证书什么时候必须续期**”。把事件流当作一个信息率信号，喂给位姿不确定度的演化方程，就能得到时变的位姿球 `ε_pose(t)`。

**灵感 4（自运动消解：事件残差才是信号）**
直觉：机器人快速运动时，大部分事件是“自己动”造成的，而不是环境变了。既然动作 `a` 与本体感觉 `u` 已知，就可以预测自运动事件 `E_ego(a,u)`，并把它从观测事件里减掉。**残差事件 `R_E = E ⊖ E_ego` 才是外部变化/接触/人为干扰的信号**。这直接接上第 54 轮的动作剖面 `α_S`：动作不光“覆盖哪些动作”，还“解释哪些事件”。事件相机由此从被动传感器变成动作条件的验证通道。

**灵感 5（事件驱动的不确定度演化 → 时变位姿球 → 触发式再认证）**
直觉：没有事件时（静止、无纹理、均匀光照），位姿不是“更确定”，而是**慢慢漂移**；事件密集时，信息率上升，位姿球收缩。于是位姿不确定度是一个受事件信息率驱动的随机过程 `dε²/dt = D - 2κI_E(t)`。证书不该是一次性盖章，而应带**有效期**：当 `ε_pose(t)` 超预算、或残差事件率异常、或时基偏差超限时触发再认证。这就是**事件触发再认证 ETR**。

**灵感 6（时基是证书的一等维度）**
直觉：最阴险的失败不是位姿算错，而是位姿算对了但“过期了”。帧式估计在 `t_f`、事件在 `t_e`、动作在 `t_c`，若 `δ_t = |t_f - t_c| + latency` 超过预算，则基于该位姿的动作证书在物理上无效。时基偏差经动作雅可比放大为动作误差 `Δa ≤ L_a·δ_t`，必须作为证书的显式否决项，而不是工程细节。

**灵感 7（云边交换的是“位姿契约 + 时间窗”，不是位姿点）**
直觉：云端维护全局位姿图（慢、准、可回环），边端维护事件驱动的局部位姿（快、低延迟、会漂移）。二者各自局部正确，却可能在对称商上分叉，或一个新鲜一个过期。云边契约应交换 `(对称类, 假设集, 商距离上界, 时间戳, 有效窗, 残差事件摘要)`。**位姿混叠 (pose alias)** 有两种：空间混叠（残差小但商距离大）和**时间混叠**（残差小但已过有效期）。事件残差与时间窗共同把二者区分开。

**灵感 8（主动消歧只解决可观测方向，规范方向应拒绝）**
直觉：若歧义落在规范方向（真实对称），再拍多少帧、再看多少事件都无法消除，继续消歧只是浪费动作预算；只有可观测方向上的不确定性能被信息增益降低。因此主动消歧应在商空间上计算**单位预算信息增益** `IG_a`，当剩余歧义在预算内不可判定时，系统应给出“可证明不可判定”的保守动作或拒绝，而不是赌一个位姿。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（动作相关位姿商与位姿球）**
对象对称群 `G_obj = {g ∈ SE(3) | g·O = O}`。对动作类 `a`，动作相关对称群
```
G_act(a) = { g ∈ G_obj | Φ_a(Tg) = Φ_a(T), ∀T ∈ SE(3) }
```
动作相关位姿商 `P_a = SE(3)/G_act(a)`，商距离
```
d_{P_a}([T1],[T2]) = min_{g1,g2∈G_act(a)} ||log((T1 g1)^{-1}(T2 g2))||_se(3)
```
位姿球 `B_ε^{P_a}([T]) = { [T'] : d_{P_a}([T],[T']) ≤ ε }`。**保守性约定**：证书只使用估计 `Ĝ_act(a) ⊆ G_act(a)`，于是 `P̂_a` 更细、`d_{P̂_a} ≥ d_{P_a}`；任何证书结论在真实商上仍成立。

**定义 122（事件流与自运动残差）**
事件流 `E = {(x_k,t_k,p_k)}`。给定动作 `a` 与本体感觉 `u`，自运动事件预测器 `E_ego(a,u)`。**残差事件**
```
R_E = E ⊖ E_ego(a,u)
```
其中 `⊖` 为带极性/时间容差的多重集差或对比度残差。残差事件率 `λ_R(t) = |R_E ∩ [t-Δ,t]| / Δ`，自运动解释率 `η_ego(t) = 1 - λ_R(t)/λ_E(t)`。理想情形 `η_ego→1` 表示“全是自己动的”，`η_ego→0` 表示环境/接触发生了独立变化。

**定义 123（事件信息率与时变位姿不确定度）**
位姿不确定度按随机过程演化
```
dε_pose²/dt = D(ρ_motion, texture, exposure) - 2κ·I_E(t)
```
`I_E(t)` 为事件信息率（残差对齐后的 Fisher/Hessian 信息流），`D` 为漂移率。在校准集上用分裂保形校准，使在触发时刻
```
P( d_{P̂_a}([T_true], [T̂]) ≤ ε_pose(t) ) ≥ 1 - α_p
```
**位姿护栏** `Guard_pose(t) = 1[ε_pose(t) ≤ ε_budget ∧ t - t_last_update ≤ H_pose]`。

**定义 124（位姿条件动作剖面与位姿条件鲁棒性）**
动作映射 `Φ_a` 在 `P_a` 上的水平雅可比 `S_a = ∂Φ_a/∂ξ`，位姿协方差回拉
```
Σ_a = S_a Σ_ξ S_a^T
```
位姿条件动作剖面与鲁棒性
```
α_S(a | [T], ε) = inf_{[T']∈B_ε^{P̂_a}([T])} α_S(a | [T'])
ρ_S(d | ε)      = inf_{[T']∈B_ε^{P̂_a}([T])} ρ_S(d; [T'])
```
二者构成**位姿感知动作证书** `PAC = (α_S(·|[T],ε), ρ_S(·|ε), Σ_a, ε_pose)`。与第 54 轮接口：`A_cert` 的取值域改为 `P̂_a` 上的商球，`δ_a` 增加位姿回拉项 `tr(Σ_a)^{1/2}`。

**定义 125（事件触发再认证 ETR）**
触发谓词
```
Trig(t) = [λ_R(t) ≥ θ_e] ∨ [¬Guard_pose(t)] ∨ [δ_t(t) > Θ_t] ∨ [Alias_evt(t) = 1]
```
再认证受**驻留时间**与滞回约束：仅当 `t - t_last ≥ τ_dwell` 时才真正再认证，否则合并触发，避免颤抖。**ETR 证书** `N_event = (t_last, τ_dwell, θ_e, ε_budget, trigger_log)`。证书稳定条件：`触发率 ≤ θ_trig` 且相邻两次再认证的结论不翻转，或翻转被驻留时间抑制。

**定义 126（时基契约与时序偏差）**
三套时基：帧式位姿 `t_f`、事件 `t_e`、动作指令 `t_c`。时序偏差
```
δ_t = max(|t_f - t_c|, |t_e - t_c|) + latency_pipeline
```
由动作对位姿的 Lipschitz 性，`Δa ≤ L_a·δ_t`。**时序有效窗** `H_t = min(H_pose, Δ_max/δ_drift)`。证书可部署要求 `δ_t ≤ Θ_t` 且位姿时间戳落在 `H_t` 内；否则判为**时间混叠**。

**定义 127（云边事件-位姿契约）**
```
C_ep = ( G_c, [T_e], Σ_e, Ĝ_act, δ_pose, δ_t, H_t, R_E, Λ_loop )
```
一致性条件
```
d_{P̂_a}([T_c], [γ_ce T_e]) ≤ δ_pose  ∧  |t_c - t_e| ≤ δ_t
```
**位姿混叠检测**
```
Alias_spatial = 1[ res_e < τ_r ∧ d_{P̂_a}([T_c],[γ_ce T_e]) > δ_pose ∧ m(H) < θ_m ]
Alias_temporal = 1[ res_e < τ_r ∧ (t - t_e) > H_t ]
Alias_evt = Alias_spatial ∨ Alias_temporal ∨ [R_E 与云端位姿图变化不一致]
```
即“局部残差小”不再等于“位姿可用”；必须同时满足商距离与时间窗。

**定义 128（时空联合证书 SEPC）**
```
SEPC = ( ρ, α_S, A_cert, γ_ce, δ_a, PAC, C_ep, N_event, δ_t, H_t, evidence )
```
部署可接受当且仅当
```
dom(T) = in
∧ min_d ρ_S(d|ε_pose) ≥ ρ_min
∧ δ_a + tr(Σ_a)^{1/2} ≤ Θ_a
∧ δ_t ≤ Θ_t
∧ ε_pose ≤ ε_budget
∧ N_event 有效（未超时、无颤抖）
∧ Ĝ_act ⊆ G_act
```
`evidence` 至少包含：对称反例集、事件残差分离日志、位姿保形校准记录、时基漂移记录与云边混叠反例。

## 2. 关键算法 伪代码

### IP-121 PQC（Pose Quotient Characterization）

```python
def action_quotient(skill, action_class, G_candidates, sampler):
    G_act = set()
    for g in G_candidates:
        invariant = all(
            action_equivariant(skill.Phi(action_class), T, g)
            for T in sampler.pose_samples(action_class)
        )
        if invariant:
            G_act.add(g)
    G_act = conservative_closure(G_act, G_candidates)   # Ĝ ⊆ G_act
    return PoseQuotient(G_act, metric=quotient_metric(G_act))

def action_equivariant(Phi_a, T, g):
    return Phi_a(T @ g) == Phi_a(T)   # 动作结果在对称下不变
```

### IP-122 ERD（Event Residual Decomposition）

```python
def event_residual(events, action, proprio, ego_model, dt=0.005):
    E_ego = ego_model.predict(action, proprio, events.times)
    R = temporal_multiset_diff(events, E_ego, tol=dt)
    lambda_R = R.count_in_window(t, dt) / dt
    eta_ego = 1 - lambda_R / max(events.count_in_window(t, dt)/dt, eps)
    return EventResidual(R, lambda_R, eta_ego)
```

### IP-123 ETO（Event-Triggered Observability）

```python
def update_pose_uncertainty(eps2, events_res, motion, kappa, drift):
    I_E = event_information_rate(events_res)
    eps2 = max(0.0, eps2 + drift(motion)*dt - 2*kappa*I_E*dt)
    return eps2

def etr_trigger(eps_pose, lambda_R, delta_t, alias, last_t, now, cfg):
    trig = (lambda_R >= cfg.theta_e or eps_pose > cfg.eps_budget
            or delta_t > cfg.Theta_t or alias)
    if trig and (now - last_t) >= cfg.tau_dwell:
        return True, now
    return False, last_t
```

### IP-124 PAC（Pose-Aware Certificate）

```python
def pose_conditioned_certificate(skill, pose_class, ball, action_set):
    J = horizontal_jacobian(skill.Phi)          # S_a
    Sigma_a = J @ ball.cov @ J.T
    alpha_min = {a: min(skill.alpha(a, T2) for T2 in ball)
                 for a in action_set}
    rho_min = {d: min(skill.rho(d, T2) for T2 in ball)
               for d in rho_dims}
    return PAC(alpha_min, rho_min, Sigma_a, ball.eps)
```

### IP-125 TTC（Temporal Contract）

```python
def temporal_contract(t_frame, t_event, t_cmd, latency, L_a, cfg):
    delta_t = max(abs(t_frame-t_cmd), abs(t_event-t_cmd)) + latency
    da_bound = L_a * delta_t
    H_t = min(cfg.H_pose, cfg.Delta_max / cfg.delta_drift)
    ok = (delta_t <= cfg.Theta_t) and (t_cmd - t_frame <= H_t)
    return TemporalCert(delta_t, da_bound, H_t, ok)
```

```python
def cloud_edge_pose_check(T_c, T_e, Sigma_e, G_act, res_e, t_c, t_e, cfg):
```

### IP-127 SEPC（Spatio-Temporal Joint Certificate）

```python
def spacetime_certificate(skill_seq, pose_states, event_log, time_cert, cfg):
    if not conservative_symmetry(pose_states.G_act_hat):
        return ('reject','symmetry_not_conservative')
    rho = compose_robustness_chain([s.rho for s in skill_seq], K)
    pac = [pose_conditioned_certificate(s, ps, ps.ball, A_T)
           for s, ps in zip(skill_seq, pose_states)]
    for d in rho:
        if min(p.rho_min[d] for p in pac) < cfg.rho_min:
            return ('reject','pose_robustness_fail', d)
    if not time_cert.ok:
        return ('reject','temporal_skew', time_cert)
    if not etr_valid(event_log, cfg):
        return ('reject','etr_invalid', event_log)
    return ('ok', SEPC(rho, [p.alpha_min for p in pac],
                       A_cert=intersection(ps.ball for ps in pose_states),
                       time_cert, event_log))
```

### IP-128 AAD（Active Ambiguity Disambiguation）

```python
def active_disambiguate(belief, action_lib, budget, dt_budget):
    best, best_gain = None, -inf
    for a in action_lib:
        ig_obs = quotient_information_gain(belief, a)     # 只算可观测方向
        cost = execution_cost(a) + dt_budget
        gain = ig_obs / max(cost, eps)
        if gain > best_gain:
            best, best_gain = a, gain
    if max_observable_ig(belief) < theta_ig:
        return ('undecidable_conservative', conservative_action(belief))
    return ('disambiguate', best)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|

| ERD | O(\|E\|+\|E_ego\|) | O(Δt) 流式 | 自运动预测残差有界 |
| ETO | O(\|E\|) 流式 | O(1) | 信息率估计无偏、漂移上界 |

| EPC | O(\|V\|+\|E\|+\|R_E\|) | O(\|V\|+\|E\|) | 商距离、时间窗、残差一致 |
| SEPC | O(\|S\|·\|A\|·\|B_ε\|) | O(\|A\|) | 各否决项 sound |
| AAD | O(\|A_lib\|·\|H\|) | O(\|H\|) | 只对可观测方向计算 IG |

**正确性定理（Event-Pose-Action Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `Ĝ_act(a) ⊆ G_act(a)` 保守，商距离因此是上界；**(A30)** 自运动事件预测残差有界 `||E_ego - E_ego^*|| ≤ β_ego`，故 `R_E` 的外部事件误分率 ≤ θ_res；**(A31)** 位姿球经分裂保形校准，覆盖率 ≥ 1-α_p，且漂移上界 `D` 成立；**(A32)** 时基同步使 `δ_t ≤ Θ_t`，且动作对位姿 Lipschitz 常数 `L_a` 已知。
则部署成功概率
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a+tr(Σ_a)^{1/2} > Θ_a)
            - P(d_{P̂_a}([T_true],H) > ε_pose) - P(δ_t > Θ_t)
            - P(ERD 误分 > θ_res) - P(ETR 超时/颤抖)
```
关键：**位姿在动作相关商上声明**（非裸 SE(3)）、**事件只增加信息且自运动被显式解释**、**时间窗是硬否决项**。

```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a+tr(Σ_a)^{1/2} > Θ_a)
```
