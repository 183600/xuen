# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感循环第 2 轮；本轮灵感：「分布外泛化」×「场景驱动创新」）

> R69 把不确定性分成 aleatoric（噪声）与 epistemic（歧义），用「流匹配多模态策略 + 主动交互」消解后者；消解失败时退回 R68 的保守 λ_floor。它最漂亮的理论姿态是「R68 是永不交互边界」。但它仍有一条没写进任何定义的前提：**标定、模态权重、流似然、VoI，乃至 R68 的保守退避，全部只在训练分布的支持集内成立。** R69 自陈的最大风险——模态权重不可信时「问错比不问更危险」——其实是更一般病症的一个特例：**系统在 OOD 场景里，仍按 in-distribution 的证书行事。**
>
> 更尖锐的是：R68 的「不确定就收紧」看似万能安全港，但**减速只有在世界模型与标定仍有效时才安全**。在 OOD 下，「慢下来」可能把系统留在一个正在失效的模型里更久——错误的障碍物类别、失效的抓取动力学、被新光照欺骗的视觉。保守不是无条件的安全，它也有适用域。
>
> 本轮两个灵感正好从两个方向补上：
> - **分布外泛化**要求显式建模「支持集之外」：不是把 OOD 当成一个异常分，而是承认它是一类**不可由测试时交互消解**的不确定性（ontological / competence uncertainty）；
> - **场景驱动创新**要求把创新锚定在具体场景上：把部署场景写成可组合的「场景语法」，维护一张**经过认证的场景卡库**，让每一个 OOD 缺口变成一张可审计的「能力票据」——要么扩展能力边界，要么正式收缩声称边界，绝不静默忽略。
>
> 核心命题：**在 R69 的 (U_ale, U_epi) 之外加入第三类 U_ont（支持集/能力边界不确定性）；用「场景语法 + 场景卡库 + 多通道 OOD 共识 + 支持条件证书」把 OOD 从黑箱异常分升级为可解释、可审计、可创新的能力边界；证书只在支持集内签发，支持集外只允许「包络内退避」或「显式移交」，并生成负证书。** 命名 **SCOPE-RAS**（Scenario-Certified Out-of-distribution Provably-conservative Envelope）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我究竟有什么资格断言？哪些地方连减速都不安全？**」——安全不只是一张「已证明安全」的地图，还包括地图边缘之外那片被明确标注为「未认证」的空白。

## 0. 直觉与动机

**灵感 1（分布外泛化 → 保守也有适用域）**
直觉：R68/R69 的 fallback 是「把不确定当成噪声，收紧 λ」。但 OOD 的可怕之处不是某个输入看起来奇怪，而是**产生证书的那套假设整体失效**：标定残差、流似然、模态权重、WM 预测都可能是「在错误的世界里自洽」。这时减速只是把错误执行得更慢。真正该做的是：先判断「我还在不在自己有资格谈论安全的区域」，不在就先退到**仍被认证的那一小块包络**，或移交。由此得到本轮第一个姿态：**保守不是铁的，保守是条件于支持集的。**

**灵感 2（分布外泛化 → 三类不确定性，第三类不能被“问”掉）**
直觉：R69 的 U_epi 是「多峰但可分，问一下/看一眼就能消解」；而 OOD 是「你连该分成哪几峰都不知道」。前者是**认识论的可约**，后者是**本体论的支持缺口**：再多一次注视、探针、问句也无法保证答案落在训练支持内，甚至交互本身（OOD 下的注视、探针、社交动作）都可能不安全。于是 U_ont 不是 U_epi 的更大值，而是**另一种处置通道**：不能靠 VoI 交互消解，只能靠「包络退避 + 负证书 + 离线能力扩展」。这把 R69 的二分升级为三分，同时保持严格包含：U_ont=0 时逐指令退化为 FLUID-RAS。

**灵感 3（场景驱动创新 → 场景不是数据点，是可组合的语法对象）**
直觉：OOD 检测若只看输入密度，会陷入两个困境：一是「解释不了为什么 OOD」，二是「不知道怎么补」。场景驱动创新给了一条更好的路：把部署世界写成**场景语法**——智能体类型 × 地形 × 光照/天气 × 任务 × 社交结构 × 传感器健康——再用组合算子生成场景。于是 OOD 被拆成两种可操作的东西：**语法内但未被场景卡库覆盖的组合**（coverage gap），以及**越出能力包络的参数区**（envelope breach）。前者提示「补场景卡」，后者提示「缩能力声称」。OOD 从一个标量异常分，变成一张**有坐标、有原因、有下一步**的缺口地图。

**灵感 4（场景驱动创新 → 创新是“扩展或收缩”的双向证书操作）**
直觉：多数研究把 innovation 理解为「加模块、涨指标」。但在安全关键系统里，最诚实的创新有两种：**扩展**（在场景卡上通过再认证扩大包络）与**收缩**（承认当前能力不覆盖该场景，正式缩小声称边界）。二者都比「静默忽略」更安全。于是引入**创新账本**：每个部署中发现的 OOD 缺口都必须得到处置（扩展/收缩/拆分/带到期日的缓议），并留下证据哈希。这把「场景驱动创新」从口号变成**可审计的过程不变量**——安全论证不是一张静态地图，而是一条只允许「显式扩展」或「显式收缩」的演化轨迹。

**灵感 5（场景驱动创新 × 分布外泛化 → 覆盖的是交互结构，不是数据量）**
直觉：随机堆数据对 OOD 的边际收益递减；真正决定泛化的是场景**交互结构**是否被覆盖。若场景效应在至多 t 个原语上有界交互（A100），那么 t-wise 覆盖的场景卡库就能给出部署风险的上界。场景驱动创新因此有了可度量的目标：不是「再多 10 万条数据」，而是「把尚未覆盖的 t-wise 组合补齐」或「把不能补齐的组合显式列为负证书」。这把场景覆盖与 OOD 泛化用一个可证明的桥连起来，也让「创新能力」可以用「单位风险下覆盖缺口减少量」来排序。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（SCOPE-RAS 总览与四不变式）** SCOPE-RAS = (SGR, SBI, ODC, CBC, ERT, SCIF, ILT, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **证书只在支持集内签发**：J_SCOPE 的有效性以 U_ont ≤ τ_ont 且场景卡在支持集内为前提；
(iii) **OOD 只允许保守方向出错**：检测不确定 ⇒ 判为支持集外（宁可假 OOD，不可假证书）；
(iv) **缺口不可静默吸收**：每个支持集外事件必须产生负证书或一张创新票据，二者都进只追加账本。

**定义 311（场景语法 SGR）** 场景描述符 s = Compose(p_1,…,p_m)，由原语 p ∈ P（智能体类型、地形、光照/天气、任务阶段、社交结构、传感器健康）经算子 ∘ ∈ {并行、顺序、扰动、组合} 生成；语法 G 决定合法组合。场景卡 c = (s_c, derivation_c, E_c, I_c, J_c, provenance_c, failure_modes_c)，其中 E_c ⊂ 𝒳 为能力包络，I_c 为不变式集，J_c 为离线认证证书。

**定义 312（场景卡库与能力前沿）** 场景卡库 ℬ = {c_i}_{i=1}^N，带版本号。能力前沿 F(ℬ) = ∪_i (E_i × {s_i})，即「被认证覆盖的场景 × 参数区」。覆盖度 Cov_t(ℬ) 为场景语法上 t-wise 组合的覆盖比例。ℬ 只允许离线追加/替换，运行时只读。

**定义 313（场景后验与支持质量）** 设场景卡后验 β_i(o) = p(c_i | o)，支持内质量 m_in(o) = Σ_i β_i(o)；支持外质量 b(o) = 1 − m_in(o)。Signed envelope margin：d(o, ∂E) = min_i d(o, ∂E_i)；d < 0 表示越出被认证包络。定义 **U_ont = b(o) + γ·max(0, −d(o, ∂E))**（支持缺口 + 包络越界）。

**定义 314（多通道 OOD 共识 ODC）** 四个正交通道：① 场景语法覆盖（descriptor novelty / t-wise 覆盖）；② 表征密度（R69 trunk z 的 Mahalanobis/energy）；③ 行为非一致性（复用 R69 FMA 的流似然/WM 残差）；④ 标定有效性（R68 COF 残差的二样本检验）。判 **支持集内** 需四通道一致；任一通道报外 ⇒ **支持集可疑**；两通道以上报外 ⇒ **支持集外**。支持集可疑按支持集外处理（定义 310-iii）。

**定义 315（共形/ACI 校准门）** 对每个场景卡用加权共形预测校准非一致性阈值，给出有限样本覆盖 P(c ∈ C_α(o)) ≥ 1−α（卡内可交换假设）；在线用 ACI 更新 α_{t+1} = α_t + γ(α − err_t)，在无交换性漂移下保持长期误覆盖率 ≤ α + o(1)。C_α 为空或尺寸异常 ⇒ ODC 判外。

**定义 316（三分不确定性）** U_ale（模态内噪声）、U_epi（支持内可约歧义，R69 定义 297）、U_ont（支持集/能力边界缺口，定义 313）。三分不做标量加和；处置通道分别为：U_ale → λ floor；U_epi → MINT 交互；U_ont → 禁止 VoI 交互、进入 CBC/ERT（因为支持集外连模态校准都不可信）。

**定义 317（支持条件证书 CBC）** 正证书 J_SCOPE = (J_FLUID, card_id, bank_ver, U_ont, in_bank_conf, conformal_size, aci_alpha, retreat_mode, neg_cert_id, ledger_hash, scope_ver)。Valid ⇔ Valid(J_FLUID) ∧ bank_ver 为当前版本 ∧ U_ont ≤ τ_ont ∧ in_bank_conf ≥ τ_bank。**负证书** N(o) = (reason_code ∈ {coverage_gap, envelope_breach, detector_disagreement, stale_card, aci_violation}, evidence_hash, expiry, next_action)：合法地声明「此处不签发正证书」。

**定义 318（包络退避 ERT）** 支持集外时，策略改为在「后验可信的场景卡包络之交/鲁棒集」内求解：
a* = argmax_a V(a) s.t. max_{i: β_i ≥ τ_β} Risk(a; E_i) ≤ ε_retreat。
若可行集为空 ⇒ 最小风险认证动作（制动/停靠）或**显式移交**人类；移交本身须进负证书与账本。不得在包络外执行任何由 in-distribution 证书背书的动作。

**定义 319（场景驱动创新环 SCIF）** 缺口挖掘：从部署日志、近边界回放与场景语法重组生成候选缺口 g。能力票据 ticket(g) = (s_g, failure_mode, change_type ∈ {expand, shrink, split, defer}, evidence)。**能力 VoI**：CVoI(g) = ΔCov_g · Sev_g / (Cost_g + Risk_g)，其中 ΔCov_g 为预期覆盖缺口减少量，Sev_g 为未处置后果。预算下用子模贪心选票；`shrink/split` 证据充分时可直接采纳（只会让声称更诚实）。`defer` 必须带到期日与监控条件，不得无限期沉默。

**定义 320（创新账本 ILT）** 只追加账本 L，记录每次 OOD 事件的处置：expanded / shrunk / split / deferred(expiry) / handed_over，附证据哈希与卡库版本。不变式：**不存在无处置的 OOD 事件**；账本哈希进 J_SCOPE，可被外部审计重放。

**定义 321（OOD 威胁模型 ℰ_shift）** ℰ_shift = {诱骗性分布漂移（看起来 in-bank 的 OOD）、OOD 幻觉（假外→可用性 DoS/保守瘫痪）、包络蠕变（用边界样本逐步扩大声称）、场景卡投毒（伪造覆盖/证书）、语法过期（世界出现新原语）、证书重放（旧版本证书）}。并入 AIC-SCOPE = ℰ_CALM × ℰ_poison × ℰ_flow × ℰ_shift。

**定义 322（证书与审计 VQAuditor-S）** VQAuditor-S 审计：负证书是否完整、票据处置是否到期、覆盖声明是否被场景卡投毒污染、包络蠕变速率是否越界、旧证书是否被重放。结论回灌 SCIF 的成本先验与 ℬ 的准入规则。

**定义 323（时序耦合与两层时间尺度）** 快回路（< 3ms）：场景后验 + ODC + CBC/ERT，只读 ℬ；慢回路（小时/天，离线）：SCIF 票据、场景卡再认证、ℬ 版本升级。**运行时绝不更新 ℬ**；慢回路产物必须重新通过 J_SCOPE 才能进入快回路。这把 R68 的「零实时学习写」扩展到「零实时能力声称写」。

# IP-266 SBI：场景后验 + 支持外质量
def infer_support(bank, o, z):
    beta  = softmax([-dist(z, card.centroid(c)) for c in bank])   # 或小型判别器
    b     = 1.0 - beta.sum()                                      # out-of-bank mass
    d     = min(card.margin(o) for card in bank)                  # signed envelope margin
    U_ont = b + GAMMA * max(0.0, -d)
    return beta, b, d, U_ont

# IP-267/268 ODC：四通道共识 + 共形/ACI 门
def ood_consensus(o, z, flow_ll, cal_res, bank, acis):
    votes = {
        'grammar':  sgr.coverage_vote(o, bank),
        'density':  mahalanobis_vote(z),
        'behavior': flow_residual_vote(flow_ll),      # 复用 R69 FMA
        'calib':    two_sample_vote(cal_res),         # 复用 R68 COF 残差
    }
    if any(v.out for v in votes.values()):
        return 'suspect'                              # 疑外即外（定义 310-iii）
    if sum(v.out for v in votes.values()) >= 2:
        return 'out'
    for card in bank:                                 # 卡条件共形 + 在线 ACI
        if not acis[card].covers(o):
            return 'out'
    return 'in'

# IP-269/270 CBC + ERT：支持条件证书与包络退避
def support_step(M, o, z, k_f, lam_f, mode_f):
    beta, b, d, U_ont = M.sbi.infer_support(M.bank, o, z)
    status = M.odc.consensus(o, z, M.fma.score, M.cof.residual, M.bank, M.acis)
    if (status == 'in') and (U_ont <= TAU_ONT):
        J = J_SCOPE(M.fluid.last_J, card_id=int(argmax(beta)),
                    bank_ver=M.bank.ver, U_ont=U_ont, scope_ver=SCOPE_VER)
        return k_f, lam_f, mode_f, J, None            # 严格退化为 FLUID
    # 支持集外：禁止 R69 的 VoI 交互，模态校准在此不可信
    a_safe = M.ert.robust_argmax(beta, M.bank, eps=EPS_RETREAT)
    if a_safe is None:
        N = NegativeCert(reason=status, evidence_hash=hash(o), next_action='handover')
        return 'handover', None, None, None, N
    N = NegativeCert(reason=status, evidence_hash=hash(o), next_action='retreat')
    return a_safe.k, a_safe.lam, a_safe.mode, None, N

# IP-272/273 SCIF + ILT：离线场景驱动创新（只追加，不回写运行时）
def scenario_ticket_loop(bank, deployment_gaps, budget):
    tickets = [make_ticket(g) for g in mine_near_boundary(deployment_gaps)]
    for t in tickets:
        t.cvoi = delta_coverage(t) * severity(t) / (cost(t) + risk(t))
    chosen = submodular_greedy(tickets, budget, key='cvoi')
    for t in chosen:
        if t.change_type in ('shrink', 'split') and strong_evidence(t):

            else: ledger.append(defer(t, expiry=t.deadline))   # 不得无限期沉默
    return bank

## 3. 推导

先固定本轮假设：
**A99（语法表达力）** 部署分布 μ 可由场景语法 G 生成；语法扩展事件可被日志检出（否则见最大风险）。
**A100（有界 t-wise 交互）** 场景风险 f(s)=Risk(π,s) 可分解为阶数 ≤ t 的项加残差：f = Σ_{|I|≤t} f_I + r_t，且 |r_t| ≤ ε_t。
**A101（证书可靠）** 场景卡离线认证 J_c 对其包络 E_c 内成立（由既有验证管线保证）。
**A102（检测保守性）** 在标定集上，真外判内的概率 ≤ ε_fc；且卡内共形满足覆盖下界。
**A103（退避可用）** 支持集外要么存在满足 ε_retreat 的认证动作，要么移交通道可用。

**引理 19（U_ont 不能被测试时交互消解）** 设 b(o) ≥ β_0 使场景后验落在支持外，且 R69 的模态后验 p_in(M|o) 只在支持内被校准。若支持外真实模态后验 p_out 与 p_in 的全变差 ≥ δ_b，则用 p_in 算出的 VoI 与真实 VoI 之差至少为 δ_b 量级；因此在 A102 与 δ_b > 阈值下，存在漂移使 **估计 VoI > 0 而真实 VoI ≤ 0**，即 R69 的交互在该状态下会主动放大错误。系：**U_ont 的处置通道必须是“禁止交互/退避”，不能是把 U_epi 的 VoI 继续算下去。**

**引理 20（非对称 OOD 过近似）** 在 A101–A102 下，若正证书只在 ODC 判内且 U_ont ≤ τ_ont 时签发，则假证书概率 ≤ ε_fc；把内判外的假 OOD 只降低可用性，不破坏安全侧。故「疑外即外」是一个**只允许保守方向出错**的构造，其代价可用 E310 的保守瘫痪时长来度量。

**引理 21（t-wise 覆盖 → OOD 风险上界）** 在 A100 下，若场景卡库 ℬ 对语法 G 的 t-wise 组合全覆盖，则对任意 s~G，
E[Risk(π,s)] ≤ max_{c∈ℬ} sup_{x∈E_c} Risk(π,c,x) + ε_t。
要点：控制 OOD 的不是样本量，而是**场景交互结构的覆盖**；这为场景驱动创新提供了可证明的优化目标（补 t-wise 缺口或显式缩边界），也解释了为什么“多采数据”未必降低 OOD 风险。

**定理 18（SCOPE 对 FLUID/R68 的条件严格包含）** 在 A99–A103 下：
(i) 支持集内且 ODC 判内 ⇒ SCOPE 与 FLUID 逐指令相同（U_ont 只做门控，不改支持内计算），因而在 R69 的退化边界上同时等于 R68；
(ii) 支持集外 ⇒ SCOPE 不签发正证书，只执行 ERT 的认证退避或显式移交；
(iii) 因此 SCOPE 的**可认证安全区域 ⊆ R68 的可认证安全区域**，缺口被显式化为负证书。安全侧不做无根据的扩展，可用性侧的代价被显式计量。

**定理 19（创新账本的单调性与可审计性）** 每个票据只可能是：expand（必须再认证，只增加已认证区域）、shrink/split（删除声称）、defer（带到期日与监控）、handed_over。故声称区域 C_t 的每次变化都可追溯到票据与证据；不存在“静默增加未认证区域”的转移。若 CVoI 关于票据集合单调子模，则预算下贪心选票达到 (1−1/e) 的最优缺口减少近似。

**定理 20（无静默 OOD）** 运行时每个 U_ont > τ_ont 的事件，由定义 320 的不变式必然产生负证书或票据处置；因此“被承认的 OOD 事件集合”是“被检出事件集合”的超集。注意其边界：**未检出的 OOD 仍可能发生**——这由 A102 的 ε_fc 与语法表达力 A99 共同限制，正是本轮最大风险的来源。

## 6. 本轮最大风险

**一句话**：SCOPE-RAS 的安全性押在「场景语法 + 四通道共识能对 OOD 做保守过近似」上，但最危险的 OOD 往往是**语法表达不出来、且四通道都看起来 in-distribution 的未知未知**——此时负证书会漏报，系统仍会拿着一叠看似完整的支持集证书安全地驶出地图；**你能标注“知道自己不知道”的空白，却无法用同一张地图标注“不知道自己不知道”的空白。**

**次级风险与缓解**：
1. **假 OOD 导致保守瘫痪/可用性 DoS** → 定义 310-iii 的非对称只保安全侧，需 E310 限制瘫痪时长 + ACI 自适应恢复；
2. **场景卡投毒/覆盖声明造假** → 卡库只追加 + 来源证明 + VQAuditor-S 审计（定义 322）；
3. **包络蠕变（用边界样本逐步扩大声称）** → 扩展必须再认证 + 蠕变速率阈值 + 账本审计（定理 19）；
4. **语法过期（世界出现新原语）** → 日志触发的语法扩展检测 + 新原语一律先判外；
5. **共形/ACI 的假设被破坏**（卡内不可交换）→ 卡条件校准 + 疑外即外 + 失败即负证书，绝不静默放行。

# IP-266 SBI：场景后验与 U_ont
def infer_support(bank, o, z):
    beta  = softmax([-dist(z, card.centroid(c)) for c in bank])
    b     = 1.0 - beta.sum()
    d     = min(card.margin(o) for card in bank)
    return beta, b, d, b + GAMMA * max(0.0, -d)

# IP-267/268 ODC：四通道共识 + 共形/ACI
def ood_consensus(o, z, flow_ll, cal_res, bank, acis):
    votes = {'grammar': sgr.coverage_vote(o, bank),
             'density': mahalanobis_vote(z),
             'behavior': flow_residual_vote(flow_ll),   # 复用 R69 FMA

    if any(v.out for v in votes.values()): return 'suspect'   # 疑外即外

def support_step(M, o, z, k_f, lam_f, mode_f):

def scenario_ticket_loop(bank, gaps, budget):

    for t in tickets:

## 4. 推导

假设：A99 语法可表达部署分布；A100 场景风险 t-wise 可分解且残差 ≤ ε_t；A101 场景卡离线证书在包络内可靠；A102 真外判内率 ≤ ε_fc；A103 退避动作或移交通道可用。

**引理 19（U_ont 不能被测试时交互消解）** 支持外时 R69 的模态后验 `p_in` 不再被校准；若真实后验与 `p_in` 的全变差 ≥ δ_b，则估计 VoI 与真实 VoI 相差 δ_b 量级，存在漂移使「估计 VoI>0 而真实 VoI≤0」。故 U_ont 只能走退避/负证书，不能继续算 VoI。

**引理 20（非对称 OOD 过近似）** A101–A102 下，正证书只在 ODC 判内且 `U_ont≤τ_ont` 时签发 ⇒ 假证书率 ≤ ε_fc；假 OOD 只损失可用性。故「疑外即外」只允许保守方向出错，其代价用 E310 度量。

**引理 21（t-wise 覆盖 → OOD 风险上界）** A100 下，若 `ℬ` 对语法 G 的 t-wise 组合全覆盖，则 `E[Risk(π,s)] ≤ max_{c∈ℬ} sup_{x∈E_c} Risk(π,c,x) + ε_t`。控制 OOD 的是交互结构覆盖而非样本量；这给场景驱动创新一个可证明的目标。

**定理 18（对 FLUID/R68 的条件严格包含）** (i) 支持集内且判内 ⇒ 与 FLUID 逐指令相同，故在 R69 退化边界上同时等于 R68；(ii) 支持集外 ⇒ 永不签发正证书，只做 ERT 认证退避或移交；(iii) 因此 `SCOPE 可认证安全区域 ⊆ R68 可认证安全区域`，缺口被显式化为负证书。

**定理 19（创新账本单调可审）** 票据只可能 expand（再认证后只增已认证区）、shrink/split（删除声称）、defer（到期+监控）、handed_over；不存在静默增加未认证区域的转移。若 CVoI 单调子模，预算下贪心达到 (1−1/e) 的缺口减少近似。

**定理 20（无静默 OOD）** 每个 `U_ont>τ_ont` 事件由账本不变式必然产生负证书或票据处置，故「被承认的 OOD ⊇ 被检出的 OOD」。边界：未检出的 OOD 仍可能发生，由 ε_fc 与语法表达力 A99 共同限制——这正是最大风险。

## 6. 实验设计 E301–E315 与预期结果 / Kill Criteria

| 实验 | 核心问题 | 预期结果与判据 | Kill Criterion |
|---|---|---|---|
| E301 场景语法与卡库 | 语法能否表达部署场景 | 推导合法率 ≥ 99%；训练分布覆盖 ≥ 95% | 合法率 < 95% 或覆盖 < 85% ⇒ 语法不成立 |
| E302 组合式 OOD 检测 | 四通道共识是否有效 | composition-shift AUROC ≥ 0.92；AUPR-out ≥ 0.80 | AUROC < 0.80 ⇒ 退化为单通道并缩声称 |
| E303 共形/ACI 校准 | 漂移下覆盖是否守住 | 卡条件覆盖 ≥ 1−α−0.03；ACI 长期误覆盖 ≤ α+0.02 | 覆盖跌破 1−α−0.08 ⇒ 禁用正证书 |
| E304 假证书率 | 最危险错误是否结构性消除 | 外部分布基准上 **假证书 = 0** | 任一假证书 ⇒ 本轮方案失败 |
| E305 包络退避 vs R68 fallback | OOD 下「减速」是否仍安全 | 违规/碰撞率相对 R68 −60%；停机/移交成功 ≥ 98% | 无改善 ⇒ U_ont 仅增加复杂度 |

## 7. 本轮最大风险

**一句话**：SCOPE-RAS 的安全性押在「场景语法 + 四通道共识能对 OOD 做保守过近似」上，但最危险的 OOD 往往是**语法表达不出来、且四通道都看起来 in-distribution 的未知未知**——此时负证书会漏报，系统仍会拿着一叠看似完整的支持集证书安全地驶出地图；**你能标注“知道自己不知道”的空白，却无法用同一张地图标注“不知道自己不知道”的空白。**

**次级风险与缓解**：假 OOD 导致保守瘫痪（非对称门控 + ACI 恢复 + E310 时限）；场景卡投毒/覆盖造假（只追加 + 来源证明 + VQAuditor-S）；包络蠕变（扩展必须再认证 + 蠕变速率阈值 + 账本审计）；语法过期（日志触发扩展检测，新原语一律先判外）；共形/ACI 假设破坏（卡条件校准 + 疑外即外 + 失败即负证书）。
