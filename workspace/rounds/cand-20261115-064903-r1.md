# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「对话管理」×「多视角视觉」）

> R69 把不确定性一分为二：aleatoric 收紧、epistemic 主动交互消解。它交出了一个会「看、问、触」的系统，但交互仍然是**单发、短视、单视角、且信任一个固定的人类似然**：问一句 → 得一个答案 → 贝叶斯更新一次。R69 自陈的最大风险正是这个模型的软肋——**若流模型的模态分布未校准，VoI 就在错误信念上计算，系统会自信地追问一个幻影、或把一句误导性回答盖上「已验证」的章；问错比不问更危险。**
>
> 本轮两个灵感恰好补上两块缺失：
> - **对话管理**：真实求证不是「问一句」，而是一个**有状态、多轮、可能对方不配合、且回答之间相关**的对话过程。要维护的不只是「世界是什么」，还有「对方知道什么、是否愿意说、前后是否自洽」。R69 的 VoI 是 horizon-1 的贪心；对话管理是**有限时域、信念空间上的对话策略**。
> - **多视角视觉**：R69 的「注视」只是一个传感器动作；多视角给出的是**模型无关的几何证词**——多个标定视角若不能同时容纳某个被假设的 3D 结构（极线/重投影残差超噪），该结构（以及流模型据此幻觉出的模态）就被几何否决。这条通道不依赖学习，也骗不过标定良好的多相机几何。
>
> 核心命题：**把 R69 的「单轮贪心交互」升级为「对话状态 POMDP + 多视几何证词」；对话负责低成本的语义消歧，几何负责高成本但难伪造的结构否决；两者按成本-保真度互补分配预算。R69 严格退化为「T=1、单视角、固定人类似然」的边界。** 命名 **DIALECTIC-RAS**（Dialogue-Integrated Active multi-view Long-horizon Epistemic Consensus, Trust-Invariant Checks）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「**该怎么谈、谈多久、以及哪些话根本不可信**」——求证不是一次采信，而是一场要防对方撒谎、也防自己幻听的审讯式对齐。

## 0. 直觉与动机

**灵感 1（对话管理 → 求证是有状态的，不是一次采样）**
直觉：R69 的 `choose_interaction` 对每个候选信息动作算一步 `VoI−c`，选了就执行、更新一次后验，然后结束。但人求证时不是这样：先问 A，听答案里有没有回避；据此决定问 B，还是换个说法再确认 A；如果前后矛盾，就降低对这个人「配合度」的估计，转而去看而不是继续问。这里有三个 R69 没有的量：**对方的知识状态**（知不知道）、**配合度/诚实度**（愿不愿说真话）、**历史承诺集**（前后说过什么）。它们会在轮次间演化，且答案在给定真实模态后仍**强相关**（同一个人会坚持同一个说法）。R69 把 y 当作 i.i.d. 的固定似然观测，于是「被同一个人连续骗两次」被当成两条独立证据——这正是引理 18 的 k-源上界在真实对话里失效的原因。

**灵感 2（多视角视觉 → 一条模型无关、但只认结构的证词）**
直觉：R69 用流似然检测「行为自洽」，但它和标定层仍可能被同一偏移一起骗过。多视角是另一种性质的东西：给定标定 (K_i,R_i,t_i)，任何被假设的 3D 点 X 必须在每个视角的像平面落回像素 π(K_i(R_iX+t_i))；两个视角还须满足极线约束 x_2ᵀF x_1≈0。这个残差**不需要训练、不需要信任策略**。若流模型幻觉出一个模态，它隐含的「世界结构」在多视几何下要么不可三角化、要么重投影炸开——于是可以被**否决（veto）**，而不只是「再加一个似然投票」。这是对 R69 最大风险的直接回应。

**灵感 3（互补性 → 对话便宜但可被欺骗，几何昂贵但难伪造）**
直觉：这两条通道不是同类证据的叠加，而是**成本-保真度轴上的两端**。对话单轮极便宜，但对一个*始终自洽*的骗子几乎零收益——你说什么他都顺着编，多问几轮只会得到一套连贯的谎话；多视角很贵（要动、要时间、要安全认证），但一个只靠嘴的骗子改不了几何。所以正确的做法不是「两个都用」，而是**按威胁模型分配**：面对一个*不自洽*的对手（绝大多数真人，因为编谎话的认知负担高），对话最划算；面对一个*自洽但没能力*的对手，几何做终裁；两者结合时，拒绝的成本远高于任一单独通道。这把 R69 的证据纪律从「同时刻 k 源一致」升级为「跨轮 × 跨视角的独立证词一致」。

**灵感 4（VoI 的时域化 → R69 是 horizon-1 的退化）**
直觉：R69 的 `argmax_g [VoI(g)−c]` 是一个**近视（myopic）**决策：它不考虑「问了 A 之后 B 还值不值得问」「先看再问能不能少问一句」。对话管理天然是有限时域 POMDP：状态 = 对话状态，动作 = 问/看/等，观测 = 回答/新视角，回报 = 信息增益 − 成本。R69 恰是「时域 T=1、单视角、人类模型固定」的特例。于是理论姿态延续前几轮：**新层必须是旧层的严格泛化**——否则每层都多一个要独立信任的黑箱。

**灵感 5（新攻击面 → 对话层可被诱导、可被投毒、可疲劳）**
直觉：一个会多轮对话的系统，攻击面从「答错一句」升级为「被牵着走」：诱导性提问把答案污染成自己想要的、人设漂移让同一问题前后口径不同、会话历史被注入伪造轮次、多视角共谋（把一个几何自洽的假目标摆在所有相机前）来骗过几何终裁。此外还有非恶意但致命的**对话疲劳**：反复追问同一件事会让配合度骤降，T 越大不一定越好。所以必须同时交付：反诱导过滤、跨轮矛盾检测、对话状态哈希链、对话预算与疲劳模型、以及「几何零检验」——用来区分「几何否决了一个幻影」与「外参漂移把真结构否了」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DIALECTIC-RAS 总览）** DIALECTIC-RAS = (DSM, HRM, DPP, MGV, NBV, XTED, GNT, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **对话预算硬约束**：轮数 ≤ T_max、同一断言重复征询 ≤ 1 次（矛盾复询不计）、社交成本累加受 F_max 约束，且每个信息动作仍通过与任务动作相同的 C-RAS-WM 认证；
(iii) **跨轮证据纪律**：单一轮次/单一视角/单一模态证词不得定案，需独立证词图 D 上 ≥k 一致且矛盾数为 0；
(iv) **几何终裁与零检验**：任何「幻影否决」必须先通过与已知 fiducial/静态背景的零检验，否则不得以几何为由否决真模态。

**定义 311（对话状态）** s_d = (b_h, C, h, F)。b_h 为人类模型后验（知识态 K × 合作度 ρ × 能力 κ）；C = {(c_i, 来源, 轮次, 哈希)} 为承诺集；h 为轮次/历史；F 为疲劳度。

**定义 312（人类响应模型 HRM）** p(y_t | s_d, g_ask) 依赖 (K, ρ, κ)，且**跨轮相关**：同一 (K,ρ) 下回答服从一个持续性的 latent 立场 z，p(y_{1:T}) ≠ Π_t p(y_t)。ρ ∈ {cooperative, evasive, adversarial}。这是「同一人反复骗」不被当成独立证据的形式化。

**定义 313（多视角观测组）** 视角集 𝒱 = {(K_i, R_i, t_i, view_i)}，标定参数取 R68 COF 窗口内的当前估计。多视观测 y^V_t = {I_i}。

**定义 314（几何支持度与残差）** 对某假设结构 X（由某模态隐含），三角化得 X̂；重投影残差 e_geo(X) = Σ_i‖x_i − π(K_i(R_iX̂+t_i))‖²，极线残差 e_epi = Σ_{i<j}(x_jᵀF_{ij}x_i)²。几何支持度 S_geo(X) = exp(−e_geo/τ_geo)，并要求 e_epi ≤ τ_epi。**语义不在此列——只认结构。**

**定义 315（幻影否决）** 模态 m_k 隐含结构 X_k。若 S_geo(X_k) < τ_veto **且残差是局部的**（仅该模态邻域升高，全局背景残差正常），则 veto(m_k)=1，权重按 bayes_reject 下调。若全局残差同时升高 ⇒ 转定义 323 零检验。

**定义 316（对话 POMDP 与有限时域 VoI）** 策略 π_d: s_d → (g_ask, g_view, stop)。有限时域 T ≤ T_max 的期望信息收益：
VoI(π_d) = E_{τ~π_d}[ H(M|o) − H(M | o, y_{1:τ}, y^V_{1:τ}) ] − Σ_t c(g_t) − Σ_t F(h_t)。
DPP 用深度 ≤ T_max 的信念树 lookahead（宽度受候选动作 ≤ 5 限制）+ 叶节点 rollout 评估。**R69 的贪心 = T=1、单视角、ρ 固定。**

**定义 317（停止规则与混合主动）** 停止当且仅当：下一轮边际 VoI−c ≤ 0，或证据纪律满足（定义 318），或预算/疲劳触顶，或检出矛盾需转几何终裁。混合主动：人类主动提供的信息进入 C，但标记 provenance=volunteered，权重折扣，且不得单独定案。

**定义 318（跨轮证据纪律与独立性图）** 证词集合 T = {t_i}；独立性图 D 以 (来源, 轮次, 视角, 模态) 为节点，共享 latent 立场/同一视角/同一措辞族的证词连边，边权为估计相关 ρ_ij。要求存在加权独立度 ≥ k 的一致子集支持同一断言，且矛盾数 = 0。错误采纳上界随有效独立度指数下降（引理 21 修订 R69 引理 18）。

**定义 319（正交征询）** 对同一潜在量用**语义正交**的两种问法复询（paraphrase g_ask^⊥），要求答案在潜空间一致而表层不同。一致说谎者对同一种问法容易自洽，但要在两种正交框架下同时保持几何/逻辑自洽，认知成本显著上升。正交度定义为两问法条件分布的互信息与词面重叠的联合下界。

**定义 320（反诱导过滤器）** 问句 g_ask 经 leading-question 检测：若含对期望答案的预设、评价性措辞或二选一强迫，则重写或拒绝；评分由冻结 LLM + 规则 + 人类研究（E307）校准。诱导性 > τ_lead ⇒ 该轮答案降权或重问。

**定义 321（对话预算与疲劳）** 单位任务对话轮数 ≤ T_max；同一断言重复征询 ≤ 1（矛盾复询不计）；疲劳 F(h) 随重复/打断/强问句**超线性**增长，F > F_max 强制停止并降级为自主保守。社交成本并入 c(g)。

**定义 322（主动视角选择 NBV）** 选择视角子集 V' ⊆ 𝒱 最大化三角化的 Fisher 信息 D-optimality（或模态与 V' 观测的互信息），s.t. 移动/时间/遮挡成本与 C-RAS-WM 认证。NBV 是 R69「注视」在多视角下的严格推广。

**定义 323（几何零检验 GNT）** 用静态背景/已知 fiducial 的残差 e_null 作为「当前标定是否可信」的探针。判据：e_null 正常而某模态局部 e_geo 高 ⇒ 幻影（可 veto）；e_null 也升高 ⇒ 疑似外参漂移（COF 失效或漂移超出窗口），**不得 veto**，转 R68 最保守并告警。这是把 R68 的「标定不可吸收」问题镜像到几何通道。

**定义 324（对话状态完整性与防投毒）** 每轮 (g_ask, y, provenance, ts) 进哈希链；跨会话恢复须验链；未验签/断链的轮次隔离为 untrusted，不参与证据纪律。检测对象：注入轮次、人设漂移、来源伪造。

**定义 325（证书 J_DIALECTIC）** J_DIALECTIC = (J_FLUID, dialogue_state_hash, turns_used, contradiction_count, geo_residual_p95, e_null_ok, phantom_veto_count, effective_independence, fatigue_max, dialectic_ver)。Valid ⇔ Valid(J_FLUID) ∧ 证据纪律满足 ∧ 对话预算未越界 ∧ 状态链完整 ∧ 零检验通过（若发生过 veto）。

**定义 326（两级包含与退避）** 当 T_max=1、|𝒱|=1、ρ 固定、且关闭 veto 时，DIALECTIC 逐指令退化为 FLUID-RAS。任一安全门（诱导性、疲劳、零检验失败、状态断链）触发 ⇒ 关闭对话/几何增强，单调退化为 R69→R68 保守链，λ 单调不降。

# IP-264 DSM：对话状态 + 哈希链（防投毒）
class DialogueStateManager:
    def __init__(self):
        self.s = DialogueState(b_h=prior(), C=set(), h=0, F=0.0, chain=[])
    def observe(self, g_ask, y, provenance, verify):
        if not verify: provenance = 'untrusted'
        self.s.chain.append(hash_chain(self.s.chain, g_ask, y, provenance))
        self.s.h += 1
        if provenance != 'untrusted':
            self.s.C.add((y, provenance, self.s.h))

# IP-265 HRM：跨轮相关、可非合作的人类响应模型
class HumanResponseModel:
    def sample(self, s_d, g_ask, n):                 # 同一 (K,rho) 下 latent 立场 z 持续
        z = sample_persistent(s_d.b_h, n)
        return [response(s_d.b_h, z, g_ask) for _ in range(n)]

# IP-266 DPP：有限时域信念树；T=1 即 R69 贪心
class DialoguePOMDPPlanner:
    def plan(self, s_d, o, modes, budget):
        if T_max == 1:
            return greedy_voi(modes, o, budget)       # 严格退化为 R69
        return belief_tree_search(s_d, o, modes, depth=T_max,
                                  branch=candidates(modes), leaf=voi_rollout)

# IP-267 MGV：多视几何证词（模型无关）
class MultiViewGeometricVerifier:
    def residual(self, X, views):
        Xh = triangulate(X, views)
        return sum(reproj_err(x_i, project(Xh, v)) for x_i, v in zip(X, views))
    def veto(self, modes, views, null_probe):         # 与 GNT 联动
        if not null_probe['ok']: return {}            # 标定可疑 → 不得 veto
        return {k for k in modes if self.residual(modes[k].X, views) > TAU_GEO}

# IP-268 NBV：主动选视角（三角化 Fisher/D-optimal）
class NextBestView:
    def choose(self, X_hyp, views, move_cost):
        return argmax(V for V in subsets(views)
                      if c_ras_wm.certify_view(V) and move_cost(V) <= B_MOVE)(
                   fisher_D_optimal(X_hyp, V) - move_cost(V))

# IP-269/270 XTED：独立性图 + 矛盾 + k-一致裁决
class CrossTurnEvidence:
    def decide(self, testimonies):
        D = independence_graph(testimonies)           # 共享立场/视角/措辞连边
        agree = [c for c in max_weight_independent(D) if no_contradiction(c)]
        return 'verified' if max_independence(agree) >= K_EVID else 'undecided'
    def contradiction(self, C):
        return find_inconsistent(C)                   # 逻辑 + 几何一致性

# IP-269 GNT：几何零检验（区分幻影与外参漂移）
class GeoNullTest:
    def probe(self, views, fiducials):
        e = mean_residual_on(fiducials, views)
        return {'ok': e <= TAU_NULL, 'e': e}

# IP-275 主闭环（继承 R69，在交互处置处替换为对话 + 多视终裁）
def DIALECTIC_RAS_round(M, obs, views):
    z, o = M.mtm.forward(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi, modes = M.aud.decompose(modes, z)
    # 1) 先几何否决假模态；零检验保护真模态
    null  = M.gnt.probe(views, M.fiducials)
    veto  = M.mgv.veto(modes, views, null)
    modes = downweight(modes, veto); U_epi = recompute_epi(modes)
    # 2) 有限时域对话规划；T_max=1 时退化为 R69
    plan = M.dpp.plan(M.dsm.s, o, modes, M.budget)
    for g in plan.actions:
        if not M.budget.allow(g) or not M.c_ras_wm.certify_info(g, o): break
        if g.is_view:
            views += M.nbv.execute(g)                 # 主动多视角
        else:
            if M.lead.score(g) > TAU_LEAD: continue   # IP-271 反诱导
            y = M.hrm.sample(M.dsm.s, g, n=1)[0]
            M.dsm.observe(g, y, provenance='answered', verify=True)
            if M.xted.contradiction(M.dsm.s.C): break # 矛盾 → 几何终裁
        if M.xted.decide(M.dsm.s.testimonies()) == 'verified': break
        if M.dsm.s.F > F_MAX: break
    # 3) 证据裁决 + 两级退避
    verdict = M.xted.decide(M.dsm.s.testimonies())
    U_epi_after = 0.0 if verdict == 'verified' else U_epi
    U_floor = U_ale + U_epi_after
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if (not null['ok']) or M.dsm.s.F > F_MAX or verdict == 'contradiction':
        lam = max(lam, 0.8)                           # 回 R68 最保守
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ...)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, verdict, veto, null)
    return k, lam, mode, (U_ale, U_epi_after, verdict, veto)

## 3. 推导

**引理 19（时域单调性与 R69 的包含）** 设对话策略空间 Π_T 包含任意 T 轮动作序列；则 max_{π∈Π_T} VoI ≥ max_{π∈Π_1} VoI = R69 的单步贪心值，因为 T=1 是 Π_T 的子集。更强地，当第二轮条件信息 I(M; y_2 | y_1, g_2) > 0 且成本 c(g_2) 小于该增益时严格改进。系：R69 是 horizon-1/单视角边界；对话增强在安全侧不退步（停止规则只在边际 VoI ≤ 0 时停）。

**引理 20（多视幻影否决的可靠性与其空集）** 若模态 m 隐含结构 X_m 在 ≥2 个基线 b 的标定视角下重投影 e_geo(X_m) > τ_geo 而 e_null 正常，则 X_m 不可由当前观测实现，veto 后 m 的权重被压到 ≤ ε；且当语义歧义落在**几何零空间**（两个语义标签对应同一 3D 结构）时 veto 不触发——**几何只否决结构，不否决含义**。这个空集正是 R70 最大风险的来源。

**引理 21（自洽对手下的通道互补）** 若人类为 consistent adversary（固定谎言、无认知噪声），纯对话的 k-一致纪律错误采纳率下界 = 对手先验（多轮不降低）；而多视几何能把可被结构约束的断言错误率压到 O(exp(−b²/σ²))（b 为基线）。故最优预算分配随「对手自洽概率」由对话滑向几何，构成成本-保真度 Pareto 前沿。

**定理 18（DIALECTIC 严格包含 FLUID-RAS）** 在 A99–A101 下，DIALECTIC 的期望风险 ≤ FLUID-RAS；当 T_max=1、|𝒱|=1、ρ 固定、零检验恒通过且关闭 veto 时，二者逐指令相同。安全侧只增不减：任何对话/几何增强失败都单调退回 R69→R68。

**定理 19（对话安全、终止与无突变）** 硬轮数上限 T_max + 疲劳上限 + C-RAS-WM 认证 + 停止规则 ⇒ 对话必然有限步终止；信息动作只改「选哪个模态」，不改安全包络；矛盾/零检验失败/断链时 λ 单调不降退回保守；R68 换装不变式保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：多视几何只认**结构**、不认**语义**，而且它依赖标定——一旦外参发生缓慢漂移，几何残差会“全局一致地错”，系统就会**系统性地否决真模态、确认幻影**；也就是说，那条本用来抓 R69 幻影的通道，自己会变成幻影制造机。与此同时，对话通道对一个*始终自洽*的对手几乎无解——**多轮只惩罚不自洽的谎言，不惩罚自洽的谎言**。于是 DIALECTIC 的安全感悬在两个都可能静默失效的假设上：几何可信、对手不自洽。

**次级风险与缓解**：
1. **语义歧义落在几何零空间**（结构同、含义不同）→ 显式登记为几何空集，交回对话/保守，不假装已消解（E313）；
2. **外参漂移造成全局误否决** → GNT 零检验 + fiducial 探针 + 零检验失败即禁用 veto 并回 R68（定义 323、E303）；
3. **自洽对手击败多轮对话** → 引导航几何终裁 + 正交征询 + 对可结构约束断言强制多视，量化残余风险（引理 21、E304/E314）；
4. **对话疲劳与社交成本** → 超线性疲劳 + 硬轮数上限 + 重复征询禁令（定义 321、E309）；
5. **会话状态投毒** → 哈希链 + 验签 + untrusted 隔离（定义 324、E311）；
6. **诱导性提问自我污染** → 冻结 LLM + 规则 + 人类校准的反诱导过滤（定义 320、E307）。

## 4. 推导

**引理 19（时域单调性与 R69 包含）** 对话策略空间 `Π_T` 包含单步动作，故 `max_{π∈Π_T}VoI ≥ max_{π∈Π_1}VoI = R69 贪心`；当 `I(M;y_2|y_1,g_2)>0` 且 `c(g_2)` 小于该增益时严格改进。R69 = horizon-1/单视角边界，安全侧不退步。

**引理 20（多视幻影否决及其空集）** 若模态 `m` 的结构 `X_m` 在 ≥2 个基线 `b` 的标定视角下 `e_geo>τ_geo` 且 `e_null` 正常，则 `X_m` 不可实现、`veto` 后权重 ≤ε；但语义歧义若落在几何零空间（两个语义标签对应同一 3D 结构），veto 不触发——**几何只否决结构，不否决含义**。

**引理 21（自洽对手下的通道互补）** 对 consistent adversary，纯对话 k-一致纪律错误率下界 = 对手先验（多轮不降）；多视几何把可被结构约束断言错误率压到 `O(exp(−b²/σ²))`。最优预算随「对手自洽概率」从对话滑向几何，形成成本-保真度 Pareto 前沿。

**定理 18（DIALECTIC 严格包含 FLUID-RAS）** A99–A101 下期望风险 ≤ FLUID-RAS；当 `T_max=1,|𝒱|=1,ρ固定,零检验恒过,veto关` 时逐指令相同。安全侧只增不减。

**定理 19（对话安全、终止与无突变）** 硬轮数 + 疲劳上限 + C-RAS-WM 认证 + 停止规则 ⇒ 必然有限步终止；交互只改模态选择、不改安全包络；矛盾/零检验失败/断链时 λ 单调不降退回保守；R68 换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：多视几何只认**结构**、不认**语义**，且依赖标定——外参一旦缓慢漂移，几何残差会“全局一致地错”，系统就会**系统性地否决真模态、确认幻影**，那条本用来抓 R69 幻影的通道自己变成幻影制造机。与此同时，对话通道对*始终自洽*的对手几乎无解——**多轮只惩罚不自洽的谎言，不惩罚自洽的谎言**。DIALECTIC 的安全感因此悬在两个都可能静默失效的假设上：几何可信、对手不自洽。

**次级风险与缓解**：语义歧义落几何零空间（显式登记、交回对话/保守，E313）；外参漂移全局误否决（GNT 零检验 + fiducial 探针，失败即禁用 veto 回 R68，E303）；自洽对手击败对话（几何终裁 + 正交征询 + 强制多视，引理 21、E304/E314）；对话疲劳/社交成本（超线性疲劳 + 硬轮数 + 重复征询禁令，E309）；会话状态投毒（哈希链 + 验签 + untrusted 隔离，E311）；诱导性提问自我污染（冻结 LLM + 规则 + 人类校准过滤，E307）。
