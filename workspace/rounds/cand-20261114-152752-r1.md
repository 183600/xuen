# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据增强」×「最优控制」）

> R69 让系统学会了「问」，却把两个极强的默认前提当成了免费午餐：
> - **数据增强默认是离线、廉价、无害的**——多造点数据总归提升鲁棒性；
> - **交互决策默认是「当前一步谁的信息增益最高」的贪心问题**。
>
> 实际上这两个前提都在暗中支撑 R69 的结论。(1) 一旦把合成数据混入模态权重、ECE 与流似然异常分，它会**只缩短置信区间、不减小偏差**，于是系统在错误模态上更自信，校验器还给它盖章——R69 最大风险（幻觉出幻影模态）由此获得一个更隐蔽的镜像：**假对称性把真模态静音**。(2) R69 的 MINT 是 H=1 的近视贪心，忽略了 Feldbaum 意义上的**对偶效应**：探测既改变信念、又消耗预算、还产生下一轮可用的数据；最优策略必须为未来信息支付当下代价。
>
> 本轮两个灵感正好各补一块：
> - **数据增强**在数学上就是「沿一个对称群轨道移动数据」。增强不是「更多数据」，而是一条**被认证的对称性**。沿已认证的对称方向可以免费想象；沿**对称性破缺**方向，任何由群作用生成的样本都不含该方向的信息，必须靠真实交互去测。
> - **最优控制**把「问不问、问什么、何时问、问完怎么用」统一为有限时域对偶控制；R69 的贪心 VoI 恰是 H=1、学习价值为零、无增强控制的退化特例。
>
> 核心命题：**按认证对称群把 epistemic 不确定性拆成「轨道内（U_orb，可增强、免费、任务无关）」与「破缺方向（U_brk，不可增强、必须实测）」；轨道内用认证增强吸收，破缺方向用有限时域对偶控制花真实预算；并用来源账本硬性隔离「用于规划的反事实合成数据」与「用于定案/标定的证据」。** 命名 **ORBIT-RAS**（Orbit-certified, Belief-adaptive, Interaction-optimal, Two-timescale RAS）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**哪些不确定可以靠想象解决、哪些必须真的去碰**」——增强负责想象，控制负责验证，账本负责不让想象冒充验证。

## 0. 直觉与动机

**灵感 1（数据增强 = 群轨道，而不是「更多数据」）**
直觉：翻转、旋转、加噪、时间平移之所以有效，是因为它们**不改变任务答案**。把这些变换收集成群 G，任何 g∈G 作用在样本上仍落在同一「任务等价类」里。所以增强的本质不是样本量，而是一张**对称性证书**：只有 G 被认证为任务对称群，沿轨道造多少数据才是安全的。反过来，若 G 只是**近似的**（重力破坏全 SE(3)、接触破坏时间反演、传感器视场破坏旋转），增强就会悄悄抹平一条真正改变任务的方向；R69 的模态分布对这种抹平极端敏感。

**灵感 2（最优控制 = 对偶控制：控制与学习不可分）**
直觉：R69 的 MINT 每一步取 argmax[VoI−cost]，是**近视**的：它不知道这次探测把信念带到哪里、不知道探测预算如何跨时域分配、更不知道这次探测产生的数据会改变下一次的模型。Feldbaum 的**对偶控制**指出，最优控制中动作同时有「控制」与「探测」两种效应，最优策略必须为**未来的信息**付出当下代价。把 R69 的交互决策写成 H 步有限时域代价，贪心 VoI 就是 H=1、学习价值=0 的边界——不是推翻，而是包含。

**灵感 3（增强与交互的分界线 = 对称性破缺）**
直觉：沿已认证的对称方向可以「免费想象」，因为合成样本与真实样本同属一个轨道；但沿**法向（normal bundle）**，群作用根本不改变这个坐标，合成样本对该坐标**零信息**。于是有一条清晰分工：**轨道内 → 增强；破缺方向 → 真实交互**。R69 交互预算之所以浪费，正是因为它没有把「冗余自由度里不改变任务的假歧义」与「真正改变任务的破缺歧义」分开。

**灵感 4（增强是双刃剑 = 自证循环）**
直觉：若模态权重、ECE、流似然异常分都在掺了合成数据的集合上估计，会出现极坏的组合：合成数据把置信区间收窄（有效样本量变大），却完全不减小偏差（数据由模型自己生成）。结果是系统**更自信地错着**，而校验器仍盖章通过。R69 的最大风险是「幻觉出幻影模态」；本轮补上它的镜像——**假对称性把真模态静音**。因此必须有来源账本：合成数据可以进入**训练/规划**，但**不得进入标定/定案/异常分**；用于规划的反事实 ≠ 用于更新的证据。

**灵感 5（两个时间尺度 = 快环对偶控制 + 慢环增强控制）**
直觉：运行时（毫秒）要解「当前该不该探、探哪个」的对偶控制；训练时（小时/天）要解「下一轮沿哪些方向、造多少合成数据」的**数据分布控制**。两者都是最优控制，但状态变量、时域、约束完全不同。慢环只在维护窗口运行，天然满足 R68「实时流零学习写操作」不变式；快环只读不学。只有把「数据增强」本身也当成受控对象，才配得上「最优控制」四个字，而不是把增强当成固定超参。

**灵感 6（严格包含 R68/R69）**
直觉：当认证群退化为平凡群 {e}、时域退化为 H=1、学习价值置零、来源权重全为 1 时，ORBIT 逐指令退化为 FLUID；再令 VoI≤成本即退化为 R68。安全侧不因多一层控制而放松：任何被执行的探测仍要过 C-RAS-WM 认证，增强只改规划与训练，不改安全包络。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（ORBIT-RAS 总览）** ORBIT-RAS = (SGT, CAG, OPD, DUC, MACE, PEL, OAC, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；慢环只在维护窗口）；
(ii) **来源分离**：合成/反事实样本可用于训练与规划，但证据、标定与异常分只取「真实或已核实交互」样本（定义 313、318）；
(iii) **增强守恒**：任何合成样本必须由认证群元素或认证扰动生成，且落在 G_cert(δ) 内（定义 312）；
(iv) **对偶预算**：真实交互 ≤1 次/单位时间、位移 ≤ ε_g、社交成本 ≤ c_max；合成算力预算单独核算；两者联合进入有限时域代价（定义 316）。

**定义 311（任务对称群与等变误差）** 群 G 作用 T^o_g: O→O、T^a_g: A→A，并要求动力学等变 f(T^a_g a, T^o_g o)=T^o_g f(a,o)。任务对称当且仅当 y(T^o_g o)=y(o) 且最优动作共变。策略等变误差 ε_eq(g)=E_{o∼𝒟}‖π_θ(T^o_g o)−T^a_g π_θ(o)‖。**关键：G 是待检验对象，不是先验给定。**

**定义 312（认证增强集 G_cert）** 对每个 g，用真实数据估计语义风险差 r_sem(g)=E[ℓ(π_θ(T^o_g o), T^a_g a*(o))]−E[ℓ(π_θ(o), a*(o))]，并用共形/自助法给上置信界。G_cert(δ)={g∈G : UCB_δ r_sem(g) ≤ ε_aug ∧ ε_eq(g) ≤ ε_eq^max ∧ 动力学等变检验通过}。未认证 g 生成的样本记为非法合成，直接丢弃。

**定义 313（来源标签与证据权重）** 样本 d=(o, ξ, p, ρ)，p∈{real, interaction, synthetic(g), counterfactual}，ρ 为可验证的生成/采集凭证。证据权重 ω(p)：real/interaction 核实后 =1；synthetic/counterfactual 对证据与标定为 0，对表征训练 ≤ α_syn<1。**证据集** ℰ_t={d : p∈{real,interaction} ∧ 凭证有效}；**规划集** 𝒫_t 可含 counterfactual/synthetic。

**定义 314（轨道—破缺不确定性分解 OPD）** 对 R69 的模态原型 {ξ̄_k} 与模态内协方差 Σ_k，取模态差 δ_{ij}=ξ̄_i−ξ̄_j，按认证群李代数切空间（由 T^a_g 的 Jacobian 张成）正交分解为 δ_{ij}=δ^∥_{ij}+δ^⊥_{ij}。若 ‖δ^⊥_{ij}‖ ≤ ε_merge‖δ_{ij}‖，则 i、j 视为**同一轨道**并合并（任务等价，不再计入歧义）。定义
U_orb = Σ_{i<j} w_i w_j ‖δ^∥_{ij}‖² / Δ̄²，
U_brk = Σ_{i<j} w_i w_j ‖δ^⊥_{ij}‖² / Δ̄²，
Δ̄ 为归一化尺度。R69 的 U_epi = U_orb + U_brk + 交叉项；**只有 U_brk 进入 VoI 与真实交互预算**，U_orb 由认证增强与轨道商化吸收。

**定义 315（破缺方向的零信息性）** 设 θ_brk 参数化沿 normal bundle 的对称性破缺。精确对称下，认证群轨道上的合成分布对 θ_brk 的边缘似然不变，即 Fisher 信息 I(θ_brk; D_synth | G_cert)=0；近似对称时泄漏 ≤ C·ε_eq²。故 U_brk 只能由真实/交互样本降低。

**定义 316（有限时域对偶控制 DUC）** 信念 b_t 含模态后验与 θ_brk 后验；控制 u_t=(a_t,g_t)∈𝒜_+。目标
J_H = E[ Σ_{t=0}^{H−1}( c_task(x_t,u_t)+c_info(g_t)+c_syn·1[g_t 为合成规划] ) + λ_term·U_brk(b_H) + λ_ale·U_ale(b_H) ]，
s.t. 安全包络、预算、来源约束。求 u*_{0:H−1}=argmin J_H，按 MPC 只执行 u*_0。R69/MINT 是 H=1、学习价值=0、c_syn=0 的退化。

**定义 317（模型增强反事实评估 MACE）** 用已学习的观测/结果生成器或认证群作用构造候选 g 的反事实结果 {y^{(j)}}，**仅用于估计** E_y[H(M|o,y)] 与到达代价，**不用于**后验更新。MACE 输出必须带「规划专用」标记，其偏差由真实探测的 regret 监控。

**定义 318（来源证据账本 PEL 与自证断路器）** PEL 记录每样本的来源与用途（train/plan/evidence/calibrate）。硬规则：evidence 与 calibrate 用途只能引用 ℰ_t；训练/规划的合成数据不得改变模态权重、ECE、FMA 异常分。**自证测试**：把合成子集整体替换为独立同分布真实数据再训练，若 ΔECE 或 ΔVoI 超过容差 τ_prov，判定自证污染，回滚并禁用该增强方向。

**定义 319（增强策略作为慢环控制 OAC）** 慢环状态 s=(各模态覆盖 n_k、校准误差 e、各 g 的等变误差)，控制是增强分布 q_φ(g) over G_cert，代价为负覆盖 + 计算 + 校准退化惩罚；动力学用便宜代理（覆盖计数 + 误差经验模型）近似。维护窗口内解有限时域问题，重训仅周期性执行，且每次重训前重跑 G_cert 认证。

**定义 320（来源不相交的模态校准门 MCG-O）** ECE 与可靠图必须在与合成/反事实不相交的校准集上估计，并报告有效样本量 ESS 与偏差下界。ECE>τ_ece 或 ESS<n_min 或 PEL 校验失败 ⇒ 禁用 VoI/交互，退 R69→R68 纯保守。

**定义 321（增强规划的安全）** 由增强/反事实得到的候选探测 g 只是**建议**；执行前仍须过 C-RAS-WM 前缀认证与预算。增强不得直接改变 λ_floor 或安全包络。

**定义 322（参与式审计 VQAuditor-O）** 审计增强方向是否被误认证、合成数据是否进入证据/标定、对偶探测是否超预算、反事实规划与实际执行的 regret、慢环重训是否导致行为突变；结论回灌 AuditBuf。

**定义 323（攻击/干扰集 ℰ_ORBIT）** = ℰ_FLUID × ℰ_sym（假对称、错误群元素、被投毒的认证集）× ℰ_prov（来源伪造、凭证重放）× ℰ_dual（诱导长期探测耗尽预算、用反事实污染规划）。并入 AIC-ORBIT。

**定义 324（证书 J_ORBIT）** J_ORBIT=(J_FLUID, G_cert_hash, ε_eq, ε_sem_ucb, provenance_ledger_hash, ESS, U_orb/U_brk, dual_horizon H, outer_policy_hash, orbit_ver)。Valid ⇔ Valid(J_FLUID) ∧ G_cert 认证有效 ∧ PEL 校验通过 ∧ 预算未越界 ∧ 自证测试通过。

**定义 325（退化与严格包含）** G_cert={e} ∧ H=1 ∧ c_syn=0 ∧ 学习价值=0 ∧ 来源权重全为 1 ⇒ ORBIT ≡ FLUID；再 VoI≤成本 ⇒ ≡ R68。任何认证失败、自证失败或预算耗尽 ⇒ 单调退回 FLUID 的保守分支。

# IP-264 SGT：认证哪些增强方向真的不改任务（离线/低频，结果缓存）
class SymmetryTester:
    def certify(self, G, real_data, policy, delta):
        Gcert = {}
        for g in G:
            eq = empirical_equivariance(policy, real_data, g)      # eps_eq(g)
            rs = semantic_risk_gap(policy, real_data, g)           # r_sem(g)
            ucb = conformal_ucb(rs, real_data, delta)
            if eq <= self.eps_eq_max and ucb <= self.eps_aug \
               and dynamics_equivariant(g, real_data):
                Gcert[g] = (eq, ucb)
        return Gcert

# IP-265 CAG / IP-266 OPD：轨道商化 + 破缺分量
def orbit_decompose(modes, covs, w, Gcert):
    pairs = []
    for i in range(len(modes)):
        for j in range(i + 1, len(modes)):
            d = modes[i] - modes[j]
            d_par, d_perp = split_by_lie_algebra(d, Gcert)  # Jacobian 张成切空间
            if norm(d_perp) <= eps_merge * norm(d):
                merge(modes[i], modes[j])                    # 同一轨道 → 任务等价
                continue
            pairs.append((i, j, norm(d_par) ** 2, norm(d_perp) ** 2))
    U_orb = sum(w[i] * w[j] * par for i, j, par, perp in pairs)
    U_brk = sum(w[i] * w[j] * perp for i, j, par, perp in pairs)
    return U_orb, U_brk, quotient(modes)

# IP-267 DUC：有限时域对偶控制（beam-MPC，只执行首步）
def dual_control_plan(belief, H, budget, Gcert, mode_head):
    best = None
    for u in beam_candidates(belief, width=W):                # 任务动作 + 信息动作
        if not budget.allow(u) or not c_ras_wm.certify(u): continue
        J = rollout_cost(u, belief, H,
                         use_counterfactual=True, update_belief=False)
        J += lam_term * predict_U_brk(belief, u, mode_head)
        if best is None or J < best.J: best = (u, J)
    return best.u[0] if best else fallback_to_fluid(belief)

# IP-268 MACE：反事实评估（明确标记 planning-only，不更新后验）
def counterfactual_voi(g, belief, generator):
    ys = generator.sample_outcomes(g, belief, tag="planning_only")
    return entropy(belief.modes) - mean(entropy_bayes(belief.modes, y) for y in ys)

# IP-269 PEL：来源账本 + 自证断路器
class ProvenanceLedger:
    def add(self, d, purpose):
        assert purpose in {"train", "plan", "evidence", "calibrate"}
        if purpose in {"evidence", "calibrate"}:
            assert d.p in {"real", "interaction"} and d.rho_valid
        self.rows.append((hash(d), d.p, purpose, d.rho))

    def self_confirmation_test(self, model, synth_subset, real_holdout):
        m1 = retrain_without(model, synth_subset)
        m2 = retrain_with(model, synth_subset)
        return max(abs(ece(m1, real_holdout) - ece(m2, real_holdout)),
                   abs(voi(m1) - voi(m2))) <= tau_prov

# IP-270 OAC：慢环——增强分布本身是控制量（仅维护窗口）
def outer_augmentation_control(state, Gcert, compute_budget):

            cost=lambda q: -coverage(q) + lam_cal * calib_risk(q)
                           + lam_cmp * compute(q),
            dynamics=coverage_surrogate,
            constraints=[q on Gcert])
    return q                     # 交给离线训练；训练前重跑 SGT

## 3. 推导

**引理 19（轨道增强的零信息性与泄漏界）** 设认证群精确。对只改变法向参数 θ_⊥ 的环境变化，轨道样本似然 p(g·d | θ_⊥)=p(d | θ_⊥=0)（群作用不涉及 θ_⊥），故得分函数 ∂log p/∂θ_⊥=0，Fisher 信息 I(θ_⊥;D_synth)=0；近似对称下 |I(θ_⊥;D_synth)| ≤ C·ε_eq²。**系**：U_brk 的任何下降必须来自真实/交互样本；增强只能在 U_orb 上做功。这既是「增强—交互」分界，也解释了 MINT 为何把预算花在假歧义上。

**引理 20（自证偏差：方差缩短、偏差不减）** 设 n_R 个真实证据、模态权重估计偏差 b=‖ŵ_R−w*‖。引入 n_S 个与模型同源的合成样本后，ŵ=(n_R ŵ_R+n_S ŵ_S)/(n_R+n_S)，其中 E[ŵ_S]=ŵ_R（模型生成）。于是 E[ŵ]=E[ŵ_R]（偏差不改善），而 Var(ŵ)≈Var(ŵ_R)·n_R/(n_R+n_S)（自信度虚高）。若用该方差构造置信半径，则「自认为的误差」下降而真实误差 b 不变，置信区间覆盖真实模态的概率可低于标称。**系**：ECE 可被合成数据刷低而真实模态错误率不变；故校准集必须来源不相交（定义 320），且来源账本必须可审计（定义 318）。

**引理 21（对偶效应：探测的学习价值）** 设探测 g 产生的样本进入下一次重训，使模型误差按 δ(θ) 下降。单步 VoI 忽略的「学习价值」为 LV(g)=E_{y∼p(·|g)}[V_{t+1}(b',θ')−V_{t+1}(b',θ)]。当 θ' 只在破缺方向改善（引理 19）时 LV(g)≥0，且对真实探测在未收敛时严格为正。故 H>1 的对偶控制相对贪心 VoI 的改进下界为 Σ_t LV_t；贪心恰是 H=1、LV=0 的退化。

**定理 18（精确对称下的严格包含）** 在 A99–A103 与 ε_eq=0、r_sem=0 下，ORBIT 任意状态的期望风险 ≤ FLUID；当 G_cert={e}、H=1、c_syn=0、LV=0、来源权重全为 1 时两者逐指令相同；再 VoI≤成本则 ≡ R68。近似对称下结论放宽为 ≤ FLUID + ε_aug，且 ε_aug 显式进入证书 J_ORBIT，绝不被隐去。

**定理 19（安全不变与递归可行）** 若 (i) 终端代价 V_H(b)=λ_term U_brk+λ_ale U_ale 正定且沿闭环下降；(ii) 每步可行集包含 R69 的保守动作；(iii) 执行动作一律过 C-RAS-WM；则 MPC 递归可行、代价单调不增、安全包络不变；认证失败/自证失败/预算耗尽时切换到 FLUID 保守分支，λ 单调不降。⇒ 控制连续、无突变（继承 R69 定理 17）。

## 6. 本轮最大风险

**一句话**：ORBIT 的全部效率收益押在「G_cert 确实是任务对称群的子群」这一前提上——**若 SGT 误把一条真正改变任务的方向认证为对称，系统就会用增强把那条方向上的真模态抹平、在错误的轨道商化下宣布「无歧义」，从而跳过本该进行的真实探测、自信地执行错误模态**；假对称性比无知更危险，因为它让系统连「我不知道」都说不出口。

**次级风险与缓解**：
1. **来源账本被绕过/伪造** → PEL 哈希链 + 来源不相交校准集 + 自证断路器（定义 318、320）；
2. **反事实规划污染信念** → MACE 强制 planning-only 标记，后验更新只接受真实 y（定义 317）；
3. **对偶控制时域过长击穿实时预算** → beam-MPC + H=1 默认 + mode_head 门控（定义 316、308）；
4. **近似对称的泄漏** → 泄漏界 C·ε_eq² 进入证书，ε_eq 超阈值即禁用该方向增强（引理 19、定义 312）；
5. **慢环重训引起行为突变** → 仅维护窗口、重训前重认证、切换时 λ 单调不降（定理 19、定义 319）。

## 4. 推导

**引理 19（轨道增强的零信息性与泄漏界）** 精确对称下，认证群轨道上的合成分布对法向参数 θ_⊥ 的边缘似然不变，故 `I(θ_⊥;D_synth)=0`；近似对称时泄漏 `≤C·ε_eq²`。系：U_brk 只能由真实/交互样本降低，增强只在 U_orb 上做功——这就是「增强—交互」分界线。

**引理 20（自证偏差）** 引入与模型同源的 n_S 个合成样本后，`E[ŵ]` 不变（偏差不减），但 `Var(ŵ)≈Var(ŵ_R)·n_R/(n_R+n_S)`（置信区间虚缩）。于是 ECE 可被刷低而真实模态错误率不变；故校准集必须来源不相交，PEL 必须可审计。

**引理 21（对偶效应）** 探测的学习价值 `LV(g)=E[V_{t+1}(b',θ')−V_{t+1}(b',θ)]≥0`，未收敛时严格为正；H>1 对偶控制相对贪心 VoI 的改进下界为 `Σ LV_t`。贪心是 H=1、LV=0 的退化。

**定理 18（精确对称下的严格包含）** A99–A103 且 ε_eq=r_sem=0 时，ORBIT 期望风险 ≤ FLUID；G_cert={e},H=1,c_syn=0,LV=0 时逐指令相同；再 VoI≤成本则 ≡ R68。近似对称下放宽为 ≤ FLUID+ε_aug，且 ε_aug 显式入证书。

**定理 19（安全不变与递归可行）** 终端代价正定下降、可行集含 R69 保守动作、执行过 C-RAS-WM ⇒ MPC 递归可行、代价单调不增、安全包络不变；认证失败/自证失败/预算耗尽 ⇒ 单调退回 FLUID 保守分支。⇒ 无突变（继承 R69 定理 17）。

## 7. 本轮最大风险

**一句话**：ORBIT 的全部效率收益押在「G_cert 确实是任务对称群的子群」这一前提上——**若 SGT 误把一条真正改变任务的方向认证为对称，系统就会用增强把该方向上的真模态抹平、在错误的轨道商化下宣布「无歧义」，从而跳过本该进行的真实探测、自信地执行错误模态**；假对称性比无知更危险，因为它让系统连「我不知道」都说不出口。

**次级风险与缓解**：来源账本被绕过（PEL 哈希链 + 来源不相交校准 + 自证断路器）；反事实污染信念（MACE 强制 planning-only，后验只吃真实 y）；对偶时域过长（beam-MPC + H=1 默认 + mode_head 门控）；近似对称泄漏（C·ε_eq² 入证书，超阈值禁用该方向）；慢环重训突变（仅维护窗口、重训前重认证、λ 单调不降）。
