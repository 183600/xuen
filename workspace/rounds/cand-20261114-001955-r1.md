# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「边缘计算」×「智能体」）

> R69 学会了「问」：把不确定性拆成 aleatoric / epistemic，用流匹配的模态分布算 VoI，用注视/探针/问句去消解可约的歧义。但它默默假设了三件从未被检验的事：**答案瞬时到达且永久有效**、**回答者诚实且彼此独立**、**算得出就一定来得及执行**。边缘计算与智能体同时打穿这三条：
> - 边缘把「取证」变成一条**供应链**：查询要过异构节点、观测带传输延迟、远端模型会陈旧、网络会分区。一个晚到 50ms 的完美答案，对 10ms 的避障窗口等于没答。
> - 智能体把「向谁问」变成「**委托谁**」：回答者是有自身状态、模型、数据与激励的 agent；它们可能共享训练数据（错误相关）、可能过时、可能被攻陷、可能策略性撒谎。R69 的「k 个正交证据源一致」在源不独立时，只是**同一张嘴的 k 次复读**。
>
> 本轮两个灵感各补一块：
> - **边缘计算**给出「信息的保质期」与「计算的位置」——价值必须按**能否在截止时间前到达、到达时是否仍然有效**来折算；
> - **智能体**给出「委托与代理问题」——安全不能外包给远端，只能保留**本地否决权**，并用可审计的出处与相关性估计来约束共识。
>
> 核心命题：**把 R69 的「单节点、瞬时、独立」取证假设，升级为「分布式、带截止时间、相关失效」的证据供应链。安全由本地零网络反射保证；远端 deliberation 只能产出可被本地认证门否决的建议；信息价值按时效（temporal VoI）与有效正交性（effective independence）折算；当证据不能及时到达、不能相互独立、不能通过出处校验或网络分区时，单调退化为 R69，再退化为 R68。** 命名 **MESH-RAS**（Multi-agent Edge Safety Hierarchy for Risk-Adaptive Systems：证据可以来自天边，否决权必须握在本地）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**答案什么时候能到、从哪个节点算、那几个声音是不是同一张嘴**」——不确定性不只是一种信念，还是一份有延迟、有出处、可能被伪造的**证据物流**。

## 0. 直觉与动机

**灵感 1（边缘计算 → 信息有「保质期」，计算有「位置」）**
直觉：R69 的 VoI(g)=H(M|o)−E[H(M|o,y)] 隐含地假设 y 立刻返回且 y 的语义不随时间变化。边缘系统里，y 要经过「本地感知 → 上行链路 → 远端模型/agent → 下行链路」；延迟 L 是随机变量，观测在远端看到的还是若干毫秒前的世界。对硬实时控制，**迟到的确定性不是确定性，而是噪声**。更微妙的是，远端模型的先验可能陈旧（模型版本落后于本地场景），此时答案不是「不知道」，而是「带着旧世界观的自信」。因此边缘强迫我们把「问什么」扩展成「**在哪算、何时算、值不值得等**」，并把 freshness（新鲜度）提升为一等状态变量。计算位置本身也参与信息安全：越远越省本地算力，但越可能偏移、越不可认证。

**灵感 2（智能体 → 「问谁」变成「委托谁」，而委托引入代理问题）**
直觉：R69 把证据源当作诚实的测量通道。智能体世界里，证据源是**有自己目标的 agent**：一个视觉 agent 可能为了「看起来成功」而漏报，一个规划 agent 可能与主 agent 共享同一份训练数据，一个云端 agent 可能在断网时返回缓存的旧结论。委托的收益是能力与并行，代价是**代理风险**：你无法直接读它的内部状态，只能看它交出的证据与行为。于是「k 源一致」必须回答两个新问题：这 k 个源是否**有效独立**（失效相关性是否接近 0）？这 k 个源是否**可归责**（出错时能否定位到具体节点并撤销其权重）？R69 的证据纪律在单机内是统计保证，在网格里必须先变成**相关性审计 + 拜占庭容错**。

**灵感 3（双时标 → 把安全放在不依赖网络的一侧）**
直觉：边缘系统必须假设网络会断、节点会挂、agent 会错、云端会过期。那唯一稳的做法是**把硬实时反射全部留在本地，且零网络依赖**；远端 deliberation 只做「慢思考」，产出建议与证据，永远不能直连执行器。建议进入控制前必须过一道**本地认证门**：本地小模型在本地安全包络内复核、检查新鲜度与出处、检查有效正交配额。这样远端再糟，最坏也只是「建议被拒」，系统退回保守，而不会因远端错误直接致险。这是对 R69「取证」架构的**拓扑化**：证据可以分布，否决权不能分布。

**灵感 4（推测预取 → 用「早」换「等」）**
直觉：既然延迟是敌人，就不要等到需要答案时才发问。R69 的 mode_head 已经能廉价预测「哪里可能歧义」；用它做**推测式预取**：在决策点之前把可能的证据取回缓存，把延迟分布整体左移。代价是浪费算力、占用带宽、缓存可能过期。于是预取变成一个可判定的投资问题：预测歧义概率 × 决策时刻的期望 TVoI 是否大于预取成本与过期浪费？预取永远只改善时延，不改善安全——因为过期缓存一律丢弃，绝不降级使用。

**灵感 5（分布式 FMA → 用节点间分歧做第二意见）**
直觉：R69 用「观测 vs 标定观测」的动作似然差 Δa 识别被标定吸收的缓变故障。网格里还有一条更强的信号：**不同节点对同一动作的似然分歧**。若节点 i、j 各自局部自洽（本地残差都低），却对同一条动作给出差异巨大的似然，那么至少一个节点的观测被偏移、过时或被投毒。分歧本身携带**归因信息**：配以新鲜度和出处，可把「有故障」细化成「哪个节点的观测不可信」。这把 R69 的对偶通道从「传感器 vs 行为」升级为「节点 vs 节点」的分布式对偶。

**灵感 6（严格包含 → 网格是 R69 的边界退化）**
直觉：新层不能是并列替代，否则每加一层就多一个要独立信任的黑箱。MESH 必须满足：当网络延迟为零、freshness=1、只有一个节点、证据源独立、无分区时，TVoI 退化为 R69 的 VoI，本地认证门对可信本地证据恒通过，拜占庭共识退化为 R69 的证据纪律，MESH 的执行路径与 FLUID 逐指令一致。且在所有不确定情形下，MESH 的 λ 单调不低于 R69——**安全侧只做加法，效率侧才做减法**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MESH-RAS 总览与四不变式）** MESH-RAS = (EGM, TVoI, REFLEX, LCG, EOS, BEC, SPH, DFA, PLG, RAS-WM‡)。四不变式：
(i) **本地反射零网络依赖**：硬实时控制路径的 WCET 有界且不等待任何远端响应；
(ii) **远端不直连执行器**：远端输出只是建议/证据，必须通过 LCG（定义 315）才可影响控制；
(iii) **时效纪律**：超时、过期、无法校验出处的证据视同未获得，不得用于降低 λ；
(iv) **正交纪律升级**：需 k 个**有效正交**源一致（定义 316），单源或低有效正交不得定案；R69 的 k 源独立是其 Σ=I 的特例。

**定义 311（证据网格 EGM）** 图 G=(N,E)。节点 n=(o_n, f_n, c_n, a_n, b_n, τ_n)：观测、模型、标定状态、历史准确率、算力、时钟。边 (i,j) 带延迟分布 L_ij、带宽、失效相关性 ρ_ij。证据 e=(source n, payload y, timestamp t, provenance hash h, calib version v, correlation group g)。网格是时变的：节点上线/下线、链路抖动、模型换版。

**定义 312（观测偏移与新鲜度）** 远端观测 o_n = Φ_n(x_{t−δ_n}) + b_n + ξ_n，δ_n 为老化时间，b_n 为节点偏置。新鲜度 ρ(δ)=exp(−δ/τ_half)，单调不增。陈旧引入不可约项 U_stale = (1−ρ)·U_range，其中 U_range 为该证据可区分的动作差异幅度。**陈旧不是 epistemic，因为再问同一份旧证据也不会变新；它必须按 aleatoric 兜底。**

**定义 313（时效信息价值 TVoI）** 决策截止时刻 d，在 t 经节点 n 执行信息动作 g：
TVoI(g,n,t) = P(L_{g,n} ≤ d−t) · ρ(E[δ_{g,n}]) · κ_n · ΔH(g) − c_comm(g,n) − c_priv(g,n) − c_energy(g,n)，
其中 κ_n = 2a_n−1（历史准确率的信任折扣），ΔH(g) 为 R69 定义 298 的熵减估计。若 max_{g,n} TVoI ≤ 0：**不查询、锚定当前后验**，走 R69 兜底。

**定义 314（双时标控制契约 REFLEX）** 控制分为 π_loc（本地反射：认证过的保守策略，WCET T_loc，零网络）与 D_edge（边缘 deliberation：异步，可跨节点，产出建议）。t 时刻本地默认执行 m_safe；仅当 LCG 接受一条**新鲜且已认证**的建议 m_adv 时才切换，且 m_adv 不得越出本地安全包络、不得使 λ 低于本地地板。

**定义 315（本地认证门 LCG）** Verify(m_adv, e, x_t)=1 当且仅当：(i) 本地 C-RAS-WM 前缀认证通过；(ii) ρ(age(e)) ≥ ρ_min；(iii) 参与源的有效正交数 ≥ k_min（定义 316）；(iv) 出处哈希链可校验且节点已登记（定义 320）；(v) m_adv 不越出本地安全包络。任一不满足 ⇒ 保留 m_safe，事件写审计。

**定义 316（有效正交性与联盟选择 EOS）** 失效相关矩阵 Σ，ρ_ij=Corr(F_i,F_j)（F 为「该源给出错误模态」）。有效独立数 k_eff = (tr Σ)² / tr(Σ²)（参与率，1≤k_eff≤|C|）。联盟选择 C* = argmax_C k_eff(C) s.t. Σ_{n∈C} L̄_n ≤ L_budget 且 Σ energy ≤ E_budget。**更多源不一定更安全：三个同源 agent 的 k_eff≈1，不如两个真正独立的源。**

**定义 317（拜占庭证据共识 BEC）** 容 f 个恶意/失效源时，多数正确需 k_eff ≥ 2f+1。加权投票权重 w_n ∝ calibration_n · ρ(age_n) · ∂k_eff/∂n（边际独立性贡献）；共识输出为加权模态中位数。k_eff < 2f+1 ⇒ 无法定案，U_epi 保持未消解。

**定义 318（推测式证据预取 SPH）** 用 mode_head 预测未来时域内的歧义概率 p_amb；若 p_amb · E[TVoI@decision] > c_prefetch + p_expire · c_waste，则提前向候选节点发起查询并写入带 deadline 的缓存。缓存超过 deadline 一律丢弃；预取不影响安全，只左移延迟分布。

**定义 319（分布式流似然异常 DFA）** 跨节点第二意见：Δa_ij = |a_score(ξ|o_i) − a_score(ξ|o_j)|，a_score 同 R69 定义 301。若 Δa_ij 高而两节点本地残差 r_res 均低 ⇒ 至少一个节点的观测被偏移/过时/投毒；结合新鲜度与出处可把嫌疑归因到节点子集。所有节点互相一致但本地残差也低 ⇒ 怀疑**共模**（共享上游传感器/同一训练数据），而非单节点。

**定义 320（出处与新鲜度账本 PLG）** 只追加的哈希链账本：每条证据记录 source_id、calib_version、timestamp、correlation_group、验证结果、LCG 判决。账本同时是 EOS 估计失效相关矩阵的数据源，也是 VQAuditor-I 的审计输入。

**定义 321（分区与退化策略 PDP）** 网络分区或法定人数丢失时：冻结到最后一次**本地认证**的计划，λ = λ_floor(U_ale + U_epi + U_stale)；绝不接受未校验的远端建议；重连后先重新校验新鲜度与出处，再允许 λ 下降。退化单调，恢复需重新取证。

**定义 322（不确定性记账）** U_total = U_ale + U_epi_unresolved + U_stale + U_comm。只有 U_ale 真正不可约；U_epi 由交互消解；U_stale 由预取与新鲜度门控压制；U_comm 是由通信不确定性引入的等效噪声。四者分通道进入 λ_floor，不做简单加和。

**定义 323（离线/在线写纪律）** 节点模型与 agent 权重只允许离线写；实时环路零学习写操作（继承 R68 定义 276-i / R69 定义 293-i）。登记新 agent 必须通过标定 + 相关性审计 + 出处校验三关。

**定义 324（自适应证据深度）** 默认 K=1、单节点、本地反射；仅当 mode_head 报歧义且截止时隙允许时，升 K=4 并请求远端联盟。K 与联盟规模在 deadline−t 的松弛时间下联合选择，保证本地 WCET 不被 deliberation 抢占。

**定义 325（证书 J_MESH）** J_MESH = (J_FLUID, provenance_root, freshness_p95, k_eff, byzantine_f, tvoi_ratio, partition_events, mesh_ver)。Valid ⇔ Valid(J_FLUID) ∧ freshness_p95 ≥ ρ_min ∧ k_eff ≥ k_min ∧ 出处链完整 ∧ 本地 WCET 未越界。

**定义 326（两级保守退避）** 证据及时且有效 ⇒ λ = λ_floor(U_ale)（resolution bonus，同 R69）；证据超时/过期/分区/低 k_eff/拜占庭嫌疑 ⇒ λ = λ_floor(U_ale + U_epi + U_stale) ≥ R69 的对应值。故 MESH 的安全侧永不弱于 FLUID。

```python
# IP-264 EGM：证据网格与新鲜度
class EvidenceMesh:
    def __init__(self, nodes, links, tau_half):
        self.nodes, self.links, self.tau_half = nodes, links, tau_half
        self.Sigma_fail = {}                      # 由 PLG 审计日志估计
    def freshness(self, e, t):
        return math.exp(-(t - e.t) / self.tau_half)
    def candidates(self, modes, o_t, deadline):
        return [q for n in self.nodes for q in n.info_actions(modes, o_t)]

# IP-265 TVoI：时效信息价值（R69 VoI 的严格扩展）
def tvoi(g, n, modes, t, deadline, mesh, budget):
    L = n.latency_dist(g)                         # 传输 + 远端计算
    p_on_time = L.cdf(deadline - t)
    if p_on_time < P_MIN: return -math.inf
    dH   = entropy(modes) - expected_entropy(modes, g, n)
    rho  = mesh.freshness_at(n, t + L.mean())
    trust = 2 * n.accuracy - 1                    # 准确率折扣
    cost = comm_cost(g, n) + priv_cost(g, n) + energy_cost(g, n)
    return p_on_time * rho * trust * dH - cost

# IP-268 EOS：相关失效下的有效独立联盟
def select_coalition(cands, budget, Sigma):
    best = None
    for C in powerset(cands):                     # 候选 <= 5，可枚举
        if latency(C) > budget.latency or energy(C) > budget.energy:
            continue
        k_eff = participation_ratio(Sigma[C, C])  # (trΣ)²/tr(Σ²)
        if best is None or k_eff > best.k_eff:
            best = Coalition(C, k_eff)
    return best

# IP-269 BEC：拜占庭共识（按有效正交加权）
def byzantine_consensus(answers, weights, f, Sigma):
    if participation_ratio(Sigma) < 2 * f + 1:
        return None                               # 无法定案 → U_epi 未消解
    return weighted_median_mode(answers, weights)

# IP-315 LCG：远端建议进入控制的唯一入口
def local_certify(m_adv, e, x_t, local_wm):
    if not c_ras_wm.certify_locally(m_adv, x_t, local_wm): return False
    if e is None or mesh.freshness(e, now()) < RHO_MIN:      return False
    if effective_k(e.sources, mesh.Sigma_fail) < K_MIN:      return False
    if not ledger.verify_chain(e):                           return False
    return True

# IP-318 SPH：推测式预取（只左移时延，不放松安全）
def maybe_prefetch(z_t, horizon, cache, mesh, budget):
    p_amb = mode_head(z_t)
    if p_amb < TAU_PREFETCH: return
    for q in predict_future_queries(z_t, horizon):
        if p_amb * expected_tvoi(q) > prefetch_cost(q):
            cache.prefetch(q, deadline=horizon, budget=budget)

# IP-319 DFA：跨节点动作似然分歧（分布式 FMA）
def distributed_flow_anomaly(policy, xi, obs_by_node):
    scores = {n: -policy.log_likelihood(xi, obs_by_node[n]) for n in obs_by_node}
    spread = max(scores.values()) - min(scores.values())
    return spread, argmax(scores)                 # 分歧定位可疑节点

# IP-274 主闭环：本地反射 + 异步 deliberation + 本地否决
def MESH_RAS_round(M, obs):
    # A. 本地硬实时反射（零网络，WCET 有界）
    z, o_loc = M.local_trunk(obs)
    U_ale, U_epi = M.local_estimate(z, o_loc)     # R69 廉价通道
    m_safe = M.local_reflex.conservative_mode(o_loc)
    # B. 异步 deliberation 提交/轮询（可能空、过期、分区）
    M.deliberator.submit(o_loc, z, deadline=M.vista.H)
    msg = M.deliberator.poll()
    # C. 本地认证门：远端只可建议，不可直连
    ok = (msg is not None and
          M.lcg.local_certify(msg.mode, msg.evidence, o_loc, M.local_wm))
    m_exec, U_epi_after = (msg.mode, msg.U_epi_after) if ok else (m_safe, U_epi)
    U_stale = 0.0 if ok else M.mesh.stale_uncertainty(msg)
    # D. 风险缩放：未及时/未独立/不可信一律视同未消解
    U_floor = U_ale + (0.0 if ok else U_epi_after) + U_stale
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix_local(m_exec, ...)   # 仅本地认证
    # E. 预取 / 账本 / 审计（全部异步，不阻塞控制）
    M.sph.maybe_prefetch(z, M.vista.H, M.cache, M.mesh, M.budget)
    M.ledger.append(msg)
    M.vqa_i.submit_async(msg, ok, U_stale)
    return k, lam, m_exec, (U_ale, U_epi_after, U_stale)
```

## 3. 推导

**引理 19（TVoI 的截止单调性与锚定阈值）** 设延迟 CDF F、新鲜度 ρ(δ) 单调不增、熵减 ΔH>0。则 TVoI 关于截止松弛 (d−t) 单调不增、关于期望老化单调不增；故存在阈值 d*，当 d−t < d* 时「不查询、锚定」严格优于任何查询。系 1：**交互不是越早越好，而是越靠近决策点越值钱**——这也是预取的意义。系 2：推测预取使延迟分布一阶随机占优地左移，故 TVoI 单调上升，但不改变锚定阈值的保守性。此时 R69 的 VoI 是 L≡0、ρ≡1 的退化情形。

**引理 20（有效正交性的拜占庭上界）** 设单源欺骗概率 δ_p，平均失效相关 ρ，k 源多数一致。错误采纳率 ≤ δ_p·ρ^{k_eff−1} + ε_σ，其中 k_eff=(trΣ)²/tr(Σ²) ≤ k。容 f 个拜占庭源需 k_eff ≥ 2f+1；若 k_eff < 2f+1 则不存在确定性多数保证。系：**「多问几个 agent」不是安全策略，「问几个真正不共享失效模式的 agent」才是**；共享训练数据/同一上游传感器/同一供应商会让 k_eff 坍缩到接近 1。

**引理 21（跨节点 FMA 的归因性）** 设节点 j 观测偏移 Δo_j，节点 i 干净。在 R69-A98（策略密度对条件 Lipschitz，常数 L_z 有界）下，a_score(o_j) − a_score(o_i) ≥ L_z‖Δo_j‖ − √(trΣ_flow)。若两节点本地残差 r_res 均低（各自局部自洽），则高 Δa_ij 把故障归因到 {i,j} 中的偏移侧；两两比较可缩小到节点子集。若全网互相一致但普遍偏离本地似然，则判为共模而非单点。这是 R69 引理 17 在网格上的镜像。

**引理 22（预取的收益条件与零安全损害）** 预取在决策时刻的净收益 = p_amb·(E[TVoI|预取] − E[TVoI|即查]) − c_prefetch − p_expire·c_waste。因过期缓存被 LCG 丢弃并计入 U_stale，故预取不改变 λ_floor 的下界；即**预取只可能改善时延与效率，不可能放松安全**。当 p_amb 或 ΔH 低于阈值时，预取退化为 R69 的即时查询（或完全不查）。

**定理 18（MESH 严格包含 FLUID/R69）** 在零延迟、ρ≡1、单节点、Σ=I、无分区的退化条件下：TVoI→R69 VoI，LCG→恒通过，BEC→R69 证据纪律，PDP→空操作，MESH 执行路径与 FLUID 逐指令相同。在超时/过期/分区/低 k_eff 时，U_stale 与未消解 U_epi 进入 λ_floor，故 λ_MESH ≥ λ_R69。因此 MESH 的期望风险 ≤ R69，且严格包含 R69 为「单节点零时延无相关」边界；安全侧不做任何让步，效率侧获得时效与并行收益。

**定理 19（网络无关的安全性与无突变）** 执行器指令只能来自本地反射与本地的 `certified_prefix_local`；远端建议必须通过 LCG，而 LCG 强制本地安全包络、新鲜度、出处与正交配额。因此无论远端节点诚实、过时、被攻陷还是网络分区，MESH 的轨迹始终落在本地认证安全集内。切换只在决策边界经前缀认证发生（延续 R69 定理 17），故控制连续、无突变；**安全性不依赖网络可用性与 agent 诚实性**。

**定理 20（退化单调性）** 定义安全序由 (λ, k) 给出：λ 越大、k 越小越保守。当分区、超时、出处失败或 k_eff 低于 2f+1 时，λ 单调不降、k 单调不增；恢复必须重新通过新鲜度与出处校验后才允许 λ 下降。故不存在「安全振荡」，且任意故障序列下的安全性不弱于冻结策略。

## 6. 本轮最大风险

**一句话**：MESH-RAS 把安全论证压在两个会被同一类资源竞争侵蚀的假设上——**「本地反射的 WCET 永远守得住」** 与 **「跨 agent 的失效相关性估得准」**；一旦边缘设备的热节流/电池降频/同租户抢占击穿了本地实时保障，或共享训练数据的多个 agent 让 k_eff 被系统性高估，MESH 就会以比 R69 更快的速度、更自信的口气，执行一个由「同一张嘴的多次复读」伪装成的共识——**分布式取证最大的危险不是问不到，而是以为问到了独立的多方**。

**次级风险与缓解**：
1. **本地 WCET 被 deliberation/预取抢占** → 严格资源隔离、预取只在不影响反射的预算内、E312 设否决门槛；
2. **相关性估计滞后于漂移** → PLG 持续审计 + 相关性告警 + k_eff 保守下界，越界即退回单机 R69；
3. **远端建议「形式正确、语义错误」** → LCG 本地安全包络复核 + 出处链 + 证据纪律，远端永不直连执行器；
4. **新鲜度模型过于乐观** → 分布外延迟用保守分位数、过期一律丢弃、U_stale 进地板；
5. **共模故障伪装成独立共识** → 上游链路/训练数据血缘审计，共模检测与单点归因分开处理。

## 3. 关键算法伪代码

```python
# IP-264 EGM + IP-265 TVoI：按「到达概率 × 新鲜度 × 准确率」折算信息价值
class EvidenceMesh:
    def freshness(self, e, t): return math.exp(-(t - e.t) / self.tau_half)

def tvoi(g, n, modes, t, deadline, mesh):
    p_on_time = n.latency_dist(g).cdf(deadline - t)
    if p_on_time < P_MIN: return -math.inf
    dH = entropy(modes) - expected_entropy(modes, g, n)
    trust = 2 * n.accuracy - 1
    rho = mesh.freshness_at(n, t + n.latency_dist(g).mean())
    return p_on_time * rho * trust * dH - comm_cost(g, n) - priv_cost(g, n) - energy_cost(g, n)

def maybe_prefetch(z_t, horizon, cache, mesh, budget):
    p_amb = mode_head(z_t)
    if p_amb < TAU_PREFETCH: return
    for q in predict_future_queries(z_t, horizon):
        if p_amb * expected_tvoi(q) > prefetch_cost(q):
            cache.prefetch(q, deadline=horizon, budget=budget)

# IP-271 DFA：跨节点似然分歧，兼做第二意见与归因
def distributed_flow_anomaly(policy, xi, obs_by_node):
    s = {n: -policy.log_likelihood(xi, obs_by_node[n]) for n in obs_by_node}
    return max(s.values()) - min(s.values()), argmax(s)

# IP-274 主闭环：本地反射 + 异步 deliberation + 本地否决
def MESH_RAS_round(M, obs):
    # A. 本地硬实时反射（零网络，WCET 有界）
    z, o_loc = M.local_trunk(obs)
    U_ale, U_epi = M.local_estimate(z, o_loc)
    m_safe = M.local_reflex.conservative_mode(o_loc)
    # B. 异步 deliberation（可空/过期/分区）
    M.deliberator.submit(o_loc, z, deadline=M.vista.H)
    msg = M.deliberator.poll()
    # C. 本地认证门：远端只可建议，不可直连执行器
    ok = msg is not None and M.lcg.local_certify(msg.mode, msg.evidence, o_loc,
                                                 M.local_wm, M.mesh, M.ledger)
    m_exec, U_epi_after = (msg.mode, msg.U_epi_after) if ok else (m_safe, U_epi)
    U_stale = 0.0 if ok else M.mesh.stale_uncertainty(msg)
    # D. 及时/独立/可信才获得 resolution bonus，否则视同未消解
    U_floor = U_ale + (0.0 if ok else U_epi_after) + U_stale
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix_local(m_exec, ...)
    # E. 预取 / 账本 / 审计（异步，不阻塞控制）
    M.sph.maybe_prefetch(z, M.vista.H, M.cache, M.mesh, M.budget)
    M.ledger.append(msg)
    M.vqa_i.submit_async(msg, ok, U_stale)
    return k, lam, m_exec, (U_ale, U_epi_after, U_stale)
```

## 4. 推导

**引理 19（TVoI 截止单调性与锚定阈值）** TVoI 关于松弛 (d−t) 单调不增、关于期望老化单调不增，故存在 d*，`d−t<d*` 时锚定严格优于任何查询。系：交互越靠近决策点越值钱；预取使延迟分布一阶随机占优左移，提升 TVoI 但不突破锚定保守性；R69 的 VoI 是 `L≡0, ρ≡1` 退化。

**引理 20（有效正交拜占庭上界）** 错误采纳率 `≤ δ_p·ρ^{k_eff−1}+ε_σ`，`k_eff=(trΣ)²/tr(Σ²)`；容 f 个拜占庭需 `k_eff≥2f+1`，否则无确定性多数保证。系：多问几个共享训练数据的 agent，k_eff≈1，等于同一张嘴的复读。

**引理 21（跨节点 FMA 归因）** 节点 j 偏移 Δo_j 时，`a_score(o_j)−a_score(o_i) ≥ L_z‖Δo_j‖−√(trΣ_flow)`；两节点本地 r_res 均低而 Δa_ij 高 ⇒ 故障可归因到 {i,j} 的偏移侧；全网一致但普遍偏离本地似然 ⇒ 共模。R69 引理 17 的网格镜像。

**引理 22（预取收益与零安全损害）** 净收益 `=p_amb·(E[TVoI|预取]−E[TVoI|即查])−c_prefetch−p_expire·c_waste`；过期缓存被 LCG 丢弃并计入 U_stale，故预取不改变 λ_floor 下界——只改善时延，不放松安全。

**定理 18（MESH 严格包含 FLUID/R69）** 零延迟、ρ≡1、单节点、Σ=I、无分区时，TVoI→VoI、LCG 恒通过、BEC→R69 证据纪律、PDP 空操作，执行路径逐指令相同；在超时/过期/分区/低 k_eff 时，`λ_MESH ≥ λ_R69`。故期望风险 ≤ R69，安全侧不让步，效率侧获时效与并行收益。

**定理 19（网络无关安全与无突变）** 执行器指令只来自本地反射与 `certified_prefix_local`；远端建议必须过 LCG 的本地包络/新鲜度/出处/正交四重校验。故无论远端诚实、过时、被攻陷或分区，轨迹始终在本地认证安全集内；切换只在决策边界经前缀认证发生（延续 R69 定理 17），控制连续、无突变。**安全性不依赖网络与 agent 诚实性。**

**定理 20（退化单调性）** 分区/超时/出处失败/`k_eff<2f+1` 时，λ 单调不降、k 单调不增；恢复须先复验新鲜度与出处才允许 λ 下降。故无安全振荡，任意故障序列下不弱于冻结策略。

## 7. 本轮最大风险

**一句话**：MESH-RAS 的安全论证压在两个会被同一类资源竞争侵蚀的假设上——**本地反射的 WCET 永远守得住** 与 **跨 agent 的失效相关性估得准**；一旦热节流/电池降频/同租户抢占击穿本地实时保障，或共享训练数据的多个 agent 让 k_eff 被系统性高估，MESH 就会以更快速度、更自信口气执行一个由「同一张嘴多次复读」伪装成的共识——**分布式取证最大的危险不是问不到，而是以为问到了独立的多方**。

**次级风险与缓解**：本地 WCET 被抢占（资源隔离 + 预取不占反射预算 + E312 否决门槛）；相关性漂移滞后（PLG 持续审计 + 保守 k_eff 下界 + 越界退单机）；远端「形式正确、语义错误」（LCG 本地包络复核 + 出处链 + 证据纪律，永不直连执行器）；新鲜度模型过乐观（保守分位数 + 过期即弃 + U_stale 进地板）；共模伪装独立共识（上游链路与训练数据血缘审计，共模检测与单点归因分离）。
