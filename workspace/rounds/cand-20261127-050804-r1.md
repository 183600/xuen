### 第 1 轮灵感驱动研究记录（技术路线图 · 场景理解）

**灵感词**：技术路线图、场景理解

**直觉与动机**：
v24（USMC）已经把「感知-合规-能量-结构-力学」压成一条证书链，但它有两个从未写进类型的默认前提。第一，证书的操作数是「数字」——几何、能量、应力、力——而不是「意义」：门是通道还是玻璃、杯子是空的还是满的、物体是可抓取还是可支撑，这些语义事实不在证书里。第二，证书的版本演化是隐式的：v19 到 v24 的依赖关系散落在代码、论文和部署脚本中，没有一个可检查的路线图。于是出现两类新失效：(a) 数值上安全、语义上错误的计划，例如把玻璃门当通道、把空杯当满杯、把可抓取物当支撑面；(b) 能力上「越级」的部署，例如在没有 FCC 的平台上启用 LSC 的轻量化结果，或把只在标定 ODD 内验证的感知模型外推到新场景——证书链看似完整，实则某一环的依赖被静默跳过。

受「场景理解」启发：感知不应只输出坐标，而应输出一张带不确定性、可供性（affordance）与时序一致性的场景图；证书的语义操作数必须来自这张图，且图本身要带 conformal 覆盖与 OOD 弃权。受「技术路线图」启发：能力不是平铺的清单，而是一个带依赖边、成熟度（TRL）、认证域（ODD）与弃用状态的 DAG；任何计划都必须沿 DAG 做依赖闭包，且场景复杂度决定所需成熟度。

核心洞见：**场景理解是证书的「语义操作数」，技术路线图是证书的「依赖类型系统」。安全不是「每张证书各自通过」，而是「每个语义操作数都落在其使用能力的认证域内，且该能力在路线图中依赖闭合、成熟度足够、出处可验证」。** 因此 v25 不是再加一条更严的约束，而是给证书补上两个一直缺失的自变量：语义域（scene domain）与路线图出处（provenance）。

**形式化目标**：
1. 定义场景理解证书（SUC）：场景图 S=(O,R,A,U)，split-conformal 语义覆盖 P(Y∈C_α)≥1−α、OOD 弃权、可供性前置条件置信下界、时序图编辑距离约束。
2. 定义技术路线图证书（RMC）：能力 DAG R=(C,E,τ,D,v,status)，依赖闭包、TRL 门槛、版本单调、弃用/禁用检查与「无证书洗白」证明项。
3. 定义路线图-场景一致性（RSC）：S∈D_c、κ(S)≤κ_max(c)、τ(c)≥τ_req(κ(S),risk)，把场景复杂度与所需成熟度耦合，并把 SUC 的语义谓词桥接为 SOC/FCC/LSC/EVC 的语义前置条件。
4. 构建 v25 统一准入门（SRG）：Exec_v25=Exec_v24∩Fil_suc∩Fil_rmc∩Fil_rsc⊆Exec_v24，并给出最小修复路线规划器，使 fail-closed 之后仍可修复而非死锁。
5. 证明 SUC 的概率语义可靠性、RMC 的防静默回归性、RSC 的前置条件传递性，以及 v25 单调退化链的保持性。

**本轮最大风险（一句话）**：SUC 的 conformal 覆盖依赖标定与测试场景的可交换性，而 RMC 的 TRL 依赖组织自评；两者在长尾新场景中可能同时失真，使 v25 以「语义正确 + 路线图合规」的假象放行物理上不安全的计划。

## 0.1 技术路线图（能力 DAG）

技术路线图不是一张装饰性的甘特图，而是准入判定使用的**依赖类型**：节点是能力及其证书集，边是「使用该能力前必须已认证」的依赖，节点携带成熟度 τ、认证域 D_c、最大场景复杂度 κ_max 与弃用状态。

```text
c19 HPC-E+ 基座 ──► c20 云边一致性 ──► c21 少样本 conformal ──┐
      │                                                        ├──► c24 场景理解（SUC）──┐
      └──────────► c22 能量约束 ──► c23 结构-力学（SOC/FCC/LSC）┘                         ├──► c25 路线图-场景闭合（RMC/RSC/SRG）
                                                       └──────────────────────────────────┘
```

| 节点 | 能力 | 关键证书 | TRL（示例） | 认证域 D_c（摘要） |
|---|---|---|---|---|
| c19 | HPC-E+ 基座 | 几何∧规范∧负信息∧能量 | 9 | 平坦地面、已知负载、非接触富集任务 |
| c20 | 云边一致性 | CESC / FSVC | 8 | 网络延迟有界、版本可同步 |
| c21 | 少样本适应 | ACSC / DCSC | 7 | 标定类别覆盖内的新任务 |
| c22 | 能量约束 | EVC | 8 | 坡度 ≤10°、能量预算内 |
| c23 | 结构-力学 | SOC / FCC / LSC | 6 | 名义材料、载荷在 FEM 包络内、无损伤 |
| c24 | 场景理解 | SUC | 5 | κ(S)≤0.6、\|O\|≤50、可见度≥0.7、已知类别 |
| c25 | 路线图-场景闭合 | RMC / RSC / SRG | 4 | v25 全认证域 |

> TRL 与阈值均为可校准参数，不是本体论承诺；关键是它们被显式写入证书并可被审计，而不是藏在部署脚本里。

## 0.2 增量符号体系（定义 1100–1199）

| 符号 | 含义 |

| ρ ∈ [0,1] | 任务风险等级 |
| τ_req(κ,ρ) | 场景复杂度与风险要求的成熟度（对二者单调不减） |
| E ⊆ C×C | 能力依赖边；(c,c') 表示 c 依赖 c' |
| CertSet(c,v) | 能力 c 在版本 v 下保证的证书集合 |
| W_c | 版本升级时补偿被移除保证的 waiver（须附补偿证书） |
| GED(S,S') | 场景图编辑距离（近似匹配） |
| ε_t | 时序一致性允许的图编辑距离上界 |
| Fil_suc, Fil_rmc, Fil_rsc | 语义 / 路线图 / 域一致性过滤器 |
| Exec_v25 | 通过 SRG 验证的计划集合 |
| ζ_srg | ζ_usmc ∪ (S, C_α, κ, R, CertSet, provenance) |

**关键定义（场景复杂度）**：

$$
\kappa(S)=\mathrm{clip}\Big(w_1\frac{|O|}{N_{\mathrm{ref}}}+w_2(1-\mathrm{vis}(S))+w_3\frac{2|R|}{|O|(|O|-1)}+w_4\,\mathrm{nov}(S)+w_5\,\mathrm{dyn}(S),\,0,1\Big),
\quad \sum_i w_i=1.
$$

其中 vis 为可见度，nov 为场景嵌入到标定集的 kNN 新颖度，dyn 为高速度不确定对象占比。

**关键定义（成熟度需求，示例）**：

$$
\tau_{\mathrm{req}}(\kappa,\rho)=\mathrm{clip}\big(4+\lfloor 4\kappa+2\rho\rfloor,\,4,\,9\big).
$$

该函数对 κ 与 ρ 单调不减；任何满足单调性的校准表都可替换此式。

## 1. 关键算法骨架（在 IP-440–443 骨架上扩展）

```python
# ============================================================
# IP-444 Scene Understanding Certificate (SUC) — 场景理解证书
# ============================================================
@dataclass
class ObjectNode:
    label_set: frozenset[str]        # conformal 预测集 C_α(o)
    gt_label_prob: float             # 校准用：真实标签的模型概率
    pose: Tensor                     # [7] 位置+四元数
    visibility: float                # [0,1]
    embedding: Tensor                # [d] 语义嵌入
    alpha: float                     # 该对象的 conformal 水平


@dataclass
class SceneGraph:
    objects: list[ObjectNode]
    relations: Tensor                # [|O|,|O|] 关系置信度
    affordances: dict[tuple[int, str], float]
    affordances_lower: dict[tuple[int, str], float]  # 置信下界
    embedding: Tensor                # [d]
    timestamp: float
    novelty: float = 0.0

    def complexity(self, weights=(0.2, 0.2, 0.15, 0.3, 0.15)) -> float:
        w1, w2, w3, w4, w5 = weights
        n = max(1, len(self.objects))
        vis = sum(o.visibility for o in self.objects) / n
        rel_density = 2.0 * float((self.relations > 0.5).sum()) / (n * (n - 1) + 1e-9)
        dyn = sum(1 for o in self.objects if getattr(o, "dynamic_unc", 0.0) > 0.5) / n
        kappa = (w1 * min(n / 50.0, 1.0) + w2 * (1.0 - vis)
                 + w3 * min(rel_density, 1.0) + w4 * min(self.novelty, 1.0)
                 + w5 * dyn)
        return float(np.clip(kappa, 0.0, 1.0))


def conformal_quantile(scores: list[float], alpha: float) -> float:
    """split-conformal 的分位数：q = s_(⌈(n+1)(1−α)⌉)，越界取 +∞。"""
    n = len(scores)
    if n == 0:
        return float("inf")
    idx = int(np.ceil((n + 1) * (1.0 - alpha))) - 1
    if idx >= n:
        return float("inf")
    return float(np.sort(scores)[idx])


@dataclass
class SceneUnderstandingCertificate:
    scene: SceneGraph
    alpha: float = 0.05              # 总语义失败预算
    delta: float = 0.01              # 可供性总失败预算
    beta: float = 0.01               # OOD 弃权预算
    q_label: float = 0.0             # 标签 conformal 阈值
    q_ood: float = 0.0               # OOD 阈值
    epsilon_t: float = 0.25          # 时序图编辑距离上界
    alpha_o: float = 0.0             # 逐对象水平 = α/|O|
    delta_a: float = 0.0             # 逐可供性水平 = δ/K
    calibration_valid: bool = False
    calib_hash: str = ""

    # ---- 校准（离线）----
    @staticmethod
    def calibrate(calib_scenes: list[SceneGraph], alpha: float, beta: float,
                  delta: float, n_affordances: int) -> dict:
        max_objects = max(1, max(len(s.objects) for s in calib_scenes))
        alpha_o = alpha / max_objects
        label_scores = [1.0 - o.gt_label_prob
                        for s in calib_scenes for o in s.objects]
        ood_scores = [s.novelty for s in calib_scenes]
        return {
            "q_label": conformal_quantile(label_scores, alpha_o),
            "q_ood": conformal_quantile(ood_scores, beta),
            "alpha_o": alpha_o,
            "delta_a": delta / max(1, n_affordances),
        }

    # ---- 运行时验证 ----
    def verify_coverage(self) -> bool:
        """结构性检查：标定有效、每个对象有非空 conformal 集且水平正确。
        注意：覆盖保证是统计性的，不能在单帧运行时被“验证为真”；
        这里只检查证书是否具备产生该保证的结构条件。"""
        return (self.calibration_valid and
                all(o.label_set and abs(o.alpha - self.alpha_o) < 1e-9
                    for o in self.scene.objects))

    def verify_ood(self) -> bool:
        """OOD 弃权：新颖度超过标定分位数即拒绝，绝不外推。"""
        return self.scene.novelty <= self.q_ood + 1e-9

    def verify_affordances(self, required: set[tuple[int, str]]) -> bool:
        """计划所需的每个可供性都必须有足够高的置信下界。"""
        for key in required:
            if self.scene.affordances_lower.get(key, 0.0) < 1.0 - self.delta_a:
                return False
        return True

    def verify_temporal(self, prev: SceneGraph | None) -> bool:
        """时序一致性：场景图不能剧烈跳变，且时间戳单调。"""
        if prev is None:
            return True
        if self.scene.timestamp <= prev.timestamp:
            return False
        return approx_ged(self.scene, prev) <= self.epsilon_t

    def verify_all(self, required_affordances: set[tuple[int, str]],
                   prev: SceneGraph | None = None) -> bool:
        return (self.verify_ood() and
                self.verify_coverage() and
                self.verify_affordances(required_affordances) and
                self.verify_temporal(prev))

    # ---- 语义前置条件：桥接 v24 证书 ----
    def semantic_preconditions(self) -> dict[str, bool]:
        """把场景语义翻译为 SOC/FCC/LSC/EVC 的显式前提。"""
        return {
            "soc_load_in_envelope": self._mass_and_contact_within_fem_envelope(),
            "fcc_contact_in_domain": self._friction_and_geometry_in_calibration(),
            "lsc_no_damage": self._no_impact_or_damage_event(),
            "evc_terrain_in_domain": self._terrain_and_energy_in_domain(),
        }

    def _mass_and_contact_within_fem_envelope(self) -> bool:
        return all(o.label_set & {"heavy", "fragile", "person"} == set()
                   for o in self.scene.objects
                   if self.scene.affordances_lower.get((id(o), "contact"), 0.0) > 0.0)

    def _friction_and_geometry_in_calibration(self) -> bool:
        # 由场景图中的材质/表面语义给出摩擦下界；未知材质一律拒绝
        return all(self.scene.affordances_lower.get((i, "graspable"), 0.0)
                   >= 1.0 - self.delta_a
                   for i in range(len(self.scene.objects))
                   if self.scene.affordances_lower.get((i, "graspable"), 0.0) > 0.0)

    def _no_impact_or_damage_event(self) -> bool:
        return not any(getattr(o, "damage_suspected", False)
                       for o in self.scene.objects)

    def _terrain_and_energy_in_domain(self) -> bool:
        return self.scene.affordances_lower.get((-1, "traversable"), 1.0) >= 1.0 - self.delta_a


def approx_ged(a: SceneGraph, b: SceneGraph) -> float:
    """近似图编辑距离：匈牙利匹配对象嵌入 + 关系不匹配惩罚，O(n^3)。"""
    n, m = len(a.objects), len(b.objects)
    if n == 0 and m == 0:
        return 0.0
    cost = np.full((n, m), 1.0)
    for i, oa in enumerate(a.objects):
        for j, ob in enumerate(b.objects):
            cost[i, j] = float(torch.norm(oa.embedding - ob.embedding)) \
                         + (0.0 if oa.label_set & ob.label_set else 0.5)
    rows, cols = scipy.optimize.linear_sum_assignment(cost)
    matched = cost[rows, cols].sum() if len(rows) else 0.0
    return float(matched + abs(n - m))

# IP-445 Technology Roadmap Certificate (RMC) — 技术路线图证书
# ============================================================
@dataclass(frozen=True)
class Waiver:
    removed_certs: frozenset[str]
    compensating_certs: frozenset[str]
    verified: bool
    expires_at: float


@dataclass(frozen=True)
class CapabilityNode:
    name: str
    version: int
    trl: int
    deps: frozenset[str]
    domain: Callable[[SceneGraph], bool]
    kappa_max: float
    cert_set: frozenset[str]
    semantic_preconditions: Callable[[SceneGraph], dict[str, bool]]
    status: str = "active"           # active | deprecated | forbidden
    waiver: Waiver | None = None


@dataclass
class TechnologyRoadmapCertificate:
    nodes: dict[str, CapabilityNode]
    history: dict[tuple[str, int], frozenset[str]]  # (name, version) -> CertSet
    active: frozenset[str]
    risk: float
    provenance: dict[str, str]       # cert_hash -> capability name
    roadmap_hash: str

    def verify_dependency_closure(self) -> bool:
        """活动集在依赖边下向下封闭：用 c 必须已认证 c 的全部依赖。"""
        stack, seen = list(self.active), set(self.active)
        while stack:
            c = stack.pop()
            node = self.nodes.get(c)
            if node is None or node.status == "forbidden":
                return False
            for d in node.deps:
                if d not in self.nodes:
                    return False
                if d not in seen:
                    seen.add(d)
                    stack.append(d)
        # 依赖必须在活动集中（不是仅“存在”）
        return all(d in self.active for c in self.active
                   for d in self.nodes[c].deps)

    def verify_status(self) -> bool:
        for c in self.active:
            node = self.nodes[c]
            if node.status == "forbidden":
                return False
            if node.status == "deprecated":
                if node.waiver is None or not node.waiver.verified:
                    return False
        return True

    def verify_version_monotonicity(self) -> bool:
        """版本升级不得静默移除旧保证；移除必须有补偿证书。"""
        for name, node in self.nodes.items():
            if node.version <= 1:
                continue
            prev = self.history.get((name, node.version - 1))
            if prev is None:
                return False
            if node.cert_set >= prev:
                continue
            if node.waiver is None or not node.waiver.verified:
                return False
            if not (node.waiver.compensating_certs <= node.cert_set):
                return False
        return True

    def verify_trl(self, kappa: float) -> bool:
        req = tau_req(kappa, self.risk)
        return all(self.nodes[c].trl >= req for c in self.active)

    def verify_provenance(self, verified_certs: dict[str, bool]) -> bool:
        """每个被使用的证书都必须有签名出处，且归属于活动能力。"""
        for h, ok in verified_certs.items():
            if not ok or h not in self.provenance:
                return False
            if self.provenance[h] not in self.active:
                return False
        return True

    def verify_no_laundering(self, claim: "SafetyClaim") -> bool:
        """证明项中每个叶子必须是已验证证书；裸断言不构成保证。"""
        if claim.proof is None:
            return False
        return all(leaf.verified and leaf.cert_hash in self.provenance
                   for leaf in claim.proof.leaves)

    def verify_all(self, kappa: float,
                   verified_certs: dict[str, bool] | None = None,
                   claim: "SafetyClaim" | None = None) -> bool:
        ok = (self.verify_dependency_closure() and
              self.verify_status() and
              self.verify_version_monotonicity() and
              self.verify_trl(kappa))
        if verified_certs is not None:
            ok = ok and self.verify_provenance(verified_certs)
        if claim is not None:
            ok = ok and self.verify_no_laundering(claim)
        return ok

# IP-446 Roadmap-Scene Consistency (RSC) — 路线图-场景一致性
# ============================================================
@dataclass
class RoadmapSceneConsistency:
    def verify(self, scene: SceneGraph, suc: SceneUnderstandingCertificate,
               rmc: TechnologyRoadmapCertificate) -> bool:
        kappa = scene.complexity()
        suc_pre = suc.semantic_preconditions()
        for c in rmc.active:
            node = rmc.nodes[c]
            # (1) 场景必须落在能力的认证域内
            if not node.domain(scene):
                return False
            # (2) 场景复杂度不得超过该能力被认证的上界
            if kappa > node.kappa_max + 1e-9:
                return False
            # (3) 场景复杂度越高，要求的成熟度越高
            if node.trl < tau_req(kappa, rmc.risk):
                return False
            # (4) v24 证书的语义前置条件必须被 SUC 以保守下界支持
            node_pre = node.semantic_preconditions(scene)
            if not all(node_pre.values()):
                return False
            if not all(suc_pre.get(k, False) for k in node_pre):
                return False
        return True

# IP-447 Unified Semantic-Roadmap Gate (SRG / USMC-v25)
# ============================================================
@dataclass
class UnifiedSemanticRoadmapGate:
    v24: "UnifiedStructuralMechanicalCertificate"
    suc_factory: Callable[[SceneGraph], SceneUnderstandingCertificate]
    rsc: RoadmapSceneConsistency = field(default_factory=RoadmapSceneConsistency)

    def admits(self, plan, scene: SceneGraph, prev_scene: SceneGraph | None,
               rmc: TechnologyRoadmapCertificate,
               verified_certs: dict[str, bool],
               claim: "SafetyClaim",
               v24_args: tuple, v24_kwargs: dict) -> tuple[bool, dict]:
        # 1) 先过 v24：语义增强不得绕过既有物理/结构保证
        if not self.v24.admits(*v24_args, **v24_kwargs):
            return False, {"stage": "v24"}
        # 2) 语义证书
        suc = self.suc_factory(scene)
        if not suc.verify_all(plan.required_affordances, prev_scene):
            return False, {"stage": "suc", "kappa": scene.complexity()}
        # 3) 路线图证书
        kappa = scene.complexity()
        if not rmc.verify_all(kappa, verified_certs, claim):
            return False, {"stage": "rmc", "kappa": kappa}
        # 4) 域一致性
        if not self.rsc.verify(scene, suc, rmc):
            return False, {"stage": "rsc", "kappa": kappa}
        return True, {"stage": "admitted", "kappa": kappa,
                      "tau_req": tau_req(kappa, rmc.risk)}


def tau_req(kappa: float, risk: float) -> int:
    return int(np.clip(4 + np.floor(4.0 * kappa + 2.0 * risk), 4, 9))

# 最小修复路线规划器：fail-closed 之后仍可修复

@dataclass(frozen=True)
class RoadmapState:
    versions: tuple[tuple[str, int], ...]     # 可哈希的能力版本向量
    kappa_bucket: int                         # 复杂度分桶
    perception: tuple[str, ...]               # 已采取的主动感知动作
    waivers: frozenset[str]


@dataclass(frozen=True)
class RepairAction:
    kind: str                                 # perception | upgrade | waiver | fallback
    name: str
    cost: float
    apply: Callable[[RoadmapState], RoadmapState]


def plan_repair(initial: RoadmapState, actions: list[RepairAction],
                is_admissible: Callable[[RoadmapState], bool],
                max_states: int = 512) -> tuple[list[str], float] | None:
    """在有限修复动作图上做 Dijkstra，返回最小代价修复路线。"""
    import heapq
    pq, best, parent = [(0.0, initial)], {initial: 0.0}, {}
    while pq:
        cost, state = heapq.heappop(pq)
        if cost > best.get(state, float("inf")):
            continue
        if is_admissible(state):
            path, cur = [], state
            while cur != initial:
                prev, act = parent[cur]
                path.append(act)
                cur = prev
            return list(reversed(path)), cost
        if len(best) >= max_states:
            break
        for act in actions:
            nxt = act.apply(state)
            nc = cost + act.cost
            if nc < best.get(nxt, float("inf")):
                best[nxt] = nc
                parent[nxt] = (state, act.name)
                heapq.heappush(pq, (nc, nxt))
    return None
```

## 3. 正确性论证（增量）

### 引理 9（SUC 的概率语义可靠性）
**陈述**：设标定场景与测试场景可交换；对每个对象使用水平 1−α/|O| 的 split-conformal 标签集，对每个计划所需可供性使用水平 1−δ/K 的保守下界，OOD 弃权阈值为新颖度的 1−β 分位数。若 `SUC.verify_all` 通过（未弃权且所有断言通过），则计划所需全部语义断言同时为真的概率至少为 1−(α+δ+β)。

**证明**：由 split-conformal 的边际覆盖，单个对象标签遗漏概率 ≤α/|O|；对 |O| 个对象取联合界得 ≤α。单个可供性下界失效概率 ≤δ/K；对 K 个谓词取联合界得 ≤δ。OOD 弃权在 nov(S)>q_OOD 时拒绝，按分位数定义其触发概率 ≤β；未弃权时，剩余语义断言由前两项覆盖。三者取联合界即得 1−(α+δ+β)。∎

**诚实边界**：conformal 只给边际覆盖，不给条件覆盖；可交换性一旦被语义漂移破坏，上述保证退化为经验覆盖。因此 SUC 必须把 OOD 弃权当作硬门，而不是可调启发式。

### 引理 10（RMC 的依赖闭包与防静默回归）
**陈述**：若 `RMC.verify_all` 通过，则活动能力集在 E 下向下封闭；对每个能力 c，其版本升级要么满足 CertSet(c,v_c) ⊇ CertSet(c,v_c−1)，要么附带已验证且补偿证书被包含的 waiver。因此不存在「删掉依赖或旧保证却仍声称原保证」的静默回归。

**证明**：依赖闭包由 DFS 与「依赖必须在活动集中」的二次检查保证；版本单调由逐节点比较 CertSet 与 waiver 补偿证书包含关系保证；状态检查排除 forbidden 与无 waiver 的 deprecated。对任意安全声明 σ，其证明项的叶子必须是已验证证书（`verify_no_laundering`），由 DAG 无环性沿依赖边拓扑归纳，所有叶证书的保证可传递到根，且没有任何节点被跳过。∎

### 引理 11（RSC 的语义前置条件传递）
**陈述**：若 `RSC.verify` 通过，则对每个活动能力 c，有 S∈D_c、κ(S)≤κ_max(c)、τ(c)≥τ_req(κ,ρ)，且 A_c(S) 成立（A_c 为该能力对应的 SOC/FCC/LSC/EVC 语义前置条件）。因此 v24 各证书的数值验证是在其语义前提成立的工况点上执行的。

**证明**：RSC 是上述四个条件的逐能力合取。A_c(S) 由能力节点的 `semantic_preconditions` 给出，并要求 SUC 的对应谓词同时为真；SUC 谓词以置信下界形式给出（引理 9），故不会把「未知」误判为「成立」。由合取消除直接得到结论。∎

### 引理 12（v25 单调退化链保持）
**陈述**：`Exec_v25 ⊆ Exec_v24`，且在 SUC 失败、RMC 失败、RSC 失败及其任意组合下保持。

**证明**：由定义 `Exec_v25 = Exec_v24 ∩ Fil_suc ∩ Fil_rmc ∩ Fil_rsc`，集合交直接给出包含关系。任一过滤器失败时 SRG 拒绝；拒绝后的保守回退是 `Exec_v24`（或修复规划器选择的 `Exec_v24` 子集），不引入新的执行计划。组合失效取交集，交集保持单调性；继续向下退化由引理 4、8 保证。∎

### 定理（SRG 的语义-路线图完备性）
**陈述**：在证书语义（含 SUC 的概率保证）下，`SRG.admits(π)=True` 当且仅当 π 同时满足：
(1) v24 的物理接地安全、云边一致性、少样本覆盖、专利保护、结构-力学三重保证；
(2) SUC 的语义覆盖、OOD 未弃权、可供性下界、时序一致性；
(3) RMC 的依赖闭包、状态合法、版本单调、TRL 足够、出处可验证；
(4) RSC 的域包含、复杂度上界、成熟度匹配、语义前置条件成立。

**证明**：必要性：`admits` 是四段短路合取，任一为假即拒绝，对应一类未被缓解的风险。充分性：四段全真时，由引理 9–11 得语义断言可靠、路线图无静默回归、v24 证书前提成立；由引理 12 得执行集单调退化；由 v24 定理得物理/合规/结构保证。合取即完备。∎
