# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC：SSM×CIEC×EPIR×SERC×PCE++++；灵感循环第 1 轮；本轮灵感：「协同控制」×「基线复现」）

> 第 60 轮把「执行层→证据层」升级为「认知驱动的场景-执行闭环」，但**三个结构性隐患**被进一步放大：
> 1. **控制的串行幻觉**：SERC 的 ①–⑪ 步是一个**顺序编排**——场景识别完才编译阻抗、意图接收完才锁定约束、执行完才写 EPIR。现实中这些环节是**并发的、异时间尺度的**：安全治理器必须在 1 kHz 响应，场景识别只有 10 Hz，意图解析可能延迟 300 ms。顺序编排在跨尺度扰动下会「用慢环的结论去约束快环」，形成**控制时序倒置**。
> 2. **多控制器缺乏协同契约**：SSM、CIEC、ERTC、EEIS、EPIR 各自维护约束集，第 60 轮的 SIC 只是「三元与校验」，并未回答：当场景先验要求「低 K_p」、意图要求「高 K_d」、安全要求「F ≤ F_safe」时，**谁有权否决谁**？缺少**权威偏序 + 安全否决**的协同仲裁，多个正确模块可以组合出错误行为。
> 3. **跨轮基线不可复现**：本轮已是第 61 轮、定义 160 条、实验 E1–E191，但所有「ΔECE ≥ 20%」「τ_response ≤ 500 ms」都是**相对上一轮记忆中的数字**，而非**可复现基线的重放结果**。一旦代码、随机种子、ROS 版本、传感器标定漂移，所谓「改进」可能只是**基线漂移的假象**。这是整条研究链最大的方法论漏洞：**结论的置信度增长快于其可复现性**。

## 0. 直觉与动机

**灵感 1（协同控制 → 协同控制图 CCG）**
直觉：把控制栈看成一个**异质多智能体网络**，而不是一条流水线。安全治理器是「领导者（leader）」，阻抗/场景/意图/证据是「跟随者（follower）」，它们通过共享变量（K、预算、约束域）耦合，各自有不同的时间常数 τ 和信息集。关键洞见：**协同不是平均，而是「权威偏序下的共识」**——安全性 ≻ 意图 ≻ 场景 ≻ 性能。只要安全智能体拥有**否决权（veto）**，其余智能体可以自由地并行协商。

**灵感 2（协同控制 → 安全过滤共识 SCC）**
直觉：让所有智能体先自由提出自己的期望控制量 u_i，再由安全治理器用一个 **CBF-QP 安全滤波器**把共识结果投影回安全集：u* = argmin ‖u − ū‖²_W s.t. 控制屏障函数约束。关键洞见：**协同的价值不在于让所有人达成一致，而在于让分歧发生在一个被证明安全的不变集内**。若安全集为空，才触发降级，而不是先执行再发现冲突。

**灵感 3（基线复现 → 基线复现契约 BRC）**
直觉：科学上的「基线复现」不是重跑一遍看数字像不像，而是**冻结配置 + 预注册指标 + 等价性检验**。把基线冻结为 BRC =（baseline_id, Θ₀, seeds, metrics, ε, env_hash），复现算子输出「通过/不通过」。关键洞见：**只有基线被复现，新的机制才获得「宣称权（claim right）」**——否则新机制的收益无法与「环境漂移」区分。

**灵感 4（基线复现 → 复现门 RG 与漂移检测 BDD）**
直觉：把复现门设计成研究循环里的「安全治理器」：创新智能体提出机制，复现智能体拥有**否决权**。用 TOST 等价检验（差值置信区间落在 ±ε 内）判定基线复现，用最小可检测效应（MDE）+ 统计功效来判定改进是否可信。再用 Page-Hinkley/CUSUM **在线检测基线漂移**；一旦漂移，跨轮比较被标记为「不可通约（non-commensurable）」，而不是悄悄放宽 ε。关键洞见：**漂移应当被当作数据，而不是被当作失败去调参掩盖**。

**灵感 5（双尺度合流 → 协同复现闭环 CRL 与 PCE+++++）**
直觉：微观层是「控制器之间的协同控制」，宏观层是「创新与研究复现之间的协同控制」——两者结构同构：**都有一个安全/复现的否决者，都有权威偏序，都要在预算下达成共识**。于是把第 60 轮的认知预算扩展为 **B_coop（协同开销）/B_repro（复现开销）**：协同预算耗尽⇒退回串行 SERC；复现预算耗尽⇒仅允许「冻结基线内」的保守改进；检测到漂移⇒旧结论降级为「待复现假设」。形成闭环：**冻结基线→复现门→协同仲裁→执行→证据→漂移检测→重新冻结**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（协同控制图 CCG）** 协同控制图 G_c = (V, E, A, τ, ≻)。其中：
- **智能体集** V = {g_s, g_K, g_π, g_I, g_E}：分别对应安全治理、阻抗编译、场景识别、意图解析、证据同步。
- **耦合边** E ⊆ V×V：边 (i,j) 表示 j 的决策依赖 i 的输出（如 g_K 依赖 g_π 的场景先验）。
- **权威矩阵** A ∈ [0,1]^{|V|×|V|}：A_ij 表示 i 对 j 的否决强度；安全治理行满足 ∀j, A_{g_s,j} = 1（完全否决）。
- **时间尺度向量** τ = (τ_s, τ_K, τ_π, τ_I, τ_E)，满足 τ_s ≪ τ_K ≪ τ_I ≪ τ_π ≪ τ_E（安全最快、证据最慢）。
- **权威偏序** ≻：g_s ≻ g_I ≻ g_π ≻ g_K ≻ g_E，用于冲突消解；偏序必须无环，否则拒绝进入协同模式。

**定义 162（安全过滤协同共识 SCC）** 给定各智能体的期望控制量 {u_i}、权重 {w_ij} 与安全集 S_safe = {x | h(x) ≥ 0}，协同算子：
```
ū = Σ_j w_ij·u_j / Σ_j w_ij            # 加权共识（跟随者）
u* = argmin_u ‖u − ū‖²_W + ρ‖u − u_s‖²  # 向安全智能体轻微正则
     s.t.  L_f h(x) + L_g h(x)·u + α·h(x) ≥ 0   # 离散/连续 CBF 约束
           u ∈ U,  L_authority(x, u) ≥ 0        # 权威偏序约束
```
若可行集为空，则不执行「软折中」，而是返回 DEGRADE_SAFE（保持上一安全控制量 u_s 并冻结 K 更新）。协同正确性要求：**任何跟随者的更新都不能使 h(x) 的零上水平集被突破**。

**定义 163（基线复现契约 BRC）** BRC = (id, Θ₀, S_seed, M, ε, H_env)。其中：
- **冻结配置** Θ₀：代码提交哈希、依赖版本、ROS 发行版、控制器参数、标定文件哈希。
- **种子集** S_seed：预注册的 K 个随机种子（含至少 1 个 held-out 种子）。
- **指标向量** M = (m₁, ..., m_q)：如 ECE、D⁺、τ_response、证据链完整性。
- **等价边界** ε：每个指标的预注册等价区间（不是事后挑选）。
- **环境指纹** H_env：机器型号、驱动、负载、时钟源。
- **复现算子** Repro(BRC) → (M̂, pass, δ)：在 Θ₀、S_seed 下重放，计算 M̂ 与冻结基线 M₀ 的差 δ，用 TOST 判定 δ 是否落在 ±ε 内。

**定义 164（复现门 RG）** 复现门是研究循环的准入算子：
```
RG(m, BRC, Δ_min, α, β) =
  ADMIT        if Repro(BRC).pass ∧ CI_{1-α}(δ_m) 下界 > Δ_min ∧ power ≥ 1-β
  REJECT       if Repro(BRC).pass ∧ CI_{1-α}(δ_m) 上界 ≤ Δ_min
  INCONCLUSIVE if ¬Repro(BRC).pass ∨ 功效不足
```
只有 ADMIT 的机制才获得「宣称权」；INCONCLUSIVE 的机制进入**隔离队列**而非被当作成功。RG 的判据必须在看结果前预注册（否则等价于 p-hacking）。

**定义 165（基线漂移检测器 BDD）** 对基线指标的滚动序列 {m_t} 运行 Page-Hinkley 统计量：
```
PH_t = Σ_{k=1..t} (m_k − m̄_ref − θ_drift)
drift  ⇔ max_t PH_t − PH_t > λ_drift
```
检测到漂移时，标记本轮跨轮比较为 `NON_COMMENSURABLE`，并生成「基线重冻结」请求；**禁止**通过调大 ε 或更换种子来让复现「通过」。

**定义 166（协同复现闭环 CRL）** 算子 CRL(M, BRC, mechanism, scene, intent)：
```
① freeze: (Θ₀, S_seed, M₀, H_env) ← BRC.load_or_create()
② repro:  pass ← RG.precheck(Repro(BRC))          # 复现门先于创新
③ if ¬pass: return QUARANTINE(mechanism); log NON_COMMENSURABLE
④ ccg:    G_c ← build_cooperative_graph(M); assert acyclic(≻) and τ ordered
⑤ scc:    u* ← safety_filtered_consensus(G_c, M.state)
⑥ exec:   telemetry ← execute(u*); EV-exec ← build_exec_evidence(telemetry)
⑦ evid:   EPIR.append(EV-exec); S_sync.push()
⑧ drift:  BDD.update(M̂); if drift: request_refreeze(); invalidate cross-round claims
⑨ gate:   verdict ← RG.evaluate(mechanism, δ_m)
⑩ return (verdict, u*, EV-exec, BRC.status, G_c.health)
```

**定义 167（协同-复现预算 B_coop 与 PCE+++++）** PCE 预算五维化：
```
B_plus = (B_coop, B_repro, B_scene, B_intent, B_exec)
B_coop  = (Consensus_iters, Authority_check_ops, Sync_slack)
B_repro = (Seed_runs, Replay_hours, Env_rebuild_budget)
```
协同成本与复现成本：
```
cost_coop  = λ_c·Consensus_iters + λ_a·Authority_check_ops
cost_repro = λ_r·Seed_runs + λ_e·Env_rebuild_budget
voi_repro(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_coop(π) − cost_repro(π) − cost_exec(π)
```
降级策略：B_coop 耗尽⇒退回串行 SERC（放弃并行协同，保安全）；B_repro 耗尽⇒只允许「冻结基线内」的零成本改进（禁止新机制宣称）；B_scene/B_intent 耗尽⇒沿用第 60 轮策略；B_exec 耗尽⇒原有降级。

**定义 168（宣称账本与复现证书 CL/BRC-Cert）** 跨轮保留的**单一事实源**：
- **宣称账本** L_claim = {(claim_id, mechanism, baseline_id, δ_m, CI, verdict, BRC_hash, timestamp)}；任何跨轮「改进」必须能在 L_claim 中追溯到一条 ADMIT 记录。
- **复现证书** Cert_repro = (BRC_hash, S_seed, M̂, δ, pass, H_env_hash, signature)；无证书的实验数字只可作为「观察」，不可作为「结论」。
- **不可通约标记**：若 BRC_hash 或 H_env_hash 变化且未重冻结，则旧 L_claim 自动降级为 `STALE`。

## 2. 关键算法伪代码

### IP-161 CCG（协同控制图）

```python
class CooperativeControlGraph:
    def __init__(self, agents, tau, authority_order):
        self.agents = agents                      # {name: agent}
        self.tau = tau                            # timescales
        self.order = authority_order              # ['g_s','g_I','g_π','g_K','g_E']
        self.edges = self._build_edges()
        self._assert_acyclic()
        self._assert_timescale_separated()

    def _assert_timescale_separated(self, ratio=5.0):
        taus = [self.tau[a] for a in self.order]
        for fast, slow in zip(taus, taus[1:]):
            assert slow >= ratio * fast, "timescale inversion"

    def _assert_acyclic(self):
        # 权威偏序必须无环，否则协同仲裁无解
        dag = {a: set() for a in self.order}
        for i, hi in enumerate(self.order):
            for lo in self.order[i+1:]:
                dag[hi].add(lo)
        assert not self._has_cycle(dag), "authority order has cycle"

    def collect_proposals(self, state):
        return {a: self.agents[a].propose(state) for a in self.order}

    def authority_filter(self, proposals):
        # 高权威约束先落地，低权威只能在剩余可行域内优化
        feasible = self.agents['g_s'].safe_set(state)
        for a in self.order[1:]:
            feasible = feasible & self.agents[a].constraint_set(proposals[a])
            if feasible.is_empty():
                return None, a                 # 冲突源可定位，便于审计
        return feasible, None
```

### IP-162 SCC（安全过滤共识）

```python
def safety_filtered_consensus(graph, state, W, alpha=1.0, rho=0.1):
    proposals = graph.collect_proposals(state)
    feasible, blocker = graph.authority_filter(proposals)
    if feasible is None:
        # 不软折中：保持上一安全控制量并冻结参数更新
        return DEGRADE_SAFE(blocker=blocker, u=state.last_safe_u)

    u_bar = weighted_mean(proposals, W)
    u_s = graph.agents['g_s'].propose(state)
    # min ‖u−ū‖²_W + ρ‖u−u_s‖² s.t. CBF + authority + box
    u_star = solve_qp(
        H=W + rho * np.eye(len(u_bar)),
        f=-(W @ u_bar + rho * u_s),
        cbf=_cbf_rows(state),          # L_f h + L_g h u + α h ≥ 0
        authority=graph.authority_constraints(state),
        box=graph.actuation_limits(),
    )
    if u_star is None:
        return DEGRADE_SAFE(blocker='cbf_infeasible', u=state.last_safe_u)
    assert cbf_value(state, u_star) >= -1e-9   # 安全不变性硬校验
    return u_star
```

### IP-163 BRC（基线复现器）

```python
@dataclass(frozen=True)
class BaselineReproductionContract:
    id: str
    config_hash: str
    seeds: tuple
    metrics: tuple
    epsilon: dict                # 预注册等价边界
    env_hash: str

def reproduce(brc, baseline_metrics, run_fn, alpha=0.05):
    results = []
    for seed in brc.seeds:                       # 含 held-out 种子
        with frozen_config(brc.config_hash, brc.env_hash):
            results.append(run_fn(seed))
    m_hat = aggregate(results)
    delta = {m: m_hat[m] - baseline_metrics[m] for m in brc.metrics}
    cert = {'brc_hash': hash_brc(brc), 'env_hash': brc.env_hash,
            'delta': delta, 'ci': {}}
    passed = True
    for m in brc.metrics:
        lo, hi = bootstrap_ci([r[m] for r in results], alpha)
        d_lo, d_hi = lo - baseline_metrics[m], hi - baseline_metrics[m]
        cert['ci'][m] = (d_lo, d_hi)
        # TOST：整个 CI 落在 ±ε 内才算等价
        passed &= (d_lo > -brc.epsilon[m]) and (d_hi < brc.epsilon[m])
    cert['pass'] = bool(passed)
    return m_hat, cert
```

### IP-164 RG（复现门）

```python
def reproduction_gate(mechanism_delta, brc_cert, delta_min, alpha, beta):
    if not brc_cert['pass']:
        return 'INCONCLUSIVE', 'baseline_not_reproduced'
    lo = min(ci[0] for ci in mechanism_delta.values())
    hi = max(ci[1] for ci in mechanism_delta.values())
    power = estimate_power(mechanism_delta, delta_min, alpha)
    if lo > delta_min and power >= 1 - beta:
        return 'ADMIT', None
    if hi <= delta_min:
        return 'REJECT', 'effect_below_minimum_detectable'
    return 'INCONCLUSIVE', 'underpowered'   # 不许把功效不足当成功
```

### IP-165 BDD（基线漂移检测）

```python
class BaselineDriftDetector:
    def __init__(self, ref_mean, theta=0.05, lam=8.0):
        self.ref_mean, self.theta, self.lam = ref_mean, theta, lam
        self.ph, self.ph_max = 0.0, -np.inf

    def update(self, metric):
        self.ph += (metric - self.ref_mean - self.theta)
        self.ph_max = max(self.ph_max, self.ph)
        if self.ph_max - self.ph > self.lam:
            return 'DRIFT'                  # 触发重冻结，而非放宽 ε
        return 'OK'

def on_drift(ledger):
    for claim in ledger:
        claim.status = 'STALE'              # 旧结论降级为待复现假设
    request_refreeze_baseline()
```

### IP-166 CRL（协同复现闭环）

```python
def cooperative_reproduction_loop(M, brc, mechanism, state):
    m_hat, cert = reproduce(brc, M.baseline_metrics, M.run_fn)
    if not cert['pass']:
        return 'QUARANTINE', cert           # 复现门先于创新

    graph = CooperativeControlGraph(M.agents, M.tau, M.authority_order)
    u_star = safety_filtered_consensus(graph, state, M.weights)
    if isinstance(u_star, DegradeSafe):
        return 'DEGRADE_SAFE', u_star

    telemetry = execute(u_star)
    ev = build_exec_evidence(telemetry)
    M.epir.append(ev); M.sync.push()

    if M.bdd.update(m_hat['ece']) == 'DRIFT':
        on_drift(M.claim_ledger)
        return 'NON_COMMENSURABLE', cert

    verdict, why = reproduction_gate(M.effect(m_hat), cert,
                                     M.delta_min, M.alpha, M.beta)
    M.claim_ledger.append(Claim(mechanism, brc.id, m_hat, verdict, cert))
    return verdict, (u_star, ev, cert)
```

### IP-167 PCE+++++（协同-复现预算）

```python
class CooperativeReproductionBudget:
    def __init__(self, B_coop, B_repro, B_scene, B_intent, B_exec):
        self.B = dict(coop=B_coop, repro=B_repro,
                      scene=B_scene, intent=B_intent, exec=B_exec)

    def mode(self):
        if self.B['repro'] <= 0:
            return 'FROZEN_BASELINE_ONLY'  # 无新宣称，仅复现
        if self.B['coop'] <= 0:
            return 'SERIAL_SERC'           # 放弃并行协同，保安全
        if self.B['scene'] <= 0:
            return 'GENERAL_SCENE_PRIOR'
        if self.B['intent'] <= 0:
            return 'DEFAULT_CONSTRAINTS'
        return 'NORMAL'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CCG | O(|V|²) 构建/轮 | O(|V|²) | 权威偏序无环；时间尺度分离比 ≥ 5 |
| SCC | QP 多项式时间，控制周期内 ≤ 1 ms | O(|u|²) | CBF 硬校验；不可行即 DEGRADE_SAFE |
| BRC | O(K·run_cost)，K 个种子 | O(K·q) | TOST 等价；held-out 种子防过拟合 |
| RG | O(K) 统计 | O(K) | 假宣称率 ≤ α；功效 ≥ 1−β |
| BDD | O(1)/样本 | O(1) | 漂移触发即标记不可通约 |
| CRL | O(复现 + 闭环) | 复用 | 复现门先于创新；证书可追溯 |

**正确性定理（RCCL）**：
假设 A66–A70 成立：**(A66)** 安全集 S_safe 非空且初始状态 h(x₀) ≥ 0，权威偏序 ≻ 无环、g_s 拥有完全否决权；**(A67)** 时间尺度分离满足 τ_s ≪ τ_K ≪ τ_I ≪ τ_π ≪ τ_E，且在分离比下共识算子为压缩映射；**(A68)** 在冻结 Θ₀、H_env 下重放同一基线无真实变化时，指标差 δ 的 1−α 置信区间以概率 ≥ 1−α 落在 ±ε 内；**(A69)** 复现门的 TOST+功效分析使假宣称率 ≤ α，且在效应 ≥ Δ_min 时功效 ≥ 1−β；**(A70)** Page-Hinkley 检测器在无漂移时每 N 轮的误报率 ≤ γ。

则：
1. **协同安全性**：若初始 h(x₀) ≥ 0 且 CBF-QP 可行，则对任意跟随者提议，SCC 输出 u* 使 h(x_t) ≥ 0 对所有 t 成立（前向不变性）；不可行时保持上一安全量，不产生更差行为。
2. **权威一致性**：安全否决不会被任何低权威智能体的共识平均稀释；冲突源可被 `authority_filter` 定位审计。
3. **宣称有效性**：任一进入 L_claim 的 ADMIT 记录，其效果量均相对**已复现基线**报告，假宣称率 ≤ α。
4. **可通约性**：检测到漂移后，旧宣称自动降级为 STALE，跨轮比较不再被当作有效证据。
5. **预算安全性**：B_repro/B_coop 任一耗尽均触发保守降级，绝不「借未来预算」维持协同。

## 4. 实验设计 E192–E196

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 CCG/SCC | 协同仲裁延迟；CBF 违反次数；不可行降级率 | 延迟 < 1 ms；违反 = 0；降级 < 1% |
| E193 BRC | 基线复现通过率；指标偏差 δ 分布（多机器/多种子） | 通过率 ≥ 95%；δ 落在 ±3% 内 |
| E194 RG | 零效应下的假宣称率；真实效应下功效 | 假宣称 ≤ 5%；功效 ≥ 80% |
| E195 BDD | 漂移检测延迟；误报率 | 延迟 ≤ 50 样本；误报 ≤ 1/1000 |
| E196 端到端 | 先复现第 59/60 轮基线，再评估 RCCL；协同开销；证书覆盖率 | 基线可复现；开销 < 10% WCET；证书覆盖 100% 的 ADMIT |

**关键实验纪律**：E193/E194 的种子、等价边界 ε、Δ_min 必须**在看结果前预注册**；E196 的对照必须是「重放出来的基线」，不是「上一轮记录的数字」。若第 59/60 轮基线本身无法复现，则本轮的首要产物不是新机制，而是**对旧结论的降级清单**。

## 5. 本轮最大风险

**一句话**：复现门可能被「复现剧场（reproduction theater）」架空——即在看到结果后悄悄调大 ε、挑选种子或只报告通过的子集，使 160 条定义的巨塔看起来越来越严谨、实则越来越不可证伪；必须以「预注册 BRC + held-out 种子 + 漂移即降级、绝不放宽 ε + 宣称账本强制追溯」四重约束，确保复现门否决的是幻觉，而不是被幻觉说服。

> 本轮结论：把「协同控制」从控制器内部扩展到研究过程本身，得到双尺度同构的 RCCL；其真正贡献或许不是又一层控制，而是让前面 60 轮的结论第一次**可被自己推翻**。

## 2. 关键算法伪代码

### IP-161 CCG（协同控制图）

```python
class CooperativeControlGraph:
    def __init__(self, agents, tau, authority_order):
        self.agents, self.tau, self.order = agents, tau, authority_order
        self._assert_acyclic()
        self._assert_timescale_separated()

    def _assert_timescale_separated(self, ratio=5.0):
        taus = [self.tau[a] for a in self.order]
        for fast, slow in zip(taus, taus[1:]):
            assert slow >= ratio * fast, "timescale inversion"

    def _assert_acyclic(self):
        # 权威偏序无环，否则协同仲裁无解
        assert not has_cycle(self.order), "authority order has cycle"

    def collect_proposals(self, state):
        return {a: self.agents[a].propose(state) for a in self.order}

    def authority_filter(self, proposals, state):
        feasible = self.agents['g_s'].safe_set(state)
        for a in self.order[1:]:                    # 安全优先，其余在剩余可行域
            feasible &= self.agents[a].constraint_set(proposals[a])
            if feasible.is_empty():
                return None, a                      # 冲突源可审计
        return feasible, None
```

### IP-162 SCC（安全过滤共识）

```python
def safety_filtered_consensus(graph, state, W, alpha=1.0, rho=0.1):
    proposals = graph.collect_proposals(state)
    feasible, blocker = graph.authority_filter(proposals, state)
    if feasible is None:
        return DEGRADE_SAFE(blocker=blocker, u=state.last_safe_u)

    u_bar = weighted_mean(proposals, W)
    u_s = proposals['g_s']
    u_star = solve_qp(
        H=W + rho * np.eye(len(u_bar)),
        f=-(W @ u_bar + rho * u_s),
        cbf=_cbf_rows(state),                   # L_f h + L_g h u + α h ≥ 0
        authority=graph.authority_constraints(state),
        box=graph.actuation_limits(),
    )
    if u_star is None:
        return DEGRADE_SAFE(blocker='cbf_infeasible', u=state.last_safe_u)
    assert cbf_value(state, u_star) >= -1e-9    # 安全不变性硬校验
    return u_star
```

### IP-163 BRC（基线复现器）

```python
def reproduce(brc, baseline_metrics, run_fn, alpha=0.05):
    results = [run_fn(seed) for seed in brc.seeds]   # 含 held-out 种子
    m_hat = aggregate(results)
    delta = {m: m_hat[m] - baseline_metrics[m] for m in brc.metrics}
    cert = {'brc_hash': hash_brc(brc), 'env_hash': brc.env_hash,
            'delta': delta, 'ci': {}}
    passed = True
    for m in brc.metrics:
        lo, hi = bootstrap_ci([r[m] for r in results], alpha)
        d_lo, d_hi = lo - baseline_metrics[m], hi - baseline_metrics[m]
        cert['ci'][m] = (d_lo, d_hi)
        passed &= (d_lo > -brc.epsilon[m]) and (d_hi < brc.epsilon[m])  # TOST
    cert['pass'] = bool(passed)
    return m_hat, cert
```

### IP-164 RG（复现门）

```python
def reproduction_gate(mechanism_delta, brc_cert, delta_min, alpha, beta):
    if not brc_cert['pass']:
        return 'INCONCLUSIVE', 'baseline_not_reproduced'
    lo = min(ci[0] for ci in mechanism_delta.values())
    hi = max(ci[1] for ci in mechanism_delta.values())
    power = estimate_power(mechanism_delta, delta_min, alpha)
    if lo > delta_min and power >= 1 - beta:
        return 'ADMIT', None
    if hi <= delta_min:
        return 'REJECT', 'effect_below_minimum_detectable'
    return 'INCONCLUSIVE', 'underpowered'
```

### IP-165 BDD（基线漂移检测）

```python
class BaselineDriftDetector:
    def __init__(self, ref_mean, theta=0.05, lam=8.0):
        self.ref_mean, self.theta, self.lam = ref_mean, theta, lam
        self.ph = 0.0
        self.ph_max = -np.inf

    def update(self, metric):
        self.ph += (metric - self.ref_mean - self.theta)
        self.ph_max = max(self.ph_max, self.ph)
        return 'DRIFT' if self.ph_max - self.ph > self.lam else 'OK'

def on_drift(ledger):
    for claim in ledger:
        claim.status = 'STALE'        # 旧结论降级为待复现假设
    request_refreeze_baseline()       # 绝不通过放宽 ε 来让复现通过
```

### IP-166 CRL（协同复现闭环）

```python
def cooperative_reproduction_loop(M, brc, mechanism, state):
    m_hat, cert = reproduce(brc, M.baseline_metrics, M.run_fn)
    if not cert['pass']:
        return 'QUARANTINE', cert                     # 复现门先于创新

    graph = CooperativeControlGraph(M.agents, M.tau, M.authority_order)
    u_star = safety_filtered_consensus(graph, state, M.weights)
    if isinstance(u_star, DegradeSafe):
        return 'DEGRADE_SAFE', u_star

    telemetry = execute(u_star)
    ev = build_exec_evidence(telemetry)
    M.epir.append(ev)
    M.sync.push()

    if M.bdd.update(m_hat['ece']) == 'DRIFT':
        on_drift(M.claim_ledger)
        return 'NON_COMMENSURABLE', cert

    verdict, why = reproduction_gate(M.effect(m_hat), cert,
                                     M.delta_min, M.alpha, M.beta)
    M.claim_ledger.append(Claim(mechanism, brc.id, m_hat, verdict, cert))
    return verdict, (u_star, ev, cert)
```

**正确性定理（RCCL）**：
若 A66–A70 成立（安全集非空且权威偏序无环、时间尺度分离且共识压缩、冻结配置下基线可等价复现、复现门假宣称率 ≤ α 且功效足够、漂移误报受控），则：
1. **协同安全性**：CBF-QP 可行时 h(x_t) ≥ 0 前向不变；不可行时保持上一安全控制量，不产生更差行为。
2. **权威一致性**：安全否决不被共识平均稀释；冲突源可由 `authority_filter` 定位审计。
3. **宣称有效性**：所有 ADMIT 的效果量相对已复现基线报告，假宣称率 ≤ α。
4. **可通约性**：漂移或环境指纹变化触发 STALE，跨轮结论不再被当作有效证据。
5. **预算安全性**：B_repro/B_coop 任一耗尽都保守降级，绝不透支未来预算维持协同。
