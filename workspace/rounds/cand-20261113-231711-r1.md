# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「平衡控制」×「演示方案」）

> R69 把不确定性拆成 aleatoric / epistemic，并让系统学会「看、问、触」去主动消解后者。它在漂亮的二分之下偷偷记了两笔**假账**：
> - **(a) 交互是可以在时间轴上"暂停"插入的无息支出**。安全裕度被当成一个可以预先划拨的标量预算，「单位时间 ≤1 次交互」被当作约束；默认系统随时能站定、想清楚再动。
> - **(b) 支撑分辨率红利（resolution bonus）的证据是普适、可迁移的**。只要模态校准过了 ECE 门、用户研究跑过 E288/E294，就默认"测过 = 可信"。
>
> 两个灵感恰好各击穿一笔：
> - **平衡控制**：控制权限是**状态相关、会被消耗、且部分不可逆**的资源。腿足/人形/欠驱动系统根本不能"停下来问"——它维持站立本身就要持续花控制权限；一次注视、一次探针、一次等待，都会从**同一个**稳定裕度里扣钱，甚至可能诱发它本想避免的那次跌倒；而跌倒是一个**吸收态**（fall is absorbing），没有"下一轮再补救"。R69 的「≤1 次/单位时间」数的是事件，不是裕度。
> - **演示方案**：任何"分辨率红利"所依据的证据，都来自一份**演示方案**——一组场景、一个演示者/操作者策略、一次数据切分、一次预注册。它是一份**采样契约**，不是普适真理。挑选场景（cherry-picking）、幸存者偏差、舞台漂移、偷看停测（optional stopping）、人群外推，都会让"演示过"变成统计幻觉。R69 的 E288/E294 正是把一场演示当成了证书，却从未定义它在哪个分布上成立、覆盖了哪些危险角落。
>
> 核心命题：**把"分辨率红利"从免费改成记账制。任何一次比 R68 更不保守的 λ 减免，必须同时由两本账支付：(i) 动态平衡账本——沿"任务+信息"增广轨迹的可行核裕度全程不越界；(ii) 演示证据账本——该减免落在已预注册、对危险分层有覆盖、并有有限样本保证的演示方案支持域内。任一本账透支，减免归零、退回 R68。** 命名 **POISE-RAS**（Proof-carrying Operation with Information under Stability and Evidence）——"poise"既是**平衡/稳住**，也是**蓄势待发**：先能稳住，才有资格去问。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我此刻有没有资格问——问了会不会先摔倒；而我用来证明"问得值"的那场演示，究竟证明了谁**」。

## 0. 直觉与动机

**灵感 1（平衡控制 → 稳定裕度才是信息动作真正花掉的那种钱）**
直觉：倒立摆、单腿支撑、爬楼时，系统不是"先算清楚再动"，而是"脚已经在动，脑子并行找更好的落点"。R69 的交互层默认可以插入一个"暂停—观察—询问"的间隙；但欠驱动系统的可行控制集随状态变化，低裕度时**根本没有能力执行一次分神的注视或探针**。更关键的是，信息动作不是免费的：转头会改变质心与角动量、探针会产生反作用力、等待会让支撑腿的可用力矩窗口过去。R69 用"次数"给交互记账，POISE 改用**裕度**给交互记账——同一个动作在站立时便宜、在踉跄时致命，而次数预算对此一无所知。

**灵感 2（平衡控制 → 不确定性先吃掉裕度，于是"问"可能要求你先"站稳"）**
直觉：状态估计误差会经反馈控制器放大成实际姿态误差，因此**不确定性本身就是一种对裕度的扣款**：`m_eff(s,U) = m(s) − κ·ε(U)`。这制造了一个鸡生蛋死循环：越不确定 → 有效裕度越低 → 越没资格去交互消歧 → 不确定持续。R69 没有这一项，于是会在"最该先稳住"的时刻安排"最该问"的动作。破局点是一个新的时序原语：**先稳后问（Stabilize-Before-Query, SBQ）**——当 `m_eff < m_ask` 时，先执行一个**让最坏情形裕度单调回升**的任务动作（降低质心、迈步、扩大支撑、扶住环境），站稳之后再谈信息；若连稳定动作都找不到，就进入 R68 的紧急/最保守分支。人类不是"摔倒前先问路"，而是"先扶稳再抬头"。

**灵感 3（演示方案 → 演示是一份采样契约，不是一张万能证书）**
直觉：演示方案真正定义的是**证据的适用域**：在哪些任务、哪些裕度桶、哪些歧义桶上采了多少样本、由谁演示、留出集是否被碰过、假设是否预先注册。R69 的红利本质上是一个统计断言，却被当成确定性结论使用。POISE 要求：红利的支持域必须覆盖**最危险的角落**——低裕度 × 高歧义，因为那正是交互最容易"问出事故"的角落；只用平稳站立场景做的演示，对"边踉跄边询问"没有任何证明力。于是演示从"展示能力"变成"划定证书疆域"，而挑选场景、幸存者偏差、舞台漂移都被显式折算成覆盖缺口，直接扣减可用红利。

**灵感 4（演示方案 → 把"演示"搬进运行时：提交前先预演一遍）**
直觉：既然离线演示只是一份契约，那就让系统在上线后也随身带一个"微型演示"：任何非默认动作（一次交互、一次投机模态切换）在提交前，先在世界模型里把"任务动作 + 信息动作"的**增广轨迹**预演一遍，并对模型误差做鲁棒裕度折扣；预演不通过就**丢弃**（不是降级使用）。这把"演示"从一次性评测升级为**每次提交前的安全原语**，也让 R69 的投机分支有了可执行的门槛。命名"预演—提交（Rehearse-before-Commit, RbC）"。

**灵感 5（两者合起来 → 双账本，R68 与 R69 恰是它的两个边界）**
直觉：单独看，"平衡"像又一层保守刹车，"演示"像又一道合规门。合起来才看清：**平衡账本决定"你付不付得起这次信息"，演示账本决定"这次信息值不值这个价"**。R69 的红利 = 只记收入、不记支出的账；POISE 的红利 `r = min(r_margin, r_demo)` 是两本账都为正时才允许的**盈余**。于是三者关系是干净的夹逼：无盈余时逐指令退回 R68；裕度无限且演示覆盖全域时逐指令等于 R69；一般情形夹在两者之间，且**安全侧永不弱于 R69、效率侧永不弱于 R68**。这不是推翻 R69，而是把它从"凭感觉发钱"改成"按账本放款"。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（POISE-RAS 总览）** POISE-RAS = (VMC, MBL, SBQ, MINT-B, DSR, SCC, RbC, VPP, EBC, EDS, AIC-POISE, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **默认分支恒可行（fail-safe by construction）**：任一时刻都存在一个已认证、保持在可行核内的 R68 默认动作；信息/投机动作只能**替换**它，不能**阻塞**它；
(iii) **平衡账本不越界**：任何信息动作与 λ 减免都必须使增广轨迹的平衡账本 `M(ξ) ≥ 0`；`m_eff < m_ask` 时禁止交互，必须先 SBQ；
(iv) **证据账本可追溯**：任何分辨率红利 `r>0` 必须绑定一份通过预注册与分层覆盖检查的演示方案证书；支持域之外红利恒为 0；
(v) **预演—提交**：任何非默认动作在提交前必须通过 RbC 的鲁棒预演；预演失败即丢弃，执行已认证默认动作。

**定义 311（状态、可容许集、可行核、平衡裕度）** 状态 `s=(x,ẋ) ∈ 𝒮`。可容许集 `𝒮_adm = {s : h_i(s) ≤ 0, i=1..n_h}` 编码支撑多边形/质心、关节限位、接触力锥、力矩上限等。**可行核** `𝒱 ⊆ 𝒮_adm` 为最大受控不变集：`s ∈ 𝒱 ⇔ ∃策略使 s_τ ∈ 𝒮_adm, ∀τ≥t`。**平衡裕度** `m(s) = min_i (−h_i(s))`（归一化符号距离）。**跌倒为吸收态**：`s ∉ 𝒱 ⇒` 恢复只能以 `≥ c_fall` 的紧急代价进行或不可恢复；该标志进入风险项，不可被 R68 的"下一轮再修"吸收。

**定义 312（不确定性—裕度耦合）** 状态估计误差上界 `ε(U)` 由 R69 的 `U_ale + 未消解 U_epi` 经估计器 Lipschitz 映射得到；反馈控制器 Lipschitz 常数为 `L_c`，则**有效裕度** `m_eff(s,U) = m(s) − κ ε(U)`，`κ>0`。消解歧义把 `ε(U_epi)` 降为 `ε(U_epi^after)`，带来**裕度回收** `Δm_res(g) = κ(ε_before − ε_after) ≥ 0`。反之，一次信息动作的**平衡开销** `c_b(g;s) = m(s) − m(s^+(g)) ≥ 0`，其中 `s^+(g)` 为执行 `g` 且不产生任务进展后的状态。

**定义 313（增广轨迹平衡账本 MBL）** 增广控制 `ξ_τ=(a_τ,g_τ)`，增广轨迹 `ξ_{t:t+H}`，状态演化 `s_{τ+1}=f(s_τ,ξ_τ,w_τ)`。**平衡账本**
`M(ξ) = min_{τ∈[t,t+H]} [ m_eff(s_τ,U_τ) − m_min ]`，并要求 `s_H ∈ 𝒱_ε`（带 `ε` 余量的可行核）。
`ξ` **平衡可行** ⇔ `M(ξ) ≥ 0`。局部一阶下守恒式：`M(ξ(a,g)) ≈ M(ξ(a)) − c_b(g) + Δm_res(g) − δ_mis`，`δ_mis` 为模型/观测失调税。

**定义 314（平衡约束 VoI，MINT-B）** 候选信息动作
`g* = argmax_{g∈𝒜_info} [ VoI(g) − c(g) − β·c_b(g) ]`
s.t. `M(ξ(a^D,g)) ≥ 0`、`risk(g) ≤ ε_int`、全局交互预算未超、C-RAS-WM 认证通过。若最优 `g*` 的净分 `≤0` 或可行集为空：不交互，走 R69/R68 兜底。

**定义 315（先稳后问 SBQ）** 设 `m_ask` 为容许执行任意信息动作并仍能恢复所需的最小有效裕度。若 `m_eff(s,U) < m_ask`，则
`a_stab = argmax_{a∈𝒜_task} min_{w∈𝒲} m(f(s,a,w))`，s.t. 任务不倒退（或紧急优先）。
执行 `a_stab` 直到 `m_eff ≥ m_ask + m_reserve` 后再进入 MINT-B。若不存在使最坏情形裕度严格回升的 `a_stab`，则触发 R68 紧急最保守分支。SBQ 是本轮唯一的**新时序原语**：先站稳，再求证。

**定义 316（演示方案 DSR）** 演示方案 `D = (𝒮_D, π_D, Σ, Cov*, n, 𝒟_tr/𝒟_te, h_prereg, α, seq_plan)`：场景分布、演示者/操作者策略、分层集合、覆盖要求、样本量、训练/留出切分、预注册哈希、显著性水平、序贯检验计划。`D` **有效** ⇔ 预注册哈希一致 ∧ 留出集未被触碰 ∧ 覆盖检查通过 ∧ 未检测到偷看停测（alpha-spending 违约）。

**定义 317（演示分层覆盖 SCC）** 分层 `σ = (task, ⌊m/m_δ⌋, ⌊U_epi/δ_u⌋)`，即任务 × 平衡裕度桶 × 歧义桶。**危险分层集** `Σ_crit` 为低裕度桶 × 高歧义桶的笛卡尔子集（交互最易致险的角落）。覆盖 `Cov_σ(D) = P_{𝒮_D}(σ)`；`D` **覆盖合格** ⇔ `min_{σ∈Σ_crit} Cov_σ(D) ≥ c_min`。演示若不覆盖 `Σ_crit`，其对交互安全的证明力按缺口折价。

**定义 318（有限样本演示证书与红利上界）** 留出集 `n_te` 上经验失败率 `R̂`，Clopper–Pearson 上界 `p_U = CP(R̂, n_te, α)`；部署分布与演示分布的总变差 `TV(P_deploy, 𝒮_D)`。演示红利上界
`r_demo = η · max{ 0, [ Δ_safe^{LCB}(p_U) − TV(P_deploy, 𝒮_D) ] }`，
其中 `Δ_safe^{LCB}` 为"相对 R68 的安全改进"的 `(1−α)` 下置信界。任一有效性/覆盖/预注册检查失败 ⇒ `r_demo = 0`。

**定义 319（预演—提交 RbC）** 提交前用世界模型集合 `{f̂_j}`（`w_j ~ q`，`j=1..N_r`）对增广计划 `ξ` 滚动 `H` 步，得 `M̂_j`。**鲁棒预演通过** ⇔ `min_j M̂_j − L_wm·δ_wm ≥ 0`，`δ_wm` 为世界模型误差上界、`L_wm` 为其 Lipschitz 常数。不通过 ⇒ **丢弃**计划（非降级使用），执行默认分支。

**定义 320（平衡保持增广前缀 VPP）** 把 R69 定义 302 的"信息动作单独认证"升级为"任务+信息联合认证"：前缀长度
`k_vpp = min{ k_wm, ⌊(t_fall^bound(s,ξ) − t_recover)/Δt⌋ }`，并要求 `∀τ≤k_vpp: m_eff(s_τ) ≥ m_min`、信息动作不越专用包络（注视/力/等待窗）。任一不满足 ⇒ `k_vpp=0`、`g` 作废、`U_epi` 视为未消解。`t_fall^bound` 由可行核/捕获点给出，`t_recover` 为切换回默认策略所需的恢复时间。

**定义 321（双账本减免律 EBC）** 分辨率红利 `r = min(r_margin, r_demo)`，其中 `r_margin = φ(M(ξ))` 为平衡账本盈余的单调函数（盈余越厚，允许的非保守越多），`r_demo` 如定义 318。风险缩放
`λ = max{ λ_task, λ_floor(U_ale + 未消解 U_epi) − r, λ_abs }`，
`λ_abs` 为不可突破的绝对安全下界。`r=0` 时逐指令等于 R68；两本账同时满额时等于 R69 的全额分辨率红利。**没有免费的分辨率**：`r ≤ min(r_margin, r_demo)`。

**定义 322（裕度感知模态选择）** 在证据一致、后验权重落在最大权重容差内的模态集合 `M_ε` 中，选择
`k* = argmax_{k∈M_ε} m_eff(s^+ ; ξ_k)`，即执行后**最坏情形裕度最大**者，任务进展作次级排序。多个模态"都对"时，选那个让系统更稳的——这是把平衡账本从"预算约束"延伸为"平票裁决"。

**定义 323（主动演示调度 EDS）** 当 `r_demo` 受覆盖缺口限制时，选择下一次演示场景 `d` 以最大化
`E[ Δr_demo(d) ] / cost(d)`，s.t. 分层覆盖目标与预注册分层检验计划。当演示的 VoI（对红利的边际提升）≤ 成本、或预算耗尽、或覆盖已满足时停止。演示调度本身是信息动作，只是发生在"离线账本"上，不占用实时交互预算，但其结论必须回灌 DSR。

**定义 324（干扰集 ℰ_POISE）** 在 R69 的 `ℰ_FLUID` 上再乘两类：
- `ℰ_demo`：场景挑选（cherry-picking）、幸存者/表演性演示、舞台漂移、覆盖伪造、演示投毒、偷看停测；
- `ℰ_balance`：裕度测量攻击（IMU/足底力篡改使 `m` 虚高）、低裕度状态伪装、诱使 SBQ 失效的共振扰动。
`ℰ_POISE = ℰ_FLUID × ℰ_demo × ℰ_balance`。

**定义 325（证书 J_POISE）** `J_POISE = (J_FLUID, m_eff_min, M(ξ), m_ask, r_margin, r_demo, demo_scheme_hash, coverage_vector, n_te, cp_upper, prereg_ok, rehearsal_residual, vpp_k, poise_ver)`。
Valid ⇔ Valid(J_FLUID) ∧ `M(ξ) ≥ 0` ∧ 预注册一致 ∧ 覆盖合格 ∧ `cp_upper ≤ τ_fail` ∧ 预演通过 ∧ `r ≤ min(r_margin, r_demo)` ∧ 交互/前缀预算未越界。

**定义 326（退化边界与 SBQ 时序）** 若 `r = 0`（任一本账为空、证书失效或 `m_eff < m_ask` 且 SBQ 失败）⇒ POISE 逐指令等于 R68；若 `𝒱 = 𝒮`（裕度无限，如固定基座/全驱动）且演示覆盖全域（`TV=0, c_min=1`）⇒ `r_margin, r_demo` 均为全额 ⇒ POISE 逐指令等于 R69。中间状态由 `(M 盈余, 覆盖)` 连续插值。SBQ 不改变安全包络，只改变**时序**：先执行已认证的稳定动作，再考虑信息。

# IP-264 VMC：平衡裕度与可行核（闭式距离 + QP 热启动投影）
class ViabilityMarginController:
    def margin(self, s):                    # 归一化到可容许集边界的符号距离
        return min(-h(s) for h in self.constraints)
    def effective_margin(self, s, U):       # 定义 312：不确定性先扣裕度
        return self.margin(s) - KAPPA * eps_upper(U)
    def in_kernel(self, s, eps=0.0):
        return self.margin(s) >= self.m_min + eps
    def project(self, s):
        return qp_project_to_kernel(s, self.constraints)

# IP-265/266：增广轨迹平衡账本 + 先稳后问
def balance_ledger(f, s0, xi, U, H):
    m = float('inf')
    for t in range(H):
        s0 = f(s0, xi[t])
        m = min(m, vmc.effective_margin(s0, U) - M_MIN)
    return min(m, viability_slack(s0, H))      # 定义 313

def stabilize_before_query(A_task, s, U):
    def worst_margin(a):
        return min(vmc.margin(f_worst(s, a, w)) for w in disturbance_samples())
    a = max(A_task, key=worst_margin)
    return a if worst_margin(a) > vmc.effective_margin(s, U) else None   # None → 紧急

# IP-267 MINT-B：平衡约束下的信息动作选择
def choose_interaction_balanced(modes, w, o, s, U, budget):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        xi = augmented_default_plan(o, g)                    # (a_default, g)
        if balance_ledger(f, s, xi, U, H) < 0: continue      # 定义 314 可行性
        score = entropy(w) - expected_entropy(w, g, o) - cost(g) - BETA * c_b(g, s)
        if best is None or score > best.score: best = (g, score)
    if best and best.score > 0: return best
    return None

# IP-268/269：演示方案红利（离线/异步，不占实时环）
def demo_bonus(D, deploy_dist):
    if not prereg_match(D) or not held_out_untouched(D): return 0.0
    cov = empirical_coverage(D.scheme, D.samples)
    if min(cov[si] for si in CRITICAL_STRATA) < C_MIN: return 0.0
    pU  = clopper_pearson_upper(D.heldout_fail, D.n_test, D.alpha)
    tv  = total_variation(deploy_dist, D.scheme)
    return max(0.0, ETA * (safe_gain_lcb(pU) - tv))          # 定义 318

# IP-270 RbC：提交前在世界模型里预演增广轨迹
def rehearse_before_commit(wm_ensemble, xi, s, H, N_r):
    worst = min(rollout_margin(fj, s, xi, H) for fj in wm_ensemble[:N_r])
    return worst - L_WM * DELTA_WM >= 0.0                    # 定义 319

# IP-271 VPP：平衡保持的认证前缀
def viability_prefix(A, g, s, wm_preds):
    if augmented_ledger_ok(A, g, s) is False: return 0
    k  = c_ras_wm.certified_prefix(A, g, wm_preds)
    tf = time_to_fall_bound(s, (A, g), wm_preds)
    return min(k, int((tf - T_RECOVER) / DT))                # 定义 320

# IP-275 主闭环（继承 R69/R68，仅在"资格/记账"处插入 POISE 层）
def POISE_RAS_round(M, obs):
    s = M.state; z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(...)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K=M.adaptive_K(z)), z, M.fmp.mode_head)
    # 1) 演示账本（异步缓存）——决定"最多能放多少款"
    r_demo = M.dsr.cached_bonus(M.current_scheme, M.deploy_dist)
    # 2) 资格检查：低裕度先站稳，别边踉跄边提问
    if M.vmc.effective_margin(s, (U_ale, U_epi)) < M.M_ASK:
        a_stab = M.sbq.stabilize(M.task_actions, s, (U_ale, U_epi))
        if a_stab is None: return M.r68_emergency(...)        # 定义 315/326
        return M.r68_execute(a_stab)                          # 本轮不交互
    # 3) 平衡约束 VoI
    g = (M.mint_b.choose(modes, o, s, (U_ale, U_epi), M.budget)
         if U_epi > TAU_EPI else None)
    xi = M.plan(M.default_action, g)
    # 4) 预演—提交：不通过就丢弃（不是降级使用）
    if g is not None and not M.rbc.rehearse(M.wm_ensemble, xi, s, M.H, M.N_r):
        g, xi = None, M.plan(M.default_action, None)
    if g is not None:
        ans = M.cia.execute(g); U_epi = M.cia.update_belief(modes, ans)
    # 5) 双账本：收入必须由平衡盈余 + 演示证据共同背书
    U_floor  = U_ale + (U_epi if g is None else 0.0)
    r_margin = M.mbl.slack_bonus(xi, s, (U_ale, U_epi))
    r        = min(r_margin, r_demo)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor) - r, LAM_ABS)
    # 6) 平衡保持前缀 + 裕度感知模态裁决
    k = M.vpp.viability_prefix(M.default_action, g, s, M.wm_preds)
    mode = M.mas.select(modes, U_epi, lam, s)                 # 定义 322
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 7) 审计与证书
    M.vqa_b.submit_async(g, r_margin, r_demo, M.M, M.coverage)
    return k, lam, mode, (U_ale, U_epi, r_margin, r_demo)

## 3. 推导

**引理 19（裕度—信息守恒）** 在定义 311–313 与 ‖f‖ 局部 Lipschitz 下，对任一信息动作 `g` 的一阶展开有
`M(ξ(a,g)) = M(ξ(a)) − c_b(g) + Δm_res(g) − δ_mis`。
系：**只有当消歧回收的裕度严格大于交互开销与失调税之和时，交互才可能同时提升安全与效率**；否则交互是纯负债——这正是"边踉跄边提问"在数学上被禁止的原因。R69 的 VoI 只数信息收益，漏掉了 `c_b` 与 `Δm_res` 这两项以裕度计的收支。

**引理 20（演示覆盖决定红利上界）** 对任意部署分布 `P` 与演示分布 `𝒮_D`，
`E_P[risk] ≤ E_{𝒮_D}[risk] + TV(P, 𝒮_D)`；因此定义 318 的红利上界必须减去变差项。若 `P` 在高歧义×低裕度分层 `σ∈Σ_crit` 上质量占比为 `μ`，而 `𝒮_D` 在该分层覆盖率为 `c`，则 `TV ≥ |μ − c|`。系：**只演示平稳场景的方案，对危险角落的证书效力随缺口线性归零**；`c_min` 是所有交互红利的"质押率"。

**引理 21（先稳后问的安全性）** 对欠驱动系统，若 `m_eff(s,U) < m_ask`，则存在一个满足物理约束的扰动 `w`，使得在施加任意非零信息动作 `g` 后 `s ∉ 𝒱`（分神/反作用/等待耗尽恢复窗口）；而按定义 315 选择最坏情形裕度最大的 `a_stab`，只要该动作存在，就保持 `s ∈ 𝒱`。若不存在任何使最坏情形裕度严格回升的任务动作，则系统已处于不可恢复区，此时唯一无学习写操作的选择是 R68 紧急分支。系：**"先稳后问"不是保守偏好，而是可行性的必要条件**。

**定理 18（POISE 夹逼并严格泛化 R68 与 R69）** 在 A99（风险对 λ 单调、裕度感知模态选择不增风险）、A100（演示证书健全，见引理 20）、A101（预演健全，见定理 20）下，对任意状态 `s`：
`R(POISE) ≤ R(R69)`（因为 `r ≤ R69` 的全额红利，且 SBQ/VPP/RbC 只会更保守），
`E(POISE) ≥ E(R68)`（因为 `r ≥ 0`，且盈余为正时获得非保守收益）。
当 `r=0` 时逐指令等于 R68；当 `𝒱=𝒮` 且 `TV=0, c_min=1` 时逐指令等于 R69。故 POISE 不是与二者并列的第三层，而是**由两本账参数化的连续插值**，两端精确退化。安全侧不放宽到 R69 之下，效率侧不退化到 R68 之下。

**定理 19（无免费分辨率 / 双账本紧性）** 设 `r > min(r_margin, r_demo)`。则存在 `ℰ_POISE` 中的环境（裕度被高估，或演示未覆盖部署的危险分层）使 POISE 的实际风险超过 R68 证书界；反之，若 `r ≤ min(r_margin, r_demo)` 且 A99–A101 成立，则风险仍在 R68 证书界内。因此 `min` 是**最大安全红利**（紧的）：多放一分，必有一类可构造场景把账做坏。

**定理 20（预演健全性与无突变）** 若世界模型误差 `≤δ_wm` 且 `f̂` 关于状态 Lipschitz 常数 `≤L_wm`，则鲁棒预演 `min_j M̂_j − L_wm δ_wm ≥ 0` ⇒ 真实增广轨迹在 `H` 步内以概率 `≥1−p_wm` 保持 `m_eff ≥ m_min`；预演失败时丢弃投机计划并执行已认证默认动作，因默认动作在提交前已存在（不变式 310-ii），控制连续、无安全突变（继承 R68 定理 15 与 R69 定理 17）。

## 6. 本轮最大风险

**一句话**：POISE 的全部效率收益押在两个人造前提上——**平衡裕度 `m_eff` 可信、演示方案不可被挑选**；一旦裕度被乐观估计（或演示被表演化/覆盖造假），双账本会把一笔坏账同时记成两份盈余，系统将以"已预演、已认证、已审计"的姿态完成一次本该放弃的交互——**被审计过的翻车，比诚实的犹豫更危险**。

**次级风险与缓解**：
1. **裕度模型偏差** → 定义 319 用 `L_wm δ_wm` 对预演做鲁棒折扣；E301/E313 专测裕度攻击；不确定裕度时按最坏情形 `m_lb` 记账。
2. **SBQ 变成"永远先稳"导致任务瘫痪** → SBQ 仅在 `m_eff < m_ask` 触发，且以"最坏情形裕度严格回升"为退出条件；E311 度量任务时间增幅。
3. **演示证书的 Goodhart 化（为拿红利而表演）** → 预注册 + 留出集 + 序贯 alpha 控制 + 覆盖缺口折价（定义 317–318）；E305/E307 专测。
4. **预演的世界模型幻觉** → 集合预演 + 误差上界折扣 + 失败即丢弃；预演永不替代默认分支（不变式 310-ii）。
5. **两次记账的接口放大延迟** → 演示账本离线缓存、预演仅在请求红利时触发、VMC 复用 R68/R69 状态量（E314）。

| `J_POISE=(J_FLUID,m_eff_min,M(ξ),r_margin,r_demo,coverage_vector,cp_upper,rehearsal_residual,vpp_k,…)` | 证书 |

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** POISE-RAS 十二元组；零学习写操作继承；默认分支恒可行（fail-safe by construction）；平衡账本不越界；证据账本可追溯；预演—提交。

**定义 311–313（平衡对象与账本）** `m(s)=min_i(−h_i(s))`，`𝒱` 为最大受控不变集，跌倒吸收；`m_eff=m−κε(U)`；增广轨迹 `M(ξ)=min_τ[m_eff(s_τ)−m_min]` 且 `s_H∈𝒱_ε`；局部守恒 `M(ξ(a,g))≈M(ξ(a))−c_b(g)+Δm_res(g)−δ_mis`。

**定义 314–315（MINT-B 与 SBQ）** `g*=argmax[VoI−c−βc_b]` s.t. `M(ξ(a^D,g))≥0`、`risk≤ε_int`、预算与认证；`m_eff<m_ask` 时先 `a_stab=argmax_a min_w m(f(s,a,w))`，回升到 `m_ask+m_reserve` 后再交互；无稳定动作 ⇒ R68 紧急分支。

**定义 316–318（演示方案、覆盖、红利）** `D` 为采样契约，有效需预注册一致、留出未碰、覆盖合格、无偷看停测；危险分层 `Σ_crit` 的 `min Cov_σ≥c_min`；`r_demo=η·max{0,Δ_safe^{LCB}(p_U)−TV}`，`p_U=CP(R̂,n_te,α)`，检查失败即 0。

**定义 319–320（RbC 与 VPP）** 预演 `min_j M̂_j−L_wm δ_wm≥0` 才提交，否则丢弃；前缀 `k_vpp=min{k_wm,⌊(t_fall^bound−t_recover)/Δt⌋}`，全程 `m_eff≥m_min`，否则 `g` 作废、`U_epi` 未消解。

**定义 321–322（双账本与模态裁决）** `r=min(r_margin,r_demo)`；`λ=max{λ_task,λ_floor(U_ale+未消解U_epi)−r,λ_abs}`；多个等价模态中取执行后最坏情形裕度最大者。

**定义 323–326（演示调度、干扰集、证书、退化）** EDS 主动补覆盖；`ℰ_demo`（挑选/表演/漂移/覆盖伪造/偷看停测）+ `ℰ_balance`（裕度测量攻击）；J_POISE 并入裕度与演示账本；`r=0`↔R68，裕度无限且全域演示↔R69。

## 3. 关键算法伪代码

```python
# IP-264 VMC：平衡裕度 / 有效裕度 / 可行核
class ViabilityMarginController:
    def margin(self, s):                 return min(-h(s) for h in self.constraints)
    def effective_margin(self, s, U):    return self.margin(s) - KAPPA*eps_upper(U)
    def in_kernel(self, s, eps=0.0):     return self.margin(s) >= self.m_min + eps

# IP-265/266：平衡账本 + 先稳后问
def balance_ledger(f, s0, xi, U, H):
    m = float('inf')
    for t in range(H):
        s0 = f(s0, xi[t]); m = min(m, vmc.effective_margin(s0, U) - M_MIN)
    return min(m, viability_slack(s0, H))

def stabilize_before_query(A_task, s, U):
    worst = lambda a: min(vmc.margin(f(s, a, w)) for w in disturbance_samples())
    a = max(A_task, key=worst)
    return a if worst(a) > vmc.effective_margin(s, U) else None   # None → 紧急

# IP-267 MINT-B：平衡约束信息决策
def choose_interaction_balanced(modes, w, o, s, U, budget):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        if balance_ledger(f, s, augmented_default_plan(o, g), U, H) < 0: continue
        score = entropy(w) - expected_entropy(w, g, o) - cost(g) - BETA*c_b(g, s)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268/269：演示红利（离线/异步）
def demo_bonus(D, deploy_dist):
    if not prereg_match(D) or not held_out_untouched(D): return 0.0
    cov = empirical_coverage(D.scheme, D.samples)
    if min(cov[si] for si in CRITICAL_STRATA) < C_MIN: return 0.0
    pU = clopper_pearson_upper(D.heldout_fail, D.n_test, D.alpha)
    return max(0.0, ETA*(safe_gain_lcb(pU) - total_variation(deploy_dist, D.scheme)))

# IP-270 RbC：提交前预演
def rehearse_before_commit(wm_ensemble, xi, s, H, N_r):
    worst = min(rollout_margin(fj, s, xi, H) for fj in wm_ensemble[:N_r])
    return worst - L_WM*DELTA_WM >= 0.0

# IP-271 VPP：平衡保持前缀
def viability_prefix(A, g, s, wm_preds):
    if augmented_ledger_ok(A, g, s) is False: return 0
    k  = c_ras_wm.certified_prefix(A, g, wm_preds)
    tf = time_to_fall_bound(s, (A, g), wm_preds)
    return min(k, int((tf - T_RECOVER)/DT))

# IP-275 主闭环
def POISE_RAS_round(M, obs):
    s = M.state; z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.adaptive_K(z)), z, M.fmp.mode_head)
    r_demo = M.dsr.cached_bonus(M.current_scheme, M.deploy_dist)          # 异步
    if M.vmc.effective_margin(s, (U_ale, U_epi)) < M.M_ASK:              # 资格检查
        a = M.sbq.stabilize(M.task_actions, s, (U_ale, U_epi))
        if a is None: return M.r68_emergency(...)
        return M.r68_execute(a)                                           # 先站稳，不问
    g = M.mint_b.choose(modes, o, s, (U_ale, U_epi), M.budget) if U_epi > TAU_EPI else None
    xi = M.plan(M.default_action, g)
    if g is not None and not M.rbc.rehearse(M.wm_ensemble, xi, s, M.H, M.N_r):
        g, xi = None, M.plan(M.default_action, None)                      # 预演失败即丢弃
    if g is not None:
        ans = M.cia.execute(g); U_epi = M.cia.update_belief(modes, ans)
    U_floor  = U_ale + (U_epi if g is None else 0.0)
    r_margin = M.mbl.slack_bonus(xi, s, (U_ale, U_epi))
    r        = min(r_margin, r_demo)                                      # 双账本
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor) - r, LAM_ABS)
    k = M.vpp.viability_prefix(M.default_action, g, s, M.wm_preds)
    mode = M.mas.select(modes, U_epi, lam, s)                             # 裕度裁决
    M.vqa_b.submit_async(g, r_margin, r_demo, M.M, M.coverage)
    return k, lam, mode, (U_ale, U_epi, r_margin, r_demo)
```

## 4. 推导

**引理 19（裕度—信息守恒）** `M(ξ(a,g))=M(ξ(a))−c_b(g)+Δm_res(g)−δ_mis`。系：只有消歧回收裕度严格大于交互开销与失调税之和，交互才可能同时提升安全与效率；R69 的 VoI 只记信息收入，漏了以裕度计的两笔支出。

**引理 20（覆盖决定红利上界）** `E_P[risk] ≤ E_{𝒮_D}[risk] + TV(P,𝒮_D)`；危险层部署质量 `μ`、演示覆盖 `c` ⇒ `TV ≥ |μ−c|`。系：只演示平稳场景的方案，对危险角落的证书效力随覆盖缺口线性归零。

**引理 21（先稳后问的安全性）** 若 `m_eff<m_ask`，存在满足物理约束的扰动使任意非零信息动作导致 `s∉𝒱`（分神/反作用/等待耗尽恢复窗）；最坏情形裕度最大的 `a_stab` 只要存在即保持可行；不存在 ⇒ 已入不可恢复区，唯一选择是 R68 紧急分支。故 SBQ 是可行性的必要条件，不是保守偏好。

**定理 18（夹逼并严格泛化 R68/R69）** A99–A101 下，`R(POISE) ≤ R(R69)` 且 `E(POISE) ≥ E(R68)`；`r=0` 逐指令 = R68，`𝒱=𝒮 ∧ TV=0 ∧ c_min=1` 逐指令 = R69。POISE 是由两本账参数化的连续插值，安全侧不弱于 R69、效率侧不弱于 R68。

**定理 19（无免费分辨率 / 紧性）** 若 `r>min(r_margin,r_demo)`，存在 `ℰ_POISE` 环境（裕度高估或危险层漏覆盖率）使实际风险越过 R68 证书界；若 `r≤min(r_margin,r_demo)` 且 A99–A101 成立则风险在界内。故 `min` 是最大安全红利，多放一分必有一类可构造场景做坏账。

**定理 20（预演健全性与无突变）** 世界模型误差 `≤δ_wm`、Lipschitz `≤L_wm` 时，鲁棒预演通过 ⇒ 真实增广轨迹在 `H` 步内以概率 `≥1−p_wm` 保持 `m_eff≥m_min`；预演失败丢弃投机计划、执行已认证默认动作（不变式 310-ii），控制连续、无安全突变（继承 R68 定理 15、R69 定理 17）。

## 7. 本轮最大风险

**一句话**：POISE 的全部效率收益押在「平衡裕度 `m_eff` 可信、演示方案不可被挑选」上；一旦裕度被乐观估计或演示被表演化/覆盖造假，双账本会把一笔坏账同时记成两份盈余，系统将以「已预演、已认证、已审计」的姿态完成一次本该放弃的交互——**被审计过的翻车，比诚实的犹豫更危险**。

**次级风险与缓解**：裕度模型偏差（`L_wm δ_wm` 鲁棒折扣 + E301/E313 + 不确定时用 `m_lb`）；SBQ 导致任务瘫痪（仅 `m_eff<m_ask` 触发、以最坏情形裕度严格回升为退出条件、E311 计时）；演示证书 Goodhart 化（预注册 + 留出 + 序贯 alpha + 覆盖折价 + E305/E307）；世界模型预演幻觉（集合预演 + 失败即丢弃 + 默认分支恒可行）；双账本接口延迟（演示账本异步缓存、预演仅请求红利时触发、VMC 复用既有状态量，E314）。
