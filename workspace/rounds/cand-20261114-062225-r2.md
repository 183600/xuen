# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 2 轮；本轮灵感：「用户测试」×「四足机器人」）

> R72 完成了「认知层 GAUGE」向「具身 GAUGE」的下沉：REG 实时执行图、IRL 意图隐变量、DMEM 灵巧接触计量、EREFLEX 三层反作用、S2R-UQ 桥接，核心是「在 ROS 实时调度下、面对意图模糊的人、用灵巧手触摸世界时，仍逐指令兑现风险界」。但 R72 有一个未被审计的**验证前提**：
> - **用户测试视角**：R72 的所有结论都来自基准测试与**脚本化的配合型成年人**。可是「用户满意度/信任/工作量/偏好」本身就是**测量**：有构念效度（construct validity）、外部效度（external validity）、信度（test-retest / inter-rater / internal consistency）、跨人群**测量不变性**（measurement invariance），而且**会被测试本身改变**（需求特征、Hawthorne 效应、新奇效应、学习效应、信任漂移）。把 Likert 原始均值当区间数、把「信任分高」当安全证据，等于**把一台未标定的传感器接进证书**。更尖锐的是：**过度信任是安全漏洞**——机器人只在平地认证，用户却信任它上楼梯，证书被人绕过了。
> - **四足机器人视角**：R72 的接触计量是**桌面灵巧手**。四足把问题换成**运动接触**：足端模式 c_foot ∈ {flight, touchdown, stance, slip, stumble, break}，噪声强依赖**地形类 τ** 与**步态相位**；腿式里程计会漂移；而**跌倒是吸收态（absorbing state）**，任务收益无法补偿一次摔伤。把四足的力/IMU/关节证据当「又一个 y」送进同一套 λ，会低估地形不确定度与足滑延迟，导致「自信地走进冰面」。
>
> 本轮两个灵感不是并列补丁，而是**同一条链的两端**：用户测试决定「谁来验证、验证谁、验证多久」；四足决定「在哪验证、接触什么、什么代价不可逆」。合起来逼出一个新对象：**证书必须带适用范围（scope of validity）**。
>
> - **用户测试** → **FSM（Field Study Metrology）**：把研究协议当量具，显式建模信度、构念效度、测量不变性、需求特征、预注册与盲法；主观量表用 IRT/Rasch 估潜变量与标准误，而不是平均 Likert。**低质量研究只能产生探索性证据，不能更新安全证书。**
> - **四足机器人** → **LEG-MET**：把 DMEM 的「接触模式条件似然」推广到足端，引入**地形条件证据**、**运动不确定度五分量**、**稳定性裕度**与**跌倒否决**。
> - **两者交汇** → **TRUST-CAL + SCOPE**：信任必须校准到**已认证范围**；过度信任 = 用户把系统推出 scope = 证书失效。**J_FIELD 的有效性被索引在一个显式 σ 上，σ 之外自动降级，而不是无限外推。**
> - **评测反作用** → **EREFLEX†（L4）**：做一次用户测试本身就是一次干预，会改变用户（学习/疲劳/信任）与系统行为（被观察）。把「开展评测」当作动作 g_eval，消耗评测反作用预算 B_eval_total。
>
> 核心命题：**从「在实验室里我的测量链可信吗」，进化为「在这群用户、这块地形、这段时间里可信吗；出了这个范围，系统会不会诚实地失效？」** —— **FIELD-GAUGE-RAS：带适用范围、经用户测试计量审计、面向四足野外部署的具身证据闭环。**

## 0. 直觉与动机

**灵感 1（用户测试 → 用户不是裁判，用户是量具）**
直觉：R72 默认「用户说的话/打的分数」是关于系统好坏的地面真值。但 HRI 里的信任量表、NASA-TLX、Godspeed、SUS 都是**间接测量**：它们测的是构念（construct），不是物理量。量表有天花板/地板效应，跨年龄/文化未必满足标量不变性（scalar invariance）；同一用户第一次和第三次打分不同（学习/新奇）；知道「这是实验」会改变行为（需求特征）。**把原始 Likert 均值直接当证据，就像把未标定、非线性的电压读数当温度。** 正确做法：用项目反应理论（IRT）估潜变量 ξ 与其标准误 SE(ξ̂)，并报告信度、效度、不变性与反应性。**用户测试不是最后一步，它是证书里的一个测量通道。**

**灵感 2（四足机器人 → 脚是另一种手，地形是未建模的接触对象）**
直觉：R72 的灵巧手有 taxel、力矩、滑移；四足有足端力、关节力矩、IMU、腿式里程计。表面上「换成足端」即可，实际上**分布移位更剧烈**：桌面物体几何相对稳定，而地形从瓷砖到冰面、沙子、草地、楼梯、碎石是**开放集**。足端接触模式更多（touchdown/stumble/break），且**控制指令（步态、落足点、速度）直接改变接触模式**——这正是 R72 L3 接触反作用的运动版。**四足的核心风险不是「抓不住」，而是「摔倒」；摔倒是吸收态，必须非补偿性否决。**

**灵感 3（信任校准 → 过度信任是比不信任更危险的安全漏洞）**
直觉：若系统只在 σ =（平地、室内、成人、短时）内认证，但用户因为界面流畅而**信任它上楼梯**，那么实际运行已越出 σ，而 J_EMB 仍然「有效」。这不是模型错，是**证书被人类行为绕过了**。所以信任不是软指标，是**安全包络的一部分**：T̂ 必须与客观可靠度 R 校准（ECE_trust），过度信任概率 O 与不信任概率 U 都要进入风险缩放；高风险越界动作必须由系统**主动拒绝**，而不是交给用户信任。

**灵感 4（评测反作用 → 测试即干预，L4 第四层反作用）**
直觉：R72 有三层反作用：ψ（情感/可信度）、z（意图漂移）、c（接触模式）。**做用户测试是第四层**：被观察改变用户（需求特征/新奇/疲劳），被观察也改变系统（Hawthorne：工程师调参、演示模式），重复测试还会让用户学习并抬高信任。把评测当免费观测，会得到**被测试过程污染的证据**。因此「开展一次研究/一次现场试跑」本身是一个动作，有成本、有预算、有有限停止。

**灵感 5（适用范围 → 没有 scope 的证书是无限外推）**
直觉：任何安全界都是条件性的：`风险 ≤ ε | 人群 P、地形 T、语境 X、时长 H、用户状态 U`。R72 把这些条件藏在基准协议里。R73 把 σ 显式写进证书：**σ 之外，证书不是「略有误差」，而是「不成立」**。这带来两个工程后果：(i) 系统必须能**在线检测越界**（OOD 地形/人群/语境）；(ii) 证据组合不能偷偷扩大 σ——两个小范围研究不能拼成一个更大的认证范围，除非有交集覆盖与不变性证明。**Scope 只能单调收窄，不能靠组合凭空放宽。**

## 1. 形式化定义（增量：定义 366–383）

**定义 366（FIELD-GAUGE-RAS 总览与七不变式）** FIELD-GAUGE-RAS = (FSM, TRUST-CAL, LEG-MET, LOCO-RISK, ECO-IVG, EREFLEX†, S2X-UQ, J_FIELD)。七不变式：
(i) **效度优先**：任何用户/现场证据，未经 FSM 效度链与 ECO-IVG 门控，只能标为「探索性」，**不得进入安全声明或 J_FIELD**；
(ii) **范围条件化**：每个认证界必须索引在 σ = (P, T, X, H, U) 上；σ 外证书失效，触发降级而非外推；
(iii) **运动接触完整性**：每条足端证据携带 (接触模式 c_foot, 地形后验 b_t(τ), 地形条件似然 p(y_leg|s,τ,c), 运动不确定度 u_loco)；
(iv) **跌倒非补偿否决**：p_fall 超阈或地形/足滑不确定度超预算 ⇒ 禁止运动，**不可用任务收益或信任分抵消**；
(v) **信任校准**：ECE_trust < τ_T 且过度/不信任概率在安全带内；否则禁用依赖信任的自主性；
(vi) **评测反作用预算**：Σ c_eval ≤ B_eval_total；每层（ψ,z,c,e）稳态集全满足；
(vii) **严格逐指令退化链**：FSM 失效 ⇒ 无用户声明；LEG-MET 失效 ⇒ 已知地形保守步态 + 硬跌倒否决；S2X 失效 ⇒ 仅实验室内范围；TRUST 失效 ⇒ 显式确认 + 速度上限；全失效 ⇒ R68。**新层只在「研究有效、运动可计量、信任已校准、范围可检测」时启用。**

**定义 367（现场研究计量仪器 FSM）** 一次用户研究是仪器 M_user = (C, Ω, P, Π, A)：构念 C、操作化 Ω、样本 P、协议 Π、分析 A。输出潜变量估计 ξ̂ 及其不确定度 u_user。效度向量
V_user = (rel, con, inv, pow, pre, blind)，
其中 rel = 信度（test-retest ICC、inter-rater κ、内部一致性 ω）；con = 构念效度（MTMM/名义网络、区分效度）；inv = 测量不变性（跨人群 configural/metric/scalar，ΔCFI < 0.01、ΔRMSEA < 0.015）；pow = 统计功效 1−β ≥ 0.8；pre = 预注册哈希；blind = 盲法状态。**若主观响应为有序量表，必须用 IRT 建模**
p(r_ij = 1 | ξ_i, α_j, β_j) = σ(α_j (ξ_i − β_j))，
报告 ξ̂ 与 SE(ξ̂)，**不得用原始 Likert 均值冒充区间量**。反应性指数 D = E[score | 被观察] − E[score | 隐蔽观察]。**V_user 不全为真 ⇒ 证据降级为探索性。**

**定义 368（潜变量信任与信任校准 TRUST-CAL）** 设潜变量信任 T_t、客观可靠度 R_t（已认证成功率/已实现风险）。校准误差
ECE_trust = Σ_b (n_b/N) · |T̄_b − R̄_b|（按可靠度分箱），
过度信任 O = P(T − R > δ_T)，不信任 U = P(R − T > δ_T)。认证信任带 = [R − δ_T, R + δ_T]。**越界侵入概率**
P_intrude = P(用户请求/许可的动作越出 σ | 过度信任)。
信任感知风险缩放：
λ_T = λ_base · (1 + κ_O · O + κ_U · U + κ_I · P_intrude)。
**信任声明有效 ⇔ V_user 有效 ∧ ECE_trust < τ_T；否则禁用信任依赖型自主性，退回显式确认。**

**定义 369（四足足端接触模式与地形条件证据）** 接触模式 c_foot ∈ C_L = {flight, touchdown, stance, slip, stumble, break}；地形类 τ ∈ T = {rigid, deformable, granular, slippery, stairs, obstacle, unknown}。足端观测 y_leg = (足端力/接触开关, 关节力矩, IMU, 腿式里程计, 足底触觉) 服从
p_leg(y_leg | s, τ, c_foot) = 𝒩(y_leg; h_{τ,c}(s), Σ_{τ,c}(s))，
Σ 随地形与接触模式变化（slippery: 重尾各向异性；granular: 高噪；stairs: 多峰/饱和）。地形后验 b_t(τ) 由本体感觉 + 外感受在线推断；接触后验 b_t(c_foot) 由 HMM/粒子滤波推断。**缺地形后验的接触证据不得进入 λ。**

**定义 370（运动不确定度五分量）**
u_loco² = u_terrain² + u_slip_foot² + u_odom² + u_gait² + u_payload²，
分别对应：地形错分/未建模地形、足滑检出延迟、腿式里程计漂移、步态相位/切换暂态、负载/质心偏移。五分量**近似独立但不严格正交**（地形→足滑、负载→步态），故在线用保守协方差上界
u_loco = sqrt(1ᵀ Σ_u 1), Σ_u ⪰ diag(u_i²)，非对角项按物理耦合给非负上界。**每项独立追溯链 τ_loco_i。**

**定义 371（运动风险缩放与跌倒否决 LOCO-RISK / FALL-VETO）** 稳定性裕度 m_t（捕获点距离 / ZMP 裕度 / 角动量界）带后验。跌倒概率
p_fall = P(m_t < 0 | b_t(s), b_t(τ), b_t(c_foot))。
风险缩放：
λ_loco = max( risk_scale(U_ale, U_epi, H[b_t(z)], H[b_t(τ)], u_loco),
              λ_floor(U_ale + U_epi + H[b_t(z)] + H[b_t(τ)] + u_loco) )。
**硬否决**：p_fall > τ_fall ∨ H[b_t(τ)] > τ_τ ∨ u_loco > τ_u ∨ 足滑检出延迟 > τ_slip_lat ⇒ 禁止运动（降落/减速/停步/换保守步态）。**否决是非补偿的：不可与任务进度、信任分、用户催促加权平均。**

**定义 372（生态效度门控 ECO-IVG）** 门控用户/现场证据：
- 研究效度 V_user 全真且样本功效达标；
- 信任已校准 ECE_trust < τ_T；
- 范围覆盖 cov(σ) ≥ 要求（人群/地形/语境/时长/用户状态）；
- 预注册分析与实际分析一致（偏差计数 = 0）；
- 无选择性报告 / HARKing / 事后分层；
- 失访率 < τ_att 且无幸存者偏差；
- 测量不变性成立（否则禁止跨组均值比较）。
任一失败 ⇒ 证据标为 **exploratory**：只能更新未来研究的先验，**绝不能更新 J_FIELD 或安全声明**。**确证性（confirmatory）证据必须通过 ECO-IVG。**

**定义 373（评测反作用 L4 与 EREFLEX†）** 评测动作 g_eval 改变用户状态 u（信任/疲劳/学习/唤醒）与系统被观察行为：
u_{t+1} ~ p(u' | u, g_eval, r_t)， a_{t+1} ~ p(a' | a, observed_t)。
评测反作用成本
c_eval = D_KL(b(u_{t+1}) ‖ b(u_t)) + λ_n·Novelty + λ_d·Demand + λ_f·Fatigue + λ_h·Hawthorne。
累计预算 Σ_t c_eval ≤ B_eval_total。**L4 与 L1 ψ、L2 z、L3 c 耦合**：被测试→用户紧张（L1）→指令语气变（L2）→机器人阻抗变（L3）→接触变（L3）→用户更紧张。**联合反作用上界 c_joint ≥ Σ 五层边际成本。**

**定义 374（S2X-UQ：sim2robot / sim2terrain / sim2user）** 三条桥：
- 机器人：θ_real = φ_R(θ_sim) + Δ_R；
- 地形/现场：θ_field = φ_T(θ_sim) + Δ_T（天气、光照、GPS 拒止、地面材质）；
- 用户：θ_user = φ_U(θ_sim-user) + Δ_U（年龄、文化、经验、身体能力；仿真用户 = Wizard-of-Oz / LLM persona 只是代理）。
每个残差用非参数尾部分位（GP/正态化流 + 99.9% 分位）估计，所有进入控制/声明/评测的参数携带 (θ, u_sim, u_real, Σ_Δ, τ_s2x)。**S2U 残差特别易被低估：仿真用户不会真的害怕、不会真的摔倒。**

**定义 375（现场证书 J_FIELD 与适用范围 SCOPE）** 
J_FIELD = (J_EMB, protocol_hash, prereg_hash, irb_ethics, power, blind, invariance_proof,
           u_user, trust_calib, terrain_scope, population_scope, duration_scope,
           loco_valid, fall_margin, s2x_hash, ver)，
并绑定 σ = (P, T, X, H, U)。Valid ⇔ Valid(J_EMB) ∧ FSM 有效 ∧ ECO-IVG 全过 ∧ 信任已校准 ∧ LEG-MET 有效 ∧ 跌倒否决满足 ∧ S2X 链完整 ∧ **当前运行点在 σ 内**。**σ 外 ⇒ 证书不是「降级为低置信」，而是「不成立」**，必须回退到保守策略。

**定义 376（适用范围代数与证书组合）** σ = (P, T, X, H, U)。交集 σ1 ⊕ σ2 = 逐分量取交；并集仅在支撑重叠且测量不变性成立时允许。证书组合规则：
J(σ1 ⊕ σ2) 有效 ⇔ J(σ1) ∧ J(σ2) ∧ 存在不变性证明 ∧ 并集内无未覆盖洞。
**关键单调性：σ 只能通过新证据收窄，不能靠两个小样本研究拼接而放宽。** 组合是「求交/带洞并集」，默认安全侧是收窄。

**定义 377（现场指标扩展 E-MIB†）** 在 R72 E-MIB 上新增：
- **研究族**：ICC、κ、ω、ΔCFI/ΔRMSEA、ECE_trust、O/U、失访率、需求指数、预注册偏差计数；
- **运动族**：地形分类 ECE、足滑检出延迟、每公里跌倒次数、绊倒恢复率、稳定性裕度 P5、里程计漂移 m/km、足端接触模式校准；
- **现场族**：越界率、near-miss 率、人工干预率、MTBF、恢复时间、信任漂移斜率。
所有指标同遵循六元组 (φ,m,u,D,τ,I⊥) 与 V/L/G/A 分层。

**定义 378（现场威胁模型 AIC-FIELD）** ℰ_FIELD = ℰ_EMB × ℰ_study × ℰ_field × ℰ_trust：
- ℰ_study = {p-hacking, HARKing, 选择性报告, 需求特征, Hawthorne/新奇, 失访/幸存者偏差, WEIRD 样本, 评价者偏差, 破盲, 量表天花板/地板}；
- ℰ_field = {对抗地形（冰/油/沙/碎石）、楼梯、人群/儿童/宠物、GPS/视觉欺骗、天气/热、电量、牵引绳缠绕、网络中断}；
- ℰ_trust = {诱导过度信任、绕过安全功能、社会工程、演示模式作弊}。

**定义 379（现场严格退化包含链）** 逐指令等价：

**安全侧只增不减：任何退化保留 R68 硬安全包络与 λ_floor。**

**定义 380（现场 VoI 与有限停止 FVOI）** 
VoI^F(g) = c(ψ)·IG_s + η_z·IG_z + η_u·IG_user − Σ_{i∈{ψ,z,c,e}} c_reflex^i − c_eval − γ·E[Δloss_future] − κ·ScopeRisk(g)。
其中 IG_user 为「用户状态/信任/偏好的信息增益」。**评测动作与交互动作统一在候选集 𝒢 中排序**；max VoI^F ≤ 0 或预算耗尽 ⇒ 停止并回退。有限停止由边际增益非增 + 每层成本正下界保证。

**定义 381（现场四域分离）** 在 R72 三域之外新增**评测域（study domain）**：控制域（运动 500Hz–1kHz，硬实时，只读快照）/ 计量域（20–50Hz，软实时）/ 感知域（30–100Hz，Best-effort）/ **评测域（事件驱动、异步、低优先级、永不进入控制环）**。评测域只能通过**受伦理与安全门控的干预**（知情同意、指令、问卷、场景变更）影响系统，且写入**签名的研究清单（signed study manifest）**。**测试者不能直接拧控制参数，正如计量层不能阻塞控制层。**

**定义 382（证据准入：探索性 vs 确证性）** 用户/现场证据分两级：探索性（ECO-IVG 未过）只可改变未来研究先验；确证性（ECO-IVG 全过）才可更新 J_FIELD。**任何事后分析自动降级为探索性，除非在预注册中显式声明。** 这是对 garden-of-forking-paths 的结构性防御。

**定义 383（跌倒吸收态与非补偿性）** 把运动建模为带吸收失败态 FAIL 的 MDP。若策略 π 的 p_fall(π) > τ_fall，则对任意有限任务收益 R_max 与灾难成本 C_fail（伤害/信任/财产），存在 C_fail 使期望成本超过收益；对人身伤害取 C_fail → ∞。故**跌倒否决不可补偿**。**任何把 p_fall 与任务进度做加权和的设计，都在理论上允许用一次摔伤换一次任务完成。**

# IP-298 LOCO-RISK / FALL-VETO：运动风险与硬否决（控制域只读）
def locomotion_risk(leg_ev, b_t, risk_params):
    H_tau = leg_ev.b_tau.entropy()
    denom = (b_t.U_ale + b_t.U_epi + b_t.H_z + H_tau + leg_ev.u_loco)
    lam = max(risk_params.scale(denom), risk_params.floor(denom))
    p_fall = fall_probability(b_t, leg_ev)          # 捕获点/ZMP 后验
    veto = (p_fall > TAU_FALL or H_tau > TAU_TAU
            or leg_ev.u_loco > TAU_U_LOCO
            or leg_ev.slip_latency > TAU_SLIP_LAT)
    return lam, p_fall, veto

# IP-299 ECO-IVG：生态效度门控（计量域，事件触发）
def eco_ivg(study, trust, coverage, prereg_reports):

    if trust.ece >= TAU_TRUST:                return Gate('exploratory','trust_uncalibrated')
    if coverage(study.scope) < TAU_COVER:     return Gate('exploratory','scope_undercovered')

def ereflex_field_step(psi, z_dist, c_dist, u_user, g, budget):
    psi2, cz, _ = reflex_step(psi, g, robot_prosody(g), None, budget)     # L1
    z2  = intent_transition(z_dist, g, psi)                                # L2
    c2  = contact_transition(c_dist, g)                                    # L3
    u2  = user_transition(u_user, g)                                       # L4 用户被评测改变
    cost = (cost_psi(psi,psi2) + kl(z_dist,z2) + contact_cost(c_dist,c2)
            + kl(u_user,u2) + LAM_N*novelty(g) + LAM_D*demand(g)
            + LAM_F*fatigue(g) + LAM_H*hawthorne(g))
    if not in_safe_sets(psi2,z2,c2,u2) or budget.spent + cost > budget.B:
        return None, cost                       # 五层任一越界/超预算 ⇒ 拒绝
    return (psi2,z2,c2,u2), cost

## 3. 推导

**引理 33（有序量表误用的偏差界）** 设真实潜变量 ξ，Likert 响应为 ξ 的单调离散化，原始均值 μ_raw 与 IRT 估计 ξ̂。若量表级数 K 有限且阈值非等距，则 |E[μ_raw] − E[ξ]| ≤ Δ_disc + Δ_thresh，其中 Δ_disc 为离散化偏差、Δ_thresh 为阈值非等距偏差；**两者都不随样本量 N 消失**。系：**把原始 Likert 均值当区间量，会得到一个「大样本也收敛到错误值」的估计；必须用 IRT/测量模型。**

**引理 34（评测反应性偏差界）** 设被观察与隐蔽观察下的响应差异 D = E[score|obs] − E[score|hidden]。若协议未控制需求特征与 Hawthorne，则观测均值偏差 |E[score] − E[score_true]| ≤ |D| + |Novelty| + |ExperimenterBias|。盲法/cover task/预注册只能降低各项，不能证明为零；**未测量的反应性会系统性抬高信任与偏好**。系：**「用户说好」在未通过 ECO-IVG 前不是证据，是被测试过程污染的信号。**

**引理 35（过度信任绕过证书）** 设系统仅在 σ 内认证，越界动作的实际风险 Risk_out > ε。若过度信任概率 O > 0，且越界许可概率 P_intrude|O > 0，则实际违规概率
P(violation) ≥ O · P_intrude|O > 0，
即使 J_EMB 在 σ 内完全有效。**因此信任校准不是 HCI 软指标，而是证书完整性的必要条件。** 系：**一个「让人放心」的界面，可能正是安全漏洞。**

**引理 36（跌倒否决的非补偿性）** 在带吸收失败态 FAIL 的 MDP 中，若 p_fall(π) > τ_fall，对任意有限任务收益 R_max，取 C_fail > R_max / p_fall 即得 E[cost] > E[reward]；对人身伤害 C_fail = ∞。故任何形如 `score = reward − w·p_fall` 的加权和都可被足够大的 reward 补偿。系：**跌倒否决必须是集合约束，不是惩罚项。**

**引理 37（适用范围只能单调收窄）** 设 σ1, σ2 为两研究覆盖范围。若 σ1 与 σ2 无交集或不变性不成立，则不存在仅由 J(σ1), J(σ2) 推出的 J(σ1 ∪ σ2)；证书组合只能给出 J(σ1 ∩ σ2) 或带洞并集。故**范围放宽必须伴随新的、覆盖并集的证据**。系：**两个小样本研究不能拼出一个大认证范围。**

**引理 38（S2X 残差与泛化界）** 设现场分布与训练分布散度为 D_f，S2X 残差上界 u_s2x。则现场风险界 Risk_field ≤ Risk_lab + L·D_f，且当 D_f > ε_σ（超出 σ）时界退化为平凡上界（无保证）。**因此范围检测器（OOD 地形/人群）是证书有效性的组成部分，不是可选监控。**

**定理 27（FIELD 严格包含与安全单调）** 在 A111–A116（FSM 效度可测、信任可校准、LEG-MET 五分量可辨、跌倒后验有界、S2X 残差有界、范围可检测）下：FIELD 在退化条件下逐指令等于 R72/R71/R68（定义 379），且对任意有效执行，其风险界 ≤ R72 风险界。**安全单调不减，效率只在「研究有效、运动可计量、信任已校准、范围可检测」时获益。**

**定理 28（现场证书有效性 ⇒ 范围内安全）** 若一次执行通过 J_FIELD 且当前运行点 ∈ σ，则：(i) J_EMB 有效 ⇒ 具身认知/时序安全；(ii) LEG-MET 有效 ∧ 跌倒否决满足 ⇒ 运动接触与跌倒风险在界内；(iii) 信任已校准 ⇒ 越界侵入概率在安全带内；(iv) FSM + ECO-IVG 全过 ⇒ 用户证据为确证性，非探索性污染；(v) S2X 链完整 ⇒ 参数/地形/用户残差已传播。综上，**σ 内风险 ≤ ε_field（相对现场测量模型）**。证明重量落在「σ 可被在线检测」与「S2U 残差未被低估」上。

**定理 29（评测反作用的有限停止）** 设评测累计成本 C_eval(n) 严格增且边际成本有正下界 ε_e，边际用户/物理信息增益随 n 非增。则存在有限 n* 使第 n*+1 次评测的边际净收益 ≤ 0；FVOI 在 n* 停止。**「测到什么时候停」在评测层也是可证明的，不是经费耗尽为止。**

**定理 30（信任不能替代测量）** 若系统以抬高主观信任 T 为目标而不改善客观可靠度 R，则 ECE_trust 单调上升、O 上升，由引理 35，P(violation) 上升。故**任何把信任分作为优化目标、却不把 R 与 scope 绑定的设计，都会把安全证书变成营销指标**。系：**信任是风险包络的输入，不是安全性的证据。**

**定理 31（范围组合安全）** 由引理 37，任何证书组合若试图扩大 σ 而无覆盖并集的新证据，则存在 σ 内点无有效证书；此时系统必须判为越界并降级。故**组合算子 ⊕ 在安全侧是收窄算子**。

## 6. 本轮最大风险

**一句话**：FIELD-GAUGE-RAS 把安全从「相信实验室证书」转移到「相信 **适用范围 σ 被正确声明且能在线检测**、相信 **用户测试这台量具在真实人群上仍然有效**、相信 **S2U 残差没有低估真人的恐惧与过度信任**」——**如果团队为了「通过评测」把 σ 写得极窄（平地、成人、短时、理想光照），证书在纸面上永远有效，而真实部署几乎总在 σ 外；同时用户研究因伦理限制无法随机化到危险条件，导致内部效度弱、样本 WEIRD、失访与需求特征把信任分系统性抬高，ECO-IVG 却因「流程齐全」而放行；再叠加四足跌倒的稀有尾事件在有限现场测试中根本采不到样本，p_fall 被严重低估——系统会拿着一份「限定条件下完全正确、所有量表都显著、所有契约都通过」的现场证书，在野外第一次遇到冰面、儿童或一个过度信任它的用户时失效，事后审计发现「所有指标当时都在有效域内、所有研究当时都通过了门控」，这就是**带适用范围的「自信地错自己的适用范围」**。**

次级风险与缓解：
1. **σ 被写成永远成立的空洞范围** → **范围非空洞性检查**：σ 必须覆盖部署任务分布的可测分位（至少 P50 主场景 + 预注册的 P90 挑战场景），否则 J_FIELD 判无效；范围声明本身纳入审计。
2. **用户研究内部效度弱** → **三角测量**：量表（IRT）+ 行为（越界请求、干预率）+ 生理/眼动 + 现场 near-miss 多方法交叉；单一主观来源不定案（复用 R72 单源不定案原则）。
3. **信任分被 Goodhart** → **信任只做安全包络输入、不做优化目标**；以越界率/near-miss 为最终指标；界面改动若抬高 T 而不抬高 R，直接判 ECE_trust 恶化。
4. **S2U 残差低估** → **真人恐惧/过度信任压力测试**：故意设计「看起来更可靠」的演示，测量越界许可概率；非参数尾部建模 + 99.9% 分位。
5. **跌倒尾事件采样不足** → **稀有事件重要性采样 + 物理仿真对抗地形 + 形式化稳定性包络**；现场只做「包络内验证」，不靠现场撞出统计显著性。
6. **评测反作用累积** → **FVOI 有限停止 + 评测预算 + 用户间轮换 + 长期队列**；把「测试疲劳」和「新奇」显式建模进 L4。
7. **复杂度/伦理成本爆炸** → **模块化上限**：|σ 维度|≤5、|T|≤8、|C_L|≤6、每研究必带预注册与一份可复算效度报告；伦理与安全审查作为部署门禁而非事后补丁。

---

**方法学自省**：R72 的证书回答「我的测量链在具身条件下可信吗」；R73 的回答是「**只在说清楚『对谁、在哪、多久』之后，可信才有意义**」。最大的诱惑是把 scope 当成免责声明，而正确的用法是把它当成**运行时的安全约束**：越界即失效，失效即降级。

# 第 73 轮产物 · 创新点清单 v4：FIELD-GAUGE-RAS（Field-valid, In-situ, Ecologically-valid, Longitudinal, Dyadic GAUGE for RAS：适用范围条件化 × 用户测试计量 × 四足运动接触 × 信任校准 × 评测反作用；FSM × LEG-MET × TRUST-CAL × ECO-IVG × EREFLEX† × S2X-UQ × J_FIELD）

> - 缺 **用户测试计量（FSM）**：HRI 量表与行为编码是**测量**，有信度、构念效度、跨人群不变性，且会被测试本身改变（需求特征/Hawthorne/新奇/学习）。原始 Likert 均值不是区间量；低质量研究不能更新安全证书。
> - 缺 **四足运动接触计量（LEG-MET）**：足端接触模式 c_foot ∈ {flight,touchdown,stance,slip,stumble,break}，噪声强依赖地形 τ 与步态相位；腿式里程计漂移；**跌倒是吸收态**，任务收益无法补偿。
> - 缺 **信任校准（TRUST-CAL）**：过度信任会让用户把系统推出已认证范围，**证书被人类行为绕过**；不信任导致突袭式干预/牵引绳拉扯，同样危险。
> - 缺 **生态效度门控（ECO-IVG）**：探索性证据与确证性证据不分，事后分析/HARKing/选择性报告可悄悄污染安全声明。
> - 缺 **评测反作用（L4）**：做一次用户测试本身就是干预——改变用户与系统行为；评测需要预算与有限停止。
> - 缺 **适用范围（SCOPE）**：所有安全界都是条件概率；没有显式 σ 的证书是无限外推。
>
> 核心命题：**从「在实验室里我的测量链可信吗」，进化为「在这群用户、这块地形、这段时间里可信吗；出了这个范围，系统会不会诚实地失效？」** —— **带适用范围、经用户测试计量审计、面向四足野外部署的具身证据闭环。**

## 2. 形式化定义（要点版）

**定义 366（总览与七不变式）** 效度优先、范围条件化、运动接触完整性、跌倒非补偿否决、信任校准、评测反作用预算、严格退化链。

**定义 367（FSM 现场研究计量仪器）** 研究 = 仪器 (C,Ω,P,Π,A)。V_user 含信度（ICC/κ/ω）、构念效度（MTMM）、测量不变性（ΔCFI<0.01、ΔRMSEA<0.015）、功效、预注册、盲法。有序量表用 IRT：p(r_ij=1|ξ_i,α_j,β_j)=σ(α_j(ξ_i−β_j))，报告 ξ̂ 与 SE。反应性 D = E[score|被观察]−E[score|隐蔽]。**V_user 不全真 ⇒ 探索性。**

**定义 368（TRUST-CAL 信任校准）** ECE_trust = Σ_b (n_b/N)|T̄_b−R̄_b|；O、U、P_intrude。λ_T = λ_base(1+κ_O·O+κ_U·U+κ_I·P_intrude)。**信任声明有效 ⇔ V_user 有效 ∧ ECE_trust<τ_T。**

**定义 369（LEG-MET 足端接触）** c_foot 六模式，τ 七类。p_leg(y_leg|s,τ,c)=𝒩(h_{τ,c}(s),Σ_{τ,c}(s))。地形后验 b_t(τ) 由本体 + 外感受推断；接触后验 b_t(c_foot) 由 HMM/粒子滤波。**无地形后验的接触证据不得进 λ。**

**定义 370（u_loco 五分量）** u_terrain（地形错分/未建模）、u_slip_foot（足滑延迟）、u_odom（腿式里程计漂移）、u_gait（步态暂态）、u_payload（负载/质心）。近似独立但不正交，用保守协方差 Σ_u ⪰ diag(u_i²)，u_loco = sqrt(1ᵀΣ_u1)。

**定义 371（LOCO-RISK / FALL-VETO）** p_fall = P(m_t<0|b_t)。λ_loco = max(risk_scale(U_ale,U_epi,H_z,H_τ,u_loco), λ_floor(...))。**硬否决**：p_fall>τ_fall ∨ H[b(τ)]>τ_τ ∨ u_loco>τ_u ∨ 滑移延迟>τ_slip_lat ⇒ 禁运动。**否决是集合约束，不是惩罚项。**

**定义 372（ECO-IVG 生态效度门控）** 过 V_user、ECE_trust、cov(σ)、预注册一致、无选择报告、失访<τ_att、不变性。失败 ⇒ exploratory，只能改未来先验，**不得更新 J_FIELD**。

**定义 373（EREFLEX† · L4 评测反作用）** u_{t+1}~p(u'|u,g_eval,r_t)，a_{t+1}~p(a'|a,observed)。c_eval 含 KL + Novelty + Demand + Fatigue + Hawthorne；Σ c_eval ≤ B_eval_total。L4 与 ψ/z/c 耦合，联合上界 ≥ 各层边际成本之和。

**定义 374（S2X-UQ）** θ_real=φ_R(θ_sim)+Δ_R（机器人）、θ_field=φ_T(θ_sim)+Δ_T（地形/现场）、θ_user=φ_U(θ_sim-user)+Δ_U（用户）。非参数尾分位 99.9%；所有参数携带 (θ,u_sim,u_real,Σ_Δ,τ_s2x)。**仿真用户不会真的害怕、不会真的摔倒。**

**定义 375（J_FIELD 与 SCOPE）** Valid ⇔ J_EMB 有效 ∧ FSM 有效 ∧ ECO-IVG 全过 ∧ 信任校准 ∧ LEG-MET 有效 ∧ 跌倒否决满足 ∧ S2X 链完整 ∧ 运行点 ∈ σ。**σ 外证书不成立，必须回退。**

**定义 376（范围代数）** σ1⊕σ2 = 逐分量交；并集仅在支撑重叠 + 不变性证明 + 无未覆盖洞时允许。**组合是收窄算子；两个小研究不能拼出大范围。**

**定义 377（现场指标 E-MIB†）** 研究族（ICC/κ/ω/ΔCFI/ECE_trust/O/U/失访/需求指数/预注册偏差）、运动族（地形 ECE/足滑延迟/跌倒每公里/绊倒恢复/裕度 P5/里程计漂移/接触模式校准）、现场族（越界率/near-miss/干预率/MTBF/恢复时间/信任漂移斜率）。

**定义 378（AIC-FIELD 威胁模型）** ℰ_EMB × ℰ_study × ℰ_field × ℰ_trust。研究威胁（p-hacking/HARKing/选择报告/需求特征/失访/WEIRD/破盲/量表地板）、现场威胁（对抗地形/楼梯/人群儿童宠物/GPS 欺骗/天气/电量/牵引绳/断网）、信任攻击（诱导过度信任/绕过安全/演示作弊）。

**定义 379（现场退化链）** FSM 失效 ⇒ 撤销用户声明；LEG-MET 失效 ⇒ 已知地形保守步态 + 硬否决；S2X 失效 ⇒ 仅实验室 σ；TRUST 失效 ⇒ 显式确认 + 速度上限；全有效 ⇒ FIELD 完整。**安全侧只增不减。**

**定义 380（FVOI 有限停止）** VoI^F = c(ψ)IG_s + η_z IG_z + η_u IG_user − Σ_{ψ,z,c,e} c_reflex − c_eval − γE[Δloss] − κScopeRisk。评测与交互统一排序，≤0 或预算耗尽即停。

**定义 381（四域分离）** 控制域（500Hz–1kHz 硬实时，只读快照）/ 计量域（20–50Hz 软实时）/ 感知域（30–100Hz Best-effort）/ **评测域（事件驱动、异步、永不进控制环，只能经伦理与安全门控的签名干预）**。

**定义 382（证据准入）** 探索性（ECO-IVG 未过）只改先验；确证性（全过）才更新 J_FIELD；任何未预注册的事后分析自动降级为探索性。

**定义 383（跌倒吸收态）** FAIL 为吸收态；p_fall>τ 时对任意有限 R_max 与 C_fail，期望成本可超收益；人身伤害 C_fail→∞。**跌倒否决不可补偿。**

class TrustCalibrator:
    def update(self, user_behavior, R):
        T   = self.trust_model.posterior(user_behavior)
        ece = expected_calibration_error(T, R)
        O   = prob(T - R > DELTA_T)
        U   = prob(R - T > DELTA_T)
        return TrustState(T=T, ece=ece, over=O, under=U)

# IP-297 LEG-MET：四足足端接触计量（感知域异步）
class LeggedContactMetrology:
    def update(self, leg_frame, gait_cmd, extero):
        b_tau = self.terrain.posterior(leg_frame, extero)
        b_c   = self.hmm.step(leg_frame, contact_mode_prior(gait_cmd, b_tau))
        u = (self.calib.terrain_uncertainty(b_tau),
             self.calib.slip_latency(b_c),
             self.calib.odom_drift(),
             self.calib.gait_transient(gait_cmd),
             self.calib.payload_shift())
        Sigma_u = conservative_cov(*u)
        return LegEvidence(lik=leg_likelihood(leg_frame, b_tau, b_c),
                           b_tau=b_tau, b_c=b_c,
                           u_loco=sqrt(one().T @ Sigma_u @ one()),
                           tau=self.calib.tchain)

# IP-298 LOCO-RISK / FALL-VETO（控制域只读）
def locomotion_risk(leg_ev, b_t, p):
    H_tau = leg_ev.b_tau.entropy()
    denom = b_t.U_ale + b_t.U_epi + b_t.H_z + H_tau + leg_ev.u_loco
    lam, p_fall = max(p.scale(denom), p.floor(denom)), fall_probability(b_t, leg_ev)
    veto = (p_fall > TAU_FALL or H_tau > TAU_TAU
            or leg_ev.u_loco > TAU_U_LOCO
            or leg_ev.slip_latency > TAU_SLIP_LAT)
    return lam, p_fall, veto

# IP-299 ECO-IVG：证据准入门控
def eco_ivg(study, trust, coverage, prereg_reports):
    if not study.valid.all():                return Gate('exploratory','invalid_study')
    if trust.ece >= TAU_TRUST:               return Gate('exploratory','trust_uncalibrated')
    if coverage(study.scope) < TAU_COVER:    return Gate('exploratory','scope_undercovered')
    if prereg_deviation(prereg_reports) > 0: return Gate('exploratory','post_hoc_analysis')
    if study.attrition > TAU_ATT:            return Gate('exploratory','attrition_bias')
    return Gate('confirmatory','ok')

# IP-300 EREFLEX†：五层反作用（含 L4 评测反作用）
def ereflex_field_step(psi, z, c, u_user, g, budget):
    psi2, _, _ = reflex_step(psi, g, robot_prosody(g), None, budget)  # L1
    z2 = intent_transition(z, g, psi)                                  # L2
    c2 = contact_transition(c, g)                                      # L3
    u2 = user_transition(u_user, g)                                    # L4
    cost = (cost_psi(psi,psi2) + kl(z,z2) + contact_cost(c,c2) + kl(u_user,u2)
            + LAM_N*novelty(g) + LAM_D*demand(g)
            + LAM_F*fatigue(g) + LAM_H*hawthorne(g))
    if not in_safe_sets(psi2,z2,c2,u2) or budget.spent + cost > budget.B:
        return None, cost
    return (psi2,z2,c2,u2), cost

# IP-301 S2X-UQ：三桥残差（机器人/地形/用户）
def sim2x_bridge(kind, theta_sim, sim_data, real_data):
    delta = nonparametric_tail_model(theta_sim, sim_data, real_data)  # GP/flow
    return BridgedParam(kind=kind,
                        theta=phi(kind, theta_sim) + delta.mean,
                        u_sim=u_sim(theta_sim),
                        u_real=sqrt(u_sim(theta_sim)**2 + delta.q999),
                        delta=delta, tchain=hash(real_data))

# IP-302/303：FIELD 主闭环（四域分离；评测域永不进控制环）
def FIELD_GAUGE_RAS_round(M, obs, audio, leg_frame, extero):
    # ===== 控制域 (500Hz-1kHz, 硬实时) =====
    snap = M.snapshot.read_latest()
    b_t  = M.bse.step_ctrl(snap.b_prev, obs, M.last_action, M.last_g, M.last_y)
    lam, p_fall, veto = locomotion_risk(snap.leg_ev, b_t, M.risk_params)
    if veto:
        M.ctrl_out.publish(stop_or_conservative(M.last_gait))   # 硬否决
        return ('halt',), lam, M.cert_ctrl.fragment(p_fall=p_fall, veto=True)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(...), lam, ...)
    M.ctrl_out.publish(k, lam); M.last_action = k

    # ===== 计量域 (20-50Hz, 软实时) =====
    if M.clock.due_metric():
        b_full = M.bse.step_full(...)
        z_dist = M.irl.update(M.y_intent_buf, M.psi_hat, b_full)
        trust  = M.trust.update(M.user_behavior_buf, M.j_emb.reliability)
        gate   = M.eco_ivg.check(M.study, trust, M.coverage, M.prereg_reports)
        lgate  = M.loco_ivg.check(snap.leg_ev, b_full, M.tac_ev)
        if not (gate.valid and lgate.valid):
            M.mode = degrade_to(gate, lgate)     # R72 / 保守步态 / R68
        M.snapshot.write(b_full, z_dist, trust, gate, lgate, M.leg_ev)

    # ===== 感知域 (30-100Hz, Best-effort) =====
    M.psi_hat, ece_aff = M.aura.update(audio)
    M.leg_ev = M.leg_met.update(leg_frame, M.last_gait, extero)
    M.user_behavior_buf.append(extract_user_behavior(obs, audio, M.last_action))

    # ===== 评测域 (事件驱动, 异步, 永不进控制环) =====
    if M.study_scheduler.due() and M.mode == 'FULL':
        g_eval = M.fvoi.choose(M.snapshot.read_latest(), M.study, M.budget_eval)
        if g_eval and M.consent.allows(g_eval):
            M.study.execute(g_eval)              # 签名研究清单
    return M.last_action, lam, make_J_FIELD(M, M.current_scope)

## 4. 推导

**引理 33（有序量表误用偏差界）** 原始 Likert 均值偏差 ≤ Δ_disc + Δ_thresh，且**不随 N 消失**。系：必须用 IRT/测量模型，原始均值会大样本收敛到错误值。

**引理 34（评测反应性偏差界）** |E[score]−E[score_true]| ≤ |D| + |Novelty| + |ExperimenterBias|；盲法/cover task 只能降低不能证明为零。系：未过 ECO-IVG 的「用户说好」是被污染信号。

**引理 35（过度信任绕过证书）** 若 O>0 且 P_intrude|O>0，则 P(violation) ≥ O·P_intrude|O > 0，即使 J_EMB 在 σ 内完全有效。系：让人放心的界面可能正是安全漏洞。

**引理 36（跌倒否决非补偿）** FAIL 吸收态下，p_fall>τ 时可令 C_fail > R_max/p_fall 使期望成本超收益；人身伤害 C_fail=∞。故 `reward − w·p_fall` 可被大 reward 补偿。系：跌倒否决必须是集合约束。

**引理 37（范围只能单调收窄）** 无交集或不变性不成立时，J(σ1),J(σ2) 推不出 J(σ1∪σ2)；只能给交集或带洞并集。系：两个小样本研究不能拼出大认证范围。

**引理 38（S2X 与泛化界）** Risk_field ≤ Risk_lab + L·D_f；D_f>ε_σ 时界退化为平凡上界。系：OOD 范围检测器是证书有效性的一部分。

**定理 27（FIELD 严格包含与安全单调）** 在 A111–A116 下，FIELD 在退化条件下逐指令等于 R72/R71/R68（定义 379），且有效执行风险界 ≤ R72。**安全单调不减。**

**定理 28（J_FIELD ⇒ 范围内安全）** 若通过 J_FIELD 且运行点 ∈ σ，则认知/时序安全（J_EMB）、运动接触/跌倒界（LEG-MET+否决）、越界侵入安全带（信任校准）、确证性证据（FSM+ECO-IVG）、残差传播（S2X）同时成立 ⇒ σ 内风险 ≤ ε_field。**证明重量在「σ 可在线检测」与「S2U 残差未低估」。**

**定理 29（评测有限停止）** 评测成本严格增、边际成本有正下界、边际信息增益非增 ⇒ 存在有限 n*，FVOI 停止。**不是经费耗尽为止。**

**定理 30（信任不能替代测量）** 只抬高 T 不改善 R ⇒ ECE_trust 与 O 上升 ⇒ 由引理 35，P(violation) 上升。系：信任是风险包络输入，不是安全证据。

**定理 31（范围组合安全）** 由引理 37，无新证据的范围扩大必留未覆盖洞，系统必须判越界并降级；组合算子 ⊕ 在安全侧是收窄算子。

## 7. 本轮最大风险

**一句话**：FIELD-GAUGE-RAS 把安全从「相信实验室证书」转移到「相信 **σ 被正确声明且能在线检测**、相信 **用户测试这台量具在真实人群上仍然有效**、相信 **S2U 残差没有低估真人的恐惧与过度信任**」——**如果团队把 σ 写成永远成立的空洞窄域（平地、成人、短时、理想光照），证书在纸面上永远有效而真实部署几乎总在 σ 外；同时伦理限制使研究无法随机化到危险条件，导致内部效度弱、样本 WEIRD、失访与需求特征系统性抬高信任分，ECO-IVG 却因「流程齐全」而放行；再叠加四足跌倒的稀有尾事件在有限现场测试中采不到样本，p_fall 被严重低估——系统会拿着一份「限定条件下完全正确、所有量表都显著、所有契约都通过」的现场证书，在野外第一次遇到冰面、儿童或一个过度信任它的用户时失效，事后审计发现「所有指标当时都在有效域内、所有研究当时都通过了门控」，这就是**带适用范围的「自信地错自己的适用范围」**。**

次级风险与缓解：
1. **σ 空洞化** → 范围非空洞性检查：必须覆盖部署任务分布 P50 主场景 + 预注册 P90 挑战场景；范围声明纳入审计。
2. **用户研究内部效度弱** → 三角测量：IRT 量表 + 行为（越界请求/干预率）+ 生理/眼动 + near-miss 多方法交叉；单源不定案。
3. **信任分 Goodhart** → 信任只做安全包络输入、不做优化目标；最终指标是越界率/near-miss；界面改动抬高 T 而不抬高 R 即判 ECE_trust 恶化。
4. **S2U 残差低估** → 设计「看起来更可靠」的演示，测越界许可概率；非参数尾部 + 99.9% 分位。
5. **跌倒尾事件采样不足** → 稀有事件重要性采样 + 对抗地形仿真 + 形式化稳定性包络；现场只做包络内验证。
6. **评测反作用累积** → FVOI 有限停止 + 评测预算 + 用户轮换 + 长期队列；显式建模测试疲劳与新奇。
7. **复杂度/伦理成本** → 模块化上限 |σ|≤5、|T|≤8、|C_L|≤6；每研究必带预注册与可复算效度报告；伦理与安全审查作为部署门禁。

---

**结论**：R72 问「我的测量链在具身条件下可信吗」；R73 的回答是「**只有在说清楚『对谁、在哪、多久』之后，可信才有意义**」。最大的诱惑是把 scope 当免责声明；正确的用法是把它当**运行时安全约束**：越界即失效，失效即降级。
