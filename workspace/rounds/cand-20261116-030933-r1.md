# 第 11 轮（承接 v10 CTZ；本轮灵感：「失败恢复」×「手眼标定」×「多机评测」）
> **基线**：第 10 轮 MetricVoiceGauge-CTZ（定义 540–551；引理 87–93；实验 E571–E590）。
> 本轮纪律：**逐时刻硬守卫 + 双向退化 + 车队验证**。v10 把"固定余量"升级为"共形分位数"、把块规划升级为管束 MPC，但留下三个结构性债：(i) **边际债**——共形保证是长期平均而非逐状态条件，突变后连续"未覆盖"无逐时刻硬兜底；(ii) **单向债**——退化链只会向下（Level-0…5），失败后无受控恢复路径；(iii) **单机债**——共形校准与恢复证据只在单机验证，"覆盖 ≥1−α"只是自报。三个灵感正对症：**手眼标定**给逐时刻几何硬约束（治边际债），**失败恢复**把退化格补上向上的边（治单向债），**多机评测**给覆盖与恢复证据做车队级实证（治单机债）。三者共享同一条"一致性残差"流，但必须用独立见证者切断同源自证。

## 0. 直觉与动机

**灵感 1（失败恢复 → 退化格的第二条边）**
v9/v10 的退化是单向阶梯：只会向下、从不向上；一次误触发可能让系统"永久降级"。真正的韧性要求能**受控地爬回来**，这需要三件东西：(a) **恢复证书**——重新进入高能力级的前置条件；(b) **迟滞**——恢复阈值严格比降级阈值保守，防止降级-恢复抖振；(c) **状态复原**——中块降级时丢失的块必须带有效证书**重签**，而非继续沿用旧块。核心创新：**RecoveryCertifier (RC)**，把 v10 的单向退化链升级为**双向退化格**：向下边即时触发，向上边由恢复证书守卫，且每条向上边要求一个**独立见证者**（P17），杜绝"出故障的模块为自己背书"。

**灵感 2（手眼标定 → 把"平均正确"补成"逐时刻正确"）**
v10 的最大风险：共形证书是**边际/长期平均**保证，ACI 在突变后若干步内可能连续未覆盖——恰在最需要安全的瞬间交出"平均而言正确"的证书。手眼标定给出一种**完全不同的**保证：机器人在相机坐标系观测到的末端运动 B_t，与正运动学/前向模型给出的末端运动 A_t，在真实手眼变换 T_HE 下必须满足 A_t·T_HE ≈ T_HE·B_t（AX=XB）。这是**几何硬约束**，每周期（50Hz）可测，**不是统计量**。核心创新：**HandEyeConsistencyGuard (HEC)**：在线估计 T_HE、输出逐周期残差 r_HE，把 v10 余量分解为 β = β_model + β_HE + β_res；r_HE 越阈**当周期**即使证书失效。这是对 v10"边际≠条件"风险的正面回击：管束证书负责全空间、长期覆盖；手眼几何守卫负责**可观测耦合子空间、逐时刻**硬兜底。

**灵感 3（多机评测 → 覆盖承诺的车队级实证与恢复证据迁移）**
v10 的共形校准与恢复证据都是单机、单次部署的。多机评测思想：把覆盖审计与恢复证据放到异构车队上。核心创新：**FleetCoverageValidator (FCV)**：把 N 台机器的覆盖指示量汇总，用二项下置信界给出**车队级覆盖承诺**；β 按机体迁移并本地重标定；一条恢复边只有在 ≥ q 台机器复现才被提升为"车队可信"；一机失败时车队协调退化。多机评测把"手调约定"升级为"统计实证"，并给出跨机可复现性。

**三者的统一**：HEC 提供**逐时刻、单机、几何**的一致性证据；FCV 把该证据（及其覆盖）汇总成**车队级统计**；RC 依据"当前证据 + 独立见证 + 车队 quorum"决定**是否向上恢复**。于是形成闭环：几何守卫发现不一致 → 降级（向下即时）→ 恢复证书要求证据清除 + 独立见证 + 车队复现 → 恢复（向上受控）。v10 的"边际-单向-单机"三债被同时治理，且任一模块失效都注入中立元、逐位退回 v10 CTZ。

## 1. 研究问题（轮次升级版）

- **Q1（逐时刻 vs 边际）**：手眼几何残差 r_HE 在**可观测耦合子空间**上是否是前向模型误差的逐时刻下界代理？其 1 周期延迟能否闭合 v10"突变后连续未覆盖"的缺口？不可观测子空间上的残余误差由谁兜底？
- **Q2（恢复安全）**：恢复证书的前置条件、迟滞、dwell 与独立见证，如何保证"任意恢复态仍是 v10 退化格成员"、不引入新失效模式、且不造成降级-恢复抖振或"自证恢复"？
- **Q3（车队覆盖）**：车队级覆盖审计（二项下置信界）在异构机体上如何给出可信的覆盖承诺？跨机 β 迁移与本地重标定、恢复证据 quorum 如何保持逐机证书可靠？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 逐时刻几何守卫律（Per-Moment Geometric Guard, HEC）**
证书可靠性分解为 β = β_model + β_HE + β_res；手眼几何残差 r_HE 在**可观测耦合子空间**上提供逐周期硬检查：r_HE ≥ τ_HE ⇒ 当周期证书失效、K_eff←1、启用模型无关活守卫。几何守卫只覆盖可观测子空间；不可观测子空间仍由 v10 共形管束（边际）负责——**两种保证职责分离、不可互相冒充**。

**P17 恢复需证据律（Recovery-Needs-Evidence, RC）**
向上迁移必须同时满足：(a) 触发降级的失效原因已清除且带裕度（恢复阈值 = 降级阈值/2）；(b) 满足 dwell T_dwell；(c) 存在**独立见证者**（≠ 触发降级的信号源）；(d) 若该边声明为"车队边"，则车队 quorum 复现。禁止跨级跳变（只能 ℓ→ℓ−1）；恢复后必须**重签**当前块证书再执行。恢复永不覆盖安全关键不变式。

**P18 车队验证覆盖律（Fleet-Validated Coverage, FCV）**
覆盖承诺以车队实证为准：N 台机器各 n 个样本的经验覆盖，取二项下置信界 ρ_cov；ρ_cov ≥ 1−α−ε 才判"车队可信"，否则保守回退。β 跨机迁移后必须本地重标定；恢复证据跨机迁移需 quorum。FCV 只读统计量、不改单机安全路径；失效即单机自报覆盖（等价 v10）。

## 3. 与基线的接口（如何退化）

- HEC 失效（T_HE 不可辨识 / 残差通道丢失）⇒ r_HE≡0、τ_HE≡∞，几何守卫停用，K_eff 门控回退 v10 共形门控（逐位等价）；
- RC 失效 ⇒ 禁用所有向上边，退化格坍缩为 v10 单向链（只降不升）；
- FCV 失效 ⇒ 覆盖承诺回退单机自报，β 不回退、恢复不需 quorum（等价 v10）；
- 三者全失效 ⇒ 精确 v10 CTZ；再沿 v10 链退到 v9 ACMD → v8 → v7 → v6。

## 4. 预期贡献

1. **逐时刻几何硬守卫**：以手眼 AX=XB 一致性把 v10 的边际保证在可观测子空间上补成逐时刻保证，正面治理"边际≠条件"风险；
2. **双向退化格 + 恢复证书**：把单向退化升级为受控恢复，含迟滞、独立见证、状态重签；
3. **车队级覆盖验证**：二项下置信界给出跨机覆盖承诺，恢复证据 quorum 与跨机 β 迁移；
4. **三债同治理 + 严格退化**：新模块均可注入中立元、逐位退回 v10，安全性由 v10 引理 87–93 传递；E591–E610 覆盖几何守卫即时性、恢复、车队覆盖、洗白攻击与端到端。

## 5. 本轮最大风险

**一句话**：手眼残差 r_HE 只在**可观测耦合子空间**上有效，而在线自标定可能把真实前向模型误差**吸收进 T_HE**（把 r_HE 优化到零）——于是逐时刻硬守卫被自己的自校准"洗白"，在最需要硬保证的耦合方向上反而最不可信；而不可观测子空间只剩 v10 那张"平均而言正确"的证书兜底。

# 第 11 轮产物 · 创新点清单 v11：**MetricVoiceGauge-HERM**（Hand-Eye geometric guard, Recovery-certified lattice & Multi-machine-validated coverage）

> 背景：第 10 轮 MetricVoiceGauge-CTZ（定义 540–551；引理 87–93；实验 E571–E590）。
> 本轮灵感：「失败恢复」×「手眼标定」×「多机评测」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v10 的 CEO/TCP/ZRA/CSD/CG 与 v9 的 AC/MW/ID 原样继承。新组件一律为**可选增强**：任一环节不可用 ⇒ 注入中立元，严格等价退回 v10 CTZ（引理 97），而非行为漂移。

**退化链声明（v11 契约化七级，全部可由中立元触发）：**
- **Level-0（几何失配）**：r_HE ≥ τ_HE 或 T_HE 不可辨识 ⇒ 当周期 K_eff←1、启模型无关活守卫、证书作废（新增，最先触发，逐时刻）；

- **Level-2**：TCP 不可行 / 管束越 β_max / QP 超时 ⇒ 退回 v9 AC 固定 β 采样 MPC；再不可行 ⇒ K=1；
- **Level-3**：CEO 失校 ⇒ β_t^{(i)}(k)←β^{(i)}（v9 常数余量）；
- **Level-4**：ZRA 失效 ⇒ 冻结 f̂（v9 前向模型）；CSD 失效 ⇒ 漂移信号回退 DA-ML 的 Δ_dom；
- **Level-5**：全部新模块失效 ⇒ 精确 v10 CTZ；再沿 v10 链退到 v9 ACMD → v8 → v7 → v6。

## 1. 符号体系增量（定义 552–563）

| 符号 | 含义 |
|---|---|
| T_HE ∈ SE(3) | 手眼变换（相机↔末端/基座），在线估计、按外参自由度慢更新 |
| A_t, B_t ∈ SE(3) | 相对末端运动（前向模型/正运动学）与相对相机运动（实测） |
| r_HE(t) = ‖log(A_t T_HE − T_HE B_t)‖ | 手眼几何残差（逐周期，AX=XB 不一致度） |

| ℓ ∈ {Full, L0, L1, L2, L3, L4, L5} | 能力级节点（双向退化格，定义 555） |
| rec_cert(e) | 恢复证书：原因清除+裕度 ∧ dwell ∧ 独立见证 ∧（车队边）quorum（定义 556） |
| T_dwell | 恢复确认所需连续周期数 |
| w(ℓ) | 降级边 ℓ 的**独立见证者**（≠ 触发降级的信号源，定义 558） |
| ρ_cov | 车队覆盖的二项下置信界（定义 560） |
| β_fleet → β_local | 跨机 β 迁移 + 本地重标定（定义 561） |
| q | 恢复边"车队可信"所需机器数 quorum（定义 562） |
| K_eff^{HERM}(t) | v11 有效块长（几何守卫与共形门控取交，定义 563） |

**新增定义 552（手眼几何残差）** 设 t→t+1 的相对末端运动 A_t 由前向模型/正运动学给出，相对相机运动 B_t 由视觉实测给出。手眼一致性要求 A_t·T_HE = T_HE·B_t（AX=XB）。残差
```
r_HE(t) = ‖ log_SE3( A_t · T_HE − T_HE · B_t ) ‖
```
其中 log_SE3 取 SE(3) 对数范数。T_HE 由在线 AX=XB 解（Tsai-Lenz/Park-Martin 或非线性最小二乘）估计，**只更新 6 个外参自由度、限速率、不与动力学残差联合优化**（防止定义 559 的洗白）。r_HE 每周期可得，作用在**可观测耦合子空间**（相机能看到的末端运动方向）。

**新增定义 553（证书余量三分解）** 将 v10 的共形半径按来源分解：
```
β = β_model + β_HE + β_res ,   β_HE(t) = c_HE · r_HE(t)
```
β_model 为 v10 共形分位数扣除手眼成分后的余项，β_res 为**不可观测子空间**的残余误差上界（相机几何看不见的状态方向，如相机自身内参漂移、被遮挡自由度）。β_HE 与 β_res 分别由 HEC 与 v10 管束承担，**不可互相抵消**。

**新增定义 554（逐时刻几何守卫）** 当周期硬检查：
```
guard_geo(t) = [ r_HE(t) < τ_HE  ∧  β_HE(t) ≤ β_HE^max ]
```
guard_geo=false ⇒ 当周期证书失效、K_eff←1、启用模型无关活守卫（引理 90）。几何守卫是**逐时刻**判据，不含任何统计假设；其覆盖范围严格限于可观测耦合子空间（见引理 94 与 §8）。

**新增定义 555（双向退化格）** 能力级节点 ℓ ∈ {Full, L0, L1, L2, L3, L4, L5}，Full 为 v11 全功能。**向下边**（ℓ→ℓ+1）：由 v10 各级触发条件即时触发（含 HEC：Full→L0）。**向上边**（ℓ→ℓ−1）：由恢复证书守卫（定义 556）。禁止跳级（不能 ℓ→ℓ−2）。格点的可达集 ⊇ v10 的退化链，故 v10 全部安全引理在每个节点成立。

**新增定义 556（恢复证书）** 对向上边 e: ℓ→ℓ−1，恢复证书
```
rec_cert(e) = cause_cleared(ℓ, τ/2)  ∧  dwell(ℓ) ≥ T_dwell
              ∧  witness_ok(w(ℓ))     ∧  (is_fleet_edge(e) ⇒ quorum_ok(e, q))
```
cause_cleared 要求触发降级的原因信号低于**降级阈值的一半**（迟滞，定义 557）；witness_ok 要求独立见证者健康（定义 558）；quorum_ok 见定义 562。

**新增定义 557（恢复迟滞）** 降级阈值 θ_d，恢复阈值 θ_r = θ_d/2（对 Δ_dom、τ_HE、δ、r_HE 等各信号一致）。θ_r < θ_d 保证"清除后才恢复"，配合 dwell T_dwell 消除降级-恢复抖振（引理 97）。

**新增定义 558（独立见证者）** 见证者 w(ℓ) 必须**不是**触发该次降级的信号源：
- 若由 CSD（统计漂移）降级 ⇒ w = HEC 几何残差 r_HE（物理几何）；
- 若由 HEC（几何失配）降级 ⇒ w = CSD 覆盖/漂移 + 车队覆盖 ρ_cov（统计 + 车队）；
- 若由 TCP/CEO/ZRA 降级 ⇒ w = HEC ∧ CSD 联合。
禁止"自证"：出故障的模块不得为自身恢复背书（引理 98）。

**新增定义 559（状态复原与重签）** 恢复发生时：(a) 丢弃当前动作块 ζ；(b) 以新能力级 ℓ−1 重新规划并**重签**证书 Ĉ；(c) 重置中止点集 P；(d) 记录恢复事件（原因、见证、quorum）供离线审计。防止"用降级前旧证书直接续跑"。

**新增定义 560（车队覆盖审计）** 车队 F={m_1,…,m_N}，各机 n_i 个覆盖试验（覆盖指示量 1[s ≤ β]），总成功数 S=Σs_i、总试验数 n=Σn_i，经验覆盖 p̂=S/n。**二项下置信界**
```
ρ_cov = p̂ − z · sqrt( p̂(1−p̂)/n )        (z=1.96 ⇒ 95% 单侧)
```
判据：ρ_cov ≥ (1−α) − ε 才判"车队可信"（ε=0.02）。若某机覆盖显著低于车队（残差 > 3σ），标记该机标定异常并触发本地重标定。

**新增定义 561（跨机 β 迁移与重标定）** 新机 m 冷启动用车队合并分位数 β_fleet 作先验；累计 W_local=200 样本后切换本地共形分位数 β_local（继承 v10 定义 541）。迁移只搬统计量、不搬模型参数；迁移期 K_eff 取保守值。

**新增定义 562（恢复证据 quorum）** 对声明为"车队边"的恢复边 e，在滑窗内统计各机 e 的恢复成功/失败；若成功机数 ≥ q（默认 q=⌈N/2⌉）且无机器复现失败，则 e 判"车队可信"，允许各机采用；否则 e 视为"本地边"，恢复需逐机重新取证。

**新增定义 563（有效块长 v11）**
```
K_eff^{HERM}(t) = 1                                  若 ¬(U_t ∧ guard_geo(t))
                = min( v10 定义 550 的 K_eff , K_geo(t) )   否则
K_geo(t) = max(1, ⌊K_max·(1 − min(1, r_HE(t)/τ_HE))⌋)
```
几何残差越大块越短；guard_geo=false 时直接 K_eff=1（等价 v10 Level-1 语义，但触发更快）。

# IP-362 HandEyeConsistencyGuard：手眼一致性几何守卫
class HandEyeConsistencyGuard:
    def __init__(self, tau_HE=0.01, c_HE=1.2, beta_HE_max=0.03, max_rate=1e-3):
        self.T_HE = init_extrinsic()          # 初始外参（可离线标定）
        self.tau_HE, self.c_HE = tau_HE, c_HE
        self.beta_HE_max, self.max_rate = beta_HE_max, max_rate

    def observe(self, A_t, B_t):
        # 在线 AX=XB：只更新 6 外参自由度、限速率，绝不与动力学残差联合优化
        dT = axb_delta(self.T_HE, A_t, B_t)   # 外参方向上的更新增量
        dT = clamp_norm(dT, self.max_rate)    # 限速 ⇒ 防定义 559 洗白
        self.T_HE = self.T_HE @ exp_se3(dT)
        r = se3_log_norm(A_t @ self.T_HE - self.T_HE @ B_t)   # 定义 552
        return r

    def guard(self, r):
        return (r < self.tau_HE) and (self.c_HE * r <= self.beta_HE_max)  # 定义 554

    def beta_HE(self, r):
        return self.c_HE * r                  # 定义 553


# IP-363 RecoveryCertifier：恢复证书器（双向退化格）
class RecoveryCertifier:
    def __init__(self, ratio=0.5, T_dwell=100, q=None):
        self.ratio, self.T_dwell, self.q = ratio, T_dwell, q
        self.dwell = defaultdict(int)

    def step(self, level, signals, thresholds, witness, fleet):
        # 向下：即时（含 HEC：Full->L0 由 guard_geo 触发，见主闭环）
        if self.down_triggered(level, signals, thresholds):
            self.dwell[level] = 0
            return level + 1
        # 向上：受恢复证书守卫，且禁止跳级
        if level != FULL and self.can_recover(level, signals, thresholds, witness, fleet):
            self.dwell[level] = 0
            return level - 1
        self.dwell[level] += 1
        return level

    def can_recover(self, level, signals, thresholds, witness, fleet):
        cause_cleared = all(signals[k] < self.ratio * thresholds[k]
                            for k in causes(level))            # 迟滞：θ_r=θ_d/2
        dwell_ok = self.dwell[level] >= self.T_dwell
        witness_ok = witness.independent_ok(w(level))          # 独立见证（≠触发源）
        fleet_ok = (not is_fleet_edge(level)) or fleet.quorum_ok(level, self.q)
        return cause_cleared and dwell_ok and witness_ok and fleet_ok


# IP-364 FleetCoverageValidator：车队覆盖验证器
class FleetCoverageValidator:
    def __init__(self, z=1.96, eps=0.02):
        self.z, self.eps = z, eps

    def audit(self, counts):                 # counts: [(successes_i, trials_i)]
        S = sum(s for s, _ in counts); n = sum(t for _, t in counts)
        p_hat = S / max(n, 1)
        rho = p_hat - self.z * math.sqrt(max(p_hat*(1-p_hat), 0.0) / max(n, 1))
        return rho                           # 定义 560 二项下置信界

    def fleet_trusted(self, rho, alpha):
        return rho >= (1 - alpha) - self.eps

    def quorum_ok(self, edge, q):            # 定义 562 恢复证据 quorum
        ok = sum(1 for m in self.fleet if m.edge_success(edge))
        fail = sum(1 for m in self.fleet if m.edge_failed(edge))
        return ok >= q and fail == 0

## 4. 推导（引理 94–100）

**引理 94（手眼残差对前向模型误差的逐时刻下界）** 设真实前向模型误差 e_t = x_{t+1} − f̂(x_t,a_t) 在**可观测耦合子空间** S_obs（相机可辨的末端运动方向）上的分量为 e_t^{obs}。若相机与标定噪声范数 ≤ η，则
```
r_HE(t) ≥ ‖e_t^{obs}‖ − η − ‖e_t^{unobs}‖_⊥
```
证明：A_t·T_HE − T_HE·B_t = T_HE·(T_HE^{-1}A_t T_HE − B_t)；括号项在 S_obs 上等于"模型预测末端运动 − 实测末端运动"的旋转/平移差，而实测与预测之差包含 e_t^{obs}（模型误差的可观测投影）与传感噪声；不可观测分量正交投影掉，仅经 ‖·‖_⊥ 进入。取范数即得。∎ 推论：S_obs 上误差越大，r_HE 越大；故 r_HE 是 S_obs 上模型误差的**逐时刻**代理（非统计）。

**引理 95（几何守卫的即时性与条件兜底）** r_HE 每周期可得，故 guard_geo 在失配发生后**1 个周期**内触发，关闭 v10"CSD/ACI 数步未覆盖"的缺口——但仅在 S_obs 上。对 S_obs 上的失配，条件安全由几何守卫**逐时刻**保证；对 S_unobs（不可观测子空间），逐时安全仍只由 v10 引理 90 的模型无关活守卫 + 共形管束（边际）承担。故 v11 安全 = 几何守卫（S_obs，逐时） ⊕ 活守卫/管束（全空间，逐时+边际）。∎

**引理 96（恢复安全 / 不引入新失效模式）** 恢复只沿格点向上边 ℓ→ℓ−1 移动，且每条边被 rec_cert 守卫；任意可达状态 ∈ {Full,L0…L5} ⊆ v10 退化格点。恢复不改变任何模块的取值集合，只改变"当前处于哪个已定义能力级"。故 v10 引理 87–93 在每个节点成立，恢复不产生格点外状态。∎

**引理 97（无抖振 / 无 Zeno）** 向下边即时、向上边需 cause_cleared(θ_r=θ_d/2) ∧ dwell(T_dwell)。因 θ_r<θ_d，一次降级后必须把原因信号压到降级阈值一半以下并保持 T_dwell 才能恢复，故相邻"降级→恢复"间隔 ≥ T_dwell 周期，翻转率 ≤ 1/T_dwell，有限时间迁移次数有限。几何边（HEC）与统计边（CSD）各自独立迟滞，互不诱导抖振。∎

**引理 98（恢复不自证）** 见证者 w(ℓ) 定义为"≠ 触发降级的信号源"（定义 558）。若 CSD 触发降级，见证为 HEC（独立物理通道）；若 HEC 触发降级，见证为 CSD+车队覆盖（独立统计/跨机通道）。故任何恢复都有至少一条**与故障源独立**的证据支持，杜绝"故障模块自证恢复"。∎

**引理 99（车队覆盖审计的置信性）** 覆盖指示量独立同分布近似下，二项下置信界 ρ_cov 满足 P(ρ_cov ≤ 真实覆盖) ≥ 1−z 分位置信（CLT/Clopper-Pearson 近似）。ρ_cov ≥ (1−α)−ε 判"车队可信"时，真实覆盖低于 1−α−ε 的概率被置信水平控制；异构机体上按机分层审计可检出标定异常机。∎

**引理 100（对 v10 的逐位退化等价）** 令 r_HE≡0、τ_HE≡∞、guard_geo≡true、RC 禁用所有向上边（格坍缩为 v10 单向链）、FCV 关闭（ρ_cov 不参与门控、恢复不需 quorum）。则定义 553 退化为 v10 单一 β，定义 554 恒真，定义 555 退化为 v10 退化链，定义 563 退化为 v10 定义 550。主闭环与 v10 CTZ 逐位一致：HEC/RC/FCV 只改变"取哪个 β""何时向上""是否需要 quorum"，在退化配置下取值集合与调用顺序均与 v10 相同。故 v11 故障格点 ⊇ v10，任一增强失效均可按 Level-0…Level-5 注入中立元、可观测日志逐位等价。∎

| 黑障恢复（E609） | 安全停驻、1 周期回 Full | 预载 T_HE、加速恢复路径 |
| 跨机可复现（E610） | 完成率 ↑≥10% | 契约表版本化、冲突消解 |

## 8. 本轮最大风险

**一句话**：手眼残差 r_HE 只在**可观测耦合子空间**上有效，而在线自标定可能把真实前向模型误差**吸收进 T_HE**（把 r_HE 优化到零）——于是逐时刻硬守卫被自己的自校准"洗白"，在最需要硬保证的耦合方向上反而最不可信；而不可观测子空间只剩 v10 那张"平均而言正确"的证书兜底。
