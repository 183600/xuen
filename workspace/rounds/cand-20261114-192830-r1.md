# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；本轮灵感：「社会影响」×「对比实验」）

> R69 把不确定性一分为二，用「流匹配多模态策略 + 主动交互」去消解 epistemic。但它有一个隐含、从未被检验的假设：**被问的人/信源是独立的、诚实的，而且我的提问不会污染答案**。R69 自己写下「单次交互不得定案，需 k 个正交证据源一致」，却把「正交」当成一个免费属性，而不是一个**待测量的量**。现实里，人会被别人影响、会顺着机器人的话头回答、会为了社交和谐而附和；多个信源一致，可能不是因为他们都对，而是因为他们**互相回声**。与此同时，R69 的「看/问/触」本质上都是**他人的证词或被动观测**；它从未考虑过一种更硬的证据：**自己做一个对比实验**。
>
> 本轮两个灵感正好补上两块缺失：
> - **社会影响**：信源不是孤立的陪审员，而是处在影响图上的社会主体；**一致 ≠ 独立，多数 ≠ 正确**。必须估计「有效独立信源数」，并把机器人自己对人的影响也放进因果图。
> - **对比实验**：世界不会撒谎。设计一个最小、安全、配对的干预对比，让**因果效应**而不是**他人证词**来裁决歧义。随机化是对外与对内同一个解药：对外打断信源之间的相互影响，对内打断机器人自己的提问引导。
>
> 核心命题：**epistemic 不确定性进一步拆成「证词型（testimonial）」与「实验型（experimental）」；证词型被社会影响图折损，实验型被因果可识别性约束；系统在两者之间做价值仲裁，都不可用才退回 R69 的交互消解、再退回 R68 的纯保守。** 命名 **SIREN-RAS**（Social-Influence-aware, contRastive-Experiment Navigated risk-adaptive system）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该信谁的话，还是自己动手做一个对比实验**」——证据不只有别人的嘴，还有世界的差分。

## 0. 直觉与动机

**灵感 1（社会影响 → 一致性是可疑的）**
直觉：R69 的证据纪律是「多个正交信源一致就采信」。但在一个会互相观察的群体里，信源之间先互相影响、再一起回答。此时观测到的相关性里，混着一部分由**影响图**机械制造出来的共识，而不是由**真实模态**制造的共识。更糟的是，机器人自己的提问会改变人的回答（引导性提问、社会赞许、对机器权威的顺从），于是「机器人用信念 b 去问 → 人顺着 b 回答 → 机器人把回答当作独立证据更新 b」构成一个闭环——这正是 R69 引理 18 假设 ρ<1 失效的地方，也是 R69 最大风险（把误导回答盖上「已验证」的章）的**结构性根源**，而不是偶发的投毒。

**灵感 2（对比实验 → 让世界当裁判）**
直觉：R69 的交互是「去问」。但很多歧义其实可以**测**出来：绕左还是绕右，不必问人，做一个小的、可回退的探行对比，看哪种预测更符合观测；接住还是避让，可以先用最小试探力做一次加载对比。「做一个小实验」与「问一句话」在信息论上同属 value-of-information，但**证据等级不同**：证词可以被撒谎和从众污染，配对干预对比只要满足随机化与可识别性，就由世界本身裁决。对比实验因此是 R70 的「硬证据通道」。

**灵感 3（随机化是同一个解药）**
直觉：社会影响的本质是**混杂**——信源的真实判断与群体共识混在一起，无法从一次观测里分开；自反影响的本质也是混杂——机器人的假设通过问法泄漏进答案。对抗混杂的通用工具就是**随机化**：对外随机化信息获取的顺序/对象/框架，打断信源间的诱导；对内随机化**语义等价的中立问法**，使问法与机器人当前假设统计独立。对比实验是「对干预随机化」，随机化问法是「对证词获取随机化」——同一个因果推断原则的两个面。

**灵感 4（严格泛化，而不是并列替代）**
直觉：R70 必须能被 R69 包含。若信源确实独立（ρ̄=0）、无自反影响、且实验不可行/不可识别，仲裁必然选择证词通道、k_eff=n，行为逐指令回落到 R69；若连证词的 VoI 也不为正，再回落到 R68。这样每加一层仍只增加一条**可审计、可关闭**的通道，而不是多一个需要独立信任的黑箱。安全侧永不弱于 R68，效率侧获得「实验裁决」的 resolution bonus。

**灵感 5（新威胁：实验洗白与操纵）**
直觉：一旦系统会「做实验」，就有了比「问错」更危险的新失败模式：**实验洗白（experiment-washing）**——用一个有未观测混杂的对比实验，给一个原本来自社会影响的偏见盖上「因果证实」的章。而且，随机化问法与对比实验一旦被用于**说服而非求真**，就从消歧变成了操纵。因此本轮必须同时交付：可识别性门控、双臂安全认证、非操纵预算、序贯有效停止（防反复偷看导致的假消解），以及社会影响审计。否则 R70 不是进步，而是给 R69 的「会撒谎的嘴」配了一双「会自证的实验手」。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（SIREN-RAS 总览）** SIREN-RAS = (SIG, SCE, RQI, CDE, CSS, ATR, AVS, SIA, STD, RAS-WM†)。在 R69 三不变式之上新增三条：
(i) **反射环零改动**：SIREN 只运行在慢环（决策停顿/交互时刻），2.6ms 实时反射环完全继承 R69；
(ii) **证据等级不可逆**：实验证据 > 去相关证词 > 单源/未去相关共识；低等级证据不得覆盖高等级证据（定义 324）；
(iii) **非操纵与无伤害**：任何信息动作必须同时通过双臂安全认证（定义 321）与非操纵预算（定义 322），否则作废。

**定义 311（社会信源模型与影响图）** 信源集合 𝒮，|𝒮|=n≤8（人、同伴机器人、LLM、标定模块）。信源 i 的报告 y_i = f_i(M,c) + b_i + η_i，其中 M 为模态身份，c 为上下文，b_i 为系统性偏向（迎合/自利/对抗），噪声满足 Corr(η)=R。影响图 A_t 为行随机矩阵，信源按 DeGroot 型规则更新公开信念 z_i ← (1−α_i)s_i + α_i Σ_j A_{ij} z_j（s_i 为私有信念、α_i 为社会易感度）。**关键**：观测到的一致部分由 R 与 A 共同生成，A 制造的一致性不携带关于 M 的信息。

**定义 312（有效独立信源数）** 令 ρ̄ 为去除共享可观测上下文后信源残差的平均非对角相关。定义
k_eff = n / (1 + (n−1)·ρ̄) ∈ [1,n]。
k_eff 是「设计效应」校正后的有效样本量：ρ̄=0 时 k_eff=n（R69 的独立情形），ρ̄→1 时 k_eff→1（单一共同冲击，全体一致也只等于一个信源）。R69 的 k 一律替换为 k_eff。

**定义 313（信源可信度与激励模型）** 信源 i 的可信度 c_i = P(y_i=M | 诚实)，激励类型 θ_i ∈ {honest, conformist, adversarial, self-interested}。SIREN **不假设诚实**，而以审计历史与跨情境一致性维护后验；conformist 的偏向与群体共识同向，adversarial 的偏向可与共识反向。

**定义 314（自反影响与提问内生性）** 提问 q 由当前信念 b 与策略 π 生成：q=π(b)。人/模型 answered 依赖 q 的表述：因果图 M→y←q，且 b→q。定义**泄漏量** L_q = I(q; y | M) 与自反强度 β = ∂y/∂q。当 q 是 b 的确定性函数且 b 依赖历史数据 D，则把 y 与 D 当作独立证据会重复计入 D→q→y 路径（证据双计）。线性高斯例：y=M+βq+ε、q=b，忽略 βq 会把观测精度高估 β²Var(q)，即**越自信地问，越过度自信**。

**定义 315（随机化问法 RQI）** 给定语义等价、情感中立、不透露机器人偏好的问法等价类 ℱ。RQI 从 ℱ 中按与 (b,M) 独立的分布抽取框架 f，生成 q=Decode_LLM(g_ask,f) 且不透露当前假设；随后以 f 为工具变量差分掉 presentation effect：用 inverse-propensity / 差分框架估计「M 对 y 的效应」。这使 q ⫫ (b,M)，从而斩断自反路径。

**定义 316（对比消歧实验 CDE）** 实验 e=(do(X=x_1), do(X=x_2))，在同一上下文块内配对执行（blocking），结果对比 τ = E[Y(x_1) − Y(x_2)]。设计目标：选择使**不同模态预测的 τ 差异最大**的一对臂，即
e* = argmax_e min_{i≠j} |τ̂(m_i) − τ̂(m_j)| / σ_diff(e)，
在候选臂对（≤ C(4,2)=6）与安全/预算约束下枚举。配对差分消除上下文共同项，方差 σ_diff² 远小于非配对 2σ²。

**定义 317（因果可识别性）** 实验 e 可识别当且仅当：(i) 正性 0<p(X|context)<1；(ii) 可交换性（随机化 ⇒ X ⫫ 潜在结果）；(iii) 一致性/SUTVA（无干扰、干预良定义）；(iv) 对比无未观测混杂（配对设计差分掉上下文混杂后仍成立）。记可识别性分数 id(e)∈[0,1]；id(e)<τ_id 的实验**不得单独定案**。

**定义 318（实验信息价值）** VoI_exp(e) = H(M|o) − E_{y}[H(M|o,e,y)]，净价值 = VoI_exp(e)·id(e) − c_exp(e)，c_exp 含时间、能耗、社交打扰与风险。仅当净价值 > 0 且通过定义 321/322 才可选。

**定义 319（证词—实验仲裁 ATR）** 通道 ch ∈ {experiment, testimony, none}：
score_test = IG_test(k_eff, c_i, δ, L_q) − c_social，
score_exp = VoI_exp(e*)·id(e*) − c_exp。
若 max(score) ≤ 0 → 返回 none，交回 R69 的 MINT 交互决策（可能仍不交互 → R68）。当 score_exp ≥ score_test 选实验，否则选去相关证词；**不允许证词覆盖已完成的可识别实验结果**。

**定义 320（anytime-valid 序贯裁决 AVS）** 实验按序贯 e-process 运行：E_t = Π_{s≤t}(1+λ_s(LR_s−1))，当 E_t ≥ 1/α 时停止并声明消解。由 Ville 不等式，在「模态未被真正消解」的原假设下，任意停止时刻误判概率 ≤ α。这防止长时实验中反复「偷看」造成的假消解与实验洗白。

**定义 321（反事实安全护盾 CSS）** 一个实验 e=(x_1,x_2) 可执行，当且仅当**两个臂**都通过 C-RAS-WM 前缀安全认证（即使只执行一个臂，随机分配也必须使任一臂安全），且期望物理/社交风险 ≤ ε_exp。任一臂不安全 ⇒ 实验不可采纳（不是「换一个更安全的臂」，而是整对作废，避免选择偏倚）。

**定义 322（非操纵预算）** 机器人在信息动作中对人的影响不得超过「如实传递信息本身」所必需：定义操纵量 Δ_man = 人信念的变化中超出其获得信息内容的部分。约束 Δ_man ≤ b_max，禁止利用从众、权威顺从、恐惧或欺骗；随机化问法因**降低**机器人影响而被允许。SIA 审计每次交互的 Δ_man 并与证书绑定。

**定义 323（社会影响审计 SIA）** 审计对象：影响图估计是否漂移、是否出现信息级联/共谋、实验是否预注册并按 AVS 停止、非操纵界是否越界、以及**互惠影响**（机器人是否亲手制造了它随后采信的共识）。结论回灌 AuditBuf，成为下一轮 c_i、ρ̄、成本与信任动态（STD）的先验。

**定义 324（证据等级与融合纪律）** 三级证据：Level 2 = 可识别对比实验；Level 1 = 去相关证词（k_eff≥2 且跨源一致）；Level 0 = 单源/未去相关共识。融合规则：实验作为似然、证词只作先验或佐证；若先验与似然来自同一批数据，必须样本分割，禁止证据双计。Level 0 永不得单独把 U_epi 置零。

**定义 325（威胁模型 ℰ_SIREN）** ℰ_SIREN = ℰ_FLUID × ℰ_social × ℰ_causal × ℰ_ethics。ℰ_social：级联、经共享影响图的共谋、声誉操纵、迎合/谄媚、社交工程；ℰ_causal：未观测共同原因、选择偏差、SUTVA 违背、实验者需求效应；ℰ_ethics：操纵、胁迫、隐私、未经同意的实验。

**定义 326（证书 J_SIREN）** J_SIREN = (J_FLUID, k_eff, ρ̄, source_graph_hash, channel_choice, experiment_design_hash, identifiability, e_value, manipulation_bound, siren_ver)。Valid ⇔ Valid(J_FLUID) ∧（若用实验：id≥τ_id ∧ CSS）∧ k_eff 证据纪律 ∧ 非操纵界 ∧ AVS 的 α 纪律。

**定义 327（三级保守退避）** 实验消解：λ=λ_floor(U_ale)（Level 2，最大 resolution bonus）；去相关证词消解：λ=max(λ_floor(U_ale)+δ_t, …)（Level 1，δ_t>0 为证词保留裕度）；未消解/超时/被污染/可识别性不足/ECE 越界：λ=λ_floor(U_ale+U_epi)（Level 0 = R69），再叠加 R68 的 slow_fault 最保守分支。对任意状态，λ 单调不低于 R68 的 λ_floor，且当「无实验、无自反影响、ρ̄=0」时逐指令等于 R69。

```python
# IP-264 SIG：社会影响图 + 有效独立信源数（慢环，n<=8）
class SocialInfluenceEstimator:
    def __init__(self, n):
        self.R = eye(n)                      # 残差相关矩阵
        self.A = uniform_row_stochastic(n)   # 影响图
    def update(self, reports, contexts, audits):
        r = residualize(reports, contexts)   # 去掉共享可观测上下文
        self.R = shrink_corr(ema_corr(r))
        self.A = fit_deGroot(r, self.A)
        return self
    def k_eff(self):
        n = self.R.shape[0]
        rho = clip((self.R.sum() - n) / (n * (n - 1)), 0.0, 1.0)
        return n / (1 + (n - 1) * rho)       # 设计效应校正
    def cascade_risk(self):
        return top_eig(self.R) / self.R.shape[0]   # 越接近1越像共同冲击

# IP-266 RQI：随机化问法，斩断自反影响
class RandomizedQuery:
    def __init__(self, framings, rng):
        self.framings, self.rng = framings, rng
    def ask(self, g_ask, belief):
        f = self.rng.choice(self.framings)   # f ⫫ (belief, M)
        return decode_neutral(g_ask, f), f    # 中立、不透露假设
    def debias(self, answers, framings):
        return iv_estimate(answers, framings)  # 工具变量差分 presentation effect

# IP-267 CDE：最小配对对比实验设计
def design_contrast(modes, causal_model, budget, shield):
    best = None
    for (x1, x2) in candidate_arm_pairs(causal_model):      # <= 6 对
        if not shield.certify_both(x1, x2):     continue     # 两臂都安全
        if not causal_model.identifiable(x1, x2): continue    # 正性/可交换/SUTVA
        tau = causal_model.predicted_contrast(x1, x2)
        sep = min_disagreement(modes, tau)                   # 模态预测差异
        n   = required_sample(sep, alpha, power)             # 配对设计
        score = sep - budget.cost(x1, x2, n)
        if best is None or score > best.score:
            best = (x1, x2, n, score)
    return best

# IP-269 ATR：证词 vs 实验的通道仲裁
def arbitrate(buf, sig, causal_model, budget):
    s_test = evidence_gain_testimony(sig.k_eff(), buf.credibility,
                                     buf.deception, buf.reflexive_leak)
    s_exp  = evidence_gain_experiment(causal_model, buf.modes) \
             * causal_model.identifiability()
    s_test -= budget.social_cost('testimony')
    s_exp  -= budget.cost('experiment')
    if max(s_test, s_exp) <= 0:
        return None                                  # 交回 R69 MINT
    return 'experiment' if s_exp >= s_test else 'testimony'

# IP-270 AVS：anytime-valid 序贯裁决
class EProcess:
    def __init__(self, alpha, h0):
        self.alpha, self.h0, self.E = alpha, h0, 1.0
    def update(self, y):
        lr  = likelihood_ratio(y, self.h0)
        lam = betting_fraction(self.E)
        self.E *= (1 + lam * (lr - 1))
        return self.E >= 1 / self.alpha                 # 可安全停止

        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))

    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    mode = select_mode(modes, 0.0 if resolved else U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.sia.submit(channel, k_eff, M.sig.rho_bar(), resolved,
                 M.sig.cascade_risk(), M.budget.manipulation_used)
    M.vqa_i.submit_async(channel, U_epi, a_hat)
    return k, lam, mode, (U_ale, U_epi, resolved, channel)
```

## 3. 推导

**引理 19（相关信源的证据折损）** 设 n 个信源等准确率 p>1/2、两两等相关 ρ̄，且对任一集中不等式其统计量方差按设计效应放大。则票差 S=Σx_i 的方差为 n p(1−p)(1+(n−1)ρ̄)，等价于独立样本量 k_eff = n/(1+(n−1)ρ̄)；故多数票错误率界由 exp(−n·I) 变为 exp(−k_eff·I)。系：ρ̄→1 时 k_eff→1，**全体一致不提供任何超过单源的证据**；R69 引理 18 的 δ_p·ρ^{k−1} 必须以 k_eff 重新标定。这是本轮对 R69 证据纪律最关键的一处修正。

**引理 20（自反影响的过度自信）** 线性高斯模型 y=M+βq+ε、q=b、b 依赖历史数据 D。若把 y 与 D 视为独立证据，等价于把 βq 当作噪声忽略，观测精度被高估 Δ_prec = β²Var(q) ≥ 0；当 β≠0 且 q 随信念变化时，后验方差系统性偏小、置信区间过窄。随机化问法使 q ⫫ (b,M)，β 的估计退化为可差分的 presentation effect，Δ_prec→0。系：**引导性提问不是「多一条证据」，而是「同一份证据被数了两遍」**。

**引理 21（对比实验的可识别性与效率）** 在正性、可交换性、SUTVA 下，配对对比 τ̂ = m^{-1}Σ(Y_i(x_1)−Y_i(x_2)) 无偏估计 τ，Var(τ̂)=σ²_diff/m，其中 σ²_diff=Var(Y(x_1)−Y(x_2))，强正相关配对远小于非配对的 2σ²/m。若存在关联强度 γ、方差 Var(U) 的未观测混杂且与处理回归系数为 δ，则偏倚 |E[τ̂]−τ| ≤ |γ·δ|；当该上界 > τ_id 时 id(e) 置零、实验不得定案。故「可识别性」必须与「统计显著性」分开报告。

**定理 18（SIREN 严格包含 R69 与 R68）** 当 ρ̄=0、L_q=0（q ⫫ b）、且无实验可行或可识别（VoI_exp≤0）时，k_eff=n、ATR 只能选证词或 none，SIREN 逐指令等价于 R69；当进一步 VoI_testimony≤c_social 时等价于 R68。且对任意状态，SIREN 的 λ 单调不低于 R68 的 λ_floor。故 R70 是 R69 的严格泛化、R68 的二次边界退化；安全侧不做任何让步，效率侧新增实验裁决的 resolution bonus。

**定理 19（通道仲裁的近优性与无伤害）** 在 CSS（双安全臂）与非操纵预算（Δ_man≤b_max）约束下，ATR 选择 max(score_test, score_exp) 的通道，其期望模态误差不高于任一固定单通道策略（因 VoI 定义为期望熵降，取最大者至少不劣于任一单项）；所有被选通道的物理风险 ≤ ε_exp、对人的影响 ≤ b_max。失败/超时/污染时按定义 327 单调回落到 R69/R68，控制连续、无突变（继承 R69 定理 17）。

**定理 20（序贯停止控制假消解）** 若每个实验预注册对比并运行 e-process，在 E_t ≥ 1/α 时停止，则在模态未被真正消解的原假设下，任意停止时刻声明消解的概率 ≤ α（Ville 不等式）。故「反复偷看、随时停止」不会膨胀假消解率；结合 id(e) 门控，**实验洗白**需要同时满足「可识别性被高估」与「α 纪律被绕过」，二者在审计下可分离。

## 6. 本轮最大风险

**一句话**：SIREN 把「证据」从别人的话升级为自己做的实验，但它的两块基石——**社会影响图/相关结构**与**对比实验的因果可识别性**——恰恰是最难从有限、非平稳、含人的数据里估准的量；一旦 ρ̄ 被低估或未观测混杂被漏掉，系统就会把**一个被社会塑造的偏见洗成「经实验证实」的事实**——**伪证（experiment-washing）比轻信更危险**，因为它披着因果的外衣，且会污染后续所有先验。

**次级风险与缓解**：
1. **社会影响图漂移/估错**（k_eff 高估 → 过度信任回声）→ SIG 在线校准 + cascade_risk 门控 + 保守先验 ρ̄_prior≥0.3，估计不确定时按更保守的 k_eff 下界使用；
2. **未观测混杂导致实验洗白** → 定义 317 可识别性门控 + 配对设计 + 敏感性分析（γ·δ 上界）+ AVS 的 α 纪律；
3. **机器人自身的操纵/自反污染** → RQI 随机化问法 + 非操纵预算 Δ_man + SIA 互惠影响审计；
4. **实验本身不安全或打扰过重** → CSS 双臂认证（任一臂不安全则整对作废）+ ε_exp 风险预算 + 社交成本入 VoI；
5. **实时预算被慢环实验侵蚀** → 实验严格限制在决策停顿、反射环零改动、慢环 < 1.2ms 且可随时中止；
6. **伦理与同意** → 人类被试预注册、最小侵入、可退出；ℰ_ethics 并入威胁模型并进证书。

## 3. 关键算法伪代码

```python
# IP-264 SIG：社会影响图 + 有效独立信源数（慢环，n<=8）
class SocialInfluenceEstimator:
    def __init__(self, n):
        self.R, self.A = eye(n), uniform_row_stochastic(n)
    def update(self, reports, contexts, audits):
        r = residualize(reports, contexts)
        self.R = shrink_corr(ema_corr(r)); self.A = fit_deGroot(r, self.A)
        return self
    def k_eff(self):
        n = self.R.shape[0]
        rho = clip((self.R.sum()-n)/(n*(n-1)), 0.0, 1.0)
        return n / (1 + (n-1)*rho)                  # 设计效应校正
    def cascade_risk(self):
        return top_eig(self.R)/self.R.shape[0]      # →1 表示共同冲击

# IP-266 RQI：随机化中立问法，斩断机器人自身影响
class RandomizedQuery:
    def __init__(self, framings, rng): self.framings, self.rng = framings, rng
    def ask(self, g_ask, belief):
        f = self.rng.choice(self.framings)          # f ⫫ (belief, M)
        return decode_neutral(g_ask, f), f
    def debias(self, answers, framings):
        return iv_estimate(answers, framings)        # 工具变量差分 presentation effect

# IP-267 CDE：最小配对对比实验设计
def design_contrast(modes, causal_model, budget, shield):
    best = None
    for (x1, x2) in candidate_arm_pairs(causal_model):
        if not shield.certify_both(x1, x2):      continue   # 两臂都安全
        if not causal_model.identifiable(x1, x2): continue   # 正性/可交换/SUTVA
        tau = causal_model.predicted_contrast(x1, x2)
        sep = min_disagreement(modes, tau)
        n   = required_sample(sep, alpha, power)            # 配对设计
        score = sep - budget.cost(x1, x2, n)
        if best is None or score > best.score: best = (x1, x2, n, score)
    return best

# IP-269 ATR：证词 vs 实验的净价值仲裁
def arbitrate(buf, sig, causal_model, budget):
    s_test = evidence_gain_testimony(sig.k_eff(), buf.credibility,
                                     buf.deception, buf.reflexive_leak) \
             - budget.social_cost('testimony')
    s_exp  = evidence_gain_experiment(causal_model, buf.modes) \
             * causal_model.identifiability() - budget.cost('experiment')
    if max(s_test, s_exp) <= 0: return None             # → R69 MINT
    return 'experiment' if s_exp >= s_test else 'testimony'

# IP-270 AVS：anytime-valid 序贯停止
class EProcess:
    def __init__(self, alpha, h0): self.alpha, self.h0, self.E = alpha, h0, 1.0
    def update(self, y):
        lam = betting_fraction(self.E)
        self.E *= (1 + lam*(likelihood_ratio(y, self.h0) - 1))
        return self.E >= 1/self.alpha                    # 可安全停止

# IP-275 主闭环：SIREN 插在 R69 的不确定性处置处；2.6ms 反射环不变
def SIREN_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(o)
    M.sig.update(M.last_reports, M.last_contexts, M.audit); k_eff = M.sig.k_eff()
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    resolved, channel = False, None
    if U_epi > TAU_EPI and not slow and M.mcg.pass_(M.last_ece):
        channel = M.atr.arbitrate(M.buf, M.sig, M.causal, M.budget)
        if channel == 'experiment':
            e = M.cde.design_contrast(modes, M.causal, M.budget, M.shield)
            if e is not None: resolved = M.run_experiment(e, M.avs)
        elif channel == 'testimony':
            g, f = M.rqi.ask(M.mint.choose_interaction(modes, o, M.budget), M.belief)
            ans  = M.cia.execute_blinded(g, f)
            resolved = M.cia.update_belief_k(modes, ans, k_eff) >= TAU_RES
    if   channel == 'experiment' and resolved:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale))
    elif channel == 'testimony' and resolved:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale) + DELTA_T)
    else:
        lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi))
    if slow: lam = max(lam, 0.8)
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow: k = min(k, k_cal_shrink(A, U_cal))
    mode = select_mode(modes, 0.0 if resolved else U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.sia.submit(channel, k_eff, M.sig.rho_bar(), resolved,
                 M.sig.cascade_risk(), M.budget.manipulation_used)
    M.vqa_i.submit_async(channel, U_epi, a_hat)
    return k, lam, mode, (U_ale, U_epi, resolved, channel)
```

## 4. 推导

**引理 19（相关信源的证据折损）** n 个等准确率 p>1/2、两两相关 ρ̄ 的信源，票差方差为 n·p(1−p)(1+(n−1)ρ̄)，等价独立样本量 k_eff=n/(1+(n−1)ρ̄)；多数票错误率界从 exp(−n·I) 变为 exp(−k_eff·I)。ρ̄→1 时 k_eff→1，全体一致不提供超过单源的证据；R69 引理 18 的 δ_p·ρ^{k−1} 必须以 k_eff 重标定。

**引理 20（自反影响的过度自信）** 线性高斯 `y=M+βq+ε`、`q=b`；忽略 `βq` 使观测精度高估 `β²Var(q)`，后验方差偏小。RQI 令 `q⫫(b,M)`，`β` 退化为可差分的 presentation effect，偏差归零。引导性提问不是多一条证据，而是同一份证据被数了两遍。

**引理 21（对比实验的可识别性与效率）** 正性/可交换/SUTVA 下，配对 `τ̂` 无偏，`Var(τ̂)=σ²_diff/m`，强相关配对远优于非配对 `2σ²/m`。存在未观测混杂（关联 γ、处理回归 δ）时偏倚 ≤ |γ·δ|；上界超阈值则 `id(e)=0`，实验不得定案。可识别性必须与统计显著性分开报告。

**定理 18（严格包含 R69 与 R68）** ρ̄=0、`L_q=0`、且无可行/可识别实验时，k_eff=n、ATR 只能选证词或 none，SIREN 逐指令等价 R69；再令 VoI_testimony≤c_social 则等价 R68。任意状态下 λ 单调不低于 R68 的 λ_floor。安全不让步，效率获实验裁决的 resolution bonus。

**定理 19（仲裁近优与无伤害）** 在 CSS（双臂安全）与非操纵预算下，ATR 选 max(score_test, score_exp) 的期望模态误差不高于任一固定单通道（VoI 为期望熵降，取最大者不劣于单项）；被选通道风险 ≤ ε_exp、对人的影响 ≤ b_max；失败/超时/污染按定义 327 单调回落，控制连续无突变（继承 R69 定理 17）。

**定理 20（序贯停止控制假消解）** 预注册对比 + e-process 在 `E_t≥1/α` 停止，则原假设下任意停止时刻误判概率 ≤ α（Ville）。故反复偷看不会膨胀假消解率；结合 id(e) 门控，实验洗白需同时「高估可识别性」且「绕过 α 纪律」，二者在审计下可分离。

## 7. 本轮最大风险

**一句话**：SIREN 把证据从别人的话升级为自己做的实验，但其两块基石——**社会影响图/相关结构**与**对比实验的因果可识别性**——恰是最难从有限、非平稳、含人的数据里估准的量；一旦 ρ̄ 被低估或未观测混杂被漏掉，系统就会把一个被社会塑造的偏见洗成「经实验证实」的事实——**伪证（experiment-washing）比轻信更危险**，因为它披着因果外衣，并污染后续所有先验。

**次级风险与缓解**：影响图漂移/估错（SIG 在线校准 + cascade_risk 门控 + ρ̄_prior≥0.3 保守下界）；未观测混杂（定义 317 门控 + 配对设计 + γ·δ 敏感性上界 + AVS）；机器人操纵/自反污染（RQI + Δ_man + SIA 互惠审计）；实验不安全或打扰过重（CSS 双臂认证 + ε_exp + 社交成本入 VoI）；实时预算被侵蚀（实验限于决策停顿、反射环零改动、慢环 <1.2ms 可中止）；伦理与同意（预注册、最小侵入、可退出，ℰ_ethics 进证书）。
