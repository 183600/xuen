# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；新一轮灵感循环第 1 轮；本轮灵感：「本体感知」×「技术融合」）

> 第 57 轮把证据承诺做到了"少样本可校准、跨模态可对账、个性化有界"，但它自陈的最大风险暴露了一个更深的结构性缺口：**整套证据体系全部由"外部观测通道"供料，没有任何通道测量"动作作用于身体之后的后果"**。视觉/触探/声学都在问"世界长什么样"，却不问"我刚才那一步，身体到底承受了什么"；于是一个能同时骗过所有外部通道的新世界（透明冰面、干沙下的空洞）在承诺发生前是隐形的。与此同时，第 57 轮的融合是**同质的**——它融合的是"信念"这一种类型，而不是把数据驱动的元模型、基于物理的动力学模型、身体内部的本体感觉、跨机器人/人类的证词这些**异质技术**放进同一张可审计的融合图；每个技术单独被验证过，但技术之间的**接缝**无人验证，而接缝恰是静默失效藏身之处。本轮两个灵感各补一刀：**本体感知**把"每一步都是一次免费的、作用于身体的实验"变成常开的证伪通道，并用"世界新奇 vs 身体漂移"的**归因分离**解决它的自指性；**技术融合**把"融合信念"升级为"类型化融合图 + 接缝契约 + 跨范式对账 + 跨体来源追溯"。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"本体可归因、融合可审计、跨体可追溯的证据承诺"**。

核心矛盾：
- **H29（本体自指 vs 世界新奇）**：本体感知永远在线、几乎零成本，但它自指——标定漂移、足端磨损、负载变化会让身体"对自己说谎"。同一个本体残差既可能是"世界很怪"，也可能是"我坏了"；两个方向的误判都危险：把身体漂移当成世界新奇会制造无谓绕行与假警报，把世界危险当成身体漂移则会**把真实危险"重新标定掉"然后继续走**。
- **H30（融合增效 vs 接缝失效）**：融合异质技术能产生任何单一技术都没有的能力，但每个融合接口都是一条未被认证的接缝；单独认证的部件可以组合成一个未被认证的系统。融合越深，接缝越多，而接缝上的单位/时标/标定/独立性假设失配是**静默**的——输出依然平滑，只是错了。
- **H31（跨体摊销 vs 身体异质）**：联邦/元学习用"全体机器人经验"换样本效率，但不同身体（质量、几何、执行器增益、足端柔度）的本体签名不同；跨体摊销的先验可能对新身体系统性错误（负迁移），且一次来源错误会沿经验谱系传播。
- **H32（实时自省 vs 控制时限）**：本体感知必须留在控制回路里（高频），但深度的归因、跨范式对账、跨体更新是慢的。若把慢推理塞进快回路，要么违反控制时限，要么被迫偷工减料——自省本身成为新的实时性风险。

## 0. 直觉与动机

**灵感 1（本体感知 → 常开证伪 + 世界/身体归因分离）**
直觉：机器人每走一步都在做一次**免费的物理实验**——脚踩下去，关节力矩、IMU、接触力、电流立刻返回"这一步的真实后果"。这是唯一直接测量"动作→身体"的通道，不需要探针预算、不需要人、不需要到访新区域。但它自指：身体模型本身可能是错的。关键不是残差的**大小**，而是残差的**模式**：**身体漂移是跨上下文持续的**（换一块地、换一个方向，同一条腿照样打滑），且与外感受**不一致**（视觉说地面干燥平整，脚下却滑）；**世界新奇是区域局部的**，且与外感受**同向**（视觉也觉得那块地不对劲）。于是把残差做**混合效应分解**——全局随机效应 Δβ（身体）与按区域分组效应 Δθ_w（世界）——就能把"我坏了"和"世界怪"分开。分开之后，身体漂移触发**重新标定 + 回溯作废依赖该参数的历史证据**；世界新奇触发**OOD 与探询**。归因不是锦上添花，它是让"免费证据"变安全的前提。

**灵感 2（技术融合 → 类型化融合图 + 接缝契约）**
直觉：真正的"技术融合"不是把几路信号加权平均，而是把**不同类型的判定器**（数据驱动元模型、物理动力学模型、本体图式、跨体/人类证词）按**类型**接线，并在每条边上写**契约**：输入输出类型、必须保持的不变量（区间包含、符号一致、摩擦锥、能量上界、标定覆盖）、误差界、独立性声明（统计/物理/因果三种，各配一个可执行的检验）、以及**接缝监视器**。接缝残差 s_ν 必须 ≤ 各输入误差界之和 + **实测**接缝松弛 ε_seam（绝不手设）。一旦越界，融合节点**退化为保守的区间外壳（Hull）**，绝不再吐点估计——宁可又宽又慢，不可又窄又错。融合因此从"一个 Fuse 函数"变成"一张可审计的图"。

**灵感 3（跨体联邦 → 活的语料 + 来源追溯 + 负迁移护栏）**
直觉：第 57 轮的元语料是静态的、且可能系统性盲区。把语料换成机队的**活经验流**，但每条经验都带**身体签名**与**标定来源**。迁移前过两道门：身体相似度 sim(β_i,β_j)≥θ_body，以及**预注册的本地验证**——该先验必须在留出的小标定集上不劣于本地非参基线，否则拒收、退回共形带。来源被事后证伪时，沿推导图**传递式撤回**其全部下游贡献。这样"坏先验普遍"从"无法察觉"变成"可被本地证据否决、可被来源追溯撤回"。

**灵感 4（物理-数据跨范式对账 → 不依赖"见过"的 OOD）**
直觉：第 57 轮的 OOD 门只能识别"语料里见过的模式之外"，本质上仍依赖语料。物理模型 g_ψ（刚体动力学 + 接触约束）对**没见过的新材质**依然能给出可行性判断：所需摩擦超过 μ_max、压力中心跑出支撑多边形、能量不守恒——这些是**语料无关**的硬约束。但物理模型也会错（未建模动力学），所以它不能当真理，只能作为**另一个独立失效模式**参与融合：物理说"不可行"是**硬告警**（独立于数据模型）；物理与数据的跨范式残差 δ 大，则作为**新的不确定性下限**触发加宽与归因。跨范式独立性比跨模态独立性更可辩护——它们不是同一个学习偏差的两个副本。

**灵感 5（合流 → 第六类证据、身体洁净证书、两时间尺度）**
直觉：证据门从五类扩到六类，新增 **EV-proprio**（本体证据），但它有一条硬限：**只能在线、只能用于已接触区域**——第一步之前没有本体证据，所以它**永远不能进入"首次不可逆接触"的必要证据集**（防止"免费证据"变成"免费风险"）。不可逆接触除原证据集外，还须满足**身体洁净证书** s_b≥θ_b、无物理硬告警、接缝洁净。架构分两时间尺度：快回路（控制率）只跑残差、接缝监视、硬告警，做反射式否决/降档；慢回路（检查点）跑归因、元推断、跨体更新、证据门。所有新机制只能经"加宽信念 / 作废证据 / 否决 / 降档"四个方向起作用，延续交互单调性。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（本体图式自省与残差归因 PBS）** 本体图式 β=(m,c,L,k_f,η,b_s)（质量/质心偏置/连杆/足端柔度/执行器增益/传感器偏置），在线估计 β̂_t 及协方差 Σ_β。本体模型 f_β̂ 预测 o^p_{t+1}，本体残差 r^p_t=o^p_{t+1}−f_β̂(o^p_t,u_t)。**混合效应分解**：r^p_t ≈ J_β(t)Δβ + J_w(t)Δθ_{w(r_t)} + ε，其中 Δβ 为**跨区域共享的全局随机效应**（身体漂移），Δθ_w 为**按区域分组的效应**（世界新奇）。归因后验 a_t∈{body,world,both,unknown} 由两组效应的后验质量决定：Λ_t=log[p(r^p,r^x|H_body)/p(r^p,r^x|H_world)]，|Λ_t|≤θ_attr 记 unknown。判 body 且 CUSUM_body 越界 ⇒ 宣布身体漂移：更新 β̂，并**传递式作废**所有似然依赖被漂移参数的历史证据（挂 provenance，复用前必须重探）。身体自信任 s_b=P(‖Δβ‖≤ε_β|data)，drift 时按检出延迟 D_b 单调下降。

**定义 140（本体证据通道 PEC）** 本体证据两型：EV-proprio⁺（预测的接触力/滑移/沉陷落在带内 ⇒ 正向确认）与 EV-proprio⁻（非预期滑移/沉陷/力尖峰 ⇒ 负向否决，可即时否决当前步态并强制降档）。**在线性硬限**：EV-proprio(r,t) 仅当机器人在 r 已执行 ≥1 次接触步时有效，故永不进入"首次不可逆接触"的必要证据集；它只能支持 L1 或进行中的 L0/L1，并充当第 57 轮 R3 事后证伪的**执行器**（预测接触失败 ⇒ 标记责任模态/先验为伪）。"免费证据"记账：定义单位能量证据产出，并规定免费证据不得顶替任何不可逆接触的承诺前证据。

**定义 141（融合契约 FCF）** 融合图 G_F 为有向无环图，节点 ν 的契约 C_ν=(τ_in,τ_out,I_ν,ε_ν,Indep_ν,μ_ν)：类型、不变量集、声明误差界、独立性声明（统计/物理/因果，各配可执行检验）、接缝监视器。边合法 ⇔ 类型匹配且上游不变量 I_ν⊆下游前条件。接缝残差 s_ν=d(output_ν, ⊕inputs)，运行时须满足 s_ν≤Σε_in+ε_seam(ν)，其中 **ε_seam 由标定集实测并审计，不得手设**。越界 ⇒ 节点退化为**保守区间外壳 Hull(inputs)**（Hull 必包含真值），发接缝告警，禁止再输出点估计；告警向上游传播为"无正向证据"。
