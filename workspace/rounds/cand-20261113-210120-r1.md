# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务」IP-243~252；本轮灵感：「目标检测」×「示教学习」）

> 第 68 轮把「标定」升格为在线潜变量，用自监督残差流和单模型多任务骨干把「测量可信度」第一次纳入闭环。但它自己的最大风险已经把下一块短板写得清清楚楚：**漂移与故障只靠「时间带宽」一根轴来分离**（引理 13：ω_f ≥ 3ω_cal）。单轴可分是脆弱的——只要真实故障长得和漂移一样慢，它就被 COF「标好」，CFA 抬高 H_cal，系统在「测量越来越准」的假象中失去检出能力。**一根轴无法定义坐标系，至少需要第二根轴。**
>
> 本轮两个灵感恰好各补一根轴：
>
> - **目标检测**补上「空间/实体轴」：世界不是一袋无结构的残差数字，而是有身份、有几何、可被多模态重复观测的**物体**。被检测并持续跟踪的物体是天然的**计量锚点（fiducial anchor）**。漂移是作用在全部锚点上的**低秩全局变换**，故障是只作用于少数锚点/区域/模态的**稀疏局部破坏**——于是「漂移 vs 故障」变成一个 **低秩 + 稀疏分解（Robust PCA）** 问题，即便两者时间带宽完全相同也可分。
> - **示教学习**补上「任务/意图轴」：示教不是一段可模仿的轨迹，而是三重免费资源——(a) **任务相关性**（哪些锚点值得看）、(b) **激励信号**（示教动作天然激励标定模态，是主动系统辨识的激励源）、(c) **纠正标签**（人类接管/纠正是对「测量或决策错了、错在哪」的稀有高价值标注）。示教把 R68 的「2s 不收敛 → 冻结按最坏情况」升级为「**查询示教 → 恢复可辨识性**」。
>
> **核心命题：用「目标检测提供的任务相关锚点图」把标定从 12 维盲 EKF 变成可辨识的低秩计量；用「示教」同时提供任务相关性、标定激励与纠正标签，让「漂移 vs 故障 vs 世界真变了」三分解在时间、空间、意图三根轴上同时受约束——DOME-RAS（Demonstration-anchored Object-detection Metrology for risk-adaptive Embodied systems，示教锚定·目标计量·风险自适应闭环）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我凭什么相信这个『准』字——参照系本身从哪里来**」。

## 0. 直觉与动机

**灵感 1（目标检测 → 物体是天然的计量锚点，几何自带冗余）**
直觉：R68 把残差 r_t 当成一袋无结构的数丢进 12 维 EKF，滤波器只能「整体地」解释残差，于是任何看起来像慢变量的东西都能被吸收。但物理世界是有结构的：一个杯子同时被 RGB、深度、触觉/力感知，三种独立测量指向**同一个实体**，它们之间的闭合环就是一条标定约束——这正是 SLAM/光束法平差（bundle adjustment）的老智慧：相机外参由「同一批路标在多视角下的重投影一致性」标定，而不是由「整幅图像的统计量」标定。把物体检测+跟踪引入闭环，等于给标定装了**路标**：
- 一条边（edge）是「同一实体的一次跨模态/跨时刻重复观测」；
- 全局一致的缓慢形变 = **低秩**的标定漂移 L_t；
- 只影响个别实体/区域/模态的突变 = **稀疏**的真实故障 S_t；
- 残差矩阵 R = L + S + N，用加权 Robust PCA 分离。
关键收益：**空间支撑（哪些锚点不一致）提供了与时间频率正交的第二判别轴**。一个「慢得像漂移」的故障，只要它是**局部**的（只坏了一个传感器的一段视场、一个触觉阵列、一只轮子的力零偏），低秩项就解释不了它，稀疏项必然把它抓出来。R68 的最大风险被结构性拆除，而不是靠调阈值硬扛。

**灵感 2（示教学习 → 示教既是标签，也是激励，还是恢复技能）**
直觉：人类专家示范对机器人研究者最朴素的意义是「照着做」，但对一个**计量闭环**而言，示教的价值远不止策略：
- **任务相关性 w_demo(e)**：专家在示教中看什么、碰什么、绕过什么，直接告诉我们哪些锚点是 task-critical、哪些可以先不管。这把「全场景一致性检验」收缩为「任务路径一致性检验」，既降误报又降算力；
- **持久激励（persistent excitation）**：系统辨识的第一定理是「没有激励就没有可辨识性」。R68 在锚图秩亏时只能冻结、按最坏情况走；而示教动作（抓取、旋转、推拉、多视角巡视）天生让标定参数变得可观测。**示教 = 主动系统辨识的激励设计**，把「不可辨识」变成「主动查询一次示教/一次安全探针即可辨识」；
- **纠正标签**：人类接管、急停、手动修正，是极稀有但极干净的监督信号——它同时标注了「状态是坏的」「正确动作是什么」，并隐式指出「哪个锚点/测量不可信」。R68 的 CAC canary 集覆盖不到缓变故障，而**人类对缓变故障的每一次纠正都是现成的 canary**；
- **恢复技能库 R_demo**：R66–R68 的保守纪律只会「收紧 λ、收缩前缀、最后停机」。示教接管片段天然是「故障发生后人怎么做」的恢复策略库，让系统从「只会变保守」升级为「保守 **或** 执行一个已被示范验证过的安全恢复」。

**灵感 3（两灵感合流 → 三轴可辨识性，而不是又加一层模块）**
直觉：R68 的单轴判别是「一维投影」，两个量在一维上重合就永久不可分。目标检测给第二根轴（空间：低秩 vs 稀疏），示教给第三根轴（意图：任务一致 vs 任务偏离）。三根轴构成一个**并集判别**：只要任意一根轴把漂移与故障分开，系统就可辨识；要同时骗过三根轴，攻击者必须构造一个「时间上像漂移、空间上低秩、意图上又完全符合专家预期」的残差——这是一个**测度极小、且必须与任务语义同谋**的集合。这把「标定能力越强、慢故障越隐形」的原罪，转化为「**至少三根轴里会有一根露出破绽**」的可证伪命题。

**灵感 4（三灵感合流 → DOME-RAS 六组件）**
1. **TAG Task-relevant Anchor Graph**：检测+跟踪产出任务相关实体锚点，构建跨模态/跨时刻/跨实体的异构观测图；
2. **STCD Spatio-Temporal Coherence Decomposition**：在锚残差矩阵上做加权低秩+稀疏分解，L_t 喂标定、S_t 喂故障；
3. **DEX Demonstration-Excited Identifiability**：锚图雅可比秩亏时，选一段能最大化激励不可观测子空间的示教/安全探针；
4. **DCL Demonstration-Correction Labels**：把人类纠正转成 cal-vs-fault 判别的监督标签、CAC 的缓变故障 canary、以及「何时该不信任自己」的元标签；
5. **DRP Demonstration-conditioned Recovery Policy**：故障归因后从示教恢复技能库中选一个风险有界的安全恢复，选不出才停机；
6. **RAS-WM†† 继承核**：ACH-RAS / EFS / C-RAS-WM / ERS-WM / MTM / SSG / COF / CFA / CAC 全保留，只是 COF/CFA 的观测被 TAG+STCD 重构、CAC 被 DCL 增广。

**灵感 5（对 R68 风险的对症下药）**
- R68「缓变故障被标定吸收」：STCD 的空间稀疏轴直接拆除「时间带宽相同」这一前提；
- R68「标定红线悖论（红线也依赖初始标定）」：TAG 的多模态锚环 + 示教纠正提供**外部/半外部参照**，红线可由锚环残差自洽地在线核验；
- R68「伪标签自毒」：DCL 的纠正标签来自人类而非模型自预测，切断自指回路；
- R68 遗留的「过度保守」：DRP 把「只会停机」升级为「执行示范过的安全恢复」；
- 新引入的「算力/实时性」：检测器只在任务相关 ROI 上跑、与 MTM 共享底层特征但**保留一条独立模态（深度/触觉/标定板）用于可辨识性**（见定义 302 与最大风险）。

## 1. 形式化定义（增量：定义 293–306）

**定义 293（DOME-RAS 总览）** DOME-RAS = (TAG, STCD, DEX, DCL, DRP, RAS-WM††)。三条新不变式叠加于 R68 定义 276：
(i) **锚一致性不变式**：标定只允许解释在任务相关锚点上**低秩相干**的残差；空间稀疏/局部残差一律不得被标定吸收（稀疏否决权）；
(ii) **示教接地不变式**：计量层的任何自监督更新必须有示教纠正或外部锚点提供接地，禁止 R68 式的纯自指更新；
(iii) **可辨识性不变式**：当前锚图上 rank(J_G(c_t)) < dim(c_eff) 时，必须先由 DEX 激励/查询，或在「计量弃权态」下按最坏情况归因，禁止在不可辨识时输出高置信标定。

**定义 294（任务相关锚图 TAG）** 时刻 t 检测+跟踪得到实体集 E_t，每个实体 e 含掩码/框、类别、跟踪 id、几何 g_e（位姿/尺寸）、检测置信 q_e，以及跨模态关联矩阵。任务相关性 w_e = w_demo(e)·w_geo(e)，其中 w_demo 由示教注意力/接触统计学习。锚图 G_t = (E_t, A_t)，A_t 为异构边：
- 跨模态边（视觉↔深度↔触觉/力测量同一实体）；
- 跨时刻边（同一跟踪 id 的连续观测）；
- 跨实体边（先验已知的刚体/装配关系）。
每条边 a 产出残差 r_a（重投影/尺度/相对位姿/接触点一致性）。

**定义 295（锚残差矩阵与 STCD 分解）** 将带权边残差堆成 R_t ∈ ℝ^{m×n}（m 条约束、n 个模态或时间窗），权重 w_a。分解
R_t = L_t + S_t + N_t，
其中 L_t = J_cal(c_t)·δc + L_0 为 **低秩**（rank ≤ r_cal）全局标定分量，S_t 为 **稀疏**（‖S_t‖_0 ≤ k_fault）局部故障分量。用加权 Robust PCA 求解
min_{L,S} ‖L‖_* + λ‖S‖_1 + (μ/2)‖W^{1/2}∘(R−L−S)‖_F²，λ = 1/√(max(m,n))。
标定观测用 L_t（喂 COF），故障证据用 S_t 的支撑 supp(S_t)（喂 CFA）。

**定义 296（三轴可分性）** 称漂移 δc 与故障 s 在时刻 t 可分，若满足以下**任一**条件：
- **(T) 时间轴**：ω_f ≥ 3ω_cal（R68 引理 13）；
- **(S) 空间轴**：rank(L_drift) ≤ r_cal 且 ‖S_fault‖_0 ≤ k_fault，且 (r_cal, k_fault) 满足 RPCA 的非相干/秩-稀疏折中条件（引理 16）；
- **(I) 意图轴**：锚几何相干（S≈0）但示教一致性残差 r_demo 显著超阈（定义 297）。
判别规则：三轴投票，任一轴报警即进入故障分支；三轴同时「无信号」才允许 H_cal。**三者是并集，不是交集**——这直接对应「至少一根轴露出破绽」。

**定义 297（示教相关性与示教一致性残差）** 给定示教集 D = {(o_i, a_i^*)}：学习任务相关性 w_demo(e) 与示教条件策略 π_demo(·|z_t)。定义示教一致性残差
r_demo = −log π_demo(a_t | z_t) + ρ_demo·d(ô_t, o_t^{demo-manifold})，
即「在当前观测下，专家会怎么做/世界本该长什么样」的偏离度。r_demo 高而锚几何自洽 ⇒ **世界/任务真变了**（H_real），既非漂移也非传感器故障。

**定义 298（示教激励可辨识性 DEX）** 标定可辨识 ⇔ 锚图雅可比 J_G(c_t) 列满秩。秩亏时取不可观测子空间 U_0 = null(J_G)。DEX 选择示教片段/安全探针 d*：
d* = argmax_{d ∈ D ∪ D_probe} λ_min( P_{U_0} J_G(d)^T W J_G(d) P_{U_0} )，
s.t. 安全约束（定义 276-ii 红线）与人类查询预算 B。若预算内无法恢复秩条件 → 进入计量弃权态（定义 300 的 fallback），禁止高置信输出。

**定义 299（示教纠正标签 DCL）** 人类干预集合 L_demo = {(s_t, intervention_type, a_t^{corr}, attributed_anchor)}。它提供三类监督：
1. cal-vs-fault 判别器的监督标签（把 S_t 的支撑与人类指认对齐）；
2. CAC 的缓变故障 canary 集 D_canary^slow；
3. 元标签「此刻标定本身不可信」，训练弃权分类器 P(trust | features)。
DCL 是 R68 自监督体系之外的**外生接地**，按引理 18 以 O(√(d/n_corr)) 降低判别误差。

**定义 300（计量弃权态与示教条件恢复 DRP）** 当 U(ĉ) > τ_cal 或三轴均不可辨识时，系统进入**计量弃权态**：λ_floor = 0.8、前缀收缩 k_cal、所有高置信结论撤回。此时若 joint_post 指向真实故障，DRP 从示教恢复技能库 R_demo 中选择
ρ* = argmin_{ρ ∈ R_demo} Risk(ρ; joint_post, U) s.t. 风险上界 ≤ 停机风险，
执行示范验证过的恢复；若 R_demo 中无满足者则停机（k*RAS = 0）。这把「保守」从被动收缩升级为「主动、有界、可示范验证的恢复」。

**定义 301（CAC-Slow 增广）** 在 R68 五关（定义 287）上，用 DCL 增广金标/ canary：
- 金标集加入缓变故障示范纠正样本；
- canary 不可修复性判据改为**对稀疏项**成立：候选适配器须使 ‖S_canary‖_1 ≥ τ_sparse，即不得把低频故障的稀疏支撑也解释掉（防止「低秩+稀疏联合吸收」）；
- 新增第六关「锚偏置关」：候选适配器不得改变 col(J_det)∩col(J_cal) 的秩（定义 302），否则一票否决。

**定义 302（锚-标定混淆与可辨识缺陷）** 检测器偏差 b_det 与标定漂移 δc 可混淆，若存在非零 δc 使 J_det·b_det ≈ J_cal·δc，即
col(J_det) ∩ col(J_cal) ≠ {0}。
此时纯内部方法在数学上无法区分「检测器系统性偏了」与「标定漂了」。可辨识缺陷维数 d_conf = dim(col(J_det) ∩ col(J_cal))。必须由外部参照（标定板/已知尺寸 fiducial/独立深度或触觉通道）张成的子空间补足：require col(J_F) ⊇ col(J_det)∩col(J_cal)。

**定义 303（锚覆盖度与弃权）** 锚覆盖度 cov_t = Σ_{e∈E_t^crit} w_e·1[#独立模态(e) ≥ 2] / Σ_{e∈E_t^crit} w_e。cov_t < cov_min（任务关键实体缺少冗余观测）⇒ 可辨识性不足，按计量弃权态处理。

**定义 304（J_DOME 证书）** J_DOME = (J_CALM, anchor_graph_hash, rank(J_G), cov_t, d_conf, sparse_support_hash, demo_set_hash, recovery_id, demo_grounding)。Valid ⇔ Valid(J_CALM) ∧ rank(J_G)=dim(c_eff) ∧ cov_t ≥ cov_min ∧ d_conf 被外部参照覆盖 ∧ 红线未越界。

**定义 305（管线）** 离线：训练检测/跟踪与示教策略 → 从 D 学 w_demo、π_demo、R_demo → 在锚图上做 STCD 自监督预训练 → 首次标定与 CAC 提交。在线：TAG（任务 ROI 降采样）→ STCD（100ms 窗口）→ COF（用 L_t）→ CFA（用 S_t）→ 秩亏则 DEX 查询 → DRP 恢复 → CAC-Slow 异步提交。

**定义 306（运行时预算不变量）** 检测仅在任务相关 ROI 上以 ≥10Hz 运行、跟踪插值补帧；STCD 与 DEX 检查在 100ms 慢环、CAC/SSG/VQA-D 在影子/异步环；实时控制环保持 R68 的零学习写操作，并新增「稀疏否决」原子检查（O(1)）。

## 2. 关键算法骨架

```python
# IP-253 TAG：任务相关锚图（检测+跟踪 → 异构观测图）
class TaskRelevantAnchorGraph:
    def build(self, obs, w_demo):
        E   = self.detector_tracker(obs.rgb, obs.depth)      # 实体/几何/跟踪id/置信
        A   = self.cross_modal_edges(E, obs)                 # 视觉↔深度↔触觉
        A  += self.temporal_edges(E)                         # 同一 track
        A  += self.relation_edges(E)                         # 已知刚体/装配关系
        w   = w_demo(E) * self.geo_weight(A)                 # 任务相关性 × 几何置信
        return AnchorGraph(E, A, w)

# IP-254 STCD：加权 Robust PCA，低秩=标定，稀疏=故障
class SpatioTemporalCoherence:
    def decompose(self, R, w, r_cal, k_fault):
        W  = sqrt(w)                                         # 约束权重
        L, S = weighted_rpca(W * R, lam=1/sqrt(max(R.shape)),
                             rank_bound=r_cal, sparsity_bound=k_fault)
        return L, S                                          # L→COF，supp(S)→CFA

# IP-255 DEX：秩亏 → 选最能激励不可观测子空间的示教/安全探针
class DemoExcitedIdentifiability:
    def ensure(self, G, c, budget):
        while matrix_rank(self.J(G, c)) < self.dim_eff and budget.left:
            U0 = null_space(self.J(G, c))
            d  = self.select_probe(U0, G)                    # argmax λ_min(P_U0 JᵀWJ P_U0)
            self.run_or_query(d)                             # 安全探针或请求示教
            budget.spend(d)
        return self.rank_full(), self.frozen                 # 秩满 or 弃权

# IP-257 DCL：把人类纠正转成监督/ canary / 元标签
class DemonstrationCorrectionLabels:
    def ingest(self, intervention):
        self.discriminator.add(s=intervention.state, y=intervention.cal_or_fault,
                               anchor=intervention.attributed_anchor)
        self.canary_slow.add(intervention.corrected_trajectory)
        self.trust_meta.add(features=s, label=0)             # 标定不可信

# IP-258 CFA-2：三轴投票归因（继承 R68 定义 281）
def three_axis_attribution(L, S, r_demo, c, U, cof):
    if not cof.converged_within(2.0): c, U = cof.freeze(), np.inf
```

## 3. 推导

**引理 16（秩-稀疏两轴可分性）** 设 R = L_0 + S_0 + N，rank(L_0) ≤ r、‖S_0‖_0 ≤ k，且 L_0 满足 μ-非相干、S_0 支撑均匀分布。若 r ≤ c₁·min(m,n)/(μ log² max(m,n))、k ≤ c₂·mn，则以概率 ≥ 1 − C·max(m,n)^{−c₃} 有 L̂ = L_0、Ŝ = S_0。系：**当漂移与故障的时间带宽完全相同（T 轴失效）时，只要故障空间支撑稀疏且漂移低秩，S 轴仍能精确分离**——这正是 R68 最大风险的结构性解药。

**引理 17（激励-可辨识等价）** 标定 δc 在锚图 G 上可辨识 ⇔ rank(J_G) = dim(c_eff)。DEX 的探针选择使 λ_min(P_{U_0}J_G^T W J_G P_{U_0}) 单调上升；经 B 次查询后若该值 ≥ ε_pe，则 Σ_c 在 U_0 方向的方差下降至少 ε_pe 倍。系：**示教不是策略迁移的奢侈品，而是可辨识性的必要投入**；把它放在"2s 超时"之前，等于把不可辨识从「失败」变成「可查询」。

**引理 18（外生纠正标签的样本复杂度）** 设 cal-vs-fault 判别器 VC 维为 d，纠正标签 n_corr 条，则泛化误差 ≤ O(√(d/n_corr))；由于纠正样本稀有但对边界（尤其缓变故障）信息量极大，其有效样本增益约为自监督伪标签的 1/ρ_demo 倍（ρ_demo 为示教覆盖偏差）。系：**DCL 用 O(1/ρ_demo) 的样本量补上 R68 canary 集的覆盖空洞**。

**定理 16（DOME-RAS 端到端风险一致性，扩 R68 定理 14）** 在 A87–A94 与新增 A95（锚图非相干）、A96（示教覆盖）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_anchor + α_demo**；
2. 若 (T)∨(S)∨(I) 任一成立，则缓变故障检出概率 ≥ 1 − δ_S（引理 16/18），**R68 的「慢故障隐形」单点失效被解除**；
3. 若三轴同时不可分（T∧S∧I 全失效），系统进入计量弃权态：λ ≥ 0.8 ∧ k 收缩 ∧ 撤回高置信结论——**不可辨识永远导向收缩**；
4. DRP 恢复风险上界 ≤ min(停机风险, 任一 R_demo 恢复风险)；若 R_demo 为空则退化为 R68 的保守停机，风险不回退。

**定理 17（参照系自指安全性）** 若 col(J_det) ∩ col(J_cal) ≠ {0}（d_conf > 0），则任何仅使用检测锚点与内部残差的估计器都无法区分检测偏差与真实标定漂移；可辨识性当且仅当外部参照 F 满足 col(J_F) ⊇ col(J_det)∩col(J_cal)。系：**闭环的可信度上界由外部参照的秩决定，而非由内部模型精度决定**；这既解释了 R68 的标定红线悖论的根源，也指出了本方案的真正天花板。

## 6. 本轮最大风险

**一句话**：DOME-RAS 把计量参照系交给了目标检测器，而检测器本身是学习模块——**若检测偏差是低秩且任务相关的（系统性地把某类物体整体偏移/缩放），它恰好落在标定雅可比的列空间里，于是结构上与真实标定漂移不可区分，又因其低秩而躲过稀疏项**，系统会用「越来越自洽」的锚把整个空间参照系带偏；示教也救不了，因为人类纠正标注的是任务结果而非传感器几何——「参照系自指（reference-frame self-reference）」取代缓变故障，成为新的不可见失效。

**次级风险与缓解**：
1. **锚覆盖不足/遮挡** → cov_t 门控 + 计量弃权态 + 跟踪插值 + 主动视角（DEX）；
2. **检测算力超预算** → 任务 ROI 剪枝 + 慢环跟踪插值 + 与 MTM 共享底层特征（但保留独立深度/触觉/标定板通道）；
3. **RPCA 非相干条件不满足（漂移并不低秩）** → 分段/局部低秩 + 稀疏度自适应 + 三轴中仍有 T/I 兜底；
4. **示教分布偏移/覆盖偏差** → DCL 置信加权 + 示教 Sim2Real 校准 + 无覆盖时退回停机的保守纪律；
5. **DEX 查询的人类成本与安全** → 优先安全探针、查询预算硬上限、探针动作受红线约束。

**定义 301（CAC-Slow）** 五关 + 稀疏 canary（`‖S_canary‖_1 ≥ τ_sparse`）+ 锚偏置关（不得改变 d_conf 的秩），否则一票否决。

**定义 302（锚-标定混淆）** `col(J_det)∩col(J_cal)≠{0}` 时检测偏差与标定漂移内部不可分；须由外部参照 F 满足 `col(J_F)⊇col(J_det)∩col(J_cal)`。

**定义 303（锚覆盖度）** `cov_t = Σ w_e·1[#独立模态≥2] / Σ w_e`；`cov_t<cov_min` ⇒ 弃权态。

**定义 304–306（证书/管线/预算）** J_DOME 扩 J_CALM；在线检测走 10–15Hz 慢环+跟踪插值、STCD 走 100ms 慢环、实时控制环保持零学习写操作并加 O(1) 稀疏否决。

```python
# IP-253 TAG：检测+跟踪 → 任务相关锚图
class TaskRelevantAnchorGraph:
    def build(self, obs, w_demo):
        E = self.detector_tracker(obs.rgb, obs.depth)
        A = self.cross_modal_edges(E, obs) + self.temporal_edges(E) \
          + self.relation_edges(E)

# IP-254 STCD：低秩=标定，稀疏=故障
def stcd(R, w, r_cal, k_fault):
    return weighted_rpca(sqrt(w) * R, lam=1/sqrt(max(R.shape)),
                         rank_bound=r_cal, sparsity_bound=k_fault)   # L, S

# IP-255 DEX：秩亏 → 激励/查询
def ensure_identifiable(G, c, budget):
    while matrix_rank(J(G, c)) < dim_eff and budget.left:
        U0 = null_space(J(G, c))
        run_or_query(argmax_excitation(U0, G))       # 安全探针 or 请求示教
        budget.spend()
    return matrix_rank(J(G, c)) == dim_eff

# IP-258 CFA-2：三轴并集投票
def three_axis_attribution(L, S, r_demo, c, U):
    h_T, h_S, h_I = post_lowrank(L, c), post_sparse(S), post_demo(r_demo)
    joint = merge(h_T, h_S, h_I)
    return worst_case_post(joint) if (U > TAU_CAL or not rank_ok) else joint

# IP-257 DRP：示教条件恢复
def demonstration_recovery(joint, R_demo, U):
    if not fault_dominant(joint): return None
    ok = [r for r in R_demo if risk_upper(r, joint, U) <= risk_halt]
    return min(ok, key=lambda r: risk_upper(r, joint, U)) if ok else HALT

# IP-262 主闭环
def DOME_RAS_round(M, obs):
    G = M.tag.build(obs, M.w_demo)                       # 1) 锚图
    L, S = stcd(M.tag.residual_matrix(G), G.w, 3, M.k)   # 2) 低秩|稀疏
    c, U, thr = M.cof.step(z_cal=L, r=L, sigma_stat=sigma_stat(M))  # 3) 标定只吃 L
    r_demo = M.demo_consistency(obs, M.pi_demo)          # 4) 意图轴
    joint, supp = three_axis_attribution(L, S, r_demo, c, U)        # 5) 三轴归因
    if not ensure_identifiable(G, c, M.query_budget):    # 6) 秩亏 → 激励/弃权
        return M.abstain(joint)
    rec = demonstration_recovery(joint, M.R_demo, U)     # 7) 示教恢复
    if rec is not None: return M.execute(rec)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(obs), joint, ...)
    lam = max(M.efs.risk_scale(joint), M.lam_floor(U),
              0.8 if U > TAU_CAL else 0.6)               # 8) 风险缩放
    tau = M.pi_sigma.prefix_dispatch(...) * lam
    M.vqa_d.submit_async((G, L, S, r_demo), {'cal': (c, U), 'joint': joint})
    M.cac_slow.maybe_commit(M.shadow, M.time_since_last_commit)
    assert not sparse_veto_violated(L, S)                # 9) 稀疏否决
    return k, lam, joint, (c, U)
```

## 4. 推导

**引理 16（秩-稀疏两轴可分性）** R=L₀+S₀+N，rank(L₀)≤r、‖S₀‖₀≤k，L₀ μ-非相干、S₀ 支撑均匀；若 r ≤ c₁·min(m,n)/(μ log² max(m,n))、k ≤ c₂·mn，则以概率 ≥ 1−C·max(m,n)^{−c₃} 精确恢复 L̂=L₀、Ŝ=S₀。系：**时间带宽相同也能分离**——拆除 R68「缓变故障隐形」的结构前提。

**引理 17（激励-可辨识等价）** δc 可辨识 ⇔ rank(J_G)=dim(c_eff)。DEX 探针使 λ_min(P_{U0}J_G^T W J_G P_{U0}) 单调上升；B 次查询后达 ε_pe 则 U_0 方向方差降 ≥ ε_pe 倍。系：示教是可辨识性的必要投入，把「超时失败」变「可查询」。

**引理 18（外生纠正标签样本复杂度）** VC 维 d、n_corr 条纠正 ⇒ 误差 ≤ O(√(d/n_corr))；对边界（尤其缓变故障）信息量极大，等效样本增益 ≈ 1/ρ_demo。系：少量人类纠正即可补 R68 canary 覆盖空洞。

**定理 16（端到端风险一致性，扩 R68 定理 14）**
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_anchor+α_demo`；
2. `(T)∨(S)∨(I)` 任一成立 ⇒ 缓变故障检出 ≥ 1−δ_S（引理 16/18），**解除 R68 单点失效**；
3. 三轴全失效 ⇒ 弃权态：λ≥0.8 ∧ k 收缩 ∧ 撤回高置信结论；
4. DRP 恢复风险 ≤ min(停机风险, 最优 R_demo 恢复风险)；R_demo 空则退化为保守停机，风险不回退。

**定理 17（参照系自指安全性）** 若 `col(J_det)∩col(J_cal)≠{0}`（d_conf>0），仅用检测锚点+内部残差无法区分检测偏差与真实漂移；可辨识 ⇔ 外部参照 F 满足 `col(J_F)⊇col(J_det)∩col(J_cal)`。系：**闭环可信度上界由外部参照的秩决定，而非内部模型精度**——这解释了 R68 标定红线悖论的根源，也标出本方案天花板。

## 7. 本轮最大风险

**一句话**：DOME-RAS 把计量参照系交给了目标检测器，而检测器本身是学习模块——**若检测偏差低秩且任务相关，它恰好落在标定雅可比列空间内，结构上与真实漂移不可区分，又因其低秩而躲过稀疏项**，系统会用「越来越自洽」的锚把空间参照系整体带偏，而示教纠正标注的是任务结果而非传感器几何、无法救援——「参照系自指」取代缓变故障，成为新的不可见失效。

**次级风险与缓解**：锚覆盖不足/遮挡（cov 门控 + 弃权态 + 主动视角）；检测算力超预算（ROI 剪枝 + 慢环跟踪插值 + 共享底层特征但保留独立深度/触觉/标定板通道）；RPCA 非相干不满足（分段局部低秩 + 三轴 T/I 兜底）；示教分布偏移（置信加权 + Sim2Real 校准 + 无覆盖退回停机）；DEX 人类查询成本与安全（优先安全探针 + 预算硬上限 + 红线约束）。
