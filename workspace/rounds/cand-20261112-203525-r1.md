# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC；灵感循环第 1 轮；本轮灵感：「异常检测」×「角色一致性」）

> 第 61 轮用 USR × MEL × DMS × SRT-Dual × PCE+++++ 打通了「语义统一表征 → 大模型零样本泛化 → 多轮对话接地 → 双流时序解耦」。但它留下三个结构性盲点：
> 1. **有不确定性，没有异常性**：MEL 的 U_epistemic / U_aleatoric 只是「模型自认为有多不确定」，不是「世界是否越出已知分布」的统计检验；没有 p 值、没有误报率控制、没有「新场景是危险还是仅仅新颖」的判别。
> 2. **有语义一致，没有角色一致**：J_sem_exec 校验的是场景/意图/阻抗/证据是否自洽，却不校验「机器人是否还是它声称的那个角色」——同一套语义可以自洽地执行一个越权、变调、违背承诺的行为。
> 3. **有事后证书，没有在线护栏**：XMC+++ / J_sem_exec 在事后对账，异常发生时实时流可能已执行若干周期；缺少「检测 → 定位 → 最小干预 → 修复」的闭环。

## 0. 直觉与动机

**灵感 1（异常检测 → 角色条件正常性 RCNM）**
直觉：异常不是世界的绝对属性，而是「相对于某个角色所承诺的行为分布」的偏离。同样 5N 的接触力，在「精密装配」角色下是异常，在「重载搬运」角色下是正常；同样一句「再快一点」，对「协作助手」是合理请求，对「安全监护者」可能是越权指令。传统异常检测用单一正常性分布 p(x)，会把角色切换误判为异常，也会把角色内部的越权行为漏判为正常。关键洞见：**把正常性条件化到角色 r 上，得到 p(x|r)，让异常成为「角色条件下的似然检验」**，而不是无条件的离群点检测。

**灵感 2（角色一致性 → 角色契约 RC 与身份流形 RIM）**
直觉：演员要「入戏」——同一角色在不同场景、不同镜头下保持语气、能力边界与承诺一致。机器人也需要「角色契约」：不能上一秒承诺轻触、下一秒猛压；不能声称自己是助手却执行破坏性动作；不能把「已答应用户的约束」在多轮对话后遗忘。角色一致性不是文本层的口吻模仿，而是**跨模态、跨时间、跨任务的行为不变量**。关键洞见：用一个低维「角色指纹」F_role 表示行为签名，把「入戏程度」定义为角色条件行为分布与契约流形之间的最小偏差。

**灵感 3（两灵感合流 → 角色-异常平面 RAP）**
直觉：异常与角色不一致是两条正交轴。最危险的不是「明显的异常」——那种会被现有安全兜底拦住；最危险的是「统计上完全正常、但角色已经悄悄漂移」的静默失效：机器人语气仍然温和、动作仍很流畅、证据链仍很自洽，但它已经在做一件「不是这个角色该做的事」。反过来，真正的新场景（新材质、新地形）虽然异常，却是学习机会，不应被异常检测误杀。关键洞见：**用二维平面 (新颖度 N, 角色不一致度 D) 替代一维异常分数，四象限分别执行「放行 / 探索 / 修复 / 接管」**。

**灵感 4（共形异常检测 → 有统计保证的实时护栏）**
直觉：不要问「这个分数算不算高」，而要问「在当前误报预算 α 下，这个样本的共形 p 值是否足够小」。共形预测把任意启发式异常分数（能量、重构误差、USR 距离、触觉残差）变成有边际覆盖保证的检验；在分布漂移下用 ACI 自适应校准 α；在多层检测上用 BH 控制 FDR，避免「五层里总有一层报警」的多重比较灾难。关键洞见：**异常分数可以很朴素，但阈值必须由校准集给出，且必须带误报预算**。

**灵感 5（修复闭环 → 分层干预 + 一致性约束策略 CARL）**
直觉：检测不是目的，修复才是。按「观察 → 澄清 → 重锚定 → 收紧约束 → 回滚 → 接管」的最小干预阶梯修复：能问一句就不收紧约束，能收紧约束就不回滚，能回滚就不接管。把角色一致性作为 CARL 的**约束**（CMDP）而非奖励项，再由规则盾保证任何 RL 动作都不越过角色契约与 ERTC 硬约束。关键洞见：**角色一致性不能靠「奖励里加一项」来保证，只能靠「约束 + 盾 + 证书」来保证**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（角色契约 RC）** 角色契约 RC = (r_id, r_emb, Π_permit, Π_prohibit, T_tone, E_comp, I_inv, W_role)。其中：
- **角色标识** r_id：角色名（如 assembly_assistant、heavy_lifter、surgical_scrub_nurse）
- **角色嵌入** r_emb ∈ ℝ^d_role（d_role = 64）：角色身份的可学习稳定签名
- **许可动作集** Π_permit：该角色允许执行的动作-约束对集合
- **禁止动作集** Π_prohibit：该角色绝对禁止的动作-约束对集合
- **语气规范** T_tone：对话语用约束（称呼、确定性表达、拒绝方式）
- **能力包络** E_comp：任务族、力/速度/工作空间上限
- **时序不变量** I_inv = {ι_1, …, ι_K}：如「承诺轻触后 N 轮内不得超 F_soft」「破坏性动作前必须 confirm」「不得在未澄清时改变任务目标」
- **角色时域** W_role：角色在任务切换后仍应保持承诺的时间窗口

**定义 174（角色同一性流形 RIM）** 角色同一性流形 M_role 是角色条件行为分布的支撑集：
```
M_role = closure{ (E_state(x), a) ∈ ℝ^d_us × A : p_θ(a | x, r_id) ≥ τ_support }
```
行为指纹 F_role(t) = E_role(τ_{t-W:t})，由动作统计、阻抗轨迹、对话语用特征拼接后编码为 d_role 维。同一角色在不同场景/任务下应满足**指纹不变性**：‖F_role(t) − F_role(t')‖ ≤ δ_role。

**定义 175（角色一致性分数 RCS）** 角色一致性分数取三个子分数的**最小值**（保守聚合）：
```
C_role(t) = min( C_emb(t), C_inv(t), C_beh(t) ) ∈ [0, 1]
  C_emb = exp( −‖F_role(t) − r_emb‖² / (2σ_role²) )        # 身份指纹贴近度
  C_inv = 1 − Σ_k w_k·violation_k(t) / Σ_k w_k               # 契约不变量满足度
  C_beh = exp( −D_KL( p_t(a|x) ‖ p_role(a|x) ) / KL_max )     # 行为分布贴合度
```
若 C_role(t) ≥ τ_role（默认 0.8）则称角色一致；若 C_role(t) < τ_role 则称发生**角色漂移**。

**定义 176（角色漂移 RD 与双通道检测）** 残差 e_role(t) = 1 − C_role(t)。两类检测器并行：
- **突变检测**：e_role(t) > τ_abrupt（默认 0.35）⇒ 立即报警
- **渐变检测（CUSUM）**：S_t = max(0, S_{t−1} + e_role(t) − μ_0 − k_slack)，S_t > h ⇒ 漂移报警

漂移类型分为五类：**失调**（tone）、**越权**（authority）、**失能**（competence）、**失诺**（promise）、**失配**（embodiment）。定义平均修复时间 MTTR 为从首次报警到 C_role 恢复 ≥ τ_role 的期望步数。

**定义 177（角色条件正常性模型 RCNM）** 以能量模型刻画角色条件下的观测分布：
```
p_θ(x | r) = exp(−E_θ(x, r)) / Z(r)
s_nov(x, r) = −log p_θ(x | r) = E_θ(x, r) + log Z(r)
```
其中 x = (V, T, P, L, scene_emb, evidence_emb) 经 MEL 编码后进入 USR。角色 r 的共形校准集 D_cal(r) 由「该角色下的正常执行片段」构成。新颖度定义为归一化分数 N(x) = σ((s_nov − median(D_cal(r))) / MAD(D_cal(r))) ∈ [0,1]。

**定义 178（共形异常检测 CAD）** 给定异常分数 s(x)（越大越异常）与校准集 {s_i}_{i=1..n}，共形 p 值：
```
p(x) = (1 + Σ_i 𝟙[s_i ≥ s(x)]) / (n + 1)
```
在可交换性假设下，误报率满足 P(p(X_new) ≤ α) ≤ α。多层检测用 BH 过程在 q 水平控制 FDR；分布漂移下用 ACI 自适应校准：
```
α_t = clip( α_{t−1} + γ·(α_0 − err_t), 0, 1 ),   err_t = 𝟙[第 t 步误报]
```
长程误报率满足 limsup (1/T)Σ err_t ≤ α_0 + ε（ε 随 γ 与漂移幅度）。**关键区分**：新颖（novelty）用角色条件正常性检验；危险（hazard）用任务风险模型检验，二者不可混同。

**定义 179（层级异常检测 HAD）** 五层检测与各自的运行时预算：
```
L0 传感层  (1–10 kHz): 尖峰、饱和、时间戳断档、NaN、零漂
L1 语义层  (10–100 Hz): USR 嵌入 OOD、场景-物理先验矛盾、MEL 不确定性异常
L2 行为层  (10–100 Hz): 动作偏离角色流形、对话语用越界、约束越权
L3 系统层  (1–10 kHz):  锚点过期、版本回退、证书校验失败、时序抖动
L4 身份层  (1–10 Hz):   角色指纹漂移、承诺遗忘、跨任务身份不一致
```
每层输出 p 值 p_l 与 e 值 e_l（零假设下 E[e_l] ≤ 1）；层间用 e 值乘积融合 e_fused = ∏_l e_l（独立时零假设下 E[e_fused] ≤ 1）；异常向量 A_t = (p_0..p_4, e_fused, type, localization)。

**定义 180（角色-异常平面 RAP 与四象限响应 QRP）** 二维平面：
```
横轴 新颖度 N(x) ∈ [0,1]       （1 − p_nov，越高越新颖）
纵轴 角色不一致度 D(x) = 1 − C_role(x) ∈ [0,1]
```
四象限与响应：
| 象限 | 判据 | 语义 | 响应 |
|---|---|---|---|
| Q0 | N<τ_N, D<τ_D | 正常且一致 | proceed（放行） |
| Q1 | N≥τ_N, D<τ_D | 新颖但一致（新材质/新地形） | explore + learn_if_safe（探索学习，**不抑制**） |
| Q2 | N<τ_N, D≥τ_D | 正常但角色漂移（静默失效） | clarify → re_anchor → constrain → rollback（最高优先级） |
| Q3 | N≥τ_N, D≥τ_D | 新颖且不一致 | abort / handover（接管） |

**定义 181（异常感知证据 AEC，升级 J_sem_exec）**
```
AEC = ( J_sem_exec,
        p_0..p_4, e_fused,
        C_role, F_role, drift_state, repair_trace,
        α_conformal, warranty_level )
warranty_level = 1 − α_0 − ACI_correction(T)
验证规则：Valid(AEC) ⇔
    Valid(J_sem_exec)
  ∧ (p_2 > α_role ∨ repair_completed)
  ∧ (p_3 > α_sys)
  ∧ anchor_fresh
  ∧ C_role ≥ τ_role
```

**定义 182（角色漂移修复 RDR）** 修复动作按成本单调排列：
```
Ladder = [wait, clarify, re_anchor, constrain, rollback, abort]
```
**最小干预原则**：选择阶梯中成本最低、且预测后状态满足 (C_role ≥ τ_role) ∧ safe 的动作；若所有动作都不满足则升到 abort。修复算子 RDR 在至多 K 步（默认 3）内收敛到安全集，否则升级人工接管。

**定义 183（一致性约束对话策略 CARL）** 把 DMS 建模为约束 MDP：
```
CMDP = (S, A, P, R, C_role, γ)
目标：max_π E[Σ γ^t R_t]  s.t.  E[Σ γ^t 𝟙(C_role(t) < τ_role)] ≤ κ
拉格朗日：ℒ = R − λ·(C_role − τ_role) − λ_repair·cost(repair)
策略类：π = Shield ∘ π_RL，Shield 硬性过滤 Π_prohibit 与 ERTC 不变量
```
Shield 保证「无论 RL 输出什么，执行动作永远落在角色契约与实时安全集内」。

**定义 184（七维角色-异常预算 PCE++++++）**
```
B_cog7 = ( B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_anomrole )
B_anomrole = ( B_anom, B_role )
  B_anom = ( Detect_freq, Calib_size, FPR_target, ACI_gamma, Multi_level_q )
  B_role = ( Role_check_freq, Drift_threshold, Repair_budget, Audit_depth )
```
成本与降级：
```
cost_cog7 = cost_cog5 + λ_anom·(Detect_cost/FPR_target) + λ_role·(Repair_cost/Repair_budget)
B_anom 耗尽 ⇒ 关闭 L1/L4 慢检测，保留 L0/L3 快检测 + 常开规则盾（绝不进入「无监测」）
B_role 耗尽 ⇒ 冻结角色重锚定，只保留 CUSUM 漂移检测与 rollback 兜底
```

## 2. 概念增量小结

1. **从「一维异常分数」到「角色条件 + 二维平面」**：异常检测第一次被要求回答「这是新颖，还是越界」，而不是「这离均值多远」。
2. **从「文本角色扮演」到「可验证角色契约」**：角色一致性变成可测量、可报警、可修复的系统属性，而非主观观感。
3. **从「事后证书」到「在线护栏 + 修复闭环」**：检测、定位、最小干预、回滚、接管形成闭环，且全部纳入七维预算。
4. **从「奖励塑形」到「约束 + 盾 + 共形保证」**：角色一致性获得分布无关的误报控制与硬约束安全。

## 3. 本轮最大风险

**一句话**：若角色契约与正常性模型都在「被监测的同一套 USR 语义空间」内定义与估计，系统就存在**自指盲区**——一旦 MEL 表征整体漂移或契约本身残缺，异常检测与角色监测会共同「自信地」为系统性越界背书（角色幻觉），因此必须保留独立于学习表征的硬件级安全不变量与人工审计作为最终裁决者。

```python
class RoleIdentityManifold:
    def __init__(self, d_role=64, window=50, sigma_role=0.5):
        self.d_role = d_role
        self.window = window
        self.sigma_role = sigma_role
        self.encoder = RoleFingerprintEncoder(d_role)  # action stats + impedance + pragmatics
        self.cusum_S = 0.0

    def fingerprint(self, trajectory):
        # 轨迹：[(a_t, K_t, u_t, ts)]，编码为角色指纹
        return self.encoder(trajectory[-self.window:])

    def consistency(self, F_role, contract, p_t, p_role, violations):
        c_emb = np.exp(-np.linalg.norm(F_role - contract.r_emb) ** 2
                       / (2 * self.sigma_role ** 2))
        w = np.array([inv.weight for inv in contract.invariants])
        v = np.array([1.0 if inv.violated else 0.0 for inv in contract.invariants])
        c_inv = 1.0 - float((w * v).sum() / max(w.sum(), 1e-9))
        c_beh = np.exp(-kl_divergence(p_t, p_role) / 2.0)
        return float(min(c_emb, c_inv, c_beh)), (c_emb, c_inv, c_beh)

    def drift_detect(self, C_role, tau_abrupt=0.35, mu0=0.05,
                     k_slack=0.02, h=1.0):
        e = 1.0 - C_role
        abrupt = e > tau_abrupt
        self.cusum_S = max(0.0, self.cusum_S + e - mu0 - k_slack)
        gradual = self.cusum_S > h
        return abrupt or gradual, (abrupt, gradual, self.cusum_S)

    def classify_drift(self, F_role, contract, violations, dialogue):
        if any(v.type == 'tone' for v in violations): return 'dysphonia'
        if any(v.type == 'authority' for v in violations): return 'usurpation'
        if any(v.type == 'competence' for v in violations): return 'incapacity'
        if self._promise_broken(dialogue): return 'promise_break'
        return 'embodiment_mismatch'
```

### IP-185 CAD（共形异常检测 + ACI + BH）

```python
class ConformalAnomalyDetector:
    def __init__(self, alpha0=0.05, gamma=0.01, calib_window=500):
        self.alpha0 = alpha0
        self.alpha = alpha0
        self.gamma = gamma
        self.calib = deque(maxlen=calib_window)   # 正常校准分数
        self.p_nov_calib = deque(maxlen=calib_window)  # 新颖度专用校准

    def score(self, x, role):
        # 可插拔：能量 / 重构误差 / USR 距离 / 触觉残差
        return float(self._energy(x, role))

    def p_value(self, s, calib=None):
        calib = self.calib if calib is None else calib
        n = len(calib)
        if n == 0:
            return 1.0
        return (1.0 + sum(1 for si in calib if si >= s)) / (n + 1.0)

    def test(self, x, role):
        s = self.score(x, role)
        p = self.p_value(s)
        alarm = p <= self.alpha
        return alarm, p, s

    def aci_update(self, err):
        # err_t = 1 表示该步发生误报（真实正常却被判异常）
        self.alpha = float(np.clip(
            self.alpha + self.gamma * (self.alpha0 - err), 0.0, 1.0))

    def bh(self, pvals, q=0.05):
        m = len(pvals)
        order = np.argsort(pvals)
        k_star = 0
        for rank, idx in enumerate(order, start=1):
            if pvals[idx] <= q * rank / m:
                k_star = rank
        return {int(i) for i in order[:k_star]}

    def novelty_and_hazard(self, x, role, hazard_model):
        p_nov = self.p_value(self.score(x, role), self.p_nov_calib)
        p_haz = hazard_model.p_value(x)   # 任务风险参考集，独立校准
        return 1.0 - p_nov, 1.0 - p_haz   # (N, hazard)
```

```python
class HierarchicalAnomalyDetector:
    LEVELS = ('L0_sensor', 'L1_semantic', 'L2_behavior',

        self.det = {lvl: ConformalAnomalyDetector() for lvl in self.LEVELS}
        self.fast = ('L0_sensor', 'L3_system')     # 1–10 kHz

        s['L0_sensor'] = self._sensor_stats(obs.V, obs.T, obs.P)
        s['L1_semantic'] = usr.distance_to_role_manifold(obs)
        s['L2_behavior'] = self._behavioral_residual(act, role_state)
        s['L3_system'] = self._system_stats(usr.anchor, act.cert)
        s['L4_identity'] = self._identity_residual(role_state.F_role,

        return s

    def step_fast(self, obs, usr, act, role_state):

                             self._localize(p, rejected))
```

### IP-187 RAP-QRP（角色-异常平面与四象限响应）

```python
class RoleAnomalyPlane:
    def __init__(self, tau_N=0.5, tau_D=0.2):
        self.tau_N, self.tau_D = tau_N, tau_D

    def quadrant(self, N, D):
        if N < self.tau_N and D < self.tau_D: return 'Q0'
        if N >= self.tau_N and D < self.tau_D: return 'Q1'
        if N < self.tau_N and D >= self.tau_D: return 'Q2'
        return 'Q3'

    def response_ladder(self, q, severity):
        base = {
            'Q0': ['wait'],
            'Q1': ['explore', 'learn_if_safe'],
            'Q2': ['clarify', 're_anchor', 'constrain', 'rollback'],
            'Q3': ['abort', 'handover'],
        }[q]
        if severity > 0.8:
            return base + ['abort']
        return base

    def decide(self, N, D, severity, repairer, dms):
        q = self.quadrant(N, D)
        if q == 'Q0':
            return 'proceed', q
        if q == 'Q1':
            # 新颖但一致：允许探索，绝不因为"异常"而抑制学习
            return repairer.minimal_intervention(['explore', 'learn_if_safe'],
                                                 severity), q
        # Q2 / Q3：角色不一致优先于新颖性
        allowed = self.response_ladder(q, severity)
        return repairer.minimal_intervention(allowed, severity), q
```

### IP-189 RDR（最小干预修复）

```python
class RoleDriftRepairer:
    LADDER = ['wait', 'clarify', 're_anchor', 'constrain', 'rollback', 'abort']

    def __init__(self, monitor, ertc, dms, usr, tau_role=0.8):
        self.monitor = monitor
        self.ertc = ertc
        self.dms = dms
        self.usr = usr
        self.tau_role = tau_role
        self.trace = []

    def predict(self, action, drift):
        # 预测修复动作执行后的 (safe, C_role)，轻量模型 + 保守界
        if action == 'wait':      return True, self.monitor.C_role
        if action == 'clarify':   return True, min(1.0, self.monitor.C_role + 0.10)
        if action == 're_anchor': return True, min(1.0, self.monitor.C_role + 0.25)
        if action == 'constrain': return True, min(1.0, self.monitor.C_role + 0.20)
        if action == 'rollback':  return True, 1.0
        if action == 'abort':     return True, 1.0
        return False, 0.0

    def minimal_intervention(self, allowed, severity):
        for action in self.LADDER:
            if action not in allowed:
                continue
            safe, c_pred = self.predict(action, severity)
            if safe and c_pred >= self.tau_role:
                self.trace.append((action, severity, c_pred))
                return action
        self.trace.append(('abort', severity, 1.0))
        return 'abort'

    def apply(self, action):
        if action == 'clarify':
            return self.dms.ask_clarify('角色一致性下降，请确认当前任务目标与约束')
        if action == 're_anchor':
            return self.usr.recommit_role_anchor()
        if action == 'constrain':
            return self.ertc.tighten_constraints(role_safe=True)
        if action == 'rollback':
            return self.ertc.rollback_to_last_certified_anchor()
        if action == 'abort':
            return self.ertc.safe_abort_and_handover()
        return None
```

```python
class ConsistencyAwarePolicy:
    def __init__(self, base_policy, shield, tau_role=0.8,
                 lam=1.0, lr=0.01):

        self.shield = shield      # 硬约束：Π_prohibit + ERTC 不变量
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RC / RIM | O(d_role + K_inv) / 检查 | O(d_role + W) | 指纹不变性 ‖F(t)−F(t')‖ ≤ δ_role；不变量可判定 |
| RCM | O(1) 突变 + O(1) CUSUM | O(1) | 突变检测延迟 1 步；CUSUM 对阶跃漂移平均延迟 ≈ h/(μ−μ0−k) |

| RACL | 实时流附加 ≤ 0.05ms；语义流附加 2–5ms | O(d_role + n) | 检测不阻塞实时环；修复动作受 Shield 约束 |

**正确性定理（RACL-Complete）**：
假设 A61–A70 及 **(A71)** 角色契约的每个不变量 ι_k 可在 ≤ 0.1ms 内判定，且 violation 函数对输入 Lipschitz 连续。**(A72)** 每层异常检测在角色分层内可交换；分布漂移下 ACI 的 γ-更新满足长程误差 ≤ α_0 + ε_γ。**(A73)** 角色指纹编码器满足 ‖F(t)−F(t')‖ ≤ L_role‖τ−τ'‖，且角色校准原型覆盖角色行为流形（覆盖半径 ≤ ρ_role）。**(A74)** 修复阶梯中每个动作的执行器都经过 ERTC 认证，且「rollback/abort」总能到达一个已认证安全状态。**(A75)** 七维预算单调消耗；B_anom/B_role 耗尽时规则盾与 L0/L3 常开。

则：
1. **异常误报可控**：各层 P(误报) ≤ α_0；跨层 BH 下 FDR ≤ q；ACI 下长程误报 ≤ α_0+ε，且异常风暴中不会因预算耗尽而失去 L0/L3 兜底。
2. **角色一致性可靠**：若监测器完备且 C_role ≥ τ_role，则在角色时域 W_role 内不执行 Π_prohibit 中动作；若发生越界，CUSUM 在 W 步内以概率 ≥ 1−β 检出（给定阶跃幅度）。
3. **新颖/越界可分**：Q1（新颖-一致）的误抑制率 ≤ δ_suppress（目标 ≤ 5%），Q2（正常-不一致）的漏检率 ≤ δ_miss（目标 ≤ 5%）；即纯一维异常检测无法覆盖的 Q2 被显式补上。
4. **修复收敛**：RDR 至多 K 步（默认 3）到达 (safe ∧ C_role ≥ τ_role)，否则 abort/handover；且所取动作是满足约束的最低成本动作。
5. **闭环安全**：CARL 的 Shield 保证 Π_prohibit 违反率恒为 0，ERTC 实时契约不被异常检测与修复动作破坏；AEC 证书在每次交付时可通过独立校验。

## 5. 本轮最大风险

**一句话**：若角色契约与正常性模型都在「被监测的同一套 USR 语义空间」内定义与估计，系统就存在**自指盲区**——一旦 MEL 表征整体漂移或契约本身残缺，异常检测与角色监测会共同「自信地」为系统性越界背书（角色幻觉），因此必须保留独立于学习表征的硬件级安全不变量与人工审计作为最终裁决者。
