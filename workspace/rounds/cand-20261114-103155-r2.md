# 第 70 轮（承接第 69 轮「FLUID-RAS 不确定性二分交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多视角视觉」×「论文创新点」）

> R69 把不确定性一分为二，让 epistemic 不再只会「刹车」，而会「去看、去问、去摸」。但它犯了一个隐蔽的自指错误：**判断「分区是否可消解」，用的仍是那个需要被检验的生成模型本身**——流策略说「我有两个模态、间距很大、值得问」，系统就去问；它若幻觉出一个模态，VoI 就是在错误信念上算出来的。R69 的「k 个正交证据源」也只是个手挥的口号：θ 从没定义过「正交」是什么、怎么测、可不可以为 0。更糟的是，R69 的解答恰恰是最危险的形态——**多个来源异口同声地说错**。
>
> 本轮两个灵感分别给出一把尺子和一面镜子：
> - **多视角视觉**告诉我们：信息不来自视点的**数量**，而来自视点之间的**基线（baseline）**。三台绑在同一根支架上的相机，是一台相机；三个共享同一标定、同一光照、同一先验的回答，是一个回答。正交性不是假设，而是可以在**视图图**上被认证（或证伪）的几何/因果结构；
> - **论文创新点**提醒我们：一个贡献主张本身也是被多个「通道」（理论、消融、基线对照、人类研究）观测的隐变量。若这些通道只是同一句话的换皮，主张的 N_eff 就是 1——那是「共模新颖」，不是创新。**新颖性也需要视差**：相对先前工作必须有非零基线，且差异要能通过一次「断裂测试」（消融）。
>
> 核心命题：**把 R69 的「多源一致」升级为「带基线认证的视图图共识」。共识只在视图相互独立（N_eff 足够）、且经「断裂测试」仍不消失时，才算证据；否则它只是相关。** 命名 **PARALLAX-RAS**（取「视差」：深度来自基线错位，而非视点数量）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的证据真的独立吗——还是它们只是在附和同一个错误**」。

## 0. 直觉与动机

**灵感 1（多视角视觉 → 信息来自基线，不来自视点数量）**
直觉：R69 的证据纪律说「至少两个正交证据源一致」。可「一致」是最廉价的东西——三台相机装在同一块刚性板上，看到的世界永远一致；同一模型的三个副本，永远互相点头。真正的信息藏在**视差**里：两只眼睛之所以有立体感，是因为它们分开了几厘米，同一个物点在两幅图上错位。把这一条讲透，R69 的口号就变成一个可计算的量：**正交性 = 视图之间没有共享的错误祖先 + 基线够大**。于是「k 源」被替换为「有效独立视图数 N_eff」，而 N_eff 可以为 1，哪怕你有 100 个源。

**灵感 2（共模故障 → 最危险的共识是假共识）**
直觉：R69 最怕「投毒」，但它把投毒想成「某个源说了假话」。多视角视觉揭示了一个更阴险的形态——**共模**：所有源都没撒谎，它们只是共享了同一个误差源（同一套坏标定、同一帧被回放的图像、同一个谄媚的人类先验、同一个被污染的模型）。它们一致，恰恰因为它们是同一个错的 N 个副本。**证据不是「大家点头」，而是「在换了基线之后大家还点头」**。所以本轮必须能主动「打破取景框」：挪一下、等一会儿、换个模态、盲问一句，看这份共识会不会蒸发。

**灵感 3（三分 → 有些歧义永远问不出来，正确动作是不问）**
直觉：R69 把 epistemic 一律当成「可约」。但几何上至少有两类：一类随你退后两步就看清楚了（**视差受限**，比如带纹理物体的深度）；另一类你把相机绕它转一圈也没用（**对称**，比如无纹理圆柱绕轴的自转、正对镜面的左右镜像）。后者是全视图族的**零空间**。R69 会在对称陷阱上永远追问——每一次「问」都毫无收益，却持续消耗预算、暴露攻击面、甚至诱发危险动作。**知道什么时候不问，和知道什么时候问一样重要。**

**灵感 4（人即视图 → R69 的「问人」只是加了一个可能零基线的视图）**
直觉：R69 的 g_ask、g_gaze、g_probe 被当成三种不同的东西。在多视角框架下它们是同一件事：**获取一个新视图**。而「问人」的信息价值服从同一套基线定律——如果人只是顺着你刚才透露的信念说话（谄媚/锚定），这个「人视图」与你的先验相关系数 ρ≈1，基线为零，N_eff 不增加。R69 的「投毒上界」于是被统一为一个**可测的相关系数 ρ**：投毒是 ρ→1 的极端情形。我们可以通过「盲问」（不透露当前信念）来估计 ρ，并据此给这个视图打折。

**灵感 5（论文创新点 → 新颖性本身需要视差与断裂测试）**
直觉：这套机器不只审传感器，也审我们自己写下的 IP 清单。一个「创新点」如果只有理论一段、没有能在别处复现的消融、没有能让先前工作失败而本轮成功的最小对照，那么它的证据通道 N_eff≈1——只是给旧东西换了个名字（**共模新颖**）。真正的创新点需要两样东西：**相对先前工作的非零基线**（存在一个先前方法确实会错、而本方法会对的判别性场景）与**通过断裂测试**（去掉该组件，效果显著塌陷）。于是本轮把「视图图共识」反身应用到论文的主张上，产出新颖性断言账本 NCL。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PARALLAX-RAS 总览）** PARALLAX-RAS = (VGC, TEC, NVE, USD, BBT, NBV, HAV, CG, MVA, VQAuditor-P, AIC-PARALLAX, J_PARALLAX, NCL, RAS-WM†)。三不变式：
(i) **实时零学习写操作**与**安全包络**继承 R69 定义 293；
(ii) **独立性必须被认证，不得被假设**：任一视图对，只有当其基线 B_ij 已标定、对齐已认证、且错误来源 DAG 中无公共祖先时，才计入独立证据；否则按共模收缩为一个视图；
(iii) **无断裂即无加成**：任何 resolution bonus（R69 定义 307）都必须通过基线断裂测试 BBT 与共识门 CG；未通过则退化为 R69 的 λ_floor(U_ale+U_epi)。

**定义 311（视图与广义基线）** 视图集 𝒱={v_i}，视图 i 的观测 y_i∈ℝ^{m_i}，把潜在状态 s（三维场景 + 任务状态）映到观测的投影 π_i（相机为 `π_i(s)=K_i T_i s`）。**广义基线** B_ij = ‖c_i−c_j‖（相机情形为光心间距）或对于非相机视图的一般化「信息分离度」：时间窗间隔、物理激励差异、模态物理量差。约定：B_ii=0；共位/同源视图 B_ij=0。

**定义 312（对齐认证）** 异构视图需对齐映射 A_i: y_i→𝒮_canonical，认证误差 ε_i。仅当 ε_i≤ε_max 且 A_i 的标定数据与待用视图不共享采集批（防泄漏共模）时，v_i 获「已认证」标记。未认证视图可以参与观测，但**不计入独立证据**（N_eff 中权重置 0）。

**定义 313（视图图与共模收缩）** 视图图 G_𝒱=(𝒱,E,B,ρ,𝒟)，边 (i,j) 携带基线 B_ij、共模相关 ρ_ij∈[0,1]、以及错误来源 DAG 𝒟 中最近公共祖先。**共模收缩**：若 ρ_ij≥ρ_crit，或 i,j 在 𝒟 中共享误差祖先（同标定器、同支架、同模型、同人类先验、同回放源），则把 i,j 合并为一个超节点（视为同一视图）。收缩后的商图节点即**有效独立视图簇** 𝒞={c_1,…,c_M}，M≤N。关键：**M 是认证出来的，不是数出来的。**

**定义 314（三角化与 Fisher 信息）** 对假设 s，加权残差 `ρ(s)=Σ_i w_i‖A_i(y_i)−π_i(s)‖²_{Σ_i^{-1}}`，MLE `ŝ=argmin ρ(s)`（Gauss–Newton）。Fisher 信息 `I(s)=Σ_i J_iᵀ Σ_i^{-1} J_i`，J_i=∂π_i/∂s。三角化协方差近似 `Cov(ŝ)≈I(ŝ)^{-1}`。在商图上按簇求和：`I_C = Σ_{c∈𝒞} I_c`。

**定义 315（有效独立视图数 N_eff 与有效基线 B_eff）** 对任一潜在方向 u（单位向量），簇 c 的信息量 `i_c(u)=uᵀ I_c u`，定义
`N_eff(u) = (Σ_c i_c(u))² / Σ_c i_c(u)²`（参与率/Participation Ratio），
`N_eff = min_{u∈𝒰_crit} N_eff(u)`（最弱关键方向）。`B_eff = min_{c≠c'} ‖P_u(c_c−c_{c'})‖` 投影到该最弱方向。性质：独立等强 ⇒ N_eff=M；完全共模 ⇒ N_eff=1；B=0 ⇒ 无论 M 多大，该方向信息不增。

**定义 316（三分不确定性）** 在 R69 的 (U_ale,U_epi) 上做几何细化：
- `U_ale`：视图内噪声（沿 I 的满秩部分），不可约；
- `U_par = tr(I_C^{-1} P_∥)`：沿「基线可增信息」子空间 P_∥ 的分量，**可被移动/加独立视图消解**；
- `U_sym = tr(I_C^{-1} P_0)`：落在全视图族与可行基线族的 Fisher 零空间 P_0 的分量（对称/结构歧义），**任意多视图、任意大基线都消不掉**。
且 `U_epi = U_par + U_sym`（对 R69 的严格细化，非新增并列黑箱）。注：U_sym 相对当前视图族 𝒱 与可行基线集 ℬ 而言；只有「扩充视图族」（换新传感器/新物理量）才可能打破，故其正确动作是**对冲/规避或升级感知族**，而非在旧视图上继续追问。

**定义 317（视差增益与可约性判据）** 新增一个独立视图（基线 B、噪声 Σ）沿方向 u 的期望信息增量 `Δi ≈ B²·g_u/σ_u²`（g_u 为几何因子）。定义视差可约性 `κ = Δi/(i_old+Δi)`，与 VoI 的几何上界 `VoI_par(g) ≤ U_par·κ`。**判据**：仅当 `U_par>τ_p` 且 `κ>κ_min` 时，NBV/交互才可能盈利；`U_sym` 不产生 VoI（引理 21）。

**定义 318（共模/共谋统计）** 在基线 B 下，独立视图的残差互相关应随 B 增大而下降（视差预测）；若残差相关**不随 B 下降**，则存在共模成分。统计量 `Λ_cm = corr(r_i,r_j) − ρ_pred(B_ij)`，ρ_pred 由几何与噪声模型给出。`Λ_cm>τ_cm` ⇒ 判为共模，收缩。回放攻击（同一图像喂给两相机）是 B_ij=0 且残差完全相关的极端情形。

**定义 319（基线断裂测试 BBT）** 选一个安全、能改变基线或去相关的动作 `g_bbt`（微移视点、等待运动视差、切到物理独立模态、盲问且不透露先验），重采后计算共识变化
`Λ_BBT = D(y_after) − D(y_before)`，D 为视图间规范化分歧度。检验 H0：共识为真（分歧不随基线变化）。若 `Λ_BBT>τ_bbt`（共识消失）⇒ 判为共模，**撤销** R69 的 resolution bonus；否则认证通过。BBT 受 R69 定义 302 与 C-RAS-WM 认证约束，位移 ≤ ε_bbt。

**定义 320（下一最佳视图 NBV 信息动作）** 统一 R69 的 g_gaze/g_probe/g_ask 为「获取新视图」：
`g_view* = argmax_{g∈𝒢_feasible} [E_{y~p(·|g)}[ΔU_par] − c(g) − risk(g)]`，s.t. 安全包络与交互预算。
候选族 𝒢_feasible = 未访问视点（NBV）/延时（运动视差）/新模态/人类询问（语义视图）。R69 的 MINT 是本定义在「单视图族」上的退化。

**定义 321（人即视图与谄媚系数）** 人类回答建模 `a = (1−ρ)·y_indep + ρ·b_prior + η`，b_prior 为系统当前信念，ρ∈[0,1] 为**谄媚/锚定系数**。该视图的有效信息乘以 (1−ρ²)。ρ 通过盲问（不透露 b_prior）或双盲拆分估计；`ρ≥ρ_crit ⇒ N_eff 不增加，视图并入系统自身簇`。推论：R69 的投毒上界（引理 18）是 ρ→1 的边界情形。

**定义 322（共识门 CG）** 授予 R69 resolution bonus（`λ=λ_floor(U_ale)`）当且仅当：`N_eff≥τ_N`、`B_eff≥τ_B`、所有视图对齐已认证、`Λ_cm≤τ_cm`、BBT 通过、且模态校准 `ECE≤τ_ece`。任一不满足 ⇒ `λ=λ_floor(U_ale+U_par+U_sym)`（等价 R69 的 `U_ale+U_epi`）；若慢变故障疑（R69 定义 309）则再叠加 R69 最保守档。

**定义 323（多视标定与慢变故障 VA）** 把 R69 的 COF 从单传感器残差升级为**多视光束法平差式联合标定**：共享标定漂移使跨视图残差在共模收缩后消失；**单视图漂移**使收缩后残差仍存。故 `(r_res^contracted↑)` 检单视图故障，`(r_res↓, Δa↑)`（R69 定义 309）检共模/标定被吸收故障，二者互补。

**定义 324（视差审计 VQAuditor-P）** 审计：是否把共模视图当独立（N_eff 高估）、是否对 U_sym 追问（对称陷阱）、BBT 是否真改变了基线（而非形式通过）、人类视图 ρ 是否被低报、被遮挡视图是否被过加权。结论回灌 AuditBuf 与视图图边权。

**定义 325（视差干扰集 ℰ_parallax）** 回放/重放攻击、共享支架共谋、谄媚人类、标定锁定（锁死基线使 BBT 无效）、对称陷阱、遮挡视图过加权、视图饥饿（永不扩族）、对齐投毒。并入 AIC：`ℰ_PARALLAX = ℰ_FLUID × ℰ_parallax`。

**定义 326（证书 J_PARALLAX）** `J_PARALLAX = (J_FLUID, n_eff, b_eff, lambda_cm, bbt_stat, view_graph_hash, rho_human, claim_ledger_hash, parallax_ver)`。Valid ⇔ Valid(J_FLUID) ∧ CG 满足 ∧ 审计无高危项 ∧ 账本与视图图未被篡改。

**定义 327（新颖性断言账本 NCL）** 每个主张 c 赋予支持通道集 S(c)（理论证明 T、消融 A、基线对照 B、人类研究 H 等），按定义 315 计算 `N_eff^claim(c)`；并要求：(a) 存在**先前工作判别性基线**（一个先前方法失败、本方法成功的场景，即主张的「非零基线」）；(b) 通过**断裂测试**（去掉该组件后效应显著塌陷，即主张的 BBT）。若 `N_eff^claim<2` 或无判别性基线或断裂测试失败 ⇒ 标记「共模新颖」并从有效贡献中剔除。

# IP-264 VGC：视图图构建与共模收缩（M 是认证出来的，不是数出来的）
class ViewGraph:
    def __init__(self, views, provenance_dag, rho_crit=0.3):
        self.V, self.D = views, provenance_dag
    def edges(self):
        for i, j in pairs(self.V):
            yield i, j, dict(B=self.baseline(i, j),
                             rho=self.estimate_rho(i, j),
                             shared=self.D.common_ancestor(i, j))
    def contract(self):                     # 共模 → 超节点
        uf = UnionFind(self.V)
        for i, j, e in self.edges():
            if e['rho'] >= RHO_CRIT or e['shared']: uf.union(i, j)
        return uf.clusters()                # 有效独立视图簇 𝒞

# IP-265 TEC + IP-266 NVE：三角化、N_eff、B_eff
def triangulate(clusters, obs):
    s, I = gauss_newton_mle(clusters, obs)          # 定义 314
    I_C  = sum_cluster_info(clusters)               # 商图 Fisher
    return s, I_C

def n_eff_b_eff(I_C, clusters):
    n_eff = min(participation_ratio(I_C, u) for u in critical_dirs(I_C))
    b_eff = min(projected_baseline(c, c2, weakest_dir(I_C))
                for c, c2 in pairs(clusters))
    return n_eff, b_eff

# IP-267 USD：三分不确定性（P_∥ 可解，P_0 对称零空间）
def decompose3(samples, I_C, symmetry_group):
    U_ale = within_mode_trace(samples)
    P_par = range_projector(I_C)                    # 信息随基线增长子空间
    P_0   = null_projector(I_C, symmetry_group)     # 任意视图都看不到
    U_par = trace(pinv(I_C) @ P_par)
    U_sym = trace(pinv(I_C) @ P_0)
    return U_ale, U_par, U_sym                      # U_epi = U_par + U_sym

# IP-268 BBT：基线断裂测试（共识消失 ⇒ 共模）
def baseline_break_test(graph, obs, ctx):
    g = choose_safe_decorrelating_action(graph, ctx)   # 过 C-RAS-WM
    y_after = acquire(g)                               # 位移 ≤ ε_bbt
    return divergence(y_after) - divergence(obs) > TAU_BBT, g

# IP-269 NBV：只看 U_par 才值得问（U_sym 永不问）
def next_best_view(graph, U_par, U_sym, budget):
    if U_par <= TAU_P or U_sym >= U_par: return None   # 对称陷阱 → 不问
    best = None
    for g in graph.feasible_views():                   # 视点/延时/模态/人类
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = parallax_gain(g) - cost(g) - risk(g)   # 定义 317
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-270 HAV：人即视图，谄媚打折
def human_view(answer, prior, rho):
    return effective_info(answer) * (1.0 - rho**2)     # ρ→1 则零增益

# IP-271 CG：共识门（独立性 + 断裂 + 校准）
def consensus_gate(graph, bbt_ok, ece):
    n_eff, b_eff = n_eff_b_eff(*graph.info)
    return (n_eff >= TAU_N and b_eff >= TAU_B and bbt_ok
            and graph.lambda_cm <= TAU_CM and ece <= TAU_ECE)

## 3. 推导

**引理 19（视差–深度信息界）** 两视图基线 B、焦距 f、深度 Z、单视图像素噪声 σ_px。深度的 Fisher 信息 `i_Z ≈ (fB/Z²)² / σ_px²`，故 `σ_Z ≈ Z²σ_px/(fB)`；多视图（有效独立数 N_eff）下 `σ_Z² ≈ Z⁴σ_px²/(f²B²N_eff)`。系：`U_par ∝ Z⁴σ_px²/(f²B²N_eff)`。**推论（正交性的可测定义）**：B=0 或 ρ=1（共模）时 N_eff 不增，ξ 个共位视图等价于 1 个——这正式把 R69 的「k 个正交源」改写成一台可读数的仪表。

**引理 20（谄媚衰减界）** 若人类回答与系统先验在潜变量上的相关系数为 ρ（高斯近似），则回答提供的互信息 `I(M;a) ≈ (1−ρ²)·I_indep`，`ρ→1 ⇒ I→0`。系：R69 的投毒上界 `δ_p·ρ^{k−1}` 只是本式的极端离散化；本轮用盲问估计 ρ，把「投毒」从一个定性威胁变成一个**可标定的相关系数**，并据此打折（定义 321）。

**引理 21（对称不可约性）** 若存在非平凡群 G 使 `π_i(g·s)=π_i(s)` 对所有视图 i 与所有可行基线成立，则沿 G 轨道方向的 Fisher 信息恒为 0，`U_sym>0` 且对任意多视图/任意大基线/任意多轮追问都不下降。系：`VoI(U_sym)=0`；对 U_sym 追问不仅无用，还持续消耗预算、扩大攻击面。正确动作是对冲/规避，或**扩充视图族**去打破对称（定义 316 的注），而绝不是在旧视图上继续「问」。

**引理 22（共识不超独立信息）** 对任意融合规则，给定视图族后验熵 ≥ 给定其「最大独立子集」加等量噪声后的后验熵；M 个完全相关视图的信息至多等于 1 个。即 `N_eff≤M`，等号当且仅当条件独立。系：R69 的「k 源一致」若不做共模收缩，其错误率上界引理 18 中应把 k 替换为 N_eff；当 N_eff=1 时上界退化为单源的 δ_p——**这正是 R69 的隐形漏洞**。

**定理 18（PARALLAX 对 FLUID/R68 的严格包含，且在共模集上严格更安全）** 在 A99–A104（视图对齐认证、近似高斯视图噪声、基线可测、共模相关可估、对称可检测、C-RAS-WM 对信息动作有效）下，PARALLAX 的期望风险 ≤ FLUID-RAS ≤ R68。进一步，在共模失效集 `ℰ_cm`（R69 会因多个共模源一致而错误授予 resolution bonus 的状态集）上，PARALLAX 经 N_eff/B_eff/BBT 撤销该 bonus，风险**严格低于** FLUID；当 `N_eff=1` 且不扩族时，两者逐指令相同（退化为 FLUID）；当无交互亦无共识时，退化为 R68。⇒ 本轮不只是旧层的泛化，而是在一个**可测失败集**上更强。

**定理 19（NBV 交互安全与无突变）** NBV/BBT 作为信息动作经 C-RAS-WM 认证（继承 R69 定义 302），物理风险 ≤ ε_int；改变视点/延时/模态只改变「看哪个视图」，不改变任务动作的安全包络；BBT 失败、共识门不过、或超时时，λ 单调不降地退回 R69→R68 档；换装/提交不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

**命题 1（新颖性三角化判据，定义 327 的依据）** 一个贡献主张相对先前工作可被判为「有效新颖」仅当：`N_eff^claim≥2`（至少两条**非同源**证据通道，如理论+消融），存在**判别性基线**（先前方法确实失败的最小场景），且通过**断裂测试**（移除该组件效应塌陷）。三者缺一即「共模新颖」——与视图图共识完全同构：**新颖性也是被多个独立视图三角化出来的，不是自我声明出来的。**（注：这是方法论判据而非物理定理，故以命题给出。）

**定义 322（共识门 CG）** bonus ⇔ `N_eff≥τ_N ∧ B_eff≥τ_B ∧ 对齐认证 ∧ Λ_cm≤τ_cm ∧ BBT 通过 ∧ ECE≤τ_ece`；否则 `λ=λ_floor(U_ale+U_par+U_sym)`，慢变故障疑则叠加 R69 最保守档。

**定义 323（多视标定 MVA）** 联合光束平差式标定；共模收缩后残差仍存 ⇒ 单视图漂移；残差消失但 `(Δa↑)` ⇒ 共模/标定被吸收故障。与 R69 定义 309 互补。

**定义 324–326（审计/干扰/证书）** VQAuditor-P 审 N_eff 高估等；`ℰ_PARALLAX=ℰ_FLUID×ℰ_parallax`；J_PARALLAX 增视图图与账本哈希。

**定义 327（新颖性断言账本 NCL）** 主张 c 需 `N_eff^claim(c)≥2` + 先前工作判别性基线 + 断裂测试；否则标「共模新颖」并剔除。与视图图共识同构：**新颖性要被三角化，不能自我声明。**

class ViewGraph:
    def edges(self):
        for i, j in pairs(self.V):
            yield i, j, dict(B=self.baseline(i,j), rho=self.estimate_rho(i,j),
                             shared=self.D.common_ancestor(i,j))

        uf = UnionFind(self.V)
        for i, j, e in self.edges():

        return uf.clusters()                     # 有效独立视图簇 𝒞

def next_best_view(graph, U_par, U_sym, budget):

        sc = parallax_gain(g) - cost(g) - risk(g)
        if best is None or sc > best.score: best = (g, sc)

## 4. 推导

**引理 19（视差–深度信息界）** 基线 B、焦距 f、深度 Z、像素噪声 σ_px：`σ_Z²≈Z⁴σ_px²/(f²B²N_eff)`，即 `U_par∝Z⁴σ_px²/(f²B²N_eff)`。**系**：B=0 或 ρ=1 时 N_eff 不增，ξ 个共位视图等价于 1 个——把 R69 的「k 个正交源」改写成可读数仪表。

**引理 20（谄媚衰减界）** 人类回答与先验相关 ρ 时 `I(M;a)≈(1−ρ²)I_indep`，ρ→1 ⇒ 0。R69 投毒上界 `δ_p·ρ^{k−1}` 是本式极端离散化；本轮用盲问估计 ρ，把投毒变成可标定系数。

**引理 21（对称不可约性）** 若群 G 使 `π_i(g·s)=π_i(s)` 对所有视图/基线成立，则沿 G 轨道 Fisher 信息恒 0，`U_sym>0` 且任意多视图/大基线/多轮追问均不下降。**系**：`VoI(U_sym)=0`；对 U_sym 追问只会耗预算、扩攻击面——正解是对冲/规避或扩充视图族。

**引理 22（共识不超独立信息）** 任意融合规则下，后验熵 ≥ 最大独立子集加等量噪声后的后验熵；M 个完全相关视图信息至多等于 1 个，`N_eff≤M`，等号当且仅当条件独立。**系**：R69 引理 18 的 k 应替换为 N_eff；N_eff=1 时其上界退化为单源 δ_p——这正是 R69 的隐形漏洞。

**定理 18（严格包含且共模集上更安全）** A99–A104 下，PARALLAX ≤ FLUID ≤ R68；在共模失效集 ℰ_cm（R69 会因共模源一致而误发 bonus）上，本轮经 N_eff/B_eff/BBT 撤销 bonus，风险**严格低于** FLUID；N_eff=1 且不扩族时逐指令退化为 FLUID；无交互无共识时退化为 R68。

**定理 19（NBV 交互安全与无突变）** NBV/BBT 过 C-RAS-WM 认证 ⇒ 物理风险 ≤ ε_int；只改变「看哪个视图」不改安全包络；失败/超时/门控不过时 λ 单调不降退回 R69→R68；换装不变式（R68 定理 15）保持 ⇒ 连续无突变。

**命题 1（新颖性三角化判据）** 主张「有效新颖」⇔ `N_eff^claim≥2` + 判别性基线 + 断裂测试；缺一即「共模新颖」。与视图图共识同构：**新颖性必须被多个独立视图三角化，而非自我声明。**（方法论判据，非物理定理。）

## 7. 本轮最大风险

**一句话**：PARALLAX-RAS 把整条安全论证押在「视图图与对齐认证本身正确」上——**若独立性认证被欺骗或本身就错（外参标定错、错误来源 DAG 漏记共享祖先、BBT 选了无法真正改变基线的动作），系统就会把共模视图当独立视图、在假共识上授予 resolution bonus，而这次它还握着一份看似无懈可击的证书（N_eff、B_eff、BBT 统计量）——认证层于是从守门人变成洗白相关性的洗衣房，用一份合法的证书把「大家一起错」盖章成「已被验证」。**

**次级风险与缓解**：BBT 动作自身风险（R69 定义 302 + ε_bbt + 定理 19）；视图图/对齐投毒（ℰ_parallax 对抗训练 + VQAuditor-P + 错误祖先多源核验）；U_sym 检测失效致无限追问（引理 21 零空间检测 + 硬预算）；人类 ρ 低报（盲问 + 双盲拆分 + E307）；NCL 被游戏（外部评审 + 第三方复现断裂测试）。
