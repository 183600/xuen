# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；本轮灵感：「多模态大模型」×「开源生态」）

> 第 67 轮 SimRAS 把安全闭环推到了「离线仿真预训练 + 在线世界模型 + VQA 审计」。但它有一个隐含的架构假设：**审计者是一个可信的、单一的、封闭的黑箱**。一旦这个黑箱本身被污染、许可受限或分布外失效，整个闭环的前瞻信心就建立在一根柱子上。
>
> 本轮灵感的核心命题是：
>
> **把「单一闭源审计者」升级为「开源多模态模型共同体（Safety Commons）」：用异构开源 MLLM 的分歧估计认知不确定性，用可验证的来源图（Provenance Graph）与许可/供应链门控约束谁有资格进入控制回路，用拜占庭容错共识把「多个模型说安全」变成「可证书化的安全」。**
>
> 命名：**EcoRAS（Ecosystem-grounded Epistemic Risk-aware Adaptive Closure）**。它问的不再是「模型说了什么」，而是「**这个模型凭什么被相信，以及多少个互不相关的模型才够**」。安全性从「模型准确率」迁移为「来源可验证 × 独立可度量 × 共识可仲裁」。

## 0. 直觉与动机

**灵感 1（多模态大模型 → 从单模型置信度到群体认知）**
直觉：单个 MLLM 的 softmax 或自述置信度校准很差，尤其在分布外场景会「自信地胡说」。但如果让来源不同、架构不同、训练数据不同的多个开源 VLM 对同一场景各自给出结构化风险判断（风险因子、反事实、建议动作、证据引用），它们的**分歧**就是认知不确定性的天然探针。这类似于集合天气预报：没有任何一个模式可信，但模式间的离散度比任何单一模式的"置信度"都更可靠。

**灵感 2（开源生态 → 模型血缘与安全物料清单）**
直觉：开源交付的不只是权重，还有 model card、训练数据说明、许可证、issue 轨迹、基准榜单和 CVE。把模型当作软件供应链来管理：需要「模型物料清单」（MBOM: Model Bill of Materials）、权重签名哈希、许可证依赖 DAG。安全不再只是「准不准」，而是「**从哪来、经过谁、能不能在这个用途下合法使用**」。

**灵感 3（开放参与 → 拜占庭而非高斯）**
直觉：封闭系统里模型误差可以近似为高斯噪声；开放生态里模型可能被投毒、植入后门、恶意 fork 或伪造评测。此时「统计集成」不够，必须用**拜占庭容错**：若最多 f 个模型可能作恶，则需要 n ≥ 3f+1 且加权 quorum > 2/3。这个借自分布式系统的结论，恰好把「开源生态的开放性」从风险转化为可度量的安全参数。

**灵感 4（安全公共品 → 联邦审计账本）**
直觉：SimRAS 的 AuditBuf 只是本地缓存；开源生态应当让失败案例成为公共品。用哈希链 + 差分隐私，把各部署的匿名化失败场景汇成「已知失效地图」：社区发现的新长尾直接变成所有部署的负先验。但公共品也可能被投毒，因此账本本身需要拜占庭审计。

**灵感 5（四灵感合流 → EcoRAS 五层）**
1. **MZoo 模型内阁**：异构开源 VLM/MLLM 集合，各自输出结构化风险主张；
2. **ProvGraph 来源图**：模型→数据→许可证→评测→公告的签名 DAG，计算来源信任；
3. **EcoGate 生态门控**：哈希完整性、许可证合规、关键公告硬排除，决定模型「准入/弃权/隔离/吊销」；
4. **DELIB 审议共识**：结构化辩论 + 物理/几何验证器仲裁 + BFT quorum，输出加权共识与认知不确定性；
5. **EpiRisk / EcoLedger / C-RAS-Eco / ERS-Eco**：认知风险缩放、联邦账本复用、共识认证前缀、共识塑形控制。

## 1. 形式化定义（增量：定义 276–300）

- **定义 276（EcoRAS 总览）**：`EcoRAS = (MZoo, ProvGraph, EcoGate, DELIB, EpiRisk, EcoLedger, C-RAS-Eco, ERS-Eco)`。定位：SimRAS 的「单一审计者」升级为「可验证的开源模型共同体」。不变式：来源验证、辩论、账本写入只在语义流/后台；实时流只读取缓存共识与 λ_eco，零模型写操作。
- **定义 277（模型内阁）**：`MZoo = {(m_i, w_i, p_i, ℓ_i, h_i)}_{i=1}^n`，其中 m_i 为模型、w_i 为权重参数/能力标签、p_i 为提示模板、ℓ_i 为许可证节点、h_i 为权重与配置的签名哈希。
- **定义 278（来源图）**：`G_P = (V, E, σ)`，V = 模型 ∪ 数据集 ∪ 许可证 ∪ 评测 ∪ 公告；E ⊆ V×V 表示 `trained-on / derived-from / evaluated-on / governed-by / affected-by`；σ 为逐节点签名。模型 m 的来源子图记为 `G_P(m)`。
- **定义 279（来源信任）**：`Trust(m) = clip(α_d·DataLineage(m) + α_e·EvalIndependence(m) + α_a·CommunityAudit(m), 0, 1)`，三项分别衡量数据血缘可追溯性、评测独立性与社区审计证据量。
- **定义 280（供应链完整性）**：`Verify(m) = 1 ⇔ hash(weights_m || config_m) = h_i^signed` 且其所有基础构件通过递归验证，且不存在未处置的关键公告。任一失败则 `Verify(m)=0`。
- **定义 281（许可 DAG 与合规）**：许可证构成 DAG `L`，用途上下文 `u ∈ {research, commercial, safety_critical, redistribution}`；`Comply(m, u) = 1` 当且仅当 m 的许可证及其全部上游义务在 u 下可满足。安全关键用途额外要求「可审计权重」与「免责声明可被安全案例覆盖」。
- **定义 282（结构化风险主张）**：`c_i = (risk_factors, counterfactuals, action, probs, evidence_refs, confidence_i)`。证据引用必须指向 G_P 中的节点或当前观测的可验证片段。
- **定义 283（辩论算子）**：第 r 轮 `c_i^{(r+1)} = Debate(c_i^{(r)}, {c_j^{(r)}}_{j≠i})`。辩论只允许「引用证据 / 指出反例 / 修正概率」，不允许无证据地改变主张；每轮记录完整 transcript。
- **定义 284（验证器仲裁）**：验证器 `V(c, scene) ∈ {grounded, ungrounded, refuted}`，可调用几何/力/动力学证书、单位一致性检查、场景事实核对。只有 `grounded` 主张进入共识；`refuted` 主张触发对应模型的来源信誉扣减。
- **定义 285（加权共识与 quorum）**：`p̄ = Σ_{i∈G} w_i p_i / Σ_{i∈G} w_i`，`w_i = Trust(m_i)·Verify(m_i)·Comply(m_i,u)`，G 为 grounded 集合。当 `Σ_{i∈G} w_i < q·Σ_{i∈ADMIT} w_i`（取 q = 2/3）时判定 `NO_QUORUM`。
- **定义 286（认知不确定性分解）**：`H(Y|X) = E_{p(θ|D)}[H(Y|X,θ)] + I(Y;θ|X)`。集成估计：`Ale = (1/|G|)Σ H(p_i)`，`Epi = H(p̄) − Ale ≥ 0`。Epi 高表示模型们「各说各话」，是分布外或投毒的信号。
- **定义 287（有效集成规模）**：`n_eff = n / (1 + (n−1)·ρ̄)`，ρ̄ 为模型两两误差相关系数（用共享预训练数据、同源基准、共同 backbone 估计）。n_eff 修正「表面很多、实则同源」的虚假独立。
- **定义 288（认知风险缩放）**：`λ_eco(t) = clip(λ_base·(1 − a·Epi(t) − b·(1 − Trust̄))·min(1, n_eff/n_min), 0.6, 1.1)`。认知不确定越高、来源越不可信、独立模型越少，容差越收紧。
- **定义 289（联邦审计账本）**：`EcoLedger = [e_1, …, e_N]`，`e_j = (scene_hash, advisory, consensus, outcome, prev_hash, sig_j)`，满足哈希链 `prev_hash_j = H(e_{j−1})`。任何篡改都会破坏链。
- **定义 290（联邦复用与隐私）**：查询时按 `scene_hash` 邻域检索，返回经 `(ε_dp, δ_dp)` 差分隐私处理的聚合统计；发布需满足 k-匿名（同桶至少 k 条）。命中结果作为负先验注入 EFS-WM。
- **定义 291（EcoGate 状态机）**：`ADMIT → ABSTAIN → QUARANTINE → REVOKE`。哈希失败→QUARANTINE；许可不满足→REVOKE；关键公告未处置→ABSTAIN；全部通过→ADMIT。
- **定义 292（共识认证前缀）**：`k_eco = max{k : ∀i≤k, λ_eco(t+i)·ρ_safe(t+i) ≥ 0}`；最终 `k* = min(k_VISTA, k_emo, k_wm, k_eco, m_ras)`。
- **定义 293（共识塑形控制）**：`τ_cmd = τ_desired − γ∇_τ R_emotion − η·1[Epi > τ_epi]·(τ_desired − τ_conservative)`。认知不确定高时向保守解收缩，而非仅缩放幅度。
- **定义 294（生态干扰集）**：`ℰ_Eco = ℰ_SimRAS × {供应链投毒, 后门/木马, 许可证陷阱, 同源评测过拟合, 共识羊群效应, 账本投毒, 社区工件提示注入, 虚假高置信} `。
- **定义 295（EcoRAS 证书）**：`J_EcoRAS = (J_SimRAS, model_manifest_hash, provenance_root, gate_state, license_compliance, consensus_hash, n_eff, epi_uncertainty, ledger_height)`。Valid ⇔ Valid(J_SimRAS) ∧ gate_state = ADMIT_QUORUM ∧ license_compliance = 1 ∧ n_eff ≥ n_min ∧ epi_uncertainty ≤ τ_epi_cert。
- **定义 296（隔离与降级）**：任一模型 QUARANTINE/REVOKE 后，其权重置零并重新计算 quorum；若全局 `NO_QUORUM`，EcoRAS 冻结前瞻，`k_eco = 0`，回退到 RAS 的纯情绪闭环。
- **定义 297（模型贡献归因）**：用 Shapley 值 `φ_i = Σ_{S⊆N\{i}} |S|!(n−|S|−1)!/n!·[v(S∪{i}) − v(S)]` 分配审计信用，v 为共识与真值的一致性。防止「搭便车」与单一模型主导共识。
- **定义 298（公告即硬排除）**：若 G_P 中某关键公告标记模型 m 在用途 u 下不安全，则无论其准确率多高，`w_i := 0`。公告是对「历史已证伪」的硬约束，不可被集成投票覆盖。
- **定义 299（安全公共品不变式）**：单个模型不得单方面使共识通过；任何 DECIDED 结论必须同时满足「加权 quorum ≥ 2/3」「全部主张经验证器 grounded」「无关键排除」。这三个条件构成公共品的准入规则。
- **定义 300（在线部署不变式）**：EcoGate、辩论与账本全部异步；实时环路只消费缓存的 `(consensus, λ_eco, k_eco)`。模型更新必须走「来源验签 → 沙箱评测 → 影子部署 → 原子切换」四步，禁止热替换。

## 2. 关键算法骨架

```python
class ProvenanceGraph:
    def trust(self, m):
        if not self.verify_hash(m) or self.critical_advisory(m):
            return 0.0
        return clip(0.4*self.data_lineage(m) +
                    0.3*self.eval_independence(m) +
                    0.3*self.community_audit(m), 0, 1)

    def verify_hash(self, m):
        return sig_ok(m.h, hash(m.weights, m.config))

    def license_comply(self, m, use_ctx):
        return license_dag.satisfiable(m.license, use_ctx)


class EcoGate:
    def admit(self, m, use_ctx):
        if not self.prov.verify_hash(m):
            return 'QUARANTINE'
        if not self.prov.license_comply(m, use_ctx):
            return 'REVOKE'
        if self.prov.critical_advisory(m):
            return 'ABSTAIN'
        return 'ADMIT'


class DeliberativeCabinet:
    def decide(self, scene, models, quorum=2/3, rounds=2):
        active = [m for m in models if self.gate.admit(m, self.ctx) == 'ADMIT']
        claims = {m.id: m.risk_claim(scene) for m in active}
        for _ in range(rounds):
            claims = {i: self.debate(claims[i],
                              [c for j, c in claims.items() if j != i])
                      for i in claims}
        grounded = {i: c for i, c in claims.items()
                    if self.verifier.grounded(c, scene) != 'refuted'}
        weights = {i: self.prov.trust(M[i]) for i in grounded}
        if sum(weights.values()) < quorum * sum(m.weight for m in active):
            return Consensus(None, 'NO_QUORUM', epi=1.0)
        p_bar = weighted_mean([claims[i].probs for i in grounded], weights)
        ale = mean([entropy(claims[i].probs) for i in grounded])
        epi = max(0.0, entropy(p_bar) - ale)
        return Consensus(p_bar, 'DECIDED', epi)


def eco_risk(consensus, n_eff, trust_bar):
    lam = (1.0 - 0.4*sigmoid(consensus.epi) - 0.3*(1 - trust_bar))
    lam *= min(1.0, n_eff / N_MIN)
    return clip(lam, 0.6, 1.1)


def EcoRAS_round(M, obs):
    x_prime, face_gate, wm_preds = M.simras_frontend(obs)
    consensus = M.cabinet.decide(x_prime, M.mzoo.models)
    lam_eco = eco_risk(consensus, M.n_eff, M.trust_bar)

    if consensus.state == 'NO_QUORUM':
        return M.ras_fallback(obs)          # 冻结前瞻，回退纯 RAS

    k_eco = M.cert.certified_prefix_eco(consensus, lam_eco, M.m)
    k = min(k_eco, M.k_ras, M.k_wm, M.m)

    tau = M.pi_sigma.prefix_dispatch(x_prime, k)
    tau = (tau * lam_eco
           if consensus.epi <= M.tau_epi
           else M.contract_conservative(tau, w=consensus.epi))

    M.ledger.append(scene_hash(x_prime), consensus, outcome=None)
    return k, lam_eco, consensus, tau
```

## 3. 推导

**引理 13（认知不确定性分解与集成估计一致性）** 对任意输入 X 与答案 Y，`H(Y|X) = E_{p(θ|D)}[H(Y|X,θ)] + I(Y;θ|X)`。若各模型可视为对后验 p(θ|D) 的独立采样，则 `Ale = (1/n)ΣH(p_i)` 与 `Epi = H(p̄) − Ale` 分别是两式的相合估计；n→∞ 时 Epi→0 当且仅当模型认知一致。故「分歧」不是噪声，而是可估计的模型级不确定性。

**引理 14（相关误差下的有效集成规模）** 设单模型错误率 ε<1/2、两两错误相关 ρ̄，令 `n_eff = n/(1+(n−1)ρ̄)`，则多数投票错误率满足 `P(err) ≤ exp(−2·n_eff·(1/2−ε)²)`。当 ρ̄→1（同源模型）时 n_eff→1，集成退化为单模型；这解释了为什么「同 backbone、同数据、同榜单」的开源模型集合会制造虚假的安全感。

**定理 14（EcoRAS 端到端风险一致性）** 在 A87–A91、WM 误差界与引理 13–14 下，EcoRAS 的控制指令满足：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_eco`；
2. `α_eco ≤ exp(−2·n_eff·(q − ε_eco)²) + P(gate_sound_fail)`，其中 q = 2/3；
3. `λ_eco ≥ 0.6 ⇒ 实际执行风险 ≤ 设定上限 × 1.1`；
4. `NO_QUORUM ⇒ k_eco = 0 ∧ 回退 RAS`。

**定理 15（EcoGate 门控可靠性）** 若哈希函数抗碰撞、签名不可伪造、许可证 DAG 判定正确，则 `gate_state = ADMIT` ⇒ `Verify(m)=1 ∧ Comply(m,u)=1 ∧ 无关键公告`；供应链接管被检出的概率至少 `1 − 2^{−λ_hash}`；关键公告模型对共识的权重严格为 0。

**定理 16（拜占庭审议的安全性）** 设最多 f 个模型可能被投毒或恶意，n ≥ 3f+1，加权 quorum ≥ 2/3 且验证器 V 是 sound 的（不把 grounded 判成 refuted，也不接受物理上不可能的证书）。则任何 DECIDED 主张都必须被 V 锚定；低于 2/3 权重的恶意联盟无法翻转共识，安全违规要么破坏哈希/签名假设，要么需要 V 不 sound。这把「开源开放」从不可控风险转成可配置的 f。

**定理 17（联邦账本的完整性与可用性）** 哈希链使任意历史篡改以 `1 − 2^{−λ_hash}` 概率被检出；在 `(ε_dp, δ_dp)` 差分隐私与 k-匿名发布下，账本复用结论的误差满足 `E|λ_reuse − λ*| ≤ L_lip·d_scene·e^{−ε_dp}`；覆盖 95% 在线场景所需审计样本数随场景维度与桶半径呈 `N ≥ (d_scene/τ_scene)^{d}·log(1/δ)` 增长。

## 6. 本轮最大风险

**一句话**：开源生态的「多样性」并不等于「独立性」——共享预训练语料、共同基准与同源 backbone 会让模型们高度相关（`n_eff` 远小于 n），而供应链投毒与许可证/公告陷阱又能在来源验证通过的情况下注入系统性偏差；此时 EcoRAS 会把「很多模型都同意」误当作「可证书的安全」，把公开的公共品变成**共识化的错误**——这是本轮所有理论依赖的核心假设：**来源可验证性与模型间分歧，能够忠实代理模型的独立性与可信度**。

**次级风险与缓解**：1) 同源相关性 → 显式估计 ρ̄ 与 n_eff，低于 n_min 直接拒绝证书；2) 验证器本身不可靠 → 验证器必须是最小可信基（形式化几何/力证书），且与模型内阁异构；3) 公共品投毒 → 哈希链 + 贡献者信誉 + 冗余复核；4) 许可判定法律歧义 → 保守默认（不确定即 REVOKE）；5) 共识延迟 → 缓存 + 影子部署，绝不让实时环路等待辩论。

# IP-244 ProvGraph：来源图与 MBOM
class ProvenanceGraph:
    def __init__(self, nodes, edges, sigs, license_dag):
        self.V, self.E, self.sig = nodes, edges, sigs
        self.license_dag = license_dag

    def verify_hash(self, m):
        return sig_ok(m.h, hash_bytes(m.weights) + hash_bytes(m.config))

    def critical_advisory(self, m):
        return any(a.severity == 'critical' and a.model == m.id
                   and a.use_ctx in (None, CURRENT_USE)
                   for a in self.advisories())

    def trust(self, m):
        if not self.verify_hash(m) or self.critical_advisory(m):
            return 0.0
        return clip(0.4*self.data_lineage(m) +
                    0.3*self.eval_independence(m) +
                    0.3*self.community_audit(m), 0, 1)


# IP-245 EcoGate：四态门控
class EcoGate:
    def admit(self, m, use_ctx):
        if not self.prov.verify_hash(m):
            return 'QUARANTINE'
        if not self.prov.license_dag.satisfiable(m.license, use_ctx):
            return 'REVOKE'
        if self.prov.critical_advisory(m):
            return 'ABSTAIN'
        return 'ADMIT'


# IP-246 DELIB：辩论 + 验证器 + BFT quorum
class DeliberativeCabinet:
    def __init__(self, verifier, prov, use_ctx, quorum=2/3, rounds=2):
        self.verifier, self.prov, self.ctx = verifier, prov, use_ctx
        self.quorum, self.rounds = quorum, rounds

    def decide(self, scene, models):
        active = [m for m in models if self.gate.admit(m, self.ctx) == 'ADMIT']
        claims = {m.id: m.risk_claim(scene) for m in active}
        for _ in range(self.rounds):
            claims = {i: self.debate(claims[i],
                              [c for j, c in claims.items() if j != i])
                      for i in claims}
        grounded = {i: c for i, c in claims.items()
                    if self.verifier.check(c, scene) != 'refuted'}
        weights = {i: self.prov.trust(M[i]) for i in grounded}
        total = sum(weights.values())
        if total < self.quorum * sum(m.weight for m in active):
            return Consensus(None, 'NO_QUORUM', epi=1.0)
        p_bar = weighted_mean([claims[i].probs for i in grounded], weights)
        ale = mean([entropy(claims[i].probs) for i in grounded])
        epi = max(0.0, entropy(p_bar) - ale)
        return Consensus(p_bar, 'DECIDED', epi, transcript=claims)


# IP-247 EpiRisk：认知风险缩放
def eco_risk(consensus, n_eff, trust_bar, n_min=3, a=0.4, b=0.3):
    lam = 1.0 - a*sigmoid(consensus.epi) - b*(1 - trust_bar)
    lam *= min(1.0, n_eff / n_min)
    return clip(lam, 0.6, 1.1)


def effective_size(n, rho_bar):
    return n / (1 + (n - 1) * rho_bar)

class ChunkSafetyCertificateEco(ChunkSafetyCertificateRASWM):

        if consensus.state != 'DECIDED':
            return 0
        k_best = 0
        for k in range(1, m + 1):
            if lam_eco * self.safety_margin_est(k) >= 0:

    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

## 4. 推导

**引理 13（认知不确定性分解与集成估计一致性）** 对任意 X, Y：
```
H(Y|X) = E_{p(θ|D)}[H(Y|X,θ)] + I(Y;θ|X)
```
若各模型可视为对后验 p(θ|D) 的独立采样，则 `Ale = (1/n)ΣH(p_i)` 与 `Epi = H(p̄) − Ale` 分别是两式的相合估计。n→∞ 时 Epi→0 当且仅当模型认知一致。故分歧是可估计的模型级不确定性，而非单纯噪声。

**引理 14（相关误差下的有效集成规模）** 设单模型错误率 ε<1/2、两两错误相关 ρ̄，`n_eff = n/(1+(n−1)ρ̄)`，则
```
P(majority err) ≤ exp(−2·n_eff·(1/2−ε)²)
```
ρ̄→1 时 n_eff→1，集成退化为单模型；这解释了同 backbone、同数据、同榜单的开源模型集合为何制造虚假安全。

**定理 14（EcoRAS 端到端风险一致性）** 在 A87–A91、WM 误差界与引理 13–14 下：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_eco`；
2. `α_eco ≤ exp(−2·n_eff·(q−ε_eco)²) + P(gate_sound_fail)`，q = 2/3；
3. `λ_eco ≥ 0.6 ⇒ 实际执行风险 ≤ 设定上限 × 1.1`；
4. `NO_QUORUM ⇒ k_eco = 0 ∧ 回退 RAS`。

**定理 15（EcoGate 门控可靠性）** 若哈希抗碰撞、签名不可伪造、许可 DAG 判定正确，则 `ADMIT ⇒ Verify=1 ∧ Comply=1 ∧ 无关键公告`；供应链接管检出概率 ≥ `1 − 2^{−λ_hash}`；关键公告模型权重严格为 0。

**定理 16（拜占庭审议安全性）** 设最多 f 个恶意/投毒模型，n ≥ 3f+1，加权 quorum ≥ 2/3，验证器 V sound。则任何 DECIDED 主张必须被 V 锚定；低于 2/3 权重的恶意联盟无法翻转共识。安全违规要么破坏哈希/签名假设，要么要求 V 不 sound。

**定理 17（联邦账本完整性与可用性）** 哈希链使历史篡改以 `1 − 2^{−λ_hash}` 被检出；在 `(ε_dp, δ_dp)` 差分隐私与 k-匿名下，复用结论误差 `E|λ_reuse − λ*| ≤ L_lip·d_scene·e^{−ε_dp}`；覆盖 95% 在线场景需 `N ≥ (d_scene/τ_scene)^d·log(1/δ)`。

## 7. 本轮最大风险

**一句话**：开源生态的「多样性」并不等于「独立性」——共享预训练语料、共同基准与同源 backbone 会让模型高度相关（`n_eff` 远小于 n），而供应链投毒与许可证/公告陷阱又能在来源验证通过的情况下注入系统性偏差；此时 EcoRAS 会把「很多模型都同意」误当作「可证书的安全」，把公共品变成**共识化的错误**——这是本轮所有理论依赖的核心假设：**来源可验证性与模型间分歧，能够忠实代理模型的独立性与可信度**。

**次级风险与缓解**：1) 同源相关性 → 显式估计 ρ̄ 与 n_eff，低于 n_min 直接拒绝证书；2) 验证器不可靠 → 验证器必须是最小可信基（形式化几何/力证书），且与模型内阁异构；3) 公共品投毒 → 哈希链 + 贡献者信誉 + 冗余复核；4) 许可判定法律歧义 → 不确定即 REVOKE；5) 共识延迟 → 缓存 + 影子部署，实时环路不等待辩论。
