# 第 56 轮（承接第 55 轮 v31 GroundEdge-GenSim+++；灵感循环第 2 轮；本轮灵感：「微调」×「可靠性」）

> 第 55 轮把证书推进到“语义-接触生存核”。本轮转而审视整条证书链上最容易被忽视、却几乎必然发生的一步：**微调**。核心矛盾：**H24（证据断点）**：证书是对旧策略 `π0` 在核心域 `C0` 上的最坏情形保障，而微调只在少量 `D_ft` 上提供新证据；`D_ft` 通常集中在目标任务，`C0` 通常覆盖安全核心，二者交集之外的区域在微调后处于“证据真空”，但没有任何机制阻止系统继续沿用旧证书。**H25（点态-分布态错配）**：微调目标是逐样本 task loss，可靠性是分布态最坏情形；task loss 下降不保证任何证书裕度不降，而参数空间的信赖域（KL、LoRA 范数）也不能保证行为空间有界——参数的一小步可以是决策边界的一大步。

## 0. 直觉与动机

**灵感 1（微调 = 证书的证据断点，而非证书的延续）**
直觉：人们默认“微调只是让模型更适配”，于是把微调前的鲁棒性数字直接贴到微调后的模型上。但微调恰恰是分布偏移最剧烈、证据最稀疏的一步。正确的心智模型是：**微调使旧证书进入“待重证”状态，而不是“已通过”状态**。可部署性必须重新计算，默认值是“降级”而不是“继承”。

**灵感 2（在证书空间设信赖域，而不是在参数空间）**
直觉：KL/LoRA-norm 约束的是参数，不是行为；真正要在意的是“微调后策略在核心域上的行为与裕度漂移了多少”。定义行为证书距离 `d_J(π0,π1)`，把 CCFT 写成 `min L_task s.t. d_J ≤ ε_J`。更进一步，约束强度随旧裕度自适应：**核心（高裕度）紧约束、前沿（低裕度）松约束**——在已被证明安全的地方保守，在尚未证明的地方探索。

**灵感 3（影响函数 = 预测哪条样本会侵蚀哪块证书）**
直觉：不是所有微调样本都同等危险。用证书裕度对参数的梯度与样本 loss 的 Hessian 逆，可一阶预测每条样本 `z` 对状态 `x` 证书裕度的影响 `I(z,x)`。于是微调前可做 **可靠性数据筛选/重加权**，微调后只需对“高影响状态集”做增量重证——把 O(全域) 的昂贵核重建，压缩成 O(影响集)。

**灵感 4（证书账本与单调性：证据不可遗传）**
直觉：若允许“微调后沿用、再微调后再沿用”，证书会像传话游戏一样逐轮膨胀，最终与真实可靠性脱节。需要 **只追加的证据账本** 与 **单调性不变量**：某一维证书要维持原等级，必须在 `π_{k+1}` 上重新验证；否则自动降级。口号是“**要么重证，要么降级**”。

**灵感 5（可靠性是生存函数，不是标量）**
直觉：可靠性工程的成熟语言是危险率与生存函数：`R(t)=P(无故障到 t)`、`h(t)=−dlnR/dt`。把技能失败定义为“轨迹越出生存核 `K(Σ)` 的不可逆接触”，则证书可写成危险率上界 `h≤h_max`，微调改变的是 `h`。这把第 55 轮的生存核与经典可靠性理论接上，并给出可校准的时间尺度承诺 `R(t)≥e^{−h_max t}`。

**灵感 6（微调表面 → 证书维度风险图）**
直觉：全参微调、LoRA、只调头、prompt/适配器，触达的表示层不同，能破坏的证书维度也不同。全参最易侵蚀底层几何/接触维，只调头最易侵蚀输出层任务映射而相对保留底层鲁棒性。需要一张 **表面-证书风险图** `Φ(S,d)`，指导“为了任务增益，最少动哪一层、最多牺牲哪一维”，并决定重证集合。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（微调算子、证据域与证据真空）**
微调算子 `T=(S,D_ft,η)`，`S` 为被更新的参数子集（表面），`D_ft` 为数据，`η` 为优化过程；`π1=FT(π0,T)`。证据域 `E_ft=N_ε(supp(D_ft))`（数据支撑及其 `ε`-邻域）。旧证书核心域记为 `C0`。**证据真空** `V=C0\E_ft`。微调后 `V` 上的可靠性无见证：`witness(π1,x)=0, x∈V`。

**定义 128（证书空间信赖域 / 裕度弹性约束）**
对 `x∈C0`，证书裕度向量 `m_π(x)=(m_K,m_contact,m_sem,…)`，归一化为 `m̃∈[0,1]^d`。行为证书距离
`d_J(π0,π1)=sup_{x∈C0}[λ_a‖π1(·|x)−π0(·|x)‖_TV + Σ_d λ_d (m̃_{π0,d}(x)−m̃_{π1,d}(x))_+]`。
CCFT：`min_{π1} L_task(π1;D_ft) + μ·Σ_{z∈D_ft}ℓ_reg(z)  s.t.  d_J(π0,π1)≤ε_J`，并把约束按 `g(m̃_{π0}(x))`（随旧裕度递增）加权，实现“核心紧、前沿松”。

**定义 129（证书影响函数）**
`I(z,x) = −∇_θ m_π(x)^⊤ H_θ^{-1} ∇_θ ℓ(z,θ)`。一阶漂移估计
`Δ̂m(x)=Σ_{z∈D_ft}|I(z,x)|·|Δθ(z)|`，余项 `O(‖Δθ‖²·sup_x‖∇²_θ m‖)`。
影响集 `S_I(τ)={x∈C0 | Δ̂m(x)≥τ}`。`S_I` 既是数据筛选依据（`I` 大则降权/剔除），也是增量重证的候选集合。

**定义 130（证书账本与单调性不变量）**
账本 `L=[(k,hash(π_k),J_k,E_k,δ_k,sig_k)]` 只追加、可验签。单调性不变量：对每维 `d`，
`ρ_{k+1}(d) ≤ ρ_k(d)`，**除非**存在证据 `E'` 在 `π_{k+1}` 上覆盖 `C0_d` 且 `δ_{E'}≤Θ_d` 并记入账本。即证据不可继承，只能重证或降级。

**定义 131（危险率-可靠性证书）**
`R_π(t|x)=P(在[0,t]内不越出K(Σ)|x,π)`，`h_π(t|x)=lim_{Δt→0}P(故障∈[t,t+Δt)|存活到t)/Δt`。证书给出核上危险率上界 `h_π(t|x)≤h_max`，从而 `R_π(t|x)≥e^{−h_max t}`。微调对可靠性的作用被压缩为对 `h` 的扰动。

**定义 132（增量（Delta）证书与重组合）**
`J^Δ=(S_I,Δρ̂,cov,ε_IF,recheck_log)`。重组合
`J_{k+1}=downgrade_unsupported(J_k,T) ⊕ J^Δ`：
- `downgrade_unsupported`：把与 `S_I` 相交、且未在 `π_{k+1}` 上重证的维度降级；
- `J^Δ` 只对 `S_I` 与 `E_ft\C0` 给出（后者为**临时证书**，不并入正式等级）。
soundness 条件：若影响估计误差 `≤ε_IF`，则 `C0\S_I` 上的裕度变化 `≤τ`，无需重跑生存核。

## 2. 关键算法 伪代码

### IP-127 CCFT（Certificate-Constrained Fine-Tuning）

```python
def certificate_constrained_finetune(pi0, D_ft, cert0, eps_J, steps):
    pi = clone(pi0)
    for batch in loader(D_ft):
        loss = task_loss(pi, batch)
        # 采样核心域状态，估计行为证书距离及其梯度
        xs = sample_core(cert0.C0, n=256)
        dJ, grad_dJ = certificate_distance(pi, pi0, xs, cert0, need_grad=True)
        w = margin_weight(margin_vector(pi0, xs))       # g(m~): core-tight, frontier-loose
        penal = sum(w * relu(grad_dJ))                  # 约束的加权 hinge
        pi = sgd_step(pi, loss + mu * penal)
        if dJ > eps_J:                                  # 信赖域投影/回退
            pi = interpolate(pi0, pi, eps_J / dJ)
    return pi
```

### IP-128 FCS（Fine-tuning Certificate Sketch / 表面-证书风险图）

```python
def surface_certificate_risk(surfaces, cert_dims, probe_set):
    Phi = {}
    for S in surfaces:                       # full / lora / head / prompt
        for d in cert_dims:
            rho = probe_certificate_dimension(S, d, probe_set)
            Phi[(S, d)] = rho                # 该表面最多能使该维漂移多少
    return Phi                               # 用于选择最小暴露的微调表面

def minimal_surface(Phi, required_gain, loss_budget):
    return argmin_S surface_cost(S) \
        s.t. task_gain(S) >= required_gain \
        and all(Phi[(S, d)] <= loss_budget[d] for d in cert_dims)
```

### IP-129 IFD（Influence-guided Data curation / recheck-set）

```python
def influence_curate(pi, D_ft, cert0, tau_I, tau_keep, H_inv):
    impact = {}
    for z in D_ft:
        g_loss = grad_loss(pi, z)
        for x in cert0.probe_states:
            I = -dot(grad_margin(pi, x), H_inv @ g_loss)
            impact[x] = impact.get(x, 0.0) + abs(I)
    S_I = {x for x, v in impact.items() if v >= tau_I}
    keep = [z for z in D_ft if max_x abs(influence(z, x)) <= tau_keep]
    reweight = {z: min(1.0, tau_keep / max_x abs(influence(z, x)))
                for z in D_ft}
    return keep, reweight, S_I
```

### IP-130 RML（Reliability-Monotone Ledger）

```python
def ledger_update(L, pi_new, cert_claims, evidence):
    for d in cert_claims:
        revalidated = evidence.covers(pi_new, d) and evidence.delta(d) <= Theta[d]
        if not revalidated:
            cert_claims[d] = min(cert_claims[d], L[-1].J[d])   # 单调降级
    J_new = downgrade_unsupported(L[-1].J, pi_new) | cert_claims
    L.append(sign((len(L), hash(pi_new), J_new, evidence, ts())))
    return L, J_new
```

### IP-131 HRC（Hazard-Reliability Certificate）

```python
def hazard_certificate(pi, C0, S_I, horizon, delta_h):
    # 只在影响集 S_I 上重估危险率，其余沿用旧上界
    h_hat = {}
    for x in S_I:
        trajectories = rollout(pi, x, horizon, n=N)
        h_hat[x] = kaplan_meier_hazard(trajectories) + hoeffding(delta_h)
    h_max_new = max(baseline_h(C0 - S_I), max(h_hat.values(), default=0))
    R_bound = lambda t: exp(-h_max_new * t)
    return h_max_new, R_bound
```

### IP-132 DRC（Delta Re-Certification）

```python
def delta_recertify(pi_new, cert0, S_I, eps_IF, tau, budgets):
    delta = {}
    for d in cert0.dims_affected(S_I):
        m_before = cert0.margin(d, S_I)
        m_after = measure_margin(pi_new, d, S_I)
        delta[d] = m_before - m_after
        if delta[d] > budgets.tau_d:
            if not verify_with_full_kernel(pi_new, d, S_I):   # 必要时升级为全量
                return ('reject', 'cert_regression', d, delta[d])
    if eps_IF > budgets.eps_IF or coverage(S_I, cert0.C0) < budgets.cov_min:
        return ('reject', 'influence_bound_unsound')
    J_delta = DeltaCert(S_I, delta, coverage(S_I, cert0.C0), eps_IF)
    return ('ok', recompose(cert0, J_delta))     # J_{k+1} = downgrade ⊕ J^Δ
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CCFT | O(N_ft·T·(C_task+C_cert)) | O(|θ|) | 行为信赖域逐步投影、`d_J` 上界可估 |
| FCS | O(|S|·|d|·|probe|) | O(|S|·|d|) | 风险图覆盖、表面选择不越预算 |
| IFD | O(|D_ft|·|probe|·H⁻¹) | O(|probe|) | 影响一阶近似的余项有界 |
| RML | O(|d|·|E|) | O(|L|) | 账本只追加、签名可验、单调不变量 |
| HRC | O(|S_I|·N·T) | O(|S_I|) | 危险率估计 PAC、外推区间 sound |
| DRC | O(|S_I|·|d| + 升级项) | O(|S_I|) | 影响集完备、必要时升级全量重证 |

**正确性定理（Fine-tuning Reliability Preservation）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 影响函数一阶近似误差 `≤ε_IF` 且 `H_θ` 正定；**(A34)** CCFT 每步满足 `d_J(π0,π1)≤ε_J`；**(A35)** 账本只追加、签名可验、单调不变量由执行器强制；**(A36)** 影响集外状态裕度变化 `≤τ`，`S_I` 上危险率估计满足 PAC `(ε_h,δ_h)`。
则微调后在 `C0` 上、时域 `T` 内的故障概率满足：
```
P_fail ≤ exp(-(h_max - ε_h)·T) + P(d_J > ε_J) + P(ε_IF exceeded) + P(τ underestimated) + P(ledger tampered)
```
关键：**微调不是“重新相信模型”，而是“证书先降级、再按影响集重证”**；四道护栏（行为信赖域、影响界、危险率、账本单调性）任一失守，都不得把“微调后任务指标更好”当作“可靠性未退化”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 影响函数在非凸/大模型上低估漂移 | 高 | 二阶/多步核验 + 影响集保守扩边 + 定期全量抽检 |
| 证书距离不可微/非光滑致 CCFT 不稳定 | 高 | 平滑代理裕度 + 保守投影 + 约束违反即回退 |
| 连续微调导致证书链断裂/账本无人校验 | 中 | 强制账本不变量 + 签名与审计 + 自动降级 |
| 危险率外推在小样本下过乐观 | 高 | Kaplan-Meier + 置信上界 + 分层先验 |
| 表面风险图跨架构不可迁移 | 中 | 每架构重标定 + 探针集版本化 + 风险图有效期 |

## 6. 本轮最大风险

**一句话**：证书约束微调把“微调”从不可见的信任黑洞改造成“先降级、按影响集重证”的可审计过程，但其 soundness **三重依赖影响函数的一阶近似、证书裕度的可微代理、以及危险率外推的校准**；一旦影响函数在大模型非凸处系统性低估漂移，账本就会给出一份“看起来仍然可靠”的伪证书，让微调后的策略在核心区静默越过生存核边界——因此必须以 **影响界保守扩边 + 定期全量抽检 + 账本强制降级** 三重护栏，宁可在证据不足时降级证书，绝不把“任务指标变好”当作“可靠性未退化”。

# 第 56 轮产物 · 创新点清单 v32：RelTrust-FT（CCFT×FCS×IFD×RML×HRC×DRC）

> 承接第 55 轮产物 v31。本轮把证书体系延伸到模型生命周期的最后一公里——**微调**：把“微调”从隐式的信任假设，升级为可约束、可归因、可重证、可审计的过程。

```python
    pi = clone(pi0)
    for batch in loader(D_ft):
        loss = task_loss(pi, batch)
        xs = sample_core(cert0.C0, n=256)
        dJ, grad_dJ = certificate_distance(pi, pi0, xs, cert0, need_grad=True)
        w = margin_weight(margin_vector(pi0, xs))    # core-tight, frontier-loose
        penal = sum(w * relu(grad_dJ))
        pi = sgd_step(pi, loss + mu * penal)
        if dJ > eps_J:                               # 信赖域投影/回退
            pi = interpolate(pi0, pi, eps_J / dJ)
    return pi
```

```python
def surface_certificate_risk(surfaces, cert_dims, probe_set):

def minimal_surface(Phi, required_gain, loss_budget):

        s.t. task_gain(S) >= required_gain \
```

### IP-129 IFD

```python
def influence_curate(pi, D_ft, cert0, tau_I, tau_keep, H_inv):
    impact = {}
    for z in D_ft:
        g_loss = grad_loss(pi, z)
        for x in cert0.probe_states:
            I = -dot(grad_margin(pi, x), H_inv @ g_loss)
            impact[x] = impact.get(x, 0.0) + abs(I)
    S_I = {x for x, v in impact.items() if v >= tau_I}
    keep = [z for z in D_ft if max_x abs(influence(z, x)) <= tau_keep]
    reweight = {z: min(1.0, tau_keep / max_x abs(influence(z, x)))
                for z in D_ft}
    return keep, reweight, S_I
```

### IP-130 RML

```python
def ledger_update(L, pi_new, cert_claims, evidence):
    for d in cert_claims:
        revalidated = evidence.covers(pi_new, d) and evidence.delta(d) <= Theta[d]
        if not revalidated:
            cert_claims[d] = min(cert_claims[d], L[-1].J[d])   # 单调降级
    J_new = downgrade_unsupported(L[-1].J, pi_new) | cert_claims
    L.append(sign((len(L), hash(pi_new), J_new, evidence, ts())))
    return L, J_new
```

### IP-131 HRC

```python
def hazard_certificate(pi, C0, S_I, horizon, delta_h):
    h_hat = {}
    for x in S_I:
        trajectories = rollout(pi, x, horizon, n=N)
        h_hat[x] = kaplan_meier_hazard(trajectories) + hoeffding(delta_h)
    h_max_new = max(baseline_h(C0 - S_I), max(h_hat.values(), default=0))
    R_bound = lambda t: exp(-h_max_new * t)
    return h_max_new, R_bound
```

### IP-132 DRC

```python
def delta_recertify(pi_new, cert0, S_I, eps_IF, tau, budgets):
    delta = {}
    for d in cert0.dims_affected(S_I):
        m_before = cert0.margin(d, S_I)
        m_after = measure_margin(pi_new, d, S_I)
        delta[d] = m_before - m_after
        if delta[d] > budgets.tau_d:
            if not verify_with_full_kernel(pi_new, d, S_I):   # 必要时升级全量
                return ('reject', 'cert_regression', d, delta[d])
    if eps_IF > budgets.eps_IF or coverage(S_I, cert0.C0) < budgets.cov_min:
        return ('reject', 'influence_bound_unsound')
    J_delta = DeltaCert(S_I, delta, coverage(S_I, cert0.C0), eps_IF)
    return ('ok', recompose(cert0, J_delta))     # J_{k+1} = downgrade ⊕ J^Δ
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CCFT | O(N_ft·T·(C_task+C_cert)) | O(\|θ\|) | 行为信赖域逐步投影，`d_J` 上界可估 |
| FCS | O(\|S\|·\|d\|·\|probe\|) | O(\|S\|·\|d\|) | 风险图覆盖，表面选择不越预算 |
| IFD | O(\|D_ft\|·\|probe\|·H⁻¹) | O(\|probe\|) | 影响一阶近似余项有界 |
| RML | O(\|d\|·\|E\|) | O(\|L\|) | 只追加、签名可验、单调不变量 |
| HRC | O(\|S_I\|·N·T) | O(\|S_I\|) | 危险率 PAC、外推区间 sound |
| DRC | O(\|S_I\|·\|d\| + 升级项) | O(\|S_I\|) | 影响集完备，必要时全量重证 |

**正确性定理（Fine-tuning Reliability Preservation）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 影响函数一阶近似误差 `≤ε_IF` 且 `H_θ` 正定；**(A34)** CCFT 每步 `d_J(π0,π1)≤ε_J`；**(A35)** 账本只追加、签名可验、单调不变量由执行器强制；**(A36)** 影响集外裕度变化 `≤τ`，`S_I` 上危险率估计满足 PAC `(ε_h,δ_h)`。
则微调后在 `C0` 上、时域 `T` 内的故障概率：
```
P_fail ≤ exp(-(h_max - ε_h)·T) + P(d_J > ε_J) + P(ε_IF exceeded)
         + P(τ underestimated) + P(ledger tampered)
```
关键：**微调不是“重新相信模型”，而是“证书先降级、再按影响集重证”**。

**推论（证据不可继承）**：对任意链式微调序列 `π0→π1→…→πn`，若无逐轮重证，则账本给出的证书等级满足 `ρ_n(d) ≤ ρ_0(d)`；因此“连续微调后可靠性不降”在任何不重证的实现中都不可能成立，正是这一单调性把“静默膨胀”变成可检测的违规。

**增量重证的压缩比**：设 `|C0|=N`、`|S_I|=m`，则全量重证成本 `O(N·T·QP)`，增量成本 `O(m·T·QP)`；在影响函数把漂移集中到少数状态的场景下（实验 E168），预期 `m/N ≤ 0.15`。

2. 影响集能把重证成本压到全量的 10–20%，使“每次微调都重证”在工程上可行；
3. 账本单调性消除链式微调的证书膨胀，使可靠性承诺可审计；
4. 危险率证书给出可校准的时间尺度承诺，把“可靠性”从一句形容词变成可验收的 `R(t)`；

## 6. 本轮最大风险

**一句话**：证书约束微调把“微调”从不可见的信任黑洞改造成“先降级、按影响集重证”的可审计过程，但其 soundness **三重依赖影响函数的一阶近似、证书裕度的可微代理、以及危险率外推的校准**；一旦影响函数在大模型非凸处系统性低估漂移，账本就会给出一份“看起来仍然可靠”的伪证书，让微调后的策略在核心区静默越过生存核边界——因此必须以 **影响界保守扩边 + 定期全量抽检 + 账本强制降级** 三重护栏，宁可在证据不足时降级证书，绝不把“任务指标变好”当作“可靠性未退化”。
