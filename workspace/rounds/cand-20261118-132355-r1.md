# 第 13 轮（新灵感循环第 4 轮；本轮灵感：「行为克隆」×「自主导航」）

> **基线**：第 12 轮 MetricVoiceGauge-NCD-HUT（定义 571–582；引理 104–112；实验 E607–E626）。
> 本轮纪律：**示范只作先验 + 支撑内闭环 + 不确定性下的导航-支撑一致**。不推倒 v12：USG/TGC/BAA/GAGP 与 v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与九不变式全部保留。三个新组件——SCBP（支持证书化行为先验）、CLSC（闭环协变量证书）、UCN（不确定性证书化导航）——一律以**中立元**接入，失效即严格退回 v12（引理 119），再沿 v12/v11 退化链退回 v10/v9/v8/v7/v6。本轮只做三件事：把"行为克隆"从不可证的黑箱策略改成**带支撑证书的先验**；把"自主导航"从几何寻路改成**塑造闭环查询分布的支撑感知规划**；把"示范—漂移"对偶变成**可花费的闭环协变量预算**。

## 0. 直觉与动机

**灵感 1（行为克隆 → 支持证书化的行为先验）**
直觉：BC 最诱人的地方是"看一遍就会"，最危险的地方也正是"只会它看过的"。经典结论是复合误差：单步误差 ε 在闭环里会被 T² 放大，因为策略一旦偏离示范分布，就会进入"没人教过"的状态并越走越偏（covariate shift）。所以 v13 不把 BC 当控制器，而把它当**先验**：BC 提供动作候选、技能初始化、歧义时的并列选项，但每个查询必须携带**支撑证书**——当前 (s,a) 是否仍落在示范分布的有界密度比支撑内。核心创新：**支持证书化行为先验（Support-Certified Behavioral Prior, SCBP）**：`Ĉ_sup=(ρ̂_max,U_sup,cov,prov)`。BC 在支撑内是免费的加速器，在支撑外是必须被拒绝的幻觉。

**灵感 2（自主导航 → 导航塑造查询分布）**
直觉：导航不只是"从 A 到 B"。在 BC 闭环里，**导航决定了策略会被问到哪些状态**：路径越靠近障碍与窄通道，查询就越可能掉出示教支撑；定位越不确定，"我在支撑内"的判断本身就越不可信。所以自主导航应从几何最短路升级为**支撑感知 + 不确定性证书化**的规划：在机会约束 `P_collide≤δ_nav` 下，最小化目标代价、支撑偏离与定位熵的联合代价；当必须离开支撑时，显式插入主动定位/示范查询节点，而不是让 BC 在支撑外自信外推。核心创新：**不确定性证书化导航（Uncertainty-Certified Navigator, UCN）** 与**支持感知导航（Support-Aware Navigation）**。

**灵感 3（行为克隆 × 自主导航 → 支撑—漂移对偶）**
直觉：这两个词不是并列而是**对偶**：BC 给"在支撑内怎么动"的便宜先验，导航决定"你会被推到支撑内还是支撑外"并度量漂移。把两者统一起来，就得到一条可证的闭环：**用导航约束查询分布，用支撑证书约束 BC 的适用范围，用复合误差界约束整条轨迹的偏移预算**。核心创新：**闭环协变量证书（Closed-Loop Shift Certificate, CLSC）**：`Ĉ_shift=(ε̂,U_shift,T_eff,support)`，把单步模仿误差、支撑不确定性、定位不确定性与复合放大系数合成一个只能消耗的预算 `B_shift`（其真实来源是示范/纠偏查询预算 `B_demo`）。它和 v12 的 TGC 是"孪生但不同源"：TGC 管 sim→real 的迁移间隙，CLSC 管 demo→deployment 的分布漂移，二者都只删候选、不放宽任何安全证书。

**三者如何统一**
统一为**支撑—漂移约束下的示范先验闭环**：SCBP 在支撑内生成动作先验与技能初始化；CLSC 为整段闭环给出共形偏移上界并消耗 `B_shift`；UCN 在定位/感知不确定性下规划并认证概率中止点；SADNP 在"目标进度 / 支撑偏离 / 定位信息价值 / 偏移预算"之间联合排序；v12 的 USG/TGC 与 v11 的四重证书仍是唯一的证明来源。共享状态 `ζ_bn=(π_bc, Ĉ_sup, Ĉ_shift, B_shift, B_demo, b(x), Ĉ_nav, prov)`。**SCBP 回答"示范在这里怎么说"，CLSC 回答"整段闭环还能偏多远"，UCN/SADNP 回答"该把机器人导到哪，才让前两个问题仍有解"**。

## 1. 研究问题（轮次升级版）

- **Q1（支撑的可证边界）**：如何定义"在示范支撑内"才既能在高维状态-动作空间上检验、又能给出共形覆盖？密度比、流形距离、provenance 三者如何合成一个支撑证书？当示范多模态、非独立同分布时，支撑判定的错误率如何界定？
- **Q2（闭环偏移证书）**：单步 ε、支撑不确定度 U_sup、定位协方差 Σ 与 horizon T 如何合成闭环偏移上界？在非可交换、非平稳部署下 `Ĉ_shift` 何时失效？安全约束下的 DAgger 查询会把样本复杂度推高多少？
- **Q3（不确定性下的支持感知导航）**：如何用位姿信念而非点估计判定"是否在支撑内"，并让机会约束与支撑走廊同时成立？在必须离开支撑时，主动定位/示范查询节点的插入能否被证明优于被动外推？
- **Q4（与 v12/v11 的兼容与活性）**：BC 先验会不会绕过 USG/HAS 与 v11 四重证书？CLSC 只做过滤会不会清空可行集？UCN 的保守机会约束会不会让导航无解？新增模块能否守住 50Hz/p99≤22ms？

## 2. 设计原则（在 P19–P21 基础上新增 P22–P24）

**P22 示范即先验律（Demonstration as Prior, Never as Proof）**
BC 策略 `π_bc` 只能提供动作候选、技能初始化与并列选项，不得作为执行正确性的证明。任何由 `π_bc` 驱动的动作必须同时通过 v11/v12 全部适用证书 **且** 通过支撑证书 `Ĉ_sup`；无 `Ĉ_sup` 的 BC 查询只能作为"未认证建议"，不得进入主执行路径。

**P23 支撑内闭环预算律（In-Support Closed Loop）**
每条闭环轨迹必须携带 CLSC 的协变量偏移上界 `U_shift`，并与 v12 的 `Ĉ_gap` 及 v11 四重证书**合取**。`B_shift` 只能被消耗、不能被"想完成任务"透支；`U_shift>B_remaining` 的轨迹只能被删除、重规划、插入示范查询节点或退回 v11 规划器。CLSC 不得修改任何 v11/v12 阈值。

**P24 不确定性下导航-支撑一致律（Belief-Robust Support Consistency）**
支撑成员判定、机会约束与中止点必须对**位姿信念** `b(x)` 成立（最坏情况或置信上界），不得用点估计代替；"离开示范支撑"记为软风险（消耗预算），"未知且无恢复示范"记为硬风险（直接拒绝）。导航只能收紧可行集，不能放宽证书。

## 3. 与基线的接口（如何退化）

- SCBP 失效 ⇒ 注入先验中立元：无 BC 动作候选、无示范初始化，技能只来自 v12 USG/v11 HAS，**等价 v12 技能生成路径**；
- CLSC 失效 ⇒ 注入偏移中立元：`U_shift≡0`、`B_shift≡∞`、`Ĉ_shift≡⊤`，规划器忽略偏移项，**等价 v12 规划路径**（安全证书不变）；
- UCN 失效 ⇒ 导航退回 v12 `P_t^nav`，取消概率机会约束与支撑走廊，**等价 v12 导航/规划路径**；
- SADNP 失效 ⇒ 仍由 v12 GAGP/NCP 在候选上选择，支撑与偏移仅作事后审计，**等价 v12 NCP 决策路径**；
- 四者全失效 ⇒ MetricVoiceGauge-NCD-HUT v12，再沿 v12 前三级与 v11 十三级链退回 v10/v9/v8/v7/v6；
- **安全继承**：SCBP 只能生成候选/初始化、CLSC 只能删除候选、UCN 只能收紧导航可行集、SADNP 只能排序。新模块不能放宽 v11/v12 任何证书；四重证书 + gap 证书 + 支撑/偏移证书的合取仍由原语检查（引理 118 升级引理 109）。

## 4. 预期贡献

1. **可证的示范先验**：把"行为克隆"从"一个模仿策略"改写为"带共形支撑证书、只作候选/初始化的先验"，给出密度比—流形—provenance 三合一的支撑判定与覆盖界，覆盖 v12 完全未定义的"示范复用边界"；
2. **闭环协变量预算**：把 BC 的复合误差从事后曲线变成逐轨迹、可花费的共形上界，显式耦合支撑不确定度与定位协方差，解决"离线模仿很好、闭环越走越偏"的评估盲区；
3. **不确定性下的支持感知导航**：把导航从几何最短路变成"机会约束 + 支撑走廊 + 主动定位/示范查询"的联合规划，用位姿信念而非点估计判定支撑，避免"被认证的分布外查询"；
4. **示范-导航-安全统一闭环**：E627–E646 覆盖支撑校准、闭环偏移、机会约束导航、安全查询、多模态示范、消融与端到端长跑。

## 5. 本轮最大风险

**一句话**：支撑成员是用**估计位姿**判定的，定位一旦漂移，"在支撑内"就可能变成假阳性；而示范恰恰系统性缺少危险/恢复状态（人不会演示怎么撞墙后再救回来）。两者叠加会让 SCBP 在"支撑证书有效"的表象下，于真实状态已经出界的区域调用 BC 先验——即**用错误的位姿把分布外查询认证成支撑内查询**。

**定义 583（示范集与行为先验）** 示范集
```
D_demo = { (s_i, a_i, c_i) : i=1..N } ,  c_i ∈ C_prov
```
其中 `C_prov` 为来源标签集合（人、遥操作、其他策略、仿真）。行为先验 `π_bc(a|s)` 由 D_demo 训练（多模态头：混合密度/扩散/能量模型，避免模式平均），但 **π_bc 不是控制器**：它只在支撑证书有效时提供动作候选、技能初始化与并列选项。`π_bc` 的质量用单步共形误差 `ε` 与支撑覆盖共同刻画，而不是"离线准确率"。

**定义 584（支撑与支撑证书）** 部署查询测度 `μ_q` 与示范测度 `μ_demo` 的密度比 `ρ(s,a)=μ_q(s,a)/μ_demo(s,a)`。称查询在 `(ρ_max,r_sup)`-支撑内，若
```
ρ(s,a) ≤ ρ_max  ∧  dist( (s,a), M_demo ) ≤ r_sup ,
```
其中 `M_demo` 为示范流形。支撑证书
```
Ĉ_sup = (ρ̂_max, U_sup, cov_sup, prov_set)
```
由来源分层共形校准得到：`ρ̂_max` 是 `ρ` 的有限样本上分位，`U_sup` 是其统计不确定度，`cov_sup` 是校准覆盖，`prov_set` 是证书有效所依赖的来源标签集合。**provenance 不匹配（如用遥操作示范去认证自主部署）直接使证书失效**，不论密度比多小。

**定义 585（闭环协变量偏移与复合误差）** 设单步代价 `ℓ` 对状态 L-Lipschitz，`π_bc` 在示范分布上的期望单步误差为 `ε=E_{μ_demo}[ℓ]`，闭环第 t 步查询分布为 `μ_t`，漂移 `d_t=TV(μ_t, μ_demo)`。则
```
L_T(π_bc) = E[ Σ_{t=0}^{T-1} ℓ(s_t, π_bc(s_t)) ] ≤ T·ε + L·Σ_{t=0}^{T-1} d_t .
```
复合漂移满足递推 `d_{t+1} ≤ d_t + η·(ε + c_ρ·U_sup + c_Σ·σ_loc)`（`η` 为策略/转移敏感度，`σ_loc=sqrt(λ_max(Σ))` 为定位不确定度）。由此得到闭环偏移证书
```
Ĉ_shift = ( ε̂, U_shift, T_eff, support )
U_shift = T_eff·ε̂ + (L·η/2)·T_eff·(T_eff−1)·( ε̂ + c_ρ·U_sup + c_Σ·σ_loc ) .
```
`Ĉ_shift` 有效 ⇔ (i) 部署查询与校准查询在类型/来源内可交换（或已加权共形）；(ii) 每个查询的 `Ĉ_sup` 有效；(iii) `U_shift ≤ B_remaining`。有效时以 ≥1−α 的概率有 `L_T ≤ ĝ_shift + U_shift`。**CLSC 只删除轨迹，不修改任何 v11/v12 证书。**

**定义 586（示范查询预算与安全 DAgger）** `B_demo` 为一个任务/episode 可消耗的真实纠偏查询预算。候选查询 `q=(s,a)` 的选取为
```
q* = argmax_{q∈Q_cand}  IG(q) / cost(q)
     s.t.  q 通过 v11 物理/接触/谐波/规范证书
           ∧ 扰动到 q 后 P_t^? 非空（含 P_t^g、P_t^n）
           ∧ q 不属于"无恢复示范"禁入集 R_forbid .
```
`IG` 是对 `π_bc` 误差或 `Ĉ_shift` 的信息增益。**安全约束下可查询集 `Q_safe⊆Q_cand` 变小，会直接抬高样本复杂度（引理 115），这是不可回避的代价，而非实现缺陷。**

**定义 587（不确定性证书化导航）** 位姿信念 `b_t(x)`（高斯/粒子），障碍集 `O`。导航包络
```
N_δ = { τ : P_{b}( ∃t, x_t∈O ) ≤ δ_nav } ,
```
用置信椭球膨胀实现：`O_δ = O ⊕ E_k(Σ)`，`E_k` 为 k_δ 置信椭球，并要求跟踪余量 `m(τ) ≥ k_δ·sqrt(λ_max(Σ)) + m_track`。证书 `Ĉ_nav=(δ_nav,margin,cov,map_ver)`。**map_ver 变化（地图更新）使旧证书失效，必须重证。**

**定义 588（支持感知导航 Support-Aware Navigation）** 在目标、支撑与信息之间联合规划
```
min_τ  J_goal(τ) + λ_s·D_sup(τ) + λ_u·H(b_T) + λ_q·#QueryNodes(τ)
s.t.   τ ∈ N_δ ,
       对每个 t，若用 π_bc 查询则 Ĉ_sup(ŝ_t,b_t,π_bc(ŝ_t)) 有效；
       否则该处必须插入主动定位节点或退回 v11 规划器/专用技能。
```
支撑偏离 `D_sup(τ)=∫ max(0, dist(s_t,C_sup)) dt`。**注意：导航在这里不是"绕路偏好"，而是决定 BC 查询分布的控制量。**

**定义 589（示范-导航共享状态）**
```
ζ_bn = ( π_bc, Ĉ_sup, Ĉ_shift, B_shift, B_demo, b(x), Ĉ_nav, prov )
```
SCBP 读 `(π_bc,Ĉ_sup,prov)` 生成候选；CLSC 读 `(ε̂,U_shift,B_shift,Σ)` 删除轨迹；UCN 读 `(b,Ĉ_nav,C_sup)` 收紧导航可行集；SADNP 在 `ζ_bn` 上排序。四者共享同一状态，避免"示范、偏移、导航"各自维护一份不一致的支撑假设。

P_t = P_t^nav ∪ P_t^c ∪ P_t^h ∪ P_t^g ,
```
其中 `P_t^nav` 由 UCN 以概率证书给出（`P_collide≤δ_nav` 且存在可停位置），`P_t^g` 为 v12 迁移回退集。可执行段的必要条件升级为：`P_t^nav≠∅ ∧ P_t^c≠∅ ∧ P_t^h≠∅ ∧ P_t^g≠∅`，且整段 `Ĉ_shift` 有效、展开后的每个 BC 查询 `Ĉ_sup` 有效。四类/五类中止点分别回答"能不能安全停""接触能不能安全停""谐波能不能耗散停""迁移有没有认证回退""概率上会不会撞"。

**定义 592（技能项升级，升级定义 581）** v12 的 `π_u=(τ,β,π_h,effect,pre,post)` 追加示范元数据

```

**定义 593（BC 查询门 BC Query Gate）** 查询 `(ŝ,a)` 可被采用当且仅当
```
(i)  Ĉ_sup 有效且 prov 匹配；
(ii) dist( a, A_v11^safe(ŝ) ) ≤ m_a（动作不得越过 v11 安全动作集边界）；

```
`A_v11^safe` 是 v11/v12 证书允许的动作集，`m_a` 为安全余量。任一条件不满足 ⇒ 该 BC 动作降级为建议，主路径走 v11 规划器/专用技能。

**定义 594（支撑走廊与支持可行轨迹）**
```
C_sup = { s : Ĉ_sup(s,b(x)) 有效 } .
```
轨迹 τ 称为**支持可行**，若对每个使用 BC 查询的时刻 `s_t∈C_sup` 且 `dist(s_t,∂C_sup) ≥ m_sup`；否则必须显式插入主动定位/示范查询节点，使下一个查询点重新进入 `C_sup`。`m_sup` 为支撑边界余量，吸收定位协方差。

# IP-371 SupportCertifiedBehavioralPrior
class SupportCertifiedBehavioralPrior:
    def __init__(self, policy, density_model, provenance_index,
                 rho_max=3.0, r_sup=0.15, m_sup=0.05, alpha=0.1):
        self.pi = policy                 # 多模态 BC 头
        self.rho = density_model         # μ_q/μ_demo
        self.prov = provenance_index
        self.rho_max, self.r_sup, self.m_sup = rho_max, r_sup, m_sup
        self.alpha = alpha

    def query(self, s_hat, belief, prov_deploy, action_ref=None):
        # 1) provenance 硬门
        if not self.prov.covers(prov_deploy):
            return None
        # 2) 信念鲁棒支撑判定（定义 584/594）：最坏情况而非点估计
        rho_hi = self.rho.upper(s_hat, belief, alpha=self.alpha)
        dist_hi = self.rho.dist_to_manifold_upper(s_hat, belief)
        margin = self.r_sup - dist_hi
        if rho_hi > self.rho_max or margin < self.m_sup:
            return None
        cands = self.pi.sample(s_hat, action_ref=action_ref)   # 多模态候选
        return cands, SupCert(rho_hat=rho_hi, U_sup=self.rho.U(alpha=self.alpha),
                              cov=1 - self.alpha, prov=prov_deploy,
                              margin=margin)

    def init_skill(self, tau, beta, uc):
        # 只给 v12 USG/HAS 的初值/先验，必须被 v11/v12 重新认证
        g = self.pi.propose_skill_init(tau, beta)
        return g if g is not None else None

# IP-372 ClosedLoopShiftCertifier
class ClosedLoopShiftCertifier:
    def __init__(self, alpha=0.1, lip_L=1.0, eta=1.0, c_rho=1.0,
                 c_sigma=1.0, min_calib=30):
        self.alpha, self.L, self.eta = alpha, lip_L, eta
        self.c_rho, self.c_sigma = c_rho, c_sigma
        self.min_calib = min_calib
        self.step_scores = []            # 单步模仿误差校准集

    def update(self, step_errors):
        self.step_scores.extend(step_errors)

    def certify(self, plan, zeta_bn, B_remaining):
        if len(self.step_scores) < self.min_calib:
            return None
        eps = conformal_upper(self.step_scores, alpha=self.alpha)
        T = plan.effective_horizon                    # T_eff
        U_sup = zeta_bn.sup.U_sup
        sigma_loc = sqrt(max_eig(zeta_bn.belief.cov))
        # 定义 585：最坏情况复合
        U_shift = T * eps + (self.L * self.eta / 2.0) * T * (T - 1) * (
            eps + self.c_rho * U_sup + self.c_sigma * sigma_loc)
        if not plan.all_queries_support_certified():
            return None                               # 支撑外，无证书
        if U_shift > B_remaining:
            return None
        return ShiftCert(eps_hat=eps, U_shift=U_shift, T_eff=T,
                         support=True, coverage=1 - self.alpha)

# IP-373 UncertaintyCertifiedNavigator
class UncertaintyCertifiedNavigator:
    def __init__(self, planner, collision_checker, delta_nav=0.01,
                 k_delta=3.0, m_track=0.02, map_version=None):
        self.planner = planner
        self.check = collision_checker
        self.delta_nav, self.k_delta = delta_nav, k_delta
        self.m_track, self.map_ver = m_track, map_version

    def plan(self, belief, goal, obstacles, C_sup):
        # 1) 置信椭球膨胀（定义 587）
        inflated = [inflate(o, self.k_delta * sqrt(max_eig(belief.cov)))
                    for o in obstacles]
        # 2) 机会约束 + 支撑走廊联合规划（定义 588）
        tau = self.planner.solve(goal, inflated, support_corridor=C_sup,
                                 entropy_weight=0.3, support_weight=1.0)
        if tau is None:
            return self._fallback_v12(belief, goal, obstacles)
        # 3) 概率校验 + 跟踪余量
        if not self.check.chance_bound(tau, belief, self.delta_nav):
            return self._fallback_v12(belief, goal, obstacles)
        cert = NavCert(delta_nav=self.delta_nav,
                       margin=self.k_delta * sqrt(max_eig(belief.cov)) + self.m_track,
                       cov=1 - self.delta_nav, map_ver=self.map_ver)
        # 4) 若必须离开支撑：显式插入主动定位/示范查询节点
        for t, s in enumerate(tau.states):
            if not in_support(s, C_sup):
                tau.insert_query_node(t, kind="active_localize_or_demo")
        return tau, cert

    def _fallback_v12(self, belief, goal, obstacles):
        return self.planner.v12_deterministic(belief, goal, obstacles), None

## 4. 推导

**引理 113（支撑内复合误差界）** 设单步代价 L-Lipschitz，`π_bc` 在示范上单步误差为 ε，闭环漂移递推 `d_{t+1}≤d_t+η(ε+c_ρU_sup+c_Σσ_loc)`，则
```
L_T ≤ Tε + (Lη/2)·T(T−1)·(ε + c_ρU_sup + c_Σσ_loc) ,
```
即 `L_T = O(T²(ε+U_sup+σ_loc))`；若每 k 步做一次安全纠偏重置，则
```
L_T ≤ Tε + O(T·k·(ε+U_sup+σ_loc)) .
```
证明：由 `L_T ≤ Tε + LΣd_t` 展开，代入递推并求和 `Σ_{t<T}(t·δ)=T(T−1)/2·δ`；纠偏把每段初始 `d=0`，故求和被 `k` 截断。∎ 推论：**只报告离线单步误差没有意义；闭环风险由 ε、支撑不确定度、定位不确定度三者共同决定，且 horizon 是放大器。**

**引理 114（支撑证书的共形覆盖）** 若校准查询与部署查询在同来源分层内可交换，`ρ̂_max` 取有限样本修正的 `⌈(1−α)(n+1)⌉` 分位，则
```
P(ρ(s,a) ≤ ρ̂_max) ≥ 1−α .
```
若来源混合发生偏移但满足密度比有界与支撑覆盖，则来源分层加权共形给出 `1−α−ε_prov` 的保守下界。证明：标准分裂共形 + 分层加权共形定理；provenance 不匹配时无支撑，故 SCBP 必须把 `prov` 作为硬门。∎ 推论：**支撑证书是"来源相关"的，跨来源复用示范是未认证的。**

**引理 115（安全约束下 DAgger 的查询复杂度）** 设残差在查询特征下 Fisher 信息为 `I(q)`，无约束 D-最优每步最大信息增益；安全约束把候选集限制为 `Q_safe⊆Q_cand`，则 n 次查询后
```
tr(Cov_n) ≤ tr( (Σ_0^{-1} + Σ_{i=1}^n I(q_i))^{-1} ) ,   q_i∈Q_safe ,
```
且达到误差 ε 所需 `n ≥ Ω(d/ε · (Vol(Q_cand)/Vol(Q_safe))^{2/d})`。证明：约束 CRLB + 椭球体积比；安全约束删除的是信息量最大的边界查询，故只能以更多样本补偿。∎ 推论：**"安全查询"必然比"自由查询"贵；B_demo 必须按 Q_safe 的有效体积打折。**

**引理 116（机会约束导航的可靠性）** 若每个时刻 `b_t` 的协方差满足 `λ_max(Σ_t)≤σ_max²`，障碍按 `k_δσ_max` 膨胀且跟踪误差 `≤m_track`，则
```
P( τ∩O ≠ ∅ ) ≤ δ_nav + P( tracking violation ) ,
```
其中 `δ_nav ≤ exp(−k_δ²/2)`（高斯尾界）。证明：对每步用高斯/Chebyshev 尾界，再对 t 做 union bound；跟踪违约单独计入。∎ 推论：`Ĉ_nav` 只在 `map_ver` 与协方差界内有效；地图更新或协方差爆掉时证书自动失效。

**引理 117（支持走廊的绕行-漂移权衡）** 设支撑走廊 `C_sup` 宽度为 w，目标在 `C_sup` 外，最短无约束路径长 `L*`。任一支持可行路径长度 `L_sup` 满足
```
L_sup ≥ L* + 2·dist( goal, C_sup ) − O(w) ,
```
若允许离开支撑时长 `τ_out`，则闭环漂移至少增加 `c·τ_out`，对应 `U_shift` 至少增加 `(Lη)·T_eff·τ_out·(ε+…)`，故 `B_shift` 必须相应增长。证明：几何投影给出绕行下界；漂移项由引理 113 的递推对离开支撑区间积分得到。∎ 推论：**"支撑内更安全"不是免费的，它用路径长度与任务时间换偏移预算。**

**引理 118（安全继承与不可绕过）** v13 执行集为
```
Exec_13 = { g : v11 物理/接触/谐波/规范证书有效
               ∧ Ĉ_gap 有效（v12）
               ∧ Ĉ_sup 有效 ∧ Ĉ_shift 有效 ∧ ΣU_shift≤B_shift
               ∧ P_t^nav≠∅ ∧ P_t^g≠∅ } .
```
则 `Exec_13 ⊆ Exec_12 ⊆ Exec_11`（按展开后的 v11 技能序列比较）。证明：SCBP 只写初始化/候选，展开后仍逐项通过 v11/v12 证书；CLSC 的合取只进一步缩小集合；UCN 只收紧导航可行集；SADNP 只排序。∎ 因此 v11 引理 101/95 与 v12 引理 109 的安全继承在 v13 上继续成立。

**引理 119（中立元退化等价 v12）** 将定义 590 的四个中立元分别注入 SCBP/CLSC/UCN/SADNP 端口，则候选生成退化为 v12 USG 技能集、偏移约束恒真、导航退回 v12 `P_t^nav`、选择退化为 v12 NCP；主闭环调用序列与 v12 逐位一致，再沿 v12/v11 链退回 v10/v9/v8/v7/v6。证明：逐端口代入定义 590 即得；四端口互不相交，且中立元不改变 v11/v12 的任何证书检查。∎

**引理 120（预算守恒 v13）** 新增在线成本上界：SCBP 查询 ≤0.8ms（5Hz 摊销 0.16ms）；CLSC 证书 ≤0.5ms（摊销 0.1ms）；UCN 规划 ≤2ms（10Hz 摊销 0.2ms）；SADNP 排序 ≤1ms；导航/支撑守卫 ≤0.4ms。总决策 p99 仍 ≤22ms，50Hz 保持。证明：逐项代入复杂度表并做静态 EDF 校验 `ΣŴ_m≤B_dec`；v12 留有约 2ms 余量，v13 新增摊销约 0.5ms。∎

**引理 121（示范-导航-支撑三难下界）** 对支撑覆盖率 `1−ε_cov`、路径效率 `η=L_plan/L*`、偏移预算 B，存在论域分布使
```
n ≥ Ω( d_eff · max( log(1/ε_cov), 1 ) / B² )   或   ε_cov·η ≥ c / B ,
```
其中 `d_eff` 为示范-部署联合模型的有效维度。证明：构造一个"危险区域与示范支撑反相关"的分布（人只在安全区演示，危险区只有极少数恢复样本），把覆盖、路径效率与漂移估计联合视为一致收敛问题；由 minimax 下界得证。∎ 推论：**v13 不能同时免费获得"全支撑覆盖""零绕行""零偏移预算"；必须用 UC 拒绝域、B_shift 与 B_demo 三者显式交换。**

## 8. 已知风险与失效模式

1. **位姿不确定性下的支撑假阳性**：支撑成员用估计状态判定时，定位漂移会把真实出界的查询判成"在支撑内"。缓解：信念鲁棒支撑判定（最坏情况/置信上界）、`m_sup` 吸收协方差、定位熵超阈时禁止 BC 查询。
2. **示范对危险/恢复状态系统性缺失**：人只在安全区演示，危险区样本极少，导致支撑覆盖与安全需求反相关。缓解：`R_forbid` 硬门、恢复示范专项采集、把"无恢复示范"显式记入无证书、仿真补危险样本但只作先验。
3. **provenance 漂移**：遥操作/他人示范与自主部署不同源，密度比与支撑证书失效。缓解：来源分层共形、provenance 硬门、跨源只作初始化不作认证。
4. **复合误差界过保守或失效**：`η` 与 `L` 难估，界可能过松导致活性下降，或在非平稳部署下过紧。缓解：在线估计 `η`、分段重置、分层校准、保守余量可收紧不可放松。
5. **机会约束模型失配**：高斯/静态障碍假设遇到动态障碍、未知地图时失效。缓解：动态障碍单独机会约束、地图版本化、`map_ver` 变更即重证、检测到失配自动降级。
6. **安全 DAgger 采样不足**：`Q_safe` 过小导致信息增益低、样本爆炸。缓解：仿真预筛、约束贝叶斯实验设计、把"不可安全查询"显式记入无证书而非强行采集。
7. **多模态示范的模式平均**：混合示范下回归型 BC 取平均，导致在歧义状态执行"两个模式之间"的危险动作。缓解：多模态头 + 显著模式选择 + 歧义时并列选项交由 v12 NCP 认证。
8. **过度保守导致活性下降**：支撑覆盖不足 + 偏移预算紧张 + 机会约束严苛可能让可行集清空。缓解：分层预算、增加恢复示范与回退技能、把"可安全探测"纳入规划，但只收紧不放松。

## 9. 本轮最大风险

**一句话**：支撑成员是用**估计位姿**判定的，定位一旦漂移，"在支撑内"就可能变成假阳性；而示范恰恰系统性缺少危险/恢复状态（人不会演示怎么撞墙后再救回来）。两者叠加会让 SCBP 在"支撑证书有效"的表象下，于真实状态已经出界的区域调用 BC 先验——即**用错误的位姿把分布外查询认证成支撑内查询**。
