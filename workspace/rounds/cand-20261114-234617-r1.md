> R69 把「我该向谁求证」写进了闭环：不确定性被拆成 aleatoric 与 epistemic，后者用「流匹配多模态策略 + 主动注视/探针/问句」去消解。但 R69 有一个从未被点破的隐含前提：**闭环里的「我」是一台固定的、已知的、被工厂认证过的身体**。J_FLUID 这张证书默认写了「适用于这台机器人」，却从未把「这台」形式化。
>
> 本轮两个灵感正好把这个前提撕开：
> - **UniBot-V1（统一跨具身机器人基座模型）** 让同一套权重跑在成百上千种身体上——行为可以零样本迁移，**安全却不会**。迁移的是一条策略，不是一张证书。
> - **开源硬件** 让身体本身变成开放、可复现、可被任意克隆与魔改、会磨损、会被换件的公共制品。BOM、固件、标定来源、零件真伪，全部从「出厂常量」变成「运行时变量」。
>

>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还是被认证的那台机器吗**」——安全不只是刹车与提问，也是一张能说明「我是谁、我凭什么」的身份证。

## 0. 直觉与动机

**灵感 1（UniBot-V1 → 行为迁移 ≠ 安全迁移）**
直觉：统一基座模型把动作空间归一化、把身体编码成一个「形态 token」，于是同一策略能在机械臂、四足、轮式之间复用。这解决的是**能力**的可迁移性：动作分布相似、任务语义相似。但安全是另一回事——同样的归一化动作在质量大 5 倍的身体上是温和的，在质量小 5 倍的身体上就是危险惯性；同一夹持力对刚性指尖安全，对柔性指尖可能夹碎。**零样本迁移在能力上是卖点，在安全上是漏洞**：模型越统一，越容易让人误以为证书也统一。本轮第一刀：把「策略共享」与「证书按实例签发」彻底分离。

**灵感 2（开源硬件 → 身体是一个会变的运行时变量）**
直觉：闭源机器人出厂即冻结，BOM、固件、标定、零件都是常量；开源硬件则相反——社区会换电机、打补丁、换打印件、用克隆板、做降本替代。身体从常量变成**带来源与磨损状态的变量**。更麻烦的是「同一型号」根本不等于「同一种动力学」：开源硬件的公差、装配、耗材、固件分支差异远大于工业货架品。于是「证书适用于某型号」这句话在开源世界里几乎无意义，必须升级为「证书适用于某台已通过物理核验的个体」。

**灵感 3（开源既是风险也是解药 → 可复现性是新的信任根）**
直觉：开源降低克隆与魔改门槛（风险），但同时让 BOM 与固件**可复现构建、可被社区逐行审计**（解药）。工业闭源固件里说谎没人看得见；开源固件至少可以被复现哈希与第三方复算。所以本源不追求「信任厂商」，而是把信任挪到**可公开验证的制品**（reproducible build、签署的 BOM、社区连署）加**不可伪造的物理响应**上。开源不是安全的对立面；它是把信任从「品牌」换成「可验证性」的机会——前提是观察链独立于被观察者。

**灵感 4（身份必须物理锚定 → 不要问固件「你安全吗」）**
直觉：最深的陷阱是——如果安全核验依赖机器人自报状态，那么一个恶意固件分支可以永远自报「一切正常」，而它控制的正是「一切」。开源固件无法靠安全芯片背书（多数开源硬件没有可信执行环境）。因此核验必须**锚定在物理**：给身体一段随机、安全的激励（力矩 chirp、小幅摆动），观测其真实响应，估计惯量/阻尼/执行器增益/时延/回差，形成一个很难在没有该身体时伪造的**物理指纹**。一个能对所有随机挑战都匹配的冒牌货，在行为上已经等价于真身——这把「不可伪造性」优雅地归约为「行为等价性」。再配一个**固件之外的外部观察者**（独立电流钳、IMU、相机）做否决，才算把信任根从固件里拿了出来。

**灵感 5（可修复性 ⇒ 可再认证性 → 证书格与单调降级）**
直觉：开源的伦理核心是 right-to-repair——用户有权换件、有权自己修。但「修好能用」不等于「修好还安全」。若每次换件都要返厂重认证，开源硬件的可维护性就被安全流程杀死；若换件后默默沿用旧证书，安全就被开源杀死。中间道路是**本地再认证**：换件后重跑物理挑战 + 有界包络测试，签发一张更新来源链、但**安全包络只会收缩不会扩张**的新证书；证明不足就沿证书格向下取 meet，单调退化到 R68 的纯保守。这样修复权与安全权不冲突：**Right to repair 蕴含 Right to re-certify。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (EID, PAA, MGE, STC, XOM, RC, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **证书作用域不变式**：任何非安全停机的动作都必须伴随一张对**当前已认证身体身份**有效的证书 J；未认证/未迁移 ⇒ 只能走降级梯（定义 325）；
(iii) **失败闭合**：物理核验、外部观察、迁移任一失败，安全等级单调不升，绝不因「重新认证成功」而放宽到旧证书之外。

**定义 311（具身身份 EID）** EID = (bom_hash, fw_build_hash, calib_provenance, component_attestations, wear_state)。它是**声明身份**，不可信，只作为被核验对象。`fw_build_hash` 要求可复现构建（同一源码与工具链 ⇒ 同一哈希），使社区能独立复算。

**定义 312（物理具身指纹 Φ_emb）** 对外部施加的安全激励集合 C = {c_1..c_m}（力矩 chirp、小幅正/负向点动、静止保持段），观测响应 y，拟合物性参数 θ_emb = (惯量、阻尼、执行器增益、时延、回差、摩擦) 与残差谱。Φ_emb = (θ̂_emb, spec_residual)。距离 d_Φ(Φ_a, Φ_b) = ‖θ_a − θ_b‖_{W} + λ‖spec_a − spec_b‖。**关键性质**：Φ_emb 由物理决定，固件只能影响施加的激励与上报值，不能影响真实响应谱。

**定义 313（物理锚定认证 PAA）** 验证者 V（独立于被认证机器人固件）发随机挑战 c ← C，观测真实响应 y。PAA 通过 ⇔ d_Φ(Φ_obs(c), Φ_ref) ≤ τ_id ∧ 来源链 Valid（定义 317）∧ 挑战不可预测（c 每次新采）。**不要求安全芯片**；冒牌者若能在所有挑战上通过，即构成行为等价，而非漏洞。

**定义 314（证书作用域 σ(J)）** σ(J) = (embodiment_class, env_envelope, task_envelope, disturbance_budget)。J 不再是「一张适用于某机器人的证」，而是类型为 (Embodiment × Env × Task) → SafetyLevel 的**带作用域证书**。R69 的 J_FLUID 是 σ = 单一已知身体、无迁移的实例。

**定义 315（形态间隙 δ_m）** 在共同归一化状态 x 上比较两台身体经同一安全滤波后的闭环转移 f_A^cl, f_B^cl：
δ_m(A,B) = sup_{x∈𝒳_env} ‖f_A^cl(x) − f_B^cl(x)‖ / ρ_c(x)，
其中 ρ_c 为证书给出的收缩/不变集裕度（最小安全距离的归一化）。δ_m 把「质量/惯量/限幅/时延/传感差异」压成一个**相对于安全裕度**的无量纲量：同样的物理差异，在裕度大的身体上可迁移，在裕度小的身体上不可迁移。

**定义 316（安全迁移算子 STC 与迁移松弛）** 给定 A 上的 J_A（裕度 ρ_A）与目标 B：若 δ_m(A,B) ≤ κ·ρ_A 且 σ(J_A) 覆盖 B 的 env/task 包络，则 STC 签发 J_B，且：
(i) **迁移松弛**：J_B 的裕度 ρ_B = ρ_A − δ_m/κ（严格小于 ρ_A）；
(ii) **残余风险项** r_trans = δ_m/κ 记入证书，不可删除；
(iii) 否则拒绝迁移，B 只能走定义 320 的再认证或定义 325 的降级。

**定义 317（来源链与可复现性）** 来源链 P = 追加式哈希链，记录 BOM 版本、固件源码/工具链/构建哈希、标定来源、换件记录、社区连署。性质：**必要不充分**——来源链能排除「用错固件/换了未申报零件」，不能排除「同型号克隆件在物理上不同」，后者只能由 PAA（定义 313）兜底。

**定义 318（供应链威胁 ℰ_supply）** 伪造执行器（错扭矩常数）、替换传感器（错标度/延迟）、篡改固件谎报限幅/状态、重放旧认证记录、克隆件冒充原厂、在 BOM 中隐藏降级替代。并入 AIC：ℰ_MOSAIC = ℰ_FLUID × ℰ_supply。

**定义 319（外部观察者 XOM 与覆盖度 γ）** XOM 拥有独立于目标固件的传感通道（电流钳、独立 IMU、相机）与独立安全包络，可**否决**目标动作。覆盖度 γ ∈ [0,1] = 被 XOM 可观测且可判定的危险事件占比。定义 325 的降级梯以 γ 为分级依据。

**定义 320（修复—再认证协议 RC 与包络单调性）** 换件后执行局部 RC：PAA + 有界包络测试（在 σ 的 env_envelope 边界抽样）+ 来源链更新，签发 J′。**单调性**：除非完整重跑原认证全部条款，否则 σ(J′) ⊆ σ(J)，裕度 ρ′ ≤ ρ。证明不足 ⇒ 不放宽，只收缩。这把「本地再认证」限制为**安全上只能变保守**的操作。

**定义 321（共享策略 / 按实例证书分离）** UniBot-V1 共享权重 π_θ(·|o, e)，e = Embed(EID, Φ_emb) 为形态嵌入。允许 π 跨身体共享；**禁止** J 跨身体共享。任何「同一模型 ⇒ 同一安全」的推理非法。策略是**先验**，证书是**逐实例后验**。

**定义 322（具身条件安全滤波 EC-SF）** C-RAS-WM 升级为以已认证 EID 为条件的安全滤波器：认证时用 δ_m 收紧后的包络；运行时若实测残差偏离 Φ_ref 超过 τ_drift（磨损/松动/换件），EC-SF 自动收紧并触发 RC。安全滤波的输入永远是**已认证身份**，不是型号字符串。

**定义 323（证书格与合并）** 证书构成偏序（作用域包含 + 裕度大小）。同一台身体经多次修复得到多张 J，取 meet 得保守合并；社区评审以「安全用例 PR」形式合并，任何合并不得越出各部分作用域的交集。失败认证与旧证书取 meet ⇒ 只会更保守。

**定义 324（投毒上界与外部可观测性）** 设攻击者控制目标固件（可谎报一切）但不可控 XOM 与真实物理。若 XOM 覆盖度 γ、挑战独立、单次判定漏检率 ≤ 1−γ，则 k 次独立挑战下冒名/隐身成功率 ≤ (1−γ)^k + ε_phys。系：**安全的上界由「物理 + 独立观察」决定，而不是由固件的诚实度决定**——这正是开源硬件唯一可依赖的信任根。

**定义 325（三级降级梯，严格包含 R69/R68）** 依证据强度单调降级：
- L2（EID 认证 + 迁移有效 + XOM γ 高）⇒ 完整 MOSAIC 闭环，等同 R69 能力；
- L1（认证失败/来源可疑，但 XOM 可观测 γ>0）⇒ 丢弃交互与迁移，退回 R68 标定保守环，包络按 δ_m 收缩；
- L0（既不能认证也不能外部观测）⇒ 安全停机/最小风险姿态。
边界：σ 退化为单一已认证身体且 δ_m=0 时，MOSAIC ≡ R69；L1 ≡ R68；L0 ⊂ R68。**新层仍是旧层的严格泛化。**

**定义 326（证书 J_MOSAIC）** J_MOSAIC = (J_FLUID, EID, Φ_emb_hash, pa_result, δ_m, transfer_slack, provenance_root, xom_coverage γ, wear_state, mosaic_ver)。Valid ⇔ Valid(J_FLUID) ∧ PAA 通过 ∧ 迁移/再认证合法 ∧ σ 覆盖当前任务 ∧ γ 满足该等级要求。

# IP-264 EID：声明身份与可复现来源链（不可信，只作为被核验对象）
class EmbodimentIdentity:
    def build(self, bom, fw_src, calib):
        fw_hash = reproducible_build_hash(fw_src)     # 社区可独立复算
        chain   = ProvenanceChain.genesis(bom, fw_hash, calib)
        return EID(bom_hash=hash(bom), fw_build_hash=fw_hash,
                   calib_provenance=calib, component_attestations=[], wear=None)

    def on_part_swap(self, part, receipt):
        self.chain.append(('swap', part.id, hash(receipt)))   # 追加式，不可改历史

# IP-265 PAA：物理锚定认证（外部验证者发随机挑战，观测真实响应）
def physics_attest(robot, verifier, eid, tau_id):
    for c in verifier.fresh_challenges():             # 力矩 chirp / 点动 / 保持
        y = verifier.observe_physical_response(robot, c)  # 独立传感，不信固件自报
        phi = fit_embodiment(robot, c, y)             # 惯量/阻尼/增益/时延/回差
        if d_phi(phi, verifier.ref[eid]) > tau_id:
            return Attestation.fail('physical_mismatch')
    return Attestation.ok(phi_hash=hash(phi)) if eid.chain.valid() else \
           Attestation.fail('provenance')

# IP-266 MGE：形态间隙估计（把物理差异压成相对安全裕度的无量纲量）
def morphology_gap(J_A, body_B, env):
    xs = sample_common_states(env)                    # 共同归一化状态
    num = max(norm(cl_closed_loop(A, J_A, x) -
                   cl_closed_loop(B, J_A, x)) for x in xs)
    return num / J_A.margin                           # delta_m

# IP-267 STC：安全迁移券（只签有限、带松弛、带残余风险的新证书）
def transfer_certificate(J_A, body_B, kappa=1.0):
    dm = morphology_gap(J_A, body_B, J_A.sigma.env)
    if dm > kappa * J_A.margin: return None          # 迁移不成立
    if not covers(J_A.sigma, envelope(body_B)): return None
    rho_B = J_A.margin - dm / kappa                   # 严格更保守
    return J_B(J_A, rho=rho_B, transfer_slack=dm / kappa,
               residual_risk=dm / kappa, parent=J_A.id)

# IP-268 XOM：固件之外的外部观察者（拥有否决权）
class ExternalObserver:
    def __init__(self, channels, envelope):
        self.ch, self.env = channels, envelope        # 电流钳 / IMU / 相机
    def veto(self, state, action):
        est = self.estimate_independent(state, action)  # 不看机器人自报
        return self.env.violates(est), est

# IP-269 RC：修复—再认证（局部、可复现、包络只收缩）
def repair_recertify(robot, J_old, swapped_parts):
    eid = robot.eid.on_part_swap_all(swapped_parts)
    att = physics_attest(robot, robot.verifier, eid, TAU_ID)
    if not att.ok: return degrade(J_old, to='L1')
    J' = refine_envelope(J_old, att, shrink_only=True)   # sigma' ⊆ sigma
    return J' if bounded_env_test(robot, J'.sigma) else degrade(J_old, to='L1')

# IP-270 EC-SF：以已认证身份为条件的安全滤波（不是以型号为条件）
def embodiment_conditioned_filter(J_cur, x, action):
    if residual_drift(x, J_cur.phi_ref) > TAU_DRIFT:   # 磨损/松动/换件
        return repair_recertify_signal()
    return c_ras_wm.certified_prefix(action, J_cur.tightened_envelope)

# IP-271 AIC-MOSAIC：供应链威胁并入干扰集
def update_threat_model(base_events):
    return base_events + [CounterfeitActuator(), SwappedSensor(),
                          LyingFirmware(), ReplayedAttestation(),
                          HiddenDowngradePart()]        # ℰ_MOSAIC = ℰ_FLUID × ℰ_supply

# IP-272 J_MOSAIC：把身份、指纹、认证、间隙、来源、γ 一并写进证书
def issue_certificate(J_fluid, eid, att, dm, r_trans, chain, gamma, wear):
    return J_MOSAIC(J_fluid, eid, att.phi_hash, att.result, dm,

# IP-273 证书格：多次修复取 meet，合并不得越出作用域交集
def merge_certificates(Js):
    return fold(lambda a, b: meet(a, b), Js)          # sigma ∩, rho = min

# IP-274 MOSAIC 主闭环（外层身份/来源，内层沿用 R69 FLUID，失败即降级）
def MOSAIC_round(M, obs, task):
    # 1) 身份层：先答「我是谁、我凭什么」，再谈控制
    att = M.paa.verify(M.robot, M.verifier, M.eid)      # 含来源链 + 物理指纹
    if not att.ok:                                       # 认证失败：降级，不冒险
        return degrade_loop(M, obs, level='L1')          # 回 R68；L0 则安全停机
    # 2) 作用域层：当前任务是否落在已认证证书的 sigma 内
    if not covers(M.J.sigma, (M.eid, M.env, task)):
        J_B = M.stc.transfer_certificate(M.J, M.body, kappa=M.kappa)
        if J_B is None: return degrade_loop(M, obs, level='L1')
        M.J = M.J.merge_with(J_B)                        # 取 meet，只会更保守
    # 3) 能力层：R69 FLUID 闭环，但安全包络用迁移松弛后的包络
    with M.J.tightened_envelope as env:
        k, lam, mode, U = M.fluid_round(obs)             # IP-263
    # 4) 外部否决：即使内部全票通过，独立观察者可一票否决
    bad, est = M.xom.veto(M.state, mode.a[:k])
    if bad:
        M.audit.log('xom_veto', est)
        return safe_stop_or_R68(M, est, level='L1')
    # 5) 运行时漂移：物理指纹偏离参考 → 触发再认证（单调收缩）
    if residual_drift(M.fingerprint_now, M.J.phi_ref) > TAU_DRIFT:
        M.J = repair_recertify(M.robot, M.J, M.pending_swaps)
    M.audit.submit(M.J, att, U)                          # 证书 + 认证 + 不确定性
    return k, lam, mode, U
```

## 3. 推导

**引理 19（迁移的可靠性）** 设 A 的证书给出收缩裕度 ρ_A（闭环在不变集上以速率 ρ_A 收缩），B 相对 A 的形态间隙为 δ_m。若 δ_m ≤ κ ρ_A，则同一安全滤波在 B 上仍保持不变集，且实际裕度 ρ_B ≥ ρ_A − δ_m/κ；B 上的最坏偏差轨迹与 A 的偏差轨迹之差 ≤ (δ_m/κ)·e^{−ρ_B t}。要点：迁移不是「相信两台身体一样」，而是「把差异计入、从裕度里扣掉」；δ_m 在训练包络外无界，故迁移只在 σ 覆盖的 env 内有效。

**引理 20（物理认证的不可伪造性）** 攻击者控制固件但不可控真实物理。要在 m 次独立随机挑战上通过 PAA 且不拥有参考身体，需在挑战诱导的响应泛函上逐点逼近至 τ_id 以内；其成功率 ≤ (1−γ)^m + ε_phys，其中 γ 为独立观察覆盖度、ε_phys 为物理不可分辨界。极端情形 τ_id→0 时，通过者与参考身体**行为等价**——伪造退化为「造了一台一样的机器」，不再构成安全漏洞。

**引理 21（修复的单调降级）** 设修复后仅执行局部 RC。则除非重新满足原认证的全部条款，新包络满足 σ′ ⊆ σ、ρ′ ≤ ρ；证书格中 J′ ≤ J。故「本地可修复性」不会成为安全的后门：用户获得了修复权，但只获得了**收缩后的**安全声明。

**定理 18（MOSAIC 严格包含 FLUID-RAS 与 CALM-RAS）** 在 A99–A101 下，对任意状态与任务，MOSAIC 的安全等级 ≤ 其证据所支持的最高等级；当身体唯一、PAA 通过、δ_m=0、γ=1 时，MOSAIC 与 R69 逐指令相同；当进入 L1 时与 R68 相同；L0 为其子集。因此 R66–R69 全部落在 MOSAIC 降级梯的边界上，安全侧不做任何让步，新增的只是「跨身体/跨来源」的合法扩展。

**定理 19（车队级安全组合）** 设车队中每台已认证身体 i 的证书给出风险上界 ε_i（含迁移松弛 r_trans,i），且策略 π_θ 共享不改变各实例的 σ。则对任意任务分配，车队级最坏风险 ≤ Σ_i ε_i / N + max_i r_trans,i，且**不随车队规模放大**——前提是「共享权重、逐实例证书」不变式（定义 321）成立。系：UniBot-V1 的规模化收益不需要以安全为代价，代价只是「每台都要单独认证」的部署成本。

**定理 20（供应链投毒与外部可观测性）** 在 ℰ_supply 下，若攻击者只能篡改目标固件与 BOM 声明，而 XOM 覆盖度 γ 且挑战独立，则任何「谎报安全状态」的攻击被检出概率 ≥ 1−(1−γ)^k；若 γ→0（无可信外部观察），则不存在仅靠固件自报的安全保证。故定义 325 的 L1/L0 不是保守过度，而是**信息论下界**：没有独立观测，就没有可验证的安全。

## 6. 本轮最大风险

**一句话**：MOSAIC 把安全从「控制问题」改写成「身份与供应链问题」，而开源硬件的信任根最终只能落在「物理响应 + 独立观察」上——**若物理指纹的判别力不足（大量不同身体都能通过 τ_id）、或 δ_m 只在有限采样状态上估计而在真实包络外失控、或外部观察者本身也可被替换，那么这套认证只是「认证剧场」：系统拿着一沓盖了章的证书，自信地在一台已经不是证书所指的身体上运行**——证错了，比没有证更危险。

**次级风险与缓解**：
1. **物理挑战本身不安全**（chirp/点动可能诱发碰撞）→ 只在安全包络内、空载或支撑态执行；挑战设计过 C-RAS-WM 认证；
2. **迁移松弛被工程化滥用**（用大裕度掩盖真实差异）→ 残余风险 r_trans 写入证书且不可删；E306 强制「只更保守」；
3. **来源链不等于物理一致**（同哈希不同零件）→ 来源链只作必要条件，PAA 兜底（定义 317、引理 20）；
4. **修复流程被绕过**（社区自行换件不申报）→ 运行时指纹漂移检测 + XOM 否决 + 证书格只收缩（定义 320、322）；
5. **外部观察者的信任危机**（观察者也可能被换）→ γ 显式入证；γ 不足直接降 L0，绝不假装有独立观测。

# IP-264 EID：声明身份与可复现来源链（不可信，只作被核验对象）
class EmbodimentIdentity:
    def build(self, bom, fw_src, calib):
        fw_hash = reproducible_build_hash(fw_src)          # 社区可独立复算
        return EID(hash(bom), fw_hash, calib,
                   component_attestations=[], wear=None,
                   chain=ProvenanceChain.genesis(bom, fw_hash, calib))

    def on_part_swap(self, part, receipt):
        self.chain.append(('swap', part.id, hash(receipt)))  # 追加式，不可改历史

# IP-265 PAA：物理锚定认证（外部验证者发随机挑战，观测真实响应）
def physics_attest(robot, verifier, eid, tau_id):
    for c in verifier.fresh_challenges():                  # chirp / 点动 / 保持
        y   = verifier.observe_physical_response(robot, c) # 独立传感，不信自报
        phi = fit_embodiment(robot, c, y)                  # 惯量/阻尼/增益/时延/回差
        if d_phi(phi, verifier.ref[eid]) > tau_id:
            return Attestation.fail('physical_mismatch')
    return Attestation.ok(hash(phi)) if eid.chain.valid() \
           else Attestation.fail('provenance')

# IP-266 MGE：形态间隙（压成相对安全裕度的无量纲量）
def morphology_gap(J_A, body_B, env):
    xs  = sample_common_states(env)
    num = max(norm(cl_closed_loop(A, J_A, x) -
                   cl_closed_loop(B, J_A, x)) for x in xs)
    return num / J_A.margin                                # delta_m

# IP-267 STC：迁移券（只签有限、带松弛、带残余风险的新证书）
def transfer_certificate(J_A, body_B, kappa=1.0):
    dm = morphology_gap(J_A, body_B, J_A.sigma.env)
    if dm > kappa * J_A.margin:                 return None
    if not covers(J_A.sigma, envelope(body_B)): return None
    return J_B(J_A, rho=J_A.margin - dm / kappa,
               transfer_slack=dm / kappa,
               residual_risk=dm / kappa, parent=J_A.id)

# IP-268 XOM：固件之外的外部观察者（否决权）
class ExternalObserver:
    def __init__(self, channels, envelope):
        self.ch, self.env = channels, envelope             # 电流钳 / IMU / 相机
    def veto(self, state, action):
        est = self.estimate_independent(state, action)     # 不看机器人自报
        return self.env.violates(est), est

# IP-269 RC：修复—再认证（局部、可复现、包络只收缩）
def repair_recertify(robot, J_old, swapped_parts):

    att = physics_attest(robot, robot.verifier, eid, TAU_ID)
    if not att.ok: return degrade(J_old, to='L1')
    J_new = refine_envelope(J_old, att, shrink_only=True)  # sigma' ⊆ sigma
    return J_new if bounded_env_test(robot, J_new.sigma) else degrade(J_old, 'L1')

# IP-270 EC-SF：以已认证身份为条件（不是以型号为条件）
def embodiment_conditioned_filter(J_cur, x, action):
    if residual_drift(x, J_cur.phi_ref) > TAU_DRIFT:       # 磨损/松动/换件
        return repair_recertify_signal()
    return c_ras_wm.certified_prefix(action, J_cur.tightened_envelope)

# IP-274 MOSAIC 主闭环（外层身份/来源，内层 R69 FLUID，失败即降级）
def MOSAIC_round(M, obs, task):
    att = M.paa.verify(M.robot, M.verifier, M.eid)         # 身份层
    if not att.ok: return degrade_loop(M, obs, level='L1') # 失败：L1 / L0
    if not covers(M.J.sigma, (M.eid, M.env, task)):        # 作用域层
        J_B = M.stc.transfer_certificate(M.J, M.body, M.kappa)
        if J_B is None: return degrade_loop(M, obs, level='L1')
        M.J = M.J.merge_with(J_B)                          # meet，只会更保守
    with M.J.tightened_envelope:                           # 能力层：R69
        k, lam, mode, U = M.fluid_round(obs)               # IP-263
    bad, est = M.xom.veto(M.state, mode.a[:k])             # 外部否决
    if bad: return safe_stop_or_R68(M, est, level='L1')
    if residual_drift(M.fingerprint_now, M.J.phi_ref) > TAU_DRIFT:
        M.J = repair_recertify(M.robot, M.J, M.pending_swaps)
    M.audit.submit(M.J, att, U)
    return k, lam, mode, U
```

## 4. 推导

**引理 19（迁移的可靠性）** 设 A 的证书裕度 ρ_A，B 相对 A 的形态间隙 δ_m。若 `δ_m ≤ κρ_A`，则同一安全滤波在 B 上仍保持不变集，裕度 `ρ_B ≥ ρ_A − δ_m/κ`；两轨迹偏差之差按 `e^{−ρ_B t}` 收敛。要点：迁移不是假设两台身体一样，而是把差异从裕度里扣掉；δ_m 在 σ 外无界，故迁移只在覆盖包络内有效。

**引理 20（物理认证的不可伪造性）** 攻击者控固件但不可控物理。要在 m 次独立挑战上通过 PAA，需在响应泛函上逐点逼近至 τ_id；成功率 ≤ `(1−γ)^m + ε_phys`。τ_id→0 时通过者与参考身体行为等价——伪造退化为「造了一台一样的机器」。

**引理 21（修复单调降级）** 仅执行局部 RC 时，除非重跑原认证全部条款，否则 `σ′ ⊆ σ`、`ρ′ ≤ ρ`，J′ ≤ J。故本地可修复性不会成为安全后门。

**定理 18（严格包含 R69/R68）** 安全等级 ≤ 证据所支持的最高级；单具身 + PAA 通过 + δ_m=0 + γ=1 时与 R69 逐指令相同；L1 与 R68 相同；L0 ⊂ R68。R66–R69 全落在降级梯边界上。

**定理 19（车队级安全组合）** 各实例风险上界 ε_i（含迁移松弛），共享 π_θ 不改变实例 σ ⇒ 车队最坏风险 ≤ `Σε_i/N + max_i r_trans,i`，不随规模放大。系：UniBot-V1 的规模化收益不以安全为代价，代价是逐台认证的部署成本。

**定理 20（供应链投毒与外部可观测性）** 攻击者只能篡改固件/BOM，XOM 覆盖 γ、挑战独立 ⇒ 谎报被检出 ≥ `1−(1−γ)^k`；γ→0 时不存在仅靠固件自报的安全保证。故 L1/L0 是信息论下界而非保守过度。

## 7. 本轮最大风险

**一句话**：MOSAIC 把安全从「控制问题」改写成「身份与供应链问题」，而开源硬件的信任根最终只能落在「物理响应 + 独立观察」上——**若物理指纹判别力不足（大量不同身体都能通过 τ_id）、或 δ_m 只在有限采样状态上估计而在真实包络外失控、或外部观察者本身也可被替换，那么这套认证只是「认证剧场」：系统拿着一沓盖章证书，自信地在一台已不是证书所指的身体上运行**——证错了，比没有证更危险。

**次级风险与缓解**：物理挑战越界（只在安全包络内空载/支撑态执行 + 挑战过 C-RAS-WM）；迁移松弛被滥用（r_trans 入证不可删 + E306 强制只更保守）；来源链≠物理一致（仅作必要条件，PAA 兜底）；修复被绕过（指纹漂移检测 + XOM 否决 + 证书格只收缩）；观察者信任危机（γ 显式入证，γ 不足直接降 L0，绝不假装有独立观测）。
