# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「差异化定位」×「预训练」）

> 第 54 轮把技能组合从“能力匹配”推进到“动作空间剖面 + 云边联合证书”，但其 `α_S`、`ρ_S` 仍是**逐技能、从零标定**的，且组合判据 `compat = |A_i∩A_j|/|A_i∪A_j|` 隐含“越重叠越兼容”。本轮提出两个反向命题：H22：**相似不等于可组合**——高重叠技能会共享同一失效模式，组合只是冗余并放大负迁移；H23：**标定不必从零开始**——能力的动作-鲁棒剖面存在可预训练的低维流形，新技能只需少量样本“对位”。核心转为 **预训练能力场 + 差异化定位 + 覆盖/分离选型**。

## 0. 直觉与动机（先直觉，后定义）

**灵感 1（预训练 → 把逐技能标定变成能力场对位）**
直觉：第 54 轮的 ACS 为每个技能枚举 `A_c×A_e` 做剖面，`|S|` 个技能就是 `|S|·|A|` 次仿真，新技能无法复用旧知识。人类不是这样：人有一个“能力先验”，看到“抓取”“推”“拧”就能大致知道它们占哪块动作空间、怕什么扰动。于是先把大量异构技能的动作-鲁棒剖面预训练成一个**能力坐标场 `φ`**，新技能只需少量样本在场上“对位”，标定从 `O(|A|)` 降到 `O(k)`（k 为对位样本数）。

**灵感 2（差异化定位 → 从“重叠度”改为“地盘分离度”）**
直觉：两个技能动作剖面几乎相同，`compat→1`，第 54 轮会判为最易组合；但它们的失效模式也几乎相同，组合不增加能力覆盖，反而把同一脆弱点在时序上串联、放大负迁移。真正好的组合是**能力上不同、动作上能接**。所以给每个技能一个“地盘”：位置 `z_S`（能力坐标）、半径 `r_S`（可靠覆盖范围）、裕度 `m(S)`（与最近同行的安全边界）。组合既不许可 `m<μ`（太像、冗余），也不许可距离过大（动作语义断层），只许可一条**分离带** `μ ≤ d(z_i,z_j) ≤ η`。

**灵感 3（两个灵感相乘 → 定位需要坐标系，坐标系需要预训练）**
直觉：没有预训练，`z_S` 无从谈起，定位退化为又一次逐技能标定；没有差异化，预训练出的嵌入会把冗余技能聚成一团，还因“距离近”被误判为兼容。**预训练提供坐标系，差异化定位在坐标系里划地盘**，二者缺一不可。这把第 54 轮的 `compat`（对称重叠）升级为 **“互补性 + 连续性”双条件**。

**灵感 4（云边 → 定位对齐而不只是动作对齐）**
直觉：云端用大语料预训练 `φ_c`，边端用小样本微调 `φ_e`；两份定位之间的漂移 `δ_pos = d(z^c_S, z^e_S)` 才是云边契约真正要守的不变量。第 54 轮的 `γ_ce : A_c→A_e` 只管动作映射，若能力坐标漂移，边端会把“在云端不同”的两个技能当成“几乎一样”，区分化判据在边端失效。于是把 `γ_ce` 升级为 **定位映射 `γ_pos : Z_c→Z_e`**，并给漂移预算 `Δ_pos`。

**灵感 5（从路径搜索到覆盖-分离选型）**
直觉：第 54 轮问“能否找到一条技能组合路径”；本轮先问“该不该选这个技能进组合”。技能库选型是 **最大任务覆盖 + 最小两两冗余** 的带约束集合选择，路径搜索只是选型之后的事。这使“差异化定位”从相似度指标变成可优化的库级目标。

**灵感 6（金字塔的定位层）**
直觉：在第 54 轮动作-协同一层 `𝔸` 之上再加 **定位-预训练层 `ℙ`**：`ℙ_0` 预训练语料偏置，`ℙ_1` 能力坐标场 `φ`，`ℙ_2` 技能定位与裕度 `(z,r,m)`，`ℙ_3` 云边定位漂移 `δ_pos`。跨层证书必须同时携带 `ρ`、`A_cert`、`(z,r,m)` 与 `δ_pos`，形成 **鲁棒-动作-定位三证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（能力预训练场 CPF）**
能力预训练场是参数化映射 `φ_θ : (S, A, T_ctx) → Z ⊆ ℝ^d`，在大规模异构技能语料 `D_pre = {(S_i, A_i, α_i, ρ_i)}` 上以自监督目标训练：
```
L_pre = E_{(S,a,d)}[ ||dec(φ(S),a,d) - (α_S(a), ρ_S(d))||² ] + λ_c · InfoNCE(z_S, z_{S+}; z_{S-})
```
其中正样本 `S+` 为同一技能在不同任务/视角/负载下的增广，负样本 `S-` 为动作剖面几乎不相交的技能。训练后 `z_S = φ_θ(S)` 称 **能力坐标**。关键约束：`φ` 学的是“动作-鲁棒剖面”的低维流形，而非技能名/外观，故 **剖面相似 ⇒ 坐标相近**。

**定义 122（差异化定位与定位证书）**
技能 `S` 的定位 `pos(S) = (z_S, r_S)`，`r_S` 为其可靠覆盖半径（由其校准变体到 `z_S` 的 q-分位距离估计）。对任务族 `τ(S)` 内的技能库 `𝕊_τ`：
```
m(S) = min_{S'∈𝕊_τ, S'≠S} [ d(z_S, z_{S'}) - r_S - r_{S'} ]
```
称 `m(S) ≥ μ` 时 S **差异化可辨**；`m(S) < 0` 表示两技能地盘重叠。定位证书
```
P_cert(S) = (z_S, r_S, m(S), τ(S), g_S)
```
`g_S` 为覆盖缺口（该技能未能覆盖的任务动作子集）。注意：只与同任务族比较，跨任务族距离不具可比性。

**定义 123（差异化组合判据 DAC）**
在定义 116 的动作兼容之外，加入“分离带”两侧条件：
```
compose(S_i,S_j) ⇔ compat_a(S_i,S_j) ≥ θ_a                 # 能衔接（动作）
                ∧ m_ij = d(z_i,z_j) - r_i - r_j ≥ μ          # 不冗余（下限）
                ∧ d(z_i,z_j) ≤ η                             # 不跳跃（上限）
                ∧ ρ_{S_i⊗S_j}(d) ≥ ρ_min  ∀ d ∈ 𝔇_ρ          # 够鲁棒
```
`μ ≤ d ≤ η` 即 **分离带**。可行性要求 `μ + r_i + r_j ≤ η`，否则该技能对无可行组合带。第 54 轮的 Jaccard 判据被修正为“重叠有上限”：重叠过高即冗余否决。

**定义 124（预训练-边端定位漂移 PTC）**
云端定位 `z^c_S = φ_{θ_c}(S)`，边端微调后 `z^e_S = φ_{θ_e}(S)`。定位漂移
```
δ_pos(S) = d(z^c_S, z^e_S),   预算 δ_pos(S) ≤ Δ_pos
```
若 `φ` 在技能流形上 L-Lipschitz 且边端/云端微调数据分布满足 `W_1(D_e, D_c) ≤ ε`，则
```
δ_pos(S) ≤ L·( ε + ||θ_c - θ_e|| )
```
云边契约 `C_ce` 从动作映射扩展为 **定位映射** `γ_pos : Z_c → Z_e`，并要求 `γ_pos(z^c_S) = z^e_S` 在 `Δ_pos` 内。

**定义 125（覆盖-分离选型目标）**
技能组合选型问题：
```
max_{𝕊'⊆𝕊}   Coverage(𝕊', A_T)
s.t.          m_ij ≥ μ                 ∀ S_i,S_j ∈ 𝕊'
              ρ_{⊗𝕊'}(d) ≥ ρ_min       ∀ d
              |𝕊'| ≤ k
```
即 **最大覆盖 + 最小冗余** 的带约束集合选择。它是 NP-hard（含最大覆盖），贪心得 `1-1/e` 近似；路径规划在选定 `𝕊'` 诱导的子图上再做。

**定义 126（定位-鲁棒-动作联合证书 J+）**
```
J+ = ( J, P_cert, δ_pos, geometry_audit )
```
其中 `J=(ρ, A_cert, γ_ce, δ_a)` 为第 54 轮联合证书；`P_cert` 为定位证书；`δ_pos` 为定位漂移；`geometry_audit` 为预训练场几何体检结果。仅当 `m ≥ μ`、`δ_pos ≤ Δ_pos`、`geometry_audit = pass` 且 `J` 可部署时，组合才允许部署。

## 2. 关键算法（本轮草案）

### IP-121 CPF（能力预训练）
```python
def pretrain_capability_field(D_pre, d=64, epochs=100, lam_c=0.1):
    phi, dec, opt = Encoder(d), Decoder(), Adam()
    for _ in range(epochs):
        for batch in D_pre:                      # (skill, aug, neg, action, dim, alpha, rho)
            z = phi(batch.skill, batch.ctx)
            rec = dec(z, batch.action, batch.dim)
            loss = mse(rec, (batch.alpha, batch.rho))
            loss += lam_c * info_nce(z, phi(batch.aug), phi(batch.neg))
            opt.zero_grad(); loss.backward(); opt.step()
    return phi
```

### IP-122 DiPo（差异化定位）
```python
def position_skills(phi, skills, family, q=0.95, inf=float('inf')):
    raw = {}
    for s in skills:
        zs = mean([phi.embed(s, ctx) for ctx in s.contexts])
        rs = quantile([distance(zs, phi.embed(s, v)) for v in s.calib_variants], q)
        raw[s.id] = (zs, rs)
    pos = {}
    for s in skills:
        zs, rs = raw[s.id]
        peers = [t for t in skills if t.id != s.id and family[t.id] == family[s.id]]
        m = min((distance(zs, raw[t.id][0]) - rs - raw[t.id][1] for t in peers), default=inf)
        pos[s.id] = PosCert(zs, rs, m, family[s.id], coverage_gap(s))
    return pos
```

### IP-123 DAC（差异化组合规划）
```python
def differentiated_composition(skills, pos, A_T, mu, eta, theta_a, rho_min, k, K):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            d = distance(pos[s1.id].z, pos[s2.id].z)
            m_ij = d - pos[s1.id].r - pos[s2.id].r
            if m_ij < mu or d > eta:            # 太像(冗余) 或 太远(断层)
                continue
            if compat(s1.alpha, s2.alpha, s1.A, s2.A) < theta_a:
                continue
            if min(compose_robustness(s1.rho, s2.rho, K).values()) < rho_min:
                continue
            band_pen = abs(d - (mu + eta) / 2)  # 越靠近带中心越稳
            G.add_edge(s1.id, s2.id, cost=cost_align(s1, s2) + w_m * band_pen)
    selected = greedy_cover_separate(G, A_T, k, mu)   # 1-1/e 覆盖近似
    path = a_star(G.subgraph(selected), start='root', goal=A_T)
    return path, selected
```

### IP-124 PTC（预训练-边端迁移证书）
```python
def pretrain_transfer_cert(phi_c, phi_e, skills, Delta_pos, L, eps, tol=1e-3):
    reports = []
    for s in skills:
        delta = distance(phi_c.embed(s), phi_e.embed(s))
        bound = L * (eps + norm(phi_c.theta - phi_e.theta))
        ok = (delta <= Delta_pos) and (delta <= bound + tol)
        reports.append((s.id, delta, bound, ok))
    return all(r[3] for r in reports), reports
```

### IP-125 DNT（差异化负迁移绊线）
```python
def negative_transfer_tripwire(stream, pos, mu, c_max=0.05, window=32, hyst=0.02):
    hist = deque(maxlen=window)
    for step in stream:
        hist.append(step.conflict)
        m_now = min_margin(pos, step.active_skills)
        if m_now < mu and mean(hist) > c_max:
            return ('veto', step.active_skills, m_now)      # 裕度坍缩 + 冲突上升 → 否决
        if m_now < mu - hyst:
            pos = reprofile(pos, step)                      # 触发重定位而非硬组合
    return ('ok', pos)
```

### IP-126 GeoAudit（几何体检）
```python
def geometry_audit(phi, probes, kappa=0.7):
    ds   = [distance(phi.embed(a), phi.embed(b)) for a, b in probes]
    conf = [conflict_rate(a, b) for a, b in probes]
    corr = spearman(abs(ds), conf)        # 期望：距离远 → 冲突低，应取负相关
    collapsed = effective_rank(phi.embed_matrix()) < 0.3 * phi.dim
    return {'pass': (corr <= -kappa) and not collapsed, 'corr': corr, 'rank': ...}
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CPF | O(E·|D_pre|·d·|A|)（离线） | O(|D_pre|·d) | 剖面重建无泄漏、对比负样本动作不相交 |
| DiPo | O(|S|·|ctx|·d + |S|²·d) | O(|S|·d) | 半径分位可复现、同族比较 |
| DAC | O(|S|²·d + k·|S|² + |V| log|V| + |E|) | O(|S|²) | 分离带可行、覆盖近似有界 |
| PTC | O(|S|·d) | O(|S|) | δ_pos 预算闭合、L-Lipschitz 成立 |
| DNT | O(window + |S_on|·d) 每步 | O(window) | 迟滞防震荡、否决可回滚 |
| GeoAudit | O(N_probe·d) | O(N_probe) | 探针冲突率无偏、秩不塌缩 |

**正确性定理（Positioning-Transfer Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增：**(A29)** `φ` 在技能流形上 `L`-Lipschitz；**(A30)** 云边微调 `W_1(D_e,D_c) ≤ ε`；**(A31)** `GeoAudit` 通过（距离与冲突相关系数 `≤ -κ`）；**(A32)** 每个被选技能对满足分离带可行 `μ + r_i + r_j ≤ η`。
则对任一通过 `J+` 的组合，由并集界：
```
P(conflict | deploy) ≤ P(compat_a<θ_a) + P(m<μ) + P(d>η)
                      + P(δ_pos>Δ_pos) + (1-κ)·P(geometry distorted) + β_pre
```
覆盖保证：
```
Coverage(𝕊') ≥ (1 - 1/e)·Coverage*(A_T) - β_pre
```
其中 `β_pre` 为预训练重建偏差。关键：**冗余由下限 μ 拦住，断层由上限 η 拦住，坐标可信由几何体检 κ 担保，云边一致由 δ_pos 担保**；四者缺一，`J+` 不得签发。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 预训练场几何失真（hubness / 表示塌缩） | 高 | GeoAudit + 反事实探针 + 白化/去 hub + 拒绝签发 |
| 跨域协变量漂移导致定位漂移超预算 | 高 | Lipschitz 约束 + δ_pos 预算 + 边端重定位 |
| 分离带不可行（μ 与 η 无交集） | 中 | 按任务族自适应 μ/η；不可行则新增技能而非硬组合 |
| 预训练语料偏置/泄漏 | 中 | 去重 + 分层采样 + OOD 检测 + 剖面留出集 |
| 覆盖-分离选型 NP-hard 近似误差 | 低 | 贪心 + 局部搜索 + 覆盖上界证书 |

## 6. 本轮最大风险

**一句话**：把“差异化定位”建立在预训练潜空间距离上，整套 soundness 就押注 **`d(z_i,z_j)` 必须忠实反映真实动作冲突**；一旦能力场几何失真（hubness、塌缩、语料偏置），裕度 `m` 与分离带 `μ≤d≤η` 会同时失效——冗余被判成互补、断层被判成连续，且预训练先验会让这种错误在云边一致地复现（`δ_pos` 小反而掩盖了错误），故必须以 **反事实探针的几何体检 + 真实冲突率校准的 μ/η + 边端负迁移绊线** 三重护栏，绝不允许“潜空间里离得远”直接当作“能力上互补”的部署依据。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CPF×DiPo×DAC×PTC×DNT×GeoAudit）

> 承接第 54 轮产物 v31。本轮在动作剖面 + 云边联合证书之上，针对 **“相似≠可组合”“标定不可复用”** 两个病灶，增加 **预训练能力场、差异化定位、覆盖-分离选型** 三大算子：
> - **CPF（Capability Pretraining Field）**：自监督预训练能力坐标场 `φ`，把逐技能剖面标定摊薄为少样本对位；
> - **DiPo（Differentiated Positioning）**：技能定位 `(z_S,r_S)` 与差异化裕度 `m(S)`，输出定位证书；
> - **DAC（Differentiation-Aware Composition）**：分离带 `μ ≤ d(z_i,z_j) ≤ η` 的组合判据，修正第 54 轮“越重叠越兼容”；
> - **PTC（Pretrain-Transfer Certificate）**：云边定位漂移 `δ_pos` 与 Lipschitz 迁移界；
> - **DNT（Differentiated Negative-transfer Tripwire）**：裕度坍缩 + 冲突上升的在线否决/重定位；
> - **GeoAudit（Geometry Audit）**：潜空间距离-真实冲突相关性体检，防止几何失真。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-116/117/118/120 以纳入定位维度。

### IP-121 CPF

```python
def pretrain_capability_field(D_pre, d=64, epochs=100, lam_c=0.1):
    phi, dec, opt = Encoder(d), Decoder(), Adam()
    for _ in range(epochs):
        for batch in D_pre:
            z = phi(batch.skill, batch.ctx)
            rec = dec(z, batch.action, batch.dim)
            loss = mse(rec, (batch.alpha, batch.rho))
            loss = loss + lam_c * info_nce(z, phi(batch.aug), phi(batch.neg))
            opt.zero_grad(); loss.backward(); opt.step()
    return phi
```

### IP-122 DiPo

```python
def position_skills(phi, skills, family, q=0.95):
    raw = {}
    for s in skills:
        zs = mean([phi.embed(s, c) for c in s.contexts])
        rs = quantile([distance(zs, phi.embed(s, v)) for v in s.calib_variants], q)
        raw[s.id] = (zs, rs)
    pos = {}
    for s in skills:
        zs, rs = raw[s.id]
        peers = [t for t in skills if t.id != s.id and family[t.id] == family[s.id]]
        m = min((distance(zs, raw[t.id][0]) - rs - raw[t.id][1] for t in peers),
                default=float('inf'))
        pos[s.id] = PosCert(zs, rs, m, family[s.id], coverage_gap(s))
    return pos
```

### IP-123 DAC

```python
def differentiated_composition(skills, pos, A_T, mu, eta,
                               theta_a, rho_min, k, K):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            d = distance(pos[s1.id].z, pos[s2.id].z)
            if d - pos[s1.id].r - pos[s2.id].r < mu:  continue  # 冗余
            if d > eta:                               continue  # 断层
            if compat(s1.alpha, s2.alpha, s1.A, s2.A) < theta_a: continue
            rho_comp = compose_robustness(s1.rho, s2.rho, K)
            if min(rho_comp.values()) < rho_min:     continue
            G.add_edge(s1.id, s2.id,
                       cost=cost_align(s1, s2) + w_m * abs(d - (mu + eta) / 2),
                       m_ij=d - pos[s1.id].r - pos[s2.id].r,
                       rho_comp=rho_comp)
    selected = greedy_cover_separate(G, A_T, k, mu)
    path = a_star(G.subgraph(selected), start='root', goal=A_T)
    return path, selected
```

### IP-124 PTC

```python
def pretrain_transfer_cert(phi_c, phi_e, skills, Delta_pos, L, eps, tol=1e-3):
    reports = []
    for s in skills:
        delta = distance(phi_c.embed(s), phi_e.embed(s))
        bound = L * (eps + norm(phi_c.theta - phi_e.theta))
        ok = (delta <= Delta_pos) and (delta <= bound + tol)
        reports.append((s.id, delta, bound, ok))
    return all(r[3] for r in reports), reports
```

### IP-125 DNT

```python
def negative_transfer_tripwire(stream, pos, mu, c_max=0.05,
                               window=32, hyst=0.02):
    hist = deque(maxlen=window)
    for step in stream:
        hist.append(step.conflict)
        m_now = min_margin(pos, step.active_skills)
        if m_now < mu and mean(hist) > c_max:
            return ('veto', step.active_skills, m_now)
        if m_now < mu - hyst:
            pos = reprofile(pos, step)
    return ('ok', pos)
```

### IP-126 GeoAudit

```python
def geometry_audit(phi, probes, kappa=0.7):
    ds   = [distance(phi.embed(a), phi.embed(b)) for a, b in probes]
    conf = [conflict_rate(a, b) for a, b in probes]
    corr = spearman(abs(ds), conf)
    collapsed = effective_rank(phi.embed_matrix()) < 0.3 * phi.dim
    return {'pass': (corr <= -kappa) and not collapsed,
            'corr': corr, 'collapsed': collapsed}
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPF | O(E·|D_pre|·d·|A|) 离线 | O(|D_pre|·d) | 剖面重建无泄漏，负样本动作不相交 |
| DiPo | O(|S|·|ctx|·d + |S|²·d) | O(|S|·d) | 半径分位可复现，同族比较 |
| DAC | O(|S|²·d + k·|S|² + |V|log|V|+|E|) | O(|S|²+|E|) | 分离带可行，覆盖 1−1/e 近似 |
| PTC | O(|S|·d) | O(|S|) | δ_pos 预算闭合，L-Lipschitz 成立 |
| DNT | O(window + |S_on|·d) / 步 | O(window) | 迟滞防震荡，否决可回滚 |
| GeoAudit | O(N_probe·d) | O(N_probe) | 探针无偏，有效秩不塌缩 |

**正确性定理（Positioning-Transfer Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立，并新增 **(A29)** `φ` 在技能流形上 `L`-Lipschitz；**(A30)** 云边微调 `W_1(D_e,D_c) ≤ ε`；**(A31)** `GeoAudit` 通过（距离-冲突相关系数 `≤ -κ`，有效秩 `≥ 0.3d`）；**(A32)** 被选技能对满足 `μ + r_i + r_j ≤ η`。则对任一通过 `J+` 的组合：
```
P(conflict | deploy) ≤ P(compat_a<θ_a) + P(m<μ) + P(d>η)
                      + P(δ_pos>Δ_pos) + (1-κ)·P(geometry distorted) + β_pre

Coverage(𝕊') ≥ (1 - 1/e)·Coverage*(A_T) - β_pre
```
关键：**下限 μ 拦冗余、上限 η 拦断层、κ 担保坐标可信、δ_pos 担保云边一致**；四者任一失守，`J+` 不得签发。

## 7. 本轮最大风险

**一句话**：把“差异化定位”建立在预训练潜空间距离上，整套 soundness 就押注 **`d(z_i,z_j)` 必须忠实反映真实动作冲突**；一旦能力场几何失真（hubness、塌缩、语料偏置），裕度 `m` 与分离带 `μ≤d≤η` 会同时失效——冗余被判成互补、断层被判成连续，且预训练先验会让这种错误在云边一致地复现（`δ_pos` 小反而掩盖了错误），故必须以 **反事实探针的几何体检 + 真实冲突率校准的 μ/η + 边端负迁移绊线** 三重护栏，绝不允许“潜空间里离得远”直接当作“能力上互补”的部署依据。
