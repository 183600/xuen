## 双轴映射（外加二者交叉）

| 灵感词 | ToolGauge 的隐含假设 | 升级为 | 一句话动机 |
|---|---|---|---|
| 姿态估计 | D-Box 的覆盖是平坦格子 (d,m,i)，与观察位姿无关 | **P-Box 姿态纤维化覆盖 + 别名集** | 同一个格子「正面看过」不等于「背面看过」；位姿不确定性本身就是计量分辨率的下界 |

数值真值仍由计量层独占；姿态与身份只作为**证据的坐标系与同一性**进入，不进入数值通道。

**不变式保持声明**：
- MODGAUGE 五不变式全部保留；
- **新增证据独立性不变式**：任何用于校准/验证的回执，必须携带身份与位姿来源，且校准使用 n_eff 而非原始条数（定义 437）；
- **严格退化链延长**：TwinGauge 失效（重识别置信低 / 位姿图矛盾 / 别名不可解 / 姿态层校准样本不足）

## 0. 直觉与动机

**灵感 1（姿态估计 → 覆盖不是一个格子，而是 SE(3) 上的一个纤维）**
直觉：ToolGauge 的 D-Box 把世界压成 `(距离, 材质, 光照)` 的平坦格子，只要格子里有过一条有效回执就记为覆盖。
但感知的困难几乎全部是**位姿条件**的：同一块反光板，正对着看能测，掠射角就测不到；同一只杯子，
从把手侧看能分辨前后，从正上方看就出现前后镜像别名；同一个深度补测，位姿协方差大的时候，
「测到了」与「测准了」是两件事。姿态估计的关键启示不是「再加一个位姿输入」，而是三件更根本的事：
(a) 位姿后验是覆盖的**坐标系**——覆盖必须沿 SE(3) 纤维定义，盲区是位姿流形上的子集，而不是基空间的一个点；
(b) 位姿协方差会通过观测函数**传播**进 σ_decl，忽略它会让风险门 λ 系统性高估安全余量；
(c) 对称物体让位姿后验**多模态**，此时单模态高斯契约在数学上就是错的，必须用别名集与保守包络。
此外，姿态估计天然带有**规范自由度**（世界系怎么选），契约若不 SE(3) 等变，热替换就会在换系后失效。

**灵感 2（角色一致性 → 证据也有「同一性」，重复观测不是重复样本）**
直觉：生成视频里的「角色一致性」是让同一个人物跨帧、跨视角保持同一身份；在我们的计量系统里，
这对应一个更冷峻的统计问题：**回执必须绑定到物理实体**。ToolGauge 的 V 阶段要求「至少一条未参与拟合的独立回执」，
但什么算独立？如果三条回执都来自同一个物体、同一条连续轨迹、相邻视角，它们高度相关，
把它们当三个样本就是统计学里的**伪重复（pseudo-replication）**，会把 n=3 虚报成有效信息量 3。
更糟的是「身份泄漏」：在物体 A 上校准出的实例级参数，被热替换写进了类别级作用域，随后污染物体 B。
角色一致性给的解药是一个**身份-角色台账**：每条回执绑定 (instance id, pose track, role)，
用外观、几何、触觉、运动多线索重识别；用位姿图做跨视角/跨时间的全局一致；用角色状态机识别「角色翻转」
（工具变障碍物、部件变背景），并把身份/姿态来源写进修复证书，供人工审计。

**灵感 3（交叉 → 位姿别名与身份别名是同一枚硬币的两面）**
直觉：位姿别名是「**看起来一样，其实位姿不同**」（对称物体）；身份别名是「**位姿一样，其实物体不同**」
（两个同型号零件、换人、遮挡后接错轨迹）。两者都会制造**隐藏相关**：前者让同一物理位姿被当成多个视角，
后者让同一视角被当成多个实体。ToolGauge 的最大风险是「跨盲区相关污染」，而这两条灵感恰好指向相关性的
两个主要来源：**同一实体的重复计数**与**对称等价的重复计数**。TwinGauge 用一张统一的**证据图**同时处理：
边 = 共享身份或位姿重叠；独立集 = 可用于校准与验证的近似独立证据。

## 1. 形式化定义（增量：定义 432–449）

**定义 432（姿态纤维化覆盖与 P-Box）** 令状态空间 ℳ = SE(3) × 𝒜（𝒜 为外观/材质/光照模式），
底投影 π: ℳ → ℬ 把位姿纤维压回基格子。一个**位姿条件化格子** s = (b, U, a)，其中 b ∈ ℬ、U ⊂ SE(3) 可测、
a ∈ 𝒜。覆盖是纤维上的函数 C_t: ℳ → [0,1]；给定位姿后验 ρ_t(ξ|o)，格子的**有效覆盖**定义为
C_t(s; ρ) = ∫_U c_t(ξ,a)·ρ_t(ξ|o)dξ / ∫_U ρ_t(ξ|o)dξ，并同时记录下侧分位 C_t^{α_tail}(s; ρ)。
当 C_t(s;ρ) < 1−ε_cov 或 C_t^{α_tail} < 1−ε_tail 时，s 为盲区。
直觉：平均值覆盖会掩盖「掠射角尾部全瞎」；两个数都要报。

**定义 433（位姿可分辨尺度与 CRLB 粗粒化）** 观测 o 对位姿的 Fisher 信息
J(ξ) = E[∇_ξ log p(o|ξ) ∇_ξ log p(o|ξ)ᵀ]，Cramér–Rao 下界 Σ_CRLB(ξ) = J(ξ)⁻¹。
定义位姿分辨率 λ_pose(ξ) = √λ_max(Σ_CRLB(ξ))。**粗粒化原则**：覆盖只在直径 ≥ λ_pose 的位姿胞上声明；
任何小于该尺度的「覆盖」不计数。这把「测不准的点」从覆盖统计中剔除，防止用后验均值假装测准。

**定义 434（对称别名集与多模态契约）** 设对称群 G_sym ≤ O(3) 作用在位姿上。给定观测 o 与位姿 MAP ξ̂，
别名集 A(o) = { g·ξ̂ : g ∈ G_sym, p(o|gξ̂) ≥ (1−ε_alias)·max_h p(o|h) }，模式权重 π_m ∝ p(o|m)。
别名熵 H(A) = −Σ_m π_m log π_m。契约按模式索引：q(u|m) = 𝒩(μ_m, Σ_m)；当 |A| > 1 时，
**禁止**输出单个高斯，必须输出 (i) 混合契约，或 (ii) **保守包络**（各模式可信域的并 + 模式间散布项）。
单模态点契约在 |A|>1 时视为无效契约（定义 433 的别名版不可辨识性，见引理 52）。

**定义 435（SE(3) 规范等变契约）** 对 T = (R,t) ∈ SE(3)，位姿作左作用 T·ξ。契约 EC 称为**规范等变**的，若
EC(T·x) = ρ(T)·EC(x) 对某个表示 ρ 成立（标量量如深度偏移应不变，向量量按 R 旋转）。
热替换的前置条件包含等变测试：在留出的变换集合上误差 ≤ ε_eq。含等变失败 ⇒ 不替换（stub），
防止「在 A 坐标系标定、换到 B 坐标系后悄悄错」。

**定义 436（身份-角色台账 IRL）** 台账 ℒ = {e_k}，每条 e_k = (id_k, τ_k, role_k, z_k, ξ_{k,1:t}, π_k, c_k)：
实例 id、轨迹、角色、外观嵌入、位姿轨迹、来源、置信度。回执 r 通过绑定函数 b(r) 关联到 e_k；
绑定分数由外观/几何/触觉/运动四线索融合，b(r).conf ≥ c_id_min 才允许进入实例级统计。
角色枚举 ℛ = {part, tool, obstacle, human, background}，角色状态机只允许预注册迁移 Δ_role。

**定义 437（证据独立性图与有效样本量 n_eff）** 以回执为节点建图 G_E：若两回执共享 id，
或位姿距离 d_SE3(ξ_i, ξ_j) < δ_pose（位姿重叠/邻近），或来自同一采集批/同一环境协变量，则连边。
校准与 V 阶段只能使用 G_E 的独立集 I(G_E)，且要求 |I| ≥ 2。
有效样本量采用聚类设计效应：n_eff = n / (1 + (n̄_g − 1)ρ_ICC)，ρ_ICC 由同身份重复观测的 ANOVA 估计；
**默认最坏相关 ρ_ICC = 1 ⇒ n_eff = 身份簇数**（保守下界）。曲线拟合/后验更新一律以 n_eff 替换 n。

**定义 438（伪重复、身份泄漏与作用域契约）** 同一 id 的 k 条回执称为 k 次**伪重复**；
其信息量按 n_eff 计，不按 k 计。契约参数带作用域 scope(u) ∈ {instance(id), class(c), global}；
热替换的写集 W(EC) 必须落在盲区 s 被授权的 scope 内：
实例参数要求该实例 n_eff ≥ n_eff_min；类别参数要求 ≥ K 个**不同实例**且每实例 n_eff ≥ 1。
违者判定为**身份泄漏**（在 A 上标定、写进 class 污染 B），拒绝替换。

**定义 439（语义-数值-身份一致性 SNIC）** 在 SNC（定义 425）上增加身份轴：
对同一 id，跨回执的角色必须一致（除非命中 Δ_role），且位姿归一化后的度量/外观描述子距离
d(z_i, z_j; ξ) ≤ ε_id。角色翻转或描述子越界 ⇒ 判为「身份错误」或「新盲区」二选一，
进入定义 440 的分诊；不得直接写入契约。

**定义 440（位姿图一致性与回路分诊）** 以回执位姿为节点、相对观测为边建位姿图，回路 l 的残差
e_l = log(ξ_i⁻¹ ξ_ij ξ_j)，一致性统计量 χ²_l = e_lᵀ Ω_l e_l。χ²_l > χ²_gate 时为矛盾，按固定顺序分诊：
(a) 身份关联错误 ⇒ 触发重识别探测；(b) 对称别名 ⇒ 触发别名破除探测（定义 441）；(c) 真实盲区 ⇒ 进入修复。
分诊顺序固定，避免「用修契约来掩盖关联错误」。

**定义 441（别名破除探测与别名信息增益）** 工具库扩展 T₀′ = T₀ ∪ {texture.gradient, tactile.contact,
motion.parallax}，专门用于打破 G_sym 不变性。采集函数增加别名项：
Ĝ_alias = H(A) − E_{z}[H(A|z)]（对模式不确定性的期望下降，而非仅方差下降）。
T-Box 的增益注改为 β_t = Ĝ_var + λ_alias·Ĝ_alias − c_t ≥ γ_B；当 H(A) 高于阈值时别名项获得优先权。

**定义 442（位姿不确定性的契约传播）** 观测 y = g(ξ) + ε，ε ~ 𝒩(0, σ_meas²)，ξ ~ 𝒩(ξ̂, Σ_ξ)。
一阶传播给出 Σ_y ≈ σ_meas²·I + J_g Σ_ξ J_gᵀ；标量通道取
σ_decl² = σ_meas² + λ_max(J_g Σ_ξ J_gᵀ)（保守上界）。
每条回执新增字段 pose_cov 与 propagated σ；缺失 pose_cov 时用 Lipschitz 上界
σ_pose ≤ L_g·σ_ξ·√(2 log(1/δ)) 兜底（引理 53）。风险门 λ 必须用传播后的 σ_decl 计算。

**定义 443（分层共形姿态覆盖）** 将 SE(3) 划为姿态层 {P_j}（方位×俯仰×距离的预注册分箱）。
在每个层内独立做 split conformal，得到层条件覆盖 P(h*∈H_s | s∈P_j) ≥ 1−α；
跨层同时保证用 Bonferroni（每层 α/T）或 learn-then-test 自适应分配 α_j。
某层校准样本 n_j < n_min 时先做相邻层分层池化；仍不足则该姿态层标为 UNKNOWN（退化，不假装覆盖）。

**定义 444（TwinGauge 八段闭环 8C）** 修复循环 =
H(ypothesize) → B(ind) → C(ompile) → E(xecute) → G(auge) → C(alibrate) → V(erify) → U(pdate)：
1. H：P-Box 发现位姿条件盲区 s，L-Box 产出假设集 H_s 与别名集 A_s；
2. B：IRL 绑定身份/角色，构证据图；置信不足先尝试重识别探测，仍不足则 UNKNOWN；
3. C：T-Box 编译含别名破除工具的 Π_s，TCV 验证 schema/前置/预算/循环；
4. E：PROBING 态执行，回执携带 pose_cov 与来源签名；
5. G：位姿图更新与回路分诊（定义 440），不一致先修关联/别名，不修契约；
6. C：AP-Cal 以 n_eff 与传播后的 σ 输出模式索引后验；
7. V：**身份相异 + 位姿分离**的独立回执交叉验证 + 等变测试 + 契约回归；
8. U：按 scope 热替换 + 证据谱系证书；失败 ⇒ 声明式保守退化（定义 447）。

**定义 445（姿态-身份预算契约 PIP-Contract）** PIP = (B_tools, B_pose, L_max, δ_pose, n_eff_min,
c_id_min, χ²_gate, τ_repair, recovery)，是 TB-Contract（定义 424）的姿态/身份细化：
多出的别名破除与重识别探测计入 B_pose；n_eff 不足、身份置信不足、回路矛盾超时都按 recovery 处理。
时序结论继承引理 45/50。

**定义 446（身份修复证书与证据谱系）** RepairCert′(s) = (H_s, A_s, Π_s, receipts, {b(r)},
位姿图补丁, n_eff, 等变测试报告, 文字解说)。解说中的每个数值仍须逐字引自 receipts；
新增身份/位姿谱系字段，使「这条证据来自哪个物体的哪个视角」可审计（E443/E455）。

**定义 447（姿态/身份驱动的声明式退化链）** 触发条件与语义：
- 重识别置信 < c_id_min 且重识别探测预算耗尽 ⇒ 以 ρ_ICC=1 合并身份簇，取 n_eff = 簇数下界；
  若 n_eff < n_eff_min ⇒ stub + RED（**不**静默假设独立）；
- 位姿层校准不足 ⇒ 该层 UNKNOWN；别名不可解 ⇒ 只允许保守包络契约，否则 stub；
- 等变测试失败 ⇒ 拒绝替换；以上任一 ⇒ 退回 ToolGauge 的等价路径（其自身再退化到 LeanGauge/MODGAUGE）。

**定义 448（角色状态机）** 每个 id 维护角色状态 role_t 与允许迁移 Δ_role；
未声明迁移即角色翻转，产生矛盾证据。角色不是语义装饰：它决定实例级参数能否跨部件复用，
以及别名破除工具是否可选（例如 tactile.contact 对 human 角色受 PROBING 约束限制）。

**定义 449（继承与退化特例）** 未重定义记号沿用定义 398–431。令 G_sym = {e}、位姿已知（Σ_ξ = 0）、
每条回执来自不同实例、无回路矛盾 ⇒ TwinGauge ≡ ToolGauge；
令 VLA=∅、T₀′={被动观测}、MP-Φ=物理先验 ⇒ 继续退化为 LeanGauge/MODGAUGE。

```python
                tail  = lower_quantile_coverage(b, U, rho, q=ALPHA_TAIL)

                    yield BlindSpot(b, U, appearance_mode(b), cov, tail)
    def update(self, s, q_u):
        self.fiber[s] = mix_on_fiber(self.fiber[s], q_u)   # 按位姿纤维聚合，不压平

# IP-322 AliasSet：对称别名 + 保守包络契约
class AliasSet:
    def infer(self, obs, xi_hat, sym_groups):
        g = select_group(obs, sym_groups)                  # 由失败指纹选对称群
        modes = [g_i * xi_hat for g_i in g]
        w = softmax([loglik(obs, m) for m in modes])
        return AliasSet(modes, w, H=entropy(w))
    def contract(self, a):

        return EnvelopeContract(a.modes, radius=a.spread + max_sigma)  # 不输出单高斯

# IP-323 IRL：身份-角色台账 + 证据独立性图 + n_eff
class IRL:
    def bind(self, r, tracks):
        s = [assoc_score(r, t) for t in tracks]            # 外观+几何+触觉+运动
        k = argmax(s)
        if softmax(s)[k] < C_ID_MIN: return None
        return IDBinding(tracks[k].id, tracks[k].role, conf=softmax(s)[k])
    def independence_graph(self, receipts, delta_pose):
        G = nx.Graph(); G.add_nodes_from(receipts)
        for ri, rj in combinations(receipts, 2):
            if same_id(ri, rj) or d_se3(ri.pose, rj.pose) < delta_pose:
                G.add_edge(ri, rj)
        return G
    def effective_n(self, receipts):
        groups = group_by_identity(receipts)
        if not rho_hat: return len(groups)               # 默认 ρ=1 的最坏下界
        de = 1 + (mean(len(g) for g in groups) - 1) * rho_hat
        return len(receipts) / de

# IP-324 PoseGraph：回路一致性与固定顺序分诊
class PoseGraph:
```

## 3. 推导

**引理 51（伪重复下的有效样本量与覆盖塌缩）** 设 n 条回执分为 G 个身份簇、簇内相关 ρ_ICC，
设计效应 DE = 1 + (n̄_g − 1)ρ_ICC，则均值估计方差膨胀 DE 倍，n_eff = n/DE。
若误用 n 而报名义 1−α 区间，实际覆盖仅为 2Φ(z_{1−α/2}/√DE) − 1：
例如 DE=4 时名义 95% 实际 ≈ 67%，名义 99% 实际 ≈ 84%。
证明：聚类高斯的可交换相关结构使样本均值方差 = σ²·DE/n；区间半宽按 √(n_eff) 应放大 √DE；
对固定半宽，覆盖退化为 z/√DE 处的正态质量。
**系 51.1**：ToolGauge 的「n ≥ n_min」若不换成 n_eff，等价于在 DE>1 时系统性高估置信度；
默认 ρ=1 时 n_eff 退化为身份簇数，是最保守且无需估计 ρ 的安全下界。

**引理 52（对称别名的不可辨识下界）** 若似然与先验在有限对称群 G（|G|=m）下不变且作用自由，
则后验在轨道上均匀，任何点估计器的模式错误概率 ≥ 1 − 1/m；别名熵 H(A) = log m。
对二重对称（m=2）点契约至少 50% 概率选错模式。只有**打破 G 不变性**的观测才能降低该风险：
若探测 z 使模式间似然比期望为 KL_min，则剩余别名熵满足 E[H(A|z)] ≤ log m − KL_min。
证明：后验 G-不变 ⇒ 任意可测估计器在轨道上取常值，0-1 风险最小为 1−1/m；信息增益由 KL 链式法则给出。
**系 52.1**：这解释了为什么「加采样」对对称物体无效——增加的是同模式内的样本，不是模式间的证据；
必须用 texture.gradient / tactile.contact / motion.parallax 这类**破对称**工具。

**引理 53（位姿不确定性的保守传播与风险门不可伪安全）** 设 g 为 L_g-Lipschitz，ξ ~ 𝒩(ξ̂, Σ_ξ)。
一阶传播 Σ_y = σ_meas²I + J_gΣ_ξJ_gᵀ；且以概率 ≥ 1−δ，
|g(ξ) − g(ξ̂)| ≤ L_g·√(λ_max(Σ_ξ))·√(2 log(1/δ))。
若契约漏报该姿态项，则 σ_decl 被低估 ≥ σ_pose，风险门
λ = σ_pred − σ_decl 被高估 ≥ σ_pose，存在被 λ 放行的不安全探测；
把 σ_decl 替换为传播上界后，λ 重新成为安全裕度的下界。
证明：Lipschitz 复合 + 高斯向量范数的 sub-Gaussian 集中；风险门单调性直接推出。

**引理 54（分层共形与姿态层同时覆盖）** 在每层 P_j 内可交换且 n_j ≥ n_min 时，
split conformal 给出 P(h*∈H_s | s∈P_j) ≥ 1−α_j。跨 T 层若要求同时覆盖 1−α，
取 α_j = α/T（Bonferroni）即可；自适应 learn-then-test 可在层难度不均时收窄平均集合。
若某层 n_j < n_min，分层池化只允许借用**相邻层**并保持单调覆盖，否则该层必须标 UNKNOWN。
证明：层内标准 split conformal + 并集界；池化单调性由加权分位数的保守性给出。
**系 54.1**：边际共形可能总体 95% 而掠射角层只有 60%；定义 443 把「姿态尾部」变成一等 SLA。

**引理 55（身份/位姿分离下交叉验证才有效）** 设 V 阶段用独立回执算 z = (μ_ind − μ̂)/√(Σ̂+σ_ind²)。
若校准与验证回执身份相异且位姿分离（d_SE3 ≥ δ_pose），z 近似标准正态，
假通过率 ≤ 2(1−Φ(ε_cross))。若两者共享身份或位姿重叠产生相关 κρ，
则 Var(z) 至少放大 (1+κρ)，假通过率升至 ≤ 2(1−Φ(ε_cross/√(1+κρ)))，单调增于 ρ。
位姿相关按核 exp(−d_SE3/ℓ_corr) 衰减，故取 δ_pose ≥ ℓ_corr·log(1/ρ_max) 可把残余相关压到 ρ_max 以下。
证明：相关高斯差的方差展开；指数核的相关模型；σ 单调性。
**系 55.1**：ToolGauge 的「cross.modal 独立回执」若不检查身份与位姿，可能只是同一轨迹的相邻帧，
其假通过率远高于名义 α；TwinGauge 用证据图的独立集把这条假设变成可执行约束。

**引理 56（规范等变与作用域隔离下的热替换交换性）** 若 EC 规范等变（定义 435）且 U 只写
经 scope 授权的 u_fields/χ_R/claims，则对任意 T∈SE(3)，热替换与 T 作用交换：
T·(U(EC)) = U(T·EC)；子图数值等价性（引理 44/49）保持；不同实例的写集不相交时，
跨实例身份泄漏概率为 0。
证明：等变性与写集封闭性给出交换图；scope 不相交由定义 438 保证；claims 不在数值路径。

## 6. 本轮最大风险（一句话）

**一句话**：身份台账与位姿图本身会成为新的**单点相关失效源**——一次系统性重识别偏差或对称群误设，
会把本相关的证据错标为独立，使 n_eff 被高估、V 阶段的「身份相异 + 位姿分离」检查被伪通过，
于是系统比 ToolGauge **更自信地错**：修正相关性的机制反而制造了虚假的独立性。

**次级风险与缓解**：
1. **位姿图漂移/回环错误** → 固定分诊顺序（定义 440）+ 定期重锚 + 矛盾时先修关联再修契约；
2. **对称群误设**（漏掉反射/连续对称）→ 候选群集合并行检验 + 无法判定时只出保守包络；
3. **n_eff 过保守导致修复停滞** → 自适应 ρ_ICC 估计保留最坏下界，保守只影响修复不影响控制；
4. **姿态尾层校准样本不足** → 相邻层分层池化 + 不足即 UNKNOWN（定义 443/447）；
5. **重识别嵌入域漂移** → 外观/几何/触觉/运动多线索 + 置信门 + 专用 re-ID 探测；
6. **身份/位姿欺骗攻击** → 签名来源 + 位姿图一致性 + 角色状态机三重校验（E453）；
7. **计算与内存增长** → 50Hz 路径仅哈希与传播；位姿图/图匹配全部异步、稀疏触发。

## 2. 形式化定义（要点）

**定义 432（P-Box）** 状态空间 ℳ=SE(3)×𝒜；格子 s=(b,U,a)；有效覆盖 C(s;ρ)=位姿后验加权覆盖，

**定义 433（CRLB 粗粒化）** 以 Fisher 信息给出位姿分辨率 λ_pose，小于该尺度的覆盖不计数。
**定义 434（别名集）** A(o)={g·ξ̂}，模式权重 π_m；|A|>1 时禁止单高斯，必须混合或保守包络。
**定义 435（规范等变）** EC(T·x)=ρ(T)·EC(x)；等变测试是热替换前置条件。
**定义 436（IRL）** 每条回执经外观/几何/触觉/运动绑定到 (id, τ, role)，置信 ≥ c_id_min 才入实例统计。
**定义 437（证据独立性）** G_E 连边 = 同身份或位姿距离 < δ_pose 或同采集批；
校准/验证只用独立集；n_eff = n/(1+(n̄_g−1)ρ_ICC)，默认 ρ=1 ⇒ n_eff=身份簇数。
**定义 438（作用域）** 实例/类别/全局参数写集必须落在授权 scope；类别参数需 ≥K 个不同实例，否则拒写。
**定义 439（SNIC）** 同 id 的角色与位姿归一化描述子必须一致；翻转/越界进入分诊，不得直接写契约。
**定义 440（位姿图）** 回环残差 χ²_gate；矛盾按「关联错→别名→真盲区」固定顺序分诊。
**定义 441（破对称探测）** T₀′=T₀∪{texture.gradient, tactile.contact, motion.parallax}；
增益注 β_t=Ĝ_var+λ_alias·Ĝ_alias−c_t。
**定义 442（位姿传播）** 回执新增 pose_cov；σ_decl 取一阶传播上界；缺失时用 Lipschitz 兜底。
**定义 443（分层共形）** 姿态层内独立校准；跨层 Bonferroni 或 learn-then-test；样本不足则池化或 UNKNOWN。
**定义 444（Twin-8C）** H→B→C→E→G→C→V→U；V 同时检查独立证据、位姿分离与等变。
**定义 445（PIP-Contract）** 在 TB-Contract 上增加 B_pose、δ_pose、n_eff_min、c_id_min、χ²_gate。
**定义 446（RepairCert′）** 证书携带回执、身份绑定、位姿图补丁、别名集、n_eff、等变报告与文字解说。
**定义 447（声明式退化）** 任一前置不满足 ⇒ 显式 ρ=1/σ 膨胀/UNKNOWN/stub+RED；绝不静默假设独立。
**定义 448（角色状态机）** 角色只能按预注册 Δ_role 迁移；未声明翻转是矛盾证据。
**定义 449（退化特例）** 平凡对称群、位姿精确、实例互异、无回环 ⇒ TwinGauge≡ToolGauge；继续退化到 LeanGauge/MODGAUGE。

## 3. 关键算法骨架

```python
@dataclass
class PoseReceipt(Receipt):
    pose: SE3
    pose_cov: np.ndarray | None
    id_binding: "IDBinding | None"
    alias_set: "AliasSet | None"

class PBox:                                   # IP-321
    def blind_spots(self, R, rho, crlb):
        for b in R.blind_cells():
            for U, mass in pose_patches(b, rho, res=crlb_resolution(b, crlb)):
                if mass >= MASS_MIN and (fiber_cov(b,U,rho) < 1-EPS_COV
                                         or tail_cov(b,U,rho) < 1-EPS_TAIL):
                    yield BlindSpot(b, U, appearance_mode(b))
    def update(self, s, q_u): self.fiber[s] = mix_on_fiber(self.fiber[s], q_u)

class AliasSet:                               # IP-322
    def infer(self, obs, xi_hat, sym_groups):
        g = select_group(obs, sym_groups)
        modes = [gi * xi_hat for gi in g]
        w = softmax([loglik(obs, m) for m in modes])
        return AliasSet(modes, w, H=entropy(w))
    def contract(self, a):
        return (GaussianContract(a.modes[0]) if len(a.modes) == 1
                else EnvelopeContract(a.modes, a.spread + max_sigma))

class IRL:                                    # IP-323
    def bind(self, r, tracks):
        s = [assoc_score(r, t) for t in tracks]
        k = argmax(s)
        return None if softmax(s)[k] < C_ID_MIN else IDBinding(tracks[k].id, tracks[k].role)
    def independence_graph(self, receipts, delta_pose):
        G = nx.Graph(); G.add_nodes_from(receipts)
        for ri, rj in combinations(receipts, 2):
            if same_id(ri, rj) or d_se3(ri.pose, rj.pose) < delta_pose:
                G.add_edge(ri, rj)
        return G
    def effective_n(self, receipts):
        groups = group_by_identity(receipts)
        if not rho_hat: return len(groups)             # 最坏相关下界
        de = 1 + (mean(len(g) for g in groups) - 1) * rho_hat
        return len(receipts) / de

class PoseGraph:                              # IP-324
    def update(self, receipts):
        for r in receipts: self.add_node(r.pose); self.add_edges(r.rel_obs)
        for l in self.detect_loops():
            if chi2(l) > CHI2_GATE: return triage(l)
        return "consistent"

def twingauge_8c(M, s):                       # IP-325
    H, A = M.lbox.hypothesize(s, M.pbox.fiber[s])                    # H
    prog = M.tbox.plan(H, A, M.tools, M.pip.budget_left(s))          # C
    R = M.tcv.execute(prog, M.env)                                   # E（PROBING）
    B = [M.irl.bind(r, M.tracks) for r in R]                         # B
    if any(b is None for b in B):
        R = M.tcv.execute(M.tbox.reid_probe(), M.env); B = re_bind(R)
    g = M.pgraph.update(R)                                           # G
    if g != "consistent": return handle_triage(M, s, g)
    n_eff = M.irl.effective_n(R)
    if n_eff < M.pip.n_eff_min: return stub_and_red(s, "n_eff_low")
    R = [propagate_pose_cov(r) for r in R]                           # 定义 442
    mu, Sig = M.apcal.calibrate(R, H, s, n_eff=n_eff)                # C
    indep = independent_set(M.irl.independence_graph(R, M.pip.delta_pose))
    if len(indep) < 2: return stub_and_red(s, "no_independent_evidence")
    if not M.apcal.cross_validate(mu, Sig, indep, A):                # V
        return stub_and_red(s, "cross_failed")
    if not equivariance_test(M.dpe, M.pip.eps_eq):
        return stub_and_red(s, "gauge")
    new_ec = M.apcal.update_contract_scoped(M.dpe, mu, Sig, s, B)    # U
    if not contract_regression(new_ec): return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec); M.pbox.update(s, mu, Sig)
    bind_certificate(new_ec, H, A, R, B, n_eff)
    return True

def TwinGauge_round(M, obs, audio, tac, depth, det):                 # IP-326
    for s in M.pbox.detect_blind_spot(M.rho):
        if s not in M.inflight:
            M.inflight.add(s); submit_async(twingauge_8c, M, s)
    if M.pip.exhausted(): M.degrade_to_toolgauge(declared_rho=1.0)
    return MODGAUGE_round(M, obs, audio, tac, depth, det)
```

## 4. 推导

**引理 51（伪重复）** DE = 1+(n̄_g−1)ρ_ICC，n_eff = n/DE。误用 n 时名义 1−α 区间实际覆盖
2Φ(z_{1−α/2}/√DE)−1：DE=4 时名义 95%→≈67%。默认 ρ=1 ⇒ n_eff=身份簇数。
**引理 52（对称别名）** 有限对称群 |G|=m、后验 G-不变 ⇒ 任一点估计器模式错误率 ≥1−1/m，H(A)=log m；
只有破对称探测以 KL 形式降低别名熵；加同模式样本无效。
**引理 53（位姿传播）** Σ_y=σ_meas²I+J_gΣ_ξJ_gᵀ；Lipschitz 集中给出 |g(ξ)−g(ξ̂)| ≤ L_g√λ_max(Σ_ξ)√(2log(1/δ))；
漏报使 λ 高估、风险门伪安全；替换为传播上界后恢复安全下界。
**引理 54（分层共形）** 层内 ≥1−α_j；跨 T 层 Bonferroni α_j=α/T 得同时覆盖；样本不足池化或 UNKNOWN；
系：边际 95% 可能掩盖掠射角层 60%。
**引理 55（交叉验证有效性）** 身份相异 + 位姿分离 ⇒ z≈N(0,1)，假通过 ≤2(1−Φ(ε))；
相关 κρ 使 Var(z) 放大 (1+κρ)，假通过 ≤2(1−Φ(ε/√(1+κρ)))；
取 δ_pose ≥ ℓ_corr·log(1/ρ_max) 控制残余相关。
**引理 56（等变交换性）** 规范等变 + scope 写集隔离 ⇒ 热替换与 SE(3) 变换交换，子图数值等价性保持，
实例写集不相交 ⇒ 身份泄漏概率 0。

## 7. 与 ToolGauge 的差异与继承

- **继承**：MODGAUGE 五不变式、6C→8C 的骨架、MTC/TCV、双层下注、MP-Φ/AP-Cal、TB-Contract、严格退化链、
  claims 绑定与语言证书、50Hz 硬实时隔离。
- **修复**：
  1. V 阶段独立性 → 证据图独立集 + 身份相异 + 位姿分离（定义 437/444，引理 55）；
  2. n_min 用原始 n → n_eff 聚类设计效应，默认 ρ=1（定义 437，引理 51）；
  3. 平坦覆盖 → P-Box 位姿纤维化 + CRLB 粗粒化（定义 432/433）；
  4. σ_decl 漏位姿 → 协方差传播 + Lipschitz 兜底（定义 442，引理 53）；
  5. 单模态契约 → 别名集 + 混合/包络（定义 434，引理 52）；
  6. 边际共形 → 分层共形 + 同时覆盖（定义 443，引理 54）；
  7. 热替换身份泄漏 → scope 契约 + 证据谱系（定义 438/446）；
  8. 角色翻转无约束 → SNIC + 角色状态机（定义 439/448）；
  9. 无坐标系等变检查 → 等变测试作为替换前置（定义 435，引理 56）；
  10. 证书缺证据相关性 → RepairCert′ 记录身份/位姿谱系与 n_eff（定义 446）。
- **新增**：P-Box、AliasSet、IRL、PoseGraph、PIP-Contract、声明式退化、破对称工具。

## 8. 本轮最大风险

**一句话**：身份台账与位姿图是新的单点相关失效源——一次系统性重识别偏差或对称群误设，
会把相关证据错标为独立，使 n_eff 被高估、V 阶段检查被伪通过，系统比 ToolGauge 更自信地错；
以 E443/E449/E451/E453/E455 证伪，以「声明式退化 + 独立集 + 固定分诊顺序」三重兜底。
