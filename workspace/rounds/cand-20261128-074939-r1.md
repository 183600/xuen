### 第 7 轮灵感驱动研究记录

**灵感词**：多机评测、行为克隆

**继承关系**：第 6 轮 CADVS-v6（IP-497~500）在七硬门 fail-closed 边界不变的前提下，用 GGC/MCTM/STM 三个「凿」把提议约束到物理可行、空间连通、语义可解释的亚族，并以软因子链 η_g·η_topo·η_interp·η_cmd 只收紧不放松。本轮延续「硬门不增、软因子只收紧」纪律，聚焦「**演示先验与机群校准**」：行为克隆为流提议提供专家先验（提升效率），多机评测为这份先验提供总体可靠性校准（约束可信度），二者相乘决定软收紧的力度。

**直觉与动机**：

1. **行为克隆 → 从「可行域随机探索」到「专家流形锚点」**。v6 的 FMPP 即使加了 GGC/MCTM/STM，仍在可行域内做随机采样，样本效率低、易生成非专家风格动作。行为克隆（BC）从人类遥操作演示中学到策略 π_BC，其均值动作 a_BC 可把流提议「拉」到专家流形附近。**关键洞见**：BC 不做执行者，只做提议的「锚点」——它把 K=8 个候选从「全空间撒点」变成「专家邻域撒点」，用更少流步数达到同样接受率；能否执行仍由七硬门决定。

2. **BC 的死穴是协变量偏移 → 用集成不确定性在线量化**。BC 经典失败模式是：一旦离开演示状态分布，误差按 O(T²) 复合放大。与其相信单条 BC，不如训练 M 条不同初始化的 BC 集成；集成分歧 u_bc(s) 与到演示状态集的距离 d_bc(s) 共同刻画「当前状态是否仍在专家支持集内」。**关键洞见**：把「BC 是否可信」变成可在线计算的标量支持度 r_bc(s) ∈ (0,1]，再映射为只收紧的软因子 η_bc = 1 + (1−r_bc)·κ_bc——不确定时更保守，而非更冒险。

3. **多机评测 → 从「单机证书」到「总体证书」**。v6 的所有保证都是单机的：在某一台机器人上，七硬门对每条轨迹给出证书。但真实部署是异构机群（负载、摩擦、标定、磨损各异），BC 在一台机器上学到的演示换一台可能因动力学差异而失效。引入多机评测（MME）：在 N 台机器上做总体评测，用 Clopper–Pearson 下置信界给出「总体通过率 ≥ ρ_mme」的统计保证，并映射为只收紧的 η_mme = 1 + (1−ρ_mme)·κ_mme。**关键洞见**：MME 不是新硬门，而是对软因子先验的「可信度校准」——机群越不一致，η_mme 越大，阈值越严，执行集越小。

**关键洞见总述**：v6 回答「如何让提议符合物理/空间/意图」；v7 回答「当提议来自演示先验时，如何在机群层面保持 fail-closed」。七硬门 kc_evidence_forged_v5 记号与 v6 软链原样复用；本轮新增的只有：
- IP-501 BCPK（行为克隆集成先验 + 支持因子 η_bc），
- IP-502 MMEK（多机总体证书 + 稳健因子 η_mme），
- IP-503 DPM（演示溯源记忆 + 跨机一致性筛选），
- IP-504 EFA-v7（软评分 η_bc·η_mme）。

**形式化目标（增量）**：

1. **BCPK（Behavior-Cloning Prior Kernel）**：<br>
   - 演示集 D_m = {(s_t^m, a_t^m)}，BC 集成 {π_BC^(k)}_{k=1}^M，M=5，各自最小化 L_BC^(k) = −E_{D_m} log π_BC^(k)(a|s) + λ_reg‖θ_k‖²<br>
   - 先验动作 a_BC(s) = (1/M)Σ_k π_BC^(k)(s)；认知不确定性 u_bc(s) = (1/M)Σ_k ‖π_BC^(k)(s) − a_BC(s)‖²<br>
   - 支持距离 d_bc(s) = 到演示状态集 D_m 的 kNN 距离；支持度 r_bc(s) = σ(−d_bc/σ_b)·exp(−λ_u·u_bc) ∈ (0,1]<br>
   - 软因子 η_bc(s) = 1 + (1−r_bc(s))·κ_bc，κ_bc=0.1（只收紧，η_bc ∈ [1,1.1]）<br>
   - FMPP 条件扩展：a_BC 仅作 proposal anchor（均值偏移/热启动），不扩大采样支持

2. **MMEK（Multi-Machine Evaluation Kernel）**：<br>
   - 机群 M = {m_1,…,m_N}，每机 E 个评测回合，门通过指示 X_{m,i} ∈ {0,1}；单机通过率 p̂_m = (1/E)Σ_e ∧_i X_{m,e,i}<br>
   - 总体通过率下置信界 ρ_mme = LCB_{1−δ}(p̂_1,…,p̂_N)（Clopper–Pearson / 自助法）<br>
   - 跨机迁移矩阵 T_{ij} = BC 在 m_i 训练、在 m_j 评测的成功率；跨机一致性 C = min_{i≠j} T_{ij}/T_{ii}<br>
   - 软因子 η_mme = 1 + (1−ρ_mme)·κ_mme，κ_mme=0.2（η_mme ∈ [1,1.2]）<br>
   - 离线部署门：ρ_mme ≥ 1−δ_target 且 C ≥ θ_transfer 才允许签名下发；否则回退 v6

3. **DPM（Demonstration Provenance Memory）**：<br>
   - 记忆条目拓展 e_τ = (emb_traj, label_grasp, η_safety, src, prov)，prov = (machine_id, demo_id, cross_agree)<br>
   - cross_agree = 该演示在跨机迁移矩阵下的一致性分（同簇演示的成功迁移比例）<br>
   - 检索时过滤 cross_agree ≥ θ_agree（默认 0.6），避免把单机特化演示当作通用先验

4. **EFA-v7 软评分**：ECS_v7 = ECS_v6 · η_bc · η_mme；τ_i^v7 = γ_i·τ_i^v5·Π_factor_i^v6·η_bc_i·η_mme_i；设计上限 Π_factor_i^v7 ≤ 1.5；任一因子 < 1（检测到误判）立即回退 v5 规则提议。

5. **形式化定义**：给定指令 L、目标 ρ_target、记忆 M、机器 m：<br>
   - q_L = STM(L)；m_topk = Top-k(Retr_M(q_L, K=4) s.t. cross_agree ≥ θ_agree)；<br>
   - a_BC = BCPK.prior(s_0)；r_bc = BCPK.support(s_0)；η_bc = 1+(1−r_bc)·κ_bc；<br>
   - c_ctx = (obj, g_emb, θ_fp, task, ŝ_emo, m_{1:k}, ρ_target, t_topo, q_L, a_BC)；<br>
   - cands = FMPP.propose(c_ctx, anchor=a_BC, K=8)；<br>
   - surv = [x ∈ cands : GGC(x) ∧ MCTM(x) ∧ ¬Ψ_novel(x)]；<br>
   - Exec_CADVS-v7 = {x ∈ surv : ∧_i kc_i(x,c; τ_i^v7)=1}。

**本轮最大风险**：多机评测的总体证书依赖机器间可交换性（i.i.d.）假设，而真实机群异质且相关；BC 的演示偏差与机群异质性耦合后，可能让系统在「总体统计上合规」的同时，在具体部署机上出现未被评测覆盖的失效模式——把评测覆盖面误当作安全边界。

## 2. 关键算法骨架

### IP-501 BCPK：行为克隆集成先验

```python
@dataclass
class BehaviorCloningPriorKernel:
    """BCPK：BC 集成只做提议锚点，不执行；支持因子只收紧。
    红线：BC 不直接产生可执行动作，所有候选仍须过七硬门。"""
    ensemble: list[BCPolicy]        # M=5 条不同初始化/数据顺序
    demo_states: torch.Tensor       # D_m 的状态集（kNN 用）
    kappa_bc: float = 0.1
    sigma_b: float = 0.5
    lambda_u: float = 0.5

    def prior(self, s) -> torch.Tensor:
        """集成均值动作 → FMPP 热启动锚点"""
        return torch.stack([p(s) for p in self.ensemble]).mean(0)

    def epistemic(self, s) -> float:
        """集成分歧：方差越大越不可信"""
        acts = torch.stack([p(s) for p in self.ensemble])
        return acts.var(0).mean().item()

    def support(self, s) -> float:
        """支持度 r_bc：离演示越远 / 分歧越大 → 越低"""
        d = knn_distance(s, self.demo_states, k=1)
        u = self.epistemic(s)
        return sigmoid(-d / self.sigma_b) * math.exp(-self.lambda_u * u)

    def factor(self, s) -> float:
        """η_bc = 1 + (1−r_bc)·κ_bc ∈ [1, 1+κ_bc]，只收紧"""
        r = self.support(s)
        return 1.0 + (1.0 - r) * self.kappa_bc
```

### IP-502 MMEK：多机总体评测

```python
@dataclass
class MultiMachineEvaluationKernel:
    """MMEK：离线机群评测 → 总体证书与跨机一致性 → 只收紧的 η_mme。
    红线：MME 是校准器而非硬门；未过部署门则回退 v6。"""
    n_machines: int
    episodes_per_machine: int
    delta: float = 0.05
    kappa_mme: float = 0.2
    theta_transfer: float = 0.6

    def population_lcb(self, pass_rates: list[float]) -> float:
        """机群总体通过率的下置信界（Clopper–Pearson / 自助法）"""
        return clopper_pearson_lcb(pass_rates, self.delta)

    def transfer_consistency(self, T: np.ndarray) -> float:
        """跨机迁移一致性 C = min_{i≠j} T_ij / T_ii"""
        diag = np.diag(T)
        mask = ~np.eye(len(T), dtype=bool)
        rel = T[mask] / np.repeat(diag, len(T) - 1)
        return float(rel.min())

    def factor(self, pass_rates: list[float]) -> float:
        """η_mme = 1 + (1−ρ_mme)·κ_mme ∈ [1, 1+κ_mme]，只收紧"""
        rho = self.population_lcb(pass_rates)
        return 1.0 + (1.0 - rho) * self.kappa_mme

    def deploy_gate(self, pass_rates: list[float], T: np.ndarray) -> bool:
        """离线签名门：总体通过率与跨机一致性双达标"""
        return (self.population_lcb(pass_rates) >= 1.0 - self.delta
                and self.transfer_consistency(T) >= self.theta_transfer)
```

### IP-503 DPM：演示溯源记忆

```python
@dataclass
class DemonstrationProvenanceMemory:
    """DPM：为记忆条目附加演示溯源与跨机一致性，检索时过滤单机特化先验。"""
    store: list[MemoryEntry]        # e_τ 含 prov
    theta_agree: float = 0.6

    def retrieve(self, q, k: int = 4) -> list[MemoryEntry]:
        cands = topk_by_similarity(q, self.store, k=4 * k)
        # 先按跨机一致性过滤，再取前 k，避免单机特化演示污染通用先验
        return [e for e in cands if e.prov.cross_agree >= self.theta_agree][:k]

    def cross_agree(self, demo_id: int, T: np.ndarray) -> float:
        """同簇演示的跨机成功迁移比例 → prov.cross_agree"""
        return float(T[:, demo_id].mean())
```

### IP-504 EFA-v7：七硬门 + BC/MME 软链

```python
@dataclass
class EvidenceForgingAssemblerV7:
    """EFA-v7：七硬门不变 + 软链 η_bc·η_mme（叠加在 v6 软链之上）。"""
    v6: EvidenceForgingAssemblerV6
    bcpk: BehaviorCloningPriorKernel
    mme: MultiMachineEvaluationKernel
    dpm: DemonstrationProvenanceMemory
    eta_mme: float = 1.0            # 离线由 MMEK 校准后注入
    kappa_cap: float = 1.5          # Π_factor_i^v7 上限

    def select(self, L, t_now, context):
        # 1. v6 语义/拓扑/几何流程（省略），BC 锚点接入 FMPP
        s_emo = self.v6.famk.observe(context.face, t_now)
        gamma = self.v6.famk.gamma(s_emo)

        a_BC = self.bcpk.prior(context.s0)
        eta_bc = self.bcpk.factor(context.s0)           # ∈ [1,1.1]
        if L is not None:
            q_L = self.v6.stm.forward(L)
            m_topk = self.dpm.retrieve(q_L, k=4)
        else:
            q_L, m_topk = None, self.v6.lmem.query(context)

        t_topo = self.v6.mctm.token(context.pose)
        eta_topo = self.v6.mctm.query(context.pose)

        c = build_ctx(context, s_emo, m_topk, t_topo, q_L, a_BC)
        cands = self.v6.fmpp.propose(c, anchor=a_BC, K=8)

        eta_total = eta_bc * self.eta_mme
        if eta_total > self.kappa_cap:
            eta_total = self.kappa_cap
        surv = [x for x in cands
                if self.v6.ggc.filter(x) and not psi_novel(x)]

        # 2. 七硬门：阈值在 v6 基础上乘 η_bc·η_mme（只收紧）
        finals = []
        for x in surv:
            if self.v6.v5.hard_gates_pass(x, c, gamma, factor=eta_total):
                finals.append(x)
        if not finals:
            return self.v6._fallback_rule_proposal(gamma)
        best = max(finals, key=self.v6._margin)
        return True, best, 'FORGED_CGE_V7'

    def ecs_v7(self, x, n_flow, s_emo, eta_factors) -> float:
        """ECS_v7 = ECS_v6 · η_bc · η_mme"""
        return self.v6.ecs_v6(x, n_flow, s_emo, eta_factors) \
               * eta_factors['bc'] * eta_factors['mme']
```

### 集成流水线（v6 → v7）

```
离线/慢时域：
  BC 训练（小时级）：每机 200 条遥操作演示 → M=5 集成（不同 seed/数据顺序）
  MME 评测（小时级）：N=10 台异构机器 × E=50 回合 → p̂_m, T_ij, ρ_mme, C
  部署门：ρ_mme ≥ 1−δ_target 且 C ≥ θ_transfer → 签名下发；否则回退 v6
  联邦下发：BC 集成权重、demo_states、η_mme、θ_agree → 站内签名分发

在线准入（异步，秒级）：
  BCPK.prior(s0) ──▶ a_BC（FMPP 热启动）
  BCPK.support(s0) ──▶ r_bc → η_bc
  DPM.retrieve(q_L) ──▶ 跨机一致性过滤后的 m_topk
  FMPP.propose(c, anchor=a_BC) ──▶ K=8 候选
       ├─ 全灭 ──▶ fail-closed 回退 v5 规则提议
       └─ 幸存 ≤3 ──▶ 七硬门（τ·η_bc·η_mme）──▶ 取边际最大者

在线控制环（目标 < 0.6 ms）：
  EFA-v7 只消费预计算的 η_bc/η_mme；BC 前向在准入时域（~1 ms NPU），不进控制环
```

| BCPK.support | O(log |D_m|) kNN | O(|D_m|) | |D_m|=200 | < 0.1 ms |
| MMEK（离线） | O(N·E·T) | O(N·E) | N=10, E=50 | 小时级 |
| DPM.retrieve | O(log |store|) 近似 | O(|store|) | |store|~10^5 | < 0.5 ms |
| EFA-v7 软因子链 | O(1) | O(1) | — | < 0.05 ms |

**端到端在线增量**：BC 前向与 DPM 检索在准入时域完成，控制环只消费预计算标量；七硬门 O(1)。总 P99 维持 v6 的 ≈0.6 ms。

## 4. 正确性论证（增量更新）

### 定理 11（Fail-closed 保持 / 软因子单调收紧）

**陈述**：设 η_bc, η_mme ∈ [1, 1+κ]，κ>0。则 τ_i^v7 = τ_i^v6·η_bc·η_mme ≥ τ_i^v6，故 Exec_CADVS-v7 ⊆ Exec_CADVS-v6 ⊆ Exec_CADVS-v5。当 r_bc=1 且 ρ_mme=1 时 η_bc=η_mme=1，恢复 v6。

**证明**：η_bc=1+(1−r_bc)κ_bc ≥ 1，η_mme=1+(1−ρ_mme)κ_mme ≥ 1，故乘积 ≥1，软阈值单调升；七硬门判定 1[s_i ≥ τ] 在 τ 增大时结果不变或更严格（单调性），执行集只缩不扩。因子取 1 时 τ_i^v7=τ_i^v6，逐项恢复 v6。

### 定理 12（总体证书可靠性）

**陈述**：设机群从机器分布 P_M 中可交换抽样、每机 E 个 i.i.d. 评测回合，p̂_m 为单机门通过率。则 Clopper–Pearson 下界 ρ_mme 满足 P(Cert_pop ≥ ρ_mme) ≥ 1−δ，其中 Cert_pop = E_{m~P_M}[pass rate]。若 ρ_mme ≥ 1−δ_target，则以置信度 1−δ 断言机群总体 fail-closed 通过率 ≥ 1−δ_target。

**证明**：将 N·E 个回合视为混合总体的 i.i.d. 样本（可交换性下可按机器加权），Clopper–Pearson 区间对二项比例具有 ≥1−δ 覆盖；下界即证书。若机器分层不可交换，改用分层权重 w_m 与 Bonferroni 校正（每层 δ/N），保守性更强。

### 定理 13（BC 复合误差被硬门截断）

**陈述**：设 BC 在演示支持集内单步误差 ≤ ε，单步离开支持集概率 δ_s，硬门对支持集外动作的拒绝率为 q，单步最大代价 Δ_max。则执行轨迹的累积代价满足 J(π_exec) ≤ J(π*) + T·ε + T·(1−q)·δ_s·Δ_max。

**证明**（归纳）：每步若在支持集内，误差 ≤ ε；若离开支持集，以概率 q 被硬门拒绝并回退（代价 0 的规则动作），以概率 1−q 未被拒绝、代价 ≤ Δ_max。对 T 步求和，得到线性于 T 的项，而非纯 BC 的 O(T²ε) 二次复合。代价是 q 未覆盖的残余风险 T(1−q)δ_sΔ_max。

### 诚实声明

- **可交换性是强假设**：真实机群存在相关性与分层（同批次、同工况），Clopper–Pearson 下界可能过于乐观；分层抽样 + Bonferroni 只能缓解，无法根除相关机群带来的偏差。
- **BC 演示偏差不可由支持度检测**：η_bc 只度量「离演示多远」，无法识别「演示本身有偏/错误」；专家风格偏差会被忠实放大。
- **集成不确定性可能被系统性低估**：所有成员共享同一数据偏差时 u_bc 偏小，r_bc 虚高，导致 η_bc 过松。
- **MME 样本成本**：δ_target 越严、机器越异质，所需 N·E 越大；序贯检验（SPRT）可降成本但增加实现复杂度。
- **软因子乘积仍可能塌缩**：Π_factor_i^v7 上限 1.5，若多因子误判同时偏大，执行集会过度收缩（与 v6 R58 同类），需 κ 上限与人工抽检兜底。

## 7. 本轮最大风险（最终确认）

**一句话**：**多机评测的总体证书依赖机器间可交换性（i.i.d.）假设，而真实机群异质且相关；BC 的演示偏差与机群异质性耦合后，可能让系统在「总体统计上合规」的同时，在具体部署机上出现未被评测覆盖的失效模式——把评测覆盖面误当作安全边界。**
