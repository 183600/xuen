### 第 1 轮灵感驱动研究记录（承接 v29）

**灵感词**：消融实验、创新点

**直觉与动机**：

v29 已经堆到十二张证书（v28 九证 + VAC/DGC/CCC），每个模块单独看都「有道理」。但「有道理」和「有用」是两件事。一个不断做加法的系统最危险的错觉，是把「组件存在」当成「组件贡献」。消融实验（ablation）正是拆开这个捆绑包的手术刀：把某张证书短路为恒真（最大放行）、强制拒绝、替换为教师输出、或打乱标签重训，观察安全、实时性、成功率这些指标是否真的变化。若移除某证书后指标几乎不动，它要么是**冗余**的（总和另一张证书同时满足），要么是**装饰**的（在评测分布上从不触发），要么甚至**有害**（只增加误拒与延迟却不换来安全）。

于是重新定义「创新点」：创新点不是「我新增了模块 X」，而是「移除 X 会造成一个**预先指定**的安全指标发生**统计显著且不可被其他模块补偿**的退化」。前者是叙事，后者是可证伪的因果声明。本轮把消融从「论文末尾的一张表」提升为一等公民——一个可计算、带置信区间、跨分布稳定的**创新必要性证书（Innovation Necessity Certificate, INC）**。它不只回答「哪些模块有用」，还主动回答「哪些模块可以删」：删不掉的才配叫创新点。

**严谨定义**：

1. **消融干预算子族**。设证书集合 C = {C_1,…,C_n}（本轮 n = 12），门 G: S→{0,1} 由证书按合取与路径选择组成。对任意子集 A ⊆ C，记 G_A 为「仅 A 中证书生效、其余按指定方式消融」的门。消融算子：
   - A^del（删除/短路）：被消融证书恒真，即最大放行；
   - A^rej（强制拒绝）：被消融证书恒假，保守路由到教师；
   - A^T（教师替换）：用教师对应模块的输出替换该证书判据；
   - A^scr（标签打乱重训）：保留结构与算力、破坏信息，用于分离「算力贡献」与「信息贡献」。
   基线与全集分别为 G_∅（全放行）与 G_C（v29 原门）。

2. **多目标效用**。V(G_A) = (1 − ε_cat) − λ_lat·L̂_p95(G_A) − λ_fr·FR(G_A)，其中 ε_cat 为灾难违规率，L̂_p95 为归一化 p95 延迟，FR 为误拒/教师升级率。安全项与成本项显式分离，防止「越保守越安全」把门退化成全拒绝。

3. **Shapley 贡献与置信区间**。φ_i = Σ_{A⊆C\{i}} [|A|!(n−|A|−1)!/n!]·(V(G_{A∪{i}}) − V(G_A))。φ_i 是证书 i 在所有联盟下的**平均边际贡献**，天然处理证书间交互与加入顺序。用随机排列采样无偏估计（O(m·n) 次门评估），bootstrap 给 95% CI。

4. **必要性 / 冗余性 / 拮抗性**。i **必要**：φ_i 的 CI 下界 > 0 且移除 i 使 ε_cat 上升 ≥ Δ_cat_min。i、j **冗余**：拒绝集 Jaccard J(R_i,R_j) ≥ τ_J 且 |φ_i − φ_j| 小。i **拮抗**：φ_i < 0（移除反而更好，通常由误拒或延迟主导）。

5. **创新点（形式化）**。模块 m 是本轮创新点 ⟺ 同时满足：
   (a) φ_m ≥ φ_min；
   (b) **不可替代性** I_m := min_{A⊆C\{m}} [V(G_{A∪{m}}) − V(G_A)] > 0（最不利联盟下仍为正贡献）；
   (c) **跨分布秩稳定**：在 K 个偏移环境上 φ 的 Spearman 秩相关 ρ_stab ≥ ρ_min。
   条件 (b) 排除「只在特定搭档存在时才有用」的伪创新，条件 (c) 排除「只在评测分布上耦合」的假阳性。

6. **有效证书数**。n_eff = (Σ_i φ_i⁺)² / Σ_i (φ_i⁺)²（参与率），衡量十二证里真正独立承重的有几个；n_eff ≪ n 即冗余的直接证据。

**关键洞见**：消融不是「证明我们做了很多」的展览，而是「证明哪些可以删」的审计。一个诚实的系统应主动寻找可被安全删除的证书——删不掉的才配叫创新点；删得掉的，早删比晚删好，因为每多一张证书就多一条共因失效路径和一份延迟预算。这把 v29 的「证书军备竞赛」反转为「证书极简主义」：以 n_eff 与不可替代性为目标，而非以证书数量为目标。

**形式化目标（增量）**：
1. 定义消融算子族与消融格（2^n 联盟，排列采样近似）。
2. 定义 INC 五元组：(φ_i, CI_i, I_m, ρ_stab, ROI_i = φ_i / cost_i)。
3. 证明 AND 单调性：纯安全度量下 φ_i ≥ 0，且 Σ_i φ_i = ε_cat(G_∅) − ε_cat(G_C)，即总安全增益被精确加性分解。
4. 证明装饰性证书 φ = 0、完全替代证书平分 φ，使「从不触发」与「彼此冗余」可被审计精确识别。
5. 实验目标：识别 ≤ 3 个真正不可替代的创新点，给出可安全删除的证书清单（若有），并把 n_eff 从名义 12 降到其真实值。

**本轮最大风险**：**消融归因的分布依赖与 Goodhart**——Shapley 必要性是在与训练/校准同源的评测分布上测得的，而各证书本就针对该分布协同设计；一旦部署分布偏移，必要性排序可能反转，于是 INC 会「认证」只在基准上承重、在尾部却无关的模块，同时误删真正保护尾部的模块；更糟的是，若以 φ_i 作为优化或保留目标，组件会通过彼此削弱来「制造」承重地位，让消融实验奖励人为耦合而非真实独立安全。

### IP-473 Ablation Intervention Operator Library (AIOL)

```python
class AblationInterventionLibrary:
    """把每张证书包装为可干预黑盒，统一构造 G_A。"""
    MODES = ("del", "rej", "teacher", "scramble")

    def wrap(self, cert_name, mode):
        if mode not in self.MODES:
            raise ValueError(mode)
        # del    : 判据恒真（放行）
        # rej    : 判据恒假（保守拒绝，路由教师）
        # teacher: 用教师同名模块输出替换该证书判据
        # scramble: 保留结构，用打乱标签重训后的副本替换（破坏信息、保留算力）
        return _CertShim(cert_name, mode)

    def build(self, gate, active: set, mode_map: dict):
        """返回仅 active 生效、其余按 mode_map 消融的门 G_A。"""
        shims = {c: self.wrap(c, mode_map.get(c, "del"))
                 for c in gate.certs if c not in active}
        return _AblatedGate(gate, active=set(active), shims=shims)
```

### IP-474 Shapley Causal Attribution Auditor (SCAA)

```python
@dataclass
class ShapleyCausalAttributionAuditor:
    n_perm: int = 2000
    n_boot: int = 500
    tau_j: float = 0.8

    def attribute(self, gate, env, utility_fn, certs):
        """排列采样 Shapley：无偏估计 φ_i，并保留每条排列的边际贡献用于 bootstrap。"""
        marginals = {c: [] for c in certs}          # 每行: 一次排列的全部边际
        for _ in range(self.n_perm):
            pi = random.sample(list(certs), len(certs))
            active, prev = set(), utility_fn(gate, set(), env)   # V(G_∅)
            row = {}
            for c in pi:
                active.add(c)
                cur = utility_fn(gate, set(active), env)
                row[c] = cur - prev
                prev = cur
            for c in certs:
                marginals[c].append(row[c])
        phi = {c: float(np.mean(v)) for c, v in marginals.items()}
        ci = {c: self._bootstrap_ci(v) for c, v in marginals.items()}
        return phi, ci, marginals

    def irreplaceability(self, gate, env, utility_fn, m, certs, n_sample=500):
        """I_m：随机抽联盟 A，取 V(G_{A∪{m}})−V(G_A) 的最小值（保守估计）。"""
        rest = [c for c in certs if c != m]
        vals = []
        for _ in range(n_sample):
            A = set(random.sample(rest, random.randint(0, len(rest))))
            vals.append(utility_fn(gate, A | {m}, env) - utility_fn(gate, A, env))
        return float(np.percentile(vals, 5))        # 5% 分位作为保守下界

    def interaction(self, gate, env, utility_fn, i, j, certs):
        """Shapley 交互指数 I_ij 的采样估计（正值=互补，负值=替代/冗余）。"""
        rest = [c for c in certs if c not in (i, j)]
        acc = []
        for _ in range(500):
            A = set(random.sample(rest, random.randint(0, len(rest))))
            d = (utility_fn(gate, A | {i, j}, env)
                 - utility_fn(gate, A | {i}, env)
                 - utility_fn(gate, A | {j}, env)
                 + utility_fn(gate, A, env))
            acc.append(d)
        return float(np.mean(acc))

    def redundancy(self, rejection_sets):
        """拒绝集 Jaccard 聚类：高重叠且 φ 接近者标为冗余。"""
        return {(i, j) for i in rejection_sets for j in rejection_sets
                if i < j
                and _jaccard(rejection_sets[i], rejection_sets[j]) >= self.tau_j}

    @staticmethod
    def effective_count(phi):
        pos = np.array([max(0.0, v) for v in phi.values()])
        return float(pos.sum() ** 2 / max((pos ** 2).sum(), 1e-12))
```

### IP-475 Ablation Protocol & Benchmark (APB)

```python
@dataclass
class AblationProtocolBenchmark:
    """预注册、配对、分阶段、带负对照的消融协议。"""
    envs: list                 # E_1..E_6
    n_scen: int = 2000
    seeds: int = 5
    metrics: tuple = ("eps_cat", "eps_viol", "success", "FR", "L_p95")
    delta_cat_min: float = 0.01
    rho_min: float = 0.7
    eps_budget: float = 0.005

    def run(self, gate, scaa, certs):
        # 0) 负对照自检：审计必须先能识别「零贡献」与「负贡献」
        ctrl = self._negative_controls(gate)
        assert abs(ctrl["null_phi"]) < 0.005, "随机证书未被判为 φ≈0，审计失效"
        assert ctrl["harm_phi"] < 0, "有害证书未被判为 φ<0，审计失效"

        # 1) 阶段 A：2^(12-5) 分辨度 IV 分数因子筛选主效应（128 次门评估）
        screen = self._fractional_factorial(gate, self.envs[0], resolution=4)

        # 2) 阶段 B：E_1..E_4 上排列采样 Shapley（每环境 N_perm=2000）
        per_env = {e.name: scaa.attribute(gate, e, self.utility_fn, certs)
                   for e in self.envs[:4]}

        # 3) 阶段 C：对候选创新点做 2^k 全因子交互（k≤6，≤64 次）
        shortlist = self._shortlist(per_env, screen)
        interactions = self._full_factorial(gate, self.envs[0], shortlist)

        # 4) 阶段 D：E_1..E_6 上跨分布秩稳定
        stab = self._rank_stability(per_env, self.envs)
        return per_env, interactions, stab, ctrl
```

**协议要点**：所有环境共用公共随机数（CRN）与同一批初始状态，做配对比较；多证书/多环境的多重比较用 Holm–Bonferroni 校正；评测指标与阈值在实验前冻结（预注册），禁止看到 φ 后改指标。

### IP-476 Innovation Necessity Certificate (INC)

```python
@dataclass
class InnovationNecessityCertificate:
    phi_min: float = 0.02
    rho_min: float = 0.7
    eps_budget: float = 0.005

    def evaluate(self, m, phi, ci, irr, rho_stab, cost):
        """输出 (decision, reason)；decision ∈ {keep, merge, demote, remove, unverified}"""
        if rho_stab < self.rho_min:
            return "unverified", "跨分布排序不稳定，禁止据此增删"
        if phi[m] < 0:
            return "remove", "φ<0：误拒/延迟主导，移除反而更优"
        if ci[m][0] <= 0:
            return "merge", "CI 下界≤0：与某证书冗余，合并而非保留"
        is_innov = (phi[m] >= self.phi_min and irr[m] > 0)
        return ("keep" if is_innov else "demote"), (
            "不可替代且跨分布稳定" if is_innov else "有贡献但可被替代，降级")

    def plan_removals(self, decisions, delta_cat):
        """消融安全预算 ASB：按 Δ_cat 从小到大删除，直到预算耗尽。"""
        chosen, spent = [], 0.0
        for m, d in sorted(delta_cat.items(), key=lambda kv: kv[1]):
            if decisions[m] in ("remove", "merge") and spent + d <= self.eps_budget:
                chosen.append(m); spent += d
        return chosen, spent
```

### IP-477 Cross-Distribution Stability Gate (CDSG)

```python
class CrossDistributionStabilityGate:
    """用秩相关检验 φ 的必要性排序是否只是基准分布上的耦合。"""
    def check(self, per_env_phi, certs, rho_min=0.7):
        ranks = {e: _rank([per_env_phi[e][c] for c in certs]) for e in per_env_phi}
        base = ranks[next(iter(ranks))]
        rho = {e: spearmanr(base, ranks[e]).correlation for e in ranks}
        return rho, all(v >= rho_min for v in rho.values())
```

## 3. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| AIOL 构造 G_A | O(n) | O(n) | n=12 |
| 排列采样 Shapley | O(N_perm·n·C_eval) | O(N_perm·n) | N_perm=2000，C_eval=一次门评估 |
| bootstrap CI | O(N_boot·N_perm) | O(N_perm) | N_boot=500 |
| 不可替代性 I_m | O(n_sample·n·C_eval) | O(n_sample) | n_sample=500 |
| 交互指数 I_ij | O(500·n·C_eval) 每对 | O(1) | 仅候选对 |
| 阶段 A 分数因子 | O(2^(n−5)·C_eval)=128·C_eval | O(1) | 分辨度 IV |
| 阶段 C 全因子 | O(2^k·C_eval)≤64·C_eval | O(1) | k≤6 |
| 跨环境稳定门 | O(K·n log n) | O(K·n) | K=6 |
| 全协议总评估 | ≈ (2000·12 + 128 + 64)·C_eval·4 环境 ≈ 1e5·C_eval | — | 全离线 |

**对照**：全联盟枚举需 2^12 = 4096 次/环境，且无法给 CI；排列采样以约 2.4e4 次/环境获得同等（更优）估计与置信区间，是本方案可落地的关键。

## 4. 正确性论证

### 定理 A（AND 门的 Shapley 非负与精确分解）

**陈述**：设门为纯合取组合，安全度量 M(G) = 1 − ε_cat(G) 对被准入集合单调不增（准入越少越安全）。则对任意 i，φ_i ≥ 0；且 Σ_i φ_i = M(G_C) − M(G_∅) = ε_cat(G_∅) − ε_cat(G_C)。

**证明**：对任意 A ⊆ C\{i}，G_{A∪{i}} ⊆ G_A（多一张证书只会更严），故 M(G_{A∪{i}}) ≥ M(G_A)，每条边际贡献非负，取平均得 φ_i ≥ 0。Shapley 效率公理给出 Σ_i φ_i = M(G_C) − M(G_∅)。∎

**工程含义**：总安全增益可被**精确加性分解**到各证书，不存在「无法归因的剩余」。若观测到 φ_i < 0，则要么度量被延迟/误拒项主导（多目标正常现象），要么门实现有 bug 或评测被游戏化——这是一个可自动触发的告警。

### 引理 A（装饰性证书的零贡献）

**陈述**：若证书 i 在评测分布上从不拒绝（判据恒真），则对任意 A，G_{A∪{i}} = G_A，故 φ_i = 0。

**证明**：所有边际贡献均为零，平均仍为零。∎

**工程含义**：审计无法被「证书存在但从不生效」欺骗；零 φ 是装饰性的精确指纹。

### 引理 B（完全替代证书的贡献平分）

**陈述**：若 i、j 完全可替代——对任意 A ⊆ C\{i,j} 有 G_{A∪{i}} = G_{A∪{j}} = G_{A∪{i,j}}——则 φ_i = φ_j，且 φ_i + φ_j 等于二者合并的边际价值。

**证明**：由对称性与 Shapley 的对称公理，二者在任意排列中的期望边际贡献相同；合并后新增的价值被两人平分。∎

**工程含义**：冗余不会增加总贡献，只会摊薄单张证书的 φ；因此 n_eff 与冗余聚类能同时捕获「证书很多但真正独立承重的很少」。

### 定理 B（消融安全预算的可加保证）

**陈述**：设被删除集合为 R，且对每个 i∈R 有 Δε_cat,i = ε_cat(G_{C\{i}}) − ε_cat(G_C)。若在 AND 单调链上按序删除并满足 Σ_{i∈R} Δε_cat,i ≤ ε_budget，则 ε_cat(Exec_v30) ≤ ε_cat(Exec_v29) + ε_budget。

**证明**：沿删除链 G_C → … → G_{C\R} 对 ε_cat 做 telescoping：总增量等于各步增量之和；单调性保证每步增量非负且不超过单独删除时的 Δε_cat,i（交互项在单调 AND 下不会使增量变小）。故总增量 ≤ Σ Δε_cat,i ≤ ε_budget。∎

**诚实声明**：若删除的是 DGC 这类会把动作路由到教师的证书，安全可能不降反升而延迟上升，此时单调性只在安全维度成立、在多目标 V 上不成立；因此 INC 的删除决策必须同时报告安全与成本两个坐标，不能只报 V 的标量增益。

**分阶段**：

- C 交互：对 ≤6 个候选做 2^k 全因子（≤64 次），估计 I_ij，识别互补/替代对；
- D 稳定：E_1..E_6 上 Spearman 秩相关，过 CDSG 才允许删除/保留；

## 7. 本轮最大风险（最终确认）

**一句话**：**把消融归因当成创新的「证明」而非「假设检验」**——φ 与 I_m 都是在与训练同源的分布上测得的耦合量，一旦部署偏移，INC 会把「基准上承重」误读为「因果必要」，并以 φ 为保留目标诱发组件互相削弱来制造承重地位的 Goodhart 循环，最终删掉真正保护尾部的那张证书。
