# 第 8 轮（新灵感循环第 1 轮；本轮灵感：「安全交互」×「抓取」）
> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮纪律：**抓取不是一次静态几何检查，而是机器人与人/物之间一份可撤销的物理契约**。新增约束只能收紧 M₀/M₁；人类可随时否决，机器人可随时安全中止；任一新增模块失效 ⇒ 严格退回 v7。

## 0. 直觉与动机

**灵感 1（安全交互 → 安全是双方共同维持的可撤销契约）**
直觉：v7 的安全主要是“机器人单方面出证书”——检查 τᵢ、γ_grasp、SoftCert 后执行。但真实的人机安全更像递一杯水：双方都要能看见对方、都能说“停”、都能松手。只要有一方松手，另一方必须立刻退让，而不是继续完成动作。因此安全交互至少需要三条公理：**可观测性**（双方状态可被估计）、**可撤销性**（人类否决 / 机器人中止在一个控制周期内生效）、**有界能量**（物理耦合时机器人注入的能量有上限，人总能压倒机器人）。

**灵感 2（抓取 → 抓取是交互从语义变成物理的那一刻）**
直觉：v7 的 GCT/γ_grasp 只检查接触发生前的几何参数（宽度、深度、最小力）。真正的危险发生在接触之后：法向力过大压坏物体、切向力超过摩擦锥导致滑落、闭合速度过快产生冲击、递接时夹到人手、提升时物体滑移。抓取规划因此要从“几何可行性”升级为“接触过程可行性”：接触包络、接触模态、滑移检测、冲击冲量与被动能量罐。

**合成直觉（安全交互 × 抓取 = 可撤销的接触契约 SICG）**
把两个灵感合成 **SICG（Safe Interaction Contract for Grasping）**：语音给出“意图”，抓取几何给出“接触候选”，人类状态给出“共享空间许可”，触觉/力传感器给出“物理事实”，接触阶段机把四者组织成一份分阶段、带不变式、可撤销的契约。v7 的 OTL/ER 自适应只在交互风险低时允许开启；一旦人类靠近、滑移发生或接触力越界，立即冻结自适应并退回 v7 的保守抓取。直觉上：**抓取成功不再是“抓住了”，而是“在整个接触过程中，双方都保留退出的权利，且退出本身是安全的”。**

## 1. 研究问题（轮次升级版）

- **Q1（可撤销接触契约）**：如何把抓取指令、接触包络、人类许可、能量预算编码成一份可验证、可过期、可撤销的契约，使任一参与方退出时系统都能在一个控制周期内安全中止？
- **Q2（接触过程的安全判据）**：如何把摩擦锥、压力上限、冲击冲量、滑移与接触模态做成可在线检查的证书，而不是只检查抓取前的几何参数？
- **Q3（交互风险下的门控与退化）**：人类接近、接触不确定或传感器失效时，如何冻结 OTL/ER、切换接触模态，并保证任一新增模块失效都等价退回 v7、v7 再失效退回 v6？

## 2. 设计原则（在 P7–P9 基础上升级为 P14–P19）

**P14 可撤销交互契约（Revocable Interaction Contract, RIC）**
抓取执行前生成结构化契约，而不是直接下发动作：
```
C = (κ, E_g, H_safe, E_budget, t0, TTL, n, σ, m0)
Valid(C,t) ⇔ Verify(σ) ∧ n 未重放 ∧ t−t0 ≤ TTL
            ∧ κ ⪯_safe ι_v7 ∧ STI(χ)
```
其中 κ 是只允许“收紧”的接触候选，E_g 为接触包络，H_safe 为共享空间许可，E_budget 为能量预算，n 为一次性 nonce，m0 为初始接触模态。

**P15 接触包络（Contact Envelope, CE）**
把“抓得住”从几何参数升级为接触力/力矩的集合约束：
```
E_g = { w=(f,τ) : ∀c, f_n ≥ 0, ||f_t|| ≤ μ_s·f_n,
        f_n ≤ f_max, p_c ≤ p_max, CoP(w_c) ∈ P_support,
        ∫ ||f(τ)|| dτ ≤ J_max }
```
μ_s 是保守的静摩擦下界，P_support 是接触支撑多边形，J_max 限制冲击冲量。实际估计的接触力必须落在包络内部并留出扰动裕度。

**P16 人类间距与递接许可（Human Clearance & Handover Consent, HCH）**
共享工作空间中，安全不是“不接触”，而是“没有许可就不进入接触区”：
```
d_min(t) = min_{p∈B_r(t), q∈H(t)} ||p−q||
τ_tc(t)  = (d_min − δ_pad) / (||ṗ_rel|| + ε)
Clear(t) ⇔ (d_min ≥ d_safe ∧ τ_tc ≥ τ_react)
           ∨ (处于递接区 ∧ Consent(t))
```
其中 δ_pad 为安全垫，τ_react 为人类/机器人反应时间下界；递接区是唯一允许“人类主动靠近”的例外区域。

**P17 接触阶段机（Contact Phase Machine, CPM）**
抓取被拆成带守卫的状态转移，而不是一条顺序脚本：
```
Q = {Idle, Approach, Touch, Close, Lift, Handover, Place, Release, Abort}
Approach → Touch   : d_min ≥ d_safe ∧ f_cmd ≤ f_touch
Touch    → Close   : ŵ ∈ E_g ∧ σ_mode ≥ σ_min
Close    → Lift    : slip = 0 连续 N 拍 ∧ 稳定抓取证书
Lift     → Handover: Consent ∧ human_ready ∧ E_tank ≥ E_req
*        → Abort   : 永远使能（人类否决 / 机器人中止 / 证书过期）
```
每个状态都带独立不变式；非法转移一律走 Abort，而不是“尽量完成”。

**P18 被动能量罐（Passivity Energy Tank, PET）**
物理耦合/递接期间，机器人不能成为能量源：
```
E_{t+1} = clip( E_t + Δt·(⟨f_ext,v⟩ − ⟨f_cmd,v⟩), 0, E_max )
admissible(t) ⇔ E_t + Δt·(⟨f_ext,v⟩ − ⟨f_cmd,v⟩) ≥ 0
```
能量罐见底时切换到零力/阻尼模式，保证人类始终能压倒机器人；这比单纯限制力更适合解释“递接时被人类突然推一下”的场景。

**P19 交互风险门（Interaction Risk Governor, IRG）**
交互风险高时，冻结 v7 的在线适应，而不是继续学习：
```
ρ_int = max( (d_safe−d_min)/d_safe, (f_n−f_max)/f_max,
             slip, mode-uncertainty, (E_req−E_t)/E_req )
g_int = 1[ρ_int ≤ 0]
η_eff = η·g_int,  β_eff = β·g_int
```
`g_int=0` 时 OTL 停止更新、ER 退回风险权重；注意 IRG 只“冻结”适应，不能放松 v7 的任何硬约束。

## 3. 与基线的接口（如何退化）

- 接触传感或 CSE 不可用 ⇒ 无客观接触事实，禁用 SICG 增强，走 v7 的 γ_grasp 静态检查；
- 人类状态估计不可用 ⇒ 禁用共享空间运动与递接，SICG 关闭，行为等价 v7；
- 许可/撤销通道不可用或过期 ⇒ 视为持续否决，SICG 关闭，行为等价 v7；
- 能量罐不可用 ⇒ 禁止物理递接与柔性耦合，SICG 关闭，行为等价 v7；
- IRG 不可用 ⇒ 不启用交互门控，行为等价 v7；
- v7 的 OTL/GCT/ER 再失效 ⇒ 退回第 6 轮 MetricVoiceGauge v6（固定 τ、无抓取几何、风险仅权重）。

## 4. 预期贡献

1. 把“抓取安全”从静态几何判据升级为**带接触包络、阶段不变式和撤销语义的交互契约**；
2. 用被动能量罐给出递接/物理耦合场景的**有界能量**保证，使人类始终保留最终否决权；
3. 用交互风险门把 v7 的在线适应“刹住”，直接回应第 7 轮“过度适应导致退化频率不稳”的风险；
4. E526–E545 覆盖接触安全、人类间距、撤销时延、能量有界、传感器失效与端到端人机抓取。

## 5. 本轮最大风险

**一句话**：SICG 把“人类意图/接触模态”当作可验证输入，但这两者恰是最易误估的量——把人类主动施力误判为扰动会让能量罐持续泄能而僵死，把扰动误判为协作则可能突破接触包络，过度保守与过度信任只隔一个估计误差。

**定义 530（交互上下文 Interaction Context）**
```
χ = (o, h, ι, m̂, t)
h = ({p_i, v_i, σ_i}_{i∈H}, ready, consent, veto)
```
o 为物体与机器人状态，h 为人类手/身体的位置 p_i、速度 v_i、置信度 σ_i、就绪标志 ready、许可 consent 与否决 veto；ι 为 v7 VoiceCommandTyping/GCT 输出的类型化指令。

**定义 531（接触包络 Contact Envelope, CE）**
对接触集合 `C = {c_1,…,c_k}`，包络为
```
E_g = { w : ∀c∈C,
        f_{c,n} ≥ 0,                         # 只能推不能拉
        ||f_{c,t}|| ≤ μ_s · f_{c,n},         # 保守摩擦锥
        f_{c,n} ≤ f_max,                     # 法向力上限
        p_c = f_{c,n}/A_c ≤ p_max,           # 接触压力上限
        CoP(w_c) ∈ P_support,                # 压力中心在支撑多边形内
        ∫_{t0}^{t} ||f(τ)|| dτ ≤ J_max }     # 冲击冲量上限
```
`E_g` 是闭凸集的交集，因此对接触力做凸组合仍留在包络内；这为后面“取更保守者”的合并提供了代数基础。

**定义 532（接触状态估计 Contact State Estimate, CSE）**
```
m̂ ∈ {free, approach, touch, close, grasp, slip, release}
ŵ = (f̂, τ̂),  σ_m ∈ [0,1]
s = 1[ ||f̂_t|| > μ_k · f̂_n ]              # μ_k 为动摩擦估计
```
CSE 由触觉阵列、六维力/力矩、关节电流与夹爪开度融合；`σ_m` 低于 `σ_min` 时，任何依赖模态的转移都不得发生。

**定义 533（人类间距与到达时间 Human Clearance）**
设机器人扫掠体积为 `B_r(t)`，人类手/身体为 `H(t)`：
```
d_min(t) = min_{p∈B_r(t), q∈H(t)} ||p−q||
τ_tc(t)  = (d_min(t) − δ_pad) / (||ṗ_rel(t)|| + ε)
Clear(t) ⇔ (d_min ≥ d_safe ∧ τ_tc ≥ τ_react)
           ∨ (在递接区 ∧ Consent(t) ∧ human_ready(t))
```
递接区是契约显式声明的允许人类主动接近的子空间；在递接区之外，`d_min < d_safe` 直接触发 Abort 或后退，而不是“减速硬闯”。

**定义 534（许可与撤销 Consent / Revocation）**
```
Consent(t) ⇔ Verify(σ_h) ∧ t−t_consent ≤ TTL_c
             ∧ nonce 未重放 ∧ phase_compatible(m̂)
v_h(t) ∈ {0,1},  a_r(t) ∈ {0,1}
v_h=1 ∨ a_r=1 ⇒ Contract.state = Vetoed/Aborted 于 T_rev 内生效
```
人类否决优先于任何任务奖励；`T_rev ≤ T_cycle`（50Hz 下 ≤20ms），保证“说停就停”是控制层事实而不是界面承诺。

**定义 535（安全交互谓词 Safe-to-Interact, STI）**
```
STI(χ) ⇔ γ_grasp(ι)                     # v7 的接触前几何门
        ∧ ŵ ∈ E_g                        # 接触力落在包络内
        ∧ Clear(t)                       # 人类间距/递接许可
        ∧ Consent(t)                     # 有效且未撤销的许可
        ∧ E_t ≥ E_min                    # 能量罐非空
        ∧ phase_invariant(m̂, χ)          # 当前阶段不变式成立
```
STI 是“允许发生下一次接触动作”的合取谓词；它不替代 v7 的 M₀/M₁，而是把 v7 的检查嵌入到接触过程的每一步。

**定义 536（交互契约 Interaction Contract）**
```
C = (κ, E_g, H_safe, E_budget, t0, TTL, n, σ, m0)
Valid(C,t) ⇔ Verify(σ) ∧ n 未重放 ∧ t−t0 ≤ TTL
            ∧ κ ⪯_safe ι_v7 ∧ STI(χ)
Contract.state ∈ {Active, Vetoed, Expired, Aborted, Completed}
```
`κ ⪯_safe ι_v7` 表示契约只能收紧 v7 的力/速度/工作空间约束，不能放宽 M₀/M₁；这是整个 SICG 与基线的安全接口。

**定义 537（接触阶段机 Contact Phase Machine, CPM）**
```
Q = {Idle, Approach, Touch, Close, Lift, Handover, Place, Release, Abort}
⇝ ⊆ Q × Q × Guard
```
关键转移与不变式：
```
Approach → Touch    : d_min ≥ d_safe ∧ f_cmd ≤ f_touch
Touch    → Close    : ŵ ∈ E_g ∧ σ_m ≥ σ_min
Close    → Lift     : s=0 连续 N 拍 ∧ σ_grasp ≥ σ_grasp_min
Lift     → Handover : Consent ∧ human_ready ∧ E_t ≥ E_req
Handover → Release  : 人类握力 ≥ f_hold 或物体已被支撑
Place    → Release  : 支撑面承重 ≥ W_obj
*        → Abort    : 无条件使能
```
每个状态的不变式：
- `Approach/Touch`：法向力 ≤ `f_touch`，接近速度 ≤ `v_touch`；
- `Close`：闭合速率 ≤ `ḟ_max`，接触力始终在 `E_g` 内；
- `Lift`：滑移 `s=0`，且稳定抓取证书未过期；
- `Handover`：能量罐 ≥ `E_req`，人类许可有效；
- `Release`：物体被支撑或人类已建立足够握力。

**定义 538（被动能量罐 Passivity Energy Tank, PET）**
```
E_{t+1} = clip( E_t + Δt·(⟨f_ext,v⟩ − ⟨f_cmd,v⟩), 0, E_max )
admissible(t) ⇔ E_t + Δt·(⟨f_ext,v⟩ − ⟨f_cmd,v⟩) ≥ 0
```
当 `admissible(t)=false` 时，控制器切换到零力/阻尼模式（`f_cmd = −D·v`），并把状态置为 `Abort`。该式把“机器人不能向人注入超过预算的能量”写成了一条可在线检查的不等式。

**定义 539（交互风险门 Interaction Risk Governor, IRG）**
```
ρ_int = max( (d_safe−d_min)/d_safe,
             (f_n−f_max)/f_max,
             s,
             max(0, 1−σ_m/σ_min),
             max(0, (E_req−E_t)/E_req) )
g_int = 1[ρ_int ≤ 0]
η_eff = η·g_int,  β_eff = β·g_int
```
`g_int=0` 时 OTL 停止更新、ER 退回风险权重；它只冻结 v7 的适应，不改变 v7 的 τ 基线，也不放松 M₀/M₁。

**定义 540（抓取指令的安全细化 Safe Refinement of Grasp Command）**
```
κ ⪯_safe ι ⇔ 
    κ.force_max ≤ ι.force_max
  ∧ κ.speed_max ≤ ι.speed_max
  ∧ Workspace(κ) ⊆ Workspace(ι)
  ∧ type(κ) = type(ι) ∈ Σ_ι
  ∧ κ.grasp_geometry 满足 v7 的 γ_grasp
```
即交互层只能让抓取更慢、更轻、更窄，不能把 v7 拒绝的指令“改回来”。

**定义 541（SICG 状态与组合退化 SICG State / Compositional Degradation）**
```
Φ_SICG = (Contract Active, m̂ 一致, STI 成立, E_t ≥ 0, RAC 在线)
Φ_v7   = (无 SICG 契约, v7 OTL/GCT/ER 在线)
Φ_v6   = (固定 τ, 无抓取几何, 风险仅权重)

SICG --CEC/CSE✗--> v7
SICG --HCG✗------> v7
SICG --ICF✗------> v7
SICG --PET✗------> v7
SICG --IRG✗------> v7
SICG --RAC✗------> v7
v7   --OTL/GCT/ER✗--> v6
```

**定义 542（可撤销中止不变式 Revocable Abort Invariant）**
```
∀t, state ≠ Abort ⇒ Abort 在 t+T_rev 内可达
在 Abort 中：f_cmd ≤ f_safe, ||v_cmd|| ≤ v_safe,
             且仅在 (物体被支撑 ∨ 人类握力 ≥ f_hold) 时释放
```
中止不是“急停后松手”，而是“先进入有界力/速度的安全态，再在满足支撑条件时释放”；否则递接中松手可能直接摔落物体。

**定义 543（交互安全不变式 Interaction Safety Invariant）**
```
Inv(χ) ⇔ (STI(χ) ⇒ M₀ 满足)
       ∧ ŵ ∈ E_g
       ∧ (递接区外 ⇒ d_min ≥ d_safe)
       ∧ E_t ≥ 0
       ∧ (每次转移 ⇒ 守卫成立)
```
这是本轮的主定理目标：SICG 的每一步都保持 `Inv`，从而不会在接触过程中制造新的硬约束违背。

**定义 544（SICG 闭环标识）**
```
Φ_SICG = (契约验证, CPM 阶段一致, PET 能量有界,
          HCG 间距许可, IRG 冻结适应, RAC 可撤销)
```
`Φ_SICG` 与 v7 的 `Φ_OTL-GC-ER` 是叠加关系：前者不替换后者，只在后者外面加一层“接触过程安全壳”。

## 2. 形式化定义（对 v7 既有定义的接口）

from dataclasses import dataclass
from enum import Enum
import numpy as np


class Phase(Enum):
    IDLE = "idle"
    APPROACH = "approach"
    TOUCH = "touch"
    CLOSE = "close"
    LIFT = "lift"
    HANDOVER = "handover"
    PLACE = "place"
    RELEASE = "release"
    ABORT = "abort"


class ContactMode(Enum):
    FREE = "free"
    APPROACH = "approach"
    TOUCH = "touch"
    CLOSE = "close"
    GRASP = "grasp"
    SLIP = "slip"
    RELEASE = "release"


@dataclass(frozen=True)
class ContactWrench:
    force: tuple          # 世界系接触力
    torque: tuple = (0.0, 0.0, 0.0)
    contact_area: float = 1e-4
    cop: tuple = (0.0, 0.0)


@dataclass(frozen=True)
class ContactEstimate:
    wrenches: tuple       # tuple[ContactWrench, ...]
    mode: ContactMode
    mode_conf: float
    slip: bool


@dataclass(frozen=True)
class HumanState:
    positions: tuple
    velocities: tuple
    ready: bool
    consent: bool
    veto: bool
    consent_ts: float
    nonce: str


@dataclass(frozen=True)
class InteractionContract:
    kappa: dict
    envelope: "ContactEnvelope"
    workspace: dict
    energy_budget: float
    t0: float
    ttl: float
    nonce: str
    signature: bytes
    phase: Phase = Phase.IDLE


class ContactEnvelope:
    def __init__(self, mu_s=0.5, f_max=40.0, p_max=2e5,
                 j_max=0.8, support_polygon=None):
        self.mu_s = mu_s
        self.f_max = f_max
        self.p_max = p_max
        self.j_max = j_max
        self.support_polygon = support_polygon or [(-1, -1), (1, -1), (1, 1), (-1, 1)]
        self.impulse = 0.0

    def _support_ok(self, cop):
        # 凸多边形内点测试（叉积同号）
        x, y = cop
        signs = []
        poly = self.support_polygon
        for i in range(len(poly)):
            x1, y1 = poly[i]
            x2, y2 = poly[(i + 1) % len(poly)]
            cross = (x2 - x1) * (y - y1) - (y2 - y1) * (x - x1)
            signs.append(cross)
        return all(c >= -1e-9 for c in signs) or all(c <= 1e-9 for c in signs)

    def contains(self, w: ContactWrench, margin=0.0):
        # 简化：世界系 z 为接触法向；实际实现按每个接触帧做旋转变换
        fn = w.force[2]                       # 法向分量
        ft = np.linalg.norm(w.force[:2])      # 切向分量
        pressure = max(fn, 0.0) / max(w.contact_area, 1e-9)
        return (
            fn >= margin
            and ft <= (1.0 - margin) * self.mu_s * fn
            and fn <= (1.0 - margin) * self.f_max
            and pressure <= self.p_max
            and self._support_ok(w.cop)
        )

    def impulse_after(self, w: ContactWrench, dt):
        # 纯函数：只预测冲量，不改变状态（避免检查失败仍污染累计量）
        return self.impulse + float(np.linalg.norm(w.force)) * dt

    def accumulate_impulse(self, w: ContactWrench, dt):
        self.impulse = self.impulse_after(w, dt)

    def reset(self):
        self.impulse = 0.0


class HumanClearanceGuard:
    def __init__(self, d_safe=0.25, delta_pad=0.05, tau_react=0.25, eps=1e-3):
        self.d_safe = d_safe
        self.delta_pad = delta_pad
        self.tau_react = tau_react
        self.eps = eps

    @staticmethod
    def min_distance(robot_points, human_points):
        return min(
            float(np.linalg.norm(np.subtract(p, q)))
            for p in robot_points for q in human_points
        )

    def time_to_contact(self, d_min, v_rel):
        return (d_min - self.delta_pad) / (float(np.linalg.norm(v_rel)) + self.eps)

    def clear(self, d_min, v_rel, in_handover_zone, consent_ok, now, consent_ts, ttl_c):
        separation_ok = (
            d_min >= self.d_safe
            and self.time_to_contact(d_min, v_rel) >= self.tau_react
        )
        handover_ok = in_handover_zone and consent_ok and now - consent_ts <= ttl_c
        return separation_ok or handover_ok


class PassivityEnergyTank:
    def __init__(self, e_init=1.0, e_max=2.0):
        self.e = e_init
        self.e_max = e_max

    def admissible(self, f_ext, f_cmd, v, dt):
        power_net = float(np.dot(f_ext, v)) - float(np.dot(f_cmd, v))
        return self.e + dt * power_net >= 0.0

    def update(self, f_ext, f_cmd, v, dt):
        power_net = float(np.dot(f_ext, v)) - float(np.dot(f_cmd, v))
        self.e = float(np.clip(self.e + dt * power_net, 0.0, self.e_max))
        return self.e

    def damped_command(self, v, damping=20.0):
        # 能量罐见底：零力/阻尼模式，人类始终可压倒机器人
        return -damping * np.asarray(v, dtype=float)


class InteractionRiskGovernor:
    def __init__(self, d_safe, f_max, sigma_min=0.8, e_req=0.2):
        self.d_safe = d_safe
        self.f_max = f_max
        self.sigma_min = sigma_min
        self.e_req = e_req

    def risk(self, d_min, fn, slip, sigma_m, e_t):
        return max(
            (self.d_safe - d_min) / self.d_safe,
            (fn - self.f_max) / self.f_max,
            1.0 if slip else 0.0,
            max(0.0, 1.0 - sigma_m / self.sigma_min),
            max(0.0, (self.e_req - e_t) / self.e_req),
        )

    def gate(self, rho):
        return 1 if rho <= 0.0 else 0


class ContactPhaseMachine:
    ALLOWED = {
        Phase.IDLE: {Phase.APPROACH, Phase.ABORT},
        Phase.APPROACH: {Phase.TOUCH, Phase.ABORT},
        Phase.TOUCH: {Phase.CLOSE, Phase.ABORT},
        Phase.CLOSE: {Phase.LIFT, Phase.ABORT},
        Phase.LIFT: {Phase.HANDOVER, Phase.PLACE, Phase.ABORT},
        Phase.HANDOVER: {Phase.RELEASE, Phase.ABORT},
        Phase.PLACE: {Phase.RELEASE, Phase.ABORT},
        Phase.RELEASE: {Phase.IDLE, Phase.ABORT},
        Phase.ABORT: {Phase.IDLE},
    }

    def step(self, phase, contact, human, contract,
             clearance_ok, envelope_ok, energy_ok):
        if human.veto or not human.consent:
            return Phase.ABORT
        if phase == Phase.IDLE:
            return Phase.APPROACH if clearance_ok else Phase.IDLE
        if phase == Phase.APPROACH:
            return Phase.TOUCH if clearance_ok else Phase.ABORT
        if phase == Phase.TOUCH:
            return Phase.CLOSE if (envelope_ok and contact.mode_conf >= 0.8) else Phase.ABORT
        if phase == Phase.CLOSE:
            ok = contact.mode in (ContactMode.GRASP, ContactMode.CLOSE)
            return Phase.LIFT if (ok and not contact.slip) else Phase.ABORT
        if phase == Phase.LIFT:
            if human.ready and human.consent and energy_ok:
                return Phase.HANDOVER
            return Phase.PLACE
        if phase in (Phase.HANDOVER, Phase.PLACE):
            return Phase.RELEASE
        if phase == Phase.RELEASE:
            return Phase.IDLE
        return Phase.ABORT


def safe_refines(kappa, iota):
    return (
        kappa.get("force_max", float("inf")) <= iota.get("force_max", float("inf"))
        and kappa.get("speed_max", float("inf")) <= iota.get("speed_max", float("inf"))
        and set(kappa.get("workspace", [])).issubset(set(iota.get("workspace", [])))
        and kappa.get("type") == iota.get("type")
    )


def verify_contract(contract, now, verify_signature, used_nonces, sti, safe_ok):
    return (
        verify_signature(contract.signature)
        and contract.nonce not in used_nonces
        and now - contract.t0 <= contract.ttl
        and sti
        and safe_ok
    )


def sicg_step(M, s, obs, human, contact, contract, now, v7_step,
              verify_signature, used_nonces):
    """SICG：在 v7 主路径外加一层可撤销接触契约；任何失败都回退 v7。"""
    envelope = contract.envelope if contract is not None else None
    hcg = M.sicg.clearance_guard
    irg = M.sicg.risk_governor
    pet = M.sicg.energy_tank
    cpm = M.sicg.phase_machine

    d_min = hcg.min_distance(M.robot_points(obs), human.positions)
    v_rel = M.robot_velocity(obs, human)
    clearance_ok = hcg.clear(
        d_min, v_rel, M.in_handover_zone(obs),
        human.consent and not human.veto,
        now, human.consent_ts, M.sicg.consent_ttl,
    )

    envelope_ok = bool(envelope) and all(
        envelope.contains(w, margin=M.sicg.envelope_margin)
        for w in contact.wrenches
    )
    impulse_ok = bool(envelope) and all(
        envelope.impulse_after(w, M.dt) <= envelope.j_max
        for w in contact.wrenches
    )

    safe_ok = (
        contract is not None
        and safe_refines(contract.kappa, M.default_iota)
    )
    sti = (
        M.grasp.check(contract.kappa if contract is not None else M.default_iota)
        and envelope_ok and impulse_ok
        and clearance_ok
        and human.consent and not human.veto
        and pet.e >= M.sicg.e_min
    )

    if contract is None or not verify_contract(
            contract, now, verify_signature, used_nonces, sti, safe_ok):
        # 任一失败：关闭 SICG，严格走 v7 原路径
        return v7_step(M, s, obs), {"sicg": False, "reason": "contract_invalid"}

    fn = max((w.force[2] for w in contact.wrenches), default=0.0)
    rho = irg.risk(d_min, fn, contact.slip, contact.mode_conf, pet.e)
    g_int = irg.gate(rho)

    energy_ok = pet.e >= contract.energy_budget
    next_phase = cpm.step(
        contract.phase, contact, human, contract,
        clearance_ok, envelope_ok, energy_ok,
    )
    if next_phase == Phase.ABORT:
        f_cmd = pet.damped_command(M.robot_velocity(obs))
        return v7_step(M, s, obs, phase=Phase.ABORT, f_cmd=f_cmd), {
            "sicg": False, "reason": "abort", "rho_int": rho, "phase": next_phase,
        }

    if not pet.admissible(M.f_ext(obs), M.f_cmd(obs), M.robot_velocity(obs), M.dt):
        f_cmd = pet.damped_command(M.robot_velocity(obs))
        return v7_step(M, s, obs, phase=Phase.ABORT, f_cmd=f_cmd), {
            "sicg": False, "reason": "energy_tank_empty",
        }
    for w in contact.wrenches:
        envelope.accumulate_impulse(w, M.dt)
    pet.update(M.f_ext(obs), M.f_cmd(obs), M.robot_velocity(obs), M.dt)

    result = v7_step(M, s, obs,
                     eta=M.otl.eta * g_int, beta=M.er.beta * g_int)
    return result, {
        "sicg": True, "phase": next_phase, "rho_int": rho,
        "gate": g_int, "d_min": d_min, "energy": pet.e,
    }

## 4. 推导

**引理 77（接触包络的扰动鲁棒性）** 设实际接触力 `w = ŵ + δ` 且 `||δ|| ≤ δ_max`。若 `ŵ` 落在 `E_g` 内且到包络边界的欧氏距离 ≥ `δ_max`，则 `w ∈ E_g`。证明：`E_g` 是若干闭凸约束的交，包含以 `ŵ` 为心、半径 `δ_max` 的球；故扰动不越界。特别地，`||f_t|| ≤ μ_s f_n − δ_max` 保证实际切向力仍低于保守摩擦锥，不会滑移。∎

**引理 78（人类间距的到达时间安全）** 若 `d_min ≥ d_safe` 且 `τ_tc ≥ τ_react`，且相对速度与加速度有界，则在 `τ_react` 内不会发生非预期接触。证明：由 `τ_tc` 定义，以当前相对速度把间距压到 `δ_pad` 至少需要 `τ_tc`；在反应时间内系统可执行 Abort 或后退。若加速度使到达时间缩短，则用最坏加速度重算 `τ_tc`（在实现中取 `v_max` 而非瞬时速度），故保守性保持。∎

**引理 79（接触阶段机的不变式保持）** 若 `Inv(χ)` 在进入某阶段时成立，且每次转移的守卫成立，则 `Inv(χ)` 在转移后仍成立。证明：对 `Q` 做结构归纳。Approach/Touch 的守卫直接给出 `f_n ≤ f_touch` 与 `d_min ≥ d_safe`；Touch→Close 要求 `ŵ ∈ E_g` 与 `σ_m ≥ σ_min`；Close→Lift 要求连续 `N` 拍 `s=0`；Abort 无条件使能且进入有界力/速度态。每个转移只缩小可行域，故不变式保持。∎

**引理 80（能量罐的被动性界）** 若 `E_0 ∈ [0,E_max]` 且每步只执行 `admissible(t)` 为真的控制，则对所有 `t` 有 `0 ≤ E_t ≤ E_max`，且系统向环境注入的累计能量不超过 `E_max − E_0`。证明：更新式对 `E` 做 `clip`，非负性由 `admissible` 保证；单步净能量流出不超过 `E_t`，对时间求和即得累计上界。当 `E_t` 见底时切换到 `f_cmd = −Dv`，控制器耗散而非注入能量，故人类始终可压倒机器人。∎

**引理 81（许可与撤销的重放安全）** 若许可使用一次性 nonce、签名与 TTL，且 `T_rev ≤ T_cycle`，则过期的许可与重放的许可能在一个控制周期内被拒绝；人类否决 `v_h=1` 必然导致 `Contract.state ∈ {Vetoed, Aborted}`。证明：nonce 由 `used_nonces` 单调去重，TTL 检查拒绝陈旧许可，签名验证拒绝伪造；撤销在控制回路入口读取，故时延不超过一个周期。∎

**引理 82（风险门只能冻结适应）** IRG 的输出 `g_int ∈ {0,1}`，且 `η_eff=η·g_int`、`β_eff=β·g_int`。因此 `g_int=0` 只会使 OTL 停止更新、ER 退回风险权重，不会修改 `τ` 的基线，也不会放松 `M₀/M₁`。若 IRG 模块缺失，系统直接走 v7 原路径。证明：由定义 539，`g_int=0` 时两个增益为零；v7 的阈值与硬约束检查不在 IRG 的写入集合内。∎

**引理 83（契约的安全细化）** 若 `Valid(C,t)` 且 `Accept` 成立，则 `κ ⪯_safe ι_v7`，因此契约不会放宽 v7 的力/速度/工作空间约束，也不会放宽 M₀/M₁。证明：`Valid` 的合取项直接包含 `κ ⪯_safe ι_v7`；由定义 540，κ 的力、速度、工作空间均为 ι 的收紧，类型与几何仍满足 v7 的 γ_grasp。∎

**引理 84（SICG 组合退化等价性）** ① CEC/CSE 失效 ⇒ 无 `envelope_ok`，`verify_contract` 失败，直接调用 `v7_step`，行为等价 v7；② HCG/ICF/PET/IRG/RAC 任一失效 ⇒ 对应守卫为假或模块被绕过，同样走 `v7_step`；③ v7 的 OTL/GCT/ER 失效 ⇒ 由 v7 已证明的退化链等价 v6。各分支只读取上一层接口，不触发级联。∎

**引理 85（可撤销中止的完备性）** 从任意阶段 `q ∈ Q`，Abort 均使能；Abort 态的命令力/速度满足 `f_cmd ≤ f_safe`、`||v_cmd|| ≤ v_safe`，且仅在物体被支撑或人类握力 ≥ `f_hold` 时释放。因此任意时刻的人类否决或机器人中止都能在 `T_rev` 内到达安全态。证明：Abort 的守卫为空（无条件），释放条件由定义 542 给出；有界力/速度由 `damped_command` 与 v7 的安全裁剪共同保证。∎

**引理 86（交互安全不变式的归纳保持）** 若初始 `Inv(χ)` 成立，且每个控制周期执行 `sicg_step` 的契约验证、包络检查、间距检查、能量检查和阶段转移，则 `Inv(χ)` 在每个周期末仍成立。证明：契约验证给出引理 83，包络检查给出引理 77，间距检查给出引理 78，阶段转移给出引理 79，能量检查给出引理 80；四者合取即 `Inv` 的每一项。由数学归纳，所有周期成立。∎

**推论 87（SICG 不制造新的硬安全风险源）** 由引理 83 与 86，SICG 只能在 v7 已满足 M₀/M₁ 的前提下进一步收紧接触力、速度与工作空间；任何检查失败都进入 v7 或 Abort，而不是继续执行。因此 SICG 不会成为新的硬约束违背源，只会把“接触后才发现不安全”提前为“接触前/接触中可撤销”。

## 8. 本轮最大风险

**一句话**：SICG 把“人类意图/接触模态”当作可验证输入，但这两者恰是最易误估的量——把人类主动施力误判为扰动会让能量罐持续泄能而僵死，把扰动误判为协作则可能突破接触包络，过度保守与过度信任只隔一个估计误差。
