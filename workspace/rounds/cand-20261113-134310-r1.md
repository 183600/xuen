# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 4 轮；本轮灵感：「开放词汇」×「分布外泛化」）

> 第 65~67 轮走完了「故障可归因（VISTA）→ 意图可协商（RAS）→ 未来可预演（SimRAS）」三级跳。然而这条主线始终在两个**闭合世界**里运行：
>
> 1. **概念闭合**：故障假设集 ℋ 只有固定的 6~7 类、情绪集 E 只有 4 类。一个从未被命名的故障（例如「夹爪勾住了织物纤维」「地面材质变软导致轮子下陷」）在贝叶斯归一化下没有对应模板，其后验会被**结构性地推给 H0=正常**。这不是检测器不够强，而是**假设空间不完备**——闭合词表会把「未知」误读成「安全」。
> 2. **分布闭合**：SimEngine 的 TV<0.1、WM 的误差界、VQA 的泛化界、乃至共形/后验的可靠性，都默认标定分布与部署分布可交换（exchangeable）。一旦部署进入 OOD 场景，所有「覆盖率/误差界」在形式上失效，而系统却可能仍然**自信地**输出高 λ_risk、长认证前缀。
>
> 这两个闭合其实是同一个病：**世界会用「没被命名的概念」和「没被采样过的分布」来惩罚我们。**
>
> 本轮的核心命题是：
>
> **把「封闭词表的故障闭环」升级为「开放词表的风险接地闭环」：让故障/情绪/风险都以自然语言概念的形式存在于一个可扩展的概念库中，用概念接地的最大相似度同时完成「故障命名」与「OOD 检测」，用加权共形风险控制为分布外场景恢复有限样本保证，用组合留出仿真生成真正的 OOD 训练与评测，构成 OV-RAS（Open-Vocabulary Risk-aware Adaptive Closure）。**
>
> OV-RAS 追问的既不是「哪一层坏了」，也不是「谁该控制多少」，而是：**「我现在遇到的这个东西，我的语言里有没有名字？如果没有，我凭什么还敢放行？」**

## 0. 直觉与动机

**灵感 1（开放词汇 → 会生长的假设空间）**
直觉：第 66 轮把情绪、第 67 轮把故障都做成了「固定类别的分类器」。但真实故障是长尾的、可被人类用任意短语描述的。若把每个假设 `H_j` 绑定到一条语言概念 `c_j`（如「轮胎打滑」「夹爪空抓」「人因恐惧而后撤」），则假设空间可以从一个**概念库**动态检索出来，而不是写死在代码里。更关键的是：加入一个显式的 `H_∅`（none-of-the-above），使归一化分母包含「以上都不是」，于是新故障不再被强行摊派给 H0。**闭合词表的病根不是缺类别，而是缺「未知」这个类别。**

**灵感 2（分布外泛化 → 共形风险控制，而不是又一个检测头）**
直觉：SimRAS 的「风险一致性」是平均意义/误差界意义上的，遇到 OOD 就空转。真正想在部署时说的话是：「在置信度 1-δ 下，执行风险不超过 α」。这正是**共形风险控制**的语言：用一小批标定样本给出 `λ_risk` 与认证前缀 `k` 的有限样本上界；当协变量发生偏移时，用**加权共形**（密度比加权）把保证搬过去；当权重不可估或偏移过大时，**弃权**（abstain）到最保守策略，而不是假装还有保证。

**灵感 3（两灵感合流 → 未知既是 OOD 的敌人，也是它的解药）**
直觉：这是本轮最漂亮的一步。设观测编码 `φ(o)`、概念文本编码 `ψ(c)`，概念匹配分 `s_j = <φ(o), ψ(c_j)>/τ`。那么：
- 故障命名 = `argmax_j s_j`；
- OOD 分数 = `u(o) = 1 - max_j s_j`；
- **同一套内积，同时给出「最像谁」和「像不像任何东西」**。
所以「开放词汇」不是给 OOD 加模块，而是**OOD 检测的天然载体**。反过来，OOD 场景一旦被人类用一句话命名并入库，就立刻从「分布外」变成「分布内」。**未知概念是 OOD 的元凶，命名是它的解药。**

**灵感 4（组合性 → SimEngine 生成真正的 OOD）**
直觉：随机域随机化只能造出「同分布附近的更多样本」，造不出「概念组合上没见过」的样本。若 SimEngine 用一个概念语法 `G` 组合场景因子（材质 × 地形 × 人因 × 故障），并**留出某些组合**作为 OOD split，则离线阶段就能测出「组合泛化」而不是「插值泛化」。例如训练见过「光滑地面×下坡」「粗糙地面×上坡」，留出「光滑地面×上坡」——这才是 OOD 该有的样子。

**灵感 5（从「检测」到「命名即预演」→ 概念条件世界模型）**
直觉：如果 WM 能接受概念嵌入 `e_c` 作为条件，那么当操作员说「小心，夹爪可能会勾住布」，系统无需任何该故障的训练数据，就能**零样本预演**这条概念对应的风险轨迹。命名不只是标签，它是**可执行的风险先验**。这也把第 67 轮的「VQA 审计」从被动解释升级为「语言→概念→预演→认证」的主动闭环。

## 1. 形式化定义（增量：定义 276–292）

- **定义 276（开放词汇概念库）**：`C = C_fault ∪ C_emotion ∪ C_risk`，每个概念 `c_j` 对应单位球上的文本嵌入 `e_j = ψ(c_j) ∈ S^{d-1}`。概念库带版本号 `ver_C`，支持运行时由人类新增短语（如「织物勾连」）。定位：替代封闭的 ℋ 与 E。
- **定义 277（概念接地分数）**：对观测 `o_t = (ρ_t, face_t, z_t)`，`s_j(t) = <φ(o_t), e_j> / τ`，`φ(o_t) ∈ S^{d-1}`。开放后验 `π_c(j | o_t) = softmax_j(s_j(t))`。`φ` 可复用第 67 轮 WM 的编码器，`ψ` 为冻结的文本编码器（CLIP 类）。
- **定义 278（开放假设集与弃权假设）**：`ℋ_open(t) = TopK_{j∈C_fault}(s_j(t)) ∪ {H0, H_∅}`。`H_∅` 是「无概念可解释」假设，其证据由概念库的整体失配给出。后验必须在 `ℋ_open` 上归一化，因此 `P(H0 | novel)` 不再结构性趋近 1。
- **定义 279（新颖度 / OOD 分数）**：`u(t) = 1 - max_j s_j(t) ∈ [0, 2]`。`u` 越大越可能 OOD。注意 `u` 与接地同源，无需第二个模型。
- **定义 280（共形新颖度 p 值）**：给定标定集 `{u_i^cal}_{i=1..n}`，`p_ood(t) = (1 + #{i : u_i^cal ≥ u(t)}) / (n+1)`。`p_ood < δ` 判为 OOD。
- **定义 281（加权共形风险控制）**：设目标分布 `P_tgt` 与标定分布 `P_cal` 的密度比 `w(x) = p_tgt(x)/p_cal(x)`，归一化权重 `w̃_i = w(x_i) / Σ_k w(x_k)`。风险控制器在最坏情形风险上取加权分位数：`λ̂ = inf{λ : Σ_i w̃_i · 1[R_i(λ) ≤ α] ≥ 1 - δ}`。覆盖在协变量偏移下近似成立。
- **定义 282（概念条件世界模型 WM-OV）**：`WM_θ(z_t, e_c) → (π_{t+1}, P(H_{t+1}))`。给定一个**从未在训练中出现但可被语言命名**的概念 `c*`，可零样本预演其风险轨迹。零样本误差随 `d(e_{c*}, nearest seen concept)` 增大。
- **定义 283（组合 OOD 划分）**：概念语法 `G` 生成场景因子组合。训练组合集 `C_train`，留出组合集 `C_ood = {组合 ∉ C_train}`。OOD split `D_ood = {τ_sim : comp(τ_sim) ∈ C_ood}`，用于度量组合泛化而非插值泛化。
- **定义 284（语义歧义度 / 接地间隔）**：`m(t) = s_(1)(t) - s_(2)(t)`（top-1 与 top-2 匹配分之差）。`m < τ_g` 表示「像好几个概念但都不确定」，触发接地弃权。
- **定义 285（OV 认证前缀）**：`k*OV = min(k_VISTA, k_emo, k_wm, k_ood)`，其中 `k_ood = 0` 若 `p_ood < δ` 或 `m < τ_g`；否则 `k_ood = k_wm`。
- **定义 286（弃权控制律）**：若 `p_ood < δ` 或 `m < τ_g`，则强制 `λ_risk ≤ λ_floor = 0.6`、`k = 1`、`τ_cmd` 走最小力/最慢速保守策略；同时把该 `(o_t, u_t)` 写入 `NoveltyBuf` 供人类命名。
- **定义 287（概念库增广）**：`C ← C ∪ {c_new}` 仅允许在人类命名或高置信聚类后发生；增广后重算 `ψ(c_new)` 并**重跑共形标定**，防止旧 p 值失效。
- **定义 288（AIC-OV 干扰与共因）**：`ℰ_OV = ℰ_SimRAS × ℰ_ground × ℰ_shift`，其中 `ℰ_ground = {概念幻觉, 同义词/多义词歧义, 对抗性短语, 组合崩塌}`，`ℰ_shift = {协变量偏移, 标签偏移, 概念漂移}`。
- **定义 289（J_OVRAS 证书）**：`J_OVRAS = (J_SimRAS, ver_C, concept_topk_hash, p_ood, grounding_margin, conformal_lambda, coverage_delta)`。Valid ⇔ `Valid(J_SimRAS) ∧ p_ood ≥ δ ∧ (m ≥ τ_g ∨ λ_risk ≤ λ_floor)`。
- **定义 290（命名即先验）**：对外部语言指令 `ℓ`，提取候选概念 `c_ℓ`，令 `e_ℓ = ψ(c_ℓ)`，则 `P_prior(H) ← softmax(<e_ℓ, e_j>_j)`，直接注入 FRAS/EFS 的先验，无需在线数据。
- **定义 291（开放词汇完整性）**：对真实新故障 `f*`，若 `max_j <φ(f*), e_j> ≤ 1 - γ`（与库中概念有间隔 γ），则 `P(H0 | f*) ≤ 1 - P(H_∅ | f*)`；`γ` 越大，新颖度越可分离。
- **定义 292（OV-RAS 总览）**：`OV-RAS = (OVCB, OVG, OHM, CRC, WM-OV, SimEngine-OV, C-OV, ERS-OV, NoveltyBuf)`。不变式：概念库增广与共形重标定只发生在离线段；实时流只做前向内积、p 值查表与弃权判定，零梯度写。

## 2. 关键算法骨架

```python
# OVCB + OVG：开放词汇概念库与接地
class OpenVocabGrounding:
    def __init__(self, text_encoder, phi, concepts, tau=0.07):
        self.psi, self.phi, self.tau = text_encoder, phi, tau
        self.C = list(concepts)
        self.E = normalize(text_encoder(self.C))       # [|C|, d]
        self.ver = 0

    def ground(self, rho, face_feat, z):
        o = normalize(self.phi(rho, face_feat, z))
        s = (self.E @ o) / self.tau                 # 概念匹配分
        post = softmax(s)
        top1, top2 = torch.topk(s, 2).values
        u = 1.0 - top1.item()                         # OOD / 新颖度
        margin = (top1 - top2).item()                 # 接地间隔
        return {'s': s, 'post': post, 'u': u, 'margin': margin,
                'topk': torch.topk(s, 8).indices.tolist()}

    def augment(self, new_concept):
        self.C.append(new_concept)
        self.E = normalize(self.psi(self.C))
        self.ver += 1


class OpenHypothesisManager:
    # 把开放概念接成 ℋ_open = TopK ∪ {H0, H_∅}
    def hypotheses(self, ground_res, K=5):
        topk = ground_res['topk'][:K]
        Hs = [f"H_{j}" for j in topk] + ["H0"]
        # H_∅ 的证据 = 概念库整体失配
        p_known = sum(ground_res['post'][j] for j in topk)
        p_null = max(0.0, 1.0 - p_known)
        return Hs + ["H_NULL"], {'H_NULL': p_null}


class ConformalRiskController:
    def __init__(self, delta=0.05, alpha=0.05):
        self.delta, self.alpha = delta, alpha
        self.u_cal, self.w_cal = [], []

    def calibrate(self, u_cal, risks_fn, weights=None):
        self.u_cal = sorted(u_cal)
        self.w_cal = normalize(weights or [1.0] * len(u_cal))
        # 选 λ：使加权风险 ≤ alpha 的比例 ≥ 1-delta
        best = 0.5
        for lam in [0.5 + 0.05 * i for i in range(15)]:
            keep = sum(w for u, w in zip(self.u_cal, self.w_cal)
                       if risks_fn(u, lam) <= self.alpha)
            if keep >= 1 - self.delta:
                best = lam
                break
        self.lam_hat = best
        return best

    def p_ood(self, u):
        n = len(self.u_cal)
        ge = sum(1 for v in self.u_cal if v >= u)
        return (1 + ge) / (n + 1)


# C-OV：开放词汇认证前缀 + 弃权
class CertifiedOpenVocab:
    def __init__(self, crc, delta=0.05, tau_g=0.05, lam_floor=0.6):
        self.crc, self.delta = crc, delta
        self.tau_g, self.lam_floor = tau_g, lam_floor

    def prefix(self, A, ground_res, k_vista, k_emo, k_wm, m):
        p = self.crc.p_ood(ground_res['u'])
        abstain = (p < self.delta) or (ground_res['margin'] < self.tau_g)
        if abstain:
            return 1, self.lam_floor, True, p       # k=1, 保守 λ
        k_ood = k_wm
        return min(k_vista, k_emo, k_wm, k_ood, m), None, False, p


# OV-RAS 在线环路（在 SimRAS 基础上改三处）
def OVRAS_round(M, obs, language_hint=None):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) 开放词汇接地：命名 + OOD 分数同源
    g = M.ovg.ground(M.vista.fir.signature(M.vista.stage.split(
        M.vista.residual_log)), extract_face(img), x_prime)

    # 2) 语言提示注入先验（命名即预演）
    if language_hint:
        M.efs.inject_prior(M.ovg.psi([language_hint]))

    # 3) ACH + WM-OV：概念条件滚动
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    e_top = M.ovg.E[g['topk'][0]]
    wm_preds = M.wm_ov.rollout(x_prime, A, e_c=e_top, k=5)

    # 4) EFS：开放假设集（含 H_∅）
    Hs, prior_null = M.ohm.hypotheses(g)
    joint_post = M.efs.synthesize_open(Hs, g, wm_preds, prior_null)

    # 5) C-OV：共形认证前缀 + 弃权
    k, lam_override, abstain, p_ood = M.cov.prefix(
        A, g, M.k_vista(A, joint_post), M.k_emo(joint_post),
        M.k_wm(wm_preds), M.m)
    lam = lam_override if lam_override is not None else M.efs.risk_scale(joint_post)

    # 6) 控制 + 新颖场景入库（等待人类命名）
    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau_cmd = M.ers_ov.shaping(tau_cmd, joint_post, language_hint)
    if abstain:
        M.novelty_buf.push({'u': g['u'], 'obs': obs, 'o': x_prime})
    return k, lam, abstain, p_ood, joint_post, g
```

## 3. 推导

**引理 13（弃权假设消除「闭合假安全」）**
设新故障 `f*` 与概念库的最大匹配 `s_max(f*) ≤ 1-γ`，而分布内样本满足 `s_max ≥ 1-γ_in` 且 `γ > γ_in`。则存在阈值使 `u(f*) = 1-s_max(f*) ≥ γ > 1-γ_in ≥ u(in-dist)`。于是 `H_∅` 的后验在 `f*` 上单调上升，`P(H0|f*) ≤ 1 - P(H_∅|f*)`，闭合归一化不再把未知推给 H0。**直觉：只要「未知」有自己的抽屉，它就不会被塞进「正常」的抽屉。**

**引理 14（加权共形的偏移覆盖）**
若密度比估计满足 `E|ŵ(x) - w(x)| ≤ ε_w`，则加权共形的实际覆盖满足 `P(R > α) ≤ δ + ε_w/2 + α_ground`（`α_ground` 为概念接地的固有误判）。**直觉：共形保证可以「借」到新分布，但借得越远（权重估计越差）利息越高。**

**定理 14（OV-RAS 端到端风险一致性）**
在定义 281 的加权共形、定义 282 的 WM-OV 误差界、定义 279 的新颖度可分离性下，OV-RAS 输出满足：
1. `P(R > α) ≤ δ + α_chunk + α_ground + α_wm + ε_w/2`；
2. 若 `p_ood < δ` 或 `m < τ_g`，则 `λ_risk ≤ λ_floor = 0.6 ∧ k = 1`（弃权即最保守，绝不「因未知而放行」）；
3. `H_∅` 后验单调反映概念失配，`P(H0 | novel) ≤ 1 - P(H_∅ | novel)`。

**定理 15（开放词汇完整性的样本复杂度）**
设新故障 `f*` 与库中概念的间隔为 `γ`，用 `n` 个标定样本估计 `u` 的分布。若用 Hoeffding 界，则把 `f*` 误吸收入 H0 的概率满足 `P(absorb) ≤ 2·exp(-2nγ²) + α_ground`。取 `γ=0.1, n=500` 即可把误吸收压到 `<1e-4` 量级。**直觉：新颖度只需要「离得够远」和「看得够多次」两件事。**

**定理 16（组合 OOD 的泛化界）**
设 WM-OV 对因子可分解，组合误差满足 `E_ood ≤ E_iid + Σ_{未见面因子} Lip(factor_i)·gap_i`。当因子共享表示（同一编码器）时，`E_ood` 随留出组合数亚线性增长；若 WF 用概念条件而非独立头，则 `gap_i` 被 `d(e_c, e_seen)` 上界。**直觉：组合泛化不是魔法，它取决于「没见过的那个因子」与「见过的因子」在语言空间里有多近。**

**定理 17（零样本命名故障的风险预测界）**
对由短语 `ℓ` 指定的未见故障 `c*`，`|R_WM(c*) - R_true(c*)| ≤ ε_WM + L_ψ·d(e_{c*}, e_{NN})`，其中 `e_{NN}` 是库中最近概念嵌入。**直觉：命名越贴近已知故障族，零样本预演越准；「小心夹爪勾布」比「小心」有用，正因为后者离所有概念都远。**

## 2. 形式化定义（完整版）

**定义 276（开放词汇概念库）** 概念库 `C = C_fault ∪ C_emotion ∪ C_risk`，每个概念 `c_j` 有文本嵌入 `e_j = ψ(c_j) ∈ S^{d-1}`。概念库带版本 `ver_C`，支持运行时由人类新增短语；任何增广都必须触发定义 287 的重标定。

**定义 277（概念接地分数）** 对观测 `o_t = (ρ_t, face_t, z_t)`：
```
s_j(t) = <φ(o_t), e_j> / τ,   φ(o_t) ∈ S^{d-1}
π_c(j | o_t) = softmax_j(s_j(t))
```

**定义 278（开放假设集与弃权假设）**
```
ℋ_open(t) = TopK_{j∈C_fault}(s_j(t)) ∪ {H0, H_∅}
```
`H_∅` 表示「无概念可解释」，其先验证据 `p_null = max(0, 1 - Σ_{j∈TopK} π_c(j|o_t))`。后验在 `ℋ_open` 上归一化，因此 `P(H0|novel)` 不再被闭合性结构性推到 1。

**定义 279（新颖度 / OOD 分数）**
```
u(t) = 1 - max_j s_j(t) ∈ [0, 2]
```
`u` 与接地共用同一套内积，不需要第二个检测模型。

**定义 280（共形新颖度 p 值）** 给定标定集 `{u_i^cal}_{i=1..n}`：
```
p_ood(t) = (1 + #{i : u_i^cal ≥ u(t)}) / (n + 1)
```
`p_ood < δ` 判为 OOD。

**定义 281（加权共形风险控制）** 设密度比 `w(x)=p_tgt(x)/p_cal(x)`，归一化 `w̃_i = w(x_i)/Σ_k w(x_k)`：
```
λ̂ = inf{ λ : Σ_i w̃_i · 1[R_i(λ) ≤ α] ≥ 1 - δ }
```
加权分位数给出协变量偏移下的近似边际覆盖。

**定义 282（概念条件世界模型 WM-OV）**
```
WM_θ(z_t, e_c) → (π_{t+1}, P(H_{t+1}))
```
对仅在语言中出现、训练未见的 `c*`，可直接以 `e_{c*}=ψ(c*)` 为条件零样本预演其风险轨迹。

**定义 283（组合 OOD 划分）** 概念语法 `G` 组合场景因子（材质×地形×人因×故障）。`C_train` 为训练组合集，`C_ood = {组合 ∉ C_train}`；OOD split `D_ood = {τ_sim : comp(τ_sim) ∈ C_ood}`。评测指标为组合泛化而非插值泛化。

**定义 284（语义歧义度 / 接地间隔）**
```
m(t) = s_(1)(t) - s_(2)(t)
```
`m < τ_g` 表示「像多个概念但都不确定」，触发接地弃权。

**定义 285（OV 认证前缀）**
```
k*OV = min(k_VISTA, k_emo, k_wm, k_ood)
k_ood = 0                    若 p_ood < δ 或 m < τ_g
k_ood = k_wm                 否则
```

**定义 286（弃权控制律）** 若 `p_ood < δ` 或 `m < τ_g`：
```
λ_risk ≤ λ_floor = 0.6,  k = 1
```
控制走最小力/最慢速保守策略，并把 `(o_t, u_t)` 写入 `NoveltyBuf` 等待人类命名。

**定义 287（概念库增广）** `C ← C ∪ {c_new}` 只允许在人类命名或高置信聚类后发生；增广后重算 `ψ(c_new)` 并**重跑共形标定**，防止旧 p 值失效。

**定义 288（AIC-OV 干扰与共因）**
```
ℰ_OV = ℰ_SimRAS × ℰ_ground × ℰ_shift
ℰ_ground = {概念幻觉, 同义词/多义词歧义, 对抗性短语, 组合崩塌}
ℰ_shift  = {协变量偏移, 标签偏移, 概念漂移}
```

**定义 289（J_OVRAS 证书）**
```
J_OVRAS = (J_SimRAS, ver_C, concept_topk_hash, p_ood,
           grounding_margin, conformal_lambda, coverage_delta)
```
Valid ⇔ `Valid(J_SimRAS) ∧ p_ood ≥ δ ∧ (m ≥ τ_g ∨ λ_risk ≤ λ_floor)`。

**定义 290（命名即先验）** 对外部语言指令 `ℓ`，提取候选概念 `c_ℓ`，令 `e_ℓ=ψ(c_ℓ)`：
```
P_prior(H) ← softmax_j( <e_ℓ, e_j> )
```
直接注入 EFS/FRAS 先验，无需在线数据。

**定义 291（开放词汇完整性）** 对真实新故障 `f*`，若 `max_j <φ(f*), e_j> ≤ 1-γ`，则 `P(H0|f*) ≤ 1 - P(H_∅|f*)`；`γ` 越大，新颖度越可分离。

**定义 292（OV-RAS 总览）**
```
OV-RAS = (OVCB, OVG, OHM, CRC, WM-OV, SimEngine-OV, C-OV, ERS-OV, NoveltyBuf)
```
不变式：概念库增广与共形重标定只在离线段；实时流只做前向内积、p 值查表与弃权判定，零梯度写。

# IP-243/244 OVCB + OVG
class OpenVocabGrounding:
    def __init__(self, text_encoder, phi, concepts, tau=0.07):
        self.psi, self.phi, self.tau = text_encoder, phi, tau
        self.C = list(concepts)
        self.E = normalize(text_encoder(self.C))          # [|C|, d]
        self.ver = 0

    def ground(self, rho, face_feat, z):
        o = normalize(self.phi(rho, face_feat, z))
        s = (self.E @ o) / self.tau
        post = softmax(s)
        top1, top2 = torch.topk(s, 2).values
        return {'s': s, 'post': post,
                'u': 1.0 - top1.item(),
                'margin': (top1 - top2).item(),
                'topk': torch.topk(s, 8).indices.tolist()}

    def augment(self, new_concept):
        self.C.append(new_concept)
        self.E = normalize(self.psi(self.C))
        self.ver += 1


# IP-245 OHM：开放假设管理
class OpenHypothesisManager:
    def hypotheses(self, g, K=5):
        idx = g['topk'][:K]
        Hs = [f"H_{j}" for j in idx] + ["H0", "H_NULL"]
        p_known = float(sum(g['post'][j] for j in idx))
        p_null = max(0.0, 1.0 - p_known)
        return Hs, {'H_NULL': p_null}


# IP-246 CRC：共形风险控制（含加权）
class ConformalRiskController:
    def __init__(self, delta=0.05, alpha=0.05):
        self.delta, self.alpha = delta, alpha
        self.u_cal, self.w_cal, self.lam_hat = [], [], 0.5

    def calibrate(self, u_cal, risks_fn, weights=None):
        self.u_cal = sorted(u_cal)
        w = weights or [1.0] * len(u_cal)
        z = sum(w)
        self.w_cal = [wi / z for wi in w]
        for lam in [0.5 + 0.05 * i for i in range(15)]:
            keep = sum(wi for u, wi in zip(self.u_cal, self.w_cal)
                       if risks_fn(u, lam) <= self.alpha)
            if keep >= 1 - self.delta:
                self.lam_hat = lam
                break
        return self.lam_hat

    def p_ood(self, u):
        n = len(self.u_cal)
        return (1 + sum(1 for v in self.u_cal if v >= u)) / (n + 1)


# IP-247 WM-OV：概念条件世界模型
class ConceptConditionedWorldModel(WorldModel):
    def rollout_cond(self, obs_t, act_seq, e_c, k=5):
        z = self.enc(obs_t.half())
        preds = []
        for a in act_seq[:k]:
            z = self.dyn(z, a.half(), e_c.half())   # 概念注入动力学
            pi = self.emo(z)
            pH = self.fault(z)
            lam = 1 - 0.3 * self.risk_emotion(pi) - 0.2 * self.risk_fault(pH)
            preds.append({'pi': pi.float(), 'pH': pH.float(),
                          'lambda': lam.float()})
        return preds

class CompositionalSimEngine(SimEngine):

        while len(ood) < n:
            comp = grammar.sample()
            if comp not in seen_comps:
                ood.append(self.generate_trajectory(
                    self.policy, self.scene_from(comp)))

# IP-249 EFS-OV：开放假设集上的联合后验
class EmotionFaultSynthesisOV(EmotionFaultSynthesis):
    def synthesize_open(self, Hs, g, wm_preds, prior_null):
        post = {}
        for i, h in enumerate(Hs):
            p_h = float(g['post'][g['topk'][i]]) if h.startswith('H_') and h != 'H_NULL' else None
            if h == 'H_NULL':
                p_h = prior_null['H_NULL']
            elif h == 'H0':
                p_h = 0.05
            # WM-OV 时序先验
            for j, pred in enumerate(wm_preds):
                w = math.exp(-(j + 1) / 3.0)
                p_h = p_h * float(pred['pH'].get(h, 1e-3) ** (w * 0.1))
            post[h] = p_h
        return normalize(post)


# IP-250 C-RAS-OV：开放词汇认证前缀 + 弃权
class CertifiedOpenVocab:
    def __init__(self, crc, delta=0.05, tau_g=0.05, lam_floor=0.6):
        self.crc, self.delta = crc, delta
        self.tau_g, self.lam_floor = tau_g, lam_floor

    def prefix(self, A, g, k_vista, k_emo, k_wm, m):
        p = self.crc.p_ood(g['u'])
        abstain = (p < self.delta) or (g['margin'] < self.tau_g)
        if abstain:
            return 1, self.lam_floor, True, p
        return min(k_vista, k_emo, k_wm, m), None, False, p


# IP-253 OV-RAS 在线闭环
def OVRAS_round(M, obs, language_hint=None):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))

    # 1) 开放词汇接地：命名 + OOD 同一套内积
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    g = M.ovg.ground(rho, extract_face(img), x_prime)

    # 2) 命名即先验（可选语言提示）
    if language_hint:
        M.efs.inject_prior(M.ovg.psi([language_hint]))

## 4. 推导

**引理 13（弃权假设消除「闭合假安全」）** 设新故障 `f*` 与概念库最大匹配 `s_max(f*) ≤ 1-γ`，分布内样本 `s_max ≥ 1-γ_in`，且 `γ > γ_in`。则 `u(f*) ≥ γ > 1-γ_in ≥ u(in-dist)`，`P(H_∅|f*)` 单调上升，且
```
P(H0 | f*) ≤ 1 - P(H_∅ | f*)
```
闭合归一化不再把未知推给 H0。

**引理 14（加权共形的偏移覆盖）** 若 `E|ŵ(x)-w(x)| ≤ ε_w`，则
```
P(R > α) ≤ δ + ε_w/2 + α_ground
```
其中 `α_ground` 为概念接地的固有误判。

**定理 14（OV-RAS 端到端风险一致性）** 在定义 281 的加权共形、定义 282 的 WM-OV 误差界、定义 279 的新颖度可分离性下：
1. `P(R > α) ≤ δ + α_chunk + α_ground + α_wm + ε_w/2`；
2. `p_ood < δ ∨ m < τ_g ⇒ λ_risk ≤ 0.6 ∧ k = 1`（弃权即最保守）；
3. `P(H0|novel) ≤ 1 - P(H_∅|novel)`（未知不被吞入正常）。

**定理 15（开放词汇完整性的样本复杂度）** 设新故障与库中概念间隔 `γ`，`n` 个标定样本，则
```
P(absorb) ≤ 2·exp(-2nγ²) + α_ground
```
取 `γ=0.1, n=500` 时误吸收 `<1e-4` 量级。

**定理 16（组合 OOD 泛化界）** 设 WM-OV 因子可分解：
```
E_ood ≤ E_iid + Σ_{未见面因子} Lip(factor_i)·gap_i
```
若用概念条件共享编码器，则 `gap_i` 被 `d(e_c, e_seen)` 上界，`E_ood` 随留出组合数亚线性增长。

**定理 17（零样本命名故障的风险预测界）** 对短语 `ℓ` 指定的未见故障 `c*`：
```
|R_WM(c*) - R_true(c*)| ≤ ε_WM + L_ψ·d(e_{c*}, e_NN)
```
命名越贴近已知故障族，零样本预演越准。

## 7. 本轮最大风险

**一句话**：OV-RAS 的全部安全性建立在「开放词汇接地能把未知故障推离所有已知概念、从而触发 `H_∅` 或弃权」之上，但语义幻觉与分布外样本恰恰可能被**高置信地匹配到一个无害的已知概念**（如把「夹爪勾住织物」接成「正常接触」、把「地面下陷」接成「正常落地」），此时 `u` 很小、`p_ood` 不触发、加权共形又在 OOD 下失去可交换性——系统会以**看似有保证的高 `λ_risk` 放行真正的新故障**，即「开放词表反而给了误判一个更体面的理由」。
