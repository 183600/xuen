# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「动力学」×「个性化交互」）

> R69 让系统学会了「问」，但被问的那个「谁」是一个**匿名、静止、单次的应答器**：它有一个固定的欺骗率 δ_p，问一次得到一条似然，再用「k 个正交源一致」把投毒压下去。这个抽象在两处失真：
> - **它没有动力学**：合作者是一个会疲劳、会紧张、会因被反复追问而变得敷衍甚至敌意的**动力系统**；机器人自己的探询就是输入，回答是输出，信任是隐藏状态。R69 的 VoI 是无记忆的一步决策，不知道「问」会改变「还能不能问」；它也没有用上机器人最诚实的一条通道——**物理动力学**（接触、力、惯量）本身就能证伪一个视觉上很合理的假设。
> - **它没有个性化**：不同的人/机器人/模拟器在**不同模态上的可靠性完全不同**——有人看得准但说不清，有人嘴甜但常错，有人慢却很稳。R69 用同一个群体先验和同一个 k 处理所有人：对可靠专家太啰嗦，对自信的吹牛者太轻信。
>
> 核心命题：**把「合作者」建模成一个非平稳、可个性化的潜动力系统，把「交互」建模成在信任资本与疲劳动力学约束下的闭环最优控制；个性化只用来重配证据权重与提问方式，绝不越过按严重度设定的信任天花板。** 命名 **TEMPO-RAS**（Trust-Evolving Multimodal Personalized Orchestration for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个特定的人此刻还值得信吗、我该用什么方式、在什么时机问他，才不至于把他也问坏**」——信任不是静态标签，而是一种会被赚取、被消耗、也会被养坏的动力学量。

## 0. 直觉与动机

**灵感 1（动力学 → 合作者与探询都是动力系统）**
直觉：R69 把人当成「每次独立掷骰子」的 oracle。真实协作里，人的状态有惯性和疲劳：疲劳降低可靠性，被反复质疑降低配合意愿，一次成功又提高耐心与信任。于是「问」不是免费的、一次性的信息抽取，而是对一个动力系统的**输入**；它的价值必须放在闭环、跨时的眼光下计算。更进一步，机器人自身的**物理动力学**是独立于人类说辞的第二证据源：接触刚度、力—位移响应、惯量辨识，都能直接证伪一个「看起来对」的物体假设——物理不会撒谎，也不会疲劳。动力学因此同时补上 R69 的两处空白：**信任的演化**与**物理的证伪**。

**灵感 2（个性化交互 → 同一个问题对不同人价值不同）**
直觉：R69 的「k 个正交源一致」是群体层面的防御，代价是忽视个体差异。一个在视觉上一贯精准的专家，问一次就该接近定案；一个总在动力学判断上过度自信的新手，问十次也可能只是十个相关的错误。个性化还能决定**怎么问**：这个人吃短问句、那个人需要看示意图；此刻他正忙、换个时机问成本更低。个性化让交互更省、更准、更不烦人。

**灵感 3（合流的真正难点：个性化是内生的，会被反噬）**
直觉：如果系统按「谁让我更确定」来加权，它会逐渐只信那些**顺着它**的人——这就是回音室与谄媚陷阱；如果系统按「多问就多信息」来优化，它会把人问到疲劳、敷衍甚至敌意，把自己唯一的信息源**耗尽**；如果有人先可靠 k 次骗取信任、再撒一个高价值谎，个性化恰好把那一次谎放大到最大。R69 的静态 k 一致对这些**自适应攻击**无能为力，因为它假设欺骗率不变、来源独立。R70 因此必须同时交付：**信任天花板（单源永远不能独立定高严重度案）+ 变化点检测（截断「养熟再背叛」）+ 信任资本上限（把最坏损失变成有界量）+ 多样性下限（个性化不得抹平真实歧义）。**

**灵感 4（严格包含：个性化只是先验，不是许可证）**
直觉：R70 必须像 R69 包含 R68 那样包含 R69。做法是把「不个性化、静止信任、单步交互、忽略疲劳」定义成 R70 的边界：此时 TEMPO 逐指令退化为 FLUID-RAS。并且在高严重度决策上，无论信任多高，单源贡献被信任天花板截断，决策规则与 R69 的 k 一致**逐指令相同**。个性化只在低/中严重度上换效率；安全侧单调不降。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TEMPO-RAS 总览）** TEMPO-RAS = (TDM, PEC, TIPO, DVO, CPG, DFE, TCC, RAS-WM††)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **信任不得越过安全**：个性化仅重配证据权重与交互形式，任何单源对严重度 ≥ s_crit 的 claim 的贡献被信任天花板 w_cap 截断，高严重度决策规则与 R69 的 k 源一致逐指令相同；
(iii) **信任估计可被证伪**：信任状态必须附带变化点检测与信任资本上限，任一触发即冻结个性化、退回 R69 群体先验。

**定义 311（合作者潜动力系统 TDM）** 每个合作者 c 有隐藏状态 h_c(t) ∈ ℝ^d（分量对应各模态胜任度、诚实度、时延、压力敏感度、一致性）。演化为
h_c(t+1) = f_φ(h_c(t), u_t, e_t) + w_t, w_t ~ 𝒩(0,Q)；回答/响应 y_t ~ p_ψ(· | h_c(t), u_t, o_t)，
其中 u_t = (g_t, tempo_t) 是交互输入（问什么 + 以什么节奏/方式问），e_t 是环境/任务上下文。f_φ, p_ψ 冻结；实时只做**前向滤波** b_t(h_c) = P(h_c(t) | y_{0:t})，不做梯度写。这把 R69 的静态欺骗率 δ_p 升级为一条可观测、可预测、可检测突变的轨迹。

**定义 312（个性化证据可靠度与有效源数）** 对合作者 c 的源/模态 i，可靠度 ρ_{c,i}(t) = P(回答正确 | 源 i, h_c(t))，由 b_t(h_c) 读出并校准。证据以温度化似然比融合：后验 ∝ 先验 × Π_i LR_i^{ρ_{c,i}}。定义**有效证据源数**
k_eff(c,t) = (Σ_i ρ_{c,i})² / Σ_i ρ_{c,i}² ∈ [1, |ℰ|]，
把 R69 的整数 k 变成随人与模态变化的连续量：专家问 1–2 次即可，生手/夸口者需要更多**正交**源。系：个性化在低严重度上把「统一 k」换成「按人 k_eff」，正是 R69 效率损失的来源。

**定义 313（信任天花板与严重度门）** 设 claim 的严重度为 s，单源对数似然权重被截断为
w_i ← min(w_i, w_cap(s))，w_cap(s) = log(1/ε_s)·1[s < s_crit] + w_safe·1[s ≥ s_crit]。
w_safe 保证单源最多把后验移动一个有界倍数。于是：低严重度允许「高度可信的专家一问定案」；高严重度上无论 ρ 多接近 1，仍至少需要 R69 的 k 个正交源一致。这是个性化与安全之间的**可证明分离面**。

**定义 314（个性化交互动作与响应模型）** 增广信息动作 g = (g_gaze, g_probe, g_ask, g_style, g_time)，其中 g_style（措辞/语言寄存器/图示）与 g_time（相对合作者认知负荷与疲劳的时机）是**个性化新增维度**。响应分布 p(y | g, c, h_c) 显式依赖 (c, h_c)：同一条问题，对不同人、不同疲劳状态，成本与信息量都不同。

**定义 315（动力学感知的闭环 VoI，DVO）** 令信念 b_t 在交互与任务执行下按 TDM 前推。定义 H 步价值
VoI_H(g_{t:t+H}) = E[ Σ_{τ=t}^{t+H} γ^{τ−t}( H(M_τ|o_τ) − E_{y_τ}[H(M_τ|o_τ,y_τ)] ) ] − Σ_τ c(g_τ; c, h_c)，
s.t. 安全认证、预算、疲劳约束。R69 的一步 VoI 是 H=1、h_c 静止、无观测效应的特例。关键：**问会把 h_c 推向更好或更差的状态**（定义 316），所以「现在多问一句」会扣减「以后还能问」的价值。

**定义 316（交互疲劳与观测效应）** 疲劳/配合度状态 z_t ⊂ h_c 满足
z_{t+1} = clip(z_t + α·n_ask(t) − β·1[成功且低打扰], 0, 1)，ρ_{c,i}(t) = ρ̂_{c,i}·(1 − κ z_t)。
过度追问单调降低可靠度；成功且低打扰的协作可缓慢恢复。于是交互是一个**会消耗自身信息源**的控制问题，最优策略不是「能问就问」，而是「在信任资本耗尽前问到关键处」。

**定义 317（信任资本与花费/再生动力学，TCC）** 合作者 c 的信任资本 C_c(t) ≥ 0 随可信互动积累、随高打扰/高风险探询消耗：
C_c(t+1) = clip(C_c(t) + r_c(成功,低打扰) − spend(g_t), 0, C_max)。
设**伤害上界不变式**：任何一次被采纳的谎言造成的损失 ≤ C_c(t)（可花费的信任是有限抵押）。把 C_max 设为单次高严重度 claim 的最大可接受损失，则「养熟再背叛」的最坏伤害有界。高严重度查询优先花费资本；低价值歧义先用自己的动力学/物理证据。

**定义 318（变化点守卫 CPG）** 在交互残差 r_t = 预测回答 − 实际回答（及一致性、时延、语气）上跑 CUSUM/贝叶斯变化点检测。累计对数似然比超阈值 b 即报警并执行：冻结个性化 → 退回 R69 群体先验 → 提高 w_cap 保守度 → 触发身份再认证。检测延迟与最坏伤害上界由引理 21 给出。

**定义 319（动力学证据与幻影模态过滤，DFE）** 用机器人自身动力学/接触模型构造独立证据：
r_dyn^{(m)} = y_force/torque − ĝ_dyn(m, u_probe)，
其似然 p(r_dyn | m) 直接为候选模态 m 投票（物质/质量/摩擦/柔顺性）。同时对流策略采样的每个模态做**动力学可行性过滤**：违反接触/力/位/惯量约束的样本判为不可行。记过滤后的模态质量 m_k^feas，得 U_epi^feas = H_mode(feas)·g(Δ_min(feas))。这是对 R69「流模型幻觉幻影模态」这一最大风险的**非统计**补充：即使模态权重未校准，物理不可行的幻影也会被动力学剔除。

**定义 320（个性化模态先验与多样性下限 PTP）** 允许按合作者偏好重配任务模态先验 π_c(m)，但必须满足安全相关模态的熵下限 H(π_c) ≥ H_min，且 KL(π_c ‖ π_uniform) ≤ log N_modes − H_min。否则个性化会把「人喜欢的方向」自动变成「唯一看到的方向」，造成**下游版模态坍缩/回音室**，令 U_epi 被人为压低、真实歧义被隐藏。

**定义 321（分层贝叶斯冷启动与迁移 HBT）** 信任先验 p(h_c) = ∫ p(h_c|θ) p(θ) dθ，θ 为群体超参数。冷启动用群体后验（行为 ≈ R69）；样本累积后个性化。跨任务可迁移胜任度与风格，但**跨严重度不自动迁移**：进入 s ≥ s_crit 的任务必须重新用高严重度证据验证。

**定义 322（因果信任归因）** 任务成功/失败后，信任更新只用干预/反事实证据（随机低风险探询、审计实例），不用原始相关：Δtrust ← do-演算下的信用分配。否则机器人会把自己的失败归咎于可靠的合作者，或因一次侥幸成功而信任一个骗子。

**定义 323（双时间尺度分离）** 信任/疲劳在慢时间尺度（回合级，步长 η）更新；安全认证在快时间尺度（控制步）执行。若信任更新满足 η·L_f·H < c_L，则沿任意信任轨迹，快环安全保证与 R69 一致，风险增量 O(η)。η→0 即 R69 的静止信任边界。

**定义 324（参与式审计 VQAuditor-T）** 新增审计对象：提问是否针对该人的弱点与偏好、是否在疲劳/变化点附近继续追问、信任是否被单次高价值回答异常抬高、是否存在回音室（模态熵塌缩）、身份是否连续。结论回灌 AuditBuf，作为下一轮 TDM 的先验与 TCC 的成本估计。

**定义 325（威胁模型 AIC-TEMPO）** ℰ_TEMPO = ℰ_FLUID × ℰ_groom（养熟再背叛）× ℰ_swap（身份替换）× ℰ_fatigue（诱导过劳/敷衍）× ℰ_echo（谄媚式附和）。每个子威胁对应一条防御：CPG / 身份认证 / 定义 316 的疲劳模型 / 定义 320 的多样性下限。

**定义 326（证书、严格包含与退避）** J_TEMPO = (J_FLUID, trust_calibration_ece_c, cp_alarm_rate, single_source_cap_violations, trust_capital_violations, diversity_floor_ok, identity_auth_ok, fatigue_index, trust_traj_hash, tempo_ver)。Valid ⇔ Valid(J_FLUID) ∧ ECE_c ≤ τ_ece ∧ 单源天花板违规 = 0 ∧ 资本不越界 ∧ 多样性下限满足 ∧ 身份认证通过。退避链：CPG 报警 / ECE 越界 / 身份未认证 / 资本耗尽 → 冻结个性化，逐指令退化为 R69；R69 在无利可图时再退化为 R68。故 **R68 ⊂ R69 ⊂ R70** 的包含关系在安全侧严格成立。

```python
# IP-264 TDM：合作者潜动力系统的在线前向滤波（冻结模型，零写）
class TrustDynamics:
    def __init__(self, f, g, Q, R):
        self.f, self.g, self.Q, self.R = f, g, Q, R
    def update(self, b, u, y, ctx):
        b_pred = propagate(b, self.f, u, ctx, self.Q)     # 预测 h_c(t+1)
        w      = self.g(b_pred, u, ctx)                   # 期望回答
        b_post = bayes_obs(b_pred, y, w, self.R)          # 观测更新
        return b_post, residual(y, w)                     # 残差喂给 CPG

# IP-265 PEC：按人按模态的可靠度与有效源数，并施加信任天花板
def personalized_weights(b, sources, severity):
    rho = {i: read_reliability(b, i) for i in sources}    # 定义 312
    k_eff = sum(rho.values())**2 / sum(v*v for v in rho.values())
    cap = trust_cap(severity)                             # 定义 313
    logits = {i: min(rho[i] * log_lr(sources[i]), cap) for i in sources}
    return logits, k_eff

# IP-267/270 DVO + TCC：闭环 H 步 VoI，显式计入疲劳与信任资本
def plan_interaction(modes, b, C, budget, H):
    best = None
    for g in info_action_candidates(modes, b):            # 含 g_style / g_time
        if not budget.allow(g) or not c_ras_wm.certify_info(g, b): continue
        gain = 0.0; C_h = C; b_h = b
        for t in range(H):                                # 信念与疲劳前推
            info = entropy(b_h.mode) - expected_entropy(b_h, g, t)
            gain += (0.9 ** t) * info
            C_h, b_h = C_h - spend(g, b_h), fatigue_step(b_h, g)
            if C_h <= 0: break
        score = gain - social_physical_cost(g) - capital_risk(C - C_h)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 无利可图 → R69

# IP-268 CPG：交互残差上的变化点/养熟背叛检测
class ChangePointGuard:
    def __init__(self, thresh): self.s, self.b = 0.0, thresh
    def step(self, resid):
        self.s = max(0.0, self.s + log_lr(resid))         # CUSUM
        if self.s > self.b:
            self.s = 0.0
            return True                                   # 冻结个性化
        return False

# IP-269 DFE：动力学证据 + 幻影模态过滤
def dynamics_filter(modes, probe, dyn_model):
    feasible = [m for m in modes if dyn_model.feasible(m, probe)]
    ll = {m: dyn_model.loglik(probe.force - dyn_model.predict(m, probe))
          for m in feasible}
    return feasible, ll                                   # 物理不可行 → 幻影剔除

# IP-276 主闭环（继承 R69，仅在信任处置处插入 TEMPO 层）
def TEMPO_RAS_round(M, obs, collaborator, severity):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    b, resid = M.tdm.update(M.b_prev, M.last_u, collaborator.answer, o)  # 1) 信任滤波
    alarm = M.cpg.step(resid)
    # 2) 信任可信？不可信则冻结个性化，退回 R69 群体先验
    frozen = alarm or not M.identity.ok(collaborator) or M.pec.ece(b) > TAU_ECE
    w, k_eff = (personalized_weights(b, M.sources, severity) if not frozen
                else population_weights(M.sources))
    # 3) 动力学证据先剔除物理幻影，再算个性化歧义
    modes, dyn_ll = M.dfe.dynamics_filter(M.aud.modes, M.last_probe, M.dyn)
    U_ale, U_epi = M.aud.decompose(modes, z, M.fmp.mode_head)
    # 4) 闭环 VoI（含疲劳/资本）；高严重度查询优先花资本
    g = None
    if not frozen and U_epi > TAU_EPI:
        g = M.dvo.plan_interaction(modes, b, M.tcc.capital(collaborator),
                                   M.budget, H=M.vista.H)
    # 5) 执行交互并更新信念/资本；证据纪律按 k_eff 与严重度门
    if g is not None:
        y = M.tipo.execute(g, collaborator)               # 看/问/触/风格/时机
        modes = M.cia.update_belief(modes, y, logits=w, severity=severity)
        M.tcc.spend(collaborator, g); U_epi = M.cia.residual(modes)
    # 6) 两级保守退避：冻结/未消解 → U_epi 视同 aleatoric
    U_floor = U_ale + (U_epi if (frozen or g is None) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if frozen: lam = max(lam, 0.8)
    mode = select_mode(modes, U_epi, lam)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    M.vqa_t.submit_async(g, b, U_epi, alarm, M.tcc.capital(collaborator))
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（个性化证据增益与有效源数）** 在局部平稳、可靠度已校准的窗口内，以 ρ_i 温度化融合 k 个源的期望对数似然比为 Σ_i ρ_i·D_i（D_i 为单源 KL 散度）。令源可靠度均值为 ρ̄，则达到同一后验熵所需的源数满足 k_req ≈ k_eff^{-1}·k_uniform，其中 k_eff = (Σρ_i)²/Σρ_i²。系：**当一个个体的可靠度分布越集中（少数模态很强），个性化省下的提问次数越多；当可靠度彼此接近，k_eff≈k，个性化自动退化为 R69 的统一 k。**

**引理 20（信任天花板的安全保证）** 若单源对数似然权重 w_i ≤ w_safe，则任何单个被污染的源把后验从真模态翻转所需的基础概率下界为 ε_s = e^{−w_safe}（相对先验比）。因此在高严重度集合上，TEMPO 的错误采纳率与「该源可靠度恒等于群体值」的 R69 相同，个性化只能降低低严重度情形的错误率，不能抬高任意严重度下的事故率。系：**信任是证据的先验，不是安全约束的松弛量。**

**引理 21（养熟背叛的检测延迟与伤害上界）** 设背叛后每次交互的对数似然比增量为 δ_g > 0、正常漂移均值为 μ_0 < δ_g，CUSUM 阈值 b，则由 Wald 近似，期望检出的背叛样本数 E[N] ≤ (b + c)/(δ_g − μ_0)。又由定义 317 的伤害不变式，报警前累计可采纳的谎言损失 ≤ C_max。取 b ∝ C_max 即可把「养熟再背叛」的最坏伤害压到与一次高严重度损失同阶。系：**个性化不能防止背叛，但能让背叛的损失有界且可预算。**

**引理 22（动力学过滤的幻影剔除）** 设幻影模态由忽略接触/力约束的流模型采样产生，记其满足机器人动力学可行性约束的比例为 φ < 1（A99：幻影不满足接触可行性）。则一次 DFE 过滤后幻影模态质量至少下降 (1−φ) 的比例；若幻影与真模态在动力学残差上可分（A100），则 U_epi^feas 中幻影贡献的期望 ≤ (1−φ)·U_epi。系：**R69 用统计校准防幻影，R70 多了一条完全独立的物理否决权——即使模态权重错得离谱，物理不可行的动作也不会被追问。**

**定理 18（双时间尺度下的安全保持）** 若信任/疲劳更新满足 η·L_f·H < c_L，且信任只经定义 313 的截断权重进入决策，则沿任意信任轨迹，快环的 C-RAS-WM 认证与 λ_floor 保证成立，TEMPO 的期望风险 ≤ R69 的风险 + O(η)。当 η→0（冻结个性化）时风险差为 0。证明要点：把慢变量 h_c(t) 视为在快环一个控制周期内为常数的有界扰动，代入 R69 定理 16–17 的鲁棒性余量。

**定理 19（严格包含 R68 ⊂ R69 ⊂ R70）** 在 A99–A100 下，TEMPO 取边界「信任=群体先验、H=1、忽略疲劳、无动力学证据」时与 FLUID-RAS 逐指令相同；FLUID-RAS 在「永不交互」时与 CALM-RAS 逐指令相同。且对任意 s ≥ s_crit，信任天花板使 TEMPO 的决策规则等同于 R69 的 k 源一致。故安全侧不减，个性化只在 s < s_crit 上带来效率增益。

**定理 20（回音室/模态坍缩的界）** 若无多样性下限，重复「按合作者偏好重配模态先验 → 采样偏好模态 → 合作者偏好被强化」的正反馈，可使 H(π_c) → 0，令 U_epi 被低估至 0、系统对真实歧义失明。施加 H(π_c) ≥ H_min 后，个性化先验相对均匀先验的 KL 被限制在 log N_modes − H_min 内，故 U_epi 的低估量有界；在 H_min 处系统退化为 R69 的均匀先验。系：**个性化必须留一扇「不讨人喜欢」的窗，否则它会把不确定性优化掉，而不是解决掉。**

## 6. 本轮最大风险

**一句话**：TEMPO 的全部效率收益押在「个性化信任估计正确」这一前提上，而信任是**内生**的——系统自己的追问会改变合作者的可靠度（疲劳、反感、谄媚），所以朴素优化器会学会「把人问到枯竭」或「把顺着自己的人养成唯一可信源」，最终把 R69 的「问错」升级成「**亲手养出一个会说谎的专家**」。

**次级风险与缓解**：
1. **养熟再背叛/身份替换** → CPG + 伤害不变式（定义 317–318）+ 身份认证 + 引理 21；
2. **回音室与模态坍缩** → 多样性下限与 KL 预算（定义 320、定理 20）；
3. **个性化过拟合/冷启动偏差** → 分层贝叶斯 + 跨严重度不迁移（定义 321）；
4. **信任更新被相关而非因果污染** → 干预式归因与随机审计（定义 322）；
5. **物理动力学模型自身失配** → DFE 只作否决权不作唯一证据；失配时退回 R69 统计证据（定义 319、定理 18）。

```python
class TrustDynamics:
    def update(self, b, u, y, ctx):
        b_pred = propagate(b, self.f, u, ctx, self.Q)
        w      = self.g(b_pred, u, ctx)
        b_post = bayes_obs(b_pred, y, w, self.R)
        return b_post, residual(y, w)                # 残差 → CPG

# IP-265 PEC：按人按模态可靠度 + 信任天花板
def personalized_weights(b, sources, severity):
    rho  = {i: read_reliability(b, i) for i in sources}
    k_eff = sum(rho.values())**2 / sum(v*v for v in rho.values())
    cap  = trust_cap(severity)                       # 定义 313
    return {i: min(rho[i]*log_lr(sources[i]), cap) for i in sources}, k_eff

# IP-267/270 DVO + TCC：闭环 H 步 VoI，含疲劳与资本消耗
def plan_interaction(modes, b, C, budget, H):

    for g in info_action_candidates(modes, b):       # 含 g_style / g_time
        if not budget.allow(g) or not c_ras_wm.certify_info(g, b): continue

    alarm = M.cpg.step(resid)
    frozen = alarm or not M.identity.ok(collaborator) or M.pec.ece(b) > TAU_ECE
    w, k_eff = (personalized_weights(b, M.sources, severity) if not frozen
                else population_weights(M.sources))
    modes, dyn_ll = M.dfe.dynamics_filter(M.aud.modes, M.last_probe, M.dyn)
    U_ale, U_epi = M.aud.decompose(modes, z, M.fmp.mode_head)
    g = (M.dvo.plan_interaction(modes, b, M.tcc.capital(collaborator), M.budget, M.vista.H)
         if (not frozen and U_epi > TAU_EPI) else None)
    if g is not None:
        y = M.tipo.execute(g, collaborator)
        modes = M.cia.update_belief(modes, y, logits=w, severity=severity)
        M.tcc.spend(collaborator, g); U_epi = M.cia.residual(modes)
    U_floor = U_ale + (U_epi if (frozen or g is None) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if frozen: lam = max(lam, 0.8)
    mode = select_mode(modes, U_epi, lam)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    M.vqa_t.submit_async(g, b, U_epi, alarm, M.tcc.capital(collaborator))
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（个性化证据增益）** 局部平稳且可靠度已校准时，以 ρ_i 温度化融合的期望对数似然比为 Σρ_i D_i；达到同一后验熵所需源数约按 1/k_eff 缩放，`k_eff=(Σρ_i)²/Σρ_i²`。可靠度越集中（少数模态很强），个性化省下的提问越多；可靠度接近时 k_eff≈k，自动退化为 R69 的统一 k。

**引理 20（信任天花板安全）** 单源权重 ≤ w_safe ⇒ 单源污染翻转后验所需基础概率 ≥ e^{−w_safe}。故高严重度集合上 TEMPO 的错误采纳率与 R69 相同，个性化只能改善低严重度，不能抬高任意严重度事故率。系：信任是证据先验，不是安全松弛量。

**引理 21（养熟背叛上界）** 背叛后增量 δ_g、正常漂移 μ_0<δ_g、阈值 b 时，CUSUM 期望检出样本数 E[N] ≤ (b+c)/(δ_g−μ_0)；伤害不变式给出报警前累计损失 ≤ C_max。取 b∝C_max 即把最坏伤害压到一次高严重度损失同阶。

**引理 22（动力学幻影剔除）** 幻影不满足接触可行性（A99）；DFE 过滤后幻影质量至少降 (1−φ)。若幻影与真模态在动力学残差上可分（A100），U_epi^feas 中幻影贡献期望 ≤ (1−φ)·U_epi。系：统计校准防幻影之外，多了一条物理否决权。

**定理 18（双时间尺度安全保持）** `η·L_f·H<c_L` 且信任仅以截断权重进入时，快环 C-RAS-WM 与 λ_floor 保证沿信任轨迹成立，风险 ≤ R69 + O(η)；η→0 时差为 0。

**定理 19（严格包含 R68⊂R69⊂R70）** 边界「信任=群体先验、H=1、忽略疲劳、无动力学证据」时 TEMPO 与 FLUID-RAS 逐指令相同；FLUID-RAS「永不交互」时与 CALM-RAS 相同；且 s≥s_crit 时信任天花板使决策规则等价于 R69 的 k 源一致。

**定理 20（回音室界）** 无多样性下限时，偏好重配→采样偏好模态→偏好强化的正反馈可使 H(π_c)→0、U_epi 被低估至 0。施加 H(π_c)≥H_min 后 KL 被限制在 logN_modes−H_min 内，U_epi 低估有界；H_min 处退化为 R69 均匀先验。系：个性化必须留一扇「不讨人喜欢」的窗。

## 7. 本轮最大风险

**一句话**：TEMPO 的全部效率收益押在「个性化信任估计正确」这一前提上，而信任是**内生**的——系统自己的追问会改变合作者的可靠度（疲劳、反感、谄媚），所以朴素优化器会学会「把人问到枯竭」或「把顺着自己的人养成唯一可信源」，最终把 R69 的「问错」升级成「**亲手养出一个会说谎的专家**」。

**次级风险与缓解**：养熟再背叛/身份替换（CPG + 伤害不变式 + 身份认证 + 引理 21）；回音室与模态坍缩（多样性下限与 KL 预算，定理 20）；个性化过拟合/冷启动偏差（分层贝叶斯 + 跨严重度不迁移）；信任更新被相关污染（干预式归因 + 随机审计）；物理模型失配（DFE 只作否决权，失配时退回 R69 统计证据）。
