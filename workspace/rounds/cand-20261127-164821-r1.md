### 第 1 轮灵感驱动研究记录（承接 CADVS v30 谱系）

**灵感词**：手势识别、地形适应

**直觉与动机**：

先给直觉。前几轮我们造了一整套「证书链」：时序证书（TCVM）、视觉特征质量证书（FQC）、差分定位证书（DLC）、多机一致性证书（MRCC）。这些证书有一个从未被点破的共同前提——它们都在证明「系统内部的量」是可信的：时间没过期、特征没退化、定位没漂移、同伴没掉队。但它们都默默假设了一件从未被证明的事：**我们理解对了外部语境**。机器人「以为」人想让它做什么（语义语境），以及「以为」脚下是什么地面（物理语境）。

手势识别与地形适应这两个词恰好戳在这个盲点上：

1. **手势识别是「读人」**。它把一段含噪的骨骼/手部轨迹翻译成一个离散意图 g ∈ 𝒢（停、走、跟随、指向、慢行……）。它的本质是**低带宽、高语义、强歧义、随时间演化**：一个手势在完成前是不可判定的，不同用户做同一手势差异极大，遮挡与视角变化会让分类器「自信地错」。
2. **地形适应是「读地」**。它把本体感觉 + 视觉 + 接触力翻译成一个潜在地形类别 τ ∈ 𝒯（刚性、湿滑、颗粒、可变形、台阶、斜坡），并据此调整摩擦估计、步态、阻抗与 MPC 模型。它的本质是**不可直接观测、只能推断、且误判代价极高**：把薄冰误判成湿滑，可能直接导致滑倒。

**关键洞见**：手势与地形不是两个并列的新功能，而是同一个结构性缺失的两面——**语境（context）本身就是一类证书**。更尖锐地说：**语境是所有下游证书的共同祖先**。若 θ = (g, τ) 推断错了，那么依赖 θ 的一整批证书会**同时**「看起来有效」；这不是 n 个独立故障，而是一次**共模故障（common-mode failure）**。前几轮辛苦建立的证书冗余，在语境错误面前冗余度会瞬间坍缩为 1。这是本轮真正想解决的问题。

因此本轮不是「再加两个模块」，而是给证书体系补上缺失的**根节点**：Context-Certified Control（语境认证控制，C³），并把它落到**双接地（dual grounding）**——语义接地（人的意图）+ 物理接地（地的可供性）。

**严谨定义（增量）**：

- 语境空间：Θ = 𝒢 × 𝒯，θ = (g, τ)。
- 语境后验：p_t(θ) = p(θ | o_{1:t})，o 为多模态观测（骨架、深度、IMU、关节力矩、接触）。
- 语境置信集：S_δ(t) ⊆ Θ，满足（在可交换性/校准假设下）P(θ* ∈ S_δ(t)) ≥ 1−δ。实现上用**分裂共形预测（split conformal）**而非裸 softmax 阈值——这是保证「覆盖」而非「自信」的关键区别。
- 证书的语境前件：每个证书 c 携带 A_c ⊆ Θ，表示「当真实语境落在 A_c 内时，c 的推导是可靠的」。
- 语境认证有效：val_c(t) = internal_c(t) ∧ [S_δ(t) ⊆ A_c]。注意是**整个置信集被包含**，而非点估计落入——这带来保守性，但换来可靠性。
- 双接地可行集：U_adm(t) = U_CADVS(t) ∩ U_g(t) ∩ U_τ(t)，其中 U_g 为手势语义诱导的约束（如「停」→{0}），U_τ 为地形诱导的物理约束（如湿滑→加速度/步长上界）。
- 执行：u* = argmin_{u ∈ U_adm} J(u)；若 U_adm = ∅ → 分级回退（保守教师/急停）。

**为什么是「置信集包含」而非「点估计」**：直觉上，如果只信「最可能的地形是湿滑」，那当真实地形其实是「薄冰」（被误判为湿滑）时，证书依然全绿。要求整个 S_δ 都落在 A_c 内，等于说「在所有我还不能排除的语境里，这个证书都成立」。当 S_δ 因分布漂移而膨胀到 Θ 时，所有前件自动失败 → 系统自动变保守。这把「不确定性」直接变成了「安全行为」，而不是把它藏在 softmax 的一个小数里。

**形式化目标（增量）**：

1. GICK：手势后验 + 时序稳定度（margin/entropy/K 帧一致）+ 共形置信集 S_δ^g + 语义→约束映射 U_g。
2. TLCE：地形后验 + 滑移风险 + 共形置信集 S_δ^τ + 地形→模型/阈值参数化。
3. CCCA：证书代数 c_1 ⊗ c_2，前件取交、有效取合取，证明执行集单调收缩。
4. ASR-MPC：在 S_δ^τ × S_δ^g 上的歧义集鲁棒 MPC（min-max），OOD 时 S_δ = Θ 自动退化为最保守策略。
5. CMCFM：共模故障监控——当语境熵上升而证书通过率不降时，判定「疑似共模」，强制膨胀 S_δ 并降级。
6. 证明：在语境覆盖成立时 Exec_C³ ⊆ Exec_CADVS，且安全违规概率 ≤ δ_g + δ_τ + δ_CADVS（联合界）；并给出语境覆盖失败时共模故障概率下界 ε_c，说明冗余度坍缩。

**本轮最大风险**：**语境置信集的覆盖失败（coverage failure under distribution shift）**——共形预测的 1−δ 覆盖依赖可交换性；新用户的新手势、训练集外的地形（薄冰、松沙、破损台阶）会破坏可交换性，使 S_δ 虽小却**不包含真值**。此时点估计「自信且错误」，一整批依赖 θ 的证书同时被误判为有效，系统在「全绿」状态下做出语义或物理上错误的高风险动作——这比单个证书失效隐蔽得多，因为监控看到的是一片健康。

## 2. 关键算法骨架

### IP-478 Gesture Intent Certificate Kernel (GICK)

```python
@dataclass
class GestureIntentCertificateKernel:
    """GICK：手势后验 + 时序稳定度 + 分裂共形置信集 + 语义约束映射"""
    intents: list = field(default_factory=lambda: ['stop', 'go', 'follow', 'point', 'slow'])
    m_min: float = 0.35          # top1-top2 后验间隔下界
    H_max: float = 0.60          # 归一化熵上界
    K_stable: int = 5            # 连续一致帧数
    alpha: float = 0.10          # 共形显著性（覆盖 ≥ 1-alpha）
    freq_hz: int = 30

    def __post_init__(self):
        self.hist = deque(maxlen=self.K_stable)
        self.calib_scores = []   # 校准集上的非一致性分数 s = 1 - p(true)

    def posterior(self, skeleton_seq) -> np.ndarray:
        """轻量 TCN/Transformer：骨骼关键点序列 → 意图分布"""
        logits = self._temporal_net(skeleton_seq)
        return softmax(logits)

    def stability(self, p: np.ndarray) -> tuple[float, float, bool]:
        order = np.argsort(p)[::-1]
        margin = float(p[order[0]] - p[order[1]])
        H = float(-np.sum(p * np.log(p + 1e-12)) / np.log(len(p)))
        self.hist.append(int(order[0]))
        stable = (len(self.hist) == self.K_stable and len(set(self.hist)) == 1)
        return margin, H, stable

    def conformal_set(self, p: np.ndarray) -> set:
        """分裂共形：S = {g : 1 - p(g) <= q}，q 为校准分数 (1-alpha) 分位"""
        q = float(np.quantile(self.calib_scores, 1 - self.alpha))
        return {self.intents[i] for i in range(len(p)) if 1 - p[i] <= q}

    def certify(self, skeleton_seq) -> GestureCert:
        p = self.posterior(skeleton_seq)
        margin, H, stable = self.stability(p)
        S = self.conformal_set(p)
        g_star = self.intents[int(np.argmax(p))]
        # 承诺(commitment)只用于任务效率；安全路径始终使用完整 S
        committed = (margin > self.m_min and H < self.H_max
                     and stable and len(S) <= 2)
        return GestureCert(g_star=g_star, S_delta=S, margin=margin,
                           entropy=H, stable=stable, committed=committed,
                           t_stamp=time.time(),
                           validity_window=2.0 / self.freq_hz)

    def to_constraints(self, cert: GestureCert) -> ConstraintSet:
        """语义→可行域；未承诺时对 S 内所有意图取保守交集"""
        if cert.committed:
            return SEMANTIC_MAP[cert.g_star]
        return intersect([SEMANTIC_MAP[g] for g in cert.S_delta])

    def as_cert(self, cert: GestureCert) -> ContextConditionedCert:
        """接入 CCCA：前件 A_c 为『手势分布内且非对抗』"""
        return ContextConditionedCert(
            cid='kc_gesture_valid',
            internal_ok=cert.valid and cert.entropy < self.H_max,
            A=IN_DISTRIBUTION_GESTURE_CONTEXTS,
            t_stamp=cert.t_stamp,
            validity_window=cert.validity_window)
```

### IP-479 Terrain Latent Certificate Estimator (TLCE)

```python
@dataclass
class TerrainLatentCertificateEstimator:
    """TLCE：地形后验 + 滑移风险 + 共形置信集 + 跨模态一致性 + 模型参数化"""
    classes: list = field(default_factory=lambda: [
        'rigid', 'slippery', 'granular', 'deformable', 'stairs', 'slope'])
    alpha: float = 0.05
    slip_thresh: float = 0.15
    T_max: float = 0.5

    def __post_init__(self):
        self.calib_scores = []

    def posterior(self, proprio, depth, contact) -> np.ndarray:
        feat = self._fuse(proprio, depth, contact)   # 拼接/注意力融合
        return softmax(self._terrain_net(feat))

    def slip_risk(self, v_cmd, v_est) -> float:
        resid = float(np.linalg.norm(v_est - v_cmd))
        return 1.0 - float(np.exp(-resid / self.slip_thresh))

    def conformal_set(self, p: np.ndarray) -> set:
        q = float(np.quantile(self.calib_scores, 1 - self.alpha))
        return {self.classes[i] for i in range(len(p)) if 1 - p[i] <= q}

    def certify(self, proprio, depth, contact) -> TerrainCert:
        p = self.posterior(proprio, depth, contact)
        S = self.conformal_set(p)
        tau_star = self.classes[int(np.argmax(p))]
        slip = self.slip_risk(proprio.v_cmd, proprio.v_est)
        # 跨模态矛盾：视觉判刚性但本体强烈滑移 → 不信任地形后验
        cross_ok = not (tau_star == 'rigid' and slip > 0.5)
        return TerrainCert(tau_star=tau_star, S_delta=S, slip_risk=slip,
                           cross_modal_ok=cross_ok, t_stamp=time.time(),
                           validity_window=self.T_max)

    def to_model_params(self, cert: TerrainCert) -> dict:
        """在 S 上取最坏参数，供 ASR-MPC 使用（保守化）"""
        S = cert.S_delta if cert.cross_modal_ok else set(self.classes)
        return {
            'mu_min': min(TERRAIN[t].mu for t in S),
            'compliance_max': max(TERRAIN[t].compliance for t in S),
            'slope_max': max(TERRAIN[t].slope for t in S),
        }

    def as_cert(self, cert: TerrainCert) -> ContextConditionedCert:
        return ContextConditionedCert(
            cid='kc_terrain_valid',
            internal_ok=cert.cross_modal_ok and cert.slip_risk < 0.9,
            A=IN_DISTRIBUTION_TERRAIN_CONTEXTS,
            t_stamp=cert.t_stamp,
            validity_window=cert.validity_window)
```

### IP-480 Context-Conditioned Certificate Algebra (CCCA)

```python
@dataclass
class ContextConditionedCert:
    cid: str
    internal_ok: bool
    A: frozenset          # 语境前件 A_c ⊆ Θ
    t_stamp: float
    validity_window: float

def compose(c1: ContextConditionedCert, c2: ContextConditionedCert) -> ContextConditionedCert:
    """证书组合：内部条件取合取，语境前件取交（单调收缩）"""
    return ContextConditionedCert(
        cid=f'{c1.cid} ⊗ {c2.cid}',
        internal_ok=c1.internal_ok and c2.internal_ok,
        A=c1.A & c2.A,
        t_stamp=max(c1.t_stamp, c2.t_stamp),
        validity_window=min(c1.validity_window, c2.validity_window))

def context_valid(c: ContextConditionedCert, S_delta: frozenset, t_now: float) -> bool:
    """语境认证：整个置信集必须被前件包含，且未过期"""
    if not c.internal_ok or (t_now - c.t_stamp) > c.validity_window:
        return False
    return S_delta.issubset(c.A)

def context_valid_all(certs, S_delta, t_now) -> bool:
    # 等价于对组合证书做一次检查：A = ∩ A_c，internal = ∧ internal_c
    composed = reduce(compose, certs)
    return context_valid(composed, S_delta, t_now)
```

**性质**：compose 满足结合律与交换律；A 随组合单调不增，故加入证书只会缩小可行集。这给出一个格（lattice）结构，可计算「维持某动作所需的最小语境证书集」。

### IP-481 Ambiguity-Set Robust MPC (ASR-MPC)

```python
def asr_mpc_solve(x0, S_theta: frozenset, horizon: int,
                  model_fn, cost_fn, constraints) -> np.ndarray | None:
    """
    歧义集鲁棒 MPC：min_u max_{theta in S_theta} J_theta(u)
    S_theta 为 (S_delta^g × S_delta^tau) 离散化后的情景集
    """
    if len(S_theta) == 0 or S_theta == FULL_THETA:
        # OOD：置信集膨胀到全空间 → 无可信模型，退化为保守教师/急停
        return conservative_stop_or_teacher(x0)

    # 情景约简：若 |S_theta| 过大，按后验质量保留 top-B 情景 + 最坏情景
    scenarios = reduce_scenarios(S_theta, budget=16)

    best_u, best_worst = None, float('inf')
    for u_seq in candidate_sequences(x0, horizon):
        worst = max(cost_fn(model_fn(th), x0, u_seq) for th in scenarios)
        feasible = all(constraints(th, u_seq) for th in scenarios)
        if feasible and worst < best_worst:
            best_worst, best_u = worst, u_seq
    return best_u
```

> 连续语境时，用情景采样 + 情景优化界（scenario optimization）替代精确 min-max，并以 β 置信度保证约束满足；离散类别场景下即为精确枚举。

### IP-482 Dual-Grounding Execution Gate (DGEG)

```python
def dual_grounding_gate(u_cand, gic: GestureCert, tac: TerrainCert,
                        cadvs_certs, S_delta, t_now) -> ControlOutput:
    """双接地门控：语境认证 → 可行域取交 → 优先级投影"""
    # 1) 语境认证：CADVS 全部证书 + 两个语境证书的前件都必须覆盖 S_delta
    all_certs = list(cadvs_certs) + [gic.as_cert(), tac.as_cert()]
    if not context_valid_all(all_certs, S_delta, t_now):
        return fallback_conservative_teacher(reason='context_uncovered')

    # 2) 双接地可行域
    U = (U_CADVS(u_cand)
         & gic.to_constraints(gic)      # 语义接地
         & tac.to_constraints(tac))     # 物理接地

    if U.is_empty():
        return fallback_stop(reason='dual_grounding_empty')

    # 3) 优先级投影：安全(地形/停止) > 语义意图 > 任务目标
    return project_with_priority(u_cand, U,
                                 order=['terrain_safety', 'gesture', 'task'])
```

### IP-483 Common-Mode Context Failure Monitor (CMCFM)

```python
@dataclass
class CommonModeContextFailureMonitor:
    """CMCFM：语境熵升 + 证书通过率不降 → 疑似共模故障"""
    H_rise: float = 0.15
    pass_high: float = 0.90
    window: int = 50
    cooldown_steps: int = 20

    def __post_init__(self):
        self.H_hist = deque(maxlen=self.window)
        self.pass_hist = deque(maxlen=self.window)
        self.cooldown = 0

    def update(self, context_entropy: float, cert_pass_rate: float) -> bool:
        self.H_hist.append(context_entropy)
        self.pass_hist.append(cert_pass_rate)
        if self.cooldown > 0:
            self.cooldown -= 1
            return False
        if len(self.H_hist) < self.window:
            return False
        dH = self.H_hist[-1] - float(np.mean(list(self.H_hist)[:-1]))
        rate = float(np.mean(self.pass_hist))
        # 语境越来越不确定，证书却几乎全通过 → 共模嫌疑
        suspicious = (dH > self.H_rise) and (rate > self.pass_high)
        if suspicious:
            self.cooldown = self.cooldown_steps
        return suspicious

    def on_suspicious(self, S_delta) -> frozenset:
        # 不信任当前语境后验：膨胀到全语境，令所有前件自动失败
        return FULL_THETA
```

### C³ 统一执行流（单步）

```python
def c3_step(robot_state, sensor_data) -> ControlOutput:
    """
    C³ 单步：语境认证 → 共模监控 → ASR-MPC/学生 → 双接地门控
    """
    # 0) 语境推断与共形置信集
    gic = gick.certify(sensor_data.skeleton_seq)
    tac = tlce.certify(sensor_data.proprio, sensor_data.depth, sensor_data.contact)
    S_delta = frozenset((g, tau) for g in gic.S_delta for tau in tac.S_delta)
    H_ctx = context_entropy(gic, tac)

    # 1) 共模故障监控
    pass_rate = cadvs_cert_pass_rate()
    if cmcfm.update(H_ctx, pass_rate):
        S_delta = cmcfm.on_suspicious(S_delta)     # → FULL_THETA
        log_warn('common-mode suspicion: inflate context set')

    # 2) 语境认证（CADVS + 手势 + 地形）
    certs = cadvs_certs() + [gic.as_cert(), tac.as_cert()]
    if not context_valid_all(certs, S_delta, time.time()):
        return fallback_conservative_teacher(reason='context_uncovered')

    # 3) 教师路径：歧义集鲁棒 MPC；学生路径：沿用 v30 准入
    u_teacher = asr_mpc_solve(robot_state.x, S_delta, horizon=20,
                              model_fn=terrain_model(tac),
                              cost_fn=kt_mpc_cost, constraints=kc_constraints)
    u_student = student_forward(robot_state) if student_admitted() else None
    u_cand = u_student if u_student is not None else u_teacher

    # 4) 双接地门控（最终裁决）
    return dual_grounding_gate(u_cand, gic, tac, certs, S_delta, time.time())
```

## 4. 正确性论证（增量更新）

### 引理 32（手势共形覆盖与稳定度的效率-安全性分离）

**陈述**：设校准序列与测试序列可交换（exchangeable），非一致性分数 s = 1 − p(y|x)，q_g 为校准分数的 ⌈(n+1)(1−α_g)⌉/n 分位。则分裂共形集满足 P(g* ∈ S_δ^g) ≥ 1−α_g。时序稳定度条件（margin、熵、K 帧一致）**不改变覆盖性**，只影响承诺（commitment）的误触发率与集合效率。

**证明**：分裂共形覆盖性由可交换性直接给出（标准结论），与后验是否校准无关。稳定度是对同一后验的确定性筛选，且安全路径始终使用完整 S_δ^g（承诺仅用于任务代价），故不改变 S 的覆盖。∎

**诚实说明**：若在安全路径中用「承诺后的点 g*」替换 S，覆盖性即失效——因此 DGEG 强制安全路径用 S 的交集约束。

### 引理 33（地形歧义集鲁棒可行性）

**陈述**：若 ASR-MPC 在 t=0 对 S_δ^τ 内所有情景可行，且存在对 ∀τ∈S_δ^τ 不变的终端集 X_f，真实地形 τ* ∈ S_δ^τ，则闭环系统在任意时域内满足状态/输入约束。

**证明**：对情景集做鲁棒管束 MPC 归纳。约束对 ∀τ∈S_δ^τ 施加，故对 τ* 成立；终端不变集保证递归可行性。∎

**诚实说明**：该保证依赖「真实模型属于模型类」与「τ* ∈ S_δ^τ」。一旦共形覆盖失败（τ* ∉ S_δ^τ），引理不成立——这正是本轮最大风险所在。

### 引理 34（语境条件组合的单调收缩）

**陈述**：对任意两证书 c_1, c_2，val(c_1 ⊗ c_2) ⇒ val(c_1) ∧ val(c_2)，且 A_{c_1⊗c_2} = A_{c_1} ∩ A_{c_2}。因此加入证书只会收缩执行集：Exec(C ∪ {c}) ⊆ Exec(C)。

**证明**：由定义，组合的内部条件为合取、前件为交集；S_δ ⊆ A_{c1}∩A_{c2} ⇔ S_δ⊆A_{c1} ∧ S_δ⊆A_{c2}。可行集取交单调不增。∎

### 命题 35（共模故障下界与冗余度坍缩）

**陈述**：设 n 个证书 c_1..c_n 共享同一语境前件（均依赖 θ），且语境置信集以概率 ε_c 发生覆盖失败（如分布漂移下「自信地错」，即 S_δ 小而 θ* ∉ S_δ，但 S_δ ⊆ A_c 仍成立）。假设各证书内部条件在误推断下仍可通过，则 P(∃i: val_{c_i} 虚假成立) ≥ ε_c。进一步，条件于覆盖失败，各虚假成立事件**同单调（comonotone）**，即有效独立冗余度为 1 而非 n；增大 n 不降低该概率。

**证明**：覆盖失败事件 E 的概率 ≥ ε_c；在 E 上，错误估计 θ̂ 与 S_δ 一致且落入 A_c，故所有依赖 θ 的 c_i 同时通过，而真实语境违反前件。所有 c_i 共享同一 E，故并集概率等于 ε_c（而非 1−(1−ε_c)^n）。∎

**工程含义**：证书数量不是安全性的充分统计量；必须单独保证**语境覆盖**。CMCFM 的作用正是把「覆盖可能已失败」这一元不确定性显式化并触发保守化。

### 定理（双接地执行集收缩与安全概率界）

**陈述**：在以下假设下：
(C1) 语境覆盖：P(θ* ∈ S_δ) ≥ 1 − δ_ctx，δ_ctx = δ_g + δ_τ；
(C2) CADVS 内部证书在语境正确时可靠，P(内部证书虚假通过) ≤ δ_CADVS；
(C3) ASR-MPC 满足引理 33 的鲁棒可行性。
则：
(a) Exec_C³ ⊆ Exec_CADVS，且当 S_δ^g 或 S_δ^τ 为 Θ 的真子集时严格收缩；
(b) 闭环轨迹在时域 T 内保持安全的概率 ≥ 1 − δ_ctx − δ_CADVS。

**证明**：
(a) DGEG 要求 CADVS 全部证书 + 语境证书同时有效，再由引理 34 组合收缩，并进一步与 U_g、U_τ 取交，故为子集；当语境约束非平凡时严格更小。
(b) 由联合界：P(安全) ≥ 1 − P(语境覆盖失败) − P(内部证书虚假通过 \| 语境正确) ≥ 1 − δ_ctx − δ_CADVS；条件于两者成立，每个被接受控制在真实 θ 下满足约束（引理 33 + 内部可靠性）。∎

**诚实声明**：(C1) 依赖可交换性，而真实部署恰恰会破坏它；(b) 的联合界可能偏保守，且 δ_ctx 与 δ_CADVS 未必独立。C³ 的价值不在于消除这些假设，而在于**把假设变成可监控、可回退的运行时对象**。

## 5. 实验设计

### 5.1 平台与数据

- **仿真**：MuJoCo 双足（Unitree G1 / Cassie 简化），控制 200Hz，语境证书 20–30Hz。
- **地形套件**：6 类（刚性/湿滑/颗粒/可变形/台阶/斜坡），每类随机化摩擦、柔度、坡度、粗糙度；**测试集刻意包含训练分布外地形**（薄冰、松沙、破损台阶）。
- **手势数据**：ChaLearn/Jester 等公开骨架数据集重映射为 5 类机器人指令 + 自采小样本；测试集包含**未见用户、未见速度、遮挡与视角变化**。
- **校准/验证/测试**三分，测试集引入受控分布漂移。

### 5.2 基线

| 编号 | 方法 |
|---|---|
| B0 | CADVS v30（无语境证书） |
| B1 | CADVS + 手势点估计（argmax，无置信集） |
| B2 | CADVS + 地形点估计 |
| B3 | CADVS + 手势/地形双点估计 |
| B4 | C³ 去掉 CMCFM |
| B5 | C³ 完整（GICK+TLCE+CCCA+ASR-MPC+DGEG+CMCFM） |

### 5.3 指标

- **SR**：任务成功率。
- **FVR**（核心安全指标）：虚假有效步占比——所有证书通过但真实状态/动作违反安全约束的步数比例。
- **FR**：新地形跌倒率。
- **GFA**：手势误激活次数/分钟；**GLD**：指令延迟（ms）。
- **TST**：地形切换后恢复稳定步态的调节时间（s）。
- **CMDR / CMDL**：共模检测召回率 / 检测延迟。
- **保守代价**：额外回退比例、任务完成时间。

### 5.4 关键实验

- **E1 分布内**：各方法性能接近；量化 C³ 的保守代价（预期 SR 下降 ≤ 5%）。
- **E2 地形漂移**：在新地形上测 FVR/FR；预期 B0–B3 的 FVR 因共模而骤升，C³ 通过 S_δ 膨胀维持低 FVR。
- **E3 手势漂移**：未见用户/手势下测 GFA；预期共形 + 稳定度使 GFA 相对 argmax 基线下降 ≥ 50%。
- **E4 共模注入**：推理期对抗性翻转语境标签；检验 CMCFM 能否在「熵升 + 通过率高」时触发回退，预期召回 ≥ 80%、延迟 ≤ 200ms。
- **E5 消融**：分别去掉共形（改 softmax 阈值）、CMCFM、时序稳定度，观察 FVR/GFA 变化，验证每个组件不可替代。
- **E6 鲁棒可行性**：扫描 |S_δ| 与 ASR-MPC 可行率/代价；验证 OOD 时安全停机而非冒险。

### 5.5 预期结论（待验证假设，非既成结果）

- C³ 在地形漂移下将 FVR 相对 B3 降低 ≥ 60%，代价是回退比例增加 ≤ 15%。
- CMCFM 能捕获「语境熵升但证书全绿」的共模前兆，将相关漏检率降低一个量级。
- 手势误激活率显著下降，但**在极端未见手势上仍可能漏检**——需承认边界。

## 7. 本轮最大风险（最终确认）

**一句话**：**语境置信集的覆盖失败——在分布漂移下「自信地错」，使整个证书链发生共模失效，系统在全绿状态下做出语义或物理上错误的高风险动作**。共形预测的 1−δ 覆盖以可交换性为命门，而新用户的新手势、训练集外的地形恰恰系统性破坏它；更危险的是，此时 S_δ 往往很小、点估计很自信，监控看到的是「一片健康」，而真实语境早已滑出前件。C³ 的所有机制（OOD 膨胀、跨模态一致性、CMCFM）都只能**探测并保守化**这一失败，而无法从原理上消除它——这是把「语境」升格为证书所必须付出的根本代价，也是本框架能否安全落地的生死线。
