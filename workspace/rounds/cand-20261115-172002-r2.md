# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语义地图」×「力矩控制」）

> R69 把不确定性一分为二（aleatoric / epistemic），并给 epistemic 装上「问」的能力：看、问、触、VoI 定价、单源不定案。但 R69 仍站在两个未写进证书的假设上：
> - **世界是平的、无记忆的。** 每一步都从当前观测重新计算模态熵，仿佛机器人没有空间、没有过去。真实系统靠一张**语义地图**携带跨时间的先验：杯子在哪、门往哪开、这块地滑不滑。地图把「问」摊薄成「记得」，也让不确定性第一次有了**空间结构**——不是「我此刻有多不确定」，而是「世界的哪个角落、哪个属性、值不值得去核实」。
> - **动作只分「任务」与「信息」两类。** R69 的探针是一个显式的额外查询。但在接触操作里，**每一个力矩都同时在做事和试探**：按压既推动物体，也暴露刚度；抓取既维持任务，也暴露摩擦。信息不是任务之外的动作，而是任务的副产物。
>
> 本轮两个灵感正好补上两块：
> - **语义地图** = 关于世界的**长时程、空间索引、可被写错的信念**。它把 R69 的 U_epi 从标量升级为一张**不确定性场**，把「该不该问」升级为「该去哪里、对什么、以多大把握去核实」。
> - **力矩控制** = 语义承诺的**物理结算通道**。它是唯一能把「标签」变成「证据」、也能把「错误标签」变成「不可逆破坏」的接口。
>
> 核心命题：**语义地图是「读」——对世界的先验与承诺；力矩是「写」——对世界的试探与兑现。把二者闭成环：地图给出语义假设集与可容许力矩包络，力矩在包络内以「双效」方式边做边验，接触证据回写地图；只有在证据接地（grounded）时才允许扩大力矩权限，否则维持最保守包络。** 命名 **ATLAS-RAS**（Affordance-grounded Torque-Limited Adaptive Semantic-map Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我对世界的理解值多少力，而这份理解是被证据接地，还是被地图的自信洗白的**」——不确定性不只是一句提问，也可以是一张会撒谎的地图，和一只把谎言变成破坏的手。

## 0. 直觉与动机

**灵感 1（语义地图 → 不确定性有空间结构，也可以被摊薄）**
直觉：R69 每步重新算模态熵，像每次都把书从头读一遍。语义地图是外存：它把「这个物体是什么、有多重、滑不滑、脆不脆、门往哪边开」记在空间索引上。好处有两层：一是**摊薄**——同一个对象只需接地一次；二是**定位**——不确定性不是均匀的，它有热点。遮挡的角落、没碰过的抽屉、第一次见到的材质，才是 U_epi 高的地方。于是 R69 的「要不要问」变成「**先去哪里、对什么、花多少预算**」。但地图不是事实，是信念；它会把旧的错误保存得比新的观测更久。

**灵感 2（力矩控制 → 语义的物理结算，且结算是不可逆的）**
直觉：视觉能告诉你「像杯子」，只有接触能告诉你「拿得动、不打滑、不会碎」。质量、摩擦、柔顺、间隙、关节自由度、稳定性——这些**可操作属性只存在于接触中**。力矩因此是语义的物理实验：一个力旋量打下去，返回的是世界的真实参数。但同一个力矩也是承诺：按太深会压碎，抓太紧会捏坏，滑一下可能掉。**语义错误本身不可怕，可怕的是它通过力矩变成物理后果。** 所以力矩权限不能由「地图有多自信」决定，只能由「这个语义主张被多少独立证据接地」决定。

**灵感 3（对偶闭环 → 地图先验 / 力矩证据，且必须防自证）**
直觉：R69 已有一条对偶通道——传感器残差测「测量自洽」，流似然测「行为自洽」。R70 再加一条：**地图标签测「世界被如何理解」，力矩签名测「世界实际如何响应」**。前者是读，后者是写。闭环的诱惑是自证：地图说「刚性」，机器人就不试探；不试探就没有反例；没有反例地图就更自信。**不问不会留下痕迹，问错才会。** 所以闭环里必须有一个主动的反证机制，否则语义地图会变成一间回音室。

**灵感 4（双效控制 → 边做边验，但证据可能被实验毁掉）**
直觉：控制理论早就知道动作有「双重效应」：既控制状态，也改变对状态的信念。R69 把信息动作从任务动作里拆出来，代价是每次求知都要额外停一下；力矩控制允许把二者重新合并——**用完成任务所需的同一个力矩，顺带把最不确定的那个属性测出来**。但不是所有实验都能重来：想知道一只杯子有多脆，最省事的办法是用力捏，而捏碎了就再也测不了第二次。于是本轮引入**最小不可逆充分实验（LISE）**：在能把假设分开的前提下，选不可逆度最低的力轨迹；能轻触就不重压，能一次分辨就不反复试探。

**灵感 5（新威胁 → 地图投毒 + 力矩放大；自信不等于接地）**
直觉：R69 的最坏情况是「问错，比不问更危险」。R70 的最坏情况升级为「**地图错，比没有地图更危险**」：攻击者不必控制机器人，只要把地图里的「易碎品」改成「刚性件」、把「人」改成「假人」、把「向内开」改成「向外开」，机器人自己的力矩就会替攻击者完成破坏。更阴险的是**接地伪造**：先污染地图，再用一个看起来独立的接触事件「证实」它。因此本轮的中心安全原则是 **GGA（Grounding-Gated Authority）**：**自信不授权，证据才授权**；权限只随「独立、新鲜、物理接地」的证据扩张，绝不随地图置信度扩张。

**灵感 6（R69 是边界，不是被替代）**
直觉：把语义地图退化为「只有几何、没有语义属性」，把可容许包络退化为整个力矩空间，把双效信息项设为零，把权限恒设为 1，ATLAS 就逐指令退化成 FLUID；再把交互预算设为零，就退化成 R68。新层只增加约束（语义包络、接地门控、契约监视），效率增益来自「接地的语义先验」与「双效探索」，而不是放松任何安全谓词。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（ATLAS-RAS 总览与四不变式）** ATLAS-RAS = (SEM, GPA, SVE, DTC, T2S, LISE, SMINT, MPG, GGA, EEG, SCM, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **语义权限不变式**：力矩权限只随接地证据扩张，绝不随置信度扩张；未知/开放世界语义一律取最保守包络（风险不对称）；
(iii) **语义-力矩契约**：每个力矩指令必须落在「对支撑集内所有假设都安全」的包络内，并受运行时契约监视；违约即语义中断与安全停；
(iv) **溯源与证据纪律**：每次地图写入带溯源；单源、陈旧或非物理证据不得提升权限；高风险主张需 ≥2 类独立证据。

**定义 311（语义-认知地图 SEM）** SEM = (G, O, C, A, Π, T, b)。G 为度量/占据层；O 为对象实例（位姿、形状、类别、存在性）；C 为关系/拓扑主张（在…上、属于…房间、可到达…）；A 为可操作属性场；Π 为溯源（来源、传感器、标定、签名、链）；T 为时间戳与陈旧度；b 为对上述主张的联合信念。一条主张 c = (subject, predicate, value, support, π, t, κ)，κ 为来源可靠性；查询返回后验、溯源与接地分，而非裸标签。地图是**信念**，不是事实。

**定义 312（可接地物理属性场 GPA）** 对象 o 的可操作属性 φ_o = (m, μ_s, μ_k, κ_c, γ_f, d_art, z_stab, …)，分别为质量、静/动摩擦、接触刚度、柔顺/脆性、关节自由度、稳定裕度。A: x ↦ p(φ_x | E_x) 与其接触模型后验。**语义标签是离散压缩，GPA 保留力矩所需的连续残差**；标签到属性的映射本身带不确定性。

**定义 313（语义假设集、支撑与接地分）** H(s) = {h : b(h) ≥ 1−α}，开放世界时并入 H_unknown（含「可能是人」「可能是易碎品」「可能是铰接件」等最坏假设）。支撑 S(h) 为生成该主张的证据集。置信度 conf(h) = b(h)；接地分 ground(h) = g(S(h)) 是**独立性 × 新鲜度 × 物理性 × 可重复性**的函数，与 conf 正交。**高置信低接地**是本轮要防的核心状态。

**定义 314（语义-力矩安全包络 SVE）** 对意图 ι 与假设 h，C_safe(h) 为 R68 C-RAS-WM 与力/冲量/滑移漏斗给出的名义安全力矩/力集。鲁棒包络：

T_env(s) = ⋂_{h∈H(s)} C_safe(h)，

并按风险不对称扩张：H 含「人」⇒ 人人安全上限；含「易碎」⇒ 易碎上限；开放未知 ⇒ 未知安全上限（最严）。因此**语义不确定直接收缩权限；接地的消解才扩张权限**（引理 19）。T_env 以盒/多面体形式下发快环。

**定义 315（双效力矩控制 DTC）** 选力矩轨迹 τ_{0:H} 最大化

J = R_task(τ) + β·I(φ; y_contact | τ, s) − λ_e·E[energy(τ)]

s.t. τ ∈ T_env(s) 且满足契约。力矩同时控制与求知；R69 的独立信息动作是 ∂I/∂τ ≡ 0 的特例。信息项用接触响应对 φ 的 Fisher 信息/互信息近似；实时实现为「解析阻抗 + 小 QP 投影」，慢环负责重规划。

**定义 316（力矩→语义证据通道 T2S）** 接触响应 y = (F, τ, Δx, 滑移起始, 振动谱, 屈服点, 关节反力)。似然 p(y | φ, τ, s) 由接触模型给出，并含模型误差项 ε_model。证据类型：静刚度斜率（→κ_c）、断裂力（→γ_f）、滑移起始（→μ_s）、阻尼/摩擦迟滞（→μ_k）、反力-位移滞回（→d_art）。贝叶斯更新 p(φ | E∪{y})。此类证据是**内生的**（由自身力矩产生），远程伪造难，但会被物理伪装与模型误差欺骗。

**定义 317（证据可毁灭性与 LISE）** 探针 τ 可能销毁证据/对象：D(τ) ∈ [0,1]，损失 L_d，未来信息价值 V_future。可毁灭 VoI：

VoI_D(τ) = I(φ; y | τ) − λ_d·E[D(τ)]·(L_d + V_future)。

LISE 选 τ* = argmin_{τ: I(φ;y|τ) ≥ I_need} D(τ)，即「刚好能分辨、尽量不破坏」。一次性实验（不可重复）必须使用更保守的先验并要求更高分辨阈值。

**定义 318（空间 VoI 场与 SMINT）** 地图上的不确定度场

U_map(x) = H(φ_x | E_x) · stakes(x) / cost(x)。

SMINT 在 R69 预算内选「区域/对象/信息动作」最大化单位成本 VoI，兼顾证据可毁灭性与可达性；目标是次模的，贪心给 1−1/e 保证。R69 的 MINT 是 U_map 退化为单点、成本为标量时的特例。

**定义 319（地图来源与投毒防护 MPG）** 溯源 π = (source, sensor, time, calibration, signature, chain)。写入须带溯源；物理证据必须来自本体内生传感器；做度量-拓扑-语义三层一致性检查；陈旧度衰减；写入认证与不可篡改审计日志；异常检测。威胁 ℰ_map：标签投毒、属性投毒（易碎→刚性、人→假人）、拓扑投毒、溯源伪造、感知混叠。

**定义 320（接地门控权限 GGA）** 权限 α(c) ∈ [0,1] 缩放包络：α=0 取最保守包络，α=1 取 C_safe(h)。α = σ(w·ground(c) − θ) · risk_factor(stakes)，**不依赖 conf(c)**。高风险主张需在窗口内 ≥2 类独立证据（如视觉 + 力矩，或地图 + 新鲜观测）。核心原则：**自信不授权，证据才授权**。

**定义 321（语义回声与探索下限 EEG）** 若某主张的支撑单源且陈旧，而策略从不试探它，则错误主张是吸收态。EEG：高风险主张每 T_echo 或在分布漂移时必须重新接地；对高风险单元保留探索下限 ε_explore；低风险可依赖先验。形式化为吸收马尔可夫链，探索下限给出期望纠正时间上界。

**定义 322（语义-力矩契约监视 SCM）** 契约 κ = (intent, h_assumed, T_env, predicted_contact_manifold, monitor_predicates, fallback)。运行时残差 r_τ = dist(y_t, manifold)；若 r_τ > θ_contract 或力逼近包络边界且趋势异常，触发**语义中断**：权限→0、安全停/保持、重新定位、修订地图、重规划。契约哈希进证书。

**定义 323（地图修订与证据加权）** 溯源加权贝叶斯：

p(h | E∪{y}) ∝ p(y | h, τ)·p(h)·w(π_y)，

w 依来源可靠性、新鲜度、独立性。矛盾触发「信念冲突」标记并要求消歧；**禁止静默覆盖**。每次修订重算接地分与权限。

**定义 324（双时间尺度接口）** 慢环 10–50Hz：SEM/GPA/SVE/SMINT/MPG；快环 1kHz：DTC 投影 + SCM + 力/力矩安全。慢环把包络以已认证盒/多面体下发；快环在线不查询学习型地图（零学习写），保证 P99 时序。

**定义 325（证书 J_ATLAS）** J_ATLAS = (J_FLUID, map_grounding_ratio, map_ECE, semantic_conflict_rate, sve_margin, torque_authority_hist, contract_hash, t2s_evidence_hash, destroyability_budget, atlas_ver)。Valid ⇔ Valid(J_FLUID) ∧ GGA 满足 ∧ SCM 无未处理违约 ∧ 溯源完整。

**定义 326（威胁模型 AIC-ATLAS）** ℰ_ATLAS = ℰ_FLUID × ℰ_map × ℰ_contact。ℰ_contact：物理伪装（看着硬实则软、看着软实则硬）、接触模型失配、力矩级传感器欺骗、对抗表面。跨域攻击：地图投毒 + 伪装，制造「伪接地」。

**定义 327（参与式审计 VQAuditor-M）** 审计地图写入、权限扩张、契约违约、接地证据的独立性、力矩是否始终在包络内、地图修订是否有据。结论回灌 AuditBuf，成为下一轮 MPG/SMINT 的先验。

```python
# IP-264 SEM：语义-认知地图（主张带后验/溯源/接地分；地图是信念不是事实）
class SemanticEpistemicMap:
    def add_claim(self, claim, source, sensor, t, signature):
        claim.support.append((source, sensor, t, signature))
        claim.b      = provenance_weighted_bayes(claim, source, sensor, t)
        claim.ground = grounding_score(claim.support)   # 独立×新鲜×物理×可重复
        claim.write_audit("append", source, t)          # 不可篡改日志
        return claim

    def query(self, x, field):
        return {"posterior": ..., "support": ..., "ground": ..., "age": ...}

    def ambiguity_set(self, x, alpha=0.05):
        H = [h for h in hypotheses(x) if self.b(h) >= 1 - alpha]
        return H + (["unknown"] if self.open_world(x) else [])

# IP-266 SVE：语义包络 = 对支撑集内所有假设都安全的力矩集之交（风险不对称）
def semantics_to_torque(intent, H, s, claims):
    sets = [C_safe(h, intent, s) for h in H]          # C-RAS-WM + 力/冲量/滑移漏斗
    if any(is_human(h) for h in H):    sets.append(C_safe_human(s))
    if any(is_fragile(h) for h in H):  sets.append(C_safe_fragile(s))
    if "unknown" in H:                 sets.append(C_safe_unknown(s))
    T_env = intersect(sets)                            # 盒/多面体
    alpha = grounding_gated_authority(claims)          # IP-272：只看接地，不看置信
    return expand(T_env, base=conservative_envelope(s), alpha=alpha)

# IP-267 DTC：双效力矩（任务收益 + 接触信息 − 能耗），投影回包络
def dual_effect_torque(policy, H, T_env, s, n_steps):
    tau = policy.nominal_torque(s, n_steps)            # 任务名义解
    for _ in range(n_steps):
        info = fisher_info_contact(tau, s, H)          # 力矩对 φ 的信息量
        tau  = tau + beta * grad_info(info) - lambda_e * grad_energy(tau)
        tau  = project_to_envelope(tau, T_env)         # 快环 QP，恒可行
        tau  = enforce_contract(tau, T_env, s)         # IP-274
    return tau

# IP-268 T2S：接触响应 → 属性后验（内生证据；含模型误差与伪装鲁棒项）
def torque_to_semantics(y, tau, s, H):
    L = {h: contact_likelihood(y, h, tau, s) for h in H}
    L = robustify(L, eps_model=MODEL_ERR, camouflage=RESIST)
    return bayes_update(H, L), contract_residual(y, tau, s)

# IP-269 LISE：最小不可逆充分实验（能分辨即可，能轻则不重）
def LISE(H, s, T_env, I_need):
    for tau in sorted(experiments(H, T_env), key=destruction):  # 不可逆度升序
        if expected_info(tau, H, s) >= I_need:
            return tau
    return None                                        # 分辨不了则不碰 → R69 兜底

# IP-270 SMINT：空间 VoI 分配（哪里最值得核实）
def spatial_mint(sem, s, budget):
    best = None
    for r in epistemic_frontier(sem, s):               # 高熵 × 高 stakes × 可达
        if not budget.allow(r): continue
        voi = entropy(sem, r) * stakes(r) / cost(s, r)
        if best is None or voi > best.voi: best = (r, voi)
    return best

# IP-272 GGA：接地门控权限（conf 不进入）
def grounding_gated_authority(claim):
    g = grounding_score(claim.support)                 # 独立性/新鲜/物理/可重复
    a = sigmoid(W @ g - theta) * risk_factor(claim.stakes)
    if claim.stakes > S_HIGH and independent_types(claim.support) < 2:
        a = min(a, A_CONSERVATIVE)
    return a
```

## 3. 推导

**引理 19（语义包络单调性与 resolution bonus）** 设 H1 ⊆ H2 为语义假设集，T_env(Hi) = ⋂_{h∈Hi} C_safe(h)。则 H1 ⊆ H2 ⇒ T_env(H1) ⊇ T_env(H2)。证明：交集的约束项越少，可行集越大。故「接地消解」只扩张可容许力矩集，永不收缩；但扩张由 α(ground) 门控，conf 不进入。系：R69 的 λ_floor 是 H={safe, unsafe}、力矩空间一维时该包络的标量投影——未消解对应 α=0 的最保守点，接地消解对应 α=1 的点。

**引理 20（双效力矩的信息-不可逆前沿）** 对局部接触模型，Fisher 信息 I(φ; y | τ) 随激励能量 E(τ) 与法向接触力单调上升；同时破坏风险 D(τ) 也单调上升。在正则条件下，可行 (I, D) 区域存在 Pareto 前沿，LISE 是「给定 I_need 的最小 D」下包络点。系：**接触里不存在「高信息、零不可逆」**；R69 的「信息动作成本为标量」只是 D ≡ 0 的无接触切片。

**引理 21（自信 ≠ 接地：投毒放大上界）** 设损害 ≈ α·Irr·L。若权限由置信度驱动（α=α(conf)），地图投毒在无物理支撑下抬高 conf 即可抬高 α，损害随 conf 增长；若 α=α(ground) 且投毒不改变真实支撑，则 α 不变，损害 ≤ 保守包络下的损害。系：**置信门控权限是攻击放大器；GGA 切断了这条放大通道**。

**引理 22（语义回声的吸收态与探索下限）** 考虑单源陈旧支撑的错误主张。若策略仅在 conf < τ 时试探，则高置信错误主张永不触发试探，其信念是吸收态。若对高风险主张保留探索下限 ε_explore，则 T 步内至少试探一次的概率 ≥ 1−(1−ε_explore)^T，期望纠正时间 ≤ 1/ε_explore。故 EEG 给「过时但自信」的主张一个可证明的纠正上界。

**定理 18（ATLAS 严格包含 FLUID / R68）** 在 A99–A101 下，令语义层为空（仅几何）、H={any}、T_env=全力矩空间、β=0、α=1、SMINT=MINT，则 ATLAS 与 FLUID 逐指令相同；再令交互预算=0，则退化为 R68。安全侧：ATLAS 的包络恒为 FLUID 包络的子集，故风险 ≤ FLUID；效率增益只来自接地的扩张与双效探索。

**定理 19（契约监视下的语义错误损害上界）** 若 H 含真假设 h*、T_env ⊆ C_safe(h*)，且 SCM 以概率 ≥1−ε_m 检出偏离、回退为安全停且停损 ≤ L_stop，则支撑集内任意语义错误造成的期望损害 ≤ ε_m·L_irr + L_stop。支撑集外的开放世界错误由 H_unknown 的最保守包络与监视共同兜底。系：语义错误从「静默灾难」降级为「可恢复故障」，前提是契约流形可标定。

**定理 20（双时间尺度无突变）** 慢环以已认证集合下发包络；快环对每个指令做集合投影。包络收缩时投影满足有界步长（Lipschitz），配合安全停与速率限制，力矩不会产生超过认证斜率的跳变。继承 R69 定理 17 的换装不变式，故地图修订不能诱发控制突变。

## 6. 本轮最大风险

**一句话**：ATLAS 把效率押在「语义地图是接地的」这一前提上，但地图恰恰是最容易被陈旧、混叠和投毒污染的部件，而力矩又是唯一会把错误信念变成不可逆物理后果的通道——**地图越流畅、权限越果断，一次错误标签的代价就越接近不可撤销**；GGA 能阻止「自信」直接换来「大力」，却阻止不了「伪造的接地」与「真实但过时的接地」。

**次级风险与缓解**：
1. **语义包络过保守导致任务不可行** → 接地 resolution bonus + 任务感知包络 + 不可行时回退 R69 的保守 $\lambda$；
2. **契约流形标定误差**（监视以为正常、其实已偏） → 保守阈值 + 多通道残差 + E311 注入测试；

4. **双效探索诱发破坏** → LISE + 可毁灭预算 + 一次性实验的更高分辨阈值；
5. **地图修订震荡** → 迟滞 + 信念冲突标记 + 禁止静默覆盖 + 审计；
6. **双时间尺度时序** → 已认证集合投影 + 快环不查学习型地图 + 速率限制（定理 20）。

```python
    M.sem.revise(H_post, provenance=onboard())                   # 溯源加权，禁静默覆盖
    if r > THETA_CONTRACT:
        M.scm.interrupt(); tau = M.safe_stop(); M.audit.flag("contract")
    lam = max(M.efs.risk_scale(...), M.ras69.lam_floor(...))     # R68/R69 兜底
    return tau, lam, T_env, (H_post, r)
```

## 4. 推导

**引理 19（包络单调性与 resolution bonus）** `H1⊆H2 ⇒ T_env(H1)⊇T_env(H2)`。交集约束越少，可行集越大；故接地消解只扩张权限，且扩张由 `α(ground)` 门控，`conf` 不进入。系：R69 的 `λ_floor` 是该包络在二值假设、一维力矩空间下的标量投影。

**引理 20（信息-不可逆前沿）** 接触 Fisher 信息 `I(φ;y|τ)` 与破坏风险 `D(τ)` 均随激励能量单调上升，可行 `(I,D)` 区域有 Pareto 前沿；LISE 是给定 `I_need` 的最小 `D` 下包络。系：接触中不存在「高信息、零不可逆」，R69 的标量成本只是 `D≡0` 的无接触切片。

**引理 21（自信≠接地：投毒放大上界）** 损害 `≈α·Irr·L`。置信门控下投毒抬高 `conf` 即抬高 `α`，损害随置信增长；GGA 下投毒不改变真实支撑，`α` 不变，损害 ≤ 保守包络。**置信门控权限是攻击放大器，GGA 切断放大通道。**

**引理 22（语义回声）** 仅在 `conf<τ` 时试探的策略下，高置信错误主张是吸收态；探索下限 `ε` 使 `T` 步内至少试探一次的概率 ≥ `1−(1−ε)^T`，期望纠正时间 ≤ `1/ε`。

**定理 18（严格包含 FLUID / R68）** 令语义层为空、`H={any}`、`T_env=` 全力矩空间、`β=0`、`α=1`、`SMINT=MINT`，ATLAS 与 FLUID 逐指令相同；再令交互预算=0，退化为 R68。安全侧包络恒为 FLUID 包络子集。

**定理 19（契约监视下的损害上界）** 若 `H` 含真假设、`T_env⊆C_safe(h*)`、SCM 以概率 ≥`1−ε_m` 检出偏离且回退安全停损失 ≤`L_stop`，则支撑集内任意语义错误的期望损害 ≤ `ε_m·L_irr + L_stop`。语义错误从「静默灾难」降级为「可恢复故障」。

**定理 20（双时间尺度无突变）** 慢环下发已认证包络，快环集合投影满足有界步长；包络收缩时配合安全停与速率限制，力矩无超认证斜率跳变。继承 R69 定理 17 的换装不变式。

## 8. 本轮最大风险

**一句话**：ATLAS 把效率押在「语义地图是接地的」这一前提上，但地图恰恰是最容易被陈旧、混叠和投毒污染的部件，而力矩又是唯一会把错误信念变成不可逆物理后果的通道——**地图越流畅、权限越果断，一次错误标签的代价就越接近不可撤销**；GGA 能阻止「自信」直接换来「大力」，却阻止不了「伪造的接地」与「真实但过时的接地」。

**次级风险与缓解**：语义包络过保守（接地 resolution bonus + 任务感知包络 + 回退 R69）；契约流形标定误差（保守阈值 + 多通道残差 + E311）；接触模型失配/物理伪装（鲁棒似然 + 多类证据 + 物理根信任 + E317）；双效探索诱发破坏（LISE + 可毁灭预算）；地图修订震荡（迟滞 + 冲突标记 + 禁静默覆盖）；双时间尺度时序（已认证集合投影 + 快环不查学习型地图 + 速率限制）。
