# 第 67 轮（承接第 66 轮「CALIPER 构念审计指标」IP-224~233；灵感循环第 2 轮；本轮灵感：「点云配准」×「灵巧手」）

> 第 66 轮把「可归因」升级为「受测量学审计」，其自述最大风险一针见血：**构念覆盖缺口——没被指标写进去的危害等于不存在；审计集被同一 Goodhart 压力污染时，系统会以「指标全绿、非补偿无否决」的更强形式伪装错误自信。** 但 CALIPER 的两个前提仍然被悄悄当作全局成立：测量模型 `m=Λθ+Γψ+ε` 的**对应关系是给定的、处处正确的**，而「覆盖」只是**一个标量检查**。本轮借两个新意象把这两个前提本身拆开：
>
> - **点云配准**：配准的本质不是「对齐」，而是在**部分重叠、错误对应、几何退化**下建立可信对应。一次内点率很高的配准仍可能沿退化方向「滑」——平面沿面内平移、圆柱绕轴旋转、对称物体交换部件，残差都很小，位姿却错了。测量同理：**高构念载荷不等于对应正确，标量覆盖不等于方向覆盖**。
> - **灵巧手**：多指抓取的本质不是「夹住」，而是**接触扳手空间的力封闭**；内部力让一只手能在单指打滑时由其余手指自动补偿，于是**总力看着正常、单点已经失效**。测量同理：**聚合指标会把单通道故障藏进「内部力」里**，而 CALIPER 的非补偿否决仍作用在聚合后的标量上。
>
> 本轮核心命题：
>
> **把 CALIPER 的「一把受审的尺子」升级为「一组经过配准的对应关系 + 一个对危害扳手空间力封闭的指标张成」：用点云配准的鲁棒对应、退化谱、部分重叠显式列出测量盲区；用灵巧手的力封闭、内部力审计显式拆穿聚合补偿；证书只在其真实可观、力封闭、对应有效的子空间上有效——看不见的自由度，不许假装安全。**

## 0. 直觉与动机

**灵感 1（点云配准 → 高内点率不等于对应对，标量覆盖不等于方向覆盖）**
直觉：ICP / 特征配准最危险的失败不是「完全对不上」，而是「在重叠区对得很漂亮、沿某个退化方向滑了一段」。平面沿面内平移、圆柱绕轴旋转、左右对称零件互换，残差都可以很小，但位姿已错。测量系统一模一样：CALIPER 用载荷 / AVE / HTMT 证明「指标测到了构念」，这只证明了**在已覆盖的干预方向上**对得上；如果某个危害方向从未被干预过（partial overlap），指标可以在其余方向全绿，而该方向正是**零空间**。更隐蔽的是**错误对应（perceptual alias）**：某指标看起来与构念强相关，实际测的是共同方法因子 ψ；载荷越高越像真的。配准的教训是：判断对应是否有效，必须靠**跨干预共识、外点剔除与退化谱**，不能靠拟合优度自证。

**灵感 2（灵巧手 → 聚合会奖励致盲，内部力会藏故障）**
直觉：两指夹持时 `f1+f2` 恒定；若一指打滑、另一指自动加力，总力完全正常，抓取「看起来」稳，实际已单点失效。这正是 CALIPER 非补偿聚合的盲区：否决项仍作用在**聚合后的标量**上，而**自适应补偿发生在聚合之前**。灵巧手给出两层启示：(i) **力封闭**要求接触扳手矩阵张成整个扰动扳手空间，否则存在「推不动也测不到」的方向；(ii) **内部力**是力封闭所必需的，却天然落在「净扳手=0」的核空间里——故障可以伪装成内部力。因此证书必须做**逐接触 / 逐通道分解**，并审计内部力的来源：是命令的抓取内力，还是无法解释的补偿残差。

**灵感 3（合流 → MANUS：先配准对应、再检验张成）**
直觉闭环：VLA 只负责提出「危害扳手空间的基」和「指标-构念对应候选」（仍是假设，不是真值）→ ICR 用干预数据做鲁棒配准，剔除错误对应、给出内点率与残差谱 → ODS 用配准的 Jacobian 做退化谱分解，显式输出**不可观测子空间** → HGC 把已声明 / 红队危害张成扳手空间 W，检验指标抓取矩阵 G 在 W 上是否力封闭 → CBM 逐接触拆解，检测聚合致盲与「伪装成内部力」的故障 → STA 在对称群商空间上归因，消除对称退化 → ARC 在接触图切换（换指 / 重抓 / 滚动）后强制重配准 → POR 把「覆盖率」从标量变成**已覆盖危害集 W_cov 与未覆盖集 U_cov** → GCR 审计优化压力是否把**对应关系本身**刷偏 → CSC-M2 用上述结构门控认证前缀 → J_manus。VISTA 管「物理安全 + 故障归因」，CALIPER 管「尺子有效」，MANUS 管「**对应是否配准、张成是否封闭、盲区在哪**」。

**灵感 4（VISTA / CALIPER 组件的原位升级）**
- **CIM → ICR**：固定 `Λ` 变成「带对应集合的鲁棒配准」，允许部分重叠、外点与错误对应，输出 `r_in`、残差谱、别名标志。
- **覆盖效度 `v_cov` → ODS/POR**：标量覆盖率变成「可观测子空间 O + 不可观测子空间 U_deg + 未覆盖危害集 U_cov」三件套，证书只在其上有效。
- **NCA → CBM**：非补偿否决从「聚合后」下沉到「逐接触 / 逐通道」，并增加内部力来源审计；防止自适应补偿把单点故障平均掉。

- **DAP → DAP-C**：探针目标除了可辨识性，还要求能**改变危害张成或增加独立通道**；若某危害方向在 ker G 内，任何只调权重的探针都无效，必须换传感器 / 换接触构型。
- **CSC-M → CSC-M2**：认证前缀新增「不激励不可观测方向、力封闭裕度达标、无补偿致盲、对称商稳定、对应新鲜、轨迹不离 W_cov」六道门。
- **RSC-C/WCV-C → RSC-M/WCV-M**：搜索域新增「不可观测方向不得被当成已确认安全」「未覆盖危害按最坏情况兜底」；只膨胀被结构审计抬升的方向。
- **AIC-C → AIC-M**：干扰集新增「对应攻击」（故意让指标在训练干预上对、在部署方向错）、「接触图错位 / 换指瞬态」、「对称歧义利用」、「内部力伪装」。
- **J_caliper → J_manus**：证书增 `correspondence_set / r_in / residual_spectrum / U_deg / o_min / closure_margin / compensation_blind / internal_force_provenance / symmetry_quotient / W_cov / U_cov / reg_freshness / anchor_provenance`。

## 1. 形式化定义（增量：定义 249–260）

- **定义 249（MANUS 闭环）**：MANUS = (CALIPER, ICR, ODS, HGC, CBM, STA, ARC, POR, GCR, DAP-C, CSC-M2, RSC-M/WCV-M, AIC-M, J_manus)。定位：CALIPER 的「测量框架结构审计」外层。不变式：**VLA 危害/对应提案、配准、退化谱、力封闭、补偿审计、对称商与证书构建只在语义流；实时流只做配准残差查询、退化/封闭查表、逐接触否决、前缀执行与早停，零学习写操作。**
- **定义 250（指标–构念配准 ICR）**：构造干预探针集 `P={π_a}`，每个探针给出已知构念位移 `δθ_a∈ℝ^p` 与实测指标位移 `δm_a∈ℝ^k`。测量模型局部为 `δm_a = Λ_a δθ_a + Γ δψ_a + ε_a`。ICR 把「哪些指标通道以何种载荷对应哪些构念方向」当作配准问题：`min_{Λ,C} Σ_{(a,i)∈C} ρ(‖δm_{a,i}−Λ_i δθ_a‖_{Σ⁻¹}) + λ|C^c|`，用 RANSAC / 渐进非凸求鲁棒解。输出对应集合 `C`、内点率 `r_in=|C|/|C∪C^c|`、残差谱与 bootstrap 共识稳定度。**别名（perceptual alias）判据**：`r_in<r_min` 或 `bootstrap 不稳定` 或「留一通道后共识崩塌」——载荷高但对应错时，拟合优度仍高，只有跨干预共识能揭穿。
- **定义 251（可观测谱与退化子空间 ODS）**：在操作点取 `J=∂m/∂θ`（由 ICR 的 Λ 与工作点处操作化得到），观测信息矩阵 `H=JᵀΣ_ε⁻¹J+H_0`（`H_0` 为先验精度）。特征分解 `H=U diag(λ_1≥…≥λ_p)Uᵀ`。`ε`-退化子空间 `U_deg(ε)=span{u_i:λ_i≤ε}`，可观测子空间 `O=U_deg^⊥`。方向可观测裕度 `o(u)=uᵀHu/‖u‖²`。**证书只能在 O 上断言构念性质；落在 U_deg 的方向必须输出 unobservable，并由锚点或主动探针补足，否则不得声明覆盖。** 这直接把 CALIPER 的标量覆盖缺口变成可打印的子空间。
- **定义 252（危害扳手空间与安全力封闭 HGC）**：VLA 与红队给出已声明危害张成 `W=span{w_1,…,w_h}⊂ℝ^d`（力/力矩/滑移/热/时间到碰撞等方向）。指标抓取映射 `G:W→ℝ^k`，`w↦Gw` 为危害 `w` 下的期望指标签名（含方向与符号）。**γ-安全力封闭** ⇔ `σ_min(G|_W)≥γ`，即 `∀w∈W, ‖Gw‖≥γ‖w‖`，等价于 `G|_W` 列满秩。若存在 `0≠w∈W` 使 `Gw=0`，则 `w` 是**不可检测危害**；证书必须显式列出，并收回任何覆盖它的保证。`γ_G=σ_min(G|_W)` 为安全力封闭裕度。
- **定义 253（补偿致盲子空间 CBM 与内部力溯源）**：设聚合算子 `A:ℝ^k→ℝ^r`（如把多指力池化为净扳手、把多指标池化为总分）。**补偿致盲子空间** `B=ker(AG)⊂W`。若存在 `0≠w∈B` 且控制器可经 `δ_comp∈ker A` 抵消 `Gw`，则聚合量 `Am` 对危害 `w` 不变，任何仅基于 `Am` 的证书都看不见它。**内部力溯源**：`ker A` 中的分量若等于已命令的抓取内力或已声明 ψ，则良性；否则为「未解释内部力」，记为 `u_int`。CBM 输出 `(B, u_int, masked)`，并要求**逐接触 / 逐通道最低裕度否决**，例如 `min_c m_c ≥ τ_c`，而不是 `A m ≥ τ`。
- **定义 254（对称感知归因 STA）**：物体 / 接触构型存在对称群 `S`（圆柱的 SO(2)、球面的 SO(3)、对称零件的反射）。配准解仅在商流形 `Θ/S` 上有意义。对解集 `{p_j}` 定义对称残差 `e_sym=max_j min_{g∈S} d(g p_j,p_j)`。若某构念方向与 `S` 的生成元对齐，则该方向并入 `U_deg`。**归因后验必须在商空间上 S-不变；`e_sym>τ_sym` 或对称群未辨识时判 ambiguous**，防止绕对称轴「自信地转错」。
- **定义 255（接触切换再配准 ARC）**：接触图 `C_t` 记录哪些指 / 掌垫接触、接触模式（固定 / 滑动 / 滚动）与法向拓扑。ICR 的对应与 HGC 的 `G` 都以 `C_t` 为条件。定义锚点通道 `A_ind`（本体感觉、关节编码器、IMU、已知标定靶，`Γ=0`）与锚点覆盖 `A_cov(A_ind,U_deg)`。**当 `C_t` 变化（换指、重抓、滚动）时，ARC 必须用锚点重估 `Λ,G` 并刷新 `reg_freshness`；锚点覆盖不足则 `k*=0`。** 否则旧对应在新接触图下是「过期的配准」。
- **定义 256（部分重叠覆盖证书 POR）**：给定危害空间 `W`、可观测子空间 `O` 与抓取映射 `G`，定义已覆盖集
  `W_cov = {w∈W : w∈O 且 ‖Gw‖≥γ_min}`，未覆盖集 `U_cov = W∖W_cov`。
  重叠度 `ρ_ov=μ(W_cov)/μ(W)`（`μ` 为声明危害分布或均匀测度）。**证书只在 W_cov 上有效；U_cov 必须逐项列出，并选择：保守最坏兜底 / 定向探针缩小 / 拒绝认证。** 不得再用一个标量覆盖分把 U_cov 平均掉。
- **定义 257（对应漂移与反 Goodhart GCR）**：优化压力不只刷指标值，还可能**移动对应关系**——策略会在代理对应局部成立的操作点 / 接触构型上停留，使 `m_P` 与构念在审计锚点上仍对齐、在部署方向上漂开。定义对应漂移 `d_corr=sup_{a∈A_anchor}‖Ŵ(m_a)−W*(m_a)‖`。GCR 要求审计集包含**破坏对应的干预**（换接触构型、对称位姿、负载重分布、透明 / 遮挡），并要求 `d_corr≤d_max` 且 `g_ucb≤g_max`；否则证书降级。
- **定义 258（MANUS 认证前缀 CSC-M2）**：`k*=max k`，使 (i) VISTA 物理安全对支持集内所有 `H` 成立；(ii) CALIPER 的效度 / 信度 / 否决 / Goodhart 全部通过；(iii) 块动作不激励不可观测方向，`max_{s≤k}‖P_{U_deg} J_a a_s‖≤ε_deg`；(iv) 块诱导危害上 `γ_G≥γ_min`；(v) 无未解释内部力且 `masked=0`；(vi) `e_sym≤τ_sym` 且 `reg_freshness≤τ_reg`；(vii) 预测轨迹危害始终落在 `W_cov`，进入 `U_cov` 即截断。任一不过则 `k*=0` 安全回退，且仍保持 `k*≤m`。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 12（部分重叠下的可观测下界）**：构念方向 `u` 的后验方差满足 `Var(uᵀθ|m) ≥ (uᵀHu + uᵀH_0u)⁻¹`。若该方向没有任何干预 / 指标响应（`u∈U_deg`），则 `uᵀHu=0`，信息只剩先验；任何标量覆盖分都不能把它变成「已被测量」。故 CALIPER 的标量 `v_cov` 必须被 ODS/POR 的**子空间证书**取代。
- **引理 13（闭包是检测的必要条件）**：若存在 `0≠w∈W` 使 `Gw=0`，则在健康与危害 `w` 下指标分布同均值、同协方差，任何检验的功效 ≤ 检验水平 α，与样本量无关。因此 `σ_min(G|_W)≥γ` 不是「加分项」，而是**可检测性的必要条件**。
- **引理 14（聚合致盲的不可检测性）**：若 `w∈ker(AG)` 且补偿可在 `ker A` 内实现，则聚合量 `Am` 对 `w` 不变；任何只看聚合的证书都无法发现它。逐接触分解 `(Gw)_c` 在 `w∉ker G` 时非零，故「安全力封闭 + 逐接触最低裕度 + 内部力溯源」是拆穿补偿的必要充分结构。
- **定理 11（MANUS 子空间化安全）**：在 A95–A101 下，`Valid(J_manus)` ⇒ CALIPER 的保证只在 `W_cov` 上成立，而 `U_cov` 要么被保守兜底、要么被探针缩小、要么拒绝认证；`W_cov` 内不存在「力封闭却测不到」或「聚合后看不见」的危害；对应有效与对称商稳定保证归因不会「高置信地错」。这把 CALIPER 隐含的「全覆盖」假设替换为**显式子空间 / 区域保证 + 盲区清单**。
- **定理 12（接触切换的安全再配准）**：若每次接触图变化时 ARC 要么恢复锚点覆盖、要么在任何动作前令 `k*=0`，则跨切换的执行始终满足当前图上的封闭与可观测性；否则旧对应可产生有界但不可忽略的偏差，切换瞬间的额外风险计入 `α_chunk+δ_stale`。
- **命题（聚合奖励致盲）**：两指 `A=[1,1]`，故障让 `f1→f1−δ`、自适应补偿让 `f2→f2+δ`，则 `A f` 不变而 `min(f1,f2)` 下降。故任何作用在聚合量上的非补偿否决都能被这组故障绕过；必须逐接触取最小裕度。**推论：CALIPER 的 NCA 解决「加权和补偿」，MANUS 的 CBM 解决「自适应补偿」。**

## 2. 形式化定义（完整版）

**定义 249（MANUS 闭环）** MANUS 是 CALIPER 的「测量框架结构审计」外层：在 CALIPER 的「语义流 ∘ 实时流」骨架上挂载 ICR（指标-构念配准）、ODS（可观测/退化谱）、HGC（危害力封闭）、CBM（补偿致盲）、STA（对称商）、ARC（接触切换再配准）、POR（部分重叠区域证书）、GCR（对应漂移审计），并原位升级 DAP→DAP-C、CSC-M→CSC-M2、RSC-C/WCV-C→RSC-M/WCV-M、AIC-C→AIC-M、J_caliper→J_manus。不变式：**VLA 危害/对应提案、配准、谱分析、力封闭、补偿审计、对称商与证书构建只在语义流；实时流只做配准残差查询、退化/封闭查表、逐接触否决、前缀执行与早停，零学习写操作。**

**定义 250（指标–构念配准 ICR）** 设干预探针集 `P={π_a}`，每个探针给出已知构念位移 `δθ_a∈ℝ^p` 与实测指标位移 `δm_a∈ℝ^k`，局部测量模型为
`δm_a = Λ_a δθ_a + Γ δψ_a + ε_a`，`E[ε_a]=0`，`Cov(ε_a)=Σ_ε,a`。
把「指标通道 i 是否以载荷 `λ_i` 对应构念方向 j」视为对应 `c=(i,j)∈C`，ICR 解
`min_{Λ,C} Σ_{(a,i)∈C} ρ(‖δm_{a,i}−Λ_i δθ_a‖_{Σ_ε⁻¹}) + λ|C^c|`，
其中 `ρ` 为 Huber/Tukey 鲁棒损失，用 RANSAC 采样一致 + 渐进非凸（GNC）求解。输出对应集合 `C`、内点率 `r_in`、残差谱 `{e_reg,i}` 与 bootstrap 共识稳定度 `stab`。**别名（perceptual alias）判据**：
`alias ⇔ r_in<r_min ∨ stab>τ_stab ∨ ConsensusBreak(leave_one_channel_out)`。
直觉：载荷高只说明「在已采样的干预上线性拟合好」，别名之所以危险，正是因为它在该子集上拟合得更好；只有留一通道 / 换干预的共识崩塌能揭穿它。

**定义 251（可观测谱与退化子空间 ODS）** 在操作点取 `J=∂m/∂θ`（由 ICR 的 `Λ` 与操作化映射复合得到），观测信息矩阵
`H = JᵀΣ_ε⁻¹J + H_0`（`H_0` 为先验精度，可为 0）。
特征分解 `H=U diag(λ_1≥…≥λ_p)Uᵀ`。`ε`-退化子空间
`U_deg(ε)=span{u_i : λ_i≤ε}`，可观测子空间 `O=U_deg^⊥`，
方向裕度 `o(u)=uᵀHu/‖u‖²`，谱条件 `o_min=λ_min(H)/λ_max(H)`。
**证书只能在 O 上断言构念性质；`U_deg` 必须输出 `unobservable`，并由锚点/探针补足，否则不得声明覆盖。** 与点云配准的退化分析同构：法方程小特征值方向就是「位姿沿之滑动而残差不变」的方向；这里就是「危害沿之变化而指标不变」的方向。

**定义 252（危害扳手空间与安全力封闭 HGC）** VLA 与红队给出已声明危害张成
`W = span{w_1,…,w_h} ⊂ ℝ^d`（力/力矩/滑移/热/时间到碰撞等方向；`d` 为危害描述维数）。指标抓取映射 `G:W→ℝ^k`，`w↦Gw` 为危害 `w` 下的期望指标签名（含符号与方向）。**γ-安全力封闭**：
`∀w∈W, ‖Gw‖ ≥ γ‖w‖ ⇔ σ_min(G|_W) ≥ γ`（`G|_W` 列满秩）。
`γ_G=σ_min(G|_W)` 为安全力封闭裕度；`N_G=ker(G|_W)` 为**不可检测危害子空间**。若 `N_G≠{0}`，证书必须列出 `N_G` 的基向量，并收回覆盖这些方向的任何保证。类比灵巧手：接触扳手矩阵必须在所需扰动扳手空间上满秩才能力封闭；这里指标抓取矩阵必须在危害空间上满秩才能「检测封闭」。`W` 之外的危害是更深的开集风险，见定义 256/259。

**定义 253（补偿致盲子空间 CBM 与内部力溯源）** 设聚合算子 `A:ℝ^k→ℝ^r`（如把多指力池化为净扳手、把多指标池化为总分）。**补偿致盲子空间**
`B = ker(AG) = {w∈W : AGw=0}`。
若 `w∈B` 且控制器可施加补偿 `δ_comp∈ker A` 使 `Gw+δ_comp∈ker A`（净聚合不变），则 `Am` 对危害 `w` 完全不敏感。**内部力溯源**：`ker A` 中分量若等于已命令的抓取内力 `f_int,cmd` 或已声明方法因子 `Γψ`，良性；其余为未解释内部力 `u_int`。CBM 输出 `(B, u_int, masked)`，其中
`masked ⇔ ∃0≠w∈B : P_{ker A}(Gw) 不在 span(f_int,cmd) ∪ span(Γψ)`。
**决策下沉为逐接触最低裕度**：`δ=reject` if `min_c m_c < τ_c`，而非仅 `A m<τ`。这在形式上解释了为什么「非补偿聚合」还不够：它只防加权和，不防聚合前的自适应补偿。

**定义 254（对称感知归因 STA）** 物体/接触构型存在对称群 `S`（圆柱 `SO(2)`、球 `SO(3)`、对称零件反射群）。配准解只在商流形 `Θ/S` 上有意义。对解集 `{p_j}` 定义
`e_sym = max_j min_{g∈S} d(g p_j, p_j)`。
若构念方向 `u` 与 `S` 的某个生成元对齐（`u∈Lie(S)` 的作用方向），则 `u` 并入 `U_deg`。**归因后验必须在商空间上 S-不变；`e_sym>τ_sym` 或对称群未辨识时判 ambiguous**，不允许在对称轨道内挑一个「最高后验」的代表继续执行——那正是点云配准在对称物体上「置信地转错」的同构失败。

**定义 255（接触切换再配准 ARC）** 接触图 `C_t=(V_c,E_c,{mode_c},{n_c})` 记录哪些指/掌垫接触、接触模式（固定/滑动/滚动）与法向拓扑。ICR 的对应与 HGC 的 `G` 均以 `C_t` 为条件。锚点通道
`A_ind={本体感觉, 关节编码器, IMU, 已知标定靶}`，满足 `Γ=0`（方法不变）。锚点覆盖 `A_cov(A_ind,U_deg)` 为 `U_deg` 中被锚点独立约束的方向比例。**触发规则**：若 `hash(C_t)≠hash(C_{t−1})`（换指/重抓/滚动/掉指），ARC 必须用锚点重估 `Λ,G`、重算 `U_deg/γ_G` 并刷新 `reg_freshness`；若 `A_cov<A_min` 或重配准未通过，立刻 `k*=0`。旧对应在新接触图下是**过期配准**，其误差不会因「上次证书有效」而消失。

**定义 256（部分重叠覆盖证书 POR）** 给定 `W`、`O`、`G`，定义
`W_cov = {w∈W : w∈O ∧ ‖Gw‖≥γ_min}`，`U_cov = W∖W_cov`，
重叠度 `ρ_ov = μ(W_cov)/μ(W)`（`μ` 可取声明危害分布或均匀测度）。**证书只在 `W_cov` 上有效**；`U_cov` 必须逐项列出并三选一处置：(a) 保守最坏兜底（把 `U_cov` 当作始终可能发生的最坏危害）；(b) 定向探针/新通道缩小 `U_cov`；(c) 拒绝认证。禁止用一个标量覆盖分把 `U_cov` 平均进「覆盖率」。这对应点云配准只对重叠区负责：非重叠区不是「配准误差大」，而是**根本没有对应**。

**定义 257（对应漂移与反 Goodhart GCR）** 优化压力不只刷指标值，还可能**移动对应关系**：策略会在「代理对应局部成立」的操作点/接触构型上停留，使 `m_P` 在审计锚点上仍与构念对齐、在部署方向上漂开。定义
`d_corr = sup_{a∈A_anchor} ‖Ŵ(m_a) − W*(m_a)‖`。
GCR 是 GAA 的结构版：审计集必须包含**破坏对应的干预** `E_corr={换接触构型, 对称位姿, 负载重分布, 透明/遮挡, 换指瞬态}`，并要求
`d_corr≤d_max ∧ g_ucb≤g_max`；否则证书降级或 `k*=0`。关键区别：GAA 防「指标值被刷」，GCR 防「指标与构念之间的对应被刷」。

**定义 258（MANUS 认证前缀 CSC-M2）** `k* = max k`，使
(i) VISTA 物理安全对 `supp_δ(post)` 内所有 `H` 成立；
(ii) CALIPER 的效度/信度/否决/Goodhart 全部通过；
(iii) 不激励不可观测方向：`max_{s≤k} ‖P_{U_deg} J_a a_s‖_Σ ≤ ε_deg`；
(iv) 块诱导危害 `W(A[:k])` 上 `γ_G≥γ_min`；
(v) CBM `masked=0` 且无未解释内部力 `‖u_int‖≤ε_int`；
(vi) 对称商稳定 `e_sym≤τ_sym`，对应新鲜 `reg_freshness≤τ_reg`；
(vii) 预测轨迹危害 `⊆W_cov`，一旦进入 `U_cov` 即截断。
任一不过则 `k*=0` 安全回退；仍约束 `k*≤m`（长预测、短执行）。

**定义 259（MANUS 证书 J_manus）** 
`J_manus=(J_caliper, C, r_in, residual_spectrum, U_deg, o_min, γ_G, B, u_int, S, e_sym, C_t, W_cov, U_cov, ρ_ov, d_corr, reg_freshness, anchor_provenance, aic_m_ver)`。
验证规则：
`Valid(J_manus) ⇔ Valid(J_caliper) ∧ r_in≥r_min ∧ (A_cov≥A_min ∨ 保证已限制在 O) ∧ γ_G≥γ_min ∧ masked=0 ∧ ‖u_int‖≤ε_int ∧ e_sym≤τ_sym ∧ reg_freshness≤τ_reg ∧ d_corr≤d_max ∧ 轨迹危害⊆W_cov ∧ aic_m_ver 为当前版本`。
审计链新增：**这组指标与构念是怎么配准上的（C/r_in/别名）、哪些方向根本不可观测（U_deg）、危害空间是否被指标张成（γ_G/ker G）、有没有被聚合/内部力藏起来（B/u_int）、对称和换指后对应还是否有效（e_sym/C_t/reg_freshness）、哪些危害没被覆盖（U_cov）。**

**定义 260（MANUS 闭环算子）** 见 IP-243 伪代码。语义流：`[LiDAR→LSF→USR/MEL→VPG→ACH→阶段切分→VCV→ISC(VLA 提危害基/对应候选)→ICR→ODS→HGC→CBM→STA→ARC→POR→CMF/OSM→FIR-M→DAP-C/FPE→NCA/CBM→GCR→WCV-M→CSP-V→CSC-M2→Shield→执行 k*→EV_exec→RSC-M→OLP→DIR→SSB→AIC-M]`；实时流：`[锚点读→配准残差查表→U_deg/γ_G 查表→逐接触否决→CSC-M2 早停→前缀派发→J_manus 构建]`。

### IP-234 ICR（指标-构念鲁棒配准）

```python
class IndicatorConstructRegistration:
    """用干预数据把指标通道配准到构念方向。高载荷 ≠ 对应对。"""
    def __init__(self, sigma_eps, ransac_n=256, tau_in=3.0, r_min=0.85):
        self.Sigma_inv = np.linalg.inv(sigma_eps)
        self.ransac_n, self.tau_in, self.r_min = ransac_n, tau_in, r_min

    def register(self, interventions):
        best = None
        for _ in range(self.ransac_n):
            sub = sample_consensus_subset(interventions)
            Lam = self._robust_fit(sub)                       # Huber IRLS
            inl = self._inliers(interventions, Lam)            # 残差 < tau_in
            score = self._consensus(inl) - 1e-3 * np.linalg.norm(Lam)
            if best is None or score > best['score']:
                best = {'Lam': Lam, 'inl': inl, 'score': score}
        boot = bootstrap_consensus(interventions, best['Lam'], B=64)
        alias = (len(best['inl']) / max(len(interventions), 1) < self.r_min
                 or boot['instability'] > TAU_STAB
                 or leave_one_channel_breaks(interventions, best['Lam']))
        J = compose_jacobian(best['Lam'], operating_point())
        return Registration(Lam=best['Lam'], C=best['inl'],
                            r_in=len(best['inl']) / max(len(interventions), 1),
                            residual=self._residuals(interventions, best['Lam']),
                            alias=alias, J=J, freshness=now())
```

### IP-235 ODS（退化谱）

```python
def observability_spectrum(Lam, Sigma_eps, H0=None, eps_deg=1e-3):
    J = Lam
    H = J.T @ np.linalg.solve(Sigma_eps, J)
    if H0 is not None:
        H = H + H0
    evals, evecs = np.linalg.eigh(H)
    order = np.argsort(evals)[::-1]
    evals, evecs = evals[order], evecs[:, order]
    mask = evals > eps_deg
    U_deg = evecs[:, ~mask]
    O = evecs[:, mask]
    o_min = float(evals[mask].min() / evals.max()) if mask.any() else 0.0
    return {'evals': evals, 'U_deg': U_deg, 'O': O, 'o_min': o_min,
            'margins': evals / max(evals.max(), 1e-12)}
```

### IP-236 HGC（安全力封闭）

```python
class HazardGraspClosure:
    """G: 危害方向 -> 指标签名。列满秩才谈得上检测。"""
    def __init__(self, G):
        self.G = np.asarray(G)

    def closure(self, W_basis, gamma_min):
        Gw = self.G @ W_basis                    # h 个危害基方向
        U, sv, Vt = np.linalg.svd(Gw, full_matrices=True)
        gamma = float(sv[-1]) if sv.size else 0.0
        # Gw 的零空间（在 W 坐标下）=> 不可检测危害组合
        rank = int(np.sum(sv > 1e-9))
        null_W = Vt[rank:].T
        undetectable = W_basis @ null_W
        return {'closed': gamma >= gamma_min and undetectable.size == 0,
                'gamma': gamma, 'undetectable': undetectable,
                'null_W': null_W}
```

### IP-237 CBM（补偿致盲 + 内部力溯源）

class CompensationBlindAudit:
    def __init__(self, A, G):
        self.A, self.G = np.asarray(A), np.asarray(G)

    def blind_subspace(self):
        return null_space(self.A @ self.G)       # B = ker(AG)

    def audit(self, per_contact_residual, commanded_internal, declared_psi):
        B = self.blind_subspace()
        explained = span_of([commanded_internal, declared_psi])
        u_int = project_out(per_contact_residual, explained)
        masked = False
        if B.size:
            leak = B.T @ per_contact_residual
            masked = np.linalg.norm(project_out(leak, explained)) > TAU_MASK
        return {'B': B, 'masked': masked, 'u_int': u_int,
                'min_contact_margin': float(np.min(per_contact_residual))}
```

### IP-238 STA（对称商）

def symmetry_quotient(pose_solutions, symmetry_group, tau_sym):
    reps, residuals = [], []
    for p in pose_solutions:
        orbit = [g @ p for g in symmetry_group.generators()]
        q = min(orbit, key=lambda z: pose_distance(z, p))
        reps.append(q)
        residuals.append(pose_distance(q, p))
    e_sym = float(max(residuals)) if residuals else 0.0
    deg_dirs = [gen.axis for gen in symmetry_group.generators()]  # 并入 U_deg
    return {'reps': reps, 'e_sym': e_sym, 'stable': e_sym <= tau_sym,
            'symmetry_deg_dirs': deg_dirs}
```

def csc_m2_prefix(A, post, reg, cl, cbm, sym, ov, m,
                  eps_deg, gamma_min, eps_int, tau_sym, tau_reg):
    k_best = 0
    for k in range(1, min(len(A), m) + 1):
        if not physical_safe(A[:k], post):            # VISTA
            break
        if not caliper_valid(reg):                     # CALIPER
            break
        if excite_deg(A[:k], reg.U_deg, reg.J) > eps_deg:   # (iii)
            break
        if cl['gamma'] < gamma_min:                    # (iv) 力封闭
            break
        if cbm['masked'] or np.linalg.norm(cbm['u_int']) > eps_int:  # (v)
            break
        if sym['e_sym'] > tau_sym:                     # (vi) 对称
            break
        if (now() - reg.freshness) > tau_reg:          # (vi) 对应过期
            break
        if not ov['certifiable'] or hazards_leave(A[:k], ov):  # (vii)
            break
        k_best = k
    return k_best

## 4. 推导

**引理 12（部分重叠下的可观测下界）** 设局部线性模型 `m=Jθ+ε`、`ε∼N(0,Σ_ε)`，先验 `θ∼N(0,H_0⁻¹)`。则后验协方差 `Σ_post=(JᵀΣ_ε⁻¹J+H_0)⁻¹`，对任意方向 `u`，
`Var(uᵀθ|m)=uᵀ(JᵀΣ_ε⁻¹J+H_0)⁻¹u ≥ 1/(uᵀ(JᵀΣ_ε⁻¹J+H_0)u)`。
若 `u∈U_deg(ε)`，则 `uᵀJᵀΣ_ε⁻¹Ju≤ε`，信息量至多 `ε`（加先验）；当先验为无信息（`H_0→0`）时方差发散。故「未被任何干预/指标覆盖的方向」不是「误差大一点」，而是**没有信息**；标量覆盖分不能把它变成「已测量」。这正是 CALIPER 用一句「覆盖效度达标」掩盖的东西。∎

**引理 13（闭包是可检测性的必要条件）** 设健康与危害 `w` 下指标分别为 `m∼N(μ,Σ_ε)` 与 `m∼N(μ+Gw,Σ_ε)`。若 `Gw=0`，两者分布完全相同，其 KL 散度 `D_KL=0`，任何检验在任意样本量下功效 ≤ 水平 α。故存在 `w∈W` 使 `Gw=0` 时，无论采多少数据都无法检测该危害；`σ_min(G|_W)≥γ` 是可检测性的必要条件，而非工程加分项。∎

**引理 14（聚合致盲的不可检测性）** 设聚合 `Am`、补偿可在 `ker A` 内实现。若 `w∈ker(AG)`，取 `δ_comp=−Gw∈ker A`，则危害后的聚合观测量与健康时相同：`A(m+Gw+δ_comp)=Am`。任何仅依赖 `Am` 的证书对 `w` 不可区分。另一方面，因 `γ_G≥γ_min` 蕴含 `ker(G|_W)={0}`，有 `(Gw)_c≠0` 对某个接触通道 `c` 成立；故逐接触残差能看到它。再由内部力溯源排除「已命令内力」造成的良性解释，即得「力封闭 + 逐接触最低裕度 + 内部力溯源」是拆穿补偿的必要充分结构。∎

**定理 11（MANUS 子空间化安全）** 在 A95–A101 下：

1. **对应有效**：`r_in≥r_min` 且 `alias=0` 保证配准对应在干预覆盖范围内有效；`d_corr≤d_max` 保证优化未把对应刷偏。由引理 12，证书只在 `O` 上有内容，`U_deg` 被显式隔离。
2. **检测封闭**：由引理 13，`γ_G≥γ_min` 排除 `ker(G|_W)` 内的不可检测危害；`W_cov` 内的每个危害都有可辨指标签名。
3. **聚合不可致盲**：由引理 14，`masked=0` 与 `‖u_int‖≤ε_int` 排除自适应补偿与内部力伪装。
4. **对称不自信**：`e_sym≤τ_sym` 且对称方向并入 `U_deg`，归因后验在 `Θ/S` 上稳定；对称轨道内的「最高后验」不再被当作确定解。
5. **切换不继承过期对应**：由定义 255 与定理 12，接触图变化后要么重配准成功、要么 `k*=0`。
6. **子空间化证书**：`Valid(J_manus)` 只承诺 `W_cov` 上的安全；`U_cov` 必被保守兜底、探针缩小或拒绝认证。故 CALIPER 隐含的「全覆盖」假设被替换为**显式区域保证 + 盲区清单**。∎

**定理 12（接触切换的安全再配准）** 设接触图在时刻 `t_1<…<t_N` 变化。对每个变化点，若 ARC 恢复 `A_cov≥A_min` 并重配准，则其后执行满足当前图上的 `γ_G` 与 `U_deg` 证书；若 `A_cov<A_min` 或重配准失败，则 `k*=0`，不执行任何可能造成不可逆后果的动作。由归纳，跨所有切换的执行都满足当前接触图上的封闭与可观测性。切换瞬态风险由 `α_chunk+δ_stale` 计入风险预算，其中 `δ_stale` 由 `τ_reg` 与接触图变化频率界定。∎

**命题（聚合奖励致盲，NCA 不充分）** 令 `A=[1,1]`、`G=[1,−1]ᵀ`，危害 `w` 使 `Gw=(−δ,+δ)`（一指卸载、另一指补偿）。则 `AGw=0`，`A m` 对 `w` 不变；若仅用聚合否决 `A m≥τ`，该故障永远通过。而 `min_c m_c` 下降 `δ`，逐接触最低裕度可检出。故「非补偿聚合」只解决加权和补偿；**自适应补偿发生在聚合之前，必须用 CBM 的逐接触分解 + 内部力溯源**。∎

**命题（只调权重的探针无法救 ker G）** DAP-C 若只优化可观测子空间内的 Fisher 信息或后验熵，则由引理 13，对 `w∈ker(G|_W)` 的任何加权/采样都不改变 `Gw=0`。因此探针必须**改变张成**（新增独立传感器通道、改变接触构型使 `G` 行空间扩大）或**缩小 W**（证明该危害不可能发生）；仅调权重的探针在结构上无效。这解释了为什么 CALIPER 的 DAP 不够：它优化的是「已知通道上的信息」，而 MANUS 要问「通道张成是否覆盖危害」。∎

## 7. 已知风险

**一句话**：MANUS 的全部保证依赖「危害扳手空间 W 被正确枚举、指标抓取映射 G 与对应关系在证书有效期内不漂移」；一旦真实危害落在未被枚举的 W 之外，或对应在接触切换/对称/负载重分布下漂移而 ICR 的干预集恰好没覆盖到，系统就会以「配准内点高、力封闭裕度足、退化谱干净」的更强形式给出**结构性盲视**——把 CALIPER 的标量覆盖缺口升级成「披着配准与力封闭外衣的方向性盲区」。

**次级风险与缓解**：
1. **W 的开放集缺口**：危害枚举来自 VLA + 红队，必然不完备。缓解：把 `W` 的生成器与版本写入证书；用开集缺拟/新锚点持续扩充；对 `W` 外危害只承诺保守兜底，不承诺检测。
2. **对应在部署方向漂移**：ICR 的干预集可能与部署分布错位，GCR 只能测有限锚点。缓解：把「破坏对应的干预」纳入常规审计、轮换锚点、预注册审计协议；`d_corr` 超界即降级。
3. **G 的估计偏差**：`G` 由离线故障注入/线性化得到，真实危害下可能非线性。缓解：分区域线性化、把 `G` 的不确定度并入 `γ_G` 下界、在 `γ_G` 接近阈值时禁用认证。
4. **接触图哈希漏检**：微小接触变化（法向偏转、接触面积变化）可能不触发 ARC。缓解：连续接触模式监控 + 配准残差 CUSUM；由残差漂移而非仅拓扑变化触发重配准。
5. **对称群误判/漏判**：把非对称物体当对称会过度保守，反之会自信错。缓解：多假设对称群 + `e_sym` 与视觉几何交叉验证；不确定时判 ambiguous。
6. **内部力溯源依赖命令模型**：`f_int,cmd` 本身可能错，导致把故障当良性内力。缓解：独立触觉阵列交叉验证、命令-实测残差入证书、`u_int` 阈值自适应。
7. **逐接触传感器不完备**：并非每个接触都有独立力/触觉通道，`(Gw)_c` 可能不可测。缓解：把不可测接触方向并入 `U_deg` 并显式声明；优先增加独立通道而非只调算法。
8. **实时预算**：配准残差与逐接触查表逼近 3ms。缓解：语义流离线算 `G/U_deg/γ_G`，实时只查表；事件触发重配准；ROI 降采样。
9. **认证前缀过度保守**：六道门可能使 `k*` 长期为 0，退化为「安全但不可用」。缓解：分层门（硬门/软门）、软门用风险预算、主动探针缩小 `U_cov/U_deg`、把不可用率作为独立指标报告。
