# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「语音交互」×「模仿学习」）

> 第 54 轮把技能刻画为动作占用剖面 `α_S`、鲁棒性谱 `ρ`、云边映射 `γ_ce`，并给出联合证书 `J`。但它默认了「技能库现成、任务以动作序列下发」。本轮补上两个被遗漏的来源问题：技能来自**模仿学习（示范）**，任务来自**语音交互（说话）**。核心矛盾：H22：语音指令引入「方式维」`M`（速度/力度/幅度/平滑度），而示范只覆盖 `M` 的一部分，语言请求会落在无证据区域；H23：能执行（`α_S`）不等于有证据（示范支撑 `supp_ε(D_S)`），二者混淆会制造「语音幻觉执行」——系统自信执行却无任何示范支撑。

## 0. 直觉与动机

**灵感 1（语音是动作空间「方式维」的入口）**
直觉：人不会只报「抓杯子」，还会说「轻一点、慢慢放、别碰到旁边」。这些词不改变目标，却改变动作的方式。于是动作空间应从 `A = A_c × A_e` 扩张为 `A⁺ = A_c × A_e × M`，其中方式空间 `M ⊆ ℝ^k` 覆盖速度、力度、幅度、平滑度。语音指令本质上是**在 A⁺ 上指定一个子区域 R**，而不只是一个离散技能 ID。

**灵感 2（模仿学习给的是技能 + 证据，不只是能力）**
直觉：示范集 `D_S = {(s_i, a_i⁺)}` 既是技能 S 的生成来源，也是它「被证明做过」的证据。必须把「能执行」`α_S⁺` 与「有示范支撑」`supp_ε(D_S)` 分成两个独立谓词。语音可以请求一个 `α_S⁺` 上看似可达、但 `supp_ε(D_S)` 完全没覆盖的区域——此时执行就是**语音幻觉**，而非能力不足。

**灵感 3（接地-支撑二维判定 → 执行 / 主动示范 / 澄清 / 拒绝）**
直觉：接地（语言→A⁺ 区域）与支撑（该区域样例覆盖）是两个正交维度，构成一个 2×2 决策矩阵：
| | 有示范支撑 | 无示范支撑 |
|---|---|---|
| 可接地 | 带证书执行 | **主动模仿查询**（请人示范） |
| 不可接地 | **澄清对话**（语言歧义） | 拒绝 / 安全回退 |
这把「有求必应的语音助手」改造成「知道自己不知道的管家」，并把拒绝/查询作为安全阀。

**灵感 4（韵律-动作时序对齐：说到 ≠ 做到）**
直觉：语音的韵律（重音、停顿、语速）编码了方式与时序，示范轨迹编码了动作相位（接近-接触-搬运-释放）。二者需对齐：说「慢—慢—放」时动作相位也应放缓。定义韵律事件与动作相位的 DTW 对齐成本 `c_ta`，超阈值即判定「说到没做到」，拒绝发放执行证书。

**灵感 5（主动模仿查询 → 用最小人类代价填补支撑空洞）**
直觉：语音会主动暴露支撑空洞。系统不应被动等示范，而应生成**定向示范请求** `q`（如「请示范一次轻放玻璃杯」），并按 `U(q)=Δcov(q) − λ_h·effort(q) − λ_r·risk(q)` 选择收益最高的查询。新示范补入 `D_S` 后重估支撑与证书。这形成 **语音 → 模仿 → 语音** 的闭环，把「说话」变成主动学习的查询接口。

**灵感 6（金字塔扩展：语音-示范接地层 VIG）**
直觉：在第 54 轮动作-协同层 `𝔸` 之上叠加 **语音-示范接地层 `𝕍`**：`𝕍_0` ASR 与语义原子，`𝕍_1` 语音→A⁺ 接地，`𝕍_2` 示范支撑，`𝕍_3` 主动查询闭环。跨层证书需同时携带 `provenance`（示范来源）与 `grounding`（语言接地），形成 **证据-接地双证书**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（方式维扩展动作空间）**
`A⁺ = A_c × A_e × M`，`M ⊆ ℝ^k` 为方式空间（速度、力度、幅度、平滑度）。技能 S 的扩展剖面 `α_S⁺ : A⁺ → [0,1]`，满足 `∫_{A⁺} α_S⁺ = vol(S)`。

**定义 122（语音意图元组与接地）**
语音指令 `c` 解析为意图元组 `I(c) = ⟨v, o, m_req, τ_req, κ⟩`（动词、宾语、方式、时序限定、约束）。接地映射 `g` 把每个原子映到 `A⁺` 的一个区域或 `⊥`：`g : atom → 2^{A⁺} ∪ {⊥}`。当且仅当 `∀ atom, g(atom) ≠ ⊥` 时，`c` 可接地，其请求区域 `R(c) = ∏_atom g(atom)`（带约束交）。

**定义 123（示范支撑集与覆盖率）**
示范集 `D_S = {(s_i, a_i⁺)}_{i=1..n}`。`ε`-支撑 `supp_ε(D_S) = { a⁺ : ∃i, d_A(a⁺, a_i⁺) ≤ ε ∧ d_S(s, s_i) ≤ δ_s }`。区域 `R` 的覆盖率
`cov_ε(R, D_S) = vol(R ∩ supp_ε(D_S)) / vol(R)`，支撑空洞 `gap = 1 − cov_ε`。

**定义 124（接地-支撑双证书 GSC）**
`GSC_S(c) = (R, cov_ε(R,D_S), gap, manner_cov, prov(D_S), c_ta, decision, evidence)`，其中 `prov(D_S)` 为示范来源与时间戳，`c_ta` 为韵律-动作对齐成本。判定规则：
```
if R = ⊥:                       decision = clarify  (可恢复) / refuse
elif gap ≤ θ_g ∧ c_ta ≤ τ_ta:   decision = execute
elif gap ≤ θ_q:                 decision = query_demo
else:                           decision = refuse / fallback(safe_skill)
```
要求 `0 ≤ θ_g < θ_q ≤ 1`；执行仅在**支撑充分且时序对齐**时发放。

**定义 125（韵律-动作时序对齐）**
韵律事件序列 `E_p = {(t_k, type_k)}`，动作相位序列 `Φ = {(phase_j, t_j)}`。对齐成本 `c_ta = DTW_dist(E_p, Φ) / |path|`；`c_ta ≤ τ_ta` 时称韵律与动作「说到做到」，方式保真度 `m_fid = 1 − c_ta`。

**定义 126（主动模仿查询）**
示范请求 `q` 诱导的期望覆盖增益 `Δcov(q) = E_{d∼q}[cov(R*, D_S∪{d}) − cov(R*, D_S)]`。效用 `U(q) = Δcov(q) − λ_h·effort(q) − λ_r·risk(q)`；选 `q* = argmax_{q∈Q} U(q)`，当 `max U < ν` 时停止查询。

## 2. 关键算法 伪代码

### IP-121 VGP（Voice Grounding Parser）

```python
def voice_ground(command, asr_conf, ontology):
    atoms = parse_intent(command)   # v, o, m_req, tau_req, kappa
    regions = {}
    for name, val in atoms.items():
        reg, conf = ontology.ground(name, val)
        if reg is None:
            return GroundingResult(ungrounded=name,
                                   recoverable=ontology.has_alternative(name))
        regions[name] = (reg, conf * asr_conf)
    R = product_regions(regions)              # 约束求交
    return GroundingResult(R=R, conf=min(c for _, c in regions.values()))
```

### IP-122 DSC（Demo Support Coverage）

```python
def support_coverage(R, D_S, eps, n=2000, alpha=0.05):
    samples = sample_uniform(R, n)            # A+ 内采样
    covered = sum(1 for x in samples
                  if knn_dist(x.action, D_S.actions) <= eps
                  and knn_dist(x.state, D_S.states) <= delta_s)
    cov = covered / n
    lo, hi = clopper_pearson(covered, n, alpha)   # 覆盖率置信区间
    return Coverage(cov=cov, ci=(lo, hi), gap=1 - cov)
```

### IP-123 AIQ（Active Imitation Query）

```python
def active_imitation_query(R_star, skill, D_S, budget, lam_h=1.0, lam_r=1.0):
    best = None
    for q in generate_demo_requests(R_star, skill):
        delta_cov = expected_coverage_gain(q, R_star, D_S, skill)
        U = delta_cov - lam_h * human_effort(q) - lam_r * query_risk(q)
        if best is None or U > best.U:
            best = Query(text=q, U=U, delta_cov=delta_cov)
    return best if best is not None and best.U >= budget.nu else None
```

### IP-124 PTA（Prosody-Temporal Alignment）

```python
def prosody_temporal_alignment(prosody_events, action_trace):
    phases = extract_phase(action_trace)      # approach/contact/transport/release
    D, path = dtw(prosody_events, phases, cost=event_phase_cost)
    c_ta = D[-1][-1] / max(len(path), 1)
    return c_ta, map_events_to_phases(path)
```

### IP-125 GSC（Grounding-Support Certificate）

```python
def gsc(command, asr_conf, skill, D_S, theta_g, theta_q, tau_ta):
    g = voice_ground(command, asr_conf, ontology)
    if g.R is None:
        return Cert('clarify' if g.recoverable else 'refuse', reason=g.ungrounded)
    cov = support_coverage(g.R, D_S, eps)
    c_ta, _ = prosody_temporal_alignment(g.prosody, skill.traces)
    if cov.gap <= theta_g and c_ta <= tau_ta:
        return Cert('execute', R=g.R, cov=cov, c_ta=c_ta, prov=D_S.provenance)
    if cov.gap <= theta_q:
        q = active_imitation_query(g.R, skill, D_S, budget)
        if q is not None:
            return Cert('query_demo', q=q, gap=cov.gap, partial_region=g.R)
    return Cert('refuse' if cov.gap > theta_q else 'fallback',
                reason='unsupported', gap=cov.gap)
```

### IP-126 VIL（Voice-Imitation Loop）

```python
def voice_imitation_loop(command, skill_lib, D, budget, max_rounds=2):
    for _ in range(max_rounds):
        cert = gsc(command, asr_conf, select_skill(command, skill_lib), D, ...)
        if cert.decision == 'execute':   return execute_with_cert(cert)
        if cert.decision == 'clarify':   return ask_clarification(cert)
        if cert.decision == 'query_demo':
            demo = request_and_record(cert.q)     # 人类示范
            D.augment(demo); update_support(skill_lib, D)
            continue
        return safe_fallback(cert)                 # 拒绝/回退安全技能
    return safe_fallback(cert)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| VGP | O(|atoms|·|ontology|) | O(|atoms|) | 接地映射 sound、约束可交 |
| DSC | O(n·log|D_S|)（kNN 索引） | O(|D_S|) | ε-覆盖校准、置信下界 |
| AIQ | O(|Q|·n·log|D_S|) | O(|Q|) | 效用单调、停止条件 |
| PTA | O(|E_p|·|Φ|) | O(|E_p|·|Φ|) | DTW 最优、成本为度量 |
| GSC | O(DSC + PTA) | O(|D_S|) | 判定阈值 sound、拒绝安全阀 |

**正确性定理（Voice-Grounding-Support Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** ASR 置信已校准（可靠性图 ECE ≤ ε_asr）；**(A30)** 支撑估计器 (δ,α)-校准：`P(|ĉov − cov| ≤ δ) ≥ 1−α`；**(A31)** 韵律-相位 DTW 成本为度量且 `τ_ta` 已校准。则：
```
P(unsafe_exec) ≤ P(接地错误未被识别) + P(cov_true < ĉov − δ) + P(c_ta > τ_ta | accept)
               ≤ ε_asr + α + β_ta
```
关键：**要界的是误接受（false accept），而非误拒绝**；`clarify` / `query_demo` / `refuse` 是安全阀，宁可多问一句，不发放无证据的执行证书。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| ASR 错误被误判为接地鸿沟 | 高 | 双通道置信 + 澄清模板 + 复述确认 |
| 高维方式维支撑估计不可靠 | 高 | 降维 + 分层 ε + 校准区间 + 主动采样 |
| 主动查询打扰用户 | 中 | 效用阈值 + 批量查询 + 人类预算 |
| 韵律-相位对齐过拟合 | 中 | 多示教 + 正则 + 仅在 manner 原子触发 |
| 拒绝过保守导致可用性下降 | 高 | 安全回退技能 + 可调 θ_g/θ_q + 在线阈值校准 |

## 6. 本轮最大风险

**一句话**：语音-示范双通道把技能从「有能力」推进到「有证据且被语言接地」，但其 soundness **三重依赖 ASR 置信校准、示范支撑估计的 (δ,α) 校准、以及韵律-相位对齐阈值的可靠性**；一旦「听错」被误判成「接地空洞」、或支撑估计在高维方式维上系统性高估覆盖，系统就会在看似有证据的区域误接受，把语音幻觉执行包装成有证书的部署，故必须以 **校准置信 + 覆盖率置信下界 + 误接受绊线** 三重护栏，宁可多问一句、保守回退，绝不把「语言可说」当作「示范已证」。

```python
            demo = request_and_record(cert.q)      # 人类示范
            D.augment(demo); update_support(skill_lib, D)
            continue
        return safe_fallback(cert)                 # 拒绝/回退安全技能
    return safe_fallback(cert)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VGP | O(|atoms|·|ontology|) | O(|atoms|) | 接地 sound，约束可交 |
| DSC | O(n·log|D_S|) | O(|D_S|) | ε-覆盖校准，置信下界 |
| AIQ | O(|Q|·n·log|D_S|) | O(|Q|) | 效用单调，停止条件 |
| PTA | O(|E_p|·|Φ|) | O(|E_p|·|Φ|) | DTW 最优，成本为度量 |
| GSC | O(DSC+PTA) | O(|D_S|) | 判定阈值 sound，拒绝安全阀 |

**正确性定理（Voice-Grounding-Support Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** ASR 置信已校准（ECE ≤ ε_asr）；**(A30)** 支撑估计器 (δ,α)-校准；**(A31)** 韵律-相位 DTW 成本为度量且 `τ_ta` 已校准。则：
```
P(unsafe_exec) ≤ ε_asr + α + β_ta
```
关键：界的是**误接受**；`clarify / query_demo / refuse` 是安全阀，宁可多问一句，不发放无证据的执行证书。

## 5. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 接地鸿沟检测 | AUROC / 虚假执行率 | AUROC ≥ 0.90，虚假执行 ≤ 3% |
| E163 语音幻觉拒绝 ROC | false accept @ false refuse ≤ 10% | false accept ≤ 2% |

| E165 韵律-动作对齐 | 方式指令满意度、`c_ta` | 满意度 ≥ 85%，`c_ta ≤ τ_ta` |

**消融建议**：去掉 DSC（仅看 α_S）→ 预期虚假执行显著上升；去掉 PTA → 方式指令满意度下降；去掉 AIQ（随机示范请求）→ 样本效率下降 ≥ 30%。

## 6. 本轮最大风险

**一句话**：语音-示范双通道把技能从「有能力」推进到「有证据且被语言接地」，但其 soundness **三重依赖 ASR 置信校准、示范支撑估计的 (δ,α) 校准、以及韵律-相位对齐阈值的可靠性**；一旦「听错」被误判成「接地空洞」、或支撑估计在高维方式维上系统性高估覆盖，系统就会在看似有证据的区域误接受，把语音幻觉执行包装成有证书的部署，故必须以 **校准置信 + 覆盖率置信下界 + 误接受绊线** 三重护栏，宁可多问一句、保守回退，绝不把「语言可说」当作「示范已证」。
