# 第 12 轮（新灵感循环第 1 轮；本轮灵感：「容错控制」×「灵巧手」）

> **基线**：第 11 轮 MetricVoiceGauge-NCD-H（定义 554–570；引理 96–103；实验 E589–E606；IP-363–366）。
> 本轮纪律：**故障可观、隔离先于重构、重构只减不增、证书对故障假设鲁棒**。不推倒 v11：HAS/HCC/HATD/HDT、MetricVoiceGauge 九不变式、NGE/DSL/CC/CWM/CAE/NCP、AC/MW/ID、DA/SPR/Cal 全部保留；三个新组件以**互不相交端口**接入，任一失效注入中立元，严格退回 v11（引理 109），再沿 v11 十三级链退回 v10/v9/v8/v7/v6。本轮只做三件事：把"故障"变成技能的一等状态、把"故障证书"变成可隔离的鲁棒证书、把"灵巧手冗余"变成可控的优雅降级资源。

## 0. 直觉与动机

### 0.1 v11 真正遗漏的两个隐含假设

v11 已经把规范、接触、因果、谐波四类约束接进同一个块级决策闭环，并把执行器柔顺度提升为技能与证书的一等公民。但它的四重证书仍默认两件事：

1. **执行器与传感器是健康的，且健康状态在执行中不变。** π_h 的 k_h、d_h，HCC 的 β 余量，HDT 的域随机化，都假设"同一套硬件从开始到结束按同一模型工作"。真实灵巧手会出现：编码器跳变/漂移、电流传感偏置、腱绳蠕变或断裂、关节卡滞、触觉阵列局部失效、驱动板降额。v11 的谐波模型可以吸收**连续的参数漂移**，却不能区分"参数漂移"与"离散故障"；更严重的是，HCC 会把故障残差解释成模型失配，从而继续签发"柔轮安全"的证书。这是**故障被证书吸收**，而不是被诊断。

2. **技能与分解在故障后仍按原能力假设执行，且能力损失是连续的。** v11 的任务分解以谐波带宽/共振/热为约束，但没有"能力"这一维度。灵巧手的本质是**高维冗余**：多指、多关节、多接触模式、腱耦合、协同子空间。一个手指失效并不意味着任务失败，可能只需换抓取模式、把接触重新分配到剩余手指、或退到二指捏取。但 v11 没有形式化的"故障后可重构能力"，也没有"重构不能偷偷扩张执行集"的纪律。冗余如果只被用来"继续做"，就会把故障掩盖到饱和；冗余如果被正确建模，就是**优雅降级的物理资源**。

两个盲点互相放大：故障越隐蔽，证书越自信；冗余越强，故障越容易被补偿掩盖；直到某次接触相变或负载峰值让冗余耗尽，能力缺口突然暴露，而证书仍按"健康 + 未饱和"签发。

### 0.2 灵感 1（容错控制 → 从"鲁棒吸收"到"诊断—隔离—重构"）

直觉：鲁棒控制把不确定性吸收进裕度，容错控制则要求**先知道发生了什么**，再决定"继续/降级/中止"。灵巧手的接触残差与故障残差在统计上高度混淆：滑移会产生力矩尖峰，编码器跳变也产生尖峰；抓取物体变重会产生电流上升，腱绳断裂也会。FTC 的关键不是把阈值调大，而是构造**方向性残差**：用多指/多关节的冗余观测做一致性检验（parity space），把"外部接触"与"内部执行器故障"投影到不同残差方向；并显式维护**故障假设集**与**隔离模糊类**，在模糊未消除前只允许对模糊类内所有故障都安全的动作。

核心创新：**故障感知技能契约（Fault-Aware Skill Contract, FASC）+ 故障诊断与隔离证书器（Fault Diagnosis & Isolation Certifier, FDIC）**。技能 π_h^f 显式携带健康状态 H、故障假设集 F、故障条件下的能力包络 E_f 与重构策略 ρ；FDIC 输出故障证书 Ĉ_f=(检测时延上界, 隔离模糊类, 误报/漏报界, 置信度)，并把"故障未隔离"变成证书的一个显式前提，而不是隐式假设。

### 0.3 灵感 2（灵巧手 → 冗余是优雅降级的资源，不是隐藏故障的缓冲）

直觉：灵巧手与串联机械臂的最大区别是**接触模式本身就是冗余**。同一物体可以用三指包络、二指捏、侧捏、掌心托、环境约束；同一指尖可以用不同关节组合到达；腱驱动还有协同子空间。故障后不必"用同样的方式更用力"，而可以**换一种接触拓扑**。但换拓扑必须满足：新抓取的力闭合/抗扰裕度足以覆盖任务所需扳手；新协同子空间仍能实现任务关键方向；新接触不引入新的共振/热/滑移风险。

核心创新：**冗余感知灵巧重构器（Redundancy-Aware Dexterous Reconfigurer, RADR）**。它定义"故障后能力测度"（抓取扳手空间体积、最小奇异值、协同秩、力闭合裕度、接触模式可达集），在故障假设下计算**能力包络**，并选择重构动作（换抓取、重分配手指、切换协同子空间、利用环境约束、降级任务）。RADR 只做"能力可行 + 证书闭合"的重构，不直接改技能参数。

### 0.4 三者如何统一

把决策写成**故障假设下的能力约束任务分解**：FDIC 维护故障信念 b_f 与隔离模糊类 A；FASC 为每个技能给出"对 A 内所有故障都安全"的鲁棒包络（或明确要求先隔离）；RADR 在能力空间里选择重构；HATD 的每段必须满足"在 b_f 的置信集上，至少存在一个重构使段可执行，且证书闭合"。共享状态 ζ_f=(b_f, A, H, cap, ρ)。**FTC 回答"现在坏没坏、坏在哪"，灵巧手回答"坏了还能怎么抓"，分解回答"怎么切段才不越过能力边界"**。三者不是补丁，而是"诊断—能力—重构"闭环。

### 0.5 为什么不是这些"显然的解法"

- **不是"把鲁棒裕度调大"**：那会把故障和接触一起吸收，牺牲可用性且无法解释能力缺口。
- **不是"故障后一律紧急停止"**：灵巧手的冗余本可安全完成任务；一律停是可用性灾难，也浪费了 FTC 的核心价值。
- **不是"多传感器融合就一定可诊断"**：若所有传感器共享同一故障源（同一驱动板、同一腱、同一标定），独立性不成立；需要显式的可诊断性条件。
- **不是"重构即重新规划"**：重构必须受证书与预算约束，且不能扩张 v11 的执行集。

## 1. 研究问题（轮次升级版）

- **Q1（故障可检测/可隔离性）**：在接触丰富、模式频繁切换的灵巧操作中，用关节/电机编码器、电流、触觉、腱张力，如何构造对接触扰动解耦的残差，使执行器/传感器故障的检测时延与隔离模糊类有可证界？
- **Q2（故障条件证书）**：当故障只被隔离到模糊类 A 时，如何签发"对 A 内所有故障都安全"的鲁棒证书？其保守性代价与可执行段非空率如何权衡？
- **Q3（冗余重构最优性）**：给定故障后的能力包络与任务所需扳手/运动，如何选择抓取拓扑/手指分配/协同子空间，使任务完成率最大、性能降级最小、且不越过 v11 证书？
- **Q4（三环耦合与 v11 兼容）**：FDIC 的故障信念与 HCC 的谐波参数、HATD 的段、NCP 的规范盾如何避免同源误差？故障重构是否会与接触/谐波中止点冲突？三者全失效能否逐位退回 v11？

## 2. 设计原则（在 P16–P18 基础上新增 P19–P21）

**P19 故障可观与隔离律（Fault Observability & Isolation）**
任何故障容错动作的前提是：故障已被检测，且其隔离模糊类 A 足够小，使得存在对 A 内所有故障都安全的动作；否则必须先执行隔离动作（主动激励/探测），不得用"更鲁棒的控制器"隐式吸收。故障假设、残差方向、误报/漏报界必须显式记录在技能与证书中。

**P20 故障条件证书律（Fault-Conditioned Certification）**
证书必须写成 Ĉ_f(·|A,H)：对隔离模糊类 A 与健康状态 H 的**每一个**成员都成立；不允许用点估计的故障参数签发。若证书只能对部分成员成立，则这些成员必须被排除（需要可观测证据），否则该段不可执行。故障证书与物理/接触/谐波/规范证书合取，且不能放宽任何既有证书。

**P21 重构只减不增律（Reconfiguration Contracts Only）**
RADR 只能删除候选段、缩小技能包络、替换为能力更低的抓取/协同模式，不能新增 v11 未认证的技能、不能放宽证书界、不能扩大执行集。重构的收益必须用"能力包络仍覆盖任务需求"证明，而不是用"上次这样做成功过"。

## 3. 与基线的接口（如何退化）

- FASC 失效 ⇒ 注入故障中立元：H≡健康、F=∅、E_f≡v11 包络、ρ≡恒等，技能退回 π_h，**等价 v11 灵巧路径**；
- FDIC 失效 ⇒ 故障证书恒真、不产生隔离义务，HCC 仍在线拦截谐波/接触，**等价 v11 证书路径**；
- RADR 失效 ⇒ 不做重构，HATD 退回 v11 谐波感知分解，**等价 v11 分解路径**；
- 三者全失效 ⇒ MetricVoiceGauge-NCD-H v11，再按 v11 十三级链退回 v10/v9/v8/v7/v6；
- **安全继承**：物理/接触/谐波/规范四重证书仍是硬门，新增故障证书只能删段；FDIC 只能收缩故障假设集（需证据）或触发隔离；RADR 只能降级。任何新模块都不能绕过 v11 适用证书（引理 110）。

## 4. 预期贡献

1. **故障感知技能契约与故障隔离证书**：把健康状态、故障假设集、隔离模糊类、故障条件包络提升为技能与证书的一等变量，覆盖 v11 完全未建模的离散故障安全性；
2. **冗余感知灵巧重构器**：用抓取扳手空间/协同秩/力闭合裕度定义故障后能力包络，实现"换接触拓扑而非硬扛"的优雅降级；
3. **故障假设下的能力约束分解**：HATD 的每段在故障信念置信集上闭合，解决"故障后要么全停、要么盲干"的二难；
4. **诊断—能力—重构统一与 v11 兼容**：E607–E626 覆盖故障注入、隔离、鲁棒证书、重构、退化和长跑；形式化中立元证明逐位退回 v11。

## 5. 本轮最大风险

**一句话**：接触相变产生的残差与执行器/传感器故障的残差在方向和幅度上高度混淆，FDIC 把真实故障判成"接触不确定性"并继续签发证书，同时 RADR 用冗余把故障补偿到不可见，直到冗余饱和的瞬间能力缺口突现，即**被冗余掩盖的故障在最需要余量的时刻才暴露**。

F = {f_0, f_1, …, f_m},   f_0 = healthy
```
每个 f_i 由故障位置（关节/传感器/腱/驱动板）、故障类型（加性偏置、乘性增益、卡滞、丢帧、断裂）与严重度区间 [s_i^min,s_i^max] 描述。健康状态 H∈[0,1]^n 是连续退化量；离散故障是 H 的跳变或锁定，连续磨损是 H 的慢漂移。**关键约定**：H 不是"置信度"，而是物理退化程度的可观测估计；其不确定性由故障信念 b_f 与集合值健康估计 H_set 共同表示。

**定义 572（方向性残差与故障签名 Directional Residual & Fault Signature）** 在当前接触模式 m 的工作点局部线性化：
```
r(k) = W_f(m)·φ(k) + W_c(m)·c(k) + n(k)
```
其中 φ 为故障幅值向量，c 为外部接触/负载扰动，n 为噪声与未建模动态。接触解耦残差
```
r⊥(k) = Π_c(m)·r(k),   Π_c(m) = I − W_c(m)W_c(m)^†
```
投影后故障签名 S_f(m)=Π_c(m)W_f(m)。**可检测性**要求 σ_min(S_f(m)) 足够大；**可隔离性**要求不同故障的投影签名夹角/最小距离 ≥ γ_iso。若两个故障的签名在 γ_iso 内不可分，则它们属于同一隔离模糊类 A。该构造不是"消除接触"，而是把接触扰动投影到与故障签名尽可能正交的方向；残余接触泄漏由 ε_c 显式计入。

**定义 573（故障感知技能契约 Fault-Aware Skill Contract）** 一个 FASC 是 v11 HAS 的扩展：
```
π_h^f = ( π_h, H, F, {E_f}_{f∈F}, {Ĉ_f}_{f∈F}, ρ, pre_f, post_f )
```
其中 π_h 为 v11 技能；E_f 是技能在故障 f 下仍满足 v11 四重证书的状态—模式—相位集合；ρ 是重构策略（定义 578）；pre_f 要求当前状态属于鲁棒包络 E_A（A 为当前模糊类）或隔离义务已满足；post_f 要求结束状态同样在 E_A 内且能力仍覆盖任务需求。**技能不能在 E_A 外执行**；若 A 太大导致 E_A 为空，只能执行隔离动作或中止。

**定义 574（故障证书 Fault Certificate）** FDIC 在线签发
```
Ĉ_f = ( τ_det, A, α_FAR, β_MD, γ_iso, conf, indep_ok )
```
有效 ⇔
```
τ_det ≤ τ_max ∧ |A| ≤ N_amb ∧ α_FAR ≤ α_max ∧ β_MD ≤ β_max
∧ conf ≥ 1−δ ∧ indep_ok = true
```
`indep_ok` 表示故障证据与被认证模型/证书证据在 provenance 上独立（定义 582）；若为 false，只能退回 v11 固定阈值，故障证书不得作为放宽任何界的依据。约定 A=∅ 时 Ĉ_f≡true、indep_ok=true，以便中立元严格退化为 v11。**故障证书不是"健康证书"**：它只声明"故障已被检测并隔离到 A，且证据独立"，安全性仍由鲁棒证书定义 575 承担。

**定义 575（隔离模糊类与鲁棒故障证书 Robust Fault Certificate）** 对模糊类 A 与健康集合 H_set，鲁棒证书定义为逐分量最坏情形：
```
Ĉ_f(A,H_set) = ∧_{f∈A} ∧_{H∈H_set} Ĉ_f(·|f,H)
θ_max(A) = max_{f∈A,H∈H_set} θ_max(f,H),   τ_max(A) = max_{f∈A,H∈H_set} τ_max(f,H)
E_diss_min(A) = min_{f∈A,H∈H_set} E_diss_min(f,H), …
```
有效 ⇔ 每个分量都满足 v11 的物理/接触/谐波/规范界，且对每个 f∈A 都存在故障安全中止点。若 A 含传感器故障，状态估计必须用集合值观测器给出 X_A，证书对 X_A 再做一次最坏情形量化。**A 越大，证书越保守；当 A 使可行段为空时，必须隔离或中止，而不是放宽证书。**

**定义 576（故障容错不变式与中止点 Fault-Tolerant Invariant & Abort Points）** 中止点 p∈P^f 满足 I_ft(p)：
```
∀f∈A, ∃ 从 p 开始的恢复/重构轨迹，使
   (完成当前段 ∧ 全程满足 I_c ∧ I_h ∧ I_norm)
   ∨ (到达 q∈P^f 的受控释放/保持状态，且不触发共振、不破坏力闭合)
∧ 全程 Cap(ρ,H,f) ⪰ Cap_req
```
多语义中止点升级为 P_t = P_t^nav ∪ P_t^c ∪ P_t^h ∪ P_t^f。块可执行必要条件：当前模式对应的 v11 中止点集非空，且新增的故障中止点集 P^f 非空（若 FDIC 未激活则 P^f 退化为 P_t^c∩P_t^h）。

**定义 577（灵巧能力测度 Dexterous Capacity Measure）** 对抓取拓扑/手指分配/协同基 (ρ,H,f)，定义
```
Cap(ρ,H,f) = ( V_GW, σ_min, r_syn, γ_fc, μ, reach )
```
- V_GW：抓取扳手空间体积（或任务方向上的支撑函数下界）；
- σ_min：抓取映射 G 与手雅可比 J 的联合最小奇异值；
- r_syn：有效协同秩（能独立控制的任务方向数）；
- γ_fc：力闭合裕度（接触力可行域到边界的距离）；
- μ：可操作度；reach：故障后可达接触模式集。
Cap 带部分序：Cap ⪰ Cap_req 当且仅当每个分量都不低于任务要求。**能力测度是充分条件而非必要条件**：它保守，但可在多项式时间内计算并用于分解剪枝。

**定义 578（重构动作与退化映射 Reconfiguration & Degradation Map）** 重构动作
```
ρ ∈ R = { 换抓取拓扑、重分配手指/接触点、切换协同子空间、利用环境约束、降级任务、受控释放 }
```
退化映射 D_f: π_h → π_h^ρ 必须满足：
```
(i) 不新增 v11 未认证的技能；
(ii) 不放宽任何 v11 证书界；
(iii) 只删除候选段/缩小包络/降低能力需求；
(iv) 重构瞬态本身必须满足 v11 四重证书与故障中止点条件。
```
RADR 的输出是一个**收缩后的**技能—抓取对，而不是"更强的控制器"。

**定义 579（故障容错任务分解 Fault-Tolerant Task Decomposition）** 输入：任务图 G、故障信念 b_f、模糊类 A、故障状态 ζ_f。输出有序段序列 S=[seg_1,…,seg_M]，每段
```
seg = ( π_h^{1:K}, ρ, Ĉ_joint, Ĉ_f(A,H_set), P^nav, P^c, P^h, P^f )
```
分解目标：
```
min M
s.t. ∀seg, ∀f∈A_supp:
   (鲁棒证书) Ĉ_joint ∧ Ĉ_f(A_supp,H_set) 有效
   (能力)     Cap(ρ,H,f) ⪰ Cap_req(seg)
   (v11 约束) 带宽/共振/热/接触模式连贯（v11 定义 557）
   (中止)     P^f ≠ ∅ ∧ v11 中止点集非空
   (切换)     seg 内接触模式切换数 ≤ N_switch_max
```
其中 A_supp={f: b_f ≥ δ_supp} 为可信故障支撑集。求解：分层 A*/MCTS，启发式 = 剩余语义距离 + 能力缺口 + 模糊类熵；先按能力剪枝，再按证书剪枝。

**定义 580（故障信念更新与隔离义务 Fault Belief & Isolation Obligation）** 用 HMM/粒子滤波更新
```
b_f(k) ∝ P(r⊥(k)|f,H)·Σ_{f'} P(f|f')·b_{f'}(k−1)
```
故障起始率 λ、切换矩阵由实验/先验给定。隔离义务
```
O(A) = { u∈U_diag : u 通过 v11 四重证书 ∧ IG(u;A)/cost(u) ≥ ρ_diag }
```
IG 为期望信息增益（签名分离度/后验熵下降）。若 O(A)=∅，则只能使用 A 上的鲁棒证书；若鲁棒证书仍不可行，触发故障中止。**禁止**用"更高增益的鲁棒控制器"替代隔离义务。

**定义 581（故障掩盖度 Fault Masking Index）** 定义
```
mask_f(k) = A_comp(k) / ( A_comp(k) + A_evidence(k) + ε )
```
A_comp 为超出标称控制的多余补偿权威（关节力矩余量、未使用协同方向、接触力重分配量），A_evidence 为故障残差的信噪比/证据强度。mask 高表示"用冗余把故障压住、但证据很弱"。触发规则：
```
mask_f(k) > δ_mask ∧ Cap_margin(ρ,H,f) < γ_mask ⇒ 强制隔离或主动降级
```
该指标把"冗余掩盖故障"从定性风险变成可监测的运行时量。

**定义 582（故障账本与证据图 Fault Ledger & Evidence Graph）** 只追加、内容寻址的账本 L_f 记录：
```
entry = (hash, 时间, 故障假设, 残差摘要, 证据来源与独立性标签,
         重构动作, 证书, 决策, 执行结果)
```
证据图 G_f 的边为"证据→诊断""诊断→证书""证书→段"。一条证据可作为证书证据，当且仅当其 `indep_ok` 为真且 `use_tags` 未被标记为 reused。账本使"哪条残差支持了哪个诊断、哪个诊断又支持了哪个证书"可审计、可复现、可追责。

**定义 583（v12 中立元表）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| FASC 技能 | π_h^f ← π_h（H≡健康、F=∅、E_f≡v11 包络、ρ≡恒等） | Level-3（v11） |
| FDIC 证书 | Ĉ_f 恒真、A=∅、无隔离义务、故障信念冻结 | Level-2（v11） |
| RADR 重构器 | 不做重构、Cap 不参与规划、ρ≡恒等 | Level-1（v11） |

**定义 584（v12 退化链）** 见第 0 节：Level-0 全激活；Level-1 RADR 失效；Level-2 FDIC 失效；Level-3 FASC 失效；Level-4…Level-14 对应 v11 Level-1…Level-11。前三个端口互不相交，任意子集失效都落到 v11 的明确退化点。

**定义 585（诊断动作与嵌套盾 Diagnostic Actions & Nested Shield）** 诊断动作集
```
U_diag = { 主动正弦微扰、负载阶跃、单指轻触、协同基激励、接触点重定位、短暂释放 }
```
每个 u 必须 (i) 通过 v11 物理/接触/谐波/规范四重证书；(ii) 信息增益/成本 ≥ ρ_diag；(iii) 有故障中止点。嵌套盾：若 u 不安全，退回被动观测；若被动观测仍不能缩小 A，则收缩包络；若包络为空，故障中止。**诊断动作是"用安全的信息换取可执行性"，不是"用冒险换取性能"。**

## 2. 形式化定义（要点与升级）

**升级定义 554′（谐波增强技能，v12）** HAS 升级为 FASC π_h^f（定义 573）。前置条件增加
```
state ∈ E_A(H_set) ∧ (A=∅ ∨ 隔离义务已完成) ∧ Cap(ρ,H,f) ⪰ Cap_req(π)
```
后置条件同理。v11 技能视为 F=∅、H≡健康、ρ≡恒等的特例。

**升级定义 555′（谐波合规性证书，v12）** HCC 的证书与故障证书合取：
```
Ĉ_joint = Ĉ_physical ∧ Ĉ_contact ∧ Ĉ_h ∧ Ĉ_f(A,H_set)
```
有效 ⇔ 四者均有效。若 A 含影响编码器/电流/触觉的传感器故障，则 Ĉ_h 与 Ĉ_contact 必须先对 X_A 做集合值量化，否则不得签发。当 FDIC 中立时 Ĉ_f≡true，逐项退回 v11 定义 555。

**升级定义 557′（谐波感知分解，v12）** HATD 的每段候选新增
```
∀f∈A_supp: Cap(ρ,H,f) ⪰ Cap_req(seg) ∧ Ĉ_f(A_supp,H_set) 有效
```
且段的入口/出口必须落在 E_{A_supp} 内。若一段在某个 f∈A_supp 下无可行重构，则该段不可执行；HATD 必须换粒度、换抓取或请求隔离，而不是假设故障不存在。

**升级定义 531′（软硬约束衔接，v12）** M₀ 硬检查新增故障入口：
```
残差超过检测阈但未被诊断 ⇒ 硬违规（禁止带病执行）；
隔离模糊类 A 超出 N_amb 且无可用隔离动作 ⇒ 硬违规；
Cap(ρ,H,f) ≺ Cap_req 仍尝试执行 ⇒ 硬违规；
重构瞬态未通过 v11 证书 ⇒ 硬违规。
```
v11 的物理/接触/规范 M₀ 判据不因故障模块存在而放宽。

**升级定义 534″（多语义中止点，v12）** P_t = P_t^nav ∪ P_t^c ∪ P_t^h ∪ P_t^f。块可执行必要条件：当前模式对应的 v11 中止点集非空，且 P^f 非空；在接触模式还要求 P^c∩P^h∩P^f 非空（或存在已认证的受控释放）。

**升级定义 547′（接触证书，v12）** 若 FDIC 的模糊类 A 含触觉/编码器故障，Ĉ_contact 的定义域从"标称状态"改为"集合值状态 X_A"，并对 X_A 取最坏情形；若无法界定 X_A，则接触证书不可签发，必须隔离或退回 v11 固定余量（且不得引用故障证据）。

class FaultAwareSkillContract:
    def __init__(self, base_skill, healthy_envelope, fault_envelopes,
                 reconfig_policy, fault_pre, fault_post):
        self.base = base_skill                    # v11 π_h
        self.E_healthy = healthy_envelope
        self.E_f = fault_envelopes                # {f: envelope}
        self.rho = reconfig_policy
        self.pre_f, self.post_f = fault_pre, fault_post

    def robust_envelope(self, A):
        # 定义 575：对模糊类 A 取交集
        env = self.E_healthy
        for f in A:
            env = env.intersect(self.E_f[f])
            if env.is_empty():
                return None
        return env

    def check_pre(self, state, A, H_set, capacity_req):
        env = self.robust_envelope(A)
        if env is None or state not in env:
            return False
        if H_set is not None and not self._health_feasible(H_set):
            return False
        if A and not self._isolation_obligation_satisfied(A):
            return False
        return self._capacity_covers(state, A, capacity_req)

    def degrade(self, fault, state):
        # 定义 578：只收缩，不扩张
        cand = self.rho.propose(self.base, fault, state)
        return cand if cand is not None and cand.contracts_only() else None

# IP-369 RedundancyAwareDexterousReconfigurer
class RedundancyAwareDexterousReconfigurer:
    def __init__(self, hand_model, capacity_requirements, reconfig_catalog):
        self.hand = hand_model
        self.req = capacity_requirements
        self.catalog = reconfig_catalog

    def capacity(self, grasp, H, f):
        # 定义 577：扳手空间 / 奇异值 / 协同秩 / 力闭合裕度
        gw = self.hand.grasp_wrench_space(grasp, H, f)
        J = self.hand.hand_jacobian(grasp, H, f)
        return Capacity(V_GW=gw.volume(),
                        sigma_min=min_singular_value(J),
                        r_syn=self.hand.synergy_rank(grasp, H, f),
                        gamma_fc=gw.force_closure_margin(),
                        mu=self.hand.manipulability(J),
                        reach=self.hand.reachable_contact_modes(grasp, H, f))

    def propose(self, skill, A, H_set, state):
        # 定义 578：只返回能力覆盖 + v11 证书闭合的重构
        out = []
        for rho in self.catalog:
            if not rho.contracts_only():
                continue
            ok = True
            for f in A:
                for H in H_set:
                    if not (self.capacity(rho.grasp, H, f) >= self.req[skill]):
                        ok = False
                        break
            if ok and rho.reconfigured_skill(skill).passes_v11_certificates(state):
                out.append(rho.reconfigured_skill(skill))
        return out

            trigger_fault_safe_abort(ctx)      # 定义 576：I_ft ∧ v11 中止点
            return

    # ---- RADR：5Hz 故障后能力评估与重构（摊销 ≤0.5ms）----
    if current_chunk is None or current_chunk.exhausted or b_f.changed():
        reconfigured = radr.propose(current_skill, A, ctx.H_set, ctx.state)
        # 由重构后的技能与 v11 段生成候选；没有重构则保持 v11 段
        segments = hatd.decompose(task_graph, ctx.harmonic_state, ctx.env_est,
                                  fault_state=ctx.zeta_f,
                                  reconfig_candidates=reconfigured)
        cands = segments_to_candidates(segments)
        current_chunk = planner.plan_with_fault(
            ctx.state, nge.b, ctx.delta_dom, ctx.tau_dom,
            trust_ok=(ctx.delta_dom < ctx.tau_dom and ctx.risk_slam < M.tau_slam),
            harmonic_state=ctx.harmonic_state,
            harmonic_pred=harmonic_pred,
            fault_cert=fault_cert,
            capacity_req=ctx.cap_req)

    # ---- 50Hz：v11 守卫 + 故障守卫（合计 ≤1.1ms）----
    verdict, k_next = chunk_guard_fault(current_chunk, k_exec, live_obs,
                                        nge.b, hcc, fdic, radr)
    if verdict == 'fault_abort':
        current_chunk.execute_fault_safe_abort(k_next)   # 定义 576
        current_chunk = None
    elif verdict == 'reconfigure':
        current_chunk.replace_skill(k_next, radr.best_contracting(ctx))
    elif verdict == 'recover':
        execute_recovery(nge.epistemic_recovery())
    else:
        execute(current_chunk.skills[k_next])

    # ---- v10/v11 继承路径（GCT/ER/5 维风险/奖励/ID）----
    C, spatial_cert, claims, metrics, rewards = M.inherited_v11_path(ctx)

    # ---- 故障账本与在线校准（异步）----
    fdic.ledger.append(b_f, A, fault_cert, current_chunk, verdict)
    if cycle_idx % T_calib == 0 and real_trajectory_available():
        hdt.update_calibration(real_trajectory)

    return C, spatial_cert, claims, metrics, rewards
```

## 4. 推导

**引理 104（故障可检测性与隔离界的时延界）** 设 (A1) 接触解耦后噪声有界 ‖Π_c n(k)‖ ≤ ε_n；(A2) 接触泄漏 ‖Π_c W_c c(k)‖ ≤ ε_c；(A3) 故障 f 在 k₀ 发生，解耦残差沿故障签名方向的每步增量至少为 ρ_f（阶跃故障取 ρ_f=g_f·δ_f，渐进故障取每步增量），且 σ_min(Π_c W_f) ≥ g_f；(A4) 检测阈 h = ε_n+ε_c+ν（ν>0）。则健康时无误报（确定性噪声模型），故障检测时延满足
```
τ_det ≤ 1 + ceil( (ε_n+ε_c+ν) / ρ_f )
```
当 ρ_f>0 时有限；对阶跃故障该界退化为 1 个采样，对渐进故障为残差累积到阈值所需的步数。隔离：若 ‖S_f(e_i−e_j)‖ ≥ γ_iso，则 f_i,f_j 可分；否则并入同一模糊类 A。噪声为次高斯时，误报率满足 α_FAR ≤ 2·exp(−ν²/(2σ²))（单次检验），对窗口做 union bound。证明：由 r⊥=S_fφ+Π_c n+Π_c W_c c 与三角不等式，健康时 ‖r⊥‖≤ε_n+ε_c<h；故障后残差沿签名方向以至少 ρ_f/步增长，超过阈值即触发。隔离界由签名差的范数与最近邻分类的间隔直接得到。∎

**引理 105（隔离模糊类下鲁棒证书的安全性）** 设真实故障 f*∈A、真实健康 H*∈H_set，且鲁棒证书 Ĉ_f(A,H_set) 有效。则执行期间 v11 的物理/接触/谐波/规范约束全部满足；若 A 中存在某个故障使可行集为空，则鲁棒证书为空（不可签发）。证明：Ĉ_f(A,H_set) 对每个分量取 A×H_set 上的最大值（约束）或最小值（耗散），而 f*,H* 属于该集合，故真实值 ≤ 最坏上界 ≤ 极限；耗散同理。若某成员无安全动作，最坏情形本身越界，证书为空。∎

**引理 106（冗余重构的优雅降级存在性）** 设 (A1) 对每个 f∈A，重构后抓取映射 G(ρ,f) 在任务扳手方向上的最小奇异值 σ_G(ρ,f) ≥ σ_req；(A2) 协同基 U(ρ,f) 在任务运动子空间上的最小奇异值 σ_U(ρ,f) ≥ σ_req；(A3) 力闭合裕度 γ_fc(ρ,f) > 0；(A4) 重构技能通过 v11 四重证书。则存在故障容错执行使任务扳手/运动仍可实现；相对健康抓取的接触力上界增加不超过
```
Δ‖λ‖/‖λ‖ ≤ σ_G^H/σ_G(ρ,f) − 1
```
跟踪误差增加不超过 L_d(1/σ_U(ρ,f) − 1/σ_U^H) + ε_model（L_d 为扰动—误差 Lipschitz 常数）。证明：扳手平衡方程 w=Gλ 在 σ_G≥σ_req 时可解且 ‖λ‖≤‖w‖/σ_G；协同映射的可控性由 σ_U 给出；误差界由线性化灵敏度与 Lipschitz 性得到。该条件是充分非必要：能力测度保守，但不排除更优的非线性重构。∎

**引理 107（故障容错分解的存在性与近似）** 设任务图有限、故障支撑集 A_supp 有限、离散化能力空间紧致，且存在满足定义 579 的分解 S*。则 FT-HATD 的分层最好优先搜索在有限步内找到可行分解；在离散化粒度 ε 下段数满足 M ≤ M_opt + 1。若不存在可行分解，算法返回隔离动作或故障中止，**绝不返回未认证段**。证明：能力剪枝与证书剪枝只会删除不可行分支；启发式（剩余语义距离 + 能力缺口 + 模糊熵）非负且一致，故最好优先不丢最优分支；离散化误差使段数最多多一段。无解时由定义 579 的可行性判据与 v11 单原语回退保证返回安全动作。∎

**引理 108（故障掩盖的自证不可能性）** 设诊断器与证书器共用同一残差模型，且模型类足够丰富。则存在两个环境 E₀（健康 + 未建模接触柔顺）与 E₁（故障 f₁ + 标称接触），它们在全部可用残差观测上产生完全相同的序列，但在某个状态 x* 上的安全集不同。任何仅依赖该残差的证书器要么同时接受 E₀ 与 E₁（在其中一个环境不安全），要么同时拒绝（真空）。因此非平凡的故障证书必须依赖**独立证据**（指令—测量对照、跨指一致性、主动探测）或排除其中一个环境的强先验。证明：由残差序列不可区分性，证书器是残差序列的函数，故对两环境输出相同；而安全集在 x* 不同，故至少一个输出错误。∎

**引理 109（中立元退化等价 v11）** 将定义 583 的三个中立元分别注入 FASC/FDIC/RADR 端口，则：FASC 退化为 π_h，FDIC 的故障证书恒真且不产生隔离义务，RADR 不做重构；主闭环的候选技能集、证书判据、分解结果、规划评分与调用序列逐位等于 v11。证明：逐端口代入；三端口互不相交，代入后可交换至调度顺序；FASC 中立时 E_f≡v11 包络，FDIC 中立时 Ĉ_f≡true，RADR 中立时 ρ≡恒等，故执行集与 v11 相同。再由 v11 引理 102 继续退回 v10/v9/v8/v7/v6。∎

**引理 110（五重证书合取的安全继承）** v12 的执行管线为
```
物理 ∧ 接触 ∧ 谐波 ∧ 故障 → 规范盾 → 因果评分
```
FASC 只能收缩包络，FDIC 只能收缩模糊类（需证据）或触发隔离，RADR 只能降级。对 v11 技能子集，故障证书在中立时恒真，故执行集等于 v11 安全集；对 FASC 新技能，引理 104–107 覆盖故障安全，v11 引理 97–101 覆盖谐波/接触/规范/因果。因此不存在绕过任何 v11 适用证书的执行路径，v11 引理 101 的安全继承在 v11 子集上继续成立。∎

**引理 111（预算守恒 v12）** 新增在线成本上界：FDIC 残差库（6–12 DoF、4 通道）≤0.3ms；故障信念更新 O(|F|²)≤0.1ms；鲁棒证书 O(|A|·d_cert)≤0.2ms；RADR 能力评估 5Hz、摊销 ≤0.5ms；FT-HATD 在 v11 分解上增加 |A_supp| 倍证书检查，摊销 ≤1.5ms；隔离动作规划 1Hz、摊销 ≤2ms。v11 继承路径 ≤11ms。静态 EDF 校验后决策侧典型 ≤12ms、p99 ≤22ms，50Hz 保持。若某 tick 无法在预算内完成故障证书，则**该 tick 自动退回 v11 固定阈值**（deadline-aware fallback），不丢拍、不使用过期故障证书。证明：逐项代入复杂度表并做 EDF 校验；回退分支的最坏执行时间不超过 v11。∎

**引理 112（故障后性能降级界）** 设 (A1) 故障估计误差 ‖f̂−f*‖ ≤ ε_f；(A2) 能力裕度 γ = min_i(cap_i(ρ,f)/cap_req,i) − 1 > ε_f；(A3) 闭环任务误差关于故障估计误差是 L-Lipschitz。则
```
‖e_task‖ ≤ L·ε_f/(γ−ε_f) + ε_model
J(π_ρ) ≥ J(π_0) − [1 − cap_req/cap_avail]·J_scale − L·ε_f/γ
```
且任务成功率 ≥ 1−δ_cert（δ_cert 为证书置信度）。证明：由灵敏度分析，误差对参数扰动的增益被能力裕度 γ 归一化；ε_f 是扰动上界；性能损失由能力比与跟踪误差两部分组成；成功率由引理 105 的鲁棒证书立即得到。界是保守的，且当 γ→ε_f 时退化，提示必须在能力裕度耗尽前降级或中止。∎

## 8. 已知风险与失效模式

1. **接触—故障混淆**：滑移/碰撞产生的残差与编码器跳变、腱断裂在短时窗内高度相似。缓解：方向性残差 + 接触模式条件化 + 跨指一致性 + 主动探测；在 A 未缩小时使用鲁棒证书而非点估计。
2. **渐进故障被冗余掩盖**：RADR 用剩余手指/协同方向补偿，mask 指标升高但证书仍按"健康"签发，直到能力饱和。缓解：把 mask 与能力裕度作为一等监测量；裕度低于阈值时强制隔离/降级；故障账本记录补偿权威使用量。
3. **模糊类爆炸导致无可行段**：多传感器/多故障同时出现时 |A| 过大，鲁棒证书过度保守，可行段为空。缓解：分层证书（hard/soft）、细化隔离动作、受控释放、任务级松弛；若仍无解则安全中止。
4. **传感器故障污染接触/谐波证书**：编码器偏置会同时破坏 HCC 的 θ_flex 估计与接触证书。缓解：集合值观测器、跨传感器一致性、独立触觉/电流通道、故障时切换到仅用健康传感器的降级证书。
5. **重构瞬态本身不安全**：换抓取/重分配手指的过渡可能激发共振、瞬时失去力闭合或滑移。缓解：过渡轨迹纳入 v11 四重证书；限制重构速度；在 P^f 密度高的状态才允许重构。
6. **能力测度保守/不充分**：Cap ⪰ Cap_req 是充分条件，可能拒绝本可行的非线性重构；也可能因线性化低估接触耦合而误判可行。缓解：Cap 作为剪枝而非唯一判据，保留仿真 rollout 复核；对线性化误差加裕度。
7. **主动探测的代价与安全**：探测需要激励，可能干扰任务或暴露于危险接触。缓解：嵌套盾、幅值/频率限制、信息增益/成本门槛、优先被动观测。
8. **同源误差跨模块传播**：FDIC 的故障信念→FASC 包络→HATD 分解→NCP 规范盾→CAE 归因，可能形成正反馈。缓解：独立证据通道、显式不确定性传播、故障账本审计、必要时 a_ask 打破环。
9. **欠驱动/腱耦合导致可诊断性退化**：腱驱动手指的关节运动强耦合，故障签名接近共线，隔离分辨率下降。缓解：利用腱张力直接观测、设计激励使签名正交、接受更大的模糊类并降级。
10. **规范/人类偏好与故障降级的冲突**：故障后"继续完成任务"可能与安全规范冲突。缓解：P21 只减不增；规范盾优先；故障中止点显式建模人类接管。

## 9. 本轮最大风险

**一句话**：接触相变产生的残差与执行器/传感器故障的残差在方向和幅度上高度混淆，FDIC 把真实故障判成"接触不确定性"并继续签发证书，同时 RADR 用冗余把故障补偿到不可见，直到冗余饱和的瞬间能力缺口突现，即**被冗余掩盖的故障在最需要余量的时刻才暴露**。
