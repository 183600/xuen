# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因」IP-214~223；本轮灵感：「世界模型」×「联邦学习」）

> 第 65 轮 VISTA 把「几何可证伪」升级为「故障可归因」，其自述最大风险非常诚实：归因依赖「故障属于有限假设集 + 视觉与几何失效相互独立」；透明/镜面/对抗 patch 会让两者共享同一个分布外失效源，未知复合故障会被强行归入最近假设，而系统因「已经归因」反而更自信地继续执行。本轮不新增传感器、也不无限扩大假设集，而是换一个**证据来源**：单机只能在自己有限的激励与故障库内归因，**机群**却天然覆盖不同的状态-动作区域、不同的物体与不同的故障史。本轮核心命题是：
>
> **把「单机可归因」升级为「机群可归因、且每个客户端都安全」：用世界模型作为可共享、可做梦、可压缩的安全表征，用联邦学习在不泄露原始数据的前提下聚合跨客户端的激励与故障证据；但安全证书绝不做平均——它必须是逐客户端的交集（worst-client），并用共因锚点、拜占庭鲁棒、陈旧度预算与隐私-安全核算把「共识」与「真相」分开。**

## 0. 直觉与动机

**灵感 1（世界模型 → 安全证据的压缩、想象与方向性）**
直觉：第 65 轮的世界模型只用于块级视觉前瞻。这里再往前一步：世界模型的本质是「把动力学压进潜空间」，所以它同时是三种东西：(i) **可传输的**——潜空间统计量比原始图像/力序列小几个数量级，适合跨机器人共享；(ii) **可做梦的**——可以在不动物体的前提下，本地 rollout 出大量反事实轨迹，估计"如果这样推会怎样"；(iii) **可归因的**——预测残差在潜空间的方向，比单一 ‖e‖ 更能区分故障类型。但世界模型也会**幻觉**：模型越错，梦越"真"、越危险。所以梦必须接地（dream grounding），否则只是把第 65 轮的「视觉不可观测」换成「想象不可证伪」。

**灵感 2（联邦学习 → 异质性不是噪声，而是激励）**
直觉：第 65 轮的三阶段可辨识性要求零力窗/轻触/加载都被激励；单机在某些任务上根本走不到某个阶段，签名矩阵就会缺秩。机群的异质性恰好补上：A 站点常做重载、B 站点常做易损轻触、C 站点有大量透明物体。**联邦学习不只是省通信/保隐私，它把「谁见过这种故障」变成隐私保护下的共享证据。** 这是把第 65 轮"时间分离创造可辨识性"扩展到"客户端分离创造可辨识性"。

**灵感 3（联邦学习 → 平均模型不是安全模型）**
直觉：FedAvg 优化的是平均风险，而安全是**逐客户端的最坏情况约束**。平均安全不等于每个都安全；更糟的是，非凸聚合可能得到一个"对谁都不最优、对谁都可能不安全"的平均模型——"没有一个客户端是那个平均"。两个客户端的风险可以是 {0, 2α}，平均 α 看起来达标，最坏 2α 已经越界；N 个客户端可以做到一个客户端 Nα、其余 0，平均仍为 α。所以安全证书**不能是标量平均**，而必须是"每个客户端都成立"的交集，或者至少是最坏客户端约束。这是本轮与普通联邦学习最本质的分歧。

**灵感 4（联邦学习 → 新的故障源，且隐私让审计变难）**
直觉：联邦引入三类单机没有的故障：(i) **非 IID 漂移 H_shift**——客户端分布不同，全局模型对某些客户端系统性偏差；(ii) **拜占庭 H_byz**——恶意/损坏客户端可后门化世界模型；(iii) **陈旧 H_stale**——部分参与让模型版本落后。更麻烦的是：隐私保护（安全聚合 + DP）让服务器**看不到个体数据**，于是"是谁坏了"本身变得不可审计。归因必须从"看原始证据"升级为"看可验证的聚合统计 + 挑战-响应 + 零知识/DP 证据"。

**灵感 5（合流 → FLEET：Federated Latent-Envelope Embodied Trust，联邦潜空间包络具身信任）**
闭环：每个客户端本地训练世界模型并生成**接地梦**（DRP）→ 只上传"保证统计量"（conformal 分数草图、支撑覆盖、漂移界、故障签名）→ 服务器鲁棒聚合（RBA）与隐私核算（PSA）→ 联邦 conformal（FCA）给逐客户端 + 同时覆盖 → 机群激励引擎（FEE）在隐私/安全预算下选择各客户端任务以最大化可辨识性 → 联邦风险归因（FRA）在扩展假设集 {H_shift, H_byz, H_stale, H_common} 上归因 → 机群安全包络（FSE）取 worst-client 交集而非平均 → 跨站点证书护照（CFT）→ J_fleet。第 65 轮是「单机的故障可归因」，FLEET 是「**机群的可归因，但每个成员都安全，且共识必须被锚定**」。

**灵感 6（FLEET 相对 VISTA 的原位升级）**
- **FIR → FRA**：假设集加 H_shift/H_byz/H_stale/H_common；签名加跨客户端挑战不一致、梦发散、陈旧度。
- **AFA → FEE**：探针从单机主动判别升级为"机群任务分配"，目标从单机互信息升级为机群 Fisher 可辨识性 λ_min(I_fleet)。
- **CSC → 逐客户端 CSC**：认证前缀必须在每个客户端的支持集上成立，k*_fleet = min_c k*_c。
- **RSC-V → FSE**：不再只膨胀一个球，而是维护"每个客户端的包络"，取交集/最坏。
- **世界模型 → FWM + DRP**：潜空间共享、接地梦。
- **AIC-V → AIC-F**：干扰集加非 IID、拜占庭、陈旧、共因 + 通信延迟/丢包。
- **J_vista → J_fleet**：证书加 client_set、simultaneous_coverage、staleness、byz_bound、ε_dp、excitation_rank、common_mode_flag。

## 1. 形式化定义（增量：定义 233–246）

- **定义 233（FLEET 闭环）**：FLEET = (逐客户端 VISTA, FWM, DRP, FCA, FSE, FRA, FEE, RBA, PSA, CFT, J_fleet)。不变式：**原始传感器流与原始数据永不离开客户端；跨边界只允许"保证统计量"与 DP/安全聚合后的摘要；实时流仍只做残差采集、前缀执行、早停，零学习写。**
- **定义 234（联邦世界模型与保证统计量）**：客户端 c 有本地世界模型 f_c=(enc_c,p_c,dec_c) 与本地数据 D_c；个性化 f_c=Π(f_0,D_c)。保证统计量 a_c=(conformal 分数草图、状态-动作支撑覆盖 sketch、漂移上界、故障签名直方图、梦想发散摘要)，满足通信预算 ‖a_c‖≤B。服务器只聚合 {a_c}，不接触原始数据；模型更新若上传则经安全聚合+DP。
- **定义 235（接地梦 DRP）**：给定 f_c 与候选块 A，本地采样 K 条潜空间 rollout，得预测安全裕度与观测量分布 d_c(A)。梦只有在"在留出真实短执行上的预测误差 ≤ q_c(α)"时才**接地**；只有接地梦的摘要可进入机群包络。未接地梦标记 `ungrounded`，只能作探索先验，不得作为安全证据。
- **定义 236（联邦 conformal 与同时覆盖 FCA）**：客户端 c 的局部非一致性分数 s_{c,i} 给 split-conformal p 值 p_{c,i}。构造 conformal e-process M_c(t)=∏_{i≤t}(1−α_c+1[p_{c,i}≤α_c])；在局部可交换/模型有效下 E[M_c(t)]≤1（非负上鞅）。对机群同时覆盖取 α_c=α/N，由 Ville + 联合界：P(∃t,∃c: M_c(t)≥N/α)≤Σ_c α/N=α。故机群任意时刻、跨客户端的分布无关同时覆盖 ≥1−α，且不要求客户端之间独立同分布。
- **定义 237（机群安全包络 FSE 与 worst-client）**：客户端 c 的局部安全集 K_c={π: J_c 有效}；机群在共享任务潜空间上定义 K_fleet={π: ∀c, π|_c∈K_c}，机群风险 R_fleet=max_c R_c，要求 R_fleet≤α。对比 FedAvg 目标 mean_c R_c：命题（无客户端是平均）给出 mean≤α 不蕴含 max≤α，且差距可随 N 线性放大。故 FSE 的证书是**交集语义**，不是平均语义。
- **定义 238（联邦风险归因 FRA）**：扩展假设 ℋ_F=ℋ_VISTA∪{H_shift,H_byz,H_stale,H_common}。机群签名 ρ_F=(逐客户端阶段签名聚合、跨客户端挑战探测不一致、梦发散、模型陈旧度、鲁棒聚合距离)。后验 P(H|ρ_F) 在安全聚合统计上计算；个体级归因只在客户端本地或 DP 披露下进行。H_common（全队共享同一错误先验）**只**在锚点集上可辨识（定义 244）。
- **定义 239（联邦可辨识性与机群 Fisher）**：单客户端 Fisher I_c=S_cᵀΣ_c⁻¹S_c；机群信息 I_fleet=Σ_c n_c I_c（注意区别于证书 J_fleet）。可辨识 ⇔ I_fleet≻0，κ_fleet=λ_min(I_fleet)/λ_max(I_fleet)。因为 PSD 求和，λ_min(I_fleet)≥max_c n_c λ_min(I_c)：**一个激励充分的客户端就能让系统性故障可辨识**；但逐客户端安全仍需每个客户端自己的覆盖——**可辨识性可池化，安全性不可池化**。
- **定义 240（机群激励引擎 FEE）**：在隐私预算、物理力限 f≤f_safe、通信预算下选各客户端任务/探针 a_c，最大化可辨识性：max λ_min(Σ_c n_c I_c(a_c))，用 log-det（D-最优）作子模代理，并显式约束**异质性下界**（禁止把所有客户端同质化，否则人为制造共因）。
- **定义 241（拜占庭鲁棒聚合 RBA）**：RobAgg 的崩溃点 β*（坐标中位数/截尾均值/Krum）。加**区域化挑战-响应**：服务器用 DP 合成状态 Q 询问各客户端预测，按区域 R 做鲁棒聚合；若该区域恶意比例 β_R<1/2，则区域鲁棒估计与诚实集合有界偏差。后门检测：客户端在区域 R 的挑战预测偏离、但其上报 conformal 分数在 R 异常低（隐藏）即标记。全局中位数会被大区域稀释，故必须区域化。
- **定义 242（隐私-安全核算 PSA）**：记录 (ε_dp,δ_dp)、安全聚合协议、以及 DP 噪声对 conformal 阈值的覆盖退化 Δα(ε_dp)（由噪声计数/草图的集中界给出）。证书必须同时声明隐私预算与**因隐私而膨胀的安全阈值**；隐私越强覆盖越保守，二者是显式前沿而非免费。
- **定义 243（跨站点证书护照 CFT）**：把证书迁移到新站点/新本体时，附带域漂移界 δ_W（潜嵌入的 Wasserstein 距离）与漂移 Lipschitz 常数 L；可迁移条件为 δ_W·L ≤ 阈值，否则证书降级为 `transport_unverified`，必须本地重接地。**证书不能裸迁移。**
- **定义 244（共因与锚点覆盖）**：定义锚点集 A={状态: 至少一个客户端有独立的物理接地检查（接触/力/真实干预，承接第 64 轮）}。机群共识在 A 上可被证伪；在 A 外，即使全队一致也只能标 `consensus_ungrounded`。共因得分 c_common 只在 A 上统计；A 覆盖率不足时 H_common 与 H0 不可分，必须置 ambiguous。
- **定义 245（FLEET 证书 J_fleet）**：J_fleet=(逐客户端 J_vista 摘要, client_set, participation, simultaneous_coverage, staleness 向量, byz_bound 与检测集, ε_dp, excitation_rank/λ_min, dream_grounding_hash, common_mode_flag, fleet_ver)。Valid ⇔ ∀c: Valid(J_vista,c) ∧ s_c≤T_c(α) ∧ 同时覆盖 ∧ β*≥β ∧ 隐私预算未超 ∧ 梦已接地 ∧ (归因确定 ∨ 显式 ambiguous) ∧ (A 覆盖充分 ∨ common_mode_flag=True)。
- **定义 246（FLEET 闭环算子）**：语义流（服务器+客户端低频）：[本地世界模型→DRP 接地梦→保证统计量→安全聚合/RBA→FCA→FRA 归因→FEE 任务分配→FSE 交集→CFT 护照→J_fleet]；实时流（客户端）：[锚点读→本地残差/阶段采集→逐客户端 CSC 早停→WCV-V 编译→π_σ 前缀派发→J_vista,c]。两流之间只通过"保证统计量"与"证书"通信。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（联邦同时覆盖）**：每个客户端维护非负上鞅 conformal e-process M_c(t)，取每客户端阈值 N/α；由 Ville + 联合界，P(∃t,∃c: M_c(t)≥N/α)≤α。故机群同时覆盖 ≥1−α，且不要求跨客户端独立或同分布。
- **引理 10（机群可辨识性）**：系统性（共享）故障下 I_fleet=Σ_c n_c I_c；I_fleet≻0 则 θ 可辨识，且 λ_min(I_fleet)≥max_c n_c λ_min(I_c)。因此**一个客户端的激励可被全队共享用于归因**；但客户端特有的故障仍需本地激励，不可池化。
- **命题 1（没有客户端是平均）**：N 个客户端中一个风险 Nα、其余 0，则 mean=α 而 max=Nα。故"平均达标"不能推出"每个都安全"，FSE 必须用交集/worst-client 语义。
- **定理 9（FLEET 逐客户端安全）**：在 A94–A99 下，Valid(J_fleet) ⇒ 对所有参与与未参与客户端，同时覆盖下逐客户端安全；拜占庭比例 <β* 时鲁棒；陈旧 s_c≤T_c；隐私预算内；共因要么被锚点证伪、要么显式标记 `consensus_ungrounded`。
- **定理 10（长梦短信）**：设陈旧度 s 下世界模型漂移 ‖f^{(t)}−f^{(t−s)}‖≤L·s，conformal 阈值随陈旧度 q_c(α,s)≤q_c(α,0)+L·s。信任视界 T_c(α)=(q_max−q_c(α,0))/L。于是**梦可以做得长（H 大、样本多），但对共享世界模型的信任必须短（s≤T_c）**——这是第 65 轮"长预测、短执行"在联邦层面的对偶。
- **实时性**：所有联邦聚合、归因、激励分配、证书都在语义流/服务器低频线程；客户端实时路径仍只做本地残差、CSC 早停与派发，目标 ≤2.5ms（A93 契约不变）。

## 5. 本轮最大风险

**一句话**：FLEET 的最大风险是「共识不等于真相」——当所有客户端共享同一个错误的世界模型先验（同源预训练、同款传感器、同一非 IID 偏移）时，跨客户端一致性会很高、归因后验会很自信，而联邦聚合与隐私保护恰好抹掉了发现该共因所需的个体差异与可审计性；系统会把「全队都错」误判为「全队都对」，并因联邦证书而放大到整个机群，这是本轮同时覆盖、可辨识性与 worst-client 论证共同依赖的隐藏假设（A97 锚点覆盖）。

## 2. 形式化定义（完整版）

**定义 233（FLEET 闭环）** FLEET 是在逐客户端 VISTA 之上挂载联邦层的机群安全闭环：FLEET=(VISTA_c, FWM, DRP, FCA, FSE, FRA, FIE, RBA, PSA, CFT, J_fleet)。位置：VISTA 回答"这个机器人哪一层坏了"，FLEET 回答"**整个机群是否每个成员都安全、以及我们凭什么相信这个共识**"。不变式：**原始传感器流、原始数据、原始梯度永不离开客户端；跨客户端边界只允许"保证统计量"与 DP/安全聚合摘要；实时流仍零学习写操作。**

**定义 234（联邦世界模型 FWM 与保证统计量）** 客户端 c 持有本地世界模型 f_c=(enc_c,p_c,dec_c)（潜编码 → 潜动力学 → 解码/任务头）与本地数据 D_c。服务器维护共享先验 f_0，个性化 f_c=Π(f_0,D_c)（Π 可为部分微调、adapter 或正则化局部更新）。客户端向服务器上传的**不是原始数据、也不是可逆的原始梯度**，而是保证统计量
a_c = ( conformal 分数草图 Φ_c, 状态-动作支撑覆盖 sketch Ψ_c, 漂移上界 \hat L_c, 故障签名直方图 h_c, 梦想发散摘要 e_c ),
且 ‖a_c‖≤B。服务器只聚合 {a_c}；若需上传模型更新，走安全聚合（secure aggregation）+ DP-SGD，并把 (ε_dp,δ_dp) 写入证书。**"保证统计量"是安全层的一等公民，而非训练的副产品。**

**定义 235（接地梦 DRP）** 给定本地世界模型 f_c 与候选块 A=(a_1,…,a_H)，客户端在潜空间采样 K 条 rollout
τ_k = (z_0, a_1, z_1, …, a_H, z_H)^{(k)}，得到预测安全裕度分布 {m_k} 与预测任务观测量分布 d_c(A)。梦有两类用途：
- **探索梦**（ungrounded）：只作先验、用于生成候选与激励；
- **接地梦**（grounded）：在留出真实短执行集合上，预测误差 ≤ q_c(α) 才接地。只有接地梦的**摘要**可进入机群安全包络。

不接地的梦必须标 `ungrounded`；用未接地梦去支撑证书视为违反 J_fleet。这直接封堵"世界模型越错、梦越自信"的模型幻觉。

**定义 236（联邦 conformal 与同时覆盖 FCA）** 客户端 c 在本地标定集上计算非一致性分数 s_{c,i}（预测量与真实短执行之差），得到局部 conformal p 值 p_{c,i}（在局部可交换/模型有效下 P(p_{c,i}≤u)≤u）。构造 e-process
M_c(t) = ∏_{i=1}^{t} ( 1 − α_c + 1[p_{c,i} ≤ α_c] ).
若局部模型有效，则 E[1−α_c+1[p≤α_c]] = 1−α_c+P(p≤α_c) ≤ 1，故 M_c 为非负上鞅、E[M_c(t)]≤1。由 Ville 不等式，P(∃t: M_c(t) ≥ 1/α_c) ≤ α_c。取 α_c=α/N，并对 c 联合界：
P(∃t,∃c: M_c(t) ≥ N/α) ≤ Σ_{c=1}^N α/N = α.
于是机群**任意时刻、跨客户端**同时覆盖 ≥1−α，且**不要求客户端之间独立或同分布**。Bonferroni 的固定阈值 α_c=α/N 是保守特例；e-process 版本对"持续漂移"更敏感，且支持随时停止（anytime-valid）。

**定义 237（机群安全包络 FSE 与 worst-client）** 客户端 c 的局部安全集 K_c={π: Valid(J_vista,c)}。机群在共享任务潜空间（由 CFT 对齐，定义 243）上定义
K_fleet = { π : ∀c∈C, π|_c ∈ K_c }，
机群风险 R_fleet=max_{c∈C} R_c，要求 R_fleet≤α。这与 FedAvg 的目标 mean_c R_c 有本质差异，见命题 1。工程上 K_fleet 不能显式求交（不同本体），故以"逐客户端证书 + 最坏客户端聚合"实现：J_fleet 只有在每个客户端都 Valid 时才 Valid，`k*_fleet = min_c k*_c`。

**定义 238（联邦风险归因 FRA）** 扩展假设集
ℋ_F = {H0, H_geo, H_force, H_model, H_vis, H_policy, H_shift, H_byz, H_stale, H_common}.
机群签名
ρ_F = ( {ρ^{(c)}_{approach,touch,load}}_c, Δ_challenge, e_dream, s_c, d_robust )
其中 Δ_challenge 是各客户端在服务器挑战状态 Q 上预测的两两/中位数不一致，e_dream 是梦与真实短执行的发散，s_c 是陈旧度，d_robust 是更新到鲁棒中心的距离。后验 P(H|ρ_F)∝p(ρ_F|H)P(H)，在安全聚合统计上计算。归因粒度分两层：**机群级**（谁的系统性故障，如 H_shift/H_byz/H_stale/H_common）在服务器；**客户端级**（本地 H_geo/H_force/…）在客户端本地。隐私约束下，服务器只做机群级归因，个体级归因需 DP 披露或本地执行。

**定义 239（联邦可辨识性与机群 Fisher FIE 的信息部分）** 系统性（共享）故障幅度 θ 下，客户端 c 的线性化签名模型 ρ^{(c)}=S_c θ+ε_c，ε_c∼N(0,Σ_c)，局部 Fisher I_c=S_cᵀΣ_c⁻¹S_c。独立噪声下机群信息可加：
I_fleet = Σ_{c∈C} n_c I_c ,
可辨识 ⇔ I_fleet≻0，κ_fleet=λ_min(I_fleet)/λ_max(I_fleet)。由于 PSD 求和的 λ_min 单调不减，
λ_min(I_fleet) ≥ max_c n_c λ_min(I_c),
故**一个激励充分（三阶段齐全、覆盖广）的客户端即可让系统性故障在全队可辨识**。但注意两点：(i) 客户端**特有**故障的 θ_c 不能跨客户端池化，必须本地激励；(ii) 可辨识性可池化，但**安全性不可池化**（定义 237），这是本轮最关键的非对称性。

**定义 240（机群激励引擎 FEE）** 在隐私预算 (ε_dp,δ_dp)、每客户端物理力限 f≤f_safe、通信预算 B、任务预算下，选择各客户端任务/探针分配 a=(a_1,…,a_N) 以最大化机群可辨识性：
a* = argmax_a λ_min( Σ_c n_c I_c(a_c) )，
s.t. ε_dp 预算、f_{n,c}≤f_safe、‖a_c‖≤B、覆盖约束。
λ_min 非子模，故用 log-det（D-最优，子模）作代理：max log det(Σ_c I_c(a_c)+λI)，贪心 (1−1/e) 近似，再用 λ_min≥ε 作事后证书。显式加入**异质性下界**：若所有客户端被分配同一任务，签名矩阵趋同、H_common 风险上升，故约束各客户端任务分布的散度 ≥ h_min。**不要把机群同质化成一台机器人。**

**定义 241（拜占庭鲁棒聚合 RBA）** 客户端更新/统计按区域 R∈ℛ 分区（R 由潜空间的覆盖簇或任务类型定义）。区域 R 的聚合用崩溃点 β*_R 的鲁棒算子 RobAgg_R（坐标中位数、截尾均值、或 Krum）。若区域恶意比例 β_R<1/2，则 RobAgg_R 的估计与诚实集合有界偏差
‖RobAgg_R − mean_{honest}‖ ≤ C_R·β_R·diam_R.
**区域化是必须的**：全局中位数会被大区域稀释，后门集中在被忽视的小区域。后门检测用**挑战-响应**：服务器生成 DP 合成状态 Q_R（不泄露任何客户端数据），要求各客户端返回 f_c(Q_R) 预测；对每个区域 R，计算预测到区域中位数的距离。若客户端在 R 的预测偏离、但其上报的 conformal 分数在 R 异常低（即"本地声称很准、实际与全队不符"），则标记为可疑。该检测不要求服务器看到真实标签，只要求区域内诚实多数。

**定义 242（隐私-安全核算 PSA）** 记录隐私三元组 (ε_dp,δ_dp,安全聚合协议) 与安全后果：DP 噪声加到 conformal 草图/计数上，使有效阈值从 q_c(α) 膨胀为 q_c(α)+Δα(ε_dp)，其中 Δα 由噪声计数/草图的集中不等式给出（例如 m 个计数、敏感度 Δ 的高斯机制，Δα ≈ √(2Δ²log(1/δ))/(mε) 量级）。证书同时声明隐私预算与**因隐私而膨胀的安全阈值**：
q^{priv}_c(α) = q_c(α) + Δα(ε_dp).
隐私不是免费的：ε_dp 越小 → Δα 越大 → 包络越保守 → 执行越受限。PSA 把这条前沿显式化，避免"用了隐私保护，所以更安全"的错觉。另加**可审计性代价**：服务器看不到个体数据，个体归因能力下降，必须由客户端本地归因或 ZK/DP 披露补偿。

**定义 243（跨站点证书护照 CFT）** 把策略/世界模型/证书迁移到新站点或新本体时，定义潜嵌入空间的域漂移
δ_W = W_2( P^{src}_{z}, P^{tgt}_{z} )（Wasserstein-2），并假定世界模型的预测误差关于潜分布漂移满足 Lipschitz：‖f^{src}−f^{tgt}‖ ≤ L·δ_W。可迁移条件 δ_W·L ≤ τ_transfer，此时证书以 α' = α + c·δ_W·L 降级有效；否则证书标 `transport_unverified`，必须在目标站点做本地重接地（本地 conformal + 物理锚点）后才能重新签发。**证书不能裸迁移；迁移的是"带条件的证书"，不是"信任本身"。**

**定义 244（共因与锚点覆盖）** 定义物理锚点集
A = { 状态 s : 至少一个客户端在 s 附近有独立的物理接地检查（接触/力/真实干预，承接第 64 轮 GRIP） }。
机群共识只有在 A 上才能被外部真值证伪。定义共因得分 c_common = 在 A 上，各客户端预测的**一致度**与**实际物理结果**的背离；若 A 覆盖率不足（A 未覆盖某安全关键区域），则即使全队一致，也只能标 `consensus_ungrounded`，并把 H_common 与 H0 视为不可分（归因必须 ambiguous）。**这是本轮唯一诚实的边界：没有独立锚点，任何"全队都同意"都不构成安全证据。**

**定义 245（FLEET 证书 J_fleet）**
J_fleet = ( {J_vista,c}_c, client_set, participation, simultaneous_coverage, staleness={s_c}, byz_bound, detected_byz, eps_dp, excitation_rank, dream_grounding_hash, common_mode_flag, fleet_ver ).
验证规则：
Valid(J_fleet) ⇔
  (∀c∈C: Valid(J_vista,c))                                   # 逐客户端，非平均
  ∧ simultaneous_coverage ≥ 1−α                               # FCA 同时覆盖
  ∧ (∀c: s_c ≤ T_c(α))                                        # 陈旧度在信任视界内
  ∧ (β* ≥ β ∧ detected_byz 已隔离)                            # 拜占庭鲁棒
  ∧ (eps_dp 未超预算 ∧ q^{priv} 已计入)                        # 隐私-安全核算
  ∧ (所有入证的梦均 grounded ∧ dream_grounding_hash 一致)      # 梦接地
  ∧ (归因确定 ∨ 显式 ambiguous)                                # FRA
  ∧ (A 覆盖充分 ∨ common_mode_flag=True)                       # 共因锚定
  ∧ fleet_ver 为当前版本。
审计链新增：**哪一群客户端**（client_set/coverage）、**哪个成员最坏**（worst-client）、**共识是否被锚定**（common_mode_flag）、**隐私付出多少安全**（eps_dp/Δα）、**世界模型的信任还剩多久**（staleness/trust horizon）。

**定义 246（FLEET 闭环算子）** 语义流（服务器 + 客户端低频，10–100Hz 或更低）：
[本地世界模型 f_c → DRP 接地梦 → 保证统计量 a_c → DP/安全聚合 → RBA 区域鲁棒 → FCA 同时覆盖 → FRA 机群/个体归因 → FIE 任务分配 → FSE worst-client 交集 → CFT 护照 → J_fleet]。
实时流（客户端，零学习写）：
[锚点读 → 本地残差/阶段采集 → 逐客户端 CSC 早停 → WCV-V 编译 → π_σ 前缀派发 → J_vista,c]。
两流之间只通过"保证统计量"与"证书"通信；服务器不得直接读客户端实时流。

### IP-224/225 FWM + DRP（客户端）

```python
class LocalWorldModel:
    def personalize(self, f0, D_c):
        return adapt(f0, D_c)                      # adapter/partial finetune

    def dream(self, f_c, candidate_blocks, K, q_c):
        dreams = []
        for A in candidate_blocks:
            roll = [f_c.rollout(A, z0=sample_latent(f_c)) for _ in range(K)]
            m = [r.min_safety_margin for r in roll]
            d = predict_obs_dist(roll)
            grounded = self._grounded(f_c, A, roll, q_c)   # 留出真实短执行核对
            dreams.append({'A': A, 'margin_q': quantile(m, [0.05, 0.5]),
                           'obs': d, 'grounded': grounded})
        return dreams

    def _grounded(self, f_c, A, roll, q_c):
        err = heldout_short_exec_error(f_c, A)     # 本地真实执行，短前缀
        return err <= q_c
```

### IP-226/231 FCA + PSA（客户端编辑 + 服务器聚合）

```python
def local_evalue(p_c, alpha_c):
    # 单步 e-value；有效模型下 E[e] <= 1
    return 1.0 - alpha_c + (1.0 if p_c <= alpha_c else 0.0)

def fca_round(per_client_ps, N, alpha):
    alpha_c = alpha / N
    probs = {}
    for c, ps in per_client_ps.items():
        M = 1.0
        for p in ps:
            M *= local_evalue(p, alpha_c)
        probs[c] = {'M_t': M, 'alarm': M >= 1.0 / alpha_c}
    fleet_alarm = any(v['alarm'] for v in probs.values())
    return {'per_client': probs, 'fleet_alarm': fleet_alarm,
            'simultaneous_coverage': 1 - alpha}

def dp_conformal_threshold(q_c, eps_dp, m, sens):
    d_alpha = (sens / max(m, 1)) * (1.0 / max(eps_dp, 1e-6))
    return q_c + d_alpha                         # 隐私越强，阈值越保守
```

def allocate_excitation(clients, tasks, budget, privacy):

def attribute_fleet(rho_F, prior):

## 4. 推导

**引理 9（联邦同时覆盖）** 设客户端 c 的 conformal p 值 p_{c,i} 在局部模型有效时满足 P(p_{c,i}≤u)≤u。令 e_{c,i}=1−α_c+1[p_{c,i}≤α_c]，则
E[e_{c,i}] = (1−α_c)P(p>α_c) + (2−α_c)P(p≤α_c)
          = 1−α_c + P(p≤α_c) ≤ 1.
故 M_c(t)=∏_{i≤t} e_{c,i} 为非负上鞅，E[M_c(t)]≤1。由 Ville 不等式，
P(∃t: M_c(t) ≥ 1/α_c) ≤ α_c.
取 α_c=α/N 并对 N 个客户端做联合界：
P(∃t,∃c: M_c(t) ≥ N/α) ≤ Σ_c α/N = α.
因此机群同时覆盖 ≥1−α。注意：全程只用了每个客户端自身的局部有效性，**不需要客户端之间独立或同分布**；联合界承担了跨客户端的任意依赖。代价是阈值随 N 变严（N/α），这是"同时"而非"平均"的必然成本。∎

**引理 10（机群可辨识性）** 对系统性故障 θ，客户端 c 的线性化观测 ρ^{(c)}=S_c θ+ε_c，ε_c∼N(0,Σ_c)，独立。联合对数似然的海森为 Σ_c n_c S_cᵀΣ_c⁻¹S_c = I_fleet。故 θ 可辨识 ⇔ I_fleet≻0，Laplace 后验协方差 ≈ I_fleet⁻¹。由 PSD 求和，
λ_min(I_fleet) = λ_min(Σ_c n_c I_c) ≥ max_c λ_min(n_c I_c) = max_c n_c λ_min(I_c).
因此单个激励充分的客户端即可使全队系统性故障可辨识——"可辨识性可池化"。反之，若故障是客户端特有的 θ_c（不同客户端坏法不同），则联合模型中 θ_c 仅出现在第 c 块，必须 S_c 自身满秩，跨客户端求和**不能**补秩——"客户端特有故障不可池化"。这给出联邦归因的适用边界。∎

**命题 1（没有客户端是平均）** 设客户端风险 R_c，FedAvg/服务器约束 mean_c R_c ≤ α。取 R_1=Nα、R_{2..N}=0，则 mean=α 恰好达标，而 max=Nα。故平均安全不蕴含任一具体客户端安全，更不蕴含最坏客户端安全；差距随 N 线性增长，且若高风险客户端恰是数据最少/最边缘的客户端，则同时构成安全问题与公平问题。因此 FSE 必须采用 max/交集语义（定义 237），J_fleet 不得以平均覆盖签发。∎

**定理 9（FLEET 端到端逐客户端安全）** 在 A94–A99 下：
1. **逐客户端覆盖**：由引理 9，机群同时覆盖 ≥1−α，即 ∀c 的局部证书在同时意义下有效；`∀c Valid(J_vista,c)` 是 J_fleet 的必要条件。
2. **系统性故障可归因**：由引理 10，若 I_fleet≻0 且三阶段/跨客户端激励覆盖，则 H_shift/H_byz/H_stale 等系统性故障可被机群归因；归因不确定时显式 ambiguous 并触发保守包络。
3. **拜占庭鲁棒**：若每个区域 β_R<β*_R（RobAgg 崩溃点）且挑战-响应隔离可疑客户端，则诚实集合的聚合有界偏差，后门在受影响区域被标记。
4. **陈旧可控**：由定理 10，s_c≤T_c(α) 的客户端证书有效；超视界客户端自动失证并要求重接地。
5. **隐私显式**：q^{priv}_c 计入 Δα(ε_dp)，隐私预算与安全阈值同时写入证书，不存在"隐私免费"。
6. **共因诚实**：锚点覆盖充分时 H_common 可被证伪；不足时强制 `common_mode_flag=True` 且 `consensus_ungrounded`，不签发确定性归因。
7. **证书链**：Valid(J_fleet) ⇒ 逐客户端 GRIP/VISTA 有效 ∧ 同时覆盖 ∧ 拜占庭界 ∧ 陈旧界 ∧ 隐私界 ∧ 梦接地 ∧ 归因/ambiguous ∧ 共因锚定。∎

**定理 10（长梦短信：陈旧度与信任视界）** 设世界模型在训练/数据分布漂移下的预测误差关于陈旧度 s 满足 ‖f^{(t)}−f^{(t−s)}‖∞ ≤ L·s（L 为漂移 Lipschitz 常数，可由历史重放估计）。conformal 阈值随陈旧度满足
q_c(α,s) ≤ q_c(α,0) + L·s.
定义信任视界 T_c(α)=sup{ s≥0 : q_c(α,0)+L·s ≤ q_max } = (q_max−q_c(α,0))/L。当 s>T_c 时，证书不能保证覆盖，必须失证。于是：**梦的视界 H 可以很长（用于方差缩减与反事实前瞻），但对共享世界模型的信任必须很短（s≤T_c）**——"长梦、短信"，是第 65 轮"长预测、短执行"在联邦时间轴上的对偶。∎

**命题 2（隐私-安全前沿）** 若 conformal 草图经 (ε,δ)-DP 噪声扰动，则有效阈值膨胀 Δα(ε)≥0 且关于 ε 单调不增（ε 越小越保守）。因此存在一条显式前沿：给定安全预算 α，可达的最小隐私预算 ε_min(α) 由 Δα(ε)≤α−α_0 解出。把 ε<ε_min 说成"更安全"是错误的：更强的隐私掩盖了更多个体证据，安全包络只会更宽、可用性更低。PSA 的作用是把这条权衡写进证书，而不是隐藏它。∎

**命题 3（证书不可裸迁移）** 若源/目标潜分布 Wasserstein 距离 δ_W>0 且误差 Lipschitz 为 L，则目标站点上的实际覆盖至少下降 c·L·δ_W（一阶界）。当 δ_W·L>τ_transfer 时，原始证书在目标站点的覆盖保证失效。故 CFT 只能签发"带漂移惩罚的降级证书"，或要求目标站点本地重接地。∎

**正确性定理（FLEET-Complete）** 见定理 9。核心是三条非对称性：
1. **可辨识性可池化，安全性不可池化**：`I_fleet=Σ n_c I_c` 可共享，但 `R_fleet=max_c R_c` 必须逐客户端。

## 7. 已知风险

**一句话**：FLEET 的最大风险是「共识不等于真相」——当所有客户端共享同一个错误的世界模型先验（同源预训练、同款传感器、同一非 IID 偏移）时，跨客户端一致性会很高、归因后验会很自信，而联邦聚合与隐私保护恰好抹掉了发现该共因所需的个体差异与可审计性；系统会把「全队都错」误判为「全队都对」，并因联邦证书而放大到整个机群，这是本轮同时覆盖、可辨识性与 worst-client 论证共同依赖的隐藏假设（A97 锚点覆盖）。

**次级风险与缓解**：
1. **共因不可辨识**：无外部物理锚点时，H_common 与 H0 在观测上等价。缓解：显式锚点集 A、`consensus_ungrounded` 标记、注入独立通道（IMU/本体感觉/人工抽检）；锚点不足时拒绝签发确定性归因。
2. **非 IID 下的覆盖名不副实**：局部 conformal 依赖客户端内部可交换性；若客户端内部也漂移，p 值失效。缓解：在线重校准、漂移检测触发重接地、把 α 预算的一部分留给漂移。
3. **拜占庭区域化仍可被"广撒"攻击**：攻击者若同时污染大量区域，区域诚实多数假设失效。缓解：跨区域交叉验证、随机区域轮换、限制单客户端影响、崩溃点证书 β* 明确写入。
4. **隐私-安全-可审计三角**：强隐私使个体归因不可行，弱隐私泄露数据。缓解：客户端本地归因 + 仅上传聚合证据；ZK range proof 证明统计量物理可行；把 ε_dp 与 Δα 写进证书接受外部审计。
5. **世界模型梦的分布外幻觉**：接地只覆盖留出分布，OOD 区域仍可能自信地错。缓解：梦只在有覆盖的潜区域入证；OOD 检测（密度/重构）失败即 `ungrounded`；梦只作探索先验。
6. **通信/参与不公平**：低频/弱网客户端长期不参与，证书陈旧。缓解：陈旧度预算、分层聚合、给弱客户端更保守的本地证书与更短的 k*。
7. **FIE 组合爆炸与激励成本**：任务分配是组合优化且扰动生产。缓解：log-det 子模贪心 + 小规模在线 bandit；把探针限制在 null_test/visual_probe 等低风险元技能（承接第 65 轮 AFA）。
8. **平均化诱惑**：工程上最容易退化为"服务器报一个平均覆盖率"。缓解：J_fleet 的 schema 强制 per-client 字段与 worst-client 字段，缺一即拒签；审计展示最坏成员而非平均值。
