# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；本轮灵感：「低成本方案」×「可重构机构」）

> 第 54 轮把技能升级为“动作剖面 + 鲁棒性谱 + 云边联合证书”，但默认了 **一台（昂贵）执行体拥有一个固定的动作空间 A**。本轮反转这个默认：动作空间不再是常量，而是随 **机构构型 m** 变化的纤维 `A(m)`。核心矛盾：**H22（覆盖-成本悖论）**——单个构型越便宜，`A(m)` 越小、`ρ_m` 越低；用重构补覆盖就要支付切换代价，于是“覆盖率/美元”与“切换频率”直接对立。**H23（证书不可迁移）**——第 54 轮的联合证书 `J` 只在构型内有效，换构型后 `α_S, ρ, γ_ce` 全变，而切换边界正是误差最集中的位置。

## 0. 直觉与动机

**灵感 1（动作空间是构型的纤维，不是常量）**
直觉：不要用一台昂贵机器人“买断”整个动作空间，而用一族便宜的、可相互转换的构型“按需租用”动作子空间。形式上说，存在 **构型空间 M** 与投影 `π: A → M`，每个 `m` 诱导动作空间 `A(m) ⊆ A_univ` 与剖面 `α_{S,m}`。可重构机构的本质是：可以在 `M` 上移动，从而让**访问过的构型并集**覆盖任务动作集。这把“硬件覆盖”换成“时间上的构型覆盖”。

**灵感 2（低成本的弱点可被重构转成优点）**
直觉：便宜执行器公差大、间隙大、漂移快，单构型鲁棒谱 `ρ_m(d)` 偏低且随时间退化。但重构提供了新的失效响应：当某自由度 `d` 的 `ρ_m(d)` 跌破阈值时，不必硬扛，而是 **绕开退化自由度换到 m′**，使 `d` 不在关键路径上。于是“容错（fault tolerance）”升级为“容构（fault-tolerant reconfiguration）”——可靠性弱不再只是缺陷，而可被结构性冗余部分抵消。

**灵感 3（低成本覆盖 = 预算约束下的子模覆盖 + 切换代价）**
直觉：给定任务动作需求分布 `P_T` 与总硬件预算 `B`，选择一个小构型基 `S ⊆ M`，使期望动作覆盖最大，同时支付每次任务切换引起的重构代价。这是一个 **成本感知的子模背包覆盖**：覆盖函数对 `S` 单调子模，成本 = 硬件成本 `Σ c(m)` + 期望切换成本 `λ_sw·E[#switches]`。优化目标不是“最强”，而是 **单位美元覆盖最优且切换不失控**。

**灵感 4（证书必须按构型索引，并且可迁移）**
直觉：`J` 变成 `J_m`；真正决定系统 soundness 的不是单个 `J_m`，而是 **重构迁移证书 RTC(m,m′)**。切换安全要求：切换轨迹始终落在共享动作子空间 `A_∩(m,m′) = A(m) ∩ A(m′)` 内，且切换全程的鲁棒地板 `ρ_sw ≥ ρ_sw_min`。否则“省钱的构型”会在切换瞬间产生动作错位或碰撞。

**灵感 5（金字塔新增重构层）**
直觉：在第 54 轮动作-协同层之上再插一层 **重构层 𝕄**：`𝕄_0` 模块与拓扑可行集，`𝕄_1` 构型动作纤维 `A(m)`，`𝕄_2` 重构迁移，`𝕄_3` 预算-任务调度。跨层证书需同时携带 `ρ_m`、`A_cert(m)`、`RTC` 与预算凭证，形成 **低成本-可重构双账本**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（构型空间与构型动作纤维）**
机构构型 `m = (τ_m, J_m, P_m)`：`τ_m` 为连杆-关节拓扑，`J_m` 为关节模式向量（刚性/柔顺/锁定），`P_m` 为模块参数。构型空间 `M = {m}`。每个 `m` 诱导动作空间 `A(m) ⊆ A_univ` 与技能剖面 `α_{S,m}: A(m) → [0,1]`。硬件成本 `c(m)`、装配时间 `t_set(m)` 为已知函数。**构型覆盖** `cover(m, A_T) = 1 ⇔ ∀a∈A_T, α_{S,m}(a) ≥ θ_cov`。

**定义 122（可重构关系与安全切换）**
可重构关系 `R ⊆ M × M`，边 `(m,m′)` 附带切换代价 `c_sw(m,m′)`、停机时间 `d_sw(m,m′)` 与共享动作子空间 `A_∩(m,m′) = A(m) ∩ A(m′)`。切换 **可容许** 当且仅当存在切换轨迹 `τ_sw: [0,1] → A_∩` 满足 `τ_sw(0)∈A(m)`、`τ_sw(1)∈A(m′)`，且切换全程 `min_d ρ_sw(d) ≥ ρ_sw_min`。记切换鲁棒地板 `ρ_sw(m,m′) = min_{t,d} ρ(d; τ_sw(t))`。

**定义 123（低成本动作覆盖与预算）**
任务动作需求分布 `P_T`，每个任务需要动作集 `A_T`。构型基 `S ⊆ M` 的期望覆盖
```
C(S) = E_{A_T~P_T}[ max_{m∈S} cover(m, A_T) ] = Σ_T w_T · max_{m∈S} cover(m, A_T)
```
（对 `S` 单调子模）。总成本 `Cost(S, π_R) = Σ_{m∈S} c(m) + λ_sw·E_{π_R}[#switches] + λ_t·E[d_sw]`，预算 `Cost ≤ B`。**覆盖效率** `η(S)=C(S)/Cost(S)`。目标是求预算-覆盖前沿上的 `S*`，而非单一“最强构型”。

**定义 124（构型条件鲁棒性谱与迁移漂移）**
构型条件鲁棒谱 `ρ_{m}(d) ∈ [0,1]`，含低成本公差项 `ε_tol(m)` 与时间漂移项 `ε_drift(m,t)`。跨构型迁移界：
```
ρ_{m′}(d) ≥ ρ_m(d) − L_m·dist_M(m,m′) − ε_tol(m′) − ε_drift(m′,Δt)
```
其中 `dist_M` 为模块/拓扑编辑距离，`L_m` 为迁移 Lipschitz 常数。**构型鲁棒地板** `ρ_floor(S)=min_{m∈S, d} ρ_m(d)`。

**定义 125（重构迁移证书 RTC）**
`RTC(m,m′) = (A_∩, τ_sw 的轨迹类, ρ_sw, c_sw, d_sw, evidence)`。**sound** 当且仅当：(i) `τ_sw ⊆ A_∩` 可验证；(ii) `ρ_sw ≥ ρ_sw_min`；(iii) `c_sw ≤ B_sw`、`d_sw ≤ d_max`；(iv) `evidence` 至少含边端切换仿真的反例搜索记录与失败回滚日志。

**定义 126（预算-鲁棒联合证书 Frugal Certificate）**
`F = (S, π_R, {J_m}_{m∈S}, {RTC_e}_{e∈π_R}, B_used, C(S), ρ_floor, evidence)`：
- `S` 为选中构型基，`π_R` 为重构调度（含触发条件）；
- `J_m` 为第 54 轮构型内联合证书；
- `B_used = Cost(S,π_R)`；
- 部署可判定：`B_used ≤ B ∧ C(S) ≥ C_min ∧ ρ_floor(S) ≥ ρ_min ∧ ∀e∈π_R: RTC_e sound`。若任务 `T` 的 `A_T` 被 `S` 覆盖且 `dom_F(T)=in`，则可部署。

### IP-122 RCG（Reconfiguration Graph，重构图）

```python
def build_reconfig_graph(M, modules, sim, rho_sw_min):
    R = nx.DiGraph()
    for m in M:
        R.add_node(m, cost=mech_cost(m), A=A(m))
    for m in M:
        for m2 in M:
            if m == m2 or not modules_compatible(m, m2): continue
            Ash = A(m) & A(m2)
            if not switch_traj_exists(Ash): continue
            c_sw, d_sw = switch_cost(m, m2)
            rho_sw = switching_floor(m, m2, sim)
            if rho_sw < rho_sw_min: continue
            R.add_edge(m, m2, A_shared=Ash, c_sw=c_sw,
                       d_sw=d_sw, rho_sw=rho_sw)
    return R
```

### IP-123 LCC（Low-Cost Coverage，预算子模覆盖）

```python
def frugal_coverage_select(M, R, P_T, B, lam_sw, C_min):
    # 成本-收益贪心 + 单点枚举，保证 (1-1/e) 近似
    best_S = None
    for seed in enumerate_topk_singletons(M, P_T, k=min(len(M), 10)):
        S, budget = set(seed), sum(c(m) for m in seed)
        while budget < B:
            cand = None
            for m in set(M) - S:
                gain = marginal_coverage(S | {m}, P_T)      # 子模增益
                cost = c(m) + lam_sw * expected_switch_freq(m, S, R)
                score = gain / max(cost, eps)
                if cand is None or score > cand.score:
                    cand = (m, gain, cost, score)
            if cand is None or budget + cand.cost > B or cand.gain < eps:
                break
            S.add(cand.m); budget += cand.cost
        if best_S is None or coverage(S, P_T) > coverage(best_S, P_T):
            best_S = S
    return best_S if coverage(best_S, P_T) >= C_min else None
```

### IP-124 RRC（Reconfiguration Robustness Certificate，构型鲁棒证书）

```python
def config_robustness(m, dims, t, tol):
    return {d: base_rho(m,d) - tol(m,d) - drift(m,d,t) for d in dims}

def transfer_floor(m, m2, dims, L_m, delta_t):
    # 定义 124 的保守下界，用于拒绝“迁移后其实更脆”的构型
    return {d: rho[m][d] - L_m*dist_M(m,m2)
               - tol[m2][d] - drift(m2,d,delta_t) for d in dims}
```

### IP-125 RSC（Reconfiguration Switching Certificate，切换证书）

```python
def switching_certificate(m, m2, R, rho_sw_min, d_max, B_sw):
    e = R[m][m2]
    if not trajectory_contained(e.trajectory, e.A_shared): return ('reject','not_shared')
    if e.rho_sw < rho_sw_min: return ('reject','rho_switch_floor')
    if e.c_sw > B_sw or e.d_sw > d_max: return ('reject','switch_budget')
    return ('ok', RTC(m, m2, e.A_shared, e.trajectory, e.rho_sw,
                      e.c_sw, e.d_sw, evidence=e.sim_log))
```

### IP-126 BCP（Budget-Constrained Planner，预算-鲁棒联合规划）

```python
def budget_robust_plan(A_T, S, R, G_S, B, rho_min):
    # 三图联合搜索：(构型调度 π_R) × (技能组合路径 in G_S)
    frontier = []
    for m in S:
        if not cover(m, A_T): continue
        for path in k_shortest_paths(G_S, A_T, k=8):
            plan = schedule(m, path, R)
            if Cost(plan) <= B and min_rho(plan) >= rho_min \
               and all_rtc_sound(plan, R):
                frontier.append(plan)
    return pareto_min(frontier, keys=('Cost','-coverage','-min_rho'))
```

**劣化触发重构（容构）策略**

```python
def degradation_triggered_reconfig(state, M, R, rho_min):
    d_bad = [d for d, r in state.rho.items() if r < rho_min]
    if not d_bad: return state.m
    # 选择能绕开退化自由度、且切换证书 sound 的最近构型
    cands = [m for m in M if R.has_edge(state.m, m)
             and all(d not in critical_dofs(m) for d in d_bad)
             and R[state.m][m].rho_sw >= rho_min]
    return min(cands, key=lambda m: R[state.m][m].c_sw, default=state.m)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RAP | O(|M|·|A_univ|·|T|) | O(|M|·|A_univ|) | 参数化仿真校准；剖面采样覆盖 |
| RCG | O(|M|²·|A|) | O(|M|²) | 共享子空间可判定、切换地板 sound |
| LCC | O(k·B/c_min·|M|·|T|) | O(|M|·|T|) | 覆盖函数单调子模 |
| RRC | O(|M|·|𝔇_ρ|) | O(|M|·|𝔇_ρ|) | 迁移界 Lipschitz 保守 |
| RSC | O(|τ_sw|·|𝔇_ρ|) | O(|τ_sw|) | 轨迹 ⊆ A_∩、ρ_sw 可验证 |
| BCP | O(|M|·k·(|V|log|V|+|E|)) | O(|V|+|E|) | RTC 闭合、Pareto 前沿 |

**定理 1（低成本覆盖近似性）**
覆盖函数 `C(S)` 对 `S` 单调子模（加权 max-coverage）。预算约束下，IP-123 的“成本-收益贪心 + 单点枚举”给出
```
C(S_greedy) ≥ (1 − 1/e)·C(S*)
```
其中 `S*` 为预算最优构型基。含义：**不必买最贵的最强构型，也能逼近预算最优覆盖**。

**定理 2（切换安全性）**
若对调度 `π_R` 中每条边 `RTC(m,m′)` sound，且每次切换的轨迹 `τ_sw ⊆ A_∩(m,m′)`、`ρ_sw ≥ ρ_sw_min`，则切换过程中不存在构型诱导的动作错位事件，切换失败概率
```
P_switch_fail ≤ β_sw + Σ_d(1 − ρ_sw(d))
```
其中 `β_sw` 为仿真-真机切换差距。

**定理 3（低成本可重构端到端成功率）**
设任务 `T` 被 `S` 覆盖，且 `F` 可部署。则由定义 124 的迁移界与定理 2：
```
E[P_success] ≥ C(S)·(1 − Σ_d(1 − ρ_floor(d)) − β_sw − β_E) − P(B_used > B)
```
关键：**覆盖项来自“构型并集”，鲁棒项来自“构型地板”，切换风险是两者之间的独立扣减**。三者必须同时入账，任何一项被忽略都会系统性高估。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 便宜机构公差/间隙导致 `ρ_m` 与证书失真 | 高 | 公差感知标定 + 悲观下界 + 在线漂移估计 |
| 切换边界动作错位（H23） | 高 | RTC 强制 + 共享子空间轨迹验证 + 失败回滚 |
| 覆盖/美元优化选到“切换狂”构型（frugal trap） | 高 | 切换预算 `B_sw` + `λ_sw` 惩罚 + 停机时间上限 |
| 构型空间 |M| 组合爆炸 | 中 | 模块化生成 + 对称性裁剪 + 分层枚举 |
| 劣化触发重构震荡 | 中 | hysteresis + 最小驻留时间 + 冷却窗口 |
| 仿真到真机切换差距 β_sw | 高 | 域随机化 + 切换专用红队反例 + 安全护栏 |

## 6. 本轮最大风险

**一句话**：低成本可重构方案的最大风险是“廉价陷阱”——覆盖/美元优化会系统性偏好**单构型便宜但切换频繁**的构型基，而便宜机构的公差、间隙与漂移使第 54 轮证书在构型间不可迁移，误差恰好堆积在切换边界，最终省下了硬件钱却付出隐蔽的切换失效与负迁移代价；因此必须以 **切换预算 + 构型条件鲁棒地板 + 悲观迁移界** 三重护栏，宁可少覆盖，也不把“单位美元覆盖率高”误当作“可部署”。

# 第 55 轮产物 · 创新点清单 v32：FrugalReconf-GenSim（RAP×RCG×LCC×RRC×RSC×BCP）

> 承接第 54 轮产物 v31。本轮把“动作空间”从常量升级为 **构型条件纤维 `A(m)`**，在层级化鲁棒性 + 动作-协同证书之上，增加 **低成本可重构** 的四个能力：

| `M={m}` | 构型空间（含模块可组合性约束） |
| `A(m) ⊆ A_univ` | 构型条件动作纤维 |
| `α_{S,m}: A(m)→[0,1]` | 构型条件技能动作剖面 |
| `c(m), t_set(m)` | 硬件成本、装配时间 |
| `R ⊆ M×M` | 可重构关系图 |
| `A_∩(m,m′)=A(m)∩A(m′)` | 共享动作子空间 |
| `c_sw,d_sw,ρ_sw` | 切换代价、停机时间、切换鲁棒地板 |
| `C(S), Cost(S,π_R)` | 期望覆盖、含切换的总成本 |
| `η(S)=C(S)/Cost(S)` | 覆盖/美元效率 |
| `ρ_m(d), ε_tol, ε_drift` | 构型鲁棒谱、公差项、漂移项 |
| `RTC(m,m′)` | 重构迁移证书 |
| `F=(S,π_R,{J_m},{RTC_e},B_used,C,ρ_floor)` | 预算-鲁棒联合证书（Frugal Certificate） |

### IP-122 RCG

```python
def build_reconfig_graph(M, modules, sim, rho_sw_min):
    R = nx.DiGraph()
    for m in M:
        R.add_node(m, cost=mech_cost(m), setup=setup_time(m), A=A(m))
    for m in M:
        for m2 in M:
            if m == m2 or not modules_compatible(m, m2):
                continue
            Ash = A(m) & A(m2)
            traj = synthesize_switch_traj(m, m2, Ash)   # 轨迹合成
            if traj is None:
                continue
            rho_sw = min(robustness(traj(t), dims='all') for t in grid(0,1,N))
            if rho_sw < rho_sw_min:
                continue
            c_sw, d_sw = switch_cost(m, m2)
            R.add_edge(m, m2, A_shared=Ash, trajectory=traj,
                       c_sw=c_sw, d_sw=d_sw, rho_sw=rho_sw)
    return R
```

### IP-123 LCC

```python
def marginal_coverage(S, P_T, profiles):
    base = {T: max(config_cover(profiles,m,S,A_T) for m in S) if S else 0
            for T, A_T in P_T.items()}
    return base

def frugal_coverage_select(M, R, P_T, profiles, B, lam_sw, C_min):
    best_S, best_C = None, -1
    for seed in enumerate_topk_singletons(M, P_T, profiles, k=min(len(M),10)):
        S, budget = set(seed), sum(mech_cost(m) for m in seed)
        cur = marginal_coverage(S, P_T, profiles)
        while budget < B:
            cand = None
            for m in set(M) - S:
                new = marginal_coverage(S | {m}, P_T, profiles)
                gain = sum(w*(new[T]-cur[T]) for T,w in P_T.weights.items())
                cost = mech_cost(m) + lam_sw*expected_switch_freq(m, S, R)
                if gain <= 0: continue
                score = gain / max(cost, 1e-9)
                if cand is None or score > cand[3]:
                    cand = (m, gain, cost, score)
            if cand is None or budget + cand[2] > B:
                break
            m, gain, cost, _ = cand
            S.add(m); budget += cost; cur = marginal_coverage(S, P_T, profiles)
        C = sum(w*cur[T] for T,w in P_T.weights.items())
        if C > best_C:
            best_S, best_C = S, C
    return best_S if best_C >= C_min else None
```

### IP-124 RRC

```python
def config_robustness(m, dims, t, tol):
    return {d: base_rho(m,d) - tol(m,d) - drift(m,d,t) for d in dims}

def transfer_lower_bound(m, m2, dims, L_m, dt, tol, rho):
    # 定义 124：便宜构型迁移后可能更脆，必须用保守下界
    return {d: rho[m][d] - L_m*dist_M(m,m2)
               - tol[m2][d] - drift(m2,d,dt) for d in dims}

def robust_floor(S, dims, rho):
    return min(rho[m][d] for m in S for d in dims)
```

### IP-125 RSC

```python
def switching_certificate(m, m2, R, rho_sw_min, d_max, B_sw):
    e = R[m][m2]
    if not trajectory_contained(e.trajectory, e.A_shared):
        return ('reject', 'trajectory_not_in_shared_subspace')
    if e.rho_sw < rho_sw_min:
        return ('reject', 'switch_robustness_floor')
    if e.c_sw > B_sw or e.d_sw > d_max:
        return ('reject', 'switch_budget_exceeded')
    return ('ok', RTC(m, m2, e.A_shared, e.trajectory, e.rho_sw,
                      e.c_sw, e.d_sw, evidence=e.sim_counterexamples))
```

### IP-126 BCP

```python
def budget_robust_plan(A_T, S, R, G_S, B, rho_min, k=8):
    frontier = []
    for m in S:
        if not cover_any(m, A_T): continue
        for path in k_shortest_paths(G_S, A_T, k=k):
            plan = interleave_config_schedule(m, path, R)  # 构型调度 × 技能路径
            if any(not all(switching_certificate(u,v,R,...)=='ok'
                           for u,v in plan.switches)): 
                continue
            if Cost(plan) <= B and min_rho(plan) >= rho_min:
                frontier.append(plan)
    return pareto_min(frontier, ('Cost', '-coverage', '-min_rho'))
```

### IP-126+ 劣化触发重构（容构）

```python
def degradation_triggered_reconfig(state, M, R, rho_min, dwell_time):
    d_bad = [d for d,r in state.rho.items() if r < rho_min]
    if not d_bad:
        return state.m
    cands = []
    for m in M:
        if not R.has_edge(state.m, m): continue
        if R[state.m][m].rho_sw < rho_min: continue
        if any(d in critical_dofs(m) for d in d_bad): continue
        if state.time_since_switch < dwell_time: continue   # 防震荡
        cands.append(m)
    return min(cands, key=lambda m: R[state.m][m].c_sw, default=state.m)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RAP | O(|M|·|A_univ|·|S|) | O(|M|·|A_univ|) | 参数化仿真校准，采样覆盖 ≥ 95% |
| RCG | O(|M|²·(|A|+|τ_sw|·|𝔇_ρ|)) | O(|M|²) | 共享子空间可判定，切换地板可验证 |
| LCC | O(k·(B/c_min)·|M|·|T|) | O(|M|·|T|) | 覆盖单调子模，贪心 (1−1/e) 近似 |
| RRC | O(|M|·|𝔇_ρ|) | O(|M|·|𝔇_ρ|) | Lipschitz 下界保守，拒绝“迁移更脆” |
| RSC | O(|τ_sw|·|𝔇_ρ|) | O(|τ_sw|) | 轨迹 ⊆ A_∩，ρ_sw ≥ 地板 |
| BCP | O(|M|·k·(|V|log|V|+|E|)) | O(|V|+|E|) | RTC 闭合，Pareto 前沿可解释 |

**定理 1（低成本覆盖近似性）**
`C(S)` 为单调子模。预算约束下 IP-123 的“成本-收益贪心 + 单点枚举”满足 `C(S_greedy) ≥ (1−1/e)C(S*)`。**含义：可通过廉价构型基逼近预算最优覆盖，而无需单一昂贵构型。**

**定理 2（切换安全性）**
若 `π_R` 每条边 `RTC` sound，则切换过程无构型诱导动作错位，且
```
P_switch_fail ≤ β_sw + Σ_d(1 − ρ_sw(d))
```

**定理 3（低成本可重构端到端成功率）**
任务 `T` 被 `S` 覆盖且 `F` 可部署时：
```
E[P_success] ≥ C(S)·(1 − Σ_d(1 − ρ_floor(d)) − β_sw − β_E) − P(B_used > B)
```
证明要点：覆盖项由构型并集给出；构型内成功率由第 54 轮定理给出并以 `ρ_floor = min_m ρ_m` 取最差构型；切换风险由定理 2 独立扣除；预算超支为一票否决项。三项独立，不能互相抵消。

## 5. 本轮最大风险

**一句话**：低成本可重构方案的最大风险是“廉价陷阱”——覆盖/美元优化会系统性偏好**单构型便宜但切换频繁**的构型基，而便宜机构的公差、间隙与漂移使第 54 轮证书在构型间不可迁移，误差恰好堆积在切换边界，最终省下了硬件钱却付出隐蔽的切换失效与负迁移代价；因此必须以 **切换预算 + 构型条件鲁棒地板 + 悲观迁移界** 三重护栏，宁可少覆盖，也不把“单位美元覆盖率高”误当作“可部署”。
