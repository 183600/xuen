# 第 6 轮（灵感循环新循环第 1 轮；本轮灵感：「技能学习」×「场景落地」）

> **基线**：第 5 轮 InstructGauge-RTDI（IP-334–339；定义 468–492；引理 63–68；实验 E473–E492）。第 1–4 轮 LeanGauge / MODGAUGE / ToolGauge / InstructGauge 骨架继续继承不变。
> 本轮纪律：**增量升级 + 严格退化**。技能学习与场景落地各沿一条轴升级 RTDI，任一环节不可用都必须能一键退回 v5；学习与落地是增强项、不是依赖项。

## 0. 直觉与动机

**灵感 1（技能学习 → 学的不是轨迹，而是「带能力域的契约」）**
直觉：人类师傅教徒弟，教的不是一段固定轨迹，而是「什么条件下能用、做到什么算成功、失败怎么收场」。机器人技能学习如果只拟合一个策略 checkpoint，最大的隐患不是「学不会」，而是**静默越界**：在演示分布内很好，稍微偏出分布仍然自信输出，却没有任何机制说「这里我不行」。因此技能的正确对象不是 π，而是 `(π, pre/post, 验收测试, 能力域 K, 成本, 可逆性, 版本哈希)` 的**技能契约**。学习算子的产出必须包含「我在哪里有效、哪里必须弃权」的证书；`UNKNOWN` 必须是一等结果，不能被当成 PASS。这与 v5 的能力闭包一脉相承：v5 约束「语言不能扩权」，本轮约束「学习不能偷偷扩能力域」。

**灵感 2（场景落地 → 不是一次 sim2real 迁移，而是一段可追责的灰度过程）**
直觉：实验室里调通的技能，到了真实场景坏掉，往往不是像素差，而是**场景结构变了**：物体关系、反光、遮挡、动态干扰、人的活动都变了。更关键的是，「落地」不是把开关从仿真拨到真机，而是一个**有包线、有监测、有回滚、有证据账本**的过程：先在数字孪生/影子模式跑，再在可逆动作上灰度，最后才允许自主执行不可逆动作。正确口径是把场景形式化为签名 `s`，把落地形式化为「场景包线 × 技能能力域」的兼容性证书与模式晋升；落地失败不是灾难，而是**降级并留下可审计证据**。

**灵感 3（两者耦合 → 最危险的是「边执行边自我修改」）**
直觉：技能学习想在线更新，场景落地又要求持续适应，二者一耦合就会产生最隐蔽的失败：**系统用自己正在执行的策略去产生验证自己的证据**。一旦允许测试时更新，校准所依赖的可交换性被破坏，证书从「保证」退化成「自证」。因此耦合处必须放一堵**学习-部署防火墙**：生产路径只读**钉扎的、已认证的技能版本**；学习只能写影子注册表，只有在可逆、有回滚、有人监督的状态下才允许探索；晋升必须走离线证书 + 金丝雀 + 证据账本。再叠加**三值验收**、**能力域闸门**与**不可逆禁学**，把「学得越多越自信」改造成「学得越多，越清楚自己的边界」。

## 1. 研究问题（本轮要回答什么）

- **Q1（技能的可认证性）**：能否让每个学习到的技能自带「能力域 + 三值验收 + 版本谱系」的证书，使越界调用在**执行前**被拦住，而不是在执行后被发现？
- **Q2（落地的可追责性）**：如何把场景落地从一次性迁移变成有包线、有灰度、有回滚、有证据的可审计过程，并量化「何时可以从影子/守护模式晋升到自主」？
- **Q3（耦合的防火墙）**：当学习与部署同时在线，如何用结构（钉扎、影子、不可逆禁学、外部验收）阻止「自证式适应」把证书有效性悄悄掏空？

## 2. 四条设计原则（雏形，正式化见产物区定义 493–518）

**P1 契约化技能（Contractual Skill）**
技能不是 checkpoint，而是契约：`pre/post` 定义适用条件与目标，`Acc` 是三值验收（PASS/FAIL/UNKNOWN），`K` 是校准过的能力域，`h` 是内容哈希。只有 `s ∈ K̂_σ` 且证书未过期才允许调用；否则必须组合、回退或求助。**能力域外不执行，是类型级纪律，不是运行时建议。**

**P2 场景包线（Scene Envelope）**
把场景写成签名 `s=(对象,关系,光照,动态,人)`，把部署写成包线 `E=(S_E, 假设, 监测, 回滚)`。每个块执行前计算 `Compat(Π_used, s)`；不兼容即降级到守护模式或拒绝。**落地不是「迁移成功」，而是「在包线内可证、出包线可退」。**

**P3 学习-部署防火墙（Learning-Deployment Firewall）**
生产只执行钉扎版本；学习写影子注册表；晋升需要离线证书 + 金丝雀 + 证据账本。**绝不允许正在产生评估证据的策略在同一轮里被更新**——这是保证校准可交换性的结构前提。

**P4 不可逆禁学（No-Learn on Irreversible）**
凡是不可逆动作，禁止探索式学习与未认证技能；只允许已认证、K=1、外部回执交叉验证的执行。学习可以发生在可逆状态，**不可逆状态只消费证书，不生产证书**。

## 3. 与基线的接口（如何退化）

- 技能学习/认证不可用 ⇒ 冻结为 v5 预注册原语库 Π₀，等价于 RTDI 的 PrimitiveGraph；
- 能力域证书不可用/样本不足 ⇒ 所有技能按 `UNKNOWN` 处理，只走 v5 已注册任务，K=1；
- 场景签名/包线不可用 ⇒ 只允许 v5 已注册场景，退回 RTDI 的 SpatialCert 逐帧校验；
- 防火墙/影子注册表不可用 ⇒ 禁止在线学习，生产只读 pinned Π₀；
- 落地模式不可用 ⇒ 永远停留在 GUARDED（可逆 + K=1），等价于 v4 WR 的保守路径；
- SLD 失效 ⇒ RTDI；RTDI 失效 ⇒ InstructGauge-WR ⇒ InstructGauge v3 ⇒ ToolGauge；LeanGauge / MODGAUGE 骨架不变。

## 4. 预期贡献

1. 一个「技能契约 + 能力域证书」的可认证技能口径，把技能学习的风险从「学不会」移到可检查的「越界不执行」；
2. 一个「场景包线 + 灰度落地 + 证据账本」的落地协议，把场景迁移从一次性赌博变成可追责的状态机；
3. 一堵「学习-部署防火墙」，用钉扎、影子、不可逆禁学与外部验收阻断自证式适应；
4. 一条完整可证伪路径：E493–E514 覆盖契约推断、能力域校准、越界检测、负迁移、灰度晋升、回滚、漂移、跨场景落地与 50Hz 保全。

## 5. 本轮最大风险

**一句话**：能力域与场景签名都是系统从有限、非独立同分布数据里自证的，真实的语义漂移可能恰好落在「特征不变但物理已变」的盲区；一旦验收测试也由同一套感知给出，系统会得到「证书有效、物理已偏」的自信失败，而防火墙只能阻止自我修改，阻止不了自证。

## 2. 形式化定义（要点）

**定义 493（技能契约 SkillContract）**
一个技能不是策略权重，而是契约：
```
σ = (id, h, π_σ, θ_σ, pre_σ, post_σ, Acc_σ, K_σ, c_σ, rev_σ, ver_σ)
h        = H(π_σ, θ_σ, pre_σ, post_σ, Acc_σ, K_σ)
Acc_σ    : (s, s', trace) → {PASS, FAIL, UNKNOWN}
rev_σ    ∈ {reversible, irreversible, mixed}
```
调用前提（执行前硬闸门）：
```
Invokable(σ, s, m) ⇔ pre_σ(s) ∧ s ∈ K̂_σ ∧ CC(σ,s).valid
                     ∧ mode_allows(m, σ) ∧ h_σ = Pinned(σ)
```
`UNKNOWN` 不满足 `valid`；`Acc_σ` 的任何 `PASS` 必须来自独立于策略的验收器（见定义 507）。

**定义 494（场景签名与距离 SceneSignature）**
```
s = (O, R, L, D, H)
φ(s) = (φ_O, φ_R, φ_L, φ_D, φ_H) ∈ ℝ^d
d_S(s,s') = sqrt( Σ_k w_k · d_k(φ_k(s), φ_k(s'))² )
```
`w_k` 由部署前校准集学习并冻结；签名本身不包含任务标签，避免「语义看似相同、物理不同」的标签泄漏。

**定义 495（能力域 CompetenceRegion）**
```
K_σ = { (θ,s) | P(Acc_σ = PASS | θ, s, π_σ) ≥ 1 - δ_σ }
K̂_σ = ⋃ { cell_c | p_LB(c) ≥ 1 - δ_σ ∧ n_eff(c) ≥ n_min }
```
`p_LB` 为 Clopper–Pearson 下界；网格按 `(θ 离散化, φ(s) 主轴)` 划分，并做层级平滑（父单元先验向子单元收缩）。`K̂_σ` 允许非凸、可不连通；补集不自动等于 `FAIL`，而是 `UNKNOWN`。

**定义 496（能力域证书 CompetenceCert）**
```
CC(σ,s) = (h_σ, s_fp, p̂, p_LB, n_eff, method, cell, issued_at, ttl, valid)
valid ⇔ s_fp ∈ K̂_σ ∧ p_LB ≥ 1 - δ_σ ∧ n_eff ≥ n_min
        ∧ (now - issued_at) ≤ ttl ∧ ¬DriftAlarm(s)
```
`ttl` 与漂移事件都会使证书过期；过期不是错误，而是**回到 UNKNOWN 的正常路径**。

**定义 497（场景包线与兼容证书 SceneEnvelope）**
```
E = (S_E, Φ_E, M_E, R_E)
Compat(Π_used, s) = 1 ⇔ s ∈ S_E ∧ ∀σ ∈ Π_used : CC(σ,s).valid
```
若 `Compat=0`，返回见证 `w = (s, {σ | CC(σ,s) 无效}, 失效原因)`；见证写入证据账本，供后续扩包线或重训使用。

**定义 498（技能获取算子 SkillAcquisition）**
```
Acquire(D, Π, B) = Certify(Fit(D), Π)
Certify 接受条件：
 (i)   留出集上 Acc 的假 PASS 率 ≤ α（PASS 必须可被独立复核）
 (ii)  K̂_σ 非空，且在其覆盖的网格上校准覆盖率 ≥ 1 - β
 (iii) I(σ,Π) ≤ ε（负迁移闸门）
 (iv)  rev_σ = irreversible ⇒ D 中不得含探索式数据，且只能由已认证子技能组合
否则返回 ⊥（不进入注册表）。
```

**定义 499（安全可学谓词 SafeToLearn）**
```
SafeLearn(s,σ) ⇔ rev_state(s) = reversible
                 ∧ ¬human_in_workspace(s)
                 ∧ RB.ready
                 ∧ M_E.active
                 ∧ B_left > 0
irreversible(s) ⇒ SafeLearn(s,σ) = false
```
该谓词是**学习发生**的许可，不是技能调用的许可；两者不得互相替代。

**定义 500（技能干扰与负迁移 SkillInterference）**
```
I(σ,Π) = max_{σ'∈Π} max_{x∈K̂_{σ'}} [ p_{σ'}(x) - p_{σ'|σ}(x) ]_+
```
`p_{σ'|σ}` 是引入 σ（共享表征/参数更新）后 σ' 的成功率。若 `I>ε`，拒绝 σ 或将其放入隔离注册表（仅影子、不晋升）。

**定义 501（技能图与契约链 SkillGraph）**
```
G_Π = (Π, E_Π)
(σ_i, σ_j) ∈ E_Π ⇔ post_{σ_i} ⊨ pre_{σ_j}
                    ∧ effects(σ_i) ∩ hazards(σ_j) = ∅
                    ∧ tools(σ_i) ∪ tools(σ_j) ⊆ T₀
```
路径 `σ₁…σ_k` 合法当且仅当存在契约链见证（定义 512）；技能图把 v5 的「原语类型匹配」升级为「认证后的效果蕴含匹配」。

**定义 502（落地模式与晋升 DeploymentMode）**
```
m ∈ {TWIN, SHADOW, GUARDED, AUTONOMOUS}
mode_allows(TWIN, σ)       = false            // 不产生物理动作
mode_allows(SHADOW, σ)     = true             // 仅影子执行，不驱动执行器
mode_allows(GUARDED, σ)    = (rev_σ = reversible) ∧ K = 1 ∧ human_ack
mode_allows(AUTONOMOUS, σ) = CC(σ,s).valid
```
晋升谓词（`m → m+1`）：
```
Promote(m) ⇔ n_episodes ≥ n_m
             ∧ LCB(success | m) ≥ 1 - δ_m
             ∧ safety_violations = 0
             ∧ drift_alarm = false
             ∧ rollback_verified = true
```
任一不安全事件、证书过期或漂移告警 ⇒ 立即降级（至少降到 `GUARDED`），并解除钉扎。

**定义 503（证书钉扎与漂移 CertificatePinning）**
```
Pinned(σ) = h  ⇔ 生产注册表中 σ.id ↦ h
DriftAlarm(s) ⇔ d_S(φ(s), M_known) > τ_d
                ∨ CUSUM(residual) > h_c
```
漂移告警触发：解钉扎、证书失效、模式降级、把当前场景写入「未知场景」队列。**生产执行期间哈希不可变**。

**定义 504（学习-部署防火墙 LearningDeploymentFirewall）**
```
Prod ⊆ { σ | Pinned(σ) }                  // 生产读路径
Learn writes Π_shadow                       // 学习写路径
Promote: Π_shadow → Π  ⇔  Certify(σ) ∧ Canary(σ) ∧ IndependentAccept(σ)
```
防火墙不是「权限检查」，而是**数据流隔离**：生产的证据流不得回流去更新生产正在使用的策略。

**定义 505（金丝雀协议 CanaryProtocol）**
```
Canary(σ) = 在 SHADOW/GUARDED 下、仅在可逆子场景、与 pinned 对照做配对试验
Promote    ⇔ LCB(Δsuccess) > 0 ∧ Δsafety = 0 ∧ 回滚演练通过
```

**定义 506（回滚契约 RollbackContract）**
```
RB = (ckpt_policy, restore, verify)
rollback_ok ⇔ H(restore(ckpt)) = H(ckpt) ∧ effects ⊆ ReversibleSet
```
回滚是落地协议的一等公民：不能回滚的技能，不能进入 `AUTONOMOUS`。

**定义 507（三值验收 AcceptanceTest）**
```
Acc_σ : (s, s', trace) → {PASS, FAIL, UNKNOWN}
UNKNOWN ≠ PASS
cost(Acc_σ) 计入 WCET
```
`UNKNOWN` 触发升级/求助或保守回退；它同时是「验收器看不到」与「验收器不确定」的统一出口。

**定义 508（获取预算与优先级 SkillBudget）**
```
rank(σ_cand) = E[ΔCover(σ_cand)] · (1 - λ·risk(σ_cand)) / cost(σ_cand)
risk = P(rev = irreversible) · (1 - coverage) + I(σ,Π)
```
预算既包括示范/标注，也包括认证所需的交互次数；**认证成本必须计入获取决策**。

**定义 509（落地证据账本 FieldEvidenceLedger）**
```
L = append-only chain
entry = (episode_id, mode, Π_pinned, CC digest, outcome, drift, escalation, H(prev))
```
账本用于：晋升审计、漂移归因、回滚定位、以及向外部监管证明「当时用的是哪个版本」。

**定义 510（升级/求助策略 EscalationPolicy）**
```
if UNKNOWN ∨ ¬Compat ∨ cert_expired ∨ DriftAlarm
then FALLBACK(ι₀) 或 ASK_HUMAN
```
求助必须带最小证据包 `(s_fp, 失败技能, CC, 见证, 建议动作)`，避免「只报错不解释」。

**定义 511（场景漂移监测 SceneDriftMonitor）**
```
two-sample test: φ(s_current) vs φ(M_known)
CUSUM: S_t = max(0, S_{t-1} + (r_t - μ₀ - k))
alarm ⇔ p_value < α ∨ S_t > h
```
监测器只做「分布是否变了」的报警，不负责判断「为什么变」；后者交给 Diag/FaultCert。

**定义 512（契约链 ContractChain）**
```
chain(σ₁…σ_k) valid ⇔
  pre_{σ₁} ⊆ s ∧
  ∀i<k : post_{σ_i} ⊨ pre_{σ_{i+1}} ∧
  effects(σ_i) 不破坏 φ_E 中的包线假设
```
契约链是 v5 Kinematic-Loop 的语义升级：不仅要求前缀可截断，还要求每一步的后置能推出下一步的前置。

**定义 513（技能组合证书 SkillCompositionCert）**
```
SCC = (path, {edge_witness}, p_LB^agg, irr_check, WCET^agg)
p_LB^agg = max(0, 1 - Σ_i (1 - p_LB_i))     // 并集界，保守
```
组合后置的成功下界必须显式给出；不允许把各步点估计直接相乘当作保证。

**定义 514（能力域网格与校准 CompetenceGrid）**
```
grid: (θ 离散桶) × (φ(s) 主轴分位桶)
cell posterior: Beta(a+1, b+1), a=#PASS, b=#FAIL
LCB: Clopper–Pearson(α=δ_σ)
hierarchical: 子单元向父单元收缩，n_eff 按有效样本计
n < n_min ⇒ UNKNOWN（不是 0，也不是 1）
```

**定义 515（版本谱系 SkillVersion）**
```
ver_σ = (h, parents, data_hash, cert_hash, created_at, signer)
```
任何影响 `π_σ/θ_σ/pre/post/Acc/K` 的修改都产生新 `h`；生产只认钉扎哈希，**不存在「同 id 静默升级」**。

**定义 516（SLD-8C 闭环扩展）**
```
W:       感知（含 WristCam）
R:       推理（Hypothesis + Γ_parse）
SkillPlan: 技能规划（G_Π 上的契约链搜索 + Γ_inst）
Gate:    双闸门（Compat + Invokable + mode_allows）
E:       执行（rt-chunk；GHARDED 下 K=1；实时 SpatialCert）
V:       验证（CVC + SpatialCert + 三值 Acc）
Diag:    诊断（FaultCert + 证书失效见证）
Recover: 恢复（RecoveryRegistry + RB）
Learn:   影子学习（仅在 SafeLearn；写 Π_shadow）
U:       更新（Dbox + 证据账本 + 钉扎/谱系 + 漂移统计）
```

**定义 517（落地证书 DeploymentCert）**
```
DC = (site_id, E, Π_pinned, mode, evidence_digest, expiry, signer)
```
`DC` 是「这个站点、这个包线、这个技能版本集合、这个模式下」的可审计快照；任何一项变化都必须重新签发。

**定义 518（落地就绪度 FieldReadiness）**
```
FR = (coverage, false_safe_rate, rollback_rate, drift_latency, escalation_precision)
Ready ⇔ coverage ≥ 1-β ∧ false_safe_rate = 0
        ∧ rollback_rate = 1 ∧ drift_latency ≤ 2 blocks
        ∧ escalation_precision ≥ 0.9
```
`FR` 不是论文指标，而是上线放行门槛；任一不达标只能停留在更低模式。

from dataclasses import dataclass
from enum import Enum


class Acc(Enum):
    PASS = 1
    FAIL = 0
    UNKNOWN = -1


@dataclass(frozen=True)
class SkillContract:
    sid: str
    h: str
    pi: object                  # 闭环控制器
    theta: dict
    pre: callable
    post: callable
    acc: callable               # (s, s2, trace) -> Acc
    K: "CompetenceModel"
    cost: dict
    rev: str                    # reversible | irreversible | mixed
    ver: tuple


class CompetenceModel:
    """能力域：网格 + Clopper-Pearson 下界 + 层级平滑。"""

    def __init__(self, delta=0.05, n_min=30, ttl_s=3600):
        self.delta = delta
        self.n_min = n_min
        self.ttl_s = ttl_s
        self.cells = {}          # cell -> [pass, fail]
        self.issued = {}         # cell -> timestamp

    def _cell(self, theta, scene_fp):
        return (round(theta.get("t", 0.0), 2), scene_fp)

    def observe(self, theta, scene_fp, acc):
        if acc is Acc.UNKNOWN:
            return                # UNKNOWN 不进入成功率统计
        c = self.cells.setdefault(self._cell(theta, scene_fp), [0, 0])
        c[0 if acc is Acc.PASS else 1] += 1

    def lcb(self, theta, scene_fp):
        a, b = self.cells.get(self._cell(theta, scene_fp), (0, 0))
        n = a + b
        if n < self.n_min:
            return 0.0, n        # 样本不足 => 下界 0 => UNKNOWN
        return clopper_pearson_lower(a, n, self.delta), n

    def valid(self, theta, scene_fp, now):
        p_lb, n = self.lcb(theta, scene_fp)
        issued = self.issued.get(self._cell(theta, scene_fp), now)
        return (n >= self.n_min and p_lb >= 1 - self.delta
                and now - issued <= self.ttl_s)


class SceneEnvelope:
    def __init__(self, S_E, phi_E, monitor, rollback, tau_d=0.8):
        self.S_E = S_E
        self.phi_E = phi_E
        self.monitor = monitor
        self.rollback = rollback
        self.tau_d = tau_d

    def in_envelope(self, s):
        return self.S_E.contains(phi_scene(s)) and self.monitor.no_alarm(s)

    def compat(self, pi_used, s, now):
        if not self.in_envelope(s):
            return False, "out_of_envelope"
        for sig in pi_used:
            if not sig.K.valid(sig.theta, scene_fp(s), now):
                return False, f"competence:{sig.sid}"
        return True, "ok"


class SkillAcquisition:
    """技能获取：只在 SafeLearn 状态运行；产出必须过认证。"""

    def __init__(self, alpha=0.01, beta=0.05, eps=0.05):
        self.alpha, self.beta, self.eps = alpha, beta, eps

    def acquire(self, D, Pi, budget, s):
        if not safe_to_learn(s):
            return None
        cand = self.fit(D)
        cand = self.infer_contract(cand, D)
        self.calibrate(cand, D.holdout)
        return cand if self.audit(cand, Pi) else None

    def audit(self, cand, Pi):
        if false_pass_rate(cand.acc, cand.val_set) > self.alpha:
            return False
        if not cand.K.nonempty():
            return False
        if self.interference(cand, Pi) > self.eps:
            return False
        if cand.rev == "irreversible" and cand.used_exploration:
            return False
        return True

    def interference(self, cand, Pi):
        worst = 0.0
        for other in Pi:
            for x in other.K.sample_cells():
                p_before = other.success_at(x)
                p_after = other.success_after_update(cand, x)
                worst = max(worst, max(0.0, p_before - p_after))
        return worst


class DeploymentGate:
    MODES = ("TWIN", "SHADOW", "GUARDED", "AUTONOMOUS")

    def __init__(self, n_m, delta_m):
        self.mode = "TWIN"
        self.n_m, self.delta_m = n_m, delta_m

    def allow(self, sig, s, now, human_ack=False):
        if self.mode == "TWIN":
            return False
        if self.mode == "SHADOW":
            return True                      # 只影子，不驱动执行器
        if not sig.K.valid(sig.theta, scene_fp(s), now):
            return False
        if self.mode == "GUARDED":
            return sig.rev == "reversible" and human_ack
        return True

    def promote(self, ledger, now):
        m = self.mode
        if m == "AUTONOMOUS":
            return m
        if (ledger.n_episodes(m) >= self.n_m[m]
                and ledger.lcb_success(m) >= 1 - self.delta_m[m]
                and ledger.safety_violations(m) == 0
                and not ledger.drift_alarm(m)
                and ledger.rollback_verified(m)):
            return self.MODES[self.MODES.index(m) + 1]
        return m

    def demote(self, why):
        self.mode = "GUARDED" if self.mode == "AUTONOMOUS" else "SHADOW"
        return why


class LearningFirewall:
    """生产与学习的数据流隔离。"""

    def __init__(self):
        self.pinned = {}         # sid -> h
        self.shadow = {}         # sid -> SkillContract

    def pin(self, sig):
        self.pinned[sig.sid] = sig.h

    def stage(self, sig):
        self.shadow[sig.sid] = sig

    def promote(self, sig, canary_ok, cert_ok, independent_ok):
        if (canary_ok and cert_ok and independent_ok
                and sig.rev != "irreversible"):
            self.pinned[sig.sid] = sig.h
            return True
        return False

    def production_skill(self, sid, registry):
        h = self.pinned.get(sid)
        return registry.get(sid, h) if h else None

def instructgauge_sld(M, s, ell=None):
    """SLD 增强闭环：先过场景/能力域闸门，再执行，最后只做影子学习。"""
    now = M.env.time()

    # 1. 场景包线 + 技能兼容性（执行前硬闸门）
    ok, why = M.envelope.compat(M.used_skills(ell), s, now)
    if not ok:
        M.gate.demote(why)
        M.ledger.append(s, M.gate.mode, witness=why)
        return instructgauge_rtdi(M, s, ell)      # 严格退 v5

    # 2. 在认证技能图上规划契约链
    path = M.skill_graph.plan(ell, M.registry.pinned(), s)
    if not path or not M.skill_graph.chain_valid(path, s):
        return instructgauge_rtdi(M, s, ell)

    # 3. 逐技能闸门 + 实时任务建模（复用 v5 RT-CVC）
    iota = M.skill_graph.instantiate(path, M.scene)
    C = M.iac.plan_chunk(iota, M.lbox.hypothesize(s, M.dbox.R[s], iota[0]),
                         M.tools, M.budget_left(s), M.drift_bound(s))
    if not M.gate.allow(path[0], s, now, human_ack=M.human_ack(s)):
        M.gate.demote("mode_not_allow")
        return instructgauge_rtdi(M, s, ell)

    # 4. 执行 + 三值验收 + SpatialCert（复用 v5 诊断恢复）
    C, spatial_cert, fault_certs = M.rtdi_execute(C, iota, s)

    # 5. 证据账本（append-only）
    M.ledger.append(episode=s, mode=M.gate.mode, path=path,
                    cert=spatial_cert, outcome=C.status,
                    drift=M.envelope.monitor.status(s),
                    escalations=M.escalations(s))

    # 6. 影子学习：只写 Π_shadow，绝不改生产 pinned
    if M.safe_to_learn(s) and M.firewall.shadow_enabled:

                                     M.budget_left(s), s)
        if cand is not None:
            M.firewall.stage(cand)
            M.registry.record_shadow(cand)

    # 7. 模式晋升/降级（证据驱动）
    M.gate.mode = M.gate.promote(M.ledger, now)
    return C, spatial_cert, bind_claims(C, iota, M.tcv.get_receipts())

## 4. 推导

**引理 69（能力域证书的单次安全性）**
假设场景监测对包线外无假阴性，且 `CC(σ,s).valid` 由 Clopper–Pearson 下界给出。若一次调用满足 `Invokable(σ,s,m)`，则其验收 PASS 的真实概率至少为 `1-δ_σ-β_mon`，其中 `β_mon` 是监测假阴性率。
证明：`valid` 要求 `p_LB ≥ 1-δ_σ`，而 `p_LB` 是真实成功率的 `1-α` 置信下界；场景监测的假阴性以 `β_mon` 计入并集界。注意该引理只保证「执行前的能力域归属」，不保证验收器本身的假 PASS；后者由定义 507 的独立性与引理 71 约束。

**引理 70（契约链组合可靠性）**
若 `chain(σ₁…σ_k)` 有效，且每一步的验收在独立回执下为 PASS，则组合后置 `post_{σ_k}` 以至少 `1-Σ_i δ_i` 的概率成立。
证明：对 `i` 归纳。`post_{σ_i} ⊨ pre_{σ_{i+1}}` 由链有效性给出；若 `σ_i` 的 PASS 为真，则后置成立，下一步前提满足。各步失败事件取并集界，得到 `1-Σδ_i`。这里不使用独立性假设，因此下界偏保守但可证。

**引理 71（学习-部署防火墙与可交换性）**
若生产策略在证据收集期间保持 pinned 不变，则证据样本相对执行策略可交换，`CC` 的覆盖保证成立；若允许同一轮在线更新，则存在反例使名义 `1-δ` 覆盖失效。
证明：可交换性要求样本分布不随样本索引变化；同轮更新使 `π_t` 依赖前 `t-1` 个样本，分布漂移，Clopper–Pearson/共形覆盖的前提被破坏。反例：两阶段 bandit，第一阶段探索把第二阶段最优点排除，名义区间仍收缩，但真实成功率停在 `1-δ` 以下。防火墙把更新移到影子路径，生产证据仍由固定 `π` 产生，故可交换性保留。

**引理 72（负迁移界）**
若 `I(σ,Π) ≤ ε` 且所有调用受能力域闸门约束，则引入 `σ` 后已有技能的成功率下降不超过 `ε + δ`。
证明：`I` 取所有 `x∈K̂_{σ'}` 上的最大逐点下降；能力域闸门排除 `x∉K̂_{σ'}` 的越界调用；剩余误差来自能力域估计的 `δ`。因此总退化 ≤ `ε + δ`。

**引理 73（落地模式单调性与回滚）**
在证据账本完整、证书未过期、无漂移事件的条件下，模式晋升不会降低安全成功率的下界；任一不安全事件触发降级，回滚后状态与最近 pinned 检查点同构。
证明：晋升谓词要求 `LCB(success)` 不低于 `1-δ_m` 且安全违背为 0，故允许集只收紧、不放松；降级把允许集进一步收紧到 `GUARDED`；回滚契约验证 `H(restore(ckpt))=H(ckpt)` 且副作用属于可逆集。注意这是条件性单调：漂移或证书过期会主动撤销单调性。

**引理 74（能力域样本复杂度）**
要在单个网格单元以置信度 `1-α` 证明成功率 ≥ `1-δ`，Hoeffding 需要 `n ≥ ln(1/α)/(2δ²)`；使用 Clopper–Pearson 可更紧。总认证预算为 `O(|cells| · n)`。
证明：Hoeffding 不等式直接给出；Clopper–Pearson 由二项分布精确反演。推论：网格分辨率提高会使预算二次增长，因此必须层级平滑 + 主动采样，而不是均匀铺满。

**引理 75（退化等价性扩展）**
- 关闭 `Acquire`/`Firewall` ⇒ `Π` 冻结为 v5 预注册库，`PrimitiveGraph` 的 `Γ_parse/Γ_inst` 语义不变；
- 关闭 `CompetenceModel` ⇒ 所有 `CC` 为 `UNKNOWN`，只执行 v5 已注册任务且 K=1，等价 RTDI；
- 关闭 `SceneEnvelope` ⇒ 仅 v5 注册场景，`SpatialCert` 逐帧校验保留；
- 关闭 `DeploymentGate` ⇒ 固定 `GUARDED`（可逆 + K=1），等价 v4 WR 保守路径；
- 任一认证失败 ⇒ 回退默认 `ι₀`。
证明：逐项比较允许集与执行分支。关闭增强时，`Invokable` 退化为 v5 的 `pre/post + tools ⊆ T₀`，`Compat` 退化为包线恒真，`Acquire` 返回 ⊥；此时 `instructgauge_sld` 与 `instructgauge_rtdi` 在同一输入上走同一分支、产生同一 `ι` 与同一块，故 diff=0。

## 8. 本轮最大风险

**一句话**：能力域证书、场景签名与验收测试三者共享同一套感知与数据，最容易在「特征分布内、物理语义已变」的迁移上同时失效——系统会给出形式完美、物理错误的落地证书；灰度与防火墙只能阻止自我修改，阻止不了自证，因此真正的残余风险是**独立外部验收的缺失**。
