# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「主动交互」×「演示方案」）

> R69 让系统学会了「问」：把 epistemic 歧义交给注视、探针、问句去消解。但 R69 的交互本质上仍是**符号问答**——它索取一个标签（「左还是右？」「这是开心还是紧张？」），然后相信那个标签。这留下三个未解的洞：
> 1. **答非所示**：当歧义是**程序性**的（「该怎么做」），一句话根本说不清。人能说「绕左」，却没法用一句话教会系统「贴着墙、降速、到拐角先探头、留出回旋余量」。
> 2. **不可验证**：符号答案没有物理约束，无法在世界模型里重放、无法证伪；R69 的最大风险「问错，比不问更危险」正源于此——一个错误答案可以被证据纪律盖上「一致」的章。
> 3. **问而不学**：R69 每次问完，模态后验更新了，**策略权重没变**。同一种歧义下次还会出现，系统永远停在「反复求证」，而不是「学会」。
>
> 本轮两个灵感各补一刀：
> - **主动交互**不只是「提问」，还包括**演示**。人是靠「做给你看」传递程序性知识的；演示是比答案高一个数量级的交互带宽——它同时携带分类信息与程序信息。
> - **演示方案**把「要演示什么、向谁演示、在哪演示、如何验证、怎样安全地学」变成一份**可审批、可审计、可回滚的计划**，而不是零散的一次性提问。
>
> 核心命题：**演示是一条轨迹，而轨迹正是 R69 流匹配策略的动作单元**——于是「动作 / 问题 / 证据 / 教材」被统一成同一种对象。系统既**向人索取演示**（学习），也**向人提供演示**（让意图可读、让纠错可指认）；两者共用同一套「演示有效性认证 + 隔离学习 + 认证晋升」。命名 **DEMO-RAS**（Demonstration-Exchange, Mutual-Observation, Risk-Adaptive Safety：双向演示—互观认证风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**你能不能做给我看——以及我能不能做给你看**」。不确定性不仅可以是一句话，也可以是一段被纠正的轨迹。

## 0. 直觉与动机

**灵感 1（演示是轨迹，不是标签 → 与流策略同构）**
直觉：R69 的交互返回一个符号 y，要再经过一层「符号接地」才能变成动作；演示直接返回一条轨迹 ξ，与 R69 的策略输出 ξ 在**同一个空间**里。这意味着同一套流匹配解码器、同一套似然评分、同一套 C-RAS-WM 认证可以同时服务于「生成动作」「编码问题」「验证回答」「当作教材」。R69 里最脆弱的一环——语言答案到动作的接地——在演示里被**消掉**了：不需要接地，因为演示本身就是动作。这也是本轮最关键的表示论姿态：**用同一个对象承载沟通与执行，跨层误差就没有落脚点。**

**灵感 2（演示是干预，不是观测 → 因果信息量更大）**
直觉：问一句「你会怎么做」得到的是**观测性**回答（人可能说得好听、做得不同、或事后合理化）；请人演示得到的是**干预性**样本——在指定情境下真实执行的一条轨迹。因果推断里，intervention 比 observation 多出「在 do(context) 下系统会怎样」的信息。于是「选哪个情境请人演示」不是被动采样，而是**主动实验设计**：挑那些能最大程度区分当前几个模态、且人类成本低、状态可恢复的情境。这正是「演示方案」的严格含义——**方案 = 一组情境 × 请求的实验设计**，而不是一句「你来演示一下」。

**灵感 3（双向演示 → 识别优于回忆）**
直觉：R69 问「左还是右」，要求人**回忆/描述**自己的偏好；但人更擅长**指认与纠正**。DEMO-RAS 先把自己的 k 个候选轨迹**演示给人看**（幽灵轨迹/预览），人只需指一下「这个」或「这样改」。这把开放式提问变成**排序/偏好**信号（recognition over recall），更省人力、更少歧义、也更难被语言幻觉污染。反向演示同时解决**可读性（legibility）**：人看得见系统打算做什么，才能在它执行前拦下。**主动交互因此是双向的：既主动求教，也主动交底。**

**灵感 4（演示可被验证 → 正面回应 R69 最大风险）**
直觉：一句话答案无法证伪，一条轨迹却可以四路复核：①在 WM 里重放是否物理可行；②对无关情境扰动是否**不变**、对相关情境是否**敏感**（因果一致性）；③在当前策略密度下偏离是否**可解释**（Δa 应局部化在被质疑的模态上，而非任意乱走）；④是否与至少一个正交证据源（注视 / 第二次演示 / 任务结果）一致。**演示把「相信一个说法」变成「审计一个行为」**。这是 R70 相对 R69 最大的安全性增益。

**灵感 5（演示即学习 → 但学习必须被关进笼子）**
直觉：R68/R69 有一条铁律——**实时流零学习写操作**。演示若直接在线更新策略，就同时击穿实时性、安全认证与可回滚性。因此 DEMO-RAS 把演示学习做成三段式：**隔离缓冲（QDB）→ 离线蒸馏（SDF）→ 认证晋升（MOC/换装）**。实时控制器始终只读一个**冻结**策略；新策略必须通过安全回归、支撑集门控、反事实保持、金丝雀与回滚，才被允许上岗。演示还顺带成为 R69 模式校准（MCG）的**真值样本**——但必须用「情境 + 演示者」双留出，防止自我确认。**演示让系统终于能学习，但学习速度必须由认证带宽决定，而不是由数据带宽决定。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DEMO-RAS 总览）** DEMO-RAS = (DRP, DSO, TEL, DVA, QDB, SDF, DMC, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；实时路径对演示数据只读，或只写隔离缓冲）；
(ii) **演示隔离**：QDB 内样本不得影响任何在线推理；晋升只能经 SDF 与认证换装；
(iii) **双向同意与预算**：人→机演示须经 MOC 声明并获同意；机→人演示不得造成视觉/认知过载（≤ k_preview 条轨迹、单次 ≤ T_preview）；单位时间演示请求 ≤ 1；
(iv) **演示不单独定案**：单次演示只能更新后验或进入缓冲，不得单独改变安全包络、单独触发晋升（继承 R69 定义 293-iii 的证据纪律）。

**定义 311（演示对象与双向演示空间）** 人→机演示 ξ^H_{t:t+H} ∈ 𝒜_+（R69 增广动作空间，含任务与信息动作）；机→人演示为一组候选 {(ξ_k, ℓ_k, r_k)}，ℓ_k 为可读解释、r_k 为风险标注。双向演示空间 𝒟 = 𝒟_{H→R} ∪ 𝒟_{R→H}。

**定义 312（演示请求与演示方案）** 请求 q = (o_ctx, instr, target)，target ∈ {mode_id, procedure, boundary}。演示方案 D = (q_1,…,q_m) 是请求序列（可含情境构造与复位动作）。

**定义 313（演示信息增益与演示 VoI）** 令 ℬ 为当前证据。IG_demo(q) = H(M|ℬ) − E_{ξ^H∼π_H(·|q)}[H(M|ℬ ∪ ξ^H)]。VoI_demo(q) = IG_demo(q) − c_H(q) − c_safe(q) − c_rev(q)，其中 c_H 为人力/时间、c_safe 为演示本身风险、c_rev 为情境复位/不可逆成本。

**定义 314（主动演示方案设计 DSO）** D* = argmax_{D: Σc ≤ B, |D|≤m_max} [IG_demo(D) − λ·cost(D)]，其中 IG_demo(D) 为子模近似下的序列增益；要求 D 在可达状态集上**可复位**，且覆盖被区分模态的判别性子空间。求解用子模贪心（1−1/e 近似）。

**定义 315（问答/演示判别器）** 把歧义分解为分类分量（哪一类）与程序分量（怎么做）。若 I(mode; procedure | ξ) > I(mode; label | y)，选演示；反之选 R69 的提问。即：**分类歧义→问，程序歧义→演**；两者都大时先演（演示蕴含标签）。

**定义 316（演示有效性评估 DVA）** 对 ξ^H 计算四元证据：feas(ξ^H)（WM 重放与 C-RAS-WM 可行性）、caus(ξ^H)（无关扰动不变性 + 相关扰动敏感性）、expl(ξ^H)（Δa 局部化于 target 模态的似然可解释度）、cons(ξ^H)（与正交源一致性）。DVA 通过 ⇔ 四项均过阈值；否则该演示不进入学习缓冲，只作弱证据。

**定义 317（演示威胁模型）** 演示投毒（恶意/错误演示）、教学应试（只在会被测的情境演示）、演示疲劳（质量随次数下降）、规格博弈（演示编码表面特征而非意图）、专家偏差（演示者本身不是目标策略）。并入 AIC：ℰ_DEMO = ℰ_FLUID × ℰ_demo × ℰ_fatigue × ℰ_spec。

**定义 318（隔离演示缓冲 QDB）** 有容量上限、带来源/同意/时间戳/情境哈希的不可变日志；支持按情境去重与覆盖度检索；任何实时推理路径**禁止读**QDB 中的原始样本。

**定义 319（安全蒸馏 SDF 与认证晋升）** 离线在 QDB 上蒸馏策略增量 Δθ，须过四项检查：①安全回归（认证包络内不劣化）；②支撑集门控（在演示覆盖外的状态禁用增量，退化为冻结策略）；③反事实保持（对无关扰动的输出不变）；④金丝雀与回滚（可一键恢复上一冻结版本）。晋升复用 R68 定理 15 的换装不变式。

**定义 320（演示驱动模式校准 DMC）** 演示是真值模态样本，用于校准 R69 的 mode_head 与模态权重；校准集与验收集按「情境 × 演示者」双留出，禁止同一演示既训练又验收；ECE 回灌定义 306 的 MCG。

**定义 321（互观契约 MOC）** 交互前声明「我要演示什么 / 我需要你演示什么 / 用途与保留期 / 预算与安全边界」，获同意后执行；未声明请求作废；契约、同意与结果全部进审计。

**定义 322（演示安全）** 人→机演示不得诱导危险情境（情境构造本身过 C-RAS-WM）；机→人演示的幽灵轨迹必须标注风险，且不得被规划器误当作可执行指令；双方演示都受安全包络约束。

**定义 323（证书 J_DEMO）** J_DEMO = (J_FLUID, dva_pass_rate, demo_provenance_hash, scheme_coverage, distill_delta_id, safety_regression, rollback_ready, ECE_demo)。Valid ⇔ Valid(J_FLUID) ∧ DVA 通过 ∧ 晋升检查通过 ∧ 契约与预算未越界。

**定义 324（演示干扰集 ℰ_DEMO）** 见定义 317；并入 AIC 的对抗训练与审计。

**定义 325（演示课程覆盖与多样性）** cov(D) = 覆盖的判别性子空间比例；div(D) = 演示情境间最小距离。方案要求 cov ≥ τ_cov 且 div ≥ τ_div，避免「同一情境反复演示」造成的假学习。

**定义 326（退化关系）** 关闭演示（D = ∅ 或所有 VoI_demo ≤ 0 或 MOC 未同意）⇒ DEMO-RAS 逐指令退化为 FLUID-RAS；再关闭交互 ⇒ R68。安全侧单调不弱。

## 2. 关键算法骨架

```python
# IP-264 DRP + IP-265 DSO：何时 / 向谁 / 演什么（慢环路）
def plan_demonstration(modes, w, belief, reachable, budget):
    if ambiguity_type(modes) == 'categorical':
        return None, ask_label(modes)                  # 分类歧义 → 回 R69 提问
    D, gain = [], 0.0                                  # 程序歧义 → 主动实验设计
    while budget.left() and len(D) < M_MAX:
        q = max(reachable, key=lambda s: ig_demo(s, modes, belief)
                                          / (cost_H(s) + cost_safe(s)))
        if ig_demo(q, modes, belief) - cost(q) <= 0: break
        D.append(q); gain += ig_demo(q, modes, belief) - cost(q)
        reachable = exclude_near(reachable, q)         # 多样性：排除已覆盖情境
        belief = fictive_update(belief, q)             # 子模贪心用虚构后验
    return D, None

# IP-266 TEL：机→人演示（可读候选 + 指认 / 纠错，识别优于回忆）
def demonstrate_to_human(modes, k_preview=3):
    cands = topk(modes, k_preview)
    return [GhostTrajectory(xi=m.xi, label=m.explain, risk=m.risk) for m in cands]

# IP-267 DVA：四元演示有效性（把「相信说法」变成「审计行为」）
def validate_demo(xi, q, policy, wm, evidence):
    feas = wm.replay_feasible(xi) and c_ras_wm.envelope_ok(xi)
    caus = (invariance_ok(policy, xi, irrelevant_perturbs(q))       # 无关扰动不变
            and sensitivity_ok(policy, xi, relevant_perturbs(q)))   # 相关扰动敏感
    expl = likelihood_deviation_localized(policy, xi, q.target)     # Δa 局部化
    cons = agrees_with_orthogonal(xi, evidence)                     # ≥1 正交源
    return feas and caus and expl and cons

# IP-268 / IP-269：隔离 → 离线蒸馏 → 认证晋升（实时零学习写）
def ingest_demo(xi, q, consent):
    if not consent or not validate_demo(xi, q, ...): return REJECT
    qdb.append(xi, provenance=hash_state(q), consent=True, ts=now())
    return ACCEPT

def promote(policy, qdb):
    delta = distill_offline(policy, qdb)               # 离线，不碰实时环
    if not safety_regression_pass(delta):   return None
    delta.gate = support_mask(qdb)                     # 支撑集门控
    if not counterfactual_preserve(delta):  return None
    deploy_canary(delta); schedule_rollback(policy.frozen_id)
    return delta

# IP-271 DMC：演示驱动模式校准（情境 + 演示者双留出）
def calibrate_modes(mode_head, qdb):
    tr, va = split_by_context_and_demonstrator(qdb)
    mode_head.fit(tr)
    ece = expected_calibration_error(mode_head, va)
    return mode_head, ece                              # ECE 回灌 MCG

# IP-275 主闭环（继承 R69；演示只走慢环路 / 异步，实时环不变）
def DEMO_RAS_round(M, obs):
    k, lam, mode, (U_ale, U_epi) = M.fluid.round(obs)  # R69 实时环，< 2.6ms
    if U_epi > TAU_EPI and M.budget.allow_demo():
        D, ask = M.dso.plan_demonstration(M.modes, M.w, M.belief,
                                          M.reachable, M.budget)
        if ask is not None:
            M.mint.enqueue(ask)                        # 分类歧义退回 R69 提问
        if D:
            M.moc.declare(D)                           # 先声明，后执行
            if M.moc.consented():
                for q in D:
                    xi = M.human.request(q)            # 人→机演示
                    if M.dva.validate(xi, q, M.policy, M.wm, M.evidence):
                        M.qdb.ingest(xi, q, consent=True)
    M.tel.render(M.dso.current_modes())                # 机→人演示（可读候选）
    M.vqa_d.submit_async(M.qdb.last, M.tel.last, U_epi)
    return k, lam, mode, (U_ale, U_epi)
```

## 3. 推导

**引理 19（演示对答案的支配）** 设答案 y 是演示轨迹 ξ^H 的（随机）粗化，即存在确定性映射 f 使 y = f(ξ^H)。由数据处理不等式，I(M; ξ^H) ≥ I(M; y)，差额恰为 I(M; ξ^H | y)。故当程序分量为歧义主成分时 VoI_demo ≥ VoI_ans；反之当歧义是纯分类且演示成本更高时，答案更优。系：定义 315 的判别器是「单位成本信息增益」比较，而非「信息量绝对大小」比较。

**引理 20（演示的干预可识别性）** 若演示方案 D 在可达状态集上覆盖每个模态的判别性子空间，且情境构造满足后门准则（无未观测混杂），则模态身份 M 可被干预识别。反之，存在两个「说一套、做一套」的专家策略 π_H^(1), π_H^(2)，其**观测性答案分布相同**但 M 不同；仅演示分布可区分它们。系：**问句只能识别「人以为的模式」，演示才能识别「人实际执行的模式」**——这正是 R69 无法覆盖的「说做不一致」。

**引理 21（因果验证下的投毒上界）** 设原始演示投毒率 δ_d，DVA 对真实恶意演示的拒绝率为 κ'，对诚实演示的误拒率为 FP。进入 QDB 的投毒率 ≤ δ_d(1−κ') + (1−δ_d)·FP。进一步，若投毒演示必须在 m 个互不相同的情境上保持因果一致才能通过 caus 检验，则有效投毒率随 m 指数衰减。系：**演示把投毒从「骗过一次问答」升级为「在多个情境下一致地骗过世界模型」**，攻击成本随方案长度指数上升。

**引理 22（演示校准的双刃性）** 若演示来自目标专家且按「情境 × 演示者」双留出，则模态 ECE 期望下降 ≥ c·√(n_q)（n_q 为每情境有效演示数）。但若训练与验收演示同源（自我确认），ECE 可被**虚假压低**至少 ε_self，且该偏差在校准集内不可见。故 DMC 必须双留出，且 ECE 需在留出集上重估后才允许回灌 MCG。

**定理 18（DEMO-RAS 严格包含 FLUID-RAS）** 当 D = ∅、所有 VoI_demo ≤ 0 或 MOC 未同意时，DEMO-RAS 的控制指令与 FLUID-RAS 逐条相同；故安全与效率不低于 R69。有演示时，演示只通过「后验更新 + 隔离缓冲」改变决策与未来策略，实时安全包络不变。⇒ R69 是 R70 在「永不演示」边界上的严格退化。

**定理 19（隔离学习的实时安全性与可回滚性）** 因实时路径只读冻结策略，QDB 写入与离线蒸馏不改变任何在线行为（零学习写操作保持）。晋升经定义 319 四检后：安全回归不劣化、支撑集外退化为冻结策略、反事实保持、金丝雀可监控；任一失败可单调回滚到上一冻结版本。故演示学习不引入实时突变，且失败可逆。

## 6. 本轮最大风险

**一句话**：R69 的风险是「问错，比不问更危险」；R70 的风险是「**学错，比不问更危险**」——演示把一次错误从「一个可撤销的后验」固化成「一份通过全部安全检查的权重」，因为 DVA、安全回归、反事实保持全部只在**演示分布上**检验，一个自洽、物理可行、甚至因果一致的错误演示，会带着证书被蒸馏进策略，只在分布外或反事实处暴露，而那时它已经"合法"了。

**次级风险与缓解**：
1. **演示者偏差**（演示者不是目标策略）→ 定义 316 的 cons 交叉源 + E316 偏差检测 + 多演示者一致性；
2. **教学应试 / 规格博弈** → 定义 325 覆盖/多样性硬约束 + 留出情境验收 + 反事实保持；
3. **演示疲劳与高质量数据稀缺** → 预算门控 + 质量加权 + 只在 VoI 显著为正时才请求；
4. **隔离被绕过**（工程事故导致在线偷读 QDB）→ 定义 310-ii + E307 零写验证 + 进程级只读隔离；
5. **自我确认式校准**（用演示校准又用演示验收）→ 定义 320 双留出 + 引理 22 的 ε_self 监测。

def plan_demonstration(modes, w, belief, reachable, budget):
    if ambiguity_type(modes) == 'categorical':
        return None, ask_label(modes)                 # 分类歧义 → 回 R69 提问
    D = []
    while budget.left() and len(D) < M_MAX:

                                          / (cost_H(s) + cost_safe(s)))
        if ig_demo(q, modes, belief) - cost(q) <= 0: break
        D.append(q); reachable = exclude_near(reachable, q)
        belief = fictive_update(belief, q)
    return D, None

# IP-266：机→人演示（识别优于回忆）
def demonstrate_to_human(modes, k_preview=3):

            for m in topk(modes, k_preview)]

def validate_demo(xi, q, policy, wm, evidence):
    feas = wm.replay_feasible(xi) and c_ras_wm.envelope_ok(xi)
    caus = invariance_ok(policy, xi, irrelevant_perturbs(q)) \
           and sensitivity_ok(policy, xi, relevant_perturbs(q))

    cons = agrees_with_orthogonal(xi, evidence)
    return feas and caus and expl and cons

def ingest_demo(xi, q, consent):

    qdb.append(xi, provenance=hash_state(q), consent=True, ts=now())

def promote(policy, qdb):
    delta = distill_offline(policy, qdb)
    if not safety_regression_pass(delta):  return None

## 4. 推导

**引理 19（演示支配答案）** 答案 y 是演示 ξ^H 的粗化 ⇒ 由数据处理不等式 `I(M;ξ^H) ≥ I(M;y)`，差额为 `I(M;ξ^H|y)`。程序歧义为主时 VoI_demo 更优；纯分类且演示更贵时答案更优。系：定义 315 比较的是单位成本信息增益。

**引理 20（干预可识别性）** D 覆盖各模态判别子空间且情境构造满足后门准则 ⇒ M 可干预识别；纯观测答案在「说做不一致」下不可识别（存在答案分布相同、执行模式不同的两个专家）。系：**问句识别「人以为的模式」，演示识别「人实际执行的模式」**。

**引理 21（因果验证下的投毒上界）** 入缓冲投毒率 ≤ `δ_d(1−κ') + (1−δ_d)·FP`；若需在 m 个情境因果一致，则有效投毒率随 m 指数衰减。系：演示把投毒从「骗过一次问答」升级为「在多情境一致地骗过世界模型」。

**引理 22（演示校准双刃性）** 双留出下 ECE 期望下降 ≥ `c√(n_q)`；同源自欺可虚低至少 `ε_self` 且校准集内不可见 ⇒ DMC 必须双留出并重估后回灌 MCG。

**定理 18（DEMO-RAS 严格包含 FLUID-RAS）** `D=∅` 或 `VoI_demo≤0` 或 MOC 未同意时，逐指令等同 FLUID-RAS；有演示时只经「后验 + 隔离缓冲」改变决策与未来策略，实时安全包络不变。⇒ R69 = 「永不演示」边界。

**定理 19（隔离学习安全且可回滚）** 实时只读冻结策略 ⇒ 零学习写保持；晋升四检（安全回归 / 支撑集门控 / 反事实保持 / 金丝雀）通过后安全不劣化、覆盖外退化、可单调回滚。⇒ 无实时突变，失败可逆。

| E312 演示疲劳 | 长时程质量衰减 | 前后 20 次质量差 ≤ 5% |
| E313 严格包含 FLUID-RAS | 无演示逐指令一致 | 退化边界行为差 = 0 |
| E314 反事实保持 | 是否学到伪相关 | 无关属性扰动不变率 ≥ 98% |
| E315 课程覆盖 vs 泛化 | 覆盖/多样性阈值 | cov ≥ 0.8、div ≥ τ_div 时最优 |
| E316 专家偏差 | 演示者非目标策略 | 检测 AUC ≥ 0.85，拒绝错误晋升 |

## 7. 本轮最大风险

**一句话**：R69 的风险是「问错，比不问更危险」；R70 的风险是「**学错，比不问更危险**」——演示把一次错误从「一个可撤销的后验」固化成「一份通过全部安全检查的权重」。因为 DVA、安全回归、反事实保持都只在**演示分布上**检验，一个自洽、物理可行、甚至因果一致的错误演示，会带着证书被蒸馏进策略，只在分布外或反事实处暴露——而那时它已经「合法」了。**演示让系统学会学习，也第一次让系统学会一个无法撤销的错误。**

**次级风险与缓解**：演示者偏差（cons 交叉源 + E316 + 多演示者一致）；教学应试/规格博弈（覆盖/多样性硬约束 + 留出验收 + 反事实保持）；疲劳与数据稀缺（预算门控 + 质量加权 + 仅在 VoI 显著为正时请求）；隔离被工程绕过（定义 310-ii + E307 零写验证 + 进程级只读隔离）；自我确认式校准（定义 320 双留出 + 引理 22 的 ε_self 监测）。
