### 第 6 轮灵感驱动研究记录

**灵感词**：消融实验、步态规划

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把框架从「规则提议」推广为「任意生成器 + 认证边界」（CGE）：条件流匹配提议 π_FM、LMEM-v2 记忆固化、FAMK 情感调制、EFA-v5 级联、定理 5~8。但 v5 留下两笔结构性欠账：(a) 它一直在**加**模块、加软因子，却没有一件仪器去度量「每个门/模块是否还配得上它的维护成本」——R52 锚点维护负债与 R57 自指博弈只有红队，没有可量化的判据；(b) 整个框架是机械臂中心：候选 x=(pose,wrench)、接触集固定，无法表达腿足运动里「哪只脚何时着地」这个离散、会切换的决策。两个灵感词指向同一主题——「认证的可消融混合执行」（Certified Ablatable Hybrid Execution, CAHE），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门仍不新增**（维持七门），并首次允许**可证安全地移除门**——消融不是事后跑分的实验，而是一等公民的证书算子。

**直觉与动机**：

1. **消融实验 → 从「跑分表」升级为「证书级归因」**。ML 里消融问的是「去掉这个部件会怎样」；安全框架也必须问，但答案不能是均值，必须是证明。定义门 g 的**唯一贡献** U_g = Exec(G\{g}) \ Exec(G)：通过其余所有门、唯独死在 g 上的轨迹集合。若在声明域 D 上可证 U_g ∩ D = ∅，则 g 冗余，移除后执行集**逐点不变**——于是消融是单调安全的（不放大，嵌套链保持）。反之若 U_g ≠ ∅，就得到一条**见证**，证明该门「是活的」：无见证不设门。更妙的是，把敏感度 ρ_g(π)=π(U_g) 作为在线仪表：v5 的 R57 预言，学会博弈门 g 的策略会把 ρ_g 压到 0 而真实安全并不提升；「ρ_g 塌缩 ∧ 见证集非空」就是博弈的早期警报。消融因此同时偿还维护负债并给最深风险装上探针。

2. **步态规划 → 执行集必须抬升到混合（离散-连续）空间**。直觉：走路是一串接触模式，最危险的时刻是**切换**（触地冲击、离地打滑），而不是稳定支撑相。v5 的连续 x 表示不了「何时哪只脚着地」，其平衡门 BCK 隐含固定接触集。引入混合候选 ξ=(σ,P,x)：接触时序 σ、落足点 P、体/肢轨迹 x。平衡门升级为混合证书：每个模式 q 一段 ZMP/质心动量 barrier B_q，在模式切换处用**守卫证书**（冲量锥/摩擦锥/捕获点连续）拼接，并强制最小停留时间 τ_dwell 以排除 Zeno 颤振。关键纪律：接触可行性并入 physics 门、混合平衡并入 BCK，**不新增第八门**。提议器 HFGP 把流匹配扩成混合生成：落足点连续（条件流匹配）、接触时序离散（相位策略/掩码扩散），以地形与检索到的步态记忆为条件。

3. **合流：消融 × 步态 = 门的作用随模式而变，故消融必须分层**。单模式机械臂里各门近乎独立；一旦接触切换，门之间产生组合交互——某个在支撑相「休眠」的门，可能恰是触地瞬间唯一防摔的东西。因此唯一贡献要按模式分解 U_g = ∪_q (U_g|q)，安全移除必须在**所有可达模式**上成立，而非平均意义上成立。步态让消融从可选项变成必需品。

**关键洞见**：v5 回答「提议是生成式时如何守住证书边界」；v6 回答「执行是混合式时如何守住，且如何**证明**每道门仍在挣它的位置」。七门不变；v6 新增的是一个只做「可证冗余移除」的元算子（执行集不变）与一套混合证书（扩域）。v6 不是更大空间里的简单子集，而是**保守扩展**：限制到单模式子空间 Σ0（σ 恒定、P 固定）时精确等于 v5（定理 12），故 Exec_v6|Σ0 = Exec_v5 ⊆ Exec_v4 ⊆ … 在机械臂子域上仍成立；在腿足新子域上则是一张全新的认证集。

**形式化目标（增量）**：
1. 混合候选 ξ=(σ,P,x)，σ 为分段常值接触模式序列，切换时刻 {t_k}，停留约束 t_{k+1}−t_k ≥ τ_dwell。
2. HCGK：逐模式 barrier B_q + 切换守卫 G_{q→q'}；定理 9（局部证书沿守卫拼接为全局证书）。
3. CAAK：U_g、可证冗余、安全消融 A_safe（Exec 不变）、敏感度 ρ_g、见证集 W_g；定理 10（安全消融不变性）、定理 11（ρ_g 博弈检测，统计界）。
4. HFGP：离散接触时序 + 连续落足点混合生成；地形/步态记忆条件化。
5. 保守扩展：定理 12（Exec_v6|Σ0 = Exec_v5），保证版本链在旧子域不退化为膨胀。
6. ECS_v6 = ECS_v5 · η_gait（η_gait 为步态质量软因子：切换边际、停留裕度、能耗，∈[0,1]）。

**本轮最大风险**：**消融证明本身不可靠**——安全消融把「移除门」的正当性押在一个**证明器 + 有界域模型 D** 上；若蕴含/空集判定器不可靠，或 D 漏掉了真实工况（地形、负载、接触假设），「可证冗余」就变成**静默放大执行集**，而且与「加门」不同，门的移除无法被单调收缩自动纠正，整个信任边界最终压在验证最少的那个组件上。

### IP-498 CAAK：证书级消融与归因（离线发版；不可判定即保留）

```python
@dataclass
class CertifiedAblationAttributionKernel:
    """CAAK：把消融从『平均指标』升级为『可证谓词运算』。
    红线：只在域 D 上做可证冗余移除；证明不可靠/超时 → fail-closed 保留门。"""
    verifier: Any          # 可靠的蕴含/空集判定器（SMT / barrier / 区间算术）
    domain: Any            # D：声明工况域（地形/负载/接触/参数包络，版本化）

    def unique_contribution(self, G, g) -> Region:
        return Exec(G - {g}, self.domain) - Exec(G, self.domain)   # U_g ∩ D

    def is_redundant(self, G, g) -> bool:
        # 证明 U_g ∩ D = ∅；不可判定/超时/域外 → False（保留门，fail-closed）
        return self.verifier.prove_empty(self.unique_contribution(G, g))

    def safe_ablate(self, G) -> tuple[set, AblationCert]:
        """按维护成本从高到低尝试；每次相对『当前』G2 重证（处理顺序依赖）。"""
        G2, removed = set(G), []
        for g in sorted(G, key=lambda x: -maintenance_cost(x)):
            if self.is_redundant(G2, g):
                G2.remove(g)
                removed.append((g, self._proof_of_empty(G2, g)))
        return G2, AblationCert(removed, domain=self.domain,
                                invariant='Exec(G2)∩D == Exec(G)∩D')

    def sensitivity(self, G, g, pi, n=2048) -> float:
        # ρ_g = P_{x~pi}[x ∈ U_g]；与见证集联合判 gaming（定理 11）
        return estimate_mass(pi, self.unique_contribution(G, g), n)

    def witness(self, G, g) -> list:
        # 反例见证：证明门『活着』（U_g 非空）；无见证不设门
        return self.verifier.find_counterexample(self.unique_contribution(G, g))

    def stratify(self, G, g, modes) -> dict:
        # 分层唯一贡献：U_g|q，确保安全移除在所有可达模式上成立
        return {q: self.unique_contribution(G, g, restrict=q) for q in modes}
```

### IP-499 HFGP：离散接触时序 + 连续落足点的混合生成（准入/10 Hz）

```python
@dataclass
class HybridFlowGaitProposal:
    """HFGP：混合生成。离散模式序列 + 连续落足点；生成后仍须 HCGK 认证。
    单模式调用时精确退化为 v5 的 FMPP。"""
    schedule_head: Any    # 相位策略 / 掩码扩散：p(q_{k+1} | q_k, c)
    foothold_net: Any     # 条件流匹配：落足点连续场 v_φ(P_t, t | σ, c)
    S: int = 10
    K: int = 8

    def propose(self, c, k: int = None) -> list[GaitPlan]:
        plans = []
        for _ in range(k or self.K):
            sigma = self._sample_schedule(c)                 # 离散模式序列
            P = self._sample_footholds(sigma, c)             # 流匹配 ODE
            plans.append(GaitPlan(sigma, P))
        return plans

    def _sample_footholds(self, sigma, c):
        z = randn(self.d_P)
        for s in range(self.S):
            z = z + (1.0 / self.S) * self.foothold_net(z, s / self.S, sigma, c)
        return decode_footholds(z)
```

## 4. 正确性论证（增量更新）

### 引理 45（最小停留时间 ⇒ 无 Zeno）

**陈述**：若 σ 的所有区间满足 t_{k+1}−t_k ≥ τ_dwell > 0，则区间总数 m ≤ ⌊T/τ_dwell⌋，切换有限，无 Zeno。**证明**：切换时刻严格单调、相邻间隔有正下界。∎

### 引理 46（敏感度估计集中界）

**陈述**：以 n 个 i.i.d. 样本估计 ρ_g，Hoeffding：P(|ρ̂_g−ρ_g| ≥ ε) ≤ 2exp(−2nε²)；n=2048、ε=0.03 时 < 1e-3。∎

### 定理 9（混合证书拼接）

**陈述**：若 ξ 每模式区间 B_{q_k} 成立、每切换守卫 G_{q_k→q_{k+1}} 成立且停留 ≥ τ_dwell，则 ξ 全局平衡安全。**证明**：对模式序列归纳，区间内由 B_q，跨区间由守卫，有限切换由引理 45。∎ **诚实边界**：守卫谓词为模型近似，真实冲量瞬态误差不在界内。

### 定理 10（安全消融不变性）

**陈述**：A_safe 仅移除 U_g∩D=∅ 的门并对剩余门重证，则对 ξ∈D，ξ∈Exec(A_safe(G)) ⇔ ξ∈Exec(G)，执行集逐点不变。**证明**：U_g∩D=∅ ⇒「通过 G\{g}」与「通过 G」在 D 上等价；对移除序列归纳。∎ **诚实边界**：仅 D 上成立；D 外可能放大。

### 定理 11（门博弈检测，统计界）

**陈述**：若 ρ_g→0、语义失败未降、W_g∩D≠∅，红队以比例 α 采样 U_g，则 n 次检出概率 ≥ 1−(1−α)^n；配合引理 46 可在语义失败显著上升前约 3 个固化周期报警。**证明**：几何分布 + 前置条件。∎ **诚实边界**：检测概率界，非「无博弈」证明。

### 定理 12（保守扩展）

**陈述**：限制到 Σ0（σ 恒定、P 固定），HCGK→BCK、HFGP→FMPP、空消融为恒等，故 Exec_v6|Σ0 = Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29。**证明**：逐模块代入退化参数即得。∎

### 定理 v6（总装：混合扩展 + 可证消融，信任链保持）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 守卫谓词模型误差 ≤ ε_guard、(B9) 消融验证器在 D 上可靠 下：
(i) 混合平衡安全：定理 9（模型级）；
(ii) 安全消融：A_safe 在 D 上逐点保持 Exec（定理 10），可减少门数而不放大；
(iii) 版本链：Exec_v6|Σ0 = Exec_v5 ⊆ … ⊆ Exec_v29（定理 12）；
(iv) 博弈可检测：定理 11 的统计界；
(v) 无见证不设门：任何保留门 g 满足 W_g∩D≠∅ 或不可判定（fail-closed）。
**证明**：(i)~(iii) 由定理 9/10/12；(iv) 由定理 11；(v) 由 A_safe 的定义。∎

**诚实声明**：(B9) 把「证明器 + 域模型 D」变成新的可信基（TCB）；D 不完备或验证器不可靠时，(ii) 失效且**不可被单调收缩纠正**（移除不可逆）。混合守卫的冲量瞬态、Zeno 之外的滑移/颤振、以及长时域接触时序组合，均只得到模型级或统计级保证，非物理真值。

### 5.3 诚实边界

- 可证冗余只在声明的 D 上成立；复杂/未见地形默认**不可消融**（保留门），因此维护成本下降幅度随 D 覆盖度波动。
- 最小门基**不唯一**、消融**顺序依赖**（定理 10 只保证不变性，不保证唯一性）；本轮报告一个基与依赖图，不宣称最优。
- 混合守卫与冲量瞬态只到模型级保证；实机冲击、柔性接触、长时域组合未验证。

## 7. 本轮最大风险（最终确认）

**一句话**：**消融证明本身不可靠**——安全消融把「移除门」的正当性押在一个证明器 + 有界域模型 D 上；若蕴含/空集判定器不可靠，或 D 漏掉真实工况（地形、负载、接触假设），「可证冗余」就变成静默放大执行集，而且与「加门」不同，门的移除无法被单调收缩自动纠正，整个信任边界最终压在验证最少的那个组件上。
