## 1. 直觉与动机（两个灵感的碰撞）

**灵感 1（碰撞检测 → 没有力传感时，碰撞不是传感器，而是「计划与现实不符」的可计算残差）**

直觉：真机桌面操作里，分数几乎都丢在接触瞬间——抓滑、插偏、倒洒、叠塌。但这套接口没有任何力/触觉通道（F8），我们永远拿不到「碰撞」这个标签。反直觉的解法不是去补传感器，而是把碰撞**重新定义**成「预测误差」：前向模型预测「我这样动，世界应该这样变」，一旦实际观测偏离预测，残差尖峰就是异常接触的可观测影子。它只需要 RGB + 本体感觉 + 动作历史，全部现成；而接触物理跨任务共享，官方 110 任务语料正好是训练这个「惊讶检测器」的原料。

严谨地说：碰撞的物理定义是接触冲量非零；在无力传感时只能定义**操作化碰撞** `c_t = 1[r_t > θ_t]`，其中 `r_t` 是前向预测残差（视觉光流残差 + 末端/夹爪运动学不一致 + 物体相对滑移）。它不等同于真实接触力，但对「哪里会丢分」应是高召回的。这个「残差=碰撞」的转译，是本轮全部方案的地基。

**灵感 2（数据规模 → 瓶颈不是「多少条」，而是「覆盖了多少种接触」）**

直觉：官方 32,000 条 / 169 小时（F20），相对评测约 320 条是约 100×；再堆同分布数据，边际收益极低。真正稀缺的是**接触状态的多样性**：同一个杯子，正抓/侧抓/高位抓/被干扰物挤住时的接触构型，才是未见物品轴与干扰轴上的得分点。于是「数据规模」应被拆成一个向量而不是一个标量：`D = (N 条数, T 帧数, N_eff 有效样本数, Cov 接触覆盖, Q 质量, Div 多样性)`。**规模律的自变量应是 (N_eff, Cov)，不是 TB。** 第 2 轮把 110 语料按「语义孪生」入训，本质上是在用语义近似接触覆盖；本轮把它换成可计算的接触分布距离。

**两者统一（本轮核心命题）**：碰撞检测是数据价值的**测量仪**，数据规模是**预算**。用碰撞事件给每条/每段数据定价，把有限的数据与算力预算花在「碰撞前沿」——即当前策略最容易发生异常接触、且评测分布最可能出现的接触构型上。反直觉点：**不是「多给数据」提升泛化，而是「碰撞覆盖」提升泛化；数据规模只是覆盖的载体。**

## 0. 本轮一句话

**把「碰撞检测」当作数据价值的测量仪，把「数据规模」从条数重定义为接触覆盖；用碰撞前沿给数据定价，用标度律决定何时停止加数据。**

## 1. 严谨定义（先定义，再谈方案）

### 1.1 操作化碰撞（没有力传感时的可观测替代）

- 物理定义：碰撞 = 接触冲量非零。本赛题观测无任何力/触觉通道（F8），该量**不可直接观测**。
- 操作化定义：

  `r_t = || φ(o_{t-k:t}, a_{t-k:t}) - o_t ||_Σ`，`c_t = 1[r_t > θ_t]`

  其中 `φ` 是前向/逆动力学预测器，`r_t` 是「计划与现实不符」的残差。`θ_t` 按任务阶段自适应（接近段阈值高、接触段阈值低）。
- 残差分解（三个互补通道，全部来自现成观测）：

  `r_t = w_v·r_vis + w_k·r_kin + w_s·r_slip`

  - `r_vis`：光流残差（由动作预测的相机/物体流 vs 实际流，接触区加权）；
  - `r_kin`：夹爪/末端指令位移 vs 实际位移不一致（stall、异常减速、回弹）；
  - `r_slip`：物体关键点相对夹爪的滑移量。
- 标签来源：仿真精确接触标签（Isaac Lab，F14）预训练 + 少量真机人工标注校准；**不得**把该推断量用于安全关键停机，只用于数据调度与软触发。
- 关键区别：这是「异常接触/惊讶」而非力；它测量的是**策略与物理的失配**，恰好是丢分的近因。

### 1.2 碰撞覆盖（数据规模的真实自变量）

- 接触状态：`z = (物体类别, 相对位姿, 夹爪开度, 接近方向, 接触类型)`。
- 编码：`e(z)` 用关键点 + 几何描述词，或 DINOv2 patch 特征池化（与 I9 共用嵌入基础设施）。
- 覆盖度（对任务 τ）：

  `Cov(D; τ) = (1/M) Σ_i 1[ min_{d∈D} ||e(z_i) - e(d)|| < ε ]`，`z_i ~ 留出接触流形 p_τ`

  即「目标任务接触流形的 ε-覆盖比例」。无参考近似可用 k-center / Vendi score。
- 为什么不用条数：同样 10k 条，全部是标称正抓，与覆盖 6 种接触构型，对未见物品轴的价值差一个数量级。

### 1.3 数据规模向量与有效样本数

- `D = (N, T, N_eff, Cov, Q, Div)`：条数、帧数、有效样本数、接触覆盖、质量、多样性。
- `N_eff = (Σ_i w_i)^2 / Σ_i w_i^2`（加权采样的有效样本数；官方 loader 的样本数比例混采会使远任务主导 `N_eff`，见 F11）。
- **规模律的自变量是 `(N_eff, Cov)`，不是 TB。** 这是本轮对「数据规模」的核心重定义。

### 1.4 碰撞前沿标度律（可检验假设 H-CF）

`S_τ(N_eff, Cov) = S∞_τ · (1 - e^{-κ_τ·Cov}) · (1 - e^{-λ·N_eff}) - μ·Mismatch(src, τ)`

- 直觉推导：行为克隆无法从「零支撑的接触模式」外推出正确接触动力学；若某评测接触模式在训练集中无 ε-邻域支撑，该模式上的误差不可约。因此**覆盖率决定分数上限/渐近项**，样本量决定逼近速度。
- 可检验推论：
  1. 低覆盖区 `∂S/∂Cov ≫ ∂S/∂N`；
  2. `Cov → 1` 后 S 对 N 饱和；
  3. 负迁移由 `Mismatch`（碰撞剖面距离）预测，可在训练前定价。
- 拟合方式：L0 用不同 `(N_eff, Cov)` 子集训练小模型，2D 网格 + 非线性最小二乘；参数 `(S∞, κ, λ, μ)` 按任务族分层。

## 2. 创新点详述

### I10 碰撞前沿数据缩放引擎（新） ★★★★★

- **动机**：无传感 + 32k/169h（F20）+ 评测约 320 条。瓶颈不是条数，而是接触覆盖；需要一台「数据定价器」把有限预算花在会丢分的接触构型上，并给出停止规则。
- **与现有方案差异**：
  - 第 2 轮 I2 按「语义孪生表 + 手工质量分 + 手工权重」；本轮把孪生相似度换成**可计算的接触分布距离（碰撞剖面）**，把负迁移从「事后家族消融」提前到「事前剔除」。
  - 直接 SFT/均匀混训按样本数比例；本引擎按「边际覆盖增益 / 成本」分配，并对接触剖面相斥的数据直接剔除。
  - 与 I1 的分工：I1 在已有数据上造分布；I10 决定「哪些数据值得下/造/合成」。
- **四组件**：
  1. **碰撞事件检测器**：仿真精确标签预训练 + 真机残差校准；输出每帧 `c_t` 与置信度。
  2. **碰撞覆盖度量**：接触状态编码 + ε-覆盖 / Vendi；每任务一条覆盖曲线 `Cov(N)`。
  3. **碰撞剖面相似度**：源任务与目标任务的接触状态分布距离（MMD / 分位数 Wasserstein）；构建 110×32 剖面矩阵，替代手工 `TWINS`。
  4. **预算分配器 + 停止规则**：在固定预算 B 下最大化 `Σ ΔCov/成本`，带 `Mismatch` 惩罚；当预测边际增益 < 测量噪声或 `ΔCov < ε` 时停止下载/生成。
- **技术可行性**：中-高。检测器是轻量残差头（推理 <5ms，可只用于离线数据调度）；覆盖与剖面矩阵全离线；主要成本是 200–500 段真机碰撞标注。前沿数据生成可复用官方 Isaac Lab（F14）与 WMA-0 仿真模式（F15）。
- **所需资源**：1×24GB GPU 做检测器/嵌入；真机标注 200–500 段（约 3–5 人日）；离线计算 1 GPU 日/全量剖面。
- **落地步骤**：①检测器原型（仿真标签 + 200 段真机标定）；②覆盖度量与 `Cov(N)` 曲线；③110×32 碰撞剖面矩阵；④L0 标度律拟合；⑤预算分配器 + 停止规则；⑥前沿主动生成（仿真优先）。
- **风险**：检测器噪声（见 §4 的 σ 敏感性）；高维接触空间覆盖估计的维度灾难；前沿生成可能产生物理不可行/越界示教（用考纲卡与得分点可行性过滤）。

### I1 v3 考纲校准五轴增广引擎 ★★★★★（深化）

- 保留 v2 的考纲卡与五轴；**增广剂量不再人工定三档**，而是由 I10 的覆盖曲线定档：增大某轴剂量直到 `ΔCov/成本` 饱和或碰撞率越界，取饱和点前一档。这样增广强度与「接触覆盖」直接挂钩，而不是拍脑袋。
- 风险不变：考纲卡偏差；位置重拼接物理不可行（>5% 不可行动作则降级）。

### I2 v3 数据引擎 2.0 ★★★★★（深化）

- **手工 `TWINS` → 碰撞剖面矩阵**：`w_src(τ) = exp(-d_profile(src, τ)^2 / 2σ^2)`，`d_profile` 为接触状态分布距离；相斥（距离过大）直接置 0，而非 0.05 低权重保留。
- **采样权重 = 覆盖边际增益**：`w ∝ ΔCov(src→τ)/cost(src)`，叠加质量权重 `q`；用 `N_eff` 监控远任务是否仍主导。
- **停止规则**：当 I10 标度律预测的边际分数增益低于测量噪声（约 1–2 分）时，停止新增数据/下载，把预算转 I5 合成或 I6 部署。
- 风险：剖面距离估计误差导致误剔除；先以「只剔除 top-10% 最远源」的保守策略起步。

### I3 v3 接触任务族关键点视觉伺服回退 ★★★★（深化）

- 碰撞残差 `r_t` 作为**接触相位触发/确认**：接近段用关键点伺服，`r_t` 尖峰确认进入接触段，双门控（关键点置信度 + 残差）降低误触发。
- 碰撞残差也是「抓滑/插偏」的早期告警，可提前进入恢复（与 I5 联动），不必等到大偏差。
- 合规边界不变：混合推理需组委会书面确认，I3' 降级预案保留。

### I4 v3 人手干预感知门控 ★★★★（深化）

- 碰撞/近距检测兼任**人手安全闸**：视觉近距（人手/人体关键点）+ 残差尖峰 → 降速/停持/让位（PR3）。这条直接对齐「人手干预」计分轴，且不需要额外传感器。
- chunk 自适应参数不变（干预态 4–6 步、稳定态 8–16 步，参照 F12）。

### I5 v3 非标称示教合成 + 得分点对齐恢复 ★★★★（深化）

- **合成目标 = 碰撞前沿**：扰动重放/跨段缝合/世界模型续写，优先合成「当前覆盖最低、且碰撞残差最高」的接触构型，而不是均匀随机扰动。
- **自动标注**：碰撞事件 `c_t` + 官方得分点里程碑共同做质量门禁；只有「发生偏离 → 碰撞/异常 → 达成下一得分点」的段才保留为恢复示教。
- 风险：合成分布与真实偏离失配（用考纲卡约束扰动幅度）；里程碑检测器误差（置信门控 + 抽检 5%）。

### I6 v3 确定性低延迟部署服务 ★★★★（维持）

- 维持 v1.1 六要素；碰撞残差头若上在线，走轻量模型并只做软触发，预算 <5ms；p99 目标仍 <40ms（15Hz 参照，F12）。
- 若在线残差头挤压延迟，则退化为**纯离线数据调度**（不参与推理），主链零风险。

### I7 世界模型测试时前瞻 ★★ → **裁撤（推理路径）**

- 理由：15Hz/66ms 预算下 O(1–2) 次 rollout 的前瞻收益/延迟比不划算，且 I10 提供了更便宜的数据侧杠杆。
- 资产转用：WMA-0 仿真模式（F15）转为 I10 的**碰撞前沿数据生成器**；裁撤不等于废弃。

### I8 v3 评测运营闭环 + 分级消融注册表 ★★★★（深化）

- L0 新增三类实验：**检测器标定**（L0-A）、**覆盖-分数标度律拟合**（L0-B）、**碰撞剖面迁移预测**（L0-C，预测符号而非仅大小）。
- 注册表新增字段：`collision_profile_distance`、`Cov_before/after`、`predicted_marginal_gain`、`realized_gain`；滚动校准「预测增益 vs 真机增益」，并检验 `Cov` 代理是否优于 `N` 代理。
- 风险不变：离线代理与真机相关建立慢；先用 3–4 个已知结果回填。

### I9 v3 reset 期检索类比迁移 ★★★★（深化）

- 检索键从「物体外观嵌入」升级为「物体嵌入 + 碰撞剖面」：该物体在 110 语料中的常见接触构型（接近高度/方向、夹爪开度、接触类型）作为先验。
- 先验内容加入「预期碰撞阶段与风险接触点」，episode 内用于软门控（例如在预期接触段降低 chunk 长度、提高 I3 触发灵敏度）。
- 风险不变：误检索；先验仅软偏置 + 距离阈值门控；合规性书面确认。

## 3. 关键伪代码

### 3.1 操作化碰撞检测器（I10-1）

```python
class CollisionResidualDetector:
    # 训练：仿真精确接触标签 + 真机少量标注；推理只读现有观测，无需新传感器
    def __init__(self, forward_model, tau_by_phase):
        self.fwd = forward_model          # 预测下一帧/下一状态
        self.tau = tau_by_phase           # {approach: 高阈值, contact: 低阈值}
    def residual(self, obs_hist, act_hist):
        pred = self.fwd(obs_hist, act_hist)            # 期望观测
        r_vis = flow_residual(obs_hist[-2:], pred)     # 光流残差
        r_kin = kinematic_stall(obs_hist, act_hist)    # 指令 vs 实际位移
        r_slip = keypoint_slip(obs_hist[-3:])          # 物体相对滑移
        return 0.5*r_vis + 0.3*r_kin + 0.2*r_slip
    def __call__(self, obs_hist, act_hist, phase):
        r = self.residual(obs_hist, act_hist)
        return (r > self.tau[phase]), r             # c_t, 置信度
```

### 3.2 覆盖度量与标度律拟合（I10-2 + I8 L0-B）

```python
def contact_coverage(selected_states, target_heldout, enc, eps=0.12):
    Zs = enc(selected_states); Zt = enc(target_heldout)
    d, _ = cKDTree(Zs).query(Zt, k=1)
    return float((d < eps).mean())                   # Cov(D; τ)

def fit_scaling_law(runs):
    # runs: [(N_eff, Cov, score)]，来自 L0 子集训练
    def f(X, Sinf, kappa, lam, mu):
        N, Cov, Mismatch = X
        return Sinf*(1-np.exp(-kappa*Cov))*(1-np.exp(-lam*N)) - mu*Mismatch
    p, _ = least_squares(residuals, runs, model=f, p0=[100, 5, 1e-4, 10])
    return p      # 用 ∂S/∂Cov 与 ∂S/∂N 决定预算去向
```

### 3.3 碰撞剖面孪生 + 预算分配（I10-3/4，替代 I2 手工表）

```python
def collision_profile_distance(src_states, tgt_states, enc):
    Zs, Zt = enc(src_states), enc(tgt_states)
    return mmd_rbf(Zs, Zt)                 # 或分位数 Wasserstein

def allocate_budget(candidates, target, B, cost):
    # candidates: 110 源任务；target: 32 考题之一
    scores = {}
    for src in candidates:
        d = collision_profile_distance(src.contact_states, target.contact_states, enc)
        gain = predicted_marginal_coverage(src, target)      # 用覆盖曲线估计
        scores[src] = 0.0 if d > D_MAX else gain / cost[src] # PR6：相斥直接剔除
    chosen, spent = [], 0
    for src in sorted(scores, key=scores.get, reverse=True):
        if scores[src] <= 0 or spent >= B: break
        k = min(src.remaining_eps, int((B - spent) / cost[src]))
        chosen.append((src, k)); spent += k * cost[src]
        if predicted_marginal_gain(chosen) < NOISE_FLOOR: break   # 停止规则
    return chosen
```

### 3.4 碰撞前沿主动生成（I10-4，仿真优先）

```python
def frontier_generate(policy, sim, syllabus_card, target_cover, n):
    # 在仿真里主动寻找「低覆盖 × 高碰撞残差 × 物理可行」的接触构型
    pool = []
    for _ in range(n):
        scene = sim.sample_scene(syllabus_card)          # 考纲约束内
        roll = sim.rollout(policy, scene)
        for t, (z, c) in enumerate(zip(roll.contact_states, roll.collisions)):
            if c and not covered(target_cover, z):       # 碰撞且未覆盖
                if sim.is_physically_valid(roll, t):     # 过滤穿模/越界
                    pool.append((scene, t))
    return dedup_by_contact_state(pool)                  # 只保留接触状态新颖的段
```

## 4. 玩具数值验证（合成接触流形；**非真机、非官方数据**）

> 目的：只验证「覆盖度量 + 标度律 + 剖面噪声」这条管线在数学上成立，不作为赛事结论。设置：3D 接触状态空间，32 个目标任务（各 6 个接触模式），110 个源任务（32 个精确孪生、30 个部分孪生、48 个远任务），源数据量重尾分布（模拟 110 语料体量不均）。6 个随机种子平均。

**预算匹配对比（B=400 条/任务）**

| 策略 | 平均分 | p10 | 说明 |
|---|---|---|---|
| 均匀/样本数比例（官方默认混采） | 40.6 | — | 远任务体量稀释覆盖 |
| 手工语义孪生权重 | 62.3 | — | 比均匀好，但相似度靠猜 |
| 碰撞剖面权重（本方案） | **97.7** | — | 接近 oracle 98.2 |

**标度律对比（平均分，6 seeds）**

| N | 均匀 | 手工孪生 | 碰撞剖面 |
|---|---|---|---|
| 100 | 19.3 | 33.3 | **95.0** |
| 400 | 40.6 | 62.3 | **97.7** |
| 1600 | 77.6 | 89.2 | **98.1** |
| 6400 | 92.4 | 97.5 | **98.2** |
| 12800 | 96.3 | 98.0 | **98.2** |

读法：碰撞剖面在 N=400 已达到均匀采样 N=12800 以上的水平（97.7 vs 96.3），**约 30× 样本效率**；且曲线更早进入平台。这支持 H-CF 的推论 1（低覆盖区覆盖增益远大于样本增益）。

**剖面误差敏感性（B=400，5 seeds）**——对应 P10 风险：

| 剖面距离噪声 σ | 平均分 |
|---|---|
| 0（oracle 剖面） | 98.15 |
| 0.10 | 98.13 |
| 0.25 | 97.66 |
| 0.50 | 88.15 |
| 均匀采样（对照） | 71.91 |

读法：检测/剖面误差在 σ≲0.25 时收益基本保留；σ≈0.5 时增益腰斩。这给出一个可操作的验收线：**碰撞剖面距离的相对误差需控制在约 0.25 个接触状态尺度内**，否则先做检测器标定、不要放量。

**玩具的局限（必须承认）**：没有建模「主动负迁移」（源任务教错接触动力学），只建模了预算稀释；真实负迁移需 L0-C 用 110×32 剖面矩阵与 I2 家族消融去验证符号。

## 5. 实验设计（分级消融 v3）

|---|---|---|---|

## 6. 数据规模预算与停止规则（把 F20 用起来）

- 硬底数：32 任务 / 32,000 eps / 169 h（F20）；评测约 320 eps（N≈10），训练/评测 ≈100×。**结论：绝对条数不是瓶颈，覆盖才是。**
- 旧计划（v1.1）：孪生子集 1–2TB + 32 任务 2TB + 增广 2TB。本轮改为**按边际覆盖增益分批下载**：
  1. 先只下 32 任务 + 剖面距离 top-10 孪生源（约 0.3–0.5TB），跑 L0-B；
  2. 拟合 `S(N_eff, Cov)`，若 `∂S/∂Cov` 仍显著且边际增益 > 1–2 分/百 GB，再扩到 top-30；
  3. 若 `ΔCov < ε` 或预测增益 < 噪声，**停止下载**，预算转 I5 合成/I6 部署。
- 停止规则（三选一触发）：①覆盖饱和 `Cov > 0.9·Cov_max`；②标度律边际 < 1 分/百 GB；③新源任务剖面距离 > `D_MAX`（相斥，直接剔除）。
- 资源不变：训练 1×24GB 起步（F11）、8×A100 上限；检测器/嵌入 1×GPU 日；真机标注 3–5 人日。
