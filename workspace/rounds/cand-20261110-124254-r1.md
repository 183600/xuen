# 第 44 轮（本轮灵感循环第 1 轮） · Sim-Cover × Distill-Cert：把「仿真训练覆盖」与「模型蒸馏保真」纳入端到端证书预算（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但它仍压着两个未审计的假设：**(H3) 仿真训练被当作「数据越多越可信」**——sim-to-real 分布偏移只靠经验回归，证书在仿真里学、在真实里直接用；**(H4) 模型蒸馏被当作「精度掉一点点的压缩」**——从不证明学生的证书边际在安全尾部仍然保持。本轮灵感词「仿真训练」「模型蒸馏」精确命中这两个假设：**仿真训练**迫使我们把 sim 数据从训练燃料提升为**可计价的证书收入**——只有密度比有界、支撑集覆盖的关键区域才能「赚到」证书预算；**模型蒸馏**迫使我们把学生模型从精度复制品提升为**证书搬运工**——学生只能收缩教师的认证域，并必须支付显式的边际税 δ。二者耦合处是本轮真正的新问题：**覆盖收入与蒸馏支出必须记在同一本账上**，否则会在「仿真没去过的关键尾部」同时出现「无覆盖」与「学生最自信」的静默失效。

## 0. 直觉与动机

**灵感 1（仿真训练 = 铸币，不是许愿）**：直觉上，仿真里跑一百万次不等于真实世界安全一百万次；只有那些真实世界也会出现、且仿真也采样到的状态，才构成证据。因此把仿真训练产出定义为**加权覆盖证书**：用密度比 w = dP_real/dP_sim 给每个仿真样本「计价」，只有 w 有界、关键单元被覆盖的部分才能进入共形校准；仿真从未采样的真实关键状态构成**不可约覆盖债务 β**。一句话：**仿真不是真理，仿真是有汇率的证据**。

**灵感 2（模型蒸馏 = 兑换，必须缴税）**：直觉上，学生模仿教师，平均精度可以持平甚至更高，但在教师刚好卡在安全阈值上的稀有状态，学生会把边界「抹平」。因此把蒸馏定义为**证书搬运**：教师认证域 R_T(θ+δ) 可被学生继承为 R_S(θ)，代价是 δ 的**边际税**；学生永远不能凭蒸馏扩张教师的认证域。关键设计选择是**只蒸馏小监控器，不蒸馏大策略**：策略只提议，证书监控器才承担安全证明，而小电路的失真界可算、非空洞。一句话：**蒸馏只收缩，保真需付费**。

**灵感 3（耦合 = 一本账，三条支出）**：仿真覆盖给出收入 α_cov，蒸馏给出支出 α_d，v20 的人格/并发/租约给出支出 α_run；仿真未覆盖的真实质量 β 则是**永远还不上的坏账**。端到端安全不是三个模块各自「大概没问题」，而是**证书预算会计**：P_real(safe) ≥ 1 − (β + α_cov + α_d + α_run + α_neg + …)，只要账不平就不能部署。覆盖债务驱动的主动仿真训练负责「开源」，证书保持蒸馏负责「节流」，账本负责在延迟、算力、覆盖之间做 Pareto 分配。四层架构由 v8 升级为 v9：在 PCE/CCR/ICV 之外加入 SCC（覆盖认证器）、CDL（证书保持蒸馏器）、CBL（证书预算账本）。

**与 v20 的统一**：v20 的原则是「收缩免费、扩张持证」；v21 补上它的数据/模型侧对偶——「**覆盖是收入、蒸馏是税收、运行时是支出、支撑集失配是坏账**」。二者共同构成一个可审计的证书经济学：性能模块（策略/VLM）可以离线无证书地训练与蒸馏，安全监控模块则必须在线持证。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（加权仿真覆盖证书）**：设真实分布 P_real、仿真分布 P_sim，关键状态集 S_crit。若 P_real 在 S_crit 上关于 P_sim 绝对连续，密度比 w(x)=dP_real/dP_sim(x)，并设 W_max 为其（截断）上界。对任意非一致性分数 s(x)，用仿真校准集与权重 w 取加权 (1−α_cov) 分位数 q，则在加权可交换性与 w≤W_max 下，P_real(s(X)≤q | X∈S_crit∩supp(P_sim)) ≥ 1−α_cov−δ_w，其中 δ_w 由权重估计误差、权重截断偏差与有效样本量 n_eff≈n/(1+W_max) 给出。**覆盖证书** C_sim=(q, W_max, n_eff, β)，**β=P_real(S_crit∖supp(P_sim))** 为不可约覆盖债务。**总覆盖失效界**：未覆盖质量无任何保证，故 P_real(s(X)≤q) ≥ (1−β)(1−α_cov−δ_w)，等价地失效概率 ≤ β+α_cov+δ_w。**硬前提**：若 β 或 W_max 估计越界，纯仿真认证直接判 INFEASIBLE，不得用 clipped 权重自欺。

**定义 45（证书保持蒸馏）**：教师监控器 t 的边际 m_T(x)，学生 s 的边际 m_S(x)，失真 Δ(x)=|m_T(x)−m_S(x)|。在加权校准集上、**按「覆盖单元 × 教师边际分箱」做 Mondrian 共形**，取 Δ 的 (1−α_d) 分位 δ_d；对 K 个证书单元用 Bonferroni 取 α_d/K，避免「只在教师边际高的子集上校准」的选择偏差。**蒸馏证书** C_d=(h_T, e, δ_d, α_d, D_cov, K)，h_T 为教师版本哈希，e 为蒸馏轮次，D_cov 为覆盖证书声明的有效域。**定理（边际税）**：在事件 {Δ≤δ_d} 与教师证书有效事件的交上，m_S(x) ≥ m_T(x) − δ_d；因此 **R_T(θ+δ_d) ⊆ R_S(θ)**，学生必须把阈值抬高 δ_d，**只能收缩不能扩张**。**推论**：学生若想在原阈值 θ 下保留原认证域，必须 δ_d=0；任何蒸馏收益都以认证域收缩或阈值抬升支付。

**定义 46（端到端证书预算与联合可靠性）**：显式列出失效事件：E_β（支撑集失配，质量 β）、E_cov（覆盖校准失效，α_cov+δ_w）、E_d（蒸馏失真超界，α_d）、E_run（v20 的人格契约/并发/租约失效，α_run）、E_neg（协商失败，α_neg）。由并集界，**P_real(safe) ≥ 1 − (β + α_cov + δ_w + α_d + α_run + α_neg)**，即**证书预算账本** L=β+Σα_i。部署可行当且仅当 L≤α_budget，且 W_max≤W_bound、δ_d 可估。**分配问题**：min latency/compute s.t. L≤α_budget；覆盖与蒸馏可互换（更多 sim 覆盖可容忍更大 δ_d，从而更少的学生认证域收缩），但**不可通过调账消灭 β**。

**定义 47（覆盖债务驱动的主动仿真课程）**：对关键单元 c，定义覆盖债务 D_c = P_real(c)·[α_cov^req(c) − α_cov^actual(c)]_+ + λ_β·β(c)。采集分数 a(c)=D_c·criticality(c)·disagreement_T,S(c)，其中师生分歧在证书边界带 {x: m_T(x)∈[θ, θ+δ_d]} 上度量。主动训练在仿真中最大化 a(c) 生成场景，终止条件为 max_c D_c≤ε 或算力耗尽。**命题（诚实版）**：在平稳、可达假设下该过程使债务单调不增；不声称全局收敛，必须用 E96 实测「每仿真样本的债务下降」。

**定义 48（蒸馏租约与语义漂移失效）**：在 v20 租约 ℓ=(m,τ,λ,κ) 上增加语义维度，ℓ_d=(m,τ,λ,κ,h_T,e,D_cov,δ_d)。**有效性判据**：x∈D_cov、教师哈希与轮次匹配、OOD/密度比 w(x)≤W_max、且 m−λ(t−τ)−δ_d≥θ。任一不满足则租约失效，必须单调降级到在线教师/保守监控，禁止用学生边际放行。**注**：时间衰减管「测量陈旧」，蒸馏维度管「语义陈旧」，二者不可互相替代。

**定义 49（不可约仿真债务下界 / 负面定理）**：β=P_real(S_crit∖supp(P_sim))。任何仅依赖仿真数据的认证器，其覆盖失效概率至少为 β；蒸馏不改变支撑集，故不能降低 β。**推论**：当 β>α_budget 时，不存在任何预算分配能让学生证书 sound；唯一合法出路是扩大仿真支撑集（新场景/新传感器/新区域）或完全放弃该区域的仿真认证，改用不依赖 sim 的运行时保守策略。**这是本轮最重要的边界条件**：蒸馏只能搬运已有证据，不能生产证据。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 SIM-COVERAGE-CERTIFIER（仿真覆盖认证器 SCC）
1. **密度比计价**：域分类器/两类样本检验估 w(x)，给出 W_max 与有效样本量；对 w=∞ 或仿真空单元直接记为覆盖债务，而非硬编造权重。
2. **加权共形覆盖**：按关键单元做 Mondrian 加权共形，输出 C_sim；安全关键单元用更严 α_cov 与上尾分位。
3. **支撑集失配检测**：β 估计与置信上界；β>α_cov 时返回 INFEASIBLE，阻断「仿真认证」。
4. **覆盖债务地图**：按单元输出 D_c、W_max、n_eff，供主动课程与账本分配。

### 2.2 IP-61 CERTIFIED-DISTILLER（证书保持蒸馏器 CDL）
1. **只蒸馏监控器**：教师=浮点 CMC/守卫，学生=INT8 小监控器；策略/VLM 仍只提议，不承担证书。
2. **失真校准**：按「覆盖单元 × 教师边际分箱」加权共形估计 Δ 的 (1−α_d) 分位 δ_d；INT8 量化误差用区间算术给出解析下界，二者取 max 或相加（保守）。
3. **边际税编译**：输出学生阈值 θ+δ_d、认证域 R_T(θ+δ_d)、教师哈希与蒸馏轮次；禁止学生自行降低阈值。
4. **尾部见证挖掘**：在证书边界带与低密度尾部采样师生分歧，作为下一轮课程与 E99 对抗集。

### 2.3 IP-62 CERT-BUDGET-LEDGER（证书预算账本 CBL）
1. **统一账本**：记录 β、α_cov、δ_w、α_d、α_run、α_neg、W_max、δ_d 及其证据哈希；每次部署前做 L≤α_budget 检查。
2. **Pareto 分配**：在「多采仿真 / 多花蒸馏预算（更大 δ_d → 更小认证域）/ 提高运行时保守性」间求解延迟-覆盖-安全前沿。
3. **不可行熔断**：β>α_cov、W_max>W_bound、δ_d 不可估、L>α_budget 任一成立则拒绝部署，输出最小修复建议（扩覆盖/抬阈值/停蒸馏）。
4. **运行期审计**：租约失效、OOD、账本漂移触发单调降级；把实际失效频率回灌校准，防止账本长期漂移。

## 5. 本轮最大风险

**一句话**：加权共形只在 P_real≪P_sim 且密度比有界时成立；一旦真实部署存在仿真从未采样的关键尾部（β>0），覆盖证书与蒸馏证书会同时失效，而学生恰好在尾部最自信——因此必须把「支撑集失配 β 检测」和「尾部零容忍回退」设为红线，默认回退到在线教师/保守监控，绝不让学生在未覆盖区域放行。

# 第 44 轮产物 · 创新点清单 v21：Sim-Cover × Distill-Cert（SCC × CDL × CBL）× 端到端证书预算闭环（四层架构 v9）

> 承接第 43 轮产物 v20。本轮**增量插入** IP-60/61/62，并升级 IP-44/45/49/50/51/52/53/54/55/56/59；不推倒任何既有层级。核心是把 v20 的「仿真→检索→边缘→仿真」飞轮，升级为同时满足 **仿真覆盖可计价（β 是坏账）** 与 **蒸馏保真可审计（δ_d 是边际税）** 的端到端证书预算闭环。

## 1. 符号体系（增量：定义 44–49 符号）

## 2. 关键算法（伪代码）

### IP-60 SCC：密度比、加权共形与覆盖债务

```
def estimate_density_ratio(D_sim, D_real):
    # 域分类器/两类样本检验；输出 w 与截断标记
    w, clipped = classifier_two_sample(D_sim, D_real)
    if clipped:
        w = clip(w, 1, W_bound)          # 截断 -> 必须计 δ_w
    return w, clipped

def sim_coverage_certificate(D_sim, D_real_cal, cells, alpha_cov, delta):
    w, clipped = estimate_density_ratio(D_sim, D_real_cal)
    W_max = weighted_quantile(w, 1 - delta)          # 上界估计
    beta = real_mass([c for c in cells
                      if sim_empty(c) or w_unbounded(c)], D_real_cal)
    if beta > alpha_cov or W_max > W_bound:
        return CoverageCert(status=INFEASIBLE, beta=beta, W_max=W_max)
    for c in cells:                                   # Mondrian：按单元分层
        s = [nonconformity(x) for x in D_sim if cell(x) == c]
        q[c] = weighted_quantile(s, 1 - alpha_cov, weights=w[c])
    n_eff = len(D_sim) / (1 + W_max)
    return CoverageCert(q, W_max, n_eff, beta, status=OK)

def coverage_debt_map(D_sim, D_real, cells, alpha_cov):
    # 每个单元的债务 = 真实质量 × 覆盖缺口 + 不可约失配
    return {c: real_mass(c) * max(0, alpha_cov - coverage(c))
               + lambda_beta * beta(c) for c in cells}
```

### IP-61 CDL：证书保持蒸馏与边际税

```
def certified_distill(teacher, student_arch, cells, alpha_d, theta, epoch):
    student = train(student_arch, teacher,
                    loss=cert_margin_loss + lambda_q * quantization_loss)
    K = len(cells)
    delta = {}
    for c in cells:                       # 按「覆盖单元 × 教师边际分箱」校准
        d = [abs(teacher.margin(x) - student.margin(x))
             for x in witness[c]]
        # Bonferroni：K 个单元同时覆盖
        delta[c] = weighted_quantile(d, 1 - alpha_d / K, weights=w[c])
    delta_witness = max(delta.values())
    delta_quant = interval_bound_int8(student)     # 逐层区间算术，解析界
    delta_d = max(delta_witness, delta_quant)      # 两个上界取最保守
    theta_s = theta + delta_d                      # 边际税：只能抬阈值
    R_cert = {x: teacher.margin(x) >= theta_s}     # 学生可继承的收缩域
    return StudentCert(student, delta_d, R_cert,
                       teacher.hash, epoch, cells, theta_s)

def interval_bound_int8(monitor):
    # 对 CMC 小电路逐层传播 [lo,hi]，给出量化+舍入的最坏误差
    lo, hi = -inf, inf
    for layer in monitor.layers:
        lo, hi = layer.interval_propagate(lo, hi)
    return max(abs(lo), abs(hi))                   # 输出边际误差界
```

### IP-62 CBL：账本、分配与运行期熔断

```
def budget_check(ledger, alpha_budget):
    L = (ledger.beta + ledger.alpha_cov + ledger.delta_w
         + ledger.alpha_d + ledger.alpha_run + ledger.alpha_neg)
    if ledger.beta > ledger.alpha_cov:
        return INFEASIBLE("support mismatch: beta exceeds coverage budget")
    if ledger.W_max > W_bound:
        return INFEASIBLE("density ratio unbounded")
    if L > alpha_budget:
        return INFEASIBLE(f"budget imbalance L={L}")
    return OK(L)

def allocate_budget(alpha_budget, frontier):
    # frontier: (sim_samples, delta_d, runtime_conservatism) -> (L, latency)
    feasible = [p for p in frontier if budget_check(p.ledger, alpha_budget) == OK]
    if not feasible:
        return INFEASIBLE("no Pareto point closes the ledger")
    return argmin(feasible, key=lambda p: p.latency)   # 延迟优先，安全为约束

def runtime_guard_v9(x, cert, persona, lease, distill, ledger, t):
    if x not in distill.D_cov:                 # 语义有效域外
        return FALLBACK_TEACHER
    if OOD(x) or density_ratio(x) > distill.W_max:
        return FALLBACK_TEACHER               # 覆盖债务触发
    m = min(cert.m_lookup, lease.decayed_m(t),
            persona.cap(x), distill.student_margin(x) - distill.delta_d)
    if m < theta: return MONOTONE_DOWNGRADE
    if budget_check(ledger, alpha_budget) != OK:
        return FALLBACK_TEACHER                # 账本不平，禁止学生放行
    return ALLOW
```

### IP-51/50/54 升级：覆盖-蒸馏感知的守卫与课程

```
def car_transition_guard_v9(e, x, cert_obj, persona, lease, distill, ledger, t):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup  = cert_lookup_L0(x).m_lo[e]
    m_lease   = lease.m - lease.lam * (t - lease.tau)
    m_cap     = persona_cap[e](persona)
    m_student = distill.student_margin(x) - distill.delta_d
    if x not in distill.D_cov: return False, FALLBACK_TEACHER
    if budget_check(ledger, alpha_budget) != OK: return False, FALLBACK_TEACHER
    return min(m_lookup, m_lease, m_cap, m_student) >= theta, ALLOW

def coverage_debt_curriculum(debt_map, teacher, student, theta, delta_d,
                             sim_budget):
    for c in debt_map:
        band = {x in c: teacher.margin(x) in [theta, theta + delta_d]}
        a[c] = debt_map[c] * criticality(c) * disagreement(teacher, student, band)
    scenarios = sim_generate(argmax_k(a, sim_budget))
    return scenarios            # 回灌 SCV/ICV，重颁覆盖与蒸馏证书

def distill_tail_audit(teacher, student, low_density_cells, alpha_tail):
    # 尾部零容忍：低密度单元的失真必须单独校准，不能用全局分位掩盖
    return {c: weighted_quantile(
                [abs(teacher.margin(x) - student.margin(x))
                 for x in witness[c]],
                1 - alpha_tail, weights=w[c])
            for c in low_density_cells}
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 支撑集失配 β>0：仿真从未采样的真实关键尾部无任何保证，且蒸馏无法生产证据 | 极高 | E95/E99 红线；β 置信上界检测；β>α_cov 直接 INFEASIBLE；默认在线教师/保守回退 |
| 密度比估计错误或权重截断，导致加权共形覆盖名义达标、实际失效 | 高 | 两类样本检验 + 敏感性分析；W_max 保守上界；截断偏差 δ_w 显式入账；拒绝无界比区域 |
| 蒸馏尾部塌陷：全局/分位 δ_d 掩盖低密度单元，学生恰在安全边界最自信 | 极高 | 按单元×边际分箱 Mondrian；尾部单独校准；E99 对抗挖掘；尾部零容忍 + OOD 熔断 |
| 账本并集界过松，或失效事件不独立导致 L 低估 | 中-高 | 显式事件划分；保守并集界；实际失效频率回灌；L 校准误差 <20% 纳入验收 |

| 蒸馏对象误选大策略，导致失真界空洞、δ_d 不可用 | 中 | 只对 CMC 小监控器发证；策略仅提议；大模型失真只做经验评估，不入账 |
| INT8 量化与蒸馏误差叠加被低估 | 中 | 逐层区间算术 + 实测 δ_d 取 max；部署前全量量化回归；误差预算纳入 E97 |
| 主动课程使用同一批数据做训练与校准，破坏可交换性 | 中 | 训练/校准/见证三集分离；交叉拟合；课程只改仿真分布，校准集独立重采 |

## 6. 本轮最大风险

**一句话**：加权共形只在 P_real≪P_sim 且密度比有界时成立；一旦真实部署存在仿真从未采样的关键尾部（β>0），覆盖证书与蒸馏证书会同时失效，而学生恰好在尾部最自信——因此必须把「支撑集失配 β 检测」和「尾部零容忍回退」设为红线，默认回退到在线教师/保守监控，绝不让学生在未覆盖区域放行。
