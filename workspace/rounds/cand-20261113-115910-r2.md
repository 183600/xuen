## 0. 直觉与动机

**灵感 1（力矩传感 → 不可伪造的物理通道）**
直觉：视觉可以被贴纸、镜面、透明物、对抗纹理欺骗；语言模型可以被提示注入劫持；情绪可以被假笑伪造。但只要机器人真的碰到了东西，关节就必须输出（或承受）对应的力矩。**力是做了功的账本，伪造它需要真的做功。** 因此力矩残差天然是一个「物理水印」：它不依赖语义，也不容易被远端攻击者重放。

**灵感 2（三维感知 → 接触的支撑先验）**
直觉：仅凭力矩反演接触是严重欠定的——n 个关节只能给 n 个方程，而一个点接触就有 3 个力分量和 3 个位置自由度。三维感知提供的不是「力」，而是**支撑（support）与自由空间（free space）**：接触点必须落在可见物体表面附近；机器人本体不能穿透自由空间。把这两个约束加进去，反演就从「任意分布力」收缩到「表面上的稀疏接触」。

**灵感 3（力-形互证 → 零空间互补）**
直觉：力矩看不见**自平衡内力**（两只手对捏一个杯子，净力矩为零），三维感知看不见**力的幅值**（它只知道那里有表面，不知道你用了多大力）。二者各自都有一个巨大的盲区，但盲区并不重合：
- 力矩盲区 = `ker(J_C^T)`，即自平衡接触力；
- 几何盲区 = 「力的大小」与「未知/遮挡区域内的接触」。
把两个观测拼起来，联合盲区收缩为「内力子空间」。而内力恰好可以被**形变**（三维看到压痕）或**运动**（改变雅可比后内力在关节空间的投影不再为零）打破。这就是 TORUS 的理论支点。

**灵感 4（接触层析 → 从边界力反演内部接触）**
直觉：医学 CT 用边界测量反演内部结构；机器人也可以用「关节力矩（边界力）+ 三维表面（边界几何）」反演「接触集合（内部状态）」。把机器人本体看成一台**分布式力传感器**，把三维感知看成它的**几何正则化器**，于是接触估计变成一个带支撑先验与摩擦锥约束的稀疏反问题——我称之为**接触层析（Contact Tomography）**。

**灵感 5（动觉视差 → 主动探测的物理根据）**
直觉：人判断一个力来自哪里，会「换个姿势再感受一下」。因为同一个物理力，在不同关节构型下投影到关节空间的方向不同；而**自平衡内力**在单一构型下恰好投影为零，换个构型就可能露出马脚。TORUS 把这种「动觉视差」形式化为：选择一段探测轨迹，使堆叠的接触雅可比 `[J_C(q_0); J_C(q_1); …]` 满秩，从而在内力子空间上获得可辨识性。这是 RAS「主动情绪探针」的物理版本，但探针问的是世界，不是人心。

**灵感 6（三灵感合流 → TORUS 的分层结构）**
TORUS 在 VISTA / RAS 的时序骨架上换装为：
1. **TSG Torque Sensing Gateway**：动量观测器 + 关节力矩滤波，输出残差 `r` 与传感器健康度；
2. **G3P Geometric 3D Perception**：TSDF/ESDF + 法向 + 自由/占据/未知三值几何；
3. **CTX Contact Tomography eXtractor**：带表面支撑、摩擦锥、稀疏性约束的接触反演，输出 `Ĉ` 与可辨识裕度 `μ`；
4. **XCF cross-modal Consistency Falsifier**：计算力矩残差 `ε_τ`、几何残差 `ε_g`，在 7 个力-形假设上做联合归因；
5. **TAC Torque-Attested Contact**：注入受证的小幅运动抖动，检验力矩响应是否落在 `range(J_Ĉ^T)` 内，做物理挑战-响应认证；
6. **CRC Contact-Realizable Certificate**：把「力-形一致」写进证书 `J_TORUS`；
7. **TCI Torque-Consistent Impedance**：把期望力矩投影到「几何可实现 + 力矩可承受」的集合；
8. **ACP Active Contact Probing**：在可辨识裕度不足时，选择使 Fisher 信息最大的探测动作。

## 1. 形式化定义（增量：定义 245–262）

- **定义 245（TORUS 总览）**：`TORUS = (TSG, G3P, CTX, XCF, TAC, CRC, TCI, ACP)`。定位：把 RAS 的「意图闭环」重建为「力-形互证的物理闭环」。不变式：(i) 三维几何与力矩残差只在语义流做联合反演与归因；(ii) 实时流只做残差计算、证书查表与力矩投影，零学习写操作；(iii) 任何被放行的接触，必须同时通过力矩证据与几何证据（或显式标记 `unverifiable` 并保守处理）。
- **定义 246（力矩残差观测量）**：对 n 关节机器人，`r_t = τ_ext,t + b_t + η_t`，其中 `τ_ext` 为外力矩，`b` 为偏置/温漂，`η` 为噪声。由广义动量观测器给出 `r_t = K_o( p_t − ∫(τ_m + C(q,q̇)^T q̇ − g(q) + r) dt )`，`p = M(q)q̇`。`r_t ∈ ℝ^n`，采样率 `f_τ ≥ 1 kHz`。
- **定义 247（三维几何观测量）**：`G_t = (φ_t, n_t, O_t)`，`φ: ℝ³→ℝ` 为截断符号距离场，`n` 为表面法向，`O: ℝ³→{free, occupied, unknown}`。定义表面带 `S_δ = {x : |φ(x)| ≤ δ}`、自由空间 `F_δ = {x : φ(x) > δ}`、未知区 `U_δ = {x : 0 < φ(x) ≤ δ}`。`unknown ≠ free`：未知区不构成「无接触」的证据。
- **定义 248（接触集合与预测力矩）**：接触集合 `C = {(p_i, w_i)}_{i=1..K}`，`p_i ∈ ∂B`（机器人本体表面），`w_i = (f_i, m_i) ∈ ℝ⁶`。接触雅可比 `J_p(q) ∈ ℝ^{n×6}` 把外部力旋量映射为关节力矩：`τ(C) = Σ_i J_{p_i}(q)^T w_i`。点接触取 `m_i = 0` 且 `f_i` 落在摩擦锥 `K_μ(n_i) = {f : ||f_t|| ≤ μ f_n, f_n ≥ 0}` 内。
- **定义 249（接触层析问题 CTP）**：给定 `(r_t, G_t, q_t)`，求
  `Ĉ = argmin_C  ½ (r − τ(C))^T Σ^{-1} (r − τ(C)) + λ_K K + λ_s Σ_i d(p_i, S_δ)^2`
  s.t. `p_i ∈ ∂B`，`w_i ∈ K_μ(n(p_i))`，`||τ(C)||_∞ ≤ τ_max`。第一项是力矩证据，第二项是稀疏接触先验，第三项是几何支撑先验。
- **定义 250（力-形一致三值判决）**：对候选接触 `(p, w)`：
  - `consistent`：`d(p, S_δ) ≤ ε_s` 且 `r − τ(Ĉ)` 在噪声内；
  - `inconsistent`：`p ∈ F_δ`（自由空间里不可能有接触）或力矩残差超出噪声；
  - `unverifiable`：`p ∈ U_δ`（遮挡/未知区），几何既不能证实也不能证伪。
  `unverifiable` 不得被当作 `consistent`，也不得直接触发 SafeStop。
- **定义 251（力矩不可见子空间）**：在固定构型下，`N_τ(C) = ker(J_C^T)`，其中 `J_C^T = [J_{p_1}^T, …, J_{p_K}^T] ∈ ℝ^{n×6K}`。`N_τ` 中的力旋量不产生任何关节力矩，典型例子是对捏产生的**自平衡内力**。
- **定义 252（可辨识裕度）**：`μ(C) = σ_min(J_C^T) / √K`，即单位接触力旋量在关节空间中的最小可观测增益。`μ` 越小，同样噪声下可分辨的最小接触力越大。`μ < μ_min` 时判定该接触「力矩不可辨识」，转交 ACP 或几何/形变通道仲裁。
- **定义 253（力-形失配假设集）**：`ℋ_T = {H0 一致, H_bias 力矩零偏/温漂, H_dyn 未建模动力学, H_occl 视觉遮挡/透明, H_phantom 视觉幻影, H_geom 几何/运动学模型错误, H_common 共因故障}`。联合后验
  `P(C, H | r, G) ∝ p(r | C, H) · p(G | C, H) · P(C | H) · P(H)`。
- **定义 254（物理挑战-响应认证 TAC）**：由密钥 `k` 生成伪随机抖动序列 `δq_k`，在受证力矩包络内执行小幅运动抖动，测力矩响应 `δτ`。认证统计量
  `ρ_ac = 1 − ||(I − Π_{range(J_Ĉ^T)}) δτ|| / ||δτ||`。
  `ρ_ac ≥ ρ_min` 且 `δτ` 与 `δq_k` 的相关性显著时，判定接触为「物理真实」；视觉幻影通常给不出力响应，重放攻击无法预知 `δq_k`。
- **定义 255（接触可实现证书 J_TORUS）**：
  `J_TORUS = (J_RAS, Ĉ, ε_τ, ε_g, μ, w_min, ρ_ac, sensor_health, aic_t_ver)`。
  `Valid ⇔ Valid(J_RAS) ∧ ε_τ ≤ τ_τ ∧ ε_g ≤ τ_g ∧ μ ≥ μ_min ∧ (ρ_ac ≥ ρ_min ∨ 接触标记 unverifiable) ∧ sensor_health = ok`。其中检测下限 `w_min = τ_τ / μ`。
- **定义 256（力矩一致阻抗 TCI）**：固定支撑 `Ĉ` 后，定义可实现力矩锥
  `T_cert(Ĉ) = { Σ_i J_{p_i}^T w_i : w_i ∈ K_μ(n_i) } ∩ { τ : ||τ||_∞ ≤ τ_max }`。
  控制指令 `τ_cmd = Π_{T_cert(Ĉ)}(τ_desired)`；不可行时回退到 VISTA/RAS 的认证前缀或 SafeStop。
- **定义 257（主动接触探测 ACP）**：候选探测动作 `u` 诱导轨迹 `q_{0:T}(u)`。Fisher 信息
  `F(u) = Σ_{t=0}^{T} J_{Ĉ}(q_t(u))^T Σ^{-1} J_{Ĉ}(q_t(u))`。
  选择 `u* = argmax_u log det F(u)`，并约束 `u` 在证书允许的力矩/速度/工作空间内。对内力歧义，关键量是堆叠雅可比 `P(u) = [J_Ĉ(q_0); …; J_Ĉ(q_T)]` 的秩：`rank(P) ≥ 6K` 即「动觉视差」足以击穿 `N_τ`。
- **定义 258（几何/形变仲裁）**：若物体可形变且三维可测压痕 `d`，用柔顺模型 `w = K_c d` 把几何观测升级为力观测。此时内力 `w` 与 `−w` 都产生可测形变，`N_τ` 被形变通道补全；`K_c` 的标定不确定度计入 `Σ`。
- **定义 259（扰动与共因集 AIC-T）**：`ℰ_T = ℰ_τ × ℰ_G × ℰ_common`，其中 `ℰ_τ` 含噪声、零偏、温漂、量化、饱和；`ℰ_G` 含遮挡、透明、镜面、稀疏、运动模糊、对抗纹理；`ℰ_common` 含碰撞（同时激发力矩与几何变化）、负载变化（力矩变、几何不变）、抓取可形变物（两者同时变）。
- **定义 260（双频分工）**：语义面（10–30 Hz）跑 G3P + CTX + XCF + ACP；实时面（≥500 Hz）跑 TSG + CRC 查表 + TCI 投影。两个平面只通过 `J_TORUS` 与 `Ĉ` 交换只读快照，不共享可变状态。
- **定义 261（力-形联合归因）**：`XCF` 的判别特征为 `ψ = (ε_τ, ε_g, corr(r, q̈), 谱质心(r), 持续时长, 抖动响应 ρ_ac, 几何三值判决)`。`H_bias` 对应高 DC、低 `corr(r,q̈)`、长期持续；`H_dyn` 对应高 `corr(r,q̈)`；`H_occl` 对应力矩冲击 + 接触点位于 `U_δ`；`H_phantom` 对应静态几何穿透 + 无力矩；`H_common` 对应两者同刻、同向变化。
- **定义 262（TORUS 端到端闭环）**：`TORUS_round = TSG → G3P → CTX → XCF → (ACP|TAC) → CRC → TCI`。闭环不变式：**任一时刻被 dispatch 的力矩指令，必须属于某个经力-形互证（或显式 `unverifiable` 保守处理）的接触集合的可实现锥。**

## 2. 关键算法骨架

```python
# TSG：力矩残差网关（1 kHz）
class TorqueSensingGateway:
    def __init__(self, n, Ko=1.0, tau_eps=0.5):
        self.n, self.Ko, self.tau_eps = n, Ko, tau_eps
        self.r = np.zeros(n)

    def update(self, q, dq, tau_m, dt):
        p = self.M(q) @ dq
        self.beta += dt * (tau_m + self.C(q, dq).T @ dq - self.g(q) + self.r)
        self.r = self.Ko * (p - self.beta)          # ≈ τ_ext + b + η
        health = 'ok' if np.max(np.abs(self.r)) < 10 * self.tau_eps else 'saturated'
        return self.r, health


# CTX：接触层析（10–30 Hz）
def contact_tomography(r, q, patches, Sigma, tau_max, mu=0.7):
    # 候选 patch p 上的力旋量 w_p，组稀疏 SOCP
    # min 0.5 (r - Σ J_p^T w_p)^T Σ^{-1} (...) + λ Σ ||w_p||_2
    # s.t. w_p ∈ FrictionCone(n_p, mu), ||τ||∞ ≤ tau_max
    C_hat, info = solve_group_socp(r, q, patches, Sigma, tau_max, mu)
    mu_margin = smallest_singular_value(contact_jacobian(C_hat, q)) / sqrt(max(1, len(C_hat)))
    return C_hat, mu_margin


# XCF + CRC：力-形一致性与证书
def certify(r, G, C_hat, mu_margin, J_ras, tau_tau, tau_g, mu_min):
    eps_tau = residual_norm(r - predicted_torque(C_hat))
    eps_g = sum(dist(p, surface_band(G)) for p, _ in C_hat)
    unverifiable = any(in_unknown_region(p, G) for p, _ in C_hat)
    valid = (J_ras.valid and eps_tau <= tau_tau and eps_g <= tau_g
             and mu_margin >= mu_min and (unverifiable or tac_pass(C_hat)))
    w_min = tau_tau / max(mu_margin, 1e-9)   # 可检测的最小接触力
    return Certificate(valid, eps_tau, eps_g, mu_margin, w_min, unverifiable)


# TCI：力矩一致阻抗投影（≥500 Hz）
def project_torque(tau_des, C_hat, q, tau_max, mu=0.7):
    # min ||tau - tau_des||_W^2  s.t. tau = Σ J_p^T w_p, w_p ∈ K_mu, ||tau||∞ ≤ tau_max
    tau_cmd, feasible = solve_qp(tau_des, C_hat, q, tau_max, mu)
    return tau_cmd if feasible else fallback_vista_ras(tau_des)


# ACP：主动接触探测
def choose_probe(C_hat, q0, Sigma, horizon=5):
    best_u, best_info = None, -np.inf
    for u in probe_primitives(q0, horizon):
        qs = rollout(q0, u)
        F = sum(contact_jacobian(C_hat, q).T @ inv(Sigma) @ contact_jacobian(C_hat, q)
                for q in qs)
        info = logdet(F + 1e-9 * np.eye(F.shape[0]))
        if info > best_info and within_certified_envelope(u):
            best_u, best_info = u, info
    return best_u, best_info


def TORUS_round(M, obs):
    q, dq, tau_m, img, depth, J_ras = obs
    r, health = M.tsg.update(q, dq, tau_m, M.dt)
    G = M.g3p.build(img, depth)
    C_hat, mu_margin = M.ctx.solve(r, q, M.g3p.patches, M.Sigma, M.tau_max)

    if mu_margin < M.mu_min:
        u = M.acp.choose_probe(C_hat, q, M.Sigma)
        if u is not None:
            M.execute_probe(u)
            C_hat, mu_margin = M.ctx.solve(M.tsg.r, q, M.g3p.patches, M.Sigma, M.tau_max)

    J_torus = M.crc.certify(r, G, C_hat, mu_margin, J_ras, M.tau_tau, M.tau_g, M.mu_min)
    tau_cmd = M.tci.project(M.pi_sigma.prefix_dispatch(), C_hat, q, M.tau_max)
    return J_torus, C_hat, tau_cmd
```

## 3. 推导

**引理 11（力矩不可见子空间 = 内力子空间）** 固定构型下 `τ(C) = J_C^T w` 是线性映射，故 `τ(C)=0 ⇔ w ∈ ker(J_C^T)`。当 `K≥2`、各接触力沿同一作用线等大反向时，净力旋量为零，因而 `w ∈ N_τ`；这类自平衡内力是力矩通道的**唯一结构性盲区**（其余为数值奇异）。

**引理 12（几何通道对力幅值全盲）** 几何观测算子只依赖支撑点 `p` 与表面法向 `n`，与 `||w||` 无关；对同一支撑上的任意 `λw`，`G` 不变。落在未知区 `U_δ` 的接触对 `G` 完全不可见。因此几何通道的盲区至少包含「力幅值」与「未知区接触」。

**定理 11（零空间互补与可辨识性）** 在定义 250 的三值判决下，记联合盲区 `N_comb = N_τ ∩ N_G`。若接触支撑可见（`p ∉ U_δ`）且 `J_C` 在支撑上列满秩，则 `N_comb = N_τ`；若进一步满足下列任一条件，则 `N_comb = {0}`，接触集合在 `(r, G)` 下局部可辨识：
1. **单接触**：`K=1`，`J_p^T` 列满秩（一般位形成立）；
2. **形变可观测**：三维可测压痕且柔顺模型 `K_c` 已知（定义 258）；
3. **动觉视差**：存在探测轨迹使堆叠雅可比 `P(u)` 满足 `rank(P) ≥ 6K`（定义 257）。
特别地，纯内力歧义只在「多接触 + 不可形变 + 单一静止构型」三者同时成立时存在。

**定理 12（接触检测下限）** 若 `J_TORUS` 有效、力矩残差阈值 `τ_τ`、可辨识裕度 `μ = σ_min(J_Ĉ^T)/√K`，则任何未被认证集合覆盖、且满足 `||w||₂ > τ_τ/μ` 的附加接触都会使 `ε_τ > τ_τ` 从而被检出。即最小可检测接触力为 `w_min = τ_τ/μ`。推论：接近奇异位形（`μ→0`）会抬高检测下限，此时必须由几何支撑、形变通道或 ACP 把 `μ` 拉回；这也解释了为什么「只凭力矩的接触检测」在伸展臂末端最不可靠。

**定理 13（TAC 的抗幻影性）** 设视觉幻影不产生真实外力矩，则其 `δτ` 只含传感器噪声，`ρ_ac → 0`；设攻击者重放历史力矩，则由于抖动序列 `δq_k` 由密钥伪随机生成，重放响应与当前 `δq_k` 的相关性以概率 `1−2^{-b}` 失效（`b` 为挑战位数）。因此 `ρ_ac ≥ ρ_min` 构成一个**需要真实接触才能通过**的物理挑战-响应。

## 6. 本轮最大风险

**一句话**：TORUS 的全部推理都建立在「接触模型 + 三维支撑 + 关节力矩标定足够正确」之上；一旦遇到软体/可形变物、未建模的线缆张力或强摩擦，这些**模型误差会被 CTX 反演成一个自洽的“虚假接触”并通过证书**，于是它比 VISTA/RAS 更危险——因为它把错误从「未检出」升级成了「被物理证书背书」。

**次级风险与缓解**：
1. **软体/形变接触**：`K_c` 未知 → 不把形变通道当力证据，标记 `unverifiable`，走保守容差；
2. **力矩传感器成本与带宽**：无全关节力矩时用 SEA 形变/电流估计，但需在线辨识摩擦与齿隙；
3. **零偏与温漂**：TSG 周期自校准（空载激励 + 运动学一致），漂移超限直接降级；
4. **未知区语义**：`unknown` 与 `free` 必须严格区分，否则会把遮挡误当无接触；
5. **主动探测安全**：探测轨迹先过 TCI 与 VISTA 认证前缀，禁止在接触密集区做大幅抖动；
6. **对抗攻击面转移**：攻击者改攻力矩传感器 → 用 TAC 的随机抖动 + 多源冗余（电流/SEA/基座力）交叉验证。

## 3. 关键算法伪代码

```python
# IP-234 TSG
class TorqueSensingGateway:
    def __init__(self, n, Ko=1.0):
        self.n, self.Ko = n, Ko
        self.r = np.zeros(n); self.beta = np.zeros(n)

    def update(self, q, dq, tau_m, dt):
        p = self.M(q) @ dq
        self.beta += dt * (tau_m + self.C(q, dq).T @ dq - self.g(q) + self.r)
        self.r = self.Ko * (p - self.beta)
        health = 'ok' if np.max(np.abs(self.r)) < 10 * self.tau_eps else 'saturated'
        return self.r, health


# IP-236 CTX：组稀疏 SOCP（每个候选 patch 一组 w_p）
def contact_tomography(r, q, patches, Sigma, tau_max, mu=0.7, lam=0.1):
    # min 0.5 (r - Σ_p J_p^T w_p)^T Σ^-1 (...) + lam Σ_p ||w_p||_2
    # s.t. w_p ∈ K_mu(n_p), ||Σ_p J_p^T w_p||∞ ≤ tau_max
    C_hat = solve_group_socp(r, q, patches, Sigma, tau_max, mu, lam)
    J_C = contact_jacobian(C_hat, q)
    mu_margin = np.linalg.svd(J_C, compute_uv=False)[-1] / np.sqrt(max(1, len(C_hat)))
    return C_hat, mu_margin


# IP-237/239 XCF + CRC
def certify(r, G, C_hat, mu_margin, J_ras, tau_tau, tau_g, mu_min, rho_ac):
    eps_tau = np.linalg.norm(r - predicted_torque(C_hat))
    eps_g = sum(dist(p, surface_band(G)) for p, _ in C_hat)
    unverifiable = any(in_unknown_region(p, G) for p, _ in C_hat)
    valid = (J_ras.valid and eps_tau <= tau_tau and eps_g <= tau_g
             and mu_margin >= mu_min
             and (unverifiable or rho_ac >= RHO_MIN))
    w_min = tau_tau / max(mu_margin, 1e-9)
    return Certificate(valid, eps_tau, eps_g, mu_margin, w_min, unverifiable)


# IP-238 TAC：受证运动抖动 + 力矩响应范围检验
def physical_attestation(C_hat, q, key, eps=0.02):
    dq = eps * prng_direction(key, nonce=current_nonce())
    apply_certified_dither(dq)                 # 先过 TCI/VISTA 前缀
    dtau = measure_torque_response()
    J = contact_jacobian(C_hat, q)
    P = J.T @ np.linalg.pinv(J @ J.T) @ J      # range(J^T) 投影
    rho_ac = 1.0 - np.linalg.norm((np.eye(len(dtau)) - P) @ dtau) / (np.linalg.norm(dtau) + 1e-9)
    return rho_ac


# IP-240 TCI：力矩投影 QP（固定支撑 ⇒ 凸锥）
def project_torque(tau_des, C_hat, q, tau_max, mu=0.7, W=None):
    W = np.eye(len(tau_des)) if W is None else W
    # min ||tau - tau_des||_W^2 s.t. tau = Σ J_p^T w_p, w_p ∈ K_mu, ||tau||∞ ≤ tau_max
    tau_cmd, feasible = solve_qp(tau_des, C_hat, q, tau_max, mu, W)
    return tau_cmd if feasible else fallback_vista_ras(tau_des)


# IP-241 ACP：Fisher 信息 + 动觉视差
def choose_probe(C_hat, q0, Sigma, horizon=5):
    best_u, best_info = None, -np.inf
    for u in probe_primitives(q0, horizon):
        if not within_certified_envelope(u):
            continue
        F = np.zeros((6 * len(C_hat), 6 * len(C_hat)))
        for q in rollout(q0, u):
            J = contact_jacobian(C_hat, q)
            F += J.T @ np.linalg.inv(Sigma) @ J
        info = np.linalg.slogdet(F + 1e-9 * np.eye(F.shape[0]))[1]
        if info > best_info:
            best_u, best_info = u, info
    return best_u, best_info


# IP-242/243 TORUS 闭环
def TORUS_round(M, obs):
    q, dq, tau_m, img, depth, J_ras = obs
    r, health = M.tsg.update(q, dq, tau_m, M.dt)
    G = M.g3p.build(img, depth)
    C_hat, mu_margin = M.ctx.solve(r, q, M.g3p.patches, M.Sigma, M.tau_max)

    if mu_margin < M.mu_min:
        u, _ = M.acp.choose_probe(C_hat, q, M.Sigma)
        if u is not None:
            M.execute_probe(u)
            C_hat, mu_margin = M.ctx.solve(M.tsg.r, q, M.g3p.patches, M.Sigma, M.tau_max)

    rho_ac = M.tac.physical_attestation(C_hat, q, M.key)
    J_torus = M.crc.certify(r, G, C_hat, mu_margin, J_ras,
                            M.tau_tau, M.tau_g, M.mu_min, rho_ac)

    tau_cmd = M.tci.project(M.pi_sigma.prefix_dispatch(), C_hat, q, M.tau_max)
    return J_torus, C_hat, tau_cmd
```

## 4. 推导

**引理 11（力矩不可见子空间 = 内力子空间）** 固定构型下 `τ(C)=J_C^T w` 线性，故 `τ(C)=0 ⇔ w ∈ ker(J_C^T)`。当 `K≥2` 且各接触力沿同一作用线等大反向时，净力旋量为零，因而 `w ∈ N_τ`；自平衡内力是力矩通道的唯一结构性盲区。

**引理 12（几何通道对力幅值全盲）** 几何观测算子只依赖支撑 `p` 与法向 `n`，与 `||w||` 无关；同一支撑上的任意 `λw` 给出相同 `G`。未知区 `U_δ` 内的接触对 `G` 完全不可见。故几何盲区至少包含力幅值与未知区接触。

**定理 11（零空间互补与可辨识性）** 记联合盲区 `N_comb = N_τ ∩ N_G`。若接触支撑可见且 `J_C` 在支撑上列满秩，则 `N_comb = N_τ`；若进一步满足下列任一条件，则 `N_comb = {0}`：
1. **单接触**：`K=1` 且 `J_p^T` 列满秩；
2. **形变可观测**：三维可测压痕且 `K_c` 已知；
3. **动觉视差**：存在探测轨迹使 `rank([J_Ĉ(q_0); …; J_Ĉ(q_T)]) ≥ 6K`。
纯内力歧义只在「多接触 + 不可形变 + 单一静止构型」同时成立时存在。

**定理 12（接触检测下限）** 若 `J_TORUS` 有效、阈值 `τ_τ`、裕度 `μ = σ_min(J_Ĉ^T)/√K`，则任何未被认证集合覆盖且 `||w||₂ > τ_τ/μ` 的附加接触都会使 `ε_τ > τ_τ` 而被检出。即 `w_min = τ_τ/μ`。推论：接近奇异位形（`μ→0`）抬高检测下限，必须由几何支撑、形变或 ACP 把 `μ` 拉回。

**定理 13（TAC 抗幻影性）** 视觉幻影不产生真实外力矩，其 `δτ` 只含噪声，`ρ_ac → 0`；重放历史力矩时，抖动序列 `δq_k` 由密钥伪随机生成，重放响应与当前 `δq_k` 的相关性以概率 `1−2^{-b}` 失效。因此 `ρ_ac ≥ ρ_min` 是**需要真实接触才能通过**的物理挑战-响应。

**命题 1（证书的保守回退）** 若 `Ĉ` 中存在 `unverifiable` 接触，则 `J_TORUS` 可以不要求 `ρ_ac`，但必须把 `λ_risk` 压到 RAS 的保守区间，并把 `T_cert(Ĉ)` 收缩为「仅允许撤出力」的方向锥。这保证「看不见」不会被解释成「可以冒险」。

## 6. 本轮最大风险

**一句话**：TORUS 的全部推理都建立在「接触模型 + 三维支撑 + 关节力矩标定足够正确」之上；一旦遇到软体/可形变物、未建模线缆张力或强摩擦，模型误差会被 CTX 反演成一个自洽的“虚假接触”并通过证书——这比 VISTA/RAS 更危险，因为它把错误从「未检出」升级成了「被物理证书背书」。

**次级风险与缓解**：
1. **软体/形变接触**：`K_c` 未知时禁用形变通道，标记 `unverifiable`，走保守容差；
2. **传感器成本/带宽**：无全关节力矩时用 SEA 形变或电流估计，但在线辨识摩擦与齿隙；
3. **零偏与温漂**：TSG 周期自校准（空载激励 + 运动学一致），漂移超限直接降级；
4. **未知区语义**：严格区分 `unknown` 与 `free`，避免把遮挡误当无接触；
5. **主动探测安全**：探测轨迹先过 TCI 与 VISTA 认证前缀，接触密集区禁止大幅抖动；
6. **攻击面转移**：攻击者改攻力矩传感器 → TAC 随机抖动 + 电流/SEA/基座力多源交叉验证。
