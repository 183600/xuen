# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「能耗优化」×「动作分块」）

> 第 59 轮把「执行」接入了物理与实时契约：BUQ 辨识电机非高斯不确定性、ERTC 守住 WCET/抖动、EEIS 把 δ_f 编译成阻抗参数、CLEP 让执行证据回传。但它仍隐含两个理想化：**（i）每个决策是一个「动作原子」**——作出即执行、执行即可立即再决策；**（ii）能量是被优化掉的标量成本**——不进入安全状态、不产生证据。本轮两个灵感正好拆穿它们：**动作分块**把承诺从「单步」拉长为「一段开环时域」——一次策略推理输出 H 步动作并连续执行，计算/通信能耗被摊薄，但反馈被切断 H 步，证据鲜度、模型误差、环境变化在开环段内**复利累积**；**能耗优化**把能量从「账单」提升为**一等安全状态与观测通道**——SoC/热降额/再生能力决定「还能不能安全停下」，而执行一段动作所耗的能量本身携带环境刚度、负载、地形、效率漂移的信息。本轮核心命题：**「用能耗预算决定动作分块的时域长度，用动作分块的能量指纹反哺证据层；在能耗—风险—证据鲜度三者之间求取可证明安全的分块承诺。」**

核心矛盾：
- **H32（承诺时域化·开环漂移复利）**：动作分块把推理频率从 100~1000 Hz 降到 2~20 Hz，能耗与延迟大降；但 H 步开环期间没有任何新观测修正，单步失效率 δ_step 以 1−(1−δ_step)^H 累积，模型误差以 c·(H·Δt)^α 增长，证据在 τ_ev+H·Δt 后彻底陈旧。**分块长度不是超参，而是一个必须被安全预算约束的决策变量**；现有证据门只认证「单步承诺」，从未认证「一段开环承诺」。
- **H33（能量即安全状态·储备不可挪用）**：低 SoC、低温/高温降额、再生受限会**收缩可达安全集**——同样一段动作，在高电量下安全，在低电量下可能「走到一半没能量安全停」。能量预算不能像探针预算那样「省着用」，它必须预留 **E_stop（减速+落地+保持的最小安全能量）**；任何把安全储备挪去探索/加速的优化都是把失效概率偷偷转嫁给未来。
- **H34（能量即证据·自由探针与被混淆）**：执行一段动作的能耗是**已经付过费**的观测量——能耗残差可反推环境刚度、负载质量、地面摩擦、传动效率漂移，是「零额外能耗的自由探针」。但它被热动态、电压跌落、电流采样误差混淆，且并非独立于执行模态（同一轨迹的副产物），因此**只能用于对账与触发降级，不能直接充当独立佐证**；更危险的是，若把它当作「免费午餐」而缩短分块、减少真探针，就会陷入「用相关证据替代独立证据」的自证陷阱。

## 0. 直觉与动机

**灵感 1（能耗优化 → 能量状态量化 EEQ）**
直觉：机器人不是「恒定效率的功率源」，而是**效率随转矩、转速、结温、母线电压漂移的非线性系统**。把能量状态纳入一等状态 ξ_energy=(SoC, E_avail, T_junc, V_bus, η(τ,ω,T), η_regen, P_static, E_stop)；铜损 P_cu=(τ/k_t)²R 与热耦合（热又反过来降额 k_t、升 R），再生在负功率段回收 η_regen 比例。关键洞见：**能量预测误差本身是可在线校准的**——用每段动作的「预测能耗 vs 实测能耗」更新效率图与 SoC 估计，并把不确定度传播为 **E_chunk 的保守上界**。于是「还能跑多远」从拍脑袋变成**带置信上界的安全约束**。

**灵感 2（动作分块 → 分块时域综合 ACB）**
直觉：动作分块本质是**用「开环时域」换「推理/通信能耗」**。当每个控制步的推理能耗为 E_inf、控制周期为 Δt 时，分块长度 H 把推理能耗率从 E_inf/Δt 降到 E_inf/(H·Δt)——H 越大越省；但开环风险 δ_chunk(H)≈1−(1−δ_step)^H+c(H·Δt)^α 随 H 单调上升。于是存在一个**安全可行上界 H_risk**（δ_chunk≤δ_req）与一个**储备可行上界 H_energy**（E_avail−E_committed−E_chunk(H)≥E_stop+E_margin）。最优策略不是「越长越省」，而是**在双重约束下取最长可行分块**；若 H_risk<H_min（连最短安全分块都不可行）⇒ 必须降速/降档/停，而不是冒险拉长。

**灵感 3（能耗优化 × 动作分块 → 能量契约与安全储备 ECT）**
直觉：实时契约 ERTC 管的是「时间不能超」，能量契约管的是「能量不能借」。定义 ECT：E_avail(t)−E_committed(t) ≥ E_stop(ξ_exec,b_r)+E_margin 是**任意时刻必须成立的硬不变量**；E_committed 是「已下发但未执行完的分块的最坏能耗」——因为分块是开环承诺，**承诺即占用，不论实际用多少都要先扣掉**。运行时能量监视器 M_en 采样 SoC/母线/温度/电流，若某候选分块会击穿储备 ⇒ 缩短 H、限速限矩、禁探针，最终受控返航/安全停。这把「电量焦虑」变成**可审计的安全契约**。

**灵感 4（能量指纹 → 自由探针 EFI）**
直觉：同一段任务动作，在软地、硬地、有负载、无负载下耗能不同；能耗残差 r_E=(E_meas−E_pred)/σ_E 因此是环境/负载/效率的**观测**。因为任务动作本来就要执行，这部分能量已经付过，故称 **自由探针（free probe）**：VOI_E(π)=λ_I·I_E(π)−λ_E·max(0,E_chunk(π)−E_chunk^min)，只对「为获取信息而额外多花的能量」计价。更主动地，可在能耗几乎不变的动作族里挑选**能量信息量最大**的分块（例如刻意改变加减速剖面/力矩分布以激发可辨识性），实现「一边干活一边做系统辨识」。但必须遵守与第 59 轮相同单向性：能量证据只能加宽后验/触发降级，**不能减少探针、不能替独立佐证**。

**灵感 5（合流 → 能量感知分块闭环 EAC-CLEP 与五预算 PCE++++）**
直觉：把第 59 轮 CLEP 从「单步闭环」升级为「分块闭环」：EEQ 更新能量状态 → ECT 检查储备 → BUQ 更新执行不确定性 → ACB 综合分块长度与能量证书 → EFI 预测能量指纹与信息量 → 开环执行整段（安全护盾在线）→ 能耗残差/力异常触发**提前终止** → EV-energy 回传 → XMC++ 把能量作为第 6 模态**仅作对账** → 信念更新 → 下一分块。预算从四重扩为五重：B_probe/B_ft/B_ux/B_exec/**B_energy**，其中 B_energy 含**不可挪用的安全储备子账户**，其余预算只能花「自由能量」，不能触碰储备。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（能量状态 EEQ）** ξ_energy = (SoC, E_avail, T_junc, V_bus, {R_j, k_t,j}, η(τ,ω,T), η_regen, P_static, E_stop)。单关节电功率（含铜损与再生）：
```
P_j(t) = τ_jω_j / η_j(τ_j,ω_j,T_j) + (τ_j/k_t,j)²R_j        , τ_jω_j ≥ 0
P_j(t) = η_regen,j·τ_jω_j          + (τ_j/k_t,j)²R_j        , τ_jω_j < 0
P_elec(t) = Σ_j P_j(t) + P_0 + P_comp + P_comm
```
在线辨识 η、R、k_t（随温度/老化慢漂移）：ξ_energy ← EKF/RLS(telemetry)，与 BUQ 的 ξ_exec 共享 T_junc 观测量。能量 OOD：SoC 估计残差或效率图残差超阈值 ⇒ 标 `energy_ood=true`，强制最保守储备。

**定义 154（分块能耗模型与最坏界）** 分块 π=(a_1..a_H) 的预测能耗与保守上界：
```
E_chunk(π; ξ_energy) = Σ_{t=1}^H P_elec(t; a_t, ξ_energy)·Δt
E_chunk^max(π) = max_{ξ_energy∈Ξ_E, b_r∈B} E_chunk(π; ξ_energy)   # 区间/情景上界
```
推理能耗摊薄：E_inf^rate(H)=E_inf/(H·Δt)；因此长分块省的是**计算/通信**，不是执行能量。

**定义 155（分块开环风险 δ_chunk）** 给定单步失效率 δ_step、模型误差增长指数 α、证据有效期 T_fresh：
```
δ_chunk(H) = 1 − (1−δ_step)^H + c_model·(H·Δt)^α
             + β_stale·max(0, τ_ev + H·Δt − T_fresh)
```
风险分配：在 n 个检查点上要求 δ_chunk(H) ≤ δ_f^req/n_cp（Boole）。定义安全可行上界 H_risk = max{H : δ_chunk(H) ≤ δ_f^req/n_cp}。

**定义 156（能量契约与安全储备 ECT）** E_contract=(E_stop, E_margin, SoC_min, T_hold, P_max, Regen_limit, Recheck_period)。硬不变量：
```
Inv_E:  E_avail(t) − E_committed(t) ≥ E_stop(ξ_exec,b_r) + E_margin
E_committed(t) = Σ_{π在途} E_chunk^max(π)          # 开环承诺即占用
```
E_stop = 最小安全停能量 = ∫(减速+落地+保持 T_hold) 的最坏能耗。运行时监视器 M_en 每 Recheck_period 采样；若候选分块使 Inv_E 失效 ⇒ 拒绝、缩短 H（降到 H_energy），SoC<SoC_min ⇒ 受控返航/安全停；违例即 `DEGRADE_ENERGY`。

**定义 157（能量指纹证据 EV-energy 与自由探针）** 分块末残差 r_E=(E_meas−E_pred(π;h))/σ_E，对假设 h（环境刚度/负载/摩擦）给似然 L_E(r_E|h)=N(r_E;0,σ_E²(h))。自由探针价值：
```
VOI_E(π) = λ_I·I_E(π) − λ_E·max(0, E_chunk(π) − E_chunk^min)
I_E(π)   = E_{r_E}[ KL( p(h|r_E,π) ‖ p(h) ) ]
```
EV-energy=(E_meas, E_pred, r_E, energy_ood, reserve_margin, τ_ev, H)。**单向性**：EV-energy 只进对账分歧 D^++ 与降级触发，不进入 EV-xmodal/EV-human 佐证集；`|r_E|>θ_E` ⇒ 加宽后验 + 缩短下一分块 + 可触发定向探针。

**定义 158（分块时域综合 ACB）** 候选分块 π∈Π_H，任务进度 g(π)。可行域：
```
H_risk   = max{H : δ_chunk(H) ≤ δ_f^req/n_cp}
H_energy = max{H : E_avail − E_committed − E_chunk^max(H) ≥ E_stop + E_margin}
H_info   = argmax_H [ g(π_H) + VOI_E(π_H) ]
H* = min(H_risk, H_energy, H_plan, H_info)   # 双约束 + 信息偏好
```
若 H*<H_min（最小可用分块）⇒ 不承诺，进入降档/协商/安全停。输出分块证书 Cert_chunk=(H*, E_chunk^max, E_pred, δ_chunk, reserve_margin, H_risk, H_energy, version)。

**定义 159（能量感知分块闭环 EAC-CLEP）** 算子 EAC-CLEP(M, cp, δ_f^req, budget)：
```
① EEQ: ξ_energy ← update(telemetry)；E_chunk^max 上界传播
② ECT: Inv_E 预检查；若破 ⇒ DEGRADE_ENERGY
③ BUQ(第59轮): ξ_exec ← UKF.update；Σ_exec ← propagate
④ ACB: H*, Cert_chunk ← synthesize_horizon(δ_f^req, ξ_energy, ξ_exec, b_r)
      if H*<H_min: return DEGRADE_ENERGY/协商
⑤ EFI: E_pred, I_E, VOI_E ← energy_fingerprint_plan(π_H*, h)
⑥ Dispatch: 下发整段分块 + 安全护盾（力/电流/姿态/能量阈值）
⑦ Execute: 开环执行 H* 步；M_en/M_rt/安全护盾在线；异常 ⇒ 提前终止
⑧ EV-energy ← build_energy_evidence(telemetry, Cert_chunk)
⑨ XMC++: 能量模态仅对账；分歧 ⇒ 加宽后验/缩短下一 H
⑩ BeliefUpdate + 能量状态/预算快照；到分块边界再规划
```

### IP-152 EEQ（能量状态量化）

```python
class EnergyStateEstimator:
    def __init__(self, battery, motor_map):
        self.battery = battery
        self.eta_map = motor_map          # η(τ,ω,T), η_regen
        self.rls = RLS(dim=6)             # R_j, k_t,j, P_static, eta_scale
        self.soc = battery.soc0

    def power(self, tau, omega, T, j):
        R, kt = self.rls.theta[j]
        p_cu = (tau / kt) ** 2 * R
        if tau * omega >= 0:
            return tau * omega / self.eta_map(tau, omega, T) + p_cu
        return self.eta_map.regen(tau, omega, T) * tau * omega + p_cu

    def update(self, telemetry):
        # 用实测电压/电流/转速/结温校准效率图与内阻
        self.rls.update(telemetry.v, telemetry.i, telemetry.omega, telemetry.T)
        self.soc = self.battery.coulomb_count(telemetry.i, dt=telemetry.dt)
        return EnergyState(soc=self.soc, T_junc=telemetry.T,
                           eta=self.eta_map, ood=self.is_ood())

    def chunk_energy_upper(self, actions, horizon, dt):
        # 情景上界：η 取下分位、R 取上分位、V_bus 取下分位、负载取上界
        worst = worst_case_set(self.rls.confidence())
        return max(sum(self.power(a.tau, a.omega, T, j) * dt
                       for a in actions for j in range(n_joints), **worst)
                   for worst in worst)
```

### IP-153/158 ACB（分块时域综合）

```python
def synthesize_horizon(delta_f_req, xi_energy, xi_exec, b_r, budget):
    # 1. 安全可行上界：δ_chunk 随 H 单调增
    H_risk = max_h(lambda H: 1 - (1-delta_step)**H
                             + c_model * (H*dt)**alpha
                             + beta_stale * max(0, tau_ev + H*dt - T_fresh)
                             <= delta_f_req / n_cp,
                   lo=1, hi=H_max)

    # 2. 能量可行上界：Inv_E，E_chunk^max 随 H 单调增
    H_energy = max_h(lambda H: (E_avail - E_committed
                                - chunk_energy_upper(plan(H)) 
                                >= E_stop(xi_exec, b_r) + E_margin),
                     lo=1, hi=H_max)

    # 3. 信息偏好：在能耗几乎不变的动作族中选 I_E 最大者
    H_info = argmax_H([g(plan(H)) + VOI_E(plan(H)) for H in range(1, H_max+1)])

    H_star = min(H_risk, H_energy, H_plan, H_info)
    if H_star < H_MIN:
        return None, None                      # 不可承诺 → 降档/停
    cert = ChunkCertificate(H=H_star, E_max=chunk_energy_upper(plan(H_star)),
                            delta_chunk=delta_chunk(H_star),
                            reserve_margin=E_avail-E_committed
                                          -chunk_energy_upper(plan(H_star))
                                          -E_stop(xi_exec,b_r),
                            H_risk=H_risk, H_energy=H_energy, version=ver++)
    return plan(H_star), cert
```

### IP-154 ECT（能量契约监视器）

```python
class EnergyContractMonitor:
    def __init__(self, contract, estimator):
        self.C = contract
        self.eeq = estimator
        self.committed = []        # 在途分块的 E_chunk^max

    def reserve_margin(self):
        return (self.eeq.E_avail() - sum(self.committed)
                - E_stop(self.eeq.xi_exec, self.b_r))

    def admit_chunk(self, cert_chunk):
        if self.reserve_margin() - cert_chunk.E_max < self.C.E_margin:
            return False, "reserve_violation"
        if self.eeq.soc < self.C.SoC_min:
            return False, "soc_below_min"
        if cert_chunk.E_max > self.C.P_max * cert_chunk.H * dt:
            return False, "power_peak"
        self.committed.append(cert_chunk.E_max)
        return True, "ok"

    def release_chunk(self, cert_chunk):
        self.committed.remove(cert_chunk.E_max)

    def check(self):
        if (self.eeq.soc < self.C.SoC_min or
            self.reserve_margin() < self.C.E_margin):
            return False, "DEGRADE_ENERGY"   # 缩 H / 限速 / 返航 / 安全停
        return True, "ok"
```

### IP-157/159 EFI + EAC-CLEP（能量指纹与分块闭环）

```python
def energy_aware_chunk_loop(M, cp, delta_f_req, budget):
    # ① EEQ
    M.xi_energy = M.eeq.update(M.telemetry_latest)
    # ② ECT 预检查
    ok, reason = M.en.check()
    if not ok:
        return degrade_energy_mode(M, cp, reason)

    # ③ BUQ（第 59 轮，结构化执行不确定性）
    M.buq.predict(M.dt_control); M.buq.update(M.telemetry_latest)

    # ④ ACB 分块时域综合
    plan, cert_chunk = synthesize_horizon(delta_f_req, M.xi_energy,
                                          M.buq.ukf.x, M.b_r[cp.region], budget)
    if plan is None:
        return degrade_energy_mode(M, cp, "H_infeasible")
    admitted, why = M.en.admit_chunk(cert_chunk)
    if not admitted:
        return degrade_energy_mode(M, cp, why)

    # ⑤ EFI 能量指纹规划（自由探针信息量）
    E_pred, I_E = M.efi.predict_fingerprint(plan, cert_chunk)

    # ⑥ 下发整段 + 安全护盾（力/电流/姿态/能量阈值）
    dispatch_chunk(plan, cert_chunk, shield=M.safety_shield)

    # ⑦ 开环执行，在线护盾；能量/力/姿态异常 ⇒ 提前终止
    telemetry, terminated = execute_chunk(plan, timeout=H*dt,
                                          shield=M.safety_shield,
                                          energy_monitor=M.en)
    M.en.release_chunk(cert_chunk)

    # ⑧ EV-energy 构建
    EV_E = build_energy_evidence(telemetry, cert_chunk, M.xi_energy,
                                 terminated, M.xi_energy.ood)
    M.EV_energy_log.append(EV_E)

    # ⑨ XMC++：能量仅作对账
    M, fused, D_pp = xmodal_fuse_pp(M, cp.region, EV_E)

    # ⑩ 信念更新 + 恢复到分块边界再规划
    M = update_beliefs_with_energy(M, cp.region, fused, EV_E)
    budget.energy_snapshot = M.en.snapshot()
    return M, fused, D_pp, EV_E, cert_chunk

def build_energy_evidence(tel, cert, xi_e, terminated, ood):
    r_E = (tel.E_measured - cert.E_pred) / max(tel.sigma_E, eps)
```

### IP-152 EEQ（能量状态量化）

```python
class EnergyStateEstimator:
    """能量状态：SoC、效率图、内阻、热、再生；输出 E_chunk 的保守上界"""
    def __init__(self, battery, eta_map, n_joint):
        self.battery = battery
        self.eta_map = eta_map            # η(τ,ω,T), η_regen(τ,ω,T)
        self.rls = RLS(dim=3*n_joint)     # 每关节 (R_j, k_t,j, offset_j)
        self.n_joint = n_joint
        self.soc = battery.soc0
        self.T_junc = battery.T0

    def joint_power(self, tau, omega, T, j):
        R, kt, _ = self.rls.theta[3*j:3*j+3]
        p_cu = (tau / max(kt, eps)) ** 2 * R
        if tau * omega >= 0:                       # 电动
            return tau * omega / max(self.eta_map(tau, omega, T), eps) + p_cu
        return self.eta_map.regen(tau, omega, T) * tau * omega + p_cu  # 再生(负)

    def power_total(self, tau_v, omega_v, T):
        return sum(self.joint_power(tau_v[j], omega_v[j], T, j)
                   for j in range(self.n_joint)) + self.P_static + self.P_comp + self.P_comm

    def update(self, telemetry):
        # 电压/电流/转速/结温 → 校准内阻与效率；库仑计数 → SoC
        self.rls.update(telemetry.v, telemetry.i, telemetry.omega, telemetry.T)
        self.soc = self.battery.coulomb_count(telemetry.i, dt=telemetry.dt)
        self.T_junc = telemetry.T
        return EnergyState(soc=self.soc, T_junc=self.T_junc, V_bus=telemetry.vbus,
                           eta=self.eta_map, ood=self.is_ood())

    def chunk_energy_upper(self, plan, dt):
        """情景上界：η 取下分位、R 取上分位、V_bus 取下分位、负载取上界"""
        scenarios = worst_case_scenarios(self.rls.confidence(), self.eta_map)
        worst = -inf
        for sc in scenarios:
            e = 0.0
            for a in plan.actions:
                e += self.power_total(a.tau, a.omega, sc.T, eta=sc.eta, R=sc.R) * dt
            worst = max(worst, e)
        return worst

    def is_ood(self, alpha=0.01):
        return mahalanobis(self.rls.theta, self.rls.theta_nominal,
                           self.rls.cov) > chi2.ppf(1-alpha, df=len(self.rls.theta))
```

### IP-153/158 ACB（分块时域综合）

```python
def delta_chunk(H, delta_step, c_model, alpha, beta_stale, tau_ev, dt, T_fresh):
    return (1 - (1 - delta_step) ** H
            + c_model * (H * dt) ** alpha
            + beta_stale * max(0.0, tau_ev + H * dt - T_fresh))

def synthesize_horizon(delta_f_req, xi_energy, xi_exec, b_r, plan_builder, budget):
    """在风险与能量双重约束下取最长可行分块，并用信息偏好修正"""
    # 1) 安全可行上界 H_risk：δ_chunk 单调增
    H_risk = max_feasible(
        f=lambda H: delta_chunk(H, delta_step, c_model, alpha, beta_stale,
                                tau_ev, dt, T_fresh) <= delta_f_req / n_cp,
        lo=1, hi=H_MAX)

    # 2) 能量可行上界 H_energy：E_chunk^max 单调增，且承诺即占用
    def energy_ok(H):
        e_ub = eeq.chunk_energy_upper(plan_builder(H), dt)
        return (eeq.soc_energy() - sum(en.committed) - e_ub
                >= E_stop(xi_exec, b_r) + E_margin)
    H_energy = max_feasible(energy_ok, lo=1, hi=H_MAX)

    # 3) 信息偏好 H_info：在能耗几乎不变的动作族中最大化 任务进度 + VOI_E
    H_info = argmax_H([plan_builder(H).progress
                       + efi.voi_e(plan_builder(H), budget)
                       for H in range(1, H_MAX + 1)])

    H_star = min(H_risk, H_energy, H_plan, H_info)
    if H_star < H_MIN:
        return None, None                      # 不可承诺 → 降档/协商/安全停

    plan = plan_builder(H_star)
    cert = ChunkCertificate(
        H=H_star, E_max=eeq.chunk_energy_upper(plan, dt),
        E_pred=eeq.chunk_energy_mean(plan, dt),
        delta_chunk=delta_chunk(H_star, ...),
        reserve_margin=eeq.soc_energy() - sum(en.committed)
                      - eeq.chunk_energy_upper(plan, dt) - E_stop(xi_exec, b_r),
        H_risk=H_risk, H_energy=H_energy, version=++ver)
    return plan, cert

def max_feasible(f, lo, hi):
    """单调谓词二分：返回最大满足 f 的整数 H；无解返回 lo-1"""
    if not f(lo):
        return lo - 1
    while lo < hi:
        mid = (lo + hi + 1) // 2
        if f(mid): lo = mid
        else:      hi = mid - 1
    return lo
```

```python
@dataclass
class EnergyContract:
    E_stop: float          # 最坏情景最小安全停能量 (J)
    E_margin: float        # 安全裕度 (J)
    SoC_min: float         # 最低可用 SoC

    Recheck_period: float  # 契约复核周期 (s)

class EnergyContractMonitor:
    def __init__(self, contract, eeq, shield):
        self.C = contract
        self.eeq = eeq
        self.shield = shield
        self.committed = []        # 在途分块的 E_chunk^max（开环承诺即占用）
        self.violations = []

    def reserve_margin(self):
        return (self.eeq.available_energy() - sum(self.committed)
                - E_stop(self.eeq.xi_exec, self.b_r))

    def admit_chunk(self, cert):
        if self.reserve_margin() - cert.E_max < self.C.E_margin:
            self._log("reserve_violation", cert); return False, "reserve_violation"
        if self.eeq.soc < self.C.SoC_min:
            self._log("soc_below_min", cert); return False, "soc_below_min"
        if cert.E_max > self.C.P_max * cert.H * DT:
            self._log("power_peak", cert); return False, "power_peak"
        self.committed.append(cert.E_max)
        return True, "ok"

    def release_chunk(self, cert):
        self.committed.remove(cert.E_max)

    def check(self):
        if self.eeq.soc < self.C.SoC_min or self.reserve_margin() < self.C.E_margin:
            return False, "DEGRADE_ENERGY"
        return True, "ok"

    def _log(self, kind, cert):

                                'E_max': cert.E_max, 'soc': self.eeq.soc})
```

```python
class EnergyFingerprintInference:
    """能量残差 = 已付费的观测，用于环境/负载/效率的对账与信息型分块"""

    def likelihood(self, r_E, h):
        # 各假设预测的能耗不同 → 残差似然
        return gaussian_pdf(r_E, loc=0.0, scale=self.sigma_E(h))

    def information_gain(self, plan, cert):
        # 期望信息增益 I_E(π) = E_r[ KL(p(h|r,π)||p(h)) ]
        preds = {h: self.predict_energy(plan, h) for h in self.H}
        return mutual_information(self.H, preds, self.sigma_E)

    def voi_e(self, plan, budget):
        e_min = budget.min_energy_for_task(plan)
        extra = max(0.0, plan.E_chunk - e_min)     # 只有额外能耗计入探针成本
        return LAMBDA_I * self.information_gain(plan, plan.cert) - LAMBDA_E * extra

    def update_belief(self, belief, r_E, plan):
        for h in self.H:
            belief[h] = bayes_update(belief[h], self.likelihood(r_E, h))
        return belief             # 仅对账/加宽，不作为独立佐证
```
