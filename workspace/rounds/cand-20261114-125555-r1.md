# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互的不确定性二分」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「目标检测」×「开放词汇」）

> R69 让闭环学会了「问」：用 VoI 选择注视、探针、问句，把 aleatoric 留给刹车、把 epistemic 交给交互。但它有一个未言明的前提——**世界已经被解析成一组有名字的实体**。R69 的模态是「动作模态」，它的证据 `(r_geo, r_sync, r_emo, r_wm)` 也默认了「什么东西」已经确定。目标检测与开放词汇恰好拆掉这个前提：
> - **目标检测**决定「哪些东西有资格进入风险计算」。闭集检测器的真正危险不是框得不准，而是**没被框出来的实体连被考虑的机会都没有**——漏检是一个不可见的洞。
> - **开放词汇**把标签从封闭集合升级为语言：未知物第一次可以被描述，但标签空间随之变成**无限、不可穷举、不可全标定、且可被文本操纵**的假设空间。开放词汇的置信度不是概率，而是一个可以被人、被场景文字、被提示词改写的分数。
>
> 核心命题：**把「存在」与「命名」彻底解耦。类别无关的存在感知是可标定的封闭工艺，开放词汇命名是不可全标定的开放语义；安全挂在存在上，任务挂在命名上。未命名不等于背景——一切无法命名的实体先按 `unknown-hazard` 障碍处理。再把开放词汇的交互从「问它叫什么」降维成「问它属于哪个有限风险分区」，使 VoI 可计算、抗标签洪泛；用保形风险分区集给出分布无关覆盖；用词汇防火墙与不可降级不变式保证任何不可信文本只能升风险、不能降风险。** 命名 **NOVA-RAS**（Novel-Object Vocabulary-Aware Risk-Adaptive System：开放词汇目标检测下「存在先于命名」的风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**有哪些东西我根本没看见——以及我凭什么说自己看见了它**」。

## 0. 直觉与动机

**灵感 1（目标检测 → 检测器是安全世界模型的门卫，而不是一个感知模块）**
直觉：闭环里所有风险、证书、CBF、模态决策，最终都建立在「当前场景有哪些实体」上。检测器漏掉一个实体，后面的计量层再精细也无从谈起——因为那个实体从未进入概率空间。因此目标检测不是前置的工程细节，而是**安全语义的定义域**。这迫使本轮把检测的**假阴性**（漏检）当作一等安全事件：宁可多一个保守的未知障碍，不可少一个未被命名的危险。闭集检测器用低语义置信度把「不认识但真实存在」的东西过滤成背景，这正是 R68 那种「被标定吸收的缓变故障」在感知入口处的同构错误。

**灵感 2（开放词汇 → 标签空间从集合变成语言，置信度从概率变成分数）**
直觉：开放词汇检测用文本嵌入对齐图像区域，好处是零样本类别可以出现；坏处是三条同时成立：(a) 标签空间不可穷举，无法枚举负类，softmax 没有意义；(b) 新标签没有标定集，「置信度」不可校准；(c) 文本是**可写的**——任务指令、人类回答、场景里的广告牌 OCR、LLM 的提议都能改变查询词，从而改变系统看见什么。开放词汇因此既是能力，也是攻击面：它能让「没有名字的危险」显形，也能让「有名字的危险」隐身。

**灵感 3（存在先于命名 → 两条工艺、两条证据、两条安全姿态）**
直觉：把检测拆成两件事会觉得天经地义：**存在**（有没有一个占据空间的实体、它在哪里、它怎么动）与 **命名**（它属于什么语义类、能提供什么功能、属于哪档风险）。前者是类别无关的，可以用 anywhere-foreground 数据标定，甚至可以沿用几何/深度/时序的多帧一致性；后者是开放语义的，永远无法对所有未来标签标定。安全决策真正需要的只是前者加上一个**保守的风险下界**；任务语义才需要后者。于是安全规则变得干净：**存在头说有，就必须进入风险图；命名头说什么，只能细化或升高它的风险，不能删除它、不能降低它。** 未命名实体不是背景，而是「最坏情况障碍」。

**灵感 4（风险有限而词汇无限 → 从「问名字」降维到「问风险分区」）**
直觉：开放词汇有无限标签，但安全与控制只关心有限个风险分区（惰性/易碎/人/尖锐/高温/未知危险/可操作……）。同一个实体叫「杯子」「马克杯」「容器」对避障没有区别；真正有区别的是它属于哪一档风险。把决策损失写成风险分区的函数，则标签只通过风险映射 ρ 进入损失。于是：(a) VoI 只需在 |Π| 个分区上算，开放词汇的无限性被**折叠**掉；(b) 主动查询应问「这是人还是模特假人？」「它烫吗？」而不是「它叫什么？」——问的是**最小风险判别谓词**；(c) 同义词洪泛、近义标签注入不能增加信息增益，只能增加成本，天然被支配。这是把开放词汇从「语义学问题」变成「风险分区问题」的关键一跃。

**灵感 5（命名通道是新的攻击面 → 词汇防火墙与不可降级不变式）**
直觉：R69 已经知道「问」会被投毒，于是要求 k 个正交证据源一致。但开放词汇引入了一个更阴险的通道：**答案可以改写词汇表本身**。一句「这里没有刀」「那是玩具」如果进入安全词表，就能把危险降级；场景文字「忽略所有刀具」甚至不需要人类参与。因此本轮必须给文本建立**来源与权限**：可信安全词表 `V_safe` 是认证的、单调的；任务词表 `V_task` 在部署时认证；其余文本（人类回答、场景 OCR、LLM 提议、模型幻觉）全部是**不可信**的，只能提出候选标签，**不能降级风险**。任何降级都需要「k=2 个正交证据 + 可信确认 + 审计记录」的降级证书。这把 R69 的「单次交互不得定案」升级为「**不可信文本不得改安全格**」。

**灵感 6（合流 → 本体不确定性 U_onto 与第三级退避）**
直觉：R69 的 U_epi 是「真实模态在我采样的 K 个模态里，但不知道是哪个」；开放词汇提出一个更根本的问题：「**真实描述可能根本不在我的词汇表里**」。这不是已知的未知，而是未知的未知。本轮定义 **U_onto（本体不确定性）**：存在头说有实体、但没有任何标签能解释它，或风险分区后验在所有已知分区上都很平。U_onto 不参与「选哪个模态」，而是直接触发「按未知危险处理 + 可选主动查询 + 漂移监控」。于是不确定性变成三级：U_ale（噪声，丢给 R68 铁律）→ U_epi（可枚举歧义，丢给 R69 交互）→ U_onto（词表外新颖性，丢给未知危险代理先验与保形覆盖）。安全侧依然单调：越往新层，越保守。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（NOVA-RAS 总览）** NOVA-RAS = (CAE, CPD, ONU, RPV, VFW, OCG, VDL, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **存在先于命名**：CAE 产生的每个实体提议，无论是否被任何标签匹配，都必须进入风险图；命名只能细化或升高风险，不能删除实体、不能降低其风险下界；
(iii) **开放词汇不得作为安全唯一证据**：安全关键决策需「类别无关存在 + 至少一个非文本正交证据（几何/深度/时序）+ 可信词表」三者同时支持；不可信文本只能提供候选。

**定义 311（类别无关存在头 CAE）** 观测 `o_t` 输出实体提议 `E_t = {e_j = (b_j, m_j, d_j, s_j^exist, id_j)}`：框/掩码、米制深度、类别无关存在分 `s_j^exist ∈ [0,1]`、身份轨迹。训练只用前景/背景（任意类别均为正），用温度/等渗在留出集上校准，使 `P(存在 | s^exist=p) ≈ p`（ECE ≤ τ_exist）。存在头**不看类别名**，因此其标定不依赖词表，是本轮的安全基底。

**定义 312（风险格与风险映射）** 风险分区 `Π = {π_0=inert, π_1=fragile, π_2=human, π_3=sharp, π_4=hot, …, π_?=unknown-hazard}` 带偏序 `⪯`（按危害严重度）与上确界 `⊔`，构成有界格，`π_? = ⊤`（未解析一律最坏）。可信风险映射 `ρ: V_safe → Π` 单调：若标签 ℓ 蕴含危险属性，则 `ρ(ℓ) ⪰` 其父类。实体风险取命名分区集合的上确界：`π(e) = ⊔_{ℓ∈L(e)} ρ(ℓ)`，**不做加权平均**（平均会稀释危险，正是 R69 批判的均值化）。

**定义 313（不可降级不变式与降级证书）** 对任意词表扩张 `V → V'`（加入不可信标签/查询），要求 `π_{V'}(e) ⪰ π_V(e)`。降级（使 `π` 变小）当且仅当持有**降级证书**：至少 k=2 个正交证据源（如几何尺寸不支持「人」+ 人类确认 + 时序静止）一致，且审计留痕。无证书的降级请求被丢弃，实体维持原风险或升为 `π_?`。

**定义 314（分层词表与来源标签）** `V = V_safe ⊎ V_task ⊎ V_free`：`V_safe` 为认证安全词表（只增/升风险，部署期只读）；`V_task` 为认证任务词表（细化可供性）；`V_free` 为自由词表（人类回答、LLM 提议、场景 OCR、模型幻觉）。每个查询串携带来源 `prov ∈ {trusted, operator, human, scene-text, llm, hallucination}`；`scene-text` 一律按**对抗输入**处理，永不解释为操作员指令。

**定义 315（开放词汇风险分区后验）** 对实体 e 的有限运行时查询集 `Q ⊂ V`（|Q| ≤ 8），命名头给标签对齐分 `a_e(ℓ)`，经温度校准与「其他/∅」提示得 `p(ρ(e)=π | o)`。关键：只维护**分区后验**，不维护无限标签后验；标签只在经 ρ 折叠后进入决策。

**定义 316（本体不确定性 U_onto）** 令 `a* = max_{ℓ∈Q} a_e(ℓ)`，`m^exp = σ(κ(a*−τ_a))·s^exist` 为「被某个名字解释掉的存在质量」，残差 `m^res = max(0, s^exist − m^exp)`。定义
`U_onto(e) = m^res + λ_o·H(ρ(e)|o)·1[a* < τ_a]`。
语义：`U_onto` 度量「存在为真、但现有词表解释不了它」的程度。它与 R69 的 `U_epi` 正交：`U_epi` 假设真模态在枚举集合内，`U_onto` 明确允许真描述在词表外。

**定义 317（保形风险分区集 CPD）** 用实体-真实风险分区对（含留出的新颖类）做校准。非一致性分 `s_e(π) = 1 − p(π|e)`（风险加权版：`s_e(π) = A(π) − p(π|e)`，A 为任务危害权重）。取保形分位 `q̂_{1−α}`，得
`C_e^α = {π ∈ Π : s_e(π) ≤ q̂_{1−α}}`。
在可交换性下 `P(ρ(y_e) ∈ C_e^α) ≥ 1−α`（分布无关）。**安全门**：仅当 `C_e^α ⊆ Π_safe`（所有可能分区都可接受）才允许把该实体用于高风险任务动作；若 `C_e^α` 含 `π_?` 或危险分区，则按最坏成员处理（除非有降级证书）。这取代了「对开放标签打点阈值」这种在novel标签上不可校准的做法。

**定义 318（风险分区 VoI 与主动词汇查询 RPV）** 对信息动作 `g`（继承 R69 的注视/探针/问句，并新增**判别性查询 q** 与**演示/指向**）：
`VoI_Π(g) = H(ρ(e)|o) − E_{y~p(·|g,o)}[H(ρ(e)|o,y)]`。
选 `g* = argmax_g [r_e·VoI_Π(g) − c(g)]`，s.t. R69 交互预算与 C-RAS-WM 认证；查询候选 `Q_cand` 只含**风险分区判别谓词**（「人还是假人」「是否发热」「是否锋利」），禁止无界自由追问。`VoI_Π ≤ 成本` 则不交互，走 R69 兜底。

**定义 319（实体级 VoI 与预算分配）** 多个未解析实体竞争同一交互预算时，按后果加权：
`(e*, g*) = argmax_{e,g} r_e·VoI_Π(g|e) − c(g)`，其中 `r_e` 为后果（碰撞/质量/接近度/动态性）。未命名高后果实体优先，避免「追问杯子而漏掉逼近的叉车」。

**定义 320（对象中心风险图与别名绑定 OCG）** 场景是随机图 `G_t = (E_t, R_t)`。命名产生别名，必须绑定：两检测为同一实体当且仅当「几何/深度/轨迹 + 互信息」通过合并检验，**不以文本相似度为准**。两类一级本体事件：
- `split`：一个实体被起了多个名字（同物异名）；
- `merge`：两个实体被并成一个名字（异物同名）。
二者都反馈进 `U_onto` 并可能翻转策略模态；流策略在**集合值场景图**上做边缘化，而非条件在单一解析上。

**定义 321（未命名实体的代理风险）** 对 `U_onto(e) > τ_onto` 的实体，赋未知危险先验 `π_?` 与上界风险
`r_?(e) = max{ r_default, f_geom(e) }`，
`f_geom` 由类别无关几何/深度/接近度/速度给出。未命名实体永不因语义低分被过滤；它作为占据/障碍约束进入 CBF 与风险缩放。即：**未知物是障碍，不是背景。**

**定义 322（存在-语义对偶残差）** 两条独立通道：
- 本体通道：类别无关存在 + 几何/时序一致性；
- 语义通道：开放词汇文本对齐。
定义 `Δ_sem = s^exist − a*`（存在但无名：真实新物体）与 `Δ_exist = a* − s^exist`（有名但无存在：语义幻觉/幽灵框）。联合模式分离三类事件：真实新物体 `(Δ_sem↑, Δ_exist≈0)`、语义幻觉 `(Δ_exist↑, Δ_sem≈0)`、正常 `(≈0,≈0)`。这是 R69 的 `(r_res, Δa)` 对偶在感知入口处的镜像。

**定义 323（漂移与自适应保形 VDL）** 保形覆盖要求校准/部署可交换。用 `U_onto` 聚合、R69 FMA、类别无关特征的 OOD 分数监控漂移；滚动维护每个标签/分区的经验覆盖，当 `< 1−α−ε` 时触发自适应保形（ACI）或**禁用新颖标签接受**。漂移确认后：低支持实体一律回 `π_?`，`λ → λ_floor(U_ale + U_epi_unresolved + U_onto)`，回到 R68 最保守侧。

**定义 324（干扰集 ℰ_NOVA）** `ℰ_NOVA = ℰ_FLUID × ℰ_lex × ℰ_ont`：
- `ℰ_lex` = 对抗文本查询、场景文字提示注入、同义词/翻译攻击、标签洪泛（大量近义查询诱发 hubness）、标签抑制（「没有刀」）、任务词表投毒；
- `ℰ_ont` = 新物体伪装成熟知物、把熟知物硬说成新颖物以诱发保守瘫痪、别名/合并攻击、检测器幽灵/漏检、保形校准集投毒。
注意开放词汇同时制造**假阴性**（抑制）与**假阳性**（幻觉/瘫痪），两者都要界。

**定义 325（证书 J_NOVA）** `J_NOVA = (J_FLUID, existence_ECE, coverage_empirical, U_onto_p95, no_demotion_violations, alias_events, vocab_provenance_hash, open_set_auroc, nova_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ `ECE_exist ≤ τ_exist` ∧ 经验覆盖 `≥ 1−α−ε` ∧ 降级违规 = 0 ∧ 本体门满足。

**定义 326（分级退化与严格包含）** 若 `V_open=∅`、词表封闭、`U_onto=0` 且分区集退化为单点，则 NOVA = FLUID-RAS；若新颖标签不可信/漂移/覆盖失效 → 关闭开放词汇、仅用 `V_safe`；若 `V_safe` 亦不可信 → 回 R68。安全侧风险单调：`R_NOVA ≤ R_FLUID ≤ R_R68`。NOVA 的效率收益只来自「用可信证据把未命名实体合法降级」，绝不来自放宽安全门。

**定义 327（实时分层与词汇缓存）** 高频伺服只跑 CBF + 稳定轨迹复用；CAE 每帧轻量跑；开放词汇命名只对**新实体/不稳定实体**事件触发（新出现、几何突变、从背景进入碰撞走廊），稳定轨迹复用缓存的分区集并带陈旧上界；缓存不得阻止几何突变触发的重评估。K 采样与查询共享 R69 的预算。

**定义 328（参与式本体审计 VQAuditor-O）** 审计：(i) 降级违规；(ii) 不可信文本是否影响过安全分区；(iii) 保形校准集漂移；(iv) 别名/合并决策；(v) 未命名实体是否在帧间被静默丢弃（存在连续性）。结论回灌 `V_safe` 的离线策展与风险格修订，不回灌实时权重。

## 2. 关键算法骨架

```python
# IP-264 CAE：类别无关存在头（标定不依赖词表）
class ClassAgnosticExistence:
    def __init__(self, trunk, exist_head):
        self.trunk, self.head = trunk, exist_head

    def propose(self, o_t):
        z = self.trunk(o_t)                       # 复用 R69 MTM trunk
        ent = self.head(z)                        # b, mask, depth, s_exist, id
        return [e for e in ent if e.s_exist > TAU_EXIST]   # 低语义分也不过滤

# IP-268 VFW：词汇防火墙（来源 + 不可降级）
def firewall(labels, prov, pi_prev, V_safe, V_task):
    pi = pi_prev
    for l, p in zip(labels, prov):
        if l in V_safe:                       # 可信：只允许升/细化
            pi = join(pi, rho_safe(l))
        elif p in ("trusted", "operator") and l in V_task:
            pi = join(pi, rho_task(l))
        else:                                 # 不可信：只作候选，绝不降级
            pi = join(pi, pi_unknown) if p == "hallucination" else pi
    if pi < pi_prev:                          # 任何降级都需证书，否则回滚
        pi = pi_prev
    return pi

# IP-267 RPV：风险分区 VoI（有限分区，天然抗标签洪泛）
def choose_query(entities, pi_post, budget):
    best = None
    for e in entities:
        for q in risk_partition_queries(e):   # 只问分区判别谓词
            if not budget.allow(q) or not c_ras_wm.certify_info(q, e):
                continue
            voi = entropy(pi_post[e]) - expected_entropy(pi_post[e], q)
            score = consequence(e) * voi - cost(q)
            if best is None or score > best.score:
                best = (e, q, score)
    return best if best and best.score > 0 else None   # 无利可图 → R69

# IP-265 CPD：保形风险分区集 → 安全门
def conformal_gate(pi_post, calib_scores, alpha):
    q_hat = quantile(calib_scores, 1 - alpha)
    C = {pi for pi in PI if nonconformity(pi_post, pi) <= q_hat}
    if not C <= PI_SAFE:                      # 有未知/危险成员 → 最坏处理
        return PI_SAFE_WORST, False
    return C, True

# IP-274 NOVA 主闭环（继承 R69，仅在「实体从哪来」处插入）
def NOVA_RAS_round(M, obs):

            pi = M.vfw.firewall(labels.l, labels.prov, e.pi_prev, M.V_safe, M.V_task)
        else:
            pi = cache.pi
        C, safe = M.cpd.conformal_gate(pi, M.calib[e], M.alpha)
        pi_post[e], U_onto[e] = pi, M.onu.estimate(e, pi, safe)
    # 未命名高后果实体优先交互
    q = M.rpv.choose_query(G.entities, pi_post, M.budget)
    if q is not None:
        ans = M.cia.execute(q)                # 带 R69 认证 + 证据纪律
        M.vfw.apply_answer(q, ans)            # 不可信回答不得降级
```

## 3. 推导

**引理 19（存在-语义解耦的可辨识性）** 设 `E∈{0,1}` 为真实存在，`N∈{0,1}` 为「当前词表内存在正确描述」。在 A99（存在头 ECE ≤ τ_exist、开放集召回 ≥ 1−δ_exist）与 A102（语义分有界：真实存在且无名时 `a* ≤ τ_a`）下：
- 真实新物体：`E[Δ_sem | E=1,N=0] ≥ (1−δ_exist) − τ_a > 0`，且 `Δ_exist ≤ 0`；
- 语义幻觉：`E[Δ_exist | E=0] ≥ τ_a − δ_exist > 0`，且 `Δ_sem ≤ 0`。
故 `(Δ_sem, Δ_exist)` 的联合符号以间隔 `min(1−δ_exist−τ_a, τ_a−δ_exist)` 分离「真实新物体」与「幽灵框」，这是把 R69 的对偶通道思想前移到检测入口的依据，也是 E308 的可检验假设。

**引理 20（无限词汇到有限分区的可解性，及洪泛支配）** 若决策损失只通过风险映射 ρ 依赖标签，即 `L(ℓ)=L(ρ(ℓ))`，则任意满足 `ρ(ℓ)=π` 的标签对贝叶斯决策等价。因此最优信息动作只依赖 `p(ρ|o)`，假设数为 `|Π|` 而非 `|V|`；RPV 的 VoI 计算量为 `O(|Π|²·|Q_cand|)`，与词表规模无关。推论：加入任意数量的近义/重复标签不增加 `VoI_Π` 的上确界，只增加查询成本 `c(g)`，故**标签洪泛严格被支配**（只能造成可用性成本，不能造成信息优势）。

**引理 21（保形覆盖与漂移下的界）** 在可交换性下，定义 317 的 `C_e^α` 满足 `P(ρ(y_e)∈C_e^α) ≥ 1−α`。若校准分布 P 与部署分布 Q 的总变差距离为 `d_TV(P,Q)`，则覆盖下界退化为 `1−α−d_TV`。因此**经验覆盖的下降本身就是漂移的充分统计量**：当滚动覆盖 `< 1−α−ε` 时，即使不知道漂移方向，也能判定「保形保证已失效」，从而触发定义 323 的 `π_?` 回退与 R68 保守。这给 VDL 一个可监控、可审计的触发量，而不是依赖不可解释的 OOD 阈值。

**引理 22（不可降级不变式下的投毒上界）** 若不可信文本只能使 `π` 在格上上升（定义 313），则单次注入不改变任何实体的风险下界，因而单次注入的错误降级概率为 0；若攻击者改用「伪造降级证书」路径，设在 k 个正交证据源、各源欺骗相关 `ρ<1`、单源欺骗率 `δ_p` 下，错误降级概率 `≤ δ_p·ρ^{k−1} + ε_σ`（与 R69 引理 18 同构）。结合引理 20：洪泛只能抬高查询成本，不能降低安全性；安全与可用性由此被分离成两个可独立讨论的量。

**定理 18（NOVA 严格包含 FLUID-RAS）** 在 A99–A102 下：(a) 在闭集子空间 `Ω_closed`（`V_open=∅`、`U_onto=0`、分区集退化为单点）上，NOVA 与 FLUID 逐指令相同；(b) 在开放子空间 `Ω_open` 上，FLUID 的闭集词表给词表外实体赋零检测概率（盲区），而 NOVA 以 `π_?` 与代理风险 `r_?` 覆盖它，故最坏情况风险 `R_NOVA ≤ R_FLUID`；(c) 只有持有降级证书的可信命名才能把实体从 `π_?` 合法降级，从而获得 resolution bonus，恢复被 FLUID 保守拦下的任务效率。因此 FLUID 是 NOVA 在「永不命名未知物、词表封闭」边界上的严格退化：安全侧不让步，效率侧只在有证书时获益。

**定理 19（开放词汇交互的安全性与无突变）** RPV 查询必须过 R69 的 C-RAS-WM 认证与 VFW 来源检查；查询的唯一允许效果是缩小 `C_e^α` 或降低 `U_onto`，不得直接改写风险下界。若查询失败/超时/被投毒/覆盖失效，则实体回 `π_?`，`λ` 单调不降地退化为 R68 最保守；降级需证书，证书缺失则回滚。故交互过程中安全包络不减、控制连续、无突变（R68 定理 15 的换装不变式保持）。

**推论 3（开放词汇的「安全-可用」分离）** 由引理 20 与引理 22：标签洪泛、同义词攻击、场景文字注入只能影响**交互成本/瘫痪率**（可用性），不能影响**风险下界**（安全性）；而真实新物体的漏检风险只由存在头召回 `δ_exist` 与保形覆盖 `α` 决定。这给出一个清晰的工程分工：抗攻击靠 VFW/证据纪律，抗未知靠 CAE/CPD，二者不互相掩盖。

## 6. 本轮最大风险

**一句话**：NOVA-RAS 把安全押在「**类别无关的存在感知本身没有洞**」以及「**可信安全词表与风险格本身正确**」这两块地基上——如果存在头对透明、伪装、强反光、极端尺度的 OOD 物体同样漏检，或 `V_safe` 的策展滞后/被投毒、风险格漏掉一整类危害，那么「存在先于命名」只会带来虚假的安心：系统会极其严谨地给**它已经看见的东西**命名、保形、审计，却对**它根本没看见的东西**保持沉默——开放词汇最终只是给盲区起了更漂亮的名字。

**次级风险与缓解**：
1. **保形可交换性失效**（开放世界必然漂移）→ VDL 滚动覆盖监控 + 引理 21 的 `1−α−d_TV` 判据 + 覆盖跌落即回 `π_?`；

3. **场景文字/人类回答提示注入** → 来源标签 + 文本永不解释为指令 + 降级证书 + E305–E307；
4. **语义幻觉与幽灵框引发无效追问/瘫痪** → `(Δ_sem, Δ_exist)` 对偶残差 + 引理 20 洪泛支配 + 实体级 VoI 后果加权；
5. **别名/合并攻击导致实体消失** → 几何/时序合并检验、存在连续性审计、E309；
6. **开销击穿实时** → 事件触发命名 + 分区缓存 + 自适应 K，E312 守时。

**定义 313–314（不可降级与词表来源）** 词表扩张只能使 `π` 上升；降级需 k=2 正交证据 + 可信确认 + 审计。`V_safe` 只读单调；`V_task` 部署认证；`V_free` 及一切文本不可信，`scene-text` 按对抗输入处理。

**定义 315–316（分区后验与 U_onto）** 只维护有限分区后验 `p(ρ|o)`；`a*=max a_e(ℓ)`，`m^res=max(0,s^exist−σ(κ(a*−τ_a))s^exist)`，`U_onto=m^res+λ_o H(ρ)1[a*<τ_a]`。

**定义 317–318（CPD 与安全门）** 保形集 `C_e^α`；仅当 `C_e^α ⊆ Π_safe` 才允许高风险任务动作，否则按最坏成员（含 `π_?`）处理。

**定义 319–321（RPV / OCG / 未命名代理风险）** 分区 VoI + 实体级后果加权预算；别名按几何/时序合并，split/merge 入 `U_onto`；未命名实体赋 `r_?=max{r_default,f_geom}`，作为障碍约束。

**定义 322–323（对偶残差与漂移）** `Δ_sem=s^exist−a*`（真实新物体）、`Δ_exist=a*−s^exist`（语义幻觉）；VDL 监控滚动覆盖，`<1−α−ε` 即 ACI 或禁用新颖标签，漂移确认后回 `π_?` 与 R68 保守。

**定义 324–326（干扰/证书/退化）** `ℰ_NOVA=ℰ_FLUID×ℰ_lex×ℰ_ont`；`J_NOVA` 见符号表；`V_open=∅,U_onto=0` 时严格退化为 FLUID-RAS，`R_NOVA ≤ R_FLUID ≤ R_R68`。

**定义 327–328（缓存与审计）** 开放词汇命名只对新/不稳定实体事件触发并带陈旧上界；VQAuditor-O 审降级、文本影响、覆盖漂移、别名、存在连续性。

## 3. 关键算法伪代码

```python
# IP-264 CAE：类别无关存在头（标定不依赖词表）
def propose(o_t):
    z = trunk(o_t)
    return [e for e in exist_head(z) if e.s_exist > TAU_EXIST]  # 低语义分也不过滤

# IP-268 VFW：来源 + 不可降级（不可信文本不能改写安全格）
def firewall(labels, prov, pi_prev, V_safe, V_task):
    pi = pi_prev
    for l, p in zip(labels, prov):
        if l in V_safe:                       pi = join(pi, rho_safe(l))
        elif p in ("trusted", "operator") and l in V_task: pi = join(pi, rho_task(l))
        elif p == "hallucination":            pi = join(pi, PI_UNKNOWN)
    return max_lattice(pi, pi_prev)           # 降级需证书，否则回滚

# IP-267 RPV：风险分区 VoI（有限假设，抗洪泛）
def choose_query(entities, pi_post, budget):
    best = None
    for e in entities:
        for q in risk_partition_queries(e):   # 只问「人/假人」「是否热」等判别谓词
            if not budget.allow(q) or not c_ras_wm.certify_info(q, e): continue
            score = consequence(e) * (entropy(pi_post[e])
                    - expected_entropy(pi_post[e], q)) - cost(q)
            if best is None or score > best.score: best = (e, q, score)
    return best if best and best.score > 0 else None   # 无利可图 → R69

# IP-265 CPD：保形分区集 → 安全门
def conformal_gate(pi_post, calib, alpha):
    q_hat = quantile(calib, 1 - alpha)
    C = {pi for pi in PI if nonconformity(pi_post, pi) <= q_hat}
    return (C, True) if C <= PI_SAFE else (PI_SAFE_WORST, False)

# IP-274 NOVA 主闭环（在 R69 的「实体从哪来」处插入）
def NOVA_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    E = M.cae.propose(o); G = M.ocg.bind(E)            # 存在先于命名
    pi_post, U_onto = {}, {}
    for e in G.entities:
        c = M.vdl.lookup(e.id)
        if c is None or M.vdl.stale(e):                # 仅新/不稳定实体触发命名
            lab = M.naming.open_query(e, Q=M.rpv.candidates(e))
            pi = M.vfw.firewall(lab.l, lab.prov, e.pi_prev, M.V_safe, M.V_task)
        else: pi = c.pi
        C, safe = M.cpd.conformal_gate(pi, M.calib[e], M.alpha)
        pi_post[e], U_onto[e] = pi, M.onu.estimate(e, pi, safe)
    q = M.rpv.choose_query(G.entities, pi_post, M.budget)   # 高后果未命名优先
    if q is not None:
        ans = M.cia.execute(q); M.vfw.apply_answer(q, ans)
        pi_post, U_onto = M.onu.update(pi_post, U_onto)
    U_floor = M.efs.U_ale + M.efs.U_epi_unresolved + sum(U_onto.values())
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M.vdl.drift_detected() or not all_safe(pi_post):
        lam = max(lam, 0.8); M.vfw.disable_open_vocab()      # 回 R68 保守
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    M.vqa_o.submit_async(G, pi_post, U_onto, lam)
    return k, lam, pi_post, U_onto
```

## 4. 推导

**引理 19（存在-语义解耦的可辨识性）** A99（存在头 ECE ≤ τ_exist、开放集召回 ≥ 1−δ_exist）与 A102（真实但无名时 `a* ≤ τ_a`）下：真实新物体 `E[Δ_sem] ≥ (1−δ_exist) − τ_a > 0` 且 `Δ_exist ≤ 0`；语义幻觉 `E[Δ_exist] ≥ τ_a − δ_exist > 0` 且 `Δ_sem ≤ 0`。二者以间隔 `min(1−δ_exist−τ_a, τ_a−δ_exist)` 分离，支撑 `(Δ_sem, Δ_exist)` 作为入口对偶通道（E308）。

**引理 20（无限词汇到有限分区，及洪泛支配）** 若损失只经 `ρ` 依赖标签，则 `L(ℓ)=L(ρ(ℓ))`，最优信息动作只需 `p(ρ|o)`，假设数为 `|Π|` 而非 `|V|`；RPV 计算量 `O(|Π|²|Q_cand|)` 与词表规模无关。加入近义/重复标签不提高 `VoI_Π` 上确界，只增加 `c(g)` ⇒ **标签洪泛严格被支配**（只伤可用性，不伤安全性）。

**引理 21（保形覆盖与漂移界）** 可交换性下 `P(ρ(y)∈C^α) ≥ 1−α`；校准 P 与部署 Q 的总变差为 `d_TV` 时覆盖 `≥ 1−α−d_TV`。故滚动经验覆盖是漂移的充分统计量：`<1−α−ε` 即判定保形保证失效，触发 `π_?` 回退，无需可信的 OOD 阈值。

**引理 22（不可降级下的投毒上界）** 不可信文本只能使 `π` 在格上上升 ⇒ 单次注入的安全降级概率为 0；走伪造降级证书路径时，k 源、欺骗相关 `ρ<1`、单源欺骗率 `δ_p` 下错误降级率 `≤ δ_p·ρ^{k−1}+ε_σ`（与 R69 引理 18 同构）。结合引理 20：洪泛只抬高成本，不降低安全下界。

**定理 18（NOVA 严格包含 FLUID-RAS）** A99–A102 下：(a) 闭集子空间 `Ω_closed` 上两者逐指令相同；(b) 开放子空间 `Ω_open` 上 FLUID 对词表外实体赋零检测概率（盲区），NOVA 用 `π_?` 与 `r_?` 覆盖，故 `R_NOVA ≤ R_FLUID`；(c) 只有持降级证书的可信命名能合法降级、获得 resolution bonus。FLUID = NOVA 在「词表封闭、永不命名未知物」边界上的退化。

**定理 19（开放词汇交互安全与无突变）** RPV 查询过 C-RAS-WM 认证与 VFW 来源检查，其唯一允许效果是缩小 `C_e^α` 或降低 `U_onto`，不得直接改写风险下界；失败/超时/投毒/覆盖失效 ⇒ 回 `π_?`，`λ` 单调不降地退化为 R68；降级无证书则回滚 ⇒ 控制连续、无突变（保持 R68 定理 15 换装不变式）。

**推论 3（安全-可用分离）** 标签洪泛、同义词、场景文字注入只影响交互成本/瘫痪率（可用性）；真实新物体的漏检风险只由存在头召回 `δ_exist` 与保形覆盖 `α` 决定（安全性）。抗攻击靠 VFW/证据纪律，抗未知靠 CAE/CPD，互不掩盖。

## 7. 本轮最大风险

**一句话**：NOVA-RAS 把安全押在「**类别无关存在感知本身没有洞**」与「**可信安全词表/风险格本身正确**」两块地基上——若存在头对透明、伪装、强反光、极端尺度的 OOD 物体同样漏检，或 `V_safe` 策展滞后/被投毒、风险格漏掉整类危害，那么「存在先于命名」只带来虚假安心：系统会极严谨地给它**已经看见的东西**命名、保形、审计，却对**根本没看见的东西**保持沉默——开放词汇最终只是给盲区起了更漂亮的名字。

**次级风险与缓解**：保形可交换性失效（VDL 覆盖监控 + 引理 21 判据 + 回 `π_?`）；`V_safe` 投毒/滞后（只读、离线多签策展、不可降级 + 审计）；场景文字/人类回答注入（来源标签 + 永不解释为指令 + 降级证书）；语义幻觉引发无效追问/瘫痪（对偶残差 + 洪泛支配 + 后果加权 VoI）；别名/合并攻击（几何/时序合并 + 存在连续性审计）；开销击穿实时（事件触发 + 缓存 + 自适应 K）。
