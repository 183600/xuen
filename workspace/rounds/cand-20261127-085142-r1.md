### 第 1 轮灵感驱动研究记录

**灵感词**：快速原型、预测性维护

**直觉与动机**：
v25 的 SRC-USC 已把证书做成「七证一体」，但它隐含两个静态假设：(A) 设计对象 D 在认证后冻结，证书是一次性断言；(B) 物理本体健康度恒定，证书永不过期。现实中机器人恰在两个方向上高速变化：快速原型让设计以天甚至小时为单位迭代，预测性维护揭示关节磨损、电池衰减、标定漂移会随时间吃掉同一份证书的裕度。受「快速原型」启发，证书应像编译产物一样由 CAD/仿真流水线自动生成，并在设计增量 Δ 上做「增量重编译」——只重验受影响的依赖子树，同时附赠局部鲁棒半径；受「预测性维护」启发，证书应带到期时间（validity horizon），把健康状态 h(t) 与 RUL 的 conformal 下界纳入准入，并在裕度下降时对计划做降额（derating）。核心洞见：**证书不是一次性静态证明，而是有寿命、可被编译与再认证的时变资产；设计迭代重编译它，物理退化稀释它，维护复位则要求它整体重建。**

**形式化目标**：
1. 定义快速原型证书（RPC）：证书编译器 F:(D,spec)→C(D) 附带假设依赖图 G=(V,E)，每个原子约束带归一化裕度 μ_i 与 Lipschitz 常数 L_i；证明若同拓扑类且 ‖δ‖_𝒟 ≤ ρ(D)=min_i μ_i/L_i，则 C(D+δ) 仍成立。
2. 定义预测性维护证书（PMC）：健康状态 h(t)、退化动力学 ḣ=f(h,u)+w、conformal RUL 下界；证书有效期 τ=min(τ_sched,τ_RUL,τ_drift)，保证 ℙ(μ(t')≥0, ∀t'∈[t,t+τ])≥1-γ。
3. 定义证书可信衰减与降额算子 η(h)：裕度下降时对计划降额，保持 μ(D,h,η(h)π)≥0，而不是直接拒证。
4. 构建时态生命周期统一准入门（TLC-USC）：SRC-USC ∪ RPC ∪ PMC 九证一体；Exec_v26(t)=Exec_v25 ∩ Fil_rp ∩ Fil_pm(t) ⊆ Exec_v25。
5. 用悲观健康包络 h̄(t)（单调不增）证明时态单调收缩 Exec_v26(t2)⊆Exec_v26(t1)（t2≥t1，且无维护复位事件）。
6. 桥接两个灵感：设计变更落在 ρ(D) 内时退化模型可迁移；超出则强制重校准以恢复 conformal 交换性，定义联合可迁移半径 min(ρ_design, ρ_health)。

## 1. 关键算法骨架（在 IP-444–447 骨架上扩展）

```python
# ============================================================
# IP-448 Rapid Prototyping Certificate (RPC) — 快速原型证书
# ============================================================
@dataclass
class DesignSpec:
    params: Tensor                 # 连续设计参数（连杆长度/壁厚/晶格密度…）
    topology: 'CellComplex'        # 离散拓扑（模块/孔洞/连接图）
    material: 'MaterialSpec'
    topology_class: str            # 同伦/同胚类标识，判断能否局部重认证

@dataclass
class CertificateAtom:
    name: str                      # 如 "SOC.stress" / "FCC.passivity" / "LSC.buckling"
    margin: float                  # 归一化裕度 μ_i，≥0 即满足
    lip_const: float               # L_i = sup‖∂μ_i/∂D‖
    depends_on: set[str]           # 依赖的设计原语

@dataclass
class RapidPrototypingCertificate:
    design: DesignSpec
    spec: 'TaskSpec'
    atoms: dict[str, CertificateAtom] = field(default_factory=dict)
    dep_graph: 'DependencyGraph' = None

    def compile(self) -> bool:
        """全量证书编译：CAD+仿真 → 原子裕度 + 依赖图"""
        self.atoms = {}
        for atom in self.spec.required_atoms:      # 复用 v25 的 SOC/FCC/LSC/USMC/SMC/RMC/MCC
            mu, lip, deps = atom.evaluate(self.design)
            self.atoms[atom.name] = CertificateAtom(atom.name, mu, lip, deps)
        self.dep_graph = DependencyGraph.from_atoms(self.atoms)
        self.compile_ok = all(a.margin >= 0 for a in self.atoms.values())
        return self.compile_ok

    def certified_perturbation_radius(self) -> float:
        """ρ(D) = min_i μ_i / L_i：仍能保证所有原子裕度非负的最大设计球"""
        rho = float('inf')
        for a in self.atoms.values():
            if a.margin < 0:
                return 0.0
            if a.lip_const > 0:
                rho = min(rho, a.margin / a.lip_const)
        return max(rho, 0.0)

    def incremental_reverify(self, delta: 'DesignDelta') -> tuple[bool, DesignSpec]:
        """只重验 delta 触达的依赖子树；拓扑类改变则全量重编译"""
        new_design = self.design.apply(delta)
        if new_design.topology_class != self.design.topology_class:
            self.design = new_design
            return self.compile(), new_design       # 拓扑跳变：Lipschitz 论证失效
        touched = self.dep_graph.affected(delta.primitives)
        for name in touched:
            mu, lip, _ = self.spec.atom(name).evaluate(new_design)
            if mu < 0:
                return False, new_design
            self.atoms[name].margin, self.atoms[name].lip_const = mu, lip
        ok = self.verify_untouched(new_design, delta)
        self.design = new_design
        return ok, new_design

    def verify_untouched(self, new_design, delta) -> bool:
        """未重验原子由 Lipschitz 局部鲁棒性兜底：μ_i(D+δ)≥μ_i(D)-L_i‖δ‖≥0"""
        dn = delta.norm()
        for name in self.dep_graph.untouched(delta.primitives):
            a = self.atoms[name]
            if a.margin - a.lip_const * dn < 0:
                return False
        return True


# ============================================================
# IP-449 Predictive Maintenance Certificate (PMC) — 预测性维护证书
# ============================================================
@dataclass
class HealthState:
    h: Tensor                      # 归一化健康向量 ∈[0,1]^d
    timestamp: float
    confidence: Tensor             # 各分量置信半宽

@dataclass
class DegradationModel:
    f: Callable                    # ḣ=f(h,u,t)，名义退化动力学
    bound: Callable                # 认证退化上界，产出悲观包络
    lip_design: float              # f 对设计参数的 Lipschitz 常数
    version: str                   # 退化模型版本（与设计版本绑定）

@dataclass
class PredictiveMaintenanceCertificate:
    health: HealthState
    degradation: DegradationModel
    rul_conformal: 'ConformalRUL'  # 给出 RUL 的 (1-γ_RUL) 下界
    gamma: float = 0.05
    derate: 'DeratingPolicy' = None
    last_cert_t: float = 0.0
    horizon: float = 0.0

    def certified_health_envelope(self, t: float) -> HealthState:
        """h̄(t)≤h(t) 的单调不增下界：取认证退化上界，禁止乐观外推"""
        if t <= self.health.timestamp:
            return self.health
        return self.degradation.bound(self.health, t - self.health.timestamp)

    def compute_validity_horizon(self, plan) -> float:
        tau_sched = self._margin_crossing_time(plan)          # μ(t)=0 的预测时刻 × 安全系数
        tau_rul = self.rul_conformal.lower_bound(self.health)  # conformal 下界
        tau_drift = self._drift_detector.time_to_ood()        # 分布漂移到达时间
        self.horizon = min(tau_sched, tau_rul, tau_drift)
        return self.horizon

    def verify_at(self, t: float, plan) -> bool:
        if t > self.last_cert_t + self.horizon:               # 证书过期
            return False
        h_bar = self.certified_health_envelope(t)
        pi_derated = self.derate.apply(plan, h_bar)           # 健康感知降额
        return self._margins_nonnegative(h_bar, pi_derated)

    def _margin_crossing_time(self, plan) -> float:
        """在悲观包络上二分/解析求最早 μ(t)=0 时刻，并乘安全系数 κ<1"""
        lo, hi = self.last_cert_t, self.last_cert_t + self.max_horizon
        for _ in range(64):
            mid = 0.5 * (lo + hi)
            if self._margins_nonnegative(self.certified_health_envelope(mid), plan):
                lo = mid
            else:
                hi = mid
        return self.safety_factor * (lo - self.last_cert_t)

    def _margins_nonnegative(self, h_bar, plan) -> bool:
        return min(a.margin(h_bar, plan) for a in self.margin_atoms) >= 0


# ============================================================
# IP-450 TLC-USC 时态生命周期统一准入门
# ============================================================
@dataclass
class TemporalLifecycleUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    rpc: RapidPrototypingCertificate
    pmc: PredictiveMaintenanceCertificate
    recert: 'RecertificationPolicy'

    def admits_at(self, t: float, multi_plan, sensor_data, **kw) -> bool:
        # 1) v25 七证（语义/重构/协同/结构力学…）
        if not self.src_usc.admits(multi_plan, sensor_data, **kw):
            return False
        # 2) 原型证书：已编译、当前设计未越出鲁棒半径
        if not self.rpc.compile_ok:
            return False
        if self.rpc.certified_perturbation_radius() <= 0.0:
            return False
        # 3) 维保证书：未过期、降额后裕度非负
        if not self.pmc.verify_at(t, multi_plan):
            return False
        # 4) 到期/漂移/复位未完成 → 拒绝执行，等待重认证
        if self.recert.is_due(t, self.pmc, self.rpc):
            return False
        return True

    def on_maintenance_reset(self, event: 'ResetEvent') -> bool:
        """维护复位：只允许显式事件抬高 h̄，且必须整体重建证书"""
        if event.kind not in {'replace', 'recalibrate', 'overhaul'}:
            return False
        self.pmc.health = event.new_health
        self.pmc.last_cert_t = event.t
        self.rpc.compile_ok = self.rpc.compile()          # 复位后全量重编译
        self.pmc.rul_conformal.recalibrate(event.calib_set)
        self.pmc.compute_validity_horizon(self.pmc.current_plan)
        return self.rpc.compile_ok
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| RPC 全量编译 | O(|V|·c_atom)，c_atom 为单原子（如 FEM）代价 | O(|V|) 原子 + O(|E|) 依赖边 | |V|≤200 |
| RPC 增量重认证 | O(|affected(Δ)|·c_atom + |untouched|) | O(|Δ|) 增量 | 典型 \|affected\|≤0.1\|V\| |
| RPC 鲁棒半径 | O(|V|) | O(1) | — |
| PMC 悲观包络 | O(d·N_step) 数值积分，解析时 O(d) | O(d) 健康状态 | N_step≤1000 |
| PMC 有效期 | O(64) 二分 × O(|margin_atoms|) | O(1) | 64 次迭代 |
| PMC conformal RUL | O(log n_cal) 分位查询 | O(n_cal) 校准集 | n_cal≤10⁴ |
| TLC-USC 准入 | v25 关键路径 + O(|Δ| + log n_cal) | +O(|V|+n_cal) | 增量近似 O(1) |
| 端到端单步（增量） | +O(|affected|) ~ +1–3ms；拓扑跳变例外 +O(|V|·c_atom) | +O(|V|) | 50Hz 控制环内可接受 |

**实时性说明**：稳态下 RPC 命中缓存、PMC 有效期与包络增量更新，关键路径只在设计修订或临近到期时出现毫秒到秒级尖峰；因此 TLC-USC 把「重认证」做成异步流水线，执行侧只消费带时间戳的证书句柄。

## 3. 正确性论证（增量）

### 引理 13（RPC 局部可靠性）
**陈述**：设各原子裕度 μ_i 在设计度量 d_𝒟 下 L_i-Lipschitz，且 D 与 D+δ 属同一拓扑类。若 C(D)=True 且 ‖δ‖_𝒟 ≤ ρ(D)=min_i μ_i/L_i，则 C(D+δ)=True。
**证明**：对每个原子，μ_i(D+δ) ≥ μ_i(D) − L_i‖δ‖_𝒟 ≥ μ_i(D) − L_i·ρ(D) ≥ 0。所有原子非负即 C(D+δ)=True。∎
**反例说明**：拓扑类改变时结论可失效（例如承力孔被删去使应力集中跳变），故算法显式检测 topology_class 并退回全量编译，这是该引理的适用边界而非缺陷。

### 引理 14（PMC 有效期可靠性）
**陈述**：设 (a) conformal RUL 下界以概率 ≥1−γ₁ 覆盖真值；(b) 悲观包络满足 h̄(t)≤h(t) 以概率 ≥1−γ₂；(c) 各裕度对健康退化单调不增（假设 A1）。则 ℙ(∀t'∈[t,t+τ], μ(D,h(t'),η(h̄(t'))π)≥0) ≥ 1−γ₁−γ₂。
**证明**：在事件 (a)∧(b)（概率 ≥1−γ₁−γ₂，联合界）下，τ≤τ_RUL 保证真 RUL 未到，τ≤τ_sched 与 A1 保证包络上裕度不先穿越零，故区间内降额计划的裕度始终非负。∎
**注**：A1 不成立时（某些裕度随退化反而增大）不再声称单调，退回逐时点复核，弱化但不破坏安全性。

### 引理 15（时态单调收缩）
**陈述**：若在相邻两次维护复位之间对任意 t2≥t1 有 h̄(t2)≤h̄(t1)（分量序），则 Exec_v26(t2) ⊆ Exec_v26(t1) ⊆ Exec_v25。
**证明**：Exec_v26(t)=Exec_v25∩{π: RPC(D)∧PMC(t,D,π)}。由 μ 对 h 单调（A1）及降额 η 不增，h̄ 下降只会使可接纳计划集缩小；RPC 与 t 无关，故交集单调收缩；再由定义 Exec_v26(t)⊆Exec_v25。∎
**复位处理**：T_reset 处的 h̄ 跳升是唯一允许执行集扩张的入口，且必须经 on_maintenance_reset 全量重编译与重校准，故「扩张」不等于「绕过验证」。

### 引理 16（设计-健康跨版本可迁移性）
**陈述**：若设计增量 ‖δ‖_𝒟≤ρ(D) 且 ‖∂f/∂D‖≤L_f，则退化预测偏差被 O(L_f·ρ(D)·τ) 界定；据此定义 ρ_health=γ_margin/(L_f·τ)。当 ‖δ‖_𝒟≤min(ρ(D),ρ_health) 时，RPC 与 PMC 可同时免于全量重认证；否则必须重校准以恢复 conformal 交换性。
**证明**：由 f 的 Lipschitz 性与 Grönwall 不等式得健康轨迹偏差上界，再经 μ 的 Lipschitz 性转成裕度偏差，令其不超过预留安全裕度 γ_margin 即得 ρ_health。∎

### 定理（TLC-USC 九证生命周期完备性）
**陈述**：对任意时刻 t 与多机计划 Π，`TLC-USC.admits_at(t,Π)=True` ⟺ Π 同时满足 v25 的十项条件，外加：
(11) 原型可编译性：全部原子裕度非负且同拓扑类内 ρ(D)>0；
(12) 维保时态有效性：t≤last_cert+τ，且降额后在悲观包络上裕度非负、未触发重认证。
**证明**：`admits_at` 为 v25 十项与 (11)(12) 的合取，充分性由各连言直接给出；必要性由任一条件缺失即返回 False，分别对应设计漂移、证书过期/健康衰减两类未被缓解的风险。结合引理 13–15，执行集满足 Exec_v26(t)⊆Exec_v25 并在无复位时随时序单调收缩。∎

## 4. 已知风险与缓解（增量）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R16 | 拓扑跳变/屈曲分岔使 μ 在设计度量下不 Lipschitz，局部重认证可能漏判 | 高 | 1) topology_class 变化强制全量编译；2) 对接近分岔的设计做特征值/屈曲跟踪并显式标红；3) 蒙特卡洛抽样做 soundness 回归 | 分岔点附近的临界设计仍可能出现「差之毫厘」的漏判 |
| R17 | RUL 分布漂移与维护后非交换性使 conformal 覆盖失效 | 高 | 1) 滑动窗口/加权 conformal 在线重校准；2) OOD 检测触发保守降额；3) 复位后强制重校准 | 全新失效模式（无历史样本）下覆盖率无保证 |
| R18 | 快速迭代下证书陈旧，执行侧消费到过期句柄 | 高 | 1) 证书带时间戳与哈希，执行前校验新鲜度；2) 重认证异步流水线 + 到期前主动吊销；3) 过期即回退 v25 保守计划 | 高频修订时重认证吞吐不足会造成大面积保守停机 |
| R19 | 「复位攻击」：换件/重标定重置健康计时器，但潜伏损伤未消除 | 高 | 1) 复位只抬升显式可测分量，不可测疲劳量用保守残差继承；2) 复位事件需双人/传感交叉确认；3) 审计日志不可篡改 | 隐患（如内部微裂纹）无法被外部传感器观测，包络可能高估健康 |
| R20 | 九证 × 时间维度的耦合保守性，使 Exec_v26(t) 加速收缩至空集 | 高 | 1) 风险预算在 RPC/PMC 间显式分配；2) 降额而非硬拒证，保留可执行降级方案；3) 预测性维护提前触发备件/检修调度 | 预测精度不足时降额过猛，任务可用率下降 |

## 6. 本轮最大风险（最终确认）

**一句话**：**快速原型的拓扑跳变会让 RPC 的 Lipschitz 局部论证在分岔点附近静默失效，而预测性维护的「复位」又会把不可观测的潜伏损伤从悲观健康包络中抹去——两者叠加时，证书可能被局部重编译与复位事件「合法地」刷新为有效，而真实裕度早已为负，时态证书本身反而成为最隐蔽的攻击面。**
