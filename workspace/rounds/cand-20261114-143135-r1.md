# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 1 轮；本轮灵感：「传感器融合」×「双臂协调」）

> R73 把证据计量做成了**可组合的契约**：EC 声明预算/通道/有效域/否决，CCA 用 SER/PAR/VETO 组合，热替换定理把「换实现不改系统」从实验希望升为定理，CPB 把体系蒸馏为三条可证伪主张。但 R73 的组合代数压在三个**未言明的独立性假设**上，本轮两个灵感正好把这三个假设逐一击穿：
> - **PAR 的独立性假设**：并联融合只在 pairwise 相关估计 |ρ̂|<ρ_max 时缩窄。可现实中多个传感器共享**同一物理世界**——同一盏灯、同一台 IR 投影器、同一张会振动的桌子、同一个温度场、甚至同一个被抓的物体。R73 末尾把「隐共享物理过程耦合」列为**最大风险的缓解项第 5 条**；双臂协调让这个「边缘风险」变成**默认工况**：两臂操作同一物体时，共因不是例外而是结构。
> - **反作用的自我指涉假设**：R73 的 χ_R 是「我的动作 → 我的噪声」。双臂共享工作空间时，A 为了看清而移动 → 遮挡 B 的相机 / 扰动 B 的接触 / 抢占同一物体 → **改变 B 的证据质量** → 改变 B 的动作 → 再反过来改变 A。χ_R 必须是**关系型** χ_R^{i→j}，而相互追逐证据质量会产生振荡、死锁或极限环。R73 的有限停止证明只覆盖单体的自反作用，不覆盖耦合系统。
> - **失效本地化假设**：R73 的 stub 让失效「只丢失该模态、零级联」。但两臂通过**物体**相连：A 的接触模块 stub 化（松手）会改变 B 的负载、力矩与滑动风险——失效沿着**物理对象**级联，而不沿着数据流级联。R73 的「零级联」在物理耦合下是**假命题**，必须重新表述为「数据流级联有界 + 物理级联受联合包络约束」。
>
> 核心命题：**当证据系统不再是一个孤立观察者，而是多个共享同一物理世界的行动者时，「可组合的独立证据」这一前提本身失效。** 本轮把 R73 的最大风险升格为**核心研究对象**，提出 **COUPLED-GAUGE**（COUpled evidence metrology with shared-cause GAUGE audits）——**共享世界耦合计量学**：
> - **CAF（Common-cause-Aware Fusion）**：把共因隐变量 ζ 显式建模，融合前先问「我们共享了什么」；给出融合收益的**硬上界**（引理 38）与三档融合语义（ζ 可观测 / 部分可识别 / 不可识别→保守协方差交集）。
> - **DAC（Dual-Arm Coordination contract）**：跨体反作用通道 χ_R^{i→j} + 耦合矩阵谱半径 ρ(K) + 弱耦合压缩定理 / 强耦合令牌协议（引理 40/41）。
> - **OME（Object-Mediated Evidence）**：共享物体是**物理审计器**——力闭合、静力平衡残差、无滑移给出确定性一致性约束；但平衡可被错误共享状态满足（规范自由），故必有外部锚点（引理 42）。
> - **耦合闭包与联合证书 J_COORD**：证明「一致性 ≠ 独立性」「证书不可借安全」；模块热替换的 O(模块) 承诺在共因主导时退化为 O(耦合闭包)——这是一个**诚实的负结果**，也是本轮最大的理论贡献边界。

## 0. 直觉与动机

**灵感 1（传感器融合 → 「同意」不等于「正确」）**
直觉：十台相机同时说「物体在 1.2 米」并不比一台更可信，如果它们共用同一块标定板误差、同一盏频闪灯、同一台 IR 投影器、或同一段错误的时钟。R73 的 PAR 融合把方差按 1/N 缩窄，这在**独立同分布噪声**下正确；但真实的多传感器系统里，误差有二阶结构：
`y_i = h_i(s, ζ) + ε_i`，ζ 是共享外因（照度、IR、温度、振动、物体位姿、标定漂移），ε_i 才是各源自有的噪声。
若忽略 ζ，把 y_i 当条件独立，融合方差会随着 N 增大无界下降，而真实可达到的下界被 ζ 的方差**钉住**。这给出一个漂亮的、可证伪的定量预测：定义共因占比 κ = σ_c²/(σ_c²+σ_e²)，则**无论加多少传感器，后验方差不会低于 κ 决定的平台**（引理 38）。所以正确的融合不是「更多源、更小方差」，而是先做**共因核算**：把 u² 分解为 u_common² + u_idio²，只在 idio 部分享受 1/N 收益，common 部分要么条件化（找到 ζ 的独立观测），要么原样保留（保守）。「共识陷阱」是双臂系统里最危险的认知错觉：两臂用同一套标定、看同一个被照亮的场景，它们「一致」恰恰可能是**共享了同一个错误**。

**灵感 2（双臂协调 → 反作用是关系，不是属性）**
直觉：单臂 Move-to-See 是「我动 → 我看得更清」。双臂是「我动 → 你被遮挡 / 你被我碰到 / 我们抢同一个物体」。把动作对证据质量的调制写成**耦合矩阵** K，其元素是 ∂(源 j 的噪声/有效域)/∂(臂 i 的动作) 的 Lipschitz 常数。于是「协调」有了一个精确定义：**让联合反作用映射成为一个有唯一不动点的压缩映射**（弱耦合，ρ(K)<1，引理 40），或者在强耦合（ρ(K)≥1）时用**令牌/角色不对称**打破对称，把双人互相追逐变成有先后的单人序列（引理 41）。这解释了一个工程现象：为什么两个都「主动感知」的机械臂会来回摆（A 让位看 B，B 又让位看 A）——那是耦合映射的 2-周期，不是调参问题，是**结构性的对称性**。令牌不是工程补丁，而是恢复压缩性的**结构契约**。

**灵感 3（共享物体 → 物理是最强的审计，也是会骗人的审计）**
直觉：两臂同时抓住一个刚性物体时，牛顿-欧拉方程给出一个**确定性**约束：两端的力/力矩、重力、加速度必须平衡；摩擦锥必须包含接触力；不能有相对滑移。这比统计 conformal 审计强，因为它把证据钉在**物理定律**上，而不是历史校准集上。但物理审计有一个致命的**规范自由**：如果两臂都对物体位姿有同样的整体偏移，而力仍平衡（例如平移不影响静力平衡，或均匀的外力偏置被控制器吸收），残差为零却状态错误。因此「物理平衡」是**必要非充分**：它排除不一致，但不能唯一确定状态；必须有独立于该耦合闭包的**外部锚点**（固定基准、第三视角、重力方向、已知支撑面）。这直接对应 R73 的「深度自标定自举」风险的升级版：**用物体审计物体**会形成闭环自欺。

**灵感 4（耦合闭包 → 模块化的边界在哪里）**
直觉：R73 的热替换定理说「同契约替换 ⇒ 系统性质保持，认证成本 O(模块)」。这条定理的证明只引用 EC。但引理 43 会构造一个反例：两个实现的总不确定度 u 相同、契约字段逐项相同，却对共因 ζ 的**敏感度 κ 不同**；替换后边缘 u 不变，但联合覆盖率崩掉。这说明 R73 的 EC **表达力不足**：它携带 u，却不携带 u 的**共因结构**。修法是给契约加 FC（融合契约）字段，并把认证单元从「模块」改为「耦合闭包」——所有通过 ζ 或物体或遮挡相互依赖的模块必须**成组认证**。代价是诚实的：热替换的 O(模块) 只在 κ≈0 时成立；κ→1 时闭包→全系统，模块化退化为单体。**「模块化在最需要它的地方失效」**——这句话是本轮要正面承认、并量化其边界的结论，而不是藏起来的风险。

**灵感 5（CPB v2 → 三条新主张，各自可隔离证伪）**
直觉：R73 的 C1/C2/C3 关心「物理感知计量 / 反作用预算 / 契约模块化」。本轮加三条，且每条都绑定一个**会让方案自己难堪**的对照：
- **C4（共因感知融合）**：在共因主导场景，CAF 的覆盖率与下游安全显著优于朴素 PAR；且**朴素 PAR 的覆盖率随源数 N 单调恶化**（可证伪的「共识陷阱」）。对照：朴素 PAR、协方差交集、单一最佳源。
- **C5（耦合反作用稳定）**：跨体通道 + 谱半径判据 + 令牌能把双臂证据追逐的振荡率降到阈值以下，且有限停止可证。对照：无令牌、固定增益、随机让位。可证伪点：若 ρ(K)≥1 而无令牌仍能稳定，则 C5 错。
- **C6（对象中介联合审计）**：物理平衡审计能捕获统计融合漏掉的共因故障，但单独使用会被规范自由欺骗；与独立锚点联用才能给出联合证书。对照：仅统计融合、仅物理审计、物理+锚点。可证伪点：若仅物理审计在对抗位姿偏移下仍 100% 正确，则 C6 的「必要非充分」被推翻。

## 1. 形式化定义（增量：定义 383–398）

**定义 383（COUPLED-GAUGE 总览）** COUPLED-GAUGE = (MMS†, CAF, DAC, OME, J_COORD, CPB†)。六不变式：
(i) **契约完整性**（继承 R73）：无契约不入图；
(ii) **耦合闭包完备**：每条融合边与物理耦合边都属于唯一一个显式声明的耦合闭包（定义 387），禁止跨闭包的隐性依赖；
(iii) **共因非负**：任何融合不得减少共因分量，收益只作用于特异性分量（定义 385、引理 38/39）；
(iv) **耦合反作用稳定**：联合反作用映射要么满足压缩条件 ρ(K)<1，要么运行在令牌协议下（定义 389）；未通过者不得进入认证稳态集；
(v) **联合否决**：共享物体的物理一致性被破坏时，对整个耦合闭包投非补偿否决票（定义 391），**证书不可借安全**（定义 392）；
(vi) **严格退化**：单臂、κ=0、无共享物体、平凡令牌时，逐指令等价于 R73 MODGAUGE；安全侧只增不减。

**定义 384（共因隐变量与条件独立模型）** 对证据源集合 S，状态 s，共因隐变量 ζ ∈ Z_ζ（照度、IR 投影、温度、振动、物体位姿、标定漂移）：
`y_i = h_i(s, ζ) + ε_i`，且 `ε_i ⟂ (s, ζ)`、`ε_i ⟂ ε_j`（给定 s, ζ）。
不确定度分解：`u_i² = u_{i,common}² + u_{i,idio}²`，其中 `u_{i,common}² = E_ζ[Var(h_i(s,ζ)|s)]`，`u_{i,idio}² = Var(ε_i)`。
**共因占比** `κ_i = u_{i,common}² / u_i²`；系统级 `κ = max_i κ_i`（或按闭包聚合）。**关键**：κ 是融合语义的必要输入；R73 的 EC 只携带 u，故对 κ 不可见——这正是引理 43 反例的根源。

**定义 385（共因感知融合算子 COMP-CAF）** n 元算子，按 ζ 的可识别性分三档：
- **R1（ζ 可观测）**：存在独立于 S 的环境观测 ζ̂（基准物、第三视角、独立光照/温度/振动传感器）。条件化后只融合特异性部分：`u_out² = u_prop(ζ̂)² + fuse_idio({u_{i,idio}}, ρ̂_idio)`，其中 `u_prop(ζ̂)` 为 ζ̂ 不确定度经 h 传播。
- **R2（ζ 部分可识别）**：对 (s, ζ) 做联合 MAP；用 Jacobian `J = ∂(h_i)/∂ζ` 的秩与 Fisher 信息判定可识别性；秩亏 ⇒ 降级到 R3。
- **R3（ζ 不可识别）**：保守分解 `u_out² = max_i u_{i,common}² + CI_fuse({u_{i,idio}})`（CI = 协方差交集，对任意相关性给出上界）；若 `max_i κ_i > κ_max`，额外投 `CAF_COMMON_DOMINATED` 指示并禁止下游把 u_out 当独立证据使用。
**溯源保持**：输出携带参与向量 π（源、权重、每源边际贡献）、ζ̂ 或 ζ 的不确定集、以及所用的融合档位——融合不得把多源压成一个无出处的标量。

**定义 386（融合契约 FC）** 扩展 EC：`FC = (EC, S_in, J_struct, Δt_budget, ζ_ref, byz_k)`：
- S_in：参与的源集合；
- J_struct：**联合结构**（协方差/因子图/高阶相关），而非仅边缘方差——这是与 R73 EC 的根本差别；
- Δt_budget：异步预算（定义 397）；
- ζ_ref：共因参考（独立观测或声明为「不可识别」）；
- byz_k：可同时容忍的故障源数（Byzantine 一致性，定义 394/398）。
FC 是融合节点入图的必填字段；缺 J_struct 或 ζ_ref 的融合节点按 R3 保守处理。

**定义 387（耦合闭包 C）** 定义依赖关系 `i ~ j` 当且仅当 (a) 共享 ζ 且 `κ_ij > κ_0`，或 (b) 通过同一物体/接触发生物理耦合，或 (c) 存在遮挡/时序耦合（i 的动作改变 j 的视角或光照）。**耦合闭包** `C(i)` 为该关系的传递闭包；所有闭包构成 V_M 的一个划分。**认证单元 = 闭包**，而非单模块。

**定义 388（跨体反作用通道 χ_R^{i→j}）** 对臂 i 的动作 a_i 与模块 j：`χ_R^{i→j}: a_i ↦ (θ_noise^j, D^j)`——我的动作如何调制**你的**噪声参数与有效域。联合映射 `χ_R^{1→N} = (χ_R^{i→j})_{i,j}`。**耦合矩阵** `K`，`K_ij = Lip(χ_R^{i→j})`；谱半径 ρ(K) 判定联合反作用的稳定性（引理 40/41）。χ_R^{i→i} 即 R73 的自我反作用。

**定义 389（协调不动点与令牌协议）** 联合势函数
`Φ(a) = Σ_i [−Progress_i(a) + λ_i·u_i(a) + c_reflex^i(a)] + Σ_{i≠j} P_ij(a)`，
其中 P_ij 编码互遮挡、IR 互扰、物体争用等耦合代价。**协调不动点**为 Φ 的局部极小（势博弈的纯 Nash）。
- **弱耦合**：若 ρ(K) < 1，则最佳响应映射是压缩的 ⇒ 唯一不动点（引理 40）；
- **强耦合**：若 ρ(K) ≥ 1，强制**令牌协议** T_τ：任一时刻只有一个臂持有「证据获取令牌」，另一臂在其承诺动作下做最佳响应；令牌按冻结-轮转或优先级发放。认证态只接受 T_τ 下的不动点（引理 41）。

**定义 390（对象中介证据 OME）** 对共享物体，观测 `y_obj = (各抓取点力/力矩, 滑移指示, 形变, 相对位姿)`。**物理残差**
`r_eq = || M(q)·q̈ + C(q,q̇) + g(q) − Jᵀf_ext ||`（或准静态时 `||g − Jᵀf||`），
外加力闭合裕度（接触力在摩擦锥内）与无滑移条件。OME 的计量分量：`u_obj² = u_compliance² + u_sensor_bias² + u_unmodeled²`。注意：r_eq 是**确定性约束残差**，不是似然——它审计一致性，不提供 s 的完整后验。

**定义 391（联合物理一致性审计 JPA 与联合否决）** JPA 通过当且仅当：力闭合 ∧ `r_eq ≤ ε_model` ∧ 无滑移 ∧ 存在**单一** `(ŝ_obj, ζ̂)` 使所有参与臂的 OME 残差同时落在模型误差内。否则触发 `COMP-JVETO`：对**整个耦合闭包**非补偿否决（不允许「另一只臂说没事」来抵消）。**外部锚点** `A_ext`（固定基准/第三视角/重力方向/已知支撑面）在 `rank(∂r_eq/∂s) < dim(s)`（规范自由）时是必需的，见引理 42。

**定义 392（联合证书 J_COORD 与联邦闭合）** `J_COORD = (⊗_{C∈Closures} J_C) ⊗ J_CAF ⊗ J_token ⊗ J_OME`，其中 `J_C = (⊗_{i∈C} J(module_i)) ⊗ J_coupling(C)`。有效性要求**闭包级重认证**，而非模块级。
**不可借安全**：`Valid(J_COORD)` 只对每个模块**自身**的安全包络给出保证；跨臂共享约束的安全量是闭包内所有臂的 `inf`（最弱环节），不得把 A 的裕度借给 B。
**联邦顺序**：证书集合 {J_i} 在闭包 C 下**联合可采纳**当且仅当预算闭合、ζ_ref 一致、J_struct 相容、令牌协议可执行；否则必须合并为更大的闭包或拒绝。

**定义 393（耦合感知退化 E-IVG²）** 区分两类级联：
- **数据流级联**：由 EC 预算否决约束，继承 R73 定理 29，有界；
- **物理级联**：经共享物体传播（A 的接触 stub→松手→B 负载突变→滑移）。受**联合安全包络**与**力重分配可行性**约束，不再无条件为零。
**协调退化阶梯**：L0 全功能 → L1 减少冗余源（保留锚点）→ L2 单臂安全保持（另一臂支撑/让位）→ L3 受控释放物体 → L4 急停。每级声明转移条件、力重分配方案与最坏执行时间。**物理零级联条件**：阶梯转移可行 ∧ 联合包络不越界 ∧ 力重分配解存在（定理 32）。

**定义 394（共识陷阱与融合收益上界）** 模型 `y_i = s + ζ + ε_i`，`s~N(0,σ_s²)`，`ζ~N(0,σ_c²)`，`ε_i~N(0,σ_e²)`，N 个条件独立源。则
`Var(s | y_1..y_N) = [1/σ_s² + 1/(σ_c² + σ_e²/N)]^{-1} ≥ σ_s²σ_c²/(σ_s²+σ_c²)`，
故 N→∞ 的后验方差平台由 σ_c² 决定，**不趋零**。若误当 ζ=0 做独立融合，声称方差 `[1/σ_s² + N/σ_e²]^{-1} → 0`，过度自信比可无界增长。**共存故障**：若 k 个源被同一攻击/同一偏置劫持（Byzantine 共识劫持），一致性检查反而会把它们当作「多数真值」；故 FC 必须声明 byz_k，并对「一致性来源是否共享 ζ」做溯源。

**定义 395（双臂基准 DBench）** 最小、可复现、预注册：
- **DB1 共因融合**：受控照度/IR/振动/温度 × N 源，测 κ 辨识、覆盖率、共识陷阱；
- **DB2 协调反作用稳定**：共享工作空间互遮挡，测 ρ(K)、振荡率、令牌 vs 无令牌；
- **DB3 对象中介审计**：柔顺/刚性物体、滑移、规范自由反例、外部锚点消融；
- **DB4 对抗**：共因伪造、共识劫持、令牌抢占、物体位姿欺骗。
各 ≤3 小时单卡（DB3 可用 CPU/小臂仿真）可复现；固定种子 + 预注册脚本 + 密封保持集 SEAL-DB。

**定义 396（耦合认证成本）** `CertCost_coord = Σ_C Σ_{i∈C}(SEAL_i + conformal_i) + Σ_C J_coupling(C) + J_CAF + J_token + J_OME`。
C6/负结果的可证伪形式：测量**闭包占比** `γ = max_C |C|/|V_M|`。κ→0 ⇒ γ→O(1/|V_M|)（模块化成立）；κ→1 或物体强耦合 ⇒ γ→1（模块化退化为单体）。报告 `CertCost_coord / CertCost_single` 随 κ 的曲线，而非只报最优工况。

**定义 397（时序对齐与延迟预算）** 各源时间戳 t_i，偏斜 `Δ_ij = |t_i − t_j|`。外推引入 `u_time ≥ L_v·Δ`（L_v 为状态速度 Lipschitz 界），并可能引入**时间共因**（同一物理事件在不同时刻被不同源看到）。FC 的 Δt_budget 规定容许偏斜；超预算 ⇒ 降权/重加权/该源 stub，禁止静默外推。融合方差须加 `u_time²`。

**定义 398（对抗威胁面 ℰ_coord）** ℰ_coord = {共因伪造（打光/加热/振动使多源同错）, 共识劫持（k 源同偏置）, 令牌抢占/重放, 物体位姿欺骗（施加外力使平衡残差仍小）, 时钟欺骗（制造假异步）}。防线：独立锚点 A_ext、溯源参与向量 π、byz_k 一致性、令牌认证、时序单调性校验、单源不定案（继承 R73 原则）。

# IP-303 CAF：共因感知 n 元融合（三档语义）
def caf_fuse(sources, s_prior, zeta_obs=None, kappa_max=0.5):
    us   = [s.u for s in sources]
    kappa= [s.kappa for s in sources]                 # u_common²/u²
    u_com= [s.u * math.sqrt(s.kappa) for s in sources]
    u_idio=[s.u * math.sqrt(1 - s.kappa) for s in sources]

    if zeta_obs is not None:                          # R1：ζ 可观测，条件化
        u_prop = propagate_zeta(zeta_obs, sources)    # 经 h 传播的 ζ̂ 不确定度
        u_id   = fuse_idio(u_idio, corr=sources[0].rho_idio)
        u_out  = math.hypot(u_prop, u_id); regime = 'R1'
    else:
        J = common_cause_jacobian(sources)            # ∂h/∂ζ
        if matrix_rank(J) >= zeta_dim(sources):       # R2：部分/完全可识别
            s_hat, z_hat, cov = joint_map(sources, s_prior)
            u_out, regime = math.sqrt(cov), 'R2'
        else:                                         # R3：不可识别 → 保守 CI
            u_out = math.hypot(max(u_com), ci_fuse(u_idio))
            regime = 'R3'
    veto = {'CAF_COMMON_DOMINATED'} if max(kappa) > kappa_max else set()
    return Ev(u=u_out, regime=regime, kappa=max(kappa),
              participation=participation_vector(sources),   # 溯源 π
              D=intersect_domains(sources), veto=veto)

# IP-304 DAC：耦合反作用谱半径判据 + 令牌
def coordinate(arms, K, phi, budget):
    rho = spectral_radius(K)
    if rho < 1.0:                                     # 弱耦合：压缩 -> 唯一不动点
        a = banach_iterate(lambda a: best_response(phi, a), a0=arms.state,
                           L=rho)                       # 几何收敛
        return a, 'CONTRACTIVE'
    else:                                             # 强耦合：令牌化打破对称
        token = acquire_token(arms, policy='freeze_rotate')
        a_i = best_response(phi, arms.other.frozen_action) if token.holder == i else arms.other.frozen
        return commit(a), 'TOKENIZED'                 # 只在 T_τ 下认证

# IP-305 OME：对象中介联合物理审计
def joint_physical_audit(arms, y_obj, anchor=None, eps_model=1e-2):
    r_eq   = newton_euler_residual(arms, y_obj)
    close  = force_closure(y_obj, friction_cones=arms.cones)
    noslip = not slip_detected(y_obj)
    J      = deq_ds(arms, y_obj)
    gauge  = matrix_rank(J) < state_dim(arms)         # 规范自由 -> 需外部锚点
    consistent = close and noslip and (r_eq <= eps_model)
    if gauge:
        consistent = consistent and anchor is not None and anchor_consistent(anchor, arms)
    if not consistent:                                # 对整个闭包联合否决（非补偿）
        return JVETO(scope=closure_of(arms), reason='JPA_FAIL', gauge=gauge)
    return OME_EVIDENCE(r_eq=r_eq, gauge=gauge, anchor_used=gauge, u=ome_uncertainty(y_obj))

# IP-306 J_COORD：联邦证书（按耦合闭包认证）
def J_COORD(closures, module_certs, fc_edges, token, ome):
    certs = []
    for C in closures:                                # 认证单元 = 闭包
        assert all(budget_closed(*e) for e in internal_edges(C, fc_edges))
        assert zeta_ref_consistent(C) and J_struct_compatible(C)
        certs.append(tensor(module_certs[i] for i in C) ⊗ coupling_cert(C))
    assert token.is_certified() and ome.is_valid()
    return tensor(certs) ⊗ fusion_cert(fc_edges)      # 不可借安全：只保证各自包络

# IP-307 耦合感知退化阶梯
LADDER = ['L0_FULL','L1_REDUCE_REDUNDANCY','L2_SINGLE_ARM_HOLD',
          'L3_RELEASE_OBJECT','L4_EMERGENCY_STOP']

           joint_envelope_ok(closure, level) and \
           force_redistribution_exists(closure, level):

    return 'L4_EMERGENCY_STOP'

def COUPLED_round(A, B, obs, depth_imgs, tacs, y_obj, budget):
    # 感知域：各臂证据 + 共因观测
    ev = {arm: gather_evidence(arm, depth_imgs[arm], tacs[arm], obs) for arm in (A,B)}
    zeta_obs = environment_anchor()                   # 独立环境观测（可为 None）
    # 计量域
    fused = caf_fuse(list(ev.values()), A.s_prior, zeta_obs)     # IP-303
    closures = compute_closures(ev, A.mreg, B.mreg)             # 定义 387
    ome = joint_physical_audit((A,B), y_obj, anchor=external_anchor())  # IP-305
    if ome.is_veto: return safe_hold(A, B, ome)                 # 联合否决 -> L2/L3
    a, mode = coordinate((A,B), estimate_K(A,B), joint_potential, budget)  # IP-304
    if mode == 'TOKENIZED': A,B = apply_token((A,B), a)
    if not budget.ok(): return degrade(closures, 'BUDGET')
    # 控制域（只读快照 + 联合证书）
    commit = safe_execute((A,B), a)
    return commit, J_COORD(closures, {arm: cert(arm) for arm in (A,B)}, fc_edges(ev), token, ome)

## 3. 推导

**引理 38（共因融合收益上界）** 在定义 394 的线性高斯模型下，任意对 N 个条件独立（给定 s, ζ）源的线性融合都满足 `Var(s|y_{1:N}) ≥ σ_s²σ_c²/(σ_s²+σ_c²)`；当 N→∞ 时趋于该平台，而不趋于 0。系：**「加传感器」不能突破共因决定的信息地板——这是 C4 的定量核心，也是「共识陷阱」的数学形式。**

**引理 39（CAF 的保守性与覆盖）** R3 档用 `u_out² = max_i u_{i,common}² + CI_fuse(u_idio)`，对任意真实相关结构 `ρ ∈ [−1,1]` 给出不小于真实后验方差的估计（协方差交集的保守性 + 共因分量不下调）。故在 ζ 不可识别时覆盖率 ≥ 名义 1−α；代价是可能过度保守。相对地，忽略 ζ 的朴素 PAR 在 κ>0 时覆盖率随 N 单调下降。系：**CAF 用保守性换取「不会自信地错」——这正是安全侧只增不减的体现。**

**引理 40（弱耦合压缩与协调不动点）** 若耦合矩阵 `ρ(K) < 1`，最佳响应映射在联合动作空间上是压缩映射，由 Banach 不动点定理存在唯一协调不动点，迭代几何收敛，配合 ΣREFLEX 预算给出有限停止。系：**弱耦合下双臂主动感知不需要令牌，自然收敛；ρ(K) 是可测的设计量，而非玄学调参。**

**引理 41（强耦合的 2-周期与令牌消解）** 当 `ρ(K) ≥ 1` 且两臂势函数对称时，存在对称最佳响应的 2-周期（构造：A 让位以观察 B 的遮挡区，B 同时让位观察 A 的遮挡区，状态往复）。引入令牌 T_τ 后，未持牌臂的动作冻结为承诺值，联合映射退化为单臂压缩映射，唯一不动点恢复，有限停止成立。系：**令牌不是工程补丁，而是强耦合下恢复压缩性的结构契约；C5 的可证伪点即「无令牌仍稳定」。**

**引理 42（物理一致性的必要非充分与规范自由）** `r_eq=0` 是真实共享状态的必要条件；但当 `rank(∂r_eq/∂s) < dim(s)` 时存在一族 `s′ ≠ s` 使 `r_eq(s′)=0`（如整体平移、均匀外力偏置、特定对称位姿）。故 JPA 单独不足以定案，必须有独立锚点 `A_ext` 使增广 Jacobian 满秩。系：**「物理审计最强」是错觉——它只排除不一致，不唯一确定世界；物体审计自己会自举。**

**引理 43（耦合闭包下的热替换界限）** 设 impl 与 impl′ 的 EC 逐字段相同、边缘 u 相同，但共因占比 `κ ≠ κ′`。则替换后边缘融合不变，联合覆盖率改变；存在参数使 `Valid(J_MOD)` 仍真而联合违规概率上升。故必须有 FC 的 J_struct/κ 字段，且替换只在**同一耦合闭包内重新认证**时安全；认证成本从 O(模块) 变为 O(闭包)。系：**R73 的契约表达力对融合不足——它携带边缘，不携带共同命运；这是本轮最重要的修正。**

**引理 44（时序误差下界）** 若源 i 相对融合时刻偏斜 Δ，状态速度界为 L_v，则任何不建模该偏斜的融合估计满足 `u ≥ L_v·Δ`。故 Δt_budget 之外的外推必然引入不可消除的误差下界。系：**「异步融合」不是工程细节，而是计量契约的一个硬预算项。**

**定理 30（COUPLED-GAUGE 严格包含 R73）** 取单臂、κ=0（无边共因）、无共享物体（OME 平凡）、令牌平凡，则 CAF 退化为 R73 的 PAR（独立、可缩窄），DAC 退化为自我反作用，J_COORD 退化为 J_MOD；由定义 383(vi)，逐指令等于 MODGAUGE，再退化等于 EMBODIED/R71/R68。**安全单调不减。**

**定理 31（联合证书有效性 ⇒ 联合安全）** 若 `Valid(J_COORD)`（各闭包模块证书有效、FC 预算闭合、ζ_ref 一致、J_struct 相容、JPA 通过或带锚点、令牌协议可认证、ΣREFLEX 闭合），则在 A114（ζ 模型表达力）、A115（J_struct 校准不被对抗漂移）、A116（物理模型误差 ≤ ε_model）下，双臂联合执行风险 ≤ ε_coord。**证明重量落在：(a) ζ 是否被正确声明；(b) 规范自由是否被独立锚点消解；(c) 耦合矩阵估计是否覆盖最坏情况。** 三条任一不成立，定理只保证「证书自洽」，不保证「世界正确」。

**定理 32（耦合退化的有界性与零级联条件）** 数据流级联由 EC 否决有界（继承定理 29）。物理级联有界当且仅当退化阶梯转移可行 ∧ 联合安全包络不越界 ∧ 力重分配解存在；否则存在反例：A 的接触 stub 导致 B 负载突增、滑移、物体跌落。系：**R73 的「零级联」必须改写为条件命题；无条件零级联在物理耦合下是假的。**

**定理 33（共识陷阱的可证伪形式）** 在定义 394 下，朴素独立融合声称的方差随 N 以 1/N 下降，而真实后验受 `σ_c²` 平台约束；故覆盖率随 N 单调恶化，过度自信比可无界。C4 因此可被单个实验（DB1 增大 N）证伪或证实：若朴素 PAR 覆盖率不随 N 下降，则 C4 错。系：**好的主张必须能被自己的基准打脸——这是 CPB v2 的纪律。**

**一句话**：本轮的核心发现本身就是风险——**模块化的认证复利在耦合闭包处破产**：当共因 ζ 不可识别或共享物体把两臂绑成不可分解的闭包时，热替换定理只能保证「闭包内重认证」，认证成本从 O(模块) 退化为 O(闭包)，而闭包可能等于全系统；于是**在最需要模块化的耦合场景里，模块化恰恰退化为单体**。若为了保住 O(模块) 的宣传而把强耦合硬拆成独立模块，就会重现 R73 末尾警告的失败模式：所有证书有效、所有组合校验通过，系统却自信地组合出一个错误的世界。

次级风险与缓解：
1. **ζ 不可识别 / 模型表达不足** → R3 保守档 + 独立锚点 + 覆盖率监控；禁止在 ζ_ref 缺失时使用 R1/R2。
2. **共因占比 κ 估计漂移** → 在线 κ 监控 + κ 超阈自动降档 + SEAL-CommonCause 审计集；κ 作为一等可观测指标进入证书。
3. **令牌协议引入死锁/饥饿** → 令牌超时回退到 L2 单臂安全保持 + 优先级公平性证明；令牌状态进入证书。
4. **物理模型误差（柔顺、摩擦、未建模动力学）** → ε_model 在线辨识 + 柔顺物体降级到力控 + 残差监控触发联合否决。
5. **规范自由被误判为「已解决」** → 强制 `rank(∂r_eq/∂s)` 检查；无外部锚点时证书标注「条件有效」，不得用于安全关键判定。
6. **共识劫持绕过 byz_k** → 溯源参与向量 + 独立锚点交叉校验 + 单源不定案；k 值随闭包规模显式声明。
7. **DBench 过拟合 / 负结果被藏** → 预注册 γ(κ) 曲线与融合收益平台；三方复现；负结果（O(闭包) 退化）作为正文贡献而非附录。

# IP-303 CAF：共因感知 n 元融合（三档语义 + 溯源）
def caf_fuse(sources, s_prior, zeta_obs=None, kappa_max=0.5):
    u_com  = [s.u * math.sqrt(s.kappa) for s in sources]
    u_idio = [s.u * math.sqrt(1 - s.kappa) for s in sources]
    if zeta_obs is not None:                           # R1：ζ 可观测
        u_prop = propagate_zeta(zeta_obs, sources)
        u_out  = math.hypot(u_prop, fuse_idio(u_idio)); regime = 'R1'
    else:
        J = common_cause_jacobian(sources)             # ∂h/∂ζ
        if matrix_rank(J) >= zeta_dim(sources):        # R2：可识别
            _, _, cov = joint_map(sources, s_prior); u_out, regime = math.sqrt(cov), 'R2'
        else:                                          # R3：不可识别 → 保守
            u_out = math.hypot(max(u_com), ci_fuse(u_idio)); regime = 'R3'
    veto = {'CAF_COMMON_DOMINATED'} if max(s.kappa for s in sources) > kappa_max else set()
    return Ev(u=u_out, regime=regime, participation=participation_vector(sources),
              D=intersect_domains(sources), veto=veto)

# IP-304 DAC：谱半径判据 + 令牌（强耦合下恢复压缩性）
def coordinate(arms, K, phi, budget):

    if rho < 1.0:                                      # 弱耦合 → Banach 压缩

def joint_physical_audit(arms, y_obj, anchor=None, eps_model=1e-2):
    r_eq  = newton_euler_residual(arms, y_obj)
    close = force_closure(y_obj, arms.cones); noslip = not slip_detected(y_obj)
    J     = deq_ds(arms, y_obj); gauge = matrix_rank(J) < state_dim(arms)
    ok = close and noslip and (r_eq <= eps_model)
    if gauge:
        ok = ok and anchor is not None and anchor_consistent(anchor, arms)
    if not ok:
        return JVETO(scope=closure_of(arms), reason='JPA_FAIL', gauge=gauge)
    return OME_EVIDENCE(r_eq=r_eq, gauge=gauge, u=ome_uncertainty(y_obj))

# IP-306 J_COORD：按耦合闭包联邦认证（不可借安全）
def J_COORD(closures, module_certs, fc_edges, token, ome):
    certs = []
    for C in closures:
        assert all(budget_closed(*e) for e in internal_edges(C, fc_edges))
        assert zeta_ref_consistent(C) and J_struct_compatible(C)
        certs.append(tensor(module_certs[i] for i in C) ⊗ coupling_cert(C))
    assert token.is_certified() and ome.is_valid()
    return tensor(certs) ⊗ fusion_cert(fc_edges)

## 4. 推导

**引理 38（共因融合收益上界）** 线性高斯 `y_i=s+ζ+ε_i` 下，任意 N 源线性融合满足 `Var(s|y) ≥ σ_s²σ_c²/(σ_s²+σ_c²)`，N→∞ 趋于该平台。系：**加传感器不能突破共因信息地板；这是「共识陷阱」的数学形式，也是 C4 的定量核心。**

**引理 39（CAF 保守性）** R3 的 `max u_common² + CI(u_idio)` 对任意真实相关给出不小于真实后验方差的估计，覆盖率 ≥1−α；代价可能过度保守。忽略 ζ 的朴素 PAR 在 κ>0 时覆盖率随 N 单调恶化。系：**用保守性换「不会自信地错」。**

**引理 40（弱耦合压缩）** ρ(K)<1 ⇒ 最佳响应是压缩映射 ⇒ Banach 唯一不动点、几何收敛、配合预算有限停止。系：**弱耦合双臂主动感知无需令牌，ρ(K) 是可测设计量。**

**引理 41（强耦合 2-周期与令牌）** ρ(K)≥1 且势函数对称时存在 2-周期（互相让位观察对方遮挡区）；令牌冻结未持牌臂后联合映射退化为单臂压缩，唯一不动点与有限停止恢复。系：**令牌是强耦合下恢复压缩性的结构契约，不是调参。**

**引理 42（物理审计必要非充分）** r_eq=0 必要；若 `rank(∂r_eq/∂s)<dim(s)`（整体平移/均匀外力偏置/对称位姿），存在 `s′≠s` 使残差为零。故需 A_ext 使增广 Jacobian 满秩。系：**物理审计只排除不一致，不唯一确定世界；物体审计会自举。**

**引理 43（闭包热替换界限）** 同 EC、同边缘 u、不同 κ 的替换会改变联合覆盖率；存在参数使 `Valid(J_MOD)` 仍真而联合违规概率上升。故 EC 表达力不足，需 FC 的 J_struct/κ；替换仅在闭包内重认证安全，成本 O(模块)→O(闭包)。系：**R73 契约携带边缘，不携带共同命运——本轮最重要修正。**

**引理 44（时序误差下界）** 偏斜 Δ、速度界 L_v ⇒ 任何不建模偏斜的融合满足 u ≥ L_v·Δ。系：**异步是计量硬预算项。**

**定理 30（严格包含 R73）** 单臂、κ=0、无对象、令牌平凡 ⇒ CAF→PAR、DAC→自我反作用、J_COORD→J_MOD，逐指令等于 MODGAUGE，再退化等于 EMBODIED/R71/R68。**安全单调不减。**

**定理 31（J_COORD 有效 ⇒ 联合安全）** 在 A114（ζ 表达力）、A115（J_struct 校准不被对抗漂移）、A116（物理模型误差≤ε_model）下，联合执行风险 ≤ ε_coord。证明重量落在：ζ 是否被正确声明、规范自由是否被锚点消解、K 估计是否覆盖最坏情况；任一不成立则只保证「证书自洽」，不保证「世界正确」。

**定理 32（耦合退化有界与零级联条件）** 数据流级联由 EC 有界（继承定理 29）；物理级联有界当且仅当阶梯转移可行 ∧ 联合包络不越界 ∧ 力重分配解存在；否则存在 A 松手→B 负载突增→滑移跌落的级联反例。系：**R73「零级联」必须改写为条件命题。**

**定理 33（共识陷阱可证伪）** 朴素独立融合声称方差 1/N 下降，真实后验受 σ_c² 平台约束；覆盖率随 N 单调恶化，过度自信比无界。DB1 增大 N 即可证实/证伪 C4。系：**主张必须能被自己的基准打脸。**

## 7. 本轮最大风险

**一句话**：模块化的认证复利在耦合闭包处破产——当共因 ζ 不可识别或共享物体把两臂绑成不可分解的闭包时，热替换只能保证「闭包内重认证」，认证成本从 O(模块) 退化为 O(闭包)，而闭包可能等于全系统，于是**在最需要模块化的强耦合场景里模块化退化为单体**；若为了保住 O(模块) 宣传而强拆耦合，就会重演「所有证书有效、所有校验通过，系统却自信地组合出一个错误世界」。

次级风险与缓解：
1. **ζ 表达不足/不可识别** → R3 保守档 + 独立锚点 + 覆盖率监控；缺 ζ_ref 禁用 R1/R2。
2. **κ 估计漂移** → 在线 κ 监控 + 超阈自动降档 + SEAL-CommonCause；κ 进入证书。
3. **令牌死锁/饥饿** → 超时回退 L2 + 公平性证明；令牌状态进证书。
4. **物理模型误差（柔顺/摩擦/未建模）** → ε_model 在线辨识 + 柔顺物体力控降级 + 残差监控触发联合否决。
5. **规范自由误判** → 强制 rank 检查；无锚点证书标注「条件有效」，不得用于安全关键判定。
6. **共识劫持绕过 byz_k** → 溯源 π + 独立锚点交叉校验 + 单源不定案；k 随闭包规模声明。
7. **负结果被藏/DBench 过拟合** → 预注册 γ(κ) 与收益平台曲线；三方复现；O(闭包) 退化作为正文贡献。
