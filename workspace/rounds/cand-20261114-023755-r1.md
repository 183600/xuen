# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「跨任务泛化」×「差异化定位」）

> R69 把不确定性一分为二（aleatoric 收紧、epistemic 去问），并让「看/问/触」成为可认证、可审计的信息动作。但它默默假设了**任务分布是固定的**：COF 标定、模态先验、VoI 成本乃至 λ_floor 的尺度，都是在一个任务族上调好、再原样使用的。一旦系统同时面对多任务、新任务与任务切换，两个此前被折叠的问题同时暴露：
> - **跨任务泛化**：到底什么能迁移？动作生成器可以，但「在这个任务上该多保守」未必。盲目迁移会把 A 任务校好的自信搬到 B 任务，变成**负迁移**（negative transfer）；拒绝迁移则退化为每任务独立标定——昂贵、样本低效、且在新任务上没有先验。
> - **差异化定位**：系统必须先知道**「我在哪个任务、离已知任务多远、和哪个任务最像」**。任务身份不是预处理阶段的附属标签，而是与动作同等的一等状态。两个动作都合理，未必是「动作歧义」，也可能是**任务根本没定位**。
>
> 核心洞察来自一条恒等式：**H(M|O) = I(M;T|O) + H(M|T,O)**。R69 的 U_epi 只处理第二项（给定任务后的动作歧义），却把第一项（可由任务身份解释的歧义）也当成「问一句就能消解」的 epistemic。于是它会去问「绕左还是绕右」，而真正的答案其实是「你让我做的是哪个任务」。**问错问题，比不问更危险**——这正是 R69 自陈最大风险在多任务场景下的具体形态。
>
> 核心命题：**新增第三条不确定性通道 U_task（任务/迁移不确定性）；安全内核任务无关且冻结，任务适配只在「定位可信 + 负迁移被拒斥」时打开；只有 within-task 的 U_epi 才允许触发交互；其余全部逐指令退化为 R69 的保守。** 命名 **COMPASS-RAS**（Cross-task Meta-Positioned Adaptive Safety System：跨任务元定位自适应安全系统）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在哪个任务、什么能迁移、这份熟悉感此刻可信吗**」。先定位，再泛化；定位不确定，就不放宽。

## 0. 直觉与动机

**灵感 1（跨任务泛化 → 安全内核必须任务无关，适配必须任务相关）**
直觉：多任务系统里，真正可迁移的不是某条轨迹，而是**「哪些东西在任何任务上都必须成立」**——不改安全包络、不改证据纪律、不因任务而放松 λ 下限。反过来，标定参数、模态先验、VoI 成本则**必须随任务变化**。R69 把这两类东西混在同一个 FLUID 层里，导致要么整体迁移（负迁移风险），要么整体不迁移（无法泛化）。本轮把架构一分为二：**冻结的任务无关安全内核 K** + **可定位、可拒斥的任务条件适配层**。跨任务泛化因此不是「一个模型在所有任务上一样好」，而是「安全不随任务漂移，效率只在有证据时迁移」。

**灵感 2（差异化定位 → 任务身份是一等状态，裕度比最近邻更重要）**
直觉：人进厨房不会先问「这是哪个任务」，而是先做**定位**：这是灶台、这是水槽、这是切菜板；不确定时会多看一眼。差异化定位的要点不在「最近的已知任务是谁」，而在**top-2 的差**：最像 A、次像 B，且两者只差一点，说明当前任务在两个任务族之间，此时任何单任务先验都不可信。因此 COMPASS 同时维护四个量：任务后验 q、任务熵 H_task、**位置裕度 ρ_pos = s_(1) − s_(2)**、**新颖度 d_nov = 1 − s_(1)**。「离已知任务很远」与「夹在两个已知任务之间」是两种不同的危险，必须分开处理。

**灵感 3（归因恒等式 → R69 的 U_epi 是一个混合量）**
直觉：模态熵可以来自两个完全不同的地方：**(a) 我不知道你要哪个任务**，**(b) 我知道任务，但动作本身多峰**。前者靠「再看一眼/问左还是右」永远消不掉，只能靠任务识别或回退；后者才是 R69 的 MINT 该处理的。用 H(M|O)=I(M;T|O)+H(M|T,O) 做精确拆分：I(M;T|O) 记入 U_task，H(M|T,O) 记入 U_epi。当任务被定位，I(M;T|O)≈0，COMPASS 精确回到 FLUID——**R69 是 U_task≡0 的边界情形**，而不是被推翻的旧方案。

**灵感 4（定位门控 → 新层必须严格包含旧层）**
直觉：任务条件适配是一把双刃剑：开对了获得跨任务先验，开错了就是「自信地用错任务的标定」。因此门控必须是**悲观**的：不仅要求定位置信、校准通过，还要求任务条件头在独立审计集上的风险**置信上界**不高于 FLUID 回退的风险**置信下界**。门一关，COMPASS 逐指令等于 FLUID；门一开，也只是在安全内核不动的条件下换一个更合适的标定头。安全侧永不弱于 R69，这是本系列一以贯之的姿态。

**灵感 5（跨任务泛化的真正敌人 → 负迁移与任务伪装）**
直觉：跨任务失败很少是「动作生成不会」，更多是**「在错误的任务先验下过度自信」**。三种典型：新任务靠近已知原型（边界漂移）、对抗指令让 s_easy 被人为抬高（任务伪装）、任务原型库被污染（原型投毒）。更隐蔽的是**负迁移伪装**：审计任务上通过，部署时子任务分布不同而失效。所以本轮必须交付：任务级负迁移拒斥、原型库鲁棒估计、任务伪装检测、以及「定位误判率 ≤ α」的 conformal 保证。

**灵感 6（时间维度 → 任务切换的瞬态必须显式保守）**
直觉：任务边界处指纹会抖动，专家会来回切换，λ 会跟着闪烁；而最危险的往往正是切换后的第一秒——旧任务的标定还温着，新任务的动作已经发出。因此需要**滞回与驻留时间**：后验稳定 Δt 后才切换专家；指纹过期（stale）进入 transient，λ ≥ λ_FLUID、禁止 resolution bonus。**定位不是一次分类，而是一段带惯性的信念轨迹。**

## 1. 形式化定义（增量：定义 310–323）

**定义 310（COMPASS-RAS 总览）** COMPASS-RAS = (TPE, TPB, MCH, UAD, SPG, TVI, SKI, NTG, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **安全内核冻结**：C-RAS-WM 前缀认证、证据纪律、λ 单调性、提交/换装不变式与任务无关，适配层只能加非负 λ 偏移或在已认证集合内选模态；
(iii) **定位门控**：任务条件头仅在定位可信、任务校准通过、且迁移被悲观支配检验接受时启用；
(iv) **负迁移拒斥**：任何迁移必须在与元训练不相交的审计任务上，以置信上界证明不劣于 FLUID 回退；
(v) **归因先行**：每个不确定性必须先归因到 U_ale / U_epi / U_task，只有 within-task 的 U_epi 可触发交互。

**定义 311（任务指纹 TPE）** 任务上下文 ψ =（指令、目标、场景标签的符号编码）；位置指纹 φ_t = normalize(W_p [z_t ; e_ψ]) ∈ S^{d−1}，其中 z_t 为 R68/R69 MTM trunk 输出，e_ψ 为冻结指令编码器。对同一任务的改写/多语言，要求 ‖φ(ψ_1) − φ(ψ_2)‖ ≤ ε_ψ（A99），否则定位裕度会被人为压低。

**定义 312（原型库与差异化定位 TPB）** 已知任务原型 P={p_i}，单位化。位置相似度 s_i = cos(φ̄_t, p_i)，φ̄_t 为抗单帧噪声的滑动平均；后验 q_i = softmax(s_i/τ_pos)；任务熵 H_task = −Σ q_i log q_i；**位置裕度** ρ_pos = s_(1) − s_(2)；**新颖度** d_nov = 1 − s_(1)。决策依赖 top-2 的**差**而不只是最近邻：s_(1) 高但 ρ_pos 低，意味着「夹在两个任务之间」，与「不在任何已知任务中」同样要求保守。

**定义 313（任务条件校准头 MCH）** 任务 i 有校准头 h_i:(z,ψ)→(COF 参数, 模态先验, λ 偏移 δλ_i ≥ 0, VoI 成本 c_i)。新任务用超网络 g_η(p_i, D_i^{few}) 生成头参数；混合头 θ_eff = Σ_i q_i θ_i。g_η 只拟合校准量、先验与成本，**不得接触安全内核与 C-RAS-WM 认证逻辑**。

**定义 314（三通道不确定性）** U_ale = Σ_k ŵ_k tr(Σ_k)（模态内噪声，继承 R69 定义 297）；U_epi = H(M|T,O)（给定任务后的模态间歧义）；U_task = H(T|O) + g_nov(d_nov) + I(M;T|O)（任务身份 + 新颖度 + 可由任务解释的模态熵）。三者语义不同，分通道处置，不做简单加权和。

**定义 315（任务归因分解 UAD）** 对恒等式 H(M|O) = I(M;T|O) + H(M|T,O)，定义 U_task^mode = I(M;T|O)（模态熵中由任务身份解释的部分），U_epi = H(M|T,O)（within-task 残余歧义）。在任务被良好定位时 I(M;T|O)≈0，U_epi 即 R69 的 U_epi。UAD 输出三元组 (U_ale, U_epi, U_task)，其中 U_task 另含定位熵与新颖度项。**归因错误本身要被审计**：若 UAD 把 U_task 误记为 U_epi，MINT 会问错问题。

**定义 316（选择性定位门 SPG）** 门控 z_gate=1 当且仅当：
q_max ≥ τ_q，ρ_pos ≥ τ_ρ（conformal 校准），d_nov ≤ τ_nov，task_id_ECE ≤ τ_ece，
且 UCB_α[R_T(θ_eff)] ≤ LCB_α[R_T(θ_agnostic)]（悲观迁移支配）。
任一不满足 ⇒ 门关：θ_eff = θ_agnostic（FLUID 头），禁用 resolution bonus，禁用 within-task 交互。

**定义 317（任务感知 VoI TVI）** 信息动作分两级：within-task 动作 g_w（注视/探针/「绕左还是绕右」）与 meta 动作 g_t（「你要我做哪个任务」/请求示范/重新定位）。VoI(g)=H(M|O)−E[H(M|O,y)]。若 g_w 条件独立于任务身份 T，则它只降低 H(M|T,O)，其增益上界为 U_epi；当 U_task 主导时，argmax 应落在 g_t 或直接回退。g_t 的成本含人类负担与时间，且必须与任务动作一样过 C-RAS-WM 认证。

**定义 318（安全内核不变式 SKI 与三级退避）** 内核 K=(C-RAS-WM 认证, 证据纪律, λ 单调性, 提交/换装不变式) 在元训练与在线适配中**冻结**。适配层只能 δλ_i ≥ 0、在已认证前缀集合内选模态、改变 within-task 信息动作排序。三级退避：
- 定位可信且 U_epi 已消解：λ = λ_floor(U_ale + U_task)；
- 定位可信但 U_epi 未消解：λ = λ_floor(U_ale + U_epi + U_task)；
- 定位不可信：λ = λ_floor(U_ale + U_epi + U_task)，且禁用 resolution bonus 与 within-task 交互。
U_task 仅在 meta 交互成功且双源验证后置 0，否则始终在 floor 内。**R69 = (U_task≡0, 定位可信)** 的边界。

**定义 319（跨任务证书 J_COMPASS）** J_COMPASS = (J_FLUID, task_id_ECE, ρ_pos^{p5}, novelty_AUROC, negative_transfer_rate, forward_transfer_gain, task_bank_hash, meta_version, fallback_rate, spoof_alarm)。Valid ⇔ Valid(J_FLUID) ∧ 门控校准 ∧ NTG 满足 ∧ 无 spoof 告警 ∧ 安全内核 hash 未变。

**定义 320（任务迁移威胁模型 ℰ_task）** 任务边界漂移（新任务靠近已知原型）、任务伪装（对抗指令/观测抬高 s_easy）、原型投毒（污染 TPB）、指令改写/多语言指纹漂移、负迁移伪装（审计通过、部署子任务失败）、温柔新颖性（定位看似可信但接触动力学不同）。ℰ_COMPASS = ℰ_FLUID × ℰ_task。

**定义 321（负迁移拒斥 NTG 与迁移遗憾）** 对任务 i，Reg_i = R_i(θ_eff) − R_i(θ_agnostic)。仅当独立审计分布上 UCB_α(Reg_i) ≤ 0 时接受迁移，否则回退。负迁移率 NT = P(接受且真实 Reg_i > 0)。NTG 使用任务级 bootstrap/conformal 置信界，审计任务与元训练任务不相交，避免选择偏差。

**定义 322（任务切换滞回 HYS）** 任务后验需连续 Δt 稳定且 ρ_pos 超过切换阈值才切换专家；若指纹与当前观测的残差 > τ_stale，进入 transient，λ ≥ λ_FLUID，禁止 resolution bonus。防止边界抖动导致安全松弛闪烁。

**定义 323（跨任务元训练目标 DRO）** 在任务分布族 𝒫 上做分布鲁棒优化：
min_η max_{P∈𝒫} E_{T∼P}[ R_T(θ_agnostic; head_η(T)) + β·ECE_T ] + γ·CVaR_α(Reg)
s.t. 安全内核不变式与 SPG 约束。𝒫 至少覆盖任务族、物体/场景/指令偏移与改写；目标是 worst-task 而非 average-task，直接对齐「跨任务泛化」。

# IP-264/265 TPE + TPB：任务定位（差异化定位）
def locate(z, psi, bank, tau_pos=0.1):
    phi   = normalize(Wp @ cat([z, instr_encoder(psi)]))
    phi_b = ema(phi)                                  # 抗单帧噪声
    s     = bank.prototypes @ phi_b                   # [N]
    q     = softmax(s / tau_pos)
    return Position(phi_b, q, entropy(q),
                    top1(s) - top2(s), 1 - top1(s))   # H_task, rho, d_nov

# IP-266 MCH：任务条件校准头（超网络混合，安全内核不动）
def mix_head(pos, bank, meta_net):
    heads = [meta_net.emit(bank.p[i], bank.fewshot[i]) for i in range(len(bank))]
    return blend(heads, pos.q)                        # (COF, prior, dlam>=0, cost)

# IP-267 UAD：把模态熵归因为「任务」还是「动作」
def attribute(modes, pos, task_cond):
    H_mode = entropy(mode_weights(modes))
    I_MT   = mutual_info(mode_id, task_id, task_cond) # 可学习判别器或列联表
    U_task_mode = min(I_MT, H_mode)
    U_epi  = max(H_mode - U_task_mode, 0.0) * sep_factor(modes)
    U_task = pos.H_task + g_nov(pos.d_nov) + U_task_mode
    return U_task, U_epi

# IP-268/271 SPG + NTG：悲观定位门（门关 -> 严格等于 FLUID）
def gate(pos, head, fluid_head, audit):
    if not (pos.q_max >= TAU_Q and pos.rho >= TAU_RHO
            and pos.d_nov <= TAU_NOV and head.ece <= TAU_ECE):
        return False
    return ucb(audit.risk(head), 0.05) <= lcb(audit.risk(fluid_head), 0.05)

# IP-269 TVI：任务不确定时先问任务，而不是问动作
def task_aware_voi(modes, pos, budget):
    if pos.U_task > TAU_TASK:
        cands = meta_info_actions(pos)          # ask-which-task / re-localize
    else:
        cands = within_task_info_actions(modes) # R69 的 gaze / probe / ask
    best = max(cands, key=lambda g: voi(g) - cost(g)
               if budget.allow(g) and c_ras_wm.certify_info(g) else -inf)
    return best if best and voi(best) > cost(best) else None

# IP-276 主闭环：继承 FLUID，仅在「定位/迁移」处插入门控
def COMPASS_round(M, obs, psi):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    pos  = M.tpe.locate(z, psi, M.tpb)
    head = M.mch.mix_head(pos, M.tpb, M.meta_net)
    if not M.spg.gate(pos, head, M.fluid_head, M.ntg.audit):
        return M.fluid_round(z, o, psi)                 # 逐指令 = R69
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi = M.uad.decompose(modes, z)
    U_task, U_epi = M.uad.attribute(modes, pos, M.task_cond)
    # 任务不确定 -> 只允许 meta 交互或回退
    if U_task > TAU_TASK:
        g = M.tvi.task_aware_voi(modes, pos, M.budget)
        if g is None:
            return M.fluid_round(z, o, psi)
        ok, ans = M.cia.execute_meta(g)
        if not (ok and M.verify.two_source(ans)):
            return M.fluid_round(z, o, psi)
        pos = M.tpe.relocalize(ans); U_task = 0.0
    # within-task 交互：R69 MINT，仅在 U_epi 可约时
    g_w = (M.mint.choose_interaction(modes, o, M.budget)
           if U_epi > TAU_EPI else None)
    U_epi_after = U_epi if g_w is None else M.cia.update_belief(modes, M.cia.execute(g_w))
    # 三级退避：U_task 永远在 floor 内；resolution bonus 只作用于 U_epi
    U_floor = U_ale + U_task + (U_epi_after if g_w is None else 0.0)
    lam = max(M.efs.risk_scale(...), M.ski.lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., M.wm_preds)
    if M.hys.transient(pos):
        lam = max(lam, M.ski.lam_floor(U_ale + U_epi + U_task))
    mode = select_mode(modes, U_epi_after, lam)
    M.vqa_t.submit_async(pos, head, g_w, U_task, U_epi_after)
    return k, lam, mode, (U_ale, U_task, U_epi_after)

## 3. 推导

**引理 19（归因恒等式）** 对任意任务 T、模态 M、观测 O：
H(M|O) = I(M;T|O) + H(M|T,O)。
取 U_task^mode := I(M;T|O)，U_epi := H(M|T,O)，即得无重叠分解。当 T 被定位（H(T|O)=0）时 U_task^mode=0，分解退化为 R69 的模态熵。系：**R69 的 U_epi 在本轮被严格细化为「任务条件化之后的残余歧义」**；把 I(M;T|O) 误当 U_epi，会让交互预算花在错误的问题上。

**引理 20（定位误差 → 迁移风险 Lipschitz 界）** 设对 φ 在原型 p 的邻域内，任务风险满足 |R_T(θ) − R_p(θ)| ≤ L_pos‖φ − p‖（A100），定位误差 δ = ‖φ − p_{ĉ}‖。则
R_T(θ_eff) ≤ R_p(θ_eff) + L_pos·δ，
R_T(θ_agnostic) ≥ R_p(θ_agnostic) − L_pos·δ。
于是迁移的净收益满足
R_T(θ_agnostic) − R_T(θ_eff) ≥ −Reg_p − 2L_pos·δ。
系：**只有当任务头的优势 Reg_p 的负值（即增益）超过 2L_pos·δ 时，跨任务迁移才保证为正收益**；定位越准（δ 小），越值得迁移。这把「差异化定位」从经验直觉变成了可计算的迁移开关。

**引理 21（within-task 交互无法消解 U_task）** 若信息动作 g_w 在给定 O 下条件独立于任务身份 T（它只读任务无关的动作相关变量），则 p(T|O,y_g)=p(T|O)，且
max_{g_w} [H(M|O) − E H(M|O,y_g)] ≤ H(M|T,O) = U_epi。
交互后的残余模态不确定度下界为 I(M;T|O)。系：**当 U_task 主导时，within-task 交互的期望信息增益有上界 U_epi，且无法把残余压到 U_task 以下**；此时正确动作是 meta 交互或保守回退，而不是更努力地看/问动作。

**引理 22（安全内核在元适配下的不变性）** 设内核 K 冻结，任务头只能产生 δλ_i ≥ 0 且在已认证前缀集合内选模态。则对任意任务与任意门控状态：
λ_COMPASS ≥ λ_floor(U_ale + U_task) ≥ λ_floor(U_ale) = λ_FLUID^{resolved}，
且认证前缀集合 ⊆ R69 的认证集合。故安全侧单调不弱于 R69；当门关或 U_task=0 时逐指令相同（定理 18）。

**定理 18（COMPASS 严格包含 FLUID）** 在 A99–A102 下：
(i) 门控关闭 ⇒ COMPASS 的每一步指令与 FLUID 完全相同（实现上是直接调用 fluid_round）；
(ii) 门控打开 ⇒ 由 SPG 的悲观支配条件 UCB(R_eff) ≤ LCB(R_agnostic) 与引理 22，期望风险以概率 ≥ 1−α 不高于 FLUID；
(iii) 定位可信且 U_task=0 ⇒ 三级退避退化为 R69 的两级退避，resolution bonus 完全一致。
因此 FLUID 是 COMPASS 在「单任务且永不迁移」边界上的严格退化；安全侧不做任何让步，效率侧只在有定位证据时兑现跨任务先验。

**定理 19（跨任务前向迁移的收益条件）** 对新任务 T' 与最近原型 p，若门控打开且 NTG 接受迁移，则由引理 20：
R_{T'}(θ_eff) ≤ R_p(θ_agnostic) + L_pos·δ + UCB(Reg_p)，
而在同样定位误差下 FLUID 的风险下界为 R_p(θ_agnostic) − L_pos·δ。
因此当 UCB(Reg_p) + 2L_pos·δ < 0 时，COMPASS 在新任务上**严格优于** FLUID；当该条件不成立时，门控应保持关闭——**不为「泛化」的叙事牺牲 worst-task 安全**。这就是本轮的差异化定位：不以平均成功率取胜，而以 worst-task 风险与负迁移率为约束。

**定理 20（任务切换的滞回稳定性）** 在定义 322 的滞回与驻留规则下，任务边界处专家切换次数有界，且任何 transient 区间内 λ ≥ λ_FLUID。故切换不产生安全松弛的瞬时下陷；换装不变式（R68 定理 15）与交互安全（R69 定理 17）保持。

## 6. 本轮最大风险

**一句话**：COMPASS 把「是否放宽安全」的钥匙交给了**任务定位**，而定位层本身是学出来的、可被伪装/投毒、且在最危险的新任务上恰恰最容易「自信地看起来熟悉」——一旦 ρ_pos 高却指向错误任务，SPG 会打开、任务头会以错误先验放宽 λ，而审计只看到「定位高置信、证书齐全」，于是**差异化定位退化为「自信的错位」**，跨任务泛化变成跨任务负迁移，且失败是静默的。

**次级风险与缓解**：
1. **定位过度自信** → conformal 裕度阈值 + 悲观 SPG + 门关回退 R69；
2. **任务伪装/原型投毒** → ℰ_task 对抗训练 + 鲁棒原型估计 + 任务库 hash 审计；
3. **归因错误（把 U_task 当 U_epi）** → UAD 双通道交叉检验 + 归因审计 + 错归因即回退；
4. **负迁移伪装** → 审计任务与元训练不相交 + UCB(Reg)≤0 + 部署期回退率监控；
5. **切换瞬态** → 滞回/驻留 + transient 期强制 λ ≥ λ_FLUID + 零 resolution bonus；
6. **元训练分布覆盖不足** → DRO worst-task 目标 + 任务族留出 + 新任务快速回退。

# IP-264/265 TPE + TPB：差异化定位
def locate(z, psi, bank, tau_pos=0.1):
    phi   = normalize(Wp @ cat([z, instr_encoder(psi)]))
    phi_b = ema(phi)
    s     = bank.prototypes @ phi_b
    q     = softmax(s / tau_pos)
    return Position(phi_b, q, entropy(q), top1(s)-top2(s), 1-top1(s))

# IP-266 MCH：任务条件头（安全内核不参与）
def mix_head(pos, bank, meta_net):
    heads = [meta_net.emit(bank.p[i], bank.fewshot[i]) for i in range(len(bank))]
    return blend(heads, pos.q)                  # COF / prior / dlam>=0 / cost

# IP-267 UAD：把模态熵归因为任务或动作
def attribute(modes, pos, task_cond):
    H_mode = entropy(mode_weights(modes))
    I_MT   = mutual_info(mode_id, task_id, task_cond)
    U_task = pos.H_task + g_nov(pos.d_nov) + min(I_MT, H_mode)
    U_epi  = max(H_mode - min(I_MT, H_mode), 0.0) * sep_factor(modes)
    return U_task, U_epi

# IP-268/271 SPG + NTG：悲观门控（门关 -> 严格 FLUID）
def gate(pos, head, fluid_head, audit):
    if not (pos.q_max>=TAU_Q and pos.rho>=TAU_RHO
            and pos.d_nov<=TAU_NOV and head.ece<=TAU_ECE):
        return False
    return ucb(audit.risk(head),0.05) <= lcb(audit.risk(fluid_head),0.05)

# IP-269 TVI：任务不确定时先问任务
def task_aware_voi(modes, pos, budget):
    cands = meta_info_actions(pos) if pos.U_task>TAU_TASK else within_task_info_actions(modes)
    best = max((g for g in cands if budget.allow(g) and c_ras_wm.certify_info(g)),
               key=lambda g: voi(g)-cost(g), default=None)
    return best if best and voi(best)>cost(best) else None

# IP-276 主闭环：继承 FLUID，仅在定位/迁移处插入门控
def COMPASS_round(M, obs, psi):

    pos  = M.tpe.locate(z, psi, M.tpb)
    head = M.mch.mix_head(pos, M.tpb, M.meta_net)
    if not M.spg.gate(pos, head, M.fluid_head, M.ntg.audit):
        return M.fluid_round(z, o, psi)                 # 逐指令 = R69
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    U_ale, U_epi = M.uad.decompose(modes, z)
    U_task, U_epi = M.uad.attribute(modes, pos, M.task_cond)
    if U_task > TAU_TASK:                               # 先问任务，不问动作
        g = M.tvi.task_aware_voi(modes, pos, M.budget)
        if g is None: return M.fluid_round(z, o, psi)
        ok, ans = M.cia.execute_meta(g)
        if not (ok and M.verify.two_source(ans)):
            return M.fluid_round(z, o, psi)
        pos = M.tpe.relocalize(ans); U_task = 0.0
    g_w = (M.mint.choose_interaction(modes, o, M.budget)
           if U_epi > TAU_EPI else None)
    U_epi_after = U_epi if g_w is None else M.cia.update_belief(modes, M.cia.execute(g_w))

    mode = select_mode(modes, U_epi_after, lam)
    M.vqa_t.submit_async(pos, head, g_w, U_task, U_epi_after)

## 4. 推导

**引理 19（归因恒等式）** `H(M|O)=I(M;T|O)+H(M|T,O)`。取 `U_task^mode=I(M;T|O)`、`U_epi=H(M|T,O)` 即无重叠；T 已知时前者为 0，退化为 R69。系：R69 的 U_epi 是「未条件化」的混合量，会把任务歧义误当动作歧义。

**引理 20（定位误差 → 迁移风险）** A100 下 `R_T(θ_eff) ≤ R_p(θ_eff)+L_pos·δ`，`R_T(θ_agnostic) ≥ R_p(θ_agnostic)−L_pos·δ`，故 `R_T(agnostic)−R_T(eff) ≥ −Reg_p−2L_pos·δ`。系：只有任务头增益超过 `2L_pos·δ` 时跨任务迁移才保证正收益——定位越准越值得迁移。

**引理 21（within-task 交互的 U_task 上界）** 若 g_w 条件独立于 T，则 `p(T|O,y_g)=p(T|O)`，且 `max_{g_w}[H(M|O)−E H(M|O,y_g)] ≤ U_epi`；交互后残余不确定度下界为 `I(M;T|O)`。系：U_task 主导时，更努力地看/问动作无益，应问任务或回退。

**引理 22（内核不变性）** 内核冻结且任务头只能 δλ≥0、在认证集合内选模态，故 `λ_COMPASS ≥ λ_floor(U_ale+U_task) ≥ λ_floor(U_ale)=λ_FLUID^{resolved}`，认证前缀集合 ⊆ R69；门关或 U_task=0 时逐指令相同。

**定理 18（COMPASS 严格包含 FLUID）** A99–A102 下：(i) 门关 ⇒ 逐指令等于 FLUID；(ii) 门开 ⇒ 由 SPG 的 `UCB(R_eff)≤LCB(R_agnostic)` 与引理 22，期望风险以概率 ≥1−α 不高于 FLUID；(iii) 定位可信且 U_task=0 ⇒ 三级退避退化为 R69 两级退避、resolution bonus 完全一致。FLUID = 「单任务且永不迁移」边界。

**定理 19（前向迁移收益条件）** 新任务 T' 与最近原型 p：`R_{T'}(θ_eff) ≤ R_p(agnostic)+L_pos·δ+UCB(Reg_p)`，而 FLUID 下界为 `R_p(agnostic)−L_pos·δ`。故 `UCB(Reg_p)+2L_pos·δ<0` 时 COMPASS 严格优于 FLUID；否则门控应保持关闭。**不以平均成功率取胜，以 worst-task 风险与负迁移率为约束。**

**定理 20（切换滞回稳定性）** 滞回 + 驻留下专家切换次数有界；transient 期 λ ≥ λ_FLUID，故无安全松弛的瞬时下陷；R68 换装不变式与 R69 交互安全（定理 17）保持。

## 7. 本轮最大风险

**一句话**：COMPASS 把「是否放宽安全」的钥匙交给了**任务定位**，而定位层本身是学出来的、可被伪装/投毒、且在最危险的新任务上恰恰最容易「自信地看起来熟悉」——一旦 ρ_pos 高却指向错误任务，SPG 会打开、任务头会以错误先验放宽 λ，而审计只看到「高置信定位 + 证书齐全」，于是**差异化定位退化为「自信的错位」**，跨任务泛化变成跨任务负迁移，且失败是静默的。

**次级风险与缓解**：定位过度自信（conformal 裕度 + 悲观 SPG + 门关回退）；任务伪装/原型投毒（ℰ_task 对抗训练 + 鲁棒原型 + 库 hash 审计）；归因错误（UAD 双通道交叉检验 + 错归因即回退）；负迁移伪装（审计与元训练不相交 + UCB(Reg)≤0 + 部署回退率监控）；切换瞬态（滞回/驻留 + transient 强制 λ ≥ λ_FLUID）；元训练覆盖不足（worst-task DRO + 任务族留出 + 快速回退）。
