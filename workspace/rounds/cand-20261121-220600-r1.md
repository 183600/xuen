# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「多机评测」×「放置」）

> **基线**：v20 = MetricVoiceGauge-NCD-HUTDH-v20（IP-420–424：PCA / CTS / CFC / HPC / CFCtrl）。
> 本轮纪律：**评测是证伪，放置是闭合**。不推倒 v20：PCA 的联邦感知 Hull、CTS 的谱系迁移、CFC 的拜占庭共识、HPC 的可审计证书、CFCtrl 的时序回退全部保留。本轮只做一件事：**把 v20 的“单机、运动段碰撞证书”推进为“跨机器人总体有效、且延伸到松手与静置之后”的放置闭合证书**。

## 0. 直觉与动机

**灵感 1（多机评测 → 评测是对证书的证伪实验，不是排行榜）**
直觉：一个只在机器人 A 上成立的“证书”，本质上是一次巧合，而不是证书。多机评测真正要回答的不是“平均成功率多高”，而是“换一台形态、传感器、控制器都不同的机器人，这张证书还成立吗”。主流做法把不同机器人的分数做平均或排名，这会**把最差机器人类别的系统性失效平均掉**，制造安全幻觉。核心创新：**跨机器人证书压力测试 (Cross-Robot Certification Stress Test, CRCST)** 与 **总体有效性 (Population Validity)**。把机器人看成从一个异质性分布 𝒫 中抽取的样本，评测输出不是均值，而是**单侧置信下界 V_LB 与最差分层 V_robust**；并把失败方差分解为“证书固有风险 / 机器人个体差异 / 机器人×任务交互”，用组内相关系数 ICC 判断证书能否做全局声明。关键反直觉点：**多机评测的价值不在“平均分高”，而在“最差机器人类别仍然安全”；随机平均是安全幻觉的温床**。

**灵感 2（放置 → 碰撞证书的时间边界必须延伸到接触之后）**
直觉：v20 的证书覆盖“运输过程中不碰撞”，但放置的真正风险发生在**松手之后**：物体可能滑移、倾倒、滚出目标区、或撞到邻近物体。传统系统把“物体到达目标位姿”当作任务结束，这等价于只验证了一个点；而松手后的状态是一个**集合**——受释放姿态误差、夹爪释放不对称、支撑面摩擦与扰动影响。核心创新：**放置闭合证书 (Placement Closure Certificate, PCC)**，采用**三段闭合**：接近闭合（approach-closure）、释放闭合（release-closure）、静置闭合（settle-closure）。关键反直觉点：**放置安全不是“松手瞬间不碰撞”，而是“松手后的可达集仍落在已认证安全集内”**——这是可达性 / 生存性条件，不是逐点检查。

**灵感 3（两者的统一：评测总体有效性 × 放置时间闭合）**
统一为 v20 证书体系之上的**评测-闭合层**：v20 回答“给定机器人、给定运动段，θ 是否零碰撞”；v21 回答“这张放置证书对整个机器人总体是否成立，并且是否覆盖到松手与静置之后”。MREP 提供总体有效性证据（证伪侧），HDA 解释异质性来源（归因侧），PCC 把证书延伸到释放（时间侧），SSC 把证书延伸到静置（接触侧），RPFC 在闭合失败时保守退化（安全侧），ERL 保证评测可复现（审计侧）。共享状态 `ζ_eval = (robot_strata, soundness_samples, icc, transfer_gaps, R_post, settle_invariants, seeds, mode_eval)`。统一接口：**运输段由 v20 的 HPC 认证；总体有效性 V_LB ≥ 1−δ；三段闭合通过；否则回退 v20 或保守放置**。

## 1. 研究问题（轮次升级版）

- **Q1（总体有效性）**：如何定义“证书对机器人总体有效”？分层抽样、公共随机数、单侧置信下界与最差分层如何组合，才能在有限机器人样本下给出不过度乐观的结论？当机器人总体分布 𝒫 本身未知或只能部分枚举时，如何给出分布鲁棒（DRO）的有效性下界？

- **Q2（异质性分解）**：如何用混合效应模型把失败方差分解为“证书固有风险”与“机器人个体差异”？ICC 达到什么阈值时必须放弃全局证书、改为按机器人类别条件化？机器人×放置场景的交互项如何估计与解释？

- **Q3（放置闭合）**：如何刻画松手时刻的不确定性集 U_r 与松手后的可达集 R_post？如何用可计算的过近似（zonotope / interval）保证 `R_post ∩ Obstacles = ∅` 且 `R_post ⊆ G_ε`？三段闭合的交集如何与 v20 的授权域复合？

- **Q4（静置稳定性）**：在非光滑摩擦接触下，如何给出支撑多边形余量、摩擦锥余量与防倾倒势函数 Φ 的可验证条件？刚性假设失效（柔性 / 变形物体）时如何检测并回退？

- **Q5（评测可复现与防过拟合）**：如何在多机器人、多场景、多随机种子下用公共随机数做配对比较？如何预注册评测协议，防止“换机器人 / 换种子直到通过”的事后挑选？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P38）

**P34 总体有效性律（Population Validity）**
设证书族为 C，机器人实例 `r = (m_r, s_r, c_r)` 从总体分布 𝒫 抽取，`Sound(C, r) ∈ {0,1}` 表示 C 在 r 上对所有授权 θ 都零碰撞且满足放置闭合。总体有效性定义为 `V(C) = Pr_{r∼𝒫}[Sound(C,r)]`。评测在分层 `S_1,…,S_K`（按形态 / 传感器 / 控制器聚类）上抽样，每层 `n_k` 台；对每层用 Clopper–Pearson 在置信度 `1−α/K`（Bonferroni）下给出单侧下界 `V_k^LB`，最终报告 `V_LB = min_k V_k^LB`（最差分层）与 `V_pop^LB`（按层权重的总体下界）。**只有 `V_LB ≥ 1−δ` 时才允许作出“总体有效”的证书声明；跨机器人的平均成功率被显式禁止作为有效性依据。**

**P35 异质性分解律（Heterogeneity Decomposition）**
对机器人 r 在第 t 次试验的失败指示 `Y_{r,t} ∈ {0,1}` 建立混合效应模型 `Y_{r,t} = μ + b_r + e_{r,t}`，其中 `b_r ∼ N(0, σ_b²)` 为机器人随机效应，`e_{r,t} ∼ N(0, σ_e²)` 为试验噪声。定义组内相关系数 `ICC = σ_b² / (σ_b² + σ_e²)`。若 `ICC ≥ κ`（默认 κ=0.3），说明失败主要由机器人身份解释，**必须改用机器人条件化证书或按分层分别认证，禁止单一全局域声明**。同时定义跨机器人迁移差 `Δ(A→B) = f_B − f_A`（f 为失败率），并报告同层内有向对的最大迁移差；Δ 越大，越应把证书视为“局部知识”而非“通用规律”。

**P36 放置闭合律（Placement Closure）**
放置计划 `π = (approach, release, settle)`。松手时刻的不确定性集 `U_r = PoseErr × VelErr × GripperAsym`（用 box 或 zonotope 表示）；松手后可达集 `R_post = Reach(U_r, dynamics, W, horizon)`，其中 `W` 为有界扰动集。**授权条件必须是开集鲁棒**：`closure(N_ε(θ)) ⊆ 已认证集`（不是单点 θ 通过即可），且 `R_post ∩ Obstacles = ∅` 且 `R_post ⊆ G_ε`（目标区带容差）。三段闭合取交集 `C_place = C_appr ∧ C_rel ∧ C_settle`。**闭合只能收缩授权域，不能扩张**。

**P37 接触后不变量（Post-contact Invariant）**
对静置段定义支撑多边形余量 `δ_sup = dist(CoM_proj, ∂SP)`、摩擦锥余量 `δ_fric = min_c (μ_c N_c − |F_{t,c}|)`、防倾倒势 `Φ(x) = w_1·h_com + w_2·tilt + w_3·dist_to_SP_edge`。静置证书成立需存在认证区域 Ω，使得在 Ω 内 `Φ(x) ≤ φ_max`、`Φ̇(x) ≤ 0`（沿接触动力学，含扰动 W）、`Ω ∩ Obstacles = ∅`、`δ_sup ≥ δ_sup^*`、`δ_fric ≥ δ_fric^*`。**静置证书必须在有界扰动下保持不变，而非仅在标称轨迹上成立。**

**P38 评测可复现律（Evaluation Reproducibility）**
所有跨机器人比较必须使用**公共随机数 (Common Random Numbers, CRN)**：同一任务实例、同一场景种子、同一扰动序列在各机器人上复用，做配对统计。评测协议（分层、n_k、δ、α、κ、φ_max、δ_sup^*、δ_fric^*）必须**在看到结果前预注册**；事后增删机器人分层或更换种子都视为新的评测轮次，需重新注册。种子、任务、机器人版本全部写入可审计账本 ERL。

## 3. 与基线的接口（如何退化）

- 总体有效性不可证（样本过小 / 𝒫 未知且无法界定）⇒ 证书退化为“仅对已评测机器人成立”的单机证书 ⇒ 等价 v20；
- `ICC ≥ κ` 且无机器人条件化证书 ⇒ 拒绝全局声明，只保留各分层（可能为空）的局部域；
- 放置闭合失败（`R_post` 无法界定，如未建模接触 / 柔性物体）⇒ RPFC 退化为夹具放置、人机交接或仅运输 ⇒ 等价 v20；
- 静置不变量不可用 ⇒ 禁止自主松手，转为交接；
- 三者全失效 ⇒ 完全回退 v20；**安全继承**：`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`，由引理 162 保证。

## 4. 预期贡献

1. **总体有效性评测协议（CRCST / MREP）**：首次把“证书有效性”定义为机器人总体上的最差分层单侧下界，而非跨机器人平均分，给出分层抽样 + CRN + 预注册的完整评测流程；
2. **异质性分解与证书条件化**：用混合效应 ICC 与迁移差 Δ 判断“全局证书”是否成立，给出全局 / 机器人条件化 / 分层拒绝的三级决策；
3. **放置闭合证书（PCC）**：把碰撞证书从“运输段”延伸到“松手后可达集”，用可达集过近似把放置安全从逐点检查升级为生存性条件；
4. **静置稳定性证书（SSC）**：给出支撑多边形、摩擦锥、防倾倒势的可验证不变量，覆盖非光滑接触下的静置安全；
5. **可复现评测账本（ERL）**：用 CRN、种子注册与预注册防止“换机器人 / 换种子直到通过”的评测过拟合；
6. **统一退化链**：评测-闭合层只能收缩授权域，实现 `Exec_v21 ⊆ Exec_v20`，把“多机评测 → 放置闭合 → 碰撞安全”闭合成环。

## 5. 本轮最大风险

**一句话**：总体有效性只在有限且可能偏置的机器人样本上估计；若分层漏掉了某类具有系统性证书盲区的机器人（如柔性夹爪、低刚度臂），`V_LB` 会过度乐观，系统会把“总体有效”的放置证书部署到从未被评测的类别上——即“评测集偏置导致的安全幻觉”。

# IP-425 Multi-Robot Evaluation Protocol (MREP)
class MultiRobotEvaluationProtocol:
    def __init__(self, strata, delta=0.05, alpha=0.05, n_per_stratum=30):
        self.strata = strata            # {S_k: [robot_id, ...]}
        self.delta = delta              # 允许失效比例
        self.alpha = alpha              # 单侧置信水平
        self.n = n_per_stratum

    def stratified_sample(self, population):
        sample = {}
        for k, members in self.strata.items():
            # 分层抽样：每层独立抽 n_k 台，避免大类淹没小类
            sample[k] = random.sample(members, min(self.n, len(members)))
        return sample

    def evaluate(self, cert_family, sample, tasks, seeds):
        """CRN：同一任务与种子在所有机器人上复用，做配对比较"""
        failures = {k: [] for k in sample}
        for k, robots in sample.items():
            for r in robots:
                for task, seed in zip(tasks, seeds):
                    ok = cert_family.sound_on(r, task, seed)   # 复用 v20 HPC
                    failures[k].append(0 if ok else 1)
        return failures

    def population_validity(self, failures):
        """每层 Clopper–Pearson 单侧下界，报告最差层与总体下界"""
        alpha_k = self.alpha / len(failures)          # Bonferroni
        per_stratum = {}
        for k, fails in failures.items():
            n = len(fails)
            s = sum(fails)
            # 失败率上界 -> 成功率下界
            ub_fail = clopper_pearson_upper(s, n, 1 - alpha_k)
            per_stratum[k] = 1.0 - ub_fail
        V_LB = min(per_stratum.values())              # 最差分层
        V_pop = sum(weight(k) * per_stratum[k] for k in per_stratum)
        return {
            "V_LB": V_LB,
            "V_pop_LB": V_pop,
            "per_stratum": per_stratum,
            "claim_ok": V_LB >= 1.0 - self.delta,
        }


# IP-426 Heterogeneity Decomposition Analyzer (HDA)
class HeterogeneityDecompositionAnalyzer:
    def __init__(self, kappa=0.3):
        self.kappa = kappa

    def fit_mixed_effects(self, Y, robot_ids, task_ids):
        """Y_rt = mu + b_r + e_rt，估计 sigma_b^2 与 sigma_e^2"""
        mu = mean(Y)
        # 机器人均值残差估计 between-robot 方差
        r_means = group_mean(Y, robot_ids)
        sigma_b2 = max(0.0, var(r_means) - mean(group_var(Y, robot_ids)))
        sigma_e2 = max(1e-9, mean(group_var(Y, robot_ids)))
        icc = sigma_b2 / (sigma_b2 + sigma_e2)
        return MixedEffectsFit(mu=mu, sigma_b2=sigma_b2,
                               sigma_e2=sigma_e2, icc=icc)

    def transfer_gap(self, failures_A, failures_B):
        return mean(failures_B) - mean(failures_A)

    def recommend_mode(self, fit, per_stratum_gap):
        if fit.icc >= self.kappa:
            return "ROBOT_CONDITIONED"    # 禁止全局证书
        if per_stratum_gap > self.kappa:
            return "STRATUM_CONDITIONED"
        return "GLOBAL"


# IP-427 Placement Closure Certificate (PCC)
class PlacementClosureCertificate:
    def __init__(self, v20_hpc, eps_target=0.01, eps_open=0.005):
        self.hpc = v20_hpc
        self.eps_target = eps_target
        self.eps_open = eps_open

    def release_reachable_set(self, obj, target, U_release, W, horizon):
        """用 zonotope 过近似 R_post = Reach(U_r, dynamics, W, horizon)"""
        R = Zonotope.from_box(U_release)
        for _ in range(horizon):
            R = propagate(R, obj.dynamics, W)     # 保守 Minkowski 和
        return R

    def check_closure(self, node, obj, theta, target, U_release, W):
        # 1) 接近闭合：运输段由 v20 HPC 认证，且开集鲁棒
        if not self.hpc.contains(closure_ball(theta, self.eps_open)):
            return None, "APPROACH_UNSAFE"
        # 2) 释放闭合：松手后可达集不碰障碍、落在目标容差内
        R_post = self.release_reachable_set(obj, target, U_release, W, horizon=H)
        if intersects(R_post, obstacles(obj, node)):
            return None, "RELEASE_COLLISION"
        if not subset(R_post, inflate(target, self.eps_target)):
            return None, "RELEASE_OUT_OF_TARGET"
        # 3) 静置闭合：交给 SSC
        settle_ok, settle_reason = SSC.certify(R_post, obj, target)
        if not settle_ok:
            return None, settle_reason
        return PlacementCert(node, theta, R_post, target), "OK"


# IP-428 Settling Stability Certificate (SSC)
class SettlingStabilityCertificate:
    def __init__(self, delta_sup=0.02, delta_fric=0.15, phi_max=0.3):
        self.delta_sup = delta_sup
        self.delta_fric = delta_fric
        self.phi_max = phi_max

    def support_polygon_margin(self, contacts, com):
        SP = convex_hull([c.point for c in contacts])
        return dist_point_to_polygon(com_projection(com), SP)

    def friction_cone_margin(self, contacts, forces, mu):
        return min(mu * f.normal - norm(f.tangential) for f in forces)

    def potential(self, state):
        h_com = state.com.z
        tilt = angle(state.up, world_up)
        d_edge = dist_to_support_edge(state)
        return w1 * h_com + w2 * tilt + w3 * d_edge

    def certify(self, R_post, obj, target):
        # 在 R_post 上检查不变量，而非仅在标称落点
        for x in sample_boundary_and_interior(R_post):
            if self.support_polygon_margin(x.contacts, x.com) < self.delta_sup:
                return False, "SUPPORT_MARGIN"
            if self.friction_cone_margin(x.contacts, x.forces, x.mu) < self.delta_fric:
                return False, "FRICTION_MARGIN"
            if self.potential(x) > self.phi_max:
                return False, "TOPPLE_POTENTIAL"
        if not is_non_increasing(self.potential, R_post):
            return False, "POTENTIAL_INCREASING"
        return True, "OK"


# IP-429 Robust Placement Fallback Controller (RPFC)
class RobustPlacementFallbackController:
    def fallback(self, reason):
        if reason in ("RELEASE_COLLISION", "RELEASE_OUT_OF_TARGET"):
            return "FIXTURE_PLACE"        # 退到固定夹具，落点确定
        if reason in ("SUPPORT_MARGIN", "FRICTION_MARGIN", "TOPPLE_POTENTIAL"):
            return "HANDOVER"             # 交给人 / 外部支撑
        if reason in ("APPROACH_UNSAFE", "RELEASE_UNBOUNDED"):
            return "V20_TRANSPORT_ONLY"   # 只执行 v20 运输段
        return "REJECT"

    def execute(self, plan, decision):
        # 所有退化模式都是 v20 已认证动作的子集
        return self.v20_csc.execute(subset_plan(plan, decision))


# IP-430 Evaluation Reproducibility Ledger (ERL)
class EvaluationReproducibilityLedger:
    def __init__(self):
        self.entries = []
        self.prereg = None

    def preregister(self, strata, n_k, delta, alpha, kappa,
                    phi_max, delta_sup, delta_fric):
        self.prereg = dict(strata=strata, n_k=n_k, delta=delta, alpha=alpha,
                           kappa=kappa, phi_max=phi_max,
                           delta_sup=delta_sup, delta_fric=delta_fric)
        return hash_protocol(self.prereg)

    def register_run(self, robots, tasks, seeds, cert_version):
        entry = dict(robots=robots, tasks=tasks, seeds=seeds,
                     cert_version=cert_version, prereg_hash=hash_protocol(self.prereg))
        self.entries.append(entry)
        return merkle_append(entry)

    def verify_claim(self, claim):
        # 任何事后增删分层 / 换种子都必须重新注册
        if claim.prereg_hash != hash_protocol(self.prereg):
            return False, "PREREG_MISMATCH"
        if not subset(claim.robots, union(self.prereg["strata"].values())):
            return False, "UNREGISTERED_ROBOT"
        return True, "OK"

## 2. 推导

**引理 157（总体有效性下界）** 在分层抽样下，对每层 `S_k` 以置信度 `1−α/K` 用 Clopper–Pearson 得到成功率下界 `V_k^LB`。由 Bonferroni 不等式，`Pr[∀k, V(S_k) ≥ V_k^LB] ≥ 1−α`。取 `V_LB = min_k V_k^LB`，则 `Pr[∀k, V(S_k) ≥ V_LB] ≥ 1−α`。因最差分层下界不超过任何按层权重平均的总体下界，故 `V_LB ≥ 1−δ ⇒ V_pop ≥ 1−δ`。∎ 推论：**最差分层下界是总体有效性的保守充分条件，均值不能替代它**。

**引理 158（异质性分解的信息量）** 在 `Y_{r,t} = μ + b_r + e_{r,t}` 下，`Var(Y) = σ_b² + σ_e²`，`ICC` 为机器人身份解释的方差比例。若 `ICC ≥ κ`，则跨机器人平均成功率主要由机器人身份决定，单一全局证书在总体上的失败率无法由“平均性能”稳定预测；因此全局声明不具统计意义，必须按机器人条件化。∎

**引理 159（放置闭合保守性）** 由定义 `C_place = C_appr ∧ C_rel ∧ C_settle ⊆ C_appr`，而 `C_appr` 要求 `closure(N_ε(θ)) ⊆ v20 认证集`，故 `C_place ⊆ v20 认证域`。因此 `Exec_v21 ⊆ Exec_v20`；且开集鲁棒条件保证松手扰动下的状态仍落在认证集内。∎

**引理 160（静置不变量安全性）** 若在认证区域 Ω 上 `Φ(x) ≤ φ_max`、`Φ̇(x) ≤ 0`（沿含扰动 W 的接触动力学）、`δ_sup ≥ δ_sup^*`、`δ_fric ≥ δ_fric^*` 且 `Ω ∩ Obstacles = ∅`，则在刚性接触与有界扰动假设下，静置过程中不发生倾倒、滑移逃逸或碰撞。∎ 注：该引理对柔性 / 变形物体不成立，需由 RPFC 检测并回退。

**引理 161（回退安全性）** RPFC 的输出仅包含 `FIXTURE_PLACE`、`HANDOVER`、`V20_TRANSPORT_ONLY`、`REJECT` 四种模式，前两者把落点约束到固定支撑或外部承托，第三种直接复用 v20 运输证书，REJECT 为空动作。故所有回退结果都是 v20 认证动作的子集。∎

**引理 162（v21 整体安全继承）** 在同一几何快照、同一机器人集合、同一预注册评测协议下，`Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。证明：MREP/HDA 只决定“是否允许全局声明”，不扩张域；PCC 取三段交集，SSC 只在不变量成立时放行，RPFC 只做子集退化；六者叠加只能产生子集。∎

## 6. 已知风险与失效模式

1. **评测集偏置**：机器人分层若漏掉某类（柔性夹爪、低刚度臂），V_LB 会过度乐观。缓解：对抗分层、DRO 模糊集、外部机器人目录交叉验证。
2. **ICC 混杂**：任务难度与机器人身份相关时，ICC 会把“任务难”误归因为“机器人差异”。缓解：机器人×任务双向分解、随机任务分配。
3. **释放不确定性集错设**：真实接触动力学不连续且对初值敏感，`U_r` 若偏小，`R_post` 会漏掉真实落点。缓解：保守放大 `U_r`、用真实数据校准、在线残差检测。
4. **静置势函数非 Lyapunov**：非光滑摩擦接触下 `Φ̇ ≤ 0` 未必成立，刚性假设对软物体失效。缓解：分段势函数、接触仿真验证、柔性检测回退。
5. **zonotope 过近似过保守**：高维状态或长时间域下可达集膨胀，导致大量放置被拒。缓解：分段时间域、局部线性化、支撑函数优化。
6. **回退模式被滥用**：RPFC 频繁退到夹具 / 交接会显著降低活性。缓解：回退率监控、按场景分层统计。
7. **评测过拟合**：反复换机器人 / 换种子直到 V_LB 通过。缓解：预注册 + 种子账本 + 独立复核；任何协议变更视为新轮次。
8. **多机通信与时钟偏差**：CRN 要求同一扰动序列，若各机器人时钟不同步，配对比较失效。缓解：逻辑时钟、种子显式下发、时间戳对齐。

## 7. 本轮最大风险

**一句话**：总体有效性建立在有限且可能偏置的机器人分层样本上，而放置闭合又依赖对松手后接触动力学的有界扰动假设；若分层漏掉了具有系统性证书盲区的机器人类别、且真实释放动力学超出 `W`，则系统会同时获得“总体有效”的统计假象与“闭合成立”的模型假象，把从未被真正覆盖的机器人 / 放置场景判为安全——即“评测集偏置 × 释放混沌 = 总体有效性幻觉”。
