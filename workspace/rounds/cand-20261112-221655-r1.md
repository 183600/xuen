# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC；新产品线灵感循环第 1 轮；本轮灵感：「最小可行产品」×「机器人」）

> 第 61 轮把第 60 轮的场景-执行闭环推进为 ESEC：USR 统一语义表征、MEL 多模态具身大模型、DMS 多轮对话、SRT-Dual 语义-实时双流、PCE+++++ 六维预算。但站在「产品能否真的跑起来」的角度，暴露出**四个更根本的局限**：
> 1. **理论膨胀 vs 可部署性**：USR 需要四类编码器 + 256 维共享空间，MEL 需要 ViT-L + LLM，SRT-Dual 需要共享内存双流——**没有任何一条证据表明，存在一个在低成本机器人上可运行、且真实用户愿意用的最小子集**。复杂度本身成了部署门槛。
> 2. **横向分层 vs 纵向价值**：每轮都在「补一层模块」（语义层、对话层、双流层），但**从未有一条从用户一句话到物理结果、再回到用户反馈的端到端证据链**。任何一层的漂亮指标，都不能证明系统作为产品可行。
> 3. **指标 SOTA vs 产品价值**：前 61 轮用成功率、误差、抖动、证书通过率衡量，**缺少 integration cost、运维成本、用户认知负荷、安全风险的综合价值度量**——导致「基准更好」与「更值得部署」脱钩。
> 4. **安全被当作模块 vs 被当作不可约约束，技术债被隐性化**：安全内核、实时契约若被当成「以后再加的一层」，而被砍掉的模块又没有记录「为何砍、何时必须补」，系统就会永远停留在「差一层就完整」的演示状态，形成隐形技术债。

## 0. 直觉与动机

**灵感 1（最小可行产品 → 最小可行机器人 MVR 与能力契约）**
直觉：MVP 不是「功能少」，而是「用最小成本换到真实反馈，并让被砍掉的东西显性化」。机器人不是「会动」，而是「物理后果不可撤销、安全不能试错」。因此先定义 **最小可行机器人 MVR = (H_min, E_cap, T_task, K_safe, V_eval)**：最小硬件包、最小能力包、目标任务族、不可约安全内核、用户价值评价。可行性不再是一句口号，而是一个带约束的三元检验：**任务成功率 ≥ s_min、安全不变量成立、价值密度 VD ≥ v_min**——三者同时成立才叫「可行」，否则只是「能演示」。

**灵感 2（最小可行产品 → 垂直切片优先 VSF）**
直觉：前 61 轮是「横向分层」——先建语义层，再建对话层，再建双流。MVP 要求「纵向切片」：S0 遥操作保底 → S1 脚本化单任务 → S2 结构化语义总线 + 规则对话 → S3 才引入蒸馏 MEL。**每一片都必须端到端闭合**（语言→语义→控制→证据→用户反馈），任何一片没有闭合就不算可行。这迫使研究者最早面对真实摩擦，而不是在第 10 层才发现第 1 层接口错了。

**灵感 3（最小可行产品 → 语义债账本 SDL）**
直觉：被砍掉的 ESEC 组件不能悄悄消失，而要登记成一条「债」：**预期损失 L_d(t)、利息率 λ_d、升级触发 T_d、责任人**。触发条件必须是可测量的失败模式（零样本失败率超阈、澄清轮次 > 3、投影漂移 > ε、用户投诉率上升）。这把「以后再做」变成「何时必须做」的可证伪承诺：债不会消失，只会在某个可观测信号出现时被强制偿还。

**灵感 4（机器人 → 最小充分语义总线 MSB）**
直觉：机器人侧算力、时延、内存都有限，USR 的 256 维四编码器 + MEL 全模态不应是默认配置。构建 **最小充分语义总线 MSB**：以结构化锚点（任务、意图槽、物体属性、物理先验、不确定性、安全标志、版本）为默认表示；只有当某嵌入特征的**信息增益/成本**超过阈值 θ_ig 时，才把这一维加进总线。这把「表征能力」从「越大越好」改为「够用即可、按需加维」，且可给出子模优化的近似保证。

**灵感 5（机器人 → 不可约安全内核 NSK）**
直觉：MVP 可以砍感知、砍对话、砍大模型，**唯独不能砍安全**。构建 NSK = (硬限位、看门狗、证书校验、保守控制器、急停)。它作为 shield 永远在线：任何候选动作必须先过 NSK，不安全就投影到安全集或直接停机。关键洞见：**安全不是 ESEC 的一个模块，而是所有切片的准入前提**；因此「语义债账本」对 NSK 关闭——安全债恒为零。

**灵感 6（三灵感合流 → MVP-ESEC 能力阶梯 MRL-0~4）**
直觉：把「加什么、何时加」制度化。定义能力就绪等级：MRL-0 遥操作、MRL-1 脚本化单任务、MRL-2 MSB + 规则 DMS、MRL-3 ESEC 子集（蒸馏 MEL + SRT-Dual）、MRL-4 完整 ESEC 零样本。**每次升一级必须同时满足「债触发」与「价值密度提升 ≥ Δv_min」**，否则不升级。配套产品证书 J_mvp 把安全证明、任务证据、债账本、等级、价值密度绑定，用于审计与对外承诺。

**灵感 7（评价标准 → 价值密度 VD 取代 SOTA）**
直觉：把 integration cost、运维成本、安全风险纳入分母：VD = E[user_value] / (C_int + C_ops + λ_r·R_safety + λ_m·C_maint)。区分「演示成功」与「最小可行成功 MVS = Success ∧ Safety ∧ VD ≥ v_min」。这直接回应前 61 轮「指标漂亮但不可部署」的隐患。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（最小可行机器人 MVR 与能力契约）** MVR = (H_min, E_cap, T_task, K_safe, V_eval)。其中：
- **最小硬件包** H_min：支撑 T_task 的最小传感-执行集合（示例：6-DoF 机械臂 + 腕部 RGB-D + 六维力/力矩 + 两指夹爪；不含触觉皮肤、LiDAR、移动底盘）
- **能力包** E_cap：H_min 上可实现的原子技能集合（reach, grasp, place, insert, wipe…）
- **任务族** T_task：带用户价值分布 p(τ) 的目标任务集合
- **安全内核** K_safe = NSK（定义 178），不可裁剪
- **价值评价** V_eval：任务成功率、安全不变量、价值密度 VD（定义 181）
- **能力契约**：MVR 可行 ⇔ ∀τ∈T_task，∃垂直切片 σ，使 Success(σ,τ) ≥ s_min ∧ Safe(σ,τ)=True ∧ VD(σ,τ) ≥ v_min。三者缺一即判「不可行」，禁止用单项指标宣称可行。

**定义 174（能力-价值-风险三元筛选 CVT）** 对每个候选能力 c 定义三元组 (v(c), k(c), r(c))：
- v(c) = E_{τ~p}[Success(with c) − Success(without c)]：边际任务价值
- k(c) = k_int(c) + k_comp(c) + k_lat(c)：集成、算力、时延成本（折算到统一「工程小时」）
- r(c) = 加入 c 引入的安全/可靠性风险（0~1，NSK 可覆盖部分不计入）
选型问题：max_{S⊆C} Σ_{c∈S} v(c) − λ_k Σ k(c)，s.t. Σ k(c) ≤ B_int，r(c) ≤ r_max，且**任何降低 NSK 保障的能力一律禁止入选或必须由 NSK 等价替代**。结果按 MoSCoW 映射为 Must / Should / Could / Won't。

**定义 175（垂直切片 VS 与切片完整度）** 一个垂直切片 σ 是单任务上的端到端路径：
σ = (感知 → 语义 → 决策/对话 → 控制 → 执行证据 → 用户反馈)
- **切片完整度** ρ(σ) = min_{stage} coverage(stage)，coverage∈[0,1]
- **切片可行** ⇔ ρ(σ)=1 ∧ NSK 门通过 ∧ Success(σ,τ) ≥ s_min
- **切片阶梯** S0⊂S1⊂S2⊂S3：后一片只允许在「前一片已闭合且债触发」时启用，禁止跨级先建上层。

**定义 176（语义债账本 SDL 与升级触发）** 债记录 d = (capability, omit_reason, L_d(t), λ_d, T_d, owner)。
- **预期损失** L_d(t) = E_{τ~p_t}[loss from omitting d]：随任务分布漂移按 λ_d 增长（债的利息）
- **升级触发** T_d：可测量的失败信号（如 zero_shot_fail > θ_z ∧ clarification_turns > 3 ∧ proj_drift > ε）
- **总债** D(t) = Σ_{d∈Active} L_d(t)
- **规则**：(i) NSK 相关能力禁止记为债（安全债恒为 0）；(ii) 每条债必须有触发 T_d，否则视为无效登记；(iii) 活跃债数量 |Active| ≤ N_debt，超出则强制偿还最高 L_d 的债——用数量上限防止「无限延期」。

**定义 177（最小充分语义总线 MSB）** MSB = (A_struct, F_opt, g_select)：
- **结构化锚点** A_struct = (task_id, intent_slot, object_attrs, φ_phys_prior, uncertainty, safety_flags, version)，默认零嵌入
- **候选特征** F_opt：场景嵌入、对话嵌入、证据嵌入、阻抗嵌入等可选维
- **选维准则**：特征 f 入总线 ⇔ IG(f; success | A_struct) / cost(f) ≥ θ_ig，其中 IG 为条件互信息
- **优化**：在预算 B_bus 下最大化 Σ IG(f)，目标函数子模 ⇒ 贪心可达 (1−1/e) 近似
- **降级**：预算耗尽时冻结当前总线，仅保留 A_struct；MSB 是 IP-173 USR 的「按需展开」特例

**定义 178（不可约安全内核 NSK）** NSK = (hard_limits, watchdog, cert_checker, conservative_controller, emergency_stop)。
- **Shield 语义**：对任意候选动作 u，NSK(u) = u' 满足 u' ∈ C_safe；若无法投影则返回 stop
- **不变量**：任何 MRL 等级、任何预算耗尽、任何语义流超时，NSK 始终在线且优先
- **最小干预**：‖u' − u‖ 在 C_safe 内取最小（或按保守序），避免安全层破坏任务
- **不可债化**：SDL 不允许登记「安全能力」；NSK 的删除是系统级非法操作

**定义 179（MVP 三预算 PCE-MVP）** B_mvp = (B_int, B_comp, B_attn)：
- B_int：集成工程时间；B_comp：机载算力/内存；B_attn：人类注意力（标注、调参、澄清）
- 把第 61 轮六维 B_cog5 **降维**为三预算，因为 MVP 阶段其余维度不可观测，强行建模只会制造虚假精度
- **MVP 价值率** VOI_mvp(a) = ΔE[value | a] / (c_int + c_comp + c_attn)
- **降级**：预算耗尽 ⇒ 冻结新特征、回退到脚本化切片、降低澄清频率；**NSK 不降级**

**定义 180（具身 Build-Measure-Learn 循环 BMLE）** 状态 M_k = (build, D_k, G_k)。每轮：
1. 在活跃债与候选能力中选 VOI_mvp 最高者
2. 构建其最小垂直切片（不跨级）
3. 在 T_task 上用真实用户测量（成功率、安全、VD、认知负荷）
4. 用 MA（定义 184）归因，更新债账本与能力阶梯
5. 终止条件：max VOI_mvp < θ_stop 或所有能力契约满足
- **收敛前提**：边际价值随能力增加单调不增（diminishing returns）

**定义 181（价值密度 VD 与最小可行成功 MVS）**
```
VD(σ) = E_{τ~p}[user_value(σ,τ)] / (C_int + C_ops + λ_r·R_safety + λ_m·C_maint)
MVS(σ) ⇔ Success(σ) ≥ s_min ∧ Safe(σ)=True ∧ VD(σ) ≥ v_min
```
- user_value 由真实用户任务完成时间、返工率、主观可用性加权
- 「演示成功」只要求 Success；「最小可行成功」额外要求 Safety 与 VD——两者必须在报告中分开标注

**定义 182（能力就绪阶梯 MRL-0~4）**
| 等级 | 配置 | 退出判据 |
|---|---|---|
| MRL-0 | 遥操作 + NSK | 安全门 100% 通过 |
| MRL-1 | 脚本化单任务（无学习） | 单任务 Success ≥ s_1 且 VD ≥ v_min |
| MRL-2 | MSB + 规则 DMS | 3 个任务族 Success ≥ s_2，澄清 ≤ 3 轮 |
| MRL-3 | ESEC 子集（蒸馏 MEL + SRT-Dual） | 未见物体泛化 ≥ s_3，实时抖动达标 |
| MRL-4 | 完整 ESEC 零样本 | 目标分布 OOD 成功率 ≥ s_4 |
- **升级规则**：l → l+1 ⇔ 存在已触发的债 T_d 且 E[VD_{l+1} − VD_l] ≥ Δv_min；否则不升级（防止「为了发论文而升级」）

**定义 183（MVP 产品证书 J_mvp）**
```
J_mvp = (SafetyProof, TaskEvidence, DebtLedgerHash, MRL_level, VD, expiry)
Valid(J_mvp) ⇔ NSK_verified
             ∧ CI_lower(Success) ≥ s_min
             ∧ ∀d∈Active: T_d 已定义
             ∧ (无安全类债)
             ∧ (now < expiry)
```
- 证书随任务分布漂移而过期；过期必须重测而非自动续期

**定义 184（MVP 消融归因 MA）** 在 MVR 基准上对各组件 c 计算 Shapley 边际贡献：
```
φ_c = Σ_{S⊆C\{c}} [|S|!(|C|−|S|−1)!/|C|!] · (v(S∪{c}) − v(S))
下一优先能力 c* = argmax_c φ_c / k(c)，且仅当对应债已触发才允许实施
```
- 满足效率性 Σ_c φ_c = v(C) − v(∅)，保证归因可加、可审计

### IP-183 MVR 选型与能力契约编译

```python
def compile_mvr(task_family, hardware_envelope, capabilities, budget):
    # 1. 先固定 NSK（安全不可选、不可债化）
    nsk = NonNegotiableSafetyKernel(hardware_envelope)
    candidates = [c for c in capabilities
                  if not c.safety_relevant or nsk.covers(c)]

    # 2. 估计三元组 (v, k, r)
    scored = []
    for c in candidates:
        v = estimate_marginal_value(c, task_family, hardware_envelope)
        k = c.integration_cost + c.compute_cost + c.latency_cost
        r = c.risk if not nsk.covers(c) else 0.0
        scored.append((c, v, k, r))

    # 3. 约束贪心（预算 + 风险上限），NSK 强制项先入选
    selected, used, active_risk = [], 0.0, 0.0
    for c, v, k, r in sorted(scored, key=lambda x: x[1] / max(x[2], 1e-6), reverse=True):
        if r > budget.r_max:      continue
        if used + k > budget.B_int: continue
        selected.append(c); used += k; active_risk = max(active_risk, r)

    mvr = MinimumViableRobot(
        H_min=hardware_envelope, E_cap=selected, T_task=task_family,
        K_safe=nsk, V_eval=value_density_evaluator())

    # 4. 能力契约：逐任务族验证三元条件
    contract = {}
    for tau in task_family:
        slice_ = build_vertical_slice(tau, mvr)     # 必须端到端闭合
        ok = (slice_.rho == 1.0 and nsk.passes(slice_)
              and slice_.success >= s_min and slice_.vd >= v_min)
        contract[tau] = ok
    mvr.viable = all(contract.values())
    return mvr, contract
```

### IP-186 语义债账本

```python
class SemanticDebtLedger:
    def __init__(self, max_active=6):
        self.debts = {}          # id -> DebtRecord
        self.max_active = max_active

    def register(self, capability, omit_reason, loss_fn,
                 interest, trigger, owner):
        assert not capability.safety_relevant, "安全能力禁止记为债"
        assert trigger is not None, "每条债必须有可测量触发条件"
        self.debts[capability.name] = DebtRecord(
            capability, omit_reason, loss_fn, interest, trigger, owner,
            created_at=time.time(), status='active')
        if self.active_count() > self.max_active:
            self.force_repay(self.highest_loss())

    def tick(self, task_distribution):
        for d in self.debts.values():
            if d.status != 'active':
                continue
            d.loss = d.loss_fn(task_distribution) \
                     + d.interest * (time.time() - d.created_at)
            d.triggered = d.trigger.evaluate(task_distribution)

    def forced_repairs(self):
        # 已触发的债 = 强制升级候选；未触发的一律不动
        return [d for d in self.debts.values()
                if d.status == 'active' and d.triggered]

    def total_debt(self):
        return sum(d.loss for d in self.debts.values() if d.status == 'active')
```

### IP-187 最小充分语义总线 MSB

```python
def build_msb(anchor, candidate_features, budget_bus, theta_ig):
    # 结构化锚点是默认表示，零额外嵌入
    bus = {'anchor': anchor, 'features': []}
    remaining = budget_bus
    # 子模贪心：每步选「信息增益/成本」最高的特征
    while remaining > 0:
        best, best_ratio = None, 0.0
        for f in candidate_features:
            if f in bus['features']:
                continue
            ig = conditional_mutual_information(f, success, bus)
            cost = f.encode_cost
            ratio = ig / max(cost, 1e-6)
            if ratio >= theta_ig and ratio > best_ratio and cost <= remaining:
                best, best_ratio = f, ratio
        if best is None:
            break
        bus['features'].append(best)
        remaining -= best.encode_cost
    return bus   # 贪心近似保证 ≥ (1−1/e)·OPT
```

### IP-188 不可约安全内核 NSK

```python
class NonNegotiableSafetyKernel:
    def __init__(self, hw):
        self.hard_limits = hw.limits
        self.watchdog = Watchdog(timeout_ms=2)
        self.cert_checker = CertificateChecker()
        self.emergency_stop = EmergencyStop()

    def shield(self, u, state):
        # 永远在线：任何等级、任何降级路径都先过这里
        if not self.watchdog.alive() or state.impact_imminent:
            return Control.stop()
        u_safe = project_to_safe_set(u, self.hard_limits, state)
        if not self.cert_checker.verify(u_safe, state):
            return Control.stop()
        return u_safe   # 最小干预投影，避免安全层破坏任务

    def passes(self, slice_):
        return all(self.cert_checker.verify(a, s)
                   for a, s in slice_.action_trace)
```

### IP-190 具身 Build-Measure-Learn 控制器

```python
def bmle_loop(mvr, capability_pool, ledger, budget, theta_stop, dv_min):
    history = []
    while True:
        # 1. 候选 = 已触发债 ∪ 未实现能力；按 VOI_mvp 排序
        candidates = ledger.forced_repairs() + remaining(capability_pool)
        if not candidates:
            break
        a = max(candidates, key=lambda c: voi_mvp(c, budget))
        if voi_mvp(a, budget) < theta_stop:
            break

        # 2. 构建最小垂直切片（禁止跨级）
        slice_ = build_vertical_slice(a.task, mvr, level=mvr.mrl)
        if not nsk.passes(slice_):
            ledger.mark_blocked(a, reason='safety_gate')

        # 3. 真实用户测量
        result = user_study(slice_, mvr.T_task)

        # 4. 归因 + 更新
        phi = shapley_attribution(a, mvr, mvr.benchmark)
        mvr.update(result, phi)
        ledger.tick(mvr.task_distribution)

        # 5. 升级判定：债触发 ∧ 价值密度提升达标
        if (ledger.is_triggered(a)
                and result.vd - mvr.vd >= dv_min):
            mvr.upgrade_level()
        history.append((a, result, phi))
    return mvr, history
```

### IP-183 MVR 选型与能力契约编译

```python
def compile_mvr(task_family, hardware_envelope, capabilities, budget):
    # 1. NSK 先固定：安全不可选、不可债化
    nsk = NonNegotiableSafetyKernel(hardware_envelope)
    candidates = [c for c in capabilities
                  if not c.safety_relevant or nsk.covers(c)]

    # 2. 估计 (v, k, r)；NSK 可覆盖的风险不计入 r
    scored = []
    for c in candidates:
        v = estimate_marginal_value(c, task_family, hardware_envelope)
        k = c.integration_cost + c.compute_cost + c.latency_cost
        r = 0.0 if nsk.covers(c) else c.risk
        scored.append((c, v, k, r))

    # 3. 预算 + 风险约束贪心（按价值成本比降序）
    selected, used, active_risk = [], 0.0, 0.0
    for c, v, k, r in sorted(scored, key=lambda x: x[1] / max(x[2], 1e-6),
                             reverse=True):
        if r > budget.r_max or used + k > budget.B_int:
            continue
        selected.append(c)
        used += k
        active_risk = max(active_risk, r)

    mvr = MinimumViableRobot(
        H_min=hardware_envelope, E_cap=selected, T_task=task_family,
        K_safe=nsk, V_eval=value_density_evaluator())

    # 4. 能力契约：逐任务族验证三元条件，禁止单项指标宣称可行
    contract = {}
    for tau in task_family:
        slice_ = build_vertical_slice(tau, mvr)   # 必须端到端闭合
        contract[tau] = (slice_.rho == 1.0
                         and nsk.passes(slice_)
                         and slice_.success >= s_min
                         and slice_.vd >= v_min)
    mvr.viable = all(contract.values())
    return mvr, contract
```

### IP-186 语义债账本

```python
class SemanticDebtLedger:
    def __init__(self, max_active=6):
        self.debts = {}
        self.max_active = max_active

    def register(self, capability, omit_reason, loss_fn,
                 interest, trigger, owner):
        assert not capability.safety_relevant, "安全能力禁止记为债"
        assert trigger is not None, "每条债必须有可测量触发条件"
        d = DebtRecord(capability, omit_reason, loss_fn, interest,
                       trigger, owner, status='active',
                       created_at=time.time())
        self.debts[capability.name] = d
        if self.active_count() > self.max_active:
            self.force_repay(self.highest_loss())   # 防止无限延期

    def tick(self, task_distribution):
        for d in self.debts.values():
            if d.status != 'active':
                continue
            d.loss = d.loss_fn(task_distribution) \
                     + d.interest * (time.time() - d.created_at)
            d.triggered = d.trigger.evaluate(task_distribution)

    def forced_repairs(self):
        return [d for d in self.debts.values()
                if d.status == 'active' and d.triggered]

    def total_debt(self):
        return sum(d.loss for d in self.debts.values()
                   if d.status == 'active')
```

### IP-187 最小充分语义总线 MSB

```python
def build_msb(anchor, candidate_features, budget_bus, theta_ig):
    bus = {'anchor': anchor, 'features': []}   # 默认零嵌入，可运行
    remaining = budget_bus
    while remaining > 0:
        best, best_ratio = None, 0.0
        for f in candidate_features:
            if f in bus['features']:
                continue
            ig = conditional_mutual_information(f, success, bus)
            cost = f.encode_cost
            ratio = ig / max(cost, 1e-6)
            if (ratio >= theta_ig and ratio > best_ratio
                    and cost <= remaining):
                best, best_ratio = f, ratio
        if best is None:
            break
        bus['features'].append(best)
        remaining -= best.encode_cost
    return bus   # 子模贪心，≥ (1−1/e)·OPT
```

```python
class NonNegotiableSafetyKernel:
    def __init__(self, hw):
        self.hard_limits = hw.limits
        self.watchdog = Watchdog(timeout_ms=2)
        self.cert_checker = CertificateChecker()
        self.emergency_stop = EmergencyStop()

    def shield(self, u, state):
        # 所有 MRL 等级、所有预算降级路径都先过高危内核
        if not self.watchdog.alive() or state.impact_imminent:
            return Control.stop()
        u_safe = project_to_safe_set(u, self.hard_limits, state)
        if not self.cert_checker.verify(u_safe, state):
            return Control.stop()
        return u_safe   # 最小干预投影，避免安全层破坏任务

    def passes(self, slice_):
        return all(self.cert_checker.verify(a, s)
                   for a, s in slice_.action_trace)
```

```python
def bmle_loop(mvr, capability_pool, ledger, budget, theta_stop, dv_min):
    history = []
    while True:
        candidates = ledger.forced_repairs() + remaining(capability_pool)
        if not candidates:
            break
        a = max(candidates, key=lambda c: voi_mvp(c, budget))
        if voi_mvp(a, budget) < theta_stop:
            break

        slice_ = build_vertical_slice(a.task, mvr, level=mvr.mrl)
        if not mvr.K_safe.passes(slice_):
            ledger.mark_blocked(a, reason='safety_gate')
            continue

        result = user_study(slice_, mvr.T_task)         # 真实用户
        phi = shapley_attribution(a, mvr, mvr.benchmark)
        mvr.update(result, phi)
        ledger.tick(mvr.task_distribution)

        if ledger.is_triggered(a) and result.vd - mvr.vd >= dv_min:
            mvr.upgrade_level()                          # 债触发才升级
        history.append((a, result, phi))
    return mvr, history
```

### IP-192 MVP 消融归因

```python
def shapley_attribution(component, mvr, benchmark):
    components = mvr.active_components()
    others = [c for c in components if c != component]
    total = 0.0
    for r in range(len(others) + 1):
        for S in combinations(others, r):
            w = (math.factorial(len(S)) * math.factorial(len(others) - len(S))
                 / math.factorial(len(components)))
            total += w * (mvr.success(set(S) | {component})
                          - mvr.success(set(S)))
    return total   # 满足效率性 Σφ = v(C) − v(∅)

def next_capability(ledger, mvr, capabilities):
    triggered = {d.capability for d in ledger.forced_repairs()}
    cands = [c for c in capabilities if c.name in triggered]
    return max(cands, key=lambda c: abs(shapley_attribution(c, mvr, mvr.benchmark))
               / max(c.cost, 1e-6), default=None)
```

| E208 MA/J_mvp | 归因-消融相关性；证书通过率；SUS | ρ ≥ 0.85；≥ 99%；≥ 75 |

**对照**：第 61 轮 ESEC 全量为「重基线」，MRL-0 纯遥操作 + NSK 为「轻基线」；验证 MVP-ESEC 在「价值/成本」平面更靠近帕累托前沿，且安全违规率与重基线同为 0。

## 5. 本轮最大风险

**一句话**：MVP 最危险的失败不是「做少了」，而是把「安全/实时/分布外泛化」也当成可延期技术债，用演示场景的垂直切片伪装成产品可行性（Potemkin MVP）——必须以 NSK 永久在线、安全债恒为零、能力契约三元检验、J_mvp 证书过期重测四道闸门，确保「最小化」永远只作用于能力，不作用于安全。
