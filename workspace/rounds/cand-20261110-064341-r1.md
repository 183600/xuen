# 第 42 轮（新循环第 2 轮） · 6D 位姿估计 × 参数高效微调：把证书从「几何点断言」升级为「位姿集合上的可适配契约」（四层架构 v7）

> 承接第 41 轮 v18（运行时证书自动机 CAR × 轻量分层认证 LCS × 证书监控编译器 CMC）。第 41 轮自陈最大风险是**可用性崩塌**：一旦感知/模型不确定，单调保守性就把系统推向 Degraded/SafeStop。本轮灵感词「6D 位姿估计」「参数高效微调」正好提供两条**不必牺牲安全性就能恢复可用性**的杠杆：6D 位姿估计把「一个点 + 一个各向同性误差球」升级为「一个带覆盖保证的位姿集合」；参数高效微调把「改模型必破坏证书」升级为「在证书预算内做可证明不改变守卫符号的低秩编辑」。核心主张：**不确定性不是降级的理由，无法被安全地消解的不确定性才是。**

## 0. 直觉与动机

**灵感 1（6D 位姿估计 → 证书的对象应当是位姿集合，而不是位姿点）**：第 41 轮的几何守卫本质上假设「物体的位姿是已知的」。但真实抓取/装配里，6D 位姿估计给出的从来不是一个点：深度缺失、遮挡、反光、无纹理，以及**对称物体**（杯子、盒子、法兰、圆柱）都会产生多峰分布——一个杯子绕自身轴转 180° 在几何上完全等价，估计器却可能给出两个相距 π 的假设。若只取 top-1，证书是 unsound；若用一个足够大的各向同性误差球把两个模态都包住，证书 sound 但极其保守，Nominal 会被瞬间吃光。正确的对象是**带覆盖保证的位姿集合** \(C_t\)（例如 conformal 置信集），并把「物理上不可区分的位姿」按物体对称群 \(G_o\) 取商 \(C_t/G_o\)。于是守卫变成「对集合内所有**可区分**位姿都安全」，而不是「对最坏误差球安全」。这带来两个直接收益：其一，对对称物体，商空间把模态数直接减半，守卫不再被无意义的对称歧义拖入 Degraded；其二，集合可以显式区分**可约歧义**（多看一个视角就能消掉）与**不可约歧义**（对称/完全遮挡，怎么看都消不掉），为下一步动作提供依据。

**灵感 2（参数高效微调 → 适配不一定要重证，只要扰动落在证书预算内）**：第 41 轮的证书是部署前一次性颁发的，模型一改就失效。但真实落地必须适配新物体、新相机、新末端执行器。全量微调会不可控地改变 Lipschitz 常数与守卫边际；而 LoRA/Adapter 这类参数高效微调有一个非常适合做证书的结构：它把权重变化写成低秩扰动 \(\Delta W=BA\)，其谱范数可控、参数量极小。若守卫边际对权重扰动的敏感度有局部界 \(|\Delta m|\le L_e^\pi\|\Delta W\|_2 R_D\)，那么只要该上界小于当前「证书预算」\(b=m-\theta-\eta\)，适配就**不可能翻转任何守卫符号**——CAR 的归纳不变式原封不动。换句话说，PEFT 不是证书的敌人，而是可以在证书预算内执行的**受限编辑**。更重要的是，当域漂移（新物体外观、新光照）开始侵蚀边际时，一次可证的小适配可以把边际修回来，而不是把阈值调低或直接停机。

**耦合（问、改、停：把「不确定」从二元判决变成一条动作序列）**：位姿集合告诉我们「歧义有多大、是否可约」；PEFT 告诉我们「模型偏差能否在预算内修」；二者共同支撑一个**消歧-适配-降级调度器 ARL**：能通过安全的信息获取动作消掉的歧义，就先「问」（Ask）；能通过可证低秩编辑修掉的模型偏差，就再「改」（Adapt）；只有当歧义不可约或预算耗尽时，才「停」（Degrade/SafeStop）。这直接针对第 41 轮的可用性风险：v18 把「不确定」直接映射为「降级」，本轮把它映射为「先尝试用安全动作换取信息或修复，再决定是否降级」。安全性不靠乐观，而靠三条硬约束：Ask 必须保持在归纳不变式内，Adapt 必须满足证书预算，任何一条不满足就退回保守解释。

## 1. 形式化定义

**定义 32（6D 位姿置信集与对称商）**：给定观测 \(z\)、标定集 \(\mathcal{D}_{cal}\) 与非一致性分数 \(s(T,z)\)（可用位姿回归残差、假设分数或点云配准误差），取 conformal 分位数 \(q_{1-\delta}\)，定义
\[
C_t=\{T\in SE(3): s(T,z)\le q_{1-\delta}\},\qquad \Pr[T^\star\in C_t]\ge 1-\delta
\]
在可交换性下成立。设物体精确对称群为 \(G_o\le SE(3)\)（由 CAD 或训练时枚举的离散群给出），若守卫边际满足 \(m_e(x,T\circ g)=m_e(x,T)\) 对所有 \(g\in G_o\)，则定义**对称商位姿集** \(\bar C_t=C_t/G_o\)，并取每个轨道的一个规范代表。\(C_t\) 可分解为若干连通模态 \(M_1,\dots,M_K\)；记模态权重 \(w_k\)、直径 \(d_k\)，**位姿歧义度** \(A_t=H(w_1,\dots,w_K)\)（或 \(\max_k d_k\)，按守卫需要选用）。

**定义 33（位姿集合守卫 PSet-Guard）**：对每条 CAR 转移边 \(e\)，定义
\[
g_e^{pose}(x,\bar C_t)=\min_{T\in\bar C_t}\big(m_e(x,T)-\theta_e\big).
\]
用区间算术给出 \([lo,hi]\ni g_e^{pose}\)：\(lo\ge0\) 判为**接受**，\(hi<0\) 判为**拒绝**，否则**未定**。**单边可靠性**：若 \(lo\ge0\)，则在 \(1-\delta\) 置信下，所有物理上可区分的合理位姿都满足守卫；对称商不损失可靠性，因为被商掉的位姿在物理上与代表元不可区分。**命题 1（比误差球更紧）**：若 \(\bar C_t\subseteq B(\hat T,e)\)（以点估计为中心、半径 \(e\) 的误差球），则对任意 \(x\) 有 \(g_e^{pose}(x,\bar C_t)\ge g_e^{ball}(x,B(\hat T,e))\)；二者覆盖率相同时，集合守卫**至少同样可用**，且在对称/多峰情形严格更可用。

**定义 34（证书预算与证书保持的低秩适配 CAC）**：设基础策略权重为 \(W\)，低秩扰动 \(\Delta W=({\alpha}/{r})BA\)，\(\operatorname{rank}(BA)\le r\)，\(\rho=\|\Delta W\|_2\)。对守卫 \(e\) 与工作域 \(D\)（由激活范围、位姿集合与状态包络给出），若存在局部常数 \(L_e^\pi\) 使
\[
|m_e^{W+\Delta W}(x)-m_e^{W}(x)|\le L_e^\pi\,\rho\,R_D,\qquad \forall x\in D,
\]
定义**证书预算** \(b_e(x)=m_e^W(x)-\theta_e-\eta_e\)（\(\eta_e\) 为安全缓冲）。称 \(\Delta W\) 在 \(D\) 上**可容许**，当且仅当对所有守卫 \(e\) 与 \(x\in D\)：
\[
L_e^\pi\,\rho\,R_D\le b_e(x).
\]
此时所有守卫符号在 \(D\) 上不变，CAR 的归纳不变式保持。**适配证书** \(\mathrm{CAC}=(r,\rho,L_e^\pi,R_D,D,T_{valid},\delta)\) 记录上述量；超过 \(T_{valid}\)、离开 \(D\) 或检测到分布漂移即失效。**修复模式**：若当前边际已被模型偏差侵蚀，适配本身只能保证「不额外变坏」；要声称「修好了」，必须在适配后用独立标定集**重新颁发**证书，且新证书边际严格优于旧值。此约束禁止用适配去「洗白」一个本不成立的守卫。

**定义 35（可约/不可约歧义与安全消歧动作）**：在不变式 \(I\) 内允许的信息获取动作集合为 \(\mathcal{A}_{ask}\)（移动腕部相机、改变视角、增加曝光、轻触探测等）。对 \(v\in\mathcal{A}_{ask}\)，期望信息增益
\[
\mathrm{IG}(v)=H(\bar C_t)-\mathbb{E}_{z_{t+1}|v}\big[H(\bar C_{t+1})\big],
\]
成本为 \(c(v)\)（时间/能量/暴露风险）。**可约歧义** \(A_{epi}=\sup_{v\in\mathcal{A}_{ask}}\mathrm{IG}(v)\)；**不可约歧义** \(A_{irr}\) 为任意允许观测后仍残留的歧义下界（由对称群、遮挡锥或传感器视场给出）。**安全约束**：执行 \(v\) 的整条轨迹必须保持在 \(I\) 内，且不触发任何守卫拒绝；否则 \(v\notin\mathcal{A}_{ask}\)。**命题 2**：在 \(I\) 内执行 Ask 不可能破坏安全；若 \(\mathrm{IG}(v)>0\)，则 Ask 只能提高后续进入 Nominal 的概率。若 \(A_{irr}>\theta_A\)，则任何 Ask 都无法消歧，此时降级是**有根据的**，而不是保守性的副作用。

**定义 36（ARL 消歧-适配-降级调度器）**：调度器
\[
\sigma:(q,x,\bar C_t,\text{budget})\mapsto\{\text{Ask}(v),\text{Adapt}(r,\Delta W),\text{Degrade}\}
\]
按如下优先级运行：若所有守卫已判定 → 保持/进入 Nominal；若 \(A_{epi}>0\) 且存在安全 \(v\) 使 \(\mathrm{IG}(v)/c(v)\) 超阈值 → Ask；否则若存在可容许 CAC 且预测任务收益为正 → Adapt；否则 → Degrade。**安全定理**：若 (i) 位姿集合满足 \(1-\delta\) 覆盖，(ii) 每个被执行的 CAC 可容许，(iii) 每个 Ask 保持在 \(I\) 内，则 ARL 的所有动作都保持 \(I\)；系统进入 Degraded 仅当 \(A_{irr}\ge\theta_A\) 或预算耗尽。**可用性推论**：与 v18 的「歧义 ⇒ 降级」相比，ARL 把「可约歧义」和「可修模型偏差」从降级原因中移除，因此可用性严格不降（在上述假设下），且不会以放松守卫为代价。**命题 3（组合）**：两个适配证书的扰动界按三角不等式相加，\(\rho_{12}\le\rho_1+\rho_2\)；位姿集合按交集/乘积合成，守卫取各分量守卫的合取；因此技艺组合仍是带证书预算的乘积自动机。

**设计约束（证据单调保守性）**：当覆盖保证无法成立（可交换性被破坏、标定集与当前分布显著漂移）、CAC 过期/越域、或对称群无法精确确认时，必须退化为**最保守解释**：\(\bar C_t\) 取传感器一致的全位姿集（或 v18 的膨胀误差球），\(\Delta W:=0\)。任何「适配后看起来更好」的结论都必须有独立重认证，绝不能只用适配自身的界来自证。此约束把「证书洗白」堵在类型层。

## 2. 三大产出设计

### 2.1 IP-54 POSE-SET-CERT（位姿集合证书 PSC）
1. 6D 位姿前端输出 top-\(K\) 假设与分数；在 held-out 标定集上按物体类别做 conformal（必要时 Mondrian/条件 conformal），得到 \(C_t\) 与覆盖率证书。
2. 对称群检测与商化：只对 CAD 可验证的**精确**离散对称群取商；近似对称不取商，只按角度容差膨胀，避免把不同物理位姿错并。
3. 模态分解与歧义度量：对 \(C_t\) 聚类成 \(M_k\)，输出权重、直径、\(A_t\)、\(A_{epi}/A_{irr}\) 的可计算代理（对称/遮挡锥给出下界）。
4. 高效最坏情况守卫：不稠密枚举 \(T\)，而是对每个模态用位姿 Lipschitz 界
   \(m_e(x,T)\ge m_e(x,T_k)-L_{pose}\|T\ominus T_k\|\)，先在代表元算边际，再按模态直径打折；区间算术把离散化与舍入误差一并计入。
5. 与 CAR/LCS 接口：PSet-Guard 作为新的守卫维度；把「集合宽度/模态数」纳入决策等价精化，未定则升级档位或进入 ARL，而不是直接降级。

### 2.2 IP-55 CERT-PRESERVING-PEFT（证书保持低秩适配 CPT）
1. 适配位置：只修改证书敏感度低、边际余量大的层/头；对安全关键方向（高 \(L_e^\pi\) 的雅可比子空间）冻结或做零空间投影。
2. 证书预算计算：用幂迭代/区间界估 \(\rho\)，用激活包络估 \(R_D\)，用局部 LipSDP/采样给出 \(L_e^\pi\)；得到每条守卫的可用预算 \(b_e\)。
3. 秩与尺度选择：在 \(L_e^\pi\rho R_D\le b_e\) 约束下最大化预测任务收益；按「边际余量/敏感度」做贪心秩分配，避免把秩浪费在高敏感层。
4. CAC 颁发与注册：适配器携带 \((r,\rho,D,T_{valid},\delta)\)、组合规则与回滚点；服务总线路由前先查 CAC 是否覆盖当前位姿集合与制度。
5. 修复回路：检测边际侵蚀 → 提议适配 → 预算检查 → 独立重认证 → 接受/回滚；只有重认证后的新边际确实更大才允许替换旧证书。

### 2.3 IP-56 AMBIGUITY-RESOLUTION-LOOP（消歧-适配-降级闭环 ARL）
1. 歧义分解：用对称群、遮挡锥、视场与观测模型给出 \(A_{irr}\) 下界；用候选视角的信息增益给出 \(A_{epi}\)。
2. Ask：在 \(I\) 内选择视角/腕部运动/曝光/轻触，满足时间、能量与暴露预算；当 \(A_{epi}\) 低于阈值或收益/成本低于阈值即停止。
3. Adapt：仅当歧义主要来自模型偏差（位姿前端或策略的外观偏差）且存在可容许 CAC 时执行；否则不冒险改模型。
4. Degrade：仅当 \(A_{irr}\ge\theta_A\) 或预算耗尽；配滞回与最小驻留时间，避免 Ask/Adapt/Degrade 之间抖动（Zeno）。
5. 与 CAR/CMC 融合：Ask 是 Query 超态内的安全自转移；Adapt 是带 CAC 的参数 reset；CMC 看门狗同时监控「位姿集合覆盖是否仍有效」「CAC 是否过期/越域」，任一失效即 trip 到 SafeStop。

## 4. 实验设计（E79–E84，硬门槛）

## 5. 本轮最大风险

**一句话**：最大的风险不是「位姿集合太大」或「PEFT 界太松」这类保守性，而是**证书洗白**——conformal 覆盖依赖可交换性、CAC 依赖局部 Lipschitz 在工作域内成立，一旦真实分布漂移让这些假设静默失效，系统会在「看起来更可用」的同时欠覆盖地不安全；因此 E79 的覆盖率与 E81 的界违反率必须是硬门槛，任何漂移告警都应立即回退到 v18 的膨胀误差球与零适配。

# 第 42 轮产物 · 创新点清单 v19：位姿集合证书（PSC）× 证书保持低秩适配（CPT）× 消歧-适配-降级闭环（ARL）（四层架构 v7）

> 承接第 41 轮产物 v18（IP-48/49/50 + IP-51/52/53）。本轮**增量插入** IP-54/55/56，并升级 IP-39/43/45/46/47/48/49/50/51/52/53；不推倒 v18 的运行时证书自动机，而是给它补上**物体级证据**与**可证适配**：证书从「对一个位姿点成立」升级为「对一个带覆盖保证、按对称群取商的位姿集合成立」，模型从「改则失效」升级为「在证书预算内可改」。核心命题：**不确定性不应直接导致降级；只有不可消解的不确定性才有资格导致降级。**

## 0. 核心 IP 设计

## 1. 符号体系（承接定义 32–36）

| 符号 | 含义 | 定义 |
|---|---|---|
| \(C_t\) | 6D 位姿置信集 | \(\{T:s(T,z)\le q_{1-\delta}\}\)，\(\Pr[T^\star\in C_t]\ge1-\delta\) |
| \(G_o\) | 物体精确对称群 | CAD 可验证的离散子群；仅对精确对称取商 |
| \(\bar C_t\) | 对称商位姿集 | \(C_t/G_o\)；每个轨道取规范代表 |
| \(M_k,w_k,d_k\) | 模态/权重/直径 | \(C_t\) 的连通模态分解 |
| \(A_t,A_{epi},A_{irr}\) | 歧义度/可约/不可约 | \(A_t=H(w)\)；\(A_{epi}\) 为安全 Ask 的最大期望信息增益；\(A_{irr}\) 为残余下界 |
| \(g_e^{pose}\) | 位姿集合守卫 | \(\min_{T\in\bar C_t}(m_e(x,T)-\theta_e)\)，用区间 \([lo,hi]\) 判接受/拒绝/未定 |
| \(L_{pose}\) | 边际对位姿的 Lipschitz 常数 | 用于由代表元边际推整个模态下界 |
| \(b_e\) | 证书预算 | \(m_e-\theta_e-\eta_e\)；适配可消耗的余量 |
| \(\Delta W=(\alpha/r)BA\) | 低秩扰动 | rank≤r，\(\rho=\|\Delta W\|_2\) |
| \(L_e^\pi,R_D\) | 策略敏感度/激活包络 | \(|\Delta m|\le L_e^\pi\rho R_D\) 在 \(D\) 上成立 |
| CAC | 适配证书 | \((r,\rho,L_e^\pi,R_D,D,T_{valid},\delta)\)，可容许即守卫符号不变 |
| Ask/Adapt/Degrade | ARL 三动作 | 安全消歧 / 预算内修复 / 不可约时降级 |

## 2. 关键算法（伪代码）

### IP-54 PSC：位姿集合证书与集合守卫
```
def pose_set_cert(z, object_id, delta):
    H = pose_hypotheses(z, object_id)          # top-K (T_i, score_i)
    q = conformal_quantile(calib[object_id], delta)
    C = [T for (T, s) in H if nonconformity(T, z) <= q]
    G = exact_symmetry_group(object_id)         # CAD; None if not exact
    Cbar = quotient(C, G) if G else C           # orbits + canonical reps
    modes = cluster_modes(Cbar)                 # M_k, w_k, d_k
    return SetCert(Cbar, modes, A_t=entropy(w),
                   A_epi=..., A_irr=lower_bound(G, occlusion_cone(z)))

def pset_guard(x, cert, e):
    lo, hi = +INF, -INF
    for (Tk, dk) in cert.mode_reps():           # 代表元 + 模态直径
        m0 = e.margin(x, Tk)
        m_lo = m0 - e.L_pose * dk               # 位姿 Lipschitz 下界
        lo = min(lo, m_lo - e.theta)
        hi = max(hi, m0 + e.L_pose * dk - e.theta)
    if lo >= 0: return ACCEPT                   # 1-delta 下所有可区分位姿安全
    if hi <  0: return REJECT
    return UNDECIDED                            # 交给 LCS 精化或 ARL

def symmetry_safe(T, G, eps):
    return G is not None and exact_group_verified(G, eps)   # 近似对称不取商
```

### IP-55 CPT：证书预算与低秩适配
```
def cac_budget(cert, e, D):
    return cert.margin[e] - e.theta - e.eta          # 可用余量

def admit(dW_BA, e, D, budget):
    rho = spectral_norm(dW_BA)                       # power iteration
    Lpi = local_lipschitz_policy(e, D)               # LipSDP / interval / sampling
    RD  = activation_envelope(D)
    return Lpi * rho * RD <= budget

def choose_adapter(layers, margin_budget, task_loss):
    # knapsack: maximize predicted gain subject to L*rho*R <= budget
    ranks = greedy_rank_by_headroom(layers, margin_budget)
    B, A = low_rank_fit(task_loss, ranks)
    project_out(BA, sensitive_subspace(layers))       # freeze safety-critical dirs
    if not all(admit(BA, e, D, cac_budget(cert, e, D)) for e in guards):
        return reject_or_shrink_rank(BA)
    return CAC(rank=r, rho=spectral_norm(BA), Lpi=..., D=D,
               T_valid=..., delta=delta)

def repair_loop(cert, shift):
    if not drift_detected(shift): return cert
    dW = propose_adapter(shift)
    cac = issue_if_admissible(dW, cert)
    if cac is None: return cert                       # 不改，保持保守
    new_cert = recertify_after_adaptation(cac)        # 独立标定集，禁止自证
    return new_cert if new_cert.margin > cert.margin else cert
```

### IP-56 ARL：消歧-适配-降级调度
```
def arl_step(q, x, cert, budget):
    if all(guards_decided(q, x, cert)):
        return NOMINAL
    if cert.A_epi > 0 and (v := best_safe_view(cert)) is not None:
        if IG(v) / cost(v) > theta_ask and keeps_invariant(x, v):
            return ASK(v)                              # 安全信息获取
    if cert.A_irr < theta_A and (cac := find_admissible_cac(cert)) is not None:
        if predicted_gain(cac) > theta_adapt:
            return ADAPT(cac)                          # 预算内修复
    return DEGRADE                                     # 不可约/预算耗尽
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| IP-54 pose set | 每帧 O(K·(|z|+conformal 查询))；商化 O(K·|G|) | 可交换性下覆盖≥1−δ；精确对称商不损失 soundness |
| IP-54 PSet-Guard | 每守卫 O(K)（模态数，通常 1–4） | 命题 1：\(\bar C_t\subseteq B\) 时 \(g^{set}\ge g^{ball}\)，同覆盖率下更可用 |
| IP-55 CAC | 每适配 O(r·层宽 + 幂迭代)；离线预算分钟级 | 可容许 ⇒ \(D\) 上所有守卫符号不变 ⇒ CAR 归纳不变式保持 |
| IP-55 组合 | O(适配器数)；界按三角不等式相加 | \(\rho_{12}\le\rho_1+\rho_2\)；组合后重查预算 |
| IP-56 ARL | 每拍 O(|Ask|+|guards|)；Ask 视点数常数 | 命题 2/3：Ask/Adapt 保 \(I\)；仅 \(A_{irr}\ge\theta_A\) 或预算耗尽才降级 |
| IP-51/52/53（升级） | 沿用 v18 + 集合/ CAC 常数开销 | 沿用归纳不变式；CMC 单边可靠，覆盖/CAC 失效即 trip |

**正确性要点**：
1. **集合守卫的 soundness 来自覆盖，不来自估计精度**：只要 \(T^\star\in C_t\)，且 \(lo\ge0\)，则真实位姿满足守卫；即使估计器点估计错得离谱，也不会产生「误判 safe」。
2. **对称商只在精确对称下使用**：若非精确对称被误判，可能把不同物理位姿合并，破坏 soundness；因此代码强制 `exact_group_verified`，否则不取商。
3. **CAC 只保证「不变坏」**：适配后可容许只说明守卫符号不变；若要宣称边际提升，必须独立重认证（`recertify_after_adaptation`），否则就是证书洗白。
4. **ARL 的安全性与可用性分离**：Ask/Adapt 都在 \(I\) 内，安全性由不变式保证；可用性由「可约歧义被消掉多少」决定，二者可分别度量与守门。

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 证书洗白：conformal 可交换性失效 / CAC 局部界越域 | 高 | 在线漂移检测 + 条件/Mondrian conformal；CAC 带 \(D,T_{valid}\)；任一失效即回退 v18 球与零适配；E79/E81 硬门槛 |
| 对称群误判导致错误商化 | 高 | 只对 CAD 精确对称取商；近似对称按容差膨胀；反例测试；不确定则不商 |
| 位姿集合过大 → 仍然保守/降级 | 中 | 条件 conformal、模态分解、位姿 Lipschitz 打折；ARL 主动消歧；E80 以 Nominal 守门 |
| CAC 界太松 → 适配被过度限制 | 中 | 局部 LipSDP/分段 Lipschitz；按层预算；只改低敏感层；必要时只做最后一层适配 |
| Ask 增加时间/暴露/能耗 | 中 | 信息增益/成本比阈值；单步/固定候选视角回退；与续航证书联合预算 |
| Ask/Adapt/Degrade 抖动（Zeno） | 中 | 滞回 + 最小驻留 + 单次 Ask 上限；E83 检查有界驻留 |
| 适配器组合爆炸或相互抵消 | 中 | 三角不等式预算、组合后重证、注册表中心化管理；只对任务相关组合展开 |
| 6D 位姿前端本身漂移 | 中 | 前端集成到 IP-54 的可观测性证书；漂移超阈即扩大集合而非降低阈值 |
| 位姿集合与 LCS 档位耦合导致算力回升 | 低-中 | 模态数上限 K；代表元 + Lipschitz 代替稠密枚举；超预算降级到 P0 |

## 6. 本轮最大风险

**一句话**：最大的风险是**证书洗白**——位姿集合的覆盖率与低秩适配的扰动界都建立在可交换性、精确对称与局部 Lipschitz 这些会在真实漂移下失效的假设上；一旦假设静默失效，系统会以「更可用」的外观换取欠覆盖的不安全。因此 E79（覆盖率/误 safe=0）与 E81（界违反=0）必须与 E80/E82/E84（Nominal/收益/端到端）同时守门，任何漂移告警都回退到 v18 的膨胀误差球与零适配。
