# 新循环第 1 轮（基线 v9；本轮灵感：「通用机器人平台」×「论文发表」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**具身无关 + 证据可发表**。两个灵感分别治理 v9 的两种债：**可移植债**（所有证书、退化链、块长门控都暗含单一具身的动力学/时延/传感假设）与**可信债**（IP 越堆越多，但「贡献」仍是叙事而非可证伪的证据）。硬约束：平台抽象失效 ⇒ 退回平台特定 v9 证书（行为严格等价）；证据台账失效 ⇒ 仅影响报告、不影响运行时（安全上零耦合）。

## 0. 直觉与动机

**灵感 1（通用机器人平台 → 具身无关契约与证书迁移）**
直觉：轮式底盘、四足、机械臂、飞行器共享的是"安全论证的结构"，不是"论证的数值"。v9 的 d_brake、F̂、中止点集全是某个具身的函数。要变成"通用平台"，不应复制代码，而应复制**证明**：把平台压成一个安全相关画像 P，只在**证书等价类（CEC）**内迁移证书；跨类时用平台态射的失真界给证书"充气"（β'=β+β_emb，d_safe'=d_safe+ε_emb）。核心创新：**平台契约套件（PlatformContractKit, PCK）**——画像 + 等价类 + 迁移规则 + 部署期探针自辨识；辨识未收敛前强制使用保守**引导证书**。

**灵感 2（论文发表 → 预注册证据台账与自文档化）**
直觉：审稿人不会数模块，只会问"哪个主张被哪个实验、以多大效应量、排除了哪些替代解释地支持"。把发表纪律写进系统：每条主张配一张**主张卡**（假设/机制/指标/可证伪谓词 ψ/预注册门槛/威胁清单），运行期自动产出证据钩子，离线用**证据台账（EvidenceLedger, EL）**做只追加、哈希链的证据溯源。核心创新：把 v9 的在线消融归因升级为"在线发现 + 离线确证"的双轨证据，并定义**消融完备性阶**与**叙事债**，让"14 个 IP"从负担变成可审计资产。

**两灵感的交点（关键）**：通用平台把证据负担乘以平台数——每条主张的支持度不再是标量，而是**按 CEC 分层的向量**；发表纪律反过来约束"通用"声明：未在 CEC 外层测过，只能声称"平台特定"，不能声称"通用"。二者共同定义**可移植性-证据前沿（Portability-Evidence Frontier）**。

## 1. 研究问题（轮次升级版）

- **Q1（证书迁移）**：在何种平台态射失真界 (ε_emb, β_emb) 下，充气证书在目标平台上保持保守？等价类关系是否可传递，链式迁移的充气如何累积？
- **Q2（自辨识安全）**：部署期探针在多少步、何种激励下能辨识制动族与时延画像？辨识收敛前的引导证书凭什么保证不越界？
- **Q3（证据健全性）**：主张卡 + 只追加台账如何防止事后调参/HARKing？消融完备性阶能否给"贡献"估计一个可证误差界？
- **Q4（跨平台证据）**：如何在不做全平台笛卡尔积实验的前提下，报告"通用性"的分层证据而不虚报？

## 2. 设计原则（在 P1–P12 基础上新增 P13–P15）

**P13 具身无关证书迁移律（Embodiment-Agnostic Certificate Transfer, PCK）**
证书按平台等价类迁移：若 P2 与 P1 间存在 ε-态射 (ε_emb, β_emb)，则 P1 的证书在 P2 上以充气参数 (β+β_emb, d_safe+ε_emb, K_max·κ_len) 保守成立；充气只增不减，链式迁移充气按三角不等式累积。任何态射失真超阈 ⇒ 该 CEC 拒绝迁移，回退平台特定 v9 证书。

**P14 引导安全律（Bootstrap Safety, PCK）**
平台自辨识未收敛（探针后验方差 > σ_probe）前，系统只允许使用**引导证书**：K_eff=1、d_safe 取画像先验上界、β 取最大类间失真。辨识收敛并经双探针一致性核验后，才允许恢复 v9 的分块执行。

**P15 证据不删改律（Evidence-Not-Rewrite, EL）**
证据台账只追加、哈希链锚定；主张卡在实验前冻结（pre-registration manifest 哈希入链）；任何后验修改必须新增一条"修订主张"而非覆盖原卡。运行时仅写入证据钩子、从不读取台账，故 EL 失效不影响安全路径。

## 3. 与基线的接口（如何退化）

- PCK 态射超阈 / 等价类拒绝 / 辨识不收敛 ⇒ K_eff←1、使用平台特定 v9 证书，等价 v9；
- PCK 整体失效 ⇒ 关闭迁移，回到"每平台一套 v9 配置"；
- EL 失效 ⇒ 主张默认标为 unsupported，报告退回 v9 叙事，运行时行为不变（零耦合）；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 引理 83–86 逐级退化，回退 v8/v7/v6；
- 全部失效 ⇒ 完整退回 v6。

## 4. 预期贡献

1. **具身无关证书迁移**框架：平台画像/等价类/态射充气/探针引导，把"换机器人重做安全论证"变成"类内迁移 + 跨类有界充气"；
2. **预注册证据台账**：主张卡 + 只追加哈希链 + 消融完备性阶，给"贡献"以可证伪、可复现的统计语义；
3. **可移植性-证据前沿**：跨平台证据的分层报告法，显式区分"平台特定"与"类内通用"，用叙事债单调性阻止廉价的通用性声明；
4. **零耦合安全/报告分层**：运行时安全路径与离线证据路径彻底解耦，EL 的任何故障都不改变机器人行为。

## 5. 本轮最大风险

**一句话**：平台等价类与充气界是在少数具身上标定的，而"通用"的发表激励会诱导把边界平台事后纳入等价类（platform HARKing），使迁移证书看似普适、实则只对已测平台保守——通用性声明在最未测的具身上最先失效。

**新增定义 540（平台安全画像 PlatformSafetyProfile）** P = (A, S, D, B, Λ, Ξ, σ_s)。其中 B = {d_brake(·; θ)} 为制动族（θ 含最大减速度、响应延迟、地面附着系数区间），Λ 为传感→执行全链路时延分布，D 为质量/惯量/摩擦包络。P 只保留**安全相关**分量，其余（品牌、关节数、颜色等）不进入画像——这是等价类有意义的前提。

**新增定义 541（ε-平台态射 PlatformMorphism）** 映射 φ=(φ_S,φ_A) 满足：
```
∀(s,a):        d_S(φ_S(s), s')            ≤ ε_state
sup_v |d_brake^{P2}(φ_A(v)) − d_brake^{P1}(v)| ≤ ε_brake
sup_{s,a} ‖F̂^{P2}(φ(s,a)) − φ(F̂^{P1}(s,a))‖ ≤ β_emb
|Λ_2 − Λ_1|                                ≤ ε_lat
```
合并制动失真 ε_emb = ε_brake + v_max·ε_lat（时延按最高速折算为额外刹停距离）。

**新增定义 542（证书等价类 CEC）** P1 ~_ε P2 ⇔ 存在 ε-态射且 ε_emb ≤ ε_max、β_emb ≤ β_max。注意 ~_ε **一般不可传递**（失真界逐跳累积），故定义 n-hop 迁移：ε^{(n)} ≤ Σ_{j=1}^{n} ε_max，n > H_hop 一律拒绝。论文中必须报告 hop 数与累积充气，禁止把多跳伪装成单跳。

**新增定义 543（充气迁移规则 InflationRule）**
```
β'      = β + β_emb
d_safe' = d_safe + ε_emb
K_max'  = max(1, ⌊K_max · (1 − β_emb/β_max)⌋)
迁移接受 ⇔ β' ≤ β_cap ∧ d_safe' ≤ d_safe_max ∧ K_max' ≥ 1
否则拒绝 → 平台特定 v9 证书（K_eff=1）
```
充气只增不减；迁移记录写入 provenance 字段（源画像哈希、态射、充气量、跳数），供证据台账审计。

**新增定义 544（平台自辨识探针 ProbeProtocol）** 用两段互不相同的激励辨识 θ 与 Λ：斜坡制动扫描（估计最大减速度与响应延迟）与阶跃响应（估计时延与超调）。收敛判据：后验方差 σ_probe ≤ σ* **且** 两探针估计差 |θ̂1−θ̂2| ≤ ε_rep（双探针一致性，排除粗差误判）。未收敛 ⇒ 输出 BootstrapCertificate：K=1、d_safe = 先验上界（含最坏附着/最坏时延）、β = β_max。

**新增定义 545（主张卡 ClaimCard）** CC_i = (id, h_i, mechanism, μ_i, ψ_i, δ_i, ρ_i, T_i, scope)。ψ_i 为可证伪谓词（如 "在 CEC-轮式上，AC 使中止成功率 ≥99%"），δ_i 为预注册最小效应量，ρ_i = H(CC_i) 为冻结哈希，T_i 为威胁清单（如"收益仅来自增加候选采样数"），scope 为允许声称的 CEC 集合。

**新增定义 546（证据台账 EvidenceLedger）** 只追加 DAG：节点 = (claim_id, experiment_id, profile_hash, seed, effect_size, CI, protocol_hash)；边 = support / attack。哈希链：
```
h_j = H( h_{j-1} ‖ ρ_claim ‖ canonical_json(record_j) )
```
支持以**按 CEC 分层的向量**表示 supp_i = {c ↦ (δ̂, CI, n_seeds)}，禁止把不同 CEC 的证据平均成单一分数。

**新增定义 547（证据覆盖率与叙事债）** 权重 w_i（按主张重要性/风险归一）：
```
Cov_i = 1[ ∃ 预注册通过 : δ̂ > δ_i ∧ CI_{95%} 不含 0 ∧ T_i 全部关闭 ]
D_narr = Σ_i w_i · (1 − Cov_i)
```
论文/报告必须同时给出 Cov、D_narr 与每个 CEC 的分层 Cov——单一总数视为不充分报告。

**新增定义 548（消融完备性阶 AblationCompletenessOrder）** Ord_k 表示所有 ≤k 因子子集均已测。声称"模块 m 贡献 g"在 Ord_k 下可接受，仅当未测高阶交互的残差上界 Σ_{|S|>k}|interaction_S| ≤ η_g；否则主张降级为"相关性"而非"因果贡献"。v9 的 ID 在线归因只能作为 Ord_1 的候选发现，不能直接充当发表级因果证据。

**新增定义 549（复现决定论 ReplayDeterminism）** 给定 (seed, profile_hash, manifest_hash)，管线输出逐位一致的日志序列：契约排序按 (deadline, priority, H(name)) 确定性打破平局，每模块独立 RNG 子流（substream = H(seed‖module‖cycle)），浮点累加顺序固定。

```python
        self.chain, self.records = [genesis_hash], []

    def append(self, card, record):
        assert sha256(card.canonical()) == card.rho      # 预注册哈希校验
        payload = canonical_json(record)
        h = sha256((self.chain[-1] + card.rho + payload).encode()).hexdigest()
        self.chain.append(h)
        self.records.append((h, card.id, record))

    def accept(self, card, cec):
        # 预注册谓词 + 95%CI 排除 0 + 效应量 ≥ δ + 威胁关闭
        ev = [r for (_, cid, r) in self.records
              if cid == card.id and r['cec'] == cec]
        if not ev:
            return False
        d_hat = pooled_effect(ev)
        return (d_hat > card.delta and ci95(ev).excludes_zero()
                and all(t.closed for t in card.threats))

# ---------- 主闭环集成（EL 只写不读，安全零耦合） ----------
def metricvoicegauge_round_10(M, s, obs, platform, ...):
    # 1) 部署期：平台辨识（一次性/换平台时）
    ident = probe.identify(platform)
    if isinstance(ident, BootstrapCertificate):
        cfg = v9_platform_specific_config(platform)   # 等价 v9，K_eff=1
    else:
        base = v9_local_chunks(platform)              # 本地生成证书
        cfg  = pck.transfer(base, platform, platform) or base

    # 2) 运行时：完全走 v9 闭环（安全路径不含 EL）
    C, spatial, claims, metrics, rewards = v9_closed_loop(M, s, obs, cfg)

    # 3) 证据钩子：只追加，不读取，不影响返回值
    try:
        ledger.append_async(EvidenceRecord(cycle=now(), profile=platform.profile_hash,
                                           seeds=cfg.seed, metrics=metrics))
    except Exception:
        pass                                          # EL 故障 = Level-5，无行为改变
    return C, spatial, claims, metrics, rewards
```

## 4. 推导

**引理 87（充气迁移保守性）** 设源平台证书在源平台保守：∀k, g^{P1}_k ≥ ĝ_min。若 P2 与 P1 间存在 ε-态射且 ‖F̂^{P2}−φF̂^{P1}‖ ≤ β_emb、|d_brake^{P2}−d_brake^{P1}| ≤ ε_emb，则充气证书 (β'=β+β_emb, d_safe'=d_safe+ε_emb) 在 P2 上保守。
证明：g^{P2}_k ≥ F̂^{P2}_k − β_true ≥ (F̂^{P1}_k − β_emb) − β_true ≥ (ĝ_min + β) − β_emb − β = ĝ_min − β_emb。若要求 g^{P2}_k ≥ d_safe，只需 ĝ_min − β_emb ≥ d_safe，即采用 d_safe'=d_safe+ε_emb 与 β'=β+β_emb 的联合保守判据（当 β_true^{P2} ≤ β）。制动侧：d_brake^{P2} ≤ d_brake^{P1}+ε_emb，故原停车不变式加 ε_emb 余量后仍成立。∎

**引理 88（等价类不可传递与链式充气界）** ~_ε 一般不传递。反例：P1→P2 与 P2→P3 各有 ε 失真但方向相反，合成失真可达 2ε。定义 n-hop 充气为 ε^{(n)}=n·ε_max、β^{(n)}=n·β_max，由三角不等式得上界；n>H_hop 拒绝迁移。故论文只能声称"≤H_hop 跳内保守"，不得把多跳写成单跳。∎

**引理 89（探针收敛前的引导安全）** 辨识未收敛时 K=1、d_safe 取画像先验上界、β 取最大类间失真，则系统行为等价于"v9 单步 + 最坏情形余量"。由 v9 引理 81（单步安全）与 d_safe 的先验上界性，任一步都满足停车不变式；双探针一致性核验以 |θ̂1−θ̂2| ≤ ε_rep 排除粗差误判，若两探针不一致则继续停留在引导证书。∎

**引理 90（PCK 退化与 v9 逐位等价）** 若迁移被拒、态射超阈或探针未收敛，PCK 返回该平台的 v9 配置（K_eff=1、平台标定证书）。此分支不读取任何 CEC 数据，控制路径与 v9 完全相同，故逐位等价。推论：PCK 的失败只会减少通用性，不会降低安全。∎

**引理 91（证据台账健全性）** 主张卡以 ρ_i=H(CC_i) 冻结并入链；记录哈希 h_j 链式覆盖 h_{j-1} 与本条载荷。任何对历史主张或证据的后验篡改都会破坏某条哈希关系（可由第三方从创世哈希重放检出）。接受谓词要求预注册 ψ_i、CI 不含 0、效应量 ≥δ_i 且威胁关闭，故"事后挑结果"无法生成可通过的记录。∎

**引理 92（消融完备性误差界）** 若实测 Ord_k，则未测高阶交互的贡献估计偏差 = Σ_{|S|>k} interaction_S。当 k=2 时若该残差 ≤ η_g，则"m 贡献 g"的估计误差 ≤ η_g；否则只能声称相关。ID 的在线 c_m 属 Ord_1 发现信号，不满足发表级因果门槛。∎

**引理 93（复现决定论）** 契约排序确定、每模块独立 RNG 子流、浮点累加顺序固定 ⇒ 给定 (seed, profile_hash, manifest_hash) 时事件序列唯一。归纳于周期数即可：每周期输入确定、调度确定、RNG 子流确定、累加顺序确定，故输出确定。∎

**引理 94（叙事债单调性）** 若把主张 i 的 scope 从 CEC 集 S 扩大到 S∪{c} 而 c 上无预注册证据，则 Cov_i 不增、D_narr 不减（分层支持向量要求每个 c 单独满足接受谓词）。故"通用"声明不可能比"平台特定"声明更廉价——这是防止 platform HARKing 的结构性约束。∎

## 8. 本轮最大风险

**一句话**：平台等价类与充气界是在少数具身上标定的，而"通用"的发表激励会诱导把边界平台事后纳入等价类（platform HARKing），使迁移证书看似普适、实则只对已测平台保守——通用性声明在最未测的具身上最先失效。
