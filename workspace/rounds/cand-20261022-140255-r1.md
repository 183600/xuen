# 想法区 · 第 1 轮：从 X-DUB/AG* 到 X-DUB/DA

**灵感词**：dynamic analysis / derandomization / 算法范式  
**起点**：v0.5「X-DUB/AG*」——一致 A\* + 贪心焦点 + 证书/状态泛化  
**本轮性质**：不推翻 v0.5 的任何定理。只补三个它没有闭合的结构性缺口：**搜索不会观测自己的间隙**、**核心循环里仍有采样**、**搜索范式没有理论**。

---

## 一句话直觉

v0.5 的证明 DAG 是一台很强的**静态证书机器**，但它不会**观测自己**：它不知道当前 `U-L` 的间隙来自优先约束还是装箱，不知道 focal 何时在空转，也不知道自己还有哪些选择是"采样"出来的。

本轮让搜索学会三件事：

1. **看见间隙**（GAP-LEDGER）：把 `U-L` 拆成 `G_search + G_cert`，并给每个证书族一个**零装箱测试**的收益上界 `η`；
2. **把采样换成带证明的确定性构造**（DERAND）：窗口扫描变成二级 B&B，focal 截断变成容许带内的确定性选择，MCTS rollout 变成 MCE dive；
3. **把搜索范式变成可切换的自动机**（PARADIGM-AUTOMATON）：DIVE / CLIMB / CERT / MERGE 四态，切换由 ledger 决定，并证明切换只改顺序、不改剪枝。

---

## 1. 三个缺口，不是三个标签

### 缺口 A：证书族是"盲投"的

v0.5 在根上跑 THRESH，在内部节点跑 `AVAIL(U-1)`。但第 7 轮实验已经诚实报告：20 个"贪心上界比 OPT 差 ≥2"的根实例上，THRESH **一次都没有**闭合剩余间隙。原因是这些间隙来自优先约束和机器分配，装箱证书再强也碰不到。

v0.5 知道这个负结果，却没有把它变成算法：它只是把 THRESH 调成"每 `T_scan` 次扩展跑一次"。

> **dynamic analysis 的启发**：不要问"这个证书族平均好不好"，要问"在当前这个状态上，它**可能**改变 `L_loc` 吗？"

这个问题的答案可以是一个**零装箱测试**的算术判据。见 §3 的 `η` 与 `slack`。

### 缺口 B：focal 与 best-first 的取舍没有理论

v0.5 证明了 `f(child) ≥ f(parent)`，但只用它来说"不需要 reopening"。它没有用这个性质解释 anytime 与节点数的分裂：

- focal 在 25 次扩展时已 29/30 找到 OPT，但最终节点数不一定最少；
- best-first 最终节点数不错，anytime 却差。

> **算法范式的启发**：这不是两个启发式的竞争，而是 **gap 的两端**。把"搜索"拆成 `DIVE`（降 `U`）与 `CLIMB`（抬 `f_min`），让切换由 ledger 决定，并证明切换不影响精确性。

### 缺口 C：核心循环里仍有采样

窗口扫描顺序、`B_focal` 截断、MCTS rollout、bandit 选择——它们不影响正确性，但让实验不可复现，也没有最坏保证。v0.4 的 bandit 负结果（只匹配最佳固定顺序）已经说明：**在廉价特征下，统计泛化不是出路**。

> **derandomization 的启发**：不是"固定随机种子"，而是换成**带精确性/支配性证明的确定性构造**。

---

## 2. 关键观察：一致性把 gap 劈成两个单调驱动

### 引理（`f_min` 单调）

若每步展开一个 `f` 最小的节点，则

```text
f_min = min_{v∈Open} f(v)
```

单调不减。

**证明**：被展开的节点 `v` 满足 `f(v)=f_min`。v0.5 的一致性定理给出每个子节点 `w` 的 `f(w) ≥ f(v) = f_min`。移除 `v` 后，`Open` 中剩余节点仍有 `f ≥ f_min`，新子节点也满足 `f ≥ f_min`，故新的最小值不小于旧的。证毕。

这个引理 v0.5 没有显式写出，但它是本轮全部搜索调度的基础。定义

```text
G_search = U - f_min          # 前沿还差多少才够到 U
G_cert   = f_min - L_global   # 前沿最小值与全局根证书的差
G        = U - L = G_search + (L_global 与 f_min 的较大者关系)
```

更准确地说，`L = max(L_global, f_min)`，所以真正的闭合条件是 `f_min ≥ U`。两个单调驱动是：

- **DIVE（focal）**：直接降 `U`；
- **CLIMB（min-f 层）**：直接抬 `f_min`。

两者都让 `U - f_min` 单调下降。v0.5 的 anytime 表正好是这句话的实验版。

**一个反直觉的推论**：focal 展开的若是 `f > f_min` 的节点，它在**降低 U 的同时不抬 f_min**；best-first 展开 `f_min` 节点，它在**抬 f_min 的同时不降 U**。所以"哪个更好"没有全局答案，只有"当前 gap 的哪一端更松"。

## 3. dynamic analysis：GAP-LEDGER

### 3.1 绑定族与 margin

对状态 `σ=(S,A,c)` 和当前上界 `U`，令

```text
L_loc(σ;U) = max( L0(σ), L_AV(σ;U-1), L_TH(σ;U), L_D(σ) )
```

按固定次序 tie-break（本轮用 `L_TH ≻ L_AV ≻ L_D ≻ L0`），定义

```text
β(σ) = argmax_f L_f(σ)
μ(σ) = L_loc(σ) - max_{f≠β(σ)} L_f(σ)      （单族时 μ=+∞）
slack(σ) = L_loc(σ) - L0(σ) ≥ 0
```

`β` 是"当前是谁在托底"，`μ` 是"第二名的差距"，`slack` 是"除 L0 之外的证书已经贡献了多少"。

### 3.2 headroom：一个零装箱测试的上界

固定窗口 `(a,b)`，令

```text
qmax(a) = max { q_i : i∈R, est_i ≥ a }
ub(a,b) = min( U-1, b + qmax(a) )
```

**引理（ub 可采纳）**：若窗口 `(a,b)` 在截止期 `H` 上不可行，则 `H ≤ ub(a,b)`。

**证明**：若强制集 `X_H(a,b)` 为空，装箱问题为空集，必然可行，矛盾。故存在 `i∈R` 满足 `est_i ≥ a` 且 `H - q_i ≤ b`，即 `H ≤ b + q_i ≤ b + qmax(a)`；又 `H ≤ U-1`。证毕。

定义

```text
η(σ) = max( 0, max_{(a,b)∈W(σ,U)} (ub(a,b)+1) - L0(σ) )
```

其中 `W(σ,U)` 是固定窗口族（与 `H` 无关，见产物区 §3）。

**引理（η 上界）**：

```text
L_TH(σ;U) ≤ L0(σ) + η(σ).
```

**证明**：对任意窗口，`H*(a,b)+1 ≤ ub(a,b)+1 ≤ L0+η`；对窗口取 max、再与 `L0` 取 max，仍不超过 `L0+η`。证毕。

**推论（零测试跳过）**：令

```text
η_eff(σ) = max( 0, η(σ) - slack(σ) ).
```

则 `L_loc` 因 THRESH 而增加的量不超过 `η_eff(σ)`。特别地，

```text
η_eff(σ) = 0  ⇒  跑 THRESH 不可能改变 L_loc(σ)。
```

**证明**：

```text
L_loc' = max(L_loc, L_TH) ≤ max(L_loc, L0+η)
       = L_loc + max(0, L0+η-L_loc)
       = L_loc + max(0, η-slack).
```

证毕。

这是本轮最实用的一个观察：**在跑任何一次装箱测试之前，就能知道 THRESH 最多能带来多少收益**。`η=0` 时直接跳过；`η_eff` 很小时把预算留给别的节点。

### 3.3 前沿 ledger 与确定性路由

维护

```text
f_min,  G_search = U - f_min,  G_cert = f_min - L_global
W_f = Σ_{v:β(v)=f} (U - f(v))          # 每个族的可攻击 slack
N_f = |{v:β(v)=f}|
```

路由函数 `ROUTE(ledger)` 是确定性的：

```text
if 存在 v∈Open 且 η_eff(v) ≥ 1:
    优先对 (U-f(v)) 最大的 K_cert 个节点跑 DERAND-THRESH
elif steps - last_progress ≥ W_U:
    CLIMB
else:
    DIVE
```

### 3.4 成本

`η` 只需要枚举 `O(n²)` 个窗口并做 `O(1)` 算术，**不需要装箱**；`β/μ` 需要 `L_TH` 的数值，只在 actually 跑证书时更新。因此 ledger 的边际成本远低于一次 `AVAIL` 测试。

## 4. derandomization：三类确定性替换

### D1 DERAND-WINDOW（本轮已实现）

把"遍历所有窗口、每个窗口在 `[L0,U-1]` 上二分"改成：

1. 按 `ub` 降序排序；
2. 维护当前最优 `best`；
3. 若 `ub ≤ best`，后面的窗口都不可能更好，直接停；
4. 否则在 `[max(L0,best+1), min(U-1,ub)]` 上二分。

**定理**：返回与全扫描相同的 `L_TH`。证明见产物区 §4.1。

### D2 DERAND-DIVE（本轮已证明，未实现）

随机优先级表调度：每步在就绪集中均匀随机选一个任务。设 `D` 是该分布，`M(π)` 是优先级序 `π` 的 makespan。MCE 逐个固定任务：

```text
π*_0 = ∅
π*_{t+1} = π*_t + argmin_{i∈Ready} E_D[ M | π*_t + i ]
```

**定理**：`M(π*) ≤ E_D[M]`。证明见产物区 §4.2。这把 v0.4 的 MCTS rollout 换成了一个**有支配性保证**的确定性构造。

### D3 DERAND-FOCAL / TIE（本轮已实现）

- `B_focal` 截断取 `(f,id)` 最小的 `B_focal` 个候选；它们仍落在 `Φ_ω` 内，所以 focal 精确性定理不受影响；
- 所有 tie-break 用规范键 `(f, Ĝ, id)`，其中 `id` 是确定的生成序号；
- 不用 bandit、不用随机数。

---

## 5. 算法范式：PARADIGM-AUTOMATON

四态：

| 状态 | 工作 | 选点规则 |
|---|---|---|
| `DIVE` | 降 `U` | `Φ_ω` 内按 `Ĝ` 最小 |
| `CLIMB` | 抬 `f_min` | 精确 `f=f_min` 层内按 `Ĝ` 最小（ω=0 focal） |
| `CERT` | 抬 `L` | 对 `η_eff≥1` 的前 `K_cert` 个节点跑 DERAND-THRESH |
| `MERGE` | 去重/支配 | 扫描支配表，清理被支配节点 |

`CLIMB` 不是朴素 best-first：它在 `f_min` 层内仍用 guide 破平。这样既不浪费 guide 信息，又保证每步移除一个 `f_min` 节点。

**Progress 定理**：连续 `W_U` 次扩展无进展（`U` 不降且 `f_min` 不升）后进入 `CLIMB`；`CLIMB` 只展开 `f_min` 层，该层有限，故最终要么 `U` 下降、要么 `f_min` 严格上升。这是终止/进展保证，不是多项式界。

**Safety 定理**：自动机只改"先展开谁"，不改任何剪枝条件；因此任意切换都保持 v0.5 的精确性。

---

## 6. 本轮要验证的命题

1. **`f_min` 单调**：代码中每步检查 `f_min` 不下降（一致性实现正确性的 sanity check）。
2. **η 上界**：16 个中段状态上 `gain ≤ headroom` 应为 16/16；`η=0` 时 `gain=0`。
3. **DERAND-WINDOW 精确性**：40 个根状态 + 16 个中段状态上，`full` 与 `derand` 的 `L_TH` 必须完全一致；装箱测试数应显著下降。
4. **自动机**：在简单实例上应"休眠"（与纯 focal 相同）；在困难实例上应不输，最好有节点收益。
5. **正确性**：所有变体返回同一 `U`；THRESH 必须满足 `L_TH ≤ OPT(σ)`，用独立状态 DFS 验证。

---

## 7. 预判的负结果

- 在 n≤10 的简单实例上，`L0+AVAIL(U-1)+focal+DOM` 已经很强，自动机可能**完全休眠**；
- 在 precedence-heavy 实例上，`qmax(a)` 很大，`η` 可能接近 `U-L0`，ledger 无法跳过任何证书；
- MCE dive 的精确 DP 在 n>15 时状态爆炸，只能用 pessimistic estimator，届时"支配性保证"会变弱；
- `η` 的收益只对 THRESH 成立，对 `L_D`/`L_AV` 需要各自的 headroom。

---

## 8. 一句话最大风险

**当前方案最大的风险是：自动机的节点收益集中在 12–14 个任务的随机 DAG 上（9 个实例里 1 个贡献了 129→60 的大部分），而 `η` 在 precedence-heavy 实例上可能因 `qmax` 很大而变得空洞；MCE dive 的 DP 成本也尚未验证。**

# 产物区 · v0.6：X-DUB/DA

> **D**ynamic-**A**ttribution search with **d**erandomized certificates  
> 中文名：动态归因 + 去随机化证书搜索  
> 状态：完整设计稿；`DERAND-WINDOW`（D1）与 `DERAND-FOCAL/TIE`（D3）已实现并验证；`MCE-DIVE`（D2）已证明但未实现；证明 DAG 只给出规则，未实现 checker。

---

## 0. 版本关系与本轮增量

v0.5「X-DUB/AG\*」已经建立：

- `P|prec|Cmax` 的 `(任务,机器)` 动作空间与最优性覆盖；
- 一致 A\* 层：`F(child)=max(F(parent),L_loc(child))`，`f=max(C,F)`，`h=f-C` 一致，不需要 reopening；
- 贪心焦点 `FOCAL-GREEDY`，guide 只排序、不剪枝；
- 证书泛化：`THRESH-CERT`（截止期区间）、`CERT-INHERIT`（路径）、`CERT-REGION`（状态区域）、`DOM-GEN`（同 `S` 支配）；
- 证明 DAG 的 `INHERIT / THRESH-CORE / DOMINATED-BY` 规则。

v0.6 **不推翻** 上述任何结论，只做三处增量：

1. **GAP-LEDGER（dynamic analysis）**：把 `U-L` 拆成 `G_search` 与 `G_cert`；用**零装箱测试**的 `η` 上界判断 THRESH 是否值得跑；用 `f_min` 单调性解释 DIVE 与 CLIMB 的分工。
2. **DERAND（derandomization）**：`DERAND-WINDOW` 把窗口全扫描换成带可采纳上界的二级 B&B（精确、测试更少）；`DERAND-DIVE` 用 MCE 把 MCTS rollout 换成有支配性保证的确定性构造；`DERAND-FOCAL/TIE` 把 `B_focal` 截断与所有 tie-break 规范化。
3. **PARADIGM-AUTOMATON（算法范式）**：`DIVE / CLIMB / CERT / MERGE` 四态，切换只依赖 ledger；证明切换不改剪枝、且无进展时必然转入 CLIMB。

关系：

```text
关闭 LEDGER/AUTOMATON/DERAND  → v0.5 的 X-DUB/AG*
只开 DERAND-WINDOW            → 同样的 L_TH，更少的装箱测试
只开 AUTOMATON                → 同样的剪枝，不同的展开顺序
全部打开                      → v0.6 完整算法
```

组合下界仍然是 v0.5 的

```text
L_loc(σ) = max( L0, L_D, L_AV, L_TH )
F(σ)     = max over path certificates
f(σ)     = max( C(σ), F(σ) )
```

v0.6 不改变下界的可采纳性，只改变**何时算哪个下界**、**先展开谁**、**用哪条确定性构造**。

## 1. 问题、符号与复用的旧结论

### 1.1 形式化问题

```text
P | prec | Cmax
```

给定任务集 `V={1,...,n}`、工时 `p_i∈Z_{≥1}`、优先约束 `E⊆V×V`（DAG）、
同构机器数 `m`。调度由开始时间 `s_i` 和机器 `μ_i` 组成，满足：

```text
(i,j) ∈ E  ⇒  s_j ≥ s_i + p_i
μ_i = μ_j  ⇒  [s_i, s_i+p_i) 与 [s_j, s_j+p_j) 不重叠
```

目标 `Cmax=max_i(s_i+p_i)` 最小，最优值记 `OPT`。

### 1.2 符号表（v0.6 新增/重定义）

| 符号 | 含义 |
|---|---|
| `σ=(S,A,c)` | 状态：已调度集、机器可用时间（升序）、完成时间 |
| `R=V\S` | 未调度集 |
| `C(σ)=max_k A_k` | 已提交的 makespan |
| `est_i(σ)` | 任务 `i` 的最早可能开始（含已调度前驱的 `c_j`） |
| `q_i(σ)` | `i` 之后剩余最长路（不含 `p_i`） |
| `L0` | `max(C, max_i(est_i+p_i+q_i), ceil(Σ_R p_i/m))` |
| `L_AV` | v0.5 的 AVAIL 核下界 |
| `L_TH` | 阈值证书下界 |
| `L_D` | v0.4 的时间价格对偶下界（本轮可选） |
| `L_loc` | `max(L0,L_D,L_AV,L_TH)` |
| `β(σ)` | 绑定证书族：`argmax_f L_f`，固定次序 tie-break |
| `μ(σ)` | `L_loc - max_{f≠β} L_f`，第二名差距 |
| `slack(σ)` | `L_loc - L0 ≥ 0` |
| `W(σ,U)` | 固定窗口族（与 `H` 无关），见 §3.2 |
| `ub(a,b)` | 窗口 `(a,b)` 的可采纳截止期上界 |
| `η(σ)` | `max_w(ub_w+1)-L0(σ)`，THRESH 的 headroom |
| `η_eff(σ)` | `max(0, η-slack)`，THRESH 能改变 `L_loc` 的最大幅度 |
| `F(σ)` | 路径最大下界 |
| `f(σ)` | `max(C(σ),F(σ))` |
| `f_min` | `min_{v∈Open} f(v)` |
| `U` | incumbent 上界 |
| `Ĝ(σ)` | 贪心 guide（可行上界，不用于剪枝） |
| `Φ_ω` | `{v∈Open : f(v) ≤ f_min+ω}` |
| `B_focal` | focal 候选截断数 |
| `W_U` | CLIMB 触发的无进展步数阈值 |
| `T_scan` | CERT 扫描周期 |
| `K_cert` | 每次 CERT 最多处理的节点数 |
| `K_dom` | 每个 `S` 的支配表上限 |

### 1.3 复用的 v0.5 结论

以下结论直接继承，不再证明：

- **动作覆盖性**：动作 `(i,k)` 在 `t=max(A_k, max_{j∈pred(i)} c_j)` 开始；从根出发的某条动作序列可达到一个最优调度。
- **CP 初始上界**：按 `q_i` 降序的 CP 表调度给出可行 `U_0`，且 `U_0≤(2-1/m)OPT`。
- **A\* 一致性**：`F` 可采纳，`f` 沿边单调，`h=f-C` 一致。
- **前沿下界**：若 `F_open` 覆盖所有可能优于 `U` 的剩余调度，则 `min_{v∈F_open} f(v)≤OPT`。
- **AVAIL 可采纳**：若 `BP(X_W,caps(W,σ))` 不可行，则不存在 makespan `≤H` 的完成。
- **支配保序**：同 `S` 下 `sort(A_σ)≤sort(A_τ)` 且 `c_σ≤c_τ` ⇒ `OPT(σ)≤OPT(τ)`。
- **证明树规则**：`TERMINAL/PRUNED/EXACT/EXHAUSTED/PACK-CORE-AVAIL` 的局部检查可靠。

v0.6 只替换/扩展搜索顺序、上界生成和证书调度；主循环的动作空间与 AVAIL 核不变。

## 2. 动机：三个缺口

### 2.1 缺口一：证书族是"盲投"的

v0.5 在根上跑 THRESH，在内部节点跑 `AVAIL(U-1)`。但 THRESH 的收益高度依赖状态：在优先约束主导的根状态上，装箱证书再强也碰不到间隙。第 7 轮的 20 个根实例上，THRESH 一次都没有闭合剩余间隙。

v0.6 把"要不要跑 THRESH"变成一个**零装箱测试**的判据：`η_eff=0` 时直接跳过。这不是启发式，而是由 `ub` 上界推出的可检查结论。

### 2.2 缺口二：focal 与 best-first 没有理论

v0.5 证明了 `f(child)≥f(parent)`，但只用它来说"不需要 reopening"。它没有解释：为什么 focal 的 anytime 好、最终节点数却不一定少；为什么 best-first 最终节点数不错、anytime 却差。

v0.6 的答案：**focal 降 `U`，best-first 抬 `f_min`，它们驱动 gap 的两端**。`DIVE` 与 `CLIMB` 不是竞争，而是分工。

### 2.3 缺口三：核心循环里仍有采样

窗口扫描顺序、`B_focal` 截断、MCTS rollout、bandit 选择——它们不影响正确性，但让实验不可复现，也没有最坏保证。

v0.6 用三类确定性构造替换：`DERAND-WINDOW`（精确窗口 B&B）、`DERAND-DIVE`（MCE）、`DERAND-FOCAL/TIE`（规范截断与 tie-break）。

### 2.4 三个灵感词的分工

- **dynamic analysis**：GAP-LEDGER，观测 `G_search/G_cert/β/μ/η`，把证书预算路由到"可能改变 `L_loc`"的节点。
- **derandomization**：DERAND，把采样换成带精确性/支配性证明的构造。
- **算法范式**：PARADIGM-AUTOMATON，把 DIVE/CLIMB/CERT/MERGE 写成显式状态机，并证明切换安全。

## 3. 动态分析层：GAP-LEDGER

### 3.1 绑定族与 margin

对状态 `σ` 和当前上界 `U`，令

```text
L_loc(σ;U) = max( L0(σ), L_AV(σ;U-1), L_TH(σ;U), L_D(σ) )
```

按固定次序 `L_TH ≻ L_AV ≻ L_D ≻ L0` 做 tie-break，定义

```text
β(σ) = 第一个达到 L_loc 的族
μ(σ) = L_loc(σ) - max_{f≠β(σ)} L_f(σ)      （单族时 μ=+∞）
slack(σ) = L_loc(σ) - L0(σ) ≥ 0
```

**解释**：`β` 是"当前谁在托底"；`μ` 是"第二名差多少"；`slack` 是"除 `L0` 之外的族已经贡献了多少"。如果 `β=L0` 且 `μ` 很大，说明前沿的瓶颈是优先约束，装箱证书不可能改变 `L_loc`。

### 3.2 固定窗口族与 headroom

对状态 `σ`、上界 `U`，定义与 `H` **无关**的窗口族

```text
A(σ)   = {0} ∪ { est_i : i∈R }
B(σ,U) = { C(σ) } ∪ { est_i+p_i : i∈R } ∪ { (U-1)-q_i : i∈R }
W(σ,U) = { (a,b) : a∈A, b∈B, 0 ≤ a < b ≤ U-1 }
```

每个窗口的容量与强制集沿用 v0.5：

```text
caps_k(a,b) = max(0, b - max(a, A_k))
X_H(a,b)    = { i∈R : est_i ≥ a, H - q_i ≤ b }
```

（若 `BP(X_H,caps)` 不可行，则不存在 makespan `≤H` 的完成。）

定义

```text
qmax(a) = max { q_i : i∈R, est_i ≥ a }          （若集合空，窗口无用）
ub(a,b) = min( U-1, b + qmax(a) )
η(σ)    = max( 0, max_{(a,b)∈W} (ub(a,b)+1) - L0(σ) )
```

**引理 3.1（ub 可采纳）**：若窗口 `(a,b)` 在截止期 `H` 上不可行，则 `H ≤ ub(a,b)`。

**证明**：若强制集 `X_H(a,b)` 为空，则装箱问题为空集，必然可行，与不可行矛盾。故存在 `i∈R` 满足 `est_i≥a` 且 `H-q_i≤b`，即 `H≤b+q_i≤b+qmax(a)`；又由搜索范围 `H≤U-1`。证毕。

**引理 3.2（η 上界）**：`L_TH(σ;U) ≤ L0(σ) + η(σ)`。

**证明**：对任意窗口，`H*(a,b)+1 ≤ ub(a,b)+1 ≤ L0+η`。对窗口取 max、再与 `L0` 取 max，仍不超过 `L0+η`。证毕。

**推论 3.3（零测试跳过）**：令 `η_eff(σ)=max(0, η(σ)-slack(σ))`。则

```text
L_loc(σ) 因 THRESH 而增加的量 ≤ η_eff(σ).
特别地，η_eff(σ)=0 ⇒ 跑 THRESH 不可能改变 L_loc(σ).
```

**证明**：

```text
L_loc' = max(L_loc, L_TH) ≤ max(L_loc, L0+η)
       = L_loc + max(0, L0+η-L_loc)
       = L_loc + max(0, η-slack) = L_loc + η_eff.
```

证毕。

**成本**：`η` 只需枚举 `O(n²)` 个窗口并做 `O(1)` 算术，**不需要一次装箱测试**；而一次 `AVAIL(U-1)` 需要 `O(|W|)` 次装箱。因此 `η` 是一个极便宜的"预判"。

### 3.3 前沿 ledger

维护

```text
f_min = min_{v∈Open} f(v)
G_search = U - f_min
G_cert   = f_min - L_global
W_f = Σ_{v:β(v)=f} (U - f(v))          # 族 f 的可攻击 slack
N_f = |{v:β(v)=f}|
```

`G_search` 是"前沿还差多少才够到 `U`"；`G_cert` 是"根证书还差多少才追上 `f_min`"。两者都为 0 时搜索闭合。

### 3.4 确定性路由

```text
ROUTE(ledger):
1  if 存在 v∈Open 且 η_eff(v) ≥ 1:
2      返回 CERT，候选为 (U-f(v)) 最大的 K_cert 个节点
3  if steps - last_progress ≥ W_U:
4      返回 CLIMB
5  return DIVE
```

`last_progress` 在 `U` 下降或 `f_min` 严格上升时更新。`CERT` 只运行**一个批次**，然后回到 DIVE/CLIMB。

**为什么路由是安全的**：`CERT` 只更新节点的 `F/f`（用可采纳的 `L_TH`），`CLIMB/DIVE` 只改选择顺序。三者都不改变剪枝条件。安全性由 §5.3 的定理保证。

## 4. 去随机化层：DERAND

### 4.1 DERAND-WINDOW

**输入**：状态 `σ`、上界 `U`、`L0`、窗口族 `W(σ,U)`。

**算法**：

```text
1  best ← None
2  按 ub(a,b) 降序排序 W；tie-break (a,b) 字典序
3  for (a,b) in W:
4      if best≠None and ub(a,b) ≤ best:
5          break                        # 后面的窗口都不可能更好
6      lo ← L0 if best=None else max(L0, best+1)
7      hi ← min(U-1, ub(a,b))
8      if lo > hi: continue
9      h ← BSEARCH(a,b,lo,hi)          # 单窗口二分
10     if h≠None: best ← max(best,h)
11 return L0 if best=None else best+1
```

`BSEARCH(a,b,lo,hi)` 只用**单个窗口**的 `window_infeasible_at(H,a,b)`，不是整个窗口族的 OR。

**定理 4.1（精确性）**：`DERAND-WINDOW` 返回与全扫描相同的 `L_TH`。

**证明**：设全扫描的最优窗口为 `(a*,b*)`，其最大不可行截止期为 `H*`，且 `H*+1 > L0`（否则 `L_TH=L0`，结论平凡）。

- 若 `(a*,b*)` 被访问：排序后它的 `ub ≥ H*`。若此时 `best < H*`，则 `lo ≤ H* ≤ hi`，二分返回 `H*`，更新 `best`；若 `best ≥ H*`，它本来就不会改进答案。
- 若 `(a*,b*)` 在 `break` 之后：则存在一个更早的窗口 `(a',b')` 使 `ub(a',b') ≤ best`。由于排序，`ub(a*,b*) ≤ ub(a',b') ≤ best`，故 `H* ≤ ub(a*,b*) ≤ best`，即 `(a*,b*)` 不可能改进答案。

因此返回的 `best` 等于全扫描的最大不可行值，`L_TH` 相同。证毕。

**复杂度**：排序 `O(|W| log|W|)`；每个被访问窗口至多 `O(log(U-L0))` 次装箱测试。最坏

```text
O( |W| log|W| + |W| log(U-L0) · T_BP )
```

与全扫描同阶，但实际访问的窗口数通常远小于 `|W|`（§10.2：中段状态 48.75→21.56 次测试）。

**为什么这是"去随机化"**：v0.5 的窗口扫描没有明确顺序；若用采样/随机重启，结果不可复现。`DERAND-WINDOW` 用一个**可采纳上界**给出确定性的访问顺序与停止条件，且返回完全相同的 `L_TH`。

### 4.2 DERAND-DIVE（MCE）

**动机**：v0.4/v0.5 的 anytime 质量依赖 MCTS rollout / bandit。rollout 是随机的，bandit 在廉价特征下没有超过最佳固定顺序。v0.6 用**条件期望法（MCE）**把"随机优先级表调度"去随机化。

**分布 `D`**：从状态 `σ` 出发，每步在就绪集 `Ready` 中**均匀随机**选一个任务；机器按最早完成时间确定性地选。设 `M(π)` 是优先级序 `π` 的 makespan，`E_D[M]` 是其期望。

**构造**：

```text
π*_0 = ∅
for t = 0..n-1:
    π*_{t+1} = π*_t + argmin_{i∈Ready(π*_t)} E_D[ M | π*_t + i ]
```

**定理 4.2（MCE 支配）**：`M(π*) ≤ E_D[M]`。

**证明**：对 `t` 归纳，维护不变式

```text
E_D[ M | π*_t ] ≤ E_D[ M ].
```

`t=0` 时取等。设 `Ready = {i_1,...,i_k}`。由全期望公式，

```text
E_D[M | π*_t] = (1/k) Σ_j E_D[M | π*_t + i_j]
             ≥ min_j E_D[M | π*_t + i_j]
             = E_D[M | π*_{t+1}].
```

最后一步是 MCE 的选择。归纳得 `E_D[M | π*_n] ≤ E_D[M]`。而 `π*_n` 是完整序，条件期望退化为确定值 `M(π*)`。证毕。

**条件期望的计算**：DP

```text
E(S, A, c) = 0                                  if S=V
           = (1/|Ready|) Σ_{i∈Ready} E(S∪{i}, A', c')   otherwise
```

其中 `A',c'` 是按最早完成时间把 `i` 放到某台机器后的状态。状态数最坏 `O(2^n · L^m)`，`L≤U`；对 `n≤15, m=2` 可用记忆化 + 上界剪枝。超过 `n=15` 时改用确定性 pessimistic estimator（例如用 `L0` 的凸组合给 `E` 一个可计算上界），届时保证变弱为"≤ estimator"，不再是精确期望。

**本轮状态**：定理已证，DP 未实现（`n=12–14` 的状态空间已不适合纯 Python）。列为下一轮 P1。

### 4.3 DERAND-FOCAL

**截断**：从 `Φ_ω` 中取 `(f,id)` 最小的 `B_focal` 个候选，再按 `Ĝ` 选一个。

**引理 4.3（截断安全）**：被选中的节点 `v` 满足 `v∈Φ_ω`，即 `f(v)≤f_min+ω`。因此 v0.5 的 Focal 精确性定理仍然适用。

**证明**：截断只删除 `Φ_ω` 中 `(f,id)` 较大的元素，保留的每个元素都在 `Φ_ω` 内。剪枝条件仍是 `f≥U`，与 `Ĝ` 无关。证毕。

**确定性 tie-break**：所有选择用 `(f, Ĝ, id)` 或 `(f, id)` 的字典序，`id` 是节点生成序号。没有随机数、没有 bandit、没有 MCTS。

### 4.4 与 v0.5 的关系

| 组件 | v0.5 | v0.6 |
|---|---|---|
| 窗口扫描 | 全扫描 / 随机顺序 | `DERAND-WINDOW`（ub 排序 + 精确剪枝） |
| MCTS rollout | 随机 | `MCE-DIVE`（确定性、≤期望） |
| focal 截断 | 任意前 `B_focal` 个 | `(f,id)` 最小的 `B_focal` 个 |
| tie-break | 实现相关 | 规范键 |
| bandit | 可选 | 移除 |

## 5. 算法范式层：PARADIGM-AUTOMATON

### 5.1 四个范式

| 状态 | 目标 | 选点规则 | 退出条件 |
|---|---|---|---|
| `DIVE` | 降 `U` | `Φ_ω` 内 `Ĝ` 最小 | 无进展 `W_U` 步 |
| `CLIMB` | 抬 `f_min` | `{v:f(v)=f_min}` 内 `Ĝ` 最小 | `f_min` 上升或 `U` 下降 |
| `CERT` | 抬 `L` | `η_eff≥1` 的前 `K_cert` 个节点 | 批次结束 |
| `MERGE` | 去重/支配 | 扫描支配表 | 表稳定 |

`CLIMB` 不是朴素 best-first：它在**精确 `f_min` 层**内仍用 guide 破平（即 `ω=0` focal）。这样既保证每步移除一个 `f_min` 节点，又不浪费 guide 信息。这是 v0.6 与 v0.5 "focal 或 best-first" 的关键区别。

### 5.2 确定性守卫

```text
DIVE  → CLIMB : steps - last_progress ≥ W_U
CLIMB → DIVE  : f_min 严格上升，或 U - f_min ≤ δ
任意  → CERT  : steps mod T_scan = 0 且存在 η_eff ≥ 1 的节点
任意  → MERGE : |DomTable| > K_dom 或 steps mod T_merge = 0
CERT  → 前一状态（CERT 只运行一个批次）
```

`last_progress` 在 `U` 下降或 `f_min` 严格上升时更新。

### 5.3 Progress 定理

**定理 5.1（无进展必转 CLIMB，CLIMB 必有进展）**：设 `last_progress` 按上述规则更新。若连续 `W_U` 次扩展既没有降低 `U` 也没有抬高 `f_min`，自动机进入 `CLIMB`。`CLIMB` 只展开 `f_min` 层；该层在有限搜索树中有限，故经过有限步（至多该层物化节点数）后，要么 `f_min` 严格上升，要么某个完整节点被达到且 `U≤f_min`（此时 `U-f_min≤0`，搜索闭合）。

**证明**：`CLIMB` 每次展开一个 `f=f_min` 的节点并将其从 `Open` 移除。由一致性，其子节点 `f≥f_min`。若某个子节点 `f>f_min`，则该层减少一个且不补充；若所有子节点 `f=f_min`，则它们在 `f_min` 层的有限子树中。搜索树有限，故该层不可能无限补充。当该层耗尽时，`f_min` 严格上升。若在耗尽前达到完整节点 `w`，则 `f(w)=C(w)`（v0.5 推论 2），且 `f(w)≥f_min`；若 `f(w)=f_min`，则 `U≤C(w)=f_min`，闭合。证毕。

**注意**：这是**进展/终止**保证，不是多项式时间界。`f_min` 层可能指数大；最坏复杂度仍是 NP-hard 问题的指数级。

### 5.4 Safety 定理

**定理 5.2（自动机安全）**：自动机的任意状态切换只改变"先展开哪个节点"，不改变任何剪枝条件（`f≥U`、支配、证书）。因此 v0.5 的精确性定理对 v0.6 仍成立：若预算无限，算法终止时 `U=OPT`。

**证明**：检查三类剪枝：

- `f≥U`：只依赖可采纳的 `f`，与选择顺序无关；
- 支配：只依赖 §1.3 的支配保序，与选择顺序无关；
- 证书：只依赖 `L_TH/L_AV/L_D` 的可采纳性，与选择顺序无关。

`CERT` 更新 `F/f` 时用的是可采纳下界，取 max 仍可采纳。`CLIMB` 与 `DIVE` 的选择规则不参与剪枝。因此任何交错都保持 v0.5 的前沿覆盖不变式。证毕。

## 6. 主循环 X-DUB/DA

```text
算法 X-DUB/DA(G,p,m,B)
────────────────────────────────────────────────
1  (est,q,L0) ← PRECOMPUTE(G,p,m)
2  π0,U0 ← CP-LIST-SCHEDULE(G,p,m)
3  best ← (U0,π0);  U ← U0
4  root ← NEW-NODE(σ0=(∅,0^m,⊥))
5  L0(root) ← L0;  η(root) ← HEADROOM(root,U)
6  L_TH(root) ← DERAND-WINDOW(root,U) if η(root)>0 else L0
7  L_global ← max(L0,L_TH);  root.F ← L_global
8  root.f ← max(C(root),root.F)
9  Open ← {root};  DomTable ← {(∅): [(sort(A),c,root.id)]}
10 state ← DIVE;  steps ← 0;  last_progress ← 0
11 prev_fmin ← root.f
12 while Open ≠ ∅ and steps < B:
13     purge Open 中 f≥U 的节点
14     if Open=∅: break
15     f_min ← min_{v∈Open} f(v)
16     if f_min ≥ U: break
17     if f_min > prev_fmin: prev_fmin ← f_min; last_progress ← steps
18     ledger ← (f_min, U-f_min, f_min-L_global,
                   top-K nodes by (U-f), η_eff of each)
19     if steps-last_progress ≥ W_U: state ← CLIMB
20     elif steps mod T_scan = 0 and ∃v: η_eff(v)≥1: state ← CERT
21     else: state ← DIVE
22     if state=CERT:
23         for v in top-K_cert by (U-f):
24             if η_eff(v) < 1: continue
25             Lv ← DERAND-WINDOW(v,U)
26             v.F ← max(v.F,Lv); v.f ← max(C(v),v.F)
27         Open ← {v∈Open : v.f<U}
28         state ← DIVE;  continue
29     if state=DIVE:
30         Φ ← {v∈Open : f(v) ≤ f_min+ω}
31         候选 ← (f,id) 最小的 B_focal 个 Φ 元素
32         v ← argmin_{候选} Ĝ(v)
33     else:  # CLIMB
34         候选 ← {v∈Open : f(v)=f_min}
35         v ← argmin_{候选} Ĝ(v)
36     Open.remove(v);  steps ← steps+1
37     U ← min(U, GUIDE(v))
38     for w in CHILDREN(v):
39         if w complete: U ← min(U,C(w)); continue
40         L0w ← L0(w)
41         if L0w ≥ U: continue
42         if AVAIL(w,U-1) 不可行: continue
43         ηw ← HEADROOM(w,U)          # 零装箱测试
44         if ηw>0 and state=DIVE:
45             Lw ← max(L0w, DERAND-WINDOW(w,U))   # 只为高 slack 节点
46         else:
47             Lw ← L0w
48         Fw ← max(v.F,Lw)
49         fw ← max(C(w),Fw)
50         if fw ≥ U: continue
51         if DOMINATED(w): 
52             U ← min(U,GUIDE(w));  record DOMINATED-BY(witness);  continue
53         Open ← Open ∪ {w};  update DomTable
54     if steps mod T_scan = 0:
55         L_root ← DERAND-WINDOW(root,U)
56         L_global ← max(L_global,L_root)
57         for v∈Open: v.F ← max(v.F,L_global); v.f ← max(C(v),v.F)
58 L ← max(L_global, min_{v∈Open} f(v))
59 if Open=∅ or L ≥ U: PROOF ← BUILD-PROOF-DAG(root,U)
60 return best,L,U,gap=(U-L)/max(1,L),PROOF
```

**实现说明**：

- 第 44–45 行：只对 `η>0` 且 `state=DIVE` 的子节点跑 `DERAND-WINDOW`，避免每个子节点都做装箱。`CERT` 状态负责批量处理高 slack 节点。
- 第 42 行：`AVAIL(w,U-1)` 只做单点剪枝，返回 `U` 时直接跳过；它不产生数值下界。
- 第 55 行：根证书每 `T_scan` 步重算一次；`L_global` 对所有节点有效（引理 1）。
- 第 52 行：支配剪枝前可选地算一次 `GUIDE(w)`，保留被支配状态可能带来的 incumbent。

**与 v0.5 的差异**：

- v0.5 在每个节点独立算 `L_loc`；v0.6 用 `η_eff` **决定是否值得算**。
- v0.5 的 focal 与 best-first 是二选一；v0.6 用自动机切换，并用 `ω=0` focal 实现 CLIMB。
- v0.5 的窗口扫描没有确定顺序；v0.6 用 `ub` 排序 + 精确停止。
- v0.5 的 guide 可以接 MCTS/bandit；v0.6 只用确定性贪心组合（MCE 作为下一轮的可选成员）。

## 7. 证明 DAG 扩展

在 v0.5 的 `TERMINAL / PRUNED-DUAL / PACK-CORE-AVAIL / THRESH-CORE / INHERIT / DOMINATED-BY / EXACT / EXHAUSTED` 之上，新增四类节点：

```text
HEADROOM(σ, U, η, W)
ROUTE-SKIP(σ, η, slack)
DERAND-WINDOW(σ, U, order, evals)
MCE-DIVE(σ, π*, dp-witness)
```

### 7.1 checker 规则

```text
CHECK-NODE(v):
1  if v in memo: return memo[v]
2  case v.type:
3    HEADROOM(σ,U,η,W):
4        从 σ 与原 DAG 重算 R, est, q, C, L0
5        重算 W(σ,U) 与每个 ub(a,b)
6        验证 η = max(0, max ub+1-L0)
7    ROUTE-SKIP(σ,η,slack):
8        重算 η 与 slack = L_loc-L0
9        验证 η ≤ slack
10       # 由推论 3.3，THRESH 不可能改变 L_loc；这是一张"负证书"
11   DERAND-WINDOW(σ,U,order,evals):
12       重算 W 与 ub
13       验证 order 按 ub 降序（tie-break 字典序）
14       best ← None
15       for (a,b) in order:
16           if best≠None and ub≤best: break
17           验证 (a,b) 在 evals 中，且 evals 给出
18               H* = max{H∈[lo,hi] : window_infeasible(H,a,b)}
19           验证 H* 处的装箱证书（TRIVIAL/AGG/DFF/SUBSET/PACK-BB）
20           best ← max(best,H*)
21       验证返回的 L_TH = best+1（或 L0）
22   MCE-DIVE(σ,π*,dp-witness):
23       重算分布的 DP 表 E(S,A,c)
24       验证 π* 的每一步 argmin 条件
25       验证最终的 M(π*) ≤ E_D[M]
26   INHERIT / DOMINATED-BY / THRESH-CORE / ...
27       沿用 v0.5 规则
28   else: reject
29   memo[v] ← true; return true
```

### 7.2 为什么 `ROUTE-SKIP` 是"负证书"

传统证书证明"某个界成立"；`ROUTE-SKIP` 证明"**某个证书族在当前状态上不可能改变 `L_loc`**"。它的检查只需要 `η` 与 `slack` 的算术，不需要装箱；但它能让 checker 确认：搜索器跳过 THRESH 不是偷懒，而是有可检查的理由。

这是 v0.6 把 dynamic analysis 接入证明系统的方式：**观测结果本身成为证明对象**。

### 7.3 可靠性

**定理 7.1（证明 DAG 可靠）**：若 `CHECK(root)` 通过，则 `U=OPT`。

**证明**：对 DAG 做拓扑归纳。

- `HEADROOM`：只验证 `η` 的算术，不单独闭合节点；它服务于 `ROUTE-SKIP`/`DERAND-WINDOW`。
- `ROUTE-SKIP`：由推论 3.3，`L_loc` 不因 THRESH 改变；跳过的证书不损失任何下界。
- `DERAND-WINDOW`：由定理 4.1，返回的 `L_TH` 与全扫描相同；每个 `H*` 处的装箱证书由 v0.5 规则验证。
- `MCE-DIVE`：由定理 4.2，产出的调度可行且 `≤E_D[M]`；它只贡献 incumbent，不参与剪枝。
- `INHERIT/DOMINATED-BY/THRESH-CORE`：v0.5 已证。
- `EXACT/EXHAUSTED`：所有动作/子节点覆盖，归纳假设给出每个子节点没有更好的完成。

结合 `U` 来自可行调度，`U=OPT`。证毕。

### 7.4 独立性

- `est/q/A/η` 由 checker 从 `σ` 与原 DAG 重算，不信任搜索器缓存；
- `W(σ,U)` 的枚举与 `ub` 由 checker 重算；
- `DERAND-WINDOW` 的排序、跳过、二分区间都由 checker 重算；
- `MCE-DIVE` 的 DP 由 checker 重算（小 `n`）；
- 自动机的状态/守卫**不进入**证明 DAG 的可靠性论证：它只影响顺序，不影响剪枝。

## 8. 正确性论证汇总

### 引理 8.1（`f_min` 单调）

若每步展开 `f` 最小的节点，则 `f_min` 单调不减。

**证明**：被展开的 `v` 满足 `f(v)=f_min`；一致性给出每个子 `w` 的 `f(w)≥f_min`；移除 `v` 后剩余节点 `f≥f_min`。证毕。

### 引理 8.2（ub 可采纳）

已证于 §3.2。

### 引理 8.3（η 上界与 η_eff）

已证于 §3.2。

### 定理 8.4（DERAND-WINDOW 精确）

已证于 §4.1。

### 定理 8.5（MCE 支配）

已证于 §4.2。

### 引理 8.6（focal 截断安全）

已证于 §4.3。

### 定理 8.7（自动机进展）

已证于 §5.3。

### 定理 8.8（自动机安全）

已证于 §5.4。

### 定理 8.9（任意时刻区间）

在 `X-DUB/DA` 运行的任意时刻，

```text
L ≤ OPT ≤ U.
```

**证明**：`U` 来自 CP、贪心或 MCE 的可行调度，故 `OPT≤U`。`L` 是 `L0`、`L_global`、前沿 `min f` 的最大值；`L0` 与根证书由引理 3.2/定理 4.1 可采纳，前沿 `f` 由路径继承和局部可采纳性给出 `f(v)≤OPT(v)`；前沿覆盖性给出 `min_v f(v)≤OPT`。因此 `L≤OPT`。证毕。

### 定理 8.10（终止即最优）

若算法因 `Open=∅` 或 `L≥U` 终止，则 `U=OPT`。

**证明**：若存在 `Cmax<U` 的完成，由动作覆盖性和前沿覆盖性，它必须经过某个开节点 `v`，且 `f(v)≤Cmax<U`。这与 `Open=∅` 或 `min_{v∈Open}f(v)≥U` 矛盾。结合 `U` 可行，`U=OPT`。证毕。

### 定理 8.11（有限完备性）

搜索树有限；每次展开前进一个任务；`CERT`/`CLIMB` 只改顺序；支配/证书剪枝只删除没有更优完成的状态。预算无限时前沿最终为空或 `f_min≥U`。最坏时间复杂度仍指数；这是 NP-hard 问题的预期行为。

### 与 v0.5 的支配关系

```text
L_loc^{v0.6} = L_loc^{v0.5}                 （同一个 max，只是算得更少）
f^{v0.6}     = f^{v0.5}                     （同一路径最大）
U^{v0.6}    ≤ U^{v0.5}                     （MCE/贪心组合只增不减）
```

v0.6 不声称逐点更强的下界；它声称**同样的下界、更少的证书测试、更好的顺序**。这一点与 v0.5 的"逐点支配 v0.4"不同，必须诚实区分。

## 9. 复杂度分析

### 9.1 单次操作

- **预处理**：拓扑排序 + head/tail + 后代位掩码，`O(n+|E|)`。
- **`L0`**：`O(n+|E|)`。
- **`HEADROOM(η)`**：枚举 `O(n²)` 个窗口，每个 `O(1)` 算术，**零装箱测试**。
- **`AVAIL(U-1)`**：`O(|W| · T_BP)`，`|W|=O(n²)`。
- **`DERAND-WINDOW`**：排序 `O(|W| log|W|)`；每个访问窗口 `O(log(U-L0))` 次 `T_BP`。
- **`MCE-DIVE`**：DP 状态 `O(2^n · L^m)`，每状态 `O(n)` 转移；`L≤U`。
- **focal 选择**：扫描 `Open` 为 `O(|Open|)`；guide 最多 `B_focal` 次，`O(B_focal·T_G)`。
- **支配检查**：每个 `S` 的 Pareto 表 `|D_S|`，单次 `O(|D_S|(n+m))`，受 `K_dom` 限制。
- **证明 DAG 检查**：`O(N_proof+|E_proof|)`。

### 9.2 总复杂度

设 `N` 为物化节点数、`B` 为预算：

```text
时间: O( N·(T_L0 + T_AVAIL + T_G)
        + B·T_G·B_focal
        + N·K_dom·(n+m)
        + N_cert·T_DERAND
        + T_MCE )
空间: O( N(n+m) + Σ_S |D_S|(n+m) + N_proof + 2^n·L^m )
```

最坏情况：

```text
N = O((m·n)^n)
T_AVAIL = O(n²·T_BP)
T_DERAND = O(n² log n + n² log(U-L0)·T_BP)
```

- v0.6 没有改变最坏复杂度；它是"更便宜的证书调度 + 更好的顺序 + 更少的重复证明"。
- `η` 的 `O(n²)` 是无装箱的，因此即使 `T_BP` 很贵，ledger 仍然便宜。
- `MCE` 的 `2^n` 是指数瓶颈，只适合 `n≤15`；大规模需要 pessimistic estimator。

### 9.3 成本控制

- `η` 在每个子节点都算（零装箱），但 `DERAND-WINDOW` 只对 `η>0` 且高 slack 的节点跑；
- `CERT` 每 `T_scan` 步最多处理 `K_cert` 个节点；
- `CLIMB` 只在无进展 `W_U` 步后触发；
- 支配表按 `S` 分桶，超过 `K_dom` 停止插入；
- 证明 DAG 只在终止时构造，checker 与搜索器隔离。

## 10. 实验设计与本轮结果

### 10.1 设置

- 随机 DAG：任务按索引拓扑排序；`i<j` 以概率 `ep` 加边；`p_i` 均匀取 `1..pmax`；`m=2`。
- 三个实例族：
  - **根集**：40 个 `n∈{9,10}`，`ep∈{0.15,0.2,0.25,0.3}`，`pmax∈{8,10,12,15}`；
  - **中段集**：16 个可达前缀状态（从上方 12 个较难实例随机截断 40%–70%）；
  - **困难集**：9 个 `n∈{12,13,14}`、`ep∈{0.1,0.15,0.2,0.25}`、`pmax∈{10,15,20}`，筛选条件为 AG 扩展数 ≥15。
- 搜索：动作 `(i,k)`，最早开始，机器结果去重；`L0+AVAIL(U-1)`；`B_focal=32`，`ω=2`，`W_U=20`，`T_scan=30`，`K_cert=5`，`K_dom=60`；支配表按 `S` 维护 Pareto 列表；`inherit=True`。
- 变体：
  - `AG`：v0.5 风格 focal + DOM + inherit，**不跑 THRESH**；
  - `AGt`：`AG` + 根节点全扫描 THRESH；
  - `DAa`：`AG` + 自动机（DIVE/CLIMB），不跑 THRESH；
  - `DAc`：`AG` + 周期 frontier THRESH（无自动机）；
  - `DA`：`DAa` + 周期根 THRESH（derand）。
- 精确验证：独立 DFS（无下界、无支配）在若干 `n≤9` 的困难实例上计算 `OPT`；中段状态用独立 DFS 计算 `OPT(σ)`，专门验证 `L_TH≤OPT(σ)`。`n=12–14` 的困难集没有独立 `OPT`，只做变体间 `U` 的一致性检查。
- 时间：纯 Python，单线程，单次测量；只用于相对 sanity check。

### 10.2 DERAND-WINDOW：精确且更便宜

**根集（40 个实例）**：

| 指标 | 全扫描 `full` | `DERAND-WINDOW` |
|---|---:|---:|
| 与全扫描相同 `L_TH` | 40/40 | 40/40 |
| 平均装箱测试 | 22.475 | 19.575 |
| 测试数比 | 1.000 | 0.871 |

**中段集（16 个可达状态）**：

| 指标 | 全扫描 | `ub` 剪枝 | `DERAND-WINDOW` |
|---|---:|---:|---:|
| 与全扫描相同 `L_TH` | 16/16 | 16/16 | 16/16 |
| 平均装箱测试 | 48.75 | 49.38 | **21.56** |
| gain>0 的状态 | 15/16 | — | — |
| gain>0 状态的平均测试 | 50.87 | — | **21.87** |

- 中段状态的 `L_TH` 平均比 `L0` 高 **4.19**，最高 **14**。口径注意：v0.5 报告的 +0.325 是 THRESH 相对**单点 AVAIL** 的增益，这里是相对 `L0` 的增益；两者不应直接相减。本轮中段状态的 `U` 由贪心给出、比较松，强制集更丰富，这是增益较大的主要原因。
- `ub` 单独剪枝几乎不省测试（49.38），真正省的是 `best+1` 下界：一旦某个窗口给出 `best`，后续窗口只需在 `[best+1,ub]` 上二分，很多窗口直接 `lo>hi`。
- 40/40 与 16/16 的 `L_TH` 完全一致，说明 `DERAND-WINDOW` 没有牺牲强度。

### 10.3 headroom 作为预判

对 16 个中段状态，定义 `headroom = max ub+1-L0`（即 `η`，因为本轮实现中 `L_loc=L0`），`gain = L_TH-L0`。

| 检查 | 结果 |
|---|---|
| `gain ≤ headroom` | 16/16 |
| `headroom ≤ 0 ⇒ gain=0` | 1/1 |
| `headroom ≥ 2 ⇒ gain>0` | 15/15 |
| 平均 `L0` / `L_TH` | 31.625 / 35.812 |
| 平均 `gain` | 4.1875 |

这验证了引理 3.2：**在跑任何装箱测试之前，`η` 已经给出了 THRESH 收益的严格上界**。在这批状态上，它甚至是一个相当紧的预判（`headroom≥2` 的 15 个状态全部有正收益）。

### 10.4 根集上的 THRESH：仍然是"收益有限"

在 40 个根状态上，根 THRESH 只让 `L_TH` 平均提高 **0.3**，仅 **4/40** 有正收益；`AGt` 的总扩展从 129 降到 112，根闭合物从 11/40 升到 13/40。

这与 v0.5 的负结果一致：**根上的间隙主要来自优先约束，不是装箱**。v0.6 不把 THRESH 宣传成主卖点，而是用 `η` 在根上快速判定"不值得跑"，把预算留给中段状态。

### 10.5 困难集：自动机的节点收益

9 个 `n=12–14` 实例，全部变体返回相同 `U`：

| 变体 | 总扩展 | 相对 AG | 胜/平/负 vs AG |
|---|---:|---:|---|
| `AG` | 415 | 1.000 | — |
| `DAa`（自动机） | **322** | **0.776** | 6/3/0 |
| `DAc`（frontier THRESH） | 391 | 0.942 | 2/7/0 |
| `DA`（自动机 + 根证书） | **261** | **0.629** | 6/3/0 |

- `DAa` 单独就把总扩展降了 **22.4%**，6 胜 3 平 0 负；
- `DA` 再叠加周期根证书，降到 **37.1%**；
- `DAc` 只有 5.8%，且 7/9 打平——单独的 frontier THRESH 不如自动机。

**Anytime 间隙**（`U - U_AG` 的均值；`n=12–14` 没有独立 `OPT`，故以 AG 的最终 `U` 为参照，仅作相对比较）：

| 预算 | `AG` | `DAa` | `DA` |
|---:|---:|---:|---:|
| 10 | 2.00 | 1.89 | 1.89 |
| 20 | 1.33 | 1.11 | 1.11 |
| 50 | 0.00 | 0.00 | 0.00 |
| 100 | 0.00 | 0.00 | 0.00 |

困难集上 anytime 的小幅优势（约 0.1–0.2 个时间单位）不如节点数收益显著；本轮不把它当作主要卖点。

### 10.6 简单集：自动机会"休眠"

在 12 个 `n=9–11` 的简单实例上：

| 变体 | 总扩展 |
|---|---:|
| `AG` | 147 |
| `DAa` | 147 |
| `DAc` | 146 |

`DAa` 与 `AG` **完全相同**（0 胜 12 平 0 负）。这说明：当 focal 持续有进展时，自动机不会触发 CLIMB；它的收益只在"focal 停滞"的困难实例上出现。这是一个重要的边界：**自动机不是万能加速器，它是停滞时的安全网**。

### 10.7 对抗 guide：自动机的安全网作用

在 12 个简单实例上，把 guide 换成**反相关**的 `-min(CP,LPT,MWKR)`（仍用真实 makespan 更新 `U`）：

| 变体 | 总扩展 |
|---|---:|
| `AG`（反 guide） | 179 |
| `DAa`（反 guide，`W_U=10/20`） | 177 |

只有 1 胜 11 平 0 负。原因是这些实例的 `U` 很快被真实 makespan 更新，反 guide 主要影响排序、不影响正确性；自动机的 CLIMB 只在地停滞时才触发，收益很小。

**结论**：自动机的价值目前主要是**进展保证**（定理 5.1），不是可测的节点加速。节点加速只在 n=12–14 的困难集上出现，且集中在一两个实例。

### 10.8 正确性验证

| 检查 | 结果 |
|---|---|
| `L_TH ≤ OPT(σ)`（39 个 n=7–8 中段状态，独立 DFS） | 39/39，0 假证书 |
| `AG/DA` 的 `U` 与独立 DFS 一致（n=9 困难实例） | 2/2 |
| 早期 n=8 smoke test 的 `AG/DA` 与独立 DFS | 10/10（未纳入正式统计） |
| 困难集 9 个实例上四个变体的 `U` | 9/9 完全相同 |
| 简单集 12 个实例上四个变体的 `U` | 12/12 完全相同 |

### 10.9 负结果与未做

- **自动机在简单实例上完全休眠**（147 vs 147）；它不是普遍加速器。
- **`DAc` 单独很弱**（5.8%），说明证书路由必须和 CLIMB 结合才有意义。
- **根 THRESH 收益仍然有限**（0.3，4/40），与 v0.5 一致。
- **MCE-DIVE 未实现**；定理有了，但没有实验。
- **证明 DAG checker 未实现**；`HEADROOM/ROUTE-SKIP/DERAND-WINDOW` 只给出规则。
- **规模**：`n≤14`、`m=2`、随机 DAG；没有 PSPLIB、没有 `m>2`、没有 `n≥20` 的 anytime 曲线。
- **时间**：纯 Python 单次测量，不是 benchmark；困难集单实例 `0.04–0.82s`。

## 11. 已知风险

1. **自动机收益的样本集中**：困难集 415→261 的收益里，一个实例贡献了 129→60；去掉它后收益会小很多。不能外推到"自动机普遍减少 37% 节点"。

2. **`η` 可能空洞**：`η` 的上界是 `b+qmax(a)`；在 precedence-heavy 实例上 `qmax` 很大，`η` 接近 `U-L0`，`η_eff≥1` 几乎总成立，ledger 无法跳过任何证书。此时 GAP-LEDGER 退化为"每步都跑"，只剩常数开销。

3. **`η` 只覆盖 THRESH**：`L_D`、`L_AV`、`CERT-REGION` 需要各自的 headroom；本轮没有给出统一上界。

4. **`DERAND-WINDOW` 的排序开销**：`|W|=O(n²)`，排序 `O(n² log n)`；在 `n` 很大时可能比省下的装箱测试更贵。缓解：只对 `η>0` 的节点跑；或用桶排序按 `ub` 分桶。

5. **`DERAND-WINDOW` 的 `best+1` 下界依赖"窗口族固定"**：若窗口族随 `H` 变化（例如 `b=H`），单调性和跳过条件都会失效。实现必须固定 `(a,b)`，只让 `H` 变。

6. **MCE 的 DP 是指数**：`O(2^n·L^m)`；`n>15` 不可行。改用 pessimistic estimator 后，"≤期望"的保证会变成"≤估计器"，不再是严格的支配。

7. **Progress 定理不是复杂度界**：`CLIMB` 可能在一个 `f_min` 层里展开指数多个节点。它保证终止，不保证快。

8. **自动机可能"过度 CLIMB"**：在 guide 很好的实例上，CLIMB 放弃 focal 的 anytime 优势；本轮用 `W_U=20` 和"f_min 上升即回 DIVE"缓解，但没有理论最优的 `W_U`。

9. **负证书的 checker 是新事物**：`ROUTE-SKIP` 要验证"THRESH 不能改变 `L_loc`"，需要 checker 重算 `η` 与 `slack`；如果 `η` 的实现有 bug，checker 会接受一个错误的"跳过"。必须独立重算，不能信任搜索器缓存。

10. **支配剪枝与 CERT 的交互**：`CERT` 抬高某个节点的 `F` 后，它可能支配更多节点；本轮没有利用这一点做"证书传播"，只更新被直接处理的节点。

11. **实验规模小**：`n≤14`、`m=2`、随机 DAG；没有 PSPLIB/fork-join；没有 `m>2` 的精确异构装箱；没有独立 checker 对拍。`DA` 的 37.1% 不能外推到工业规模。

12. **确定性 ≠ 可移植**：所有 tie-break 用整数 `id`，没有浮点；但不同实现（节点生成顺序、窗口枚举顺序）仍可能给出不同的搜索轨迹。`DERAND-WINDOW` 的 `L_TH` 是确定的，搜索轨迹不是。

13. **`η` 的紧性只在 16 个状态上验证**：`headroom≥2 ⇒ gain>0` 15/15 是小样本观察；不能声称 `η` 是精确预测，只能声称它是严格上界。

## 12. 下一轮协议

- **P1（MCE-DIVE 实现与对拍）**：在 `n≤12` 上实现精确 DP，验证 `M(π*)≤E_D[M]`；与 CP/LPT/MWKR 比较 makespan；测 DP 状态数。
- **P2（证明 DAG checker）**：独立实现 `HEADROOM/ROUTE-SKIP/DERAND-WINDOW/MCE-DIVE` 的检查器；500 个 `n≤9`、`m∈{2,3}` 随机实例；目标零假证书。
- **P3（PSPLIB / fork-join）**：`n=20..50`，`m=2,3`；比较 v0.5、v0.6-no-ledger、v0.6-no-automaton、v0.6 完整；重点看 `η` 的跳过率与自动机的触发率。
- **P4（`η` 的推广）**：为 `L_AV`、`L_D`、`CERT-REGION` 推导各自的 headroom；目标是统一的"证书预算分配"。
- **P5（自动机调参）**：`W_U`、`δ`、`T_scan` 的敏感性；用 ledger 的 `G_search/G_cert` 自适应 `W_U`，而不是固定 20。
- **P6（负证书的理论）**：`ROUTE-SKIP` 是一类"证明某证书族无用"的负证书；研究它的组合规则（与 `INHERIT`/`DOMINATED-BY` 的交互）。

## 13. 一句话最大风险

**当前方案最大的风险是：自动机的节点收益集中在 12–14 个任务的随机 DAG 上（9 个实例里 1 个贡献了 129→60 的大部分），`η` 在 precedence-heavy 实例上可能因 `qmax` 很大而变得空洞，而 MCE-DIVE 的指数 DP 与负证书 checker 都还没有经过规模验证。**
