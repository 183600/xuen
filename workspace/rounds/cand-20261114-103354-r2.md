# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；本轮灵感：「轮足机器人」×「容错控制」）

> R72 把证书从「认知层测量链」下沉到「具身系统」：REG 实时执行图（ROS 2 调度契约 + RTA + 熔断）、IRL 意图隐变量 z、DMEM 灵巧手接触模式 c 与四分量接触不确定度、EREFLEX 三层反作用 ψ/z/c、ERVOI、E-RISK、S2R-UQ、J_EMB。它回答的是：**测量链在实时调度、意图模糊、灵巧接触下，还能逐指令兑现风险界吗？**
>
> 但 R72 有三条隐含假设，本轮两个灵感正好逐条击穿：
> - **轮足机器人视角**：R72 的「本体」是**固定拓扑**的——固定连杆、固定接触点集合、固定运动学。轮足机器人却是**混合离散系统**：同一台机器在轮式（高效、连续接触、少自由度）与足式（越障、离散落足、欠驱动平衡）之间切换；**运动模式 m 本身就是会跳变的隐状态**，而**模式切换瞬间（起身/蹲下/上台阶/跳越/轮腿过渡）是全身最危险的相位**。R72 的接触模式 c 只描述「末端怎么接触」，无法描述「**整机处于哪种运动体制、接触拓扑如何、动力学是否欠驱动**」。把 m 当成又一个 c，会把「模式切换瞬态」误读为「世界状态突变」，把「欠驱动平衡失败」误读为「物体位姿跳变」。
> - **容错控制视角**：R72 的「退化链」是**算法退化**（REG 熔断 / IRL 失效 / DMEM 失效 → R71/R68）——它隐含假设**本体始终完好**，降级只是关掉某些高级功能。真实系统会**坏**：轮毂电机堵转、关节编码器偏置、IMU 漂移、轮胎磨损、驱动器过热、结构裂纹、通信丢包。容错控制（FTC）关心的是完整链条：**故障检测与隔离（FDI）→ 控制重构（control allocation）→ 剩余权限（authority）→ 安全降级**。R72 没有任何「健康状态 h」的概念，因此它的证书对「执行过程中本体坏掉」是**结构性盲的**。
> - **二者交叉的杀手问题**：轮足机器人上，「打滑」既可能是**地形/接触**（冰面，c=sliding，非故障），也可能是**执行器故障**（轮毂扭矩丢失，h=actuator-fault），还可能是**模式切换瞬态**（轮→腿过渡中驱动断开）。**把故障误判为地形 ⇒ 继续加力 ⇒ 失控；把地形误判为故障 ⇒ 不必要的急停 ⇒ 任务失败与信任透支；把瞬态误判为故障 ⇒ 反复重构 ⇒ 磨损加速**。R72 的 DMEM 只能归因到 c，无法与 m、h 区分——这是**接触-模式-故障三重归因歧义**，也是本轮最硬的技术核心。
>
> 核心命题升级：**R72 问「我的测量链还兑现得起风险界吗」；R73 问「当我的**身体正在坏、并且正在轮/腿两种体制间跳变**时，我还能不能在故障把系统推出安全集之前检测它、隔离它、重构它，并对重构后的残余系统**继续兑现风险界**？」** 把 EMBODIED-GAUGE-RAS 升级为 **RESILIENT-GAUGE-RAS（R-GAUGE）**：Resilient（韧性）× Embodied（具身）× Self-diagnosing（自诊断）× Irreversibility-aware（不可逆健康预算）× Locomotion-hybrid（轮足混合）× Intent-aware（意图）× Envelope-certified（恢复包络）× Non-compensatory（权限硬否决）× Time-bounded（诊断截止）——**可容错的具身计量审计闭环**。

## 0. 直觉与动机

**灵感 1（轮足机器人 → 运动模式是「身体的意图」，模式切换是高风险动作）**
直觉：轮式与足式不是两套控制器，而是**同一个混合自动机的两个离散状态**。轮式高效但怕台阶/碎石；足式能越障但欠驱动、易失稳；混合模式（轮+腿支撑）在斜坡/载荷转移时最稳但最耗能。关键点有三：
(i) **模式不是观测出来的，而是被选择的**——控制器主动决定 `WHEEL→LEG`，但**能不能切、何时切**取决于地形、健康、速度、剩余权限；所以 m 是**半马尔可夫、含控制输入的隐状态**，与 R72 的意图 z 结构同源但作用于「自身身体」而非「他人目标」。
(ii) **模式切换是一次跳跃（jump），切换期间测量模型失效**：轮子离地、足端触地瞬间、驱动器扭矩重新分配，本体感觉与触觉都处于暂态；此时若仍用稳态似然更新 BSE，会把「暂态」误读成「世界剧变」。
(iii) **模式决定安全集与调度**：LEG 平衡模式要求更高控制频率与更低延迟，`δ_ctrl(LEG) < δ_ctrl(WHEEL)`；模式切换会改变 REG 的节点拓扑与 WCET。**「模式即语义」是 R72「调度即语义」的上一层。**

**灵感 2（容错控制 → 证书不是控制器的属性，是「故障转移系统」上的属性）**
直觉：经典 FTC 的叙事是「检测故障 → 重构控制器 → 继续任务」。但 RAS 视角要追问：**重构之后的系统，它的风险界由谁担保？** 我们认为答案是：**韧性不是一个控制器的性质，而是一个「故障转移系统（fault-transition system）」上的证书性质**。也就是：
- 对**每一个可达故障假设 h ∈ H**，都必须存在一个**降级级别 d(h)**，其证书仍有效；
- 降级映射 d 必须是一个**仿真关系（simulation）**：沿任意故障转移 `h→h'`，系统要么留在当前 d 的有效集内，要么向下走一级，**安全界只增不减**；
- 重构本身消耗**剩余控制权限（authority）**，权限是**不可补偿的硬约束**——再高的置信度、再小的不确定度，也换不回已经丢失的扭矩。
这把 R72 的「四退化情形」升级为**带偏序的退化格 + 仿真证明**，并把「容错」从设计经验变成**可审计的证书族**。

**灵感 3（轮足 × 容错 → 接触/模式/故障三重归因歧义）**
直觉：轮足机器人上，一个残差 r（轮速与里程计不符、IMU 出现横向加速度、关节力矩异常）可以被至少三类假设解释：
- **接触假设**：地面摩擦变了（冰/油/砂），c 变，**不是故障**；
- **模式假设**：正处于 `WHEEL→LEG` 瞬态，驱动短暂卸载，**不是故障**；
- **故障假设**：轮毂电机扭矩常数退化、编码器偏置、轮胎爆胎，**是故障**。
三者的**观测支撑集重叠**，单通道残差无法区分。更糟的是**误归因代价高度不对称**：把故障当地形 → 继续给扭矩 → 打滑/翻车（灾难）；把地形当故障 → 保守急停（低效但安全）；把瞬态当故障 → 反复重构（磨损级联）。所以必须引入**跨通道一致性**与**非对称损失下的归因规则**，并显式把「归因歧义度 ι_attr」放进证书——**单源证据不得对故障定案**（延续 R71/R72 的「单源不定案」原则，但对象从「世界状态」变成「自身的病」）。

**灵感 4（四层反作用 → 健康是唯一的「不可逆」自反作用层，会级联）**
直觉：R72 的反作用是 ψ（情感）、z（意图）、c（接触）三层，都**可恢复、可回退**：人可以消气，意图可以澄清，接触可以重抓。R73 新增 **L4 健康反作用 h**，它有三个残酷的不同：
- **不可逆**：过热、磨损、裂纹、编码器漂移不会自动恢复（健康势 Φ(h) 单调不增）；
- **自反且加速**：激进控制 → 热/冲击/负载↑ → 故障概率↑ → 剩余执行器被迫承担更多 → 更多故障，形成**正反馈级联**；
- **预算非再生**：不能像 R72 的 B_reflex 那样「花掉再攒回」，只能**预留**。
因此 R72 的贪心 ERVOI 在 L4 下**不再最优**（存在「留一点健康给恢复」的期权价值），必须升级为**带硬预算约束的 CMDP / 拉格朗日前瞻**。**健康不是又一项成本，而是一份会耗尽的、决定你还能不能退化的战略储备。**

**灵感 5（诊断截止时间 → 故障检测也有 deadline）**
直觉：R72 用 RTA 证明「控制环 WCET ≤ δ_ctrl」。FTC 里有一个完全平行的时序量，却长期被当成「平均检测延迟」：**从故障发生到它能把系统推出安全集，还剩多少时间**。定义
`T_unsafe(k)`：在认证前缀 k 与最坏可容许故障演化下，系统首次离开安全集的时间；
`T_diag = τ_detect^{99.9} + τ_isolate + τ_reconfig`：检测（99.9 分位）+ 隔离 + 重构所需时间。
**证书存在的必要条件**是 `T_unsafe(k) > T_diag`（诊断截止时间裕度 Δ_diag > 0）。若某类故障演化得比我们能诊断它还快，那么**没有任何控制器能救**，唯一正确的动作是**收缩认证前缀 k**（降速/减小动作幅度），把 T_unsafe 推远，直到重新满足裕度。这把「安全」从「控制器好不好」变成「**你的诊断速度追不追得上故障的破坏速度**」——**诊断也有 deadline，且它是证书的一部分。**

## 1. 形式化定义（增量：定义 366–381）

**定义 366（RESILIENT-GAUGE-RAS 总览）** RESILIENT-GAUGE-RAS = (REG†, HYM, FDIM, FTC-A, DTO, REC, H-RISK, EREFLEX†, J_RES)。六不变式：
(i) **模式-健康显式性**：所有控制/规划/证书必须条件于 (m, h) 或其后验（定义 367–369）；
(ii) **归因可分离性**：c / m / h 三重归因必须跨通道，单源不得定案（定义 370）；
(iii) **诊断截止优先**：认证前缀 k 必须满足 T_unsafe(k) > T_diag（定义 372），否则收缩 k；
(iv) **权限不可透支**：控制分配后的权限裕度 α ≥ α_min；α 是不可补偿硬否决（定义 373–376）；
(v) **不可逆健康预算**：健康势 Φ(h) 单调不增，累计损耗 ≤ B_health，级联核谱半径 < 1（定义 375）；
(vi) **严格退化**：新层失效 ⇒ 退化为 R72/R71/R68，安全只增不减（定义 378）。

**定义 367（联合具身状态与因子化后验）** 具身状态 ξ = (s, z, c, m, h)。联合后验按「时间尺度分离」因子化：
b_t(ξ) ≈ b_t(m, h) · b_t(c | m, h) · b_t(z | m) · b_t(s | c, m, h, z)。
合理性：m、h 是**慢变量**（秒级），c 是**快变量**（毫秒级），z 是**任务级**，s 是**物理级**。因子化误差 ε_fac 显式进入证书（定义 379）；当 ε_fac > τ_fac 时禁止使用因子化近似，回退到 R72 的三元后验。

**定义 368（轮足混合运动模式 m）** m ∈ ℳ = {WHEEL, LEG, HYBRID, BRACE, RECOVERY}。混合自动机 A_m = (ℳ, Guard, Jump, f_m, g_m, σ)：
- 每个模式有模式相关动力学 ẋ = f_m(x, u) + w 与观测 y = g_m(x, u) + v；LEG/HYBRID 可欠驱动；
- 接触拓扑 σ(m) ⊆ limbs × {wheel, foot, air} 描述每条腿的接触类型；
- 迁移 (`m→m'`) 由守卫 Guard_{m→m'}(x, h, 地形) ∈ {0,1} 与控制器决策联合触发（m 是**含控制输入的半马尔可夫隐状态**）；
- 每次迁移含**切换瞬态窗** [t_sw, t_sw + Δ_t(m→m')]，窗内观测模型 g_m 失效，必须切换为**备份/鲁棒控制器**并暂停 BSE 测量更新。
**关键**：m 是「身体的意图」，与 z（人的意图）结构同源；切换是**受证书约束的动作**（定义 377）。

**定义 369（健康/故障隐变量 h 与故障签名）** h ∈ ℋ = {nominal} ∪ ℋ_act ∪ ℋ_sen ∪ ℋ_str：
- ℋ_act = {轮毂电机失效/堵转、关节扭矩衰减、驱动器过热、抱闸卡死}；
- ℋ_sen = {编码器偏置、IMU 漂移、力矩零点漂移、轮速计标定失效}；
- ℋ_str = {轮胎磨损/爆胎、连杆裂纹、关节间隙}。
每个故障有类型（瞬态/间歇/持久）与严重度 s_h ∈ [0,1]。**故障签名矩阵**：受 h 影响的有效性矩阵 B(h) 将指令力矩映射为实际力矩；结构化残差 r = y − ŷ ~ 𝒩(μ_h, Σ_h)。后验 b_t(h, s_h) 由跨通道残差在线推断。

**定义 370（三重归因歧义）** 给定残差 r，其归因假设集
A(r) = { (Δc, Δm, h) : r ∈ supp p(r | Δc, Δm, h) }。
定义**非对称误归因损失** L(a*, â)，满足 L(h→c) ≫ L(c→h) > L(Δm→h)（把故障当环境 = 灾难；把环境当故障 = 保守）。归因歧义度
ι_attr(b) = E_{a*∼b}[ min_{â≠a*} L(a*, â) ] / L_max。
**规则**：ι_attr > τ_attr 时，不得输出确定性归因，必须：(a) 触发跨通道一致性检验（轮速计 vs 视觉 vs IMU vs 关节运动学）；(b) 允许保守归因（默认按故障处理，除非有强反证）；(c) 进入主动诊断（定义 381）。

**定义 371（FDI 计量审计）** 故障检测与隔离器输出
(ĥ, b_t(h), ECE_fault, τ_detect^{p}, ι_iso, FAR, MDR, OOD_fault, D_fdi, τ_fdi)，
其中 τ_detect^{p} 为 p 分位检测延迟（证书用 99.9 分位，不用均值），ι_iso 为隔离歧义，FAR/MDR 为虚警/漏检率，D_fdi 为 FDI 有效域，τ_fdi 为其追溯链。**FDI 自身也是一条测量链**，必须被 GAUGE 审计：若 ECE_fault 超阈、OOD_fault 触发或 τ_fdi 断链，则**禁止发放韧性证书**。「谁监控监控者」的递归由定义 366(vi) 的 RTM/安全壳作为**信任锚**截断（FDI 失效 ⇒ 退化为保守固定故障先验 + R68 安全包络）。

**定义 372（诊断截止时间 DTO）** 对认证前缀 k（动作序列 A_1..A_k）与故障演化集合，定义
T_unsafe(k) = inf{ t : x(t) ∉ SafeSet ∨ risk(t) > ε_res }，取**最坏可容许故障演化**；
T_diag = τ_detect^{99.9} + τ_isolate + τ_reconfig；
**诊断裕度** Δ_diag(k) = T_unsafe(k) − T_diag。
**证书条件**：Δ_diag(k) > Δ_min > 0。**最大认证前缀** k* = max{ k : Δ_diag(k) > Δ_min }。若 k* = 0，只允许急停/恢复（RECOVERY 模式）。T_unsafe 由离线可达性给出保守下界 + 在线预计算插值（O(1) 查表）。

**定义 373（容错控制分配与权限账本）** 控制分配
u* = argmin_u ‖W_u u‖² s.t. B(h) u = τ_des, u ∈ U(h)，
其中 U(h) 为故障后各执行器可达集合。可达力矩集 𝒯(h) = B(h)U(h)；**权限裕度**
α(h, τ_des) = dist(τ_des, ∂𝒯(h)) / ‖τ_des‖ ∈ [0, 1]。
**权限账本** Λ_t 记录每个执行器的已用/剩余权限与被降额量；重构不得**静默**把负载转嫁给健康执行器（否则加速 L4 级联）。重构在控制域执行，其 WCET 计入 δ_ctrl(m')（引理 39）。

**定义 374（可达安全集与恢复不变量集）** 模式-健康条件下的**受控不变可生存集**
V(h, m) = 在 SafeSet 内、动力学 f_m 与可达力矩 𝒯(h) 下能永远停留的最大受控不变集。
**恢复不变量集** R ⊆ ⋃_{h,m} V(h,m)，且存在恢复控制器 π_rec，使 ∀ x ∈ R、∀ 可达 h ∈ ℋ，在 T_rec 内要么回到 V(nominal, m)，要么进入某个**已认证的降级集** V(d(h), m)。认证执行必须满足 x_t ∈ V(h_t, m_t)（或 x_t ∈ R 等待恢复）。

**定义 375（四层反作用 EREFLEX† 与不可逆健康预算）** L1 ψ、L2 z、L3 c 继承 R72。**L4 h**：
- 健康转移 p(h_{t+1} | h_t, u_t^ctrl, load_t)：控制负载/热/冲击驱动故障发生；
- 边际健康成本 c_reflex^h = ΔΦ(h) + λ_h·𝟙[h ∉ ℋ_safe]，其中健康势 Φ(h) **单调不增**；
- **不可逆预算** Σ_t ΔΦ(h_t) ≤ B_health，且 B_health 不可再生；
- **级联核**：故障降低权限 α → 剩余执行器负载 L↑ → 故障率 ∝ κ(L) → 定义级联谱半径 ρ_casc；**稳定性要求 ρ_casc < 1**，否则必须主动降额。
合计预算：可逆三层 Σ(c^ψ+c^z+c^c) ≤ B_reflex_total；不可逆层独立约束 Σ ΔΦ ≤ B_health。**贪心 VoI 在 L4 下不再最优**（引理 35）。

**定义 376（健康感知风险缩放 H-RISK）** 
λ = max( risk_scale(U_ale, U_epi, H_z, u_tac, H_h, H_m),
         λ_floor(U_ale + U_epi + H_z + u_tac + H_h + H_m),
         λ_auth(α) )
其中 **λ_auth(α) = ∞ 若 α < α_min**，否则随 (1−α) 单调上升。**物理/意图/接触/健康/模式五维不确定度同权入分母；权限是硬否决，不可被任何置信度补偿**——延续 R71「非补偿性安全否决」，但把「否决源」从认知指标扩展到**物理剩余能力**。

**定义 377（模式切换证书）** 切换动作 `m→m'` 允许当且仅当：
(i) 目标可生存：x_t ∈ V(h, m')（当前健康下的目标模式仍有非空可生存集）；
(ii) 瞬态有界：∫_{瞬态} risk dt ≤ ε_switch；
(iii) 瞬态可认证：瞬态窗内观测失效，必须由**备份/鲁棒控制器**证明 x(t) 留在 SafeSet；
(iv) 调度可认证：δ_ctrl(m') 可调度且重构 WCET 入账（引理 39）。
四者全满足才产出 J_switch；否则禁止切换，停留在当前模式或进入 RECOVERY。

**定义 378（故障转移退化格与仿真关系）** 退化级别 D = {D0 全功能, D1 无 IRL, D2 无 DMEM, D3 R71, D4 R68 开环, D5 急停/恢复}。退化映射 d : ℋ × ℳ → D 满足**仿真关系**：对任意可达故障转移 (h,m) → (h',m')，要么 d 不变且 x ∈ V(h',m')，要么 d 严格下降一级且 x ∈ V(d(h'),m')。**安全单调**：沿 d 下降，认证风险界不减（ε(D_{i+1}) ≥ 安全余量意义上的更强包络）。R72 的四情形退化是此格在 h≡nominal、m 固定时的**一维截断**。

**定义 379（韧性证书 J_RES）** J_RES = (J_EMB, H_cover_hash, fdi_validity, dto_proof, authority_ledger_hash, viability_proof, switch_certs, health_budget_proof, cascade_spectral, factor_err, res_ver)。
Valid ⇔ J_EMB 有效 ∧ H_cover 与部署故障假设集一致 ∧ FDI 审计通过 ∧ Δ_diag(k*) > Δ_min ∧ α ≥ α_min ∧ x ∈ V(h,m) ∧ Σ ΔΦ ≤ B_health ∧ ρ_casc < 1 ∧ ε_fac ≤ τ_fac。

**定义 380（威胁模型 AIC-RES）** ℰ_RES = ℰ_EMB × ℰ_fault × ℰ_attr：
ℰ_fault = {故障掩蔽（隐藏真实故障）、故障诱导（对抗性热/负载注入加速损坏）、虚假故障注入以触发不必要急停（诊断 DoS）、诊断截止攻击（让故障演化快于 τ_detect）、伪造健康信号}；
ℰ_attr = {故障-接触混淆注入、模式瞬态伪装、地形欺骗（把故障伪装成冰面）}。

**定义 381（主动诊断 VoI：AD-VoI）** 允许动作集新增**诊断探针** g_diag（受控激励：短暂负载测试、单腿点地、微滑探测）。其 VoI 为
VoI^D(g) = H[b(h)] − E[H[b'(h)]] + η_m (H[b(m)] − E[H[b'(m)]]) − c_probe(g) − ΔΦ(g) − γ·E[ΔH^{future}]，
其中 c_probe 为瞬态风险成本，ΔΦ 为健康消耗。**只有当 VoI^D > 0、探针证书有效、且健康预算留足恢复储备时才执行**——「花一点小风险去买可诊断性」，但**永远保留回不去的健康**。

# IP-295 HYM：轮足模式推断（计量域 50Hz；切换瞬态暂停测量更新）
class HybridModeInference:
    def __init__(self, terrain_net, mode_hmm, proprio_calib):
        self.terrain, self.hmm, self.calib = terrain_net, mode_hmm, proprio_calib
    def update(self, obs, proprio, last_ctrl, h_post):
        m_prev = self.hmm.last_mode
        m_prior = self.hmm.predict(m_prev, last_ctrl, self.terrain(obs))
        if self.hmm.in_transient():          # 切换瞬态：观测失效，只用动力学
            m_post = m_prior
            trans  = True
        else:
            m_post = self.hmm.correct(m_prior, proprio, h_post)
            trans  = False
        return ModePosterior(b_m=m_post, transient=trans,
                             switch_risk=self.calib.transient_risk(m_post),
                             tau=self.calib.tchain)

# IP-296 FDIM：故障诊断 + 自身计量审计（含接触/模式条件化，抗三重歧义）
class FaultDiagnosisMetrology:
    def __init__(self, signature, calib, cusum):
        self.sig, self.calib, self.det = signature, calib, cusum
    def update(self, residual, c_post, m_post):
        # 关键：残差似然必须条件于 (c, m)，否则会把打滑/瞬态当故障
        b_h = self.sig.match(residual, c=c_post, m=m_post)   # b_t(h, s_h)
        det = self.det.step(residual)
        tau = det.alarm_time - det.onset if det.alarm else self.calib.max_tau
        return FaultEvidence(
            b_h=b_h, ece=self.calib.ece_fault(), tau_detect=tau,
            iota_iso=self.sig.isolation_ambiguity(b_h),
            far=self.calib.far(), ood=self.calib.ood_fault(),
            tau=self.calib.tchain)

# IP-297 FTC-A：带权限账本的控制分配（控制域硬实时）
def allocate_with_authority(tau_des, h_post, m, limits, ledger):
    B = effectiveness_matrix(h_post)          # E[B(h)]
    U = actuator_limits(h_post)               # 故障后可达集
    u, alpha = qp_allocate(tau_des, B, U)     # min ||W u||^2 s.t. B u = tau
    ledger.consume(u, alpha)                  # 记录转嫁，防静默过载健康执行器
    if alpha < ALPHA_MIN:
        return None, alpha, ledger            # 权限硬否决
    return u, alpha, ledger

# IP-298 DTO：诊断截止时间与前缀收缩（离线可达 + 在线查表）
def diagnosability_prefix(k_max, tau_diag, reach_table):
    k = k_max
    while k > 0:
        T_unsafe = reach_table.time_to_unsafe(k)      # 最坏故障演化下的保守下界
        if T_unsafe > tau_diag + T_RECONFIG + DELTA_MIN:
            return k, T_unsafe - tau_diag             # Δ_diag
        k -= 1
    return 0, 0.0                                     # 只能急停/恢复

# IP-299 REC：恢复不变量集成员查询（O(1)）
def in_recovery_set(x, h_post, m):
    return x in R_BY_MODE[m] and recovery_exists(m, h_post)

# IP-300 H-RISK：健康/模式/权限进入 λ，权限为硬否决
def resilient_risk_scale(U_ale, U_epi, H_z, u_tac, H_h, H_m, alpha, p):
    denom = U_ale + U_epi + H_z + u_tac + H_h + H_m
    lam = max(p.lam_base * (1 + denom / p.lam_scale),
              p.lam_floor * (1 + denom))
    if alpha < p.alpha_min:
        return float('inf')                  # 不可补偿：没有权限就没有指令
    return lam * (1 + p.lam_auth * (1 - alpha))

# IP-301 EREFLEX†：四层反作用（L4 不可逆健康预算）
def ereflex_res_step(psi, z, c, h, g, budget, p):
    psi2, c_psi, _ = reflex_step(psi, g, p)          # L1
    z2  = intent_transition(z, g, psi)               # L2
    c2  = contact_transition(c, g)                   # L3
    h2, dphi, load = health_transition(h, g)         # L4：负载 -> 故障概率
    cost_rev = kl(z, z2) + (c2.entropy() - c.entropy())
    if h2 not in H_SAFE or dphi > budget.health_left:
        return None                                  # 健康不可逆越界 -> 拒绝
    if cascade_spectral(h2, load) >= 1.0:
        return None                                  # 级联不稳定 -> 必须降额
    return psi2, z2, c2, h2, (cost_rev, dphi)

# IP-302 AD-VoI：主动诊断决策
def active_diagnosis_voi(b_h, b_m, probes, budget, p):
    best = None
    for g in probes:
        if not probe_certificate(g): continue
        if g.dphi > budget.health_left - budget.recovery_reserve: continue
        h2, dphi = expected_health(b_h, g)
        ig = (entropy(b_h) - expected_entropy(b_h, g)) \
             + p.eta_m * (entropy(b_m) - expected_entropy(b_m, g))
        score = ig - g.cost - dphi - p.gamma * expected_future_loss(g)
        if best is None or score > best[1]:
            best = (g, score)
    return best[0] if best and best[1] > 0 else None

# IP-303 R-GAUGE 主闭环：模式感知调度 + 故障转移运行时
def RESILIENT_GAUGE_RAS_round(M, obs, audio, tac, proprio):
    # ===== 控制域 1kHz（δ_ctrl 依 m 变化；LEG 更紧）=====
    snap = M.snapshot.read_latest()
    m    = snap.m_post.mode
    h    = snap.h_post
    alpha = M.ledger.margin()
    lam  = resilient_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                                snap.u_tac, snap.H_h, snap.H_m,
                                alpha, M.risk_params)
    if lam == float('inf') or not in_recovery_set(snap.x, h, m):
        k = 0; u = M.recovery.emergency_stop()       # 权限耗尽/出可生存集
    else:
        A  = M.ach.propose_ctrl(snap.b, m, h)
        k  = M.c_ras_wm.certified_prefix(A, lam, M.dto.k_star(h, m))
        u, alpha, M.ledger = allocate_with_authority(A[:k], h, m,
                                                     M.limits, M.ledger)
        if u is None:
            k = 0; u = M.recovery.emergency_stop()
    M.ctrl_out.publish(u, lam)
    M.cert_ctrl.write(k=k, lam=lam, alpha=alpha, mode=m,
                      wcet=M.rtm.wcet_us(), breaker=M.breaker.status())

    # ===== 计量域 50Hz（软实时）=====
    if M.clock.due_metric():
        m_post = M.hym.update(obs, proprio, M.last_ctrl, M.h_post)     # 295
        h_ev   = M.fdim.update(M.residual, snap.c_post, m_post)        # 296
        # 三重归因 + 非对称损失
        attr   = attribute(M.residual, snap.c_post, m_post, h_ev,
                           asymmetry=LOSS)
        # 故障转移：更新退化级别（仿真关系）
        M.mode = degradation_map(h_ev.b_h, m_post)
        # 诊断截止：收缩前缀
        k_star, delta = M.dto.update(m_post.mode, h_ev.tau_detect)
        # 主动诊断（事件触发）
        if h_ev.iota_iso > TAU_ATTR and M.budget.health_left > M.budget.reserve:
            g = active_diagnosis_voi(h_ev.b_h, m_post.b_m, M.probes,
                                     M.budget, M.params)
            if g: M.execute_probe(g)
        M.snapshot.write(m_post=m_post, h_post=h_ev.b_h, attr=attr,
                         delta_diag=delta, k_star=k_star, U_ale=..., U_epi=...,
                         H_z=..., u_tac=..., H_h=entropy(h_ev.b_h),
                         H_m=m_post.entropy(), c_post=snap.c_post)

    # ===== 感知域（Best-effort）=====
    M.tac_ev = M.dmem.update(tac, M.last_ctrl)
    M.y_intent_buf.append(extract_intent_obs(obs, audio, M.last_ctrl))
    psi_hat, ece = M.aura.update(audio)
    if ece > TAU_AFF: M.psi_hat = None
    # 模式切换（受证书约束的动作）
    if M.hym.wants_switch() and switch_certificate(M, M.hym.target_mode):
        M.scheduler.reconfigure(M.hym.target_mode)   # 模式感知调度
        M.hym.commit_switch()

    return k, lam, J_RES(M)

## 3. 推导

**引理 33（诊断截止时间 ⇒ 认证前缀收缩）** 若 Δ_diag(k) = T_unsafe(k) − T_diag ≤ Δ_min，则不存在任何控制策略能对前缀 k 发放 J_RES。证明：由定义 366(v) 与 378，证书要求对每个可达故障 h 存在有效降级，而降级需在 T_diag 内完成；若最坏故障在 T_unsafe(k) 前即离开安全集，则降级尚未完成系统已越界，与「有效降级」矛盾。故必须收缩 k 直到 Δ_diag(k) > Δ_min；k* 的存在性由 T_unsafe 关于 k 的单调性（动作越短越保守）保证。系：**「安全」不仅是控制问题，还是「诊断速度 vs 破坏速度」的竞赛。**

**引理 34（三重归因非对称损失下界）** 若归因假设 A(r) 的支撑重叠质量 p_amb > 0，则任何仅依赖单通道残差 r 的确定性归因规则，其期望损失满足
E[L] ≥ p_amb · min(L(c→h), L(h→c), L(Δm→h)) > 0，
且该下界可通过跨通道一致性检验（把 A(r) 的支撑取交）降为 0（当且仅当通道条件独立且至少一通道在 h 下与在 c/Δm 下支撑不交）。证明：由贝叶斯风险下界与支撑重叠定义直接得到；跨通道取交降低歧义质量。系：**「单源不定案」在故障域不是保守主义，而是非对称损失下的最优决策。**

**引理 35（不可逆预算下的有限停止，且贪心非最优）** 设健康势 Φ(h_t) 单调不增且每步非零负载下严格下降，下界为 Φ_min，则总动作步数有限：n ≤ (Φ_0 − Φ_min)/ε_Φ。但贪心 ERVOI（每步取最大即时净收益）可能提前耗尽预算，使后续必须执行的高价值**恢复**动作无预算可用；存在反例使贪心策略的累计收益严格低于带恢复储备约束的 CMDP 最优值。故 L4 下应求解带硬约束的 CMDP：max E[Σ r] s.t. E[Σ ΔΦ] ≤ B_health − B_reserve。系：**健康预算的核心不是「怎么花」，而是「给回不去的那一步留多少」。**

**引理 36（权限的不可补偿性与风险单调）** 在定义 373 下，故障使 B(h) 退化，可达集 𝒯(h) 收缩，故 α(h, τ_des) 关于故障严重度单调不增。当 α < α_min 时，存在 τ_des ∉ 𝒯(h)，任何有限 λ（即任何降速/软化）都无法使该指令在执行器极限内实现；因此 λ_auth 必须为硬否决（∞），不能作为可加权项。系：**不确定度可以「用保守换安全」，权限不能——这是两类完全不同的风险来源。**

**引理 37（模式切换瞬态证书保持）** 若 (a) x_t ∈ V(h, m')；(b) 瞬态窗 [t_sw, t_sw+Δ_t] 内备份控制器使 x(t) ∈ SafeSet；(c) ∫瞬态 risk dt ≤ ε_switch；(d) 目标模式调度可认证；则 `m→m'` 全过程的认证风险 ≤ max(ε_switch, ε_res)。证明：把切换过程分三段（切换前/瞬态/切换后）分别用 V(h,m)、备份控制器、V(h,m') 认证，拼接即得；瞬态测量失效不影响，因为备份控制器不依赖被污染的测量。系：**切换的安全性来自「备份控制器 + 目标可生存集」，而不是「切换瞬间估得准」。**

**引理 38（故障转移仿真 ⇒ 安全单调）** 若退化映射 d 是仿真关系（定义 378），且每个退化级别的控制器在其不变量上有效，则对任意可达故障轨迹，执行始终位于 ⋃_i V(d_i) 内，且沿 d 下降风险界单调不恶化。证明：对故障转移步数归纳；每步由仿真关系保证要么留在原 V，要么进入更低级的 V，后者由对应控制器认证；安全界按级别包含关系单调。系：**「容错」可被证明为一条仿真链，而不是一堆 if-else 降级分支。**

**引理 39（重构本身必须可调度）** 设目标模式 m' 的控制 WCET 为 C(m')、重构计算 WCET 为 C_rec，则认证要求 C(m') + C_rec(暂态摊销) ≤ δ_ctrl(m')；若一次重构放不下，必须**分期重构（staged reconfiguration）**：在安全点（x ∈ R 且进入短暂开环安全区）分多个周期完成，并把每个中间态加入认证。证明：由 REG† 的 RTA 与定义 373；否则重构期间控制环 deadline miss，引理 28 失效。系：**恢复动作本身也要过 RTA——救火不能把消防通道堵死。**

**定理 27（严格包含与风险单调）** 当 ℋ = {nominal}、ℳ = 单点、B(h) = I 时，RESILIENT 退化为 R72 的 EMBODIED（定义 364 逐指令等价）；且对任意有效执行，其风险界 ≤ R72 的风险界。**安全单调不减，效率仅在「模式可辨、故障可诊断、权限充足」时获益。**

**定理 28（韧性证书有效性 ⇒ 故障下有界安全）** 在 A111–A116（H_cover 完整、FDI 审计通过、Δ_diag(k*) > Δ_min、α ≥ α_min、x ∈ V(h,m) 或 x ∈ R、ρ_casc < 1、ε_fac ≤ τ_fac）下，若一次执行通过 J_RES，则对所有**在认证时域内可达的 h ∈ H_cover**，物理执行风险 ≤ ε_res。证明由引理 33（前缀足够短）、引理 36（权限未透支）、引理 38（仿真链）、定理 24（J_EMB 有效）逐条合成。**证明重量落在「H_cover 真的覆盖了会发生的故障」与「FDI 没有骗我们」上。**

**定理 29（诊断截止不可满足 ⇒ 必须收缩或停机）** 若对当前 (h,m) 有 Δ_diag(k) ≤ Δ_min 对所有 k ≥ 1 成立，则 J_RES 不可发放，系统必须切换到 RECOVERY（k=0）或进入 R68 安全包络。这是引理 33 的直接推论，也是运行时的**强制规则**（不是建议）。

**定理 30（级联稳定性）** 设级联核 K 描述「故障 → 负载转嫁 → 新故障」的一步期望放大，若谱半径 ρ(K) < 1，则故障传播的期望总量有界（Neumann 级数收敛）；若 ρ(K) ≥ 1，则存在故障级联放大，必须主动降额使 ρ < 1 或进入 RECOVERY。证明：线性化故障-负载耦合的 Neumann 级数。系：**容错的敌人不只是故障本身，还有「为了补偿故障而把健康部件累死」的级联。**

**定理 31（模式自动机 + 恢复集 ⇒ 无死锁/活锁）** 若每个模式的 Guard 在其可生存集上完备（不把系统困在无出口状态）、恢复控制器在 R 上有定义、且切换优先级单调（RECOVERY 最高），则混合自动机在认证执行下无死锁、无活锁。证明：构造一个秩函数（模式偏序 + 到 V(nominal) 的距离）沿恢复路径严格下降。系：**「能退化」还不够，必须证明「退化路径自身不会卡死」。**

## 6. 本轮最大风险

**一句话**：RESILIENT-GAUGE-RAS 把安全从「相信计量审计证书」与「相信调度契约」进一步转移到「相信**故障假设集 H 是完备的**、相信**故障诊断器没有骗我们**、相信**健康势与级联核在分布外仍可标定**」——**若真机出现一个从未建模的故障（新型多故障耦合、被攻击者刻意在诊断截止窗外触发的隐蔽退化、把故障伪装成地形的对抗输入），或 FDI 在 OOD 下给出高置信的错误隔离，而 H_cover 与 ECE_fault 都显示「一切正常」，同时模式切换瞬态与重构又恰好吃掉那点 Δ_diag 裕度，那么系统会拿着一份「所有故障假设都已覆盖、所有诊断都在有效域、所有权限账本都平衡」的盖章韧性证书，在真机上翻车、把执行器烧毁、并在事后审计中证明「它从未超出它所想象的故障世界」——这就是**对未建模故障的「自信地可容错」**。**

次级风险与缓解：
1. **H 不完备（开放世界故障）** → 在线**假设扩张（hypothesis expansion）**：OOD 残差触发新增故障类并进入保守包络；SEAL-Fault 隐藏故障集做离线覆盖审计；H_cover 不匹配即拒绝发证。
2. **FDI 被掩蔽/投毒** → **跨通道证明（wheel odometry × vision × IMU × joint kinematics）** + 单源不定案 + SEAL-Fault 对抗审计 + FDI 自身 TCHAIN。
3. **c/m/h 三重归因错误** → 非对称损失决策 + 主动诊断探针 + 「高负载时默认按故障处理」的保守偏置。
4. **健康预算错配 / 贪心耗尽** → CMDP + 恢复储备 B_reserve + 离线策略评估；禁止动用恢复储备做探索。
5. **故障级联** → 监测 ρ_casc，主动降额；负载转嫁必须入账，禁止静默。
6. **模式切换瞬态吃裕度** → 备份控制器 + 目标可生存集 + 分期重构 + 模式感知 RTA。
7. **sim2real 故障签名漂移** → 把故障参数纳入 S2R-UQ；实机故障注入标定；重尾分位取 99.9%。
8. **复杂度爆炸** → 模块上限 |ℳ|≤6、|ℋ|≤16、|D|≤6；层次化后验（先 m/h 慢变量，再 c/s 快变量）；复杂度纳入审计指标。

# 第 73 轮产物 · 创新点清单 v4：RESILIENT-GAUGE-RAS（可容错的具身计量审计闭环；HYM × FDIM × FTC-A × DTO × REC × H-RISK × EREFLEX† × J_RES）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 完成了「具身层」的实时调度契约（REG）、意图隐变量（IRL）、灵巧接触计量（DMEM）、三层反作用（ψ/z/c）、具身风险缩放与 sim2real 桥接，确立了「测量链在调度/意图/接触下逐指令兑现风险界」。但 R72 隐含三条未言明的假设，本轮两个灵感逐条击穿：
> - **轮足机器人**：R72 的本体是固定拓扑，没有「运动模式 m」这个会跳变的离散隐状态，更没有「模式切换瞬态期间观测模型失效」；把 m 当 c，会把整机体制切换误读为世界突变。
> - **容错控制**：R72 的退化是**算法退化**，假设本体完好；没有健康状态 h、没有 FDI、没有控制重构、没有权限账本——证书对「执行中本体坏掉」结构性盲。
> - **交叉杀手**：轮足上的打滑可由接触（冰）、模式瞬态（驱动断开）、执行器故障（扭矩丢失）三类原因造成，R72 的 DMEM 无法区分——**接触-模式-故障三重归因歧义**，且误归因代价高度不对称。
>
> 本轮三位一体补齐：
> - **HYM/FDIM/FTC-A**：把运动模式 m 与健康故障 h 显式纳入联合后验；故障诊断自身作为被测链审计；控制分配带权限账本；
> - **DTO**：引入「诊断截止时间」`T_unsafe(k) > T_diag`，把容错从「控制器性质」变成「证书的时序性质」，不可满足则收缩认证前缀；
> - **REC/退化格**：恢复不变量集 + 故障转移仿真关系，使降级链可证明而非 if-else；
> - **EREFLEX†**：新增第四层 L4 健康反作用，**不可逆、会级联、非再生预算**，贪心 VoI 不再最优，升级为 CMDP；
> - **H-RISK**：健康/模式不确定度入 λ 分母，**权限 α 作为不可补偿硬否决**；
> - **J_RES**：韧性证书 = J_EMB + 故障覆盖 + FDI 审计 + 诊断裕度 + 权限账本 + 可生存性 + 健康预算 + 级联谱半径。
>
> 核心命题：**从「我的测量链在轮足跳变、身体会坏的条件下，还能否在故障把系统推出安全集之前诊断并重构，并对残余系统继续兑现风险界？」** ——**可容错的具身计量审计闭环**。
>
> IP 编号：IP-295~303（共 9 个）+ EMBODIED 组件的 † 化。理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价，安全以仿真关系而非分支堆叠。**

## 2. 形式化定义（要点版）

**定义 366（总览与六不变式）** 核心：模式-健康显式性、归因可分离性、诊断截止优先、权限不可透支、不可逆健康预算、严格退化。任一新层失效回退 R72/R71/R68，安全只增不减。

**定义 367（联合具身状态与因子化）** ξ=(s,z,c,m,h)，按慢/快变量因子化；因子化误差 ε_fac 进证书，超阈回退 R72 三元后验。

**定义 368（轮足混合模式）** m 五模式；模式相关 f_m/g_m/σ(m)；LEG/HYBRID 可欠驱动；迁移由守卫+控制输入触发；切换瞬态窗内观测失效，须备份控制器。

**定义 369（健康/故障与签名）** h 分执行器/传感器/结构三类；故障类型（瞬态/间歇/持久）+ 严重度；有效性矩阵 B(h)；结构化残差 r~𝒩(μ_h,Σ_h)。

**定义 370（三重归因歧义）** A(r)={c/m/h 假设}；非对称损失 L(h→c)≫L(c→h)>L(Δm→h)；ι_attr>τ_attr 时禁止确定性归因，须跨通道 + 保守偏置 + 主动诊断。

**定义 371（FDI 审计）** FDI 输出含 99.9 分位检测延迟、隔离歧义、虚警/漏检、OOD、有效域与追溯链；FDI 自身是被测链，未过审计不得发 J_RES；其失效由 RTM 信任锚截断。

**定义 372（DTO）** T_unsafe(k)（最坏故障演化下首次离开安全集）、T_diag=τ_detect^{99.9}+τ_isolate+τ_reconfig、Δ_diag=T_unsafe−T_diag；证书要求 Δ_diag>Δ_min；k*=max{k:Δ_diag(k)>Δ_min}；k*=0 只许急停/恢复。

**定义 373（控制分配与权限账本）** u*=argmin‖W_u u‖² s.t. B(h)u=τ_des,u∈U(h)；𝒯(h)=B(h)U(h)；α=dist(τ_des,∂𝒯(h))/‖τ_des‖；账本记录转嫁，禁止静默过载健康执行器；重构 WCET 入 RTA。

**定义 374（可生存集/恢复集）** V(h,m) 为 SafeSet 内最大受控不变集；R⊆⋃V，存在 π_rec 使 ∀x∈R、∀h，T_rec 内回 V(nominal,m) 或认证降级集；认证执行须 x∈V(h,m) 或 x∈R。

**定义 375（EREFLEX† 与不可逆健康预算）** L1/L2/L3 继承；L4：p(h'|h,u^ctrl,load)、c^h=ΔΦ+λ_h·1[h∉ℋ_safe]、Φ 单调不增、ΣΔΦ≤B_health；级联核谱半径 ρ_casc<1；可逆预算与不可逆预算分开约束；贪心非最优（引理 35）。

**定义 376（H-RISK）** λ=max(risk_scale(U_ale,U_epi,H_z,u_tac,H_h,H_m), λ_floor(…), λ_auth(α))；α<α_min ⇒ λ=∞；物理/意图/接触/健康/模式同权入分母，权限为不可补偿硬否决。

**定义 377（模式切换证书）** 允许当且仅当 (i) x∈V(h,m')；(ii) 瞬态风险≤ε_switch；(iii) 瞬态由备份控制器认证；(iv) δ_ctrl(m') 与重构 WCET 可调度。

**定义 378（退化格与仿真关系）** D={D0…D5}；d:ℋ×ℳ→D 为仿真映射；任意故障转移要么留在原 V、要么降一级进入 V(d(h'))；安全单调；R72 四情形是其在 h=nominal、m 固定时的一维截断。

**定义 379（J_RES）** Valid ⇔ J_EMB ∧ H_cover 匹配 ∧ FDI 审计通过 ∧ Δ_diag(k*)>Δ_min ∧ α≥α_min ∧ x∈V(h,m) ∧ ΣΔΦ≤B_health ∧ ρ_casc<1 ∧ ε_fac≤τ_fac。

**定义 380（AIC-RES）** ℰ_RES=ℰ_EMB×ℰ_fault×ℰ_attr；新增故障掩蔽/诱导/虚假故障 DoS/诊断截止攻击/伪造健康；归因攻击（故障-接触混淆、瞬态伪装、地形欺骗）。

**定义 381（AD-VoI）** 诊断探针 g_diag；VoI^D=H[b(h)]−E[H[b'(h)]]+η_m(H[b(m)]−E[H[b'(m)]])−c_probe−ΔΦ−γ远期；仅当 VoI^D>0、探针证书有效、且不动用恢复储备时执行。

def resilient_risk_scale(U_ale, U_epi, H_z, u_tac, H_h, H_m, alpha, p):
    denom = U_ale + U_epi + H_z + u_tac + H_h + H_m
    lam = max(p.lam_base*(1+denom/p.lam_scale), p.lam_floor*(1+denom))
    if alpha < p.alpha_min: return float('inf')       # 不可补偿
    return lam * (1 + p.lam_auth*(1-alpha))

# IP-301 EREFLEX†：四层反作用（L4 不可逆 + 级联稳定）
def ereflex_res_step(psi, z, c, h, g, budget, p):
    psi2, c_psi, _ = reflex_step(psi, g, p)
    z2 = intent_transition(z, g, psi)
    c2 = contact_transition(c, g)

# IP-302 AD-VoI：主动诊断（保留恢复储备）
def active_diagnosis_voi(b_h, b_m, probes, budget, p):
    best = None
    for g in probes:
        if not probe_certificate(g): continue
        if g.dphi > budget.health_left - budget.recovery_reserve: continue
        h2, dphi = expected_health(b_h, g)
        ig = (entropy(b_h) - expected_entropy(b_h, g)) \
             + p.eta_m*(entropy(b_m) - expected_entropy(b_m, g))
        score = ig - g.cost - dphi - p.gamma*expected_future_loss(g)
        if best is None or score > best[1]: best = (g, score)
    return best[0] if best and best[1] > 0 else None

## 4. 推导

**引理 33（诊断截止 ⇒ 前缀收缩）** 若 Δ_diag(k)≤Δ_min，则无策略能对前缀 k 发放 J_RES；必须收缩到 k* 使 Δ_diag(k*)>Δ_min，k*=0 时只允许急停/恢复。系：安全是「诊断速度 vs 破坏速度」的竞赛。

**引理 34（三重归因非对称损失下界）** 支撑重叠质量 p_amb>0 时，任何单通道确定性归因的期望损失 ≥ p_amb·min(L(c→h),L(h→c),L(Δm→h))>0；跨通道取交可降为 0（通道条件独立且至少一通道支撑不交）。系：故障域「单源不定案」是贝叶斯最优，不是保守。

**引理 35（不可逆预算：有限停止且贪心非最优）** Φ 单调不增且有下界 ⇒ 步数有限 n≤(Φ_0−Φ_min)/ε_Φ；但贪心 ERVOI 可能耗尽预算使恢复无预算，存在严格劣于带恢复储备的 CMDP 的反例。系：不可逆预算的核心是「给回不去的那一步留多少」。

**引理 36（权限不可补偿与风险单调）** 故障使 B(h) 退化、𝒯(h) 收缩 ⇒ α 关于严重度单调不增；α<α_min 时存在 τ_des∉𝒯(h)，任何有限 λ 都无法实现该指令 ⇒ λ_auth 必须为硬否决。系：不确定度可用保守换安全，权限不能。

**引理 37（模式切换瞬态证书保持）** 若 x∈V(h,m')、瞬态由备份控制器保 SafeSet、瞬态风险≤ε_switch、目标调度可认证，则切换全程风险 ≤ max(ε_switch, ε_res)。系：切换安全来自备份控制器 + 目标可生存集，不来自「切换瞬间估得准」。

**引理 38（故障转移仿真 ⇒ 安全单调）** d 为仿真关系且各级控制器在其不变量上有效 ⇒ 任意可达故障轨迹保持于 ⋃V(d_i)，沿 d 下降风险界单调不恶化。系：容错是可证明的仿真链，不是 if-else 分支堆叠。

**引理 39（重构本身必须可调度）** C(m')+C_rec ≤ δ_ctrl(m')，否则须分期重构（safe-point staging）并把每个中间态纳入认证。系：救火不能堵死消防通道。

**定理 27（严格包含与风险单调）** ℋ={nominal}、ℳ 单点、B(h)=I 时退化为 R72，逐指令等价；有效执行风险界 ≤ R72。安全单调不减。

**定理 28（J_RES 有效 ⇒ 故障下有界安全）** 在 A111–A116（H_cover 完整、FDI 审计通过、Δ_diag(k*)>Δ_min、α≥α_min、x∈V 或 x∈R、ρ_casc<1、ε_fac≤τ_fac）下，通过 J_RES ⇒ 对认证时域内所有可达 h∈H_cover，物理风险 ≤ ε_res。证明重量落在 H_cover 完备性与 FDI 诚实性。

**定理 29（诊断截止不可满足 ⇒ 必收缩或停机）** 引理 33 的运行时强制规则：Δ_diag≤Δ_min 对 ∀k≥1 ⇒ 必须 RECOVERY 或 R68。

**定理 30（级联稳定性）** 级联核谱半径 ρ(K)<1 ⇒ 故障传播期望总量有界（Neumann 级数收敛）；ρ(K)≥1 ⇒ 必须主动降额或 RECOVERY。

**定理 31（模式自动机 + 恢复集 ⇒ 无死锁/活锁）** Guard 在可生存集上完备、恢复控制器有定义、RECOVERY 最高优先级 ⇒ 无死锁；存在秩函数（模式偏序 + 到 V(nominal) 距离）沿恢复路径严格下降 ⇒ 无活锁。

## 7. 本轮最大风险

**一句话**：RESILIENT-GAUGE-RAS 把安全押在「**故障假设集 H 完备**、**FDI 诚实**、**健康势与级联核分布外可标定**」上——若出现未建模的新型多故障、被攻击者在诊断截止窗外触发的隐蔽退化、或把故障伪装成地形的对抗输入，而 H_cover 与 ECE_fault 仍显示一切正常，同时模式切换瞬态与重构吃掉 Δ_diag 裕度，系统就会拿着「所有故障都已覆盖、所有诊断都在有效域、所有权限账本都平衡」的盖章证书在真机上翻车——**对未建模故障的「自信地可容错」**。

次级风险与缓解：
1. **H 不完备** → 在线假设扩张 + SEAL-Fault 隐藏故障审计 + H_cover 不匹配拒绝发证。
2. **FDI 被掩蔽/投毒** → 跨通道证明 + 单源不定案 + FDI 自身 TCHAIN + 对抗审计。
3. **c/m/h 归因错误** → 非对称损失 + 主动诊断 + 高负载时默认按故障处理。
4. **健康预算错配** → CMDP + 恢复储备 B_reserve，禁止动用储备探索。
5. **故障级联** → 监测 ρ_casc，主动降额，负载转嫁入账。
6. **瞬态吃裕度** → 备份控制器 + 目标可生存集 + 分期重构 + 模式感知 RTA。
7. **sim2real 故障签名漂移** → 故障参数纳入 S2R-UQ + 实机故障注入 + 99.9% 分位。
8. **复杂度爆炸** → |ℳ|≤6、|ℋ|≤16、|D|≤6；层次化后验；复杂度入审计。
