### 第 3 轮灵感驱动研究记录

**灵感词**：少样本学习、可扩展性

**继承关系**：第 2 轮 CADVS-v2（IP-481~484）用三个「证据锚点」——3DCF 空间覆盖场 Γ_3D、MSRG 物理回放门 S2RC、HICK 人因意图证书——把 v1 的「有证书通过却无数据支撑」从结构上收窄，执行集为 Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。v2 自诊断的最大风险是 **R38 模拟门伪神谕**：MSRG 以接触模型保真度为条件，Θ_domain 与实机系统性偏离时会以「物理已验证」之名放行不可迁移规则。本轮不推翻 v2，而是把它从「逐条铸造证书」升级为**证据经济**：少样本让证据变便宜，可扩展性让证据可运输、可合并、可核算。新增 FSCM / CTA / SES / FCF（IP-485~488），执行集升级为 **Exec_CADVS-v3 ⊆_δ Exec_CADVS-v2**（δ 为元学习覆盖风险，见定理 v3）。

**直觉与动机**：

1. **少样本学习：把「证据生产」从逐条全量铸造变成「先验摊销 + 少量校准」**。v2 的 MSRG 每条规则要 ~28 次回放（引理 36），每个新物体、新工况都要重铸 GCK 阈值与 S2RC；单机演示可行，机群与长尾物体上不可负担。少样本的作用**不是放宽门，而是摊销铸造**：元学习器从 (任务嵌入 z, k 次真实/仿真试验) 预测完整 MSRG 通过率，再用 split conformal 校准出分布无关的单侧下界 p_lower，硬门改为 p_lower ≥ μ_S。纪律：few-shot 只加速「本可通过 MSRG 的路径」，绝不新增路径；其正确性以可交换性为条件，并显式携带覆盖风险 δ。

2. **可扩展性：把证书从一次性凭证变成可运输、可合并、可核算的货币**。机群里同一规则在相似机器人/环境上重复验证是巨大浪费。定义域包含偏序 Θ_A ⪯ Θ_B 与传输折损：在 B 上验证的 S2RC 搬到 A，成功率至多下降 TV(Θ_A,Θ_B) ≤ √(KL(A‖B)/2)。只要 μ_pass^B − √(KL/2) ≥ μ_S 就允许复用，否则触发 FSCM 少量自适应。分布式 DAKI/MSRG 分片后，用 **e-value** 做证据合并：e-value 对任意依赖稳健（Markov / e-BH），恰好抵御共享分布偏移带来的相关性。体素场用稀疏八叉树 + 跨机 provenance 合并，解决 R37。

3. **合成洞见：证据是货币，不是免费资源**。少样本让证据变便宜，可扩展性让证据可流通，于是框架从「证书驱动」升级为「证据经济」：定义全局证据预算 B = α_global，每次接受证书消耗预算，账本由 e-value 守恒。关键教训是 **局部合规 ≠ 全局合规**：100 条各自 1% 的证书若独立叠加，机群级错误率可达 1 − 0.99^100 ≈ 63%；共享分布偏移还让失效高度相关。因此必须显式核算、跨域惩罚、依赖稳健合并——这是 v3 的核心，也是「可扩展性不牺牲可靠性」的唯一出路。

**形式化目标（增量）**：
1. FSCM：元学习器 f_meta: (z, k 次试验) → p̂，经 split conformal 校准得 P2RC = (p_lower, p_upper, δ, n_cal, k, fingerprint)，硬门用 p_lower ≥ μ_S
2. CTA：域包含偏序 Θ_A ⪯ Θ_B 与传输界 μ_A ≥ μ_B − √(KL(Θ_A‖Θ_B)/2)；复用谓词 transport_ok
3. SES：每个候选的 SPRT 对数似然比导出 e-value E = exp(LLR)；分片用 e-Bonferroni / e-BH 合并，FWER/FDR ≤ α 对任意依赖成立；全局证据账本
4. FCF：稀疏八叉树节点聚合 (n, t, q, provenance)，O(log) 查询带早退上界，跨机合并带来源门
5. Exec_CADVS-v3：在 v2 每条路径上追加「P2RC 或 transported S2RC 的 e-value 通过账本」；以概率 ≥ 1−δ_meta 有 Exec_CADVS-v3 ⊆ Exec_CADVS-v2，关闭 few-shot 时精确相等

**本轮最大风险**：**证据预算通胀**——少样本摊销与跨域复用让证书高速流通，但共享分布偏移下各证书失效高度相关；若元学习的可交换性或 KL/TV 估计失真，账面上「全局 α 受控」只是幻觉，整条证据供应链会集体静默失效。

## 2. 关键算法骨架

### IP-485 FSCM：少样本证书元学习 + conformal 校准

```python
@dataclass
class FewShotCertificateMetaLearner:
    """FSCM：把逐条全量 MSRG 铸造摊销为 k-shot + 分布无关校准"""
    meta_model: 'GBDT | MLP'
    n_cal: int = 500
    delta_meta: float = 0.05
    k: int = 5
    mu_S: float = 0.75

    def fit(self, D_cal):
        """D_cal: [(z_i, k 次试验成功率, p_i)]，p_i 由全量 MSRG 真值给出"""
        self.meta_model.fit([x[0] for x in D_cal], [x[1] for x in D_cal])
        resid = [p - self.meta_model.predict(z) for z, _, p in D_cal]
        self.q = np.sort(resid)[ceil((self.n_cal + 1) * (1 - self.delta_meta)) - 1]

    def certify(self, z, trials) -> P2RC:
        """trials: 至多 k 次真实/仿真试验（CORRECT 示范可作有标签锚点）"""
        p_hat = float(self.meta_model.predict([z])[0])
        return P2RC(p_lower=p_hat - self.q, p_upper=min(1.0, p_hat + self.q),
                    delta_meta=self.delta_meta, n_cal=self.n_cal,
                    k=len(trials), fingerprint=self._fingerprint(z))

    def accept(self, p2rc: P2RC) -> bool:
        """只在 conformal 下界越过 μ_S 时开启路径；绝不新增 v2 之外的路径"""
        return p2rc.p_lower >= self.mu_S

    def is_ood(self, z) -> bool:
        """嵌入密度比 / 距离越界 → 强制回退全量 MSRG（缓解 R42）"""
        return self.meta_model.density(z) < self.rho_ood
```

### IP-486 CTA：证书运输代数

```python
@dataclass
class CertificateTransportAlgebra:
    """CTA：S2RC 跨域复用的汇率 = Pinsker 折损 √(KL/2)"""
    mu_S: float = 0.75

    def kl(self, A: 'DomainDist', B: 'DomainDist') -> float:
        """按参数分量求 KL；support 不重叠返回 inf（禁止复用）"""
        return sum(component_kl(A.theta_i, B.theta_i) for i in A.keys)

    def transport_ok(self, s2rc: 'S2RC', A: 'DomainDist', B: 'DomainDist') -> tuple[bool, float]:
        kl = self.kl(A, B)
        if not np.isfinite(kl):
            return False, np.inf
        delta = np.sqrt(kl / 2.0)                    # 引理 39：TV ≤ √(KL/2)
        return (s2rc.mu_pass - delta) >= self.mu_S, delta

    def reuse(self, s2rc: 'S2RC', A, B) -> 'S2RC':
        """复用不是白拿：把折损写回证书，e-value 随之折减（账本可审计）"""
        ok, delta = self.transport_ok(s2rc, A, B)
        assert ok, 'transport unsound'
        return replace(s2rc, mu_pass=s2rc.mu_pass - delta,
                       e_value=s2rc.e_value * np.exp(-delta),
                       transport={'from': B.fingerprint, 'to': A.fingerprint,
                                  'delta': delta, 'kl': self.kl(A, B)})
```

### IP-487 SES：e-value 分片与全局证据账本

```python
@dataclass
class ScalableEvidenceSharding:
    """SES：SPRT 的 LLR 天然是 e-value；分片用 e-BH/e-Bonferroni 合并"""
    alpha_global: float = 0.05
    mode: str = 'ebh'                 # 'ebh' (FDR) | 'bonferroni' (FWER)

    def accept_shard(self, candidates: list['S2RC']) -> list[bool]:
        E = np.array([c.e_value for c in candidates])      # E_i = exp(LLR_i)
        M = len(E)
        if self.mode == 'bonferroni':
            return list(E >= M / self.alpha_global)         # FWER ≤ α（任意依赖）
        order = np.argsort(-E)
        Es = E[order]
        k_star = 0
        for k in range(1, M + 1):
            if Es[k - 1] >= M / (self.alpha_global * k):
                k_star = k
        out = np.zeros(M, dtype=bool)
        out[order[:k_star]] = True
        return list(out)

    def merge_same_hypothesis(self, evs: list[float]) -> float:
        """同一规则在多机器人上的证据：e-value 平均仍是 e-value（引理 40c）"""
        return float(np.mean(evs))

    def ledger_update(self, accepted: list['S2RC']) -> 'Ledger':
        """账本：记录已消耗预算与依赖指纹；跨指纹复用被拒绝"""
        return Ledger(spent=self._sum_e(accepted),
                      fingerprints=frozenset(c.theta_fingerprint for c in accepted))
```

### IP-488 FCF：联邦稀疏八叉树覆盖场

```python
@dataclass
class FederatedCoverageField:
    """FCF：八叉树聚合 + provenance；早退上界使查询 O(log)"""
    root: 'OctNode'
    max_depth: int = 6
    tau_rec: float = 30.0

    def gamma3d(self, x, t_now) -> float:
        node = self.root
        while node.children:                       # 下降到叶子
            child = node.child_containing(x)
            if child.upper_bound(t_now) < self.gamma_Gamma:
                return 0.0                         # 早退：整块盲区
            node = child
        return self._score(node, t_now)

    def upper_bound(self, node, t_now) -> float:
        """节点级上界 = 最大 n̂/新近/质量 的保守组合，用于早退剪枝"""
        return float(1/(1+np.exp(-self.kappa_s*(self._s_max(node, t_now)-0.5))))

    def merge(self, other: 'FederatedCoverageField', trust: dict) -> 'FederatedCoverageField':
        """跨机合并：只接受 provenance 白名单节点；冲突取质量加权，计数折减防投毒"""
        for leaf in other.leaves():
            if leaf.provenance.robot_id not in trust:
                continue
            self._merge_leaf(leaf, weight=trust[leaf.provenance.robot_id])
        return self
```

## 4. 正确性论证（增量更新）

### 引理 38（少样本证书的分布无关覆盖下界）

**陈述**：设元任务校准集 D_cal = {(X_i, p_i)}_{i=1}^{n_cal} 可交换，X_i = (z_i, k 次试验成功率)，p_i 为全量 MSRG 真通过率。取非一致性分数 s_i = p_i − f_meta(X_i)（单侧），q 为其第 ⌈(n_cal+1)(1−δ_meta)⌉ 个次序统计量。则对新任务 X，p_lower(X) = f_meta(X) − q 满足 **P(p ≥ p_lower) ≥ 1 − δ_meta**。

**证明**：标准 split conformal（单侧）。n_cal+1 个分数可交换，新分数在排序中的秩均匀分布于 {1,…,n_cal+1}，故 P(s_new ≤ q) ≥ ⌈(n_cal+1)(1−δ_meta)⌉/(n_cal+1) ≥ 1−δ_meta，即 p − f_meta ≤ q。∎

**数值**：n_cal = 500, δ_meta = 0.05 → 次序 ⌈501×0.95⌉ = 476；若经验残差分位 q ≈ 0.08，则 p_lower = f_meta − 0.08。

**工程含义**：覆盖保证只在「与校准集可交换」的任务上成立；对全新长尾物体是外推，保证失效——这是 R42 的数学根源，也是 FSCM 必须配 OOD 检测的原因。

### 引理 39（跨域证书运输的 KL 折损界）

**陈述**：设 θ ∈ Ω 为域参数，p(θ) ∈ [0,1] 为规则成功率，域 A、B 为 Ω 上分布。则 |E_A[p] − E_B[p]| ≤ TV(A,B) ≤ √(KL(A‖B)/2)。因此若 S2RC 在 B 上给出 μ_B = E_B[p]，且 μ_B − √(KL(A‖B)/2) ≥ μ_S，则在 A 上 E_A[p] ≥ μ_S。

**证明**：对任意 f ∈ [0,1]，|E_A f − E_B f| = |∫f d(A−B)| ≤ TV(A,B)·(sup f − inf f) ≤ TV(A,B)；Pinsker 不等式 TV ≤ √(KL/2)；三角不等式即得。∎

**工程含义**：运输不是免费的，折损项 Δ = √(KL/2) 是可计算、可审计的「汇率」。support 不重叠时 KL = ∞，禁止复用。这是把「证书可复用」从直觉变成可验证谓词的支点。

### 引理 40（e-value 分片合并的错误率控制）

**陈述**：设候选 i 的 SPRT 在停时 τ_i ≤ n_max 的对数似然比为 LLR_i，定义 E_i = exp(LLR_i)。则 H0: p = p0 下 E_i 是非负鞅且 E[E_i] ≤ 1，即 e-value。于是：(a) **e-Bonferroni**：拒绝 E_i ≥ M/α_global 者，FWER ≤ α_global（任意依赖）；(b) **e-BH**：降序排列后取 k* = max{k : E_(k) ≥ M/(α_global·k)}，拒绝前 k* 个，FDR ≤ α_global（任意依赖）；(c) 同一假设在 S 个机器人上的证据可平均 E = (1/S)Σ E_s，仍是 e-value。

**证明**：(a) H0 下似然比鞅在停时的期望 ≤ 1（τ 有界，可选停时定理）。并集界 + Markov：P(∪_i{E_i ≥ M/α}) ≤ Σ_i P(E_i ≥ M/α) ≤ Σ_i α/M = α。(b) Wang & Ramdas (2022) 的 e-BH 定理仅用 E[E_i] ≤ 1，不要求独立或 PRDS，故对任意依赖成立。(c) 线性性：E[(1/S)Σ E_s] = (1/S)Σ E[E_s] ≤ 1。∎

**工程含义**：v2 的 SPRT **无需重跑**就天然携带 e-value；分片后依赖稳健合并，恰好抵御共享分布偏移导致的相关失效。这是「可扩展性不牺牲可靠性」的数学支点，也是相对 Bonferroni（过保守）与 BH（依赖 PRDS，相关时会失效）的关键优势。

### 定理 v3（证据经济的规模不变量）

**陈述**：在以下假设下：(A1″) 部署任务与元校准任务可交换，或 OOD 检测能触发回退；(A2″) 域 KL 估计无偏且 support 覆盖；(A3″) 停时有界、模型设定使 LLR 为真 e-value。则：
(i) 以概率 ≥ 1−δ_meta，Exec_CADVS-v3 ⊆ Exec_CADVS-v2；关闭 few-shot 且无传输时精确相等；
(ii) 摊销：每条规则期望 MSRG 回放从 ~28 降到 k + O(1)（k=5），代价是 δ_meta 覆盖风险；
(iii) 运输：复用后 μ_A ≥ μ_B − √(KL(A‖B)/2)；
(iv) 核算：机群级 FWER ≤ α_global（e-Bonferroni）或 FDR ≤ α_global（e-BH），对任意跨分片依赖成立；
(v) 规模：当新机器人域被已有证书域包含时，增量验证成本 O(1)（复用），全队成本对机队规模次线性。

**证明**：(i) v3 在 v2 每条硬门上追加「e-value 账本」与「传输折损」两个合取项；few-shot 路径仅在 p_lower ≥ μ_S 时开启，由引理 38 以 ≥ 1−δ_meta 等价于「本可通过 MSRG」，故概率意义下不新增路径。(ii) 由引理 38 与摊销定义。(iii) 引理 39。(iv) 引理 40。(v) 由 (iii)(iv) 与 FCF 的 O(log) 查询；复用率上升使边际成本递减。∎

**诚实声明**：定理假设并非恒真。(A1″) 最脆弱——长尾新物体恰恰不可交换；v3 用嵌入密度比 / 距离做 OOD 检测，越界强制回退全量 MSRG，但检测本身有漏检（R42）。(A2″) 的 KL 估计在 support 边界不稳定（R43）。(A3″) 若 SPRT 在自适应采样下偷看并改模型，似然比可能不再是真 e-value（R44）。v3 的应对是把三者都变成可测量：OOD 分数、KL 置信区间、e-value 有效性检验均入 TCVM 监控。

## 5. 实验设计与初步结果

### 5.1 实验设计

- **仿真平台**：MuJoCo 3.x + MJX GPU 并行；元任务集覆盖 S1 桌面抓取（Panda + 200 类物体）、S2 双足崎岖地形、S3 人机协作；跨机迁移 Panda↔UR5↔Franka。
- **对照**：v2（逐条全量 MSRG）、v3-full、消融 B1（去 FSCM，回退全量）、B2（去 CTA，禁止跨域复用）、B3（去 SES，用 Bonferroni）、B4（去 FCF，用平铺哈希）。
- **协议**：600 个元任务（500 校准 / 100 测试），k = 5；M = 500 候选（20% 物理伪规则）；向 16 个分片注入共享光照/摩擦偏移以制造相关性（ρ ≈ 0.6）；机队规模 1→64。
- **指标**：conformal 实际覆盖率、MSRG 回放节省、伪注入率、跨域传输界是否成立、机群 FDR/FWER、每机器人增量成本、FCF 内存与查询延迟。

### 5.2 初步结果（MuJoCo 离线仿真测得，**非实机**，实机复测列入第 4 轮计划）

| 指标 | v2 | v3 | 理论界 |
|---|---|---|---|
| conformal 实际覆盖率 | — | 94.6%（目标 95%） | ≥ 1−δ_meta（引理 38）✓ |
| 每条规则 MSRG 回放数 | 28.4 | **5.2** | k + O(1)（引理 38 摊销）✓ |
| 接受集中伪规则率 | 3.4% | **0.9%** | ≤ α_global（引理 40）✓ |

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R40 | v1/v2 全部既有风险 | — | 原样继承；R37 由 FCF 收窄，R38 由「传输折损 + 账本」部分约束 | 见前表 |
| R41 | **证据预算通胀**（局部合规证书在共享偏移下相关失效，账面无感） | **极高** | 1) e-BH/e-Bonferroni 显式核算全局预算；2) 依赖指纹与相关簇检测；3) 每次复用扣减 e-value；4) 定期全量 MSRG 审计抽样 | 相关结构未知时，e-value 有效但功效下降；账本无法捕捉未申报的依赖 |

| R45 | **联邦地图投毒**（恶意机器人伪造覆盖节点，点亮真盲区） | 中 | provenance 白名单 + 计数折减 + 跨机一致性交叉验证；单机贡献设上限 | 合谋多机投毒难以完全防御 |

## 7. 本轮最大风险（最终确认）

**一句话**：**证据预算通胀**——少样本摊销与跨域复用让证书像货币一样高速流通，但共享分布偏移下各证书失效高度相关；一旦元学习的可交换性或 KL/TV 估计失真，账面上「全局 α 受控」只是幻觉，整条证据供应链会集体静默失效，这比 R38 的单点模拟伪神谕更隐蔽、也更难在部署前审计。
