# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「UniBot世界挑战赛」×「云端协同」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**有界委托 + 时效封印 + 准入裁判**。两个灵感分别治理 v9 的两种债：**泛化债**（证书、阈值、块长只为单机单域调参，无法在挑战赛的异构任务/对手/实体下免调迁移）与**分布债**（v9 假设全模块本地同步；云卸载引入异步、陈旧、乱序、分区与投毒，可能悄悄破坏"中立元退化逐位等价"）。铁律：**云只做可撤销增强，边只保留不可撤销安全**——任何云端产物失效、过期、乱序或作恶时，边缘严格退回 v9。

## 0. 直觉与动机

**灵感 1（UniBot世界挑战赛 → 标准化准入裁判）**
直觉：挑战赛的本质不是"跑通一个任务"，而是"在异构任务、异构对手、异构实体、可复现评分下，证明系统没有偷偷调参"。v9 的 14 个 IP 与 5 级退化链是为单机单域手调的；直接上赛会撞上三重压力：任务分布切换令证书阈值失效、跨实体技能迁移没有验收、评分不可复现令增益无法归因。核心创新：**UniBot 准入裁判（UniBotChallengeAdmission, UCA）**——把"新技能/新契约上线"从"改代码"变成"过准入"：对新候选做 N 个**配对影子回合**，用成功率 Wilson 下界与安全违背 Wilson 上界给出统计证书，只有"下界不劣于当前、违背上界 ≤ ε"才放行，否则回滚为中立元；候选多于一个时用 Holm–Bonferroni 控制族错误率。挑战配置（Profile）声明任务族、对手强度、评分权重、随机种子与日志模式，使评分可确定性重放。

**灵感 2（云端协同 → 有界委托的两平面）**
直觉：云端能提供更强的前向模型、全局地图与跨回合经验；但云延迟不可控、会分区、可能被污染。若让云进入安全闭环，v9"最需要安全时证书最不可靠"的风险会被放大。关键洞察：**不必信任云，只要限制云能造成的最大损失**。把证书拆成**边缘地板** `Ĉ^E`（保守、实时、模型无关，预留 ρ 余量）与**云端增益** `ΔĈ`（重模型，被裁剪到 `[0,ρ]`）。云最多花掉边缘主动透支的 ρ；即使云完全错误或作恶，有效证书仍不超过边缘自己的 sound 界。核心创新：**云边中介（CloudEdgeBroker, CEB）+ 有界委托证书（Bounded-Delegation Certificate）**：边缘安全平面永不阻塞等待云，云平面只发"建议"；建议晚到即丢弃、旧版本即拒绝、旧纪元即作废。

**灵感 3（综合 → 可审计增益链）**
直觉：挑战赛要"公平可复现"，云边要"信任可验证"，两者是同一个问题——**每一分增益都必须有可重放的证据**。核心创新：**可审计增益账本（AuditableGainLedger, AGL）**：云产出（技能/证书/契约）必须携带时效封印 `σ=(版本,签发时戳,TTL,信任纪元,证据包哈希,签名)`，边缘与裁判都能离线重放证据包（准入日志 + 证书差量 + 环境种子 + 代码哈希），只有证据链验证通过，增益才计入成绩。由此"云端贡献"从论文叙事升级为可审计事实，同时天然抵抗投毒、重放与刷分。

## 1. 研究问题（轮次升级版）

- **Q1（有界委托安全）**：在 `‖ΔĈ‖∞ ≤ ρ` 的委托半径下，如何构造边缘地板使安全性对云端正确性**完全免疫**？ρ 与 v9 引理 82 的 β 余量如何联合预算，才能在"云无用"时不失效、在"云有用"时真正释放块长？
- **Q2（时效与分区退化）**：如何用封印、版本单调与信任纪元，使陈旧、乱序、分区、重放的云建议精确退化为"无建议"，并证明退化结果落在 v9 安全集内？
- **Q3（准入统计）**：影子准入需要多少回合 N 才能在给定置信度下保证"接受即不劣"？多 Profile、多候选下如何控制多重比较导致的假阳性放行？配对设计能否显著降低 N？
- **Q4（可审计性）**：如何用最小证据包让第三方裁判100%重放云端增益，且证据包不可伪造、不可重放、不可选择性遗漏？

## 2. 设计原则（在 P10–P12 基础上新增 P16–P18）

**P16 有界委托律（Bounded Delegation, CEB）**
证书按"单调乐观方向"拆分。间隙类（越大越安全）：`g_eff = g_E − ρ + clip(δ_g, 0, ρ)`；能耗类（越小越安全）：`e_eff = e_E + ρ − clip(δ_e, 0, ρ)`；抓取有效性取合取 `γ_eff = γ_E ∧ γ_cloud`（边缘判无效则不可被云翻案）。**恒等式**：只要 `g_E ≤ g_true ≤ e_E` 的 sound 性成立，则对任意云端输出（含错误/恶意）都有 `g_eff ≤ g_true`、`e_eff ≥ e_true`。云只能在边缘透支的 ρ 内"补回"保守性，永不越界。部署期约束 `ρ + β_floor ≤ g_E − d_safe`，否则强制 `K_eff=1`。

**P17 时效封印律（Ephemeral Seal, ESC）**
云建议 ω 必须带封印 `σ_ω=(v,τ_issue,TTL,e,H)`。边缘谓词 `fresh(ω,t)=SigOK ∧ (t−τ_issue≤TTL) ∧ (v≥v_seen) ∧ (e=e_cur) ∧ H(evidence)=H`。任一不满足 ⇒ ω 整体视为**中立元**（`δ=0`），不阻塞边缘周期。乱序由版本单调拒绝，分区由 TTL 到期自动退化，云被攻陷由 `e←e+1` 使全部旧封印立即作废。

**P18 准入不劣律（Admission Non-Degradation, UCA）**
新技能/新契约 h′ 只有在对同一 Profile、同一批配对种子影子执行 N 回合后，满足 `L_N(succ′) ≥ L_N(succ_cur)` 且 `U_N(viol′) ≤ ε`（Wilson 界），且经 Holm 校正后显著，才被接纳；否则回滚（等价"从未发生"）。准入只改变"用哪个已本地可执行的策略"，不改变安全地板。

## 3. 与基线的接口（如何退化）

- **AGL 失效** ⇒ 控制与安全不变，仅增益不计分，运行态等价 v9；
- **UCA 失效** ⇒ 拒绝一切新技能准入、冻结当前已准入策略，等价 v9（不接纳＝无变化）；
- **CEB/ESC 失效（封印无效/过期/分区/旧纪元/乱序）** ⇒ `δ≡0`，有效证书退 `Ĉ^E⊖ρ`；`ρ=0` 时逐位等价 v9，`ρ>0` 时为 v9 安全集的保守子集（K 更短但不失效），主环零阻塞；
- **边缘地板不可算（grasp 未知 / 状态不可观测）** ⇒ `K_eff←1`，退 v9 逐步决策粒度；
- **v9 ACMD 失效** ⇒ `K_eff←1` + MW 网关，退 v8；
- **v8 的 DA/SPR/Cal 任一失效** ⇒ 中立元注入，退 v7；全失效退 v6。

## 4. 预期贡献

1. **有界委托证书**：把"是否信任云"转化为"分配多少可透支安全余量 ρ"的风险预算问题；安全性对云端正确性免疫（引理 87），是 v9 最大风险的结构性修复；
2. **时效封印 + 两平面实时调度**：云端延迟/分区/乱序/旧纪元一律不进入安全闭环，退化精确落入 v9 安全集（引理 88）；
3. **统计准入裁判**：把技能上线变成可预注册的配对假设检验，Holm 控制族错误率，杜绝"为刷分放宽安全"（引理 89）；
4. **可审计增益链**：增益=可重放证据，兼顾挑战赛公平、云边信任与抗投毒/抗重放（引理 90）；
5. **Profile 泛化与实时守恒**：安全地板跨挑战配置不变（引理 92），云延迟被 5Hz 块边界隐藏，边缘 WCET 仅 +0.1ms（引理 91）；
6. **E571–E590** 覆盖委托半径预算、地板 soundness 压力测试、分区/陈旧/重放、对抗投毒、准入功效与多重比较、跨实体迁移、可审计重放与端到端竞赛。

## 5. 本轮最大风险

**一句话**：有界委托的安全性完全押在"边缘地板 `Ĉ^E` 确实是对真实值的 sound 下界"这一假设上——而它为了 ≤0.3ms 只能用粗粒度最坏界（忽略转向可逃逸性、动态障碍与传感器共因失效）；若地板本身在动态/对抗场景下不 sound，ρ 只是把不安全**伪装成"有界"**，云边协同反而会以"合法增益"的名义花掉本应用于安全的余量。即「把安全押在一个从未被在线校验的地板假设上」。

**新增定义 540（挑战配置 ChallengeProfile）**
`P=(T,O,W,S,L)`。`T` 为任务族（导航/抓取/操作/协同等），`O` 为对手或环境难度参数，`W` 为评分权重，`S` 为配对随机种子集，`L` 为裁判可读日志模式。评分函数 `Score(P, trajectory)` 只读取 `L` 模式记录与固定种子，故**可确定性重放**；任何未落入 `L` 的私有状态不得参与计分。

**新增定义 541（边缘地板证书 EdgeFloorCertificate）**
由模型无关的最坏界在 ≤0.3ms 内算出：
```
g_E = dist_min(s, O) − v_max·K_max·Δt − ε_sensor
e_E = e_max_act                  （执行器/能耗上界，常量标定）
γ_E = [grasp_conf ≥ θ_g ∧ ¬fault]     （保守：未知即无效）
```
其中 `dist_min` 为当前可观测障碍距离，`v_max·K_max·Δt` 为块时域内可达路径长度上界，`ε_sensor` 为传感器不确定界。**sound 性约定**：在静态/可膨胀动态障碍与有界传感器误差下，`g_E ≤ g_true`、`e_E ≥ e_true`。该约定是 v10 唯一的硬假设，由 E572 在线压力测试持续校验。

**新增定义 542（有界委托证书 BoundedDelegationCertificate）**
给定边缘地板 `Ĉ^E`、委托半径 `ρ` 与云增益 `δ`，逐分量定义：
```
g_eff = g_E − ρ + clip(δ_g, 0, ρ)
e_eff = e_E + ρ − clip(δ_e, 0, ρ)
γ_eff = γ_E ∧ (δ_γ = valid)
```
**核心恒等式**：若 `g_E ≤ g_true` 且 `e_E ≥ e_true`，则对任意 `δ`（含越界、错误、恶意）都有 `g_eff ≤ g_true`、`e_eff ≥ e_true`。云只能在 ρ 内把边缘透支的保守性补回，**永不越过边缘 sound 界**。部署期要求 `ρ+β_floor ≤ g_E−d_safe`；不满足则 `K_eff=1`。

**新增定义 543（时效封印 EphemeralSeal）**
```
σ_ω = (v, τ_issue, TTL, e, H(B), sig)
```
`v` 版本号单调递增，`τ_issue` 签发时戳，`TTL` 有效期，`e` 签发时信任纪元，`H(B)` 证据包哈希，`sig` 云私钥签名。任何字段被改动都会使 `H` 或 `sig` 校验失败。

**新增定义 544（信任纪元与新鲜性 Freshness）**
```
fresh(ω,t) = SigOK(ω) ∧ (t−τ_issue ≤ TTL) ∧ (v ≥ v_seen)
             ∧ (e = e_cur) ∧ (H(B) = σ.H)
```
云被攻陷或契约清单更新时 `e ← e+1`，全部旧封印立即作废。`fresh=false` ⇒ `ω ≡ δ^⊥`（中立元），整体丢弃且**不阻塞**边缘周期。

**新增定义 545（云边中介 CloudEdgeBroker）**
两平面：
- **边缘安全平面**（硬实时）：运行 v9 主闭环 + AC 中块守卫，每周期只做 `O(1)` 的 `ingest/uplift`，**从不等待云**；
- **云平面**（尽力而为）：异步计算强前向模型、全局地图与跨回合经验，发布带封印的建议。
建议必须在块边界前到达；晚到即丢弃（中立元）。合并规则：取版本最大者；同版本取先到者（幂等）。

**新增定义 546（影子准入 ShadowAdmission 与准入证书）**
对候选策略/契约 `h′` 与当前 `h_cur`，在同一 Profile `P`、同一批配对种子 `S_N` 上各跑 N 回合，记成功数 `succ`、安全违背数 `viol`。计算 Wilson 下界 `L_N`、上界 `U_N`。**接纳判据**：
```
accept(h′) ⇔ L_N(succ′,N) ≥ L_N(succ_cur,N)
             ∧ U_N(viol′,N) ≤ ε
             ∧ Holm 校正后仍显著
```
准入证书 `A=(P_id,N,S_N 承诺, ŝ′,ŝ_cur,L,U,α,verdict)` 全量可重放。拒绝 ⇒ 回滚为中立元，"从未发生"。

**新增定义 547（可审计增益账本 AuditableGainLedger）**
追加式哈希链，记录
```
r_i = (i, prev=H(r_{i−1}), P_id, σ, H(B), Δscore)
```
验证器 `verify(Ledger, replay_fn)` 逐条检查：哈希链连续、封印有效、`replay_fn(r_i)=Δscore`。**只有验证通过的记录才计入挑战排行榜**。`Δscore` 必须由"已准入建议 + 合法封印"产生，否则视为无效增益。

**新增定义 548（云建议格与中立元 Advisory Lattice）**
建议状态 `(v,δ)` 在合并下构成有界 join-半格：合并取 `max(v)`，`δ` 逐分量裁剪；`δ^⊥=0`（`v=−∞`）为中立元。`fresh=false` 映射为 `δ^⊥`。版本单调保证有限时间内无振荡（无 Zeno）。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9：`M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM)` 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承 v9；`τᵢ(t)` 在 `K_eff>1` 时以有效证书 `Ĉ` 替代逐层逐步复核。
**升级定义 533（块证书，v10）** 证书来源改为 `Ĉ=(Ĉ^E⊖ρ)⊕δ`；当云不可用时 `Ĉ=Ĉ^E⊖ρ`，仍为 sound 界，仅更保守（引理 87/88）。
**升级定义 539（有效块长，v10）** `K_eff` 由**有效证书**而非云增益直接驱动：
```
K_eff(t) = 1                                   若 Ĉ 无效或 U_t 不成立
         = max(1, ⌊K_max·(1 − min(1, Δ_dom/τ_dom))⌋)   否则
```
云增益只通过"能否让 `g_eff` 继续满足证书"间接影响 `K_eff`，绝不绕过 M₀ 硬检查。
**升级定义 496（软证书，v10）** `δ_trigger` 五条件中的 `Ĉ_t valid` 一律解释为**有效证书**（含 ρ 侵蚀）；云增益缺失只是让 `Ĉ` 更保守，不会制造"软通过硬失效"的空洞。

def fresh(adv, now_ms, v_seen, epoch_cur, verify_key):
    s = adv.seal

            and now_ms - s.issued_ms <= s.ttl_ms

class CloudEdgeBroker:
    """IP-357：两平面。边缘每周期 O(1)，从不等待云。"""
    def __init__(self, rho, epoch_cur, verify_key):
        self.rho = rho
        self.epoch = epoch_cur
        self.verify_key = verify_key
        self.v_seen = -1
        self.latest = None                       # Advisory | None

    def ingest(self, adv, now_ms):               # 云线程调用，非阻塞
        if fresh(adv, now_ms, self.v_seen, self.epoch, self.verify_key):
            if self.latest is None or adv.seal.version > self.latest.seal.version:
                self.latest = adv
                self.v_seen = adv.seal.version

    def epoch_bump(self):                        # 云被攻陷/清单更新
        self.epoch += 1
        self.latest = None

    def _uplift(self, now_ms):
        if self.latest is None:
            return 0.0, 0.0                      # 中立元 δ^⊥
        s = self.latest.seal
        if now_ms - s.issued_ms > s.ttl_ms:      # 过期即中立元
            self.latest = None
            return 0.0, 0.0
        dg = min(max(self.latest.delta_g, 0.0), self.rho)
        de = min(max(self.latest.delta_e, 0.0), self.rho)
        return dg, de

    def effective_cert(self, cert_edge, now_ms):  # 定义 542
        dg, de = self._uplift(now_ms)
        g = cert_edge.g_E - self.rho + dg        # 恒 ≤ g_E ≤ g_true
        e = cert_edge.e_E + self.rho - de        # 恒 ≥ e_E ≥ e_true
        grasp = cert_edge.grasp_ok and (self.latest is not None
                                        and self.latest.delta_grasp)
        return EffectiveCert(g, e, grasp)


def wilson(k, n, z):
    if n == 0:
        return 0.0, 1.0
    p = k / n
    d = 1 + z * z / n
    c = (p + z * z / (2 * n)) / d
    h = z * math.sqrt(p * (1 - p) / n + z * z / (4 * n * n)) / d
    return max(0.0, c - h), min(1.0, c + h)


class UniBotAdmission:
    """IP-359：配对影子准入 + Wilson 界 + Holm 多重比较。"""
    def __init__(self, N=200, alpha=0.05, eps=0.01):
        self.N, self.alpha, self.eps = N, alpha, eps
        self.z = 1.96

    def _paired_stats(self, cand, cur, profile):
        sc = cc = vc = vcur = 0
        for seed in profile.seeds[:self.N]:
            s = profile.reset(seed)              # 同一初始状态
            r_c = rollout(cand, deepcopy(s))
            r_b = rollout(cur,  deepcopy(s))
            sc += int(r_c.success);  cc += int(r_c.violation)
            vc += int(r_b.success);  vcur += int(r_b.violation)
        return sc, cc, vc, vcur

    def evaluate(self, cand, cur, profile):
        sc, cc, vc, vcur = self._paired_stats(cand, cur, profile)
        L_c, _ = wilson(sc, self.N, self.z)
        L_b, _ = wilson(vc, self.N, self.z)
        _, U_c = wilson(cc, self.N, self.z)
        p_noninf = paired_bootstrap_pvalue(sc, vc)   # H0: succ' ≤ succ_cur
        accept = (L_c >= L_b) and (U_c <= self.eps)
        return AdmissionCert(profile.task, self.N, L_c, L_b, U_c,
                             p_noninf, accept)

    def admit_batch(self, cands, cur, profile):
        certs = [self.evaluate(c, cur, profile) for c in cands]
        pvals = [c.p_noninf for c in certs]
        order = sorted(range(len(pvals)), key=lambda i: pvals[i])
        for rank, i in enumerate(order):         # Holm–Bonferroni
            if pvals[i] > self.alpha / (len(pvals) - rank):
                certs[i].accept = False
        return certs


class AuditableGainLedger:
    """IP-360：追加式哈希链，增益必须可重放。"""
    def __init__(self):
        self.chain = []

    def head(self):
        return self.chain[-1].h if self.chain else "GENESIS"

    def append(self, profile_id, adv, admission, delta_score):
        prev = self.head()
        rec = LedgerRecord(len(self.chain), prev, profile_id, adv.seal,
                           adv.seal.evidence_hash, admission, delta_score)
        rec.h = sha256(repr(rec)).hexdigest()
        self.chain.append(rec)

    def verify(self, replay_fn):
        prev = "GENESIS"
        for rec in self.chain:
            if rec.prev != prev or not verify_seal(rec.seal):
                return False
            if replay_fn(rec) != rec.delta_score:   # 证据包重放
                return False
            prev = rec.h
        return True

## 4. 推导

**引理 87（有界委托安全 / 云正确性免疫）** 设边缘地板 sound：`g_E ≤ g_true`、`e_E ≥ e_true`。对任意云输出 `δ`（不要求 `δ∈[0,ρ]`，因为定义了裁剪），由定义 542：
```
g_eff = g_E − ρ + clip(δ_g,0,ρ) ≤ g_E − ρ + ρ = g_E ≤ g_true
e_eff = e_E + ρ − clip(δ_e,0,ρ) ≥ e_E + ρ − ρ = e_E ≥ e_true
```
故有效证书对**任意**云端行为（正确、错误、越界、恶意、NaN 被裁剪）仍 sound。云缺失时 `g_eff=g_E−ρ`，只是更保守。安全性不依赖云正确性。∎

**引理 88（封印/分区退化与 v9 安全集包含）** `fresh=false` ⇒ `δ=δ^⊥=0` ⇒ `Ĉ=Ĉ^E⊖ρ`。若 `ρ=0`，则 `Ĉ=Ĉ^E`，决策与 v9 逐位等价；若 `ρ>0`，则 `g_eff=g_E−ρ≤g_E`、`e_eff=e_E+ρ≥e_E`，有效证书比 v9 更保守，故 `K_eff` 单调不增，接受的动作集是 v9 接受集的子集。过期、乱序（`v<v_seen`）、旧纪元（`e≠e_cur`）、签名失败、分区（TTL 到期）都映射到 `fresh=false`。∎

**引理 89（准入统计保证）** 设影子回合与真实部署同分布、配对种子消除环境方差。Wilson 区间在置信水平 `1−α` 下覆盖真值。单候选时，接受一个真实更差的候选（成功率真值更低却 `L_N(succ′)≥L_N(succ_cur)`）的概率 ≤α。K 个候选经 Holm 校正后族错误率 FWER ≤α（Holm 的逐步拒绝性质）。安全违背判据 `U_N(viol′)≤ε` 给出"真实违背率 ≤ε"的单侧置信保证。故"接受即不劣"在统计意义下成立；配对比独立样本降低方差，从而降低所需 N。∎

**引理 90（可审计增益完整性与抗重放）** Ledger 每条记录绑定 `(P_id, σ.version, i, H(B))`，且 `σ` 含 `τ_issue/TTL/e`。验证器校验哈希链连续、签名有效、`replay_fn(r)=Δscore`。伪造需同时攻破哈希链、签名与重放函数；重放旧记录因 `i` 唯一与版本单调被拒；跨纪元重放因 `e=e_cur` 被拒；选择性遗漏会破坏 `prev` 链。故有效增益记录与真实发生一一对应。∎

**引理 91（实时守恒 / 非阻塞）** 边缘每周期仅调用 `ingest`（哈希/签名可摊销预校验）与 `_uplift`（两次比较），`O(1)`、≤0.1ms；所有云 I/O 在独立线程/进程，`effective_cert` 不等待网络。晚到建议在块边界被丢弃。故边缘最坏 WCET = v9 最坏 WCET + 0.1ms ≤ 20ms，50Hz 保持。∎

**引理 92（Profile 泛化安全不变）** 安全地板 `g_E,e_E` 只依赖实体最坏界与当前观测，不依赖任务族 `T`、对手 `O` 或权重 `W`；`W` 只进入评分与准入排序，`T,O` 只改变采样分布。在有界委托预算满足时，任意 Profile 下的单步安全界相同；准入只允许"成功率不劣"的替换。故跨 Profile 迁移不降低已证安全地板（在定义 541 的 sound 假设跨 Profile 成立的前提下）。∎

## 8. 本轮最大风险

**一句话**：有界委托的安全性完全押在"边缘地板 `Ĉ^E` 确实是对真实值的 sound 下界"这一假设上——而它为了 ≤0.3ms 只能用粗粒度最坏界（忽略转向可逃逸性、动态障碍与传感器共因失效）；若地板本身在动态/对抗场景下不 sound，ρ 只是把不安全**伪装成"有界"**，云边协同反而会以"合法增益"的名义花掉本应用于安全的余量。即「把安全押在一个从未被在线校验的地板假设上」。
