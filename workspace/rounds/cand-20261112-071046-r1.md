# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「状态隔离」×「跨物体泛化」）

> 第 57 轮把证据质量做到"少样本可校准、跨模态可对账、个性化有界"，但它默认所有证据与信念都住在同一张**共享黑板**上：元先验从全体区域摊销、模态可靠性 ρ_m 全局共享、操作者状态跨会话累积、地图单元彼此可见。共享带来样本效率，也带来**污染通道**——一个被冰面骗过的区域、一个被对抗性伪装过的物体、一次橡皮章确认，都可能沿共享状态悄悄改写远处的承诺；而"跨物体泛化"恰恰要求把状态从 A 搬到 B，这与隔离直接冲突。本轮两个灵感把这个冲突提升为设计公理：**状态隔离**把"谁能读/写哪一格状态"变成可审计的安全边界（原始观测与未证伪信念默认隔离，只有认证抽象可越界）；**跨物体泛化**把越界从"偷偷共享"变成"持证迁移"——只在迁移契约成立、迁移风险可定价、源状态无污染时，才把源物体的认证充分统计量作为目标物体的先验，且只允许 L0/L1。二者合流得到本轮命题：**"隔离可验证、泛化可定价、污染可回滚的证据说可信"**。

核心矛盾：
- **H32（隔离 vs 泛化）**：隔离越严，每个物体/区域可用的证据越少，退回第 57 轮之前的少样本饥饿；泛化越自由，一个被污染或对抗伪装的源物体就会污染整类目标。泛化本质上就是一次受控的隔离越界，必须同时给出"为什么可越界"（契约）与"越界错了怎么办"（污染预算+回滚）。
- **H33（同一性 vs 属性迁移）**：跨物体泛化先要回答"这两个物体算不算同类"，但物体同一性本身带熵：外观相同质量不同的"双胞胎"、遮挡后的重识别、类别后验的漂移，都会让"看起来像"变成"自信地传错"。身份不确定性必须显式进入迁移门，而不是被类别标签掩盖。
- **H34（回滚 vs 不可逆承诺）**：隔离让信念可回滚，但物理接触不可回滚——你可以撤销一个错误先验，撤不回一次已经发生的跌落。因此回滚必须发生在承诺**之前**：证书要携带完整 provenance 与依赖闭包，L2 承诺前必须证明依赖闭包 taint-free；否则"可回滚"只是事后的安慰。
- **H35（隔离开销 vs 实时控制）**：事务化状态、版本向量、依赖图与 taint 闭包都会进入控制回路；全量隔离可能把实时性预算吃光，最终逼部署者关掉隔离——安全机制不能以牺牲可用性为代价。

## 0. 直觉与动机

**灵感 1（状态隔离 → 状态防火墙，而不是共享黑板）**
直觉：机器人内部最危险的不是"没有状态"，而是"状态到处流"。把证据状态想成一栋大楼：原始观测是未消毒的样本，未证伪信念是可疑包裹，只有通过检验的抽象才能进入公共大厅。状态隔离给每个作用域（物体/区域/任务/操作者/模态/会话）发独立保险箱与版本号，所有读写经过一个**状态经纪人 broker**：读要声明用途，写要事务提交，跨作用域只能读"认证抽象"（充分统计量+区间+provenance），全局层只收聚合/DP/证书化摘要。这样，一个区域的坏信念默认**流不出去**；一旦发现污染，还能按依赖图精确回滚，而不是把整张地图推倒重来。关键不是"少共享"，而是**共享必须留下可审计的过境记录**。

**灵感 2（跨物体泛化 → 持证迁移，而不是盲目共享）**
直觉：泛化的经济学价值极高——见过 100 个杯子后，第 101 个杯子不该再从零探起。但"同类"是个概率命题，不是标签事实。跨物体泛化因此应写成一份**迁移契约**：源与目标同属一个可供性/机制簇（后验≥ρ_tr）、目标自身证据不足、源状态无污染、并且能给出迁移风险上界 ε_tr（分层贝叶斯 + 加权共形）。满足契约时只迁移**认证抽象**（如"质量 0.3±0.05 kg、易碎、摩擦中"），绝不迁移原始观测；目标自己的观测一旦与迁移先验冲突超过 θ_tr，契约立即证伪、撤销迁移、并回溯降低该物体类的可靠性 ρ_cls。泛化不是"相信相似"，而是"用可证伪的赌注换样本效率"。

**灵感 3（隔离 × 泛化 → 越界是一等公民，必须有护照）**
直觉：把两者对立起来是错的。隔离定义"默认不共享"，泛化定义"例外如何被批准"。真正需要的是**越界护照**：每条跨物体迁移边都记录 (源,目标,契约假设,ε_tr,时间,证据版本)，进入依赖图；任何证书都能回答"我依赖了哪些越界"。于是污染可以被精确定位：不是"整个系统不可信"，而是"这 7 张证书、这 3 个物体、这 1 条迁移边受影响"。隔离提供**定位精度**，泛化提供**样本效率**，依赖图把两者焊在一起。

**灵感 4（三机制合流 → 证据门新增"护照/污染"维度）**
直觉：第 57 轮五类证据门（EV-probe*/visit/margin/xmodal/human）在本轮全部要带三样东西：**作用域**（这条证据属于哪个物体/区域）、**隔离级**（I0 原始 / I1 受控 / I2 认证）、**provenance/taint**（它从哪来、是否被污染）。新增 **EV-transfer**（跨物体迁移证据），但它只配 L0/L1，永远不能进入不可逆接触的必要证据集；L2 的必要证据仍是 EV-probe*∨EV-margin 加佐证。击穿安全从"五层纵深"变成"七层"：元先验错 ∧ OOD 漏检 ∧ 跨模态无一致 ∧ 迁移契约错 ∧ 污染未被 taint 检出 ∧ 无裕度 ∧ 人也错。

**灵感 5（SIX → 隔离屏障与泛化检查点进入探-诺-演）**
直觉：探询不再只问"哪个探针信息量最大"，还要问"这次探针会不会把污染带过界""这次承诺依赖的迁移边是否已确认"。每个检查点插入两个新关卡：**泛化检查点**（是否可用 EV-transfer 省探针）与**隔离屏障**（承诺前依赖闭包是否 taint-free、L2 是否只依赖本地实证）。所有新机制仍只经两个安全通道起作用：让信念更准（含加宽）或让动作更保守；区别是这次多了一个**可回滚通道**——在承诺前把错误状态收回保险箱。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（状态隔离域 SID）** 状态空间 𝕊 分解为带作用域与隔离级的状态单元 c=(scope,key,ver,iso,prov)，scope∈{obj,region,task,op,modal,session,global}，iso∈{I0,I1,I2}（I0 原始/未证伪，I1 受控共享的认证抽象，I2 全局聚合/DP/证书化摘要）。所有读写经状态经纪人 𝔅：(read/write/derive,c,purpose,writer) 须过隔离策略 π_iso；写为事务 prepare→validate→commit/abort，提交时校验策略与依赖并更新版本向量 v(c)。隔离不变量：跨 scope 不得直接读 I0；I1/I2 只含"充分统计量+区间+provenance"；全局单元不得含原始观测。依赖图 G_dep 记录 (cell,writer,parents) 与迁移边。隔离级只允许单向提升 I0→I1→I2（提升需证书或聚合/DP 证明）。

**定义 140（物体中心状态 OCT）** 物体 o=(id,H_cat,θ_o,pose,aff_o,prov) 为一等状态实体；H_cat 为类别/可供性后验，θ_o=(μ,m,k,F_bear,fragility) 为物理属性后验。身份跟踪为多假设：id 可 merge/split/re-id，身份熵 H_id(o)=H(H_cat,id 分配) 显式；观测 e 经证据门后以似然更新 θ_o 与 H_cat，原始 e 存 I0，抽象属性存 I1，类别级统计存 I2。**身份门**：H_id(o)>θ_id ⇒ 禁止迁移、只允许本地探针；身份未定的观测进 pending(I0)，不参与任何跨物体先验。

**定义 141（迁移契约与跨物体泛化 XOG）** 迁移算子 T_{s→t} 把源 s 的 I1 认证抽象变为目标 t 的先验。契约 𝒯(s,t) 成立 ⇔ (i) 可供性/机制簇后验 ≥ρ_tr 且机制声明 M(s,t)（材质/几何/质量范围）一致；(ii) 目标证据不足 k_t<k\*(w\*)；(iii) 源 taint-free 且 H_id(s),H_id(t)≤θ_id；(iv) 迁移风险上界 ε_tr(α) 由分层贝叶斯+加权共形给出：ε_tr(α)=Quantile_{1−α}({w_j·res_j})，权重 w_j∝exp(−d(z_s,z_j)/h) 归一化，并计入加权交换性修正，覆盖率 ≥1−α−ε_w。满足时只传充分统计量/区间并写入 t.prov 与 G_dep 迁移边；目标观测与迁移先验冲突 B_tr=log[p(o_t|θ_t^{local})/p(o_t|θ_t^{tr})]>θ_tr ⇒ 契约证伪，撤销迁移并按类回溯 ρ_cls。

**定义 142（污染传播与回滚 TCB）** 依赖图 G_dep 连接状态单元/迁移边到证书与承诺。单元被证伪（新证据/OOD/对抗/人工）⇒ taint(c)=1，沿 G_dep 求 taint 闭包 τ(c)。未承诺证书：失效重算；已承诺动作：不可逆，标记受影响物体、隔离降档、触发保守再验证并记录。**回滚不变量**：任何 L2 不可逆承诺前，其依赖闭包必须 taint-free 且跨物体迁移边已显式确认；违反即拒绝承诺。污染预算 Σ_{e∈cross} ε_tr(e)≤B_contam，且 Σ ε_tr 计入 P_fail 上界。

**定义 143（状态隔离证据门 SIG，升级 FSE）** 证据带 (class,scope,iso,prov,taint)。类集扩展 EV-transfer（仅 L0/L1，须 𝒯 成立且 ε_tr 声明；不得进入不可逆接触必要证据集）；EV-probe\*/visit/margin/xmodal/human 仅在 taint-free 单元上有效，且 I0 原始证据不得直接支撑 L2。不可逆接触必要证据集={EV-probe\*∨EV-margin}∪佐证，不含 EV-transfer/EV-xmodal。证书 J_s=(J_p,isolation_log,object_id_log,transfer_log,taint_log,rollback_log)，继承 J_p 全检。

**定义 144（状态隔离探询算子 SIX / PCX++）** 每检查点：①对象定位与作用域解析（更新 H_id，决定隔离域）；②泛化检查点：若 𝒯(s,t) 成立且 ε_tr 可负担，则用 EV-transfer 初始化 t 的先验并记边；③探询：netVOI 含迁移价值，探针结果经 𝔅 写入对应 scope；④隔离屏障：承诺前求证书依赖闭包，要求 taint-free，L2 额外要求无 transfer/xmodal 边依赖；⑤承诺；⑥证伪则按 scope 回滚（τ 闭包）并重规划。四态与终止性继承 PCE+。

## 2. 关键算法伪代码（完整版见产物区）

```python
def broker_write(cell, value, writer, iso, prov, policy):
    if not policy.allows(cell, writer, iso): return abort('isolation')
    tx = begin(cell); tx.prepare(value, prov)
    if not validate(tx, policy): return abort('validate')
    commit(tx); cell.ver = bump(cell.ver, writer)
    dep_graph.add(cell, prov.parents); return ok

def object_update(objs, e, gate):
    ids = identity_hypotheses(objs, e)          # merge/split/re-id
    o = argmax(ids, key=posterior); o.H_id = entropy(ids)
    if gate.reject(e) or o.H_id > theta_id: return objs
    o.theta = bayes_update(o.theta, e.like, w=e.w); o.H_cat = update_cat(o.H_cat, e)
    o.prov.append(e.id); return objs

def transfer(objs, t, gate):
    for s in sorted([x for x in objs if x.id != t.id], key=transfer_value, reverse=True):
        if not contract(s, t) or s.tainted or t.k >= kstar(t): continue
        eps = weighted_conformal_risk(s, t, alpha)
        if eps > theta_tr: continue
        t.theta = hier_prior(t.theta, certified_abstract(s), eps)
        dep_graph.add_edge(s, t, kind='transfer', eps=eps)
        t.prov.append(('transfer', s.id, eps)); return 'EV-transfer'
    return None

def taint_rollback(cell, dep_graph, certs):
    tau = dep_graph.closure(cell)
    for cert in certs:
        if cert.depends_on(tau):
            (quarantine(cert.objects) if cert.committed else cert.invalidate())
    dep_graph.mark(tau); return tau
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SID | O(1)/访问 + O(\|dep\|) 校验 | O(\|cells\|·\|deps\|) | I0 不越界、审计完备（A41） |
| OCT | O(\|O\|·\|H_id\|)/更新 | O(\|O\|·d_θ) | 身份熵校准、merge/split 可回溯 |
| XOG | O(\|S\|·d)+O(N_cal) | O(\|S\|·d) | 契约诚实、ε_tr 覆盖（A42） |
| TCB | O(\|V_dep\|+\|E_dep\|)/闭包 | O(\|G_dep\|) | taint 闭包完整（A43） |
| SIG | O(\|σ\|) | O(\|σ\|) | 无护照即拒、L2 禁 transfer |
| SIX | O(\|CP\|·(k_p+k_c)·(C_VOI+d)+闭包) | O(\|V\|+\|σ\|+\|G_dep\|) | 屏障先于承诺、污染预算内终止 |

**正确性定理（Isolated-Generalized Soundness, IGS 概要）**：在 A33–A40 上加 (A41) 状态隔离与 broker 审计完备；(A42) 物体身份与迁移契约诚实，ε_tr 为有效上界（加权共形覆盖 ≥1−α−ε_w）；(A43) taint 闭包完整（每条迁移边与证书依赖均入图）；(A44) 污染预算 Σ ε_tr≤B_contam 且计入失效界。则：(i) 承诺失效率 ≤ δ_f+ε_meta(k)+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+Σ_{e∈dep}ε_tr(e)+ε_id；(ii) 隔离-泛化单调性：隔离只减证据/增保守，泛化只经带 ε_tr 的 EV-transfer 且限 L0/L1，二者均无升险路径；(iii) 回滚有效性：承诺前依赖闭包 taint-free，未承诺证书遇污必失效，已承诺 L2 在承诺时无 transfer 依赖；(iv) SIX 在 k_p+k_c 内终止。

## 6. 本轮最大风险

**一句话**：本轮把安全押在"隔离边界与依赖图的记账完整性"上——只要有一条跨物体迁移边或状态依赖没被 provenance 记录，污染就会静默越过隔离、taint 闭包漏检，而证书看起来仍然干净；越是用跨物体泛化省探针，这条隐形边越致命，因此必须以"无 provenance 不证据、无依赖边不承诺、L2 永不接受迁移证据"为硬约束，并接受"隔离失败时宁可退回又慢又笨的本地探针"。

```python
def state_read(c, reader, purpose, policy, dep_graph):
    if not policy.read_allowed(c, reader, purpose):
        return abort('isolation_read')
    if c.iso == 'I0' and reader.scope != c.scope:
        return abort('raw_state_cross_scope')          # 原始观测不越界
    dep_graph.add_read(reader, c)                      # 读也留痕
    return certified_view(c) if c.iso in ('I1', 'I2') else c

def state_write(c, value, writer, iso, prov, policy, dep_graph):
    tx = begin(c)
    tx.prepare(value, prov, writer)
    if not policy.write_allowed(c, writer, iso):
        return abort('isolation_write')
    if not validate(tx, policy):                       # schema/taint/version
        return abort('validate')
    commit(tx)
    c.ver = bump(c.ver, writer)
    dep_graph.add(c, parents=prov.parents, writer=writer)
    audit.log(('write', c.key, writer, c.ver))
    return ok

def promote(c, target_iso, policy):                    # I0 -> I1 -> I2 单向
    if target_iso == 'I2' and not c.is_aggregated_or_dp():
        return abort('global_requires_dp')
    if target_iso == 'I1' and not has_certificate(c):
        return abort('no_cert')
    c.iso = max_iso(c.iso, target_iso)                 # 只升不降
    audit.log(('promote', c.key, c.iso))
    return c
```

### IP-140 OCT（物体中心状态与多假设身份跟踪）

```python
def identity_update(objs, e):
    hyps = [('keep', o, likelihood(o, e)) for o in objs]
    hyps += [('new', make_object(e), p_new(e))]
    hyps += [('merge', (a, b), p_merge(a, b, e)) for a, b in pairs(objs)]
    hyps += [('split', o, p_split(o, e)) for o in objs]
    H = normalize(hyps)
    for h in H:
        if h.op == 'merge': objs = merge(h.a, h.b)
        if h.op == 'split': objs = split(h.o)
    return objs, entropy(H)

def object_update(objs, e, gate):
    objs, H_id = identity_update(objs, e)
    o = argmax_object(objs, e)
    o.H_id = H_id[o.id]
    if gate.reject(e):
        return objs, o, 'rejected'
    if o.H_id > theta_id:
        o.pending.append(e)                            # 身份未定：进 I0，禁迁移
        return objs, o, 'identity_uncertain'
    o.theta = bayes_update(o.theta, e.like, w=e.w)
    o.H_cat = update_cat(o.H_cat, e)
    o.prov.append(e.id)
    state_write(o.cell('I1'), certified_abstract(o), 'oct', 'I1',
                prov=[e.id], policy=iso_policy, dep_graph=G_dep)
    return objs, o, 'ok'
```

### IP-141 XOG（跨物体泛化与迁移契约）

```python
def contract(s, t, meta):
    if t.k >= meta.kstar(t): return False              # 目标已够证据
    if s.tainted or t.tainted: return False            # 源/目标无污染
    if s.H_id > theta_id or t.H_id > theta_id: return False
    if kl(s.H_cat, t.H_cat) > meta.theta_cls: return False   # 同类/同可供性簇
    if not mechanism_compatible(s, t, meta.M): return False  # 材质/几何/质量范围
    return True

def transfer(objs, t, meta):
    for s in sorted(objs, key=lambda x: transfer_value(x, t), reverse=True):
        if s.id == t.id or not contract(s, t, meta):
            continue
        eps = weighted_conformal_risk(s, t, alpha)     # 分层+加权共形上界
        if eps > meta.theta_tr:
            continue
        prior = certified_abstract(s)                  # 只传 I1：充分统计量+区间
        t.theta = hier_prior(t.theta, prior, eps)
        t.prov.append(('transfer', s.id, eps, meta.M))
        dep_graph.add_edge(s, t, kind='transfer', eps=eps)
        audit.log(('transfer', s.id, t.id, eps))
        return 'EV-transfer', eps
    return None, 0.0

def conflict_check(t, e, meta):
    if loglik(e, t.theta_local) - loglik(e, t.theta_tr) > theta_tr:
        t.theta = t.theta_local                        # 撤销迁移，回本地先验
        dep_graph.remove_edges_into(t, kind='transfer')
        rho_cls(t.H_cat) *= gamma_down                 # 类可靠性回溯降级
        audit.log(('contract_falsified', t.id, e.id))
        return 'contract_falsified'
    return 'ok'
```

### IP-142 TCB（污染传播、隔离屏障与按 scope 回滚）

```python
def taint(cell, reason, dep_graph, certs):
    tau = dep_graph.closure(cell)                      # 沿依赖图求 taint 闭包
    for c in tau:
        c.tainted = True
    affected = []
    for cert in certs:
        if cert.depends_on(tau):
            if cert.committed:
                quarantine(cert.objects)
                cert.reverify = True                   # 不可逆：标记并再验证
            else:
                cert.invalidate()                      # 未承诺：直接失效重算
            affected.append(cert)
    audit.log(('taint', cell.key, reason, len(tau), len(affected)))
    return tau, affected

def isolation_barrier(cp, cert, dep_graph):
    closure = dep_graph.deps(cert)
    if any(c.tainted for c in closure):
        return False, 'tainted_dependency'
    if cp.level == 'L2':
        if any(e.kind in ('transfer', 'xmodal') for e in closure):
            return False, 'L2_requires_local_probe'    # 不可逆接触不吃迁移/一致证据
    if sum(e.eps for e in closure if e.kind == 'transfer') > B_contam:
        return False, 'contamination_budget'
    return True, 'ok'

def rollback_scope(cell, tau, objs):
    for o in objs:
        if o.scope == cell.scope or o.id in dep_graph.descendants(cell):
            o.theta = o.last_certified_snapshot()      # 回滚到隔离快照
            o.tainted = False
    audit.log(('rollback', cell.key, len(tau)))
    return objs
```

```python
def state_isolated_gate(c, M, persona, dep_graph, ood_reg):
    if not has_passport(c):
        return ('reject', 'no_provenance', c)          # 无护照不证据
    if c.tainted:
        return ('reject', 'tainted_evidence', c)
    if c.ev == 'EV-transfer':
        ok = c.level in ('L0', 'L1') and c.contract_ok and c.eps_tr <= theta_tr
        if not ok:
            return ('reject', 'transfer_invalid', c)
        if c.irreversible:
            return ('reject', 'transfer_on_irreversible', c)
        return ('ok', c)
    if c.ev == 'EV-probe*' and c.iso == 'I0' and c.level == 'L2':
        return ('reject', 'raw_probe_on_L2', c)
    if c.ev == 'EV-xmodal' and c.irreversible:
        return ('reject', 'xmodal_on_irreversible', c)
    if c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth)

        ok = round57_checks(c, M) and c.scope == c.cert_scope
    else:
        return ('reject', 'no_evidence_class', c)
    return ('ok', c) if ok else ('reject', 'evidence_insufficient', c)

def certificate_s(sched, logs, M, dep_graph):
```

```python
def state_isolated_probe_commit(x0, M, objs, task, budget, consent, personas):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        objs, o, id_st = object_update(objs, M.obs[cp.region], gate)
        ev_tr, eps = transfer(objs, o, meta) if id_st == 'ok' else (None, 0.0)
        sigma = foothold_schedule(x0, cp, M)
        R = schedule_risk(sigma, M)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)
            p = argmax(cands, key=lambda q: net_voi(q, M, objs, ev_tr) - cost(q))
            if net_voi(p, M, objs, ev_tr) < theta_voi:
                break
            e = execute_probe(p, cap=F_abs)
            state_write(cell_of(p), e, 'probe', 'I0', prov=[p.id],
                        policy=iso_policy, dep_graph=G_dep)
            M = xmodal_fuse(M, cp.region, e)[0]
            if conflict_check(o, e, meta) == 'contract_falsified':
                taint(o.cell, 'transfer_conflict', G_dep, certs)
            budget.spend(p)
        cert = build_certificate_s(cp, M, objs, G_dep)
        ok, why = isolation_barrier(cp, cert, G_dep)
        if not ok:
            return degrade_or_reverify(cp, objs, why, consent, personas)
        if state_isolated_gate(core_contact(cp), M, personas, G_dep,
                               ood_reg)[0] == 'ok':
            commit(sigma, select_gait(R), cert)
            continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt
            continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return route, objs
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SID | O(1)/访问 + O(\|dep\|) 校验 | O(\|cells\|·\|deps\|) | I0 不越界、事务原子、审计完备（A41） |
| OCT | O(\|O\|·\|H_id\|)/更新 | O(\|O\|·d_θ) | 身份熵校准、merge/split 可回溯 |
| XOG | O(\|S\|·d)+O(N_cal)/目标 | O(\|S\|·d) | 契约诚实、ε_tr 覆盖 ≥1−α−ε_w（A42） |
| TCB | O(\|V_dep\|+\|E_dep\|)/闭包 | O(\|G_dep\|) | taint 闭包完整、屏障先于承诺（A43） |
| SIG | O(\|σ\|) | O(\|σ\|) | 无护照即拒、EV-transfer 限 L0/L1 |
| SIX | O(\|CP\|·(k_p+k_c)·(C_VOI+d)+闭包) | O(\|V\|+\|σ\|+\|G_dep\|) | 屏障先于承诺、污染预算内终止 |

**正确性定理（Isolated-Generalized Soundness, IGS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；新增：
**(A41)** 状态隔离与 broker 审计完备：I0 不跨 scope 直读，I1/I2 只含认证抽象，所有读写与迁移边入 G_dep；
**(A42)** 物体身份与迁移契约诚实：H_id 校准、机制声明真实、ε_tr 为加权共形有效上界（覆盖 ≥1−α−ε_w）；
**(A43)** taint 闭包完整：证书依赖与迁移边无漏记，闭包传播正确；
**(A44)** 污染预算：Σ_{e∈cross} ε_tr(e) ≤ B_contam，且计入 P_fail。

则：

1. **隔离遏制**：污染单元的 taint 闭包之外，未承诺证书失效数为 0（除非存在漏记边，A43 排除）。
2. **泛化健全性**：承诺失效率 ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1] + Σ_{e∈dep} ε_tr(e) + ε_id，其中 ε_id 为身份错配未被 H_id 门拦截的概率。
3. **回滚有效性**：任何 L2 承诺在承诺时依赖闭包 taint-free 且无 transfer/xmodal 边；发现污染后未承诺证书 100% 失效，已承诺动作被标记并进入再验证。
4. **单调性**：SID 只可能减少可用证据或增加保守性；XOG 只经带 ε_tr 的 EV-transfer 且限 L0/L1 增加证据；不存在"隔离/泛化导致风险上升"的通道。
5. **终止性**：SIX 每检查点探针 ≤k_p+k_c，闭包计算有限，终止于 {承诺, 绕行, 降级再验证, L2 协商, 安全停}。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp [δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                   + δ_xm·1[L1] + Σ_{e∈dep(cp)} ε_tr(e) + ε_id]
          − P(G_dep 漏边) − P(隔离屏障失效) − P(τ_int ∧ 安全停失效)
```

关键：**隔离给定位精度**（污染只影响闭包内对象/证书）、**泛化给样本效率**（认证抽象+ε_tr 换探针）、**依赖图给回滚能力**（承诺前屏障、承诺后标记）；三者缺一不可。隔离不是目的，泛化也不是目的——**可审计的越界**才是本轮真正新增的安全对象。

其中新增：`iso_cells` 状态单元与隔离级；`H_id` 物体身份熵；`𝒯/ε_tr` 迁移契约与风险上界；`G_dep/taint` 依赖图与污染闭包；`J_s` 状态隔离-泛化证书；`rollback_state` 回滚快照与受影响集合。

云边协议 CEB++ → **CEB+++**：云端下发的元模型、类别级统计与迁移先验必须携带"隔离级标签 + 聚合/DP 证明 + 语料覆盖标签"，只能进 I2 或经影子隔离；边端回传**迁移证伪事件与 taint 记录**（而非原始观测），作为 ρ_cls 更新与语料补盲依据。第 57 轮"一切判定器（含元模型）走隔离"在本轮推广为"**一切状态读写走隔离，一切越界走护照**"；云端永远不能直接写边端的 I0/I1 单元。

## 6. 本轮最大风险

**一句话**：本轮把安全押在"隔离边界与依赖图的记账完整性"上——只要有一条跨物体迁移边或状态依赖没被 provenance 记录，污染就会静默越过隔离、taint 闭包漏检，而证书看起来仍然干净；越是用跨物体泛化省探针，这条隐形边越致命，因此必须以"无 provenance 不证据、无依赖边不承诺、L2 永不接受迁移证据"为硬约束，并接受"隔离失败时宁可退回又慢又笨的本地探针"。
