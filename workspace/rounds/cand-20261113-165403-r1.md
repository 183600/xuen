# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序闭环」IP-214~223；新一轮灵感循环第 1 轮；本轮灵感：「续航能力」×「演示数据」）

> 第 65 轮用视觉与动作分块把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**VISTA 依赖「故障属于有限假设集、且视觉与几何的失效相互独立」；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，于是 FIR 把未知复合故障强行归入最近假设、只膨胀错误的球——第 64 轮的单点故障升级为「归因错误的复合故障」，系统还因为「已经归因」而更自信地继续执行。** 本轮不再往假设集里加第五个感知模态，而是换两个更基础的问题：
>
> **(Q1) 系统里有没有「自带真值」的物理量，能绕过学习证据的共因失效？** 有——能量与功率：它们守恒、单调、可独立测量，且失效结构与视觉/几何不同。
> **(Q2) 我们凭什么相信「归因」这件事本身是可做的？** 只能凭数据覆盖：演示数据决定了哪些状态、哪些故障方向真的被观测过；覆盖之外必须诚实地「弃权」。
>
> 本轮核心命题：**用「能量接地」给归因一个独立物理旁证与硬预算，用「演示数据覆盖见证」给归因一个可证明的能力边界——能归因才归因，不能归因就明确弃权并保守降级，而不是强行归因。**

## 0. 直觉与动机

**灵感 1（续航能力 → 能量是自带真值的量，也是不可逆预算）**
直觉：第 65 轮的全部证据（视觉、力、几何、策略残差）都是「学习/标定出来的」，它们的错误可能相关。能量不一样：电池 SoC、母线电压、关节电流、功率是**直接测量**的物理量，且电池是**单调消耗**的。它同时给三样东西：
(i) **独立旁证**：接触载荷、非预期摩擦、堵转、滑移都会在功率/电流上留下特征。若视觉与几何同时说「没接触」，而功率显示有载荷，共因失效就被直接戳穿——因为功率模型与视觉特征不是同一个学习器。
(ii) **硬预算**：探测、悬停、退避都耗能；归因不能无限做，必须「anytime」且能量有界；剩余电量还定义了「退到安全态所需能量」E_safe，这是一个**物理的不可逆视界**，比第 65 轮仅凭力/几何反解的 m 更可靠。
(iii) **诚实的边界**：功率也不是万能——准静态、轻质、柔顺接触可能不显功率；功率模型与电流传感器也会偏。所以能量是「**失效结构不同的第四条可错证据**」，不是新真值。

**灵感 2（演示数据 → 有限、离线、幸存者偏差的先验：它既校准也限制可辨识性）**
直觉：机器人里的演示数据通常只包含「健康、成功、被操作者挑选过」的轨迹。它能校准 H0 与策略先验，却**不能告诉我们故障长什么样**——故障签名必须来自故障注入数据。更尖锐的是：演示数据是**幸存者偏差**的，操作者会本能地绕开危险与失败，所以演示分布天然缺少边界样本。于是演示数据有两面：
(i) **校准面**：在演示分布覆盖的状态上，用加权 conformal 做分布偏移下的有效校准；演示条件行为似然可作策略 OOD 证据。
(ii) **限制面**：演示分布之外，校准与归因都**没有保证**。因此「归因」不是无条件可做的：它是数据覆盖的函数。演示越偏、越旧、越「表演化」，可辨识的故障方向越少。
此外，「演示数据」还有第二重含义：**论文与汇报里被挑出来展示的漂亮数据**。本轮把「演示分布 vs 部署分布」的偏移（shift）当作一等安全变量，而不是默认二者同分布。

**灵感 3（合流 → ENDOW：Energy-grounded, Demo-calibrated Observability Witness）**
直觉：把上述两件事做成一个闭环：
1. **能量接地签名**（EGS）给出独立物理旁证与 E_safe / m_E；
2. **演示覆盖见证**（DCW）给出「这块状态、这个故障方向到底被数据支持到什么程度」；
3. **可辨识性诚实归因**（IHU）先做可辨识性审计：覆盖足够且有故障注入数据才归因，否则输出 `unidentifiable` 并弃权；
4. **每焦耳信息探针**（EPC）把主动探测从「最大化互信息」改成「最大化互信息/能量」，并强制预留 E_safe；
5. **能量约束认证前缀**（ECS）把 k* 截断到 min(k_geom, m_E)，保证块内不会把电用尽而 stranded；
6. 归因确定→定向膨胀对应球；弃权→覆盖自适应的联合球 + safe_idle/柔顺退避，而不是第 65 轮「强行选一个最近的假设」。
一句话：**第 65 轮问「谁坏了」；ENDOW 先问「我们有没有资格说谁坏了」，再用能量这个独立通道去说。**

- **定义 234（能量观测量与功率签名）**：电池状态 B_t∈[0,B_max]、母线电压/电流、关节电流 I_t、功率 P_t。能量残差 e_E(t)=|(B_{t−1}−B_t)−Δt·P_t|/σ_E；功率签名 π_t=[P^a,P^c,P^s,{I_j}]。能量模型 B_{t+1}=B_t−Δt(P^0+P^a(a_t,φ,load)+P^c+P^s)+ξ_t。**e_E 只产生「与能量模型不符」的证据，不是物理真值。**

## 2. 关键算法骨架

```python
# DCW：覆盖见证 + 可辨识性证书（语义流，低频）
cov = dcw.coverage(D_demo, D_fault, deploy_states)   # C_state, C_fault, W_hat
ident = identifiability_cert(S_D=D_fault.signature_matrix(),
                             cov=cov, kappa_min=K_MIN, snr_min=SNR_MIN)

# IHU：先审计资格，再归因；不可辨识就弃权
if ident.passed:
    post, h_star, eq = ihu.attribute(phases, ident)   # 只在可辨识等价类内
    if eq.size == 1:
        balls, w_vis, H = directed_demote(h_star, balls, w_vis, H)
    else:
        balls = inflate_union(balls, post, cov)       # ambiguous_equivalent
        abstention = True
else:
    post = ihu.posterior_for_logging(phases)          # 只记录，不执行
    balls = inflate_union(balls, post, cov)           # 覆盖自适应联合球
    abstention = True

# EGS：能量旁证裁决共因（独立于视觉/几何）
e_E, pi_power = egs.residual(B, dt, I, V, model)
if visual_geo_conflict and egs.load_signature(pi_power) > TAU_P:
    h_common_cause_resolved = True                     # 视觉+几何都错，接触真实存在
    balls['r_energy'] = egs.conformal_radius(alpha_E)

# EPC：每焦耳信息探针，强制预留 E_safe
if abstention and B - E_safe(s) > B_probe_min:
    a = epc.choose(post, E_safe, B_min, f_safe, demo_support)
    execute(a)                                         # 信息/焦耳 最大
elif abstention:
    safe_idle()                                        # 电不够，先退到安全态

# ECS：能量约束认证前缀
k_star = min(csc.certified_prefix(A, post, m, alpha_chunk),
             egs.energy_horizon(A, B, E_safe, B_min))
for a in A[:k_star]:
    dispatch(a)
    if ecs.monitor_step(a, B, post).abort:             # 力/视觉/能量任一越界
        break
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（能量旁证的共因可分辨性）**：若功率对接触载荷的灵敏度 |∂P/∂load|≥γ、且功率模型误差与视觉/几何误差独立，则当载荷超过 τ_P 时，视觉-几何共因失效可被能量通道检出，漏检概率随功率 SNR 指数下降。**反之，准静态/轻质/柔顺接触（载荷不显功率）时该保证失效——能量旁证有明确适用域。**
- **引理 10（覆盖不足则不可辨识，Fano/Le Cam 下界）**：若两个故障假设在可用数据支持下的观测分布满足 KL≤ε，则任何归因器的最小错误率 ≥½(1−√(ε/2))。因此「弃权」不是保守偏好，而是**数据不足时的必然结论**；IHU 的 `unidentifiable` 分支与下界一致。
- **引理 11（偏移下的加权 conformal）**：若 w(s)≤W_max，则加权 split-conformal 的覆盖 ≥1−α；Ŵ>W_max 时覆盖保证失效，必须降级为 `shift_out_of_bound` 并弃权/回退。**演示数据只在被覆盖的部署分布上可信。**
- **定理 9（ENDOW 端到端诚实安全）**：在 A94–A99 下，Valid(J_endow) ⇒（归因可辨识且只膨胀正确球）∨（显式 abstention 且联合保守球覆盖真值）∧ 能量可返回 ∧ 不会 stranded ∧ 共因冲突被能量旁证解释或被标为不可解释。
- **定理 10（每焦耳探针的近最优性）**：互信息对观测集单调子模、代价线性，则代价-收益贪心在背包预算下达到最优的常数因子近似；因此「信息/焦耳」是能量受限主动归因的正确目标，而非单纯最大化互信息。
- **定理 11（能量约束前缀的无 stranded 安全）**：k*≤min(m_geom,m_E) 且每步保留 E_safe ⇒ 单块越界概率 ≤α_chunk+δ_fi+α_vis+α_E，且执行中断时机器人仍有能量到达 S_safe。**长预测、短执行由此升级为「长预测、短执行、留足回程电」。**
- **实时性**：能量采样/残差 <0.05ms、覆盖查表 <0.1ms、演示行为残差 <0.2ms；世界模型、覆盖审计、归因、EA-V 全在语义流，目标实时路径 ≤2.5ms（A100 修订契约）。

## 5. 本轮最大风险

**一句话**：ENDOW 的「诚实」完全建立在「能量通道与视觉/几何独立且功率模型正确」以及对演示数据覆盖的准确估计上，但功率在准静态/柔顺接触下可能根本不显载荷、电池模型与电流传感器会与执行器故障共因漂移，而演示数据本身是幸存者偏差且可能被投毒——于是系统可能**为不可辨识的故障签发一张「已认证可辨识」的证书**，把第 65 轮的「错误归因」升级为「有证书的错误归因」，这比没有证书更危险（A94）。

## 2. 形式化定义（完整版）

**定义 233（ENDOW 闭环）** ENDOW 是 VISTA 的「可辨识性诚实 + 能量接地」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 EGS（能量签名）、DCW（演示覆盖见证）、IHU（可辨识性诚实归因）、EPC（每焦耳信息探针）、ECS（能量约束认证前缀）、DEMO-V（演示相对行为残差），并原位升级 RSC-V→RSC-E、WCV-V→WCV-E、CSP-V→CSP-E、AIC-V→EA-V、J_vista→J_endow。不变式：**所有覆盖审计、可辨识性判定、归因、证书构建只发生在语义流；实时流只做能量/力/视觉残差采集、阶段判定、安全前缀执行与早停，零学习写操作。** ENDOW 的目标不是让归因更「准」，而是让系统**只在有资格时归因**，并在没有资格时明确降级。

**定义 234（能量观测量与功率签名）** 电池状态 B_t∈[0,B_max]，母线电压 V_t、电流 I_t、关节电流 I_t^j，总功率 P_t=V_t I_t 分解为执行功率 P^a、计算功率 P^c、传感功率 P^s。能量模型
B_{t+1}=B_t−Δt(P^0+P^a(a_t,φ,load)+P^c+P^s)+ξ_t，
其中 P^0 为静态功耗，ξ_t 为未建模损耗。能量残差
e_E(t)=|(B_{t−1}−B_t)−Δt·P_t|/σ_E，
功率签名 π_t=[P^a,P^c,P^s,{I_j}]。由于电池模型存在温漂、内阻与老化，e_E 用 split-conformal 取分布无关上界 q_E(α)。**能量残差只产生「与能量模型不符」的证据，不产生物理真值；它的价值在于失效结构与视觉/几何不同。**

**定义 235（能量安全裕度与不可逆能量视界）** 设安全吸收集 S_safe（停机、抱闸、退避到标称位姿等），定义
E_safe(s)=在粗状态抽象上值迭代得到的 min_π E[Σ energy | s_0=s, 到达 S_safe] 的保守上界。
给定当前电量 B_t，定义能量不可逆视界
m_E(s,B)=max{k : Σ_{i<k} ê(a_i)+E_safe(s_{t+k}) ≤ B_t−B_min}。
与第 65 轮的 m 不同，m_E 由**物理能量**而非仅由力/几何反解给出，因而在执行器增益漂移、接触模型错误时仍然成立（只要电池模型可信）。这直接给出「长预测、短执行」的能量版本：**预测可以长，执行前缀必须留足回程电。**

**定义 236（演示集、故障注入集与协变量偏移）** 健康演示集 D_demo={(s_i,a_i,y_i,ρ_i,B_i)}∼p_demo，通常由操作者挑选的健康、成功轨迹组成；故障注入集 D_fault 由仿真与真机标定台在受控故障下采集，用于估计 p(ρ|H)。演示与部署的协变量偏移用密度比
w(s)=clip(p_deploy(s)/p_demo(s),0,W_max)
刻画，由域分类器估计，Ŵ=sup_s w(s)。若 Ŵ>W_max，标记 `shift_out_of_bound`，此后一切依赖演示分布的校准保证作废，必须弃权或回退到纯在线/纯物理证据。有效样本量 n_eff=(Σw)²/Σw² 用于判断覆盖是否足够。

**定义 237（演示覆盖见证 DCW）** 定义状态覆盖
C_state=P_{s∼p_deploy}[d(s,supp(D_demo))≤r_cov]，
故障覆盖 C_fault=min_{H∈ℋ} n_H/n_min（n_H 为 D_fault 中第 H 类样本数），覆盖证书 C_D=(C_state,C_fault,Ŵ,n_eff)。**关键命题（演示数据的双重角色）**：健康演示只覆盖 H0 与策略方向，故仅由 D_demo 诱导的故障签名矩阵秩 ≤1（只能辨识「健康/非健康」一个方向）；要辨识 H_geo/H_force/H_model/H_vis/H_policy，D_fault 是**必要条件**。这意味着「用演示数据训练出的置信度」不能直接当作故障可辨识性；DCW 必须显式计入 D_fault 的覆盖，否则 `unidentifiable`。

**定义 238（可辨识性证书 IHU 的前置）** 设 S_D 为 D_fault 诱导的签名矩阵（各假设下阶段证据的期望差分），ℐ=(rank(S_D),κ_fi,SNR_min,C_D)。可辨识当且仅当
rank(S_D)=d_H ∧ κ_fi=λ_min(S_DᵀΣ_ρ⁻¹S_D)/λ_max(·)≥κ_min ∧ SNR_min≥snr_min ∧ C_state≥c_min ∧ C_fault≥c_min ∧ Ŵ≤W_max。
若不可辨识，则用 Le Cam/Pinsker 给出**必然性**：对任意 H_i,H_j，若其在可用数据支持下的观测分布满足 KL(p_i‖p_j)≤ε，则任何判决器的最小错误率
P_e≥½(1−√(ε/2))。
因此 `unidentifiable` 不是工程上的保守偏好，而是数据不足时的**信息论下界**。定义不可分辨图 G_ε：边 (i,j) 当 KL≤ε；其连通分量给出「可辨识等价类」，等价类内部只能判 `ambiguous_equivalent`。

**定义 239（可辨识性诚实归因 IHU）** IHU 的决策规则：
1. 若 ℐ 不通过 → `unidentifiable`；后验 P(H|ρ) 仅写入日志与证书，**不用于定向处置**；动作走覆盖自适应联合膨胀（定义 243）+ safe_idle/柔顺退避。
2. 若 ℐ 通过，在可辨识等价类 G_ε 的分量内做后验；分量大小为 1 → 定向处置；>1 → `ambiguous_equivalent`，仍不做错误定向膨胀，而是对分量内假设做联合膨胀并记录`abstention=True`。
3. 只有当后验集中在单一可辨识等价类、且能量旁证无未解释冲突时，才允许 `directed_demote`。
**这与第 65 轮 FIR 的根本区别是：第 65 轮永远 argmax，ENDOW 允许并强制「不归因」。**

**定义 240（能量有界探针 EPC）** 探针集 A={visual_probe, null_test, power_probe, park, press, rub, tap, lift}，其中 power_probe 在空载/已知负载下测功率签名，park 用于测能量模型并进入低功耗安全态。选择
a*=argmax_{a∈A} I(ℋ;ρ_new(a)|ρ_old)/E_cost(a)，
s.t. B_t−E_cost(a)−E_safe(s′)≥B_min、f_n≤f_safe(φ̂,f̂_vis)、形变≤ε_strain、探针状态∈supp(D_demo) 或显式标记 shift。
与第 65 轮 AFA 的「最大化互信息」相比，EPC 的两个变化直接来自「续航能力」：(i) 分母是能量代价，因而优先选「信息密度高、耗能低」的探针；(ii) 硬约束是回程电，因而低电量时不是「少探一点」，而是「先回安全态」。若信息/焦耳的最大值 <δ_fi，放弃物理探针。

**定义 241（能量约束认证前缀 ECS）** 对块 A_t 与执行前缀 k，在可辨识等价类/后验支持集上逐一验证 ρ_safe≥0，并验证能量可行：
∀i<k: Σ_{j≤i} ê(a_j)+E_safe(s_{t+i+1})≤B_t−B_min。
输出
k*=min(csc.certified_prefix(A_t,post,m,α_chunk), m_E(A_t,B_t))。
单块越界概率
P[越界]≤α_chunk+δ_fi+α_vis+α_E，
其中 α_E 来自能量残差 conformal。执行器只执行 k* 步即强制重规划与再归因；**即使故障在块首发生，也能在耗尽回程电之前停下**。

**定义 242（演示相对行为残差 DEMO-V）** 用演示数据拟合条件策略似然 p_D(a_t|s_t)，定义
e_demo(t)=−log p_D(a_t|s_t)（按维度/分位数归一化）。
在偏移下用 shift 修正 e_demo^w=w(s)·e_demo；若 Ŵ>W_max，e_demo 仅作诊断、不作 OOD 判决。演示按版本与年龄衰减 ρ_demo(t)=ρ_0·exp(−(t−t_ver)/τ_demo)，过期即触发重采集请求并降低演示对后验的影响。**演示数据是「会过期的先验」，不是永久真值。**

**定义 243（RSC-E 能量/覆盖定向球）** 维护五个独立半径：r_geo（几何先验）、r_force（F/T 标定）、r_model（接触模型）、r_energy（能量模型残差 conformal）、r_demo（覆盖距离 d_cov 映射），以及视觉信任权重 w_vis。融合半径
r=√(r_geo²+r_force²+r_model²+r_energy²+r_demo²)。
- 可辨识且定向：只膨胀被归因的那个球；H_energy（功率/电池异常）→r_energy↑ 并触发零负载功率重标定；H_demo（覆盖不足/偏移）→r_demo↑ 并请求数据。
- 不可辨识：不做「最近假设」定向膨胀，而是对后验加权的所有假设求最小包含球 r_U，并置 `abstention=True`。**联合球可能很大，但它是诚实的；错误的小球比诚实的大球更危险。**

**定义 244（WCV-E 能量-覆盖联合压缩）** 搜索域
B(φ̂,r)∩𝒢(g)∩K(μ̂)∩ℱ(f_lim)∩𝒱∩ℰ∩𝒟，
其中 ℰ={φ:E_safe 在 φ 下可行且能量足够}，𝒟={s: C_state/偏移在界内或已标 unidentifiable}。CVaR 尾部采样 n_worst=8，尾部权重按 P(H|ρ)·w(s) 加权；交集为空→safe_idle，并置 `energy_or_coverage_conflict=True`。

**定义 245（CSP-E 能量约束块规划）** 在 CSP-V 的层级 A* 上以块为边，每条块边需 Valid(J_endow)、k*≥1 且能量可行。TSL 技能 σ 绑定典型能量签名分布 𝒟_σ^E，实际能量签名到 𝒟_σ^E 的 Mahalanobis 距离>τ_E 即判能量 OOD。规划器可插入 `power_probe`、`null_test`、`park`、`recharge` 元技能。代价增 λ_E·E_cost 与 λ_cov·max(0,c_min−C_state)（覆盖亏空），使规划主动走向「可校准、可归因、可回程」的区域。

**定义 246（EA-V 能量/演示对抗认证）** 干扰集
ℰ_E=ℰ_V×ℰ_energy×ℰ_demo，
ℰ_energy 含功率传感器欺骗、电流偏置、内阻/老化导致的电池模型漂移、隐藏功耗（计算峰值）；ℰ_demo 含演示投毒、幸存者偏差（只采成功轨迹）、演示过期、超界 shift。ρ_dir 在 ℰ_E 上重算（n_cert 128→160，其中 32 给能量/演示）；ρ_force 在最坏偏置与最坏遮挡下取最坏；J_dir 增 energy_calib_ver、demo_version、coverage_ver。**在能量欺骗或演示投毒下，不要求归因正确，只要求判 `unidentifiable` 并安全降级。**

**定义 247（ENDOW 证书 J_endow）** J_endow=(J_vista, energy_margin, E_safe_reserve, m_E, demo_coverage, shift_bound, identifiability_margin, abstention, energy_calib_ver, demo_version)。验证规则：
Valid(J_endow) ⇔ Valid(J_vista)
∧ (max_H P(H|ρ)≥1−δ_fi 且 ℐ 通过 ∨ abstention=True 且已走联合保守球)
∧ k*≥1 ∧ k*≤m_E ∧ E_safe_reserve 满足
∧ (demo_coverage≥c_min ∧ shift_bound≤W_max ∨ 已标 unidentifiable/shift_out_of_bound)
∧ (能量旁证未被未解释地忽略)

### IP-224 EGS（能量接地签名与回程裕度）

```python
class EnergyGrounding:
    """能量/功率是独立物理通道：既作旁证，又作硬预算。"""
    def __init__(self, capacity, B_min, sigma_E, model, alpha_E=0.05):
        self.B, self.B_min, self.sigma_E = capacity, B_min, sigma_E
        self.model, self.alpha_E = model, alpha_E
        self.q_E = None                            # conformal 上界

    def residual(self, B_prev, B_now, dt, V, I):
        P = V * I
        e_E = abs((B_prev - B_now) - dt * P) / self.sigma_E
        pi = self._signature(V, I)                 # [P^a, P^c, P^s, {I_j}]
        return e_E, pi

    def load_signature(self, pi):
        # 接触载荷/堵转/摩擦在功率上的投影（相对空载基线）
        return float(pi[0] - self.model.idle_power) / self.model.sigma_P

    def energy_to_safe(self, s):
        # 粗抽象上的保守值迭代；离线缓存，在线查表
        return self.model.E_safe_lookup(s)

    def energy_horizon(self, A, B, s, dt):
        # 保留回程电后，最多可执行多少步
        used, k = 0.0, 0
        for a in A:
            used += self.model.expected_cost(a, dt)
            s_next = self.model.step(s, a)
            if B - used < self.energy_to_safe(s_next) + self.B_min:
                break
            k += 1
            s = s_next
        return k

    def conformal_radius(self, residuals):
        return np.quantile(residuals, 1 - self.alpha_E)
```

```python
class DemoCoverageWitness:
    def __init__(self, D_demo, D_fault, r_cov, W_max, c_min, n_min):
        self.support = build_support(D_demo)       # kd-tree / 密度模型
        self.D_fault, self.r_cov, self.W_max = D_fault, r_cov, W_max
        self.c_min, self.n_min = c_min, n_min

    def coverage(self, deploy_states, density_ratio):
        C_state = np.mean([self.support.dist(s) <= self.r_cov
                           for s in deploy_states])
        counts = Counter(h for h, *_ in self.D_fault)
        C_fault = min(counts.get(h, 0) for h in HYP) / self.n_min
        w = np.array([density_ratio(s) for s in deploy_states])
        n_eff = w.sum() ** 2 / max((w ** 2).sum(), 1e-12)
        return dict(C_state=C_state, C_fault=C_fault,
                    W_hat=float(w.max()), n_eff=float(n_eff))


class IdentifiabilityHonestAttribution:
    HYP = ('H0', 'H_geo', 'H_force', 'H_model', 'H_vis', 'H_policy', 'H_energy')

    def certificate(self, S_D, cov, kappa_min, snr_min):
        rank = np.linalg.matrix_rank(S_D)
        if rank < len(self.HYP):
            return Cert(passed=False, reason='rank_deficient', margin=0.0)
        Sig = np.cov(S_D.T) + 1e-9 * np.eye(S_D.shape[1])
        J = S_D.T @ np.linalg.inv(Sig) @ S_D
        kappa = np.linalg.eigvalsh(J).min() / np.linalg.eigvalsh(J).max()
        passed = (kappa >= kappa_min and cov['C_state'] >= self.c_min
                  and cov['C_fault'] >= self.c_min and cov['W_hat'] <= self.W_max)
        return Cert(passed=passed, reason='ok' if passed else 'coverage_or_shift',
                    margin=kappa)

    def attribute(self, phases, cert, eps=0.05):
        if not cert.passed:
            return posterior_for_logging(phases), None, None, 'unidentifiable'
        # 只在 KL<=eps 的不可分辨图连通分量内比较
        comp = indistinguishability_component(self.lik, phases, eps)
        post = posterior_within(phases, comp)
        if len(comp) > 1:
            return post, None, comp, 'ambiguous_equivalent'
        return post, comp[0], comp, 'identifiable'
```

## 4. 推导

**引理 9（能量旁证的共因可分辨性）** 设功率对接触载荷的灵敏度 |∂P/∂load|≥γ>0，功率模型误差与视觉/几何误差独立，且能量残差上界为 q_E。当真实载荷满足 load>τ_P 时，能量通道给出的检验统计量 z=load_sig 在「有接触」与「无接触」下的分布间距 ≥γ·(load−τ_P)/σ_P>0；由 Hoeffding/Bernstein，漏检概率随 (γ(load−τ_P)/σ_P)²·n 指数下降。因此当视觉与几何同时误判「无接触」而实际有载时，能量旁证以可控概率戳穿共因。**适用域**：准静态、轻质、柔顺接触下 ∂P/∂load→0，或存在与执行器故障共因的功耗（计算峰值、摩擦随温度漂移）时，该保证失效；此时 ENDOW 必须把能量旁证标为 `unreliable`，不得据此裁决。∎

**引理 10（覆盖不足则不可辨识：Fano/Le Cam 下界）** 设可用观测分布为 p(ρ|H_i)，两个假设 H_i,H_j 满足 KL(p_i‖p_j)≤ε。由 Pinsker 不等式，全变差 ≤√(ε/2)，于是任何判决器的贝叶斯错误率
P_e≥½(1−‖p_i−p_j‖_TV)≥½(1−√(ε/2))。
更一般地，Fano 不等式给出 P_e≥1−(I(H;ρ)+log 2)/log|ℋ|。因此若 D_demo/D_fault 的支持使两个故障方向的观测分布 KL 低于 ε，则**不存在**能区分它们的归因器；IHU 的 `unidentifiable`/`ambiguous_equivalent` 分支与下界一致，而不是过保守。特别地，健康演示只覆盖 H0，故仅用 D_demo 时 H_geo/H_force 的 KL≈0，归因必然失败——这从信息论上说明了「健康演示不能辨识故障」。∎

**引理 11（偏移下的加权 conformal 覆盖）** 若密度比 w(s)≤W_max 且 w 已知，则对加权 split-conformal，覆盖率为
P[e_new≤q_w(α)]≥1−α，
其证明沿用 Tibshirani 等人的加权可交换性/重要性加权分位数。当 Ŵ>W_max 时，权重尾部使有效样本量 n_eff 骤降，覆盖界不再成立；ENDOW 因此把 `shift_out_of_bound` 作为硬弃权条件，避免「用旧演示的置信度给新分布背书」。演示版本年龄进一步以 ρ_demo(t)=ρ_0 e^{−(t−t_ver)/τ_demo} 降低其在后验与校准中的权重。∎

**定理 9（ENDOW 端到端诚实安全）** 在 A94–A99 下：
1. **资格诚实**：若 ℐ 不通过（秩亏、覆盖不足、偏移超界），IHU 输出 `unidentifiable` 或 `ambiguous_equivalent`，**不做定向膨胀**；由引理 10，这是数据不足时的必然结论，而非保守选择。
2. **归因正确性**：若 ℐ 通过，归因在可辨识等价类内进行；类大小为 1 时，可辨识性保证错误率随 n_eff·κ_fi 指数下降；只膨胀被归因的球（RSC-E），不会在正确几何/力传感器上误降级。
3. **共因裁决**：若视觉与几何冲突且能量通道可靠（引理 9 的适用域），能量旁证裁决共因；若能量不可靠，则显式标 `unreliable` 并判 `unidentifiable`，不强行归因。
4. **能量安全**：k*≤m_E 且每步保留 E_safe，由定理 11 保证不会 stranded。
5. **证书诚实**：Valid(J_endow) 强制记录 abstention、覆盖、偏移、可辨识裕度，审计者能区分「已归因」与「无资格归因」。
6. **实时性**：实时路径 ≤2.5ms，零学习写操作（A100）。∎

**定理 10（每焦耳探针的常数因子近最优）** 互信息 I(ℋ;ρ_new(a)|ρ_old) 对观测集是单调子模的（条件独立观测下互信息的子模性），E_cost(a) 线性可加，探针选择等价于带背包约束的单调子模最大化。代价-收益贪心至少达到最优的常数因子（1−1/e 类保证；对背包约束为 (1−1/e)/2 的下界），且每步只需 O(|A|) 次互信息估计。因此「信息/焦耳」不仅直觉合理，而且在能量受限下优于「只最大化互信息」——后者会把预算耗在信息高但极耗能的探针上。若最优信息/焦耳<δ_fi，则任何探针都不值得做，应回安全态。∎

**定理 11（能量约束前缀的无 stranded 安全）** 设 k*≤min(m_geom,m_E)，且对每个前缀 i≤k* 有 B_t−Σ_{j≤i}ê(a_j)≥E_safe(s_{t+i})+B_min。则由能量残差 conformal，能量模型偏差超过 q_E 的概率 ≤α_E；几何/力/视觉越界概率分别为 α_chunk、δ_fi、α_vis。联合界给出单块越界概率 ≤α_chunk+δ_fi+α_vis+α_E。由于每个前缀都保留 E_safe，即使故障在块首激活并触发早停，机器人仍有足够能量到达 S_safe；即「长预测、短执行」升级为「长预测、短执行、留足回程电」。∎

**命题（演示数据的双重角色）** 仅用健康演示 D_demo 估计的故障签名矩阵 S_D 的秩至多为 1（只能区分「健康/非健康」），因为 D_demo 中不含 H_geo/H_force/H_model/H_vis/H_policy 的受控样本。因此任何声称「用演示数据校准了故障归因」的做法在数学上不成立；ENDOW 强制 S_D 由 D_fault 构造，并把 D_demo 仅用于 H0/策略校准与覆盖。这解释了为什么「演示数据」既是资源也是限制：它让健康行为可信，却不能凭自身让故障可辨识。∎

**命题（归因弃权 vs 过度保守的权衡）** 第 65 轮在任何拒绝后膨胀单一 r，体积膨胀 κ_infl^{d_φ}；ENDOW 在可辨识时只膨胀对应分量（体积增益 1/κ_infl^{d_φ} 的分量级），在不可辨识时膨胀覆盖自适应联合球 r_U。设联合球与第 65 轮单球的体积比为 V_U/V_single。若真实故障在覆盖内，V_U 可能大于定向球但小于盲目单球；若真实故障在覆盖外，第 65 轮的单球**根本不包含真值**，而 r_U 至少包含后验支持内的真值。因此 ENDOW 用「可证明更大但诚实」的球替换「可能更小但错误」的球，这是安全上的严格改进。∎

## 7. 已知风险

**一句话**：ENDOW 的「诚实」完全建立在「能量通道与视觉/几何独立且功率模型正确」以及对演示数据覆盖的准确估计上，但功率在准静态/柔顺接触下可能根本不显载荷、电池模型与电流传感器会与执行器故障共因漂移，而演示数据本身是幸存者偏差且可能被投毒——于是系统可能**为不可辨识的故障签发一张「已认证可辨识」的证书**，把第 65 轮的「错误归因」升级为「有证书的错误归因」，这比没有证书更危险（A94）。

**次级风险与缓解**：
1. **能量旁证适用域窄**：准静态/轻质/柔顺接触不显功率；功率模型漂移与执行器故障共因。缓解：显式 `unreliable` 标记；只在载荷 SNR 足够时裁决；引入热/电流/IMU 多通道交叉；定期 park 标定。
2. **演示覆盖估计不准**：高维状态空间 kd-tree 覆盖不可靠，密度比估计本身有误差。缓解：用低维任务观测量（位姿/接触斑）做覆盖；保守 r_cov；W_max 留裕度；覆盖不足直接弃权。
3. **演示幸存者偏差/投毒**：坏演示抬高 C_fault/C_state 或污染 p_D。缓解：EA-V 显式建模；演示来源审计与版本签名；投毒检测用留出集与行为一致性；不完全信任任何单一演示集。
4. **弃权过多导致任务失败**：覆盖不足时频繁 `unidentifiable` 会降低成功率。缓解：CSP-E 主动规划到高覆盖区；`power_probe`/`null_test` 低成本补数据；把弃权率作为一等指标而非隐藏代价；允许操作者介入采集。
5. **能量模型误差累积**：内阻/老化/温度使 E_safe 估计偏乐观，可能 stranded。缓解：conservative 上界 + conformal α_E；电量低于硬阈值直接 park；在线更新电池参数但实时流只读。
6. **可辨识性证书的秩条件过强**：真实故障方向近共线，rank 永远亏。缓解：用有效秩/κ_fi 阈值而非严格满秩；对近共线方向判 `ambiguous_equivalent` 并联合膨胀；用 EPC 主动增加激励。
7. **计算/感知功耗被忽略**：世界模型与 EA-V 本身耗电，低电量时越算越危险。缓解：语义流降频/卸载；能量感知的计算调度；把计算功耗计入 E_cost 与 E_safe。
8. **证书与实际安全脱节**：J_endow 记录了大量字段，但审计者可能只看 `Valid=True`。缓解：证书显式区分 `identifiable`/`abstention`/`unreliable` 三态；UI 与日志强制展示弃权原因；把「诚实弃权率」纳入评测。

## 8. 与前序轮次的关系

- **对第 65 轮 VISTA**：保留其视觉前瞻、动作分块、阶段化签名、认证前缀与四层/五层证书；新增「资格审计」与「能量旁证」，把「归因」从无条件动作改为有条件动作。
- **对第 64 轮 GRIP**：能量回程与安全吸收集直接复用 GRIP 的安全约束，但把「不可逆视界」从几何/力扩展到能量。
- **对更早的「轻量化/边缘计算」线**：E_cost 显式包含计算功耗，使低电量时自动降级世界模型与 EA-V 频率。
- **对「演示数据」双重含义**：既用机器人演示数据做校准，也把「演示分布 vs 部署分布」的偏移当作安全变量，直接回应「只在演示数据上好看」的评测风险。
