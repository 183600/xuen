# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计层」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「开源生态」×「移动底盘」）

> R70 把 FLUID 的「动作模态 epistemic」升级成显式世界状态后验 b_t(s)，并交付了基线协议与原型验收。但它默认了一个从未被写下来的前提：**整个系统是一个可被单一机构端到端认证的、近乎静止的整体**。R70 自陈的最大风险正是「后验可能自信地错，实时部署会放大状态估计的脆弱性」——而真正放大这个风险的，恰恰是 R68–R70 从未正面处理的两个人间事实：
> - **开源生态**：真实机器人栈不是一个人写成的，而是几十个相互依赖、各自演进、质量不齐、甚至可能被投毒的模块拼起来的。J_BELIEF 是一张「整体证书」，一次依赖升级、一次 `git pull` 就可能让它悄悄失效，而证书本身毫无察觉。
> - **移动底盘**：R70 的「静止世界」假设一旦放到会滑、会颠、会热、会载物的底盘上，标定参数与状态都在**连续**漂移；R68「标定不能吸收慢变故障」的对偶判据会把**合法的物理漂移**（加载、轮胎磨损、悬挂压缩、热致外参）误判为故障，或者反过来让真故障藏进合法漂移的噪声带里。
>
> 本轮把这两件事看成同一问题的两面：**移动底盘就是开源生态的物理镜像——它由可热插拔、带版本、会漂移的模块组成，而整机必须在模块不断被替换/升级、底盘不断滑移的过程中，保持可证明的安全。**
>
> 核心命题：把 R70 的「单体证书」换成「**可组合证书代数 + 运行时假设契约 + 行为语义版本 + 漂移触发的增量再认证 + 事务化重配置**」；把移动底盘的滑移/载重/热漂移纳入信念与漂移先验，使「合法漂移」与「故障」在物理侧也可分离。命名 **MOSAIC-RAS**（Modular Open-Source Assembly with Interface-Certified safety on a moving chassis）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「世界是什么状态」，R71 问「**当我脚下的底盘在滑、而我手里的每个零件都可能被别人替换时，我还能相信哪一条保证**」——安全不再是系统的整体属性，而是一份可被第三方检查、可增量维护、可在替换中原子回滚的**契约**。

## 0. 直觉与动机

**灵感 1（开源生态 → 安全必须是可组合的，而不是整体的）**
直觉：开源生态里没有唯一的、可信的「总装厂」。每个模块由不同的人维护、以不同的节奏升级，接口可能不变而行为早已不同。此时「我们把整机测了一遍，它是安全的」这条陈述的生命周期只有到下一次 `pip install --upgrade`。所以安全证据必须换形态：从「对整机的一次性证明」变成「对每条模块边的一次性证明 + 组合规则」。这正是形式化方法里的 assume-guarantee（A/G）契约：每个模块声明「我保证 G、我要求 A」，组合合法当且仅当上游的 G 蕴含下游的 A，再加一组只属于组合的交互不变式。局部证明 + 组合规则 = 可随生态演进而局部维护的证书。

**灵感 2（行为语义版本 → 证书按指纹失效，而非按名字失效）**
直觉：供应链最经典的陷阱是「API 没变，实现变了」。按版本号或哈希去认证是脆弱的：一个 patch 完全可以在不改接口的情况下改变行为，把安全裕度悄悄吃掉。真正的认证对象应是**行为**：在冻结的一致性套件上跑出一段轨迹分布，作为「行为指纹」；版本变化时比较旧指纹与新指纹的语义距离，超过由保证裕度反推的容差就让所有下游证书自动失效。这不是语义化版本（semver）的营销承诺，而是**可检查的行为语义版本**。

**灵感 3（移动底盘 → 合法漂移与故障必须可分离）**
直觉：静止平台上「慢变 = 可疑」是合理的；移动底盘上「慢变」常常是**正常的**——你往车上装了一箱货，悬挂被压下去，外参变了，轮胎磨了，电机热了。R68 的对偶判据若原样搬过来，会把载重当成故障、把轮胎磨损当成传感器漂移。正确做法不是放宽阈值，而是**把「会漂移」本身写成先验**：显式估计漂移参数 d_t，规定哪些通道允许以多快速度变化；只有漂移**越出先验**才判故障。于是移动底盘不是敌人，失控的先验才是。

**灵感 4（热插拔 → 事务化重配置 + 增量再认证）**
直觉：移动底盘会对接、换工具、换电池、换传感器；开源栈会升级依赖。你不能每换一个零件就把整机停下来重认证十分钟——任务不等人。于是重配置必须是一个**事务**：预检（签名/复现包络）→ 对受影响的契约边做增量再认证 → 新旧组合影子并行一段时间 → 原子提交或回滚到 last-known-good（LKG）。重认证只碰证书依赖图里被改动的后代子图，成本与「受影响边数」成正比，而不是整机规模。这是「可维护性」第一次成为安全论证的一部分。

**灵感 5（组合涌现：局部安全 ≠ 整体安全）**
直觉：最阴险的失败不是某个模块坏了，而是几个各自都正确的模块**耦合**出不稳定的闭环：控制器和状态估计器各自稳定，回路增益却 > 1；两个模块都做输出钳位，合起来形成极限环。单模块证书检查不到这种「涌现」。所以契约代数之外必须再加一层**交互不变式**：小增益/收缩、无极限环/无死锁、速率与最坏执行时间相容。它对应软件工程里「所有单测都过，系统仍然挂」的那类 bug。

**灵感 6（生态的攻击面：供应链 × 滑移 × 涌现 × 复现性）**
直觉：R69 的投毒威胁在生态尺度被放大：恶意/误配模块、依赖混淆、被投毒的权重、许可证污染，以及更棘手的「套件内合法、套件外作恶」的特洛伊木马。物理侧也有攻击面：环境可以主动把底盘推滑，探询力可以把质心推出支撑多边形。但生态也给了正面的武器：**复现性**。如果每个模块都带一个可被第三方重放的复现包络，那么「说得清、跑得通、谁都能验」就成了生态里的硬通货。安全证书的最后一栏必须能从「内部基线通过」升级为「第三方回放 hash 一致」。

## 1. 形式化定义（增量：定义 331–348）

**定义 331（MOSAIC-RAS 总览）** MOSAIC-RAS = (Γ_AG, Φ, 𝒢_cert, 𝒟, TRX, MB, REG, RAS-WM†)。Γ_AG 为假设-保证契约代数；Φ 为行为指纹；𝒢_cert 为证书依赖图；𝒟 为漂移先验；TRX 为事务化重配置器；MB 为移动底盘被控对象模块；REG 为生态注册表。四不变式：
(i) **实时流零学习写操作**（继承 R70 定义 310-i）；
(ii) **组合证书闭包**：任何对外发布的整机保证，必须由一条从叶子模块到根的可验证契约链支撑，缺一环即降级，绝不以「整体测过」代替契约链；
(iii) **行为失效**：模块版本变化若使行为指纹距离超限，则其所有下游证书原子失效，未再认证前不得上车；
(iv) **事务重配置**：换模块/升级/换底盘构型是一个要么全成、要么回滚到 LKG 的事务，重配置期间 LKG 独占控制权。

**定义 332（模块契约五元组）** 模块 μ = (τ, G, A, φ, κ)。τ = (In, Out, rate, QoS) 为类型化端口；G 是对输出/状态轨迹的时序谓词（「位姿误差 ≤ e」、「输出 ∈ 安全集」、「时延 P99 ≤ ℓ」）；A 是对输入与环境的谓词；φ 为行为指纹（定义 333）；κ 为证书元数据（签名、许可证、复现包络、来源）。

**定义 333（行为指纹与一致性套件）** 对模块 μ 固定一致性套件 𝒞_μ（输入轨迹集 × 环境剖面），φ_μ = 在 𝒞_μ 上输出轨迹的经验摘要（分位数、矩、DTW/功率谱特征）。要求 𝒞_μ 覆盖 A→G 的全部边界面。指纹刻画**行为**而非**名字**。

**定义 334（行为语义距离与版本失效）** 对版本 μ→μ′，d_b(φ_μ, φ_μ′) = max_{c∈𝒞} W_2(φ_μ(c), φ_μ′(c))（或契约相关统计量最大偏移）。令 δ_μ 为由 G 的裕度反推的容差。d_b > δ_μ ⇒ μ′ 使所有以 μ 为节点的证书失效，必须重跑 𝒞 并重签。称 (μ, φ_μ, δ_μ) 为模块的**行为语义版本**。

**定义 335（假设-保证组合）** 组合 μ_1 ⊕ μ_2 合法 ⇔ 端口类型匹配 ∧ 边 (μ_1→μ_2) 上 G_1 ⊨ A_2 ∧ 交互不变式 𝕀(μ_1, μ_2) 成立。整机保证 Compose(𝒢_cert) = 由叶子保证沿契约图经蕴含传播到根的闭包。

**定义 336（交互不变式）** 𝕀 至少含：(i) **小增益/收缩**：任意耦合回路的增益矩阵谱半径 < 1；(ii) **无极限环/无死锁**：组合可达集不含非期望环，且资源/端口无循环等待；(iii) **速率相容**：上游输出速率与抖动满足下游最坏执行时间与截止期。𝕀 是 R70「单模块稳定性」之外的**涌现**检查。

**定义 337（组合证书 J_cert）** 一条组合证书 = (G_root, 支撑契约链, 每边蕴含证明哈希, 𝕀 检查结果, 行为指纹摘要, 复现包络)。Valid ⇔ 链完整 ∧ 所有边 d_b ≤ δ ∧ 𝕀 成立 ∧ 签名与复现包络有效。

**定义 338（证书依赖图与增量再认证）** 𝒢_cert 的节点为模块/契约边，有向边表示「谁的保证被谁使用」。模块 μ 变化时失效集 = μ 在 𝒢_cert 中的后代闭包 desc(μ)；再认证只重验 desc(μ)。成本 ∝ |desc(μ)| 与受影响边数，而非整机模块数。

**定义 339（移动底盘被控对象模块 MB）** 状态 x = (p, R, v, ω, β, m, c)，含位置、姿态、速度、角速度、滑移率 β、质量/负载、质心 c。运动学可切换（差速/阿克曼/麦轮），动力学含纵/侧向滑移与悬挂。**MB 本身是一个带版本、带指纹、带契约的模块**：底盘固件或参数更新同样触发定义 334 的再认证。

**定义 340（漂移先验与合法/故障分离）** 漂移先验 𝒟 = 允许缓慢变化的参数通道集合及其幅值/速率上限（载重 m、轮胎磨损、悬挂零位、热致外参）。d_t 为参数变化向量。合法 ⇔ d_t ∈ 𝒟 且 |ḋ_t| ≤ rate_max。在 b_t 中显式估计 d_t，把 R70 的 (r_res, Δa, H[b_t]) 判据升级为四元组 (r_res, Δa, H[b_t], d_t − 𝒟)：只有漂移**越出先验**才判故障，先验内的慢变不再被误杀。

**定义 341（事务化重配置）** 重配置事件 e ∈ {swap(μ), upgrade(μ→μ′), reconfigure(chassis)}。事务 = 预检（签名/复现包络/指纹）→ 增量再认证 → 影子运行（新组合影子模式与 LKG 并行最多 T_shadow）→ 原子提交/回滚。任一阶段失败 ⇒ 回滚 LKG；提交是瞬时的控制权切换（双缓冲），继承 R70 定理 15 的提交/换装不变式。

**定义 342（含底盘稳定性的交互预算）** R69 的信息动作 g 额外需过 MB 稳定证书：质心投影到支撑多边形的裕度 ≥ 1、牵引利用率 μ_used/μ_avail ≤ ρ_max；「凑近看/推一下」必须携带稳定认证，否则作废。滑移大时禁止会产生明显横向力/急转的探询。

**定义 343（生态供应链威胁模型 ℰ_supply）** 恶意/误配模块、依赖混淆（同名不同源）、被投毒权重、许可证污染、以及「套件内合法、套件外触发」的特洛伊木马。并入 AIC：ℰ_MOSAIC = ℰ_BELIEF × ℰ_supply × ℰ_slip（地形致滑移越先验）× ℰ_emergent（组合涌现失稳）。

**定义 344（复现包络与第三方回放）** 每个证书携带容器镜像摘要、种子集、硬件类别、数值容差、以及可被**第三方**重放的 I/O 摘要与 hash。Valid ⇔ 第三方回放 hash 在容差内一致。复现性从「内部基线」升级为「生态货币」：不可复现的模块不得进入证书链。

**定义 345（生态注册表 REG 与撤销）** 公开注册表记录 (μ, 版本, 指纹, 证书, 第三方回放, 撤销状态)。撤销（漏洞/投毒/回归）触发全网依赖它的证书批量失效；fleet 通过注册表协同降级到各自 LKG。撤销是生态级的「安全更新」。

**定义 346（运行时假设见证器）** 每条被依赖的假设 A_i 由一个轻量监视器见证（「状态估计无偏」由残差监测，「速率不过载」由时间戳监测）。见证失败 ⇒ 该契约边由「已证」降为「未证」，触发定义 338 失效与定义 341 回滚。

**定义 347（生态级失效归因与自愈）** 失败归因到：模块内部（指纹命中）、契约失配（蕴含漏洞）、交互涌现（𝕀 漏检）、物理越先验（𝒟 外）、供应链（签名/回放不一致）。归因结果回灌注册表，自动生成新的一致性套件用例——生态把每次事故变成对下一代模块的测试。

**定义 348（对 R70 的退化）** 当所有模块为 R70 原栈且无版本变化、d_t ∈ 𝒟 且位于先验中心、无重配置、交互只走 R70 路径时，MOSAIC 的决策与 R70 逐指令相同，安全侧不让步。

```python
# IP-275 Contract：模块契约与 A/G 组合
@dataclass
class ModuleContract:
    tau: InterfaceType
    G: list[Predicate]           # 提供的保证
    A: list[Predicate]           # 要求的假设
    phi: BehaviorFingerprint     # 一致性套件上的行为摘要
    kappa: CertMeta              # 签名 / 许可 / 复现包络

def compose_valid(mu1, mu2, invariants):
    if not type_match(mu1.tau.out, mu2.tau.in):  return False
    if not entails(mu1.G, mu2.A):                return False   # A/G 蕴含
    if not invariants.check(mu1, mu2):           return False   # 小增益/无极限环/速率
    return True

# IP-276/277 Fingerprint + 行为语义版本
def version_invalidates(mu_old, mu_new, suite, delta):
    phi_new = run_conformance(mu_new, suite)                # 冻结套件上重放
    d = behavior_distance(mu_old.phi, phi_new)              # DTW / Wasserstein
    return d > delta, d                                    # 超容差 → 下游证书失效

# IP-278/279 增量再认证：只碰后代子图
def incremental_recert(graph, changed_module):
    affected = graph.descendants(changed_module)            # 拓扑后代闭包
    for node in topo_order(affected):
        if not recompose_valid(node, graph):  return FAIL(rollback=True)
        node.cert = issue_cert(node)                        # 缓存重签
    return OK(graph)

# IP-280 TRX：事务化重配置（swap / upgrade / reconfigure）
def transactional_reconfigure(robot, event, registry, lkg):
    mod = registry.fetch(event.target)
    if not (verify_signature(mod) and third_party_replay_ok(mod)):
        return lkg                                          # 预检失败：不动
    shadow = RobotStack.build(event.apply(lkg.stack))       # 影子组合
    if not incremental_recert(shadow.graph, mod): return lkg
    if not shadow.run_shadow(T_shadow, ref=lkg):  return lkg
    return shadow.commit()                                  # 原子提交（双缓冲）

# IP-281 Drift：合法漂移 vs 故障（移动底盘）
def drift_gate(b_t, d_t, prior, r_res, a_hat):
    legit = (in_range(d_t, prior.range) and rate(d_t) <= prior.max_rate)
    # 只有“越出先验”的慢变才算故障；先验内的滑移/载重不误杀
    fault = (not legit) and (r_res < TAU_RES) and (a_hat > TAU_FMA)
    return legit, fault

# IP-283 StableInfo：含底盘稳定性的信息动作认证
def certify_info_action(g, mb, support_polygon):
    if not inside_with_margin(project_com(mb), support_polygon, margin=1.0):
        return False                                        # 倾覆风险
    if traction_ratio(mb) > RHO_MAX: return False           # 滑移大：禁急转/侧向探询
    return c_ras_wm.certify_info(g, mb)                     # R69 认证 + 底盘稳定

# IP-284 Witness：运行时假设见证
def runtime_witness(edge, monitors):
    for a in edge.assumptions:
        if not monitors[a].holds(): return UNPROVEN         # 假设被现场证伪
    return PROVEN

# IP-288 MOSAIC 主闭环（继承 R70，在漂移/见证/重配置处插入）
def MOSAIC_round(robot, obs):
    b_t = robot.bse.step(...)                               # R70 信念
    # 0) 漂移门：合法滑移/载重 vs 越先验故障
    legit, fault = drift_gate(b_t, robot.d_t, robot.drift_prior,
                              robot.last_r_res, robot.last_a_hat)
    # 1) 运行见证失败 → 立即回滚 LKG（通信/估计/速率任一被证伪）
    if not all_witnessed(robot.graph): return robot.trx.rollback_to_lkg()
    # 2) 决策仍走 R70（FMP/AUD/MINT/FMA）
    U_ale, U_epi = robot.aud.decompose_from_belief(b_t, robot.fmp, obs)
    g = robot.mint.choose_interaction_belief(b_t, robot.fmp, robot.budget)
    if g is not None and not certify_info_action(g, b_t, robot.support):
        g = None                                            # 底盘不稳 → 不交互
    lam = max(robot.efs.risk_scale(...),
              lam_floor(U_ale + (U_epi if g is None else 0.0)))
    if fault: lam = max(lam, 0.8)                           # 越先验 → 回 R68 最保守
    # 3) 仅安全态发起重配置
    if robot.pending_event and robot.safe_to_reconfigure(b_t):
        robot.trx = transactional_reconfigure(robot, robot.pending_event,
                                              robot.registry, robot.lkg)
    return lam, robot.trx.commit_ready
```

## 3. 推导

**引理 23（A/G 组合的可靠性）** 若 𝒢_cert 中每条边 μ_i→μ_j 满足 G_i ⊨ A_j，且交互不变式 𝕀 成立，则在 A102（蕴含判定可靠、见证器不漏报）下，根节点保证 G_root 在组合系统中成立。证明：对契约图做拓扑归纳，叶子保证成立，沿边由蕴含传递，𝕀 排除耦合回路的额外发散模式。系：**组合证书只需检查局部边，不必枚举整机状态空间**——把「指数级的整机验证」换成「边数的局部检查」。

**引理 24（行为指纹失效的保守性）** 令 δ_μ 由 G 的裕度反推：任何超出 δ 的输出偏移都会破坏 G。则 d_b(φ,φ′)>δ ⇒ μ′ 不再保证 G（逆否）。故「指纹距超限即失效」是安全的：可能过度失效，但绝不漏失效。系：它把「未知行为」默认当故障，与 R68「不确定就收紧」同构——这是同一哲学在软件供应链上的投影。

**定理 20（严格包含链）** 在 A102–A105（契约蕴含可靠、漂移先验覆盖合法漂移、𝕀 充分、无供应链攻击）下，MOSAIC 的期望风险 ≤ R70 ≤ FLUID ≤ R68；且当无版本变化、d_t ∈ 𝒟、无重配置、交互仅走 R70 路径时，四者逐指令相同。故 R68–R70 是 MOSAIC 在「生态静止、底盘静止、永不替换」边界上的退化，安全侧层层不让步。

**引理 25（合法漂移与故障可分离）** 在漂移先验 𝒟 内，滑移/载重使 (r_res, Δa) 同向小幅上升但 d_t−𝒟=0；越先验故障则 d_t−𝒟≠0 且 (r_res↓, Δa↑) 反号。若两类在 (r_res, Δa, d_t−𝒟) 空间可分，则存在阈值使误判率→0。系：移动底盘不是威胁，**失控的先验才是**——𝒟 过宽则漏故障，过窄则误杀赛道上一切正常载重；这是一个显式、可调、可审计的旋钮。

**引理 26（含底盘的交互安全）** 若信息动作 g 满足质心投影裕度 ≥ 1 且 μ_used/μ_avail ≤ ρ_max，则含倾覆与侧滑在内的物理风险 ≤ ε_int，且探询力不越出摩擦锥。系：R69 的交互安全（定理 17）是其在固定支撑多边形、无滑移约束下的特例。

**定理 21（增量再认证成本界）** 再认证成本 ≤ Σ_{v∈desc(μ)} cost_conf(v) + |E_affected|·cost_entail，且 ≤ 全量再认证；当证书图为森林时等于受影响子树。给出与「受影响边数」成正比的界，使一天数十次对接/换件在毫秒到秒级可完成。

**引理 27（供应链检测的上下界）** 若恶意版本在一致性套件上的行为距离 > δ，则定义 334 必检测；若 < δ（只在套件外作恶），则可能漏检，漏检概率受套件覆盖度与攻击者「套件内保持合法」能力限制。系：**一致性套件是生态安全的最小公分母**，必须由生态共同维护（定义 347 回灌），否则局部认证给出虚假的组合安全感。

**定理 22（事务重配置的无危险窗口）** 在 LKG 独占控制权、影子只观测不执行、提交为瞬时双缓冲切换且新组合已过增量再认证与影子对比的前提下，重配置全程不存在「未认证组合执行任务动作」的时间窗；任一失败原子回滚，控制连续（继承 R70 定理 15）。⇒ 热插拔不引入新的安全让步。

## 6. 本轮最大风险

## 2. 形式化定义（要点版，定义 349–366）

**定义 349（MOSAIC v1 总览）** 继承定义 331 四不变式，并把「组合证书闭包」细化为可机读的契约链：J_MOSAIC 必须能导出每个节点的 (G,A,φ,κ) 与每条边的蕴含证明哈希，任何字段缺失即 Valid=false。

**定义 350（契约语言 CL）** 谓词文法：`bound(var, c, [t0,t1])`（区间界）、`rate(var, r)`（变化率）、`eventually/always/until`（时序）、`depends(var1,var2)`（条件独立假设）。语义为在离散时间轨迹上的可判定片段；蕴含 G ⊨ A 用区间抽象 + SMT（线性算术/差分逻辑）判定，不可判定片段退化为运行时见证（定义 346）。

**定义 351（蕴含判定与见证兜底）** 四值结果 {PROVEN, REFUTED, UNKNOWN, WITNESSED}。PROVEN 边可入证书；UNKNOWN 边只能以 WITNESSED 形式进入「有条件证书」，且计入风险附加。

**定义 352（一致性套件覆盖度）** Cov(𝒞) = 对 A→G 边界面的输入空间覆盖率（区间划分 + 角点）与故障注入类别的加权和。要求 Cov(𝒞_μ) ≥ c_min，否则 μ 的指纹不可用于失效判定（不得进入证书链）。

**定义 353（行为距离的统计判定）** 对 φ, φ′ 用双样本检验（能量距离/Wasserstein bootstrap），给出 d_b 的置信上界 \hat d_b^{1−α}；失效判据 \hat d_b^{1−α} > δ_μ，控制第二类错误 ≤ β_stat。

**定义 354（交互不变式判定）** (i) 由各模块的增益界装配小增益矩阵 S，判 ρ(S)<1；(ii) 对组合可达集做有界模型检验，检测极限环/死锁；(iii) 速率相容由 τ 的 (rate, jitter) 与下游 WCET 的偏序判定。

**定义 355（增量再认证引擎语义）** `Recert(𝒢, μ_changed)`：失效集 = desc(μ_changed)；按拓扑序重验边与 𝕀；缓存键 = (module_hash, phi_hash, suite_hash, contract_ver)；相同键复用证明，保证幂等与可重现。

**定义 356（影子运行对比）** 新组合在影子模式只接收观测、不驱动执行器，与 LKG 并行 T_shadow；对齐指标 = 决策动作的 KL/最大偏差、触发安全边界的次数、后验熵差。超阈值即判影子失败。

**定义 357（漂移先验在线拟合）** d_t 由物理先验（载重/磨损/温度模型）+ 变点检测（贝叶斯在线变点）联合估计；rate 估计用滑动窗回归。越界判定用 D 的硬约束 + 变点后验概率的软置信，二者取「或」以保证不漏故障、取「与」以控制误杀（可配置）。

**定义 358（底盘滑移可观测性）** 以轮速编码器、IMU、视觉/激光里程计构成观测；β 的能观性与地形相关，定义观测性指标 κ_o，κ_o 低时 MB 契约降级为「保守运动包络」并要求更低速度。

**定义 359（ZMP/摩擦锥交互约束）** 信息动作 g 的可接受域 = {CoM 投影离开 SP 边界裕度 ≥ m_s} ∩ {μ_used/μ_avail ≤ ρ_max} ∩ {探询冲量不触发侧滑}；不满足即拒。

**定义 360（见证器合成）** 从 A 的谓词自动生成监视器（区间越界报警、速率超限报警、依赖破坏报警）；监视器自身有误报/漏报率，纳入 J_MOSAIC 的 witness_ece。

**定义 361（注册表撤销传播）** 撤销事件 r=(μ, 版本, 原因) 触发所有依赖 μ 的证书失效；fleet 在 ≤ T_revoke 内降级到 LKG，并上报降级确认。注册表可审计、可镜像、可离线快照。

**定义 362（复现包络与第三方回放）** 复现包络 = (镜像 digest, 种子集, 硬件类别, 数值容差, 依赖锁文件)；第三方回放输出 I/O 摘要 hash；Valid ⇔ 与发布者 hash 在容差内一致。禁止「仅内部可复现」的模块进入证书链。

**定义 363（供应链特洛伊检测）** 对套件外行为设置蜜罐探测（随机化输入 + 侧信道样例）；若模块在蜜罐上的行为异常而套件上正常，标记为 suspect 并冻结。检测能力受蜜罐覆盖度限制（引理 27）。

**定义 364（生态级失效归因）** 归因函数 A: 事故 → {module, edge, emergent, drift, supply}；用指纹命中、蕴含反例、𝕀 复现、d_t−𝒟、签名/回放不一致分别作为证据；归因结果回灌 𝒞，形成自愈闭环。

**定义 365（J_MOSAIC 证书与 Valid）** Valid ⇔ Valid(J_BELIEF) ∧ 契约链完整 ∧ 所有边 d_b ≤ δ ∧ 𝕀 成立 ∧ d_t−𝒟 未越界（或已降级）∧ 签名与第三方回放有效 ∧ 注册表无撤销。字段自动生成，哈希可追溯到代码/数据/种子/模块来源。

**定义 366（对 R70 的严格包含）** 在 A102–A106 下，MOSAIC 期望风险 ≤ R70；生态静止/底盘静止/无替换时逐指令相同；任何不确定性（契约未知、漂移越先验、见证失败、供应链可疑）都单向退化为更保守的 R70/R68 路径。

## 4. 推导

**引理 28（四值契约的代数与保守性）** 若只把 PROVEN/REFUTED 作为二元证书，UNKNOWN 一律视为 REFUTED，则定义 350–351 的契约代数在 A102 下仍可靠（不产生假阳性 Valid）；若允许 WITNESSED 入链，则可靠性由见证器漏报率 η_w 控制，J_MOSAIC 的假 Valid 概率 ≤ 1−Π(1−η_w)。系：**「未知即失效」是默认，只有带见证的未知可被有条件接受**——与 R68 的保守哲学一致。

**引理 29（增量再认证的等价性）** 若缓存键唯一标识 (module, φ, suite, contract) 且图谱中未受影响边的证明与缓存一致，则 `Recert(desc(μ))` 与全量再认证产生相同的 Valid 集合；增量只改变耗时，不改变结论。系：局部维护不以牺牲正确性为代价。

**定理 23（事务重配置的观测等价与安全）** 影子期间新组合不驱动执行器，故其任何缺陷不进入物理世界；提交为双缓冲瞬时切换且新组合已过增量再认证，故提交后系统等价于「一个已认证组合」，控制连续、无危险窗口。⇒ 热插拔/升级的期望风险 ≤ 不重配置的 R70。

**引理 30（漂移先验的误杀-漏检权衡）** 设合法漂移分布 P_L、故障分布 P_F，四元组判据的误杀率 α(𝒟)、漏检率 β(𝒟) 随 𝒟 单调反向变化；总代价 C = c_α α + c_β β 的最优 𝒟* 由物理风险比 c_α/c_β 决定。系：**不能一味放宽**；应先由安全分析定 c_β/c_α，再选 𝒟，使漂移先验成为可审计的设计参数而非调参玄学。

**定理 24（严格包含与退化）** 在 A102–A106 下，MOSAIC 的各层都只在「生态/物理/交互出现不确定性」时单向收紧；当所有模块为 R70 原栈、d_t ∈ 𝒟 中心、无替换、无见证失败时，MOSAIC ≡ R70（逐指令）。故 R71 不引入安全让步，只把 R70 的隐式整体假设显式化、可维护化。

**引理 31（复现性与可保性的耦合）** 若第三方回放失败，则模块行为不可独立复现，其指纹可被发布者单方面操纵；因此第三方回放是行为语义版本的「可信根」。系：安全证书的可信度 ≤ 其最弱一环的复现性——这与 R70 的「基线纪律」同构，但把「内部可复现」升级为「他方可复现」。

## 8. 本轮最大风险

**一句话**：MOSAIC-RAS 把所有保证押在「一致性套件 + 契约蕴含」是真实行为的**可靠代理**上——套件不具代表性或蕴含检查有漏洞时，模块会被盖章「已认证」却在部署中违反假设；开源生态由此给出**虚假的组合安全感**，移动底盘再把一次未检测的契约违反直接放大为倾覆。**橡皮图章式的认证，比没有认证更危险**。
