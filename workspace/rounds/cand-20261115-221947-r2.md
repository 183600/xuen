# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「云边协同」×「抓取规划」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570；IP-340–356）。
> 本轮纪律：**证书拆分 + 云边时效契约 + 边缘主权**。两个灵感分别治理 v9 的两个未解债：**接地债**（v9 把所有模块当同构组件，误以为算力是唯一稀缺资源，未区分"强先验/弱接地"与"弱先验/强接地"）与**操作债**（v9 的 AC 只覆盖导航避障，未触达抓取这一真正高组合复杂度且不可逆的动作）。任一云侧环节失效必须注入中立元、严格退回 v9 边缘自治行为，而非行为漂移。

## 0. 直觉与动机

**灵感 1（云边协同 → 时效契约与边缘主权）**
直觉：v9 默认所有模块共享同一时钟、同一世界模型、同一失效语义。跨网络后这三条全断：云可观全局却只见过期观测，边可实时却只看得见局部。资源的真正稀缺性不是"算力"，而是**强先验与实时接地的正交错配**。核心创新：**云边计划账本（CloudEdgePlanLedger, CEPL）**——只追加、带单调版本 n 与因果时间戳 τ_c 的计划记录；**时效契约（Staleness-Aware Contract）**把网络时延、丢包、分区概率写进契约；**边缘主权门（EdgeSovereignGate, ESG）**保证云永远不能越过边的实时安全判据去触发不可逆动作。分区时云模块注入中立元 v^⊥，系统退化为"最后有效先验 + 边缘自治"，即 v9 行为。

**灵感 2（抓取规划 → 证书拆分）**
直觉：抓取规划是组合爆炸（候选采样、碰撞、力闭合、可达性、语义可抓性）且**不可逆**（合爪即承诺），天然适合云生成、边验证。但 v9 的单体块证书解决不了跨网络陈旧性：云算的证书到手时观测已过期。核心创新：**证书拆分（Split Certificate）**——云只算**抓取流域的保守内近似族** B̂(θ)（昂贵、依赖强模型），边只做 **O(1) 成员测试** x_t ∈ B̂(θ_t)（便宜、依赖实时感知）。陈旧性因此只降低"命中率"（覆盖率），**不破坏单次接受判据的可靠性**，因为判据永远在 t 时刻用实时状态求值。配套 **证书化抓取块（CertifiedGraspChunk, CGC）**：抓取位姿 + 接近轨迹 + 抓取证书 + 撤退点 + 有效期；以及 **重抓取退化梯（RegraspFallbackLadder, RFL）**：滑脱/碰撞/未闭合时按代价递增的候选梯回退。

## 1. 研究问题（轮次升级版）

- **Q1（拆分证书的可靠性）**：如何定义参数化流域族 B̂(θ) 与边的成员测试 V，使 `accept ⇔ x_t∈B̂(θ_t) ∧ 实时检查` 在云观测任意陈旧、对象位姿在边侧被重新估计时仍保持力闭合与无碰撞？"云算区域、边验成员"能否把 v9 的 β-信任域假设从"整段执行期"收缩到"单次判据"？
- **Q2（云边退化与分区等价）**：如何把云侧契约的失效（超时、分区、版本倒挂、时钟偏斜）编码为中立元，使"云不可用"与"显式降级"在可观测日志层面不可区分，并严格退化为 v9 边缘自治？
- **Q3（不可逆动作的双钥活性）**：在"云给任务钥、边给安全钥"的双钥提交下，如何保证既不因云沉默而死锁（活性），又不存在任何云消息序列能诱发越过实时安全判据的不可逆动作（安全性）？重抓取退化梯在几次失败内必然到达安全态？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 证书拆分律（Split Certificate, SC）**
抓取证书分为云侧区域与边侧测试：Ĝ = (B̂(θ), V)。B̂ 是成功抓取流域 B(g) 的保守内近似族，θ 为对象类别/位姿/尺度参数；V(x, B̂) 为 O(1)/O(log n) 成员测试。执行判据：`x_t ∈ B̂(θ_t) ∧ V_force ∧ V_clear ∧ V_reach`。云陈旧只影响 B̂ 的覆盖与 θ 的初值，**不影响任一时刻判据的可靠性**；边侧对 θ 的不确定性用鲁棒成员测试吸收。

**P14 云边时效契约律（Staleness-Aware Contract, SCC）**
云侧契约 κ_m^cloud 在 v9 κ_m 基础上扩展网络项 (L_net, σ_net, ρ_part, T_silent, ack_policy)。每条跨边界计划携带 (n, τ_c, T_g, Δ_max)；接受门：`age = t−τ_c ≤ T_g ∧ age+ε_clk ≤ Δ_max(g) ∧ n ≥ floor ∧ 版本因果一致`。超时/分区/版本倒挂均注入中立元 v^⊥ = "无新先验"。

**P15 边缘主权律（Edge Sovereignty, ES）**
不可逆动作 u（合爪、抬升、放置）执行需双钥：任务钥（云授权该对象/该任务，n ≥ floor）与安全钥（边在实时状态上通过 P13 判据）。**安全钥是必要条件且由边本地求值**，云消息序列无权替代；云沉默 ≥ T_silent 时任务钥默认"继续当前安全任务或保持"，对**新**不可逆动作默认拒绝。撤退/松开永远单边可执行，不受双钥约束。

## 3. 与基线的接口（如何退化）

- 云计划陈旧/分区 ⇒ CEPL 冻结，B̂ 取最后有效版本，边仅用实时成员测试执行（"陈旧但可靠"，成功率下降、安全性不变）；
- B̂ 超有效期 T_g ⇒ 边本地粗流域（腕相机 ICP + 局部采样）或反应式抓取，等价 v9 边缘自治 + 简化抓取；
- CGC 证书失效/重抓取梯耗尽 ⇒ 撤退到安全位姿，回到 v9 的 AC 导航避障；
- CGC 模块超时 ⇒ MW 注入 v^⊥，逐位等价 v9（引理 88 复用引理 83）；
- da/SPR/Cal 失效 ⇒ v9 中立元链，等价 v7；
- 全部失效 ⇒ 完整退回 v9 → v8 → v7 → v6。

## 4. 预期贡献

1. **证书拆分框架**：把"昂贵区域计算"与"实时成员测试"沿网络边界劈开，使跨边界陈旧性从"安全性问题"降级为"覆盖率问题"——这是对 v9 最大风险的原理性回应；
2. **云边时效契约 + 计划账本**：跨边界失效语义的代数化，分区严格退化为 v9 边缘自治（引理 88）；
3. **双钥不可逆提交与重抓取退化梯**：不可逆动作的安全-活性分离，云永远无法越过边的实时安全门（引理 92）；
4. **语义-几何分离的诚实边界**：明确拆分证书只保几何-物理有效性、不保语义身份，并把该残余风险做成可测实验（E578/E589）。

## 5. 本轮最大风险

**一句话**：拆分证书能证明「这样抓得住」，却证明不了「该抓这个」——语义身份错误对几何成员测试不可见，而云恰是语义的唯一来源；于是"陈旧云语义 + 快速局部几何"会产出**自信地抓错**，且分区期间的合爪不可撤销。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

| γ = (g,a^{1:K_a},u,Ĝ,P_ret,P_esc,T_g) | 证书化抓取块：位姿/接近轨迹/合爪指令/证书/撤退点/逃逸路径/有效期 |

| K_task / K_safe | 双钥：云任务钥（授权对象）/ 边安全钥（实时判据） |

**新增定义 540（云边计划账本 CloudEdgePlanLedger）** 只追加记录 L = {(n, τ_c, ŝ_0, γ, ack)}，n∈ℕ 单调递增，τ_c 为云侧因果时间戳（PTP 同步，时钟偏斜 |ε_clk| ≤ 1ms）。边维护 floor = max{n : ack(n)}，**单调不下退**；接受任何记录需 n≥floor 且其因果前驱已 ack（Lamport 序一致）。账本只记录**计划**，不记录传感器原始流：带宽 O(每块 KB 级)，与对象复杂度无关。

**新增定义 541（证书化抓取块 CertifiedGraspChunk）** 一次抓取尝试的最小承诺单元：
```
γ = (g, a^{1:K_a}, u, Ĝ, P_ret, P_esc, T_g)
g = (R∈SO(3), t∈ℝ³, w∈[w_min,w_max], ψ)      # 位姿、开度、预成形
u ∈ {CLOSE(force), HOLD, RELEASE}            # 不可逆动作仅 CLOSE/LIFT
Ĝ = (B̂(θ), V, ε̂_fc, ĉ_app, r̂_reach, p̂_succ)  # 拆分证书 + 各裕度
P_ret ⊆ {1..K_a},  P_esc ⊆ SE(3)              # 撤退点、抓后逃逸路径
```
块在云侧规划（5Hz 以下，允许 100–1000ms），边侧以 50Hz 执行接近段并在任一时刻可切至 P_ret。

**新增定义 542（抓取流域与拆分证书 GraspBasin / SplitCertificate）**
```
B(g) = { x : λ_min(G(x,g)) ≥ ε_min            # 力闭合裕度（G 为抓取矩阵）
            ∧ clear(x, g) ≥ c_min             # 接近走廊无碰撞
            ∧ IK(x, g) 有解且关节限位裕度 ≥ r_min
            ∧ P_slip(x, g, f) ≤ 1−p_min }     # 摩擦锥内滑脱概率
Ĝ 健全 ⇔ B̂(θ) ⊆ B(g(θ)) 且 V(x,B̂)=true ⇒ x∈B̂(θ)
```
**证书拆分**：B̂(θ) 由云用强模型（全场景重建、GPU 候选采样、力闭合锥计算）求出，以参数化族下发；V 由边用实时腕相机/触觉在 O(1) 内求值。二者以对象相对坐标表达，故边界只传"区域族 + θ 先验"，不传逐步动作。

**新增定义 543（停滞预算 StalenessBudget）** 设对象速度/加速度有界 (v_max, a_max)，则
```
W(Δ) = v_max·Δ + ½·a_max·Δ²
Δ_max(g) = max{ Δ : ∀θ'∈U_t(θ): B̂(θ') ⊕ W(Δ) ⊆ B̂(θ) }
```
接受门：`age ≤ min(T_g, Δ_max(g) − ε_clk)`。Δ 超出只拒绝**新**抓取提交，不阻断已在执行的撤退/松开。

**新增定义 544（双钥与边缘主权 DualKey / EdgeSovereignty）**
```
execute(u) 允许 ⇔  K_safe(x_t, γ)=true  ∧  K_task(n, γ)=true
K_safe  : 仅由边本地实时状态求值（P13 判据），云不可代理
K_task  : n ≥ floor ∧ 账本记录授权该 (对象,任务) ∧ 未过期
云沉默 ≥ T_silent ⇒ K_task 对新 u 默认 false，对当前任务为 "hold"
撤退/松开: 仅需 K_safe=false-or-true 的本地安全条件，永远可执行
```
主权不变式：对任意云消息序列（含对抗性），不存在不通过 K_safe 的不可逆动作。

**新增定义 545（推测计划树 SpeculativePlanTree）** 云依生态模型预测未来状态桶集合 Ŝ={ŝ_1..ŝ_m}，对每桶预生成分支 γ(ŝ_j) 并写账本。边在 t 时刻以实时状态匹配最近桶 ŝ*；命中（dist(x_t,ŝ*)≤δ_match）则直接提交，未中则 Level-1。命中率 ℓ_hit 与预取深度 m、对象混合时间 T_mix 相关；目标是让往返时延 L 被预测深度掩盖。

**新增定义 546（重抓取退化梯 RegraspLadder）** 失败事件 e∈{SLIP, COLLISION, NO_CLOSURE, TIMEOUT} 后按序尝试
```
Λ = [γ_local1, γ_local2, γ_reactive, γ_retreat]
```
每级有独立证书要求（γ_retreat 无抓取证书、仅需撤退路径安全）；第 4 级失败即 Level-3 回 v9 导航。梯长 Q≤4，禁止无限重试。

**新增定义 547（因果版本一致性 CausalConsistency）** 账本用向量时钟 (v_c, v_e)：云记录携带其已知边版本；边拒绝任何"引用了未被 ack 的前驱"或"n<floor"的记录。目的：防止分区愈合后旧分支覆盖新分支（write-skew）。

**新增定义 548（云边契约 CloudContract）** 扩展 v9 定义 535：
```
κ_m^cloud = (In, Out, D_m, Ŵ_m, v_m^⊥, π_m, φ_m^elig,
             L_net, σ_net, ρ_part, T_silent, ack_policy)
```
v_m^⊥ = "无新先验"（CEPL 冻结、B̂ 取最后有效、θ 只用边估计）。部署期校验 E[L_net]+k·σ_net ≤ 规划节拍与 T_g 的兼容性。

**新增定义 549（抓取计划链 GraspPlanChain）** 长程取放序列 Γ=(γ_1..γ_p)，放置 γ_i 的后状态集 Post_i 决定 γ_{i+1} 的前置流域 Pre_{i+1}。链健全 ⇔ ∀i: Post_i ⊆ Pre_{i+1}（在证书保守性下）且每段 T_g 与执行时域相容。链证书 = 逐段证书之交 + 段间可达性证明。

## 2. 形式化定义（要点与升级）

**升级定义 533（块证书 → 拆分证书，v10）** 原 Ĉ=(ĝ_min, ê_max, γ̂_grasp) 保留用于导航；抓取分支改用 Ĝ=(B̂(θ),V,ε̂_fc,ĉ_app,r̂_reach,p̂_succ)。导航与抓取共享同一 MW 端口与中立元语义。

**升级定义 534（中止点 → 撤退点 + 逃逸路径）** 抓取段的中止不再是"停驻"，而是"撤退并松开"：p∈P_ret 满足 retract(p) 在 c_min 内；抓后 P_esc 保证物体不撞周边。故抓取的失败语义是**可逆撤退**，唯一不可逆点是 u=CLOSE→LIFT。

**升级定义 535（契约表增加云行）** 新增行：CEPL/SCC（D=网络，Ŵ=规划 200ms，v^⊥=冻结）、CGC 规划（D≤1000ms，v^⊥=边本地流域）、ESG 提交门（D=0.2ms，v^⊥=拒绝新不可逆动作）、RFL（D≤2ms，v^⊥=撤退）。

**升级定义 539（有效块长门控，v10）** 抓取段块长由"对象混合时间"门控：
```
K_a,eff = 1                         若 U_t(θ) 不满足成员鲁棒性
        = max(1,⌊K_a·(1−‖U_t‖/τ_U)⌋) 否则
```
对象越不确定、接近轨迹越短；极端退化为单步接近 + 每步重验。

class CloudEdgePlanLedger:
    def __init__(self, t_silent=1.0, eps_clk=0.001):
        self.n_floor = 0; self.last = None
        self.last_ack_t = -1.0; self.t_silent = t_silent; self.eps_clk = eps_clk

    def accept(self, rec, now, vclock_edge):
        if rec.n <= self.n_floor: return False              # 版本倒挂
        if not causal_predecessors_acked(rec, self): return False
        age = now - rec.tau_c
        if age < -self.eps_clk: return False                # 时钟偏斜/伪造

        if age + self.eps_clk > rec.delta_max: return ('STALE', rec)  # 仅冻结新提交

        return ('OK', rec)

    def ack(self, n, now): self.n_floor = max(self.n_floor, n); self.last_ack_t = now

    def cloud_silent(self, now): return (now - self.last_ack_t) >= self.t_silent

## 4. 推导

**引理 87（拆分证书可靠性 / 陈旧不伤健全性）** 设 B̂(θ) 对对象参数 θ 保守（B̂(θ)⊆B(g(θ))），V 健全（V(x,B̂)=true ⇒ x∈B̂(θ)），且 θ∈U_t 由边实时估计并做鲁棒成员测试。则无论云记录年龄 Δ 多大，只要提交门通过，被执行抓取的力闭合裕度、接近无碰撞、可达性与滑脱上界均成立。证明：安全性是 t 时刻的合取判据，仅依赖实时 x_t 与边估计的 θ、U_t；云记录只决定**下发哪个 B̂ 族**，不参与判据求值。若 B̂ 族本身是对象相对坐标的保守内近似（对类别内的任意 θ 均成立），则陈旧仅可能使 B̂ 覆盖变小、命中率降低，不可能使"通过判据的 x_t"落在 B 之外。∎

**推论 87.1（陈旧性的语义转移）** 云陈旧从"证书可能已经失效"（v9 风险）转移为"可能没有可执行计划命中"（覆盖率/ℓ_hit 问题）。安全性不再随 Δ 单调恶化；这是与 v9 引理 82 的本质区别：v9 的 β-信任域要求在**整段执行期**内误差有界，P13 只要求**单次判据**时点上的成员关系。

**引理 88（分区退化 ≡ v9 边缘自治）** 当云沉默 ≥ T_silent，SCC 对所有云模块注入 v^⊥="无新先验"，CEPL 冻结于 floor，γ 取最后有效 B̂（或 Level-2 边本地流域）；ESG 对新不可逆动作默认拒绝、对当前任务 hold。此时系统可观测行为等价 v9 边缘自治 + 一个固定抓取流域，且 v9 引理 83 的中立元表逐行适用。证明：构造账本重放映射，将每条云记录替换为 v^⊥ 后，边侧状态机转移与 v9 对应退化级一致；AC/CGC 的失败语义（撤退/单步）在 v9 已定义。∎

**引理 89（抓取链组合安全）** 若链 Γ 逐段满足 Post_i ⊆ Pre_{i+1}（在 B̂ 保守性下）且每段执行时 age≤min(T_g,Δ_max)，则整链执行期间不存在"未达前置流域即提交"的段。证明：对 i 归纳。γ_i 通过判据后由引理 87 得其后状态必在 Post_i 内（保守），链条件给出 Post_i⊆Pre_{i+1}=B_{i+1} 的内近似，故 γ_{i+1} 提交时 x∈B_{i+1}，归纳成立。∎

**引理 90（双钥提交无死锁 / 活性）** 安全钥 K_safe 是边本地 O(1) 谓词、不依赖云；撤退/松开单边可执行；云沉默时任务钥默认 hold 而非阻塞。故：(i) 任意时刻系统可在有限步内到达安全态（撤退）；(ii) 云永久沉默不会使边进入等待云的非安全挂起。证明：(i) RFL 最多 Q 级、每级有限步，耗尽早退 Level-3 撤退；(ii) hold 是可执行状态而非阻塞态，且撤退路径不查询 K_task。∎

**引理 91（推测命中与有效利用率）** 设对象状态混合时间 T_mix，云往返 L，预取深度 m，规划节拍 T_c。若 m·T_c ≥ L 且状态桶覆盖真实状态（δ_match 半径内），则稳态命中率 ℓ_hit ≥ 1 − exp(−T_mix/T_c) 量级；有效云利用率 = ℓ_hit，未中部分由 Level-1 的"陈旧但可靠"执行兜底。带宽 O(m·|γ|/T_c)，与对象几何复杂度弱相关（流域族为参数化表示）。∎（工程命题，E582/E583 标定）

**引理 92（边缘主权不变式 / 抗对抗云）** 对任意云消息序列（含伪造版本、时钟倒拨、重放旧分支），不存在不通过 K_safe 的不可逆动作。证明：execute(u) 的定义要求 K_safe ∧ K_task；K_safe 仅由本地实时状态与本地 θ 估计求值，云消息最多影响 K_task（授权）与 B̂ 族选择，而 B̂ 必须经 V 在实时 x 上成立才能提交。版本/时钟攻击由 CEPL 的 n≥floor、因果前驱 ack、ε_clk 检查拦截（定义 547）。退化路径（撤退）不受云控制。∎

## 8. 本轮最大风险

**一句话**：拆分证书能证明「这样抓得住」，却证明不了「该抓这个」——语义身份错误对几何成员测试不可见，而云恰是语义的唯一来源；于是"陈旧云语义 + 快速局部几何"会产出**自信地抓错**，且分区期间的合爪不可撤销。缓解只能靠外挂的语义复核键（任务钥里的类别/实例校验）与边侧触觉/视觉 instance 复核，但这已超出几何证书的证明范围——这是本方案的诚实边界。
