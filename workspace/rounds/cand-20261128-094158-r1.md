### 第 6 轮灵感驱动研究记录（新循环首轮）

**灵感词**：自监督学习、语言指令

**继承关系**：第 5 轮 CADVS-v5（IP-493~496，CGE 认证生成式执行）把框架从「规则系统」推广为「任意生成器 + 认证边界」：七硬门 kc_evidence_forged_v4 冻结、阈值只紧、Exec_CADVS-v5 ⊆ Exec_CADVS-v4，并以流匹配提议、记忆固化、情感调制三条非侵入路径扩张能力。但 v5 遗留两笔结构性债务：(a) **R57 记忆固化自指回路**——固化只吃 D_cert={x:七门通过}，而 D_cert 的分布由 π 自己决定（π→候选→过门→D_cert→π'），缺乏门外真值，策略会向门边界漂移博弈；(b) **意图通道缺失**——人因接口只有情感调制，任务仍是离散 rule_id 枚举，人类无法表达"轻放红色杯子到左架"这类自然意图。本轮两个灵感词统一为主题「接地式可指令认证执行」（Grounded Instructable Certified Execution, GICE）：**自监督学习**提供一条不引用任何门谓词的接地信号来减 R57 的债；**语言指令**提供一条不可信的、只能塑形提议、只能收紧阈值的意图通道。形成 CADVS-v6（IP-497~500 + CERTCALC-v6）。自律：**硬门仍为七门**（维持 R52 锚点维护负债不增），执行集嵌套 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **自监督学习 → 用「数据流形」这条门外轴偿还固化自指**。v5 固化的病根是"选择事件"：只有过门片段被训练，于是策略学会的是"如何过门"而非"世界如何运转"。自监督的关键作用不是加门，而是提供一条**不引用任何 kc_i** 的训练信号：掩码轨迹重建（MTM）、时序对比（InfoNCE）、前向动力学/世界模型预测（dyn）、SE(3) 等变一致性（eq）。把固化目标从"只模仿铸证片段"改为联合目标 L_cons = L_imit(D_cert) + λ_fail·L_neg(D_fail) + λ_ssl·L_SSL(D_all) + λ_kl·KL，其中 D_all 含被拒绝候选与失败片段。直觉：证书只告诉你"安全"，自监督告诉你"像不像这个世界真会发生的事"；两条轴正交，门博弈策略会在"形式合规但物理离谱"处被 SSL 项惩罚。**定理 11** 给出诚实边界：SSL 只把策略锚到观测流形 M_data；若 M_data 本身含"合规但有害"的行为，SSL 会把它固得更牢——SSL 是减债，不是免债。

2. **语言指令 → 意图通道必须按「提议可塑、证书不可塑」切开**。语言让人类用自然语言给任务（"把红色杯子轻放到左边架子上"），但语言是不可信输入：歧义、误解、提示注入都会污染它。核心设计是**语言-证书分离（定理 9）**：语言只走两条写路径——(i) 条件化流提议（task/指代/意图嵌入），(ii) **单调约束编译** γ_lang,i ≥ 1（只紧不松，如"轻放/易碎"→抬高 ξ_wrench/ξ_zmp）。任何"放宽安全/忽略力限"的请求被结构性钳制为 γ=1 或被拒——不是靠过滤器，而是**根本不存在降低阈值的写路径**。语言指代必须接地到场景物体；接地置信度低或歧义高 → 澄清回退（fail-safe），不执行。**定理 10** 给出联合调制有界与非塌缩条件，Exec_CADVS-v6(ℓ) ⊆ Exec_CADVS-v5。

3. **两者的合流 → 指令条件的自监督接地**。语言给出弱监督（"红杯子"↔视觉/轨迹），SSL 用它做跨模态对比接地；反过来 SSL 的预测一致性又给语言指代提供可验证的物理线索（指代错误的轨迹会在世界模型下"跳变"）。于是形成「语言→弱标签→自监督接地→更稳提议」与「SSL→一致性→指代校验」的双向正循环，且都不触碰门。接地不一致 d_ssl 只并入 kc_mem 的新颖度裁决 Ψ_novel（OR 合成），fail-closed 回退规则提议/人工，不新增硬门。

**关键洞见**：v5 回答"提议=任意生成器时证书边界如何不变"；v6 回答"**当能力来源（自监督、语言）本身不可信且可能自指时，如何让证书边界继续不变，同时诚实承认证书只证安全、不证语义**"。七硬门 kc_evidence_forged_v4 原样复用；本轮新增只有：接地表示 z_g 与一致性分 d_ssl（并入 kc_mem，非新门）、语言单调调制 γ_lang（仅收紧）、软评分 ECS_v6 = ECS_v5·η_lang·η_ground。执行集 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 由「同门 + γ_emo·γ_lang 只紧 + 提议支撑受限 + 接地不一致回退」四重保证。

**形式化目标（增量）**：
1. 自监督：L_SSL = L_MTM + L_NCE + L_dyn + L_eq；接地编码 z_g=Enc_g(o,x)；一致性 d_ssl(x)=沿 x 的期望一步预测误差。
2. 语言：ℓ → I=(task, refs, constraints, ambiguity, conf)；双通道 P（提议）/C（单调约束）；γ_lang,i = 1 + κ_i^ℓ·r_i^ℓ，r_i^ℓ∈[0,1] 为约束请求强度，γ_lang ≥ 1 恒成立。
3. 联合调制：γ_tot,i = min(γ_emo,i·γ_lang,i, 1+Δ_max)，Δ_max=0.2；τ_i^6 = γ_tot,i·τ_i^4（τ^4 冻结只读）。
4. 固化 v3：L_cons = L_imit(D_cert)+λ_fail·L_neg(D_fail)+λ_ssl·L_SSL(D_all)+λ_kl·KL(π_new‖π_old)。
5. 新颖度：Ψ_novel = 计数统计 ∨ n_flow ∨ 1[d_ssl>τ_cons]（接地不一致 fail-closed 回退规则提议/人工）。
6. Exec_CADVS-v6 = {x∈supp(π_FM(·|c,ℓ,z_g)) : ∧_i kc_i(x,c;τ_i^6)=1} ⊆ Exec_CADVS-v5。
7. 定理 9（语言-证书分离）、定理 10（联合调制有界/非塌缩）、定理 11（接地锚定与选择偏差削减）、定理 12（接地固化漂移界）；引理 45（接地一致性谬拒界）。

**本轮最大风险**：**证书语义盲区**——七门证明的是动作在物理/人因/平衡上安全，从不证明动作是用户想要的；语言接地错误叠加 SSL 流形固化，会产出"安全、物理合理、但语义错误"的动作，且所有证书都通过，系统会自信地做错事。

## 2. 关键算法骨架

### IP-497 SSGK：自监督接地核（离线预训练；在线推理与 1 kHz 环解耦）

```python
@dataclass
class SelfSupervisedGroundingKernel:
    """SSGK：门外的接地信号。红线：L_SSL 不引用任何 kc_i；
    d_ssl 只并入 kc_mem 的新颖度裁决，不新增硬门"""
    enc: Any                 # z_g = Enc_g(o, x)
    world: Any               # f_dyn：一步前向动力学/世界模型
    tau_cons: float = 0.0    # 按 D_all 的 d_ssl P99 标定

    def pretrain(self, D_all) -> None:
        # 关键：在 D_all（含被拒候选与失败片段）上训练，而非仅 D_cert
        L = (masked_trajectory_loss(self.enc, D_all)          # L_MTM
             + info_nce_temporal(self.enc, D_all)             # L_NCE
             + forward_dynamics_loss(self.enc, self.world, D_all)  # L_dyn
             + se3_equivariance_loss(self.enc, D_all))        # L_eq
        ...

    def embed(self, o, x) -> np.ndarray:
        return self.enc(o, x)                                 # z_g

    def consistency(self, x, actions) -> float:
        """d_ssl：沿轨迹的期望一步预测误差（世界模型惊讶度）"""
        zs = [self.embed(o_t, x) for o_t in x.obs]
        return mean(‖self.world(zs[t], actions[t]) - zs[t + 1]‖ ** 2
                    for t in range(len(zs) - 1))
```

### IP-498 LITB：语言指令信任边界（解析/接地在准入时域，端侧或沙箱）

```python
@dataclass
class LanguageInstructionTrustBoundary:
    """LITB：语言是不可信输入。定理 9：语言只能收紧阈值/限制提议支撑，
    不存在降低阈值的写路径——注入最坏只造成过度收紧或无效"""
    parser: Any              # 解析器（LLM/文法），输出视为不可信
    grounder: Any            # 语言-视觉指代接地（CLIP/OWL-ViT 类）
    alpha_max: float = 0.3   # 歧义上限，超过 → 澄清回退
    conf_min: float = 0.6    # 接地置信下限

    def compile(self, ell, scene) -> Instruction:
        I = self.parser.parse(ell)
        I.refs, I.conf, I.ambiguity = self.grounder.resolve(I.refs, scene)
        # 解析器沙箱：不触发任何工具/系统调用；只产出结构化 I
        return I

    def gamma_lang(self, I) -> dict:
        """单调约束编译：只有 upward 写路径。
        '轻放/易碎/慢一点' → 抬高对应阈值；'放宽/忽略力限' → 无对应算子，钳制为 1"""
        g = {i: 1.0 for i in ('veto', 'wrench', 'zmp', 'val')}
        for r in I.constraints:                 # r 只能携带 tighten 语义
            for i, k in r.tighten.items():
                g[i] = max(g[i], 1.0 + k)        # max 保证 γ ≥ 1，绝不下降
        return g

    def proposal_cond(self, I, z_g) -> Cond:
        return Cond(task=I.task, refs=I.refs, i_emb=Enc_l(I), z_g=z_g)
```

### IP-499 GCP：接地-固化提议核（提议在线；固化离线）

```python
@dataclass
class GroundedConsolidatedProposal:
    """GCP：流提议条件化于指令/接地；固化 v3 用联合损失削减自指。
    红线：门代码与 τ^4 冻结只读，任何梯度不经过门"""
    fmpp: Any                # v_θ(x,t|c,i_emb,z_g)
    lmem: Any                # LMEM-v3：条目附 (e_τ, z_g)
    ssgk: SelfSupervisedGroundingKernel

    def propose(self, c, I, z_g, k) -> list[Trajectory]:
        cond = merge(c, Enc_l(I), z_g)
        xs = randn(k, d_x)
        for s in range(self.S):
            xs = xs + (1.0 / self.S) * self.fmpp.net(xs, s / self.S, cond)
        return decode(xs)

    def consolidate(self, D_all, D_cert, D_fail, lam_fail, lam_ssl, lam_kl) -> None:
        """只上线通过回归门测试+红队+人工抽检的策略；否则回滚旧 θ"""
        L = (imitation_loss(self.fmpp, D_cert)              # 铸证片段模仿
             + lam_fail * preference_loss(self.fmpp, D_fail) # 失败片段负例/排序
             + lam_ssl * self.ssgk.pretrain_loss(D_all)      # 门外接地信号（减 R57）
             + lam_kl * kl_div(self.fmpp, self.fmpp_old))    # 防遗忘/防漂移
        # frozen-gate：kc_i 与 τ^4 在此只读
        ...
```

### IP-491 扩展 CERTCALC-v6：新增引理 45 与定理 9~12（离线理论）

```python
# 引理 45：接地一致性谬拒界
def lemma_grounding_consistency_bound() -> str:
    """
    引理 45：设分布内 d_ssl 的均值/标准差为 (μ_d, σ_d)、估计误差 ε_d，则
    P(d_ssl > τ_cons | x~p_data) ≤ exp(−(τ_cons−μ_d−ε_d)²/(2σ_d²))（Cantelli）。
    OOD 假接受原理性无界，故 d_ssl 只并入 Ψ_novel 的 OR 合成并 fail-closed 回退，
    不单独充当安全证书。∎
    """
    return "Proven (in-distribution); OOD false-accept unbounded"

# 定理 9：语言-证书分离（本轮理论主轴）
def theorem_language_certificate_separation() -> str:
    """
    定理 9：对任意 ℓ（含对抗/注入），设语言唯一写路径为
    (i) 提议支撑 supp(π(·|c,ℓ)) 与 (ii) 单调阈值 γ_lang,i(ℓ) ≥ 1，
    则 Exec_v6(ℓ) = {x∈supp(π(·|c,ℓ)) : ∧_i kc_i(x; γ_tot,i·τ_i^4)=1} ⊆ Exec_v5(static)。

    而非放松安全。证明：γ_emo≥1、γ_lang≥1 ⇒ γ_tot≥1 ⇒ 各门通过集单调不增；
    支撑限制只删候选。∎
    诚实边界：只约束「安全集」，不约束「语义正确性」——语言可改任务，
    使一个安全动作变得答非所问。
    """
    return "Proven (safety set); semantics NOT covered"

# 定理 10：联合调制有界与非塌缩
def theorem_joint_modulation_bounded() -> str:
    """
    定理 10：γ_tot,i = min(γ_emo,i·γ_lang,i, 1+Δ_max)，Δ_max=0.2。
    若 x∈Exec_v5 的归一化边际 m_i(x)=s_i(x)/τ_i^4 ≥ 1+Δ_max 对所有 i 成立，
    则 x∈Exec_v6；执行集相对 v5 的收缩仅由 m_i<1+Δ_max 的点贡献。
    证明：γ_tot ≤ 1+Δ_max ⇒ τ^6 ≤ (1+Δ_max)τ^4；m_i≥1+Δ_max ⇒ s_i ≥ τ^6。∎
    工程含义：联合调制有界，高边际集不塌缩；长期痛苦+强约束语言仅压缩低边际区。
    """
    return "Proven"

# 定理 11：接地锚定与选择偏差削减
def theorem_grounding_anchoring() -> str:
    """
    定理 11：设 D_cert={x:S(x)=1}（S=∧kc_i，分布依赖 π），D_all 为含被拒/失败/未标注全量。
    L_cons = L_imit(D_cert)+λ_fail L_neg(D_fail)+λ_ssl L_SSL(D_all)+λ_kl KL。则
    (i) ∇L_SSL 不引用 S，其总体风险仅是 P_data 的泛函，不随门通过事件变化；
    (ii) KL 预算 ε_KL 内，任意门博弈策略 π_g 的 SSL 惩罚 ≥ λ_ssl·dist(supp(π_g), M_data)²。
    即 SSL 把策略锚到观测流形，抬高「形式合规但物理离谱」策略的代价。
    证明：(i) L_SSL 定义不含 kc_i；(ii) 由一致性损失的二次下界/Lipschitz。∎
    诚实边界：若 M_data 本身含「合规但有害」轨迹，SSL 会将其固化得更牢（流形内盲区）；
```

### IP-500 EFA-v6：七硬门 + 语言编译 + 联合调制 + 接地级联选证

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变（τ^6=γ_tot·τ^4，只紧不松）+ 语言信任边界 + 接地级联"""
    gcp: GroundedConsolidatedProposal
    litb: LanguageInstructionTrustBoundary
    ssgk: SelfSupervisedGroundingKernel
    v5: EvidenceForgingAssemblerV5

    def select(self, state, ell, t_now, context) -> tuple[bool, Trajectory | None, str]:
        I = self.litb.compile(ell, context.scene)
        if I.ambiguity > self.litb.alpha_max or I.conf < self.litb.conf_min:
            return self._clarify_or_hold(I)                 # fail-safe：不执行，澄清
        g_lang = self.litb.gamma_lang(I)
        g_emo = self.v5.famk.gamma(self.v5.famk.observe(context.face, t_now))
        g_tot = {i: min(g_emo[i] * g_lang[i], 1.0 + DELTA_MAX) for i in g_lang}
        z_g = self.ssgk.embed(context.obs, state)
        cands = self.gcp.propose(build_ctx(context), I, z_g, self.gcp.K)
        # 级联第 0 层（新增）：接地一致性预筛（O(S)），不一致 fail-closed
        cands = [x for x in cands if self.ssgk.consistency(x, x.actions) <= self.ssgk.tau_cons]
        if not cands:
            return self._fallback_rule_proposal(g_tot)       # 回退 v4 规则提议
        # 级联第 1 层：廉价门（coverage/physics/memory/novelty，含 n_flow）
        surv = [x for x in cands if self._cheap_gates(x, g_tot)]
        if not surv:
            return self._fallback_rule_proposal(g_tot)
        # 级联第 2 层：VACK 仅评 ≤3 幸存者（调制 τ_val）
        surv.sort(key=lambda x: self._prefilter_score(x), reverse=True)
        finals = [x for x in surv[:3]
                  if self.v5.vack.kc_val(self.v5.vack.evaluate(x, context, t_now),
                                         tau=g_tot['val'] * TAU_VAL4)]
        # 级联第 3 层：BCK 轨迹预览（事件触发 QP + 缓存内插）
        ok = [x for x in finals if self._bck_preview(x, g_tot)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=certified_margin)
        return True, best, 'FORGED_GICE'

    def ecs_v6(self, x, I, d_ssl) -> float:
        eta_lang = I.conf if I.ambiguity <= self.litb.alpha_max else 0.0
        eta_ground = math.exp(-d_ssl / max(self.ssgk.tau_cons, 1e-6))
        return self.v5.ecs_v5(x) * eta_lang * eta_ground
```

## 4. 正确性论证（增量更新）

### 引理 45（接地一致性谬拒界）

**陈述**：设分布内 d_ssl 的均值/标准差为 (μ_d, σ_d)、估计误差 ε_d，则 P(d_ssl > τ_cons | x~p_data) ≤ exp(−(τ_cons−μ_d−ε_d)²/(2σ_d²))（Cantelli）。∎

**诚实边界**：仅分布内成立；OOD 假接受原理性无界。故 d_ssl 只并入 Ψ_novel 的 OR 合成并 fail-closed 回退，不单独充当安全证书。

### 定理 9（语言-证书分离）

**陈述**：对任意 ℓ（含对抗/注入），语言唯一写路径为 (i) 提议支撑 supp(π(·|c,ℓ))、(ii) 单调阈值 γ_lang,i(ℓ) ≥ 1，则 Exec_v6(ℓ) ⊆ Exec_v5(static)。

**证明**：γ_emo ≥ 1、γ_lang ≥ 1 ⇒ γ_tot ≥ 1 ⇒ 各门通过集单调不增；支撑限制只删候选。∎

**诚实边界**：只约束安全集，不约束语义正确性——语言可改任务，使安全动作答非所问。

### 定理 10（联合调制有界与非塌缩）

**陈述**：γ_tot,i=min(γ_emo,i·γ_lang,i,1+Δ_max)，Δ_max=0.2；若 x∈Exec_v5 满足 m_i(x)=s_i(x)/τ_i^4 ≥ 1+Δ_max ∀i，则 x∈Exec_v6；收缩仅由 m_i<1+Δ_max 的点贡献。

**证明**：γ_tot ≤ 1+Δ_max ⇒ τ^6 ≤ (1+Δ_max)τ^4；m_i ≥ 1+Δ_max ⇒ s_i ≥ τ^6。∎

### 定理 11（接地锚定与选择偏差削减）

**陈述**：D_cert={x:S(x)=1}（S=∧kc_i，分布依赖 π），D_all 含被拒/失败/未标注；L_cons=L_imit(D_cert)+λ_fail L_neg(D_fail)+λ_ssl L_SSL(D_all)+λ_kl KL。则 (i) ∇L_SSL 不引用 S，其总体风险仅是 P_data 的泛函；(ii) KL 预算 ε_KL 内，任意门博弈策略 π_g 的 SSL 惩罚 ≥ λ_ssl·dist(supp(π_g), M_data)²。

**证明**：(i) L_SSL 定义不含 kc_i；(ii) 由一致性损失的二次下界/Lipschitz。∎

**诚实边界**：若 M_data 本身含「合规但有害」轨迹，SSL 会将其固化得更牢（流形内盲区）；SSL 减债非免债。

### 定理 12（接地固化漂移界，扩展定理 7）

**陈述**：若 ‖Δθ‖≤Δ_max、KL(π_new‖π_old)≤ε_KL、门与 τ^4 冻结，则 (i) 策略漂移 ≤ √(ε_KL/2)；(ii) 执行集只缩不涨；(iii) 门博弈率仅以红队回归检测率为经验上界。∎

### 定理 v6（执行集四重收缩与语言-证书分离，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 接地/解析器误差受控下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 语言-证书分离：注入不能扩大安全执行集（定理 9）；
(iii) 联合调制有界：γ_tot ≤ 1+Δ_max，高边际集不塌缩（定理 10）；
(iv) 接地锚定：SSL 抬高「合规但物理离谱」策略的代价（定理 11）；
(v) 固化漂移有界：KL 冻结 ⇒ 只缩不涨（定理 12）；
(vi) 七锚完备性保持（v5 定理 8 原样）。

**证明**：(i) 由同门 + γ_tot 只紧 + 支撑受限 + 接地回退。(ii)~(v) 分别由定理 9~12。(vi) 锚点集合不变。∎

**诚实声明**：(i) **证书只证安全/物理/人因/平衡，不证语义意图正确**；(ii) 语言接地错误与 SSL 流形盲区均有原理性残余；(iii) R57 由 SSL 减债但未根除，门博弈只能检测不能证明消除；(iv) 加性价值假设 (B4) 继承自 v4，未解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**证书语义盲区**——七门证明的是动作在物理/人因/平衡上安全，从不证明动作是用户想要的；语言接地错误叠加 SSL 流形固化，会产出"安全、物理合理、但语义错误"的动作，且所有证书都通过，系统会自信地做错事。
