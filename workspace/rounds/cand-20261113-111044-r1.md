# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「同步定位与建图」×「差异化定位」）

> 第 66 轮 RAS 把「被动故障响应」升级为「主动意图感知」：用面部表情捕获风险态度，用时空一致性压低误判，用 λ_risk 把情绪注入闭环。但 RAS 有一个被它自己忽略的维度：**风险是时间索引的，却从未被空间索引**。同一个「让使用者皱眉的桌角」，第一次撞上时被归因为 E3/H_geo，五分钟后又从零开始重新紧张一次。风险没有记忆，于是闭环每轮都在「重新认识同一个危险」。
>
> 本轮两个灵感恰好补上这一维：
> - **同步定位与建图（SLAM）** 提供的不是「更准的位姿」，而是一种**可回溯的空间记忆与回环重归因机制**——回环闭合会一次性重写过去整段轨迹，这正是第 65 轮 FIR「事后重归因」在空间上的孪生；
> - **差异化定位（differentiated positioning）** 提醒我们：**不存在唯一权威的全局坐标系**。机器人有 LiDAR/视觉、人有社会性方位线索、环境有 fiducial 锚点，三者各有各的协方差与可信度；强行融合成一张图，反而会摧毁每一路的差异化可靠性。
>
> 本轮核心命题：
>
> **把「标量、无记忆的风险闭环」升级为「位姿锚定、可回溯、多视角的风险建图闭环」：PRISM（Pose-anchored Risk Integration via SLAM & Multi-positioning）——用 SLAM 回环做故障重归因，用差异化定位承载多主体的分歧，用主动视角探测把 RAS 的情绪探针推广为「信息最优的空间探针」。**
>
> PRISM 问的不再是「此刻风险多大」，而是「**这个风险发生在哪里、由谁的坐标系认定、下次经过时还应不应该相信它**」。

## 0. 直觉与动机

**灵感 1（SLAM → 风险的空间记忆与回环重归因）**
直觉：SLAM 的本质闭环是「预测位姿 → 观测 → 校正」，而**回环闭合（loop closure）**是它最像「故障重归因」的一步：当机器人绕一圈回到起点，回环把过去几十秒累积的漂移在**一次后验更新里整体拉直**——这不是修正当前状态，而是**重写历史**。第 65 轮 FIR 做的正是「用新观测重新分配过去故障的后验」；第 66 轮 RAS 把它升级到情绪维度，却仍然只是**时间轴上的事后**。若把风险（λ_risk、H 后验）锚定到地图的位姿节点上，回环闭合就同时完成了两件事：拉直轨迹 + **修正「哪段路曾经危险」的空间归因**。风险第一次获得了可回溯的地址。

**灵感 2（差异化定位 → 不存在唯一的风险坐标系）**
直觉：单一全局地图隐含了一个危险假设——**所有观测者共享同一套位置误差**。但机器人靠 LiDAR、人靠「我离那个柜子大概两步」、环境靠墙上的 marker，三者的误差结构、失效模式、更新频率完全不同。把它们硬融进一张图，等价于用最自信但可能最错的那一路去覆盖其余。RAS 的 λ_risk 也是同一个问题：它把所有人的情绪压成一个标量。**差异化定位**给出的答案不是「融得更狠」，而是「保留分歧、按场景分配权威」：在走廊里信几何，在人旁边信社会方位，在标记前信 fiducial。风险因此不再是一个数，而是**一张带权威标签的图**。

**灵感 3（主动 SLAM → 从情绪探针到空间探针）**
直觉：RAS 的 FAS 会在情绪不确定时主动做探针（转头、眼神接触、微表情）。主动 SLAM 的 next-best-view 是同一件事的空间版本：**移动到哪里看，能让位姿和风险的信息增益最大**。两者其实共享一个目标函数——期望信息增益（expected information gain）。一旦承认这一点，第 66 轮「在情绪维探针」就自然升维成「在 6-DoF 观测位姿上探针」，而探针的成本（时间、暴露、打扰）可以被统一进同一个效用函数。

**灵感 4（回环 ↔ 风险闭环的自指危险）**
直觉：把风险锚到图上、又用图去决定回环，天然形成一条**自指回路**：风险先验参与回环判定 → 回环结果改写位姿 → 位姿又决定风险锚点更新。如果某处风险锚是错的（假警报），它会降低该处的回环接受阈值，使错误地图更容易被「闭合」，从而把假警报永久固化。这不是普通噪声，而是**风险-定位的自我确认（risk-localization self-confirmation）**。所以 PRISM 必须在结构上把「风险似然」和「回环似然」解耦：风险只能作为**查询层的先验**，不得作为**回环几何判定的证据**。

**灵感 5（四灵感合流 → PRISM 六层闭环）**
把 VISTA/RAS 的时序链换装为空间链：
1. **DPG Differentiated Positioning Graph**：几何/语义/社会三层差异化定位图，各自维护 Σ、w，不预先融合；
2. **DPR Differentiated Positioning Reconciliation**：按「定位权威」临时调和出一个工作坐标系，输出调和残差 ρ_pos；
3. **LCF Loop-Closure Fault Attribution**：回环残差 × 语义一致性 × 几何一致性 → H_alias / H_drift / H_map；
4. **RPA Risk-Pose Atlas**：把 λ_risk 与故障后验锚定位姿节点，形成风险场 λ(x,t)；
5. **AVP Active View Probing**：以联合信息增益选下一个观测位姿，替代/扩展现有情绪探针；
6. **RCC Risk-aware Certified Closure**：认证执行前缀不仅满足力/几何/情绪容差，还要让协方差始终留在认证盆地 B_cert 内。

## 1. 形式化定义（增量：定义 245–258）

- **定义 245（PRISM 总览）**：PRISM = (DPG, DPR, LCF, RPA, AVP, RCC, CMF, PAI)。定位：RAS 的「时间域风险闭环」升级为「时空域风险建图闭环」。不变式：地图层分离、风险锚与回环似然解耦、实时流只做位姿外推与锚点查询，零建图写操作。
- **定义 246（差异化定位图 DPG）**：DPG = (V, {E_ℓ}, {Σ_i^ℓ, w_i^ℓ})，ℓ ∈ {geo, sem, soc}。节点 i 表示一个位姿/地标，E_ℓ 为第 ℓ 层边集（几何约束 / 语义共现 / 社会方位），Σ_i^ℓ 为该层局部协方差，w_i^ℓ 为该层可信权重。三层**不共享**误差状态，只共享节点 id。
- **定义 247（定位权威）**：节点 i 的权威向量 `a_i = softmax_ℓ(-½·logdet Σ_i^ℓ + log w_i^ℓ) ∈ Δ^3`。它回答「此刻谁的坐标系说了算」，而不是「谁最准」。
- **定义 248（调和与残差）**：给定各层到工作系的变换 {T_ℓ→0}，`U* = argmin_{T} Σ_ℓ a_i^ℓ·||T_ℓ - T||²_{Σ_i^ℓ}`，调和残差 `ρ_pos(i) = min_T (上式)`。ρ_pos 进入 EFS 的联合似然，但**不进入** LCF 的回环判据。
- **定义 249（回环故障签名）**：回环对 (i,j) 上定义残差 `r_lc = ||T_ij T_ji - I||_{Σ_lc}`、几何一致性 `c_geo`、语义一致性 `c_sem`。判决：
  - `r_lc ≤ τ_lc ∧ c_sem ≥ τ_sem` → H0；
  - `r_lc > τ_lc ∧ c_geo < τ_geo ∧ c_sem ≥ τ_sem` → **H_drift**（几何漂移，语义仍对）；
  - `r_lc > τ_lc ∧ c_geo ≥ τ_geo ∧ c_sem < τ_sem` → **H_alias**（感知别名/假回环）；
  - `r_lc > τ_lc ∧ c_geo < τ_geo ∧ c_sem < τ_sem` → **H_map**（地图污染/共因）。
- **定义 250（风险-位姿地图 RPA）**：风险场 `λ: V × T → (0.5, 1.2)`。锚定更新用核加权遗忘：
  ```
  λ_i(t+1) = (1-η)·λ_i(t) + η·λ_risk(t)·κ(||x_t - x_i||),
  κ(d) = exp(-d² / 2σ_a²)
  ```
  查询用核回归 `λ(x) = Σ_i κ(||x-x_i||)·λ_i / Σ_i κ(||x-x_i||)`。η 是风险遗忘率，σ_a 是空间支持半径。
- **定义 251（可回溯风险重归因算子）**：回环闭合后，对区间 [t_0, t] 内的锚点执行 `λ_i ← λ_i · exp(-μ·r_lc·1[H_drift])`，并同步回写该段故障后验 `P(H | ρ_{t_0:t})`。它是 FIR 的**空间化逆算子**。
- **定义 252（风险感知 Fisher 信息）**：观测位姿 v 下 `I_F(v) = J_v^T Σ_obs^{-1} J_v`；位姿信息增益 `IG_pose(v) = ½ logdet(I + Σ I_F(v))`；风险信息增益 `IG_risk(v) = I(λ_x; z_v)`。
- **定义 253（主动视角探测 AVP）**：`v* = argmax_{v∈C} [IG_pose(v) + μ·IG_risk(v) - c(v)]`，C 为可达观测位姿集，c(v) 为时间/暴露成本。λ 的估计不确定度用锚点有效样本数近似。
- **定义 254（认证协方差盆地与 RCC）**：`B_cert = {Σ : λ_min(Σ) ≥ σ_min² ∧ tr(Σ) ≤ σ_max²}`。认证前缀 `k*` 需满足 `∀s≤k`：(a) `Σ_s ∈ B_cert`；(b) `λ(x_s)·ρ_safe(s) ≥ 0`；(c) `ρ_pos(i_s) ≤ τ_pos`；(d) `k* ≤ m_prism = min(m_VISTA, m_emotion, m_map)`。
- **定义 255（定位歧义指数 PAI）**：`PAI(i) = 1 - max_ℓ a_i^ℓ ∈ [0, 2/3]`。`PAI > τ_amb` 触发差异化降级（切回单层安全模式，不做跨层调和）。
- **定义 256（跨模态地图融合与共因）**：干扰集 `ℰ_PRISM = ℰ_RAS × ℰ_map × ℰ_alias × ℰ_common_map`；`ℰ_common_map` 捕获「一次物理移动同时污染几何层与语义层」的共因（如搬动家具）。
- **定义 257（空间风险一致性）**：对同一物理位置 x 的两次独立访问，`|λ(x,t_1) - λ(x,t_2)| ≤ δ_s` 除非检测到 H_map 或环境变更事件。它是 RPA 的自检不变式。
- **定义 258（J_PRISM 证书）**：`J_PRISM = (J_RAS, pose_covariance, loop_closure_posterior, risk_anchor_version, map_authority) `。Valid ⇔ `Valid(J_RAS) ∧ tr(Σ) ≤ σ_max² ∧ (H_alias = 0) ∧ (PAI ≤ τ_amb ∨ single_layer_safe)`。

## 2. 关键算法骨架

```python
class DifferentiatedPositioningGraph:
    def __init__(self, layers=('geo', 'sem', 'soc')):
        self.layers = layers
        self.nodes = {}                       # id -> node meta
        self.Sigma = {l: {} for l in layers}  # 差异化协方差，绝不预融合
        self.w = {l: {} for l in layers}

    def update(self, node_id, z, layer, H, R):
        # 单层 EKF，禁止跨层回写
        S = H @ self.Sigma[layer][node_id] @ H.T + R
        K = self.Sigma[layer][node_id] @ H.T @ inv(S)
        self.nodes[node_id]['x'] = self.nodes[node_id]['x'] + K @ z
        self.Sigma[layer][node_id] = (I - K @ H) @ self.Sigma[layer][node_id]

    def authority(self, node_id):
        s = {l: -0.5 * logdet(self.Sigma[l][node_id]) + log(self.w[l][node_id])
             for l in self.layers}
        return softmax(s)                     # a_i ∈ Δ^3


class DifferentiatedReconciliation:
    def reconcile(self, dpg, node_id):
        a = dpg.authority(node_id)
        # 按权威加权估计工作系，输出调和残差；不写回任何单层
        T0 = weighted_alignment(dpg, node_id, a)
        rho_pos = sum(a[l] * mahalanobis(dpg, node_id, l, T0)
                      for l in dpg.layers)
        return T0, rho_pos


class LoopClosureAttribution:
    def attribute(self, r_lc, c_geo, c_sem,
                  tau_lc=0.5, tau_geo=0.7, tau_sem=0.7):
        if r_lc <= tau_lc and c_sem >= tau_sem:
            return 'H0'
        if r_lc > tau_lc and c_geo < tau_geo and c_sem >= tau_sem:
            return 'H_drift'
        if r_lc > tau_lc and c_geo >= tau_geo and c_sem < tau_sem:
            return 'H_alias'
        if r_lc > tau_lc and c_geo < tau_geo and c_sem < tau_sem:
            return 'H_map'
        return 'H0'


class RiskPoseAtlas:
    def __init__(self, eta=0.1, sigma_a=0.6):
        self.eta, self.sigma_a = eta, sigma_a
        self.lam = {}                          # node_id -> risk
        self.version = 0

    def anchor(self, x_t, risk_t, dpg):
        for nid, meta in dpg.nodes.items():
            d2 = norm_sq(x_t - meta['x'])
            k = exp(-d2 / (2 * self.sigma_a ** 2))
            if k < 0.05:
                continue
            old = self.lam.get(nid, 1.0)
            self.lam[nid] = (1 - self.eta) * old + self.eta * risk_t * k
        self.version += 1

    def query(self, x):
        num = den = 0.0
        for nid, meta in self.atlas_nodes.items():
            k = exp(-norm_sq(x - meta['x']) / (2 * self.sigma_a ** 2))
            num += k * self.lam.get(nid, 1.0); den += k
        return num / den if den > 1e-9 else 1.0

    def retro_reattribute(self, t0, t1, r_lc, mu=0.3):
        # 回环闭合后拉直历史段的风险锚（定义 251）
        for nid in self.history[t0:t1]:
            self.lam[nid] *= exp(-mu * r_lc)


class ActiveViewProbing:
    def next_best_view(self, candidates, Sigma, risk_uncertainty, cost, mu=0.5):
        best, best_gain = None, -inf
        for v in candidates:
            J = observation_jacobian(v)
            IG_pose = 0.5 * logdet(I + Sigma @ J.T @ inv(obs_noise(v)) @ J)
            IG_risk = mutual_information(risk_uncertainty, v)
            gain = IG_pose + mu * IG_risk - cost(v)
            if gain > best_gain:
                best, best_gain = v, gain
        return best


class RiskCertifiedClosure:
    def certified_prefix(self, A, atlas, Sigma0, m_prism,
                         sigma_min=0.05, sigma_max=0.5, tau_pos=0.3):
        Sigma, k_best = Sigma0, 0
        for k in range(1, min(len(A), m_prism) + 1):
            Sigma = propagate_covariance(Sigma, A[k - 1])
            basin_ok = (lambda_min(Sigma) >= sigma_min ** 2
                        and trace(Sigma) <= sigma_max ** 2)
            risk_ok = atlas.query(A[k - 1].pose) * A[k - 1].rho_safe >= 0
            pos_ok = A[k - 1].rho_pos <= tau_pos
            if basin_ok and risk_ok and pos_ok:
                k_best = k
            else:
                break
        return k_best


def PRISM_round(M, obs):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    # 1) 差异化定位图更新（三层独立）
    nid = M.dpg.add_or_match(x_prime)
    M.dpg.update(nid, P_cloud, 'geo', H_geo, R_geo)
    M.dpg.update(nid, y_vis,    'sem', H_sem, R_sem)
    M.dpg.update(nid, social_pose(img), 'soc', H_soc, R_soc)

    # 2) 差异化调和（只读权威，不跨层回写）
    T0, rho_pos = M.dpr.reconcile(M.dpg, nid)

    # 3) 情绪观测（RAS 保留）
    face_gate = M.er.recognize(img)

    # 4) 回环故障归因（与风险似然解耦！）
    r_lc, c_geo, c_sem = M.lcf.residuals(nid, M.dpg)
    lc = M.lcf.attribute(r_lc, c_geo, c_sem)
    if lc == 'H_drift':
        M.atlas.retro_reattribute(M.t_last_loop, M.t, r_lc)

    # 5) 联合后验：RAS 的 EFS 增加 ρ_pos 与 lc 证据
    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post = M.efs.synthesize(rho, face_gate, rho_pos=rho_pos, lc=lc)
    lam_risk = M.efs.risk_scale(joint_post)

    # 6) 风险锚定到地图
    M.atlas.anchor(x_prime, lam_risk, M.dpg)

    # 7) 定位歧义 → 主动空间探针
    if M.pai(nid) > M.tau_amb:
        v = M.avp.next_best_view(M.reachable_views(), M.dpg.Sigma_cov(nid),
                                 M.atlas.uncertainty_near(x_prime), M.view_cost)
        M.execute_view_probe(v)
        M.dpg.update(nid, *M.reobserve(v)); rho_pos = M.dpr.reconcile(M.dpg, nid)[1]

    # 8) 风险认证前缀（协方差盆地 + 风险场 + 调和残差）
    m_prism = min(M.vista.m, M.er.max_m_emotion, M.dpg.max_m_map)
    k_prism = M.rcc.certified_prefix(A, M.atlas, M.dpg.Sigma_cov(nid), m_prism)

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_prism])
    tau_cmd = tau_cmd * M.atlas.query(x_prime)
    return k_prism, lam_risk, joint_post, lc, M.atlas.version
```

## 3. 推导

**引理 11（风险锚的遗忘界）** 设每步风险估计误差有界 `|λ_risk(t) - λ*| ≤ ε_R`，核权 `κ ≤ 1`。则按定义 250 更新，`|λ_i(t) - λ*|` 收敛到 `(η(ε_R + L_λ) + (1-η)·0)/(1-(1-η))` 量级的上界，即随 `η` 增大而变紧但抖动增大；最优 `η* = O(ε_R/σ_λ)`。含义：**遗忘率必须与风险估计噪声匹配**，否则要么永久固化旧风险，要么每秒重置。

**引理 12（回环重归因降低漂移方差）** 设回环前累积位姿协方差 `Σ_pre`，回环观测信息 `Λ_lc`。闭合后 `Σ_post = (Σ_pre^{-1} + Λ_lc)^{-1}`，故 `tr(Σ_post) ≤ tr(Σ_pre)`，且等号仅在 `Λ_lc = 0`。对风险锚而言，`λ_i` 的后验误差随位姿误差二阶下降。含义：**回环不只修位姿，它给「历史风险归因」提供了一次免费的后验修正**。

**定理 11（PRISM 端到端风险-定位一致性）** 在 A87–A91 与定义 254 的 RCC 条件下，执行前缀满足：
1. `P(Σ_s ∉ B_cert) ≤ α_chunk + α_lc + α_pos`；
2. `λ(x_s)·ρ_safe(s) ≥ 0 ⇒ 实际执行风险 ≤ 设定上限 × 1.2`；
3. 若 `H_alias = 0`，则回环重归因后的空间风险一致性 `|λ(x,t_1)-λ(x,t_2)| ≤ δ_s` 成立。
关键点：条件 1 把 RAS 的「力/几何证书」升级为「不确定度证书」——**认证的是位姿的置信盆地，而不只是动作的安全边界**。

**定理 12（差异化不劣于集中式）** 若三层在给定共享位姿下条件独立，则按权威 a_i 的调和在 KL 意义下满足 `D_KL(p* || q_diff) ≤ D_KL(p* || q_central) + PAI(i)·L`，其中 L 为层间似然比上界。即：**当某一层明显权威时（PAI→0），差异化至少与集中式等价；当三层接近（PAI→2/3），最坏情况的多付代价被 PAI 显式界住**。这为「不强行融合」提供了理论依据，也说明 PAI 是必须进证书的量。

**定理 13（主动视角的次模近似）** 若 `IG_pose` 与 `IG_risk` 关于已选视角集均次模，则贪心 AVP 的累计信息增益 `≥ (1-1/e)·OPT`。这给了 RAS 的「情绪探针」一个可证的最优性下界，并说明探针不必穷举。

```python
# IP-234 DPG：三层独立 EKF，禁止跨层回写
class DifferentiatedPositioningGraph:
    def __init__(self, layers=('geo', 'sem', 'soc')):
        self.layers = layers
        self.nodes = {}
        self.Sigma = {l: {} for l in layers}
        self.w = {l: {} for l in layers}

    def update(self, nid, z, layer, H, R):
        S = H @ self.Sigma[layer][nid] @ H.T + R
        K = self.Sigma[layer][nid] @ H.T @ inv(S)
        self.nodes[nid]['x'] += K @ z
        self.Sigma[layer][nid] = (I - K @ H) @ self.Sigma[layer][nid]

    def authority(self, nid):
        s = {l: -0.5 * logdet(self.Sigma[l][nid]) + log(self.w[l][nid])
             for l in self.layers}
        return softmax(s)


# IP-237 DPR：按权威调和，输出残差，不写回
class DifferentiatedReconciliation:
    def reconcile(self, dpg, nid):
        a = dpg.authority(nid)
        T0 = weighted_alignment(dpg, nid, a)
        rho_pos = sum(a[l] * mahalanobis(dpg, nid, l, T0) for l in dpg.layers)
        return T0, rho_pos


# IP-236 LCF：回环故障归因（风险似然不参与判定）
class LoopClosureAttribution:
    def attribute(self, r_lc, c_geo, c_sem,
                  tau_lc=0.5, tau_geo=0.7, tau_sem=0.7):
        if r_lc <= tau_lc and c_sem >= tau_sem: return 'H0'
        if r_lc > tau_lc and c_geo < tau_geo and c_sem >= tau_sem: return 'H_drift'
        if r_lc > tau_lc and c_geo >= tau_geo and c_sem < tau_sem: return 'H_alias'
        if r_lc > tau_lc and c_geo < tau_geo and c_sem < tau_sem: return 'H_map'
        return 'H0'


# IP-235 RPA：风险锚 + 查询 + 回环重归因
class RiskPoseAtlas:
    def __init__(self, eta=0.1, sigma_a=0.6):
        self.eta, self.sigma_a = eta, sigma_a
        self.lam, self.history, self.version = {}, [], 0

    def anchor(self, x_t, risk_t, dpg):
        for nid, meta in dpg.nodes.items():
            k = exp(-norm_sq(x_t - meta['x']) / (2 * self.sigma_a ** 2))
            if k < 0.05: continue
            self.lam[nid] = ((1 - self.eta) * self.lam.get(nid, 1.0)
                             + self.eta * risk_t * k)
        self.history.append(list(self.lam.keys())); self.version += 1

    def query(self, x):
        num = den = 0.0
        for nid, meta in self.atlas_nodes.items():
            k = exp(-norm_sq(x - meta['x']) / (2 * self.sigma_a ** 2))
            num += k * self.lam.get(nid, 1.0); den += k
        return num / den if den > 1e-9 else 1.0

    def retro_reattribute(self, t0, t1, r_lc, mu=0.3):
        for nid in set(sum(self.history[t0:t1], [])):
            self.lam[nid] *= exp(-mu * r_lc)


# IP-238 AVP：next-best-view，贪心近似
class ActiveViewProbing:
    def next_best_view(self, candidates, Sigma, risk_unc, cost, mu=0.5):
        best, best_gain = None, -inf
        for v in candidates:
            J = observation_jacobian(v)
            IG_pose = 0.5 * logdet(I + Sigma @ J.T @ inv(obs_noise(v)) @ J)
            gain = IG_pose + mu * mutual_information(risk_unc, v) - cost(v)
            if gain > best_gain: best, best_gain = v, gain
        return best


# IP-239 RCC：协方差盆地 + 风险场 + 调和残差
class RiskCertifiedClosure:
    def certified_prefix(self, A, atlas, Sigma0, m_prism,
                         sigma_min=0.05, sigma_max=0.5, tau_pos=0.3):
        Sigma, k_best = Sigma0, 0
        for k in range(1, min(len(A), m_prism) + 1):
            Sigma = propagate_covariance(Sigma, A[k - 1])
            basin_ok = (lambda_min(Sigma) >= sigma_min ** 2
                        and trace(Sigma) <= sigma_max ** 2)
            risk_ok = atlas.query(A[k - 1].pose) * A[k - 1].rho_safe >= 0
            pos_ok = A[k - 1].rho_pos <= tau_pos
            if basin_ok and risk_ok and pos_ok: k_best = k
            else: break
        return k_best


# IP-243 PRISM 闭环
def PRISM_round(M, obs):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    M.lsf.update_geometry(P_cloud)
    x_prime = M.lsf.fuse(M.usr.fuse(V, T, P, L))
    y_vis = M.f_vis(img, depth, flow)

    nid = M.dpg.add_or_match(x_prime)
    M.dpg.update(nid, P_cloud, 'geo', H_geo, R_geo)
    M.dpg.update(nid, y_vis, 'sem', H_sem, R_sem)
    M.dpg.update(nid, social_pose(img), 'soc', H_soc, R_soc)

    T0, rho_pos = M.dpr.reconcile(M.dpg, nid)
    face_gate = M.er.recognize(img)

    r_lc, c_geo, c_sem = M.lcf.residuals(nid, M.dpg)
    lc = M.lcf.attribute(r_lc, c_geo, c_sem)
    if lc == 'H_drift':
        M.atlas.retro_reattribute(M.t_last_loop, M.t, r_lc)

    A = M.vista.ach.propose(x_prime, H=M.vista.H)
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    joint_post = M.efs.synthesize(rho, face_gate, rho_pos=rho_pos, lc=lc)
    lam_risk = M.efs.risk_scale(joint_post)
    M.atlas.anchor(x_prime, lam_risk, M.dpg)

    if M.pai(nid) > M.tau_amb:
        v = M.avp.next_best_view(M.reachable_views(), M.dpg.Sigma_cov(nid),
                                 M.atlas.uncertainty_near(x_prime), M.view_cost)

        M.dpg.update(nid, *M.reobserve(v))
        rho_pos = M.dpr.reconcile(M.dpg, nid)[1]

    m_prism = min(M.vista.m, M.er.max_m_emotion, M.dpg.max_m_map)
    k_prism = M.rcc.certified_prefix(A, M.atlas, M.dpg.Sigma_cov(nid), m_prism)

    tau_cmd = M.vista.pi_sigma.prefix_dispatch(A[:k_prism])
    tau_cmd = tau_cmd * M.atlas.query(x_prime)
    return k_prism, lam_risk, joint_post, lc, M.atlas.version
```

## 4. 推导

**引理 11（风险锚遗忘界）** 设 `|λ_risk(t) − λ*| ≤ ε_R`、`κ ≤ 1`，则 `|λ_i(t) − λ*| ≤ η(ε_R + L_λ)/(1−|1−η|)` 量级；最优遗忘率 `η* = O(ε_R/σ_λ)`。含义：**遗忘必须与估计噪声匹配**，否则不是固化旧风险就是每秒重置。

**引理 12（回环重归因降低漂移方差）** `Σ_post = (Σ_pre⁻¹ + Λ_lc)⁻¹`，故 `tr(Σ_post) ≤ tr(Σ_pre)`，等号仅当 `Λ_lc=0`；风险锚的后验误差随位姿误差二阶下降。含义：**回环给「历史风险归因」提供一次免费的后验修正**。

**定理 11（PRISM 端到端风险-定位一致性）** 在 A87–A91 与 RCC 条件下：
1. `P(Σ_s ∉ B_cert) ≤ α_chunk + α_lc + α_pos`；
2. `λ(x_s)·ρ_safe(s) ≥ 0 ⇒ 实际执行风险 ≤ 设定上限 × 1.2`；
3. 若 `H_alias = 0`，则 `|λ(x,t_1) − λ(x,t_2)| ≤ δ_s` 成立。
关键：证书认证的是**位姿置信盆地**，不只是动作安全边界。

**定理 12（差异化不劣于集中式）** 若三层在给定共享位姿下条件独立，则
```
D_KL(p* ‖ q_diff) ≤ D_KL(p* ‖ q_central) + PAI(i)·L
```
当某层明显权威（PAI→0）时差异化至少与集中式等价；当三层接近（PAI→2/3）时最坏多付代价被 PAI 显式界住。这为「不强行融合」提供理论依据。

**定理 13（主动视角次模近似）** 若 `IG_pose` 与 `IG_risk` 关于已选视角集次模，则贪心 AVP 的累计信息增益 `≥ (1−1/e)·OPT`。探针不必穷举即可近优。

## 6. 本轮最大风险

**一句话**：PRISM 让「风险」与「位置」互相定义——风险锚参与观测与认证，观测与认证又反过来更新风险锚与地图；一旦某处风险锚是错的，它会降低该处的回环接受门槛、把错误地图「闭合」得更牢，从而把一次误判固化为永久的空间偏见，形成**风险-定位自确认回路**；这是本轮所有理论依赖的核心假设：**风险似然与回环几何似然可被结构性地严格解耦，且差异化权威不会系统性放大最自信却最错的那一层**。

**次级风险与缓解**：
1. **自指固化**：LCF 回环判定禁用 λ 先验；每 N 次回环做一次「去风险先验」的独立重定位；E259 专测；
2. **权威误配**：PAI 超阈时退化为单层安全模式；权威向量带时间滞回，避免抖动切换；
3. **地图污染共因**：引入环境变更检测（家具位移、光照突变）作为 H_map 触发；风险锚整段失效重估；
4. **风险记忆过时**：η 自适应于估计噪声（引理 11）；环境变更事件强制 `λ ← 1.0`；
5. **算力与内存**：三层图分频更新（几何 30Hz / 语义 5Hz / 社会 2Hz），锚点稀疏化（< 1 节点/m²），AVP 贪心而非穷举。
