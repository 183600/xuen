# 第 44 轮（新循环第 4 轮） · Curriculum-Intent-Cert：把「课程学习」与「意图识别」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v8（Persona-Cert × Concurrent-Cert）。v8 自陈最大风险是「共形只保边际覆盖 + 多用户契约求交为空」。但 v8 仍压着两个未言明的单点假设：**(G1) 校准数据是外生、被动、给定的**——它假设总有足够多「已识别、已校准」的用户与交互样本，却没说这些样本从哪来；冷启动用户没有校准集，共形覆盖无从谈起，只能永远退回纯收缩。**(G2) 意图是某一时刻的标签/集合，识别质量用分类指标衡量**——它假设 h_t 是静态标签，而真实意图是**有时间承诺的**（持续、抢占、撤销、超时），且「识别得准」不等于「行动得安全」。本轮灵感词「课程学习」「意图识别」精确命中这两个假设：**课程学习**把「校准数据的产生」从被动等待提升为**主动设计**——课程不是教学技巧，而是**证书的增长顺序**；**意图识别**把「意图」从标签提升为**带时间承诺、且只需在动作商上可辨**的证书对象。二者耦合处是本轮真正的新问题：课程会**改变校准分布**，使条件覆盖「自证成立」却在部署分布上失效；意图-动作商可能把危险不同的意图**并入同一格**而静默放行。

## 0. 直觉与动机

**灵感 1（课程学习 → 「课程即证书的增长顺序」）**：直觉上，课程学习是「先易后难」。但在安全关键机器人里，「难」意味着高风险，不能靠失败来学习。于是把它反过来：**课程是一串被证书门控的操作包络 E_0⊆E_1⊆…**，每一阶段只在「已认证安全 + 覆盖达标 + 有兜底策略」时才允许进入下一阶段；难度不由「任务多难」定义，而由**意图歧义度**定义——模型越不确定（共形集越宽、跨动作商格越多），越「难」。这样课程不是「让学生犯错」，而是「在兜底的保护下，按最省样本的顺序把可认证区域撑大」。一句话：**普通课程用难度排序样本，我们的课程用「证书可扩张性」排序样本。**

**灵感 2（意图识别 → 「意图不是标签，是带承诺、且只需动作可辨的证书对象」）**：用户说「去厨房」，这不是一帧分类，而是一个**承诺**：持续到完成/撤销；「停」是**抢占**，必须在截止期内覆盖一切。因此把意图建模为**承诺自动机**上的信念集合，而不是点标签。更关键的是：机器人不需要知道用户到底想什么，只需要知道**在动作商意义下**该怎么动。若整个共形集诱导出相同的安全动作集，就无需进一步澄清——识别问题被**商掉**（quotient）了。这既降低了对识别精度的要求，又给出可证明的安全判据：只要共形集不跨危险商格，或鲁棒动作交集非空，就能安全行动；否则触发**澄清**而非猜测。

**灵感 3（耦合 → 课程主动校准 × 意图歧义信号，形成闭环）**：意图识别天然给出「难度信号」：共形集宽度、跨商格数、时序不一致率。课程编排器用这个信号决定「下一次该采集哪种交互」；采集到的样本又用于分层共形校准，缩小歧义、提高条件覆盖、赚取信任预算，进而扩张包络。闭环为：**意图歧义 → 课程选样 → 分层校准 → 覆盖达标 → 包络扩张 → 更难意图进入覆盖范围**。但闭环的阴暗面正是本轮红线：课程自己选样本，会诱导出与部署不同的分布，覆盖可能**只对课程成立**。

**耦合升级**：ICE（意图承诺引擎）把意图编译为承诺自动机 + 动作商证书 + 意图租约；CCO（课程证书编排器）用歧义信号驱动分层主动校准与包络门控；CIV（课程-意图验证器）审计部署偏移、商健全性与时序承诺。四层架构由 v8「人格契约 + 并发证书」升级为 v9「人格契约 + 并发证书 + **课程-意图-承诺层**」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（意图承诺自动机与轨迹级信念）**：潜在意图承诺自动机 M=(Q, U, δ, q_0, O, T_ov)：Q 为有限承诺状态（目标、避让、停止、跟随、让行…），U 为用户指令，δ: Q×U → 2^Q 为（因语言歧义而非确定的）转移，O⊆Q 为抢占态（停/让），T_ov 为抢占截止期。识别器在观测史 o_{0:t} 上输出信念集合 Q̂_t⊆Q（或 B_t⊆Δ(Q)）。**承诺视野** H_t={q_{t:t+H} : q_t∈Q̂_t, q_{τ+1}∈δ(q_τ,u_τ)}。**时序覆盖**要求 P(q_{t:t+H}∈H_t)≥1−α，而**不是**逐步集合相乘——逐步 (1−α)^H 会掉覆盖，必须做轨迹级共形（定义 47）。

**定义 45（意图-动作商与鲁棒可执行性）**：给定安全集 S，意图 q 在状态 x 下的安全动作集 A_safe(x,q)={a : f(x,a,q)∈S}。**鲁棒动作集** I_robust(x,Q̂)=∩_{q∈Q̂} A_safe(x,q)。定义等价关系 q≈q′ ⟺ ∀x∈E（当前操作包络），A_safe(x,q)=A_safe(x,q′)；商空间 Q/≈ 称为**意图-动作商**。**歧义宽度** ω(Q̂)=|{σ∈Q/≈ : σ∩Q̂≠∅}|。**动作可认证识别**：若 ω(Q̂)≤1 或 I_robust(x,Q̂)≠∅，则识别「对该动作已足够」；否则必须澄清或协商。**非对称误差**：不安全接受（把危险意图并入安全格）记为 R_fa，过度澄清（可用性损失）记为 C_fr；安全约束要求 P(R_fa)=0，仅在 C_fr 上做优化。

**定义 46（证书门控课程）**：课程 C={(s_k,D_k,E_k,g_k)}_{k=0..K}：D_k 为阶段 k 的校准交互分布，E_k 为操作包络（单调 E_k⊆E_{k+1}），g_k 为门控。转移 k→k+1 可采纳当且仅当：
(1) **覆盖**：∀ 层 σ⊆E_{k+1}，D_k 上的条件覆盖（按部署权重，定义 48）≥1−α；
(2) **影子**：E_k 上影子证书零违例；
(3) **兜底**：存在已认证兜底策略 π_fb 在 E_{k+1}\E_k 上风险 ≤ τ_k（下行有界）；
(4) **预算**：τ_{k+1}=clip(τ_k+β·IG_k−γ·Risk_k, 0,1) ≥ 0。
**难度** d(σ)=E[ω(Q̂)|σ]·risk_weight(σ)。采用**兜底锚定的最难安全优先**：在「失败可被 π_fb 吸收」的前提下优先采集歧义最大的层（信息量最大），否则退化为最易优先（先积累信任）。

**定义 47（分层条件覆盖与课程主动校准）**：分层 S=P×(Q/≈)×Ctx（人格 × 意图商格 × 上下文域）。对每层 σ 维护校准多重集，Mondrian 共形给出**条件覆盖** ≥1−α 需 n_σ≥n_min 且经验误覆盖 ≤α−δ_n。**可认证区域** R_α={σ : 条件覆盖达标}。课程即**在样本/风险预算下最大化 |R_α|（或覆盖质量）**的主动分配问题（分层 bandit：臂=层，回报=覆盖增量，成本=样本+信任消耗）。**轨迹级共形**：对整条意图轨迹定义非一致性分数，或用序贯共形鞅，避免逐步乘积掉覆盖。部署锚层（canary）始终按部署分布采样，用于定义 48 的偏移估计。

**定义 48（课程—部署偏移下的加权覆盖）**：课程分布 P_cur 与部署分布 P_dep 一般不同；共形可交换性只对校准分布成立。设密度比 w=dP_dep/dP_cur，若 w∈[w_min,w_max] 已知，则**加权共形**分位数给出 P_dep 下覆盖 ≥1−α；若只有估计 ŵ 且 sup|ŵ−w|≤ε_w，则覆盖 ≥1−α−Δ_shift(ε_w,ρ)，其中 ρ 为锚层估计的 TV 距离上界。**命题（保守版）**：ρ=0（同分布）退化为标准共形；当 ρ>ρ_max 或所需 w_max 使有效样本发散时，禁止扩张。E95 为红线：必须在**部署 holdout** 上测覆盖，而非在课程分布上测。

**定义 49（信任预算动力学与自融资课程）**：信任预算 τ∈[0,1] 是「允许承担多少未认证探索」的资源。扩张消耗 τ，认证成功回补 τ；τ=0 时强制纯收缩 + 主动澄清。**自融资条件**：存在兜底 π_fb 使探索阶段**最坏额外风险 ≤ τ_k**（下行有界），且单位风险的信息增益 E[IG]/E[Risk]≥θ_ig。**安全命题（有界破产）**：若每阶段均满足定义 46(3) 且 τ 不可为负，则课程学习期间违例概率有上界，且 τ_k=0 时退化为永不失效的纯收缩底线——即「学习可以失败，但失败被兜底吸收」。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CURRICULUM-CERT-ORCHESTRATOR（课程证书编排器 CCO）
1. **课程生成**：由可认证区域 R_α、歧义地图、τ 生成阶段序列（兜底锚定最难安全优先）。
2. **四重门控**：覆盖 / 影子零违例 / 兜底存在 / 预算非负；任一失败即回滚阶段、冻结包络。
3. **主动校准分配**：分层 bandit 选样；部署锚层 canary 持续估计偏移 ρ。
4. **偏移熔断**：ρ>ρ_max 或加权覆盖跌破 → τ→0、关闭扩张、退回纯收缩。

### 2.2 IP-61 INTENT-COMMITMENT-ENGINE（意图承诺引擎 ICE）
1. **承诺自动机**：语言/动作/凝视多模态 → 信念集合 Q̂_t；支持持续、抢占、撤销、超时。
2. **动作商证书**：计算 A_safe、I_robust 与商格；ω≤1 或 I_robust≠∅ 才放行。
3. **澄清触发**：当 I_robust=∅ 且澄清期望风险 < 盲动风险时，生成最小澄清问题（与 IP-57 协商接口对接）。
4. **意图租约**：意图带持久度与抢占截止期，纳入 IP-58 租约表；超时/抖动即降级。
5. **轨迹级共形**：对承诺轨迹做共形/序贯校准，避免逐步相乘掉覆盖。

### 2.3 IP-62 CURRICULUM-INTENT-VALIDATOR（课程-意图验证器 CIV）
1. **部署偏移审计**：在部署 holdout / 锚层上测条件覆盖，检测「自证式覆盖」。
2. **商健全性检查**：枚举意图对，验证 q≈q′ 不把安全动作集不同的意图合并（反例搜索）。
3. **时序承诺 fuzz**：意图抖动、延迟抢占、陈旧意图、撤销丢失。
4. **课程反事实回放**：比较课程分布与部署分布的动作/风险差异，生成课程回归集。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| E99 课程学习安全 | 学习期违例；兜底触发率；阶段回滚次数 | 0；有界；可解释 |
| E100 信任预算 | 破产率；自融资比；非预期收缩率 | 0；≥θ_ig；<5% |
| E101 对抗偏移/投毒 | 覆盖崩塌检出率；误扩张；恢复时延 | ≥95%；0；<30s |
| E102 长时程课程+漂移 | 100h 不安全事件；persona/意图漂移检出；课程扩张次数 | 0；≥95%；≥20 |

回退：E95 不达标 → 关闭课程扩张，只用部署同分布样本；E97 商不健全 → 商格细化为最保守（退化为逐意图）；E98 时序失效 → 缩短承诺视野 H 并强制频繁澄清；E99/E100 不达标 → 停止探索、纯收缩；任何红线失败 → 熔断回退 v8。

## 5. 本轮最大风险

**一句话**：课程自己选择校准分布，会让条件覆盖在**课程分布**上「自证成立」却在**部署分布**上失效（自证式覆盖），叠加意图-动作商可能把安全动作不同的意图并入同一格（商坍缩），二者相乘会出现「学得越好、证书越漂亮、却越危险」的静默失效——因此 E95（部署 holdout 覆盖）与 E97（商健全性）必须设为红线，并默认回退到「纯收缩 + 逐意图保守 + 串行安全监控」的永不失效底线。

### IP-61 ICE：承诺信念、动作商与意图租约

```
def intent_belief(obs_hist, automaton, alpha, persona_id):
    Q_hat = conformal_intent_states(obs_hist, alpha, persona_id)  # Mondrian 分层
    Q_hat = automaton.sigma_constrain(Q_hat)       # 语言歧义 -> 2^Q
    H     = automaton.rollout(Q_hat, horizon=H_commit)
    H     = trajectory_conformal(H, alpha)          # 轨迹级，非逐步乘积
    return Q_hat, H

def action_quotient_cert(x, Q_hat, safe_set, envelope):
    cells   = {quotient_cell(q, x, envelope) for q in Q_hat}   # q ~ q'
    omega   = len(cells)
    I_rob   = intersect_all(A_safe(x, q, safe_set) for q in Q_hat)
    if omega <= 1 or I_rob:
        return Certified(I_rob if I_rob else A_safe_union(x, cells))
    if expected_risk(blind_action(x)) > clarification_cost(Q_hat):
        return Clarify(minimal_disambiguating_question(Q_hat))
    return FallbackOrStop()                          # 空集绝不静默放行

def intent_lease(q_hat, t, persistence, T_ov):
    return IntentLease(q_hat, tau=t, survive_until=t+persistence,
                       override_deadline=t+T_ov)

def trajectory_conformal(trajs, alpha):
    scores = [nonconformity(t) for t in calib_trajs]
    qhat   = quantile(scores, 1 - alpha)
    return {t for t in trajs if nonconformity(t) <= qhat}
```

### IP-60 CCO：证书门控课程与偏移熔断
```
def next_stage(R_alpha, ambiguity_map, tau, rho, rho_max):
    if tau <= 0 or rho > rho_max:
        return FREEZE_AND_CONTRACT()                 # 熔断：纯收缩
    strata = sort_by(ambiguity_map, key=difficulty, descending=True)
    for sigma in strata:
        if fallback_certified(sigma) and risk(sigma) <= tau:
            return SampleStage(sigma)                # 兜底锚定最难安全优先
    return EasiestSafeStage()                        # 否则先积累信任

def gate(k, D_k, E_k, E_next, shadow, fallback, tau_k, P_dep):
    cov_ok = all(weighted_coverage(D_k, sigma, alpha, P_dep) >= 1 - alpha
                 for sigma in strata(E_next))
    shadow_ok   = shadow.zero_violation(E_next)
    fallback_ok = fallback.risk(E_next - E_k) <= tau_k
    tau_next    = clip(tau_k + beta*info_gain(D_k) - gamma*risk(D_k), 0, 1)
    return (cov_ok and shadow_ok and fallback_ok and tau_next >= 0), tau_next

def weighted_conformal(scores, weights, alpha):
    # 加权分位数：在 w 已知且支撑重叠时给出 P_dep 覆盖
    order = argsort(scores)
    W     = cumsum(weights[order]); W /= W[-1]
    return scores[order][searchsorted(W, 1 - alpha)]
```

### IP-62 CIV：商健全性、部署偏移与时序 fuzz

```
def quotient_soundness_check(Q, safe_set, envelope):
    for q1, q2 in pairs(Q):
        if same_quotient(q1, q2) and \
           exists_x(envelope, A_safe(x,q1) != A_safe(x,q2)):
            return Counterexample(q1, q2, x)          # 危险合并 -> 细化商
    return OK

def deployment_shift_audit(anchor_stats, alpha, rho_max):
    rho     = tv_estimate(anchor_stats.P_cur, anchor_stats.P_dep)
    cov_dep = empirical_coverage(anchor_stats.holdout, alpha)
    return Audit(rho=rho, coverage=cov_dep,
                 fuse=(rho > rho_max or cov_dep < 1 - alpha))

def commitment_fuzz(automaton, T):
    # 抖动 / 延迟抢占 / 陈旧意图 / 撤销丢失
    for trace in enumerate_temporal_attacks(T):
        if automaton.override_latency(trace) > T_ov or automaton.stale_use(trace):
            yield Counterexample(trace)
```

```
def car_transition_guard(e, x, cert_obj, persona, intent_lease, lease, t):
```

## 6. 本轮最大风险

**一句话**：课程自己选择校准分布，会让条件覆盖在**课程分布**上「自证成立」却在**部署分布**上失效（自证式覆盖），叠加意图-动作商可能把安全动作不同的意图并入同一格（商坍缩），二者相乘会出现「学得越好、证书越漂亮、却越危险」的静默失效——因此 E95（部署 holdout 覆盖）与 E97（商健全性）必须设为红线，并默认回退到「纯收缩 + 逐意图保守 + 串行安全监控」的永不失效底线。
