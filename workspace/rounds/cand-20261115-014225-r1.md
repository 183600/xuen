# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「状态机」×「目标检测」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric / epistemic，用流匹配显式表示多峰动作，再用注视、探针、问句去购买信息。但 R69 的「问」是**无记忆、无对象身份**的：每一轮都从流采样重新聚出匿名模态，付一次 VoI，然后忘掉；它从不问「我上一轮问的是不是同一个东西」「那个回答在对象被遮挡、轨迹断裂、ID 交换之后还作不作数」。于是 R69 的两种典型失败都不是「问错话」，而是**问错了对象、或把旧证据记到了新对象头上**。
>
> 本轮两个灵感正好补上这条时间轴：
> - **目标检测**不是「又一个模态」，而是**对象假设的出生—维持—死亡过程**：检测器真正输出的不是类别标签，而是带存在概率、身份、遮挡状态、开放集未知槽的轨迹。它把 R69 的匿名模态 `m_k` 绑定到一个可被重识别的 `track id`。
> - **状态机**不是「又一层控制器」，而是**跨时间的认知承诺与协议**：状态表示「我现在相信什么」，守卫表示「凭什么允许改变相信」，不变量表示「永远不许发生什么」，滞回/驻留表示「不许抖」，而 Zeno 行为正是 R69 那种「无限追问、反复横跳」的病。
>
> 核心命题：**消歧必须绑定到对象轨迹，并由显式的认知状态机承载；证据必须按「溯源 + 新颖性」折减时间相关性，身份提升必须通过多通道一致性证书，负证据必须在检测覆盖锥内才有效；任一守卫失败就降级/退休并退回 R69，而不是让状态记忆把一次错误固化成永久「已验证」。** 命名 **TEMPEST-RAS**（Track-bound Epistemic Machine with Persistent Evidence and Safe Transitions）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我要求证的那个东西，还是同一个对象吗？我上一次的求证，现在还作数吗？**」——不确定性不仅有形状、有收件人，还有**寿命和身份**。

## 0. 直觉与动机

**灵感 1（目标检测 → 对象是有寿命的假设，不是一帧标签）**
直觉：R69 的模态是从当前观测临时聚出来的，像每次提问都重新认一遍人。但真实世界里的消歧对象是**持续的**：杯子可能在桌沿、被手挡住、被拿起、又放下；人可能走出视野再回来；检测器会漏检、会误检、会把两个相邻物体粘成一条轨迹、也会在遮挡后把 ID 换给另一个物体。目标检测真正提供的不是 `class=cups`，而是 `track τ_i`：存在概率 `e_i`、外观嵌入 `a_i`、位姿与协方差、遮挡状态、以及「未知但真实」的开放集槽。把模态绑到轨迹上，R69 的「追问幻影」才第一次有了可检验的指称对象：**要么这个 track 存在且身份自洽，要么它根本不配被追问**。

**灵感 2（状态机 → 认知承诺需要守卫、驻留与逃逸门）**
直觉：R69 的每个决策都是一次性的；但「我已经确认过」「我正在怀疑」「它被挡住了」「它回来了但可能换了个 ID」这些是**状态**，不是每轮重算的标量。状态机给出四样 R69 没有的东西：(i) **记忆**——同一个歧义不重复购买；(ii) **守卫**——提升到「已验证」需要什么证据，而不是 posterior 一过阈值就跳；(iii) **滞回与驻留**——防止在边界上抖动、防止无限追问（Zeno）；(iv) **逃逸门**——`VERIFIED → CONTRADICTED/OCCLUDED`，让记忆可以被证伪。没有 (iv) 的记忆不是记忆，是偏见。

**灵感 3（最危险的病理：证据重复计数与 ID 交换）**
直觉：R69 的证据纪律假设「k 个来源正交」，但在时间轴上，同一个物体连续 30 帧的检测**不是 30 个独立证据**，它们共享同一个遮挡、同一个光照、同一次标定误差。更糟的是，轨迹会碎片化/合并/交换：本来属于 A 的证据被记到 B 头上，B 于是「被验证」了。**状态机会把这种错误从一次性错误升级为持久错误**：`VERIFIED` 一旦写错，后面每轮都少花一次 VoI 去问，错误反而更「省钱」。所以本轮必须同时交付：证据溯源 DAG、有效样本数 `n_eff`、新颖性门、身份一致性证书、以及 `VERIFIED` 的强制逃逸路径。

**灵感 4（检测是不对称的：没看到 ≠ 不存在）**
直觉：目标检测的漏检率随距离、遮挡、视角剧烈变化。R69 若把「没有检测到」当成「对象不存在」，就会把真实障碍物退休掉——这是比追问幻影更致命的安全错误。正确做法是**覆盖感知的负证据**：只有在检测器标定覆盖锥内、且漏检率低于阈值的「没看到」才算负证据；覆盖不到的地方，沉默不含信息。开放集未知物体也必须有一个显式状态（`UNKNOWN_REAL`：不知道是什么，但它真实存在，按安全包络避让），而不是被塞进某个已知类或直接被丢掉。

**灵感 5（记忆是双刃剑 → 严格包含 R69，且保留纠错）**
直觉：滞回防止抖动，但也可能把一次 ID 混淆锁死。因此本轮的理论姿态不是「状态机替代 R69」，而是：**在单轨迹、身份已知、全覆盖、无遮挡、驻留=1 的投影下，TEMPEST 逐指令退化为 R69 的每轮 VoI**；同时在非退化情形下，TEMPEST 只允许通过「带证书的转移」获得效率收益，任何守卫失败都单调退回 R69 保守。**R69 是 TEMPEST 的「无记忆切片」；TEMPEST 是 R69 的「有时间、有身份、可纠错」的严格泛化。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TEMPEST-RAS 总览）** TEMPEST-RAS = (OTT, TEA, EPN, CEN, IDC, HYS, RGL, OPN, TLC, RAS-WM†)。五不变式：
(i) **指称绑定**：每个 epistemic 决策必须绑定到某个轨迹 `τ_i`，或显式标注 `UNBOUND`；不存在匿名模态决策；
(ii) **禁止单次提升**：进入 `VERIFIED` 需同时满足 IDC、`k_eff ≥ 2`、驻留 `n_min`；
(iii) **证据不重复计数**：证据只能经溯源 DAG 与新颖性门进入后验，同一事件/同一轨迹碎片的相关观测按 `n_eff` 折减；
(iv) **Zeno-free 与交互有界**：驻留与冷却为正 ⇒ 任意有限时域内转移数有限、交互次数有界；
(v) **单调退避**：任一守卫失败 ⇒ 降级/退休/未消解 ⇒ 退回 R69 保守；安全侧永不弱于 R69。

**定义 311（对象轨迹表 OTT）** 时刻 `t` 的轨迹表 `𝒯_t = {τ_i} ∪ 𝒰_t`。每条轨迹
`τ_i = (id_i, B_i, e_i, a_i, χ_i, ℋ_i, o_i, P_i)`，
其中 `B_i` 为位姿/包围体及协方差 `Σ_i`，`e_i ∈ [0,1]` 为存在后验，`a_i` 为外观嵌入，`χ_i` 为类别/属性后验，`ℋ_i` 为轨迹绑定的模态假设集，`o_i ∈ {visible, partial, occluded, lost}` 为遮挡状态，`P_i` 为溯源根集合。`𝒰_t` 为未绑定检测的暂存槽。轨迹按生存模型出生/死亡。

**定义 312（轨迹绑定假设与参考不确定性）** 轨迹绑定假设 `h = (i, m)`，后验
`p(h | o_{1:t}) = p(τ_i | o_{1:t}) · p(m | τ_i, o_{1:t})`。
关联矩阵 `A ∈ [0,1]^{N_d × N_t}`（软关联）。定义**参考不确定性** `U_ref = H(A | o_{1:t})`。则
`U_epi = U_ref + Σ_i p(τ_i) · U_epi,i`，`U_ale = Σ_i p(τ_i) · U_ale,i`。
关键：`U_ref` 不能靠「问类别」消解，只能靠外观/几何/时序/交互溯源消解；把 `U_ref` 混进 `U_epi` 会让系统去问一个「对象尚未确定」的问题。

**定义 313（轨迹认知状态机 TEA）** 每条轨迹一个自动机 `𝒜_i = (Q, E, δ, q_0, G)`，状态
`Q = {UNBOUND, CANDIDATE, CONTESTED, VERIFIED, OCCLUDED, CONTRADICTED, RETIRED}`。
- `UNBOUND → CANDIDATE`：存在概率 `e_i > τ_e` 且获得关联；
- `CANDIDATE → CONTESTED`：模态未消解或证据冲突；
- `CANDIDATE/CONTESTED → VERIFIED`：IDC 通过 ∧ `k_eff ≥ 2` ∧ 驻留 ∧ 残余 `U_epi ≤ τ_epi`；
- `VERIFIED → CONTRADICTED`：出现与当前模态/身份不相容的独立证据；
- `VERIFIED → OCCLUDED`：遮挡/丢失超过 `τ_occ`；
- `OCCLUDED → CANDIDATE`：重现且通过重识别（**绝不直接回 VERIFIED**）；
- `CONTRADICTED → CANDIDATE/RETIRED`：重探针成功 / 证伪为幻影；
- 任意状态 `→ RETIRED`：死亡、过期、或后悔账本越界且不可解。
转移守卫 `G` 同时包含 TLC 监视器（定义 321）。

**定义 314（证据溯源 DAG 与有效样本数）** 每个证据事件 `e = (src, t, τ, parents)`，按共享根/时间窗/重叠度构建溯源 DAG。等价类 `e ~ e'` 当且仅当共享溯源根或相似度超过阈值。对等相关的 `n` 次观测（相关系数 `ρ ∈ [0,1)`），定义
`n_eff = n / (1 + (n − 1)ρ)`，`k_eff = (Σ_r w_r)² / Σ_r w_r²`（Kish 有效样本数，`w_r` 为各独立根权重）。
后验更新只使用 `n_eff`，且 `k_eff` 是提升到 `VERIFIED` 的证据计数。系：`ρ→1` 时 `n_eff→1`，**再多的重复帧也无法完成提升**。

**定义 315（新颖性门 EPN）** 证据新颖度 `ν(e) = 1 − max_{e' ∈ P_i} sim(e, e')`。仅当 `ν(e) ≥ ν_min` 才计入独立证据；低新颖度证据可以更新连续量（如位置平滑），但**不得作为提升票**，也不得增加 `k_eff`。

**定义 316（覆盖感知负证据 CEN）** 检测器标定给出 `p_det(x; τ_i)` 与漏检率 `p_miss(x; τ_i)`（距离/遮挡/视角的函数）。只有落在覆盖锥 `C_t = {x : p_miss(x) ≤ τ_miss}` 内的「未检测到」才作为负证据更新 `e_i`；覆盖外视为无信息（似然比 = 1）。定义安全侧存在下界 `e_i^-`，`e_i < τ_e` 方可退休；未知真实物体转入 `UNKNOWN_REAL`，不因「没分类」而被删除。

**定义 317（身份一致性证书 IDC）** 提升到 `VERIFIED` 需至少 `k_id = 3` 个条件独立通道同时一致：外观 `a_i`、几何/运动学 `B_i`、交互溯源 `p_i`（回答只在指代该轨迹时语义成立）、时序连续性 `c_i`。身份交换风险 `r_swap(τ_i, τ_j) = P(同一物理对象被两条轨迹共享 | 证据)`，要求 `r_swap < τ_swap`。遮挡后重识别只能回到 `CANDIDATE`；单帧、单模态、单次回答都不得作为身份证明。

**定义 318（滞回、驻留与 Zeno 防护 HYS）** 每个状态 `q` 有最小驻留 `d_q > 0`，每条交互边 `e` 有冷却 `c_e > 0`，转移还要求证据变化 `Δ ≥ Δ_min`（安全覆盖例外需记录并直接转保守）。由此任意有限时域 `T` 内转移数 `≤ T / d_min`，交互数 `≤ T / (d_min + c_min)`：不存在「无限追问」与状态抖动。

**定义 319（轨迹级时序 VoI 与后悔账本 RGL）** R69 的 VoI 是单轮量；定义
`TVoI_i(g) = E[ ∫_t^{t+Δ} ( H(M_s | o_{≤s}) − H(M_s | o_{≤s}, y_g) ) ds ] − c(g) − c_cool(g)`，
其中证据熵按 `n_eff` 折减。未消解风险随时间累积：
`L_i(t) = ∫_0^t ρ_i(s) ds`，`ρ_i(s) = Σ_{m ≠ m*} p(m | τ_i) · ℓ(m, m*)`（选错模态的期望损失）。
`L_i > L_max` ⇒ 允许一次「爆发探询」；仍不可解 ⇒ 降级/退休/弃权。进入 `VERIFIED` 时获得 resolution bonus：`λ` 下限只计 `U_ale`；账本记入审计。

**定义 320（开放集新物体协议 OPN）** 未匹配检测进入 `CANDIDATE`，若 `e_i > τ_e` 但分类置信 `< τ_cls`，经至多 `n_probe` 次注视/探针/问句后进入 `UNKNOWN_REAL`（按安全包络避让，禁止静默丢弃）。幻影轨迹（存在证据不成立）经 `CONTRADICTED → RETIRED`。**「不知道是什么」不等于「不存在」；「不能分类」不等于「可以忽略」。**

**定义 321（时序逻辑证书 TLC）** 规范：
- 安全：`G( VERIFIED_i → IDC_i ∧ k_eff,i ≥ 2 ∧ dwell_i )`；
- 活性：`G( CANDIDATE_i → F_{≤H}( VERIFIED_i ∨ CONTRADICTED_i ∨ RETIRED_i ) )`；
- 不重复提问：`G( ask(i, q) → X( ¬ask(i, q) U (expire ∨ Δevidence) ) )`；
- 交互预算：`limsup_{T→∞} N_ask(T)/T ≤ 1/(d_min + c_min)`；
- 无 Zeno：任意有限时域内转移有限；
- 单调退避：`G( guard_fail → X( safe_retreat ) )`。
监视器增量运行；证书 `J_TEMPEST` 记录其判决。

**定义 322（轨迹级保守退避与 R69 包含）** 投影 `Π`：单轨迹、身份已知、检测全覆盖、无遮挡、无开放集、`d=c=1` 时，TEA 的每步守卫退化为 R69 的每轮 `argmax[VoI−c]`，状态记忆为空。此时 `Π(TEMPEST) = FLUID`。非退化时，TEMPEST 只在通过带证书转移后获得效率收益；任一守卫失败单调退回 R69。

**定义 323（交互片段与冷却纪律）** 一次交互是一个片段 `ep = (owner_track, q_fingerprint, budget, expiry, required_evidence)`。同一 `(track, q_fingerprint)` 在过期或证据变化前不得重复；轨迹合并后片段仅在溯源可继承时继承，否则作废。R69 的「k 个正交源一致」在此升级为「`k_eff` 个独立溯源根一致」。

**定义 324（证书 J_TEMPEST）** `J_TEMPEST = (J_FLUID, track_trace_hash, provenance_root, idc_vec, k_eff, zeno_margin, tlc_verdict, ledger_final, reid_swap_rate, coverage_ratio, tempest_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ IDC ∧ TLC 全绿 ∧ k_eff 达标 ∧ 预算未越界 ∧ 无未审计的 UNBOUND 决策`。

**定义 325（参与式审计 VQAuditor-T）** 审计对象新增轨迹记账：某轨迹为何被提升、是否计入重复证据、是否发生 ID 交换、负证据是否越出覆盖锥、未知真实物体是否被丢弃、同一问题是否被重复追问。结论回灌 AuditBuf，成为下一轮 `ν_min`、`k_id`、`τ_miss` 的先验。

**定义 326（威胁模型 ℰ_TEMPEST）** `ℰ_TEMPEST = ℰ_FLUID × ℰ_track`，其中
`ℰ_track = { 幻影轨迹注入, 轨迹删除/遮挡 DoS, ID 交换/关联投毒, 重复证据洪泛, 检测器欺骗 }`。
各威胁分别由 OPN、CEN、IDC、EPN、AIC-TEMPEST 拦截；任何未拦截者必须在 TLC 中留下可审计痕迹。

# IP-264 OTT：带出生/死亡、遮挡、开放集的轨迹表
class ObjectTrackTable:
    def update(self, dets, o_t):
        A, U_ref = associate(dets, self.tracks)          # 软关联 + 关联熵
        for tr in self.tracks:
            ev = evidence_of(A, dets, tr, o_t)
            ev = provenance_gate(ev, tr.prov)             # IP-267：去重 + n_eff 折减
            ev = coverage_negative(ev, o_t, tr)           # IP-268：覆盖外的“没看到”不算负证据
            tr.posterior = bayes_update(tr.posterior, ev, n_eff=ev.n_eff)
            tr.state     = tea_step(tr, ev, o_t)          # IP-265/266
        self.birth_death(o_t, U_ref)                      # 新物体 → CANDIDATE / UNKNOWN_REAL
        return self.tracks, U_ref

# IP-265/266：轨迹认知状态机（滞回、驻留、逃逸门）
def tea_step(tr, ev, o_t):
    q = tr.state
    if not dwell_ok(tr) and not safety_override(ev):      # 驻留期内不跳变
        return q
    if q == CANDIDATE and idc_pass(tr) and tr.k_eff >= 2:
        if tr.residual_U_epi <= TAU_EPI: return VERIFIED
    if q == VERIFIED and contradiction(tr):               # 记忆必须有逃逸门
        return CONTRADICTED
    if q == VERIFIED and occluded(tr, TAU_OCC):
        return OCCLUDED
    if q == OCCLUDED and reappear(tr) and reid_pass(tr):
        return CANDIDATE                                  # 绝不直接回 VERIFIED
    if q in (CANDIDATE, CONTESTED) and tr.ledger > L_MAX:
        return RETIRED if not existence_ok(tr) else UNKNOWN_REAL
    return q

# IP-269/270：身份证书 + 时序 VoI + 片段冷却
def choose_info(tr, budget):
    if not idc_possible(tr): return None
    best = None
    for g in info_action_candidates(tr):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, tr): continue
        if episode_repeat(tr, g): continue                # IP-273：不得重复追问
        score = temporal_voi(tr, g) - cost(g) - cooldown_penalty(tr, g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

            decisions.append((tr, tr.mode, lam_floor(tr.U_ale)))   # resolution bonus
            continue
        g = choose_info(tr, M.budget) if tr.state in (CANDIDATE, CONTESTED) else None
        if g is not None:
            ans = M.cia.execute(g, owner=tr.id)           # 交互绑定到轨迹
            tr.update_belief(ans)
            tr.ledger.credit(g)                           # 记录花费与收益
        tr.state = tea_step(tr, ev=None, o_t=obs)
        lam = lam_floor(tr.U_ale + unresolved(tr))
        decisions.append((tr, select_mode(tr), lam))
    if U_ref > TAU_REF:                                   # 关联不确定 → 全域保守
        decisions = [(tr, m, max(lam, LAMBDA_REF)) for tr, m, lam in decisions]
    M.vqa_t.submit_async(tracks, decisions)
    return merge(decisions)
```

## 3. 推导

**假设** A99（投影条件：单轨迹/已知身份/全覆盖/无遮挡/无开放集/`d=c=1`）；A100（时间相关可用等相关 `ρ<1` 建模）；A101（检测器覆盖与漏检率可标定）；A102（`k_id` 个身份通道在给定真实身份下条件独立，单通道错误率 `<1`）；A103（驻留与冷却为正且在实时预算内可行）。

**引理 19（相关证据的有效样本数）** 设同一物理事件的 `n` 次观测等相关 `ρ`，则后验均值方差为 `σ²/n · (1 + (n−1)ρ)`，等效独立样本数 `n_eff = n/(1+(n−1)ρ)`。因此达到固定置信所需的观测数随 `ρ→1` 趋于无穷，重复帧不能制造验证。系：EPN 的溯源折减是**正确性条件**，不是性能优化；R69 的「k 源独立」在时间轴上默认失效。

**引理 20（覆盖感知负证据）** 若在覆盖锥内漏检率 `p_miss ≤ τ_miss`，覆盖外似然比设为 1，则「未检测到」导致的错误退休概率 `≤ τ_miss`（加上存在先验）。反之，若把覆盖外的沉默当负证据，可构造遮挡场景使错误退休概率任意接近 1。系：**没看到只说明「不在覆盖锥内」，不说明「不存在」**；开放集未知物体必须转 `UNKNOWN_REAL`。

**引理 21（身份交换上界）** 在 A102 下，若每次提升要求 `k_id` 个独立通道一致、且遮挡后只能回 `CANDIDATE`，则经 ID 交换获得错误 `VERIFIED` 的概率
`ε_swap ≤ Π_{c=1}^{k_id} ε_c + ε_assoc`。
取 `k_id=3, ε_c=0.1, ε_assoc=1e-2` 得 `ε_swap ≤ 1.1e-2`（可继续用第 4 通道收紧）。单帧/单模态提升不满足该上界，故被禁止。

**定理 18（Zeno-free 与交互有界）** 在 HYS 下，任意长度 `T` 的时域内轨迹转移数 `≤ T/d_min`，交互数 `≤ T/(d_min+c_min)`；安全覆盖例外按独立速率上界计。故不存在有限时间内无限追问/无限切换，长期社交成本有界。R69 的「每轮都可重新问」被替换为「按片段与冷却记账」。

**定理 19（TEMPEST 严格包含 R69/FLUID）** 在 A99 投影下，TEA 的每步守卫退化为 R69 的每轮 `argmax[VoI−c]`，且 `Π(TEMPEST) = FLUID`。一般情形下，TEMPEST 的任一决策要么等价于 R69（无可用带证书转移），要么在通过 IDC/EPN/CEN/TLC 后获得效率收益；任一守卫失败单调退回 R69，故期望风险 `≤` R69，安全侧不让步。

**定理 20（轨迹攻击下的已验证状态安全）** 在 IDC、EPN、CEN 同时生效时，产生错误 `VERIFIED` 只可能经由三条路径之一：身份交换（≤ 引理 21 上界）、证据重复（被 `n_eff` 封顶）、负证据越界（被覆盖锥禁止）。三者概率各自有界，故错误验证概率有界；任一 TLC 违例强制转保守并写入 `J_TEMPEST`。因此状态记忆不会无条件放大一次性错误，但**其纠错依赖逃逸门 `VERIFIED → CONTRADICTED/OCCLUDED` 真的被触发**——这正是本轮最大风险所在。

class ObjectTrackTable:
    def update(self, dets, o_t):
        A, U_ref = associate(dets, self.tracks)
        for tr in self.tracks:
            ev = provenance_gate(evidence_of(A, dets, tr, o_t), tr.prov)
            ev = coverage_negative(ev, o_t, tr)              # 覆盖外不算负证据

# IP-265/266：轨迹认知状态机（驻留 + 逃逸门）
def tea_step(tr, ev, o_t):
    if not dwell_ok(tr) and not safety_override(ev): return tr.state
    if tr.state == CANDIDATE and idc_pass(tr) and tr.k_eff >= 2 \
       and tr.residual_U_epi <= TAU_EPI: return VERIFIED
    if tr.state == VERIFIED and contradiction(tr):       return CONTRADICTED
    if tr.state == VERIFIED and occluded(tr, TAU_OCC):   return OCCLUDED
    if tr.state == OCCLUDED and reappear(tr) and reid_pass(tr):
        return CANDIDATE                                  # 绝不直接回 V
    if tr.state in (CANDIDATE, CONTESTED) and tr.ledger > L_MAX:
        return RETIRED if not existence_ok(tr) else UNKNOWN_REAL
    return tr.state

# IP-267/268：证据门（溯源折减 + 覆盖负证据）
def provenance_gate(ev, prov):

    rho = estimate_correlation(ev)
    ev.n_eff = len(ev) / (1 + (len(ev)-1) * rho)          # 引理 19
    return ev

def coverage_negative(ev, o_t, tr):
    for e in ev.absent:                                   # “没检测到”的事件
        if not in_coverage_cone(e.x, o_t, tr): e.lr = 1.0 # 沉默无信息
    return ev

# IP-269/270：身份证书 + 时序 VoI + 冷却
def choose_info(tr, budget):
    if not idc_possible(tr): return None
    best = None
    for g in info_action_candidates(tr):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, tr): continue
        if episode_repeat(tr, g): continue                # 不重复追问
        score = temporal_voi(tr, g) - cost(g) - cooldown_penalty(tr, g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-275 主闭环：R69 的记忆化、对象化
def TEMPEST_RAS_round(M, obs):
    tracks, U_ref = M.ott.update(obs.detections, obs)
    if not tracks: return M.fluid_round(obs)              # 无对象 → R69 匿名路径
    out = []
    for tr in tracks:
        if tr.state == VERIFIED:
            out.append((tr, tr.mode, lam_floor(tr.U_ale))); continue
        g = choose_info(tr, M.budget) if tr.state in (CANDIDATE, CONTESTED) else None
        if g is not None:
            ans = M.cia.execute(g, owner=tr.id); tr.update_belief(ans); tr.ledger.credit(g)
        tr.state = tea_step(tr, ev=None, o_t=obs)
        out.append((tr, select_mode(tr), lam_floor(tr.U_ale + unresolved(tr))))
    if U_ref > TAU_REF:
        out = [(tr, m, max(lam, LAMBDA_REF)) for tr, m, lam in out]
    M.vqa_t.submit_async(tracks, out)
    return merge(out)
```

## 4. 推导

**假设** A99（投影：单轨迹/已知身份/全覆盖/无遮挡/无开放集/`d=c=1`）；A100（等相关 `ρ<1`）；A101（覆盖与漏检可标定）；A102（`k_id` 身份通道条件独立）；A103（驻留/冷却在实时预算内）。

**引理 19（相关证据的有效样本数）** 等相关 `n` 次观测的后验均值方差 `σ²/n·(1+(n−1)ρ)`，故 `n_eff=n/(1+(n−1)ρ)`；`ρ→1` 时 `n_eff→1`，重复帧不能制造验证。系：EPN 的溯源折减是正确性条件而非性能优化。

**引理 20（覆盖感知负证据）** 覆盖锥内漏检率 `p_miss≤τ_miss` 时，错误退休概率 `≤τ_miss`；若把覆盖外沉默当负证据，可构造遮挡场景使错误退休概率趋近 1。系：`UNKNOWN_REAL` 是安全必需状态。

**引理 21（身份交换上界）** A102 下，`k_id` 通道一致 + 遮挡后只回 CANDIDATE，则错误 `VERIFIED` 的交换概率 `ε_swap ≤ Πε_c + ε_assoc`；`k_id=3, ε_c=0.1, ε_assoc=1e-2 ⇒ ε_swap ≤ 1.1e-2`。单帧/单模态提升不满足该上界，故禁止。

**定理 18（Zeno-free 与交互有界）** HYS 下任意 `T` 内转移 `≤T/d_min`、交互 `≤T/(d_min+c_min)`；不存在无限追问与无限切换，长期社交成本有界。

**定理 19（TEMPEST 严格包含 R69）** A99 投影下 `Π(TEMPEST)=FLUID`，每步守卫退化为 R69 的 `argmax[VoI−c]`；一般情形只在通过 IDC/EPN/CEN/TLC 后获利，任一守卫失败单调退回 R69，故期望风险 `≤` R69，安全侧不让步。

**定理 20（轨迹攻击下的已验证状态安全）** 错误 `VERIFIED` 只能经身份交换（引理 21）、证据重复（`n_eff` 封顶）、负证据越界（覆盖锥禁止）三条路径，概率各自有界；任一 TLC 违例强制保守并写入 `J_TEMPEST`。因此记忆不会无条件放大一次性错误，但纠错依赖 `VERIFIED→CONTRADICTED/OCCLUDED` 逃逸门被真实触发。

## 7. 本轮最大风险

**一句话**：TEMPEST 的全部收益押在「轨迹身份 + 状态记忆」这对互相背书的前提上——**一次 ID 交换、轨迹碎片化或关联投毒就能把错误证据洗白进 `VERIFIED` 并长期锁死；而防抖的滞回/驻留同时堵住了纠错通道，使系统比 R69 更自信、更省事地做错**——记忆能防止无限追问，也能把一次错误固化为一生的偏见。

**次级风险与缓解**：状态僵化（`VERIFIED→CONTRADICTED/OCCLUDED` 逃逸门 + 后悔账本 `L_max` + E311）；ID 交换/关联投毒（IDC + 遮挡后只回 CANDIDATE + 引理 21 + E303）；证据重复（溯源 DAG + `n_eff`/`k_eff` + 引理 19 + E302）；负证据误用/开放集漏检（覆盖锥 CEN + `UNKNOWN_REAL` + E304/E305）；实时预算（轨迹上限 + 增量 TLC + E314）；R69 退化不彻底（定义 322 投影 + E309）。
