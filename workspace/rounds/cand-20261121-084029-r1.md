# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「技能学习」×「机械臂抓取」）

> **基线**：上一轮（灵感「大语言模型」×「机器人」×「智能体」）MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**学习是查询、接触证书是唯一裁决、练习与探索只提高覆盖率不新增授权**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC，v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB，v15 的 SCD/DSD/DCA/EDC，v12 的 USG/TGC/BAA/GAGP/UC，v11 的 HAS/HCC/HATD/HDT，v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。六个新组件——RSL（残差技能格）、SAG（技能准入闸）、GCC（抓取接触证书）、HMV（混合模式验证器）、SCP（技能巩固与练习调度）、CEG（接触探索守卫）——插在 v17 语言层与 v16 行为层之间，失效即严格退回 v17（引理 143），再沿 v17→v16→v15→…→v6 退化链退回。本轮只做三件事：把"技能学习"改写为**残差管道内的查询与准入**，把"机械臂抓取"改写为**接触包络上的鲁棒证书与模式转移证书**，把"练习/探索"改写为**只提高证书覆盖率的单调过程**。

## 0. 直觉与动机

**灵感 1（技能学习 → 学习是查询，不是授权：残差技能格 + 技能准入闸）**
直觉：技能学习（模仿学习、强化学习）产出的新策略通常被直接部署，从而绕过了 v16/v17 辛苦建立的证书链；另一极端是拒绝一切学习，机器人便永远无法适应新物体与新任务。核心创新一：**残差技能格（Residual Skill Lattice, RSL）**。任何学到的技能都被强制分解为 `σ = (n_base, δ_θ)`：`n_base` 是 v17 已认证锚（BT 节点），`δ_θ` 是学习得到的残差策略；残差必须落在一个**认证管道（certified tube）** `Tube(n_base; ρ, ε) = {δ : ∀s∈Run_{n_base}, ‖δ(s)‖ ≤ ρ ∧ post_dev(n_base, δ) ≤ ε}` 内，且管道的成员资格用**控制障碍函数（CBF）在连续域上证明**，而不是在有限采样上打勾。关键反直觉点：**学习不创造新能力，只创造旧能力的新参数化**——它的价值是把"保守证书包络"与"真实安全集"之间的保守间隙吃掉，让系统**更放得开**（活动性上升），而不是**能做更多**（授权上升）。这把 v17 的"语言无特权"直接推广为"学习无特权"。
但彻底禁止扩张又会让系统学不会新技能，于是有核心创新二：**技能准入闸（Skill Admission Gate, SAG）**。当残差必须冲出管道时，技能不被直接执行，而进入四关准入：(a) **覆盖证书**——技能 rollout 分布必须被既有 NC 的闭包覆盖；(b) **缝证书**——技能内部及技能间的所有接触缝经 HMV 复验；(c) **影子验证**——与 base 并行执行 N 个回合、零违规（此期间新技能**不真正驱动执行器**）；(d) **NC 合成与独立验证**——由 v16 NCS 合成新节点证书并独立验证。四关全过，新锚才进入锚集。**准入的单调性：影子期 `Exec_v18 ⊆ Exec_v17`，转正后新增执行项必携带新 NC。**

**灵感 2（机械臂抓取 → 抓取是接触区间上的鲁棒证书，不是抓取点）**
直觉：抓取通常被参数化为"一个位姿 + 一个夹爪开度"，但真实抓取是**接触构型集合（contact manifold）× 摩擦锥 × 力闭合裕度**。真正的危险不在"抓得准不准"，而在**接触暂态**：接近→接触→闭合→抬升是一串混合模式，每个模式的证书可以单独成立，模式切换却可能无证书——这正是 v17"计划缝"在接触空间的翻版，而且更险：状态缝只需状态满足前置/后置，接触缝还需冲量、摩擦与位姿不确定性同时被覆盖。核心创新一：**抓取接触证书（Grasp Contact Certificate, GCC）**。它把一个抓取认证为**接触包络** `CE = B(p̂, Σ_pose) × [w_min, w_max] × C_fric × margin_FC`，要求对不确定性椭球内**所有**位姿都成立力闭合与摩擦锥约束（鲁棒证书，而非点证书）。核心创新二：**混合模式验证器（Hybrid Mode Verifier, HMV）**，把抓取建模为模式自动机 `FREE→APPROACH→CONTACT→CLOSE→LIFT→TRANSPORT→RELEASE`，每条边 `e:m→m'` 需要**转移证书** `TC_e = (Post_m ∩ Pre_{m'} ≠ ∅) ∧ (|J_e| ≤ J_max)`。关键反直觉点：**抓取成功率由"接触缝的集合包含"决定，而非"抓取点的精度"决定**——一个位姿略偏但接触缝鲁棒的抓取，严格优于一个位姿精准但接触缝只是点估计的抓取。点包含不够，必须**集合包含**：`B(p̂, Σ_pose) ⊆ CS`。

**两者如何统一：证书覆盖率是唯一货币**
把"技能学习"和"机械臂抓取"统一为一个量：**证书覆盖率** `κ = vol(已认证可达集) / vol(真实可达集)`。学习（RSL 吃保守间隙、SAG 转正新技能）、练习（SCP 收紧证书）、探索（CEG 降低位姿不确定性从而放大已认证包络）三者都只在**提高 κ**，而**从不提高"未认证体积"**；抓取（GCC 鲁棒包络 + HMV 模式转移证书）则决定接触这一最危险子空间里的 κ 能否被真正覆盖。于是 v18 是夹在 v17 与 v16 之间的**技能层**：v17 回答"哪些语言计划可被编译与调度"（`Exec_v17`），v16 回答"哪些全身行为可被安全执行"（`Exec_v16`），v18 回答"哪些学到的技能与抓取可被准入为认证锚、并在接触证书与模式转移证书下执行"（`Exec_v18`）。共享状态 `ζ_sk = (anchors, tube, shadow_pool, contact_env, mode_state, κ, practice_stats, explore_budget, mode_sk)`。**RSL 回答"能怎么变"，SAG 回答"能不能转正"，GCC 回答"这个抓取覆盖了哪些不确定性"，HMV 回答"模式切换是否被覆盖"，SCP 回答"练习让哪些边界更紧"，CEG 回答"探索能减少多少不确定性但不新增未授权体积"**。六者不是六个补丁，而是"约束—准入—接触—模式—巩固—探索"的实现链。

## 1. 研究问题（轮次升级版）

- **Q1（残差管道的可靠性与紧致性）**：如何用 CBF/障碍函数在连续域上证明 `∀s∈Run_{n_base}: ‖δ(s)‖≤ρ`？管道边界 `ρ, ε` 如何与 v16 的 NC 后置条件联合标定，既不虚高（不 sound）也不虚低（学不动）？残差在分布外状态上如何检测并回退？
- **Q2（准入的覆盖证书与影子验证）**：如何判定"技能 rollout 分布被既有 NC 的闭包覆盖"而不至于过度保守？影子模式需要多少回合、何种统计保证才能从"零违规"推到"可转正"？转正后的新 NC 由 NCS 合成时，覆盖集与旧 NC 的包含关系如何保持？
- **Q3（接触包络与接触缝的鲁棒性）**：高维位姿不确定性椭球下，鲁棒力闭合的判定复杂度如何控制？摩擦锥/力闭合裕度如何与 v16 WBC 的力矩约束接口？非凸接触流形上 `B(p̂,Σ) ⊆ CS` 如何可判定地近似？
- **Q4（练习/探索的单调性与注入边界）**：SCP 如何保证"只收紧不扩张"？CEG 的探索动作越界如何硬停？练习样本被投毒（伪造成功反馈）时，κ 的估计会否被系统性抬高？探索—重证—再探索的循环会不会把不确定性估计压到不 sound？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P33）

**P31 学习无特权律（Learning as Query, Not Authority）**
学习输出只是*查询*：技能要么落在某已认证锚的残差管道内（复用 `NC_{n_base}`，不得放宽），要么必须经 SAG 四关准入并合成新 NC。**任何绕过 RSL/SAG 的策略参数更新都视为非法**；语言层（v17 S2C）只能投影到"带 NC 的锚"，学习层不得直接写 BT 结构、证书阈值或 WBC 约束。**未经准入的技能，其可新增授权基数恒为零。**

**P32 接触集合包含律（Contact Set Inclusion, Not Point）**
抓取认证必须对位姿不确定性椭球做**集合级**覆盖：`B(p̂, Σ_pose) ⊆ CS_e` 且 `∀p∈B(p̂,Σ_pose): robust_force_closure(p)`；模式转移 `TC_e` 必须同时满足缝非空、集合包含与冲量界 `|J_e| ≤ J_max`。**点包含一律不足以授权接触暂态**；任何只在 `p̂` 处成立、在椭球边缘失效的抓取证书必须被拒绝。

**P33 练习/探索单调律（Practice & Exploration Monotone in Coverage, Not in Authority）**
SCP 只允许在固定管道内细化残差、收缩 `ρ/ε`、收紧 NC，禁止扩大管道或放宽证书；CEG 的探索动作必须落在当前认证接触包络内（否则硬停），探索后必须由 GCC **重新认证**才可使用新包络。练习与探索可以提高 `κ`（已认证体积），但**未认证体积不因练习或探索而减少其风险标注**——新动作仍须携带新证书。

## 3. 与基线的接口（如何退化）

- RSL 失效（CBF 证书器不可用）⇒ 只允许零残差技能（`δ≡0`），即纯 v17 锚——**等价 v17**；
- SAG 失效（覆盖/影子/独立验证任一不可用）⇒ 新技能一律不准入，锚集冻结——**等价 v17**；
- GCC 失效 ⇒ 只允许"退化抓取"（单一位姿、零不确定性、预认证的少数抓取），其余 ⊥——**等价 v17（抓取活动性骤降）**；
- HMV 失效 ⇒ 抓取降为单模式（只执行已认证的单步接近或释放），禁止多模式序列——**等价 v17**；
- SCP 失效 ⇒ 不巩固：残差与证书保持准入时原样——**等价 v17**；
- CEG 失效 ⇒ 不主动探索：位姿不确定性不降低，`κ` 不增——**等价 v17**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v6 退化链退回；
- **安全继承**：RSL 只在管道内改动作、SAG 只经四关扩锚、GCC 只给鲁棒包络、HMV 只增转移约束、SCP 只收紧、CEG 只减少不确定性。六端口均不能跳过证书；影子期 `Exec_v18⊆Exec_v17`，转正后 `Exec_v18⊆⋃NC`（引理 143）。

## 4. 预期贡献

1. **残差技能格**：首次把"学习新技能"改写为"在认证锚的残差管道内重新参数化"，用 CBF 在连续域上证明管道成员资格，证明学习只吃保守间隙、不增授权，填补"技能学习直通执行器"的安全空白；
2. **技能准入闸**：给出"覆盖证书 + 缝证书 + 影子验证 + NC 独立验证"四关准入与影子期单调性，使"技能转正"从经验判断升级为可审计的证书流程；
3. **抓取接触证书**：把抓取从"位姿点"升级为"对位姿不确定性鲁棒的接触包络"，给出鲁棒力闭合与摩擦锥约束的集合级判定，关闭"点证书在椭球边缘失效"的缺口；
4. **混合模式转移证书**：发现并形式化"每个抓取模式都有证书、模式切换却没有"的接触缝缺口，给出 `B(p̂,Σ)⊆CS` 集合包含与冲量界语义；
5. **练习/探索单调性**：证明 SCP 只收紧、CEG 只提覆盖率，把"自监督练习"与"主动触觉探索"纳入"只增覆盖率不增未授权体积"的框架，关闭练习投毒/探索越界的授权攻击面；
6. **技能层分离**：v17 管语言计划、v18 管技能准入与接触、v16 管全身行为，用 `Exec_v18⊆⋃NC`（影子期 `⊆Exec_v17`）把语言、技能、接触、行为四层解耦；E711–E730 覆盖管道 soundness、准入、鲁棒抓取、接触缝、练习单调、探索安全、端到端与消融。

## 5. 本轮最大风险

**一句话**：残差管道与接触包络的边界（`ρ, ε, Σ_pose, m_FC`）本身都是从有限示范/有限回合**估计**出来的——学习可以在采样覆盖的管道内部通过 CBF 证书，却在管道边界之外的**未采样残差方向**上把系统带出真实安全集，即"管道内处处有证书、边界处证书是外推"的、通过准入却绝对不安全的技能。

## 1. 关键算法骨架

```python
# IP-415 Residual Skill Lattice：残差管道（连续域 CBF 证书）
class ResidualSkillLattice:
    def __init__(self, rho, eps, cbf):
        self.rho, self.eps, self.cbf = rho, eps, cbf   # 范数界、后置偏差界、CBF 证书器

    def decompose(self, sigma):
        return sigma.n_base, sigma.delta

    def in_tube(self, n_base, delta):
        # 连续域：∀s∈Run_{n_base}，不是有限采样打勾
        if not self.cbf.invariant(n_base.Run, delta, self.rho):
            return False
        return self.cbf.post_bound(n_base, delta, self.eps)

    def apply(self, n_base, delta, s):
        a = n_base.policy(s) + delta(s)
        return clip_to_nc(a, n_base.NC)                # 残差只改动作，不改证书


# IP-416 Skill Admission Gate：四关准入
class SkillAdmissionGate:
    def __init__(self, rsl, ncs, hmv, shadow_n, alpha_adm):
        self.rsl, self.ncs, self.hmv = rsl, ncs, hmv
        self.shadow_n, self.alpha_adm = shadow_n, alpha_adm

    def admit(self, sigma, demos):
        base, delta = self.rsl.decompose(sigma)
        if self.rsl.in_tube(base, delta):
            return Admission(sigma, nc=self.ncs[base], mode='RESIDUAL')   # 不扩锚
        if not self._coverage(sigma, demos):  return Admission(None, reason='COVER')
        if not self.hmv.verify_all(sigma):   return Admission(None, reason='SEAM')
        if not self._shadow(sigma, base):    return Admission(None, reason='SHADOW')
        nc = self.ncs.synthesize(sigma, coverage=self._cover_set(sigma, demos))
        if not self.ncs.independently_validate(nc, alpha=self.alpha_adm):
            return Admission(None, reason='NC')
        return Admission(sigma, nc=nc, mode='ADMITTED')

    def _coverage(self, sigma, demos):
        return closure_cover(sigma.rollouts(demos), self.ncs.all())   # 组合证书

    def _shadow(self, sigma, base):
        # 影子期与 base 并行、不驱动执行器；零违规才继续
        return shadow_compare(sigma, base, episodes=self.shadow_n, tol=0.0)

    def _cover_set(self, sigma, demos):
        return conservative_envelope(sigma.rollouts(demos))


# IP-417 Grasp Contact Certificate：鲁棒接触包络
class GraspContactCertificate:
    def __init__(self, eps_pose, w_range, fc_margin, cbf):
        self.eps_pose, self.w_range = eps_pose, w_range
        self.fc_margin, self.cbf = fc_margin, cbf

    def certify(self, obj, p_hat, Sigma, gripper):
        E = ellipsoid(p_hat, Sigma)                    # 位姿不确定性椭球
        ce = ContactEnvelope(E, self.w_range,
                             friction_cones(obj), self.fc_margin)
        if not ce.robust_force_closure():              # ∀p∈E 均力闭合
            return None
        if not self.cbf.covers(ce, obj.contact_manifold):   # 连续域覆盖
            return None
        return ce


# IP-418 Hybrid Mode Verifier：抓取模式自动机 + 接触缝集合包含
class HybridModeVerifier:
    MODES = ('FREE', 'APPROACH', 'CONTACT', 'CLOSE', 'LIFT', 'TRANSPORT', 'RELEASE')

    def __init__(self, nc_table, J_max, margin_cs):
        self.nc, self.J_max, self.margin = nc_table, J_max, margin_cs

    def step(self, mode, obs, ce):
        for mp in self.successors(mode):
            tc = self.transition_cert(mode, mp, obs, ce)
            if tc.ok:
                return mp, tc
        return None, None                              # 无可用转移 ⇒ 回退

    def transition_cert(self, m, mp, x, ce):
        cs = intersect(self.nc[m].Post, self.nc[mp].Pre)   # 接触缝
        # P32：集合包含 B(x,ε)⊆CS，而非点包含 x∈CS
        if not cs.contains_ball(x, ce.eps_pose):
            return TC(False, 'SEAM')
        if self.impulse_bound(m, mp) > self.J_max:
            return TC(False, 'IMPULSE')
        if cs.volume() < self.margin:
            return TC(False, 'VOLUME')
        return TC(True, cs)

    def verify_all(self, sigma):
        return all(self.transition_cert(m, mp, x, sigma.ce).ok
                   for (m, mp, x) in sigma.seams())


# IP-419 Skill Consolidator：练习只收紧
class SkillConsolidator:
    def __init__(self, rsl, practice_period, pf):
        self.rsl, self.period, self.pf = rsl, practice_period, pf

    def consolidate(self, sigma, feedback):
        if self.pf.suspect_feedback(feedback):
            return sigma                               # 疑似投毒：不巩固
        sigma.delta = self._refine_within_tube(sigma.delta, feedback)
        self.rsl.rho = min(self.rsl.rho, self._new_rho(feedback))
        self.rsl.eps = min(self.rsl.eps, self._new_eps(feedback))
        return sigma                                   # 只收缩，不扩张


# IP-420 Contact Exploration Guard：探索越界硬停、探索后重证
class ContactExplorationGuard:
    def __init__(self, gcc):
        self.gcc = gcc

    def explore(self, ce, probe):
        if ce is None or not ce.contains(probe):       # 越出认证包络 ⇒ 停
            return HALT
        return probe

    def after_explore(self, obj, p_hat, Sigma_new, gripper):
        # 不确定性降低 ⇒ 重新认证（更大已认证包络），而非直接授权
        return self.gcc.certify(obj, p_hat, Sigma_new, gripper)
```

## 2. 推导

**引理 143（学习无特权与准入安全）** 设每个被执行技能 σ 满足：(a) 残差管道内，复用 `NC_{n_base}`；或 (b) 经 SAG 四关准入并合成 `NC_σ` 且独立验证。则任一时刻执行状态落在某个已认证 NC 的 Run 内；且影子期 `Exec_v18 ⊆ Exec_v17`，转正后 `Exec_v18 ⊆ ⋃NC`。证明：(a) CBF 管道保证 `∀s∈Run_{n_base}` 残差后的轨迹仍在 `Run_{n_base}` 的证书包络内，`post_dev≤ε` 保证后继条件不被破坏，故复用 `NC_{n_base}`；(b) 覆盖证书保证 `rollout⊆closure(旧 NC)`，影子期零违规且不驱动执行器，NCS 合成并独立验证产生新 NC；v17 的 S2C 只能投影到带 NC 的锚。故任何新增执行项必携带证书。影子期新技能不驱动执行器，故 `Exec_v18=Exec_v17`。∎ 推论：**学习层与语言层失效模式同向——只损活动性，不增不安全率；扩张必须走准入。**

**引理 144（接触包络的鲁棒覆盖）** 若 `CE` 对椭球 `B(p̂,Σ_pose)` 内所有位姿满足 `m_FC>0` 且接触力在 `C_fric` 内，则抓取在 CE 内执行时 `slip(CE,x)=false`；若 slip 仍触发，则 `RELEASE` 回退落在 CE 的认证子集内。证明：鲁棒力闭合意味着 `∀p∈B(p̂,Σ)` 存在接触力分配使合力/力矩平衡且每接触力在 `C_fric` 内；HMV 的转移证书保证执行期间位姿不越出 `B(p̂,Σ)`；slip 检测触发时进入自动机中预认证的 `RELEASE` 边，其 `Post⊆CE`。∎ 推论：**抓取安全是"包络 × 摩擦锥 × 模式边"的合取，不是单点力闭合的断言。**

**引理 145（接触缝集合包含的必要性）** 设 `CS_e = Post_m ∩ Pre_{m'}`。若只验证 `p̂∈CS_e`（点包含）而不验证 `B(p̂,Σ_pose)⊆CS_e`，则存在位姿扰动 `p∈B(p̂,Σ)` 使 `p∉CS_e`，导致 `m'` 在未满足前置时执行，违反 v16 引理 131。构造：令 `CS_e` 边界穿过 `p̂` 邻域，取椭球长轴方向 `p=p̂+ε·u`，则 `p∉CS_e` 而 `p̂∈CS_e`。故必须集合包含。∎ 推论：**接触暂态的证书粒度是"椭球"，不是"点"；点证书在不确定性下等价于无证书。**

**引理 146（练习单调性）** 设 SCP 只允许 (i) 在固定 `Tube` 内细化 `δ`，(ii) 收缩 `ρ,ε`，(iii) 收紧 NC，且巩固样本过投毒过滤。则每次巩固后证书包络只收缩，`Exec_v18` 不新增未认证体积，保守性单调不增。证明：`cons` 的输出是输入的证书细化，`ρ/ε` 取 `min`，`δ` 仅在管道内更新；由引理 143，覆盖率 `κ` 单调不减且无新增未认证项。投毒过滤排除伪造反馈，防止 `ρ/ε` 被反向抬高。∎ 推论：**练习让系统"更敢动"（保守间隙变小），但从不"更越界"。**

**引理 147（探索不增未授权体积）** CEG 的探索动作必须落在当前 `CE` 内（否则 HALT）；探索降低 `Σ_pose` 后，新 `CE'` 必须由 GCC 重新认证。则探索只能通过"更小的不确定性 ⇒ 更大的已认证包络"提高 `κ`，不能产生无证书动作。证明：探索动作 `∈CE` 由 guard 保证；`CE'` 经 GCC 鲁棒认证；未认证体积 `= 真实可达 − 已认证`，探索不直接改变真实可达，只改变估计；任何新动作仍需 `CE'` 认证。∎ 推论：**主动探索是"提高覆盖率"的操作，不是"扩大授权"的操作。**

**引理 148（组合技能闭包）** 若组合技能 `σ_c` 的 rollout 集 `⊆ closure(⋃_{i} NC_i)` 且所有技能间接触缝通过 HMV，则合成 `NC_{σ_c} ⊆ closure(⋃NC_i)`，组合安全。证明：覆盖证书给出集合包含；缝证书保证模式切换被覆盖；NCS 合成的 NC 是覆盖集的保守包络，包含关系传递。∎ 推论：**技能组合的安全性可由"成分覆盖 + 缝覆盖"推出，无需重新从零认证组合体。**

## 6. 已知风险与失效模式

1. **管道边界的估计偏差**：`ρ, ε` 由有限示范/回合估计，CBF 只在估计边界内 sound；边界外的未采样残差方向可能越出真实安全集。缓解：保守先验、在线收缩、分布外残差检测、边界处强制影子。
2. **覆盖证书的过度保守**：`closure(⋃NC)` 过紧导致新技能几乎无法准入，`κ` 长期停滞。缓解：证书族内共享、分层闭包、允许局部临时包络 + 影子。
3. **影子验证的统计不足**：N 回合零违规不代表转正后零违规（稀有事件）。缓解：置信上界、稀有事件定向压力测试、延长观察期、独立验证。
4. **鲁棒力闭合计算爆炸**：高维位姿椭球 × 多接触点的鲁棒判定代价高。缓解：接触流形降维、摩擦锥线性化、GPU 并行、缓存。
5. **接触缝集合包含不可判定**：非凸接触流形上 `B(p̂,Σ)⊆CS` 只能近似。缓解：凸包保守近似、拒绝边界模糊样本、加过渡模式。
6. **练习投毒**：伪造成功反馈使 `ρ/ε` 被反向抬高或 `δ` 学到危险动作。缓解：反馈签名、单源配额、投毒过滤、周期审计。
7. **探索把不确定性压到不 sound**：探索样本有偏导致 `Σ_pose` 被低估，`CE` 虚假放大。缓解：探索样本加权、保守协方差、探索后独立验证、上限约束。
8. **模式自动机的组合爆炸**：多物体/多指抓取的转移数激增。缓解：分层自动机、按物体类共享边、在线剪枝。
9. **技能与语言层锚版本漂移**：SAG 扩锚后 v17 计划缓存引用旧锚。缓解：锚版本号、扩锚只在无计划窗、缓存整体失效。
10. **残差与 base 证书冲突**：残差动作虽在范数管道内，却可能违反 NC 的 Run 约束。缓解：`clip_to_nc` 硬投影、管道与 NC 联合证书、运行时复验。
11. **`κ` 的可测量性**：真实可达集体积不可知，`κ` 只是代理指标。缓解：用覆盖率下界、多估计器交叉、预注册代理指标。
12. **过度证书叠加导致活性塌缩**：RSL∩SAG∩GCC∩HMV∩v17 五层求交可能使通过率趋零。缓解：加权而非纯求交、动态阈值、活性监视、分级放宽。

## 7. 本轮最大风险

**一句话**：残差管道与接触包络的边界（`ρ, ε, Σ_pose, m_FC`）本身都是从有限示范/有限回合**估计**出来的——学习可以在采样覆盖的管道内部通过 CBF 证书，却在管道边界之外的**未采样残差方向**上把系统带出真实安全集，即"管道内处处有证书、边界处证书是外推"的、通过准入却绝对不安全的技能。
