# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮 / 本次会话第 2 轮；本轮灵感：「共情表达」×「基线复现」）

> 第 54 轮已把技能组合推进为动作-鲁棒性双证书与云边协同闭环。本轮不再继续加高能力塔，而是补上一层「有效性审计」：**共情表达（对外，面向人）** 与 **基线复现（对内，面向科学）**。核心矛盾：H22——共情表达若不做证据门控，会把人机交互中的人类纠错变成「共情剧场」，用主观好感掩盖真实失败；H23——若基线不可复现，前 54 轮几乎所有鲁棒性增益都可能落在复现噪声半径之内，证书体系会集体失效。统一视角：两者都是**带不确定性的参考对齐**，都需要容差、置信与弃权三件套。

## 0. 直觉与动机

**统一直觉（双向对齐证书）**
共情表达是「机器人的外显行为 ↔ 人的内隐状态」的对齐；基线复现是「我测到的结果 ↔ 别人报告的结果」的对齐。二者共享同一骨架：参考量 `r` 不可直接观测、只能带噪估计；对齐必须给出**容差、置信、弃权**，否则「对齐姿态」本身就是过拟合。于是本轮把第 54 轮的动作证书体系扩展为 **双向对齐证书**：一条朝向人（`E_cert`），一条朝向基线（`R_cert`）。若 REX/Explain 是对「为什么失败」的认知解释，`E_cert` 就是对「你现在感受如何、我如何回应」的情感解释——两者都是人对机器的可理解性接口。

**灵感 1（共情表达 → 一个受证据门控的通信动作子空间）**
直觉：共情不是贴在策略外面的语气词，而是动作空间里的一条**通信通道** `A_x ⊆ A_e`（语调、目光、停顿、手势、措辞、节奏）。它和执行动作共享带宽与时机，因此必须进入技能动作剖面。更关键：表达强度不能超过对他人状态推断的证据强度；证据弱时应「安全共情」（承认不确定、低强度陪伴），而不是自信地断言「我懂你」。这把共情从表演变成**可校准的估计-表达映射**。

**灵感 2（共情剧场 → 最大威胁不是不共情，而是过度共情）**
直觉：过度共情会制造**信任错配**：人因为被理解而降低监督，系统真实失败被主观好感掩盖。因此需要「过度表达惩罚」与「共情消融对照（sham empathy）」：同样交互时长、同样信息量，只改变情感断言强度，看人类纠错是否真的更快更准。只有当「有共情 vs 无共情（或 sham）」的鲁棒性差超过复现噪声，才承认共情是鲁棒性通道。

**灵感 3（基线复现 → 把「提升」重新定义为超过复现半径）**
直觉：基线不是跑一次得到一个数，而是一个**分布**。给出环境哈希、种子集、容差区间与等价性检验；任何「比 baseline 好 X%」的声称，必须先证明 X 大于基线在匹配环境下的**复现半径** `r_rep`。这把复现从附录工作变成一线约束：不满足 `R_cert` 的实验，不进入创新点清单。

**灵感 4（人类评价的复现 → 主观指标的客观锚）**
直觉：共情的好坏由人评分，而人类评分本身需要复现协议：盲评、平衡顺序、多评分者、跨文化分层、评分者间信度 `κ`。因此「基线复现」不仅覆盖自动指标，还覆盖**人类基线**（共情评分与纠错行为）。两条线在人机实验里交汇，这也是「共情」与「复现」不是两个话题而是一个闭环的原因。

**灵感 5（有效性层 → 叠加 L0.6，而非继续加高能力塔）**
直觉：在 L0.5++ 动作-协同层之上加 **L0.6 有效性与共情层**。它不是新能力，而是对整座塔的**闸门**：任何下层证书要对外声称，都必须经过 `R_cert`（科学有效性）与 `E_cert`（人际有效性）双重放行。证书体系从「能做什么」升级为「说的和做的是否一致、测的和报的是否一致」。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（情感状态空间与共情表达动作）**
情感状态空间 `(H,d_H)`，`h∈H` 为多评分者标注的隐状态（效价、唤醒、不确定、参与度），`d_H` 为加权度量（如归一化 Earth Mover 距离）。共情表达动作 `A_x ⊆ A_e`，含语调、目光、停顿、措辞、手势。共情策略 `π_e(a_x|ĥ,c)`，`c` 为上下文，表达强度 `I(a_x)∈[0,1]`。

**定义 122（共情保真度与过度表达）**
给定校准器 `ĥ=φ(o)`、共形集 `C_α(ĥ)` 与多评分者评分 `r(a_x,h,c)`：
`F_e = E[r]·(1 - E[d_H(ĥ,h)]/d_max)`；
过度表达 `OE = E[max(0, I(a_x) - β(conf, |C_α|))]`，其中 `β` 关于 `conf` 单调增、关于 `|C_α|` 单调减。**证据门控**要求 `I(a_x) ≤ β(conf,|C_α|)`，否则拒绝该表达；证据不足时退化为「安全共情」（承认不确定、低强度陪伴）。

**定义 123（共情接地证书）**
`E_cert = (ĥ, C_α, conf, a_x, I, r_multi, κ, abstain, evidence)`：`r_multi` 为多评分者分布，`κ` 为评分者间信度，`abstain` 表示低证据安全共情，`evidence` 含盲评原始评分与校准日志。若 `F_e ≥ θ_F`、`κ ≥ κ_0` 且无越界表达，则称共情表达**接地**。

**定义 124（基线复现协议与证书）**
基线 `B`、环境规格 `env`、种子集 `S`、指标集 `M`。环境哈希 `h_env = H(env)`。复现分布 `D_m = {m(B,s,env)}_{s∈S}`，复现间隙 `g_rep(m) = W_1(D_m, D_m^rep)`（报告值为单点时与参考区间比较）。`R_cert = (B, h_env, S, {D_m}, {g_rep}, {ε_rep}, {power})`。若 `∀m: g_rep(m) ≤ ε_rep(m)`、`h_env` 匹配且检验功效 `≥ 1-β_pow`，则**可复现**。

**定义 125（复现半径与复现校正鲁棒性）**
复现半径 `r_rep(m) = Quantile_{1-α}({m(B,s,env')} over env perturbations)`，即在硬件/软件/切分/种子扰动下的指标波动上分位。复现校正鲁棒性 `ρ^R_m = LCB_{1-α}(ρ_m) - r_rep(m)`。共情增益 `Δρ_e(m) = ρ_m(empathy) - ρ_m(sham/off)`，仅当 `LCB(Δρ_e) > r_rep(m)` 且多重比较校正后仍显著，才记为有效。

**定义 126（双向有效性联合证书）**
`J_V = (E_cert, R_cert, ρ^R, Δρ_e, r_rep, prereg, evidence)`。部署/声称条件：
```
F_e ≥ θ_F ∧ κ ≥ κ_0 ∧ g_rep ≤ ε_rep ∧ LCB(Δρ_e) > r_rep ∧ FWER ≤ α
```
`evidence` 至少含盲评原始评分、环境哈希、种子清单与预注册假设；`prereg` 用于拒绝事后改指标。

## 2. 关键算法 伪代码

### IP-121 EEP（Empathic Expression Profiling）

```python
def empathic_profile(estimator, rater_pool, H_grid, A_x, alpha=0.1):
    profile = {}
    for h in H_grid:
        h_hat, conf = estimator.predict(h.context)
        C_alpha = conformal_set(h_hat, alpha)
        for a_x in A_x:
            ratings = rater_pool.rate_blinded(a_x, h, shuffle=True)
            profile[(h, a_x)] = {
                'r_mean': mean(ratings),
                'r_var': var(ratings),
                'kappa': inter_rater_kappa(ratings),
                'C_alpha': C_alpha,
                'conf': conf,
            }
    return profile
```

### IP-122 EGC（Empathic Grounding Certificate）

```python
def empathic_certificate(h_hat, conf, C_alpha, a_x, intensity,
                         theta_F, kappa, kappa_0, k_max):
    if kappa < kappa_0:
        return ('reject', 'unreliable_raters', kappa)
    if conf < theta_e or len(C_alpha) > k_max:
        return ('ok', safe_empathy(h_hat, a_x))          # 低强度 + 承认不确定
    if intensity > intensity_bound(conf, len(C_alpha)):  # 定义122的门控
        return ('reject', 'over_expression', intensity)
    fidelity = r_mean * (1 - d_H(h_hat, h) / d_max)
    if fidelity < theta_F:
        return ('reject', 'low_fidelity', fidelity)
    return ('ok', E_cert(h_hat, C_alpha, conf, a_x,
                         intensity, fidelity, kappa))
```

### IP-123 BRP（Baseline Reproduction Protocol）

```python
def reproduce_baseline(B, env, seeds, metrics, reported, eps_rep):
    h_env = hash_env(env)
    runs = [B.run(seed=s, env=env) for s in seeds]
    certs = {}
    for m in metrics:
        dist = bootstrap_distribution([r[m] for r in runs])
        gap = wasserstein_1(dist, reported[m])
        power = posthoc_power(dist, eps_rep[m])
        if gap > eps_rep[m]:
            return ('reject', 'baseline_not_reproduced', m, gap)
        if power < 0.8:
            return ('reject', 'underpowered', m, power)
        certs[m] = (dist, gap, power)
    return ('ok', R_cert(B, h_env, seeds, certs))
```

### IP-124 RAR（Reproduction-Adjusted Robustness）

```python
def reproduction_adjusted_gain(rho_new, rho_base_runs, r_rep, alpha=0.05):
    gains, pvals = {}, {}
    for m in rho_new:
        base = rho_base_runs[m]
        gains[m] = lcb(rho_new[m] - mean(base), alpha)
        pvals[m] = permutation_test(rho_new[m], base)
    adj = holm_bonferroni(pvals)
    valid = {m for m in gains if adj[m] < alpha and gains[m] > r_rep[m]}
    return valid, gains, adj
```

### IP-125 ERL（Empathy-Reproduction Loop）

```python
def empathy_ablation(agent, tasks, humans, seeds,
                     conditions=('empathy_on', 'empathy_off', 'sham_empathy')):
    results = {}
    for s in seeds:
        for cond in conditions:
            for task, human in balanced_pairs(tasks, humans, seed=s):
                trace = agent.run(task, human, empathy=cond, seed=s)
                results[(cond, task, human, s)] = {
                    'success': trace.success,
                    'correction_latency': trace.t_correct,
                    'trust_calibration': trust_error(trace, human),
                    'empathy_rating': blinded_rating(trace),
                }
    return results   # sham 匹配交互时长与信息量，仅改变情感断言强度
```

### IP-126 JERC（Joint Empathy-Reproduction Certificate）

```python
def joint_validity_certificate(E_cert, R_cert, gains, r_rep, prereg, alpha=0.05):
    if E_cert.kappa < kappa_0 or E_cert.fidelity < theta_F:
        return ('reject', 'empathy_not_grounded')
    if any(R_cert.gap[m] > R_cert.eps[m] for m in R_cert.metrics):
        return ('reject', 'baseline_not_reproduced')
    if prereg.hypotheses != E_cert.hypotheses:
        return ('reject', 'posthoc_hypothesis')
    valid = {m for m in gains if gains[m] > r_rep[m]}
    if not valid:
        return ('reject', 'gain_within_reproduction_noise')
    return ('ok', J_V(E_cert, R_cert, valid, r_rep, prereg))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| EEP | O(|H|·|A_x|·|R|) | O(|H|·|A_x|) | 多评分者 κ、共形覆盖 |
| EGC | O(|C_α|+|A_x|) | O(|C_α|) | 强度门控 sound、弃权完备 |
| BRP | O(|B|·|S|·|M|) | O(|S|·|M|) | 环境哈希一致、功效充足 |
| RAR | O(Boot·|M|) | O(|M|) | 半径校准、FWER 控制 |
| ERL | O(|T|·|K|·|S|·|U|) | O(|T|·|K|·|S|·|U|) | 随机平衡、盲评 |
| JERC | O(|M|) | O(|M|) | 双通道闸门、预注册一致 |

**正确性定理（双向有效性放行定理）**
假设承接 (A22)–(A28)，并新增：**(A29) 共形有效性**：可交换性下真实 `h` 落入 `C_α` 的概率 `≥ 1-α`；**(A30) 证据门控单调**：`I(a_x) ≤ β(conf,|C_α|)`，`β` 关于 `conf` 增、关于 `|C_α|` 减；**(A31) 复现匹配与功效**：`h_env` 一致、`g_rep ≤ ε_rep`、功效 `≥ 1-β_pow`；**(A32) 盲法消融**：on/off/sham 三条件随机平衡、评分者盲法、`κ ≥ κ_0`。
则对任何经 `J_V` 放行的「共情条件鲁棒性提升」声称，真实效应超过复现半径的概率满足：
```
P(effect > r_rep | release) ≥ 1 - α_conf - α_FWER - α_rep - β_pow - β_E - γ_shared
```
其中 `γ_shared` 为两条有效性通道共享同一 harness 的相关失效项，必须由**独立重实现**估计；若无法估计，取 `γ_shared = 1`，即禁止声称。
**推论（历史审计规则）**：当 `r_rep ≥ 历史声称增益` 时，该增益应降级为「未区分于噪声」——这正是本轮对前 54 轮 E1xx 的统一审计口径。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共情表达被感知为操纵/越界 | 高 | 透明声明 + 可退出 + 强度上限 + 伦理审查 |
| 情感标注跨文化/跨评分者不稳 | 高 | 多评分者 + κ 门槛 + 文化分层 + 共形集 |
| 基线伪复现（共享 harness bug） | 高 | 独立重实现 + 环境哈希 + 第三方盲复现 |
| 复现半径低估导致虚假显著 | 高 | 嵌套 bootstrap + 功效分析 + 预注册 |
| 共情消融混淆（时长/注意力） | 中 | sham 匹配时长与信息量 + 盲评 |
| 人类被试成本高 | 中 | 序贯检验 + 自适应停止 + 分层抽样 |

## 6. 本轮最大风险

**一句话**：共情表达与基线复现看似一外一内、互相独立，实则共享同一套实验 harness 与人类评分流程——最危险的不是单点失败，而是**两条有效性通道被同一个系统性偏差同时欺骗**：共情让人因好感降低监督（共情剧场），伪复现又给这套 harness 盖章（伪基线），于是 `J_V` 联合证书会以很高置信度放行一个「被喜欢但没做成」的系统；故必须以独立重实现、sham 消融与预注册阈值**切断两条通道的相关性**，宁可拒绝放行，也不让双向证书变成双向背书。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-EEBR（EEP×EGC×BRP×RAR×ERL×JERC）

> 承接第 54 轮产物 v31。本轮不新增执行能力，而是在 `L0.5++ 动作-协同层` 之上增加 **L0.6 双向有效性层**，作为所有对外声称的**放行闸门**：
> - **EEP（Empathic Expression Profiling）**：把共情表达纳入动作剖面，建立情感状态 → 表达动作的可校准映射；
> - **EGC（Empathic Grounding Certificate）**：用共形集与证据门控约束表达强度，输出 `E_cert`；
> - **BRP（Baseline Reproduction Protocol）**：环境哈希 + 种子分布 + 等价性检验，输出 `R_cert`；
> - **RAR（Reproduction-Adjusted Robustness）**：用复现半径 `r_rep` 校正鲁棒性增益，`ρ^R = LCB(ρ) - r_rep`；
> - **ERL（Empathy-Reproduction Loop）**：empathy_on / off / sham 三条件盲法消融，把共情增益与复现噪声分离；
> - **JERC（Joint Empathy-Reproduction Certificate）**：`J_V` 双通道联合放行证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-118/120，使其证书必须消费 `R_cert` 与 `E_cert`。

### IP-121 EEP

```python
def empathic_profile(estimator, rater_pool, H_grid, A_x, alpha=0.1):
    profile = {}
    for h in H_grid:
        h_hat, conf = estimator.predict(h.context)
        C_alpha = conformal_set(h_hat, alpha)
        for a_x in A_x:
            ratings = rater_pool.rate_blinded(a_x, h, shuffle=True)
            profile[(h, a_x)] = {
                'r_mean': mean(ratings),
                'r_var': var(ratings),
                'kappa': inter_rater_kappa(ratings),
                'C_alpha': C_alpha,
                'conf': conf,
            }
    return profile
```

### IP-122 EGC

```python
def empathic_certificate(h_hat, conf, C_alpha, a_x, intensity,
                         theta_F, kappa, kappa_0, k_max):
    if kappa < kappa_0:
        return ('reject', 'unreliable_raters', kappa)
    if conf < theta_e or len(C_alpha) > k_max:
        return ('ok', safe_empathy(h_hat, a_x))          # 低强度 + 承认不确定
    if intensity > intensity_bound(conf, len(C_alpha)):
        return ('reject', 'over_expression', intensity)
    fidelity = r_mean * (1 - d_H(h_hat, h) / d_max)
    if fidelity < theta_F:
        return ('reject', 'low_fidelity', fidelity)
    return ('ok', E_cert(h_hat, C_alpha, conf, a_x,
                         intensity, fidelity, kappa))
```

### IP-123 BRP

```python
def reproduce_baseline(B, env, seeds, metrics, reported, eps_rep):
    h_env = hash_env(env)
    runs = [B.run(seed=s, env=env) for s in seeds]
    certs = {}
    for m in metrics:
        dist = bootstrap_distribution([r[m] for r in runs])
        gap = wasserstein_1(dist, reported[m])
        power = posthoc_power(dist, eps_rep[m])
        if gap > eps_rep[m]:
            return ('reject', 'baseline_not_reproduced', m, gap)
        if power < 0.8:
            return ('reject', 'underpowered', m, power)
        certs[m] = (dist, gap, power)
    return ('ok', R_cert(B, h_env, seeds, certs))
```

### IP-124 RAR

```python
def reproduction_adjusted_gain(rho_new, rho_base_runs, r_rep, alpha=0.05):
    gains, pvals = {}, {}
    for m in rho_new:
        base = rho_base_runs[m]
        gains[m] = lcb(rho_new[m] - mean(base), alpha)
        pvals[m] = permutation_test(rho_new[m], base)
    adj = holm_bonferroni(pvals)
    valid = {m for m in gains if adj[m] < alpha and gains[m] > r_rep[m]}
    return valid, gains, adj
```

```python
def empathy_ablation(agent, tasks, humans, seeds,
                     conditions=('empathy_on', 'empathy_off', 'sham_empathy')):
    results = {}
```

### IP-126 JERC

```python
def joint_validity_certificate(E_cert, R_cert, gains, r_rep, prereg, alpha=0.05):
    if E_cert.kappa < kappa_0 or E_cert.fidelity < theta_F:
        return ('reject', 'empathy_not_grounded')
    if any(R_cert.gap[m] > R_cert.eps[m] for m in R_cert.metrics):
        return ('reject', 'baseline_not_reproduced')
    if prereg.hypotheses != E_cert.hypotheses:
        return ('reject', 'posthoc_hypothesis')
    valid = {m for m in gains if gains[m] > r_rep[m]}
    if not valid:
        return ('reject', 'gain_within_reproduction_noise')
    return ('ok', J_V(E_cert, R_cert, valid, r_rep, prereg))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EEP | O(|H|·|A_x|·|R|) | O(|H|·|A_x|) | 多评分者 κ ≥ κ_0，共形覆盖 1-α |
| EGC | O(|C_α|+|A_x|) | O(|C_α|) | 强度门控 sound、弃权完备 |
| BRP | O(|B|·|S|·|M|) | O(|S|·|M|) | 环境哈希一致、功效 ≥ 1-β_pow |
| RAR | O(Boot·|M|) | O(|M|) | 半径校准、FWER ≤ α |
| ERL | O(|T|·|K|·|S|·|U|) | O(|T|·|K|·|S|·|U|) | 三条件随机平衡、盲评 |
| JERC | O(|M|) | O(|M|) | 双通道闸门、预注册一致 |

**正确性定理（双向有效性放行定理）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** 共形有效性：可交换性下 `P(h∈C_α) ≥ 1-α`；**(A30)** 证据门控单调：`I(a_x) ≤ β(conf,|C_α|)`；**(A31)** `h_env` 匹配、`g_rep≤ε_rep`、功效 `≥1-β_pow`；**(A32)** on/off/sham 随机平衡、评分者盲法、`κ≥κ_0`。
则经 `J_V` 放行的声称满足：
```
P(effect > r_rep | release) ≥ 1 - α_conf - α_FWER - α_rep - β_pow - β_E - γ_shared
```
`γ_shared` 由独立重实现估计；不可估计时取 1（禁止声称）。**推论**：`r_rep ≥ 声称增益` 的结论一律降级为「未区分于噪声」。

## 7. 本轮最大风险

**一句话**：共情表达与基线复现看似一外一内、互相独立，实则共享同一套实验 harness 与人类评分流程——最危险的不是单点失败，而是**两条有效性通道被同一个系统性偏差同时欺骗**：共情让人因好感降低监督（共情剧场），伪复现又给这套 harness 盖章（伪基线），于是 `J_V` 会以很高置信度放行一个「被喜欢但没做成」的系统；故必须以独立重实现、sham 消融与预注册阈值切断两条通道的相关性，宁可拒绝放行，也不让双向证书变成双向背书。
