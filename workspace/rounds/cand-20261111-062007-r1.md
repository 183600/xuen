# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「数据配比」×「自适应控制」）

> 第 54 轮把技能组合推进到动作空间剖面 α_S、云边映射 γ_ce 与联合证书 J。但其 soundness 的第一块基石——"动作剖面由结构化仿真校准、覆盖可判定"——其实是一个**关于数据的隐含假设**：哪些动作被采样、以什么比例进入校准集。本轮把**数据配比**从训练超参数提升为**证书契约参数**，并用**自适应控制**闭环调节配比。核心矛盾：H22：证书的可靠性不在"平均精度"，而在"数据配比支撑的域"；平均精度高但极端动作欠采样的配比会制造"自信的盲区"。H23：在线自适应配比用证书自身的反馈来调数据，形成自证偏差（data incest），越调越只看见自己想看见的。

## 0. 直觉与动机

**灵感 1（数据配比 = 证书的定义域预算）**
直觉：同一技能在"名义数据 99% + 极端数据 1%"上校准，和在"名义 60% + 极端 40%"上校准，得到的 ρ/α 数值可能相同，但**能用它们说话的地方**完全不同。数据配比不是让模型更准的旋钮，而是决定证书在动作-环境空间上"哪里有资格成立"的预算。因此证书应携带 `V(w)`——由配比 w 支撑的有效域；域外的 `α_S=1` 一律视为"未观测"而非"已覆盖"。

**灵感 2（覆盖缺口，而非平均误差）**
直觉：安全关键系统怕的不是平均误差，而是**目标分布中没被数据覆盖的那块质量**。定义覆盖缺口 `CD(w)=Σ_k max(0, q_k - p_w(k))`，其中 `q_k` 是目标任务在动作-环境格 k 上的质量，`p_w(k)` 是配比诱导的数据质量。它比"验证集精度"更贴近部署风险：CD 大的地方，证书没有证据，只是没被证伪。

**灵感 3（配比作为控制量，证书作为观测）**
直觉：把 `w(t)` 当作控制输入，把边端 Explain 回传的失配率、覆盖缺口、证书域外触发当作观测，构造带死区与投影的自适应律 `w(t+1)=Proj_Δ(w(t)-η·sgn(e)·∇̂L(w))`。目标不是最小化训练损失，而是把 `CD` 拉回参考带 `[CD*-ε_dz, CD*+ε_dz]`。这把第 54 轮的"主动采样"从启发式升级为**有参考模型、有稳定性条件的闭环**。

**灵感 4（审计锚：对抗自证偏差）**
直觉：如果自适应配比只看自己签发的证书，就会形成"数据近亲繁殖"：系统把资源投向自己已经擅长、已覆盖的区域，证书域越来越窄却越来越自信。必须保留一份**不可被策略选择掉的审计流** `w_audit`（随机均匀 / 红队 / 外生基准），它是唯一能估计真实 `R_T` 与 `CD` 的无偏信标。

**灵感 5（数据-控制联合证书）**
直觉：第 54 轮的 `J=(ρ,A_cert,γ_ce,δ_a)` 只是"模型侧"证书；本轮叠加"数据侧"证书 `D=(w,n_eff,V(w),CD(w),Aud)`，形成 `J_dc=(J_w,D,u)`。部署条件变为：`V(w)⊇A_core` 且 `CD(w)≤Θ_cd` 且 `Aud≤Θ_aud`。**没有数据配比支撑的动作核心集，不允许被写进承诺。**

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证据源与数据配比策略）**
证据源 `{P_j}_{j=1}^m`（真实边端回放、云端 GenSim、对抗红队、失败重放、外生审计），采集成本 `c_j`。数据配比策略 `w∈Δ^{m-1}`，总量 `n` 时 `n_j≈w_j n`。诱导证据分布 `P_w=Σ_j w_j P_j`。有效样本量 `n_eff(w)=n/Σ_j w_j^2`（Kish 有效样本量）。

**定义 122（覆盖缺口与支撑域）**
把动作-环境空间划分为格 `{B_k}`，目标任务质量 `q_k`、数据质量 `p_w(k)=Σ_j w_j P_j(B_k)`。覆盖缺口
```
CD(w)=Σ_k max(0, q_k - p_w(k)) ∈ [0,1]
```
配比支撑域 `V(w)={k | p_w(k) ≥ ν q_k}`，`ν` 为域阈值。

**定义 123（配比条件证书）**
`J_w=(J, w, n, n_eff, V(w), CD(w), κ)`。其 soundness 仅在 `V(w)` 上声明：`∀x∈V(w)`，以概率 `≥1-κ`
```
R_T(J) ≤ Σ_j w_j R̂_j + ε_conc(n_eff,κ) + CD(w) + σ_s·τ_loop
```
其中 `R̂_j` 为源 j 上经验风险，`ε_conc=sqrt(ln(1/κ)/(2n_eff))`，`σ_s` 为非平稳漂移，`τ_loop` 为 Explain 回传延迟。**域外一律回答 `unknown`，不得复用域内结论。**

**定义 124（配比自适应控制律）**
误差 `e(t)=CD(w(t))-CD*`，参考模型给出目标带 `[CD*-ε_dz, CD*+ε_dz]`。带投影与死区的更新：
```
w(t+1)=Proj_Δ( w(t) - η(t)·sgn(e(t))·∇̂L(w(t)) )
L(w)=CD(w)+λ·R̂_mix(w)+μ·C(w)-γ·H(w)
```
`H(w)=-Σ_j w_j ln w_j` 为熵（防配比塌缩），`C(w)=Σ_j w_j c_j` 为采集成本；`sgn(e)` 仅在 `|e|>ε_dz` 时非零（死区）；`Proj_Δ` 为概率单纯形投影。

**定义 125（审计锚与外生信标）**
审计分量 `w_audit≥w_min`，其采样**不受证书与自适应律影响**（随机均匀 / 红队 / 外生基准）。审计漂移 `Aud(t)=|R_T^{aud}-R_T^{cert}|` 是证书自证偏差的可观测上界代理。

**定义 126（数据-控制联合证书）**
`J_dc=(J_w, D, u)`，`D=(w,n_eff,V(w),CD(w),Aud)`，`u` 为最近控制动作与投影记录。可部署条件：
```
V(w) ⊇ A_core ∧ CD(w) ≤ Θ_cd ∧ Aud ≤ Θ_aud ∧ δ_a ≤ Θ_a
```
否则降级为 `unknown`，并回退到上一枚 `V(w)` 非空的快照证书。

## 2. 关键算法 伪代码

### IP-121 DCP（Data Composition Policy）

```python
def solve_mix(sources, target_q, budget, nu=0.1, eps=1e-3):
    # 目标：在成本预算下最小化 CD(w)，并保证 V(w) 覆盖 A_core
    w = uniform(sources)
    for _ in range(max_iter):
        grad = coverage_gradient(w, target_q) + cost_gradient(w, budget)
        w = project_simplex(w - lr * grad)
        if coverage_deficit(w, target_q) <= eps:
            break
    return MixPolicy(w, CD=coverage_deficit(w, target_q),
                     V=support_domain(w, target_q, nu),
                     n_eff=effective_n(w, n))
```

### IP-122 MCC（Mixture-Conditioned Certificate）

```python
def certify_with_mix(skill, mix, kappa, A_core):
    alpha = weighted_profile(skill, mix)          # 配比加权 alpha_S
    rho   = weighted_spectrum(skill, mix)         # 配比加权 rho
    if not domain_covers(mix.V, A_core):
        return ('unknown', 'coverage_unsupported', mix.CD)
    eps = sqrt(log(1/kappa) / (2 * mix.n_eff))
    ub  = weighted_empirical_risk(skill, mix) + eps + mix.CD + drift_bound
    return ('ok', MixCertificate(rho, alpha, mix.V, mix.CD, eps, ub))
```

### IP-123 ACR（Adaptive Composition Regulation）

```python
def acr_step(w, mix, explain, ref):
    e = mix.CD - ref.CD_star
    if abs(e) <= ref.deadzone:                    # 死区：不追噪声
        return w, 'hold'
    g = coverage_gradient(w, ref.q) + ref.lam * cert_grad(explain)
    w_new = project_simplex(w - ref.eta * sign(e) * g)
    w_new = entropy_floor(w_new, ref.w_min)       # 防配比塌缩
    w_new[AUDIT] = max(w_new[AUDIT], ref.w_audit) # 审计锚不可被选掉
    if coverage_deficit(w_new, ref.q) > ref.CD_max:
        return w, 'reject_and_rollback'           # 域不扩大则不动
    return w_new, 'update'
```

### IP-124 CDG（Coverage Deficit Guard）

```python
def guard(cert_old, cert_new, audit):
    if cert_new.V < cert_old.V:                   # 域收缩必须显式登记
        cert_new = shrink_domain(cert_new, reason='coverage_loss')
    if cert_new.CD > Theta_cd or audit.drift > Theta_aud:
        return rollback_to_snapshot(cert_old)
    return cert_new
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DCP | O(I·m·|B|) | O(m+|B|) | 单纯形投影精确、梯度无偏 |
| MCC | O(m·|B|+|A|) | O(|A|+|B|) | 域覆盖可判定、PAC 界有效 |
| ACR | O(|B|+m) / step | O(m+|B|) | 死区收敛、投影有界、审计锚保留 |
| CDG | O(|V|) | O(|V|) | 域单调不扩张、回滚原子性 |

**正确性定理（Mixture-Conditioned Adaptive Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 在 `V(w)` 上密度比 `dP_T/dP_w ≤ Λ`；**(A30)** 非平稳漂移 `||P_j(t+1)-P_j(t)||_TV ≤ σ_s`，且控制步长满足 `η·L_g < 1`；**(A31)** 审计分量 `w_audit≥w_min` 且与策略独立，Explain 延迟 `≤τ_loop`。
则对任意 `t`，若 `V(w(t))⊇A_core`、`CD(w(t))≤Θ_cd`，以概率 `≥1-κ`：
```
R_T(J_dc) ≤ Σ_j w_j R̂_j + sqrt(ln(1/κ)/(2n_eff)) + CD(w) + σ_s·τ_loop
```
且自适应律在死区外使 `|CD(w(t))-CD*|` 单调不增（至噪声带），死区内 `w` 不变；证书域满足 `V(w(t+1)) ⊆ V(w(t)) ∪ 新增支撑`，即**永不凭空扩大**。关键：数据配比决定证书能说多远，自适应控制只允许在"有证据"的方向上调整，审计锚防止闭环自证。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 自适应配比自证偏差（data incest） | 高 | 审计锚 + 外生 holdout + 因果干预样本 |
| 目标非平稳使 `CD` 失效 | 高 | 遗忘因子 + 滑窗 + 定期重认证 |
| 配比塌缩到少数源 | 中 | 熵下限 + 每源最小配额 + 探索噪声 |
| 证书域过度收缩伤可用性 | 中 | 双侧控制 + 可用性下限 + `unknown` 分级降级 |
| 反馈延迟引发配比振荡 | 中 | 死区 + 投影 + 速率限幅 + 快照回滚 |

## 6. 本轮最大风险

**一句话**：把数据配比作为证书定义域、再用自适应控制闭环调它，第一次让"证据从哪来"成为可审计的安全变量，但整条链的 soundness **依赖审计锚始终外生、目标漂移慢于控制、以及覆盖缺口可被无偏估计**；一旦审计流被策略污染或目标漂移快于配比调整，证书的"有效域"就只是数据策略的自我投影——系统会越来越自信地只在自己看过的地方宣布安全，故必须以**外生审计锚 + 漂移检测触发重认证 + 域外强制 `unknown`** 为硬护栏，宁可承认不知道，绝不让配比自己给自己发合格证。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（DCP×MCC×ACR×CDG×AUD×DAC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书之上，增加 **数据配比作为证书定义域** 与 **配比自适应控制闭环** 两大机制：
> - **DCP（Data Composition Policy）**：以目标质量匹配与成本预算求解数据配比 `w`；
> - **MCC（Mixture-Conditioned Certificate）**：证书携带支撑域 `V(w)`、覆盖缺口 `CD(w)`、有效样本量 `n_eff`；
> - **ACR（Adaptive Composition Regulation）**：带死区 / 投影 / 熵下限的配比自适应律；
> - **CDG（Coverage Deficit Guard）**：域单调不扩张 + 超预算快照回滚；
> - **AUD（Exogenous Audit Anchor）**：策略无关审计流，估计真实 `R_T` 与自证偏差 `Aud`；
> - **DAC（Data-Action-Control Joint Certificate）**：`J_dc=(J_w,D,u)`，数据-动作-控制联合可部署判据。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/118/120 以纳入数据侧证书。

```python
    w = uniform(sources)
    for _ in range(max_iter):
        grad = coverage_gradient(w, target_q) + cost_gradient(w, budget)

                     CD=coverage_deficit(w, target_q),

def project_simplex(v):
    # 标准 Duchi 投影，保证 w>=0 且 sum(w)=1
    u = sorted(v, reverse=True)
    css = cumsum(u)
    rho = max(i for i in range(1, len(v)+1) if u[i-1] + (1 - css[i-1]) / i > 0)
    theta = (css[rho-1] - 1) / rho
    return [max(vi - theta, 0) for vi in v]
```

| DAC | O(m·|B|+|A|) | O(|A|+|B|) | 四条件合取 sound |

**正确性定理（Mixture-Conditioned Adaptive Certificate Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 在 `V(w)` 上密度比 `dP_T/dP_w ≤ Λ`；**(A30)** 非平稳漂移 `||P_j(t+1)-P_j(t)||_TV ≤ σ_s`，控制步长满足 `η·L_g < 1`；**(A31)** 审计分量 `w_audit≥w_min` 且与策略独立，Explain 延迟 `≤τ_loop`。
则对任意 `t`，若 `V(w(t))⊇A_core`、`CD(w(t))≤Θ_cd`，以概率 `≥1-κ`：
```
R_T(J_dc) ≤ Σ_j w_j R̂_j + sqrt(ln(1/κ)/(2n_eff)) + CD(w) + σ_s·τ_loop
```
并且：
1. **域安全**：`V(w(t+1)) ⊆ V(w(t)) ∪ 新增支撑`，证书域永不凭空扩大；
2. **控制收敛**：死区外 `|CD(w(t))-CD*|` 单调不增至噪声带，死区内 `w` 冻结，无极限环；
3. **偏差可观测**：`Aud` 由策略无关审计流给出，`Aud≤Θ_aud` 是"未自证"的必要条件而非充分条件。

关键：**配比决定证书能说多远，控制只允许朝有证据的方向调整，审计锚防止闭环自证。**

## 6. 本轮最大风险

**一句话**：把数据配比作为证书定义域、再用自适应控制闭环调它，第一次让"证据从哪来"成为可审计的安全变量，但整条链的 soundness **依赖审计锚始终外生、目标漂移慢于控制、以及覆盖缺口可被无偏估计**；一旦审计流被策略污染或目标漂移快于配比调整，证书的"有效域"就只是数据策略的自我投影——系统会越来越自信地只在自己看过的地方宣布安全，故必须以**外生审计锚 + 漂移检测触发重认证 + 域外强制 `unknown`** 为硬护栏，宁可承认不知道，绝不让配比自己给自己发合格证。
