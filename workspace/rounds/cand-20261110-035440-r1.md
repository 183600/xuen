# 第 41 轮 · 异常即证据 v8：负空间证书 × 保形异常哨兵 × 异常反哺课程（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「创新点、异常检测」把焦点从「如何证明策略在已知分布上安全」推进到「如何证明系统知道自己何时不再安全」：把异常检测从旁路诊断工具升格为证书体系的一等公民——用保形（conformal）统计给报警以假警率保证，用「负空间证书」显式认证策略的无效域，用异常反哺课程引擎形成「越异常越练」的闭环。

## 0. 直觉与动机

**灵感 1（创新点 → 从「更强的模块」到「不可组合的新能力」）**：过去四十轮大多是「在既有链路上插入一个更强模块」——更强的执行骨干、更准的几何、更聪明的课程。这类增量容易被归类为组合式改良（combinatorial incrementalism）：审稿人只需说「把 A 换成一个更好的 A'」就能消解其新颖性。真正的创新点应当满足**不可组合性**：存在一项能力 K，使得任何由既有 IP 组合而成的系统都无法逼近 Δ 在 K 上的表现。本轮主张：这项能力是**「对自身无效域的自觉」**——v17 的证书全部是正向承诺（在已认证区域内能做到什么），而对「何时会失效」只有事后 RCA 与固定阈值。给系统一个带统计合同的「否定面」，不是给 v17 再加模块，而是改变证书的语义类型：从 `Safe(x) : Prop` 变成 `Safe(x) ⊔ Unknown(x)`，且 `Unknown` 自身可被度量、可被预算、可被审计。为使「创新点」不被滥用，先给出三条判据（定义 27），本轮的三个设计必须逐条通过。

**灵感 2（异常检测 → 报警需要的是统计合同，不是阈值）**：机器人上的异常报警长期不可用的根因不是 score 不够好，而是**没有合同**。固定阈值有三宗罪：a) 误报率随部署分布漂移而失控，运维被迫调松阈值直到漏报；b) 单帧报警无法区分「一次抖动」与「持续变化」；c) 只给「异常/正常」二元标签，不告诉下游该探索、该兜底还是该重认证。保形预测（conformal prediction）给出 distribution-free 的单帧 p 值：只需可交换性，不需分布假设，`P(p ≤ α) ≤ α`。再把单帧 p 值串成**保形测试鞅**（conformal test martingale）或 **e-CUSUM**，就得到序贯合同：无异常时 `P(∃t: M_t ≥ 1/α) ≤ α`（Ville 不等式），等价于平均运行长度 `ARL ≥ 1/α`；异常时给出可分析的检测延迟。分布漂移下用自适应保形推断（ACI）把长期误报率钉在 `α + γ` 内。一句话：**报警从「经验阈值」变成「有假警预算的统计判决」**。

**灵感 3（异常 × 证书 × 课程 → 负空间闭环）**：v17 的 `ValidRegion(C)` 是证书的**定义域**，但从未有人监控「系统是否正在滑出定义域」。异常检测恰好提供这个监控通道，且必须区分两类异常，否则动作会做反：**认知新颖性**（未知物体/地形/任务，传感器本身是好的）应触发探索、扩大不确定球 `B_t`、并把样本送入课程；**传感/执行退化**（激光退化、雨雾粉尘、执行器打滑）应触发兜底与降级，而不是去「探索」一个新世界。两者都通过后，说明是真正的「未知未知」，此时才熔断并升级人类。检测到的异常同时进入证据账本，累计证据（而非单次尖峰）驱动 IP-46 重颁证书。课程引擎（IP-50）由此获得一个**主动难度源**：让任务采样对准「异常出现但尚未被证书覆盖」的边界地带。学习不再是「把已知练熟」，而是「把未知变成已知」。

**三灵感的耦合**：创新点判据约束设计不沦为组合式增量；异常检测提供带统计合同的「否定面传感器」；负空间证书与课程把否定面变成可管理、可收敛的对象。三者把 v17 的「抗漂移活文档」升级为「**知道自己盲区在哪、并主动去补的活文档**」：证书不再默认真空之外皆危险或皆安全，而是显式标注 `Unknown` 并为其分配预算。

## 1. 形式化定义

**定义 27（创新点判据）**：相对既有系统 B，一个想法 Δ 构成本轮的创新点当且仅当同时满足：
- **I1 不可组合性**：存在能力 K 与效应阈值 δ>0，使得对 B 的任意 IP 组合 Π，都有 `Perf_Π(K) ≤ Perf_Δ(K) − δ`；
- **I2 可证伪性**：存在一组预先注册的实验与硬门槛 `(E, θ)`，且实验可在 Δ 缺席时把功效归因于基线；
- **I3 侵入最小性**：Δ 修改的既有接口数 `|ΔI| ≤ k`（本轮取 k=3），新增状态可被整体关闭并回退。

**定义 28（负空间证书 CertNeg）**：技能 h 的契约 C 之外，追加否定面组件
`CertNeg = (s, D_cal, α, A_α, V_eff)`：
- 非一致性分数 `s(x) ∈ R`，可取证书边际轨迹 + 多模态特征（几何 ESDF 统计、视觉嵌入、ODE 残差）的联合打分；
- 校准集 `D_cal ~ P_id`（已认证的在分布数据），`n = |D_cal|`；
- 保形 p 值 `p(x) = (1 + Σ_{i=1}^{n} 1[s(x_i) ≥ s(x)]) / (n+1)`；
- 异常集 `A_α = {x : p(x) ≤ α}`；
- 有效证书域 `V_eff(C) = V(C) ∧ ¬A_α`。
- **覆盖保证**：在可交换性下，`P_{x~D_cal}(x ∈ A_α) ≤ α`，即无效域被误判为有效（漏报）的边际概率受 α 控制；`V_eff` 是「正向已验证 ∧ 未落入否定面」的交集。

**定义 29（保形异常哨兵与序贯合同）**：对在线流 `x_1, x_2, …`，逐帧构造保形 p 值 `p_t`（校准集滑动更新或用 ACI 修正水平）。取非增下注函数族 `f_t: [0,1] → R_{≥0}` 且 `∫_0^1 f_t(u) du ≤ 1`（在 p 小处下注大），定义测试鞅
`M_t = Π_{s=1}^{t} f_s(p_s), M_0 = 1`。
- **定理（误报控制）**：若 `p_t` 在 H0 下超均匀且近似独立，则 `M_t` 为非负上鞅，Ville 不等式给出 `P(∃t: M_t ≥ 1/α) ≤ α`；首次报警时刻 `τ = inf{t: M_t ≥ 1/α}` 满足 `ARL ≥ 1/α`。
- **漂移鲁棒**：非可交换时用 ACI 更新 `α_{t+1} = α_t + γ(α − err_t)`，长期误报率 `≤ α + γ`；用 e-CUSUM 的漂移项 `E_t = max(0, E_{t−1} + λ_t − κ)` 获得检测延迟上界（由 e-value 的 KL 下界给出）。
- **多通道**：对语义/物理两个通道分别给 `p_t^{sem}, p_t^{phys}`，联合报警需两通道证据同时越界（AND），以压低良性新颖性造成的误熔断。

**定义 30（异常语义分解与路由）**：设 `p^{sem}` 来自语义特征空间、`p^{phys}` 来自物理一致性残差（LIO 残差、ESDF 突变、执行器跟踪误差）。路由
`R(x) ∈ {normal, explore, fallback, revoke}`：
- `p^{sem} > α_s ∧ p^{phys} > α_p` → normal；
- `p^{sem} ≤ α_s ∧ p^{phys} > α_p` → **认知新颖性** → explore（扩 `B_t`、请求主动感知、入课程）；
- `p^{sem} > α_s ∧ p^{phys} ≤ α_p` → **传感/执行退化** → fallback（降级、切保守技能）；
- `p^{sem} ≤ α_s ∧ p^{phys} ≤ α_p` → **未知未知** → revoke（安全停、升级人类、强制重认证）。
路由错误代价不对称：把退化误判为新颖性（→explore）最危险，需单独设误路由率门槛。

**定义 31（异常反哺的课程难度）**：在定义 26 的证书赤字上增加异常项
`D_anom(τ) = E_{x~τ}[ max(0, 1 − p(x)/α) ]`，
总难度 `D(τ) = D_cert(τ) + w_anom · D_anom(τ)`。课程带采样偏置到 `D_anom` 高但尚未违约的地带，回放权重同时覆盖异常类型，使「异常覆盖」成为与证书边际并列的一等难度轴。

## 2. 三大产出设计

### 2.1 IP-51 CONFORMAL-ANOMALY-SENTINEL（保形异常哨兵）

1. **三源打分**：a) 证书边际轨迹 `m(x) = (m_1…m_p)` 的时序非一致性（如多元分位/马氏距离的保形化）；b) 几何与语义特征（ESDF 统计量、点云密度、视觉嵌入、种子相似度）；c) 执行一致性（ODE 残差、动作块重叠区差异、IMU-里程计残差）。三源分别保形化后做可学习的对数池化，池化权重在校准集上以「误报预算内最大化检测功效」为目标拟合。
2. **序贯判决**：单帧 p 值 → 测试鞅 + e-CUSUM 双通道；测试鞅负责「是否存在系统性变化」的低误报长程监控，e-CUSUM 负责「变化发生时刻」的低延迟定位。
3. **漂移自适应**：ACI 在线校正每通道工作点，显式维护「误报预算账本」；良性新颖性（新但安全）通过 AND 规则与迟滞避免频繁熔断。
4. **可解释输出**：每次报警输出「哪一源、哪一通道、证据强度 e 值、建议路由 R(x)」，写入 IP-46 的证据账本，供重认证与审计。
5. **开销控制**：滑窗保形分位用增量数据结构（t-digest / 有序直方图），逐帧 O(log n)，不阻塞流式执行。

### 2.2 IP-52 NEGATIVE-SPACE-CERTIFICATE（负空间证书）

1. **契约扩展**：技能契约的 `SemanticType` 由 `C_ms` 扩展为 `C_ms^⊥ = (φ_sem, B, A_α)`；类型蕴含增加否定面条件：`C^⊥ ⊢ C'^⊥ ⟺ φ_sem ⊨ φ_sem' ∧ B ⊆ B' ∧ A'_α ⊆ A_α`（否定面越大越保守、越可组合）。
2. **有效域发布**：`V_eff` 上报 Registry；IP-45 网关路由从「在 `ValidRegion` 内」升级为「在 `V_eff` 内且未触发哨兵」，出域或报警即熔断（新增第五、第六触发器）。
3. **未知未知条款**：契约显式声明「本证书不覆盖 `A_α`，落入 `A_α` 时行为未认证」；禁止把 `Unknown` 静默当作 `Safe`。回退策略必须与契约一同注册并热更新。
4. **证据账本**：报警不以单次尖峰重颁证书，而以累计 e 证据 `E_accum = Σ log e_t` 越过阈值触发；重颁后 `A_α` 更新（收缩或迁移），并记录「哪类异常被吸收」。
5. **审计接口**：输出 `certificate_coverage = 1−α`、`A_α` 的体积估计、`V_eff` 占比、以及「最近一次证明它无效」的证据链。

### 2.3 IP-53 ANOMALY-CURRICULUM-COUPLER（异常反哺课程）

1. **异常入课**：`explore` 路由产生的样本与仿真中注入的异常族，按 `D_anom` 加权进入 IP-50 的任务采样；对退化类异常不采样任务，而是采样「降级技能 + 兜底策略」的训练对。
2. **异常覆盖回放**：回放缓冲按「异常类型 × 证书赤字」二维分桶，保证每类异常都有最小覆盖配额，防遗忘与长尾塌缩。
3. **闭环重认证**：异常证据累计越界 → 触发 IP-46 重颁 → 契约与回退策略热更新 → 新证书重新计算 `V_eff`；形成「检测—学习—重认证—收缩盲区」的闭环。
4. **课程目标**：不是最大化成功率，而是最大化「在固定误报预算下被吸收的异常体积」，即 `max Δ|A_α^{absorbed}|`，避免为刷成功率而选择性忽略异常。

## 4. 实验设计（E73-E78 硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E73 误报合同 | 静态校准集经验 FPR；交换性持有集 ARL | FPR ≤ 1.2% @α=1%；ARL ≥ 0.8/α |
| E74 检测延迟 | 注入 6 类异常的中位检测延迟与召回 | 延迟 ≤ 3 帧（≤0.3s@10Hz）；5 帧内召回 ≥95% |
| E75 负空间覆盖 | 保形覆盖 1−α；OOD 上异常召回/误报 | 覆盖 ∈[0.98,1.0]；召回≥90%、FPR≤5% |
| E76 语义路由 | 认知/退化分类准确率；危险误路由率 | 准确率≥85%；退化→explore 误路由 ≤1% |
| E77 异常反哺课程 | 相对 E71 的每千步安全违约与样本效率 | 违约下降≥40%；样本效率提升≥25% |
| E78 端到端新异常 | 新异常族下近碰撞率、证书违约率 | 近碰撞下降≥40%；违约<0.5%，零灾难 |

**分布漂移专项（E73b/E75b）**：在长时部署日志上按时间切分，测「误报率随漂移的漂移量」，要求 ACI 开启后长期 FPR ≤ α+γ 且不出现持续漏报。此专项是回退判据：若失控，保留哨兵为诊断工具，负空间证书降级为 advisory，不参与熔断。

**回退路径**：E73/E75 不达标 → 回退 v17（固定阈值 + 迟滞 RCA），IP-51 仅离线分析、IP-53 仅离线难例挖掘。

## 5. 创新点自检（对定义 27）

## 6. 本轮最大风险

**一句话**：保形合同的全部效力都寄生在「校准集可交换 / 近似可交换」之上，而真实机器人长时部署几乎必然破坏它，且异常可能在「证书边际 + 多模态特征」张成的表示中不可见——一旦如此，误报控制与负空间证书会同时失效，系统陷入「要么误熔断、要么静默漏报」的两难，故必须以 E73b（漂移下 FPR 漂移量）而非静态校准结果作为本轮第一守门实验。

## 1. 符号体系（承接定义 19-31）

| 符号 | 含义 | 定义 |
|---|---|---|
| `C_ms^⊥` | 负空间契约类型 | `(φ_sem, B, A_α)`；`⊢` 需 `φ_sem⊨φ_sem' ∧ B⊆B' ∧ A'_α⊆A_α` |
| `s(x)` | 非一致性分数 | 边际轨迹 + 几何语义特征 + 执行残差的联合打分 |
| `p(x)` | 保形 p 值 | `(1+#{s(x_i)≥s(x)})/(n+1)`，`x_i~D_cal` |
| `A_α` | 异常集（负空间） | `{x: p(x)≤α}`；`P_{D_cal}(A_α)≤α` |
| `V_eff(C)` | 有效证书域 | `V(C) ∧ ¬A_α`；路由与熔断的实际判据 |
| `M_t` | 保形测试鞅 | `Π f_s(p_s)`，`f` 非增且 `∫f≤1`；Ville：`P(∃t:M_t≥1/α)≤α` |
| `E_t` | e-CUSUM 证据 | `max(0,E_{t−1}+λ_t−κ)`，用于检测延迟控制 |
| `p^sem / p^phys` | 双通道 p 值 | 语义新颖性 / 物理一致性退化 |
| `R(x)` | 语义路由 | `{normal, explore, fallback, revoke}`（见定义 30 真值表） |
| `D_anom(τ)` | 异常难度 | `E_{x~τ}[max(0,1−p(x)/α)]` |
| `E_accum` | 证据账本 | `Σ log e_t`；越过阈值才触发重颁，抑制单尖峰误重颁 |

## 2. 关键算法

### IP-51 保形异常哨兵（伪代码）
```
def conformal_p(score, cal_scores):          # 单帧、distribution-free
    n = len(cal_scores)
    return (1 + sum(1 for c in cal_scores if c >= score)) / (n + 1)

def sentinel_stream(x_t, cal, alpha=0.01, gamma=0.01):
    s_sem, s_phys = score_sem(x_t), score_phys(x_t)
    p_sem  = conformal_p(s_sem,  cal.sem)
    p_phys = conformal_p(s_phys, cal.phys)
    f = betting_fn()                          # 非增，∫f≤1，在 p 小处下注大
    M = M * f(p_sem) * f(p_phys) if joint else M  # 或双通道 AND
    E = max(0.0, E + log_evalue(p_sem, p_phys) - kappa)   # e-CUSUM
    alarm = (M >= 1/alpha)
    route = route_semantics(p_sem, p_phys, alpha_s, alpha_p)  # 定义 30
    alpha = alpha + gamma * (target_alpha - (p_sem <= alpha))  # ACI（漂移）
    cal.update_incremental(x_t)               # t-digest 滑窗，O(log n)
    return alarm, route, evidence(M, E, p_sem, p_phys)

def route_semantics(p_sem, p_phys, a_s, a_p):
    if p_sem <= a_s and p_phys >  a_p: return "explore"    # 认知新颖性
    if p_sem >  a_s and p_phys <= a_p: return "fallback"   # 传感/执行退化
    if p_sem <= a_s and p_phys <= a_p: return "revoke"     # 未知未知
    return "normal"
```

### IP-52 负空间证书（伪代码）
```
def build_negative_certificate(skill, cal_set, alpha=0.01):
    scores = [nonconformity(x, skill) for x in cal_set]
    A_alpha = ConformalSet(scores, alpha)          # 隐式集合 / 分数阈值
    V_eff   = lambda x: in_valid_region(skill, x) and not A_alpha.contains(x)
    return CertNeg(scores, alpha, A_alpha, V_eff,
                   coverage=1 - alpha, ledger=EvidenceLedger())

def gate_route(contract, x, sentinel_state):
    if not contract.V_eff(x):                 return FALLBACK
    if sentinel_state.route == "revoke":      return EMERGENCY_STOP
    if sentinel_state.route == "fallback":    return DEGRADE
    if sentinel_state.route == "explore":     return EXPLORE_THEN_REPLAN
    return EXECUTE

def maybe_recertify(ledger, theta):
    if ledger.E_accum > theta:                # 累计证据，而非单尖峰
        new = RCA.reissue(cert_type="C_ms^perp")
        Registry.publish_negative_space(new.A_alpha)
        Registry.hot_reload(contracts, fallback_policies)
```

### IP-53 异常反哺课程（伪代码）
```
def anomaly_curriculum_step(band, w_anom=0.5, target=0.7):
    tasks = sample_band(band)                  # P ∝ exp(-(D-D_c)²/2σ²)·replay_w
    for t in tasks:
        d_cert = cert_deficit(t)
        d_anom = mean(max(0, 1 - p(x)/alpha) for x in rollout(t))
        t.D = d_cert + w_anom * d_anom         # 定义 31
    succ = mean(policy_bank.rollout(t).success for t in tasks)
    band.center += eta * (succ - target)       # Robbins-Monro
    replay.fill(explore_buffer, quota=min_coverage_per_anomaly_type)
    objective = absorbed_anomaly_volume()      # max Δ|A_α absorbed|，不刷成功率
    return objective
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| 保形 p 值 | 校准集滑窗 O(log n)（t-digest） | 可交换下 `P(p≤α)≤α`（distribution-free） |
| 测试鞅监控 | 每帧 O(1) | 非负上鞅 + Ville：`P(∃t:M_t≥1/α)≤α`，`ARL≥1/α` |
| e-CUSUM 延迟 | 每帧 O(1) | 检测延迟受 e-value KL 下界控制 |
| ACI 漂移自适应 | 每帧 O(1) | 长期误报率 `≤α+γ`（非平稳下渐近） |
| 负空间证书 | 构建 O(n log n)，查询 O(log n) | 边际 FPR≤α；`V_eff=V∩¬A_α` |
| 语义路由 | 每帧 O(1) | 真值表 + 不对称误路由门槛（E76） |
| 异常入课 | 每任务 O(1)+rollout | 覆盖配额保证长尾不塌缩 |
| 组合契约 | O(|V|+|E|) | `A_α` 并集 + `α_comp=1−Π(1−α_i)`；反单调蕴含传递 |

**正确性边界（必须写进契约）**：保形保证是**边际**（marginal）而非条件（conditional）的——它对「平均而言的漏报率」负责，不对「某个具体子群/某个具体状态」负责。因此高风险子群必须单独校准（Mondrian 保形），否则会出现「总体达标、危险工况漏报」的辛普森式假象。

## 4. 实验设计（E73-E78，硬门槛）

| 实验 | 指标 | 门槛 |

**消融（必须做）**：a) 去掉保形改固定阈值 → 测 FPR 失控；b) 去掉 AND 双通道 → 测良性新颖性误熔断；c) 去掉证据账本 → 测误重颁频率；d) 去掉异常课程 → 测长尾异常覆盖塌缩。四项消融用于支撑 I1 不可组合性证据。

## 6. 本轮最大风险

**一句话**：保形合同的效力完全依赖校准集可交换性，而真实部署的持续漂移与「表示空间不可见异常」会让误报控制与负空间证书同时失效，系统退化为「误熔断」或「静默漏报」二选一，故 E73b/E75 是决定本轮成败的第一守门实验。
