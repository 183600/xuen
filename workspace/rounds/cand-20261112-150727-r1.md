# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「开源硬件」×「多机评测」）

> 第 60 轮把「证据层→执行层」升级为「认知驱动的场景-执行闭环」：SSM 场景语义、CIEC 意图约束、EPIR 因果隔离、SERC 闭环、PCE++++ 四维认知预算。但**三个跨机层面的根本局限**仍未解决：
> 1. **开源硬件的执行不可比性**：BUQ/ERTC/EEIS 都默认「同一台机器、同一套动力学」。开源硬件意味着同一套设计被不同人用不同批次电机、不同装配公差、不同传感器标定复现——同一个 K_safe 在 A 机安全、在 B 机可能失稳；EV-exec 缺少「硬件身份」这一维，证据天然不可跨机比较。
> 2. **多机评测的统计失真**：把多台机器的指标直接求平均，隐含「机器可交换」假设。硬件异质时会产生**辛普森悖论**：某控制器在每台机器上都更差，却因机器分布偏斜而在总体均值上更好；平均指标无法支撑「可复现、可推广」的结论。
> 3. **跨机证据链的断裂**：EPIR 解决的是单机 ROS 消息乱序/丢包，但开放硬件下「任何人都能重建机器人」，若没有**机器无关的规范证据形式**与**可重放执行包**，云端聚合的 EV-exec 既不能在另一台机器上复算，也无法判定两台机器的证据是否属于「同一实验」。

## 0. 直觉与动机

**灵感 1（开源硬件 → 硬件护照 HPI）**
直觉：开源硬件不是「一台机器」，而是「设计 + 实例 + 标定 + 来源」的四元组。同一张 BOM 可以被两双手装出两台动力学不同的机器人；因此证据必须携带**硬件身份**才能被解释。给每台机器发一本「护照」：设计规格 h_spec 是它的出身，实例标定 h_cal 是它的体检，来源链 h_prov 是它的履历。关键洞见：**把「硬件异构」从噪声变成一等公民**——定义硬件距离 d_H，相近者归入同一「等价类」，只有等价类内的 K_safe 与 EV-exec 才允许互相推断和比较。

**灵感 2（开源硬件 → 实例校准执行 ICE）**
直觉：护照只回答「它是谁」，执行层还要回答「它此刻怎样」。把第 59 轮的 BUQ 从「单机在线辨识」升级为「护照先验 + 实例后验」的两级辨识：设计先验给出 θ_nom，实例遥测把后验收紧到 θ_inst；EEIS 编译 K_safe 时按**标定不确定度 + 硬件距离**膨胀安全裕度。关键洞见：**跨机迁移不等于复制参数，而是「带误差界的安全映射」**——K_safe^A 只有在 d_H(A,B) ≤ ε_H 时才能迁移到 B，且必须膨胀 z_{1-α}·sqrt(tr Σ_cal)。

**灵感 3（多机评测 → 跨机证据可比性 CMEC）**
直觉：两台机器都说「接触力 12N」，但 A 的额定力是 30N、B 是 12N，这两句话根本不等价。把 EV-exec 投影到**无量纲、硬件无关的规范坐标** Can(EV-exec, Π) = (F/F_rated, x/workspace_scale, t/T_ctrl, 归一化动力学残差)；只有当护照等价、规范残差小、标定置信度足够时，才判定两份证据「可比」。关键洞见：**可比性是可判定的谓词，而不是想当然的假设**——不可比就必须重标定，而不是硬平均。

**灵感 4（多机评测 → 硬件分层评测 HSA + 多机评测证书 MMEC）**
直觉：多机评测的正确单位不是「机器」，而是「硬件等价类」。先按等价类分层，层内估计效应 τ_h，再用逆方差加权得到总体 μ_strat；同时做**符号一致性检验**以检出辛普森悖论。最终输出一张**多机评测证书**：覆盖了哪些层、每层样本量、置信区间、是否有悖论、来源根哈希、可复现哈希。关键洞见：**评测结论本身就是一份需要签名的证据**——没有覆盖度与功效声明的「平均值」不具备证书资格。

**灵感 5（开源硬件 × 多机评测 → REB + PCE+++++ + FMMEL）**
直觉：开放硬件的价值在于「可重建」，所以评测的终点是**可复现执行包 REB**：护照、控制器版本、K_safe、随机种子、环境规格、EV-exec 一起打包哈希，任何等价机器都能 replay 并在 ε_replay 内复算。评测本身也消耗资源：B_hw（标定/迁移次数）与 B_eval（机器数 K、每机试验数 n）要按**统计功效/成本**联合决策（PCE+++++ 的 VOI：多一台机器 vs 多一次试验，哪个先让置信区间变窄）。最终由**联邦多机演化闭环 FMMEL** 汇聚规范证据、隔离缺陷硬件、把校准先验回传给等价机器。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（开源硬件护照 HPI）** 硬件护照 Π = (h_id, h_spec, h_cal, h_unc, h_prov)。其中：
- **身份**：h_id = H(BOM_hash ‖ serial ‖ assembly_hash)，H 为抗碰撞哈希
- **设计规格**：h_spec = (kinematics, θ_nom, F_rated, workspace_scale, T_ctrl)
- **实例标定**：h_cal = θ_inst = (k_t, b_fric, b_sensor, τ_lat)，由实例辨识得到
- **标定不确定度**：h_unc = Σ_cal（θ_inst 的后验协方差）
- **来源链**：h_prov = [(batch, assembly, calib_log, signature_i)]，逐条签名
- **硬件距离**：d_H(Π,Π') = sqrt((θ_inst−θ'_inst)ᵀ(Σ_cal+Σ'_cal)⁻¹(θ_inst−θ'_inst)) + λ_spec·d_spec + λ_prov·d_prov
- **等价类**：Π ~_ε Π' ⇔ d_H(Π,Π') ≤ ε_H；等价类记为 [Π]
- **护照条件契约**：ERTC_Π = ERTC ∧ C_hw(Π)，即执行契约必须显式携带硬件前提

**定义 162（实例校准执行 ICE）** 给定护照 Π 与实例遥测 D：
- **两级先验**：p(θ|Π) = N(θ_inst, Σ_cal) ⊕ N(θ_nom, Σ_spec)（设计先验在现场被标定先验替换）
- **实例后验**：p(θ|D,Π) ∝ p(D|θ)·p(θ|Π)，在线 BUQ² 更新
- **硬件条件编译**：K_safe^Π = EEIS.compile(δ_f_req, θ_post, inflation = 1 + κ·tr(Σ_post) + λ_H·d_H(Π, Π_ref))
- **跨机迁移算子** T_{A→B}：
```
if d_H(A,B) ≤ ε_H:
    K_safe^B = inflate(K_safe^A, κ_H·d_H(A,B) + z_{1-α}·sqrt(tr Σ_cal^B))
else:
    K_safe^B = ∅        # 超出等价类，必须重标定，禁止迁移
```
- **安全保持**：在 d_H ≤ ε_H 且标定置信度 ≥ τ_cal 下，迁移后接触力峰值 ≤ F_max 的概率 ≥ 1−α。

**定义 163（跨机证据可比性 CMEC）** 规范映射 Can: (EV-exec, Π) → Ỹ：
- Ỹ = (F/F_rated, x/workspace_scale, t/T_ctrl, g(θ_inst))，g 为动力学归一化项
- **可比性谓词**：Comm(E_A,Π_A; E_B,Π_B) = (d_H(Π_A,Π_B) ≤ ε_H) ∧ (‖Can(E_A)−Can(E_B)‖ ≤ ε_canon) ∧ (cal_conf ≥ τ_cal)
- **Lipschitz 界**：‖Can(E_A)−Can(E_B)‖ ≤ L_H·d_H(Π_A,Π_B) + L_e·‖E_A−E_B‖
- **不可比处理**：Comm=false 时禁止跨机平均，只能分层报告或触发重标定。

**定义 164（硬件分层评测 HSA）** 机器总体 M = {m₁,…,m_K}，层 h 为一个硬件等价类：
- **层内效应**：τ_h = μ_h(controller) − μ_h(baseline)
- **分层估计**：μ_strat = Σ_h w_h·μ_h，w_h = n_h/N 或逆方差权重；Var(μ_strat) = Σ_h w_h²·Var_h
- **辛普森判据**：若 ∃h,h′: sign(τ_h) ≠ sign(τ_h′)，且 sign(τ_pooled) ∉ {sign(τ_h)}，则判为辛普森悖论
- **每层样本量**：n_h ≥ 2(z_{1−α/2}+z_{1−β})²·σ_h²/Δ²，保证功效 1−β

**定义 165（多机评测证书 MMEC）** 证书 C_mm = (M_pop, strata, estimates, CIs, paradox_flag, coverage, provenance_root, replay_hash)。
- **验证谓词**：Verify(C_mm) = coverage ≥ K_min ∧ ∀h: n_h ≥ n_min ∧ CI 有效 ∧ 来源链可追溯到 h_id ∧ replay_hash 匹配
- **执行证书合成**：J_mm = ∧_h J_exec^h，每个 J_exec^h 绑定对应 h_id 与 Σ_cal^h；任一层的来源链断裂则 J_mm = ⊥

**定义 166（可复现执行包 REB）** R = (Π*, controller_ver, K_safe, seeds, env_spec, EV-exec, reb_hash)。
- **包哈希**：reb_hash = H(Π*.h_id ‖ controller_ver ‖ K_safe ‖ seeds ‖ env_spec)
- **重放**：replay(R, Π') → EV-exec′
- **可复现谓词**：Repro(R, Π') = Comm(EV-exec, Π*; EV-exec′, Π') ∧ ‖Can(EV-exec′)−Can(EV-exec)‖ ≤ ε_replay

**定义 167（硬件-评测预算 PCE+++++）** B_hw = (B_cal, B_refresh, B_transfer)，B_eval = (B_K, B_n, B_power)。
- **评测价值（VOI）扩展**：
```
voi_hw(π) = E[CI_shrink | K, n] − λ_cal·B_cal − λ_m·K·cost_machine − λ_n·K·n·cost_trial
```
- **预算策略**：选择 (K, n) 最大化 voi_hw 且满足 power ≥ 1−β；若 B_cal 耗尽 ⇒ 退回设计先验并放大 inflation；若 B_eval 耗尽 ⇒ 只报告已有层并标记 underpowered，禁止给出总体结论。

**定义 168（联邦多机演化闭环 FMMEL）** 算子 FMMEL(fleet, task)：
```
① Local_i: EV_i ← m_i.run(task)；Ỹ_i ← Can(EV_i, Π_i)      # 原始数据不出域
② Upload: (Ỹ_i, Π_i.h_id, Σ_cal^i, h_prov_i) → Cloud
③ Stratify: strata ← 按 [Π] 聚类；C_mm ← HSA.aggregate(uploads)
④ Audit: outliers ← {i | d_H(Π_i, centroid([Π_i])) > ε_H 或 规范残差异常}
⑤ Quarantine: 隔离 outliers（缺陷开源硬件），禁止其证据进入总体
⑥ Transfer: 对 i ∉ outliers，p(θ|Π_i) ← 用联邦后验收缩本地先验
⑦ Return (C_mm, outliers, transferred_priors)
```

### IP-161 HPI（硬件护照）

```python
class HardwarePassport:
    def __init__(self, design_spec, serial):
        self.h_id = sha256(json.dumps(
            [design_spec.bom_hash, serial, design_spec.assembly_hash]).encode()
        ).hexdigest()[:32]
        self.spec = design_spec
        self.cal = dict(design_spec.theta_nom)
        self.unc = dict(design_spec.sigma_spec)
        self.prov = []

    def calibrate(self, cal_data, provenance_record):
        theta_inst, Sigma_cal = instance_identify(cal_data, self.spec)
        self.cal, self.unc = theta_inst, Sigma_cal
        self.prov.append(sign_chain(provenance_record, self.h_id))

    def distance(self, other):
        d_theta = vector(self.cal) - vector(other.cal)
        S = diag(self.unc) + diag(other.unc) + 1e-9 * np.eye(len(d_theta))
        return float(np.sqrt(d_theta @ np.linalg.inv(S) @ d_theta)) \
            + 0.1 * spec_distance(self.spec, other.spec) \
            + 0.05 * prov_distance(self.prov, other.prov)

    def equivalent(self, other, eps_H=0.5):
        return self.distance(other) <= eps_H and self.prov_is_rooted()
```

```python
def instance_calibrated_execution(passport, telemetry, delta_f_req, alpha=0.05):
    # 两级先验：护照标定先验 + 在线遥测

def transfer_contract(K_safe_A, passport_A, passport_B, alpha=0.05):
```

```python
def canonicalize(ev_exec, passport):
    s = passport.spec
    return np.array([
        ev_exec.force_peak / s.F_rated,
        ev_exec.contact_pos / s.workspace_scale,
        ev_exec.duration / s.T_ctrl,
        dynamics_residual(ev_exec, passport.cal),
    ])


def commensurable(evA, pA, evB, pB, eps_H=0.5, eps_canon=0.1, tau_cal=0.8):
    if pA.distance(pB) > eps_H:
        return False
    if min(pA.cal_confidence(), pB.cal_confidence()) < tau_cal:
        return False
    return np.linalg.norm(canonicalize(evA, pA) - canonicalize(evB, pB)) <= eps_canon
```

### IP-164 HSA + IP-165 MMEC（分层评测与证书）

```python
def hardware_stratified_assessment(records, metric, alpha=0.05):
    strata = cluster_by_equivalence_class([r.passport for r in records])
    tau_h, var_h, n_h = {}, {}, {}
    for h, idx in strata.items():
        vals_ctrl = [metric(records[i]) for i in idx if records[i].is_controller]
        vals_base = [metric(records[i]) for i in idx if not records[i].is_controller]
        tau_h[h] = mean(vals_ctrl) - mean(vals_base)
        var_h[h] = var(vals_ctrl) / len(vals_ctrl) + var(vals_base) / len(vals_base)
        n_h[h] = len(idx)

    w = {h: 1.0 / var_h[h] for h in strata}
    z = sum(w.values())
    mu_strat = sum(w[h] * tau_h[h] for h in strata) / z
    se_strat = np.sqrt(1.0 / z)
    ci = (mu_strat - norm.ppf(1 - alpha/2) * se_strat,
          mu_strat + norm.ppf(1 - alpha/2) * se_strat)

    signs = {np.sign(v) for v in tau_h.values()}
    pooled = (sum(tau_h[h] * n_h[h] for h in strata) / sum(n_h.values()))
    paradox = len(signs) > 1 and np.sign(pooled) not in signs
    return {'tau_h': tau_h, 'mu_strat': mu_strat, 'ci': ci,
            'paradox': paradox, 'n_h': n_h}


class MultiMachineEvalCertificate:
    def __init__(self, assessment, coverage, provenance_root, replay_hash):
        self.a = assessment
        self.coverage = coverage
        self.provenance_root = provenance_root
        self.replay_hash = replay_hash

    def verify(self, K_min=3, n_min=5):
        return (self.coverage >= K_min
                and all(n >= n_min for n in self.a['n_h'].values())
                and self.a['ci'][0] <= self.a['ci'][1]
                and self.provenance_root is not None
                and self.replay_hash is not None)
```

### IP-166 REB（可复现执行包）

```python
class ReproducibleExecutionBundle:
    def __init__(self, passport, controller_ver, K_safe, seeds, env_spec, ev_exec):
        self.passport = passport
        self.controller_ver = controller_ver
        self.K_safe = K_safe
        self.seeds = seeds
        self.env_spec = env_spec
        self.ev_exec = ev_exec
        self.reb_hash = self._hash()

    def _hash(self):
        blob = json.dumps([self.passport.h_id, self.controller_ver,
                           as_dict(self.K_safe), self.seeds, self.env_spec])
        return sha256(blob.encode()).hexdigest()

    def replay(self, target_passport, runner, eps_replay=0.1):
        if not commensurable(self.ev_exec, self.passport,
                             self.ev_exec, target_passport):
            return None
        ev2 = runner(self.controller_ver, self.K_safe, self.seeds, self.env_spec)
        ok = np.linalg.norm(canonicalize(self.ev_exec, self.passport)
                            - canonicalize(ev2, target_passport)) <= eps_replay
        return ev2 if ok else None
```

### IP-167 PCE+++++（硬件-评测预算）

```python
class HardwareEvalBudget:
    def __init__(self, cal_trials=20, refresh=5, transfer=10,
                 K_machines=5, n_trials=20, power_target=0.8):
        self.B_cal, self.B_refresh, self.B_transfer = cal_trials, refresh, transfer
        self.B_K, self.B_n, self.B_power = K_machines, n_trials, power_target

    def choose_design(self, effect_size, sigma, cost_machine=10.0, cost_trial=1.0):
        n_required = int(np.ceil(
            2 * (norm.ppf(0.975) + norm.ppf(self.B_power)) ** 2 * sigma**2
            / effect_size**2))
        best = None
        for K in range(3, self.B_K + 1):
            for n in range(5, self.B_n + 1):
                if n < n_required:
                    continue
                power = 1 - norm.cdf(norm.ppf(0.975)
                                     - effect_size / (sigma * np.sqrt(2 / n)))
                voi = effect_size / np.sqrt(K * n) \
                    - 0.1 * K * cost_machine - 0.1 * K * n * cost_trial
                if best is None or voi > best['voi']:
                    best = {'K': K, 'n': n, 'power': power, 'voi': voi}
        return best or {'K': self.B_K, 'n': self.B_n, 'power': None, 'voi': None}
```

### IP-168 FMMEL（联邦多机演化闭环）

```python
def federated_multimachine_evolution_loop(fleet, task, eps_H=0.5):
    uploads = []
    for m in fleet:
        ev = m.run(task)                         # 本地执行
        y_canon = canonicalize(ev, m.passport)   # CMEC 规范坐标
        uploads.append({'y': y_canon, 'h_id': m.passport.h_id,
                        'unc': m.passport.unc, 'prov': m.passport.prov,
                        'machine': m.id})

    centroids = cluster_by_equivalence_class([m.passport for m in fleet])
    outliers = [u['machine'] for u in uploads
                if u['h_id'] not in centroids[u['machine']]]

    kept = [u for u in uploads if u['machine'] not in outliers]
    assessment = hardware_stratified_assessment(kept, metric=lambda u: u['y'][0])
    cert = MultiMachineEvalCertificate(
        assessment, coverage=len(set(u['h_id'] for u in kept)),
        provenance_root=merkle_root([u['prov'] for u in kept]),
        replay_hash=merkle_root([u['y'].tobytes() for u in kept]))

    transferred = {}
    for m in fleet:
        if m.id in outliers:
            continue
        transferred[m.id] = shrink_prior_to_fleet(m.passport, kept)
    return cert, outliers, transferred
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HPI | O(d²) 标定/次，O(d²) 距离 | O(d² + |prov|) | 等价类划分稳定，身份抗碰撞 |
| ICE | O(d²) 两级 BUQ²/周期 | O(d²) | 迁移安全保持概率 ≥ 1−α |
| CMEC | O(1) 规范化/样本 | O(1) | 可比性判定 sound（不把不可比判为可比） |
| HSA+MMEC | O(K·d² + K log K) | O(K·d²) | 分层 CI 覆盖率 ≥ 1−α；悖论可检出 |
| REB | O(包大小) 哈希/重放 | O(包大小) | replay 保真度 ≤ ε_replay |
| FMMEL | O(K) 本地 + O(K²) 聚类 | O(K·d) | 缺陷硬件被隔离，联邦统计有效 |

**正确性定理（MERC）**：

```python
class HardwarePassport:
    def __init__(self, design_spec, serial):
        self.h_id = sha256(json.dumps(
            [design_spec.bom_hash, serial, design_spec.assembly_hash]).encode()
        ).hexdigest()[:32]
        self.spec = design_spec
        self.cal = dict(design_spec.theta_nom)
        self.unc = dict(design_spec.sigma_spec)
        self.prov = []
        self.reference = self

    def calibrate(self, cal_data, provenance_record):
        theta_inst, Sigma_cal = instance_identify(cal_data, self.spec)
        self.cal, self.unc = theta_inst, Sigma_cal
        self.prov.append(sign_chain(provenance_record, self.h_id))

    def distance(self, other):
        d_theta = vector(self.cal) - vector(other.cal)
        S = diag(self.unc) + diag(other.unc) + 1e-9 * np.eye(len(d_theta))
        return float(np.sqrt(d_theta @ np.linalg.inv(S) @ d_theta)) \
            + 0.1 * spec_distance(self.spec, other.spec) \
            + 0.05 * prov_distance(self.prov, other.prov)

    def equivalent(self, other, eps_H=0.5):
        return self.distance(other) <= eps_H and self.prov_is_rooted()

    def cal_confidence(self):
        return float(np.exp(-np.trace(self.unc)))
```

### IP-164 HSA + IP-165 MMEC（硬件分层评测与多机证书）

```python
def hardware_stratified_assessment(records, metric, alpha=0.05):
    strata = cluster_by_equivalence_class([r.passport for r in records])
    tau_h, var_h, n_h = {}, {}, {}
    for h, idx in strata.items():
        ctrl = [metric(records[i]) for i in idx if records[i].is_controller]
        base = [metric(records[i]) for i in idx if not records[i].is_controller]
        tau_h[h] = mean(ctrl) - mean(base)
        var_h[h] = var(ctrl) / max(len(ctrl), 1) + var(base) / max(len(base), 1)
        n_h[h] = len(idx)

    w = {h: 1.0 / (var_h[h] + 1e-9) for h in strata}
    z = sum(w.values())
    mu_strat = sum(w[h] * tau_h[h] for h in strata) / z
    se = np.sqrt(1.0 / z)
    ci = (mu_strat - norm.ppf(1 - alpha/2) * se,
          mu_strat + norm.ppf(1 - alpha/2) * se)

    signs = {np.sign(v) for v in tau_h.values() if abs(v) > 1e-12}
    pooled = sum(tau_h[h] * n_h[h] for h in strata) / sum(n_h.values())
    paradox = len(signs) > 1 and np.sign(pooled) not in signs
    return {'tau_h': tau_h, 'mu_strat': mu_strat, 'ci': ci,
            'paradox': paradox, 'n_h': n_h}


class MultiMachineEvalCertificate:
    def __init__(self, assessment, coverage, provenance_root, replay_hash):
        self.a = assessment
        self.coverage = coverage
        self.provenance_root = provenance_root
        self.replay_hash = replay_hash

    def verify(self, K_min=3, n_min=5):
        return (self.coverage >= K_min
                and all(n >= n_min for n in self.a['n_h'].values())
                and self.a['ci'][0] <= self.a['ci'][1]
                and self.provenance_root is not None
                and self.replay_hash is not None)
```

```python
class ReproducibleExecutionBundle:
    def __init__(self, passport, controller_ver, K_safe, seeds, env_spec, ev_exec):
        self.passport, self.controller_ver = passport, controller_ver
        self.K_safe, self.seeds, self.env_spec = K_safe, seeds, env_spec
        self.ev_exec = ev_exec
        self.reb_hash = self._hash()

    def _hash(self):
        blob = json.dumps([self.passport.h_id, self.controller_ver,
                           as_dict(self.K_safe), self.seeds, self.env_spec])
        return sha256(blob.encode()).hexdigest()

    def replay(self, target_passport, runner, eps_replay=0.1):
        if not commensurable(self.ev_exec, self.passport,
                             self.ev_exec, target_passport):
            return None
        ev2 = runner(self.controller_ver, self.K_safe, self.seeds, self.env_spec)
        delta = np.linalg.norm(canonicalize(self.ev_exec, self.passport)
                               - canonicalize(ev2, target_passport))
        return ev2 if delta <= eps_replay else None
```

```python
class HardwareEvalBudget:
    def __init__(self, cal_trials=20, refresh=5, transfer=10,
                 K_machines=5, n_trials=20, power_target=0.8):
        self.B_cal, self.B_refresh, self.B_transfer = cal_trials, refresh, transfer
        self.B_K, self.B_n, self.B_power = K_machines, n_trials, power_target

    def choose_design(self, effect_size, sigma, cost_machine=10.0, cost_trial=1.0):
        n_req = int(np.ceil(
            2 * (norm.ppf(0.975) + norm.ppf(self.B_power)) ** 2 * sigma**2
            / effect_size**2))
        best = None
        for K in range(3, self.B_K + 1):
            for n in range(5, self.B_n + 1):
                if n < n_req:
                    continue
                power = 1 - norm.cdf(norm.ppf(0.975)
                                     - effect_size / (sigma * np.sqrt(2 / n)))
                voi = effect_size / np.sqrt(K * n) \
                    - 0.1 * K * cost_machine - 0.1 * K * n * cost_trial
                if best is None or voi > best['voi']:
                    best = {'K': K, 'n': n, 'power': power, 'voi': voi}
        return best or {'K': self.B_K, 'n': self.B_n, 'power': None, 'voi': None}
```

```python
def federated_multimachine_evolution_loop(fleet, task, eps_H=0.5):
    uploads = []
    for m in fleet:
        ev = m.run(task)
        uploads.append({'y': canonicalize(ev, m.passport),
                        'h_id': m.passport.h_id,
                        'unc': m.passport.unc,
                        'prov': m.passport.prov,
                        'machine': m.id})

    class_of = cluster_by_equivalence_class([m.passport for m in fleet])
    outliers = [u['machine'] for u in uploads
                if u['h_id'] not in class_of[u['machine']]]

    kept = [u for u in uploads if u['machine'] not in outliers]
    assessment = hardware_stratified_assessment(kept, metric=lambda u: u['y'][0])
    cert = MultiMachineEvalCertificate(
        assessment,
        coverage=len(set(u['h_id'] for u in kept)),
        provenance_root=merkle_root([u['prov'] for u in kept]),
        replay_hash=merkle_root([u['y'].tobytes() for u in kept]))

    transferred = {m.id: shrink_prior_to_fleet(m.passport, kept)
                   for m in fleet if m.id not in outliers}
    return cert, outliers, transferred
```
