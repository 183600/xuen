# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「行为树」×「物体泛化」）

> 第 54 轮把技能组合建成动作空间图 `G_S`，并用云边联合证书 `J` 约束组合。但 `G_S` 本质是**直线序列**：它只表达“先 S1 再 S2”，没有表达“若失败则回退/重试/并行仲裁”的任务级控制流；同时所有证书都绑定在**具体物体实例**上，物体一换（新实例/新类别/几何-外观漂移），`α_S` 与 `ρ` 就静默失效。本轮引入**行为树**作为可反应、可验证的控制骨架，**物体泛化**作为对物体分布的量化，把第 54 轮的“动作-鲁棒性双证书”升级为**证书类型化的行为树 CTBT**。核心矛盾：H22：动作层 sound 的组合在任务层缺少守卫与回退，单点失败整链崩溃；H23：证书在 φ-物体类内看似成立，却在 φ 折叠了行为差异时给出“已泛化”的假象。

## 0. 直觉与动机

**灵感 1（行为树 → 从直线路径到反应式控制骨架）**
直觉：第 54 轮的 `G_S` 只能给出 sequence。真实任务需要 Fallback 回退、Retry 重试、Parallel 仲裁、Condition 守卫。行为树（BT）恰好是“带成功/失败/运行三态语义的组合子代数”。把技能叶子挂到 BT 上，组合的 soundness 就从“路径存在”升级为“树在任意执行状态下都能返回 S 或 F，且 F 能被上层 Fallback 接住”。**BT 让鲁棒性从“被证书下界约束”变成“被控制结构主动恢复”**——Fallback 把总失败概率从求和压成乘积。

**灵感 2（物体泛化 → 守卫才是泛化的真正载体）**
直觉：物体泛化不是“把成功率抬高一点”，而是“Condition 节点所检验的谓词在新物体上仍然为真”。BT 的 Condition 正是符号与连续的接缝：`is_graspable(z)`、`is_pushable(z)`、`is_symmetric(z)`。因此泛化分析应落在**守卫在物体特征商空间 Z 上的有效区域**，而不是笼统宣称“技能能泛化”。这给了我们一个可判定的对象 `Gen(B)`：不是“大概能泛化”，而是“在这棵树上、这些守卫下、这个物体集合内可执行”。

**灵感 3（证书类型化 → 把 BT 组合写成效应系统）**
直觉：给每个节点一个效果 `E_n=(ρ_n, A_n, O_n)`：鲁棒性谱、动作占用证书、物体泛化证书。Seq / Fall / Par / Decorator 各自有组合规则，像类型规则一样静态传播。`⊢B:E_root` 能成立才允许部署，运行时监控再核对实际效果。**这把第 54 轮的联合证书 `J` 变成 BT 的“节点类型”，组合从图搜索变为树类型检查**；证书不再是一份日志，而是参与组合的静态约束。

**灵感 4（物体泛化谱 → 泛化半径 + 见证物体，而非单一成功率）**
直觉：一个技能在训练物体上 95% 成功，不代表在“尺寸 ×1.3、对称性破坏、关节松动”的物体上成立。我们要求证书给出**泛化半径 `r_gen`**（在 Z 中可外推多远）和**见证集 W**（边界物体、对抗物体、反例）。用分裂共形预测（split conformal）把 `r_gen` 校准成带覆盖保证的半径，替代拍脑袋阈值；则“泛化”变成一个可被证伪的区间，而不是一句形容词。

**灵感 5（失败归因到节点 → Explain 的树内定位）**
直觉：第 53–54 轮的 `Explain` 给出“哪个动作/哪个维度失败”，但没给出“树的哪个节点失败”。BT 的失败轨迹天然对应一棵**最小失败子树** `B*`。把根因映射到节点，就能只修 `B*`（换守卫、换叶子、加 Retry、收紧超时），而不是整棵树重训。**这使跨物体迁移的修复代价从 O(全树) 降到 O(失败子树)**，也让“泛化失败”有了可操作的局部修复语义。

**灵感 6（金字塔扩展 → 控制层 𝔹 与物体层 𝕆）**
直觉：在 `𝕃`（鲁棒性）、`𝔸`（动作协同）之上叠加 `𝔹`（BT 控制）与 `𝕆`（物体泛化）：`𝔹_0` 三态语义、`𝔹_1` 节点证书、`𝔹_2` 守卫覆盖；`𝕆_0` 物体空间、`𝕆_1` φ-类、`𝕆_2` 泛化半径。跨层证书同带 `(ρ, A_cert, O_cert, blame)`，形成**控制-物体-动作-鲁棒性四证一体**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（物体参数化技能与物体抽象）**
物体空间 `O`，物体抽象 `φ: O → Z`（Z 为几何/材质/可动性等特征商空间）。技能 `S` 在物体 `o` 上诱导动作剖面 `α_S(·; o)` 与鲁棒性谱 `ρ_S(·; o)`，记 `S|_o`。φ-纤维 `[z] = φ^{-1}(z)` 称为物体类。称 `φ` 在物体类上**行为充分**，当且仅当 `∀o,o'∈[z]`：守卫真值相同，`α_S(·;o)=α_S(·;o')`，且 `|ρ_S(d;o)-ρ_S(d;o')| ≤ δ_o`。

**定义 122（物体泛化谱与泛化证书）**
对物体分布 `D_O` 与漂移预算 `ε`，定义 `g_S(z) = inf_{o∈[z]∩supp D_O} min_d ρ_S(d;o)`。泛化半径
```
r_gen(S) = sup{ ε ≥ 0 : ∀z, d_Z(z, z_core) ≤ ε ⟹ g_S(z) ≥ ρ_min }。
```
泛化证书 `O_cert = (z_core, r_gen, δ_o, W)`，`W` 为见证集（边界物体、对抗物体、反例）。`o ⊨ O_cert` 当且仅当 `d_Z(φ(o), z_core) ≤ r_gen` 且 `min_d ρ_S(d;o) ≥ ρ_min - δ_o`。记 `Region(O_cert) = {o : o ⊨ O_cert}`。

**定义 123（证书类型化行为树 CTBT）**
语法：
```
B ::= Action(S) | Cond(ψ) | Seq(B1..Bk) | Fall(B1..Bk)
    | Par(B1..Bk) | Retry_k(B) | Timeout_τ(B)
```
三态 big-step 语义 `⟨B,s⟩ ⇓ (β, s')`，`β ∈ {S,F,R}`。节点效果类型 `E = (ρ, A, O, p_fail)`，其中 `A` 为动作占用证书、`O` 为物体泛化证书、`p_fail` 为该节点失败概率上界；类型判断 `⊢ B : E`。

**定义 124（证书代数）**
- `Seq ⊗`：`ρ = compose_robustness_chain(ρ_i)`，`A = ⋂A_i ⊕ transition`，`O = ⋂O_i`（物体区域取交），`p_fail = 1 - ∏(1 - p_fail,i)`。
- `Fall ⊕`：若守卫族 `Ψ` 在 `Gen(B)` 上互斥且覆盖，则 `p_fail = ∏ p_fail,i`；否则保守取 `p_fail = min(1, Σ p_fail,i)`；`O = ⋃O_i ∪ Cover(Ψ)`。
- `Par ∥`：`ρ = min_i ρ_i`，动作不冲突（`act(A_i)∩act(A_j)=∅` 或存在仲裁器），`O = ⋂O_i`。
- `Retry_k`：`p_fail = (p_fail,child)^k`，`A,O` 不变，`ρ` 记 k 次恢复预算。
- `Timeout_τ`：增加时延上界，`ρ` 的时延维度按 `τ` 截断。

**定义 125（守卫覆盖与泛化区域）**
守卫族 `Ψ = {ψ_1..ψ_m}`，`ψ_i : Z → {0,1}`。`Cover(Ψ,D) = 1` 当且仅当 `∀o∈D, Σ_i ψ_i(φ(o)) ≥ 1`；`Disjoint(Ψ,D) = 1` 当且仅当 `∀o∈D, Σ_i ψ_i(φ(o)) ≤ 1`。定义
```
Gen(B) = ⋂_{leaf∈B} Region(O_cert(leaf))
         ∩ { o : Cover(Ψ,o) ∧ Disjoint(Ψ,o) }。
```
`Gen(B)` 是这棵树**带证书可部署**的物体集合，而不是训练集。

**定义 126（行为树泛化契约与失败归因）**
契约 `C_BT = (B, E_root, Gen(B), W, blame_map)`。失败轨迹 `τ` 的最小失败子树 `B* = blame(τ) ⊆ B`，根因 `root = Explain(τ)` 给出动作 `a_e`、维度 `d` 或物体属性 `z`。修复算子 `repair(B*) ∈ {tighten_guard, replace_leaf, add_retry, retrain}`。部署条件：
```
⊢ B : E_root  ∧  o ∈ Gen(B)  ∧  δ_o ≤ Θ_o。
```

## 2. 关键算法 伪代码

### IP-121 OGS（Object Generalization Spectrum）

```python
def object_generalization(skill, D_O, phi, eps_grid, rho_min, alpha_cp):
    z_core = weighted_centroid([phi(o) for o in D_O])
    W, scores = [], []
    r_gen = 0.0
    for eps in sorted(eps_grid):
        shell = sample_object_shell(z_core, eps, n_strata)
        worst = min(shell, key=lambda o: min_dim(skill.rho(o)))
        scores.append(1.0 if min_dim(skill.rho(worst)) >= rho_min else 0.0)
        if scores[-1] == 0.0:
            W.append(worst)          # 边界反例，进见证集
            break
        r_gen = eps
    delta_o = conformal_radius(scores, alpha_cp)   # 分裂共形校准
    return ObjectCert(z_core, r_gen, delta_o, W)

def guard_cover(guards, D_Z):
    return all(sum(g(z) for g in guards) == 1 for z in D_Z)
```

### IP-122 CBT（Certified Behavior Tree）

```python
def typecheck(B, gamma, K, gen):
    if is_action(B):
        return gamma[B.skill].effect
    if is_cond(B):
        return Effect(rho=ONE, A=ALL, O=region(B.guard), p_fail=0.0)
    if is_seq(B):
        return reduce(seq_effect, [typecheck(c, gamma, K, gen) for c in B.children])
    if is_fall(B):
        effs = [typecheck(c, gamma, K, gen) for c in B.children]
        if not (guard_cover(B.guards, gen) and guard_disjoint(B.guards, gen)):
            raise TypeError("guard_not_partition")   # 假覆盖直接拒绝
        return Effect(rho=min(e.rho for e in effs),
                      A=union_A(effs), O=union_O(effs),
                      p_fail=prod(e.p_fail for e in effs))
    if is_par(B):
        effs = [typecheck(c, gamma, K, gen) for c in B.children]
        assert pairwise_disjoint_actuators(effs)
        return reduce(par_effect, effs)
    if is_retry(B):
        e = typecheck(B.child, gamma, K, gen)
        e.p_fail = e.p_fail ** B.k
        return e
    if is_timeout(B):
        e = typecheck(B.child, gamma, K, gen)
        e.rho['latency'] = min(e.rho['latency'], B.tau)
        return e
```

### IP-123 BTA（BT Attribution）

```python
def blame_failure(B, trace, explain):
    for node in postorder(B):                    # 最深违约节点优先
        if violates(trace, node.effect):
            root = explain.rootcause(trace, node.effect)
            return minimal_subtree(B, node), root
    return B, explain.rootcause(trace, B.effect)
```

### IP-124 OGX（Object-Grounded eXecution）

```python
def run_bt(B, o, world):
    z = phi(o)
    if not in_gen(B, z):
        return ('OOD', z)                        # 泛化区域外：拒执行，不静默兜底
    return eval_node(B, world, z)

def synthesize_guards(O_certs, D_Z):
    order = sort_by_gen_radius(O_certs)
    guards = [indicator_of(oc.region) for oc in order]   # 有序判定表先验互斥
    guards.append(complement_guard(guards))              # 缺省分支 = 拒绝
    return guards
```

### IP-125 BTL（BT Lifting along φ）

```python
def lift_bt(B, phi, O_certs):
    if is_action(B):
        return ActionLeaf(B.skill, O_cert=O_certs[B.skill])
    if is_cond(B):
        return CondLift(B.guard, region=intersect_regions(B.children, O_certs))
    return rebuild(B, [lift_bt(c, phi, O_certs) for c in B.children])
```

### IP-126 CGT（Cross-object Generalization Transfer）

```python
def transfer(B, C_BT, o_new, sim):
    z = phi(o_new)
    if z in C_BT.Gen:
        return ('reuse', C_BT)
    B_star, root = blame_failure(B, sim.probe(B, o_new), Explain)
    if root.kind == 'object_attr' and extendable(C_BT.O_cert, root.z):
        return ('extend', retype(C_BT, root.z))
    return ('repair', repair(B_star, root))      # 只修失败子树
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| OGS | O(|D_O|·|𝔇_ρ| + |eps_grid|·n_strata) | O(|W|) | 壳层采样覆盖、共形校准 |
| CBT | O(|N|·|A| + |N|·|E|) | O(|N|) | 代数 sound、守卫分区 |
| BTA | O(|N| + |τ|) | O(|B*|) | 最深违约节点定位 |
| OGX | O(|D_Z|·|Ψ|) | O(|Ψ|) | 互斥覆盖、缺省拒绝 |
| BTL | O(|N|·|Z|) | O(|N|) | φ 行为充分、区域交保序 |
| CGT | O(|N| + |Z| + |B*|·|A|) | O(|B*|) | blame 局部化、修复闭合 |

**正确性定理（Object-Generalized Certified Behavior Tree Soundness）**
承接第 54 轮 (A22)–(A28)；新增假设：
- **(A29)** `φ` 在 `Gen(B)` 上行为充分（定义 121）；
- **(A30)** 守卫族 `Ψ` 在 `Gen(B)` 上互斥且覆盖（定义 125）；
- **(A31)** 每个叶子效果由第 54 轮联合证书 `J` 保证 sound；
- **(A32)** 运行时监控对动作/物体效果的观测误差 `≤ δ`。

则对 `o ∈ Gen(B)`，`p_fail(root)` 由 Seq/Fall/Par/Retry 递归给出，且
```
P_fail(B,o) ≤ p_fail(root) + P(o ∉ Gen(B)) + β_E + P(δ_o > Θ_o)。
```
关键：**Fallback 把失败从“求和”压成“乘积”，守卫分区保证乘积成立，O_cert 保证物体量化域，blame 保证修复局部化**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| φ 折叠行为不同的物体 | 高 | 反事实物体对检验 + 行为充分性回归测试 |
| 守卫“假覆盖”、缺省分支静默兜底 | 高 | 缺省拒绝 + 覆盖见证 + 运行时断言 |
| 泛化半径分布外外推失效 | 高 | 分裂共形 + 对抗边界采样 + OOD 拒执行 |
| BT 记忆/状态耦合破坏叶子证书 | 中 | 效果系统加 state token + 节点前置条件 |
| 树规模爆炸与重规划延迟 | 中 | 子树缓存 + 节点哈希 + 惰性类型检查 |

## 6. 本轮最大风险

**一句话**：CTBT 的 soundness 三重依赖 **φ 的行为充分性、守卫的分区覆盖、泛化半径的分布外外推**；一旦 φ 把行为不同的物体折叠进同一类、或守卫在边界处只“看似覆盖”而缺省分支静默兜底，整棵树会通过类型检查却在新物体上选错子树或让 Fallback 永远不可达，这种“带证书的泛化假象”比扁平组合的失败更危险，故必须以 **反事实物体对检验 φ + 缺省拒绝而非兜底 + 共形校准的 r_gen + 死锁绊线** 四重护栏。

### IP-121 OGS

```python
def object_generalization(skill, D_O, phi, eps_grid, rho_min, alpha_cp):
    z_core = weighted_centroid([phi(o) for o in D_O])
    W, scores, r_gen = [], [], 0.0
    for eps in sorted(eps_grid):
        shell = sample_object_shell(z_core, eps, n_strata)
        worst = min(shell, key=lambda o: min_dim(skill.rho(o)))
        ok = min_dim(skill.rho(worst)) >= rho_min
        scores.append(1.0 if ok else 0.0)
        if not ok:
            W.append(worst)
            break
        r_gen = eps
    delta_o = conformal_radius(scores, alpha_cp)
    return ObjectCert(z_core, r_gen, delta_o, W)

def guard_disjoint(guards, D_Z):
    return all(sum(g(z) for g in guards) <= 1 for z in D_Z)
```

### IP-122 CTBT

```python
def typecheck(B, gamma, K, gen):
    if is_action(B): return gamma[B.skill].effect
    if is_cond(B):   return Effect(rho=ONE, A=ALL, O=region(B.guard), p_fail=0.0)
    if is_seq(B):
        return reduce(seq_effect, [typecheck(c,gamma,K,gen) for c in B.children])
    if is_fall(B):
        effs = [typecheck(c,gamma,K,gen) for c in B.children]
        if not (guard_cover(B.guards, gen) and guard_disjoint(B.guards, gen)):
            raise TypeError("guard_not_partition")
        return Effect(rho=min(e.rho for e in effs), A=union_A(effs),
                      O=union_O(effs), p_fail=prod(e.p_fail for e in effs))
    if is_par(B):
        effs = [typecheck(c,gamma,K,gen) for c in B.children]
        assert pairwise_disjoint_actuators(effs)
        return reduce(par_effect, effs)
    if is_retry(B):
        e = typecheck(B.child,gamma,K,gen); e.p_fail = e.p_fail ** B.k; return e
    if is_timeout(B):
        e = typecheck(B.child,gamma,K,gen)
        e.rho['latency'] = min(e.rho['latency'], B.tau); return e
```

### IP-123 BTA

```python
def blame_failure(B, trace, explain):
    for node in postorder(B):
        if violates(trace, node.effect):
            root = explain.rootcause(trace, node.effect)
            return minimal_subtree(B, node), root
    return B, explain.rootcause(trace, B.effect)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OGS | O(|D_O|·|𝔇_ρ| + |eps_grid|·n_strata) | O(|W|) | 壳层采样覆盖，共形校准 1-α |
| CTBT | O(|N|·|A| + |N|·|E|) | O(|N|) | 证书代数 sound，守卫分区 |
| BTA | O(|N| + |τ|) | O(|B*|) | 最深违约节点定位 sound |
| OGX | O(|D_Z|·|Ψ|) | O(|Ψ|) | 互斥覆盖，缺省拒绝 |
| BTL | O(|N|·|Z|) | O(|N|) | φ 行为充分，区域交保序 |
| CGT | O(|N| + |Z| + |B*|·|A|) | O(|B*|) | blame 局部化，修复闭合 |

**正确性定理（Object-Generalized Certified Behavior Tree Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `φ` 在 `Gen(B)` 上行为充分（同 φ-类守卫真值相同、`|Δρ|≤δ_o`）；**(A30)** 守卫族 `Ψ` 在 `Gen(B)` 上互斥且覆盖；**(A31)** 叶子效果由第 54 轮 `J` 保证 sound；**(A32)** 运行时观测误差 `≤ δ`。
则对 `o ∈ Gen(B)`：
```
P_fail(B,o) ≤ p_fail(root) + P(o ∉ Gen(B)) + β_E + P(δ_o > Θ_o)
```
其中 `p_fail` 按证书代数递归：`Seq: 1-∏(1-p_i)`，`Fall: ∏p_i`（守卫分区时），`Par: 1-∏(1-p_i)`，`Retry_k: p^k`。
关键：**Fallback 用乘积替代求和**，**守卫分区使乘积成立**，**O_cert 界定物体量化域**，**blame 使修复局部化**。

## 5. 本轮最大风险

**一句话**：CTBT 的 soundness 三重依赖 **φ 的行为充分性、守卫的分区覆盖、泛化半径的分布外外推**；一旦 φ 把行为不同的物体折叠进同一类、或守卫在边界处只“看似覆盖”而缺省分支静默兜底，整棵树会通过类型检查却在新物体上选错子树或让 Fallback 永远不可达，这种“带证书的泛化假象”比扁平组合的失败更危险，故必须以 **反事实物体对检验 φ + 缺省拒绝而非兜底 + 共形校准的 r_gen + 死锁绊线** 四重护栏。
