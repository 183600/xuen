# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「意图理解」×「三维感知」）

> R69 学会了「去问」：把不确定性拆成 aleatoric / epistemic，用流匹配策略给出有形状的动作模态，再用注视、探针、提问去消解可约部分。但它默认了两件从未被检验的事：**问的是「哪个动作」，而不是「谁想要什么」；回答是关于「动作模式」，而不是关于「世界里的哪个东西」。** 真实指令往往是「把那个放到那边」——这里有**两层互相缠绕的歧义**：指称歧义（that / there 到底对应三维场景里的哪个物体、哪个区域）与意图歧义（要我做什么、做到什么程度、这是谁的意图、我该不该照做）。R69 把这两层一起压进了动作模态向量，等于用一个未落地的语义先验替用户做了指称决定。
>
> 本轮两个灵感正好补上这对缺失：
> - **三维感知**提供唯一能把「指称」落到实处的度量语言：物体实例、6D 位姿、占据、可及性、支撑/遮挡关系、接触流形。没有三维几何，「那个」永远只是一个词。
> - **意图理解**提供三维感知所缺的「相关性」：场景里物体无数，但只有与意图相关的少数才有资格成为指称；意图不是分类标签，而是**对可观测未来状态的可证伪假设**。
>
> 核心命题：**意图与场景是相互识别的（mutually identifying）。意图决定「看哪里、把什么当成指称」，三维几何决定「哪个意图在物理上可能、可区分」。** 因此不能先融合再分类，而要联合推断 (意图, 指称)，并用一个**可辨识性判据**回答一个 R69 没问的问题：**这种歧义究竟能被「看」消除、只能被「干预」消除、只能被「问」消除，还是根本不该被消除而应拒绝？** 命名 **GIST-RAS**（Grounded Intent–Scene Triangulation for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**对方到底想要什么、指的是哪一个、我有没有资格替他决定**」——意图不是一句解释，而是一条能被三维几何证伪、也可能被三维几何欺骗的假设。

## 0. 直觉与动机

**灵感 1（意图没有几何是不可证伪的，几何没有意图是不相关的）**
直觉：只说「用户想拿杯子」无法检验；但若把它展开成「目标区域是杯柄右侧 3cm、末端沿 −z 接近、接触面是圆柱侧面、未来 0.8s 内杯子应上移」，它立刻变成一组可测量的三维量。反过来，桌上十个物体都在点云里，哪个重要不由几何决定，而由意图决定。**意图是几何的查询条件，几何是意图的测量仪器。** 这正是「三角测量」：两束射线只有在同一个三维点上相交，指称才成立；若两束射线平行或重合而无法定交，就必须换一个观测动作。

**灵感 2（R69 把「指称」偷偷 argmax 掉了）**
直觉：R69 的 MINT 在动作模态上算 VoI，但「左绕/右绕」对应的其实是「把哪个物体当作目标」。它先验地用语义模型选了一个指称，再在这个指称下讨论动作——这叫**指称坍缩（referential collapse）**。一旦指称选错，后面的交互再精细也只是「精确地回答错误的问题」。三维感知的第一个贡献不是更准的检测，而是**把指称从隐变量提升为与意图平权的显变量**，禁止提前坍缩。

**灵感 3（三维歧义不是噪声，而是不可辨识性）**
直觉：R68/R69 把不确定性主要当方差。但三维场景里最难的一类歧义是**对称性**：两个一模一样的杯子、被遮挡的抽屉内部、透明/镜面物体、重复纹理。它们不是「测得不准」，而是「从任何允许的被动视角看，两个假设产生完全相同的观测」。**被动地看再多眼，信息增益仍为零。** 这正是 R69 用「交互」解决的东西，但 R69 没有区分「看」和「干预」：只有**干预**（移动、触摸、打开、提问）才能打破被动观测无法打破的对称。R70 必须把这一点写成判据，而不是靠调用顺序碰运气。

**灵感 4（可辨识性有「恰到好处的窗口」）**
直觉：两个意图的三维后果几乎相同（δ≪σ）时，看也看不清，应该直接问或保守；三维后果天差地别（δ≫σ）时，一眼就能分，根本不必交互；只有**中等可分**时，主动选视角/选干预才最值钱。这把 R69 的 VoI 从「值不值得问」细化为「**该用哪种信息动作、能不能问得动**」——VoI 是「可被某类动作区分的歧义」的函数，不是「模糊」的函数。

**灵感 5（可证伪性是解药，也是新毒）**
直觉：要求每个被采纳的意图都给出一个可检验的三维预测，能有效阻止「意图投射」（把任何模糊行为解释成自己熟悉的意图）。但危险在于：**预测 G(h) 的模型与解释观测的模型是同一个模型**。若坐标系错了、标定漂了、或场景被摆成对抗几何，一个错误意图可以自洽地「被几何证实」。这就是**几何确认偏误**：R69 的「问错问题」升级为「用测量证明错误答案」。所以必须引入独立的几何通道、坐标系审计与欺骗上界。

**灵感 6（「谁的意图」不能被几何读出）**
直觉：操作者的指令、旁观者的手势、机器人自身的安全意图可能冲突；三维几何只能告诉你「手在往哪指」，不能告诉你「谁有权决定」。意图理解必须同时输出**主体（principal）**与**权限（authority）**，否则系统会高效地服从一个它无权服从的人。这是 R69 完全没有的社会-安全维度，也是本轮必须显式建模的。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GIST-RAS 总览）** GIST-RAS = (IRD, RSG, GCM, ISC, NBA-I, FIG, GSG, RAS-WM†)。五条不变式：
(i) 实时流零学习写操作（继承 R69 定义 293-i）；
(ii) **可证伪性**：任何被提交的意图 h 必须携带几何后果 G(h) 与至少一个已检验（或显式标注「不可检验」）的预测；
(iii) **禁止坍缩**：不得在意图未定时对指称取 argmax，反之亦然；除非该边缘后验已通过校准与可辨识性检查；
(iv) **权限纪律**：主体未解析时按最保守主体处理，几何证据不得覆盖权限判定；
(v) 交互预算与证据纪律继承 R69（定义 293-ii/iii）。

**定义 311（意图假设格）** 意图 i = (i_goal, i_ref, i_manner, i_principal) ∈ ℐ，分别表示目标终态、指称对象/区域、执行方式（轻/重、快/准、是否可中断）、意图主体。ℐ 带**细化偏序** ≼（子目标程序细化父目标），一个意图是带软约束的时序目标程序，而非单个标签。时刻 t 的假设集 ℋ_t ⊆ ℐ × 𝒱(RSG)（意图 × 指称节点分布）。先验 p(i) 由语言、任务、历史与共同基础给出。

**定义 312（指称场景图 RSG）** G_t = (V, E)：节点 v 为物体/部件/区域，携带位姿分布 p(T_v)、占据 O_v、可及性/可供性 A_v 与认知不确定度；边 e 为空间关系（on/in/left-of/near）、支撑、遮挡、相似/重复、可达。指称落点是指称节点上的后验 p(r|o)。必须用三维而非二维，因为深度、遮挡与实例同一性在图像平面上不可恢复。

**定义 313（几何后果图 GCM / 签名）** 后果映射 G: ℐ × G_t → 𝒫(𝒴_geo)，把意图假设送到可观测几何量的分布：
G(h) = (T_h 目标区域, P_h 接近位姿, C_h 接触流形, O_h 期望占据变化, g_h 注视/头向, τ_h 时序）。由场景图 + 正/逆运动学 + 可微渲染/占据预测计算。**G 是让意图可检验的测量模型**；没有 G，意图只是叙事。

**定义 314（联合后验）** p(h | o_{1:t}) ∝ p(o_{1:t} | h) p(h)，其中似然分解为语言/手势项 L_lang、几何一致性项 L_geo(h) = exp(−½ r_geo(h)^⊤ Σ_geo^{-1} r_geo(h))、语用/社会项 L_prag、安全可采纳项（0/1）。**关键：不假设条件独立**，p(o | i,r) ≠ p(o|i)p(o|r)——指称与意图通过场景耦合，这正是联合推断的理由。

**定义 315（可辨识性与歧义图 ISC）** 对任意观测/干预动作 g，定义签名间隔
δ_g(h,h') = ‖μ_{G(h)}(g) − μ_{G(h')}(g)‖_{Σ_g^{-1}}。
令 δ_view = max_{g∈𝒢_view} δ_g，δ_all = max_{g∈𝒢_view∪𝒢_int∪𝒢_ask} δ_g。在假设集上建**歧义图** 𝔊_view：h,h' 连边当且仅当 δ_view < τ。设 κ = min_{δ_view ≥ τ} δ_view/σ。𝔊_view 的连通分量 = **被动不可区分类**；𝔊_all 的分量 = **任何允许动作都不可区分类**。若二假设在 𝔊_view 同分量而在 𝔊_all 不同分量 ⇒ 必须干预；若在 𝔊_all 仍同分量 ⇒ 语义/权限不可由几何解决，只能问或拒绝。另定义共辨识度 C = I(I;R|o)/√(H(I|o)H(R|o))，刻画两层歧义的缠绕程度。

**定义 316（可解性分类）** 给定联合后验与歧义图，每个歧义类被标为：
- **观察可解**：存在被动视角 g 使其分裂 ⇒ NBV-I；
- **干预可解**：仅存在物理干预 g（移动/触摸/打开/推）使其分裂 ⇒ 干预优先；
- **询问可解**：仅存在语言/手势提问能分裂 ⇒ 沿用 R69 MINT 的问句通道；
- **不可解/不安全**：所有允许动作都不能分裂，或某假设的 G(h) 越出安全包络 ⇒ 保守/拒绝。
分类由 𝔊_view、𝔊_all 与安全包络共同决定，是 R70 对 R69「统一 VoI」的结构性细化。

**定义 317（意图驱动最优动作 NBA-I）** 对每类 g，信息增益 IG(g) = H(I,R|o) − E_{y~p(·|do(g),o)}[H(I,R|o,y)]；选择
g* = argmax_g [IG(g) − c(g)]，s.t. risk(g) ≤ ε_int、预算未越、类型与定义 316 一致。
对被动视角用 Fisher/熵近似；对干预用 do-算子下的因果预测 p(y | do(g), h)，因为干预改变的是场景生成机制而非仅仅多一个样本。

**定义 318（指示语落地 Deictic Grounding）** 指点/注视射线在三维中张成锥形分布；与可达性、显著度、共同基础先验及意图先验相乘，得到 RSG 节点上的指称后验。显式处理三类难例：被遮挡的指称（射线穿过前景）、完全相同的重复实例（几何退化）、以及「指向一个尚无物体的位置」（意图先于指称）。

**定义 319（可证伪意图门 FIG）** 执行前要求：(a) 被提交的 h* 至少有一个 G(h*) 预测可在未来 k 步检验；(b) 尚未排除的竞争假设被保留为显式不确定性，而非被 argmax 抹掉；(c) 后验质量集中于单点或显式携带多峰不确定性；(d) 若无可检验预测且无询问预算 ⇒ 拒绝猜测，转询问/保守。

**定义 320（意图安全包络）** 对每个 h，令其一致动作集 𝒜(h) = {a : G(h,a) 在认证安全集内}。若最大后验 h 的 𝒜(h) 为空 ⇒ 不得执行，即使这是「用户明确要求」；若存在安全但低后验的 h′，可在预算内询问以消歧，否则按最安全 h′ 执行并标注。**执行的是安全且被证实的意图，不是被推断出的意图。**

**定义 321（几何欺骗防护 GSG）** 检测使几何证据**非辨识**的条件：透明/镜面/低纹理/重复实例/对称/遮挡/诱饵摆放；估计欺骗位移上界 ε_spoof。若 δ_all ≤ 2ε_spoof，判为「几何不可信」，禁止用几何定案，退回干预/询问/保守。要求多视角或多物理通道的一致性来压低 ε_spoof。

**定义 322（坐标系与规范一致性）** 所有 G(h) 在统一世界系表达；维护标定与位姿图的协方差，检测坐标系漂移/旋转错配。**坐标系不一致时冻结意图提交**——因为一个旋转错的坐标系足以让错误意图自洽。该机制与 R68 的 COF 标定层显式对接。

**定义 323（意图动力学与承诺）** 意图是分段平稳的切换过程；用变点检测与滞回（hysteresis）建模，连续 m 次一致观测后才提交，新证据可撤回；定义「意图半衰期」防止左右横跳。意图是轨迹，不是快照。

**定义 324（意图主体与权限）** P ∈ {operator, bystander, robot-safety, system}；权限先验 A(P|语境)，硬约束来自安全与角色。输出必须是 (h, P) 联合；几何无法辨识 P。冲突时排序 safety ≻ operator ≻ bystander，且优先显式询问；无权限的意图即使几何上可执行也拒绝。

**定义 325（证书 J_GIST）** J_GIST = (J_FLUID, H(I,R) 前/后, κ 或终止证据, r_geo, nbv_gain, spoof_flags, frame_hash, authority_state, gist_ver)。Valid ⇔ Valid(J_FLUID) ∧（可辨识性达标 ∨ 显式携带不确定性）∧ frame 一致 ∧ 权限已解析或按默认 ∧ 至少一个签名预测被检验。

**定义 326（两级严格退化）** 正常 → GIST；若指称唯一且意图为单模态动作但仍有动作歧义 → FLUID（R69）；若不可辨识/被欺骗/权限未决/超预算 → R68 纯保守。λ 在退化链上单调不降，安全侧不做让步。

## 2. 关键算法骨架

# IP-264 IRD：联合意图-指称分解（禁止指称坍缩）
def propose_joint(o, lang, gesture, rsg, last_modes):
    refs  = rsg.referent_posterior(lang, gesture)       # 3D nodes, 不许 argmax
    goals = parse_goal_lattice(lang, last_modes)        # 分层目标程序
    H = [h for i in goals for h in bind(i, refs)]       # 保留耦合
    return prune_by_physics(H, rsg)                     # 只剪物理不可能

# IP-265/266 RSG + GCM：把意图翻译成可测三维后果
def build_signatures(H, rsg):
    return {h: gcm.predict(h, rsg) for h in H}          # T,P,C,O,gaze,timing

# IP-267 ISC：歧义图 + 可解性分类（look / intervene / ask / refuse）
def classify(H, sig, rsg, budget):
    for h1, h2 in pairs(H):
        d_view = max(sep(sig[h1], sig[h2], g) for g in view_candidates(rsg))
        d_all  = max(d_view, max(sep(..., g) for g in intervention_candidates(rsg)))
        add_edge(G_view, h1, h2, d_view < TAU)
        add_edge(G_all,  h1, h2, d_all  < TAU)
    comps = components(G_view)
    return [triage(c, G_view, G_all, budget) for c in comps]

# IP-268 NBA-I：选「看 / 干预 / 问」中期望切分最大且安全的那一个
def choose_action(comps, post, budget):
    best = None
    for g in view_candidates + intervention_candidates + question_candidates:
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        gain = expected_component_split(comps, post, g, do=(g in interventions))
        s = gain - cost(g)
        if best is None or s > best.score: best = (g, s)
    return best if best and best.score > 0 else None

# IP-269/270 FIG + 安全包络：只提交可证伪、可安全实现的意图
def commit(post, sig, rsg, authority):
    h_star = argmax(post)
    if not safe_envelope(sig[h_star], rsg):        return None, "unsafe_intent"
    if authority.unresolved(post):                return None, "ask_authority"
    if not has_checkable_prediction(sig[h_star]): return None, "untestable"
    return h_star, "commit"

# IP-274 主闭环（继承 R69；只在决策层插入意图-场景三角测量）
def GIST_RAS_round(M, o_t, lang, gesture):
    z, o = M.mtm.forward(o_t)                          # R68/R69 同一次前向
    G    = M.rsg.build(o_t, z)                         # 3D 指称场景图（增量）
    H    = M.ird.propose_joint(o, lang, gesture, G, M.aud.last_modes)
    sig  = {h: M.gcm.predict(h, G) for h in H}
    post = M.ird.posterior(H, sig, o_t)
    # 1) 歧义不是标量，是有结构的图；先问「哪类动作能切开它」
    comps = M.isc.classify(H, sig, G, M.budget)
    g = M.nba.choose_action(comps, post, M.budget)
    if g is not None:
        y = M.look(g) if g.kind == 'view' else (
            M.intervene(g) if g.kind == 'intervene' else M.mint.ask(g))
        post = M.ird.update(post, y)
    # 2) 可证伪 + 安全 + 权限三门
    h_star, status = M.fig.commit(post, sig, G, M.irr.authority(post))
    if status != "commit":
        return M.fluid.fallback(post, status)          # R69/R68 保守链
    # 3) 执行：把已落地意图交给 R69 的认证前缀控制
    return M.fluid.execute_grounded(h_star, sig[h_star], post)

## 3. 推导

**引理 19（签名可分性决定意图误差）** 设签名观测 y = μ_h(g) + n，n ∼ 𝒩(0,Σ_g)，两假设等协方差，δ_g = ‖μ_h−μ_h′‖_{Σ_g^{-1}}。则 Bayes 错误率 ≤ exp(−δ_g²/8)。故**意图可辨识度完全由「几何后果在该观测动作下分得多开」决定**。系 1（主动感知的终止条件）：当 min_{h≠h′} δ_g ≥ √(8 ln(1/ε)) 时可停止观察，误差 ≤ ε。系 2（Goldilocks 区间）：δ≫σ 时无需交互；δ≈σ 时选视角最值钱；δ≪σ 时任何被动视角都无效，必须干预/询问。这把 R69 的标量 VoI 变成**有类型的实验设计**。

**引理 20（对称性只能被干预打破）** 若对任意允许的被动视角 g∈𝒢_view 都有 p(y|h,g)=p(y|h′,g)（例如两个几何全同的实例、被外壳遮挡的内部），则对任意被动观测序列，后验比恒等于先验比，被动信息增益恒为 0。若存在干预 g_int 使 p(y|do(g_int),h)≠p(y|do(g_int),h′)，则正信息增益可达。**系：R69「看一眼再说」对对称歧义无效；「看」不能替代「触/移/问」。** 这是本轮把信息动作分型的形式依据。

**引理 21（几何欺骗的可辨识上界）** 若场景/位姿扰动使签名均值位移至多 ε_spoof（在 Σ^{-1/2} 范数下），则有效间隔满足 δ_eff ≥ max(0, δ_all − 2ε_spoof)。当 ε_spoof ≥ δ_all/2 时，错误假设可被排到正确假设之前，即**错误意图可获得最高几何支持**。若 m 个近似独立视角/物理通道的扰动独立，则 ε_spoof 降为 ε_spoof/√m。故 GSG 的职责是估计 ε_spoof 并在 δ_all ≤ 2ε_spoof 时禁用几何定案。

**定理 18（GIST 严格包含 R69 与 R68）** 在 A99–A104（签名 Lipschitz、传感器校准、坐标系一致、安全包络闭合、权限可判定）下，GIST 的期望任务风险 ≤ FLUID（R69）≤ CALM（R68）。当指称唯一且意图为单模态动作时，GIST 逐指令退化为 R69；当不可辨识、被欺骗、权限未决或超预算时，逐指令退化为 R68 保守链。**新层是旧层的严格泛化，安全侧不做任何让步。**

**定理 19（可证伪意图的安全提交）** 在 FIG（定义 319）与意图安全包络（定义 320）下，任何被执行的意图 h* 满足：(i) 至少一个签名预测被检验或显式标注不可检验；(ii) 其一致动作集非空且落在认证安全集内；(iii) 权限已解析或按安全默认处理。因此意图驱动的执行不会越出安全包络；不安全或无权限的指令被拒绝并留下证书。注意：可证伪性是**必要非充分**——它排除「不可检验的独断」，但不能排除「被自洽几何欺骗」，后者由 GSG 与引理 21 处理。

## 6. 本轮最大风险

**一句话**：GIST-RAS 把意图的可信度押在几何后果图 G(h) 的**保真度与坐标系正确性**上——一旦标定/位姿漂移，或场景是透明、对称、被诱饵摆布的对抗几何，系统就会用**错误但自洽**的三维证据把错误意图「证成」，把 R69 的「问错问题」升级为「用测量证明错误答案」，即**几何确认偏误**。

**次级风险与缓解**：
1. **可辨识性判据本身估错**（把不可分的当成可分）→ ISC 保守阈值 + 多视角验证 + E302 校准；
2. **几何欺骗/对抗物体** → GSG 估计 ε_spoof + 多通道独立一致性（引理 21）+ E306；
3. **指称坍缩的隐性回潮**（实现中为省算力又 argmax 指称）→ 定义 310-iii 禁止 + E312 消融监测；
4. **权限误判导致越权服从** → 安全 ≻ 操作者 ≻ 旁观者 的硬序 + 定义 324 + E310；
5. **坐标系/规范错误** → frame 审计冻结提交（定义 322）+ 与 R68 COF 联动 + E308。

# 第 70 轮产物 · 创新点清单 v1：GIST-RAS（Grounded Intent–Scene Triangulation for Risk-Adaptive Safety：意图理解 × 三维感知的联合可辨识消歧闭环；IRD×RSG×GCM×ISC×NBA-I×FIG×GSG×RAS-WM†）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 学会了主动求证，但它默认「问什么」已经明确：它把**指称歧义**（「那个/那里」对应三维场景里的哪个对象/区域）与**意图歧义**（要做什么、做到什么程度、是谁的意图）一起压进了动作模态，提前用语义先验 argmax 了指称。结果是：问得越准，可能只是**精确地回答了错误的问题**。
>
> 本轮用两个灵感重建问题：**三维感知**把「指称」落到可测几何（实例、6D 位姿、占据、可及性、接触流形）；**意图理解**把「相关性」注入几何，且把意图定义为**可被三维后果证伪的假设**（不是标签）。两者不是后期融合，而是**相互识别**：意图决定看哪里/什么算指称，几何决定哪个意图物理可能、可区分。
>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**对方到底想要什么、指的是哪一个、我有没有资格替他决定**」。

> IP 编号：IP-264~IP-275（共 12 个）。理论姿态：GIST 在「指称唯一 + 意图单模态」时逐指令退化为 R69，在「不可辨识/被欺骗/权限未决」时退化为 R68；安全侧不让步。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 零学习写操作；可证伪（每个提交意图带 G(h) 与检验记录）；禁止坍缩（不提前 argmax 意图或指称）；权限纪律（主体未决取最保守）；继承 R69 的预算与证据纪律。

**定义 311–312（意图假设格与 RSG）** `i=(goal,ref,manner,principal)` 带细化偏序，是时序目标程序；`G_t=(V,E)` 为带位姿分布/占据/可供性/遮挡/重复关系的三维指称图。指称必须三维落地，否则深度/遮挡/实例同一性不可恢复。

**定义 313–314（GCM 与联合后验）** `G(h)` 把意图送到可测几何分布；后验 `p(h|o) ∝ L_lang·L_geo·L_prag·1_safe`，且 `p(o|i,r) ≠ p(o|i)p(o|r)`——耦合是联合推断的理由。

**定义 315（ISC 与歧义图）** `δ_g` 为签名间隔；`𝔊_view` 边 = 所有被动视角都分不开；`𝔊_all` 边 = 所有允许动作都分不开。分量即不可区分类；被动分量可被干预切开者 ⇒ 必须干预；`𝔊_all` 分量仍不切者 ⇒ 问或拒绝。

**定义 316（四类可解性）** 观察可解 / 干预可解 / 询问可解 / 不可解或不安全；分类由歧义图与安全包络联合决定。

**定义 317（NBA-I）** `g*=argmax[IG−c]`，约束安全与预算；干预的信息增益用 `p(y|do(g),h)` 计算，因为干预改变生成机制。

**定义 318（指示语落地）** 指点/注视射线张成三维锥分布，乘可达性、显著度、共同基础与意图先验；显式处理遮挡、全同实例、空位置指称。

**定义 319–320（FIG 与安全包络）** 提交需可检验预测 + 显式未排除假设；`𝒜(h)` 非空且落认证安全集才可执行；不安全/无权限意图拒绝而非服从。

**定义 321–322（GSG 与坐标系审计）** 透明/镜面/对称/重复/诱饵 ⇒ 估计 `ε_spoof`，`δ_all ≤ 2ε_spoof` 禁用几何定案；frame 不一致冻结提交，与 R68 COF 联动。

**定义 323–324（意图动力学与权限）** 变点检测 + 滞回 + 意图半衰期，意图是轨迹；输出 `(h,P)` 联合，冲突硬序 safety ≻ operator ≻ bystander，几何不得覆盖权限。

**定义 325–326（证书与严格退化）** `J_GIST` 并入联合熵/κ/签名残差/欺骗与坐标系标志；GIST → FLUID（指称唯一）→ CALM（不可辨识/被欺骗/权限未决）逐指令退化，λ 单调不降。

## 3. 关键算法伪代码

```python
# IP-264 IRD：联合意图-指称假设（保留耦合，禁止指称坍缩）
def propose_joint(o, lang, gesture, rsg, last_modes):
    refs  = rsg.referent_posterior(lang, gesture)        # 3D nodes, no argmax
    goals = parse_goal_lattice(lang, last_modes)         # hierarchical programs
    return prune_by_physics([h for i in goals for h in bind(i, refs)], rsg)

# IP-265/266 GCM：把意图翻译成可测三维签名
def build_signatures(H, rsg):
    return {h: gcm.predict(h, rsg) for h in H}           # T,P,C,O,gaze,timing

# IP-267 ISC：歧义图 → 看 / 干预 / 问 / 拒绝
def classify(H, sig, rsg):
    for h1, h2 in pairs(H):
        d_view = max(sep(sig[h1], sig[h2], g) for g in view_candidates(rsg))
        d_all  = max(d_view, max(sep(sig[h1], sig[h2], g) for g in interventions(rsg)))
        add_edge(G_view, h1, h2, d_view < TAU)
        add_edge(G_all,  h1, h2, d_all  < TAU)
    return [triage(c, G_view, G_all) for c in components(G_view)]

# IP-268 NBA-I：选择期望切分最大且安全的信息动作
def choose_action(comps, post, budget):
    best = None
    for g in view_candidates + intervention_candidates + question_candidates:
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        gain = expected_component_split(comps, post, g, do=(g in interventions))
        if best is None or gain - cost(g) > best.score: best = (g, gain - cost(g))
    return best if best and best.score > 0 else None     # 无利可图 → R69/R68

# IP-269/270 FIG + 安全包络：只提交可证伪且可安全实现的意图
def commit(post, sig, rsg, authority):
    h = argmax(post)
    if not safe_envelope(sig[h], rsg):        return None, "unsafe_intent"
    if authority.unresolved(post):            return None, "ask_authority"
    if not has_checkable_prediction(sig[h]):  return None, "untestable"
    return h, "commit"

# IP-275 主闭环（继承 R69，只在决策层插入三角测量）
def GIST_RAS_round(M, o_t, lang, gesture):
    z, o = M.mtm.forward(o_t); G = M.rsg.build(o_t, z)
    H    = M.ird.propose_joint(o, lang, gesture, G, M.aud.last_modes)
    sig  = build_signatures(H, G); post = M.ird.posterior(H, sig, o_t)
    comps = M.isc.classify(H, sig, G)
    g = M.nba.choose_action(comps, post, M.budget)
    if g is not None:
        y = M.look(g) if g.kind == 'view' else (
            M.intervene(g) if g.kind == 'intervene' else M.mint.ask(g))
        post = M.ird.update(post, y)
    h, status = M.fig.commit(post, sig, G, M.irr.authority(post))
    if status != "commit": return M.fluid.fallback(post, status)   # R69/R68
    return M.fluid.execute_grounded(h, sig[h], post)
```

## 4. 推导

**引理 19（签名可分性 → 意图误差）** `y=μ_h(g)+n, n~N(0,Σ_g)`，等协方差时 `δ_g=‖μ_h−μ_h′‖_{Σ_g^{-1}}`，则 Bayes 错误率 `≤ exp(−δ_g²/8)`。系 1：`min δ_g ≥ √(8 ln(1/ε))` 可停止观察。系 2（Goldilocks）：`δ≫σ` 无需交互；`δ≈σ` 主动选视角最值钱；`δ≪σ` 被动视角无效，必须干预/询问。R69 的标量 VoI 由此变成**有类型的实验设计**。

**引理 20（对称只能被干预打破）** 若对所有允许被动视角 `p(y|h,g)=p(y|h′,g)`（全同实例、封闭外壳），则任意被动观测的后验比恒等于先验比，被动信息增益为 0；存在干预 `g_int` 使 `p(y|do(g_int),h)≠p(y|do(g_int),h′)` 时才有正增益。系：「看」不能替代「触/移/问」——这是信息动作分型的形式依据。

**引理 21（几何欺骗上界）** 扰动使签名均值位移至多 `ε_spoof`，则 `δ_eff ≥ max(0, δ_all−2ε_spoof)`；当 `ε_spoof ≥ δ_all/2` 时错误假设可被排到最前。`m` 个近似独立视角/物理通道把 `ε_spoof` 降为 `ε_spoof/√m`。故 GSG 必须估计 `ε_spoof`，并在 `δ_all ≤ 2ε_spoof` 时禁止几何定案。

**定理 18（GIST 严格包含 R69/R68）** 在 A99–A104 下，期望风险 GIST ≤ FLUID ≤ CALM；指称唯一且意图单模态动作时逐指令退化为 R69；不可辨识/被欺骗/权限未决/超预算时逐指令退化为 R68，且 λ 单调不降。

**定理 19（可证伪意图的安全提交）** FIG + 安全包络 ⇒ 被执行的 h* 至少有一个检验/显式不可检验标注，其 `𝒜(h*)` 非空且落认证安全集，权限已解析或按安全默认；因此不越出安全包络，不安全/无权限指令被拒绝并留证书。注意可证伪性必要非充分：它排除独断，不排除「被自洽几何欺骗」（由 GSG/引理 21 处理）。

## 7. 本轮最大风险

**一句话**：GIST-RAS 把意图的可信度押在几何后果图 `G(h)` 的保真度与坐标系正确性上——**一旦标定/位姿漂移，或场景是透明、对称、被诱饵摆布的对抗几何，系统就会用错误但自洽的三维证据把错误意图「证成」，把 R69 的「问错问题」升级为「用测量证明错误答案」，即几何确认偏误。**

**次级风险与缓解**：可辨识性判据估错（ISC 保守阈值 + 多视角 + E302）；几何欺骗（GSG + 多通道独立一致性 + 引理 21 + E306）；指称坍缩回潮（定义 310-iii + E312）；权限误判（安全 ≻ 操作者 ≻ 旁观者 + E310）；坐标系/规范错误（frame 审计冻结提交 + R68 COF 联动 + E308）。
