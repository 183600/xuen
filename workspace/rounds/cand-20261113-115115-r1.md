# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；新灵感循环第 1 轮；本轮灵感：「机器人操作系统」×「具身智能大模型」）

> 第 66 轮 RAS 把 VISTA 的被动故障闭环升级为「主动意图感知闭环」：用面部表情捕获风险态度，用风险缩放 `λ_risk` 调制控制量。但它仍然默认了一个**并不存在的单机世界**：所有节点同步、所有观测同源、所有证书在一个进程里签发、一个 `λ_risk` 统管全局。
>
> 真实的机器人不是这样的。它是 **ROS 2 图**：几十个节点通过 topic / action / service 相连，各自有不同的 QoS、不同的时钟、不同的生命周期；而最会「思考」的那个节点——具身智能大模型（VLA / MLLM）——恰恰是**最慢、最随机、最容易被幻觉与对抗提示劫持**的那一个。
>
> 前两轮问的是「**哪一层坏了**」（VISTA）与「**谁来控制、控制多少**」（RAS）。本轮问第三个问题：
>
> **「这条指令凭什么能在此时被这个节点执行；如果它错了，图和证书能不能在它碰到执行器之前把它拦下来，并且事后说清是谁的责任？」**
>
> 本轮的核心命题是：**把具身智能大模型从「驾驶者」降级为「不可信的语义规划器」，把 ROS 2 图从「消息管道」升级为「受证内核」——构成 ARGOS（Assured ROS Graph Operating Substrate，受证 ROS 图操作基底）。**
>
> ARGOS 不是替代 VISTA/RAS，而是它们的**运行环境**：VISTA/RAS 变成图上的证书服务，ARGOS 负责调度、隔离、撤销与追责。

## 0. 直觉与动机

**灵感 1（ROS 2 图 → 分布式证书基底，而不是消息总线）**
直觉：ROS 2 的 topic / action / QoS / lifecycle 本质上是一张**可观测的因果图**。延迟、丢包、QoS 违约、生命周期迁移、action cancel——这些不是「运行时噪声」，而是**天然的故障签名**。VISTA 的 `ρ` 是单机残差签名；ROS 图让我们把它扩展成 `ρ_G`：每条边上都有时间戳、每条 QoS 都有契约、每个节点都有生命周期状态。于是「证书」不再只存在于控制器内部，而是可以**沿着图的边运输、在图的状态上生效**。

**灵感 2（具身大模型 → 不可信的「意图编译器」）**
直觉：VLA 把 `(自然语言指令, 视觉观测)` 编译成动作 token。编译器从来不被信任去直接执行生成物：我们先做类型检查、再做沙箱、再做验证。具身大模型也一样。它应该只产出**候选语义动作图（SAG）**——带前置/后置条件、证据跨度、置信度的动作节点——而**没有任何直接写执行器的权限**。所有执行必须经过 ROS 侧的零信任 shim（ZTS）。大模型负责「想做什么」，图与证书负责「现在能不能做、做错了谁负责」。

**灵感 3（动作分块 → 可撤销的执行租约）**
直觉：VISTA/RAS 的认证前缀 `k*` 是**长度**——「沿这条线性计划能安全走几步」。但长度不能表达时间：一个 10 步计划可能 200ms 就过期，也可能 2s 仍然有效。ARGOS 把它换成**带 TTL 的执行租约（lease）**：租约不是「必须执行」的义务，而是「在 TTL 内允许 dispatch」的**可撤销能力（capability）**。语义面每次重规划签发新租约，图级故障归因可以随时撤销它。一句话：**证书是没有时间维度的断言，租约是把断言变成可安全撤销的权限。**

**灵感 4（语义 QoS → 让「语义失效」成为可调度事件）**
直觉：ROS 2 的 DDS QoS 已经有 reliability / durability / deadline / liveliness，但它们只管「消息到没到」，不管「消息还值不值得信」。ARGOS 增加 **Semantic QoS（S-QoS）** 四个维度：
- `D_sem` 语义截止期：证据的最大允许年龄；
- `c_min` 置信下限：低于它就必须降级；
- `π_req` 溯源要求：这条消息必须能追到哪一帧、哪一段 token；
- `deg` 违约策略：违约时执行哪种 lifecycle 迁移。
这样，「语义过期」就和「deadline miss」一样，成为一个**可被实时调度理论分析的一等事件**。

**灵感 5（生命周期 → 安全偏序，恢复必须逐级解锁）**
直觉：ROS 2 lifecycle 的 configure / activate / deactivate / cleanup 本是一个状态机。ARGOS 把它加强为一个**安全格**：`SafeStop ≺ Inactive ≺ Configured ≺ Degraded ≺ Active`。降级可以自由往下跳，**升级必须携带新证书**。这借的是电网「五防闭锁」与核电站「安全壳」的思想：故障后的恢复不是「把开关打回去」，而是**逐级重新验证、逐级解锁**。由此得到 ARGOS 的核心不变式：**No Silent Promotion（无证书不得提升信任）**。

**灵感 6（图级故障归因 → 从「哪一层」到「哪条边、哪次迁移」）**
直觉：VISTA 归因「几何 / 传感器 / 模型」，RAS 再加「情绪 / 意图」。但这些假设在分布式系统里不够用：真正的故障常常是「感知节点没崩，只是它的 topic 延迟了 300ms」「VLA 没坏，只是它的输出分布漂移了」「执行器没坏，只是 action goal 的租约过期了」。ARGOS 把故障假设集扩到图级：`H_node_late`、`H_topic_drop`、`H_qos_mismatch`、`H_semantic_drift`、`H_lease_expiry`，并用 ROS 图的因果结构做置信传播，而不是把节点当成独立同分布的证据源。

**灵感 7（双平面 → 让大模型「慢得安全」）**
直觉：把 VLA 塞进 2ms 实时环是工程上的自欺。正确的做法是**双平面**：
- 语义面（2–5Hz）：VLA 规划、SAG 编译、图级归因、漂移检测；
- 实时面（≥500Hz）：ZTS 准入、租约校验、dispatch / cancel、lifecycle 迁移。
两个平面只通过**租约**交换权限，不共享可变状态。语义面宕机、超时、被劫持，实时面都能在租约到期后自动回落到 VISTA/RAS 的受证动作。这就是「让大模型进入安全关键环路」的前提：**它的失败必须是可隔离、可过期、可撤销的。**

**灵感 8（本轮与前三轮的关系）**
- VISTA 提供 `ρ`、`k*`、故障归因 → ARGOS 把它们**分布式化**为 `ρ_G`、租约、图级归因；
- RAS 提供 `λ_risk`、情绪/意图 → ARGOS 把它们变成 S-QoS 的**人的维度**（人类状态是前置条件的一部分）；
- ARGOS 新增的是**操作系统层**：零信任、租约、生命周期、溯源。它不替代前两轮，而是回答「这些证书在真实的分布式机器人上靠什么被执行」。

## 1. 形式化定义（增量：定义 251–268）

- **定义 251（ARGOS 总览）**：`ARGOS = (SAG, SQ, ZTS, CXL, LSM, GFA, SDS, DPE, J_ARGOS)`。定位：VISTA/RAS 的「单机证书」升级为「ROS 2 图上的分布式受证执行」。不变式：(i) 语义面只写候选动作图、租约申请、证据，不直接写执行器；(ii) 实时面只做准入、派发、撤销、生命周期迁移，零学习写操作；(iii) 任何信任提升必须携带新证书。
- **定义 252（ROS 2 图）**：`G_t = (N_t, E_t, Q_t, Λ_t, C_t)`。`N_t` 节点（含角色与执行器），`E_t` 边（topic / action / service），`Q_t` QoS 剖面，`Λ_t` 生命周期状态，`C_t` 时钟与 executor 配置。每条边 `e` 有轨迹 `T_e(t) = {(t_i, size_i, latency_i, drop_i, qos_ok_i)}`。
- **定义 253（语义动作图 SAG）**：`A_t = (V_a, E_a, pre, post, ev, conf)`。动作节点类型 `{navigate, grasp, place, handover, ask, stop}`；`pre/post` 是定义在世界证书 `W_t` 上的谓词；`ev` 是证据跨度（图像 bbox / 时间区间 / VLA token 区间）；`conf` 是校准置信度。VLA 输出候选 SAG 的分布 `P(A_t | instruction, o_t)`。
- **定义 254（世界证书与前置条件预言机）**：`W_t = (J_vista, J_ras, geometry, force_limits, human_state)`。谓词求值器 `pre(a)(W_t)` 返回 `{true, false, unknown}`；`unknown` 一律 fail-closed。证书本身带 `soundness` 位，只有 sound 的证书可参与准入。
- **定义 255（语义 QoS 契约 S-QoS）**：`q_e = (D_sem, ρ_min, c_min, π_req, deg)`。`D_sem` 证据最大年龄，`ρ_min` 可靠性下限，`c_min` 置信下限，`π_req` 溯源要求，`deg` 违约时的 lifecycle 迁移。S-QoS 是 DDS QoS 的语义扩展，违约触发迁移而不是仅丢包。
- **定义 256（零信任执行 shim ZTS）**：对动作 `a` 在时刻 `t` 的准入谓词
  `Admit(a,t) = pre(a)(W_t) ∧ CertValid(a) ∧ LeaseValid(L_a,t) ∧ SQoS_ok(a,t) ∧ ProofVerifiable(a)`。
  不变式：`¬Admit(a,t) ⇒ 执行器不可写`。ZTS 是唯一执行路径（由 DDS Security + 单一 actuation endpoint 强制）。
- **定义 257（执行租约 CXL）**：`L = (id, goal, t_issue, TTL, deps, cert_hash, revoke_set, epoch)`。
  `Valid(L,t) = (t ≤ t_issue + TTL) ∧ (epoch = current) ∧ (deps 全部 Valid) ∧ (id ∉ revoke_set) ∧ (cert_hash 匹配)`。
  语义：租约授予「在 TTL 内 dispatch 该 goal 链」的**权利**，不构成执行义务；可被 GFA 在任意调度点撤销。
- **定义 258（租约链与语义时效）**：链 `L_1 → … → L_n` 有效当且仅当每个 `L_i` 有效且 `TTL_i` 沿依赖单调不增。若证据年龄为 `age`，要求 `TTL_i ≤ D_sem − age`。由此保证：任何被 dispatch 的动作，其依据的证据年龄不超过 `D_sem`。
- **定义 259（生命周期安全格）**：状态集 `L = {Init, Inactive, Configured, Degraded, Active, SafeStop, Recovering}`，信任秩 `rank(SafeStop)=0 < rank(Inactive)=1 < rank(Configured)=2 < rank(Degraded)=3 < rank(Active)=4`。迁移函数 `δ: L × Event → L`，允许自由降秩，提升秩需要证书。
- **定义 260（No-Silent-Promotion 不变式）**：任何 `s → s'` 且 `rank(s') > rank(s)` 的迁移，必须携带新证书 `J`，满足 `Valid(J) ∧ P(H_bad | J) ≤ τ_promo ∧ graph_quarantine_clear = true`；否则迁移被拒绝。恢复路径必须重新执行 VISTA/RAS 证书与图隔离检查。
- **定义 261（图级故障签名）**：`ρ_G(t) = (ρ_V, ρ_R, Δ_lat, drop, qos_viol, life_seq, lease_exp, drift)`，分别投影到节点与边上。`ρ_V`、`ρ_R` 继承 VISTA/RAS；其余为图新增观测量。
- **定义 262（图级故障假设与置信传播）**：`ℋ_G = ℋ_VISTA ∪ ℋ_RAS ∪ {H_node_late, H_topic_drop, H_qos_mismatch, H_semantic_drift, H_lease_expiry}`。后验按 ROS 图的因果 DAG 因子分解：
  `P(H_G | ρ_G) ∝ ∏_n ψ_n(H_n, ρ_n) ∏_{(n,m)∈E} ψ_{nm}(H_n, H_m)`，用置信传播/变分消息传递近似。
- **定义 263（语义漂移哨兵 SDS）**：对 VLA 动作分布定义漂移
  `D_sem(t) = sup_a KL(P_t(a | s) || P_ref(a | s))`，
  用 logits 上的 CUSUM 在线估计。`D_sem > τ_drift` 时置 `H_semantic_drift`，撤销该 VLA 的语义租约，但**不直接触发 SafeStop**（它属于慢平面）。
- **定义 264（双平面调度 DPE）**：语义面周期 `T_s ∈ [200, 500]ms`，实时面周期 `T_r ≤ 2ms`。语义工作跑低优先级 executor，实时准入是 O(1) 查表。ZTS 的 WCET 记作 `C_zts`，由固定优先级响应时间分析给出上界。
- **定义 265（降级策略）**：`deg: Violation → {Tighten, Degrade, SafeStop}`。例：租约过期 → `Degrade` 并切到 VISTA/RAS 回退；QoS 违约 → 隔离该边并重路由；语义漂移 → 降级该 VLA 节点；前置条件 unknown → `SafeStop`。
- **定义 266（ARGOS 证书）**：`J_ARGOS = (J_vista, J_ras, SAG_hash, lease_ids, qos_snapshot, prov_chain, graph_cert, aic_argos_ver)`。`Valid ⇔` 各分量有效 ∧ 无过期租约 ∧ 图隔离已清除。
- **定义 267（可追责证据链）**：`Prov(a) = (action_id → SAG node id → VLA token span → sensor frame ids → cert chain → lease chain → outcome)`，哈希链式、只追加。用于事后审计与责任划分（规划器 / 证书器 / 传感器 / 执行器）。
- **定义 268（联邦组合）**：多个 VLA 节点 `N_sem = {v_1,…,v_k}` 通过 SAG 边组合。联邦安全当且仅当：租约依赖图无环、跨节点边满足 S-QoS、冲突由「优先级 + 受证回退」解决。组合证书 `J_fed` 是各节点证书的合取加上跨边契约。

## 2. 关键算法骨架

```python
# SAG：VLA 输出 → 候选语义动作图（慢平面，非实时）
class SemanticActionCompiler:
    def compile(self, instruction, obs, world_cert):
        tokens = self.vla.encode(instruction, obs)          # token span
        raw = self.vla.decode_actions(tokens)               # 候选动作序列
        V, E = self._type_check(raw)                        # 类型/参数校验
        for a in V:
            a.ev = tokens[a.token_span]                     # 证据跨度
            a.conf = self.calibrator.calibrate(a)           # 校准置信度
            a.pre = lambda W, a=a: self._eval_pre(a, W)     # 世界证书谓词
        return SemanticActionGraph(V, E,
                                   conf=self._graph_confidence(V, E))


# ZTS：实时面零信任准入（每次 dispatch 调用，O(1)）
class ZeroTrustShim:
    def admit(self, a, t, world_cert, lease_mgr):
        if not world_cert.sound:                 return False, "cert_unsound"
        if self._eval_pre(a.pre, world_cert) != True:
            return False, "pre_unknown_or_false"
        if not self._cert_valid(a):              return False, "cert_invalid"
        L = lease_mgr.lease_of(a)
        if not lease_mgr.valid(L, t):            return False, "lease_invalid"
        if not self._sqos_ok(a, t):              return False, "sqos"
        if not self._proof_ok(a):                return False, "proof"
        return True, "admit"


# CXL：租约签发 / 续约 / 撤销
class LeaseManager:
    def issue(self, goal, ttl, deps, cert_hash):
        assert all(self.valid(d, now()) for d in deps)
        ttl = min(ttl, min((d.expires - now()) for d in deps))
        return Lease(new_id(), goal, now(), ttl, deps, cert_hash, epoch=self.epoch)

    def revoke(self, lease_id, reason):
        self.revoked.add(lease_id)
        self.bump_epoch()                        # 原子 epoch，防止旧租约复用

    def valid(self, L, t):
        return (L.id not in self.revoked
                and L.epoch == self.epoch
                and t <= L.t_issue + L.TTL
                and all(self.valid(d, t) for d in L.deps))


# LSM：生命周期安全格 + No-Silent-Promotion
class LifecycleSafetyManager:
    def request(self, node, target, cert=None):
        cur = node.state
        if RANK[target] <= RANK[cur]:            # 降级/同级：允许
            return self._apply(node, target)
        if cert is None or not cert.valid:
            return False, "promotion_without_cert"
        if cert.p_bad > self.tau_promo:
            return False, "posterior_too_high"
        if not self.graph.quarantine_clear(node):
            return False, "quarantined"
        return self._apply(node, target)


# GFA：图级故障归因（置信传播，慢平面）
class GraphFaultAttributor:
    def attribute(self, rho_G, G):
        factors = self._node_factors(rho_G, G)   # ψ_n
        edges   = self._edge_factors(rho_G, G)   # ψ_nm
        return self._belief_propagation(factors, edges, self.H_G, iters=5)


# 主循环：双平面
def ARGOS_round(M, obs, instruction):
    # ---- 语义面（2-5Hz，可超时/可被劫持）----
    W = M.world_cert.build(obs)
    A = M.sag.compile(instruction, obs, W)                  # 候选 SAG
    joint = M.gfa.attribute(M.gfa.signature(M.graph.trace()), M.graph)
    drift = M.sds.update(M.vla.action_logits)
    if drift > M.tau_drift:
        M.leases.revoke_all(vla=M.vla.id, reason="semantic_drift")

    # ---- 证书 + 租约签发 ----
    J = M.cert.build(J_vista=W.jv, J_ras=W.jr, A=A,
                     graph_cert=M.gfa.cert(joint), prov=A.prov())
    if not J.valid or joint.p_bad > M.tau_promo:
        M.lsm.request(M.vla.node, "Degraded", cert=None)
        return M.fallback_vista_ras(obs)                    # 受证回退
    leases = [M.leases.issue(a.goal, ttl=min(M.TTL_max, a.deadline),
                             deps=M._deps(a), cert_hash=J.hash)
              for a in A.topological_order()]

    # ---- 实时面（>=500Hz）----
    executed = []
    for a in A.topological_order():
        ok, why = M.zts.admit(a, now(), W, M.leases)
        if ok:
            executed.append(M.executor.dispatch(a))
        elif why == "lease_invalid":
            M.leases.revoke_all(reason=why)
            M.lsm.request(M.vla.node, "Degraded", cert=None)
            return M.fallback_vista_ras(obs)
        else:
            return M.fallback_vista_ras(obs)
    return executed, J, joint, drift
```

## 3. 推导

**引理 11（租约撤销的暴露上界）** 设故障在 `t_f` 发生，GFA 的检测 + 撤销延迟为 `T_revoke`，实时面 dispatch 周期为 `Δ`。若故障后不再续签租约，则故障后被执行的动数量满足
```
N_exec(t_f) ≤ floor((TTL + T_revoke) / Δ) + 1.
```
特别地，`TTL` 给出与检测尾部无关的硬上界：即使 GFA 的检测延迟是重尾分布，暴露也只在租约剩余寿命内。**证明**：最后一次合法租约的到期时间不晚于 `t_f + TTL`（故障后不续签），撤销生效时间不晚于 `t_f + T_revoke`；两次 dispatch 的最小间隔为 `Δ`，故区间 `[t_f, t_f + min(TTL, T_revoke)]` 内最多 `floor(·/Δ)+1` 次派发。

**引理 12（S-QoS 违约的并集界）** 设边 `e` 的单次语义违约概率为 `p_e`，一条动作链经过 `n` 条边。若违约事件在给定图状态下条件独立，则整链违约概率 `P_chain ≤ 1 − ∏_{e}(1 − p_e) ≤ Σ_e p_e`。因此 S-QoS 的可靠性预算可按边分配；对关键边要求 `p_e ≤ ε/n` 即可保证 `P_chain ≤ ε`。这为「语义 deadline 分配」提供了与实时系统利用率分析同构的工具。

**定理 11（零信任执行的端到端安全性）** 假设：(i) 所有执行器写操作都经过 ZTS（无旁路）；(ii) `pre` 是安全集的可靠过近似；(iii) 证书不可伪造且 soundness 以概率 `≥ 1 − δ_cert` 成立；(iv) 租约由 DDS Security 保护、不可伪造。则对任意 VLA 行为（包括幻觉与对抗提示），
```
P(unsafe actuation) ≤ δ_cert + δ_lease + α_chunk + δ_graph,
```
其中 `α_chunk` 沿用 VISTA 的认证前缀失败率，`δ_graph` 为图级归因/撤销失败率。**证明**：一次不安全的写入必然属于以下互斥情形之一——`pre` 不 sound、证书失效、租约伪造/过期、图级撤销失效；对四者取并集界。关键点是：**大模型的输出分布完全不出现在这个界里**，因为大模型只能改变「候选 SAG 的分布」，不能改变准入谓词的真值。

**定理 12（单调降级与无静默提升）** 在定义 259 的安全格与定义 260 的守卫下，任意有限迁移序列的信任秩只能在携带有效证书且后验达标的步骤上升；任一使证书失效的故障，必在 `T_revoke` 内使秩下降。故「不安全的 Active 时间」满足
```
E[unsafe_active_time] ≤ T_revoke · P(fault),
```
且不存在从 `Degraded` 到 `Active` 的无证书路径。**证明**：对迁移序列按秩归纳；提升步由守卫保证，降级步总是被允许；故障检测由 GFA 的 liveness/租约过期保证，故秩下降的延迟不超过 `T_revoke`。

**定理 13（租约链的语义时效）** 若租约链满足定义 258 的单调 TTL 与 `TTL_i ≤ D_sem − age_i`，则任一被 dispatch 的动作所依据的证据年龄 `≤ D_sem`；且端到端语义延迟的期望不超过 `T_s + max_i TTL_i`。**证明**：对依赖链归纳：叶租约的证据年龄由 `D_sem − TTL` 约束，每向上组合一次 TTL 不增，故最坏年龄不超过 `D_sem`；调度延迟由语义面周期与租约剩余寿命相加得到。

**定理 14（图级归因的信息增益）** 记节点局部观测为 `ρ_local`，图级观测为 `ρ_G`，则 `σ(ρ_local) ⊆ σ(ρ_G)`，由数据处理不等式
```
I(H_G; ρ_G) ≥ I(H_G; ρ_local).
```
在 ROS 图的因果马尔可夫性、且时序/QoS 观测量对 `H_node_late`、`H_topic_drop`、`H_qos_mismatch` 忠实（faithful）时，不等号严格成立。**证明**：局部签名是图签名的坐标投影，构成马尔可夫链 `H_G → ρ_G → ρ_local`；忠实性排除「时序信息被局部签名完全遮蔽」的退化情形。这解释了为什么把 QoS/延迟/lifecycle 纳入签名，能显著提升 `node_late` 与 `topic_drop` 的可辨识度。

## 6. 本轮最大风险

**一句话**：ARGOS 的全部安全性建立在两个工程假设上——「ZTS 是唯一执行路径」与「`pre` 谓词是安全集的可靠过近似」；在真实 ROS 图中，只要有一条绕过 ZTS 的 actuator 话题、一个语义正确但形式上可证的错误计划，或者一个漏检的 QoS 违约，零信任就会退化为「局部受证、整体幻觉」——**证书证明了每一步都合法，却没有证明整条计划是用户想要的**。

**次级风险与缓解**：
1. **ZTS 旁路**：厂商驱动直接写硬件、共享内存、独立安全链 → 用 DDS Security 域隔离 + 硬件互锁 + 启动时枚举所有 publisher 做审计；
2. **谓词不可靠**：`pre` 只是过近似，可能漏掉物理耦合 → 运行时监视器 + 保守下置信界 + 把未知一律 fail-closed；
3. **租约粒度两难**：TTL 太大暴露大，太小频繁停走 → 按风险自适应 TTL，并让 `TTL ≤ D_sem` 与证据年龄联动；
4. **生命周期竞态**：多节点同时请求迁移 → 每个节点单一 lifecycle 权威 + epoch 逻辑时钟 + 迁移幂等；
5. **时钟偏斜**：用单调时钟 + 逻辑 epoch，禁止用墙钟比较 TTL；
6. **漂移检测太慢**：SDS 只作慢平面降级，不承担安全触发 → 安全仍由租约到期与 VISTA/RAS 回退兜底；
7. **恢复抖动**：恢复即重新认证，可能反复升降 → 滞回 + 隔离窗口 + 恢复速率上限；
8. **可追责≠可解释**：证据链能定位责任，但不能证明计划符合用户意图 → 关键任务保留人类确认或形式化意图规约。

## 7. 一句话结论

ARGOS 把「具身大模型 + ROS」从「把最聪明的模型接到最底层的消息总线上」改写为「**让最聪明的模型只拥有可撤销的语义权限，让操作系统在它碰到执行器之前完成验证、限时与追责**」；本轮最需要证明的不是模型多强，而是**当模型错得离谱时，图能否在毫秒级把它变成一个安全的『不执行』**。

## 3. 关键算法伪代码

```python
# IP-234 SAG：VLA 输出 → 候选语义动作图（慢平面）
class SemanticActionCompiler:
    def compile(self, instruction, obs, world_cert):
        tokens = self.vla.encode(instruction, obs)      # token span
        raw = self.vla.decode_actions(tokens)           # 候选动作
        V, E = self._type_check(raw)                    # 类型/参数
        for a in V:
            a.ev = tokens[a.token_span]                 # 证据跨度
            a.conf = self.calibrator.calibrate(a)       # 校准置信度
            a.pre = self._make_pre(a, world_cert)       # 世界证书谓词
        return SemanticActionGraph(V, E, conf=self._graph_conf(V, E))

# IP-236 ZTS：实时面零信任准入（<50us）
class ZeroTrustShim:
    def admit(self, a, t, world_cert, lease_mgr):
        if not world_cert.sound:                 return False, "cert_unsound"
        if self._eval_pre(a.pre, world_cert) is not True:
            return False, "pre_unknown_or_false"
        if not self._cert_valid(a):              return False, "cert_invalid"
        if not lease_mgr.valid(lease_mgr.lease_of(a), t):
            return False, "lease_invalid"
        if not self._sqos_ok(a, t):              return False, "sqos"
        if not self._proof_ok(a):                return False, "proof"
        return True, "admit"

# IP-237 CXL：租约签发 / 续约 / 撤销
class LeaseManager:
    def issue(self, goal, ttl, deps, cert_hash):
        assert all(self.valid(d, now()) for d in deps)
        ttl = min(ttl, min((d.expires - now()) for d in deps))
        return Lease(new_id(), goal, now(), ttl, deps, cert_hash, epoch=self.epoch)

    def revoke(self, lease_id, reason):
        self.revoked.add(lease_id)
        self.bump_epoch()                # 原子 epoch，防旧租约复用

    def valid(self, L, t):
        return (L.id not in self.revoked
                and L.epoch == self.epoch
                and t <= L.t_issue + L.TTL
                and all(self.valid(d, t) for d in L.deps))

# IP-238 LSM：安全格 + No-Silent-Promotion
class LifecycleSafetyManager:
    def request(self, node, target, cert=None):
        if RANK[target] <= RANK[node.state]:     # 降级/同级：允许
            return self._apply(node, target)
        if cert is None or not cert.valid:
            return False, "promotion_without_cert"
        if cert.p_bad > self.tau_promo:
            return False, "posterior_too_high"
        if not self.graph.quarantine_clear(node):
            return False, "quarantined"
        return self._apply(node, target)

# IP-239 GFA：图级故障归因（慢平面）
class GraphFaultAttributor:
    def attribute(self, rho_G, G):
        factors = self._node_factors(rho_G, G)    # psi_n
        edges   = self._edge_factors(rho_G, G)    # psi_nm
        return self._belief_propagation(factors, edges, self.H_G, iters=5)

# IP-243 PROV：证据链
def provenance(a, token_span, frame_ids, cert_chain, lease_chain, outcome):
    return hash_chain([a.id, a.sag_node, token_span, frame_ids,
                       cert_chain, lease_chain, outcome])

# IP-241 主循环：双平面
def ARGOS_round(M, obs, instruction):
    # ---- 语义面（2-5Hz，可超时/可被劫持）----
    W = M.world_cert.build(obs)
    A = M.sag.compile(instruction, obs, W)
    joint = M.gfa.attribute(M.gfa.signature(M.graph.trace()), M.graph)
    drift = M.sds.update(M.vla.action_logits)
    if drift > M.tau_drift:
        M.leases.revoke_all(vla=M.vla.id, reason="semantic_drift")

    J = M.cert.build(J_vista=W.jv, J_ras=W.jr, A=A,
                     graph_cert=M.gfa.cert(joint), prov=A.prov())
    if not J.valid or joint.p_bad > M.tau_promo:
        M.lsm.request(M.vla.node, "Degraded", cert=None)
        return M.fallback_vista_ras(obs)

    # ---- 证书 + 租约签发 ----
    leases = [M.leases.issue(a.goal, ttl=min(M.TTL_max, a.deadline),
                             deps=M._deps(a), cert_hash=J.hash)
              for a in A.topological_order()]

    # ---- 实时面（>=500Hz）----
    executed = []
    for a in A.topological_order():
        ok, why = M.zts.admit(a, now(), W, M.leases)
        if ok:
            executed.append(M.executor.dispatch(a))
        elif why == "lease_invalid":
            M.leases.revoke_all(reason=why)
            M.lsm.request(M.vla.node, "Degraded", cert=None)
            return M.fallback_vista_ras(obs)
        else:
            return M.fallback_vista_ras(obs)
    return executed, J, joint, drift
```

## 4. 推导

**引理 11（租约撤销的暴露上界）** 设故障在 `t_f` 发生，GFA 检测 + 撤销延迟为 `T_revoke`，实时面 dispatch 周期为 `Δ`。若故障后不再续签租约，则
```
N_exec(t_f) ≤ floor((TTL + T_revoke) / Δ) + 1.
```
与检测尾部无关；`TTL` 是硬上界。**证明**：故障后最后合法租约到期不晚于 `t_f + TTL`，撤销生效不晚于 `t_f + T_revoke`；最小派发间隔为 `Δ`。

**引理 12（S-QoS 违约的并集界）** 动作链经过 `n` 条边、单边语义违约概率 `p_e`，在给定图状态下条件独立时
```
P_chain ≤ 1 − ∏_e (1 − p_e) ≤ Σ_e p_e.
```
因此可靠性预算可按边分配：关键边取 `p_e ≤ ε/n` 即保证 `P_chain ≤ ε`。

**定理 11（零信任执行的端到端安全性）** 在「ZTS 无旁路、`pre` 可靠过近似、证书不可伪造、租约受 DDS Security 保护」下，对任意 VLA 行为（含幻觉/对抗提示），
```
P(unsafe actuation) ≤ δ_cert + δ_lease + α_chunk + δ_graph.
```
**证明**：不安全写入必属于「`pre` 不 sound / 证书失效 / 租约伪造或过期 / 图级撤销失效」之一，取并集界。**大模型的输出分布不出现在界中**：它只能改变候选 SAG 的分布，不能改变准入谓词的真值。

**定理 12（单调降级与无静默提升）** 在安全格与守卫下，信任秩只能在携带有效证书且后验达标的步骤上升；任一使证书失效的故障，必在 `T_revoke` 内使秩下降。故
```
E[unsafe_active_time] ≤ T_revoke · P(fault),
```
且不存在从 `Degraded` 到 `Active` 的无证书路径。**证明**：对迁移序列按秩归纳；提升步由守卫保证，降级步总被允许；秩下降延迟由 liveness/租约过期界定。

**定理 13（租约链的语义时效）** 若租约链满足 `TTL` 单调不增且 `TTL_i ≤ D_sem − age_i`，则任一被 dispatch 的动作证据年龄 `≤ D_sem`，端到端语义延迟期望不超过 `T_s + max_i TTL_i`。**证明**：对依赖链归纳；每向上组合一次 `TTL` 不增。

**定理 14（图级归因的信息增益）** 记节点局部观测 `ρ_local`，图级观测 `ρ_G`，则 `σ(ρ_local) ⊆ σ(ρ_G)`，由数据处理不等式
```
I(H_G; ρ_G) ≥ I(H_G; ρ_local).
```
在 ROS 图因果马尔可夫性且时序/QoS 观测对 `H_node_late/H_topic_drop/H_qos_mismatch` 忠实时，不等号严格成立。**证明**：`H_G → ρ_G → ρ_local` 构成马尔可夫链；忠实性排除退化遮蔽。

## 6. 机制检查（合成数据，非 benchmark）

> 代码：`workspace/exp/argos_sim.py`；结果：`workspace/exp/argos_results.json`；种子 `20261113`。
> 这些数字只用于隔离机制、发现设计漏洞，**不是真实机器人或公开数据集上的证据**。

### A. ZTS 零信任准入（40,000 个候选动作，15% 有害/幻觉）

| 策略 | 准入率 | 不安全执行率 | 有害动作准入率 | 无害误拒率 |
|---|---|---|---|---|
| 直接执行（naive） | 1.000 | 0.1366 | 1.000 | 0.000 |
| 仅阈值 `m̂ ≥ 0` | 0.855 | 0.0166 | 0.175 | 0.025 |
| ZTS + conformal 95% | 0.672 | **0.0007** | 0.0198 | 0.213 |
| ZTS + conformal 90% | 0.728 | 0.0018 | 0.0342 | 0.150 |

**解读**：零信任把不安全执行率从 13.7% 压到 0.07%，代价是约 21% 的无害动作被保守拒绝。这个代价可以接受——**在安全关键环里，误拒是性能问题，误放行是安全问题**。若嫌保守，可把 conformal 的 `α` 调到 0.10，用 0.18% 的不安全换取 15% 的无害误拒。

### B. 租约撤销暴露（20,000 次故障注入，detect ~ LogNormal(mean 120ms, σ=0.9)，Δ=50ms）

| 策略 | 平均暴露动作数 | P99 | 最大 | 解析上界 |
|---|---|---|---|---|
| 无租约（仅靠检测） | 3.788 | 19 | **74** | — |
| TTL=200ms | 1.498 | 4 | 4 | 5 |
| TTL=250ms | 2.073 | 5 | 5 | 6 |
| TTL=300ms | 2.500 | 6 | 6 | 7 |
| TTL=500ms | 3.292 | 10 | 10 | 11 |

**解读**：检测延迟是重尾的，无租约时最坏暴露达 74 个动作；租约把最大暴露压到 `floor(TTL/Δ)+1` 以内。**这正是引理 11 的工程价值：安全性不再依赖检测器的尾部，而依赖一个可配置的 TTL。**

### C. 生命周期单调性（20,000 轮，40% 提升请求无有效证书）

| 策略 | 不安全激活数 | 不安全 Active 时间占比 | 合法提升被放行 |
|---|---|---|---|
| 朴素 lifecycle | 15,826 | 39.97% | 24,173 |
| ARGOS 守卫 | **0** | **0%** | 24,173 |

**解读**：守卫只阻断无证书的提升，不误伤合法恢复（定理 12）。

### D. 图级故障归因（5 类，最近质心分类器，8,000 train / 8,000 test）

| 特征 | 总体 top-1 | none | node_late | topic_drop | qos_mismatch | semantic_drift |
|---|---|---|---|---|---|---|
| 仅节点残差 `ρ_local` | 0.530 | 0.292 | 0.369 | 0.413 | 0.809 | 0.757 |
| `ρ_G`（+图特征） | **0.946** | 0.881 | 0.946 | 0.952 | 0.975 | 0.976 |

**解读**：节点残差几乎无法区分 `node_late / topic_drop / none`（0.29–0.41），加入延迟、丢包、QoS、lifecycle 后提升到 0.88–0.98。这直接支持定理 14：**图不是管道，图是额外的观测面。**

### E. 语义漂移检测（CUSUM，阈值在 null 轨迹上校准到 1% 误报）

| 漂移 δ | 校准阈值 h | 平均检测延迟（样本） | P95 | 漏检率 | 误报率 |
|---|---|---|---|---|---|
| 0.25 | 44.572 | 300.6 | 548.5 | 1.0% | 0.33% |
| 0.50 | 22.159 | 84.0 | 159.2 | 0% | 0.67% |
| 1.00 | 12.340 | 23.5 | 43.1 | 0% | 0% |

**解读**：SDS 是**慢平面**监视器，检测延迟以 token 样本计；它不承担安全触发，只负责撤销语义租约、把 VLA 降级。真正的安全兜底仍是租约到期 + VISTA/RAS 回退（定理 11）。

## 7. 本轮最大风险

**一句话**：ARGOS 的全部安全性建立在「ZTS 是唯一执行路径」与「`pre` 是安全集的可靠过近似」这两个工程假设上；在真实 ROS 图中，只要存在一条绕过 ZTS 的 actuator 话题、一个语义正确但形式上可证的错误计划，或一次未被观测到的 QoS 违约，零信任就会退化为**「局部受证、整体幻觉」**——证书证明了每一步都合法，却没有证明整条计划是用户想要的。

**次级风险与缓解**：
1. **ZTS 旁路**：厂商驱动直写硬件、共享内存、独立安全链 → DDS Security 域隔离 + 硬件互锁 + 启动时枚举所有 publisher 审计；
2. **谓词不可靠**：`pre` 只是过近似，可能漏掉物理耦合 → 运行时监视器 + 保守下置信界 + 未知 fail-closed；
3. **租约粒度两难**：TTL 大则暴露大，小则频繁停走 → 风险自适应 TTL，并令 `TTL ≤ D_sem − age`；
4. **生命周期竞态**：多节点并发迁移 → 每节点单一 lifecycle 权威 + epoch 逻辑时钟 + 迁移幂等；
5. **时钟偏斜**：禁止墙钟比较 TTL，改用单调时钟 + 逻辑 epoch；
6. **漂移检测慢**：SDS 只作慢平面降级，安全由租约到期与 VISTA/RAS 兜底；
7. **恢复抖动**：滞回 + 隔离窗口 + 恢复速率上限；
8. **可追责≠可解释**：证据链能定位责任，不能证明计划符合用户意图 → 关键任务保留人类确认或形式化意图规约。

## 8. 结论

ARGOS 把「具身大模型 + ROS」从「把最聪明的模型接到最底层的消息总线上」改写为「**让大模型只拥有可撤销的语义权限，让操作系统在它碰到执行器之前完成验证、限时与追责**」。本轮的机制检查显示：零信任把不安全执行率压到 0.07%，租约把最坏暴露从 74 个动作压到 `TTL/Δ+1`，生命周期守卫把不安全激活压到 0，图级签名把故障 top-1 从 0.53 提到 0.95。**但这些都是合成数据上的机制证明，不是真实机器人上的安全证明。**
