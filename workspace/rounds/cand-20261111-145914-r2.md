# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；本轮灵感：「状态隔离」×「行为树」）

> 第 54 轮把技能组合推进到“动作剖面 α_S + 鲁棒性谱 ρ + 云边映射 γ_ce”的三重证书，但仍隐含两个过强假设：组合是**一条线性路径**，且各技能运行在**共享的可变状态**上。本轮补上被遗漏的两个第一性维度——**状态**与**执行结构**。核心矛盾：H22：两个技能动作兼容、鲁棒性达标，却因共享黑板、传感器缓存、控制器积分项发生隐性状态耦合，组合证书在运行时失效；H23：行为树的 fallback/retry 会重新进入带记忆的子树，陈旧状态把“已验证轨迹”变成“未验证的新轨迹”。

## 0. 直觉与动机

**灵感 1（状态足迹 → 把隐性耦合显性化为可检查的读写集）**
直觉：技能失败往往不是“动作不会做”，而是“动了不该动的状态”。给每个技能 S 标注状态足迹 `σ_S=(R_S,W_S,ℓ_S)`：读什么、写什么、写多久。两个技能能否组合，先看隐藏耦合集 `H_ij` 是否为空；非空则必须走声明端口，否则视为状态泄露。这把第 54 轮的“动作空间第一性约束”推进为 **动作空间 × 状态空间的双第一性约束**。

**灵感 2（状态隔离 → 用胶囊代替共享黑板）**
直觉：共享黑板是组合系统的“全局变量地狱”。把行为树的每个子树包进 **状态胶囊**：子树拥有自己的写域，读按作用域链解析，跨胶囊写只能经带类型的端口；胶囊关闭时回收 transient/leased 状态。状态隔离因此从口头约定变成可执行边界，类似分离逻辑（separation logic）的 separating conjunction：只要两个技能的足迹不相交，一个技能的证明在另一个技能存在时仍然成立。

**灵感 3（行为树 → 把线性计划升级为可反应、可回退的执行结构）**
直觉：第 54 轮的 `G_S` 路径只能表达“按序做”，无法表达“失败就换、超时就重试、并行就互斥”。行为树（Sequence/Selector/Parallel + Retry/Timeout 装饰器）给出了可组合、可反应、可监控的执行语义。组合问题于是从“找一条路径”变成“找一棵树，使其所有运行时轨迹都满足证书”。

**灵感 4（行为树验证 → 对轨迹集合而非单轨迹做证明）**
直觉：BT 的 Selector/Retry 意味着真实执行轨迹由运行时条件决定，验证必须**全称量化到所有根到叶轨迹**（含 fallback 分支和重入）。这把第 54 轮的路径证书扩展为 `BT_Cert=(Cov_A,ρ_BT,Iso_BT,Reen_BT,Live_BT)`：动作覆盖、最差轨迹鲁棒性、状态隔离、可重入安全、无死锁/活锁。

**灵感 5（云边状态契约 → 动作映射之外的第二条同步线）**
直觉：云端的粗计划不仅可能动作错位，还可能**状态错位**：云端用旧的共享状态做决策，边端已经更新。把状态划分为 `X_c`（云拥有）/`X_e`（边拥有）/`X_sh`（共享），共享状态只同步带版本号的差分；版本差超过 `Δ_ver` 或陈旧度超过 `τ_stale` 就冻结共享状态并回滚/重规划。第 54 轮的 `γ_ce` 由此升级为动作×状态的联合映射。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（状态足迹）**
状态空间 `X` 为可寻址变量集合。技能/动作 `S` 的状态足迹 `σ_S=(R_S,W_S,ℓ_S)`，其中 `R_S,W_S⊆X` 为读/写集合，`ℓ_S:W_S→{transient,persistent,leased(τ)}` 为写的生命周期。时刻 t 的有效写集
```
W_S(t) = { x∈W_S | ℓ_S(x) 未过期且 S 所在胶囊未关闭 }
```
**足迹守恒假设**：对 `X` 的任何访问都可归因到某个 `σ_S` 或一个显式端口 `Π`。

**定义 122（状态隔离与泄露）**
对 `S_i,S_j`，声明端口 `Π_ij⊆X`。隐藏耦合集
```
H_ij = (W_i∩(R_j∪W_j)) ∪ (W_j∩(R_i∪W_i)) \ Π_ij
```
状态泄露 `L_ij = |H_ij| / |X|`（可按访问频度加权）。`H_ij=∅` 为**强隔离**；`L_ij≤Θ_L` 为 **ε-隔离**。顺序组合允许经端口的 persistent 传递，但 transient/leased 未在胶囊关闭时回收即计入泄露；并发组合（Parallel）要求更强的写-写互斥。

**定义 123（状态胶囊）**
胶囊 `C=(id,parent,X_C,Π_C,policy)`，`policy∈{isolated,shared(lock),CoW}`。子树在胶囊帧中执行：读沿 `C→parent` 作用域链解析，写只落在自有 `X_C`，跨胶囊写必须经 `Π_C` 的类型检查；`close(C)` 回收 transient/leased 写。胶囊给出可执行的**干扰边界**。

**定义 124（行为树组合模式）**
行为树 `BT=(N,τ,ch,g,α,ρ,σ,C)`：节点类型 `τ∈{Sequence(→),Selector(?),Parallel(⇉),Action(S),Retry(k),Timeout(τ)}`，`ch` 为子节点，`g` 为守卫条件，Action 叶携带 `(α_S,ρ_S,σ_S)`，`C` 为节点胶囊。执行语义 `run(BT,b)=(status,b')`，`status∈{Success,Failure,Running}`。执行轨迹 `tr` 为根到一次终止的叶子激活序列；有环 BT 以重试预算 k 截断，记 `Tr_k(BT)` 为所有可达轨迹集合。

**定义 125（行为树组合证书）**
`BT_Cert=(Cov_A,ρ_BT,Iso_BT,Reen_BT,Live_BT)`：
- `Cov_A`：`∀a∈A_T` 存在可达 Action 叶且 `α_S(a)≥θ_cov`；
- `ρ_BT = min_{tr∈Tr_k(BT)} compose_robustness(tr,K)`；
- `Iso_BT`：tr 上所有并发/相邻节点的泄露 `L(tr)≤Θ_L` 且胶囊策略被遵守；
- `Reen_BT`：每次重入节点满足重置不变式（stale-state 检测为零）；
- `Live_BT`：重试预算内无死锁/活锁。
`BT_Cert.status=ok` 当且仅当五项同时成立。

**定义 126（云边状态契约与状态-动作-鲁棒性联合证书）**
云边状态契约 `C_se=(X_c,X_e,X_sh,Δ_ver,τ_stale,freeze)`：共享状态 `X_sh` 仅以带版本号差分同步，一致性要求 `|ver_c(x)-ver_e(x)|≤Δ_ver` 且 `staleness(x)≤τ_stale`；违约则原子地 `freeze(X_sh)` 并触发回滚/重规划。
联合证书 `J*=(ρ,A_cert,σ_cert,BT_Cert,γ_ce,δ_a,L,τ_stale,evidence)`，部署条件：
```
dom(J*)=in ∧ δ_a<Θ_a ∧ L≤Θ_L ∧ τ_stale≤τ_loop ∧ BT_Cert.status=ok
```

## 2. 关键算法 伪代码

### IP-121 SFP（State Footprint Profiling）

```python
def state_footprint(skill, sim, X):
    taint = TaintTracker(X)
    trace = sim.run(skill, taint=taint)
    R = taint.reads(skill)
    W = taint.writes(skill)
    leases = {x: infer_lease(trace, x) for x in W}
    unknown = taint.escaped()          # 指针别名/系统调用等未归因访问
    return StateFootprint(R | unknown, W | unknown, leases)  # 保守并集
```

### IP-122 SIB（State Isolation Barrier）

```python
class Capsule:
    def __init__(self, cid, parent=None, ports=None, policy='CoW'):
        self.cid, self.parent, self.policy = cid, parent, policy
        self.ports = ports or {}
        self.store = CoWStore(parent.store if parent else None)

    def read(self, x):
        if x in self.ports:
            return self.ports[x].read()
        return self.store.read(x)

    def write(self, x, v):
        if x in self.ports:
            return self.ports[x].write(v)
        if x not in self.store.owned and self.parent and x in self.parent.store:
            raise LeakageError(self.cid, x)
        self.store.write(x, v)

    def close(self):
        self.store.release(lambda x: self.store.lease(x) != 'persistent')
```

### IP-123 BTC（Behavior Tree Composition）

```python
def compile_bt(task, skills, G, monitors, k):
    root = build_and_or(task)                       # 任务 AND-OR 分解
    for leaf in root.leaves():
        leaf.action = select_skill(leaf.subgoal, skills, G)  # 动作兼容 + rho
    for node in postorder(root):
        node.scope = Capsule(node.id, parent=node.parent.scope)
        annotate(node)                              # 附加 alpha, rho, sigma
    return add_fallbacks(root, monitors, k)         # Selector(monitor, Retry(k, act))
```

### IP-124 BTV（Behavior Tree Verification）

```python
def verify_bt(bt, A_T, rho_min, theta_L, K, k):
    traces = bounded_unroll(bt, k)
    for tr in traces:
        if not cover_actions(tr, A_T):
            return ('reject', 'coverage', tr)
        if min(compose_robustness(tr, K)) < rho_min:
            return ('reject', 'robustness', tr)
        if leakage(tr) > theta_L:
            return ('reject', 'state_leak', tr)
        if not reentrant_safe(tr):
            return ('reject', 'reentrancy', tr)
    if not progress(bt, k):
        return ('reject', 'livelock')
    return ('ok', BTCert(traces, rho=min_rho(traces), L=max_L(traces)))
```

### IP-125 SSC（State Sync Contract）

```python
def sync_state(c_state, e_state, spec):
    X_c, X_e, X_sh = partition(spec.X)
    for x in X_sh:
        if abs(c_state.ver(x) - e_state.ver(x)) > spec.delta_ver:
            freeze(X_sh, x)
            return ('diverged', x, 'replan')
    if max_staleness(c_state, e_state, X_sh) > spec.tau_stale:
        freeze(X_sh)
        return ('stale', 'rollback')
    for x in X_sh:
        if e_state.ver(x) > c_state.ver(x):
            c_state.apply(x, e_state.diff(x))
    return ('ok', sync_report(c_state, e_state))
```

### IP-126 JSC（Joint State Certificate）

```python
def joint_state_certificate(bt, rho_min, theta_L, delta_a_budget, tau_stale):
    cert = verify_bt(bt, bt.task.A_T, rho_min, theta_L, K, k=bt.retry_bound)
    if cert.status != 'ok':
        return ('reject', cert.reason, cert.trace)
    if not cloud_edge_contract_holds(bt.C_se, tau_stale):
        return ('reject', 'state_stale', bt.C_se)
    sigma_cert = (cert.isolation_edges, cert.leases, cert.leakage)
    J = JointStateCert(rho=cert.rho, A_cert=bt.A_cert, sigma_cert=sigma_cert,
                       BT_cert=cert, gamma_ce=bt.gamma_ce,
                       delta_a=bt.delta_a, L=cert.leakage,
                       tau_stale=bt.C_se.tau)
    return ('ok', J)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SFP | O(|tr|·|X|) | O(|X|) | 污点追踪对读/写集是 sound over-approximation |
| SIB | O(1) 摊还 | O(|X_C|)/胶囊 | 写屏障完备，无静默跨胶囊写 |
| BTC | O(|N|·|S|) | O(|N|) | AND-OR 分解覆盖任务，叶节点可执行 |
| BTV | O(|Tr_k|·|N|) | O(d·|X|) | 有界展开 sound；环路需运行时监控补足 |
| SSC | O(|X_sh|)/次同步 | O(|X_sh|) | 版本差/陈旧度可观测，freeze 原子 |
| JSC | O(|Tr_k|·(|X|+|𝔇_ρ|)) | O(|X|+|𝔇_ρ|) | 联合证书 sound，各预算闭合 |

**正确性定理（State-Isolated Behavior-Tree Composition Soundness）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** `σ_S` 是真实读写集的 sound over-approximation，未知访问并入 `R_S∪W_S`；**(A30)** 胶囊写屏障完备，任何越界写都会触发 `LeakageError` 而非静默忽略；**(A31)** BT 重试有界为 k 且调度公平，`Tr_k(BT)` 覆盖所有 k-重试内的执行；**(A32)** 云边状态版本差与陈旧度可观测，`freeze` 原子；**(A33)** Explain 回传延迟 ≤ `τ_loop`。
则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
              - P(L>Θ_L) - P(stale>τ_stale) - β_re
```
其中 `β_re` 为有界展开之外的长期重入污染逃逸概率。关键论证：胶囊 + 足迹不相交给出分离逻辑式的局部性（frame rule），使每个子树的证书在组合下不被其他子树改写；有界展开把 BT 的轨迹集合覆盖到 k 次重试；`freeze` 把状态陈旧变成 fail-safe 而非 fail-silent。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 状态足迹欠近似（指针/OS 缓存/策略隐状态） | 高 | 污点追踪 + unknown-writes 保守隔离 + 运行时写屏障 |
| 胶囊导致状态复制与同步开销 | 中 | CoW + transient 原地写 + 只对跨边界状态做差分 |
| BT 环路使验证不可判定 | 高 | 有界展开 k + 运行时监控 + 不可验证子树强制隔离/硬重置 |
| 云边状态陈旧引发震荡 | 中 | 版本号 + freeze + hysteresis + 回滚锚点 |
| 行为树与技能语义错配 | 中 | 统一任务本体 + 叶节点类型契约 + 反例回放 |

## 6. 本轮最大风险

**一句话**：本轮方案的最大风险是 **状态隔离的 soundness 完全取决于状态足迹的可观测性**——一旦指针别名、OS 缓存或学习策略的隐状态逃逸出污点追踪，胶囊与行为树证书就会把“看不见的耦合”误判为隔离；叠加行为树环路的不可判定性，被有界展开漏掉的长程状态污染可能直到部署后才暴露，因此必须以 **保守 unknown-writes 隔离 + 运行时写屏障 + 不可验证子树硬重置** 作为最后防线。

```python
def verify_bt(bt, A_T, rho_min, theta_L, K, k):
    traces = bounded_unroll(bt, k)
    for tr in traces:
        if not cover_actions(tr, A_T):          return ('reject','coverage',tr)
        if min(compose_robustness(tr, K)) < rho_min:
                                                return ('reject','robustness',tr)
        if leakage(tr) > theta_L:               return ('reject','state_leak',tr)
        if not reentrant_safe(tr):              return ('reject','reentrancy',tr)
    if not progress(bt, k):                     return ('reject','livelock')
    return ('ok', BTCert(traces, rho=min_rho(traces), L=max_L(traces)))
```

def sync_state(c_state, e_state, spec):
    X_c, X_e, X_sh = partition(spec.X)
    for x in X_sh:
        if abs(c_state.ver(x) - e_state.ver(x)) > spec.delta_ver:
            freeze(X_sh, x); return ('diverged', x, 'replan')
    if max_staleness(c_state, e_state, X_sh) > spec.tau_stale:
        freeze(X_sh); return ('stale', 'rollback')
    for x in X_sh:
        if e_state.ver(x) > c_state.ver(x):
            c_state.apply(x, e_state.diff(x))
    return ('ok', sync_report(c_state, e_state))

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SFP | O(|tr|·|X|) | O(|X|) | 污点追踪 sound over-approximation |
| SIB | O(1) 摊还 | O(|X_C|)/胶囊 | 写屏障完备，无静默越界写 |
| BTC | O(|N|·|S|) | O(|N|) | AND-OR 分解覆盖任务 |
| BTV | O(|Tr_k|·|N|) | O(d·|X|) | 有界展开 sound，环路需运行时监控 |
| SSC | O(|X_sh|)/次 | O(|X_sh|) | 版本/陈旧度可观测，freeze 原子 |
| JSC | O(|Tr_k|·(|X|+|𝔇_ρ|)) | O(|X|+|𝔇_ρ|) | 联合证书 sound，预算闭合 |

**正确性定理（State-Isolated Behavior-Tree Composition Soundness）**
假设 (A22)–(A28) 成立；**(A29)** `σ_S` 为真实读写集的 sound over-approximation，未知访问并入 `R_S∪W_S`；**(A30)** 胶囊写屏障完备，越界写触发 `LeakageError`；**(A31)** BT 重试有界 k 且调度公平；**(A32)** 云边版本差与陈旧度可观测且 `freeze` 原子；**(A33)** Explain 回传延迟 ≤ `τ_loop`。
则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
              - P(L>Θ_L) - P(stale>τ_stale) - β_re
```
其中 `β_re` 为有界展开之外的长期重入污染逃逸概率。关键：**足迹不相交 + 胶囊写入边界 ⇒ 分离逻辑式局部性**，**有界展开覆盖 k-重试轨迹**，**freeze 把状态陈旧转为 fail-safe**。

## 6. 本轮最大风险

**一句话**：本轮方案的最大风险是 **状态隔离的 soundness 完全取决于状态足迹的可观测性**——一旦指针别名、OS 缓存或学习策略的隐状态逃逸出污点追踪，胶囊与行为树证书就会把“看不见的耦合”误判为隔离；叠加行为树环路的不可判定性，被有界展开漏掉的长程状态污染可能直到部署后才暴露，因此必须以 **保守 unknown-writes 隔离 + 运行时写屏障 + 不可验证子树硬重置** 作为最后防线。
