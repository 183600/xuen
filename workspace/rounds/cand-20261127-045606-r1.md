### 第 1 轮灵感驱动研究记录

**灵感词**：路径规划、夹爪控制

**直觉与动机**：
现有 v24（USMC）已把「感知-合规-能量-结构-力学」串成证书链，但运动与操作仍被当作两个独立后处理：路径规划负责「去哪里」，夹爪控制负责「抓得牢」。真实失效恰恰发生在二者的接口——一条对空载机器人安全的轨迹，可能在夹持物体后因惯性加速度超出摩擦锥而打滑；一个在静止标定下力封闭的抓取，可能在高速搬运的急动（jerk）下瞬时失去接触。受「路径规划」启发，轨迹应携带时空安全证书（安全走廊、动态可行性、时序逻辑鲁棒性）；受「夹爪控制」启发，抓取应携带接触证书（力封闭裕度、摩擦锥、夹持力窗口、无源性）。核心洞见：**路径规划决定证书的「时空调度」，夹爪控制决定证书的「接触边界条件」；二者不是串联而是耦合——轨迹加速度反作用于抓取所需法向力，夹爪带宽反作用于轨迹可执行急动**。因此必须引入一个显式的「计划-抓取组合证书」，把两个子证书的假设在时间轴上对齐，否则「各自正确」的组合仍可能不安全。

**形式化目标**：
1. 定义路径规划证书（PPC）：轨迹 ξ(t) 的安全走廊 P_k、鲁棒间隙 d(t) ≥ d_safe、动态可行域 q̇/q̈/τ 与 STL 鲁棒度 ρ_φ ≥ ρ_min。
2. 定义抓取证书（GCC）：抓取矩阵 G、力封闭裕度 ε_fc、摩擦锥内接触力 λ ∈ K_μ、夹持力窗口 f_n ∈ [f_min, f_max]、夹爪力控无源性。
3. 定义抓取可行加速度包络（GMFE）：A_grasp = {a : ∃λ∈K_μ, Gλ = m(g−a)}，把抓取能力翻译为轨迹加速度的凸约束。
4. 定义计划-抓取组合证书（PGCC）：在接触区间 [t_g, t_r] 上逐时刻验证 λ_req(t) ∈ K_μ 与力控带宽-轨迹 jerk 耦合 ω_grip ≥ κ‖jerk‖_∞，并覆盖接近/抓取/抬升/搬运/释放的接触模式切换。
5. 构建统一时空准入门（USTC）：v24 ∪ PPC ∪ GCC ∪ GMFE ∪ PGCC，Exec_v25 ⊆ Exec_v24；给出「子证书各自成立但组合失效」的反例，并证明组合证书补上了该缺口。

**本轮最大风险（想法层）**：接触/摩擦模型是准静态、确定性的，而真实接触含未建模冲击、摩擦系数不确定与力跟踪滞后；在高 jerk + 低摩擦 + 模式切换冲击的协同下，PGCC 可能把一条实际会打滑的计划判为通过。

# ============================================================
# IP-444 Path Planning Certificate (PPC) — 路径规划证书
# ============================================================
@dataclass
class PathPlanningCertificate:
    """安全走廊 + 动态可行性 + STL 鲁棒性三重证书"""
    trajectory: 'Trajectory'          # ξ(t), t ∈ [0,T]
    corridor: list['Polytope']        # P_1..P_K，凸安全走廊
    obstacles: 'ObstacleSet'
    d_safe: float                     # 含控制误差的最小间隙
    eps_u: float                      # 不确定半径
    qd_max: Tensor; qdd_max: Tensor; tau_max: Tensor
    stl_spec: 'STLSpec'
    rho_min: float = 0.0

    def verify_corridor(self) -> bool:
        """ξ(t) 落在走廊内，且每条走廊与障碍物保持 d_safe"""
        for k, P in enumerate(self.corridor):
            if self.obstacles.distance(P) < self.d_safe + self.eps_u:
                return False
        for t, xi in self.trajectory.samples():
            if not any(P.contains(xi) for P in self.corridor):
                return False
        return True

    def verify_clearance(self) -> bool:
        """扫掠体积膨胀 ε_u 后与障碍物的距离 ≥ d_safe"""
        for t in self.trajectory.sample_times():
            S = self.trajectory.swept_volume(t, inflate=self.eps_u)
            if self.obstacles.distance(S) < self.d_safe:
                return False
        return True

    def verify_dynamics(self, rbd: 'RigidBodyDynamics') -> bool:
        """关节速度/加速度/力矩逐点满足硬上界"""
        for q, qd, qdd in self.trajectory.joint_samples():
            if (qd.abs() > self.qd_max).any():
                return False
            if (qdd.abs() > self.qdd_max).any():
                return False
            tau = rbd.inverse_dynamics(q, qd, qdd)
            if (tau.abs() > self.tau_max).any():
                return False
        return True

    def verify_temporal(self) -> bool:
        """STL 鲁棒度非负（留 ρ_min 裕度）"""
        return self.stl_spec.robustness(self.trajectory) >= self.rho_min

    def verify_all(self, rbd: 'RigidBodyDynamics') -> bool:
        return (self.verify_corridor() and self.verify_clearance() and
                self.verify_dynamics(rbd) and self.verify_temporal())


# ============================================================
# IP-445 Grasp Control Certificate (GCC) — 夹爪控制证书
# ============================================================
@dataclass
class GraspCertificate:
    """力封闭 + 摩擦锥 + 夹持力窗口 + 夹爪无源性/带宽"""
    contacts: list['Contact']         # (p_i, n_i, μ_i)
    G: Tensor                         # [6, n_c] 抓取矩阵
    eps_fc: float                     # 力封闭裕度
    eps_fc_min: float = 0.1
    f_min: float = 0.0
    f_max: float = 1e3
    delta: float = 0.1                # 摩擦锥内缩比例
    omega_grip: float = 100.0         # 夹爪力控带宽 (rad/s)
    # 夹爪力控回路（与 IP-441 同构）
    M_d: Tensor = None; B_d: Tensor = None; K_d: Tensor = None
    T_s: float = 1e-3

    def verify_force_closure(self) -> bool:
        """ε_fc ≥ ε_min：原点深入力旋量多面体 W={Gλ:λ∈K_μ}"""
        return self.eps_fc >= self.eps_fc_min

    def verify_force_window(self, f_n_cmd: Tensor) -> bool:
        return bool((f_n_cmd >= self.f_min).all() and
                    (f_n_cmd <= self.f_max).all())

    def in_robust_friction_cone(self, lam: Tensor) -> bool:
        """λ ∈ (1−δ)K_μ：切向不超过 (1−δ)μ 法向"""
        lam = lam.reshape(-1, 3)
        fn, ft = lam[:, 0], lam[:, 1:].norm(dim=-1)
        return bool((fn > 0).all() and
                    (ft <= (1 - self.delta) * self.mu * fn).all())

    def required_contact_forces(self, a: Tensor, alpha: Tensor,
                                omega: Tensor, m: float, I: Tensor,
                                g_vec: Tensor) -> Tensor:
        """G λ = w_req(t)，取最小范数解 + 内力预紧"""
        w_req = torch.cat([m * (g_vec - a),
                           I @ alpha + torch.cross(omega, I @ omega)])
        lam = torch.linalg.pinv(self.G) @ w_req + self.lambda_int
        return lam

    def verify_passivity(self, F_hist: Tensor, v_hist: Tensor) -> bool:
        power = (F_hist * v_hist).sum(dim=-1)
        return bool((power.cumsum(0) * self.T_s >= -1e-6).all())


# ============================================================
# IP-446 Grasp-Motion Feasibility Envelope (GMFE) — 耦合包络
# ============================================================
def grasp_feasible_acceleration_set(grasp: GraspCertificate, m: float,
                                    g_vec: Tensor, alpha: Tensor,
                                    omega: Tensor, I: Tensor,
                                    n_h: int = 64) -> 'Polytope':
    """A_grasp = {a : ∃λ∈K_μ, Gλ = w_req(a)}
    由于 w_req 对 a 仿射、K_μ 为凸锥、G 为线性映射，
    投影后 A_grasp 仍为凸多面体。离线用多面体投影/半空间枚举，
    在线退化为「给定 a 求 λ 并检查锥约束」。"""
    # 生成摩擦锥的极射线，构造可达力旋量多面体，再投影到加速度空间
    rays = friction_cone_extreme_rays(grasp.contacts, grasp.mu)
    w_poly = convex_hull([grasp.G @ r for r in rays])      # W ⊂ ℝ⁶
    # w_req(a) = w0 − [mI_3; 0] a  ⇒  a = (w0 − w)/m 的线性像
    A = project_affine(w_poly, scale=1.0 / m, offset=w0(g_vec, alpha, omega, I))
    return A


# ============================================================
# IP-447 Plan-Grasp Composition Certificate (PGCC) — 组合证书
# ============================================================
@dataclass
class PlanGraspCompositionCertificate:
    ppc: PathPlanningCertificate
    gcc: GraspCertificate
    t_grasp: float
    t_release: float
    kappa: float = 1.0                # 带宽-急动耦合系数
    m: float = 1.0; I: Tensor = None
    g_vec: Tensor = None

    def verify_acceleration_envelope(self) -> bool:
        """接触区间内 a(t) ∈ A_grasp（逐点凸可行性检查）"""
        A = grasp_feasible_acceleration_set(self.gcc, self.m, self.g_vec,
                                            alpha=0, omega=0, I=self.I)
        for t in linspace(self.t_grasp, self.t_release):
            a = self.ppc.trajectory.acceleration(t)
            if not A.contains(a):
                return False
        return True

    def verify_force_schedule(self) -> bool:
        """由 a(t) 反解 λ_req(t)，检查鲁棒摩擦锥与夹持力窗口"""
        for t in linspace(self.t_grasp, self.t_release):
            a = self.ppc.trajectory.acceleration(t)
            alpha = self.ppc.trajectory.angular_acceleration(t)
            omega = self.ppc.trajectory.angular_velocity(t)
            lam = self.gcc.required_contact_forces(a, alpha, omega,
                                                   self.m, self.I, self.g_vec)
            if not self.gcc.in_robust_friction_cone(lam):
                return False
            if not self.gcc.verify_force_window(lam.reshape(-1, 3)[:, 0]):
                return False
        return True

    def verify_bandwidth_jerk_coupling(self) -> bool:
        """ω_grip ≥ κ·‖jerk‖_∞：力控回路必须快于轨迹急动"""
        jerk_inf = self.ppc.trajectory.jerk_norm_inf(self.t_grasp,
                                                     self.t_release)
        return self.gcc.omega_grip >= self.kappa * jerk_inf

    def verify_contact_mode_invariants(self) -> bool:
        """接近→抓取→抬升→搬运→释放，每次切换保持接触不变式：
        (i) 切换瞬间法向速度 ≤ v_touch_max（软着陆，限制冲击）；
        (ii) 切换后力控参考在 [f_min,f_max] 内连续；
        (iii) 释放前负载速度在支撑面法向分量受控。"""
        for ev in self.ppc.trajectory.contact_events(self.t_grasp, self.t_release):
            if ev.kind == 'touch':
                if ev.normal_speed > self.v_touch_max: return False
            if ev.kind == 'release':
                if ev.normal_speed_out > self.v_release_max: return False
            if not self.gcc.verify_force_window(ev.f_n_ref): return False
        return True

    def verify_all(self) -> bool:
        return (self.verify_acceleration_envelope() and
                self.verify_force_schedule() and
                self.verify_bandwidth_jerk_coupling() and
                self.verify_contact_mode_invariants())

# IP-448 USTC 统一时空准入门
# ============================================================
@dataclass
class UnifiedSpatiotemporalCertificate:
    ustc_v24: 'UnifiedStructuralMechanicalCertificate'
    ppc: PathPlanningCertificate
    gcc: GraspCertificate
    pgcc: PlanGraspCompositionCertificate

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               F_hist, v_hist, volume, rho_solid, rbd) -> bool:
        # 1. v24 四证（感知-合规-能量-结构）
        if not self.ustc_v24.admits(plan, x, v, z, E_res, margin_req,
                                    modules, F_hist, v_hist, volume, rho_solid):
            return False
        # 2. 路径证书
        if not self.ppc.verify_all(rbd):
            return False
        # 3. 抓取证书
        if not (self.gcc.verify_force_closure() and
                self.gcc.verify_passivity(F_hist, v_hist)):
            return False
        # 4. 包络非空（该抓取至少能承载一种运动）
        if grasp_feasible_acceleration_set(self.gcc, self.pgcc.m,
                                           self.pgcc.g_vec, 0, 0,
                                           self.pgcc.I).is_empty():
            return False
        # 5. 组合证书（路径与抓取的时空对齐）
        if not self.pgcc.verify_all():
            return False
        return True

## 3. 正确性论证（增量）

### 引理 9（路径证书的间隙-动态-时序三重保证）
**陈述**：`PPC.verify_all = True` ⟹ 轨迹 ξ(t) 在 t∈[0,T] 上同时满足：
(1) 膨胀不确定半径后与所有障碍物间隙 ≥ d_safe；
(2) 关节速度/加速度/逆动力学力矩逐点不超过硬件上界；
(3) STL 规范 φ 的鲁棒度 ≥ ρ_min。

**证明**：
1. `verify_corridor` 保证 ξ(t) 落在凸走廊并集内，且每条走廊与 O 的距离 ≥ d_safe+ε_u；`verify_clearance` 进一步对扫掠体膨胀 ε_u 后直接测距，二者独立冗余，取合取更保守。
2. `verify_dynamics` 在采样时刻逐点用 RNEA 计算 τ，采样间隔由轨迹的 Lipschitz 常数上界保证（速度/加速度有界），故连续时间界可由采样界加 Lipschitz 余量推出；本证书要求采样密度满足 Nyquist-like 条件。
3. STL 鲁棒度是连续时间语义的保守离散近似；ρ_min>0 提供额外时间裕度。
∎

### 引理 10（抓取证书的力封闭-摩擦-力窗-无源四重保证）
**陈述**：`GCC.verify_force_closure ∧ in_robust_friction_cone ∧ verify_force_window ∧ verify_passivity = True` ⟹ 抓取在任意 λ∈(1−δ)K_μ 且 f_n∈[f_min,f_max] 时能抵抗任意方向外力旋量，且夹爪能量不增。

**证明**：
1. 力封闭裕度 ε_fc 定义为原点深入 W={Gλ:λ∈K_μ} 的距离；ε_fc≥ε_min>0 等价于 W 包含以原点为中心、半径 ε_min 的球，故任意 ‖w_ext‖≤ε_min 的外力旋量都可由锥内接触力平衡（标准力封闭判据）。
2. 内缩 δ 把摩擦锥边界留出相对裕度，抵抗 μ 的估计误差：真实 μ_true≥μ_nom 时仍安全。
3. 力窗口保证不滑（f_n≥f_min）且不压碎（f_n≤f_max）。
4. 无源性由离散功率积分非负保证，夹爪-环境接触不会注入能量。
∎

### 引理 11（GMFE 的精确性与凸性）
**陈述**：A_grasp={a:∃λ∈K_μ, Gλ=w_req(a)} 是凸集；且 a∈A_grasp ⟺ 存在满足摩擦锥的接触力平衡负载惯性力。

**证明**：
1. w_req(a)=w_0−[mI₃;0]a 对 a 仿射；K_μ 是凸锥；线性映射 G 保凸，故 {(a,λ):Gλ=w_req(a),λ∈K_μ} 为凸集，其在 a 上的投影 A_grasp 为凸集。
2. 由定义直接得等价性：a∈A_grasp 当且仅当存在 λ∈K_μ 使 Gλ=w_req(a)，即牛顿-欧拉平衡可被锥内接触力实现。
3. 若 A_grasp=∅，则不存在任何接触力配置能承载负载，任何轨迹都不可能安全，必须在抓取层重规划（换抓取点/增大 μ/降低负载）。
∎

### 引理 12（PGCC 的组合可靠性）
**陈述**：若 PPC、GCC 成立且 `PGCC.verify_all = True`，则在接触区间 I_c 上存在接触力轨迹 λ(t)∈(1−δ)K_μ∩[f_min,f_max]，使负载沿 ξ(t) 运动的牛顿-欧拉方程逐时刻成立；在力跟踪误差界 ‖e(t)‖≤c·‖jerk‖_∞/ω_grip² 且 δ、ρ_min 覆盖该误差时，实际接触不打滑、不失稳。

**证明**：
1. `verify_acceleration_envelope` 给出 ∀t∈I_c: a(t)∈A_grasp；由引理 11，逐点存在 λ(t)∈K_μ 满足平衡。
2. `verify_force_schedule` 取其中满足内缩锥与力窗的最小范数解+内力，保证 λ(t) 有统一正裕度。
3. `verify_bandwidth_jerk_coupling` 给 ω_grip≥κ‖jerk‖_∞；对二阶力控回路，跟踪误差上界与 jerk/ω_grip² 同阶。选择 κ 与 δ 使 (1−δ)μ·f_min 大于误差引起的切向力偏差，则实际 λ 仍在真实摩擦锥内。
4. `verify_contact_mode_invariants` 限制切换瞬间法向速度，使冲击力增量 ≤ m·v_touch/T_s，并被 f_max−f_n 的余量吸收，故模式切换不破坏上述不变式。
∎

### 命题（子证书各自成立不蕴含组合安全——反例）
**陈述**：存在 PPC=True 且 GCC=True，但 PGCC=False 且实际打滑的计划；故 PGCC 不可由 PPC∧GCC 推出。

**构造**：负载 m=1kg，g=9.8m/s²，两接触点 μ=0.5，夹持力各 f_n=10N（窗口 [5,20]N，静止时总最大切向摩擦 2·0.5·10=10N > mg=9.8N，故 GCC 的静止力封闭成立）。取一条在自由空间无碰撞、且加速度满足空载动力学上界的轨迹，其在 t₀ 处有向上加速度 a=1m/s²。所需总法向支撑力为 m(g+a)=10.8N > 10N，切向需求超过摩擦上限，实际打滑。此例中 PPC（对空载机器人）与 GCC（对静止负载）均为真，但 PGCC 的 `verify_force_schedule` 在 t₀ 处为假。
∎

**意义**：这正是「运动-操作接口」的证书缺口；USTC 必须把 PGCC 作为独立合取项，而不能把 PPC、GCC 的合取误当作充分条件。

### 引理 13（五证一体单调退化链延伸）
**陈述**：任意单点/组合失效下，`Exec_v25 ⊆ Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：在引理 8 基础上增加四条退化路径：
- 路径不可行（碰撞/超动力学/STL 违反）→ `PPC=false` → 退回 `Exec_v24`：原地制动到已认证的保守速度包络并重规划，保留 v24 全部证书。
- 抓取不可行（力封闭失败/超力窗）→ `GCC=false` → 退回 `Exec_v24`：先放置负载或改用已认证的备用抓取，禁止搬运。
- 包络为空（A_grasp=∅）→ `GMFE=∅` → 退回 `Exec_v24`：该负载-抓取组合禁止运动，只允许原地保持。
- 组合失配（a(t)∉A_grasp 或带宽-急动不足）→ `PGCC=false` → 退回 `Exec_v24`：降速/降 jerk 到 PGCC 通过，或中止搬运并放置。
- 组合失效取交集，单调性由集合交保持。
∎

### 定理（USTC 的时空-接触完备性）
**陈述**：对任意计划 π，`USTC.admits(π)=True` ⟺ π 同时满足：
(1)–(7) v24 的感知/合规/云边/少样本/专利/结构/力控/轻量化条件；
(8) 路径安全走廊、鲁棒间隙、动态可行性、STL 鲁棒性；
(9) 抓取力封闭、鲁棒摩擦锥、夹持力窗口、夹爪无源性；
(10) 抓取可行加速度包络非空；
(11) 接触区间内加速度∈A_grasp、接触力∈(1−δ)K_μ∩力窗、带宽-急动耦合、接触模式切换不变式。

**证明**：由 `USTC.admits` 的十一个合取项直接得。必要性：任一项缺失即拒证，分别对应碰撞、超动力学、时序违反、滑移、压碎、能量注入、惯性失配、切换冲击八类风险之一。充分性：由引理 9–13，全部条件成立时存在逐时刻接触力轨迹并满足牛顿-欧拉平衡与无源性，且退化链保证执行集单调收缩，故构成时空-接触闭环。
∎
