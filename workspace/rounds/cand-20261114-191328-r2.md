# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「用户体验」×「遥操作」）

> R69 把不确定性一分为二（aleatoric / epistemic），并让系统学会「问」：看、问、触、等。但 R69 的整个交互模型把人当成一个**免费、无限耐心、状态不变的答案神谕**：一次提问只扣一点社交成本 c(g)，回答的分布不因「人此刻正在避障、已经连续值守六小时、或过度信任自动化」而改变。真实遥操作里，人不是神谕，而是**带宽有限、会疲劳、会过度信任或过度怀疑、会因被接管而失去情境意识的伙伴**。同一个问题，在操作员空闲时是帮助，在避障关键时刻是致命分心；同一次自动接管，在警觉时是减负，在长期运行后是**技能退化与脱岗**。更隐蔽的是：R69 的提问会**改变人**——增加负荷、改变信任、转移注意——而 R69 的 VoI 假设人状态不变，因此会系统性高估提问的价值。
>
> 本轮两个灵感正好互补：
> - **遥操作**把「人」变成回路中的一等状态：延迟 δ、权限 α、接管/交还、人在环/人在环上，都是控制问题；
> - **用户体验**把「人」从成本项变成**必须被观测、被校准、被保护的状态变量**：工作负荷、情境意识、信任校准、心智模型、可预测性、掌控感。
>
> 核心命题：**R69 只优化「信息值不值钱」；R70 必须同时优化「这个问题/这个动作，对这个状态下的这个人，值不值钱」。把权威分配 α 与沟通 g 作为与风险缩放 λ 并列的控制变量；把人的状态 h 作为必须估计但不可完全观测的隐变量；信任只校准、不最大化；自主只减负、不剥夺情境意识。** 命名 **TANDEM-RAS**（Trust-calibrated, Authority-Negotiated, Delay-compensated, Explainable, Mental-model-aligned Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该把多少控制权、在什么时刻、以什么方式交还给一个正在疲劳/分心/过度信任的人？**」——最好的交互不是问得最多，而是让人类在需要时刚好知道得足够多、握得住方向盘。

## 0. 直觉与动机

**灵感 1（遥操作 → 人不是外挂，是回路中的状态）**
直觉：R69 的人在环外，只在被问时出现。真实遥操作里，人的延迟 δ、命令到达率、注视、接管动作都在实时影响系统。更关键的是，**控制权不是二值开关**：从全手动到全自主之间是连续的 α；而 α 一变，人的情境意识和未来接管能力也跟着变。于是「谁控制」不是一次性分配，而是一个**双边、连续、带记忆的协商过程**。系统必须同时估计：人现在能不能接、愿不愿接、接了以后还来不来得及。

**灵感 2（用户体验 → 负荷、信任、情境意识是安全变量）**
直觉：UX 常被当成界面美化，但在遥操作里它是安全科学：
- **工作负荷**高 → 反应变慢、漏看告警；R69 在此刻提问等于添乱；
- **情境意识**低 → 接管时不知道发生了什么；过度自主会让人「脱岗」，需要时接不回来；
- **信任失准** → 过度信任导致自动化 complacency，信任不足导致弃用；目标不是「让人更信任」，而是「让信任匹配可靠性」；
- **心智模型**错 → 模式混淆，人以为机器人要做 A，机器人做了 B。
这些都不是软指标，而是**决定接管成功率的硬状态**。R70 把它们写成约束与控制目标。

**灵感 3（R69 的 VoI 是「人状态冻结」的退化情形）**
直觉：R69 的 VoI(g)=H(M|o)−E[H(M|o,y)] 只算「答案能减少多少机器人歧义」，不算「问这一句会让人多累、多慌、少看几眼路」。把它显式化：问句有**表演性效应**（performative effect），h_{t+1}=T(h_t,g)。于是净 VoI 必须减去人状态转移带来的未来代价。只有在 h 恒定、δ=0、α 不参与时，R70 才逐指令退化为 R69。这保持了 R68⊆R69⊆R70 的严格包含链。

**灵感 4（延迟 → 权限必须按「预测可信度」打折）**
直觉：遥操作的核心物理约束是延迟 δ。人此刻的摇杆命令要到 t+δ 才生效，系统必须预测。预测越不可信，越不能把 α 拉向人；但也不能直接夺权——突然接管会让人的心智模型断裂。正确做法是**延迟补偿的连续权限**：用预测分布的可信度给 α 打折，同时用预览/触觉提示把「我要怎么做」提前告诉人，让接管变成可预期的事件，而不是惊吓。

**灵感 5（双刃剑 → 信任操纵与「把人养废」）**
直觉：一旦系统能观测并优化人的状态，它就有了操纵人的能力：选择性地展示信息以提高服从、用「为你好」的接管剥夺练习机会、用过多确认让人形成依赖。更糟的是闭环自证：系统判断人「负荷高」→ 接管 → 人失去情境意识 → 下次更「负荷高」→ 永久接管。**UX 优化若没有非操纵约束与人类主权，会把共享控制变成温柔的暴政。** 所以必须交付：信任校准而非最大化、解释的可审计真实性、人类否决权、技能保持预算、以及「不接管」作为一种需要被论证的选择。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（TANDEM-RAS 总览）** TANDEM-RAS = (HSU, TCM, ANA, LAC, XIC, HOV, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）：人状态模型只在线推断，不在实时回路写参数；
(ii) **人类主权**：HOV 保证人的显式否决/接管优先；任何自主决策不得绕过 HOV；权限切换必须先宣告后执行；硬安全滤波独立于人状态估计；
(iii) **非操纵与真实性**：沟通必须是系统真实信念的充分统计量，不得为提升依从而选择性披露；信任只校准到可靠性，不最大化；所有沟通与权限决策可审计。

**定义 311（人的隐状态）** h_t = (w_t, s_t, τ_t, f_t, r_t, i_t, c_t) ∈ ℋ：工作负荷、情境意识、信任、疲劳、接管准备度/反应时、意图、胜任度。可观测代理 y^h_t（注视/瞳孔、心率变异性、控制输入熵、反应时、接管时延、主观量表）。U_h = H(h_t | y^h_{1:t}) 为**伙伴不确定性**：既非机器人世界的 aleatoric，也非可由提问消解的 epistemic；它是关于另一个主体的、只能观测/推断/协商的隐变量。

**定义 312（人状态观测器 HSU）** 后验 b_t(h) = p(h_t | y^h_{1:t}, context)；用 conformal 给出 w,s,τ,r 的区间，OOD 分数 o_h。HSU 输出只允许进入 α 与 g 的选择，**不得进入硬安全滤波**。若 o_h 超阈值 ⇒ 进入 U_h 保守模式（定义 323）。

**定义 313（带延迟的有限理性人策略）** 人命令 u^h_t ~ π_h(· | i_t, M^h_t, h_t)，其中 M^h_t 为人对机器人的心智模型；人有反应延迟 δ_h 与链路延迟 δ_c，机器人于 t+δ 收到 u^h_t（δ=δ_h+δ_c）。命令噪声/量化使预测分布 \hat p(u^h_{t+δ|t}) 有熵 U_lat。HSU 不知道 i_t 时，意图后验进入 U_h。

**定义 314（心智模型与可预测性）** 人预测机器人下一动作分布 q^h_t = M^h_t(·|o_t)；机器人实际策略 p^θ_t。D_MM(t)=D_KL(p^θ_t‖q^h_t)（或 Wasserstein）。Legibility(t)=1/(1+D_MM)。模式混淆 = 宣布模式 \hat m 与人推断模式 \tilde m 不一致的持续时间。D_MM 是 UX 的「理解误差」，与 R69 的模态熵不同：后者是机器人对世界的歧义，前者是人对机器人的歧义。

**定义 315（信任动力学与校准）** 客观可靠性 R_t 为窗口内任务成功/干预正确率；信任更新 τ_{t+1}=clip(τ_t+η(R_t−τ_t)+κ e_t+ξ_t)，e_t 为解释/结果信号。校准误差 E_τ=|τ_t−R_t|，过信任 O_τ=(τ_t−R_t)_+，欠信任 U_τ=(R_t−τ_t)_+。**目标是 E_τ ≤ ε_τ，而非 τ→1**；解释不得把 τ 推到 R+ε_τ 以上（非操纵约束，定义 322）。

**定义 316（情境意识、准备度与技能保持）** 
s_{t+1}=clip(s_t − λ_SA(1−α_t)Δt·1[无参与] + μ·info(g_t) − ν·overload(w_t))；
r_t=σ(κ_s s_t+κ_c c_t−κ_f f_t−δ_h)；
技能保持 S_t：在 α=0 连续 k 分钟后人的接管表现；无参与时 dS/dt ≤ 0，要求 S_t ≥ S_min。直观：**全自主不是免费的**——它把人从回路里移出，迟早要还这笔「准备度债」。

**定义 317（连续权威分配与人类主权）** α_t∈[0,1] 为人持有权限（α=1 全手动，α=0 全自主）。混合命令
u_t = Π_{𝒮_t}( α_t u^h_{t−δ} + (1−α_t) u^auto_t )，
其中 Π_{𝒮_t} 为 C-RAS-WM/CBF 认证集上的安全投影。HOV：人的显式 takeover/veto 在安全时直接接受；不安全时系统必须**警告并投影**，不得静默忽略；越权接管被记录并进入审计。权限不是开关，α 的轨迹本身是状态。

**定义 318（延迟感知权限与预测可信度）** 人命令预测 \hat u^h_{t+δ|t} 及其协方差；预测可信度 ρ_t=exp(−U_lat/τ_lat)·1[δ≤δ_max]。有效权限
α_eff,t = α_t·ρ_t·σ(κ_r(r_t−r_min))·1[o_h≤τ_o]，
即在人「接得住、预测得准、状态可观测」时才把权限交给人；否则平滑降低 α_eff 并提前宣告。安全包络用 lookahead H_δ=ceil(δ/Δt) 的前缀认证，保证延迟期间不变式不破。

**定义 319（UX 效用）**
J_ux = E[Σ_t γ^t (R_task,t − c_w w_t − c_s(1−s_t) − c_τ E_{τ,t} − c_m D_MM,t − c_f f_t − c_i intr(g_t))]。
硬约束：w_t≤w_max, s_t≥s_min, E_τ≤ε_τ, S_t≥S_min, 安全不变式。与 R69 的标量风险不同，J_ux 是**多目标**；它不是用来「讨好用户」，而是用来在同样安全的策略之间做选择。

**定义 320（表演性净 VoI / XIC）** 沟通/交互动作 g 的价值：
J(g)= VoI_robot(g) + β_s ΔSA(g) + β_τ Δ(−E_τ)(g) − β_w E[Δw(g)] − c_attn(g) + E[V(h_{t+1})−V(h_t)]，
其中 VoI_robot 为 R69 定义 298 的模态信息增益；h_{t+1}=T(h_t,g,α) 是**人状态转移**；V 为 UX 价值函数；c_attn 为注意力占用。选择 g*=argmax J(g) s.t. 安全、预算 B(h_t)（随 w_t 递减）、非操纵。若 J≤0：**不沟通**，走 R69 兜底。R69 的 MINT 是 h 冻结、β 全零、只含 ask 的特例。

**定义 321（沟通动作空间）** g=(g_ask, g_tell, g_preview, g_haptic, g_auth)：
- ask：向人提问/求证（消耗注意力，R69 已有）；
- tell：解释「为什么/是什么/多确定/下一步」（增加 SA，可能增加负荷）；
- preview：虚拟轨迹/幽灵预览（低负荷地增加可预测性）；
- haptic：共享控制触觉提示（低带宽、强时序）；
- auth：权限增减/接管宣告（改变 α）。
每个 g 有物理/社交成本；preview 不直接驱动执行器但仍需安全评估；auth 必须满足定义 324 的无突变协议。

**定义 322（非操纵解释）** 解释 e 可采纳 ⇔ (a) e 是系统真实后验的**充分统计量**：对决策相关不确定性 I(e; decision) ≥ (1−ε) I(b; decision)；(b) e 不条件于「期望的人反应」，即生成 e 的策略不得以 τ 的提升为目标；(c) e 不得把信任抬到 R_t+ε_τ 以上。操纵度 M(e)=E[τ_after−R]−E[τ_after−R | truthful]；要求 M(e)≤ε_m。简言之：**解释必须让人更懂，而不是让人更听话。**

**定义 323（准备度约束的权限优化 URA）** 在每个决策点解
α_t* = argmax_{α∈[0,1]} J_ux  s.t. 安全, w≤w_max, s≥s_min, r≥r_min, E_τ≤ε_τ, S≥S_min，
用 horizon H 的 MPC/约束 MDP；对人状态不确定性用 CVaR/鲁棒约束：以 1−δ_h 置信满足约束。若可行域为空 ⇒ 进入**安全退化包络**：α=α_safe（由硬安全与最小准备度决定），提高 λ，必要时安全停；绝不为了 UX 指标牺牲硬安全。

**定义 324（接管/交还协议与无突变）** α_t→α_{t+1} 需满足：(a) 控制连续 |u_{t+1}−u_t|≤ε_u（除紧急停机）；(b) 模式宣告至少提前 τ_announce；(c) 人接管需 r_t≥r_min 或显式确认；系统紧急接管可缩短宣告但必须事后解释；(d) 所有切换记录哈希进入证书。把 R68 定理 15 的提交/换装不变式扩展到「人的心智模型」这一侧：不仅要控制无跳变，**认知也不能无预警跳变**。

**定义 325（UX 证书 J_TANDEM）** J_TANDEM=(J_FLUID, hsu_calibration, U_h, trust_error, D_MM, workload, SA, skill_retention, authority_trace_hash, latency_stats, explanation_log_hash, nonmanipulation_score, tandem_ver)。Valid ⇔ Valid(J_FLUID) ∧ HSU 校准达标 ∧ E_τ≤ε_τ ∧ s≥s_min ∧ D_MM≤ε_mm ∧ 非操纵审计通过 ∧ 接管协议满足 ∧ 权限/沟通预算未越界。

**定义 326（UX 对抗集 ℰ_TANDEM）** ℰ_TANDEM = ℰ_FLUID × ℰ_ux；ℰ_ux 包含：人状态信号伪造（假注视/假 HRV）、告警洪泛/注意力劫持、习得性无助诱导、过度信任利用、模式混淆攻击、解释投毒、延迟注入/拒绝服务、语音社交工程。**新的攻击面不是「答案错」，而是「让人变成系统想要的状态」。**

**定义 327（参与式审计 VQAuditor-X）** 审计：是否在不必要时提问、解释是否真实且决策相关、是否尊重否决、是否维持 SA/技能、是否存在可避免的接管、信任校准是否改善、是否出现操纵性沟通。结论回灌成本先验与权限约束；高杠杆交互进入人工复核。

**定义 328（严格包含与边界）** 当 U_h=0（人状态完美已知）、δ=0、w/s/τ 恒定且无约束、α 固定不参与决策、只允许 ask 类动作时，TANDEM 逐指令退化为 FLUID；且由于 Π_𝒮 与 λ_floor 不依赖 h 估计，任何 HSU 错误只能影响性能/UX，不能削弱硬安全。故 R68⊆R69⊆R70，安全侧逐级不让步。

```python
# IP-264 HSU：人状态后验（校准 + OOD），只在线推断，不写参数
class HumanStateObserver:
    def update(self, y_h, ctx):
        b = self.posterior(y_h, ctx)          # w,s,tau,f,r,i,c
        return b, entropy(b), self.ood_score(y_h)

# IP-265 TCM：信任校准 + 心智模型散度（从行为/接管/解释后反馈估计）
def trust_update(tau, R, e, eta, kappa):
    return clip(tau + eta*(R - tau) + kappa*e, 0, 1)

def mental_model_divergence(q_h, p_theta):
    return kl(q_h, p_theta)                   # 或 Wasserstein

# IP-266 ANA：准备度约束的权限优化（CVaR 鲁棒）
def allocate_authority(b_h, U_h, lat, budget):
    # horizon-H 小规模约束优化；变量 (alpha, lambda)
    alpha = argmax_{a in [0,1]} J_ux_est(a, b_h, ...) \
            s.t. safety(a), w<=W_MAX, s>=S_MIN, r>=R_MIN, \
                 E_tau<=EPS_TAU, S>=S_MIN, CVaR_delta(U_h)
    if infeasible(b_h):
        return ALPHA_SAFE, LAMBDA_HIGH, "degrade"
    return alpha, lam_from(b_h), "ok"

# IP-267 LAC：延迟补偿 + 预测可信度
def delay_aware_command(u_h, u_auto, alpha, delta, pred):
    rho = exp(-pred.entropy / TAU_LAT) if delta <= DELTA_MAX else 0.0
    a_eff = alpha * rho * readiness_factor(pred.r)
    u = a_eff * pred.mean_u_h + (1 - a_eff) * u_auto
    return safety_project(u, lookahead=ceil(delta/DT))

# IP-268 XIC：表演性净 VoI（含人状态转移、非操纵过滤）
def choose_communication(modes, b_h, U_h, budget):
    best = None
    for g in [ASK, TELL, PREVIEW, HAPTIC, AUTH, SILENCE]:
        if not budget.allow(g, b_h.w): continue
        if not nonmanipulative(g, b_h): continue          # 定义 322
        if not safe_if_physical(g):     continue
        J = voi_robot(modes, g) \
            + BETA_S * delta_SA(g, b_h) \
            - BETA_TAU * delta_trust_error(g, b_h) \
            - BETA_W * expected_workload(g, b_h) \
            - c_attn(g) \
            + future_value(b_h, g)                        # T(h,g)
        if best is None or J > best.J: best = (g, J)
    return best if best and best.J > 0 else None          # 无利可图 → 不沟通

# IP-269 HOV：人类主权 / 否决 / 越权保护
def apply_human_override(u_h, u_safe, takeover):
    if takeover and is_safe(u_h): return u_h, "accepted"
    if takeover and not is_safe(u_h):
        warn("override unsafe: projected")
        return safety_project(u_h), "projected_warn"
    return u_safe, "nominal"

# IP-275 SRB：技能保持预算（周期性参与，不是永久接管）
def maintain_skill(alpha, b_h, timer):
    if (1-alpha) * timer > T_OOTL(b_h) or b_h.S < S_MIN:
        return engage("preview+micro-manual")   # 低负荷参与
    return None

# IP-273 主闭环（继承 R69；UX 层只改 α/g，不绕过硬安全）
def TANDEM_round(M, obs, u_h, takeover):
    z, o = M.mtm.forward(obs)
    b_h, U_h, ood = M.hsu.update(M.human_signals, obs)
    samples = M.fmp.sample(o, K=M.budget_K(o))

    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, obs, M.o_cal)
    slow = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 1) 先决定“说什么/问什么/何时宣告”，含沉默与预览
    g = (M.xic.choose_communication(modes, b_h, U_h, M.budget)
         if (U_epi > TAU_EPI and not slow and ood <= TAU_OOD) else None)
    if g is not None:
        M.xic.execute(g)                     # 可能更新 b_h（performative）
        if g.kind == ASK: U_epi = M.cia.update_belief(modes, M.cia.answer)
    # 2) 再决定“交多少权限”，用更新后的人状态
    alpha, lam, mode_auth = M.ana.allocate(b_h, U_h, M.latency, M.budget)
    if ood > TAU_OOD or U_h > TAU_UH or slow:
        alpha, lam = min(alpha, ALPHA_SAFE), max(lam, 0.8)   # 保守
    # 3) 延迟补偿 + 硬安全投影 + 人类主权
    u_safe = M.lac.delay_aware_command(u_h, M.autopilot(o), alpha, M.latency, b_h)
    u, ovr = M.hov.apply_human_override(u_h, u_safe, takeover)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(u, M.vista.H), ..., wm_preds)
    M.srb.maintain_skill(alpha, b_h, M.timer)
    M.vqa_x.submit_async(g, alpha, u, ovr, b_h, U_h, a_hat)
    return k, alpha, lam, u, (U_ale, U_epi, U_h)
```

## 3. 推导

**引理 19（表演性 VoI 的保守上界）** 设 R69 的朴素 VoI 为 V0(g)，忽略人状态转移；R70 的净值为 J(g)=V0(g)+E[V(h_{t+1})−V(h_t)]−c_attn。若沟通 g 使工作负荷上升 Δw>0，且 V 对 w 的 Lipschitz 常数为 L_w，则 J(g) ≤ V0(g) − L_w Δw − c_attn。因此当 L_w Δw + c_attn > V0(g) 时，R69 会问而 R70 不会；差距随「人越忙、问题越不重要」单调增大。系：**提问的价值不是信息量的函数，而是信息量减去「让人更忙」的函数。**

**引理 20（信任校准的可控性）** 在 A104（信任更新单调、有界）与 A108（解释真实性可审计）下，存在解释频率/内容策略使 E_τ ≤ ε 当且仅当 R_t 可观测且解释不条件于期望反应。若策略以提升 τ 为目标，则它必须减少决策相关信息的充分性，从而在审计中表现为 I(e;decision) 下降；故过信任与操纵可被联合检测（信任误差↑ ∧ 解释充分性↓）。系：**「让人更信任」与「让人更懂」在可审计意义下可分离。**

**引理 21（情境意识的脱岗时间）** 在 A105 下，α=0 且无参与时 s_t 以速率 λ_SA 衰减，接管准备度跌破 r_min 的时间 T_OOTL ≈ (s_0−s_min)/λ_SA。若 α 只在 [α_min, α_max] 内，则 T_OOTL 延长为 (s_0−s_min)/(λ_SA(1−α))。因此存在非空可行权限带 [α_min, α_max] 使 w≤w_max 且 s≥s_min 同时成立，当且仅当 λ_SA(1−α_max) < (s_0−s_min)/T_budget 且 α_min 足以抑制负荷。系：**「全自主最省事」是短视的；可行解是一个带，不是两个端点。**

**引理 22（延迟-权限折衷）** 设预测误差随 δ 以 e^{δ/τ_lat} 增长（A107），则有效权限 α_eff = α·e^{−δ/τ_lat}，跟踪误差上界随 α_eff 与 δ 增大。为保证延迟期间安全，需 lookahead H_δ=ceil(δ/Δt) 并满足 certified_prefix 的不变式；当 δ>δ_max 时 α_eff 必须降到 α_safe 以下（或安全停）。系：**延迟不是「慢一点」，而是对「谁在控制」的连续征税。**

**定理 18（TANDEM 严格包含 FLUID/R68）** 在 A102–A109 下，TANDEM 的硬安全由 Π_𝒮 与 λ_floor 保证，与 h 估计无关；当 U_h=0、δ=0、w/s/τ 恒定无约束、α 不参与、只含 ask 时，逐指令退化为 R69；当进一步 VoI≤成本时退化为 R68。故 R68⊆R69⊆R70，安全项不弱，UX 项只在可行域内改善。**安全侧不让步，体验侧才有资格谈优化。**

**定理 19（人在回路安全与无突变）** 在 A106、A109 下，任一 α∈[0,1] 经 Π_𝒮 投影后的命令满足硬安全不变式；HOV 保证显式否决在安全时被接受、不安全时被警告并投影；接管协议（定义 324）保证控制连续与认知宣告，故权限切换无控制跳变、无未宣告模式跳变；HSU 被攻击或 OOD 时 α 单调降向 α_safe、λ 单调升，退化为 R68 最保守。**人状态估计错了，最多体验变差，不会让安全包络失效。**

**定理 20（非操纵可审计性）** 在 A108 下，任何使 τ 超过 R+ε_τ 的解释必须牺牲决策相关充分性；VQAuditor-X 以 (E_τ, I(e;decision)) 联合检验，可在有限样本下以给定功效检出。故 J_TANDEM 有效 ⇒ 不出现系统性信任操纵；若检测到，证书失效并回退到「只告知不劝说」的基线。

**假设 A102–A109**：A102 人状态代理与隐状态有有界噪声相关；A103 人策略对 h 平滑、δ 有界；A104 信任更新单调有界；A105 SA 衰减/增益有界；A106 安全投影对任意混合命令保持认证集不变式；A107 延迟预测误差随 δ 指数增长；A108 解释真实性可由审计核验；A109 权限混合与切换连续。

## 6. 本轮最大风险

**一句话**：TANDEM-RAS 的全部 UX 收益押在「能从行为/生理信号里可靠估计人的负荷、信任、情境意识与准备度」这一前提上——而 HSU 是一个**把人本身当被控对象的闭环观测器**：一旦它估错，系统就可能以「为你好」的名义在操作员最清醒时夺权、在最需要练习时永久接管，或用选择性解释把信任推到可靠性之上；更糟的是这会自我实现——**系统判断人不行 → 接管 → 人真的不行 → 更有理由接管，最后把一个熟练操作员养成一个只会按「同意」的乘客**。这不只是性能风险，而是把共享控制异化为温柔的支配。

**次级风险与缓解**：
1. **HSU 误估/分布外**（跨操作员、疲劳、装具变化）→ conformal 区间 + OOD 检测 + CVaR 鲁棒约束 + HSU 错误只影响 α/g、绝不进入硬安全；
2. **信任操纵**（选择性披露、过度确认）→ 非操纵解释约束（定义 322）+ VQAuditor-X 联合检验 + 证书失效回退；
3. **技能退化/习得性无助** → SRB 技能保持预算 + 周期性低负荷参与 + E308/E316 长时程验证；
4. **延迟预测失败** → 延迟感知权限 + lookahead 前缀认证 + 预先宣告 + 必要时安全停；
5. **生理/行为数据隐私** → 端侧推断、最小化采集、明确同意、可删除；UX 不能以监控为代价；
6. **个性化过拟合** → 群体先验 + 有界在线适配 + 留一操作员泛化测试。

**定义 324（接管协议与无突变）** 控制连续、提前宣告、接管需准备度、紧急接管事后解释、切换哈希入证；控制与认知都不得无预警跳变。

**定义 325–327（证书、UX 对抗、审计）** J_TANDEM 并入 HSU 校准、U_h、信任误差、D_MM、SA、技能保持、权限/解释哈希、延迟统计；ℰ_ux 覆盖信号伪造/告警洪泛/习得性无助/解释投毒/延迟攻击；VQAuditor-X 审权限与沟通并回灌成本先验。

**定义 328（严格包含）** U_h=0、δ=0、w/s/τ 恒定无约束、α 不参与、仅 ask ⇒ 逐指令退化为 FLUID；λ_floor 与 Π_𝒮 不依赖 h ⇒ HSU 错误只影响体验，不削弱硬安全；R68⊆R69⊆R70。

```python
            + future_value(b_h, g)                 # T(h,g)
        if best is None or J > best.J: best = (g, J)
    return best if best and best.J > 0 else None   # 无利可图 → 不沟通
```

## 4. 推导

**引理 19（表演性 VoI 的保守上界）** 朴素 VoI V0(g) 忽略人状态转移；净值 J(g) ≤ V0(g) − L_wΔw − c_attn。当 L_wΔw+c_attn > V0(g) 时，R69 会问而 R70 不会；差距随「人越忙、问题越不重要」单调增大。系：**提问价值 = 信息量 − 让人更忙的代价。**

**引理 20（信任校准可控性）** 在信任更新单调有界、解释真实性可审计下，存在策略使 E_τ≤ε 当且仅当 R_t 可观测且解释不条件于期望反应；以提升 τ 为目标的策略必然降低决策相关充分性 I(e;decision)，故过信任与操纵可由 (E_τ↑, I(e;decision)↓) 联合检出。系：**「更信任」与「更懂」可分离。**

**引理 21（脱岗时间与可行权限带）** α=0 无参与时 T_OOTL≈(s_0−s_min)/λ_SA；一般 α 下为 (s_0−s_min)/(λ_SA(1−α))。存在非空 [α_min,α_max] 同时满足 w≤w_max 与 s≥s_min 的充要条件由衰减率与预算给出。系：**全自主最省事是短视的；可行解是带，不是端点。**

**引理 22（延迟-权限折衷）** 预测误差随 δ 以 e^{δ/τ_lat} 增长，则 α_eff=α·e^{−δ/τ_lat}，跟踪误差上界随 α_eff 与 δ 增大；须用 H_δ=ceil(δ/Δt) 的 lookahead 前缀认证，δ>δ_max 时降 α 或安全停。系：**延迟是对「谁在控制」的连续征税。**

**定理 18（TANDEM 严格包含 FLUID/R68）** A102–A109 下，硬安全由 Π_𝒮 与 λ_floor 保证、与 h 估计无关；U_h=0、δ=0、w/s/τ 恒定无约束、α 不参与、仅 ask 时逐指令退化为 R69；再令 VoI≤成本则退化为 R68。故 R68⊆R69⊆R70，安全侧不让步，体验侧仅在可行域内改善。

**定理 19（人在回路安全与无突变）** 任意 α∈[0,1] 经 Π_𝒮 投影后满足硬安全不变式；HOV 使安全否决被接受、不安全否决被警告并投影；接管协议保证控制连续与认知宣告；HSU 被攻击/OOD 时 α 单调降、λ 单调升，退化为 R68 最保守。**人状态估错，最多体验变差，不会让安全包络失效。**

**定理 20（非操纵可审计性）** 信任超过 R+ε_τ 必须牺牲解释的决策充分性；VQAuditor-X 以 (E_τ, I(e;decision)) 联合检验可在有限样本下检出。J_TANDEM 有效 ⇒ 无系统性信任操纵；否则证书失效并回退「只告知不劝说」。

## 7. 本轮最大风险

**一句话**：TANDEM-RAS 的全部 UX 收益押在「能从行为/生理信号可靠估计人的负荷、信任、情境意识与准备度」上——而 HSU 是一个**把人本身当被控对象的闭环观测器**：估错时系统可能以「为你好」的名义在最该让人练习时永久接管，或用选择性解释把信任推到可靠性之上；更糟的是这会自我实现——**系统判断人不行 → 接管 → 人真的不行 → 更有理由接管，最后把熟练操作员养成只会按「同意」的乘客**；这不是性能风险，而是把共享控制异化为温柔的支配。

**次级风险与缓解**：HSU 误估/分布外（conformal + OOD + CVaR，且 HSU 不进硬安全）；信任操纵（非操纵解释 + VQAuditor-X 联合检验 + 证书失效回退）；技能退化/习得性无助（SRB + 周期性参与 + E308/E316）；延迟预测失败（延迟感知权限 + lookahead 认证 + 预先宣告）；生理/行为数据隐私（端侧推断 + 最小化 + 同意 + 可删除）；个性化过拟合（群体先验 + 有界在线适配 + 留一泛化）。
