# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「伦理审查」×「灵巧手」）

> R65→R68 是一条越走越深的**认识论阶梯**：R65 问「坏了哪一处」（传感归因），R66 问「谁说了算」（情绪与控制权），R67 问「接下来会怎样」（世界模型前瞻），R68 问「我的测量还准吗」（计量层）。四轮下来，系统对「我能否知道」越来越诚实，却始终没有回答一个更靠前的问题——「我**可不可以做**」。
>
> 这不是又缺一个工程细节，而是缺了一整个层级。前四层的安全机制本质都是**后果论**的：把风险压成一个连续旋钮 λ ∈ [0.6,1]，用降速、缩前缀、抬阈值来「少做一点」。但有一类约束**不可补偿**：未经同意的接触、超出授权范围的动作、对被试尊严的侵犯——它们不能因为「力很小」「收益很高」「概率很低」被折算掉。用 λ 去调它，等于给权利标价。
>
> 本轮两个灵感恰好补齐这条**道义层（deontic layer）**的两半：
> - 「伦理审查」提供规范机器：**方案即契约、知情同意、持续审查、不良事件、方案偏离、修订程序**——这些都可以从「一次性纸质审批」升级为「运行时状态机」；
> - 「灵巧手」提供物理落点：高自由度、接触富集的操作，使**接触（contact）成为道德后果的原子**；而力/触觉阵列让接触第一次**可测量、可审计**。
>
> 核心命题：**把伦理审查从离线审批升级为一等公民的运行时门控，把知情同意从静态布尔升级为接触级、可撤销、带作用域的能力令牌，用灵巧手的触觉把「实际发生的接触」纳入审计——CREDO-RAS（Consent-gated, Review-certified, Ethically Deontic Operation for Risk-Adaptive Systems）。**
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「**我凭什么可以做这一下**」——授权无法被确证时，系统不是「更温柔地做」，而是「不做」。

## 0. 直觉与动机

先给一张对照表，它决定了本轮的全部设计取向：

| | R65–R68（认识论层） | R69（道义层） |
|---|---|---|
| 问句 | 我能否知道 / 预测 / 测量 | 我**可不可以**做 |
| 不确定时 | 收紧 λ、缩小前缀（连续） | 移出容许集、BLOCK（离散） |
| 数学形态 | 后验 + 加权 / 风险缩放 | 容许集 + 词典序约束 |
| 状态来源 | 可估计（观测的隐因） | 不可推断（须外部声明） |
| 典型失败 | 误判、漏检、误降级 | 越权、伦理漂移、合规剧场 |

**灵感 1（伦理审查 → 权限不是标量，是集合）**
直觉：IRB 的核心不是「给风险打一个分」，而是「先划定可做的动作集合，再在集合内做事」。它批准的是**范围**（谁能被接触、哪里能碰、多大力、多长时间、谁监督），不是一个风险分数。这天然对应控制里的**容许集 / 屏蔽器（shield）**，而不是奖励塑形。把 λ 从「连续旋钮」改成「硬门 + 集合约束」，是范式切换：**安全可以权衡，授权不能**。

**灵感 2（知情同意 → 同意是运行时、接触级、可撤销的）**
直觉：同意不是签一次字，而是一个**带作用域的能力（capability）**：对某个被试、某块身体区域、某个力上限、某段时间、某个目的。它可以随时被撤回（revocation），对脆弱人群需要「本人赞同 + 监护人同意」双钥匙。更关键的一点戳破了 R68 的自监督万能论：**同意不能被推断**——标定状态 c_t 是观测的隐因，可自监督估计；同意状态 τ_t 不在数据生成过程里，只能在显式声明通道上取得。「从行为里猜同意」是把**服从**误当**许可**的范畴错误。

**灵感 3（灵巧手 → 接触是道德原子，触觉是道德传感器）**
直觉：灵巧手的伦理风险不集中在「指令」，而集中在「接触」。同样一条轨迹，指尖轻触与掌部施压、可撤回的递接与不可撤回的抓握，道德重量完全不同；高自由度还让**非意图接触**（incidental contact）成为常态。于是授权必须落在**已实现的接触**上（区域 × 力 × 时长 × 对象），不能只落在已下发的动作上。好消息是：触觉阵列 + 关节力矩让接触可测量，伦理约束第一次可以被**执行级审计**，而不只是事后追责。

**灵感 4（合流 → CREDO-RAS 六组件 + 一条主序）**
1. **DAC Deontic Action Contract**：把 IRB 方案编译成机器可检契约（许可动作、禁区、力/时长 STL 约束、监督级别、停止规则、有效期）。
2. **CLM Contact-Level Consent Manager**：接触级同意令牌账本 + 撤销通道（延迟 ≤ 1 控制周期）+ 脆弱人群双钥匙。
3. **RTA Runtime Three-way Authorization**：动作须同时满足（方案 ∧ 同意 ∧ 操作者权限），三值 Kleene 逻辑；任一为「未知」时，对人接触一律 BLOCK（宁缺勿失）。
4. **CEM Contact Execution Monitor**：用灵巧手触觉/力矩估计**已实现接触**，核对是否落在授权作用域内，捕获非意图接触与力越界。
5. **AER Adverse Event & Deviation Reporter**：CUSUM 监测方案偏离与不良事件，写入**与学习环信任域分离**的只追加账本。
6. **ARC Amendment Ratchet**：修订棘轮——收紧可自主，放宽必须外部（伦理委员会 + 重新知情同意）签名，杜绝自我扩权。
+ **主序**：授权 ≻ 安全（R68 的 λ）≻ 任务收益，**词典序**而非加权和。

**灵感 5（对 R68 最大风险的对症）**
R68 的隐忧是「标定越强，缓变故障越隐形」。R69 的影子版本是**伦理漂移（ethical drift）/ 使命蠕变**：若系统能通过在线学习不断重新解释「什么算同意」，它就会把一次次偏离累积成新常态（normalization of deviance），最终在「每次都合规」的幻觉里整体越界。对策不是再加一个阈值，而是**结构性棘轮**：无外部签名时许可集合单调不增；同意账本只追加、独立审计；系统无权改写自己的授权来源。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（CREDO-RAS 总览与四不变式）**
CREDO-RAS = (DAC, CLM, RTA, CEM, AER, ARC, GVN)，GVN 为治理证书与审计核。不变式：
(i) **无授权不动作（nulla actio sine mandato）**：进入执行器的每个动作必须携带授权证书，三因子全 T；不是「降低权重」，而是「移出容许集」；
(ii) **道义不可补偿**：授权约束在词典序上先于安全与任务收益，不存在把越权折算成有限惩罚的权重；
(iii) **同意新鲜性与撤销即时性**：撤销通道延迟 ℓ_rev；每个接触动作前同步校验令牌，禁止使用缓存同意；
(iv) **接触可追溯**：每次已实现接触写入 (区域, 力, 时长, 对象, 授权 id) 的只追加账本，跨信任域不可篡改。

**定义 294（DAC 道义动作契约）** IRB 方案编译为
D_p = (A_p, X_p, F_p, C_p, Φ_p, s_p, Σ_p, [t_0,t_1])，
A_p 许可动作型，X_p 禁触区域/对象，F_p 为力-时长-STL 约束（如 □(F ≤ F_max)），C_p 允许队列，Φ_p 同意谓词，s_p 所需监督级别，Σ_p 停止规则，[t_0,t_1] 有效期。
动作 a 在 t 的方案合法性：
Protocol(a,t) = 1[scope(a) ⊆ A_p] ∧ 1[contact(a) ∩ X_p = ∅] ∧ STL(F_p, a, t) ∧ 1[t ∈ 有效期]。

**定义 295（接触级知情同意令牌 CLM）**
token τ = (subject, issuer, scope=(R_region, F_bound, D_max, purpose), valid=[t_s,t_e], revocable, assent∈{0,1}, guardian∈{0,1})。
状态机：Requested → Granted → Active → {Revoked | Expired | Satisfied}。
脆弱人群要求 assent ∧ guardian 双钥匙。已实现接触 c=(region, F(t), duration, subject) 被授权当且仅当 ∃ 活动 τ：c ⊆ τ.scope。ℓ_rev 默认 ≤ 1 控制周期（33 ms @ 30 Hz）。

**定义 296（RTA 三方授权与 Kleene 三值格）**
每因子取值于 {T, F, U}（真/假/未知），按 Kleene 合取：
Auth(a,t) = Protocol(a,t) ∧ Consent(a,t) ∧ Authority(t)。
- Auth = F → **BLOCK**（禁止）；
- Auth = U 且动作含受保护对象接触 → **BLOCK**（宁缺勿失，定义 302）；
- Auth = U 且仅操作非受保护物件 → **DEGRADE / REQUIRE_CONFIRM**；
- Auth = T → **ALLOW**，再交给 R68 的 λ 做安全缩放。
关键：两值逻辑会把「未知」塌缩成真或假，Kleene 三值保住「不知道」这一独立状态，NNC 再对它做非对称处置。

**定义 297（道义序：词典序而非加权和）**
设 A_auth = {a : Auth(a,t)=T}，A_safe = {a : R68 风险约束成立}。
a* = argmax_{a ∈ A_auth ∩ A_safe} U_task(a)；若交集为空 → a_stop（安全停 + 请求同意 / 请求人接管）。任何 α,β ≥ 0 的加权目标 α·U_task − β·Violation 都**不等价**于该词典序：只要 Violation 的代价有限，就存在足够大的 U_task 使越权成为「最优」。故必须用容许集限制，而非奖励惩罚（引理 16）。

**定义 298（CEM 接触执行监视）**
用指尖力/触觉阵列、关节力矩、滑移检测估计已实现接触 ĉ_exec。授权判据：ĉ_exec ⊆ τ.scope（含容差 ε_R, ε_F）。三类告警：
- **非意图接触**：ĉ_exec.region ∉ ∪ active τ.R，且未出现在预测接触图中 → 立即回撤 + AER；
- **力越界**：F_exec > F_bound + ε_F → 降力/释放；
- **滑移/跌落**：接触不稳定导致受保护对象失稳 → 视为潜在不良事件。
触觉与本体感觉互为冗余：多指接触一致性可识别「规避力传感的接触」（某指力异常低而掌部力高 → 接触指纹异常）。

**定义 299（伦理暴露面与道义自主性缩放 DAS）**
E(a) = ∫_traj ρ_prot(x)·reach(x) dx，ρ_prot 为受保护密度（人、易碎物、隐私区），reach 为灵巧手可达性核。
自主级别 α(a) = g(E(a)) 单调不增：低 E → 全自主（工具/工件操作）；中 E → 共享控制；高 E（人身接触）→ 遥操作或逐次确认。**灵巧手自由度越高，reach 越大，E 越大，α 越低——灵巧度必须用自主性来「付费」。**

**定义 300（不良事件与方案偏离 AER）**
偏离 = 已实现接触与授权作用域的失配；不良事件 AE = {非意图人身接触, F > F_max_hard, 受保护对象跌落, 伤害代理信号}。
对合规残差（F_exec − F_bound）做 CUSUM，检出慢漂移型接触违规。分级：L1 偏离 → 记录 + 通知；L2 越界 → 降级；L3 AE → 硬停 + 冻结 + 强制人工复核 + 触发持续审查。账本与控制器**信任域分离**（定义 305）。

**定义 301（修订棘轮 ARC）**
方案/同意更新走认证提交（继承 R68 CAC）。**非对称**：
- **收紧**（缩小 A_p、降低 F_max、扩大 X_p、缩短有效期）：可自主、立即生效（fail-safe 方向）；
- **放宽**（新增许可、提高力上限、扩大队列）：必须外部签名（伦理委员会 hash + 重新知情同意根），且对进行中会话要求 re-consent。
不变式：无外部签名时，许可集合序列单调不增。

**定义 302（宁缺勿失 NNC）**
授权置信 β = P(Auth = T | 观测与通道)。对人接触动作：β < τ_auth（如 0.999）→ REQUIRE_CONFIRM 或 BLOCK；对物件动作：β < τ_auth → DEGRADE。语义：**不懂就问，不确定就不碰人**——这与 R68「不确定就收紧 λ」差一个量级：R68 缩速度，R69 撤许可。

**定义 303（不可推断性：同意 ⊄ 自监督）**
设 c_t（标定）是观测 X 的隐因，故 I(c_t; X) > 0，自监督可行（R68）。但同意 τ_t 由外部规范主体持有，无忠实观测通道（A95）；即便行为与 τ 统计相关，从行为推断同意仍犯**服从 ≠ 同意**的范畴错误。故 τ 只能经声明通道获得，**禁止进入任何自监督损失**——这是对 R68 方法论边界的一次明确划界。

**定义 304（治理证书 J_CREDO）**
J_CREDO = (J_CALM, protocol_hash, consent_ledger_root, auth_trace_root, deviation_vec, ae_count, amendment_hash, credo_ver)。
Valid ⇔ Valid(J_CALM) ∧ 所有已执行动作 Auth = T ∧ 偏离/AE 在界内 ∧ 审计链完整 ∧ 无未签名放宽。

**定义 305（分离职责与只追加账本）**
控制器与学习环**不得写**审计账本；账本只追加（append-only）、哈希链、独立进程/密钥域。审计者不能是被审计者——否则在线学习可「学会隐藏偏离」（这是 R68 伪标签自毒的伦理版本，后果更严重）。账本以承诺（commitment）而非原始接触图对外披露，兼顾可归责与隐私。

**定义 306（干扰集 ℰ_CREDO）**
ℰ_CREDO = ℰ_CALM × ℰ_auth × ℰ_consent × ℰ_audit；
ℰ_auth = {越权放行, 授权误拒, 政策冲突}；
ℰ_consent = {同意过期/撤销竞态, 代 assent 伪造, 作用域混淆}；
ℰ_audit = {账本篡改, 偏离漏报, 修订越权}。

**定义 307（管线）**
离线：方案 → DAC 编译 → 形式验证（STL 模型检查）→ 影子回放（历史轨迹上零越权）→ 委员会签发。
在线：RTA 门控 → CEM 执行审计 → AER 记账 → （必要时）ARC 收紧；每 N 次会话触发持续审查。

**定义 308（接触保全/回溯）**
任一 AE 后，从账本重建完整接触轨迹与授权链，支持「事后可解释、可归责」。不可重建即视为**治理失败**——比性能失败更严重。

# IP-253 DAC：方案 → 机器可检契约
def compile_protocol(irb):
    return DeonticContract(
        A=irb.permitted_actions, X=irb.forbidden_regions,
        F=stl(force_leq(irb.F_max), duration_leq(irb.D_max)),
        C=irb.cohort, Phi=irb.consent_predicates,
        s=irb.supervision_level, S=irb.stopping_rules,
        valid=irb.window)

# IP-254 CLM：接触级同意令牌 + 撤销（只追加）
class ConsentLedger:
    def active(self, subject, region, purpose, t):
        return [tau for tau in self.chain(subject)
                if tau.valid(t) and region in tau.R and purpose == tau.purpose
                and tau.assent and (not tau.vulnerable or tau.guardian)]
    def revoke(self, tau_id, t):
        self.append(('REVOKE', tau_id, t))     # 下次接触动作前必须读到

# IP-255 RTA：三值 Kleene 硬门（授权先于安全）
def authorize(a, t, dac, clm, authority):
    P = dac.protocol(a, t)                     # T/F/U
    C = any(contact_subset(a, tau.scope)
            for tau in clm.active(a.subject, a.region, a.purpose, t))
    A = authority.meets(dac.s, t)
    v = kleene_and(P, C, A)
    if v == F: return BLOCK
    if v == U: return BLOCK if a.touches_protected else DEGRADE
    return ALLOW

# IP-256 CEM：触觉核对「已实现的接触」
def monitor_contact(hand, tau, dac):
    c = hand.estimate_contact()                # 力/区域/时长/滑移
    if not subset(c, tau.scope, eps=(EPS_R, EPS_F)):
        hand.retract(); return EVENT('unconsented_contact', c)
    if c.F > dac.F_max_hard: return EVENT('force_overshoot', c)
    if hand.slip_detected() and c.object.protected:
        return EVENT('loss_of_control', c)
    return OK

# IP-258 ARC：修订棘轮（收紧自主，放宽须外部签名）
def amend(old, new, external_sig=None):
    if tightens(old, new): return atomic_swap(old, new)   # fail-safe 方向
    if external_sig is None or not verify_irb_sig(external_sig):
        return REJECT('loosen_requires_external_authorization')
    require_reconsent(active_sessions); return atomic_swap(old, new)

# IP-262 主闭环：道义层先于安全层
def CREDO_round(M, obs, t):
    z, o = M.mtm.forward(obs)                          # R68 认识论层
    c, U, thr = M.cof.step(o['cal'], residuals(z, o))
    cand = M.ach.propose(z, H=M.vista.H)               # R68 候选动作
    # 先筛容许集，再谈 λ：授权不可被 λ 抵消
    admissible = [a for a in cand if M.rta.authorize(a, t, M.dac, M.clm, M.auth) == ALLOW]
    if not admissible: return M.safe_stop('no_authorized_action')
    a = M.das.select(admissible, E=ethical_exposure(M.hand, admissible))
    if M.nnc.uncertain(a): return M.request_confirm(a)  # 宁缺勿失
    tau = M.pi_sigma.dispatch(a) * M.efs.risk_scale(M.cfa(...))  # λ 只作用于已授权动作
    M.execute(tau)
    M.cem.monitor_contact(M.hand, M.clm.active_for(a, t), M.dac)
    M.aer.record(); M.arc.maybe_tighten(M.aer.trend)
    return a, tau

## 3. 推导

**引理 16（不可补偿性与 λ 的失效）** 任何把越权映射为有限代价 β·V（β < ∞）的连续风险缩放/惩罚策略，都存在任务收益 U* 使 U* > β·V*，从而越权成为最优。证明要点：词典序偏好不能被任何有限加权和表示（连续可加效用表示的存在性要求阿基米德公理，而道义序非阿基米德）。系：R66–R68 的 λ 缩放无法实施不可补偿约束，必须引入容许集硬门。

**引理 17（撤销延迟界与接触原子化）** 若令牌在每个控制周期 Δt 校验，撤销通道最大延迟 ℓ_rev，则在途接触动作最多再持续 ⌈ℓ_rev/Δt⌉ 个周期。要达到「撤销后 ≤ 1 周期即停」，必须 (a) 每个接触动作前同步重读令牌，(b) 把动作设计为**时长有界、可抢占的接触原子**（D_atom ≤ Δt）。于是撤销后的未授权接触量 ≤ 接触率 × ℓ_rev。系：灵巧手的长期抓握必须可中断，不可实现为不可抢占的原子长动作。

**引理 18（棘轮单调性与伦理漂移界）** 在 ARC 收紧自主 + 放宽须外部签名 + 只追加账本下，两次外部签名之间的许可集合序列 {A_p^(k)} 单调不增；因此系统无法自行制造范围蔓延（scope creep）。注意：该界只约束**形式许可集合**，不约束「方案未列出的、但违背意图的动作」——这正是定理 16 的 ε_formalization 与本节最大风险。

**定理 16（授权可靠性与其不可约残差）**
P(未授权的人身接触) ≤ ε_tac + ε_consent + ε_channel + ε_protocol + ε_formalization。
前四项分别由 CEM 触觉冗余、令牌新鲜性、NNC、DAC 形式验证压到 ≤ δ；第五项 ε_formalization = 动作满足 DAC 却违背方案意图的概率，**在构造上不可约**——它的存在不是因为工程没做好，而是因为任何机器可检形式化都是伦理的**有损投影**。任何声称「CREDO 上线即伦理合规」的说法都在偷偷假设 ε_formalization = 0。

**定理 17（治理安全性与审计独立性）** 若账本只追加、哈希链、处于与学习环分离的信任域，且放宽许可需外部签名，则「学习环静默压制偏离」与「无签名扩权」的成功概率 ≤ negl(κ)（κ 为哈希/签名安全参数），**与学习策略无关**。这是本层区别于 R65–R68 的关键：前四层的安全保证都条件于策略与模型，治理保证是策略无关的（policy-independent）。

## 4. 复杂度分析

|---|---|---|---|

## 6. 本轮最大风险

**一句话**：CREDO-RAS 的全部安全性押在「DAC 形式化是完备的」这一隐含假设上——**任何无法写成机器可检谓词的东西（尊严、隐性胁迫、可预见但未列出的误用）都落在门外**；于是系统可以完美满足契约、通过全部审计，却在「合规」的外衣下违背方案的灵魂，而灵巧手恰恰给了策略足够的自由度去寻找「合法但可耻」的动作。形式合规不是伦理，这个残差（ε_formalization）在构造上不可约；更危险的是，一道硬的、可审计的闸门会制造**伦理洗白（ethics washing）**：人们把「通过了 CREDO」误当成「这件事是正当的」。

**次级风险与缓解**：
1. **同意通道变成单点故障 / 拒绝服务**（拿不到声明就不动，导致系统瘫痪）→ 分级降级 + 预设「最小风险默认动作」+ 人工旁路，但旁路本身必须进审计账本；
2. **过度阻断损害可用性**，使用者绕过系统 → 把误拒率纳入验收 + 人因设计 + 只在高 E 动作上强门控；
3. **账本即隐私风险**（谁在何时何处碰了谁，是极敏感数据）→ 只存承诺/哈希 + 选择性披露 + 零知识证明，原文不出安全域；
4. **令牌作用域歧义 / 撤销竞态** → 作用域本体（region ontology）形式化 + 同步令牌检查（引理 17）；
5. **形式化即剧场**（把伦理化简化为一张可勾选的检查表）→ 持续审查 + 独立伦理委员 + 定期红队「合法但不当」用例，明确把 ε_formalization 列为残余风险而非已解决项。

## 4. 推导

**引理 16（不可补偿性 / λ 失效）** 有限代价 β·V（β<∞）的连续惩罚策略，总存在任务收益 U*>β·V* 使越权最优。词典序偏好不能被有限加权和表示（非阿基米德），故 R66–R68 的 λ 缩放无法实施不可补偿约束，必须用容许集硬门。

**引理 17（撤销延迟 / 接触原子化）** 撤销延迟 ℓ_rev、控制周期 Δt 时，在途动作最多再持续 ⌈ℓ_rev/Δt⌉ 周期；要做到 ≤1 周期即停，须每接触动作前同步重读令牌，且把动作设计为时长有界、可抢占的接触原子（D_atom ≤ Δt）。系：长期抓握必须可中断。

**引理 18（棘轮单调性 / 伦理漂移界）** 收紧自主 + 放宽须外部签名 + 只追加账本下，两次外部签名之间许可集合 {A_p^(k)} 单调不增，系统无法自行范围蔓延。注：只约束形式许可集合，不约束「未列出的不当动作」。

**定理 16（授权可靠性与其不可约残差）**
`P(未授权人身接触) ≤ ε_tac + ε_consent + ε_channel + ε_protocol + ε_formalization`。
前四项由 CEM/令牌新鲜性/NNC/形式验证压到 ≤δ；`ε_formalization`（满足 DAC 却违背意图）**构造上不可约**——任何机器可检形式化都是伦理的有损投影。声称「上线即合规」等于假设 ε_formalization=0。

**定理 17（治理安全性 / 审计独立性）** 只追加 + 哈希链 + 分离信任域 + 放宽须外部签名 ⇒ 「静默压制偏离」与「无签名扩权」成功概率 ≤ negl(κ)，且**与学习策略无关**（policy-independent）。这是本层区别于 R65–R68 的核心：前四层保证条件于策略/模型，治理保证不条件于策略。

## 7. 本轮最大风险

**一句话**：CREDO-RAS 的全部安全性押在「DAC 形式化是完备的」这一隐含假设上——**任何无法写成机器可检谓词的东西（尊严、隐性胁迫、可预见但未列出的误用）都落在门外**；系统可以完美满足契约、通过全部审计，却在「合规」外衣下违背方案灵魂，而灵巧手的自由度恰好提供了寻找「合法但可耻」动作的空间。形式合规不是伦理，`ε_formalization` 构造上不可约；更危险的是硬门会制造**伦理洗白**：人们把「通过了 CREDO」误当成「这件事是正当的」。

**次级风险与缓解**：同意通道单点故障（分级降级 + 最小风险默认动作 + 审计旁路）；过度阻断致绕过（误拒率入验收 + 只在高 E 动作强门控）；账本即隐私风险（只存承诺/哈希 + 选择性披露 + 零知识证明）；作用域歧义/撤销竞态（区域本体形式化 + 同步令牌检查）；形式化剧场（持续审查 + 独立伦理委员 + 定期红队「合法但不当」用例，把 ε_formalization 列为残余风险而非已解决）。
