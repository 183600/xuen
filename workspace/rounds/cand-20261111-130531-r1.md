# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「联邦学习」×「轨迹优化」×「技能组合」）

> 第 54 轮把技能组合从“能力匹配”提升为“动作-鲁棒性双证书”（α_S, G_S, γ_ce, J）。但它仍是**静态、单主体、离散**的：技能之间怎么连续连过去、动力学是否允许、多个异质边端如何共同背书，都未回答。本轮补上三个缺失维度：**时间/动力学（轨迹优化）**、**多主体/异质证据（联邦学习）**、**连续实现（轨迹原语聚合）**。核心矛盾：H22：动作集合相容不代表存在满足动力学约束与鲁棒管的连续可行轨迹（静态相容 ≠ 轨迹可行）；H23：多边端局部剖面/谱异质（非 IID），全局聚合证书可能掩盖局部失败（聚合悖论）。

## 0. 直觉与动机

**灵感 1（轨迹优化 → 从离散技能序列到连续可行轨迹）**
直觉：第 54 轮的 G_S 只给出一串技能节点 `S_1→…→S_k`，但两个技能之间“怎么连过去”是空的。轨迹优化（直接配点 / 打靶 / SCP / 管 MPC）正是补齐这段：给定技能序列，求解 `ξ(t)=(x(t),u(t))`，满足动力学 `ẋ=f(x,u)`、拼接连续性、碰撞与能量约束，并给出**鲁棒管** `{x: ||x-ξ_nom||≤η}`。组合可行性的第一性条件从 `compat(A_i,A_j)≥θ_a` 升级为 **存在可行轨迹 + 管可行**。

**灵感 2（联邦学习 → 证书的多主体分布式生成，不共享原始数据）**
直觉：现实中 N 个边端各有自己的技能库、仿真器、数据分布 `D_i`（非 IID）。把原始轨迹/数据集中到云端既不现实也侵犯隐私。联邦学习提供范式：**边端本地优化轨迹，只上传低维轨迹原语（路点 / B 样条控制点 / 时间参数）与局部证书，云端做安全/鲁棒聚合**。证书因此变成“联邦证书”：由多个互不信任的主体各自背书。

**灵感 3（联邦轨迹优化 → 本地 TO + 共识/ADMM + 压缩通信）**
直觉：把轨迹优化按边端分解，用 ADMM/一致性约束在共享边界状态上达成共识；每轮只传压缩后的原语而非整条轨迹。压缩误差 `ε_comp` 不是免费的，必须**传播进鲁棒管半径** `η_eff = η + ε_comp`，否则“通信省下的带宽”会以“管变大、裕度消失”的方式还回来。

**灵感 4（局部-全局证书对偶 → 防聚合悖论）**
直觉：`FedAvg` 式聚合会让全局 `ρ̄` 看起来很漂亮，但某个边端可能已经局部失败（类似辛普森悖论/聚合悖论）。因此全局证书必须**托管（escrow）每一份局部证书**并保留**逐边否决权**：`C_global` 成立 ⇏ `C_i` 成立，反之亦然，双向都要验。异质性 `δ_fed = Σ w_i d(α_i, ᾱ)` 必须是**测出来的**，不能假设。

**灵感 5（对抗与隐私 → 拜占庭鲁棒 + 差分隐私会计）**
直觉：联邦里总有恶意/故障边端投毒轨迹原语。用 Krum/截尾均值聚合，并把 DP 噪声显式会计进证书（噪声吃掉的鲁棒裕度 `Δ_DP` 必须从 `ρ_min` 里扣）。这延续第 53 轮“鲁棒性可解释”的主线：任何聚合操作对证书的影响都要可追溯、可审计。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（轨迹提升）**
技能序列 `S_1..S_k` 的轨迹提升 `Λ(⟨S_i⟩)` 给出 `ξ:[0,T]→X×U`，满足 `ξ(t)∈supp(α_{S(t)})`（动作剖面一致性）、分段动力学 `ẋ=f(x,u)`、拼接处 `C¹` 连续性。称序列**轨迹可行**当且仅当 `Λ` 的可行集非空。

**定义 122（鲁棒管与管证书）**
名义轨迹 `ξ_nom` 的鲁棒管 `𝒯(ξ_nom,η) = {x(t): ||x(t)-ξ_nom(t)|| ≤ η(t)}`。管半径传播 `η_{t+1} = γ·η_t + w_t`，`γ` 为动力学收缩因子。轨迹证书 `T_cert = (ξ_nom, η, ρ_tube, 𝒞)`，其中 `ρ_tube = inf_{x∈𝒯} ρ(x)`，`𝒞` 为约束裕度。`T_cert` 有效 iff `𝒯 ⊆ 可行域` 且 `ρ_tube(d)≥ρ_min ∀d`。

**定义 123（联邦技能聚合与异质性）**
N 边端，本地剖面 `α_i`、本地谱 `ρ_i`、本地数据分布 `D_i`。聚合 `ᾱ = Σ_i w_i α_i`，`ρ̄ = FedAgg({ρ_i})`。异质性度量
`δ_fed = Σ_i w_i · W_1(α_i, ᾱ)`（1-Wasserstein），`D_i` 非 IID 时 `δ_fed>0`。

**定义 124（局部-全局证书对偶）**
全局证书 `C_G` 定义在 `∪_i dom_i`，局部证书 `C_i` 定义在 `dom_i`。称证书体系**可分解** iff
`C_G ⟺ (∀i, C_i) ∧ δ_fed ≤ Δ_fed ∧ E_priv ≤ E_max`。
若 `C_G` 成立而某 `C_i` 失败，称发生**聚合悖论**，必须由托管机制检出。

**定义 125（联邦轨迹优化问题 FTO）**
```
min_{ξ_1..ξ_N, z}  Σ_i [cost_i(ξ_i) + w_ρ·pen(ρ_i) + w_c·||prim(ξ_i)-z||²]
s.t.  ξ_i 满足本地动力学/约束； z = 共识原语； Σ_i comm(prim(ξ_i)) ≤ B;
      ρ_i(d) ≥ ρ_min ∀d;  δ_fed ≤ Δ_fed
```
其中 `prim(·)` 为低维原语压缩，`B` 为总通信预算。

**定义 126（联邦轨迹证书）**
`FT_cert = (z, {T_cert_i}, {C_i^escrow}, η_eff, δ_fed, ε_comp, β_byz, Δ_DP)`：
- `z` 聚合轨迹原语；
- `T_cert_i` 各边端管证书；
- `C_i^escrow` 局部证书托管；
- `η_eff = η + ε_comp` 压缩后管半径；
- `δ_fed` 异质性；`ε_comp` 压缩误差；`β_byz` 拜占庭比例；`Δ_DP` 隐私噪声吃掉的裕度。
可部署 iff `η_eff ≤ η_max`、`δ_fed ≤ Δ_fed`、`β_byz < 1/3` 且 `Δ_DP` 已从裕度扣除。

## 2. 关键算法 伪代码

### IP-121 TOC（Trajectory-Optimized Composition）

```python
def trajectory_compose(skill_seq, dynamics, x0, constraints):
    segs = [local_traj_opt(s, dynamics, constraints) for s in skill_seq]
    xi = stitch(segs, order=1)                      # C1 拼接
    eta = forward_tube(x0.std, dynamics, xi)        # eta_{t+1}=gamma*eta_t + w_t
    if not tube_feasible(xi, eta, constraints):
        return ('reject', 'tube_infeasible', argmin_margin(xi, eta))
    rho_tube = inf_robustness_tube(xi, eta)
    if min(rho_tube.values()) < RHO_MIN:
        return ('reject', 'tube_robustness_fail', rho_tube)
    return ('ok', T_cert(xi, eta, rho_tube))
```

### IP-122 FPA（Federated Profile Aggregation，FedProx 式）

```python
def federated_profile_aggregate(local_alpha, weights, mu):
    alpha_bar = {a: sum(w*local_alpha[i].get(a,0) for i,w in enumerate(weights))
                 for a in union_keys(local_alpha)}
    delta_fed = sum(w * wasserstein1(local_alpha[i], alpha_bar)
                    for i,w in enumerate(weights))
    if delta_fed > DELTA_FED:
        return ('reject', 'heterogeneity_exceeded', delta_fed)
    return ('ok', alpha_bar, delta_fed)
```

### IP-123 FLT（Federated Trajectory Optimization，ADMM + 压缩）

```python
def federated_trajectory_opt(edges, task, rounds, comm_budget):
    z = init_consensus(task)
    for k in range(rounds):
        locals_ = []
        for e in edges:
            xi_e = local_traj_opt(e, task, z, prox=e.mu)      # 本地 TO + FedProx
            p_e  = compress(xi_e, budget=comm_budget // len(edges))
            c_e  = local_trajectory_cert(xi_e, e.constraints)
            locals_.append((p_e, c_e, xi_e))
        z = byzantine_robust_mean([p for p,_,_ in locals_], n_byz=BETA_BYZ)
        z = dual_update(z, locals_)
    eps_comp = max(recon_error(p, decompress(p)) for p,_,_ in locals_)
    return z, eps_comp, [c for _,c,_ in locals_]
```

### IP-124 LGC（Local-Global Certificate Duality）

```python
def local_global_dual(C_global, C_locals, delta_fed):
    if not C_global.valid:
        return ('reject', 'global_invalid')
    if not all(c.escrow is not None for c in C_locals):
        return ('reject', 'missing_escrow')            # 无托管不准信全局
    bad = [i for i,c in enumerate(C_locals) if not c.valid]
    if bad:
        return ('reject', 'aggregation_paradox', bad)  # 全局过、局部败
    if delta_fed > DELTA_FED:
        return ('reject', 'heterogeneity_exceeded', delta_fed)
    return ('ok', DualityCert(C_global, C_locals, delta_fed))
```

### IP-125 TTC（Tube Trajectory Certificate）

```python
def tube_certificate(xi_nom, eta, rho_tube, constraints, rho_min):
    for t in time_grid:
        if margin(xi_nom[t], constraints) < eta[t]:
            return ('reject', 'tube_hits_boundary', t)
    if min(rho_tube.values()) < rho_min:
        return ('reject', 'tube_robustness_fail')
    return ('ok', T_cert(xi_nom, eta, rho_tube))
```

### IP-126 BRA（Byzantine-Robust Aggregation + DP 会计）

```python
def byzantine_robust_aggregate(updates, f_byz, eps_dp, rho_min):
    n = len(updates)
    f = min(f_byz, (n - 1) // 3)
    keep = trimmed_mean(updates, trim=f)               # 或 Krum
    sens = l2_bound(keep)
    noise = laplace(scale=sens / eps_dp)
    agg = keep + noise
    delta_dp = robustness_erosion(noise, rho_min)      # 噪声吃掉的安全裕度
    return agg, delta_dp
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TOC | O(k·T·n_iter) | O(T·|X|) | SCP 收敛、管收缩 γ<1 |
| FPA | O(N·|A|) | O(N·|A|) | 异质性可测、FedProx 收敛 |
| FLT | O(R·(N·T_local + N·|prim|)) | O(N·|prim|) | ADMM 收敛、压缩误差可传播 |
| LGC | O(N) | O(N) | 托管完整、双向对偶 |
| TTC | O(T·|𝔇_ρ|) | O(T) | 管内约束枚举 sound |
| BRA | O(N²)（Krum）/ O(N log N) | O(N) | β_byz<1/3、DP 会计闭合 |

**正确性定理（Federated Trajectory Composition Soundness）**
承接第 54 轮 (A22)–(A28)。新增假设：
- **(A29)** 动力学 `f` 局部 Lipschitz，管收缩因子 `γ<1`，故 `η_t` 有界并收敛；
- **(A30)** 异质性 `δ_fed ≤ Δ_fed` 在留出边端上**实测**（而非假设）；
- **(A31)** 压缩误差 `ε_comp` 有界，且已并入 `η_eff=η+ε_comp`；
- **(A32)** 拜占庭比例 `β_byz<1/3`，DP 噪声裕度 `Δ_DP` 已扣除。

则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
            - P(δ_fed>Δ_fed) - P(η_eff>η_max) - β_byz - Δ_DP
```
每一项对应一个可独立监控的失败模式，延续“鲁棒性可解释、证书可审计”的主线。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 轨迹管有效性 | 管内约束违反率 / 预测 vs 实测 η | 违反率 ≤ 1%，η 误差 ≤ 10% |
| E163 联邦 vs 集中 | Δρ 随 δ_fed 的退化曲线 | δ_fed≤Δ_fed 时退化 ≤ 5% |
| E164 聚合悖论检出 | 局部失败召回率 / 误报率 | 召回 ≥ 95%，误报 ≤ 3% |
| E165 压缩-证书退化 | ε_comp 对 η_eff 的增长 | 单调有界，≤ 预算 |
| E166 拜占庭鲁棒 | β_byz<1/3 下证书有效率 | ≥ 90% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 轨迹管传播发散（γ≥1） | 高 | 收缩性验证 + 保守管初始化 + 分段重规划 |
| 异质性 δ_fed 被低估 | 高 | 留出边端实测 + DRO + 局部证书托管 |
| 聚合悖论掩盖局部失败 | 高 | 逐边否决权 + escrow + 悖论检测器 |
| 压缩原语丢失鲁棒信息 | 中 | 误差传播上界 + 自适应带宽 |
| 拜占庭/投毒 | 中 | Krum/截尾均值 + 质押/信誉 |
| DP 噪声侵蚀鲁棒裕度 | 中 | 噪声会计入 tube + 隐私预算上限 |

## 6. 本轮最大风险

**一句话**：联邦轨迹组合把静态动作证书推进为“连续轨迹管 + 多主体联邦证书”，但其 soundness 同时押注 **动力学管收缩 γ<1、异质性 δ_fed 的实测上界、以及压缩/拜占庭/DP 三种损耗的显式会计**；一旦管在耦合动力学下发散、或全局聚合把某个边端的局部失败平均掉（聚合悖论），系统就会拿着“漂亮的全局证书”在真实边端撞上不可行轨迹，故必须以 **收缩性验证 + 留出边端异质性实测 + 逐边托管否决** 三重护栏，宁可拒绝联邦共识，也不接受掩盖局部失败的全局证书。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（TOC×FPA×FLT×LGC×TTC×BRA）

> 承接第 54 轮产物 v31。本轮在“动作-鲁棒性双证书”体系之上，增加 **轨迹可行化、联邦证书聚合、局部-全局对偶、拜占庭/隐私会计** 四大算子：
> - **TOC（Trajectory-Optimized Composition）**：技能序列 → 连续鲁棒轨迹 + 管证书；
> - **FPA（Federated Profile Aggregation）**：非 IID 边端动作剖面的联邦聚合与异质性度量；
> - **FLT（Federated Trajectory Optimization）**：ADMM/共识式联邦轨迹优化 + 压缩原语；
> - **LGC（Local-Global Certificate Duality）**：局部-全局证书对偶 + 聚合悖论检测；
> - **TTC（Tube Trajectory Certificate）**：鲁棒管轨迹证书；
> - **BRA（Byzantine-Robust Aggregation）**：拜占庭鲁棒聚合 + DP 会计。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入轨迹与联邦维度。

```python
    return ('ok', DualityCert(C_global, C_locals, delta_fed))
```

### IP-126 BRA

```python
def byzantine_robust_aggregate(updates, f_byz, eps_dp, rho_min):
    n = len(updates)
    f = min(f_byz, (n - 1) // 3)
    keep = trimmed_mean(updates, trim=f)               # 或 Krum
    sens = l2_bound(keep)
    noise = laplace(scale=sens / eps_dp)
    agg = keep + noise
    delta_dp = robustness_erosion(noise, rho_min)
    return agg, delta_dp
```

## 5. 本轮最大风险

**一句话**：联邦轨迹组合把静态动作证书推进为“连续轨迹管 + 多主体联邦证书”，但其 soundness 同时押注 **动力学管收缩 γ<1、异质性 δ_fed 的实测上界、以及压缩/拜占庭/DP 三种损耗的显式会计**；一旦管在耦合动力学下发散、或全局聚合把某个边端的局部失败平均掉（聚合悖论），系统就会拿着“漂亮的全局证书”在真实边端撞上不可行轨迹，故必须以 **收缩性验证 + 留出边端异质性实测 + 逐边托管否决** 三重护栏，宁可拒绝联邦共识，也不接受掩盖局部失败的全局证书。
