# 第 58 轮（承接第 57 轮「MFSL×XMC×PTM」IP-133~138；灵感循环第 1 轮；本轮灵感：「虚拟仿真」×「ROS」）

> 第 57 轮把安全赌注押在"少样本可校准、跨模态可对账、个性化有界的证据承诺"上，并用共形保底、EV-xmodal 限 L1、授权单向有界三重护栏兜底。但它仍默认了两个更底层的承重假设：**(a) 证据来自一个同步、同源、真实的世界快照**——XMC 把"不同模态"当成"独立证据"，MFSL 把"当前观测"当成"来自真实分布的样本"；**(b) 对先验的质疑只能靠真机探针**——每区域 k≤5，语料盲区无法在部署前被主动触碰，于是坏先验只能等坏结果来揭发，代价往往是不可逆接触。本轮两个灵感精确命中这两个缺口：**虚拟仿真**提供一种"先于真机、但不许替真机下结论"的**反事实实验设计**能力——仿真不认证先验，只用最坏情形假设去**设计那一次最能揭穿先验的真机探针**；**ROS** 提供证据的真实运行时刻画——证据不是快照，而是沿 topic/TF/rosbag/clock 域流动的消息谱系，**"独立"必须由因果祖先分叉来证明，而不能由"来自不同传感器"默认**。二者在 `use_sim_time` 与 rosbag 回放处正面相撞：仿真证据可以伪装成实时证据。于是本轮把证据门的前提从"证据说了什么"升级为 **"证据从哪来、何时来、其祖先是否分叉"**，核心命题升级为 **"先验可反证、独立有族谱、时基不冒充的证据说可信"**。

核心矛盾：
- **H29（仿真自证）**：仿真器与元先验共享同一套物理建模假设（同一接触模型、同一摩擦锥、同一执行器模型）。用仿真"补语料盲区"，等于让先验出题、先验阅卷；仿真报通过只证明"在该仿真器的世界观里没找到反例"，它无法证明真实世界没反例，却能显著抬高置信。更糟的是乐观偏差是**单侧**的：仿真低估风险才危险，而单侧误差无法被对称的误差棒吸收。
- **H30（伪独立）**：ROS 的发布订阅让不同 topic 看起来彼此独立，但共享订阅者、共享 TF 树、共享上游检测器、共享 rosbag、共享仿真实例都会制造**隐藏共同祖先**。此时"视觉与触觉一致"可能只是"同一个旧快照被回声了两次"；把模态数当独立证据数，等于把第 57 轮的"同一模态问五遍"升级成"同一祖先问五遍"。
- **H31（时基冒充）**：`use_sim_time`、rosbag 回放、节点时钟漂移与重传，使**仿真时间与真实时间在消息层面不可区分**。一条被回放的旧消息既"新鲜"（时间戳新）又"一致"（与同批回放的其他模态一致），恰好同时满足第 57 轮的新鲜度直觉与跨模态一致判据——攻击者不需要伪造物理，只需伪造时间。
- **H32（反事实代价）**：仿真越便宜，越容易用同一先验生成"我早就知道"的反事实：搜索空间由先验设定，危险假设被先验的盲区剪掉，反事实实验于是**空转**——跑了很多，只证伪了先验本来就相信的东西。反事实的独立性（仿真器族、危险假设族、真实双胞胎锚点）和真机探针预算一样，是需要显式记账的稀缺资源。

## 0. 直觉与动机

**灵感 1（虚拟仿真 → 仿真只设计实验，不签发结论）**
直觉：仿真最危险的角色是"法官"，最安全的角色是"实验设计师"。一个先验说自己"很确信这里安全"，我们不该问仿真"这里安全吗"（它和先验同源），而该问仿真："**如果这个世界是危险的，哪一种观测最能当场揭穿这个先验？**"——在仿真里枚举危险的物理参数（低摩擦、隐藏空腔、软支撑、刚度突变），合成对应的观测序列，看元先验在这些观测下会不会仍然自信、会不会自信地错；然后把这套观测翻译成一次**真实、可逆、非破坏**的探针。仿真产出的是"该做哪个实验"，不是"实验的答案"；答案必须由真机给出。

**灵感 2（虚拟仿真 → 多仿真器分歧即认识论下界）**
直觉：单个仿真器的盲区就是先验的盲区。用多个**接触/摩擦/传感模型不同**的仿真器做同一反事实：若它们对"什么是危险"意见一致，至少说明这个危险假设不是某个引擎的私货；若它们分歧很大，则区域被标为 **sim-ambiguous**，其信念强制加宽、仿真建议只按最坏仿真器采用。**分歧不降低不确定性，只提高或维持它**——这与第 57 轮"跨模态分歧即不确定性下限"同构，只是把"模态"换成了"世界模型"。多仿真器一致仍**不构成认证**（它们可能共享同一篇论文的错误），但它能防止单个引擎把探针预算带进自己的盲区。

**灵感 3（ROS → 证据有族谱，独立要验祖先）**
直觉：在 ROS 里，"证据来自哪个传感器"是消息的**元数据**，"证据是不是独立"却是消息的**因果历史**。给每条证据挂来源谱系（源节点、topic、header.stamp、clock 域、父消息、QoS、签名、启动代际），把一次任务的所有证据拼成 DAG。两条证据只有在**因果祖先在观测事件之前分叉**时才算独立；共享上游检测器/回放缓冲/TF 源的一律折算为一条。有效独立度不是"模态数"，而是**谱系重叠折扣后的参与比** `n_C`。这样 EV-xmodal 就不再是"视觉+触觉=2"，而是"两个真正分叉的观测链=2"。

**灵感 4（ROS → 时基必须被外部证明，不能自报）**
直觉：安全系统里最不可信的字段就是消息自己声明的"我现在是真实时间"。时基证明必须来自**准入监视器**：进程身份、launch 配置、硬件单调计数器和启动代际共同证明一条消息属于 `real` 还是 `sim/bag`；`use_sim_time` 节点的任何输出自动降级为 `sim`，只能进沙箱。承诺链只接受 `real` 且墙钟年龄 ≤τ_fresh 的证据。回放/洗白检测用内容哈希 + 单调序号：同一 payload 以新 stamp 重现，判为 `launder` 并隔离——**旧内容换个时间戳，仍然是旧内容**。

**灵感 5（合流 → 证据门七类、PCX++ 与"双隔离"）**
直觉：第 57 轮证据门五类在本轮各获一个来源维度：`EV-probe*` 增加"真实时钟 + 谱系完整"、`EV-xmodal` 增加"因果独立 + 时钟同步"、`EV-human` 增加"来源真实"、新增 **`EV-sim⁻`**（纯负向反证信号，只可拒否或触发探针，永不计正证据）。不可逆接触必要证据集仍只认 `{EV-probe*∨EV-margin}∪人工佐证`，且全部 `att=real`；`EV-xmodal` 与 `EV-sim⁻` 一律不得进入。第 57 轮"一切判定器（含元模型）走隔离"推广为"**仿真证据走沙箱、回放证据走隔离、时基走外部证明**"的双隔离。安全纵深从五层到七层：元先验错 ∧ OOD 漏检 ∧ 模态共谋 ∧ 谱系伪独立 ∧ 时基冒充 ∧ 仿真自证 ∧ 无裕度/人也错。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（反事实实验设计 CFX）** 仿真器族 `𝓢={S_1,…,S_L}`，`S_l` 给出预测 `p_l(o|θ,r)` 与风险 `R_l(θ,r)`；危险假设集 `Θ_d(r)={θ:∃l, R_l(θ,r)>δ_f}`（对仿真器族取悲观并）。对候选真机探针 `a∈A(r)`，定义最坏情形信息增益
`IG_robust(a)=min_l E_{o∼p_l(·|θ*,r)}[H(q_φ(θ|o_{1:k}))−H(q_φ(θ|o_{1:k},o))]`，`θ*` 在 `Θ_d(r)` 内对抗选取；`a*=argmax_a IG_robust(a)`。三条硬约束：**(F1)** 仿真只产出待检验假设与探针建议，永不产出承诺证据；**(F2)** 若仿真器分歧 `D_S(r)=max_{l≠l'}TV(p_l,p_{l'})>θ_S`，则区域标 `sim-ambiguous`，`a*` 只按 `min_l` 选且信念强制加宽；**(F3)** 反事实预算 `k_cf` 与真机探针预算 `k_probes` 独立记账，仿真省下的探针只能折成"更少盲区"，不得折成"更多承诺"。

**定义 140（ROS 因果谱系 CGP）** 证据 `e=(id,src,topic,header.stamp,clock_domain,pa(e),qos,sig,gen)`，父边构成 DAG `𝒢_E`；`Anc(e)` 为祖先集，`I` 为基础设施祖先（时钟、静态 TF、日志）；`CA(e_i,e_j)=(Anc(e_i)∩Anc(e_j))∖I`。因果独立 `Ind_C(e_i,e_j)⇔CA(e_i,e_j)=∅`；谱系重叠 `κ_ij=|CA|/|Anc_i∪Anc_j∖I|`（`κ_ii=1`）；有效独立度 `n_C(E)=(Σ_i w_i)²/Σ_{ij}w_iw_jκ_ij∈[1,|E|]`。谱系不完整时 `κ` 取**保守下界**（把可能共因计入），隐藏共因质量上界记为 `δ_anc`。`Ind_C` 只是 EV-xmodal 的**必要非充分**条件，还须 `D(r)≤θ_D`、同为真实时钟域、`|t_i−t_j|≤τ_sync`。

**定义 141（时基证明 TBA）** 时钟域 `dom(e)∈{sys,ros,sim,bag,unknown}`，来源**不可自报**，由准入监视器依进程身份、launch 配置、硬件单调计数器与启动代际外部证明为 `att(e)∈{real,sim,bag,unknown}`。承诺链只接受 `att=real` 且 `age_wall(e)≤τ_fresh`；`sim/bag` 证据进入沙箱，只能用于离线校准、回归与反事实设计，**永不得进入在线承诺链**。洗白检测：`hash(payload)`、单调序号、源身份、`gen`；同一 payload 以新 stamp 重现 ⇒ 判 `launder` 并隔离。跨模态对账要求两证据同属真实时钟域且 `|t_i−t_j|≤τ_sync`；`use_sim_time` 节点的任何输出自动降为 `sim`。

**定义 142（双胞胎校准包络 TCE）** 双胞胎集 `𝒯={(r_j,o_j^real,o_j^{S_l})}`（同一区域真机与第 l 个仿真器各观测一次；**密封**，不参与元训练、超参选择与早停）。乐观残差 `ΔR_{j,l}=R_real(r_j)−R_l(r_j)`（正=仿真低估风险）；单侧共形上界 `ε_op^l(α)=Q_{1−α}(ΔR_{·,l})`，只上不下。仿真可否决规则：若 `∃l:R_l(θ,r)+ε_op^l>δ_f`，则否决该假设；若所有 `l` 都不否决，只说明"在仿真器族内未被反证"，**不构成认证**。保真权重 `w_sim=1[D_S≤θ_S]·(1−D_S/θ_S)_+` 只用于反事实排序与加宽，**不得计入 P_fail 的正向证据项**。按材质簇×坡度×季节做 Mondrian 单侧共形，报告逐层最差覆盖，禁止只报均值。

**定义 143（谱系-时基-保真证据门 EFG 与证书 J_r）** 证据类 `{EV-probe*,EV-visit,EV-margin,EV-xmodal,EV-human,EV-sim⁻}`。`EV-probe*` 须 `att=real`、`age≤τ_fresh`、谱系完整，并满足第 57 轮 ECE/OOD 契约；`EV-xmodal` 须 `Ind_C∧D≤θ_D∧同真实时钟∧|Δt|≤τ_sync`，仅限 L1；`EV-sim⁻` 只可拒否或触发探针，永不计正证据。不可逆接触必要证据集 `={EV-probe*∨EV-margin}∪human 佐证`，全部须 `att=real` 且谱系干净；`EV-xmodal`、`EV-sim⁻` 一律不得进入。证书 `J_r=(M_core,C_core,K_margin,ρ_sem,δ_s,probe_log,consent_log,evidence,meta_cal_log,xmodal_log,auth_log,ood_reg,prov_root,clock_att,cf_log,twin_cal,quarantine)`，继承 J_p 全检并新增三项硬检：`prov_root` 可重放、`clock_att` 全为 real、`cf_log` 无仿真证据越级。

**定义 144（探-诺-演++ PCX++）** 每检查点六步：⓪**准入与证明**（谱系/时基/回放隔离，失败即隔离）；①**元推断**（ID→摊销后验 / OOD→共形带）；②**反事实设计**（高置信且 `sim-ambiguous` 或语料稀疏 ⇒ 求 `a*` 入探针队列；仿真可否决、不可承诺）；③**因果对账**（只在 `Ind_C` 子集上算 `D(r)`；独立模态不足 ⇒ 视 `D=∞` 并强制加宽）；④**因果折扣 VOI**：`VOI_eff(q)=VOI(q)·(1−κ_q)`，`κ_q` 为候选探针与既有证据的谱系重叠；⑤**承诺** ⇔ `∃g:R≤δ_f(g)` ∧ EFG 过 ∧ 承诺链无 `sim/bag` 证据；否则 探尽→绕行→降档→L2（`τ_int(auth)`）或安全停。

```python
def provenance_admit(e, g, clocks):
    if not verify_sig(e) or e.gen != clocks.gen(e.src): return QUARANTINE
    att = clocks.attest(e.src, e.header.stamp, e.clock_domain)  # 外部证明，非自报

def cfx_design_probe(r, q, sims, budget):             # IP-139: 只设计，不认证
    if confidence(q) < theta_conf or not sparse_or_ambiguous(r): return None
    danger = adversarial_worlds(sims, r, delta_f)     # Θ_d(r)
    best, best_ig = None, -inf
    for a in admissible_probes(r):                    # A34 非破坏过滤继承
        ig = min_l expected_ig(sims[l], a, q, danger) # 对仿真器族取最坏
        if ig > best_ig: best, best_ig = a, ig
    return best if best_ig >= theta_ig else None

def causal_xmodal_fuse(M, r, es):                    # IP-140: 只认分叉祖先
    ind = [e for e in es if Ind_C(es, e) and same_real_clock(es, e)]
    if n_C(ind) < 2: return widen(M.b[r], INF)        # 独立不足 → 保守加宽
    D = disagreement(ind)
    fused = Fuse(ind, rho=w_sim_weighted(M))
    return widen(fused, D) if D > theta_D else fused

def evidence_gate_r(c, M, s, twin):                  # IP-143
    if c.ev == 'EV-sim-': return ('reject_or_probe' if c.rejects else 'ignore')
    if c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_causal and c.dt <= tau_sync \
             and c.D <= theta_D and c.att == 'real'
    elif c.ev == 'EV-probe*':
        ok = c.att == 'real' and c.age <= tau_fresh and c.prov_complete \
             and (round57_meta_contract(c) or c.region in twin.certified)
    elif c.ev == 'EV-human':
        ok = s[c.op].auth >= 'A1' and c.corrob >= corrob_star(s[c.op].auth) \
             and c.att == 'real'
    else: ok = round56_checks(c, M)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-xmodal', 'EV-sim-'):
        return ('reject', 'sim_or_xmodal_on_irreversible', c)
    return ('ok', c)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CFX | O(L·N_cf·C_SIM)/检查点 | O(\|𝒯\|+\|𝓢\|) | 单侧乐观界、仿真零正证据、多仿真器取最坏 |
| CGP | O(\|E\|·b)/谱系查询；Merkle 下 O(log\|E\|) | O(\|E\|·b) | 祖先完备、篡改可验、`δ_anc` 有界 |
| TBA | O(1)/消息 | O(\|E\|) | 外部证明、仿真/回放不进承诺链 |
| TCE | O(N_twin)/层 | O(\|𝒯\|) | 双胞胎密封、逐层最差覆盖 |
| EFG | O(\|σ\|+谱系检查) | O(\|σ\|) | 无真实证据不承诺、EV-sim⁻ 只负向 |
| PCX++ | O(\|CP\|·(k_p+k_c+k_f)·(C_VOI+d_φ)+谱系) | O(\|V\|+\|σ\|) | 三预算终止、六态完备 |

**正确性定理（Falsifiable-Provenance Soundness, FPS）**：在 A33–A40 上新增 **(A41)** 仿真单侧乐观界 `ε_op^l` 覆盖真实-仿真风险差 ≥1−α_op，且仿真/回放证据零正向计数；**(A42)** 谱系 DAG 完备、只追加不可篡改，隐藏共因质量 ≤δ_anc，`Ind_C` 判定保守；**(A43)** 时基外部证明可靠，`sim/bag` 误判为 real ≤δ_clk，真实证据 `age≤τ_fresh`；**(A44)** 双胞胎集密封且对材质簇交换可用，Mondrian 单侧共形覆盖有效。则：

1. **承诺健全性**：`P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_anc + δ_clk`；仿真误差只进入**漏检危险**（可用性）项，不进入正向 soundness 项；`EV-xmodal` 仅在 `Ind_C∧L1` 上贡献 `δ_xm`。
2. **交互单调性**：CFX 只增加探针或否决、CGP 只剔除伪独立证据或加宽、TBA 只隔离非真实/过期证据、TCE 只加宽或排序——四者都只经"动作更保守"或"信念更宽"影响系统，不存在升险路径。
3. **终止性**：每检查点共识探针 ≤k_cons、反事实设计 ≤k_f，PCX++ 在 `k_probes+k_cons+k_f` 内终止于 {承诺, 绕行, L2 协商, 安全停}。
4. **部署界**（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_anc + δ_clk)
             − P(谱系洗白未检出) − P(时基误证) − P(τ_sync ∧ τ_int 超时 ∧ 安全停失效)
```

### IP-139 CFX（反事实实验设计：仿真只设计，不认证）

```python
def cfx_design_probe(r, q, sims, budget):
    """输入当前元后验 q；输出一条真机探针建议，或 None。"""
    if confidence(q) < theta_conf or not sparse_or_ambiguous(r):
        return None                                  # 先验已够宽 / 区域不模糊 → 不花反事实
    danger = adversarial_worlds(sims, r, delta_f)     # Θ_d(r)：多仿真器危险假设并集
    best, best_ig = None, -inf
    for a in admissible_probes(r, F_abs):             # A34 非破坏过滤继承
        igs = [expected_ig(S, a, q, danger) for S in sims]
        ig = min(igs)                                 # 对仿真器族取最坏（防单引擎盲区）
        if ig > best_ig:
            best, best_ig = a, ig
    if best_ig < theta_ig:
        return None
    budget.spend_cf(1)                                # 与真机探针预算分账（F3）
    return best                                       # 只返回“该做哪个实验”

def cfx_can_reject(r, theta, sims, twin):
    """仿真可否决一个“安全”假设；twin 提供单侧乐观界。"""
    for S in sims:
        if S.risk(theta, r) + twin.eps_op[S.id] > delta_f:
            return True                               # 可否决
    return False                                      # 未反证 ≠ 认证（F1）
```

### IP-140 CGP（ROS 因果谱系与有效独立度）

```python
def build_provenance(e, g):
    e.anc = frozenset(g.parents(e)) | {p.id for p in e.parents}
    e.anc |= {e.id}
    g.add_node(e)                                    # 只追加，不删边（A42）
    return e

def ind_causal(e1, e2, infra=I):
    return len((e1.anc & e2.anc) - infra) == 0       # 观测祖先必须分叉

def n_effective(es):
    w = [e.w for e in es]
    num = sum(w) ** 2
    den = sum(w[i] * w[j] * kappa(es[i], es[j])      # κ_ii=1；共因取保守下界
              for i in range(len(es)) for j in range(len(es)))
    return num / max(den, EPS)

def kappa(e1, e2, infra=I):
    ca = (e1.anc & e2.anc) - infra
    un = (e1.anc | e2.anc) - infra
    return len(ca) / max(len(un), 1)

def causal_xmodal_fuse(M, r, es):
    ind = [e for e in es if ind_causal(es[0], e) and same_real_clock(es[0], e)]
    if n_effective(ind) < 2:
        return widen(M.b[r], INF)                    # 伪独立 → 退化为单证据并加宽
    D = disagreement(ind)
    fused = Fuse(ind, rho=[w_sim_weighted(M, e) for e in ind])
    return widen(fused, D) if D > theta_D else fused
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CFX | O(L·N_cf·C_SIM)/检查点 | O(\|𝒯\|+\|𝓢\|) | 单侧乐观界、仿真零正证据（A41） |
| CGP | O(\|E\|·b)/查询；Merkle O(log\|E\|) | O(\|E\|·b) | 祖先完备、只追加、δ_anc（A42） |
| TBA | O(1)/消息 | O(\|E\|) | 外部证明、sim/bag 隔离（A43） |
| TCE | O(N_twin)/层 | O(\|𝒯\|) | 双胞胎密封、逐层最差覆盖（A44） |
| EFG | O(\|σ\|+谱系检查) | O(\|σ\|) | 无真实证据不承诺、EV-sim⁻ 只负向 |
| PCX++ | O(\|CP\|·(k_p+k_c+k_f)·(C_VOI+d_φ)+谱系) | O(\|V\|+\|σ\|) | 三预算终止、六态完备 |

**正确性定理（Falsifiable-Provenance Soundness, FPS）**
假设 A22–A40（第 53–57 轮）成立；新增 **(A41)** 仿真单侧乐观界：`∀l`，`P(R_real−R_l≤ε_op^l)≥1−α_op`，且仿真/回放证据零正向计数；**(A42)** 谱系 DAG 完备、只追加不可篡改，隐藏共因质量 ≤δ_anc，`Ind_C` 判定保守（宁可判不独立）；**(A43)** 时基外部证明可靠，`sim/bag` 误判为 `real` 的概率 ≤δ_clk，真实证据 `age≤τ_fresh`；**(A44)** 双胞胎集密封、对材质簇可交换，Mondrian 单侧共形逐层覆盖有效。则：

1. **承诺健全性**：`P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_anc + δ_clk`；仿真误差只进入**漏检危险**（可用性）项，不进入正向 soundness 项；`EV-xmodal` 仅在 `Ind_C∧L1` 上贡献 ≤δ_xm。
2. **交互单调性强化**：CFX 只增探针或否决、CGP 只剔伪独立证据或加宽、TBA 只隔离非真实/过期证据、TCE 只加宽或排序——四者都只经 (a) 更宽的信念或 (b) 更保守的动作影响系统，不存在升险路径。
3. **终止性**：每检查点共识探针 ≤k_cons、反事实设计 ≤k_f，`PCX++` 在 `k_probes+k_cons+k_f` 内终止于 {承诺, 绕行, L2 协商, 安全停}。
4. **部署界**（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_anc + δ_clk)
             − P(谱系洗白未检出) − P(时基误证) − P(τ_sync ∧ τ_int 超时 ∧ 安全停失效)
```
5. **仿真非认证性（本轮新增核心）**：对任意仿真器族与任意搜索预算，`EV-sim⁻` 与 CFX 均不能提高任何证据项的正向置信；仿真只能通过 `reject_or_probe` 改变**动作**，不能改变**证据的符号**。

关键：**仿真给实验、真机给结论**（效率与 soundness 解耦）；**独立由祖先分叉证明**（把"不同传感器"升级为"不同观测链"）；**时基由外部证明**（旧内容换新戳仍是旧内容）；多仿真器分歧只加宽、不加信。

## 6. 本轮最大风险

**一句话**：本轮把"先验有病"的诊断权交给一个与先验同源的仿真器，又把"证据独立"的判定权交给一张由同一 ROS 图生成的谱系图——若两者同时系统性失明（仿真共享同一接触模型、谱系共享同一上游节点），系统会得到一份"因果独立、仿真未反证、时钟真实"的自洽错误证据，并比第 57 轮更快地承诺；必须以多仿真器最坏情形、密封真机双胞胎锚点、外部时基证明与 fail-closed 谱系四重护栏兜底，且永远只让仿真设计探针、不让仿真签发承诺。
