# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「轻量化设计」×「技术路线图」）

> 前几轮把可信组合做得越来越“重”：动作剖面 `α_S`、鲁棒性谱 `ρ`、组合图 `G_S`、云边映射 `γ_ce`、联合证书 `J`。本轮反过来追问两个被忽略的问题：**这套保证体系自身能不能跑在边端？它会不会先于技能压垮系统？** 以及 **每一轮的证书凭什么能在下一轮继续有效？** 核心矛盾：H22：保证层的成本随技能库规模超线性增长，证书本身成为部署瓶颈，“可验证”与“可部署”冲突；H23：技术路线图上的里程碑会改变质量/负载/接口/假设，上一轮证书在新里程碑上会静默失效（certificate decay），缺少显式有效期与迁移义务。

## 0. 直觉与动机

**灵感 1（证书也有重量：从“能不能证”到“证得起吗”）**
直觉：一张证书不只有真值，还有成本 `c(Π)=(c_mem,c_flop,c_lat,c_energy)`。边端预算是 `B_e`，若 `c(Π)>B_e`，再 sound 的证书也部署不了。轻量化设计的第一性对象不是模型，而是 **保证本身**：要优化“单位成本换来的可信度”，即保证密度 `AD(Π)=Δsound(Π)/||c(Π)||_1`。直觉上大量证书维度对具体动作是冗余的：远离覆盖阈值 `θ_cov` 的动作不需要全谱，只需要一个保守包络。

**灵感 2（保守 sketch：压缩必须向下近似可认证集）**
直觉：压缩不能“丢信息后假装没丢”。安全做法是让 sketch **只认证它敢担保的动作**：`Acc(σ(Π)) ⊆ Safe(Π)`。它可能误拒（保守），但绝不误放（unsound）。于是压缩的代价从“漏检风险”转成“保守率 `γ_σ`”。用动作哈希 + 区间包络 + `ρ` 维度区间壳实现；关键是 sketch 必须对组合运算封闭，否则路径搜索时又要把全证书解压回来。

**灵感 3（惰性验证：边端只做 O(1) 守卫，重证据按需上浮）**
直觉：边端常驻短 digest `h(Π)` 与本地守卫 `g(σ)`（区间包络、边界标志）。绝大多数动作落在边界内，O(1) 通过；只有接近 `θ_cov`/`ρ_min` 边界或审计挑战时才向云端请求完整证书（L2）。这像 proof-carrying code + just-in-time proof：**证明不是常驻负载，而是异常路径上的按需负载**。随机审计率 `p_audit` 负责兜底“sketch 因漂移而过期”。

**灵感 4（轻量化设计 = 设计参数漂移下的证书半径）**
直觉：机体减重不是免费的：质量、惯量、刚度、摩擦一起变，`α_S` 与 `ρ` 随之漂移；而且减重并非单向变好——某些关节裕度上升，另一些因刚度/摩擦变化而下降。因此需要 **方向敏感性 `∂ρ/∂θ_P`** 与 **证书有效性半径 `r(Π)`**：只要设计参数步长 `||Δθ_P||≤r(Π)`，旧证书可迁移；超出则必须重校准。轻量化因此被“半径约束”驯服，而不是被禁止。

**灵感 5（技术路线图 = 假设偏序 + 就绪度债务）**
直觉：路线图不是 PPT 上的箭头，而是里程碑 `M` 上的 **假设集合偏序** 与依赖 DAG `E_R`。证书 `Π` 只在有效期 `H(Π)` 内有效，前提是区间内假设成立、设计参数落在 `r(Π)` 内、鲁棒性衰减不超预算。每个 IP 有就绪度 `r_v`，组合就绪度取瓶颈 `r(v)=min(r_local, min parents)`——一个未验证的底座会卡住整条链。没做的验证就是 **路线图债务** `d_v=r*_v-r_v`；下一步实验应最大化“每单位成本消除的债务”。这样路线图从叙事变成有目标函数、可复算的调度问题。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（证书成本与保证密度）**
沿用第 54 轮联合证书 `Π=J=(ρ,A_cert,γ_ce,δ_a,evidence)`。成本向量 `c(Π)=(c_mem,c_flop,c_lat,c_energy)`，边端预算 `B_e`。保证密度 `AD(Π)=Δsound(Π)/||c(Π)||_1`。`Π` 边端可驻留当且仅当 `c(Π)≤B_e` 逐分量；否则必须 sketch 化。

**定义 122（保守证书 sketch）**
sketch 编码 `σ` 与解码 `D`。**可认证集** `Acc(σ):=D(σ)`。soundness-preserving 条件：
```
Acc(σ(Π)) ⊆ Safe(Π),   ε_σ := vol(Acc(σ) \ Safe(Π)) = 0
```
保守率 `γ_σ := 1 - vol(Acc(σ))/vol(Safe(Π)) ≤ γ_max`，压缩率 `κ_σ := ||c(σ(Π))||/||c(Π)||`。轻量化目标：
```
min κ_σ   s.t.   ε_σ = 0,  γ_σ ≤ γ_max
```
即：在零误放前提下，用最小成本换取最低误拒率。

**定义 123（sketch 组合闭合性）**
若 `σ(Π_1⊗Π_2)=⊗_σ(σ(Π_1),σ(Π_2))` 可由两个 sketch 直接计算，且
```
Acc(⊗_σ(σ_1,σ_2)) ⊆ Acc(σ_1) ∩ Acc(σ_2) ⊆ Safe(Π_1⊗Π_2)
```
则称 sketch 对组合 **闭合**。要求 `⊗_σ` 结合、单调（接受集更小则结果更小）。闭合性保证第 54 轮 SCOM 的路径搜索可全程在 sketch 层完成，且组合仍 sound。

**定义 124（惰性验证与审计）**
守卫 `g(σ)=(h(Π),E_σ,∂σ)`：证书 digest、认证包络、边界集。运行判定：
```
verify(a,σ) = L1_pass   if a∈Acc(σ) ∧ a∉∂σ ∧ interval_ok(E_σ,a)
             = L2_fetch  otherwise
```
随机审计以概率 `p_audit` 用 `h(Π)` 向云端核验；失配则回滚。**漂移漏检** `π_drift := P(σ 已过期 ∧ L1 仍放行)`。审计的作用不是补 sketch 的 soundness（后者按定义为 0 误放），而是补 **时序漂移**。

**定义 125（设计敏感性与证书有效性半径）**
设计参数 `θ_P∈Θ_P`（质量、惯量、连杆长度、刚度、摩擦）。证书 `Π=Π(θ_P)`。方向敏感性 `∇_θ ρ(θ_P)` 与包络敏感性 `∇_θ E(θ_P)`。**证书有效性半径**
```
r(Π) := sup{ Δ : ||θ_P-θ_P^0|| ≤ Δ ⇒
            Acc(σ(Π(θ_P))) ⊆ Safe(Π(θ_P))
            ∧ ρ(θ_P) ≥ ρ_min - β_ρ
            ∧ E(θ_P) ⊆ E_buffer }
```
轻量化算子 `L: θ_P ↦ θ_P'`（`Δm<0`）。若 `||θ_P'-θ_P||≤r(Π)` 则可迁移，否则证书作废并强制重校准。注意 `r(Π)` 按方向而非仅按质量标量计算，因为减重对 `ρ` 的影响非单调。

**定义 126（技术路线图与就绪度债务）**
路线图 `R=(M,≤,cap,A,Θ_P,E_R)`：里程碑偏序、能力向量、假设族、设计参数轨迹、依赖边。证书有效期 `H(Π)=[m_i,m_j]`，当且仅当对任意 `m∈[m_i,m_j]`：
```
A_m ⊨ A(Π)  ∧  ||θ_P(m)-θ_P^0|| ≤ r(Π)  ∧  Σ_{m'≤m} Δρ(m') ≤ β_H
```
跨里程碑迁移证书 `MIG_{m→m'}=(ΔA,Δθ_P,Δρ,Δc,evidence)`。就绪度 `r_v∈[0,1]`，瓶颈组合 `r(v)=min(r_local(v), min_{(u,v)∈E_R} r(u))`，债务 `d_v=r*_v-r_v`。路线图一致发布：发布里程碑 `m` 的整条依赖链满足 `min_{v∈anc(m)} r(v) ≥ r*`。

## 2. 关键算法 伪代码

### IP-121 LCS（Lightweight Certificate Sketch）

```python
def sketch_certificate(cert, theta_cov, gamma_max, eps=0.02):
    # 只保留边界动作；内部折叠为保守包络（欠近似可认证集）
    boundary = {a for a in cert.A if abs(cert.alpha[a] - theta_cov) <= eps}
    env = inner_hull(cert.A)              # 只缩不放：Acc(σ) ⊆ Safe(Π)
    rho_shell = {d: (cert.rho[d] - slack(d), cert.rho[d] + slack(d))
                 for d in cert.rho}
    sk = Sketch(hash_cert(cert), env, rho_shell, boundary, cost_estimate(cert))
    assert is_sound(sk, cert)             # ε_σ == 0
    assert conservatism(sk, cert) <= gamma_max
    return sk
```

### IP-122 SCC（Sketch Composition Closure）

```python
def compose_sketch(s1, s2, margin):
    # 接受集先取交，再减去转换带与不确定耦合裕度
    acc = intersect(s1.env, s2.env) - interface_band(s1, s2) - margin
    rho = {d: interval_min(s1.rho[d], s2.rho[d]) for d in s1.rho}
    boundary = s1.boundary | s2.boundary | interface_band(s1, s2)
    return Sketch(combine_hash(s1.h, s2.h), acc, rho, boundary,
                  s1.cost + s2.cost)

def sketch_path_search(G_sketch, task, k=5):
    # A* 全程在 sketch 层；仅对 top-k 路径解压做 L2 复核
    paths = a_star(G_sketch, task,
                   cost=lambda e: e.cost + e.conservatism + e.margin_penalty)
    return [decompress(p) for p in paths[:k]]
```

### IP-123 LVC（Lazy Verification Controller）

```python
def lazy_verify(a, sk, cloud, p_audit, theta_cov):
    if a not in sk.env or near_boundary(a, sk.boundary, theta_cov):
        return escalate_to_L2(sk, cloud)
    ok = interval_ok(sk.rho, a) and a in sk.env
    if random() < p_audit:
        ok = ok and (sk.h == cloud.digest(sk.id))
    return ok

def escalate_to_L2(sk, cloud):
    cert = cloud.fetch_full(sk.id)        # 第 54 轮联合证书 J
    if cert is None:
        return False
    return cert.covers(current_action)
```

### IP-124 DSC（Design-Sensitivity Certificate）

```python
def design_radius(cert, theta0, directions, delta_max):
    radius = delta_max
    for d_theta in directions:            # 质量/惯量/刚度/摩擦
        for delta in grid(0, delta_max, step):
            theta = theta0 + delta * d_theta
            if not cert.valid_at(theta):  # 覆盖、ρ、包络三项
                radius = min(radius, delta)
                break
    return radius

def lightweight_transfer(cert, theta_new, radius):
    if norm(theta_new - cert.theta0) <= radius:
        return ('ok', migrate_certificate(cert, theta_new))
    return ('recalibrate', design_radius(cert, theta_new, ...))
```

### IP-125 RHA（Roadmap Horizon Algebra）

```python
def certificate_horizon(cert, roadmap):
    lo = cert.milestone
    cur = lo
    for m in roadmap.after(lo):
        if not implies(roadmap.A[m], cert.assumptions):
            return (lo, cur)
        if norm(roadmap.theta[m] - cert.theta0) > cert.radius:
            return (lo, cur)
        if cumulative_decay(cert, m) > cert.beta_H:
            return (lo, cur)
        cur = m
    return (lo, max(roadmap.M))

def issuance_guard(cert, roadmap):
    return 'ok' if roadmap.current in cert.horizon else 're-certify'
```

### IP-126 LRP（Lightweight Roadmap Planner）

```python
def readiness(roadmap, r_local):
    r = dict(r_local)
    for v in topo_order(roadmap):         # 瓶颈传播
        for u in roadmap.parents(v):
            r[v] = min(r[v], r[u])
    return r

def plan_next_experiment(candidates, roadmap, r, r_star, budget):
    scored = []
    for e in candidates:
        gain = sum(min(max(0.0, r_star[v] - r[v]), e.evidence[v])
                   for v in e.covers)
        scored.append((gain / e.cost, e))
    scored.sort(reverse=True, key=lambda x: x[0])
    plan, spent = [], 0.0
    for ratio, e in scored:
        if spent + e.cost <= budget:
            plan.append(e); spent += e.cost
    return plan, spent
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| LCS | O(|A| log|A|) | O(|∂σ|+|𝔇_ρ|) | 欠近似构造、`ε_σ=0` 可验证 |
| SCC | O(|S|²·|σ|) | O(|E|·|σ|) | `⊗_σ` 结合单调、接受集只缩不放 |
| LVC | O(1) 均摊 + `p_esc`·L2 | O(|σ|) | 边界判定完备、digest 不可伪造 |
| DSC | O(|directions|·|grid|·|A|) | O(|A|) | 方向敏感性覆盖非单调效应 |
| RHA | O(|M|+|E_R|) | O(|M|) | 假设蕴含可判定、衰减可加 |
| LRP | O(|E_cand| log|E_cand|) | O(|V|) | 债务可加、证据收益不超估 |

**正确性定理（Lean-Roadmap Certificate Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** `σ` 在签发时 sound（`ε_σ=0`）且组合闭合；**(A30)** 审计间隔内设计/上下文漂移 `≤r(Π)` 的概率 `≥1-π_drift`；**(A31)** 审计信道安全，`p_audit>0`，L2 上浮延迟 `≤τ_L2`；**(A32)** 里程碑假设蕴含可判定，就绪度估计在留出证据上校准。
则对使用证书 `Π` 的部署：
```
P(unsafe deploy | m) ≤ (1-p_audit)·π_drift + P(m ∉ H(Π)) + P(δ_a > Θ_a)
```
进而在 `m∈H(Π)` 且 `δ_a≤Θ_a` 时：
```
P(success) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - (1-p_audit)·π_drift
```
要点：轻量化不改变 soundness 的 **签发时刻** 保证，它把风险从“压缩误差”转移到“时序漂移 + 里程碑越界”，而这两者分别由审计与 horizon 显式兜住。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| sketch 过度保守导致边端频繁上浮 | 高 | 自适应边界细化 + 分层 `γ` 预算 + 上浮率反馈 |
| 未建模耦合使 sketch 组合欠保守 | 高 | 组合裕度 + 对抗组合审计 + 每次新增技能强制重证 |
| 设计漂移超出半径而未被发现 | 高 | 硬件指纹 + 周期重 sketch + 审计绊线 |
| 路线图假设静默漂移 / 就绪度自证 | 高 | 预注册里程碑 + 独立证据 + 债务未清不发布 |
| 减重方向非单调被标量质量掩盖 | 中 | 按方向测敏感性，禁止只报 `Δm` |

## 6. 本轮最大风险

**一句话**：轻量化 sketch 与路线图期限的联合 soundness **同时依赖“签约时保守、漂移后被审计发现、里程碑假设单调”三件事**；一旦 sketch 因未建模耦合而欠保守，或路线图把“减重/升级”当作无需重证的小步，系统就会以更低的成本、更漂亮的路线图去认证一个已经失效的组合，故必须把 **保守性对抗审计 + 设计漂移绊线 + 债务未清不发布** 设为不可谈判的硬约束，绝不拿压缩率换 soundness。

def sketch_certificate(cert, theta_cov, gamma_max, eps=0.02):
    boundary = {a for a in cert.A if abs(cert.alpha[a] - theta_cov) <= eps}
    env = inner_hull(cert.A)                 # 只缩不放：sound 欠近似
    rho_shell = {d: (cert.rho[d] - slack(d), cert.rho[d] + slack(d))
                 for d in cert.rho}
    sk = Sketch(hash_cert(cert), env, rho_shell, boundary, cost_estimate(cert))
    assert is_sound(sk, cert) and conservatism(sk, cert) <= gamma_max
    return sk

def sketch_price(cert, B_e):
    if fits(cert, B_e):
        return ('full', cert)
    sk = sketch_certificate(cert, theta_cov, gamma_max)
    if not fits(sk, B_e):
        return ('reject', 'cannot_afford_assurance')
    return ('sketch', sk)

def compose_sketch(s1, s2, margin):
    acc = intersect(s1.env, s2.env) - interface_band(s1, s2) - margin
    rho = {d: interval_min(s1.rho[d], s2.rho[d]) for d in s1.rho}
    boundary = s1.boundary | s2.boundary | interface_band(s1, s2)
    return Sketch(combine_hash(s1.h, s2.h), acc, rho, boundary,
                  s1.cost + s2.cost)

def sketch_path_search(G_sketch, task, k=5):
    paths = a_star(G_sketch, task,
                   cost=lambda e: e.cost + e.conservatism + e.margin_penalty)
    return [decompress(p) for p in paths[:k]]

def lazy_verify(a, sk, cloud, p_audit, theta_cov):

### IP-124 DSC

```python
def design_radius(cert, theta0, directions, delta_max, step):
    radius = delta_max
    for d_theta in directions:               # 质量 / 惯量 / 刚度 / 摩擦
        for delta in grid(0, delta_max, step):
            theta = theta0 + delta * d_theta
            if not cert.valid_at(theta):     # 覆盖 + ρ + 包络三项
                radius = min(radius, delta)
                break
    return radius

def lightweight_transfer(cert, theta_new, radius):
    if norm(theta_new - cert.theta0) <= radius:
        return ('ok', migrate_certificate(cert, theta_new))
    return ('recalibrate', design_radius(cert, theta_new, cert.directions,
                                         cert.delta_max, cert.step))
```

### IP-125 RHA

```python
def certificate_horizon(cert, roadmap):
    lo, cur = cert.milestone, cert.milestone
    for m in roadmap.after(lo):
        if not implies(roadmap.A[m], cert.assumptions):
            return (lo, cur)
        if norm(roadmap.theta[m] - cert.theta0) > cert.radius:
            return (lo, cur)
        if cumulative_decay(cert, m) > cert.beta_H:
            return (lo, cur)
        cur = m
    return (lo, max(roadmap.M))

def milestone_migrate(cert, m_from, m_to, roadmap, budget):
    mig = MIG_{m_from -> m_to}(delta_A(roadmap, m_from, m_to),
                               delta_theta(roadmap, m_from, m_to),
                               delta_rho(cert, roadmap, m_to),
                               delta_cost(cert, roadmap, m_to),
                               evidence=roadmap.evidence[m_to])
    if mig.delta_rho > budget.rho or mig.delta_theta > cert.radius:
        return ('reject', mig)
    return ('ok', mig)
```

### IP-126 LRP

```python
def readiness(roadmap, r_local):
    r = dict(r_local)
    for v in topo_order(roadmap):            # 瓶颈传播：底座未证则整链受限
        for u in roadmap.parents(v):
            r[v] = min(r[v], r[u])
    return r

def plan_next_experiment(candidates, roadmap, r, r_star, budget):
    scored = []
    for e in candidates:
        gain = sum(min(max(0.0, r_star[v] - r[v]), e.evidence[v])
                   for v in e.covers)
        scored.append((gain / e.cost, e))
    scored.sort(reverse=True, key=lambda x: x[0])
    plan, spent = [], 0.0
    for ratio, e in scored:
        if spent + e.cost <= budget:
            plan.append(e); spent += e.cost
    return plan, spent
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LCS | O(\|A\| log\|A\|) | O(\|∂σ\|+\|𝔇_ρ\|) | 欠近似构造，`ε_σ=0` 可验证 |
| SCC | O(\|S\|²·\|σ\|) | O(\|E\|·\|σ\|) | `⊗_σ` 结合单调，接受集只缩不放 |
| LVC | O(1) 均摊 + `p_esc`·L2 | O(\|σ\|) | 边界判定完备，digest 不可伪造 |
| DSC | O(\|directions\|·\|grid\|·\|A\|) | O(\|A\|) | 方向敏感性覆盖非单调效应 |
| RHA | O(\|M\|+\|E_R\|) | O(\|M\|) | 假设蕴含可判定，衰减可加 |
| LRP | O(\|E_cand\| log\|E_cand\|) | O(\|V\|) | 债务可加，证据收益不超估 |

**正确性定理（Lean-Roadmap Certificate Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** `σ` 签发时 sound（`ε_σ=0`）且组合闭合；**(A30)** 审计间隔内设计/上下文漂移 `≤r(Π)` 的概率 `≥1-π_drift`；**(A31)** 审计信道安全，`p_audit>0`，L2 上浮延迟 `≤τ_L2`；**(A32)** 里程碑假设蕴含可判定，就绪度估计在留出证据上校准。
则：
```
P(unsafe deploy | m) ≤ (1-p_audit)·π_drift + P(m ∉ H(Π)) + P(δ_a > Θ_a)

P(success) ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - (1-p_audit)·π_drift
             (当 m ∈ H(Π) 且 δ_a ≤ Θ_a 时)
```
关键解释：轻量化不削弱 **签发时刻** 的 soundness；它把风险转移到 **时序漂移** 与 **里程碑越界**，分别由 `p_audit` 与 `H(Π)` 显式兜底。压缩率与保证密度只在 `γ_σ≤γ_max` 的可行域内优化。

## 6. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| sketch 过度保守导致频繁上浮 | 高 | 自适应边界细化 + 分层 `γ` 预算 + 上浮率反馈 |
| 未建模耦合使组合 sketch 欠保守 | 高 | 组合裕度 + 对抗组合审计 + 新增技能强制重证 |
| 设计漂移超半径而未被发现 | 高 | 硬件指纹 + 周期重 sketch + 审计绊线 |
| 路线图假设静默漂移 / 就绪度自证 | 高 | 预注册里程碑 + 独立证据 + 债务未清不发布 |
| 减重方向非单调被标量质量掩盖 | 中 | 按方向测敏感性，禁止只报 `Δm` |

## 7. 本轮最大风险

**一句话**：轻量化 sketch 与路线图期限的联合 soundness **同时依赖“签约时保守、漂移后被审计发现、里程碑假设单调”三件事**；一旦 sketch 因未建模耦合而欠保守，或路线图把“减重/升级”当作无需重证的小步，系统就会以更低的成本、更漂亮的路线图去认证一个已经失效的组合，故必须把 **保守性对抗审计 + 设计漂移绊线 + 债务未清不发布** 设为不可谈判的硬约束，绝不拿压缩率换 soundness。
