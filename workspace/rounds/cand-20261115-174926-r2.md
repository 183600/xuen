# 第 8 轮（灵感循环第 2 轮；承接第 7 轮 MetricVoiceGauge-OTL-GC-ER；本轮灵感：「单模型多任务」×「双足机器人」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮纪律：**共享表示 + 动态平衡 + 可证安全**。第 7 轮把语音、抓取、情感拆成三个可选模块；本轮用「单模型多任务」把它们收进一个共享主干，再用「双足机器人」把动态平衡提升为一等硬约束。二者结合后出现全篇最大的结构性变化：**共享主干把多个独立失效点合并为一个公共失效模式，而双足平台让这个公共失效直接等价于摔倒**。因此本轮的核心不是「让一个模型做更多事」，而是「让一个模型做更多事的同时，仍能被独立、快速地证伪」。

## 0. 直觉与动机

**灵感 1（单模型多任务 → 共享主干 + 隔离适配器）**
直觉：v7 中的 VoiceCommandTyping、GraspCommandTyping、EmotionalReweighting、MetricLadder 各自持有表示，参数与延迟重复；它们其实共享同一个「任务—价值—身体」潜空间。单模型多任务把语音意图、抓取几何、情感、指标满足度、平衡风险压进同一个主干 f_φ，只保留轻量任务头 h_θk 与适配器 g_ψk。收益是跨任务迁移、参数共享、统一 WCET；代价是灾难性遗忘与**公共失效模式**：主干一次扰动会同时污染所有头。
设计上必须把「共享」与「可隔离」同时做到：共享主干负责泛化，任务适配器负责隔离，独立证书负责兜底。

**灵感 2（双足机器人 → 平衡即硬约束 + 姿态级退化）**
直觉：轮式/固定基座机器人可以「停下来」即安全；双足机器人「停下来」本身就是一个需要主动维持的动力学任务。ZMP 必须落在支撑多边形内，CoM 投影要留裕度，捕获点要能吸收扰动，足底接触力与步态相位要一致。于是 v7 的「退化到硬约束」在双足上必须具体化为**退化到双支撑站立（double-support stand）**，而不是抽象地「收紧阈值」。
更关键的是：平衡不能由学习模型自证。必须有一个**非学习的几何/动力学守护者**以更高频率独立验算 ZMP/CoM/接触力，学习模型只能提议动作，不能签署自己的安全证书。

**交会点（OMT-BR）**
单模型多任务提供「慢而广」的语义与效能推理（50Hz 外环）；双足平衡守护者提供「快而窄」的硬安全（≥500Hz 内环）。两者用**任务条件证书**连接：每个任务头输出带自己的 SoftCert，主干另有共享主干证书；一旦公共模式熔断触发，整条共享分支被切断，逐任务回退到 v7 的模块化实现。核心命题：
> **可认证的单模型多任务 = 共享表示（泛化）+ 隔离适配器（抗干扰）+ 独立守护者（可证伪）+ 姿态级退化（可恢复）。**

## 1. 研究问题（轮次升级版）

- **Q1（干扰上界）**：共享主干下任务 j 的输出偏差能否被任务 k 的更新所界定？能否在线估计干扰矩阵 I 并在超界时隔离该任务？
- **Q2（平衡硬约束）**：ZMP/CoM/捕获点/接触力/步态相位如何统一进 MetricLadder 的 M₀/M₁，并与 v7 的 τᵢ(t)、γ_grasp 兼容而不破坏 50Hz WCET？
- **Q3（公共模式）**：当多个任务同时失效时，如何区分「任务本身变难」与「共享主干坏了」？熔断器如何在有限延迟内做出判断且不误伤？
- **Q4（双速率时序）**：50Hz 多任务外环与 ≥500Hz 平衡内环如何切分，才能同时满足 WCET 与「外环两次更新之间仍安全」？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 共享主干—隔离适配器（Shared Trunk, Isolated Adapters, STIA）**
```
f_φ : x ↦ z                       # 全局共享主干
g_ψk : z × e_k ↦ z_k              # 任务私有适配器
h_θk : z_k ↦ y_k                  # 任务私有头
K = {intent, grasp, emotion, metric, gait, balance-risk}
```
主干参数 φ 全局共享；适配器 ψk 与头 θk 任务私有；新增任务只加适配器与头，默认**冻结 φ**，从而把「持续增任务」的遗忘压到零（见引理 82）。

**P11 平衡即硬约束（Balance-as-Hard-Constraint, BaHC）**
```
M₀^bal : ZMP(t) ∈ S(t) ∧ d(CoM_xy, ∂S(t)) ≥ ε_c
       ∧ f_c(t) ∈ [f_min, f_max] ∧ phase_consistent(t)
```
由独立守护者 G_bal 以 Δt_in 周期验算；不满足 ⇒ 姿态级退化（P12），而不是先调软阈值。

**P12 姿态级退化（Posture-Level Degradation, PLD）**
```
δ_bal : 任意 M₁/M₂/M₃^bal 违背或 G_bal 报 fail
      ⇒ 进入 double-support stand（双脚着地、步态相位冻结、基座锁定、速度归零）
```
PLD 是 v7「1 跳退化到 M₀」在双足上的物理实现：不是把阈值调小，而是把身体放到一个静态可稳的姿态。

**P13 公共模式熔断（Common-Mode Circuit Breaker, CMCB）**
```
若 |{k : violation_k}| ≥ q  或  conf(f_φ) < c_min  或  Î_common > I_max
⇒ 冻结 OTL 与共享分支；逐任务切到 v7 模块；仅保留 G_bal + PLD
```
熔断策略必须「宁可误熔断、不可漏熔断」：在双足上，漏熔断的代价是摔倒，误熔断的代价只是一次保守回退。

## 3. 与基线的接口（如何退化）

- 共享主干不可用/低置信 ⇒ 逐任务回退 v7 模块（OTL/GCT/ER 各自可用则继续用）；
- 某任务适配器失效 ⇒ 仅该任务回退 v7 对应模块，其余任务不受影响；
- 平衡守护者失效 ⇒ 立即 PLD 双支撑站立并锁定基座（最保守分支）；
- 情感/抓取/语音模块失效 ⇒ 与 v7 相同：β = 0 / 跳过 γ_grasp / ι ← ι₀；
- 双速率调度失效 ⇒ 外环降为 25Hz 并扩大平衡裕度，内环保持独立运行。

## 4. 预期贡献

1. **STIA**：把 v7 的六模块统一进共享主干，同时用任务适配器把任务间干扰局部化到可界定范围；
2. **BaHC/PLD**：把双足动态平衡作为一等硬约束，并给出「姿态级退化」这一可恢复退化范式；
3. **CMCB**：显式建模单模型多任务的公共失效模式，给出可在线计算的熔断判据与误报界；
4. **双速率安全架构**：外环多任务 + 内环独立几何守护，给出「外环延迟内仍安全」的时序契约；
5. 完整实验覆盖干扰、公共模式、平衡、双速率与端到端：E526–E540。

## 5. 本轮最大风险

**一句话**：单模型的共享主干把原本独立的多个失效点合并成一个公共失效模式，而双足的动态不稳定性让这个公共失效直接等价于摔倒——若独立几何守护者所依赖的力/位姿估计本身有偏，系统就会同时失去「多任务统一」与「安全可证」这两个承诺。

# 第 8 轮产物 · 创新点清单 v8：**MetricVoiceGauge-OMT-BR**（One-Model-Multi-Task × Bipedal Robot）

> 背景：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮灵感：「单模型多任务」×「双足机器人」
> **继承纪律**：v7 六不变式（CVC-闭环、SpatialCert、RT-CVC 任务模型、FaultCert 闭环、PrimitiveGraph 接地、严格退化链）全部保留。STIA/BaHC/PLD/CMCB 均为**可选增强**：任一环节不可用 ⇒ 逐任务退回 v7，平衡相关增强不可用时退回最保守的双支撑站立。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进（相对 MetricVoiceGauge-OTL-GC-ER v7） |
|---|---|---|---|
| IP-350 | SharedTaskTrunk 共享任务主干 | 新增模块 | 单一主干 f_φ 同时服务 intent/grasp/emotion/metric/gait/balance-risk 六个任务，参数共享 |
| IP-351 | TaskAdapterBank 任务适配器组 | 新增模块 | 每任务 LoRA/FiLM 适配器 g_ψk 与轻量头 h_θk，任务间表示隔离；新增任务冻结主干 |
| IP-352 | InterferenceMonitor 干扰监测器 | 新增模块 | 在线估计任务梯度余弦与输出敏感度，构造干扰矩阵 Î，超界即隔离任务 |
| IP-353 | BipedalBalanceLayer 双足平衡指标层 | 新增模块 | 把 ZMP/CoM/捕获点/接触力/相位纳入 M₀^bal–M₃^bal，并并入 v7 的 MetricLadder |
| IP-354 | IndependentBalanceGuardian 独立平衡守护者 | 新增模块 | 非学习几何/动力学检查器，≥500Hz 独立验算；学习模型不得自证安全 |
| IP-355 | PostureDegradationController 姿态级退化控制器 | 新增模块 | 任意平衡软层违背 ⇒ double-support stand，可恢复、可审计 |
| IP-356 | CommonModeCircuitBreaker 公共模式熔断器 | 新增模块 | 以「同时违背任务计数 + 主干置信 + 公共干扰」判据切断共享分支，冻结 OTL |
| IP-357 | DualRateScheduler 双速率调度器 | 新增模块 | 内环 ≥500Hz 守护 + 外环 50Hz 多任务；给出两环之间的时序契约 |
| IP-358 | MultiTaskSoftCert 多任务软证书 | 升级 | 每任务 SoftCert_k 叠加共享主干证书 (φ, σ_φ, I_max)，逐任务可独立失效 |
| IP-359 | GaitCommandTyping 步态命令类型化 | 新增模块 | 语音→{stand, walk_slow, walk_fast, turn, stop}，并做平衡包络可行性检查 γ_gait |
| IP-360 | OMT-BR 主闭环集成 | 集成 | v7 闭环外挂 STIA；共享分支与独立守护者双轨并行，任一失败按退化链降级 |

**退化链声明**：
- SharedTaskTrunk 失效或低置信 ⇒ 逐任务退回 v7 模块化实现（OTL/GCT/ER 各自保持可用）；
- TaskAdapterBank 中某适配器失效 ⇒ 仅该任务回退 v7，其余任务不受影响；
- BipedalBalanceLayer / IndependentBalanceGuardian 失效 ⇒ 立即 PLD 双支撑站立并锁定基座；
- CommonModeCircuitBreaker 触发 ⇒ 冻结 OTL 与共享分支，整体退回 v7 + 平衡守护；
- GaitCommandTyping 失效 ⇒ 退回 v7 的 VoiceCommandTyping，步态命令降级为 stand。

## 1. 符号体系增量（定义 530–540）

| 符号 | 含义 |
|---|---|
| `f_φ : X → Z` | 共享任务主干（参数 φ 全局共享） |
| `e_k, g_ψk, h_θk` | 任务嵌入、任务适配器、任务头 |
| `K = {intent, grasp, emotion, metric, gait, balance-risk}` | 任务集合 |
| `I_{jk}` | 任务 k 的参数更新对任务 j 输出的干扰上界 |
| `Î_common` | 公共模式干扰估计（多任务共享方向上的输出漂移占比） |
| `ZMP(t)` | 零力矩点 |
| `S(t)` | 足底支撑多边形 |
| `ξ(t) = CoM_xy + v_CoM / ω₀` | 捕获点，`ω₀ = sqrt(g / h_CoM)` |
| `M^bal = (M₀^bal, M₁^bal, M₂^bal, M₃^bal)` | 双足平衡指标层 |
| `G_bal` | 非学习独立平衡守护者 |
| `s_ds` | 双支撑站立姿态（double-support stand） |
| `q, c_min, I_max, N_d` | CMCB 的违背计数阈、置信阈、干扰阈、驻留周期 |
| `Δt_in, Δt_out` | 内环/外环周期（默认 2ms / 20ms） |
| `γ_gait(ι)` | 步态指令在当前平衡裕度下的可行性判据 |

**定义 530（共享任务主干 SharedTaskTrunk）** 单一主干加任务私有变换：
```
z      = f_φ(x)
z_k    = g_ψk(z, e_k)
y_k    = h_θk(z_k),          k ∈ K
Θ      = φ ∪ {ψ_k, θ_k}_{k∈K}
```
默认训练/部署纪律：φ 冻结，仅更新 ψ_h、θ_k；需要联合微调时，φ 的学习率乘以共享保护系数 λ_φ ≪ 1。

**定义 531（任务干扰矩阵 InterferenceMatrix）** 对任务对 (j,k)：
```
I_{jk} = sup_{x∈D} ‖y_j(x; Θ + Δ_k) − y_j(x; Θ)‖ / ‖Δ_k‖
```
在线可计算代理（一阶）：
```
ρ_{jk} = ⟨∇_φ L_j, ∇_φ L_k⟩ / (‖∇_φ L_j‖ · ‖∇_φ L_k‖)
Î_{jk} ≈ η · ‖∇_φ L_k‖ · Lip(h_θj ∘ g_ψj)
```
ρ_{jk} → 1 表示两任务在主干上争夺同一方向（强干扰），ρ_{jk} ≈ 0 表示近正交（低干扰）。

**定义 532（公共模式统计量 CommonModeStatistic）** 令 v_k ∈ {0,1} 为任务违背指示：
```
CM(t) = max( (Σ_{k∈K} v_k) / |K| ,  1 − conf(f_φ) ,  Î_common / I_max )
```
当 CM(t) ≥ 1 或同时违背任务数 ≥ q 且持续 N_d 个外环周期，触发 CMCB。

**定义 533（双足平衡硬约束 BipedalBalanceConstraint）** 记足底接触力 f_i、接触点 p_i：
```
ZMP_x = Σ_i (x_i f_i^z − z_i f_i^x) / Σ_i f_i^z
ZMP_y = Σ_i (y_i f_i^z − z_i f_i^y) / Σ_i f_i^z
B(s) = [ZMP ∈ S] ∧ [d(CoM_xy, ∂S) ≥ ε_c] ∧ [f_i^z ≥ f_min]
       ∧ [ξ ∈ S ⊕ S_margin] ∧ [phase_consistent]
```

**定义 534（双足平衡指标层 BipedalBalanceLayer）**
```
M₀^bal : B(s) = true                                   # 硬约束
M₁^bal : normalized margin = d(CoM_xy, ∂S) / ε_c        # 安全裕度
M₂^bal : CoT = E_gait / (m g Δx) + slip_penalty         # 步态能效
M₃^bal : jerk_rms + phase_smoothness                    # 步态自然度
全局硬约束：M₀ = M₀^{v7} ∧ M₀^bal
```
平衡层的软层（M₁–M₃^bal）可被 OTL 在线调节，但 M₀^bal 永不参与阈值学习。

**定义 535（独立平衡守护者 IndependentBalanceGuardian）** 非学习映射：
```
G_bal : (q_joint, τ_joint, f_contact, IMU) → {pass, fail, margin}
运行周期 Δt_in ≤ 2ms；以保守过近似判定稳定域：G_bal = pass ⇒ B(s) = true。
```
守护者的参数只允许来自解析模型与离线标定，禁止用共享主干反向训练，以保证**证书独立性**。

**定义 536（姿态级退化 PostureDegradation）** 从任意状态到双支撑站立的映射：
```
δ_bal : s ↦ s_ds = (feet_flat, CoM_xy = centroid(S),
                    v_CoM = 0, ω_body = 0, gait_phase = frozen)
恢复条件：B(s_ds) = true 连续 N_hold 个内环周期，且外环显式 re-enable。
```

**定义 537（公共模式熔断器 CommonModeCircuitBreaker）** 三态状态机：
```
CLOSED  → 正常；执行 STIA + OTL
OPEN    → CM(t) ≥ 1 或 (Σv_k ≥ q 持续 N_d)：切断共享分支、冻结 OTL、逐任务回退 v7
HALF_OPEN → 冷却 N_c 周期后仅接通单任务试探；连续 N_ok 成功才回 CLOSED
```

**定义 538（双速率时序契约 DualRateContract）**
```
内环：T_in ≤ Δt_in = 2ms（G_bal + PLD，硬实时）
外环：T_out ≤ Δt_out = 20ms（STIA + OTL + 规划，软实时）
契约：latency_outer + T_pred ≤ Δt_out，且外环两次更新之间由内环独立维持 B(s)。
```

**定义 539（多任务软证书 MultiTaskSoftCert）** 证书成立当且仅当逐任务证书与主干证书同时成立：
```
Cert(t) = ( ∧_{k∈K} Cert_k ) ∧ Cert_trunk
Cert_k     = (layer_k, σ_k, δ_trigger,k)
Cert_trunk = (φ, σ_φ, I_max)
任一 Cert_k 失效 ⇒ 仅该任务回退 v7；Cert_trunk 失效 ⇒ CMCB(OPEN)。
```

**定义 540（步态命令类型化 GaitCommandTyping）** 语音意图到步态原语的可行映射：
```
ℓ_voice → ASR → text → GaitNLI → g ∈ {stand, walk_slow, walk_fast, turn, stop}
γ_gait(ι) = feasible(v_cmd, ω_cmd, stride) given (S, margin, f_min)
若 γ_gait = false ⇒ 裁剪到安全包络内；若裁剪后仍不可行 ⇒ ι ← stand
```

## 2. 形式化定义（要点）

**定义 493′（指标层级闭合，平衡扩展）** MetricLadder 扩展为 M = (M₀, M₁, M₂, M₃)，其中 M₀ = M₀^{v7} ∧ M₀^bal；τᵢ(t) 仍由 OTL 在线调节，但 i ∈ {1,2,3} 仅在语义/效能层生效，硬约束 τ₀ 与平衡阈值不参与学习。

**定义 494′（语音指令类型化，步态扩展）** VoiceCommandTyping 后接 GaitCommandTyping：π_voice = (ASR, NLI, GaitNLI)，若识别为移动指令则先过 γ_gait，再进入 v7 的抓取/几何检查。

**定义 495′（奖励可逆向性，平衡项）** 奖励分解扩展一项：
```
R(s,a) = Σ_{i=0}^{3} w_i(s) · r_i(s,a) + w_bal(s) · r_bal(s,a)
r_bal = −λ_zmp · max(0, ε_c − margin) − λ_slip · slip − λ_jerk · jerk_rms
```
w'_i 仍按 v7 的情感/风险 softmax 计算；w_bal 不参与情感调节（安全项不随情绪放松）。

**定义 521′（在线阈值调节，受限版）** OTL 仅作用于 M₁–M₃^{v7} 与 M₁–M₃^bal；当 CMCB 处于 OPEN 或 CM(t) ≥ 1 时，OTL 被冻结（`freeze-and-hold`），避免公共模式下的阈值崩塌。

**定义 529′（软硬约束无缝衔接，双足版）**
```
δ_trigger = {σ < τ_safe} ∨ {γ_grasp invalid} ∨ {margin < ε_c}
退化目标 = v7 硬约束 ∧ B(s_ds)
```
证明要点：δ_trigger 的每一项都与某个硬约束判据同尺度；PLD 将状态投影到 s_ds，而 s_ds 属于 M₀^bal 的内部（静态稳定），故退化后硬约束必然满足。

import numpy as np


class SharedTaskTrunk:
    """IP-350/351：共享主干 + 任务适配器 + 轻量头。主干默认冻结。"""

    def __init__(self, trunk, adapters, heads, task_emb):
        self.f = trunk                 # z = f_phi(x)
        self.adapters = adapters       # {k: g_psik(z, e_k)}
        self.heads = heads             # {k: h_thetak(z_k)}
        self.e = task_emb              # {k: e_k}
        self.trunk_frozen = True

    def forward(self, x, tasks=None):
        z = self.f(x)
        tasks = tasks or list(self.heads)
        out = {}
        for k in tasks:
            z_k = self.adapters[k](z, self.e[k])
            out[k] = self.heads[k](z_k)
        return z, out


class InterferenceMonitor:
    """IP-352：在线干扰估计 + 任务隔离建议。"""

    def __init__(self, tasks, i_max=0.35, window=32):
        self.tasks = list(tasks)
        self.i_max = i_max
        self.window = window
        self.grad_hist = {k: [] for k in self.tasks}

    def observe(self, task, grad_phi):
        h = self.grad_hist[task]
        h.append(grad_phi / (np.linalg.norm(grad_phi) + 1e-9))
        if len(h) > self.window:
            h.pop(0)

    def matrix(self):
        I = {}
        for j in self.tasks:
            for k in self.tasks:
                if j == k or not self.grad_hist[j] or not self.grad_hist[k]:
                    continue
                gj = np.mean(self.grad_hist[j], axis=0)
                gk = np.mean(self.grad_hist[k], axis=0)
                I[(j, k)] = float(abs(gj @ gk) /
                                  (np.linalg.norm(gj) * np.linalg.norm(gk) + 1e-9))
        return I

    def isolate(self):
        """返回需要隔离（改用 v7 模块）的任务集合。"""
        I = self.matrix()
        bad = set()
        for j in self.tasks:
            if any(v > self.i_max for (jj, _), v in I.items() if jj == j):
                bad.add(j)
        return bad


class BipedalBalanceGuardian:
    """IP-354：非学习、保守过近似的平衡守护者（≥500Hz）。"""

    def __init__(self, eps_c=0.03, f_min=20.0, margin_s=0.02):
        self.eps_c = eps_c
        self.f_min = f_min
        self.margin_s = margin_s

    def _zmp(self, contacts):
        num_x = sum(p[0] * f[2] - p[2] * f[0] for p, f in contacts)
        num_y = sum(p[1] * f[2] - p[2] * f[1] for p, f in contacts)
        den = sum(f[2] for _, f in contacts) + 1e-9
        return np.array([num_x / den, num_y / den])

    def _inside(self, zmp, polygon):
        # 支撑多边形为凸：叉积同号即在内（含边界）
        signs = []
        n = len(polygon)
        for i in range(n):
            a = np.array(polygon[i]); b = np.array(polygon[(i + 1) % n])
            cross = (b[0] - a[0]) * (zmp[1] - a[1]) - (b[1] - a[1]) * (zmp[0] - a[0])
            signs.append(cross)
        return all(s >= -1e-9 for s in signs) or all(s <= 1e-9 for s in signs)

    def _dist_to_boundary(self, zmp, polygon):
        best = np.inf
        n = len(polygon)
        for i in range(n):
            a = np.array(polygon[i]); b = np.array(polygon[(i + 1) % n])
            ab = b - a
            t = np.clip(np.dot(zmp - a, ab) / (np.dot(ab, ab) + 1e-12), 0.0, 1.0)
            best = min(best, np.linalg.norm(zmp - (a + t * ab)))
        return best

    def check(self, contacts, polygon, com_xy, com_v, phase_consistent):
        if any(f[2] < self.f_min for _, f in contacts):
            return False, 0.0
        zmp = self._zmp(contacts)
        if not self._inside(zmp, polygon):
            return False, 0.0
        margin = self._dist_to_boundary(com_xy, polygon)
        if margin < self.eps_c:
            return False, margin
        g, h = 9.81, max(com_xy[2] if len(com_xy) > 2 else 0.9, 0.3)
        omega0 = np.sqrt(g / h)
        capture = np.array(com_xy[:2]) + np.array(com_v[:2]) / omega0
        if not self._inside(capture, polygon):
            return False, margin
        if not phase_consistent:
            return False, margin
        return True, margin


class PostureDegradationController:
    """IP-355：姿态级退化到双支撑站立。"""

    def __init__(self, n_hold=50):
        self.n_hold = n_hold
        self.active = False
        self.hold = 0

    def trigger(self):
        self.active = True
        self.hold = 0
        return {"feet_flat": True, "v_cmd": 0.0,
                "omega_cmd": 0.0, "gait_phase": "frozen", "lock_base": True}

    def update(self, balance_ok):
        if not self.active:
            return None
        if balance_ok:
            self.hold += 1
            if self.hold >= self.n_hold:
                self.active = False
                return "release"
        else:
            self.hold = 0
        return "hold_double_support"


class CommonModeCircuitBreaker:
    """IP-356：公共模式熔断三态机。"""

    CLOSED, OPEN, HALF_OPEN = "closed", "open", "half_open"

    def __init__(self, q=3, c_min=0.35, i_max=0.35, n_d=3, n_c=25, n_ok=5):
        self.q, self.c_min, self.i_max = q, c_min, i_max
        self.n_d, self.n_c, self.n_ok = n_d, n_c, n_ok
        self.state = self.CLOSED
        self.bad_streak = 0
        self.cool = 0
        self.ok = 0

    def step(self, violations, trunk_conf, i_common):
        n_bad = int(sum(1 for v in violations.values() if v))
        common = (n_bad >= self.q) or (trunk_conf < self.c_min) or (i_common > self.i_max)
        if self.state == self.CLOSED:
            self.bad_streak = self.bad_streak + 1 if common else 0
            if self.bad_streak >= self.n_d:
                self.state = self.OPEN
                self.cool = self.n_c
        elif self.state == self.OPEN:
            self.cool -= 1
            if self.cool <= 0:
                self.state = self.HALF_OPEN
                self.ok = 0
        else:  # HALF_OPEN
            if common:
                self.state = self.OPEN
                self.cool = self.n_c
                self.ok = 0
            else:
                self.ok += 1
                if self.ok >= self.n_ok:
                    self.state = self.CLOSED
                    self.bad_streak = 0
        return self.state

    @property
    def shared_branch_enabled(self):
        return self.state == self.CLOSED


class GaitCommandTyping:
    """IP-359：语音→步态原语，并用当前平衡裕度做可行性检查。"""

    ENVELOPE = {"stand": (0.0, 0.0), "walk_slow": (0.25, 0.2),
                "walk_fast": (0.6, 0.3), "turn": (0.1, 0.6), "stop": (0.0, 0.0)}

    def parse(self, text, margin, eps_c):
        t = text.lower()
        if any(w in t for w in ["停", "stop", "halt"]):
            g = "stop"
        elif any(w in t for w in ["转身", "turn"]):
            g = "turn"
        elif any(w in t for w in ["快", "fast", "run"]):
            g = "walk_fast"
        elif any(w in t for w in ["走", "walk", "forward", "前进"]):
            g = "walk_slow"
        else:
            g = "stand"
        v, w = self.ENVELOPE[g]
        # 裕度越低，允许的速度/角速度越小
        scale = float(np.clip((margin - eps_c) / max(eps_c, 1e-6), 0.0, 1.0))
        feasible = scale > 0.0 or g in ("stand", "stop")
        if not feasible:
            return "stand", (0.0, 0.0), False
        return g, (v * scale, w * scale), True


def omt_br_step(M, s, obs, voice_text="", trunk=None, monitor=None,
                guardian=None, pld=None, cmcb=None, gait=None,
                v7_modules=None, dt_in=0.002):
    """IP-360：双速率 OMT-BR 主闭环（外环 50Hz，内环由独立线程按 dt_in 跑 G_bal）。"""

    v7_modules = v7_modules or {}

    # ---------- 内环（概念上由独立线程以 ≥500Hz 调用）----------
    contacts = M.estimate_contacts(s)
    polygon = M.support_polygon(s)
    com_xy = M.estimate_com(s)
    com_v = M.estimate_com_velocity(s)
    ok_bal, margin = guardian.check(contacts, polygon, com_xy, com_v,
                                    M.phase_consistent(s))
    if not ok_bal:
        cmd = pld.trigger()
        return {"mode": "PLD", "cmd": cmd, "margin": margin,
                "state": cmcb.state if cmcb else "disabled"}

    # ---------- 外环 ----------
    z, heads = ({}, {})
    if trunk is not None and (cmcb is None or cmcb.shared_branch_enabled):
        z, heads = trunk.forward(obs)

    # 1) 任务级证书 + 公共模式熔断
    violations = {}
    if heads:
        violations = {
            "intent": not M.intent_ok(heads.get("intent")),
            "grasp": not M.grasp_ok(heads.get("grasp")),
            "emotion": not M.emotion_ok(heads.get("emotion")),
            "metric": not M.metric_ok(heads.get("metric")),
            "gait": not M.gait_ok(heads.get("gait")),
        }
    i_common = float(np.mean(list(monitor.matrix().values()))) if monitor else 0.0
    state = cmcb.step(violations, M.trunk_conf(heads), i_common) if cmcb else "disabled"

    # 2) 共享分支被切断 / 某任务被隔离 ⇒ 该任务回退 v7
    disabled = set()
    if state == "open":
        disabled = set(violations)
    elif monitor is not None:
        disabled = monitor.isolate()

    # 3) 语音→步态（受当前平衡裕度约束）
    gait_cmd, feasible = "stand", True
    if voice_text:
        gait_cmd, (v_cmd, w_cmd), feasible = gait.parse(voice_text, margin, guardian.eps_c)
        if not feasible:
            gait_cmd = "stand"

    # 4) v7 模块作为逐任务兜底；平衡项不交给情感/OTL
    out = {"mode": state, "margin": margin, "gait": gait_cmd,
           "feasible": feasible, "disabled": sorted(disabled)}
    for task, fallback in v7_modules.items():
        out[task] = fallback(s, obs) if task in disabled else heads.get(task)
    return out

## 4. 推导

**引理 77（任务干扰上界）** 设适配器 g_ψj 为 L_j-Lipschitz、头 h_θj 为 L_h,j-Lipschitz，主干更新满足 ‖Δφ‖ ≤ ε_φ。则任务 j 的输出变化满足
```
‖Δy_j‖ ≤ L_h,j · L_j · ( L_f · ‖Δφ‖ + ‖Δψ_j‖ + ‖Δθ_j‖ )
```
且当 φ 冻结、仅更新任务 k≠j 的 (ψ_k, θ_k) 时，对任务 j 的**一阶干扰为 0**；若共享归一化统计量（BN）被更新，则残留干扰 ≤ L_h,j L_j · δ_BN。故「冻结主干 + 任务私有归一化」可把跨任务干扰压到可忽略；否则可用 Î_{jk} 在线界定。

**引理 78（公共模式可检测性）** 设无公共故障时各任务违背独立，违背率 p_k；公共故障下同时违背任务数至少 q，且单个任务漏检概率 ≤ δ。令 V = Σ_k v_k。则
```
E[V | 公共故障] ≥ q(1−δ),    E[V | 无公共故障] = Σ_k p_k
```
取阈值 q' ∈ (Σp_k, q(1−δ))，由 Chernoff 界，误报率 ≤ exp(−D(q'‖Σp_k)·|K|)。因此在条件独立假设下，「同时违背计数」是公共模式的充分统计量；CMCB 的计数判据不是启发式，而是有误报界的假设检验。当任务噪声强相关时该假设失效，需叠加「主干置信」与 Î_common 两个证据（本设计的三证据熔断正是为此）。

**引理 79（守护者健全性 / 证书独立性）** 若 G_bal 是真实稳定域的**保守过近似**（G_bal = pass ⇒ B(s) = true），且执行器指令必须经 G_bal 放行，则任何学习模型（含共享主干）的输出误差都不能直接造成 M₀^bal 违背：误差只能改变性能，不能改变硬安全。证明：设学习模型输出 a，执行前被替换为 a′ = Gate(a)，其中 Gate 仅在 G_bal(pass) 时放行 a；由于 G_bal 保守，B(s) 始终成立。故安全证明不依赖学习模型的正确性——这正是把平衡从「学出来的能力」变成「可证伪的约束」的关键。

**引理 80（双速率安全）** 设内环周期 Δt_in 内 CoM 位移上界为 ε_in(Δt_in)（由加速度与扰动界给出），且内环在每个周期都保持 d(CoM_xy, ∂S) ≥ ε_c。则外环任意延迟 ≤ Δt_out 期间，平衡裕度始终 ≥ ε_c − ε_in(Δt_in) > 0。证明：外环只改变任务目标与软权重，不直接写执行器；内环按周期重新验算并可在任意周期触发 PLD。故外环延迟只影响任务质量，不影响硬安全。工程条件：Δt_in 需满足 ε_in(Δt_in) < ε_c，默认 2ms 对应 ε_in ≈ 3mm ≪ ε_c = 30mm。

**引理 81（逐任务退化等价）** 若 STIA 被禁用或 CMCB 处于 OPEN，则每个任务 k 调用 v7 对应模块，系统在该任务上的行为与 v7 等价；若 G_bal 失效，则 PLD 把状态投影到 s_ds，而 s_ds 是静态稳定姿态（ZMP 位于支撑多边形质心、v = 0），故 B(s_ds) = true。因此任意子集失效都导致「v7 等价」或「更保守」，不产生级联崩溃。

**引理 82（持续增任务的无遗忘性）** 在 φ 冻结、每任务独立归一化的条件下，新增任务 k 只增加 (ψ_k, θ_k)，不改变任何既有 z_j = g_ψj(f_φ(x), e_j)，故既有任务输出逐点不变（零遗忘，而非近似零）。若需联合微调 φ，则遗忘上界由引理 77 给出，并可用 Î_{jk} 监控。
