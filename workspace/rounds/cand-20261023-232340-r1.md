## 0. 本轮结论

这一轮我把上一轮的判断又往前推了一步：**SPA-VLA 的“部件语义”仍然对，但它已经从主押注降为底座；本轮真正的主押注是“传动/接触残差”**。

**本轮思考路径**：先重读规则/榜单（确认能不能用分数）→ 再读提交 README（确认模型能拿到什么信号）→ 再抽样 HangCup 数据（确认 action/state/current/夹爪约定）→ 再查 G1 传动（确认灵感词是否成立）→ 再读两篇本体触觉论文（确认技术路线）→ 最后做取舍（SPA 降级、PWM/CMT/CRP 升级）。

具体地说，我把“谐波减速器”这个灵感词查了一遍，发现 G1 的肩/肘并不是谐波减速器，而是两级行星减速（约 15:1、可背驱、输出端测位置）。这反而把问题问得更清楚了：**比赛用的 G1 我们改不了硬件，能改的只有“如何从位置接口里读出接触”**。于是本轮提出 **TAC-VLA（Transmission-Aware Contact VLA）**：

- 用**关节空间世界模型 PWM** 预测“如果没有接触，下一帧关节应该在哪里”，把 raw residual 变成**接触 surprise**；
- 用**接触模式 token CMT** 把 free / grasp / constrained / human / slip / collision / lost 变成动作头的条件；
- 用**柔顺参考 CRP** 在位置接口上实现“遇到阻力就退一点”的力控效果；
- 用**机器人指纹适配 RFA** 处理多台 G1 的摩擦/回差/PD 增益差异；
- SPA-VLA 保留为**语义层**（K=8 部件 query、2D centroid + 腕部近景，不做全 3D PartSAM）；RPSM 保留为**记忆/撤销恢复层**；Compliance / Endurance / Portfolio 保留为 P1/P2 的“防归零”工程。

一句话：**语义告诉模型“抓哪里”，传动残差告诉模型“现在到底碰到了没有、该不该退”；后者才是接触任务最后几毫米的胜负手。**

### 1.3 G1 传动：不是谐波，问题反而更清楚了

第三方拆解（humanoid.guide，2026-09-13）称 G1 的肩/肘是**两级行星减速，约 15:1**，可背驱，输出端测位置；为了背驱和成本，回差/柔度是权衡项；腕部具体传动未核实。

这条事实很重要，因为它推翻了一个很容易犯的错误：**不要写“针对谐波减速器的回差补偿”**。比赛机器人不是谐波，而且我们也不能改硬件。正确的抽象是：

> **传动感知残差（transmission-aware residual）**：不管减速器是行星还是谐波，位置接口都会把“指令位置”和“实际位置”之间的差异暴露出来；这个差异里包含跟踪滞后、摩擦、回差、柔度、接触力。用一个动作条件的动力学模型把“无接触时应有的滞后”预测出来，剩下的才是接触/传动的 surprise。

这个抽象同时满足三个约束：硬件无关、只用 API 给的位置信号、能在单模型里实现。

### 1.4 接口：没有 current/torque/depth，chunk 还是开环的

README 的 observation 只有：

- 4 路 RGB：`cam_left_high`、`cam_right_high`、`cam_left_wrist`、`cam_right_wrist`（480×640×3 uint8）；
- 左右臂关节 7 维、左右 EE pose + gripper 6 维、左右 gripper 1 维、`lower_body` 15 维、语言字符串；
- **没有 motor current、没有 torque、没有 depth、没有相机内参/外参**。

action 可以是 joint 或 EE：左右臂各 7 维、左右 gripper 各 1 维、`action.pivot` 7 维、`meta.token`；`action_chunk_size` 固定 ≥1；**evaluator 按 chunk 开环执行；在再次调用 `get_action` 之前，chunk 内没有逐帧反馈**。

这带来一个很硬的推论：

| chunk 大小 | 控制 30Hz 时的策略频率 | 一个 chunk 的执行时间 | 接触最后几毫米的反馈 |
|---|---|---|---|
| 1 | 30Hz | 33ms | 每步都能改，但推理必须 <33ms |
| 4 | 7.5Hz | 133ms | 133ms 开环 |
| 8 | 3.75Hz | 267ms | 267ms 开环 |
| 16 | 1.875Hz | 533ms | 533ms 开环 |

**如果 chunk=8，策略在接触阶段其实是 3.75Hz 的“盲走”**；插头、拉链、拧盖这种任务，267ms 足够把很小的对齐误差放大成失败。大 VLA + 大 chunk 的组合在语义任务上很强，但在接触任务上会天然吃亏。这不是“模型不够大”，而是**接口把反馈频率锁死了**。

因此本轮把 chunk 当成一等设计变量：

- 接触阶段优先 **chunk=1 或 2**，用蒸馏/小头/缓存把单步推理压到 33–66ms；
- 自由空间可以用 **chunk=4–8** 提速；
- 训练时做 **chunk-size dropout**，让同一个模型能根据 `meta` 或内部接触模式切换 chunk；
- 如果平台不允许动态 chunk，就固定 chunk=2–4，并把“接触时的柔顺”放进动作本身（CRP），而不是指望 chunk 内反馈。

### 1.5 数据：action 是目标位置，state 是测量值，且没有 current

HangCup 样本（1043 episodes / 194,564 frames，LeRobot v3、Apache-2.0、30fps、AV1、480×640×3、4 相机）：

- `action` 是**目标关节位置**，`observation.state` 是**测量关节位置**；两者相减就是位置接口的 tracking residual 的近似；
- 没有 motor current/torque；
- gripper 约定 **5.5 开 → 0 合**；在已抽样的 719 个 HangCup episodes 里，右夹爪 719/719 闭合，左夹爪只有 3 次；物件在右手；
- 我做了个粗略残差分析：右臂 `a_{t-1} − q_t` 的 mean|.| 约 0.017–0.039 rad，p95 约 0.03–0.09 rad；右夹爪闭合瞬间的残差中位数约为闭合前的 **2.3×**。

但这不是“接触检测器”的证据：**残差在快速运动时也会变大**，raw residual 被运动/跟踪滞后严重混淆。直接设阈值会在每次加速时误触发。正确的做法是：

1. 用历史 `(q, q̇, a)` 训练一个**动作条件的下一帧关节预测器** `f`；
2. 用 `q_next − f(q, q̇, a)` 作为 residual；
3. 这个 residual 才是“模型没预料到的阻力/接触”，而不是“我刚才动得快”。

这就是 PWM 的直接动机。它也解释了为什么“谐波减速器”这个灵感词最后落在了**世界模型**上：不是去造一个更好的减速器，而是去学一个“没有接触时机器人会怎么动”的世界模型。

### 1.6 论文证据：本体感受确实能当触觉用

- **Blind Dexterity**（arXiv 2608.29487）：在 G1 上用纯本体感受做灵巧操作；把“上一帧指令关节目标 + 测量关节角”的残差当作力矩/接触信号；50Hz；作者称关节编码器可以当全身触觉通道。它支持“位置残差里有接触信息”，但没有解决“残差被运动混淆”的问题。
- **Current as Touch**（arXiv 2607.03529）：用 motor current + joint states 预测 compliance reference position，通过 PD 位置接口实现力控；G1 Dex3；10 帧历史、10 帧 chunk；在插拔/接触任务上比纯位置基线更好。它支持“位置接口 + 残差/电流可以做出柔顺”，但**比赛 API 没有 current**，所以我们要把电流换成本体残差 + 视觉。

本轮的新意不是“残差里有接触”（这一点两篇论文已经证明），而是：

> **在只有位置接口、没有 current/torque、chunk 还是开环的比赛约束下，用一个动作条件的关节世界模型把残差去卷积，再把 contact mode + compliance reference 塞进同一个 VLA checkpoint。**

### 1.7 难度与统计：不要把 1–2pp 当信号

- 32 任务难度：Easy 12、Medium 12、Hard 8。
- 320 trials；p≈0.3 时总平均成功率的标准误约 **2.56pp**；3pp 真实优势才有约 80% 概率排名更高，5pp 约 90%。
- 人为干扰占 20%：若 no-human 成功率 p=0.4、human 成功率 q=0，总平均只有 0.32；把 q 提到 p 可加约 **8pp**。
- 所以：**先消灭 0%、再攻人为干扰/未见物品、最后才抠 hard 任务的步骤分**；不要用 1–2pp 的榜单差距做决策。

## 2. 三条灵感词怎么落

| 灵感词 | 字面落点（不采用） | 本轮采用的落点 | 为什么 |
|---|---|---|---|
| 具身智能大模型 | 再训一个更大的 VLA；14B 视频世界模型 | **单 checkpoint 的因子化具身模型**：VLA 语义底座 + PWM 关节世界模型 + CMT/CRP/RFA 头 | 大模型解决语义，但解决不了 267ms 开环接触；因子化头更便宜、更快、可解释 |
| 谐波减速器 | 针对谐波回差做补偿；改硬件 | **传动感知残差**：动作条件动力学预测 + 残差 surprise + 柔顺参考 + 机器人指纹 | G1 不是谐波；我们不能改硬件；残差抽象对行星/谐波都成立 |
| 视觉语言模型 | 运行时调 GPT/Qwen 做规划 | **离线 VLM 任务/部件编译器**：把 5 条复述 + score_steps 编译成谓词图/部件短语；运行时只跑语言编码器 + part queries | 运行时 VLM 延迟/网络/单模型风险高；离线编译保留语义收益 |

这三个落点合起来就是 TAC-VLA 的三层：

1. **语义层**（VLM 离线蒸馏 + 部件 query）：知道“抓哪里、插哪里、现在大概到哪一步”；
2. **物理层**（PWM + CMT + CRP）：知道“有没有碰到、碰到什么、该不该退”；
3. **恢复层**（RPSM + RFA）：知道“人手把状态改回去了、换了一台机器人，怎么重新对齐”。

## 3. 头部方案为什么会在接触上失手

我不掌握真实榜单，所以这里只做架构推演，不点名“谁第几”。

- **大 VLA 的强项是语义泛化**：π0.5、GR00T N1.5、MolmoAct2、WALL-OSS-0.5 这一代的核心是“看得懂、听得懂、跨物体”，不是“知道插头还差 2mm”。
- **视频世界模型的强项是长时预测**：DreamZero 这类 14B、7Hz 的模型能生成未来视频，但 7Hz 对接触伺服太慢，且视频像素不等于力。
- **大 chunk 的强项是吞吐**：一次推理执行 8–16 步，训练/部署都便宜；但接触阶段是开环，误差会累积。
- **没有 current/torque 的强项是接口简单**：平台只给位置，大家都一样；但这也意味着**谁能从位置残差里读出接触，谁就有额外信息**。
- **人为干扰的强项是“看起来像新任务”**：多数策略会把“毛巾被翻开”当成新初始状态，重新做一遍；但 180s 不够重跑，且评分看的是最终状态。

所以头部方案的共同盲区不是“语义不够”，而是：

1. 接触阶段没有高于 chunk 频率的反馈；
2. 没有显式的“接触模式”让策略切换快/慢/柔/退；
3. 没有“状态被撤销”的检测与定向修复；
4. 没有“这台机器人的摩擦/回差和我训练时不一样”的适配。

TAC-VLA 就是对着这四个盲区设计的。

## 4. 新主押注：TAC-VLA

### 4.1 总览

```text
4×RGB ──► visual encoder ──► part queries (K=8) ──► part tokens ─┐
language ─► text encoder ───────────────────────────► task tokens ──┤
proprio ──► history encoder ──► PWM ──► residual ──► CMT ──────────┤
                                 │                    │             ├─► action head ─► chunk
                                 └─► RFA latent ──────┴─► RPSM ─────┘        │
                                                                             ├─► CRP (target adjust)
                                                                             └─► safety clip / watchdog
```

所有块在**同一个 checkpoint**里；SAM3/PartSAM/VLM 只做离线教师；运行时没有第二个模型、没有任务 ID、没有外部 API。

### 4.2 PWM：把 raw residual 变成 contact surprise

- 输入：最近 `H` 帧的 `(q, q̇, a_prev, gripper, ee_pose)`，以及当前 chunk 的 `a`；
- 输出：下一帧（或未来 `K` 帧）的关节/EE 预测；
- 训练：在挑战数据上做一步/多步预测；自由空间样本占多数，接触样本用重加权/难例挖掘；
- 推理：`r = q_next − f(...)`；`r` 的范数/方向/各关节分布 → contact score；
- 关键：**不是预测动作，而是预测“没有接触时机器人会怎么动”**；动作是条件，不是标签；
- 用 FK 把关节残差映射到 Cartesian residual，得到接触方向；用 gripper gap 得到“夹住了没有”；
- 轻量版：PWM 只做 1 步预测、2 层 MLP/GRU，~1–3M 参数，推理 <2ms；重版才用 Transformer。

为什么不是直接用 `a − q`：raw residual 在自由空间也会因为跟踪滞后/摩擦变大；PWM 把“可预测的滞后”减掉，剩下的才是“不可预测的接触”。这是本轮最核心的技术判断。

### 4.3 CMT：接触模式 token

7 个模式：`free`、`grasp`、`constrained`、`human`、`slip`、`collision`、`lost`。

| 证据 | free | grasp | constrained | human | slip | collision | lost |
|---|---|---|---|---|---|---|---|
| PWM residual | 小 | 中 | 大/持续 | 大/突发 | 中/下降 | 大/突发 | 大 |
| gripper gap | 开 | 有物体 | 有物体 | 可能开 | 变大 | 有物体 | 无 |
| 物体运动 | 自由 | 跟随手 | 被约束 | 被人移动 | 掉落 | 突然停 | 不可见 |
| 人手可见 | 否 | 否 | 否 | 是 | 否 | 可能 | 否 |

- 训练：弱标签（gripper gap、物体跟踪、人手检测、残差阈值）+ 少量人工标注关键帧；用软 token/概率，不硬切；
- 用法：CMT embedding 作为 action head 的 FiLM/交叉注意力条件；`human` 时降低速度/让开，`slip` 时重新夹，`constrained` 时减小目标增量，`collision` 时后退再试；
- 它也是 RPSM 的“物理证据”：人手接触可以先于视觉状态变化被检测到。

### 4.4 CRP：在位置接口上做柔顺

动作是目标位置，底层 PD 会跟踪；如果目标一直往物体里推，力会越来越大。CRP 的做法：

```text
a_task = policy(...)                  # 任务目标
r = q_next - PWM(q, qdot, a_task)    # 接触残差
a_ref = a_task - Kc * clamp(r)       # 遇到阻力就退一点
a_out = clip(a_ref, soft_limits)     # 安全限幅
```

- `Kc` 不是手调常数，而是 action head 的一个输出（或由 CMT 条件化）；
- 训练时用演示动作作为监督：演示里“遇到阻力时目标回退”的片段，正是 CRP 的学习目标；
- 因为 action 是位置，CRP 不需要额外力矩接口；它只是把“位置目标”改成“柔顺参考”；
- 单模型：CRP 是 action head 的一部分，不是外挂控制器；这样不违反“不得混合多个模型”。

### 4.5 RFA：机器人指纹适配

- 指纹维度：关节零偏、摩擦、回差、PD 增益、负载质量、相机外参；
- 推断：用一段自由空间运动（episode 开头的安全小动作）的 residual 统计，推断 latent `z_r`；
- 使用：FiLM 调制 PWM/action head；训练时域随机化（质量/摩擦/PD/回差/延迟）+ 多机器人数据（如果有）；
- 为什么重要：比赛是多台机器人；同一策略在不同机器上的 tracking residual 不同，PWM 的阈值会漂；RFA 让“接触 surprise”跨机器可比；
- 最低成本版：不做学习，直接在线减掉自由空间 residual 的均值/方差（1–2s 校准）；这也是 RFA 的 fallback。

### 4.6 SPA-lite：语义底座，不做全 3D

- K=8 个 part queries，输出 2D centroid + mask/visibility + descriptor；**不做全 3D PartSAM**，因为 API 没有相机内参/外参，3D 融合容易错；
- 部件短语由离线 VLM 生成：`handle`、`rim`、`prong`、`socket`、`zipper pull`、`cap`、`key`、`towel corner`、`bowl rim`、`earphone`、`phone`、`pin`、`plunger`、`tool handle`；
- 训练：SAM3/PartSAM 在关键帧生成伪标签；学生只学 centroid/visibility/descriptor，轻量、快；
- 推理：2D centroid + 腕部近景的相对几何 → 抓取点/插入方向；需要深度时用立体匹配或单目深度头，但只作为辅助，不作为主表示；
- 与动作头：part tokens 通过交叉注意力进入 action head；语言 token 负责“哪个部件/哪一步”，part token 负责“在哪里”。

### 4.7 RPSM：撤销检测与定向修复

- 谓词库：`on_hook`、`inserted`、`screwed`、`zipped`、`folded`、`stacked`、`sorted`、`locked`、`plugged`、`filled` 等；
- 输入：part tokens + CMT + 语言；输出：每个谓词的概率/进度；
- 撤销检测：反向播放/状态翻转样本训练 `progress_delta` 头；`human` CMT + 谓词回退 → 触发 repair；
- 修复：只重做被撤销的子目标，不重跑全程；180s 下这是必须的；
- 与 TAC-VLA 的协同：人手把插头拔起时，PWM 先看到 residual 突变，CMT 判 `human`，RPSM 把 `plugged` 置回 false，action head 收到 `repair(plugged)` 条件。

## A. 结论

本轮把上一轮的 **RUBICON 3.0（SPA-VLA + RPSM + Compliance/Endurance/Portfolio）** 升级为 **RUBICON 4.0 / TAC-VLA**：

> **TAC-VLA（Transmission-Aware Contact VLA）**：在单模型 VLA 内加入**动作条件的关节世界模型（PWM）**，把“指令位置 − 实际位置”的残差去卷积成**接触 surprise**；用**接触模式 token（CMT）**条件化动作头；用**柔顺参考（CRP）**在位置接口上实现“遇阻回退”；用**机器人指纹适配（RFA）**处理多台 G1 的摩擦/回差/PD 差异。部件语义（SPA-lite）降为底座，RPSM 保留为撤销恢复层。

三个关键事实支撑这次转向：

1. **比赛 API 没有 motor current / torque / depth**，只有 4 路 RGB + 关节/EE/gripper + 语言；接触信息只能从位置残差和视觉里来。
2. **action chunk 是开环执行的**：chunk=8、30Hz 时策略只有 3.75Hz；接触最后几毫米在 267ms 内没有反馈。大 VLA + 大 chunk 在语义任务上强，在接触任务上天然吃亏。
3. **G1 肩/肘是两级行星减速（约 15:1），不是谐波**；我们不能改硬件。正确的抽象不是“谐波回差补偿”，而是**硬件无关的传动感知残差**。

一句话：**语义决定“抓哪里”，传动残差决定“碰到了没有、该不该退”；后者是接触任务最后几毫米的胜负手。**

### B.5 硬件：G1 不是谐波

第三方拆解（S10，2026-09-13）称：

- 肩/肘为**两级行星减速，约 15:1**；
- 可背驱；输出端测位置；
- 为背驱/成本，回差/柔度是权衡项；
- 腕部具体传动未核实。

**含义**：

- 不要写“谐波减速器回差补偿”；比赛机器人不是谐波，且不能改硬件。
- 正确抽象是**传动感知残差**：行星/谐波都会有指令位置与实际位置的差异，差异里包含跟踪滞后、摩擦、回差、柔度、接触力；用动作条件动力学模型预测“无接触时的滞后”，剩下的才是接触 surprise。
- 这个抽象硬件无关，只用 API 的位置信号，能在单模型里实现。

## C. 评分数学与策略

### C.1 排名口径

- 32 任务 × 10 trials = **320 trials**。
- 总平均成功率优先；步骤分只是 tie-breaker；再同分看提交日期。
- 5 类泛化各 2 次：位置、干扰物、背景、未见物品、人为干扰。
- 人为干扰占 **20%**（64/320）。
- 单任务 10 trials 的成功率粒度是 10pp；单任务 0/10 与 1/10 的差别，对总平均只有 0.3125pp，但对“是否 0%”很关键。

### C.2 统计功效

- p≈0.3 时，320 trials 的总平均成功率标准误：`sqrt(0.3×0.7/320) ≈ 2.56pp`。
- 3pp 真实优势才有约 80% 概率排名更高；5pp 约 90%。
- 1–2pp 的榜单差距是噪声；不要为它改方向。
- 单任务 10 trials 的 95% CI 很宽（0/10 的上界约 26%），所以**不要用单任务小样本做生死决策**；用分层/配对/bootstrap。

### C.3 人为干扰的 20%

设 no-human 成功率 `p`，human 成功率 `q`：

- 总平均 = `0.8p + 0.2q`。
- 若 `p=0.4, q=0` → 0.32；若 `q=p=0.4` → 0.40；**差 8pp**。
- 若 `p=0.3, q=0` → 0.24；`q=p` → 0.30；差 6pp。
- 所以：**把 human 从 0 提到 no-human 水平，是单个最大的杠杆之一**；RPSM/CMT 的价值直接用这个公式算。

### C.4 难度与杠杆

| 难度 | 任务数 | 代表任务 | 策略 |
|---|---|---|---|
| Easy | 12 | T01–T04、T06、T08、T13、T17、T20、T21、T25、T27 | 先消灭 0%；这些是平均成功率的地板 |
| Medium | 12 | T07、T11、T15、T18、T19、T22–T24、T26、T30–T32 | 接触/长程/插入；TAC-VLA 的主战场 |
| Hard | 8 | T05、T09、T10、T12、T14、T16、T28、T29 | 低成功率、低弹性；先保步骤分，不烧太多预算 |

**杠杆排序**：

1. 0% 的 Easy/Medium 任务（边际收益最大）；
2. 人为干扰的 8 个撤销任务（T10/T12/T14/T16/T17/T19/T24/T27）；
3. 未见物品（部件语义泛化）；
4. 接触插入（T05/T10/T12/T14/T19/T26/T32）；
5. Hard 长程（T09/T15/T16/T18/T22/T28）的步骤分。

### C.5 组合优化

用 Beta-Binomial 对每个任务的成功率建模，按“提升总平均成功率的期望/成本”分配预算：

- 先验：Easy 0.55、Medium 0.30、Hard 0.10（仅先验，不是榜单）。
- 每次真机 trial 的成本：约 2–5 分钟（含 reset/干扰/评分）。
- 约束：任务至少 10 trials；human/未见物品各 2 trials；总预算固定。
- 决策：Thompson sampling + 边际收益；对 0% 任务给探索加成；对高方差任务多做几次确认。
- 停止：某任务连续 20 trials 无提升且失败模式相同 → 降级；把预算移到高弹性任务。
- 报告：每个任务的成功率/CI/失败模式；总平均的 bootstrap CI；不要只报一个点估计。

## E. TAC-VLA 架构

### E.1 设计约束

1. **单 checkpoint**：所有头共享 backbone；SAM3/PartSAM/VLM 只做离线教师。
2. **无任务 ID**：只用语言 + 4 路 RGB + proprio；不喂 task slug/one-hot。
3. **无 current/torque**：接触信号只能来自位置残差 + 视觉。
4. **chunk 开环**：策略频率 = 控制频率 / chunk；接触阶段必须小 chunk 或把柔顺放进动作。
5. **N 端口**：后端要并发、隔离、p99 可控。
6. **可审计**：每个头有消融；许可证清晰；无运行时外部 API。

### E.2 总览

```text
4×RGB ──► visual encoder ──► part queries (K=8) ──► part tokens ─┐
language ─► text encoder ───────────────────────────► task tokens ──┤
proprio ──► history encoder ──► PWM ──► residual ──► CMT ──────────┤
                                 │                    │             ├─► action head ─► chunk
                                 └─► RFA latent ──────┴─► RPSM ─────┘        │
                                                                             ├─► CRP (target adjust)
                                                                             └─► safety clip / watchdog
```

### E.3 因果残差

在时刻 `t`，我们只能观察到 `q_t`，不能观察 `q_{t+1}`。因此：

```text
# 训练：PWM 学一步/多步预测（a_t 是条件，q_{t+1} 是标签）
q_hat_{t+1} = PWM(q_{t-H+1:t}, qdot, a_{t-H+1:t}, gripper, ee)
loss = || q_{t+1} - q_hat_{t+1} ||_1 + λ * NLL

# 推理：在 t 时刻用 t−1 及之前的历史预测 q_t，计算上一帧的 surprise
r_t = q_t - PWM(q_{t-H:t-1}, a_{t-H:t-1})   # 可用，因果
mode_t = CMT(vis_t, prop_t, r_t)
a_t = ActionHead(vis_t, txt, part_t, r_t, mode_t, z_r)
```

- `r_t` 是**上一帧的接触 surprise**，不是当前帧；在 30Hz 下延迟 33ms，可接受。
- 在 chunk 边界，`r_t` 是最近一次可观测的残差；chunk 内没有更新。这就是为什么要小 chunk。
- PWM 的预测目标是“无接触时机器人会怎么动”；动作是条件，不是标签。

### E.4 PWM：关节空间世界模型

**输入**：

- 最近 `H=8–16` 帧的 `q`、`qdot`、`a_prev`、`gripper`、`ee_pose`；
- 训练时：当前/未来 chunk 的动作 `a_{t:t+K}`（用于预测 `q_{t+1:t+K+1}`）；
- 推理时：只用 `t−1` 及之前的历史预测 `q_t`，保证因果；
- RFA latent `z_r`（可选）。

**输出**：

- 未来 `K` 帧的关节位置 `q_hat`（或 delta）；
- 每个关节的预测方差（可选）。

**结构**：

- 轻量版：2 层 GRU（hidden 256）+ 3 层 MLP/关节；约 1–3M 参数；推理 <2ms。
- 重版：4 层 Transformer（256 dim，8 heads）；约 10–20M；只在离线/大 GPU 用。
- 共享 proprio encoder；PWM 有独立 GRU，不走视觉 backbone，保证快。

**训练**：

- 全部 32 任务；一步/多步预测；L1 + Gaussian NLL。
- 自由空间样本多、接触样本少：按“残差/夹爪/阶段”重加权；难例挖掘。
- 硬负例：快速自由运动 vs 接触；同样的 residual 幅度，不同 context。
- 不使用未来帧作为输入；严格因果。

**接触分数**：

```text
s_t = || (q_t - q_hat_t) / sigma_j ||_2
```

- `sigma_j` 是每关节的自由空间尺度（RFA/在线校准）；
- 用 GRU 平滑；输出 `s_t`、方向（FK 到 Cartesian）、每关节贡献；
- 阈值不是手调，而是用验证集的 FAR/TPR 选。

### E.5 CMT：接触模式 token

7 个模式：`free`、`grasp`、`constrained`、`human`、`slip`、`collision`、`lost`。

| 证据 | free | grasp | constrained | human | slip | collision | lost |
|---|---|---|---|---|---|---|---|
| PWM residual | 小 | 中 | 大/持续 | 大/突发 | 中/下降 | 大/突发 | 大 |
| gripper gap | 开 | 有物体 | 有物体 | 可能开 | 变大 | 有物体 | 无 |
| 物体运动 | 自由 | 跟随手 | 被约束 | 被人移动 | 掉落 | 突然停 | 不可见 |
| 人手可见 | 否 | 否 | 否 | 是 | 否 | 可能 | 否 |

**训练**：

- 弱标签：gripper gap、物体跟踪、人手 query、残差阈值；
- 500–1000 帧人工标注做校准/评测；
- 软概率（7 维）而不是硬切；交叉熵 + 熵正则；
- 人类手检测用同一个 part head 的 `hand` query，不引入第二个模型。

**用法**：

- `free`：正常速度/chunk 4–8；
- `grasp`：闭合夹爪，确认物体跟手；
- `constrained`：减小目标增量，启用 CRP；
- `human`：减速/让开/等待，RPSM 准备回退；
- `slip`：重新夹/降低加速度；
- `collision`：后退 1–2cm，重新对齐；
- `lost`：停止盲动，重新扫描。

### E.6 CRP：位置接口上的柔顺

```text
a_task = ActionHead(...)                 # 任务目标
r = q_t - PWM(q_{t-1}, a_{t-1})          # 接触残差
a_ref = a_task - Kc * tanh(r / scale)    # 遇阻回退
a_out = clip(a_ref, soft_limits)         # 安全限幅
```

- `Kc` 是 action head 的输出（每关节 1 维，或由 CMT 条件化）；不是手调常数。
- 训练：用演示动作监督 `a_ref`；演示里“遇阻回退”的片段就是 CRP 的目标。
- 因为 action 是位置，CRP 不需要力矩接口；它只是把“位置目标”改成“柔顺参考”。
- **chunk 级柔顺包络**：如果只能用 chunk=4，输出一个小范围的“搜索/回退”轨迹（例如 ±1–2mm 的微动），让开环 chunk 对接触位置不敏感；这是 CRP 的工程补充。
- 单模型：CRP 是 action head 的一层，不是外挂控制器。

### E.7 RFA：机器人指纹适配

- 指纹维度：关节零偏、摩擦、回差、PD 增益、负载质量。
- 推断：episode 开头 1–2s 自由空间小动作的 residual 统计 → `z_r`（16 维）。
- 使用：FiLM 调制 PWM/action head；训练时域随机化（质量/摩擦/PD/回差/延迟）+ 多机器人数据。
- 最低成本版：不做学习，在线减掉自由空间 residual 的均值/方差；这是 RFA 的 fallback。
- 为什么重要：比赛是多台机器人；同一策略在不同机器上的 tracking residual 不同，PWM 阈值会漂；RFA 让“接触 surprise”跨机器可比。

### E.8 SPA-lite：语义底座

- K=8 个 part queries；输出 2D centroid + visibility + descriptor；**不做全 3D PartSAM**。
- 原因：API 没有相机内参/外参；3D 融合容易错；头部双目只有厘米级精度，接触必须腕部近景。
- 部件短语（离线 VLM 生成）：`handle`、`rim`、`prong`、`socket`、`zipper pull`、`cap`、`key`、`towel corner`、`bowl rim`、`earphone`、`phone`、`pin`、`plunger`、`tool handle`。
- 训练：SAM3/PartSAM 关键帧伪标签；学生只学 centroid/visibility/descriptor；轻量、快。
- 推理：2D centroid + 腕部近景相对几何 → 抓取点/插入方向；深度只做辅助。
- 与动作头：part tokens 交叉注意力进入 action head；语言负责“哪个部件/哪一步”，part 负责“在哪里”。

### E.9 RPSM：撤销检测与定向修复

- 谓词库：`on_hook`、`inserted`、`screwed`、`zipped`、`folded`、`stacked`、`sorted`、`locked`、`plugged`、`filled` 等。
- 输入：part tokens + CMT + 语言；输出：每个谓词的概率/进度。
- 撤销检测：反向播放/状态翻转样本训练 `progress_delta` 头；`human` CMT + 谓词回退 → 触发 repair。
- 修复：只重做被撤销的子目标，不重跑全程；180s 下这是必须的。
- 协同：人手拔插头时，PWM 先看到 residual 突变，CMT 判 `human`，RPSM 把 `plugged` 置回 false，action head 收到 `repair(plugged)` 条件。

### E.10 单模型合规

- 一个 checkpoint；一个 forward graph；所有头共享 backbone。
- 不喂 task ID；只用语言 + 图像 + proprio。
- SAM3/PartSAM/VLM 只在离线；运行时没有第二个模型/外部 API。
- Safety monitor 是规则式（关节限位、速度、人手距离），不是第二个 policy。
- 提交 manifest：模型 hash、许可证、训练数据清单、消融表、单模型声明。
- 若用外部基座（WLA-1.0/GigaBrain，Apache-2.0）：全量微调所有头；保留 NOTICE。

### E.11 伪代码

```python
class TACVLA(nn.Module):
    def __init__(self, base):
        self.backbone = base
        self.part_queries = PartQueries(K=8)
        self.pwm = JointWorldModel(hidden=256)
        self.cmt = ContactModeHead(n_modes=7)
        self.rpsm = PredicateMemory(n_pred=12)
        self.rfa = RobotFingerprintAdapter(dim=16)
        self.action = ActionHead(chunk=4)

    def forward(self, obs, lang, prev_action, prev_q, z_r=None):
        vis = self.backbone.encode_images(obs.images)       # 4 views
        txt = self.backbone.encode_text(lang)
        prop = self.backbone.encode_proprio(obs.proprio)

        parts = self.part_queries(vis, txt)                 # 2D centroid, vis
        q_hat = self.pwm(hist_q, hist_a, z_r)               # 用 t−1 历史预测 q_t
        r = obs.q - q_hat                                   # contact surprise
        mode = self.cmt(vis, prop, r, parts)                # 7-way soft token
        state = self.rpsm(parts, mode, txt, prev_state)     # predicates

        a_task, kc = self.action(vis, txt, parts, prop, r, mode, state)
        a_ref = a_task - kc * torch.tanh(r / self.scale)
        a_out = clip(a_ref, self.soft_limits)
        return a_out, state, mode, r, q_hat
```

> 真实实现中 `prev_q/prev_action` 是最近一帧；`obs.q` 是当前测量；`q_hat` 是 PWM 对当前帧的预测（由上一帧算得），所以 `r` 是因果的。

- `recomputed_ee_valid` 可用于过滤无效 EE 帧。
- 语言：每任务 5 条英文复述；用留一法验证语言泛化。
- 时长 6.2–37.6s；长任务（T09/T15/T16/T17/T18/T22/T28）需要阶段预算。
- 标定：至少 10 组头部双目；不能全局硬套外参；按任务读 `camera_params`。

### F.2 残差分析（HangCup 预实验）

| 指标 | 数值 | 说明 |
|---|---|---|
| 右臂 mean|`a_{t-1}−q_t`| | 0.017–0.039 rad | 各关节不同 |
| 左臂 mean|`a_{t-1}−q_t`| | 0.009–0.035 rad | 左臂用得少 |
| 右臂 p95 | 0.03–0.09 rad | 快速运动时更大 |
| 右夹爪闭合瞬间 | 中位数约为闭合前 **2.3×** | 已抽样 719 episodes；但被运动混淆 |
| 接触标签 | **没有** | 只能用夹爪/阶段/视觉做弱标签 |

**结论**：

- raw residual 有接触信号，但不是干净的接触信号；快速自由运动也会触发。
- 必须用 PWM 把“可预测的跟踪滞后/摩擦”减掉，剩下的才是 contact surprise。
- 下一步：训练 PWM，离线测 contact AUC；AUC <0.65 就停。

### F.3 标签与增广

- **PWM 标签**：下一帧关节位置；不需要人工。
- **CMT 弱标签**：gripper gap、物体跟踪、人手 query、残差阈值；500–1000 帧人工校准。
- **Part 标签**：SAM3/PartSAM 关键帧伪标签；过滤低置信/跨视角不一致。
- **RPSM 标签**：`score_steps` 阶段 + 人工对齐；成功 episodes；反向播放做 undo。
- **增广**：
  - 颜色/光照/背景；相机 dropout；小范围平移；
  - 语言复述留一法；
  - 人手 overlay/遮挡（只用于 CMT/RPSM，不用于 action cloning）；
  - 物体状态回退（仿真/反向片段；只用于 RPSM/CMT）。
- **不做**：用未来帧预测动作（泄漏）；用测试任务硬编码；用榜单分数调参。

### F.4 训练配方

- 基座：UnifoLM-WLA-1.0 6B（Apache-2.0、G1、2500h、64 tasks）优先；GigaBrain-0.7-3.5B 备选。
- 微调：LoRA/部分微调；视觉 backbone 低 LR；action/PWM/CMT 头高 LR。
- 损失：`L_action + λ1 L_pwm + λ2 L_cmt + λ3 L_part + λ4 L_pred + λ5 L_smooth`。
- chunk：训练时采样 K∈{1,2,4,8,16}；`action_chunk_size` token；chunk dropout。
- 接触平衡：按夹爪/阶段/残差重加权；PWM 硬负例。
- 课程：先自由空间/简单任务，再接触/长程/干扰。
- 正则：动作平滑、速度限制、关节限位惩罚（soft）。
- 复现：seed、config、git hash、数据版本、模型 hash。

## G. 接口、延迟与 chunk 工程

### G.1 observation/action

- 4 路 RGB 480×640×3；无 depth/current；语言字符串。
- joint 或 EE 控制；`action_chunk_size` 固定；`meta.token` 每 episode。
- `reset()` 每 episode；`get_action` 每步/每 chunk。
- N 端口 8765…8765+N−1；每端口独立 state。

### G.2 chunk 数学

| chunk | 30Hz 策略频率 | chunk 执行时间 | 接触反馈 |
|---|---|---|---|
| 1 | 30Hz | 33ms | 每步可改；推理需 <33ms |
| 2 | 15Hz | 67ms | 67ms 开环 |
| 4 | 7.5Hz | 133ms | 133ms 开环 |
| 8 | 3.75Hz | 267ms | 267ms 开环 |
| 16 | 1.875Hz | 533ms | 533ms 开环 |

> 上表假设推理延迟可忽略；实际周期约为 `max(t_infer, chunk/f_control) + t_network`。如果推理比 chunk 执行还慢，策略频率由推理决定，表里的频率只是上界。

**策略**：

- 接触任务优先 chunk=1–2；自由空间 chunk=4–8。
- 如果平台只允许固定 chunk：固定 2–4，并把 CRP/柔顺包络放进动作。
- 训练 chunk dropout，让模型适配不同 chunk。
- 实测控制频率/推理延迟后重算；不要假设 30Hz。

### G.3 延迟预算

- 单步预算：`t_infer + t_network < chunk_period`。
- chunk=1、30Hz：`t_infer < 33ms`；6B 模型 4 视图很难，需要蒸馏/量化/小模型。
- chunk=2、30Hz：`t_infer < 67ms`；更现实。
- chunk=4：`t_infer < 133ms`；6B 可行（L40S/H100，量化后）。
- p99 而不是均值；动作规律/抖动也会被记录。
- 优化：TensorRT/ONNX、FP16/INT8、CUDA graphs、视觉 token 缓存、动态 batching、warm-up。
- 降级：如果 p99 超预算，减视图/降分辨率/减 chunk/换小模型；不能返回 NaN/超时。

### G.4 N 端口与状态隔离

- 每端口一个 session：`episode_id/token`、RPSM 状态、PWM 历史、prev_action、prev_q。
- 共享 GPU 后端：动态 batching + deadline；每请求超时；排队上限。
- 不允许跨端口共享 episode state；模型权重共享可以。
- 4h soak：成功率漂移、p99 漂移、显存增长、热节流、崩溃恢复。
- 端口数未知：按 N=1/3/8 做压力测试；配置化。

### G.5 安全与 watchdog

- 关节限位/速度/加速度 clip；soft limits。
- 人手接近：减速/停止/让开；CMT `human` 双确认。
- 超时：阶段预算；180s 前 safe retreat；不硬撞。
- NaN/Inf：拒绝动作，回退到 hold/retreat。
- 碰撞：CMT `collision` → 后退 1–2cm，重新对齐。
- 日志：每步动作/延迟/模式/残差；便于复盘（不上传敏感数据）。

### J.2 P0：PWM（Proprioceptive World Model）

- **动机**：API 没有 current/torque；raw residual 被运动/跟踪滞后混淆；接触最后几毫米需要比 chunk 更高的反馈。
- **差异**：Blind Dexterity 用 raw residual 当触觉；Current as Touch 用 motor current；我们用**动作条件关节世界模型**预测“无接触时的运动”，把可预测的滞后减掉，只留 contact surprise。这是“世界模型”在位置接口上的一个具体用法，不是视频世界模型。
- **可行性**：HangCup 预实验显示夹爪闭合时残差中位数 2.3×；PWM 是 1–3M 小头；训练数据现成；推理 <2ms。
- **资源**：1×GPU 离线训练 1–2 天；数据 32 任务；无需仿真。
- **步骤**：
  1. 构造 `(q, qdot, a_prev, gripper, ee) → q_next` 数据集；
  2. 训练 GRU/MLP；按任务/关节评估；
  3. 用验证集选 contact 阈值（FAR/TPR）；
  4. 接入 TAC-VLA，消融；
  5. 用 FK 输出 Cartesian 方向；
  6. 失败分析：快速运动误触发、软物体、回差。
- **风险**：残差主要是噪声 → AUC <0.65 就停；回退到视觉接触 + CRP + 小 chunk。

### J.3 P0：CMT（Contact Mode Token）

- **动机**：接触不是一个二值信号；free/grasp/constrained/human/slip/collision/lost 需要不同策略；CMT 也是 RPSM 的物理证据。
- **差异**：现有 VLA 没有显式接触模式；CMT 是软 token，不是硬规则；与 action head 端到端训练。
- **可行性**：gripper gap、物体跟踪、人手 query、PWM residual 都能提供弱标签；500–1000 帧人工校准即可。
- **资源**：标注 1 人周；训练几小时；推理可忽略。
- **步骤**：
  1. 定义 7 类与证据表；
  2. 生成弱标签；人工校准；
  3. 训练 CMT（CE + 熵正则）；
  4. 接入 action head（FiLM/交叉注意力）；
  5. 消融 human/constrained/slip；
  6. 失败分析：人手误判、遮挡。
- **风险**：弱标签噪声 → 用软标签/人工校准；不要把 CMT 当硬安全开关。

### J.4 P0：CRP（Compliance Reference Position）

- **动机**：action 是位置目标；一直往物体里推会力过大/卡住；需要“遇阻回退”。
- **差异**：Current as Touch 用 current 预测 CRP；我们用 PWM residual + 演示动作学习 CRP；不需要力矩接口；是 action head 的一层。
- **可行性**：演示里有“遇阻回退”的片段；位置接口天然支持；单模型合规。
- **资源**：无额外数据；训练端到端；推理 <1ms。
- **步骤**：
  1. action head 输出 `a_task` 和 `Kc`；
  2. `a_ref = a_task − Kc·tanh(r/scale)`；
  3. 用演示动作监督；加平滑/限幅；
  4. chunk 级柔顺包络；
  5. 接触任务消融；
  6. 失败分析：chunk 内不能更新 → 小 chunk。
- **风险**：chunk 开环 → CRP 只在 chunk 边界生效；用 chunk=1–2 或柔顺包络。

### J.5 P0：RPSM（Reversible Part-State Memory）

- **动机**：官方 human 干扰是撤销式（T10/T12/T14/T16/T17/T19/T24/T27）；20% trials；180s 不够重跑。
- **差异**：现有 VLA/进度头假设单调推进；RPSM 显式维护可逆谓词，检测回退并定向修复。
- **可行性**：`score_steps` 提供阶段；成功 episodes 提供标签；反向播放做 undo 增广；CMT 提供物理证据。
- **资源**：谓词标注 1–2 人周；训练几小时；推理可忽略。
- **步骤**：
  1. 定义 12 个谓词；
  2. 用 `score_steps`/人工对齐打标签；
  3. 训练谓词头 + `progress_delta`；
  4. 反向/回退增广；
  5. repair 条件接入 action head；
  6. 在 8 个撤销任务上评测。
- **风险**：谓词误判/回退误触发 → 软概率 + 双确认（CMT human + 视觉）；修复失败 → 回退全程。

### J.6 P0.5：SPA-lite（Semantic Part Queries）

- **动机**：32 任务都是部件级交互；物体级 3D 不够；未见物品需要部件语义。
- **差异**：上一轮的全 3D PartSAM 被砍；本轮 K=8、2D centroid + wrist、不做全 3D；更轻、更稳、无标定依赖。
- **可行性**：SAM3/PartSAM 离线伪标签；2D centroid 足够抓取/插入；腕部近景补足精度。
- **资源**：伪标签 1 人周；训练与 VLA 共享；推理轻量。
- **步骤**：
  1. 离线 VLM 生成部件短语；
  2. SAM3/PartSAM 关键帧伪标签；
  3. 训练 part queries（centroid/visibility/descriptor）；
  4. 接入 action head；
  5. 未见物品/遮挡消融；
  6. 失败分析：透明/反光/小部件。
- **风险**：无标定/遮挡 → 2D+wrist；透明物体 → 深度/腕部；部件混淆 → 语言对比学习。

### J.7 P1：RFA（Robot Fingerprint Adapter）

- **动机**：比赛多台 G1；摩擦/回差/PD/负载不同；PWM 阈值会漂。
- **差异**：现有 VLA 不做机器人级残差校准；RFA 用自由空间 residual 推断 16 维指纹，FiLM 调制。
- **可行性**：1–2s 自由空间动作即可；最低成本版是在线 residual 归一化；无需额外数据。
- **资源**：多机器人数据（若有）；否则仿真域随机化；训练几小时。
- **步骤**：
  1. 采集自由空间 residual 统计；
  2. 训练 `z_r` encoder；
  3. FiLM 调制 PWM/action；
  4. 域随机化/多机器人；
  5. 跨机器消融；
  6. fallback：在线减均值/方差。
- **风险**：多机器人数据少 → 先做归一化；RFA 学习版延后。

### J.8 P1：Task Portfolio Optimizer

- **动机**：320 trials；成功率优先；预算有限；1–2pp 是噪声。
- **差异**：上一轮的“高地板/首点优先”改为“最差任务优先 + Beta-Binomial + 成本”；用 CI 而不是榜单。
- **可行性**：本地 10-trial 协议；每任务成功率/CI；成本可估。
- **资源**：评测机时；无需训练。
- **步骤**：
  1. 定义先验/成本；
  2. 每轮更新后验；
  3. Thompson sampling 分配；
  4. 0% 任务探索加成；
  5. 停止/降级规则；
  6. 报告总平均 CI。
- **风险**：先验偏差 → 用弱先验；评测噪声 → 配对/重复。

### J.9 P1：Compliance Compiler

- **动机**：单模型/许可/外部数据/安全/延迟任何一项不清可能归零。
- **差异**：不是 PPT 声明，而是“规则→实现→测试”的门禁；每条规则有测试。
- **可行性**：规则已知部分 + 未核实部分标注；提交 manifest；CI。
- **资源**：1 人周；主要是工程。
- **步骤**：
  1. 规则表；
  2. 单模型检查（一个 checkpoint/无运行时教师/无 task ID）；
  3. 许可证/NOTICE；
  4. N 端口/延迟/动作规律测试；
  5. 安全/watchdog；
  6. 红队/复现。
- **风险**：规则未读全 → 先按保守版；正式提交前读 5.1/5.2。

### J.10 P1/P2：Endurance Governor

- **动机**：N 端口、长时并发、p99/热/内存会吃掉成功率；语义记忆跨遮挡也不能丢。
- **差异**：把“续航”拆成服务续航 + 语义续航；不是猜电池。
- **可行性**：动态 batching、CUDA graphs、量化、warm-up、4h soak 都是成熟工程。
- **资源**：1–2 人周；GPU 压力测试。
- **步骤**：
  1. 每端口 session 隔离；
  2. 动态 batching + deadline；
  3. p99/显存/热监控；
  4. 4h soak；
  5. 语义记忆跨遮挡测试；
  6. 降级策略。
- **风险**：工程量大 → P1/P2；先保证单端口正确。

### J.11 P2：Offline VLM Compiler

- **动机**：5 条语言复述 + `score_steps` 需要编译成谓词/部件短语；运行时 VLM 太慢。
- **差异**：离线编译，运行时只跑语言编码器；不是运行时 LLM 规划。
- **可行性**：32 任务、5 条复述、score_steps 现成；VLM 离线一次。
- **资源**：1 人周；离线 GPU。
- **步骤**：
  1. 解析 tasks.parquet/score_steps；
  2. VLM 生成谓词图/部件短语；
  3. 人工校验；
  4. 接入 RPSM/SPA-lite；
  5. 留一法语言测试。
- **风险**：运行时不需要 → P2；先手工谓词图。

## 附录 D：HangCup 残差预实验细节

- 样本：HangCup 已抽样的 719 episodes（首个 parquet 分片）；1043 episodes/194,564 frames 总量。
- 残差定义：`r_t = a_{t-1} − q_t`（目标关节位置 − 下一帧测量关节位置）。
- 统计：右臂 mean|r| 0.017–0.039 rad；左臂 0.009–0.035 rad；p95 0.03–0.09 rad；max 0.13–0.50 rad。
- 夹爪闭合：右夹爪 719/719 episodes 闭合；闭合瞬间残差中位数约为闭合前的 2.3×。
- 局限：残差被快速运动/跟踪滞后混淆；没有接触标签；没有 current；不能直接当接触检测器。
- 下一步：训练 PWM，报告 contact AUC/TPR@FAR=5%；如果 AUC <0.65，停掉 PWM 主线，回退“视觉接触 + CRP + 小 chunk”。

## 附录 E：术语表

- **PWM**：Proprioceptive World Model，关节空间动作条件世界模型。
- **CMT**：Contact Mode Token，7 类接触模式软 token。
- **CRP**：Compliance Reference Position，柔顺参考位置。
- **RFA**：Robot Fingerprint Adapter，机器人指纹适配。
- **SPA-lite**：Semantic Part-Affordance lite，K=8 部件 query。
- **RPSM**：Reversible Part-State Memory，可逆部件状态记忆。
- **TAC-VLA**：Transmission-Aware Contact VLA，本轮主架构。
- **chunk**：evaluator 开环执行的动作序列长度。
- **FAR/TPR**：false acceptance rate / true positive rate。
