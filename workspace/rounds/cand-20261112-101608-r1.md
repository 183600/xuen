# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；新灵感循环第 1 轮；本轮灵感：「技术融合」×「手势识别」）

> 第 59 轮把执行层纳入安全论证链后，系统已经拥有 L0–L6 的纵向堆栈、五模态对账、四重预算、执行证书与双向契约。但它仍是一个**「每层各自自证、层间靠口头承诺」**的拼装体：视觉说「我 95% 确信」，触觉说「我误差 2N」，规划说「我 δ_f=10⁻⁴」，执行说「我 WCET 20μs」——这些数字**单位不同、时钟不同、独立性假设不同、权限上限不同**，一旦组合，谁也不能保证「接口处的假设」仍然成立。本轮两个灵感正好击中这个**组合性缺口**：**「技术融合」**不是再堆一个模块，而是把异构能力变成**可验证组合的契约网**（assume-guarantee 接缝、融合债务、相关性校正）；**「手势识别」**不是新增一条命令通道，而是把人类意图接入为**可校准、可拒识、可溯源、权限封顶的证据模态**——**识别正确不等于授权安全**。本轮核心命题：**「技术融合的安全单位不是模块，而是接缝；手势识别的安全单位不是准确率，而是误授权代价；融合只能让系统更保守，不能让系统凭空更自信。」**

核心矛盾：

- **H35（组合性泄漏·融合债）**：每个模块在自己的测试分布上都是「音完备」的，但模块之间依赖的隐含假设——同一时间基准、同一坐标系、同一不确定性语义、同一权限等级、误差条件独立——**从未被显式认证**。第 59 轮之后，层数越多，接缝越多；接缝上的假设一旦失效，组合系统的真实失效率可以远高于各层失效率之和。**技术融合若只做接口适配、不做契约测试，就是把安全论证建立在一组未验证的「应该没问题」上。**
- **H36（识别—授权鸿沟·手势假阳性）**：手势识别模型的 top-1 准确率、mAP、词表覆盖率，都是**识别指标**，不是**授权指标**。一个「停止」手势的漏检可能导致碰撞，一个「继续」手势的误检可能让机械臂在人类面前启动；更危险的是**无意手势、旁观者手势、视频回放注入、跨符号系统歧义**。把 `argmax p(y|x)` 直接当命令，是把**人类意图的观测**误当成**人类意图本身**。
- **H37（独立性幻觉·融合税）**：多模态融合的经典收益公式假设各模态误差条件独立；但机器人现场的相关性极强——同一遮挡同时打击视觉与手势骨架、同一光照同时影响深度与颜色、同一个人同一动作同时被手势与语音表达。**相关证据被当作独立证据重复计数，会制造虚假的置信度增益**；融合若能无条件降低方差，它就能把「三个都不太确定的模态」变成「一个非常确定的错误」。
- **H38（意图归属缺失·责任不可追溯）**：手势是「谁在什么时候、以什么身份、对什么对象、表达了什么意图」的复合命题。只保存 `(label, confidence)` 而不保存**签署者绑定、活体证据、时间窗、语境指代、共识过程**，一旦误授权，既无法复现，也无法界定是识别错误、交互设计错误还是操作者误用。

## 0. 直觉与动机

**灵感 1（技术融合 → 从「纵向堆栈」到「横向接缝」）**
直觉：一个 59 轮堆出来的系统，最脆弱的地方不是最深的那一层，而是**层与层之间的接缝**。技术融合的正确对象不是「把更多算法塞进同一个盒子」，而是**让每个模块带一份可检查的契约**：我假设输入满足什么分布/时钟/坐标系/权限；我保证输出满足什么误差界/单调性/失效模式；我的证书在什么版本、什么测试套件下有效。两个模块能否组合，不取决于它们「看起来能接上」，而取决于 `G_i ⇒ A_j` 与 `G_j ⇒ A_i` 是否被测试验证。于是「融合」从一句口号变成一个**可判定的关系**，而「融合债」成为可计量的安全风险：**每个未验证的接口假设，都会以其失效概率进入最终部署界。**

**灵感 2（手势识别 → 从「命令通道」到「意图证据」）**
直觉：手势是人和机器人之间**带宽最高、歧义也最高**的通道之一。它可以是 deictic（指哪）、command（过来/停）、affect（犹豫/紧张）、consent（确认/拒绝）、emergency（急停）。但机器人看到的永远只是**骨骼点序列**，不是人的意图。因此正确姿势是把它降格为**证据**、而不是升格为**命令**：
- **校准**：`p(y|x)` 必须在**跨签署者**、跨距离、跨光照的留出集上校验 ECE，而不是在训练同分布上自评；
- **拒识**：允许输出 `unknown/none`，用选择性分类的 risk–coverage 曲线而不是覆盖率换准确率；
- **溯源**：把标签绑定到**已认证的签署者**（人脸/工牌/声纹/操作员会话）、**活体**（深度、微动、反射）与**时间窗**；
- **权限封顶**：手势的权限等级由「活体 + 溯源 + 佐证」共同决定，**任何手势都不能单独授权不可逆动作**。
关键洞见：**识别模型可以犯错，授权逻辑必须为此买单**。

**灵感 3（多模态意图融合 → 相关性校正 + 不对称损失）**
直觉：把「手势 + 注视 + 语音 + 接近 + 上下文」融合，不能简单做 product-of-experts。先用**有效证据数** `n_eff = n/(1+(n−1)ρ̄)` 给相关性打折：三个高度相关的模态，最多只值一个多一点模态的证据量。然后，授权决策不能最小化分类错误率，而要最小化**不对称代价**：把「错误授权」的代价设成「错误拒绝」的几十倍，把「澄清」设成有成本但可接受的动作。于是决策规则自然变成**三值决策**：`authorize / clarify / refuse-or-stop`；不可逆动作再叠加 `k_irr` 个独立佐证。

**灵感 4（安全单向性 → 手势可以自由地让系统更保守）**
直觉：这是本轮最重要的一条工程伦理约束。**手势让系统「更保守」时，不需要任何额外佐证**：任何人做出「停止」「退后」「松开」的手势，机器人都应立即减速/停止/释放——因为最坏情况只是效率损失。**手势让系统「更激进」时，必须经过独立佐证与共识**：恢复运动、提高速度、进入接触、执行不可逆操作，不能只看一个手势标签。这条规则把第 58–59 轮已经建立的「信念可以更准、不确定性只能更大、动作只能更保守」三条单向通道，扩展为**交互层的单向安全闸门**：`gesture → conservatism` 免费，`gesture → authorization` 收费。

**灵感 5（融合—意图—承诺闭环 → FIG-CLEP 与融合证书）**
直觉：把上述内容接进第 59 轮的 CLEP 闭环：每次承诺前，先做**融合拓扑契约检查**（接缝是否良构）→ **融合债核算**（当前组合是否仍在安全预算内）→ **手势证据校准与溯源**（谁在表达什么）→ **多模态意图融合**（相关性校正 + 不对称损失）→ **人机共识**（是否需要澄清）→ 再进入 BUQ/ERTC/EEIS 的阻抗编译与执行。所有中间结果写入 **J_fuse 融合证书**：拓扑、契约测试、融合债轨迹、手势校准报告、意图溯源账本、共识日志、融合决策理由。这样「技术融合」与「手势识别」不是两个孤立功能，而是**同一个安全论证链上的一对偶**：**融合定义谁能被相信，手势定义人类想让谁做什么，证书定义两者如何被审计。**

## 1. 形式化定义（增量：定义 153–160）

**定义 153（融合模块、接口契约与组合算子 FTC）** 一个融合模块 `m = (A_m, G_m, δ_m, Cert_m, κ_m)`：`A_m` 为输入/环境假设集合，`G_m` 为输出保证集合，`δ_m` 为模块失效概率上界，`Cert_m` 为不可篡改证书，`κ_m` 为接口契约。接口契约
```
κ = (unit, frame, clock, unc_type, auth_ceiling, failure_mode, version, test_suite)
```
分别约束：物理单位、坐标系、时间基准与最大年龄、不确定性表示（概率/区间/共形/确定性界）、**权限上限**、失效模式、版本、契约测试套件。组合 `m₁ ⊗ m₂` 有定义，当且仅当：
```
(1) G₁ ⇒ A₂  且  G₂ ⇒ A₁            # assume-guarantee 互 discharge
(2) κ₁ 与 κ₂ 的 unit/frame/clock/unc_type 兼容
(3) 两侧 test_suite 均通过，且覆盖率 ≥ 1−ε_c
```
组合失效界 `δ_{12} ≤ δ₁ + δ₂ + δ_seam`，其中 `δ_seam` 是接口测试未覆盖的残余风险。**组合证书**由 `Cert₁, Cert₂, κ₁, κ₂` 与契约测试结果共同生成；证书不可跨版本复用。

**定义 154（融合拓扑与融合债 FQM）** 融合拓扑 `F = (V, E, κ)`：节点为能力/证据源 `V`，边为契约化接缝 `E`，每条边 `e=(i,j)` 携带假设集 `A_e`。对每个假设 `a∈A_e`，定义验证指标 `u_e(a)∈[0,1]`（未验证程度，由契约测试、分布漂移监测与人工审计共同给出）。**融合债**
```
D_fuse(F) = Σ_{e∈E} w_e · (1/|A_e|) Σ_{a∈A_e} u_e(a)
```
`w_e` 为接缝权重（由该边承载的风险预算与不可逆性决定）。融合成熟度向量
```
Φ(F) = (φ_sem, φ_time, φ_unc, φ_auth, φ_test)
```
分别度量语义互操作、时间对齐、不确定性可比、权限一致、测试覆盖。**良构条件**：`D_fuse(F) ≤ D_max` 且 `Φ(F) ≥ φ_min` 逐分量成立。**关键语义：融合债不是软件工程里的技术债，它会以概率形式进入部署安全界；未验证的接缝不是「待办」，而是「已计入的风险」。**

**定义 155（手势证据 GE）** 手势流 `x_{1:t}` 经分段器得到片段 `σ=(t_s,t_e, skeleton)`，词表 `𝒴_g = {point(o), come, hold, stop, release, confirm, deny, none, unknown}`。识别器输出校准后验 `p(y|x, s)`，其中 `s` 为签署者/视角/距离嵌入。**手势证据**
```
E_g = (p(y|x,s), referent(o), window, conf, spoof_score, signer_id, liveness, authority_cap, provenance)
```
`authority_cap ∈ {A0_observe, A1_stop_only, A2_reversible, A3_irreversible_candidate}` 由「活体通过 ∧ 签署者已认证 ∧ 时间窗有效」决定，且**任何单一手势的 authority_cap 最高为 A2**；`A3` 必须由独立佐证与共识另行升级。校准契约：跨签署者留出集上 `ECE_g ≤ ε_g`，选择性风险满足 `Risk(coverage) ≤ ε_sel(coverage)`，活体误接受率 `FAR_spoof ≤ δ_spoof`。

**定义 156（多模态意图融合 MIF）** 证据源集合 `ℰ = {gesture, gaze, speech, proximity, touch, context, exec}`，各源似然 `L_i(y)`。估计相关矩阵 `R`（误差相关，非标签相关），有效证据数
```
n_eff = n / (1 + (n−1)·ρ̄),   ρ̄ = mean_{i≠j} |R_ij|
```
相关性校正后的对数似然增益满足 `Δ_fused ≤ n_eff · max_i Δ_i`（禁止把相关证据当独立证据重复计数）。意图后验 `p(y|E) ∝ p(y) · Σ_i w_i log L_i(y)`，其中 `w_i = (R^{-1}1)_i / (1^T R^{-1} 1)`。**不对称损失** `L(a, y)`：`L(authorize, y≠intended) = C_harm ≫ L(refuse, y=intended) = C_task`；动作集 `A_intent = {authorize, clarify, refuse, safe_stop}`。**决策规则**：
```
authorize   iff  R(authorize) ≤ δ_intent  ∧  independent_corroboration ≥ k_req(intent)
clarify     iff  不确定性可通过一次低成本询问显著降低
refuse/stop otherwise
```
**不可逆动作硬约束**：`irr=true ⇒ gesture 单独绝不满足 corroboration；k_req ≥ k_irr ≥ 2`，且至少一个佐证来自非手势、非同源模态。

**定义 157（人机意图共识协议 HICP）** 共识状态 `c ∈ {aligned, ambiguous, conflicting}`，澄清动作 `A_c = {ask_confirm, ask_point, demonstrate, rephrase, cancel, safe_stop}`。人体意图先验 `b_h` 与机器人理解 `b_r` 的互信息低于阈值、或后验熵高于阈值时进入 `ambiguous`；两独立模态指向不同指代对象时进入 `conflicting`。协议在 `K_consensus` 轮内终止于「达成共识 / 安全停 / 转人工」；禁止用「默认同意」超时。**意图溯源账本**
```
P = (who, when, modality, model_version, confidence, consent_state, referent, hash)
```
每次授权动作必须能追溯到一条完整 `P` 链；账本只追加、不可改写。

**定义 158（融合感知承诺算子 FIG-CLEP）** 在 CLEP 前插入融合—意图阶段：
```
FIG-CLEP(M, cp, δ_f^req, B_fuse):
  ① FTC.check(F)                   # 接缝契约与版本
  ② D_fuse ← FQM.estimate(F)       # 融合债
     if D_fuse > D_max: return DEGRADE_FUSION
  ③ E_g ← GEC.calibrate_gesture(stream, signer_binding)
  ④ p_intent ← MIF.fuse(E_g, gaze, speech, proximity, context, R)
  ⑤ c ← HICP.consensus(p_intent, b_h, b_r)
     if c = conflicting: return SAFE_STOP
     if c = ambiguous: return CLARIFY(A_c) or SAFE_STOP on timeout
  ⑥ if authorize and irr: verify k_irr independent corroborations
  ⑦ M, fused, D⁺, EV_exec, Cert_eeis ← CLEP(M, cp, δ_f^req)
  ⑧ J_fuse ← build_fusion_certificate(F, D_fuse, E_g, p_intent, c, P, decisions)

```
**单向安全闸门**：手势可以提高 `D_fuse` 以外的保守性（触发 `safe_stop`、降低速度、释放接触）而无需佐证；任何降低保守性的动作必须通过步骤 ④–⑥。FIG-CLEP 不得绕过 CLEP 的 ERTC/EEIS 硬约束。

**定义 159（融合预算 B_fuse 与 PCE++++）** `B_fuse = (compute_slack, bw_slack, latency_slack, attention_slack, label_slack)`；融合成本
```
cost_fuse(π) = λ_c·max(0, compute(π)−compute_slack)
             + λ_b·max(0, bw(π)−bw_slack)
             + λ_l·max(0, latency(π)−latency_slack)
             + λ_a·max(0, attention(π)−attention_slack)
```
**融合税** `tax_fuse = λ_tax·D_fuse + λ_corr·(n−n_eff)/n`。PCE++++ 的价值函数
```
voi_fuse(π) = VOI_meta_pessimistic(π) − cost_exec(π) − cost_fuse(π) − tax_fuse
```
仅当 `voi_fuse` 的**下界**大于阈值 `τ_fuse` 时才允许增加融合复杂度；`B_fuse` 耗尽 ⇒ 回退到经认证的单模态策略或安全停，而不是「继续融合碰运气」。

### IP-152 FTC（融合拓扑契约检查器）

```python
class FusionTopologyContract:
    def __init__(self, nodes, edges, contracts):
        self.V, self.E, self.kappa = nodes, edges, contracts
        self.version = hash((tuple(nodes), tuple(edges),
                             tuple(sorted(contracts.items()))))

    def check_composition(self, m1, m2):
        k1, k2 = m1.kappa, m2.kappa
        # 单位/坐标系/时钟/不确定性表示必须可比
        compat = (k1.unit == k2.unit and k1.frame == k2.frame
                  and abs(k1.clock_domain - k2.clock_domain) <= MAX_CLOCK_SKEW
                  and k1.unc_type == k2.unc_type)
        # assume-guarantee 双向 discharge，且必须有测试证据
        ag_ok = (implies(m1.G, m2.A) and implies(m2.G, m1.A)
                 and contract_test_covered(m1, m2) >= 1 - EPS_C)
        delta_seam = seam_residual(m1, m2)   # 接口测试未覆盖的残余风险
        return compat and ag_ok, delta_seam

    def well_formed(self, F):
        # 逐边检查 + 融合债务预算
        for e in F.E:
            ok, _ = self.check_composition(F.node(e.i), F.node(e.j))
            if not ok:
                return False, f"seam_violation:{e}"
        return D_fuse(F) <= D_MAX, "ok"
```

### IP-153 FQM（融合债与成熟度计量）

```python
def fusion_debt(F, test_results, drift_monitor):
    debt = 0.0
    for e in F.E:
        assumptions = F.assumptions(e)
        unverified = []
        for a in assumptions:
            t = test_results.get((e, a), None)
            d = drift_monitor.assumption_drift(e, a)
            # 未测试/测试过期/分布漂移都计入未验证程度
            u = 1.0 if t is None else max(t.residual, d)
            unverified.append(u)
        debt += F.weight(e) * np.mean(unverified)
    return debt

def fusion_maturity(F):
    return FusionMaturity(
        semantic=min(contract_semantic_score(e) for e in F.E),
        temporal=min(clock_alignment_score(e) for e in F.E),
        uncertainty=min(uncertainty_commensurability(e) for e in F.E),
        authority=min(authority_consistency(e) for e in F.E),
        test=min(contract_test_coverage(e) for e in F.E))
```

### IP-154 GEC（手势证据校准、拒识与溯源）

```python
class GestureEvidenceCalibrator:
    def __init__(self, recognizer, signer_db, liveness_model):
        self.rec = recognizer
        self.signers = signer_db
        self.live = liveness_model
        self.temperature = fit_temperature_on_signer_split()

    def calibrate(self, stream):
        segs = segment(stream)
        out = []
        for (ts, te, sk) in segs:
            logits = self.rec.logits(sk)
            p = softmax(logits / self.temperature)          # 校准
            spoof = self.live.score(sk)                     # 活体/重放检测
            signer = self.signers.identify(sk)              # 签署者绑定
            liveness_ok = spoof < DELTA_SPOOF
            conf = p.max()
            # 拒识：低置信/活体可疑/签署者未知 => unknown
            if conf < TAU_REJECT or not liveness_ok or signer is None:
                y, cap = "unknown", "A0_observe"
            else:
                y = p.argmax()
                # 权限封顶：单手势最高 A2；stop 可 A1 立即生效
                cap = "A1_stop_only" if y in ("stop", "release") else "A2_reversible"
            out.append(GestureEvidence(p=p, y=y, window=(ts, te), spoof=spoof,
                                       signer=signer, liveness=liveness_ok,
                                       authority_cap=cap,
                                       provenance=ledger(ts, signer, self.rec.version)))
        return out

    def risk_coverage(self, val_loader):
        # 选择性分类：以拒识阈值换风险，报告完整 risk-coverage 曲线
        return compute_risk_coverage(self.rec, val_loader, self.temperature)
```

### IP-155 MIF（相关性校正的多模态意图融合 + 不对称损失）

```python
def fuse_intent(evidence, prior, R, loss):
    # 相关矩阵 R 来自留出集误差相关，不是标签相关
    n = len(evidence)
    rho_bar = mean_abs_offdiag(R)
    n_eff = n / (1 + (n - 1) * rho_bar)
    w = solve(R, np.ones(n)); w = w / w.sum()

    log_post = log(prior)
    for wi, (name, L) in zip(w, evidence.items()):
        log_post = log_post + wi * safe_log(L)
    # 有效证据数保守约束：总增益不得超过 n_eff 倍单模态最大增益
    post = normalize(exp(log_post))
    return post, n_eff

def intent_decision(post, loss, corroboration, irr):
    # R(a) = Σ_y L(a,y) p(y)
    risk = {a: sum(loss[a, y] * post[y] for y in post) for a in ACTIONS}
    if irr and (corroboration < K_IRR or not has_non_gesture_evidence()):
        return "clarify" if risk["clarify"] < risk["safe_stop"] else "safe_stop"
    if risk["authorize"] <= DELTA_INTENT and corroboration >= K_REQ:
        return "authorize"
    if risk["clarify"] <= risk["safe_stop"]:
        return "clarify"
    return "safe_stop"
```

### IP-157 FIG-CLEP（融合—意图—承诺闭环）

```python
def fig_clep(M, cp, delta_f_req, budget):
    # ① 接缝契约与融合债
    ok, why = M.ftc.well_formed(M.F)
    D = M.fqm.estimate(M.F)
    if not ok or D > M.D_max:
        return degrade_fusion(M, cp, why or "fusion_debt")

    # ② 手势证据（校准/拒识/溯源/权限封顶）
    E_g = M.gec.calibrate(M.gesture_stream.latest(cp.window))

    # ③ 多模态意图融合（相关性校正 + 不对称损失）
    p_intent, n_eff = fuse_intent({**M.evidence_at(cp), "gesture": E_g},
                                  M.intent_prior, M.R_corr, M.loss)
    corroboration = count_independent(M.evidence_at(cp), exclude="gesture")

    # ④ 人机共识
    c, action = consensus_step(M.b_h, M.b_r, p_intent, M.turn)
    if c == "conflicting" or action == "safe_stop":
        return safe_stop(M, cp, "intent_conflict", J_pending=(E_g, p_intent))
    if c == "ambiguous":
        return clarify(M, cp, action, E_g, p_intent)

    # ⑤ 授权判定（不可逆动作需 k_irr 独立佐证）
    a_intent = intent_decision(p_intent, M.loss, corroboration, cp.irreversible)
    if cp.irreversible and a_intent != "authorize":
        return refuse_or_clarify(M, cp, a_intent)

    # ⑥ 进入既有 CLEP（BUQ/ERTC/XMC+/EEIS/CLEP）
    M, fused, D_plus, EV_exec, Cert_eeis = closed_loop_exec_probe(
        M, cp, delta_f_req, budget)
    if EV_exec.degraded_flag:
        return degrade_fusion(M, cp, "exec_degraded")

    # ⑦ 融合证书
    J_fuse = build_fusion_certificate(M, E_g, p_intent, n_eff, c, a_intent, D)
    budget.spend_fuse(cost_fuse_of(M, cp))
    return M, fused, EV_exec, Cert_eeis, J_fuse
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FTC | O(\|E\|·\|A_e\|) 每拓扑变更 | O(\|V\|+\|E\|) | assume-guarantee 双向 discharge、契约测试覆盖 ≥1−ε_c |
| FQM | O(\|E\|·\|A_e\|) / 续约周期 | O(\|E\|) | 融合债单调、漂移计入、超预算即降级 |
| GEC | O(T·d) / 手势片段 | O(词表+签名库) | 跨签署者 ECE≤ε_g、选择性风险界、活体 FAR≤δ_spoof |
| MIF | O(n³) 求逆 + O(n·\|𝒴\|) | O(n²+\|𝒴\|) | 相关性校正、n_eff 保守、增益上界、不对称损失最小化 |
| HICP | O(K·\|𝒴\|·\|A_c\|) | O(\|𝒴\|) | 有界轮终止、歧义即澄清、冲突/超时即安全停 |
| FIG-CLEP | O(FTC+FQM+GEC+MIF+CLEP) | 复用 CLEP | 单向安全闸门、不可逆需 k_irr 独立佐证 |
| J_fuse | O(1)/事件追加 | O(事件数) | 版本链、溯源连续、契约/校准/佐证可审计 |

**正确性定理（Fusion-Intent Soundness, FIS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** FTC：每个接缝的 `assume-guarantee` 双向蕴含由契约测试以覆盖率 ≥1−ε_c 验证，未覆盖残余风险计入 `δ_seam`；版本/单位/时钟/不确定性语义不兼容即拒绝组合。**(A57)** FQM：融合债 `D_fuse` 是接口假设失效概率的**上界**（不是点估计），漂移监测只会增大它；`D_fuse>D_max ⇒ 禁止新增融合`。**(A58)** GEC：手势后验在跨签署者留出集上校准误差 `ECE_g≤ε_g`；拒识阈值可降低风险；活体误接受 `FAR_spoof≤δ_spoof`；签署者绑定与时间窗溯源诚实。**(A59)** MIF：误差相关矩阵 `R` 的上界估计给出保守 `n_eff`；对数似然增益不超过 `n_eff·max_i Δ_i`；损失矩阵 `L` 是真实代价的诚实上界；不可逆动作 `k_irr≥2` 且至少一个非手势同源佐证。**(A60)** HICP：协议在 `K_consensus` 轮内终止；不使用默认同意；冲突与超时均落到安全停；溯源账本只追加。则：

1. **组合健全性**：若拓扑 `F` 良构（所有接缝通过 FTC、`D_fuse≤D_max`、成熟度逐分量达标），则组合系统失效概率
```
P_fail(⊗_{m∈F} m) ≤ Σ_m δ_m + Σ_{e∈E} δ_seam(e) + D_fuse(F)
```
且不存在「因组合而获得未计入的置信度增益」。
2. **融合增益上界（无免费融合）**：对任意证据集 `ℰ`，`Δ_fused ≤ n_eff·max_i Δ_i ≤ Σ_i Δ_i`，当 `ρ̄>0` 时严格小于独立假设值；因此相关性校正后的融合只会**减少**而非制造过度自信。
3. **手势授权安全性**：`Pr[不可逆动作被手势单独授权] = 0`；对任意可逆授权，
```
Pr[错误授权] ≤ δ_intent + δ_spoof + ε_g + P(∑ 非手势佐证不足)
```
且「手势→更保守」方向不要求佐证、不受该界约束。
4. **单向安全闸门**：FIG-CLEP 产生的任何动作，其保守性不低于 CLEP 单独产生的对应动作；手势证据只能通过「触发澄清/拒绝/安全停」或「在独立佐证下升级授权」影响系统，不能直接放宽 ERTC/EEIS 的硬约束。
5. **共识终止与责任可追溯**：每个被授权的动作都存在一条 `P` 链（谁、何时、何模态、何模型版本、何置信、何同意状态、何指代）；歧义/冲突/超时均终止于澄清或安全停，`J_fuse` 可独立复核该链。
6. **部署界**（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD]
                   + δ_ertc·1[契约违例] + δ_eeis·1[μ分析漏报]
                   + δ_seam·1[接缝未覆盖] + D_fuse·1[融合债超界]
                   + δ_intent·1[意图歧义] + δ_spoof·1[活体失败]
                   + δ_consensus·1[共识超时])
         − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
         − P(固件回滚失败) − P(溯源账本被篡改)
```
关键：**技术融合把「模块可信」升级为「接缝可验证」**——assume-guarantee 契约 + 融合债 + 相关性校正，杜绝「组合后凭空更自信」；**手势识别把「识别正确」降格为「意图证据」**——校准、拒识、活体、溯源、权限封顶，杜绝「一个误检标签直接驱动不可逆动作」；**单向安全闸门**保证手势可以随时让系统更保守，但永远不能单独让系统更激进。三条安全单向通道继续延伸：**信念更准（相关校正融合）、不确定性更大（融合债/意图歧义）、动作更保守（澄清/安全停优先）**。

### IP-152 FTC（融合拓扑契约检查器）

```python
from dataclasses import dataclass
from typing import Set, Tuple, Dict

@dataclass(frozen=True)
class InterfaceContract:
    unit: str                 # "N", "m", "rad/s", "prob"
    frame: str                # "base_link", "camera", "tool0"
    clock_domain: str         # "control_1ms", "vision_30hz", "human_event"
    max_age: float            # 时间戳最大年龄 (s)
    unc_type: str             # "gaussian" | "interval" | "conformal" | "deterministic"
    auth_ceiling: str         # "A0_observe" ... "A3_irreversible_candidate"
    failure_mode: str         # "fail_stop" | "fail_safe" | "fail_operational"
    version: str
    test_suite: str

@dataclass
class FusionModule:
    A: Set[str]               # 输入/环境假设
    G: Set[str]               # 输出保证
    delta: float              # 失效概率上界
    cert: "Certificate"
    kappa: InterfaceContract

class FusionTopologyContract:
    def __init__(self, modules: Dict[str, FusionModule], edges, weights):
        self.m = modules
        self.edges = edges
        self.w = weights
        self.topo_version = sha256(
            str((sorted(modules), edges, weights)).encode()).hexdigest()

    def contract_test(self, mi, mj) -> ContractTestResult:
        ki, kj = mi.kappa, mj.kappa
        compatible = (
            ki.unit == kj.unit and
            ki.frame == kj.frame and
            ki.unc_type == kj.unc_type and
            ki.auth_ceiling == kj.auth_ceiling and
            abs(clock_offset(ki.clock_domain, kj.clock_domain)) <= MAX_SKEW and
            min_age_bound(ki, kj) <= MAX_AGE
        )
        # assume-guarantee 双向 discharge 必须由测试证明，而非人工签字
        ag = (implies(mi.G, mj.A) and implies(mj.G, mi.A))
        coverage, failures = run_contract_suite(ki.test_suite, kj.test_suite,
                                                mi, mj, n_cases=N_CONTRACT)
        seam = (1.0 - coverage) * (1.0 - empirical_pass_rate(failures))
        return ContractTestResult(compatible, ag, coverage, seam, failures)

    def compose(self, mi, mj):
        r = self.contract_test(mi, mj)
        if not (r.compatible and r.ag and r.coverage >= 1 - EPS_C):
            raise CompositionError(r)
        return FusionModule(
            A=(mi.A - mj.G) | (mj.A - mi.G),
            G=mi.G | mj.G,
            delta=min(1.0, mi.delta + mj.delta + r.seam),
            cert=compose_certificates(mi.cert, mj.cert, r),
            kappa=merge_kappa(mi.kappa, mj.kappa))

    def well_formed(self, F):
        reports = []
        for (i, j) in F.E:
            r = self.contract_test(F.m[i], F.m[j])
            reports.append(r)
            if not (r.compatible and r.ag and r.coverage >= 1 - EPS_C):
                return False, f"seam_violation:{(i,j)}", reports
        debt = self.debt(F, reports)
        if debt > D_MAX:
            return False, f"fusion_debt:{debt:.3f}", reports
        if not all(v >= PHI_MIN for v in self.maturity(F).values()):
            return False, "fusion_maturity", reports
        return True, "ok", reports

    def debt(self, F, reports):
        # 每个接缝的每条假设，未测试/测试过期/漂移都计入
        d = 0.0
        for (e, r) in zip(F.E, reports):
            a_set = F.assumptions(e)
            u = []
            for a in a_set:
                t = self.latest_test(e, a)
                drift = self.drift_monitor(a, e)
                u.append(1.0 if t is None or t.expired else max(t.residual, drift))
            d += self.w[e] * (sum(u) / max(1, len(u)))
        return d

    def maturity(self, F):
        return {
            "sem": min(semantic_score(e) for e in F.E),
            "time": min(clock_alignment_score(e) for e in F.E),
            "unc": min(uncertainty_commensurability(e) for e in F.E),
            "auth": min(authority_consistency(e) for e in F.E),
            "test": min(contract_coverage(e) for e in F.E),
        }
```

### IP-153 FQM（融合债与成熟度计量）

```python
class FusionQualityMeter:
    def __init__(self, debt_bound=D_MAX, phi_min=PHI_MIN):
        self.D_max = debt_bound
        self.phi_min = phi_min
        self.history = []          # 融合债轨迹，只增不删

    def estimate(self, F, contract_report):
        debt = 0.0
        per_edge = {}
        for e, r in zip(F.E, contract_report):
            assumptions = F.assumptions(e)
            u = [self._unverified(e, a) for a in assumptions]
            contribution = F.weight(e) * (np.mean(u) if u else 0.0)
            per_edge[e] = contribution
            debt += contribution
        # 融合债单调保护：若新增证据反而降低债，必须给出独立复测证据
        if self.history and debt < self.history[-1].debt - EPS_DEBT_DECREASE:
            if not self._has_independent_retest(F):
                debt = self.history[-1].debt
        self.history.append(FusionDebtSample(time_now(), debt, per_edge))
        return debt

    def _unverified(self, e, assumption):
        t = self.tests.get((e, assumption))
        if t is None or t.expired:
            return 1.0
        drift = self.drift.upper_bound(e, assumption)   # 上界，不是点估计
        return min(1.0, max(t.residual, drift))

    def gate(self, F):
        debt = self.estimate(F, self.contract_report)
        ok = debt <= self.D_max and all(
            v >= self.phi_min for v in self.maturity(F).values())
        return ok, debt
```

### IP-154 GEC（手势证据校准器）

```python
class GestureEvidenceCalibrator:
    def __init__(self, recognizer, signer_db, liveness, calibration_set):
        self.rec = recognizer
        self.signers = signer_db
        self.liveness = liveness
        # 必须在 signer-disjoint 的留出集上拟合，不得使用训练同分布
        self.temperature = fit_temperature(calibration_set, split="signer_disjoint")
        self.ece = evaluate_ece(calibration_set, self.temperature, split="signer_disjoint")

    def process(self, stream, operator_session):
        evidences = []
        for seg in segment(stream):
            logits = self.rec.logits(seg.skeleton, seg.depth)
            p = softmax(logits / self.temperature)
            spoof = self.liveness.score(seg)              # 深度+微动+反射
            signer = self.signers.identify(seg, operator_session)
            bound = (signer is not None and signer.session == operator_session
                     and seg.t_start >= operator_session.start)
            liveness_ok = spoof <= DELTA_SPOOF

            conf = float(p.max())
            label = int(p.argmax())
            if not liveness_ok or not bound or conf < TAU_REJECT:
                y, cap = "unknown", AuthorityCap.A0_OBSERVE
            elif label in (STOP, RELEASE):
                # 安全方向：低阈值、高召回；即使置信略低也应触发
                y, cap = label, AuthorityCap.A1_STOP_ONLY
            else:
                y, cap = label, AuthorityCap.A2_REVERSIBLE

            evidences.append(GestureEvidence(
                p=p, label=y, window=(seg.t_start, seg.t_end),
                confidence=conf, spoof_score=spoof, signer_id=signer.id if signer else None,
                liveness_ok=liveness_ok, authority_cap=cap,
                provenance=Provenance(seg.t_start, signer, self.rec.version,
                                      operator_session.consent_state, hash(seg))))
        return evidences

    def stop_channel(self, evidences):
        # 停止通道独立于授权通道：任一有效 stop/release 即触发，不需要佐证
        return any(e.label in (STOP, RELEASE) and e.liveness_ok
                   and e.authority_cap == AuthorityCap.A1_STOP_ONLY
                   for e in evidences)

    def risk_coverage_curve(self):
        return selective_risk_coverage(self.rec, self.calibration_set,
                                       self.temperature, splits=["signer", "distance", "lighting"])
```

### IP-155 MIF（相关性校正的多模态意图融合）

```python
class MultimodalIntentFusion:
    def __init__(self, loss_matrix, corr_estimator):
        self.L = loss_matrix            # L[a][y]，真实代价的诚实上界
        self.corr = corr_estimator      # 从留出集误差估计 R

    def fuse(self, evidence: dict, prior, R):
        names = list(evidence)
        n = len(names)
        R = ensure_psd(R)
        rho_bar = np.mean(np.abs(R - np.eye(n))) * n / max(1, n - 1)
        n_eff = n / (1 + (n - 1) * rho_bar)          # 相关证据的保守折扣

        # 广义最小二乘权重；相关越强，权重越互相抵消
        w = np.linalg.solve(R, np.ones(n))
        w = np.clip(w / w.sum(), 0, None)
        w = w / w.sum()

        log_post = np.log(prior + EPS)
        for wi, name in zip(w, names):
            L_i = evidence[name].likelihood          # 归一化似然
            log_post += wi * np.log(L_i + EPS)
        post = normalize(np.exp(log_post))

        # 保守上界：融合对数增益不得超过 n_eff 倍单模态最大增益
        gains = [kl_divergence(evidence[k].likelihood, prior) for k in names]
        if n_eff * max(gains) < sum(gains):
            post = conservative_backoff(post, prior, n_eff, gains)
        return IntentPosterior(post, n_eff=n_eff, rho_bar=rho_bar, weights=w)

    def decide(self, post, corroboration, irreversible):
        risk = {a: sum(self.L[a][y] * post.p[y] for y in post.labels)
                for a in ACTIONS}
        if irreversible and (corroboration < K_IRR or
                             not corroboration.sources - {"gesture"}):
            return "clarify" if risk["clarify"] <= risk["safe_stop"] else "safe_stop"
        if risk["authorize"] <= DELTA_INTENT and corroboration.count >= K_REQ(post.label):
            return "authorize"
        if risk["clarify"] < risk["safe_stop"] and budget_for_clarify():
            return "clarify"
        return "safe_stop"
```

### IP-156 HICP（人机意图共识协议）

```python
class HumanIntentConsensus:
    def __init__(self, K=K_CONSENSUS, mi_min=MI_MIN, h_max=H_MAX):
        self.K, self.mi_min, self.h_max = K, mi_min, h_max
        self.ledger = IntentProvenanceLedger()

    def step(self, b_h, b_r, post, turn, history):
        mi = mutual_information(b_h, b_r)
        h = entropy(post.p)
        if mi >= self.mi_min and h <= self.h_max:
            self.ledger.append("consensus", post, turn)
            return Consensus("aligned", None)
        if self._conflicting_referents(post):
            self.ledger.append("conflict", post, turn)
            return Consensus("conflicting", Action.SAFE_STOP)
        if turn >= self.K:
            # 禁止默认同意：超时只能安全停或转人工
            self.ledger.append("timeout", post, turn)
            return Consensus("ambiguous", Action.SAFE_STOP)
        a = max(Action.clarify_set(),
                key=lambda a: expected_information_gain(a, b_h, b_r, post))
        self.ledger.append(f"clarify:{a}", post, turn)
        return Consensus("ambiguous", a)

    def _conflicting_referents(self, post):
        # 手势指向 A、注视/语音指向 B => 冲突，不得取平均
        refs = [r for r in post.referents if r.prob >= REF_MIN]
        return len(set(refs)) > 1
```

### IP-157 FIG-CLEP（融合—意图—承诺闭环）

```python
def fig_clep(M, cp, delta_f_req, budget):
    # ① 接缝契约：任何未认证的组合都不得进入承诺
    ok, why, reports = M.ftc.well_formed(M.F)
    debt = M.fqm.estimate(M.F, reports)
    if not ok or debt > M.D_max:
        M.fusion_log.append(("degrade", why, debt))
        return degrade_fusion(M, cp, why or "fusion_debt")

    # ② 手势证据：校准 + 拒识 + 活体 + 签署者绑定 + 权限封顶
    E_g = M.gec.process(M.gesture.stream(cp.window), M.operator_session)

    # ③ 停止通道优先：手势→保守方向无需佐证
    if M.gec.stop_channel(E_g):
        return safe_stop(M, cp, "gesture_stop", E_g)

    # ④ 多模态意图融合（相关性校正 + 不对称损失）
    ev = M.evidence_at(cp)                       # vis/tap/prop/acou/exec...
    ev["gesture"] = GestureEvidenceAdapter.last(E_g)
    post = M.mif.fuse(ev, M.intent_prior, M.R_corr)
    corr = M.corroboration(cp, exclude={"gesture"})

    # ⑤ 共识
    c = M.hicp.step(M.b_h, M.b_r, post, M.turn, M.consensus_history)
    if c.state == "conflicting":
        return safe_stop(M, cp, "intent_conflict", E_g, post)
    if c.state == "ambiguous":
        if c.action == Action.SAFE_STOP:
            return safe_stop(M, cp, "consensus_timeout", E_g, post)
        return clarify(M, cp, c.action, E_g, post)

    # ⑥ 授权判定
    a_intent = M.mif.decide(post, corr, cp.irreversible)
    if a_intent != "authorize":
        return refuse_or_clarify(M, cp, a_intent, post)
    if cp.irreversible and not corr.has_non_gesture_source():
        return refuse_or_clarify(M, cp, "clarify", post)

    # ⑦ 进入既有 CLEP（BUQ/ERTC/XMC+/EEIS/执行）
    M, fused, D_plus, EV_exec, Cert_eeis = closed_loop_exec_probe(
        M, cp, delta_f_req, budget)
    if EV_exec.degraded_flag:
        return degrade_fusion(M, cp, "exec_degraded")

    # ⑧ 融合证书（与 J_exec 版本链交叉引用）
    J_fuse = build_fusion_certificate(
        topo=M.F, reports=reports, debt_traj=M.fqm.history,
        gesture=E_g, post=post, consensus=c, action=a_intent,
        provenance=M.hicp.ledger, j_exec=M.J_exec.latest())
    budget.spend_fuse(M, cp, debt, post.n_eff, len(ev))
    return M, fused, EV_exec, Cert_eeis, J_fuse

def degrade_fusion(M, cp, reason):
    M.fusion_degraded = True
    # 回退到经认证的单模态 + 最保守动作；不得继续拼接未认证模块
    return dispatch_safe_fallback(M, cp, reason)
```

### IP-158 J_fuse（融合证书）

```python
@dataclass
class FusionCertificate:

    contract_test_report: list

```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FTC | O(\|E\|·(\|A_e\|+N_contract)) 每拓扑/版本变更 | O(\|V\|+\|E\|+测试报告) | 双向 A-G discharge、覆盖 ≥1−ε_c、版本不可跨用 |
| FQM | O(\|E\|·\|A_e\|) / 续约周期 | O(\|E\|+历史) | 债为上界、单调保护、漂移只增、超界即降级 |
| GEC | O(T·d + N_cal) 校准；O(T·d) 在线 | O(签名库+词表) | 跨签署者 ECE≤ε_g、risk–coverage、FAR_spoof≤δ_spoof |
| MIF | O(n³) 相关求逆 + O(n·\|𝒴\|) | O(n²+\|𝒴\|) | n_eff 保守、增益上界、非负权重、不对称损失 |
| HICP | O(K·\|𝒴\|·\|A_c\|) | O(\|𝒴\|+账本) | K 轮终止、无默认同意、冲突/超时安全停 |
| FIG-CLEP | O(FTC+FQM+GEC+MIF+HICP+CLEP) ≈ 300μs | 复用 CLEP | 单向安全闸门、不可逆 k_irr 独立佐证、降级即保守 |
| J_fuse | O(1)/事件追加；O(N) 验证 | O(事件数) | 版本单增、溯源连续、校准未过期、与 J_exec 对齐 |

**正确性定理（Fusion-Intent Soundness, FIS）**
假设 A22–A55（第 53–59 轮）成立；**(A56)** FTC：每个接缝的 `assume-guarantee` 双向蕴含由契件测试以覆盖率 ≥1−ε_c 验证；`δ_seam` 诚实上界未覆盖残余风险；单位/坐标系/时钟/不确定语义/权限任一不兼容即拒绝组合。**(A57)** FQM：`D_fuse` 是接口假设失效概率的上界；漂移监测只增大债；任何债下降必须有独立复测证据；`D_fuse>D_max` 或成熟度不达标 ⇒ 禁止新增融合并触发 `DEGRADE_FUSION`。**(A58)** GEC：校准在 signer-disjoint 留出集上完成，`ECE_g≤ε_g`；拒识机制可被使用且 risk–coverage 达标；活体 `FAR_spoof≤δ_spoof`；签署者绑定/时间窗/同意状态溯源诚实；权限封顶不可被识别器绕过。**(A59)** MIF：误差相关矩阵 `R` 的上界估计给出保守 `n_eff`；相关校正后融合对数增益 `Δ_fused≤n_eff·max_i Δ_i`；损失矩阵 `L` 为真实代价上界；不可逆动作要求 `k_irr≥2` 且至少一个非同源、非手势佐证。**(A60)** HICP：协议在 `K_consensus` 轮内终止；不存在默认同意路径；冲突/超时一律安全停或转人工；溯源账本只追加、哈希链连续。则：

1. **组合健全性**：若融合拓扑 `F` 良构，则
```
P_fail(⊗_{m∈F} m) ≤ Σ_{m∈F} δ_m + Σ_{e∈E} δ_seam(e) + D_fuse(F)
```
且组合不会产生任何未计入该界的置信度增益；**技术融合的收益必须由「独立的、契约覆盖的接缝」支付，不能由「接口看起来一致」赊账。**
2. **无免费融合（相关性税）**：对任意证据集 `ℰ` 与相关矩阵 `R`，
```
Δ_fused ≤ n_eff·max_i Δ_i ≤ Σ_i Δ_i
```
当 `ρ̄>0` 时严格小于独立融合界；因此**相关模态只能被当作一个多一点的模态使用**，不能重复计数。
3. **手势授权安全性**：不可逆动作被手势单独授权的概率为 0；对可逆授权，
```
Pr[错误授权] ≤ δ_intent + ε_g + δ_spoof + P(corroboration < k_req)
```
而「手势→更保守」路径（stop/release/减速）不在此界内，可无条件触发。
4. **单向安全闸门**：FIG-CLEP 的任一动作，其保守性不低于仅用 CLEP 时的对应动作；手势证据只能通过「触发停止/澄清/拒绝」或「在独立佐证下升级授权」产生影响，**不能修改 ERTC 的 WCET/Jitter 界、不能修改 EEIS 的 `K_safe`、不能绕过不可逆禁令**。
5. **共识终止与责任可追溯**：每个授权动作都可追溯到一条完整 `P` 链；冲突/歧义/超时终止于澄清或安全停；`J_fuse.verify_chain()` 可独立复核接缝测试、融合债、手势校准、`k_irr` 佐证与 `J_exec` 对齐。
6. **部署界**（对检查点取联合界）：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD]
                   + δ_ertc·1[契约违例] + δ_eeis·1[μ分析漏报]
                   + δ_seam·1[接缝未覆盖] + D_fuse·1[融合债超界]
                   + δ_intent·1[意图歧义] + δ_spoof·1[活体失败]
                   + δ_consensus·1[共识超时])
         − P(𝒢 结构性错误未检出) − P(护盾回退失败) − P(τ_int 超时 ∧ 安全停失效)
         − P(固件回滚失败) − P(溯源账本被篡改)
```
关键：**FTC 把「技术融合」从接口适配升级为可判定的 assume-guarantee 组合**；**FQM 把未验证接缝变成进入安全界的融合债**；**GEC 把「手势识别」从命令通道降格为校准、拒识、溯源、权限封顶的意图证据**；**MIF 用相关性税与不对称损失消除虚假置信**；**HICP 用共识替代默认同意**；**FIG-CLEP/J_fuse 让「融合—意图—承诺」可审计**。三条安全单向通道延续并扩展到交互层：**信念更准（有契约的融合）、不确定性更大（融合债/意图歧义/相关性税）、动作更保守（停止免费、授权收费）**。

## 6. 本轮最大风险

**一句话**：本轮把「模块可信」升级为「接缝可验证」，但最大风险是**融合债被系统性低估、手势假阳性又被相关性校正后的融合放大**——若契约测试只覆盖 happy path、相关矩阵滞后于现场分布漂移、或不可逆动作的「独立佐证」退化为同源模型的另一个输出头，系统就会在一条看似严谨的证书链下完成一次错误授权；必须以「接缝故障注入 + 融合债只增不减 + 手势绝不单独授权不可逆 + 至少一个非同源佐证 + 冲突/超时一律安全停」五重护栏死守。
