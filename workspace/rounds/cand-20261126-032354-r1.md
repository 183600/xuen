## 0. 直觉与动机

**灵感 1（机械臂 → 安全契约从"永不接触"变为"受控接触"）**
直觉：v18–v23 的全部证书都建立在一个隐含公理上——"碰撞 = 失败"，所以执行集 = 无碰撞构型集合。但机械臂要工作就必须**主动接触**：夹爪合拢、手指压住物体、物体压住桌面。抓取不是碰撞的失败，而是一次**被认证的接触**。因此安全不变量必须随**模式**切换：自由运动模式下仍是"零接触"；接触/抓取模式下变成"接触力始终落在已认证的摩擦锥内，且法向力不超过夹爪能力"。核心创新：**混合接触模式自动机 (Hybrid Contact-Mode Automaton, HCMA)**，把执行集按模式分层 `Exec_v24 = ⊔_q Exec_q`，每个模式的容许集都是 v23 同一构型容许集的子集——接触只"换约束"，不"放宽约束"。关键反直觉点：**进入接触模式是唯一一次安全契约的降级，但它必须由一张抓取证书"预付费"，而不是由规划器自行宣布。**

**灵感 2（抓取规划 → 抓取是离散、不可逆、带不确定参数的承诺）**
直觉：与连续轨迹不同，抓取是**离散的、带锁存的承诺**：一旦合拢，机器人几何多了一个物体、质量多了一份载荷、失败模式多了一种打滑；而且"后悔"是昂贵的——退不回原位（载荷挡住退路），松手可能摔坏物体或砸到人。同时物体参数（质量 m、摩擦 μ、质心 com）**从未被精确知道**，只有视觉估计加误差。核心创新：**鲁棒力闭合证书 (Robust Force Closure Certificate, RFCC)**——用摩擦系数的 **conformal 下界 μ⁻**（而非点估计）做力闭合判定，用质量/质心的 conformal 上界 `m⁺, com⁺` 做能量与动力学预算；**不可逆承诺证书 (Irreversible Commitment Certificate, ICC)**——抓取前必须证明"抓后还能安全退出"，释放前必须证明"松手后状态安全（有支撑 / 有人接 / 有安全落点）"。关键反直觉点：**"能抓住"和"能安全地抓住并放开"是两个不同的谓词；前者是力闭合，后者是不可逆承诺——只证前者是 v24 最容易犯的错。** 抓取规划的搜索空间是"离散接触点 × 连续位姿/力"的混合空间，必须**验证在环 (verification-in-the-loop)**：证书是过滤器，不是排序分。

**三者如何统一（机械臂 × 抓取规划 × v23 证书链）**
把 v23 的"运动证书"扩展为**操作证书**：SDC 提供物体类别与包围盒（抓取目标的身份与几何），CAC 提供落点/交接区的缺席证据，GIC 提供交接意图，ACSC/PGEV 提供臂的能量与配空间边界；新增 GVC/RFCC/ICC/PCDC 提供"抓得住、抓得稳、退得出、放得下"。共享状态扩展为 `ζ_manip = ζ_ce ∪ (q_mode, g, μ⁻, m⁺, W, retreat_ok, release_ok)`。统一准入门 **GMC = HPC-E+ ∧ GVC ∧ PCDC ∧ ICC**。单调链：`Exec_v24 = ⊔_q Exec_q ⊆ Exec_v23(Obs ∪ Payload) ⊆ Exec_v23(Obs)`。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P47）

**P43 接触模式契约律（Contact-Mode Safety Contract）**
安全不变量按模式定义：`Inv_Free : dist(robot, Obs) > d_safe`；`Inv_Contact : ∀i, f_i ∈ K_i(μ_i⁻) ∧ f_{n,i} ≤ f_grip,max ∧ |slip| ≤ ṡ_max`；`Inv_Grasp/Transport : Inv_Contact ∧ payload ⊆ CertBox_payload`。模式迁移由守卫触发，遵循**低门槛中止、高门槛推进**：任一模式可低门槛进入 SafeHold（力越锥、打滑、能量越界、感知失证），而推进到下一模式（尤其接触与释放）必须持相应证书。每个模式的容许集定义为 `Exec_q = Exec_v23|_q ∩ Inv_q`，故 `Exec_q ⊆ Exec_v23|_q`。

**P44 鲁棒力闭合律（Robust Force Closure under Parameter Uncertainty）**
抓取 `g` 可证当且仅当：(i) 用 `μ_i⁻ = max(0, μ̂_i − q_{1-α})` 采样的摩擦锥构造抓取扳手空间 `W(g)`，且 `0 ∈ int(conv W(g))`（力闭合）；(ii) 抓取质量 `ε(g)`（`conv W(g)` 内以原点为心的最大球半径）满足 `ε(g) ≥ ε_min`；(iii) 每个接触点位于 SDC 证书的物体表面（而非膨胀后的自由空间）；(iv) 所需法向力 `f_n ≤ f_grip,max` 且关节力矩在限内。**点估计 μ̂ 永不用于闭合判定**；用 μ⁻ 使闭合对摩擦不确定性单调保守。

**P45 不可逆承诺律（Irreversible Commitment）**
抓取与释放是锁存动作。抓取前置条件 `RetreatOK(g)`：在"抓取后构型 + 载荷障碍"下存在无碰撞退出路径，或任务显式接受"抓后不退出"（此时必须已证释放安全）。释放前置条件 `ReleaseOK(r)`：`(支撑 ∧ 静平衡(μ⁻)) ∨ (交接 ∧ GIC 高门槛 ∧ 接收方就绪) ∨ (安全落点 ∧ AbsCert ∧ E_impact ≤ E_drop,max)`。空中无条件松手被禁止。`RetreatOK ∧ ReleaseOK` 任一不可满足 → 不进入该模式（回到上一模式或 SafeHold），绝不静默死锁。

**P46 载荷耦合单调律（Payload-Coupled Monotonicity）**
抓取后 `Obs_t ← Obs_t ∪ CertBox_payload(m⁺, com⁺)`、`E_budget ← E_budget − E_payload(m⁺, com⁺)`、臂有效惯量 `M_eff = M_arm + J^T M_payload J`。三者单调：障碍只增、能量只减、惯量只增（不确定性一律取上界）。因此 v24 的搬运轨迹在"放大后的障碍集"下是 v23 可行的，进而 `Proj_motion(Exec_v24) ⊆ Exec_v23(Obs ∪ Payload) ⊆ Exec_v23(Obs)`。

**P47 验证在环抓取搜索律（Verification-in-the-Loop Grasp Search）**
抓取候选由生成器产生（类别→抓取先验），但**每个候选必须先过证书预言机**（RFCC ∧ ICC ∧ PCDC）才进入质量排序；排序分 `ε(g)` 不能替代证书。证书预言机可缓存、惰性求值、摊销：同 (物体实例, 接触拓扑) 复用；只有排序前 K 个候选做完整证书，其余用快速上界筛除。**高置信度不等于可执行性**。

## 3. 与基线的接口（如何退化）

- GVC/RFCC 失效（摩擦不可估）⇒ 禁用抓取，退回 v23 纯运动 ⇒ 子集；
- PCDC 失效（载荷参数不可信）⇒ 不搬运（原地保持或仅放置），`E_payload` 取上界 ⇒ 更保守；
- ICC 失效 ⇒ 只允许"抓后能退回原位"的抓取，禁止空中释放 ⇒ 子集；
- HCMA 失效 ⇒ 冻结在 Free 模式 ⇒ 等价 v23；
- 接触瞬态超调（冲量越界）⇒ 低门槛退入 SafeHold，力控回撤 ⇒ 不扩大执行集；
- 全部失效 ⇒ 完全退回 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ ... ⊆ Exec_v18`。
- **安全继承**：接触只换约束不放宽、载荷只增障碍/减能量/增惯量、释放只在高门槛下发生；任意失效都向更保守方向退化。

## 5. 本轮最大风险

**一句话**：整套力闭合与释放安全都押在摩擦/接触模型上，而 conformal 的 μ⁻ 仅在标定分布内有效——一旦遇到湿滑、油污、可变形或强逆光的分布外接触，证书会**形式成立、物理打滑**，机器人便"合规地、可审计地"把物体摔落或撞向本应被它护住的区域——即**被认证的滑落 (certified slip)**。

## 1. 关键算法骨架（在 IP-440–446 上实现）

```python
# ============================================================
# IP-441 / IP-440  Robust Force Closure + Grasp Viability
# ============================================================
import numpy as np
from dataclasses import dataclass
from scipy.spatial import ConvexHull
from scipy.optimize import linprog


@dataclass
class Contact:
    p: np.ndarray          # 接触点（世界系）
    n: np.ndarray          # 内法向（指向物体内部，单位）
    mu_hat: float          # 摩擦系数点估计
    mu_low: float          # conformal 下界 μ⁻


@dataclass
class GraspPlan:
    obj_id: str
    contacts: list[Contact]
    T_ee: np.ndarray       # 末端位姿 4x4
    f_grip: float          # 夹持力上限
    approach_dir: np.ndarray


def friction_cone_edges(c: Contact, k: int = 8) -> np.ndarray:
    """把摩擦锥线性化为 k 条边向量；用 μ⁻ 而非 μ̂（保守）。"""
    mu = max(0.0, c.mu_low)
    t1 = _unit(np.cross(c.n, _arbitrary_perp(c.n)))
    t2 = np.cross(c.n, t1)
    dirs = []
    for j in range(k):
        a = 2.0 * np.pi * j / k
        d = c.n + mu * (np.cos(a) * t1 + np.sin(a) * t2)
        dirs.append(_unit(d))
    return np.array(dirs)                       # (k, 3)


def _wrench(direction: np.ndarray, p: np.ndarray) -> np.ndarray:
    return np.concatenate([direction, np.cross(p, direction)])


def grasp_wrench_space(g: GraspPlan, k: int = 8) -> np.ndarray:
    W = []
    for c in g.contacts:
        for d in friction_cone_edges(c, k):
            W.append(_wrench(d, c.p))
    return np.asarray(W)                        # (|C|·k, 6)


def force_closure_margin(W: np.ndarray) -> float:
    """ε(g)：原点在 conv(W) 内的内切球半径下界（Ferrari–Canny 近似）。
    生产实现用 LP：max ε s.t. ε·d_j ∈ conv(W) 对采样方向 d_j 成立。"""
    if len(W) < 7:
        return 0.0
    try:
        hull = ConvexHull(W)
    except Exception:
        return 0.0
    # hull.equations: A x + b ≤ 0；原点到各面距离最小值的负号即内切半径
    dists = -(hull.equations[:, :6] @ np.zeros(6) + hull.equations[:, 6])
    return float(max(0.0, dists.min()))


@dataclass
class GraspViabilityCertificate:
    g: GraspPlan
    eps: float
    force_closed: bool
    within_force_limit: bool
    contacts_on_certified_surface: bool

    @staticmethod
    def build(g: GraspPlan, eps_min: float, sdc) -> "GraspViabilityCertificate":
        W = grasp_wrench_space(g)
        eps = force_closure_margin(W)
        fc = eps >= eps_min
        force_ok = all(np.linalg.norm(c.n) > 1e-9 for c in g.contacts) and g.f_grip > 0.0
        surf_ok = all(sdc.contains_surface(c.p) for c in g.contacts)
        return GraspViabilityCertificate(g, eps, fc, force_ok, surf_ok)

    def admits(self) -> bool:
        return self.force_closed and self.within_force_limit and self.contacts_on_certified_surface

@dataclass
class PayloadCoupledDynamicsCertificate:
    m_plus: float              # 质量 conformal 上界
    com_plus: np.ndarray       # 质心不确定集中心
    com_radius: float          # 质心不确定球半径
    CertBox_payload: "Box"     # 载荷几何包围盒
    E_payload: float           # 载荷能耗上界

    @staticmethod
    def build(obj, m_hat, m_q, com_hat, com_q, geom_unc, lift_h) -> "PayloadCoupledDynamicsCertificate":
        m_plus = m_hat + m_q
        com_plus = com_hat
        certbox = obj.certbox.inflate(geom_unc + com_q)
        E_payload = m_plus * 9.81 * (lift_h + com_q) * 1.1   # 保守上界
        return PayloadCoupledDynamicsCertificate(m_plus, com_plus, com_q, certbox, E_payload)

    def energy_budget(self, E_res, E_fallback, E_arm, E_reach_safe, E_margin) -> float:
        return E_res - (E_fallback + E_arm + E_reach_safe + E_margin) - self.E_payload

    def admits(self, E_res, E_fallback, E_arm, E_reach_safe, E_margin) -> bool:
        return self.energy_budget(E_res, E_fallback, E_arm, E_reach_safe, E_margin) >= 0.0

    def effective_inertia(self, M_arm: np.ndarray, J: np.ndarray, I_payload: np.ndarray) -> np.ndarray:
        return M_arm + J.T @ I_payload @ J

# IP-444  Irreversible Commitment Certificate (ICC)
# ============================================================
@dataclass
class IrreversibleCommitmentCertificate:
    retreat_ok: bool
    release_ok: bool
    release_mode: str            # "support" | "handover" | "safe_drop" | "none"
    witness: dict

    @staticmethod
    def check_pre_grasp(g: GraspPlan, motion_planner, obs_augmented,
                        accept_no_retreat: bool) -> "IrreversibleCommitmentCertificate":
        path = motion_planner.plan(g.T_ee, target="retreat", obstacles=obs_augmented)
        retreat_ok = path is not None
        if not retreat_ok and not accept_no_retreat:
            return IrreversibleCommitmentCertificate(False, False, "none", {})
        # 若接受"抓后不退出"，则必须已证释放安全（由 release 检查补足）
        return IrreversibleCommitmentCertificate(retreat_ok, accept_no_retreat,
                                                 "pending_release", {"path": path})

    @staticmethod
    def check_release(r, support_surface, gic, cac, E_impact_max) -> "IrreversibleCommitmentCertificate":
        # (a) 支撑：静平衡（用 μ⁻ 的摩擦锥）
        if support_surface is not None and support_surface.stable_rest(r, mu_low=True):
            return IrreversibleCommitmentCertificate(True, True, "support", {"surface": support_surface.id})
        # (b) 交接：GIC 高门槛（conformal Γ⊆{handover} ∧ 目标区 AbsCert ∧ ≥2 模态）
        if gic is not None and gic.high_confidence_handover(r.target) and cac.absent(r.target):
            return IrreversibleCommitmentCertificate(True, True, "handover", {"receiver": r.target})
        # (c) 安全落点：区域无人的缺席证书 + 冲击能上界
        if cac.absent(r.drop_zone) and r.E_impact <= E_impact_max:
            return IrreversibleCommitmentCertificate(True, True, "safe_drop", {"zone": r.drop_zone})
        return IrreversibleCommitmentCertificate(True, False, "none", {})

# IP-443  Hybrid Contact-Mode Automaton (HCMA)
# ============================================================
class HybridContactModeAutomaton:
    def __init__(self, eps_min=0.01, slip_max=0.02, force_slack=1.1):
        self.q = "Free"
        self.eps_min = eps_min
        self.slip_max = slip_max
        self.force_slack = force_slack

    def _violation(self, sensors, certs) -> bool:
        if sensors.get("slip", 0.0) > self.slip_max:
            return True
        if not sensors.get("force_in_cone", True):
            return True
        if certs.get("pcdc") is not None and not certs["pcdc"].admits(**certs["energy_args"]):
            return True
        if sensors.get("sensor_stale", False):      # 接入 v17 APS 新鲜度阶梯
            return True
        return False

    def step(self, sensors: dict, certs: dict) -> str:
        # 低门槛中止：任一模式均可进入 SafeHold
        if self._violation(sensors, certs):
            self.q = "SafeHold"
            return self.q

        # 高门槛推进
        if self.q == "Free":
            if certs.get("gvc") is not None and certs["gvc"].admits() and sensors.get("target_reachable"):
                self.q = "Approach"
        elif self.q == "Approach":
            if sensors.get("contact_established") and sensors.get("force_in_cone"):
                self.q = "Contact"
        elif self.q == "Contact":
            if certs["gvc"].admits() and sensors.get("force_closure_verified"):
                self.q = "Grasp"
        elif self.q == "Grasp":
            if certs.get("pcdc") is not None and certs.get("icc") is not None \
                    and certs["icc"].retreat_ok:
                self.q = "Transport"
        elif self.q == "Transport":
            if sensors.get("at_release_pose") and certs.get("icc_release") is not None \
                    and certs["icc_release"].release_ok:
                self.q = "Release"
        elif self.q == "Release":
            if sensors.get("released"):
                self.q = "Retreat"
        elif self.q == "Retreat":
            if sensors.get("retreated") or sensors.get("task_done"):
                self.q = "Free"
        return self.q

# IP-445  Verification-in-the-Loop Grasp Planner (ViL-GP)
# ============================================================
class VerificationInTheLoopGraspPlanner:
    def __init__(self, generator, sdc, motion_planner, eps_min=0.01, K_full=16):
        self.generator = generator          # 类别→抓取先验（可来自 DCSC 骨干）
        self.sdc = sdc
        self.motion_planner = motion_planner
        self.eps_min = eps_min
        self.K_full = K_full
        self._cache = {}                    # (obj_id, contact_topology) → 证书

    def plan(self, obj, energy_args, accept_no_retreat=False):
        cands = self.generator(obj)
        # 1) 快速上界筛除（O(1) 近似，不构成承诺）
        ranked = []
        for g in cands:
            ub = self._quick_upper_bound(g)
            if ub < self.eps_min:
                continue
            ranked.append((ub, g))
        ranked.sort(key=lambda x: -x[0])

        # 2) 仅前 K 个做完整证书
        for _, g in ranked[: self.K_full]:
            key = (g.obj_id, frozenset((tuple(c.p.round(3)) for c in g.contacts)))
            if key in self._cache:
                gvc, pcdc, icc = self._cache[key]
            else:
                gvc = GraspViabilityCertificate.build(g, self.eps_min, self.sdc)
                if not gvc.admits():
                    continue
                pcdc = PayloadCoupledDynamicsCertificate.build(obj, *obj.payload_stats())
                obs_aug = obj.scene.obstacles.union(pcdc.CertBox_payload)
                icc = IrreversibleCommitmentCertificate.check_pre_grasp(
                    g, self.motion_planner, obs_aug, accept_no_retreat)
                self._cache[key] = (gvc, pcdc, icc)
            if not gvc.admits() or not icc.retreat_ok:
                continue
            if not pcdc.admits(**energy_args):
                continue
            return g, gvc, pcdc, icc
        return None                          # 无已认证抓取 → 不抓（退回 v23）

    def _quick_upper_bound(self, g: GraspPlan) -> float:
        """用 μ̂ 与少采样快速估计 ε 上界；只用于排序/筛除，不作承诺。"""
        W = grasp_wrench_space(g, k=4)
        return force_closure_margin(W)

# IP-446  GMC Gate（统一操作准入门）
# ============================================================
@dataclass
class GMCGate:
    hpce_plus: "HPCEPlus"

    def admits(self, plan, g, gvc, pcdc, icc, hpce_args, energy_args) -> bool:
        if not self.hpce_plus.admits(**hpce_args):        # 承 v23 四证
            return False
        if g is None or not gvc.admits():                  # 抓取可证
            return False
        if not pcdc.admits(**energy_args):                 # 载荷能量可行
            return False
        if not (icc.retreat_ok and icc.release_ok):        # 不可逆承诺
            return False
        return True


# ============================================================
# 端到端扩展流水线
# ============================================================
class GraspManipulationPipeline:
    def __init__(self, config):
        self.v23 = config["pipeline_v23"]                  # 复用 v23 全链
        self.hcma = HybridContactModeAutomaton(config.get("eps_min", 0.01))
        self.gmc = GMCGate(self.v23.hpc_e_plus)
        self.vil = VerificationInTheLoopGraspPlanner(
            config["grasp_generator"], config["sdc"], config["motion_planner"],
            eps_min=config.get("eps_min", 0.01))

    def step(self, sensor_data: dict) -> tuple[bool, dict]:
        mode = self.hcma.q
        certs = {"energy_args": sensor_data["energy_args"]}

        # 1) 规划阶段（仅 Free/Approach）：验证在环抓取
        grasp = None
        if mode in ("Free", "Approach") and sensor_data.get("target_obj") is not None:
            grasp = self.vil.plan(sensor_data["target_obj"], sensor_data["energy_args"])
            if grasp is not None:
                _, gvc, pcdc, icc = grasp
                certs.update(gvc=gvc, pcdc=pcdc, icc=icc)

        # 2) 释放阶段：ReleaseOK
        if mode == "Transport" and sensor_data.get("at_release_pose"):
            certs["icc_release"] = IrreversibleCommitmentCertificate.check_release(
                sensor_data["release_req"], sensor_data.get("support_surface"),
                sensor_data.get("gic"), sensor_data.get("cac"), sensor_data["E_impact_max"])

        # 3) 模式推进（低门槛中止优先）
        new_mode = self.hcma.step(sensor_data, certs)

        # 4) 统一准入（抓取/搬运模式下才强制 GMC 全证）
        admitted = True
        if new_mode in ("Contact", "Grasp", "Transport", "Release") and grasp is not None:
            _, gvc, pcdc, icc = grasp
            admitted = self.gmc.admits(
                plan=sensor_data["plan"], g=grasp[0], gvc=gvc, pcdc=pcdc, icc=icc,
                hpce_args=sensor_data["hpce_args"], energy_args=sensor_data["energy_args"])
        elif new_mode == "SafeHold":
            admitted = False

        return admitted, {"mode": new_mode, "grasp": grasp, "admitted": admitted}
```

## 3. 正确性论证

### 引理 5（鲁棒力闭合的单边可靠性）
**陈述**：若对每个接触 `P(μ_i ≥ μ_i⁻) ≥ 1-α_i`，且 `0 ∈ int(conv W(g; μ⁻))`，则真实摩擦锥下的抓取力闭合以概率 `≥ 1 - Σ_i α_i` 成立。

**证明**：
1. `W(g; μ)` 随每个 `μ_i` 单调递增（摩擦锥随摩擦系数单调扩张）。
2. 事件 `E = {∀i: μ_i ≥ μ_i⁻}` 蕴含 `W(g; μ⁻) ⊆ W(g; μ)`，故 `0 ∈ int(conv W(g; μ⁻))` ⇒ `0 ∈ int(conv W(g; μ))`。
3. 由 union bound，`P(E) ≥ 1 - Σ_i α_i`。故真实力闭合成立的概率下界为 `1 - Σ_i α_i`。
4. 取 `α_i = α/|C|` 得总体 `≥ 1-α`。∎

### 引理 6（不可逆承诺的无自由落体）
**陈述**：若抓取前 `RetreatOK(g)` 成立或任务接受"不退出"且释放安全已证，且每次释放前 `ReleaseOK(r)` 成立，则任何可达终态都是"已证支撑 / 已证交接 / 已证安全落点"，不存在无指令的自由落体。

**证明**：
1. 由 P45，释放只允许在 `ReleaseOK` 的三种模式之一成立时发生；三者分别是静平衡、接收方就绪、落点无人且冲击能有界。
2. 抓取只在 `RetreatOK` 或"不退出但释放安全已证"时发生，故不存在"抓后既退不出又放不下"的锁存态。
3. HCMA 的低门槛中止保证力越锥/打滑/失证时退回 SafeHold，不产生新的释放路径。∎

### 引理 7（载荷耦合单调退化链）
**陈述**：`Proj_motion(Exec_v24) ⊆ Exec_v23(Obs ∪ Payload) ⊆ Exec_v23(Obs) ⊆ ... ⊆ Exec_v18`。

**证明**：
1. 抓取后障碍集 `Obs ∪ CertBox_payload ⊇ Obs`，能量预算减去 `E_payload ≥ 0`，有效惯量增大——三者均使可行动作集收缩（P46）。
2. 接触模式 `Exec_q = Exec_v23|_q ∩ Inv_q ⊆ Exec_v23|_q`（P43），接触只加约束。
3. 因此 v24 任一搬运轨迹在放大障碍集下是 v23 可行的；而 `Exec_v23(Obs ∪ Payload) ⊆ Exec_v23(Obs)` 因障碍单调。
4. 逐级向下取交，传递到 v18。∎

### 定理（GMC 准入门的安全-可操作性完备性）
**陈述**：`GMCGate.admits(π,g) = True` ⟺ π 同时满足：(1) v23 四证（几何∧规范∧负信息∧能量∧云边∧少样本∧IP）；(2) 抓取力闭合且质量达标；(3) 载荷能量可行；(4) 抓前可退、放后可安。

**证明**：由 `GMCGate.admits` 的四个连言条件与引理 5–7 直接可得；必要性对应四类未缓解风险，充分性给出单调执行链与统计覆盖的闭环。∎

## 6. 本轮最大风险（最终确认）

**一句话**：整套力闭合与释放安全都押在摩擦/接触模型上，而 conformal 的 μ⁻ 仅在标定分布内有效——一旦遇到湿滑、油污、可变形或强逆光的分布外接触，证书会**形式成立、物理打滑**，机器人便"合规地、可审计地"把物体摔落或撞向本应被它护住的区域——即**被认证的滑落 (certified slip)**。
