# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；灵感循环第 7 轮；本轮灵感：「多机协同」×「桌面操作」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×SIC×CESC×PCE++++ 把「场景→意图→约束→阻抗→执行→证据→场景更新」的单机认知-执行闭环做严了。但**桌面操作场景**恰好把这套闭环的四个「单数假设」同时击穿：
> 1. **单场景信念**：SERC 只有一个场景后验。多机围桌时，N 台机器人各有一份桌面信念，直接相乘会把「同一张桌子的 N 个视角」当作 N 份独立证据——**相关证据被重复计数**，后验方差虚假收缩，团队过度自信。桌面恰恰是共模失效高发区（同一块反光、同一片阴影同时骗过所有俯视相机）。
> 2. **单空间所有权**：桌面是一个**有界、共享、不可并行的物理资源**。第 60 轮只有碰撞几何，没有「谁此刻可以动这张桌上的这个物体」的概念；两台机器人可能同时伸手抓同一物体、或接近走廊在时空上交叠却各自认为安全。碰撞避免 ≠ 操作互斥。
> 3. **单阻抗权威**：CESC 的 K_safe 是单机阻抗。桌面上的双臂刚性共持会耦合成**闭链阻抗**，产生不驱动运动的**内部力**；而且桌面对物体还有**第三个接触（支撑力+摩擦）**，在「提起」瞬间支撑力会**相变式消失**，单机 K_safe 的并集既不能约束内部力，也无法处理这个突变。
> 4. **单证据日志**：EPIR 只保证单机 EV-exec 的因果顺序。桌面上最关键的事件是**物体保管权交接**，它天然是分布式的、可能被故障或撒谎节点污染的；把「转发来的交接证据」当「亲历证据」，会让共识放大单点错误。
> 本轮核心论点：**多机桌面协同不是把单机 SGEC 复制 N 份，而是在「桌面这块公共资源」上引入四个桌面专属的联合算子——信念要相关感知、空间要时空互斥、阻抗要含支撑相变、证据要可溯源自证，并且每次交接必须是物理与证据同时原子的。**

## 0. 直觉与动机

**灵感 1（多机协同 → 桌面相关感知场景融合 CSBF-T）**
直觉：三台相机围着同一张桌子，看到的不是三张桌子，而是「同一张桌子的三个视角」。直接相乘等于假装做了三次独立实验，一旦三视角同时被同一块反光欺骗，**过度自信的错误信念会被整队共享**，形成共模失效。正确姿势是用**协方差交集（Covariance Intersection, CI）**做一致性融合——无论证据如何相关，融合结果都不会比真实更自信；再叠加**冲突门控**：用 Bhattacharyya 系数度量两机信念分歧，超阈值就拒绝融合、退回一次安全接触探测，而不是强行折中。桌面专属的一点是：桌平面给了所有机器人一个共享几何先验，**视角相关度 ρ_ij（由视角夹角估计）可以直接量化「共模风险」**，并据此下调权重、收紧冲突阈值。

**灵感 2（桌面操作 → 共享桌面时空占用与保管权 STOM）**
直觉：桌面不是「空旷的自由空间」，而是**有界、共享、需要分时复用**的资源。两个末端执行器即使不碰撞，也可能同时想抓同一个物体、或把同一片区域当抓取位；更隐蔽的是，A 的接近走廊可能与 B 的放置走廊在**时空上**交叠。因此要像操作系统分配临界区那样，把桌面切成**时空占用管（4D tube）**，机器人必须先申请「操作令牌」；同时引入**物体保管权（custody）**：任一物体在任一时刻至多被一个机器人「持有」，交接必须显式进行。关键洞见：**桌面互斥是资源分配问题，不是几何避障问题**；并且必须用全局对象序做**有序申请**来杜绝死锁（餐桌哲学家问题）。

**灵感 3（多机协同 → 支撑感知协作阻抗契约 CIC-T）**
直觉：两台机械臂刚性夹住桌面上一个箱子，每台各执行自己的 K_safe。物体位移只由**合力矩**决定，而两臂力中很大一部分落在抓取矩阵的**零空间（内部力）**里，只把箱子往中间挤、不产生运动。更关键的是桌面对物体有**支撑法向力和摩擦**：静止时支撑力抵消重力，**提起瞬间支撑力相变式归零**，外部扳手会阶跃变化，若内部力控制器还按「静止相」整定，就会在离桌瞬间产生力矩尖峰，轻则打滑、重则夹坏。因此多机桌面安全必须在**物体扳手空间 + 支撑接触**上联合编译：物体级阻抗 K_o、内部阻抗 K_int、桌面支撑相（rest/lift/slide）三者同时可行才算安全；可行集为空就降级抓取，绝不退回单机 K_safe 并集。

**灵感 4（多机协同 → 可溯源自证的共享证据账本 SEB）**
直觉：桌面上最重要的事件是「物体从 A 手里交到 B 手里」。这类证据是分布的，且可能有掉队、故障甚至撒谎的节点。若把转发来的证据当亲历证据，一次错误就能被共识放大成整队记忆。所以要建**共享证据账本**：每条 EV-exec 带签名、哈希链和**溯源权重**（亲历=1，转发按跳数 λ^h 衰减），关键事件（交接、物体状态）必须达到拜占庭容错法定人数（N≥3f+1，容 f 个故障），且**「保管权」的唯一性由账本共识来担保**，而不是由某台机器人的本地日志担保。

**灵感 5（三灵感合流 → 共享桌面协作闭环 STCC + 团队预算 PCE+++++）**
直觉：CSBF-T 给出「大家信的是不是同一张桌子」；STOM 给出「谁此刻有权动哪里/哪个物体」；CIC-T 给出「怎么一起动才不会夹坏/顶牛/离桌失控」；SEB 给出「这一切是否被可追溯地证明」。四者串成闭环：**共享桌面信念 → 时空令牌+保管权 → 支撑感知协作阻抗 → 分布式执行 → 原子交接+证据共识 → 信念/占用/预算更新**。并用 PCE+++++ 把第 60 轮四维认知预算扩成**团队预算** B_team=(B_comm, B_consensus, B_custody, B_sync)：通信、共识、交接、同步任一耗尽，就回退到「各自本地、保守单机」而不是带病协同。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（桌面相关感知场景融合 CSBF-T）** 设 N 台机器人围桌，各自维护阻抗/场景信念 `b_i = N(μ_i, Σ_i)`（或类别后验 `p_i(z)`）。
- **CI 融合（连续）**：`Σ_f^{-1} = Σ_i ω_i Σ_i^{-1}`，`μ_f = Σ_f Σ_i ω_i Σ_i^{-1} μ_i`，`Σ_i ω_i = 1, ω_i ≥ 0`，`ω* = argmin_ω det(Σ_f(ω))`（凸优化，单纯形上求解）。CI 在**未知相关结构**下仍保证一致性 `Σ_f ⪰ E[(x−μ_f)(x−μ_f)^T]`。
- **类别融合（log-linear pooling）**：`p_f(z) ∝ ∏_i p_i(z)^{w_i}`，硬约束 `Σ_i w_i ≤ 1`；`Σ w_i > 1` 视为重复计数并禁止。
- **视角相关度**：`ρ_ij = exp(−Δθ_ij² / 2σ_θ²)`，`Δθ_ij` 为两机对视桌面的视角夹角；**共模风险** `R_cm = max_{i≠j} ρ_ij · 1[Δ_belief_ij > δ]`。
- **冲突门控**：`K_conf = 1 − min_{i≠j} BC(p_i, p_j)`，`BC = Σ_z sqrt(p_i(z) p_j(z))`；若 `K_conf > τ_conf` 或 `R_cm > τ_cm`，令 `b_f = ⊥`（拒绝融合），回退第 60 轮单机 SSM 接触探测。
- **有效独立证据数**：`n_eff = 1 / Σ_i w_i²`（Kish 有效样本量）；`n_eff < N` 时，下游 CCT 只按 `n_eff` 计信。

**定义 162（共享桌面时空占用与保管权 STOM）** 桌面工作区 `W = [0,Lx]×[0,Ly]×[0,h]`，物体集 `O = {o_1,…,o_M}`。
- **操作令牌**：`τ = (i, o, R, C, [t_s,t_e], π)`，`i` 机器人、`o` 目标物体、`R ⊂ W` 抓取/放置区、`C ⊂ W` 接近/撤离走廊、`π` 优先级。
- **时空互斥**：`τ_a ⊥ τ_b ⇔ ((R_a∪C_a)×[t_sa,t_ea]) ∩ ((R_b∪C_b)×[t_sb,t_eb]) ≠ ∅` 且 `o_a = o_b` 或体积交叠。冲突在**4D（空间×时间）**上判定，而非仅几何相交。
- **保管权**：`cust: Robot × O × T → {0,1}`，恒有 `Σ_i cust(i,o,t) ≤ 1`；物体被操作期间 `Σ_i cust(i,o,t) = 1`。
- **有序申请（死锁避免）**：全局对象序 `o_1 < o_2 < … < o_M`；机器人只能按序申请令牌，且不可抢占已授予令牌（可等待但按序），从而排除循环等待，**保证无死锁**。
- **仲裁**：冲突时按 `π = (deadline 紧迫度, 已持令牌数, 任务关键度)` 字典序裁决；落败方进入等待或改期，不忙等占用走廊。

**定义 163（支撑感知协作阻抗契约 CIC-T）** n 台机器人刚性共持物体，抓取矩阵 `G_i`（`ẋ_i = G_i V_o`），堆叠 `G=[G_1;…;G_n]`，末端力 `f=[f_1;…;f_n]`，物体扳手 `w_o = G^T f`。
- **物体准静态平衡**：`G f + w_table + w_g = m a_o`，其中 `w_g` 为重力扳手，`w_table` 为桌面支撑接触扳手（法向 `f_n ≥ 0`、切向满足摩擦锥 `‖f_t‖ ≤ μ_t f_n`）。
- **内部力子空间**：`F_int = null(G^T)`；`f = f_motion + f_int`，`f_motion = G^{T†} w_o`。
- **物体级/内部级阻抗**：`K_o = Σ_i G_i^T K_i G_i`，`f_int = −K_int(x_int − x_int^ref) − D_int ẋ_int`，要求 `‖f_int‖_∞ ≤ F_int^max`。
- **支撑相**：`s_sup ∈ {rest, lift, slide}`。`rest` 时 `w_table` 抵消重力；`lift` 时 `f_n → 0` 且 `w_table → 0`（**支撑相变**）；`slide` 时 `f_t = −μ_t f_n · sign(v_o)`。契约要求每个相内与**相切换的邻域**都可行。
- **联合可行集**：`K_team = {(K_o,K_int,s_sup) : ∃f s.t. G f = w_o(K_o), ‖f_int‖≤F_int^max, τ_i = J_i^T f_i ∈ [τ_i^min,τ_i^max], 摩擦锥成立, 支撑相约束成立}`。`K_team = ∅ ⇒ DEGRADE_GRASP`（松手/改抓/单臂/求助），**绝不退回单机 K_safe 并集**。
- **证书**：`Cert_cict = (K_o, K_int, s_sup, F_int^max, cond(G), 相变裕度)`。

**定义 164（可溯源自证共享证据账本 SEB）** 账本 `L` 为签名事件 DAG。
- **事件**：`e = (id, robot_id, ts, seq, hash, prev_hashes, content, signature, hops)`。
- **溯源权重**：`w_prov(e) = λ^{hops(e)}`，`0<λ<1`；亲历 `hops=0 ⇒ w=1`，转发按跳数指数衰减。
- **拜占庭容错法定人数**：`N ≥ 3f+1`，`|Q| ≥ ⌈(2N+1)/3⌉` 且 `Σ_{i∈Q} w_prov(e_i) ≥ W_quorum`；仅当所有诚实节点对 `e` 达成一致才提交。
- **一致性冲突**：若两事件 `e_a,e_b` 对同一 `(o,t)` 给出矛盾保管权，二者不能同时提交；标记 `provenance_conflict` 并触发 HAP 回滚。
- **保管权担保**：`cust(i,o,t)=1` 仅当存在一条**已被法定人数确认**的交接链；本地日志不足以单独改变保管权。

**定义 165（保管权原子交接协议 HAP）** 交接双方 `A→B`，状态机 `IDLE → PREPARE → DUAL_HOLD → COMMIT → RELEASE`（可 `ABORT`）。
- **PREPARE**：B 向 STOM 申请 `o` 的令牌与区域 `R_B`，CIC-T 编译**双持**契约 `K_team^{AB}`（`A`、`B` 同时抓取，内部力仍受界）。
- **DUAL_HOLD**：两机同时接触物体，验证 `‖f_int‖≤F_int^max`、物体位姿漂移 `‖Δx_o‖≤ε_x`、无滑移（切向力在摩擦锥内）。
- **COMMIT**：两机签名交接事件 `e_hand`，经 SEB 法定人数确认；**原子地**更新 `cust(A,o):1→0`、`cust(B,o):0→1`（同一账本事务）。
- **RELEASE**：A 按力斜坡卸载并撤离，B 接管阻抗；若 `DUAL_HOLD` 期间检测滑移/力尖峰/证据冲突，则 `ABORT` 并恢复 A 的保管权（同样经账本事务）。
- **原子性**：`cust` 的变更与 `e_hand` 的提交绑定为「要么都成功、要么都不发生」，杜绝瞬时双持。

**定义 166（共享桌面协作闭环 STCC）** 算子 `STCC(A, O, task, intent, Δf_req)`：
```
① CSBF-T: 逐机 SSM.update → {b_i}; b_scene ← ⊕_CI{b_i}
           if b_scene=⊥ 或 n_eff<θ_eff → 单机保守先验 + 接触探测
② STOM:   按全局对象序申请令牌; 冲突按 π 仲裁; 获得 custody 候选
③ CIC-T:  s_sup ← 支撑相估计; K_team ← compile(K_o,K_int|b_scene,s_sup,Δf_req)
           if K_team=∅ → DEGRADE_GRASP
④ CIEC+:  C_intent ← ϕ(intent); 以团队安全包络封顶（人类意图不越 K_team）
⑤ Exec:   分布式阻抗控制 {K_i}; 逐机跟踪 f_i
⑥ HAP:    需要移交 → 原子交接（PREPARE→DUAL_HOLD→COMMIT→RELEASE）
⑦ SEB:    逐机签名 append(EV-exec); 关键事件法定人数确认
⑧ Update: 按 EV-exec 更新 b_i / 占用 / custody / 团队预算
⑨ Return: (b_scene, K_team, custody, EV_team, Cert_cict, ledger.status)
```

**定义 167（协作一致性三元组 CCT）** 团队动作 `a` 有效当且仅当：
- **信念一致**：`belief_ok = (b_scene ≠ ⊥) ∧ (K_conf ≤ τ_conf) ∧ (n_eff ≥ θ_eff)`；
- **扳手可行**：`wrench_ok = (K_team ≠ ∅) ∧ (s_sup 相变裕度 ≥ 0)`；
- **保管唯一**：`custody_ok = (∀o: Σ_i cust(i,o,t) = 1[o 被操作]) ∧ (无 provenance_conflict)`。
`CCT_valid(a) = belief_ok ∧ wrench_ok ∧ custody_ok`；任一为假即降级（保守单机 / 停手 / 回滚交接）。

**定义 168（团队预算 PCE+++++）** `B_team = (B_comm, B_consensus, B_custody, B_sync)`：
- `B_comm`：CI 融合与令牌交换的通信配额；`B_consensus`：关键事件共识轮次配额；`B_custody`：单位时间允许的交接次数；`B_sync`：允许的团队时钟/状态同步滞后上界。
- `cost_team = λ_comm·Comm + λ_cons·Consensus_rounds + λ_cust·Handovers + λ_sync·max(0, Sync_lag − B_sync)`。
- **降级链**：`B_comm` 耗尽 ⇒ 只用本地信念、团队阻抗取保守交集；`B_consensus` 耗尽 ⇒ 冻结交接（只保持当前 custody）；`B_custody` 耗尽 ⇒ 不再获取新物体；`B_sync` 超界 ⇒ 退化为各自独立的单机闭环。任一耗尽都**先收缩团队耦合，再收缩执行能力**。

## 2. 本轮最大风险

**一句话**：CI 只保证「不因相关证据而过度自信」，却无法纠正「整队在同一块反光桌面上一致地看错」的共模误判；一旦这种错误信念又叠加了交接时通信时延造成的瞬时双持，内部力会从零空间溢出，团队就会「一致地犯错、再一起把物体夹坏」——因此必须用「视角相关度触发共模门控」「HAP 原子 custody」「支撑相变裕度」「CCT 三元校验」四重护栏，让团队一致性永远不能超过物理可行性。

### IP-161 CSBF-T（桌面相关感知场景融合）

```python
class TabletopSceneFusion:
    def __init__(self, tau_conf=0.35, tau_cm=0.6, theta_eff=1.5):
        self.tau_conf, self.tau_cm, self.theta_eff = tau_conf, tau_cm, theta_eff

    def fuse(self, beliefs, view_angles):
        # beliefs: [(mu_i, Sigma_i, p_i)]; view_angles: 各机视角
        N = len(beliefs)
        rho = self._view_correlation(view_angles)          # ρ_ij
        # log-linear 权重：Σ w_i ≤ 1，视角越相关权重越低
        w = np.array([1.0 / (1.0 + rho[i].sum() - rho[i, i]) for i in range(N)])
        w = w / max(w.sum(), 1.0)                          # 关键：不放大到 >1
        n_eff = 1.0 / np.sum(w ** 2)
        # 冲突门控：Bhattacharyya
        K_conf = 1.0 - self._min_bhattacharyya([b[2] for b in beliefs])
        R_cm = max((rho[i, j] for i in range(N) for j in range(N) if i != j),
                   default=0.0) * float(K_conf > self.tau_conf)
        if K_conf > self.tau_conf or R_cm > self.tau_cm:
            return None, n_eff                          # b_f = ⊥，回退接触探测
        # CI 融合（连续）：凸优化 ω
        omega = self._solve_ci_weights([b[1] for b in beliefs])
        Sigma_f = np.linalg.inv(sum(o * np.linalg.inv(b[1])
                                    for o, b in zip(omega, beliefs)))
        mu_f = Sigma_f @ sum(o * np.linalg.inv(b[1]) @ b[0]
                             for o, b in zip(omega, beliefs))
        if n_eff < self.theta_eff:
            return (mu_f, Sigma_f, n_eff), n_eff         # 下游只按 n_eff 计信
        return (mu_f, Sigma_f, n_eff), n_eff

    def _solve_ci_weights(self, Sigmas):
        # min det(Σ_f(ω)) s.t. Σω=1, ω≥0（对数域凸，坐标下降/投影梯度）
        omega = np.ones(len(Sigmas)) / len(Sigmas)
        for _ in range(20):
            omega = self._project_simplex(
                omega - 0.1 * self._grad_logdet(Sigmas, omega))
        return omega
```

### IP-162 STOM（共享桌面时空占用与保管权）

```python
class SharedTabletopOccupancy:
    def __init__(self, object_order):
        self.order = {o: i for i, o in enumerate(object_order)}
        self.tokens = []                                  # 已授予令牌
        self.custody = {}                                 # (o) -> robot_id

    def request(self, req):
        # req = (robot, obj, region, corridor, t_window, priority)
        if self._conflicts(req):
            winner = self._arbitrate(req)
            if winner is not req:
                return None, 'wait_or_reschedule'
        # 死锁避免：按全局对象序申请，禁止逆序持有
        held = [t.obj for t in self.tokens if t.robot == req.robot]
        if held and self.order[req.obj] <= max(self.order[o] for o in held):
            return None, 'order_violation'               # 排除循环等待
        self.tokens.append(req)
        return req, 'granted'

    def _conflicts(self, req):
        tube = (req.region | req.corridor) * req.t_window
        for t in self.tokens:
            if t.obj == req.obj or self._vol_overlap(t, req):
                if self._tube_overlap(t, req):
                    return True
        return False

    def transfer_custody(self, frm, to, obj, ledger_txn):
        # 仅由 HAP 在证据提交时原子调用
        assert self.custody.get(obj) == frm
        self.custody[obj] = to                           # 与 ledger_txn 同事务
```

### IP-163 CIC-T（支撑感知协作阻抗契约）

```python
class TabletopCooperativeImpedance:
    def compile(self, grasps, b_scene, s_sup, delta_f_req):
        G = np.vstack(grasps.G)                           # 堆叠抓取矩阵
        G_pinv = np.linalg.pinv(G.T)
        w_g = self._gravity_wrench()
        w_table = self._support_wrench(s_sup)             # rest/lift/slide
        # 期望物体扳手（物体级阻抗）
        w_des = self._object_impedance(b_scene, delta_f_req)
        f_motion = G_pinv @ w_des
        # 内部力：零空间上由 K_int 生成，受界约束
        N_null = self._null_basis(G.T)
        alpha = self._solve_internal(N_null, w_des, w_g, w_table, s_sup)
        f = f_motion + N_null @ alpha
        if not self._feasible(grasps, f, w_table, s_sup):
            return None                                   # K_team=∅ → DEGRADE_GRASP
        return {
            'K_o': self._object_stiffness(grasps),
            'K_int': self._internal_gain(alpha),
            's_sup': s_sup,
            'F_int_max': self._f_int_max,
            'cert': self._build_cert(grasps, G, f, s_sup),
        }

    def _feasible(self, grasps, f, w_table, s_sup):
        # 内部力界
        f_int = self._project_null(f, grasps.G)
        if np.linalg.norm(f_int, np.inf) > self._f_int_max:
            return False
        # 各机力矩饱和
        for g, fi in zip(grasps, self._split(f)):
            tau = g.J.T @ fi
            if np.any(tau < g.tau_min) or np.any(tau > g.tau_max):
                return False
        # 摩擦锥 + 支撑相约束
        return self._friction_ok(f, grasps) and self._support_ok(w_table, s_sup)

    def support_phase_guard(self, s_sup, s_sup_next):
        # 相变邻域必须同时可行，否则在离桌前降速/加内部力裕度
        return self.compile(..., s_sup) and self.compile(..., s_sup_next)
```

### IP-164 SEB（可溯源自证共享证据账本）

```python
class SharedEvidenceBook:
    def __init__(self, n_robots, lam=0.6, W_quorum=None):
        self.N = n_robots
        self.f = (n_robots - 1) // 3                      # N ≥ 3f+1
        self.lam = lam
        self.W_quorum = W_quorum or (2 * n_robots + 1) / 3.0
        self.dag = {}

    def append(self, event, signer, hops=0):
        event['w_prov'] = self.lam ** hops
        event['hash'] = sha256(canonical(event))
        event['signature'] = signer.sign(event['hash'])
        self.dag[event['id']] = event
        return event

    def consensus_commit(self, eid, votes):
        # votes: [(robot_id, signed_event, hops)]
        weight = sum(self.lam ** h for _, _, h in votes)
        quorum = len(votes) >= (2 * self.N + 1) // 3
        agree = all(self._same_content(e, self.dag[eid]) for _, e, _ in votes)
        if not (quorum and agree and weight >= self.W_quorum):
            return False
        self.dag[eid]['committed'] = True
        return True

    def custody_txn(self, frm, to, obj, e_hand, votes):
        # 原子性：custody 变更与交接事件提交同生共死
        if not self.consensus_commit(e_hand['id'], votes):
            return False
        if self._has_conflict(obj, e_hand['ts']):
            return False                                  # provenance_conflict
        self.custody[(obj)] = to                          # 与提交绑定
        return True
```

### IP-165 HAP（保管权原子交接）

```python
class HandoverAtomicProtocol:
    def __init__(self, stom, cict, seb):
        self.stom, self.cict, self.seb = stom, cict, seb

    def handover(self, A, B, obj, t_window):
        # 1) PREPARE：B 申请令牌 + 双持契约
        tok, st = self.stom.request(self._req(B, obj, t_window))
        if st != 'granted':
            return 'ABORT'
        K_dual = self.cict.compile([A.grasp, B.grasp], ..., s_sup='rest')
        if K_dual is None:
            return 'ABORT'                                # 双持不可行，不硬来
        # 2) DUAL_HOLD：物理验证
        if not self._dual_hold_ok(A, B, obj):
            return self._abort_restore(A, obj)
        # 3) COMMIT：签名 + 法定人数 + 原子 custody 事务
        e_hand = self.seb.append(self._event(A, B, obj), signer=A)
        votes = self._collect_votes(A, B, obj)
        if not self.seb.custody_txn(A.id, B.id, obj, e_hand, votes):
            return self._abort_restore(A, obj)
        # 4) RELEASE：A 力斜坡卸载撤离，B 接管
        self._ramp_release(A)
        return 'COMMITTED'

    def _dual_hold_ok(self, A, B, obj):
        return (norm(self.cict.f_int, np.inf) <= self.cict.F_int_max
                and norm(obj.pose - obj.pose_ref) <= self.eps_x
                and self.cict.friction_ok(A.f, B.f))
```

### IP-166 STCC（共享桌面协作闭环）

```python
def shared_tabletop_cooperative_loop(team, objects, task, intent, delta_f_req):
    # ① 相关感知场景融合
    beliefs = [r.scene_model.belief() for r in team.robots]
    b_scene, n_eff = team.fusion.fuse(beliefs, [r.view_angle for r in team.robots])
    if b_scene is None or n_eff < team.fusion.theta_eff:
        b_scene = team.fusion.general_prior()             # 保守先验
    # ② 时空占用 + 保管权
    tokens = []
    for r, obj in team.plan(task):
        tok, st = team.stom.request(team.req(r, obj))
        if st == 'granted':
            tokens.append(tok)
    # ③ 支撑感知协作阻抗
    s_sup = team.estimate_support_phase(objects)
    K_team = team.cict.compile(team.grasps, b_scene, s_sup, delta_f_req)
    if K_team is None:
        return team.degrade_grasp(objects)
    # ④ 意图约束封顶（人类意图不得越过团队安全包络）
    C_intent = team.ciec.map(intent)
    K_team = team.ciec.cap_by_envelope(K_team, C_intent)
    # ⑤ 分布式执行
    team.distributed_impedance_control(K_team)
    # ⑥ 交接（如需）
    if team.needs_handover():
        status = team.hap.handover(team.current, team.next, team.obj, team.t_window)
    # ⑦ 证据共识
    ev = [r.sign(r.build_exec_evidence()) for r in team.robots]
    team.seb.append_batch(ev)
    # ⑧ 更新信念 / 占用 / custody / 团队预算
    team.fusion.update(ev)
    team.budget.charge_team(comm=len(ev), consensus=team.seb.rounds,
                            handovers=team.hap.count, sync_lag=team.sync_lag)
    return b_scene, K_team, team.stom.custody, ev, K_team['cert'], team.seb.status()
```

### IP-168 PCE+++++（团队预算）

```python
class TeamBudget:
    def __init__(self, comm=200, consensus=30, custody=10, sync=0.1):
        self.B_comm, self.B_consensus = comm, consensus
        self.B_custody, self.B_sync = custody, sync
        self.used = {'comm': 0, 'consensus': 0, 'custody': 0}

    def mode(self):
        if self.used['consensus'] >= self.B_consensus:
            return 'freeze_handover'                      # 冻结交接，保持现状
        if self.used['comm'] >= self.B_comm:
            return 'local_belief_conservative'            # 本地信念 + 保守交集
        if self.used['custody'] >= self.B_custody:
            return 'no_new_object'
        if self.sync_lag > self.B_sync:
            return 'independent_single_arm'               # 退化为单机闭环
        return 'normal'

    def charge_team(self, comm, consensus, handovers, sync_lag):
        self.used['comm'] += comm
        self.used['consensus'] += consensus
        self.used['custody'] += handovers
        self.sync_lag = sync_lag
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSBF-T | O(N²·m³)（CI 权重凸优化） | O(N·m²) | 一致性 `Σ_f ⪰ Σ_true`；共模门控拒绝冲突融合 |
| STOM | O(|tokens|²) 冲突检查 + O(|O|) 有序申请 | O(|tokens|) | 无死锁（有序申请）；custody 唯一 |
| CIC-T | O(n³) 伪逆 + O(n·m²) 内部力 QP / 控制周期 | O(n·m) | 内部力 `‖f_int‖≤F_int^max`；支撑相变邻域可行 |
| SEB | O(N) 追加 / O(N²) 共识消息 | O(|events|) | BFT：f < N/3 故障下 custody 安全 |
| HAP | O(1) 状态转移 + 一次共识 | O(1) | 交接原子性：custody 与证据同事务 |
| STCC | 上述组合 | 复用 | CCT 三元校验通过才执行 |

**正确性定理（STCC）**：假设 A66–A70 成立。
- **(A66) CSBF-T**：CI 在任意未知相关下保持一致，故 `b_scene ≠ ⊥` 时不会比真实更自信；`n_eff` 正确折减重复计数。
- **(A67) STOM**：全局对象序的有序申请排除循环等待 ⇒ 无死锁；令牌互斥 + `cust` 约束 ⇒ 任一 `(o,t)` 至多一个持有者。
- **(A68) CIC-T**：`K_team ≠ ∅` 当且仅当存在满足内部力界、力矩饱和、摩擦锥、支撑相约束的 `f`；相变裕度 ≥0 保证 rest↔lift↔slide 切换无失稳。
- **(A69) SEB/HAP**：`N ≥ 3f+1` 且加权法定人数达成时，诚实节点对 custody 事件一致；custody 变更与事件提交绑定 ⇒ 无瞬时双持。
- **(A70) PCE+++++**：`B_team` 单调消耗，任一耗尽触发对应降级且**先收缩团队耦合、再收缩执行**。

则：
1. **信念一致性**：融合信念不因相关证据过度自信；共模风险高时拒绝融合并回退接触探测。
2. **空间安全性**：无死锁，操作互斥，custody 唯一。
3. **物理安全性**：内部力有界，支撑相变不失稳，物体不被夹坏/顶牛/离桌失控。
4. **证据可靠性**：BFT 下 custody 共识安全，交接原子可追溯。
5. **团队可降级**：任一团队预算耗尽均退到安全模式而非带病协同。

## 5. 本轮最大风险

**一句话**：CI 只保证「不因相关证据而过度自信」，却无法纠正「整队在同一块反光桌面上一致地看错」的共模误判；一旦这种错误信念又叠加了交接时通信时延造成的瞬时双持，内部力会从零空间溢出，团队就会「一致地犯错、再一起把物体夹坏」——因此必须用「视角相关度触发共模门控」「HAP 原子 custody」「支撑相变裕度」「CCT 三元校验」四重护栏，让团队一致性永远不能超过物理可行性。
