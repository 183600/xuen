# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「LoRA」×「开源生态」）

> R69 把不确定性二分、让系统学会「问」，但它仍默认一个昂贵的前提：**闭环里每一块权重都是「我们自己的」**——同一个可信训练管线产出、同一份数据标定、同一个版本、同一个许可证。开源生态让这个前提直接失效：真实可部署的闭环，往往是「冻结基座 + 若干社区 LoRA + 第三方标定包 + 别人的流匹配头 + 外部 LLM 解码器」拼出来的。每一块都可能来自陌生人、会随上游静默更新、许可各异、且能低成本热插拔。R69 问「我该向谁求证」，R70 必须问：**这些别人的低秩增量，凭什么允许挂进安全关键路径？它们组合起来还是我们认证过的那套系统吗？上游悄悄换个版本，我的证书还算数吗？**
>
> 本轮两个灵感正好是一对：
> - **LoRA** 把「改模型」降成可加、可拆、可算的秩-r 增量；于是「信任」第一次能被写成**可计算的组合代数**（影响范数、干涉项、逐模块权限），而不是只能整体重训、整体信任、整体推翻。
> - **开源生态** 把攻击面从「单点模型」扩成「**供应链**」——适配器投毒、许可证洗白、依赖混淆、静默升级、共谋组合；也同时提供解药：模型卡、可复现工件、公开探针集、社区交叉审计、CVE 式的吊销公告。
>
> 核心命题：**把 R69 的「整体可信闭环」替换为「可认证的缝纫」：每个第三方工件携带签名清单与行为契约；准入只做「不信任的本地复核」（影响范数 + 干涉矩阵 + 标定漂移 + 行为锁文件 + 最小权限）；只有通过组合安全证书的子集才允许挂载；任一失败即退回基座——恰好是 R69。** 命名 **LOOM-RAS**（Low-rank Open-source Orchestration & Mounting for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这一针一线是谁的、缝在一起还安全吗、线断了能不能拆回去**」——信任从「证据」进一步下沉到「工件与组合」。

## 0. 直觉与动机

**灵感 1（LoRA → 信任第一次可以「按秩计费」）**
直觉：R68/R69 的证书是对「整个模型」的认证——只要任何一个权重变了，旧的标定、旧的似然、旧的安全包络都可能失效，只能整体重训、整体重证。LoRA 把一次改动压缩成一个低秩增量 ΔW = BA：它可加（多适配器叠加）、可拆（单独卸载）、可投影（只看它在某个方向上的作用）、可算（算子范数与逐模块影响都便宜）。于是「这块权重能不能进安全关键路径」不再是一个二元信任问题，而是一份**可以逐项记账的账单**：它在安全关键方向上改了多少（影响范数）、它和别的适配器是否在同一条子空间里打架（干涉）、它把标定推偏了多少（漂移）、它的来路是否可复现（溯源）。

**灵感 2（开源生态 → 攻击面从模型变成供应链）**
直觉：开放模型的危险不在于「基座本身是坏的」——坏基座一眼就能测出来；危险在于**供应链的静默与组合**。一个 Hugging Face 式适配器仓库里，同名不同源、浮动 tag、许可证洗白、上游偷偷 re-upload、以及「两个各自都通过公共评测、合起来却绕过安全包络」的共谋组合。xz 后门事件的教训是：攻击者不需要攻破你的代码，只需要成为你依赖链里那块「看起来很正常、复现性也还行」的工件。因此 R70 的安全单元不是「模型」，而是**工件 + 来路 + 组合**。

**灵感 3（低秩 ≠ 低影响 → 谱范数会骗人）**
直觉：一个自然的想法是「适配器 ΔW 的谱范数小就安全」。这是错的。安全关键方向可能只占参数空间极小的一角：一个秩-1、‖ΔW‖₂ 很小的适配器，只要它的输入/输出方向恰好对齐安全 Jacobian 的主奇异方向，就能造成很大的影响。**「低秩」描述的是参数空间的便宜，不是行为空间的无害**。所以 LOOM 的计费单位必须是**影响范数** ν = ‖J_safety · B A‖，而不是 ‖B A‖。这也是本轮最重要的技术纠偏：把「便宜的改动」误当成「安全的改动」，是开源适配器生态里最容易发生的事故。

**灵感 4（组合不是加法 → 干涉与共谋）**
直觉：多适配器叠加在参数上是加法，在行为上不是。两个适配器可能在同一低秩子空间里互相抵消/放大（干涉），也可能各自都安全、合起来却把系统推出认证包络（共谋）。R69 的证据纪律要求「k 个正交证据源一致」；R70 在参数侧有一个漂亮的镜像：**正交的适配器可安全叠加，同向的适配器必须做联合审计**。这把「正交性」从证据空间带回了权重空间，是本轮理论上的主线。

**灵感 5（可认证的缝纫 → 严格包含 R69）**
直觉：LOOM 不是推翻 R69，而是给 R69 的闭环外面套一层「工件准入 + 组合证书」。当适配器集合为空（S=∅）时，LOOM 逐指令等于 R69；当任何证书失败时，LOOM 单调地缩小 S，最终回到 ∅。安全侧永不弱于 R69，效率侧靠「可认证的社区增量」获得增益——这与 R68→R69「新层是旧层的边界退化」的理论姿态完全一致。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LOOM-RAS 总览）** LOOM-RAS = (ARM, PTL, ACA, INC, BLL, MAC, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）：挂载/卸载只是指针切换，发生在安全前缀点，绝不在实时环内做梯度更新；
(ii) **最小权限 + 组合预算**：任一时刻活动集 S 满足 CSC(S) ≤ B_comp，且每个适配器只被授权改写其声明的目标模块；安全临界模块（标定器、风险缩放、监视器）默认不可被第三方适配器触碰；
(iii) **不信任本地复核**：信任不来自贡献者声誉或下载量，而来自本地可复现的复核结果；任一复核失败 ⇒ S 单调收缩，最终 S=∅ 退化为 R69。

**定义 311（适配器工件与 MBOM）** 工件 a = (h_base, {(m, B_m, A_m, α_m)}_{m∈T_a}, manifest_a)，其中 m 为目标模块、B_m ∈ ℝ^{d×r}、A_m ∈ ℝ^{r×k}、r 为秩、α_m 为缩放。manifest_a = (license_a, data_provenance_a, objective_a, claimed_metrics_a, h_β(a), signature_a, dep_pins_a)。MBOM（Model Bill of Materials）= 工件依赖的完整清单。关键约定：**manifest 是「声明」，不是「保证」**；LOOM 只采信本地复核（定义 314–315、320）。

**定义 312（溯源信任格 PTL）** 信任等级 𝒯 = {T0 未知, T1 签名 + 可复现构建, T2 公开探针集审计通过, T3 在本闭环上本地重认证}，偏序 T0 ⊏ T1 ⊏ T2 ⊏ T3。组合的信任取 meet（短板）：trust(S) = ∧_{a∈S} trust(a)；多源证据的合并取 join（∨）。注意：meet 只给「信任下限」，**不能替代组合干涉审计**（定义 321）——这正是开放生态里「每个都 T2、合起来出事」的漏洞。

**定义 313（低秩组合代数与干涉矩阵）** 挂载 S（缩放 α_i）后 W_S = W0 + Σ_{i∈S} α_i ΔW_i，ΔW_i = B_i A_i（逐目标模块）。非交换交叉项 I_ij = ΔW_i ΔW_j + ΔW_j ΔW_i；归一化干涉 ρ_ij = ‖I_ij‖_F / (‖ΔW_i‖_F ‖ΔW_j‖_F) ∈ [0,2]。ρ_ij ≪ 1 表示两适配器近似正交、可加性成立；ρ_ij 接近上限表示 capability collision（能力碰撞），必须联合审计。

**定义 314（影响范数）** 设 z = f_base(x) 为安全相关隐表示，y_s = g_s(z) 为安全输出，J_s(z) = ∂y_s/∂z。适配器 i 的影响范数 ν_i(z) = ‖J_s(z) B_i A_i‖₂（可用 JVP/Hutchinson 廉价估计）。与参数谱范数 ‖ΔW_i‖₂ 不同：ν 只在**安全关键方向**上计费。组合影响一阶界 ν(S) = Σ_i α_i ν_i；二阶余项由干涉项给出（引理 19）。

**定义 315（组合安全证书 CSC）** CSC(S) = (risk_bound(S), cal_drift(S), beh_hash(S), license_ok(S), prov_level(S), privilege_ok(S))，其中 risk_bound(S) = Σ_i α_i ν_i + Σ_{i<j} ρ_ij √(ν_i ν_j) + O(ε²)，cal_drift(S) 为挂载后标定门 ECE 的预期漂移，beh_hash(S) 为组合行为哈希。Valid(CSC) ⇔ risk_bound ≤ B_comp ∧ cal_drift ≤ τ_cal ∧ beh_hash 与锁文件一致 ∧ license 兼容 ∧ prov_level ≥ T2（安全模块需 T3）∧ privilege_ok。

**定义 316（行为锁文件 BLL）** 对每个工件在固定探针集 P_β 上记录行为哈希 h_β，锁文件同时钉住权重哈希、行为哈希与依赖哈希。**语义版本钉的是「契约」，不是「权重」**：上游任何改动只要改变 h_β 即视为新工件（降级为 T0），必须重认证；只改权重不改行为则视为良性重打包。这把 R68 的「缓变故障」搬到供应链层：**静默上游漂移 = 供应链级缓变故障**。

**定义 317（挂载准入控制器 MAC）** 给定上下文 c，选择 S* = argmax_S U_LOOM(S | c) s.t. Valid(CSC(S))、权限最小、无冲突边（定义 321）。无可行非空 S ⇒ S=∅，走基座，即 R69。挂载在安全前缀点做指针切换（沿用 R68 定理 15 的换装不变式）。

**定义 318（供应链干扰集 ℰ_chain）** 适配器投毒（触发器后门）、许可证洗白（GPL→Apache 谎报）、依赖混淆 / 名称抢注、上游静默更新、共谋适配器（单独安全、联合越界）、可复现性失效 / bit-rot、恶意 tokenizer 或解码器。并入 AIC：ℰ_LOOM = ℰ_FLUID × ℰ_chain。

**定义 319（证书 J_LOOM）** J_LOOM = (J_FLUID, S_mounted, CSC, prov_level(S), lockfile_hash, impact_vectors, interference_matrix, adapter_hashes, recert_time, loom_ver)。Valid ⇔ Valid(J_FLUID) ∧ Valid(CSC) ∧ 锁文件一致 ∧ 无未决吊销（定义 324）。

**定义 320（双通道复核 DRV）** 密码学通道（哈希/签名/可复现构建）与行为通道（探针行为 h_β）必须同时通过。单通道都不够：哈希对但行为变 ⇒ 静默更新或后门；行为对但哈希变 ⇒ 良性重打包或篡改（需进一步判定）。只有双通道一致才升 T2/T3。

**定义 321（共谋干涉审计 CIA-2）** 对任意满足 ρ_ij > τ_ρ 的适配器对，强制联合探针测试；若联合风险 > B_comp 或联合行为越出认证包络，则在冲突图中加边 (i,j)，禁止共挂载。这把 R69 引理 18 的「k 个正交证据源」镜像到参数空间：**正交才可叠加，同向必须联合审计**。

**定义 322（严格包含与退化边界）** S=∅ ⇒ LOOM 与 R69 逐指令相同；任何证书/漂移/吊销失败 ⇒ S 单调收缩至可行，最终 ∅。故 R69 是 LOOM 的「零适配器」边界，安全侧不做让步。

**定义 323（供应链审计 VQAuditor-S）** 审计对象新增：manifest 声明与本地实测的一致性、许可证兼容性、可复现性、重认证时效、冲突边决策、吊销响应。结论回灌 AuditBuf，作为下一轮 PTL 与准入的先验。

**定义 324（退役与回收 REVOKE）** 若某工件事后被判定恶意/故障（社区公告、漂移检测、红队），按哈希吊销；所有挂载该哈希的闭环必须在下一个安全前缀点重新认证或回滚，吊销日志只追加（append-only）。这是开放生态的「CVE 机制」在权重层的对应物。

**定义 325（信任预算与最小权限）** 适配器只被授权改写其声明的目标模块；安全临界模块集 M_prot（标定器、λ 缩放、FMA/MCG 监视器）默认禁止第三方适配器改写，除非 T3 + 本地重认证 + 双人复核。权限面 = 参数量 × 模块数；权限越大，要求的证据等级越高。

**定义 326（跨版本不变式）** 基座升级 W0 → W0′ 会使所有依赖 h_base 的适配器失效，除非在 W0′ 上重新认证；适配器与基座哈希强绑定。这正面回应「上游悄悄更新基座」：**没有免费的向后兼容，只有重新缝纫**。

# IP-264 ARM：工件清单校验（离线/安装期；不信任贡献者）
def verify_artifact(a, registry):
    if sha256(a.delta) != a.manifest.weight_hash: return None      # 内容寻址
    if not verify_signature(a.manifest, registry.keys): return None
    if a.manifest.base_hash != registry.base_hash: return None     # 跨版本失效
    if not deps_pinned(a.manifest.dep_pins): return None           # 依赖混淆
    if not license_compatible(a.manifest.license, registry.policy): return None
    return a

# IP-265 INC：影响范数（只对安全关键方向计费，O(rank) 的 JVP）
def impact_norm(a, z, J_s, eps=1e-3):
    nu = {}
    for m, (B, A, alpha) in a.modules.items():
        v = lambda dz: J_s(z) @ (B @ (A @ dz))                     # 低秩前向
        nu[m] = alpha * operator_norm_estimate(v, z, eps)          # JVP/Hutchinson
    return nu

# IP-266 ACA/CSC：组合证书（一阶影响 + 干涉余项 + 标定漂移）
def composition_certificate(S, artifacts, z, J_s, cal_probe):
    nu   = {i: impact_norm(artifacts[i], z, J_s) for i in S}
    risk = sum(nu[i] for i in S)
    inter = {}
    for i, j in pairs(S):
        rho = interference(artifacts[i], artifacts[j])             # 定义 313
        inter[(i, j)] = rho
        risk += rho * sqrt(nu[i] * nu[j])                          # 二阶余项界
    cal_drift = expected_ece_drift(S, artifacts, cal_probe)
    beh_hash  = behavioral_hash(S, artifacts, PROBE_SET)
    return CSC(risk, cal_drift, beh_hash, license_ok(S),
               min_prov(S), privilege_ok(S), inter)

# IP-267 BLL：行为锁文件复核（供应链级漂移检测）
def lockfile_check(S, artifacts, lockfile):
    for i in S:
        if behavioral_hash_one(artifacts[i], PROBE_SET) != lockfile[i].h_beta:
            return DRIFT                                       # 降级 T0，须重认证
        if artifacts[i].base_hash != lockfile[i].base_hash:
            return BASE_DRIFT                                  # 跨版本失效
    return OK

# IP-268 CIA-2：共谋干涉审计（正交可叠加，同向须联合测）
def collusion_audit(S, artifacts, conflict_graph, risk_budget):
    for i, j in pairs(S):
        if interference(artifacts[i], artifacts[j]) > TAU_RHO:
            if joint_risk(i, j) > risk_budget:
                conflict_graph.add_edge(i, j)                  # 禁止共挂载
    return conflict_graph

# IP-269 MAC + 主闭环（继承 R69，仅在挂载处插入 LOOM 层）
def LOOM_RAS_round(M, obs, ctx):
    # 0) 准入（离线算好，实时只读指针；任一失败 ⇒ S 收缩至 ∅）
    S = M.mac.select(ctx, M.registry, M.budget)
    if M.mac.last_check_failed:
        S = M.mac.shrink_until_valid(S)                        # 单调回退
    M.hot_swap(S)                                              # 安全前缀点指针切换
    # 1) 以下完全继承 R69 的 FLUID 闭环
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    g = M.mint.choose_interaction(modes, o, M.budget) if (U_epi > TAU_EPI and not slow) else None
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(...)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, U_epi, lam)
    M.vqa_s.submit_async(S, g, a_hat, M.csc, M.lockfile_hash)  # 供应链 + 交互审计
    return k, lam, mode, (U_ale, U_epi)

## 3. 推导

**引理 19（组合影响的一阶界与干涉余项）** 设 g_s 局部 C²、J_s 在认证域内 Lipschitz 常数 L_J。对适配器集 S，安全输出的改变满足 ‖Δy_s‖ ≤ Σ_i α_i ν_i + Σ_{i<j} ρ_ij√(ν_i ν_j) + O(ε²)，其中 ε = max_i α_i‖ΔW_i‖₂。系：**正交适配器（ρ≈0）的风险近似可加，可按单项记账；同向适配器（ρ→2）必须联合评估。**

**引理 20（谱范数不足 / 低秩高影响）** 对任意 δ>0，存在秩-1 适配器 ΔW = u vᵀ 使 ‖ΔW‖₂ ≤ δ（参数侧任意小），但 ν = ‖J_s u vᵀ‖₂ = ‖J_s u‖₂‖v‖₂ 达到 O(‖J_s‖)（行为侧不可忽略），只需把 u 对齐 J_s 的主左奇异方向。故**谱范数不是安全代理**；准入必须以影响范数 ν 与探针行为为准。此引理是 R70 反对「小范数即安全」的核心论证。

**引理 21（共谋下界 / 为何 meet 不够）** 存在两个适配器 a,b，各自满足 CSC({a})、CSC({b}) 有效，但 CSC({a,b}) 的联合风险 > B_comp：取 ρ_ab 足够大，使交叉项 Σρ√(νν) 单独即超预算。故信任格的 meet 只给许可下限，**联合可达性必须显式审计**（定义 321）；这也是 R69 引理 18 的「单源采纳」风险在参数空间的镜像。

**定理 18（LOOM 严格包含 R69）** 当 S=∅ 时，LOOM 的实时环与 R69 逐指令相同；当 S≠∅ 时，LOOM 的期望风险 ≤ R69 + B_comp（组合预算），且任何证书/漂移/吊销失败都使 S 单调收缩至 ∅。因此 R69 是 LOOM 的「零社区增量」边界；安全侧不降，效率侧以可认证增量换取收益。

**定理 19（证书可靠性与 fail-safe）** 若 CSC 在条件下式成立（risk_bound 为引理 19 的严格上界、cal_drift 由 R68 标定界覆盖、beh_hash 由密码学绑定），则挂载后闭环风险改变 ≤ B_comp，且标定门 ECE 不越 τ_cal；若任一项无法复核，则 MAC 返回 ∅ ⇒ 逐指令回退 R69。故 LOOM 的失效模式只有「更保守」，没有「更激进」。

**定理 20（行为锁文件对静默漂移的检测）** 若上游改动使某工件在 P_β 上的行为发生变化，则 h_β 以高概率改变（P_β 对行为差异的判别力 ρ_β > 0 时，单探针检测概率 ≥ ρ_β，|P_β| 个独立探针下漏检 ≤ (1−ρ_β)^{|P_β|}）；锁文件不匹配即降级 T0 并要求重认证。系：**供应链级缓变故障与 R68 传感器级缓变故障走同一条纪律——不匹配就收紧/回退。**

## 6. 本轮最大风险

**一句话**：LOOM 的全部安全性都押在「**证书能代表真实行为**」这一前提上——但影响范数 ν 与探针集 P_β 都只是**认证域内的局部样本**；一个低秩、对齐安全 Jacobian 主方向、且在 P_β 上表现正常的适配器，完全可以在分布外带上触发器后门或共谋载荷，**通过全部本地复核**——于是「认证」非但没有排除攻击，反而把攻击**洗白成 T3 可信工件**，比未认证更危险（certification laundering）。

**次级风险与缓解**：
1. **影响范数的局部性**（认证域外失效）→ 认证域显式声明 + 域外保守回退 + 分布外探针；
2. **探针集覆盖不足/被投毒** → 多源公开探针 + 社区交叉审计 + 私有不公开探针 + 红队；
3. **共谋组合的组合爆炸** → 仅对 ρ>τ_ρ 的对做联合审计 + 冲突图，避免全子集枚举；
4. **锁文件语义哈希碰撞/漂移误报** → 双通道复核（密码学 + 行为）+ 人工复核通道；
5. **受保护模块被绕过**（经上游表示间接影响监视器）→ 权限最小化 + 影响范数含监视器输入通道 + 运行时 FMA 第二意见。

**本轮结论一句话**：LOOM 让开放生态的适配器第一次可以「不信任地组合」，但它能认证的只是**认证域内的行为**；最大的风险是证书把局部安全洗白成全局可信——**低秩很便宜，认证很昂贵，而便宜的认证最容易骗过自己。**

## 4. 推导

**引理 19（组合影响一阶界 + 干涉余项）** g_s 局部 C²、J_s 在域内 L_J-Lipschitz，则 `‖Δy_s‖ ≤ Σα_iν_i + Σ_{i<j}ρ_ij√(ν_iν_j) + O(ε²)`。系：**正交（ρ≈0）可单项记账，同向（ρ→2）须联合评估**。

**引理 20（谱范数不足 / 低秩高影响）** 对任意 δ>0 存在秩-1 `ΔW=uvᵀ` 使 `‖ΔW‖₂≤δ` 但 `ν=‖J_su‖₂‖v‖₂=O(‖J_s‖)`，只需 u 对齐 J_s 主左奇异方向。故**谱范数不是安全代理**，准入须以 ν 与探针行为为准。

**引理 21（共谋下界 / meet 不够）** 存在 a,b 各自 CSC 有效、但联合风险超预算（取 ρ_ab 使交叉项 Σρ√(νν) 单独超限）。故信任格 meet 只给许可下限，**联合可达性必须显式审计**；这是 R69 引理 18「单源采纳」在参数空间的镜像。

**定理 18（LOOM 严格包含 R69）** S=∅ 时实时环与 R69 逐指令相同；S≠∅ 时期望风险 ≤ R69 + B_comp；任一证书/漂移/吊销失败使 S 单调收缩至 ∅。R69 = 「零社区增量」边界。

**定理 19（证书可靠性与 fail-safe）** 在引理 19 严格界 + R68 标定界 + 密码学行为绑定下，挂载后风险改变 ≤ B_comp 且 ECE 不越 τ_cal；任一项不可复核则 MAC 返回 ∅，逐指令回退 R69。失效模式只有「更保守」。

**定理 20（行为锁文件对静默漂移的检测）** 若上游改动使行为在 P_β 上变化（判别力 ρ_β>0），则 |P_β| 个独立探针下漏检 ≤ `(1−ρ_β)^{|P_β|}`；哈希不匹配即降级 T0 重认证。系：**供应链级缓变故障与 R68 传感器级缓变故障走同一条纪律——不匹配就收紧/回退。**

## 7. 本轮最大风险

**一句话**：LOOM 的全部安全性都押在「**证书能代表真实行为**」这一前提上——但影响范数 ν 与探针集 P_β 都只是**认证域内的局部样本**；一个低秩、对齐安全 Jacobian 主方向、且在 P_β 上表现正常的适配器，完全可以在分布外带触发器后门或共谋载荷而**通过全部本地复核**，于是「认证」反而把攻击**洗白成 T3 可信工件**，比未认证更危险（certification laundering）。

**次级风险与缓解**：影响范数的局部性（显式认证域 + 域外保守回退 + OOD 探针）；探针集覆盖不足/被投毒（多源公开 + 私有探针 + 红队）；共谋组合爆炸（仅对 ρ>τ_ρ 的对联合审计 + 冲突图）；行为哈希碰撞/误报（DRV 双通道 + 人工复核）；受保护模块被间接绕过（权限最小化 + 影响范数含监视器输入通道 + 运行时 FMA 第二意见）。

**结论**：LOOM 让开放生态的适配器第一次可以「不信任地组合」，但它能认证的只是**认证域内的行为**；最大的风险是证书把局部安全洗白成全局可信——**低秩很便宜，认证很昂贵，而便宜的认证最容易骗过自己。**
