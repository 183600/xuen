# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「创新点提炼」×「移动操作」）

> 第 57 轮用 MFSL/XMC/PTM 补上了少样本校准、跨模态对账与个性化信任三条腿，代价是机制继续膨胀：IP 已到 138，体系层从 L0 堆到 L0.5*⁺。于是关键问题第一次从"再加什么"翻转成"**到底哪些机制在承重、迁移到新任务时该带走什么**"——这正是「创新点提炼」的锋芒。与此同时，「移动操作」把这个问题变成硬约束：空载走坡与平地抓取的证据**不能**直接搬到"抱物下湿坡"，因为地形风险与操作风险在对象处**耦合**，两个各自安全的子系统可组合出事故。本轮因此不新增"抓取模块"，而是把证据体系升级为**可提炼、可耦合、可审计**的版本：**(1)** 安全内核蒸馏 DSK——用"消融—反例搜索—证明携带"把全栈压成最小充分安全内核 𝕂*，显式度量蒸馏间隙 Δ_dist，内核内冻结、内核外影子可删、反例命中即回滚；**(2)** 移动操作耦合证书 LMC——联合风险 R_joint=G_couple⊗max(R_loco,R_manip)，把"抱物后同一步态的额外放大"入账，只有 G_couple 证为 1 的子域才允许分离论证；**(3)** 证据转账税 ETT——跨域复用证据必须缴税（最坏值膨胀、覆盖与可靠性折减），未申报即按"证据洗钱"拒绝。核心命题由"少样本可校准/跨模态可对账/个性化有界"升级为 **"可提炼、可耦合、可审计的移动操作证据承诺"**。

核心矛盾：
- **H29（蒸馏 vs 健全）**：蒸馏压缩掉冗余，也压缩掉反例的藏身之处；一个被删掉的不变量不会在下游留下任何证据，因此蒸馏错误是"删了就查不出"的静默失败。
- **H30（移动 vs 操作耦合）**：地形安全与抓持安全经对象（载荷、质心、反力、滑移后果）耦合，分离论证会重复计数证据并把组合风险漏在缝里；但耦合建模过强又会退化成一事一探，经济上不可行。
- **H31（创新通胀 vs 提炼）**：每轮加 IP 会让安全论证不可审计、让"新颖"退化为噪声；激进提炼又会误删涌现性安全——需要可度量、可回滚、可追责的提炼判据。

## 0. 直觉与动机

**灵感 1（创新点提炼 → ACP 三件套与最小充分安全内核）**
直觉：57 轮下来，真正扛住事故的可能只是少数不变量，其余是效率、解释与体验层。提炼不是"删代码"，而是一场**带反例的消融实验**：把机制从外到内逐层影子移除（**A**blation），同时主动搜索能击穿剩余内核的边界组合（**C**ounterexample），并要求保留的每条不变量携带可机检证明或可复现反例覆盖（**P**roof-carrying）。提炼产物是最小充分安全内核 𝕂*，并显式报告**蒸馏间隙** Δ_dist=|P_safe^全栈−P_safe^𝕂*|。判据是三问：改变哪个界？引入哪个失败模式？能否独立证伪？三问产出一张**创新点账本**，让"承重创新"与"装饰创新"第一次可区分。

**灵感 2（移动操作 → 耦合证书，拒绝伪分离）**
直觉：抱着物体，机器人不再是一个点——质心抬高、转动惯量变化、足端可用摩擦被抓持反力占用、制动距离变长、摔倒后果从"自损"变成"人/物俱损"。因此地形风险与操作风险不是两个独立标量相加，而是**经对象耦合**。引入耦合增益 G_couple(x,o,g)≥1 度量"同一地形/同一步态在负载下的风险放大"；联合风险取保守 max-plus 复合。只有 G_couple 被证据证明为 1 的受控子域（轻载/平地/慢速）才允许分离论证，其余一律走联合证书 J_c，并给出释放/放下这一**二次不可逆事件**的独立门槛。

**灵感 3（证据转账税 → 堵住跨域洗钱）**
直觉：移动操作最诱人的捷径是"这块地我空载走过十次，所以抱物也能走"。这是把 A 域证据非法转账到 B 域。转账不是禁止，而是**征税**：复用 e_A 得到 e_B′ 时，最坏值至少膨胀 τ_trans(A,B,o)，覆盖与可靠性折减 α_tax/ρ_tax，且某些证据类（EV-xmodal、人类标注）根本不得转往不可逆操作。未申报税=证据洗钱，一律拒绝。这让"省探针"与"安全"之间的兑换率第一次被显式标价。

**灵感 4（双用探针 → 一次接触两份证据，但禁止重复计数）**
直觉：预抓取的轻触既能测足下/接触面硬度，也能测抓持滞回——一次物理接触的信息被两个判定器使用。收益是时间；风险是把同一份相关观测当成两份独立证据，从而虚假满足佐证要求。于是双用探针 OGCP 必须带**相关折减** κ_corr∈(0,1)：共享同一物理接触的两份证据，其联合证据量按相关性打折，且探针本身须对地形与抓持都满足非破坏约束 R_joint(π)≤F_abs。

**灵感 5（合流 → 证据门第六类与 DMO 算子）**
直觉：证据门在 EV-probe*/visit/margin/xmodal/human 之上增加约束而非新维度：EV-probe* 必须"在内核内 ∧ 未跨耦合域"，并新增 EV-grasp（抓持实证）与 EV-couple（耦合证书覆盖本次 (x,o,g)）。不可逆操作必要证据集变成 (EV-probe*∨EV-margin) ∧ EV-grasp ∧ EV-couple，跨域证据先过 ETT，EV-xmodal 不得跨耦合域替代。算子 DMO 在探询前先做提炼核对与耦合规划，承诺失败时优先**任务分解**（先放稳再移动 / 先移动再抓取）而非硬降档，并在"释放/放下"处重新过门。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（安全内核蒸馏 DSK）** 全栈 S 的不变量集 Φ={φ_1,…,φ_n}，每条 φ 挂载证明/测试/历史证据。提炼算子 Distill(S,𝒜,𝒳,ε_dist)→𝕂*⊆Φ，其中 𝒜 为有序消融序列（由外向内），𝒳 为反例搜索集（历史事故、仿真对抗、边界地形×载荷×步态组合）。三规则：(D1) **内核冻结**——𝕂* 内不变量更新须过隔离区并做回归，不得被常规发布覆盖；(D2) **影子消融**——𝕂* 外机制先以影子模式移除，观测部署界与失败率变化；(D3) **回滚提升**——任一反例命中被删机制即自动提升回内核并登记。蒸馏间隙 Δ_dist=P_safe^S−P_safe^𝕂*，须 ≤ε_dist 且由消融-反例对给出置信上界。创新点账本 Ledger=(IP, Δ界, 新失败模式, 可证伪检验, 消融结论)。

**定义 140（移动操作耦合状态与耦合证书 LMC）** 耦合状态 ξ=(x,σ,g,o)（位姿/步态/抓持/对象）。本体风险 R_loco(σ|x)、操作风险 R_manip(g|x,o)、耦合增益 G_couple(x,o,g)≥1 度量负载下的额外风险放大（质心、惯量、摩擦占用、制动、后果）。联合风险 R_joint(ξ)=G_couple⊗(R_loco⊕R_manip)，其中 ⊕ 为保守 max-plus 复合、⊗ 为增益放大。联合可行集 𝒞_adm(g,o)={σ : R_joint(ξ)≤δ_f}。耦合证书 J_c=(G_couple 上界, 抓持裕度 K_g, 载荷-坡度交互表, 释放条件 R_release)。**命题**：R_loco 与 R_manip 可分仅当 G_couple 被证明为 1 的受控子域，否则分离论证不成立。

**定义 141（证据转账税 ETT）** 跨域复用 e_A→e_B（空载地形→负载地形、平地抓取→斜坡抓取）。转账算子 T_{A→B} 产出 e_B′ 并对最坏值保守膨胀：μ_B≥μ_A+τ_trans(A,B,o)，1−α_B≥1−α_A−α_tax，ρ_B≤ρ_A−ρ_tax；仅当 e_A 的证据类允许跨域时可用（EV-xmodal、EV-human 标注不得转往不可逆操作）。未声明税即判"证据洗钱"，直接拒绝。税负入账 J_d，供事后核对"省了多少探针、冒了多少额外风险"。

**定义 142（对象-地形双用探针 OGCP）** 探针 π 同时作用于地形与抓持，观测 o_π=(o_terrain,o_grasp)，似然允许相关。准入：R_joint(π)≤F_abs 且对地形与抓持均为非破坏。双账：e_terrain 与 e_grasp 各自入账，但若似然相关则联合证据量按 κ_corr∈(0,1) 折减，禁止同一物理接触被计为两次独立佐证。SPRT 早停同时检查两账，任一账未达阈即不产证据。

**定义 143（蒸馏-耦合证据门 DCE 与证书 J_d）** 证据类在 EV-probe*/visit/margin/xmodal/human 上增加：EV-probe* 须满足"命中 𝕂* 且未跨耦合域"；新增 **EV-grasp**（抓持实证：力-位移滞后、滑移检出、保持时长）与 **EV-couple**（J_c 覆盖本次 (x,o,g)）。不可逆操作必要证据集 = (EV-probe*∨EV-margin) ∧ EV-grasp ∧ EV-couple，跨域证据须先过 ETT；EV-xmodal 不得跨耦合域替代。证据门六类之外仍拒。J_d 继承 J_p 全部字段，另加 (𝕂* 版本与 Δ_dist, G_couple 上界, J_c, 转账税记录, κ_corr 折减记录, Ledger 指针)。

**定义 144（蒸馏-移动-操作算子 DMO / PCE++）** 每任务：①**提炼核对**（𝕂* 版本是否覆盖本任务域，否则内核扩容/降级）；②**耦合规划**（联合可行步态-抓持集 𝒞_adm）；③**探询**（优先级=VOI_元悲观 + 耦合增益潜在降低量，双用探针优先但受 κ_corr 折减）；④**承诺** ⇔ ∃(σ,g):R_joint≤δ_f ∧ DCE 通过；否则**任务分解**（先放稳再移动/先移动再抓取，深度≤d_split）→绕行→L2 协商→安全停；⑤**释放/放下**为二次不可逆事件，须重新过门（抓持成功 ≠ 放下安全）。终止：分解深度 ≤d_split，探针 ≤k_probes+k_cons。

## 2. 关键算法伪代码（完整版见产物区）

```python
def distill_kernel(S, ablations, search, eps):        # IP-139: ACP 三件套
    K = set(S.invariants)                             # 从全量开始
    for a in ablations:                               # 由外向内影子消融
        K_try = K - {a}
        gap = psafe(S) - psafe_with(K_try)
        if gap <= eps and not search.hits(K_try, a):  # 删除不放大风险
            K = K_try; S.shadow_remove(a)
        if search.hits(K_try, a):                     # 反例命中 → 回滚
            K.add(a); S.promote(a)
    return K, certify_gap(S, K, search)               # 携带蒸馏间隙证书

def coupled_risk(x, sigma, g, o, model):              # IP-140/141 合流
    Rl = model.loco(sigma, x)
    Rm = model.manip(g, x, o)
    G  = model.couple_upper(x, o, g)                  # 耦合增益上界
    R  = G * max_plus(Rl, Rm) if G > 1 else max(Rl, Rm)
    return R, J_c(G, model.K_g, model.load_slope_table, model.release_cond(x,o))

def transfer_tax(e, src, dst, o):                     # IP-141: 转账税
    tau = tax_table(src, dst, o); assert e.cls not in CROSS_FORBIDDEN
    return Evidence(mu=e.mu + tau.mu, alpha=e.alpha + tau.alpha,
                    rho=e.rho - tau.rho, taxed=True)

def dual_probe(pi, x, o, F_abs):                      # IP-142: 双用探针
    if coupled_risk(x, floor(pi), grasp_of(pi), o)[0] > F_abs:
        return None                                   # 非破坏准入
    o_t, o_g = execute(pi)
    e = [evidence(o_t, 'terrain'), evidence(o_g, 'grasp')]
    if corr(o_t, o_g) > rho_corr:                     # 相关折减，禁止重复计数
        e = [discount(e[0], kappa_corr), discount(e[1], kappa_corr)]
    return e
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DSK | 离线 O(\|𝒜\|·(\|Φ\|+cost(𝒳)))；在线 O(\|𝕂*\|) | O(\|𝕂*\|+Ledger) | Δ_dist≤ε_dist、回滚自动、内核冻结 |
| LMC | O(d_c)/步态-抓持对 | O(\|𝒞_adm\|) | G_couple 上界诚实、𝒞_adm 保守 |
| ETT | O(1)/转账 | O(\|tables\|) | 税如实申报、禁用类不转账 |
| OGCP | O(1)/探针 + O(H) 回放 | O(\|e\|) | 非破坏准入、κ_corr 折减诚实 |
| DCE | O(\|σ\|·\|g\|) | O(\|J_d\|) | 六类外拒、跨域先税、释放复检 |
| DMO | O(d_split·\|CP\|·(k_p+k_c)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|+\|𝒞_adm\|) | 悲观 VOI、d_split 有界、五态完备 |

**正确性定理（Distilled Coupled Commitment Soundness, DCCS 概要）**：在 A33–A40 成立之上加 (A41) 蒸馏健全——𝕂* 冻结、Δ_dist≤ε_dist、反例搜索在声明域内覆盖；(A42) 耦合证书诚实——G_couple 为上界、𝒞_adm 保守、释放条件声明；(A43) 转账税诚实——τ_trans/α_tax/ρ_tax 如实申报，无未税跨域复用；(A44) 双用探针相关折减诚实——κ_corr 与似然相关性一致、非破坏准入成立。则：

(i) **提炼健壮性**：P_safe^𝕂* ≥ P_safe^全栈 − ε_dist − P(反例逃逸搜索)；
(ii) **耦合承认健全性**：不可逆操作 P(fail) ≤ δ_f + ε_dist + ε_meta + δ_probe + δ_grasp + δ_couple；
(iii) **转账单调性**：跨域复用只能经"税后更宽的后验"或"更保守动作"影响系统，不存在省探针又升险的路径；
(iv) **终止性**：任务分解深度 ≤d_split、探针 ≤k_probes+k_cons，终止于 {承诺, 分解, 绕行, L2, 安全停}。

## 5. 风险与缓解

## 6. 本轮最大风险

**一句话**：本轮把"哪些安全机制该保留"的裁判权交给蒸馏器，而蒸馏是一个**未被验证的裁判**——若反例集不完备，𝕂* 会自信地删掉恰好护住"负物下坡+松软边+急停"这类罕见组合的不变量，且这种失败最阴险：被删掉的检查不会在下游留下任何证据，系统只会安静地错；必须以证明携带蒸馏、影子消融、反例自动回滚与盲区披露四重护栏，宁可保留冗余内核，也不让任何"删了就无法事后发现"的机制消失。

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）、第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）与更早层。本轮第一次不按"再加一层"推进，而是回答两个问题：**(Q1) 57 轮的机制里哪些真正承重？** 提出安全内核蒸馏 DSK，以"消融—反例搜索—证明携带"（ACP）压出最小充分安全内核 𝕂* 并度量蒸馏间隙 Δ_dist；**(Q2) 如何把证据体系搬到移动操作而不被伪分离与证据洗钱击穿？** 提出移动操作耦合证书 LMC（联合风险经耦合增益复合）、证据转账税 ETT（跨域复用须缴税）、双用探针 OGCP（一次接触两份证据但强制相关折减）。核心升级：**可提炼、可耦合、可审计的移动操作证据承诺**；安全论证从"堆叠纵深"变为"带证提炼的核心 + 可删除的外围"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-128/132/137 以纳入蒸馏、耦合与转账税维度。

### 0.5 创新点提炼账本（本轮方法论主张）

每条候选创新点必须过"三问"，否则不配进内核（承重创新），只可作为外围（可删）：

| 三问 | 含义 | 不通过的处理 |
|---|---|---|
| 改变哪个界？ | 是否改变 P_safe/P_fail 上界中的某项 | 归为效率/体验层，允许影子消融 |
| 引入哪个失败模式？ | 是否新增可被攻击面 | 必须配对缓解与反例 |
| 能独立证伪吗？ | 是否有可复现实验判据 | 不可证伪者不入内核 |

**本轮账本摘要**：DSK 改变 P_safe 中的 ε_dist 项（承重）；LMC 把耦合增益写入 P_fail（承重）；ETT 堵住"未税复用"这一新失败模式（承重）；OGCP 主要改变探针效率、次要改变相关折减下的证据量（半承重）；DCE/DMO 属编排层（外围，可降级到第 57 轮拆分路径）。

## 2. 关键算法伪代码

### IP-139 DSK（安全内核蒸馏，ACP 三件套）

```python
def distill_safety_kernel(S, ablations, search, eps_dist, domain):
    K = set(S.invariants)                              # 从全栈不变量开始
    ledger = Ledger()
    for a in ablations:                                # A: 由外向内有序消融
        K_try = K - {a}
        gap = psafe(S) - psafe_with(K_try, domain)     # 影子估计部署界损失
        hit = search.hits(K_try, a, domain)            # C: 反例搜索（边界×载荷×步态）
        if hit:
            K = K + {a}; S.promote(a)                 # 命中即回滚提升
            ledger.record(a, 'kept', hit.witness)
        elif gap <= eps_dist:
            K = K_try; S.shadow_remove(a)             # 未放大风险 → 允许删除
            ledger.record(a, 'removed', gap)
        else:
            ledger.record(a, 'kept', gap)
    cert = certify_gap(S, K, search, domain)           # 携带 Δ_dist 置信上界
    return K, cert, ledger

def kernel_member(inv, K, task_domain):               # 提炼核对
    return inv in K and task_domain <= K.declared_domain
```

### IP-140 LMC（移动操作耦合风险与证书）

```python
def coupled_risk(x, sigma, g, o, model):
    Rl = model.loco(sigma, x)                         # 空载/本体地形风险
    Rm = model.manip(g, x, o)                         # 抓持/操作风险
    G  = model.couple_upper(x, o, g)                  # 耦合增益上界 ≥ 1
    R  = G * max_plus(Rl, Rm)                         # 不可分离：保守复合
    Jc = J_c(G, model.K_g(g), model.load_slope_table(o),
             model.release_cond(x, o))
    return R, Jc

def admissible_set(x, o, model):
    return [ (sigma, g) for sigma in model.gaits(x)
             for g in model.grasps(o)
             if coupled_risk(x, sigma, g, o, model)[0] <= model.delta_f ]

def release_gate(x, o, g, Jc, model):                 # 放下是二次不可逆事件
    if not model.release_cond_holds(x, o, g): return ('reject', 'release_unsafe')
    if Jc.G > model.G_max_release:            return ('reject', 'coupling_too_high')
    return ('ok', Jc)
```

### IP-141 ETT（证据转账税）

```python
CROSS_FORBIDDEN = {'EV-xmodal', 'EV-human'}            # 不得转往不可逆操作

def transfer_tax(e, src, dst, obj, tables):
    assert e.cls not in CROSS_FORBIDDEN, 'forbidden_transfer'
    tau = tables.tax(src, dst, obj)                    # 查表：τ_mu/τ_alpha/τ_rho
    e2 = Evidence(mu=e.mu + tau.mu,
                  alpha=min(1.0, e.alpha + tau.alpha),
                  rho=max(0.0, e.rho - tau.rho),
                  cls=e.cls, taxed=True, src=src, dst=dst)
    if not e.taxed and (src != dst):                   # 未税跨域 = 证据洗钱
        return ('reject', 'evidence_laundering', e2)
    return ('ok', e2)
```

### IP-142 OGCP（对象-地形双用探针）

```python
def dual_purpose_probe(pi, x, o, F_abs, rho_corr):
    sigma_pi, g_pi = pi.footprint(), pi.grasp()
    R, _ = coupled_risk(x, sigma_pi, g_pi, o, model)
    if R > F_abs: return None                          # 非破坏准入
    o_t, o_g = pi.execute()
    e_t = evidence(o_t, cls='EV-probe*', domain='terrain')
    e_g = evidence(o_g, cls='EV-grasp',  domain='grasp')
    if estimate_corr(o_t, o_g) > rho_corr:             # 相关折减，禁止重复计数
        e_t, e_g = discount(e_t, kappa_corr), discount(e_g, kappa_corr)
    return e_t, e_g
```

### IP-143 DCE（蒸馏-耦合证据门 + 证书 J_d）

```python
def distilled_coupled_gate(c, K, model, tax_log):
    if c.ev == 'EV-probe*':
        ok = c.inf.ece_k <= eps_meta(c.k) and kernel_member(c.inv, K, c.domain)
    elif c.ev == 'EV-grasp':
        ok = c.hysteresis_ok and c.slip_detected is False and c.hold_time >= T_g
    elif c.ev == 'EV-couple':
        ok = c.Jc.covers(c.x, c.o, c.g) and c.Jc.G <= model.G_max
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.domain == 'terrain' and not c.cross_coupling
    elif c.ev == 'EV-human':
        ok = c.auth >= 'A1' and c.corrob >= corrob(c.auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, model.M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)
    if c.cross_domain and not tax_log.is_taxed(c):     # 跨域必须先缴税
        return ('reject', 'unpaid_transfer_tax', c)
    if c.irreversible and c.ev == 'EV-xmodal':
        return ('reject', 'xmodal_on_irreversible', c)
    return ('ok', c)

def map_evidence_certificate_d(sched, K, model, tax_log, ledger):
    for c in contacts(sched):
        st = distilled_coupled_gate(c, K, model, tax_log)
        if st[0] != 'ok': return st
    if not K.covers(sched.domain):        return ('reject', 'kernel_out_of_domain')
    if K.delta_dist > budgets.eps_dist:   return ('reject', 'distillation_gap')
    if max(x.G_couple for x in sched) > model.G_max: return ('reject', 'coupling')
    for c in releases(sched):             # 释放/放下二次不可逆，逐次复检
        if release_gate(c.x, c.o, c.g, c.Jc, model)[0] != 'ok':
            return ('reject', 'release_unsafe')
    return ('ok', J_d(K.version, K.delta_dist, model.G_bounds, tax_log,
                      ledger.hash, inherit=J_p_fields(sched)))
```

### IP-144 DMO（蒸馏-移动-操作算子，PCE++）

```python
def distill_move_operate(x0, task, K, model, budget, consent):
    if not K.covers(task.domain):                      # ① 提炼核对
        K = distill_safety_kernel(full_stack, ablations, search, eps_dist, task.domain)
    sched, log = [], []
    for cp in plan_on_map(task, model):
        adm = admissible_set(cp.x, task.object, model)  # ② 耦合规划
        while not any(coupled_risk(cp.x, s, g, task.object, model)[0]
                      <= model.delta_f for s, g in adm) and budget.left:
            p = argmax(probe_candidates(cp, adm, model),
                       key=lambda q: voi_meta(q) + coupling_gain_drop(q)
                                     - cost(q))
            evs = (dual_purpose_probe(p, cp.x, task.object, model.F_abs,
                                      model.rho_corr)
                   or [execute_probe(p)])
            for e in evs: log.append(e); update(M, e)
            adm = admissible_set(cp.x, task.object, model)
            budget.spend(p)
        pick = argmax(adm, key=lambda sg: -coupled_risk(cp.x, *sg,
                                                         task.object, model)[0])
        if distilled_coupled_gate(commit_evidence(cp, pick), K,
                                  model, tax_log)[0] == 'ok':
            sched.append(commit(pick)); continue
        if depth < d_split:                            # ③ 任务分解
            sub = decompose(cp, task)                  # 先放稳再移动 / 先移动再抓取
            return [distill_move_operate(x0, s, K, model, budget, consent)
                    for s in sub]
        alt = reroute(M, cp, model)
        if alt: sched = alt; continue
        return negotiate_or_stop(cp, M, consent, tau_int=tau_int(auth))
    return sched, log, K
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DSK | 离线 O(\|𝒜\|·(\|Φ\|+cost(𝒳)))；在线 O(\|𝕂*\|) | O(\|𝕂*\|+Ledger) | Δ_dist≤ε_dist、自动回滚、内核冻结（A41） |
| LMC | O(d_c) 每步态-抓持对 | O(\|𝒞_adm\|) | G_couple 上界、𝒞_adm 保守、释放门（A42） |
| ETT | O(1) 每转账 | O(\|tables\|) | 税额如实、禁用类不转（A43） |
| OGCP | O(1)+O(H) | O(\|e\|) | 非破坏准入、κ_corr 折减（A44） |
| DCE | O(\|σ\|·\|g\|) | O(\|J_d\|) | 六类外拒、跨域先税、释放复检 |
| DMO | O(d_split·\|CP\|·(k_p+k_c)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|+\|𝒞_adm\|) | 悲观 VOI、d_split 有界、五态完备 |

**正确性定理（Distilled Coupled Commitment Soundness, DCCS）**
假设 A22–A32、A33–A36、A37–A40 成立；并加入：**(A41)** 蒸馏健全——𝕂* 内核冻结、Δ_dist≤ε_dist、反例搜索在声明域内具备覆盖声明；**(A42)** 耦合证书诚实——G_couple 为可证上界、𝒞_adm 保守、R_release 声明；**(A43)** 转账税诚实——τ_trans/α_tax/ρ_tax 如实申报且无未税跨域复用；**(A44)** 双用探针相关折减诚实——κ_corr 与似然相关性一致、探针非破坏。则：

1. **提炼健壮性**：对声明域内任务，P_safe^𝕂* ≥ P_safe^全栈 − ε_dist − P(反例逃逸 𝒳)。
2. **耦合承诺健全性**：不可逆移动操作 P(fail) ≤ δ_f + ε_dist + ε_meta(k) + δ_probe + δ_grasp + δ_couple。
3. **转账单调性**：跨域复用只能经税后更宽的后验或更保守动作影响系统，不存在"省探针且升险"的路径；禁用类转账一律拒绝。
4. **分解与终止**：任务分解深度 ≤d_split，探针 ≤k_probes+k_cons，终止于 {承诺, 分解, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点与释放事件取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_dist + ε_meta(k) + δ_probe + δ_grasp + δ_couple)
             − Σ_release δ_release − P(𝕂* 盲区未被披露) − P(G_couple 上界失效)
             − P(未税复用绕过) − P(护盾/超时/安全停失效)
```

关键：**蒸馏把冗余变可删、把承重变可证**（效率与安全再次解耦，安全不再押在机制数量上）；**耦合证书把"搬东西"从两个独立安全域变成一个带增益的联合域**（拒绝伪分离）；**转账税给"省探针"标价**（堵住证据洗钱）；**双用探针用相关折减换取效率而不虚增证据量**。

## 6. 本轮最大风险

**一句话**：本轮把"哪些安全机制该保留"的裁判权交给蒸馏器，而蒸馏是**未被验证的裁判**——若反例集不完备，𝕂* 会自信地删掉恰好护住"负物下坡+松软边+急停"这类罕见组合的不变量，且这种失败最阴险：被删掉的检查不会在下游留下任何证据，系统只会安静地错；必须以证明携带蒸馏、影子消融、反例自动回滚与盲区披露四重护栏，宁可保留冗余内核，也不让任何"删了就无法事后发现"的机制消失。
