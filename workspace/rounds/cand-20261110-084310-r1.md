# 第 43 轮（新循环第 3 轮） · 竞争策略 × 碰撞检测：从「安全证书飞轮」到「博弈化风险预算 + 几何证书内核」（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。第 42 轮的最大风险是「仿真偏差累积 + 检索幻觉导致证书静默失效」。本轮灵感词「碰撞检测」「比赛策略」恰好提供两条互补补强线：**碰撞检测**把 v19 里靠经验/解析 Lipschitz 常数估计的边际，替换成**几何真值距离**——点到障碍的欧氏距离天然是 1-Lipschitz，连续碰撞检测 (CCD) 的 time-of-impact 天然对应保持时间 T_hold，证书的「紧」与「快」可同时改善；**比赛策略**回答 v19 没回答的问题：证书只保证「不出事」，比赛却要「赢」——在有限时间与有限风险预算下，把安全裕度当作可分配资源，在「落后敢冒险、领先守边界」之间做最优取舍。二者合成 **风险地图（碰撞检测）× 风险预算（比赛策略）**：碰撞检测说明风险在哪、多远、多久到；比赛策略决定愿意离风险多近、在多长时间内承担多大风险。证书从「安全过滤器」升级为「竞争策略的可行域」。

## 0. 直觉与动机

**灵感 1（碰撞检测 → 证书的几何真值内核）**：v19 的边际下界 m_lo 来自「离线标定 + 经验分位 + Lipschitz 放大」，L_m 是拟合量，偏保守且不可证。碰撞检测给出一个关键事实：机器人到障碍的最短距离 d(x) 是**几何真值**，且对状态 1-Lipschitz：|d(x)−d(y)| ≤ ‖x−y‖。于是查表网格粒度 δ_grid 的插值误差上界**恰为 δ_grid**，无需经验 L_m；扣掉机器人半径、安全缓冲、状态估计误差 δ_est 后得到**可证**边际 m(x)=d(x)−r−b−δ_est。更进一步，CCD 的 time-of-impact (TOI) 正是 T_hold 想要的物理量，保守推进 (conservative advancement) 可给出 TOI 的**下界**，把「保持时间」也变成可证的。窄相 GJK/EPA + 宽相 BVH 使这些在边缘端 μs 级完成，部分替代 v19 的 INT8 蒸馏监控器。

**灵感 2（比赛策略 → 证书的风险预算与博弈化）**：v19 的证书是二元的：满足 θ 放行，否则降级。比赛不是二元——有得分、时限、对手；落后应敢冒险，领先应保守。直觉是引入**风险预算**：整场有总风险额度 B_risk，策略每时刻决定「愿意离碰撞边界多近」α(t)∈[0,1]，证书阈值 θ(t) 随 α(t) 连续调节，用风险约束 MPC/动态规划分配预算。更严谨地，对手是**对抗性动态障碍**，安全不能只对「预测轨迹」成立，必须对**最坏对手动作**成立——这就是博弈论碰撞检测（inevitable collision states, ICS）：证书保证机器人始终在非 ICS 区，策略在非 ICS 区内最大化得分。安全与竞争由此统一为**在可证非碰撞集内最大化比赛收益**。

**灵感 3（耦合 → 风险地图 × 风险预算 = 可解释攻守策略）**：碰撞检测输出多层时间尺度风险地图：瞬时距离 d(x)、TOI_lo、最坏对手下的鲁棒 TOI_robust、ICS 边界距离。比赛策略读图做三件事：(1) **选路**——在高分路线与低风险路线间做 Pareto 取舍；(2) **配速**——TOI 足够大就加速穿越狭窄通道，TOI 逼近 T_hold 就收；(3) **留后手**——把「最坏情况下仍能停在非 ICS 内」作为硬约束，即安全停止能力。人类选手看似「敢」，本质是把风险预算花在 TOI 长的窗口里。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（竞争安全博弈）**：G=(S, A_r, A_o, P, r, γ, Safe)。状态 s=(x_r, x_o, t, score)，机器人动作 a_r∈A_r，对手动作 a_o∈A_o，转移 P，回报 r（得分/进度/时间惩罚），安全集 Safe 由证书给出，策略 π:S→Δ(A_r)。**竞争证书问题**：max_π E[Σγ^t r_t] s.t. Pr(∃t: s_t∉Safe) ≤ δ 且 s_t∉ICS_t 几乎必然。定义**竞争比** ρ=J(π_cert)/J(π*_unconstrained) 与**安全代价** Δ_safe=J(π*)−J(π_cert)。

**定义 39（可证几何边际与 1-Lipschitz）**：机器人占据体 R(q)，障碍 O_j，真值距离 d(q)=min_j dist(R(q),O_j)。欧氏距离对 q 为 1-Lipschitz：|d(q)−d(q')|≤‖q−q'‖。可证边际 m(q)=d(q)−b_safe−δ_est，δ_est 为状态估计误差上界。**命题**：若证书表以粒度 δ_grid 采样并插值，则 m̂(q)≥m(q)−δ_grid−δ_est，插值误差严格由 δ_grid 界出，无需经验 L_m。**系**：v19 的 α_e·θ_sim 迁移修正可被 m(q) 的几何下界替代，消除「经验 L_m 低估」失效链。

**定义 40（连续碰撞检测与 TOI 下界）**：给定 x 与控制 v，TOI(x,v)=inf{t≥0: d(x+∫v)≤0}。保守推进输出 TOI_lo(x,v)≤TOI(x,v)：每步推进 Δt=d_lo/v_max，故 TOI_lo 可证。**保持时间** T_hold(x):=TOI_lo(x,v_brake)，v_brake 为最大制动策略，即「从 x 按最安全制动仍能避免碰撞的时间」。

**定义 41（风险预算与阈值调度）**：总预算 B_risk。分配器 α:(score_gap,t_remain,risk_map)→[0,1]，证书阈值 θ(t)=θ_min+α(t)(θ_max−θ_min)。**预算约束** ∫_0^T c(α(t))dt≤B_risk，c 为风险消耗率。**最优调度** max_α E[score] s.t. 预算约束 + 非 ICS 硬约束。落后/时间少→α↑；领先/近边界→α↓。

**定义 42（博弈论碰撞检测 / ICS）**：ICS={x: ∀a_r∈A_r, ∃a_o∈A_o, 碰撞不可避免}。**鲁棒 TOI** TOI_robust(x)=min_{a_o} max_{a_r} TOI(x,a_r,a_o)。证书硬约束：x_t∉ICS 且 TOI_robust(x_t)≥T_reaction。**命题**：若每个决策周期保证 x_{t+1}∉ICS 且 TOI_robust≥T_reaction，则对任意对手策略都不会碰撞（最坏情况安全），强于 v19 对预测轨迹的检查。

**定义 43（碰撞感知的证书组合）**：C1⊗C2 的碰撞证书=各自证书 ∧ 成对碰撞证书（同时激活的部件对及与外界距离）。守卫 g_12=min(g_1,g_2,d_pair−b_pair)，TOI 取 min。**定理**：若各子证书 sound 且成对证书覆盖所有同时激活部件对，则组合证书 sound。

## 2. 产出设计（增量 IP-57/58/59 + 升级）

### 2.1 IP-57 STRAT-CERT（竞争风险预算策略）
1. **风险预算分配器**：输入分数差、剩余时间、风险地图；输出 α(t) 与 θ(t)；落后/时间紧→提高 α，拥挤/TOI 短→降低 α。
2. **风险约束 MPC**：目标=进度/得分−λ·风险消耗；约束=非 ICS + TOI_robust≥T_reaction + m(q)≥θ(t)。
3. **攻守模式机**：落后（贴边界）、领先（守安全停止）、平局（Pareto 选路）三态，切换带迟滞。
4. **对手建模**：在线估计对手攻击性/可预测性，更新 A_o 支撑集；越难预测，ICS 越大，α 自动下调。
5. **CAR 对接**：转移边增加 strategy-priority，多可行转移按得分选，但都必须落在证书内。

### 2.2 IP-58 GEO-COLLISION-KERNEL（几何碰撞内核 GCK）
1. **宽相**：动态 BVH / spatial hash，支持动态障碍扫掠体。
2. **窄相**：GJK/EPA（凸体距离/穿透深度）、SAT（盒/多面体），返回距离**下界**与最近点。
3. **CCD**：保守推进 + 扫掠球/相对运动，输出 TOI_lo；非凸体用凸分解。
4. **可证化**：所有返回值均为下界，定点实现保留误差上界；1-Lipschitz 保证插值/近似误差可控。
5. **风险地图**：输出 d(x)、TOI_lo、TOI_robust、ICS 距离，供 IP-57。
6. **边缘化**：BVH+GJK 定点版，INT32 累加，与 v19 IP-56 ECR 的 L0/L1 融合。

### 2.3 IP-59 ADVERSARIAL-COLLISION-VALIDATOR（对抗碰撞验证 ACV）
1. 在 v19 IP-54 SCV 上增加对手策略库 + self-play（激进/保守/随机/最优反应）。
2. 统计鲁棒 TOI 覆盖率、ICS 误判率、落后/领先场景安全违例。
3. 对手策略指纹入 CKB，供 IP-57 在线匹配。

## 5. 本轮最大风险

**一句话**：把安全裕度当作可分配预算、并让竞争策略主动逼近碰撞边界，会把系统推到几何证书最脆弱的边界上——一旦状态估计误差 δ_est 被低估，或 GCK 的定点/凸分解近似在动态障碍处失效，1-Lipschitz 的「可证紧界」会退化为「看起来可证」，而比赛策略恰好会最大化这种边界暴露。

## 2. 关键算法（伪代码）

### IP-58 GCK：可证距离/TOI 查询
```
def gck_query(q, obstacles, v=None, T_horizon=1.0):
    # 宽相：动态 BVH 查询候选对（障碍按 δ_est 膨胀）
    pairs = bvh_query(dynamic_bvh, fatten(q, delta_est))
    best = DistResult(inf, None)
    for (a, b) in pairs:
        # 窄相：GJK 距离下界（含数值误差上界 eps_num）
        r = gjk_distance_lower(a, b)
        if r.dist < best.dist:
            best = r
    d_lo = max(0.0, best.dist - eps_num)          # 可证距离下界
    m = d_lo - r_robot - b_safe - delta_est        # 可证边际（1-Lipschitz）
    toi_lo = conservative_advance(q, v, obstacles, T_horizon) if v else None
    return RiskMap(d_lo=d_lo, margin=m, toi_lo=toi_lo, nearest=best.pair)

def conservative_advance(q0, v_max, obstacles, T_horizon, dt_eps=1e-4):
    t = 0.0
    while t < T_horizon:
        q = integrate(q0, t)
        d_lo = gck_query(q, obstacles).d_lo
        if d_lo <= 0.0:
            return t                       # 已进入碰撞，返回保守 TOI 下界
        dt = d_lo / max(v_max, 1e-6)       # 安全推进步长 = 距离下界/速度上界
        t += max(dt, dt_eps)
    return T_horizon                       # 已验证到 T_horizon 无碰撞

def gck_margin(q):
    return gck_query(q, world).margin      # 供 CBF / CAR 使用的几何下界
```

### IP-57 STRAT-CERT：风险预算分配与风险约束 MPC
```
def allocate_risk(score_gap, t_remain, risk_map, B_remaining):
    # 压力：落后越多、剩余时间越少 → 越想冒险
    pressure = sigmoid(k1 * max(0.0, -score_gap) + k2 / max(t_remain, 1e-3))
    # 拥挤：TOI 越短、边际越小 → 越该收缩
    congestion = (w1 * clip(1.0 - risk_map.toi_lo / T_ref, 0, 1)
                  + w2 * clip(1.0 - risk_map.margin / m_ref, 0, 1))
    alpha = clip(alpha0 + kp * pressure - kc * congestion, 0.0, 1.0)
    # 预算硬约束：剩余预算不足则强制收缩
    alpha = min(alpha, budget_feasible_alpha(B_remaining, t_remain))
    theta = theta_min + alpha * (theta_max - theta_min)
    return alpha, theta

def risk_mpc(x, goal, risk_map, alpha, horizon):
    # 目标：进度 - λ·风险消耗
    # 硬约束：非 ICS、TOI_robust ≥ T_reaction、margin ≥ θ(alpha)
    best = None
    for u in sample_controls(x, goal, horizon):
        traj = rollout(x, u, horizon)
        if any(is_ics(s) for s in traj):
            continue
        if min(robust_toi(s) for s in traj) < T_reaction:
            continue
        if min(gck_margin(s) for s in traj) < theta(alpha):
            continue
        score = progress(traj, goal) - lam * risk_cost(traj, alpha)
        if best is None or score > best.score:
            best = (u, score)
    return best.u if best else brake_safe(x)

def mode_machine(score_gap, t_remain, risk_map):
    # 三态攻守，切换带迟滞，避免抖动
    if score_gap < -eps and t_remain < T_late:
        return 'ATTACK'      # 落后且时间少：提高 alpha
    if score_gap > +eps:
        return 'DEFEND'      # 领先：守安全停止能力
    return 'BALANCE'         # 平局：Pareto 选路
```

### IP-59 ACV：博弈论碰撞检测与对抗验证
```
def is_ics(x, A_o, A_r, brake_policy):
    # 对每个最坏对手动作，机器人用最安全动作仍碰撞 → ICS
    for a_o in A_o.worst_case_set(x):
        if all(simulate(x, a_r, a_o).collides for a_r in A_r):
            return True
    return False

def robust_toi(x, A_o, A_r):
    # min over opponent actions of max over robot actions
    return min(max(toi(x, a_r, a_o) for a_r in A_r) for a_o in A_o)

def adversarial_validate(policy, opponent_library, n_episodes):
    stats = {'collisions': 0, 'ics_miss': 0, 'toi_viol': 0}
    for opp in opponent_library:
        for _ in range(n_episodes):
            traj = run_match(policy, opp)
            if traj.collided:
                stats['collisions'] += 1
            for s in traj.states:
                if is_ics(s) and policy.allowed(s):
                    stats['ics_miss'] += 1
                if robust_toi(s) < T_reaction and policy.allowed(s):
                    stats['toi_viol'] += 1
    return stats
```

### IP-49/51/52/39 升级：几何证书、CAR、LCS、CBF
```
# IP-49：1-Lipschitz 可证边际，替代经验 L_m
def geometric_certificate(q):
    d_lo = gck_query(q, world).d_lo
    return d_lo - r_robot - b_safe - delta_est   # 保 sound 的边际下界

# IP-51 CAR：strategy-priority 转移 + ICS 硬守卫
def car_transition_guard_v2(e, x, cert, alpha):
    m = gck_margin(x)
    theta = theta_min + alpha * (theta_max - theta_min)
    return (m >= theta) and (not is_ics(x)) and (robust_toi(x) >= T_reaction)

def select_transition(candidates, x, alpha):
    feasible = [e for e in candidates if car_transition_guard_v2(e, x, cert, alpha)]
    return max(feasible, key=lambda e: e.strategy_priority) if feasible else None

# IP-52 LCS：预算感知 + 动态阈值
def certify_light_v3(x, alpha, budget_us=200):
    r = gck_query(x)                       # 宽相+窄相，~50μs
    if r.margin < theta(alpha):
        return downgrade(r), -1            # 单调保守降级
    if budget_us < 120:
        return r, 0                        # 预算紧：只用保守 TOI 下界
    toi = conservative_advance(x, v_max, world, T_short)
    if toi < T_reaction:
        return downgrade(r), 0
    return r, 1

# IP-39 规划：CBF 用几何下界，Lipschitz 常数=1 有保证
def cbf_margin_from_gck(x):
    return max(0.0, gck_margin(x))
```

## 6. 本轮最大风险

**一句话**：把安全裕度当作可分配预算、并让竞争策略主动逼近碰撞边界，会把系统推到几何证书最脆弱的边界上——一旦状态估计误差 δ_est 被低估，或 GCK 的定点/凸分解近似在动态障碍处失效，1-Lipschitz 的「可证紧界」会退化为「看起来可证」，而比赛策略恰好会最大化这种边界暴露。
