# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环新周期第 1 轮；本轮灵感：「多端口部署」×「腕部相机」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 建成了「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知闭环，但仍留下三个**结构性缺口**：
> 1. **场景认知仍是「接触后」的**：SSM 的场景先验 π_scene(K|z) 依赖力/位遥测，只有真正接触后才能更新——「先认知后执行」在物理上仍退化为「先接触后认知」，前置适应能力被接触事件本身卡住。
> 2. **闭环默认「单端口」**：EPIR、SIC、K_safe 契约库都假设一个边端节点。真实部署是**多端口（多机器人/多 DDS 域/多边缘节点）**：每端口的手眼外参、相机内参、动力学参数都不同，端口 A 编译的安全契约不能直接搬到端口 B，否则「安全」会随部署漂移。
> 3. **证据锚点缺少视觉真值**：EPIR 的 seq+hash 只能证明「顺序完整、未被篡改」，无法判断两个端口对同一场景的 EV-exec **谁对谁错**；缺少一个可跨端口比对的近场物理锚点。

## 0. 直觉与动机

**灵感 1（腕部相机 → 接触前视觉-触觉先验 VCP）**
直觉：第 60 轮的 SSM 像「闭着眼睛摸桌子」，必须先碰一下才知道材质。腕部相机（eye-in-hand）让机器人「低头看一眼」：在触地前看到表面法向 n̂、纹理类别 c_tex、到表面的距离 d̂，于是能预测「还有多久接触（τ̂_touch）」和「接触瞬间该用多大阻抗（K̂_pre）」。但腕部相机有两个天然噪声源——**运动模糊**（速度越快越糊）和**手眼标定漂移**（相机看到的与末端实际位置有偏差），因此视觉先验必须带一个随速度与标定残差膨胀的置信折扣 γ_vis，且模糊/漂移必须显式进入协方差，而不是被点估计吞掉。

**灵感 2（多端口部署 → 端口不变安全契约 PISC）**
直觉：把同一套 SGEC 部署到 10 台机器人（10 个端口），每台的手眼外参、相机内参、关节动力学都不同。端口 A 上编译出的 K_safe 在端口 B 上可能不安全。关键洞见：**把安全契约拆成「端口无关的不变部分」+「端口特定的适配残差」**——契约在端口变换群 G 下保持可行，且每个端口的适配残差 δ_p 与标定新鲜度必须在上线时校验；一旦某端口标定过期，就降级为「端口本地保守契约」，绝不跨端口传播。

**灵感 3（腕部相机 × 多端口 → 分布式视觉证据锚定 DVEA）**
直觉：多个端口的 EV-exec 可能冲突（A 说「刚性桌面」，B 说「湿滑地面」）。EPIR 的 hash 只能证明「没被篡改」，不能证明「谁对」。腕部相机的紧凑视觉描述子（64 维特征哈希，**不传原图**）可作为**跨端口仲裁锚点**：置信度高、时间更近、且与 EPIR seq 哈希链接的证据胜出；若双方都低于阈值，则标记为「争议（contested）」，只更新端口本地信念，绝不污染全局场景先验。

**灵感 4（三灵感合流 → 端口可移植视觉-触觉闭环 PVTC）**
直觉：VCP 把认知提前到接触前 → PISC 保证编译出的 K_safe 在目标端口可行 → DVEA 让多端口证据可仲裁 → 形成「看→预测→编译→适配→执行→视觉-触觉残差→跨端口更新」的闭环。与第 60 轮 SERC 的区别：**SERC 是单端口的「接触后闭环」，PVTC 是多端口的「接触前闭环」**；前者回答「碰了之后怎么改」，后者回答「碰之前怎么知道、换台机器还成不成立」。

**灵感 5（PCE+++++ → 部署预算 B_dep）**
直觉：新增三维预算：B_port（标定校验/契约移植开销）、B_vis（腕部相机帧率/算力/带宽）、B_sync（跨端口锚点同步带宽），与第 60 轮 B_cog 共同构成 B_dep。预算耗尽即降级：B_port 尽 → 端口本地保守契约；B_vis 尽 → 退回纯力觉 SSM；B_sync 尽 → 证据仅本地有效并标记「未跨端口验证」。

**灵感 6（反向思考 → 视觉先验毒化 VPP 与隔离）**
直觉：腕部相机不是「越多越好」。反光表面、透明物体、快速运动会让视觉先验**高置信地错**；更糟的是，多端口部署会把一个端口的错误先验当作共享知识广播出去，形成**跨端口同步失败**。因此必须把「视觉先验」当作**可污染的共享状态**来治理：标定新鲜度门控、视觉置信门控、逐端口残差校验、争议证据隔离四道闸门缺一不可。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（腕部视觉-触觉接触前先验 VCP）** 设端口 p 的腕部相机图像 I^t_wrist，手眼变换 T^p_he（相机→末端），末端速度 v_ee。视觉观测算子：
- 表面法向 n̂ = f_n(I_wrist)，纹理类别 c_tex = f_c(I_wrist)，接触距离 d̂ = f_d(I_wrist, T^p_he)
- 视觉置信 γ_vis = g(σ_blur(v_ee), 曝光 e, 标定残差 δ_he^p)，其中 σ_blur 为运动模糊核宽度
- **接触前场景先验**：π_scene(K|z, I_wrist) ∝ π_scene(K|z) · L(I_wrist | K, z; Σ_vis)，Σ_vis = Σ_base + α·σ_blur²·I + β·(δ_he^p)²·I
- **接触时间预测**：τ̂_touch = d̂ / max(||v_ee||, ε_v)
- **接触前阻抗**：K̂_pre = E[K | z, I_wrist]，在 EEIS 中作为先验**提前**收窄 K_safe；当 γ_vis < τ_vis 时退化为第 60 轮 π_scene(K|z)。

**定义 162（端口不变安全契约 PISC）** 端口集合 P = {p₁,…,p_M}，端口参数 θ_p ∈ Θ（手眼外参、内参、动力学缩放）。端口变换群 G = {g_{p→q}}。契约 C = (K_safe, Cert) 在 G 下**端口不变**，若存在残差上界 ε_port 使
  ∀p,q: ||g_{p→q}(C_p) − C_q|| ≤ ε_port ∧ C_q ∈ F_q，
其中 F_q 为端口 q 的可行域。端口适配器 A_p：C_p = A_p(C_invariant; θ_p)，部署时校验 δ_p = ||A_p(C_invariant) ⊖ C_invariant|| 与标定新鲜度 age(T^p_he)。**不变性不是「参数相同」，而是「语义安全等价」**。

**定义 163（分布式视觉证据锚定 DVEA）** 端口 p 发出锚点 a^p_t = (port, seq_id, timestamp, h_desc, h_ev, γ_vis)，其中 h_desc = SHA256(compact_descriptor(I_wrist))[:16]（不传原图），h_ev 与 EPIR 的 EV-exec 哈希链接。云端维护锚点 DAG G_anchor，边表示因果先后。**跨端口仲裁**：若端口 p、q 对同一场景 z 的 EV-exec 冲突，按 score = γ_vis · γ_he · temporal_proximity 取大者；若 max(score) < τ_vis，标记 CONTESTED，仅更新端口本地信念。

**定义 164（端口可移植视觉-触觉闭环 PVTC）** 算子 PVTC(M, p, I_wrist, δ_f^req)：
```
① 标定门控：γ_he ← verify_calibration(T^p_he)；若 γ_he < τ_he → 退回 SERC（纯力觉）
② VCP：π_scene(K|z,I_wrist) → (K̂_pre, τ̂_touch, γ_vis)
③ 视觉门控：若 γ_vis < τ_vis → 退回 SERC
④ PISC：C_inv ← EEIS.compile_invariant(δ_f^req, K̂_pre, z)；
        (C_p, status) ← PISC.port_contract(C_inv, p)
⑤ 若 status ≠ OK → C_p ← EEIS.compile_conservative(δ_f^req)
⑥ CIEC/ERTC：锁定意图约束（第 60 轮）
⑦ 接触前下发 K_safe^pre（须在 τ̂_touch 之前完成）
⑧ 接触执行，采集力/位 telemetry
⑨ 视觉-触觉残差：r_vt = ||K̂_pre − K_obs||，按端口 θ_p 归一化
⑩ DVEA：emit anchor；EPIR.append(EV-exec)；跨端口同步
⑪ 场景信念更新：scene_conf ← f(scene_conf, r_vt, γ_he, γ_vis)
⑫ Return (C_p, EV-exec, anchor, status, r_vt)
```

**定义 165（部署预算 B_dep 与 PCE+++++）** B_dep = (B_port, B_vis, B_sync, B_cog)。其中
- B_port = (Calibration_verify_budget, Contract_porting_budget, Registry_sync_rate)
- B_vis = (Wrist_fps, Visual_compute, Visual_bandwidth)
- B_sync = (Cross_port_sync_bw, Anchor_retention, Arbitration_latency)
- B_cog = 第 60 轮四维认知预算

**定义 166（端口-视觉置信度张量 PVC）** PVC = (γ_he(p), γ_vis(I), γ_scene(z), γ_K(K|z))。
- PVC_valid ⇔ 四项均 ≥ 对应阈值（τ_he, τ_vis, τ_scene, τ_K）
- 跨端口一致性：γ_cross(p,q) = 1 − disagreement(p,q)·(1 − min(γ_he(p), γ_he(q)))
- PVC 是第 60 轮 SIC 三元组（定义 158）的多端口推广：SIC 是 PVC 在「单端口、无视觉」时的退化。

**定义 167（跨端口证据仲裁 CES）** 给定端口 p、q 的冲突证据 EV_p、EV_q 及锚点 a_p、a_q：
```
score_p = γ_vis(a_p) · γ_he(p) · temporal_proximity(a_p, EV_q)
score_q = γ_vis(a_q) · γ_he(q) · temporal_proximity(a_q, EV_p)
if max(score_p, score_q) < τ_vis: return (⊥, CONTESTED)   # 隔离，不污染全局
return (EV_p if score_p ≥ score_q else EV_q, RESOLVED)
```
**争议隔离原则**：CONTESTED 的证据只写入端口本地场景信念，不进入跨端口共享先验 π_scene^global。

**定义 168（端口语义等价 PSE 与部署可移植性条件）** 端口 p、q 关于场景 z 与契约库 C 是 ε-语义等价（记 p ≡_ε q），若
  ∀z, ∀C ∈ C: ||K_safe^p(z) − K_safe^q(z)|| ≤ ε。
**部署可移植性条件**：若 ∀p: δ_p ≤ ε_port ∧ age(T^p_he) ≤ T_fresh ∧ γ_he(p) ≥ τ_he，则对共享契约库成立 p ≡_ε q，且第 60 轮的执行安全保证可从端口 p 传递到端口 q。

### IP-161 VCP（腕部视觉-触觉接触前先验）

```python
class WristVisualTactilePrior:
    def __init__(self, hand_eye, blur_model, scene_priors):
        self.T_he = hand_eye
        self.blur_model = blur_model
        self.scene_priors = scene_priors
        self.calib_residual = None

    def estimate(self, img, v_ee, z_scene):
        blur = self.blur_model.sigma(v_ee)
        n_hat, c_tex, d_hat = self._extract(img)
        gamma_vis = self._confidence(blur, img.exposure, self.calib_residual)
        Sigma_vis = self._visual_cov(blur, self.calib_residual)
        mu_pre, cov_pre = self._fuse_prior(
            self.scene_priors[z_scene], (n_hat, c_tex, d_hat), Sigma_vis)
        tau_touch = d_hat / max(v_ee.norm(), 1e-3)
        return {'K_pre': (mu_pre, cov_pre),
                'tau_touch': tau_touch,
                'gamma_vis': gamma_vis,
                'Sigma_vis': Sigma_vis}

    def residual(self, K_pre, K_obs, theta_p):
        r = K_obs - K_pre
        return float(r.T @ np.linalg.inv(theta_p.norm_cov) @ r)
```

### IP-162 PISC（端口不变安全契约）

```python
class PortInvariantContract:
    def __init__(self, eps_port=0.05, eps_calib=0.002, t_fresh=3600.0):
        self.eps_port = eps_port
        self.eps_calib = eps_calib
        self.t_fresh = t_fresh
        self.registry = {}

    def register_port(self, port_id, theta_p, sigma_p, calib_time):
        self.registry[port_id] = {
            'theta': theta_p, 'sigma': sigma_p, 'calib_time': calib_time}

    def _calib_stale(self, p, now):
        return (now - p['calib_time']) > self.t_fresh

    def port_contract(self, C_invariant, port_id, now):
        p = self.registry[port_id]
        if self._calib_stale(p, now):
            return None, 'CALIB_STALE'
        C_p = self._adapter(p['theta'])(C_invariant)
        delta = self._residual(C_p, C_invariant)
        if delta > self.eps_port + p['sigma']:
            return None, f'PORT_RESIDUAL_{delta:.3f}'
        return C_p, 'OK'

    def verify_group(self, C_invariant, ports, now):
        for q in ports:
            C_q, status = self.port_contract(C_invariant, q, now)
            if status != 'OK':
                return False, (q, status)
        return True, 'PORT_INVARIANT'
```

### IP-163 DVEA（分布式视觉证据锚定）

```python
class DistributedVisualEvidenceAnchor:
    def __init__(self, tau_vis=0.7):
        self.tau_vis = tau_vis
        self.anchors = {}
        self.dag = nx.DiGraph()

    def emit(self, port_id, ev_exec, img, gamma_vis):
        desc = self._compact_descriptor(img)          # 64-D, no raw image
        a = {'port': port_id,
             'seq': ev_exec['seq_id'],
             't': ev_exec['timestamp'],
             'h_desc': sha256(desc.tobytes()).hexdigest()[:16],
             'h_ev': ev_exec['hash'],
             'gamma_vis': gamma_vis}
        self.anchors[(port_id, ev_exec['seq_id'])] = a
        self._link_causal(a, ev_exec)
        return a

    def arbitrate(self, ev_p, ev_q):
        ap = self.anchors[(ev_p['port'], ev_p['seq_id'])]
        aq = self.anchors[(ev_q['port'], ev_q['seq_id'])]
        score_p = ap['gamma_vis'] * temporal_proximity(ap, ev_q)
        score_q = aq['gamma_vis'] * temporal_proximity(aq, ev_p)
        if max(score_p, score_q) < self.tau_vis:
            return None, 'CONTESTED'
        return (ev_p if score_p >= score_q else ev_q), 'RESOLVED'
```

def port_portable_visual_tactile_loop(M, port_id, img, delta_f_req):
    p = M.port_registry[port_id]
    gamma_he = M.calib.verify(p)
    if gamma_he < M.tau_he:
        return scenario_perception_evolution_loop(M, None, M.intent_latest, delta_f_req)

    z_scene = M.scene_model.update(M.telem_force, M.telem_pos)
    vcp = M.vcp.estimate(img, M.ee.v, z_scene)
    if vcp['gamma_vis'] < M.tau_vis:

    C_inv = M.eeis.compile_invariant(delta_f_req, vcp['K_pre'], z_scene)
    C_p, status = M.pisc.port_contract(C_inv, port_id, now=time.time())
    if status != 'OK':
        C_p = M.eeis.compile_conservative(delta_f_req)

    M.ertc.lock_constraints(M.ciec.map(M.intent_latest))
    dispatch_impedance_params(C_p.best, C_p.cert)      # pre-contact
    telemetry = wait_contact(max_wait=1.5 * vcp['tau_touch'])

    K_obs = M.buq.identify(telemetry)
    r_vt = M.vcp.residual(vcp['K_pre'], K_obs, p['theta'])
    M.scene_model.update_belief(z_scene, r_vt, gamma_he, vcp['gamma_vis'])

    ev = build_exec_evidence(telemetry, K_obs, C_p)
    M.epir.append(ev)
    anchor = M.dvea.emit(port_id, ev, img, vcp['gamma_vis'])
    M.dvea.sync_cross_port(anchor, M.budget.B_sync)
    return M, ev, anchor, status, r_vt

### IP-166/167 PVC 与 CES（置信度张量与跨端口仲裁）

```python
class PortVisualConfidence:
    def __init__(self, tau_he=0.9, tau_vis=0.7, tau_scene=0.7, tau_K=0.6):
        self.tau = {'he': tau_he, 'vis': tau_vis,
                    'scene': tau_scene, 'K': tau_K}

    def valid(self, pvc):
        return all(pvc[k] >= self.tau[k] for k in self.tau)

    def cross_port(self, pvc_p, pvc_q, disagreement):
        return 1.0 - disagreement * (1 - min(pvc_p['he'], pvc_q['he']))


def cross_port_evidence_arbitration(ev_p, ev_q, anchors, tau_vis):
    ap, aq = anchors[(ev_p['port'], ev_p['seq_id'])], \
             anchors[(ev_q['port'], ev_q['seq_id'])]
    sp = ap['gamma_vis'] * temporal_proximity(ap, ev_q)
    sq = aq['gamma_vis'] * temporal_proximity(aq, ev_p)
    if max(sp, sq) < tau_vis:
        return None, 'CONTESTED'
    return (ev_p if sp >= sq else ev_q), 'RESOLVED'
```

### IP-168 PSE（部署可移植性校验）

```python
def verify_port_semantic_equivalence(contract_lib, ports, scene_set,
                                     eps=0.05, now=None):
    now = now or time.time()
    for C_inv in contract_lib:
        ok, info = PISC.verify_group(C_inv, ports, now)
        if not ok:
            return False, info
        for z in scene_set:
            Ks = [PISC.port_contract(C_inv, p, now)[0].K_safe(z) for p in ports]
            for a in range(len(Ks)):
                for b in range(a + 1, len(Ks)):
                    if np.linalg.norm(Ks[a] - Ks[b]) > eps:
                        return False, ('SEMANTIC_DRIFT', ports[a], ports[b], z)
    return True, 'PORT_SEMANTIC_EQUIVALENT'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VCP | O(HW) 特征提取 + O(d³) 高斯融合/帧 | O(帧缓冲) | γ_vis ≥ τ_vis 时视觉先验误差 ≤ δ_vis |
| PISC | O(M) 端口校验/契约 | O(M·d) | 适配残差 δ_p ≤ ε_port，标定新鲜 |
| DVEA | O(1) 锚点生成 / O(log N) DAG | O(N_anchor·d_desc) | 跨端口一致性 ≥ 99.5% |
| PVTC | O(闭环 + 帧) | 复用 | 可移植成功率 ≥ 95%，r_vt 下降 ≥ 30% |

**正确性定理（PVTC / 部署可移植性）**：
假设 A66–A70 成立：

### IP-161 VCP（腕部视觉-触觉接触前先验）

```python
class WristVisualTactilePrior:
    def __init__(self, hand_eye, blur_model, scene_priors):
        self.T_he = hand_eye
        self.blur_model = blur_model
        self.scene_priors = scene_priors
        self.calib_residual = None

    def estimate(self, img, v_ee, z_scene):
        blur = self.blur_model.sigma(v_ee)
        n_hat, c_tex, d_hat = self._extract(img)
        gamma_vis = self._confidence(blur, img.exposure, self.calib_residual)
        Sigma_vis = self._visual_cov(blur, self.calib_residual)
        mu_pre, cov_pre = self._fuse_prior(
            self.scene_priors[z_scene], (n_hat, c_tex, d_hat), Sigma_vis)
        tau_touch = d_hat / max(v_ee.norm(), 1e-3)
        return {'K_pre': (mu_pre, cov_pre),
                'tau_touch': tau_touch,
                'gamma_vis': gamma_vis,
                'Sigma_vis': Sigma_vis}

    def residual(self, K_pre, K_obs, theta_p):
        r = K_obs - K_pre
        return float(r.T @ np.linalg.inv(theta_p.norm_cov) @ r)
```

### IP-162 PISC（端口不变安全契约）

```python
class PortInvariantContract:
    def __init__(self, eps_port=0.05, eps_calib=0.002, t_fresh=3600.0):
        self.eps_port = eps_port
        self.eps_calib = eps_calib
        self.t_fresh = t_fresh
        self.registry = {}

    def register_port(self, port_id, theta_p, sigma_p, calib_time):
        self.registry[port_id] = {
            'theta': theta_p, 'sigma': sigma_p, 'calib_time': calib_time}

    def _calib_stale(self, p, now):
        return (now - p['calib_time']) > self.t_fresh

    def port_contract(self, C_invariant, port_id, now):
        p = self.registry[port_id]
        if self._calib_stale(p, now):
            return None, 'CALIB_STALE'
        C_p = self._adapter(p['theta'])(C_invariant)
        delta = self._residual(C_p, C_invariant)
        if delta > self.eps_port + p['sigma']:
            return None, f'PORT_RESIDUAL_{delta:.3f}'
        return C_p, 'OK'

    def verify_group(self, C_invariant, ports, now):
        for q in ports:
            C_q, status = self.port_contract(C_invariant, q, now)
            if status != 'OK':
                return False, (q, status)
        return True, 'PORT_INVARIANT'
```

### IP-163 DVEA（分布式视觉证据锚定）

```python
class DistributedVisualEvidenceAnchor:
    def __init__(self, tau_vis=0.7):
        self.tau_vis = tau_vis
        self.anchors = {}
        self.dag = nx.DiGraph()

    def emit(self, port_id, ev_exec, img, gamma_vis):
        desc = self._compact_descriptor(img)          # 64-D, no raw image
        a = {'port': port_id,
             'seq': ev_exec['seq_id'],
             't': ev_exec['timestamp'],
             'h_desc': sha256(desc.tobytes()).hexdigest()[:16],
             'h_ev': ev_exec['hash'],
             'gamma_vis': gamma_vis}
        self.anchors[(port_id, ev_exec['seq_id'])] = a
        self._link_causal(a, ev_exec)
        return a

    def arbitrate(self, ev_p, ev_q):
        ap = self.anchors[(ev_p['port'], ev_p['seq_id'])]
        aq = self.anchors[(ev_q['port'], ev_q['seq_id'])]
        score_p = ap['gamma_vis'] * temporal_proximity(ap, ev_q)
        score_q = aq['gamma_vis'] * temporal_proximity(aq, ev_p)
        if max(score_p, score_q) < self.tau_vis:
            return None, 'CONTESTED'
        return (ev_p if score_p >= score_q else ev_q), 'RESOLVED'
```

class PortVisualConfidence:
    def __init__(self, tau_he=0.9, tau_vis=0.7, tau_scene=0.7, tau_K=0.6):
        self.tau = {'he': tau_he, 'vis': tau_vis,
                    'scene': tau_scene, 'K': tau_K}

    def valid(self, pvc):
        return all(pvc[k] >= self.tau[k] for k in self.tau)

    def cross_port(self, pvc_p, pvc_q, disagreement):
        return 1.0 - disagreement * (1 - min(pvc_p['he'], pvc_q['he']))


def cross_port_evidence_arbitration(ev_p, ev_q, anchors, tau_vis):
    ap, aq = anchors[(ev_p['port'], ev_p['seq_id'])], \
             anchors[(ev_q['port'], ev_q['seq_id'])]
    sp = ap['gamma_vis'] * temporal_proximity(ap, ev_q)
    sq = aq['gamma_vis'] * temporal_proximity(aq, ev_p)
    if max(sp, sq) < tau_vis:
        return None, 'CONTESTED'
    return (ev_p if sp >= sq else ev_q), 'RESOLVED'

### IP-168 PSE（部署可移植性校验）

```python
def verify_port_semantic_equivalence(contract_lib, ports, scene_set,
                                     eps=0.05, now=None):
    now = now or time.time()
    for C_inv in contract_lib:
        ok, info = PISC.verify_group(C_inv, ports, now)
        if not ok:
            return False, info
        for z in scene_set:
            Ks = [PISC.port_contract(C_inv, p, now)[0].K_safe(z) for p in ports]
            for a in range(len(Ks)):
                for b in range(a + 1, len(Ks)):
                    if np.linalg.norm(Ks[a] - Ks[b]) > eps:
                        return False, ('SEMANTIC_DRIFT', ports[a], ports[b], z)
    return True, 'PORT_SEMANTIC_EQUIVALENT'
```
