# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「情感计算」×「机器人竞赛」）

> R69 让系统学会了「问」：把不确定性拆成 aleatoric/epistemic，用流匹配多模态策略 + 主动多模态交互去消解后者。但 R69 隐含了两个过于乐观的假设：
> （1）**对方是（弱对抗的）合作者**——回答 y 服从一个固定的 p(y|g,o)，顶多被随机投毒（欺骗率 δ_p、相关 ρ<1），于是「k 个正交证据源一致」就能把错误率压到 δ_p·ρ^{k−1}；
> （2）**提问是纯粹的信息获取**——只花物理/社交成本，不改变对方，也不暴露自己。
>
> 在**机器人竞赛**这种有时间、有对手、有记分牌的设定里，两条都不成立：对手会建模你的估计器、会只污染你「会去查的那一对源」、会读懂你的犹豫；而**你自己的表达（表情、语气、迟疑、注视）就是一张会漏底的牌**。情感计算进一步指出：情绪不是等待被查询的潜变量——它一半是被读出的信号，一半是被**共同建构**并**策略性表演**的信号；同一张笑脸既可能是合作，也可能是诈唬。
>
> 核心命题：**把「交互」从信息获取升级为「信号博弈」：对手有类型 θ 与策略 σ，机器人有泄漏 L；净信息价值 = 稳健 VoI − 泄漏 − 成本。用交互差分隐私把泄漏关进预算，用随机化证据获取与预承诺挫败「懂你估计器」的投毒，用延迟而不可伪造的赛事记分作为标定锚，用分差驱动的竞争风险胃口在「效用-泄漏前沿」上动态取点。唯一不可让渡的仍是硬安全包络。** 命名 **TELL-RAS**（Tactical Expression & Leakage-Limited risk-adaptive Safety）。
>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「**我该露出什么，而对方给的到底是真话还是一张 tell**」。R69 的提问是耗费；R70 的提问是下注。

## 0. 直觉与动机

**灵感 1（情感计算 → 情绪是信号，也是动作）**
直觉：R69 把 `r_emo` 当作一条证据通道、把「问情绪」当作一次查询。但情绪有三层，R69 只碰了第一层：
- **被读层**：面部动作单元（FACS）、韵律、皮电/心率、姿态、注视——带噪且可伪装；
- **被建构层**：情绪是在互动中被共同建构的——机器人凑近、放慢、用柔和语气，会**改变**人本来要表达的情绪。观测模型因此是**内生**的 `p(y|g,e,o)`，其中 `e` 是机器人自己的表达；
- **被表演层**：在竞争/博弈中，情绪是**信号**：人可以 bluff（诈唬）或 mask（掩藏），也可以让表情、语气、姿态**共谋**制造一个自洽的假象。

于是情绪既有生理噪声，也有语义歧义，还有第三种 R69 没区分的——**定义性/标注歧义 `U_sem`**：「这个人到底是紧张还是兴奋」可能根本没有唯一答案；多问几次也问不出来，因为它不是缺信息，而是**目标本身是分布的**。U_sem 既不该驱动交互（问了也白问），也不该无限收紧（会冻住系统），只能进**分布化任务目标**。

**灵感 2（机器人竞赛 → 对手、记分、以及会读你的裁判）**
直觉：竞赛给三样 R69 没有的东西：
- **一个会建模你的对手**：它知道你会算 VoI、会查正交源、会因不确定而减速；于是它可以让「正交源」一起说谎，或专门在你减速时抢分。投毒不再是独立随机扰动，而是**针对你策略的最优响应**；
- **一块不可伪造的记分牌**：比分/名次是延迟、稀疏、但**外部客观**的标签。它正好能给 R69 最脆弱的「模态权重校准」做锚——ECE 再也不是自己校准自己；
- **一个相对的、随时间变化的目标**：竞赛不是「最小化绝对风险」，而是「赢/名次/后悔」。领先时应保守藏牌，落后时应冒险探询。风险胃口随**分差与剩余时间**变化——R68/R69 那种「任何不确定就收紧」在竞赛里会**稳定输给**一个校准良好的激进对手。

**灵感 3（合成 → 提问是双向信道，净 VoI 必须扣掉泄漏）**
直觉：R69 的 `VoI(g)` 只算「我获得了多少」。但任何可观测的交互 `g`（以及伴随表达 `e`）都同时把机器人的**私有状态**（模态信念、不确定性、甚至策略参数）编码进外部世界。对手看见你迟疑，就知道你不确定；看见你反复确认，就知道那里有诈。于是
**`VoI_net(g,e) = VoI_rob(g,e) − Exploit(g,e) − c(g,e)`。**
问得越准，往往暴露得越多；真正最优的常常不是「问最 informative 的问题」，而是「在可接受泄漏下问最有价值的问题」。这把 R69 的「交互双刃剑」从一句风险提示，升级为**可优化、可约束、可审计的第一等成本项**。

**灵感 4（严格包含 → R69 是「无对抗、无泄漏」的边界）**
直觉：当对手非策略（σ 诚实且固定）、表达不耦合（`∂p/∂e=0`）、且无泄漏顾虑（`ε→∞`）时，TELL-RAS 必须**逐指令**退化为 FLUID-RAS。竞赛中的硬安全包络仍由 R68/R69 的 λ_floor 与 C-RAS-WM 认证守住；竞争风险胃口只调节**硬包络之内**的软预算（速度、探询频率、表达开放度）。新层不推翻旧层，只在旧层「不敢问/不必藏」的边界之外加上一段**博弈与隐蔽**。

**灵感 5（新威胁模型 → 最懂你的人最危险）**
直觉：R69 的「k 源正交一致」上界 `δ_p·ρ^{k−1}` 假设**源的独立性是环境属性**。可一旦对手知道你的选择策略，独立性就成了**它的选择**：它可以只污染你**会去查的那一对**，让 k 个「正交」源同时倒向同一答案，`ρ→1`，上界退化为 `δ_p`。更阴险的是**二阶攻击**：攻击你的**泄漏估计器**——让你以为 ε 很小，实则早已裸奔；或攻击你的**记分锚**（若记分可被操纵，外部真值就没了）。因此 R70 必须引入：**随机化证据获取 + 预承诺（commitment/nonce）**、**对泄漏估计本身的对抗鲁棒性**、以及**记分锚的可信性检查**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TELL-RAS 总览）** TELL-RAS = (REF, SG, LEAK, VNI, TF, SAC, REA, CRB, RAS-WM†)。四不变式：
(i) **硬安全包络不可让渡**：继承 R68/R69 的 `λ ≥ λ_floor(U_floor)` 与 C-RAS-WM 认证，竞争胃口只在硬包络**之内**调节；
(ii) **泄漏预算硬约束**：交互-表达策略 `q(g,e|z)` 对私有状态 `z` 满足 `(ε,δ)`-交互差分隐私；
(iii) **稳健证据纪律**：单源/单次不得定案；证据获取须**随机化且预承诺**，不接受可被对手预测的「正交性」；
(iv) **记分锚可信性**：只有通过完整性检查的赛事记分才可用于标定。

**定义 311（增广动作空间 ξ=(a,g,e)）** 任务动作 `a∈𝒜_task`，信息动作 `g∈𝒜_info`（继承 R69 的注视/探针/问句），**表达动作** `e=(e_face,e_voice,e_posture,e_hes)∈𝒜_exp`（表情/语气/姿态/迟疑）。策略 `π_θ(ξ_{t:t+H}|o_t)`，流匹配骨架沿用 R69 定义 295，输出维度扩到 `d_a+d_g+d_e`。

**定义 312（内生观测模型与耦合增益）** 人类回答/情绪 `y ~ p(y|g,e,o;θ)` 显式依赖机器人表达 `e`。耦合增益 `κ = sup_{e,e'} ‖E[y|g,e,o] − E[y|g,e',o]‖/‖e−e'‖`。`κ=0` 即 R69 的非耦合情形。情绪真值按标注分布 `p_ann(y|·)` 给出，而非单点。

**定义 313（三分解不确定性）** `U_ale`（模态内噪声，继承定义 297）；`U_epi`（模态间可约歧义，继承定义 297）；`U_sem = E_{x~p_ann}[H(p_ann(·|x))]`（**标注/语义不可约**）。三者分通道：`U_ale→λ_floor`；`U_epi→交互/博弈`；`U_sem→分布化任务损失`，**不驱动交互、也不进入 λ_floor**。

**定义 314（对手信号策略与 tell）** 对手有私有类型 `θ`（真实意图/情绪/能力），选择信号策略 `σ(y|θ,g,e)`。诚实通道记 `σ_truth`。**tell 强度** `τ_tell = KL(σ(·|θ,g,e) ‖ σ_truth(·|θ))`；`τ_tell` 高表示「更像表演而非泄露」。对手可 bluff（y 偏离 θ）或 mask（压缩 `σ` 的熵）。

**定义 315（稳健 VoI）** 在对手策略的歧义集 `Σ_amb`（含诚实、诈唬、掩藏、共谋）上取最坏情形：
`VoI_rob(g,e) = inf_{σ∈Σ_amb} [ H(M|o) − E_{y~σ}[H(M|o,y)] ]`；
若给出对手策略先验，则用贝叶斯稳健版 `E_{σ~prior}[·]`。`Σ_amb={σ_truth}` 时退化为 R69 的 VoI。

**定义 316（泄漏与净 VoI）** 私有状态 `z_t = (模态后验, 不确定性, 策略内部量)`；可观测交互 `(g,e)`。泄漏 `L(g,e) = I(z_t; (g,e))`；对手利用损失 `Exploit(g,e) = max_{σ'} E[Δscore | σ', L]`。**净 VoI** `V_net(g,e) = VoI_rob(g,e) − κ_L·Exploit(g,e) − c(g,e)`，选 `argmax V_net` s.t. 安全认证与 `(ε,δ)`-IDP。

**定义 317（交互差分隐私 IDP）** 交互-表达策略 `q(g,e|z)` 对任意相邻私有状态 `z,z'` 满足 `(ε,δ)`-DP。其泄漏满足 DP→互信息界 `L ≤ Λ(ε)`，`Λ(0)=0` 且随机制灵敏度线性增长（引理 19）。这给出「用随机化把私有状态糊掉」的可计算泄漏预算。

**定义 318（被动 tell 通道 vs 主动查询通道）** 被动通道（读微表情/迟疑/韵律）`leak=0`、`U_ale` 高；主动通道（问/探/触）信息增益高但泄漏高。融合后验 `p(M|o) ∝ p_passive(M|o)·p_active(M|o,y)`，两通道权重由 `V_net` 与泄漏预算联合决定。

**定义 319（竞争风险胃口与软预算）** 记分状态 `(s,T,B)`：`s` 为归一化分差（正=领先），`T` 剩余时间，`B` 剩余预算。**进攻度** `α(s,T)∈[0,1]` 关于落后幅度与 `T` 单调增、关于领先单调减。软风险缩放
`λ_soft = max( λ_floor, λ_ref − α(s,T)·(λ_ref − λ_floor) )`，
`λ_ref` 为 R69 默认缩放。`α=0` 回 R69 默认，`α=1` 取到硬包络允许的最激进点；**恒有 `λ_soft ≥ λ_floor`**。

**定义 320（记分锚定标定 SAC）** 用延迟赛事记分/名次作**外部工具变量**校准模态权重：对每个被访问模态做反事实信用分配，最小化 `ECE` 与得分残差；在每模态覆盖 `m` 次的条件下可识别（引理 21）。记分不可信时（定义 310-iv 不过）退回 R69 的自校准并标记 `anchored=false`。

**定义 321（随机化证据获取 REA）** 从候选正交源对中按承诺哈希随机抽取需验证的子集，使对手无法预测「你会查哪一对」；选择熵 `H_sel` 直接进入有效相关上界（引理 20）。

**定义 322（承诺与 nonce）** 观测前先发布 `commit = H(protocol ‖ nonce)`，事后公开 `nonce` 验证。承诺锁定验证协议，使对手无法在观测后自适应地「制造正交」。

**定义 323（表达不透明度）** 在满足任务/社交约束下选 `e` 最小化泄漏：`e* = argmin_e L(g,e)` s.t. 任务误差 ≤ δ_task、社交约束可行。不透明度作为表达通道的显式预算项。

**定义 324（战略审计 VQAuditor-S）** 在 R69 参与式审计上新增：实际泄漏 vs 声称泄漏、bluff 是否被误当真、记分锚完整性、tell-spoofing 是否诱导了错误定案。结论回灌 AuditBuf，成为下一轮 `Σ_amb` 与泄漏预算的先验。

**定义 325（战略干扰集 AIC-STRAT）** `ℰ_STRAT = ℰ_FLUID × ℰ_est × ℰ_tell × ℰ_score`：估计器感知投毒（只污染你会查的源）、制造正交/共谋、tell-spoofing（用表演性情绪误导）、记分投毒与操纵。

**定义 326（证书 J_TELL）** `J_TELL = (J_FLUID, ε_idp, leak_realized, robust_voi_ratio, sac_ece, rea_commit_hash, strat_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ (ε,δ)`-IDP 满足 ∧ 泄漏审计通过 ∧ 证据获取可验证承诺 ∧ 记分锚完整性通过（或显式降级）。

# IP-264 EXP / IP-265 REF：表达头 + 内生观测/耦合估计
class TellPolicy:
    def sample(self, o_t, K):                       # 复用 R69 FMP，多输出 e
        z = self.trunk(o_t)
        return self.flow.sample(K)                  # ξ=(a,g,e)

    def read_passive(self, o_t):                    # 被动读 tell：leak = 0
        return self.tell_net(o_t)                   # -> (tell_post, U_ale_passive)

    def coupling_gain(self, o_t):                   # κ：表达对回答的因果影响
        return self.reflex_est.estimate(o_t)        # κ<1 方可稳定闭环

# IP-266 SG：信号博弈的稳健后验更新
def robust_update(belief, y, e, opp_model):
    ambiguities = opp_model.ambiguity_set(belief, e) # 诚实/诈唬/掩藏/共谋
    return minimax_bayes_update(belief, y, ambiguities)

# IP-268 VNI：净 VoI = 稳健增益 − 利用损失 − 成本
def net_voi(g, e, z, belief, opp, eps):
    voi_rob = robust_voi(belief, g, e, opp.ambiguity_set)
    exploit = opp.exploit_gain(g, e, belief)        # 由泄漏 L 与 ε 决定
    return voi_rob - KAPPA_L * exploit - cost(g, e)

def choose_interaction(cands, z, belief, opp, eps, budget):
    best = None
    for (g, e) in cands:
        if not budget.allow(g, e):              continue
        if not c_ras_wm.certify_info((g, e), o): continue   # 表达也过安全认证
        if not idp_ok(g, e, z, eps, budget.delta): continue # 泄漏预算硬约束
        v = net_voi(g, e, z, belief, opp, eps)
        if best is None or v > best.v: best = (g, e, v)
    return best

# IP-271 REA：承诺 + 随机化证据获取（挫败估计器感知投毒）
def reveal_and_verify(modes, z, nonce):
    commit = H(protocol, nonce)                     # 观测前发布
    subset = sample_by_hash(orthogonal_pairs(modes), commit, k=K_VERIFY)
    return subset, commit

# IP-270 SAC：用延迟记分做外部锚（反事实信用分配）
def score_anchor_update(mode_calib, match_log):
    for ep in match_log:
        mode_calib.update_counterfactual(ep.score, ep.modes_visited)
    return mode_calib.ece()

# IP-276 TELL-RAS 主闭环（继承 R69，仅在交互处置处插入博弈层）
def TELL_RAS_round(M, obs, score_state):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    # --- R69 层：歧义预测 + 分解 + 似然第二意见 ---
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, U_sem, modes = M.ref.decompose(samples, z)   # 三分解
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    slow = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # --- R70 层：战略交互 + 泄漏约束 + 竞争胃口 ---
    alpha = M.crb.aggression(score_state)                       # 分差/剩余时间
    g = e = None
    if (U_epi > TAU_EPI) and not slow and alpha > 0:
        subset, commit = M.rea.reveal_and_verify(modes, z, M.nonce)
        cands = M.rea.candidate_actions(modes, subset)
        best = M.vni.choose_interaction(cands, z, modes, M.opp, M.eps, M.budget)
        if best and best.v > M.crb.threshold(score_state):
            g, e = best.g, best.e
            y = M.sg.execute(g)                                 # 看/问/触
            U_epi = M.sg.robust_update(modes, y, e, M.opp)      # 稳健后验
    # --- 风险缩放：U_sem 不进 λ；未消解 U_epi 视同 aleatoric ---
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    lam = M.crb.apply(lam, score_state)          # 夹在 [λ_floor, λ_ref]，安全不变
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(g, e, U_epi, a_hat, commit, score_state)
    return k, lam, mode, (U_ale, U_epi, U_sem)

## 3. 推导

**引理 19（泄漏-效用前沿）** 设交互-表达策略 `q(g,e|z)` 为 `(ε,δ)`-IDP，则泄漏满足 `L(z;(g,e)) ≤ Λ(ε)`，`Λ(0)=0`、`Λ` 关于机制灵敏度单调不减（标准 DP→互信息界）。于是存在一条**帕累托前沿**：`ε→0` 时策略对 `z` 恒定，`L=0` 但 `VoI_rob=0`（相当于「永远沉默」）；`ε→∞` 时 `VoI_rob` 最大但 `L` 无界。**R69 恰是「非策略、`ε=∞`」这个角点**；TELL-RAS 是这条前沿上的可调占优曲线。

**引理 20（静态正交性在策略性对手下失效，REA 恢复上界）** 若对手知道证据选择策略，则可只污染将被查询的源，使 `ρ→1`，R69 的错误上界 `δ_p·ρ^{k−1}` 退化为 `δ_p`，与 `k` 无关。改用承诺哈希随机抽取 `k` 个源、选择熵 `H_sel`：对手只能盲污染，有效相关 `ρ_eff ≤ ρ_max(H_sel)`，错误率 `≤ δ_p·E[ρ_eff^{k−1}] + ε_σ`。系：**随机化 + 预承诺把「正交性」从对手手里夺回环境**；但选择熵本身也消耗预算，是最优化的一部分。

**引理 21（记分锚的可识别性）** 在延迟、稀疏但不可操纵的记分下，若每个模态至少被覆盖 `m` 次，则模态校准误差 `ECE` 可识别到 `O(m^{−1/2})` 的信用分配误差内。若记分可被操纵（`ℰ_score` 成立），可识别性失效——这时必须显式降级（`anchored=false`）而不是继续自校准。这是对 R69「自己校准自己」最脆弱的 MCG 的正面补强。

**定理 18（TELL 严格包含 FLUID）** 当 `Σ_amb={σ_truth}`（非策略）、`κ=0`（无情绪耦合）、`ε=∞`（无泄漏顾虑）时，TELL-RAS 与 FLUID-RAS **逐指令相同**。且任意配置下 `λ_soft ≥ λ_floor`，硬安全包络与换装不变式（R68 定理 15）保持。故 R69 是 R70 在「无对抗、无泄漏」边界上的严格退化，安全侧不做任何让步。

**定理 19（竞争风险胃口的单调性与安全不变性）** 进攻度 `α(s,T)` 关于落后幅度与剩余时间单调增、关于领先单调减；`λ_soft∈[λ_floor,λ_ref]`，且每步变化受 `|Δλ|≤Δ_max` 限制 ⇒ 控制连续、无突变；硬包络从未被竞争目标触碰。于是「领先藏牌、落后冒险」是**软预算**上的最优取点，而非对安全的妥协。

**引理 22（情感耦合闭环的稳定性）** 反思回路 `e_t → y_t → 机器人估计 → e_{t+1}` 的有效增益为 `κ`。若 `κ<1`（压缩映射），闭环收敛；若 `κ≥1`，会出现情绪传染/振荡放大。此时须提高表达不透明度，使 `κ_eff<1`（定义 323）。这给「机器人自己的情绪表达反过来污染自己估计」这一情感计算特有风险一个可证的稳定条件。

## 6. 本轮最大风险

**一句话**：TELL-RAS 的全部竞争收益押在「对对手策略与泄漏的估计是可信的」这一前提上——**若对手比模型更高阶（会利用你的 IDP 随机化、或反向操纵你「以为很安全」的泄漏估计），你就会在自以为藏住底牌时，把最致命的那张 tell 精确地亮给一个正在读你的对手；此时「泄漏估计器」本身成了最危险的攻击面，而系统会带着「已验证隐私」的证书自信地输掉比赛。**

**次级风险与缓解**：
1. **记分锚被污染**（`ℰ_score`）→ 完整性检查 + 不可信即降级 `anchored=false`，绝不拿被操纵的真值标定；
2. **U_sem 被误当 U_epi**（追问不可解问题）→ 三分解隔离 + 分布化损失，E308 验证；
3. **表达不透明度削弱社交可读性**（人机信任下降）→ 社交约束硬下限 + E310/E314 人因评估；
4. **REA 选择熵耗尽预算** → 选择熵纳入净 VoI，E304/E299 联合寻优；
5. **竞争胃口侵蚀安全边际**（差一点越界）→ `λ_soft` 夹紧 + 每步 `Δ_max` + E311 零越界门禁。

## 4. 推导

**引理 19（泄漏-效用前沿）** `(ε,δ)`-IDP 策略满足 `L≤Λ(ε)`、`Λ(0)=0`。`ε→0`：策略对私有状态恒定，`L=0` 但 `VoI_rob=0`（永远沉默）；`ε→∞`：`VoI_rob` 最大、`L` 无界。R69 是非策略、`ε=∞` 的角点；TELL 是这条前沿上的可调占优曲线。

**引理 20（静态正交性失效，REA 恢复）** 对手知晓选择策略时可只污染被查源，使 `ρ→1`，R69 上界 `δ_p·ρ^{k−1}` 退化为 `δ_p`（与 k 无关）。承诺哈希随机抽取 k 源、选择熵 `H_sel`：对手只能盲污染，`ρ_eff≤ρ_max(H_sel)`，错误率 `≤δ_p·E[ρ_eff^{k−1}]+ε_σ`。系：随机化+预承诺把「正交性」从对手手里夺回。

**引理 21（记分锚可识别性）** 延迟/稀疏但不可操纵的记分下，每模态覆盖 `m` 次时 `ECE` 可识别到 `O(m^{−1/2})` 信用分配误差；记分可操纵则由 `ℰ_score` 判失效，必须降级 `anchored=false`。

**引理 22（情感耦合稳定性）** 反思回路 `e→y→估计→e'` 有效增益 `κ`；`κ<1` 收敛，`κ≥1` 发散/振荡，须提高表达不透明度使 `κ_eff<1`。

**定理 18（TELL 严格包含 FLUID）** `Σ_amb={σ_truth}`、`κ=0`、`ε=∞` 时 TELL 与 FLUID 逐指令相同；任意配置下 `λ_soft≥λ_floor`，硬包络与换装不变式保持。R69 = 「无对抗、无泄漏」边界，安全不让步。

**定理 19（竞争胃口单调性与安全不变性）** `α(s,T)` 落后/时间增、领先减；`λ_soft∈[λ_floor,λ_ref]` 且 `|Δλ|≤Δ_max` ⇒ 控制连续、硬包络不被竞争目标触碰。「领先藏牌、落后冒险」是软预算最优取点，而非对安全的妥协。

## 7. 本轮最大风险

**一句话**：TELL-RAS 的全部竞争收益押在「对对手策略与泄漏的估计可信」这一前提上——**若对手更高阶（利用你的 IDP 随机化、或反向操纵你「以为安全」的泄漏估计），你会在自以为藏住底牌时把最致命的 tell 精确亮给一个正在读你的对手；泄漏估计器本身成了最危险的攻击面，系统会带着「已验证隐私」的证书自信地输掉比赛。**

**次级风险与缓解**：记分锚被污染（完整性检查 + 降级 `anchored=false`）；U_sem 误当 U_epi（三分解隔离 + 分布化损失 + E308）；表达不透明削弱社交可读性（社交约束硬下限 + E310/E314）；REA 选择熵耗尽预算（选择熵入净 VoI + E304/E299 联合寻优）；竞争胃口侵蚀安全边际（`λ_soft` 夹紧 + `Δ_max` + E311 零越界门禁）。
