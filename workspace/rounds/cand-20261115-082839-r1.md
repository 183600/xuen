# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「演示数据」×「场景落地」）

> R69 交付了迄今最完整的一层：把不确定性一分为二，aleatoric 交给保守铁律，epistemic 交给「流匹配多模态策略 + 主动交互」。但它建立在一个**从未被追问的公理**上：*流策略的模态分布是可信的、策略在当场是胜任的*。R69 自陈的最大风险正是「模态分布不可信 → 问错比不问更危险」。这个风险在 R69 内部无法解决，因为它是**输入层**的问题——可信从哪来、可信到哪为止。
>
> 本轮两个灵感正好从根上补：
> - **演示数据**回答「可信从哪来」：策略的每一种能力都能在演示语料里找到出生证明；而人类演示者在犹豫、凑近、开口、伸手时，已顺手把「如何消歧」写进轨迹，这正是 R69 缺的 VoI 与成本先验。
> - **场景落地**回答「可信到哪为止」：把「能力边界」从一句声明做成一个可运行、可认证、可回退的**门**——域内自治、边界保守、域外请求示范或交还给人。
>
> 核心命题：**自治权不是系统级属性，而是场景级属性。演示数据定义能力域的支撑集，分层保形统计把支撑集收紧成可证明的能力域 C_δ，运行时门控只允许在 C_δ 内自治、在边界降级、在域外请求演示。** 命名 **DEMARC-RAS**（DEMonstration-derived Autonomy Region Certification）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量准吗」，R69 问「向谁求证」，R70 问「**我凭什么在这里自治、离开演示过的地方我还能不能做**」——把「不知道」最终落成一个可执行的动作：**降级、请求示范、或交还给人**。

## 0. 直觉与动机

**灵感 1（演示数据是「能力的出生证明」，不是普通训练集）**
直觉：前几轮都在问「策略运行时该怎么做」，却从没问「凭什么相信这个策略在**这个场景**会做」。答案不在模型里，在数据里：一个策略只有在它被演示过的场景族附近，才有资格自治。演示数据不是燃料，而是**许可证**。把「数据量→性能」的直觉换成「数据覆盖→可自治范围」的直觉，是本轮的第一个转向。

**灵感 2（演示数据里藏着「人类如何消歧」的答案）**
直觉：R69 的 MINT 要算 VoI、要估成本，可这些先验从哪来？人类演示者在犹豫、凑近看、开口问、伸手试时，已经把「什么算歧义、歧义值不值得查、查要花多少」写进了轨迹。演示数据因此不只是 `(o,a)`，而是 `(o, 歧义, 信息动作, 消解)`。**R69 问「我该向谁求证」，R70 回答：先看看人类在同类场景里是怎么问的。** 这让 R69 的 VoI 不再依赖一个凭空的均匀先验。

**灵感 3（场景落地 = 把「能力边界」做成可运行的门）**
直觉：落地不是把模型部署上去，而是明确「在哪可以、在哪不可以」并在运行时执行它。演示数据划出支撑集，保形统计给出能力域，门控在边界处降级、请求演示或交人。「场景落地」的字面意思就是：**场景一个个被认证，而不是系统整体被认证**——一张覆盖 99% 场景的证书，对第 100 个场景毫无保证。

**灵感 4（数据飞轮是双刃剑：落地生产演示，也会污染演示）**
直觉：部署中的接管与修正免费产生新演示，这是落地最大的红利。但若不加甄别地把现场数据喂回训练，策略会用自己的判断确认自己（自我确认偏差），能力域被「证明」得越来越大——这正是 R69 风险（模态幻觉）在数据层的镜像：**不是模型幻觉出一个模态，而是数据幻觉出一片能力**。所以必须把「数据准入」当成与「动作认证」同级别的安全机制。

**灵感 5（演示只展示对，不展示错——负例缺口）**
直觉：演示是「示范」而不是「反例」，人不会演示「如何失败」。于是策略学到的是成功流形，却不知道失败边界在哪。落地必须补这一课：近失挖掘、反事实好演示、安全事件回放，把「错在哪」变成可学习的负例。这也解释了为什么纯自博弈数据永远替代不了真实演示。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（DEMARC-RAS 总览）** DEMARC-RAS = (DDL, CRE, SGA, SLG, DPC, HAND, FLUID-RAS†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **演示数据只读准入**：部署时策略权重冻结，现场数据不得在线写入训练；只有经 DPC 认证的演示才进入下一版本 DDL（离线、版本化、可回滚）；
(iii) **能力域优先**：自治仅在经认证的能力域 C_δ 内启用；域外必须降级、请求演示或交人，不得「越界自治」。

**定义 311（演示语料库 DDL）** D = {(o_i, ξ_i, τ_i, y_i, μ_i)}_{i=1}^N，其中 o_i 观测/场景上下文，ξ_i 为 R69 的增广演示轨迹（含信息动作 g），τ_i 为场景标签，y_i 为结果/成败/安全事件，μ_i 为演示者元数据（身份、技能后验、时间、来源签名）。每条记录含内容哈希与父哈希，构成**只追加、不可抵赖**的账本。

**定义 312（场景嵌入与场景本体）** 场景嵌入 φ(s) = (φ_obs, φ_task, φ_inter, φ_ctx) ∈ ℝ^d，分别编码观测构型、任务意图、交互历史、上下文（天气/人流/时段）。场景本体 Ω = {τ} 分层（ODD → 场景类 → 参数族），τ : S → Ω。部署分布 p_dep 未知，与演示分布 p_demo 的关系是核心未知量。

**定义 313（演示诱导支撑集与支撑距离）** 支撑集 S_demo = {s : p̂_demo(φ(s)) ≥ ε_s}，p̂_demo 为演示场景密度的核/流估计。**支撑距离** d_sup(s) = −log p̂_demo(φ(s))，越小越像演示过的场景。

**定义 314（能力域 CRE）** 给定风险预算 ρ 与置信 δ，能力域 C_δ = {s : R(s) ≤ ρ 以概率 ≥ 1−δ}，R(s) 为策略在场景 s 的期望风险（任务 + 安全）。由**场景分层保形风险控制**（定义 323）估计。**关键：C_δ ⊆ S_demo 一般不成立**——覆盖 ≠ 能力（引理 19）。

**定义 315（能力域门控 SGA）** 运行时给出门控等级 ℓ(s) ∈ {AUTONOMY, CONSERVATIVE, REQUEST_DEMO, HANDOVER}：
- AUTONOMY：d_sup(s) ≤ d_in 且 s ∈ C_δ；
- CONSERVATIVE：边界带 d_in < d_sup(s) ≤ d_out，退回 R68 最保守并显著减速；
- REQUEST_DEMO：OOD，但可经短时演示解决（人在回路/遥操作采一条 demo）；
- HANDOVER：完全域外，或演示亦无济于事（能力缺口），交还给人。
门控**前缀单调**：等级只能由自治降向保守，不得跳升（防边界抖动），与 R68 换装不变式一致。

**定义 316（演示优先级采样 DPS）** 部署中按「能力缺口 × 信息价值」决定去哪采演示：priority(s) = P(s ∉ C_δ) · VoI_demo(s)，其中 VoI_demo 为该演示对收缩 C_δ 边界的期望信息增益（如对最不确定场景类的熵减）。把主动学习与 R69 的 VoI 交互统一：**交互是问世界，采演示是问老师**。

**定义 317（近失演示挖掘 NMD）** 从安全事件/接管/惊险样本构造「反事实好演示」：在状态 s 处请专家或仿真最优控制器给出 ξ*，与现场 ξ_obs 对比得 Δξ = ξ* − ξ_obs。NMD 提供演示数据天然缺失的**负例与纠错**信号（演示只展示「对」，不展示「错在哪」）。

**定义 318（演示来源与策展 DPC）** 准入规则 admit(d) = 来源可信 ∧ 场景标签一致 ∧ 质量分 ≥ q_min ∧ 非重复 ∧ 未投毒 ∧ 独立验证通过。deploy 期数据默认进审计队列（不进训练）；只有通过 DPC 的才进下一版 DDL。威胁：恶意/漂移演示诱导能力域虚假扩张。

**定义 319（场景库 SLG）** 部署场景库 L = {(τ_j, w_j, k_j)}，w_j 为部署权重估计，k_j 为覆盖/难度指标。三源合并：演示覆盖、场景本体采样、对抗与长尾生成。**场景覆盖率** cov(L) = Σ_j w_j·1[C_δ ∩ τ_j ≠ ∅]；**风险加权缺口** gap(L) = Σ_j w_j·R_j·1[τ_j ⊄ C_δ]。落地判据：cov ≥ cov_min 且 gap ≤ gap_max 方可放行。

**定义 320（能力域证书 J_DEMARC）** J_DEMARC = (J_FLUID, DDL_hash, C_δ, cov(L), gap(L), d_sup_p99, handover_rate, demo_provenance_root, demarc_ver)。Valid ⇔ Valid(J_FLUID) ∧ 门控生效 ∧ 场景库判据满足 ∧ 数据准入纪律满足。

**定义 321（域外演示请求协议 HAND）** 当 ℓ = REQUEST_DEMO：系统发出结构化请求（场景快照 + 失效模式 + 期望演示的子任务），人在时限内提供 demo 或拒绝；超时升级 HANDOVER。请求本身写入 DDL，形成「我为什么不知道」的可审计证据。

**定义 322（数据飞轮稳定性条件）** 设第 k 版策略由 D_k 训练，部署产生 D_k^field，经 DPC 准入得 D_{k+1} = D_k ∪ admit(D_k^field)。**自我确认偏差**：若 admit 只看「与当前策略一致」，则 D_{k+1} 向策略偏好坍缩，能力域虚假扩张。稳定条件：admit 必须含**独立于策略的验证源**（人类复核 / 仿真 oracle / 场景库 held-out），且每版至少保留 ε_hold 比例的「策略失败样本」。

**定义 323（分层保形能力域估计）** 对每个场景类 τ，取校准残差 {r_i}，C_δ^τ = {s ∈ τ : r(s) ≤ Q_{1−δ}(r | τ)}；跨类用 Bonferroni/BH 修正。类内交换性下，P(R(s) ≤ ρ for s ~ p_demo | τ) ≥ 1−δ。部署偏移破坏交换性 → 由在线变化检测（复用 R69 的 Δa 与场景级 d_sup 漂移）触发重校准，否则域外误判。

**定义 324（演示者偏差传播）** 若演示者策略 π_d 相对最优 π* 有 ε_d 次优，且其消歧行为含偏差 b_d（过度谨慎/抄近路），则蒸馏出的 FLUID 策略的 U_epi 先验与 MINT 成本先验继承 b_d。缓解：演示者技能分层加权 + NMD 反事实校正 + 多演示者交叉验证（对应 R69 的 k 正交一致）。

**定义 325（落地成熟度分级 LML）** 四级：L0 仿真（无演示，仅策略）；L1 影子（有人监督、不接管执行）；L2 受限自治（C_δ 内 AUTONOMY、域外接管）；L3 规模自治（飞轮稳定 + 场景库判据长期满足）。每级有准入门槛与证书要求，构成「场景落地」的可操作刻度。

**定义 326（场景落地差距分解）** 落地失败 F = F_support（域外）+ F_general（域内泛化）+ F_data（演示偏差/投毒）+ F_deploy（集成/时延/接口）+ F_ops（人机/流程）。落地工程必须逐项度量，而非一个总 accuracy。

**定义 327（演示-部署对偶）** 演示是「过去的部署」，部署是「未来的演示」。部署中频繁接管/修正，说明能力域估计与真实能力不符；接管本身是**免费标签**（人在此不信任系统）。用接管率作为能力域边界的在线校准信号（引理 23）。

**定义 328（交互与请求的成本统一）** 把 R69 的 MINT 信息动作成本 c(g) 与 R70 的演示请求成本 c_demo 统一为「问世界」的总成本；将「问自己（内省/多采样）」「问环境（看/触）」「问人（问句/演示）」放进同一 VoI−成本 框架排序。R69 = 「不请求演示」的边界。

# IP-264 DDL：演示账本与场景标注（只追加、内容哈希）
class DemonstrationLedger:
    def __init__(self): self.records = []
    def add(self, o, xi, tau, y, mu):
        rec = dict(o=o, xi=xi, tau=tau, y=y, mu=mu,
                   hash=sha256((o, xi, tau, y, mu)), parent=self.root())
        self.records.append(rec)                 # 不可改、不可删
    def admit(self, rec, dpc, verifier):         # 部署期数据默认不进训练
        return dpc.validate(rec, verifier)       # 必须含独立验证源

# IP-265 CRE：场景分层保形能力域（离线、版本发布）
def estimate_competence(D, policy, alpha=0.05):
    C = {}
    for tau, ds in group_by_scenario(D).items():          # 按场景类分层
        r = quantile([residual(policy, d) for d in ds],
                     1 - alpha / max(1, len(groups)))
        C[tau] = (r, support_radius(ds))                  # 风险分位 + 支撑半径
    return C

# IP-266 SGA：运行时能力域门控（前缀单调）
def gate(s, C, phi, p_demo, cfg):
    d, tau = -log_density(p_demo, phi(s)), classify_scenario(s)
    if tau in C and d <= cfg.d_in and risk(C[tau], s) <= cfg.rho:
        return 'AUTONOMY'
    if tau in C and d <= cfg.d_out:
        return 'CONSERVATIVE'                             # 回 R68 最保守
    if solvable_by_demo(s, tau, C):
        return 'REQUEST_DEMO'
    return 'HANDOVER'
    # 等级只能降不能跳升；与 R68 换装不变式一致

# IP-267 DPS：演示优先级采样（能力缺口 × 信息价值）
def pick_demo_targets(pending, C, B):
    return sorted(pending, key=lambda s:
        (1 - membership(C, s)) * voi_demo(s, C))[:B]

# IP-268 NMD：近失反事实演示
def mine_near_miss(events, expert):
    out = []
    for e in events:                                  # 接管/惊险/安全事件
        xi_star = expert.counterfactual(e.s)          # 专家或仿真最优
        out.append((e.s, xi_star, e.xi_obs, xi_star - e.xi_obs))
    return out

# IP-269 DPC：准入与投毒防御
def validate(rec, verifier):
    if not verify_provenance(rec): return False
    if not labels_consistent(rec): return False
    if rec.quality < Q_MIN or is_duplicate(rec): return False
    ok, _ = verifier.check(rec)                       # 独立于当前策略
    return ok                                         # 无独立源 → 只进审计队列

# IP-270 HAND：结构化域外演示请求
def request_demo(s, failure_mode, budget):
    req = dict(snapshot=s, mode=failure_mode, subtask=estimate_subtask(s))
    return send_human(req, timeout=budget.t_demo)     # 超时 → HANDOVER

# IP-275 主循环：FLUID 域内自治 + 能力域门控（先问「我在哪」）
def DEMARC_RAS_round(M, obs):
    s    = scene(obs)
    lvl  = M.sga.gate(s, M.C, M.phi, M.p_demo, M.cfg) # 先判能力域
    if lvl == 'HANDOVER':
        return M.hand.over(obs)
    if lvl == 'REQUEST_DEMO':
        M.hand.request(s, M.fluid.last_failure)
        return M.hand.over(obs)
    lam_gate = M.cfg.lam_out if lvl == 'CONSERVATIVE' else 1.0
    k, lam, mode, U = M.fluid.round(obs)              # R69 闭环（域内）
    return k, max(lam, lam_gate), mode, U             # 门控只收紧，不放宽

## 3. 推导

**引理 19（覆盖 ≠ 能力）** 演示覆盖某场景类 τ，不代表策略在 τ 上胜任。设类内泛化误差上界为 g(|D_τ|, d_φ)，则能力域与支撑集之差由 τ 内有效多样性 n_eff 与场景嵌入维度 d_φ 控制：C_δ ∩ τ ⊆ S_demo ∩ τ 一般不反向成立；当 n_eff → 0（同类演示高度重复）时，即使覆盖率为 1，能力域可退化为空。**系：演示数据的价值不在条数，在场景的有效多样性。**

**引理 20（能力域风险上界）** 若门控对 s ∉ C_δ 至少降级到 CONSERVATIVE/HANDOVER，则部署期望风险 R_dep ≤ ρ + P(s ∉ C_δ)·R_fallback + P(门控误判)·R_miss。要点：安全来自「降级」这一结构，而非「模型更准」；把门控去掉，再多数据也不能给出这个上界。

**引理 21（纯自博弈不可替代真实演示）** 自标注/自博弈数据无法产生 (i) 人类消歧先验与 (ii) 安全负例。缺真实演示时，U_epi 校准误差与 MINT 成本先验误差存在不由数据量消除的偏差下界 b_self（由人类行为多样性决定）。**系：R69 的 VoI 在无演示先验时只能退化为均匀先验，交互收益打折。**

**引理 22（飞轮单调性条件）** 若 DPC 含独立于当前策略的验证源，且每版至少保留 ε_hold 的「策略失败样本」，则能力域序列 {C_{δ,k}} 不发生自确认式虚假扩张；反之存在反例：全自标注准入使 C_{δ,k} 在有限步内膨胀到全域，而真实风险同步上升（数据层表征坍缩）。

**引理 23（演示-部署对偶的校准性）** 若接管只在真实越界时发生，则观测接管率 ĥ 是真实越界率 e 的无偏估计；若接管还因策略偏好/误报发生，则 ĥ = e + 误报率，偏差可由「接管后复核通过率」分离。**系：接管是免费标签，但必须先扣掉「人类过度接管」这一测量噪声。**

**定理 18（场景门控严格包含 FLUID-RAS）** 当 s ∈ C_δ 且 d_sup(s) ≤ d_in 时，DEMARC-RAS 逐指令退化为 FLUID-RAS（定义 315）；当 s ∉ C_δ 时，风险不高于「R68 最保守 + 接管/请求演示」的残余风险。故 FLUID-RAS = 「能力域 = 全域」的边界情形：安全侧不做任何让步，效率侧获得场景化自治。

**定理 19（分层保形 + 偏移检测的有效性）** 在场景类内交换性下，C_δ 对 p_demo 的覆盖概率 ≥ 1−δ；偏移检测（复用 R69 的 Δa 与场景级 d_sup 漂移）触发重校准时，部署风险超过 ρ + P(偏移未检出)·ΔR 的概率被二次压低。**要点：保形的保证是「有条件的」，条件被破坏时唯一诚实的做法是收紧门，而不是继续沿用旧 C_δ。**

**定理 20（落地成熟度单调准入与安全回退）** L0→L3 的准入门槛逐级加严（证书、覆盖、飞轮稳定性）；任意一级可回退到更低级，回退只收紧门控，故成熟度回退不增加风险；升级需同时满足能力域覆盖率与场景库 gap 判据，不得以「跑得久」代替「覆盖够」。

## 6. 本轮最大风险

**一句话**：DEMARC-RAS 的全部安全性押在「能力域估计 C_δ 是 sound 的」这一前提上——**若演示数据有偏、分层保形所依赖的类内交换性在真实部署中失效、而变化检测又没抓住，C_δ 就成了一张假证书：系统会在自己其实不胜任的场景里自信地宣称 AUTONOMY，门控从「安全闸」退化成「橡皮图章」——证错，比不证更危险；一次被洗白的越界自治，比一次诚实的拒绝部署代价高得多。**

**次级风险与缓解**：
1. **演示数据有偏/覆盖虚高**（重复演示刷覆盖）→ 引理 19 的有效多样性指标 + 引理 21 偏差下界 + E301/E306；
2. **类内交换性在部署中失效**（分布偏移）→ 定理 19 的偏移检测触发重校准；检测不到就收紧门，绝不复用旧 C_δ；
3. **数据飞轮自确认坍缩**（现场数据污染）→ 定义 322 的独立验证源 + ε_hold 失败样本保留 + 引理 22；
4. **演示投毒刷大能力域** → DPC 来源校验 + 多源交叉 + E308；
5. **保形估计样本不足/场景类过细** → 场景本体分层 + 跨类修正 + 稀疏类默认降为 HANDOVER；
6. **门控抖振**（边界反复越界）→ 前缀单调门控 + 迟滞带（d_in < d_out）。

class DemonstrationLedger:
    def add(self, o, xi, tau, y, mu):
        self.records.append(dict(o=o, xi=xi, tau=tau, y=y, mu=mu,
                                 hash=sha256((o, xi, tau, y, mu)),
                                 parent=self.root()))
    def admit(self, rec, dpc, verifier):

# IP-265 CRE：场景分层保形能力域（离线）
def estimate_competence(D, policy, alpha=0.05):
    C = {}
    for tau, ds in group_by_scenario(D).items():
        r = quantile([residual(policy, d) for d in ds],
                     1 - alpha / max(1, len(groups)))
        C[tau] = (r, support_radius(ds))
    return C

# IP-266 SGA：前缀单调门控
def gate(s, C, phi, p_demo, cfg):
    d, tau = -log_density(p_demo, phi(s)), classify_scenario(s)
    if tau in C and d <= cfg.d_in and risk(C[tau], s) <= cfg.rho:
        return 'AUTONOMY'
    if tau in C and d <= cfg.d_out:   return 'CONSERVATIVE'
    if solvable_by_demo(s, tau, C):   return 'REQUEST_DEMO'
    return 'HANDOVER'

# IP-269 DPC：准入与投毒防御
def validate(rec, verifier):
    if not verify_provenance(rec) or not labels_consistent(rec): return False
    if rec.quality < Q_MIN or is_duplicate(rec):                 return False
    ok, _ = verifier.check(rec)                                 # 独立于当前策略
    return ok

# IP-275 主循环：先问「我在哪」，域内 FLUID，域外请求/交人
def DEMARC_RAS_round(M, obs):
    s, lvl = scene(obs), None
    lvl = M.sga.gate(s, M.C, M.phi, M.p_demo, M.cfg)
    if lvl == 'HANDOVER':
        return M.hand.over(obs)
    if lvl == 'REQUEST_DEMO':
        M.hand.request(s, M.fluid.last_failure); return M.hand.over(obs)
    lam_gate = M.cfg.lam_out if lvl == 'CONSERVATIVE' else 1.0
    k, lam, mode, U = M.fluid.round(obs)             # R69 闭环
    return k, max(lam, lam_gate), mode, U            # 门控只收紧，不放宽

## 4. 推导

**引理 19（覆盖 ≠ 能力）** 演示覆盖某场景类不等于策略胜任。设类内泛化误差上界 g(|D_τ|, d_φ)，则 `C_δ∩τ ⊆ S_demo∩τ` 一般不反；有效多样性 n_eff → 0 时，覆盖率 1 也可能能力域为空。系：演示价值在有效多样性而非条数。

**引理 20（能力域风险上界）** 门控对 `s∉C_δ` 至少降级时，`R_dep ≤ ρ + P(s∉C_δ)·R_fallback + P(误判)·R_miss`。安全来自「降级」结构，而非模型更准。

**引理 21（纯自博弈不可替代真实演示）** 自标注/自博弈无法产生人类消歧先验与安全负例，U_epi 校准与 MINT 成本先验存在不由数据量消除的偏差下界 b_self。系：无演示先验时 R69 的 VoI 退化为均匀先验。

**引理 22（飞轮单调性条件）** 准入含独立验证源且每版保留 ε_hold 失败样本时，{C_{δ,k}} 不自确认式虚假扩张；反之存在有限步膨胀到全域而真实风险同步上升的反例（数据层表征坍缩）。

**引理 23（演示-部署对偶校准性）** 接管只在真越界时发生则 ĥ 无偏；否则 ĥ = e + 误报率，可由「接管后复核通过率」分离。系：接管是免费标签，但须扣掉过度接管噪声。

**定理 18（场景门控严格包含 FLUID-RAS）** `s∈C_δ ∧ d_sup≤d_in` 时逐指令退化为 FLUID-RAS；`s∉C_δ` 时风险不高于「R68 最保守 + 接管/请求演示」。FLUID-RAS = 「能力域 = 全域」边界，安全不让步，效率获场景化自治。

**定理 19（分层保形 + 偏移检测有效性）** 类内交换性下覆盖 ≥ 1−δ；偏移检测触发重校准时，风险超过 `ρ + P(偏移未检出)·ΔR` 的概率被二次压低。保形保证是「有条件」的，条件破坏时应收紧门而非沿用旧 C_δ。

**定理 20（成熟度单调准入与安全回退）** L0→L3 门槛逐级加严；任意级可回退且回退只收紧门控，故回退不增风险；升级需同时满足覆盖与 gap，不得以「跑得久」代替「覆盖够」。

## 7. 本轮最大风险

**一句话**：DEMARC-RAS 的全部安全性押在「能力域估计 C_δ 是 sound 的」这一前提上——**若演示数据有偏、分层保形依赖的类内交换性在真实部署中失效、而变化检测又没抓住，C_δ 就成了一张假证书：系统会在其实不胜任的场景里自信宣称 AUTONOMY，门控从「安全闸」退化成「橡皮图章」——证错，比不证更危险；一次被洗白的越界自治，比一次诚实的拒绝部署代价高得多。**

**次级风险与缓解**：演示覆盖虚高（引理 19 有效多样性 + 引理 21 偏差下界 + E301/E306）；类内交换性失效（定理 19 偏移检测 + 检测不到即收紧门）；飞轮自确认坍缩（定义 322 独立验证源 + ε_hold + 引理 22）；演示投毒（DPC 来源校验 + 多源交叉 + E308）；保形样本不足/场景类过细（分层 + 跨类修正 + 稀疏类默认 HANDOVER）；门控抖振（前缀单调 + 迟滞带 d_in < d_out）。
