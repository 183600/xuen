# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新一轮第 1 轮；本轮灵感：「技能组合」×「迁移学习」）

> R69 把不确定性一分为二，并教会系统「去问」。但它默认了一件从未被追问的事：**这个会问的系统是一个「单一策略」**——它在一个任务、一套标定、一个域里，用同一个流模型生成动作与问句。真实的具身系统不是这样长大的：它靠**技能的组合**完成任务（抓取 → 搬运 → 递交），靠**迁移**把旧技能带到新本体、新环境。而这两件事都会悄悄拆掉 R69 的地基：组合会在技能接口处产生任何单个技能都没有的**涌现歧义**；迁移会把一个「只在源域成立」的证书**原样搬到目标域**，而证书从来不是无条件真理。
>
> 于是本轮的问题不是「怎么问」，而是：**我的能力由什么拼成？拼起来还安全吗？换个地方还作数吗？**
>
> 核心命题：**能力应被表示为一个「带契约与证书的技能库」；组合是受证明义务约束的代数运算，迁移是证书的「再认证」而非复制；只有当组合/迁移后的复合体能出示可组合、可迁移的证书时才允许执行，否则退化为已验证的最大安全子集。** 命名 **CRAFT-RAS**（Contract-algebra, Reuse And Fault-tolerant Transfer for Risk-Adaptive Skill composition）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的本事从哪来、怎么拼、换个地方还灵不灵**」——安全不只是把动作收小，也是把能力的来源与适用范围说清楚。

## 0. 直觉与动机

**灵感 1（技能组合 → 安全要「可组合」，而不是「可希望」）**
直觉：如果我们相信「每个技能都安全，所以拼起来也安全」，那便重演了安全领域最经典的错误——局部正确不等于整体正确。两个各自安全的技能，在共享同一执行器 / 同一感知通道 / 同一时间窗时，可能互相破坏对方的假设（一个技能假设「手是空的」，另一个正在占用；一个要求低延迟视觉，另一个占满带宽）。真正让工程可组合的不是信心，而是**契约**：每个技能声明前置条件、后置条件、执行期间不变式、资源签名与**适用域**；组合只在契约能「接上」（Post₁ ⊆ Pre₂）、不变式相容、资源不冲突时才被允许。组合的合法性因此变成一个**可检查的证明义务**，而不是一句祈祷。

**灵感 2（迁移学习 → 证书不会免费旅行）**
直觉：迁移学习文献几乎都在问「准确率能不能搬过去」；但对安全闭环，真正要问的是「**证书能不能搬过去**」。R68/R69 的证书都是带条件的：「在标定有效的域内、在模态校准 ECE ≤ τ 时，风险 ≤ ρ」。换一个本体/环境，条件变了，证书要么重新推导，要么失效。更隐蔽的是**负迁移**：源域的强先验可能在新域里是错的，而且错得很自信——这正是 R69 最大风险（在错误信念上自信行动）的迁移版。所以迁移必须以「证书再认证 + 证据预算」的形式进行：搬什么（结构/尺度/语义三层可迁移性不同）、要多少目标域证据才能恢复证书、恢复不了就拒绝。

**灵感 3（组合会产生新的不确定性 → U_comp）**
直觉：R69 的 U_epi 度量的是「单个策略内部的多模态歧义」。但两个技能拼在一起时，会出现一种**只在接口处存在**的歧义：A 技能的动作模态选择会改变 B 技能看到的初始条件，B 的模态又反过来影响 A 的可行性。这种耦合产生的不确定性不属于任何组件，却在复合体里真实存在。若直接继承组件证书，系统会对这种涌现歧义**完全无感**。所以必须显式定义**组合残差不确定性 U_comp**，并规定：U_comp 超阈值 ⇒ 复合体不得继承组件证书，必须整体再审计。

**灵感 4（组合/迁移本身就是一次 VoI 决策 → 复用 R69 的 MINT）**
直觉：R70 看起来是给 R69 加一层「能力管理」，容易变成并列的第二个黑箱。但有一个漂亮的收敛点：**「选哪个技能来拼」「要不要迁移这个技能」「花多少目标域样本去恢复证书」本质上都是信息动作选择**——它们和 R69 的「看/问/触」是同一个 value-of-information 问题，只是动作空间从「物理探询」扩展到「能力探询」。于是 R70 不需要新造一个决策器，而是把 R69 的 MINT 提升为**能力层的 VoI 分配器**：组合与迁移的收益 = 认证能力前沿的扩张，成本 = 证明义务 + 目标域证据 + 运行时风险。这样 R70 与 R69 是同一套信息经济学，而不是两层各自为政的保守主义。

**灵感 5（技能库是一条供应链 → 来源与签名）**
直觉：一旦能力可以「从库里取」，库本身就成了攻击面。一个被投毒的技能可以携带一份**伪造的契约**——它声明「我只在安全状态被调用」，实际却在边界状态放大动作。R69 担心的是「问错」，R70 要担心的是「**用错**」：用了一个来源不可信、契约未经审计的技能。因此技能库必须带**来源证明（provenance）与签名**，契约必须可被独立审计；否则组合代数越严谨，越是在为一个来路不明的组件提供「形式上的合法性」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CRAFT-RAS 总览）** CRAFT-RAS = (SL, CCL, CAL, GRL, XFR, SRC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **契约先行**：任何技能进入执行前，其契约必须已通过 CCL 编译并被 GRL 记账；运行时先检查 Pre/Inv，再放行；
(iii) **证书不免费旅行**：跨域使用前必须满足定义 319 的失效界，或完成定义 320 的再认证；否则证书视为**未签发**；
(iv) **保守退化**：组合/迁移/契约任一证明义务失败，退化为「已验证的最大子技能集」，且退化路径 λ 单调不降（继承 R69 定义 307）。

**定义 311（技能与契约）** 技能 s = (π_s, C_s, Dom_s, J_s, prov_s)。π_s 为（可为 R69 FLUID 的）策略；契约 C_s = (Pre_s, Post_s, Inv_s, R_s)，其中 Pre_s/Post_s ⊆ 𝒮 为执行前后状态集合（随机版为分布约束）、Inv_s 为执行期间不变式、R_s 为资源占用签名（执行器/感知通道/时间窗）。Dom_s ⊆ 𝒟 为**适用域**（本体参数、环境分布、传感器配置）；J_s 为 R68/R69 证书；prov_s 为来源签名。

**定义 312（证书与鲁棒裕度）** 证书 J_s = (J_s^0, ρ_s, ECE_s, d_s^max, ver)，J_s^0 为底层（R68/R69）证书，ρ_s 为认证风险上界，ECE_s 为模态校准误差，d_s^max 为**证书仍有效所允许的最大域偏移**。J_s 只对 Dom_s 内满足 d(·, Dom_s) ≤ d_s^max 的上下文成立。

**定义 313（技能库与来源）** 技能库 SL = {(s_i, prov_i)}_{i=1}^n，prov_i 为训练数据哈希 + 训练配置 + 签名链。库操作只读；写入技能需签名 + 审计（对应 R68 零学习写操作的「能力层版本」）。

**定义 314（组合算子）** 组合代数 CAL 提供：
- 顺序 `s₁ ; s₂`；
- 并行 `s₁ ‖ s₂`（共享执行器/感知时必须有仲裁器 Arb）；
- 条件 `if φ then s₁ else s₂`；
- 回路 `repeat s until ψ`（需良基测度）；
- 包裹 `sup(s)`（外层监督器，用于降级/混合）。
每个算子返回复合技能 s_comp = (π_comp, C_comp, Dom_comp, J_comp, prov_comp)，其中 Dom_comp = Dom₁ ∩ Dom₂ ∩ Dom_interface。

**定义 315（组合证明义务 PO）**
- 顺序：`PO_seq = {Post₁ ⊆ Pre₂（或 P(Post₁ ⊆ Pre₂) ≥ 1−δ₁₂）, Inv₁ ∧ Inv₂ ∧ Inv₁₂ 可满足}`；
- 并行：`PO_par = {R₁ ∩ R₂ = ∅, Inv₁ ∧ Inv₂ 可满足, 控制权仲裁无冲突}`；
- 条件：`PO_cond = {guard ⊆ Pre₁ ∩ Pre₂, Post₁ ∪ Post₂ ⊆ Post_comp}`；
- 回路：`PO_loop = {Inv 在每轮保持, 测度严格下降, 终止概率 1}`。
`PO(comp)` 为全部义务之并。**组合合法 ⇔ 全部 PO 被判定为真**。

**定义 316（复合证书与保证账本 GRL）** 若 PO(comp) 全部通过，J_comp = Join(J₁, J₂, R_iface)，其中 R_iface 为接口风险项（定义 315 的 δ 项，见引理 19）。GRL 记录：用了哪些技能、discharged 了哪些 PO、每条 PO 的证据来源、组合风险上界。**没有 GRL 条目的复合体，一律视为未认证。**

**定义 317（组合残差不确定性）** 设组件在共享上下文 h 上的模态身份为 M₁,…,M_n。U_comp = I(M₁,…,M_n ; h | o) − Σ_i I(M_i ; h | o)，即在给定观测下，**由共享接口变量耦合产生的、组件内部解释不了的**互信息。U_comp > τ_comp ⇒ 复合体不得继承组件证书（必须整体再审计或加监督器）。

**定义 318（迁移算子与可迁移性分层）** 迁移 T = (A, Δ)：A 为适配（参数/输入/输出重映射），Δ 为声称的域偏移预算。技能成分按可迁移性分三层：
- κ_struct（结构/动力学不变量，如刚体约束、守恒律）——可带界迁移；
- κ_scale（标定增益、阈值、单位）——迁移后必须重估；
- κ_sem（语义接地：语言/情绪/物体类别）——**默认不可迁移**，必须有目标域证据。
T 只允许搬 κ_struct 与（重估后的）κ_scale；κ_sem 必须重新用目标域证据认证。

**定义 319（证书失效界）** 设风险泛函在上下文度量 d 下 Lipschitz 常数 L_f。则对任意目标域 P_tgt：
`|R_tgt(s) − R_src(s)| ≤ L_f · d(P_src, P_tgt) + ε_est`。
证书在目标域**仍有效** ⇔ `ρ_s ≥ L_f · d(P_src, P_tgt) + ε_est`。否则证书未签发，必须走定义 320。校准同理：`ECE_tgt ≤ ECE_src + L_cal·d + ε_est`；若 `ECE_tgt > τ_ece`，R69 的 MCG 直接触发纯保守。

**定义 320（证据预算与再认证）** 再认证是购买证据的过程：抽取 n 个目标域样本，得到证书的新估计。证据预算 EBA 解 `max_T [ΔFrontier(T) − c_evidence(n) − risk_transfer(T)]`，s.t. `J_reissued 有效`。预算不足或再认证失败 ⇒ **不迁移**（保留源域证书，但禁止在目标域使用该技能）。

**定义 321（负迁移拒绝）** 设 LB_tgt(·) 为目标域上可验证的性能下界，s₀ 为目标域原生（可弱但已认证）基线。接受迁移 ⇔ `LB_tgt(T(s)) ≥ LB_tgt(s₀)`。拒绝只损失「正的迁移机会」，不损失安全；这与 R69「VoI−c ≤ 0 则不交互」同构。

**定义 322（认证能力前沿与技能路由）** 认证能力前沿 F = { (task, risk_bound) : ∃ 合法组合或迁移使 task 可被认证 }。SRC 在运行时从「单技能」与「已认证复合体」中选风险最小者；**前沿之外的 task 不得由未认证技能执行**，只能请求交互（R69 MINT）或降级。

**定义 323（契约编译 CCL）** 从演示/回放中挖掘 Pre/Post/Inv：用**保形预测（conformal）**给每条谓词一个有限样本覆盖保证 `P(Post 成立) ≥ 1−α`；契约不是「学出来的最优描述」，而是「统计上可辩护的保守外包络」。契约只许**收紧**，不许为了通过组合而放宽。

**定义 324（能力层 VoI）** 复用 R69 定义 298：候选能力动作 g_cap ∈ {组合 s_i;s_j, 迁移 s_i, 采 n 个目标样本}；`VoI_cap(g) = H(cert 有效 | o) − E[H(cert 有效 | o, y)]`。选择 `argmax [VoI_cap − c]`；无利可图 ⇒ 不组合/不迁移/不采集。

**定义 325（参与式审计 VQAuditor-X）** 审计对象新增：契约是否被运行时检查、PO 是否真的被 discharged（而非跳过）、迁移证据是否来自目标域、技能来源是否可信、U_comp 是否被计入。结论回灌 GRL 与 AuditBuf，成为下一轮 EBA 的成本先验。

**定义 326（威胁模型 AIC-CRAFT 与证书 J_CRAFT）** ℰ_CRAFT = ℰ_FLUID × ℰ_supply（投毒技能 / 伪造契约 / 伪造签名）× ℰ_compose（接口冲突 / 资源竞争 / 组合爆炸）× ℰ_transfer（负迁移 / 域偏移超界 / 目标域投毒）。J_CRAFT = (J_FLUID, PO_hash, GRL_hash, U_comp, d_domain, transfer_evidence_hash, provenance_chain, craft_ver)。Valid ⇔ J_FLUID 有效 ∧ PO 全 discharged ∧ U_comp ≤ τ_comp ∧ 证书在目标域有效（定义 319）∧ 来源链可验。

# IP-264 技能与契约
@dataclass
class Skill:
    policy: Callable            # 可为 R69 FlowMatchingPolicy
    contract: Contract          # Pre / Post / Inv / R
    domain: DomainSpec
    cert: Certificate           # J_FLUID + ρ + ECE + d_max
    provenance: Provenance
    uncertainty: UncertaintyProfile

# IP-265 CCL：保形契约编译（只收紧，不放宽）
def compile_contract(rollouts, alpha=0.05):
    pre  = conformal_envelope([r.s0 for r in rollouts], alpha)      # P(Pre) >= 1-alpha
    post = conformal_envelope([r.sT for r in rollouts], alpha)
    inv  = conformal_invariant([r.trace for r in rollouts], alpha)
    return Contract(pre, post, inv, resource_signature(rollouts))

# IP-266 CAL：受证明义务约束的组合
def compose_seq(s1, s2):
    po = [implies(s1.post, s2.pre), satisfiable(s1.inv & s2.inv & iface_inv(s1, s2))]
    if not all(check_po(o, witness_db) for o in po):
        return Uncertified("PO failed")                 # 不执行，不继承证书
    u_comp = estimate_Ucomp(s1, s2)                      # 定义 317
    cert = join_certs(s1.cert, s2.cert, R_iface=interface_risk(s1, s2))
    if u_comp > TAU_COMP:
        cert = cert.require_reaudit()                    # 复合体须整体再审计
    return CompositeSkill([s1, s2], po, cert, u_comp, GRL.append(...))

def compose_par(s1, s2):
    if s1.contract.R & s2.contract.R: return Uncertified("resource conflict")
    if not satisfiable(s1.contract.inv & s2.contract.inv): return Uncertified("inv conflict")
    return CompositeSkill([s1, s2], arb=Arbiter(s1, s2), ...)

# IP-269 XFR：迁移 = 证书再认证
def transfer(s, src, tgt, budget):
    d = domain_divergence(src, tgt)
    if not cert_survives(s.cert, d):                    # 定义 319
        n = budget.min_samples_for(s, d)
        if not budget.affords(n): return None           # 不迁移（但也不在 tgt 使用）
        s = reaudit(s, tgt, samples=budget.draw(n))     # 定义 320
    if lower_bound(tgt, s) < lower_bound(tgt, native_baseline(tgt)):
        return native_baseline(tgt)                     # 负迁移拒绝，定义 321
    return s

# IP-275 主闭环（继承 R69；能力层与风险层解耦）
def CRAFT_round(M, obs, task):
    # 1) 只在认证前沿内搜索组合
    plan = M.src.propose(task, M.library, M.grl)
    if plan is None:
        return M.fluid_round(obs)                       # 退化为 R69（单技能/交互）
    # 2) 契约运行时检查（定义 310-ii）
    if not (M.monitor.check_pre(plan, obs) and M.monitor.check_inv(plan, obs)):
        return M.src.fallback(task, M.library)          # 最大已验证子集
    # 3) 组合残差监控：U_comp + 复合轨迹 FMA
    u_comp = estimate_Ucomp_live(plan, obs)
    a_comp = M.fma.flow_anomaly(plan.policy, M.last_action, obs, obs_cal)
    out_of_contract = (u_comp > TAU_COMP) or (a_comp > TAU_FMA)
    # 4) 执行 + 单调降级
    k, lam, mode, u = M.fluid_round(obs)                # 内层仍用 FLUID
    if out_of_contract:
        plan = M.src.degrade(plan)                      # 换到更小的已验证子集
        lam  = max(lam, LAM_DEGRADE)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 5) 审计与证书
    M.vqa_x.submit_async(plan, u_comp, a_comp, M.grl.entry(plan))
    return k, lam, mode, M.grl.certify(plan)

## 3. 推导

**引理 19（契约组合的 assume-guarantee 风险界）** 设各技能在契约内失败概率 ≤ δ_i，接口义务失败概率 ≤ δ_ij。若 PO(comp) 全部 discharged，则复合体失败概率 ≤ Σ_i δ_i + Σ_{ij} δ_ij（联合界），期望风险 ≤ Σ_i R_i + R_iface。要点：组合给出的是**上界**，因此保守但可用；接口项 R_iface 是「局部正确、整体仍可能错」的显式代价，不允许被吸收进组件证书。

**引理 20（组合残差不可继承）** 若 U_comp > 0，则存在一个共享上下文 h，使各组件在其适用域内均为最优模态、复合体却选错模态。故 U_comp > τ_comp 时，组件证书的合取**不蕴含**复合体证书；必须整体再审计。系：组合不是「证书的加法」，而是「证书的重新推导」；U_comp 是这一事实的可计算代理量。

**引理 21（证书失效界与「不免费旅行」）** 由定义 319 与风险泛函的 L_f-Lipschitz 性立得 `|R_tgt − R_src| ≤ L_f d + ε_est`。系 1：源域证书裕度 ρ_s 必须覆盖域偏移，否则证书在目标域未签发。系 2：由于 ECE 同样受 L_cal d 影响，**接近校准门限的证书在迁移后几乎必然触发 MCG**，因此「迁移前先确认校准裕度」是必要步骤。

**引理 22（契约缺口可检测，但不可预防）** 若契约 C_s 对真实行为不 sound，违规集测度 ≥ ε_gap，则 R69 的复合轨迹似然 a_score 期望上升 ≥ g(ε_gap)，且契约监视器（Post 预测残差）以功效 ≥ 1−β 触发。要点：这保证「坏组合」最终会被发现，但**发现不等于没发生**——检测延迟内的风险仍由 R69 的 λ_floor 兜底。

**定理 18（CRAFT 严格包含 R69 ⊃ R68）** 当技能库只有一个技能、无组合、无迁移、且契约取平凡真（Pre/Post = 𝒮）时，CRAFT 逐指令退化为 FLUID-RAS；当进一步 VoI ≤ 成本时退化为 CALM-RAS。故 R68 ⊂ R69 ⊂ R70，安全侧不做让步，能力侧获得组合与迁移的扩张。

**定理 19（安全组合与单调迁移）** 在 A99–A103（契约 sound、域偏移界可证、证据预算经审计、U_comp 被计入）下，任一被执行的复合体要么 (i) PO 全 discharged 且持有 J_CRAFT，其风险 ≤ 认证上界；要么 (ii) 退化为已验证的最大子技能集。迁移只在前沿严格扩张时被接受；被拒迁移使前沿不变。退化路径 λ 单调不降、经监督器混合后控制连续（继承 R69 定理 17）。

**定理 20（能力前沿的可审计扩张）** 若每次组合/迁移都在 GRL 留下「PO + 证据 + 风险上界」的可验证记录，则认证能力前沿 F 的每一次扩张都可被独立复算；任何未记录在 GRL 的扩张均视为未发生。系：这把「系统变强了」从一句主张，变成一个可被第三方审计的账本增量。

## 6. 本轮最大风险

**一句话**：CRAFT-RAS 的全部「可组合、可迁移」承诺，押在「契约能忠实概括技能行为」这一前提上——**若契约不完备（contract gap：学到的策略在契约未覆盖的角落悄悄越界），assume-guarantee 组合给出的就是一个「形式合法、实质未认证」的复合体**；组合会把这个隐藏耦合放大成涌现故障，迁移再把一个只在源域成立的证书洗白成跨域通行证。此时 GRL 越完整，越像一份为未知风险出具的合规证明——**证书的组合，可能只是严谨的幻觉**。

## 4. 推导

**引理 19（契约组合的 assume-guarantee 风险界）** 各技能契约内失败 ≤ δ_i、接口失败 ≤ δ_ij，PO 全 discharged ⇒ 复合失败 ≤ `Σδ_i + Σδ_ij`，期望风险 ≤ `ΣR_i + R_iface`。接口项是「局部对、整体错」的显式代价，不得吸收进组件证书。

**引理 20（组合残差不可继承）** `U_comp>0` ⇒ 存在共享上下文 h，组件各自最优、复合体选错模态；故组件证书合取不蕴含复合证书，必须整体再审计。组合是「证书的重新推导」，`U_comp` 是其可计算代理量。

**引理 21（证书失效界）** `|R_tgt−R_src| ≤ L_f d + ε_est`；源域裕度 ρ_s 必须覆盖域偏移，否则证书在目标域未签发。ECE 同样受 `L_cal d` 影响 ⇒ 接近校准门限的证书迁移后几乎必然触发 MCG。

**引理 22（契约缺口可检测不可预防）** 非 sound 契约、违规测度 ≥ ε_gap ⇒ 复合轨迹 `a_score` 期望上升 ≥ g(ε_gap)，契约监视器功效 ≥ 1−β；但检测延迟内风险仍由 R69 的 `λ_floor` 兜底。

**定理 18（CRAFT ⊃ R69 ⊃ R68）** 单技能、无组合、无迁移、契约平凡真 ⇒ 逐指令退化为 FLUID-RAS；再令 `VoI≤成本` ⇒ 退化为 CALM-RAS。安全不让步，能力获前沿扩张。

**定理 19（安全组合与单调迁移）** A99–A103 下，执行体要么 PO 全 discharged 且持 J_CRAFT（风险 ≤ 认证上界），要么退化为最大已验证子集；迁移只在前沿严格扩张时被接受；退化 λ 单调不降、监督器混合后连续（继承 R69 定理 17）。

**定理 20（前沿可审计扩张）** 每次组合/迁移在 GRL 留「PO+证据+风险上界」记录 ⇒ 前沿每次扩张可被独立复算；未入账的扩张视为未发生。把「系统变强了」变成可第三方审计的账本增量。

## 7. 本轮最大风险

**一句话**：CRAFT-RAS 的全部「可组合、可迁移」承诺，押在「契约能忠实概括技能行为」这一前提上——**若契约不完备（contract gap：策略在契约未覆盖的角落悄悄越界），assume-guarantee 组合给出的就是一个「形式合法、实质未认证」的复合体**；组合把隐藏耦合放大成涌现故障，迁移再把只在源域成立的证书洗白成跨域通行证。此时 GRL 越完整，越像一份为未知风险出具的合规证明——**证书的组合，可能只是严谨的幻觉**。

**次级风险与缓解**：负迁移（定义 321 拒绝器 + 定义 319 失效界 + E305）；接口耦合/资源竞争漏算（U_comp + 资源签名 + 仲裁器）；供应链投毒/伪造契约（来源签名链 + VQAuditor-X + E312）；组合爆炸与实时预算（仅前沿内搜索 + 剪枝 + 缓存已认证复合体）；语义迁移幻觉（κ_sem 分层 + 强制目标域证据 + E305）。
