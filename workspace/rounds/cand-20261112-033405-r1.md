# 第 59 轮（承接第 58 轮「KG-SFT-UX」IP-139~144；新灵感循环第 1 轮；本轮灵感：「域随机化」×「运动规划」）

> 第 58 轮把安全论证压在结构化记忆 𝒢 上，也把最大风险暴露为 KG 共模失效：检索、OOD、微调、证据合成、心智预测共用一张图，一处结构性错误可同时污染五条通道。第 58 轮的风险自陈还留下两个更根本的口子：**(a) 所有"证据"最终都是在当前这一步上评估的**——检查点证据门可以每一步都过，却无法保证一段连续运动在模式转移、载荷变化与累计损伤下仍然安全；**(b) 所有"不确定性"最终都来自见过的世界**——KG 与共形带能说"我没见过"，却不能回答"如果现实落在训练分布之外，最坏会怎样、我还能走多远"。本轮两个灵感各补一端：**域随机化**把"世界可能是什么样"从隐式先验变成显式、可校准、可审计的分布；**运动规划**把"安全"从点证据变成带证书的轨迹与生存管道。合流后的核心命题是：**可校准的随机化 + 可携带证书的轨迹 + 可安全辨识的探索**——随机化不是安全证明，而是一张需要年检的"世界分布执照"；规划不是找一条能走的路，而是找一条带着证明与退路的路。

核心矛盾：
- **H29（覆盖 vs 现实）**：域随机化是"人选出来的世界分布"，覆盖更广不等于覆盖了现实；被排除在支持域外的恰恰可能是未知失效模式。更隐蔽的是循环论证——同一套仿真既生成随机化分布又验证其覆盖；而无关维度的噪声还会把真正的系统性失效"平均掉"。
- **H30（点证据 vs 轨迹）**：检查点级证据的局部健全性不能自动组合成轨迹级安全性；接触模式转移、累计塑性/压痕、信念随观测漂移，使"每一步都过"与"整段安全"之间存在组合鸿沟。逐点保守会锁死运动，逐点乐观会累积不可逆损伤。
- **H31（探索 vs 不可逆）**：主动辨识用运动换信息，但最有信息量的激励往往最接近失稳/滑移边界。禁止一切不可逆探索会让某些参数永远不可辨识；允许则可能用我们想避免的损伤去买信息。安全的赌注从"证据质量"进一步后移到"为了获得证据，我们愿意冒多大险"。

## 0. 直觉与动机

**灵感 1（域随机化 → 行为覆盖，而非参数覆盖）**
直觉：DR 常被当成"把摩擦、质量、延迟都抖一抖"的工程技巧，但安全论证需要的不是"抖过"，而是"抖到了现实"。参数空间里的均匀采样既不知道哪些参数真正影响任务，也无法证明现实系统落在支持域内。换一种问法：不承诺"我的 ξ 覆盖现实"，只承诺"在锚点动作库上，现实的行为签名落在随机化行为云的 α 分位邻域内"——覆盖从不可观测的参数空间搬到可观测的行为空间，才能被真实数据校准。再加一道因果掩码：只随机化对任务结果有因果路径的参数，别让无关噪声把真正的失效"平均掉"。

**灵感 2（运动规划 → 证书携带的轨迹与生存管道）**
直觉：安全不是某个状态点的属性，而是一条轨迹周围的"管子"。与其在检查点问"这一步能不能踩"，不如为整段运动算一条生存管道：在所有被接受的随机化世界与扰动下，状态始终留在不与危险集相交的集合序列里；一旦观测把管子打出界，立即执行预先证明过的回退，而不是现场重新规划。承诺也只承诺管子的第一段（滚动时域），后面保留为带分支的应急树。

**灵感 3（域随机化 × 运动规划 → 安全辨识运动）**
直觉：如果现实与随机化分布有差距，最好的修补不是盲目加大随机化，而是设计一段"既安全又能问出真相"的运动：慢速侧向激励测摩擦、轻载抬落测柔顺、受控滑移测粘滑边界。但信息有安全价格：最能有效辨识参数的动作，往往最接近不可逆边界。于是要把"可辨识"与"可安全激励"分开：只允许在生存核内、L1 非不可逆接触上做激励；对安全激励张成空间之外的方向，诚实地说"不可辨识"，而不是假装知道。

**灵感 4（合流 → 分布鲁棒与对抗随机化护栏）**
直觉：随机化分布本身可能错，而且规划器会学会利用仿真的伪影。两道护栏：一是把点分布换成 Wasserstein/KL 歧义集，证书要对整个邻域成立；二是留出随机化维度做"盲测"——用一部分维度规划、另一部分维度验收，若两者失效概率差距过大，就判定为仿真伪影/过拟合，拒绝该计划。对抗样本只在"合理世界"（似然下界内）里找，避免用不可能世界把系统吓成瘫痪。

**灵感 5（合流 → 轨迹级证据门与 DR-PCE）**
直觉：第 58 轮的六类证据门是检查点级的；本轮把证据单元升级为"段"与"轨迹"：EV-plan（轨迹证书）、EV-dr（行为覆盖）、EV-ident（安全辨识）、EV-fallback（回退可行性）。硬规则：EV-dr/EV-ident 永远不能单独授权不可逆接触；EV-plan 必须与力学探针/裕度证据合取；没有可行回退就不承诺。整个循环仍是探-诺-演，只是"探"可以是整段辨识运动，"诺"是第一段带管道的承诺，"演"是管道监控与回退。

## 1. 形式化定义（增量：定义 145–150）

**定义 145（行为等价与校准域随机化 CDR）** 随机化参数 ξ∈Ξ（摩擦、质量、延迟、柔顺、地形高度、传感偏置），随机化分布 p_ψ，支持域 Ξ_ψ。固定锚点动作库 𝒯_a={τ_1,…,τ_K}（可安全执行、可仿真复现的短动作），行为映射 h_ξ:𝒯_a→𝒴，𝒴 为行为签名空间（滑移率、力旋量残差、位姿误差、能耗、振动谱），度量 d。随机化行为云 ℬ_ψ={h_ξ(τ):ξ∈Ξ_ψ,τ∈𝒯_a}。真实锚点签名 D_a 分为校准集/测试集；非一致性分数 s(y)=min_{b∈ℬ_ψ}d(y,b)。取校准集分数的 (1−α_DR) 分位数 q_DR，定义覆盖事件 Cov_DR ⇔ s(h_{ξ*})≤q_DR，由 split conformal 在交换性假设下得 P(Cov_DR)≥1−α_DR。Cov_DR 失败 ⇒ DR-OOD，禁止签发 EV-plan。因果掩码 ℳ_c⊆Ξ：仅随机化经 KG 因果边可达任务签名的维度；其余维度固定或单独建模。歧义集 𝒫_DR={q:W_1(q,p_ψ)≤ε_DR}。世界分布执照 L_DR=(α_DR,ε_DR,ℳ_c,锚点覆盖审计,版本)。

**定义 146（证书携带运动规划 CCP 与生存管道）** 计划 π=(κ_t,u_t(·))_{t=0}^{H−1}，κ 为接触模式，u 为反馈控制器；初始信念 b_0 覆盖 (ξ,地形/接触)。给定覆盖集 C_DR={ξ:s(ξ)≤q_DR} 与扰动集 𝒲，生存管道是集合序列 {𝒮_t} 与反馈策略 π_fb，使得 𝒮_0={x_0}，∀t<H, ξ∈C_DR, w∈𝒲：f_ξ(𝒮_t,u_t,w)⊆𝒮_{t+1}，且 𝒮_t∩𝒳_bad=∅；执行时 π_fb 保证 x_t∈𝒮_t（barrier/contraction 条件）。机会约束 P_{ξ~p_ψ}(∃t:x_t∉𝒮_t ∨ φ 违反)≤δ_plan，用 scenario optimization 以 N≥(2/δ_plan)(ln(1/β_plan)+d_π) 个独立采样、以 1−β_plan 置信度认证（Campi 界；高维时用场景/子采样近似并显式记账）。证书 Cert(π)=(C_DR,δ_plan,β_plan,{𝒮_t},π_fb,回退树,账本)。可组合性：Cert(π_1)∘Cert(π_2) 有效 ⇔ 第一段末端管道 ⊆ 第二段初始集 ∧ 交接处信念仍在 C_DR 内；否则必须在交接点重认证。

**定义 147（安全辨识规划 AIP）** 一段运动 π_id 安全可激励 ⇔ 接触等级≤L1 ∧ ∀ξ∈C_DR,∀t：x_t∈𝒦（生存核）∧ 𝒮_t∩𝒳_bad=∅。信息增益 EIG(ξ;y_{π_id})=H(ξ)−E_y[H(ξ|y)]。线性化签名 y≈h(ξ)+ε, ε~𝒩(0,Σ_ε)，安全可辨识矩阵 G_safe=Σ_{τ∈π_id}J_h(ξ)^TΣ_ε^{-1}J_h(ξ)，J_h 只沿保持安全的激励方向取。若某参数方向 v∈null(G_safe)，称"安全不可辨识"——不得据此收窄后验，必须保留宽度或退回保守规划。双控制目标 π*=argmax_{π∈Π_safe} E[progress(π)]+λ·EIG_safe(π)−risk(π)，或以 EIG 为主、风险/进度为约束。后验更新 p(ξ|y)∝p(ξ)p(y|ξ) 并触发 C_DR 重校准；EV-ident 仅在安全可激励 ∧ EIG 下界达标时签发。

**定义 148（分布鲁棒与对抗随机化护栏 ARG）** 歧义集 𝒫={q:W_1(q,p_ψ)≤ε_DR}；鲁棒机会约束 sup_{q∈𝒫}q(∃t 违反)≤δ_plan。合理对抗集 Ξ_adv={ξ∈C_DR:p_ψ(ξ)≥p_min}；见证 ξ_adv=argmax_{ξ∈Ξ_adv}V(π,ξ)，若 V(π,ξ_adv)>δ_adv 则拒绝/重规划。留出随机化：把维度分成拟合集 Ξ_fit 与留出集 Ξ_hold，证书在 Ξ_fit 上生成、在 Ξ_hold 上盲测；利用差 Δ_gap=|V_hold−V_fit|，若 Δ_gap>τ_gap（按二项置信上界）判为仿真伪影/DR 过拟合。因果不变性检验：扰动 nuisance 维度，要求行为变化≤τ_inv。对抗搜索受预算 B_adv 限制，未找到见证记为"未发现"而非"安全"。

**定义 149（应急运动规划 CMP 与承诺视界）** 计划树 𝒯=(𝒩,ℰ)：节点是信念/分支点，边是已认证段；每个节点 n 带回退 π_abort(n) 到安全吸引集 𝒜。回退可行性 P_{ξ∈C_DR}(在 T_rec 内到达 𝒜)≥1−δ_rec ∧ 累计损伤≤D_max。执行时承诺视界 h_c：只提交到下一个分支点（或固定段数）的第一段；分支条件由观测触发，管道出界则执行 π_abort 而非从零重规划。承诺契约 K=(π_seg,π_abort,分支条件,责任账本)；计划债务 D_plan=未认证段数，提交要求承诺视界内 D_plan=0 且回退可行。

**定义 150（轨迹级证据门与 DR-PCE）** 证据类：EV-plan（Cert(π) 有效且 δ_plan≤δ_max、回退可行）；EV-dr（Cov_DR 成立且非 DR-OOD）；EV-ident（安全可激励 ∧ EIG≥θ_EIG 或后验宽度收缩≥Δ_w）；EV-fallback（回退可行性证书）。硬规则：(R1) EV-plan 只在 EV-dr 成立时有效；(R2) 不可逆接触必要证据集=(EV-plan ∧ (EV-probe*∨EV-margin) ∧ EV-fallback)∪佐证，EV-dr/EV-ident/EV-xmodal/EV-ft 均不得单独替代；(R3) DR-OOD 时禁签 EV-plan，只允许保守回退/绕行/L2；(R4) 安全不可辨识方向不得被当作已辨识。DR-PCE 算子：①更新信念与锚点；②覆盖检查（失败→保守恢复）；③在 𝒫_DR 下做 CCP；④对抗与留出检验（失败→带见证重规划）；⑤信念过宽且存在安全激励→AIP，否则用保守上界承诺；⑥轨迹门→提交第一段并记账 J_plan；⑦运行时管道监控，出界即回退。终止：H、B_adv、k_id、k_plan 有限。

## 2. 关键算法伪代码（完整版见产物区）

```python
def dr_plan_commit(x0, task, M, DR, budget):
    cov = DR.coverage(M.anchor_signatures())          # 定义145：行为覆盖
    if not cov.ok:
        return conservative_recover(M, cov)           # DR-OOD：禁 EV-plan
    plan = ccp_plan(x0, task, M, DR.ambiguity_set, delta_plan, H)   # 146
    adv = adversarial_check(plan, DR, budget.adv)      # 148：对抗+留出盲测
    if adv.gap > tau_gap or adv.violation > delta_adv:
        plan = ccp_plan(x0, task, M, DR.restrict(adv.witness), delta_plan, H)
    if M.belief_width > w_id and budget.ident_left > 0:
        pi_id = safe_excitation(M, DR, level='L1')     # 147：仅安全激励
        if pi_id is not None:
            plan = splice_ident(plan, pi_id)
    seg = plan.first_committed                        # 149：第一段承诺
    if not trajectory_gate(plan, seg, cov, adv, M):   # 150：轨迹级证据门
        return plan.fallback_tree
    commit(seg, fallback=plan.fallback_tree)
    return monitor_tube(seg, plan.tube, on_exit=plan.fallback_tree)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CDR | O(N_a·K·d + N_a log N_a) 校准；索引后 O(1)/查询 | O(N_a·K·d) | 锚点交换性、因果掩码、α_DR 声明诚实 |
| CCP | O(H·\|C_DR\|·\|𝒮\|·d_f + N_sc·H·d_f) | O(H·\|𝒮\|) | 管道过近似、scenario 置信、回退可行 |
| AIP | O(\|Π_id\|·(d_ξ²+d_y·d_ξ)) | O(d_ξ²) | 安全可激励、null(G_safe) 不冒充可辨识 |
| ARG | O(N_adv·H·c_eval) | O(H·c_eval) | 合理对抗、留出盲测、歧义集 |
| CMP | O(\|𝒯\|·(H·c_eval+\|𝒮\|)) | O(\|𝒯\|·\|𝒮\|) | 回退可达、承诺视界、分支重认证 |
| DR-PCE | 上述合计 + O(\|CP\|·(k_p+k_id)·C_VOI) | O(\|V\|+\|𝒮\|+J_plan) | 预算单调、四态完备 |

**正确性定理（DRIVE Soundness，概要）** 在 A22–A45 上加 (A46) CDR：锚点可交换、行为覆盖 ≥1−α_DR、因果掩码有效、DR-OOD 不漏报超过 δ_ood；(A47) CCP：管道是 C_DR×𝒲 下可达集的过近似、scenario 认证置信 ≥1−β_plan、回退在 T_rec 内可达；(A48) AIP：安全激励对 ∀ξ∈C_DR 留在生存核且接触≤L1、EIG 为保守下界；(A49) ARG：歧义集以 ≥1−α_DR 覆盖真实分布、留出检验有功效、对抗搜索在 B_adv 内的漏检 ≤δ_search；(A50) CMP：回退可达概率 ≥1−δ_rec、承诺视界内计划债务为 0、运行时监控无假阴性；(A51) DR-PCE 预算单调且有限终止。则：

(i) **轨迹安全界**：P_safe ≥ 1 − [α_DR + δ_plan + β_plan + δ_rec + δ_adv + δ_search + δ_ood] − 前序轮次误差项（ε_meta+δ_probe+ε_h+δ_xm+δ_ft+δ_ux+δ_kg）− P(歧义集未覆盖真实分布) − P(管道监控失效) − P(回退执行失败)。
(ii) **覆盖闸门**：DR-OOD 时 EV-plan 不可签发；假认证只可能发生在"覆盖失效 ∧ OOD 漏检"的联合事件内，概率 ≤α_DR·δ_ood 量级。
(iii) **探索不增不可逆风险**：安全激励对 C_DR 内所有世界留在生存核且只做 L1 接触；若真实世界逸出 C_DR，风险由 α_DR 显式记账，而非被"辨识"悄悄抹掉。
(iv) **反利用**：留出盲测差距 >τ_gap 即拒绝，剩余仿真伪影风险 ≤τ_gap + 统计误差。
(v) **可组合与终止**：段证书在末端包含与信念重认证下可拼接；DR-PCE 在 H+B_adv+k_id+k_plan 内终止于 {承诺第一段, 回退, 绕行, L2, 安全停}。

### IP-145 CDR（校准域随机化）

```python
class CalibratedDomainRandomization:
    def __init__(self, anchor_lib, alpha_dr=0.1, eps_dr=0.05):
        self.anchors = anchor_lib                  # 𝒯_a
        self.alpha = alpha_dr
        self.eps = eps_dr
        self.cloud = []                            # ℬ_ψ
        self.q_dr = None
        self.causal_mask = None
        self.version = 0

    def fit_cloud(self, sim, p_psi, n_samples, causal_mask):
        self.causal_mask = causal_mask             # ℳ_c：KG 因果边裁剪
        for xi in sample(p_psi, n_samples, mask=causal_mask):
            for tau in self.anchors:
                y = sim.rollout(xi, tau)
                self.cloud.append(signature(y))
        self.version += 1
        return self

    def calibrate(self, real_anchor_sigs):
        cal, test = split_conformal(real_anchor_sigs)
        scores = [self.score(y) for y in cal]
        self.q_dr = conformal_quantile(scores, 1 - self.alpha)
        # 返回测试集覆盖率，供审计；不达标则标记 coverage_unreliable
        return CoverageAudit(q=self.q_dr,
                             test_cov=mean([self.score(y) <= self.q_dr
                                            for y in test]))

    def score(self, y):
        return min(distance(y, b) for b in self.cloud)   # s(y)

    def coverage(self, real_sigs):
        s = [self.score(y) for y in real_sigs]
        ok = max(s) <= self.q_dr
        return Coverage(ok=ok, q=self.q_dr, worst=max(s),
                        ood=not ok, version=self.version)

    def ambiguity_set(self):
        return WassersteinBall(self.cloud, eps=self.eps)

    def restrict(self, witness):
        # 对抗见证只收紧歧义集，不扩大支持域
        return self.ambiguity_set().intersect(plausible_set(witness))

    def drift_monitor(self, stream):
        cov = self.coverage(stream.window())
        if not cov.ok:
            return DriftEvent(window=stream.window(), worst=cov.worst)
        return None
```

### IP-147 AIP（安全辨识规划）

def contact_level(tau):
    return tau.level                    # L0/L1/L2_irreversible

def safe_identifiability(M, DR, pi_id):
    G = zeros((d_xi, d_xi))
    for tau in pi_id.segments:
        if contact_level(tau) > 'L1':
            return None                 # 不可逆接触不得进入安全激励
        if not inside_kernel(tau, M.viability_kernel, DR.C_DR):
            return None
        J = jacobian_signature(M, tau)  # ∂y/∂ξ
        G += J.T @ inv(M.sensor_cov) @ J
    return G

def safe_excitation(M, DR, level='L1'):
    cands = [tau for tau in excitation_library(M)
             if contact_level(tau) <= level]
    best, best_eig = None, -inf
    for tau in cands:
        G = safe_identifiability(M, DR, tau)
        if G is None:
            continue
        # D-optimal：logdet；再取最小非零特征值判断可辨识方向
        score = logdet(G + ridge) if min_nonzero_eig(G) > theta_eig else -inf
        if score > best_eig and risk(tau, M, DR) <= delta_id:
            best, best_eig = tau, score
    if best is None:
        return None                     # 诚实：不存在安全激励
    return best

def aip_update(M, DR, pi_id, y):

def adversarial_check(plan, DR, budget):
    # 合理对抗：只在 C_DR ∩ {p_ψ(ξ) ≥ p_min} 内找见证
    domain = DR.plausible_set(p_min=DR.p_min)
    witness = cma_es(lambda xi: violation(plan, xi), domain=domain,
                     max_evals=budget.adv)
    v_adv = violation(plan, witness)

    # 留出维度盲测：拟合维度上认证，留出维度上验收
    fit, hold = DR.split_dimensions()
    v_fit = violation_on(plan, fit)
    v_hold = violation_on(plan, hold)
    gap = abs(v_hold - v_fit)
    gap_ub = binomial_upper(gap, n=budget.hold_n, alpha=DR.alpha)

    ok = (v_adv <= DR.delta_adv) and (gap_ub <= DR.tau_gap)
    return AdvReport(ok=ok, witness=witness, violation=v_adv,
                     gap=gap, gap_ub=gap_ub)

def robust_chance_constraint(plan, ambiguity, delta_plan):
    # 对整个 Wasserstein 球取最坏：sup_q q(违反) ≤ δ_plan
    return worst_case_over(ambiguity,
                           lambda q: chance_violation(plan, q)) <= delta_plan

def drift_or_exploit_verdict(report, DR):
    if not report.ok and report.gap_ub > DR.tau_gap:
        return "sim_artifact_or_overfit"   # 拒绝，非重规划
    if not report.ok:
        return "adversarial_witness"       # 带见证重规划
    return "pass"

### IP-149 CMP（应急运动规划）

class ContingentPlan:
    def __init__(self, tree, commit_horizon):
        self.tree = tree
        self.h_c = commit_horizon

    def debt(self, seg):
        return sum(1 for e in self.tree.edges_until(seg) if not e.certified)

    def fallback_feasible(self, seg):
        return all(cert_reachable(n.fallback, self.M, self.DR, T_rec)
                   for n in self.tree.nodes_until(seg))

def build_contingency_tree(plan, M, DR, h_c):
    nodes = [belief_node(plan, t) for t in branch_points(plan)]
    for n in nodes:
        n.fallback = plan_abort_to_attractor(n, M.viability_kernel)
        if not cert_reachable(n.fallback, M, DR, T_rec, delta_rec):
            return None                    # 没退路就不建树
    return ContingentPlan(Tree(nodes), commit_horizon=h_c)

def commit_first_segment(plan, M):
    seg = plan.tree.first_segment()
    assert plan.debt(seg) == 0
    assert plan.fallback_feasible(seg)
    return CommitContract(seg, plan.tree.fallback_tree,
                          branch_conditions=plan.tree.branch_conditions,
                          responsibility=lineage(M))

def trajectory_gate(plan, seg, cov, adv, M):
    # EV-dr：覆盖不成立则 EV-plan 无效
    if not cov.ok:
        return GateResult(False, "dr_ood")
    # EV-plan + 反利用
    if not (plan.cert.ok and adv.ok):
        return GateResult(False, "plan_or_adv_reject")
    # EV-fallback：不可逆段必须有回退
    if seg.irreversible:
        if not plan.fallback_feasible(seg):
            return GateResult(False, "no_fallback")
        # 不可逆必要集：轨迹证书 ∧ 力学证据 ∧ 回退
        if not (M.ev_probe_star(seg) or M.ev_margin(seg)):
            return GateResult(False, "missing_mechanical_evidence")
    # 安全不可辨识方向不得被当成已辨识
    if M.ident_null_dirs and M.belief_width > M.w_id:
        return GateResult(False, "unidentifiable_under_safety")
    return GateResult(True, "ok", plan.cert)

def dr_pce(x0, task, M, DR, budget, operators):
    # ① 更新信念与真实锚点
    M = M.update_from_stream()
    DR = DR.update_anchors(M.real_anchor_sigs)

    # ② 覆盖检查：失败则保守恢复（禁 EV-plan）
    cov = DR.coverage(M.recent_signatures())
    if not cov.ok:
        return conservative_recover(M, cov, operators)

    # ③ 在歧义集下做证书携带规划
    plan = ccp_plan(x0, task, M, DR.ambiguity_set(),
                    delta_plan=budget.delta_plan, H=budget.H)
    if not plan.cert.ok:
        return negotiate_or_stop(M, plan, operators)

    # ④ 合理对抗 + 留出盲测
    adv = adversarial_check(plan, DR, budget.adv)
    verdict = drift_or_exploit_verdict(adv, DR)
    if verdict == "adversarial_witness":
        plan = ccp_plan(x0, task, M, DR.restrict(adv.witness),
                        budget.delta_plan, budget.H)
    elif verdict == "sim_artifact_or_overfit":
        return conservative_recover(M, adv, operators)

    # ⑤ 信念过宽：安全辨识或保守承诺
    if M.belief_width > M.w_id and budget.ident_left > 0:
        pi_id = safe_excitation(M, DR, level='L1')
        if pi_id is not None:
            plan = splice_ident(plan, pi_id)
            budget.ident_spend()
        else:
            M = M.widen_for_unidentifiable()   # 诚信：保留宽度

    # ⑥ 应急树 + 轨迹门
    tree = build_contingency_tree(plan, M, DR, budget.h_c)
    if tree is None:
        return negotiate_or_stop(M, plan, operators)
    seg = tree.first_segment()
    gate = trajectory_gate(plan, seg, cov, adv, M)
    if not gate.ok:
        return negotiate_or_stop(M, plan, operators, gate)

    # ⑦ 提交第一段，记账，运行时监控
    contract = commit_first_segment(tree, M)
    M.J_plan.append(PlanLedger(seg=seg, cert=plan.cert, cov=cov,
                               adv=adv, ident=M.ident_log,
                               fallback=tree.fallback_tree,
                               dr_version=DR.version))
    return monitor_tube(seg, plan.cert.tubes[0],
                        on_exit=contract.fallback)

def few_shot_evidence_gate_pp_plus(c, M, persona, ood_reg, mental):
    """第 58 轮六类证据门 + 本轮四类轨迹证据"""
    if c.ev == 'EV-plan':
        ok = (c.cert.ok and c.cov.ok and c.adv.ok
              and c.seg.within_commit_horizon)
    elif c.ev == 'EV-dr':
        ok = c.cov.ok and not c.cov.ood
    elif c.ev == 'EV-ident':
        ok = (c.level == 'L1' and c.eig >= theta_eig
              and not c.null_dirs_crossed)
    elif c.ev == 'EV-fallback':
        ok = c.reachable and c.damage <= D_MAX
    else:
        return few_shot_evidence_gate_pp(c, M, persona, ood_reg, mental)

    if not ok:
        return ('reject', 'trajectory_evidence_insufficient', c)
    if c.irreversible and c.ev in ('EV-dr', 'EV-ident'):
        return ('reject', 'dr_or_ident_on_irreversible', c)
    return ('ok', c)

## 6. 本轮最大风险

**一句话**：本轮把安全承诺从"步级证据"押到"校准过的随机化分布 + 轨迹级证书"上——一旦真实世界的行为落在锚点库覆盖的行为集之外（新地形、新载荷、传感器漂移），CDR 会给出一个看似有覆盖保证、实则外推的 α_DR，而证书携带规划会据此自信地执行整段轨迹；更危险的是主动辨识为了缩小不确定性，可能去激励恰好触发不可逆接触的方向。必须把"覆盖失效"当成一等公民：行为 OOD 门 + 分布鲁棒歧义集 + 仅 L1 安全激励 + 运行时管道监控与回退四重护栏，宁可退回慢速保守规划，绝不把"仿真里随机过"当成"现实里证明过"。
