# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「自然语言指令」×「运动控制」）

> R69 让闭环学会「问」：把不确定性拆成 aleatoric/epistemic，用流匹配的多峰动作 + 主动看/问/触去消解。但 R69 有一个从没写下来的前提——**任务本身已经给定、且无歧义**。语言在 R69 里只作为**输出**出现（由冻结 LLM 解码一句问话），从不作为**输入**。而真实机器人的任务几乎总是以自然语言到达的：「把杯子拿稳一点」「先别碰那个」「给我递个能拧的东西」「快点，但要小心」。这些指令**天生欠定**：它规定的是约束与偏好，不是一条轨迹，更不是一个点目标。
>
> 更要命的是 R69 的处置方式：一旦识别出多个动作模态，就**先选一个、再按 λ 收紧**。但大量指令歧义根本不需要「问」——它需要系统**先别承诺**：沿所有仍然存活的解释的共同可行前缀往前挪，直到「分岔口」在物理上不可避免。人就是这样做的：听不懂「拿哪个」时，手先伸到两个杯子中间，而不是立刻开口。
>
> 本轮两个灵感正好补上两块缺失：
> - **自然语言指令**把「任务」从字符串变成一组**集合值规格**（目标 / 硬约束 / 容差 / 偏好 / 未指定自由度）及其解释后验——歧义终于有了「它属于哪一类」的身份；
> - **运动控制**给出「承诺的物理学」：可行核、制动视界、可逆性、阻抗。**必须做选择的时刻不是一个逻辑事实，而是一个动力学事实**——你可以靠减速把分岔口往后推；而「减速」恰恰就是 R68 的 λ。
>
> 核心命题：**把不确定性三分——aleatoric（噪声）/ epistemic（世界）/ semantic（指令欠定）；前两者沿用 R68–R69，第三者交给「可行核内的延迟接地」：在所有存活解释的共同可行核里运动，用速度 λ 购买接地时间，只在承诺前沿被迫到来（或买时间比发问更贵）时才澄清。R68 的减速、R69 的提问，被统一成同一个「接地时间预算」的两端；运动本身成为语言的后半句。** 命名 **LINGUA-RAS**（Language-Instruction Grounding under Uncertainty & Authority）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我究竟被要求做什么，以及我的运动是否已经把这句话兑现**」——**刹车踏板本身就是一种提问：它把分岔口往后推，让世界和人先说话。**

## 0. 直觉与动机

**灵感 1（自然语言指令 → 指令是「集合」，不是「点」）**
直觉：一句「把杯子拿稳一点」并没有指定抓哪个杯、用哪只手、走哪条路、多快算快；它只规定了若干**硬约束**（别洒、别捏碎）、若干**软偏好**（稳、快），以及大片**未指定自由度**。把它编译成一个「目标点 + 一条计划」，等于在没有证据时替用户做了他还没做的决定。正确的对象是一个**集合值规格**：可行轨迹集合 ℱ(ℓ)，以及一组解释 {i}。歧义不是「模型不确定」，而是「语言真的没说完」。这一步把 R69 在动作空间里数峰，换成在**解释空间**里数世界——而且解释是离散、可枚举、可被人一句话击破的。

**灵感 2（运动控制 → 承诺是一个动力学事件，不是一个逻辑事件）**
直觉：R69 一旦选定模态就立刻承诺并收缩；但「何时必须选」由物理决定。当两个解释要求不同终点时，你并不是在「当前时刻」就必须选，而是**在还能刹住、还能改道的最后一刻**之前都可以不选。这就是可行核（viability kernel）与制动视界：只要当前状态还落在所有存活解释的可行核交集里，就存在一条控制律让每个解释都仍然可达。**分岔口是交集边界，不是当前状态。** 于是「延迟承诺」有了严格定义，也有了物理截止时间。

**灵感 3（减速即提问 → 把 R68 的刹车纳入同一个预算）**
直觉：制动距离随速度下降而缩短，减速就等于把可行核交集的边界往后推，也就是**用时间买可选性**。R68 的 λ 一直只是「不确定就慢」的保守反射；R70 给了它一个信息论价格：每放慢一档，换回多少「接地时间」。于是「减速」与「发问」不再是两套系统，而是同一笔预算下的两种支付方式——**慢是便宜的提问，问是昂贵的减速**。这也解释了为什么人和机器在犹豫时都先「顿一下」。

**灵感 4（三分而非二分 → 语义不确定性不可被感知替代）**
直觉：R69 的 aleatoric/epistemic 都是「世界会怎样」的不确定；但「我被要求做什么」的不确定是另一类：**再看十眼也看不出用户想让我抓哪个杯子，只有语言或承诺动作能回答**。反过来，问「哪个杯子」也降不下关节噪声。三类不确定性对应三种动词：**问（语言）、看/触（感知）、慢（控制）**，外加一个「做（承诺）」。把它们压成一个标量熵，会让系统在需要开口时去减速、在需要减速时去追问。R70 明确分开，并给出各自的证据通道与预算。

**灵感 5（语言是权威请求，不是授权 → 新攻击面）**
直觉：一旦自然语言能实时改任务，就出现一个 R69 没有的漏洞：**语言能不能扩张安全边界？** 环境里的文字、旁人的喊话、甚至用户一句「没事，直接冲」，都可能把系统推出硬安全包络。R70 立一条**权限单调性**：语言只能**收缩**可行集，永不扩张硬安全包络；任何「放松安全」的指令都必须被识别为**规格冲突**而不是被服从。更有甚者，语言还会**渐变**：每次只要求快一点、近一点，单步都安全，累积到越界。这需要一个带记忆的权限账本与再冻结机制。

**灵感 6（接地的双通道 → R69 的 FMA 管不了「听懂错了」）**
直觉：R69 的流似然 Δa 能发现「传感器被标定骗了」，因为它测的是**行为自洽**。但如果指令被编译错了——「轻一点」被编成了「慢一点」、「拿稳」被理解为「夹紧」——那么执行会**完美地**满足那个错误的规格：行为自洽、约束不越、证书全绿，只是做的不是用户要的事。这是 R70 版本的「缓变故障」：**规格层的错配**。为此需要一个语义侧的对偶通道：**接地合规残差 G_r**（语言预测的结果 vs. 观察/人反馈的结果），与 Δa 构成二维诊断：Δa 高 G_r 低 = 执行/动力学错；Δa 低 G_r 高 = **理解/规格错**。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（LINGUA-RAS 总览）** LINGUA-RAS = (ISP, IGP, VGC, CFA, SSG, LCC, GCR, RAS-WM†)。三不变式：
(i) **快环零语言写操作**：kHz 运动环只读不可变规格快照，绝不调用 LLM（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **权限单调性**：任何语言输入只能收缩可行集，硬安全包络 Safe_auth 永不被语言扩张（定义 322）；
(iii) **承诺纪律**：不可逆动作必须发生在「坚持久一点」的成本超过信息价值之后，且信息动作必须可逆或落在接地可行核内（定义 316–321）。

**定义 311（集合值指令规格）** 指令 ℓ 编译为规格 S(ℓ) = (G, H, P, F, I)：目标谓词 G(ξ)∈{0,1}、硬约束 H(ξ)≤0、软偏好 P(ξ) 及权重 w、未指定自由度 F、解释集合 I。每个解释 i 给出一份具体化 S_i=(G_i,H_i,P_i)，可行集 ℱ_i={ξ: H_i(ξ)≤0 ∧ G_i(ξ)=1}。指令欠定 ⇔ |I|>1 或 F≠∅。**关键：把 F 显式保留下来，而不是在解析时偷偷填一个默认值。**

**定义 312（联合解释–模态后验）** 三层因子化：
p(i, m, ξ | o, ℓ) = p(i | o, ℓ) · p(m | o, ℓ, i) · p(ξ | o, m, i)。
i ∈ I 为语义解释（离散、符号、可被一句话增删），m 为 R69 的动作模态（连续轨迹簇），ξ 为轨迹。**R69 是 |I|=1 的条件切片**，其流策略升级为指令条件化的 π_θ(ξ | o, i)。

**定义 313（不确定性三分与不可替代性）**
U_sem = H(i | o, ℓ)（语义/规格欠定）；U_epi = E_i[H(m | o, ℓ, i)]（世界/感知歧义，R69）；U_ale = E_{i,m}[tr Σ_{m}]（模态内噪声，R68）。
三者**不做加权和**，各自进入不同动词：U_ale→减速/收紧；U_epi→看/触；U_sem→延迟承诺或语言澄清。不可替代性由引理 21 形式化。

**定义 314（解释条件化策略）** 在每个解释 i 下：流策略 π_θ(ξ | o, i)（复用 R69 FMP 与 R68 trunk，仅增加一个解释嵌入 e_i），以及约束动力学 ẋ=f(x,u)，输出约束 H_i。解释只改**条件与约束**，不改低层运动原语——保证跨本体可迁移。

**定义 315（可行核与接地可行核）** 解释 i 的可行核 V_i = {x : ∃u(·) 使轨迹从 x 出发满足 H_i 并到达 G_i}。对存活集 I_ε={i: p(i|o,ℓ)≥ε}，**接地可行核** V_∩ = ∩_{i∈I_ε} V_i。x ∈ V_∩ ⇔ 存在（可能依赖解释的）控制使**每个**存活解释都仍然可达。承诺前沿 = ∂V_∩。

**定义 316（生产性接地可行核）** V_∩^+ = {x∈V_∩ : ∃u 使所有 i 下目标进展速率 ≥ η>0（或松弛值下降）}。若 x∈V_∩ 但 x∉V_∩^+，则「不承诺」退化为「原地不动」——此时延迟无意义，必须发问或承诺。**这堵住了「交集只是『别动』」的退化解。**

**定义 317（承诺前沿与制动视界）** 设当前速度 v、最大减速度 a_max、沿候选轨迹到 ∂V_∩ 的距离 d。最晚决策时刻 t* = t_now + (d − d_brake)/v，d_brake=v²/(2a_max)。若 v→0，则 t*→∞（可无限延迟但完不成任务）；若 v 大，则 t* 被压缩到制动视界内。t* 是**物理事实**，不是超参数。

**定义 318（λ–视界交易）** 风险缩放 λ∈(0,1] 把执行速度变为 λv，于是可选性视界 H(λ) = (d − (λv)²/(2a_max))/(λv)。∂H/∂λ<0：**放慢买时间**。定义可选性的边际价格 π_opt = (∂H/∂λ)/(∂c_time/∂λ)，与澄清的边际成本 c_ask 比较，得到「减速 vs 发问」的判据（定义 320）。**R68 的 λ_floor 成为「当 U_sem 无法消解时按最坏解释买时间」的边界情形。**

**定义 319（延迟接地控制律 VGC）** 在 x∈V_∩^+ 时求解最小承诺 QP：
u* = argmin_u Σ_i ŵ_i·J_i(x,u) + ρ·(1−progress)  s.t.  x⁺(u) ∈ V_∩^+，硬约束与 R69 认证前缀不变。
即：在**不消灭任何存活解释的可达性**的前提下，最小化按后验加权的期望代价。已承诺度用一个隐变量 c∈{open, committed(i*)} 表示，QP 只在 c=open 时保留交集约束。

**定义 320（澄清–减速–承诺仲裁 CFA）** 三种动作，按「每单位成本买到的期望后悔下降」比较：
- **减速**：支付时间 Δt，使 t* 后移，可能让后续观测自然分离解释；收益 = E[ΔRegret | 延迟]；
- **澄清**：支付社交/时延 c_ask，直接降低 U_sem（R69 MINT 的语言版）；
- **承诺**：选 i*=argmax_i E[U | i]，支付不可逆风险 c_irr(i*)。
选择 argmax 净收益；若三者都 ≤0（高stakes 且无利可图）→ **弃权/交接**（定义 325），而不是硬猜。

**定义 321（可逆信息运动）** 信息动作 g_demo 必须是**可逆的**：存在恢复控制使系统在 τ_r 内回到承诺前状态，且能量/接触状态可复位；以回驱性、阻抗上界、最小安全距离给出可逆性证书 Rev(g)=1。不可逆动作不得作为信息获取手段（例如「先抓一下看看对不对」若夹碎则不可逆，禁止）。**运动作为提问的前提是它能被撤回。**

**定义 322（语义安全门 SSG 与权限单调性）** 新语言输入（初始指令、纠正、环境文字、第三方语音）先过门：
(a) 若 S(ℓ) 的硬约束与 Safe_auth 冲突（要求放松安全）→ 判为**规格冲突**，拒绝服从，记录并求助；
(b) 若 S(ℓ) 只增加约束 → 直接接受；
(c) **权限单调性**：对任意被接受的修订，ℱ(S(ℓ)) ⊆ Safe_auth 恒成立；语言永不扩张硬安全集。
(d) 若一次修订**翻转**已提交的硬约束，需确认（非对称证据，定义 323）。

**定义 323（在线语言纠正与非对称证据）** 人的纠正 y_c（「不是那个」「慢点」「小心！」）作为**证据**更新解释后验，而非直接命令。非对称公理：
- **任何收缩/停止类输入零确认立即生效**（刹车是单边的）；
- **任何扩张/加速/放宽类输入**需 k 个正交证据源一致（加速是多边的），且不得越过 Safe_auth。
令情感/语气强度调制证据权重，但**调制的是似然，不是权限**。

**定义 324（接地合规残差 G_r 与双通道诊断）** 执行 ξ 后：
- 硬违反 V_h = max(0, max_k H_k(ξ))；软后悔 R_s = P(ξ) − J*(S)；
- **接地残差** G_r = d( ŷ_ℓ , y_obs )：ŷ_ℓ 为规格/语言模型预测的结果（如「杯子将正立、不洒」），y_obs 为视觉/力觉/人反馈观测。
- 双通道：Δa（R69 流似然，行为自洽）与 G_r（规格兑现）联立——**(Δa↓, G_r↑) ⇒ 规格/理解错**；**(Δa↑, G_r↓) ⇒ 执行/动力学错**。

**定义 325（语义预算、弃权与交接）** 单位任务段澄清预算 ≤1 次；若预算耗尽且 U_sem 仍高、或解释集**完整性不可验证**且 stakes 高 → **弃权**（保持安全静止）或**交接**（请求人接管/换一种模态），严禁「偷偷换一个更容易的目标」来让成功率好看。

**定义 326（规格快照的实时隔离）** 快环读不可变快照 S_snap（含解释后验、约束、λ 上限）。规格修订流程：编译 → SSG 校验 → 一致性与单调性检查 → **在轨迹边界原子换装**。修订永不插入快环中途；LLM 故障时保持上一快照 + 最保守包络，绝不在未验证规格上执行。

**定义 327（威胁模型 ℰ_LINGUA）** 新增攻击面：环境文字/第三方语音的**指令注入**；**权限升级**（「忽略安全」）；**语义渐变**（每次只要快一点，累积越界）；**谄媚式字面服从**（有害字面义）；**反馈投毒**（伪造纠正）；**指代欺骗**（同形物体恶意重标）；**接地幻觉**（VLM 自信地误报结果）。并入 AIC：ℰ_LINGUA = ℰ_FLUID × ℰ_instr × ℰ_semantic。

**定义 328（证书 J_LINGUA）** J_LINGUA = (J_FLUID, U_sem_before/after, interp_hash, spec_hash, authority_monotone_proof, (V_h, R_s, G_r), commitment_ledger_hash, rev_cert, lingo_ver)。Valid ⇔ Valid(J_FLUID) ∧ 权限单调性成立 ∧ V_h=0 ∧ 证据纪律满足 ∧ 预算未越界 ∧（G_r≤τ_g 或已标记并求助）。

## 2. 关键算法骨架

```python
# IP-264 ISP：指令 -> 集合值规格 + 解释图（慢环，事件触发，不在快环）
def compile_instruction(llm, o, ell):
    S = llm.parse(ell, o)                       # {G, H, P, F, interpretations}
    I = expand_interpretations(S)               # 含 F 的显式枚举/采样
    return Spec(S, I, posterior=prior_over(I))

# IP-265 IGP：解释后验（语言先验 × 观测/纠正似然）
def update_interpretations(spec, evidence):
    for i in spec.I:
        spec.w[i] = normalize(spec.w[i] * likelihood(evidence, i))
    return spec

# IP-266 VGC：可行核交集中的最小承诺控制（快环，每毫秒）
def viability_grounded_control(x, spec, lam):
    I_eps = [i for i in spec.I if spec.w[i] >= EPS]
    Vcap  = intersect_viability_kernels(I_eps, x)      # x in Vcap ?
    Vplus = productive_part(Vcap, eta=ETA)             # 排除「原地不动」
    if x not in Vplus:
        return CFA_DECISION(spec, x, lam)              # 被迫到分岔口
    u = solve_qp(objective=sum(spec.w[i]*J[i](x,u) for i in I_eps),
                 constraints=[x_next(u) in Vplus] + spec.hard + cert_prefix,
                 warm_start=last_u)
    return EXECUTE(u, lam)                             # 保留所有解释的可达性

# IP-267 CFA：减速 / 澄清 / 承诺 / 弃权，按单位成本后悔下降比较
def CFA_DECISION(spec, x, lam):
    t_star = commitment_frontier_time(x, lam, spec)     # 定义 317
    candidates = {
        'slow':    (value_of_delay(spec, t_star), cost_time(dlam(lam))),
        'ask':     (value_of_clarification(spec),  cost_ask(spec)),
        'commit':  (-irreversible_risk(spec, x),   cost_commit(spec)),
        'abstain': (0.0,                           cost_handback(spec)),
    }
    pick = argmax((gain - cost, name) for name,(gain,cost) in candidates.items())
    return pick if pick.gain > pick.cost else ABSTAIN()  # 无利可图 -> 弃权

# IP-268 SSG：语义安全门（权限单调性）
def semantic_safety_gate(spec, safe_auth):
    if conflicts(spec.hard, safe_auth):     return REJECT_CONFLICT   # 不得放松
    if not subset(spec.feasible, safe_auth):return REJECT_EXPAND     # 只能收缩
    if flips_committed_hard(spec):          return REQUIRE_CONFIRM   # 非对称证据
    return ACCEPT

# IP-269 LCC：在线纠正作为证据（刹车单边，加速多边）
def apply_correction(spec, y_c, sources):
    if is_restrictive(y_c):  return update_interpretations(spec, y_c)   # 立即
    if is_expansive(y_c) and k_orthogonal_agree(sources) >= K:
        return semantic_safety_gate(update_interpretations(spec, y_c), Safe_auth)
    return spec                                                          # 忽略扩张

# IP-270 GCR：接地残差（语义侧第二意见）
def grounding_residual(spec, i, xi_obs, y_obs):
    y_hat = spec.predict_outcome(i, xi_obs)     # 语言/规格预测「应该看到什么」
    return distance(y_hat, y_obs)               # (Δa 低, G_r 高) => 理解错

# IP-274 主闭环（继承 R69；快慢双环隔离）
def LINGUA_RAS_round(M, obs, ell=None):
    if ell is not None:                          # 慢环：仅事件触发
        spec = M.isp.compile(ell, obs)
        spec = M.ssg.gate(spec, M.safe_auth)
        M.stage_snapshot(spec)                   # 轨迹边界原子换装
    spec = M.snap.current()                      # 快环只读
    z, o = M.mtm.forward(obs)                    # R68/R69 一次前向
    # 1) 语义层：先看能否延迟承诺（不立刻选模态）
    decision = M.vgc.viability_grounded_control(M.state, spec, M.lam)
    if decision.is_execution():
        return M.execute(decision.u)             # 共同可行核内运动
    # 2) 分岔口：减速买时间 vs 语言澄清 vs 承诺 vs 弃权
    act = M.cfa.decide(spec, M.state, M.lam)
    if act == 'slow':   return M.execute(slow_down(spec, act.dt))
    if act == 'ask':    return M.execute(M.mint.ask(spec))    # R69 语言动作
    if act == 'commit':
        spec = commit(spec, act.i_star)
        M.ledger.record(act.i_star, reversible=False)
    if act == 'abstain':return M.safe_stop_and_handback(spec)
    # 3) 执行 + 双通道诊断 + 参与式审计
    xi = M.execute(act.plan)
    a_hat = M.fma.flow_anomaly(M.fmp, xi, obs, M.o_cal)       # R69 行为通道
    g_hat = M.gcr.grounding_residual(spec, act.i_star, xi, M.obs_outcome)
    M.vqa_g.submit_async(spec, act, a_hat, g_hat)             # IP-271
    return xi, (a_hat, g_hat)
```

## 3. 推导

**引理 19（延迟承诺不劣于立即承诺）** 设 x∈V_∩^+，且存在可逆控制保持 x(t)∈V_∩^+ 至承诺前沿。则对任意解释后验，先延迟到前沿再决策的期望后悔 ≤ 立即按当前后验承诺的期望后悔；当存活解释的最优代价不同且前沿在未来时严格更小。要点：立即承诺**不可逆地丢弃**了尚未被证据排除的解释，而延迟只支付可控的时间成本——这是标准的**可选性价值**（option value），在此由可行核交集给出严格可行性保证。系：R69「一识别到多峰就选模态」在多解释场景下是次优的。

**引理 20（制动视界与 λ 的可选性价格）** 在最大减速度 a_max 下，最晚决策时刻满足 t*−t_now = (d − (λv)²/(2a_max))/(λv)，故 ∂H/∂λ<0。若时间成本线性 c_t·Δt，则减速买到的单位时间价格 π_opt = c_t / |∂H/∂λ|；当 c_ask < π_opt 时发问划算，否则减速划算。**R68 的 λ_floor 是「U_sem 不可消解、只能按最坏解释买时间」的边界解**，定理 18 给出包含关系。系：机器人的「犹豫」不是缺陷，而是最优控制对可选性的正确定价。

**引理 21（语义不确定性不可被感知替代）** 存在成对场景：(a) 两个同形杯子、世界状态完全可观测（U_epi≈0），但指代未定（U_sem 高）；(b) 世界被遮挡（U_epi 高），但指令唯一确定目标（U_sem=0）。在 (a) 中任何 R69 信息动作（注视/探针）对 H(i) 的期望下降为 0；在 (b) 中任何语言澄清对 H(m) 的期望下降为 0。故 U_sem 与 U_epi 互不支配，三分通道必要，不能压成一个标量。

**定理 18（LINGUA 严格包含 R68–R69）** 当 |I|=1、U_sem=0 时，V_∩=V_i，CFA 不退化为额外提问，VGC 的最小承诺 QP 即 R69 的「选模态 + 认证前缀」；当进一步 VoI≤成本且无可交互时，退化为 R68 的 λ_floor 闭环。且在上述边界上 LINGUA 与 R69/R68 **逐指令相同**，安全侧不做任何让步；效率侧获得「无需澄清的共同前缀」与「减速替代提问」两项 resolution bonus。

**定理 19（权限单调性 ⇒ 语言注入不可越权）** 若每个被接受的规格都满足 ℱ(S)⊆Safe_auth，且硬约束只可增不可减，则任意语言输入序列下执行轨迹均满足 Safe_auth；语言对手单独**不能**导致越权，只能导致**拒绝/弃权/任务失败**。证明：对规格修订归纳 + SSG 门控 + 快环独立认证（R68/R69 不变式）保持不变。系：最坏情况从「不安全服从」降级为「安全地不服从」。

**定理 20（双环隔离与无突变）** 规格修订在轨迹边界原子换装，快环控制律关于快照分段常数；换装点满足位移/速度连续（R68 定理 15 的不变式），故无控制突变。快环最坏延迟 ≤ R69 + QP 增量；LLM 调用完全在慢环，故障不进入实时路径。

**定理 21（非对称证据的安全下界）** 坚持「收缩单边、扩张多边」时，投毒纠正导致的不安全扩张概率 ≤ δ_p·ρ^{K−1}+ε_σ（沿用 R69 引理 18），而所有停止类输入仍 100% 生效。**刹车永远可信，油门需要多数票。**

## 6. 本轮最大风险

**一句话**：LINGUA-RAS 的全部安全性都押在「解释集合 I(ℓ) 足够完整」这一前提上——**若指令编译器漏掉了那个真正的解释，可行核交集会把系统稳稳地引到一个「自洽但错误」的共同前缀，然后在分岔口自信地承诺，硬约束不越、权限单调、证书全绿，却做了用户从未要求的事；而 G_r 也抓不到它，因为结果与那份错误的规格完美吻合。** R69 是「问错比不问更危险」，R70 是「**把错的听懂当成了懂**」——一个闭合的证据体系会为一次编译错误背书。

**次级风险与缓解**：
1. **交集退化为「不动」**（目标塌缩）→ 生产性可行核 V_∩^+（定义 316）+ 进展速率下界 η；
2. **解释集不可枚举/开放世界** → 保留弃权与交接动作、高 stakes 不耗尽可选性预算、把「完整性」当作覆盖问题审计（E313）；
3. **语言渐变与注入** → 权限单调性 + 再冻结 + 非对称证据（定义 322–323、定理 19/21）；
4. **慢环 LLM 抖动/版本漂移** → 规格哈希 + 快照隔离 + 故障保持最保守包络（定义 326）；
5. **接地残差自身幻觉**（VLM 误判结果）→ G_r 作为**证据而非定论**，与力觉/人反馈多源一致，且只触发标记与求助、不单独改变安全等级；
6. **减速-发问的交易参数 c_ask 主观** → 用户画像与在线标定，纳入审计（E305、E297 式长时程）。

**定义 320（CFA 仲裁）** 减速/澄清/承诺/弃权四选一，按「单位成本买到的期望后悔下降」；全都 ≤0 → 弃权，不硬猜。

**定义 321（可逆信息运动）** 信息动作须可逆（回驱、阻抗上界、最短复位时间 τ_r），不可逆动作不得作为探询手段。

**定义 322–323（SSG 与纠正）** 冲突安全 → 规格冲突拒绝；只增约束 → 接受；翻转已提交硬约束 → 需确认。纠正作为证据：收缩/停止单边立即生效，扩张/加速需 k 正交源一致，且不得越过 Safe_auth。

**定义 324（接地残差与双通道）** `G_r=d(ŷ_ℓ,y_obs)`；`(Δa↓,G_r↑)⇒理解/规格错`，`(Δa↑,G_r↓)⇒执行/动力学错`。

**定义 325–326（预算/弃权与快照隔离）** 语义预算 ≤1 次/段；穷尽且高风险 → 弃权/交接；规格编译→SSG→一致性→轨迹边界原子换装，LLM 故障保持最保守包络。

**定义 327–328（威胁与证书）** `ℰ_LINGUA=ℰ_FLUID×ℰ_instr×ℰ_semantic`；`J_LINGUA` 并入 U_sem、hases、权限单调证明、合规三元组、承诺账本、可逆证书。

## 3. 关键算法伪代码

```python
# IP-264/265：慢环——指令编译为集合值规格 + 解释后验
def compile_instruction(llm, o, ell):
    S = llm.parse(ell, o)                        # {G,H,P,F,I}
    return Spec(S, I=expand(F, S), w=prior(I))

def update_interpretations(spec, evidence):
    spec.w = normalize({i: spec.w[i]*likelihood(evidence, i) for i in spec.I})
    return spec

# IP-266：快环——可行核交集中的最小承诺控制
def viability_grounded_control(x, spec, lam):
    I_eps = [i for i in spec.I if spec.w[i] >= EPS]
    Vcap  = intersect_viability_kernels(I_eps, x)
    Vplus = productive_part(Vcap, eta=ETA)        # 排除「原地不动」
    if x not in Vplus:
        return CFA_DECISION(spec, x, lam)         # 已被迫到分岔口
    u = solve_qp(sum(spec.w[i]*J[i](x,u) for i in I_eps),
                 [x_next(u) in Vplus] + spec.hard + cert_prefix,
                 warm_start=last_u)               # 保留所有解释可达
    return EXECUTE(u, lam)

# IP-267：减速 / 澄清 / 承诺 / 弃权
def CFA_DECISION(spec, x, lam):
    t_star = commitment_frontier_time(x, lam, spec)      # 定义 317
    gain = {
        'slow':    value_of_delay(spec, t_star) - cost_time(dlam(lam)),
        'ask':     value_of_clarification(spec)  - cost_ask(spec),
        'commit': -irreversible_risk(spec, x)    - cost_commit(spec),
        'abstain': 0.0                            - cost_handback(spec),
    }
    name = max(gain, key=gain.get)
    return name if gain[name] > 0 else ABSTAIN()

# IP-268：语义安全门（权限单调性）
def semantic_safety_gate(spec, safe_auth):
    if conflicts(spec.hard, safe_auth):      return REJECT_CONFLICT  # 不得放松
    if not subset(spec.feasible, safe_auth): return REJECT_EXPAND    # 只能收缩
    if flips_committed_hard(spec):           return REQUIRE_CONFIRM  # 非对称证据
    return ACCEPT

# IP-269：纠正作为证据（刹车单边 / 加速多边）
def apply_correction(spec, y_c, sources):
    if is_restrictive(y_c):
        return update_interpretations(spec, y_c)                     # 立即
    if is_expansive(y_c) and k_orthogonal_agree(sources) >= K:
        return semantic_safety_gate(update_interpretations(spec, y_c), Safe_auth)
    return spec                                                      # 忽略扩张

# IP-270：接地残差（语义侧第二意见）
def grounding_residual(spec, i, xi_obs, y_obs):
    return distance(spec.predict_outcome(i, xi_obs), y_obs)          # (Δa↓,G_r↑)=理解错

# IP-274：主闭环（快慢双环隔离）
def LINGUA_RAS_round(M, obs, ell=None):
    if ell is not None:                          # 慢环：仅事件触发
        spec = M.ssg.gate(M.isp.compile(ell, obs), M.safe_auth)
        M.stage_snapshot(spec)                   # 轨迹边界原子换装
    spec = M.snap.current()                      # 快环只读，零 LLM
    z, o = M.mtm.forward(obs)                    # R68/R69 一次前向
    d = M.vgc.viability_grounded_control(M.state, spec, M.lam)
    if d.is_execution(): return M.execute(d.u)   # 共同可行核内运动
    act = M.cfa.decide(spec, M.state, M.lam)     # 分岔口四选一
    if act == 'slow':   return M.execute(slow_down(spec, act.dt))
    if act == 'ask':    return M.execute(M.mint.ask(spec))       # R69 语言动作
    if act == 'commit':
        spec = commit(spec, act.i_star); M.ledger.record(act.i_star, False)
    if act == 'abstain':return M.safe_stop_and_handback(spec)
    xi   = M.execute(act.plan)
    a_hat = M.fma.flow_anomaly(M.fmp, xi, obs, M.o_cal)          # R69 行为通道
    g_hat = M.gcr.grounding_residual(spec, act.i_star, xi, M.obs_outcome)
    M.vqa_g.submit_async(spec, act, a_hat, g_hat)                # IP-271
    return xi, (a_hat, g_hat)
```

## 4. 推导

**引理 19（延迟承诺不劣于立即承诺）** 若 `x∈V_∩^+` 且存在可逆控制保持 `x(t)∈V_∩^+` 至前沿，则延迟到前沿再决策的期望后悔 ≤ 立即按当前后验承诺；当解释的最优代价不同且前沿在未来时严格更小。系：R69「一识别多峰就选模态」在多解释场景下次优。

**引理 20（制动视界与可选性价格）** `t*−t_now=(d−(λv)²/2a_max)/(λv)`，`∂H/∂λ<0`；线性时间成本下 `π_opt=c_t/|∂H/∂λ|`；`c_ask<π_opt` 时发问划算，否则减速划算。R68 的 λ_floor 是 U_sem 不可消解时的边界解。

**引理 21（语义不确定性不可被感知替代）** 存在 `U_epi≈0` 但 `U_sem` 高的指代场景与 `U_sem=0` 但 `U_epi` 高的遮挡场景；前者注视/探针对 `H(i)` 零收益，后者语言澄清对 `H(m)` 零收益；故三分必要。

**定理 18（LINGUA 严格包含 R68–R69）** `|I|=1,U_sem=0` 时 `V_∩=V_i`，VGC 即 R69「选模态+认证前缀」；进一步无交互时即 R68 λ_floor 闭环。边界上逐指令相同：安全不让步，效率获「共同前缀」与「减速替代提问」两项 resolution bonus。

**定理 19（权限单调性 ⇒ 语言注入不可越权）** 若每个被接受规格满足 `ℱ(S)⊆Safe_auth` 且硬约束只增不减，则任意语言序列下执行轨迹均满足 Safe_auth；语言对手只能导致拒绝/弃权/任务失败，不能导致不安全服从。证明：对修订归纳 + SSG + 快环独立认证。

**定理 20（双环隔离与无突变）** 规格在轨迹边界原子换装，快环关于快照分段常数；换装满足位移/速度连续（R68 定理 15），无控制突变；LLM 故障不进入实时路径。

**定理 21（非对称证据的安全下界）** 「收缩单边、扩张多边」下，投毒纠正导致的不安全扩张概率 ≤ `δ_p·ρ^{K−1}+ε_σ`（R69 引理 18）；停止类输入 100% 生效——**刹车永远可信，油门需要多数票**。

## 7. 本轮最大风险

**一句话**：LINGUA-RAS 的全部安全性都押在「解释集合 `I(ℓ)` 足够完整」这一前提上——**若指令编译器漏掉了那个真正的解释，可行核交集会把系统稳稳地引到一个「自洽但错误」的共同前缀，然后在分岔口自信承诺：硬约束不越、权限单调、证书全绿，却做了用户从未要求的事；而 G_r 也抓不到它，因为结果与那份错误的规格完美吻合。** R69 是「问错比不问更危险」，R70 是「把错的听懂当成了懂」——一个闭合的证据体系会为一次编译错误背书。

**次级风险与缓解**：交集退化为「不动」（V_∩^+ + 进展下界 η）；解释集开放不可枚举（保留弃权/交接、高 stakes 不耗尽可选性预算、完整性当覆盖问题审计，E313）；语言渐变与注入（权限单调 + 再冻结 + 非对称证据，定义 322–323、定理 19/21）；慢环 LLM 抖动/版本漂移（规格哈希 + 快照隔离 + 故障保持最保守包络）；G_r 自身幻觉（作为证据而非定论，多源一致，仅触发标记与求助）；`c_ask` 主观（用户画像 + 在线标定 + 审计，E305）。
