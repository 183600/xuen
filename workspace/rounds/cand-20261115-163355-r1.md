# 第 8 轮（新灵感循环第 1 轮；本轮灵感：「评测指标」×「Gazebo」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 69–76；实验 E513–E525）。
> 本轮纪律：**先证明指标可测，再谈指标可用**。把 Gazebo 从“训练环境”升级为“指标的计量实验室”：每个指标必须先经过**接地（grounding）→ 保真证书（fidelity certificate）→ 有效性审计（validity audit）**三道关卡，才允许进入 OTL 与奖励函数。

## 0. 直觉与动机

**灵感 1（评测指标 → 指标不是数字，而是测量仪器）**
直觉：第 7 轮的 M₀–M₃ 本质上是一套“价值声明”，但一个量要成为科学意义上的**评测指标**，至少要回答三个问题：**可观吗**（传感器能否测到）、**可辨识吗**（测到的量是否就是它声称的能力）、**可迁移吗**（仿真里成立，真机是否成立）。现有框架直接假设这三件事都成立，这是评测指标最大的隐性漏洞。因此本轮把指标重新定义为**带不确定度的测量仪器**：输出 `m̂ᵢ ± εᵢ`，而不是一个点估计；无法给出误差界的指标，只能当日志，不能当判据。

**灵感 2（Gazebo → 指标风洞，而非训练场）**
直觉：Gazebo 的真正价值不只是 sim-to-real 训练，而是提供了真机难以同时获得的三样东西：**可复现**（固定种子可逐位重放）、**可反事实**（只改摩擦/延迟/噪声，其余不变）、**可全观测**（接触力、关节力矩、碰撞事件、精确位姿都能拿到）。这三样恰好是给“评测指标”做计量学校准所需的三件套。因此提出 **Gazebo 指标风洞（Metric Wind Tunnel）**：先在仿真中把指标“吹”到可测、可辨识、可迁移，再允许上线。

**交叉直觉**：两个灵感真正的耦合点不是“在 Gazebo 里跑实验”，而是**用 Gazebo 给指标本身做体检**。指标是“被测对象”，Gazebo 是“测量基准”，于是形成一条新链路：`指标定义 → 遥测接地 → 保真证书 → 反事实审计 → 准入 / 降级`。这把“评测指标”从被动打分器变成可被证伪、可被校准的主动科学对象。

## 1. 研究问题（轮次升级版）

- **Q1（可观测 / 接地）**：如何把抽象指标 Mᵢ 映射到 Gazebo 遥测通道集合 T，并给出可证明的接地误差界，而不是凭经验挑几个话题？
- **Q2（保真 / 不确定度）**：如何量化 Gazebo 与真机的保真缺口 Δ，并把 Δ 正确传播为每个指标证书的置信区间 εᵢ，而不是假装“仿真等于现实”？
- **Q3（有效性 / 可证伪）**：如何用反事实重放与预注册场景套件审计指标本身（构念效度、内部效度、外部效度），并识别“只存在于仿真中的伪指标”？
- **Q4（安全闭环）**：当保真度不足或指标未通过审计时，如何让 OTL、抓取几何检查、情感奖励权重安全退回 v7，而不是带着坏指标继续优化？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 指标接地（Metric Grounding）**
每个指标 mᵢ 不再直接由公式给出，而由接地算子从遥测张量导出：
```
gᵢ : T_{t:t+H} → (m̂ᵢ, σᵢ, cᵢ)
```
其中 `cᵢ ∈ [0,1]` 为所需通道的覆盖率；`cᵢ < 1` 时指标只能“部分接地”，禁止用于在线适应与奖励加权。

**P11 保真证书（Fidelity Certificate）**
指标输出是区间而非点：
```
εᵢ = Lᵢ · ||Δ||₁ + z_{1−α/2} · σᵢ / √n
mᵢ^true ∈ [m̂ᵢ − εᵢ, m̂ᵢ + εᵢ]      （置信度 1−α）
```
`Lᵢ` 是指标对保真缺口的 Lipschitz 常数；Δ 由五项缺口组成：接触模型、摩擦、通信延迟、传感噪声、执行器动力学。

**P12 评测随机化与预注册（Evaluation Randomization + Preregistration）**
场景套件 `S = {(ξₖ, sₖ, θₖ, dₖ)}` 在实验前固定：场景描述 ξ、种子 s、域参数 θ、难度 d。注意**评测随机化不是训练域随机化**：它要求种子可复现、分布预先声明、统计检验预先注册，防止“挑一个好看的种子/场景”式过拟合。

**P13 指标有效性审计（Metric Validity Audit）**
每个指标需通过三元组审计：
```
V = (V_con, V_int, V_ext)
```
分别对应构念效度（测的是不是目标能力）、内部效度（场景是否隔离因果、混杂是否受控）、外部效度（sim→real 的数值或排序一致性）。再叠加**反事实灵敏度 κᵢ**：对未建模因素越敏感，指标越“脆”，越不应进入决策闭环。

## 3. 与基线的接口（如何退化）

- **遥测织体失效**（Gazebo 不可用 / 话题缺失）⇒ 指标退回 v7 的日志点估计，证书标记 `uncertified`，审计跳过，不进入 OTL；
- **保真证书失效**（Δ 无法估计）⇒ 指标可记录但禁止进入 OTL 与奖励，OTL 冻结为固定 τ，等价 v7 的固定阈值分支；
- **场景套件 / 审计失效** ⇒ 退回 v7 的单一默认场景与手工实验协议；
- **保真门控**：任一指标 `εᵢ > ε_max,ᵢ` ⇒ 该指标降级为“仅诊断”，系统安全退回 v7，而不是用低质量信号自适应。

## 4. 预期贡献

1. **评测指标的计量学框架**：把指标从点估计升级为带保真证书的区间估计，使“指标可信度”本身成为一等公民；
2. **Gazebo 指标风洞**：可复现 + 可反事实 + 全观测的指标校准与压力测试平台；
3. **指标有效性审计**：构念 / 内部 / 外部效度 + 反事实灵敏度的可执行审计流程；
4. **保真门控的在线学习**：OTL 在指标不可信时自动冻结，避免“在错误信号上自适应”；
5. 完整实验矩阵 **E526–E545**：接地、保真、审计、门控、退化、端到端。

## 5. 本轮最大风险

**一句话**：保真缺口 Δ 本身可能无法被可靠观测，导致“保真证书”退化为用仿真给自己打分——形式上有不确定度，实质上仍是循环论证，系统可能优化一个只存在于 Gazebo 的伪指标，并在真机上产生系统性乐观的评测结论。

**定义 530（遥测张量与同步 Telemetry Bundle）**
```
T_t = ( C_t, J_t, X_t, I_t, A_t, E_t )
Ch(T) = { ch : ch 在 [t−H, t] 内有效且 δ(T) ≤ δ_sync }
δ(T) = max_k | t_k − t_ref |
```
其中 C_t 为接触力/力矩序列，J_t 为关节位置/速度/力矩，X_t 为机体与目标位姿，I_t 为 IMU，A_t 为执行器指令，E_t 为任务事件（抓取成功、碰撞、超时）。时钟偏斜超限的通道一律视为缺失，不进入 cᵢ。

**定义 531（指标接地算子 MetricGroundingOperator）**
```
gᵢ(T) = ( m̂ᵢ, σᵢ, cᵢ )
m̂ᵢ = (1/n) Σ_{k=1}^n φᵢ(T_{t_k})
σᵢ = std(φᵢ(T_{t_k})) / √n
```
φᵢ 是第 i 个指标的物理可观测量：M₁ 用接触力峰值与最小间距，M₂ 用轨迹跟踪误差与完成时间，M₃ 用关节平滑度与能耗代理。

**定义 532（保真缺口与保真证书 FidelityCertificate）**
```
Δ ∈ [0,1]⁵,  ||Δ||₁ = Σ_j Δ_j
εᵢ = Lᵢ · ||Δ||₁ + z_{1−α/2} · σᵢ / √n
FidCertᵢ = ( m̂ᵢ, εᵢ, cᵢ, Δ, statusᵢ )
statusᵢ = certified    若 cᵢ = 1 ∧ εᵢ ≤ ε_max,ᵢ
         = degraded     若 cᵢ = 1 ∧ εᵢ > ε_max,ᵢ
         = uncertified  若 cᵢ < 1
```
认证区间 `Iᵢ = [m̂ᵢ−εᵢ, m̂ᵢ+εᵢ]`。只有 `certified` 指标允许进入 OTL 与奖励；`degraded` 仅可诊断；`uncertified` 直接排除。

**定义 533（预注册场景套件 ScenarioSuite）**
```
S = { (ξₖ, sₖ, θₖ, dₖ) }_{k=1}^{K}
θₖ = ( μₖ, latencyₖ, noiseₖ, payloadₖ )
```
ξₖ 为场景模板（平地搬运、斜坡、抓取、动态障碍等），sₖ 为固定种子，θₖ 为域参数（摩擦 μ、延迟、噪声、负载），dₖ 为难度。`R(ξ,s,θ)` 在确定性传感器假设下应逐位可重放；在随机传感器下应同分布可重放。

**定义 534（指标有效性三元组 Validity Triad）**
```
V_con = ρ_spearman( m̂ᵢ , y_expert )          ∈ [−1, 1]
V_int = 1 − Var_confound / Var_total          ∈ [0, 1]
V_ext = 1 − |m̂ᵢ^sim − mᵢ^real| / max(|mᵢ^real|, ε_floor)   ∈ [0, 1]
```
`y_expert` 为专家评分或任务真值；V_int 要求混杂因素（难度、初始位姿、负载）在场景套件中被显式随机化或配对；V_ext 需要一小份真机校准集，不能只靠仿真自证。

**定义 535（反事实灵敏度 Counterfactual Sensitivity）**
```
κᵢ = max_j (1/|S|) Σ_{k} | m̂ᵢ(θₖ + δe_j) − m̂ᵢ(θₖ) | / ( δ · range(mᵢ) )
```
j 遍历“未建模因素”（接触刚度、未标定摩擦、未建模延迟等）。κᵢ 越大，说明指标越依赖仿真伪影，越“脆”。

**定义 536（指标元评测向量 Metric Meta-Evaluation, MES）**
```
MESᵢ = ( ρᵢ, ICCᵢ, AUCᵢ, ECEᵢ, κᵢ )
```
ρᵢ：与任务结局的 Spearman 相关；ICCᵢ：重测信度；AUCᵢ：成功/失败区分度；ECEᵢ：置信度校准误差；κᵢ：反事实脆性。**刻意不压成单标量**，避免用一个新的拍脑袋权重掩盖指标间不可比性；准入采用逐分量阈值与偏序。

**定义 537（保真门控在线阈值 FidelityGatedOTL）**
```
gateᵢ(t) = 1  若 statusᵢ = certified ∧ εᵢ ≤ ε_max,ᵢ
τᵢ(t+1) = clip( τᵢ(t) + η·θ(t), ε_min,ᵢ, ε_max,ᵢ )   若 gateᵢ(t)=1
        = τᵢ(t)                                      否则
```
若连续 `T_freeze` 个周期 gate=0，则 `τᵢ ← τᵢ(0)`，防止用过期阈值长期运行。

**定义 538（GEM 评测闭环与报告）**
```
GEM(S, T, g, FidCert, V, MES) → Report
Report = ( hash(S), {Iᵢ}, effect_sizes, CIs, seeds,
           prereg_hash, adoption_decisions, fallback_events )
```
报告必须包含：套件哈希、每指标区间、效应量与置信区间、全部种子、预注册哈希、准入决定、以及每次退化事件的原因。

**定义 539（指标准入 / 降级 Metric Adoption）**
```
adopt(mᵢ) ⇔ statusᵢ = certified
             ∧ V_con ≥ θ_con ∧ V_int ≥ θ_int ∧ V_ext ≥ θ_ext
             ∧ κᵢ ≤ θ_κ
```
未准入指标降级为 `diagnostic-only`：可写入报告，但不得进入 OTL 阈值、抓取几何判据、奖励权重。

**定义 540（GEM 组合与退化映射）**
```
Φ_GEM = Φ_v7 ∪ { GIF, MGO, FidCert, SSC, MVA, FG-OTL }
fallback(GIF/MGO)   = v7 日志指标
fallback(FidCert)   = v7 固定 τ + 指标仅记录
fallback(SSC/MVA)   = v7 默认场景 + 手工协议
fallback(FG-OTL)    = v7 原始 OTL（并记未认证告警）
```

## 2. 形式化定义（要点）

**定义 495（奖励可逆向性 RewardDecomposer）** - 保留自 v7。本轮增加准入门：
```
R(s,a) = Σᵢ w'_i(s) · rᵢ(s,a) · 1[adopt(mᵢ)]
```
未准入指标权重置零，而不是带着高不确定度继续优化。

**定义 496（软证书 SoftCert）** - 保留自 v7；本轮 SoftCert 的 `σ_Mᵢ` 与 FidCert 的 `εᵢ` 合并为 `max(σ_Mᵢ, εᵢ)`，软约束区间只会更保守，不会更乐观。

**定义 497（MetaWeight）** - 保留自 v7：`w_i(s)=softmax(α·risk(s))_i`；本轮若 `gateᵢ=0`，对应 `w_i` 冻结在上一次认证值。

**定义 521（在线阈值学习 OTL）** - 保留自 v7；本轮由定义 537 包裹，形成 FG-OTL。

**定义 524（情感调节）** - 保留自 v7：`w'_i(s)=softmax(α·risk_i(s)+β·emo(s)·Ṽ_i)_i`；本轮情感模块同样受指标准入约束：若 M₂ 未认证，情感对 M₂ 的增益置零。

**定义 528（抓取命令类型化）** - 保留自 v7；新增仿真接触验证，见定义 494 的增强。

**定义 530–540** - 本轮新增，构成 GEM 的完整计量学层。

import rospy
import message_filters
from dataclasses import dataclass, field
from collections import deque
from copy import replace


@dataclass
class TelemetryBundle:
    t: float
    contacts: list           # [(body_a, body_b, force_xyz, torque_xyz)]
    joints: dict             # {name: (pos, vel, torque)}
    base_pose: tuple         # (p_xyz, q_xyzw)
    target_pose: tuple
    imu: dict
    cmd: dict
    events: list             # ['grasp_ok', 'collision', 'timeout']
    channels: set
    skew: float


class GazeboInstrumentationFabric:
    TOPICS = {
        'model_states': '/gazebo/model_states',
        'link_states':  '/gazebo/link_states',
        'joint_states': '/joint_states',
        'imu':          '/imu/data',
        'contacts':     '/gazebo/contacts',
        'cmd':          '/cmd_vel',
        'clock':        '/clock',
    }

    def __init__(self, window=50, max_skew=0.005):
        self.window = window
        self.max_skew = max_skew
        self.buf = {k: deque(maxlen=window) for k in self.TOPICS}
        self.subs = []
        for key, topic in self.TOPICS.items():
            self.subs.append(rospy.Subscriber(topic, rospy.AnyMsg, self._make_cb(key)))

    def _make_cb(self, key):
        def cb(msg):
            stamp = getattr(getattr(msg, 'header', None), 'stamp', rospy.Time.now())
            self.buf[key].append((stamp.to_sec(), msg))
        return cb

    def collect(self, t_now):
        usable = {}
        skews = []
        for key, dq in self.buf.items():
            while dq and t_now - dq[0][0] > self.window / 50.0:
                dq.popleft()
            if dq:
                usable[key] = dq[-1][1]
                skews.append(abs(t_now - dq[-1][0]))
        skew = max(skews) if skews else float('inf')
        channels = set(usable) if skew <= self.max_skew else set()
        return TelemetryBundle(
            t=t_now,
            contacts=self._parse_contacts(usable.get('contacts')),
            joints=self._parse_joints(usable.get('joint_states')),
            base_pose=self._parse_pose(usable.get('model_states'), 'base'),
            target_pose=self._parse_pose(usable.get('model_states'), 'target'),
            imu=self._parse_imu(usable.get('imu')),
            cmd=self._parse_cmd(usable.get('cmd')),
            events=self._parse_events(usable.get('contacts')),
            channels=channels,
            skew=skew,
        )

    # 解析函数按 gazebo_ros_pkgs 的实际消息字段实现，此处省略细节
    def _parse_contacts(self, msg): return []
    def _parse_joints(self, msg): return {}

    def _parse_imu(self, msg): return {}
    def _parse_cmd(self, msg): return {}
    def _parse_events(self, msg): return []


# IP-352 MetricGroundingOperator：指标接地
class MetricGroundingOperator:
    REQUIRED = {
        'M1_safety':     {'contacts', 'joint_states', 'model_states', 'cmd'},
        'M2_efficiency': {'model_states', 'joint_states', 'clock'},
        'M3_grasp':      {'contacts', 'joint_states', 'model_states'},
    }

    def __init__(self, range_hint=None):
        self.range_hint = range_hint or {'M1_safety': 1.0, 'M2_efficiency': 1.0, 'M3_grasp': 1.0}

    def coverage(self, T, metric):
        req = self.REQUIRED[metric]
        return len(req & T.channels) / len(req)

    def ground(self, T, metric, window):
        c = self.coverage(T, metric)
        samples = [self._phi(T_k, metric) for T_k in window]
        if not samples:
            return float('nan'), float('inf'), c
        m_hat = float(np.mean(samples))
        sigma = float(np.std(samples) / np.sqrt(len(samples)))
        return m_hat, sigma, c

    def _phi(self, T, metric):
        if metric == 'M1_safety':
            force = max([np.linalg.norm(f) for _, _, f, _ in T.contacts] or [0.0])
            return 1.0 / (1.0 + force)                      # 归一化安全裕度
        if metric == 'M2_efficiency':
            return 1.0 / (1.0 + self._tracking_error(T))    # 归一化跟踪效率
        if metric == 'M3_grasp':
            return 1.0 if 'grasp_ok' in T.events else 0.0
        raise ValueError(metric)

    def _tracking_error(self, T):
        p, _ = T.base_pose
        q, _ = T.target_pose
        return float(np.linalg.norm(np.asarray(p) - np.asarray(q)))


# IP-353 FidelityCertificate：保真证书
@dataclass
class FidelityGap:
    contact: float = 0.05
    friction: float = 0.10
    latency: float = 0.05
    noise: float = 0.02
    actuator: float = 0.05

    def l1(self):
        return self.contact + self.friction + self.latency + self.noise + self.actuator


@dataclass
class FidCert:
    metric: str
    m_hat: float
    eps: float
    coverage: float
    gap: FidelityGap
    status: str = 'uncertified'
    alpha: float = 0.05
    z: float = 1.96

    def interval(self):
        return (self.m_hat - self.eps, self.m_hat + self.eps)


class FidelityCertificateBuilder:
    def __init__(self, L, eps_max):
        self.L = L                      # {metric: Lipschitz 常数}
        self.eps_max = eps_max          # {metric: 允许半宽}

    def build(self, metric, m_hat, sigma, coverage, gap, n):
        eps = self.L[metric] * gap.l1() + 1.96 * sigma / np.sqrt(max(n, 1))
        if coverage < 1.0:
            status = 'uncertified'
        elif eps <= self.eps_max[metric]:
            status = 'certified'
        else:
            status = 'degraded'
        return FidCert(metric, m_hat, eps, coverage, gap, status)


# IP-354 ScenarioSuiteCompiler：预注册场景套件
@dataclass(frozen=True)
class Scenario:
    name: str
    seed: int
    friction: float
    latency_ms: float
    noise: float
    payload_kg: float
    difficulty: int
    layer_target: str


class ScenarioSuiteCompiler:
    def __init__(self, layer_targets=('M1_safety', 'M2_efficiency', 'M3_grasp')):
        self.layer_targets = layer_targets

    def compile(self, K=60, master_seed=20261115):
        rng = np.random.default_rng(master_seed)
        suite = []
        for k in range(K):
            layer = self.layer_targets[k % len(self.layer_targets)]
            suite.append(Scenario(
                name=f'scene-{k:03d}',
                seed=int(rng.integers(0, 2**31 - 1)),
                friction=float(rng.uniform(0.4, 1.2)),
                latency_ms=float(rng.uniform(0.0, 20.0)),
                noise=float(rng.uniform(0.0, 0.05)),
                payload_kg=float(rng.uniform(0.0, 3.0)),
                difficulty=int(rng.integers(1, 6)),
                layer_target=layer,
            ))
        return suite

    def coverage(self, suite):
        layers = len({s.layer_target for s in suite}) / len(self.layer_targets)
        difficulties = len({s.difficulty for s in suite}) / 5.0
        return layers * difficulties


# IP-355 MetricValidityAuditor：指标有效性审计
class MetricValidityAuditor:
    def __init__(self, thresholds):
        self.th = thresholds  # {V_con, V_int, V_ext, kappa}

    @staticmethod
    def spearman(x, y):
        rx = np.argsort(np.argsort(x))
        ry = np.argsort(np.argsort(y))
        return float(np.corrcoef(rx, ry)[0, 1])

    @staticmethod
    def icc(repeats):
        # repeats: n_subjects × n_repeats
        repeats = np.asarray(repeats, dtype=float)
        grand = repeats.mean()
        ms_between = repeats.shape[1] * ((repeats.mean(axis=1) - grand) ** 2).sum() / (repeats.shape[0] - 1)
        ms_within = ((repeats - repeats.mean(axis=1, keepdims=True)) ** 2).sum() / (repeats.shape[0] * (repeats.shape[1] - 1))
        return float((ms_between - ms_within) / (ms_between + (repeats.shape[1] - 1) * ms_within + 1e-12))

    @staticmethod
    def ece(probs, labels, bins=10):
        probs = np.asarray(probs, dtype=float)
        labels = np.asarray(labels, dtype=float)
        edges = np.linspace(0, 1, bins + 1)
        ece = 0.0
        for lo, hi in zip(edges[:-1], edges[1:]):
            mask = (probs >= lo) & (probs < hi)
            if mask.any():
                ece += mask.mean() * abs(labels[mask].mean() - probs[mask].mean())
        return float(ece)

    def counterfactual_sensitivity(self, replay_fn, suite, delta, metric_range):
        vals = []
        for sc in suite:
            base = replay_fn(sc)
            pert = replay_fn(replace(sc, friction=sc.friction + delta))
            vals.append(abs(pert - base) / (delta * metric_range + 1e-12))
        return float(np.mean(vals))

    def audit(self, m_hats, y_expert, y_outcome, repeats, probs, kappa):
        V_con = self.spearman(m_hats, y_expert)
        V_int = float(np.clip(1.0 - np.var(np.asarray(m_hats) - np.asarray(y_outcome)) /
                              (np.var(m_hats) + 1e-12), 0.0, 1.0))
        V_ext = 1.0  # 由真机校准集填入；无真机数据时必须置 0，禁止自证
        return {
            'V_con': V_con,
            'V_int': V_int,
            'V_ext': V_ext,
            'ICC': self.icc(repeats),
            'ECE': self.ece(probs, y_outcome),
            'kappa': kappa,
        }

    def adopt(self, audit):
        return (audit['V_con'] >= self.th['V_con'] and
                audit['V_int'] >= self.th['V_int'] and
                audit['V_ext'] >= self.th['V_ext'] and
                audit['kappa'] <= self.th['kappa'])


# IP-356 FidelityGatedOTL：保真门控在线阈值
class FidelityGatedOTL:
    def __init__(self, otl, eps_max, t_freeze=25):
        self.otl = otl
        self.eps_max = eps_max
        self.t_freeze = t_freeze
        self.frozen_steps = 0

    def step(self, metric, cert, performance):
        gate = (cert.status == 'certified' and cert.eps <= self.eps_max[metric])
        if gate:
            self.otl.update(performance, metric)
            self.frozen_steps = 0
            return 'adapted'
        self.frozen_steps += 1
        if self.frozen_steps >= self.t_freeze:
            self.otl.reset()
            self.frozen_steps = 0
            return 'reset_to_base'
        return 'frozen'


# IP-357 GEM Evaluation Loop：评测闭环
def gem_evaluation_loop(baseline_fn, suite, fabric, grounder, cert_builder,
                        auditor, otl_gate, recorder):
    report = {'suite_hash': hash(tuple(suite)), 'runs': [], 'fallback_events': []}
    for sc in suite:
        T = fabric.collect(t_now=recorder.now(sc))
        window = recorder.window(sc)             # 同步后的 n 帧遥测
        certs = {}
        for metric in ('M1_safety', 'M2_efficiency', 'M3_grasp'):
            m_hat, sigma, cov = grounder.ground(T, metric, window)
            gap = recorder.estimate_gap(sc)
            certs[metric] = cert_builder.build(metric, m_hat, sigma, cov, gap, len(window))

        all_certified = all(c.status == 'certified' for c in certs.values())
        if not all_certified:
            report['fallback_events'].append({
                'scene': sc.name,
                'reason': {k: v.status for k, v in certs.items()},
            })
            # 安全退回 v7：OTL 冻结、未认证指标不进入奖励
            out = baseline_fn(freeze_otl=True, freeze_weights=True)
        else:
            out = baseline_fn(freeze_otl=False, freeze_weights=False)

        report['runs'].append({
            'scene': sc.name,
            'seed': sc.seed,
            'certs': certs,
            'outcome': out,
        })

    report['adoption'] = recorder.audit_report()
    report['effect_sizes'] = recorder.effect_sizes()
    report['prereg_hash'] = recorder.prereg_hash()
    return report

## 4. 推导

**引理 77（接地误差界 Grounding Error Bound）**
设指标真值 `mᵢ^true` 对保真缺口 Δ 满足 Lᵢ-Lipschitz，且 `gᵢ` 无偏、样本独立、方差有限。则对 n 个同步样本：
```
P( |mᵢ^true − m̂ᵢ| ≤ Lᵢ‖Δ‖₁ + z_{1−α/2}σᵢ/√n ) ≥ 1 − α
```
证明要点：`|mᵢ^true − m̂ᵢ| ≤ |mᵢ^true − mᵢ(Δ=0)| + |mᵢ(Δ=0) − m̂ᵢ| ≤ Lᵢ‖Δ‖₁ + |mᵢ(Δ=0) − m̂ᵢ|`。第二项由无偏性与 CLT 给出 `z·σ/√n` 界。这正是定义 532 的构造来源。

**引理 78（证书收缩与不可约下界 Certificate Contraction and Floor）**
增加同步样本 n 或增加通道使 cᵢ→1，可使统计项 `zσᵢ/√n` 单调下降；但证书半宽不可能低于 `ε_floor,ᵢ = Lᵢ‖Δ_irreducible‖₁`，其中 `Δ_irreducible` 是无法通过增加通道消除的系统性建模缺口。
证明：`εᵢ(n) = Lᵢ‖Δ‖₁ + zσ/√n` 关于 n 严格递减且下确界为 `Lᵢ‖Δ‖₁ ≥ Lᵢ‖Δ_irreducible‖₁`。因此“多采样就能让证书无限紧”是错的，必须显式报告不可约缺口。

**引理 79（灵敏度尺度不变性 Scale Invariance）**
定义 535 的 κᵢ 对指标作仿射变换 `mᵢ ↦ a·mᵢ + b (a>0)` 保持不变，因为分子与 `range(mᵢ)` 同比例缩放。
证明：`|m̂ᵢ(θ+δ) − m̂ᵢ(θ)|` 与 `range(mᵢ)` 均乘以 a，商不变。因此 κᵢ 可跨 M₁/M₂/M₃ 比较，不会因为量纲不同而误判“脆性”。

**引理 80（门控安全性 Gating Safety）**
若 `gateᵢ(t)=0` 时 OTL 不更新，则对任意未认证性能信号序列，OTL 的输出轨迹等于其在最后一次认证更新后的冻结轨迹；若冻结超过 `T_freeze`，则回到 `τᵢ(0)`，即 v7 的固定阈值分支。
证明：由定义 537 直接归纳；冻结期间 `τᵢ(t+1)=τᵢ(t)`，超过阈值后执行 `reset`。因此系统不会在坏信号上产生新的自适应行为。

**引理 81（审计对仿真伪影的拦截 Artifact Rejection）**
若某指标对未建模因素 j 的反事实灵敏度 `κᵢ > θ_κ`，则按定义 539 该指标不被准入。设审计对“κᵢ ≤ θ_κ”的判定功效为 `1−β_audit`，则误准入概率不超过 `β_audit`。
证明：准入条件是 κᵢ 的假设检验；在备择假设 κᵢ>θ_κ 下，未能拒绝原假设（误准入）的概率即第二类错误 β_audit。注意这是**条件性**保证：若审计本身无功效（例如从不做反事实重放），则无法拦截。

**引理 82（GEM 退化等价性 Fallback Equivalence）**
关闭 GIF/MGO、FidCert、SSC/MVA、FG-OTL 中任一模块，GEM 的行为分别等价于 v7 的日志指标分支、固定阈值分支、默认场景协议、原始 OTL 分支；四者同时关闭时严格等价于 MetricVoiceGauge v7。
证明：逐一对照定义 540 的 fallback 映射即可；各模块无跨模块隐式状态，故可交换、可独立关闭，满足“单一模块失效 → 平滑降级”。

**引理 83（可复现性 Reproducibility）**
在确定性传感器与固定 `(ξ,s,θ)` 下，`R(ξ,s,θ)` 的指标输出逐位一致；在随机传感器下，相同种子与相同随机流使输出分布一致，其经验分布差异仅来自浮点非确定性与并行调度。
证明：Gazebo 的物理步进在固定步长与固定种子下是确定性映射；随机传感器由显式 RNG 驱动，固定种子即固定随机流。剩余差异可由固定 `OMP_NUM_THREADS` 与容差阈值控制。
