# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环新第 1 轮；本轮灵感：「四足机器人」×「地形适应」）

> 第 60 轮把「场景」提升为阻抗先验、把「意图」锁定为实时约束、把「ROS 消息」隔离为因果证据链，形成了认知驱动的场景-执行闭环。但它有一个隐含前提：**执行体可以在「接触失败」后回退**——机械臂碰一下桌面、滑一下工件，最多是一次低效接触。四足机器人**把这个前提彻底击碎**：一次错误的落脚就是一次跌倒，而跌倒是**不可逆、不可回退、灾难性**的。
>
> 因此本轮的核心命题不是「如何更聪明地适应地形」，而是一个更尖锐的矛盾：
>
> **认知-生存悖论**：地形属性（摩擦 μ、软硬 c、坡度 θ、粗糙度 ρ）**只能通过触地才知道**，但触地**只有在已经知道地形时才安全**。机械臂可以「先失败后学习」，四足机器人**不能**。地形适应必须在「探针」与「生存」之间找到一条数学上可证的相容边界。

## 0. 直觉与动机

**灵感 1（四足机器人 → 触地即探针 Contact-as-Probe）**
直觉：四足机器人每一次落脚，本质上都是一次**物理实验**——脚掌压下去，测到法向力-位移曲线（软硬 c）、切向力-滑移关系（摩擦 μ）、足端姿态（坡度 θ）、冲击方差（粗糙度 ρ）。所以「探针预算」不再是抽象算力，而是**字面意义上的落脚次数**：第 60 轮的 B_probe 在这里变成「我还敢用几只脚去试探未知地形」。关键洞见：**步态本身就是一套采样策略**，步频、步幅、抬腿高度决定了地形信念的采样密度与探索范围。

**灵感 2（地形适应 → 地形信念场 TBF）**
直觉：第 60 轮的场景是**离散标签**（桌面/楼梯/湿滑），但四足机器人脚下的地形是**连续空间场**：同一块地面，左脚在干瓷砖、右脚在薄地毯、前方是斜坡。把「场景先验 π_scene」升级为「地形信念场 b(τ(p))」——对可达落脚流形上的每个位置 p，维护地形属性 τ(p)=(μ,c,θ,ρ) 的信念分布。每落脚一次，就在 p 附近做一个局部贝叶斯更新。关键洞见：**地形不是「识别出来的类别」，而是「落脚点上的连续随机场」**，适应=在场上做在线空间插值 + 局部探测。

**灵感 3（认知-生存悖论 → 探针安全落脚集 PSFS）**
直觉：既然「先探后走」不可行、「先走后探」会摔，那就要求**每一次落脚同时满足两个条件**：(a) 它是有信息量的探针（能降低地形熵）；(b) 在「当前信念置信椭球内最坏的地形」下它仍然不会打滑、不会陷落、不会失稳。这就是**探针安全落脚集**：只从「最坏情况安全」的落脚点里挑「信息增益最大」的。关键洞见：**探索-利用的权衡在四足上不是软约束而是硬约束**——安全是可行域，信息是目标函数；先求可行，再求最优。

**灵感 4（步态节律 → 步态相位契约 GPC）**
直觉：四足的运动是**周期性相位机**：摆动相（swing）要抬腿越过粗糙度 ρ 对应的高度，支撑相（stance）要控制法向力避免压陷软地形。第 60 轮的 ERTC 是「任务级实时契约」，本轮把它升级为**相位索引的周期契约** C_gait(φ)，φ∈[0,1) 是步态相位。关键洞见：**地形约束不是静态的，而是随相位周期切换的**——同一只脚在 swing 和 stance 下面对的是两个不同的安全约束，契约必须在相位边界无缝切换且可调度。

**灵感 5（五灵感合流 → TALEL 闭环 + 跌倒风险预算 FRB）**
直觉：TBF 提供信念、PSFS 提供可行落脚、GPC 提供相位契约、TCIT 提供地形条件阻抗、CEL-PS 提供相位同步证据账本、PFC 提供前瞻落脚承诺、WBSC 提供全身稳定证书。把它们串成 **TALEL（Terrain-Adaptive Locomotion Evidence Loop）**：**信念→落脚→契约→阻抗→执行→触地证据→信念更新**。而第 60 轮的 PCE++++ 认知预算在此必须收敛为**跌倒风险预算 FRB**：把「累计跌倒概率」当成会耗尽的资源，探针越激进消耗越快，一旦低于阈值强制切保守爬行步态。关键洞见：**在四足上，唯一真正重要的预算就是「还能承受多少跌倒概率」**，其余预算都是它的从属。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（地形信念场 TBF）** 地形信念场 B = (M_reach, τ, b, U)。其中：
- **可达落脚流形**：M_reach ⊂ SE(3) 为当前步态下可达的落脚点集合（由腿长、关节限位、质心轨迹决定）
- **地形属性**：τ(p) = (μ(p), c(p), θ(p), ρ(p)) ∈ R⁴，分别为摩擦系数、接触刚度、局部坡度、粗糙度
- **信念场**：b(τ(p)) = N(τ; m(p), Σ(p))，对每个落脚点维护局部高斯信念；未观测点取膨胀先验 N(m₀, Σ₀^infl)
- **观测模型**：一次落脚产生 z = h(τ(p)) + v，其中 h 由足端力/位/IMU 提取（滑移起点估 μ、力-位移斜率估 c、足端姿态估 θ、冲击方差估 ρ）
- **更新算子**：U: b ← Kalman/粒子更新，b'(τ(p)) ∝ b(τ(p))·P(z|τ(p))

**定义 162（探针安全落脚集 PSFS）** 给定置信水平 ε∈(0,1)，置信椭球 T_ε(p) = {τ : (τ−m(p))ᵀΣ(p)⁻¹(τ−m(p)) ≤ χ²₄(ε)}。定义：
- **防滑安全**：safe_slip(p) ⇔ ‖F_t(p)‖ ≤ μ_min(p)·F_n(p)，其中 μ_min(p) = min_{τ∈T_ε(p)} μ
- **防陷安全**：safe_pen(p) ⇔ F_n(p)/c_min(p) ≤ δ_max，其中 c_min(p) = min_{τ∈T_ε(p)} c
- **坡度安全**：safe_slope(p) ⇔ max_{τ∈T_ε(p)} |θ| ≤ θ_max
- **信息增益**：VOI(p) = H[b(τ(p))] − E_{z}[H[b'(τ(p))|z]] − λ_r·r(p) − λ_d·‖p−p_nom‖
- **跌倒风险**：r(p) = ∫_{τ unsafe(p)} b(τ(p)) dτ，即信念落在「会导致打滑/陷落/失稳」区域的质量

则 **PSFS = { p∈M_reach : safe_slip(p) ∧ safe_pen(p) ∧ safe_slope(p) ∧ VOI(p) ≥ θ_voi }**。

**定义 163（步态相位契约 GPC）** 相位契约族 C_gait = {C_gait(φ) : φ∈[0,1)}，步态周期 T_cycle、占空比 d：
- **摆动相**（φ∈[0,1−d)）：C_gait(φ) = (clearance ≥ h_min + κ_ρ·ρ_max, v_foot ≤ v_swing_max, τ_swing ≤ (1−d)T_cycle)
- **支撑相**（φ∈[1−d,1)）：C_gait(φ) = (F_z ≤ F_z_max·c_min/c_nom, slip_margin ≥ μ_min, τ_stance ≤ d·T_cycle)
- **可调度性**：schedulable(C_gait, Legs) ⇔ 每个相位内所有腿的契约工作量之和 ≤ 该相位时长；否则提升占空比或降步频
- **意图耦合**（承接第 60 轮 CIEC）：人类「慢点」→ 降 T_cycle⁻¹、升 d；「稳住」→ 升 d、降步幅

**定义 164（地形条件阻抗张量 TCIT）** 对每条腿 l 的足端空间阻抗 K_l ∈ R^{3×3}、阻尼 D_l ∈ R^{3×3}：
```
K_l = K_base ⊙ G(τ̂(p_l)),   G = diag(g_x, g_y, g_z)
g_x = g_y = clip(μ̂/μ_nom, 0.3, 1.0)          # 越滑→切向越柔，避免激励打滑
g_z = clip(ĉ/c_nom, 0.5, 2.0)·(1 + κ_θ|θ̂|)   # 越软→法向越柔；越陡→越硬
D_l = 2·ζ(ρ̂)·sqrt(K_l ⊙ M_foot)              # 临界阻尼，ζ≥1 保证无超调
```
即**阻抗不再是全局标量，而是随每条腿脚下地形逐腿张量化**；这直接继承并细化了第 60 轮「场景→阻抗先验」的思想。

**定义 165（相位同步触地证据账本 CEL-PS）** 触地证据 e = (t, seq_id, leg_id, cycle_n, φ, hash, z, K_l)。账本维护**步态偏序 DAG** G_gait：
- **因果偏序**：同一 cycle 内 stance 事件先于下一 cycle 的 swing 事件；同 cycle 内按 (φ, leg_id) 全序
- **相位同步校验**：若消息延迟跨越 cycle 边界，必须按 φ 重新锚定，禁止「晚到的 swing 证据」被误并入下一 cycle
- **ROS 恢复**（承接第 60 轮 EPIR）：seq 缺口从边端影子副本 S_shadow 增量重放；重放后仍须通过 G_gait 的偏序一致性校验
- **一致性判据**：CEL_valid ⇔ 哈希匹配 ∧ seq 连续（或可恢复）∧ 偏序无环 ∧ 相位锚定一致

**定义 166（预测性落脚承诺 PFC）** 给定目标方向 g 与地平线 H，落脚规划器 π_plan：
```
(p₁*,...,p_H*) = argmax Σ_k VOI(p_k)  s.t.  p_k ∈ PSFS,  ‖p_{k+1}−p_k‖ ≤ s_max,  WBSC(plan_{1:H})
```
即**在探针安全集内做前瞻信息最优规划**；只有当整条地平线计划通过 WBSC 时才「承诺」执行，否则缩短地平线或退化为保守步态。这解决了「边落边看」导致的短视。

**定义 167（全身稳定性证书 WBSC）** 证书 Cert_wb = (valid, horizon, ε, worst_case)：
- **捕获点条件**：ξ(t) = x_com(t) + ẋ_com(t)/ω ∈ Conv(支撑多边形)，ω=√(g/z_com)，对所有 t∈[t₀, t₀+H·T_cycle] 与所有 τ∈T_ε 成立
- **证书生成**：若存在任一 k 或 τ 使 ξ 越出支撑多边形，则 Cert_wb.valid=false，携带最坏 τ 与失效时刻
- **回退**：invalid ⇒ 降低质心、加宽支撑、切 crawl 步态后重规划

**定义 168（TALEL 闭环与跌倒风险预算 FRB）** 算子 TALEL(M, goal)：
```
① TBF:   b ← U(b, proprio.contact_obs)
② PFC:   plan ← π_plan(goal, b, gait)
③ PSFS:  F ← probe_safe_set(b, M_reach(plan))
④ GPC:   C ← C_gait(φ);  assert schedulable(C, Legs)
⑤ TCIT:  ∀l: (K_l, D_l) ← terrain_conditioned_impedance(τ̂(p_l), K_base)
⑥ WBSC:  cert ← whole_body_stability_certificate(b, plan, H)
⑦ Exec:  gait_exec.step(C);  dispatch(K_l, D_l, cert)
⑧ CEL:   ∀ contact: e ← CEL.append(...); b ← U(b, e.z)
⑨ FRB:   B_fall ← B_fall − r(p);  if B_fall ≤ θ_fall: gait ← crawl
⑩ Return: (plan, cert, B_fall, CEL_valid)
```
其中 **跌倒风险预算** B_fall(t) = B₀ − Σ_{k≤t} r(p_k) + ρ_rec·∫ margin_stable dt，且当 B_fall ≤ θ_fall 强制保守步态。它把第 60 轮 PCE++++ 的 B_scene/B_intent/B_ros/B_exec 统一为**一个生存性主预算 + 三个从属预算**：B_scene→TBF 更新频率、B_intent→相位契约锁定、B_ros→CEL 重传。

### IP-161 TBF（地形信念场）

```python
class TerrainBeliefField:
    def __init__(self, cell=0.05):
        self.cell = cell
        self.mu, self.Sigma = {}, {}
        self.prior_m = np.array([0.6, 800.0, 0.0, 0.01])   # mu,c,slope,rho
        self.prior_S = np.diag([0.09, 4e5, 0.04, 1e-4]) * 4.0  # inflated

    def query(self, p):
        c = self._cell(p)
        m = self.mu.get(c, self.prior_m.copy())
        S = self.Sigma.get(c, self.prior_S.copy())
        return Gaussian(m, S)

    def update(self, p, z):
        c = self._cell(p)
        g = self.query(p); m, S = g.mean, g.cov
        H = self._obs_jacobian(p, m)          # dz/dtau
        R = self._obs_noise(z)
        K = S @ H.T @ np.linalg.inv(H @ S @ H.T + R)
        m = m + K @ (z - self._h(m, p))
        S = (np.eye(4) - K @ H) @ S
        self.mu[c], self.Sigma[c] = m, S
```

### IP-162 PSFS（探针安全落脚集）

```python
def probe_safe_set(tbf, reachable, gait_dyn, eps=0.95, theta_voi=0.05):
    out = []
    for p in reachable:
        g = tbf.query(p)
        T_eps = confidence_ellipsoid(g, eps)
        mu_min = min(tau.mu for tau in T_eps)
        c_min  = min(tau.c  for tau in T_eps)
        th_max = max(abs(tau.slope) for tau in T_eps)
        Fn, Ft = gait_dyn.required_wrench(p)
        ok = (np.linalg.norm(Ft) <= mu_min * Fn
              and Fn / max(c_min, 1e-6) <= DELTA_MAX
              and th_max <= THETA_MAX)
        r = tail_mass_unsafe(g, gait_dyn, p)
        voi = entropy(g) - expected_post_entropy(g, p) - LAMBDA_R * r
        if ok and voi >= theta_voi:
            out.append(Foothold(p, voi=voi, risk=r))
    return sorted(out, key=lambda f: -f.voi)
```

### IP-163 GPC（步态相位契约）

```python
class GaitPhaseContract:
    def __init__(self, T_cycle=0.5, duty=0.6):
        self.T, self.duty = T_cycle, duty

    def contract_at(self, phi, tbf):
        if phi >= 1.0 - self.duty:          # stance
            c_min = tbf.min_stiffness()
            return Contract('stance',
                            Fz_max=FZ_NOM * c_min / C_NOM,
                            slip_margin=tbf.min_friction(),
                            duration=self.duty * self.T)
        else:                                # swing
            rho = tbf.max_roughness()
            return Contract('swing',
                            clearance=H_MIN + K_RHO * rho,
                            duration=(1 - self.duty) * self.T)

    def schedulable(self, legs):
        return sum(c.workload for c in legs) <= self.T
```

### IP-164 TCIT（地形条件阻抗张量）

```python
def terrain_conditioned_impedance(tau_hat, K_base, M_foot):
    mu, c, slope, rho = tau_hat
    g = np.array([np.clip(mu / MU_NOM, 0.3, 1.0),
                  np.clip(mu / MU_NOM, 0.3, 1.0),
                  np.clip(c / C_NOM, 0.5, 2.0) * (1 + K_SLOPE * abs(slope))])
    K = K_base * g
    D = 2.0 * zeta(rho) * np.sqrt(K * M_foot)   # zeta(rho) >= 1
    return K, D
```

### IP-165 CEL-PS（相位同步触地证据账本）

```python
class ContactEvidenceLedger:
    def __init__(self, window=200):
        self.shadow, self.last_seq = {}, 0
        self.dag = GaitDAG()

    def append(self, leg_id, cycle, phase, z):
        e = ContactEvidence(t=time.time(), seq_id=self.last_seq + 1,
                            leg=leg_id, cycle=cycle, phase=phase,
                            z=z, hash=sha256(z))
        self.shadow[e.seq_id] = e
        self.last_seq += 1
        self.dag.add(e)                      # partial order by (cycle, phase, leg)
        return e

    def recover(self, seen):
        missing = [s for s in range(1, self.last_seq + 1) if s not in seen]
        return [self.shadow[s] for s in missing if s in self.shadow]

    def causal_ok(self, e):
        return all(p.seq_id < e.seq_id for p in self.dag.predecessors(e)) \
               and not self.dag.has_cycle()
```

```python
def predictive_foothold_commit(goal, tbf, gait, H=3):
    cand = probe_safe_set(tbf, gait.reachable(goal), gait.dyn)
    plan = beam_search(cand, goal, H, score=lambda seq: sum(f.voi for f in seq),
```

### IP-167 WBSC（全身稳定性证书）

```python
def whole_body_stability_certificate(tbf, plan, H, eps=0.95):
    for k in range(H):
        support = convex_hull(support_points(plan, k))
        for tau in confidence_ellipsoid(tbf.query(plan[k].p), eps):
            xi = capture_point(plan[k].com, plan[k].com_vel)
            if not point_in_polygon(xi, support):
                return Certificate(False, H, eps, worst=(k, tau))
    return Certificate(True, H, eps)
```

### IP-168 TALEL（闭环 + FRB）

```python
def talel_loop(M, goal):
    for obs in M.proprio.contact_observations():
        M.tbf.update(obs.p, obs.tau_hat)

    plan = M.pfc.commit(goal, M.tbf, M.gait)
    C = M.gpc.contract_at(M.phase, M.tbf)
    assert M.gpc.schedulable(M.legs)

    for leg, p in plan.current_footholds().items():
        K, D = terrain_conditioned_impedance(M.tbf.query(p).mean, M.K_base[leg], M.M_foot)
        M.leg_ctrl[leg].set_impedance(K, D)

    cert = M.wbsc(plan, HORIZON)
    if not cert.valid:
        M.gait = conservative(M.gait)
        return talel_loop(M, goal)

    M.gait_exec.step(C)
    for e in M.gait_exec.new_contacts():
        msg = M.cel.append(e.leg, e.cycle, e.phase, e.z)
        M.tbf.update(e.p, e.tau_hat)
        if not M.frb.charge(M.tbf.tail_mass_unsafe(e.p)):
            M.gait = crawl_gait()

    M.cel.sync_to_cloud()
    return M, plan, cert, M.frb.mode()
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TBF | O(\|M_reach\|/cell) 更新 | O(N_cell) | 信念 χ² 校准、地形估计误差 ≤ δ_τ |
| PSFS | O(\|M_reach\|·\|T_ε\|) | O(\|M_reach\|) | 最坏情况防滑/防陷/坡度安全 |
| GPC | O(\|Legs\|) / 相位 | O(1) | 相位可调度、相位边界无约束跳变 |
| TCIT | O(1) / 腿 | O(1) | 临界阻尼 ζ≥1，无超调 |
| CEL-PS | O(1) 追加 / O(W) 恢复 | O(W=200) | 因果偏序无环、相位锚定一致 |
| PFC | O(\|PSFS\|^H) beam | O(H·\|PSFS\|) | 地平线内 WBSC 通过才承诺 |
| WBSC | O(H·\|T_ε\|) | O(H) | 捕获点在支撑多边形内（最坏 τ） |

### IP-161 TBF（地形信念场）

```python
class TerrainBeliefField:
    def __init__(self, cell=0.05):
        self.cell = cell
        self.mu, self.Sigma = {}, {}
        self.prior_m = np.array([0.6, 800.0, 0.0, 0.01])
        self.prior_S = np.diag([0.09, 4e5, 0.04, 1e-4]) * 4.0

    def query(self, p):
        c = self._cell(p)
        return Gaussian(self.mu.get(c, self.prior_m.copy()),
                        self.Sigma.get(c, self.prior_S.copy()))

    def update(self, p, z):
        c = self._cell(p); g = self.query(p); m, S = g.mean, g.cov
        H = self._obs_jacobian(p, m); R = self._obs_noise(z)
        K = S @ H.T @ np.linalg.inv(H @ S @ H.T + R)
        m = m + K @ (z - self._h(m, p))
        S = (np.eye(4) - K @ H) @ S
        self.mu[c], self.Sigma[c] = m, S
```

### IP-162 PSFS（探针安全落脚集）

```python
def probe_safe_set(tbf, reachable, gait_dyn, eps=0.95, theta_voi=0.05):
    out = []
    for p in reachable:
        g = tbf.query(p); T_eps = confidence_ellipsoid(g, eps)
        mu_min = min(t.mu for t in T_eps)
        c_min  = min(t.c  for t in T_eps)
        th_max = max(abs(t.slope) for t in T_eps)
        Fn, Ft = gait_dyn.required_wrench(p)
        ok = (np.linalg.norm(Ft) <= mu_min * Fn
              and Fn / max(c_min, 1e-6) <= DELTA_MAX
              and th_max <= THETA_MAX)
        r = tail_mass_unsafe(g, gait_dyn, p)
        voi = entropy(g) - expected_post_entropy(g, p) - LAMBDA_R * r
        if ok and voi >= theta_voi:
            out.append(Foothold(p, voi=voi, risk=r))
    return sorted(out, key=lambda f: -f.voi)
```

### IP-163 GPC（步态相位契约）

```python
class GaitPhaseContract:
    def __init__(self, T_cycle=0.5, duty=0.6):
        self.T, self.duty = T_cycle, duty

    def contract_at(self, phi, tbf):
        if phi >= 1.0 - self.duty:
            return Contract('stance', Fz_max=FZ_NOM * tbf.min_stiffness() / C_NOM,
                            slip_margin=tbf.min_friction(), duration=self.duty * self.T)
        return Contract('swing', clearance=H_MIN + K_RHO * tbf.max_roughness(),
                        duration=(1 - self.duty) * self.T)

    def schedulable(self, legs):
        return sum(c.workload for c in legs) <= self.T
```

### IP-164 TCIT（地形条件阻抗张量）

```python
def terrain_conditioned_impedance(tau_hat, K_base, M_foot):
    mu, c, slope, rho = tau_hat
    g = np.array([np.clip(mu / MU_NOM, 0.3, 1.0),
                  np.clip(mu / MU_NOM, 0.3, 1.0),
                  np.clip(c / C_NOM, 0.5, 2.0) * (1 + K_SLOPE * abs(slope))])
    K = K_base * g
    D = 2.0 * zeta(rho) * np.sqrt(K * M_foot)   # zeta(rho) >= 1
    return K, D
```

### IP-165 CEL-PS（相位同步触地证据账本）

```python
class ContactEvidenceLedger:
    def __init__(self, window=200):
        self.shadow, self.last_seq = {}, 0
        self.dag = GaitDAG()

    def append(self, leg_id, cycle, phase, z):
        e = ContactEvidence(t=time.time(), seq_id=self.last_seq + 1, leg=leg_id,
                            cycle=cycle, phase=phase, z=z, hash=sha256(z))
        self.shadow[e.seq_id] = e; self.last_seq += 1
        self.dag.add(e)
        return e

    def recover(self, seen):
        missing = [s for s in range(1, self.last_seq + 1) if s not in seen]
        return [self.shadow[s] for s in missing if s in self.shadow]

    def causal_ok(self, e):
        return all(p.seq_id < e.seq_id for p in self.dag.predecessors(e)) \
               and not self.dag.has_cycle()
```

```python
def whole_body_stability_certificate(tbf, plan, H, eps=0.95):
```
