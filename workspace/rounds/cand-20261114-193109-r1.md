# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「意图理解」×「多视角视觉」）

> R69 给系统装上了一张嘴：拿不准就去看、去问、去摸。但它有两个从未被审视的隐含前提：
> 1. **被问的人没有自己的心思。** R69 的 VoI 把人类回答当成一个固定的、诚实的观测通道 p(y|q,o)；它问的是「我该做什么动作来消解我的动作歧义」，而不是「**你到底想要什么**」。一旦对方有目标、会策略性回答、甚至会因为你提问而改变意图，R69 的信息增益就是在一个错误的、非因果的信道模型上算出来的——这正是 R69 自陈「问错比不问更危险」的更深根源。
> 2. **一致就等于可信。** R69 的证据纪律要求「k 个正交证据源一致」，但「正交」只是假设，不是测量。真实的多视角/多传感器共享同一个物理世界，会被同一面反光板、同一次标定漂移、同一个骗子一起带偏。**共同模态下的「一致」不是证据的叠加，而是同一个错误的复读。**
>
> 两个灵感正好补上这两块：
> - **意图理解**：把潜变量从「动作模式 M」扩展到「他者意图 h」；h 是策略性的、由响应策略 σ_t(y|q) 生成、且会被「提问」这一干预改变。VoI 因此必须是对信任集的最坏情况收益，且必须用 do(q) 而非条件概率。
> - **多视角视觉**：把「多个证据源」从不可验证的正交假设，升级为可测量的**共同模态分解**与**有效独立性 n_eff**；并让「换一个视角 / 换一个人问」本身成为一个信息动作——选视角的标准不是「看得更清」，而是「失败模式与现有证据最不相关」。
>
> 核心命题：**把 R69 的 epistemic 不确定性再拆成三层——动作歧义（照旧）、意图歧义（策略性、因果性）、共同模态歧义（证据本身是否独立）——分别用意图类型后验、鲁棒 S-VoI 与 do-query、共同模态证书与有效独立性处置；任何一层无法认证，就逐级退化为 R69，再退化为 R68。** 命名 **PRISM-RAS**（Perspective-Refracted Intent with Shared-mode Monitoring）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**他到底想要什么，而我又怎么知道我看到的是真的**」——不确定性不只可以是刹车或提问，还可以是**换一个视角、并且怀疑所有视角共享的那个盲点**。

## 0. 直觉与动机

**灵感 1（意图理解 → 回答不是测量，是一步棋）**
直觉：R69 把「人回答」建模成传感器读数：给定问题 q，回答 y 的分布 p(y|q,o) 由世界状态决定，问得越多、后验越尖。但人不是温度计。人有一个目标 h，会根据「机器人知道了什么、会拿这个答案做什么」来选择说什么。于是同一个问题，对诚实者、对想促成某结果者、对想看你出丑者，产生的是三种不同的信道。**如果系统假设的是最乐观的信道，它得到的不是信息，而是对方愿意让你得到的那个信念。** 意图理解的第一步不是「读心」，而是承认：回答是一个带类型的策略动作，必须先建模「谁在回答、他为什么这样回答」。

**灵感 2（意图是内生的 → 提问是一次干预，不是一次观测）**
直觉：R69 的 VoI 里，提问只是「获得一个 y」。可现实中提问会**改变**对方：告诉对方你在犹豫，可能让他更坚持、更退让、或开始利用你的犹豫；一个「你还好吗」可能让对方为了不麻烦你而硬撑。这就是观察者效应/表演性（performativity）。因果语言里，这是 P(h|do(q)) 与 P(h|q) 的区别。**当提问本身会移动被估计的量时，关联性的 VoI 会系统性高估收益。** 所以本轮要把「该不该问」升级成「在 do(q) 下、对最坏响应仍为正收益才问」，并显式限制意图漂移。

**灵感 3（多视角视觉 → 一致不是证据，独立才是）**
直觉：多相机看同一场景，通常被认为「更可靠」。但这只在**各视角的误差独立**时成立。反光地面让所有相机看到同一个倒影；同一套标定参数漂移让所有相机一起偏；同一个骗子对三个「独立证人」统一口径。此时 V 个视角里只有 1 份独立信息，甚至 0 份——如果共享偏差足够大，它们会**一致地指向错误**。所以「k 源一致」这条 R69 的纪律必须换成可测的：先估计共享模态 b，再看扣除 b 之后还剩多少**有效独立**信息 n_eff。一致的价值不取决于「有几个源」，而取决于「这些源的失败有多不相关」。

**灵感 4（有效独立性 → 把「正交」从形容词变成可算的量）**
直觉：统计学早就处理过这件事：相关性会让 k 个样本的等效样本量缩水，设计效应 n_eff = k/(1+(k−1)ρ) 是调查抽样与可靠性理论里的标准工具；多视角几何则给出共享偏差的可辨识条件（堆叠视角雅可比的秩）。把两者接起来，就得到一个**可认证的正交性**：不是「我们认为这些源正交」，而是「在给定容差下，共享模态可被分离，且扣除后 n_eff ≥ k*」。这让 R69 的证据纪律第一次有了可证伪的判据。

**灵感 5（视角选择 → 「向谁求证」是一个关于失败相关性的优化问题）**
直觉：R69 的 MINT 在给定候选里选信息量最大的动作，却没问「这个新证据和旧证据会不会一起错」。PRISM 的关键动作是**反相关取证**：与其再问一个和现有证人共享同一偏见的人，不如走到一个几何上真正不同的视角，或问一个利益/信息结构不同的人。下一最佳视角（NBR）因此不是「信息增益最大」，而是「单位共同模态代价下的意图信息增益最大」——**宁可少知道一点，也不要再听一遍同一个错误。**

**灵感 6（安全姿态：新层必须严格包含旧层）**
直觉：R69 最值得继承的不是某个模块，而是一种理论纪律：新层是旧层的**严格泛化**，而不是并列替代。PRISM 同样如此：当只有一个视角、只有一个诚实且不受提问影响的回答者、且共享模态为零时，PRISM 必须逐指令退化为 FLUID-RAS；任何认证失败也沿 R69 → R68 单调退避。否则每加一层「意图/多视角」就多一个需要独立信任的黑箱，最终系统会变成一个既会问又会读心、却没人能证明它安全的怪物。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（PRISM-RAS 总览与三不变式）** PRISM-RAS = (IIT, CMF, SVOI, NBR, ECI, ICG, RKD, AIC-PRISM, TCA, RAS-WM†)。三不变式：
(i) **单视角诚实边界**：当 V=1、信任集为诚实单点、提问非干预（Δ_h=0）时，PRISM 逐指令等价于 FLUID-RAS（R69 定义 293）；
(ii) **共同模态诚实**：任何证据源不得被计数超过 n_eff 次；单一共享模态下的「一致」不得作为意图认证的充分条件；
(iii) **因果交互**：任何查询须在 do(q) 下评估，意图漂移须有界；不可界定时弃权并沿 R69→R68 退避。

**定义 311（意图潜变量与响应类型）** 意图 h ∈ ℋ 是一个结构化潜变量 h = (goal, belief, plan, preference)。回答者类型 t = (h, b_t, c_t)：h 为目标/意图，b_t 为其信息状态（知道什么），c_t 为其成本与激励。系统维护联合后验 P(h, t | o^{1:V}, y^{1:m})。R69 的动作模式 M 只是「机器人该怎么做」的边缘，**不得与 h 混为一谈**：M 是机器人自己的动作歧义，h 是对方的意图。

**定义 312（意图类型追踪 IIT）** 在类型空间上用有界递归层级建模：t^{(0)} 为诚实/朴素响应者；t^{(k)} 认为机器人处于层级 k−1（level-k 心智模型），最高至 k_max（有限深度，防无限回退）。意图后验
P(h | ℰ) = Σ_t P(h | t, ℰ) P(t | ℰ)，其中 t 的先验在与人类交互数据上校准。IIT 输出 (P(h|ℰ), 类型熵 H_type, 层级后验 P(k|ℰ))，供后续 VoI 与校准门使用。

**定义 313（共同模态分解 CMF）** 第 v 个视角的观测分解为
o^v = f_v(s) + b + e^v，  e^v ~ 𝒩(0, Σ_v)，
其中 s 为共享场景状态，b 为**共同模态偏差**（反光、共享标定漂移、协同欺骗、同一套渲染错误），e^v 为视角特异噪声。定义堆叠视角雅可比 J = [J_1; …; J_V]（J_v = ∂f_v/∂s）。共同模态子空间 𝒞 为 b 可被所有视角一致表达的方向集。共同模态残差
r_cm = min_{s,b} Σ_v ‖o^v − f_v(s) − b‖²_{Σ_v^{-1}}。
**可辨识性**：b 与 s 可分离 ⇔ J 在 𝒞 方向上满列秩；若秩亏（如所有相机共线看同一平面镜面），则任意「s 的偏移」都能被「b 的反向偏移」解释，多视角一致**无法**区分二者。

**定义 314（有效独立性与有效样本量 n_eff）** 在扣除共享模态后，若各视角残差两两平均相关为 ρ̄，则
n_eff = V / (1 + (V−1) ρ̄)，  ρ̄ = (2/(V(V−1))) Σ_{i<j} corr(e^i, e^j)。
更严格版本用 Fisher 信息：n_eff = 1ᵀ Ω^{-1} 1 / (1ᵀ Ω^{-1} 1 的对角基准)，Ω 为残差协方差。语义：**V 个视角只值 n_eff 份独立证据**；n_eff=1 时多视角不提供任何冗余增益。

**定义 315（证据认证 ECI）** 证据集 ℰ 是**意图可认证的**，当且仅当同时满足：
(a) n_eff(ℰ) ≥ k*；
(b) r_cm ≤ τ_cm（共享模态可被数据解释而非异常）；
(c) 留一稳定性：去掉任一源后意图后验的 TV 距离 ≤ ε_loo（不存在「单一关键证人」）；
(d) 每个被采纳的回答都通过「表里一致性」（定义 321）。
R69 的「k 个正交源一致」被替换为 (a)–(d)。**关键：一致只提供似然，只有 n_eff 认证过的独立一致才提供置信。**

**定义 316（策略性 VoI S-VoI）** 查询 q ∈ 𝒬，响应策略 σ_t(y|q) 取自信任集 Σ_trust（诚实、含噪、level-k 策略、预算 δ_p 的对抗者）。定义
S-VoI(q) = H(h|ℰ) − sup_{σ ∈ Σ_trust} E_{y~σ(·|q)} H(h|ℰ, y) − c(q) − λ_r·risk(q)。
仅当 S-VoI(q) > 0 才查询。R69 的 VoI 是本定义在 Σ_trust = {诚实单点} 时的退化；最坏情况（sup）保证「误导性回答在最坏情况下也不能把信息增益变成正」。

**定义 317（因果交互与意图漂移）** 查询是干预：系统用 P(h | do(q), ℰ) 而非 P(h | q, ℰ) 评估后验。意图漂移
Δ_h(q) = D_KL( P(h | do(q), ℰ) ‖ P(h | ℰ) )。
若 Δ_h(q) > τ_drift，说明「提问本身改变了被估计的意图」（教学/示弱/打草惊蛇），该查询作废：要么改用不暴露信息状态的中性查询，要么不交互。**这是对 R69「观察者效应」缺失的正式补丁。**

**定义 318（下一最佳视角 NBR）** 候选视角/回答者 v'（相机位姿、机器人位姿、或「问哪一个人」）。评分
NBR(v') = IG_intent(v') / (1 + ρ_cm(v', ℰ)) − c_move(v')，
s.t. v' 的控制指令通过 C-RAS-WM 认证（R69 定义 302），位移 ≤ ε_v。
其中 IG_intent 为对 h 的期望信息增益，ρ_cm(v', ℰ) 为新视角与现有证据的共同模态相关。取 argmax。**方向性结论：反相关取证优于再取证；「问一个和你利益不同的人」可能比「问一个更了解情况但和你共享偏见的人」更值钱。**

**定义 319（意图-模式解耦与预算调度）** 联合后验在给定意图下分解
P(M, h | ℰ) = P(M | h, ℰ) P(h | ℰ)。
两类歧义的处置不同：M 歧义靠**观测/交互**消解；h 歧义靠**通信与博弈**消解。定义调度优先级：先修测量（共同模态，定义 313–315），再问意图（S-VoI），最后选动作模式（R69 AUD）。共享 R69 的信息动作预算（定义 326），避免「用三次提问解决一个共同模态问题」。

**定义 320（意图校准门 ICG）** 意图后验需校准：在留出的交互回合上测 ECE_intent 与类型空间覆盖率。若 ECE_intent > τ_ice 或回答者类型 OOD（落在类型先验支撑之外），⇒ 禁用 S-VoI，退化为 R69 的**观测式** VoI 且信任集取最坏点（往往建议不问）。对应 R69 的 MCG（定义 306）在意图侧的下游版本。

**定义 321（表里一致性检验 RKD）** 把「说的」与「做的」交叉验证：
D_rkd = D_KL( P(h | answers, ℰ) ‖ P(h | actions, ℰ) )。
若 D_rkd > τ_rkd，则要么对方在隐瞒/撒谎，要么机器人的意图模型错了；两者都意味着**不能采纳该回答**，U_epi_intent 保持未消解并退避。R69 用流似然查「行为自洽」（定义 301），本轮用它查「言行自洽」——不依赖信任回答，而依赖回答与轨迹的一致性。

**定义 322（共同模态/意图干扰集 AIC-PRISM）** 在 R69 的 ℰ_FLUID 上新增：
ℰ_CM = { 共同模态欺骗（激光/反光/回放使所有视角一致地错）, 共谋证人（多个源共享同一错误信念）, 视角饥饿（所有视角退化 ⇒ n_eff=1）, level-k 操纵（回答者建模机器人并利用其不确定性） }；
ℰ_intent = { 意图漂移/示弱被利用, 提问引发对抗, 虚假澄清 }。
ℰ_PRISM = ℰ_FLUID × ℰ_CM × ℰ_intent。

**定义 323（三通道异常 TCA）** 在 R69 的 (r_res, Δa) 之外新增共同模态通道 r_cm，构成三元组：
- (r_res↓, Δa↑, r_cm↓)：缓变故障被标定吸收（R69 定义 309 的情形）；
- (r_res↓, Δa↓, r_cm↑)：**共同模态欺骗/共享偏差**（本轮新增的可分离模式）；
- (r_res↑, Δa↑, r_cm↑)：真实故障。
三通道的联合分布用于区分「尺子坏了」「世界被同步篡改」「行为不自洽」。

**定义 324（证书 J_PRISM）** J_PRISM = (J_FLUID, n_eff_min, r_cm_p95, trust_coverage, Δ_h_max, S_VoI_min, ece_intent, rkd_p95, view_diversity, prism_ver)。
Valid ⇔ Valid(J_FLUID) ∧ n_eff ≥ k* ∧ r_cm ≤ τ_cm ∧ Δ_h ≤ τ_drift ∧ ece_intent ≤ τ_ice ∧ 预算未越界。

**定义 325（分级退避，严格单调）** 设 U_ale、U_epi_mode（R69 的动作歧义）、U_epi_intent（意图歧义）：
(i) 意图与模式都在预算内被认证消解 ⇒ λ = λ_floor(U_ale)（完整 resolution bonus）；
(ii) 仅模式消解、意图未认证 ⇒ λ = λ_floor(U_ale + κ·U_epi_intent)，κ∈[0,1] 由意图后验置信决定；
(iii) 共同模态证书失败 / 意图 OOD / 漂移不可界 ⇒ λ = λ_floor(U_ale + U_epi_mode + U_epi_intent)，并冻结意图条件策略，回退 R69（进而 R68）。
**λ 沿 (i)→(iii) 单调不降，安全侧永不弱于 R69。**

**定义 326（视角预算与联合信息动作预算）** 继承 R69 定义 293-ii：单位时间视角移动 ≤ 1、总视角位移 ≤ ε_v、查询 ≤ 1、社交/物理成本 ≤ c_max；NBR、gaze、probe、ask 共享同一预算。优先级为「先修尺子（共同模态），再问人（意图），最后选动作（模式）」。

**定义 327（严格包含的边界条件）** 当 (a) V=1 且无视角动作，(b) Σ_trust={诚实单点}，(c) 查询非干预（Δ_h=0），(d) ρ̄=0 ⇒ n_eff=1 时，IIT 退化为平凡后验、CMF 为空、S-VoI=VoI、NBR 无候选、ECI 退化为 R69 的证据纪律。此时 PRISM ≡ FLUID-RAS 逐指令相同。**R69 是 PRISM 在「单视角、无策略、无共同模态」边界上的退化。**

**定义 328（PRISM-WM† 与异步实时性）** 世界模型扩展他者意图状态 h 与共同模态 b，但实时控制环仍执行零学习写操作（继承 R69 定义 276-i）。意图推断与 CMF 以低频（5–10 Hz）异步运行，控制以 1 kHz；S-VoI 在粗类型空间上枚举，认证结果作为低频先验送入高频环。

## 2. 关键算法骨架

```python
# IP-264 IIT：带 level-k 有界递归的意图类型追踪（低频）
class IntentTypeTracker:
    def __init__(self, type_encoder, response_models, k_max=2):
        self.enc, self.sigma = type_encoder, response_models   # t -> sigma_t(y|q)
        self.k_max = k_max

    def update(self, o_views, answers, actions):
        z = self.enc(o_views)                       # 多视角证据编码
        post_t = self._type_posterior(z, answers, actions)   # level-k 混合
        post_h = marginalize(post_t, key="h")
        return post_h, entropy(post_t), post_t      # 后验、类型熵、层级

# IP-265 CMF：共同模态分解 + 有效独立性
def common_mode_factorize(o_views, f, Sigma):
    s_hat, b_hat = fit_shared(o_views, f, Sigma)     # 分离 s 与共享 b
    r_cm = residual_after(o_views, f(s_hat), b_hat, Sigma)
    rho = mean_pairwise_corr(residuals(e_i for i in views)) if len(views) > 1 else 0.0
    n_eff = len(o_views) / (1 + (len(o_views) - 1) * rho)
    identifiable = rank(J_stacked_common) == dim(common_subspace)
    return r_cm, n_eff, identifiable, b_hat

# IP-266 S-VoI：对信任集取最坏情况的鲁棒信息增益
def strategic_voi(q, post_h, trust_set, budget):
    h_before = entropy(post_h)
    worst_after = max(
        expected_entropy(post_h, sigma_t, q)         # sup over possible responders
        for sigma_t in trust_set
    )
    drift = kl_divergence(do_posterior(post_h, q), post_h)   # 定义 317
    if drift > TAU_DRIFT:
        return -inf
    return h_before - worst_after - cost(q) - LAMBDA_R * risk(q)

# IP-267 NBR：反相关取证
def next_best_view(post_h, evidence, candidates):
    best = None
    for v in candidates:
        if not c_ras_wm.certify_view(v) or not budget.allow(v): continue
        ig   = expected_intent_gain(post_h, v)
        rho  = common_mode_corr(v, evidence)         # 定义 318
        score = ig / (1.0 + rho) - move_cost(v)
        if best is None or score > best.score: best = (v, score)
    return best if best and best.score > 0 else None

# IP-268 ECI：可认证的证据独立性（替代「k 源正交一致」）
def certify_evidence(evidence, post_h):
    r_cm, n_eff, ident, _ = common_mode_factorize(*evidence)
    loo  = max(tv_distance(post_h, leave_one_out(post_h, evidence, i))
               for i in range(len(evidence)))
    ok = (n_eff >= K_STAR) and (r_cm <= TAU_CM) and ident and (loo <= EPS_LOO)
    return ok, dict(n_eff=n_eff, r_cm=r_cm, loo=loo, identifiable=ident)

# IP-270 RKD：言行一致性
def revealed_stated_consistency(post_answers, post_actions):
    d = kl_divergence(post_answers, post_actions)
    return d, d <= TAU_RKD

# IP-274 主闭环（继承 R69，仅在意图/共同模态处置处插层）
def PRISM_RAS_round(M, o_views, answers, actions):
    z, o = M.mtm.forward(...)                        # R69 一次前向
    c, U_cal, thr = M.cof.step(...)
    # 0) 低频意图与共同模态（异步结果，此处读缓存）
    post_h, H_type, post_t = M.iit.update(o_views, answers, actions)
    r_cm, n_eff, ident, _ = M.cmf.factorize(o_views)
    # 1) R69 的动作歧义（照旧）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi_mode, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 2) 意图歧义：先修尺子，再问人
    U_intent = entropy(post_h) * sep_intent(post_t)
    q = None
    if not ident or r_cm > TAU_CM:
        v = M.nbr.next_best_view(post_h, evidence=o_views, candidates=M.views)
        if v is not None and M.budget.allow(v):
            o_views = M.execute_view(v)              # 反相关取证（也过安全认证）
            r_cm, n_eff, ident, _ = M.cmf.factorize(o_views)
    if M.icg.trusted(post_h) and U_intent > TAU_INTENT:
        q = argmax_q M.svoi.strategic_voi(q, post_h, M.trust_set, M.budget)
        if q is not None and M.svoi.score(q) > 0 and M.budget.allow(q):
            y = M.execute_query(q)                   # do(q)
            post_h, _, post_t = M.iit.update(o_views, answers + [y], actions)
            U_intent = entropy(post_h) * sep_intent(post_t)
    # 3) 证据认证 + 言行一致
    ev_ok, ev_stat = M.eci.certify_evidence(o_views, post_h)
    d_rkd, rkd_ok = M.rkd.consistency(post_h, actions)
    intent_certified = ev_ok and rkd_ok and (U_intent <= TAU_INTENT)
    # 4) 三通道异常（R69 的 r_res/Δa 之外加 r_cm）
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES) and (r_cm < TAU_CM)
    cm_spoof = (r_cm > TAU_CM) and (n_eff < K_STAR)
    # 5) 分级退避：只有认证过的消解才拿 resolution bonus
    if intent_certified and U_epi_mode <= TAU_EPI:
        U_floor = U_ale
    elif U_epi_mode <= TAU_EPI:
        U_floor = U_ale + KAPPA * U_intent
    else:
        U_floor = U_ale + U_epi_mode + U_intent
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow or cm_spoof or not ident:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))   # 回 R69 最保守
    mode = select_mode(modes, U_epi_mode, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 审计 + 证书
    M.vqa_p.submit_async(q, post_h, n_eff, r_cm, d_rkd, a_hat)
    return k, lam, mode, (U_ale, U_epi_mode, U_intent, ev_stat)
```

## 3. 推导

**引理 19（共同模态的有效样本量）** 设 V 个视角残差等相关（相关 ρ），则关于共享场景 s 的 Fisher 信息至多为独立情形的 1/(1+(V−1)ρ) 倍；等价地 n_eff = V/(1+(V−1)ρ)。因此以「V 源一致」构造的置信若按独立假设计算，会高估 1+(V−1)ρ 倍。系：R69 定义 293-iii 的「k 源一致」在 ρ→1 时退化为「一源」，无论 k 多大。

**引理 20（共同模态下的不可识别性 → 视角移动是必要的）** 若堆叠视角雅可比 J 在共同模态子空间 𝒞 上秩亏，则存在非零 (δs, δb) 使 f_v(s+δs)+b+δb = f_v(s)+b 对所有 v 成立；故任意多「一致」的观测都无法区分 (s+δs, b+δb) 与 (s, b)。系：**再多的同构视角也不能替代一次几何上新的视角**——这为 NBR 提供了必要性证明，也给 R69 的「多问几个源」划出了理论边界。

**引理 21（策略性 VoI 与诚实 VoI 的落差）** 若诚实响应 σ_hon ∈ Σ_trust，则 S-VoI(q) ≤ VoI_hon(q)。且若对抗者的响应在 q 的支撑上可模仿诚实响应（δ_p 足够大），则 S-VoI(q) ≤ 0。系：R69 的乐观 VoI 在存在策略性回答时可能高估任意多；S-VoI 把「问错比不问更危险」从一句自省变成一个可计算的停止条件。

**引理 22（do-query 漂移界）** 若响应策略对机器人信息状态的敏感度有界（Lipschitz 常数 L_s），且查询 q 使机器人信息状态变化 ≤ δ_info(q)，则 ‖P(h|do(q)) − P(h|q)‖_TV ≤ L_s·δ_info(q)。故 Δ_h(q) > τ_drift 当且仅当「提问所暴露的信息状态」足以显著移动意图；此时应改用信息中性查询或弃权。

**定理 18（PRISM 严格包含 FLUID-RAS）** 在 A95–A99 下，PRISM 的期望风险 ≤ FLUID-RAS；当满足定义 327 的边界条件，或 S-VoI(q*) ≤ 0、ICG 越界、n_eff < k*、Δ_h > τ_drift、r_cm > τ_cm 时，两者逐指令相同（定义 325 的分级退避）。因此 FLUID-RAS 是 PRISM 在「单视角、诚实单点、非干预、零共同模态」边界上的退化；安全侧不做任何让步。

**定理 19（意图认证不制造虚假确定性）** 在 A99（信任集覆盖真实响应、共同模态可辨识、类型先验支撑覆盖）下，若 ECI 通过（定义 315），则采纳错误意图的概率 ≤ δ_cm + δ_type + ε_loo，其中 δ_cm 为共同模态欺骗率经 n_eff 折算后的上界，δ_type 为类型模型失配率。系：n_eff 与留一稳定性把「多源一致」的虚假保证替换为可分解的误差预算；任何一个 ε 超界都触发退避而非放行。

**定理 20（视角移动的安全与无突变）** NBR 选出的视角移动经 C-RAS-WM 认证（R69 定义 302）后，其物理风险 ≤ ε_v；视角移动只改变「证据独立性」，不改变任务安全包络；认证失败/超时/视角饥饿时 λ 单调不降地退化为 R69；R69 的提交/换装不变式（定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：PRISM 把 R69 的「问错」风险升级成了「**读懂错**」风险——只要意图类型空间或 level-k 递归深度被设错，最坏情况 S-VoI 就会让系统陷入「**永不开口的多疑瘫痪**」（把一切回答都当成策略欺骗），或者反过来，用一组「彼此独立地错」的多视角证据，为一个共同错误的意图盖上「已认证」的章；共同模态证书只能保证「证据不是同一个错误源的复读」，它**不能**保证「证据指向真实意图」。

**次级风险与缓解**：意图先验失配/level-k 过深（ICG 校准门 + k_max 有界 + OOD 退避）；视角移动本身不安全（NBR 过 C-RAS-WM + 定理 20）；共同模态攻击（ℰ_CM 对抗训练 + TCA 三通道 + n_eff 可证伪）；S-VoI 过度保守导致交互瘫痪（区分「能力不足」与「信任不足」，后者走 R69 观测式 VoI 而非完全沉默）；异步意图层与高频控制不一致（低频先验 + 高频认证 + λ 单调退避）。

**定义 310（总览与三不变式）** PRISM-RAS 十元组；三不变式：单视角诚实边界逐指令退化为 FLUID-RAS；证据源计数不得超过 n_eff；查询须在 do(q) 下评估且意图漂移有界，否则弃权退避。

**定义 311–312（意图潜变量与 IIT）** h=(goal,belief,plan,preference)，类型 t=(h,b_t,c_t)；level-k 有界递归（k ≤ k_max）；后验 P(h|ℰ)=Σ_t P(h|t,ℰ)P(t|ℰ)。M 与 h 不得混淆。

**定义 313–314（CMF 与 n_eff）** o^v=f_v(s)+b+e^v；r_cm 为共享偏差解释后的残差；堆叠雅可比在共同模态子空间满秩才可辨识 s 与 b；等相关下 n_eff=V/(1+(V−1)ρ̄)。

**定义 315（ECI）** 意图可认证 ⇔ n_eff ≥ k* ∧ r_cm ≤ τ_cm ∧ 留一 TV ≤ ε_loo ∧ 言行一致。R69 的「k 源正交一致」被替换为可证伪的四条件。

**定义 316–317（S-VoI 与 do-query）** `S-VoI(q)=H(h|ℰ)−sup_σ E_σ H(h|ℰ,y)−c−λ_r·risk`；仅当 >0 才问；`Δ_h(q)=D_KL(P(h|do(q))‖P(h))`，超界则查询作废。

**定义 318（NBR）** `argmax_{v'} IG_intent(v')/(1+ρ_cm(v',ℰ))−c_move(v')`，s.t. 过 C-RAS-WM 且位移 ≤ ε_v。反相关取证优于再取证。

**定义 319（意图-模式解耦与预算）** `P(M,h|ℰ)=P(M|h,ℰ)P(h|ℰ)`；先修测量（共同模态），再问意图（S-VoI），最后选模式（R69 AUD），共享 R69 信息动作预算。

**定义 320–321（ICG 与 RKD）** ECE_intent 越界或类型 OOD ⇒ 禁用 S-VoI；`D_rkd=D_KL(P(h|answers)‖P(h|actions))` 超界 ⇒ 不采纳回答、保持未消解。

**定义 322–323（AIC-PRISM 与 TCA）** ℰ_PRISM=ℰ_FLUID×ℰ_CM×ℰ_intent；三通道 (r_res,Δa,r_cm) 区分「尺子坏」「世界被同步篡改」「行为不自洽」。

**定义 324–325（证书与分级退避）** J_PRISM 并入 n_eff、r_cm、trust、Δ_h、S-VoI、意图校准；λ 沿（完整认证 → 仅模式 → 失败）单调不降，安全侧永不弱于 R69。

**定义 326–328（预算、包含边界、异步）** 视角/查询共享 ≤1 次/单位时间预算；V=1、诚实单点、Δ_h=0、ρ̄=0 时 PRISM≡FLUID-RAS；意图与 CMF 低频异步（5–10Hz），控制环 1kHz 零学习写操作。

```python
# IP-264 IIT：带 level-k 有界递归的意图类型追踪（低频异步）
class IntentTypeTracker:
    def update(self, o_views, answers, actions):
        z = self.enc(o_views)
        post_t = self._type_posterior(z, answers, actions)   # level-k 混合, k<=k_max
        return marginalize(post_t, "h"), entropy(post_t), post_t

# IP-265 CMF：共同模态分解与有效独立性
def common_mode_factorize(o_views, f, Sigma):
    s_hat, b_hat = fit_shared(o_views, f, Sigma)            # 分离 s 与共享 b
    r_cm = residual_after(o_views, f(s_hat), b_hat, Sigma)
    rho  = mean_pairwise_corr(residuals(o_views))
    n_eff = len(o_views) / (1 + (len(o_views)-1) * rho)     # 设计效应
    ident = rank(J_stacked_common) == dim(common_subspace)  # 可辨识秩检验
    return r_cm, n_eff, ident, b_hat

# IP-266 S-VoI：最坏情况策略性信息增益 + do-query 漂移门
def strategic_voi(q, post_h, trust_set, budget):
    if kl_divergence(do_posterior(post_h, q), post_h) > TAU_DRIFT:
        return -inf                                          # 提问会改变意图 => 作废
    worst_after = max(expected_entropy(post_h, s, q) for s in trust_set)
    return entropy(post_h) - worst_after - cost(q) - LAMBDA_R * risk(q)

# IP-267 NBR：反相关取证
def next_best_view(post_h, evidence, candidates):
    best = None
    for v in candidates:
        if not c_ras_wm.certify_view(v) or not budget.allow(v): continue
        score = expected_intent_gain(post_h, v) / (1.0 + common_mode_corr(v, evidence)) - move_cost(v)
        if best is None or score > best.score: best = (v, score)
    return best if best and best.score > 0 else None

# IP-268 ECI：可认证的证据独立性（替代「k 源正交一致」）
def certify_evidence(evidence, post_h):
    r_cm, n_eff, ident, _ = common_mode_factorize(*evidence)
    loo = max(tv_distance(post_h, leave_one_out(post_h, evidence, i)) for i in range(len(evidence)))
    ok = (n_eff >= K_STAR) and (r_cm <= TAU_CM) and ident and (loo <= EPS_LOO)
    return ok, dict(n_eff=n_eff, r_cm=r_cm, loo=loo, identifiable=ident)

# IP-270 RKD：言行一致性（用行为查回答，不信任回答本身）
def revealed_stated_consistency(post_answers, post_actions):
    d = kl_divergence(post_answers, post_actions)
    return d, d <= TAU_RKD

# IP-274 主闭环（继承 R69，仅在意图/共同模态处置处插层）
def PRISM_RAS_round(M, o_views, answers, actions):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    post_h, H_type, post_t = M.iit.update(o_views, answers, actions)     # 低频缓存
    r_cm, n_eff, ident, _ = M.cmf.factorize(o_views)
    # R69 动作歧义
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi_mode, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    U_intent = entropy(post_h) * sep_intent(post_t)
    # 先修尺子：共同模态失败则反相关取证
    if (not ident) or r_cm > TAU_CM:
        v = M.nbr.next_best_view(post_h, o_views, M.views)
        if v is not None and M.budget.allow(v):
            o_views = M.execute_view(v)                                  # 过安全认证
            r_cm, n_eff, ident, _ = M.cmf.factorize(o_views)
    # 再问意图：仅在意图可信且 S-VoI>0 时问
    q = None
    if M.icg.trusted(post_h) and U_intent > TAU_INTENT:
        q = argmax(M.svoi.strategic_voi(q, post_h, M.trust_set, M.budget) for q in M.queries)
        if M.svoi.score(q) > 0 and M.budget.allow(q):
            y = M.execute_query(q)                                       # do(q)
            post_h, _, post_t = M.iit.update(o_views, answers + [y], actions)
            U_intent = entropy(post_h) * sep_intent(post_t)
    # 证据认证 + 言行一致 + 三通道
    ev_ok, ev_stat = M.eci.certify_evidence(o_views, post_h)
    d_rkd, rkd_ok = M.rkd.consistency(post_h, actions)
    intent_certified = ev_ok and rkd_ok and (U_intent <= TAU_INTENT)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES) and (r_cm < TAU_CM)
    cm_spoof = (r_cm > TAU_CM) and (n_eff < K_STAR)
    # 分级退避
    if intent_certified and U_epi_mode <= TAU_EPI: U_floor = U_ale
    elif U_epi_mode <= TAU_EPI:                    U_floor = U_ale + KAPPA * U_intent
    else:                                          U_floor = U_ale + U_epi_mode + U_intent
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if slow or cm_spoof or (not ident):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(A, U_cal))          # 回 R69 最保守
    mode = select_mode(modes, U_epi_mode, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_p.submit_async(q, post_h, n_eff, r_cm, d_rkd, a_hat)
    return k, lam, mode, (U_ale, U_epi_mode, U_intent, ev_stat)
```

## 4. 推导

**引理 19（共同模态的有效样本量）** V 个等相关残差（相关 ρ）关于共享场景 s 的 Fisher 信息至多为独立情形的 `1/(1+(V−1)ρ)` 倍，即 `n_eff = V/(1+(V−1)ρ)`。以「V 源一致」按独立假设计算的置信会高估 `1+(V−1)ρ` 倍。系：R69 的「k 源正交一致」在 ρ→1 时退化为「一源」，无论 k 多大。

**引理 20（共同模态不可识别 → 视角移动必要）** 若堆叠雅可比 J 在共同模态子空间 𝒞 上秩亏，存在非零 (δs,δb) 使所有视角观测不变；任意多「一致」观测都无法区分 `(s+δs, b+δb)` 与 `(s,b)`。系：再多的同构视角不能替代一次几何上新的视角——NBR 的必要性证明，也是 R69「多问几个源」的理论边界。

**引理 21（策略性 VoI 落差）** 若诚实响应 ∈ Σ_trust，则 `S-VoI(q) ≤ VoI_hon(q)`；若对抗者可在 q 的支撑上模仿诚实响应，则 `S-VoI(q) ≤ 0`。系：R69 的乐观 VoI 在策略性回答下可任意高估；S-VoI 把「问错比不问更危险」变成可计算的停止条件。

**引理 22（do-query 漂移界）** 若响应策略对机器人信息状态敏感度 Lipschitz 有界 L_s，查询使信息状态变化 δ_info(q)，则 `‖P(h|do(q))−P(h|q)‖_TV ≤ L_s·δ_info(q)`。故 Δ_h(q) > τ_drift ⇔ 提问暴露的信息状态足以显著移动意图，此时应改用中性查询或弃权。

**定理 18（PRISM 严格包含 FLUID-RAS）** A95–A99 下 PRISM 期望风险 ≤ FLUID-RAS；当定义 327 的边界条件成立，或 `S-VoI(q*)≤0`、ICG 越界、`n_eff<k*`、`Δ_h>τ_drift`、`r_cm>τ_cm` 时两者逐指令相同（定义 325 分级退避）。R69 = 「单视角、诚实单点、非干预、零共同模态」边界；安全不让步。

**定理 19（意图认证不制造虚假确定性）** A99 下若 ECI 通过，则采纳错误意图的概率 ≤ `δ_cm + δ_type + ε_loo`，其中 δ_cm 为共同模态欺骗率经 n_eff 折算的上界、δ_type 为类型模型失配率。系：n_eff 与留一稳定性把「多源一致」的虚假保证替换为可分解误差预算，任一超界触发退避而非放行。

**定理 20（视角移动的安全与无突变）** NBR 选出的视角移动经 C-RAS-WM 认证后物理风险 ≤ ε_v；只改变证据独立性、不改变任务安全包络；认证失败/超时/视角饥饿时 λ 单调不降地退化为 R69；R69 提交/换装不变式（定理 15）保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：PRISM 把 R69 的「问错」升级成「**读懂错**」——只要意图类型空间或 level-k 递归深度设错，最坏情况 S-VoI 要么让系统陷入「**永不开口的多疑瘫痪**」（把一切回答都当成策略欺骗），要么用一组「彼此独立地错」的多视角证据，为一个共同错误的意图盖上「已认证」的章；共同模态证书只保证「证据不是同一个错误源的复读」，**不能**保证「证据指向真实意图」。

**次级风险与缓解**：意图先验失配/level-k 过深（ICG 校准门 + k_max 有界 + OOD 退避）；视角移动不安全（NBR 过 C-RAS-WM + 定理 20）；共同模态攻击（ℰ_CM 对抗训练 + TCA 三通道 + n_eff 可证伪）；S-VoI 过度保守导致交互瘫痪（区分能力不足与信任不足：后者走观测式 VoI 而非完全沉默）；异步意图层与高频控制不一致（低频先验 + 高频认证 + λ 单调退避）。
