# 第 62 轮（承接第 61 轮「具身语义进化闭环」ESEC IP-173~182；灵感循环第 1 轮；本轮灵感：「语音交互」×「技术路线图」）

> 第 61 轮构建了 ESEC：USR 统一语义表征、MEL 多模态具身大模型、DMS 多轮对话管理、SRT-Dual 语义-实时双流、PCE+++++ 六元预算。它解决了「语义统一、零样本、对话接地、时序解耦」，但仍有**四个结构性缺口**：
> 1. **语言被降维成文本**：Enc_l 只接收最终文本 L，丢弃了韵律（F0、能量、停顿、语速、jitter）——「轻一点」说得犹豫与说得急促对应完全不同的安全等级；ASR 的部分假设、置信度、延迟被当作噪声，语音作为「接触中唯一能喊停的通道」却没有低延迟通路。
> 2. **对话无流式轮次**：DMS 假设完整话语、干净轮次，缺少 VAD、barge-in（打断）、backchannel（嗯/对）、抢占与回声消除；用户「说到一半改主意」无法被系统感知。
> 3. **空间指代悬空**：「这里」「那个」「再往左一点」不接地到 USR 场景区域；语音意图与场景嵌入之间缺少指代消解。
> 4. **能力堆叠缺少路线图**：ESEC 已累积 10+ 模块、180+ IP，但没有成熟度、依赖、验收门与风险排序——无法回答「先做哪个、何时可部署、在什么证据下才能晋级」，存在**能力蔓延（capability sprawl）**风险。

## 0. 直觉与动机

**灵感 1（语音交互 → 韵律即不确定性 PSR）**
直觉：文本是语音的「去韵律投影」。人类用韵律表达不确定性（拖长、迟疑、填充词）、紧迫性（快、响、高音）、协商性（降调、弱化）。因此「意图」不是一个点，而是 (语义, 韵律) 的联合分布。关键洞见：**把韵律编码为可校准的不确定性/紧迫性标量，直接驱动 DMS 信念与 MEL 的 U_epistemic 修正**——让「怎么说」和「说什么」同等重要，但韵律只调置信度、不改语义真值。

**灵感 2（语音交互 → 语音反射弧 VRA）**
直觉：接触控制中，语音最重要的价值不是「理解复杂命令」，而是「安全否决」——「停！」「松！」「轻点！」。这类命令必须在 ~20ms 内生效，绝不能排队等 200ms 的 MEL。关键洞见：建立**双通道语音**：反射通道（关键词 + 紧迫韵律，<20ms，直接预占 ERTC）与思辨通道（完整语义，经 MEL/DMS/USR）。反射通道只能输出「安全格（safety lattice）」中的单调降风险动作，因此**即使 ASR 误识别也不会放大风险**。

**灵感 3（语音交互 → 流式增量语义锚点 SISA + 轮次管理 STM）**
直觉：ASR 是流式的，部分假设 h_1 ⊑ h_2 ⊑ … 逐步收敛。实时流不必等待最终文本：可用**临时锚点（provisional anchor）**提前给出「乐观的可行性先验」，但安全锁定必须等待承诺锚点（committed anchor）。配合 VAD / barge-in / backchannel，机器人能「边说边理解、被打断即让权」。

**灵感 4（语音交互 → 自噪声感知 ASR SNASR + 指示词接地 DGSG）**
直觉：机器人知道自己的关节速度、力矩、电机电流——也就是**知道自己的噪声谱**。用本体感受预测自噪声 N̂(f,t) 并做谱减/掩蔽，是「具身自知识」对语音识别的独特增益，而非通用 ASR 的堆算力。另一方面，「这里/那个」必须通过注视/手势/场景嵌入接地到 USR 的区域子空间。

**灵感 5（技术路线图 → 能力成熟度路线图 CMR）**
直觉：180+ IP 不是资产而是负债，除非有**依赖 DAG + 成熟度 + 证据门 + 风险排序**。关键洞见：把路线图形式化为「能力成熟度 Markov 决策过程」——状态是各能力成熟度向量与剩余预算，动作是投资某能力冲击下一级门，门通过概率由证据强度决定，回报是达成目标能力的价值减去风险加权成本。路线图不是甘特图，而是**在风险与证据约束下的最优投资策略 π_road**。

**灵感 6（合流 → 语音-路线图共演化治理 VRG）**
直觉：运行时语音遥测（ASR 置信度、反射触发率、打断率、误唤醒率、澄清轮次）应反向更新路线图的风险先验，使「部署证据」驱动「下一步研发排序」。于是形成双层闭环：**毫秒级语音-执行闭环（VESE）** 与 **周/月级能力-路线图闭环（CMR/VRG）**。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（韵律-语义联合表征 PSR）** PSR = (E_pros, E_intent⁺, u_pros, r_pros, κ_pros)。其中：
- **韵律特征**：ρ_t = (F0_mean, F0_std, ΔF0, E_rms, pause_ratio, speech_rate, jitter, shimmer, HNR, VAD_conf) ∈ ℝ^{d_ρ}，d_ρ ≈ 10~32
- **韵律编码器**：E_pros: ℝ^{d_ρ} → ℝ^{d_p}（2 层时序 Conv + GRU，d_p ≈ 64）
- **联合意图嵌入**：intent_emb_t = E_intent(h_t, H_diag) + λ_p·E_pros(ρ_t)，λ_p 可学习
- **认知韵律分**：u_pros = σ(w_uᵀρ_t) ∈ [0,1]（迟疑、拖长、填充词 ⇒ 高）
- **紧迫韵律分**：r_pros = σ(w_rᵀρ_t) ∈ [0,1]（快、响、高 F0、低停顿 ⇒ 高）
- **校准映射**：U_ep^voice = U_ep·(1 + κ_u·u_pros·(1-c_asr))，U_al^voice = U_al·(1 + κ_r·r_pros)，DMS 证据权重 w_t = c_asr·(1 + κ_w·r_pros)
- **保序不变式**：韵律只作用于置信度/紧迫度，不改变 argmax 语义——PSR 对意图分类是保序变换（order-preserving），避免「犹豫被误判为否定」

**定义 174（流式增量语义锚点 SISA）** ASR 流输出 {(h_i, c_i, t_i)}_{i=1..m}，h_i 为第 i 个部分假设，c_i ∈ [0,1]。定义：
- **稳定性**：stab_i = 1 - NED(h_i, h_{i-1})（归一化编辑距离）
- **一致率**：a_i = (1/k)∑_{j=i-k+1}^{i} 1[stab_j ≥ θ_e]，k=3
- **临时锚点**：Anchor^prov_i = (scene_emb, intent_emb(h_i), c_i·a_i, kind=provisional)，当 c_i ≥ θ_prov 提交，**只用于可行性先验与正常数提案，禁止参与安全锁定**
- **承诺锚点**：Anchor^com_i，当 c_i ≥ θ_asr ∧ a_i ≥ θ_stab ∧ VAD=speech_end 时提交，可参与 ERTC 锁定
- **双阈值不变式**：θ_prov < θ_asr（临时更激进），但「安全锁定」必须同时满足承诺锚点 ∧ J_voice_exec 验证——临时/承诺锚点在存储与消费路径上物理隔离（不同队列、不同权限）

**定义 175（语音反射弧 VRA 与语音安全格 VSL）** VRA = (S, Match, Trigger, A_safe, ⊑)。其中：
- **安全词表**：S = {停, 停一下, 松开, 放手, 轻点, 慢点, 起来, 退}（多语言可配）
- **模糊匹配**：编辑距离 ≤ ε_kw 容忍 ASR 错字；双词确认（如「停 停」）可降低误触发
- **触发条件**：keyword∈S ∧ c_asr ≥ θ_reflex ∧ (r_pros ≥ θ_urg ∨ double_word_confirm)
- **延迟契约**：τ_reflex ≤ 20ms（VAD + 匹配 + ERTC 预占），绕过 MEL/DMS/USR
- **语音安全格**：(A_safe, ⊑)，A_safe = {STOP, RELEASE, SOFTEN(α), SLOW(β), HOLD}，a ⊑ a' 当 R(a') ≤ R(a)
- **单调性**：∀a ∈ A_safe，emit 返回 a' = a ⊓ a_current，必有 R(a') ≤ R(a_current)——**反射通道只会降低或保持风险**
- **非对称损失阈值**：θ_reflex = argmin[λ_fa·P(FA) + λ_miss·P(Miss)]，λ_miss ≫ λ_fa（漏「停」不可逆，误「停」可恢复）

**定义 176（流式轮次管理 STM）** STM = (E_speech, T, δ_T, π_barge)。其中：
- **语音事件流**：E_speech = {speech_start, partial, final, speech_end, backchannel, barge_in, overlap}
- **轮次状态**：T_t = (floor_owner ∈ {user, robot, none}, turn_id, overlap_ratio, is_barge_in, prosody_ctx)
- **barge-in 策略**：floor_owner=robot 且检测到用户 speech_start 超过能量/时长阈值 ⇒（i）机器人语音 ducking；（ii）若正在物理执行则 ERTC 进入「预占待命」；（iii）DMS 提升中断优先级并丢弃过期 C_pending
- **backchannel 判定**：短时（<300ms）、低能量、词表 {嗯, 对, 好, 继续} ⇒ 不转移话语权，仅更新韵律上下文
- **让权保证**：用户发起 barge-in ⇒ floor_owner 在 τ_barge ≤ 100ms 内转移给用户

**定义 177（自噪声感知 ASR SNASR）** SNASR = (g_θ, M, w_snr)。其中：
- **自噪声预测**：N̂(f,t) = g_θ(P_t, P_{t-1}, a_t)，P 为本体感受（关节位置/速度/力矩），a_t 为执行命令
- **语音增强**：Ŝ(f,t) = M(f,t) ⊙ X(f,t)，M = |X|² / (|X|² + |N̂|² + ε)（Wiener 型掩蔽）
- **自噪声感知注意力**：ASR 编码器对时频块 (f,t) 施加权重 w(f,t) = σ(SNR̂(f,t)/τ_snr)，低 SNR 块降权
- **有界增益**：当谱预测误差 ‖N̂-N‖ ≤ δ_N 时，增强后 SNR 提升 ≥ Δ_SNR，且 WER 不高于无增强基线

**定义 178（指示词空间接地 DGSG）** 指代表达 R = {deictic: 这里/那里/这个/那个, comparative: 再左/再轻, anaphoric: 它/刚才那个}。接地函数：
```
G: (h_t, gaze_t, gesture_t, scene_emb_t) → r ⊆ R_scene
grounded_intent_emb = E_intent(h_t) ⊙ Mask(r) + E_scene(r)
候选后验 p(r_i)（由注视/手势/空间先验融合）；
若 max_i p(r_i) < θ_ground：DMS 发起澄清，优先询问 VOI 最大的候选
```
通过 region token 将 r 映射到 ℝ^d_us，保证「语言指代」与「场景语义」在同一空间运算。

**定义 179（能力成熟度路线图 CMR）** 能力图 G = (V, E)。其中：
- **能力节点**：v ∈ V（对应 IP/模块），成熟度 m_v ∈ M = {L0 概念, L1 仿真, L2 台架, L3 闭环仿真, L4 现场, L5 产品}
- **属性**：TRL_v、证据集 Ev_v、风险 ρ_v ∈ [0,1]、成本 c_v(m)
- **依赖边**：v → v' 表示 v 未达 L2 则 v' 不可进入 L3（集成依赖）
- **证据门**：Gate_v(m→m+1, Ev) ∈ {pass, fail, inconclusive}，由对应实验（E 编号）指标与统计显著性判定；p_v(m) = P(Gate=pass | 证据强度 e_v)
- **目标能力集**：V*，价值 value_v
- **评价指标**：风险调整完成时间 RACT = E[max_v τ_v] + λ_ρ·∑_v ρ_v·1[v∉达成]；部署就绪度 DR = ∑_{v∈V*} value_v·1[m_v ≥ L4] / ∑ value_v

**定义 180（路线图门控自动机 RGT）** R_t = (m-vector, B_road, Ev, ρ 后验)。转移：投资 v ⇒ 尝试门 m_v→m_v+1，结果 ~ Bernoulli(p_v(m_v))；成功 m_v++ 并消耗 c_v，失败消耗 γ·c_v（部分沉没）并更新 ρ_v。这是随机最短路径/MDP：π_road: R → V。无环依赖 DAG 上可用动态规划精确求解；大规模用 VOI 贪心近似。B_road 为项目级验证预算，与运行时 B_cog7 通过「验证成本 ↔ 运行时预算」换算。

**定义 181（PCE++++++：七元认知-语音预算）** B_cog7 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_voice)。其中：
- **B_voice** = (ASR_freq, VAD_latency_max, Prosody_ops, Reflex_budget, Bargein_budget, SNASR_ops)
- **成本扩展**：cost_cog7 = cost_cog5 + λ_voice·(ASR_latency/τ_asr + N̂_cost/τ_snasr + P_reflex·1[triggered])
- **降级**：B_voice 耗尽 ⇒ 思辨通道降级为「关键词 + 韵律」，反射通道保留；再耗尽 ⇒ 仅保留 VRA 安全通道，禁止新约束提案（保守冻结）。**安全通道永不降级**
- **B_road** 独立：门控验证预算，耗尽 ⇒ 路线图冻结在已验证最高成熟度（不虚报 DR）

### IP-183 PSR（韵律-语义联合表征）

```python
class ProsodySemanticRepresentation:
    def __init__(self, d_rho=16, d_p=64, d_us=256):
        self.prosody_enc = ProsodyEncoder(d_rho, d_p)
        self.intent_enc = IntentEncoder(d_us)
        self.u_head = nn.Linear(d_rho, 1)
        self.r_head = nn.Linear(d_rho, 1)
        self.lambda_p = nn.Parameter(torch.tensor(0.3))
        self.kappa_u, self.kappa_r, self.kappa_w = 0.5, 0.3, 0.4

    def extract(self, audio, sr=16000):
        f0 = estimate_f0(audio, sr)
        rho = torch.tensor([
            f0.mean(), f0.std(), f0.diff().abs().mean(),
            rms(audio), pause_ratio(audio), speech_rate(audio),
            jitter(f0), shimmer(rms(audio)), hnr(audio), vad_conf(audio)
        ])
        return rho

    def encode(self, text, history, rho):
        base = self.intent_enc.encode(text, history)
        p_emb = self.prosody_enc(rho)
        intent_emb = base + self.lambda_p * p_emb
        u_pros = torch.sigmoid(self.u_head(rho)).item()
        r_pros = torch.sigmoid(self.r_head(rho)).item()
        return intent_emb, u_pros, r_pros

    def calibrate(self, U_ep, U_al, c_asr, u_pros, r_pros):
        U_ep_v = U_ep * (1 + self.kappa_u * u_pros * (1 - c_asr))
        U_al_v = U_al * (1 + self.kappa_r * r_pros)
        w_evid = c_asr * (1 + self.kappa_w * r_pros)
        return U_ep_v, U_al_v, w_evid
```

### IP-184 SISA（流式增量语义锚点）

```python
class StreamingIncrementalAnchor:
    def __init__(self, usr, psr, theta_prov=0.5, theta_asr=0.8,
                 theta_stab=0.85, k=3, theta_e=0.9):
        self.usr, self.psr = usr, psr
        self.theta_prov, self.theta_asr = theta_prov, theta_asr
        self.theta_stab, self.k, self.theta_e = theta_stab, k, theta_e
        self.hyps, self.stab_win = [], []
        self.vad_state = 'silence'

    def on_partial(self, h_i, c_i, scene_emb, rho):
        if self.hyps:
            stab = 1 - norm_edit_distance(h_i, self.hyps[-1][0])
            self.stab_win.append(1.0 if stab >= self.theta_e else 0.0)
        self.hyps.append((h_i, c_i, time.time()))
        a_i = sum(self.stab_win[-self.k:]) / max(1, len(self.stab_win[-self.k:]))
        intent_emb, _, _ = self.psr.encode(h_i, [], rho)

        if c_i >= self.theta_prov:
            prov = SemanticAnchor(intent_emb, scene_emb, c_i * a_i,
                                  kind='provisional', ts=time.time())
            self.usr.write_provisional(prov)          # 仅可行性先验，无锁定权限

        if (c_i >= self.theta_asr and a_i >= self.theta_stab
                and self.vad_state == 'end'):
            com = SemanticAnchor(intent_emb, scene_emb, c_i * a_i,
                                 kind='committed', ts=time.time())
            self.usr.commit_anchor(com)               # 唯一可参与锁定的锚点
            self.hyps, self.stab_win = [], []
            return com
        return None
```

### IP-185 VRA（语音反射弧 + 安全格）

```python
class VoiceReflexArc:
    SAFETY_LEXICON = {
        'stop': STOP, 'ting': STOP, '松': RELEASE, '放': RELEASE,
        '轻': SOFTEN(0.7), '慢': SLOW(0.5), 'hold': HOLD

        if kw is None:
            return None

            return None

        # 安全格下确界：只允许向更安全方向移动

        assert risk(a_safe) <= risk(current_safety)   # 运行时断言 + 形式验证
```

### IP-187 SNASR（自噪声感知 ASR）

```python
class SelfNoiseAwareASR:
    def __init__(self, noise_net, asr_backbone):
        self.noise_net = noise_net        # g_theta(P_t, P_{t-1}, a_t) -> N_hat(f,t)
        self.asr = asr_backbone

    def predict_noise(self, P_t, P_prev, a_t):
        return self.noise_net(torch.cat([P_t, P_prev, a_t], dim=-1))

    def enhance(self, X, N_hat, eps=1e-6):
        mask = (X.abs() ** 2) / (X.abs() ** 2 + N_hat.abs() ** 2 + eps)
        return mask * X, mask

    def snr_attention(self, S_hat, N_hat, tau_snr=2.0):
        snr_hat = 10 * torch.log10((S_hat.abs() ** 2 + 1e-6) /
                                   (N_hat.abs() ** 2 + 1e-6))
        return torch.sigmoid(snr_hat / tau_snr)

    def transcribe(self, X, P_t, P_prev, a_t):
        N_hat = self.predict_noise(P_t, P_prev, a_t)
        S_hat, mask = self.enhance(X, N_hat)
        w = self.snr_attention(S_hat, N_hat)
        return self.asr(S_hat, attention_bias=w)
```

### IP-189 CMR（能力成熟度路线图，VOI 贪心 + DAG DP）

```python
class CapabilityMaturityRoadmap:
    def __init__(self, G, value, cost, rho, gate_prob):
        self.G, self.value, self.cost = G, value, cost
        self.rho, self.p = rho, gate_prob

    def _deps_ready(self, v, m):
        # v 的每个前置依赖已达到其集成门限
        return all(m[u] >= self.G.nodes[u]['integration_level']
                   for u in self.G.predecessors(v))

    def voi_greedy(self, m, budget, target=V_star):
        plan = []
        while budget > 0:
            best, best_score = None, -1
            for v in self.G.nodes:
                if m[v] >= target.get(v, L5) or not self._deps_ready(v, m):
                    continue
                delta_value = self.value[v] * self.p[v][m[v]]
                expected_cost = self.cost[v][m[v]] * (1 + self.rho[v])
                score = delta_value / max(expected_cost, 1e-6)   # 风险调整 ROI
                if score > best_score:
                    best, best_score = v, score
            if best is None:
                break
            plan.append((best, m[best], m[best] + 1))
            budget -= self.cost[best][m[best]]
            m[best] += 1
        return plan

    def exact_dp_dag(self, topo_order, budget, target):
        # 无环依赖下，按拓扑序做预算维度 DP，得到最优期望价值
        dp = {0: 0.0}
        for v in topo_order:
            new = {}
            for used, val in dp.items():
                for level in range(target.get(v, L5) + 1):
                    c = self._cum_cost(v, level)
                    if used + c <= budget:
                        gain = self.value[v] * level * self.p[v][level]
                        new[used + c] = max(new.get(used + c, 0.0), val + gain)
            dp = new
        return max(dp.values())
```

```python
class VoiceDrivenEmbodiedSemanticLoop:
    def __init__(self, psr, sisa, vra, stm, snasr, dgsg, mel, dms, usr, eeis, ertc, budget):
        self.psr, self.sisa, self.vra, self.stm = psr, sisa, vra, stm
        self.snasr, self.dgsg, self.mel = snasr, dgsg, mel
        self.dms, self.usr, self.eeis, self.ertc = dms, usr, eeis, ertc
        self.budget = budget

    # 反射 tick：与实时流同频或独立高优先级线程
    def reflex_tick(self, audio, P_t, P_prev, a_prev):
        N_hat = self.snasr.predict_noise(P_t, P_prev, a_prev)
        partial, c_asr = self.snasr.transcribe_partial(audio, N_hat)
        r_pros = self.psr.urgency(audio)
        a = self.vra.trigger(partial, c_asr, r_pros, self.ertc.current_safety)
        if a is not None:
            self.ertc.preempt(a)
            self.j_voice.log_reflex(a, partial, c_asr, r_pros)
        return a

    # 语义 tick：~30-100Hz
    def semantic_tick(self, audio, V, T, P, gaze, gesture):
        rho = self.psr.extract(audio)
        partial, c_asr = self.snasr.transcribe_partial(audio, self.snasr.predict_noise(P, P, 0))
        scene_emb = self.usr.latest_scene_emb()
        self.sisa.on_partial(partial, c_asr, scene_emb, rho)

        if self.budget.is_voice_budget_exhausted():
            h_final, c_final = partial, c_asr          # 降级：关键词+韵律
        else:
            N_hat = self.snasr.predict_noise(P, P, 0)
            audio_enh, _ = self.snasr.enhance(audio, N_hat)
            h_final, c_final = self.snasr.transcribe(audio_enh)

        intent_emb, u_pros, r_pros = self.psr.encode(h_final, self.dms.H_diag, rho)
        region = self.dgsg.ground(h_final, gaze, gesture, scene_emb)
        phi, z_scene, pi_intact, (U_ep, U_al) = self.mel.infer(
            V, T, P, h_final, intent_emb, region)
        U_ep_v, U_al_v, w = self.psr.calibrate(U_ep, U_al, c_final, u_pros, r_pros)
        turn = self.stm.update(self.stm.emit_events(audio))
        a_diag, C_pending, b_intent = self.dms.step(
            (U_ep_v, U_al_v), turn, w)
        self.usr.commit_anchor(
            z_scene, self.usr.intent_encoder.encode(b_intent) + self.psr.prosody_enc(rho),
            phi, (U_ep_v, U_al_v))
        return a_diag, turn
```

### IP-183 PSR（韵律-语义联合表征）

```python
class ProsodySemanticRepresentation:
    def __init__(self, d_rho=16, d_p=64, d_us=256):
        self.prosody_enc = ProsodyEncoder(d_rho, d_p)      # 2x Conv1d + GRU
        self.intent_enc = IntentEncoder(d_us)
        self.u_head = nn.Linear(d_rho, 1)
        self.r_head = nn.Linear(d_rho, 1)
        self.lambda_p = nn.Parameter(torch.tensor(0.3))
        self.kappa_u, self.kappa_r, self.kappa_w = 0.5, 0.3, 0.4

    def extract(self, audio, sr=16000):
        f0 = estimate_f0(audio, sr)
        return torch.tensor([
            f0.mean(), f0.std(), f0.diff().abs().mean(),
            rms(audio), pause_ratio(audio), speech_rate(audio),
            jitter(f0), shimmer(rms(audio)), hnr(audio), vad_conf(audio)
        ])

    def encode(self, text, history, rho):
        base = self.intent_enc.encode(text, history)
        p_emb = self.prosody_enc(rho)
        intent_emb = base + self.lambda_p * p_emb
        u_pros = torch.sigmoid(self.u_head(rho)).item()
        r_pros = torch.sigmoid(self.r_head(rho)).item()
        return intent_emb, u_pros, r_pros

    def calibrate(self, U_ep, U_al, c_asr, u_pros, r_pros):
        U_ep_v = U_ep * (1 + self.kappa_u * u_pros * (1 - c_asr))
        U_al_v = U_al * (1 + self.kappa_r * r_pros)
        w_evid = c_asr * (1 + self.kappa_w * r_pros)
        return U_ep_v, U_al_v, w_evid
```

```python
class SelfNoiseAwareASR:
    def __init__(self, noise_net, asr_backbone):
        self.noise_net = noise_net
        self.asr = asr_backbone

    def predict_noise(self, P_t, P_prev, a_t):
        return self.noise_net(torch.cat([P_t, P_prev, a_t], dim=-1))

    def enhance(self, X, N_hat, eps=1e-6):
        mask = (X.abs() ** 2) / (X.abs() ** 2 + N_hat.abs() ** 2 + eps)
        return mask * X, mask

    def snr_attention(self, S_hat, N_hat, tau_snr=2.0):
        snr = 10 * torch.log10((S_hat.abs() ** 2 + 1e-6) /
                               (N_hat.abs() ** 2 + 1e-6))
        return torch.sigmoid(snr / tau_snr)

    def transcribe(self, X, P_t, P_prev, a_t):
        N_hat = self.predict_noise(P_t, P_prev, a_t)
        S_hat, mask = self.enhance(X, N_hat)
        w = self.snr_attention(S_hat, N_hat)
        return self.asr(S_hat, attention_bias=w)
```

### IP-189 CMR（能力成熟度路线图：VOI 贪心 + DAG DP）

```python
class CapabilityMaturityRoadmap:
    def __init__(self, G, value, cost, rho, gate_prob):
        self.G, self.value, self.cost = G, value, cost
        self.rho, self.p = rho, gate_prob

    def _deps_ready(self, v, m):
        return all(m[u] >= self.G.nodes[u]['integration_level']
                   for u in self.G.predecessors(v))

    def voi_greedy(self, m, budget, target):
        plan = []
        while budget > 0:
            best, best_score = None, -1.0
            for v in self.G.nodes:
                if m[v] >= target.get(v, L5) or not self._deps_ready(v, m):
                    continue
                delta = self.value[v] * self.p[v][m[v]]
                exp_cost = self.cost[v][m[v]] * (1 + self.rho[v])
                score = delta / max(exp_cost, 1e-6)      # 风险调整 ROI
                if score > best_score:
                    best, best_score = v, score
            if best is None:
                break
            plan.append((best, m[best], m[best] + 1))
            budget -= self.cost[best][m[best]]
            m[best] += 1
        return plan

    def exact_dp_dag(self, topo_order, budget, target):
        dp = {0: 0.0}
        for v in topo_order:
            new = {}
            for used, val in dp.items():
                for level in range(target.get(v, L5) + 1):
                    c = self._cum_cost(v, level)
                    if used + c <= budget:
                        gain = self.value[v] * level * self.p[v][level]
                        new[used + c] = max(new.get(used + c, 0.0), val + gain)
            dp = new
        return max(dp.values())
```

```python
class VoiceDrivenEmbodiedSemanticLoop:
    def __init__(self, psr, sisa, vra, stm, snasr, dgsg,
                 mel, dms, usr, eeis, ertc, budget):
        self.psr, self.sisa, self.vra, self.stm = psr, sisa, vra, stm
        self.snasr, self.dgsg, self.mel = snasr, dgsg, mel
        self.dms, self.usr, self.eeis, self.ertc = dms, usr, eeis, ertc
        self.budget = budget

    def reflex_tick(self, audio, P_t, P_prev, a_prev):
        """反射路径：独立高优先级线程，动作延迟 <= 20ms"""
        N_hat = self.snasr.predict_noise(P_t, P_prev, a_prev)
        partial, c_asr = self.snasr.transcribe_partial(audio, N_hat)
        r_pros = self.psr.urgency(audio)

        return a

    def semantic_tick(self, audio, V, T, P, gaze, gesture):
        """思辨路径：~30-100Hz"""
        rho = self.psr.extract(audio)
        N_hat = self.snasr.predict_noise(P, P, 0)
        partial, c_asr = self.snasr.transcribe_partial(audio, N_hat)
        scene_emb = self.usr.latest_scene_emb()
        committed = self.sisa.on_partial(partial, c_asr, scene_emb, rho)

        if self.budget.get_voice_mode() == 'reflex_only':
            h_final, c_final = partial, c_asr        # 降级：仅关键词 + 韵律
        else:
            audio_enh, _ = self.snasr.enhance(audio, N_hat)
            h_final, c_final = self.snasr.transcribe(audio_enh)

        intent_emb, u_pros, r_pros = self.psr.encode(
            h_final, self.dms.H_diag, rho)
        region = self.dgsg.ground(h_final, gaze, gesture, scene_emb)
        if isinstance(region, tuple) and region[0] == 'clarify':
            self.dms.request_clarify(region[1])
        phi, z_scene, pi_intact, (U_ep, U_al) = self.mel.infer(
            V, T, P, h_final, intent_emb, region)
        U_ep_v, U_al_v, w = self.psr.calibrate(U_ep, U_al, c_final,
                                               u_pros, r_pros)
        turn = self.stm.update(self.stm.emit_events(audio))
        a_diag, C_pending, b_intent = self.dms.step(
            (U_ep_v, U_al_v), turn, w)
        self.usr.commit_anchor(
            z_scene,
            self.usr.intent_encoder.encode(b_intent) + self.psr.prosody_enc(rho),
            phi, (U_ep_v, U_al_v))
        return a_diag, turn, committed
```
