# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「轮足机器人」×「用户共创」）

> R69 把不确定性一分为二（aleatoric / epistemic），并把「提问」本身做成动作：系统学会向用户求证、向证据求证。但 R69 有两个被悄悄固定住的东西：**（a）它的动作空间 𝒜_task 是单一体（single embodiment / regime），默认「用同一种身体、同一套动力学」执行；（b）它的目标函数是给定的，用户只是「被问的知情人」，不是「写目标的作者」。**
>
> 本轮两个灵感各拆掉一个固定点：
> - **轮足机器人**把「身体」变成**混合离散-连续系统**：滚（wheeled）与走（legged）是两套不同的动力学、不同的约束、不同的安全包络，切换是**离散的、常常不可逆的**。系统必须先回答「我现在该用哪种身体模式」，而且答错可能回不来（在斜坡上贸然切轮/切腿、在高速时收腿）。这把 R69 的「选哪个动作」升级为「**先选哪套动力学，再选动作**」——在带记忆的混合自动机上的决策。
> - **用户共创**把「目标」变成**共同撰写、会漂移、可能自相矛盾**的对象：用户不再只回答是非题，而是改权重、加约束、纠正示范、提新玩法。系统必须回答「**这条用户编辑，是愿望还是危险**」，并在「安全不被编辑权侵犯」的前提下，让目标随用户演化。
>
> 核心命题：**把 R69 的「向谁求证」升级为「与谁共写、以何种身体执行」——用「混合模式图 + 可认证的可逆性感知切换」承载轮足，用「宪法式安全契约 + 可解释拒绝」承载共创，两者通过不可逆性感知的 VoI 耦合；R69 是本轮在『单模式 + 固定目标』边界上的严格退化。** 命名 **CRAFT-RAS**（Co-created Regime-Aware Feasible-Transition Risk-Adaptive Safety：共创目标 × 轮足模式图的可行性认证风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我该向谁求证**」，R70 问「**这是谁的目标、我用哪副身体去实现**」——安全不再只是刹住一个动作，而是守住一次「换身体」的承诺，和一份「谁说了算」的契约。

## 0. 直觉与动机

**灵感 1（轮足 → 身体是一个混合自动机）**
直觉：轮足机器人不是「一种」运动，而是「滚 / 走 / 混合」三种性格共用一副骨架。平地上滚最省最快，台阶上走才稳，过渡区要蹲低、收腿、把轮当脚。危险恰恰集中在**切换**：高速滚动时切腿会前扑，斜坡上切轮会溜坡，空中收腿会失去支撑。人类骑手不会在悬崖边换挡。所以「安全」不能只定义在连续状态上，还必须定义在**离散模式与模式之间的边**上——一个动作在模式 A 里安全，不代表它在「A→B 的瞬态」里安全。→ 需要一个**带认证边的模式图**，而不是一张动作表。

**灵感 2（用户共创 → 目标是一个会变的契约，不是一条给定的线）**
直觉：共创不是「用户填表」，而是用户不断用编辑、示范、纠正、抱怨来写目标：今天要快，明天要稳；照顾老人时不能急刹，搬货时优先续航。这些偏好**非平稳、彼此冲突、且用户自己未必自洽**。更危险的是，用户会把「我想要」误当成「你应该」，用一句「快点」要求系统突破安全边界。→ 目标必须可共写，但**安全必须是用户改不动的宪法条款**；否则共创只是把责任从设计者转移给用户，而不是让系统更安全。

**灵感 3（两个灵感的交点 → 不可逆性把 VoI 变成「先问后跳」）**
直觉：R69 的 VoI 隐含假设动作可恢复——问错了还能再问，走错了还能回来。轮足切换往往不可逆：从平地进入跳跃落地、从直立转入蹲伏、从走切到高速滚，回程代价与风险并不对等。当「选错模式」不可逆时，最优策略不是「一边做一边问」，而是**在可逆窗口里先问清楚、再进行不可逆承诺**——「跳之前先看清楚」。这把 R69 的 value-of-information 升级为 **irreversibility-discounted VoI**，并给出一个排序：可逆时边做边问（退化 R69），不可逆时先问后做。

**灵感 4（安全契约 → 共创不能稀释责任）**
直觉：一旦允许用户改目标，系统很容易把「撞坏了」解释成「用户要求的」，形成**责任稀释**与**规范投机（spec gaming）**：用户只要把「速度权重」推高，系统就「合法地」变激进。解法是把契约分成两层：**可共创的软目标（偏好单纯形内）** 与 **不可共创的硬不变式（安全包络、能量红线、过渡可行性）**；任何编辑先投影到「偏好单纯形 ∩ 安全可行域」，越界即触发可解释拒绝，并留下**双钥授权**（用户意图签名 + 安全证书）的审计痕迹。共创的自由度必须写在契约里，而不是写在解释里。

**灵感 5（轮足 × 共创 的最深矛盾 → 快慢两个时间尺度）**
直觉：用户编辑是「慢」的（分钟到小时），安全过滤是「快」的（毫秒级）。把慢变量直接灌进快回路，等价于给一个稳定控制器持续注入非平稳扰动，可能诱发振荡（用户越想稳，系统越抖；用户越催快，模式切换越频繁）。所以必须显式做**两时间尺度分离**：快回路在给定契约下收缩，慢回路只在「安全可行流形」上移动；并证明慢更新步长满足 Robbins–Monro 条件时，耦合系统既保持契约、又收敛到用户与安全都接受的定点。这正是本轮要回应的核心质疑——**共创会不会把系统搞乱**。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（CRAFT-RAS 总览）** CRAFT-RAS = (HRM, RUQ, CTC, CDG, CREL, CSC, IVoI, XR, SDD, RAG, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **模式切换必须持证**：任一边 (r→r′) 的切换，只有在 CTC 证书有效且驻留时间 ≥ τ_dwell 时放行；
(iii) **安全宪法不可编辑**：用户编辑只能作用于软目标 θ，不能作用于硬不变式集合 𝒮；
(iv) **双钥与可解释**：逼近安全边界的编辑需「用户意图签名 ∧ 安全证书」；任一不可行编辑必须返回最小反事实解释。

**定义 311（混合模式图 HRM）** 模式图 G = (ℛ, E)，顶点 r ∈ ℛ 为运动体制（wheeled / legged / hybrid / 过渡子态），边 e = (r→r′) ∈ E 携带：动力学 f_r、约束 C_r、安全包络 𝒮_r、能量模型、以及切换守卫 guard_e(x) ⊆ 𝒳。系统状态 x_t = (q, v, m_t)，m_t ∈ ℛ 为承诺模式。执行语义为 hybrid automaton：模式内的连续流由 f_{m_t} 给出，边上的离散跳转由 guard_e 触发。

**定义 312（模式后验与模式不确定性）** 给定观测 o，模式后验 p(m|o) 由地形/滑移/坡度分类器给出。模式熵 H_reg = H(m|o)。与 R69 的动作模态不同，H_reg 的支撑是**离散且带承诺成本**的：定义 U_reg = H_reg · g(Δ_guard)，其中 Δ_guard 为相邻模式守卫裕度（离切换边界越近越危险），g 同 R69 的单调可分性因子。

**定义 313（承诺与不可逆性）** 边 e 的不可逆度 ι_e ∈ [0,1]：ι_e = 1 − P(可恢复)，由「回程代价 / 前向代价」与「守卫是否双向可达」估计；若 e 的前向守卫成立而回程守卫在预演时域内不可达，则 ι_e = 1（完全不可逆）。承诺风险 R_commit = Σ_e p(e) · ι_e · ℓ_e，ℓ_e 为切换失败损失上界。

**定义 314（可认证切换 CTC）** 对边 e，存在屏障/可行性证书 B_{r,r′}: 𝒮_r ∩ guard_e → ℝ，满足：(a) 在切换瞬态窗口 [0, T_tr] 内后状态始终 ∈ 𝒮_{r′}（前向不变）；(b) 瞬态峰值风险 ≤ ε_tr；(c) 回退路径在 τ_back 内可达（除非 ι_e 被显式授权）。B 可用控制屏障函数（CBF）或 viability kernel 近似构造。CTC 输出 (valid, T_tr, ε_tr, ι_e)。

**定义 315（无抖振：迟滞与驻留 CDG）** 切换需同时满足迟滞带 h_hys 与最小驻留时间 τ_dwell：只有当守卫在带宽 h_hys 内持续满足 τ_dwell 才提交，且相邻提交间隔 ≥ τ_dwell。二者共同抑制切换边界上的抖振（chattering），避免「滚—走—滚」的高频抽搐。

**定义 316（共创偏好后验 CREL）** 用户偏好 θ ∈ Θ ⊂ ℝ^{d_θ}（速度 / 平稳 / 能耗 / 社交距离等权重）。用户通过编辑 edit、示范 demo、修正 correction、自然语言 nl 提供证据；维护后验 p(θ | ℰ_user)（偏好学习 + 贝叶斯，或由冻结 LLM 将自然语言解析为软证据）。允许非平稳：p_t(θ) 随时间漂移。

**定义 317（宪法式安全契约 CSC）** 契约 = (𝒮_hard, Θ_soft, Π_safe)。𝒮_hard 为不可编辑硬不变式（各模式安全包络、过渡可行性、能量红线、力/位红线）；Θ_soft ⊆ Θ 为软目标可行单纯形；Feasible(𝒮_hard) = {θ : 由 θ 诱导的策略风险 ≤ ε}；Π_safe = proj_{Θ_soft ∩ Feasible(𝒮_hard)}。用户编辑 e 只能生成 θ′ = Π_safe(θ ⊕ e)。Π_safe 幂等、非扩张。

**定义 318（编辑算子与双钥）** 编辑算子 ⊕ 作用于软目标；若投影距离 d(θ⊕e, Θ_soft ∩ Feasible) > τ_edit，视为「逼近/越过安全边界」，需要双钥：Key_U（用户意图签名，含自然语言理由）与 Key_S（CTC 给出的安全证书）同时有效才允许进入边界带；否则拒绝并触发 XR（定义 321）。

**定义 319（模式准入闸 RAG）** 用户可提出新模式 / 新步态 ĝ（共创的极端形式）。新模式必须先在**离线沙箱**中通过 CTC 全边认证与压力测试，才被允许加入 ℛ；在线期间新模式处于隔离区（quarantine），不得接管安全关键状态。模式图的扩展权与执行权分离。

**定义 320（不可逆性感知 VoI，I-VoI）** 对候选信息动作或「等待/探询」g：I-VoI(g) = VoI(g) − c(g) − β · E[ι_{e(g)}] · R_commit，其中 e(g) 为探询后可能触发的模式边。决策序：若存在即将发生的不可逆边且 I-VoI(等待) ≥ 0，则**先探询后承诺**；否则可逆地边做边问（退化 R69）。

**定义 321（可解释拒绝 XR）** 当编辑/请求 e 不可行（投影距离 > τ_xr）时，返回最小反事实 (θ*, r*)：θ* = argmin_{θ∈Feasible} d_W(θ, θ⊕e)，r* 为达成同一意图下最近可行模式；并给出「若坚持 e，最早失效的不变式与失效时域」。最小性由加权距离 d_W 定义。

**定义 322（规范漂移检测 SDD）** 监控 p_t(θ) 的漂移（后验熵、MMD、或变点检测）；漂移超阈则判定「用户模型过期」，暂停用陈旧 θ 驱动激进动作，重触发 CREL。

**定义 323（两时间尺度闭环）** 快时间尺度 k：给定 θ 与 m，运行 R69 的 FLUID 闭环 + CTC 认证；慢时间尺度 n：更新 p(θ)、模式图（仅 RAG 准入）、契约审计。慢步长 α_n 满足 Σα_n = ∞, Σα_n² < ∞。

**定义 324（威胁模型 ℰ_CRAFT）** ℰ_CRAFT = ℰ_FLUID × ℰ_commit × ℰ_coauthor。ℰ_commit：切换瞬态越界、抖振、守卫误判、单边不可逆误授权。ℰ_coauthor：规范投机（推高权重绕过安全）、恶意偏好投毒、越权模式注入、自然语言注入（prompt injection）、责任稀释（把危险行为归因于用户）。

**定义 325（证书 J_CRAFT）** J_CRAFT = (J_FLUID, regime_graph_hash, ctc_valid_rate, dwell_chatter_rate, theta_posterior_hash, projection_distance, dual_key_log, refusal_minimality, drift_flag, craft_ver)。Valid ⇔ Valid(J_FLUID) ∧ 切换零未认证 ∧ 契约未被越权编辑 ∧ 近边界编辑均有双钥。

**定义 326（参与式审计 VQAuditor-C）** 在 R69 的 VQAuditor-I 上增加：编辑是否被正确投影、拒绝是否最小且可懂、用户是否真正知情同意（consent）、慢回路是否偷偷放宽硬不变式。审计结论回灌为 CREL 的信任先验与 CSC 的边界收紧量。

**定义 327（对 R69 的包含）** 当 |ℛ| = 1（无模式切换）、θ 固定（无共创编辑）、且忽略 RAG 时，CRAFT-RAS 逐指令退化为 FLUID-RAS：I-VoI → VoI，CSC → R69 的固定约束，CTC → 空证书。故 R69 是本轮在「单身体 + 固定目标」边界上的严格退化。

## 2. 关键算法骨架

```python
# IP-264 HRM：混合模式图；IP-265 RUQ：模式后验与不确定性
class HybridRegimeModel:
    def __init__(self, regimes, edges):
        self.R, self.E = regimes, edges               # 顶点=体制；边=(guard, iota, f)
    def posterior(self, o):                            # 地形/滑移/坡度 -> p(m|o)
        return softmax(self.terrain_clf(o))
    def uncertainty(self, p, guards):
        return entropy(p) * guard_margin(guards)       # U_reg：越近切换边界越危险

# IP-266 CTC：可认证切换（前向不变 + 瞬态上界 + 回退可达）
def certify_transition(x, e, horizon):
    B = barrier(e.r, e.r2)                             # CBF / viability 近似
    ok_fwd  = all(B(x_t) >= 0 for x_t in rollout(e.f, x, horizon))
    ok_tr   = peak_risk(rollout(e.f, x, horizon)) <= EPS_TR
    ok_back = back_reachable(x, e, TAU_BACK) or e.iota >= IOTA_USER_AUTH
    return ok_fwd and ok_tr and ok_back               # -> (valid, T_tr, eps_tr, iota)

# IP-267 CDG：迟滞 + 驻留，抑制滚/走边界抖振
def dwell_ok(state, e, tau_dwell, h_hys):
    return (state.since_last_commit >= tau_dwell and
            guard_margin_persisted(e, state, h_hys, tau_dwell))

# IP-268 CREL + IP-269 CSC：共创编辑的宪法投影（幂等 + 非扩张）
def apply_edit(theta, edit, contract):
    theta_new  = edit.apply(theta)
    theta_proj = contract.project_safe(theta_new)      # 偏好单纯形 ∩ 安全可行域
    dist = d_w(theta_new, theta_proj)
    if dist > TAU_EDIT and not contract.dual_key(theta_new, edit):
        return None, explain_refusal(theta_new, contract)   # IP-271 XR
    return theta_proj, None

# IP-270 I-VoI：不可逆性折扣的「先问后跳」
def choose_with_irreversibility(p_mode, theta, modes, budget):
    e_next = imminent_edge(p_mode)                     # 即将发生的模式边
    if e_next and e_next.iota > TAU_IRREV:             # 不可逆 -> 先探询
        g = mint_choose(modes, budget)                 # 复用 R69 MINT
        if g is not None and ivol(g, e_next) >= 0:
            return ('elicit_then_commit', g, e_next)
    return ('act_then_ask', mint_choose(modes, budget), None)   # 可逆 -> R69

# IP-277 主闭环：快回路(ms) 与 慢回路(min) 两时间尺度
def CRAFT_ROUND(robot, user, obs):
    # --- 快回路：R69 FLUID + 模式承诺 ---
    p_m   = robot.hrm.posterior(obs)
    m_cur = robot.state.m
    e     = robot.hrm.best_edge(p_m, m_cur)
    ctc   = robot.ctc.certify(robot.state.x, e, robot.horizon) if e else None
    plan  = choose_with_irreversibility(p_m, robot.theta, robot.modes, robot.budget)
    if plan[0] == 'elicit_then_commit' and ctc and ctc.valid:
        robot.mint.execute(plan[1]); robot.mode_commit = plan[2].r2   # 先问后承诺
    elif ctc and ctc.valid and dwell_ok(robot.state, e, TAU_DWELL, H_HYS):
        robot.mode_commit = e.r2                                       # 持证切换
    k, lam, a, U = robot.fluid_step(obs, regime=m_cur)                 # R69 连续动作
    # --- 慢回路：异步、非关键路径 ---
    if user.has_edit():
        theta_p, refusal = apply_edit(robot.theta, user.edit(), robot.contract)
        if refusal: user.notify(refusal)                               # 可解释拒绝
        else:       robot.theta = theta_p
    if robot.sdd.drift(robot.theta_posterior):
        robot.crel.reelicit(user)                                      # 规范漂移 -> 重引
    robot.vqa_c.submit_async(user.edits, plan, ctc, robot.theta)       # 参与式审计
    return k, lam, a, robot.mode_commit
```

## 3. 推导

**引理 19（模式分离下的承诺收益）** 设两模式在特征空间可分裕度 Δ_reg、切换成本 c_e。若模式后验正确率 p > 1/2，则持有模式图并做持证承诺的期望代价 ≤ 单一模式策略 − (2p−1)·Δ_reg + Σ_e c_e·P(e)。系：**模式越可分、切换越便宜，混合身体越值钱**；当 c_e 很大（过渡昂贵）时收益被切换成本吃掉——这正是轮足在长平地「一直滚」、在长台阶「一直走」的原因。

**引理 20（不可逆时先问后跳最优）** 设即将发生的边 e 不可逆度 ι_e、错误承诺期望后悔 Regret_e、探询成本 c_q。若 ι_e·Regret_e > c_q，则「先探询再承诺」的期望风险 ≤「立即承诺」；且存在唯一阈值 ι* = c_q / Regret_e，ι_e > ι* 时先问、否则边做边问。这给出 I-VoI 的排序（定义 320）与 R69 的边界（ι → 0 退化为 R69「边做边问」）。

**引理 21（宪法单调性：任意编辑序列都不降低安全性）** 由于 Π_safe 幂等、非扩张且值域 ⊆ Feasible(𝒮_hard)，对任意编辑序列 e_1..e_n，执行策略的风险 ≤ ε；即硬不变式在编辑下**单调保持**。直白说：「用户可以把目标改到任何可行处，但改不出不安全。」

**引理 22（可解释拒绝的最小性与可懂性）** XR 返回的 (θ*, r*) 是加权距离下的最近可行点，故：(a) 最小性——不存在更近的可行 θ；(b) 可懂性——解释给出「最早失效的不变式 + 失效时域」，用户可据此局部修改意图。若用户坚持，双钥审计记录责任归属，避免责任稀释。

**定理 18（CRAFT 严格包含 FLUID/R69）** 在 A99–A101 下，任意状态上 CRAFT 的期望风险 ≤ FLUID；且当 |ℛ| = 1、θ 固定、无编辑时，二者逐指令相同（定义 327）。安全侧不让步，效率侧获得「身体选择 + 共写目标」的收益。

**定理 19（两时间尺度安全与收敛）** 设快回路在固定 (θ, m) 下是 ε-收缩（承 R69 定理 16），慢回路编辑算子 Π_safe∘⊕ 在可行流形上 L-Lipschitz 且步长满足 Robbins–Monro。则耦合系统：(a) 所有时刻满足契约（安全）；(b) θ_n 有界且几乎必然收敛到可行集内的稳定点（用户目标与安全约束的共同定点）；(c) 慢变量不诱发快回路抖振（因收缩性对非平稳输入有界增益）。这正面回应「共创会不会把系统搞乱」的质疑。

**定理 20（混合切换无抖振与瞬态有界）** 在迟滞 h_hys 与驻留 τ_dwell 下，边界抖振概率随时间指数衰减；持证切换（定义 314）保证瞬态峰值风险 ≤ ε_tr 且后状态前向不变；结合定理 17（R69 无突变），切换前后控制连续、无突变。系：轮足在「滚↔走」过渡区的安全性可由离线证书 + 在线守卫共同保证。

## 6. 本轮最大风险

**一句话**：CRAFT-RAS 的安全承诺是「相对于一个**被写下来的契约**」；而共创的生产性恰恰在于它能生成设计者没预见的编辑与模式——于是「逐指令满足 J_CRAFT」可能只是对一个**不完整的宪法**成立：系统可以合法地对一个没被写进 𝒮_hard 的危险说「这不在我的不变式里」；**共创把安全问题从『求解已知约束』变成了『枚举未知约束空间』，这是它最大的风险**。

**次级风险与缓解**：
1. **CTC 组合爆炸与跨模式漏检**（滚→走→混合的复合边、轮打滑叠加收腿）→ 边级 + 复合边两级证书 + 离线压力测试 + E302；
2. **慢回路非平稳导致不收敛**（用户反复改主意）→ SDD 漂移门 + Robbins–Monro 步长 + 定理 19 的收缩条件 + E308；
3. **「伪解释」：形式最小但用户不可懂** → 反事实 + 最早失效时域 + 人类研究 E306/E313；
4. **双钥被社会工程绕过**（用户坚持+伪造理由）→ VQAuditor-C 审计 + 责任归属留痕 + E309；
5. **能量/热约束被切换瞬态忽略** → 把能量红线写入 𝒮_hard，过渡能量预算纳入 CTC（定义 314）。

## 3. 关键算法伪代码

```python
# IP-264/265 HRM+RUQ
class HybridRegimeModel:
    def posterior(self, o):  return softmax(self.terrain_clf(o))
    def uncertainty(self, p, guards):  return entropy(p) * guard_margin(guards)

# IP-266 CTC：前向不变 + 瞬态上界 + 回退可达
def certify_transition(x, e, horizon):
    B = barrier(e.r, e.r2)
    ok_fwd  = all(B(x_t) >= 0 for x_t in rollout(e.f, x, horizon))
    ok_tr   = peak_risk(rollout(e.f, x, horizon)) <= EPS_TR
    ok_back = back_reachable(x, e, TAU_BACK) or e.iota >= IOTA_USER_AUTH
    return ok_fwd and ok_tr and ok_back

# IP-267 CDG
def dwell_ok(state, e, tau_dwell, h_hys):
    return (state.since_last_commit >= tau_dwell and
            guard_margin_persisted(e, state, h_hys, tau_dwell))

# IP-268/269 CREL+CSC：宪法投影（幂等 + 非扩张）
def apply_edit(theta, edit, contract):
    theta_new  = edit.apply(theta)
    theta_proj = contract.project_safe(theta_new)
    if d_w(theta_new, theta_proj) > TAU_EDIT and not contract.dual_key(theta_new, edit):
        return None, explain_refusal(theta_new, contract)      # IP-271 XR
    return theta_proj, None

# IP-270 I-VoI：不可逆 -> 先问后跳；可逆 -> R69
def choose_with_irreversibility(p_mode, theta, modes, budget):
    e_next = imminent_edge(p_mode)
    if e_next and e_next.iota > TAU_IRREV:
        g = mint_choose(modes, budget)
        if g is not None and ivol(g, e_next) >= 0:
            return ('elicit_then_commit', g, e_next)
    return ('act_then_ask', mint_choose(modes, budget), None)

# IP-277 主闭环：快/慢两时间尺度
def CRAFT_ROUND(robot, user, obs):
    p_m = robot.hrm.posterior(obs); m_cur = robot.state.m
    e   = robot.hrm.best_edge(p_m, m_cur)
    ctc = robot.ctc.certify(robot.state.x, e, robot.horizon) if e else None
    plan = choose_with_irreversibility(p_m, robot.theta, robot.modes, robot.budget)
    if plan[0] == 'elicit_then_commit' and ctc and ctc.valid:
        robot.mint.execute(plan[1]); robot.mode_commit = plan[2].r2
    elif ctc and ctc.valid and dwell_ok(robot.state, e, TAU_DWELL, H_HYS):
        robot.mode_commit = e.r2
    k, lam, a, U = robot.fluid_step(obs, regime=m_cur)          # R69 连续动作
    if user.has_edit():                                          # 慢回路（异步）
        theta_p, refusal = apply_edit(robot.theta, user.edit(), robot.contract)
        if refusal: user.notify(refusal)
        else:       robot.theta = theta_p
    if robot.sdd.drift(robot.theta_posterior): robot.crel.reelicit(user)
    robot.vqa_c.submit_async(user.edits, plan, ctc, robot.theta)
    return k, lam, a, robot.mode_commit
```

## 4. 推导

**引理 19（模式分离下的承诺收益）** 两模式可分裕度 Δ_reg、切换成本 c_e、后验正确率 p>1/2 时，持图承诺的期望代价 ≤ 单一模式 − `(2p−1)Δ_reg + Σ c_e P(e)`。系：越可分、切换越便宜，混合身体越值钱；c_e 大时收益被切换成本吃掉（长平地一直滚、长台阶一直走）。

**引理 20（不可逆时先问后跳最优）** 阈值 `ι* = c_q / Regret_e`：`ι_e·Regret_e > c_q` 时先探询后承诺期望风险 ≤ 立即承诺；`ι→0` 退化为 R69 边做边问。

**引理 21（宪法单调性）** `Π_safe` 幂等非扩张且值域 ⊆ Feasible(𝒮_hard)，故任意编辑序列后策略风险 ≤ ε：用户可把目标改到任何可行处，但改不出不安全。

**引理 22（拒绝最小性）** XR 的 `(θ*,r*)` 是加权距离最近可行点 ⇒ 最小且可懂；坚持则双钥留痕，避免责任稀释。

**定理 18（严格包含 FLUID/R69）** A99–A101 下任意状态 CRAFT 风险 ≤ FLUID；`|ℛ|=1 ∧ θ 固定 ∧ 无编辑` 时逐指令相同（定义 327）。

**定理 19（两时间尺度安全与收敛）** 快回路在固定 (θ,m) 下 ε-收缩，慢算子 Π_safe∘⊕ 在可行流形 L-Lipschitz 且 α_n 满足 Robbins–Monro ⇒ (a) 全时刻守契约；(b) θ_n 有界且 a.s. 收敛到可行稳定点；(c) 慢变量不诱发快回路抖振。

**定理 20（无抖振与瞬态有界）** 迟滞+驻留下抖振概率指数衰减；持证切换保证瞬态峰值 ≤ ε_tr 且后状态前向不变；结合 R69 定理 17 ⇒ 切换前后控制连续、无突变。

## 7. 本轮最大风险

**一句话**：CRAFT-RAS 的安全承诺是「相对于一个**被写下来的契约**」；共创的生产性恰恰在于它能生成设计者没预见的编辑与模式——于是「逐指令满足 J_CRAFT」可能只对一个**不完整的宪法**成立：系统可以合法地对一个没被写进 𝒮_hard 的危险说「这不在我的不变式里」；**共创把安全问题从『求解已知约束』变成了『枚举未知约束空间』，这是它最大的风险**。

**次级风险与缓解**：CTC 组合爆炸/跨模式漏检（边级+复合边证书 + 离线压测 + E302）；慢回路非平稳不收敛（SDD 漂移门 + Robbins–Monro + 定理 19 + E308）；「伪解释」形式最小但不可懂（反事实+失效时域+E306/E313）；双钥被社会工程绕过（VQAuditor-C + 留痕 + E309）；能量/热约束被瞬态忽略（能量红线入 𝒮_hard，过渡能量预算纳入 CTC）。
