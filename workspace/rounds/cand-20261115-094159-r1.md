# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「论文发表」×「放置」）

> R69 把不确定性一分为二，并教会系统「问」：aleatoric 收紧、epistemic 交互消解。但它默认所有动作都能「问了再做、做错再改」。真实世界有一类动作是**不可撤销的**：释放、落座、对接、发布——一旦完成，世界状态不可逆，恢复成本可能远超收益。R69 的 MINT 只在「可逆的信息动作」上算 VoI，却对**承诺时刻**沿用同一套证据阈值，这是它的盲点。
>
> 更隐蔽的是，R69 的 VoI 搜索本身是一台**多重比较机器**：在 K 个模态、≤5 个候选信息动作、若干阈值与停止规则上取 argmax，会系统性地「p-hack」出一个显著结论。它自陈的最大风险（模态权重未校准 → 自信地追问一个幻影、给误导回答盖上「已验证」的章）正是学术界的**可复制性危机**在机器人身上的翻版——**一个系统若能自由地换假设、换阈值、换停止时刻，它总能「证明」自己想证明的东西**。
>
> 本轮两个灵感正好给出解药与载体：
> - **论文发表**给出一整套对抗自我欺骗的社会技术：预注册、独立复制、对抗审稿、选择性推断校正、撤稿与引用网络；
> - **放置**给出不可逆承诺的物理原型：接触是唯一能揭示质量/摩擦/质心的时刻，而承重比例 β 恰好把「探询」与「承诺」连成一条连续谱。
>
> 核心命题：**把「不可逆性」提升为一等公民。可逆处沿用 FLUID 的交互消歧；不可逆处必须先「预注册—复制—校正」再「承诺」，并保留撤稿与恢复通道；放置不是瞬间动作，而是一个可分级、可观测、可撤回的承诺过程。** 命名 **REPLACE-RAS**（Replicated, Pre-registered, Lifecycle-Audited Commitment Engine）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**哪些话一旦说出就收不回，我凭什么敢说**」——科学不是「发出来就算」，而是「可被复制、可被撤稿、可被追责」。

## 0. 直觉与动机

**灵感 1（论文发表 → 可复制性危机是 R69 最大风险的镜像）**
直觉：R69 最怕的是「模态分布不可信，于是 VoI 在错误信念上计算」。学术界的对应物是**可复制性危机**：单个实验里显著的结果，换个样本、换个分析路径就消失。原因不是有人造假，而是**分析自由度**——你可以选样本、选指标、选阈值、选停止时刻，直到「显著」。R69 的 MINT 有完全相同的自由度：选 K、选模态聚类数、选信息动作、选停止时刻、选证据源组合。于是它可能**真诚地** p-hack 出一个本来不存在的「可消解歧义」，然后自信地去追问。论文发表这一灵感给出的不是某个算法，而是一整套**制度性防腐**：把决策规则在观测前冻结、把结论交给独立复制、把事后改口单独记账、把撤稿当作一等公民。

**灵感 2（放置 → 不可逆承诺是一条连续谱，不是一个开关）**
直觉：把物体「放下」之所以危险，是因为它是**接触即承诺**：悬持时你还能重抓，一旦完全卸载重量，物体可能滚落、倾倒、卡死，恢复成本陡增。关键洞察是：**承重比例 β ∈ (0,1]** 把「信息动作」与「不可逆承诺」连成一条连续谱——β→0 是一次轻触探询（可逆、能揭示摩擦与质心），β=1 是彻底放手（不可逆）。于是 R69 的二分（交互 vs 执行）被进一步细化为**分级承诺**：系统不必在「问」与「做」之间二选一，而可以「边放边学、边学边放」，在信息价值与滑移风险之间取一个内点 β*。这把「放置」从末端执行器的一个位姿，升级为**一个带风险预算的贝叶斯实验设计**。

**灵感 3（预注册 → 在观测前冻结决策规则，切断 forking paths）**
直觉：医学试验里，预注册（pre-registration）要求在研究开始前写死假设、样本量、主指标、统计检验与停止规则，并公开时间戳。它的作用不是提高单个检验的效力，而是**消灭事后选择的空间**。对应到闭环：不可逆动作前，先在只追加账本里冻结 `(假设集、检验统计量、显著性水平、复制次数、停止规则、随机种子、训练/验证切分)`。任何事后修改必须标记为「探索性」，**不得**作为确证性证据支撑不可逆承诺。直觉上：**先签字，后看数据；改口可以，但要留痕且降级**。

**灵感 4（独立复制 ≠ 多源一致 → R69 的证据纪律可能被相关误差骗过）**
直觉：R69 用「k 个正交证据源一致」对抗投毒，但**源与源可能共享同一台有偏的传感器、同一个有偏的 trunk、同一次标定**。三个都看了同一场被操纵的戏，会「一致地错」。学术界的教训更狠：**在同一实验室、同一设备上重复，不叫复制**。真正的复制要求独立的数据、独立的分析、有时甚至是独立的审稿人。于是本轮引入**复制审查（RRB）**：新鲜噪声下的独立重放、不同模态/时间段/隐藏传感器的去相关、以及一个专门构造「替代解释」的**对抗审稿人（Reviewer 2）**。关键量不是「重复了几次」，而是**有效独立性**（重放误差之间的互信息 ≤ τ_ind）；否则只是「自我抄袭」。

**灵感 5（撤稿与引用网络 → 承诺之后仍需追责与恢复）**
直觉：论文发表不是终点，发表后还有同行评议、复现失败、撤稿、以及引用网络的失效传播。对应到机器人：一次不可逆放置提交后，后续观测（滑移、倾倒、人类纠正）可能推翻当初赖以决策的某个证据证书。此时系统需要**撤稿算子**：显式标记该结论失效、沿**决策引用图**把失效传播到所有依赖它的下游承诺、并生成恢复计划（重抓、重新放置、补偿、告警）。这让「安全」从「提交那一刻是否正确」升级为「**全生命周期是否可追责、可回滚**」。一个不敢撤稿的系统，和一个从不承认错误的科学家一样危险。

**灵感 6（总纲：三层严格包含，安全侧永不后退）**
直觉：本轮最重要的理论姿态仍是「新层必须是旧层的严格泛化」。目标包含链是 **R68 ⊂ FLUID ⊂ REPLACE**：在可逆子空间上 REPLACE 逐指令等于 FLUID（因为 β=0、I=0，预注册与复制退化为无操作）；在不可逆动作上，REPLACE 只增加检查、从不放宽检查；任何检查失败都**单调地**降级为「分级放置 → 悬持 → R69 保守 → R68 最保守」。这样每加一层，安全侧只增不减，效率侧才敢拿「承诺红利（commitment bonus）」。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（REPLACE-RAS 总览）** REPLACE-RAS = (CMT, PRD, SIC, RRB, CPP, PLC, RET, CG, VQAuditor-R, RAS-WM‡)。四条不变式：
(i) **不可逆门控**：任何 I(a) > I_irr 的动作，未经「预注册 ∧ 复制确证 ∧ 选择性推断校正」不得提交（定义 311、324）；
(ii) **预注册不可变**：确证性决策规则在观测前写入只追加账本，事后修改一律降级为探索性（定义 313–314）；
(iii) **复制独立性**：复制必须满足有效独立性 τ_ind，相关复制不计入复制次数（定义 318）；
(iv) **撤稿完备性**：每个提交都携带引用图结点，任何祖先证书被撤稿时，全部后代在有限时延内被标记失效并触发恢复（定义 322–323）。

**定义 311（不可逆度 I(a)）** 对动作 a 与世界状态 w，令 C_rec(a,w) 为恢复到动作前状态的最小期望成本（含重抓、重放、补偿、外溢损失），B_commit 为承诺预算。定义
I(a) = 1 − exp(−C_rec(a,w) / B_commit) ∈ [0,1]。
注视/问句 C_rec≈0 ⇒ I≈0；自由空间运动有界回溯 ⇒ I 低；释放/落座/对接/发布 ⇒ C_rec 可能发散 ⇒ I→1。I 不是安全裕度，而是**「错误不可用重试买单」的程度**。

**定义 312（承诺分级与 β-放置）** 按 I 分三级：**可逆**（I < I_rev，如信息动作、可回溯运动）、**半可逆**（I_rev ≤ I < I_irr，如部分承重、可重抓）、**不可逆**（I ≥ I_irr，如完全释放、对接锁死、对外发布）。放置动作参数化为 β-放置：β ∈ [0,1] 为**承重转移比例**，β=0 悬持、β=1 完全卸载。半可逆区间恰由 β∈(0,1) 实现；β 是一个**受安全约束的连续承诺旋钮**。

**定义 313（预注册对象 R_pre）** 对不可逆候选 a，预注册对象
R_pre = (H, e, T, α, r, stop, seed, split, I_a, h),
其中 H 为冻结假设集（模态身份集合）、e 为证据源与检验统计量、T 为容差、α 为显著性水平、r 为要求复制次数、stop 为停止规则、seed 为随机种子、split 为训练/验证切分、I_a 为不可逆度、h = Hash(前八项) 写入只追加账本。**h 一旦写入不可更改**；任何不同 h 的后续分析记为探索性。

**定义 314（探索性 vs 确证性证据）** 确证性证据必须可追溯到某个 R_pre 且统计量、停止规则、切分均未偏离；偏离者记为探索性证据 ℰ_explore，可启发下一轮假设，但**不得**计入不可逆承诺的证据门槛。这是对 R69「k 源一致」纪律的加强：R69 只问「是否一致」，本轮先问「**这个一致性是不是事后挑出来的**」。

**定义 315（去偏 VoI / 交叉拟合）** R69 在候选集 G 上取 g* = argmax_g [VoI(g) − c(g)]，其选中估计存在**赢家诅咒**（winner's curse）。本轮用样本分割：在 pilot 集上选 g*，在 holdout 集上重估 VoI_hold(g*)；或用 K 折交叉拟合交叉验证。去偏 VoI 记为 VoI_cf(g*) = E_hold[VoI(g*)] − c(g*)，只有 VoI_cf > 0 才允许把 g* 作为确证性交互。

**定义 316（选择性推断校正 SIC）** 对候选信息动作集 G 做置换检验得 p 值 {p_g}，用 Benjamini–Hochberg 控制在 FDR ≤ q；只有通过 BH 的候选才进入 argmax。目的：在「多候选 × 多模态 × 多阈值」的搜索下，显式控制**发现错误结论的期望比例**，把 R69 隐式的多重比较问题摆到明面上。

**定义 317（赢家诅咒收缩）** 被选中的最大模态权重 ŵ_(1) 系统性高估真值。定义收缩估计 ŵ_k^shrink = ŵ_k − λ_sh·(ŵ_k − 1/K̂)_+，其中 λ_sh 由候选数 M 与样本量估计（近似 E[偏差] ≈ σ√(2 log M)）。任何进入证书的权重必须是收缩后权重；未收缩的原始权重只作可视化。

**定义 318（复制审查 RRB）** 对确证性结论 d，做 r 次**独立重放**：每次使用新鲜测量噪声、不同模态/时间段/隐藏传感器，并检查**有效独立性**（重放误差与原始误差的互信息 ≤ τ_ind，等价地误差相关系数 ρ ≤ ρ_max）。复制成功需：结论（所选模态/承诺决定）不变 ∧ 统计量在 R_pre 容差 T 内。**相关副本不计入 r**——这正是「同实验室重复不算复制」的形式化。

**定义 319（对抗审稿 Reviewer-2）** 一个红队模块，给定结论 d 与证据，主动搜索**替代解释**：另一组模态权重、另一条被忽略的传感器通道、一次能同时解释证据的投毒/共谋场景。若找到与 d 同等或更简的替代解释且证据不足以区分，则 d 被判为 **fatal**（不可确证）。审稿意见写入审计缓冲，成为下一轮预注册的先验。

**定义 320（放置安全证书 PLC）** 给定质心置信集 𝒞（conformal 覆盖 1−δ）、摩擦系数置信集 ℳ = [μ_lo, μ_hi]、支撑多边形 S 与承重比 β。定义支撑裕度 m_sup = min_{c∈𝒞} dist(c, ∂S) − δ_CoM，摩擦裕度 m_fric = min_{μ∈ℳ} (μ·N_contact(β) − F_tangent(β))。证书 Valid ⇔ m_sup > m_sup,min ∧ m_fric > 0 ∧ 滑移检测未触发。证书是对**性质不确定**（质量/摩擦/质心未知）的鲁棒版本，而非点估计上的乐观判断。

**定义 321（接触探针放置 CPP）** β-放置过程中，接触力/滑移/形变信号 y_contact 揭示物体性质。定义信息增益 I_prop(β) = I(质心,摩擦; y_contact | β)，滑移风险 R_slip(β) 随 β 单调增。选择 β* = argmax_β [I_prop(β) − κ·R_slip(β) − c(β)]，s.t. R_slip(β) ≤ ε_slip。β* 可能落在内点：**先放一半学性质，再决定是否完全卸载**。这就是「放置即实验」。

**定义 322（撤稿算子 RET）** 撤稿事件 e_ret = (证书 id, 反证观测, 时刻, 置信度)。算子 Retract(e_ret) 将证书标记为 RETRACTED，生成恢复计划 π_rec（重抓/重放/补偿/告警/请求人类接管），并冻结依赖该证书的下游提交。撤稿不是异常处理，而是**一等公民的正常演化操作**。

**定义 323（决策引用图 CG）** 有向无环图 G_cg：结点为证据证书与承诺动作；边 u→v 表示 v 的决策引用了 u。每个提交在写入时必须引用其全部证据证书。撤稿沿 G_cg 正向传播失效（descendants），并要求不存在**孤儿承诺**（无证据父亲的提交）。图的 DAG 性由「只能引用已存在结点」保证，从而传播必然终止。

**定义 324（不可逆证据门槛）** 由引理 19，不可逆动作的显著性门槛随 I 收紧：α_commit = α_0 / (1 + κ·I_a)，且要求复制次数 r(I_a) = ⌈log(α_target/α_0) / log ρ_max⌉（当 ρ_max<1）。可逆动作取 I_a=0 即退化为 R69 阈值 α_0。这是「说出去的话越收不回，越要求更硬的证据」的形式化。

**定义 325（复制预算与延迟分摊）** 复制有成本。定义复制预算 B_rep：单位时间内复制算力/时间/位移上限，且复制可在**后台并行**进行（不可逆提交前必须完成 r 次；半可逆可先 β-放置再异步复制）。常规可逆环路零额外延迟；不可逆路径的延迟记为 D_commit，并要求 P99 D_commit ≤ D_max。**绝不允许用「超时未复制完」冒充「复制通过」**——超时按失败处理。

**定义 326（干扰集与参与式审计）** ℰ_COMMIT = ℰ_FLUID × ℰ_p-hack × ℰ_self-replicate × ℰ_irreversible，新增：分析自由度滥用（换阈值/换切分/换停止）、同源伪复制（self-plagiarism）、不可逆动作的不可恢复失败（滚落/倾倒/锁死/误发布）。VQAuditor-R 审计对象新增：预注册是否被遵守、复制是否真独立、撤稿是否传播完备、是否存在孤儿承诺。审计结论回灌 AuditBuf，成为下一轮预注册先验。

**定义 327（证书 J_REPLACE 与三级退避）** J_REPLACE = (J_FLUID, I_a, prereg_hash, replication_effective_independence, replication_count, sic_fdr, shrunk_mode_weights, placement_cert_margin, citation_node, retraction_status, replace_ver)。Valid ⇔ Valid(J_FLUID) ∧ 预注册存在且未偏离 ∧ 复制确证 ∧ FDR 达标 ∧ 放置证书 Valid ∧ 无未处理撤稿。退避：确证失败 → **半承诺**（β<1 或悬持）；半承诺仍不安全 → **不承诺**（回 R69 保守）；连 R69 也失败 → **R68 最保守**。三级退避单调，安全侧永不弱于 FLUID。

## 2. 关键算法骨架

```python
# IP-264 CMT：承诺感知分类与不可逆度
def irreversibility(a, world, budget):
    c_rec = min_recovery_cost(a, world)              # 重抓/重放/补偿/外溢
    return 1.0 - math.exp(-c_rec / budget.B_commit)  # 0=可逆, 1=不可逆

# IP-265 PRD：预注册（不可变、只追加账本）
def preregister(modes, a, I_a, ledger, alpha0=0.05):
    r = required_replications(alpha0, I_a)           # I 越大，复制次数越多
    proto = dict(hypotheses=mode_ids(modes), stat='voi_gain',
                 alpha=alpha0 / (1.0 + KAPPA * I_a), # 门槛随不可逆度收紧
                 n_rep=r, stop='n<=r', seed=next_seed(),
                 split='pilot/holdout', I_a=I_a)
    proto['hash'] = ledger.append_and_hash(proto)    # 冻结；改则降级探索性
    return proto

# IP-267 SIC：FDR + 去偏 VoI + 赢家诅咒收缩
def corrected_voi(modes, o, proto, q=0.1):
    pilot, hold = split(o, proto['split'], seed=proto['seed'])
    pvals, cand = [], info_candidates(modes)
    for g in cand:
        pvals.append(permutation_test(g, pilot, stat='modal_entropy_drop'))
    keep = [g for g, p in zip(cand, pvals) if benjamini_hochberg(p, q)]
    best = None
    for g in keep:                                   # 只在 holdout 上重估
        score = voi(hold, g) - cost(g)               # 去 winner's curse
        best = (g, score) if best is None or score > best[1] else best
    return best if best and best[1] > 0 else None

            continue                                 # 相关副本不计入
        if (decision.conclusion(o_j) == decision.conclusion
                and within_tol(decision.stat(o_j), proto['stat'], proto['alpha'])):
            ok += 1
    alt = red_team_alternative(decision, policy)     # Reviewer-2
    return Confirmed(ok >= proto['n_rep'] and not alt.fatal, ok, alt)

# IP-269 CPP：分级放置（β 承重作为可逆的接触探针）
def graded_placement(a_place, prop_belief, budget):
    best = None
    for beta in (0.1, 0.25, 0.5, 1.0):
        slip = predicted_slip_risk(beta, prop_belief)
        if slip > EPS_SLIP:
            continue
        score = info_gain_props(prop_belief, beta) - KAPPA * slip - commit_cost(beta)
        if best is None or score > best[1]:
            best = (beta, score)
    return best if best and best[1] > 0 else (0.0, None)   # 0=悬持/不承诺

# IP-270 PLC：性质不确定下的放置证书
def placement_certificate(a_place, beta, prop_belief):
    C  = conformal_com_set(prop_belief, delta=DELTA)   # 质心置信集
    MU = conformal_friction_set(prop_belief, delta=DELTA)
    if min(support_margin(c, beta) for c in C) <= M_SUP_MIN:
        return False
    if min(friction_margin(mu, beta) for mu in MU) <= 0:
        return False
    return not slip_detected(a_place)

# IP-271/272：撤稿与引用图（DAG，只能引用已存在结点）
def retract_and_recover(cg, bad_cert, world):
    invalid = cg.descendants(bad_cert)                 # 沿引用图传播
    for d in invalid:
        d.flag = 'RETRACTED'
    return recovery_plan(invalid, world)               # 重抓/重放/补偿/告警

# IP-274 主闭环（可逆子空间逐指令退化为 R69）
def REPLACE_RAS_round(M, obs):
    # 1) 可逆层：完全承接 FLUID-RAS（不确定性二分 + 交互消歧）
    U_ale, U_epi, modes, g = M.fluid.round(M, obs)
    a  = select_mode(modes, U_epi)
    I_a = M.cmt.irreversibility(a, M.world, M.budget)
    if I_a < I_REV:                                    # 可逆：零额外开销
        return M.fluid.execute(a, modes, g)
    # 2) 不可逆层：预注册 → 选择性校正 → 复制审查
    proto = M.prd.preregister(modes, a, I_a, M.ledger)
    g = M.sic.corrected_voi(modes, obs, proto)
    if g is not None:
        M.fluid.acquire(g)
    rep = M.rrb.review(decision(a, modes), proto, M.fmp)
    # 3) 证据不确证：降级为半承诺（β-放置）；再不行则不承诺
    if not rep.confirmed:
        beta, _ = M.cpp.graded_placement(a, M.prop_belief, M.budget)
        if beta is None:
            return M.r68_conservative(a)               # 最保守兜底
        a = partial_transfer(a, beta)
    # 4) 放置证书（支撑/摩擦鲁棒裕度）；不过则不承诺
    if not M.plc.certificate(a, current_beta(a), M.prop_belief):
        return M.cpp.degrade_or_hold(a)

    cert = M.jcert.issue(a, proto, rep, U_ale, U_epi)
    node = M.cg.commit(a, cert)
    M.vqa_r.submit_async(node, proto, rep)
    return execute(a), node
```

## 3. 推导

**引理 19（不可逆性的遗憾放大与门槛收紧）** 设真实模态 m*，后验权重 w，选错模态的不可逆损失为 L_irr，而可逆动作在发现错误后可用成本 C_rec 恢复。则同一后验下，提交不可逆动作相对可逆动作的期望遗憾增量为
ΔR = (L_irr − C_rec)·(1 − w_{m*}) ≥ 0。
故要维持同等遗憾上界，需将「错误模态可接受概率」按 C_rec/L_irr 同比例压低：α_commit ≤ α_rev·C_rec/L_irr；当 C_rec→0（可逆）退化为 α_rev，当 L_irr→∞ 要求 α_commit→0。这正是定义 324 门槛收紧的来源，也说明 R69「所有动作同一阈值」在不可逆处系统性偏松。

**引理 20（预注册消除 forking-paths 膨胀）** 若分析者可在 M 条决策规则（K 值 × 模态集 × 阈值 × 证据源 × 停止时刻）间自由选择并报告最显著者，则在全局零假设下误确证概率
P_false ≤ 1 − (1 − α)^M → 1（M 增大）。
预注册把可选规则集缩为单点（或对多重比较显式校正），使 P_false ≤ α。系：R69 的 MINT 若不预注册，其「找到可消解歧义」的把握随候选数膨胀，**这正是可复制性危机的闭环版**。

**引理 21（复制过滤的误确证上界与独立性前提）** 设单次误确证概率 p_0，r 次重放误差相关系数 ρ<1。仅当每次重放都要求结论一致时，误确证率
P_false(r) ≤ p_0·ρ^{r−1} + ε_ind。
当 ρ→1（同一传感器/同一 trunk/同一标定的「自我复制」），上界退化为 p_0，复制无效。故必须要求有效独立性 ρ ≤ ρ_max（定义 318）：**独立的样本、模态或时间段，才是真正的审稿人**。这与 R69 引理 18 形式同构但语义不同——引理 18 防的是「源相关投毒」，引理 21 防的是「自我复制幻觉」。

**引理 22（赢家诅咒与交叉拟合去偏）** 在 M 个带噪候选中取最大 VoI，选中估计的期望乐观偏差约 σ√(2 log M)，随 M 增长。样本分割下，若 pilot 与 holdout 交换可测（exchangeability），则 holdout 重估 ĝ 在给定 g* 下无偏，偏差降至 O(1/√n_hold)。故定义 315 的去偏 VoI 与定义 317 的收缩权重是对 R69「ŵ 直接使用」的必修补丁：**越是从多模态里挑出来的最大权重，越不可信**。

**引理 23（分级放置的信息-风险内点）** 设 I_prop(β) 关于 β 凹增（接触越充分，性质可辨识度越高但边际递减），R_slip(β) 关于 β 凸增（承重越多，滑移风险加速上升）。则目标 J(β)=I_prop(β)−κR_slip(β)−c(β) 在 R_slip 约束边界内存在唯一内点 β* 当且仅当 I_prop'(0) > κR_slip'(0)+c'(0) 且 I_prop'(1) < κR_slip'(1)+c'(1)。系：**存在「先放一部分再决定」的最优档位**，放置不是二值选择，而是可优化的贝叶斯实验。

**定理 18（严格包含链 R68 ⊂ FLUID ⊂ REPLACE）** 在 A95–A99 下：
(i) 可逆子空间（I<I_rev）上 REPLACE 与 FLUID 逐指令相同；
(ii) 不可逆动作的可提交集是 FLUID 可执行集的子集（多出预注册、复制、FDR、放置证书四道检查，从不删减）；
(iii) 任一检查失败时，退避路径单调：确证→半承诺→不承诺→R68 最保守；
故任意状态期望风险 ≤ FLUID ≤ R68，且当 I≡0 时 REPLACE≡FLUID，当 VoI≤成本时 FLUID≡R68。**安全侧只增不减，效率侧以「commitment bonus」形式回收。**

**定理 19（撤稿健全性与有限时延）** 决策引用图 G_cg 因「只能引用已存在结点」而保持 DAG。每次不可逆提交都有证书父亲（无孤儿）。撤稿事件后，失效沿后代边传播，因图无环必在 O(V+E) 步内终止，所有依赖该证书的下游提交被标记 RETRACTED 并触发恢复计划；检测时延 ≤ 1/λ_mon + D_commit。故不存在「基于已失效证据仍被信任的承诺」。

**定理 20（认知安全：不可确证即不承诺）** 若复制审查因有效独立性不足而无法完成（ρ>ρ_max 或超时），或对抗审稿给出未被排除的替代解释，则 REPLACE 不允许 I≥I_irr 的提交，只能退到半承诺或不承诺。即：**系统宁可「不发表」，也不「发表一个自己都无法复制的结果」**。这把 R69 的「问错比不问更危险」升级为「**发错比不发更危险，且撤稿比硬撑更安全**」。

## 6. 本轮最大风险

**一句话**：REPLACE-RAS 的全部可信度押在「复制是独立的」这一前提上——**若系统用同一台有偏的传感器、同一个有偏的 trunk、同一次标定去「复制」自己的结论，它就会给自己发一张「已复现」的证书；这不是科学，而是自动化的学术腐败**：预注册被同一套先验污染、复制被同源误差骗过、对抗审稿被同一个盲区蒙蔽，最终系统会以更高的形式化严谨度，更自信地做出一个**不可逆的错误承诺**——而且引用图还会把这份错误「合规地」传播给所有下游。

**次级风险与缓解**：
1. **复制同源（self-plagiarism）** → 有效独立性 τ_ind 硬门 + 多模态/多时段/隐藏传感器去相关 + E305 红队审计；
2. **预注册被绕过**（事后改规则、偷看 holdout）→ 只追加账本 + 哈希校验 + 任何偏离自动降级为探索性（定义 313–314）；
3. **复制预算击穿实时性** → 可逆路径零开销、复制后台并行、半可逆先 β-放置再异步复制、超时按失败处理（定义 325）；
4. **撤稿风暴/误撤稿**（一次滑移误判导致大面积冻结）→ 撤稿需置信度阈值 + 恢复计划 + 人类复核通道，避免「过度自我否定」；
5. **放置证书的分布外失效**（conformal 覆盖率在 OOD 下不保）→ 交换性检验 + OOD 拒绝 + 最保守悬持兜底（E314）；
6. **制度性过度保守**（复制太贵导致永不承诺、系统退化为悬持）→ commitment bonus 与 E299 成本-收益 Pareto 调档，明确「保守是有价格的」。

**定义 318–319（复制审查与对抗审稿）** 新鲜噪声、不同模态/时段/隐藏传感器的独立重放；有效独立性 `ρ≤ρ_max`；相关副本不计入 r。Reviewer-2 主动构造替代解释，无法区分则 fatal。

**定义 320–321（放置证书与接触探针）** conformal 质心/摩擦集下的支撑与摩擦鲁棒裕度；β-放置以部分承重换取性质信息，`β*` 为信息-风险内点。

**定义 322–323（撤稿与引用图）** 撤稿算子生成恢复计划；承诺必须引用证据证书，形成 DAG；失效沿后代传播，禁止孤儿承诺。

**定义 324–325（门槛与预算）** `α_commit=α_0/(1+κI_a)`、`r(I_a)` 随不可逆度增加；复制可后台并行，超时按失败处理，绝不以超时冒充通过。

**定义 326–327（干扰/证书/退避）** `ℰ_COMMIT=ℰ_FLUID×ℰ_p-hack×ℰ_self-replicate×ℰ_irreversible`；`J_REPLACE`；三级退避：确证→半承诺（β<1/悬持）→不承诺（R69）→R68 最保守。

## 3. 关键算法伪代码

```python
# IP-264 CMT
def irreversibility(a, world, budget):
    return 1.0 - math.exp(-min_recovery_cost(a, world) / budget.B_commit)

# IP-265 PRD：预注册（不可变）
def preregister(modes, a, I_a, ledger, alpha0=0.05):
    r = required_replications(alpha0, I_a)
    proto = dict(hypotheses=mode_ids(modes), stat='voi_gain',
                 alpha=alpha0/(1.0+KAPPA*I_a), n_rep=r,
                 stop='n<=r', seed=next_seed(), split='pilot/holdout', I_a=I_a)
    proto['hash'] = ledger.append_and_hash(proto)
    return proto

# IP-267 SIC：FDR + 去偏 VoI
def corrected_voi(modes, o, proto, q=0.1):
    pilot, hold = split(o, proto['split'], seed=proto['seed'])
    cand = info_candidates(modes)
    pvals = [permutation_test(g, pilot, 'modal_entropy_drop') for g in cand]
    keep  = [g for g, p in zip(cand, pvals) if benjamini_hochberg(p, q)]
    scores = [(g, voi(hold, g) - cost(g)) for g in keep]
    best = max(scores, key=lambda t: t[1], default=None)
    return best if best and best[1] > 0 else None

# IP-266 RRB：独立复制 + 对抗审稿
def replication_review(decision, proto, policy):
    ok = 0
    for _ in range(proto['n_rep']):
        o_j = fresh_replay(policy.env, decorrelate=('modality','time','hidden_sensor'))
        if effective_independence(o_j, policy) < TAU_IND:
            continue                                  # 相关副本不计入
        if (decision.conclusion(o_j) == decision.conclusion
                and within_tol(decision.stat(o_j), proto['stat'], proto['alpha'])):
            ok += 1
    alt = red_team_alternative(decision, policy)
    return Confirmed(ok >= proto['n_rep'] and not alt.fatal, ok, alt)

# IP-269 CPP：分级放置
def graded_placement(a_place, prop_belief, budget):
    best = None
    for beta in (0.1, 0.25, 0.5, 1.0):
        slip = predicted_slip_risk(beta, prop_belief)
        if slip > EPS_SLIP:
            continue
        score = info_gain_props(prop_belief, beta) - KAPPA*slip - commit_cost(beta)
        best = (beta, score) if best is None or score > best[1] else best
    return best if best and best[1] > 0 else (0.0, None)

# IP-270 PLC：放置证书
def placement_certificate(a_place, beta, prop_belief):
    C  = conformal_com_set(prop_belief, delta=DELTA)
    MU = conformal_friction_set(prop_belief, delta=DELTA)
    return (min(support_margin(c, beta) for c in C) > M_SUP_MIN
            and min(friction_margin(mu, beta) for mu in MU) > 0
            and not slip_detected(a_place))

# IP-271/272：撤稿沿引用图传播
def retract_and_recover(cg, bad_cert, world):
    invalid = cg.descendants(bad_cert)
    for d in invalid:
        d.flag = 'RETRACTED'
    return recovery_plan(invalid, world)              # 重抓/重放/补偿/告警

# IP-274 主闭环
def REPLACE_RAS_round(M, obs):
    U_ale, U_epi, modes, g = M.fluid.round(M, obs)    # 可逆层=FLUID
    a, I_a = select_mode(modes, U_epi), None
    I_a = M.cmt.irreversibility(a, M.world, M.budget)
    if I_a < I_REV:
        return M.fluid.execute(a, modes, g)           # 零额外开销
    proto = M.prd.preregister(modes, a, I_a, M.ledger)
    g = M.sic.corrected_voi(modes, obs, proto)
    if g is not None: M.fluid.acquire(g)
    rep = M.rrb.review(decision(a, modes), proto, M.fmp)
    if not rep.confirmed:                             # 降级为半承诺
        beta, _ = M.cpp.graded_placement(a, M.prop_belief, M.budget)
        if beta is None: return M.r68_conservative(a)
        a = partial_transfer(a, beta)
    if not M.plc.certificate(a, current_beta(a), M.prop_belief):
        return M.cpp.degrade_or_hold(a)
    cert = M.jcert.issue(a, proto, rep, U_ale, U_epi)
    node = M.cg.commit(a, cert)                       # 写入引用图
    M.vqa_r.submit_async(node, proto, rep)
    return execute(a), node
```

## 4. 推导

**引理 19（不可逆性的遗憾放大与门槛收紧）** 选错模态的不可逆损失 L_irr、可逆恢复成本 C_rec，则期望遗憾增量 `ΔR=(L_irr−C_rec)(1−w_{m*})≥0`，需 `α_commit ≤ α_rev·C_rec/L_irr`。R69 的同一阈值在不可逆处系统偏松。

**引理 20（预注册消除 forking-paths 膨胀）** 可在 M 条规则间挑最显著者时 `P_false ≤ 1−(1−α)^M → 1`；预注册把规则集缩为单点（或显式多重校正）后 `P_false ≤ α`。系：R69 的 MINT 不预注册即是一台隐性 p-hacking 机器。

**引理 21（复制过滤上界与独立性前提）** `P_false(r) ≤ p_0·ρ^{r−1}+ε_ind`；当 ρ→1（同源自我复制）退化为 p_0，复制无效。故必须 `ρ≤ρ_max`。与 R69 引理 18 形式同构、语义不同：18 防相关投毒，21 防自我复制幻觉。

**引理 22（赢家诅咒与交叉拟合去偏）** M 个带噪候选取最大，乐观偏差约 `σ√(2 log M)`；样本分割下 holdout 重估在给定 g* 下无偏，偏差降至 `O(1/√n_hold)`。故必须用去偏 VoI 与收缩权重，而非 R69 的原始 ŵ。

**引理 23（分级放置的信息-风险内点）** I_prop(β) 凹增、R_slip(β) 凸增时，`J(β)=I_prop−κR_slip−c` 在约束内存在唯一内点 β*，条件为首末边际比较。系：存在「先放一半再决定」的最优档位，放置是可优化的贝叶斯实验。

**定理 18（严格包含链 R68 ⊂ FLUID ⊂ REPLACE）** (i) I<I_rev 时逐指令等于 FLUID；(ii) 不可逆可提交集 ⊂ FLUID 可执行集（只加检查）；(iii) 退避单调：确证→半承诺→不承诺→R68。任意状态期望风险 ≤ FLUID ≤ R68；I≡0 时 REPLACE≡FLUID，VoI≤成本时 FLUID≡R68。

**定理 19（撤稿健全性与有限时延）** G_cg 为 DAG、无孤儿承诺；撤稿沿后代传播必在 O(V+E) 步终止，全部下游标记 RETRACTED 并触发恢复，检测时延 `≤1/λ_mon+D_commit`。不存在「基于已失效证据仍被信任的承诺」。

**定理 20（认知安全：不可确证即不承诺）** 复制因独立性不足/超时无法完成，或对抗审稿给出未排除的替代解释时，禁止 I≥I_irr 提交，只能半承诺/不承诺。**宁可不发表，也不发表自己都无法复制的结果；撤稿比硬撑更安全。**

## 7. 本轮最大风险

**一句话**：REPLACE-RAS 的全部可信度押在「复制是独立的」这一前提上——**若系统用同一台有偏的传感器、同一个有偏的 trunk、同一次标定去「复制」自己的结论，它就会给自己发一张「已复现」的证书；这不是科学，而是自动化的学术腐败**：预注册被同一套先验污染、复制被同源误差骗过、对抗审稿被同一个盲区蒙蔽，最终系统会以更高的形式化严谨度、更自信地做出一个**不可逆的错误承诺**，而引用图还会把这份错误「合规地」传给所有下游。

**次级风险与缓解**：复制同源 → τ_ind 硬门 + 多模态/多时段/隐藏传感器去相关 + E305；预注册被绕过 → 只追加账本 + 哈希校验 + 偏离自动降级探索性；复制预算击穿实时性 → 可逆零开销、后台并行、半承诺先 β-放置、超时按失败；撤稿风暴/误撤稿 → 撤稿置信阈值 + 恢复计划 + 人类复核；证书 OOD 失效 → 交换性检验 + OOD 拒绝 + 悬持兜底；制度性过度保守 → commitment bonus + E299 成本-收益 Pareto 调档，明确「保守是有价格的」。
