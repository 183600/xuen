**事实层的核心结论**：赛题硬件是灵巧手，接口却是「1 维夹爪 + 7 维臂」。因此"灵巧"不能靠逐指控制兑现，只能靠三件事兑现：(a) 把 1 维夹爪当作**连续时序控制量**（握持相位曲线），而不是二值开关；(b) 用**腕部相机**做接触状态的视觉估计（视觉触觉代理），补上缺失的触觉；(c) 用**臂/站位冗余**去补抓取几何与可达性。上一轮 I1–I9 几乎全押在"数据侧"（语料、增广、检索），却从未显式建模**接触那一刻**——这正是本轮要补的洞。

## 1. 直觉与严谨定义

### 灵感 1（灵巧手 → 接口降维后，"灵巧"残留在握持曲线与腕部视野里）

**直觉**：灵巧手的价值本来在"多指协同、手内调整、接触力分配"。但接口只给你一个夹爪开合标量 `g_t` 和一只 6/7 维臂，逐指策略根本没有出口。悲观结论是"灵巧手在这场比赛里没用"；但换个角度看，灵巧性以两种**残差形式**活了下来：
(a) **时间残差**——示教是用灵巧手采的，夹爪开合轨迹里编码了"何时开、开多大、闭合多快、接触后是否回撤"的任务特定曲线。大多数队伍把它压成二值开关（张开→闭合），等于把一条连续控制信号丢成 1 bit。
(b) **空间残差**——两只腕部相机几乎贴着手指和物体，能看到指尖-物体接触、物体形变、相对滑移、对齐误差。在没有力/触觉的接口里，腕部相机就是**唯一的接触级传感器**。
所以"灵巧"的正确用法不是加一个灵巧手控制器，而是：**把 1 维夹爪升级为带相位的连续控制，并用腕部视觉做接触闭环**。

**定义 1（握持相位 Grasp Phase）**：设归一化夹爪指令 `g_t ∈ [0,1]`，`ġ_t` 为其时间差分，`d_t` 为 ee 到目标物体的距离，`v^{obj}_t` 为物体视觉速度。定义相位 `φ_t ∈ Φ = {REACH, ALIGN, CLOSE, LOCK, HOLD, RELEASE, RETREAT}`，其转移由可观测条件给出：`CLOSE ⇔ ġ_t<−ε`；`LOCK ⇔ ġ_t≈0 ∧ g_t 达局部极小 ∧ ‖v^{obj}_t−v^{ee}_t‖<δ`（物体开始随手下走）；`HOLD ⇔ LOCK 持续 ∧ g_t 稳定`；`RELEASE ⇔ ġ_t>+ε`。**握持曲线**是一个条件映射 `g_t = π_g(φ_t, e^{obj}, q̂_t)`，其中 `e^{obj}` 为物体嵌入、`q̂_t` 为抓取质量估计。与二值策略的差别：`π_g` 显式建模闭合速度与最大闭合量，从而在不测力的情况下**间接控制接触力与形变**（闭合越多→法向力越大，闭合越快→冲击越大）。

**定义 2（接触模式与视觉触觉代理 Visual-Tactile Proxy）**：定义接触模式 `c_t ∈ C = {free, contact, slip, grasp, deform, release}`。视觉触觉代理是一个估计器
`b_t(c) = P(c_t=c | I^{w}_t, g_t, u_t)`，
其中 `I^{w}_t=(I^{L}_t,I^{R}_t)` 为左右腕图，`u_t` 为臂动作。无力的条件下，用可观测代理定义各模式的证据：
- `contact`：腕图中指/爪边界与物体边界距离 `<τ`，且 `ġ_t<0`；
- `slip`：`g_t` 已锁定时，物体区域光流 `f_t` 与由 ee 运动经单应投影得到的预测流 `π(v^{ee}_t)` 满足 `‖f_t−π(v^{ee}_t)‖>τ_s`（物体相对手指在动）；
- `grasp`：`slip` 低且 `‖v^{obj}_t−v^{ee}_t‖<δ` 持续 `k` 帧；
- `deform`：物体轮廓在闭合过程中发生超出刚体预测的形变（掩码面积/主成分变化）。
同时回归抓取质量 `q̂_t∈[0,1]` 与滑移概率 `ŝ_t`。关键点：这些标签都能从**成功示教**里自监督挖出来（见产物区 §1.1），不需要失败数据。

### 灵感 2（地形适应 → 桌面是地形：支撑面、堆叠、杂物、软硬都是地形属性）

**直觉**：腿式机器人的地形适应 = 在线估计地形（高度、坡度、摩擦）并调整落脚与接触。桌面操作里，"地形"就是**支撑面 + 物体景观**：哪块桌面托着什么、堆叠了几层、杂物把通路切成了什么形状、物体是刚是软。它恰好对应赛题的几条计分轴——位置泛化（远/高目标需要改站姿）、干扰物泛化（杂物=不可通行地形）、未见物品泛化（新材质=新柔顺度）、以及堆叠/倒液类任务的步骤分（支撑关系错=塌/洒）。而 `action.pivot`[7] 这个几乎没人动的维度，可能就是"改变站姿/基座"的出口（待 F25 核实）。所以地形适应的落点不是导航，而是：**用头部双目估支撑地形、用腕部近距估柔顺地形、用 pivot/臂冗余改可达性**。

**定义 3（接触地形图 Contact-Terrain Map）**：在机器人基座坐标系下定义局部 2.5D 图
`T_t(x,y) = (h(x,y), n(x,y), κ(x,y), ρ(x,y))`，
`h` 为支撑高度、`n` 为表面法向、`κ∈{rigid,soft,liquid}` 为柔顺类别、`ρ∈[0,1]` 为可通行度（碰撞风险）。`h,n` 由头部双目（`cam_left_high`/`cam_right_high` 构成立体对）恢复；`κ` 由腕部形变证据（定义 2 的 `deform`）估计；`ρ` 由检测框与深度在 ee 接近方向上的占位积分给出。地形图用于三件事：选放置高度/法向、绕开杂物、判断堆叠支撑。

**定义 4（支撑关系与站位适应）**：在检测到的物体/桌面节点上建支撑图 `G_t=(V,E)`，若物体 `i` 静置于 `j` 上则边 `i→j`，并回归堆叠稳定度 `σ_t(i)`。站位适应是在 pivot/臂冗余允许的构型 `p_t`（7 维 pivot 目标）上求解
`p_t* = argmax_p [ R(p) − λ·C(p) ]`，
`R(p)` 为目标点可达裕度 `min_i dist(reach(p), target_i)`，`C(p)` 为碰撞与失稳惩罚。**该定义在 F25 未核实前只作为假设**：若 pivot 只能做微小姿态调整，则 I12 退化为"纯视觉支撑估计 + 臂内冗余"，不阻塞主链。

### 两者统一

两条灵感收敛到**同一个缺失表示**：一个在线、显式、可观测的「接触状态 + 支撑地形」估计。灵巧手问"接触此刻是什么模式、抓稳没有"，地形适应问"世界此刻怎么托着物体、我够不够得着"。VLA 主干目前把这两件事隐式塞进动作里，既不可解释也无法在单任务通道上诊断。本轮的元创新就是把这个表示**显式化**（I10 接触地形感知头），再把它的输出用于夹爪闭环（I11）、接触伺服（I3）、失败恢复（I5）与站位（I12）。它仍是单一策略服务内的辅助头/组件，不引入按任务切换的第二模型（PR2）。

- **P4（无触觉）降级**：腕部相机是官方给的接触级通道（F21），视觉触觉代理（I10）把"结构性失分"降为"可学习的接触估计问题"——但仍受遮挡/材质限制，不宣称等价于力传感。

- **新增 P10（支撑/堆叠几何误差累积）**：堆叠、放置、倒液类任务（StackBowls、PaperCupStacking、ArrangePlates、PourOutMedicine、SyringeWaterTransfer）对支撑面高度/法向/稳定度敏感，纯 ee 开环策略的误差会沿堆叠层数放大。

## 3. 研究问题（本轮立项 Q9–Q11，Q1–Q8 保留）

## 4. 设计原则（新增 PR6，其余保留）

- **PR6 可观测性优先律**：任何能力必须能由接口真实通道（4 相机 + 每侧 7 维臂/6 维 ee + 1 维夹爪 + 7 维 pivot + 本体）表达；不得假设逐指、力/触觉或评测现场信息。设计前先问"这个信号在 F20/F21 的目录里存在吗"。
- **PR7 接触证据律**：任何接触阶段的闭环修正（停合、回撤、重抓、改放置高度）必须携带一个可观测的接触证据（`b_t(c)`/`ŝ_t`/`q̂_t`/`σ_t`），否则退回开环；避免"凭想象恢复"。
- PR1–PR5 保留（第 1–2 轮 §4）。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 接触地形感知头（CTPH，新）★★★★★

- **动机**：接口无任何力/触觉（F8/F21），而接触丰富任务族是结构性洼地（P4）；灵巧手被降维成 1 维夹爪后，接触信息只能从腕部相机恢复（F20/P9）；堆叠/放置/倒液依赖支撑几何（P10）。CTPH 把"接触那一刻"变成一个显式、可诊断、可自监督的表示。
- **与现有方案差异**：纯端到端 VLA 把接触状态隐式塞进动作，既不可解释也无法在单任务通道上定位失败；只在头部相机做感知的队伍拿不到接触级分辨率。CTPH 用**两只腕部相机 + 本体**做接触级估计，输出作为**辅助监督**（塑形主干）与**运行时 guard**（停合/回撤/改放置），且全部在一个策略服务内（PR2）。
- **结构**：共享 VLM 主干 → 轻量腕部编码器 `E_w` → 五个头：
  1. 接触模式分类 `b_t(c)`（6 类，定义 2）；
  2. 滑移概率 `ŝ_t`；
  3. 抓取质量 `q̂_t∈[0,1]`；
  4. 支撑高度/法向 `(ĥ,n̂)`（头部双目 + 腕部近距融合）；
  5. 柔顺类别 `κ̂`（刚/软/液）。
  辅助损失 `L_aux = λ_c CE(b) + λ_s BCE(s) + λ_q MSE(q) + λ_h SmoothL1(h) + λ_κ CE(κ)`，与动作流匹配损失联合优化。优先共享主干（最不易触碰单模型边界）；若显存/延迟吃紧，退为"冻结主干的独立腕部编码器"（仍是服务内组件，需按 PR2 向组委会确认）。
- **标签从哪来（关键，见 §1.1）**：成功示教里自监督挖，不需要失败数据——
  - `contact`：夹爪闭合（`ġ<0`）+ 腕图中爪-物边界贴近 + 物体开始随 ee 运动；
  - `slip`：夹爪锁定后，物体区域光流与 ee 运动预测流不一致；
  - `grasp`：无滑移且物体-ee 相对速度≈0 持续 k 帧；
  - `deform`：闭合过程中物体轮廓偏离刚体预测（面积/主成分突变）；
  - `(h,n)`：头部双目深度 + 桌面/物体分割；
  - `κ`：由闭合-形变曲线聚类得到弱标签。
- **技术可行性**：中-高。腕部编码器小（ViT-S/ResNet）；标签是启发式 + 5% 人工抽检；辅助头训练 1–2 GPU 日。
- **所需资源**：1×24GB GPU；标签管线 1 人周；每任务族检测器微调 1 GPU 日。
- **落地步骤**：①**F26 数据审计**（腕部可见率、夹爪分布直方图、接触段标签可分性）——不通过就止损；②标签管线 + 抽检；③冻结 VLM 只训腕部编码器与五头（LoRA 可选）；④L0：接触模式 AUC、滑移检测 F1、抓取质量与真实成功相关；⑤接入 guard 做 L2 A/B（停合时机、重抓触发、放置高度）。
- **风险**：腕部被手/物体遮挡导致 `contact/slip` 不可观测（闸门 F26，缓解：多帧 + 头部双目交叉验证，仍不可观测则 CTPH 只保留 `(h,n,κ)` 支撑地形部分）；标签噪声（缓解：置信门控 + 人工抽检 5% + 只在 L0 通过后上真机）。

### I11 握持相位连续夹爪控制（新）★★★★

- **动机**：1 维夹爪是唯一的手部控制通道（F20），但绝大多数队伍把它当二值开关；示教里其实有连续的"何时开、开多大、闭合多快、接触后是否回撤"曲线（P9）。在不测力的情况下，闭合速度与最大闭合量是**间接控制接触力与形变**的唯一旋钮。
- **与现有方案差异**：二值阈值策略对所有物体用同一条开合曲线；本点用**相位条件 + 物体条件**的连续曲线 `g_t=π_g(φ_t,e^{obj},q̂_t)`，对易碎/可变形/插接任务限速限幅，对刚性大物体允许快合。
- **技术可行性**：高。相位分割是规则+轻量分类器；`π_g` 可先做"示教检索 + 参数插值"，再升级为小回归头；无需改主 VLA 动作头（可作后处理）。
- **所需资源**：1 人周工程 + 少量 GPU；几乎不增推理延迟（查表/小 MLP）。
- **落地步骤**：①F26 审计夹爪通道连续性；②按定义 1 分割相位，统计每任务握持曲线族；③实现 `π_g`（检索/回归二选一）；④易碎/可变形任务（FoldTowel、PackDoll、PourOutMedicine、SyringeWaterTransfer）优先试点；⑤L0 用"闭合速度-形变"关系做代理，L2 真机 A/B 成功率与步骤分。
- **风险**：数据若为退化二值则收益归零（F26，缓解：直接降级为"闭合速度限幅"规则并入 I5）；过度闭合压坏/挤飞物体（缓解：最大闭合量按物体类别设上限 + `ŝ_t` 触发停合）。

### I12 支撑地形与站位适应（新，闸门）★★★

- **动机**：堆叠/放置/倒液类任务（StackBowls、PaperCupStacking、ArrangePlates、PourOutMedicine、SyringeWaterTransfer）对支撑面高度/法向/稳定度敏感，纯 ee 开环误差随堆叠层数放大（P10）；远/高目标受固定站姿可达性限制。`action.pivot`[7] 可能提供站姿调整出口（F23/F25）。
- **与现有方案差异**：固定站姿 + 仅用 ee/臂；本点显式估计支撑图 `G_t` 与接触地形 `T_t`，并用 pivot/臂冗余优化可达裕度与碰撞裕度。
- **技术可行性**：中，**强依赖 F25**。若 pivot 语义允许基座/躯干调整且稳定，则做站位规划；若不可用，则退化为 **I12'**：纯视觉支撑估计（`h,n,σ`）+ 臂内冗余选解 + 放置高度/法向对齐，不动 pivot。
- **所需资源**：支撑图/地形估计复用 I10；站位求解 1 人周；真机标定视 F25 而定。
- **落地步骤**：①核实 F25（pivot 语义/范围/失稳边界）；②实现支撑图与 `σ_t` 回归；③放置高度/法向对齐（不依赖 pivot，先做）；④若 F25 通过，加 pivot 站位优化；⑤L0 用支撑高度扰动做代理，L2 在 StackBowls/PaperCupStacking 上 A/B。
- **风险**：pivot 语义未知或动基座触发失稳/可信度告警（缓解：I12' 降级预案，pivot 默认不动，只有 L0+L2 双证后才启用）；支撑图误判导致塌堆（缓解：`σ_t` 置信门控，低置信退回保守放置高度）。

### 1.1 CTPH 自监督标签（I10）

```python
def build_contact_labels(ep):
    """从成功示教自监督生成接触模式/滑移/质量标签；无失败数据也可。"""
    g   = ep["gripper"]                         # (T,) 归一化夹爪
    ee  = ep["ee_pose"]                          # (T,6)
    obj = track_object(ep["wrist_imgs"], ep["head_stereo"])  # 物体掩码+光流
    labels = []
    for t in range(1, len(g)):
        closing = g[t] - g[t-1] < -EPS
        near    = boundary_gap(ep["wrist_imgs"][t]) < TAU
        moving  = np.linalg.norm(obj.vel[t] - ee_vel(ee, t)) < DELTA
        pred_flow = project_ee_flow(ee, t)       # ee 运动经单应投影到腕图
        slip = (abs(g[t]-g[t-1]) < EPS) and (norm(obj.flow[t]-pred_flow) > TAU_S)
        deform = contour_change(obj.mask[t], obj.mask[t-1]) > TAU_D
        c = ("free"    if not (closing or near) else
             "contact" if closing and near and not moving else
             "slip"    if slip else
             "deform"  if deform and closing else
             "grasp"   if moving and not slip else "release")
        labels.append((c, float(slip), grasp_quality(obj, g, t)))
    h, n = stereo_support(ep["head_stereo"])     # 头部双目恢复支撑高度/法向
    kappa = compliance_from_closure(obj, g)       # 闭合-形变曲线聚类弱标签
    return labels, (h, n, kappa)
```

### 1.2 CTPH 前向 + 运行时 guard（I10/I11）

```python
class ContactTerrainHead(nn.Module):
    def forward(self, wrist_L, wrist_R, g, ee, stereo):
        z = self.wrist_enc(wrist_L, wrist_R)              # 轻量腕部编码器
        b = softmax(self.head_c(z, g))                    # 接触模式后验
        s = sigmoid(self.head_s(z, g))                    # 滑移概率
        q = self.head_q(z, g)                             # 抓取质量
        h, n = self.head_terrain(z, stereo)               # 支撑高度/法向
        k = softmax(self.head_k(z))                       # 柔顺类别
        return b, s, q, h, n, k

def contact_guard(chunk, ct, phase):
    b, s, q, h, n, k = ct
    if phase in ("CLOSE", "LOCK") and (s > S_STOP or q < Q_MIN):
        chunk = stop_closing(chunk)                       # PR7：停合/微回撤
        return chunk, "regrasp" if s > S_RETRY else "hold"
    if phase == "RELEASE":
        chunk = set_place_height(chunk, h, n)             # 支撑地形对齐
    return chunk, None
```

### 1.3 握持相位控制（I11）

```python
PHASES = ["REACH","ALIGN","CLOSE","LOCK","HOLD","RELEASE","RETREAT"]

def grasp_phase(g, dg, obj_vel, ee_vel):
    if dg < -EPS: return "CLOSE"
    if abs(dg) < EPS and obj_vel is not None and norm(obj_vel-ee_vel) < DELTA: return "LOCK"
    if abs(dg) < EPS: return "HOLD"
    if dg > EPS: return "RELEASE"
    return "REACH" if dg >= 0 else "ALIGN"

def grasp_curve(phase, obj_emb, q_hat, kappa):
    """相位+物体+柔顺类条件化的连续夹爪指令；软/液/易碎限速限幅。"""
    base = lookup_profile(obj_emb, phase)                  # 示教检索的握持曲线
    if kappa in ("soft", "liquid") or q_hat < Q_MIN:
        base = limit_speed_and_max(base, v_max=SOFT_V, g_max=SOFT_G)
    return base
```
