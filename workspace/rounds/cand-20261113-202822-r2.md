# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「多视角视觉」×「材料选型」）

> 第 68 轮把「测量可信度」建成在线潜变量 c_t，用自监督驱动、用认证提交兜底，却把最大的洞留在了自己的成功里：**凡足够慢的残差，COF 都会把它当漂移「标好」**。本轮追问一个更底层的问题：慢残差并不只来自传感器漂移，它还有第三个来源——**对象与器具的材料属性**。镜面反射、透明、软材料蠕变、热膨胀会在视觉与力/触觉中制造既非漂移、也非故障的「材料诱发不可辨识」；而 R68 的 COF 会好心地把它们也吸收进 c_t——**用标定去修一个物理上不该标定的东西，标定被材料投毒**。
>
> 两个灵感恰好给出解药。多视角视觉把冗余从「多模态」推进到「同模态多视点」，并揭示一个关键事实：**视点变化是一次天然的干预 do(v)**——材料效应随视点协变，标定漂移对视角不变，真实故障则常表现为视角无关但模态特异。材料选型则从两个方向介入：运行时把材料显式建成潜变量，给残差一个正确的去处；设计时把「可诊断性」当作选型目标（哑光标定板、低蠕变夹爪垫、低热膨胀外壳、高发射率表面）。
>
> 核心命题：**标定能修正的只是「可辨识误差」；不可辨识的残差必须被识别并拒绝标定，而不是被解释掉——MAVIS-RAS（Material-Aware multi-View Identifiability-Safe RAS）。**
>
> 一句话定位：R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「**这次残差该归咎于谁，我们分辨得出来吗**」——分辨不出时，标定锁闭、材料显式建模、安全包络收紧。

## 0. 直觉与动机

**灵感 1（多视角视觉 → 视点是免费的干预实验）**
直觉：R68 的环一致性是「视觉 vs 触觉」，但两个模态都可能有自己的病。多视角提供同模态内的独立复本：同一几何被 V 个视点同时观测，任一路的漂移/污损都能被其余视点投票掉。更深一层，**改变视点等价于对成像过程做一次 do(v) 干预**：材料（BRDF、透明度、反射、次表面散射）的像随视点协变；标定漂移（内外参、焦距）对视角不变；真实故障（镜头污点、坏像素、卡死、遮挡）固定在像平面或固定在某一路。于是「残差随视点怎么变」本身是一张诊断指纹——R68 的残差分析只有「幅度」，R69 增加了「视角响应」这一维。视角响应把「世界变了 / 传感器歪了」的二选一，升级为「共模 / 材料协变 / 单路特异」的三分解。

**灵感 2（材料选型 → 材料既是混淆变量，也是设计旋钮）**
直觉（运行时）：材料属性是横跨多个模态的**共享原因**——高光同时欺骗视觉深度与光度，软材料同时让力觉滞后与视觉形变，热膨胀同时改变外参与力零偏。R68 把这些统统当传感器问题去标定，等于用错误的解释去拟合。把材料潜变量 m_t 显式建出来，残差才有正确的去处：能被材料解释的，既不进标定，也不判故障。
直觉（设计时）：材料选型是一个可优化的**实验设计**问题。哑光标定板让镜面歧义消失，低蠕变夹爪垫让慢泄漏不被掩盖，低热膨胀外壳让温漂变小，高发射率表面让热成像可信。目标不是「选最好的材料」，而是**选让故障彼此最可分（最大最小签名距离）的材料组合**——把材料选择写成可诊断性码的设计问题，而不是经验选材。

**灵感 3（合流 → 从「校准」升级到「可辨识」）**
R68 的失败模式是：只要残差足够慢，COF 就吸收；它从未问「这个残差方向是可辨识的吗」。R69 引入可辨识裕度 ρ_id：当材料效应子空间与标定效应子空间的夹角太小（视角多样性不足、单视点、固定光照），c 与 m 不可分，此时**必须锁闭该方向的标定**，而不是硬标。合流后的闭环是：MVD 把残差按「视角不变 / 协变 / 特异」拆开 → MIL 估计材料潜变量 → GCL 只在可辨识子空间更新标定 → AMP 在决策敏感时花极小预算主动探测 → MCS 把材料不确定注入安全包络。R68 的「先标定后归因」升级为「**先判可辨识，再标定，最后归因**」。

**灵感 4（五组件 + 继承核）**
1. **MVD Multi-View Decomposition**：多视角残差张量分解为视角不变 a_t、视角协变（材料）B_t、视角特异（故障/遮挡）E_t；
2. **MIL Material Identifiability Library**：材料潜变量 + 多模态材质指纹库 + 「未知材料」开放集质量；
3. **GCL Gated Calibration Lockout**：投影 EKF，只在可辨识子空间更新 c_t，不可辨识方向冻结且不确定度只增不减；
4. **DMS Diagnosability-aware Material Selection**：离线最大化「最坏材料分布下故障签名最小距离」的选型；
5. **AMP Active Material Probing**：决策敏感时以信息增益门控的轻量探测（轻触 / 换视角 / 偏振切换）；
6. **MCS + RAS-CALM† 继承核**：材料条件安全包络叠加 R68 的 COF/CFA/CAC/MTM 全部机制。

**灵感 5（对 R68 最大风险的对症下药）**
R68 风险：缓变故障落在标定带宽内被「标好」。R69 的回答：缓变故障与慢漂移的区别不只在快慢，更在**跨视角/跨模态的协变结构**——力零偏漂移是模态特异且视角无关；材料蠕变会让视觉形变与力读数一致协变；单路镜头污染是视角特异。多视角×多模态的一致性矩阵把三者分开，GCL 拒绝把模态特异的慢残差吸收进标定。于是「标定能力越强、缓变故障越隐形」的原罪被部分解除：标定能力被限制在可辨识子空间内，且不可辨识时不确定度只增不减，只会更保守。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（MAVIS-RAS 总览）** MAVIS-RAS = (MVD, MIL, GCL, DMS, AMP, MCS, RAS-CALM†)。四条不变式：
(i) **实时流零学习写操作**（继承 R68）：实时流只做前向推理 + 投影滤波，一切参数更新在影子流、经 CAC 认证原子换装；
(ii) **可辨识门控**：COF 只沿可辨识子空间更新 c_t，不可辨识方向冻结；冻结期间 Σ 只增不减（U 不得因锁闭而虚假下降）；
(iii) **材料不确定单调保守**：材料后验越分散、可辨识裕度越低，λ_risk 越高、力/速上限越低，绝不放宽；
(iv) **视角多样性下限**：有效视角秩 rank(V_eff) < r_min 时不得宣称多视角冗余，退化为单视角并同步抬高 U 与 λ。

**定义 294（多视角残差张量与三分解）** 设 V 路视角、观测算子给出视点对 (i,j) 的几何残差 r^geo_{ij}（重投影）、光度残差 r^ph_{ij}、以及与触觉/力的跨模态残差 r^cm。堆叠为 R_t ∈ ℝ^{V×V×d}。分解：
R_t = 𝟙𝟙ᵀ ⊗ a_t + B_t + E_t + N_t，
其中 a_t 为**视角不变共模**（标定漂移、真实场景变化），B_t 为**视角协变项**且落在材料结构化子空间 span{∂h/∂m_k(v_i,v_j)}（BRDF/接触模型给出的可预测视图响应），E_t 为**视角特异稀疏项**（单路故障、遮挡、污损、坏像素），N_t 为噪声。投影算子 P_inv、P_cov、P_idio 分别由视点对中位数、材料基最小二乘、鲁棒稀疏分解实现。

**定义 295（材料潜变量与材质指纹库）** m_t ∈ ℳ ⊂ ℝ⁶ = (α_s 镜面指数, τ 透明度, k_s 柔顺度, μ 摩擦系数, κ_th 热扩散率, ε 发射率)。材料在两次接触事件之间分段常值（m_{t+1}=m_t，接触切换时允许跳变）。材质指纹 F(m) = (视点-光度响应, 力-位移曲线, 热响应) 由多模态测量给出。库 𝒟_mat = {(m_j, π_j, F_j)}_{j=1}^{64} ∪ {m_⊥}，m_⊥ 为开放集「未知材料」，其质量为 p(m_⊥)。

**定义 296（可辨识裕度 ρ_id）** 在当前场景与视点构型处线性化 r ≈ J_c δc + J_m δm + n。记 Q_c、Q_m 为 J_c、J_m 列空间的正交基，主角度余弦 γ = σ_max(Q_cᵀ Q_m) ∈ [0,1] 度量「标定能解释的残差方向」与「材料能解释的残差方向」的混淆程度。定义**可辨识裕度** ρ_id = 1 − γ。语义：ρ_id = 1 表示材料效应完全落在标定效应之外（完全可分）；ρ_id → 0 表示材料可被标定完美冒充（彻底混淆）。可辨识判据：ρ_id ≥ τ_id（默认 0.7）且 rank(J_m) ≥ r_min（默认 r_min = 2）。

**定义 297（GCL 投影标定）** 令 P_id 为标定参数空间中对混淆方向的正交补投影（由 Q_c、Q_m 的广义特征分解得到）。COF 更新改为
c ← c + K P_id (r − r̂_c)，Σ ← Σ + Q_cal（仅在 P_id 子空间）。
门控 g_cal(t) = 1[ρ_id ≥ τ_id ∧ h_view ≥ h_min]。当 g_cal = 0：冻结 c，Σ ← Σ + Q_lock（Q_lock ⪰ 0），于是 U = tr(Σ) 单调上升，经 R68 的 CAR 自动抬高 λ、收缩 k。**锁闭不等于遗忘，锁闭等于承认不知道。**

**定义 298（可诊断性材料选型 DMS）** 设计变量 s ∈ 𝒮（传感器视窗镀层、夹爪垫片、外壳、标定板涂层、照明/偏振配置）。对故障假设 h ∈ H，物理/学习模型给出签名均值 μ_h(s, m) 与协方差 Σ_h(s, m)。定义可诊断性
D(s) = min_{h≠h'} min_{m ∈ supp(𝒟_mat)} ‖μ_h(s,m) − μ_{h'}(s,m)‖²_{Σ^{-1}}。
选型为鲁棒 max-min 设计：
s* = argmax_{s∈𝒮} D(s)  s.t.  cost(s) ≤ B_s, 安全/热力学/工艺约束。
直觉：这是在「材料」这组设计变量上设计一个故障签名码，使任意两种故障在最坏材料工况下的最小签名距离最大——把选材从经验变成可证明的诊断增益。

**定义 299（材料条件安全包络 MCS）** 映射 (m̂, p(m), ρ_id) → (λ_mat, f_max, v_max, grasp_mode, sensor_weight)：
λ_mat = λ⁰·(1 + κ_m·H(p(m)))·(1 + κ_ρ·(1−ρ_id))，
其中 H(p) 为后验熵，sensor_weight 向「对当前材料最不敏感」的模态倾斜（如透明物体降视觉权重、升力/触觉权重）。单调性要求：H↑ 或 ρ_id↓ ⇒ λ_mat↑、f_max↓、v_max↓。**最坏材料界**：对 p(m) 的支撑集取安全裕度最小者，得到 τ_cmd 的最坏情形界。

**定义 300（AMP 主动材料探测）** 探测集 A_probe = {轻触测柔顺, 视点平移 Δv, 偏振切换, 结构光图案, 短时滑动测摩擦}。每次探测的决策价值：
VoI(a) = I(m; r_a | a) · Δ_decision(a)，Δ_decision = E[|Δ(H, λ, k)| | a]。
仅当 VoI(a) ≥ τ_probe 且 Δ_decision ≥ τ_dec 且探测本身通过 MCS 安全包络时执行；预算 B_probe 个/T 秒。探测只能用于**收紧**后续 λ，绝不因「探测后更确定」而放宽到 λ_floor 以下。

**定义 301（视角健康与鲁棒聚合）** 单路健康度 h_v ∈ [0,1] 由对极内点率、过曝/欠曝比例、模糊度、遮挡掩膜给出。有效视点集 V_eff = {v : h_v ≥ τ_h}。聚合用加权中位数 + Huber，单路失效只降权、不否决全局。视角多样性秩 r_view = rank(视差矩阵 | V_eff)；若 r_view < r_min，则触发定义 293-(iv) 的单视角退化与保守抬升。

**定义 302（因果结构：视点作为工具变量）** 结构因果模型：m → (外观, 触觉, 热)；c → 全部传感器；h → 传感器子集；v → 仅外观。视点由机器人主动控制，满足外生性假设 A95：v ⟂ (c, h) | scene。则对 r 施加 do(v) 只改变材料的外观实现，不改变 c 与 h；视点响应矩阵因此识别 J_m，视点不变分量张成 J_c 与 h 的可解释空间。这是「多视角可分离材料/标定」的因果依据。

**定义 303（J_MAVIS 证书）** J_MAVIS = (J_CALM, view_diversity_rank, ρ_id^{worst}, material_hash, material_db_ver, lockout_mask, probe_log, dms_selection_id)。Valid ⇔ Valid(J_CALM) ∧ (ρ_id^{worst} ≥ τ_id^hard 或 lockout_mask 已置位) ∧ 最坏材料安全界未被越过 ∧ 未发生「材料为真故障开脱」（见定义 308）。

**定义 304（AIC-MAVIS 干扰集）** ℰ_MAVIS = ℰ_CALM × ℰ_view × ℰ_mat × ℰ_select：
ℰ_view = {视角饥饿（有效视角不足）、共位视角（基线≈0）、遮挡、共模光照}；
ℰ_mat = {材料伪装（镜面/透明/回反射/低发射率涂层）、未知材料、材质对抗样本};
ℰ_select = {选型过拟合仿真、材料老化与库失配、可诊断性虚假达标}。

**定义 305（管线）** 离线：DMS 选材 → 在多视角仿真 + 真实数据训练 MVD/MIL → 在可辨识子空间上标定 → 认证冻结。在线：R68 CALM 主循环内嵌 MVD（每拍）→ MIL 后验 → GCL 投影标定 → MCS 包络 → 门控 AMP → 继承的认证前缀与 CAC 提交。硬件/材料变更触发离线 re-DMS 与库版本更新。

**定义 306（材料诱发的伪标定残差与投毒势）** 定义 r^mat_t = P_c(r_t) 中可由材料解释的分量；投毒势 Φ_p = ‖P_conf r^mat‖ / (‖r‖+ε)，其中 P_conf 为混淆方向投影。GCL 的设计目标是把标定偏差控制在 ‖b_c‖ ≤ κ_p·Φ_p；ρ_id → 1 时 Φ_p → 0（材料残差完全落在标定之外，无法投毒）。

**定义 307（诊断签名与最小距离）** 对故障 h，签名 μ_h = E[三分解结构 | h]（含视角不变性、模态特异性的模式）。签名矩阵 M_H = [μ_h]。最小签名距离 d_min = min_{h≠h'} ‖μ_h − μ_{h'}‖_{Σ^{-1}}。DMS 直接最大化最坏材料下的 d_min。

**定义 308（材料后验与开放集纪律）** p(m|r) ∝ p(r|m)·p(m)，并保留开放集质量 p(m_⊥)。**开放集纪律**：若 p(m_⊥) > τ_unk，则材料解释不得用于下调 P(H_sensor)（未知材料不能为传感器开脱）；材料只能作为「加罪于环境」的解释，不能作为「赦免传感器」的解释。此纪律防止材料潜变量退化为新的万能吸收器。

**定义 309（最坏材料安全界）** 对材料后验支撑集取最坏情形：τ_cmd ∈ [τ_min(m), τ_max(m)]，要求对 ∀m ∈ supp(p(m)) 满足安全约束；若支撑集不可枚举，用分位数 + 矩界给出保守外包。材料不确定度增高只会扩大最坏界并收紧 λ，绝不缩小。

## 2. 关键算法骨架

```python
# IP-253 MVD：多视角残差三分解（视角不变 / 协变材料 / 特异故障）
class MultiViewDecomposer:
    def __init__(self, mat_basis):
        self.Bmat = mat_basis          # ∂h/∂m 在各视点对上的结构化基

    def decompose(self, R):            # R[i,j] = 视点 i,j 的配对残差
        a = np.median(R, axis=(0, 1))  # 视角不变共模：标定漂移 / 真实场景变化
        B = self.project(R - a, self.Bmat)      # 视角协变：材料结构化子空间
        E = self.sparse_residual(R - a - B)     # 视角特异：故障 / 遮挡 / 污损
        return a, B, E, {'rank': effective_rank(R), 'health': view_health(R)}


# IP-254/296 MIL + 可辨识裕度（主角度）
def identifiability(J_c, J_m):
    Qc, _ = np.linalg.qr(J_c)
    Qm, _ = np.linalg.qr(J_m)
    gamma = float(np.linalg.svd(Qc.T @ Qm, compute_uv=False)[0])  # 主角度余弦
    return 1.0 - gamma, gamma            # rho_id, 混淆系数


class MaterialLibrary:
    def posterior(self, B, obs, prior):
        # 材质指纹匹配 + 开放集质量；返回 (m_hat, p_m, p_unknown)
        return match_fingerprint(B, obs, self.DB, prior)


# IP-257 GCL：投影标定（只在可辨识子空间更新）
class GatedCalibrationLockout(CalibrationObservationFilter):
    def step(self, z_cal, r, sigma_stat, J_c, J_m):
        rho_id, gamma = identifiability(J_c, J_m)
        if rho_id < TAU_ID:                       # 不可辨识 → 锁闭
            self.S += Q_lock                      # 不确定度只增不减
            U = np.trace(self.S)
            return self.c, U, self.thresholds(U), False
        P_id = self.identifiable_projector(J_c, J_m)  # 混淆方向正交补
        self.predict()
        self.update_projected(P_id @ np.r_[z_cal, r],
                              R_static if sigma_stat > 0.9 else R_dynamic, P_id)
        self.rate_limit()
        U = np.trace(self.S)
        return self.c, U, self.thresholds(U), True


# IP-255 DMS：可诊断性感知的材料选型（离线，最坏材料分布下）
def select_materials(candidates, fault_model, material_support, budget):
    best, best_d = None, -np.inf
    for s in candidates:                          # 镀层 / 垫片 / 外壳 / 标定板 / 偏振
        if cost(s) > budget:
            continue
        d = min(mahalanobis(fault_model.mu(h1, s, m), fault_model.mu(h2, s, m),
                            fault_model.Sigma(s, m))
                for h1, h2 in pairs(FAULTS) for m in material_support)
        best, best_d = (s, d) if d > best_d else (best, best_d)
    return best, best_d                           # 最大化最坏情形最小签名距离


# IP-256 AMP：信息增益门控的主动材料探测
def maybe_probe(p_m, decision_sensitivity, budget):
    if budget.left <= 0 or decision_sensitivity < TAU_DEC:
        return None
    for a in PROBES:                              # 轻触 / 换视角 / 偏振 / 结构光
        voi = expected_ig(p_m, a) * decision_impact(a, p_m)
        if voi >= TAU_PROBE and mcs_is_safe(a):
            budget.spend(a)
            return a
    return None


# IP-262 主闭环：MAVIS round（内嵌 R68 CALM）
def MAVIS_round(M, obs):
    # 0) 多视角残差 + R68 感知（共享 CALM 骨干）
    R = M.mvd.residuals(obs.views, obs.tactile, M.c_cache)
    a, B, E, vst = M.mvd.decompose(R)                       # 1) 三分解
    m_hat, p_m, p_unk = M.mil.posterior(B, obs, M.material_prior)  # 2) 材料后验
    J_c, J_m = M.jacobians(M.c_cache, m_hat, obs.view_geom)
    rho_id, _ = identifiability(J_c, J_m)                    # 3) 可辨识裕度
    c, U, thr, gate = M.gcl.step(M.cal_obs, a + E, sigma_stat(M), J_c, J_m)  # 4) 投影标定

    # 5) 归因：只有去掉材料解释后的残差才进故障后验（开放集纪律）
    r_res = E - M.mil.explain(B, m_hat)
    joint = M.cfa.calibrate_first_attribution(r_res, obs.face, c, U)
    if p_unk > TAU_UNK:                                      # 未知材料不赦免传感器
        joint = no_material_absolution(joint)

    # 6) 材料条件安全包络 + 决策敏感时的主动探测
    mcs = M.mcs.envelope(m_hat, p_m, rho_id)
    probe = M.amp.maybe_probe(p_m, decision_sensitivity(joint, mcs), M.probe_budget)
    if probe is not None:
        return ('PROBE', probe, mcs)                         # 轻量介入，下一拍重估

    # 7) 继承 CALM：认证前缀 + 风险缩放（叠加材料下限）
    A = M.ach.propose(M.lsf.fuse(M.usr.fuse(*obs[:4])), H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint, min(M.vista.m, M.m_emo),
                                    M.alpha_chunk)
    if not gate or rho_id < TAU_ID:
        k = min(k, k_id_shrink(rho_id))                      # 不可辨识 → 前缀收缩
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
              mcs.lam_floor, M.mcs.worst_case_floor(p_m))    # 单调保守
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = emotion_response_shaping_wm(tau, joint, M.mtm.rollout(...))

    # 8) 异步：审计 + 影子提交（继承 R68）
    M.vqa_c.submit_async({'cal_event': (c, U), 'mat': (m_hat, rho_id),
                          'joint': joint})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint, {'c': c, 'U': U, 'rho_id': rho_id, 'm': m_hat}
```

## 3. 推导

**引理 16（视点工具变量可辨识性）** 在 A95（视点外生）与定义 294 的结构假设下，视点差分算子 D_v 湮灭视角不变项 a_t，故 D_v R = D_v J_m δm + D_v n。若 rank(D_v J_m) = dim(m)（视角多样性充分），则 δm 可由视点响应唯一识别；从 R 中减去材料项后，剩余视角不变分量张成标定与真实场景变化，再结合 R68 的慢变/静态段先验即可识别 δc。若同时材料效应与标定效应的主角度余弦 γ < 1，则 δc 与 δm 局部可分辨，ρ_id = 1−γ > 0。系：**增加独立视点不会降低可辨识裕度（单调不减）**，因为新增视点只会给 J_m 增加新的行块。

**引理 17（标定投毒界）** GCL 只在 P_id 子空间更新，且 P_id 与混淆方向正交。材料残差 r^mat = J_m δm 在可辨识标定方向上的泄漏为 ‖P_id r^mat‖ ≤ γ·‖r^mat‖（γ 为主角度余弦）。故标定偏差满足
‖E[b_c]‖ ≤ ‖K‖·γ·‖r^mat‖ + ‖K‖·ε_id ≤ κ_p·Φ_p + κ_ε ε_id，
其中 ε_id 为 ρ_id 估计误差。ρ_id → 1（γ → 0）时投毒项消失；门控关闭时 c 冻结且 Σ 增长，偏差不再累积。系：**R68 的「慢故障被标定吸收」在可辨识方向被显著削弱，在不可辨识方向被替换为「不确定度增长 + 保守收缩」，而不是静默吸收**。

**引理 18（材料选型的可诊断性界）** 设故障签名近似高斯且协方差相近，Sanov/Chernoff 界给出两两误判概率 ≤ exp(−d_min²/8)。对 |H| = K 种故障，并集界 P_mis ≤ (K−1)·exp(−d_min²/8)。由于 DMS 直接最大化最坏材料下的 d_min，它同时最小化最坏情形误诊率上界。系：材料选型提供了**设计阶段的、可证明的诊断保证**，而不仅是经验提升。

**定理 16（MAVIS 端到端风险一致性）** 在 A87–A95 下，输出 τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_mat + α_id**，其中 α_mat 由材料后验开放集质量界定，α_id 由引理 17 的投毒界限制；
2. ρ_id < τ_id ⇒ GCL 锁闭标定 ∧ U 单调上升 ∧ λ_risk ≥ 0.8 ∧ k 增加 k_id 收缩——**不可辨识永远导向收缩**；
3. p(m_⊥) > τ_unk ⇒ 材料不得下调 P(H_sensor)（开放集纪律），真故障不会被「未知材料」开脱；
4. 若故障签名在材料子空间正交补上有非零分量（μ_f ⟂ span(J_m) 且分量 ≥ τ_det），则其慢变检出概率下界与无材料层时相同——**这直接回应 R68 的缓变故障被吸收风险**；
5. 视角秩不足 ⇒ 退化为单视角但 λ 抬升，系统不会「静默地失去冗余」。

**定理 17（材料选型的设计保证）** 若 DMS 选择 s* 满足 D(s*) ≥ d_min 且在支撑集上 rank 条件成立，则任意两故障在最坏材料下的误诊概率 ≤ (K−1)exp(−d_min²/8)，且标定投毒势 Φ_p ≤ κ_p。即：**选材把「可诊断性」变成了可验收指标**。

**定理 18（主动探测的安全性）** 在探测预算 B_probe 与 MCS 包络约束下，探测引起的安全越界概率 ≤ B_probe·δ_probe + P_base；探测带来的信息增益只用于收紧 λ 与收缩 k，且 λ 永不低于 λ_floor。系：主动探测是「花钱买确定性」，方向只能是更保守。

## 6. 本轮最大风险

**次级风险与缓解**：
1. **可辨识性被高估**：视角共位/共光照/固定基线使真实 ρ_id 远低于估计 → 留出视角交叉验证 + 注入已知扰动的 ρ_id 保真度校准 + 保守先验；
2. **材料库开放集失配**：未知材料被硬塞进已知类 → 开放集质量 + 定义 308 纪律，未知材料不得为传感器开脱；
3. **材料伪装/对抗涂层**：镜面、回反射、透明可伪造「正常」 → 偏振/多光谱 + 触觉交叉 + DMS 预留鉴别通道；
4. **DMS 对仿真过拟合**：仿真材料参数域随机化 + max-min 鲁棒选型 + 真实小样本复核；
5. **多视角开销与同步**：硬件同步、下采样特征、事件触发 MVD（仅当视角响应可能改变决策时全量计算）；
6. **长期锁闭导致永久保守**：主动探测 + 维护提示 + 重新标定计划；宁可保守，绝不静默放宽。

**一句话**：MAVIS-RAS 的全部安全增益都押在「视角多样性足以让 ρ_id 可估且真实」这一可辨识性假设上——若实际部署中视角高度共位（腕部单相机、固定光照、刚性共架）或材料库失配，真实 ρ_id 被高估，GCL 会在「已辨识」的幻觉下继续标定，同时「未知材料」又可能为真故障开脱；届时**材料潜变量就成了新的万能吸收器**，正如 R68 的标定吸收故障——我们只是把「不可辨识」换了个名字。这是本方案的原罪：**它必须先知道什么可辨识，才能安全地标定。**

**定义 294（多视角残差三分解）** `R_t = 𝟙𝟙ᵀ⊗a_t + B_t + E_t + N_t`：a_t 视角不变（标定漂移/真实场景变化），B_t 视角协变且落在材料结构化子空间 span{∂h/∂m_k(v_i,v_j)}，E_t 视角特异稀疏（单路故障/遮挡/污损）。投影 P_inv/P_cov/P_idio 分别由视点对中位数、材料基最小二乘、鲁棒稀疏分解实现。

**定义 295（材料潜变量与指纹库）** `m_t=(α_s,τ,k_s,μ,κ_th,ε)`，接触事件间分段常值；库 𝒟_mat={(m_j,π_j,F_j)}₆₄ ∪ {m_⊥}；F(m) 为视点-光度响应 + 力-位移曲线 + 热响应。

**定义 296（可辨识裕度）** 线性化 `r≈J_c δc+J_m δm+n`；`γ=σ_max(Q_cᵀQ_m)`；`ρ_id=1−γ`。判据 `ρ_id ≥ τ_id`（默认 0.7）且 `rank(J_m) ≥ r_min`（默认 2）。

**定义 297（GCL 投影标定）** `c ← c + K P_id (r−r̂_c)`，`Σ ← Σ+Q_cal` 仅在 P_id 子空间；`g_cal=1[ρ_id≥τ_id ∧ h_view≥h_min]`；门控关闭时冻结 c 且 `Σ←Σ+Q_lock`，U 单调上升，经 CAR 自动保守。

**定义 298（DMS 选材）** 设计变量 s∈𝒮（视窗镀层/夹爪垫/外壳/标定板/偏振照明）；鲁棒 max-min：`s*=argmax_s min_{h≠h'} min_m ‖μ_h−μ_{h'}‖²_{Σ⁻¹}` s.t. 成本/安全/工艺约束。把选材写成故障签名码设计。

**定义 299（材料条件安全包络 MCS）** `λ_mat=λ⁰(1+κ_m H(p(m)))(1+κ_ρ(1−ρ_id))`；H↑ 或 ρ_id↓ ⇒ λ↑、f_max↓、v_max↓；sensor_weight 向对当前材料最不敏感的模态倾斜；对后验支撑集取最坏安全界。

**定义 300（AMP 主动探测）** `VoI(a)=I(m;r_a|a)·Δ_decision(a)`；仅在 `VoI≥τ_probe ∧ Δ_decision≥τ_dec` 且探测本身通过 MCS 时执行；预算 B_probe/T；探测只用于收紧 λ，不得低于 λ_floor。

**定义 301（视角健康与鲁棒聚合）** h_v 由对极内点率/过曝/模糊/遮挡给出；V_eff={h_v≥τ_h}；加权中位数+Huber；多样性秩 `r_view=rank(视差矩阵|V_eff)`；秩不足触发单视角退化与保守抬升。

**定义 302（视点工具变量因果模型）** SCM：m→(外观,触觉,热)，c→全部传感器，h→传感器子集，v→仅外观；外生性 A95：`v ⟂ (c,h) | scene`。do(v) 只改变材料的外观实现，故视点响应识别 J_m，视点不变分量张成 J_c 与 h。

**定义 303（J_MAVIS 证书）** `(J_CALM, view_diversity_rank, ρ_id^{worst}, material_hash, material_db_ver, lockout_mask, probe_log, dms_selection_id)`；Valid ⇔ Valid(J_CALM) ∧（ρ_id^{worst}≥τ_id^hard 或锁闭已置位）∧ 最坏材料安全界未越 ∧ 无「材料为真故障开脱」。

**定义 304–305（干扰集/管线）** ℰ_MAVIS=ℰ_CALM×ℰ_view×ℰ_mat×ℰ_select；离线 DMS 选材 → 多视角自监督训练 → 可辨识子空间标定 → 在线 MVD/MIL/GCL/MCS/AMP + 继承 CALM 认证提交；硬件/材料变更触发 re-DMS。

**定义 306–309（投毒势/签名/开放集/最坏界）** `Φ_p=‖P_conf r^mat‖/(‖r‖+ε)`，GCL 目标 `‖b_c‖≤κ_pΦ_p`；签名 μ_h 与 `d_min`；开放集纪律 `p(m_⊥)>τ_unk ⇒ 材料不得下调 P(H_sensor)`；最坏材料安全界对 p(m) 支撑集取保守外包，材料不确定只会收紧。

# IP-253 MVD：多视角残差三分解
class MultiViewDecomposer:
    def __init__(self, mat_basis):
        self.Bmat = mat_basis                     # ∂h/∂m 的结构化视点响应基
    def decompose(self, R):                       # R[i,j]：视点对 (i,j) 残差
        a = np.median(R, axis=(0, 1))             # 视角不变共模
        B = self.project(R - a, self.Bmat)        # 视角协变（材料）
        E = self.sparse_residual(R - a - B)       # 视角特异（故障/遮挡）
        return a, B, E, {'rank': effective_rank(R), 'health': view_health(R)}

# IP-254/296：可辨识裕度（主角度）
def identifiability(J_c, J_m):
    Qc, _ = np.linalg.qr(J_c); Qm, _ = np.linalg.qr(J_m)
    gamma = float(np.linalg.svd(Qc.T @ Qm, compute_uv=False)[0])
    return 1.0 - gamma, gamma                     # rho_id, 混淆系数

# IP-257 GCL：投影标定 + 锁闭
class GatedCalibrationLockout(CalibrationObservationFilter):
    def step(self, z_cal, r, sigma_stat, J_c, J_m):
        rho_id, gamma = identifiability(J_c, J_m)
        if rho_id < TAU_ID:                       # 不可辨识 → 锁闭
            self.S += Q_lock; U = np.trace(self.S)
            return self.c, U, self.thresholds(U), False
        P_id = self.identifiable_projector(J_c, J_m)
        self.predict()
        self.update_projected(P_id @ np.r_[z_cal, r],
                              R_static if sigma_stat > 0.9 else R_dynamic, P_id)
        self.rate_limit(); U = np.trace(self.S)
        return self.c, U, self.thresholds(U), True

# IP-255 DMS：可诊断性感知的材料选型（离线，最坏材料下）
def select_materials(candidates, fault_model, material_support, budget):
    best, best_d = None, -np.inf
    for s in candidates:
        if cost(s) > budget: continue
        d = min(mahalanobis(fault_model.mu(h1, s, m), fault_model.mu(h2, s, m),
                            fault_model.Sigma(s, m))
                for h1, h2 in pairs(FAULTS) for m in material_support)
        best, best_d = (s, d) if d > best_d else (best, best_d)
    return best, best_d

# IP-256 AMP：VoI 门控主动探测
def maybe_probe(p_m, decision_sensitivity, budget):
    if budget.left <= 0 or decision_sensitivity < TAU_DEC: return None
    for a in PROBES:                              # 轻触/换视角/偏振/结构光
        voi = expected_ig(p_m, a) * decision_impact(a, p_m)
        if voi >= TAU_PROBE and mcs_is_safe(a):
            budget.spend(a); return a
    return None

# IP-262 主闭环
def MAVIS_round(M, obs):
    R = M.mvd.residuals(obs.views, obs.tactile, M.c_cache)
    a, B, E, vst = M.mvd.decompose(R)                          # 三分解
    m_hat, p_m, p_unk = M.mil.posterior(B, obs, M.material_prior)
    J_c, J_m = M.jacobians(M.c_cache, m_hat, obs.view_geom)
    rho_id, _ = identifiability(J_c, J_m)
    c, U, thr, gate = M.gcl.step(M.cal_obs, a + E, sigma_stat(M), J_c, J_m)
    r_res = E - M.mil.explain(B, m_hat)                        # 去材料后残差
    joint = M.cfa.calibrate_first_attribution(r_res, obs.face, c, U)
    if p_unk > TAU_UNK: joint = no_material_absolution(joint)  # 未知材料不赦免
    mcs = M.mcs.envelope(m_hat, p_m, rho_id)
    probe = M.amp.maybe_probe(p_m, decision_sensitivity(joint, mcs), M.probe_budget)
    if probe is not None: return ('PROBE', probe, mcs)
    A = M.ach.propose(M.lsf.fuse(M.usr.fuse(*obs[:4])), H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint, min(M.vista.m, M.m_emo), M.alpha_chunk)
    if not gate or rho_id < TAU_ID: k = min(k, k_id_shrink(rho_id))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'], mcs.lam_floor,
              M.mcs.worst_case_floor(p_m))
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = emotion_response_shaping_wm(tau, joint, M.mtm.rollout(...))
    M.vqa_c.submit_async({'cal_event': (c, U), 'mat': (m_hat, rho_id), 'joint': joint})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint, {'c': c, 'U': U, 'rho_id': rho_id, 'm': m_hat}

## 4. 推导

**引理 16（视点工具变量可辨识性）** 视点差分算子 D_v 湮灭视角不变项 a_t，`D_v R = D_v J_m δm + D_v n`。若 `rank(D_v J_m)=dim(m)`（视角多样性充分），则 δm 可唯一识别；减去材料项后的视角不变分量张成标定与真实场景变化，结合 R68 的慢变/静态段先验识别 δc。若标定与材料效应子空间主角度余弦 γ<1，则 δc 与 δm 局部可分，`ρ_id=1−γ>0`。系：增加独立视点使 J_m 增加新行块，**可辨识裕度单调不减**。

**引理 17（标定投毒界）** GCL 只在 P_id 子空间更新且 P_id ⟂ 混淆方向。材料残差在可辨识标定方向上的泄漏 `‖P_id r^mat‖ ≤ γ‖r^mat‖`，故
`‖E[b_c]‖ ≤ ‖K‖γ‖r^mat‖ + ‖K‖ε_id ≤ κ_p Φ_p + κ_ε ε_id`。
ρ_id→1 时投毒项消失；门控关闭时 c 冻结且 Σ 增长，偏差不再累积。系：R68 的「慢故障被标定吸收」在可辨识方向被显著削弱，在不可辨识方向被替换为「不确定度增长 + 保守收缩」，而非静默吸收。

**引理 18（材料选型可诊断性界）** 高斯签名近似下两两误判概率 ≤ exp(−d_min²/8)；K 种故障并集界 `P_mis ≤ (K−1)exp(−d_min²/8)`。DMS 最大化最坏材料下的 d_min，即最小化最坏误诊率上界。系：选材提供了**设计阶段可证明的诊断保证**。

**定理 16（MAVIS 端到端风险一致性）** A87–A95 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_mat+α_id`（α_mat 由开放集质量界定，α_id 由引理 17 限制）；
2. `ρ_id<τ_id ⇒ 锁闭 ∧ U↑ ∧ λ_risk≥0.8 ∧ k_id 收缩`——不可辨识永远导向收缩；
3. `p(m_⊥)>τ_unk ⇒ 材料不得下调 P(H_sensor)`——真故障不被「未知材料」开脱；
4. 故障签名在材料子空间正交补上有 ≥τ_det 分量 ⇒ 慢变检出概率下界与无材料层相同（**直接回应 R68 缓变故障风险**）；
5. 视角秩不足 ⇒ 退化单视角但 λ 抬升，不静默失去冗余。

**定理 17（材料选型的设计保证）** 若 DMS 选择 s* 满足 D(s*)≥d_min 且支撑集上秩条件成立，则最坏材料下两两误诊概率 ≤ (K−1)exp(−d_min²/8)，且 Φ_p ≤ κ_p——选材把可诊断性变成可验收指标。

**定理 18（主动探测安全性）** 探测预算 B_probe 与 MCS 约束下，安全越界概率 ≤ B_probe·δ_probe+P_base；信息增益只用于收紧 λ 与收缩 k，λ 永不低于 λ_floor。

## 7. 本轮最大风险

**次级风险与缓解**：可辨识性被高估（留出视角交叉验证 + 注入已知扰动校准 ρ_id + 保守先验）；材料库开放集失配（开放集质量 + 未知材料不得为传感器开脱）；材料伪装/对抗涂层（偏振/多光谱 + 触觉交叉 + DMS 预留鉴别通道）；DMS 对仿真过拟合（材料参数域随机化 + max-min 鲁棒 + 真实小样本复核）；多视角开销/同步（硬件同步 + 下采样 + 事件触发 MVD）；长期锁闭导致永久保守（主动探测 + 维护提示 + 重标定计划，绝不静默放宽）。

**一句话**：MAVIS-RAS 的全部安全增益都押在「视角多样性足以让 ρ_id 可估且真实」这一可辨识性假设上——若实际部署中视角高度共位（腕部单相机、固定光照、刚性共架）或材料库失配，真实 ρ_id 被高估，GCL 会在「已辨识」的幻觉下继续标定，同时「未知材料」又可能为真故障开脱；届时**材料潜变量就成了新的万能吸收器**，正如 R68 的标定吸收故障——我们只是把「不可辨识」换了个名字。这是本方案的原罪：**它必须先知道什么可辨识，才能安全地标定。**
