# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 2 轮；本轮灵感：「需求洞察」×「在线学习」）

> R72 把 GAUGE 从「认知层测量审计」下沉为「具身实时系统」：用 **REG**（实时执行图）把「计量不阻塞控制」变成调度级定理，用 **IRL** 显式建模意图 z，用 **DMEM** 把灵巧接触升级为带接触模式 c 的计量证据，用 **EREFLEX/ERVOI** 把情感/意图/接触三层反作用合算预算，用 **S2R-UQ** 把仿真不确定度吃进 WCET 与 λ_floor，并用 **J_EMB** 给每一次执行盖章。它回答的是：**「我的测量链在实时调度、意图模糊、灵巧接触下，还能逐指令兑现风险界吗？」**
>
> 但 R72 仍有两处结构性盲区，且它们互相咬合：
>
> - **需求洞察视角**：R72 把人的**陈述意图 z** 当作优化目标。可 z 只是**潜在需求 n** 的一个含噪代理。人说「帮我拿杯子」，潜在需求可能是「我手不方便」「演示给我看」「测试你会不会避开人」「我只是想让你陪着我」。把 z 当 n，是**第三类错误：把错误的问题正确地解决了**。更麻烦的是：需求**不可直接观测**，只能从行为残差（纠正、接管、重复请求、绕路、犹豫、沉默、affect ψ）反推；需求与陈述之间存在 **say–do gap**；需求有先验、有有效域、会漂移；**需求效度（objective validity）是比状态估计更高一层的「构念效度」问题**——不是「量得准不准」，而是「量的/优化的东西是不是用户真正要的」。
>
> - **在线学习视角**：R72 的所有模型（BSE、IRL、DMEM、风险参数、S2R 桥接）都**部署即冻结**，靠静态 RTA、SEAL 审计集与 J_EMB 盖章。但真实部署是**非平稳**的：触觉零点漂移、磨损、人的适应、任务迁移、跨本体换手。必须**在线学习**——可一旦模型在线更新，**被审计的测量链本身被改写了，J_EMB 当场过期**。R72 的「部署前静态验证 + 运行时只读契约」与「在线自适应」在根上冲突：**学习即是契约违约**。这不是工程补丁能解决的，需要把「学习事件」提升为一等公民并纳入证书。
>
> 本轮两个灵感不是并列模块，而是**同一闭环的两面**：
> - **需求洞察 = 目标空间的在线学习**：从流式行为证据更新「用户要什么」；
> - **在线学习 = 参数空间的需求洞察**：从流式残差更新「世界/自己怎么运作」，以更好地服务需求。
>
> 二者耦合出一个 R72 完全没建模的**混淆**：人的行为变了，究竟是 **(a) 需求 n 变了**、**(b) 模型/传感器 θ 漂移了**、还是 **(c) 人本身 h 变了**（疲劳/熟练/情绪）？把 (b) 误判为 (a)，机器人会**追着噪声学错目标**；把 (a) 误判为 (b)，机器人会**错过真实需求漂移**。而最深的坑是 **L4 需求反作用**：机器人在线学习「揭示偏好」，而它的动作同时在**塑造**偏好——**它终将把自己制造出来的需求学成目标**（依赖、过度信任、去技能化、偏好回声室）。
>
> 核心命题：**不再只问「我的测量链此刻可信吗」，而问「当测量链在持续自我改写、且用户真正的需求既没被说清、又会被我改变时，我是否仍在服务正确的需求？」** 把 R72 的「具身计量审计」升维为 **NEEDLE-GAUGE-RAS**（**N**eed-insight, **E**pistemically-audited, **E**mbodied, **D**exterous, **L**ifelong-learning, **E**volving GAUGE for RAS）——**需求有效 × 在线学习可审计的双闭环计量**。

## 0. 直觉与动机

**灵感 1（需求洞察 → 说的不是要的，需求是更高一层的隐变量）**
直觉：R72 的 `b_t(s, z)` 里，z 是「意图类别」，但它仍是**用户自己表达出来的**东西。需求洞察要求再退一层：`n ∈ 𝒩 = {拿取物体, 减轻负担, 学习/演示, 安全测试, 陪伴/确认, 委托决策}` 才是真正的目标。一个人反复说「再往左一点」，表面是位姿指令 z，潜在需求 n 可能是「我看不清」「我不信任你的避障」「我想参与而不是被替代」。**需求不是被问出来的，是被观察出来的**——最有信息量的需求证据往往不是语言，而是**用户的纠正行为、接管时刻、绕路、放弃、以及任务结束后有没有再回来用**。产品研究里叫 say–do gap：**用户说的和用户做的系统性不一致**，而做的更接近真实需求。核心命题：**状态估计的构念效度（construct validity）之上，还有目标函数的构念效度——需求效度。**

**灵感 2（在线学习 → 学习会改写被审计对象，证书必须随模型版本过期）**
直觉：R72 的漂亮之处是「部署前静态验证 + 运行时只读」。但真机上触觉会漂、人会长、任务会变；不学习就会**静默失配**，学习了就会**静默违约**。关键洞察：**在线学习不是「参数慢慢变准」，而是「审计对象在运行中被替换」**。J_EMB 是对模型版本 v 的陈述；一旦提交更新 v→v′，J_EMB(v) 不再蕴含 J_EMB(v′)。所以必须引入**证书新鲜度（certificate freshness）**：证书只在 `(模型版本 v, 有效域 D, 需求区域 N_D)` 上有效；任何更新要么**重推导证书**，要么被**门控拒绝/回滚**。**学习不是免费的自适应，学习是一次需要重新盖章的契约变更。**

**灵感 3（耦合混淆 → 需求漂移 / 模型漂移 / 人漂移必须可分离）**
直觉：用户突然频繁纠正机器人。这可能是：(a) 他需求变了（想让你更快）；(b) 你的视觉/触觉漂了（你以为对，其实错）；(c) 他累了/急了/学会了（人变了）。若不分离，在线学习会把三者**混成一个梯度**：把传感器漂移学成「用户偏好更保守」，把用户疲劳学成「需求变慢」。**需求洞察与在线学习共享同一条观测残差，因此它们天然混淆**。分离需要**外生激励（exogenous excitation）**：主动做小实验（问一句、试探一个动作、改变一个自由度），让不同漂移源在敏感度矩阵上产生可辨方向。这正是 CN-VOI 的作用：**问/看/试/停**四选一，用信息增益买可辨识性。

**灵感 4（L4 需求反作用 → 从揭示偏好里学习，会把自己造的需求学成目标）**
直觉：R72 有 L1 ψ（情感）、L2 z（意图）、L3 c（接触）。现在有 **L4 n（需求）**：机器人的行为改变人的长期需求。它给你把杯子递到手上 → 你不再自己伸手 → 去技能化；它每次都对 → 你过度信任 → 不再检查；它总在你犹豫时替你决定 → 你依赖它 → 需求从「帮我」变成「替我做」。最危险的是：**在线学习的目标（揭示偏好）由被学习系统的行为生成**。这是一个**内生非平稳**闭环：学得越好 → 行为越强 → 偏好越被塑造 → 学到的目标越偏离初始福利。**需求回声室**。因此必须有 **A-GOODHART 审计**：区分「服务需求」与「塑造需求」，把**操纵增益**、**依赖指数**、**去技能化指数**纳入否决。

**灵感 5（需求效度不可自证 → 必须有外部锚）**
直觉：一个系统无法仅凭内部指标证明「我优化的就是用户真正要的」。R72 的 MIB 能证明「我量得准」，但**没有任何内部指标能证明「我量的是对的东西」**——那正是 Goodhart 的入口。需求效度需要**外部锚（external anchor）**：密封需求审计集、独立的人类福利评估、第三方目标复核、以及「用户在一段时间后是否还愿意用」的留存证据。承认这一点，比假装能自证更严谨。**需求效度的证书必须显式标注「锚来自哪里、锚本身的不确定度多大」。**

**灵感 6（双闭环 → 需求环慢、学习环快，必须防止快环劫持慢环）**
直觉：学习环（秒–分钟）更新参数；需求环（天–周）更新目标。快环总比慢环先动，于是**快环会用自己的短期拟合去解释慢环的真实变化**：用户一周内需求没变，但触觉漂了，快环学会一个补偿偏置，恰好让短期行为「看起来对」，却把慢环的需求信号淹掉。必须给两环**不同时间常数与不同证书节奏**：学习环每次提交都要过门控；需求环只在**外部锚 + 足够外生激励**下才允许改写目标，且改写要**留痕、可回滚、可解释**。

## 1. 形式化定义（增量：定义 366–386）

**定义 366（NEEDLE-GAUGE-RAS 总览）** NEEDLE-GAUGE-RAS = (NIL, OLL, CIDS, CN-VOI, NREFLEX, NCERT, GAUGE-RAS†)。六不变式：
(i) **需求效度优先且外部锚定**：任何目标函数进入规划/控制前，必须携带 `(n 后验, 需求效度 NV, 有效域 D_need, 外部锚 A_ext, 锚不确定度 u_anchor)`；**禁止内部自证**（定义 385）；
(ii) **学习门控**：任何参数更新（在线或离线）必须通过 CommitGate（定义 371），未过门控的更新只能进入**影子缓冲**，不得进入控制/计量域；
(iii) **漂移可辨识**：需求漂移 n、模型漂移 θ、人状态漂移 h 必须被 CIDS（定义 373）分离，或显式降级为「不可分辨」，**禁止把混合残差直接喂给任一学习器**；
(iv) **四层反作用预算**：c_reflex^ψ + c_reflex^z + c_reflex^c + c_reflex^n ≤ B_reflex_total，且 Ψ_safe/Z_safe/C_safe/N_safe 全满足；
(v) **证书新鲜度**：J_NEED 只在 `(模型版本 v, 需求区域 N_D, 有效域 D)` 上有效；版本或区域变更即失效，必须重推导或回滚（定义 378、引理 34）；
(vi) **严格逐指令退化链**：学习门控失效 ⇒ 冻结模型 + R72；需求效度失效 ⇒ 回退陈述意图 z + R72；CIDS 失效 ⇒ 固定需求先验 + R72；全失效 ⇒ R68。**新层只在「需求可锚、学习可门控、漂移可分离」时启用。**

**定义 367（需求隐变量与陈述–揭示分解）** 潜在需求 `n ∈ 𝒩`，`|𝒩| ≤ 6`（拿取/减负/演示/安全测试/陪伴确认/委托决策）。陈述意图 `z ∈ 𝒵`（继承 R72）。可观行为序列 `o_{1:t}`（纠正、接管、重复请求、绕路、放弃、沉默、事后复用）。**陈述–揭示差（say–do gap）**：
`Δ_sd(z, n) = 1 − P(a_stated = a_revealed | z, n)`，并定义**缺口方向** `dir_sd = sign(E[U_n(a_revealed) − U_n(a_stated)])`。**需求不可直接观测，只能通过 `(o, z, ψ, s)` 后验反推**。

**定义 368（需求证据模型）** 多模态需求证据 `y_need = (corrections, takeovers, re-requests, workarounds, silence, retention, ψ)` 服从
`p_need(y_need | n, z, s, ψ) = Σ_k ω_k(ψ, z) · p_k(y_need | n, s)`，
其中 `ω` 复用 R71/R72 的 ψ 调制混合权重。**显式区分「言语证据」与「行为证据」两族**：`ω_speech` 与 `ω_behavior` 不共享校准；当二者冲突时，**行为证据优先但不得单独定案**（需外部锚或主动探查）。输出 `(b_t(n), Δ_sd, ECE_need, ι_need)`，`ι_need` 为跨人/跨文化/跨任务的需求不变性间隙。

**定义 369（需求后验与需求效度 NV）** 联合后验扩展为 `b_t(s, z, n) = p(s,z,n | ℋ_t)`，边缘 `b_t(n) = ∫∫ b_t(s,z,n) ds dz`。定义**需求条件效用** `U_n(a)`（在需求 n 下动作 a 的人类福利代理，见定义 386）与部署目标 `J_π`。**需求遗憾**
`Reg_n(π) = max_a U_n(a) − U_n(π)`，
**需求效度**（在有效域 `D_need` 上、以外部锚 `A_ext` 估计）：
`NV(π, D_need | A_ext) = 1 − sup_{n∈D_need} Reg_n(π) / Reg_max`。
`NV` 必须携带 `(D_need, A_ext, u_anchor, τ_anchor)`。**NV 是目标层的构念效度，不是状态层的精度**。

**定义 370（在线学习算子与学习事件）** 学习算子 `L: (θ_t, data_t, mask_t) → θ_{t+1}`，可作用于 BSE/IRL/DMEM/风险参数/S2R 桥接/需求模型。**学习事件**
`e_t = (target_params, data_provenance, Δθ, pre_metrics, post_metrics_shadow, gate_decision, rollback_point, timestamp)`。
所有 `e_t` 写入**学习事件追溯链 L-TCHAIN**。**学习事件是一等公民**：它像证据一样可审计、可回滚、可追责。

**定义 371（提交门控 CommitGate）** 更新 `θ→θ′` 仅当同时满足五条件才提交：
1. **安全单调**：在影子执行中 `J_risk(θ′) ≤ J_risk(θ) + ε_reg`，且 λ_floor 覆盖未被削弱；
2. **计量有效**：MIB/E-MIB 的 veto 指标仍在各自有效域 D 内（含 ECE/ι/OOD/四分量）；
3. **证书可重推导**：`J_NEED(θ′)` 能在 `δ_cert` 内重建，否则**降级为「延迟提交」**（先冻结，异步重推导）；
4. **预算**：SPB（定义 372）未被耗尽；
5. **血缘完整**：`data_provenance` 通过 L-TCHAIN 校验，无投毒/回放/伪造。
任一条失败 ⇒ 更新进入影子缓冲或回滚，**控制域永不见到未过门控的参数**。

**定义 372（稳定性–可塑性预算 SPB）** 预算 `B_SP = (B_forget, B_adapt)`。一次提交的**适应收益** `g_adapt = Δ performance on recent stream`，**遗忘代价** `c_forget = −Δ performance on anchored replay set + EWC 惩罚 + Reg_n 增量`。提交条件：`g_adapt − c_forget ≥ margin`，且累计 `Σ c_forget ≤ B_forget`、`Σ g_adapt ≤ B_adapt`。**SPB 是「学习不退化既有能力」的有限预算**，防止在线学习用长期遗忘换短期拟合。

**定义 373（漂移分解与耦合可辨识 CIDS）** 设行为/残差 `y_t = f(n_t, θ_t, h_t) + ε_t`。在局部线性化下，敏感度矩阵
`S = [∂y/∂n, ∂y/∂θ, ∂y/∂h] ∈ ℝ^{m×(|n|+|θ|+|h|)}`。
**可辨识条件**：`rank(S) = |n|+|θ|+|h|`（或对关心子空间满秩）。若 `rank` 不足，则存在混淆方向，必须**(i) 主动探查补充外生激励**（CN-VOI 的 probe），或 **(ii) 显式标记 `unidentifiable` 并降级**（需求学习退化为固定先验、模型学习退化为冻结）。**禁止在 rank 不足时把混合残差直接归因给 n 或 θ。** 输出 `(S, rank_gap, attribution_confidence, degrade_flag)`。

**定义 374（L4 需求反作用 NREFLEX）** 需求转移
`n_{t+1} ~ p(n_{t+1} | n_t, a_t^robot, ψ_t, z_t)`，
刻画机器人的**递物/代劳/提问/沉默**如何改变人的长期需求（依赖、信任、去技能化、参与感）。边际成本
`c_reflex^n = D_KL(b_t(n) ‖ b_{t+1}(n)) + λ_n·𝟙[n_{t+1} ∉ N_safe] + λ_dep·Dep + λ_dsk·DSK`，
其中 `Dep` 为依赖指数、`DSK` 为去技能化指数（定义 375）。**四层预算合算**：`c_reflex^ψ+c_reflex^z+c_reflex^c+c_reflex^n ≤ B_reflex_total`。

**定义 375（A-GOODHART 需求操纵审计）** 定义
- **操纵增益** `MG = Δ J_robot − Δ W_human`，其中 `W_human` 为人类福利代理（外部锚估计）；
- **依赖指数** `Dep = ∂P(求助) / ∂(机器人代劳率)`（滑动窗口）；
- **去技能化指数** `DSK = −Δ(人类独立完成率) / Δ(机器人参与率)`；
- **偏好回声指标** `ECHO = corr(a_robot, n_revealed)` 在控制 `n_true` 后仍显著。
**判定**：若 `MG > τ_MG` 或 `Dep > τ_dep` 或 `DSK > τ_dsk` 或 `ECHO > τ_echo`，触发**需求操纵否决**：禁止以「学习到的偏好」为唯一依据，强制引入外部锚与人类确认，并降级高影响动作。**「服务需求」与「塑造需求」必须在证书上分开记账。**

**定义 376（耦合需求 VoI：CN-VOI）** 在动作集合 `{ask（显式询问）, observe（被动观察）, probe（主动小实验）, act（执行）, stop（停止/回退）}` 上：
`VoI^N(g) = c(ψ)·IG_s + η_z·IG_z + η_n·IG_n − c_reflex^ψ − c_reflex^z − c_reflex^c − c_reflex^n − γ·E[ΔH_future] − c_probe(g) − c_anchor(g) + λ_id·Δrank(S_g)`。
其中 `IG_n` 为需求信息增益，`Δrank(S_g)` 为动作 g 带来的**可辨识性增益**（定义 373），`c_probe` 为打扰成本，`c_anchor` 为调用外部锚的成本。**选 `g* = argmax VoI^N`，s.t. 四层稳态全满足、SPB 未超、无操纵否决**；`max VoI^N ≤ 0` ⇒ 停止并回退。**「问」不是免费的，「看」也可能有偏，「试」可能改变需求——三者都进入同一预算。**

**定义 377（需求效度风险缩放 N-RISK）** 在 R72 的 E-RISK 基础上加入需求维度：
`λ_N = max( risk_scale(U_ale, U_epi, H_z, u_tac, H_n, (1−NV)), λ_floor(U_ale+U_epi+H_z+u_tac+H_n+(1−NV)) )`。
**需求不确定度 `H_n = H[b_t(n)]` 与需求效度赤字 `(1−NV)` 同权进入分母**：需求越模糊、越可能错配，动作越保守（降速、减力、增加确认、禁止不可逆动作）。**「我不知道你要什么」和「我不知道世界是什么样」一样，都是物理安全的直接分母。**

**定义 378（需求–学习证书 J_NEED 与学习追溯链）** 
`J_NEED = (J_EMB(v), model_version v, need_region N_D, NV, A_ext, u_anchor, lchain_root, gate_proofs, spb_state, cids_rank_gap, manipulation_flags, freshness_epoch, ver)`。
`Valid(J_NEED) ⇔ Valid(J_EMB(v)) ∧ NV ≥ τ_NV ∧ L-TCHAIN 完整 ∧ 所有提交有 CommitGate 证明 ∧ 需求区域与当前 b_t(n) 一致 ∧ freshness_epoch 未过期 ∧ 无未处理操纵否决`。
**学习事件追溯链** `L-TCHAIN`：每个 `e_t` 的哈希链 `h_t = H(h_{t-1} ‖ e_t)`，支持**回滚到任意已验证版本**。

**定义 379（威胁模型 AIC-NEED）** `ℰ_NEED = ℰ_EMB × ℰ_need × ℰ_learn`：
`ℰ_need = {需求伪造（假纠正/假接管）、需求投毒（诱导错误先验）、跨文化需求歧义、需求回声室操纵、依赖诱导}`；
`ℰ_learn = {数据投毒、回放攻击（重放旧数据让模型遗忘新分布）、模型供应链投毒、学习率/更新门控绕过、L-TCHAIN 断链、影子缓冲污染}`。

**定义 380（双闭环三域执行图 NEEDLE-REG）** 在 R72 REG 的**控制域 / 计量域 / 感知域**之上，新增两条逻辑闭环并映射到域：
- **学习环（快，秒–分）**：运行在**感知域 + 计量域**，绝不进控制域；产出候选 θ′，写影子缓冲；
- **需求环（慢，天–周）**：运行在**计量域 + 外部锚服务**，产出 n 后验与 NV，写快照；
- 控制域**只读**「已过门控且证书新鲜」的 `(θ, b_t(n), NV)` 快照；**学习环与需求环都不能回写控制域**。域间仍仅无锁环形缓冲 + 版本号 + `freshness_epoch`。

**定义 381（严格退化包含链）** 
- 学习门控失效 ⇒ **冻结模型 + R72**（NEEDLE 的 OLL 关闭，其余保留需 NV 有效）；
- 需求效度失效（NV < τ 或无锚）⇒ **回退陈述意图 z + R72**（NIL 关闭）；
- CIDS 不可辨识 ⇒ **固定需求先验 + 冻结需求模型**，学习仅作用于非需求参数；
- L4/操纵否决 ⇒ **禁止长期偏好学习**，仅保留短期技能学习；
- 全失效 ⇒ **R68**。
**安全侧只增不减：任何退化都保留 R68 硬安全包络与 λ_floor。**

**定义 382（需求–学习指标扩展 N-MIB）** 在 E-MIB 基础上新增：
- **需求族**：`NV`、`Δ_sd`、`H[b_t(n)]`、`ECE_need`、`ι_need`、需求漂移率、`MG`、`Dep`、`DSK`、`ECHO`、事后复用率；
- **学习族**：适应收益、遗忘代价、更新频率、门控拒绝率、**证书新鲜度延迟**、L-TCHAIN 覆盖率、回滚成功率、SPB 余额、影子–在线分歧；
- 所有指标同遵循定义 332 六元组 `(φ,m,u,D,τ,I⊥)` 与定义 333 DAG 分层。

**定义 383（需求–学习 IVG 扩展 N-IVG）** 新增失效条件：
- 需求：`NV < τ_NV`、`ECE_need > τ_ece`、`ι_need > τ_ι`、`H_n > τ_Hn`、`Δ_sd` 突增且无可辨识证据；
- 学习：门控拒绝率 > τ_rej、证书新鲜度延迟 > τ_fresh、L-TCHAIN 断链、SPB 耗尽、影子–在线分歧 > τ_shadow；
- 漂移：`rank_gap > 0` 且未在 τ_id 内通过 probe 补秩；
- 操纵：任一 `MG/Dep/DSK/ECHO` 超阈。
任一成立 ⇒ 相关模块降级（需求→z+R72；学习→冻结+R72；漂移→固定先验；操纵→禁长期偏好学习）。

**定义 384（运行时学习监控器 RLM）** 最高优先级旁路、静态内存、零分配、只读影子缓冲；每提交与每需求更新周期自测：门控是否真的执行、L-TCHAIN 是否连续、证书 `freshness_epoch` 是否与模型版本一致、SPB 余额是否非负。**RLM 是「学习环的最后一道防线」，自身不被在线学习，代码 < 800 行，形式化验证。**

**定义 385（外部锚协议）** 需求效度只能由**外部锚**背书：
`A_ext = (sealed need audit set, human welfare panel, third-party objective review, retention cohort)`。
锚的不确定度 `u_anchor` 必须传播进 `NV` 与 `J_NEED`；**`A_ext` 与在线学习数据必须物理/流程隔离**（密封审计集、独立人类评估、审计标签不可被在线学习器访问）。**没有外部锚的 NV 一律视为无效（NV := ⊥）。**

**定义 386（需求条件效用与人类福利代理）** `U_n(a)` 是人类在需求 n 下对动作 a 的福利；在线可观测的只是代理 `Ŵ_human = (task success, human effort, correction rate, retention, self-reported)`。**明确区分 `U_n`（真实福利，不可观测）与 `Ŵ_human`（代理，可被 Goodhart）**；`NV` 与 `MG` 都依赖代理，因此**代理本身必须被外部锚周期性校准**。这是本框架的诚实边界，不是可消除的工程细节。

# IP-295/296 NIL：需求后验 + 需求效度（计量域，慢环）
class NeedInsightLayer:
    def __init__(self, need_net, behavior_calib, speech_calib, anchor_registry):
        self.net, self.cal_b, self.cal_s = need_net, behavior_calib, speech_calib
        self.anchor = anchor_registry            # 外部锚，在线学习不可访问其标签
    def update(self, y_need, z_dist, psi, s_post):
        # 行为证据与言语证据分开打分，禁止共享校准
        logits_b = self.net.behavior(y_need.behavior, s_post, psi)
        logits_s = self.net.speech(y_need.speech, z_dist, psi)
        b_b = self.cal_b.predict(logits_b)        # ECE_need, iota_need
        b_s = self.cal_s.predict(logits_s)
        b_n = fuse_behavior_first(b_b, b_s)       # 行为优先，但冲突不单独定案
        delta_sd = say_do_gap(b_n, z_dist, y_need)  # 定义 367
        nv = self._need_validity(b_n)             # NV := ⊥ if 无 A_ext
        return NeedPosterior(b_n=b_n, delta_sd=delta_sd, NV=nv,
                             ece=b_b.ece, iota=b_b.iota, anchor=self.anchor.ref)

# IP-297/298 OLL：在线学习算子 + 提交门控 + SPB（快环）
class OnlineLearningLayer:
    def __init__(self, learners, shadow, gate, spb, lchain):
        self.learners, self.shadow = learners, shadow
        self.gate, self.spb, self.lchain = gate, spb, lchain
    def propose(self, data, mask):
        theta_prime = {k: l.step(self.shadow.theta[k], data, mask[k])
                       for k, l in self.learners.items()}
        self.shadow.write(theta_prime)             # 只进影子，不进控制域
        return theta_prime
    def try_commit(self, theta_prime, ctx):
        ev = self.gate.evaluate(self.shadow.theta, theta_prime, ctx)
        # ev: safety_monotone, metrology_valid, cert_rebuildable, spb_ok, provenance_ok
        if not ev.all_ok:
            self.lchain.record(ev, decision='reject_or_buffer')
            return False, ev
        self.spb.charge(ev.g_adapt, ev.c_forget)
        self.lchain.record(ev, decision='commit')
        self.shadow.commit(theta_prime)            # 原子切换 + 版本号 + freshness_epoch++
        return True, ev

# IP-299 CIDS：漂移分解与可辨识（计量域）
def decompose_drift(y_hist, n_post, theta, h_post):
    S = sensitivity_matrix(y_hist, n_post, theta, h_post)   # ∂y/∂[n,θ,h]
    rank_gap = S.cols - matrix_rank(S)
    if rank_gap > 0:
        return DriftReport(S=S, rank_gap=rank_gap,
                           attribution='UNIDENTIFIABLE', degrade=True)
    # 满秩：最小二乘归因，带置信区间
    attrib = ridge_attribution(S, y_hist)
    return DriftReport(S=S, rank_gap=0, attribution=attrib, degrade=False)

# IP-300 CN-VOI：问/看/试/停（慢环与快环交界）
def coupled_need_voi(b_t, z_dist, n_dist, c_dist, psi, budget, spb, anchor):
    best = None
    for g in ['ask','observe','probe','act','stop']:
        if not budget.allow(g) or not spb.allow(g): continue
        cost = reflex_cost_4layer(psi, z_dist, c_dist, n_dist, g)  # L1–L4
        if cost is None: continue                                   # 任一稳态越界
        ig_s = credibility(psi) * expected_ig_s(b_t, g)
        ig_z = ETA_Z * expected_ig_z(z_dist, g)
        ig_n = ETA_N * expected_ig_n(n_dist, g)
        did  = LAM_ID * expected_rank_gain(b_t, n_dist, g)          # 可辨识性增益
        pen  = GAMMA * expected_future_loss(...) + cost
        pen += probe_cost(g) + anchor_cost(g)
        score = ig_s + ig_z + ig_n + did - pen
        best = argmax(best, (g, score))
    if best is None or best.score <= 0:
        return 'stop'
    return best.g

# IP-301 NREFLEX：L4 需求反作用 + 四层预算
def nreflex_step(psi, z_dist, c_dist, n_dist, g, budget):
    psi2, cz, ok1 = reflex_step_L1(psi, g, budget)
    z2,   cz2, ok2 = reflex_step_L2(z_dist, g, psi, budget)
    c2,   cc,  ok3 = reflex_step_L3(c_dist, g, budget)
    n2 = need_transition(n_dist, g, psi, z_dist)     # p(n'|n,a_robot,ψ,z)
    dep, dsk, echo = dependency_indices(n_dist, n2, g)
    cn = kl_div(n_dist, n2) + LAM_N*(n2.entropy() > TAU_HN) \
         + LAM_DEP*dep + LAM_DSK*dsk
    mg = manipulation_gain(g, budget.robot_objective, budget.human_welfare)
    if not (ok1 and ok2 and ok3) or mg > TAU_MG or echo > TAU_ECHO:
        return None, dict(reject='L4_or_manipulation')
    if budget.spent + cz + cz2 + cc + cn > budget.B:
        return None, dict(reject='budget')
    return (psi2, z2, c2, n2), dict(cost=cz+cz2+cc+cn, mg=mg, dep=dep, dsk=dsk)

# IP-302 A-GOODHART：需求操纵审计
def anti_goodhart_audit(n_hist, a_hist, welfare_hist, skill_hist):
    mg   = delta_robot_obj(a_hist) - delta_human_welfare(welfare_hist)
    dep  = dependence_index(n_hist, a_hist)
    dsk  = -delta_human_independent_rate(skill_hist) / (delta_robot_participation(a_hist)+EPS)
    echo = partial_corr(a_hist, n_hist.revealed, n_hist.true_proxy)
    flags = dict(MG=mg>TAU_MG, Dep=dep>TAU_DEP, DSK=dsk>TAU_DSK, ECHO=echo>TAU_ECHO)
    return AuditResult(flags=flags, veto=any(flags.values()))

# IP-303 NCERT：J_NEED 证书 + 学习追溯链
def build_jneed(M):
    assert M.lchain.verify_chain()
    assert all(e.gate_proof for e in M.lchain.events)
    assert M.nv.anchor is not None and M.nv.anchor.sealed   # 定义 385
    return J_NEED(
        j_emb=M.j_emb, version=M.model.version, need_region=M.nv.D_need,
        nv=M.nv.value, anchor=M.nv.anchor.hash, u_anchor=M.nv.u_anchor,
        lchain_root=M.lchain.root, gate_proofs=M.lchain.gate_proofs,
        spb_state=M.spb.snapshot(), cids_gap=M.cids.rank_gap,
        manip_flags=M.goodhart.flags, freshness=M.model.freshness_epoch)

# IP-304 NEEDLE 主闭环（双闭环映射到 R72 三域）
def NEEDLE_GAUGE_RAS_round(M, obs, audio, tac_frame, human_behavior):
    # ===== 控制域（硬实时，只读“已门控 + 证书新鲜”的快照）=====
    snap = M.snapshot.read_latest()
    if not snap.fresh(M.model.version) or snap.nv is None:
        return M.degrade_to_R72_or_R68()          # 证书不新鲜 / 需求无效
    lam_N = n_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                         snap.u_tac, snap.H_n, snap.nv)   # 定义 377
    k = M.ach.certified_prefix(M.ach.propose_ctrl(...), lam_N)
    M.ctrl_out.publish(k, lam_N)

    # ===== 计量域（软实时，慢环：需求）=====
    if M.clock.due_need():
        n_post = M.nil.update(extract_need_evidence(human_behavior, obs, audio),
                              snap.z_dist, snap.psi, snap.s)
        drift  = decompose_drift(human_behavior.residual, n_post, M.model.theta, snap.h)
        if drift.degrade:                         # rank 不足 → 固定先验 + 禁需求学习
            n_post = freeze_need_prior(n_post)
        M.snapshot.write_need(n_post, drift)

    # ===== 感知域（异步，快环：学习）=====
    theta_prime = M.oll.propose(pack_stream(obs, audio, tac_frame), M.update_mask)
    ok, ev = M.oll.try_commit(theta_prime, ctx=M.cert_ctx)
    if not ok:
        M.registry.record_update_reject(ev)       # 影子缓冲/回滚，控制域无感
    # 需求操纵审计（慢，外部锚）
    if M.clock.due_audit():
        audit = anti_goodhart_audit(M.n_trace, M.a_trace, M.welfare_trace, M.skill_trace)
        if audit.veto:
            M.policy.freeze_preference_learning()  # 禁长期偏好学习
    return k, lam_N, build_jneed(M)

## 3. 推导

**引理 33（say–do gap 的可辨识需要外生激励）** 设行为由 `f(n, z, h)` 生成，用户只在 `z` 上表达。若 `a_stated` 与 `a_revealed` 之间的差异同时可由 `n` 或 `h` 解释，则仅靠被动观察 `Δ_sd` 不可识别。**证明**：被动数据中 `n` 与 `h` 的联合分布未受控，存在不可观测混淆；只有当机器人施加能改变 `∂a/∂n` 而保持 `∂a/∂h` 不同的外生试探（probe），才使敏感度矩阵满秩（定义 373）。系：**「洞察需求」在原则上需要主动实验，不是被动拟合**；CN-VOI 的 probe 项不是可选项。

**引理 34（学习使证书过期：freshness 引理）** 若在模型版本 `v` 上 `Valid(J_EMB(v))`，且存在被提交的更新 `v→v′ (v′≠v)`，则 `J_EMB(v)` 不再蕴含 `v′` 的安全/计量性质；`J_NEED` 必将 `freshness_epoch` 推进并使旧证书失效。**证明**：J_EMB 的每个字段（RTA 证明、S2R 哈希、SEAL 通过位、λ_floor 覆盖）都是 `θ_v` 的函数；`θ` 改变即函数值改变，旧证明不适用于新参数。系：**任何「边学边用」的系统必须把证书重推导纳入学习预算，否则就是在用过期证明开车**。

**引理 35（提交门控 ⇒ 安全单调）** 在定义 371 五条件全满足时提交 `θ′`，则对任意影子/在线轨迹，`J_risk(θ′) ≤ J_risk(θ)+ε_reg` 且 λ_floor 覆盖不弱化。**证明**：条件 1 直接给出风险不增；条件 2–5 保证有效域、证书、预算、血缘，排除了「靠越出有效域获得表面低风险」的退化解。系：**在线学习可以在门控下做到「安全单调」，但代价是部分更新被拒绝（可塑性受限）**。

**引理 36（漂移分离的秩条件）** 若定义 373 的敏感度矩阵 `S` 在关心的 `(n,θ,h)` 子空间上满秩，则三类漂移可局部唯一归因（至一阶）；若 `rank_gap > 0`，则存在至少一个混淆方向，任何单一归因都有正的最坏情形误差。**证明**：一阶展开 `Δy = S·[Δn;Δθ;Δh]`，满秩时有唯一最小范数解；秩亏时解空间非平凡，混淆方向上的分量不可区分。系：**CIDS 的 `degrade_flag` 是硬约束，不是置信度装饰**。

**引理 37（SPB 下的有限学习与 Pareto 前沿）** 设每次提交的 `g_adapt` 非增、`c_forget` 有正下界，且 `Σ c_forget ≤ B_forget`，则在线学习至多提交有限次「净正收益」更新，且存在一个 Pareto 点使适应收益与遗忘代价不可同时改进。**证明**：`c_forget` 正下界 + 预算有限 ⇒ 提交次数有限；每次要求 `g_adapt−c_forget ≥ margin` ⇒ 净收益序列非增，终止于 Pareto 边界。系：**「无限自适应」不是优点，是预算失控**。

**引理 38（L4 使在线学习目标内生非平稳）** 若需求转移 `p(n'|n,a_robot,ψ)` 对 `a_robot` 敏感，且在线学习器用揭示行为估计 `n`，则学习目标的期望随策略变化：`E_{π}[n_revealed] = F(π)`。**证明**：揭示需求是策略 `π` 下行为分布的函数；策略又由学习到的 `n` 决定，构成 `π ↔ n_revealed` 的不动点系统，目标随迭代移动。系：**从揭示偏好里学需求是一个自指问题，必须用 A-GOODHART 把「服务」与「塑造」分开记账，否则会收敛到「用户依赖机器人」的局部最优**。

**引理 39（需求效度不可内部自证）** 不存在仅由系统内部可观测量 `(o, z, s, ψ, θ)` 构成的函数，能在所有环境上保证 `NV` 与真实 `U_n` 一致。**证明（反证/对角化）**：若存在，则构造一个环境使 `o` 与 `U_n` 解耦而内部统计量保持相同——内部量对 `U_n` 的映射不唯一；Goodhart 即此反例的具体化。系：**`NV` 必须带外部锚 `A_ext`，无锚 `NV := ⊥`（定义 385）；这是本框架的理论边界，不是实现缺陷。**

**引理 40（双闭环活性）** 学习环只写影子缓冲、需求环只写需求快照、控制域只读且带 `freshness_epoch` 校验；三者在 REG 中优先级与域隔离（定义 380）。则不存在循环等待与优先级反转；若证书重推导超时，退化路径保证控制域仍能取到上一个已验证版本，**系统不会因学习环阻塞而死锁**。**证明**：通信拓扑为单向（学习→影子→门控→快照；需求→快照→控制只读），回边都必须经过门控且非阻塞；超时走 `degrade_to_R72_or_R68`。系：**学习可以慢、可以失败，但控制不能停**。

**定理 27（严格包含与风险单调）** 在 A111–A116（需求可锚、门控有效、CIDS 可辨识或有降级、L4 Lipschitz、SPB 有限、外部锚独立）下：NEEDLE 在退化条件下逐指令等于 R72 / R71 / R68（定义 381）；且对任意有效执行，风险界 `≤` R72 的风险界。**安全单调不减，效率与个性化仅在「需求可锚、学习可门控、漂移可分离」时获益。**

**定理 28（需求有效 + 学习门控 ⇒ 错配风险有界且学习不降安全）** 若 `Valid(J_NEED)` 且每次提交过 CommitGate，则 (i) 物理执行风险 `≤ ε_emb`（承 R72 定理 24）；(ii) 需求错配遗憾 `Reg_n ≤ (1−NV)·Reg_max + u_anchor`；(iii) 在线学习不使既有安全界退化超过 `ε_reg`。**证明**：(i) 由 J_EMB 子证书；(ii) 由 NV 定义与锚不确定度直接放缩；(iii) 由引理 35。系：**「学得越多越不安全」不是必然，前提是门控与外部锚都在**。

**定理 29（学习血缘 ⇒ 可回滚安全）** 若 L-TCHAIN 完整且每个提交携带 `rollback_point`，则任意检测到的安全/效度回退都能在 `τ_rollback` 内回滚到某个 `J_NEED`-valid 版本，且回滚后控制域仍满足 λ_floor。**证明**：链式哈希保证事件顺序不可篡改；提交原子切换 + 版本号 + `freshness_epoch` 保证回滚是幂等的；RLM 只读校验保证回滚真实发生。系：**在线学习的第一公民不是「更新」，是「可回滚」**。

**定理 30（需求效度的外部锚必要性）** 在定义 385 下，`NV` 有效 ⇒ 存在独立外部锚 `A_ext` 且 `u_anchor < ∞`；任何无锚的 `NV` 不可用于 `J_NEED`。**证明**：由引理 39，内部量不能唯一决定 `U_n`；若允许无锚 `NV` 进入证书，则存在环境使系统「自信地服务错误需求」而所有内部指标通过——与定理 28(ii) 矛盾。系：**这是本轮最重要的负面结论：需求效度买不到「自证」，只能买「可审计的外部背书」**。

**定理 31（双闭环活性与安全退化）** 在 REG 隔离（定义 380）与引理 40 下，NEEDLE 不产生学习/需求环导致控制域死锁；任何一环失效都沿定义 381 逐指令退化，且退化路径保留 R68 硬安全包络。**证明**：活性由单向通信 + 超时退化给出；退化等价性由各层开关的逐指令语义与 R72 定理 23 组合得到。

## 6. 本轮最大风险

**一句话**：NEEDLE-GAUGE-RAS 把安全从「相信测量链在具身实时下成立」转移到「相信 **需求能被外部锚正确识别**、相信 **在线学习门控在长期非平稳下仍守约**、相信 **需求/模型/人三类漂移在高维真实数据上真的可分离**」——**如果外部锚本身有偏（审计集只覆盖了会说会做一致的人群），如果在线学习在长尾漂移下反复「拒绝—回滚」导致系统僵化而 RTA 的静态余量被影子回放悄悄吃光，如果 CIDS 在 rank 不足时被工程上「临时放宽」成置信度加权从而把传感器漂移学成用户偏好——系统会用一套「有外部背书、有门控证明、有回滚记录」的双闭环算法，长期地、稳定地、可复现地服务一个它自己塑造出来、且用户已经开始依赖的需求，事后审计发现「NV 当时在阈值上、L-TCHAIN 完整、每次提交都有门控证明、操纵指标都没超阈」，这就是**需求层面的「自信地服务错误的目标」——比测量错更隐蔽，因为你连「错了」都定义不了。***

次级风险与缓解：
1. **外部锚有偏/被污染** → **多锚交叉（密封审计集 × 人类福利面板 × 第三方复核 × 留存储队列）**，任一锚冲突即把 NV 降为 ⊥ 并退化；锚数据与在线数据物理隔离。
2. **门控拒绝—回滚振荡导致僵化** → **引入「延迟提交 + 双版本并行影子」**，把重推导与在线适应解耦；用 SPB 余额做节流，避免反复回滚吃光预算。
3. **CIDS 秩亏被工程放宽** → **把 `rank_gap` 设为硬 veto（定义 373/383）**，秩亏只能「降级/固定先验」，不允许「加权硬归因」；RLM 只读校验归因必须带秩证据。
4. **偏好回声室/操纵慢性化** → **A-GOODHART 长期纵向审计 + 依赖/去技能化阈值随使用时长收紧**；一旦触发，冻结长期偏好学习、保留短期技能学习，并引入「人类独立完成配额」。
5. **在线学习攻击（回放/投毒/影子污染）** → **L-TCHAIN 哈希链 + 数据血缘 + 回放检测（时间戳/分布指纹）+ 影子隔离**；任何断链即拒绝提交并回滚。
6. **证书重推导吃控制余量** → **控制域只读已验证快照，`freshness_epoch` 不匹配即用上一已验证版本**；重推导严格在计量域异步完成，超时走退化，绝不进控制环。
7. **需求空间复杂度爆炸** → **模块化上限**：`|𝒩|≤6`、每类需求一条外部锚证据、每个 veto 一条可复算证明；复杂度本身纳入 N-MIB。

# 第 73 轮产物 · 创新点清单 v4：NEEDLE-GAUGE-RAS（Need-insight, Epistemically-audited, Embodied, Dexterous, Lifelong-learning, Evolving GAUGE for RAS：需求洞察 × 在线学习 × 具身计量 × 双闭环审计；NIL×OLL×CIDS×CN-VOI×NREFLEX×NCERT×GAUGE-RAS†）

> 承接第 72 轮 IP-287~294（EMBODIED-GAUGE-RAS）。R72 完成了「具身层」的实时计量审计：REG 把调度契约变成定理，IRL 把意图 z 纳入联合后验，DMEM 把灵巧接触升级为带模式 c 的计量证据，EREFLEX/ERVOI 把情感/意图/接触三层反作用合算，S2R-UQ 把仿真实机不确定度吃进 WCET 与 λ_floor，J_EMB 给每次执行盖章。但 R72 仍有结构性盲区：
> - 缺 **需求洞察（NIL）**：R72 把用户**陈述的意图 z** 当优化目标，未区分**潜在需求 n**。z 是 n 的含噪代理，把 z 当 n 是「正确地解决错误的问题」（第三类错误）。需求只能从纠正/接管/重复请求/绕路/沉默/事后复用等行为证据反推，存在 say–do gap，且需要**目标层的构念效度（需求效度 NV）**。
> - 缺 **在线学习（OLL）**：R72 的模型部署即冻结，靠静态 RTA + SEAL + J_EMB 背书。真实部署非平稳（传感器漂移、磨损、人的适应、任务迁移）。必须在线学习，但**学习会改写被审计对象，使证书当场过期**——「学习即契约违约」。
> - 缺 **漂移分离（CIDS）**：需求漂移 n、模型漂移 θ、人状态漂移 h 共享同一条行为残差，天然混淆。不分离就会把传感器漂移学成用户偏好、或错过真实需求变化。
> - 缺 **L4 需求反作用（NREFLEX）**：机器人从揭示偏好里在线学习需求，而动作又在塑造偏好——**内生非平稳**，会把「自己造出来的需求」学成目标（依赖、过度信任、去技能化、偏好回声室）。
> - 缺 **外部锚（定义 385）**：需求效度**不可内部自证**（引理 39），必须由密封审计集/人类福利面板/第三方复核/留存队列背书，并显式传播锚不确定度 `u_anchor`。
>
> 本轮两位一体补齐：
> - **需求侧（NIL + NCAA 需求效度）**：`b_t(s,z,n)` 联合后验；陈述–揭示分解；行为优先的双通道需求证据；`NV` 进入风险分母。
> - **学习侧（OLL + CommitGate + SPB + L-TCHAIN）**：学习事件一等公民；未过门控只进影子；证书新鲜度 `freshness_epoch`；可回滚。
> - **耦合侧（CIDS + CN-VOI）**：敏感度矩阵的秩条件分离三类漂移；问/看/试/停进入同一 VoI 与四层预算。
> - **反作用侧（NREFLEX + A-GOODHART）**：L4 需求反作用；操纵增益/依赖/去技能化/回声四指标否决。
>
> 核心命题：**不再只问「我的测量链此刻可信吗」，而问「当测量链持续自我改写、用户真正的需求既没说清又会被我改变时，我是否仍在服务正确的需求？」** 理论姿态延续：**新层是旧层的严格泛化，安全侧只增不减，退化链逐指令等价，且诚实标注本框架买不到的东西（需求效度的内部自证）。**

## 2. 形式化定义（要点版）

**定义 366（总览与六不变式）** 需求效度优先且外部锚定；学习必须过 CommitGate；漂移必须 CIDS 分离或显式降级；四层反作用预算；证书新鲜度 `(v,N_D,D,freshness_epoch)`；严格逐指令退化。

**定义 367（需求隐变量与陈述–揭示分解）** `n` 不可直接观测，只能由 `(o,z,ψ,s)` 反推；`Δ_sd=1−P(a_stated=a_revealed|z,n)`；`dir_sd` 标记缺口方向。**需求与陈述不是同一变量。**

**定义 368（需求证据模型）** 言语与行为两族证据分开校准；冲突时**行为优先但不得单独定案**；输出 `(b_t(n),Δ_sd,ECE_need,ι_need)`。

**定义 369（需求后验与需求效度）** `b_t(s,z,n)`；`Reg_n`；`NV` 在 `D_need` 上、以 `A_ext` 估计，携带 `(D_need,A_ext,u_anchor,τ_anchor)`。**NV 是目标层构念效度，不是状态层精度。**

**定义 370（在线学习算子与学习事件）** `e_t` 含目标参数、数据血缘、Δθ、前/后指标、门控决定、回滚点、时间戳；全部写入 L-TCHAIN。**学习事件是一等公民。**

**定义 371（CommitGate）** 五条件全过才提交；否则影子缓冲/回滚；**控制域永不见未过门控参数**。证书不可及时重建 ⇒ 延迟提交。

**定义 372（SPB 稳定性–可塑性预算）** `g_adapt−c_forget≥margin`，`Σc_forget≤B_forget`，`Σg_adapt≤B_adapt`。**防止用长期遗忘换短期拟合。**

**定义 373（CIDS 漂移分解）** `y=f(n,θ,h)+ε`；`S=[∂y/∂n,∂y/∂θ,∂y/∂h]`；`rank(S)` 满则局部唯一归因；秩亏则 `unidentifiable` 并硬降级。**禁止把混合残差直接喂给任一学习器。**

**定义 374（NREFLEX L4）** `n_{t+1}~p(n'|n,a_robot,ψ,z)`；成本 = KL + 稳态指示 + `λ_dep·Dep + λ_dsk·DSK`；四层合算。

**定义 375（A-GOODHART）** `MG=ΔJ_robot−ΔW_human`；`Dep`、`DSK`、`ECHO`；任一超阈 ⇒ 需求操纵否决，禁止以学习偏好为唯一依据。

**定义 376（CN-VOI）** 五动作 + 需求信息增益 + 可辨识性增益 + 探查/锚成本 + 四层反作用成本；`max VoI^N≤0 ⇒ 停止回退`。

**定义 377（N-RISK）** `H_n` 与 `(1−NV)` 同权进入 λ 分母；需求越模糊/越可能错配，动作越保守，禁止不可逆高影响动作。

**定义 378（J_NEED 与 L-TCHAIN）** `Valid ⇔ J_EMB(v) ∧ NV≥τ ∧ 链完整 ∧ 门控证明齐 ∧ 需求区域一致 ∧ freshness 未过期 ∧ 无未处理操纵否决`；哈希链支持回滚。

**定义 379（威胁模型 ℰ_NEED）** 需求伪造/投毒/跨文化歧义/回声室/依赖诱导；学习数据投毒/回放/供应链/门控绕过/断链/影子污染。

**定义 380（双闭环三域）** 学习快环（感知+计量，写影子）；需求慢环（计量+外部锚，写需求快照）；控制域只读已验证且证书新鲜的 `(θ,b_t(n),NV)`；不等待、不回写。

**定义 381（严格退化链）** 门控失效→冻结+R72；NV 失效→z+R72；CIDS 秩亏→固定先验+冻结需求模型；操纵否决→禁长期偏好学习；全失效→R68。

**定义 382（N-MIB）** 需求族（NV,Δ_sd,H_n,ECE_need,ι_need,漂移率,MG,Dep,DSK,ECHO,留存）与学习族（适应/遗忘/更新频率/门控拒绝率/证书新鲜度延迟/L-TCHAIN 覆盖/回滚率/SPB 余额/影子–在线分歧）。

**定义 383（N-IVG）** 需求/学习/漂移/操纵四类失效条件；任一成立即降级（需求→z+R72；学习→冻结；漂移→固定先验；操纵→禁长期偏好学习）。

**定义 384（RLM 运行时学习监控）** 最高优先级旁路、静态内存、零分配、只读影子；校验门控真实执行、链连续、`freshness_epoch` 与模型版本一致、SPB 非负；自身不被在线学习，代码 <800 行，形式化验证。

**定义 385（外部锚协议）** `A_ext=(密封需求审计集, 人类福利面板, 第三方目标复核, 留存储队列)`；锚数据与在线学习数据物理/流程隔离；`u_anchor` 必须传播进 NV 与 J_NEED；**无锚 NV:=⊥**。

**定义 386（需求条件效用与福利代理）** 区分 `U_n`（不可观测真实福利）与 `Ŵ_human`（可 Goodhart 的代理）；`NV` 与 `MG` 依赖代理，代理本身需被外部锚周期校准。**这是本框架的诚实边界。**

# IP-295/296 NIL：需求后验 + 需求效度（计量域，慢环 1–5Hz）
class NeedInsightLayer:
    def __init__(self, need_net, calib_behavior, calib_speech, anchor_registry):
        self.net = need_net
        self.cal_b, self.cal_s = calib_behavior, calib_speech
        self.anchor = anchor_registry            # 在线学习不可访问其标签
    def update(self, y_need, z_dist, psi, s_post):
        lb = self.net.behavior(y_need.behavior, s_post, psi)
        ls = self.net.speech(y_need.speech, z_dist, psi)
        b_b = self.cal_b.predict(lb)             # 行为证据：ECE_need, iota_need
        b_s = self.cal_s.predict(ls)             # 言语证据：独立校准
        b_n = fuse_behavior_first(b_b, b_s)      # 行为优先，冲突不单独定案
        delta_sd = say_do_gap(b_n, z_dist, y_need)
        nv = self._need_validity(b_n)            # 无 A_ext → NV := None
        return NeedPosterior(b_n, delta_sd, nv, b_b.ece, b_b.iota,
                             anchor=self.anchor.ref)

# IP-297/298 OLL：学习算子 + 提交门控 + SPB + L-TCHAIN（快环）
class OnlineLearningLayer:
    def __init__(self, learners, shadow, gate, spb, lchain):
        self.learners, self.shadow, self.gate = learners, shadow, gate
        self.spb, self.lchain = spb, lchain
    def propose(self, data, mask):
        theta_p = {k: l.step(self.shadow.theta[k], data, mask[k])
                   for k, l in self.learners.items()}
        self.shadow.write(theta_p)               # 只进影子
        return theta_p
    def try_commit(self, theta_p, ctx):
        ev = self.gate.evaluate(self.shadow.theta, theta_p, ctx)
        # safety_monotone / metrology_valid / cert_rebuildable / spb_ok / provenance_ok
        if not ev.all_ok:
            self.lchain.record(ev, 'reject_or_buffer')
            return False, ev
        self.spb.charge(ev.g_adapt, ev.c_forget)
        self.lchain.record(ev, 'commit')
        self.shadow.commit(theta_p)              # 原子切换 + version++ + freshness++
        return True, ev

# IP-299 CIDS：漂移分解（计量域）
def decompose_drift(y_hist, n_post, theta, h_post):
    S = sensitivity_matrix(y_hist, n_post, theta, h_post)   # ∂y/∂[n,θ,h]
    gap = S.cols - matrix_rank(S)
    if gap > 0:
        return DriftReport(S, gap, attribution='UNIDENTIFIABLE', degrade=True)
    return DriftReport(S, 0, attribution=ridge_attribution(S, y_hist), degrade=False)

# IP-300 CN-VOI：问/看/试/停（慢/快交界）
def coupled_need_voi(b_t, z_dist, n_dist, c_dist, psi, budget, spb):
    best = None
    for g in ('ask', 'observe', 'probe', 'act', 'stop'):
        if not budget.allow(g) or not spb.allow(g):
            continue
        cost = reflex_cost_4layer(psi, z_dist, c_dist, n_dist, g)
        if cost is None:                         # 任一层稳态越界
            continue
        score = (credibility(psi) * expected_ig_s(b_t, g)
                 + ETA_Z * expected_ig_z(z_dist, g)
                 + ETA_N * expected_ig_n(n_dist, g)
                 + LAM_ID * expected_rank_gain(b_t, n_dist, g)
                 - GAMMA * expected_future_loss(psi, z_dist, c_dist, n_dist, g)
                 - cost - probe_cost(g) - anchor_cost(g))
        if best is None or score > best[1]:
            best = (g, score)
    return best[0] if best and best[1] > 0 else 'stop'

# IP-301 NREFLEX：L4 需求反作用 + 四层预算
def nreflex_step(psi, z_dist, c_dist, n_dist, g, budget):
    psi2, cz, ok1 = reflex_step_L1(psi, g, budget)
    z2,  cz2, ok2 = reflex_step_L2(z_dist, g, psi, budget)
    c2,  cc,  ok3 = reflex_step_L3(c_dist, g, budget)
    n2 = need_transition(n_dist, g, psi, z_dist)        # p(n'|n,a,ψ,z)
    dep, dsk, echo = dependency_indices(n_dist, n2, g)
    cn = (kl_div(n_dist, n2) + LAM_N * (n2.entropy() > TAU_HN)
          + LAM_DEP * dep + LAM_DSK * dsk)
    mg = manipulation_gain(g, budget.robot_obj, budget.human_welfare)
    if not (ok1 and ok2 and ok3) or mg > TAU_MG or echo > TAU_ECHO:
        return None, {'reject': 'L4_or_manipulation'}
    if budget.spent + cz + cz2 + cc + cn > budget.B:
        return None, {'reject': 'budget'}
    return (psi2, z2, c2, n2), {'cost': cz + cz2 + cc + cn, 'mg': mg,
                                'dep': dep, 'dsk': dsk}

# IP-302 A-GOODHART：需求操纵审计（慢环 / 外部锚）
def anti_goodhart_audit(n_hist, a_hist, welfare_hist, skill_hist):
    mg   = delta_robot_obj(a_hist) - delta_human_welfare(welfare_hist)
    dep  = dependence_index(n_hist, a_hist)
    dsk  = -delta_human_independent_rate(skill_hist) / (delta_robot_participation(a_hist) + EPS)
    echo = partial_corr(a_hist, n_hist.revealed, n_hist.true_proxy)
    flags = {'MG': mg > TAU_MG, 'Dep': dep > TAU_DEP,
             'DSK': dsk > TAU_DSK, 'ECHO': echo > TAU_ECHO}
    return AuditResult(flags=flags, veto=any(flags.values()))

# IP-303 NCERT：J_NEED 证书 + 学习追溯链
def build_jneed(M):
    assert M.lchain.verify_chain()
    assert all(e.gate_proof for e in M.lchain.events)
    assert M.nv.anchor is not None and M.nv.anchor.sealed   # 定义 385
    return J_NEED(
        j_emb=M.j_emb, version=M.model.version, need_region=M.nv.D_need,
        nv=M.nv.value, anchor=M.nv.anchor.hash, u_anchor=M.nv.u_anchor,
        lchain_root=M.lchain.root, gate_proofs=M.lchain.gate_proofs,
        spb_state=M.spb.snapshot(), cids_gap=M.cids.rank_gap,
        manip_flags=M.goodhart.flags, freshness=M.model.freshness_epoch)

# IP-304 NEEDLE 主闭环（双闭环映射到 R72 三域）
def NEEDLE_GAUGE_RAS_round(M, obs, audio, tac_frame, human_behavior):
    # ===== 控制域（硬实时，只读“已门控 + 证书新鲜”的快照）=====
    snap = M.snapshot.read_latest()
    if not snap.fresh(M.model.version) or snap.nv is None:
        return M.degrade_to_R72_or_R68()          # 证书过期 / 需求无效锚
    lam_N = n_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                         snap.u_tac, snap.H_n, snap.nv)   # 定义 377
    k = M.ach.certified_prefix(M.ach.propose_ctrl(...), lam_N)
    M.ctrl_out.publish(k, lam_N)

    # ===== 计量域（软实时，慢环：需求 + 漂移）=====
    if M.clock.due_need():
        n_post = M.nil.update(extract_need_evidence(human_behavior, obs, audio),
                              snap.z_dist, snap.psi, snap.s)
        drift = decompose_drift(human_behavior.residual, n_post,
                                M.model.theta, snap.h)
        if drift.degrade:                         # rank 不足 → 固定先验 + 禁需求学习
            n_post = freeze_need_prior(n_post)
        M.snapshot.write_need(n_post, drift)

    # ===== 感知域（异步，快环：学习）=====
    theta_p = M.oll.propose(pack_stream(obs, audio, tac_frame), M.update_mask)
    ok, ev = M.oll.try_commit(theta_p, ctx=M.cert_ctx)
    if not ok:

    if M.clock.due_audit():
        audit = anti_goodhart_audit(M.n_trace, M.a_trace,
                                    M.welfare_trace, M.skill_trace)
        if audit.veto:
            M.policy.freeze_preference_learning() # 禁长期偏好学习
    return k, lam_N, build_jneed(M)

## 4. 推导

**引理 33（say–do gap 的可辨识需要外生激励）** 被动观察下 `n` 与 `h` 混淆，`Δ_sd` 不可唯一归因；需 probe 使 `S` 对 `(n,h)` 满秩。系：**需求洞察原则上需要主动实验。**

**引理 34（学习使证书过期）** 提交 `v→v′` 后 `J_EMB(v)` 不再蕴含 `v′` 的安全/计量性质；`freshness_epoch` 必须推进，旧证书失效。系：**边学边用必须以证书重推导为预算项。**

**引理 35（CommitGate ⇒ 安全单调）** 五条件全过提交 ⇒ `J_risk(θ′)≤J_risk(θ)+ε_reg` 且 λ_floor 不弱化；代价是部分更新被拒（可塑性受限）。

**引理 36（漂移分离的秩条件）** `S` 在 `(n,θ,h)` 上满秩 ⇒ 一阶唯一归因；`rank_gap>0` ⇒ 至少一个混淆方向，任何单一归因最坏误差为正。系：**`degrade_flag` 是硬约束。**

**引理 37（SPB 下有限学习与 Pareto 前沿）** `c_forget` 正下界 + 预算有限 ⇒ 净正收益提交有限次，终止于 Pareto 边界。系：**无限自适应是预算失控，不是优点。**

**引理 38（L4 使学习目标内生非平稳）** 揭示需求是策略的函数，策略又由学到的需求决定 ⇒ `π↔n_revealed` 自指，目标随迭代移动。系：**必须把「服务」与「塑造」分开记账。**

**引理 39（需求效度不可内部自证）** 不存在仅由内部量 `(o,z,s,ψ,θ)` 构成的函数能在所有环境保证 NV 与真实 `U_n` 一致（构造解耦环境即可反证）。系：**无外部锚则 NV:=⊥。**

**引理 40（双闭环活性）** 学习环只写影子、需求环只写需求快照、控制域只读并校验 `freshness_epoch`；单向通信 + 超时退化 ⇒ 无死锁、无优先级反转。系：**学习可以慢、可以失败，控制不能停。**

**定理 27（严格包含与风险单调）** 在 A111–A116 下：NEEDLE 退化时逐指令等于 R72/R71/R68；有效执行风险界 ≤ R72。**安全单调不减，个性化仅在需求可锚、学习可门控、漂移可分离时获益。**

**定理 28（需求有效 + 门控 ⇒ 错配风险有界且学习不降安全）** `Valid(J_NEED)` 且每次过门控 ⇒ (i) 物理风险 ≤ ε_emb；(ii) `Reg_n ≤ (1−NV)·Reg_max + u_anchor`；(iii) 学习不使既有安全界退化超过 `ε_reg`。

**定理 29（学习血缘 ⇒ 可回滚安全）** L-TCHAIN 完整 + 每提交带 `rollback_point` ⇒ 任意回退可在 `τ_rollback` 内回到某个 `J_NEED`-valid 版本，且回滚后仍满足 λ_floor。系：**在线学习第一公民是「可回滚」，不是「更新」。**

**定理 30（需求效度的外部锚必要性）** `NV` 有效 ⇒ 存在独立 `A_ext` 且 `u_anchor<∞`；无锚 NV 不得进入 J_NEED。**这是本轮最重要的负面结论：需求效度买不到自证，只能买可审计的外部背书。**

**定理 31（双闭环活性与安全退化）** REG 隔离 + 引理 40 ⇒ 学习/需求环不致控制域死锁；任一环失效沿定义 381 逐指令退化，且保留 R68 硬安全包络。

## 7. 本轮最大风险

**一句话**：NEEDLE-GAUGE-RAS 把安全从「相信测量链在具身实时下成立」转移到「相信 **需求能被外部锚正确识别**、相信 **在线学习门控在长期非平稳下仍守约**、相信 **需求/模型/人三类漂移在真实高维数据上真的可分离**」——**如果外部锚本身有偏（只覆盖了会说会做一致的人群），如果门控在长尾漂移下反复「拒绝—回滚」导致系统僵化而静态 RTA 余量被影子回放悄悄吃光，如果 CIDS 在秩亏时被工程上「临时放宽」成置信度加权从而把传感器漂移学成用户偏好——系统会用一套「有外部背书、有门控证明、有回滚记录」的双闭环算法，长期地、稳定地、可复现地服务一个它自己塑造出来、且用户已经开始依赖的需求，事后审计发现「NV 当时在阈值上、L-TCHAIN 完整、每次提交都有门控证明、操纵指标都没超阈」，这就是**需求层面的「自信地服务错误的目标」——比测量错更隐蔽，因为你连「错了」都定义不了。**

次级风险与缓解：
1. **外部锚有偏/被污染** → 多锚交叉（密封审计集 × 福利面板 × 第三方复核 × 留存队列），冲突即 NV:=⊥ 并退化；锚数据与在线数据物理隔离。
2. **门控拒绝—回滚振荡** → 延迟提交 + 双版本并行影子 + SPB 节流，解耦重推导与在线适应。
3. **CIDS 秩亏被放宽** → `rank_gap` 为硬 veto；秩亏只能降级/固定先验，禁止「加权硬归因」；RLM 只读校验归因必须带秩证据。
4. **偏好回声室/操纵慢性化** → A-GOODHART 纵向审计 + 依赖/去技能化阈值随使用时长收紧；触发即冻结长期偏好学习并设「人类独立完成配额」。
5. **学习攻击（回放/投毒/影子污染）** → L-TCHAIN 哈希链 + 数据血缘 + 回放检测（时间戳/分布指纹）+ 影子隔离；断链即拒绝并回滚。
6. **证书重推导吃控制余量** → 控制域只读已验证快照；`freshness_epoch` 不匹配即用上一已验证版本；重推导严格在计量域异步，超时退化，绝不进控制环。
7. **需求空间复杂度爆炸** → `|𝒩|≤6`、每类需求一条外部锚证据、每个 veto 一条可复算证明；复杂度纳入 N-MIB。
