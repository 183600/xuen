# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「三维感知」×「多端口部署」）

> 第 54 轮建立了动作剖面 `α_S`、组合图 `G_S`、云边映射 `γ_ce` 与联合证书 `J`。但 `J` 有两个未言明的前提：**(i) 场景/感知被视为干净的 2.5D**，没有把三维几何（遮挡、透明、反射、稀疏深度、标定漂移）当成证书的一等输入；**(ii) 部署端口是唯一的**，仿佛技能只在一种「本体 × 传感器 × 算力」组合上生效。本轮把「三维感知」与「多端口部署」合并为 **几何-动作-端口（GAP）三重证书**。核心矛盾：**H22**：行为距离很小的两个场景，可能在三维几何上差异巨大（玻璃/镜面/遮挡），导致 `ρ` 在真实感知下静默失效；**H23**：多端口部署不是复制证书，而是「证书族交集」与「可靠性并集界」的博弈——核心动作集取交集会过度保守甚至为空，而整体可靠性随端口数按并集界单调衰减。

## 0. 直觉与动机

**灵感 1（三维感知 = 证书的几何锚）**
直觉：第 54 轮的 `ρ`、`α_S`、场景距离都停在「行为/参数」层面，缺一个可度量、可对齐的**几何锚**。把场景实例化为**度量-语义三维地图** `M=(O,Σ,L)`：占据 `O`、占据不确定性 `Σ`（米）、语义 `L`。技能剖面升级为**几何条件化剖面** `α_S(a|M)`。证书不再说「在所有场景成立」，而说「在三维几何管 `B_3D(M,ε_g)` 内成立」。这把「感知到了什么」从输入噪声提升为证书的作用域变量——三维感知不是多加一路输入，而是定义证书边界的坐标系。

**灵感 2（遮挡/透明/反光 → 感知不确定性对动作集的腐蚀）**
直觉：三维感知最危险的不是「完全看不见」，而是「看起来看得见但几何是错的」：玻璃、镜面、黑色吸光物导致深度缺失或反射伪面；稀疏 LiDAR 在远处形成空洞。若深度/占据误差的度量上界为 `ε_g`，则安全动作不能贴着几何边界走，必须向内收缩 `ε_g`。形式化上这就是**动作核心集的形态学腐蚀**：`A_core(ε_g) = A_core ⊖ B_m(ε_g)`。感知越糊，可认证动作越窄——这比「调低置信阈值」更几何、更可解释，也更容易在多端口间比较。

**灵感 3（多端口 = 同一核心、不同外壳）**
直觉：一个技能要部署到多端口 `p=1..n`（不同本体 DOF/限位/控制率、不同三维传感器 FOV/分辨率/模态、不同边端算力与通信）。正确姿势不是「每个端口各自认证一遍再对信心取平均」，而是 **one core, many shells**：认证一个跨端口共享的核心 `A_core^Π = ⋂_p A_core^{(p)}(ε_g^{(p)})`，每个端口只保留自己的外壳 `A_shell^p`。跨端口一致的行为得到统一保证，端口特有行为单独标注、单独负责。

**灵感 4（多端口可靠性是并集界，不是平均）**
直觉：若端口 `p` 的部署失败概率上界为 `β_p`，则 n 个端口**全部**成功的概率下界是 `1-Σ_p β_p`——端口越多，整体可用性单调下降。这反直觉但严格：多端口放大的是「至少一个端口掉链子」的机会。于是端口集合选择变成带失败预算的组合优化：新增端口带来的任务价值必须超过它贡献的失败预算。它直接推翻「多端口 = 更稳」的朴素直觉。

**灵感 5（端口漂移 = 动作漂移 × 感知漂移，且感知漂移二次放大）**
直觉：从端口 `p` 迁到 `q`，有两类漂移：动作漂移 `δ_a^{p→q}`（DOF/限位/控制率差异）与三维感知漂移 `δ_o^{p→q}`（模态/分辨率/FOV/标定差异）。二者不可简单相加：感知漂移会经几何腐蚀**二次压缩**动作核心。故真正可传递的是复合漂移 `Λ(p→q)=L_a δ_a + L_o δ_o`；超过预算 `Δ_Π` 时，`q` 只能作为候选，不能继承 `p` 的证书。

**灵感 6（端口一致性必须可观测：共享三维探针场景）**
直觉：比较两个端口的感知，不能只比规格表，必须在**共享三维探针场景**上跑同一几何查询（同一视角、同一物体位姿、同一遮挡配置、同一材质），比较占据与语义输出，得到可测量的 `d_3D(p,q)`。没有共享探针，「多端口一致性」只是营销话术。

**灵感 7（从双证书到三重金字塔）**
直觉：在第 54 轮「动作-鲁棒性双证书」上再叠一层**几何层 `𝔾`**：`𝔾_0` 物理三维结构，`𝔾_1` 端口感知地图，`𝔾_2` 几何管与腐蚀核，`𝔾_3` 跨端口几何共识。形成 **几何-动作-端口（GAP）三重证书**，跨层传递必须同时携带 `(ρ, A_cert, M, ε_g, Λ, n)`。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（度量-语义三维地图与几何管）**
三维地图 `M = (O, Σ, L)`，其中 `O: ℝ³→[0,1]` 为占据度，`Σ: ℝ³→ℝ_{≥0}` 为占据不确定性（米），`L: ℝ³→2^𝒞` 为语义标签。端口 `p` 的感知算子 `π_p: Ω_p → M_p`。两地图在同一对齐坐标系（由共享探针标定）下的几何距离
```
d_3D(M,M') = ∫_{ℝ³} |O(x)-O'(x)| dx + λ_L · μ({x : L(x) ≠ L'(x)})
```
**几何管** `B_3D(M, ε_g) = { M' : d_3D(M, M') ≤ ε_g }`。注意 `ε_g` 以米为单位，可直接与动作空间的位移量纲对齐。

**定义 122（几何条件化剖面与鲁棒性）**
技能 `S` 的几何条件化动作剖面 `α_S(a|M): A×𝔐→[0,1]`，几何条件化鲁棒性谱 `ρ_d(M)`。几何条件化证书在 `B_3D(M,ε_g)` 内成立，当且仅当
```
∀ M' ∈ B_3D(M,ε_g):  cover(S, A_T | M')  ∧  ρ_d(M') ≥ ρ_min(d), ∀ d∈𝔇_ρ
```

**定义 123（感知腐蚀动作核心）**
设第 54 轮联合证书的核心动作集为 `A_core`。给定感知几何不确定性半径 `ε_g`，定义**形态学腐蚀**
```
A_core(ε_g) = A_core ⊖ B_m(ε_g) = { a ∈ A_core : dist_w(a, ∂A_core) > ε_g }
```
其中 `B_m(ε_g)` 是动作空间中以加权度量 `dist_w`（各关节按量程归一化后加权）定义的 `ε_g` 球。**腐蚀律（非正式）**：若真实地图满足 `d_3D(M,M_actual) ≤ ε_g`，则任意 `a ∈ A_core(ε_g)` 在 `M_actual` 上的可达/碰撞判定与在 `M` 上一致（严格性依赖假设 A29）。

**定义 124（端口剖面与端口算子）**
端口 `p = (κ_p, ω_p, c_p, τ_p)`：
- `κ_p` 动作端口：DOF、限位、控制率；
- `ω_p` 感知端口：三维模态（RGB-D / 双目 / LiDAR / 事件）、FOV、分辨率、深度误差模型；
- `c_p` 边端算力（TOPS/内存）；
- `τ_p` 通信延迟与带宽。

端口算子 `D_p : (S, J) → (S^{(p)}, J^{(p)})`，
```
J^{(p)} = (ρ^{(p)}, α^{(p)}, A_core^{(p)}, γ^{(p)}, M^{(p)}, ε_g^{(p)}, evidence^{(p)})
```

**定义 125（端口漂移与端口兼容）**
- 动作漂移：`δ_a(p,q) = sup_{a∈A_core^Π} dist_{κ_q}( γ_{p→q}(a), a )`
- 感知漂移：`δ_o(p,q) = sup_{M∈𝔐_probe} d_3D( π_p(M), π_q(M) )`
- 复合漂移：`Λ(p→q) = L_a·δ_a(p,q) + L_o·δ_o(p,q)`
- 端口兼容：
```
compat_Π(p,q) = 1[δ_a ≤ τ_a^0] · 1[δ_o ≤ τ_o^0] · exp( -(δ_a/τ_a^0 + L_oδ_o/τ_o^0) )
```
仅当 `Λ(p→q) ≤ Δ_Π` 时，`q` 可继承 `p` 的证书。

**定义 126（多端口证书族与端口共识）**
部署端口集 `Π = {p_1,...,p_n}`。**先腐蚀、后交集**的共享核心
```
A_core^Π = ⋂_{p∈Π} A_core^{(p)}( ε_g^{(p)} )
```
端口共识证书
```
J^Π = ( A_core^Π, {ρ^{(p)}}_{p∈Π}, {δ_a,δ_o,Λ}, ε_g^Π = max_p ε_g^{(p)}, n, evidence )
```
多端口可部署条件（四条缺一不可）：
```
1) μ(A_core^Π) ≥ θ_core · min_p μ(A_core^{(p)})      # 共识核非空且不过度腐蚀
2) ∀p∈Π, ∀d: ρ^{(p)}_d ≥ ρ_min(d)                   # 每端口鲁棒性
3) ∀p,q∈Π: Λ(p→q) ≤ Δ_Π                              # 跨端口漂移预算
4) n ≤ n_max(β_budget)                               # 可靠性并集界预算
```

**定义 127（GAP 联合证书与多端口可靠性界）**
```
J_GAP = ( M, ε_g, A_core^Π, ρ^{(Π)}, γ^{(Π)}, δ_a, δ_o, Λ, n, evidence )
```
**定理（Geo-Action-Port Soundness，端口并集界）**
假设承接第 54 轮 (A26)–(A28)，并新增 **(A29)** 几何-动作 Lipschitz：`d_A(γ_{p→q}(a), a) ≤ L_a d_3D(M,M') + L_o ε_g`；**(A30)** 端口证据满足 `Λ(p→q) ≤ Δ_Π`；**(A31)** 各端口失败事件在给定共享核下近似独立。则
```
P( ⋂_{p∈Π} success_p ) ≥ 1 - Σ_{p∈Π} [ Σ_d (1-ρ_min^{(p)}(d)) + β_E^{(p)} + P(δ_a^{(p)}>Θ_a) ] - P(μ(A_core^Π)=0)
```
**推论（端口数悖论）**：右侧下界随 `n` 单调不增，故存在最优端口数 `n*`；「多端口更稳」只在共享失败模式强相关（独立性假设失效）时才可能成立，而那时并集界本身已不可信。

## 2. 关键算法 伪代码

### IP-121 GAC（Geo-Anchored Certificate）

```python
def geo_anchor(scene, pi_p, quantile=0.95):
    M = pi_p(scene)                        # (O, Sigma, L)
    eps_g = quantile_value(M.Sigma, quantile)   # 米
    rho = geometry_conditioned_robustness(M)
    return M, eps_g, rho

def geo_certify(M, eps_g, rho, rho_min):
    margin = min(rho[d] - rho_min[d] for d in rho)
    if margin <= 0:
        return ('reject', 'geo_robustness_margin', rho)
    return ('ok', GeoCert(M, eps_g, rho, margin))
```

### IP-122 PEC（Perception-Erosion Certificate）

```python
def erode_action_core(A_core, eps_g, dist_w):
    return {a for a in A_core if distance_to_boundary(a, A_core, dist_w) > eps_g}

def perception_erosion_certify(J54, M, eps_g, theta_core, dist_w):
    A_er = erode_action_core(J54.A_core, eps_g, dist_w)
    if measure(A_er) < theta_core * measure(J54.A_core):
        return ('reject', 'over_erosion', measure(A_er), eps_g)
    return ('ok', A_er, eps_g)
```

### IP-123 PPS（Port Profile & Drift）

```python
def probe_maps(port, probes):
    return [port.pi(M) for M in probes]     # 同一探针、同一对齐

def port_drift(p, q, probes, gamma_pq, L_a, L_o):
    d_a = max(dist_action(gamma_pq(a), a) for a in shared_core(p, q))
    d_o = max(geo_distance(mp, mq) for mp, mq in zip(probe_maps(p, probes),
                                                    probe_maps(q, probes)))
    Lam = L_a * d_a + L_o * d_o
    return d_a, d_o, Lam
```

### IP-124 PCG（Port Consensus Certificate）

```python
def port_consensus(certs, theta_core, delta_pi, L_a, L_o):
    cores = [erode_action_core(c.A_core, c.eps_g, dist_w) for c in certs]
    Acore = intersect_all(cores)
    if measure(Acore) < theta_core * min(measure(c) for c in cores):
        return ('reject', 'empty_or_over_eroded_consensus', measure(Acore))
    for p in certs:
        for q in certs:
            if p is q: continue
            _, _, Lam = port_drift(p, q, PROBES, gamma_pq, L_a, L_o)
            if Lam > delta_pi:
                return ('reject', 'port_drift', p.id, q.id, Lam)
    if not all(min(c.rho.values()) >= rho_min for c in certs):
        return ('reject', 'port_robustness')
    return ('ok', ConsensusCert(Acore, certs))
```

### IP-125 MPS（Multi-Port Set Selection，带并集界预算）

```python
def select_ports(ports, value, beta_bound, beta_budget, cost, lam):
    # 0/1 背包：max  Σ value_p - lam*Σ cost_p
    #             s.t. Σ_p beta_bound[p] <= beta_budget
    # 每个候选端口先过 port_consensus，失败者 beta=1 直接淘汰
    feasible = [p for p in ports if port_consensus(p.certs, ...)[0] == 'ok']
    return knapsack(feasible, weight=beta_bound, budget=beta_budget, profit=value)
```

### IP-126 GAP-JC（Geo-Action-Port Joint Certificate）

```python
def gap_joint_certificate(ports, J54, probes, budgets):
    anchors = [geo_anchor(p.scene, p.pi) for p in ports]
    for (M, eps, rho), p in zip(anchors, ports):
        if geo_certify(M, eps, rho, rho_min)[0] != 'ok':
            return ('reject', 'geo', p.id)
    consensus = port_consensus([p.cert for p in ports], theta_core, delta_pi, L_a, L_o)
    if consensus[0] != 'ok':
        return consensus
    if len(ports) > budgets.n_max:
        return ('reject', 'port_budget', len(ports), budgets.n_max)
    return ('ok', GapCert(anchors, consensus.core, ports, budgets))
```

### IP-127 PDM（Port Divergence Monitor，在线）

```python
def port_divergence_monitor(streams, delta_pi, window=50):
    for p, q in pairs(streams):
        h_p = geometric_hash(streams[p].recent(window))   # O/L/alpha 的哈希/草图
        h_q = geometric_hash(streams[q].recent(window))
        if drift(h_p, h_q) > delta_pi:
            degrade_certificate(p); degrade_certificate(q)
            raise PortDivergence(p, q)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GAC | O(\|V_3D\| + \|A\|) | O(\|V_3D\|) | 几何管覆盖、Σ 校准 |
| PEC | O(\|A_core\|·\|∂A_core\|) | O(\|A_core\|) | 腐蚀度量一致、ε_g 上界 |
| PPS | O(n²·(\|A_core\|+\|𝔐_probe\|·\|V_3D\|)) | O(n²) | 共享探针、γ 可逆 |
| PCG | O(n·\|A_core\| + n²·\|𝔐_probe\|) | O(n·\|A_core\|) | 先腐蚀后交集、非空 |
| MPS | O(\|Π\|·β_budget) | O(β_budget) | 并集界 sound、β 独立 |
| GAP-JC | O(n·(\|V_3D\|+\|A\|) + n²·\|𝔐_probe\|) | O(n·\|V_3D\|) | 四条件联合 sound |
| PDM | O(n²·window) | O(n·window) | 哈希碰撞概率、漂移阈值 |

**正确性定理（Geo-Action-Port Soundness）**：在 (A26)–(A31) 下，若 `J_GAP` 的四条部署条件均成立，则多端口联合成功概率满足定义 127 的并集界。证明要点：几何管保证每端口动作判定一致 → 腐蚀保证边界安全 → 端口漂移预算保证继承有效 → 并集界保证整体可靠性；四步串接。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 三维标定漂移使几何管整体偏移 | 高 | 在线标定 + 几何哈希监控 + 标定证书过期机制 |
| 透明/反光/吸光材质不被 Σ 表达 | 高 | 材质感知深度不确定性 + 主动多视角探测 |

| 端口间共享感知失效 → 独立性假设失效 | 高 | 显式相关性监测 + 相关性高时退回保守单端口证书 |

## 6. 本轮最大风险

**一句话**：三维几何锚与多端口共识证书的 soundness **同时依赖「深度/占据不确定性被真实上界住」与「各端口失败近似独立」**；一旦透明/反光场景让 `ε_g` 被低估，或各端口共享同一感知失效模式，并集界会系统性乐观，多端口部署反而制造「鲁棒性假象」——故必须以 **材质感知的不确定性膨胀 + 共享失败模式相关性监测 + 保守端口数上限** 三重护栏，宁可少端口、窄核心，也绝不把「多端一致」当作可靠性证明。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GeoPort（GAC×PEC×PPS×PCG×MPS×PDM）

> 承接第 54 轮产物 v31。本轮在「动作剖面 + 组合图 + 云边映射 + 联合证书」之上，增加 **三维几何锚、感知腐蚀、端口剖面、端口共识、端口集合优化、在线端口 divergence 监控** 六个算子：
> - **GAC（Geo-Anchored Certificate）**：以度量-语义三维地图 `M=(O,Σ,L)` 为证书坐标系，证书只在几何管 `B_3D(M,ε_g)` 内承诺；
> - **PEC（Perception-Erosion Certificate）**：感知不确定性对核心动作集做形态学腐蚀 `A_core ⊖ B_m(ε_g)`；
> - **PPS（Port Profile & Drift）**：端口 `p=(κ,ω,c,τ)` 与动作/感知复合漂移 `Λ=L_aδ_a+L_oδ_o`；
> - **PCG（Port Consensus Certificate）**：先腐蚀后交集的共享核 `A_core^Π=⋂_p A_core^{(p)}(ε_g)`；
> - **MPS（Multi-Port Set Selection）**：在可靠性**并集界**预算下做 0/1 背包选端口；
> - **PDM（Port Divergence Monitor）**：在线几何哈希监控端口漂移，超限即降级证书。
>
> IP 编号：IP-121~IP-127（共 7 个新增），升级 IP-115/116/118/120 以纳入三维几何与端口维度。

## 2. 关键算法 伪代码

### IP-121 GAC

```python
def geo_anchor(scene, pi_p, quantile=0.95):
    M = pi_p(scene)                              # (O, Sigma, L)
    eps_g = quantile_value(M.Sigma, quantile)    # 米；材质区另作膨胀
    rho = geometry_conditioned_robustness(M)
    return M, eps_g, rho

def material_inflate(eps_g, M, material_prior):
    # 透明/镜面/吸光区不确定性按材质先验膨胀
    return max(eps_g, max(eps_g * gain[m] for m in material_prior if m in TRANSPARENT_SET))

def geo_certify(M, eps_g, rho, rho_min):
    if min(rho[d] - rho_min[d] for d in rho) <= 0:
        return ('reject', 'geo_robustness_margin', rho)
    return ('ok', GeoCert(M, eps_g, rho))
```

### IP-122 PEC

```python
def erode_action_core(A_core, eps_g, dist_w):
    return {a for a in A_core if distance_to_boundary(a, A_core, dist_w) > eps_g}

def perception_erosion_certify(J54, M, eps_g, theta_core, dist_w):
    A_er = erode_action_core(J54.A_core, eps_g, dist_w)
    if measure(A_er) < theta_core * measure(J54.A_core):
        return ('reject', 'over_erosion', measure(A_er), eps_g)
    return ('ok', A_er, eps_g)
```

### IP-123 PPS

```python
def port_drift(p, q, probes, gamma_pq, L_a, L_o):
    d_a = max(dist_action(gamma_pq(a), a) for a in shared_core(p, q))
    d_o = max(geo_distance(mp, mq)
              for mp, mq in zip(probe_maps(p, probes), probe_maps(q, probes)))
    return d_a, d_o, L_a * d_a + L_o * d_o
```

### IP-124 PCG

```python
def port_consensus(certs, theta_core, delta_pi, L_a, L_o):
    cores = [erode_action_core(c.A_core, c.eps_g, dist_w) for c in certs]
    Acore = intersect_all(cores)
    if measure(Acore) < theta_core * min(measure(c) for c in cores):
        return ('reject', 'empty_or_over_eroded_consensus', measure(Acore))
    for p in certs:
        for q in certs:
            if p is q:
                continue
            _, _, Lam = port_drift(p, q, PROBES, gamma_pq, L_a, L_o)
            if Lam > delta_pi:
                return ('reject', 'port_drift', p.id, q.id, Lam)
    if not all(min(c.rho.values()) >= rho_min for c in certs):
        return ('reject', 'port_robustness')
    return ('ok', ConsensusCert(Acore, certs))
```

### IP-125 MPS

```python
def select_ports(ports, value, beta_bound, beta_budget, cost, lam):
    feasible = []
    for p in ports:
        r = port_consensus(p.certs, theta_core, delta_pi, L_a, L_o)
        if r[0] == 'ok':
            feasible.append(p)
    # 0/1 背包：最大化收益，受并集界失败预算约束
    return knapsack(feasible,
                    weight={p.id: beta_bound[p.id] for p in feasible},
                    budget=beta_budget,
                    profit={p.id: value[p.id] - lam * cost[p.id] for p in feasible})
```

### IP-126 GAP-JC

```python
def gap_joint_certificate(ports, J54, probes, budgets):
    anchors = []
    for p in ports:
        M, eps, rho = geo_anchor(p.scene, p.pi)
        eps = material_inflate(eps, M, p.material_prior)
        if geo_certify(M, eps, rho, rho_min)[0] != 'ok':
            return ('reject', 'geo', p.id)
        anchors.append((M, eps, rho))
    consensus = port_consensus([p.cert for p in ports], theta_core, delta_pi, L_a, L_o)
    if consensus[0] != 'ok':
        return consensus
    if len(ports) > budgets.n_max:
        return ('reject', 'port_budget', len(ports), budgets.n_max)
    return ('ok', GapCert(anchors, consensus.core, ports, budgets))
```

### IP-127 PDM

```python
def port_divergence_monitor(streams, delta_pi, window=50):
    for p, q in pairs(streams):
        h_p = geometric_hash(streams[p].recent(window))   # O/L/alpha 草图
        h_q = geometric_hash(streams[q].recent(window))
        if drift(h_p, h_q) > delta_pi:
            degrade_certificate(p)
            degrade_certificate(q)
            raise PortDivergence(p, q)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GAC | O(\|V_3D\|+\|A\|) | O(\|V_3D\|) | 几何管覆盖、Σ 校准、材质膨胀 |
| PEC | O(\|A_core\|·\|∂A_core\|) | O(\|A_core\|) | 腐蚀度量一致、ε_g 上界 |
| PPS | O(n²·(\|A_core\|+\|𝔐_probe\|·\|V_3D\|)) | O(n²) | 共享探针、γ 可逆 |
| PCG | O(n·\|A_core\|+n²·\|𝔐_probe\|) | O(n·\|A_core\|) | 先腐蚀后交集、非空判据 |
| MPS | O(\|Π\|·β_budget) | O(β_budget) | 并集界 sound、β 独立 |
| GAP-JC | O(n·(\|V_3D\|+\|A\|)+n²·\|𝔐_probe\|) | O(n·\|V_3D\|) | 四条件联合 sound |
| PDM | O(n²·window) | O(n·window) | 哈希碰撞概率、漂移阈值 |

**正确性定理（Geo-Action-Port Soundness，端口并集界）**
承接第 54 轮 (A26)–(A28)，新增 **(A29)** 几何-动作 Lipschitz、**(A30)** `Λ(p→q)≤Δ_Π`、**(A31)** 共享核下端口失败近似独立。则
```
P( ⋂_{p∈Π} success_p )
  ≥ 1 - Σ_{p∈Π} [ Σ_d (1-ρ_min^{(p)}(d)) + β_E^{(p)} + P(δ_a^{(p)}>Θ_a) ]
      - P(μ(A_core^Π)=0)
```
**推论（端口数悖论）**：下界随 `n` 单调不增，存在 `n*`；「多端口更稳」只在共享失败模式强相关时成立，而那时独立性假设已失效、并集界不可信——必须显式监测相关性。

## 6. 本轮最大风险

**一句话**：三维几何锚与多端口共识证书的 soundness **同时依赖「深度/占据不确定性被真实上界住」与「各端口失败近似独立」**；一旦透明/反光场景让 `ε_g` 被低估，或各端口共享同一感知失效模式，并集界会系统性乐观，多端口部署反而制造「鲁棒性假象」——故必须以 **材质感知的不确定性膨胀 + 共享失败模式相关性监测 + 保守端口数上限** 三重护栏，宁可少端口、窄核心，也绝不把「多端一致」当作可靠性证明。
