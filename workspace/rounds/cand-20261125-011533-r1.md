研究循环·迁移第 1 轮；本轮灵感：「迁移学习」×「虚实迁移」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（其上承 v21 的 SDC/CAC/DCL/GIC/HPC+/CFC+，v20 的联邦感知证书 PCA/CTS/CFC/HPC/CFCtrl，及 v19/v17 各模块全保留）。
> 本轮纪律：**迁移不是"复制结论"，而是"复制带契约的信念"；虚实差距不是标量，而是随轨迹变化、可被多通道独立上界的"差距场"；负迁移是必须熔断的故障，而非可容忍的误差**。不推倒 v22：HDL/ACSC/DCSC/HPC-E/CFC++ 全部保留。本轮只做一件事：**在 v22 的层级物理-能量证书之上加一层"可迁移性"层，使证书/先验跨机器人、跨环境、从仿真迁移到现实时始终携带"出处-位移预算-到期"契约，并用差距场与负迁移熔断守住安全继承**。

## 0. 直觉与动机

**灵感 1（迁移学习 → 证书是带位移预算的"信念"，不是可随便复制的"事实"）**
直觉：v22 的证书几乎都是"就地标定"的——每台机器人、每个环境、每个用户都重新算 conformal 分位、重新标定能量模型、重新学类先验。这既昂贵又浪费：同厂商机器人、同类抓取任务、同一套规则库，本应可以"带着经验走"。迁移学习的直觉正是：**源域 S 上标定好的先验/证书，若能证明目标域 T 与 S 的分布位移足够小，就能以剩余覆盖 1-α-ε_shift 的代价搬过来用**。但安全证书不像分类精度，不能"大概好用"：一条迁移来的先验必须随身携带一张**迁移契约 (Transfer Contract)**——出处、位移预算 ε_shift、适用域、到期时间。核心创新：**迁移证书 (Transfer Certificate, T-Cert) + 出处账本 (Provenance Ledger, PL)**。关键反直觉点：**"迁移成功"不是"目标域表现好"，而是"可证明地退化到就地标定"——迁移的全部价值在于它失效时能否无损退回保守基线**。

**灵感 2（虚实迁移 → 现实差距是场，不是标量，且必须被多条独立通道同时上界）**
直觉：v22 的 RGC 用一个标量 d_gap 概括"仿真与现实差多少"，这在安全上是危险的过度简化：差距在平坦地面可能极小，在湿滑/玻璃/反光/重载下却可能爆炸。虚实迁移给出正确对象：**差距是定义在状态-轨迹空间上的场 d_gap(x, π)**，可从三条彼此独立的通道被上界——(a) **域随机化覆盖**：若 DR 参数集以 ≥1-β 覆盖真实参数，则最坏仿真裕度给出真实裕度下界；(b) **系统辨识后验**：参数后验半径 + 模型 Lipschitz 常数传播出差距上界；(c) **真实残差 conformal**：少量真实 rollout 残差给出分位上界。关键技巧与反直觉点：**取三者上界的 min 仍然安全**——每个通道给出的是"≥真值"的上界，只要同时成立（union bound 1-Σδ_i），min 仍 ≥ 真值，却比任何单通道都紧；这正是对 v22「配空间能量过度保守导致活性坍缩」的解药。支撑域之外一律 d_gap = +∞。

**灵感 3（负迁移 → 必须熔断，且熔断只能向保守方向坍缩）**
直觉：迁移学习最阴险的失败不是"没迁成"，而是**负迁移**：源域先验在目标域系统性错误，且错误方向恰好更乐观（把不该释放的自由空间释放了、把能量需求低估了）。更糟的是，这种错误会伪装成"迁移很成功"——因为监控器本身也由同源数据校准。核心创新：**负迁移熔断器 (Negative Transfer Circuit-Breaker, NTCB)**：持续对照一个"就地从头标定"的影子基线 β_0（可取得极保守），用序贯检验（CUSUM/SPRT）检测迁移预测相对 β_0 的系统性劣化或概念漂移；一旦触发，**撤销全部迁移先验、退回非迁移保守补全**。关键反直觉点：**影子基线越保守，熔断越安全**——熔断的代价只是活性，而不熔断的代价是安全。撤销必须可传递：账本记录每条证书依赖了哪些迁移先验，撤销沿依赖图闭包生效。

**三者如何统一**
在 v22 之上加 **可迁移性层 (Transferability Layer, TL)**：T-Cert/PL 回答"这条经验凭什么能搬到这里、还能用多久"，RGF 回答"仿真结论在现实里还剩多少余量"，NTCB 回答"搬错了怎么止血"。共享状态扩展为 **ζ_xfer = ζ_pgev ∪ (L_prov, τ_transfer, ε_shift, d_gap(·), nt_monitor)**。统一准入门升级为 **HPC-EX = (HPC-E, ValidTransf, GapOK)**：几何∧规范∧负信息∧能量（v22）之后，再要求 **迁移契约在当前域成立（ValidTransf）且轨迹条件差距在信用预算内（d_gap(π) ≤ credit）**。任一不满足退回 v22 的就地保守模式。故 **Exec_v23 = Exec_v22 ∩ Fil_transfer ⊆ Exec_v22**，与 v22 的「层级边界模糊」风险互补：迁移收紧保守性，熔断守住安全性。

## 2. 设计原则（在 P41–P42 基础上新增 P43–P45）

**P43 迁移契约律（Transfer Contract Law）**
每条被迁移复用的先验/证书 ξ 必须携带契约 `K_ξ = (src, ε_shift, D_transfer, t_expire, deps)`。仅当当前状态 `x_t ∈ D_transfer ∧ t ≤ t_expire ∧ ε_shift ≤ ε_budget` 且 deps 全部有效时，才允许 ξ 参与证书计算；否则 ξ 视为不存在，退回就地标定。`Exec_v23` 中所有结论都可追溯到一组契约有效的 ξ，或显式声明"未用迁移"。**推论**：契约失效只会移除乐观先验 ⇒ 执行域单调收缩至 v22。

**P44 差距场界定律（Reality Gap Field Bound Law）**
`d_gap(π) := min{ d_DR(π), d_sysID(π), d_real(π) }`，其中每个 `d_i(π)=max_{x∈traj(π)} d_i(x)` 均为在置信 1-δ_i 下 ≥ 真实差距的轨迹级上界；故 union bound 下 `d_gap(π) ≥ 真实差距` 以 ≥1-Σδ_i 成立。仿真裕度须满足 `M_sim(π) - d_gap(π) ≥ margin_req` 才授予仿真信用；`x ∉ support` 时 `d_gap = +∞`。差距按轨迹条件化（逐点取上界、轨迹取最坏点），禁止用全局平均掩盖局部尖峰。

**P45 负迁移熔断律（Negative Transfer Circuit-Breaker Law）**
维护影子基线 β_0（就地、非迁移、可取最保守）。监控序贯统计量 `Λ_t`（迁移相对 β_0 的"乐观劣化"或漂移证据），超过阈值 γ_revoke 即触发撤销 `revoke(ξ)`，沿 PL 依赖图取传递闭包。撤销仅移除迁移先验、保留 v22 全部本地证书，故 `Exec_v23^{after} ⊆ Exec_v23^{before} ⊆ Exec_v22`。熔断状态带滞回 h，避免抖动反复解锁。

## 3. 与基线的接口（如何退化）

- T-Cert 失效（位移超预算 / 契约到期 / 域外）⇒ 不用迁移先验，就地重新标定 ⇒ 比 v22 更保守 ⇒ 子集；
- RGF = +∞（轨迹出支撑）⇒ 不授予仿真信用 ⇒ 退回 v22 的能量/几何保守约束 ⇒ 子集；
- NTCB 触发 ⇒ 撤销迁移，回退非迁移基线 ⇒ 单调收缩 ⇒ 子集；
- DCSC 深度特征跨域复用但概念漂移 ⇒ 加权 conformal 覆盖率跌破 1-α-ε_budget ⇒ T-Cert 拒绝 ⇒ 子集；
- 三者全失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ …`；
- **与 v22 层级过滤协同**：迁移只能"填回"被 v22 过度保守裁掉、且有契约担保的域，撤销只能"收回"这些填回 ⇒ `Fil_strategic ⊇ Fil_tactical ⊇ Fil_operational` 在每次迁移/撤销后仍保持。

## 5. 本轮最大风险

**一句话**：**差距场与可迁移性估计本身来自同一个仿真/源域家族**——DR 参数范围、sysID 数据集、漂移监控器的参考分布都与被检验的先验同源，于是"契约有效 ∧ 差距在预算内"可以**自指地自洽**，却在真实但未见的条件（湿滑地面、反光玻璃、负载突变、非典型人体）下同时落在 DR 支撑之外、又逃过同源校准的监控器——形成 union bound 也覆盖不到的**相关盲区**，机器人会"自信地、可审计地"执行一张只在它自己仿真镜像里成立的证书，即**虚实差距的自我确认幻觉**。

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
# IP-436 迁移契约 + 契约校验（含依赖传递闭包）
@dataclass
class TransferContract:
    src: str
    eps_shift: float          # 位移预算（覆盖率损失上界）
    domain: "TransferDomain"  # D_transfer
    t_expire: float
    deps: tuple               # 依赖的其他迁移契约 id，用于撤销传递闭包

class TransferContractCertificate:
    def __init__(self, ledger, eps_budget=0.01, now=None):
        self.ledger, self.eps_budget, self.now = ledger, eps_budget, now

    def valid(self, xi, x, t=None):
        t = self.now if t is None else t
        c = self.ledger.get(xi)
        if c is None:                      return False   # 无契约→视为不存在
        if t > c.t_expire:                 return False   # 到期
        if not c.domain.contains(x):       return False   # 域外
        if c.eps_shift > self.eps_budget:  return False   # 位移超预算
        # 依赖必须同样有效（传递闭包）
        return all(self.valid(d, x, t) for d in c.deps)

    def admit(self, x, t, priors):
        """只保留契约有效的迁移先验；其余显式退回就地标定。"""
        return [xi for xi in priors if self.valid(xi, x, t)]

# IP-440 带位移预算的加权 conformal（升级 DCSC）
class TransferableConformalCalibrator:
    def __init__(self, alpha=0.01, B_max=10.0, eps_budget=0.01, probe_tol=0.02):
        self.alpha, self.B_max, self.eps_budget, self.probe_tol = \
            alpha, B_max, eps_budget, probe_tol

    def _weighted_quantile(self, scores_src, weights, alpha_eff):
        order = np.argsort(scores_src)
        s, w = np.asarray(scores_src)[order], np.asarray(weights)[order]
        cw = np.cumsum(w) / np.sum(w)
        return float(s[np.searchsorted(cw, 1.0 - alpha_eff)])

    def calibrate(self, scores_src, w_target, scores_tgt_probe=None):
        # 位移估计：似然比上界 + TV 通道
        B_hat = max(1.0, float(np.max(w_target)))
        eps_shift = 0.5 * float(np.mean(np.abs(np.asarray(w_target) - 1.0)))  # ≈ TV
        if B_hat > self.B_max or eps_shift > self.eps_budget:
            return None, eps_shift                 # 拒绝迁移，退回就地标定
        alpha_eff = self.alpha + eps_shift         # 有效覆盖 ≥ 1 - alpha_eff
        q = self._weighted_quantile(scores_src, w_target, alpha_eff)
        # 概念漂移轻量探针：目标域少量有标签样本的经验覆盖
        if scores_tgt_probe is not None:
            emp_cov = float(np.mean(np.asarray(scores_tgt_probe) <= q))
            if emp_cov < (1.0 - alpha_eff - self.probe_tol):
                return None, eps_shift             # P(Y|X) 改变 → 拒绝
        return q, eps_shift

# IP-437 差距场：三通道轨迹级上界 → 取 min；支撑外 +∞
class RealityGapFieldCertificate:
    def __init__(self, dr, sysid, real_residual, margin_req, deltas=(1e-3, 1e-3, 1e-3)):
        self.dr, self.sysid, self.real = dr, sysid, real_residual
        self.margin_req, self.deltas = margin_req, deltas

    def _d_dr(self, x):
        if not self.dr.covers(x.param):
            return np.inf                          # 出 DR 支撑
        return self.dr.lipschitz_gap(x) + self.dr.model_err

    def _d_sysid(self, x):
        post = self.sysid.posterior(x.param)
        return self.sysid.lipschitz * post.radius + self.sysid.model_err

    def _d_real(self, x):
        return self.real.conformal_upper(x, delta=self.deltas[2])

    def _channel(self, fn, plan):
        # 轨迹条件化：逐点取上界，轨迹取最坏点
        return max(fn(x) for x in plan.trajectory)

    def gap(self, plan):
        per_channel = (self._channel(self._d_dr, plan),
                       self._channel(self._d_sysid, plan),
                       self._channel(self._d_real, plan))
        d = min(per_channel)   # 每个都是 ≥真值 的上界 ⇒ min 仍 ≥真值（union bound）
        return np.inf if not np.isfinite(d) else float(d)

    def gap_ok(self, plan):
        m_sim = min(plan.rollout_margins)          # 仿真最小安全裕度
        return (m_sim - self.gap(plan)) >= self.margin_req

# IP-438 负迁移熔断器（影子基线 + CUSUM + 滞回）
class NegativeTransferCircuitBreaker:
    def __init__(self, shadow_baseline, gamma=5.0, h=1.0, k=0.5):
        self.beta0, self.gamma, self.h, self.k = shadow_baseline, gamma, h, k
        self.L, self.tripped = 0.0, False

    @staticmethod
    def _optimism(pred, realized):
        # 越乐观（pred 给出的安全裕度越大）越危险，作为正劣化信号
        return float(pred.safety_margin - realized.safety_margin)

    def update(self, x, y_transfer, y_shadow, realized):
        e = self._optimism(y_transfer, realized) - self._optimism(y_shadow, realized)
        self.L = max(0.0, self.L + e - self.k)     # 单侧 CUSUM，只惩罚乐观方向
        if self.L > self.gamma:
            self.tripped = True
        elif self.tripped and self.L < self.gamma - self.h:
            self.tripped = False                   # 滞回，避免抖动
        return self.tripped

# IP-441 出处账本（merkle DAG，撤销取传递闭包）
class ProvenanceLedger:
    def __init__(self):
        self.nodes, self.reverse = {}, {}          # id -> node / dep -> dependents
        self.root = None

    def add(self, xi, contract: TransferContract):
        nid = sha256(repr((xi, contract)).encode()).hexdigest()
        self.nodes[nid] = {"id": nid, "src": contract.src, "eps": contract.eps_shift,
                           "deps": contract.deps, "api": contract.api_id}
        for d in contract.deps:
            self.reverse.setdefault(d, set()).add(nid)
        self.root = self._merkle_root()            # 版本化根哈希，供规则库审计交叉引用
        return nid

    def revoke(self, xi):
        """沿依赖反向边取传递闭包，返回所有须撤销的证书 id。"""
        seen, stack = set(), [xi]
        while stack:
            cur = stack.pop()
            for dep in self.reverse.get(cur, ()):  # 依赖 cur 的证书一并撤销
                if dep not in seen:
                    seen.add(dep); stack.append(dep)
        return seen

# IP-439 HPC-EX 统一准入门（HPC-E 原样保留，只加迁移门）
@dataclass
class HPC_EX:
    hpc_e: HPCE
    tcc: TransferContractCertificate
    rgf: RealityGapFieldCertificate

    def admits(self, plan, x, v, z, E_res, margin_req, priors, t):
        if not self.hpc_e.admits(plan, x, v, z, E_res, margin_req):
            return False                                   # v22 门先过
        admitted = self.tcc.admit(x, t, priors)            # 契约过滤迁移先验
        if len(admitted) != len(priors):
            plan = plan.with_priors(admitted)              # 失效者退回就地标定
        if not all(self.tcc.valid(xi, x, t) for xi in admitted):
            return False
        return self.rgf.gap_ok(plan)                       # 差距在信用预算内
```

## 2. 关键引理（本轮推导）

**引理 A（min 上界的安全性）** 设计划 π 的真实差距为 `g*(π)`。三通道各返回 `d_i(π)` 且 `P(d_i(π) ≥ g*(π)) ≥ 1-δ_i`。令 `d = min_i d_i`。则
`P(d ≥ g*) = P(∀i d_i ≥ g*) ≥ 1 - Σ_i δ_i`
（union bound）。故以 d 为上界安全；且 `d ≤ d_i`（逐样本），比任何单通道都更紧。∎

**引理 B（有界位移下的覆盖率）** 在 `P(Y|X)` 不变的协变量位移下，若似然比有界 `B`，加权 conformal 覆盖率 ≥ `1-α`；以估计 `ŵ` 代入时额外损失 `O(√(Var(ŵ)/n))`。用 TV 近似 `ε_shift = ½E|w-1|`，则覆盖率 ≥ `1-α-ε_shift`。当 `P(Y|X)` 改变（概念漂移）时该不变性被破坏，必须由目标域探针拒绝。故 T-Cert 仅需 `ε_shift ≤ ε_budget` 且探针通过。∎

**引理 C（撤销单调性）** 撤销只从证书计算中移除迁移先验 ξ（替换为就地保守补全），不移除 v22 任何本地证书；就地补全的可达集 ⊆ 迁移先验下的可达集，故
`Exec_v23^{after revoke} ⊆ Exec_v23^{before revoke} ⊆ Exec_v22`。∎

## 3. 实验设计

1. **跨机器人迁移（Q12/IP-440）**：在机器人 A 标定 DCSC/TCCal，迁移到同型号不同标定/磨损的机器人 B，扫描 ε_shift（0–0.05）测经验覆盖率；再注入概念漂移（肤色/衣着/光照/手势习惯），验证拒绝率与"无静默失效"。
2. **差距场 vs 标量 RGC（Q13/IP-437）**：在湿滑地面、反光玻璃、负载突变三类场景，比较 v22 标量 d_gap 与本轮差距场的保守性 vs 活性（任务成功率、平均速度、违反事件数）；重点验证 `min` 合成既不放宽安全、又比最保守单通道更紧。
3. **负迁移熔断（Q14/IP-438）**：构造"乐观错误"的源域先验（如把人形误学为静态物、把能量模型低估），测 NTCB 检测延迟、误报率、撤销后执行域是否单调收缩、是否出现活性抖动（滞回效果）。
4. **端到端 subset 校验（IP-439）**：随机采样计划，核验 `Exec_v23 ⊆ Exec_v22` 在迁移前/后、撤销前/后恒成立；同时测契约/差距场/熔断三模块的额外开销（应保持控制路径 O(1)）。
5. **出处审计（Q15/IP-441）**：对一组含多级依赖的迁移先验执行撤销，核对传递闭包完整性，并用 merkle 根与 v22 规则库审计交叉验证版本一致性。

## 4. 预期结果（可证伪的判据）

- **覆盖率**：`ε_shift ≤ 0.01` 时 TCCal 经验覆盖 ≥ `1-α-0.01`；概念漂移场景拒绝率 > 95%，且不存在"接受但覆盖率跌破 1-α-ε_budget"的静默失效。
- **活性/安全**：差距场相对标量 RGC 提升任务成功率（预期 +5%~15%）而违反事件数不增加（保持 0）。
- **熔断**：系统性负迁移在有界步数内触发撤销，撤销后无越界执行，滞回消除反复解锁抖动。
- **subset**：100% 随机计划满足 `Exec_v23 ⊆ Exec_v22`；新增模块单步开销 ≤ O(1)，不进入 50Hz 控制热路径（事件式注入）。

## 5. 取巧与边界（自评）

- 差距场的 `min` 合成假设三通道条件独立；若它们共享 sysID 数据源，union bound 虽仍保守但概率界的"独立性折扣"失效——这正是本轮最大风险。
- `ε_shift` 的 TV 近似在似然比估计噪声大时会低估；须同时用 B_hat 上界与目标域探针双保险。
- 撤销传递闭包的最坏复杂度与依赖图规模相关，须离线建图、在线只做 O(1) 位图查询。
