## 0. 本轮结论

这一轮先做了三次“合同核对”，结论比上一轮更硬：

1. **接口合同比模型结构更硬。** 提交 README 明确规定：`control_space` 只能是 `"joint"` 或 `"ee"`，二者互斥且在握手时固定；`action_chunk_size` 固定；`obs_delta_indices` 的键同时决定“发送哪些观测”和“时间堆叠”；`image_resize` 固定；评估器按序执行整段 chunk。观测只有 4 路 RGB、双臂 joint、左右 EE pose、gripper、`lower_body[15]`、language——**没有深度、没有相机内参/外参、没有 waist/torso/neck 状态**。数据集里的 `state_torso`、`state_d435`、`waist_state_joint` 在推理时不可见。上一轮“头部双目 + 深度 + 标定做部件 3D”的假设必须修正。
2. **动作空间的选择是可测问题，不是口味问题。** 实测 3 个任务（HangCup 324 eps/64.0k frames/6.55s；OrganizeTools 76/38.3k/16.76s；PlugCharger 169/70.9k/13.95s，均 30fps）：EE 动作与当前状态差 6.1–9.6mm / 0.032–0.072rad，joint 差 0.018–0.034rad；EE 每帧位移 p50 0.6–1.5mm、p95 4.8–9.7mm、p99 9.4–16.6mm；joint p95 0.019–0.038rad、p99 0.035–0.065rad。**动作是“接近当前状态的绝对目标”**，所以“绝对输出 + 残差 delta 学习”是自然的。pivot 在 HangCup/PlugCharger 恒定（p3=0，p4=0.15，p6≈0.737–0.740；HangCup 少数抬升帧到 0.654），OrganizeTools 的 p3/p4 大幅变化；**零 pivot 是错误默认**。gripper 实际范围 0–4.5，不是 0–1。
3. **量化与 TTC 已经各自成熟，但没人把它们接在“静态接口 + 真机成功率”上。** FoldQuantVLA：W4A4 + 语言 attention-output/FFN-down 保留 W8，GR00T N1.7 从 80.0% 提到 92.5%，Orin 仅 +1ms，1.20–1.33× 加速；HoloQ-VLA：uniform W4A4，π0.5 98.0%、GR00T N1.5 87.8%，显存 −74.2%；CHASE-VLA：chunk-aware 的 action expert 量化，π0.5 W4A4 97.3%；ActQuant：action-guided sub-4-bit，3 bpw 保留 95%。TTC 侧：VLA-ATTC 用“认知离合 + 相对动作 critic”把 π0.5 在 LIBERO-LONG 的失败率降 >50%；Verify/Act/Distill 用 10 episodes/task 把 54.1% 提到 70.6%；PACE 用相位边界把真机成功率 50.7% 提到 70.4%。动作空间侧：13k+ real rollouts 的实证研究说 delta 一致更好，joint 与 task space 互补（稳定性 vs 泛化）。

因此本轮主判断：

> **RUBICON 3.0 的部件/状态接口仍然对，但它漏掉了两个更硬的约束：动作空间合同与推理算力预算。** 本轮升级为 **RUBICON 4.0**：用动作敏感的混合精度量化把单模型 VLA 的 p99 压进 chunk 预算，再把省下的算力投到“K 个动作 chunk + 部件谓词代价 + 关节一致性”的短程 MPC；动作空间选 EE + 残差 delta，pivot 用数据先验而不是零。

四个 P0：

- **Q-MPC（Quantization-funded Model-Predictive Chunking）**：同一模型采样 K 个 chunk，用相对动作 critic、RPSM 谓词代价、轻量 part-state predictor、关节/安全/平滑代价联合打分，选最优 chunk 执行；不确定性高时才开 TTC（认知离合），并按 p99 预算自适应 K。这是本轮技术主押注。
- **ASC（Action Space Contract）**：全局选 `ee`，内部学残差 delta；pivot 用 `[0,0,0,0,0.15,0,0.738]` 先验 + 小幅残差；gripper 用 0–4.5 的混合开合头；训练一个 joint 辅助头做 EE 可行性 critic。换 joint 也能用同一套 Q-MPC。
- **ASQ（Action-Sensitive Quantization）**：视觉/语言 W4A4，动作头/gripper/pivot/critic/腕部 patch 保 W8；校准集偏向接触帧和高 jerk 帧；用 chunk-aware scale 和动作误差选位宽。量化不是省电，是买 K 个候选的预算。
- **RPSM 2.0（Reversible Part-State Memory）**：谓词信念进入 MPC 代价；候选 chunk 若导致已完成谓词回退，直接加罚；检测到撤销后只修复被撤销的子目标。这是官方 `human_1/human_4` 的直接对策。

一句话：**量化买算力，MPC 花算力，动作空间合同保证花得对，RPSM 保证不把已完成的活干回去。**

**读法**：

- 动作是**接近当前状态的绝对目标**，不是速度/力矩；因此“预测绝对目标”与“预测残差再重建绝对目标”都能表达，后者更稳。

## 2. 三条灵感词的落点

### 2.1 模型量化 → ASQ + Q-MPC

- **量化不是目的，是预算转换器。** 目标不是“更省电”，而是把单次 `get_action` 的 p99 压到 `T_a / f_ctrl` 以内，从而在同一次调用里跑 K 个候选。
- **动作敏感位分配**：视觉/语言可以 W4A4；动作头、gripper/pivot 头、critic、腕部高分辨率 patch 保 W8。FoldQuantVLA 已经证明“语言 attention-out/FFN-down 保 W8”能把 GR00T N1.7 从 80.0% 拉到 92.5%；我们把同样的逻辑扩展到动作/critic/接触 patch。
- **接触帧校准**：校准集按任务和相位分层，过采样夹爪闭合、接近接触、高 jerk 的帧；不用均匀采样。ActQuant 的 action-guided 位分配是层间的，我们再加一层“帧间”的动作敏感。
- **chunk-aware scale**：action expert 的激活范围随去噪步和 chunk 内容变化；用当前 chunk/去噪步组做 scale（CHASE 的思路），避免固定 scale 在接触段失配。
- **量化感知 critic**：critic 的输入是量化后的特征；训练时加量化噪声或在量化模型上校准，critic 本身保 W8/fp16。否则 critic 会给“量化伪影”打分，而不是给动作质量打分。
- **共享前缀**：VLM/视觉前缀只算一次，K 个候选只重复 action expert 的去噪；这是 K 倍开销远小于 K 倍全模型的关键。量化再把前缀和 action expert 一起压。
- **停机条件**：如果 W4 相对 fp16 在接触任务上掉 >2pp，退回 W8 或只量化视觉；如果 Q-MPC 在 2× 延迟下提升 <1.5pp，放弃 K>1，保留量化给 N 端口/更大底座。

### 2.2 动作空间 → ASC

- **全局选 EE。** 理由不是“EE 更高级”，而是本赛的泛化轴（位置/背景/未见物品）更吃 task-space 的几何泛化；joint 的优势是控制稳定，我们用 joint 辅助头 + 一致性 critic 把稳定性补回来。最终以 3 任务 A/B 为准：EE 若比 joint 差 >5pp，就换 joint，Q-MPC 不变。
- **残差 delta**：内部预测 `Δ`，重建绝对目标 `a_t = s_t ⊕ Δ_t`。数据里动作本来就贴近当前状态；delta 让网络学“小修正”，绝对目标保证接口兼容。对 EE 用位置加 + `Exp(Δr)`；对 joint 用 `q_s + Δq`。
- **相位感知限幅**：自由空间允许 p99 级别的位移（~15mm/0.1rad 每帧），接触段收紧到 p95 以下（~5mm/0.03rad）；超限按方向缩放，不逐轴硬裁。
- **pivot 先验**：`[0,0,0,0,0.15,0,0.738]` + 小幅学习残差；默认残差为 0。OrganizeTools 这类任务才放开 p3/p4。没有 waist 观测，就用命令积分维护一个内部估计，只用于粗重投影，不用于精密控制。
- **gripper 混合头**：开/合分类 + 目标开度回归，输出 0–4.5；加 0.2 单位滞回和 2–3 帧最小保持，避免抖动。训练按 4.5 归一。
- **关节一致性 critic**：同一 checkpoint 里训练一个 joint 辅助头；用 G1 FK（若可用）或数据学到的 joint→EE 映射，检查 EE 目标是否可达。`C_agree = ||FK(q̂) − p_EE||²` 进入 Q-MPC 代价。它不改变输出空间，只做 critic。
- **chunk 合同**：`T_a=8` 默认（30fps 约 267ms），消融 4/8/16；评估器执行整段，所以 chunk 尾部要保守（减速/保持），不能指望提前重查询。跨调用做时间集成，接触段不做平滑以免滞后。

### 2.3 模型预测控制 → Q-MPC

- **把 VLA 当 proposal generator，而不是最终决策者。** 同一模型采样 K 个 chunk；用复合代价选一个执行；下一个 chunk 重新规划。这是 sampling-based MPC（MPPI/CEM 的思路），不是需要精确动力学模型的经典 MPC。
- **代价四项**：任务成功率（relative critic）、部件进度/回退（RPSM）、短程 part-state 预测（轻量 head）、关节/安全/平滑/一致性（规则 + 辅助头）。所有项都在同一 checkpoint 内，或由规则计算。
- **认知离合**：只在不确定性高时开 K>1——候选方差大、谓词熵高、part head 置信度低、接触阶段、人手进入。自由空间 K=1，省下的预算留给接触。
- **粗到细**：K 个候选先用少量去噪步（如 3 步）粗排，top-2 再补到完整步数；把 `K × n_full` 降到 `K × n_coarse + 2 × (n_full − n_coarse)`。
- **滚动时域**：chunk 长度就是预测时域；每个 chunk 调用重规划一次。因为评估器执行整段，MPC 的“重规划频率”由 `action_chunk_size` 决定，不能按阶段改；这更凸显全局选 chunk 长度的重要性。
- **与量化闭环**：Q-MPC 的 K 由 p99 预算决定；量化降低 `T_prefix`/`T_candidate`，从而允许更大的 K；更大的 K 又提升接触成功率。这个正反馈是本轮的核心叙事。

**与 RUBICON 3.0 的关键变化**：

- **主押注从“部件分割蒸馏”换成“量化供能的 MPC”**：部件接口仍然需要，但它现在是 Q-MPC 的观测/代价来源，不再单独承担“赢”的叙事。
- **动作空间从背景假设变成 P0**：`control_space` 全局互斥、无深度/标定、pivot 有数据先验——这四点直接改变架构。
- **量化从部署细节变成 P0**：不是为了省显存，而是为了买 K 个候选；ASQ 是 Q-MPC 的前置条件。
- **PACE 的“执行时域”降级**：API 执行整段 chunk，不能按阶段提前重查询；只保留“相位感知限幅/尾部保守/全局 chunk 长度选择”。
- **3D 部件从“标定 + 深度”降级为“相对/学习 2.5D”**：推理接口不给深度和内参，硬编码标定既脆弱又可能过拟合。
- **公开榜仍然不可用**：继续只引论文，不引分数。

## 4. 修剪/暂缓

- **在线分割/检测模型**：不跑第二个模型；SAM3/PartSAM 只做离线教师。
- **运行时 LLM/VLM API**：延迟/网络/规则风险；离线编译。
- **任务特定硬编码轨迹/坐标**：泛化差，可能违规；用语言 + 部件谓词 + 学习策略。
- **激进 pivot / 大幅 base 运动**：默认先验 + 小残差；先探针。
- **完整 3D 重建/标定依赖**：推理不可见；改成相对 2.5D。
- **运行中动态改 metadata**：握手固定；不要假设。
- **完整 world model rollout**：太慢；用轻量 part-state predictor/特征蒸馏。
- **在线 RL/真机 RL**：样本效率/安全/时间不允许。
- **“再大一点的 VLA”**：本轮比的是预算分配 + 动作合同 + 可逆状态，不是参数量。
- **把 K 开到底**：只在不确定性高时开；p99 是硬约束。

## 5. 为什么这版可能赢

- **对准口径**：成功率优先。Q-MPC 直接减少“坏 chunk 导致整段失败”；RPSM 直接减少“已完成子目标被撤销后继续瞎做”。
- **对准接口**：所有设计都尊重 `control_space` 互斥、chunk 固定、obs 静态、无深度/标定、单模型。不是“论文里很酷但提交不了”的方案。
- **对准数据**：EE + 残差 delta、pivot 先验、gripper 0–4.5 都来自实测，不是拍脑袋。
- **对准部署**：量化省显存支持 N 端口；共享前缀 + 自适应 K 把 p99 守住；4h soak 是门禁。
- **对准风险**：每个 P0 都有 A/B 和停止条件；如果 EE 不行换 joint，如果量化掉点退 W8，如果 Q-MPC 不涨就回 K=1；不会把整个项目押在一个未验证的假设上。
- **有真实文献支撑，但不依赖假榜单**：量化/TTC/动作空间的数字都来自论文；本赛的真实排名仍不可见，所以用离线 LPL + 真机 A/B 做决策。

## A. 结论

本轮把 RUBICON 3.0 升级为 **RUBICON 4.0**。核心不是“再大一点的 VLA”，而是把比赛最硬的三件事接起来：

1. **Q-MPC（Quantization-funded Model-Predictive Chunking）**：同一模型在一次 `get_action` 里采样 K 个动作 chunk，用“相对动作 critic + RPSM 谓词进度/回退代价 + 轻量 part-state predictor + 关节/安全/平滑/一致性代价”联合打分，选最优 chunk 执行；只在不确定性高时开 K>1（认知离合），并按 p99 预算自适应 K。
2. **ASC（Action Space Contract）**：全局选 `ee`（若 A/B 证明 joint 更好则换 joint），内部学残差 delta；pivot 用数据先验 `[0,0,0,0,0.15,0,0.738]` + 小幅残差；gripper 用 0–4.5 的混合开合头；同一 checkpoint 训练 joint 辅助头做 EE 可行性 critic。
3. **ASQ（Action-Sensitive Quantization）**：视觉/语言 W4A4，动作头/gripper/pivot/critic/腕部 patch 保 W8；接触帧校准；chunk-aware scale；量化感知 critic。量化不是省电，是买 K 个候选的预算。
4. **RPSM 2.0**：谓词信念进入 MPC 代价；候选 chunk 若导致已完成谓词回退，直接加罚；检测到撤销后只修复被撤销的子目标。

**最重要的接口修正**：提交 API 的观测只有 4 路 RGB、双臂 joint、左右 EE pose、gripper、`lower_body[15]`、language；**没有深度、没有相机内参/外参、没有 waist/torso/neck 状态**。数据集里的 `state_torso`、`state_d435`、`waist_state_joint` 在推理时不可见。因此：

- 部件 3D 不能依赖标定/深度，必须做**相对/学习 2.5D**；
- pivot 不能依赖 waist 反馈，只能**开环 + 数据先验 + 小残差**；
- `control_space` 全局互斥，不能按任务切 joint/ee；
- `action_chunk_size`、`obs_delta_indices`、`image_resize` 在握手时固定，不能运行中改；
- 评估器按序执行整段 chunk，不能指望 PACE 式提前重查询。

**评分口径不变**：成功率优先，步骤分是 tie-breaker；10 trials/task × 32 任务，p≈0.3 时总平均成功率的标准误约 2.6pp，1–2pp 的榜单差距基本是噪声。策略仍是“先消灭 0% 任务，再攻 3–5pp 的真实增益”。

以下所有事实、数字、架构、实验与风险均以 **2026-10-23** 可访问的公开页面/文件/论文为准；无法核实的地方明确标注“未核实”。

### C.2 读法与设计含义

1. **动作是“接近当前状态的绝对目标”**：EE 差 6–10mm/0.03–0.07rad，joint 差 0.018–0.034rad。这既支持“直接回归绝对目标”，也支持“预测残差再重建”。后者让网络学小修正，数值更稳。
2. **大多数帧几乎不动，大位移集中在相位边界**：EE p50 0.6–1.5mm，p95 4.8–9.7mm，p99 9.4–16.6mm；joint p50 0.0026–0.0052rad，p95 0.019–0.038rad，p99 0.035–0.065rad。**不要全程用一个限幅**；自由空间放宽、接触段收紧。
3. **pivot 有明确的数据先验**：HangCup/PlugCharger 的 p3=0、p4=0.15、p6≈0.737–0.740（HangCup 少数抬升帧到 0.654）；OrganizeTools 的 p3/p4 大幅变化（p3 −0.171–0.569，p4 0–0.573）。**零 pivot 会让机器人缺少默认高度/俯仰**；默认用先验，只有工具/架子类任务才放开残差。
4. **gripper 是 0–4.5 的目标开度**：中位数常为 4.5（张开），闭合到 0；按 0–1 归一会压扁信号。用“开/合分类 + 目标开度回归”的混合头，加滞回。
5. **EE 与 joint 都可行**：数据里两者都平滑、都贴近状态；选择取决于控制器跟踪质量与泛化轴，必须做 A/B。这推翻了“joint 一定更稳/EE 一定更准”的教条。
6. **30fps、chunk=8 → 267ms**：Q-MPC 的 p99 预算按这个量级估；实际控制频率未核实，先按 30Hz 做，实测后再改。
7. **lower_body 有运动**（per-dim std 最高 0.05–0.085，绝对值最高约 0.7–0.79rad），但 API 不提供腿动作；它只能作为平衡上下文，不能作为可控输出。

### D.3 研究空白

- 量化论文大多只报 LIBERO/SimplerEnv 和延迟/显存，**没有把省下的算力用于 TTC**；TTC 论文大多假设算力充足，**没有在真机 p99 约束下做自适应 K**。
- 动作空间论文给出“delta 更好、joint/task 互补”的统计结论，但**没有把动作空间当成提交合同**（全局互斥、无深度/标定、pivot 必填）来设计。
- PACE/Verify-Act-Distill 在 chunk 执行/候选评分上很强，但**没有处理“已完成子目标被撤销”**；RPSM 2.0 把可逆状态放进 MPC 代价。
- 本赛的接口恰好把这三条缝在一起：静态合同 + 真机成功率 + 人为撤销干扰。**Q-MPC + ASC + ASQ + RPSM 2.0** 就是针对这个缝隙的组合。

> 注：以上“短板/空白”是按公开论文做的推断，不是官方评测结论；真实排名不可见，不能据此断言谁强谁弱。

## E. Q-MPC：量化供能的模型预测分块控制

### E.1 问题定义

在每个决策步 `t`，策略收到观测 `o_t`（4 视图 + language）、本体 `s_t`（双臂 joint、EE pose、gripper、lower_body），维护部件 token `z_t` 与谓词信念 `b_t`：

```text
x_t = (o_t, s_t, z_t, b_t)
```

动作 chunk：

```text
A = (a_0, ..., a_{T_a-1})
a_i = (p^L_i, p^R_i, g^L_i, g^R_i, π_i)      # ee 模式
   或 (q^L_i, q^R_i, g^L_i, g^R_i, π_i)      # joint 模式
```

目标：在 p99 延迟预算内，选一个 chunk 最大化“完成任务且不撤销已完成子目标”的概率。

### E.2 采样与预测

同一模型采样 K 个候选：

```text
A^(k) ~ p_θ(A | x_t),  k = 1..K
```

- flow matching：不同初始噪声 `ε^(k)`；可加温度 `τ`。
- 自回归：不同采样温度/核。
- 共享前缀：VLM/视觉 token 只算一次；K 个候选只重复 action expert 的去噪。
- 轻量 part-state predictor `f_ψ`（同一 checkpoint 内的小 head）：

```text
(ẑ_{t+H}, b̂_{t+H}) = f_ψ(z_t, b_t, A^(k)),  H = T_a
```

`f_ψ` 不是第二个策略模型：它是一个 transformer/GRU head，输入是 part tokens + 候选 chunk，输出是 chunk 末端的 part-state 与谓词概率。训练目标来自数据集的未来帧（part 伪标签/谓词标签），多 horizon（1/2/4/T_a）监督。

### E.3 复合代价

```text
J(A) = λ_s · (1 − p̂_succ(A))
     + λ_g · (1 − ĝ(A))
     + λ_u · p̂_undo(A)
     + λ_r · ||ẑ_{t+H} − z*||_W²
     + λ_k · C_kin(A)
     + λ_m · C_smooth(A)
     + λ_a · C_agree(A)
```

逐项：

| 项 | 定义 | 来源 |
|---|---|---|
| `p̂_succ(A)` | relative critic 的 pairwise 分数（softmax 归一） | `φ(x_t, A)` head；VLA-ATTC 思路 |
| `ĝ(A)` | `Σ_k w_k b̂_{t+H}(k)`，加权谓词进度 | RPSM 2.0 |
| `p̂_undo(A)` | `Σ_k w_k [b_t(k) − b̂_{t+H}(k)]_+ / Σ w_k` | RPSM 2.0；撤销惩罚 |
| `‖ẑ_{t+H} − z*‖_W²` | 目标部件状态距离；`z*` 可由成功片段检索/语言目标给出 | SPA-VLA 2.0；可选 |
| `C_kin(A)` | 关节限位、速度/加速度、工作空间、自碰撞代理 | 规则 + joint 辅助头 |
| `C_smooth(A)` | jerk、gripper 抖动、与上一 chunk 的偏差 | 规则 |
| `C_agree(A)` | `‖FK(q̂(A)) − p̂_EE(A)‖²`；EE 目标与 joint 辅助头的一致性 | joint 辅助头 + FK/学习映射 |

**选择**：

```text
A* = argmin_k J(A^(k))                    # 接触段/多模态：argmin
A* = Σ_k softmax(−J(A^(k))/τ) · A^(k)     # 自由空间：软聚合
```

- 接触段用 argmin，避免平均掉正确的插入模式；
- 自由空间用软聚合，减少抖动；
- 只聚合位置/关节，不聚合 gripper 的离散开合；gripper 用投票 + 滞回。

### E.4 Relative action critic

```text
r_φ(A^i, A^j) = σ(φ(x_t, A^i) − φ(x_t, A^j))
L_φ = −E[ y log r_φ + (1−y) log(1−r_φ) ]
```

- `φ` 是同一 checkpoint 内的 critic head；输入是共享前缀特征 + 候选 chunk 的池化。
- 偏好对自动生成：
  - `A^+`：数据集的演示 chunk；或谓词进度更高的候选；或动作误差更小的候选。
  - `A^-`：加噪/扰动 chunk；谓词回退的候选；超限/不安全的候选。
- 不做绝对价值回归，避免跨任务尺度不一致；pairwise 更适合 32 任务混合训练。
- 推理时对 K 个候选算 `φ`，softmax 归一成 `p̂_succ`。

### E.5 自适应 K（认知离合）

```text
u_t = α · Var_k(A^(k)) + β · H(b_t) + γ · (1 − c_part) + δ · 1[contact]
K_t = 1   if u_t < u1
      2   if u1 ≤ u_t < u2
      4   if u2 ≤ u_t < u3
      8   if u_t ≥ u3
```

- `Var_k(A^(k))`：候选分歧；大 → 需要多想。
- `H(b_t)`：谓词熵；高 → 状态不确定。
- `1 − c_part`：part head 置信度低。
- `1[contact]`：夹爪闭合/接近目标/高 jerk。
- 延迟守门：若预测 `T_call(K_t) > 0.8 · T_budget`，逐级降 K；**p99 是硬约束，不是平均值**。
- 自由空间 K=1；接触/干扰/相位边界才开 K=4–8。

### E.6 延迟预算与粗到细

```text
T_budget = T_a / f_ctrl
T_call(K) = T_prefix + T_flow(K, n_steps) + T_critic
constraint: p99(T_call) ≤ 0.8 · T_budget
```

- `T_a=8`、30fps → `T_budget≈267ms`；`T_a=16` → 533ms。
- 共享前缀：`T_prefix` 只付一次；`T_flow` 随 K 增长。
- 粗到细：

```text
stage 1: K × n_coarse（如 3 步）→ 粗排
stage 2: top-2 × (n_full − n_coarse)（如再 7 步）→ 精排
```

- 成本从 `K·n_full` 降到 `K·n_coarse + 2·(n_full−n_coarse)`；K=8、n_full=10、n_coarse=3 时约为 38 步 vs 80 步。
- 量化（ASQ）进一步降低 `T_prefix`/`T_flow`；这是“量化买 K”的定量关系。

### E.7 算法

```text
def get_action(obs):
    x = encode_prefix(obs)                 # 共享前缀；ASQ W4
    z, b = part_head(x), rpsm(x)           # 部件 + 谓词
    K = choose_K(x, z, b, budget)          # 认知离合
    cands = sample_chunks(x, K, n_coarse)  # 同一模型，不同噪声
    top = select_top(cands, critic, 2)
    cands = refine(top, n_full)
    J = composite_cost(x, z, b, cands)
    A = argmin(J) if contact(x,z) else soft_aggregate(J, cands)
    A = smooth_and_clamp(A, prev_chunk)    # 相位感知限幅/时间集成
    return A
```

### E.8 单模型合规

- 一个 checkpoint 包含：backbone、part head、action head、predicate head、critic、predictor、joint 辅助头。
- K 个候选是**同一模型的不同采样**，不是多个模型。
- critic/predictor 是 head，不是第二个策略；不加载外部 verifier。
- 教师（SAM3/PartSAM/世界模型）只在离线；部署时不加载。
- 如果规则对“辅助头”有疑问：在 model card 说明它们在同一计算图，所有输出由同一 checkpoint 产生。

### E.9 消融与停止条件

| 实验 | 变量 | 目的 |
|---|---|---|
| Q0 | K=1（无 MPC） | 基线 |
| Q1 | K=2/4/8 固定 | K 的边际收益 |
| Q2 | + relative critic | critic 是否有效 |
| Q3 | + RPSM 代价 | 撤销惩罚是否有效 |
| Q4 | + predictor | 短程预测是否有效 |
| Q5 | + joint 一致性 | 可行性 critic 是否有效 |
| Q6 | 自适应 K vs 固定 K | 认知离合的收益/延迟 |
| Q7 | 粗到细 vs 全步 | 延迟-成功率折中 |
| Q8 | 量化 vs fp16 critic | 量化感知 critic 是否必要 |
| Q9 | oracle 选择（用真值） | 上限；判断 critic 是否值得继续投入 |

**停止条件**：

- 如果 K=4 在 2× 延迟下相对 K=1 的 full success 提升 <1.5pp，放弃 K>1，保留 K=1 + RPSM + 量化给部署。
- 如果 oracle 选择相对 K=1 的提升 <2pp，说明候选空间本身没有好解，转去提升单候选质量（数据/动作空间）。
- 如果 p99 超过 `0.8·T_budget` 且降 K 后仍超，先修量化/部署，不继续加 K。

### E.10 风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| critic 不准，选到坏 chunk | 中 | 高 | pairwise 训练 + oracle 上限 + 只在接触段开 K |
| K 倍开销压垮 p99 | 中 | 高 | 共享前缀 + 粗到细 + 自适应 K + ASQ |
| predictor 误差累积 | 中 | 中 | 多 horizon 监督 + 只用短程 + 置信度门控 |
| 软聚合平均掉多模态 | 中 | 高 | 接触段 argmin；gripper 投票 |
| 量化噪声让 critic 失真 | 中 | 中 | 量化感知训练 + critic W8 |
| 单模型解释争议 | 中 | 高 | 同一 checkpoint；教师离线；manifest |

## F. ASQ：动作敏感量化

### F.1 位分配

```text
b_l = 8   if l ∈ G_protect
      4   if S_l ≤ τ
      8   otherwise

G_protect = {action head, gripper head, pivot head, critic,
             wrist-view adapter/projection, first/last action-expert blocks}
```

- `S_l`：动作敏感度。两种估计：
  - 梯度：`S_l = E_contact[ ||∂L_action/∂W_l||_F² ]`
  - 经验：逐层量化后动作误差的增量（更贵但更准）
- `τ`：按目标位宽比例/显存预算选；先保动作，再压视觉/语言。
- 视觉/语言：W4A4（HoloQ 证明可行）；语言 attention-output/FFN-down 保 W8（FoldQuant）。
- action expert：W4A4 + chunk-aware scale（CHASE）；若动作误差超阈值，升到 W8。
- 腕部视图：接触细节，adapter/投影保 W8 或更高分辨率；头部视图可以更激进。

### F.2 校准

- 512–1024 帧，按 32 任务 × 相位分层；过采样：
  - 夹爪闭合前后 10 帧；
  - 接近接触/插入/拧盖/拉链；
  - 高 jerk（EE Δ > p95）；
  - 人为干扰/遮挡帧。
- 不用均匀采样：均匀采样会被大量“慢速自由空间”帧主导，动作敏感层校准不足。
- chunk-aware：用当前 chunk + 去噪步组做 scale（CHASE），避免固定 scale 在接触段失配。
- 离群值：Hadamard/rotation（HoloQ/FoldQuant）+ per-token dynamic activation quantization。
- 校准后验证：动作误差、谓词置信度、critic 排序一致性，不只验证 perplexity。

### F.3 量化感知 critic

- critic 的输入是量化后的共享特征；训练时加量化噪声，或在量化模型上重新校准 critic。
- critic 本身保 W8/fp16；不把 critic 压到 W4，否则它会给量化伪影打分。
- 评估：在接触任务上比较“fp16 critic + 量化特征” vs “量化 critic + 量化特征”的排序一致性（pairwise accuracy）。
- 如果排序一致性 <70%，提高 critic 位宽或改用规则代价。

### F.4 预期与测量

**论文给出的量级**（不是我们的承诺）：

- FoldQuantVLA：Orin 1.20–1.33×，桌面 1.25–1.52×；W4A4 + 特定 W8 层；GR00T N1.7 80.0→92.5%。
- HoloQ-VLA：uniform W4A4，π0.5 98.0%、GR00T N1.5 87.8%，显存 −74.2%。
- CHASE-VLA：π0.5 W4A4 97.3%，AE 权重 −73.4%，单 chunk 内存流量 −70.9%/−71.2%。
- ActQuant：3 bpw 保留 95%，2.5 bpw 90.1%，5.3× 压缩；UR3 真机保成功率、内存 −2.5×。

**我们的测量矩阵**：

| 配置 | 视觉/语言 | action head | critic | 目标 |
|---|---|---|---|---|
| QF | fp16 | fp16 | fp16 | 基线 |
| Q8 | W8A8 | W8A8 | W8 | 保守 |
| Q4 | W4A4 | W4A4 | W8 | 激进 |
| ASQ-A | W4A4 | W8A8 | W8 | 保动作 |
| ASQ-B | W4A4 + 语言 W8 层 | W4A4 + chunk scale | W8 | 论文配方 |
| ASQ-C | W4A4 | W8A8 + 腕部 W8 | W8 | 接触优先 |

指标：动作误差（mm/rad/gripper）、3 接触 + 3 简单任务的 full success、p50/p95/p99、权重/峰值显存、N 份并发的 p99。

### F.5 风险

| 风险 | 缓解 |
|---|---|
| 量化噪声让接触抖动 | 保护动作头/gripper/pivot；接触帧校准；QAT/LoRA |
| TensorRT/内核不支持某些 op | 回退 PyTorch/FP8；记录算子覆盖 |
| 量化模型不可复现 | 固定 seed/kernel；记录版本；重放 |
| 底座本身不量化友好 | 先小规模测 3 任务；不友好就只量化视觉 |
| 省下的算力被 K 吃掉 | 用 p99 守门；K 自适应；粗到细 |

## G. ASC：动作空间合同

### G.1 EE vs joint 的全局选择

**默认 `control_space="ee"`**，理由：

- 本赛的泛化轴是位置/背景/未见物品；task-space 的几何泛化更强（Demystifying 论文：task space 偏泛化，joint 偏控制稳定）。
- 接触任务（插头/网线/拉链/瓶盖）需要 Cartesian 的相对位姿伺服。
- 数据集同时有 EE 和 joint 动作，EE 监督充足；EE 动作与状态差 6–10mm，适合残差学习。

**但必须 A/B**：

- 3 任务（HangCup、PlugCharger、OrganizeTools）× 10 trials；同一底座/数据/训练预算。
- 指标：full success、EE 跟踪误差、动作平滑度、p99。
- 如果 EE 比 joint 低 >5pp，或 EE 跟踪误差 p95 >10mm，切 joint；Q-MPC/ASQ/RPSM 不变，只换输出空间和残差定义。
- 如果 joint 更好，joint 辅助头变成主头，EE 头变成一致性 critic（角色对调）。

### G.2 残差 delta

EE 模式：

```text
p_t = p_s + Δp
R_t = R_s · Exp(Δr)
a_t = (p_t, R_t)
```

joint 模式：

```text
q_t = q_s + Δq
```

- 网络预测 `Δ`；`s_t` 来自观测，`a_t` 是发给评估器的绝对目标。
- 损失：

```text
L_action = ||Δ_pred − Δ_gt||² + λ_abs · ||a_pred − a_gt||²
```

- `λ_abs` 小（如 0.1），保证重建一致；主监督在 `Δ`。
- 相位感知限幅：

```text
free space:  ||Δp|| ≤ 15mm/step,  ||Δr|| ≤ 0.10 rad/step
contact:     ||Δp|| ≤ 5mm/step,   ||Δr|| ≤ 0.03 rad/step
```

- 超限按方向整体缩放，不逐轴裁剪（保持方向）。
- 30fps 下 5mm/step ≈ 150mm/s，15mm/step ≈ 450mm/s；以真机跟踪为准再调。

### G.3 pivot 先验

```text
π_t = π_prior + δ_t
π_prior = [0, 0, 0, 0, 0.15, 0, 0.738]
```

- `δ_t` 由小 head 输出；L2 惩罚；默认 `δ=0`。
- 限幅：`p3 ∈ [−0.2, 0.6]`、`p4 ∈ [0, 0.6]`、`p6 ∈ [0.70, 0.76]`。
- 何时放开残差：语言/part head 指示工具、架子、高处/低处目标；或 EE 目标在当前 waist 下不可达（用 joint 辅助头/FK 判断）。
- 没有 waist 观测：用 `π` 命令积分维护 `π̂`；只用于粗重投影/可达性检查，不用于精密控制。漂移可接受，因为默认 pivot 静态。
- 探针：每个任务前 1–2 个 trial 先输出先验，记录是否成功；若默认高度与评测机器人不匹配，按任务中位数调先验（不是在线自适应）。
- 风险：OrganizeTools 类任务需要 waist；如果残差不够，优先用双臂可达性/底座不动，而不是大幅 waist。

### G.4 gripper 混合头

```text
u_t = MLP(features)
c_t = sigmoid(u_t)                  # 开概率
g_t = 4.5 · [ c_t · g_open + (1−c_t) · g_close ]   # 或分类 + 回归
```

- 训练：BCE（开/合）+ L1（目标开度，按 4.5 归一）；类别平衡。
- 输出：原始 0–4.5 单位；加 0.2 单位滞回 + 2–3 帧最小保持，避免抖动。
- 评估：开合切换延迟、夹爪抖动次数、抓取成功率。
- 不用纯回归：开合是双模态，纯回归容易停在中间；混合头更稳。

### G.5 chunk 合同

- 默认 `T_a=8`（30fps ≈267ms）；消融 4/8/16。
- 评估器执行整段 chunk；不能在阶段中间提前重查询。
- chunk 尾部保守：最后 1–2 步减速/保持，尤其当 `u_t` 高或接近接触。
- 时间集成：`A_out = β·A_new + (1−β)·A_prev_shifted`；位置/关节线性混合，旋转用 SLERP/四元数；自由空间 β=0.5–0.8，接触段 β=1（不平滑，避免滞后）。
- 若实际控制频率不是 30Hz：按 `T_a / f_ctrl` 重算；chunk 长度选择以 p99 与反应性折中。

### G.6 观测合同（静态）

| 键 | 偏移 | resize | 理由 |
|---|---|---|---|
| `language` | `[0]` | — | 必须 |
| `cam_left_high` | `[-4, 0]` | `[240,320]` | 全局语义/位置；2 帧足够 |
| `cam_right_high` | `[-4, 0]` | `[240,320]` | 同上；双目可学相对深度 |
| `cam_left_wrist` | `[-2, 0]` | `[240,320]` | 接触近景；2 帧抓动态 |
| `cam_right_wrist` | `[-2, 0]` | `[240,320]` | 同上 |
| `left_arm` / `right_arm` | `[-4,-2,0]` | — | 3 帧本体 |
| `left_ee_pose` / `right_ee_pose` | `[-4,-2,0]` | — | 3 帧；残差基准 |
| `left_gripper` / `right_gripper` | `[-4,-2,0]` | — | 3 帧；开合动态 |
| `lower_body` | `[-2,0]` | — | 平衡上下文；15 维，低频 |

- 这是**静态合同**；不能运行中改。选择依据：离线延迟/成功率消融。
- 4 视角 × 2 帧 × 240×320 ≈ 8 张图/次；比原生 480×640 × 4 帧便宜 8×。
- 头部 2 帧而不是 4 帧：场景变化慢；腕部 2 帧足够抓接触动态；如果消融显示 4 帧更好，再换。
- 模型内部可以做 token 裁剪/early-exit（不改 metadata），例如接触段少看头部、多看腕部。

### G.7 joint 一致性 critic

- 同一 checkpoint 训练 joint 辅助头 `q̂`（14 维）。
- 若 G1 FK 可用：`C_agree = ||FK(q̂) − p_EE||²`。
- 若 FK 不可用：在数据集上训练 `q → p` 的小 MLP（输入 14 维关节，输出 12 维双臂 EE），用 `C_agree = ||MLP(q̂) − p_EE||²`。
- 该 critic 只用于 Q-MPC 打分；不改变输出空间。
- 如果部署 joint，则角色对调：EE 辅助头做一致性 critic。

### G.8 安全限幅

- 工作空间包围盒：以桌面为中心，按数据统计设安全盒；超界缩放/拒绝。
- 最大 EE 速度/加速度、最大关节速度；NaN/超限 → hold/retreat。
- 人手接近：part head 加 `human hand` query 或轻量 RGB 检测；低于阈值降速/暂停；不引入第二个学习策略。
- 夹爪力上限（若可设）；不可设则用开度/电流代理。
- 审计：每 trial 记录动作统计、限幅触发、安全事件、延迟。

### G.9 消融

| 实验 | 变量 | 目的 |
|---|---|---|
| A0 | EE 绝对 | 基线 |
| A1 | EE + 残差 delta | delta 是否更稳 |
| A2 | joint 绝对 | 对照 |
| A3 | joint + 残差 delta | 对照 |

## H. RPSM 2.0：可逆部件状态记忆

### H.1 谓词库（8–12 个通用谓词）

| 谓词 | 含义 | 观测来源 |
|---|---|---|
| `grasped(side, part)` | 夹爪抓住部件 | gripper 开度 + part 相对位姿 |
| `in_hand(side, part)` | 部件在手中 | part 跟踪 + gripper |
| `inserted(part, target)` | 插入到位 | part-target 相对位姿 + 接触 |
| `on_hook(part)` | 挂在钩上 | part 3D/相对深度 + 钩子 |
| `closed(part)` | 盖子/拉链/笔盒闭合 | part 状态分类 |
| `stacked(part, k)` | 堆叠到第 k 层 | 高度/顺序 |
| `sorted(part, bin)` | 分拣到料盒 | part-bin 关系 |
| `in_box(part)` | 放入盒/格 | part-box 关系 |
| `unlocked` | 锁打开 | 钥匙/锁状态 |
| `poured` | 倒出 | 瓶身/药片 |
| `undone(k)` | 子目标 k 被撤销 | 上述谓词的 false 翻转 |
| `object_missing(part)` | 目标消失 | 重检测失败 |

任务映射示例：T01 `cup_on_hook`；T10 `plug_inserted`；T12 `unlocked`；T14 `cap_off`/`poured`；T16 `fold_1`/`fold_2`/`folded`；T19 `zipper_closed`；T20/T25/T27 `stacked`；T24 `sorted`；T09 `in_box`/`closed`。

### H.2 信念更新

```text
h_t = GRU(h_{t−1}, [z_t, s_t])
b_t(k) = σ(W_k [z_t, s_t, h_t] + c_k)
```

- 时序平滑：2 帧一致才翻转；否则保持。
- 温度缩放/先验校正：在验证集上校准，避免过度自信。
- 不可观测时保持 belief，不强行翻转（遮挡/透明/人手）。
- `progress = Σ_k w_k b_t(k)`；但修复决策用“最低成本未完成/被撤销谓词”，不是简单看总分。

### H.3 进入 MPC 代价

```text
C_state(A) = − Σ_k w_k [b̂_{t+H}(k) − b_t(k)]_+
             + λ_u Σ_k w_k [b_t(k) − b̂_{t+H}(k)]_+
```

- 第一项奖励进度；第二项惩罚撤销。
- `w_k`：最终谓词权重更高（如 `folded` > `fold_1`）。
- 若候选 chunk 让某个已完成谓词的概率下降超过阈值 `θ_undo`，`J` 直接加罚；不选它。
- 若所有候选都导致回退，选“回退最少 + 安全”的，并触发修复提示。

### H.4 撤销增广

| 类型 | 做法 | 对应官方干扰 |
|---|---|---|
| 反向播放 | 成功 episode 最后 2–5s 倒放 | T16 翻开毛巾、T19 拉开拉链、T14 拧回盖子 |
| 物体移除 | 把已完成子目标的物体移走/放回起点 | T12 拿走锁、T24 放回传送带、T27 拿走第二个碗 |
| 状态翻转 | 拉链拉开、盖子拧回、笔盒合上再打开 | T14/T16/T17/T19 |
| 人手遮挡 | 合成手 mask 或真实人手视频 | T05/T10/T26 |
| 底座/架子移动 | 平移相机/场景 | T08/T11/T21/T25 |

- 标签：`progress_delta ∈ {−1,0,+1}`；训练 predicate head 的差分头或对比损失。
- 正向片段 vs 反向片段对比：让模型学会“这不是新子目标，而是回退”。

### H.5 修复策略

```text
if b_t(k) drops below θ_undo and was > θ_done:
    mark subgoal k as undone
    repair = argmin cost(restore k)
    prompt: "redo <subgoal k>"
    recheck b(k); if still false, retry ≤2 / safe stop
if object_missing(part):
    re-scan (head + wrist)
    if not found: safe stop, log; do not hallucinate
```

- 定向修复优先于全程重跑：180s 预算下重跑通常不够。
- 修复顺序：先修被撤销的子目标；若后续依赖被破坏，回退到最早受影响的谓词。
- 与 Q-MPC 结合：修复提示进入语言/代价；候选 chunk 若继续原计划，`C_state` 会罚它。

### H.6 评测

- 官方备注脚本化：按 `human_1/human_4` 在真机/仿真执行；每任务 10 trials。
- 合成 undo：离线测 predicate head 的 AUC、检测延迟、误报。
- 指标：undo detection rate、false alarm rate、repair success、time-to-recover、full success under disturbance。
- 消融：单调进度头 vs RPSM；无 part 状态 vs 有；无修复 vs 有；无 MPC 代价 vs 有。

### H.7 风险

| 风险 | 缓解 |
|---|---|
| 谓词太细，标注/观测困难 | 先用 8–12 个通用谓词；任务特定只做映射 |
| 透明/反光/遮挡 | 多视角 + 腕部 + 置信度；保持 belief |
| 人手遮挡 | 等待/降速；安全优先 |
| 撤销误报 | 时序平滑 + 滞回 + 只在低风险时暂停 |
| 规则不允许主动暂停 | 先做被动检测 + 短停；不长时间等待 |

## I. SPA-VLA 2.0：无标定相对部件 token

### I.1 动机

32 个任务几乎都是部件级交互：杯把、盘沿、插头 prong、插孔、拉链头、瓶盖、钥匙、毛巾角、碗沿、耳机、手机、便签钉、注射器。物体级 3D 位姿不够；部件表示同时解决：

- **未见物品**：换颜色/形状/材质，部件语义仍在；
- **人为干扰**：部件被移动/遮挡后可重新检测；
- **进度验证**：谓词作用在部件状态上；
- **语言 grounding**：handle/rim/prong/zipper/cap 直接对应部件。

但推理 API 没有深度/内参/外参，所以部件 3D 必须是**相对/学习 2.5D**。

### I.2 架构

```text
4 views + proprio + language
        │
        ▼
VLM backbone（WLA-1.0 / GigaBrain-0.7 / 其他允许的底座）
        │
        ├─ 16 part queries（cross-attend 到 4 视图 token）
        │     ├─ existence / affordance（grasp/insert/hang/pull/push/rotate/fold/pour/place/open/close）
        │     ├─ 2D mask + centroid（每视图；soft-argmax）
        │     ├─ relative depth/scale（腕部相对；学习头）
        │     └─ descriptor（跨帧/跨视角跟踪）
        │
        ├─ language tokens ──► part-language contrastive
        │
        ▼
action expert（cross-attend 到 part tokens + language + proprio）
        │
        ▼
action chunk（EE 或 joint + grippers + pivot）
```

关键点：

- part queries 共享，不是每任务一组；**不喂 task id**。
- `K=16` 覆盖大多数任务（最多同时 4–6 个相关部件）；Hungarian matching 对齐教师。
- mask 头按需输出；centroid/relative-depth 始终输出，接触伺服和记忆主要用它们。
- **不做绝对 base-frame 3D**：头部视角给 bearing/scale，腕部给相对位姿；需要 3D 时用学习头/立体匹配，不依赖标定。
- 如果底座提供 stereo，可学一个轻量 cost volume/disparity head；但训练目标来自数据集的离线深度/伪深度，推理不读 `camera_params`。

### I.3 教师管线（离线）

1. **文本提示**：每任务 3–8 个部件短语（`cup handle`、`plate rim`、`plug prong`、`socket slot`、`zipper pull`、`bottle cap`、`key`、`towel corner`、`bowl rim`、`earphone`、`phone`、`pin`、`syringe plunger`）。
2. **分割**：SAM3（文本/概念提示）出 2D mask；PartSAM 出 3D part；GroundingDINO 出 box 兜底。
3. **多视角关联**：把 3D centroid 投影到其他视角，检查 mask/深度一致性；小部件优先腕部。
4. **时序跟踪**：SAM3 video 或轻量 tracker；光流/一致性检查；低置信帧丢弃。
5. **质量控制**：mask 面积、深度有效像素、重投影误差、时序 IoU；低置信帧不监督；人工标注 1–2k 帧做验证。
6. **标签预算**：每任务 100–200 episodes 的关键帧（每 5 帧取 1），约 10–30 万帧；8 卡 2–4 天。

### I.4 学生损失

```text
L = L_action
  + λ_mask · L_mask          # BCE + Dice，仅高置信帧
  + λ_cent · L_cent          # soft-argmax centroid L1
  + λ_aff · L_aff            # affordance CE（Hungarian matching）
  + λ_rel · L_rel            # 相对深度/尺度（离线深度蒸馏）
  + λ_temp · L_temp          # 跨帧/跨视角跟踪一致性
  + λ_lang · L_lang          # 语言-部件对比
```

- `L_action`：按底座选择 flow matching/diffusion/CE；不改动作头结构，只加 cross-attention。
- `L_rel`：只在有离线深度/双目伪深度的帧上；推理不依赖。
- `L_lang`：同任务部件 descriptor 与语言 embedding 拉近，与其他任务部件推远；hard negatives 用同任务其他部件。
- 不使用 task id；用 `tasks.parquet` 的 5 条复述；留一条做验证。

### I.5 运行时

- 每 `k=2` 个 chunk 算一次 part tokens；中间复用，用 proprio/光流更新 centroid。
- 置信度下降、遮挡、人手进入、接触阶段 → 立即重算。
- part tokens 的四个用途：接触目标、进度谓词、状态记忆、安全（human hand query）。
- 若 part head 不确定：回退到 VLA 隐式 attention；不切换模型。

### I.6 单模型合规

- 一个 checkpoint：backbone、part head、action head、predicate head、critic、predictor。
- 运行时不加载 SAM3/PartSAM；教师仅离线。
- 不按任务切换权重；不喂 task id。
- safety monitor 用规则/轻量 query，不引入第二个策略。

### I.7 消融

| 实验 | 变量 | 目的 |
|---|---|---|
| S0 | 原 VLA | 基线 |
| S1 | + part head（无语言对比） | 部件监督本身 |
| S2 | + language-part | 语言 grounding/未见物品 |
| S3 | + relative depth | 接触精度 |
| S4 | 推理时 oracle mask | 上限 |

| S7 | 无 task id vs 有 | 证明不靠任务 ID |

**指标**：full success（主）、step score（次）、unseen-object success、human-recovery success、mask IoU、centroid error、relative-depth error、p99。

### I.8 风险

- 透明/反光/小部件分割噪声；多视角 + 腕部 + 置信度 + 人工验证。
- part query 坍塌；Hungarian + diversity loss + 熵监控。
- 教师误差进动作头；oracle 上限 + 置信度门控。
- 相对深度不够准；优先用腕部相对位姿/伺服，不追求绝对 3D。
- 算力不足；LoRA/部分微调 + ASQ + 低分辨率。

### J.2 Endurance Governor

**架构**：

```text
N ports 8765..8765+N-1
   │
   ├─ per-session state（episode、belief、chunk cache；互不共享）
   ├─ request queue / dynamic batcher（按 deadline 聚合）
   ├─ one model server（Q-MPC；ASQ 量化）
   ├─ watchdog / health / metrics
   └─ safe fallback（hold/retreat/wait；不切换模型）
```

**延迟预算**：

```text
T_chunk = T_a / f_ctrl
target: p99_inference < 0.8 · T_chunk
```

- `T_a=8`、30fps → 267ms；`T_a=16` → 533ms。实际控制频率未核实，先按 30Hz，实测后改。
- Q-MPC 的 K 由预算决定；p99 超了先降 K，再降分辨率/early-exit，最后 hold/retreat。
- 记录 p50/p95/p99、jitter、超时率、每端口 QPS、K 的分布。

**降级阶梯**：

1. **Normal**：K 自适应（1–8），全量观测。
2. **High load**：K 上限降到 2–4；part tokens 每 2 chunk 更新；mask 头降频。
3. **Thermal/memory**：分辨率降一档；ASQ 更激进；early-exit 视觉层；动作头保精度。
4. **Critical**：hold/retreat/wait；记录；恢复后从 belief 继续；**不加载第二个模型**。

**语义续航**：

- Part-State Memory：descriptor、相对位置、last seen、confidence、谓词状态；TTL/置信度衰减。
- 遮挡：保持 belief；人离开后重检测；不把“看不见”当“消失”。
- 干扰：状态回退 → RPSM 修复；物体移除 → 重扫描/安全停止。
- 跨阶段：不重置记忆；只重置 episode 级状态。
- 指标：30s+ 遮挡重定位、干扰后恢复率、belief 漂移、false forget。

**Soak**：

- 4 小时、N 并发、固定脚本任务；成功率漂移 <5pp；显存/RSS 增长 <5%；热节流次数；崩溃/重启。
- 量化模型的 p99 可能更抖；单独记录 quantized vs fp16 的延迟分布。

### J.3 Task Portfolio Optimizer

- 每任务 Beta 后验；先验按难度（Easy `Beta(3,3)`、Medium `Beta(2,4)`、Hard `Beta(1.5,5)`）。
- `E[S] = (1/32) Σ E[p_i]`；`Var(S) = (1/32²) Σ Var(p_i)`；`P(S>S*)` 用 Monte Carlo。
- 新增 `Δp_i = p_i(Q-MPC) − p_i(K=1)`：在离线 LPL 上估计 Q-MPC 的每任务增益；优先把算力/标注投到 `Δp_i / cost_i` 高的任务。
- 先消灭 0% 任务（一个 0% 相对 30% 损失 0.94pp、相对 100% 损失 3.1pp），再攻 3–5 个短板。
- 步骤分只做 tie-breaker；不要为首点牺牲完整成功。
- LPL 协议：每任务 10 trials；5 类泛化各 2；离线/半离线/真机分层；Wilson/bootstrap CI。

### K.3 指标

- 主：full success（每任务/总体）、95% CI。
- 次：step score（tie-break）、检查点完成率、超时率、time-to-success。
- 泛化：位置/干扰物/背景/未见物品/人为干扰分桶成功率。
- 状态：undo detection、repair success、time-to-recover、false alarm。
- 感知：mask IoU、centroid error、relative-depth error、part tracking。
- MPC：oracle 选择上限、critic pairwise accuracy、K 分布、候选分歧。
- 量化：动作误差（mm/rad/gripper）、p50/p95/p99、权重/峰值显存、N 份并发。
- 部署：4h soak 漂移、热节流、崩溃恢复、动作离群率。
- 合规：模型 hash 不变、无 task id、许可证、红队。

### K.4 停止条件

1. **EE vs joint**：EE 比 joint 低 >5pp 或 EE 跟踪 p95 >10mm → 切 joint。
2. **ASQ**：W4 相对 fp16 在接触任务掉 >2pp → 退 W8 或只量化视觉。
3. **Q-MPC**：K=4 在 2× 延迟下提升 <1.5pp → 放弃 K>1，保留 K=1 + RPSM。
4. **oracle 上限**：oracle 选择相对 K=1 提升 <2pp → 候选空间无好解，转单候选质量。
5. **SPA-VLA**：oracle part 上限相对基线 <2pp → 停止扩大 part head。
6. **RPSM**：undo AUC <0.7 → 简化谓词/加数据，不继续复杂化。
7. **部署**：4h 漂移 >10pp → 先修部署，不继续加模型能力。
8. **规则**：若外部数据/模型被禁止，切到挑战数据 + 传统部件标签；若量化内核不允许，退回 PyTorch/FP8。
