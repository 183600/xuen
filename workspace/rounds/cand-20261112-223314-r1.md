# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 8 轮；本轮灵感：「预测性维护」×「小样本学习」）

> 第 61 轮构建了 ESEC：USR 统一语义表征、MEL 多模态具身大模型、DMS 多轮对话、SRT-Dual 语义-实时双流、PCE+++++ 六维预算。其核心贡献是让「场景→意图→约束→执行→证据」在共享语义空间中闭环。但**四个更深层的局限**在本轮暴露：
> 1. **安全是反应式的，不是预测式的**：EFGP 只在 `EV_exec.slip_detected`、`vibration > τ_vib`、`force_exceed` 已经发生后才触发澄清/协商。此时损伤可能已经造成；系统没有「健康状态」概念，无法回答「还剩多少时间会滑移/超力/失去接触」。
> 2. **零样本假设存在系统性残余偏差**：ZSSG 依赖 MEL 的零样本物理属性推断，但真实部署中材质、几何、传感器工况持续漂移；一旦 MEL 系统性低估摩擦，语义越自信、控制越危险。系统缺少「在岗、安全、少量交互」的校准机制。
> 3. **证据只用于对账，不用于寿命估计**：`EV_exec` 进入 USR 后只用于 `D⁺_sem` 与证书，**没有变成健康指标（HI）与剩余寿命（RUL）**。机器人不知道自己的接触、执行器、传感器、甚至语义模型何时会「坏」。
> 4. **维护没有预算与调度**：PCE+++++ 管理推理与对齐预算，但没有「探测/校准/停机维护」预算；也没有回答「何时该继续干、何时该停下来做一次小样本校准、何时该降额或叫人」。
>
> 本轮把「健康」提升为一等状态，把「小样本校准」从离线训练技巧变为**在线、安全、可预算的维护动作**。

## 0. 直觉与动机

**灵感 1（预测性维护 → 接触健康指数 CHI 与剩余寿命 RUL）**
直觉：工业设备不会等到轴承抱死才报警，而是用振动频谱、温度、电流纹波估计健康指数（Health Index, HI）与剩余使用寿命（Remaining Useful Life, RUL），在失效前安排维护。机械臂的「接触」同样是一个退化系统：微滑移先于宏观滑移，力跟踪误差先于力超限，接触面积漂移先于掉接触，执行器电流纹波先于力矩失效。关键洞见：把每次接触/每个实例/每个子系统视为一个**可退化资产**，从力/触觉/本体信号的时序特征估计 `h_t ∈ [0,1]^m`，用随机退化过程预测「距离失效还剩多久」，再把 RUL 的保守下界变成实时控制的**安全降额系数**。这样 EFGP 从「事后阈值」升级为「事前预后」。

**灵感 2（预测性维护 → 语义/模型健康的自维护 SHM）**
直觉：不仅机械接触会退化，**语义系统也会退化**：USR 投影误差 `e_proj` 缓慢上升、`C_sem` 缓慢下降、MEL 的 `U_epistemic` 漂移、传感器标定残差累积——这些都是「语义-控制漂移」的前兆。关键洞见：把第 61 轮的 `e_proj, C_sem, U_ep, ECE` 组合成**语义健康指数 SHI**，用同一套退化/RUL 机制预测「语义锚点还有多久会不可信」，从而在漂移造成事故前触发重校准或冻结。预测性维护因此不仅维护机器，也维护「模型」。

**灵感 3（小样本学习 → 元学习物理先验 MPP）**
直觉：新材质/新零件不可能总有大规模数据，但人类工程师摸两下就能估计「这个很滑」「这个很脆」。这种能力来自**先验 + 少量交互**。关键洞见：用元学习在多材质、多几何、多任务的仿真任务分布上学习一个**物理属性先验** `p_meta(φ; θ)`（φ = 摩擦、刚度、阻尼、脆性），部署时只需 1~5 次安全接触探测，就能得到后验 `p(φ | S_K)`，而不是从零拟合。零样本给出「先验均值」，小样本给出「后验收缩」——两者是同一贝叶斯体系的不同数据量极限。

**灵感 4（小样本学习 → 安全主动探测 SAP）**
直觉：小样本校准不能随便试错——在脆性物体上「试一下会不会滑」可能直接试坏。关键洞见：把探测本身当作**带安全约束的贝叶斯实验设计**：在可行探测集 `U_safe` 中选一个「信息增益最大且预测风险最低」的微探测（小幅法向压入、微切向扰动、短时脉冲），最大化 `I(φ; y_u | S)`，同时硬约束 `P(slip) ≤ δ_s`、`F ≤ F_max`、`E ≤ E_max`。信息不够时，宁可降额或叫人，也不做危险实验。

**灵感 5（预测性维护 × 小样本学习 → 预测触发的少样本维护闭环 PTFC/PFEC）**
直觉：维护不是周期性动作，而是**事件驱动**的：当健康指数下降或 RUL 低于阈值时，才触发「探测→后验更新→投影头校准→重新发证→继续执行」。关键洞见：小样本校准是「维护动作」的一种，维护动作有成本、有风险、有信息收益。把「何时维护、维护什么、用多少样本、是否值得」形式化为一个**带安全护栏的约束 MDP**，用一步 VOI（价值 of information）在「继续干 / 降额 / 探测校准 / 叫人 / 中止」之间选择。这样第 61 轮的语义闭环就升级为「会给自己做保养」的闭环。

**灵感 6（预算 → PCE++++++ 八维认知-语义-健康-维护预算）**
直觉：健康监测与维护探测都要消耗算力、能量、时间与人类注意力。关键洞见：在六维 `B_cog5` 上增加 `B_health`（监测频率、粒子数、RUL 视野、告警预算）与 `B_maint`（探测能量、探测次数、少样本更新次数、人类询问次数、回放 token）。任何一维耗尽都必须触发**预设的、单调更保守的降级**，而不是临时拍脑袋。

## 1. 形式化定义（增量：定义 173–186）

**定义 173（接触-系统健康状态 CHS）** 对每个接触实例 `i` 与子系统 `s`，健康状态
```
h_t = (h_slip, h_vib, h_force, h_contact, h_actuator, h_sensor) ∈ [0,1]^6
```
由观测窗口 `z_t` 经校准映射得到。`h_j = 1` 表示全新/无退化，`h_j = 0` 表示失效阈值。为避免「平均掩盖最坏维度」，定义**健康指数**
```
HI_t = min_j h_{j,t}          # 最坏维度优先，安全保守
```
观测特征至少包括：
- 滑移利用率 `s_slip = |f_t| / (μ̂·N)`、微滑移速度 `v_micro`、触觉剪切导数；
- 高频振动能量占比与谱熵（微滑移/颤振前兆）；
- 力跟踪误差 `|f - f_ref| / f_ref` 与超调；
- 接触面积/质心漂移与接触丢失指示；
- 执行器电流纹波、力矩方差、温度；
- 传感器标定残差与零漂。
校准映射采用单调校准器（如保序回归 + logistic），并做在线更新；`h_j` 对特征单调不增，保证「信号越坏，健康越低」。

**定义 174（随机退化与剩余寿命 RUL）** 对每个健康维度 `j`，用带漂移的 Wiener 过程建模
```
h_j(t) = h_j(0) - μ_j t + σ_j W_t,   μ_j, σ_j > 0
T_j = inf{ t ≥ 0 : h_j(t) ≤ 0 }
```
则 `T_j` 服从逆高斯分布 `IG(h_j(0)/μ_j, h_j(0)^2/σ_j^2)`，其生存函数
```
S_j(t) = Φ((h_j(0) - μ_j t)/(σ_j√t))
        - exp(2μ_j h_j(0)/σ_j^2) · Φ((-h_j(0) - μ_j t)/(σ_j√t))
```
系统剩余寿命取最坏维度：`T = min_j T_j`，保守下界
```
r_α = inf{ t : P(T > t) ≤ 1 - α }      # 例如 α = 0.9，取 10% 分位
```
为防模型误设，维护一个**无分布 conformal 下界** `r_α^conf`：在离线校准轨迹上计算非一致性分数，取 `α` 分位；运行时
```
r_α^safe = min(r_α^model, r_α^conf)
```
若退化非 Wiener（如 gamma 磨损、阶段性突变），由粒子滤波/换模型检测器切换，但安全下界始终取保守值。

**定义 175（语义健康指数 SHI）** 语义系统健康
```
SHI_t = exp( - ( λ1·e_proj/ε_proj + λ2·D⁺_sem/τ_sem
               + λ3·U_ep/τ_u + λ4·ECE_drift/τ_ece ) ) ∈ [0,1]
```
其中 `e_proj` 为投影误差、`D⁺_sem` 为跨模态语义分歧、`U_ep` 为 MEL 认知不确定性、`ECE_drift` 为在线校准误差漂移。`SHI` 越低越不可信。对 `1 - SHI` 套用定义 174 的退化模型，得到「语义锚点剩余可信寿命」`r_sem`。当 `r_sem` 低于阈值时，优先重校准投影头或冻结语义先验，而不是继续让大模型主导控制。

**定义 176（元学习物理先验 MPP）** 元数据集由任务 `τ = (材质, 几何, 任务)` 组成。学习先验 `p_meta(φ; θ)` 与适配器 `A_ψ`：
```
min_{θ,ψ}  E_τ [ E_{S ⊂ D_τ, |S|=K} [
    -log p(y_q | x_q, S; θ, ψ)
    + β · KL( q_ψ(φ | S) ‖ p_meta(φ; θ) )
] ]
```
其中支持集 `S = {(u_k, y_k)}_{k=1..K}` 为安全探测-响应对，`y_k` 可为接触力/位移/滑移起始等可观测量。部署时后验
```
p(φ | S_K) ∝ p_meta(φ; θ) · Π_{k=1..K} p(y_k | φ, u_k)
```
预测 `p(y | x, S_K) = ∫ p(y | x, φ) p(φ | S_K) dφ`。零样本即 `K = 0`；小样本只做后验收缩，不重训整个大模型。

**定义 177（安全主动探测 SAP）** 探测动作 `u = (方向, 法向力幅值, 时长, 波形)`。可行集
```
U_safe(φ, S) = { u : F_pred(u, φ) ≤ (1-ε_F)·F_max(φ),
                     P(slip | u, φ, S) ≤ δ_s,
                     E(u) ≤ E_max,  reversible(u) = true }
```
在 `U_safe` 内最大化期望信息增益
```
IG(u) = H[y_u | S] - E_{φ ~ p(φ|S)}[ H[y_u | φ, u] ]
u* = argmax_{u ∈ U_safe} IG(u)
```
线性高斯情形有闭式
```
IG(u) = 0.5 · log det( I + Σ_post · C_u^T · R^{-1} · C_u )
```
若 `max IG(u) < ε_eig` 或 `U_safe = ∅`，则不做探测，转入降额/人工升级。`reversible(u)` 要求探测不产生不可逆位移或损伤（纯法向微压、无宏观切向拖拽）。

**定义 178（少样本贝叶斯物理校准 FBC）** 给定 `S_K` 与后验 `p(φ|S_K)`：
1. 更新物理先验：`φ̂ = E[φ | S_K]`，`Σ_φ = Cov[φ | S_K]`；
2. 更新锚点中的 `phys_prior` 与不确定性；
3. 对投影头 `Π` 做**受约束的低秩适配**：
```
ℒ_fsl = -Σ_{(u,y)∈S_K} log p(y | φ, u)
        + λ · ‖Π_new - Π_old‖²_F
        + μ · KL( q(φ|S_K) ‖ p_meta(φ) )
```
只允许更新最后一层或 LoRA 适配器，并把更新投影回安全参数集（见定义 181 的单调降额约束），防止小样本过拟合把阻抗推到危险区。适配后用定义 184 的证书复验；不通过则回滚到旧投影头。

**定义 179（维护动作与维护 MDP MMP）** 维护决策是一个带安全护栏的约束 MDP：
```
M = (S_m, A_m, P_m, R_m, C_safe)
S_m = (h_t, p(φ|S), anchor, budget_left, task_phase)
A_m = { continue, derate(δ), probe(u), recalibrate, request_human, abort }
R_m = task_progress + α_h·Δhealth - β_c·cost - β_r·risk
```
安全护栏是硬约束：若 `r_α^safe < τ_hard`，则
```
A_safe = { derate, request_human, abort }   # 禁止 continue 与 probe
```
决策用一步 VOI：
```
VOI(a) = E_{s'~P_m(·|s,a)}[ U(s') - U(s) ] - cost(a)
a* = argmax_{a ∈ A_safe} VOI(a),  仅当 VOI(a*) > 0 才执行维护
```
训练时可离线学 RL 策略，但规则护栏始终优先（与第 61 轮 DMS 的规则优先原则一致）。

**定义 180（预测触发维护策略 PTMP）** 触发条件（任一满足且预算允许）：
```
T1: r_α^safe < τ_maint                 # 寿命将尽
T2: dh_j/dt < -κ_j 持续 N 帧           # 快速退化
T3: e_proj > ε_proj 或 SHI < τ_shi     # 语义健康恶化
T4: H[p(φ|S)] > τ_H 且 task_risk 高     # 后验仍不确定
T5: 维护后复验失败                      # 校准无效
```
优先级：`安全 > 校准 > 吞吐`。每个触发条件都有对应的最小动作集（如 T1→derate 或 probe；T3→recalibrate；T5→request_human）。

**定义 181（健康感知锚点与安全降额 HAD）** 锚点扩展为
```
HealthAnchor = (scene_emb, intent_emb, phys_prior, U_mel,
                h_vec, r_α^safe, δ_h, version, timestamp, checksum)
```
降额系数
```
δ_h = clip( (r_α^safe - τ_min) / (τ_derate - τ_min), δ_min, 1 )
若 r_α^safe ≤ τ_min：δ_h = δ_min 且强制 abort/request_human
```
实时流投影：
```
K_p' = δ_h · K_p,    K_d' = K_d / max(δ_h, ε),    F_max' = δ_h · F_max
```
**单调保守性引理**：若 `δ1 ≤ δ2`，则 `δ1` 对应的可行阻抗/力集合是 `δ2` 对应集合的子集；即健康越差，允许的控制集合只会收缩、不会扩张。这样实时流只需消费一个标量 `δ_h`，无需理解健康模型的内部细节。

**定义 182（预测性语义-实时-健康三流 P-SRT）** 在第 61 轮双流上增加健康流：
- **实时流** `f_rt ≈ 1-10 kHz`：读 `HealthAnchor`，应用 `δ_h`，`EEIS.compile`，`ERTC.dispatch`；
- **语义流** `f_sem ≈ 10-100 Hz`：MEL + DMS + USR，产生语义锚点；
- **健康流** `f_h ≈ 1-10 Hz`：消费 `EV_exec` 与锚点，更新 `h_t`、`r_α^safe`、`δ_h`、`SHI`，写 `HealthAnchor`。
三流通过版本号单调的共享锚点同步。健康流超时 `> τ_h` 时，实时流对上一 `δ_h` 再乘 `γ_stale < 1`（额外保守），绝不阻塞实时环。健康流只做低频预后，不进入 1 kHz 路径。

**定义 183（八维认知-语义-健康-维护预算 PCE++++++）**
```
B_cog8 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_health, B_maint)
B_health = (Monitor_freq, Particle_N, RUL_horizon, Alarm_budget)
B_maint  = (Probe_energy, Probe_count, FSL_iters, Human_queries, Replay_tokens)
```
成本
```
cost_cog8 = cost_cog5
          + λ_h · ( Monitor_freq/B_health.freq + Particle_N/B_health.N
                    + RUL_horizon/B_health.horizon + Alarms/Alarm_budget )
          + λ_m · ( Probe_energy/E_probe + Probe_count/N_probe
                    + FSL_iters/I_fsl + Human_queries/Q_human )
```
降级（必须单调更保守）：
- `B_health` 低 → 降低监测频率、粒子数减半、RUL 视野缩短，改用 EWMA/风险率上界；
- `B_health` 耗尽 → 冻结 RUL，仅保留最坏维度阈值告警与固定降额；
- `B_maint` 低 → 禁止探测，只允许降额/叫人；
- `B_maint` 耗尽 → 冻结小样本适配，`δ_h` 取更保守固定值；安全动作永不耗尽。

**定义 184（健康-语义-执行联合证书 J_health）**
```
J_health = ( J_sem_exec,
             h_vec, r_α^safe, SHI,
             maintenance_trace,        # 触发条件、动作、时间戳
             probe_log,                # 探测动作、安全余量、信息增益
             fsl_posterior,            # φ̂, Σ_φ, 校准 ECE
             derate_hash )             # 降额函数的可复现哈希
```
验证：
```
Valid(J_health) ⇔ Valid(J_sem_exec)
                  ∧ HI ≥ h_safe
                  ∧ (r_α^safe ≥ τ_derate ∨ δ_h 已按定义 181 应用)
                  ∧ 所有 probe ∈ U_safe 且无安全违规
                  ∧ ECE(φ posterior) ≤ τ_ece
                  ∧ 版本号单调、无撕裂读
```

**定义 185（少样本元经验回放 MER）** 维护缓冲区
```
M_exp = { (τ, S_K, φ̂, Σ_φ, outcome, safety_margin, δ_h) }
```
按「稀有材质簇 × 接近失效 × 高信息增益」优先回放，用于离线更新 MPP 先验与校准器；在线只读不写大模型参数，避免小样本灾难性遗忘。回放受 `B_maint.Replay_tokens` 约束。

**定义 186（预测性少样本进化闭环 PFEC）** 闭环算子
```
PFEC(M, obs, task):
  # 实时层：执行并产出证据
  HealthAnchor ← M.anchor
  K_safe ← EEIS.compile(..., K_prior ⊙ δ_h, φ_phys)
  EV_exec ← ERTC.execute(K_safe, obs)

  # 健康层：预后
  M.h ← CHS.update(EV_exec, M.h)
  M.r ← RUL.predict(M.h, SHI)
  M.δ ← HAD(M.r)
  M.anchor ← commit_health_anchor(M.anchor, M.h, M.r, M.δ)

  # 语义层：触发维护
  if PTMP.trigger(M):
      a ← MMP.plan(M)                       # 护栏内选动作
      if a == probe:
          S_K ← SAP.select(M.posterior, M.δ)
          M.φ, M.Σ ← FBC.update(S_K)
          M.anchor ← commit_prior(M.anchor, M.φ, M.Σ)
      elif a in {derate, recalibrate, request_human, abort}:
          M ← MMP.apply(a)
```

```python
class ContactHealthEstimator:
    def __init__(self, dims=6, n_particles=256, alpha=0.9):
        self.dims = dims
        self.n = n_particles
        self.alpha = alpha
        self.calibrators = [MonotoneCalibrator() for _ in range(dims)]
        self.particles = np.ones((n_particles, dims))
        self.weights = np.ones(n_particles) / n_particles
        self.beta = 0.98  # 退化漂移的慢变先验

    def features(self, ev_exec, window=0.2):
        return {
            'slip': ev_exec.tangential_force / (ev_exec.friction_est * ev_exec.normal_force + 1e-6),
            'micro_slip': ev_exec.micro_slip_speed,
            'vib': high_freq_energy_ratio(ev_exec.tactile, window),
            'spectral_entropy': spectral_entropy(ev_exec.tactile, window),
            'force_err': abs(ev_exec.force - ev_exec.force_ref) / (abs(ev_exec.force_ref) + 1e-6),
            'torque_ripple': ev_exec.actuator_current_var,
            'contact_drift': ev_exec.contact_centroid_drift,
            'calib_residual': ev_exec.sensor_calib_residual,
        }

    def update(self, ev_exec):
        z = self.features(ev_exec)
        # 1) 观测似然：健康越低，坏特征越可能出现
        for j in range(self.dims):
            h_pred = self.particles[:, j] * self.beta
            z_j = self.calibrators[j].severity(z)      # 统一到 [0,1]，越大越坏
            lik = np.exp(-((z_j - (1 - h_pred)) ** 2) / (2 * 0.05 ** 2))
            self.weights *= lik + 1e-12
            self.particles[:, j] = np.clip(h_pred, 0, 1)
        self.weights /= self.weights.sum()
        # 2) 重采样（低方差）
        if 1 / np.sum(self.weights ** 2) < self.n / 2:
            idx = systematic_resample(self.weights)
            self.particles = self.particles[idx]
            self.weights = np.ones(self.n) / self.n
        # 3) 健康指数
        h_mean = np.average(self.particles, axis=0, weights=self.weights)
        HI = float(np.min(h_mean))
        return h_mean, HI

    def estimate_drift(self, history):
        # 用最近 window 估计每维退化速率 dh/dt（最小二乘/卡尔曼）
        return np.array([fit_slope(history[:, j]) for j in range(self.dims)])


class RULPredictor:
    def __init__(self, alpha=0.9):
        self.alpha = alpha
        self.conformal_scores = []  # 离线校准残差

    def wiener_ig_quantile(self, h0, mu, sigma, alpha):
        # 逆高斯 CDF 反解：P(T <= t) = alpha 的 t
        return inverse_gaussian_quantile(h0 / max(mu, 1e-9),
                                         h0 ** 2 / max(sigma ** 2, 1e-9),
                                         alpha)

        # 无分布下界：用离线校准的 (真实 RUL - 模型 RUL) 分位数修正
        q = np.quantile(self.conformal_scores, 1 - alpha) if self.conformal_scores else 0.0
        return max(0.0, self.wiener_ig_quantile(h0, mu, sigma, alpha) - q)

    def predict(self, h_vec, h_sem, dt=0.1):
```

```python
class MetaPhysicalPrior(nn.Module):
    def __init__(self, phi_dim=4, hidden=128):
        super().__init__()
        self.phi_dim = phi_dim
        # 学习先验均值与对角/低秩协方差（可换成 normalizing flow）
        self.prior_mean = nn.Parameter(torch.zeros(phi_dim))
        self.prior_logstd = nn.Parameter(torch.zeros(phi_dim))
        # 适配器：支持集统计 -> 后验自然参数
        self.adapter = nn.Sequential(
            nn.Linear(phi_dim * 2 + 8, hidden), nn.GELU(),
            nn.Linear(hidden, phi_dim * 2)
        )

    def prior(self):
        return torch.distributions.Normal(self.prior_mean,
                                          self.prior_logstd.exp())

    def adapt(self, support):
        # support: [(u_k, y_k)], K <= 5
        stats = encode_support_stats(support)      # 均值/方差/探测参数
        delta = self.adapter(torch.cat(stats, dim=-1))
        post_mean = self.prior_mean + delta[..., :self.phi_dim]
        post_logstd = self.prior_logstd + delta[..., self.phi_dim:]
        return torch.distributions.Normal(post_mean, post_logstd.exp())

    def meta_train_step(self, tasks, K=5, beta=0.1):
        loss = 0.0
        for tau in tasks:
            S, Q = sample_support_query(tau, K)
            q = self.adapt(S)
            prior = self.prior()
            nll = -q.log_prob(tau.phi).mean()
            kl = torch.distributions.kl_divergence(q, prior).mean()
            # 查询集预测（用后验均值近似）
            pred = tau.g(q.mean)
            loss = loss + mse(pred, Q.y) + beta * kl + 0.1 * nll
        return loss / len(tasks)
```

### IP-185 SAP（安全主动探测）

```python
class SafeActiveProber:
    def __init__(self, delta_slip=0.01, eps_force=0.1, e_max=0.5, eps_eig=1e-3):
        self.delta_slip = delta_slip
        self.eps_force = eps_force
        self.e_max = e_max
        self.eps_eig = eps_eig

    def feasible(self, u, post, safety_model):
        phi = post.mean
        F = safety_model.pred_force(u, phi)
        p_slip = safety_model.pred_slip(u, phi, post.std)
        return (F <= (1 - self.eps_force) * safety_model.F_max(phi)
                and p_slip <= self.delta_slip
                and safety_model.energy(u) <= self.e_max
                and safety_model.reversible(u))

    def expected_info_gain(self, u, post, obs_model):
        # 线性高斯闭式：0.5 log det(I + Sigma C^T R^-1 C)
        C = obs_model.jacobian(u, post.mean)
        Sigma = post.variance()
        R = obs_model.noise_cov(u)
        M = np.eye(len(post.mean)) + Sigma @ C.T @ np.linalg.inv(R) @ C
        return 0.5 * np.linalg.slogdet(M)[1]

    def select(self, post, safety_model, obs_model, candidates):
        best_u, best_ig = None, -np.inf
        for u in candidates:
            if not self.feasible(u, post, safety_model):
                continue
            ig = self.expected_info_gain(u, post, obs_model)
            # 风险调整：信息增益除以预测风险与能量
            score = ig - 0.1 * safety_model.pred_slip(u, post.mean) \
                       - 0.05 * safety_model.energy(u)
            if score > best_ig:
                best_u, best_ig = u, score
        if best_ig < self.eps_eig:
            return None   # 宁可降额/叫人，不做无信息或危险探测
        return best_u
```

```python
class FewShotCalibrator:
    def __init__(self, projector, meta_prior, safety_set, lr=1e-3):
        self.projector = projector
        self.meta_prior = meta_prior
        self.safety_set = safety_set
        self.lr = lr

        return q

    def update_projector(self, support, q, steps=20):
        old = deepcopy(self.projector.state_dict())
        opt = torch.optim.Adam(self.projector.parameters(), lr=self.lr)
        for _ in range(steps):
            # 低秩/最后一层参数才允许更新
            loss = -log_likelihood(support, q).mean()
            loss = loss + 1e-3 * param_distance(self.projector, old)
```

```python
class MaintenancePlanner:
    def __init__(self, tau_hard=2.0, tau_derate=10.0, tau_maint=20.0):
        self.tau_hard = tau_hard
        self.tau_derate = tau_derate
        self.tau_maint = tau_maint

    def safe_actions(self, r_alpha, budget):
        if r_alpha < self.tau_hard:
            return ['derate', 'request_human', 'abort']   # 硬护栏
        acts = ['continue']
        if r_alpha < self.tau_maint:
            acts += ['derate', 'recalibrate']
            if budget.probe_allowed():
                acts += ['probe']
        if budget.human_allowed():
            acts += ['request_human']
        return acts

    def one_step_voi(self, s, a, model):
        # U = 任务进度 + 健康效用 - 风险；用模型预测下一步
        s_next = model.predict(s, a)
        return (model.utility(s_next) - model.utility(s)) - model.cost(a)

    def plan(self, s, budget, model):
        allowed = self.safe_actions(s.r_alpha, budget)
        # 安全动作优先；probe 仅在信息增益足够且可逆时考虑
        best = max(allowed, key=lambda a: self.one_step_voi(s, a, model))
        if best in ('probe', 'recalibrate') and not budget.maint_available():
            best = 'derate'
        return best
```

**正确性定理（PFEC-Complete）**：
在 A61–A70 基础上增加：
- **(A71)** 健康观测模型经校准，HI 对失效前兆的 AUROC ≥ 0.9；
- **(A72)** 退化过程属于 Wiener/gamma 族或可由粒子滤波跟踪，conformal 下界覆盖真实 RUL 的概率 ≥ 1-α；
- **(A73)** 元先验对部署材质分布有覆盖，且支持集探测可辨识 φ（Fisher 信息非奇异）；
- **(A74)** 安全探测模型是保守的：真实滑移概率 ≤ 预测值 + ε_s；
- **(A75)** 维护护栏只允许 `derate/request_human/abort`，当 `r_α^safe < τ_hard`；
- **(A76)** HAD 满足单调保守性：`δ1 ≤ δ2 ⇒ 可行控制集(δ1) ⊆ 可行控制集(δ2)`；
- **(A77)** 三流锚点 CAS 原子写、64 位单调版本号、健康流超时回退；
- **(A78)** PCE++++++ 预算单调消耗且降级策略安全不退化。

则：
1. **预后安全**：若 `r_α^safe < τ_derate` 且 HAD 已应用，则在 `r_α^safe` 时间内发生失效的概率 ≤ α + δ_model；若 `r_α^safe < τ_hard`，系统只执行安全动作。
2. **小样本收缩**：在 A73 的局部可辨识条件下，`E‖φ̂_K - φ‖² ≤ Tr((Σ_0^{-1} + K·C^T R^{-1} C)^{-1}) + o(1/K)`；因此 K 增大时误差单调下降，且 K≥1 的期望误差不超过零样本误差（先验均值）在凸风险下的上界。
3. **维护安全**：带护栏的 MMP 不会产生违反 ERTC 的约束；对近视维护 MDP，一步 VOI 策略在 `A_safe` 内最优。
4. **实时性**：实时流仍为 O(1)，健康流异步且低频；健康信息过期时只乘额外保守因子，不阻塞。
5. **预算安全**：任一维预算耗尽触发预设的单调保守降级，安全动作不参与预算竞争。

```python
class ContactHealthEstimator:
    def __init__(self, dims=6, n_particles=256):
        self.dims, self.n = dims, n_particles
        self.calibrators = [MonotoneCalibrator() for _ in range(dims)]
        self.particles = np.ones((n_particles, dims))
        self.weights = np.ones(n_particles) / n_particles
        self.beta = 0.98

    def update(self, ev_exec):
        z = health_features(ev_exec)
        for j in range(self.dims):
            h_pred = np.clip(self.particles[:, j] * self.beta, 0, 1)
            severity = self.calibrators[j].severity(z)
            self.weights *= np.exp(-((severity - (1 - h_pred)) ** 2) / 0.005) + 1e-12
            self.particles[:, j] = h_pred
        self.weights /= self.weights.sum()
        if 1 / np.sum(self.weights ** 2) < self.n / 2:
            idx = systematic_resample(self.weights)
            self.particles = self.particles[idx]
            self.weights = np.ones(self.n) / self.n
        h_mean = np.average(self.particles, axis=0, weights=self.weights)
        return h_mean, float(np.min(h_mean))


class RULPredictor:
    def __init__(self, alpha=0.9):
        self.alpha = alpha
        self.conformal_scores = []

    def predict(self, h_vec, shi):
        r = []
        for h0 in h_vec:
            if h0 <= 0:
                return 0.0
            mu, sigma = fit_wiener_from_recent(h0)
            r_model = inverse_gaussian_quantile(h0 / mu,
                                                 h0 ** 2 / sigma ** 2,
                                                 self.alpha)
            q = np.quantile(self.conformal_scores, 1 - self.alpha) \
                if self.conformal_scores else 0.0
            r_conf = max(0.0, r_model - q)
            r.append(min(r_model, r_conf))
        r.append(predict_semantic_rul(shi, self.alpha))
        return float(min(r))
```

```python
class MetaPhysicalPrior(nn.Module):
    def __init__(self, phi_dim=4, hidden=128):
        super().__init__()
        self.prior_mean = nn.Parameter(torch.zeros(phi_dim))
        self.prior_logstd = nn.Parameter(torch.zeros(phi_dim))
        self.adapter = nn.Sequential(
            nn.Linear(phi_dim * 2 + 8, hidden), nn.GELU(),
            nn.Linear(hidden, phi_dim * 2))

    def prior(self):
        return torch.distributions.Normal(self.prior_mean,
                                          self.prior_logstd.exp())

    def adapt(self, support):
        stats = encode_support_stats(support)
        d = self.adapter(stats)
        return torch.distributions.Normal(
            self.prior_mean + d[..., :4],
            (self.prior_logstd + d[..., 4:]).exp())

    def meta_train_step(self, tasks, K=5, beta=0.1):
        loss = 0.0
        for tau in tasks:
            S, Q = sample_support_query(tau, K)
            q, prior = self.adapt(S), self.prior()
            kl = torch.distributions.kl_divergence(q, prior).mean()
            loss = loss + mse(tau.g(q.mean), Q.y) + beta * kl
        return loss / len(tasks)
```

### IP-186 SAP（安全主动探测）

```python
class SafeActiveProber:
    def __init__(self, delta_slip=0.01, eps_force=0.1, e_max=0.5, eps_eig=1e-3):
        self.delta_slip, self.eps_force = delta_slip, eps_force
        self.e_max, self.eps_eig = e_max, eps_eig

    def feasible(self, u, post, safety):
        phi = post.mean
        return (safety.pred_force(u, phi) <= (1 - self.eps_force) * safety.F_max(phi)
                and safety.pred_slip(u, phi, post.std) <= self.delta_slip
                and safety.energy(u) <= self.e_max
                and safety.reversible(u))

    def info_gain(self, u, post, obs):
        C, S, R = obs.jacobian(u, post.mean), post.variance(), obs.noise_cov(u)
        M = np.eye(len(post.mean)) + S @ C.T @ np.linalg.inv(R) @ C
        return 0.5 * np.linalg.slogdet(M)[1]

    def select(self, post, safety, obs, candidates):
        best, best_score = None, -np.inf
        for u in candidates:
            if not self.feasible(u, post, safety):
                continue
            score = (self.info_gain(u, post, obs)
                     - 0.1 * safety.pred_slip(u, post.mean)
                     - 0.05 * safety.energy(u))
            if score > best_score:
                best, best_score = u, score
        return None if best_score < self.eps_eig else best
```

```python
class FewShotCalibrator:
    def __init__(self, projector, meta_prior, safety_set, lr=1e-3):
        self.projector, self.meta_prior = projector, meta_prior
        self.safety_set, self.lr = safety_set, lr

    def calibrate(self, support, steps=20):
        old = deepcopy(self.projector.state_dict())
        q = self.meta_prior.adapt(support)
        opt = torch.optim.Adam(self.projector.parameters(), lr=self.lr)
        for _ in range(steps):
            loss = (-log_likelihood(support, q).mean()
                    + 1e-3 * param_distance(self.projector, old)
                    + 0.05 * kl_divergence(q, self.meta_prior.prior()).mean())
            opt.zero_grad(); loss.backward(); opt.step()
            project_to_safe_set(self.projector, self.safety_set)
        if not verify_projector(self.projector, support):
            self.projector.load_state_dict(old)
            return None
        return q
```

```python
class MaintenancePlanner:

        self.tau_hard, self.tau_maint = tau_hard, tau_maint

    def safe_actions(self, r_alpha, budget):

            return ['derate', 'request_human', 'abort']
        acts = ['continue']
        if r_alpha < self.tau_maint:
            acts += ['derate', 'recalibrate']
            if budget.probe_allowed():
                acts += ['probe']
        if budget.human_allowed():
            acts += ['request_human']
        return acts

    def plan(self, s, budget, model):
        allowed = self.safe_actions(s.r_alpha, budget)
        a = max(allowed, key=lambda x: model.one_step_voi(s, x))
        if a in ('probe', 'recalibrate') and not budget.maint_available():
            a = 'derate'
        return a


class HealthAwareDerating:
    def __init__(self, tau_min=0.0, tau_derate=10.0, delta_min=0.2):
        self.tau_min, self.tau_derate = tau_min, tau_derate
        self.delta_min = delta_min

    def factor(self, r_alpha):
        if r_alpha <= self.tau_min:
            return self.delta_min, True
        d = (r_alpha - self.tau_min) / max(self.tau_derate - self.tau_min, 1e-6)
        return float(np.clip(d, self.delta_min, 1.0)), False

    def apply(self, K_prior, F_max, delta):
        out = dict(K_prior)
        out['K_p'] *= delta
        out['K_d'] /= max(delta, 1e-3)
        out['F_max'] = F_max * delta
        return out
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CHS | O(N_particle·m) / 10Hz | O(N_particle·m) | 单调校准；前兆 AUROC ≥ 0.9 |
| RUL | O(m) 分位 + O(N_cal) | O(N_cal) | 90% 区间覆盖 ≥ 85%；conformal 下界兜底 |
| MPP | 适配 O(K·d_φ) | ~10MB | K↑ 后验收缩；K≤5 误差显著低于零样本 |
| SAP | O(|U|·d_φ³) | O(d_φ²) | 探测 ∈ U_safe；无可行探测则升级 |
| FBC | 20 步低秩更新 ~10-50ms | 与投影头同阶 | 受约束适配；证书失败回滚 |
| MMP | O(|A_safe|) | O(1) | 护栏内动作不越过 ERTC 硬约束 |
| P-SRT | 实时 O(1)；健康 1-10Hz | ~10MB | 健康流超时→额外保守；实时不阻塞 |
| PCE++++++ | O(1) | O(1) | 任一维耗尽→单调更保守降级 |

**正确性定理（PFEC-Complete）**：在 A61–A70 上增加 A71–A78（见想法区定义 173–186）。则：
1. **预后安全**：`r_α^safe < τ_derate` 且 HAD 应用后，在 `r_α^safe` 内失效概率 ≤ α + δ_model；`r_α^safe < τ_hard` 时只允许安全动作。
2. **小样本收缩**：`E‖φ̂_K - φ‖² ≤ Tr((Σ_0^{-1} + K C^T R^{-1} C)^{-1}) + o(1/K)`；K 增大误差单调下降。
3. **维护安全**：带护栏 MMP 不产生违反 ERTC 的约束；近视维护 MDP 下一步 VOI 在 `A_safe` 内最优。
4. **实时性**：实时流 O(1)，健康流异步低频，过期只乘 `γ_stale`，不阻塞。
5. **预算安全**：任一维耗尽触发预设单调保守降级，安全动作不参与预算竞争。

## 5. 本轮最大风险

**一句话**：若健康指数与 RUL 模型系统性误设，叠加小样本后验在小支持集上的过度自信，系统可能在「一切正常」的自我报告中主动做了一次本不该做的探测或降额，造成**维护诱发失效**；必须以「CHS 在线校准 + conformal RUL 下界 + SAP 硬安全约束 + FBC 证书回滚 + HAD 单调保守 + 人工升级通道」构建预后安全护栏，确保「预测性维护」永不成为新的风险源。
