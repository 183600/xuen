# 第 16 轮（研究线累计；灵感循环第 2 轮）· HVP-TA-ZEST：人机协作原型验证 + 地形自适应信任门

> 检索/复核日期：**2026-11-03（UTC）**。赛事身份不变：宇树 **UniBot 世界挑战赛**（unibot.unitree.com），G1 + Dex1，32 项桌面任务，通才单模型赛道。**不推倒**第 10–15 轮；本轮在 ZEST-VLA 之上加两层：地形自适应归一化 + 人机协作原型验证。

## 0. 先给直觉：第 15 轮学会了不信任自己，但还没学会在不同地形上校准不信任，也没学会用人类验证来加速原型收敛

ZEST-VLA 用动作-观测残差 + conformal/CUSUM 做胜任力门控，实现了「执行不胜任时受控降级」。它留下两个未付费假设：

> A1. 残差尺度是地形不变的。  
> A2. 几何原语的成功率是地形无关的先验。  
> A3. 人类验证只在训练期有价值。

在桌面任务中，地形并非指户外坡面，而是工作面高度、物体支撑面倾斜、遮挡/反光导致的视觉-运动耦合变化。同一 `REACH→GRASP` 原语在低矮托盘和倾斜匣盒上，其几何残差基线和成功概率完全不同。若继续用全局 MAD 归一化，残差尺度漂移会让 conformal 阈值过松或过紧，假警报率随地形跳变。

更深的问题是 OOD-G 的盲区：ZEST 检测不了 VLA 和地图一起错。人类对「这个杯子到底是哪个」的判断是廉价而准确的稀疏信号；将其限制在原型验证阶段，可以在不违反单模型规则的前提下，为信任门提供地形条件化的校准。

一句话押注：

> 第 15 轮用残差一致性决定信不信 VLA；本轮用地形上下文自适应残差尺度，并用离线人机协作原型验证为几何原语提供地形条件化的成功先验，使信任门在不同地形上保持风险受控，同时把 OOD-G 的部分风险转化为可验证的原型覆盖率问题。

三个可验证创新点：

1. **地形自适应自监督**：用本地地形特征 τ_t 对残差归一化尺度做条件化，保持 conformal 边际保证在地形漂移下仍稳定；用 G13 验证假警报率地形不变性。
2. **人机协作原型验证**：离线收集极少量人类标注的原语可行性标签 V_h(τ)，用贝叶斯更新得到 g_prim(τ)；不在线学习、不更新 VLA；用 G14 验证 fallback 成功率提升。
3. **地形条件化降级**：VOI 调度引入 g_prim(τ) 和 τ-自适应胜任力 c_t(τ)；只有在地形验证通过的原语上才允许 FALLBACK；用 G15 验证安全与成本。

三个词怎么落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **人机协作** | 离线原型验证集 V_h：人类快速标注几何原语在不同地形/物体上的可行性；用于校准 g_prim(τ) 和目标残差先验 | 不在评测时引入在线人类；不做人类在环决策；不训练第二模型 |
| **原型验证** | 低成本物理原型模拟 + 人类快速核验，生成地形条件化的原语成功先验和残差尺度表；部署时只查表 | 不做大规模仿真训练；不做 test-time weight update |
| **地形适应** | 在线估计 τ_t = {平面法向、粗糙度、高度差、视差置信度}；用 τ_t 调整 MAD 尺度 f_k(τ) 和 g_prim(τ) | 不假设全球深度图；不假设腕部 IMU；不改变 WAVE-SERVO 控制律 |

## 1. 研究日志：为什么是这一层

### 1.1 第 15 轮留下的三个「未付费假设」

```text
B1. 残差尺度地形不变：σ_k 用滑动 MAD，隐含地形平稳。
B2. 原语成功率地形无关：g_prim 是标量先验。
B3. 人类知识只在训练期有用：原型验证未进入推理。
```

B1 导致在不同桌面高度/倾斜/反光下，conformal 阈值 q_α 的有效假警报率漂移。B2 导致 fallback 在不利地形上过度自信。B3 导致 OOD-G 只能放弃，而人类对 grounding 的稀疏判断本可缩小盲区。

### 1.2 三个新判断

1. **自监督残差的尺度是地形条件化的。** 残差本身无标签，但其分布随地形 τ 漂移。把归一化写成 z^k_b = r^k_b / (σ_k,b · f_k(τ_t))，其中 f_k 是从人类验证原型中统计得到的地形缩放因子，可在不学习权重的前提下恢复尺度不变性。
2. **原型验证是零样本泛化的杠杆。** 几何原语语法是手工的，但其成功率极度依赖地形。极少量人工核验 << 100 条/原语，即可把 g_prim 从保守常数提升为地形条件化的贝叶斯后验，显著降低 fallback 误用。
3. **人机协作可以是离线的、可证伪的。** 人类只在原型阶段提供可行性标签，不参与在线决策，符合单模型合规。收益是可测的：如果 g_prim(τ) 没有提升成功率/成本比，就剪枝该表。

### 1.3 与第 15 轮的关系

| 层 | 第 15 轮 ZEST-VLA | 第 16 轮 HVP-TA-ZEST |

| 不确定性 | c_t、OOD 模式 | + 地形 τ_t、原语可行性 g_prim(τ) |

| 人机 | 无 | 离线原型验证集 V_h，贝叶斯校准 |

| 安全 | WAVE-SERVO | 继承；新增地形前置条件检查 |
| 统计 | conformal/CUSUM | 继承；新增地形分层校准 |

**保留**：FACT-VLA、GEO-RESIDUAL、CHUNK-SERVO、WAVE-SERVO、VOI-MAP、ZEST 信任门、单模型合规。
**升级**：残差归一化从全局到地形条件化；fallback 从标量先验到 g_prim(τ)；OCC-G 盲区用人类原型覆盖率显式量化。
**剪枝**：不在线学习；不引入第二个策略网络；不做实时人类查询。

## 2. 机制草图

### 2.1 地形感知与自适应归一化

在线估计：

τ_t = { n_t, ρ_t, h_t, κ_t }

n_t：末端接近面法向均值；ρ_t：局部视差/光流置信度倒数；h_t：目标相对工作面高度；κ_t：图像梯度方差。

归一化：

σ_{k,b}(τ) = 1.4826·MAD_k + ε_k
f_k(τ) = exp( a_k·ρ_t + b_k·|n_t·z| + c_k·h_t )
z^k_b = r^k_b / (σ_{k,b}·f_k(τ))

a_k,b_k,c_k 从 V_h 中用线性回归拟合，无梯度训练。

### 2.2 人机协作原型验证

离线阶段：对每个原语 p ∈ {REACH,GRASP,...}，在代表性地形网格 T 上采样约 5–10 个构型，邀请人类快速判断可行/不可行，得到标签 y∈{0,1}。用 Beta 先验更新：

g_prim(τ) ~ Beta(α0 + Σ y_i·w_i(τ), β0 + Σ (1-y_i)·w_i(τ))

w_i(τ) = Kernel(τ,τ_i) 为高斯核权重。推理时查表插值，无在线学习。

### 2.3 信任门增强

保持 conformal/CUSUM 结构，但校准集按地形分桶：

q_α(τ) = Quantile_{1-α}( s | τ∈桶 )

若桶样本不足，回退到全局 q_α。门控逻辑不变，只是阈值更稳。

### 2.4 零样本降级增强

域检查扩展为地形前置条件：

dom_geo(u,τ) =语法匹配 ∧ 地图置信 ∧ g_prim(τ) > θ_g ∧ 地形安全

只有满足才允许 FALLBACK。

### 2.5 早期中止不变

仍在首个 5 步块后触发，最坏成本 1 块。

| 编号 | 假设 | 证伪条件 | 级别 |
|---|---|---|---|
| H1 | 地形自适应归一化使 ID 假警报率地形间差异 <3% | 差异 >7% | 主 |

## 4. 什么情况下放弃

- 地形估计误差 >30° 法向或 ρ_t噪声过大，导致 f_k(τ) 反而放大漂移 → 回退全局 MAD。
- 人机验证集收集成本 >预期且收益 <2pp → 砍掉 g_prim(τ)，只保留地形归一化。
- 地形分桶导致校准样本不足，q_α(τ) 方差过大 → 合并桶，回退全局。
- 原语可行性与残差无关，地形适应无增益 → 只保留原型验证的域检查。

## 5. 一句话押注

**地形会让自监督残差漂移，人类原型验证能用极少量标签把漂移校准成可查表项：HVP-TA-ZEST 用 τ-条件化归一化和 g_prim(τ) 让 ZEST 的信任门在不同桌面地形上保持风险受控，同时把 OOD-G 的盲区量化为原型覆盖率。**

## 6. 本轮最大的风险

**地形估计误差被放大**：若在线 τ_t 估计不准，f_k(τ) 会引入系统性偏差，使 conformal 阈值在某些地形上系统性过松，导致假阴性增加而信任门失效；这比全局归一化更危险，因为错误是结构性的且难以在线检测。

## 2. 符号与形式化

### 2.1 地形上下文

τ_t = (n_t, ρ_t, h_t, κ_t)

n_t ∈ S²：末端接近面法向均值  
ρ_t ≥0：视差/光流置信度倒数  
h_t：目标相对工作面高度  
κ_t：图像梯度方差

在线估计：n_t 由正运动学 + 地图平面拟合；ρ_t 由光流残差；h_t 由地图高度；κ_t 由 RGB 梯度。

### 2.2 τ-条件化归一化

滑动 MAD：σ_{k,b}=1.4826·MAD(r^k_{b-W+1:b})+ε_k

地形缩放：f_k(τ)=exp(a_k ρ_t + b_k |n_t·z| + c_k h_t)

归一化分数：z^k_b = r^k_b / (σ_{k,b} f_k(τ_t))

融合：s_b = Σ w_k z^k_b

系数 a_k,b_k,c_k 由离线线性回归拟合：min Σ (log σ*_k - log f_k(τ))^2，其中 σ*_k 为人类验证集上经验尺度。

### 2.3 人机原型验证

原语 p，离线验证集 V_h = {(τ_i, y_i)}，y_i∈{0,1} 为人类可行性标注。

先验 Beta(α0,β0)，后验：

g_prim(τ) = E[ θ | V_h ] ≈ Σ_i w_i(τ) y_i / Σ_i w_i(τ)  with 平滑

w_i(τ)=exp(-||τ-τ_i||² / 2γ²)

查表实现：预计算网格 T，离线推理后得到 g表。

### 2.4 地形条件化 conformal

将校准集按 τ 分桶 B_j。桶内分位数：

q_α(τ) = Quantile_{1-α}( s | τ∈B_j )，若 |B_j|<n_min 回退全局 q_α。

边际保证在每个桶内仍成立：Pr(s>q_α|τ∈B_j) ≤ α + O(1/√|B_j|)

### 2.5 调度增强

原 VOI 成功模型：

P_succ(SERVO) ≈ c_b b_max f(p+δ)

P_succ(FALLBACK) ≈ b_max g_prim(τ) f_geo(p)

门控硬约束保持不变：TRUST 允许 SERVO，FALLBACK 禁用 SERVO。

域检查增强：dom_geo(u,τ)=语法匹配 ∧ 地图置信 ∧ g_prim(τ)>θ_g ∧ 地形安全。

## 3. 算法

### 3.1 流程

1. 离线：收集 V_h，人类标注原语可行性；拟合 f_k(τ) 系数；构建 g表；按地形桶计算 q_α(τ)。
2. 在线每块：
   - 估计 τ_t
   - 计算残差 r^k_b，归一化得 s_b
   - e_b = 1[s_b > q_α(τ_t)]
   - CUSUM 更新 S_b
   - 若 S_b>h → FALLBACK 模式
   - VOI 在允许动作集上选最大 Δ/cost，其中 fallback 收益含 g_prim(τ)
3. 块结束记录 τ_t,s_b,模式。

def estimate_terrain(obs, M):

    kappa = image_gradient_variance(obs.rgb)

def normalized_score(r, scales, tau):

    return sum(w[k]*z[k] for k in r)

def g_primitive(p, tau):
    return lookup_g_table(p, tau)  # 线性插值

def select_action(state):

    allowed = gate_allowed(state.mode)

## 4. 性质与正确性

### 命题 1（τ-条件化尺度不变性）

若 f_k(τ) 精确等于残差尺度的地形漂移因子，则 z^k_b 分布与 τ 无关。

证明：r^k_b = σ_true(τ)·η，η 与 τ 独立。则 z = η·σ_true/(σ·f)。若 σ≈σ_true 且 f=σ_true/σ，则 z 与 τ 无关。

### 命题 2（桶内 conformal 保证）

在每个地形桶 B_j 内，若校准样本与测试样本可交换，则 Pr(s>q_α|B_j) ≤ α。

证明：标准 split conformal 在子群体上仍成立。

### 命题 3（门控安全）

HVP-TA-ZEST 的输出动作集是第 13/14/15 轮安全集的子集。

证明：门控只删除 SERVO，不新增执行通路；fallback 通过 WAVE-SERVO。

### 命题 4（原型校准单调性）

若增加人类验证样本，则 g_prim(τ) 的后验方差单调不增。

证明：Beta 后验方差随样本数单调递减。

**地形会让自监督残差漂移，人类原型验证提供极少量地形条件化校准：HVP-TA-ZEST 在保持 ZEST 风险受控的前提下，用 τ-条件化归一化和 g_prim(τ) 让信任门与 fallback 在不同桌面地形上稳定有效。**

## 8. 本轮最大风险

**地形估计误差被结构性放大**：若在线 τ_t 估计存在系统性偏差，τ-条件化归一化会把残差尺度校准到错误方向，导致 conformal 阈值在特定地形上系统性过松，信任门假阴性率上升，系统在不利地形上自信地执行错误动作，且该失效模式难以在线检测。
