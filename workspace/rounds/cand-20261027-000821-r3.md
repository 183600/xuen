# 想法区 · 新循环第 3 轮（承接 v9.0 ICF-PACT）：把外层 probe 变成 SAT 屏蔽的 Alpha-Beta 零窗口

**灵感词**：satisfiability solving / Alpha-Beta 剪枝 / branch and bound  
**起点**：v9.0 ICF-PACT 已经把「状态即部分证书」立住了：状态 $(L,U,s,m,\pi)$ 本身就是一张可审计的括号，$\pi$ 证明 $\mathrm{NO}(L-1)$，$(s,m)$ 证明 $C_{\max}=U$。它最后留下的最大风险是：**真正跑起来的是单叶特化，多叶 frontier 和割循环还停留在形式化；252 例的 gap 只有 0/1/5，`lower-first` 的一次 probe 闭合很可能只是这批语料 LP 下界太紧。** 本轮不急着把多叶 frontier 硬跑起来，而是先问一个更外层的问题：**每一次 probe 到底该问哪个 $h$？**

## 一、先看 v9.0 的外层在问什么

v9.0 的 `lower-first` 第一问固定是 $L$。它的直觉是：如果 LP 下界 $L$ 恰好等于 OPT，那么问 $L$ 会拿到调度并闭合；如果 $L=\mathrm{OPT}-1$，那么问 $L$ 会拿到 NO 并把 $L$ 抬到 OPT，也闭合。252 例上它确实至多一次 probe 闭合——但这恰恰说明**这批语料的 $U$ 已经等于 OPT，或者只差一层**。

可是从证书的角度看，问 $L$ 并不是唯一的选择，也不是最自然的选择。给定当前上界 $U$，真正能改变括号的「临界问题」只有一个：

> **是否存在长度不超过 $U-1$ 的调度？**

- 如果答案是 YES，我们拿到一个更短的调度，$U$ 严格下降；
- 如果答案是 NO，那么 $\mathrm{OPT}\ge U$，而 incumbent 已经给出 $\mathrm{OPT}\le U$，于是 $L=U$，算法直接最优闭合。

这正是 Alpha-Beta 里的**零窗口** $[U-1,U-1]$：一次 fail-high 降上界，一次 fail-low 直接结束。v9.0 的 `lower-first` 问的是 $L$，它其实是先做一个「beta 探测」，赌 $L$ 已经贴在 OPT 上；在 LP 紧的语料上这个赌很划算，但在大 gap 上它只是多花一次 NO probe。

## 二、第一次试错：把 SAT 的 UNSAT 当成证书

最直接的想法是：固定 $h$ 的调度判定可以编码成 SAT；如果 SAT 说 UNSAT，不就直接得到 $\mathrm{NO}(h)$ 了吗？这样连 LP 和 Farkas 都不需要。

这个想法被我否掉了，原因不是 SAT 不够快，而是**证书的信任基变了**。SAT 求解器的 UNSAT 结果要变成可独立检查的证书，需要 DRAT/LRAT 证明和 proof checker；而本项目的验收器只认 `verify`、`check_schedule`、`_domain` 这些已有检查器。把 SAT 的 UNSAT 直接写进 $\pi$，等于把整个证书系统建立在「相信求解器」上，和 v9.0 的「状态可独立审计」背道而驰。

所以本轮给 SAT 一个更窄、但更安全的角色：**它只决定问哪个窗口，不产生任何 NO 事实。**

## 三、第二次试错：SAT 只用来找 YES 调度

第二个自然想法是 v8t 已经试过的：SAT 只做 YES oracle，找到调度就降 $U$。这当然是 sound 的——调度会被 `check_schedule` 重放。但它没有利用 SAT 的 UNSAT 信息，而本轮 29 个 gap 例上真正贵的是 NO 侧：31 次 SAT 调用里只有 2 次返回 YES，29 次都是 UNSAT。如果 SAT 只在 YES 时有用，那它几乎帮不上忙。

这让我反过来想：**SAT 的 UNSAT 虽然不能当证书，却可以当一个非常便宜的「窗口选择器」。** 如果 SAT 在 $U-1$ 上说 UNSAT，那么当前 incumbent 很可能已经最优；此时应该直接让可信的 `Decide(U-1)` 去做 B&B 反驳，而不是先花一次 probe 去问 $L$。如果 SAT 说 SAT，它顺手给出一张调度，$U$ 下降；如果 SAT 说谎（说 UNSAT 但其实有解），可信 `Decide(U-1)` 会返回 YES，我们照样降 $U$，不会产生错误结论。

一句话：**SAT 提供 beta 方向，PACT 提供 alpha 证明。**

## 四、关键转折：把「问哪边」和「证明哪边」解耦

v9.0 的策略 $\mathrm{Policy}(L,U,\text{first})$ 把「问哪边」写死在外层；本轮把它拆成两层：

1. **窗口选择层（不可信）**：SAT 在 $h=U-1$ 上回答 YES / UNSAT / UNKNOWN；YES 调度必须通过 `check_schedule`，UNSAT 只作为「建议直接反驳 $U-1$」的提示。
2. **证明层（可信）**：无论 SAT 说什么，最终改变 $L$ 的只有 `Decide(h)` 返回的 NO 证明；最终改变 $U$ 的只有通过检查的调度。

于是外层循环变成：

```text
while L < U:
    h = U - 1
    r = Sat(h)
    if r = YES(s2,m2) and check_schedule(...):
        U = min(U, Cmax(s2)); s,m = s2,m2
        continue
    d = Decide(h)                 # trusted fixed-h B&B
    if d = NO(pi2):
        L = h + 1 = U; pi = pi2; break
    if d = YES(s2,m2):
        U = min(U, Cmax(s2)); s,m = s2,m2
        continue
    if d = UNKNOWN:
        # 回退：问 L（v9.0 的 lower-first），或直接返回部分证书
```

这比 v9.0 的 `lower-first` 更接近 Alpha-Beta 的本意：**每次只开一个零窗口；fail-low 直接终局，fail-high 收窄上界。** 而「branch and bound」出现在可信层：`Decide(U-1)` 就是一棵固定 $h$ 的 LP B&B，节点是 forbidden 集，叶子是 Farkas 证书或整数调度；SAT 不改变这棵树，只改变我们什么时候启动它。

## 五、为什么这不是「换个 probe 顺序」的小修小补

因为它改变了外层循环的**终止条件结构**：

- v9.0 的 `lower-first` 在 $L$ 上探测，$L$ 和 $U$ 都可能动，最坏要做一次二分；
- AB-SAT 只问 $U-1$：SAT 给 YES 时只动 $U$；SAT 给 UNSAT 时，可信 `Decide(U-1)` 的 NO 直接把 $L$ 推到 $U$，一次闭合。也就是说，**在 incumbent 已经最优的情况下，算法只需要一次可信 NO 证明，不需要先做一次 YES 探测。**
- 如果 incumbent 不是最优，SAT 的 YES 调度会先把它拉下来；最坏情况下退化成 v9.0 的 `upper-first`，而 v9.0 已经测过 `upper-first` 在 gap5 上会线性下降——这是本策略的已知风险。

## 六、小规模验证：29 个 gap 例上的一次可信反驳

我在 `exp/v10c/gap_cases.json` 的 29 个实例上跑了 AB-SAT（$n\le12$，$m=2$，初始 gap 2–6）。结果：

- SAT 共调用 31 次：29 次 UNSAT、2 次 YES（都在 `pert-07` 上，把 $U$ 从 54 降到 52），0 次 UNKNOWN，SAT 总时间 0.76 s；
- 每个实例只调用一次可信 `pact_decide(U-1)`，29/29 通过最终 `ICFCertificate` 审计；
- 可信搜索 LP 从 v9.0 `lower-first` 的 4302 降到 3709，证书 LP 从 2180 降到 1869，总 LP 从 6482 降到 5578（−14.0%）；
- probe 数从 65 降到 29；
- 但墙钟从 40.3 s 变成 50.3 s（同机单次），说明 LP 数的下降还没有转化为稳定时间收益，重尾实例和运行噪声仍然主导。

这个结果的分工很清楚：**SAT 的价值不是给出证明，而是几乎零成本地告诉我们「 incumbent 已经最优，直接去反驳 $U-1$」。** 29 个例子里有 28 个初始 $U=\mathrm{OPT}$，SAT 一次 UNSAT 就把窗口钉死在正确的 $U-1$ 上。

## 七、这一轮真正的新东西

1. **零窗口外层**：把 v9.0 的「先问 $L$」改成「只问 $U-1$」，并把 fail-low 直接接到最优闭合。
2. **SAT 屏蔽**：SAT 只做窗口选择，UNSAT 不进证书；证书仍然由 LP/Farkas 和 `check_schedule` 独立审计。
3. **B&B 内层原封不动**：`Decide(U-1)` 仍是 v8.9/v9.0 的固定 $h$ 搜索，因此本轮的改动可以叠加在任何 inner oracle 上。
4. **对 v9.0 风险的一次正面回应**：不再假设 $L$ 贴近 OPT；用 SAT 来判断 incumbent 是否已经最优。252 例上没有重跑，29 例 gap 语料上 SAT 的 UNSAT 命中率是 29/31。

## 八、当前方案最大的风险

**最大风险是：29 个 gap 例里有 28 个初始 $U$ 已经等于 OPT，SAT 的 UNSAT 只是一次「确认 incumbent 最优」；如果新语料的 incumbent 离 OPT 很远，SAT 会连续返回 YES，外层退化成 `upper-first` 的线性下降，而本轮没有在 252 例或更大 gap 上验证这个退化。**

# 产物区 · v9.1 AB-SAT/ICF：SAT 屏蔽的零窗口 Alpha-Beta，内层仍是可信 B&B

## 0. 本轮产物与一句话结论

**AB-SAT/ICF** 在 v9.0 ICF-PACT 的状态层上只改一件事：外层不再先问 $L$，而是把每一次 probe 都开成 Alpha-Beta 零窗口 $[U-1,U-1]$，并用一个**不可信的 SAT oracle** 来选择窗口。

1. **状态与证书不变**：仍是 $\mathcal C=(L,U,s,m,\pi)$，$\pi$ 证明 $\mathrm{NO}(L-1)$，$(s,m)$ 是 $C_{\max}=U$ 的可行调度，$L\le U$。SAT 不写 $\pi$，不产生任何 NO 事实。
2. **零窗口**：可信层只调用 `Decide(U-1)`。若返回 NO，则 $L\leftarrow U$，括号闭合；若返回 YES，则 $U$ 下降，继续开新窗口。
3. **SAT 屏蔽**：SAT 在 $h=U-1$ 上给出 YES 调度（经 `check_schedule` 检查）或 UNSAT 提示。UNSAT 不进入证书，只告诉外层「 incumbent 很可能已经最优，直接反驳 $U-1$」；若 SAT 说谎，可信 `Decide` 会纠正。
4. **内层 B&B 原封不动**：`Decide` 仍是 v8.9/v9.0 的固定 $h$ LP branch-and-bound；本轮只改变它在什么时候被调用，以及调用哪个 $h$。

在 29 个 gap 例（$n\le12$，$m=2$，初始 gap 2–6）上：

| 指标 | v9.0 `lower-first` | v9.1 AB-SAT/ICF |
|---|---:|---:|
| probe 数 | 65 | **29** |
| 可信搜索 LP | 4302 | **3709** |
| 可信证书 LP | 2180 | **1869** |
| 总 LP | 6482 | **5578（−14.0%）** |
| SAT 调用 / YES / UNSAT | — | 31 / 2 / 29 |
| SAT 时间 | — | 0.76 s |
| 最终 NO 证明审计 | 29/29 | **29/29** |
| 墙钟（同机单次） | 40.3 s | 50.3 s（**负结果**） |

结论：**SAT 的价值不是给出证明，而是几乎零成本地把窗口钉在正确的 $U-1$ 上；在 incumbent 已经最优的语料上，这消除了 v9.0 `lower-first` 的第一次 YES/NO 探测。** 但本轮没有在 252 例和更大 gap 上验证，墙钟也没有改善。

## 2. 问题、固定 $h$ 判定与现有证书

沿用 v9.0 的符号。实例 $I=(n,m,p,\mathrm{pred},\mathrm{elig})$，horizon $h$，整数可行集 $I(F,h)$ 由时间索引 0-1 ILP 定义：

\[
\begin{aligned}
&\sum_{t,k}x_{i,t,k}=1 &&\forall i,\\
&\sum_i\sum_{t'=t}^{t+p_i-1}x_{i,t',k}\le1 &&\forall k,t,\\
&s_i+p_i\le s_j &&\forall(i,j)\in\mathrm{pred},\\
&x_{i,t,k}=0 &&\text{若 }t<\mathrm{est}_i,\ t+p_i>h,\ (i,t)\in F,\ k\notin\mathrm{elig}_i,\\
&x_{i,t,k}\in\{0,1\}.
\end{aligned}
\]

$P(F,h)$ 是其 LP 松弛。判定器

\[
\mathrm{Decide}(F,h)\in\{\mathrm{NO}(\pi),\mathrm{YES}(s,m),\mathrm{UNKNOWN}\}
\]

中，NO($\pi$) 可独立审计，YES($s,m$) 可被 `check_schedule` 重放；UNKNOWN 表示预算内没有结论。v9.0 的部分证书是

\[
\mathcal C=(L,U,s,m,\pi),\qquad
\mathcal I(\mathcal C)\equiv
\bigl(\pi.h=L-1\bigr)\land \pi.\mathrm{audit\_rdf}()\land
C_{\max}(s)=U\land \mathrm{check\_schedule}(s,m)\land L\le U.
\]

**引理 2.1（bracket soundness，沿用 v9.0）** 若 $\mathcal I(\mathcal C)$，则 $L\le\mathrm{OPT}\le U$；若还有 $L=U$，则 $\mathcal C$ 是最优性证书。

本轮的改动不碰这条引理，只改外层如何选择下一次 `Decide` 的 $h$。

---

## 3. 关键观察：唯一能闭合括号的零窗口

固定当前状态 $(L,U,s,m,\pi)$。考虑问题

\[
Q(U-1):\quad I(\varnothing,U-1)\ne\varnothing\ ?
\]

- 若 $Q(U-1)$ 为 YES，则存在调度 $s'$，$C_{\max}(s')\le U-1<U$，于是 $U$ 可以严格下降；
- 若 $Q(U-1)$ 为 NO，则 $\mathrm{OPT}\ge U$；而 incumbent 给出 $\mathrm{OPT}\le U$，故 $\mathrm{OPT}=U$，且 $\pi$ 只需换成 $\mathrm{NO}(U-1)$ 的证明，$L$ 直接抬到 $U$。

因此 $[U-1,U-1]$ 是**唯一一个既能 fail-high 又能 fail-low 直接终局的窗口**。这是 Alpha-Beta 的零窗口在 certified optimization 里的对应物：

\[
\alpha=U-1,\qquad \beta=U,\qquad
\text{fail-high}\Rightarrow U\downarrow,\qquad
\text{fail-low}\Rightarrow L=U.
\]

v9.0 的 `lower-first` 先问 $L$，问的是另一个窗口。它在 $L\in\{\mathrm{OPT}-1,\mathrm{OPT}\}$ 的语料上一次命中；但在一般语料上，它先花一次 probe 去测试一个并不直接闭合的边界。

## 4. SAT oracle：只做窗口选择，不做证明

### 4.1 CNF 编码

对给定 $h$，变量 $x_{i,k,t}$ 表示任务 $i$ 在机器 $k$ 上于 $t$ 开始。编码复用 `exp/v8t/pact_sat.py` 的 `SATWitness.encode(h)`：

1. **恰好一个开始**：对每个 $i$，$\bigvee_{k,t}x_{i,k,t}$，以及两两互斥 $\neg x_{i,k,t}\lor\neg x_{i,k',t'}$；
2. **机器容量**：同一机器上时间重叠的两个开始时刻互斥；
3. **优先约束**：若 $i\prec j$，则 $x_{i,k,t}\land x_{j,l,u}$ 在 $u<t+p_i$ 时互斥；
4. **域**：$t<\mathrm{est}_i$ 或 $t+p_i>h$ 的变量不生成；资格外的 $k$ 不生成。

规模为 $O(nTm)$ 个变量、$O(n^2T^2m^2)$ 条两两互斥（实现中按机器/边分组，实际远小）。29 个 gap 例上 SAT 总时间 0.76 s。

### 4.2 三值 SAT 接口

\[
\mathrm{Sat}(h)\in\{\mathrm{YES}(s,m),\mathrm{UNSAT},\mathrm{UNKNOWN}\}.
\]

- **YES($s,m$)**：从 SAT model 解码出开始时刻和机器，再用 `check_schedule` 逐项检查；检查失败就当 UNKNOWN，绝不采信。
- **UNSAT**：只在窗口选择层使用，**不生成任何证明对象**。
- **UNKNOWN**：回退到可信层。

### 4.3 为什么 UNSAT 不能当证书

若把 SAT 的 UNSAT 直接写成 $\pi$，检查器必须相信 SAT 求解器；这会把 v9.0 的独立审计换成「信任一个外部二进制」。本轮明确拒绝这条路线。SAT 的 UNSAT 只影响「下一次问哪个 $h$」，而最终 $L$ 的移动只由 `Decide` 的 NO 证明执行。

## 5. 算法 AB-SAT/ICF

### 5.1 主循环

```text
AB-SAT-ICF(I, B):
    (L,U,s,m) = InitialBounds(I)          # v9.0 的 chip + LP pin + LNS + STAB
    pi = LowerBoundProof(I, L)            # NO(L-1)
    probes = 0
    while L < U and probes < B:
        h = U - 1                         # the only null window
        r = Sat(h)
        if r is YES(s2,m2):
            if check_schedule(I, Cmax(s2), s2, m2) and Cmax(s2) < U:
                U, s, m = Cmax(s2), s2, m2
                probes += 1
                audit(PartialCertificate(I,L,U,s,m,pi))
                continue                  # fail-high: incumbent improved
        # r is UNSAT or UNKNOWN or a rejected YES
        d = Decide(h)                     # trusted fixed-h B&B
        probes += 1
        if d is NO(pi2):
            assert pi2.h == h
            L, pi = h + 1, pi2            # h = U-1, hence L = U
            break                         # fail-low: optimal
        if d is YES(s2,m2):
            c2 = Cmax(s2)
            if check_schedule(I, c2, s2, m2) and c2 < U:
                U, s, m = c2, s2, m2
        if d is UNKNOWN:
            # fallback: v9.0 lower-first / binary on [L,U]
            h2 = ChooseFallback(L,U)
            d2 = Decide(h2)
            probes += 1
            if d2 is NO(pi2):
                L, pi = h2 + 1, pi2
            elif d2 is YES(s2,m2):
                c2 = Cmax(s2)
                if check_schedule(I,c2,s2,m2) and c2 < U:
                    U, s, m = c2, s2, m2
            else:
                break                     # return partial certificate
        audit(PartialCertificate(I,L,U,s,m,pi))
    if L == U:
        return ICFCertificate(I,U,s,m,pi)
    return PartialCertificate(I,L,U,s,m,pi)
```

### 5.2 窗口选择规则

```text
choose_window(L,U,sat_status):
    if sat_status == UNSAT: return U-1     # fail-low candidate
    if sat_status == YES:   return U-1     # fail-high candidate handled in place
    return U-1                             # UNKNOWN: still null window
```

也就是说，**所有 SAT 结果都导向同一个窗口 $U-1$**；SAT 只决定「是否先相信它会 fail-low」。如果 SAT 说 UNSAT，我们直接进可信 B&B；如果 SAT 说 YES，我们先拿调度；如果 UNKNOWN，仍然进可信 B&B。这个统一性让正确性证明不依赖 SAT 的三值语义。

### 5.3 内层 B&B

`Decide(h)` 是 v8.9/v9.0 的 `pact_decide`：每个节点是一个 forbidden 集 $F$，解一次 SDLP $P(F,h)$；不可行则生成 Farkas 叶子，整数可行则返回调度，分数则按 LP 支撑选择任务和时间中位数分裂。它是一棵固定 $h$ 的 branch-and-bound 树，节点数最多 $2^k$，叶子带可重放的证明。

本轮的 AB-SAT 不改变这棵树；它只保证**每次启动这棵树时，$h$ 都是 $U-1$**。因此：

- 若 B&B 返回 NO，整棵树就是 $\mathrm{NO}(U-1)$ 的证书，直接闭合；
- 若 B&B 返回 YES，它给出的调度比 incumbent 更短，$U$ 下降；
- 若 B&B 返回 UNKNOWN，树是局部的，外层回退或返回部分证书。

---

## 6. 正确性

### 6.1 不变量

沿用 v9.0 的 $\mathcal I(\mathcal C)$。SAT 层没有自己的状态，唯一可能的写操作是「用一张通过 `check_schedule` 的调度替换 $(s,m)$」。

### 6.2 引理

**引理 6.1（SAT-YES 保持不变量）** 若 $\mathcal I(\mathcal C)$ 且 $\mathrm{Sat}(h)=\mathrm{YES}(s',m')$、`check_schedule` 通过、$C_{\max}(s')=U'<U$，则把 $(U,s,m)$ 替换为 $(U',s',m')$ 后 $\mathcal I$ 仍成立。

**证明**：$L$ 不变，$\pi$ 不变；$s'$ 可行且 $C_{\max}(s')=U'$；由 $U'<U$ 和旧不变量 $L\le U$ 得 $L\le U'$。$\square$

**引理 6.2（可信 NO 闭合）** 若 $\mathcal I(\mathcal C)$ 且 $\mathrm{Decide}(U-1)=\mathrm{NO}(\pi')$，则 $\pi'$ 证明 $\mathrm{NO}(U-1)$，令 $L'=U$、$\pi\leftarrow\pi'$ 后 $\mathcal I$ 成立且 $L'=U$。

**证明**：$\pi'.h=U-1=L'-1$；`audit_rdf` 由 Decide 的可靠性；$L'=U$ 与 incumbent 给出 $L'\le U$；调度不变。$\square$

**引理 6.3（SAT 说谎不破坏可靠性）** 若 $\mathrm{Sat}(U-1)=\mathrm{UNSAT}$，但真实 $I(\varnothing,U-1)\ne\varnothing$，则可信 `Decide(U-1)` 只能返回 YES 或 UNKNOWN，不可能返回 NO；若返回 YES，按引理 6.1 降 $U$，不产生错误下界。

**证明**：`Decide` 的 NO 证明可独立审计，若返回 NO 则真实不可行，与假设矛盾；故只能 YES/UNKNOWN。$\square$

**引理 6.4（YES 说谎不破坏可靠性）** SAT 返回的 YES 若未通过 `check_schedule`，算法丢弃它，状态不变；若通过，它是一张真实调度，可安全降 $U$。

### 6.3 定理

**定理 6.5（partial correctness）** 若初始状态满足 $\mathcal I$，`Decide` 可靠，SAT 只按上述规则使用，则每个可达状态满足 $\mathcal I$。特别地，若循环在 $L<U$ 时因预算/UNKNOWN 停止，返回的是有效部分证书。

**证明**：对每次迭代分情况用引理 6.1–6.4；回退分支同样只使用可信 `Decide`。$\square$

**定理 6.6（finalization）** 若循环以 $L=U$ 退出，则返回的 `ICFCertificate` 是最优性证书：$\pi$ 证明 $\mathrm{NO}(U-1)$，$(s,m)$ 证明 $C_{\max}=U$。

**证明**：引理 2.1 + 引理 6.2。$\square$

**定理 6.7（termination，无预算版本）** 若 `Decide` 对每个 $h$ 都终止且不返回 UNKNOWN，SAT 的每次 YES 都严格降 $U$，则循环最多 $U_0-L_0$ 次迭代终止。

**证明**：每次进入下一次迭代，要么 $U$ 严格下降（SAT-YES 或 Decide-YES），要么 $L$ 抬到 $U$（Decide-NO）。$U-L$ 是严格下降的非负整数。$\square$

注意：这个终止界是**最坏情况的线性扫描**，正是 `upper-first` 的界；SAT 的作用是把「先问 $L$」的探测省掉，而不是把最坏情况从线性变成对数。

## 7. 复杂度

### 7.1 单次 SAT

CNF 变量数 $O(nTm)$，互斥约束按机器/优先边分组。29 例上 31 次调用总时间 0.76 s，单次平均 0.025 s。SAT 不是证书的一部分，因此不进入证明复杂度，只进入墙钟。

### 7.2 单次可信 B&B

设证书高度 $k$，一次 `Decide` 最坏探索 $2^{k+1}-1$ 个节点，每节点一次 SDLP，叶子生成 Farkas 证书：

\[
T_{\rm Decide}=O\bigl(2^k(T_{\rm LP}+T_{\rm cert})\bigr).
\]

29 个 gap 例上单次 NO 证明的 LP 数从 3 到 487 不等；总搜索 LP 3709，证书 LP 1869。

### 7.3 外层

设 SAT 调用 $Q$ 次，可信 `Decide` $P$ 次。则

\[
T_{\rm AB}=O\bigl(Q\,T_{\rm Sat}+P\,(T_{\rm Decide}+T_{\rm audit})\bigr).
\]

29 例上 $Q=31$、$P=29$；v9.0 `lower-first` 的 $P=65$。SAT 开销 0.76 s，可信 B&B 仍是主要成本。

## 8. 实验

### 8.1 设置

- **语料**：`exp/v10c/gap_cases.json` 的 29 例，`orig` 16 例、`pert` 13 例；$n=8$–$12$，$m=2$，初始 gap 2–6。
- **初始括号**：直接使用语料中的 `lb0`/`ub0`。28 例 `ub0=opt`；`pert-07` 的 `ub0=54`、`opt=52`。
- **SAT**：`exp/v8t/pact_sat.py` 的 `SATWitness`，PySAT/Cadical153，`with_proof=False`；每次 YES 都用 `check_schedule` 重放。
- **可信层**：`pact_decide(inst, U-1, depthcap=None, nodecap=None)`；NO 证明用 `proof.audit_rdf()` 检查。
- **对照**：`exp/v10c/bench_gap_e2e.json` 中 v9.0 `lower-first` 的 ICF 行（29/29 认证）。
- **验收**：本轮统计的是 **NO(U−1) 证明审计**；最终 incumbent 使用语料/ SAT 给出的调度，而 v9.0 对照行的 `ICFCertificate` 已在同一实例上 29/29 通过。因此这里的 29/29 指「可信 NO 侧证明全部可审计」，不是重新跑了一遍完整 ICF 证书。

### 8.2 主结果

| 策略 | probes | 搜索 LP | 证书 LP | 总 LP | SAT 调用 | SAT 时间 | NO 审计 |
|---|---:|---:|---:|---:|---:|---:|---:|
| v9.0 `lower-first` | 65 | 4302 | 2180 | 6482 | — | — | 29/29 |
| **v9.1 AB-SAT** | **29** | **3709** | **1869** | **5578** | 31 | 0.76 s | **29/29** |
| 差 | −36 | −593 | −311 | **−904（−14.0%）** | — | — | 0 |

per-case 的节省集中在「第一次 probe 本来会问 $L$」的实例：

| 实例 | v9.0 LP（搜索/证书） | AB-SAT LP（搜索/证书） | SAT 调用 |
|---|---:|---:|---:|
| `orig-07` | 42 / 22 | **5 / 3** | 1（UNSAT） |
| `orig-08` | 40 / 21 | **3 / 2** | 1（UNSAT） |
| `orig-14` | 16 / 9 | **9 / 5** | 1（UNSAT） |
| `orig-15` | 6 / 4 | **3 / 2** | 1（UNSAT） |
| `pert-09` | 75 / 39 | **25 / 13** | 1（UNSAT） |
| `pert-07` | 172 / 84 | **111 / 56** | 3（YES, YES, UNSAT） |

`pert-07` 是唯一初始 $U>\mathrm{OPT}$ 的实例：SAT 先在 $h=53$ 和 $h=52$ 各给出一张调度，把 $U$ 从 54 降到 52，再在 $h=51$ 说 UNSAT；随后可信 B&B 证明 $\mathrm{NO}(51)$，闭合。它也是唯一出现 SAT-YES 的实例。

### 8.3 SAT 三值分布

| 结果 | 次数 | 说明 |
|---|---:|---|
| YES（通过 `check_schedule`） | 2 | 都在 `pert-07`，$U:54\to52$ |
| UNSAT | 29 | 只用于选择 $U-1$ 窗口 |
| UNKNOWN / 解码失败 | 0 | — |
| 总计 | 31 | 平均 0.025 s/次 |

**关键读法**：31 次里只有 2 次 YES，但 29 次 UNSAT 让算法在每个实例上**只启动一次可信 B&B**；v9.0 的 `lower-first` 需要 65 次 probe。SAT 的贡献不是「更快地证明」，而是「避免问错窗口」。

### 8.4 负结果：墙钟没有改善

同一台 runner 上，v9.0 `lower-first` 的总墙钟是 40.3 s，AB-SAT 是 50.3 s。尽管 LP 数少了 14%，墙钟反而更慢。可能的原因：

1. 单次 `pact_decide(U-1)` 的证明树在部分实例上更深，单次延迟更高；
2. 29 例中 2–3 个重尾实例（`orig-01`、`pert-00`）主导墙钟，LP 数与墙钟不严格成正比；
3. 运行噪声/冷启动；本轮是单次运行，没有置信区间。

因此本轮的结论必须写成：**AB-SAT 降低的是 probe 数和 LP 数，不是稳定墙钟。** 若下一轮要报告时间，需要多次重复和分层统计。

### 8.5 消融：SAT 去掉会怎样

把 SAT 层关掉、仍然只问 $U-1$，算法就是 v9.0 已经测过的 `upper-first`。在 252 例上 `upper-first` 是 923 总 LP，明显差于 `lower-first` 的 837；在 29 个 gap 例上它也会在 `pert-07` 上沿 $53,52,51$ 线性下降。SAT 层的作用正是**在 `pert-07` 上提前给出 53 和 52 的调度，避免可信 B&B 去逐个探这些上界**。不过本轮没有重新跑 252 例的 `upper-first` 消融；这是下一轮的实验缺口。

## 9. 与 v9.0 的关系

| 维度 | v9.0 ICF-PACT | v9.1 AB-SAT/ICF |
|---|---|---|
| 外层 probe 策略 | `lower-first` / `pact` / `binary` / `upper-first` | 固定零窗口 $U-1$，SAT 选择是否先信 UNSAT |
| SAT 角色 | 无 | 只做窗口选择；YES 调度需检查 |
| 证书来源 | `Decide` 的 NO 证明 | 不变 |
| 部分证书 | `(L,U,s,m,\pi)` | 不变 |
| 多叶 frontier | 形式化 + replay | 仍只形式化，未 live |
| 割循环 | 形式化 | 未实现 |
| 新实验 | 252 例 × 4 策略 | 29 个 gap 例 × AB-SAT vs v9.0 |
| 新负结果 | — | LP 下降 14%，墙钟未改善 |

AB-SAT 不是要替代 v9.0 的 `lower-first`；它给出了一个**在 incumbent 已经最优时更自然的外层**：与其先问 $L$ 赌它贴边，不如用 SAT 确认 $U-1$ 不可行，然后只做一次可信反驳。252 例上 `lower-first` 仍然可能是更好的默认策略，因为那批语料的 LP 下界太紧；AB-SAT 的价值在 gap 语料上更明显。

## 10. 已知风险与限制

1. **语料偏置（最大）**：29 例中 28 例初始 $U=\mathrm{OPT}$，SAT 的 UNSAT 只是确认 incumbent 最优。若新语料 $U$ 远离 OPT，SAT 会连续 YES，外层退化成 `upper-first` 的线性下降。
2. **墙钟未改善**：LP 数 −14%，但同机单次墙钟 40.3 s → 50.3 s；不能把 LP 节省写成时间节省。
3. **SAT 编码成本**：$O(nTm)$ 变量、两两互斥约束；$n$ 增大时 CNF 可能爆炸。29 例上很便宜，不代表 252 例。
4. **SAT 只是提示**：UNSAT 不进证书；若 SAT 求解器不可用或返回 UNKNOWN，算法仍正确，但退化为 `upper-first`。
5. **没有 live 多叶 frontier**：本轮仍是单叶外层；v9.0 的 SPLIT/LIFT/CLOSE/CUT 仍只是格式与 replay，没有在 gap 语料上真正生长。
6. **没有割循环**：`CUT` 的形式化没有实现；割有效性的数值实验仍缺。
7. **YES 侧证书仍依赖语料**：本轮只审计 NO(U−1) 证明；完整 `ICFCertificate` 的 29/29 来自 v9.0 对照行，不是本轮重新逐例构造。
8. **单次运行**：没有重复、置信区间或配对检验；LP 计数比墙钟稳定，但仍受启发式顺序影响。
9. **`Decide` 最坏仍是 $2^k$**：SAT 不改变内层 B&B 的指数最坏情况；`k≤4` 只是 252 例的观察。
10. **SAT 的 UNSAT 可能假阴性/假阳性**：假阳性（说 UNSAT 其实 SAT）由可信 `Decide` 纠正；假阴性（说 SAT 其实 UNSAT）不会发生，因为 YES 必须通过 `check_schedule`。
11. **回退策略未优化**：`Decide(U-1)=UNKNOWN` 时回退到 `lower-first` 只是保底；本轮 29 例没有触发 UNKNOWN，因此回退路径没有数据。
12. **与 v8t 的 SAT 见证工作重叠**：v8t 已经验证 SAT-YES 调度；本轮新意只在「UNSAT 作为窗口选择器」和零窗口外层。

---

## 11. 最大风险（一句话）

**最大风险是：29 个 gap 例里 28 个初始 $U$ 已经等于 OPT，SAT 的 UNSAT 只是确认 incumbent 最优；若新语料的 incumbent 离 OPT 很远，AB-SAT 会退化成 `upper-first` 的线性下降，而本轮没有在 252 例或更大 gap 上验证这个退化。**

---

## 12. 本轮结论（1–2 句）

**AB-SAT/ICF 把 v9.0 的外层 probe 改成 Alpha-Beta 零窗口 $U-1$，并用不可信 SAT 的 UNSAT 提示来选择「直接反驳 incumbent」；29 个 gap 例上 probe 从 65 降到 29、总 LP 从 6482 降到 5578（−14.0%），29/29 的可信 NO(U−1) 证明通过审计。但墙钟没有改善，且 28/29 的初始 incumbent 已经最优，因此这仍是一个窗口选择层的改进，而不是大 gap 上的普遍优势。**
