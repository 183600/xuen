# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「续航能力」×「移动操作」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「场景→意图→约束→阻抗→执行→证据」闭环起来，解决了「认知先行」的场景适应与 ROS 证据链完整性。但它把机器人默认为**固定基座、能量无限**的操作臂：**能量**没有被建模成第一类约束，**移动**也没有被建模成与操作耦合的决策。于是出现三个新的根本局限：
> 1. **续航的事后性**：SoC 只被当作一个监控数字，而非「可预测、可证据化、可契约化」的资源。执行层可以在「电池还剩 18%」时继续按满功率阻抗动作，却无法回答「这次操作后还能否安全回充」。
> 2. **移动-操作的割裂性**：第 60 轮把执行看作「场景→K_safe」，底盘与机械臂被视为独立执行器。但移动操作的本质是**为操作而移动**：基座位姿决定可操作度，也决定移动与操作的能耗；「先到位再操作」的串行范式在续航受限时经常不可行。
> 3. **降级的非单调性**：场景/意图护栏是认知维度的「软降级」，而能量是**单调不可逆**的稀缺资源。缺少「低电量→约束单调收缩→回充保留」的能量安全包络，低电时继续执行会同时触发电压跌落、热降额、回充失败三重风险。

## 0. 直觉与动机

**灵感 1（续航能力 → 能量证据与续航模型 EEMM）**
直觉：续航不是「还剩百分之几的电」，而是「在当前策略 π 下，我还能以多大概率完成多少次任务并安全回到充电桩」。因此 SoC 应被升级为**带不确定性的随机过程**，总功率被拆成「移动 + 操作 + 计算 + 待机」四个可加项，剩余续航是一个**分布**而不是一个标量。更关键的是：每一次执行都应产出一条 **EV-energy**（预测能耗、实测能耗、二者比值），让「续航承诺」像 EV-exec 一样可审计、可追溯。

**灵感 2（移动操作 → 能耗-可操作度帕累托选点 EMPP）**
直觉：移动操作不是「先移动、再操作」的顺序拼接，而是**为了操作而选择在哪移动**。给定一个抓取/装配任务，基座位姿 b 同时决定机械臂的可操作度 w(b) 与「移动到位 + 操作过程」的总能耗 E(b)。最优点通常不是可操作度最大的位姿，而是**能耗-可操作度帕累托前沿的膝点**：用最少的移动能量换取足够（而非最大）的操作裕度。

**灵感 3（移动-操作耦合 → 全身能量分配 WBEA）**
直觉：底盘与机械臂共享同一个功率池、同一套热约束、同一个时间窗。分配向量 λ=(λ_loco, λ_manip) 决定「移动多快」与「操作多稳」。低电量时，理性的做法是把功率从「移动速度」挪给「操作稳定」，而不是两个子系统各按自己的最大功率抢电。**功率/热约束是跨执行器的耦合约束**，必须在同一预算下联合求解。

**灵感 4（契约升级 → 能量感知实时契约 EARC）**
直觉：第 60 轮的 ERTC 契约只写时间与阻抗。现在给契约加一条**能量条款**：E_clause=(P_peak_max, E_task_max, SoC_floor, T_rem_min)。契约可行当且仅当「预测任务能耗 ≤ 任务能量上限 ∧ 执行后 SoC ≥ SoC_floor ∧ 剩余续航 ≥ 安全回充需求」。随着 SoC 下降，可接受的 K_safe 集合应**单调收缩**，形成一条不会因「电量突降」而失效的能量安全包络。

**灵感 5（预算升级 → PCE+++++ 能量认知预算）**
直觉：第 60 轮的 B_scene/B_intent/B_ros/B_exec 四预算之外，必须再加 **B_energy**，并把能耗写进 VOI 成本。任何预算耗尽都触发降级，但能量预算的降级是**单调且不可逆**的（电不能凭空恢复），因此它在五维预算中拥有最高优先级：能量不足时，宁可牺牲探测/精度，也要保住「回充能力」。

**灵感 6（合流 → 能量耦合闭环 ECOL 与能量证书 J_energy）**
直觉：场景先验告诉我们「地形有多耗电」，意图约束告诉我们「要不要省电/省力」，WBEA 决定「功率怎么分」，EMPP 决定「去哪操作」，EARC 决定「能不能做」，EGD 决定「低电怎么退」，J_energy 决定「做完怎么证明」。七者合成闭环：**场景→意图→能量契约→全身分配→基座选点→阻抗执行→能量证据→场景/预算更新**，把第 60 轮的「认知驱动」推进为「能量受限下的认知-移动-操作协同」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（能量证据与续航模型 EEMM）** Γ_E = (𝒮, 𝒫, 𝒯, ℛ_E)。其中：
- **SoC 随机动力学**：SoC_{t+1} = clip(SoC_t − P_tot(t)·Δt/E_cap + w_t, 0, 1)，w_t ~ N(0, σ_E²)，w_t 吸收电池老化、温度、内阻与功率模型误差。
- **功率可加分解**：P_tot = P_idle + P_loco + P_manip + P_comp，其中
  - P_loco = c_roll(terrain)·m·g·v_b + c_aero·v_b³ + (τ_b·ω_b)/η_b，
  - P_manip = (F_e·ẋ_e)/η_arm + c_K·||K||·||Δx_e||²/Δt + c_g·m_p·g·v_z + P_hold，
  - P_comp 为感知/推理/通信算力功耗。
- **剩余任务能力（TCE）**：T_rem(π) 为给定策略 π 下「安全完成任务并回到充电桩」的剩余任务次数/时长的**预测分布**，由对 P_tot 的蒙特卡洛前向推演得到：p(T_rem | SoC_t, π) = ∫ p(T_rem | SoC_{t+H}, π)·p(SoC_{t+H} | SoC_t) dSoC_{t+H}。
- **能量证据**：EV-energy = (t, SoC_t, P_meas, E_cum, R_E = E_pred/E_meas, hash)，进入与 EV-exec 同级的证据链。

**定义 162（能耗-可操作度帕累托选点 EMPP）** 对任务 T 与基座位姿 b ∈ SE(2)：
- **可操作度**：w(b) = sqrt(det(J(q)J(q)^T))（Yoshikawa 度量），q 为在 b 处操作任务所需臂构型。
- **总能耗**：E(b) = E_move(b_cur → b) + E_manip(b, T)，其中 E_move = ∫P_loco dt，E_manip = ∫P_manip dt。
- **联合目标**：b* = argmax_b [ α·ŵ(b) − (1−α)·Ê(b) ]，s.t. w(b) ≥ w_min，re_s(b,T) = true（可达 + 无碰撞），ŵ、Ê 为归一化量。
- **帕累托前沿**：𝒫_EM = {(w(b), E(b)) | 非支配}；决策取前沿膝点 b_knee = argmax_b [w(b)−w_min]/[E(b)−E_min]，即「单位额外能耗换来的可操作度增益最大」处。

**定义 163（全身能量分配 WBEA）** 给定功率预算 P_budget(SoC, thermal) 与任务 T：
- **分配向量** λ = (λ_loco, λ_manip, λ_comp)，λ_i ≥ 0，Σλ_i ≤ 1；实际功率 P_i = λ_i·P_budget。
- **耦合可行域**：P_loco ≤ P_loco^max(λ_manip)，P_manip ≤ P_manip^max(λ_loco)，且各关节功率 P_j ≤ P_j^max(T_j)（热约束）。
- **分配问题**：
  max_λ U(T; λ) = u_loco(v_b(λ_loco), T) + u_manip(w(b), K(λ_manip), T)
  s.t. Σλ_i ≤ 1，T_j(λ) ≤ T_j^max，SoC_{t+H}(λ) ≥ SoC_reserve。
- **低电重分配规则**：当 SoC < θ_low 时，λ_manip ← λ_manip + Δ，λ_loco ← λ_loco − Δ（牺牲速度保操作稳定），直到 v_b 降到 v_b^min。

**定义 164（能量感知实时契约 EARC）** ERTC 契约 C_rt 扩展为 C_rt^E = (C_rt, E_clause)，E_clause = (P_peak_max, E_task_max, SoC_floor, T_rem_min)。契约**能量可行**当且仅当：
```
E[E_task(π)] ≤ E_task_max
E[SoC_after] ≥ SoC_floor
P(T_rem(π) ≥ T_rem_min) ≥ 1 − δ_ret
```
且**单调安全包络**要求：若 SoC₁ ≥ SoC₂，则 𝒦_acc(SoC₂) ⊆ 𝒦_acc(SoC₁)，即可接受阻抗参数集随电量下降单调收缩。

**定义 165（PCE+++++ 能量认知预算）** B_total = (B_energy, B_scene, B_intent, B_ros, B_exec)，其中 B_energy = (E_task_remaining, P_peak_headroom, Thermal_headroom, SoC_reserve)。
- **VOI 扩展**：voi_E(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_energy(π)，cost_energy = λ_E·E_task(π)/E_task_max + λ_T·max(0, T_j−T_j^max)。
- **降级优先级**：B_energy < θ_E ⇒ 关闭主动探测（B_probe→0）并收缩 K_safe；耗尽 ⇒ 进入 EGD 的橙/红档。

**定义 166（能量护栏降级 EGD）** 能量档位 τ_E ∈ {Green, Yellow, Orange, Red}：
- Green：SoC > 0.50，全部能力；
- Yellow：(0.30, 0.50]，关闭冗余探测，降低采样率；
- Orange：(0.15, 0.30]，锁定低功率阻抗、只保关键任务、禁止长距离移动；
- Red：≤ 0.15，强制 safe-stop 或回充，拒绝新任务。
- **回充保留（endurance promise）**：E_reserve = E_return(δ_ret) 为以概率 ≥ 1−δ_ret 安全回到充电桩所需能量；任何任务的能量契约必须满足 E_task + E_reserve ≤ E_rem。

**定义 167（移动操作能量证书 J_energy）** J_energy = (E_pred, E_actual, R_E, SoC_after, T_rem_est, τ_E, hash)。**有效**当且仅当 |R_E − 1| ≤ ε_E ∧ SoC_after ≥ SoC_floor ∧ EV-energy 证据链（seq_id/hash）连续。

**定义 168（能量耦合闭环 ECOL）** 算子 ECOL(M, scene, intent, T, delta_f_req)：
```
① SSM: z_scene ← R_scene.update(telemetry_obs)
② EARC: C_rt^E ← build_energy_contract(z_scene, intent, T, SoC_t)
③ WBEA: λ* ← solve_whole_body_energy(C_rt^E, P_budget(SoC_t, thermal))
④ EMPP: b* ← pareto_knee_placement(T, λ*, scene)
⑤ 迁移: move_base_to(b*) under λ*_loco
⑥ CIEC→EEIS: K_safe^E ← compile_with_energy(C_intent, π_scene, λ*_manip, delta_f_req)
⑦ Dispatch: send(K_safe^E.best, Cert_eeis, E_clause)
⑧ Execute: telemetry, P_meas, E_actual ← wait_contact_and_meter()
⑨ EPIR: S_shadow.append(EV_exec, EV-energy)
⑩ EGD: τ_E ← energy_guard(SoC_after, E_reserve); if τ_E ≥ Orange: degrade_or_return()
```

### IP-161 EEMM（能量证据与续航模型）

```python
class EnergyEvidenceModel:
    def __init__(self, e_cap, sigma_e=0.01, dt=0.1):
        self.e_cap = e_cap
        self.soc = 1.0
        self.sigma_e = sigma_e
        self.dt = dt
        self.history = deque(maxlen=200)

    def power(self, v_base, tau_base, terrain, F_e, xdot_e, K, payload, p_comp):
        p_loco = (terrain.c_roll * self.m * 9.81 * v_base
                  + terrain.c_aero * v_base ** 3
                  + abs(tau_base * v_base) / terrain.eta_base)
        p_manip = (abs(F_e * xdot_e) / self.eta_arm
                   + self.c_k * np.linalg.norm(K) * np.linalg.norm(xdot_e) ** 2
                   + self.c_g * payload * 9.81 * max(0.0, xdot_e)
                   + self.p_hold)
        return self.p_idle + p_loco + p_manip + p_comp

    def predict_tce(self, policy, horizon=3000, n_mc=128):
        samples = []
        for _ in range(n_mc):
            soc, t = self.soc, 0
            while soc > self.so_c_reserve_min and t < horizon:
                p = policy.sample_power()
                soc -= (p * self.dt) / self.e_cap
                soc += np.random.normal(0, self.sigma_e)
                t += 1
            samples.append(t * self.dt)
        return np.percentile(samples, [10, 50, 90])

    def build_evidence(self, e_pred, e_actual, soc_after, t_rem):
        ev = dict(t=time.time(), soc=soc_after, e_pred=e_pred,
                  e_actual=e_actual, r_e=e_pred / max(e_actual, 1e-6),
                  t_rem=t_rem)
        ev['hash'] = hashlib.sha256(json.dumps(ev).encode()).hexdigest()[:16]
        self.history.append(ev)
        return ev
```

### IP-162 EMPP（能耗-可操作度帕累托选点）

```python
def pareto_knee_placement(task, lambda_loco, scene, b_cur, samples=64):
    opts = []
    for b in sample_base_poses(task, samples):
        if not reachable(b, task) or collision(b, scene):
            continue
        w = yoshikawa(b, task)                         # 可操作度
        e_move = integrate(lambda_loco * P_budget, move_cost(b_cur, b))
        e_manip = integrate(P_manip_model, task, b)
        opts.append((b, w / w_max, (e_move + e_manip) / e_ref))
    front = nondominated(opts, key=lambda o: (o[1], -o[2]))   # max w, min E
    if not front:
        return None
    return min(front, key=lambda o: (o[1] - w_min) / max(o[2] - e_min, 1e-6))
```

```python
def solve_whole_body_energy(contract, p_budget, thermal):
    best = None
    for lam_loco in np.linspace(0.0, 1.0, 21):
        lam_manip = 1.0 - lam_loco
        if not coupled_feasible(lam_loco, lam_manip, thermal):
            continue
        u = task_utility_loco(lam_loco) + task_utility_manip(lam_manip)
        soc_after = predict_soc(p_budget, lam_loco, lam_manip)
        if soc_after < contract.e_clause.so_c_floor:
            continue
        if not energy_contract_ok(contract, lam_loco, lam_manip):
            continue
        if best is None or u > best.u:
            best = Allocation(lam_loco, lam_manip, u, soc_after)
    return best or DEGRADE_TO_ORANGE
```

### IP-164 EARC（能量感知契约）

```python
class EnergyAwareContract:
    def __init__(self, base_ertc, e_clause):
        self.base = base_ertc
        self.e = e_clause

    def admissible(self, k_safe, soc):
        if soc < self.e.so_c_floor:
            return False
        e_pred = predict_task_energy(k_safe)
        return (e_pred <= self.e.e_task_max
                and P_free_energy(k_safe) <= self.e.p_peak_max
                and self._monotone_ok(k_safe, soc))

    def _monotone_ok(self, k, soc):
        # 电量越低，允许的阻抗集合越小
        return np.linalg.norm(k) <= k_max_for_soc(soc)
```

### IP-165/166 PCE+++++ 与 EGD

```python
TIERS = [(0.50, 'Green'), (0.30, 'Yellow'), (0.15, 'Orange'), (0.0, 'Red')]

def energy_tier(soc):
    for thr, name in TIERS:
        if soc > thr:
            return name
    return 'Red'

def energy_guard(soc, e_reserve, e_task, e_cap, delta_ret=0.01):
    tier = energy_tier(soc)
    if e_task + e_reserve > soc * e_cap:
        return 'Red' if soc <= 0.15 else 'Orange'
    return tier

def degrade_by_energy(tier, M):
    if tier == 'Green':
        return M
    if tier == 'Yellow':
        M.budget.B_probe *= 0.5
        M.scene_model.update_rate *= 0.5
    elif tier == 'Orange':
        M.eeis.lock_low_power_impedance()
        M.task_manager.keep_only_critical()
    elif tier == 'Red':
        M.base.return_to_charge_or_safe_stop()
    return M
```

### IP-167 J_energy 与 IP-168 ECOL

```python
def build_energy_certificate(e_pred, e_actual, soc_after, t_rem, tier):
    r_e = e_pred / max(e_actual, 1e-6)
    ok = abs(r_e - 1) <= EPS_E and soc_after >= so_c_floor
    return dict(e_pred=e_pred, e_actual=e_actual, r_e=r_e,
                soc_after=soc_after, t_rem=t_rem, tier=tier,
                valid=ok, hash=sha256(...))

def energy_coupled_loop(M, scene, intent, task, delta_f_req):
    scene.update(M.telem_force, M.telem_pos)
    contract = M.earc.build(scene.top(), intent, task, M.eeis.soc)
    lam = solve_whole_body_energy(contract, M.power_budget(), M.thermal)
    b = pareto_knee_placement(task, lam.loco, scene, M.base.pose)
    M.base.move_to(b, lam.loco)
    k_safe = M.eeis.compile_with_energy(intent, scene.priors(), lam.manip, delta_f_req)
    ev_exec, e_actual = M.exec_probe(k_safe)
    M.epir.append(ev_exec, e_actual)
    tier = energy_guard(M.eeis.soc, M.eeis.e_reserve, e_actual,
                        M.eeis.e_cap)
    if tier in ('Orange', 'Red'):
        degrade_by_energy(tier, M)
    cert = build_energy_certificate(contract.e_pred, e_actual,
                                    M.eeis.soc, M.tce().median, tier)
    return M, b, lam, k_safe, cert
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EEMM | O(H·n_mc) 预测 / O(1) 更新 | O(N_hist) | 能耗预测 MAPE ≤ 8%，SoC 估计 RMSE ≤ 2% |
| EMPP | O(S·(T_reach+T_manip)) | O(S) | 选点可达且 w ≥ w_min，单位任务能耗下降 ≥ 15% |
| WBEA | O(K)（K 个分配候选） | O(1) | Σλ ≤ 1、热约束满足、SoC_after ≥ SoC_floor |
| EARC | O(1)/契约检查 | O(1) | 单调包络 K_acc(SoC₂) ⊆ K_acc(SoC₁) |
| EGD | O(1) | O(1) | 档位单调，Red 拒绝新任务 |
| J_energy | O(1) 生成 / O(chain) 校验 | O(1) | |R_E−1| ≤ ε_E，证据链完整 |

**正确性定理（ESC，Energy-Safety Certificate）**：
假设 A66–A70 成立：**(A66)** SoC 动力学有界，模型误差 w_t 零均值、方差有界；**(A67)** 功率分解可加，逼近误差 ≤ ε_P；**(A68)** EMPP 采样集包含满足 w ≥ w_min 的可行膝点；**(A69)** 当 SoC ≥ θ_E 时 WBEA 存在可行分配，否则 EGD 必然触发；**(A70)** EPIR 的 seq_id+hash 保证 EV-energy 证据链完整。

则：
1. **能耗可审计性**：以概率 ≥ 1−δ，能量证书满足 |R_E−1| ≤ ε_E，工程师可据此复算续航承诺。
2. **单调安全包络**：SoC₁ ≥ SoC₂ ⇒ 𝒦_acc(SoC₂) ⊆ 𝒦_acc(SoC₁)，低电不会放开更激进的阻抗。
3. **回充可达性**：若契约能量可行且 E_task + E_reserve ≤ E_rem，则 P(安全返回充电桩) ≥ 1−δ_ret。
4. **降级正确性**：τ_E 随 SoC 单调不升；Red 档不执行新任务，只执行 safe-stop/回充。

## 2. 关键推导：能量单调安全包络

设操作功率对阻抗近似线性：P_manip(K) = a·||K|| + b（a > 0），任务时长 T。契约要求：

```
P_peak(K) ≤ P_peak_max                         (1)
E_task(K) + E_reserve ≤ SoC · E_cap             (2)
E_task(K) ≈ (a·||K|| + b)·T
```

由 (1)(2) 得：

```
||K|| ≤ [ min(P_peak_max, (SoC·E_cap − E_reserve)/T) − b ] / a
      =: K_max(SoC)
```

因 SoC₂ ≤ SoC₁ ⇒ (SoC₂·E_cap − E_reserve)/T ≤ (SoC₁·E_cap − E_reserve)/T ⇒ K_max(SoC₂) ≤ K_max(SoC₁)，故 𝒦_acc(SoC₂) ⊆ 𝒦_acc(SoC₁)。**单调安全包络成立。**

由此还得到**任务准入必要条件**：

```
SoC ≥ (E_task + E_reserve) / E_cap
```

数值例：E_cap = 500 Wh，E_reserve = 60 Wh，某移动操作任务 E_task = 40 Wh，则 SoC_min = 100/500 = 0.20。即使 EGD 的 Orange 阈值是 0.15，该任务也会在 20% 处被 EARC 提前拒绝——这正是「能量契约先于执行」的价值。

### IP-161 EEMM（能量证据与续航模型）

```python
class EnergyEvidenceModel:
    def __init__(self, e_cap, sigma_e=0.01, dt=0.1):
        self.e_cap, self.soc, self.sigma_e, self.dt = e_cap, 1.0, sigma_e, dt
        self.history = deque(maxlen=200)

    def power(self, v_base, tau_base, terrain, F_e, xdot_e, K, payload, p_comp):
        p_loco = (terrain.c_roll * self.m * 9.81 * v_base
                  + terrain.c_aero * v_base ** 3
                  + abs(tau_base * v_base) / terrain.eta_base)
        p_manip = (abs(F_e * xdot_e) / self.eta_arm
                   + self.c_k * np.linalg.norm(K) * np.linalg.norm(xdot_e) ** 2
                   + self.c_g * payload * 9.81 * max(0.0, xdot_e)
                   + self.p_hold)
        return self.p_idle + p_loco + p_manip + p_comp

    def predict_tce(self, policy, horizon=3000, n_mc=128):
        samples = []
        for _ in range(n_mc):
            soc, t = self.soc, 0
            while soc > self.so_c_reserve_min and t < horizon:
                soc -= (policy.sample_power() * self.dt) / self.e_cap
                soc += np.random.normal(0, self.sigma_e)
                t += 1
            samples.append(t * self.dt)
        return np.percentile(samples, [10, 50, 90])

    def build_evidence(self, e_pred, e_actual, soc_after, t_rem):
        ev = dict(t=time.time(), soc=soc_after, e_pred=e_pred,
                  e_actual=e_actual, r_e=e_pred / max(e_actual, 1e-6),
                  t_rem=t_rem)
        ev['hash'] = hashlib.sha256(json.dumps(ev).encode()).hexdigest()[:16]
        self.history.append(ev)
        return ev
```

```python
def pareto_knee_placement(task, lambda_loco, scene, b_cur, samples=64):
    opts = []
    for b in sample_base_poses(task, samples):
        if not reachable(b, task) or collision(b, scene):
            continue
        w = yoshikawa(b, task)
        e_move = integrate(lambda_loco * P_budget, move_cost(b_cur, b))
        e_manip = integrate(P_manip_model, task, b)
        opts.append((b, w / w_max, (e_move + e_manip) / e_ref))
    front = nondominated(opts, key=lambda o: (o[1], -o[2]))
    if not front:
        return None
    return min(front, key=lambda o: (o[1] - w_min) / max(o[2] - e_min, 1e-6))
```

```python
def solve_whole_body_energy(contract, p_budget, thermal):
```

### IP-165/166 PCE+++++ 与 EGD

```python
TIERS = [(0.50, 'Green'), (0.30, 'Yellow'), (0.15, 'Orange'), (0.0, 'Red')]

def energy_tier(soc):
    for thr, name in TIERS:
        if soc > thr:
            return name
    return 'Red'

def energy_guard(soc, e_reserve, e_task, e_cap):
    if e_task + e_reserve > soc * e_cap:
        return 'Red' if soc <= 0.15 else 'Orange'
    return energy_tier(soc)

def degrade_by_energy(tier, M):
    if tier == 'Yellow':
        M.budget.B_probe *= 0.5
        M.scene_model.update_rate *= 0.5
    elif tier == 'Orange':
        M.eeis.lock_low_power_impedance()
        M.task_manager.keep_only_critical()
    elif tier == 'Red':
        M.base.return_to_charge_or_safe_stop()
    return M

def voi_energy(pi, meta_voi, cost_cog, cost_exec, e_task, e_max, tj, tj_max):
    return (meta_voi - cost_cog - cost_exec
            - LAM_E * e_task / e_max
            - LAM_T * max(0.0, tj - tj_max))
```

```python
def build_energy_certificate(e_pred, e_actual, soc_after, t_rem, tier):
    r_e = e_pred / max(e_actual, 1e-6)
    ok = abs(r_e - 1) <= EPS_E and soc_after >= so_c_floor
    return dict(e_pred=e_pred, e_actual=e_actual, r_e=r_e,

def energy_coupled_loop(M, scene, intent, task, delta_f_req):
    scene.update(M.telem_force, M.telem_pos)
    contract = M.earc.build(scene.top(), intent, task, M.eeis.soc)
    lam = solve_whole_body_energy(contract, M.power_budget(), M.thermal)
    b = pareto_knee_placement(task, lam.loco, scene, M.base.pose)
    M.base.move_to(b, lam.loco)
    k_safe = M.eeis.compile_with_energy(intent, scene.priors(), lam.manip, delta_f_req)
    ev_exec, e_actual = M.exec_probe(k_safe)
    M.epir.append(ev_exec, e_actual)
    tier = energy_guard(M.eeis.soc, M.eeis.e_reserve, e_actual, M.eeis.e_cap)
    if tier in ('Orange', 'Red'):
        degrade_by_energy(tier, M)
    cert = build_energy_certificate(contract.e_pred, e_actual,
```

| 组件 | 时间 | 空间 | 正确性 |

**正确性定理（ESC）**：若 A66–A70 成立（SoC 有界随机动力学、功率可加逼近、EMPP 可行膝点、WBEA 可行分配或 EGD 触发、EPIR 证据链完整），则：
1. 能量证书以概率 ≥ 1−δ 满足 |R_E−1| ≤ ε_E；
2. SoC₁ ≥ SoC₂ ⇒ 𝒦_acc(SoC₂) ⊆ 𝒦_acc(SoC₁)（单调安全包络）；
3. 契约可行且 E_task + E_reserve ≤ E_rem ⇒ P(安全回充) ≥ 1−δ_ret；
4. τ_E 随 SoC 单调不升，Red 档不执行新任务。
