### 0.1 本轮可一手核验的事实

## 1. 直觉：抓取是「坐标系握手」，技能是「物体坐标系里的动词」

### 1.1 灵感 1（机械臂抓取）→ 抓取不是「抓住没有」，而是「物体从此以什么位姿挂在手上」

在桌面操作里，任务通常是**相对物体和容器**定义的：把杯子挂到架上、把插头插进插座、把药瓶拧开、把电池取出来。策略输出的却是 EE 位姿或关节角。于是中间存在一个被大多数端到端策略**隐式学习**的量：

> 夹爪闭合之后，物体相对 EE 的刚体位姿 `X = T_{E←O}` 是什么？

如果 `X` 已知，机器人就可以直接控制「物体的位姿」，而不是控制「手的位姿」；如果 `X` 未知，每一个任务都必须从数据里间接学会「手怎么动，物体才会怎么动」。后者在训练分布内可行，但在未见物体、遮挡、透明/反光、不同抓法下非常脆弱——这正是最后一环（对齐、插入、旋转、释放）最容易崩的地方。

更重要的是：**对刚体物体，抓取是否成功，本身就是 `X` 是否能保持恒定的问题**。如果夹爪闭合后，物体在腕部相机里没有随手臂一起运动，或物体与 EE 的相对位姿在漂移，那么抓取失败（空夹、滑移、只夹到边缘）。因此「抓握确认」不需要一个独立的伪标签分类器；它可以由**刚体运动残差**直接检验。抓取在这里不是终点，而是一次「坐标系握手」：握手成功，物体成为机器人坐标系的刚体延伸；握手失败，就必须重抓或改用非抓取原语。

### 1.2 灵感 2（技能学习）→ 不要学 32 个任务，要学一小组「物体坐标系中的动词」

32 个任务并不是 32 种彼此独立的能力。把它们用「物体相对运动」重写，会得到一小组可复用的动词：

- **bind / rebind**：建立/重建物体与手的刚体连接；
- **move / transport**：把已绑定的物体从 A 移到 B；
- **align / insert / rotate**：让物体相对目标做精细位姿调整；
- **place / release / retreat**：把物体放到目标上并解除绑定；
- **push / sweep / topple / hook**：物体不可抓或不需要抓时的非抓取原语；
- **fold / zip / pour**：可变形或铰接物体的专用模式（必须从刚体模式切换出去）。

这些动词是**物体坐标系中的相对运动**，与机器人基座、桌面位置、背景、物体绝对位姿无关。于是同一个「align」技能可以服务插头、药瓶、杯子、电池；同一个「insert」技能可以服务以太网线、充电器、试管。任务身份只决定**动词序列和目标容器**，不决定「怎么动」。这正是「技能学习」相对「任务专家路由」的优势：路由只是把 32 个过拟合策略分开，而动词共享让 32 个任务互相成为彼此的数据增强。

### 1.3 合成：BOND——把抓取变成标定，把技能变成语法

**BOND = Binding-anchored Object-centric Neuro-symbolic Demonstration。**

三层加一层工程：

1. **绑定层（binding）**：在抓取瞬间估计 `b_t`（是否刚体绑定）、`X_t = T_{E←O}`（绑定变换）与证书 `C_t=(b_t, X_t, Σ_t, r_t)`；用刚体运动残差做抓握确认与滑移检测；证书无效时重抓或改用非抓取原语。
2. **技能层（verbs）**：在物体坐标系中学习 `bind / move / align / insert / rotate / place / release` 等动词；每个动词是一个带前置/后置条件的小策略头，共享主干；动作先表示为物体系 twist `ξ^O`，再通过 `ξ^E = Ad_{X_t} ξ^O` 映射到 EE 系，最后 IK 或直接下发 EE 目标。
3. **语法层（grammar）**：从 32 个任务的演示中归纳「动词序列」的潜在语法；测试时由语言指令与场景预测一个技能程序（不是按任务名查表），再按后置条件逐段执行。
4. **工程层**：固定 chunk、按端口隔离、延迟预算、动作良构性审计；所有新奇性都必须能落到「终态成功」或「失败可归因」上。

与当前草案的核心差异：

| 维度 | 当前草案 | BOND |
|---|---|---|
| 抓取 | 二值抓握确认 + 重抓 | 刚体绑定/标定事件 + 证书 + 滑移检测 |
| 技能 | 任务 token × 阶段 token 的专家混合 | 物体坐标系动词 + 语言条件化技能语法 |
| 泛化 | 推理期上下文调制/在线适配 | 物体系不变性 + 动词共享 + 视觉伺服闭环 |
| 证据 | teaser 榜单的随机数字 | 接口/schema/任务族结构 + 可预注册的离线实验 |
| 合规风险 | 多专家、在线更新可能被判非单模型 | 单 checkpoint、纯状态估计、无测试时权重更新 |

## 2. 为什么现有方案会卡在「最后一环」

1. **隐式物体坐标系**：端到端 VLA 必须从数据中同时学习「抓取变换」和「任务运动」。这两件事在数据里耦合，误差在接触阶段叠加；换物体/换抓法后，隐式映射漂移。
2. **任务级专家路由不解决坐标系问题**：即使路由到「插拔专家」，专家输出的仍是 EE 动作，物体相对 EE 的变换仍是隐式的；路由只是换了一个更强的隐式映射，没有把误差来源显式化。
3. **没有证书，失败只能到终态才发现**：空夹、滑移、只夹到边缘时，机器人会带着错误的对象继续执行；等到最后才发现失败，已经失去重抓窗口。
4. **1 维夹爪 + 无触觉**：不能靠手指关节/触觉直接读抓握状态；但 4 路视觉 + EE 位姿 + 夹爪标量足以做刚体运动检验。区别在于：**要检验的是「物体是否跟随手」，不是「夹爪是否闭合」**。
5. **可变形/铰接物体**：FoldTowel、ZipUp、PackBag、PackDoll、SyringeWaterTransfer 等任务不能用单一刚体绑定解释；必须显式切换到非刚体模式，而不是让一个刚体策略硬学。

## 3. 研究问题（本轮版）

- **Q1（绑定可观测性）**：在只有 1 维夹爪标量、无触觉、4 路相机的接口下，能否用刚体运动残差把「已绑定 / 未绑定 / 滑移」区分开？最小激励（probe）需要多大？
- **Q2（标定精度）**：绑定变换 `X` 的估计误差如何传播到物体位姿误差？对插入类任务（间隙 1–5 mm）需要多高的精度？哪些误差必须靠视觉伺服而非开环标定来吸收？
- **Q3（动词学习与迁移）**：能否从 32 个任务的演示中自动切分出物体系动词，并让在 24 个任务上学到的动词迁移到 8 个留出任务/未见物体？
- **Q4（技能语法的合规形态）**：语言 → 动词程序的解析能否避免「按任务名硬编码」？如果组委会把多技能头视为多模型，最严格的单头降级形态还剩多少收益？
- **Q5（工程语义）**：固定 chunk 下如何兼顾精细相位与延迟？N 端口共享后端时，`reset()` 与历史状态如何真正隔离？如何把延迟/动作良构性做成可审计的自证报告？

## 4. 设计原则

- **R1 物体坐标系优先**：任何技能的动作先在物体系定义，再映射到 EE/关节；不能映射到物体系的改动一律降级。
- **R2 证书门控**：绑定证书无效时，禁止执行依赖刚体假设的精细技能；宁可退回开环 VLA 或视觉伺服，也不带着错误坐标系硬做。
- **R3 动词而非任务**：技能头按「动词 × 物体类别 × 接触模式」组织，不按 32 个任务名组织；每个动词至少在 2 个任务上被复用才允许存在。
- **R4 刚体/非刚体模式切换**：对可变形、铰接、流体任务，显式切换到专用模式或退回 VLA；不允许用一个刚体策略假装能折毛巾。
- **R5 单 checkpoint、单 API、无测试时权重更新**：绑定估计是状态估计，技能选择是控制；不更新主干，不跨 episode 学习，避免合规风险。
- **R6 恢复是技能的一部分**：每个技能都带失败判据与 fallback（重抓 / 换抓法 / 非抓取 / 退回 VLA），而不是事后补一个恢复模块。
- **R7 可归因**：失败必须能落到 `bind / frame / motion / release / perception` 五类之一；不能归因的改动不进主线。

## 5. 最小可提交闭环（MVP）与退化链

**MVP = IP-01（绑定证书）+ IP-02（六个物体系动词）+ IP-04（非抓取/重抓退路）+ IP-05（数据引擎）+ IP-06（代理评测）+ IP-07（工程层）+ 一个通用 VLA 基线。**

先做「廉价决定性实验」再投入大算力：

1. 用官方 32 个数据集离线切分抓取区间，估计 `X`，测绑定检测 AUROC 与 `X` 误差（E701/E702）。
2. 用留出 episode 做「物体系动作回放」，测相对位姿误差是否比 EE 系基线下降 ≥20%（E703）。
3. 只有前两步通过，才训练技能库与语法；否则按预注册判据转向（见本文 §8 与产物区 §8）。

**严格退化链**：

- Level-0：绑定证书无效/置信度低 → 退回开环 VLA 或纯视觉伺服；
- Level-1：`X` 误差超过插入容差 → 禁用绝对物体系控制，仅保留相对视觉伺服；
- Level-2：技能语法解析失败 → 退回固定的「接近—抓取—搬运—放置—释放」模板；
- Level-3：非抓取原语不可用 → 跳过并重抓，最多 3 次；
- Level-4：整条新链路失效 → 退回纯基线 VLA（永远保留一个能跑通、可信度合规的最小提交）。

## 6. 预期贡献（可验收）

1. **把「抓取」从二值成功标志变成可标定的坐标系事件**：给出绑定状态/变换/证书的定义、可观测性条件与误差传播界；把「抓握确认」定义为可由刚体残差检验的假设，而不需要独立的伪标签分类器。
2. **给出物体系动词的技能学习框架**：把 32 个任务重写成动词序列，在物体坐标系中共享技能；给出跨任务迁移的预注册实验与可复现的数据切分。
3. **给出语言条件化技能语法的合规形态**：不按任务名硬编码，技能程序由语言 + 场景预测；预备单头降级形态并量化其代价。
4. **一套可复用的离线代理评测**：绑定检测、标定精度、动作回放、技能切分、五轴 OOD 切分；让后续迭代不依赖真机时段。
5. **把「最后一环」的失败拆成可干预的五类**：bind / frame / motion / release / perception；每一类都有对应的恢复动作与度量。
6. **工程可审计**：固定 chunk 的延迟预算、N 端口隔离、动作良构性报告，对齐官方可信度口径。

## 7. 本轮最大风险（一句话）

**绑定证书的可靠性完全取决于物体位姿估计器；而在挑战最需要泛化的场景（未见物体、遮挡、反光、可变形物体）里，估计器恰恰最容易「自信地错」——此时机器人会执行精确但错误的物体系动作，而「精确地错」比基线的「谨慎地不准」更危险。**

## 8. 下一轮迭代计划（深化与修剪，不推倒重来）

- **深化**：把绑定证书从「单帧估计」升级为「滑移感知的时序滤波器」；把物体系动词与图像视觉伺服（image-based visual servoing, IBVS）缝合成「粗—精」两段技能；补双手绑定与可变形模式。
- **修剪预案**：
  - 若 E701 绑定检测 AUROC < 0.8 → 砍掉证书门控，退回「学习式抓握分类器 + 开环 VLA」；
  - 若 E702 标定平移误差 > 1 cm → 砍掉绝对物体系控制，只保留相对视觉伺服；
  - 若 E703 回放误差下降 < 20% → 说明坐标系不可辨识，转向「VLA + 视觉伺服」而不是继续堆技能库；
  - 若 E705 跨任务迁移相对单体 VLA 增益 < 3 分 → 砍掉技能语法，保留物体系动词；
  - 若 E707 真机 A/B 无增益 → 瓶颈不在坐标系，转向感知/策略容量。
- **保留项**：IP-05（数据引擎）、IP-06（代理评测）、IP-07（工程层）在任何情况下不砍；它们是所有后续迭代的测量基础设施。

# 第 1 轮产物 · 创新点清单 v1：**BOND — Binding-anchored Object-centric Neuro-symbolic Demonstration**

## 0. 本轮结论摘要

**一句话路线**：把「机械臂抓取」重解释为**物体坐标系的建立与标定**，把「技能学习」重解释为**物体坐标系中的可组合动词 + 语言条件化技能语法**，再用一层工程层保证它在固定 chunk、N 端口、延迟审计的评测接口上真的能跑。

**核心因果链**：

```
抓取成功（对刚体物体）= 刚体绑定成立
        ⇒ 可估计 X = T_{E←O}
        ⇒ 可在物体坐标系下发动作 ξ^O
        ⇒ 精细技能（align/insert/rotate）只需学“物体怎么动”
        ⇒ 技能可跨任务/跨物体复用
        ⇒ 最后一环的误差从“隐式学习”变成“可标定 + 可伺服 + 可归因”
```

**与当前草案的三个关键差异**：

1. **抓取不是分类，是标定**：不做「抓握成功/失败」的伪标签二分类器；用刚体运动残差检验 `X` 是否恒定，顺带得到抓握确认与滑移检测。
2. **技能不是 32 个专家，是一组物体系动词**：不按任务名路由；按 `bind / move / align / insert / rotate / place / release` 等动词共享，任务身份只决定动词序列与目标。
3. **泛化不靠在线权重更新**：不更新主干、不跨 episode 学习；靠物体系不变性、动词共享与视觉伺服闭环。合规风险显著低于「多专家 + 在线适配」。

**预期收益形状**：对插拔、旋转、堆叠、整理这类「最后一环需要物体相对位姿精度」的任务收益最大；对 FoldTowel/ZipUp/PackBag 等可变形/铰接任务，收益主要来自「显式模式切换 + 退回 VLA」，而不是刚体绑定本身。

## 2. 创新点详述

### IP-01 · BindingCertificate 绑定证书（P0）

**动机**：接口只有 1 维夹爪开合、无触觉，抓握状态不可直接读出。但「抓住了没有」等价于「物体是否在刚体意义下跟随 EE」。因此不需要伪标签分类器，只需要检验一个刚体运动假设。

**与现有方案的差异**：现有做法把抓握当成策略输出的一部分（开环执行一条动作块），或训练一个抓握成功分类器。BOND 把抓握变成**坐标系标定**：估计 `X`、检验残差、输出证书；抓握确认与滑移检测是标定的副产物。

**技术可行性**：高。

- 抓取瞬间物体在腕部/头部相机中可见，可用预训练的 6D 位姿估计器或关键点跟踪器初始化 `X`。
- 抓取后做一次微小 probe（默认 2 cm 平移 + 5° 旋转，自由空间内安全），用物体相对 EE 的运动一致性精化 `X`；不 probe 时退回「抓取前位姿 + 夹爪几何」初始化。
- 残差 `r_t` 直接在观测上计算，不需要额外标签；滑移检测是残差的时序版本。

**所需资源**：数据 = 官方 32 数据集（只用于离线训练位姿/残差模型）；算力 = 单卡数小时到一天（位姿估计器蒸馏 + 残差校准）；接口 = 纯策略内部逻辑，不新增字段。

**落地步骤**：

1. 标定相机：腕部相机到 EE 的固定外参、头部双目外参；若数据卡未给外参，用离线手眼标定或已知 G1 CAD 初始化。
2. 抓取区间自动标注：夹爪闭合 + 物体与 EE 相对位姿开始保持一致 → 绑定开始；夹爪打开或残差突增 → 绑定结束。
3. 初始化 `X`：抓取前最后一帧的物体位姿 `T_{WO}` 与 EE 位姿 `T_{WE}` → `X = T_{WE}^{-1} T_{WO}`。
4. 可选 probe：执行已知 twist `ξ_probe`，跟踪物体运动，最小化刚体残差求 `X`；同时用 Fisher 信息选择 probe 方向。
5. 在线证书：窗口内残差 `r_t`、协方差 `Σ_t`、滑移标志；证书有效才允许物体系精细技能。
6. 失败响应：证书无效 → 重抓（换抓法/换角度）或非抓取原语；不做「带着错误 `X` 继续插」。

**风险**：① 抓取后物体被手/物体自身遮挡，位姿估计丢失 → 证书标记 invalid，退回视觉伺服；② 透明/反光/无纹理物体 → 位姿估计不可靠，需用双目/多视图或深度；③ probe 增加时间与碰撞风险 → 默认只在自由空间、低风险相位做；④ 标定外参未知 → 先做一次离线标定，不能假设。

**关键设计**：证书不是「抓握成功概率」，而是「刚体假设是否成立 + 变换是多少 + 不确定度多大」。它把「抓没抓住」和「抓得准不准」统一成一个可检验的量。

### IP-02 · ObjectVerb 物体系动词库（P0）

**动机**：32 个任务共享一小组物体相对运动。把这些动词学在物体坐标系里，可以去掉物体绝对位姿、背景、桌面位置等 nuisance 变量，让数据跨任务复用。

**与现有方案的差异**：现有 VLA 直接输出 EE/关节动作，任务差异由数据和容量吸收；BOND 先输出物体系 twist `ξ^O`（6 维），再映射到 EE（`ξ^E = Ad_X ξ^O`），最后 IK 或 EE 目标。动作空间更小、更不变、更可解释。

**技术可行性**：中–高。

- 训练数据：从官方演示中，对每个绑定区间用 `X` 把 EE 相对运动共轭到物体系，得到 `ξ^O` 标签；语言指令作为任务条件。
- 技能头：共享 VLA 主干 + K 个轻量动词头（或一个带技能 token 的单一头）；技能 token 由相位/语言/场景预测，不按任务名。
- 粗—精两段：`move/transport` 用物体系前馈 + 长 chunk；`align/insert/rotate` 用短 chunk + 图像视觉伺服（IBVS）闭环，吸收 `X` 的残余误差。
- 训练损失：`L = L_BC(ξ^O) + λ1 L_bind + λ2 L_relpose + λ3 L_termination`；`L_bind` 用绑定区间自监督，`L_relpose` 用物体/目标相对位姿回归，`L_termination` 用后置条件是否达成。

**所需资源**：数据 = 32 数据集 + 自动相位标签；算力 = 8×A100 × 2–3 天（若微调 2–7B 主干）或 1×A100 × 数天（若只训轻量头 + 冻结主干）；接口 = 仍是单 `get_action`。

**落地步骤**：

1. 统一下载/解码 32 个 LeRobot v3.0 数据集，对齐 4 路相机、关节、EE、夹爪、语言。
2. 自动切分相位：reach / bind / lift / transport / align / insert/place / release；用夹爪、EE 速度、物体-EE 残差做变点检测。
3. 构造物体系演示：在绑定区间内，用 `X` 把 EE 动作共轭到物体系；对非绑定区间保留 EE 系动作。
4. 训练动词头：先训单头 BC 基线，再加技能 token；每个动词至少在 2 个任务上出现才保留。
5. 粗—精调度：自由空间用长 chunk；接触/插入用短 chunk + IBVS；切换只在技能边界。
6. 消融：EE 系 BC vs 物体系 BC；单头 vs 多头；有/无 IBVS。

**风险**：① 物体系动作的标签依赖 `X` 估计，误差会进训练目标 → 用高置信绑定区间 + 残差加权；② 动词切分错误 → 人工抽检 5%，F1 <0.8 不进入训练；③ 多头被看作多模型 → 预备单头 + 技能 token 形态；④ 物体系控制在目标位姿不可观测时退化 → 退回 EE 系/视觉伺服。

### IP-03 · SkillGrammar 语言条件化技能语法（P1）

**动机**：32 个任务不是孤立的，而是动词序列的不同组合。若能归纳出「动词语法」，就能把长尾任务写成已知动词的组合，而不是再学一个任务专家。

**与现有方案的差异**：任务专家路由是「按任务选模型」；技能语法是「按语言和场景选动词序列」。前者需要见过该任务；后者可以组合未见过的序列。

**技术可行性**：中。

- 从演示中切分出每个任务的动词序列，聚类得到少量「任务模板」；用概率文法/有限状态机表示。
- 语言侧用一个轻量 parser（可基于冻结 VLM 的 embedding + 小头）预测动词程序；训练标签来自演示的动词序列。
- 为避免「按任务名硬编码」：parser 只看语言 embedding 和场景摘要（物体类别、容器、初始关系），不看任务 ID；训练时做任务名遮蔽/同义改写增强。
- 合规形态：语法与技能头都在一个 checkpoint 内；若被判多模型，语法退化为「单头技能 token 序列」，仍需实测降级损失。

**所需资源**：数据 = 32 数据集 + 动词序列标签；算力 = 小（parser 可在冻结 VLM 上训练）；接口 = 无新增字段。

**落地步骤**：① 动词序列提取；② 文法/自动机归纳；③ parser 训练与任务名遮蔽；④ 执行器：按后置条件逐段执行，失败则触发对应 fallback；⑤ 留出任务组合测试（24 训 / 8 测）。

**风险**：① 语法过拟合 32 个任务 → 留出任务与同义指令测试；② parser 依赖语言模板 → 做指令改写增强；③ 组合爆炸/长程误差累积 → 每段后置条件检查 + 最大段数限制；④ 合规 → 单头降级。

### IP-04 · Fallback 非抓取/重抓退路（P0）

**动机**：Dex1 单自由度夹爪使某些抓法物理上不可行（宽物、薄片、需要拧转的盖子、钥匙）。硬学抓取会把可救的失败变成硬失败。

**与现有方案的差异**：不是「抓取失败后随机重试」，而是先做**可抓性判定**，再在 `grasp / regrasp / non-prehensile / VLA` 之间做有原则的选择。

**技术可行性**：高（规则 + 少量学习）。

- 可抓性：夹爪开口 5.5→0、物体宽度/厚度、接近方向间隙、是否需要旋转；规则版即可上线。
- 非抓取原语：push（推）、sweep（扫）、topple（倾倒）、hook（钩）；用数据检索 + 少量真机试错固化参数。
- 重抓：在候选抓取位姿中选「预期证书质量最高且碰撞风险最低」的一个；最多 3 次。
- 失败判据：绑定证书无效 / 残差突增 / 物体未随动 / 目标位姿误差超限。

**所需资源**：数据 = 官方数据检索 + 少量真机；算力 = 小；接口 = 无。

**落地步骤**：① 规则版可抓性；② 非抓取原语库；③ 重抓候选生成与打分；④ 与证书/技能的后置条件对接；⑤ 在 Unlock / PlugInEthernet / PickOutBatteries 等任务上 A/B。

**风险**：① 非抓取原语破坏场景（推倒其他物体）→ 限制单物体场景、设禁区；② 重抓循环 → 上限 3 次 + episode 内冷却；③ 可抓性规则误判 → 以证书/残差为准，规则只做先验。

### IP-05 · DataEngine 物体系数据引擎（P0）

**动机**：没有可信的内部标尺，一切创新都无法迭代；真机时段稀缺。官方 32 个数据集是唯一大规模、同 schema 的真机数据。

**与现有方案的差异**：不是「拿数据直接训一个大 VLA」，而是把数据加工成**物体系动词演示 + 绑定标签 + OOD 切分**，让每个创新点都能离线验收。

**技术可行性**：中–高。

**落地步骤**：

1. 下载/解码 32 个 LeRobot v3.0 数据集；统一键名与时间轴；AV1 解码为帧。
2. 用夹爪开合 + EE 速度 + 物体-EE 残差做变点检测，切分 reach/bind/lift/transport/align/insert/place/release。
3. 用预训练 6D 位姿/关键点模型离线估计物体位姿；对无 CAD 物体用类别级/关键点跟踪；人工抽检 5%。
4. 估计每个绑定区间的 `X`；用 probe 一致性筛选高置信样本。
5. 生成物体系动作标签：`ξ^O = Ad_{X^{-1}} ξ^E`（相对运动共轭）。
6. 构造 OOD 切分：留出物体实例 / 背景 / 位置 / 干扰物 / 遮挡；每轴至少 2 个任务。
7. 导出回放集：给定初始观测与目标，比较预测动作与演示动作的物体系误差。

**所需资源**：数据 = 官方 32 数据集；算力 = 1×A100 × 数天（离线位姿/切分）；接口 = 无。

**风险**：① 位姿估计在无纹理物体上失败 → 多视图/双目/深度 + 人工抽检；② 自动切分噪声 → 双标注器一致性检查；③ 数据泄漏 → 严格按物体/场景切分，不按 episode 随机切。

### IP-06 · BindBench 代理评测 + 五类失败分解（P0）

**动机**：真机评测是预约时段；官方榜单不可得。需要一个与真机相关、可快速迭代的代理评测。

**与现有方案的差异**：常规代理评测只看任务成功率；BindBench 把成功分解为 `bind / frame / motion / release / perception` 五类，直接对应 BOND 的组件，能做边际收益排序。

**技术可行性**：中–高。

- 离线：绑定检测、`X` 误差、物体系动作回放、技能切分。
- 代理真机：用官方 WMA/WLA 世界模型或 MuJoCo/Isaac 重建子集场景（方块、杯子、插头、药瓶），测插入/堆叠/放置。
- 真机锚点：每轮 2–3 个真机时段，做 Spearman 相关；若 |r| < 0.3，触发剪枝（见 §8）。

**落地步骤**：① 离线指标；② 五类失败标注；③ 代理场景；④ 真机锚点；⑤ 相关性报告。

**风险**：代理与真机相关性不足（最大风险）→ 预注册剪枝；代理场景过窄 → 多任务子集；世界模型偏差 → 只用于排序，不用于最终结论。

---

### IP-07 · AnchorOps 工程层（P0）

**动机**：接口是逐 chunk 调用、N 端口、延迟与动作良构性被记录。工程事故会直接判失败。

**与现有方案的差异**：把工程要求变成可导出的产物，而不是「能跑就行」。

**关键点**：

- **固定 chunk**：README 把 `action_chunk_size` 定义为 `metadata` 中的整数；MVP 按固定值处理，不依赖运行时变更（避免利用未声明语义）。MVP 用固定 `T_a=4`（精度/延迟折中），另做 E713 扫 `T_a∈{1,2,4,8,16}`。精细相位靠短 chunk + IBVS，而不是运行时改 chunk。
- **端口隔离**：API 的 `get_action(obs)` 没有 port 参数；MVP 采用官方 Approach 1（每端口一个进程），最稳。若要共享后端，wrapper 必须显式传入 session id（连接/端口上下文），不能依赖全局状态。`reset()` 必须清空该 session 的全部历史。
- **延迟**：位姿估计 10–20 ms；技能头 3–5 ms；IK 1–2 ms；VLA 主干 50–70 ms；总 p99 目标 ≤100 ms。超时返回安全延拓 + 降级标记。
- **动作良构性**：限幅、jerk 上限、离群检测；平滑只作用于残差，不改均值；保留策略固有随机性，不做「拟人化噪声」。
- **审计**：延迟 p50/p99、chunk 边界失配计数、降级次数、动作离群率、每端口 reset 隔离自检。

**资源**：工程活；算力极小。

**风险**：① 共享后端并发串扰 → MVP 一端口一进程；② 过度平滑降成功率 → 只平滑残差；③ 固定 chunk 在精细相位不够 → E713 选型 + IBVS。

---

### IP-08 · Compliance 合规审计（P1）

**动机**：赛道是「通才模型」；多专家、在线更新、任务名分支都可能被质疑。

**合规清单**：

1. 单 checkpoint、单 API；技能头在 checkpoint 内，对外仍是一个 `get_action`。
2. 无测试时权重更新；绑定标定/技能选择都是状态估计与控制。
3. 无任务名硬编码；parser 只看语言 embedding + 场景摘要；训练做任务名遮蔽。
4. 只使用 `metadata` 声明的观测；不读评测侧私有信息；不依赖未声明的执行语义。
5. token 两处校验；N 端口连续；`reset()` 完全隔离。
6. 预备单头降级：把所有技能头蒸馏成一个技能 token 条件化的单头，实测降级损失。

**风险**：多技能头被判「多模型」→ 单头降级；语法被判「硬编码」→ 任务名遮蔽 + 同义指令测试；在线标定被误认为「在线学习」→ 明确是状态估计、无梯度更新。

---

### IP-09 · DualBind 双手绑定与相对协调（P1）

**动机**：ArrangePlates、FoldTowel、ZipUp、SyringeWaterTransfer 等任务需要双手协调；双手各自有夹爪与 EE 位姿，接口也提供两套。

**做法**：每只手一份绑定证书；物体系挂在主动手（如左手），从动手做相对对齐（如右手扶住/拉链/注射器）。协调变量是两只手之间的相对变换 `T_{E_L←E_R}`，而不是各自绝对位姿。技能包括 `hold`、`handover`、`coordinate`。

**风险**：双手同时遮挡 → 多视图； handover 时证书切换 → 用接触/相对位姿连续性做门控；复杂度高 → P1。

---

### IP-10 · SoftBind 可变形/铰接模式（P2）

**动机**：FoldTowel、PackBag、PackDoll、ZipUp、SyringeWaterTransfer 不满足单一刚体假设。

**做法**：用关键点/部件跟踪替代单一 `X`；定义 `soft binding`：物体的一部分随 EE，另一部分自由；技能切换到 `fold/zip/pour` 专用模式；若跟踪不可靠，直接退回 VLA。**不硬套刚体证书**。

**风险**：模式切换误判 → 用残差分布 + 任务先验；数据不足 → 只做 P2，不作为主押注。

## 3. 符号与定义（D1–D12）

| 符号 | 含义 |
|---|---|
| `W / E / O / T` | 基座系 / 末端系 / 物体系 / 目标（容器）系 |
| `T_{AB}` | B 在 A 中的位姿，∈ SE(3) |
| `X_t = T_{E←O}` | 绑定变换：物体在 EE 系中的位姿 |
| `b_t` | 绑定状态 ∈ {0,1}：物体是否刚体附着于 EE |
| `C_t` | 绑定证书 `(b_t, X_t, Σ_t, r_t, τ_t)` |
| `ξ^O, ξ^E` | 物体系 / EE 系 twist，∈ se(3) |
| `Ad_X` | SE(3) 伴随矩阵 |
| `σ` | 技能（动词） |
| `G` | 技能语法（动词序列的生成模型） |
| `Π` | 非抓取原语库 {push, sweep, topple, hook} |
| `F` | 失败分类 {bind, frame, motion, release, perception} |
| `ρ, δ, σ_c` | 绑定残差阈值 / 滑移阈值 / 证书协方差阈值 |

**定义 D1（绑定状态）**：`b_t=1` 当且仅当在时间窗 `[t-Δ,t]` 内，物体位姿与 EE 位姿满足刚体关系 `T_{WO}(s) = T_{WE}(s) X`（`X` 恒定），且在观测噪声下残差不超过阈值。

**定义 D2（绑定变换）**：`X_t = T_{E←O}` 为物体在 EE 系中的位姿；绑定期间视为分段恒定，滑移时允许缓慢漂移或跳变。

**定义 D3（绑定证书）**：
`C_t = (b_t, X_t, Σ_t, r_t, τ_t)`，其中 `Σ_t` 为 `X_t` 的协方差，`r_t` 为窗口刚体残差，`τ_t` 为时间戳。
证书**有效**当且仅当 `b_t=1`、`r_t ≤ ρ`、`tr(Σ_t) ≤ σ_c²`、`τ_t` 在新鲜度窗口内。

**定义 D4（物体系动作）**：技能输出物体系 twist `ξ^O_t ∈ se(3)`；映射到 EE 系
`ξ^E_t = Ad_{X_t} ξ^O_t`，
再由指数映射得到 EE 目标 `T_{WE}^{target} = exp(ξ^E_t) T_{WE}(t)`；`joint` 模式下再解 IK。

**定义 D5（技能）**：`σ = (pre_σ, post_σ, π_σ, β_σ, fallback_σ)`，分别为前置条件、后置条件、策略、终止判据、失败回退。

**定义 D6（技能语法）**：`G = (S, N, T, P)`；终结符 `T` 为带参数的技能，非终结符 `N` 为任务模板/阶段；一个任务程序是 `G` 的一个推导。测试时由语言 `ℓ` 与场景摘要 `s` 预测程序 `p = (σ_1, …, σ_m)`。

**定义 D7（绑定感知策略）**：`π(a | o, ℓ, σ, C_t)`；若 `C_t` 无效，禁止执行 `pre_σ` 中含「刚体绑定」的精细技能。

**定义 D8（可抓性）**：`f(g, o) ∈ {0,1}`：在 Dex1 单自由度、夹爪开口 5.5→0 的约束下，抓取位姿 `g` 是否物理可行（宽度、厚度、接近间隙、是否需要旋转）。

**定义 D9（滑移信号）**：`s_t = 1` 若 `r_t > ρ` 或 `‖log(X_t^{-1} X_{t-1})‖ > δ`；连续 `k` 步滑移 → 证书失效 → 重抓/非抓取。

**定义 D10（重抓）**：`g' = argmax_g E[Q(C_{t+Δ}) | g] - λ·risk_collision(g)`；最多 3 次，冷却窗口防循环。

**定义 D11（技能切分）**：把 episode 切成区间 `[t_i, t_{i+1})` 并打上动词标签；由夹爪、EE 速度、物体-EE 残差的变点检测 + 聚类得到。

**定义 D12（失败分解）**：
`P(success) ≈ P(bind) · P(frame | bind) · P(motion | frame) · P(release | motion) · P(perception gate)`；
每一项由 BindBench 的阶段标签估计，用于定位瓶颈。

class BONDPolicy:

                "observation.language": [0],

                "observation.images.cam_right_high": [0],
                "observation.images.cam_left_wrist": [-2, 0],
                "observation.images.cam_right_wrist": [-2, 0],
                "observation.state.left_arm":  [-4, -2, 0],
                "observation.state.right_arm": [-4, -2, 0],
                "observation.state.left_ee_pose_gripper_base":  [-2, 0],
                "observation.state.right_ee_pose_gripper_base": [-2, 0],
                "observation.state.left_gripper":  [-2, 0],
                "observation.state.right_gripper": [-2, 0],
                "observation.state.lower_body": [-2, 0],
            },
            "image_resize": {
                "observation.images.cam_left_high":  [240, 320],
                "observation.images.cam_right_high": [240, 320],
                "observation.images.cam_left_wrist":  [240, 320],
                "observation.images.cam_right_wrist": [240, 320],
            },
            "action_chunk_size": self.chunk_size,
            "token": os.environ["UNIBOT_SUBMISSION_TOKEN"],
        }

    def reset(self, session_id=None):
        # 官方 reset() 无参数；若一进程一端口，session_id 可为 None/固定值。
        # 若共享后端，wrapper 必须把端口/session 传进来，不能靠全局变量。
        self.sessions.pop(session_id, None)

    def get_action(self, obs, session_id=None):
        t0 = time.perf_counter()
        s = self.sessions.setdefault(session_id, Session())

        # 1) 绑定证书（抓握确认 + 标定 + 滑移）
        cert = self.bind.update(obs, s)

        # 2) 语言 + 场景 -> 技能程序（不按任务名查表）
        program = self.grammar.parse(obs["observation.language"], obs, cert)

        # 3) 选当前技能；证书无效时降级
        sigma = program.current
        if sigma.requires_binding and not cert.valid:
            a = self.fallback(obs, s, cert, sigma)
        else:
            # 4) 物体系动作 -> EE 动作
            xi_O = self.verbs.act(sigma, obs, cert)          # (6,)
            if cert.valid:
                xi_E = adjoint(cert.X) @ xi_O
                a = ee_target_from_twist(obs, xi_E, self.chunk_size)
            else:
                a = self.model.base_act(obs, self.chunk_size)  # 退回 VLA
            # 5) 粗—精：接触相位用视觉伺服修最后几毫米
            if sigma.name in ("align", "insert", "rotate"):
                a = self.visual_servo(obs, a, sigma)

        # 6) 审计 + 打包
        a = self.audit.clamp_and_log(a, obs, t0, self.tau_budget_ms)
        return self.pack(a, obs)

    def fallback(self, obs, s, cert, sigma):
        # 证书无效：先判可抓性；不可抓/滑移 -> 非抓取原语；否则重抓
        if s.n_retry < 3 and not self.detector.feasible(obs, sigma):
            return self.pack(self.prim.act(obs, s), obs)
        if s.n_retry < 3:
            s.n_retry += 1
            return self.pack(self.verbs.regrasp(obs, cert), obs)
        return self.pack(self.model.base_act(obs, self.chunk_size), obs)

    def pack(self, a_ee, obs):
        # a_ee: dict with left/right EE 6D targets and gripper commands, shape (T,·)
        return {
            "meta.token": os.environ["UNIBOT_SUBMISSION_TOKEN"],
            "action.left_ee_pose_gripper_base":  a_ee["left_ee"].astype(np.float32),
            "action.right_ee_pose_gripper_base": a_ee["right_ee"].astype(np.float32),
            "action.left_gripper":  a_ee["left_grip"].astype(np.float32),
            "action.right_gripper": a_ee["right_grip"].astype(np.float32),
            "action.pivot": a_ee["pivot"].astype(np.float32),
        }

class BindingEstimator:
    def __init__(self, pose_head, rho=0.01, sigma=0.005, window=6):
        self.pose_head = pose_head
        self.rho, self.sigma, self.window = rho, sigma, window
        self.buf = []

    def update(self, obs, session):
        T_WE = ee_pose(obs, side="right")             # 选主动手；双手见 IP-09
        T_WO, conf = self.pose_head(obs)              # 物体在基座系的位姿
        grip = float(obs["observation.state.right_gripper"][-1])
        self.buf.append((T_WE, T_WO, conf, grip))
        self.buf = self.buf[-self.window:]

        # 只在夹爪闭合且位姿置信度足够时估计绑定
        if grip > GRIP_CLOSED_THRESH or len(self.buf) < 3:
            return Certificate(b=False, X=session.last_X, Sigma=np.eye(6)*1e3,
                               r=np.inf, t=now())

        # 用相对运动估计 X：T_WO(t+1) T_WO(t)^-1 ≈ T_WE(t+1) X X^-1 T_WE(t)^-1
        X = session.last_X if session.last_X is not None else init_X(self.buf[-3:])
        X = refine_X(self.buf, X)                     # 最小二乘/手眼标定
        r = rigid_residual(self.buf, X)               # 刚体一致性残差
        Sigma = covariance_from_residual(self.buf, X)
        b = (r <= self.rho) and (np.trace(Sigma) <= self.sigma**2) and (conf > 0.5)
        session.last_X = X
        return Certificate(b=b, X=X, Sigma=Sigma, r=r, t=now())

    def probe(self, obs, session, twist=(0.02, 0, 0, 0, 0, 0.08)):
        # 可选：自由空间内做一次小 probe，提升 X 的可辨识性
        # 先下发 twist，再收集 window 帧，调用 update() 精化
        return twist

## 5. 推导（L1–L7）

**引理 L1（物体系不变性）**
若 `X` 精确且物体刚体，则物体系控制律 `T_{WO}(t+1) = T_{WO}(t) ΔT` 与 `T_{WO}(0)`、基座位置、背景无关。证明：`T_{WE} = T_{WO} X^{-1}`，控制律只依赖相对变换 `ΔT` 与 `X`，不依赖绝对位姿。∎
**含义**：同一技能可跨桌面位置/背景复用；这是 BOND 相对 EE 系 BC 的核心归纳偏置。

**引理 L2（标定误差传播）**
设 `X̂ = X exp(ε)`，EE 位姿误差为 `δ_E`，则物体位姿误差
`δ_O = Ad_{X^{-1}} δ_E + ε + O(‖ε‖²)`。
对插入任务，若间隙为 `c`，要求 `‖δ_O‖ ≤ c/2`，于是标定误差预算
`‖ε‖ ≤ c/2 − ‖Ad_{X^{-1}}‖·‖δ_E‖`。
**含义**：`c=2 mm` 时，若 EE 跟踪误差 ~1 mm，则 `X` 的平移误差必须 ≲1 mm；单靠单帧位姿估计不够，最后几毫米必须靠视觉伺服闭环。∎

**引理 L3（probe 可辨识性，证明草图）**
把物体位姿观测写成 `y_t = h(T_{WE}(t) X) + η_t`。`X` 的 Fisher 信息沿 probe twist `ξ` 的分量随 `‖ξ‖²` 与物体特征雅可比 `J_h` 增大；在 `η` 为高斯且 `J_h` 满秩时，存在足够大的 probe 使 `X` 可辨识。所需 probe 幅度与信噪比成反比；因此 probe 长度是可调的信息—时间预算。∎
**含义**：默认 2 cm / 5° 是工程起点，E709 扫最优；遮挡严重时不 probe，改用视觉伺服。

**引理 L4（技能组合）**
若每个技能的后置条件 `post_σi` 蕴含下一个技能的前置条件 `pre_σi+1`，则程序可执行；无恢复时成功率 `∏ p_i`，有恢复时按 Markov 链 `P = ∏ (p_i + (1-p_i) r_i p_i')`。∎
**含义**：失败可以按技能段归因；恢复只对「可恢复段」有价值。

**引理 L5（动词共享的样本复杂度，启发式）**
若 `K` 个动词在 `M` 个任务间共享，且每个动词有 `n` 个样本，则共享参数模型的泛化间隙按 `O(√((K log M + d)/n))` 增长，而不是按 32 个独立任务的 `O(√(32d/n))`。∎
**含义**：32 个任务互相成为数据增强；这是「动词而非任务专家」的理论动机（需 E705 实证）。

**引理 L6（非抓取可达性）**
对接触点 `p`、法向 `n`、摩擦系数 `μ`，可实现的物体 twist 集合是摩擦锥诱导的凸锥 `C(p,n,μ)`；若目标 twist 不在 `C` 内，则该 push/sweep 原语不可行，必须换接触点或换技能。∎
**含义**：非抓取不是万能退路，需几何可行性检查。

**引理 L7（合规性）**
绑定标定是状态估计（无梯度更新），技能选择是控制；系统对外仍是一个 checkpoint、一个 `get_action`。若技能库用多头实现，单头蒸馏的性能差 `Δ_single` 是可离线测量的上界；合规风险由 `Δ_single` 界定。∎
**含义**：BOND 的合规风险显著低于「在线权重更新 + 多专家路由」，但仍需准备单头降级。

## 6. 复杂度与资源预算

| 组件 | 域 | 时间/步 | 空间 | 正确性锚 |
|---|---|---|---|---|
| VLA 主干（冻结或轻微微调） | 在线 | 50–70 ms | 1×权重（端口共享时需并发） | 基线 |
| 物体位姿/关键点估计 | 在线 | 10–20 ms | 小 | D1/D2 |
| 绑定残差/证书 | 在线 | <1 ms | O(window) | L2 |
| 动词头 | 在线 | 3–5 ms | ≤5% 主干 | D4 |
| 语法 parser | 在线 | 2–3 ms | 小 | D6 |
| IK（joint 模式） | 在线 | 1–2 ms | O(1) | D4 |
| 视觉伺服（仅接触相位） | 在线 | 5–10 ms | 小 | L2 |
| 审计/限幅 | 在线 | <1 ms | O(1) | IP-07 |
| 训练：位姿/切分/回放 | 离线 | 1×A100 × 数天 | 中 | D11 |
| 训练：动词头 + 语法 | 离线 | 8×A100 × 2–3 天（若微调主干） | 中 | L5 |
| 代理评测 | 离线 | 1×A100 × 数小时 | 小 | D12 |

**接口硬约束**：N 个连续端口；每端口独立完整交互；`reset()` 与历史状态隔离；token 两处校验；固定 `action_chunk_size`。MVP 采用「一端口一进程」；共享后端作为 P1 优化。

## 7. 实验设计（E701–E720）

| 实验 | 核心问题 | 关键判据 | 未达标处置 |
|---|---|---|---|
| **E701** | 绑定检测是否可辨识 | 留出物体 AUROC ≥0.90；95% 召回下 FPR ≤5% | <0.80 砍证书门控 |
| **E702** | `X` 标定精度 | 平移误差 ≤5 mm；旋转 ≤3°；probe 后 ≤2 mm/1° | >1 cm 只保留视觉伺服 |

## 9. 风险登记册与剪枝预案

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| **物体位姿估计在未见/遮挡/反光物体上失败** | 高 | 高 | 多视图/双目/深度；证书 invalid 即退回视觉伺服；不硬做 |
| **可变形/铰接物体违反刚体假设** | 高 | 中高 | IP-10 模式切换；FoldTowel/ZipUp/PackBag 默认退回 VLA |
| **标定误差 > 插入容差** | 中高 | 高 | 粗—精两段；最后几毫米 IBVS；E702 硬门槛 |
| **技能切分噪声污染训练** | 中 | 中 | 双标注一致率；人工抽检 5%；置信度加权 |
| **技能语法过拟合 32 任务** | 中 | 中 | 24/8 留出；任务名遮蔽；同义指令增强 |
| **多技能头被判「多模型」** | 中 | 高 | 单头蒸馏；合规预确认；黑名单任务名分支 |
| **固定 chunk 在精细相位不够** | 中 | 中 | E713 选型；IBVS 吸收；必要时 `T_a=1` |
| **N 端口并发/状态串扰** | 中 | 高 | 一端口一进程；`reset()` 全清；并发压测 |
| **延迟抖动被判不可信** | 中 | 中 | 延迟预算 + 降级兜底 + 审计报告 |
| **代理评测与真机不相关** | 中 | 中高 | E717 先行；<0.3 触发剪枝 |

**剪枝预案**：

- **必保**：IP-05（数据引擎）、IP-06（代理评测）、IP-07（工程层）。
- **优先**：IP-01（绑定证书）→ IP-02（物体系动词）；这两项决定 BOND 是否成立。
- **条件推进**：IP-03（语法，依赖 E704/E705）、IP-09（双手，依赖数据与真机）、IP-10（可变形，依赖位姿/部件跟踪）。
- **暂存**：IP-08 的审计部分并入 IP-07；单头蒸馏在合规确认后再做。

## 11. 本轮最值得押注的创新点（一句话）

**押注 IP-01 + IP-02：把「抓取」从二值成功标志升级为「物体坐标系的刚体标定证书」，再把「技能学习」从 32 个任务专家升级为「物体坐标系里的可复用动词」——这条链路直接攻击最后一环的误差来源（隐式抓取变换），而且不需要在线权重更新、不需要多模型路由，合规风险与工程复杂度都远低于当前草案。**

**最大风险（一句话）**：绑定证书的可靠性完全取决于物体位姿估计器；在最需要泛化的未见/遮挡/反光/可变形物体上，估计器最容易「自信地错」，从而让机器人执行精确但错误的物体系动作。
