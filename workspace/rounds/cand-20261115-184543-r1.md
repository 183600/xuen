# 第 9 轮（灵感循环第 9 轮；本轮灵感：「论文发表」×「可靠性」）
> **基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–531；引理 77–81；实验 E531–E550）。
> 本轮纪律：**可复现性 + 可靠性工程**。把每个运行时证书当作"一篇待发表的论文"：必须有 hash-chained 证据账本、分级可复现徽章、提交前的对抗式同行评审、anytime-valid 统计声明；再用可靠性工程的 CTMC 可用度、三模冗余认证、退化预算保证长期可信。

## 0. 直觉与动机

**灵感 1（论文发表 → 证书即论文 / 可复现性）**
直觉：论文的公信力来自"任何人拿到 artifact 都能复现 claim"。机器人证书同样应可被独立重放与检验，而不是只输出一个不可追溯的 `ok/ng`。核心创新：**证书即论文（Claim-as-Paper）**——每个证书 = claim 元组 + 哈希链证据 + 预注册判据 + 可复现徽章（Bronze/Silver/Gold）。更进一步，"同行评审"对应提交动作前的**内部对抗证伪门**：先让扰动探针尽力推翻自己的 claim，推不翻才允许执行。这直接回应论文界最臭名昭著的问题——`p-hacking`/可选停止：系统运行中会反复检验，必须用 anytime-valid 的 e-process，禁止"跑到达标就停"的过度声明。

**灵感 2（可靠性 → 长期可用度 / 冗余 / 退化预算）**
直觉：单次认证正确不够，要"长期可靠地产生可信证书"。可靠性工程给了三件称手工具：(i) CTMC 马尔可夫模型刻画 OK/DEGRADED/FAIL 的稳态可用度与 MTBF；(ii) 三模冗余认证——解析证明、数字孪生仿真、运行时监控三路独立出证书，多数表决；(iii) 退化预算——v8 的最大风险是"退化风暴"，用 token bucket 给退化次数一个硬上界，预算耗尽就请求安全停机而非继续抖动退化。Weibull 浴盆曲线则用于预测性维护。

**综合直觉**：v8 让系统"更能适应"，但也更"难被相信"。v9 的目标不是再堆一个感知模块，而是给整条闭环加一层**可复现的可信性（reproducible trustworthiness）**：一个 claim 只有既"能被独立重现"又"能被长期可靠地产出"，才配获得完全自主权。

## 1. 研究问题（轮次升级版）

- **Q1（在线可复现性）**：如何在 O(1) 主环开销下生成可独立重放的证据账本，并给出 Bronze/Silver/Gold 分级徽章，而把昂贵的重放放到离线/异步路径？
- **Q2（统计声明有效性）**：系统持续运行、反复检验阈值时，如何避免可选停止导致的过度声明，使"成功率 ≥ r₀"这类 claim 在任意停止规则下假阳性率 ≤ α？
- **Q3（长期可靠性）**：如何用冗余认证与退化预算，把长期软→硬退化频率压到可证明上界，同时不破坏 50Hz WCET 与 ≤2ms 感知预算？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P12）

**P10 证书即论文（Claim-as-Paper）**
每个证书显式拆成四元组：
```
Cert(c_t) = ( claim_t , evidence_t , prereg_t , badge_t )
```
其中 `evidence_t` 进哈希链账本，`prereg_t` 是执行前冻结的判据（防 HARKing），`badge_t ∈ {Gold, Silver, Bronze, None}` 由可复现性重放决定。

**P11 内部同行评审门（Adversarial Falsification Gate）**
动作提交前，用 K 个扰动探针（输入扰动、参数扰动、时序扰动）尝试证伪当前 claim：
```
Pass(c) ⇔ ∀k ∈ [1,K], ¬Falsify(c, P_k)
```
任一探针成功证伪 ⇒ 徽章置 None ⇒ 强制退回 M₀ 硬约束检查。评审失败是"退稿"，不是"崩溃"。

**P12 可靠性预算与冗余（Reliability Budget & TMR）**
用三个独立认证路径多数表决，并给退化行为加 token-bucket 预算：
```
Authority(c) = f(Badge(c)),   Cost(t) ≤ B
```
三路不一致率 ρ 超阈值、或退化预算耗尽，都转为"请求人工/安全停机"，避免 v8 的退化风暴。

## 3. 与基线的接口（如何退化）

- 声明账本/重放失效 ⇒ 证书降级为 internal-only（badge=None），控制行为完全退回 v8；
- 冗余认证失效 ⇒ 退回单路解析认证，等价于 v8 的 δ_trigger；
- 统计验证器失效 ⇒ 退回点估计，但强制取保守置信下界，仍比裸点估计安全；
- 可靠性模型失效 ⇒ 退回 v8 的固定退化链，`risk_REL ≡ 0`；
- 退化预算失效 ⇒ 退回 v8 的无预算退化，但保留 TMR 多数表决兜底。

## 4. 预期贡献

1. **证书即论文**框架：claim + 哈希链证据 + 预注册判据 + 分级可复现徽章，让运行时证书可被第三方独立重放；
2. **内部同行评审门**：提交前对抗证伪，把"不可信证书"拦截在动作之前；
3. **anytime-valid 统计声明**：用 e-process 消除可选停止偏差，给长期运行的成功率声明一个数学护栏；
4. **可靠性工程闭环**：CTMC 可用度 + TMR 冗余认证 + 退化预算 + Weibull 预测性维护，把"退化风暴"变成有界事件；
5. 完整 **价值-行动-反馈-情感-可信** 五元闭环：E551–E570 覆盖可复现性、统计有效性、可靠性、长时运行与跨机复现。

## 5. 本轮最大风险

**一句话**：可复现性要求"全量记录 + 独立重放 + 三路冗余认证"，这与 50Hz WCET / ≤2ms 感知预算天然对抗；一旦为了实时性而对证据采样、对重放近似，那么"可复现"就退化为"抽样可复现"，Gold 徽章名不副实——最大风险是「可信性机器反噬它所服务的系统，证书膨胀把可靠性本身拖垮」。

**新增定义 532（声明账本 ClaimLedger）** 防篡改、可独立审计的证据链：
```
ℓ_t = SHA256( ℓ_{t-1} || SHA256(c_t) || SHA256(e_t) || t ),   ℓ_0 = 0^256
R_t = MerkleRoot({ℓ_τ}_{τ≤t})
```
主环只做 O(1) 追加；Merkle root 增量维护；任一条目被篡改，后续所有哈希失配，可被第三方以 O(log n) 包含证明定位。

**新增定义 533（确定性回放 DeterministicReplay）** 给定账本条目与重放条件：
```
c_t' = Replay( ℓ_{t-1}, e_t, σ, sched_t )
D_rep(c_t) = normalize( d_claim(c_t, c_t') ) ∈ [0,1]
```
确定性来源：固定 RNG 种子 σ、记录全部外部输入、逻辑时钟调度、浮点容差 ε_fp。`d_claim` 对证书类型、退化级别、阈值、权重、动作类别逐字段加权求和后归一化。

**新增定义 534（可复现徽章 ReproducibilityBadge）** 分级而非二值：
```
Gold   ⇔ 独立硬件 + 独立种子回放, D_rep = 0, 且统计等价 (95% CI 落在 margin 内)
Silver ⇔ 同硬件同种子回放, D_rep ≤ ε_rep
Bronze ⇔ 回放可执行, 但 D_rep > ε_rep (行为/数值有偏)
None   ⇔ 回放失败或证据缺失
```
覆盖率 `cov = |{c : Badge(c) ≠ None}| / |{c}|`。徽章与动作权限绑定（定义 542）。

**新增定义 535（同行评审门 PeerReviewGate）** 提交前对抗证伪：
```
Pass(c) ⇔ ∧_{k=1}^{K} ¬ Falsify(c, P_k(s))
Falsify(c, P) ⇔ ∃ 轨迹 ξ ∈ ThreatModel(P) : SafePred(c, ξ) = false
```
任一探针证伪 ⇒ `Badge(c) ← None`，强制走 M₀ 硬约束；K 默认 8，探针覆盖输入、参数、时序三类扰动。

**新增定义 536（统计声明验证 StatisticalClaimValidator）** 对 claim「成功率 p ≥ r₀」构造 e-process：
```
E_0 = 1,   E_t = Π_{i=1}^{t} ( 1 + λ (X_i - r₀) ),   λ ∈ (0, 1/r₀)
拒绝 H₀: p = r₀ (声称 p > r₀) ⇔ E_t ≥ 1/α
```
在 H₀ 下 `{E_t}` 为非负上鞅，故由 Ville 不等式，任意（含数据依赖的）停止规则下 `P(sup_t E_t ≥ 1/α) ≤ α`——这正是对论文 `p-hacking` 的机器版防御。

**新增定义 537（可靠性马尔可夫模型 ReliabilityMarkovModel）** CTMC 长期可用度：
```
Q ∈ ℝ^{|S|×|S|},  πQ = 0,  Σπ = 1
A = π_OK + Σ_{l=1}^{4} π_{DEG_l}
MTBF = 1 / Σ_{s ≠ FAIL} q_{s,FAIL}
```
`Q` 的失效率来自 v8 的退化频率统计与故障注入标定；M_rel 监控 `A ≥ A_min ∧ MTBF ≥ MTBF_min`，违背即触发降级。稳态解离线预计算，在线 O(1) 查表。

**新增定义 538（三模冗余认证 RedundantCertification）** 三路独立出证：
```
c^(1) = AnalyticCert(s)      # 形式化/解析证明
c^(2) = SimulatedCert(s)     # 数字孪生仿真
c^(3) = RuntimeMonitorCert(s)# 运行时监控
c* = Majority(c^(1), c^(2), c^(3))
ρ = (1/N) Σ_{t} 1[非多数或三路不一致]
```
`ρ > ε_ρ` 或三路无多数 ⇒ 证书降级并请求人工；三路失效独立时，多数表决错误率由单路 p 降为 `3p² - 2p³`（引理 85）。

**新增定义 539（退化预算 DegradationBudget）** token-bucket 抑制退化风暴：
```
Cost(t) = Σ_{τ=t-W_B+1}^{t} γ^{t-τ} · cost(d_τ),   cost: 软→硬退化成本(层级越高越大)
准入规则:
    if Cost(t) + cost(d_t) ≤ B_hard:  允许退化
    elif Cost(t) + cost(d_t) ≤ B:     允许但强制告警
    else:                             拒绝退化, 请求安全停机/人工
```
预算以 O(1) 指数滑动更新；`B_hard < B` 留出告警缓冲区。

**新增定义 540（可靠性风险分量 ReliabilityRiskComponent）** 注入风险向量第 6 维：
```
risk_REL(s) = w_A(1 - A) + w_M / MTBF + w_ρ · ρ + w_B · Cost(t)/B
risk(s) ∈ ℝ⁶ = [risk_SEN, risk_SEM, risk_EFF, risk_PERF, risk_SLAM, risk_REL]
```
与 v8 的 MetaWeight/ER 六维 softmax 无缝兼容。

**新增定义 541（预测性维护 PredictiveMaintenance）** Weibull 浴盆曲线：
```
故障率 h(t) = (k/λ)(t/λ)^{k-1}
h(t) > h_threshold  ⇒ calib_scheduler.submit(preventive_maintenance)  # 异步, 不阻塞
```
k<1 早期失效期、k=1 恒定失效率、k>1 耗损期；三阶段由在线估计的 (k, λ) 判定。

**新增定义 542（证书-权限映射 ClaimAuthority）** 可复现性 → 自主权，单调映射：
```
Authority(c) =
    FullAutonomy      if Badge = Gold
    MonitoredAutonomy if Badge = Silver
    HumanConfirm      if Badge = Bronze
    MinimalAction(M₀) if Badge = None
```
权限集合随徽章单调不减；不可复现的 claim 结构上无法获得完全自主权。

## 2. 形式化定义（要点）

**定义 493'（指标层级闭合，七层版）** `M = (M₀,M₁,M₂,M₃,M_dom,M_SLAM,M_rel)`；M_rel 监控 `A, MTBF, ρ, Cost`，具备到 M₀ 的退化映射 `δ_rel`。

**定义 495'（奖励可逆向性，六维版）** `w'_i(s) = softmax(α·risk_i(s) + β·emo(s)·Ṽ_i)_{i=0..5}`，`risk ∈ ℝ⁶` 含 risk_REL。

**定义 496'（软证书，RRC 版）**
```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
              ∧ risk_SLAM < τ_SLAM ∧ Badge(c) ≥ Silver ∧ Cost(t) < B_hard }
```
六条件同尺度设计，任一触发 → M₀；`Badge(c) < Silver` 是"可复现性空洞"的封堵点。

**定义 532–542** 见上（账本、回放、徽章、评审、e-process、CTMC、TMR、预算、风险分量、预测维护、权限映射）。

**定义 543（可信性闭环标识）** 完整系统标识：
```
Φ_RRC = { claim→ledger→replay→badge→authority,
          risk 6-dim(+REL), CTMC A/MTBF, TMR, budget-bounded degrade }
Φ_v8  = { τᵢ adaptative+domain, risk 5-dim, calib online, 无预算退化 }
```

    def __init__(self):
        self.entries = []
        self.prev = self.GENESIS

    @staticmethod
    def _h(x):
        if not isinstance(x, (bytes, bytearray)):
            x = str(x).encode("utf-8")
        return hashlib.sha256(x).hexdigest()

    def append(self, claim, evidence, t):
        h_c = self._h(json.dumps(claim, sort_keys=True, default=str))
        h_e = self._h(json.dumps(evidence, sort_keys=True, default=str))
        ell = self._h((self.prev + h_c + h_e + str(t)).encode("utf-8"))
        self.entries.append({"t": t, "h_claim": h_c, "h_evidence": h_e, "ell": ell})
        self.prev = ell
        return ell

    def merkle_root(self):
        layer = [e["ell"] for e in self.entries]
        if not layer:
            return self._h("")
        while len(layer) > 1:
            if len(layer) % 2:
                layer.append(layer[-1])
            layer = [self._h(layer[i] + layer[i + 1])
                     for i in range(0, len(layer), 2)]
        return layer[0]

    def verify(self):
        prev = self.GENESIS
        for e in self.entries:
            if self._h((prev + e["h_claim"] + e["h_evidence"] + str(e["t"]))
                       .encode("utf-8")) != e["ell"]:
                return False
            prev = e["ell"]
        return True


# IP-362 ReproducibilityCert：三级徽章
class ReproducibilityCert:
    def __init__(self, replay_fn, claim_distance, eps_rep=1e-6,
                 gold_margin=0.01):
        self.replay_fn = replay_fn
        self.claim_distance = claim_distance
        self.eps_rep = eps_rep
        self.gold_margin = gold_margin

    def certify(self, claim, entry, seeds=(0,), independent_machine=False):
        distances = []
        for s in seeds:
            replayed = self.replay_fn(entry, s)
            distances.append(self.claim_distance(claim, replayed))
        d_max = max(distances)
        if (d_max == 0.0 and independent_machine
                and max(distances) - min(distances) <= self.gold_margin):
            return "Gold", d_max
        if d_max <= self.eps_rep:
            return "Silver", d_max
        if np.isfinite(d_max):
            return "Bronze", d_max
        return "None", float("inf")


# IP-363 PeerReviewGate：提交前对抗证伪
class PeerReviewGate:
    def __init__(self, probes, falsify_fn, K=8):
        self.probes = probes          # [callable(state) -> perturbed state]
        self.falsify_fn = falsify_fn  # callable(claim, state) -> bool
        self.K = K

    def review(self, claim, state):
        for k in range(self.K):
            perturbed = self.probes[k % len(self.probes)](state)
            if self.falsify_fn(claim, perturbed):
                return False, k
        return True, -1


# IP-364 EProcessValidator：anytime-valid 统计声明
class EProcessValidator:
    def __init__(self, r0, alpha=0.05):
        self.r0 = r0
        self.alpha = alpha
        self.lam = 0.5 / max(r0, 1e-9)   # 严格 < 1/r0
        self.E = 1.0
        self.t = 0

    def update(self, x):
        self.E *= (1.0 + self.lam * (x - self.r0))
        self.t += 1
        return self.E >= 1.0 / self.alpha

    def reset(self):
        self.E, self.t = 1.0, 0


# IP-365 ReliabilityMarkovModel：CTMC 可用度
class ReliabilityMarkovModel:
    def __init__(self, states, Q):
        self.states = states
        self.Q = np.asarray(Q, dtype=float)
        self.pi = self._stationary(self.Q)

    @staticmethod
    def _stationary(Q):
        n = Q.shape[0]
        A = Q.T.copy()
        A[-1, :] = 1.0
        b = np.zeros(n)
        b[-1] = 1.0
        return np.linalg.solve(A, b)

    def availability(self):
        ok = self.states.index("OK")
        deg = [i for i, s in enumerate(self.states) if s.startswith("DEG")]
        return float(self.pi[ok] + self.pi[deg].sum())

    def mtbf(self):
        fail = self.states.index("FAIL")
        rate = sum(self.Q[i, fail] for i in range(len(self.states))
                   if i != fail)
        return float("inf") if rate <= 0 else 1.0 / rate


# IP-366 RedundantCertification：三路多数表决
class RedundantCertification:
    def __init__(self, eps_rho=0.05, window=200):
        self.eps_rho = eps_rho
        self.window = window
        self.disagree = []
        self._recent = []

    def certify(self, c_analytic, c_sim, c_runtime):
        labels = [c_analytic["label"], c_sim["label"], c_runtime["label"]]
        vals, counts = np.unique(labels, return_counts=True)
        ok = counts.max() >= 2
        disagreement = 1.0 - counts.max() / 3.0
        self.disagree.append(disagreement)
        if len(self.disagree) > self.window:
            self.disagree.pop(0)
        self._recent.append(ok)
        rho = float(np.mean(self.disagree))
        if not ok or rho > self.eps_rho:
            return None, rho
        return vals[counts.argmax()], rho


# IP-367 DegradationBudget：token bucket 抑制退化风暴
class DegradationBudget:
    def __init__(self, B=10.0, B_hard=8.0, gamma=0.99):
        self.B = B
        self.B_hard = B_hard
        self.gamma = gamma
        self.cost = 0.0

    @staticmethod
    def cost_of(level):
        return float(level) ** 2   # 层级越高, 代价超线性

    def register(self, level):
        self.cost = self.gamma * self.cost + self.cost_of(level)
        if self.cost + 0.0 <= self.B_hard:
            return "allow"
        if self.cost <= self.B:
            return "allow_warn"
        return "deny_stop"


# IP-541 预测性维护（Weibull）
class PredictiveMaintenance:
    def __init__(self, k_shape=1.5, lam_scale=1000.0, h_threshold=2e-3):
        self.k = k_shape
        self.lam = lam_scale
        self.h_threshold = h_threshold

    def hazard(self, t):
        return (self.k / self.lam) * (t / self.lam) ** (self.k - 1.0)

    def should_maintain(self, t):
        return self.hazard(t) > self.h_threshold

## 4. 推导

**引理 82（账本防篡改）** 设哈希链为 `ℓ_t = H(ℓ_{t-1} ‖ h(c_t) ‖ h(e_t) ‖ t)`。篡改任一历史条目 τ 必须重算 `ℓ_τ..ℓ_t` 并使新 `R_t` 等于原 Merkle root。在 SHA-256 抗第二原像/抗碰撞假设下，成功概率 ≤ `negl(κ)`（对 256 位安全强度，单次伪造可见概率 ≥ `1 - 2^{-128}`）。故第三方可用包含证明以 O(log n) 独立验证某证书确曾被系统产出。

**引理 83（回放分歧有界）** 若账本记录了全部非确定性来源且单步数值误差 ≤ ε_fp，声明映射 `F` 关于证据链 Lipschitz 常数为 L，则长度 n 的重放满足 `D_rep ≤ n · L · ε_fp`。故给定 ε_rep，可通过限制重放链长、定点化关键量或降低 L（把浮点敏感的阈值比较改为区间比较）保证 Silver 徽章；反之，长链 + 高 L 会自然落入 Bronze，提示需要更强的证据记录。

**引理 84（e-process 可选停止有效性）** 在 H₀: p=r₀ 下，`E_t = Π(1 + λ(X_i - r₀))` 为非负上鞅（因 `E[X_i]=r₀`，每因子条件期望为 1），故 `E[E_t] ≤ E_0 = 1`。由 Ville 不等式 `P(sup_t E_t ≥ 1/α) ≤ α E_0 = α`。因此无论系统何时停止检验（含"看到成功就停"），声称 p>r₀ 的假阳性率恒 ≤ α，消除论文式可选停止偏差。

**引理 85（冗余认证可靠性）** 三路条件独立、单路错误率 ≤ p 时，多数表决错误发生在 ≥2 路同时错，概率 `P_err = 3p²(1-p) + p³ = 3p² - 2p³`。`P_err < p ⇔ p(3p-1)(p-1) > 0 ⇔ p < 1/2`。例如 p=0.1 时 P_err=0.028，错误率降为单路的 28%。故 TMR 在单路优于随机的条件下严格提升认证可靠性。

**引理 86（退化预算抑制风暴）** 设最小退化代价 `cost_min > 0`。在指数滑窗下，`Cost(t) ≥ γ^{W_B-1} · cost_min · N_W(t)`，其中 N_W 为窗口内退化次数。准入规则保证 `Cost(t) ≤ B`，故 `N_W(t) ≤ B / (γ^{W_B-1} cost_min)`，即任意窗口退化次数有硬上界，v8 的"退化风暴"不可能无限持续；当 `Cost ≥ B_hard` 时系统转为告警/停机而非继续抖动。

**引理 87（可靠性风险单调性）** `risk_REL` 各项非负；对可用度 A 单调减，对 ρ、Cost、1/MTBF 单调增。将 risk_REL 追加进 risk 向量后，安全相关权重 `w₀,w₁ = softmax(...)_0,1` 对 risk_REL 单调不减（softmax 分量对自身维度输入单调增）。故可靠性下降 ⇒ 安全权重上升 ⇒ 系统更保守，方向正确。

**引理 88（可复现-权限安全性）** 由定义 542，`Authority(c)` 随 `Badge(c)` 单调不减，且 `Badge ≤ Bronze ⇒ Authority ≤ HumanConfirm`。因此任何不可被独立复现的 claim 结构上无法获得完全自主权。结合 `δ_trigger` 中 `Badge ≥ Silver` 条件，可复现性不足直接触发 M₀，不存在"不可复现却放行"的空洞。

**引理 89（六级退化正确性）** 新增 Level-5/6 接口与 v8 正交：Ledger 只写证据、不改控制；Replay 只读账本；Reliability 只改 `risk_REL` 与退化准入；Badge/Authority 只读徽章与预算。任意单模块失效按对应级别退回；组合失效按级别叠加且互不干扰；六级全失效完整退回 v8，再退回 v7/v6。无级联副作用，因各模块不共享可变控制状态。

**引理 90（e-process 与预算联合安全性）** 若 e-process 未拒绝 H₀，则声称"长期成功率达标"的 claim 不被授权为 Gold（需 Badge 与统计双条件）；若预算拒绝退化，则系统进入 MinimalAction，动作集合为 M₀ 的子集。两者同时成立时，系统既不过度声明，也不在退化上失控，联合安全域非空（退化到 M₀ 始终可执行）。
