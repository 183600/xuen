灵感驱动研究循环·新灵感三元组第 1 轮；本轮灵感：「常识推理」×「力矩传感」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23+IP-431–439（其上承 v22 的 HDL/ACSC/DCSC/PGEV、v21 的 SDC/CAC/DCL/GIC、v20 的 PCA/CTS/CFC/HPC，以及 v19/v17 全部证书与感知链）。
> 本轮纪律：**常识是事前的、可证伪的、只能加谨慎的先验；力矩是事中的、可靠的、只能证伪的物理见证；能量必须以测量接地、且测量只能收紧不能放宽**。不推倒 v23：CESC/FSVC/IPAM/HDL/ACSC/DCSC/PGEV/SDC/CAC/DCL/GIC 全部保留。本轮只做一件事：在 v23 的"语义-规范-云边"证书体系之上加一层 **"预测—见证"对偶层**——用物理上独立的力矩通道封堵 v23 的最大风险（conformal 覆盖在分布漂移下崩塌、单模态相关误判形成共识），用常识推理补上"开放世界上下文"的语义缺口，并用一条**单向收缩算子代数**保证所有新增模块只会缩小执行集。

## 0. 直觉与动机

**灵感 1（力矩传感 → 从"预测安全"到"见证安全"）**
直觉：v23 的所有证书本质上都是"预测"——预测障碍（SDC）、预测覆盖（CAC）、预测能量（PGEV/EVC）、预测分布（FSVC 的 conformal 覆盖）。预测的共同软肋是它们共享同一套视觉传感器、同一个世界模型、同一个训练分布，因此会在分布漂移时**相关地一起错**。力矩传感是第一个与视觉在物理上独立的量：它不"看见"世界，它"感受"世界对机器人的反作用。`r_t = τ_measured − τ_model(q, q̇, q̈) = τ_ext + Δ_model`。关键不是它多看见了一样东西，而是它的证据是**单向**的：零残差 ≠ 没人（轻触、远端连杆、近奇异位形都藏在模型误差 ε_model 里）；但非零残差超过界 ⇒ 在传感器健康时**一定发生了接触**。核心创新：**力矩残差见证 (Torque Residual Witness, TRW) + 接触严重度证书 (Contact Severity Certificate, CSC) + 测量接地能量账本 (Measurement-Grounded Energy Ledger, MGEL)**。关键反直觉点：**正因为力矩不能证明安全，它才可靠——它不会像视觉那样自信地看错，它只在真被碰到的瞬间说话**。于是它只当"否决者"不当"背书者"，与 P36 的非对称门槛同构，从结构上拆掉"众口铄金"：视觉可以投 SAFE，力矩只能沉默或否决；一旦否决，那张 SAFE 票立即作废。附带三件硬货：(a) 由残差 + 雅可比 + 反应时延给出接触力/冲量/压强上界，接入 ISO/TS 15066 的功率-力限制语义（但只作附加合取项收紧，绝不作放宽距离裕度的理由）；(b) `E_meas = ∫|τ_m·q̇|dt` 替代纯预测的 `∫P̂dt`，用 `max(预测, 测量+ε_E)` 作上界，只能发现模型低估、不能凭空多发预算；(c) 负载/摩擦自校准持续收缩 ε_model，从而收缩力矩盲区——但校准本身要带证书，不能在线偷偷放宽。
**盲区的结构性差异（本轮关键论点）**：视觉盲区 `B_vis = {遮挡, 小目标, 异常外观, 逆光, 透明}`；力矩盲区 `B_τ = {|τ_ext| ≤ ε_model 的轻触, 远端连杆近奇异, 关节饱和, 高加速被动力学淹没}`。二者**结构不同**，所以合起来严格强于任一单独——但**并不相交为空**：小体型儿童轻触腕部末端、恰在近奇异位形，会同时落进两个盲区。本轮必须正面承认这一残余风险，并用联合压力测试去界定它，而不是宣称"独立即万无一失"。

**灵感 2（常识推理 → 开放世界上下文，但只能单向加谨慎）**
直觉：v23 的 DCL 规则是"封闭谓词"：near、fast、person、yield 都有形式定义，但真实世界的谓词是开放的、依赖情境的。常识推理补的正是这个缺口：它知道"医院夜班走廊可能有意识混乱的病人"、"幼儿园里的'人'多数是小体型"、"仓库地面有水渍则可能滑倒"、"有人抱着箱子朝你走来，多半是想借过而不是交互"。但常识是**可证伪的、非可靠的**：它会幻觉、会过时、会与部署地文化不符。所以它绝不能像 SDC 那样直接产生证书。核心创新：**常识先验层 (Commonsense Prior Layer, CPL)**，把常识限制成**单向谨慎算子**——它只能 (a) 增加障碍/义务、(b) 抬高所需的召回下界 `κ_c^ctx ≥ κ_c^base`、(c) 对模糊谓词取保守外延（"near"取最大合理距离、"fast"取最低合理阈值）；任何"放宽"提议一律丢弃或转交可靠模块验证。形式化即 `Γ_cs(Θ, ctx) ⊆ Θ`，且 `Γ_cs` 只由交集构成。这样常识再离谱，最坏也只是把活性压死，绝不会把安全边界打开。两个高价值副产品：(a) **上下文召回调节**——直接打击 v21 的"缺席幻觉"：在儿童/轮椅/蹲姿高发情境把 AbsCert 所需的 κ_c 抬到检测器经验值之上，AbsCert 自然拒发；(b) **常识对抗场景生成**——让常识生成"你没想到但可能发生"的场景（爬行、透明玻璃门、镜面假自由空间），作为 κ_c 上调与验证集扩充的依据，而不是运行时障碍（避免无界场景导致活性归零）。关键反直觉点：**常识最诱人的用法——"此情此景不必这么保守"——恰恰是唯一禁止的用法**。活性必须从别处来（测量收紧能量、见证减少误停、上下文精准定位谨慎），而不是从放宽安全假设来。

**二者如何统一：预测—见证对偶 + 单向收缩算子代数**
按时间尺度三分：**事前**（常识先验 + 视觉缺席证书，可证伪、只加谨慎）→ **事中**（力矩见证 + 严重度，可靠、只否决）→ **事后**（测量能量账本 + 审计 + 校准）。共享状态 `ζ_fed` 扩展为 `ζ_pw = ζ_ce ∪ (r_t, ε_model, B_τ, E_meas, ctx_t, κ_c^ctx, Γ_cs, contradiction_set, δ_joint)`。
**结构定理（本轮灵魂）**：v24 新增的每个模块都是可容许计划格上的**收缩算子**——`Γ_cs(Θ) ⊆ Θ`；力矩见证是 veto 而非 add（只删票不发票）；`E_upper = max(E_pred, E_meas+ε_E) ≥ E_pred`；CMCC 只 escalate 不 de-escalate。收缩算子的复合仍是收缩，故 `Exec_v24 ⊆ Exec_v23` 是**结构性**成立，不靠逐案分析。唯一能扩张的是"双向算子"，而 v24 在类型层面禁止它。统一准入门：**HPC-E++ = HPC-E+ ∩ TRC ∩ CSC ∩ MGEL ∩ Fil_cs ∩ CMCC**——只有"v23 全证 ∧ 无接触见证 ∧ 严重度达标 ∧ 能量上界达标 ∧ 常识约束满足 ∧ 无跨模态矛盾"才进入执行；任一缺失退回 v23，再逐级下退。共识升级 **CFC-W (Witness-Modality Quorum)**：把票分为**预防票**（视觉/缺席，可背书 SAFE）与**见证票**（力矩，只能否决）；SAFE 需要预防票达法定数 ∧ 模态数 ≥ 2 ∧ **失效模式独立性**（在宣称安全的失效区域上，参与模态的盲区交集经压力测试界定 ≤ δ_joint）；任一见证票否决即 UNSAFE。这样"计数"与"结构"两道闸同时卡相关误判。

## 1. 研究问题（轮次升级版）

- **Q12（力矩残差的可靠性与盲区刻画）**：如何在负载、摩擦、构型变化下证明 `|Δ_model| ≤ ε_model`，使 `|r| > ε_model + ε_sensor` 在传感器健康时可靠地蕴含接触？如何解析刻画力矩盲区 `B_τ`（轻触、远端连杆、近奇异雅可比、饱和）并与视觉盲区 `B_vis` 的联合交集给出可计算的界 `δ_joint`？冗余估计（力矩传感器 vs 电流估计 vs 关节编码器微分）如何做传感器健康判定与偏置漂移检测？

- **Q13（接触严重度的证书化）**：如何由残差、雅可比伪逆范数、反应时延 `t_react` 给出接触力 `F_upper`、冲量 `I_upper = F_upper·t_react`、压强 `P = F/A_contact` 的可靠上界？饱和时如何退化为最坏情形？严重度证书如何只作为附加合取项收紧，而绝不用于放宽 v23 的距离裕度？

- **Q14（常识的单向性与可证伪性）**：如何形式保证 `Γ_cs` 是收缩算子（只加约束、只抬高 κ_c、只取保守外延），并把自然语言规则编译成可审计、可证伪的义务？"上下文 → 所需召回下界"映射 `Δκ_ctx(ctx) ≥ 0` 如何校准，使其只升不降？当常识与可靠模块冲突时如何强制升级而非静默择一？

- **Q15（跨模态一致性与归因）**：如何定义"视觉声称自由 / 力矩见证接触"、"视觉声称重物 / 力矩见证轻阻"等跨模态残差，并给出经 1-α 校准的矛盾阈值以控制误停率？矛盾发生时如何归因到视觉、力矩或常识三者之一，从而选择正确的降级层级（而不是一律 SafeStop 导致活性归零）？

- **Q16（盲区互补的经验认证）**：如何**经验地认证**"视觉与力矩盲区在部署情境下近似不相交"这一假设？需要多小的联合压力测试集（含常识生成的对抗场景）才能把 `P(B_vis ∩ B_τ ∩ Context_safe)` 压到 `δ_joint` 以下？当认证样本不足时，系统应如何回退到"假设二者可能同时失效"的最保守模式？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P48）

**P43 力矩残差见证律（Torque Residual Witness）**
`r_t = τ_m − τ_model`，且 `r_t = τ_ext + Δ_model + ν`，`|Δ_model| ≤ ε_model`、`|ν| ≤ ε_sensor`。接触谓词 `C_t = [sensor_healthy ∧ |r_t| > ε_model + ε_sensor]`。**单向可靠性**：`C_t = true ⇒ τ_ext ≠ 0`（接触确实发生）；`C_t = false ⇏ τ_ext = 0`（盲区 `B_τ` 内可漏检）。力矩是**反应式见证**：其保证针对**已检出**接触（在时延 `t_react` 之后），不构成对"不发生接触"的证明；因此力矩只能否决安全声称，永不能签发安全声称。传感器健康由冗余估计一致性 + 偏置漂移检测联合判定；不健康时 `C_t` 视为 `true`（fail-safe，向否决退化）。

**P44 接触严重度证书律（Contact Severity Certificate）**
检出接触于 `t_c` 后，给出端部力上界 `F_upper = ‖J^†‖·(|r| + ε_model + ε_sensor)`、冲量上界 `I_upper = F_upper·t_react`（含制动时延）、压强上界 `P_upper = F_upper/A_min`。证书有效当且仅当 `F_upper ≤ F_lim ∧ P_upper ≤ P_lim`（ISO/TS 15066 语义）。饱和或近奇异（`‖J^†‖` 爆炸）时取最坏情形并**升级**，不得插值外推。严重度证书只作为 HPC-E++ 的**附加合取项**（收紧），严禁作为放宽 v23 距离/速度裕度的依据。

**P45 常识单向谨慎律（Commonsense One-Sided Caution）**
`Γ_cs: (Θ, ctx) ↦ Θ'` 满足 `Θ' ⊆ Θ`，实现为 `Θ' = Θ ∩ ⋂_c Constraint_c(ctx)`，其中每条 `Constraint_c` 只能删除计划。具体三型：(i) 增障碍/义务；(ii) `κ_c^ctx = κ_c^base + Δκ_ctx(ctx)`，`Δκ_ctx ≥ 0`；(iii) 模糊谓词取**保守外延**（`near→max`、`fast→min`、`person→⊇` 含儿童/轮椅/蹲姿）。任何来自常识的"放宽/解锁"提案在类型层被拒绝，或转交可靠模块（HPC/TRC）验证后才可能生效。故 `Fil_cs` 是收缩算子。

**P46 常识-物理一致性律（Commonsense-Physics Consistency）**
对每条常识期望 `e_cs` 与对应物理测量 `m_phys` 定义残差 `d = |e_cs − m_phys|`，阈值 `τ_c4` 经 conformal 校准使误报率 ≤ α_c4。若 `d > τ_c4` 则产生 `Contradiction`，**强制升级**（冻结争议证书并回退一级；涉及人体安全则 SafeStop），绝不静默择一。矛盾按来源归因（视觉/力矩/常识），归因置信不足时取最严处置。

**P47 测量接地能量单向收紧律（Measurement-Grounded Energy One-Sided Tightening）**
`E_meas(t) = ∫_0^t |τ_m·q̇| dτ`，`E_upper = max(E_pred, E_meas + ε_E)`（`ε_E` 界住偏置/漂移/离散化）。储备检查使用 `E_upper`：`E_res ≥ E_fallback + E_upper + E_reach + E_margin`。故测量只能**发现**模型低估（使约束更紧），绝不能凭空增加预算。若长期 `E_meas ≪ E_pred`，仅可触发**离线重标定**并生成新的证书上界，禁止在线放宽。

**P48 单向收缩算子律与盲区互补（One-Sided Contraction & Complementary Blind-Spot）**
(v24a) v24 的每个新增模块 `O` 都是收缩算子 `O(Θ) ⊆ Θ`；收缩的复合仍收缩，故 `Exec_v24 ⊆ Exec_v23` 结构性成立。(v24b) 对"漏检人体接触"这一失效属性，安全声称要求 `P(B_vis ∩ B_τ ∩ Context_safe) ≤ δ_joint`；`Context_safe` **不得**仅由常识宣告，必须附可靠占用证书；`δ_joint` 由联合压力测试经验界定，样本不足即回退"二者可能同时失效"的最保守模式。共识法定条件因此从"模态数 ≥ 2"升级为"模态数 ≥ 2 ∧ 失效模式在宣称安全区域上独立性达标"。

## 3. 与基线的接口（如何退化）

- TRW 失效（传感器故障/标定漂移）⇒ `C_t ≡ true`（视为持续接触）⇒ 触发 SafeStop 或最大限制模式 ⇒ 比 v23 更保守；
- CSC 失效（雅可比奇异/饱和）⇒ 严重度取最坏上界，大概率 `F_upper > F_lim` ⇒ 拒证 ⇒ 回退 v23；
- MGEL 失效（力矩积分不可信）⇒ 回退纯预测 `E_pred` ⇒ 等价 v23；
- CPL 失效（常识/LLM 不可用或审计失败）⇒ `Γ_cs = id`、`Δκ_ctx = 0` ⇒ 等价 v23（不抬不降）；
- CMCC 失效 ⇒ 无矛盾检测 ⇒ 等价 v23（只少了一层交叉校验）；
- CRG 失效 ⇒ κ_c 不上调 ⇒ 等价 v23（保留 v21 原始缺席幻觉风险，不额外恶化）；
- CFC-W 无法满足失效模式独立性 ⇒ 仲裁退回 v23 的 CFC+++ 行为（仅计数 + 模态数）⇒ 等价 v23；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`（引理 162 延伸）。
- **安全继承（结构性）**：由 P48，所有新增算子皆收缩，任一失效都向更保守方向退化，无需逐案枚举；这与前几轮"任意失效向保守退化"的纪律一致，但本轮把"逐案"升级为"代数"。

## 4. 预期贡献

1. **力矩见证的证书化**：首次把 `r = τ_m − τ_model` 变成带可靠界与盲区刻画的**单向否决证据**，给出"只能证伪、不能背书"的非对称见证语义，并与 P36 非对称门槛同构；
2. **接触严重度证书**：由残差+雅可比+时延给出力/冲量/压强上界，把 ISO/TS 15066 的功率-力限制语义接入证书链，且严格只收紧不放宽；
3. **测量接地能量**：以 `max(预测, 测量+ε)` 的单向上界取代纯预测能量，首次让"能量账本"可被物理测量审计，同时保持 `Exec` 单调不增；
4. **常识单向谨慎算子**：把开放世界常识形式化为收缩算子 `Γ_cs`，用"上下文召回调节"直接打击 v21 的缺席幻觉，用"常识对抗场景生成"扩展 κ_c 的验证基础，且从类型层禁止常识放宽安全假设；
5. **跨模态一致性 + 归因**：给出视觉-力矩-常识的残差定义、1-α 矛盾阈值与来源归因，避免"一律 SafeStop"导致的活性归零；
6. **单向收缩算子代数**：把"任意失效向保守退化"从逐案证明升级为代数定理（收缩的复合仍收缩），使 `Exec_v24 ⊆ Exec_v23` 结构性成立；
7. **盲区互补的经验认证**：把"多模态独立"从口号升级为可测量、可回退的 `δ_joint` 认证程序，诚实承认 `B_vis ∩ B_τ ≠ ∅` 并用联合压力测试界定其概率。

## 5. 本轮最大风险

**一句话**：常识层唯一真正能提升活性的用法——"此情境不需要如此保守"——恰恰是单向律禁止的放宽；一旦通过自然语言编译把这种放宽伪装成"移除一条义务"混入，整条单调链在形式上仍自洽、审计上仍合规，但安全继承已失效——而力矩见证又恰在"小体型/轻触/奇异位形"处与视觉盲区重合，无法兜底。

# ============================================================
# IP-440 Torque Residual Witness (TRW) — 力矩残差单向见证
# ============================================================
@dataclass
class TorqueWitness:
    r: np.ndarray            # 每关节残差
    eps_model: np.ndarray    # 认证模型误差上界（逐关节）
    eps_sensor: np.ndarray   # 传感器误差上界
    healthy: bool            # 冗余健康判定
    contact: bool            # 单向见证：True ⇒ 确实接触
    t_detect: float

class TorqueResidualObserver:
    def __init__(self, dyn_model, eps_model_fn, eps_sensor, F_lim, P_lim,
                 A_min, t_react):
        self.dyn = dyn_model
        self.eps_model_fn = eps_model_fn   # (q,dq) -> 逐关节上界（含负载/摩擦）
        self.eps_sensor = np.asarray(eps_sensor)
        self.F_lim, self.P_lim, self.A_min = F_lim, P_lim, A_min
        self.t_react = t_react
        self.bias = np.zeros_like(self.eps_sensor)   # 在线偏置估计（带证书才启用）

    def sensor_health(self, q, dq, tau_meas, tau_current_est, tau_encoder_est) -> bool:
        """冗余一致性 + 饱和 + 偏置漂移联合判定。不健康时向否决退化。"""
        if np.any(np.abs(tau_meas) >= self.sat_level()):
            return False
        d1 = np.abs(tau_meas - tau_current_est)
        d2 = np.abs(tau_meas - tau_encoder_est)
        return bool(np.all(d1 <= 3 * self.eps_sensor) and
                    np.all(d2 <= 3 * self.eps_sensor) and
                    np.all(np.abs(self.bias) <= self.bias_lim))

    def step(self, q, dq, ddq, tau_meas,
             tau_current_est, tau_encoder_est) -> TorqueWitness:
        tau_model = self.dyn(q, dq, ddq)
        r = tau_meas - tau_model
        eps_model = np.asarray(self.eps_model_fn(q, dq))
        healthy = self.sensor_health(q, dq, tau_meas,
                                     tau_current_est, tau_encoder_est)
        # 不健康 ⇒ 视为持续接触（fail-safe，只能更保守）
        contact = True if not healthy else bool(
            np.any(np.abs(r) > eps_model + self.eps_sensor + np.abs(self.bias)))
        return TorqueWitness(r, eps_model, self.eps_sensor,
                             healthy, contact, now())

    def force_bound(self, w: TorqueWitness, q) -> tuple[float, float, float]:
        """IP-441 CSC：接触力/冲量/压强最坏上界（含近奇异放大）。"""
        J = self.dyn.jacobian(q)
        Jpinv = np.linalg.pinv(J)                      # 近奇异时范数爆炸 ⇒ 自动保守
        force_norm = np.linalg.norm(w.r) + np.linalg.norm(w.eps_model) + \
                     np.linalg.norm(w.eps_sensor)
        F_upper = float(np.linalg.norm(Jpinv) * force_norm)
        I_upper = F_upper * self.t_react
        P_upper = F_upper / self.A_min
        return F_upper, I_upper, P_upper

    def severity_ok(self, w, q) -> bool:
        if not w.healthy:
            return False                               # 不健康 ⇒ 不签严重度
        F, I, P = self.force_bound(w, q)
        return (F <= self.F_lim) and (P <= self.P_lim)

# IP-442 Measurement-Grounded Energy Ledger (MGEL)
# ============================================================
class MeasurementGroundedEnergyLedger:
    def __init__(self, eps_E: float):
        self.eps_E = eps_E
        self.E_meas = 0.0
        self.E_pred = 0.0

    def update(self, tau_meas, dq, dt, E_pred_step):
        self.E_meas += float(np.sum(np.abs(tau_meas * dq)) * dt)
        self.E_pred += float(E_pred_step)

    def E_upper(self) -> float:
        # 单向收紧：测量只能抬高上界（发现低估），绝不降低
        return max(self.E_pred, self.E_meas + self.eps_E)

    def reserve_ok(self, E_res, E_fallback, E_reach, E_margin) -> bool:
        return E_res >= E_fallback + self.E_upper() + E_reach + E_margin

    def request_offline_recalibration(self, ratio=0.5) -> bool:
        # 长期 E_meas << E_pred 仅触发离线重标定，禁止在线放宽
        return self.E_pred > 0 and self.E_meas < ratio * self.E_pred

# IP-443 Commonsense Prior Layer (CPL) — 单向谨慎算子
# ============================================================
class CommonsensePriorLayer:
    def __init__(self, reasoner, ontology, ctx_classifier,
                 kappa_base: float, alpha_cs: float = 0.05):
        self.reasoner = reasoner            # LLM/VLM，离线/异步
        self.ontology = ontology            # 场所/人群/地面/时段本体
        self.ctx_classifier = ctx_classifier
        self.kappa_base = kappa_base
        self.alpha_cs = alpha_cs

    def context_risk(self, ctx_obs) -> 'ContextRisk':
        ctx = self.ctx_classifier(ctx_obs)
        # Δκ_ctx 恒 ≥ 0：只抬不降
        dk = max(0.0, self.ontology.recall_raise(ctx))
        return ContextRisk(ctx=ctx, kappa_req=self.kappa_base + dk, delta_kappa=dk)

    def tighten(self, Theta: 'PlanSet', risk: 'ContextRisk') -> 'PlanSet':
        """收缩算子：Θ' = Θ ∩ ⋂ Constraint_c。任何放宽提案在类型层被拒绝。"""
        constraints = self._one_sided_constraints(risk)   # 仅增障碍/义务/缩域
        for c in constraints:
            Theta = Theta.intersect(c)
        return Theta

    def _one_sided_constraints(self, risk) -> list:
        out = []
        for c in self.ontology.constraints(risk.ctx):
            if c.kind in ("add_obstacle", "add_obligation", "shrink_domain"):
                out.append(c)
            # c.kind == "relax" 一律丢弃（或转交可靠模块验证，见 compile_rule）
        return out

    def compile_rule(self, nl_rule: str) -> 'DeonticRule':
        """NL→deontic：模糊谓词取保守外延；放宽型条款强制转交验证。"""
        parsed = self.reasoner.parse(nl_rule)
        for pred, val in parsed.predicates.items():
            parsed.predicates[pred] = self.ontology.conservative_extension(pred, val)
        if parsed.contains_relaxation:
            parsed.requires_verifier = True   # 不得直接生效
        return parsed

    def audit_monotonicity(self, rule: 'DeonticRule') -> bool:
        """静态审计：谓词外延必须 ⊆ 字面外延；含放宽则必须挂 verifier。"""
        for pred, val in rule.predicates.items():
            if not self.ontology.is_subset_extension(pred, val):
                return False
        return (not rule.contains_relaxation) or rule.requires_verifier

# IP-444 Cross-Modal Consistency Certificate (CMCC / C4)
# ============================================================
class CrossModalConsistencyCertificate:
    def __init__(self, tau_c4: float, alpha_c4: float = 0.01):
        self.tau_c4 = tau_c4
        self.alpha_c4 = alpha_c4

    def check(self, vision_claim, torque_w: TorqueWitness, q,
              ctx_risk, proprio) -> 'ConsistencyResult':
        contradictions = []
        # 1) 视觉声称路径自由，但力矩见证接触 ⇒ 视觉漏检
        if vision_claim.free_space_along_path and torque_w.contact:
            contradictions.append(("vision_missed_contact", "vision", 1.0))
        # 2) 视觉声称重物，但接触阻力远低于期望 ⇒ 质量/身份不符
        if vision_claim.mass_class == "heavy" and torque_w.contact:
            F, _, _ = torque_w.force_bound(torque_w, q)
            if F < vision_claim.expected_force_lo:
                contradictions.append(("mass_identity_mismatch", "vision", 0.8))
        # 3) 常识期望 vs 物理测量
        if ctx_risk is not None and hasattr(ctx_risk, "expected_force"):
            if abs(ctx_risk.expected_force - torque_w.F_est) > self.tau_c4:
                contradictions.append(("cs_physics_mismatch", "commonsense", 0.6))
        # 4) 本体感觉与视觉位姿不一致（滑移/标定漂移）
        if proprio is not None and vision_claim.pose is not None:
            if np.linalg.norm(proprio.pose - vision_claim.pose) > self.tau_c4:
                contradictions.append(("proprio_vision_mismatch", "vision", 0.5))
        return ConsistencyResult(contradictions, escalate=len(contradictions) > 0)

    def attribute(self, result: 'ConsistencyResult') -> str:
        if not result.contradictions:
            return "none"
        # 归因置信不足 ⇒ 最严处置
        top = max(result.contradictions, key=lambda x: x[2])
        return top[1] if top[2] >= 0.8 else "unknown_strict"

# IP-445 Commonsense Red-Team Generator (CRG)
# ============================================================
class CommonsenseRedTeamGenerator:
    def __init__(self, reasoner, max_scenarios: int = 64):
        self.reasoner = reasoner
        self.max_scenarios = max_scenarios

    def generate(self, ctx, n: int = 16) -> list:
        """生成未建模但合理的风险场景，仅用于验证/κ_c 上调，不注入运行时障碍。"""
        raw = self.reasoner.enumerate_hazards(ctx, n=min(n, self.max_scenarios))
        return [s for s in raw if s.is_physically_plausible()]

    def required_kappa(self, scenarios, delta_joint: float) -> float:
        """把场景覆盖折算为召回下界上调（只升不降）。"""
        uncovered = [s for s in scenarios if not s.is_covered_by_current_suite()]
        # 覆盖缺口越多，κ_c 要求越高；上限由 δ_joint 与样本量界定
        return max(0.0, 1.0 - len(uncovered) / max(len(scenarios), 1)) * (1 - delta_joint)

# IP-446 HPC-E++ 统一准入门（预测-见证）

@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'                 # v23 四证门
    trw: TorqueResidualObserver
    mgel: MeasurementGroundedEnergyLedger
    cpl: CommonsensePriorLayer
    cmcc: CrossModalConsistencyCertificate

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               q, dq, ddq, tau_meas, tau_current_est, tau_encoder_est,
               vision_claim, ctx_obs, proprio) -> tuple[bool, dict]:
        # 1) v23 基础（四证）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False, {"reason": "v23_gate"}
        # 2) 力矩见证：任何接触即否决；不健康亦否决
        w = self.trw.step(q, dq, ddq, tau_meas, tau_current_est, tau_encoder_est)
        if w.contact:
            return False, {"reason": "torque_witness_veto", "witness": w}
        # 3) 严重度证书
        if not self.trw.severity_ok(w, q):
            return False, {"reason": "severity"}
        # 4) 能量单向收紧
        if not self.mgel.reserve_ok(E_res, plan.E_fallback, plan.E_reach, margin_req):
            return False, {"reason": "energy_upper"}
        # 5) 常识收缩算子
        risk = self.cpl.context_risk(ctx_obs)
        if not self.cpl.tighten(plan.domain, risk).contains(plan):
            return False, {"reason": "commonsense_contraction", "risk": risk}
        # 6) 跨模态一致性（只 escalate）
        c4 = self.cmcc.check(vision_claim, w, q, risk, proprio)
        if c4.escalate:
            return False, {"reason": "cross_modal_contradiction",
                           "attribution": self.cmcc.attribute(c4), "c4": c4}
        return True, {"witness": w, "risk": risk}

        delta_joint = self._empirical_joint_blindspot(region)   # 压力测试估计

## 3. 正确性论证

### 引理 1（力矩见证的单向可靠性）
**陈述**：若传感器健康且 `|r| > ε_model + ε_sensor + |bias|`，则 `τ_ext ≠ 0`（发生接触）；反之 `|r|` 不超界**不能**推出 `τ_ext = 0`。

**证明**：`r = τ_ext + Δ_model + ν + bias`，由 `|Δ_model|≤ε_model`、`|ν|≤ε_sensor` 得 `|τ_ext| ≥ |r| − ε_model − ε_sensor − |bias| > 0`（三角不等式），故接触确实发生。反向：取 `τ_ext` 满足 `|τ_ext| ≤ ε_model` 且 `Δ_model = −τ_ext`、`ν=0`，则 `r=0` 而接触存在，故零残差不蕴含无接触。∎

### 引理 2（严重度上界的保守性）
**陈述**：若雅可比非奇异，则端部接触力满足 `‖F‖ ≤ ‖J^†‖·(|r|+ε_model+ε_sensor+|bias|) = F_upper`，且 `I ≤ F_upper·t_react`、`P ≤ F_upper/A_min`。

**证明**：静态关系 `τ_ext = J^T F` ⇒ `F = (J^T)^† τ_ext`，`‖F‖ ≤ ‖J^†‖‖τ_ext‖ ≤ ‖J^†‖(|r|+ε_model+ε_sensor+|bias|)`（`τ_ext` 由残差反解并取最坏界）。冲量由力上界乘反应时延得；压强由最小接触面积 `A_min` 得。近奇异时 `‖J^†‖` 增大，上界自动变保守，不破坏可靠性。∎

### 引理 3（能量测量只收紧）
**陈述**：`E_upper = max(E_pred, E_meas+ε_E) ≥ E_pred`，故储备约束 `E_res ≥ E_fallback+E_upper+E_reach+E_margin` 比 v23 的纯预测约束更紧或相等，`Exec` 不增。

**证明**：由 `max(a,b) ≥ a` 得 `E_upper ≥ E_pred`；储备不等式右边随 `E_upper` 单调不减，故满足新约束的计划集 ⊆ 满足旧约束的计划集。测量只能通过发现低估抬高上界，无法降低上界。∎

### 引理 4（常识收缩性，条件性）
**陈述**：若自然语言编译器满足"每条 `Constraint_c` 只删计划"且 `Δκ_ctx ≥ 0`，则 `Fil_cs` 为收缩算子；若编译器不满足该性质（把放宽编码为"移除义务"），则收缩性失效。

**证明**：`Fil_cs(Θ) = Θ ∩ ⋂_c Constraint_c`，交集只能减小集合；`κ_c^ctx ≥ κ_c^base` 使 AbsCert 更难签发（同样只减）。故在编译器可靠的前提下收缩成立。反向由构造：若某 `Constraint_c` 实际是并集/补集（放宽），交集可能扩大集合，破坏收缩性。编译器是否严格收缩在一般情形不可判定（见最大风险）。∎

### 引理 5（收缩算子的复合仍收缩 → 单调链）
**陈述**：若 `O_1,…,O_k` 皆收缩，则 `O_k∘…∘O_1(Θ) ⊆ Θ`。特别地 `Exec_v24 = Fil_c4∘Fil_cs∘Fil_mgel∘Fil_csc∘Fil_trc(Exec_v23) ⊆ Exec_v23`。

**证明**：归纳。`O_1(Θ)⊆Θ`；设 `S_i⊆Θ`，则 `O_{i+1}(S_i)⊆S_i⊆Θ`。故复合结果 ⊆Θ。各模块的收缩性由引理 1–4 与"力矩只否决、CMCC 只 escalate"给出。∎

### 定理（HPC-E++ 的安全继承与残余风险界）
**陈述**：在 (i) 力矩/能量/CMCC 模块实现正确、(ii) 常识编译器收缩性成立、(iii) 联合盲区压力测试给出 `δ_joint` 三个前提下，`Exec_v24 ⊆ Exec_v23`，且"漏检人体接触"的残余风险 ≤ `max(δ_joint, P(ε_model 失效), P(编译器放宽))`；其中 `P(编译器放宽)` 不可由运行时证书界定。

**证明**：`⊆` 由引理 5。残余风险分解：预防失效（视觉召回 + 常识上调）与见证失效（力矩盲区）联合概率 ≤ `δ_joint`（前提 iii）；模型误差越界概率 `P(ε_model 失效)` 由校准证书界定；编译器放宽不受运行时证书约束（前提 ii 是假设而非保证），故其概率不可界定——这正是最大风险。∎
