# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新一轮；本轮灵感：「服务设计」×「分层规划」）

> R69 给闭环装上了一张嘴：面对歧义，它会看、会触、会问，并把不确定性劈成 aleatoric 与 epistemic。但 R69 的「问」仍然是一个**扁平、单层、单主体、一次性**的动作——它用当前一步的 `VoI(g)−c(g)` 选一个信息动作，仿佛这个问题只活在当下这一个决策 epoch 里，仿佛回答者只有一种、承诺只有一条、问错的代价只由当前帧承担。
>
> 一旦系统真正进入现场，它是**服务**而不是函数：
> - 它同时面对**多个角色**（用户、家属、远程操作员、药师、其他机器人），不同角色对同一个变量的**权威**不同——只有用户能说「这是我的杯子」，只有药师能确认「这是哪种药」，路人两个都不能；
> - 它受**承诺**约束（SLA/SLO：几分钟内送达、不进入卧室、不泄露病情、不连问超过两次）——每一次提问都是从前台**支取**一份注意力/信任/时延预算；
> - 它的行为横跨**多个规划层**（服务 → 任务/旅程 → 动作），R69 的保证只是**最底层**的保证。一个在服务层说出口的承诺，只有在它**所有可容许的低层细化**下都成立，才算真的成立。
>
> 本轮两个灵感正好补上这块被 R69 折叠掉的结构：
> - **服务设计**把「一次提问」放回**服务蓝图**：前台/后台、可见性线、接触点、失败点、服务恢复、角色与共同生产。提问不是信息交易，而是**一个会被记住、会失败、需要恢复的接触点**。
> - **分层规划**把「一次决策」放回**抽象-细化**：高层承诺 ↔ 中层方法 ↔ 底层轨迹，核心问题从来不是「哪层更强」，而是**高层保证能否在细化的每一步存活**（causal-link / abstraction-gap / replanning）。
>
> 核心命题：**把「问不问」升级为「在哪一层问、以谁为证据、花掉哪条承诺、失败后在哪一层恢复」。用服务蓝图表达多层承诺网络，用细化鲁棒性定义「承诺是否成立」，用分层信息价值（HVI）决定信息动作挂在哪一层，用角色授权路由决定「谁能回答」，用层级就位的服务恢复把「问错」降级为可认证、可审计、可再协商的服务失败，而不是把整条服务退回 R68 的全局保守。** 命名 **SCAFFOLD-RAS**（Service-blueprint Commitments under Abstraction, with Fail-safe Layered Decomposition）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个问题究竟在哪一层能改变决策——而它又花掉了我对谁的哪一条承诺？**」——提问不是免费的；每一次接触点都是一张从分层承诺账户里开出的支票。

## 0. 直觉与动机

**一个贯穿全轮的最小例子（居家照护机器人）**
L3（服务层）承诺：「5 分钟内把今晚的药送到，且不进入卧室、不打扰睡眠」。L2（旅程层）方法选择：「从客厅药盒取」还是「从旅行药盒取」。L1（动作层）抓取/导航/注视。问题「哪一个是今晚的药盒？」若挂在 L1，只能改变抓取轨迹，几乎不改任何有价值的东西；若挂在 L2，它能切换整个方法（去客厅 vs 去玄关），价值巨大。但「去问睡着的用户」直接违反 L3 的「不打扰」承诺；「去问路过的家属」又超出其权威（会喂错药）。正确做法是：先由后台（标签 OCR + 用药记录）在 L1/L2 内部消解；消解不了，才把问题**上浮**为一次前台接触点，并由 LOV 门控选择不违反承诺的渠道；若回答与标签冲突，由 SAR 路由到**有权威的药师/远程操作员**做第二个正交证据；若仍然不确定，SRec 在**上一层**恢复（例如把两个药盒带到床边让用户指认，把「进入卧室」重协商为「门口展示」），而不是全局刹车。这个例子把本轮五个直觉串起来。

**灵感 1（服务设计 → 蓝图本来就是分层的，提问是一个接触点）**
直觉：服务蓝图的三条线——交互线、可见性线、内部交互线——本质上就是**抽象边界**：哪些是用户可见的前台、哪些是可被后台消解的、哪些属于支撑流程。R69 把所有不确定性都推到同一个「问用户」出口，等于取消了可见性线：凡是模型不确定，就打扰前台。服务设计说反了——**能后台算清的绝不前台问；必须前台问的，才动服务预算**。于是「不确定性处置」第一次有了一个**成本正确的默认值**：内部消解优先，前台接触点稀缺。

**灵感 2（分层规划 → 抽象承诺只有在其所有细化下存活才算数）**
直觉：在分层规划里，抽象算子 `a` 被细化为一组具体计划 `ρ(a)`；一个在抽象层成立的保证，可能被某个细化打破（经典的 causal-link threat）。R69 的保证只在单层陈述，它当然「成立」，因为它根本没有被细化过。R70 的核心动作是把**承诺写成受保护的因果链**，并要求它**在小写化的每一步都存活**：任何会威胁承诺的细化，要么被排除，要么触发恢复/再协商。这样我们就第一次能给「服务承诺」一个可检验的语义，而不是一句口号。

**灵感 3（分层规划 → 信息只有在能改变某层的选择时才值钱）**
直觉：R69 的 VoI 是「模态后验熵下降」。但信息的意义是**改变决策**：一个把抓取标准差砍半、却改不了「去哪取药」的问题，价值接近零；一个熵只降一点、却决定「今天到底吃哪种药」的问题，价值极高。分层规划告诉我们，决策发生在不同抽象层，信息必须**挂到它能撬动的那一层**才有杠杆。定义**分层信息价值 HVI**：期望可行计划集价值的变化（含方法切换价值 + 选项价值）减去预算影子价格与承诺风险。它同时解释了两种 R69 做不到的行为：**该问而不问**（低杠杆高熵）与**不该问却问**（高杠杆低熵）。

**灵感 4（服务设计 → 预算是分层账户，不是每步重置）**
直觉：R69 的 `c(g)` 是一个外生常数，隐含「问一次和问第十次同价」。但服务预算是有存量的：注意力、信任、时延、隐私额度都在旅程中被消耗；现在花掉唯一一次「用户问题」，可能让下一刻真正关键的时刻无话可问。把交互建模为**分层预算下的最优停止**：由旅程级动态规划给出影子价格，贪心 R69 恰好是「影子价格为零、只有一层」的退化。服务设计因此把「何时问」从工程阈值变成一个有理论依据的**资源分配**问题。

**灵感 5（服务设计 → 失败按层恢复，而不是全局保守）**
直觉：R69 对「问错」只有一种反应：退回 R68 纯保守。这像一个服务机构对任何一次投诉都关门歇业。服务设计不幻想零失败，它设计**恢复**：解释、换渠道、降级、转人工、重协商。更关键的是**恢复必须发生在正确的层**：探针超时是 L1 失败，不该触发 L3 的服务降级；方法不可行是 L2 失败，应当重规划；承诺守不住才是 L3 失败，应当显式再协商。把「问错」变成一次**层级就位、预认证、有预算、被审计的服务失败**，正是对 R69 最大风险的正面回答——**错可以发生，但不能悄悄发生，也不能让局部错误拖垮全局安全**。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（SCAFFOLD-RAS 总览）** SCAFFOLD-RAS = (SBH, PCR, RRC, HVI, LSA, SAR, SRec, LOV-G, FLUID†)。六条不变式：
(i) **实时 L1 零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **承诺-细化不变式**：每个活跃承诺要么是 refinement-robust（定义 314），要么被显式标记 renegotiable；任何交互、任何细化不得违反未再协商的活跃承诺；
(iii) **层级就位**：每个信息动作必须挂在一个「它能改变决策」的层（定义 317）；能由低层后台廉价消解的歧义不得上浮为前台接触点；
(iv) **角色-授权证据纪律**：证据按 `(actor, variable)` 授权加权；影响承诺或不可逆的决策需跨角色两个授权源一致，或单源高授权且存在恢复边（定义 318）；
(v) **恢复闭包**：每个失败点都有预认证的层级就位恢复边，否则该接触点禁止（定义 320）；
(vi) **预算分层**：交互额度是跨层、跨旅程的稀缺资源，按 HVI 的影子价格分配（定义 316、321）。

**定义 311（服务蓝图分层 SBH）** 层集 `𝓛 = {L3 服务, L2 旅程/任务, L1 动作}`，每层有抽象映射 `α_ℓ`、动作集 `𝒜_ℓ`、以及细化算子 `ρ_ℓ: 𝒜_ℓ → 2^{Plans_{ℓ-1}}`。SBH = `(V_actor, V_touch, E_flow, E_recover, fail, auth, ℓ_touch, vis)`：角色节点、接触点节点、旅程流边、恢复边、失败点集合、授权映射、接触点所挂层、前台/后台划分。三条服务设计线对应三个抽象边界：交互线 = 角色↔前台，可见性线 = 前台↔后台，内部交互线 = 后台↔支撑。每个接触点 `τ` 带成本向量 `c(τ)=(时间, 注意力, 隐私, 社交)` 与前置/后置条件。

**定义 312（承诺 = 受保护的因果链 PCR）** 承诺 `p = (actor, scope, φ, D, margin)`：`φ` 是该角色可观测量上的谓词，`D` 是截止/决策点，`margin` 是允诺余量。承诺在分层规划语义下就是一条**受保护的因果链**：把服务目标与某个低层效果相连；一个细化 `r` **威胁** `p`，当且仅当 `r` 能达到该效果却使 `φ` 在 `D` 前失效，或抽掉了支撑关系。活跃承诺账本 `C_t` 是所有未完成、未再协商的 `p`。违例是「有效承诺 + 可观测量 + 时间」的三元事件。

**定义 313（细化关系与容许细化集）** 抽象计划 `π_ℓ` 的细化是一棵到 L1 的计划树；`≼` 为保守模拟关系（A99：`r ≼ π` 要求可观测迹包含、成本/风险在松弛内不增）。给定信念 `b`、资源上界与已认证 L1 前缀，**容许细化集**
`R(π,b) = { r ≼ π : r 与 b 一致、满足资源上界、且其 L1 前缀被 C-RAS-WM 认证 }`。
不可认证的细化不是「低概率分支」，而是**根本不允许被规划**——这把安全从「概率」移到了「可行性」。

**定义 314（细化鲁棒承诺与细化间隙）** `p` 是 `(ε,δ)`-refinement-robust，若
`∀r∈R: Pr[φ_r 在 D+ε 前成立] ≥ 1−δ`。
**细化间隙** `Γ(p) = sup_{r∈R} [ margin_abstract(p) − margin_r(p) ]⁺`。承诺有效当且仅当 `Γ(p) ≤ Γ_max`。直觉：抽象层会「超额许诺」，`Γ` 就是这笔看不见的**抽象债务**；R69 的保证等价于只取了 `R={identity}`，所以 `Γ≡0` 是它的隐含假设——也是它一旦进入多层就会失守的原因。

**定义 315（可行计划集与分层价值）** `F_t = { 完整计划 π=(π_L3,π_L2,π_L1) : π 在 R 下满足所有活跃承诺、L1 已认证、预算未超 }`。
`V(F_t) = max_{π∈F_t} E[U(π)] + β·Option(F_t)`，
其中 `Option(F_t)` 是未来可行计划集的**选项价值**（方法多样性/可恢复接触点的覆盖），`β` 校准「保留后路」的权重。服务设计所说的「保持关系/保持可选」在此成为一个可优化项。

**定义 316（分层信息价值 HVI）** 对挂在层 `ℓ` 的候选信息动作 `g`：
`HVI_ℓ(g|F_t) = E_{y|g}[V(F_{t+1}) − V(F_t)] − λ_b·cost_budget(g) − λ_p·Δpromise_risk(g)`，
其中 `ΔV` 含三部分：**同层后验改善** + **方法切换价值**（L2/L3 的最优方法改变）+ **选项价值变化**；`λ_b` 是交互预算的影子价格（定义 321），`λ_p` 是承诺风险的影子价格。只有当 `max_ℓ HVI_ℓ(g) > 0` 且层级就位时才执行。**R69 的 VoI 恰是「单层、λ_b=0、无承诺、无选项」的退化**。

**定义 317（层级就位 LSA）** 信息动作 `g` 对层 `ℓ` **就位**，若存在 `F_t` 中两个计划，它们仅在「`g` 的结果」上不同，且该差异改变 `ℓ` 层的选择（方法/承诺/动作）。定义杠杆率
`Lev(g,ℓ) = ΔV_ℓ(g) / ΔH(g)`（单位后验熵降低换来的计划价值变化）。
插入层级 `ℓ*(g) = argmax_ℓ HVI_ℓ(g)`，并要求 `Lev(g,ℓ*) ≥ τ_lev`；否则视为「高熵低杠杆」，不提问（这是 R70 能**主动少问**的机制）。

**定义 318（多主体路由 SAR 与授权条件证据）** 角色图 `G_actor`；每个角色 `a` 对变量 `v` 有权威 `auth(a,v)∈[0,1]`、可用性、时延、隐私画像、以及角色间欺骗相关 `ρ(a,a')`。路由为约束分配：
`(a*,ch*,q*,t*) = argmax HVI  s.t. auth(a,v)≥τ_auth, privacy_leak(q,a)≤ℓ_priv, available(a,t)`。
**授权条件证据**：回答的权重 `w = auth(a,v)·calibration(a)`；不可逆/影响承诺的决策需满足
（I）两个**不同角色**、授权有效、`ρ_cross<ρ_max` 的源一致；或（II）单源 `w·conf ≥ τ` 且该决策存在恢复边。R69 的「k 个正交源一致」是本定义在**所有角色授权相同、ρ 相同**时的特例。

**定义 319（可见性治理 LOV-G）** 策略决定「后台消解 / 上浮前台」。仅当以下之一成立才上浮 `τ`：(a) 不存在成本低于 `c(τ)` 的容许后台细化能把 `U_epi` 降到阈值下；(b) 该不确定性影响活跃承诺或角色自己的决策权（用户有权知道/决定）。上浮次数计入预算并审计。这是把「可见性线」变成一个**决策边界**，从机制上禁止「问用户机器人本可自己算的东西」。

**定义 320（分层服务恢复 SRec）** 恢复策略 `π_rec: (层, 失败) → r ∈ R_rec`，带成本与承诺影响，且必须被 C-RAS-WM 与承诺检查器预认证。**层级就位**：L1 失败 → 重探/局部回退；L2 失败 → 承诺保持的重规划/方法切换；L3 失败 → **显式再协商**或优雅降级（书面、可审计、回灌账本）。恢复预算 `B_rec`。服务恢复悖论建模为有界信任状态：成功恢复可部分修复信任，重复恢复加速透支——因此恢复次数本身进入 HVI 成本。

**定义 321（分层预算与最优停止）** 旅程级 DP：状态 `s=(b, C_t, 剩余预算向量, 信任)`，Bellman
`Q(s,g) = HVI(g|s) + γ·E_{y}[V^*(s')]`，
`λ_b` 由值函数对预算的边际给出。R69 的贪心是「单步、`λ_b=0`」的短视策略。若 `|接触点|` 小则做后向归纳；否则在 A101（自适应子模）下用贪心并获得 `(1−1/e)` 近似。

**定义 322（威胁模型 AIC-SCAFFOLD）** `ℰ_SCAFFOLD = ℰ_FLUID × ℰ_role × ℰ_level × ℰ_promise`：角色冒充/权威欺骗；跨角色共谋；提问式隐私刺探；**层级混淆**（把低杠杆问题伪装成高层决策，或把高层决策藏进后台细节以逃避前台审计）；**承诺钓鱼**（诱导系统许下过强承诺再制造违约）；**蓝图遗漏**（对手活动在未建模的角色/失败点中）。注意：蓝图完备性首次成为**攻击面的一部分**。

**定义 323（证书 J_SCAFFOLD）** `J_SCAFFOLD = (J_FLUID, blueprint_hash, promise_ledger_hash, Γ_max_obs, level_adequacy_rate, actor_routing_log_hash, recovery_used, privacy_budget_used, lov_surfacing_rate, scaffold_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ 所有活跃承诺 robust 或已再协商 ∧ 恢复闭包成立 ∧ 授权纪律满足 ∧ 隐私/层级/预算未越界 ∧ `Γ ≤ Γ_max`。

**定义 324（退化链与承诺保持的重规划）** 回退链：SCAFFOLD →（承诺不鲁棒 / 无层级就位动作 / 授权-隐私不可行 / 恢复预算耗尽）→ FLUID（坍缩为单层、去承诺）→（ECE 越界 / 流异常）→ R68 的 `λ_floor`。每一步能力单调不增、保守单调不减，安全侧永不变弱。**承诺保持的重规划**：L2/L3 方法切换必须 (a) 新方法属于 `F_{t+1}`；(b) 不威胁任何活跃因果链；(c) 与当前执行存在已认证且连续的公共 L1 前缀（无跳变）。

    levels = ('L3_service', 'L2_journey', 'L1_motion')
    def refine(self, abstract_action, level): ...          # ρ_ℓ
    def admissible_refinements(self, plan, belief, budget):
        return [r for r in self.refine(plan, plan.level-1)
                if self.simulates(r, plan) and c_ras_wm.certify(r.prefix)]

# IP-265/266 PCR + RRC：承诺 = 受保护因果链；检查细化鲁棒性
def promise_robustness(promises, R):
    worst_gap, ok = 0.0, True
    for p in promises:
        gap = max(0.0, max(margin_abstract(p) - margin_under(p, r) for r in R))
        ok = ok and gap <= GAMMA_MAX
        worst_gap = max(worst_gap, gap)
    return ok, worst_gap                              # (robust?, Γ)

# IP-267/268 HVI + LSA：在哪一层问、值不值得问
def hvi(g, level, F_t, budget, promises):
    dV  = expected_plan_value_after(g, level, F_t) - value(F_t)   # 含方法切换
    dV += option_delta(F_t, g)                                    # 保留后路
    return dV - budget.shadow_price(g) - promise_risk(g, promises)

def choose_touchpoint(cands, F_t, budget, promises):
    scored = [(hvi(g, l, F_t, budget, promises), g, l)
              for g in cands for l in levels_for(g)]
    if not scored: return None
    score, g, l = max(scored)
    if score <= 0 or leverage(g, l) < TAU_LEV: return None        # 高熵低杠杆：不问
    return (g, l)

# IP-269 SAR：谁有权威回答；跨角色相关欺骗下必须正交
def route_sources(var, F_t, promises):
    feasible = [(a, ch) for (a, ch) in actors
                if auth(a, var) >= TAU_AUTH
                and privacy_leak(var, a) <= L_PRIV and available(a)]
    return argmax_assignment(feasible, hvi, corr=rho(a, a'),
                             discipline='cross_role_two_source_or_recoverable')

# IP-270 SRec：按层恢复，绝不因 L1 失败全局保守
def recover(failure):
    if failure.level == 'L1':  return re_probe_or_local_fallback(failure)
    if failure.level == 'L2':  return certified_replan(failure)   # 承诺保持
    return renegotiate_or_degrade(failure.promise)               # L3：显式记账

# IP-271 LOV-G：能后台消解就不打扰前台
def visibility_gate(U_epi, actor_decision, promises):
    if actor_decision or affects_promise(U_epi, promises): return 'surface'
    if backstage_resolves(U_epi) and cost_backstage < cost_surface: return 'backstage'
    return 'surface_if_budget'

# IP-274 主闭环（L1 完全继承 R69；L2/L3 在慢节拍上异步）
def SCAFFOLD_RAS_round(M, obs):

    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)

    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    slow = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated) > TAU_FMA
    # ---- L2/L3：分层承诺检查（慢节拍；只切换已认证公共前缀）----
    R = M.sbh.admissible_refinements(M.plan, M.belief, M.budget)
    robust, gap = M.rrc.check(M.pcr.active(), R)
    if not robust:
        M.plan, _ = M.srec.replan_or_renegotiate(M.plan, M.pcr.active())
        R = M.sbh.admissible_refinements(M.plan, M.belief, M.budget)
    F = M.sbh.feasible_plans(M.belief, M.pcr.active(), M.budget)
    # ---- 层级就位 + 角色路由 + 可见性治理 ----

            if U_epi > TAU_EPI and not slow else None)
    if pick and M.lov_gate.allow(pick):

        src = M.sar.route_sources(variable_of(g), F, M.pcr.active())
        ans = M.cia.execute(g, src)

        U_epi = M.cia.update_belief(modes, ans, auth=src.authority)
    # ---- L1 风险缩放（继承 R69/R68，安全侧不让步）----

    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    # ---- 参与式审计 + 分层证书 ----
    M.vqa_i.submit_async(pick, M.pcr.active(), gap, src)
    return k, lam, select_mode(modes, U_epi, lam), (U_ale, U_epi)

## 3. 推导

**引理 19（HVI 的分解与 R69 的退化）** 在 A99（保守抽象）下，
`HVI_ℓ = ΔH_ℓ·∂V/∂H + ΔV_method + ΔOption − λ_b·c_budget − λ_p·Δrisk`。
取 `|𝓛|=1`、`C=∅`、`λ_b=0`、`Option≡0`，则 `HVI = VoI − c`，即 R69 的选择规则。系：存在 `VoI>0` 而 `HVI<0` 的状态（低杠杆高熵，问了也改不了任何层），也存在 `ΔH≈0` 而 `HVI≫0` 的状态（高杠杆低熵，例如一句「哪盒是今晚的药」直接切换 L2 方法）。**所以 R70 能同时做到「少问」与「问对层」**。

**引理 20（细化鲁棒 ⇒ 承诺保持，且抽象债务可界定）** 设 A99（每层抽象松弛 `ε_abs,ℓ`、模拟松弛 `ε_sim,ℓ`）与 A100（恢复闭包、恢复预算 `B_rec`）成立。若每个活跃承诺 `(ε,δ)`-refinement-robust，且失败按定义 320 层级恢复，则组合系统对每条承诺的满足概率 `≥ 1 − δ − δ_rec`，且
`Γ_total ≤ Σ_ℓ (ε_abs,ℓ + ε_sim,ℓ) + max_{r∈R} slack_cost(r)`。
即抽象层「多许诺」的部分有一个**可计算、可入证书**的上界，而不是隐藏假设。R69 的 `Γ≡0` 只是 `R={identity}` 的特例。

**引理 21（角色相关欺骗下的采纳上界）** 设每源被欺骗概率 `δ_p`，跨角色欺骗相关 `ρ_c`。采用定义 318 的「k 个不同角色授权源多数一致」后，错误采纳率
`≤ δ_p·ρ_c^{k−1} + ε_cal`。
系（关键警告）：若角色可任意共谋，`ρ_c→1`，跨角色一致**不提供任何保证**；此时唯一可靠的是**物理独立通道**（传感器 vs 人类）或**可恢复性**（决策存在恢复边）。故证据纪律必须与恢复闭包联合使用，不能只靠「多问几个角色」——这正是服务设计中「不要把同一套后台系统伪装成多个前台」的形式化。

**引理 22（分层恢复的承诺违约上界）** 若每个失败点 `f` 有层级就位、预认证的恢复边且总恢复成本 `≤ B_rec`，则期望承诺违约
`≤ Σ_f p_f·1[恢复不可行或超预算] + ε_ext`。
R69 的「停止提问、全局保守」是本界的**退化恢复策略**（`R_rec={stop}`）：它把恢复成本转成了任务失败成本。层级恢复用**局部、低层**的恢复替代全局失败，因此在不放松安全的前提下降低总损失。

**定理 18（SCAFFOLD 严格包含 FLUID 与 R68）** 在 A99–A101 下，对任意状态，SCAFFOLD 的期望安全风险 `≤ FLUID ≤ R68`，而期望服务价值 `≥ FLUID`。当蓝图退化为单层、单角色、`C=∅`、`R={identity}`、恢复恒等、且 `HVI≡VoI` 时，SCAFFOLD 的执行序列与 FLUID **逐指令相同**；再叠加 `VoI≤c` 时与 R68 相同。故 R69 与 R68 都是**退化蓝图**：分层没有在安全侧做任何让步。

**定理 19（承诺保持的重规划无突变）** 若每个被接受的交互都层级就位且承诺鲁棒，且每次 L2/L3 方法切换都满足定义 324 的承诺保持条件（新方法可行、不威胁因果链、与当前执行有已认证连续公共 L1 前缀），则执行轨迹在 R68/R69 意义下连续，无跳出安全包络的突变；每次承诺违约要么被阻止，要么伴随一次显式、可审计的再协商事件。回退链 SCAFFOLD→FLUID→R68 的 `λ` 单调不降，故安全单调。

**定理 20（贪心的次优性与近似保证）** 分层预算最优停止问题中，R69 式贪心可任意次优（构造：唯一一次高杠杆提问机会被前面的低杠杆问题花掉，比值随旅程长度无界）。若接触点的条件价值满足 A101（自适应子模），则贪心 HVI 的期望价值 `≥ (1−1/e)·OPT − λ_b·B`；否则应由定义 321 的 DP 求解 `|接触点|` 较小的关键旅程。系：**R69 的贪心安全但不最优，R70 用分层 DP 换来「把问题留到该问的那一层」的能力**。

## 6. 本轮最大风险

**次级风险与缓解**：
1. **蓝图不完备**（漏角色/漏失败点/漏接触点）→ 蓝图遗漏注入对抗训练 + E310 + 运行期「未建模接触点检测」；无法检测时按 L3 最保守承诺处理；
2. **抽象债务被低估**（A99 不成立、`Γ` 实际超界）→ 证书强制 `Γ_obs ≤ Γ_max`，超界即降级到 FLUID；E302 直接测 `Γ`；
3. **分层带来时延/切换抖动** → L1 永不等待 L2/L3，只切换已认证公共前缀，慢节拍预算硬约束（定理 19）；
4. **角色共谋使「多源一致」失效** → 引理 21 系：强制物理独立通道或可恢复性，绝不把同一后台包装成多个前台；
5. **承诺钓鱼/层级混淆** → 定义 322 威胁模型 + E311，承诺强度进入审计与证书，过强承诺默认拒绝。

**一句话最大风险**：SCAFFOLD 的全部安全性押在「服务蓝图完备、承诺语义正确」这一前提上——一旦蓝图漏掉一个角色或失败点，或承诺被写错/被诱导写得过强，分层认证只会让系统更自信地守住一个**虚构的承诺**、同时悄悄违反真正重要的那一个，即「**图错，层越多，错得越有据可依**」。

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** `SCAFFOLD-RAS=(SBH,PCR,RRC,HVI,LSA,SAR,SRec,LOV-G,FLUID†)`：L1 零学习写操作；承诺-细化不变式；层级就位；角色-授权证据纪律；恢复闭包；预算分层。

**定义 311–313（蓝图分层 / 承诺 / 细化）** 三层蓝图与三条服务线对齐；承诺 = 受保护因果链；`R(π,b)` 只含与信念一致、资源可行、L1 认证的细化；不可认证细化不是低概率分支，而是**不允许被规划**。

**定义 314（细化鲁棒与间隙）** `∀r∈R: Pr[φ_r 在 D+ε 前成立] ≥ 1−δ`；`Γ(p)=sup_r[margin_abs−margin_r]⁺ ≤ Γ_max`。R69 的保证等价于 `R={identity}`、`Γ≡0` 的隐含假设。

**定义 315–317（分层价值 / HVI / LSA）** `F_t`、`V(F)` 含选项价值；`HVI=ΔV−λ_b c_budget−λ_p Δrisk`，`ΔV` 含同层后验 + 方法切换 + 选项；`Lev≥τ_lev` 才提问。R69 的 VoI = 单层、λ_b=0、无承诺、无选项。

**定义 318（SAR 与授权证据）** 约束分配 `argmax HVI` s.t. 权威/隐私/可用；决策需「两个不同角色授权源一致且 ρ_cross<ρ_max」或「单源高授权 + 存在恢复边」。

**定义 319（LOV-G）** 仅当后台无法廉价消解，或不确定性影响活跃承诺/角色决策权时才上浮；上浮计入预算并审计。

**定义 320（SRec）** L1 重探/局部回退；L2 承诺保持重规划；L3 显式再协商或优雅降级；恢复预算 `B_rec`；恢复次数进入 HVI 成本（恢复悖论有界）。

**定义 321（分层预算 DP）** `Q(s,g)=HVI+γE[V*(s')]`；`λ_b` 为预算边际值；小规模后向归纳，大规模在 A101（自适应子模）下贪心得 `(1−1/e)` 近似。

**定义 322–324（威胁 / 证书 / 退化链）** `ℰ_SCAFFOLD=ℰ_FLUID×ℰ_role×ℰ_level×ℰ_promise`（含蓝图遗漏）；J_SCAFFOLD 并入蓝图/承诺/Γ/层级/角色/恢复/隐私/可见性证据；回退 SCAFFOLD→FLUID→R68 单调；方法切换须满足承诺保持三条件（可行、不威胁因果链、公共 L1 前缀连续）。

## 3. 关键算法伪代码

```python
# IP-264 SBH：预计算细化树，在线只查表
class ServiceBlueprintHierarchy:
    levels = ('L3_service', 'L2_journey', 'L1_motion')
    def admissible_refinements(self, plan, belief, budget):
        return [r for r in self.refine(plan, plan.level-1)
                if self.simulates(r, plan) and c_ras_wm.certify(r.prefix)]

# IP-266 RRC：承诺 = 受保护因果链，检查细化鲁棒性与 Γ
def promise_robustness(promises, R):
    gaps = [max(0.0, max(margin_abstract(p) - margin_under(p, r) for r in R))
            for p in promises]
    return all(g <= GAMMA_MAX for g in gaps), max(gaps, default=0.0)

# IP-267/268 HVI + LSA：在哪一层问、值不值得问
def hvi(g, level, F_t, budget, promises):
    return (expected_plan_value_after(g, level, F_t) - value(F_t)  # 含方法切换
            + option_delta(F_t, g)                                 # 保留后路
            - budget.shadow_price(g) - promise_risk(g, promises))

def choose_touchpoint(cands, F_t, budget, promises):
    scored = [(hvi(g, l, F_t, budget, promises), g, l)
              for g in cands for l in levels_for(g)]
    if not scored: return None
    score, g, l = max(scored)
    return (g, l) if (score > 0 and leverage(g, l) >= TAU_LEV) else None

# IP-269 SAR：权威/隐私/相关欺骗感知路由
def route_sources(var, F_t):
    feasible = [(a, ch) for (a, ch) in actors
                if auth(a, var) >= TAU_AUTH and privacy_leak(var, a) <= L_PRIV]
    return argmax_assignment(feasible, hvi, corr=rho,
                             discipline='cross_role_two_source_or_recoverable')

# IP-270 SRec：按层恢复，不因 L1 失败全局保守
def recover(failure):
    if failure.level == 'L1': return re_probe_or_local_fallback(failure)
    if failure.level == 'L2': return certified_replan(failure)
    return renegotiate_or_degrade(failure.promise)      # L3 显式记账

# IP-271 LOV-G：能后台消解就不打扰前台
def visibility_gate(U_epi, actor_decision, promises):
    if actor_decision or affects_promise(U_epi, promises): return 'surface'
    if backstage_resolves(U_epi) and cost_backstage < cost_surface: return 'backstage'
    return 'surface_if_budget'

# IP-274 主闭环：L1 完全继承 R69；L2/L3 慢节拍异步，只切已认证公共前缀
def SCAFFOLD_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    slow = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated) > TAU_FMA
    # L2/L3：承诺-细化检查（慢节拍）
    R = M.sbh.admissible_refinements(M.plan, M.belief, M.budget)
    robust, gap = M.rrc.check(M.pcr.active(), R)
    if not robust: M.plan, _ = M.srec.replan_or_renegotiate(M.plan, M.pcr.active())
    F = M.sbh.feasible_plans(M.belief, M.pcr.active(), M.budget)
    # 层级就位 + 角色路由 + 可见性门控
    pick = (M.hvi.choose_touchpoint(M.sbh.candidates(F), F, M.budget, M.pcr.active())
            if U_epi > TAU_EPI and not slow else None)
    src = g = None
    if pick and M.lov_gate.allow(pick):
        g, lvl = pick
        src = M.sar.route_sources(variable_of(g), F)
        ans = M.cia.execute(g, src)
        if not M.rrc.answer_consistent(ans, src, M.pcr.active()):
            ans = M.srec.recover(TouchpointFailure(lvl))
        U_epi = M.cia.update_belief(modes, ans, auth=src.authority)
    # L1 风险缩放（继承 R69/R68）
    U_floor = U_ale + (U_epi if pick is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if slow: lam = max(lam, 0.8)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    M.vqa_i.submit_async(pick, M.pcr.active(), gap, src)
    return k, lam, select_mode(modes, U_epi, lam), (U_ale, U_epi)
```

## 4. 推导

**引理 19（HVI 分解 / R69 退化）** `HVI_ℓ = ΔH·∂V/∂H + ΔV_method + ΔOption − λ_b c_budget − λ_p Δrisk`。`|𝓛|=1, C=∅, λ_b=0, Option≡0` 时退化为 R69 的 `VoI−c`。系：存在 `VoI>0` 而 `HVI<0`（低杠杆高熵，不问）与 `ΔH≈0` 而 `HVI≫0`（高杠杆低熵，问对层）。

**引理 20（细化鲁棒 ⇒ 承诺保持，抽象债务有界）** A99+A100 下，`(ε,δ)`-refinement-robust 承诺在层级恢复后满足概率 `≥1−δ−δ_rec`，且 `Γ_total ≤ Σ_ℓ(ε_abs,ℓ+ε_sim,ℓ)+max_r slack_cost(r)`。抽象债务可计算、可入证书，R69 的 `Γ≡0` 只是 `R={identity}`。

**引理 21（角色相关欺骗上界）** k 个不同角色授权源多数一致后错误采纳率 `≤ δ_p·ρ_c^{k−1}+ε_cal`。系：`ρ_c→1`（任意共谋）时跨角色一致毫无保证，必须用物理独立通道或可恢复性；证据纪律必须与恢复闭包联合使用。

**引理 22（分层恢复违约上界）** 恢复闭包且总成本 `≤B_rec` 时，期望承诺违约 `≤ Σ_f p_f·1[恢复不可行或超预算]+ε_ext`。R69 的「停止提问」是 `R_rec={stop}` 的退化恢复：把恢复成本转成任务失败成本。

**定理 18（严格包含 FLUID / R68）** A99–A101 下安全风险 `SCAFFOLD ≤ FLUID ≤ R68`、服务价值 `SCAFFOLD ≥ FLUID`；单层单角色无承诺且 `HVI≡VoI` 时与 FLUID 逐指令相同；再叠加 `VoI≤c` 与 R68 相同。R69/R68 都是退化蓝图，安全侧不让步。

**定理 19（承诺保持重规划无突变）** 层级就位 + 承诺鲁棒 + 承诺保持切换（可行、不威胁因果链、公共 L1 前缀连续）⇒ 轨迹连续、无安全包络跳变；违约要么被阻止，要么伴随显式可审计再协商；回退链 λ 单调不降。

**定理 20（贪心次优性与近似保证）** 分层预算最优停止中 R69 式贪心可任意次优（低杠杆问题花掉唯一高杠杆机会，比值随旅程长度无界）；A101 自适应子模下贪心 `≥(1−1/e)OPT−λ_b B`，否则用定义 321 的 DP。R69 贪心安全但不最优。

## 7. 本轮最大风险

**次级风险与缓解**：蓝图不完备（遗漏注入对抗训练 + E310 + 未建模接触点检测，无法检测时按 L3 最保守承诺）；抽象债务低估（证书强制 `Γ_obs≤Γ_max`，超界即降 FLUID，E302 直测）；分层时延/切换抖动（L1 永不等待 L2/L3，只切已认证公共前缀）；角色共谋（引理 21 系：强制物理独立通道或可恢复性，不把同一后台包装成多个前台）；承诺钓鱼/层级混淆（定义 322 + E311，过强承诺默认拒绝并入审计）。

**一句话最大风险**：SCAFFOLD 的全部安全性押在「服务蓝图完备、承诺语义正确」这一前提上——一旦蓝图漏掉一个角色或失败点，或承诺被写错/被诱导写得过强，分层认证只会让系统更自信地守住一个**虚构的承诺**、同时悄悄违反真正重要的那一个，即「**图错，层越多，错得越有据可依**」。
