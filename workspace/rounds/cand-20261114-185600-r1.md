# 第 75 轮（承接第 74 轮「SENTGAUGE-RAS 契约异常哨兵 × 物体证据计量 × 约定计量适应 × 门控组合代数」IP-303~309；本轮灵感：「轨迹优化」×「深度学习」）

> R74 用 anytime-valid 哨兵把 R73 的「自信地组合一个错误世界」改造为「诚实地发现并退出错误世界」。但 R74 自认的最大风险（声明族过宽→致盲、过窄→误杀）其实掩盖了一个更根本的前提：
> - **哨兵检验的是策略实际采样的分布，不是我们声称关心的部署分布。** 轨迹优化（PVOP/MPC/RL）会主动选择「证据好看」的视角、距离、材质与接触模式；哨兵因此只在一个被策略筛选过的子集上积累证据。e-process 的 anytime-valid 性并没有被破坏——**可预测赌注对可选停止甚至可选续采都稳健**；被破坏的是「未检出 = 全域安全」这一解释。这是**覆盖问题**，不是有效性问题。
> - **深度学习让零假设本身随数据漂移。** 材质后验、在线自校准 u_calib、NCM 的 κ、赌注网络、世界模型都在拟合；若「学习」与「检测」共享时间窗与数据，则 conformal 的交换性、e-process 的超鞅性会**静默**失效——证书照样通过，但它认证的是一个被自己改写过的世界。
> - **证书的适用范围无人计量。** R74 的 J_SENT 语义默认「有效 ⇒ 部署分布安全」，而它实际只对访问测度成立；两者之差（覆盖缺口）既没有符号、也没有上界，更没有进入退化链。
>
> 本轮两个灵感分别给出「测量」与「分离」：
> - **轨迹优化 → 访问测度成为一等公民。** TEC 在证据契约里显式声明目标测度 μ（部署分布）与设计测度 ν（策略实际采样）；OPE-SENT 用离策略 e-process 对 μ 做检验，并给出每步重叠边际 η_t、视界有效样本量 ESS_H 与覆盖缺口证书 CoverCert；CERTRAJ 的轨迹目标把「否证信息量」当作与任务进度并列的优化项。
> - **深度学习 → 学习器与审计器的严格分离。** PQ-CAL 预序校准审计对**任意**深度模型、**任意**（含对抗）训练方式有效，只要「预测先于结果」；INV-AUDIT 用设计干预检验不变性，拒绝「捷径证书」；CERT-PO 用可微代理训练、用非可微审计定案（训练可微，认证必须可证伪）。
>
> 核心命题：**不再问「现实是否在契约内」，而问「我们究竟在契约的哪个子集上采集了证据，这个子集能否支撑对部署分布的断言，以及深度模型是在压缩覆盖缺口还是在制造捷径？」** 把 SENTGAUGE 重构为 **CERTRAJ-RAS**（Certificate-constrained TRAjectory optimization with deep evidence metrology for RAS）——**覆盖锚定、预序可审的认证轨迹优化**。

## 0. 直觉与动机

### 灵感 1（轨迹优化 → 策略在替你选择「考卷」）

直觉：把证据认证想成考试。R74 的哨兵是一套严格的阅卷规则，但它只批改**学生自己选的题**。轨迹优化是一个极聪明的学生：优先做简单题（走近、正对、漫反射材质），避开难题（透明、镜面、远距离、大入射角）。阅卷规则本身没错，错的是「没做完的题也算满分」。更糟的是，如果学生知道阅卷器的内部状态，它会直接学「让分数好看的解法」——这不是个别作弊，而是任何优化器面对可观测评价指标时的必然（Goodhart）。

严谨化：设部署关心的测度为 μ（状态–动作–观测空间上），策略 π 诱导设计测度 ν_π。哨兵在 ν_π 上检验契约；证书真正保证的是 R_ν，而部署风险是 R_μ。二者之间是总变差/KL 缺口。R74 隐含假设 μ = ν_π（行为策略即部署策略），而主动感知、任务优化与安全规避恰恰使 μ ≠ ν_π。本轮第一件事，就是把「证书在哪个测度上成立」写进契约与证书本身（定义 399–401）。

### 灵感 2（深度学习 → 学习器提案，审计器否证）

直觉：深度模型是必要的——材质分类、噪声预测、世界模型、赌注函数都需要它。但深度模型有两个危险的「礼貌」：(i) 它在你给它的数据分布上表现极好，包括学到与安全无关的捷径特征；(ii) 被在线更新后，它会让任何「用同一批数据拟合又检验」的统计程序悄悄失去校准。解决办法不是不用深度模型，而是**不让它参与给自己发证书**。

严谨化：预序（prequential）原则——模型在时刻 t 的预测 F̂_t 只能依赖 t 之前的观测；若模型正确，则 PIT 序列 u_t = F̂_t(y_t) 在给定过去条件下是 U(0,1)，**与模型如何训练、参数多大无关**。因此对 u_t 序列做可预测赌注的 e-process，就得到对任意黑箱深度模型成立的校准审计（定义 404、引理 44）。代价是必须严格执行「预测先于结果」的时间分离；任何用未来数据回填的「回测」都会让审计静默失效（no-peeking 账本 + 引理 44 的反例）。

### 灵感 3（两者的交汇 → 认证三难与覆盖缺口）

直觉（认证三难）：固定证据预算下，下面三件事最多同时满足两件：
1. **任务最优**：轨迹确实朝高收益走（必然使 ν 偏离 μ）；
2. **全域覆盖**：证书对部署分布 μ 成立（要求 d_TV(μ,ν)=0 或可忽略）；
3. **有限样本非空**：证书在置信水平下有实质约束力（要求支撑集上有足够有效样本）。

想要 1+2，就得不计成本地在 μ 的整个支撑上采样（放弃效率）；想要 1+3，就要接受一个明确的覆盖缺口（承认对未访问区无证书）；想要 2+3，就得让行为策略 = 部署策略、不做主动选择（放弃轨迹优化收益）。这不是工程缺陷，而是「主动数据采集 + 分布无关认证」的结构性张力（定理 32 的推论）。

严谨化（一句定理）：R_μ(E) ≤ R̂_ν(E) + slack(n,α) + d_TV(μ,ν) + ε_extrap。深度模型只能帮助降低 R̂_ν（在 ν 上拟合更好），或通过**被审计的**不变性来「借」覆盖；它不能凭空降低 d_TV。轨迹优化降低任务代价、却可能抬高 d_TV——它同时是收益来源与证书风险来源。

### 灵感 4（把覆盖缺口做成可退化的对象）

R74 的退化链是「模块失效 → stub」。覆盖缺口给出一种新降级：不是某个模块坏了，而是**证书的适用范围缩小了**。定义 CAD（Coverage-Aware Degradation）：当 CoverCert 的覆盖下界低于预注册阈值 ε_cov 时，系统不假装安全，而是显式收缩「声称安全的区域」，把未覆盖区标为 uncertified，并在其中退化为最保守策略（降速/停止/人类接管）。这把「检不出」从哲学问题变成有符号、有阈值、可审计的退化动作。

### 灵感 5（轨迹目标里的「否证红利」）

如果希望证书不是被动记录覆盖，轨迹优化应主动去买「否证信息」。定义 falsification bonus：轨迹目标加入期望对数 e-process 增长率 E[Δlog E_t | a] 作为「该动作能多快暴露契约错误」的代理。但必须防止策略反向利用（刷指标）：审计器内部赌注状态对学习器不可见（信息屏障 AIB），审计探针随机化（RCT 式），且探针不计入任务收益——否则重演 Goodhart。

### 灵感 6（与 R74 的关系：不是替代，是补一个缺失的「测度标签」）

SENTGAUGE 的哨兵、门控、组合代数全部保留；CERTRAJ 只做三件事：(i) 在契约上标注 μ/ν 与覆盖字段；(ii) 在哨兵上套离策略/预序审计；(iii) 在轨迹优化里把覆盖与否证信息量显式化。R74 是 CERTRAJ 在 ν=μ、η=1、深度模型冻结、无探针预算时的严格特例（定理 34）。

## 1. 形式化定义（增量：定义 398–414）

**定义 398（CERTRAJ-RAS 总览与八不变式）** CERTRAJ-RAS = (TEC, OPE-SENT, PQ-CAL, CERT-PO, INV-AUDIT, J_TRAJ, SENTGAUGE†)。八不变式 = R74 六不变式 +：
(vii) **覆盖完备**：每张证书必须声明目标测度 μ、设计测度 ν 与 CoverCert；未声明适用测度的证书无效；
(viii) **审计分离**：学习器不得接触审计器内部状态（赌注、个体 PIT、e-process 值），预测必须严格先于结果。

**定义 399（轨迹条件证据契约 TEC）** TEC = (EC, μ, ν, η_min, H_max, κ_H, ε_cov, W_max, B_probe, sep)：
- EC 为 R74 证据契约（定义 367）；μ 为**目标测度**（部署/任务分布，预注册，不可由策略改写）；ν 为**设计测度**（行为策略诱导，运行时可估）；
- η_t 为每步重叠边际（定义 403）；H 为视界；κ_H 为轨迹级 KL 预算；ε_cov 覆盖下限；W_max 重要性权重截断；
- B_probe 审计探针预算；sep 为审计信息屏障声明（学习器可见字段 / 不可见字段）。
有效域扩展为 D_TEC = D × {μ 可预注册} × {ν 可估}。

**定义 400（证据测度、覆盖与缺口）** 对可测集 A（状态–动作–观测域）：
- 覆盖 C_ν(A) = ν(A)；目标质量 μ(A)；部署风险 R_μ(E) = μ(E)；
- 覆盖缺口 γ(A) = d_TV(μ|_A, ν|_A)（或用 KL/χ²）；
- **声称范围** ClaimScope = {A : CoverCert(A) ≥ ε_cov}；其余记为 Uncertified。
证书语义从此分两级：`Certified(A)` 与 `Uncertified(A)`，后者不允许被静默当作安全。

**定义 401（覆盖证书 CoverCert）** 用「访问指示」随机变量 1_A(X_t) 构造 C_ν(A) 的 anytime-valid 下界：固定样本用 DKW（下界 = ν̂(A) − √(log(2/β)/(2n))），长时程用 empirical-Bernstein 置信序列。**划分 A 的网格在见数据前预注册**——否则选择偏差会重新进入覆盖证书自身（自指陷阱，见风险 6）。

**定义 402（离策略赌局哨兵 OPE-SENT）** 两种模式：
- **条件模式（默认，无视界诅咒）**：契约本为 (s,a) 条件式；在每个被访问点直接对白化残差 r_t 下注，检验「条件契约在每个访问点上成立」。不需要重要性权重，覆盖只决定「哪些条件被考过」。
- **轨迹模式（长时程性质）**：对 μ 上的轨迹性质，令 w_t = dμ/dν，r̃_t = clip(w_t, W_max)·r_t，E_t = Π_s(1+λ_s r̃_s)。正确权重下 E_ν[w r] = E_μ[r]；λ 可预测 ⇒ anytime-valid。
- **有效样本量**：ESS_H = (E w)²/E w² = exp(−2 D₂(μ‖ν))，D₂ 为 Rényi-2 散度（定义 403、引理 43）。

**定义 403（每步重叠与视界预算）** 每步重叠 η_t = essinf_a ν_t(a)/μ_t(a)（必要时取反向），则轨迹权重 sup w ≤ Π_t η_t^{-1}，且 ESS_H = exp(−2 Σ_t D₂(μ_t‖ν_t))。**视界预算法**：要求 Σ_t KL(μ_t‖ν_t) ≤ κ_H 且每步 η_t ≥ η_min、H ≤ H_max ⇒ ESS_H ≥ e^{−2κ_H}。CERT-PO 以硬约束执行；违反则拒绝该轨迹，而非事后重估。

**定义 404（预序校准审计 PQ-CAL）** 记 F̂_t 为仅用 F_{t−1} 拟合的预测 CDF，PIT u_t = F̂_t(y_t)。审计 e-process E_t^pq = Π(1 + λ_t^pq·(2u_t − 1))，λ_t^pq 可预测。**时间分离纪律**：F̂_t 的拟合集严格 ⊂ F_{t−1}；审计日志（no-peeking ledger）记录每次预测的哈希、时间戳、拟合集 id；任何「用含 y_t 的数据拟合 F̂_t」判为**审计失效**（而非模型不准）。信息屏障：学习器可见三态与聚合校准误差，不可见个体 PIT 与赌注状态。

**定义 405（证书约束轨迹优化 CERT-PO）** 每个决策点求解
a* = argmax_a E[ Rew(a) − λ_risk·Risk(a) − λ_cov·1{CoverCert < ε_cov} + β_f·E[Δlog E_t | a] ]
s.t. η_t ≥ η_min、Σ_t KL_t ≤ κ_H、Σ probe ≤ B_probe、χ_R 稳态集（R74 定义 390）。
**可微代理**：梯度用 DCS（定义 408）；**定案**：最终证书由非可微的 OPE-SENT/PQ-CAL/CoverCert 计算。随机探针：以概率 p_probe 采样「非任务最优但高信息」的动作（RCT 式），探针收益不计入 Rew。

**定义 406（审计信息屏障 AIB）** 学习器与审计器之间定义字段级可见性：学习器可见 {三态, 任务奖励, 聚合校准统计}；不可见 {个体 PIT, 赌注 λ_t, e-process 值, CoverCert 内部计数}。AIB 防止策略针对审计器做对抗优化（Goodhart 的形式化）；随机探针是其补充。

**定义 407（不变性审计 INV-AUDIT）** 用设计干预（光照/材质/距离/背景/外参等环境标签 e）构造多环境数据；检验模型预测的风险/校准是否跨 e 不变：对预测残差做 e-process 或环境标签置换/条件独立性检验；若跨环境显著漂移且漂移方向与安全相关，判为**捷径证书**（shortcut certificate），禁止用其外推覆盖缺口。此为否证性检验，不假设 IRM 成立。

**定义 408（可微证书代理 DCS）** DCS 是对 (CoverCert, E_t, Risk) 的可微、低偏代理，仅用于训练/规划；**DCS 永不作为证书**。定案时以真实审计器重算；若 |DCS − 真实证书| 超过预注册带宽，该次规划作废（proxy–audit divergence guard）。

**定义 409（证书约束的 CMDP）** 把 CERT-PO 写成约束马尔可夫决策过程 (S, A, P, Rew, C)，C = (coverage, ESS, reflex budget)；用 Lagrangian/受约束策略优化求解；对偶变量 λ_cov 即「覆盖的价格」——可解释为「降低一单位覆盖缺口所需的任务代价」。

**定义 410（覆盖感知退化 CAD）** 当 CoverCert(A) < ε_cov 或 ESS_H < ESS_min 时：ClaimScope 收缩；Uncertified 区域内策略退化为保守模式（降速/停止/人类接管）；J_TRAJ 记录收缩事件与被放弃的声称。**只收缩声称，不伪造证据。**

**定义 411（J_TRAJ 组合证书）** J_TRAJ = J_SENT ⊗ CoverCert ⊗ E^pq ⊗ OPE-SENT 截面 ⊗ INV-AUDIT 报告 ⊗ 设计账本（probe 预算、η、ESS、κ_H）⊗ CAD 日志。Valid(J_TRAJ) ⇒ 在 ClaimScope 上，R74 定理 31 全部结论成立；未覆盖区被显式标注，不作为安全断言的一部分。

**定义 412（CPB 扩展 C5/C6）** C5 ← (TEC, CoverCert, OPE-SENT, CERT-PO) ← MB5 ← AB5（有覆盖证书 vs 无覆盖/最坏界；固定任务收益下检测延迟）；C6 ← (PQ-CAL, INV-AUDIT, DCS) ← MB6 ← AB6（预序审计 vs 回测；深度捷径证书 vs 不变性审计）。C1–C4 不变。

**定义 413（假设 A117–A120）** A117 目标测度可预注册；A118 每步重叠 η_t ≥ η_min（或 κ_H 有限）；A119 预测先于结果且无时间泄漏；A120 设计干预对捷径特征可分辨（INV-AUDIT 有功效）。

**定义 414（认证三难）** 固定证据预算下，{任务最优, 全域覆盖, 有限样本非空} 至多二者由构造保证，第三者为显式缺口或显式假设。形式化见定理 32 推论。

## 2. 关键算法骨架

```python
# IP-310 TEC：轨迹条件证据契约（扩展 R74 EC）
@dataclass(frozen=True)
class TrajEvidenceContract:
    ec: EvidenceContract                 # R74 契约（类型/预算/χ_R/否决/追溯）
    mu: Callable[[State, Action], float] # 目标测度（预注册，策略不可改写）
    nu: Callable[[State, Action], float] # 设计测度（行为策略诱导，可估）
    eta_min: float; H_max: int; kappa_H: float
    eps_cov: float; W_max: float
    B_probe: float; sep: AuditBarrier    # AIB 字段级可见性
    def feasible(self, stats):
        return (stats.eta >= self.eta_min and stats.kl_sum <= self.kappa_H
                and stats.probe_spent <= self.B_probe)

# IP-311 OPE-SENT：离策略赌局哨兵（条件模式 / 轨迹模式）
class OffPolicySentinel:
    def step(self, resid, ctx):
        if self.mode == 'conditional':            # 默认：无视界诅咒
            r = resid                              # 条件契约直接检验
        else:                                      # 轨迹级长时程性质
            w = min(self.tec.mu(ctx) / self.tec.nu(ctx), self.tec.W_max)
            r = w * resid
            self.ess.update(w)                     # ESS_H = (Σw)²/Σw²
        lam = self.bets.predictable_bet(self.hist) # λ_s ∈ F_{s-1}
        self.logE += math.log(max(1.0 + lam * r, 1e-12))
        self.state = self.gate(self.logE)          # GREEN/YELLOW/RED（R74）
        return self.state, math.exp(self.logE)

# IP-312 PQ-CAL：预序校准审计（对任意深度模型有效）
class PrequentialAuditor:
    def predict(self, x_t):                        # 只依赖 < t 的模型
        self.ledger.record(hash(x_t), x_t.t, self.fit_set_id)
        self.pending = self.model.cdf(x_t)         # F̂_t
        return self.pending.quantile(0.5)
    def observe(self, y_t):
        if not self.ledger.strictly_past(y_t.t):   # 泄漏 ⇒ 审计失效
            self.state = 'AUDIT_INVALID'; return self.state
        u = self.pending(y_t)                      # PIT
        self.logE += math.log(max(1.0 + self.lam * (2*u - 1), 1e-12))
        return self.gate(self.logE)

# IP-313 CERT-PO：证书约束轨迹优化（可微代理训练 + 非可微审计定案）
def cert_traj_plan(M, b_t):
    def objective(a):
        task   = task_progress(b_t, a)
        risk   = embodied_risk_est(b_t, a)
        cov    = M.cover.surrogate(b_t, a)         # DCS（仅训练用）
        fals   = M.sent.expected_log_growth(a)     # E[Δlog E_t | a]（审计器真值，仅聚合）
        return task - M.risk_params.lam * risk - M.lam_cov * cov + M.beta_f * fals
    def constraints(a):
        return (M.overlap.margin(a) >= M.tec.eta_min,
                M.overlap.kl_sum(a) <= M.tec.kappa_H,
                M.probe.spent(a) <= M.tec.B_probe)
    g = optimize_cmdp(objective, constraints, horizon=M.tec.H_max)
    if random() < M.p_probe:                       # 随机审计探针（RCT 式）
        g = M.probe.sample_informative(b_t)        # 不计任务收益
    if not M.audit.recheck(g):                     # 真实审计器定案
        return M.cad.conservative(b_t)             # CAD：收缩声称
    return g

# IP-314 INV-AUDIT：不变性 / 捷径证书检验
class InvarianceAuditor:
    def audit(self, model, env_batches):
        resid = {e: model.residuals(b) for e, b in env_batches.items()}
        tests = [e_process_two_sample(resid[e1], resid[e2])
                 for e1, e2 in pairs(resid)]
        if any(t.reject() for t in tests):
            return 'SHORTCUT_CERTIFICATE'          # 禁止外推覆盖缺口
        return 'INVARIANT'

# IP-315 J_TRAJ：组合证书（覆盖 + 预序 + 离策略 + 设计账本 + CAD）
def write_traj_cert(M):
    return J_TRAJ(J_SENT=M.cert, cover=M.cover.cert,
                  prequential=M.pq.logE, ope=M.ope.cross_section(),
                  invariance=M.inv.report, design=M.design.ledger,
                  cad=M.cad.log, claimed=M.cover.claim_scope)

# IP-316 CERTRAJ 主闭环（复用 R74 三域；覆盖与审计作为一等步骤）
def CERTRAJ_round(M, obs, audio, tac_frame, depth_img, det_set, tracks):
    # === 感知域（异步 100Hz）===
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    o_ev = M.oem.update(det_set, tracks, d_ev, rgb, M.tac_blobs)
    M.pq.predict(d_ev.feat)                        # 预序：先预测
    for ev, mod in ((d_ev, M.dpe), (o_ev, M.oem)):
        st, E = mod.sent.step(ev.resid, M.design.ctx)
        ev.sent_state = st
        if st == 'RED': ev = stub(mod)
    M.pq.observe(d_ev.obs)                         # 预序：后观测（含泄漏检查）
    t_ev = M.dmem.update(tac_frame, M.last_action)

    # === 计量域（50Hz）===
    if M.clock.due_metric():
        M.kappa = M.ncm.adapt(M.interact_window)
        M.irl.set_convention(M.kappa)
        b_t = M.bse.step_full(..., d_ev=d_ev, o_ev=o_ev, t_ev=t_ev)
        g = M.ervoi.choose(b_t, psi_hat, z_dist, t_ev.c_dist,
                           M.budget, M.fmp, M.bse)
        g = cert_traj_plan(M, b_t) if g else None   # IP-313：证书约束
        if g:
            s2, cost = sent_reflex_step(M.mods, g, M.state, M.budget)
            if s2 is not None: M.last_g, M.state = g, s2
        M.cover.update(M.design.trace)              # CoverCert（预注册划分）
        M.mreg.audit(); M.ecg_edge_sentinels.step()
        if M.cover.cert < M.tec.eps_cov: M.cad.shrink(M.cover)  # CAD（IP-410）
        M.cert = write_traj_cert(M)                 # IP-315

    # === 控制域（1kHz，只读快照；R74 第 0 层兜底）===
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.o_ev.u),
                              M.risk_params)
    k = M.c_ras_wm.certified_prefix(
        M.ach.propose_ctrl(..., pvop_bias=snap.pvop), lam)
    M.envelope.check0(k, lam)
    return k, lam, M.cert
```

## 3. 推导

**引理 42（自适应采集下的 anytime-valid 性）** 设动作 a_t 与赌注 λ_t 均为 F_{t−1} 可测（策略只依赖过去），则即使数据由自适应轨迹优化选出，(E_t) 在零假设下仍是非负上鞅，Ville 界 P(∃t: E_t ≥ 1/α) ≤ α 成立。系：**可选停止与可选续采都不破坏有效性；它们破坏的是「未检出 = 全域安全」的解释——即覆盖，而非功效的统计合法性。**

**引理 43（条件检验无视界诅咒，轨迹级有）** 条件模式下逐点检验 (s,a) 条件契约，无需重要性权重，视界 H 不进入方差。轨迹模式下 w = Π_t μ_t/ν_t，E_ν[w]=1，且 ESS_H = 1/E_ν[w²] = exp(−2 Σ_t D₂(μ_t‖ν_t))；每步 D₂ ≥ c ⇒ ESS_H ≤ e^{−2Hc}。系：**长时程断言必须付「重叠预算」，条件断言不必——这是 OPE-SENT 双模式的理由。**

**引理 44（预序校准审计对任意预测器有效）** 若 F̂_t 为 F_{t−1} 可测且模型正确，则 u_t = F̂_t(y_t) 条件均匀，E[2u_t−1 | F_{t−1}] = 0 ⇒ e-process 有效，**与模型结构/训练方式/参数量无关**。反例：若 F̂_t 用含 y_t 的数据拟合（in-sample 回测），则 F̂_t 非 F_{t−1} 可测，鞅性失效——且由于 PIT 偏移方向不固定，失效不表现为「报警」而表现为「静默通过」。系：**深度模型可以任意复杂，但预测必须严格先于结果。**

**引理 45（覆盖缺口的功效损失）** 若目标相关区域在设计中仅有有效重叠 ρ（0<ρ≤1），则 e-process 的期望对数增长率从 δ 降为 ρδ，期望检出延迟从 log(1/α)/δ 升为 log(1/α)/(ρδ)。系：**R74 的「检不出」被定量为覆盖的代价——覆盖缺口不是哲学，是延迟乘子 1/ρ。**

**引理 46（CERT-PO 的 Pareto 前沿）** 在 A117–A120 与目标/约束对 κ_H 的单调性下，最优任务收益关于 κ_H 非减、覆盖缺口关于 κ_H 非减，故存在由对偶变量 λ_cov 参数化的 Pareto 前沿；λ_cov 是「覆盖的价格」。违反 η_min 或 κ_H 的轨迹被硬拒绝，不进入前沿。

**引理 47（不变性审计与捷径证书）** 若不同设计干预 e 下 P(y | do(e)) 不同、而模型依赖与安全无关且随 e 变化的捷径特征 z，则跨环境残差分布显著分离，INV-AUDIT 以 e-process 检出；若模型真正不变，则不报警（正确性）。系：**深度模型的「在 ν 上很好」不能自动兑换成「跨环境可信」——兑换需要审计。**

**定理 32（覆盖–认证分解）** 对任意事件 E：R_μ(E) ≤ R̂_ν(E) + slack(n,α) + d_TV(μ,ν) + ε_extrap，其中 slack 由 CoverCert 的置信界给出，ε_extrap 仅在用深度模型对未访问区外推时出现。**推论（认证三难）**：固定预算下，任务最优（μ≠ν）、全域覆盖（d_TV≈0）、有限样本非空三者至多二者由构造保证；第三者是显式缺口或显式假设。深度模型不能免费降低 d_TV。

**定理 33（离策略 anytime-valid 与延迟界）** 在 A117–A120、每步重叠 η_min 与正确设计权重下：Valid(OPE-SENT) ⇒ 对目标测度 μ 的 anytime-valid 检验，且期望延迟 ≤ log(1/α)/(ρδ) + O(1)，ρ 由 ESS_H 给出。**证明重量从「声明族在分布外成立」（不可检验）转移到「重叠可估 + 预测先于结果」（可注入检验）。**

**定理 34（严格包含）** A117–A120 下，R74 SENTGAUGE = CERTRAJ 在 ν=μ（η=1）、深度模型冻结（PQ-CAL 平凡通过）、B_probe=0、ClaimScope=全域 时的实例；退化链逐指令等于 SENTGAUGE → MODGAUGE → R72 → R71 → R68。安全单调不减，证书范围只可能更诚实（更小或带缺口标注）。

## 6. 本轮最大风险

**一句话**：CERTRAJ 把 R74 的「检不出」变成了一张可计算的**覆盖欠账单**，但这张单子可能是**自指的**——CoverCert 的划分、目标测度 μ、以及重叠估计 ν 都由同一个闭环系统给出；一旦部署分布的支撑超出具身可达/可重叠范围（物理上够不到的视角、无法安全复现的材质、目标 μ 本身不可预注册），d_TV(μ,ν) 就是**不可约**的，深度模型的外推只是假设而不是证书，于是系统会拿着一份「诚实标注了缺口、每一步都合规、但缺口永远补不上」的证书，在未覆盖区继续保持**合法的无知**——它不再假装安全，却也无法证明安全。

次级风险与缓解：
1. **重要性权重重尾 / 截断偏差** → 每步重叠预算（η_min、κ_H）+ W_max 截断 + ESS 下限；超界直接拒绝轨迹而非事后修正（定义 403、E413）。
2. **视界诅咒** → 长时程断言默认走条件模式；必须走轨迹模式时强制 H ≤ H_max 且 κ_H=O(1)（引理 43、E414）。
3. **预序审计的时间泄漏** → no-peeking 账本 + 拟合集 id + 严格时间戳；泄漏判为审计失效（定义 404、E416）。
4. **信息屏障的侧信道** → 只暴露三态与聚合统计；探针随机化；定期渗透测试（定义 406、E419）。
5. **深度捷径 / 伪不变** → INV-AUDIT 否证而非 IRM 假设；捷径证书禁止外推覆盖缺口（定义 407、E420/E421）。
6. **覆盖证书的自指/选择偏差** → 划分与 μ 预注册、第三方密封（SEAL-MB5）、CoverCert 自身用独立审计流校准（定义 401、E411/E430）。
7. **MB5/MB6 过拟合** → 密封保持集 + 三方复现 + 只认预注册指标（E430）。

## 2. 形式化定义（要点版）

**定义 398（总览与八不变式）** R74 六不变式 + (vii) **覆盖完备**（证书必须声明 μ、ν 与 CoverCert，否则无效）+ (viii) **审计分离**（学习器不得接触审计器内部状态；预测严格先于结果）。

**定义 399（TEC）** TEC = (EC, μ, ν, η_min, H_max, κ_H, ε_cov, W_max, B_probe, sep)。μ 预注册且策略不可改写；ν 运行时可估；有效域 D_TEC = D × {μ 可预注册} × {ν 可估}。

**定义 400（测度、覆盖、缺口、声称范围）** C_ν(A)=ν(A)，γ(A)=d_TV(μ|_A,ν|_A)，ClaimScope={A: CoverCert(A)≥ε_cov}；证书语义分 `Certified(A)` / `Uncertified(A)` 两级。

**定义 401（CoverCert）** 访问指示 1_A(X_t) 的 anytime-valid 下界；固定样本 DKW，长时程 empirical-Bernstein；**划分与样本量见数据前预注册**，防止选择偏差进入覆盖证书自身。

**定义 402（OPE-SENT）** 条件模式：逐访问点对 r_t 下注，无需权重，H 不进方差。轨迹模式：w=dμ/dν，r̃=clip(w,W_max)r，E_t=Π(1+λ_t r̃_t)；正确权重下 E_ν[wr]=E_μ[r]。

**定义 403（重叠与视界预算）** η_t=essinf ν_t/μ_t；ESS_H=exp(−2Σ_t D₂(μ_t‖ν_t))；约束 Σ_t KL_t≤κ_H、η_t≥η_min、H≤H_max ⇒ ESS_H≥e^{−2κ_H}；违反者硬拒绝。

**定义 404（PQ-CAL）** F̂_t 仅用 F_{t−1} 拟合；u_t=F̂_t(y_t)；E_t^pq 对 PIT 均匀性下注；no-peeking 账本；泄漏 ⇒ `AUDIT_INVALID`；AIB 字段级可见性。

**定义 405（CERT-PO）** argmax E[Rew − λ_risk·Risk − λ_cov·1{CoverCert<ε_cov} + β_f·E[Δlog E_t]] s.t. η_min、κ_H、B_probe、χ_R 稳态集；DCS 训练、审计器定案；随机探针 RCT 式且不计任务收益。

**定义 406（AIB）** 学习器可见 {三态, 奖励, 聚合校准统计}；不可见 {个体 PIT, λ_t, E_t, CoverCert 内部计数}；防 Goodhart 的形式化。

**定义 407（INV-AUDIT）** 多环境 e（光照/材质/距离/背景/外参）下残差 e-process / 条件独立性检验；显著且安全相关漂移 ⇒ `SHORTCUT_CERTIFICATE`，禁止外推覆盖缺口。

**定义 408（DCS）** 对 (CoverCert, E_t, Risk) 的可微低偏代理，仅训练；定案用真实审计器重算；|DCS−真实| 超带宽则规划作废（proxy–audit divergence guard）。

**定义 409（证书约束 CMDP）** C=(coverage, ESS, reflex budget)；Lagrangian/受约束策略优化；λ_cov 为「覆盖的价格」。

**定义 410（CAD）** CoverCert(A)<ε_cov 或 ESS_H<ESS_min ⇒ 收缩 ClaimScope；Uncertified 区降速/停止/人类接管；记录收缩事件与被放弃的声称。

**定义 411（J_TRAJ）** 组合证书；Valid ⇒ 在 ClaimScope 上 R74 定理 31 全部结论成立；未覆盖区显式标注、不属安全断言。

**定义 412（CPB 扩展）** C5 ←(TEC, CoverCert, OPE-SENT, CERT-PO)←MB5←AB5←（覆盖下界、检测延迟、低报率）；C6 ←(PQ-CAL, INV-AUDIT, DCS)←MB6←AB6←（误认证率、捷径拒绝率、泄漏检出）。C1–C4 不变。

**定义 413（A117–A120）** μ 可预注册 / η_t≥η_min（或 κ_H 有限）/ 预测先于结果无泄漏 / 干预对捷径可分辨（INV-AUDIT 有功效）。

**定义 414（认证三难）** 固定证据预算下 {任务最优, 全域覆盖, 有限样本非空} 至多二者由构造保证；第三者为显式缺口或显式假设（定理 32 推论）。

## 3. 关键算法伪代码

```python
# IP-310 TEC：轨迹条件证据契约
@dataclass(frozen=True)
class TrajEvidenceContract:
    ec: EvidenceContract                     # R74：类型/预算/χ_R/否决/追溯
    mu: Callable; nu: Callable               # 目标测度（预注册）/设计测度（可估）
    eta_min: float; H_max: int; kappa_H: float
    eps_cov: float; W_max: float
    B_probe: float; sep: AuditBarrier        # AIB 字段级可见性
    def feasible(self, s):
        return (s.eta >= self.eta_min and s.kl_sum <= self.kappa_H
                and s.probe_spent <= self.B_probe)

# IP-311 OPE-SENT：条件模式 / 轨迹模式 + 门控（复用 R74 CAS 三态）
class OffPolicySentinel:
    def step(self, resid, ctx):
        if self.mode == 'conditional':        # 默认：H 不进方差
            r = resid
        else:                                  # 轨迹级长时程性质
            w = min(self.tec.mu(ctx) / self.tec.nu(ctx), self.tec.W_max)
            r = w * resid; self.ess.update(w)
        lam = self.bets.predictable_bet(self.hist)     # λ ∈ F_{s-1}
        self.logE += math.log(max(1.0 + lam * r, 1e-12))
        self.state = self.gate(self.logE)              # GREEN/YELLOW/RED
        return self.state, math.exp(self.logE)

# IP-312 PQ-CAL：预序校准审计（任意深度模型）
class PrequentialAuditor:
    def predict(self, x_t):                    # 只依赖 < t
        self.ledger.record(hash(x_t), x_t.t, self.fit_set_id)
        self.pending = self.model.cdf(x_t)     # F̂_t
        return self.pending.quantile(0.5)
    def observe(self, y_t):
        if not self.ledger.strictly_past(y_t.t):
            self.state = 'AUDIT_INVALID'; return self.state   # 泄漏
        u = self.pending(y_t)                  # PIT
        self.logE += math.log(max(1.0 + self.lam * (2*u - 1), 1e-12))
        self.state = self.gate(self.logE); return self.state

# IP-313 CERT-PO：证书约束轨迹优化（可微代理 + 非可微定案）
def cert_traj_plan(M, b_t):
    def obj(a):
        return (task_progress(b_t, a) - M.risk_params.lam * embodied_risk_est(b_t, a)
                - M.lam_cov * M.cover.surrogate(b_t, a)      # DCS：仅训练
                + M.beta_f * M.sent.expected_log_growth(a))  # 否证红利（聚合）
    def cons(a):
        return (M.overlap.margin(a) >= M.tec.eta_min,
                M.overlap.kl_sum(a) <= M.tec.kappa_H,
                M.probe.spent(a) <= M.tec.B_probe)
    g = optimize_cmdp(obj, cons, horizon=M.tec.H_max)
    if random() < M.p_probe:                    # 随机审计探针（RCT）
        g = M.probe.sample_informative(b_t)     # 不计任务收益
    if not M.audit.recheck(g):                  # 真实审计器定案
        return M.cad.conservative(b_t)          # CAD：收缩声称
    return g

# IP-314 INV-AUDIT：不变性 / 捷径证书
class InvarianceAuditor:
    def audit(self, model, env_batches):
        resid = {e: model.residuals(b) for e, b in env_batches.items()}
        for e1, e2 in pairs(resid):
            if e_process_two_sample(resid[e1], resid[e2]).reject():
                return 'SHORTCUT_CERTIFICATE'   # 禁止外推覆盖缺口
        return 'INVARIANT'

# IP-315 J_TRAJ：组合证书
def write_traj_cert(M):
    return J_TRAJ(J_SENT=M.cert, cover=M.cover.cert,
                  prequential=M.pq.logE, ope=M.ope.cross_section(),
                  invariance=M.inv.report, design=M.design.ledger,
                  cad=M.cad.log, claimed=M.cover.claim_scope)

# IP-316 CERTRAJ 主闭环（三域复用；覆盖/预序为一等步骤）
def CERTRAJ_round(M, obs, audio, tac_frame, depth_img, det_set, tracks):
    # 感知域（异步 100Hz）
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    o_ev = M.oem.update(det_set, tracks, d_ev, rgb, M.tac_blobs)
    M.pq.predict(d_ev.feat)                     # 先预测
    for ev, mod in ((d_ev, M.dpe), (o_ev, M.oem)):
        st, E = mod.sent.step(ev.resid, M.design.ctx)
        ev.sent_state = st
        if st == 'RED': ev = stub(mod)
    M.pq.observe(d_ev.obs)                      # 后观测（含泄漏检查）
    t_ev = M.dmem.update(tac_frame, M.last_action)
    # 计量域（50Hz）
    if M.clock.due_metric():
        M.kappa = M.ncm.adapt(M.interact_window)
        M.irl.set_convention(M.kappa)
        b_t = M.bse.step_full(..., d_ev=d_ev, o_ev=o_ev, t_ev=t_ev)
        g = M.ervoi.choose(b_t, psi_hat, z_dist, t_ev.c_dist,
                           M.budget, M.fmp, M.bse)
        g = cert_traj_plan(M, b_t) if g else None
        if g:
            s2, cost = sent_reflex_step(M.mods, g, M.state, M.budget)
            if s2 is not None: M.last_g, M.state = g, s2
        M.cover.update(M.design.trace)          # CoverCert（预注册划分）
        M.mreg.audit(); M.ecg_edge_sentinels.step()
        if M.cover.cert < M.tec.eps_cov: M.cad.shrink(M.cover)   # CAD
        M.cert = write_traj_cert(M)
    # 控制域（1kHz，只读快照；第 0 层兜底）
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.o_ev.u),
                              M.risk_params)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., pvop_bias=snap.pvop), lam)
    M.envelope.check0(k, lam)
    return k, lam, M.cert
```

## 4. 推导

**引理 42（自适应采集下的 anytime-valid 性）** a_t、λ_t 均 F_{t−1} 可测 ⇒ (E_t) 在零假设下仍为非负上鞅，Ville 界成立。系：**轨迹优化不破坏有效性，只破坏「未检出=全域安全」的覆盖解释。**

**引理 43（条件无视界诅咒，轨迹级有）** 条件模式逐点检验，H 不进方差；轨迹模式 ESS_H=exp(−2Σ_t D₂(μ_t‖ν_t))，每步 D₂≥c ⇒ ESS_H≤e^{−2Hc}。系：**长时程断言必须付重叠预算。**

**引理 44（预序审计对任意预测器有效）** F̂_t 为 F_{t−1} 可测且模型正确 ⇒ u_t 条件均匀 ⇒ e-process 有效，与模型结构/训练/参数量无关；若用含 y_t 的数据拟合则鞅性失效，且失效表现为静默通过。系：**深度模型可任意复杂，预测必须严格先于结果。**

**引理 45（覆盖缺口的功效损失）** 有效重叠 ρ ⇒ 期望对数增长率 δ→ρδ，延迟 log(1/α)/δ → log(1/α)/(ρδ)。系：**R74 的「检不出」= 覆盖缺口，延迟乘子 1/ρ。**

**引理 46（CERT-PO Pareto）** A117–A120 与单调性下，任务收益关于 κ_H 非减、覆盖缺口关于 κ_H 非减 ⇒ 由 λ_cov 参数化的 Pareto 前沿；λ_cov 为「覆盖的价格」。

**引理 47（不变性审计与捷径证书）** 不同干预 e 下 P(y|do(e)) 不同、模型依赖随 e 变化的捷径特征 ⇒ 跨环境残差显著分离，e-process 检出；真不变模型不报警。系：**「在 ν 上很好」不能自动兑换「跨环境可信」。**

**定理 32（覆盖–认证分解）** R_μ(E) ≤ R̂_ν(E)+slack(n,α)+d_TV(μ,ν)+ε_extrap。**推论（认证三难）**：任务最优、全域覆盖、有限样本非空至多二者由构造保证；深度模型不能免费降低 d_TV。

**定理 33（离策略 anytime-valid 与延迟界）** A117–A120 + 正确权重下，Valid(OPE-SENT) ⇒ 对 μ 的 anytime-valid 检验，期望延迟 ≤ log(1/α)/(ρδ)+O(1)。**证明重量从「声明族分布外成立」（不可检验）转移到「重叠可估 + 预测先于结果」（可注入检验）。**

**定理 34（严格包含）** R74 SENTGAUGE = CERTRAJ 在 ν=μ（η=1）、深度模型冻结、B_probe=0、ClaimScope=全域 时的实例；退化链逐指令等于 SENTGAUGE→MODGAUGE→R72→R71→R68。证书范围只可能更诚实（更小或带缺口标注），安全单调不减。

## 7. 本轮最大风险

**一句话**：CERTRAJ 把 R74 的「检不出」变成了一张可计算的**覆盖欠账单**，但这张单子可能是**自指的**——CoverCert 的划分、目标测度 μ、重叠估计 ν 都由同一个闭环给出；一旦部署分布的支撑超出具身可达/可重叠范围（物理上够不到的视角、无法安全复现的材质、μ 本身不可预注册），d_TV(μ,ν) 不可约，深度模型的外推只是假设而非证书，系统就会拿着「诚实标注了缺口、每步合规、缺口永远补不上」的证书，在未覆盖区继续保持**合法的无知**——它不再假装安全，却也无法证明安全。

次级风险与缓解：
1. **权重重尾/截断偏差** → η_min、κ_H 硬约束 + W_max 截断 + ESS 下限；超界直接拒绝轨迹（E413）。
2. **视界诅咒** → 长时程默认条件模式；轨迹模式强制 H≤H_max 且 κ_H=O(1)（E414）。
3. **预序时间泄漏** → no-peeking 账本 + 拟合集 id + 严格时间戳；泄漏判审计失效（E416）。
4. **信息屏障侧信道** → 只暴露三态与聚合统计；探针随机化；定期渗透测试（E419）。
5. **深度捷径/伪不变** → INV-AUDIT 否证而非 IRM 假设；捷径证书禁止外推缺口（E420/E421）。
6. **覆盖证书自指/选择偏差** → 划分与 μ 预注册；SEAL-MB5 第三方密封；CoverCert 用独立审计流校准（E411/E430）。
7. **MB5/MB6 过拟合** → 密封保持集 + 三方复现 + 只认预注册指标（E430）。
