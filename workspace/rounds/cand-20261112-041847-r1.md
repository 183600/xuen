# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；新灵感循环第 1 轮／累计第 60 轮；本轮灵感：「技术路线图」×「课程学习」）

> 第 59 轮把安全论证链一路下沉到电机电流环：BUQ 在线辨识执行不确定性、ERTC 硬实时契约、EEIS 阻抗安全编译、CLEP 双向闭环、PCE+++ 四预算耦合。但它同时暴露了一个更根本的「元问题」：**59 轮、151 个 IP、7 个层级，被当成一堆默认可同时成立的「静态能力」，却没有任何一份形式化的说明书回答「何时、以什么顺序、在什么成熟度下，把它们逐个上电」。** 每个新层都假设下面所有层已经成熟；而「论文里存在」不等于「部署中合格」。本轮两个灵感恰好都是**关于时间与顺序**的：**技术路线图**回答「先建什么、后建什么、依赖谁、何时算成熟」；**课程学习**回答「以什么难度顺序接触任务与环境，才能既学得动、又不越过安全边界」。本轮核心命题：**把系统能力的发展本身，当作一个受路线图约束、受课程调度、受资格前沿保护的可控过程——「能力成熟度」与「任务难度」共同张成一张二维资格地图，系统只在已资格化的格子里自主，其余格子必须先完成「资格化子目标」。**

核心矛盾：

- **H32（能力堆叠·成熟度幻觉／路线图缺失）**：151 个 IP 被并列写进体系图，却没有形式化的「依赖边」与「就绪等级」。第 59 轮的 BUQ 实际上**证伪了**前 58 轮「探针＝观测＋高斯噪声」「执行无延迟无抖动」的隐含假设；若路线图不记录这种**假设依赖边**，下游所有基于旧假设取得的资格证据都会在不知不觉中失效。**抽象泄漏会沿依赖图反向传播，而旧体系没有反向失效机制**——称之为**资格腐化（qualification rot）**：底层假设崩塌后，上层证书仍挂在墙上，但已经作废。
- **H33（课程—部署分布漂移／校准失效）**：课程学习按「由易到难」采样，校准集天然偏向简单任务；一旦上部署分布就违反可交换性，共形覆盖率与 ECE 全部失真。更隐蔽的是**自适应课程的选择偏差**：校准任务由模型自身能力挑选，等于「自己出题考自己」；而且课程会「看到好消息就提前宣布合格」，这是**可选停止（optional stopping）**，经典 p 值与共形保证在此失效。**课程若不自证其采样分布与部署分布的关系、不抵抗自适应停止，就是一台制造虚假置信的机器。**
- **H34（资格—暴露悖论／chicken-and-egg）**：要证明某能力在难任务上安全，需要难任务上的证据；要安全地获取难任务证据，又需要该能力已被证明安全。**资格与暴露互为前提。** 传统做法要么「先信后测」（鲁莽），要么「永远不测」（瘫痪）。必须引入**受护盾约束的、风险预算可转移的分阶段资格化**，把「探索风险」变成一种可核算、可摊销、可回滚的预算。

## 0. 直觉与动机

**灵感 1（技术路线图 → 能力路线图 CRG）**
直觉：技术路线图不是甘特图，而是**「能力 × 依赖 × 就绪度 × 里程碑」的有向无环图**。把每个 IP/能力 c 表示成节点，边 e=(c₁→c₂) 表示「c₂ 的成立依赖 c₁ 的结论/接口/假设」；每个节点带就绪等级 S0~S6（纸面 → 仿真 → 影子 → 有人兜底 → 受限自主 → 全自主）。关键洞见：**依赖边不仅传「能力」，还传「假设」**——当某条底层假设被新证据证伪（如第 59 轮证伪理想执行器），所有「依赖该假设」的资格证据必须**自动失效并回溯重审**。这把软件工程里的「增量构建／依赖失效／缓存失效」搬到安全论证上：**资格也是一种构建产物，也有缓存失效**。路线图还给出「先修后建」的拓扑序：绝不把未资格化的下层能力当作前提去资格化上层。

**灵感 2（课程学习 → 能力—难度资格地图 CLS）**
直觉：课程学习的本质不是「先简单后难」这句口号，而是**控制训练/评估分布 p_cur(τ) 相对部署分布 p_deploy(τ) 的偏移速度**，使系统始终处在「跳一跳够得着」的区域（ZPD）。把难度不定义为人手标签，而定义为**当前策略下的一步失败概率 d(τ)=P_fail(τ∣π_t)**；课程调度器选择「成功率落在 [p_lo,p_hi]（如 0.6~0.9）且风险预算允许」的任务。于是「课程」成为**安全探索的顺序化装置**：它把无结构的探索风险，转成一条有界、可回滚、可核算的难度爬坡曲线。

**灵感 3（两者合流 → 资格前沿 QFRB）**
直觉：路线图定义「纵轴：能力成熟度」，课程定义「横轴：任务难度」。二者张成一张**二维资格地图** F：格子 (c,d) 若已资格化，系统可在该格子自主；未资格化格子是「前沿之外的禁区」。要扩张前沿，非得在禁区采样不可——但可以用**护盾 + 分阶段暴露 + 风险预算转移**：仿真（零物理风险，但有 sim2real 漂移）→ 影子（不动执行器）→ 有人兜底（护盾可中断）→ 受限自主。每一阶段的花费可核算为 δ_qual，只有当前阶段证据强到足以支撑下一阶段，才允许推进。**资格化因此是一个「用已证明安全的小暴露，换取证明更大范围安全所需证据」的受控过程。**

**灵感 4（自适应课程的统计陷阱 → 时间有效资格 C3P/e-process）**
直觉：课程是自适应的（按模型表现挑题），这意味着**可选停止**：系统一看到「运气好」的证据就能宣布合格。经典假设检验与共形在可选停止下都不再有效。必须改用 **e-process / test martingale**：无论课程怎么自适应挑题、无论何时停，只要原假设「该格子真实失败率 ≥ δ」成立，**曾经错误宣布合格的概率 ≤ α**（Ville 不等式）。这把「课程作弊」从道德问题变成数学上不可行的操作。同时，校准必须**按难度与能力状态分层（Mondrian）**，并用有界重要性权重 p_deploy/p_cur 校正课程偏移；权重不可靠（有效样本量 ESS 过低）或遇到未覆盖层时，**拒绝给出保证并加宽/拒答**，绝不沉默地假装有覆盖率。

**灵感 5（路线图约束决策 → RCD 与「资格即动作」）**
直觉：规划器不能把「未资格化的能力」当免费前提。任何计划若依赖未资格化格子，必须**先把资格化本身作为一等动作**写进计划，并计入其成本、风险与 VOI。于是「绕行、降档、先测后做、安全停」之外，多了第五类计划元素：**「先资格化，再做」**。路线图 VOI 回答「下一笔预算该投在哪个能力的资格化上」，使研究/部署的组合管理可形式化，而不是凭直觉堆 IP。

**灵感 6（合流闭环 → 发展治理 DGL）**
直觉：CRG 给出「谁依赖谁、谁成熟到几级」；CLS 给出「下一步练什么、按什么顺序」；QFRB 给出「如何安全地把前沿推进一格」；C3P 给出「课程偏移后校准还作不作数」；RCD 把资格化接进规划；CAC 负责「防作弊、防遗忘」；J_road 负责「可审计」。合起来就是一套**发展治理层（Development Governance Layer, DGL）**：系统像一位有导师、有课程表、有考核、有资格证、有复审制度的工程师那样成长，而不是一次性把所有功能全部打开然后祈祷。

## 1. 形式化定义（增量：定义 153–161）

**定义 153（能力路线图图 CRG, Capability Roadmap Graph）**
CRG=(V_c, E_dep, E_asm, A, ρ, ε, μ)，其中：
- V_c 为能力节点集，c=(id, IPs, I_c, E_c, ρ_c, Ev_c)：IP 集合、接口契约 I_c、**运行包络** E_c（参数区间 × 任务难度区间）、就绪等级 ρ_c、资格证据库 Ev_c；
- E_dep ⊆ V_c×V_c 能力依赖边，c₁→c₂ 表示 c₂ 的资格以 c₁ 已资格为前提，并带最低等级要求 req(c₁,c₂)；
- A 为**全局假设集**（如 a₁:「探针＝观测＋高斯噪声」、a₂:「执行零延迟」、a₃:「环境准静态」），E_asm ⊆ (V_c∪A)×V_c 假设依赖边；
- ρ: V_c→{S0,…,S6}；ε 为边关键度权重；μ 为里程碑谓词。

**有效就绪**：ρ_c 可信，当且仅当 ∀(c′→c)∈E_dep，ρ_{c′}≥req(c′,c)，且 ∀(a→c)∈E_asm，a 未被证伪。**资格腐化算子** rot：
```
falsify(a) ⟹ V_aff = Reach⁻¹_{E_asm}(a)
             ∀c∈V_aff: ρ_c ← min(ρ_c, S_shadow)
                        Ev_c^{stale} ← {e∈Ev_c | e 依赖 a}
                        requalify_queue.push(c)
```
即：假设一旦被证伪，所有下游能力**自动降级、相关证据标记过期、进入重审队列**——抽象泄漏沿依赖图反向传播，且传播是完备的（定义 160 的证书要求记录完整传播闭包）。

**定义 154（就绪阶梯与资格门 TRL-Gate）**
就绪阶梯：S0 纸面规格 → S1 单元仿真 → S2 系统仿真 → S3 硬件影子（不驱动执行器）→ S4 有人兜底（护盾可中断、人可否决）→ S5 受限自主（运行包络内、有监督）→ S6 全自主。转移 S_k→S_{k+1} 仅当资格门 G_k(c) 全部成立：
```
G_k(c) = [∀ 依赖满足] ∧ [e-process 累计证据 E_c(S_k) ≥ 1/α_qual]
       ∧ [最差难度层成功率 ≥ 1−δ_RL] ∧ [回归套件 R_c 无退化]
       ∧ [安全包络内护盾不变式 I 可证] ∧ [里程碑审计通过]
```
其中 e-process 取预测型下注（betting）构造：令 X_i=1 表示第 i 次资格试验失败，原假设 H0: P_fail ≥ δ_qual。取可预测 λ_i∈[0,1/δ_qual]，
```
E_t = ∏_{i=1}^t (1 + λ_i·(δ_qual − X_i))
```
在 H0 下 E[E_t∣F_{t−1}] ≤ E_{t−1}，故 E_t 为非负上鞅且 E[E_t]≤1；由 Ville 不等式，**任意停时** P(∃t: E_t ≥ 1/α_qual) ≤ α_qual。资格宣布当且仅当 E_t ≥ 1/α_qual 且点估计失败率 < δ_qual。这保证自适应课程下的**时间有效（anytime-valid）**资格。

**定义 155（课程调度器 CLS, Curriculum Learning Scheduler）**
任务空间 T，嵌入 φ(τ)；能力模型给出校准难度 d_t(τ)=P̂_fail(τ∣π_t)（用 C3P 校准后的预测，见定义 156）。当前资格前沿 F_t（定义 157）。调度：
```
τ_{t+1} = argmax_{τ∈T} VOI_cur(τ)
  s.t.  d_t(τ) ∈ [1−p_hi, 1−p_lo]          # ZPD：成功率落在 [p_lo,p_hi]
        risk(τ; F_t) ≤ δ_explore            # 不越过风险预算
        τ ∈ Anchor ∪ Allowed(F_t)           # 锚点任务强制保留
VOI_cur(τ) = I_frontier(τ) + V_mission(τ) − C_risk(τ) − C_forget(τ)
```
p_lo/p_hi 典型 0.6/0.9；`I_frontier` 为对资格前沿的信息增益（预期减少的资格不确定性），`C_forget` 惩罚可能引起旧资格退化的分布。以概率 ε_anchor 注入**固定锚点任务**（不随自适应变化），用于识别课程作弊与分布漂移。难度预测器本身必须用定义 156 的分层共形带给出 `d_t` 的上下界；若区间跨出 ZPD 则不选该任务。

**定义 156（课程条件共形 C3P, Curriculum-Conditional Conformal Prediction）**
课程校准集 D_cal∼p_cur 与部署分布 p_deploy 通常不可交换。按（能力状态 c，难度分箱 b）分层，层 s=(c,b)。对层 s 内样本 i 取非一致性分数 s_i（如 |y−ŷ|），构造有界重要性权重
```
w_i ∝ p_deploy(τ_i)/p_cur(τ_i),  0 < w_i ≤ w_max
ESS_s = (Σ_{i∈s} w_i)² / Σ_{i∈s} w_i²
```
若 ESS_s ≥ ESS_min 且 p_cur 在该层支撑上严格正，则给定误覆盖率 α 的加权分位数预测集满足
```
P(Y∈C_α(τ) ∣ s) ≥ 1−α−δ_w
```
否则该层**拒绝给出保证**：返回全空间（或拒答）并打 `c3p_invalid=true` 标记，强制下游走保守分支。对自适应课程（采样依赖历史），再用在线共形（ACI/e-process 更新 α_t）维持长期覆盖，并记录 `optional_stopping=true`。**核心纪律：宁可拒答，不可沉默地假装有覆盖率。**

**定义 157（资格前沿与风险预算转移 QFRB, Qualification Frontier w/ Risk Budget Transfer）**
资格地图格子 q=(c,b)，b 为难度/包络扩张分箱。格子的阶段阶梯 L(q)={sim, shadow, guarded, limited}。给定格子风险预算 δ_qual(q)，按 Boole 拆分为 δ_sim+δ_shadow+δ_guarded+δ_limited ≤ δ_qual(q)。转移 L_i→L_{i+1} 仅当：
```
E_q(L_i) ≥ 1/α_stage  ∧  δ̂_stage ≤ δ_stage  ∧  护盾不变式 I 在 E_c 内成立
```
其中 δ̂_stage 由 e-process 对「阶段内一步失败率 ≥ δ_stage」的拒绝给出。前沿单调扩张 F_{t+1}⊇F_t，只能通过**已认证转移**发生；任何未经认证的扩张视为缺陷。资格期间发生的不安全事件数满足
```
E[N_unsafe(qual)] ≤ Σ_q Σ_stage δ_stage(q)·N_stage(q)
```
（在护盾保证包络内一步不安全概率 ≤ δ_shield 的前提下，sim 阶段物理风险为 0，但需计入 sim2real gap 的 δ_gap）。

**充分状态与护盾角色**：QFRB 并不假设「探索一定安全」，而是假设「在护盾不变式 I 内，任何一步的物理不安全概率可被静态上界 δ_shield 界定」。护盾（继承 RUR）负责把「越界动作」拦截为「安全停/软限幅」，因此资格化消耗的是**被护盾封顶的残余风险**，而不是系统裸风险。

**定义 158（路线图约束决策 RCD, Roadmap-Constrained Decision）**
PCE++++ 在 PCE+++ 基础上做两件事：
1. **动作合法化**：A_t^{qual} = {a ∣ caps(a)⊆Qualified(F_t) 且参数∈E_c}；未资格化能力不得作为免费前提。
2. **资格化即动作**：新增动作 Q=(c,b,stage)，带成本 cost_qual(Q) 与风险上界 δ_qual(Q)。规划目标：
```
max_{π} E[V_mission(π)]
 s.t. 每个 a∈π 合法 或 π 含前置 Q 动作
      Σ δ_qual(Q) + Σ δ_action ≤ δ_f^req
```
若所需能力未资格化，选择：插入 Q（先资格化）／绕行／降档／安全停。路线图 VOI：
```
VOI_qual(c) = E[V_mission | c 合格] − E[V_mission | c 不合格]
            − cost_qual(c) − δ_qual(c)·λ_risk
```
于是研究/部署预算分配有了可计算依据，而不是「哪个 IP 听起来更酷」。

**定义 159（课程防作弊与反遗忘 CAC, Curriculum Anti-gaming & Anti-forgetting）**
监控指标：
- 分层能力 κ_{c,b} 与**最差层**性能 min_b κ_{c,b}（不报平均值）；
- 覆盖率熵 H_cov=−Σ_b p_b log p_b（防止只练简单层）；
- 反向迁移 BWT：新课程阶段结束后旧资格层性能变化；
- 回归套件 R_c 通过率；
- Goodhart 指数 G = |Acc_self-selected − Acc_anchor|（自选评估 vs 固定锚点评估之差）。

触发规则：
```
if min_b κ_{c,b} < κ_min ∨ BWT < −η ∨ H_cov < H_min ∨ R_c 退化 ∨ G > G_max:
    ρ_c ← ρ_c − 1;  quarantine(c);  requalify_queue.push(c)
if 总体 κ 上升 但 min_b κ 不升（Simpson 悖论）:
    block_milestone(c)
```
**关键**：任何「总体变好」的声明都必须报告最差层与锚点评估，否则视为无效证据。

```
J_road = (CRG_version, {c: ρ_c}, {c: Ev_c hashes}, assumption_falsification_log,
```

**定义 161（发展治理闭环 DGL 算子）**
```
DGL(M, τ_deploy, budget):
  ① RoadmapAudit: CRG.check(); 若假设被证伪 → rot 传播 → 降级 + 重审队列
```

### IP-152 CRG（能力路线图与假设失效传播）

```python
class CapabilityRoadmap:
    def __init__(self):
        self.V = {}            # cid -> Capability(ips, iface, envelope, rho, evidence)
        self.dep = defaultdict(set)   # c1 -> {c2: req_level}
        self.asm = defaultdict(set)   # assumption -> {affected cids}
        self.assumption_status = {}   # a -> 'active' | 'falsified'
        self.requalify = deque()

    def add_capability(self, cid, ips, envelope, rho='S0'):
        self.V[cid] = Capability(cid, ips, envelope, rho, EvidenceStore())

    def add_dependency(self, c1, c2, req='S3'):
        self.dep[c1][c2] = req

    def add_assumption_dependency(self, assumption, cid):
        self.asm[assumption].add(cid)

    def effective_ready(self, cid):
        c = self.V[cid]
        for c1, req in self.dep[cid].items():
            if rank(self.V[c1].rho) < rank(req):
                return False
        for a, affected in self.asm.items():
            if cid in affected and self.assumption_status.get(a) == 'falsified':
                return False
        return True

    def falsify(self, assumption, evidence):
        """底层假设被证伪：下游资格自动腐化（反向传播）"""
        self.assumption_status[assumption] = 'falsified'
        affected = self._reverse_closure(assumption)
        for cid in affected:
            c = self.V[cid]
            c.rho = downgrade_to_shadow(c.rho)          # min(rho, S3)
            c.evidence.mark_stale(lambda e: e.depends_on(assumption))
            self.requalify.append(cid)
        return affected  # 完整传播闭包，写入 J_road

    def _reverse_closure(self, assumption):
        seen, q = set(), deque(self.asm.get(assumption, []))
        while q:
            c = q.popleft()
            if c in seen: continue
            seen.add(c)
            for c2, deps in self.dep.items():
                if c in deps:          # c2 depends on c
                    q.append(c2)
        return seen

    def activation_order(self):
        """拓扑序：只返回依赖已满足的能力"""
        return [c for c in topo_sort(self.dep)
                if self.effective_ready(c) and self.V[c].rho != 'S0']
```

### IP-153 TRLG（就绪阶梯与时间有效资格门）

```python
class TRLGate:
    def __init__(self, delta_qual, alpha_qual):
        self.delta = delta_qual
        self.alpha = alpha_qual
        self.E = defaultdict(lambda: 1.0)   # cid -> e-process 值
        self.n = defaultdict(int)
        self.fail = defaultdict(int)

    def observe(self, cid, failed, lam=None):
        # 预测型下注：lam ∈ [0, 1/delta]，可由上一轮统计估计
        if lam is None:
            lam = min(0.5 / self.delta, 1.0 / self.delta)
        x = 1.0 if failed else 0.0
        self.E[cid] *= (1.0 + lam * (self.delta - x))
        self.n[cid] += 1
        self.fail[cid] += int(failed)

    def can_advance(self, cid, roadmap, c):
        if not roadmap.effective_ready(cid):
            return False, 'dependency_or_assumption_invalid'
        if self.E[cid] < 1.0 / self.alpha:
            return False, 'insufficient_e_value'
        if self.fail[cid] / max(1, self.n[cid]) >= self.delta:
            return False, 'point_estimate_too_high'
        if c.worst_stratum_success() < 1 - c.delta_RL:
            return False, 'worst_stratum_fail'
        if not c.regression_suite_passed():
            return False, 'regression'
        return True, 'ok'

    def advance(self, cid, roadmap):
        ok, why = self.can_advance(cid, roadmap, roadmap.V[cid])
        if ok:
            roadmap.V[cid].rho = next_level(roadmap.V[cid].rho)
        return ok, why
```

### IP-154 CLS（课程调度器）

```python
class CurriculumScheduler:
    def __init__(self, p_lo=0.6, p_hi=0.9, delta_explore=1e-3,
                 eps_anchor=0.05, anchors=None):
        self.p_lo, self.p_hi = p_lo, p_hi
        self.delta_explore = delta_explore
        self.eps_anchor = eps_anchor
        self.anchors = anchors or []
        self.competence = CompetenceModel()   # 校准过的 P_fail(τ)

    def select(self, tasks, frontier, rng):
        if rng.random() < self.eps_anchor and self.anchors:
            return rng.choice(self.anchors)          # 固定锚点，防漂移
        best, best_v = None, -inf
        for tau in tasks:
            lo, hi = self.competence.fail_interval(tau)   # C3P 区间
            if not (lo >= 1 - self.p_hi and hi <= 1 - self.p_lo):
                continue                                  # 不在 ZPD
            if estimate_risk(tau, frontier) > self.delta_explore:
                continue
            v = (self.competence.info_gain(tau, frontier)
                 + mission_value(tau)
                 - risk_cost(tau)
                 - self.competence.forget_risk(tau))
            if v > best_v:
                best, best_v = tau, v
        return best

    def update(self, tau, outcome):
        self.competence.update(tau, outcome)
```

### IP-155 C3P（课程条件共形）

```python
class CurriculumConditionalConformal:
    def __init__(self, alpha, ess_min=30, w_max=20.0, strata='difficulty_capability'):
        self.alpha = alpha
        self.ess_min = ess_min
        self.w_max = w_max
        self.strata = defaultdict(list)   # stratum -> [(score, weight)]

    def add(self, tau, score):
        s = self._stratum(tau)
        w = self._importance_weight(tau)
        self.strata[s].append((score, w))

    def _importance_weight(self, tau):
        p_dep = density_deploy(tau)
        p_cur = max(density_curriculum(tau), 1e-12)
        return min(p_dep / p_cur, self.w_max)

    def quantile(self, tau):
        s = self._stratum(tau)
        data = self.strata.get(s, [])
        ess = sum(w for _, w in data)**2 / max(1e-12, sum(w*w for _, w in data))
        if not data or ess < self.ess_min:
            return FullSet(), {'valid': False, 'reason': 'low_ess_or_empty', 'ess': ess}
        q = weighted_quantile([sc for sc, _ in data], [w for _, w in data],
                              1 - self.alpha)
        return Interval(q), {'valid': True, 'ess': ess, 'stratum': s}
```

### IP-156 QFRB（资格前沿与分阶段风险预算）

```python
class QualificationFrontier:
    def __init__(self, roadmap, shield):
        self.roadmap = roadmap
        self.shield = shield
        self.frontier = defaultdict(set)     # cid -> qualified difficulty bins
        self.ledger = RiskBudgetLedger()

    def try_expand(self, cid, bin_b, delta_qual):
        """把 (cid, bin_b) 从前沿外推进一格；分阶段消耗风险预算"""
        stages = ['sim', 'shadow', 'guarded', 'limited']
        alloc = split_boole(delta_qual, stages)   # Σδ_stage ≤ δ_qual
        for stage, delta_stage in zip(stages, alloc):
            if not self.shield.invariant_holds(self.roadmap.V[cid].envelope):
                return False, 'shield_invariant_unproven'
            result = self._run_stage(cid, bin_b, stage)
            self.ledger.spend(cid, stage, delta_stage)
            if not self._certify(result, delta_stage):
                self.roadmap.requalify.append(cid)
                return False, f'stage_failed:{stage}'
        self.frontier[cid].add(bin_b)
        return True, 'expanded'

    def _certify(self, result, delta_stage):
        # e-process: H0 = 阶段一步失败率 ≥ δ_stage
        return result.e_value >= 1.0 / result.alpha_stage

    def allowed(self, cid, bin_b):
        return bin_b in self.frontier[cid]
```

### IP-157 RCD（路线图约束规划，升级 PCE+++）

```python
def roadmap_constrained_plan(M, task, frontier, budget):
    """PCE++++：资格化作为一等动作，未资格能力不得作免费前提"""
    plan, queue = [], deque(task.checkpoints)

    while queue:
        cp = queue.popleft()
        caps = required_capabilities(cp)

        for cid, bin_b in caps:
            if frontier.allowed(cid, bin_b):
                continue
            # 所需能力未资格化：插入资格化子目标
            voi = roadmap_voi(cid, cp, M, frontier)
            if voi < theta_qual_voi or not budget.can_spend_qual(cid):
                alt = reroute_or_degrade(M, cp, reason=f'unqualified:{cid}')
                if alt is None:
                    return negotiate_or_stop(M, cp, 'unqualified_no_alt')
                queue.extendleft(reversed(alt.checkpoints))
                break
            ok, why = frontier.try_expand(cid, bin_b, budget.delta_qual(cid))
            if not ok:
                return negotiate_or_stop(M, cp, f'qualification_failed:{why}')
            queue.appendleft(cp)     # 资格化完成后再回到该检查点
            break
        else:
            plan.append(execute_within_envelope(cp, M))   # 仅已资格格子

    return plan
```

### IP-158 CAC（防作弊与反遗忘）

```python
class CurriculumAuditor:
    def __init__(self, kappa_min, eta_bwt, H_min, G_max):
        self.kappa_min, self.eta_bwt = kappa_min, eta_bwt
        self.H_min, self.G_max = H_min, G_max

    def audit(self, cid, roadmap, competence, anchors, regression):
        strata = competence.stratified_success(cid)
        worst = min(strata.values())
        H = entropy(list(strata.values()))
        G = abs(competence.anchor_accuracy(cid, anchors)
                - competence.self_selected_accuracy(cid))
        bwt = competence.backward_transfer(cid)

        flags = []
        if worst < self.kappa_min:       flags.append('worst_stratum')
        if H < self.H_min:               flags.append('coverage_collapse')
        if G > self.G_max:               flags.append('goodhart')
        if bwt < -self.eta_bwt:          flags.append('forgetting')
        if not regression.passed(cid):   flags.append('regression')
        if average_up_but_worst_flat(strata): flags.append('simpson_paradox')

        if flags:
            roadmap.V[cid].rho = downgrade(roadmap.V[cid].rho)
            roadmap.requalify.append(cid)
            quarantine(cid)
        return flags
```

```python
class CapabilityRoadmap:
    RANK = {'S0':0,'S1':1,'S2':2,'S3':3,'S4':4,'S5':5,'S6':6}

    def __init__(self):
        self.V = {}
        self.dep = defaultdict(dict)             # cid -> {prereq_cid: req_level}
        self.asm = defaultdict(set)              # assumption -> {affected cids}
        self.assumption_status = defaultdict(lambda: 'active')
        self.requalify = deque()

    def add_capability(self, cid, ips, envelope, rho='S0'):
        self.V[cid] = Capability(cid, ips, envelope, rho)

    def add_dependency(self, prereq, cid, req='S3'):
        self.dep[cid][prereq] = req

    def add_assumption_dependency(self, assumption, cid):
        self.asm[assumption].add(cid)

    def effective_ready(self, cid):
        for prereq, req in self.dep[cid].items():
            if self.RANK[self.V[prereq].rho] < self.RANK[req]:
                return False
        return all(self.assumption_status[a] != 'falsified'
                   for a, aff in self.asm.items() if cid in aff)

    def falsify(self, assumption, evidence):
        """底层假设被证伪 ⇒ 下游资格自动腐化（沿 E_asm 与 E_dep 反向闭包）"""
        self.assumption_status[assumption] = 'falsified'
        affected = self._reverse_closure(assumption)
        for cid in affected:
            c = self.V[cid]
            c.rho = min(c.rho, 'S3', key=self.RANK.get)     # 强制降到影子级
            c.evidence.mark_stale(lambda e: assumption in e.depends_on)
            self.requalify.append(cid)
        return sorted(affected)                  # 完整闭包写入 J_road

    def _reverse_closure(self, assumption):
        seen, q = set(), deque(self.asm.get(assumption, ()))
        while q:
            cid = q.popleft()
            if cid in seen:
                continue
            seen.add(cid)
            for dependent, prereqs in self.dep.items():
                if cid in prereqs:
                    q.append(dependent)
        return seen

    def activation_order(self):
        """只返回依赖满足且已离地的能力，按拓扑序"""
        order = []
        for cid in topo_sort(self.dep):
            if self.effective_ready(cid) and self.V[cid].rho != 'S0':
                order.append(cid)
        return order
```

```python
class TRLGate:
    def __init__(self, delta_qual=1e-2, alpha_qual=0.05):
        self.delta = delta_qual
        self.alpha = alpha_qual
        self.E = defaultdict(lambda: 1.0)        # e-process per capability
        self.n = defaultdict(int)
        self.fail = defaultdict(int)

    def observe(self, cid, failed, lam=None):
        # 预测型下注；lam 由上一轮失败率估计，必须可预测且在 [0, 1/δ]
        lam = lam if lam is not None else min(1.0 / self.delta, 0.5 / self.delta)
        x = 1.0 if failed else 0.0
        self.E[cid] *= (1.0 + lam * (self.delta - x))
        self.n[cid] += 1
        self.fail[cid] += int(failed)

    def gate(self, cid, roadmap):
        c = roadmap.V[cid]
        checks = {
            'dependency': roadmap.effective_ready(cid),
            'e_value':    self.E[cid] >= 1.0 / self.alpha,
            'point':      self.fail[cid] / max(1, self.n[cid]) < self.delta,
            'worst':      c.worst_stratum_success() >= 1 - c.delta_RL,
            'regression': c.regression_suite_passed(),
            'shield':     c.shield_invariant_proven(),
            'milestone':  c.milestone_audit_passed(),
        }
        return all(checks.values()), [k for k, v in checks.items() if not v]

    def try_advance(self, cid, roadmap):
        ok, failed = self.gate(cid, roadmap)
        if ok and c.rho != 'S6':
            c.rho = next_level(c.rho)
            c.evidence.append(QualificationRecord(cid, c.rho, self.E[cid], self.n[cid]))
        return ok, failed
```

```python
        self.strata = defaultdict(list)          # stratum -> [(score, weight)]

        s = self._stratum(tau)
        data = self.strata.get(s, [])
        sw = sum(w for _, w in data)
        ess = sw * sw / max(1e-12, sum(w * w for _, w in data))
        if not data or ess < self.ess_min:
```

```python
class QualificationFrontier:
    def __init__(self, roadmap, shield, alpha_stage=0.05):
        self.roadmap = roadmap
        self.shield = shield
        self.alpha_stage = alpha_stage
        self.frontier = defaultdict(set)         # cid -> {qualified difficulty bin}
        self.ledger = RiskBudgetLedger()

    def try_expand(self, cid, bin_b, delta_qual):
        stages = ['sim', 'shadow', 'guarded', 'limited']
        alloc = split_boole(delta_qual, len(stages))   # Σδ_stage ≤ δ_qual
        for stage, delta_stage in zip(stages, alloc):
            if not self.shield.invariant_holds(self.roadmap.V[cid].envelope):
                return False, 'shield_invariant_unproven'
            res = self._run_stage(cid, bin_b, stage)
            self.ledger.spend(cid, stage, delta_stage)
            if res.e_value < 1.0 / self.alpha_stage or res.fail_rate >= delta_stage:
                self.roadmap.requalify.append(cid)
                return False, f'stage_failed:{stage}'
        self.frontier[cid].add(bin_b)
        return True, 'expanded'

    def allowed(self, cid, bin_b):
        return bin_b in self.frontier[cid]
```

```python
def roadmap_constrained_plan(M, task, frontier, budget):
    plan, queue = [], deque(task.checkpoints)

    while queue:
        cp = queue.popleft()
        for cid, bin_b in required_capabilities(cp):
            if frontier.allowed(cid, bin_b):
                continue
            # 未资格化：资格化是一等动作，需计费与评估
            if roadmap_voi(cid, cp, M, frontier) < THETA_QUAL_VOI \
               or not budget.can_spend_qual(cid):
                alt = reroute_or_degrade(M, cp, reason=f'unqualified:{cid}')
                if alt is None:
                    return negotiate_or_stop(M, cp, 'unqualified_no_alt')
                queue.extendleft(reversed(alt.checkpoints))
                break
            ok, why = frontier.try_expand(cid, bin_b, budget.delta_qual(cid))
            if not ok:
                return negotiate_or_stop(M, cp, f'qualification_failed:{why}')
            queue.appendleft(cp)                 # 资格化完成后回到检查点
            break
        else:
            plan.append(execute_within_envelope(cp, M))

    return plan
```

### IP-158 CAC（防作弊与反遗忘审计）

```python
class CurriculumAuditor:
    def __init__(self, kappa_min=0.8, eta_bwt=0.02, H_min=0.5, G_max=0.1):
        self.kappa_min, self.eta_bwt = kappa_min, eta_bwt
        self.H_min, self.G_max = H_min, G_max

    def audit(self, cid, roadmap, competence, anchors, regression):
        strata = competence.stratified_success(cid)
        worst = min(strata.values())
        H = entropy(list(strata.values()))
        G = abs(competence.anchor_accuracy(cid, anchors)
                - competence.self_selected_accuracy(cid))
        bwt = competence.backward_transfer(cid)

        flags = []
        if worst < self.kappa_min:        flags.append('worst_stratum')
        if H < self.H_min:                flags.append('coverage_collapse')
        if G > self.G_max:                flags.append('goodhart')
        if bwt < -self.eta_bwt:           flags.append('forgetting')
        if not regression.passed(cid):    flags.append('regression')
        if average_up_but_worst_flat(strata):
            flags.append('simpson_paradox')

        if flags:
            roadmap.V[cid].rho = downgrade(roadmap.V[cid].rho)   # 降一级
            roadmap.requalify.append(cid)
            quarantine(cid)
        return flags
```
