# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「多机协作」×「动作空间」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险非常尖锐：**VISTA 依赖「故障属于有限假设集、且视觉与几何失效相互独立」；真实故障常是未知复合类型，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，FIR 于是把未知复合故障强行归入最近假设、只膨胀错误的球——第 64 轮的单点故障升级为「归因错误的复合故障」，而且系统会因为「已经归因」而更自信地继续执行（A88）。** 本轮不再问「再多加一个模态能否解决」，而是回到更底层的问题：
>
> **如果共因故障与传感器偏置在单机单时刻上本来就不可分，那么与其换更强的分类器，不如换一组「物理上独立的测量」与「能主动制造对比的激励」：多台机器人共同持物时，闭链内部存在不移动物体的零空间动作；这些动作用来改变载荷而不改变共同物体状态。于是「各机偏置 / 共同共因 / 接触模型错」第一次可以被结构性地分离，而不是被一个 argmax 强行归类。**
>
> 本轮核心命题：**把「故障可归因」升级为「可辨识性设计」：用多机零空间内部激励把载荷变化与共同物体状态解耦，用双向固定效应分离各机偏置、共因与模型误差，用多机故障模式码做分层定位，并在联合动作空间上做安全认证前缀——共因故障要么被结构性消去，要么被显式标为 unknown，而不再被硬塞进最近假设。**

## 0. 直觉与动机

**灵感 1（多机协作 → 不是多几张票，而是多几个物理独立的「仪器」）**

直觉：多机协作最危险的误用，是让机器人交换各自的故障判断再多数表决。若三台机器人跑同一个策略、看同一个透明物体、共享同一张地图，它们的错误是**共模**的；投票只会把同一个错误放大成「共识」。如果其中一台被俘获或时钟错位，它还能把错误「投」进安全集。多机真正值钱的不是「多几个观点」，而是三件更物理的事：

1. **物理独立的测量通道**：每台机器人有自己的 F/T、编码器和相机；同一物体状态被多个独立通道同时观测。单机的 F/T 偏置只污染自己的通道，不会自动污染别人的通道。
2. **闭链内部力**：两臂/多指共同持物时，外力闭合，但**内力不唯一**。多机可以在物体几乎不动的情况下互相「对推」，制造内部载荷变化——这是一个单臂无法产生的、任务零空间内的受控激励。
3. **相对量消共模**：若各机对同一世界量都有估计 `z_i=x+c+n_i`，`c` 是共同的物体/环境状态，那么跨机差分或双向去均值可以把 `c` 消掉；反过来，若某台机器的偏置 `b_i` 是独立的，跨时间差分又能把 `b_i` 消掉。**「用谁去消谁」取决于故障的物理结构，而不是投票。**

但必须诚实：多机也带来新的失效——**闭链耦合**会让一台机器的错误通过共同物体传播成所有人的观测异常；**协同动作**若同相位，会变成共模激励而失去对比；**通信/时钟/角色**本身会坏。因此本轮的安全原则是：多机证据只能用于「分离与保守化」，不能因为「多机一致」就解锁风险。

**灵感 2（动作空间 → 可辨识性不是数据量的函数，而是「激励方向」的函数）**

直觉：系统辨识里有一条常被忽略的硬条件——**持续激励（persistent excitation）**。一个参数只有在动作空间里被「激励到」才可辨识；激励不到的方向，数据再多也只能得到先验。第 65 轮的「三阶段」（零力窗/轻触/加载）本质上是在时间轴上制造激励，但它仍然只用单机的任务动作，因此有一个结构性盲点：**轻触/加载的载荷变化与物体位姿/表面状态是共同变化的**。于是「接触模型错」和「共同物体状态错（几何/视觉共因）」在单机数据里高度共线，A88 的不可辨识并没有被真正消除。

多机闭链恰好补上这个盲点。把关节速度空间分解为
`q̇ = q̇_E ⊕ q̇_I ⊕ q̇_R`
（E：物体运动子空间；I：内力/零空间；R：自运动）。理想刚体抓持下，`q̇_I` 不产生物体运动，却改变各接触点的法向力与切向力。于是可以设计一种**「物体不动、载荷在变」的激励**：共同物体状态 `c_t` 近似常数，而载荷回归量 `x_it` 变化。用面板数据的语言说，这就是在「时间固定效应」不变的情况下制造「个体内变化」，从而把模型斜率 β 与共同状态 c 分开。**动作空间的一个零空间方向，等价于一次免费的、可控的、低任务风险的实验设计。**

**灵感 3（合流 → CHORUS：Collaborative Hypothesis-Oriented Redundant action-space Unification & Safety，多机冗余动作空间的协同故障分离与安全闭环）**

闭环如下：

- **JAA（Joint Action-space Atlas）**：在线/离线估计联合动作空间分解 `E⊕I⊕R`、抓持矩阵、内力基与泄漏界，回答「哪些动作能激励哪些故障」。
- **NEX（Null-space EXcitation）**：在安全预算内设计零空间内部激励轨迹，最大化感兴趣参数的 Fisher 信息/互信息，同时把物体位移压到 `δ_obj` 以内。
- **CIPI（Collaborative Identification via Physical Independence）**：用双向固定效应把 `r_it = b_i + c_t + x_itᵀβ + e_it` 分解为「各机偏置 b_i / 共同状态 c_t / 模型误差 β」，并用 within-between 变换分别辨识。
- **CHA（Collaborative Hierarchical Attribution）**：先把故障定位到「单机 / 团队共因 / 协同 / 模型 / 未知」的组，再在组内分类；用故障模式码（稀疏 vs 全 1）做组测试，避免把未知复合故障塞进最近标签。
- **CVC-M（Cross-agent Visual-kinematic Consistency）**：用各机自身的视觉与运动学残差检验「是否只有某一台机器的视觉/标定坏了」，而不是让多机视觉投票。
- **CSC-M（Chunk-level Safety Certificate for Multi-agent）**：在联合动作空间上验证内力、摩擦锥、无对打、滑移与停止距离，输出联合认证前缀 `k*`。
- **RSC-M / WCV-M**：把不确定球拆成 `r_geo / r_force,i / r_model / r_coord / r_common`，只膨胀被归因者；搜索域加联合安全集。
- **CSP-M / TSL-role**：在块级多机技能图上规划，技能与「角色分配 + 联合块签名」绑定，角色错配即 OOD。
- **AIC-M**：干扰集增协同故障（时钟错位、消息丢失、角色互换、Byzantine 机、共模动作、共享物体传播）。
- **J_chorus**：证书增团队归因、故障模式、激励秩/裕度、内力裕度、同步版本与 unknown 标记。

一句话：第 65 轮问「谁坏了」；CHORUS 先问「**我有没有在正确的动作方向上、用足够的物理独立性，把这个问题变成可辨识的**」，再问「谁坏了」。

**灵感 4（VISTA 组件的原位升级）**

- **FIR → CIPI + CHA**：从单机 6 假设后验升级为「面板分解 + 分层组归因」，显式包含 `H_common` 与 `H_unknown`。
- **AFA → NEX/AFA-M**：探针从「外部接触激励」扩展为「零空间内部激励」，优先选择不移动物体的方向；易损物体用差动小内力并配合视觉。
- **VCV → CVC-M**：从单机接触斑验证升级为跨机视觉-运动学一致性，用于区分「单机视觉坏」与「共同几何坏」。
- **RSC-V → RSC-M**：增加 `r_force,i`、`r_coord`、`r_common`；归因到共因时只膨胀 `r_common`，不误伤几何。
- **CSC → CSC-M**：从单机块级认证升级为联合安全集上的认证前缀，显式处理内力耦合与「对打」。
- **CSP-V → CSP-M**：技能图从单机块升级为「技能 × 角色分配」的多机块。
- **AIC-V → AIC-M**：干扰集从视觉/时序扩展到团队/通信/共模动作/共享物体传播。
- **J_vista → J_chorus**：新增团队归因、激励秩、内力裕度、同步与 unknown 标记。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（CHORUS 闭环）**：CHORUS = (VISTA, JAA, NEX, CIPI, CHA, CVC-M, CSC-M, RSC-M/WCV-M, CSP-M/TSL-role, AIC-M, J_chorus)。定位：VISTA 的「多机动作空间可辨识性 + 联合安全」升级。不变式：**动作空间设计、面板辨识、分层归因、主动激励与证书只在语义流；实时流只做同步校验、内力/联合约束监测、认证前缀执行与早停，零学习写操作。**
- **定义 234（联合动作空间分解 JAA）**：n 台机器人，关节速度 `q̇∈ℝ^{d_q}`，手雅可比 `J∈ℝ^{6n×d_q}`，抓持矩阵 `G∈ℝ^{6×6n}`，令 `A=GJ∈ℝ^{6×d_q}`。分解 `q̇=q̇_E+q̇_I+q̇_R`，其中 `q̇_E∈row(A)`（物体运动）、`q̇_I∈N(A)`（内力/零空间）、`q̇_R∈N(J)`（自运动）。理想刚体下 `A q̇_I=0` ⇒ 物体旋量 `V_o=0`；柔顺接触下用泄漏界 `‖V_o‖≤ε_leak‖q̇_I‖` 显式记账。
- **定义 235（故障的动作空间签名子空间与可激励性）**：对每个故障假设 `H`，其签名方向为 `∂r/∂θ_H`；定义在动作 `a` 下的可激励性 `X_H(a)=λ_min(Φ_H(a)ᵀΣ⁻¹Φ_H(a))`，其中 `Φ_H` 是该动作产生的回归量。`H_sensor,i` 主要由内力方向 I 激励；`H_geo` 主要由跨机外部运动 E 与视觉足迹激励；`H_model` 由载荷幅值（E 与 I）激励；`H_coord` 由差动/时序 E 激励。若 `X_H(a)=0`，该动作对 H **结构性不可观测**，不得据此放行或否定 H。
- **定义 236（NEX 零空间激励与激励秩）**：在块内设计内力轨迹 `ξ(t)∈I`，内力 `f_int(t)=B_Iξ(t)`。选择
  `ξ* = argmax_ξ I(θ_interest; r | ξ)`（等价于对多余参数取 Schur 补后的 D-最优），
  s.t. `max_t‖f_int(t)‖≤f_crush`、摩擦锥、关节限位、`max_t‖V_o(t)‖≤δ_obj`。定义激励秩 `r_ex=rank(Φ(ξ))` 与激励裕度 `κ_ex=λ_min(Φ̃ᵀΣ⁻¹Φ̃)/λ_max(·)`（`Φ̃` 为双向去均值后的回归量）。可辨识的必要条件是 `r_ex≥dim θ_interest` 且 `κ_ex≥κ_min`。
- **定义 237（安全内力激励与泄漏）**：零空间动作「不移动物体」只在刚体近似下成立。定义泄漏 `ε_leak=sup‖V_o‖/‖q̇_I‖`（离线标定 + 在线更新），安全内力上限 `f_crush=κ_frag·f_lim`（易损物体取更小）。激励幅值 `α≤min(f_crush/‖B_Iξ‖, δ_obj/(ε_leak‖q̇_I‖))`。若 `ε_leak` 过大（软接触/柔性物体），则降级为「差动小内力 + 视觉-only」或放弃物理激励。
- **定义 238（协同面板测量模型）**：在块/探针窗口内，对 `i=1..n`、`t=1..T`，
  `r_it = b_i + c_t + x_itᵀβ + e_it`，
  其中 `b_i` 为第 i 台机器的传感器/标定偏置（个体固定效应），`c_t` 为共同物体/环境状态（时间固定效应，含共因视觉/几何失效），`x_it` 为载荷、法向、滑移等激励回归量，`β` 为接触模型/刚度误差系数，`e_it` 为噪声。视觉残差可用同构面板 `y_it=b_i^v+c_t^v+z_itᵀβ_v+e_it^v`。
- **定义 239（CIPI 双向固定效应辨识）**：定义双向去均值 `r̃_it=r_it-r̄_i·-r̄_·t+r̄_··`，它同时消去 `b_i` 与 `c_t`。若 `rank(X̃)=d_x`，则 `β̂=(X̃ᵀΣ⁻¹X̃)⁻¹X̃ᵀΣ⁻¹r̃` 可辨识，协方差下界为 `(X̃ᵀΣ⁻¹X̃)⁻¹`；随后 `b̂_i` 由组间残差恢复、`ĉ_t` 由时间残差恢复（需归一化 `Σb_i=0,Σc_t=0`）。若 `x_it` 与 `c_t` 共线（例如只有任务运动、载荷随物体状态共同变化），则 `X̃` 秩亏，`β` 与 `c` 不可分——这正是第 65 轮 A88 的形式化。零空间激励在 `c_t≈const` 时改变 `x_it`，使 `X̃` 满秩。
- **定义 240（分层故障假设）**：`ℋ_M={H0, H_sensor,i (i=1..n), H_vis,i, H_geo, H_model, H_coord, H_common, H_unknown}`。组层 `G={G_agent, G_team, G_coord, G_model, G_unknown}`：`H_sensor,i/H_vis,i` 属单机组；`H_common` 属团队共因；`H_coord` 属协同；`H_model/H_geo` 属模型/几何；`H_unknown` 不是标签而是开集/新颖类，只触发保守模式，不参与 argmax 放行。
- **定义 241（故障模式码与 CHA 分层归因）**：定义模式矩阵 `A∈{0,1}^{n×|ℋ_M|}`：`H_sensor,i` 的列为 `e_i`（稀疏），`H_common` 的列为全 1（稠密），`H_model` 为随载荷加权的近全 1，`H_coord` 为结构化列（如两机反号）。相干度 `μ(A)=max_{h≠h'}|⟨a_h,a_h'⟩|/(‖a_h‖‖a_h'‖)`。若 `μ(A)<1/(2s-1)`，s-稀疏单机故障可被 OMP/基追踪恢复；当 `n>2s` 时全 1 共因列不在任何 s-稀疏列的张成内，故「共因 vs 单机」可分离。CHA 先用模式码恢复受影响的机器集合，再在支持集内用 CIPI 做类型后验；若残差拟合优度 `q>q_α` 且无可行稀疏+共因解释，则判 `H_unknown`。
- **定义 242（CVC-M 跨机视觉-运动学一致性）**：第 i 台机器用自身相机估计物体位姿 `x̂_i^vis`，用自身运动学估计 `x̂_i^kin=T_i g_i`。定义跨机残差 `e_ck,ij=‖log(x̂_i^vis⁻¹x̂_j^vis)‖²+‖log(x̂_i^kin⁻¹x̂_j^kin)‖²+‖log(x̂_i^vis⁻¹x̂_i^kin)‖²`。单机视觉/标定故障产生「一台对多台」的离群模式；共同几何/外形错误产生「所有机器同向偏移」的模式；`visual_unobservable` 仍不得否决接触。CVC-M 是残差一致性检验，不是投票。
- **定义 243（联合安全集与耦合约束）**：`S_joint(s)={a: ∀i, f_i(a)∈FC_i; ‖f_int(a)‖≤f_crush; ‖V_o(a)‖≤v_max; 力闭合裕度≥ε_fc; τ_i≤τ_max; sync_valid; 无对打裕度≥ε_nf}`，联合裕度 `ρ_joint=min` 各约束。关键：**逐机安全的交集不等于联合安全**，内力约束把各机耦合在一起；用预算分摊 `Σ_iα_i‖f_i‖≤f_crush` 得到保守内近似。
- **定义 244（CSC-M 联合认证前缀）**：给定联合块 `A_t∈ℝ^{H×Σd_i}`、后验 `post`、不可逆视界 `m`、块预算 `α_chunk`，取
  `k*=max{k≤min(H,m): ∀H∈supp_δ(post),∀s≤k, ρ_joint(A_s,H)≥0 且 P[∃s≤k:越界]≤α_chunk}`。
  执行器只执行 `k*` 步即强制重规划与再归因；多机下对 top 假设与各机预算取并集界。
- **定义 245（RSC-M 归因定向球 / WCV-M 联合压缩）**：维护 `r_geo`、`r_force,i`、`r_model`、`r_coord`、`r_common` 与 `w_vis,i`。`H_sensor,i→r_force,i↑`（不动几何）；`H_common→r_common↑`（不动单机力球）；`H_coord→r_coord↑` 且 `H↓`、`k↓`；`H_model→r_model↑` 并切柔顺。融合 `r=√(r_geo²+Σ_i r_force,i²+r_model²+r_coord²+r_common²)`。搜索域 `B(φ̂,r)∩𝒢(g)∩K(μ̂)∩ℱ(f_lim)∩𝒱∩S_joint`；交集为空则回退 `B(φ̂,r)` 并置 `attribution_conflict=True`。

## 3. 保证概要与推导要点（完整推导见产物区）

## 2. 形式化定义（完整版）

**定义 233（CHORUS 闭环）** CHORUS 是 VISTA 的「多机动作空间可辨识性 + 联合安全」升级：在 VISTA 的语义流/实时流骨架上挂载 JAA（联合动作空间分解）、NEX（零空间激励）、CIPI（协同面板辨识）与 CHA（分层归因），并原位升级 VCV→CVC-M、CSC→CSC-M、RSC-V/WCV-V→RSC-M/WCV-M、CSP-V/TSL→CSP-M/TSL-role、AIC-V→AIC-M、J_vista→J_chorus。不变式：**动作空间设计、激励优化、面板辨识、分层归因、证书构建只在语义流；实时流只做同步校验、内力/联合约束监测、认证前缀执行与早停，零学习写操作。**

**定义 234（联合动作空间分解 JAA）** 设 n 台机器人共同持物，联合关节速度 `q̇∈ℝ^{d_q}`，手雅可比 `J∈ℝ^{6n×d_q}` 把关节速度映射为各接触点旋量，抓持矩阵 `G∈ℝ^{6×6n}` 把接触力映射为物体合力，令 `A=GJ∈ℝ^{6×d_q}`。定义正交（在质量/惯量度量下）分解
`q̇=q̇_E+q̇_I+q̇_R`，
其中 `q̇_E∈row(A)` 为物体运动方向，`q̇_I∈N(A)` 为内力/零空间方向，`q̇_R∈N(J)` 为不改变接触旋量的自运动。理想刚体抓持下 `A q̇_I=0`，故物体旋量 `V_o=GJ q̇_I=0`。柔顺接触与柔性物体下用一阶泄漏模型
`‖V_o‖ ≤ ε_leak‖q̇_I‖ + O(‖q̇_I‖²)`，
`ε_leak` 由标定与在线更新给出。JAA 的输出是 `(E,I,R,A,ε_leak,力闭合裕度)`，并在每块开始时检查 `rank(A)=6`（6 维物体运动可控）与内力基的可激励性。

**定义 235（故障的动作空间签名子空间与可激励性）** 对故障假设 H 与故障幅度 `θ_H`，残差对动作的敏感度为 `∂r/∂θ_H`。给定一个动作块 `a`，收集回归量 `Φ_H(a)`，定义可激励性
`X_H(a)=λ_min(Φ_H(a)ᵀΣ⁻¹Φ_H(a))`。
物理上：`H_sensor,i`（第 i 台 F/T 偏置/漂移）主要由 I 方向的内力变化激励；`H_geo`（几何先验错）主要由跨机 E 方向的外部运动、视觉足迹与接触落点激励；`H_model`（软接触/未建模动力学）由载荷幅值（E 与 I 均可）激励；`H_coord`（时钟/角色/通信）由差动、反相、时序错位动作激励；`H_common`（共同物体/外观/环境）由跨机共享状态激励。若 `X_H(a)=0`，则该动作对 H 结构性不可观测：**不得用该动作的残差否定 H，也不得因该动作无异常而放行 H。**

**定义 236（NEX 零空间激励与激励秩）** 在块内设计内力轨迹 `ξ(t)∈I`，内力 `f_int(t)=B_Iξ(t)`，其中 `B_I` 为内力基。选择
`ξ* = argmax_ξ I(θ_interest; r | ξ)`，
等价于对多余参数（`b_i,c_t`）取 Schur 补后的 D-最优：
`max_ξ log det( X̃(ξ)ᵀΣ⁻¹X̃(ξ) )`，
约束为 `max_t‖f_int(t)‖≤f_crush`、各接触摩擦锥、关节限位、`max_t‖V_o(t)‖≤δ_obj`、以及执行器带宽。定义激励秩 `r_ex=rank(Φ(ξ))` 与激励裕度 `κ_ex=λ_min(X̃ᵀΣ⁻¹X̃)/λ_max(X̃ᵀΣ⁻¹X̃)`。可辨识的必要条件：`r_ex≥dim θ_interest`、`κ_ex≥κ_min`。`κ_ex` 是「这组动作到底能不能把参数分开」的量化指标，而不是「数据量够不够」。

**定义 237（安全内力激励与泄漏）** 零空间动作「不移动物体」只在刚体近似下成立。定义泄漏界 `ε_leak`、易损系数 `κ_frag∈(0,1]`、`f_crush=κ_frag·f_lim`。激励幅值满足
`α ≤ min( f_crush/‖B_Iξ‖, δ_obj/(ε_leak‖q̇_I‖+η), α_bw )`。
若 `ε_leak` 过大（软接触、柔性物体、抓持松动）或 `f_crush<f_min_excite`，则放弃物理内力激励，退化为：差动小内力 + 视觉-only 探针（motion parallax）/零力窗标定。**绝不以「零空间」为名绕过挤压安全。**

**定义 238（协同面板测量模型）** 在一个块或探针窗口内，对 `i=1..n`、`t=1..T`，定义白化后的力/触觉/视觉残差
`r_it = b_i + c_t + x_itᵀβ + e_it`，
其中 `b_i∈ℝ^{d_r}` 为第 i 台机器的传感器偏置与标定误差（个体固定效应），`c_t∈ℝ^{d_r}` 为共同物体/环境状态（时间固定效应，包含共同几何错、共同视觉对抗、物体外形/质量错），`x_it∈ℝ^{d_x}` 为可测激励回归量（接触法向力、内力、切向载荷、滑移速度、接近速度等），`β` 为接触模型/刚度/摩擦模型误差，`e_it` 为零均值噪声。视觉残差可用同构面板 `y_it=b_i^v+c_t^v+z_itᵀβ_v+e_it^v`。**该模型的关键不是「更多特征」，而是把故障放进正确的统计位置：偏置是截距、共因是共同时间项、模型错是斜率。**

**定义 239（CIPI 双向固定效应辨识）** 定义双向去均值
`r̃_it = r_it - r̄_i· - r̄_·t + r̄_··`，
它同时消去 `b_i` 与 `c_t`。若 `rank(X̃)=d_x`，则
`β̂ = (X̃ᵀΣ⁻¹X̃)⁻¹X̃ᵀΣ⁻¹r̃`，
其协方差下界为 `(X̃ᵀΣ⁻¹X̃)⁻¹`（Gauss-Markov）。随后
`b̂_i = r̄_i· - r̄_·· - (x̄_i· - x̄_··)ᵀβ̂`，
`ĉ_t = r̄_·t - r̄_·· - (x̄_·t - x̄_··)ᵀβ̂`，
需归一化 `Σ_i b_i=0`、`Σ_t c_t=0` 以固定可辨识的平移。若 `x_it` 与 `c_t` 共线（例如只有任务运动，载荷随物体位姿/表面状态共同变化），则 `X̃` 秩亏，β 与 c 不可分——这正是第 65 轮 A88 的数学形式。零空间激励在 `c_t≈const` 时改变 `x_it`，恢复 `X̃` 的秩；这是 CHORUS 与「再多一个模态」的根本区别。

**定义 240（分层故障假设）** 定义
`ℋ_M={H0, H_sensor,i (i=1..n), H_vis,i (i=1..n), H_geo, H_model, H_coord, H_common, H_unknown}`。
组层为 `G={G_agent, G_team, G_coord, G_model, G_unknown}`：`H_sensor,i/H_vis,i` 属 G_agent；`H_common` 属 G_team；`H_coord` 属 G_coord；`H_geo/H_model` 属 G_model；`H_unknown` 是开集/新颖类，不参与「放行」的 argmax，只触发保守降级。与第 65 轮相比，新增 `H_common` 与 `H_unknown` 两个「不强行解释」的出口，这是对 A88 的直接结构回应。

**定义 241（故障模式码与 CHA 分层归因）** 定义模式矩阵 `A∈{0,1}^{n×|ℋ_M|}`：`H_sensor,i` 的列为 `e_i`（只有第 i 台受影响）；`H_vis,i` 同理；`H_common` 的列为全 1（所有机器共享同一状态）；`H_model` 为随载荷加权的近全 1；`H_coord` 为结构化列（例如两机反号、时序错位导致的交错模式）。相干度
`μ(A)=max_{h≠h'}|⟨a_h,a_h'⟩|/(‖a_h‖‖a_h'‖)`。
若 `μ(A)<1/(2s-1)`，s-稀疏单机故障支持可被 OMP/基追踪在噪声下稳定恢复；当 `n>2s` 时全 1 共因列不在任何 s-稀疏列的张成内，故「共因 vs 单机」可分离。CHA 分两步：
1. **组层定位**：由残差跨机模式 `p_t=sign(|r_it|)` 做稀疏恢复，得到受影响机器集合 `S`；若 `S` 近全 1，优先 `G_team`；若 `S` 是结构化小集合，优先 `G_coord`/`G_agent`。
2. **类型层分类**：在支持集上做 CIPI，得到 `(b̂_i,ĉ_t,β̂)`，用它们的相对幅值与载荷依赖关系区分 `H_sensor`、`H_common`、`H_model`。
若拟合优度 `q=‖r-Xβ̂-b̂-ĉ‖²_{Σ⁻¹}>q_α` 且不存在满足相干条件的稀疏+共因解释，则判 `H_unknown`，进入保守降级，不强行归入最近标签。

**定义 242（CVC-M 跨机视觉-运动学一致性）** 第 i 台机器用自身相机估计共同物体位姿 `x̂_i^vis`，用自身运动学估计 `x̂_i^kin=T_i g_i`（`g_i` 为抓持偏移）。定义
`e_ck,ij = ‖log(x̂_i^vis⁻¹x̂_j^vis)‖²_{Σ_v} + ‖log(x̂_i^kin⁻¹x̂_j^kin)‖²_{Σ_k} + ‖log(x̂_i^vis⁻¹x̂_i^kin)‖²_{Σ_c}`。
若只有第 i 台机器的 `x̂_i^vis` 偏离而其余一致，判 `H_vis,i` 或该机标定漂移；若所有机器同向偏离运动学链，判共同几何/抓持偏移 `H_geo`；若跨机运动学一致但视觉全体不一致，判共同视觉共因。遮挡/透明/无纹理时置 `visual_unobservable`，不得据此否决接触。CVC-M 是残差一致性检验，不是「多机投票」：它输出的是模式，不是票数。

**定义 243（联合安全集与耦合约束）** 定义
`S_joint(s) = { a : ∀i, f_i(a)∈FC_i; ‖f_int(a)‖≤f_crush; ‖V_o(a)‖≤v_max; 力闭合裕度≥ε_fc; τ_i≤τ_max; sync_valid; 无对打裕度≥ε_nf }`，
联合裕度 `ρ_joint(a)=min` 上述各约束裕度。关键：**逐机安全的交集不等于联合安全**——两台机器各自都在力限内，合起来可能把物体挤坏；一台推、一台让，可能破坏力闭合或产生滑移。工程上用预算分摊得到保守内近似：
`Σ_i α_i‖f_i‖ ≤ f_crush`，`α_i` 按接触位置/脆弱度分配；并用联合控制障碍函数（CBF）做实时滤波。无对打约束写作 `‖Σ_i f_i - F_ext^pred‖≤ε_nf` 且 `f_int` 落在可行内力锥内。

**定义 244（CSC-M 联合认证前缀）** 给定联合块 `A_t=(a_t,…,a_{t+H-1})`、后验 `post`、不可逆视界 `m`、块预算 `α_chunk`，取
`k* = max{k≤min(H,m) : ∀H∈supp_δ(post), ∀s≤k, ρ_joint(A_s,H)≥0 且 P[∃s≤k: 某通道越界]≤α_chunk}`。
对多机，越界概率用并集界分摊到各机与各假设；`k*≤m` 保证即使故障在块首发生，也能在越过不可逆点前停下。执行器只执行 `k*` 步即强制重规划与再归因——「长预测、短执行」在多机联合动作空间上的直接推广。

**定义 245（RSC-M 归因定向球 / WCV-M 联合压缩）** 维护 `r_geo`、`r_force,i`、`r_model`、`r_coord`、`r_common` 与 `w_vis,i`。定向处置：
- `H_sensor,i`：`r_force,i←min(r_max,κ_infl·r_force,i)`，触发该机零力窗重标定；**不动 r_geo**。
- `H_common`：`r_common←min(r_max,κ_infl·r_common)`，**不动几何与单机力球**；必要时触发一次共同状态重观测。
- `H_coord`：`r_coord←min(r_max,κ_infl·r_coord)`，`H←max(H_min,H/2)`，`k↓`，强制同步/角色复核。
- `H_model`：`r_model←min(r_max,κ_infl·r_model)`，切柔顺、扩大接触模型不确定集。
- `H_geo`：`r_geo←min(r_max,κ_infl·r_geo)`；仅在 CVC-M/CGG 观测到落点/法向不符时执行，否则降低归因可信度。
- `H_vis,i`：`w_vis,i←max(0,κ_vis·w_vis,i)`，退回 F/T/其他机主导。
融合 `r=√(r_geo²+Σ_i r_force,i²+r_model²+r_coord²+r_common²)`。WCV-M 搜索域
`B(φ̂,r)∩𝒢(g)∩K(μ̂)∩ℱ(f_lim)∩𝒱∩S_joint`，
CVaR 尾部 `n_worst=8`（多机取每机最坏再合并）；交集为空则回退 `B(φ̂,r)` 并置 `attribution_conflict=True`。

**定义 246（CSP-M / TSL-role 多机块级规划）** 技能图节点为 `(σ,π)`：`σ` 为技能，`π` 为角色分配（leader/follower、pusher/yielder、prober/observer）。每条块边需 `Valid(J_chorus)` 且 `k*≥1`。TSL 把 `(σ,π)` 绑定到联合块签名分布 `D_{σ,π}`（离线统计），实际签名到 `D_{σ,π}` 的 Mahalanobis 距离 `>τ_chunk` 即判 OOD，该 `(σ,π)` 不入图。规划器可插入元技能：
- `null_excite`：零空间内力激励，用于分离 `H_sensor/H_model`；
- `differential_probe`：两机反相小动作，用于分离单机偏置与共因；
- `role_swap_test`：交换 pusher/yielder，用于检测 `H_coord` 与角色依赖的模型错；
- `sync_test`：时间戳/回环校验，用于 `H_coord`。
软约束代价增 `λ_fi·H(P(H|r))`（归因熵）、`λ_k·Σ hinge(k*−k_req)` 与 `λ_c·comm_cost(π)`。

**定义 247（AIC-M 团队/动作空间对抗认证）** 干扰集
`ℰ_M=ℰ_F×ℰ_vis×ℰ_time×ℰ_team`，
`ℰ_team` 含：时钟错位、消息延迟/丢失、角色互换、Byzantine 机（任意错误消息）、共模同相动作（所有机器同相位挤压，导致无差动信号）、共享物体上的故障传播（一台机器的错误通过物体改变所有机器的观测）、以及「同一对抗 patch 同时骗过所有相机」的共因。`ρ_dir` 在 `ℰ_M` 上重算（`n_cert` 128→192，其中 64 用于团队/协同/共因）；`ρ_force` 取各机最坏偏置与最坏内力；`J_chorus` 增 `team_epoch`、`sync_skew`、`byzantine_bound`。**共模/Byzantine 下不要求归因正确，只要求判 unknown/ambiguous 并安全降级。**

**定义 248（J_chorus 与 CHORUS 闭环算子）** 证书
`J_chorus=(J_vista, team_attribution, fault_pattern, excitation_rank, excitation_margin, internal_force_margin, sync_version, role_hash, common_cause_flag, unknown_flag, aic_m_ver)`。
验证规则：
`Valid(J_chorus) ⇔ Valid(J_vista)`
∧（归因定位到 `G_agent/G_team/G_coord/G_model` 之一，或已显式标 `unknown`）
∧ 声称的分离有 `r_ex≥dim θ_interest` 且 `κ_ex≥κ_min`（否则降级为「未分离」，不得声称定向膨胀）
∧ `k*≥1` ∧ 联合安全前缀通过 ∧ 同步有效或远程证据已隔离
∧ 无对打裕度 `≥0` ∧ `aic_m_ver` 为当前版本。
语义流：
`[LiDAR/多机视觉→LSF→USR/MEL→VISTA 全链→JAA→NEX 设计→阶段/窗口证据→CIPI 面板分解→CHA 分层归因→CVC-M→AFA/NEX 补充激励→RSC-M→WCV-M→CSP-M/TSL-role 块规划→CSC-M 认证前缀→AIC-M]`；
实时流：
`[同步校验→内力/联合 CBF 监测→CSC-M 早停→前缀派发→J_chorus 构建]`。

class JointActionAtlas:
    """估计 E/I/R 分解、内力基与泄漏界。语义流/离线。"""
    def __init__(self, J, G, grasp_offsets):
        self.J, self.G = J, G
        self.A = G @ J                         # 6 x d_q
        U, s, Vt = np.linalg.svd(self.A)
        self.rank_object = int((s > 1e-6).sum())      # 期望 6
        self.E_basis = Vt[:self.rank_object].T         # 物体运动方向
        self.I_basis = null_space(self.A)              # 内力/零空间
        self.R_basis = null_space(self.J)              # 自运动
        self.grasp_margin = force_closure_margin(G, grasp_offsets)

        return self.eps_leak

    def is_excitable(self, H, a):
        return action_excitability(H, a, self) > 0.0   # 定义 235

### IP-225 NEX（零空间安全激励）

```python
class NullSpaceExciter:
    def design(self, atlas, post, f_crush, delta_obj, kappa_min, templates):
        best, best_score = None, -np.inf
        for xi in templates:                       # 正弦/扫频/阶跃/反相差动
            f_int = internal_force(xi, atlas.I_basis)
            qdot_I = atlas.I_basis @ xi
            if np.max(np.abs(f_int)) > f_crush:
                continue
            if atlas.eps_leak * np.max(np.abs(qdot_I)) > delta_obj:
                continue
            X = build_regressor(xi, post)          # 含 b_i / c_t / x_it
            X_tilde = two_way_demean(X)
            score = logdet_schur(X_tilde, Sigma)   # D-最优
            if score > best_score:
                best, best_score = xi, score
        rank = matrix_rank(two_way_demean(build_regressor(best, post)))
        margin = excitation_margin(best, post)
        if rank < required_rank(post) or margin < kappa_min:
            return None, {'rank': rank, 'margin': margin,
                          'reason': 'insufficient_excitation'}
        return best, {'rank': rank, 'margin': margin, 'eps_leak': atlas.eps_leak}


def safe_excitation_amplitude(atlas, xi, f_crush, delta_obj, eta=1e-6):
    f_scale = np.max(np.abs(internal_force(xi, atlas.I_basis)))
    v_scale = atlas.eps_leak * np.max(np.abs(atlas.I_basis @ xi))
    return min(f_crush / max(f_scale, eta),
               delta_obj / max(v_scale, eta))
```

### IP-226 CIPI（双向固定效应面板辨识）

```python
class CollaborativePanelIdentification:
    def fit(self, r, X, agent_idx, time_idx, Sigma_inv):
        # r: (n*T, d_r), X: (n*T, d_x), 双向去均值
        r_t = two_way_demean(r, agent_idx, time_idx)
        X_t = two_way_demean(X, agent_idx, time_idx)
        rank = np.linalg.matrix_rank(X_t)
        if rank < X.shape[1]:
            return {'identified': False, 'rank': rank,
                    'reason': 'rank_deficient_common_confound'}
        beta = np.linalg.solve(X_t.T @ Sigma_inv @ X_t,
                               X_t.T @ Sigma_inv @ r_t)
        resid = r - X @ beta
        b = group_means(resid, agent_idx)          # 归一化 sum b = 0
        c = group_means(resid - b[agent_idx], time_idx)
        return {'identified': True, 'beta': beta, 'b': b, 'c': c,
                'rank': rank, 'cov_lb': np.linalg.inv(
                    X_t.T @ Sigma_inv @ X_t)}


def two_way_demean(z, agent_idx, time_idx):
    z = np.asarray(z, dtype=float)
    z = z - group_means(z, agent_idx)[agent_idx]
    z = z - group_means(z, time_idx)[time_idx]
    return z + z.mean(axis=0)
```

class CollaborativeHierarchicalAttribution:
    def attribute(self, r, X, agent_idx, time_idx, A_pattern, lik, q_alpha):
        # 1) 组层：残差跨机模式 → 稀疏/全1支持
        pattern = cross_agent_pattern(r, agent_idx)
        support = omp(A_pattern, pattern, s_max=min(2, r.shape[0] // 4))
        # 2) 类型层：支持集内做 CIPI
        fit = cipi.fit(r[support], X[support], agent_idx[support], time_idx[support])
        # 3) 拟合优度：解释不了就是 unknown，不强行归类
        q_stat = chi2(r - predict(X, fit, support), Sigma_inv)
        if not fit['identified'] or q_stat > q_alpha:
            return {'group': 'G_unknown', 'support': support,
                    'unknown_flag': True, 'q_stat': q_stat}
        if is_all_ones(support):
            return {'group': 'G_team', 'hyp': 'H_common',
                    'fit': fit, 'common_cause_flag': True}
        if is_single(support):
            return {'group': 'G_agent', 'hyp': f'H_sensor_{support[0]}',
                    'fit': fit}
        if is_coord_signature(support):
            return {'group': 'G_coord', 'hyp': 'H_coord', 'fit': fit}
        return {'group': 'G_model', 'hyp': 'H_model', 'fit': fit}

    def entropy(self, post):
        return -sum(p * np.log(p + 1e-12) for p in post.values())

## 4. 推导

**引理 9（零空间分解与泄漏界）** 设 `A=GJ`，`q̇_I∈N(A)`。理想刚体下物体旋量 `V_o=Aq̇=0`。若接触/物体柔顺，用一阶模型 `V_o=Aq̇_I+C f_int`，其中 `C` 为柔顺矩阵，则 `‖V_o‖≤‖C‖‖B_I‖‖q̇_I‖`，定义 `ε_leak=‖C‖‖B_I‖` 即得 `‖V_o‖≤ε_leak‖q̇_I‖`。故零空间方向的任务运动不是「绝对为零」，而是「由内力与泄漏界线性控制」；这为安全激励幅值给出可验证上界。∎

**引理 10（双向固定效应可辨识性）** 对面板模型 `r_it=b_i+c_t+x_itᵀβ+e_it`，双向去均值算子 `M_W` 满足 `M_W b=0`、`M_W c=0`。于是 `r̃=X̃β+ẽ`。若 `rank(X̃)=d_x`，则 `β` 的最小方差线性无偏估计为 `(X̃ᵀΣ⁻¹X̃)⁻¹X̃ᵀΣ⁻¹r̃`，协方差为 `(X̃ᵀΣ⁻¹X̃)⁻¹`。`b_i`、`c_t` 在 `β` 已知后由组间/时间均值恢复。反之，若存在非零 `γ` 使 `x_it=γc_t`（载荷与共同状态共线），则 `X̃=0`，`β` 与 `c_t` 不可分。**第 65 轮的「几何/力/模型」二分正是 `X̃≈0` 的特例。** ∎

**推论（A88 的混杂偏差公式）** 若忽略 `c_t` 直接回归 `r` 对 `x`，则
`β̂_naive = β + (XᵀΣ⁻¹X)⁻¹XᵀΣ⁻¹c`。
当 `Cov(x,c)≠0`（任务载荷随物体状态共同变化）时偏差非零；当零空间激励使 `x` 变化而 `c≈const` 时，`Cov(x,c)→0`，偏差消失。这给出「为什么外部任务激励无法分离共因、而内部零空间激励可以」的定量解释。∎

**引理 11（模式码组测试）** 设模式矩阵 `A` 的列已归一化，相干度 `μ(A)<1/(2s-1)`。对 s-稀疏支持 `S`，OMP 在无噪声下精确恢复 `S`；有噪声时由 RIP 得 `‖Ŝ△S‖≤C·ε`。若 `H_common` 的列为全 1 且 `n>2s`，则全 1 向量不在任何 s-稀疏列集合的张成内，故共因不会被误判为若干单机故障的叠加；反之，若 `n≤2s`，共因与 s 个单机故障在模式上不可分，CHA 必须输出 `G_unknown` 而非强行选择。∎

**定理 9（CHORUS 端到端归因-安全）** 在 A98–A106 下：
1. **结构性分离**：若 `r_ex≥dim θ_interest`、`κ_ex≥κ_min` 且面板连通，则 CIPI 可辨识 `β`、`b_i`、`c_t`（引理 10）；零空间激励使 `c_t≈const` 而 `x_it` 变化，从而 `rank(X̃)=d_x`。归因不再依赖「视觉与力独立」这一强假设，而依赖更弱的「共同状态在块内近似常数 + 激励方向足够」。
2. **共因不被强行归类**：`H_common` 有显式全 1 模式列；当 `n>2s` 且相干条件满足时与单机故障可分（引理 11）；不可分或拟合不足时输出 `H_unknown`，进入保守降级。
3. **定向膨胀**：归因到 `H_sensor,i` 只膨胀 `r_force,i`，不动 `r_geo`；归因到 `H_common` 只膨胀 `r_common`；归因到 `H_coord` 只膨胀 `r_coord` 并缩短块。正确几何不会被误降级。
4. **联合安全**：`Valid(J_chorus)` 要求 `k*≤m` 且对支持集逐假设验证 `S_joint`，故单块内越界概率 `≤α_chunk+δ_fi+α_vis+α_sync`；逐机安全被联合约束收紧，避免「各自安全、合起来挤坏」。
5. **优雅降级**：视觉失效→`w_vis,i↓`；F/T 失效→归因 `H_sensor,i`、其余机主导；同步失效→`H_coord`、远程证据隔离；激励不可行→标「未分离」、退回 VISTA 保守模式；未知故障→`H_unknown` + safe_idle/compliant retreat。
6. **实时性**：实时路径 ≤3ms（同步 0.05 + 内力/联合 CBF 0.2 + CSC-M 早停 0.05 + 派发），零学习写操作（A106）。∎

**定理 10（零空间激励的安全占优性）** 设外部任务激励与内部零空间激励获得相同的信息增益。外部激励的风险为
`R_ext = c_o·P_collision + c_f·E[f_ext]`，
内部激励的风险为
`R_int = c_f·E[f_int] + c_leak·ε_leak`，
其中 `P_collision` 随物体运动幅值增大，`c_leak` 为泄漏惩罚。由于内部激励把 `‖V_o‖≤δ_obj` 压到任务允许的极小值，`P_collision→0`；若 `ε_leak` 小且 `f_int≤f_crush`，则 `R_int<R_ext`。当 `ε_leak` 大（软接触/柔性物体）时，`c_leak·ε_leak` 可能主导，占优性失效，此时必须退回差动小内力或视觉-only。**该定理给出「何时可以安全地主动激励、何时必须停止」的判据，而不是无条件宣称零空间安全。** ∎

**命题（多机一致不是证据）** 若所有机器共享同一共因 `c_t`，则每台机器的故障判断都含 `c_t`，多数投票的期望仍是 `c_t`，不能消去共因；双向固定效应通过差分消去 `c_t`。反过来，若各机故障独立且无共因，模式码的稀疏恢复优于投票（可用全部 n 个测量而非仅票数）。故 CHORUS 的原则是：**共因用差分消，独立故障用模式码定位，两者都不靠「一致」放行。** ∎

## 7. 已知风险

**一句话**：CHORUS 的全部分离能力依赖「零空间激励真的把载荷变化与共同物体状态解耦、且各机故障相互独立」；一旦软接触/共享控制器/时钟漂移让零空间激励泄漏为物体运动或退化成共模同相动作，双向固定效应就会秩亏，系统会把「协同挤压造成的形变/损伤」误判为接触模型误差，并用更大的内力去「验证」——形成越挤越自信的正反馈，而多机一致性还会给这个错误提供「多票背书」。

**次级风险与缓解**：
1. **零空间不零（泄漏/软接触）**：柔顺接触、柔性物体、抓持松动使 `ε_leak` 大；缓解：在线标定 `ε_leak`、幅值按 `δ_obj` 反解、超界即放弃内部激励，退回差动小内力/visual-only；证书显式记录 `eps_leak` 与 `internal_force_margin`。
2. **共模同相动作**：多机同相位挤压导致无差动信号，模式码全 1 与 `H_common` 混淆；缓解：NEX 强制差动/反相模板，AIC-M 显式注入共模动作，`κ_ex` 不足时判「未分离」。
3. **面板秩亏**：块太短、`c_t` 变化过大、激励方向单一导致 `X̃` 秩亏；缓解：分块加长、加入 `differential_probe`、用 D-最优选择多方向激励、秩不足即退回保守模式并标 `unknown`。
4. **挤压伤害**：内力激励虽不移动物体，但会挤压易损物体；缓解：`f_crush=κ_frag·f_lim`、易损物体禁用物理激励、视觉力代理先估 `f_safe`、AIC-M 把挤压损伤作为硬约束。
5. **多机故障传播**：一台机器的错误通过共同物体改变所有机器观测，伪装成「共因」；缓解：CVC-M 单机离群模式 + 角色互换测试 + 逐机零力窗标定；区分「传播源」与「共同外部原因」。
6. **同步/通信失效**：时钟漂移、丢包、延迟使 `b_i/c_t` 估计失真；缓解：硬件同步、时间戳校验、`sync_test`、同步失效时 `H_coord` 并隔离远程证据。
7. **模式码相干条件不满足**：n 小或故障数 s 大时共因与稀疏故障不可分；缓解：显式判 `H_unknown`、增加机器数/激励多样性、用连续稀疏恢复而非硬阈值。
8. **激励与任务冲突**：零空间激励占用执行器带宽、增加关节磨损/发热；缓解：在语义流规划、按信息增益与任务代价折中、设置激励预算与冷却时间。
9. **证书字段爆炸**：`J_chorus` 新增团队/激励/同步字段，审计工具需升级；缓解：保持 `J_vista` 为子结构，旧验证器可降级只验 VISTA 部分，但此时不得声称 CHORUS 级安全。
10. **实时预算**：多机同步、内力 CBF、联合监测逼近 3ms；缓解：ROI 降采样、事件触发、把 JAA/NEX/CIPI/CHA/CVC-M/AIC-M 全部留在语义流，实时只做监测与早停。
