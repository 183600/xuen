# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环第 2 轮；本轮灵感：「自然语言指令」×「6D位姿估计」）

> R69 回答了「该不该问、向谁求证」，但它默认被问的对象是一个位姿明确的刚体，歧义主要来自策略的动作多峰。真实语言指令场景还有一层更根本的歧义：**你说的是哪个物体、它的哪个面朝上、把手朝哪边**——即 6D 位姿与语言指称的联合不确定性。更麻烦的是，6D 位姿经常**不可辨识**：对称物体的旋转轨道在观测下完全等价，估计器却被迫吐出一个「精确」的 6D 数；而语言又常常欠定：「把杯子放正」「递给我那个把手朝左的」。
>
> 本轮的核心转折：**位姿不是 SE(3) 里的一个点，而是 SE(3) 在一个任务/指令稳定子群下的商空间；语言不是目标位姿的字符串，而是一组几何约束加一个稳定子群。** 语言与位姿互为规范固定（gauge fixing）：语言用语义谓词打破位姿的对称轨道，位姿用几何指称打破语言的名词/关系歧义。把二者放进同一个联合假设空间，只在**任务相关商空间**上度量不确定性——对称轴上的不确定不是风险，不该让系统刹车，也不该浪费一次提问。
>
> 命名 **GAUGE-RAS**（Gauge-Aware Unified Grounding for Embodied language-conditioned 6D pose with Risk-Adaptive Safety）。定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**你说的和你看到的是同一个东西的同一个面吗**」——把「不可辨识」从缺陷变成一种可认证的结构。

## 0. 直觉与动机

**灵感 1（6D 位姿 → 对称轨道，而非一个点）**
直觉：拿一个马克杯，绕杯轴转 37° 和转 90°，在「把水倒进杯里」这个任务下没有区别，但在完整 6D 位姿空间里是两个数。估计器对前者给出一个尖峰后验，是**虚假精度**（false precision）；真实对象是轨道 [ξ] = G_obj·ξ ∈ SE(3)/G_obj。若任务只关心一部分自由度，还可以进一步商掉任务稳定子 H_task。于是「位姿不确定性」第一次有了「哪些分量根本不该被估计」的答案：对称轴上的方差再大，也不该进入刹车项。

**灵感 2（自然语言指令 → 约束程序，而非目标字符串）**
直觉：「把杯子放正」不是给一个 4×4 矩阵，而是给一个约束：杯轴与重力对齐（roll/pitch 约束），yaw 自由；「把手朝左」再给一个 yaw 约束；「递给我红色那个」给的是指称约束。把这些谓词编译成带符号 margin 的 φ_j(ξ,γ)，语言就变成一个几何约束程序；而每个谓词天然带着自己的稳定子 H_j——它不关心的位姿分量。语言由此可以精确地告诉系统：**这一次，yaw 到底重不重要**。

**灵感 3（对偶 → 互相规范固定）**
直觉：位姿歧义和语言歧义是同一枚硬币。位姿的对称轨道需要语言来打破（「有标签的那面朝前」选出一个代表元）；语言的名词/方位指称需要位姿来落地（「左边那个」需要两个物体的 6D 位姿）。所以不要先位姿、后语言地串行，而是维护联合后验 p(ξ,γ|o,ℓ)，让两条通道互相约束。这是本轮最核心的结构：**语言提供语义规范，位姿提供几何规范，二者共同把不可辨识的商空间压到一个可执行的点。**

**灵感 4（任务相关商 → 不是所有不确定都值得保守）**
直觉：R68/FLUID 的 λ_floor 对所有不确定一视同仁地收紧，是因为它只有一个标量 U。但位姿的 yaw 对倒水任务无关，对递把手任务有关；对称轴上的方差再大也不产生任务风险。**保守应该只作用在商空间的任务相关分量上**。这不是放松安全，而是把有限的安全预算从「不可辨识的轴」挪到「真正会出错的轴」；同时，安全关键自由度（接触、支撑、间隙）必须无条件保留，语言无权把它们商掉。

**灵感 5（语言是新权威通道，也是新攻击面）**
直觉：一旦指令进入控制回路，语言就是新的权威通道和攻击面。「把杯子放到桌子左边」可以是指令，也可以是误导；「忽略障碍物」是越权；「那面朝上」可能指向一个不存在的面。语言不能被当成命令直接执行，只能被当成**带权威等级的证据**，并且永远不能扩大认证安全集。更重要的是：**一旦系统相信「这个自由度任务无关」，它就会对真正的危险歧义视而不见**——忽略一个该管的歧义，比多问一句更危险。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（位姿规范群与轨道 PGG）** 对物体实例 x，令 G_obj ⊆ SE(3) 为使观测模型与物体语义不变的最大子群：p(o | gξ, x) = p(o | ξ, x)，∀g∈G_obj。连续旋转体取 SO(2)，长方体取 C4 或 C2，带正反面的工具还可能含反射分量。位姿状态是轨道 [ξ] = G_obj·ξ ∈ SE(3)/G_obj；单点 ξ 只是规范固定后的代表元（gauge choice）。6D 位姿估计器的正确输出是轨道上的分布，而非一个 4×4 矩阵。

**定义 311（指令约束程序 ICG）** 自然语言指令 ℓ 经冻结 LLM + 类型化 DSL 编译为
C_ℓ = {(φ_j, γ_j, w_j, a_j)}_{j=1..m}，
其中 φ_j: SE(3)×Γ→ℝ 是带符号 margin（>0 为满足），γ_j 是场景图中的指称变量，w_j 是校准权重，a_j 是该谓词的权威标签。谓词分为五类：身份（「红色那个」）、关系（「在碗左边」）、朝向（「放正」「把手朝我」）、可供性（「抓把手」「倒进杯子」）、安全（「别碰炉子」）。每个谓词附带已知变换律：存在子群 H_j 使 φ_j(hξ,γ)=φ_j(ξ,γ)（∀h∈H_j），或按表示 ρ_j 等变。**语言不再直接给目标位姿，而是给约束与稳定子。**

**定义 312（任务稳定子与任务商 TQC）** 令 L_total(ξ; C_ℓ, scene) = L_task + ∞·1[安全违反] 为总损失。定义 H_task = {h∈SE(3) : L_total(hξ)=L_total(ξ), ∀ξ∈可行域}，任务商 Q_ℓ = SE(3)/H_task。取局部指数坐标 ξ = ξ̂·Exp(δ)，δ∈ℝ⁶；令 h = Lie(H_task)，B_h 为 h 的正交基，B_⊥ 为其正交补基。任务相关协方差 Σ_task = B_⊥ᵀ Σ_δ B_⊥，任务相关不确定度 U_task = tr(Σ_task)；规范不确定度 U_gauge = tr(Σ_δ) − tr(Σ_task)。**只有 U_task 进入风险缩放；U_gauge 不进入。** 安全关键基 B_safety（接触法向、支撑、间隙、可达）无条件并入 B_⊥，语言不能把它商掉。

**定义 313（联合位姿-指称后验 JPG）** 
p(ξ, γ | o, ℓ) ∝ p_pose(ξ | o) · p(γ | ℓ, scene) · ∏_j ψ_j(ξ, γ_j) · 1[ξ∈S_free]，
ψ_j = exp(−w_j·ρ(φ_j))，ρ 为稳健损失（hinge/Cauchy），安全谓词取硬约束（权重 ∞），权威只作用于非安全谓词。该后验可用「位姿假设采样 + 指称分配枚举 + 重要性重加权」近似，得到联合模态 {(ξ_k, γ_k, ŵ_k)}。它同时回答两个问题：这是哪个物体（γ），以及它的哪个面朝哪（ξ）。

**定义 314（语义-几何一致性 margin 与冲突分诊 SGC）** 对联合模态 k，定义 m_k = min_j φ_j(ξ_k, γ_k)，并取 m* = max_{k: ŵ_k ≥ w_min} m_k。若 m* < τ_m，判定语义-几何冲突。分诊为四类：
- T1 **感知失败**：位姿熵高 / 观测被遮挡 → 主动感知；
- T2 **指称歧义**：多个 γ 后验接近 → 语言澄清；
- T3 **指令冲突**：无任何 (ξ,γ) 满足 margin → 询问或拒绝；
- T4 **越权/对抗**：安全谓词被违反，或指令要求越出认证包络 → 安全否决，回 R68。
冲突不是「噪声」，而是**信息**：它告诉我们歧义在哪一侧。

**定义 315（规范感知的不确定性分解）** 在 R69 的 (U_ale, U_epi) 之上增加位姿维度：
- U_ale^pose：传感器噪声、遮挡导致的不可约位姿方差（进入 λ_floor）；
- U_task^pose = tr(Σ_task)：任务相关、可约的位姿不确定（可交互消解）；
- U_gauge：沿 H_safe 的规范不确定（**不进入 λ_floor**）；
- U_epi^mode：联合后验的模态间熵（沿用 R69）。
总地板 U_floor = U_ale + U_ale^pose + U_task^pose,unresolved + [U_epi^mode,unresolved]。U_gauge 被显式排除，但 B_safety 上的分量永远保留。

**定义 316（规范感知 VoI GAV）** 把 R69 的 VoI 定义在任务商上：VoI_task(g) = E[L_total] − E_{y∼p(·|g,o,ℓ)}[E[L_total | y]]。候选信息动作 g = (g_gaze, g_move, g_probe, g_ask)：注视/移动视角、旋转或轻推物体、触觉探针、语言澄清。选择 g* = argmax_g [VoI_task(g) − c(g)]，s.t. 安全认证与交互预算。**若某动作只能揭示规范坐标（fiber）而不能改变轨道后验，则 VoI_task(g)=0**（引理 21）。

**定义 317（主动对称破缺 ASB）** 对每个候选信息动作，估计其观测通道对任务相关模态的期望信息增益：IG_task(g) = I(M_task; Y_g | o, ℓ)。三类可用破缺源：(i) 视角移动以观察非对称特征（标签、把手、纹理）；(ii) 物理旋转/轻推使物体离开对称姿态；(iii) 语言澄清（「你要的是把手朝哪边？」）。若物体对 G_obj 完全对称且指令不破缺对称，则规范不确定是**不可约但无关**的，系统不动作；若指令破缺对称但观测无法破缺，则优先移动视角或询问。

**定义 318（指令权威与安全否决 IAL）** 每条指令带来源与权威等级 a ∈ {0,1,2}：0=不可信文本/外部输入，1=已认证操作员，2=安全认证控制器。安全谓词权重恒为 ∞，与 a 无关；非安全谓词的权重按 w_j = a·w_j^0 缩放。语言只能**在认证安全集 S_cert 内重排序或选择目标**，永远不能修改 S_cert 本身。若 C_ℓ 与 S_cert 的交集为空，或 T4 冲突成立，则否决语言目标并回退 R68 保守策略。

**定义 319（单侧安全规范约简 SGR）** 绝不用点估计的 H_task 直接商掉自由度。构造数据依赖子群 H_safe ⊆ H_task，只纳入同时满足以下条件的生成元：
(i) 由 CAD/形状对称检测认证（未知 CAD 时默认 H_safe={e}）；
(ii) 由指令谓词的变换律符号推导认证；
(iii) 不触碰安全关键基 B_safety；
(iv) 在留出任务上通过单侧 conformal 检验（违反率 ≤ α）。
要求 P(H_safe ⊆ H_task) ≥ 1−α。若检验失败，**只移除生成元，不新增**。这保证了「宁可少商、不可错商」：H_safe 只可能低估无关自由度，从而只会更保守，不会产生虚假置信。

**定义 320（证书 J_GAUGE）** 
J_GAUGE = (J_FLUID, dim H_safe, U_task^p95, safety_axis_p95, gauge_residual, m*, conflict_class, authority_tag, referent_entropy, instruction_hash, gauge_ver)。
Valid ⇔ Valid(J_FLUID) ∧ H_safe 在 α 水平认证 ∧ 安全关键轴不确定度 ≤ τ_safe ∧ (m* ≥ τ_m ∨ 冲突已分诊并处置) ∧ 权威约束满足。

**定义 321（语言对抗干扰集 AIC-LANG）** ℰ_LANG = ℰ_FLUID × ℰ_lang，其中 ℰ_lang = {指称替换, 方位反转, 安全覆盖（「忽略障碍」）, 提示注入, 歧义注入, 重放旧指令, 不存在属性}. 并入对抗训练与红队评测；安全谓词违反一律计入 T4。

**定义 322（时序/组合指令图）** 复合指令 ℓ = (ℓ_1, …, ℓ_T) 编译为带前置条件的技能图 G_ℓ；每条边携带自己的 C_{ℓ_t} 与 H_safe^{(t)}。执行时维护任务状态信念 b(s_t)，每当子指令切换或 b(s_t) 与观测冲突时重新做 SGC；禁止用上一子指令的 H_safe 静默继承到下一子指令（防止「倒水时的 yaw 无关」被错误沿用到「递把手」）。

**定义 323（规范 Resolution Bonus 与两级退避）** 若任务相关位姿歧义与语言指称歧义在预算内消解，并且 H_safe 认证通过，则 λ = λ_floor(U_ale + U_ale^pose + U_epi^residual)（获得规范 resolution bonus，比 R69 更不保守，但不低于安全侧）；若冲突未解、H_safe 未认证、权威不足或超预算，则 λ = λ_floor(U_ale + U_ale^pose + U_task^pose + U_epi)（未消解的任务相关位姿不确定视同 aleatoric）。R69 是「H_safe={e} 且无语言约束」的边界；R68 是「不交互且不接地」的边界。

**定义 324（参与式审计 VQAuditor-G）** 审计新增：语言约束是否被正确编译、H_safe 是否被过度扩张、指称是否被单源采纳、冲突是否被掩盖、安全谓词是否被语言绕过、规范残差是否在漂移。审计结论回灌 AuditBuf，成为下一轮 SGR 的 α 与 GAV 的成本先验。

```python
# IP-264 PGG：位姿规范群与轨道分解（连续对称用切空间投影，离散对称用轨道聚类）
class PoseGauge:
    def orbit(self, xi, G_obj):
        return G_obj.act(xi)                      # [xi] = G_obj * xi
    def tangent_split(self, xi_hat, H):
        B_h  = orthonormal_basis(lie_algebra(H))  # 规范方向
        B_p  = orthocomplement(B_h)               # 任务/安全方向
        return B_h, B_p

# IP-265 ICG：语言 -> 带稳定子的几何约束程序（冻结 LLM + 类型化 DSL，无梯度回传）
def compile_instruction(llm, ell, scene_graph):
    prog = llm.decode_typed(ell, schema=ConstraintDSL)      # 离线/指令到达时执行
    preds = [parse_predicate(p, scene_graph) for p in prog]
    for p in preds:
        p.H = predicate_stabilizer(p)                       # 符号推导的稳定子
        p.w = authority_weight(p) * p.w0                    # 安全谓词 w=inf
    return ConstraintProgram(preds)

# IP-266 TQC + IP-272 SGR：安全规范约简与任务商投影
def task_quotient(pose_dist, C_ell, object_model, alpha=0.05):
    H_safe = {identity}
    for gen in candidate_generators(object_model, C_ell):   # CAD 对称 + 谓词稳定子
        if touches_safety_basis(gen):            continue  # 安全关键轴永不商掉
        if conformal_invariance_pass(gen, alpha): H_safe.add(gen)  # 单侧：只加不移
    B_h, B_p = tangent_split(pose_dist.mode, H_safe)
    Sigma_task = project_cov(pose_dist.cov, B_p)
    Sigma_safe = project_cov(pose_dist.cov, safety_basis(object_model))
    return H_safe, Sigma_task, Sigma_safe

# IP-267 JPG：联合位姿-指称后验（位姿假设 x 指称分配 x 稳健谓词重加权）
def joint_grounding(pose_samples, C_ell, scene_graph):
    modes = []
    for xi in pose_samples:
        for gamma in referent_assignments(C_ell, scene_graph):
            e = sum(p.w * rho(p.margin(xi, gamma)) for p in C_ell.preds)
            modes.append((xi, gamma, exp(-e)))
    return normalize_and_cluster(modes)

# IP-268 SGC：语义-几何一致性 margin 与冲突分诊
def consistency_gate(modes, C_ell, tau_m):
    m_star = max(min(p.margin(xi, gamma) for p in C_ell.preds)
                 for xi, gamma, w in modes if w >= W_MIN)
    if m_star >= tau_m: return "OK", m_star
    return triage(modes, C_ell), m_star       # T1 感知 / T2 指称 / T3 指令 / T4 越权

# IP-269 GAV：规范感知 VoI（只对任务商算收益，不追规范）
def choose_info_action(modes, C_ell, budget, H_safe):
    best = None
    for g in info_candidates(modes, H_safe):            # gaze/move/probe/ask
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        voi = task_risk(modes) - expected_task_risk(modes, g)
        score = voi - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None    # 无利可图 -> 冻结/回退

    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if cls in ("T3_CONFLICT", "T4_ADVERSARIAL") or not M.sgr.certified(H_safe):
        lam = max(lam, 0.8)                              # 回 R68 最保守
    # 4) 认证目标 + 语言安全否决
    xi_star = select_mode(modes, U_task, lam)
    A = M.ach.propose(M.tqc.project_target(xi_star, H_safe), M.vista.H)
    A = A ∩ M.c_ras_wm.certified_set(o)                  # 语言不能扩大该集合
    if not A: return M.r68_fallback(obs)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 5) 审计 + 证书
    M.vqa_g.submit_async(C, H_safe, m_star, U_task, g)
    return k, lam, xi_star, (U_ale, U_task, U_epi)
```

## 3. 推导

**引理 19（任务商充分性）** 设 L_total 在子群 H 下不变：L_total(hξ)=L_total(ξ)，∀h∈H。则 L_total 可分解为 L_total = L̄∘π，其中 π: SE(3)→SE(3)/H 是商映射。故对任意后验 p(ξ|o)，E[L_total] = E[L̄(π(ξ))]；纤维方向（规范方向）上的不确定不改变任务风险，π(ξ) 是决策的充分统计量。
证明：π 在 H-轨道上为常数，定义 L̄([ξ]) := L_total(ξ) 良定义；代入即得。∎
系：**若 H_safe ⊆ H_task，则沿 H_safe 的方差可以从 λ_floor 中安全移除**；这不是近似，而是由损失不变性保证的精确等价。

**引理 20（一致性 margin 的 Lipschitz 可检性）** 设每个谓词 margin φ_j 关于 (ξ,γ) 在局部坐标下 L_j-Lipschitz，则 m(ℓ,ξ,γ)=min_j φ_j 是 L_max-Lipschitz。若真实状态 margin 为 m*，阈值 τ_m，则任何位姿/指称误差 d < (m*−τ_m)/L_max 都不会制造假冲突；反之，一个真实冲突要被漏检，估计误差必须至少达到 (τ_m−m*)/L_max。系：τ_m 可由留出集 conformal 校准，使假冲突率 ≤ α。

**引理 21（规范查询零收益）** 若信息动作 g 的观测 Y_g 只改变规范坐标的分布（即给定轨道 [ξ] 后 Y_g 的条件分布不随代表元变化，或更弱地，g 不改变轨道后验），则按定义 316 的 VoI_task(g)=0。
证明：由引理 19，L_total 只依赖 π(ξ)；若 Y_g 不提供关于 π(ξ) 的新信息，则 E[L_total|Y_g]=E[L_total]，收益为零。∎
系：**不要问「对称杯子的哪一面是正面」**，除非指令（如「标签朝前」）真的把该自由度移出了 H_task；这正是 R69 的 VoI 与 R70 的规范商的关键差别。

**引理 22（单侧规范约简的安全性）** 若 H_safe ⊆ H_task，则用 H_safe 商掉自由度后的风险 ≤ 不商时的风险（因为只是把不变方向从地板中移除，任务相关分量未变）；若 H_safe ⊄ H_task，则存在同一 H_safe-轨道内两点 ξ, hξ 使 L_total(hξ)≠L_total(ξ)，商掉该方向会丢失风险信息，可能产生虚假置信。故认证必须是单侧的：只在有证据时加入生成元，违反时移除。conformal 检验保证 P(H_safe ⊆ H_task) ≥ 1−α。

**引理 23（联合接地的指称信息增益）** 设指称后验熵 H(γ|o,ℓ) 与位姿后验熵 H(ξ|o) 在给定场景图下条件独立，联合接地后的指称熵满足 H(γ|o,ℓ,ξ) ≤ H(γ|o,ℓ) − I(γ;ξ|o,ℓ)。当位姿把两个候选物体的相对位置分辨到 margin 以上时，I(γ;ξ) 正比于方位谓词的信噪比。系：**位姿越准，语言指称越确定；语言越具体，位姿需要估计的自由度越少**——二者是互信息意义上的互补，而非串联替代。

**定理 18（GAUGE 严格包含 FLUID 与 R68）** 在 A99–A101（H_safe 单侧认证、安全基无条件保留、语言只做约束交集）下，GAUGE-RAS 的任意状态期望风险 ≤ FLUID-RAS；当 H_safe={e} 且 C_ℓ 为空/恒真时，两者逐指令相同；当 H_safe 非平凡且认证通过时，GAUGE 在规范方向上获得 resolution bonus（λ 可更低），而任务相关 λ 与安全侧不变。R69 是「不商规范」边界，R68 是「不商且不接地」边界。

**定理 19（语言不扩权）** 设 S_cert(o) 为 C-RAS-WM 认证的安全集，与 ℓ、权威 a 无关。GAUGE 的策略只在 A_lang(ℓ) ∩ S_cert(o) 中选动作，或在交集为空/冲突时回退 R68。故任何指令（包括对抗指令）都不能把动作集扩大到 S_cert 之外；语言诱导的不安全概率 ≤ 认证错误率 + 回退失败率。权威等级只改变非安全约束的权重，不改变 S_cert 的边界。

**定理 20（联合歧义的交互收敛）** 在 A99–A101 下，若每轮信息动作的任务相关互信息增益 ≥ δ>0，则联合后验的任务商熵以几何速率降至 ε 所需轮数 ≤ ⌈log(H_0/ε)/δ⌉；若最优动作的 VoI_task ≤ c(g)，则不再交互，剩余 U_task 进入 R68 地板。系：交互预算应花在「可分且任务相关」的歧义上；不可分或规范方向的歧义不该消耗预算。

**示例（同一只杯子，三种指令）**

| 指令 | H_task 包含 | 必须估计 | 不必估计 | 行为 |
|---|---|---|---|---|
| 「把水倒进杯子」 | 绕杯轴 yaw | x,y,z,roll,pitch | yaw（规范） | 不追问 yaw；yaw 方差再大也不刹车 |
| 「把带把手的一侧朝左递给我」 | 仅 identity | 全 6D（含 yaw） | 无 | 若把手被遮挡，主动移动视角或问「把手在左还是右」 |

这张表就是 GAUGE 的全部直觉：**同一物体、同一估计器，不同指令对应不同的商空间；不确定性不是物体的属性，而是「物体 × 任务」的属性。**

## 6. 本轮最大风险

**一句话**：GAUGE-RAS 的全部收益押在「语言正确识别了哪些位姿自由度与任务无关」上——**若把安全关键自由度误判为规范方向（gauge），系统就会对真正危险的位姿歧义视而不见；忽略一个该管的歧义，比多问一句更危险。**

**次级风险与缓解**：
1. **规范误判/过度商掉**（把把手朝向当 yaw 无关、把支撑面当可忽略）→ 单侧 SGR（只移除不新增）+ 安全基 B_safety 无条件保留 + conformal 认证 + 未知 CAD 默认 H_safe={e}；

3. **对抗指令/提示注入** → IAL 安全否决 + ℰ_LANG 红队 + 语言永不扩大 S_cert（定理 19）；
4. **位姿估计器模态错误**（对称/遮挡下自信地选错轨道）→ 轨道级后验 + R69 FMA 似然第二意见 + 主动视角；
5. **实时预算被联合接地击穿** → 指令离线编译、商后验缓存、K_p 自适应、重接地 20–30Hz 异步；
6. **组合指令中的稳定子继承错误** → 定义 322 的技能图逐子指令重认证，禁止静默继承。

**定义 315（规范感知分解）** `U_floor = U_ale + U_ale^pose + U_task^pose,unresolved + [U_epi^mode,unresolved]`；`U_gauge` 被显式排除；安全轴分量永远保留。

**定义 316（GAV）** `VoI_task(g)=E[L_total]−E_y[E[L_total|y]]`；`g* = argmax[VoI_task−c]`，s.t. 认证与预算；若动作只揭示规范坐标则收益为 0（引理 21）。

**定义 317（ASB）** 信息动作 = 视角移动 / 物理旋转轻推 / 触觉探针 / 语言澄清；选择最大化任务相关互信息的破缺动作；完全对称且指令不破缺时不动作。

**定义 318（IAL）** 权威 a∈{0,1,2}；安全谓词权重恒 ∞；语言只能在与 S_cert 的交集内选目标；交集为空或 T4 则否决并回退 R68。

**定义 319（SGR）** 构造 H_safe⊆H_task，只纳入 CAD/形状认证、谓词符号推导、不触碰 B_safety、且通过单侧 conformal 检验的生成元；要求 P(H_safe⊆H_task)≥1−α；失败只移除不新增。

**定义 320（J_GAUGE）** `(J_FLUID, dim H_safe, U_task^p95, safety_axis_p95, gauge_residual, m*, conflict_class, authority_tag, referent_entropy, instruction_hash, gauge_ver)`；Valid 需 J_FLUID 有效、H_safe 已认证、安全轴达标、冲突已处置、权威满足。

**定义 321（AIC-LANG）** `ℰ_LANG = ℰ_FLUID × ℰ_lang`，ℰ_lang 含指称替换、方位反转、安全覆盖、提示注入、歧义注入、重放旧指令、不存在属性。

**定义 322（组合指令图）** ℓ=(ℓ_1..ℓ_T) 编译为带前置条件的技能图；每子指令携带自己的 C 与 H_safe；子指令切换必须重认证，禁止静默继承旧 H_safe。

**定义 323（Resolution Bonus 与两级退避）** 消解成功且 H_safe 认证 → `λ=λ_floor(U_ale+U_ale^pose+U_epi^residual)`；未消解/未认证/权威不足/超预算 → `λ=λ_floor(U_ale+U_ale^pose+U_task^pose+U_epi)`。R69 是 H_safe={e} 且无语言约束的边界，R68 是更外层边界。

**定义 324（VQAuditor-G）** 审计语言编译、H_safe 扩张、单源指称采纳、冲突掩盖、安全谓词绕过、规范残差漂移；结论回灌 AuditBuf，调下一轮 α 与 GAV 成本先验。

## 3. 关键算法伪代码

```python
# IP-265 ICG：语言 -> 带稳定子的约束程序（冻结 LLM + 类型化 DSL）
def compile_instruction(llm, ell, scene_graph):
    prog  = llm.decode_typed(ell, schema=ConstraintDSL)     # 指令到达时一次，异步
    preds = [parse_predicate(p, scene_graph) for p in prog]
    for p in preds:
        p.H = predicate_stabilizer(p)                       # 符号推导稳定子
        p.w = authority_weight(p) * p.w0                    # 安全谓词 w=inf
    return ConstraintProgram(preds)

# IP-266 TQC + IP-272 SGR：单侧安全规范约简
def task_quotient(pose_dist, C, object_model, alpha=0.05):
    H_safe = {identity}
    for gen in candidate_generators(object_model, C):       # CAD 对称 + 谓词稳定子
        if touches_safety_basis(gen):            continue  # 安全关键轴永不商掉
        if conformal_invariance_pass(gen, alpha): H_safe.add(gen)  # 只加不移
    B_h, B_p = tangent_split(pose_dist.mode, H_safe)
    return (H_safe,
            project_cov(pose_dist.cov, B_p),                # Sigma_task
            project_cov(pose_dist.cov, safety_basis(object_model)))

# IP-267 JPG：联合位姿-指称后验
def joint_grounding(pose_samples, C, scene_graph):
    modes = []
    for xi in pose_samples:
        for gamma in referent_assignments(C, scene_graph):
            e = sum(p.w * rho(p.margin(xi, gamma)) for p in C.preds)
            modes.append((xi, gamma, exp(-e)))
    return normalize_and_cluster(modes)

# IP-268 SGC：一致性 margin 与冲突分诊
def consistency_gate(modes, C, tau_m):
    m_star = max(min(p.margin(xi, gamma) for p in C.preds)
                 for xi, gamma, w in modes if w >= W_MIN)
    return ("OK" if m_star >= tau_m else triage(modes, C)), m_star

# IP-269 GAV：只对任务商算 VoI，不追规范
def choose_info_action(modes, C, budget, H_safe):
    best = None
    for g in info_candidates(modes, H_safe):                # gaze/move/probe/ask
        if not budget.allow(g) or not c_ras_wm.certify_info(g): continue
        score = (task_risk(modes) - expected_task_risk(modes, g)) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None       # 无利可图 -> 回退

# IP-276 主闭环：R69 FLUID 的语言-位姿接地版
def GAUGE_RAS_round(M, obs, ell):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    C = M.icg.compile(ell)                                  # 指令到达时缓存
    H_safe, Sig_task, Sig_safe = M.tqc.task_quotient(M.pose.posterior(o), C, M.object_model)
    modes = M.jpg.joint_grounding(M.pose.sample(o, K_p), C, M.scene)
    cls, m_star = M.sgc.consistency_gate(modes, C, TAU_M)
    if cls == "T4_ADVERSARIAL":
        return M.r68_fallback(obs)                          # 语言无权扩大安全集
    U_task, U_epi = M.aud.decompose_task(modes, H_safe)
    U_ale = M.aud.aleatoric(modes) + trace(Sig_safe)         # 安全轴无条件保留
    g = (M.gav.choose_info_action(modes, C, M.budget, H_safe)
         if (U_task > TAU_TASK or U_epi > TAU_EPI) else None)
    if g is not None:
        modes = M.cia.update_belief(modes, M.cia.execute(g, C), C)
        U_task, U_epi = M.aud.decompose_task(modes, H_safe)
    U_floor = U_ale + U_task + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if cls in ("T3_CONFLICT", "T4_ADVERSARIAL") or not M.sgr.certified(H_safe):
        lam = max(lam, 0.8)                                 # 回 R68 最保守
    xi_star = select_mode(modes, U_task, lam)
    A = M.ach.propose(M.tqc.project_target(xi_star, H_safe), M.vista.H)
    A = A & M.c_ras_wm.certified_set(o)                     # 语言不能扩大该集合
    if not A: return M.r68_fallback(obs)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    M.vqa_g.submit_async(C, H_safe, m_star, U_task, g)
    return k, lam, xi_star, (U_ale, U_task, U_epi)
```

## 4. 推导

**引理 19（任务商充分性）** 若 L_total 在 H 下不变，则 L_total=L̄∘π，π 为商映射；故 E[L_total]=E[L̄(π(ξ))]，规范方向方差可从 λ_floor 安全移除；π(ξ) 是决策充分统计量。

**引理 20（margin 可检性）** φ_j 局部 L_j-Lipschitz ⇒ m=min_jφ_j 是 L_max-Lipschitz；真实 margin m*、阈值 τ_m 时，误差 <(m*−τ_m)/L_max 不会制造假冲突，真冲突漏检需误差 ≥(τ_m−m*)/L_max。τ_m 由 conformal 校准，假冲突 ≤ α。

**引理 21（规范查询零收益）** 若信息动作只改变规范坐标分布、不改变轨道后验，则 VoI_task=0（由引理 19）。系：不要问对称杯子的「哪面是正面」，除非指令真的把该自由度移出 H_task。

**引理 22（单侧约简安全性）** H_safe⊆H_task ⇒ 商掉后风险不增（只移除不变方向）；H_safe⊄H_task ⇒ 存在同轨道两点损失不同，商掉会丢失风险信息。故只加有证据的生成元、违反即移除；conformal 保证 P(H_safe⊆H_task)≥1−α。

**引理 23（联合接地互补性）** 给定场景图下 ξ 与 γ 条件独立时，`H(γ|o,ℓ,ξ) ≤ H(γ|o,ℓ) − I(γ;ξ)`；位姿越准指称越确定，语言越具体需要估计的位姿自由度越少。二者是互信息互补，不是串联替代。

**定理 18（严格包含 FLUID/R68）** A99–A101 下 GAUGE 风险 ≤ FLUID；H_safe={e} 且 C_ℓ 空/恒真时逐指令相同；H_safe 非平凡且认证时规范方向获 resolution bonus，任务相关 λ 与安全侧不变。R69=不商规范边界，R68=不商且不接地边界。

**定理 19（语言不扩权）** 策略只在 `A_lang(ℓ)∩S_cert(o)` 中选动作，否则回退 R68；S_cert 与 ℓ、权威无关 ⇒ 任何指令都不能扩大安全集；权威只改非安全约束权重，不改 S_cert 边界。

**定理 20（联合歧义交互收敛）** 每轮任务相关互信息增益 ≥ δ 时，商熵以几何速率降至 ε 所需轮数 ≤ ⌈log(H_0/ε)/δ⌉；若最优 VoI_task≤c(g) 则停止交互，残余 U_task 进入 R68 地板。交互预算只花在「可分且任务相关」的歧义上。

**示例（同一只杯子，三种指令）**

| 指令 | H_task 包含 | 必须估计 | 不必估计 | 行为 |
|---|---|---|---|---|
| 「把水倒进杯子」 | 绕杯轴 yaw | x,y,z,roll,pitch | yaw | 不追问 yaw；yaw 方差再大也不刹车 |
| 「把手朝左递给我」 | 仅 identity | 全 6D（含 yaw） | 无 | 把手被遮挡时主动移视角或问「把手在左还是右」 |
| 「把它放正」 | yaw | roll,pitch | yaw | 杯子躺着时优先 roll/pitch 主动感知 |

**结论**：不确定性不是物体的属性，而是「物体 × 任务」的属性；同一估计器在不同指令下应使用不同商空间。

## 7. 本轮最大风险

**一句话**：GAUGE-RAS 的全部收益押在「语言正确识别了哪些位姿自由度与任务无关」上——**若把安全关键自由度误判为规范方向（gauge），系统就会对真正危险的位姿歧义视而不见；忽略一个该管的歧义，比多问一句更危险。**

**次级风险与缓解**：规范误判/过度商掉（单侧 SGR 只移除不新增 + B_safety 无条件保留 + conformal + 未知 CAD 默认 H_safe={e}）；语言解析幻觉/指称错误（冻结 LLM + 类型化 DSL + 联合后验 + SGC + 权威）；对抗指令/提示注入（IAL 安全否决 + ℰ_LANG 红队 + 定理 19）；位姿估计器模态错误（轨道级后验 + R69 FMA 第二意见 + 主动视角）；实时预算被联合接地击穿（离线编译 + 商后验缓存 + 自适应 K_p + 20–30Hz 异步）；组合指令稳定子继承错误（技能图逐子指令重认证）。
