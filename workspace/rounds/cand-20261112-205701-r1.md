## 1. 直觉解释

**物体泛化的直觉**：人类拿到一个没见过的杯子，不需要记住它的纹理和品牌，也能抓起来倒水——因为他提取的是「圆柱容器、有开口、可握持」这类**任务相关的几何/可供性**。同样，策略若把外观当成主要变量，换一个同类别不同纹理的物体就会失效；若把任务相关几何当成主要变量，外观变化就只是一层噪声。

**点云配准的直觉**：配准不是「对齐两张图」，而是**在两个部分观测之间寻找一个把 A 搬到 B 的刚体变换（必要时加尺度、形变或对称商）**。它给了我们一件别的东西给不了的能力：把训练示范里的动作轨迹，用一个 SE(3) 变换「搬」到当前场景。于是「物体泛化」不再要求策略见过这个物体，而只要求**当前物体与示范物体在任务相关几何上可配准**。

## 2. 严谨定义

### 2.1 物体泛化缺口

设任务分布 $\mathcal{D}$，物体实例 $o=(S_o,A_o,\text{pose}_o)$，其中 $S_o$ 为形状、$A_o$ 为外观。令任务相关几何状态 $g=\phi(o,\text{context})$，并假设（A1）最优策略 $\pi^\star(a\mid o,l)$ 只通过 $g$ 依赖物体。若策略写成 $\pi=h\circ\phi$（$\phi$ 外观不变），定义未见物体上的泛化缺口为

$$
\mathrm{Gap}_{obj}(\pi)=\mathbb{E}_{o'\notin\mathcal{O}_{train}}[\ell(\pi,o')]-\mathbb{E}_{o\in\mathcal{O}_{train}}[\ell(\pi,o)].
$$

这与「在训练集上多拟合一点」是两件事：前者衡量**几何估计误差与规范空间覆盖**，后者衡量**外观记忆**。

### 2.2 部分点云配准

给定当前源点云 $P=\{p_i\in\mathbb{R}^3\}$ 与目标点云 $Q=\{q_j\}$，求

$$
T^\star=\arg\min_{T\in SE(3),\,c,\,\mu}\ \sum_i \mu_i\,\rho\!\left(\|Tp_i-q_{c(i)}\|_2\right)+\lambda\,\Omega(T),
\quad\text{s.t.}\ \frac{1}{|P|}\sum_i\mu_i\ge\tau_{ov},
$$

其中 $c$ 是稀疏对应，$\mu_i\in\{0,1\}$ 是内点/重叠掩码，$\rho$ 用截断或 Geman–McClure 鲁棒核，$\Omega$ 是正则。$\tau_{ov}$ 把「部分重叠」显式写进问题，避免把背景硬配到目标上。

### 2.3 类别级与原语级配准

当测试物体与模板**不是同一实例**时，纯刚体配准不够。类别级版本允许尺度 $s$ 与低维形变 $D_\theta$：

$$
q_j\approx sRp_i+t+D_\theta(p_i),\qquad s\in[s_{\min},s_{\max}].
$$

当测试物体属于**训练中完全未见的类别**时，类别模板也失效。此时退到**原语级**：把点云分解为平面、圆柱、长方体、把手、容器口等几何原语图，配准原语坐标系而不是整物体。原语图的优势是类别无关，代价是表达能力弱，需要与局部策略配合。

### 2.4 对称性商

对具有对称群 $G_o\subset SE(3)$ 的物体（杯/碗/瓶的连续旋转、盒子的离散 90° 旋转），规范位姿不是单点而是轨道 $[T]\in SE(3)/G_o$。配准损失必须满足 $\ell(T)=\ell(Tg),\ \forall g\in G_o$，否则同一个杯子会被规范到任意 yaw，示范迁移随之旋转错位。

### 2.5 SE(3) 等变策略

动作取 EE 位姿增量 $a=(\Delta R,\Delta t)$。若场景发生 $T=(R_T,t_T)$，等变策略满足

$$
\pi(T\cdot o)=T\cdot\pi(o),\qquad
a'=(R_T\Delta R R_T^\top,\ R_T\Delta t).
$$

对 twist $\xi=(\omega,v)$，等价写法是 $\xi'=\mathrm{Ad}_T\,\xi$，其中

$$
\mathrm{Ad}_T=\begin{pmatrix}R_T&0\\ [t_T]_\times R_T&R_T\end{pmatrix}.
$$

这条性质是「位置泛化」的数学核心：位置变了，动作只需共轭变换，不需要重新学习。

### 2.6 误差分解命题（草图）

设任务损失对动作 $L_h$-Lipschitz，$\pi=h\circ\phi$，$\phi$ 外观不变，$h$ 在规范几何空间的覆盖半径为 $\varepsilon_{cov}$，配准/几何估计误差为 $\varepsilon_{geo}$。则对未见物体

$$
\mathrm{Gap}_{obj}\le L_h\big(\varepsilon_{geo}+\varepsilon_{cov}\big)+\mathrm{Bayes}_{app},
$$

其中 $\mathrm{Bayes}_{app}$ 是外观无关假设 (A1) 被违反时的不可约项。**这个式子的意义**：点云配准精度不是装饰性预处理，它直接进入泛化上界；也说明为什么接触密集任务（要求亚厘米）不能只靠配准，而必须让配准负责「接近」，局部策略负责「接触」。

## 3. 对上一循环 v1 的诊断

- **v1 的强项**：UIP-01 的滚动时域重试、UIP-05 的语言→可供性分解、UIP-07 的离线回放、UIP-08 的延迟工程，都是对的，且都在选手权限内。
- **v1 的盲点**：UIP-01 用 VLM 判「子目标是否完成」，但 VLM 对**精确空间关系**（杯子口沿差 5 mm、网线是否对准）不可靠；UIP-05 做语言 grounding，但没有把 grounding 结果落到**可度量、可变换的 3D 坐标**；UIP-10 在 joint/ee 间仲裁，却没有一个**物体中心的任务帧**。
- **结论**：本轮不推倒 v1，而是给它补一根「几何脊柱」：用点云配准产生规范任务帧，把 v1 的语义验证升级为「语义 + 几何」双验证，把动作调度建立在 SE(3) 等变表示上。

## 4. 瓶颈假设（可证伪）

- **H1（外观 vs 几何）**：32 任务上的跨物体失败，主要来自外观/纹理过拟合，而非几何不可达。若成立，几何规范化的收益应显著大于纯数据增广。
- **H2（精度分层）**：从 480×640 AV1 双目重建的点云，在 0.5–1.0 m 工作距离上只能稳定到**厘米级**，足够「接近/抓取/放置」，不够「插网线/插充电器/注射器对接」的亚厘米精度。因此配准必须与局部视觉伺服分工。
- **H3（示范可迁移）**：同一任务下，不同实例/位置的示范轨迹经 SE(3) 变换后，仍比从头生成的 VLA 动作更接近最优；这条成立与否决定 GEO-RDT 的边际收益。
- **H4（延迟可控）**：配准只在 action chunk 边界低频运行（2–5 Hz）并异步缓存，就不会把逐步延迟方差推到「可信度」警戒线以上。
- **H5（未见类别）**：对完全未见类别，类别级原型失效，但原语图 + 局部策略仍能保住一部分步骤分。

## 6. 旗舰点一句话

**GEO-RDT**：先用静态场景配准得到粗对齐，再用语言 grounded 的物体点云做类别级/原语级精配准，得到 $T$；把最近示范的 EE 轨迹按 $\mathrm{Ad}_T$ 搬到当前场景，作为自由空间阶段的动作先验，与 VLA 输出按「配准置信度 × 任务阶段」融合；接触阶段自动把权重交还给局部策略。

## 7. 本轮最大风险

**一句话**：从 480×640 AV1 四路 RGB 重建的点云在真实背景、遮挡与对称物体下，配准精度和「自置信度」都可能不可靠；一旦低置信配准被当成高置信使用，示范迁移会把错误位姿放大成系统性失败——所以必须先做「配准置信门控 + 回退纯 VLA」的硬约束，再谈迁移收益。

## 1. 旗舰点深潜：GRP-01 GEO-RDT

### 1.1 机制

**输入**：4 路 RGB（head stereo L/R、wrist L/R）、双臂关节/EE 位姿、夹爪、语言 $l$。
**输出**：动作块 $A=(a_1,\dots,a_{T_a})$。

**流程**：

1. **部分点云重建**：head 双目做立体匹配得 $P_{head}$；wrist 单目深度估计得 $P_{wrist,L/R}$；用正运动学 + 手眼标定把 wrist 点云变到基座/桌面坐标系，融合为 $P_t$（下采样到 3–8k 点）。
2. **语言条件 3D grounding**：2D 开放词表分割 + 深度反投影，或 3D 实例分割，得到任务相关物体点云 $M_t\subset P_t$ 与静态场景点云 $S_t=P_t\setminus M_t$。
3. **两级配准**：
   - 场景级：用桌面平面、静态背景、非任务物体把当前场景粗配到最近示范的初始帧，得 $T_{scene}$；
   - 物体级：对 $M_t$ 用类别原型（GRP-02）或原语图（GRP-03）精配准，得 $T_{obj}$；
   - 合成 $T=T_{obj}\circ T_{scene}$，并交给对称商投影（GRP-04）。
4. **示范检索与轨迹搬运**：按语言 + 几何描述子检索最近示范 $D$；其初始物体位姿为 $X_D$，当前为 $X$，则 $T=XX_D^{-1}$；示范 EE 轨迹 $a_D(t)$ 经 $\mathrm{Ad}_T$ 搬运为 $a_D'(t)$。
5. **置信门控与阶段融合**：置信度 $c=\mathrm{calib}(\text{fit},\text{overlap},\text{entropy},\text{temporal})$；自由空间阶段用较大 $\alpha$ 信任示范先验，接触阶段把 $\alpha$ 降到接近 0，交还局部 VLA/视觉伺服。若 $c<\tau$，直接 $\alpha=0$ 回退纯 VLA。
6. **等变输出**：若策略头在规范任务帧输出，则用 $T$ 把动作变换回世界/EE 帧（GRP-06）。

### 1.2 与现有方案差异

- 常规 VLA 把「当前图像 + 语言」直接映射到动作，物体外观/位置一变就 OOD。
- 纯示范检索（retrieval）只能做外观相似检索，无法处理位姿变化；本点用**点云配准**显式估计位姿变换，因此可以跨实例、跨位置搬运轨迹。
- 纯几何方法（ICP/抓取检测）没有语义与长程任务能力；本点把几何作为**先验/规范帧**，语义与接触仍由 VLA 负责，分工明确。

### 1.3 两级配准的动机

- 单靠物体级配准：物体小、遮挡重、对称强时容易失败；场景级提供粗初值和合理性检查。
- 单靠场景级配准：背景变化/干扰物/人为干扰会污染；物体级把注意力拉回任务对象。
- 两级互补，且任一级失败都能被置信门控（GRP-05）检测。

### 1.4 示范迁移公式

设示范初始物体位姿 $X_D\in SE(3)$，当前 $X\in SE(3)$，则把示范坐标系搬到当前坐标系的变换是

$$
T=XX_D^{-1}.
$$

若示范动作是 EE 位姿序列 $P_D(t)$，则搬运后

$$
P'(t)=T\,P_D(t).
$$

若动作是 twist $\xi_D(t)$，则

$$
\xi'(t)=\mathrm{Ad}_T\,\xi_D(t),\qquad
\mathrm{Ad}_T=\begin{pmatrix}R&0\\ [t]_\times R&R\end{pmatrix}.
$$

**正确性条件**：任务在 SE(3) 下等变、物体几何在任务相关部分一致、机器人基座不变。三者任一被破坏，残差进入下一节的误差项。

### 1.5 可行性、资源、步骤、风险

- **可行性**：中高。点云重建与配准都有成熟开源件（OpenCV stereo、Open3D、FCGF/GeoTransformer、NOCS 类方法）；难点在真实标定与延迟。
- **资源**：32 数据集离线建原型（GPU 数天）；推理端 1 张卡同时跑 VLA + 小配准网络；存储原型描述子与检索索引。
- **落地步骤**：① 核实深度/标定 → ② 离线重建 + 原型库 → ③ 仿真中验证配准与迁移（有真值）→ ④ 回放 harness 接 v1 的 UIP-07 → ⑤ 真机小规模校准 → ⑥ 提测。
- **风险**：配准失败被误判为成功（→ GRP-05）；接触阶段精度不足（→ 阶段降权 + 局部伺服）；延迟方差（→ GRP-09）。

## 2. 关键推导

### 2.1 配准目标（部分重叠 + 鲁棒核）

$$
T^\star=\arg\min_{T,c,\mu}\sum_i\mu_i\,\rho\!\left(\|Tp_i-q_{c(i)}\|_2\right)+\lambda\Omega(T),
\quad \frac{1}{|P|}\sum_i\mu_i\ge\tau_{ov}.
$$

工程上分三步：学习特征 + 互近邻对应 → RANSAC/加权 SVD 求粗 $T_0$ → GNC-ICP 精化并估重叠。类别级再加 $(s,D_\theta)$，对称级在 $G_o$ 上取 min。

### 2.2 等变动作

对 EE 位姿增量 $a=(\Delta R,\Delta t)$：

$$
a'=(R_T\Delta R R_T^\top,\ R_T\Delta t).
$$

这条式子让「物体整体平移/旋转」不再需要新数据：策略只需在规范帧学一次，输出时共轭回当前帧。

### 2.3 误差分解（命题，草图）

设任务损失 $L_h$-Lipschitz，$\pi=h\circ\phi$，$\phi$ 外观不变，规范空间覆盖半径 $\varepsilon_{cov}$，配准误差 $\varepsilon_{geo}$，则

$$
\mathrm{Gap}_{obj}\le L_h(\varepsilon_{geo}+\varepsilon_{cov})+\mathrm{Bayes}_{app}.
$$

**推论**：若 $\varepsilon_{geo}$ 大于任务允许误差，则无论策略多强，泛化上界都被卡死；这直接解释了为什么「只换更大的 VLA」不能解决插网线类任务。

### 2.4 深度误差传播（数值敏感性）

立体深度 $Z=fb/d$，故

$$
\delta Z=\frac{Z^2}{fb}\,\delta d.
$$

取 $f=500$ px、基线 $b=0.05$ m（示例值，真实基线待核实），不同距离与视差误差下：

| $Z$ \ $\delta d$ | 0.5 px | 1.0 px |
|---|---:|---:|
| 0.5 m | 5.0 mm | 10.0 mm |
| 0.8 m | 12.8 mm | 25.6 mm |
| 1.0 m | 20.0 mm | 40.0 mm |

若基线翻倍到 0.1 m，误差减半（2.5 / 6.4 / 10 mm 与 5 / 12.8 / 20 mm）。**结论**：在 0.8–1.0 m 的典型桌面距离，厘米级是现实上限；这支持 H2「配准负责接近，局部策略负责接触」。

### 2.5 对称性

规范位姿是轨道 $[T]\in SE(3)/G_o$。对连续旋转对称（杯/瓶），$G_o\cong SO(2)$；对盒/盘，$G_o$ 是离散子群。配准损失取

$$
\ell(T)=\min_{g\in G_o}\sum_i\rho(\|Tg\,p_i-q_{c(i)}\|).
$$

若不处理，示范迁移会把「杯子的任意 yaw」当成真实位姿差，产生错误旋转。

## 3. 伪代码

```python
class GeoRDT:
    def __init__(self, vla, reconstruct, ground, retrieve,
                 reg_scene, reg_obj, symmetry, gate,
                 tau=0.55, k=4, alpha_free=0.6):
        self.vla = vla
        self.reconstruct = reconstruct      # 4 路 RGB -> 部分点云
        self.ground = ground                # 语言 -> 物体点云 M / 静态 S
        self.retrieve = retrieve            # 语言+几何 -> 最近示范
        self.reg_scene = reg_scene          # S -> T_scene
        self.reg_obj = reg_obj              # M -> T_obj（类别/原语）
        self.symmetry = symmetry            # 投影到 SE(3)/G_o
        self.gate = gate                    # 置信度校准
        self.tau, self.k, self.alpha_free = tau, k, alpha_free
        self.reset()

    def reset(self):
        self.vla.reset()
        self.T, self.conf, self.demo = None, 0.0, None
        self.t, self.buf = 0, []

    def _maybe_register(self, obs):
        # 低频：仅在 chunk 边界或缓存过期时运行（GRP-09）
        P = self.reconstruct(obs)                    # head stereo + wrist + FK
        M, S = self.ground(P, obs.language)
        D = self.retrieve(M, obs.language)
        T_scene, fit_s = self.reg_scene(S, D.scene)
        T_obj, fit_o = self.reg_obj(M, D.object, D.category, D.primitives)
        T = self.symmetry(T_obj @ T_scene, D.symmetry)
        self.T = T
        self.conf = self.gate(fit_s, fit_o, T, obs)
        self.demo = D

    def get_action(self, obs):
        if self._at_boundary(obs) or self.demo is None:
            self._maybe_register(obs)

        a_vla = self.vla.get_action(obs)             # (T_a, ...)

        if self.demo is None or self.conf < self.tau:
            return a_vla                            # 硬回退

        a_demo = self.demo.action_at(self.t)         # 示范当前时刻动作
        a_demo = self.adjoint(self.T, a_demo)        # Ad_T 搬运
        alpha = self.alpha_free * self.conf * self.phase_weight(obs)
        return self.blend(a_vla, a_demo, alpha)      # EE 增量空间线性混合

    def phase_weight(self, obs):
        # 自由空间信任示范；接近接触时降权（精度不足）
        z = self.object_distance(obs)
        return 1.0 if z > 0.05 else max(0.0, z / 0.05) * 0.5

    @staticmethod
    def adjoint(T, a):
        R, t = T[:3, :3], T[:3, 3]
        dR, dt = a[:3, :3], a[:3, 3]
        return np.block([[R @ dR @ R.T, (R @ dt)[:, None]],
                         [np.zeros((1, 3)), np.ones((1, 1))]])
```

**配准核心（部分重叠 + 对称）**：

```python
def register(P, Q, G=None, tau_ov=0.3):
    Fp, Fq = feats(P), feats(Q)
    C = mutual_nn(Fp, Fq)
    T0 = ransac_se3(P, Q, C, eps=0.05)
    T = gnc_icp(P, Q, T0, loss=gm, overlap=tau_ov)
    if G is not None:
        T = min((T @ g for g in G), key=lambda Tg: residual(P, Q, Tg))
    fit = inlier_ratio(P, Q, T, eps=0.02)
    return T, fit
```

**置信门控（GRP-05）**：

```python
def gate(fit_s, fit_o, T, prev_T):
    score = 0.4 * fit_s + 0.6 * fit_o
    score *= temporal_consistency(T, prev_T)     # T 不应突变
    score *= (1.0 - correspondence_entropy)      # 对应越弥散越可疑
    return score
```

## 5. 消融与可证伪条件

**必须做的消融**：

1. 去掉配准，仅用几何描述子检索（证明收益来自「变换估计」而非「检索」）。
2. 用随机 $T$ 替代配准 $T$（证明不是任何扰动都有效）。
3. 类别原型 vs 原语图（验证 GRP-02/03 的分工）。
4. 有/无对称商（GRP-04）。
5. 有/无置信门控（GRP-05）。
6. 配准频率 0/2/5/10 Hz（GRP-09）。
7. 自由空间/接触阶段的 $\alpha$ 调度（验证 H2）。

**可证伪条件**（任一成立则收窄或放弃旗舰）：

- E101 在典型距离的 95 分位平移误差 > 5 cm → 配准不能作为主先验。
- E102 未见实例增益 < 2 个百分点 → 收益不足以抵消复杂度。
- E105 显示低置信配准无法被可靠识别（门控 AUC < 0.7）→ 回退机制不可信。
- E106 显示延迟方差触发可信度风险 → 必须进一步降频或改为纯离线检索。

## 6. 与排行榜口径的关系

- **平均成功率**：GEO-RDT 通过「跨实例/跨位置的示范迁移」直接提升未见物体与位置泛化的成功率；置信门控保证不劣化原本能成的任务。
- **步骤分**：GRP-07 用几何量（口沿距离、孔轴对齐、重叠度）定义可观测子目标，失败时也能锁定部分步骤分；这与 v1 的 UIP-01/02 互补。
- **可信度**：GRP-09 把配准限制在低频 chunk 边界，GRP-05 在低置信时回退纯 VLA，避免「延迟异常 + 动作统计异常」。
- **竞争策略**：在榜单未开放前，先建**几何代理指标**（E101/E103），比盲目堆模型更快形成可迭代闭环。

## 8. 本轮最大风险

**一句话**：从 480×640 AV1 四路 RGB 重建的点云在真实背景、遮挡与对称物体下，配准精度和「自置信度」都可能不可靠；一旦低置信配准被当成高置信使用，示范迁移会把错误位姿放大成系统性失败——所以必须先做「配准置信门控 + 回退纯 VLA」的硬约束，再谈迁移收益。
