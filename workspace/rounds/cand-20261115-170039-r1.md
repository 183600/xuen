# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「共享控制」×「跨物体泛化」）

> R69 把不确定性一分为二（aleatoric / epistemic），并给 epistemic 装上了「问」的能力：看、问、触，VoI 定价，单源不定案。但它的「问」有一个未经审视的前提——**K 个流采样模态都属于同一个已知物体**。在开放世界里，这个前提最先崩：面对一只没见过的杯子，流策略吐出的「从上方抓 / 从侧面抓 / 推开」不是三种策略，而是三个**物体假设**——它可能根本不知道这是杯子、碗还是盖子。此时把模态聚类、算 VoI、问「选哪个」，是在问一个**不可回答的问题**；更糟的是，模态校准门 MCG 只在训练对象分布内有效，跨物体正是它看不见的 OOD 轴。R69 自陈的最大风险（模态幻觉 → 自信追问幻影）因此有一个更根本的版本：**对象幻觉**。
>
> 本轮两个灵感正好各补一刀：
> - **跨物体泛化**要求把「对象级不确定性」从「动作级不确定性」里显式拆出来：先问「这是不是我认识的物体、我能不能把已知物体的经验迁移过来」，再问「该用哪个动作模态」。
> - **共享控制**把人类从「一次性答题机」还原为「持续的共同控制者」：人的摇杆修正、手扶手腕、口头制止，既是控制信号，也是关于对象身份的连续证据，还是跨物体迁移的监督。R69 只在预算内「问一句」，丢掉了这条最丰富、最自然的通道。
>
> 核心命题：**把潜变量分成对象级 z_o 与动作级 m；对象级不确定 U_obj 先由「保形对象覆盖证书」判定是否可信任、是否可迁移；可信任则原样调用 R69（R69 是对象已知的纤维）；可迁移则用共享控制同时「借人的手」和「借人的眼」消解对象歧义、并暂存对象锚点；不可信任则不做模态级决策，安全接管或弃权。** 安全侧仍不让步：权威混合过硬认证与安全滤波，对象锚点提交需正交证据与审计。命名 **COAST-RAS**（Cross-Object Authority-Sharing and Transfer for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这到底是不是我的物体、我该不该把方向盘分出去**」——不确定性不只是刹车、提问、钉子，也可以是**一次交接**。

## 0. 直觉与动机

**灵感 1（跨物体泛化 → 模态可能根本不属于同一个物体）**
直觉：R69 的流策略在一个已知物体上产生多峰，是因为「绕左还是绕右」都合理；但在新物体上产生多峰，往往是因为策略在**同时假设几个不同的物体**。就像你远远看见一个毛茸茸的东西，脑子里同时冒出「猫 / 狗 / 外套」三个假设——这时正确的动作不是「选一个假设然后靠近」，而是「先看清它是什么」。把这两种多峰混在一个模态分布里，U_epi 会把「对象歧义」误记到「动作歧义」账上。后果是系统花信息预算去问「抓上面还是抓侧面」，而人类根本无法回答，因为问题本身预设了错误的物体。跨物体泛化的第一性原理是：**泛化 gap 是对象级的，不是动作级的；先确定对象在不在覆盖范围内，再谈动作。**

**灵感 2（共享控制 → 人不是答题机，而是持续的共同控制者与迁移源）**
直觉：R69 的 g_ask 把人类压成一个离散回答，像查表。但真实协作里，人不会等你问；人会直接把手放上来、把摇杆往回带、说「别碰那个」。共享控制有三重价值：
- **控制**：在机器人不确定时，人的输入可以立刻降低任务风险（人接管）。
- **证据**：人的修正方向、力度、时机，是关于对象身份 / 属性的连续观测（「你往左推，说明这个抽屉是拉的」）。
- **迁移**：一次人机共同完成的新物体操作，天然是一段带监督的跨物体示范，可沉淀为对象锚点。
R69 只在「预算内问一次」，既慢又丢信息；共享控制把「问」变成「一起做」，信息率更高。但代价是：**权威本身是一个需要认证的决策**，不是「人在场就安全」。

**灵感 3（两级分解 → R69 是对象已知的纤维）**
直觉：把策略写成 p(ξ|o)=∫p(z_o|o)Σ_m w_m(z_o)p(ξ|m,z_o,o)dz_o。R69 相当于把 z_o 固定成 δ(z_o^*)：对象已知，只剩模态。于是 R69 的 U_epi=H(m|o) 可以分解成 U_act + L，其中 L 是「对象泄漏」——模态熵里其实由对象歧义贡献的那部分。L 大时，R69 的 VoI 在为对象歧义定价，却在用动作级信息动作去兑现，**问错了对象**。这是本轮最重要的理论姿态：新层不是并列替代 R69，而是把 R69 当成 z_o 已知的边界纤维，严格包含。

**灵感 4（对象覆盖证书 → 正面回应 R69 最大风险的 OOD 版）**
直觉：R69 的 MCG 用 ECE 判断模态权重可不可信，但 ECE 是在训练对象分布内量的；新物体上它可以「完美校准地错误」。跨物体泛化给出一个模型无关的闸门：用对象级保形预测构造 C_ε(o)，其半径 ρ(o) 就是「这个物体离我见过的世界有多远」的可证伪度量。ρ 小 → 放心跑 R69；ρ 中等且一个对象级动作能显著缩小它 → 共享控制 / 探询；ρ 大 → 根本不该做模态级决策。这把 R69 的「模态可信吗」前置为「对象可信吗」，是对其最大风险的正面回应。

**灵感 5（共享控制是双刃剑 → 权威剧场与负迁移）**
直觉：一旦系统会「分方向盘」，就有新的失败模式：
- **权威剧场**：系统把 α 降一点、让人握着方向盘，但关键决策仍由机器人做；人以为自己被监督，实则被安抚。这比 R69 的「诚实不知道」更危险，因为它制造虚假的安全感。
- **过度信任 / 依赖**：人高估机器人，或机器人高估人（β_h 估错），共享控制反而比纯自主更差。
- **负迁移**：把「杯子」的经验硬套到「玻璃杯」上，对象锚点污染覆盖集。
- **接管攻击**：恶意 / 误操作的人类输入以「共享控制」为名绕过安全边界。
所以本轮必须同时交付：权威认证、人类可靠度在线校准、对象锚点证据纪律、负迁移审计。否则 R70 只是给 R69 装了一个会甩锅的方向盘。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（COAST-RAS 总览）** COAST-RAS = (OCF, OAU, COV, SCA, HEM, XOR, OCT, RAS-WM‡)。内环为 R69 FLUID-RAS = (FMP, AUD, MINT, CIA, FMA, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）：对象锚点只暂存于 AnchorBuf，快环只读；
(ii) **权威安全**：α 经认证，混合算子保持在安全不变集内，人类输入先过安全滤波；
(iii) **对象级证据纪律**：对象覆盖未认证时不得定案动作模态；对象锚点提交需 ≥2 个正交证据源一致 + 审计。

**定义 311（两级潜变量）** 对象潜变量 z_o ∈ 𝒵（身份 / 位姿 / 物理属性 / 可供性），动作模态 m ∈ ℳ，增广动作 ξ ∈ 𝒜_+。生成分解
p(ξ|o) = ∫ p(z_o|o) Σ_m w_m(z_o) p(ξ|m,z_o,o) dz_o。
R69 对应 z_o = δ(z_o^*)（对象已知）。对象编码器给出 q(z_o|o)，条件流场为 v_θ(x_s,s|z_o,m,o)。

**定义 312（两级不确定性分解）**
U_obj = H(z_o|o)（对象级，可约，跨物体泛化的核心）；
U_act = E_{z_o}[H(m|z_o,o)]（动作级，R69 的 U_epi 在该纤维上的条件版）；
U_ale = E_{z_o,m}[tr Σ_m(z_o)]（执行级，不可约）。
**对象泄漏** L = H(m|o) − U_act = H(z_o|o) − H(z_o|m,o) ∈ [0, U_obj]：R69 的模态熵中有多少其实来自对象歧义。三者分通道处置：U_ale→λ floor，U_act→R69 MINT，U_obj→COV/SCA。

**定义 313（对象覆盖证书 COV）** 用对象级校准集构造保形预测器 C_ε(o) ⊆ 𝒵，使 P(z_o ∈ C_ε(o)) ≥ 1−ε。定义覆盖半径 ρ(o)=diam(C_ε(o))、新颖度 s_obj(o)。三区：
- **in-coverage**：ρ ≤ ρ_in 且条件模态 ECE ≤ τ_ece；
- **resolvable-novel**：ρ_in < ρ ≤ ρ_res 且对象级 VoI_obj(g*) > c(g*)；
- **out-of-coverage**：否则。
GenCert(o) 输出 (zone, ρ, s_obj)。ρ 是「跨物体泛化 gap」的可证伪代理。

**定义 314（共享控制与权威）** 人类输入 u_h ∈ 𝒰，机器人动作 u_r = π_θ(·)。权威 α: 𝒳→[α_min,1]（机器人份额）。混合
u = Π_safe( α ⊙ u_r ⊕ (1−α) ⊙ u_h )，
其中 ⊕ 为认证混合族（凸组合 / 阻抗混合 / 接管），Π_safe 为 C-RAS-WM 安全投影。**α 是决策变量，不是固定参数**；α_min 保留人类接管能力，不等于让渡安全责任。

**定义 315（人类输入的三重角色与证据模型）** u_h 同时是：(i) 控制通道；(ii) 关于 z_o 的证据，似然 p(u_h|z_o,o)；(iii) 跨物体迁移监督，认证后可生成对象锚点。人类证据模型 HEM=(β_h,b_h,τ_h,ρ_h)：可靠度、偏差、延迟、与机器人误差的相关性。默认不把人类当 oracle；单次 u_h 只提供似然，不单独改写对象后验。

**定义 316（仲裁律 SCA）** 
α* = argmax_α E[U_task + VoI_H(α) − c_h(α) − c_auth(α)]
s.t. Risk(α,x) ≤ ε_auth，|α_t−α_{t−1}|≤δ，dwell_time≥τ_dw。
含滞回与死区；当 GenCert = out-of-coverage 时 α 强制降到 α_min（人类接管或弃权），不允许自动全权。α 的优化目标是**认证风险下的期望效用**，不是「不确定性大就交权」的启发式。

**定义 317（共享控制的信息率）** VoI_H(α,g) = I(z_o,m; y,u_h | o, do(α,g)) − c_h(α) − c_switch(α)，其中时间相关的人类输入按有效样本数 n_eff = 1/(1+2Σ_k ρ_k) 折算；c_switch 惩罚权威抖动。系：共享控制不是免费信息，人类注意力与信任都是预算。

**定义 318（跨物体迁移算子 XOR）** 已知对象锚点集 𝒜={(z_j,r_j)}。对新颖对象寻找结构化表示 z_o ≈ Σ_j λ_j z_j + δ，λ∈Δ、‖δ‖≤δ_max。迁移风险界
R(o) ≤ Σ_j λ_j R_j + L_T‖δ‖ + ε_bary + ε_cal。
用最优传输 / 重心坐标选 λ，得到「从哪些已知物体迁移」的可解释证书。

**定义 319（对象锚点 OCT）** 一次认证的共享控制 episode 可暂存为锚点 a=(z_o, 可供性后验, 交互日志, 保形残差)，进入 AnchorBuf；只有满足定义 310-iii 才提交，提交后扩张覆盖集合并重标定 COV。快环只读，不写。锚点带版本与来源哈希，可回滚。

**定义 320（两阶段分派 OGD）**
- **in-coverage** → 直接调用 R69 FLUID（逐指令相同）；
- **resolvable-novel** → 先共享控制 / 对象级探询，更新 z_o 后再调用 FLUID；
- **out-of-coverage** → 不做模态级决策；安全接管或弃权。
⇒ R69 = in-coverage 边界；安全侧不弱于 R69。

**定义 321（对象级证据纪律）** 对象级后验 / 锚点提交需：(i) 保形覆盖检查；(ii) ≥2 个正交对象证据源（视觉槽、触觉探针、人类示范）一致；(iii) 单次人类话语不得单独重定义对象身份；(iv) VQAuditor-S 审计。继承 R69 定义 293-iii 的「k 源一致」纪律，但把对象从模态里独立出来。

**定义 322（共享控制安全与无抖振）** 混合算子 Lipschitz；Π_safe 保持前向不变集；权威变化率与 dwell time 约束；人类输入越界时投影而非拒绝；接管 / 交还时 bump-less（u 连续）。定理 19 给出风险 ≤ ε_auth 与无抖振。

**定义 323（参与式审计 VQAuditor-S）** 审计：α 是否由覆盖 / 不确定性证明、人类是否被过度信任、对象锚点是否过早提交、是否把共同控制者误当 oracle。结论回灌 AnchorBuf 与仲裁先验。

**定义 324（共享控制-跨物体干扰集 AIC-COAST）** ℰ_COAST = ℰ_FLUID × ℰ_obj × ℰ_auth × ℰ_transfer：对抗纹理 / 类别混淆 / 物体伪装；接管攻击 / 权威振荡 / 社交工程；负迁移 / 虚假部件对应。

```python
# IP-264 OCF：对象中心因子化（复用 R69 trunk 的中间特征，零重复训练）
class ObjectCentricFactorizer:
    def __init__(self, slot_encoder, prop_head, aff_head):
        self.slots, self.prop, self.aff = slot_encoder, prop_head, aff_head
    def posterior(self, o):
        s, z = self.slots(o)                 # s: 对象槽，z: 对象潜变量
        return z, self.prop(z), self.aff(z)  # 物理属性 / 可供性后验

# IP-265 OAU：两级不确定性分解 + 对象泄漏 L
def decompose_two_level(policy, o, z_samples, K):
    U_obj = entropy(z_samples)
    U_act, U_ale, per_z = 0.0, 0.0, []
    for z in z_samples:
        modes = cluster_trajectories(policy.sample(o, K, cond=z))
        w = mode_weights(modes)
        U_act += entropy(w) / len(z_samples)
        U_ale += sum(w[k] * trace(cov(modes[k])) for k in modes) / len(z_samples)
        per_z.append((z, modes))
    L = entropy(cluster_trajectories(policy.sample(o, K))) - U_act  # 对象泄漏
    return U_obj, U_act, U_ale, max(L, 0.0), per_z

# IP-266 COV：对象覆盖证书（保形，模型无关）
def gen_certificate(o, ocf, calib):
    z = ocf.posterior(o)[0]
    rho = calib.conformal_radius(z)          # C_ε 的半径
    s   = calib.novelty(z)
    if rho <= RHO_IN:
        zone = "in"
    elif rho <= RHO_RES and calib.voi_obj(z, o) > calib.cost_obj(o):
        zone = "resolvable"
    else:
        zone = "out"
    return GenCert(zone, rho, s)

# IP-267/268 SCA + HEM：共享控制仲裁（带安全滤波与滞回）
def arbitrate(gencert, o, state, human, robot):
    if gencert.zone == "in":
        return 1.0, "auto"                    # 完全自主，走 R69
    if gencert.zone == "out":
        return ALPHA_MIN, ("handover" if human.available else "abstain")
    best = None
    for alpha in candidate_alphas(state):     # 含滞回 / 死区
        u = project_safe(blend(alpha, robot.action(state), human.input))
        if not c_ras_wm.certify(u, state):
            continue
        score = (task_utility(u) + voi_human(alpha, gencert, o)
                 - human.load(alpha) - risk_penalty(u))
        best = max(best, (alpha, score), key=lambda t: t[1])
    return best.alpha, "share"

# IP-269/270 XOR + OCT：跨物体迁移与对象锚点（只暂存，快环不写）
def transfer_and_stage(o, z_post, anchors, evidence):
    lam, delta = optimal_transport_barycentric(z_post, anchors)
    bound = (sum(l * a.risk for l, a in zip(lam, anchors))
             + L_T * norm(delta) + EPS_CAL)
    if evidence.orthogonal_count >= 2 and audit_passed(o, z_post, evidence):
        anchor_buf.stage(Anchor(z_post, evidence.affordance, evidence.log, delta))
    return lam, bound

# IP-275 主闭环：对象级闸门 + 内嵌 R69
def COAST_round(M, obs):
    z, props, aff = M.ocf.posterior(obs)
    gencert = M.cov.certify(z, obs)
    if gencert.zone == "in":
        return M.fluid_round(obs)                       # 逐指令 = R69
    if gencert.zone == "out":
        return M.safe_handover(obs, gencert)            # 或 abstain，绝不做模态决策
    alpha, mode = M.sca.arbitrate(gencert, obs, M.state, M.hem, M.robot)
    u_r = M.fmp.sample(obs, K=4)
    u_h = M.hem.read()
    u   = M.sca.blend(alpha, u_r, u_h)                   # 认证混合 + 安全投影
    z_post = M.hem.update_object_belief(z, u_h)          # 人输入作为对象证据
    lam, bound = M.xor.transfer_and_stage(obs, z_post, M.anchors, M.evidence)
    if M.cov.certify(z_post, obs).zone == "in":
        return M.fluid_round(obs, cond=z_post)          # 对象已消解，回 R69
    return M.safe_conservative(u, bound, gencert)        # 未消解：保守 + 保留接管
```

## 3. 推导

**引理 19（模态熵的对象泄漏分解）** 由熵的链式法则，
H(m,z_o|o) = H(z_o|o) + H(m|z_o,o) = H(m|o) + H(z_o|m,o)。
故 H(m|o) = U_act + L，其中 L = U_obj − H(z_o|m,o) = H(m|o) − U_act。由条件降低熵，0 ≤ L ≤ U_obj。
**系**：R69 的 U_epi≈H(m|o) 是 U_act 的上界。当 L≈U_obj（模态几乎不透露对象）时，R69 的模态熵由对象歧义主导；它的 VoI 在为对象歧义定价，却选择动作级信息动作，可能花预算问一个**不可回答**的问题。COAST 先把 L 从 U_act 里剥出来，再决定该问对象还是问动作。

**引理 20（对象歧义下动作模态不可辨识）** 设动作的物理语义为 φ(z_o,m)。若存在 z_1≠z_2 使 φ(z_1,m)≠φ(z_2,m)（同一模态在不同物体上意味着不同物理动作），则仅凭边缘模态划分无法确定物理动作；对混合模态聚类得到的「元模态」不对应任何单一对象的模态，条件化到元模态后 z_o 仍可能歧义。因此依赖边缘模态的决策无法给出有界的物理误差，**先对象后动作**是唯一可辨识的顺序；R69 的 action-first 在对象未知时不是次优，而是 ill-posed。

**引理 21（跨物体迁移界）** 设风险对对象表示 L_T-Lipschitz，且重心近似有 ε_bary、校准有 ε_cal。对 z_o≈Σλ_j z_j+δ，
R(o) ≤ Σ_j λ_j R_j + L_T‖δ‖ + ε_bary + ε_cal。
**系**：覆盖半径 ρ 直接给泛化 gap 上界；ρ 越大越不该信任模态。用最优传输选 λ 可同时最小化 ‖δ‖ 与加权锚点风险，给出「从哪些已知物体迁移」的可解释答案。

**引理 22（共享控制的价值与信任界）** 设机器人误差 e_r（方差 σ_r²）、人类误差 e_h+b（方差 σ_h²+b²），相关系数 ρ。凸混合误差 e=αe_r+(1−α)(e_h+b)+ε_blend，则
E[e²]=α²σ_r²+(1−α)²(σ_h²+b²)+2α(1−α)ρσ_rσ_h+σ_blend²，
最优 α* 随人类方差与偏差增大而增大、随相关性增大而减小（截断到 [α_min,1]）。**系**：共享控制只在 β_h 高且 b_h 小时优于纯自主；若 β_h 被高估，共享控制的风险可以超过纯自主保守。α 必须由校准后的 β_h 与认证风险决定，不能由「人类在场」这一事实决定。

**定理 18（COAST 严格包含 FLUID/R69）** 在 A99–A102（对象后验校准、仲裁安全、迁移界成立）下，COAST 的期望风险 ≤ FLUID + ε_cal；in-coverage 且 α=1 时两者逐指令相同；resolvable-novel 时对象级证据使 U_obj 降低，再条件化调用 FLUID，故 U_epi 与保守代价不高于 R69；out-of-coverage 时进入不弱于 R68 的保守 / 接管。安全侧不让步，效率侧获得对象级 resolution bonus。

**定理 19（共享控制安全与无抖振）** 在安全滤波 Π_safe、权威速率限制 |Δα|≤δ、dwell time τ_dw、bump-less 混合下，闭环保持在不变集内，α 有界变差，u 连续，风险 ≤ ε_auth。β_h→0 时引理 22 给出 α*→1，COAST 退化为自主保守策略，不会因人类不可靠而变差。

**定理 20（覆盖单调性与锚点扩张）** 每个通过证据纪律与留出验证的锚点只扩张（不收缩）名义覆盖集；会话内交换性成立时，保形覆盖率保持 ≥1−ε；跨会话分布漂移下改用加权保形，覆盖率以漂移界退化。**系**：跨物体泛化是可累积的，但必须审计、留出验证与可回滚，否则锚点会变成负迁移的污染源。

# 第 70 轮产物 · 创新点清单 v1：COAST-RAS（Cross-Object Authority-Sharing and Transfer for Risk-Adaptive Systems：对象级 / 动作级不确定性二分 × 保形对象覆盖 × 共享控制权威仲裁的跨物体泛化闭环；OCF×OAU×COV×SCA×HEM×XOR×OCT×RAS-WM‡）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 把不确定性一分为二（aleatoric / epistemic），并给 epistemic 配了「问」的能力，但它的「问」默认 **K 个流采样模态属于同一个已知物体**。在开放世界里，这个前提最先失效：面对新物体，流策略的多个模态往往不是「不同策略」，而是**不同物体假设**；此时 R69 的模态聚类、VoI、追问都作用在错误的潜变量上，而模态校准门 MCG 只在训练对象分布内有效——跨物体正是它看不见的 OOD 轴。
>
> 本轮两个灵感各补一刀：
> - **跨物体泛化**：把潜变量拆成对象级 z_o 与动作级 m，先判定对象是否在覆盖范围内、可否迁移，再谈动作模态。R69 的 U_epi 被分解为 U_act + L（对象泄漏），L 大时 R69 在为对象歧义定价却用动作级动作兑现。

>
> 核心命题：**对象可信 → 原样调用 R69（R69 是对象已知的纤维）；对象可迁移 → 共享控制 + 对象锚点消解 U_obj，再条件化调用 R69；对象不可信 → 不做模态级决策，安全接管或弃权。** 安全侧不让步，效率侧获得对象级 resolution bonus。命名 **COAST-RAS**。
>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这到底是不是我的物体、我该不该把方向盘分出去**」。

## 3. 关键算法伪代码

```python
# IP-264 OCF：对象中心因子化（复用 R69 trunk）
class ObjectCentricFactorizer:
    def posterior(self, o):
        s, z = self.slots(o)                  # 对象槽 + 对象潜变量
        return z, self.prop(z), self.aff(z)   # 物理属性 / 可供性

# IP-265 OAU：两级分解 + 对象泄漏 L
def decompose_two_level(policy, o, z_samples, K):
    U_obj = entropy(z_samples)
    U_act, U_ale = 0.0, 0.0
    for z in z_samples:
        modes = cluster_trajectories(policy.sample(o, K, cond=z))
        w = mode_weights(modes)
        U_act += entropy(w) / len(z_samples)
        U_ale += sum(w[k]*trace(cov(modes[k])) for k in modes) / len(z_samples)
    L = entropy(cluster_trajectories(policy.sample(o, K))) - U_act
    return U_obj, U_act, U_ale, max(L, 0.0)                 # 对象泄漏非负

# IP-266 COV：保形对象覆盖证书
def gen_certificate(o, ocf, calib):
    z = ocf.posterior(o)[0]
    rho, s = calib.conformal_radius(z), calib.novelty(z)
    if rho <= RHO_IN: zone = "in"
    elif rho <= RHO_RES and calib.voi_obj(z,o) > calib.cost_obj(o):
        zone = "resolvable"
    else: zone = "out"
    return GenCert(zone, rho, s)

# IP-267/268 SCA + HEM：共享控制仲裁

    if gencert.zone == "in":  return 1.0, "auto"           # 走 R69
    if gencert.zone == "out": return ALPHA_MIN, ("handover" if human.available else "abstain")
    best = None
    for alpha in candidate_alphas(state):                  # 滞回 / 死区
        u = project_safe(blend(alpha, robot.action(state), human.input))
        if not c_ras_wm.certify(u, state): continue
        score = (task_utility(u) + voi_human(alpha,gencert,o)
                 - human.load(alpha) - risk_penalty(u))
        best = max(best, (alpha, score), key=lambda t: t[1])
    return best.alpha, "share"

# IP-269/270 XOR + OCT：迁移界 + 锚点暂存
def transfer_and_stage(o, z_post, anchors, evidence):
    lam, delta = optimal_transport_barycentric(z_post, anchors)
    bound = sum(l*a.risk for l,a in zip(lam,anchors)) + L_T*norm(delta) + EPS_CAL
    if evidence.orthogonal_count >= 2 and audit_passed(o, z_post, evidence):
        anchor_buf.stage(Anchor(z_post, evidence.affordance, evidence.log, delta))
    return lam, bound

# IP-275 主闭环：对象闸门 + 内嵌 R69
def COAST_round(M, obs):
    z, props, aff = M.ocf.posterior(obs)
    gencert = M.cov.certify(z, obs)
    if gencert.zone == "in":
        return M.fluid_round(obs)                          # 逐指令 = R69
    if gencert.zone == "out":
        return M.safe_handover(obs, gencert)               # 或 abstain
    alpha, mode = M.sca.arbitrate(gencert, obs, M.state, M.hem, M.robot)
    u_r, u_h = M.fmp.sample(obs, K=4), M.hem.read()
    u = M.sca.blend(alpha, u_r, u_h)                       # 认证混合 + 安全投影
    z_post = M.hem.update_object_belief(z, u_h)             # 人输入 = 对象证据
    lam, bound = M.xor.transfer_and_stage(obs, z_post, M.anchors, M.evidence)
    if M.cov.certify(z_post, obs).zone == "in":
        return M.fluid_round(obs, cond=z_post)             # 对象已消解 → R69
    return M.safe_conservative(u, bound, gencert)          # 未消解：保守 + 保留接管
```

## 4. 推导

**引理 19（对象泄漏分解）** `H(m|o)=U_act+L`，`L=U_obj−H(z_o|m,o)=H(m|o)−U_act`，且 `0≤L≤U_obj`。系：R69 的 U_epi 是 U_act 的上界；L 大时 R69 在为对象歧义定价，却用动作级信息动作兑现，可能问一个不可回答的问题。

**引理 20（对象歧义下模态不可辨识）** 若同一模态 m 在不同对象上对应不同物理动作 φ(z_o,m)，则边缘模态聚类得到的「元模态」不对应单一对象，条件化后 z_o 仍歧义；依赖边缘模态的决策无法给出有界物理误差。故先对象后动作是唯一可辨识顺序；R69 的 action-first 在对象未知时是 ill-posed，而非仅次优。

**引理 21（跨物体迁移界）** 风险 L_T-Lipschitz 下，`R(o)≤Σλ_j R_j+L_T‖δ‖+ε_bary+ε_cal`。系：覆盖半径 ρ 直接给泛化 gap 上界；λ 由最优传输给出可解释迁移来源。

**引理 22（共享控制价值与信任界）** 凸混合误差方差
`E[e²]=α²σ_r²+(1−α)²(σ_h²+b²)+2α(1−α)ρσ_rσ_h+σ_blend²`；
α* 随人类方差 / 偏差增大而增大、随相关增大而减小。系：共享控制只在 β_h 高且 b_h 小时优于纯自主；β_h 高估会让共享控制比纯自主更差，因此 α 必须由校准 β_h 与认证风险决定。

**定理 18（COAST 严格包含 FLUID/R69）** A99–A102 下，期望风险 ≤ FLUID+ε_cal；in-coverage 且 α=1 时逐指令相同；resolvable-novel 时对象证据降低 U_obj，再条件化调用 FLUID，U_epi 与保守代价不高于 R69；out-of-coverage 进入不弱于 R68 的保守 / 接管。安全不让步，效率获得对象级 resolution bonus。

**定理 19（共享控制安全与无抖振）** 安全滤波 + 权威速率限制 + dwell + bump-less 下，闭环保持前向不变集，α 有界变差，u 连续，风险 ≤ ε_auth；β_h→0 时 α→1，退化为自主保守。

**定理 20（覆盖单调性与锚点扩张）** 通过证据纪律与留出验证的锚点只扩张名义覆盖集；会话内交换性下保形覆盖率 ≥1−ε；跨会话漂移用加权保形，覆盖率按漂移界退化。系：跨物体泛化可累积，但锚点必须审计、留出验证、可回滚，否则成为负迁移污染源。

## 7. 本轮最大风险

**一句话**：COAST 的全部收益押在「对象覆盖证书在分布外仍然诚实」这一前提上——**一个在对象槽空间里「看起来像已知物体」的新物体会被判为 in-coverage，系统于是照 R69 自信地问错动作问题，而共享控制又让人类误以为自己仍在监督；覆盖幻觉与权威幻觉叠加，比 R69 的模态幻觉更隐蔽、更难被人类察觉。**

**次级风险与缓解**：保形覆盖在对象漂移下失效（加权保形 + 滑动窗口 + OOD 对抗，E304/E314）；β_h 估错（在线校准 + 认证风险 + β_h 低时 α→1，引理 22/定理 19）；负迁移 / 锚点污染（证据纪律 + 留出验证 + 可回滚，E309）；权威抖振 / 接管攻击（安全滤波 + 滞回 + dwell + ℰ_auth，E307/E311）；过度因子化（保留 z_o→m 条件依赖 + 消融，E301/E302）。
