# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「运动规划」×「数字孪生」）

> R69 把不确定性一分为二，并让系统学会「去问」：aleatoric 收紧、epistemic 用看/问/触去消解。它自陈的最大风险是「模态权重不可信 → 问错比不问更危险」。但 R69 仍有两个未经审视的隐含假设：
> 1. **歧义的价值是动作块级别的**：只要动作模态熵高，就值得问；只要模态分得开，问就有用。它没有问「这个歧义会不会改变我真正要执行的计划」。
> 2. **消歧只能直接发生在真实世界上**：每一次看/问/触都要付出真实代价，且没有地方可以先彩排。
>
> 本轮两个灵感正好从两个方向拆掉这两个假设：
> - **运动规划**告诉我们，安全与效率不是单个动作的属性，而是**带分支的计划**（同伦类、接触模式、 contingency 结构、回退策略）的属性；歧义只有改变计划的**离散骨架**时才值得付出真实交互的代价。更进一步，**移动本身就是测量**——去一个更有信息的位置，往往比原地多问一句更能消歧。
> - **数字孪生**允许我们在不碰真实世界的情况下排练成千上万个计划、交互与故障后果，把「问之前先彩排」变成可能。但孪生是一个**模型**：它的保真度是状态/计划相关的、会滞后、会被投毒、会被规划器找到「只在孪生里成立」的漏洞。R68 的「标定可吸收故障」在这里升级为「孪生可吸收现实」。
>
> 核心命题：**把决策变量从「动作块 ξ」提升为「信念空间中的 contingency plan Π」；把「真实世界交互」扩展为「先在数字孪生里排练 → 用保真度证书决定哪些排练结果可以采信 → 只对能改变计划骨架的歧义做真实交互或信息运动 → 用独立现实锚点持续校准孪生」；孪生永远只是证人不是法官，一旦保真度不可证或与锚点冲突，逐级退化为 R69/R68。** 命名 **TWIN-PLAN-RAS**（Twin-Rehearsed Plan-space, Information-aware, Necessity-gated Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在哪个世界里排练、这次排练本身可信吗；为了这点不确定，值得改变计划吗**」——从「问一个动作」升级为「排练一个计划，再决定是否值得为它去问」。

## 0. 直觉与动机

**灵感 1（运动规划 → 决策的单位是「带分支的计划」，不是「动作块」）**
直觉：R69 在动作块空间采样 K 个模态，用模态熵 H_mode 判断歧义。但动作块的多峰性并不等于决策的多峰性：两条向左微调 3cm 的轨迹属于同一个同伦类，而绕左还是绕右是两个计划类；前者差之毫厘，后者谬以千里。R69 会为前者浪费一次交互，却可能对后者只看到一个「模态距离」。运动规划给出的正确对象是**带反馈与分支的计划**：同伦类/接触模式/contingency 结构决定离散骨架，连续优化只负责骨架内的轨迹。歧义只有**改变骨架、改变约束可行性、或改变安全回退**时才值得消解——这把 R69 的「熵」升级为「决策边界上的熵」。

**灵感 2（运动规划 → 移动本身就是一种测量）**
直觉：R69 的信息动作是原地看/问/触；但人类消歧最常用的动作是**走过去看清楚**、绕到侧面看遮挡、用不同接触方式试探摩擦。信息并不只来自传感器读数，也来自**选择在哪个状态观测**。因此「信息运动」必须与任务运动共享同一个计划与同一个安全认证：一条轨迹可以同时是「去目标」和「去看清目标是什么」。这既扩展了 R69 的信息动作空间，也带来新的约束——信息运动本身可能把系统带入风险区，必须像任务动作一样被认证。

**灵感 3（数字孪生 → 先排练，再承诺）**
直觉：R69 计算 VoI 时需要估计「问完之后我会怎么想」，这其实已经偷偷依赖了一个世界模型。数字孪生把这件事显式化：在孪生里批量 rollout 候选计划、候选交互、候选故障，得到反事实代价与后果，再决定是否在真实世界执行。排练的价值不只是「更便宜」，而是**把一次不可逆的真实试错，换成一万次可逆的虚拟试错**。但排练也有一个致命诱惑：孪生里的成功不代表现实中的成功。

**灵感 4（数字孪生 → 孪生是证人，不是法官）**
直觉：如果孪生既负责「生成计划」又负责「证明计划安全」，它就可以自证清白。R68 已经吃过一次亏：标定层可以把缓变故障解释掉；R70 的孪生层可以把 sim2real 偏差解释掉——只要在线更新孪生参数，使残差看起来很小。于是必须规定：**孪生只能提供排练证据，不能单独签发高风险的执行许可**；至少需要独立现实锚点（真实执行结果、随机化探针、第三方验证）与回退策略。这与 R69 的「k 个正交证据源」是同一条证据纪律，只是从「问人类」升级为「问现实」。

**灵感 5（两级时间尺度 → 用回退买时间，而不是用延迟赌安全）**
直觉：运动规划 + 孪生批量 rollout 不可能塞进 R69 的 2.6ms 实时回路。正确的工程姿态不是把规划器压到 2.6ms，而是承认它属于**慢层**：慢层异步地提议/排练/认证计划，快层只执行「已认证前缀 + 递归回退」。只要回退不变式成立，慢层迟到、超时、甚至算错，都不会破坏快层的安全；效率可以降级，安全不能。这使 TWIN-PLAN-RAS 的实时性论证从「规划要多快」变成「回退要永远可行」。

**灵感 6（新威胁模型 → 排练得越好，错得越自信）**
直觉：R69 最怕「问错，比不问更危险」；R70 最怕「排练错，比不排练更危险」。一个只在孪生里安全的计划，会被证书盖上「已验证」的章，系统因此比没有孪生时更敢于冒险。新的攻击面包括：陈旧孪生、被投毒的孪生、规划器利用孪生伪影找到的 sim2real 漏洞、现实锚点被污染、以及孪生与策略共享训练数据导致的**相关失效**（两者一起错，锚点也看不出来）。所以本轮必须同时交付：保真度证书、锚点治理、孪生发散检测、计划级审计，以及「孪生不可信即退回 R69/R68」的严格折叠。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TWIN-PLAN-RAS 总览与四不变式）** TWIN-PLAN-RAS = (FMP, AUD, MINT, CIA, FMA, TSP, PCP, PCV, IMM, FCM, RAG, TDR, HSC, FRB, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；孪生、规划、校准的更新只在慢层）；
(ii) **孪生只作证人**：任何高风险计划不得仅凭孪生内部证据获得执行许可，必须至少有一个独立现实锚点，或退化为 R69/R68；
(iii) **计划级承诺**：只执行已认证的计划前缀，且该前缀在保真度界内存在递归可行的安全回退；不得执行依赖未认证孪生区域的计划分支；
(iv) **失败折叠**：保真度不可证、锚点覆盖不足、孪生发散告警、计划 VoI ≤ 成本或 ECE 越界时，逐级退化为 R69（无孪生）或 R68（无交互）的保守策略，安全侧永不弱于前轮。

**定义 311（数字孪生对象与保真度场）** 数字孪生 T = (f_T, g_T, c_T, Σ_T, ρ_T)，由 R67 的 VISTA 世界模型与 R68 的 COF 标定层复用而来，状态 x_T 与真实状态 x 同步。f_T 预测下一步，g_T 生成观测，c_T 给出代价/风险，Σ_T 为模型不确定性，ρ_T: 𝒳×𝒰×ℋ → [0,1] 为**保真度场**。孪生-现实偏差
`d_T(x,u) = D(f_T(x,u), f_M(x,u))`，
其中 M 为真实世界，D 为任务相关度量（状态/代价/约束违反的加权）。ρ_T 不是常数，而是随区域、计划骨架、接触模式与时间变化的局部量。

**定义 312（信念空间 contingency plan）** 计划
`Π = (σ, π_σ, β_σ, Π_fb)`
其中 σ ∈ Σ_skel 是离散骨架；π_σ: 𝒳×ℬ → 𝒰 是骨架内的反馈策略；β_σ 把观测映射到子计划（分支）；Π_fb 是递归安全回退树。计划在信念 b 下的执行诱导随机轨迹分布 P(ξ|Π,b)。计划集合 F(b) 为满足硬约束与回退不变式的计划。

**定义 313（计划骨架、同伦类与稳定性）** 骨架身份
`σ(Π) = ([γ_1],…,[γ_m]; κ; ι; φ_fb)`
其中 [γ_i] 为无障碍空间中的同伦类，κ 为接触模式序列，ι 为信息分支签名，φ_fb 为回退签名。两个计划同骨架当且仅当四者相同。在可信信念集 B_δ 上，若 argmin 骨架唯一且不随 b∈B_δ 改变，称计划**骨架稳定**；否则称处于**决策边界**。同伦类之间的距离用轨迹的 W_2/Fréchet 距离与接触序列的编辑距离组合。

**定义 314（孪生排练与稳健计划代价）** 对计划 Π 在孪生中采样 N 条 rollout，得到 Ĵ_T(Π)。取计划特征 φ(Π)（骨架哈希、时域、接触模式、区域新颖度、锚点覆盖等），用现实锚点校准的分位数 q_{1−α}(φ) 构造稳健上界：
`J̄(Π) = Ĵ_T(Π) + q_{1−α}(φ(Π))`。
可行计划还需满足硬约束（碰撞、力、时间窗）与回退可行。分支计划递归地对其每个子计划应用同一上界；高风险分支不得用低风险分支的余量来「平均掉」。

**定义 315（保真度共形校准与信任域）** 现实锚点集合
`A = {(φ_i, d_i)}`，`d_i = J_M(Π_i) − J_T(Π_i)`
来自不依赖孪生预测偏差的采样策略（随机化探针、分层执行、留出环境）。用 split conformal 得局部/分组（Mondrian）分位数 q_{1−α}(φ)，并在分布漂移下用自适应共形推断（ACI）更新覆盖率。**信任域**
`𝒯_α = { (x,Π) : 局部经验覆盖率 ≥ 1−α−δ 且漂移统计量 ≤ τ_d }`。
只有落在 𝒯_α 内的计划特征才可使用 q_{1−α}；域外无保证。注意：共形保证依赖锚点与目标计划的可交换性；ACI 只维持长期覆盖率，不提供逐计划保证，因此证书必须同时报告局部覆盖率与锚点覆盖。

**定义 316（现实锚点与锚点覆盖）** 现实锚点是由真实执行、随机化探针或独立第三方验证获得、且其采集策略不依赖于孪生当前偏差预测的观测。锚点带来源、时间戳、区域与计划特征。**锚点覆盖**
`cov(A, φ) = 在 φ 邻域内至少含 m 个独立锚点的特征区域占比`。
高风险计划要求 cov ≥ c_min 且独立来源数 ≥ k。锚点本身可能被投毒，故锚点也要过 R69 的 k 源一致性纪律；由孪生生成的「伪锚点」一律不计入覆盖。

**定义 317（计划条件 VoI 与决策边界门）** 在信念 b 下，稳健计划值
`V(b) = min_{Π∈F(b)} J̄(Π; b)`。
对信息动作 g（可含信息运动）：
`VoI_plan(g) = E_{y~p(·|b,g)}[V(b_y)] − V(b)`。
设最优与次优骨架的代价差为决策裕度 Δ_σ(b)。交互/信息运动门：
`g* = argmax_g [VoI_plan(g) − c(g)]`，s.t. `risk(g) ≤ ε_int` 且预算允许；仅当 `VoI_plan(g) > c(g)` 且 g 可能改变骨架、约束可行性或回退选择时才执行。若 `σ*(b)` 在可信集 B_δ 上稳定且 Δ_σ 足够大，则即使 H_mode 很高也不交互——这直接修掉 R69 的过度交互。

**定义 318（信息丰富运动 IMM）** 信息运动 m ∈ ℳ_info ⊂ ℳ 是对计划相关潜变量 Z（模态身份、接触状态、遮挡结构、孪生偏差）有信息增益的轨迹/接触动作：
`IG(m) = H(Z|b) − E_{y~P(·|b,m)}H(Z|b,y)`。
m 与任务动作共享同一动作空间、同一 C-RAS-WM 认证与同一预算；若 m 本身越界或挤占安全回退，则作废。R69 的看/问/触是 ℳ_info 的静止特例，信息运动是其轨迹化推广。

**定义 319（孪生发散分解与「孪生吸收」判据）** 观测残差分解
`z_t = y_M − y_T = e_model + e_shift + e_poison + ε`，
分别为可学习模型误差、慢变世界漂移、对抗投毒与噪声。定义发散分 D_T = ‖z_t‖_{Σ_T} 与变点统计量，以及留出锚点一致性 A_T。**孪生吸收**指在线孪生更新把 D_T 压低、却使留出锚点的 A_T 恶化：这正是 R68「标定吸收故障」在模型层的镜像。判据：`D_T > τ_D` 且/或 `A_T > τ_A` ⇒ 收缩信任域并触发 TDR 第二意见；不能仅凭 D_T 下降就宣布孪生变好。

**定义 320（孪生威胁模型 AIC-TWIN）**
`ℰ_TWIN = ℰ_FLUID × ℰ_twin`，
`ℰ_twin = {陈旧孪生, 投毒孪生, sim2real 漏洞利用, 锚点投毒, 孪生-策略相关失效}`。
其中「漏洞利用」指规划器找到在孪生中安全、在现实中不安全的计划类；「相关失效」指孪生与策略共享训练数据/代码/偏差，导致二者一起错而锚点又恰好未覆盖。

**定义 321（递归回退与稳健安全）** 回退树 Π_fb 满足不变式：在计划执行的任意可达状态，存在可行回退策略使风险 ≤ ε_fb，且回退自身递归可行。认证前缀长度 k 取为使「最坏保真度偏差 q_{1−α} 下的回退仍可行」的最大前缀。观测落在分支外时，切换到回退或重规划，切换算子需满足控制连续性与 R68 的提交/换装不变式。

**定义 322（证书 J_TWIN）**
`J_TWIN = (J_FLUID, fidelity_coverage, conformal_q, anchor_count, anchor_coverage, plan_voi_before, plan_voi_after, skeleton_stability_margin, twin_divergence, twin_only_claim_ratio, fallback_margin, twin_ver)`。
Valid ⇔ Valid(J_FLUID) ∧ 局部覆盖率 ≥ 1−α−δ ∧ 锚点来源数 ≥ k ∧ 锚点覆盖 ≥ c_min ∧ 骨架稳定或交互已消解 ∧ 无未认证高风险孪生声明。

**定义 323（两级折叠与严格包含 R69/R68）** 三种边界：
- **排练边界**：𝒯_α 非空、锚点覆盖足够且 `VoI_plan > c` ⇒ 允许孪生排练 + 计划消歧，获得 rehearsal/planning bonus；
- **无孪生边界**：𝒯_α = ∅、锚点不足或 TDR 告警 ⇒ 禁用孪生，逐指令退化 R69（仍可用动作级 VoI 与 FMA）；
- **纯保守边界**：R69 的 VoI ≤ 成本、ECE 越界、slow_fault_suspect 或计划骨架不稳定且无法消解 ⇒ R68 的 λ_floor 保守策略。
因此 R69 是 TWIN-PLAN-RAS 在「孪生不可信/不排练」边界上的退化，R68 是「连交互也不做」边界上的退化。

**定义 324（计划级参与式审计 VQAuditor-P）** 审计对象扩展为：哪些结论是孪生单独声明的、锚点来源与覆盖、计划骨架是否因未锚定的排练而改变、信息运动是否越界、孪生是否被更新以吸收残差、回退是否始终可行。结论回灌 AuditBuf，成为下一轮 FCM 的保真度先验与 RAG 的锚点采样先验。

**定义 325（两级时间尺度与预算）** 慢层以决策周期 T_plan 异步运行：提议计划、孪生 rollout、共形更新、计划 VoI；有硬预算 B_plan，超时即返回当前最优可行计划或回退。快层以控制周期 T_ctrl 执行已认证前缀与回退，继承 R68/R69 的 <2.6ms P99。慢层失败只影响效率，不影响快层安全；计划带有效期 τ_plan，过期触发重规划或回退。

```python
# IP-264 TSP：数字孪生（复用 R67 VISTA + R68 COF，零重复大模型训练）
class DigitalTwin:
    def __init__(self, vista, cof, scenario_memory):
        self.f, self.g, self.c = vista.dynamics, vista.observe, vista.cost
        self.cof, self.mem = cof, scenario_memory

    def rollout(self, plan, N, H):
        return [self.f.simulate(plan, self.g, self.c, H) for _ in range(N)]

    def feature(self, plan):
        return plan.feature()                     # 骨架/接触/区域/新颖度/锚点覆盖

# IP-265/266 PCP+PCV：计划空间提议、稳健代价与计划条件 VoI
def plan_round(belief, twin, fcm, budget):

        p.J = J_hat + fcm.q_alpha(twin.feature(p))       # 稳健上界
    best = min(plans, key=lambda p: p.J)
    stable, margin = skeleton_stability(plans, belief, delta)
    if stable and margin > TAU_MARGIN:
        return best                                      # 计划稳定：不交互
    g = choose_info_action_plan(belief, best, budget)    # 含信息运动
    return best, g

def plan_voi(belief, best, g, twin, fcm):
    v0 = robust_value(belief, twin, fcm)
    v1 = expect_over_answers(belief, g, lambda b_y: robust_value(b_y, twin, fcm))
    return v1 - v0

# IP-267 IMM：信息运动 = 轨迹化的看/问/触
def choose_info_action_plan(belief, best, budget):
    best_g = None
    for g in info_motion_candidates(belief, best):       # 注视/探针/问句/移动观察
        if not budget.allow(g): continue
        if not c_ras_wm.certify_info(g, belief.o): continue
        score = plan_voi(belief, best, g, twin, fcm) - cost(g)
        if best_g is None or score > best_g.score: best_g = (g, score)
    return best_g if best_g and best_g.score > 0 else None

# IP-268/270 FCM+TDR：保真度共形门与孪生发散第二意见
def update_fidelity(fcm, tdr, anchors, residuals):
    fcm.update_conformal(anchors)                        # 分组 + ACI
    D_T, A_T = tdr.divergence(residuals, anchors)
    if D_T > TAU_D or A_T > TAU_A:
        fcm.shrink_trust_region()                        # 先收缩，再查吸收
    return fcm.coverage(), D_T, A_T

# IP-271/272/275 HSC+FRB+主闭环
def TWIN_PLAN_RAS_round(M, obs):

    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)

    # 1) 慢层：同步孪生、更新保真度、计划排练
    cov, D_T, A_T = update_fidelity(M.fcm, M.tdr, M.rag.recent(), M.residuals())

    # 2) 仅在计划骨架不稳定时做真实交互/信息运动

    # 3) 取认证前缀 + 递归回退；慢层超时也只影响效率
    k, lam, fb = M.hsc.certified_prefix(plan, M.fcm.radius)

    A = M.ach.propose(plan.prefix[:k], H=k)
    lambda_floor = M.efs.risk_scale(...)                 # 继承 R68
    lam = max(lam, lambda_floor)
    if slow or D_T > TAU_D:

    # 4) 执行并审计

    return k, lam, plan, fb, (U_ale, U_epi)
```

## 3. 推导

**引理 19（计划条件 VoI 是动作级 VoI 的严格细化）**
(i) 若在可信信念集 B_δ 上最优计划骨架 σ* 与有效约束集都不变，则对任何不改变骨架/约束/回退的 g，`VoI_plan(g)=0`，即使动作模态熵 H_mode 很大。R69 的模态 VoI 此时可能为正，故会过度交互。
(ii) 若两个信念模态诱导不同骨架、稳健代价差为 Δ，且 g 使后验翻转的概率为 p_g，则 `VoI_plan(g) ≥ p_g·Δ − c(g)`。即使动作块在欧氏空间几乎重合（H_mode 很小），只要它们落在不同同伦类，计划 VoI 仍可能很大——这正是 R69 会欠交互的情形。
证明要点：VoI 是「最优可行计划值」的期望改进；可行集与 argmin 不变则值不变。翻转情形下，最优值与次优值之差至少为 Δ，按翻转概率取期望即得下界。系：**该不该问，不取决于动作有多分散，而取决于答案会不会改变计划骨架**。

**引理 20（排练的共形稳健性）** 若锚点 A 与目标计划特征 φ 可交换、且 d_i 有界，则 split conformal 给出
`P(J_M(Π) ≤ J_T(Π) + q_{1−α}(φ)) ≥ 1−α`。
在分布漂移下，ACI 只保证长期覆盖率 ≥ 1−α−δ，不保证逐计划；若 φ 落在锚点支撑之外，则无任何保证。故定义 315 要求**局部覆盖率**与**锚点覆盖**同时满足，而不是只看边际覆盖率。

**引理 21（孪生自证的不可能性 → 锚点必要性）** 若证书只使用孪生内部量，则存在两个现实模型 M 与 M′，它们在孪生可达的所有查询上完全一致，只在孪生不可达的真实查询集上不同；任何仅凭孪生证据的判定器对二者给出相同结论，故不可能同时对二者安全。因此，对任何低于 1 的 false-safe 目标，**独立现实锚点或安全回退是必要的**。这不是工程保守，而是可识别性下界：你不能用被检验对象自己的语言去证明它没有说谎。

**引理 22（孪生吸收的判别模式）** 设慢变漂移被在线孪生更新吸收，则训练残差 D_T 下降；但留出锚点一致性 A_T 不下降，甚至上升。若漂移方向偏离策略/孪生的共享主脊，R69 的 FMA 行为似然 `a_score` 也会升高。故 `(D_T↓, A_T↑)` 与 `(r_res↓, Δa↑, D_T↓)` 是「孪生吸收/相关失效」的判别性联合模式，分别对应模型层与行为层的第二意见。

**定理 18（TWIN-PLAN-RAS 严格包含 R69/R68）** 在 A99–A103（孪生可行计划集包含 R69 的动作模态计划；稳健上界以高概率覆盖真实代价；回退不变式成立）下，对任意状态，TWIN-PLAN-RAS 的期望真实风险 ≤ R69；且当 𝒯_α=∅/锚点不足/TDR 告警时与 R69 逐指令相同，当进一步满足 R69 的纯保守条件时与 R68 逐指令相同。证明：R69 的计划是候选集中的一个可行点，取 min 且用稳健上界不会更差；边界情形按定义 323 直接旁路孪生层，故行为一致。

**定理 19（任意时间安全与两级时间尺度）** 若快层始终执行「已认证前缀 + 递归可行回退」，则无论慢层规划/排练是否超时、返回陈旧计划或返回错误计划，快层的安全不变式都成立；计划切换只在回退可行域内发生，故控制连续、无突变。慢层失败只导致效率降级（回退或 R69/R68），不导致安全降级。证明：快层不依赖慢层的实时性，只依赖计划前缀的认证与回退不变式；定义 321 保证回退递归可行；R68 定理 15 的换装不变式保证切换连续。

## 6. 本轮最大风险

**一句话**：TWIN-PLAN-RAS 的全部收益押在「孪生保真度证书可信」这一前提上——**保真度是用有限、非交换、可能被投毒的现实锚点估计的；一旦锚点稀疏或分布漂移，证书会给出一个局部看起来可信的信任域，规划器就会自信地执行一个只在孪生里安全的计划**——**排练得越逼真，错得越自信**。这是 R68「标定吸收故障」在模型层的镜像，也比 R69「问错」更危险：问错至少还在真实世界里，排练错则把虚幻当成了证据。

**次级风险与缓解**：
1. **陈旧/漂移孪生** → ACI + 留出锚点 + TDR 的 `(D_T↓, A_T↑)` 判据 + 信任域收缩；
2. **孪生投毒/相关失效** → 锚点来源治理 + k 源一致 + ℰ_TWIN 对抗训练 + 独立留出环境；
3. **sim2real 漏洞利用** → 稳健上界 + 锚点覆盖 + 只在孪生里成立的计划压力测试；
4. **规划延迟** → 两级时间尺度 + anytime 截断 + 递归回退；
5. **证书虚假安心** → J_TWIN 强制记录 `twin_only_claim_ratio`，高风险计划必须有独立锚点，否则退回 R69/R68。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** TWIN-PLAN-RAS 组合上述 15 个组件；不变式：实时流零学习写操作；孪生只作证人（高风险计划不得由孪生单独认证）；只执行已认证前缀且存在递归可行回退；保真度不可证/锚点不足/发散告警/VoI≤成本/ECE 越界时逐级退化 R69/R68。

**定义 311（孪生与保真度场）** `T=(f_T,g_T,c_T,Σ_T,ρ_T)`，由 VISTA+COF 复用；ρ_T 随区域/计划/接触模式/时间变化；偏差 `d_T=D(f_T,f_M)`。

**定义 312–313（计划与骨架）** `Π=(σ,π_σ,β_σ,Π_fb)`；骨架 `σ=([γ],κ,ι,φ_fb)`；同骨架当且仅当四者相同；在 B_δ 上 argmin 骨架唯一且不变称骨架稳定，否则处于决策边界。

**定义 314（排练稳健代价）** `J̄(Π)=Ĵ_T(Π)+q_{1−α}(φ(Π))`；分支递归应用，高风险分支不得用低风险分支余量平均。

**定义 315（保真度共形与信任域）** 锚点 `(φ_i,d_i)`，`d_i=J_M−J_T`；分组 conformal + ACI；`𝒯_α={局部覆盖率≥1−α−δ 且 漂移≤τ_d}`；域外无保证；证书须同时报告局部覆盖与锚点覆盖。

**定义 316（现实锚点治理）** 锚点来自真实执行/随机化探针/第三方验证，采集策略不依赖孪生当前偏差预测；`cov(A,φ)` 为邻域内至少 m 个独立锚点的区域占比；高风险要求 `cov≥c_min` 且来源数 ≥k；孪生生成伪锚点不计入。

**定义 317（计划条件 VoI）** `V(b)=min_{Π∈F(b)}J̄(Π;b)`，`VoI_plan(g)=E_{y}[V(b_y)]−V(b)`；仅当 `VoI_plan(g)>c(g)` 且 g 可能改变骨架/约束/回退时交互；骨架稳定且 Δ_σ 足够大时，即使 H_mode 很高也不交互。

**定义 318（信息丰富运动）** `IG(m)=H(Z|b)−E_{y~P(·|b,m)}H(Z|b,y)`；m 与任务动作共享动作空间、C-RAS-WM 认证与预算；R69 的看/问/触是静止特例。

**定义 319（孪生发散分解）** `z=y_M−y_T=e_model+e_shift+e_poison+ε`；`D_T=‖z‖_{Σ_T}` + 变点统计；`A_T` 为留出锚点一致性；`(D_T↓,A_T↑)` ⇒ 孪生吸收，收缩信任域并触发 TDR。

**定义 320（威胁模型）** `ℰ_twin={陈旧,投毒,sim2real 漏洞利用,锚点投毒,孪生-策略相关失效}`。

**定义 321（递归回退）** 任意可达状态存在风险 ≤ε_fb 且递归可行的回退策略；认证前缀长度 k 使最坏保真度偏差下回退仍可行；切换连续，继承 R68 提交/换装不变式。

**定义 322（证书 J_TWIN）** 见符号表；Valid ⇔ Valid(J_FLUID) ∧ 局部覆盖 ≥1−α−δ ∧ 锚点数 ≥k ∧ 锚点覆盖 ≥c_min ∧ 骨架稳定或已消解 ∧ 无未认证高风险孪生声明。

**定义 323（两级折叠）** 排练边界：𝒯_α 非空、锚点足够、`VoI_plan>c`；无孪生边界：𝒯_α=∅/锚点不足/TDR 告警 ⇒ R69；纯保守边界：R69 VoI≤成本/ECE 越界/slow fault/骨架不稳定且不可消解 ⇒ R68。R69、R68 均为严格边界退化。

**定义 324–325（审计与两级时间尺度）** VQAuditor-P 审计孪生单独声明、锚点来源、计划是否因未锚定排练改变、信息运动越界、孪生吸收、回退可行性，回灌 AuditBuf；慢层 10–25Hz/anytime 预算 B_plan，快层继承 <2.6ms P99，慢层失败只降效率不降安全，计划有效期 τ_plan。

## 3. 关键算法伪代码

```python
# IP-264 TSP：孪生（复用 R67 VISTA + R68 COF）
class DigitalTwin:
    def __init__(self, vista, cof): self.f,self.c,self.cof = vista.dynamics,vista.cost,cof
    def rollout(self, plan, N, H):  return [self.f.simulate(plan, H) for _ in range(N)]
    def feature(self, plan):        return plan.feature()   # 骨架/接触/区域/锚点覆盖

# IP-265/266 PCP+PCV：计划提议、稳健代价、骨架稳定性
def plan_round(belief, twin, fcm, budget):
    plans = [p for p in propose_contingency_plans(belief, K_PLAN)
             if fcm.in_trust_region(p)]
    if not plans: return None, None                          # → R69
    for p in plans:
        p.J = mean([twin.cost(r) for r in twin.rollout(p, 32, p.H)]) \
              + fcm.q_alpha(twin.feature(p))
    best = min(plans, key=lambda p: p.J)
    if skeleton_stable(plans, belief, delta): return best, None
    return best, choose_info_action_plan(belief, best, budget)

def plan_voi(belief, g, twin, fcm):
    v0 = robust_value(belief, twin, fcm)
    v1 = expect_over_answers(belief, g, lambda b: robust_value(b, twin, fcm))
    return v1 - v0

# IP-267 IMM：信息运动（含看/问/触/移动观察）
def choose_info_action_plan(belief, best, budget):
    best_g = None
    for g in info_motion_candidates(belief, best):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, belief.o): continue
        score = plan_voi(belief, g, twin, fcm) - cost(g)
        if best_g is None or score > best_g.score: best_g = (g, score)
    return best_g if best_g and best_g.score > 0 else None   # 无利可图 → 不交互

# IP-268/270 FCM+TDR：保真度门与孪生吸收第二意见
def update_fidelity(fcm, tdr, anchors, residuals):
    fcm.update_conformal(anchors)                           # 分组 + ACI
    D_T, A_T = tdr.divergence(residuals, anchors)
    if D_T > TAU_D or A_T > TAU_A: fcm.shrink_trust_region()
    return fcm.coverage(), D_T, A_T

# IP-271/272/275 主闭环：快层继承 R69，慢层排练计划
def TWIN_PLAN_RAS_round(M, obs):
    z,o = M.mtm.forward(...); c,U_cal,thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale,U_epi,modes,_ = M.aud.decompose(M.fmp.sample(o,K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)

    cov,D_T,A_T = update_fidelity(M.fcm,M.tdr,M.rag.recent(),M.residuals())
    twin_ok = cov >= C_MIN and D_T <= TAU_D and A_T <= TAU_A and not slow
    plan,g = plan_round(M.belief(o,modes), M.twin, M.fcm, M.plan_budget) if twin_ok else (None,None)
    if plan is None: return R69_round(M, obs)               # 无孪生边界

    if g is not None and M.budget.allow(g) and M.c_ras_wm.certify_info(g,o):
        ans = M.cia.execute(g)                              # 看/问/触/移动观察
        M.rag.add_anchor(g, ans); M.belief.update(modes, ans)
        plan,g = plan_round(M.belief, M.twin, M.fcm, M.plan_budget)

    k,lam,fb = M.hsc.certified_prefix(plan, M.fcm.radius)
    k = min(k, M.c_ras_wm.certified_prefix(plan.prefix[:k], ..., M.wm_preds))
    lam = max(lam, M.efs.risk_scale(...))
    if slow or D_T > TAU_D:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(plan.prefix[:k], U_cal))  # R68
    M.vqa_p.submit_async(plan,g,cov,D_T,A_T,M.fcm.twin_only_ratio())
    return k, lam, plan, fb, (U_ale,U_epi)
```

## 4. 推导

**引理 19（计划条件 VoI 严格细化动作级 VoI）** 若在 B_δ 上最优骨架与有效约束不变，则任何不改变骨架/约束/回退的 g 满足 `VoI_plan(g)=0`，即使 H_mode 很大（修 R69 过度交互）。若两模态诱导不同骨架、稳健代价差 Δ，g 使后验翻转概率 p_g，则 `VoI_plan(g) ≥ p_g·Δ − c(g)`；动作块几乎重合但跨同伦类时，H_mode 很小而计划 VoI 仍大（修 R69 欠交互）。证明：VoI 是最优可行计划值的期望改进；可行集/argmin 不变则值为 0；翻转时最优-次优差至少 Δ。

**引理 20（排练共形稳健性）** 锚点与计划特征可交换且 d_i 有界时，`P(J_M(Π) ≤ J_T(Π)+q_{1−α}(φ)) ≥ 1−α`。漂移下 ACI 仅保长期覆盖 ≥1−α−δ，不保逐计划；φ 在锚点支撑外则无保证。故证书须同时报告局部覆盖与锚点覆盖。

**引理 21（孪生自证不可能 → 锚点必要）** 只使用孪生内部量时，存在两个现实 M、M′ 在所有孪生可达查询上一致、只在孪生不可达查询上不同；任何孪生-only 判定器对二者同判，故不能同时对二者安全。因此低于 1 的 false-safe 目标必须依赖独立锚点或安全回退——这是可识别性下界，不是工程保守。

**引理 22（孪生吸收判别）** 慢变漂移被在线孪生吸收时 D_T 下降但留出 A_T 上升；若漂移偏离共享主脊，R69 的 FMA 行为似然也升高。故 `(D_T↓,A_T↑)` 与 `(r_res↓,Δa↑,D_T↓)` 分别构成模型层/行为层的判别联合模式。

**定理 18（严格包含 R69/R68）** 在孪生包含 R69 计划、稳健上界高概率覆盖真实代价、回退不变式成立时，任意状态期望真实风险 ≤R69；𝒯_α=∅/锚点不足/TDR 告警时与 R69 逐指令相同；再满足 R69 纯保守条件时与 R68 逐指令相同。证明：R69 计划是候选可行点，取 min + 稳健上界不劣；边界按定义 323 旁路孪生层。

**定理 19（任意时间安全）** 快层只执行已认证前缀 + 递归可行回退，故慢层超时/陈旧/错误返回不破坏安全不变式；切换在回退可行域内发生，控制连续无突变；慢层失败只导致效率降级。证明：快层不依赖慢层实时性；定义 321 保证递归可行；R68 定理 15 保证换装连续。

## 7. 本轮最大风险

**一句话**：TWIN-PLAN-RAS 的全部收益押在「孪生保真度证书可信」这一前提上——**保真度是用有限、非交换、可能被投毒的现实锚点估计的；一旦锚点稀疏或分布漂移，证书会给出一个局部看起来可信的信任域，规划器就会自信地执行一个只在孪生里安全的计划**——**排练得越逼真，错得越自信**。这是 R68「标定吸收故障」在模型层的镜像，也比 R69「问错」更危险：问错至少还在真实世界里，排练错则把虚幻当成了证据。

**次级风险与缓解**：陈旧/漂移孪生（ACI + 留出锚点 + TDR 的 `(D_T↓,A_T↑)` 判据 + 信任域收缩）；孪生投毒/相关失效（锚点来源治理 + k 源一致 + ℰ_TWIN 对抗训练 + 独立留出环境）；sim2real 漏洞利用（稳健上界 + 锚点覆盖 + 漏洞压力测试）；规划延迟（两级时间尺度 + anytime + 递归回退）；证书虚假安心（J_TWIN 强制 `twin_only_claim_ratio`，高风险必须有独立锚点，否则退回 R69/R68）。
