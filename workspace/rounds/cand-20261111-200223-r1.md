# 第 56 轮（承接第 55 轮 v31 语义-接触生存核；灵感循环第 2 轮；本轮灵感：「实时推理」×「数据质量」）

> 第 55 轮把“语义标签”升级为“可执行接触约束”，却默默假设了两件在真实机器人上最昂贵的东西：**证书来得及算**、**标定数据撑得起结论**。本轮把视角从“接触在语义上可信吗”下探到 **“这份可信在控制周期内还成立吗、在证据空间里有支撑吗”**。核心矛盾：**H24（时间支撑缺失）**：生存核、鲁棒性谱、云边重分割都是“越算越准”的离线式对象，而控制是硬截止的；一个 sound 但迟到的证书，等价于一个不 sound 的证书。**H25（证据支撑缺失）**：接触失败是稀有事件，标定集在最需要它的“危险接触格”上恰恰最稀疏；校准良好的置信可以在一个从未被数据覆盖的语义-材质格上给出漂亮却空洞的保证。

## 0. 直觉与动机

**灵感 1（实时推理 → 证书具有“保质期”，不是布尔量）**
直觉：证书不是一个“通过/不通过”的印章，而是一张带签发时间与有效期的票据。用 `t_cert` 时刻的观测算出 `x∈K_in`，若执行时刻 `t_exec` 已晚于 `t_cert+τ_v`，世界（机器人状态与接触几何）已经变了，票据作废。因此 soundness 必须被**时间索引化**：证书只在 `[t_cert, t_cert+τ_v]` 内许可动作。实时推理不是把离线算法“跑快一点”，而是把**新鲜度**变成安全前提。

**灵感 2（实时推理 → anytime 生存核，按截止时间逐级收紧）**
直觉：与其追求一次算准，不如保证**任何时候被打断都给出一个 sound 的内近似**。预计算一个粗糙但可靠的内核 `K_in^0`，在线利用剩余时间不断扩张为 `K_in(τ)`（始终满足 `K_in(τ)⊆K(Σ)`）。给了 5ms 就用 `K_in^0`，给了 50ms 就用更紧的核；**时间只买“不保守”，绝不买“更冒险”**。这就是 anytime 语义护盾：截止即返回，永不超过预算。

**灵感 3（数据质量 → 证据覆盖，而非样本总量）**
直觉：“十万帧训练数据”是虚荣指标。真正决定证书能否签字的是：轨迹实际用到的每个 `(语义标签 l, 材质 m, 接触类型 c)` 格子里，是否有**足够且可迁移的证据**。十万帧可能九万九千帧都是平地行走，而这次任务踩的是湿玻璃边缘。数据质量应定义为**被使用接触格的证据覆盖率** `cov(l,m,c)`，并配一个运行时分布外（OOS）探测器；未覆盖的格要么禁止接触，要么按最坏先验膨胀裕度。

**灵感 4（实时推理 × 数据质量 → 稀有失败下的共形校准困境）**
直觉：要把 `θ_conf` 从拍脑袋阈值升级为分布无关保证，最自然的是共形预测。但共形依赖**可交换性**与**足够的失败样本**来定位分位数；而接触失败恰恰是稀有、延迟、且常未被标注（正-未标注，PU）的事件。于是出现一个尖锐悖论：**你越想用数据校准“危险接触”，危险接触的样本越少**。实时在线自适应又要求失败反馈，而失败反馈常在一次成功之后才姗姗来迟，导致“用未来的事故校准过去的分位数”。这正是把「实时推理」与「数据质量」缝在一起的真问题。

**灵感 5（双支撑证书 → 时间支撑 × 证据支撑）**
直觉：第 55 轮的语义-接触证书 `J_s` 只有“内容维度”，缺“支撑维度”。新证书必须同时携带 `τ_v`（这份结论还能用多久）、`cov_min`（用到的最弱证据格覆盖多少）、`LCB_fail`（失败率的下置信界）。三者在同一次签字里闭合：**时间上没过期、证据上有覆盖、统计上失败率可界**，才算“此刻可部署”。这把“部署”从一次性认证改造成持续性的**支撑维护**。

## 1. 形式化定义（增量：定义 127–133）

**定义 127（证书时效与时间支撑）**
证书 `J` 在 `t_cert` 依据观测 `o(t_cert)` 签发。定义其有效期
`τ_v = sup{Δ ≥ 0 | ∀ 容许扰动 w, x(t_cert+Δ) ∈ K_in(Σ(t_cert+Δ))}`。
`J` 对执行时刻 `t_exec` **时间支撑成立**当且仅当 `t_exec - t_cert ≤ τ_v`。等价地把“sound”改写成二元谓词 `Sound(J,t) = Sound_content(J) ∧ (t-t_cert ≤ τ_v)`。

**定义 128（截止时间索引的内核族）**
存在预计算内近似 `K_in^0 ⊆ K(Σ)` 与在线细化算子 `R`，使
`K_in(τ) = R^{⌊τ/δ⌋}(K_in^0)` 满足单调性 `τ₁≤τ₂ ⇒ K_in(τ₁) ⊆ K_in(τ₂) ⊆ K(Σ)`。
**anytime soundness**：对任意中断时刻，返回的 `K_in(τ)` 都是 `K(Σ)` 的内近似。时间只增加可行域（不保守），不改变包含方向。

**定义 129（anytime 语义护盾）**
在剩余预算 `τ_rem` 下，护盾
`u* = argmin_u ||u-u_nom||²_W s.t. x_{t+1}∈K_in(τ_rem), supp(λ)⊆C^+(Σ), λ∈FC(μ), u∈A_WB`。
若在预算内连 `K_in^0` 上的可行解都未找到，输出 `u_stop` 并返回 `'deadline_safe_brake'`。护盾保证**最坏延迟 ≤ τ_budget**（由 `R` 单步代价上界与迭代次数决定）。

**定义 130（共形接触可行性集）**
对接触命题 `Y(p,c)=1[接触 (p,c) 实际可行]`，取非一致性分数 `s(p,c)`（如 `1-κ̂` 或负裕度）。在标定集 `D_cal` 上取 `q = Quantile_{⌈(n+1)(1-α)⌉/n}({s_i})`，定义
`C_α(Σ) = {(p,c) | s(p,c) ≤ q}`。
在可交换性下 `P(Y=1 | (p,c)∈C_α(Σ)) ≥ 1-α`。分布漂移时用加权共形：以密度比 `w(x)` 加权分位数，覆盖率界退化为 `1-α-TV(P,Q)/2`。

**定义 131（数据支撑覆盖度）**
把标定数据按证据格 `g=(l,m,c)` 分桶，记有效样本量 `n_eff(g)` 与特征空间覆盖半径 `r(g)`。定义
`cov(g) = clip( n_eff(g)/n_req , 0, 1 ) · 1[r(g) ≤ r_max]`，
并对运行时样本 `x_t` 计算 OOS 分数 `oos(x_t)=min_g dist(x_t, support(g))`。**数据支撑成立**当且仅当 `oos(x_t) ≤ r_OOS` 且用到的所有格子 `min_g cov(g) ≥ θ_cov`。

**定义 132（稀有失败的可置信上界）**
接触失败率 `p_f`。在正-未标注设定下，观测到的失败数 `k`、已确认安全数 `n_s`、未标注数 `n_u`，用 PU 修正的 Clopper–Pearson 上界
`LCB_fail = sup{p | P_{PU}(K ≤ k; n_s+n_u, p) ≥ β}`。
要求 `LCB_fail ≤ p_max` 才允许该接触格进入证书；否则该格视为“证据不足以宣称安全”。

**定义 133（双支撑证书）**
`J_ds = (Σ_core, C_α, K_in(τ), τ_v, cov_min, LCB_fail, oos, evidence)`，
其中 `cov_min = min_{g∈used} cov(g)`。**可部署**当且仅当
`K_in(τ)⊆K(Σ)`、`C_α` 共形校验通过、`τ_v ≥ τ_min`、`cov_min ≥ θ_cov`、`oos ≤ r_OOS`、`LCB_fail ≤ p_max`。
注意：**内容正确但支撑失效的证书一律拒签**——“算得出”不等于“此刻算数”。

## 2. 关键算法 伪代码

### IP-127 AVC（Anytime Viability Computation）

```python
def anytime_viability(K0_in, Sigma, deadline, refine_step):
    K = K0_in
    while time_left() > refine_step.cost_ub:      # 硬预算预检
        K_next = refine_step(K, Sigma)            # 单调扩张，保持内近似
        if not is_inner_approx(K_next, Sigma):    # 数值安全阀
            break
        K = K_next
    return AnytimeKernel(K_in=K, used_time=elapsed(), sound=True)
```

### IP-128 CRT（Conformal Real-time Thresholding）

```python
def conformal_contact_threshold(scores_cal, scores_live, alpha, weights=None):
    n = len(scores_cal)
    q = weighted_quantile(scores_cal, min(1.0, ceil((n+1)*(1-alpha))/n),
                          weights=weights)        # 漂移时传密度比
    C_alpha = {(p,c) for (p,c),s in scores_live.items() if s <= q}
    # 在线自适应（ACI）：用延迟到达的失败标签缓慢修正 alpha
    alpha = clip(alpha + gamma_aci * (alpha_target - miscoverage_ema), 1e-4, 0.5)
    return C_alpha, q, alpha

def weighted_quantile(vals, q, weights):
    order = argsort(vals); cw = cumsum(weights[order]) / sum(weights)
    return vals[order][bisect_left(cw, q)]
```

### IP-129 DSS（Deadline-aware Semantic Shield）

```python
def deadline_semantic_shield(u_nom, x, Sigma, C_alpha, budget):
    K = anytime_viability(precomputed_K0, Sigma, budget.tau, R)
    if K.margin_to_empty <= 0:
        return safe_brake(x), 'kernel_empty'
    u = qp_solve(H=W, g=-W@u_nom,
                 constraints=[viability(x,u,K.K_in),
                              contact_support(u, C_alpha),
                              friction_cone(u, mu),
                              joint_limit(u)])
    if u is None:
        return safe_brake(x), 'deadline_safe_brake'
    return u, ('ok' if elapsed() <= budget.tau else 'overrun_brake')
```

### IP-130 DQA（Data Quality Audit）

```python
def data_quality_audit(calib, used_cells, x_t, theta_cov, r_oos):
    cov = {}
    for g in used_cells:
        n_eff = effective_sample_size(calib[g])
        r = cover_radius(calib[g])
        cov[g] = clip(n_eff/n_req, 0, 1) * (r <= r_max)
    cov_min = min(cov.values())
    oos = min(dist_to_support(x_t, calib[g]) for g in used_cells)
    k, n_s, n_u = fail_counts(calib, used_cells)
    lcb = pu_clopper_pearson_upper(k, n_s, n_u, beta)
    if cov_min < theta_cov or oos > r_oos or lcb > p_max:
        return ('reject', dict(cov_min=cov_min, oos=oos, lcb=lcb))
    return ('ok', dict(cov_min=cov_min, oos=oos, lcb=lcb))
```

### IP-131 TSS（Temporal Support Scheduler）

```python
def temporal_support_scheduler(tasks, deadline, risk):
    # 按“风险×临期”优先级分配计算，保证高危险接触先获得细化
    schedule = []
    for task in sorted(tasks, key=lambda t: -(risk[t]*urgency(t, deadline))):
        if time_left() > task.cost_ub:
            schedule.append(task)
    watchdog = deadline - max(t.cost_ub for t in schedule)
    return schedule, Watchdog(expire_at=watchdog, on_expire=safe_brake)
```

### IP-132 DSC（Dual-Support Certificate）

```python
def dual_support_certificate(traj, Sigma, K_anytime, alpha, calib, budgets):
    Sigma_core = core_semantics(traj, Sigma)
    C_alpha = conformal_contact_set(Sigma_core, calib, alpha)
    cov = data_quality_audit(calib, used_cells(traj), traj.x[-1],
                             budgets.theta_cov, budgets.r_oos)
    if cov[0] != 'ok':
        return ('reject', 'data_support_fail', cov[1])
    if budgets.now - K_anytime.t_cert > K_anytime.tau_v:
        return ('reject', 'temporal_support_expired')
    if K_anytime.margin < budgets.theta_K:
        return ('reject', 'kernel_margin_fail', K_anytime.margin)
    return ('ok', DualCert(Sigma_core, C_alpha, K_anytime.K_in,
                           K_anytime.tau_v, cov[1]['cov_min'],
                           cov[1]['lcb'], cov[1]['oos']))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| AVC | O(B/δ·QP)（按预算截断） | O(|K|) | 每次迭代保持内近似、超预算即停 |
| CRT | O(n log n) 标定 + O(|C|) 查询 | O(n) | 可交换性/加权漂移界、ACI 步长有界 |
| DSS | O(单次 QP)，最坏 O(τ_budget) | O(|A_WB|) | 预算内必有解或安全制动 |
| DQA | O(|used|·n_eff) | O(|used|) | 覆盖可测、PU 上界 sound |
| TSS | O(|tasks| log|tasks|) | O(|tasks|) | 风险优先级+看门狗硬截止 |
| DSC | O(|轨迹|·|Ω|) | O(|Ω|) | 六项支撑同时闭合 |

**正确性定理（Dual-Support Real-Time Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** anytime 细化每一步保持 `K_in(τ)⊆K(Σ)` 且单步代价有上界；**(A34)** 执行延迟被看门狗截断在 `τ_v` 内，否则触发安全制动；**(A35)** 标定与部署在证据格上满足加权可交换性，漂移用密度比修正；**(A36)** PU 失败率上界 `LCB_fail` 以置信 `1-β` 成立。
则部署后单步失效概率满足
```
P_fail ≤ P(τ_v expired) + P(oos > r_OOS) + P(cov_min < θ_cov)
       + P(conformal miscoverage) + P(K_in unsound) + P(fallback fails) + β
```
关键：**内容证书 × 时间支撑 × 证据支撑**三者是**合取**，任一项失守都拒签或降级为安全制动；实时性通过“anytime 内近似 + 看门狗”保证，数据质量通过“覆盖度 + PU 上界 + OOS”保证。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| anytime 核在紧截止下塌成空集导致“频繁制动” | 高 | 离线分层内核 `K_in^0` + 保守度预算 + 主动探索恢复 |
| 共形可交换性假设在真实漂移下失效 | 高 | 加权共形 + ACI + OOS 触发切回保守先验 |
| 稀有失败导致PU上界过宽、几乎全拒签 | 高 | 危险格仿真增广 + 力反馈弱标签 + 分层先验 |
| 看门狗与控制器时钟不同步造成误判过期 | 中 | 单调时钟 + 时间戳随状态传播 + 双缓冲 |
| 时间/证据/安全三难下调度抖动 | 中 | 风险优先级 + 迟滞 + 明确降级策略 |

## 6. 本轮最大风险

**一句话**：把实时推理与数据质量引入证书，使“可部署”从一次性的内容正确升级为**时间支撑与证据支撑持续成立**，但其 soundness **同时依赖 anytime 核每一步都保持内近似、共形/加权可交换性在漂移下不被破坏、以及稀有失败的可信上界不过宽**；一旦紧截止把内核压成空集或加权共形在分布外悄悄失去覆盖，系统就会在“票据未过期、统计看似通过”的假象下放行动作——因此必须以 **看门狗硬截断 + OOS 回退保守先验 + PU 增广** 三重护栏，宁可频繁安全制动，绝不把“算得快”和“样本多”当作“此刻安全”。

# 第 56 轮产物 · 创新点清单 v32：RealSupport-GenSim（AVC×CRT×DSS×DQA×TSS×DSC）

> 承接第 55 轮产物 v31 语义-接触生存核。本轮在“语义进约束”之上增加 **时间支撑** 与 **证据支撑** 两大算子族，把证书从“内容正确”升级为“此刻算数”：
> - **AVC（Anytime Viability Computation）**：截止时间索引的内核族，任意中断都返回 sound 内近似；
> - **CRT（Conformal Real-time Thresholding）**：用共形/加权共形替换拍脑袋置信阈值；
> - **DSS（Deadline-aware Semantic Shield）**：在硬预算内求解，超预算即安全制动；
> - **DQA（Data Quality Audit）**：按证据格计算覆盖度、OOS 与稀有失败 PU 上界；
> - **TSS（Temporal Support Scheduler）**：风险优先调度 + 新鲜度看门狗；
> - **DSC（Dual-Support Certificate）**：时间支撑 × 证据支撑 × 内容正确三者合取。
>
> IP 编号：IP-127~IP-132（共 6 个新增），升级 IP-121/122/124 以纳入时效与证据支撑。

## 1. 符号体系增量（新增定义 127–133）

| 符号 | 含义 |
|---|---|
| `τ_v` | 证书有效期（state/scene drift 下仍保持可行的最大 Δ） |
| `K_in(τ)` | 截止 τ 下的内近似内核，`τ₁≤τ₂ ⇒ K_in(τ₁)⊆K_in(τ₂)⊆K(Σ)` |
| `K_in^0` | 离线预计算的 sound 粗糙内核 |
| `C_α(Σ)` | 共形接触可行性集（覆盖率 ≥ 1-α） |
| `q` | 共形非一致性分位数 |
| `w(x)` | 漂移修正密度比（加权共形） |
| `g=(l,m,c)` | 证据格：语义标签×材质×接触类型 |
| `cov(g)` | 证据覆盖度 `[0,1]`，由 `n_eff` 与覆盖半径决定 |
| `oos(x)` | 运行时分布外分数 |
| `LCB_fail` | 稀有失败率的 PU 置信上界 |

## 2. 关键算法 伪代码

### IP-127 AVC

```python
def anytime_viability(K0_in, Sigma, deadline, refine_step):
    K = K0_in
    while time_left() > refine_step.cost_ub:
        K_next = refine_step(K, Sigma)
        if not is_inner_approx(K_next, Sigma):
            break
        K = K_next
    return AnytimeKernel(K_in=K, used_time=elapsed(), sound=True)
```

### IP-128 CRT

```python
def conformal_contact_threshold(scores_cal, scores_live, alpha, weights=None):
    n = len(scores_cal)
    q = weighted_quantile(scores_cal, min(1.0, ceil((n+1)*(1-alpha))/n),
                          weights=weights)
    C_alpha = {(p,c) for (p,c),s in scores_live.items() if s <= q}
    alpha = clip(alpha + gamma_aci * (alpha_target - miscoverage_ema), 1e-4, 0.5)
    return C_alpha, q, alpha

def weighted_quantile(vals, q, weights):
    order = argsort(vals); cw = cumsum(weights[order]) / sum(weights)
    return vals[order][bisect_left(cw, q)]
```

### IP-129 DSS

```python
def deadline_semantic_shield(u_nom, x, Sigma, C_alpha, budget):
    K = anytime_viability(precomputed_K0, Sigma, budget.tau, R)
    if K.margin_to_empty <= 0:
        return safe_brake(x), 'kernel_empty'
    u = qp_solve(H=W, g=-W@u_nom,
                 constraints=[viability(x,u,K.K_in),
                              contact_support(u, C_alpha),
                              friction_cone(u, mu),
                              joint_limit(u)])
    if u is None:
        return safe_brake(x), 'deadline_safe_brake'
    return u, ('ok' if elapsed() <= budget.tau else 'overrun_brake')
```

### IP-130 DQA

```python
def data_quality_audit(calib, used_cells, x_t, theta_cov, r_oos):
    cov = {}
    for g in used_cells:
        n_eff = effective_sample_size(calib[g])
        r = cover_radius(calib[g])
        cov[g] = clip(n_eff/n_req, 0, 1) * (r <= r_max)
    cov_min = min(cov.values())
    oos = min(dist_to_support(x_t, calib[g]) for g in used_cells)
    k, n_s, n_u = fail_counts(calib, used_cells)
    lcb = pu_clopper_pearson_upper(k, n_s, n_u, beta)
    if cov_min < theta_cov or oos > r_oos or lcb > p_max:
        return ('reject', dict(cov_min=cov_min, oos=oos, lcb=lcb))
    return ('ok', dict(cov_min=cov_min, oos=oos, lcb=lcb))
```

### IP-131 TSS

```python
def temporal_support_scheduler(tasks, deadline, risk):
    schedule = []
    for task in sorted(tasks, key=lambda t: -(risk[t]*urgency(t, deadline))):
        if time_left() > task.cost_ub:
            schedule.append(task)
    watchdog = deadline - max(t.cost_ub for t in schedule)
    return schedule, Watchdog(expire_at=watchdog, on_expire=safe_brake)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AVC | O(B/δ·QP)，按预算截断 | O(|K|) | 每步内近似、超预算即停 |
| CRT | O(n log n)+O(|C|) | O(n) | 可交换/加权漂移界、ACI 步长有界 |
| DSS | O(QP)，最坏 O(τ_budget) | O(|A_WB|) | 预算内必有解或安全制动 |
| DQA | O(|used|·n_eff) | O(|used|) | 覆盖可测、PU 上界 sound |
| TSS | O(|tasks| log|tasks|) | O(|tasks|) | 风险优先级 + 看门狗硬截止 |
| DSC | O(|轨迹|·|Ω|) | O(|Ω|) | 六项支撑同时闭合 |

**正确性定理（Dual-Support Real-Time Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** AVC 每步保持 `K_in(τ)⊆K(Σ)` 且单步代价有上界；**(A34)** 看门狗把执行延迟截断在 `τ_v` 内；**(A35)** 标定与部署在证据格上满足加权可交换性；**(A36)** `LCB_fail` 以置信 `1-β` 成立。
则单步失效概率
```
P_fail ≤ P(τ_v expired) + P(oos > r_OOS) + P(cov_min < θ_cov)
       + P(conformal miscoverage) + P(K_in unsound) + P(fallback fails) + β
```
关键：**内容正确、时间支撑、证据支撑三者合取**；实时性由 anytime 内近似 + 看门狗保证，数据质量由覆盖度 + PU 上界 + OOS 保证，任一失守即拒签或降级。

**一句话**：RealSupport-GenSim 把“可部署”升级为内容、时间、证据三重支撑的持续维护，但其 soundness **同时依赖 anytime 核每步都保持内近似、加权共形在漂移下不丢覆盖、以及稀有失败的 PU 上界不过宽**；一旦紧截止把内核压空或分布外共形悄悄失效，系统就会在“票据未过期、样本看似充足”的双重假象下放行动作——故必须以 **看门狗硬截断 + OOS 回退保守先验 + 危险格仿真/力反馈增广** 三重护栏，宁可频繁制动，绝不把“算得快、样本多”当作“此刻已证实安全”。
