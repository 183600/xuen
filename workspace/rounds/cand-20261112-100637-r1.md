# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「轻量化设计」×「结构优化」）

> 第 57 轮把安全的赌注从"模型置信"一路换到"少样本可校准、跨模态可对账、个性化有界的证据承诺"，纵深五层；但它的自陈也暴露了一个未被正面处理的问题：**这套论证越来越重，而且它的冗余是"名义冗余"而非"结构冗余"**——五层证据门、元推断、模态分账、信任状态机在四足的能耗/时延/算力预算里未必跑得动；更糟的是，多层独立检查若共享同一个观测或同一个物理诱因，它们只是把同一根杆件数了五遍，质量上去了、刚度没上去。本轮两个灵感各给一把刀：**轻量化设计**要求建立四本质量账（能量/时延/算力/人因），用"多功能证据"把一次观测的结构作用榨干、且绝不重复计可靠性；**结构优化**要求把安全论证看成可靠性网络，在健全性、有效冗余、可审计性约束下做拓扑与形状协同优化，并像结构工程检查屈曲那样检查"共因失稳"。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"结构上必要、质量上最省、且对共因缺陷不敏感的证据说可信"**。

核心矛盾：
- **H29（轻量化 vs 健全性）**：删冗余最省质量，但最小质量解天然趋向单荷载路径；轻结构不按比例退化，而是"屈曲"式突失——一个共因（欺骗性材质/传感器雾/操作者疲劳）可同时击穿多个名义独立的证据节点，而每一层的边际概率看起来都很安全。
- **H30（优化 vs 可审计）**：拓扑优化的解常常反直觉、不规则；但审计本身是承重构件——监管者看不懂的证书等于没有证书；若把"可审计性"当免费材料，优化器会悄悄把荷载卸到人类审计这条最弱的杆上。
- **H31（质量预算 vs 人因与博弈）**：轻量化的常见捷径是把验证负担转嫁给人类（便宜传感器→更多人工确认），这会压垮疲劳操作者；而个性化授权又可能被用来"合法卸载"检查以换速度——质量账若不含人因、卸载若可被授权放大，轻量化就成了绕过证据的后门。

## 0. 直觉与动机

**灵感 1（轻量化设计 → 四本质量账 + 多功能证据，拒绝重复计可靠性）**
直觉：减重不是把每根杆都削细，而是先问"这根杆到底承不承重"。本体系里，一次轻触同时更新后验（EV-probe）、给出裕度（EV-margin）、还能与视觉对账（EV-xmodal）——这是航空式的"功能集成"，不是三个独立证据。于是质量账要分四本：能量、时延、算力、人因注意力；而可靠性账必须做**相关折减**：同一观测派生的多个证据角色，其失效事件相关系数为 1，串联起来只等于其中最强者，不能把标签数当证据数。这一条同时把第 57 轮 H27"把同一个问题问五遍"变成了可计算的质量浪费。

**灵感 2（结构优化 → 证据拓扑优化 + 认证剪枝）**
直觉：安全论证是一棵故障树/可靠性网络，证据门是串并联构件；给定每个区域的"风险需求"与许用失效预算 δ，问的是"最小质量、仍满足 δ 的构件布局"。做法不是凭经验删检查，而是**认证剪枝**：只有当删除某成员后的 P_fail 上界仍 ≤ δ、且有效冗余仍 ≥ r_min 时，才允许剪；剪枝留证明日志。形状变量（探针数 k、阈值 θ、L2 超时 τ_int、佐证数）与拓扑变量一起优化——减重既可能来自"少一根杆"，也可能来自"把杆放对位置"。

**灵感 3（结构屈曲 → 共因敏感性与有效冗余 r_eff）**
直觉：轻结构的失效模式是屈曲，不是屈服；它由**缺陷敏感性**主导。对应到证据结构：真正危险的不是某个证据弱，而是一个物理诱因能同时让视觉与触探一起说谎。于是定义共因族 Γ、屈曲指标 β_b（某个共因发生后是否跨过 δ）与有效冗余 r_eff（能承受多少个"可由共因生成"的同时失效仍安全）。β_b<0 或 r_eff<r_min 时，不允许继续减重：先加一条与风险模态条件独立的最低价并联成员，或改形降需求，或拒绝承诺。共因模型未覆盖的部分一律按 r_eff=0 处理——不认识的缺陷不计入强度。

**灵感 4（形随力走 → 形-证协同：把任务改到"不需要那么强的证明"）**
直觉：与其加强构件，不如改变几何让应力下降。系统可以在轨迹/步态/接触级层面改形：绕开高风险区、选更缓的落脚序列、优先用 L0 越过或 L1 非不可逆接触。风险需求 L_r(π) 随 π 下降，所需证书质量随之下降——**轻量化的最大来源可能不是删证据，而是把任务改简单**。约束是单向的：FEC 只准降低需求或认证剪枝，绝不准放宽 δ、绝不准为了省质量提高接触级。

**灵感 5（分级卸载 → 先降任务野心，再降证据；最后一条荷载路径永不可卸）**
直觉：载荷超限时，正确做法是"卸载"而非"让某根杆超应力"。资源紧张（电量/算力/时延/人因）时按固定偏序卸载：去重与去装饰 → 加宽后验/收紧阈值 → 降步态/绕行/降接触级 → 请求人类佐证（仅当人因账有余量）→ L2 协商/安全停。不可卸载集包括不可逆接触必要证据、最后荷载路径、OOD 共形带与 EV-xmodal 禁令。卸载只可能让动作更保守，因此保持第 57 轮的交互单调性。

**灵感 6（合流 → 轻量证书 J_w：把"安全"和"省"写在同一张账上）**
直觉：轻量化不是一次性的离线优化，而是随部署持续记账。证书 J_w 把拓扑、质量账、有效冗余、共因覆盖、剪枝证明与卸载日志钉在一起，继承 J_p；云边协议再进一步——云端下发的不是"更强的模型"，而是"更轻且不更弱的证据结构"，且同样要过影子隔离与回归测试。击穿安全从"元先验错 ∧ OOD 漏检 ∧ 无一致 ∧ 无裕度 ∧ 人错"再叠一层：还要"认证剪枝界错 ∧ 共因未覆盖 ∧ 卸载越界"。纵深没有变薄，变的是每一层都开始为质量负责。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（证据荷载结构与质量账 ELS）** 区域 r 的安全论证建模为单调可靠性网络 S_r=(V_r,E_r,x_r;φ_r)，x_e∈{0,1} 为成员选择，φ_r 为失效树布尔函数。每个成员 e 携带成本向量 c_e=(c_e^E,c_e^T,c_e^C,c_e^H)（能量/时延/算力/人因注意力）与标量质量 m_e=w·c_e；角色集 roles(e)⊆{probe,visit,margin,xmodal,human,meta,ood}，多角色必须共享同一观测 o_e。风险需求 L_r=(p_r^unsafe,sev_r,1[irreversible])，许用失效预算 δ(L_r) 对不可逆接触更紧。**相关折减规则**：若 e,e′ 由同一观测派生，则其失效事件相关 ρ_corr=1，串联可靠度取 max 而非相加，n_eff=|∪roles|−Σ折减；质量仍按成员实付。全局质量账四本分账，满足 Σ_r M(S_r)≤M_tot，且 M_human 计入操作者注意力预算。

**定义 140（可靠性拓扑优化 RBTO）** 在需求 {L_r} 与预算下求
min_{x,θ} Σ_r M(S_r) s.t. ∀r P_fail(x_r,θ_r;L_r)≤δ(L_r)，r_eff(S_r)≥r_min(L_r)，连接性（每个不可逆接触存在通往安全屏障的荷载路径），x_r∈𝓣_audit（可审计拓扑族），N−k 鲁棒。
拓扑用密度松弛 ρ_e∈[0,1] 与离散惩罚 p(ρ) 求解；P_fail 用一阶可靠度 FORM/SORM 加置信上界，或分层蒙特卡洛上界。**认证剪枝**：仅当 P_fail(S\{e})^UB≤δ 且 r_eff(S\{e})≥r_min 时删除 e，并写证明日志；形状变量 θ={k_probes,θ_voi,θ_D,τ_int,corrob} 与 x 联合更新。

**定义 141（缺陷敏感性与屈曲指标 ISI）** 共因族 Γ={γ}，每个 γ 有同时失效集 F(γ)⊆V 与发生概率 p_γ，覆盖声明域的比例 ≥1−δ_cc。共因后失效概率 P_fail^γ(S)=P_fail(S;F(γ))；屈曲裕度 b_γ=δ−P_fail^γ(S)；屈曲指标 β_b(S)=min_{γ:p_γ≥p_min} b_γ。有效冗余 r_eff(S)=max{k: 对任意可由 Γ 生成的同时失效集 A 且 |A|≤k，均有 P_fail(S;A)≤δ}（以最小割/蒙特卡洛上界计算）。判据：β_b<0 或 r_eff<r_min(L_r) 或覆盖率不足 ⇒ 存在屈曲模态/不可信，必须"加一条与风险模态条件独立的并联成员 ∨ 改形降需求 ∨ 拒绝承诺"，三者按质量从小到大尝试。未声明共因一律视为 r_eff=0。

**定义 142（形-证协同优化 FEC）** 决策 (π,x)，π∈Π_safe(task) 为轨迹/步态/接触级；需求 L_r(π) 对 π 单调（更缓/更远/更低接触级 ⇒ 不增）。求
min_{π,x} Σ_r M(S_r)+λ·J(π) s.t. P_fail(x_r;L_r(π))≤δ(L_r(π))，π 满足任务可达。
安全单向性：FEC 只允许 (a) 以降低 demand 的方式改 π，或 (b) 认证剪枝 x；禁止放宽 δ、禁止修改决策规则本体、禁止以升高接触级换取更轻证书。接触级视作"材料等级"：L0 越过 ≻ L1 非不可逆 ≻ L2 不可逆，优先使用低荷载路径。

**定义 143（轻量证书 J_w 与运行时质量账）** J_w=(topology,M_plan,M_actual,r_eff,Γ_coverage,β_b,prune_proof_log,multi_role_map,demand_profile,shed_log)，继承 J_p 全检。运行时每节拍更新四本账（能量/时延/算力/人因），任一超支即触发 GSL；J_w 与 J_p 联签，缺一不可承诺。

**定义 144（分级卸载 GSL 与算子 PCE-L）** 卸载偏序 σ_shed：
① 去重去装饰（相关重复、多角色冗余，须证明不进入必要证据集）；
② 加宽后验/收紧阈值（更保守，代价最低）；
③ 降步态/绕行/降接触级（走 FEC）；
④ 请求人类佐证（仅当 M_human 有余量且 auth 允许；不得把质量转嫁给疲劳操作者）；
⑤ L2 协商/安全停。
不可卸载集 N_shed={不可逆接触必要证据，最后一条荷载路径，OOD 共形带，EV-xmodal 仅限 L1 禁令}。PCE-L 在 PCE+ 的每检查点前插入质量账检查；资源不足时先降任务野心（①②③），再动人因（④），最后停（⑤），**永不通过卸载证据来省质量**。所有卸载步骤只使动作更保守。

## 2. 关键算法伪代码（完整版见产物区）

```python
def safe_prune(S, delta, r_min, Gamma):            # IP-140 认证剪枝
    for e in sorted(S.active(), key=lambda z: -z.mass):
        T = S.without(e)
        if not feasible_connectivity(T): continue
        if pf_upper(T) <= delta and eff_redundancy(T, Gamma) >= r_min:
            S = T; log.certified_prune(e, pf_upper(T), eff_redundancy(T, Gamma))
    return S

def buckling_index(S, Gamma, delta, delta_cc):     # IP-141 共因/屈曲
    if Gamma.coverage < 1 - delta_cc: return -inf   # 未覆盖=不可信
    return min(delta - P_fail(S, fail_set=g.F) for g in Gamma.declared())

def form_evidence_codesign(S, r):                  # IP-142 只降需求
    for pi in ordered_by_demand(Plans[r]):         # L0 > L1 > L2
        if demand(pi) < demand(S.pi) and sound_with(S, pi):
            return S.with_plan(pi)
    return None

def greedy_shed(S, budget, persona):               # IP-144 先降任务后降证据
    for stage in ('dedup', 'widen', 'reroute', 'human', 'stop'):
        if within_budget(S, budget): return S
        S = shed(S, stage, persona, protected=N_SHED)
    return safe_stop(S)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ELS | O(\|V\|+\|roles\|)/区域 | O(\|V\|) | 相关折减诚实、四本账不漏人因 |
| RBTO | O(I·(\|V\|log\|V\|+C_pf)) | O(\|V\|²) | 认证剪枝、P_fail 上界、离散惩罚 |
| ISI | O(\|Γ\|·C_pf) | O(\|Γ\|·\|V\|) | 共因覆盖 ≥1−δ_cc、r_eff 下界 |
| FEC | O(\|Π_r\|·C_pf) | O(\|Π\|) | 只降 demand、不放宽 δ |
| J_w | O(\|V\|) | O(\|V\|) | 继承 J_p、与 J_p 联签 |
| GSL | O(5·\|V\|) | O(\|V\|) | 偏序、N_shed 不可越、终止保守 |

**正确性定理（Structurally Sound Lightweight Soundness, SLS）**：在 A33–A40 之上加 **(A41)** 质量账与多角色相关折减诚实（同一观测不重复计可靠性）；**(A42)** 可靠性网络单调、P_fail 上界与认证剪枝界有效（低估概率 ≤δ_prune）；**(A43)** 共因族覆盖声明域比例 ≥1−δ_cc，r_eff 与 β_b 计算为保守上/下界；**(A44)** FEC 只降需求且不放宽 δ，GSL 遵守偏序与 N_shed 且终止于安全态。则：
(i) **健全性保持**：P_fail(S_opt)≤δ+δ_prune+δ_bound；
(ii) **质量单调性**：M(S_opt)≤M(S_0)，认证剪枝与 FEC 均不增质量；
(iii) **缺陷鲁棒性**：若 β_b≥0 且覆盖率≥1−δ_cc，则任意声明的单一共因发生后 P_fail≤δ，且 r_eff≥r_min；
(iv) **形-证单调性**：FEC 只经"需求下降"或"动作更保守"影响系统，不存在升险路径；
(v) **卸载终止性**：PCE-L 在 ≤5 步内到达 {承诺, 绕行, L2 协商, 安全停}，且 N_shed 从未被卸载。
(iii) 与 (iv) 合起来给出**轻而不弱**的核心保证：减掉的质量必须来自"相关冗余"或"更低的荷载需求"，而不是来自"更少的真实强度"。

## 6. 本轮最大风险

**一句话**：轻量化把安全论证变成"细长结构"——最小质量解天然趋向单荷载路径与未被建模的共用原因，一旦某类欺骗性材质、传感器雾或操作者疲劳同时击穿多个看似独立的证据节点，论证会像屈曲一样从"安全"瞬间跳到"失效"，而四本质量账和共形带都不会报警；必须以共因覆盖、r_eff 下界、认证剪枝界与"先减任务后减证据"的分级卸载四重约束兜底，宁可多背一点质量，也绝不采信未被共因模型覆盖的最小结构。

## 2. 关键算法伪代码

### IP-139 ELS（质量账 + 多功能证据 + 相关折减）

```python
def mass_ledger(S):
    led = {k: sum(getattr(e, k) for e in S.active()) for k in ('cE','cT','cC','cH')}
    # 同一观测派生多角色：质量按成员实付，可靠性只按一次观测计
    for group in S.same_observation_groups():
        assert all(corr(e, e2) == 1.0 for e in group for e2 in group)
    return led

def rel_capacity(S):
    # 串联 AND：q ≈ 1 - Π(1-q_e)；同观测组先合并为最强者，再参与串联
    members = S.merge_same_observation(S.active())
    return 1.0 - prod(1.0 - e.q for e in members)

def multi_role_value(e):
    # 功能集成收益：一次观测承担多个角色，但只按观测计一次证据
    return max(e.q_by_role.values())          # 不是 sum
```

### IP-140 RBTO（认证剪枝 + 拓扑/形状优化）

```python
def pf_upper(S):
    return min(form_upper(S), sorm_upper(S), mc_upper(S, conf=0.99))  # 保守上界

def feasible_connectivity(S):
    return all(reaches_barrier(S, c) for c in S.irreversible_contacts())

def safe_prune(S, delta, r_min, Gamma):
    for e in sorted(S.active(), key=lambda z: -z.mass):   # 先剪最重的
        T = S.without(e)
        if not feasible_connectivity(T):            continue
        if pf_upper(T) <= delta and eff_redundancy(T, Gamma) >= r_min:
            log.certified_prune(e, pf_upper(T), eff_redundancy(T, Gamma))
            S = T
    return S

def shape_opt(S, theta, delta):
    # 形状变量：k_probes/θ_voi/θ_D/τ_int/corrob；只在不增 P_fail 的方向移动
    return coordinate_descent(S, theta,
        step_ok=lambda t2: pf_upper(S.with_theta(t2)) <= pf_upper(S))
```

### IP-141 ISI（共因 / 屈曲 / 有效冗余）

```python
def P_fail_given(S, fail_set):
    T = S.with_failed(fail_set)          # 共因同时失效后的条件网络
    return P_fail(T)

def buckling_index(S, Gamma, delta, delta_cc):
    if Gamma.coverage < 1.0 - delta_cc:
        return -inf                       # 未覆盖的缺陷 = 不可信 = 视为屈曲
    return min(delta - P_fail_given(S, g.F)
               for g in Gamma.declared() if g.p >= p_min)

def eff_redundancy(S, Gamma, delta):
    k = 0
    for A in Gamma.admissible_simultaneous_failure_sets():
        if P_fail_given(S, A) > delta: return k
        k = max(k, len(A))
    return k                              # 保守：按可生成集合的最小跨越计算

def harden_or_reshape_or_refuse(S, r, Gamma, delta):
    if buckling_index(S, Gamma, delta, delta_cc) < 0 or \
       eff_redundancy(S, Gamma, delta) < r_min(L(r)):
        T = add_cheapest_independent_member(S, Gamma)   # ① 加最便宜的独立杆
        if T and mass(T) - mass(S) <= budget.slack: return T
        T = form_evidence_codesign(S, r)                # ② 改形降需求
        if T is not None: return T
        return None                                     # ③ 拒绝承诺
    return S
```

### IP-142 FEC（形-证协同，只降 demand）

```python
def contact_rank(pi):
    return {'L0': 0, 'L1': 1, 'L2': 2}[contact_level(pi)]

def form_evidence_codesign(S, r):
    base = contact_rank(S.pi)
    for pi in ordered_by_demand(Plans[r]):
        if contact_rank(pi) > base:                 continue   # 只降不升接触级
        if demand(pi) >= demand(S.pi):              continue   # 只降需求
        if sound_with(S, pi):                                  # 同一 δ 下仍健全
            return S.with_plan(pi)
    return None
```

### IP-143 LWC（轻量证书，与 J_p 联签）

```python
def lightweight_certificate(S, L, Gamma, log):
    led = mass_ledger(S)
    if any(led[k] > budget[k] for k in led):        return ('reject', 'mass_overrun')
    if min(x.K_margin for x in S.sched) < theta_K:  return ('reject', 'K_margin')
    if buckling_index(S, Gamma, delta, delta_cc) < 0: return ('reject', 'buckling')
    if eff_redundancy(S, Gamma, delta) < r_min(L):  return ('reject', 'redundancy')
    if not log.all_prunes_certified():              return ('reject', 'uncertified_prune')
    Jw = dict(topology=S.x, M=led, r_eff=eff_redundancy(S, Gamma, delta),
              gamma_cov=Gamma.coverage, beta_b=buckling_index(S, Gamma, delta, delta_cc),
              prune_log=log, roles=S.role_map(), demand=L, plan=S.pi)
    return ('ok', Jw)                               # 必须与 J_p 同时有效
```

### IP-144 GSL（分级卸载 / PCE-L）

```python
SHED_ORDER = ('dedup', 'widen', 'reroute', 'human', 'stop')
N_SHED = {'irreversible_required_evidence', 'last_load_path',
          'ood_conformal_belt', 'xmodal_L1_ban'}

def within_budget(S, budget):
    led = mass_ledger(S)
    return all(led[k] <= budget[k] for k in led)

def shed(S, stage, persona, protected):
    if stage == 'dedup':   return drop_correlated_duplicates(S, prove_not_in(protected))
    if stage == 'widen':   return widen_posterior(S)                # 更保守
    if stage == 'reroute': return form_evidence_codesign(S, S.region) or S
    if stage == 'human':   return request_corroboration(S, persona) \
                                  if persona.cal >= theta_cal and persona.vig >= theta_vig else S
    if stage == 'stop':    return S.to_safe_stop()

def probe_commit_evolve_light(x0, M, task, budget, consent, personas, Gamma):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        S = build_evidence_structure(cp, M)
        S = safe_prune(S, delta(cp), r_min(cp), Gamma)          # 先轻
        S = harden_or_reshape_or_refuse(S, cp, Gamma, delta(cp))
        if S is None: return negotiate_or_stop(cp, M, ..., consent)
        while not within_budget(S, budget):                     # 超预算→卸载
            S = greedy_shed(S, budget, personas.active, N_SHED)
            if S.is_safe_stop(): return S
        # 以下完全继承 PCE+（元推断→对账→承诺/探询→绕行→协商）
        S = pce_plus_step(S, cp, M, budget, consent, personas)
    return S.sched, S.log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ELS | O(\|V\|+\|roles\|)/区域 | O(\|V\|) | 相关折减诚实、四本账不漏人因（A41） |
| RBTO | O(I·(\|V\|log\|V\|+C_pf)) | O(\|V\|²) | 认证剪枝、P_fail 上界（A42） |
| ISI | O(\|Γ\|·C_pf) | O(\|Γ\|·\|V\|) | 共因覆盖 ≥1−δ_cc、r_eff 保守（A43） |
| FEC | O(\|Π_r\|·C_pf) | O(\|Π\|) | 只降 demand、不放宽 δ（A44） |
| LWC | O(\|V\|) | O(\|V\|) | 与 J_p 联签、缺一不承诺 |
| GSL | O(5·\|V\|) | O(\|V\|) | 偏序、N_shed 不可越、终止安全态（A44） |
| PCE-L | PCE+ 加 O(\|CP\|·(\|V\|log\|V\|+\|Γ\|·C_pf)) | O(\|V\|²+σ) | 每检查点剪枝有证明、卸载有界 |

**正确性定理（Structurally Sound Lightweight Soundness, SLS）**
假设 A22–A32、A33–A40 成立；**(A41)** 质量账与多角色相关折减诚实；**(A42)** 可靠性网络单调，P_fail 上界与认证剪枝界有效（低估概率 ≤δ_prune）；**(A43)** 共因族覆盖声明域 ≥1−δ_cc，β_b 与 r_eff 为保守界；**(A44)** FEC 只降需求、GSL 遵守偏序与 N_shed。则：

1. **健全性保持**：`P_fail(S_opt) ≤ δ + δ_prune + δ_bound`；认证剪枝不引入未计入的荷载路径。
2. **质量单调性**：`M(S_opt) ≤ M(S_0)`；任何被删成员必须来自"相关冗余"或"需求下降"，而非真实强度下降。
3. **缺陷鲁棒性**：若 `β_b≥0` 且 `coverage≥1−δ_cc`，则任意声明单一共因后 `P_fail≤δ` 且 `r_eff≥r_min`；未覆盖缺陷按 `r_eff=0` 处理，退回单路径保守规则（不承诺或加独立杆）。
4. **形-证单调性**：FEC 仅经"需求下降"或"动作更保守"影响系统；不存在升险路径（接触级只降不升）。
5. **卸载终止性**：PCE-L 在 ≤5 个卸载阶段内到达 {承诺, 绕行, L2 协商, 安全停}，且 N_shed 从未被卸载；超预算时先减任务野心、后减人因、最后停。
6. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_prune + δ_cc + δ_bound)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**轻量化只允许在"相关性"与"需求"上做减法，绝不在"真实强度"上做减法**；共因模型的可信度决定轻量化的上限——不认识的缺陷不计入强度，但会强制系统退回最保守的单路径规则。

## 6. 本轮最大风险

**一句话**：轻量化把安全论证变成"细长结构"——最小质量解天然趋向单荷载路径与未被建模的共用原因，一旦某类欺骗性材质、传感器雾或操作者疲劳同时击穿多个看似独立的证据节点，论证会像屈曲一样从"安全"瞬间跳到"失效"，而四本质量账和共形带都不会报警；必须以共因覆盖、r_eff 下界、认证剪枝界与"先减任务后减证据"的分级卸载四重约束兜底，宁可多背一点质量，也绝不采信未被共因模型覆盖的最小结构。
