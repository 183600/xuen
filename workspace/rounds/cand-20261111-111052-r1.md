# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「Gazebo」×「实时性」）

> 第 54 轮把技能组合提升为「动作空间 + 鲁棒性」双证书，并让云端规划、边端校验、反向解释构成闭环。但该体系有一个被默认忽略的维度：**时间**。本轮以 Gazebo（自带 `/clock`、物理步长与 RTF 的开源机器人仿真器）为“时钟暴露器”，把实时性提升为一等公民。核心矛盾：H22：前 54 轮所有证书都是“无时态”的——它们默认验证与执行不占工期，然而迟到的证书与超期的技能在实时边端等价于不存在；H23：Gazebo 的仿真时间与墙钟解耦（RTF≠1），仿真里“按时完成”的动作在真实硬件上可能系统性错过 deadline，形成隐藏的 sim-to-real 时间偏置。

## 0. 直觉与动机

**灵感 1（Gazebo 不是又一个仿真器，而是一个“拥有时钟的 oracle”）**
直觉：Gazebo 暴露 `/clock`、`use_sim_time`、physics step、RTF、传感器采样周期这些时间原语。第 54 轮的 `α_S`、`ρ`、`Explain` 都能在 Gazebo 里测，但“在什么时间尺度下测”从未被记录。于是让每份证据都附带 **采集时的实时因子域**：只有当部署时的 RTF 落在标定域内，证据才可信。Gazebo 因此从“验证工具”升级为“时间保真度标尺”。

**灵感 2（实时性不是事后约束，而是与动作、鲁棒性并列的第三维剖面）**
直觉：一个技能可以动作可达（`α_S` 高）、鲁棒（`ρ` 高），却 **时间不可行**（WCET 超过 deadline）。因此给每个技能增加 **时间剖面 `β_S(τ)=P(t_exec≤τ)`** 与 `(W_S, J_S)`（WCET / Jitter），正如第 54 轮给技能加动作剖面。动作-鲁棒-时间构成技能的“三重占用”，证书必须同时在三者上 sound。

**灵感 3（可调度性进入组合图 → SCOM 增加响应时间边约束）**
直觉：第 54 轮 SCOM 只筛 `compat≥θ_a ∧ c_trans≤τ_e ∧ ρ≥ρ_min`。本轮再加一条硬约束：整条路径的端到端响应时间 `R(P)=ΣW_i+Σc_trans+overhead` 必须满足 `R(P)≤D-Θ_s`。这把经典实时调度中的响应时间分析（RTA）搬进技能组合图，使“组合可行”第一次真正包含“来得及”。

**灵感 4（证书有保质期 → TTL 与 RTF 域，证据会“过期”）**
直觉：仿真证据不是永恒真理。环境漂移、硬件负载变化、Gazebo 版本 / 步长变化都会让旧证书失配。于是联合证书增加 **时序分量 `τ_cert=(W,J,σ,𝒦,TTL)`**：`σ=D-R` 为松弛，`𝒦` 为时间保真域，`TTL` 为有效期。部署前必须校验 `now-t_evidence≤TTL ∧ RTF_obs∈𝒦`。这把第 54 轮“静态证书”变成“带时态谓词的证书”。

**灵感 5（用实时控制视角驯服第 54 轮遗留的 Explain 震荡）**
直觉：第 54 轮把“Explain 回传震荡”列为中风险却未给判据。本轮把它当作离散反馈控制：回传环路周期 `T_loop` 必须大于最坏往返时延加重新剖分时间，否则采样混叠；且环路增益 `G_loop<1` 才能收缩。这样 **实时性反过来成为闭环稳定性的充分条件**。

**灵感 6（时间层叠加到金字塔）**
直觉：在第 54 轮动作-协同层 `𝔸` 之侧增加 **时态层 `𝕋`**：`𝕋_0` 物理时钟 / 步长，`𝕋_1` 技能 WCET 剖面，`𝕋_2` 云边环路时延，`𝕋_3` 任务 deadline。跨层证书同时携带 `ρ、A_cert、τ_cert`，形成 **动作-鲁棒-时间三证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（实时因子与时间保真域）**
一次 Gazebo 运行 `r` 的实时因子 `k_r = t_sim / t_wall`。在物理步长 `δ`、求解器迭代数 `m`、传感器采样率 `f_s` 配置下，定义 **时间保真域** `𝒦=[k_lo,k_hi]`：当 `k_r∈𝒦` 时，仿真的时间语义满足积分误差 `ε_phys(δ,m)≤ε̄` 与传感器相位误差 `ε_s(f_s,k_r)≤ε̄_s`。令相对速度偏置 `κ=|1-k_r|`。**证据只在 `𝒦` 内有意义**；`k_r∉𝒦` 的证据携带不可忽略的时间偏置 `b(κ)`。

**定义 122（技能时间剖面与 WCET）**
技能 `S` 的时间剖面 `β_S(τ)=P(t_exec(S)≤τ)`，由重复运行的经验分布估计。硬实时技能取 `W_S = max_r t_exec`（或加安全裕度），软实时技能取 `W_S = inf{τ: β_S(τ)≥1-ε_w}`。抖动 `J_S = W_S - E[t_exec]`。技能类型 `type(S)∈{hard,soft}` 决定 `ε_w=0` 或 `ε_w>0`。

**定义 123（端到端响应时间与松弛）**
路径 `P=⟨S_1,…,S_n⟩` 的端到端响应时间
`R(P) = Σ_i W_{S_i} + Σ_i c_trans(S_i,S_{i+1}) + overhead_ce`。
松弛 `σ(P)=D-R(P)`，`D` 为任务 deadline。**时间可行** 当且仅当 `σ(P)≥Θ_s`。时间鲁棒性 `ρ_time(P)=P(R(P)≤D)`。

**定义 124（可调度技能组合图）**
可调度组合图 `G_S^RT=(V,E_RT)`：边 `(i,j)` 除第 54 轮条件外，还须其所在路径满足 RTA；边附带 `slack` 与 `ρ_time`。路径搜索目标为在预算约束 `R(P)≤D-Θ_s` 下最小化 `cost_align`。这是 **资源受限最短路**，可用带预算的 A* 或拉格朗日松弛求解。

**定义 125（时序联合证书与老化）**
时序联合证书 `J_T=(ρ, A_cert, γ_ce, δ_a, τ_cert, evidence)`，其中 `τ_cert=(W,J,σ,𝒦,TTL)`。可部署当且仅当第 54 轮全部条件成立，且
`σ≥Θ_s ∧ RTF_obs∈𝒦 ∧ now-t_evidence≤TTL`。
**老化函数** `Age(t)=exp(-λ_age·(t-t_evidence))`；当 `Age<A_min`、`RTF_obs∉𝒦` 或环境漂移超预算时触发 **选择性重仿真**（只刷新时敏子图）。

**定义 126（解释闭环稳定性证书）**
设 Explain→reprofile 闭环的离散增益 `G_loop=‖∂reprofile/∂Explain‖`，环路周期 `T_loop`，最坏往返 `RTT_max`，重剖分耗时 `t_rep`。**闭环稳定** 当且仅当
`T_loop ≥ RTT_max + t_rep ∧ G_loop<1`。
违反前者造成采样混叠（表现为第 54 轮的震荡），违反后者造成非收缩迭代；此时必须冻结重剖分（hysteresis）并退回稳定锚点。

## 2. 关键算法 伪代码

### IP-121 RTFC（Real-Time Factor Calibration）

```python
def calibrate_rtf(scenario, gazebo_cfg, n=32, seed=0):
    ks, steps = [], []
    for _ in range(n):
        t0 = wall_clock()
        t_sim, step_stats = gazebo.run_headless(scenario, gazebo_cfg, seed=seed)
        t_wall = wall_clock() - t0
        ks.append(t_sim / max(t_wall, EPS))
        steps.append(step_stats)
    k_hat = median(ks)
    k_lo, k_hi = quantile(ks, [0.05, 0.95])
    domain = TemporalDomain(k_hat, (k_lo, k_hi), jitter=stdev(ks))
    # 迁移到真实硬件要求 1.0 落在保真域内
    domain.transferable = (k_lo <= 1.0 <= k_hi)
    return domain, steps
```

### IP-122 TAP（Temporal Action Profile）

```python
def temporal_profile(skill, gazebo, budgets, n=64, eps_w=0.05):
    samples = [gazebo.measure_exec_time(skill) for _ in range(n)]
    beta = {tau: mean(t <= tau for t in samples) for tau in budgets}
    if skill.type == 'hard':
        W = max(samples) + safety_margin(skill)   # 硬实时：保守上界
    else:
        W = quantile(samples, 1 - eps_w)          # 软实时：分位上界
    return TemporalProfile(beta, W=W,
                           jitter=max(samples) - mean(samples),
                           wcet_samples=samples)
```

### IP-123 SCE（Schedulability-Constrained Edges）

```python
def build_rt_composition_graph(skills, G, D, theta_s, overhead):
    G_rt = G.copy()
    for (i, j) in list(G.edges):
        lb = skills[i].W + transition_cost(skills[i], skills[j]) + overhead
        if lb > D - theta_s:            # 下界剪枝：单边已超期
            G_rt.remove_edge(i, j)
        else:
            G_rt[i][j]['rho_time'] = deadline_robustness(skills[i], D)
    return G_rt

def rta_path(path, skills, c_trans, D, overhead):
    R = sum(skills[s].W for s in path) \
        + sum(c_trans(a, b) for a, b in pairs(path)) + overhead
    return R, D - R

def search_rt_path(G_rt, skills, task, D, theta_s, cost_align):
    # 资源受限 A*：预算 = D - theta_s，拒绝超额扩展
    return a_star_budgeted(G_rt, start='root', goal=task,
                           budget=D - theta_s,
                           edge_cost=cost_align,
                           node_cost=lambda s: skills[s].W,
                           heuristic=cost_align)
```

### IP-124 TTC（Temporal Transfer Certificate）

```python
def temporal_joint_certificate(J, path, skills, D, K_obs, now, theta_s):
    R, sigma = rta_path(path, skills, transition_cost, D, overhead_ce)
    if sigma < theta_s:
        return ('reject', 'deadline_miss', sigma)
    if K_obs not in J.temporal_domain:
        return ('reject', 'rtf_out_of_domain', K_obs)
    if now - J.t_evidence > J.ttl:
        return ('reject', 'stale_evidence', now - J.t_evidence)
    tau_cert = TauCert(W=[skills[s].W for s in path],
                       J=[skills[s].jitter for s in path],
                       sigma=sigma, domain=J.temporal_domain, ttl=J.ttl)
    return ('ok', TemporalCert(J.rho, J.A_cert, J.gamma_ce, J.delta_a, tau_cert))
```

### IP-125 CAR（Certificate Aging & Refresh）

```python
def should_refresh(cert, now, rtf_obs, env_drift, drift_budget):
    if now - cert.t_evidence > cert.tau_cert.ttl:    return True,  'ttl'
    if rtf_obs not in cert.tau_cert.domain:          return True,  'rtf_drift'
    if env_drift > drift_budget:                     return True,  'env_drift'
    return False, None

def budgeted_refresh(cert, critical_subgraph, sim_budget):
    # 按时敏程度（slack 升序）优先刷新，控制重仿真成本
    order = sorted(critical_subgraph, key=lambda s: s.slack)
    refreshed = []
    for s in order:
        if sim_budget <= 0:
            break
        refreshed.append(recalibrate(s, gazebo))
        sim_budget -= sim_cost(s)
    return refreshed
```

### IP-126 LSC（Loop Stability Certificate）

```python
def loop_stability_certificate(explain_loop, T_loop, reprofile_time, K_ctl):
    rtt = explain_loop.rtt_p95()
    if T_loop < rtt + reprofile_time:
        return ('reject', 'aliasing', rtt + reprofile_time)
    J = estimate_jacobian(K_ctl, explain_loop.history)
    gain = spectral_norm(J)
    if gain >= 1.0:
        return ('reject', 'non_contractive', gain)
    return ('ok', LoopCert(T_loop, rtt, gain, margin=1.0 - gain))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RTFC | O(n·T_sim) | O(n) | 采样充分、`1.0∈𝒦` |
| TAP | O(\|S\|·n) | O(\|S\|·n) | WCET 保守、类型区分 |
| SCE | O(\|E\|+A*_budget) | O(\|V\|+\|E\|) | RTA sound、预算剪枝安全 |
| TTC | O(\|P\|) | O(\|P\|) | 时态谓词闭合、TTL 有效 |
| CAR | O(\|S_c\| log\|S_c\|) | O(\|S_c\|) | 刷新预算不破坏 soundness |
| LSC | O(\|history\|·d²) | O(\|history\|) | 增益估计下界可靠 |

**正确性定理（Real-Time Certified Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** WCET 保守：`t_exec(S)≤W_S` 以概率 `≥1-ε_w`（硬实时取 `ε_w=0`）；**(A30)** 证据采集时 `RTF∈𝒦` 且部署观测 `RTF_obs∈𝒦`；**(A31)** Explain 闭环满足 `T_loop≥RTT_max+t_rep` 且 `G_loop<1`。
则部署成功概率：
```
P_success^RT ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                 - P(compat<θ_a) - P(R(P)>D) - P(stale)
```
其中 `P(R(P)>D)≤ε_w` 由 (A29) 界定，`P(stale)` 由 TTL 刷新（IP-125）压到预算内。关键：**组合前提同时满足动作兼容、鲁棒、可调度**；**证据带时态谓词**；**闭环实时可稳定**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| Gazebo WCET ≠ 真实硬件 WCET | 高 | 硬件在环时序标定 + 保守膨胀 + 运行时 deadline 监控 |
| RTF 保真域过窄，无法覆盖实时 | 高 | 固定步长 / 无渲染 headless + 多配置标定 + 域外降级 |
| RTA 组合搜索规模爆炸 | 中 | 预算剪枝 + 分层分解 + 松弛上界 |
| TTL 刷新抢占执行算力 | 中 | 优先级预算刷新 + 错峰调度 |
| Explain 环路增益估计偏差 | 中 | 在线辨识 + 保守增益下界 + 冻结回退 |

## 6. 本轮最大风险

**一句话**：把 Gazebo 的时间证据与实时性证书引入技能组合，使体系从“动作-鲁棒双证书”升级为“动作-鲁棒-时间三证书”，但其 soundness **最终押注在“Gazebo 测得的 WCET 与 RTF 保真域能代表真实边端”** 这一假设上；由于真实硬件的 CPU、ROS 传输、传感器驱动与调度抖动都不同于仿真，一旦把 sim-WCET 当作硬实时上界，组合会在 Gazebo 里“可调度”、在真机上系统性错过 deadline，故必须以 **硬件在环时序标定 + 保守 WCET 膨胀 + 运行时 deadline 看门狗与优雅降级** 三重护栏，宁可低估实时能力，也绝不把仿真的“按时假象”当作实时保证。

def temporal_profile(skill, gazebo, budgets, n=64, eps_w=0.05):
    samples = [gazebo.measure_exec_time(skill) for _ in range(n)]
    beta = {tau: mean(t <= tau for t in samples) for tau in budgets}
    if skill.type == 'hard':
        W = max(samples) + safety_margin(skill)
    else:
        W = quantile(samples, 1 - eps_w)
    return TemporalProfile(beta, W=W,
                           jitter=max(samples) - mean(samples),
                           wcet_samples=samples)

### IP-123 SCE

```python
def build_rt_composition_graph(skills, G, D, theta_s, overhead):
    G_rt = G.copy()
    for (i, j) in list(G.edges):
        lb = skills[i].W + transition_cost(skills[i], skills[j]) + overhead
        if lb > D - theta_s:
            G_rt.remove_edge(i, j)
        else:
            G_rt[i][j]['rho_time'] = deadline_robustness(skills[i], D)
    return G_rt

def rta_path(path, skills, c_trans, D, overhead):
    R = sum(skills[s].W for s in path) \
        + sum(c_trans(a, b) for a, b in pairs(path)) + overhead
    return R, D - R

def search_rt_path(G_rt, skills, task, D, theta_s, cost_align):
    return a_star_budgeted(G_rt, start='root', goal=task,
                           budget=D - theta_s,
                           edge_cost=cost_align,
                           node_cost=lambda s: skills[s].W,
                           heuristic=cost_align)
```

def temporal_joint_certificate(J, path, skills, D, K_obs, now, theta_s):

def should_refresh(cert, now, rtf_obs, env_drift, drift_budget):

def budgeted_refresh(cert, critical_subgraph, sim_budget):
    order = sorted(critical_subgraph, key=lambda s: s.slack)
    refreshed = []
    for s in order:
        if sim_budget <= 0:
            break
        refreshed.append(recalibrate(s, gazebo))
        sim_budget -= sim_cost(s)
    return refreshed

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RTFC | O(n·T_sim) | O(n) | 采样覆盖 ≥ 95%，`1.0∈𝒦` |
| TAP | O(\|S\|·n) | O(\|S\|·n) | WCET 保守，硬/软实时区分 |
| SCE | O(\|E\|+A*_budget) | O(\|V\|+\|E\|) | RTA sound，预算剪枝安全 |
| TTC | O(\|P\|) | O(\|P\|) | 时态谓词闭合，TTL 有效 |
| CAR | O(\|S_c\| log\|S_c\|) | O(\|S_c\|) | 刷新预算不破坏 soundness |
| LSC | O(\|history\|·d²) | O(\|history\|) | 增益下界可靠 |

**正确性定理（Real-Time Certified Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `t_exec(S)≤W_S` 以概率 `≥1-ε_w`（硬实时 `ε_w=0`）；**(A30)** 证据采集与部署观测均满足 `RTF∈𝒦`；**(A31)** 闭环满足 `T_loop≥RTT_max+t_rep` 且 `G_loop<1`。
则：
```
P_success^RT ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
                 - P(compat<θ_a) - P(R(P)>D) - P(stale)
```
关键：**动作兼容 + 鲁棒 + 可调度三者同时成立**，**证据带时态谓词**，**闭环实时可稳定**。

## 5. 本轮最大风险

**一句话**：把 Gazebo 的时间证据与实时性证书引入技能组合，使体系从“动作-鲁棒双证书”升级为“动作-鲁棒-时间三证书”，但其 soundness **最终押注在“Gazebo 测得的 WCET 与 RTF 保真域能代表真实边端”** 这一假设上；由于真实硬件的 CPU、ROS 传输、传感器驱动与调度抖动都不同于仿真，一旦把 sim-WCET 当作硬实时上界，组合会在 Gazebo 里“可调度”、在真机上系统性错过 deadline，故必须以 **硬件在环时序标定 + 保守 WCET 膨胀 + 运行时 deadline 看门狗与优雅降级** 三重护栏，宁可低估实时能力，也绝不把仿真的“按时假象”当作实时保证。
