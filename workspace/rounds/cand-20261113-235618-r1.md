# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「云边协同」×「时空推理」）

> R69 让不确定性终于「有形状」（流匹配给出多模态动作）也「有嘴巴」（注视/探针/问句去主动消歧）。但它问得**近视**：只问「问什么」（VoI），不问**在哪问**、**何时问**、也默认答案会**立刻且诚实**地回来。三个默认全错：
> - 很多歧义不在本地能解，而在**别处**——云端有全局地图、车队有别人的经验、大模型有更强的推理；但云端**会迟到、会过期、会版本偏斜、会撒谎**；
> - 很多歧义**不必问**——遮挡物会走开、行人会露头，**等一等**它自己就揭晓了；「等」是一种信息动作，但等待要拿安全包络当本金；
> - R69 的第二意见（动作似然 Δa）和策略**共享同一个盲区**：若策略以同样方式错两次，两条通道会一起错。它需要一个**外部锚**。
>
> 本轮两个灵感恰好补上：
> - **云边协同**把「证据」从「本地即时」扩展到「异地全局」——代价是时延、带宽、陈旧、信任与拜占庭风险；
> - **时空推理**把「证据」从「当下」扩展到「未来」——给出可观测性预测（哪些歧义会自解）、全局不变量（墙/重力/拓扑，边缘标定吸收不了的第三通道），以及跨时间的 STL 鲁棒性（证明「未来一段时间仍安全」，而非单点安全）。
>
> 核心命题：**把「消解不确定性」从一次即时查询，升级为一个带决策死线的时空调度问题**：候选信息源 = {本地即时, 未来等待, 云端卸载}，各自带时延分布、信任度、陈旧度与安全成本；用**时间贴现 VoI**（TD-VoI）统一比较；外部信息**只能窄化不能拓宽**已认证的安全集。命名 **STRATOS-RAS**（Spatio-Temporal Reasoning And Trust-aware Offloading for Safety）。R69 是本轮在「永不等待、永不卸载」边界上的严格退化。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**该去哪里问、值不值得等、这个答案还新鲜吗**」——云是更远的眼睛，时空是更长的耐心；但迟到的好答案，可能比没有答案更危险。

## 0. 直觉与动机

**灵感 1（云边协同 → 信息的地理分工）**
直觉：边缘之所以存在，是因为「近」有价值——低时延、高频率、隐私、断网可用；云之所以存在，是因为「远」有价值——全局地图、跨机器人经验、重推理、长期记忆。R69 把所有信息动作都放在「本地、即时、永远可得」这一格；但真实系统里，最值钱的那条证据常常**在别处且要等**。所以关键不是「云更聪明」，而是**把云当成一类新的证据源来建模它的失效模式**：到达时间 T_g 是随机的、内容是带版本的、链路可能断、云端可能被投毒、车队可能共谋。一句话：**云的证据价值必须乘以「在死线前到达的概率」再乘以「信任」。**

**灵感 2（时空推理 → 不确定性会自己过期，也会自己揭开）**
直觉：R69 把 U_epi 当成一道「必须现在就去查的题」。但空间里，有些歧义是**遮挡**——退一步、转个角、等两秒，答案自己出现；这叫被动信息增益（PIG），「等」因此是一个合法信息动作，只是它的成本是**安全包络随时间收缩**。时间上，真正该证明的不是「此刻安全」，而是「未来 H 步仍安全」（STL 鲁棒度 ρ_φ 的下界）。空间上，全局不变量（墙在那、重力向下、这条路通向那）是**外部锚**：边缘的标定只能吸收本地传感器残差，吸收不了「和整个世界地图不一致」。

**灵感 3（三源三分 → R69 的交互是「本地、零时延」特例）**
直觉：R69 的 MINT 是在集合 {local} 上做 argmax[VoI−c]；STRATOS 把它扩成在 {local, future, cloud} 上做 argmax[TD-VoI]，其中 local 的到达概率恒为 1、future 的成本是包络机会损失、cloud 的到达概率由链路画像给出。于是 R69 恰是「PIG≤0、无云覆盖、δ=0」的边界；R68 再退一步（VoI≤成本）。**新层必须是旧层的严格泛化**——这条 R69 立下的规矩，本轮继续遵守。

**灵感 4（外部先验是解药，也是新毒）**
直觉：R69 自陈最大风险是「流模型的模态分布不可信」。车队共识恰好是解药：单机幻觉出的模态，别的机器人没看到，就会被截尾中位数降权。但同一件事反过来就是新毒：**一个全局的谎言，比局部幻觉更「一致」、更「权威」、更难被边缘标定吸收**。投毒的地图、回滚的版本、被延迟拖过死线的答案、共谋的车队——这些都必须进入威胁模型，而不是事后补丁。

**灵感 5（版本即换装 → 云先验不能热替换）**
直觉：云端地图/模型会更新。R68 已经有一条铁律：软硬件**换装**必须原子提交、可回滚、不得在轨迹中途发生。云先验的版本更新就是一次「换装」：若在轨迹中途热替换 M_τ，决策会从一个世界瞬间跳到另一个世界，产生突变。故本轮把云先验做成**只读版本化快照**，只在安全提交点切换，复用 R68 定理 15。这样「云边协同」的最后一公里不是网络，而是**一致性**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（STRATOS-RAS 总览）** STRATOS-RAS = (STM, STU, DAF, COST, GMT, TCF, XMC, DDC, DED, RAS-WM††)。四不变式：
(i) **实时流零学习写操作 + 云先验只读快照**（版本化，禁止轨迹中途热替换，须过 R68 换装不变式）；
(ii) **时空决策死线**：任何信息动作（含云查询、等待）不得使系统越过安全死线 D；发起前必须建立可认证的 fallback ladder；
(iii) **外部信息只窄化不拓宽安全集**：云/未来/全局先验只能从「发起时已认证安全的候选模态集 C_safe」中选择，不得引入未经本地认证的新动作，不得放宽认证前缀长度；
(iv) **证据纪律扩展**：云回答、未来观测、全局先验各为「一票」；任何单源（尤其单一云回答）不得单独定案，需与至少一个正交本地源一致。

**定义 311（时空证据与全局先验 STM/GMT）** 云/车队维护版本化时空记忆 M_τ = (map, scene graph, 轨道/拓扑, 历史轨迹统计)，时间戳 τ、版本 ver(M)。边缘在 t 观测 o_t，经位姿投影 y_t = Proj(o_t; pose_t)。全局残差 r_st(t) = d(y_t, M_τ(t))（几何/语义/拓扑距离），仅当该区域有覆盖 c_M(y_t)=1 时有效。M 只以快照形式进入实时环。

**定义 312（时空不确定性三分 STU）** 在 R69 的 U_ale、U_epi 上，把 epistemic 按「在哪/何时可解」细分：
- U_epi^local：本地即时信息动作可解（R69 原通道）；
- U_epi^future：随未来观测被动可解（等待/前进即揭晓）；
- U_epi^remote：需全局/车队/大模型推理才能解（云通道）；
- U_epi^irr：预算内任何源都不可解（视同 aleatoric 兜底）。
U_epi = 四分量之和，但各分量进入不同调度通道，**不做标量加和**。

**定义 313（可观测性预测与被动信息增益 DAF）** 由时空记忆与场景演化预测未来可见性 V(t+δ; m) ∈ [0,1]（模态 m 在 δ 后能否被观测）。被动信息增益 PIG(m) = E_{y_{t+δ}}[H(M|o_t) − H(M|o_t, y_{t+δ})] · 1{envelope open for δ}。等待动作 g_wait(δ) 是合法信息动作，成本 = 安全包络随 δ 收缩的机会风险 + 时窗损失；若 PIG > 机会成本且 DDC 覆盖 δ，则「等」优于「探」。

**定义 314（云卸载动作与到达时延）** 信息动作扩展为 g_cloud = (query, fidelity, deadline_budget, fallback)。上行查询的到达时间 T_g 服从由链路画像估计的分布 F_g；答案 q_g 带来源签名、版本 ver(M)、时间戳 τ_q。卸载决策必须携带 fallback ladder。

**定义 315（时间贴现 VoI，TD-VoI）** 决策死线 D（无动作则安全包络崩溃或任务失败的时间）。有效信息增益：
VoI_τ(g) = E[ ΔH(g) · 1{t + T_g ≤ D} · trust(g) ] − c(g) − c_wait(g)
其中 c_wait 为占用时窗与包络收缩成本。仅当 VoI_τ(g) > 0 且通过 DDC 认证才发起。系：临近死线时 T_g 右尾支配，卸载价值趋零；**迟到答案的有效 VoI = 0**。

**定义 316（三通道故障判别 TCF）** 三源残差：
- r_res（R68 传感器自洽，可被标定吸收）；
- Δa（R69 行为似然，与策略共享盲区）；
- r_st（全局时空先验，外部、跨智能体，边缘标定不可吸收）。
判别：(r_res↓, Δa 低/中, r_st↑) ⇒ 局部与行为都自洽但全局不一致，R69 的 FMA 盲区；(r_res↑) ⇒ 常规传感器故障；(c_M=0) ⇒ 无外部锚，退化为 R69 双通道。按可用通道取最大证据，不把三源简单相加。

**定义 317（跨智能体模态共识 XMC）** 车队/云端聚合各边缘的模式后验 {w^{(i)}}。在观测噪声条件独立、恶意比例 β 下，用截尾中位数 w̄ = TrimmedMedian({w^{(i)}})。共识分歧度 κ = 1 − cos(w̄, w_local) 作为 R69 MCG（定义 306）的**外部校准项**：局部幻觉模态被共识降权；κ 过大则 MCG 收紧甚至退回纯保守。

**定义 318（信任与陈旧度）** 每个证据源 s 维护信任 p_trust(s) ∈ [0,1]（历史一致率、签名、版本兼容）与陈旧度 age = t − τ_q。有效权重 ∝ p_trust(s)·exp(−age/τ_half)·1{ver compatible}。版本不兼容/签名失败 ⇒ 权重 0，但保留审计记录。

**定义 319（决策死线与 fallback ladder）** fallback ladder L = [a_0, a_1, …, a_k]：从当前状态起、在无任何新信息下逐步可认证的安全动作序列，满足 C-RAS-WM 前缀认证且覆盖 [t, D]。认证条件：∀ δ ∈ [0,D]，L 的前缀使安全包络未崩溃。若不存在 ⇒ 禁止等待/卸载，立即执行最保守本地动作（R69/R68 边界）。

**定义 320（外部信息的安全窄化）** 云/未来/先验证据只能用于在**发起时冻结的**候选集 C_safe 内重排序/选择；不得新增 C_safe 外的动作，不得修改认证前缀上限 k。答案迟到时仅回灌 AuditBuf 与下一轮先验，**禁止追溯改写已提交动作**（no retroactive override）。

**定义 321（时空一致性证书与 STL 鲁棒性）** 对关键时序约束 φ 用信号时序逻辑鲁棒度 ρ_φ(o_{t:t+H})。安全提交要求 ρ_φ ≥ 0 且其预测下界（计入云先验版本不确定性）≥ −ε_stl。时空推理交付的是「未来一段时间仍安全」的证明，而非单点安全。

**定义 322（分布式证据纪律 DED）** R69 定义 293-iii 扩展到分布式：云为单一源、未来观测为单一时序源、全局先验为单一空间源。定案需至少两类正交源一致（local/sensor ∩ global/prior，或 future/observed ∩ behavior/likelihood），除非 TD-VoI 增益超过高置信阈值且风险 ≤ ε_int。

**定义 323（证书 J_STRATOS）** J_STRATOS = (J_FLUID, prior_ver, prior_coverage, r_st_p95, T_g_p95, deadline_slack_min, trust_min, consensus_kappa, offload_log_hash, stl_robust_min, stratos_ver)。Valid ⇔ Valid(J_FLUID) ∧ 版本兼容 ∧ 死线未破 ∧ 安全窄化保持 ∧ 分布式证据纪律满足。

**定义 324（对抗集 ℰ_cloudedge）** 云先验投毒（伪造墙面/拓扑）、重放/陈旧地图、版本回滚攻击、链路延迟注入（把答案拖过死线）、模型版本偏斜、车队共谋（相关噪声破坏共识）、以「全局一致」为名的权威欺骗。并入 AIC：ℰ_STRATOS = ℰ_FLUID × ℰ_cloudedge。

**定义 325（时空调度器 COST）** 在带宽/算力/时窗预算下最大化 Σ VoI_τ(g) 的调度；候选源 = {local 即时, future 等待, cloud 卸载}。约束：每源并发 ≤ 1、单位时间信息动作 ≤ 1、不得占用 fallback 执行窗口。COST 是 R69 MINT 的超集：MINT 固定源 = local、T_g = 0。

**定义 326（退化与严格包含）** 当 PIG≤0、无云覆盖或链路不可用、且不等待（δ=0）时，STRATOS 逐指令退化为 FLUID；当进一步 VoI≤成本时退化为 R68。安全侧永不弱于 R69/R68。

```python
# IP-264 STM：版本化时空先验（只读快照，禁止轨迹中途热替换）
class SpatioTemporalMemory:
    def snapshot(self):                       # 版本化快照，过 R68 换装不变式
        return Prior(ver=self.ver, map=self.map, temporal=self.tg, ts=now())
    def project(self, o, pose, tau):          # 观测投影到全局时空坐标
        return Proj(o, pose, tau)
    def residual(self, y, prior):             # r_st：几何/语义/拓扑距离 + 覆盖
        return d(y, prior(y.t)), prior.coverage(y)

# IP-265 STU：时空不确定性三分（局部/未来/远程/不可约）
def decompose_st(samples, o, prior):
    U_ale, U_epi, modes = fluid_decompose(samples)      # R69 原分解
    U_local  = U_epi                                    # 本地可探
    U_future = U_epi * occlusion_fraction(modes, o)     # 靠未来观测可解
    U_remote = U_epi * prior_disagreement(modes, prior) # 靠全局知识可解
    U_irr    = max(0.0, U_epi - U_local - U_future - U_remote)
    return U_ale, Parts(U_local, U_future, U_remote, U_irr), modes

# IP-266 DAF：可观测性预测与被动信息增益（“等”也是动作）
def passive_gain(modes, o, horizon, envelope):
    pig = 0.0
    for m in modes:
        vis = predict_visibility(m, o, horizon)          # 未来可见性
        if envelope.open_for(horizon):
            pig += w[m] * vis * H(M | o)                 # 期望熵降的近似
    return pig - opportunity_cost(horizon)               # 等待有机会成本

# IP-267 COST：时间贴现 VoI 的时空卸载调度
def schedule(info_sources, modes, o, D, budget):
    best = None
    for g in info_sources:                               # local / wait / cloud
        if not budget.allow(g): continue
        if not ddc.has_fallback(o, g, D): continue       # 先有安全退路，再谈查询
        voi = (expected_entropy_drop(modes, g)
               * arrival_prob(g, D) * trust(g)           # 死线前到达概率 × 信任
               - cost(g) - wait_cost(g))
        if voi > 0 and (best is None or voi > best.voi):
            best = (g, voi)
    return best                                          # None → 立即本地保守（R69/R68）

# IP-268/269 GMT + TCF：全局残差与三通道联合判别
def triple_channel(r_res, dA, r_st, coverage):
    if coverage == 0:        return "fallback_r69", (r_res, dA)
    score = (r_res, dA, r_st)
    if r_res < T_RES and r_st > T_ST:  return "slow_fault_global", score  # R69 盲区
    if r_res > T_RES:                  return "sensor_fault", score
    if dA > T_FMA and r_st < T_ST:     return "behavior_anomaly", score
    return "consistent", score

# IP-270 XMC：跨智能体模态共识（外部校准局部幻觉模态）
def fleet_consensus(local_w, fleet_ws, beta):
    w_bar = trimmed_median(fleet_ws, trim=beta)          # 抗 Byzantine
    kappa = 1 - cosine(w_bar, local_w)                   # 共识分歧度
    return w_bar, kappa

# IP-271 DDC：死线证书 + fallback ladder
def has_fallback(o, g, D):
    L = certified_ladder(o, D)                           # R68/R69 认证前缀序列
    return (L is not None and covers(L, t=0, D=D)
            and (g.is_local or L.sufficient_until(D)))   # 云/等待也不得越死线

# IP-276 主闭环（继承 R69，插入时空调度层）
def STRATOS_round(M, o):
    prior = M.stm.snapshot()                             # 版本化只读快照
    z, o_cal = M.mtm.forward(o); c, U_cal = M.cof.step(o)
    samples = M.fmp.sample(o, K=M.adaptive_K(z))
    U_ale, parts, modes = M.stu.decompose_st(samples, o, prior)
    r_st, cov = M.stm.residual(M.stm.project(o, M.pose, prior.ts), prior)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal)   # R69 通道
    kind, _ = M.tcf.triple_channel(M.last_r_res, a_hat, r_st, cov)
    # 1) 时空调度：本地 / 等待 / 云，统一 TD-VoI，且先建 fallback
    g = M.cost.schedule(info_sources(parts, cov), modes, o, M.deadline, M.budget)
    # 2) 执行（可能只是“等”，也可能卸载）；外部证据带信任/陈旧度/版本
    answer = M.cia.execute_with_trust(g) if g is not None else None
    if answer is not None:
        parts = M.cia.update_belief(modes, answer)
    # 3) 车队共识做 MCG 外部锚；慢变故障回最保守
    w_bar, kappa = M.xmc.fleet_consensus(mode_weights(modes), M.fleet, M.beta)
    if kappa > T_KAPPA:
        modes = downweight_local_hallucination(modes, w_bar)
    slow = (kind == "slow_fault_global")
    # 4) 风险缩放：未消解分量入 R68 floor，消解成功者获 resolution bonus
    U_floor = U_ale + parts.residual()
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), wm_preds)
    if slow:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    # 5) 只在发起时冻结的 C_safe 内选模态（外部信息只窄化不拓宽）
    mode = select_mode(modes, parts, lam, C_safe=M.frozen_safe_at_offload)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 时空审计 + 证书
    M.sta.submit_async(g, answer, prior.ver, r_st, kappa, kind)
    return k, lam, mode, (U_ale, parts)
```

## 3. 推导

**引理 19（时间贴现的信息价值上界）** 设信息动作 g 的到达时间 T_g 分布为 F_g，单次可降熵 ΔH ≤ H_max。则有效增益 VoI_τ(g) ≤ H_max · F_g(D−t) · trust(g) − c(g)。要点：信息价值被**到达分布**与**信任**双重贴现；临近死线时 F_g(D−t)→0，远程查询的边际价值趋零，本地与等待占优。系：越早发起查询，弱支配越晚发起（同源、同内容时）。

**引理 20（全局先验的互补可探测性）** 设缓变漂移同时被本地标定吸收（r_res≈0）且落在策略训练流形主脊上（Δa≈0），则 R69 双通道均失效。若漂移方向在全局有覆盖的不变量（如墙面、重力、拓扑）上分量非零，则 r_st = Ω(ε_drift · α_M)，α_M 为该方向先验可观测性；若 c_M=0，则 r_st 无功效，三通道退化为 R69。故三通道的**可探测域是 R69 的补集而非超集**，并集覆盖更广——这正是补丁的意义。

**引理 21（车队共识抗幻觉/抗共谋）** 设各机在真值条件下模式后验条件独立，单机幻觉率 δ_h，恶意比例 β 且诚实多数。截尾中位数丢弃两端 β 后，错误模态权重 ≤ δ_h·ρ^{n−1} + ε_σ（ρ 为跨机误差相关）；当 ρ→1（共谋/相关噪声）上界失效。系：共识能给 R69 的模态 ECE 提供**外部锚**，但必须由 DED 把「一致性」与「独立性」分开检查，否则共谋的「全局一致」反而最危险。

**引理 22（等待的可行性条件）** 等待 g_wait(δ) 可采纳 ⇔ PIG(δ) > 机会成本 且 DDC 的 fallback ladder 覆盖 δ。即：等待不是免费的耐心，而是用**安全包络本金**去购买**未来可观测性**。系：当预测未来可见性低或包络收缩快时，等待无效，应立即改为本地探询或保守执行。

**定理 18（STRATOS 严格包含 FLUID/R68）** 在 A99–A102 下，STRATOS 的期望风险 ≤ FLUID ≤ R68；且当 PIG≤0、无云覆盖/链路、δ=0 时二者逐指令相同；进一步 VoI≤成本时退化为 R68。安全侧不做任何让步，效率侧额外获得 resolution bonus 与外部校准收益。

**定理 19（外部信息不拓宽安全集 + 死线不破）** 由于 C_safe 在发起卸载时冻结、fallback ladder 覆盖 [t,D]，任何云回答（哪怕对抗性）都只能在**已认证安全的子集**内选择；若到达时间 > 死线，答案不得改变已提交动作、只进审计。DC 保证在 D 前必然提交。故物理风险 ≤ ε_int、控制连续无突变，云内容不影响安全包络。

**定理 20（先验版本更新即换装，无突变）** 云先验更新按 R68 换装不变式原子提交：新版本 ver(M') 在安全提交点一次性生效、可回滚；轨迹中途只读旧快照。故版本切换不产生决策跳变，ρ_φ 的下界在切换前后连续可续。

## 6. 本轮最大风险

**一句话**：STRATOS 把「可信」从策略内部转移到了**云先验与车队共识**上——而**一个被投毒、过期或版本偏斜的全局先验最有欺骗性：它比局部证据更「权威」、比单机幻觉更「一致」，边缘标定又恰好吸收不了它**；叠加死线的诱惑（「再等一个更权威的答案」），系统可能在错误的世界模型上做出一致、自信、且无法被本地纠错的决策——**全局的谎言 + 一次不值得的等待，可能比 R69 的「问错」更致命**。

**次级风险与缓解**：
1. **云先验投毒/版本回滚** → 签名 + 版本兼容门 + ℰ_cloudedge 对抗训练 + E307；一律可回滚到 FLUID。
2. **车队共谋破坏共识**（ρ→1）→ 引理 21 的独立性前提 + DED 双源交叉 + E315；共识只作外部锚，不作单源定案。
3. **为等答案越死线** → DDC fallback ladder 硬约束 + 定理 19 + E303/E308；迟到答案只进审计。
4. **等待耗尽安全包络** → 引理 22 可行性条件 + 机会成本显式入 TD-VoI + E302。
5. **版本热替换引发突变** → 只读快照 + 换装原子提交/回滚（定理 20）+ E312。
6. **无覆盖区域误用 r_st** → 覆盖门 c_M + 自动退化 R69（引理 20、E314），绝不在无先验处伪造「全局一致」。

## 3. 关键算法伪代码

```python
# IP-264 STM：版本化时空先验（只读快照，禁止热替换）
class SpatioTemporalMemory:
    def snapshot(self):  return Prior(ver=self.ver, map=self.map, tg=self.tg, ts=now())
    def project(self, o, pose, tau):  return Proj(o, pose, tau)
    def residual(self, y, prior):     return d(y, prior(y.t)), prior.coverage(y)

# IP-265 STU：时空不确定性三分
def decompose_st(samples, o, prior):
    U_ale, U_epi, modes = fluid_decompose(samples)          # R69 原分解
    U_local  = U_epi
    U_future = U_epi * occlusion_fraction(modes, o)
    U_remote = U_epi * prior_disagreement(modes, prior)
    U_irr    = max(0.0, U_epi - U_local - U_future - U_remote)
    return U_ale, Parts(U_local, U_future, U_remote, U_irr), modes

# IP-266 DAF：被动信息增益（“等”也是动作）
def passive_gain(modes, o, horizon, envelope):
    if not envelope.open_for(horizon): return -inf
    pig = sum(w[m] * predict_visibility(m, o, horizon) * H(M | o) for m in modes)
    return pig - opportunity_cost(horizon)

# IP-267 COST：TD-VoI 时空调度（先建 fallback，再谈查询）
def schedule(info_sources, modes, o, D, budget):
    best = None
    for g in info_sources:                                  # local / wait / cloud
        if not budget.allow(g) or not ddc.has_fallback(o, g, D): continue
        voi = (expected_entropy_drop(modes, g)
               * arrival_prob(g, D) * trust(g) - cost(g) - wait_cost(g))
        if voi > 0 and (best is None or voi > best.voi): best = (g, voi)
    return best                                             # None → 立即本地保守

# IP-268/269 GMT + TCF：三通道联合判别
def triple_channel(r_res, dA, r_st, cov):
    if cov == 0:                     return "fallback_r69", (r_res, dA)
    if r_res < T_RES and r_st > T_ST: return "slow_fault_global", (r_res, dA, r_st)
    if r_res > T_RES:                 return "sensor_fault", (r_res, dA, r_st)
    if dA > T_FMA and r_st < T_ST:    return "behavior_anomaly", (r_res, dA, r_st)
    return "consistent", (r_res, dA, r_st)

# IP-270 XMC：车队截尾中位数共识（外部校准局部幻觉模态）
def fleet_consensus(local_w, fleet_ws, beta):
    w_bar = trimmed_median(fleet_ws, trim=beta)
    return w_bar, 1 - cosine(w_bar, local_w)               # w_bar, κ

# IP-271 DDC：死线 + fallback ladder
def has_fallback(o, g, D):
    L = certified_ladder(o, D)
    return (L is not None and covers(L, 0, D)
            and (g.is_local or L.sufficient_until(D)))

# IP-276 主闭环（继承 R69，插入时空调度层）
def STRATOS_round(M, o):

    z, o_cal = M.mtm.forward(o); _, _ = M.cof.step(o)
    samples = M.fmp.sample(o, K=M.adaptive_K(z))
    U_ale, parts, modes = M.stu.decompose_st(samples, o, prior)
    r_st, cov = M.stm.residual(M.stm.project(o, M.pose, prior.ts), prior)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, o_cal)
    kind, _ = M.tcf.triple_channel(M.last_r_res, a_hat, r_st, cov)
    g = M.cost.schedule(info_sources(parts, cov), modes, o, M.deadline, M.budget)
    answer = M.cia.execute_with_trust(g) if g is not None else None
    if answer is not None: parts = M.cia.update_belief(modes, answer)
    w_bar, kappa = M.xmc.fleet_consensus(mode_weights(modes), M.fleet, M.beta)
    if kappa > T_KAPPA: modes = downweight_local_hallucination(modes, w_bar)
    slow = (kind == "slow_fault_global")
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + parts.residual()))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, parts, lam, C_safe=M.frozen_safe_at_offload)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.sta.submit_async(g, answer, prior.ver, r_st, kappa, kind)
    return k, lam, mode, (U_ale, parts)
```

## 4. 推导

**引理 19（时间贴现的信息价值上界）** `VoI_τ(g) ≤ H_max·F_g(D−t)·trust(g) − c(g)`（`ΔH≤H_max`）。信息价值被**到达分布 × 信任**双重贴现；临近死线 `F_g→0`，远程查询边际价值趋零，本地/等待占优。系：同源同内容时，早发起弱支配晚发起。

**引理 20（全局先验的互补可探测性）** 若缓变漂移被标定吸收（`r_res≈0`）且落在策略主脊（`Δa≈0`），R69 双通道失效；若漂移在全局有覆盖的不变量上有分量，则 `r_st=Ω(ε_drift·α_M)`；若 `c_M=0` 则退化为 R69。故三通道可探测域是 R69 的**补集而非超集**，并集覆盖更广。

**引理 21（车队共识抗幻觉/抗共谋）** 条件独立、单机幻觉率 δ_h、恶意比例 β 且诚实多数时，截尾后错误模态权重 ≤ `δ_h·ρ^{n−1}+ε_σ`；`ρ→1`（共谋）上界失效。系：共识可为模态 ECE 提供外部锚，但 DED 必须把「一致」与「独立」分开检查。

**引理 22（等待的可行性条件）** `g_wait(δ)` 可采纳 ⇔ `PIG(δ)>机会成本` 且 fallback 覆盖 δ。等待是用**安全包络本金**购买**未来可观测性**；可见性低或包络收缩快时，应改为本地探询或保守执行。

**定理 18（STRATOS 严格包含 FLUID/R68）** A99–A102 下期望风险 ≤ FLUID ≤ R68；`PIG≤0、无云覆盖/链路、δ=0` 时逐指令相同；`VoI≤成本` 再退化为 R68。安全不让步，效率获 resolution bonus 与外部校准收益。

**定理 19（外部信息不拓宽安全集 + 死线不破）** `C_safe` 在发起时冻结、fallback 覆盖 [t,D]，故任意云回答（含对抗）只能在已认证安全子集内选择；`T_g` 超死线的答案不改已提交动作、只进审计。物理风险 ≤ ε_int、控制连续。

**定理 20（先验版本更新即换装，无突变）** 先验更新按 R68 换装不变式原子提交、可回滚；轨迹中途只读旧快照。版本切换不产生决策跳变，STL 鲁棒下界前后连续可续。

## 7. 本轮最大风险

**一句话**：STRATOS 把「可信」从策略内部转移到**云先验与车队共识**上——**一个被投毒、过期或版本偏斜的全局先验最有欺骗性：它比局部证据更「权威」、比单机幻觉更「一致」，边缘标定又恰好吸收不了它**；叠加死线的诱惑（「再等一个更权威的答案」），系统可能在错误的世界模型上做出一致、自信、且无法被本地纠错的决策——**全局的谎言 + 一次不值得的等待，可能比 R69 的「问错」更致命**。

**次级风险与缓解**：云先验投毒/回滚（签名 + 版本门 + ℰ_cloudedge + E307，一律可回滚 FLUID）；车队共谋破坏共识（引理 21 独立性前提 + DED 双源交叉 + E315，共识只作外部锚）；为等答案越死线（DDC + 定理 19 + E303/E308，迟到只进审计）；等待耗尽包络（引理 22 + 机会成本入 TD-VoI + E302）；版本热替换突变（只读快照 + 换装原子提交/回滚 + 定理 20 + E312）；无覆盖误用 r_st（c_M 门控 + 自动退化 R69 + E314）。
