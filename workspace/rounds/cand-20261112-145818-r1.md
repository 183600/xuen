# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「状态估计」×「三维感知」）

> 第 60 轮 SGEC 把「场景」压缩为标签-阻抗先验 π_scene(K|z)，再用启发式置信度 SIC 与 timestamp/seq/hash 校验 EV-exec。三个未解问题：
> 1. **几何盲区**：π_scene 是「场景标签 → 阻抗」的黑箱查表；同是桌面，边缘、斜面、薄板、悬空处的真实接触几何差异极大，标签无法表达，导致 K_safe 先验在几何上错位。
> 2. **置信度无保证**：SIC = scene_conf·exp(−D⁺) 与 τ_scene=0.7 都是经验阈值，场景误判时置信度仍可能很高——这正是第 60 轮的最大风险。更根本地，某些接触状态在当前运动下**根本不可观测**，却会被报告为「高置信」。
> 3. **证据只查自洽、不查物理**：EPIR 只校验 timestamp/seq/hash；一条哈希正确、序列完整的 EV-exec 仍可能**几何荒谬**（接触点落在感知自由空间、力方向与表面法向矛盾）。

## 0. 直觉与动机

**灵感 1（三维感知 → 几何先验阻抗 GPC）**
直觉：接触不是「场景标签→刚度」，而是「局部几何→刚度张量」。3D 感知（稠密点云/TSDF/网格）给出接触点的局部坐标系 R_c=[n,t1,t2]、主曲率 κ=(κ1,κ2) 与可视摩擦锥 μ̂。阻抗天然是二阶张量，应被分解为法向 k_n 与切向 k_t：
K_geo = R_c · diag(k_n, k_t, k_t) · R_cᵀ。
同是桌面，平面中心、棱边、悬空边缘得到不同法向与曲率，因而得到不同先验；「桌面→楼梯」的切换表现为法向/曲率突变，而不是标签跳变。关键洞见：**让阻抗成为几何协变的对象，而不是标签查表**。

**灵感 2（状态估计 → 可观测性感知 OASE）**
直觉：接触状态 x=(p_c, n, μ, v_slip, δ) 是隐变量，力/位/视觉是带噪观测。EKF/因子图能估 x，但真正的安全问题是「何时估不准」。Fisher 信息 J(x,u)=Σ HᵀΣ_z⁻¹H 的特征值谱给出可观测子空间；切向激励≈0 时，μ 与滑移方向几乎不可观测。关键洞见：**可观测性指数 O=λ_min(J) 应作为置信度的上界**——不可观测方向禁止报告高置信。

**灵感 3（三维感知 × 状态估计 → 主动探测 APO）**
直觉：可观测性依赖运动，所以应主动选择探测动作以最大化信息增益；这与 PCE 的 VOI 天然耦合。但存在硬张力：估计法向刚度 k_n 需要**法向穿透 δ**，穿透越大，损伤/滑移风险越高。于是探测 = 在「信息」与「安全」之间做受约束优化。关键洞见：**把探测从「找误差大的方向」升级为「设计可观测性」，并把 observer effect 显式纳入风险项**。

一维推导：在接触点施加小位移 δ，力测量 f = k_n·δ + n_f，σ_f 为力噪声。则 k_n 的 Fisher 信息 J_kn ≈ δ²/σ_f²，Cramér–Rao 给出 σ̂_kn ≥ σ_f/|δ|。可见**没有穿透就没有刚度信息**，信息增益与穿透能量成正比——这既解释了「零接触观测」无法建立可靠先验，也解释了主动探测为何危险。

**灵感 4（三维感知 → 几何锚定证据 GAE）**
直觉：给每条 EV-exec 绑定「几何锚」：世界系接触点 p_c^w、感知表面法向 n^w、实测力方向 f̂、几何残差 r_geo、到感知表面的距离 d_surf。证据不仅要在时间/序号上自洽，更要**落在物理世界的可见表面上**。关键洞见：几何残差是「执行证据」与「感知证据」之间的硬对账，可捕获「数值自洽、物理不可能」的伪证。

**灵感 5（状态估计 → 共形校准与不确定性传播 CPC/UPC）**
直觉：把经验阈值换成有统计保证的校准。共形预测用校准集把任意黑箱感知器变成覆盖率 ≥1−α 的预测集；再把感知协方差经 ζ→K 的雅可比传播，得到阻抗椭球不确定集，用 chance constraint 求鲁棒 K_safe^α。关键洞见：**置信度从「拍的阈值」变成「分布无关的覆盖保证」，并且只能被可观测性进一步压低（更保守），不能被抬高**。

**灵感 6（合流 → PSEC 闭环）**
三维感知出几何先验 → 状态估计出（可观测性封顶的）不确定性 → 编译鲁棒 K → 执行 → 几何锚定证据校验 → 共形校准回灌 → 主动探测决定下一次观测。闭环：**几何感知 → 状态估计 → 阻抗编译 → 执行 → 几何证据 → 校准 → 主动探测**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（几何先验阻抗 GPC）** 接触几何 g=(p_c, R_c, κ, μ̂)，R_c=[n,t1,t2]∈SO(3)。几何先验阻抗张量
```
K_geo = R_c · diag(k_n, k_t, k_t) · R_cᵀ
```
曲率 κ=(κ1,κ2)，有效曲率半径 1/R_eff = 1/R_obj + 1/R_env；Hertz/Mindlin 近似
```
a = (3·F_n·R_eff/(4·E*))^(1/3),  k_n ≈ 2·E*·a,
k_t ≈ k_n · 2(1−ν)/(2−ν)
```
并按接触安全域 clamp 到 [k_min,k_max]。几何先验 π_geo(K|g)=N(K; K_geo(g), Σ_geo(g))。相较定义 153 的标签先验 π_scene(K|z)，π_geo 对同类场景的几何差异（平面/棱边/薄板）敏感，且对「场景切换」表现为法向/曲率突变而非标签跳变。

**定义 162（可观测性感知状态估计 OASE）** 接触状态 x=(p_c, n, μ, v_slip, δ)∈X；观测 z=(wrench, joint_torque, contact_patch_3d)=h(x)+ε，ε~N(0,Σ_z)。局部 Fisher 信息
```
J(x,u) = Σ_i H_iᵀ Σ_z⁻¹ H_i,   H_i = ∂h_i/∂x
```
可观测性指数 O(x,u)=λ_min(J)/λ_ref∈[0,1]，可观测子空间由 J 的特征向量张成。Cramér–Rao：Σ_x ⪰ J⁻¹。估计器输出 x̂ 必须满足**可观测性封顶置信度** γ_obs=min(1, O/O_min)，且对不可观测特征方向 σ_j ≥ σ_floor。即：**不可观测方向不得被报告为自信**。

**定义 163（主动探测 APO）** 探测动作 u∈U（阻抗设定/微位移/接触姿态），安全域
```
U_safe = {u : K(u)∈K_safe, P(slip|u,μ̂) ≤ δ_s, barrier h_safe ≥ 0}
u* = argmax_{u∈U_safe} [ IG(x;u) − λ_r·Risk(u) ],  s.t. cost(u) ≤ B_probe
IG(x;u) ≈ ½·log det(I + J_prior^{-1/2} J(x̂,u) J_prior^{-1/2})
```
Risk(u) 显式包含 observer effect：探测位移本身可能触发滑移/损伤。若 O(x̂,u*) < O_min，则放弃主动探测，回退被动估计。

**定义 164（几何锚定证据 GAE）** 增强证据 EV-exec'=(EV-exec, a_geo)，
```
a_geo = (p_c^w, n^w, f̂, r_geo, d_surf, Σ_anchor)
r_geo = arccos( clip( (−f̂)·n^w, −1, 1) ),  d_surf = dist(p_c^w, S_perc)
G_valid = seq/hash 有效 ∧ r_geo ≤ ε_geo ∧ d_surf ≤ d_tol ∧ anchor ∈ C_α^anchor
```
若 G_valid=false 而 seq/hash 有效，则标记为「几何不可采纳」，触发重探测或保守回退。这是对定义 155/160 的增量：**证据必须同时通过时序校验与几何校验**。

**定义 165（共形感知校准 CPC）** 校准集 D_cal={(o_i,y_i)}，非一致性分数 s(o,y)。取
```
q = Quantile_{⌈(n+1)(1−α)⌉/n}({s(o_i,y_i)})
C_α(o) = {y : s(o,y) ≤ q}
```
则 P(Y∈C_α) ≥ 1−α（可交换性下）。分布漂移下用自适应共形 ACI：
```
α_{t+1} = α_t + η(α* − 1{Y_t ∉ C_{α_t}(o_t)})
```
长期覆盖 ≥ 1−α*−ε。校准置信度 γ_cal(o)=max{1−α : y∈C_α(o)}，取代 τ_scene。

**定义 166（不确定性传播 UPC）** 感知参数 ζ（位姿、分割、曲面拟合）协方差 Σ_ζ；K=g(ζ)，G=∂g/∂ζ。则
```
Σ_K = G Σ_ζ Gᵀ + Σ_model
```
机会约束 P(K∈K_safe) ≥ 1−α 的鲁棒等价：取椭球 E_α={δ : δᵀ Σ_K⁻¹ δ ≤ χ²_{d,1−α}}，令 K_safe^α = K_safe ⊖ E_α（Minkowski 腐蚀），并要求 K_geo∈K_safe^α。报告置信度 γ=min(γ_cal, γ_obs)。

**定义 167（PSEC 闭环算子）** PSEC(M, goal, intent, δ_f_req)：
```
① 感知:  S_perc, ζ, Σ_ζ ← update_3d_perception(depth, rgb, extrinsics)
② 几何先验: g ← contact_manifold(S_perc, goal)；π_geo ← GPC(g)
③ 状态估计: x̂, Σ_x, O ← OASE(wrench, proprio, contact_patch_3d)
④ 主动探测: if O < O_min and B_probe>0: u* ← APO(x̂, O, μ̂)
⑤ 传播:   Σ_K ← UPC(Σ_ζ, g)；K_safe^α ← K_safe ⊖ E_α
⑥ 编译:   K ← EEIS.compile(δ_f_req, fused, ξ_exec, Z_env, π_geo, K_safe^α)
⑦ 执行:   telemetry ← execute(K, u*)
⑧ 几何证据: EV-exec' ← GAE(telemetry, S_perc)；G_valid ← check_anchor(EV-exec')
⑨ 校准:   α ← CPC.update_aci(G_valid, anchor)；γ ← min(γ_cal, γ_obs)
⑩ 融合:   M, fused, D⁺ ← xmodal_fuse_plus(M, region, inf, EV-exec')
⑪ Return: (x̂, K, γ, O, EV-exec', S_perc.status)
```

**定义 168（信息预算 B_info 与 PCE+++++）** B_info=(B_perc, B_state, B_geo, B_probe)：
- **B_perc**：点云/TSDF 帧率、深度有效像素比、感知算力；
- **B_state**：估计器更新频率、因子图规模、协方差预算；
- **B_geo**：几何地图内存、局部 patch 半径、历史帧数；
- **B_probe**：探测次数、探测位移能量、风险预算。

VOI 扩展：
```
voi_info(π) = VOI_meta_pessimistic(π) + λ_ig·IG(π) − cost_cog − cost_exec − cost_perc
cost_perc = λ_depth·Depth_cost + λ_state·State_cost + λ_geo·Geo_mem_cost
```

### IP-161 GPC（几何先验阻抗编译）

```python
class GeometryPriorCompiler:
    def __init__(self, E_star=1e6, nu=0.3, k_min=50.0, k_max=5000.0):
        self.E_star, self.nu = E_star, nu
        self.k_min, self.k_max = k_min, k_max

    def contact_manifold(self, mesh, goal_point):
        p, n = mesh.closest_point_and_normal(goal_point)
        k1, k2 = mesh.principal_curvatures(p)
        R_c = frame_from_normal(n)
        R_obj = 1.0 / max(abs(k1), 1e-6)
        R_env = 1.0 / max(abs(k2), 1e-6)
        R_eff = 1.0 / (1.0 / R_obj + 1.0 / R_env)
        mu_hat = material_friction_estimate(mesh, p)
        return ContactGeometry(p=p, R_c=R_c, kappa=(k1, k2),
                               R_eff=R_eff, mu=mu_hat)

    def compile(self, g, F_n_nom):
        a = (3.0 * F_n_nom * g.R_eff / (4.0 * self.E_star)) ** (1.0 / 3.0)
        k_n = np.clip(2.0 * self.E_star * a, self.k_min, self.k_max)
        k_t = k_n * (2.0 * (1.0 - self.nu)) / (2.0 - self.nu)
        K = g.R_c @ np.diag([k_n, k_t, k_t]) @ g.R_c.T
        Sigma = g.R_c @ np.diag([(0.2 * k_n) ** 2,
                                 (0.3 * k_t) ** 2,
                                 (0.3 * k_t) ** 2]) @ g.R_c.T
        return K, Sigma
```

### IP-162 OASE（可观测性感知状态估计）

```python
class ObservabilityAwareEstimator:
    def __init__(self, sigma_z, lambda_ref, O_min=0.15, sigma_floor=0.05):
        self.sigma_z, self.lambda_ref = sigma_z, lambda_ref
        self.O_min, self.sigma_floor = O_min, sigma_floor
        self.x = np.zeros(8)

    def update(self, z, u):
        H = self.jacobian(z, u)
        J = H.T @ np.linalg.inv(self.sigma_z) @ H
        eigval, eigvec = np.linalg.eigh(J)
        eigval = np.maximum(eigval, 1e-12)
        Sigma_crb = eigvec @ np.diag(1.0 / eigval) @ eigvec.T
        K_gain = Sigma_crb @ H.T @ np.linalg.inv(self.sigma_z)
        self.x = self.x + K_gain @ (z - self.h(self.x, u))
        O = float(eigval.min() / self.lambda_ref)
        gamma_obs = min(1.0, O / self.O_min)
        return self.x, self.inflate(Sigma_crb), O, gamma_obs

    def inflate(self, Sigma):
        eigval, eigvec = np.linalg.eigh(Sigma)
        eigval = np.maximum(eigval, self.sigma_floor ** 2)
        return eigvec @ np.diag(eigval) @ eigvec.T
```

### IP-163 APO（主动探测）

```python
def select_probe(x_hat, J_prior, mu_hat, budget, lam_r=2.0):
    best_u, best_score = None, -np.inf
    Jp_inv_sqrt = matrix_inv_sqrt(J_prior)
    for u in sample_safe_probes(mu_hat, budget):
        if not safe_barrier(u, mu_hat):
            continue
        J_u = expected_fisher(x_hat, u)
        M = np.eye(len(x_hat)) + Jp_inv_sqrt @ J_u @ Jp_inv_sqrt
        info_gain = 0.5 * np.linalg.slogdet(M)[1]
        risk = slip_risk(u, mu_hat) + damage_risk(u, x_hat)
        score = info_gain - lam_r * risk
        if score > best_score:
            best_u, best_score = u, score
    return best_u, best_score
```

```python
def build_geometric_evidence(ev_exec, S_perc, f_meas):
    p_w = S_perc.to_world(ev_exec.contact_point)
    n_w, _ = S_perc.normal_at(p_w)
    f_hat = f_meas / max(np.linalg.norm(f_meas), 1e-9)
    r_geo = np.arccos(np.clip(np.dot(-f_hat, n_w), -1.0, 1.0))
    d_surf = S_perc.distance(p_w)
    anchor = GeoAnchor(p_w, n_w, f_hat, r_geo, d_surf,
                       S_perc.anchor_covariance(p_w))
    return ev_exec._replace(anchor=anchor)

def geometric_valid(ev, eps_geo=0.35, d_tol=0.01, alpha=0.05):
    a = ev.anchor
    return (seq_hash_valid(ev)
            and a.r_geo <= eps_geo
            and a.d_surf <= d_tol
            and within_conformal(a, alpha))
```

### IP-165 CPC（共形校准）

```python
class ConformalCalibrator:
    def __init__(self, alpha=0.05, eta=0.01):
        self.alpha0, self.alpha, self.eta = alpha, alpha, eta
        self.scores = []

    def threshold(self):
        n = len(self.scores)
        level = np.ceil((n + 1) * (1.0 - self.alpha)) / n
        return float(np.quantile(self.scores, min(level, 1.0)))

    def predict_set(self, model, obs):
        q = self.threshold()
        return [y for y in model.labels
                if nonconformity(model, obs, y) <= q]

    def update_aci(self, y_obs, pred_set):
        err = 0.0 if y_obs in pred_set else 1.0
        self.alpha = float(np.clip(
            self.alpha + self.eta * (self.alpha0 - err), 1e-3, 0.5))
```

```python
def propagate(perception_cov, g, K_safe, alpha=0.05):
    G = jacobian_geometry_to_impedance(g)
    Sigma_K = G @ perception_cov @ G.T + model_cov(g)
    d = K_safe.dim
```

### IP-167 PSEC（闭环算子）

```python
def psec_loop(M, goal, intent, delta_f_req):
    S_perc, zeta, Sigma_zeta = update_3d_perception(
        M.depth, M.rgb, M.T_extr)
    if (not S_perc.valid) or M.budget.perc_exhausted():
        pi_geo, K_safe_a = fallback_prior(M), M.K_safe
        O, gamma_obs = 0.0, 0.0
    else:
        g = M.gpc.contact_manifold(S_perc.mesh, goal)
        K_geo, Sigma_geo = M.gpc.compile(g, M.F_nom)
        x_hat, Sigma_x, O, gamma_obs = M.oase.update(M.wrench, M.u)
        u = (M.apo.select(x_hat, M.J_prior, g.mu, M.budget)
             if O < M.O_min else None)
        Sigma_K, K_safe_a = M.upc.propagate(
            Sigma_zeta + Sigma_geo, g, M.K_safe)
        pi_geo = GaussianPrior(K_geo, Sigma_K)
    M, fused, Dp, EV, cert = closed_loop_exec_probe(
        M, M.cp, delta_f_req, M.budget, pi_geo, K_safe_a)
    EVp = M.gae.build(EV, S_perc, M.wrench)
    gv = M.gae.valid(EVp)
    M.cpc.update_aci(gv, M.cpc.predict_set(M.scene_model, fused))
    gamma = min(M.cpc.confidence(fused), gamma_obs)
    if not gv:
        M = request_reprobe_or_conservative(M)
    return M, fused, Dp, EVp, gamma, O
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GPC | O(log N_mesh) 最近点 + O(1) 局部曲率 | O(local patch) | 若位姿误差 ≤ e_pose、重建误差 ≤ e_surf，则 ‖K_geo−K_true‖_F ≤ L_K(e_pose+e_surf)+O(κ²) |
| OASE | O(d_x³ + m·d_x²)/更新 | O(d_x²) | Cramér–Rao Σ_x ⪰ J⁻¹；不可观测方向 σ_j ≥ σ_floor |
| APO | O(|U|·(d³+H))/探测 | O(d²) | 探测满足 barrier；O<O_min ⇒ 被动 |
| GAE | O(log N_mesh)/锚点 | O(1)/EV | 几何伪证误收率 ≤ α_geo |
| CPC | O(n log n) 校准，O(1) 在线 | O(n) | 覆盖 ≥ 1−α；ACI 下 ≥ 1−α−ε |
| UPC | O(d_K³) | O(d_K²) | P(K∈K_safe) ≥ 1−α |

**正确性定理（PSEC）**：

5. **预算安全**：任一 B_info 分量耗尽，触发对应降级；退化为第 60 轮 SGEC 的能力下界。

### IP-161 GPC（几何先验阻抗编译）

```python
class GeometryPriorCompiler:
    def __init__(self, E_star=1e6, nu=0.3, k_min=50.0, k_max=5000.0):
        self.E_star, self.nu = E_star, nu
        self.k_min, self.k_max = k_min, k_max

    def contact_manifold(self, mesh, goal_point):
        p, n = mesh.closest_point_and_normal(goal_point)
        k1, k2 = mesh.principal_curvatures(p)
        R_c = frame_from_normal(n)
        R_obj = 1.0 / max(abs(k1), 1e-6)
        R_env = 1.0 / max(abs(k2), 1e-6)
        R_eff = 1.0 / (1.0 / R_obj + 1.0 / R_env)
        mu_hat = material_friction_estimate(mesh, p)
        return ContactGeometry(p=p, R_c=R_c, kappa=(k1, k2),
                               R_eff=R_eff, mu=mu_hat)

    def compile(self, g, F_n_nom):
        a = (3.0 * F_n_nom * g.R_eff / (4.0 * self.E_star)) ** (1.0 / 3.0)
        k_n = np.clip(2.0 * self.E_star * a, self.k_min, self.k_max)
        k_t = k_n * (2.0 * (1.0 - self.nu)) / (2.0 - self.nu)
        K = g.R_c @ np.diag([k_n, k_t, k_t]) @ g.R_c.T
        Sigma = g.R_c @ np.diag([(0.2 * k_n) ** 2,
                                 (0.3 * k_t) ** 2,
                                 (0.3 * k_t) ** 2]) @ g.R_c.T
        return K, Sigma
```

### IP-162 OASE（可观测性感知状态估计）

```python
class ObservabilityAwareEstimator:
    def __init__(self, sigma_z, lambda_ref, O_min=0.15, sigma_floor=0.05):
        self.sigma_z, self.lambda_ref = sigma_z, lambda_ref
        self.O_min, self.sigma_floor = O_min, sigma_floor
        self.x = np.zeros(8)

    def update(self, z, u):
        H = self.jacobian(z, u)
        J = H.T @ np.linalg.inv(self.sigma_z) @ H
        eigval, eigvec = np.linalg.eigh(J)
        eigval = np.maximum(eigval, 1e-12)
        Sigma_crb = eigvec @ np.diag(1.0 / eigval) @ eigvec.T
        K_gain = Sigma_crb @ H.T @ np.linalg.inv(self.sigma_z)
        self.x = self.x + K_gain @ (z - self.h(self.x, u))
        O = float(eigval.min() / self.lambda_ref)
        gamma_obs = min(1.0, O / self.O_min)
        return self.x, self.inflate(Sigma_crb), O, gamma_obs

    def inflate(self, Sigma):
        eigval, eigvec = np.linalg.eigh(Sigma)
        eigval = np.maximum(eigval, self.sigma_floor ** 2)
        return eigvec @ np.diag(eigval) @ eigvec.T
```

```python
def select_probe(x_hat, J_prior, mu_hat, budget, lam_r=2.0):
    best_u, best_score = None, -np.inf
    Jp_inv_sqrt = matrix_inv_sqrt(J_prior)
    for u in sample_safe_probes(mu_hat, budget):
        if not safe_barrier(u, mu_hat):
            continue
        J_u = expected_fisher(x_hat, u)
        M = np.eye(len(x_hat)) + Jp_inv_sqrt @ J_u @ Jp_inv_sqrt
        info_gain = 0.5 * np.linalg.slogdet(M)[1]
        risk = slip_risk(u, mu_hat) + damage_risk(u, x_hat)
        score = info_gain - lam_r * risk
        if score > best_score:
            best_u, best_score = u, score
    return best_u, best_score
```

### IP-165 CPC（共形校准）

```python
class ConformalCalibrator:
    def __init__(self, alpha=0.05, eta=0.01):
        self.alpha0, self.alpha, self.eta = alpha, alpha, eta
        self.scores = []

    def threshold(self):
        n = len(self.scores)
        level = np.ceil((n + 1) * (1.0 - self.alpha)) / n
        return float(np.quantile(self.scores, min(level, 1.0)))

    def predict_set(self, model, obs):
        q = self.threshold()
        return [y for y in model.labels
                if nonconformity(model, obs, y) <= q]

    def update_aci(self, y_obs, pred_set):
        err = 0.0 if y_obs in pred_set else 1.0
        self.alpha = float(np.clip(
            self.alpha + self.eta * (self.alpha0 - err), 1e-3, 0.5))
```

```python
def propagate(perception_cov, g, K_safe, alpha=0.05):
```
