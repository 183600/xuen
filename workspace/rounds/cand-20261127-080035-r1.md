### 第 1 轮灵感驱动研究记录（v26：从「语义-重构-协同」推进到「常识-传动」闭环）

**灵感词**：常识推理、谐波减速器

**直觉与动机**：
前几轮证书链从「感知-合规-能量」推进到「结构-力学」，再到「语义-重构-协同」，但真实部署中两条最贴近物理世界的裂缝仍未补上：

(1) **语义正确不等于常识正确**。机器人可以准确识别「杯子、水壶、桌面、刀具」，却仍可能把满杯倒扣、把重物摞在易碎品上、用刀背切菜、把只能外拉的抽屉往里推、把液体倒进已密封的容器。这类错误不是感知误差（SMC 的标签覆盖和 Hausdorff 一致性都可能通过），而是**物理/任务常识不变量**被违反。现有证书链无法排除「语义对了、做法蠢了」。

(2) **关节执行不等于理想力矩源**。谐波减速器（strain wave gearing）凭近零背隙、大减速比成为协作臂与人形关节主流，但其非线性扭转刚度、迟滞、lost motion、传动误差、柔性与疲劳寿命，会让 FCC 的无源性/带宽证书与 LSC 的刚度证书在**关节尺度**失真——「证书说无源，关节却在迟滞与柔性里储能、相位滞后、定位偏差」。

核心洞见：**常识推理是计划层的不变量证书，谐波减速器是执行层的非理想传动证书；前者回答「这件事该不该做」，后者回答「这个动作做不做得动、做得准不准、能撑多久」。二者必须联合验证，否则会出现「常识合理但动力学不可行」或「动力学可行但常识荒谬」的证书盲区。**

**形式化目标**：
1. 定义物理常识证书（PCC）：常识知识库 K_cs 编译为时序逻辑不变量 φ_cs；计划 π 需给出归纳不变式 Inv_cs，满足 Init⇒Inv_cs、Inv_cs∧T⇒Inv_cs′、Inv_cs⇒φ_cs；感知→原子 grounding 映射 g 附 conformal 覆盖 ℙ(φ_cs | g) ≥ 1−α_cs。
2. 覆盖四类常识：affordance（工具/容器正确用法）、守恒（支撑链/容纳/重力/不可逆因果）、规范（人机安全/私有区）、反事实自检（最小更优替代与荒谬度 d_cs）。
3. 定义谐波传动证书（HDTC）：在参数置信集 Θ_HD 上给出 lost motion δ_lm(T)、非线性刚度区间 [K_t⁻,K_t⁺]、每周期迟滞耗能 ΔE_h、传动误差 ε_te、效率 η、Miner 损伤 D、L10 寿命的鲁棒界。
4. 用能量存储函数证明「电机力矩→关节速度」在 Θ_HD 上无源；用最坏情况相位/幅值裕度证明带宽不降；用区间算术给出定位误差上界。
5. 构建认知-传动统一准入门（CH-USC）：SRC-USC ∪ PCC ∪ HDTC 九证一体，Exec_v26 ⊆ Exec_v25 ⊆ …；新增「常识违规」「传动证书失效」两条退化路径，并显式处理耦合约束（常识允许的动作必须落在 HDTC 的力矩/速度包络内）。

# ============================================================
# IP-448 Physical Commonsense Certificate (PCC) — 物理常识证书
# ============================================================
@dataclass
class PhysicalCommonsenseCertificate:
    kb: 'CommonsenseKB'
    invariants: list['TemporalFormula']        # φ_cs
    grounding: 'ConformalGrounding'            # g + 离线校准
    alpha_cs: float = 0.05                     # 族错误率
    tau_cs: float = 0.0                        # 荒谬度阈值
    affordances: dict = field(default_factory=dict)  # type -> {(action, region)}
    transition_model: Optional['TransitionModel'] = None

    def __post_init__(self):
        # 归纳不变式取 φ_cs 在 K_cs 上的最强可归纳强化
        self.phi = conjunction(self.invariants)
        self.inv = self.kb.strongest_inductive(self.phi)

    def verify_conformal_grounding(self, observations) -> bool:
        """ℙ(φ_cs | g) ≥ 1-α_cs：所需原子须落入 conformal 预测集"""
        required = self.kb.required_atoms(self.invariants)
        alpha_atom = self.alpha_cs / max(1, len(required))   # Bonferroni
        pred = self.grounding.predict(observations)          # atom -> set[bool]
        for atom in required:
            s = pred.get(atom)
            # 未知 / 不确定一律保守拒证（闭世界安全默认）
            if s is None or s != {True}:
                return False
        return self.grounding.empirical_coverage() >= 1.0 - alpha_atom

    def verify_affordance(self, plan: 'Plan') -> bool:
        """∀(t,a,o): a ∈ A(o)，且接触区域 region 合法"""
        for act in plan.actions:
            if act.object is None:
                continue
            A = self.affordances.get(act.object.type, set())
            if not any(kind == act.kind and region_match(region, act.region)
                       for kind, region in A):
                return False
            if act.kind in ('grasp', 'cut', 'strike') and not self._contact_ok(act):
                return False
        return True

    def verify_conservation(self, plan: 'Plan') -> bool:
        """支撑链 / 容纳 / 重力 / 不可逆因果"""
        for t in range(len(plan.states) - 1):
            s, s2 = plan.states[t], plan.states[t + 1]
            act = plan.actions[t]
            # 1) 支撑：非飞行物体必须有到地面的支撑链
            for o in s2.objects:
                if o.type not in FLYING and not self.kb.supported(o, s2):
                    return False
            # 2) 容纳：容器内物体不得凭空消失
            for o in s.objects:
                if self.kb.in_container(o, s) and not self.kb.in_container(o, s2):
                    if not (act.object == o and act.kind == 'take_out'):
                        return False
            # 3) 不可逆：破碎/泄漏单调，除非显式修复
            for o in s2.objects:
                if self.kb.broken(o, s) and not self.kb.broken(o, s2):
                    if act.kind not in ('repair', 'replace'):
                        return False
            # 4) 重力/液体常识：倒向密封容器、倒扣含液杯
            if act.kind == 'pour' and self.kb.closed(act.target, s):
                return False
            if act.kind == 'place' and act.inverted and \
               self.kb.contains_liquid(act.object, s):
                return False
            if act.kind == 'stack' and self.kb.fragile(act.target, s) and \
               self.kb.heavy(act.object, s):
                return False
        return True

    def verify_norms(self, plan: 'Plan') -> bool:
        """人机安全 / 私有区 / 高代价不可逆动作需授权"""
        for s in plan.states:
            for o in s.objects:
                if self.kb.human_occupied(o) and \
                   self.kb.distance(s.robot, o) < self.kb.personal_space:
                    return False
                if self.kb.private_zone(o) and self.kb.entered(s.robot, o):
                    return False
        self.last_norm_violations = self.kb.norm_violations(plan.states[-1])
        return len(self.last_norm_violations) == 0

    def verify_inductive_invariant(self, plan: 'Plan') -> bool:
        """Init ⇒ Inv, Inv ∧ T ⇒ Inv', Inv ⇒ φ"""
        if self.transition_model is None:
            return False
        if not self._eval(self.inv, plan.states[0]):
            return False
        for t in range(len(plan.states) - 1):
            s, act, s2 = plan.states[t], plan.actions[t], plan.states[t + 1]
            if not self._eval(self.inv, s):
                return False
            if not self._eval(self.inv, s2):
                return False
            if not self.transition_model.consistent(s, act, s2, tol=1e-3):
                return False
            if not self._eval(self.phi, s2):
                return False
        return True

    def verify_counterfactual(self, plan: 'Plan') -> bool:
        """无「更不荒谬的显然替代」；且 d_cs(π) ≥ τ_cs"""
        base = self.kb.absurdity(plan)
        if base < self.tau_cs:
            return False
        for t, act in enumerate(plan.actions):
            for alt in self.kb.nearest_alternatives(act, k=3):
                if self.kb.absurdity(plan.replace(t, alt)) < base:
                    return False   # 存在明显更优做法 => 当前做法愚蠢
        return True

    def verify_all(self, plan: 'Plan', observations) -> bool:
        return (self.verify_conformal_grounding(observations) and
                self.verify_affordance(plan) and
                self.verify_conservation(plan) and
                self.verify_norms(plan) and
                self.verify_inductive_invariant(plan) and
                self.verify_counterfactual(plan))

    def _eval(self, formula, state) -> bool:
        return self.kb.eval(formula, state)

    def _contact_ok(self, act) -> bool:
        return self.kb.contact_force_ok(act.object, act.region, act.force_limit)

# IP-449 Harmonic Drive Transmission Certificate (HDTC) — 谐波传动证书
# ============================================================
@dataclass
class HarmonicDriveTransmissionCertificate:
    ratio: float                              # N
    theta_set: 'ParameterConfidenceSet'       # Θ_HD（盒/多面体/样本）
    delta_lm: Callable[[Tensor], Tensor]      # δ_lm(T)
    K_min: Callable[[Tensor], Tensor]         # K_t^-(δ,T)
    K_max: Callable[[Tensor], Tensor]         # K_t^+(δ,T)
    hysteresis_energy: float                  # ΔE_h / 周期
    eps_te: float                             # 传动误差纹波上界
    eta_min: float
    T_rated: float
    T_peak: float
    L10: float
    duty: 'DutyCycle'                         # {(n_i, T_i, omega_i)}
    e_pos_max: float = 1e-3
    PM_min: float = 0.8727                    # 50°
    GM_min: float = 6.0                       # dB
    D_max: float = 1.0
    B_t_min: float = 0.0

    def verify_lost_motion(self, torque_hist: Tensor) -> bool:
        """δ_lm(T) ≤ δ_lm_max 且测量值落在证书内"""
        for T in torque_hist.flatten():
            if float(self.delta_lm(T)) > self.delta_lm_max:
                return False
        return True

    def verify_passivity(self, env: 'JointEnv') -> bool:
        """V = ½Jm q̇m² + ½Jl q̇l² + ½Kt δ² ≥ 0
           V̇ = τm q̇m − τext q̇l − Bt δ̇² − P_hyst
              ≤ τm q̇m − τext q̇l
           只需 Kt≥0, Bt≥0, P_hyst≥0（ΔE_h≥0）"""
        for theta in self.theta_set.samples:
            if theta.K_min < 0.0:
                return False
            if theta.B_t < self.B_t_min:
                return False
            if theta.hysteresis_energy < 0.0:     # 迟滞必须净耗能
                return False
            if not env.compatible(theta):          # 惯量/采样/时延匹配
                return False
        return True

    def verify_bandwidth_margin(self) -> bool:
        """Θ_HD 上最坏二惯量+迟滞闭环的相位/幅值裕度"""
        worst_pm, worst_gm = float('inf'), float('inf')
        for theta in self.theta_set.samples:
            pm, gm = closed_loop_margins(
                Jm=theta.Jm, Jl=theta.Jl,
                K_t=float(self.K_min(theta.delta_op)),  # 最软刚度相位滞后最大
                B_t=theta.B_t, N=self.ratio,
                delay=theta.sensor_delay)
            worst_pm = min(worst_pm, pm)
            worst_gm = min(worst_gm, gm)
        self._last_margins = (worst_pm, worst_gm)
        return worst_pm >= self.PM_min and worst_gm >= self.GM_min

    def verify_position_accuracy(self) -> bool:
        """|q_l − q_m/N| ≤ δ_lm(T_peak) + T_peak/K_min + ε_te + 热漂移"""
        for theta in self.theta_set.samples:
            err = (float(self.delta_lm(theta.T_peak))
                   + theta.T_peak / float(self.K_min(theta.delta_op))
                   + self.eps_te + theta.thermal_drift)
            if err > self.e_pos_max:
                return False
        return True

    def verify_life(self) -> bool:
        """Miner: D = Σ n_i/N_i(T_i,ω_i) ≤ D_max；L10 ≥ L10_req"""
        damage = 0.0
        for n_i, T_i, w_i in self.duty.entries:
            damage += n_i / self._sn_life(T_i, w_i)
        self._last_damage = damage
        return damage <= self.D_max and self.L10 >= self.duty.L10_req

    def verify_torque_envelope(self, tau_hist: Tensor) -> bool:
        """峰值 ≤ T_peak 且 RMS ≤ T_rated"""
        return (float(tau_hist.abs().max()) <= self.T_peak and
                float(tau_hist.pow(2).mean().sqrt()) <= self.T_rated)

    def verify_all(self, torque_hist: Tensor, env: 'JointEnv') -> bool:
        return (self.verify_lost_motion(torque_hist) and
                self.verify_passivity(env) and
                self.verify_bandwidth_margin() and
                self.verify_position_accuracy() and
                self.verify_life() and
                self.verify_torque_envelope(torque_hist))

    def _sn_life(self, T: float, omega: float) -> float:
        # 柔性轮 S-N 曲线 + 转速修正（伪实现：标注为离线辨识表）
        return self.duty.sn_curve.life(T, omega)

# 常识-传动耦合校验：堵住两类证书之间的盲区
# ============================================================
def verify_cognitive_mechanical_coupling(
        pcc: PhysicalCommonsenseCertificate,
        hdtc: HarmonicDriveTransmissionCertificate,
        plan: 'Plan',
        tau_hist: Tensor,
        contact_wrench: Optional[Tensor] = None) -> bool:
    """常识判为可行的每个接触动作，其力矩/速度/接触力需求
       必须落在 HDTC 与 FCC 的联合可行包络内。"""
    for act, tau in zip(plan.actions, tau_hist):
        if act.kind not in ('grasp', 'pour', 'cut', 'strike', 'stack'):
            continue
        if abs(float(tau.abs().max())) > hdtc.T_peak:
            return False
    if contact_wrench is not None:
        # 接触力经传动折算后不得超峰值，且不破坏 FCC 无源界
        tau_contact = contact_wrench.norm(dim=-1).max() * plan.tool_lever
        if float(tau_contact) > hdtc.T_peak:
            return False
    return True

@dataclass
class CognitiveTransmissionUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    pcc: PhysicalCommonsenseCertificate
    hdtc: HarmonicDriveTransmissionCertificate

    def admits(self, multi_plan: 'MultiRobotPlan', sensor_data: dict,
               gt_entities: Optional[list] = None,
               queries: Optional[list[str]] = None,
               retrieved: Optional[list[list]] = None) -> bool:
        # 1) v25 七证（语义-重构-协同-结构-力学）
        if not self.src_usc.admits(multi_plan, sensor_data, gt_entities,
                                   queries, retrieved):
            return False
        # 2) 常识证书（共享计划）
        if not self.pcc.verify_all(multi_plan.plan,
                                   sensor_data['semantic_observations']):
            return False
        # 3) 传动证书（逐关节）
        for i in range(self.src_usc.mcc.N):
            for j, hdtc_j in enumerate(self.hdtc if isinstance(self.hdtc, list)
                                       else [self.hdtc]):
                if not hdtc_j.verify_all(sensor_data['tau_hist'][i],
                                         sensor_data['joint_env'][i]):
                    return False
        # 4) 常识-传动耦合
        for i in range(self.src_usc.mcc.N):
            if not verify_cognitive_mechanical_coupling(
                    self.pcc, self.hdtc, multi_plan.plan,
                    sensor_data['tau_hist'][i],
                    sensor_data.get('contact_wrench', [None])[i]):
                return False
        return True

# 端到端流水线：在 v25 多机流水线后挂载认知-传动证书
# ============================================================
class CognitiveTransmissionPipeline:
    def __init__(self, config: dict):
        self.ch_usc = CognitiveTransmissionUnifiedCertificate(
            src_usc=config['src_usc'],
            pcc=PhysicalCommonsenseCertificate(
                kb=config['commonsense_kb'],
                invariants=config['invariants'],
                grounding=config['grounding'],
                alpha_cs=config['alpha_cs'],
                tau_cs=config['tau_cs'],
                affordances=config['affordances'],
                transition_model=config['transition_model'],
            ),
            hdtc=[HarmonicDriveTransmissionCertificate(**p)
                  for p in config['hdtc_params']],
        )
        self.ipam.register_module("pcc", ["IP-448"],
            ["commonsense_temporal_invariant", "conformal_grounding",
             "affordance_conservation_norms", "counterfactual_absurdity"])
        self.ipam.register_module("hdtc", ["IP-449"],
            ["lost_motion_bound", "nonlinear_stiffness_hysteresis",
             "passivity_storage_function", "robust_bandwidth_life"])
        self.ipam.register_module("ch_usc", ["IP-450"],
            ["nine_certificate_gate", "cognitive_mechanical_coupling",
             "commonsense_transmission_monotonic_chain"])

    def step(self, multi_sensor_data: dict, cloud_update=None):
        # 1) v25 全链
        admitted, info = self.v25_pipeline.step(multi_sensor_data, cloud_update)
        if not admitted:
            return False, info
        # 2) 常识证书
        plan = info['multi_plan'].plan
        cs_ok = self.ch_usc.pcc.verify_all(
            plan, multi_sensor_data['semantic_observations'])
        # 3) 传动证书 + 耦合
        hd_ok = all(
            hdtc.verify_all(multi_sensor_data['tau_hist'][i],
                            multi_sensor_data['joint_env'][i])
            for i in range(self.ch_usc.src_usc.mcc.N)
            for hdtc in self.ch_usc.hdtc)
        coup_ok = all(
            verify_cognitive_mechanical_coupling(
                self.ch_usc.pcc, self.ch_usc.hdtc[0], plan,
                multi_sensor_data['tau_hist'][i],
                multi_sensor_data.get('contact_wrench', [None])[i])
            for i in range(self.ch_usc.src_usc.mcc.N))
        if not (cs_ok and hd_ok and coup_ok):
            return False, {'reason': 'CH_USC_reject',
                           'commonsense_ok': cs_ok,
                           'transmission_ok': hd_ok,
                           'coupling_ok': coup_ok,
                           'v25_info': info}
        info['ch_usc'] = {'commonsense_ok': cs_ok,
                          'transmission_ok': hd_ok,

        return True, info

## 3. 正确性论证（增量）

### 引理 13（常识证书的「模型相对」可靠性）
**陈述**：设校准集与测试观测可交换，且转移模型与原子集合覆盖真实语义。若 `PCC.verify_all(...) = True`，则计划 π 满足常识不变量 φ_cs 的概率 ≥ 1−α_cs。

**证明**：
1. `verify_conformal_grounding` 对每个所需原子用 Bonferroni 分摊 α_cs/|Atoms_req|，conformal 边际覆盖保证每个原子 ℙ(真值∈预测集) ≥ 1−α_cs/|Atoms_req|，联合界给出全体原子覆盖 ≥ 1−α_cs。
2. 归纳不变式三条件（Init⇒Inv、Inv∧T⇒Inv′、Inv⇒φ）由数学归纳法保证所有可达状态满足 φ_cs；affordance、守恒、规范均为 φ_cs 的合取项，逐项为真则 φ_cs 真。
3. 反事实检查额外排除「满足不变量但存在明显更优/更合理替代」的退化计划，其可靠性取决于替代集构造的完备性，故结论是**模型相对**而非绝对真。
4. 未知/不确定原子被保守判为拒证（闭世界默认），只会降低通过率、不会放松保证。
∎

### 引理 14（谐波传动证书的鲁棒无源-精度-寿命保证）
**陈述**：若 `HDTC.verify_all(...) = True`，则对 Θ_HD 中所有 θ，二惯量-迟滞关节满足：(1) 对 (τ_m, τ_ext) 无源；(2) 定位误差 ≤ e_pos_max；(3) 最坏相位/幅值裕度 ≥ (PM_min, GM_min)；(4) Miner 损伤 D ≤ D_max 且 L10 达标；(5) 力矩在包络内。

**证明**：
1. 取 V = ½J_m q̇_m² + ½J_l q̇_l² + ½K_t δ² ≥ 0。沿二惯量动力学求导，V̇ = τ_m q̇_m − τ_ext q̇_l − B_t δ̇² − P_hyst。当 K_t≥0、B_t≥0、ΔE_h≥0（迟滞净耗能）时 V̇ ≤ τ_m q̇_m − τ_ext q̇_l，按无源性定义即证。
2. 定位误差由 lost motion、弹性变形 T/K_min、传动误差与热漂移四项最坏情况相加得到，区间算术保证对任意 θ∈Θ_HD 的上界有效。
3. 带宽裕度对每个采样 θ 计算，取最坏值；若 Θ_HD 为盒子且裕度对参数单调，检查顶点即可，否则用区间分支定界加密。
4. 寿命按 Miner 线性累积与柔性轮 S-N 曲线计算；力矩峰值/RMS 由包络检查保证不越过短时/额定限。
∎

### 引理 15（常识-传动的耦合无盲区）
**陈述**：`PCC.verify_all ∧ HDTC.verify_all` 不足以推出 `CH-USC.admits`；必须额外验证 `Coupling`，否则存在「常识允许但传动做不动」与「传动可行但常识荒谬」两类反例。

**证明**：
- 反例 A：常识判定「把满杯平稳放到高处」合法（affordance、守恒均通过），但所需腕部峰值力矩 > T_peak 或 RMS > T_rated；单证各自通过、联合执行却饱和/失步。故需 `verify_cognitive_mechanical_coupling` 检查力矩/接触力包络。
- 反例 B：传动证书全部通过（任意平滑轨迹都可行），但计划把刀背当刀刃、把重物压在易碎品上；HDTC 不编码任务语义，无法拒绝。故需 PCC。
- 因而两类证书不是彼此蕴含，CH-USC 以「PCC ∧ HDTC ∧ Coupling」三合取消除盲区。
∎

### 引理 16（九位一体单调退化链终局延伸）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：CH-USC 的准入条件为 v25 条件与 Fil_cs、Fil_hd、Coupling 的合取，故 Exec_v26 ⊆ Exec_v25。新增退化路径：
- 常识违规/grounding 失效 → PCC 拒证 → 退回闭世界保守计划（仅执行原子已确定可满足的几何动作，禁接触类高常识动作），保留 v25 单机与群体安全。
- 传动证书失效（lost motion 超限/无源性或裕度不足/寿命超限/力矩跃出包络）→ HDTC 拒证 → 关节降额（T_peak_eff ≤ κT_peak）或锁关节，退回 v25 的保守运动包络。
- 耦合失败 → 拒绝该接触动作，改用非接触替代或降低负载；交集运算下单调性保持。
∎

### 定理（CH-USC 九证准入门的安全-合规-可部署-可保护-结构-语义-重构-协同-常识-传动完备性）
**陈述**：对任意多机计划 Π，`CH-USC.admits(Π) = True` ⟺ Π 同时满足 v25 的十项条件，并额外满足：

**证明**：直接由 `CH-USC.admits` 的合取结构与引理 1–16 可得。必要性：任一条件缺失即对应一类未被缓解的风险。充分性：v25 保证感知-结构-语义-协同闭环，PCC 保证计划层不违反常识不变量，HDTC 保证执行层非理想传动下仍无源、可达、可寿命运行，Coupling 保证两层不互相「甩锅」，共同构成从任务语义到关节传动的完整证书链。
