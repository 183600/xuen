# 第 2 轮（灵感循环 v2：「无刷电机」×「创新点提炼」）—— 从 10 个并列点到 3 个可辩护的核心创新

> 承接第 1 轮：UIP-01~10 是一次成功的**发散**，但还不是一次成功的**提炼**。本轮用「无刷电机」作为机制隐喻，去**替换第 1 轮方案里最脆弱的耦合**（用便宜反馈替代稠密 VLM 验看、用软换向替代硬切换）；用「创新点提炼」作为**压缩算子**（在可辩护性约束下剪枝/合并/重命名）。产出：CIP-1~3 + 2 个支撑件（SIP）+ 5 个封存项。

## 0. 先给直觉，再给严谨定义

### 0.1 「无刷电机」的直觉

有刷电机靠碳刷与换向器，在固定转角**机械地**硬切电流方向：会磨损、时序固定、不可编程。无刷电机把换向交给逆变器，由**转子位置反馈**决定何时换相；「无感」方案更进一步，用绕组**反电动势**估计转子位置，把霍尔传感器省掉。FOC（磁场定向控制）再把定子电流分解为**励磁 d 轴**与**转矩 q 轴**两个正交分量，独立给增益。

一句话直觉：**别用昂贵传感器做高频闭环，先用便宜信号连续估计，只在低置信/换相点才动用昂贵传感器；别硬切换，要按状态正交分解后连续控制。**

### 0.2 映射表（严格对应）

| 无刷电机概念 | 严格含义 | 本方案对应 |
|---|---|---|
| 碳刷/换向器 | 机械接触式、固定时序、会磨损 | 硬编码子目标状态机 / 固定 `if s=="done"` 时序 |
| 霍尔传感器 | 直接测转子位置，准但需额外器件与布线 | **稠密 VLM 进度验证器**（准但慢、贵、延迟方差大） |
| 反电动势 back-EMF | 转子运动在绕组感应的电压，可反推转速/位置 | **动作–结果残差**（指令动作 vs 实际本体变化、夹爪宽度/电流代理、帧差） |
| 无感控制 | 用反电动势估计位置，省去霍尔 | 用残差估计子目标进度；VLM **仅在低置信或换相候选点**启用 |
| 三相逆变/换向 | 按转子位置在相位间电子切换 | 按进度信念在**阶段专家**间软切换 |
| FOC 的 d/q 解耦 | 励磁与转矩正交、独立控制 | 动作分解为**任务进度 q / 扰动补偿 d** 两个正交子空间、独立增益 |
| 电流环–速度环–位置环 | 多时间尺度级联闭环 | 观测器（慢）/ 阶段权重（中）/ 动作输出（快）的多速率闭环 |

### 0.3 「创新点提炼」的直觉与严谨定义

直觉：十个点并列 = 没有点。评审只记得住一句「所以你的核心贡献是什么」。提炼不是写摘要，而是**带约束的压缩**。

严谨定义：对候选集 `C`，定义机制签名 `m(p) =（所用信号, 计算结构, 干预层）`，重叠度 `O(p,q) = |m(p)∩m(q)| / |m(p)∪m(q)|`；三元评分 `L`（对「平均成功率 + 步骤分」的杠杆）、`F`（选手 API/训练权限内的可行性）、`D`（相对最朴素基线的可辩护新颖性）。提炼算子 `D(·)`：
- 若 `O(p,q) ≥ τ` → **合并**（保留强者机制，吸收弱者的目标/信号）；
- 否则若 `L·F·D < θ` 或 `L·F < θ'` → **封存**；
- 仅保留**机制唯一、可一句话说清、且高分**的点为核心。
本轮目标：`10 → 3`（压缩比 3.3×），且**不丢排名杠杆**。

## 1. 第 1 轮诊断：为什么必须提炼

## 1. CIP-1 · 无感进度观测器 SPO

### 1.1 机制（直觉 → 形式）

**直觉**：不每一步都问 VLM「成了吗」，而是先看「我让它动，它到底动没动、怎么动」——像无刷电机从反电动势读转速。只有残差解释不了时，才叫 VLM 当霍尔传感器。

**形式化**。设最近 `k` 步指令块为 `A_{t-k:t}`，本体观测量（双臂关节/EE 位姿、夹爪宽度、可用电流代理）为 `q_t`。定义**残差反电动势**：

```
Δq_t = q_t − q_{t-k}
r_t  = Δq_t − Ĝ(A_{t-k:t}, q_{t-k})          # Ĝ：小型标称动力学模型
```

`r_t` 的三种签名决定进度假设：

| 残差签名 | 物理含义 | 对应决策 |
|---|---|---|
| `‖r_t‖` 小且与指令同向 | 自由运动，指令被跟随 | 进度推进 |
| `‖r_t‖` 大、持续、方向与指令相反 | 受阻（stall / 抓取失败） | 触发重试 |
| `‖r_t‖` 大、非结构化、跨模态突变（人/异物入镜） | 外部干扰 | 暂停–等待–恢复 |

**进度信念**：`b_t = h_θ(r_{t-H:t}, Δgripper_t, framediff_t, e_lang) ∈ Δ^{K}`（每个任务 3–6 个阶段的单纯形分布）；**置信度** `κ_t = 1 − H(b_t)/log K`。

**VLM 门控（霍尔回退）**：仅当 `κ_t < κ0`、或 `argmax b_t` 发生**换相**、或每 `m` 步兜底时调用 `V(o_t, l, g)`；融合 `b_t ← normalize(b_t^{obs} ⊙ b_t^{VLM})`。

### 1.2 关键：可观性条件（防止把「卡住」误判成「正常接触」）

定义阶段可分性 `S = min_{φ≠φ'} KL(p(r | φ) ‖ p(r | φ'))`。SPO 仅在 `S > ε` 时可区分「自由运动 / 受阻」。**准静态、重力主导**的慢速段 `S≈0` → 必须加**激励门控**：仅当指令速度/幅值超过 `v_min` 时才相信 stall 推断，否则**主动探动**（小幅 dither）或直接回退 VLM。这正对应无感控制在低速/零速时反电动势趋零、必须开环启动的问题。

### 1.3 伪代码

```python
class SPO:
    def __init__(self, policy, observer, vlm, G, k=4, H=8,
                 kappa0=0.35, m=10, vmin=0.02, R=2,
                 vlm_budget_ms=250):
        self.policy, self.obs, self.vlm, self.G = policy, observer, vlm, G
        self.k, self.H, self.kappa0, self.m = k, H, kappa0, m
        self.vmin, self.R, self.budget = vmin, R, vlm_budget_ms
        self.reset()

    def reset(self):
        self.policy.reset(); self.buf = []; self.q_hist = []
        self.phase, self.retry, self.step, self.vlm_cost = 0, 0, 0, 0.0

    def get_action(self, o):
        self._ingest(o)
        if not self.buf or self._commutate(o):
            self.buf = list(self.policy.get_action(o)[: self.k])
        act = self.buf.pop(0); self.step += 1
        return act

    def _ingest(self, o):
        self.q_hist.append(o.proprio)
        if len(self.q_hist) > self.H + self.k:
            self.q_hist.pop(0)

    def _commutate(self, o):
        if len(self.q_hist) <= self.k:
            return True
        dq = self.q_hist[-1] - self.q_hist[-1 - self.k]
        r  = dq - self.G(self.buf_actions(), self.q_hist[-1 - self.k])
        b  = self.obs(self._residual_window(r), o.gripper, o.framediff, o.lang)
        kappa = 1 - entropy(b) / math.log(len(b))
        # 低置信或到兜底步：启用“霍尔传感器”
        if (kappa < self.kappa0 or self.step % self.m == 0) \
                and self.vlm_cost + self.budget <= self.budget_total:
            b = fuse(b, self.vlm(o, self.lang, self.phase))
            self.vlm_cost += self.budget
        # 激励门控：低速时不做 stall 断言
        excited = norm(self._last_cmd()) > self.vmin
        if excited and self._stall(r, b):
            if self.retry < self.R:
                self.retry += 1; return True          # 重试
            self.phase += 1; self.retry = 0; return True
        if self._disturbance(r, o):
            return self._hold_and_resume(o)           # 干扰静默
        if kappa > self.kappa0 and argmax(b) > self.phase:
            self.phase = argmax(b); self.retry = 0; return True
        return len(self.buf) == 0
```

### 1.4 成本/延迟预算（可证）

期望 VLM 调用率 `≈ 1/m + P(κ<κ0) + P(换相)`；单步延迟 `L = L_policy + P_vlm·L_vlm`。通过选择 `m` 与 `κ0`，可把 `P95` 延迟压进可信度 SLA，同时保留「卡住必重试」的召回。**这是对第 1 轮「三重护栏」的机制级替代：不是给无限重试限流，而是先让大多数步根本不需要验证器。**

### 1.5 资源与落地

数据=32 个公开数据集回放（SIP-Bench）；算力=1 张推理卡跑策略 + 小观测器（GRU/TCN）+ 小 VLM 回退；接口=只需在 `get_action`/`reset` 内维护状态。步骤：① 拟合 `Ĝ`（线性 AR 或小 MLP，成功回放自监督）；② 弱标注阶段序列训 `h_θ`；③ 接激励门控与 VLM 回退；④ 回放调 `κ0/m/vmin`。

## 2. CIP-2 · 场定向动作分解 FOAD

### 2.1 机制

**直觉**：FOC 不直接控制三相电流，而是把电流投到「产生转矩」和「产生磁通」两个正交轴上分别控制。动作也一样：一部分维度**只该负责任务进度**（把杯子往杯架推），另一部分**只该吸收扰动**（背景变了、物体偏了、桌面反光）。混在一起学，泛化轴一变就全盘漂移。

**形式化**。编码器 `E: o → (z_q, z_d)`，动作头输出 `a = a_q + λ·a_d`，约束 `a_q ⟂ a_d`：

```
L = L_task(a)
  + α·L_inv(z_q; o, o⁺)                  # 在仅扰动变化的配对 (o,o⁺) 上不变
  + β·L_recon(x⁺; D(z_q, z_d))           # d 轴必须解释扰动差异
  + γ·‖a_qᵀ a_d‖²                        # 正交惩罚
  + δ·‖a_d‖₁                             # d 轴稀疏（只在需要时补偿）
```

其中 `o⁺` 由 SIP-Data 生成：同任务状态、换背景/平移物体/换未见实例。推理时按接触状态给 λ：自由运动 λ=1（充分补偿），接触丰富 λ↓（避免与接触力对抗，对应 FOC 的弱磁/限流思路）。

### 2.2 与第 1 轮的差异

- 原 UIP-05 用 VLM 解析三元组后**条件化**；本点把语义 grounding 压进 `z_q` 的**不变性目标**，不依赖显式三元组标注，减少级联解析错误。
- 原 UIP-10 在 joint/ee 间**硬仲裁**；本点把「抗位置泛化」与「抗抖动」变成 d/q 两个连续增益，仲裁变成**标量 λ 的调度**，无模式跳变。

### 2.3 可证伪判据

若在 5 泛化轴（位置/干扰物/背景/未见物品/人为干扰）上，`λ=0`（只用 q 轴）与完整 FOAD 的逐轴成功率差 ≤ 噪声，则 FOAD 的分解假设不成立，退回 UIP-05。

## 3. CIP-3 · 电子换向阶段专家 ECPE

### 3.1 机制

**直觉**：硬切换专家 = 有刷换向——在某个时刻「啪」地切过去，动作跳变、统计规律性异常。电子换向 = 按转子位置**提前、平滑、带重叠**地导通下一相。

**形式化**。阶段集 `Φ = {approach, contact, transport, release}`；专家 `π_φ` = 共享 backbone + LoRA_φ（满足「单模型」规则）。进度信念 `b_t` 来自 CIP-1，换相权重：

```
w_t = softmax(−β · d(b_t, e_φ)) ,  s.t.  w_t ∈ conv(相邻阶段对)
a_t = Σ_φ w_{t,φ} · π_φ(o_t)
```

**换向约束**：`‖w_t − w_{t−1}‖₁ ≤ δ`，且只允许相邻阶段重叠。若各专家在重叠支撑上动作差有界 `M`，则

```
‖a_t − a_{t−1}‖ ≤ L·‖o_t − o_{t−1}‖ + M·δ
```

即**动作抖动被 `δ` 显式封顶**——这直接回应「动作统计规律性异常」触发可信度质疑的风险，比事后平滑更可证。

### 3.2 「逆变器」= N 端口工程

共享骨干批处理、per-port KV/历史隔离、确定性调度；把端口间延迟波动当作**电流纹波**来压：目标是 `Var(latency)` 下降而非仅均值下降。指标：`p50/p95`、`ripple = p95−p50`、动作 jerk 分布。

## 5. 理论分析（两个命题 + 一个边界）

**命题 1（可观性）**：SPO 能以错误率 ≤ ε 区分自由运动与受阻，当且仅当阶段残差分布可分性 `S > 2ε·log((1−ε)/ε)` 且指令激励 `> v_min`。准静态段反电动势趋零 → 必须探动或回退 VLM；这是**原理性边界**，不是调参问题。

**命题 2（换向连续性）**：在专家 Lipschitz 常数 `L` 与重叠支撑上界 `M` 下，速率受限软混合的动作差满足 `‖Δa‖ ≤ L‖Δo‖ + Mδ`；故存在 `δ*` 使 jerk 低于可信度阈值，且 `δ*` 可由回放直接标定。

**边界（何时该封存）**：若真机观测不含可靠的本体/电流代理，或 `Ĝ` 的在线重拟合误差始终高于 stall 与合规接触的残差间隔，则 SPO 退化，应回退到「低频 VLM + 保守重试」。

## 6. 资源与时间线

- 第 1 周：SIP-Bench 固定切分 + 第 1 轮基线复现（pi0/ACT 或 UnifoLM-VLA-0 微调）。
- 第 2–3 周：拟合 `Ĝ` 与 `h_θ`；打通激励门控 / VLM 回退（E007–E008）。
- 第 3–4 周：FOAD 表示学习与消融（E009–E010）。
- 第 5 周：ECPE 阶段专家与换向约束（E011），同期做逆变器端口压测（E012）。
- 第 6 周：全栈联调（E013），冻结超参；之后预约真机校准 `Ĝ` 与代理相关性。

## 7. 本轮最大风险

**一句话**：整套提炼的成败押在 `Ĝ` 与残差的可分性上——若接触丰富任务中「卡住」与「合规接触」的残差分布重叠、且真机代理信号噪声大，SPO 会把失败读成进行中而**系统性抑制重试**，此时必须靠激励探动 + 低置信 VLM 回退 + 在线重校准三层兜底，否则 CIP-1/3 的换相判断会一起失真。
