# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感驱动研究循环第 1 轮（新循环）；本轮灵感：「遥操作」×「行为克隆」）

> 第 59 轮把证据承诺一路钉到执行层物理：BUQ 在线辨识电机不确定性、ERTC 契约化嵌入式实时性、EEIS 把 δ_f 编译成阻抗参数、CLEP 让执行实测回流证据层。但它仍默认了两个更深的假设：**其一，动作从哪里来**——仿佛策略是给定的、训练数据无偏；**其二，人如何进入回路**——人只作为「同意/拒绝」的签字人，而一旦出问题，遥操作接管被默认为瞬时、可靠、无限的兜底安全网。本轮两个灵感精准击穿这两条假设：**遥操作**告诉我们，示范动作是「操作者意图」经过「特定接口、特定延迟、特定注意力」后的**带条件反事实**，不是最优动作标签；**行为克隆**告诉我们，离线拟合示范会遭遇协变量偏移与复合误差，策略在示范分布外会**自信地错**。本轮核心命题：**「把示范从『i.i.d. 最优标签』还原为『经接口信道的带删失意图』；把人类从『离线数据源 + 瞬时安全网』升级为『受契约约束、可主动查询、只在可证明包络外接管的纠正权威』；并用非对称律钉死示范/纠正不得替代物理证据。」**

核心矛盾：
- **H35（示范合法性·接口删失）**：遥操作示范 `a_t` 是意图 `z_t` 经接口 `I` 投影到可行动作集 `A_I(o_t)` 后的结果。当操作者想走更远/更快但被限位/限速挡住时，记录到的是**边界上的删失值**，不是「不想去」。把删失当标签，BC 会学到「别去那里」「别那么快」这类由**接口而非世界**制造的伪偏好。叠加观测延迟 `δ_obs`，动作与观测错位，BC 会学到**伪前瞻/伪迟滞**。不建模接口与删失，任何「示范保真」都是错觉。
- **H36（接管安全网·双向延迟与注意力衰减）**：人类接管不是瞬时开关：请求→操作者感知→决策→输入→机器人响应，端到端存在 `T_human` 的**双向延迟**；操作者还可能根本没在看（注意力 `â` 衰减）。把遥操作当作无条件安全兜底，等价于把「人类会及时救场」当成公理。必须在**接管契约**内才可信，契约外必须由**独立于人的最小风险机动（MRM）**兜底。
- **H37（示范证据越权·意图≠世界）**：示范与纠正是关于「人想让机器人怎么做」的意图证据，不是关于「世界是否安全」的独立物理观测。若用「操作者说可以」去抵消「探针测到危险」，就是用**偏好**冒充**事实**。必须区分 EV-policy 与 EV-world，并执行**非对称律**：示范/纠正可以自由收紧约束、加宽不确定性，但放松约束与满足不可逆安全门**只能**由物理证据背书。

## 0. 直觉与动机

**灵感 1（遥操作 → 意图-动作解耦 IAD）**
直觉：把遥操作录像逐帧看，会误以为「操作者做的动作」就是「操作者想要的动作」。实际上中间隔着一层**接口信道**：摇杆行程、关节限位、速度上限、通信延迟、主从映射增益，都会把意图 `z_t`（任务空间里「我想往哪走、用多大力」）挤压成实际下发 `a_t`。最典型的不是噪声，而是**删失（censoring）**：操作者想继续向前，但摇杆已推到底 / 腕部已到限位，记录到的 `a_t` 恰好落在可行域边界上。朴素 BC 把边界动作当正样本，会学出「到这里就停」的**接口伪偏好**；而真实意图可能是「继续前进」。这与 Tobit 模型/截断回归同构：边界样本只提供**不等式约束**（意图 ≥ 观测），不是等号标签。进一步，遥操作观测普遍有 `δ_obs` 延迟，`a_t` 对应的是 `o_{t−δ}`；不先做延迟对齐，BC 会把「滞后」学成「策略风格」。IAD 的任务就是：估计接口模型与延迟，推断意图后验，并把边界样本按删失似然处理。

**灵感 2（行为克隆 → 部署包络证书 BCE）**
直觉：行为克隆最危险的不是训练误差，而是**部署时进入未见过状态后误差自累积**（协变量偏移/复合误差）。经典结论是：若每步误差 ε，horizon T，最坏累积可达 O(εT²)。安全系统不能只报「验证集动作误差」，而应回答：**「在哪个状态包络内，策略误差有可证明上界；一旦离开包络，系统能否在失控前感知并升级？」** 这等价于给策略配一张**部署包络证书**：用集成分歧 + 到示范流形距离 + 接口新奇度定义非一致性分数 `s(o)`，用**轨迹级/块共形**校准阈值 `r̂`，并用**受控不变集**条件（Lipschitz 动力学 + 包络内策略误差上界 + 边界裕度）证明「只要留在包络内，误差不爆」。若不变条件不成立，就退化为一步验证：每次动作前重验，越界即减速/查询/降级。

**灵感 3（遥操作纠错 → 主动纠正查询 CCQ）**
直觉：人类演示最贵的不是「多录几条」，而是**在对的状态上给出一次纠正**。DAgger 早已指出：应让策略跑、在策略会到的状态上问专家。但现实中的「专家」是疲惫的操作者，提问有注意力成本、打断成本、接管风险。于是「何时问、问哪个状态」应服从**纠正价值（VOI_corr）**：该状态不确定性高、风险高、且人类在接管契约内**确实来得及、看得见、改得动**，才值得问。可纠正性是一个硬约束：若某状态在 `T_takeover_max` 内不可达，问也白问；操作者注意力不足时提问只会制造「假纠正」。

**灵感 4（人类接管 → 人类权威接管契约 HAHC）**
直觉：安全兜底不能写成「出问题叫人」。要写成**契约**：`T_takeover_max`（接管延迟上界）、`A_attn_min`（最低注意力）、共享控制混合曲线 `λ(t)`、安全护盾 `S_shield`、交还条件 `T_handback`、以及最坏情况下的最小风险机动 MRM。请求接管前必须验证：操作者注意力达标、信道正常、历史接管延迟在界内；任一不满足就**不要依赖人**，直接执行 MRM。接管期间机器人不是「完全放手」，而是 `u = S_shield((1−λ)u_π + λu_H)`：人和策略的输出都必须过安全护盾。交还也不能凭一句「我好了」，必须等策略在包络内稳定驻留 `T_dwell`。

**灵感 5（合流 → 可纠正示范闭环 DCL + 示范-纠正证书）**
直觉：把上面四件事接成闭环：**示范进来先解耦意图与接口删失 → 按可信度加权做删失感知 BC → 校准部署包络 → 运行时监包络 → 越界请求接管或 MRM → 把接管中的纠正作为高价值数据 → 用纠正价值选择下一次问询 → 非对称地并入假设与策略**。人类不是一次性数据源，而是**持续可纠正的权威通道**；但这条通道只能让系统「更不确定/更保守」，不能单独让系统「更确信安全」。预算侧新增 `B_corr`（注意力/接管/纠正次数/信任额度），与探针、微调、解释、执行预算并列且不可挪用。证书 `J_demo` 记录示范溯源、延迟估计、删失标记、可信度、包络证书、接管日志、纠正日志与 MRM 日志，使「策略为什么可信、什么时候不可信、谁在何时纠正过」全程可审计。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（意图-动作解耦 IAD）** 直觉：记录到的动作 = 意图经过接口信道后的**投影**；边界动作是删失观测。形式化：示范集 `D={τ^(i)}`，`τ={(o_t,u_t^H,a_t,m_t)}`，`u_t^H` 为原始遥操作输入，`a_t` 为实际执行动作，`m_t` 为接口饱和掩码。接口 `I=(A_I:O→2^A, g_I:Z×O→A, δ_obs, τ_rate, ε_I)`，其中 `A_I(o)` 为可行动作集，`g_I` 为意图到指令的映射。观测模型
```
a_t = Proj_{A_I(o_t)}( g_I(z_t, o_{t−δ_obs}) ) + e_t,   e_t ~ p_e
```
删失指示 `c_t = 1` 当且仅当 `a_t ∈ ∂A_I(o_t)` 且 `(g_I(z_t,o_{t−δ_obs}) − a_t)·n_{∂A_I}(a_t) > 0`（意图指向可行域外）。似然分段：
```
c_t=0（内部）：p(a_t|z_t) = p_e(a_t − g_I(z_t,o_{t−δ_obs}))
c_t=1（上删失）：p(a_t|z_t) = 1 − F_e(g_I(z_t,o_{t−δ_obs}) − a_t)
```
**可辨识性**：若接口在至少一个自由度上存在非退化内部段，且 `g_I` 单调，则 `z_t` 在已知 `g_I,δ_obs` 下可辨识；若所有自由度同时饱和，仅能辨识半空间 `{z: g_I(z,o) ⪰ a_t}`，此时标记为 `intent_uncertain`，**不得**记作 `intent=0`。延迟 `δ_obs` 由动作-观测互相关与接口阶跃响应联合估计 `δ̂_obs`，训练前对齐。IAD 输出 `(ẑ_t, c_t, δ̂_obs, ρ_sat)`，其中 `ρ_sat = mean_t c_t` 为饱和率。

**定义 154（示范可信度分级 DQS）** 直觉：疲劳、犹豫、接口抖动、延迟异常的操作段，其标签不该与干净示范等权。形式化：每个示范段 `d` 由**过程信号**（不含任务成败，避免幸存者偏差）构造特征
```
φ_d = (ρ_sat, h_hes, σ_δ, â_attn^d, κ_prov, r_selfcons)
```
`h_hes` 为犹豫指数（动作反转率/动作熵），`σ_δ` 延迟波动，`â_attn^d` 该段平均注意力，`κ_prov` 溯源完整度，`r_selfcons` 与后续纠正的自一致度。可信度 `w_d = Clip(σ(θ^T φ_d), w_min, w_max)`，`θ` 用留出的**干预结果**做等渗校准（isotonic），使 `E[w_d | φ_d]` 校准误差 `ECE_w ≤ ε_w`。有效样本量 `N_eff = (Σ_d w_d)² / Σ_d w_d²`。**护栏**：`w_d` 只进入 BC 损失与数据聚合，**绝不**进入物理安全证据；`N_eff < n_min` 的类别不得声明覆盖。同操作者/同接口的段存在相关性，独立性按**不同操作者/接口数**计，而非段数。

**定义 155（行为克隆部署包络证书 BCE）** 直觉：先划出「策略还靠得住」的状态包络，并证明在包络内误差不爆；出了包络立刻升级。形式化：非一致性分数
```
s(o) = max( σ_ens(o)/σ_ref, d_knn(o; D_intent)/d_ref, novelty_I(o), σ_pred(o)/σ_pred_ref )
E_π(r) = { o : s(o) ≤ r }
```
其中 `σ_ens` 为集成分歧，`d_knn` 为到解耦后意图-示范流形的距离，`novelty_I` 为接口状态新奇度。轨迹级非一致性 `L(τ)=max_t ℓ(a_t,π(o_t))`（或折扣累积）。用**块共形/鞅共形**（块=轨迹，处理时序相关）选
```
r̂ = inf{ r : (n/(n+1))·L̂(r) + B/(n+1) ≤ ε_bc },  B=1
```
给出 `P( E[L(τ) | τ⊂E_π(r̂)] ≤ ε_bc ) ≥ 1−α_bc`。**受控不变性**：设动力学 `o_{t+1}=f(o_t,a_t)+w` 在状态上 `L_f`-Lipschitz，包络内策略误差 `‖π(o)−a*‖ ≤ ε_π`。若存在裕度 `m>0` 使 `∀o∈E_π(r̂): dist(f(o,π(o)), ∂E_π) ≥ m` 且 `L_f·ε_π ≤ m`，则轨迹不离开包络，且
```
‖e_t‖ ≤ L_f^t‖e_0‖ + ε_π·(L_f^t − 1)/(L_f − 1)
       ≤ ε_π/(1 − L_f)   （当 L_f<1）
```
`L_f<1` 时误差有界；`L_f≥1` 时只给有限 horizon 界并强制**每步重验**（one-step re-certification）。证书 `Cert_bc=(r̂, ε_π, L_f, m, H_cert, α_bc, version, env_hash)`。运行时 `s(o_t)>r̂` 或裕度不足 ⇒ 触发升级（减速→CCQ→接管→MRM）。

**定义 156（人类权威接管契约 HAHC）** 直觉：接管是带延迟、带注意力前提的**有契约服务**，不是无条件兜底。形式化：
```
C_ho = (T_takeover_max, A_attn_min, λ(t) ramp, S_shield, T_handback, T_dwell, MRM, T_mrm)
```
注意力后验 `â_t` 由视线/输入节奏/周期性警觉探针经校准融合得到（`ECE_attn ≤ ε_attn`）。实测接管延迟 `L_ho = t_human_authoritative − t_request`。契约有效
```
valid(C_ho,t) = ( â_t ≥ A_attn_min ) ∧ ( Ê[L_ho] ≤ T_takeover_max )
                ∧ channel_ok ∧ shield_active
```
`valid=false ⇒ 不得依赖人`，直接执行 MRM。接管期间共享控制
```
u_t = S_shield( (1−λ_t)·u_π + λ_t·u_H ),  λ_t: 0→1 ramp, u_H 为人类输入
```
交还条件：策略重新进入 `E_π` 并连续驻留 `T_dwell`，且人类显式交还。权威状态机 `AUTONOMOUS → REQUEST → SHARED → HUMAN → HANDBACK`，每次转移必须携带 `(valid, L_ho, â_t, S_shield)` 证据。**安全定理目标**：契约有效时接管按延迟界发生；契约无效时 MRM 在 `T_mrm` 内到达安全态；人永不作为无界安全预言机。

**定义 157（纠正查询 CCQ，带纠正价值）** 直觉：只在「问得值、来得及、改得动」的状态问人。形式化：查询 `q=(region, timing, modality)`，纠正价值
```
VOI_corr(q) = E_{o~q, τ~π}[ ΔR_safe + ΔJ_task ]
              − λ_h·C_human(q) − λ_i·C_interrupt(q) − λ_t·C_takeover(q)
```
`ΔR_safe` 为风险下降，`ΔJ_task` 为任务回报提升（用集成分歧/回报 gap/不确定性估计），`C_human` 注意力成本，`C_interrupt` 打断成本，`C_takeover` 接管风险。**可纠正性硬约束**
```
Admissible(q) = reachable(q, T_takeover_max) ∧ attention_ok(q) ∧ expressible_I(q)
```
查询选择 `q* = argmax_{q∈Admissible} VOI_corr(q) s.t. B_corr`。纠正经 IAD 解析为意图标签、经 DQS 加权，以 DAgger 式聚合进数据集。**非对称**：纠正可自由**收紧**约束；**放松**约束必须另附物理证据。

**定义 158（示范模态 XMC-demo 与非对称示范律）** 直觉：示范是关于「人想怎么做」的证据，不是关于「世界是什么样」的证据。形式化：扩展模态集 `ℳ⁺⁺ = ℳ⁺ ∪ {demo}`，`demo` 似然 `ℓ_demo` 定义在意图/策略空间而非世界状态空间。分歧
```
D⁺⁺(r) = D⁺(r) + w_demo·TV(lbl_demo,lbl_fused) + w_demo·|Q_μ^demo(0.99)−Q_μ^fused(0.99)|/μ_scale
```
规则：
- **(D1)** 示范/纠正的**分歧**进入 `D⁺⁺`，只能加宽后验；
- **(D2)** 示范/纠正的**一致**不得减少探针/物理证据需求，`ρ_demo` 不进入 `EV-xmodal/EV-probe` 的判定；
- **(D3)** 放松安全约束或通过不可逆门，必须有 `EV-probe*/EV-exec` 物理证据，示范只能提供约束；
- **(D4)** 示范证据的非独立计数按 `n_distinct(operator, interface)` 计，`ρ_demo ≤ f(n_distinct)`。
并显式区分 `EV-policy`（策略/意图证据）与 `EV-world`（物理世界证据）两类标签。

**定义 159（示范-纠正闭环 DCL）** 直觉：一次「录—解耦—加权—训练—发包络—跑—越界—接管—纠正—再训练」的完整回合。形式化算子：
```
DCL(D, π, E_π, C_ho, B_corr):
 ① Align:   δ̂_obs ← estimate_delay(D); D ← align(D, δ̂_obs)
 ② IAD:     for d∈D: (ẑ, c, ρ_sat)_d ← infer_intent(d, I)
 ③ DQS:     w_d ← trust(d); N_eff ← effective_n(w)
 ④ BC:      π ← train_censored_weighted(D, w, c)      # 删失似然 + 信任加权
 ⑤ BCE:     r̂, Cert_bc ← calibrate_envelope(π, D, ε_bc); verify_invariance(Cert_bc)
 ⑥ Deploy:  while episode: 
              if s(o_t) ≤ r̂ ∧ margin_ok: u←π(o_t)
              elif s(o_t) ≤ r̂+δ_soft: u←slow(π); q←CCQ(region)
              else: escalate
 ⑦ HAHC:    if valid(C_ho): request_takeover → SHARED → HUMAN; else: MRM
 ⑧ Correct: corrections ← collect_human_corrections(); D←D∪IAD(corrections)
 ⑨ XMC-demo: fused, D⁺⁺ ← xmodal_fuse_demo(...)     # 非对称，仅对账/加宽
 ⑩ Return:  (π, E_π, Cert_bc, C_ho, corrections, D⁺⁺)
```
任一步越界或预算耗尽 ⇒ 保守分支（减速/绕行/接管/MRM），**不得**用示范一致性抵消。

**定义 160（纠正预算 B_corr、示范证书 J_demo 与 PCE+++++）** 直觉：人的注意力、接管次数、信任额度都是稀缺资源，必须和探针/微调/解释/执行预算并列且不可挪用。形式化：
```
B_corr = (B_attn, B_takeover, B_corr_cnt, B_trust, B_interface)
cost_corr(π) = λ_a·max(0, Attn(π)−B_attn) + λ_t·max(0, Takeovers(π)−B_takeover)
             + λ_c·max(0, Corr(π)−B_corr_cnt) + λ_r·max(0, Trust(π)−B_trust)
VOI_total = VOI_meta_pessimistic − cost_exec − cost_corr
```
任一子预算耗尽 ⇒ 冻结提问/接管请求，转保守策略。示范证书
```
J_demo = (demo_provenance_DAG, δ̂_obs, c_flags, w_scores, N_eff,
          Cert_bc_chain, C_ho, handover_log, correction_log, IAD_residual,
          MRM_log, B_corr_snapshot, version)
```

### IP-152 IAD（意图-动作解耦器）

```python
class IntentActionDisentangler:
    def __init__(self, interface_model, intent_prior):
        self.I = interface_model          # A_I, g_I, limits, rate
        self.prior = intent_prior
        self.delta_obs = 0.0

    def estimate_delay(self, D):
        # 用接口阶跃响应 + 动作-观测互相关联合估计 δ_obs
        best, best_score = 0.0, -np.inf
        for d in np.arange(0, self.I.max_delay + self.I.dt, self.I.dt):
            score = cross_corr_score(D, d) - self.I.step_response_penalty(d)
            if score > best_score:
                best, best_score = d, score
        self.delta_obs = best
        return best

    def infer_intent(self, o_t, a_t):
        o_obs = o_t - self.delta_obs
        lo, hi = self.I.inverse_bounds(a_t, o_obs)   # 半空间/盒约束
        c = int(self.I.is_saturated(a_t, o_obs) and
                self.I.outward_intent(a_t, o_obs))
        z_mean, z_cov = self.prior.condition(lo, hi)
        return IntentEstimate(z_mean, z_cov, censored=c, bounds=(lo, hi))

    def censored_nll(self, z_batch, a_batch, c_batch, o_batch):
        """边界样本只给不等式似然；内部样本用普通回归似然"""
        mu = self.I.g(z_batch, o_batch)
        resid = a_batch - mu
        nll_int = -self.p_e.logpdf(resid)
        nll_cen = -np.log(1e-9 + 1.0 - self.p_e.cdf(resid))  # 上删失
        return np.where(c_batch == 0, nll_int, nll_cen).mean()

    def residual(self, z, a, o, c):
        return np.where(c == 0, np.abs(a - self.I.g(z, o)),
                        np.maximum(0.0, self.I.g(z, o) - a))
```

### IP-153 DQS（示范可信度评分）

```python
class DemonstrationQualityScorer:
    def __init__(self, feature_fn, theta, w_min=0.05, w_max=1.0, n_min=20):
        self.phi, self.theta = feature_fn, theta
        self.w_min, self.w_max, self.n_min = w_min, w_max, n_min

    def score(self, d):
        # 仅用过程信号，绝不用任务成败（避免幸存者偏差）
        f = self.phi(d, exclude={"success"})
        w = sigmoid(dot(self.theta, f))
        return float(np.clip(w, self.w_min, self.w_max))

    def calibrate(self, held_out):
        # 用留出的“干预结果”做等渗校准：E[w|phi] 与真实可靠性一致
        f = np.array([self.phi(d) for d in held_out])
        y = np.array([d.intervention_agreement for d in held_out])
        raw = sigmoid(f @ self.theta)
        self.iso = IsotonicRegression(out_of_bounds="clip").fit(raw, y)
        return ece(self.iso.predict(raw), y)

    def effective_n(self, weights):
        w = np.asarray(weights)
        return float(w.sum()**2 / (np.square(w).sum() + 1e-12))

    def weighted_bc_loss(self, pi, batch, weights, c_flags, iad):
        losses = iad.censored_nll(
            pi.intent(batch.o), batch.a, c_flags, batch.o)
        return (torch.as_tensor(weights) * losses).sum() / weights.sum()

    def independence_weight(self, demos):
        # 相关性：按不同 operator/interface 计，而不是段数
        n_distinct = len({(d.operator, d.interface_id) for d in demos})
        return min(1.0, n_distinct / max(1, len(demos)))
```

### IP-154 BCE（行为克隆部署包络证书）

```python
class BCPolicyEnvelope:
    def __init__(self, policy, ensemble, demo_manifold, interface_model):
        self.pi, self.ens = policy, ensemble
        self.manifold, self.I = demo_manifold, interface_model
        self.r_hat, self.cert = None, None

    def score(self, o):
        s_ens = self.ens.disagreement(o) / self.ens.sigma_ref
        s_knn = self.manifold.distance(o) / self.manifold.d_ref
        s_nov = self.I.novelty(o)
        s_var = self.ens.predictive_std(o) / self.ens.sigma_pred_ref
        return float(max(s_ens, s_knn, s_nov, s_var))

    def calibrate(self, trajectories, eps_bc=1e-2, alpha_bc=1e-2, B=1):
        # 轨迹级/块共形：块=整条轨迹，处理时序相关
        def L(r):
            vals = []
            for tau in trajectories:
                ins = [t for t in tau if self.score(t.o) <= r]
                if ins:
                    vals.append(max(abs(t.a - self.pi(t.o)) for t in ins))
            return np.mean(vals) if vals else np.inf
        rs = np.sort(np.unique([self.score(t.o) for tau in trajectories for t in tau]))
        n = len(trajectories)
        for r in rs:
            if (n/(n+1))*L(r) + B/(n+1) <= eps_bc:
                self.r_hat = r
                self.cert = EnvelopeCertificate(r, eps_bc, alpha_bc,
                                                version=self.next_version())
                return self.cert
        self.r_hat = rs[0]                      # 最保守
        self.cert = EnvelopeCertificate(self.r_hat, eps_bc, alpha_bc, degraded=True)
        return self.cert

    def invariance_check(self, dynamics, eps_pi, m):
        Lf = dynamics.lipschitz()
        ok = (Lf * eps_pi <= m)
        bound = (eps_pi/(1-Lf) if Lf < 1
                 else eps_pi * (Lf**self.cert.H_cert - 1)/(Lf - 1))
        self.cert = self.cert.with_invariance(Lf, m, ok, bound)
        return ok, bound

    def runtime_gate(self, o):
        s = self.score(o)
        if s <= self.r_hat:
            return "RUN"
        if s <= self.r_hat + self.cert.delta_soft:
            return "SLOW_QUERY"
        return "ESCALATE"      # 可能进入 HAHC 或 MRM
```

### IP-155 HAHC（人类权威接管契约）

```python
class HandoverContract:
    def __init__(self, C_ho, attention_estimator, shield):
        self.C, self.attn, self.shield = C_ho, attention_estimator, shield
        self.state = "AUTONOMOUS"
        self.history = []

    def contract_valid(self, channel_ok, shield_active):
        a = self.attn.posterior()
        e_lat = self.attn.expected_takeover_latency()
        return (a >= self.C.A_attn_min and e_lat <= self.C.T_takeover_max
                and channel_ok and shield_active)

    def request(self, channel_ok=True, shield_active=True):
        if not self.contract_valid(channel_ok, shield_active):
            self.state = "MRM"
            self.history.append(("mrm", "invalid_contract"))
            return self.mrm()
        self.state = "REQUEST"
        self.t_request = now()
        return "REQUESTED"

    def on_human_input(self, u_h, u_pi, t):
        self.state = "HUMAN"
        self.L_ho = t - self.t_request
        lam = ramp(t - self.t_request, self.C.T_takeover_max)
        u = self.shield.filter((1-lam)*u_pi + lam*u_h)
        self.history.append(("handover", self.L_ho, self.attn.posterior()))
        return u

    def handback_ready(self, o, envelope, dwell_ok):
        return (self.state == "HUMAN" and envelope.in_envelope(o)
                and dwell_ok >= self.C.T_handback)

    def mrm(self):
        # 独立于人的最小风险机动：受控停/支撑/退让
        u = self.shield.filter(mrm_policy(self.C.MRM))
        self.history.append(("mrm", now()))
        return u
```

```python
def select_correction_query(M, region, B_corr):
    cands = candidate_states(M, region, near_envelope=True, high_risk=True)
    best, best_voi = None, -np.inf
    for q in cands:

                and M.I.expressible(q)):
```

### IP-158 DCL（示范-纠正闭环）与预算/证书

```python
def demonstration_correction_loop(D, pi, envelope, C_ho, B_corr, M):
    iad, dqs = M.iad, M.dqs
    # ① 延迟对齐
    delta = iad.estimate_delay(D); D = align_demos(D, delta)
    # ② 意图解耦 + 删失标记
    parsed = [iad.infer_intent(d.o, d.a) for d in D]
    c_flags = np.array([p.censored for p in parsed])
    # ③ 可信度 + 有效样本量
    w = np.array([dqs.score(d) for d in D]); n_eff = dqs.effective_n(w)
    # ④ 删失感知、信任加权 BC
    pi = train_bc(pi, D, w, c_flags, iad, n_eff_min=M.n_min)
    # ⑤ 部署包络校准 + 不变性验证
    cert = envelope.calibrate(M.calib_trajectories, M.eps_bc, M.alpha_bc)
    inv_ok, bound = envelope.invariance_check(M.dynamics, M.eps_pi, M.margin)
    if not inv_ok:
        cert = cert.with_mode("ONE_STEP_RECERT")
    # ⑥-⑧ 部署 → 越界 → 接管/查询 → 纠正
    corrections = []
    for step in episode:
        gate = envelope.runtime_gate(step.o)
        if gate == "RUN":
            u = pi(step.o)
        elif gate == "SLOW_QUERY":
            u = slow(pi, step.o)
            q = select_correction_query(M, step.region, B_corr)
            if q: corrections += query_human(q)
        else:
            if C_ho.contract_valid(M.channel_ok, M.shield_active):
                C_ho.request(); u = C_ho.on_human_input(
                    M.human_input(), pi(step.o), now())
            else:
                u = C_ho.mrm()                          # 不依赖人
        step.advance(u)
    # ⑨ 非对称并入（分歧只加宽）
    D = D + [iad.parse(x) for x in corrections]
    # ⑩ 证书与预算快照
    J = J_demo(D, delta, c_flags, w, n_eff, cert, C_ho,
               corrections, M.mrm_log, B_corr.snapshot())
    return pi, envelope, J, D_pp(M, corrections)
```

假设 A22–A55（第 53–59 轮）成立；**(A56)** IAD：接口映射 `g_I` 与延迟 `δ_obs` 的估计误差有界，删失似然诚实（边界样本按不等式处理），存在非退化内部段使意图可辨识。**(A57)** DQS：`w_d` 由过程信号构造并以等渗校准，`ECE_w≤ε_w`；仅当 `N_eff≥n_min` 才将示范用于覆盖声明；同源段按不同操作者/接口降独立计数。**(A58)** BCE：轨迹级块共形在校准条件下有效；包络内策略误差 `≤ε_π`；受控不变性条件（`L_f·ε_π≤m`）经运行时验证；越界检测延迟 ≤1 控制周期。**(A59)** HAHC：注意力后验校准 `ECE_attn≤ε_attn`；接管延迟实测诚实；安全护盾 `S_shield` 对人和策略输出均不放行越界动作；MRM 在 `T_mrm` 内到达安全态。**(A60)** CCQ：`Admissible` 仅包含契约内可达且可表达的状态；纠正价值估计诚实；`B_corr` 单调。**(A61)** XMC-demo：示范/纠正只进入对账与约束，不进入 `EV-xmodal/EV-probe` 物理证据判定；`ρ_demo` 按独立来源计。**(A62)** PCE+++++：五/六预算隔离、单调、不可挪用；各成本函数为真实消耗的诚实上界。则：

1. **示范合法性（去接口偏置）**：信任加权删失 BC 的意图估计在内部段一致，接口伪偏好偏置满足

### IP-152 IAD（意图-动作解耦）

```python
class IntentActionDisentangler:
    def __init__(self, interface, intent_prior):
        self.I, self.prior = interface, intent_prior
        self.delta_obs = 0.0

    def estimate_delay(self, D):
        # 接口阶跃响应 + 动作-观测互相关联合估计
        grid = np.arange(0, self.I.max_delay + self.I.dt, self.I.dt)
        scores = [cross_corr(D, d) - self.I.step_penalty(d) for d in grid]
        self.delta_obs = float(grid[int(np.argmax(scores))])
        return self.delta_obs

    def infer_intent(self, o_t, a_t):
        o = o_t - self.delta_obs
        lo, hi = self.I.inverse_bounds(a_t, o)          # 半空间/盒约束
        c = int(self.I.saturated(a_t, o) and self.I.outward(a_t, o))
        z, P = self.prior.condition(lo, hi)
        return IntentEstimate(z, P, censored=c, bounds=(lo, hi))

    def censored_nll(self, z, a, c, o):
        mu = self.I.g(z, o)
        r = a - mu
        nll_int = -self.p_e.logpdf(r)
        nll_cen = -np.log(1e-9 + 1.0 - self.p_e.cdf(r))  # 上删失
        return np.where(c == 0, nll_int, nll_cen).mean()
```

### IP-153 DQS（示范可信度）

```python
class DemonstrationQualityScorer:
    def __init__(self, phi, theta, w_min=0.05, w_max=1.0, n_min=20):
        self.phi, self.theta = phi, theta
        self.w_min, self.w_max, self.n_min = w_min, w_max, n_min

    def score(self, d):
        w = sigmoid(np.dot(self.theta, self.phi(d, exclude={"success"})))
        return float(np.clip(w, self.w_min, self.w_max))

    def calibrate(self, held_out):
        raw = np.array([sigmoid(self.phi(d) @ self.theta) for d in held_out])
        y = np.array([d.intervention_agreement for d in held_out])
        self.iso = IsotonicRegression(out_of_bounds="clip").fit(raw, y)
        return ece(self.iso.predict(raw), y)

    def effective_n(self, w):
        w = np.asarray(w)
        return float(w.sum()**2 / (np.square(w).sum() + 1e-12))

    def weighted_bc_loss(self, pi, batch, w, c, iad):
        losses = iad.censored_nll(pi.intent(batch.o), batch.a, c, batch.o)
        return (torch.as_tensor(w) * losses).sum() / w.sum()
```

### IP-154 BCE（部署包络证书）

```python
class BCPolicyEnvelope:
    def __init__(self, policy, ensemble, manifold, interface):
        self.pi, self.ens = policy, ensemble
        self.manifold, self.I = manifold, interface
        self.r_hat, self.cert = None, None

    def score(self, o):
        return float(max(
            self.ens.disagreement(o) / self.ens.sigma_ref,
            self.manifold.distance(o) / self.manifold.d_ref,
            self.I.novelty(o),
            self.ens.predictive_std(o) / self.ens.sigma_pred_ref))

    def calibrate(self, trajectories, eps_bc=1e-2, alpha_bc=1e-2, B=1):
        # 轨迹级块共形（块=轨迹，处理时序相关）
        def realized(r):
            vals = [max(abs(t.a - self.pi(t.o)) for t in tau
                        if self.score(t.o) <= r) for tau in trajectories]
            vals = [v for tau, v in zip(trajectories, vals) if any(
                self.score(t.o) <= r for t in tau)]
            return np.mean(vals) if vals else np.inf
        n = len(trajectories)
        for r in np.sort({self.score(t.o) for tau in trajectories for t in tau}):
            if (n/(n+1))*realized(r) + B/(n+1) <= eps_bc:
                self.r_hat = r
                self.cert = EnvelopeCertificate(r, eps_bc, alpha_bc, version=self.v++)
                return self.cert
        self.r_hat = min(self.score(t.o) for tau in trajectories for t in tau)
        self.cert = EnvelopeCertificate(self.r_hat, eps_bc, alpha_bc, degraded=True)
        return self.cert

    def invariance_check(self, dynamics, eps_pi, margin):
        Lf = dynamics.lipschitz()
        ok = (Lf * eps_pi <= margin)
        bound = (eps_pi/(1-Lf) if Lf < 1
                 else eps_pi*(Lf**self.cert.H_cert - 1)/(Lf - 1))
        self.cert = self.cert.with_invariance(Lf, margin, ok, bound)
        return ok, bound

    def runtime_gate(self, o):
        s = self.score(o)
        if s <= self.r_hat:                      return "RUN"
        if s <= self.r_hat + self.cert.delta_soft: return "SLOW_QUERY"
        return "ESCALATE"                         # → HAHC 或 MRM
```

```python
class HandoverContract:
    def __init__(self, C_ho, attention, shield):
        self.C, self.attn, self.shield = C_ho, attention, shield
        self.state, self.history = "AUTONOMOUS", []

    def contract_valid(self, channel_ok, shield_active):
        return (self.attn.posterior() >= self.C.A_attn_min
                and self.attn.expected_takeover_latency() <= self.C.T_takeover_max
                and channel_ok and shield_active)

    def request(self, channel_ok=True, shield_active=True):
        if not self.contract_valid(channel_ok, shield_active):
            self.state = "MRM"; self.history.append(("mrm", "invalid_contract"))
            return self.mrm()                    # 契约无效：绝不依赖人
        self.state, self.t_request = "REQUEST", now()
        return "REQUESTED"

    def on_human_input(self, u_h, u_pi, t):
        self.state = "HUMAN"
        self.L_ho = t - self.t_request
        lam = ramp(self.L_ho, self.C.T_takeover_max)
        u = self.shield.filter((1-lam)*u_pi + lam*u_h)
        self.history.append(("handover", self.L_ho, self.attn.posterior()))
        return u

    def handback_ready(self, o, envelope, dwell):
        return (self.state == "HUMAN" and envelope.in_envelope(o)
                and dwell >= self.C.T_handback)

    def mrm(self):
        u = self.shield.filter(mrm_policy(self.C.MRM))
        self.history.append(("mrm", now())); return u
```

```python
def select_correction_query(M, region, B_corr):
    best, best_voi = None, -np.inf
    for q in candidate_states(M, region, near_envelope=True, high_risk=True):
        if not (reachable(q, M.C_ho.T_takeover_max)
                and M.attn.posterior_at(q) >= M.C_ho.A_attn_min
                and M.I.expressible(q)):
            continue                                   # 不可纠正 ⇒ 不问
        gain = (M.value_model.expected_task_gain(q)
                + M.risk_model.expected_risk_drop(q))

                + LAMBDA_T*M.takeover_risk(q))
        voi = gain - cost
        if voi > best_voi and B_corr.attn_left() > 0:
            best, best_voi = q, voi
    return best if best_voi > THETA_CORR else None
```

```python
def demonstration_correction_loop(D, pi, envelope, C_ho, B_corr, M):

    for step in episode:
        gate = envelope.runtime_gate(step.o)
        if gate == "RUN":
            u = pi(step.o)
        elif gate == "SLOW_QUERY":
            u = slow(pi, step.o)

class CorrectionBudget:
    def __init__(self, attn, takeover, cnt, trust, iface):
        self.B = dict(B_attn=attn, B_takeover=takeover,
                      B_corr_cnt=cnt, B_trust=trust, B_interface=iface)
    def spend(self):
        self.B['B_corr_cnt'] -= 1
    def attn_left(self):    return self.B['B_attn']
    def exhausted(self):    return self.B['B_corr_cnt'] <= 0 or self.B['B_attn'] <= 0
    def cost_corr(self, attn, tk, corr, trust):

                + LAMBDA_T*max(0, tk-self.B['B_takeover'])
                + LAMBDA_C*max(0, corr-self.B['B_corr_cnt'])
                + LAMBDA_R*max(0, trust-self.B['B_trust']))
```
