# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 3 轮；本轮灵感：「商业模式」×「激光雷达」）

> R69 教会系统「问」，但把三件事当成了外生常量：**感知预算是标量硬约束**、**只有一个委托人**、**证据通道是诚实的**。真实部署里，感知不是免费的输入，而是一个**有价格、有外部性、有契约、有欺诈的市场**：LiDAR 每一束光都是花能量/时延买来的稀缺资源；同一空间里多台 LiDAR 互相干扰，是一种未被定价的**公地悲剧**；下游模块、运营方、保险方、监管方各自带着不同的风险预算与支付意愿；而激光注入/中继/致盲可以把「证据」本身变成攻击面，让系统给一份**看似合规、实则伪造**的证书盖章。R69 的 λ_floor 只是这个市场在「单委托人、零外部性、诚实通道、线性价值」处的**影子价格**。
>
> 本轮两个灵感正好补上三块缺失：
> - **激光雷达**：主动感知把「看哪里、看多久」变成一个**带物理成本的生产函数**（能量、眼安全、时延、r⁴ 衰减、互干扰），并提供一条可被物理层认证、也可被物理层欺骗的通道；
> - **商业模式**：把证书从「一个向量」升级为「一份契约」——风险预算、SLA、分级定价、责任与审计；把不确定性处置升级为**机制设计 / 资源市场**。
>
> 核心命题：**感知是市场，证书是契约，安全是不可交易的不变量。** 用证据市场把 LiDAR 光束、注视/探针/问句等稀缺感知资源按「边际 VoI / 边际社会成本」分配给各契约；用排放权/Pigouvian 价格内部化多机 LiDAR 互干扰；用挑战-响应脉冲编码 + 证明携带证书对抗激光欺骗与契约伪造；当市场不可行、被操纵或证据被投毒时，按**严重度字典序**（而非出价）保安全关键契约，并退回 R69 的纯保守。命名 **MARKET-RAS**（Market-mediated Active Risk-Knowledge Exchange under Trust）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这份确定值多少钱、该由谁买单、谁又能伪造它**」——不确定性第一次有了价格，但安全绝不上架。

## 0. 直觉与动机

**灵感 1（激光雷达 → 感知是内生的生产函数，不是外生输入）**
直觉：R69 把「多看/多问」当成一个带标量成本 c(g) 的信息动作。但 LiDAR 的物理告诉你：看清一个方向要花**光子预算 b_u**，测距方差大致随 `r⁴/(P·b_u)` 衰减、随背景与互干扰上升；一帧的能量受眼安全封顶，时延受控制周期封顶。于是「分辨率」不是免费属性，而是一个**必须被分配的生产要素**：远、暗、小、快的目标抢同一池光子。市场不是隐喻——同一帧里不可能对所有方向都高分辨，**分配问题客观存在**。这把 R69 的「值不值得查」升级为「这束光该给谁、给多久、值多少焦耳」。

**灵感 2（商业模式 → 证书是契约，不是标量）**
直觉：R69 的 J_FLUID 是一个向量，默认「所有下游都同样信任它」。现实里下游是**多个委托人**：导航模块要 ε_nav、抓取模块要 ε_grasp、人机安全要 ε_human、运营方要可用率、保险方要责任边界、监管方要可审计。它们风险预算不同、期限不同、支付意愿不同、违约罚金不同。证书因此是一份 **SLA**：承诺「在范围 S_c 内、截止 τ_c 前，真实风险 ≤ ε_c」，并附带**责任 L_c**。系统要做的不是「最小化一个 U」，而是「在预算与安全约束下，让一组契约同时可偿付」。这把 R69 的单目标风险缩放升级为**多委托人的契约可行性问题**。

**灵感 3（外部性 → 多机 LiDAR 互干扰是未定价的公地悲剧）**
直觉：两台机器人朝同一片区域发射激光，彼此的探测器会把对方的光子当噪声；每台都只感受到「我的信噪比变差」，却不为「我让别人变差」付费。这就是教科书级的**负外部性/公地悲剧**：非合作均衡下所有机器人都过度发射，集体"看得更清"的愿望反而让集体更看不清。商业模式的答案不是道德劝说，而是**定价**：对发射收 Pigouvian 税，或发放可交易发射权（cap-and-trade）。这是本轮最"跨学科"的一步——把光学的干扰矩阵直接接到机制设计的出清价上。

**灵感 4（欺诈 → 激光注入是"契约欺诈"，不只是传感器故障）**
直觉：R69 的 ℰ_poison 关心"人会撒谎"。LiDAR 把攻击面推进到物理层：注入伪造回波可凭空造出障碍（幻影），中继/重放可让真实障碍"消失"或"挪位"，强光致盲可让整帧失明。更阴险的是**共谋**：两个伪造源互相印证，恰好绕过 R69 的「k 个正交源一致」。这时的失败不是"没测到"，而是**签发了一份看起来可验证的假证书**——契约欺诈。防御必须同时是物理的（随机脉冲码挑战-响应、双向测距、跨视角几何一致）与制度的（证明携带证书、第三方可复算、虚假证明罚金）。

**灵感 5（严格包含 → R69 是「单委托人、零外部性、诚实通道、线性价值」的边界）**
直觉：把市场程序写成带约束的凹优化，取 KKT 乘子。单契约、无干扰、无欺诈、价值线性时，风险约束的影子价格 p_c 恰好等于 R69 的 λ_floor；分配恰好等于 MINT 的 argmax[VoI−c]；证书恰好等于 J_FLUID。于是 R69 不是被替代，而是被**包含为边界情形**。当市场不可行、被操纵或证据被投毒时，熔断并逐指令退回 R69——**安全侧永不弱于旧层**，这是整条 RAS 链一贯的理论姿态。

**灵感 6（伦理硬边界 → 可以给不确定性定价，但绝不能让安全上市）**
直觉：一旦把"保护谁"交给市场，最坏的情形是**出价最高者受保护，而不是风险最高者**。所以必须先把不可交易的东西钉死：物理安全包络 ε_int、眼安全功率上限、k≥2 证据纪律、零学习写操作、提交/换装不变式，构成不变量集合 ℐ，市场只能把它们当硬约束。剩余可交易的是**认知/性能风险**（看多清、验证多严、证书多高等级）。预算不足时按**严重度字典序**降级：先牺牲低严重度契约，任何出价都不能让高严重度契约让位。这条"安全不上架"是 MARKET-RAS 的宪法。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（MARKET-RAS 总览）** MARKET-RAS = (SPF, BAM, CCR, EM, LIX, RPA, PCC, SPL, ASM, MFM, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **安全不可交易**：物理安全包络 ε_int、眼安全功率上限、证据纪律（k≥2 正交源）、零学习写操作、提交/换装不变式属于不变量集合 ℐ，市场程序只能把它们当硬约束，任何价格/支付都不能交换它们（定义 319）；
(iii) **契约偿付性**：账本 ℒ 中任一已签发契约 c，其认证风险上界 `r̄_c ≤ ε_c + m_c`；不满足则先降级低严重度契约，绝不静默签发。

**定义 311（LiDAR 感知生产函数 SPF）** 方向 u、驻留脉冲数 b_u、峰值功率 P、距离 r(u)、背景 B、互干扰 I(u)：
`σ_r²(u,b) = σ_bg² + (κ·r(u)⁴ + ι·I(u)) / (P·b_u·η(u))`，
η 为光学/探测效率。单帧资源约束 `Σ_u b_u ≤ B_frame`（能量与眼安全）、`Σ_u b_u·Δt ≤ T_frame`（时延）。Fisher 信息 `J_r(u,b) = 1/σ_r²(u,b)` 关于 b **严格凹增**——边际信息/光子递减。感知生产集 `𝒫 = {(b, σ_r²) : 上式, 资源约束}`。

**定义 312（证书即契约 CCR）** 契约 `c = (p_c, ε_c, S_c, τ_c, v_c, L_c, w_c, sev_c)`：委托人、风险预算、作用范围、截止期限、验证等级（tier）、违约罚金/责任、支付意愿、严重度。账本 `ℒ = {c ↦ (status, r̄_c, π_c)}`，status ∈ {honored, degraded, withdrawn}。R69 的 J_FLUID 是「单契约、单层、无责任」的特例。

**定义 313（证据市场 EM）** 感知/验证动作 `a ∈ 𝒜`（光束驻留、重扫、注视、探针、问句、跨模态复核），容量 `cap_a`，成本 `cost(a)`（能量 + 时延 + 社交 + 干扰价）。分配 `x_{a,c} ∈ [0,1]`。程序：
`max_x Σ_c w_c·U_c(r̄_c(x)) − Σ_a cost(a)`
`s.t. Σ_c x_{a,c} ≤ 1, Σ_a b_a ≤ B_frame, r̄_c(x) ≤ ε_c + m_c, ℐ 满足`。
`U_c` 凹（VoI 递减）。KKT 乘子：`p_a`（动作影子价）、`p_c`（风险影子价）、`p_e`（排放价）。

**定义 314（LiDAR 互干扰外部性 LIX）** 机器人 i 受到的干扰 `I_i = Σ_{j≠i} Ω_ij·P_j·g(d_ij)`，`Ω_ij` 为角度/光谱/时间重叠，`g` 为距离衰减。社会成本 `SC = Σ_i C_i(I_i)`。每台只优化自身 ⇒ 过度发射。用可交易发射权（总cap `E_max`）或 Pigouvian 价 `p_e = ∂SC/∂E` 内部化；`p_e` 进入 `cost(a)`。

**定义 315（契约欺诈对手 CFA）** `ℰ_fraud = {`幻影注入（伪造指定距离回波）, 中继/重放（延迟真实回波→错误测距）, 致盲（饱和探测器）, 共谋（两源一致地演）, 证书伪造（伪造审计日志）`}`。并入 AIC：`ℰ_MARKET = ℰ_FLUID × ℰ_fraud`。

**定义 316（证明携带证书 PCC）** 证书 `J_c` 必须携带可第三方复算的转录 `π_c = (挑战码 c_t, 原始回波承诺 h=H(raw), 时间戳, 跨传感器残差, 验证者签名)`；`Verify(π_c, J_c)=1` 才有效。证书因此**可携带、可审计、不可抵赖**——直接对抗逆向选择与责任推诿。

**定义 317（随机脉冲码认证 RPA）** LiDAR 以秘密码 `c_t`（PRF/啁啾，κ bit 熵）发射；回波须在时延容差内匹配码型才被接收。无码欺骗者单帧漏检概率 `≤ 2^{−κ}`；中继者因随机脉冲抖动与双向挑战，伪造测距误差 `≥ c·Δt_jitter`。输出认证残差 `r_auth` 与中继残差 `r_relay`。

**定义 318（逆向选择与道德风险 ASM）** 供应商类型 θ（真实标定质量）不可观测，机器人选择验证级别 v。分级菜单 `{(v, price_v)}` 满足单交叉条件 ⇒ 激励相容（高 θ 自愿选高 v）；运营方努力 e 影响退化，审计概率 q 与保修条款对齐。审计沿用 R69 VQAuditor-I 并升维为 VQAuditor-M。

**定义 319（不可交易安全不变量 ℐ）** `ℐ = {ε_int, 眼安全功率上限, k≥2 证据纪律, 零学习写, 提交/换装不变式}`。市场可行域 `𝒳_ℐ = {x : ℐ 满足}`。**定价只作用于可交易的认知/性能风险，不作用于 ℐ**。

**定义 320（偿付性与安全优先降级 SPL）** 若预算不足以对所有契约维持偿付性，按**严重度 `sev_c` 字典序**（而非 `w_c`）降级：先撤/降低 `sev_c` 契约；任何支付不能使高 `sev_c` 契约让位。若最高严重度契约仍不可偿付 ⇒ fail-safe（R69 保守 + 请求人类）。

**定义 321（分级 SLA 与防通胀）** 契约分 bronze/silver/gold，验证级别递增，价格 = 成本 + 风险溢价。只能签发证据实际支持的层级；**层级通胀**（tier inflation）视为证书伪造。单交叉 ⇒ 自选择诚实。

**定义 322（信息的时间价值 TVI）** 动作 a 的时延 `ℓ_a`（LiDAR 驻留随 b 增长），契约剩余时间 `τ_c`：`VoI_τ(a) = VoI(a)·e^{−ρ(ℓ_a+τ_proc)}`，且 `ℓ_a ≤ τ_c` 为硬约束。故存在最优驻留 `b*(r, τ_c)`：远距离/宽裕期限多驻留，紧期限少驻留。

**定义 323（市场均衡与 λ 即价格）** 在凹效用、可分干扰、无市场力下，tâtonnement/原始-对偶收敛到唯一均衡；`p_c` 为风险约束的影子价格。单契约、无干扰、诚实通道、线性价值时 `p_c = λ_floor`（定理 18）。

**定义 324（市场失灵监测 MFM）** 监测四类失灵：效用误设（契约价值与真实任务收益偏离）、价格操纵（单一主体市场力）、证据投毒（`r_auth` 异常、跨源冲突）、振荡/饥饿。触发 ⇒ **熔断**：冻结价格、退回 R69 保守、按严重度手工优先。

**定义 325（治理与职责分离）** 感知方、证书签发方、审计方必须分离；账本 append-only；随机抽审；虚假证明罚金 `L_c` 从保证金扣除。把「谁为错误买单」写进契约，而不是留给默认信任。

```python
# IP-264 SPF：LiDAR 感知生产函数与边际信息
def marginal_info(u, b, r, P, eta, I, deadline_left):
    sigma2 = SIG_BG2 + (KAPPA*r**4 + IOTA*I) / (P*b*eta)
    dJ_db  = (KAPPA*r**4 + IOTA*I) / (P*eta*b**2 * sigma2**2)   # 严格递减
    return dJ_db * exp(-RHO*(b*DT + PROC))                       # 时间折扣

# IP-265 BAM：光束市场（原始-对偶 / tâtonnement，<=5 轮）
def beam_market(contracts, sectors, budget, price_e, warm_prices):
    p = warm_prices
    for _ in range(MAX_IT):
        bids = {}
        for c in contracts:
            for a in actions_for(c, sectors):          # 驻留/重扫/注视/问/探
                if not c_ras_wm.certify_info(a): continue   # 信息动作也过安全认证
                val = c.w * marginal_risk_reduction(c, a)
                bids[(c, a)] = val / (cost(a) + price_e*emission(a) + p[a] + EPS)
        alloc = solve_capacity(bids, budget)           # 按 bid 降序 + 容量约束
        p = dual_ascent(p, alloc)                      # p_c 即风险影子价
        if converged(p): break
    return alloc, p

# IP-266 CCR + IP-270 SPL：账本、偿付性与安全优先降级
def ledger_step(ledger, alloc, evidence):
    for c in ledger.active:
        c.r_bar = certified_risk_bound(c, alloc, evidence)   # 保守上界
        c.status = 'honored' if c.r_bar <= c.eps + MARGIN else 'degraded'
    # 预算不足时按严重度字典序降级：高 sev 永不让位给出价
    return lexicographic_downgrade(ledger, key=lambda c: (-c.sev, c.w))

# IP-267 LIX：互干扰定价（cap-and-trade 或 Pigouvian）
def interference_price(peers, cap, social_cost):
    if CAP_AND_TRADE:
        return clear_market(peers.emission_demands, cap)     # 出清价
    return d_social_cost_d_emission(peers)                   # Pigouvian

# IP-268 RPA：物理层认证（挑战-响应 + 双向测距）
def authenticate(returns, code, jitter):
    r_auth  = code_match_residual(returns, code)             # 无码者 2^-κ
    r_relay = two_way_timing_residual(returns, jitter)       # 中继测距偏差
    return r_auth, r_relay

# IP-269 PCC：证明携带证书
def issue_certificate(c, evidence, alloc):
    pi = commit(challenge=c.code, raw_hash=H(evidence.raw),
                ts=now(), residuals=evidence.residuals,
                sig=sign(VERIFIER_KEY))
    J = build_J_market(c, alloc, evidence)
    assert Verify(pi, J)                                     # 第三方可复算
    return J, pi

# IP-274 主闭环（R69 之上插入市场层；熔断即逐指令退回 R69）
def MARKET_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c_cal, U_cal, _ = M.cof.step(...)
    # 1) 证据：物理层认证 + 跨源复核；任一异常先隔离证据
    r_auth, r_relay = M.rpa.authenticate(obs.returns, M.code, M.jitter)
    if r_auth > TAU_AUTH or r_relay > TAU_RELAY:
        M.ledger.quarantine(obs); M.mfm.trigger('poisoned_evidence')
    # 2) 价格：干扰价（慢频出清）+ 风险影子价（热启动增量）
    p_e = M.lix.price(M.peers, M.cap, M.social_cost)
    alloc, p = M.bam.beam_market(M.ledger.active, M.sectors, M.budget, p_e, M.prices)
    M.prices = p
    # 3) 执行感知/验证动作（驻留/重扫/注视/问句/探针），得证据
    ev = M.execute(alloc)
    # 4) 契约偿付性；不满足高严重度契约 → fail-safe，不执行任务动作
    M.ledger = M.ccr.ledger_step(M.ledger, alloc, ev)
    if not M.ledger.solvent(M.SEV_CRITICAL):
        M.mfm.trigger('insolvent')
        return M.r69_fallback(...)                # 逐指令退化为 R69 保守
    # 5) 签发证明携带证书（分级），审计异步
    for c in M.ledger.active:
        J, pi = M.pcc.issue_certificate(c, ev, alloc)
        M.ledger[c].transcript = pi
    M.vqa_m.submit_async(M.ledger, alloc, p)
    # 6) 不变量硬门：安全永不上架
    assert invariant_satisfied(M.ledger, obs)     # ℐ 不可被任何 w_c 交换
    return M.ledger, alloc, p
```

## 3. 推导

**引理 19（LiDAR 边际信息的凹性与最优驻留）** `J_r(b)=1/σ_r²(b)` 严格凹增，`dJ/db ∝ b^{−2}·(κr⁴+ιI)` 随 b 递减。给定单位光子成本 μ、排放价 p_e 与期限折扣，最优驻留 `b*` 满足 `(dJ/db)·e^{−ρbΔt} = μ + p_e·e_emit`；距离越远（r⁴ 大）`b*` 越大，期限越紧（折扣项压低）`b*` 越小。推论：**同一帧内不可能对所有方向都高分辨**——分辨率必须被分配，这正是市场存在的物理原因，而非叙事装饰。

**引理 20（互干扰的价格无政府状态界）** 简化模型：机器人 i 发射 `e_i`，私人收益 `v·e_i − (c/2)e_i²`，对他人外部成本 `γ·e_i`。社会最优 `e* = (v − γ(n−1))/c`（需 `v > γ(n−1)`），非合作均衡 `e_NE = v/c`，故 `e_NE/e* = v/(v − γ(n−1)) > 1`。Pigouvian 税 `t = γ(n−1)` 使私人最优回到社会最优；cap-and-trade 在无市场力时出清价等于 t，达到社会最优；有市场力时 `PoA ≤ (e_NE/e*)²`。推论：**不内部化干扰，多机 LiDAR 的"看得更清"是集体幻觉**——每台都多打光，集体信噪比反而下降。

**引理 21（λ 是风险影子价格）** 单契约、`γ=0`、诚实通道、`U_c` 线性 `w·(ε_c − r̄_c)` 时，市场程序退化为 `max_x w·(风险下降) − Σcost`，KKT 给出 `p_c = w·∂r̄/∂(收紧量)`，恰是 R69 `λ_floor` 的定义（单位风险收紧的边际成本）。故 R69 是 MARKET 在边界上的退化，而不是并列的替代品。

**引理 22（证明携带证书的欺骗上界）** 若脉冲码熵 κ bit、证据纪律 k 个正交源、单源欺骗率 δ_p、源间相关 ρ<1，则签发错误偿付证书的概率 `≤ 2^{−κ} + δ_p·ρ^{k−1} + exp(−2m²/Σ_i b_i²)`（Hoeffding 对风险上界估计）。物理层认证把 R69 引理 18 的「回答投毒」扩展到「回波投毒」；且 PCC 使第三方可复算，伪造需同时攻破密码学承诺。

**定理 18（MARKET 严格包含 R69 且安全不回归）** 在「单契约、零干扰、诚实通道、线性价值」边界上，MARKET 的分配与证书**逐指令**等于 R69 FLUID-RAS；一般情况下 MARKET 的可行域 `𝒳_ℐ ⊆` R69 安全可行域（因 ℐ 是硬约束），且当市场不可行/被操纵/证据投毒时熔断并退回 R69 保守。故安全侧永不弱于 R69，效率侧只在**可交易风险**上获得分配增益。

**定理 19（安全优先降级抗出价操纵）** 采用严重度字典序降级（定义 320）时，任何契约提高 `w_c` 都不能使更高 `sev_c` 契约被降级；因此对安全关键契约，降级规则对出价是**占优策略可防操纵**的。这把"最高出价者受保护"的风险限制在低严重度、可交易性能契约内——市场可以决定"看多清"，但不能决定"谁先安全"。

**定理 20（分级 SLA 的激励相容与防通胀）** 在单交叉条件下，菜单 `{(v, price_v)}` 使高风险/高 θ 契约自愿选高验证级别（激励相容）；且因证书证明携带，签发方无法在不被第三方复算发现的情况下抬高 tier，故 tier inflation 概率 `≤ 2^{−κ} + negl(λ_crypto)`。逆向选择由菜单缓解，道德风险由随机审计与保修条款对齐。

## 6. 本轮最大风险

**一句话**：MARKET-RAS 把"该看哪里、该信多少"交给市场，前提是**价格（支付意愿 w_c）是风险的正确代理**；一旦 w_c 被误设或被策略性主体操纵，系统会以最优的效率把稀缺感知资源分配给**错误的危险**，并签发一份**可审计、可复算、却与真实风险无关**的"合规"证书——**高效地错，比低效地对更危险**。

**次级风险与缓解**：
1. **把安全市场化**（最高出价者受保护）→ 定义 319 不可交易不变量 ℐ + 定义 320 严重度字典序降级 + 定理 19；
2. **价格信号被投毒**（用假证据压低/抬高 w_c）→ RPA 物理层认证 + k 正交证据 + PCC 第三方复算 + MFM 熔断；
3. **LiDAR 互干扰定价依赖可观测的发射与重叠**（隐藏发射/市场力）→ cap-and-trade 配额审计 + 引理 20 的 PoA 界 + 邻域广播；
4. **效用误设/多委托人目标冲突** → MFM 监测 + 契约显式化（SLA）+ 保守回退；
5. **实时预算被市场迭代击穿** → 价格慢频（20Hz）、分配快频热启动、|C|/|A| 上限、熔断降级。

## 3. 关键算法伪代码

```python
# IP-264 SPF：边际信息（严格凹，随驻留递减）
def marginal_info(u, b, r, P, eta, I):
    sigma2 = SIG_BG2 + (KAPPA*r**4 + IOTA*I)/(P*b*eta)
    return ((KAPPA*r**4 + IOTA*I)/(P*eta*b**2*sigma2**2)) * exp(-RHO*(b*DT+PROC))

# IP-265 BAM：光束市场（原始-对偶，热启动，<=5 轮）
def beam_market(contracts, sectors, budget, price_e, p):
    for _ in range(MAX_IT):
        bids = {}
        for c in contracts:
            for a in actions_for(c, sectors):
                if not c_ras_wm.certify_info(a): continue
                bids[(c,a)] = (c.w*marginal_risk_reduction(c,a)) / (
                    cost(a) + price_e*emission(a) + p[a] + EPS)
        alloc = solve_capacity(bids, budget)      # bid 降序 + 容量
        p = dual_ascent(p, alloc)                 # p_c 即风险影子价
        if converged(p): break
    return alloc, p

# IP-266 + IP-270：账本偿付性与安全优先降级

    return lexicographic_downgrade(ledger, key=lambda c: (-c.sev, c.w))

    assert Verify(pi, J)                          # 第三方可复算
    return J, pi

# IP-274 主闭环：R69 + 市场层；熔断即逐指令退回 R69
def MARKET_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c_cal, U_cal, _ = M.cof.step(...)
    r_auth, r_relay = M.rpa.authenticate(obs.returns, M.code, M.jitter)
    if r_auth > TAU_AUTH or r_relay > TAU_RELAY:
        M.ledger.quarantine(obs); M.mfm.trigger('poisoned_evidence')
    p_e = M.lix.price(M.peers, M.cap, M.social_cost)
    alloc, p = M.bam.beam_market(M.ledger.active, M.sectors, M.budget, p_e, M.prices)
    M.prices = p
    ev = M.execute(alloc)                         # 驻留/重扫/注视/问/探
    M.ledger = M.ccr.ledger_step(M.ledger, alloc, ev)
    if not M.ledger.solvent(M.SEV_CRITICAL):
        M.mfm.trigger('insolvent'); return M.r69_fallback(...)
    for c in M.ledger.active:
        J, pi = M.pcc.issue_certificate(c, ev, alloc)
        M.ledger[c].transcript = pi
    M.vqa_m.submit_async(M.ledger, alloc, p)
    assert invariant_satisfied(M.ledger, obs)     # 安全永不上架
    return M.ledger, alloc, p
```

## 4. 推导

**引理 19（LiDAR 边际信息的凹性与最优驻留）** `J_r(b)=1/σ_r²(b)` 严格凹增，`dJ/db ∝ b^{−2}(κr⁴+ιI)` 递减。最优驻留满足 `(dJ/db)e^{−ρbΔt}=μ+p_e·e_emit`；远距离 r⁴ 大 ⇒ `b*` 增，紧期限 ⇒ `b*` 减。系：同一帧不可能全向高分辨，分辨率必须被分配——市场有物理必然性。

**引理 20（互干扰的价格无政府状态界）** 私人收益 `v e−(c/2)e²`、外部成本 `γe`、n 台：`e*=(v−γ(n−1))/c`，`e_NE=v/c`，`e_NE/e*=v/(v−γ(n−1))>1`。Pigouvian `t=γ(n−1)` 或 cap-and-trade 出清价恢复社会最优；有市场力时 `PoA≤(e_NE/e*)²`。系：不内部化干扰，多机"看得更清"是集体幻觉。

**引理 21（λ 是风险影子价格）** 单契约、`γ=0`、诚实通道、线性 `U_c=w(ε_c−r̄_c)` 时，市场程序退化为 `max_x w·风险下降−Σcost`，KKT 得 `p_c=w·∂r̄/∂(收紧量)=λ_floor`。故 R69 是边界退化。

**引理 22（PCC 欺骗上界）** 脉冲码熵 κ、k 正交源、单源欺骗率 δ_p、源间相关 ρ<1：错误偿付证书概率 `≤ 2^{−κ}+δ_pρ^{k−1}+exp(−2m²/Σb_i²)`。物理层认证把 R69 引理 18 的"回答投毒"扩展到"回波投毒"。

**定理 18（严格包含且安全不回归）** 单契约/零干扰/诚实/线性边界上，MARKET 与 R69 逐指令相同；一般情形 `𝒳_ℐ ⊆` R69 安全可行域，市场不可行/被操纵/投毒时熔断退回 R69。安全侧永不弱于 R69，效率增益只在可交易风险上。

**定理 19（安全优先降级抗出价操纵）** 严重度字典序降级下，提高 `w_c` 不能使更高 `sev_c` 契约被降级；对安全关键契约，降级规则对出价占优可防操纵。市场能决定"看多清"，不能决定"谁先安全"。

**定理 20（分级 SLA 激励相容与防通胀）** 单交叉 ⇒ 高风险/高 θ 自愿选高 tier；PCC 使签发方无法不被复算地抬高 tier，`tier inflation ≤ 2^{−κ}+negl(λ_crypto)`。

## 7. 与 UniBot/G1 的落地映射

把契约实例化为 G1 上的四个下游：**导航避障**（`ε_nav` 中等、期限短、低 sev）、**抓取对准**（`ε_grasp` 高精度、期限中、低 sev）、**人机安全**（`ε_human` 极小、期限极短、最高 sev）、**远程标准化 API 的合规证书**（监管/保险，需可审计、可复算）。LiDAR 光束扇区对应头/腰视角；互干扰来自共享场地内的其他 G1；`p_e` 可由赛方统一广播或本地邻域出清。落地顺序：① 单机 SPF 标定 + 契约账本（E301/E303）；② 单机光束市场（E302/E311）；③ 双机干扰定价（E304/E305）；④ 物理层认证与 PCC（E306/E307）；⑤ 治理与熔断（E310/E313）。关键接口：LiDAR 原始回波与时间戳、脉冲码控制、发射功率上限、契约注册/审计 API。

## 8. 本轮最大风险

**一句话**：MARKET-RAS 把"该看哪里、该信多少"交给市场，前提是**支付意愿 w_c 是风险的正确代理**；一旦 w_c 被误设或被策略性主体操纵，系统会以最优效率把稀缺感知资源分配给**错误的危险**，并签发一份**可审计、可复算、却与真实风险无关**的"合规"证书——**高效地错，比低效地对更危险**。

**次级风险与缓解**：把安全市场化（ℐ 不可交易 + 严重度字典序 + 定理 19）；价格信号被投毒（RPA + k 正交证据 + PCC + MFM）；互干扰定价依赖可观测发射（配额审计 + PoA 界 + 邻域广播）；效用误设/多委托人冲突（MFM + 显式 SLA + 保守回退）；实时预算被市场迭代击穿（20Hz 慢频价格 + 帧内热启动 + |C|/|A| 上限 + 熔断降级）。
