# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「开源软件」×「容错控制」）

> 第 68 轮 CALM-RAS 把「标定」升格为在线潜变量，让闭环第一次能问「我的测量还准吗」。但它自陈的最大风险——**缓变故障落在标定带宽内被当作漂移“标好”而隐形**——暴露了一个更深的元失败：R68 为提升一致性检验灵敏度，刻意用单 trunk 五头把各头噪声相关系数推到 ρ_c>0.7（引理 15）。降噪上这是对的，但它同时把 COF / CFA / WM / ERG **焊死在同一个失效域里**：共享 trunk 的盲区会让五个头**一起错**。R68 用“同源”换灵敏度，欠下了“多样性”这笔账。
>
> 更一般地，R66–R68 的容错策略始终是**被动容错（passive FTC）**：遇不确定就抬 λ、缩 k、降级——只会“收紧”，不会“换路”。真实系统的容错还有另一半：故障隔离后，用剩余健康资源**重构**控制分配，继续完成任务（fail-operational）。而要让“换路”可信，需要一套治理机制来保证被换上来的组件**真的独立、真的可溯源、真的经过契约验证**——这正是「开源软件」范式（fork / 独立复现 / 接口契约 / 溯源 / 多审计者）擅长的事。
>
> 本轮核心命题：
>
> **把闭环从“单一家族的自适应系统”升级为“双族冗余 + 契约重构 + 溯源治理”的开源式主动容错生态——FORGE-RAS（Fork-Oracle-free-Reconfiguration-Governed-Ecosystem RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**坏了还能不能继续、还有没有别的办法**」——故障隔离后先尝试认证重构保住任务层，无路可走才优雅降级，且任何“新路子”都必须通过契约与溯源。

## 0. 直觉与动机

**灵感 1（开源软件 → fork 权的本质是“可独立复现的第二意见”）**
直觉：开源之所以比闭源更能抗单点腐败，不是因为代码免费，而是因为 **fork 权**：任何人可以拿一份独立副本、用不同实现重写、再用公开测试对拍。映射到控制闭环：**应对共模失效最有效的手段不是“更多同类模型”，而是“结构不同的独立见证者”**——解析力学模型、能量/动量守恒残差、集合隶属（set-membership）检查器、独立小模型，它们与学习型 MTM 的失效模式天然正交。R68 的单 trunk 五头是“同一份代码开五个分支”，不是 fork；R69 要补的是**跨结构族的 fork**。

**灵感 2（开源软件 → 接口契约 + 语义化版本，是热替换的安全前提）**
直觉：开源生态能容忍海量陌生组件互换，靠的是 **API 契约 + SemVer + 兼容性测试**。主动容错要做“组件级热替换 / 重构”，同样必须先有契约：每个可替换组件声明其 I/O 模式、**假设集 A_C**、性能包络、已知故障模式与来源摘要；替换只允许发生在契约精化关系成立且符合性测试通过时。否则“换上一个备份估计器”可能悄悄破坏闭环的假设，制造比原故障更大的事故。

**灵感 3（开源软件 → 溯源（SBOM）+ 可复现构建，治理供应链投毒）**
直觉：开源的最大新风险是供应链攻击（依赖投毒、构建不可复现）。解法是**物料清单 SBOM + 哈希溯源 + 可复现构建**。闭环里同理：任何要进入实时流的适配器/见证者，都必须带不可伪造的来源证明与可重建的构建配方；只认证“来源可信”还不够，还要能**独立重建出同一二进制**，才能排除“源码干净、构建投毒”。这把 R68 的 CAC 从“指标过关”扩展为“指标过关 ∧ 来源闭合 ∧ 构建可复现”。

**灵感 4（容错控制 → 从被动降级到主动重构：控制分配 + 任务层不变式）**
直觉：R66–R68 的“抬 λ / 缩 k”是**被动容错**，把不确定性统一翻译成“更保守”，简单但浪费能力。**主动容错**在 FDI 之后解一个**控制分配（control allocation）**：在健康执行器/传感器集合上重新分配任务需求，只要还存在可行解，就维持当前任务层（fail-operational）；只有当重构不可行时，才沿**任务层阶梯**有序降级（graceful degradation），且降级只允许“下行需认证、上行需驻留”。

**灵感 5（两灵感合流 → FORGE-RAS 七组件 + 对 R68 风险的正面拆解）**
R68 的“标定吸收缓变故障”本质是一次**跨组件共模失效**：COF 与 CFA 共享 ĉ、共享 z，故它们不会互相揭发。R69 的正面拆解是：
1. **DRM 双族冗余网**：快速族（同构、高 ρ_noise，继承 R68 的降噪）＋ 见证族（异构、低 ρ_fail，专盯共模）。二者分工对应“噪声相关”与“失效相关”两个正交轴——这是本轮最关键的一刀。
2. **CXR 契约治理重构引擎**：主动 FTC，FDI→控制分配→任务层不变式；不可行才降级。
3. **PROV 溯源与可复现账本**：SBOM 式证词 + 重构建校验，堵供应链投毒。
4. **MAC 多审计者共识**：异构独立审计者，分歧熵触发升级，替代单点 VQAuditor。
5. **FCB 故障语料库与对抗赏金**：持续注入、按覆盖新颖度奖励，反例自动入回归集，直接补 R68 “canary 未覆盖缓变故障”的缺口。
6. **FMP 分叉-合并策略**：影子分叉 → 在 Γ 上帕累托评估 → 认证合并，限制活跃分叉数防版本爆炸。
7. **RAS† 继承核**：ACH-RAS / EFS / C-RAS-WM / ERS-WM / λ_floor 全部保留；CXR 只在重构可行时接管，λ_floor 是永久硬下限。

**关键张力（本轮的理论支点）**：R68 引理 15 的“同源共模抵消”只对**噪声**成立，对**失效**恰好相反。共享 trunk 使 ρ_noise↑（差异法方差 ∝ 1−ρ_noise，降噪），却使 ρ_fail→1（一起漏检）。圆桌上必须同时写下两条：`Var(Δ) ∝ (1−ρ_noise)σ²` 与 `P(∩ miss) ≥ max P(miss_i)`。R69 的双族架构就是让前者的收益保留、后者的风险被结构异构打断。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（FORGE-RAS 总览）** FORGE-RAS = (DRM, CXR, PROV, MAC, FCB, FMP, RAS†)。五条不变式（在 R68 三不变式之上叠加）：
(i) **多样性下限**：每个安全关键判据至少由 2 个**跨结构族**见证者计算，跨族失效相关 ρ_fail < ρ_div（默认 0.3）；
(ii) **认证重构**：故障隔离后优先在健康资源上重构以维持最高可行任务层；禁止未经认证的“静默继续”，也禁止无条件全局收紧；
(iii) **溯源闭合**：无有效 provenance 的组件不得进入实时流（离线影子流不受限）；
(iv) **单写者**：任一执行器同一时刻只接受一个已认证控制源，重构切换期间由驻留逻辑保证；
(v) **保守兜底继承**：λ_floor(U) 与 R68 全部安全红线不因重构而放松。

**定义 294（冗余双族与两类相关）**
- 快速族 F_fast：同构、共享先验（如 MTM 五头），追求高 ρ_noise；
- 见证族 F_wit：异构（解析模型、守恒残差、集合隶属检查器、独立小模型），追求低 ρ_fail；
- 噪声相关 ρ_noise(i,j) = Corr(δy_i, δy_j | benign noise)；
- 失效相关 ρ_fail(i,j) = sup_f P(miss_i ∧ miss_j | f) / max(P(miss_i|f), P(miss_j|f))；
- **多样性预算** D = 1 − max_{i∈F_fast, j∈F_wit} ρ_fail(i,j)。
设计目标：`max ρ_noise within F_fast`，`min ρ_fail across F_fast × F_wit`——两者是**正交轴**，不可用同一指标替代。

**定义 295（N-版本免神谕表决）** 设 k 个见证者对风险输出 r_i。离散裁决：若至多 f 个失效且 k ≥ 2f+1，取多数即正确。连续裁决：取截尾中位数 r̂ = median(r)；分歧度 δ_div = (Q_{0.9}(r) − Q_{0.1}(r)) / scale。若 δ_div > τ_div：**不抬 λ**，而是标记 fault-suspect 并触发 CXR（定义 297）——把“分歧”当作可执行信息而非单纯的保守信号。

**定义 296（能力契约）** 组件 C = (schema, A_C, E_C, F_C, prov_C, ver)。精化序 C₂ ⪰ C₁ ⇔ schema 相等 ∧ A_C₂ ⊆ A_C₁（假设更少更强）∧ E_C₂ ⊇ E_C₁ ∧ F_C₂ 覆盖 F_C₁。在线替换 C₁→C₂ 允许 ⇔ C₂ ⪰ C₁ ∧ ConformanceTest(C₂, Γ) = PASS ∧ Prov(C₂) = valid。

**定义 297（重构控制分配）** 设 FDI 后的健康资源集 ℋ_t，任务需求 w*，分配矩阵 B(ℋ_t)，权重 W：
`u* = argmin_{u∈𝒰(ℋ_t)} ‖W(B(ℋ_t)u − w*)‖²  s.t. 安全包络与执行器限幅`。
可行指示 ρ_reconf(ℋ_t, w*) ∈ {0,1}。若当前任务层 T 不可行 → 进入定义 299 的降级。

**定义 298（容错可达集与重构裕度）** R_T(ℋ) = { x | ∃ 策略使 x 在时域 T 内保持于任务层 T 的不变集 S_T }。重构裕度 m_re ≈ dim(𝒰(ℋ)) − rank(B(ℋ))（可用自由度减任务需求秩）。容错可运行 ⇔ x_t ∈ R_T(ℋ_t)。

**定义 299（任务层与优雅降级）** T₀ 满任务 / T₁ 降能力 / T₂ 安全停机。降级：仅当 R_T(ℋ_t) 为空时下行，且下行需 MAC 复核；升级：仅当连续驻留 τ_dwell 且 MAC 通过且重构认证通过。层间设滞回带 h_tier，防抖振。

**定义 300（多审计者共识）** 异构审计者 a_1..a_n 各给裁决 v_i 与校准置信 c_i。以对数几率池化聚合：
`L = Σ_i w_i·logit(c_i)·v_i`，w_i 按审计者历史校准误差反比。分歧熵 H(A) = H(vote 分布)。若 H(A) > τ_audit 或任一审计者一票否决 → 升级人工/全局降级。注意 n_eff = n / (1+(n−1)ρ_audit)（引理 20）。

**定义 301（溯源账本与可复现构建）** 每个可部署件 a 的证词 tuple `(h, recipe, deps, test_report, signer)`。Prov(a)=1 ⇔ 哈希链有效 ∧ 签名可信 ∧ 独立重构建得到同一哈希（reproducible match）。供应链投毒检出概率见引理 19。

**定义 302（故障语料库与对抗赏金）** Γ = {(φ, family, expected_invariant, severity, discoverer)}，φ 为故障注入器参数。新颖度 nov(φ) = dist(φ, 最近邻 Γ)。赏金 Bounty = α·nov·severity；新反例自动提交 Γ 并挂入回归门。覆盖度 Cov(Γ) 作为 canary 集的显式下界（直接回应 R68 的覆盖盲区）。

**定义 303（分叉-合并策略）** 当主组件退化指标超 τ_fork 时在影子流 fork 变体 C′；在 Γ 上评估；仅当 C′ 在 (安全性, 任务能力, 延迟) 上帕累托占优 ∧ 契约通过 ∧ 溯源通过 ∧ 回归通过时合并；活跃分叉数 ≤ N_fork，超出按贡献度淘汰。

**定义 304（任务层不变式与安全裕度）** 每层 S_T 定义安全裕度 μ_T = dist(x, ∂S_T)。重构必须在 μ_T ≥ μ_min 内完成；否则先降层再重构。此定义保证“重构本身不越界”。

**定义 305（主动-被动容错统一开关）** 令 `mode = CXR` iff ρ_reconf(ℋ_t, w*) = 1 ∧ x_t ∈ R_{T}(ℋ_t)，否则 `mode = PASSIVE`（执行 R68 的 λ_floor + 收缩）。即：**能换路就换路，换不了才收紧**，且收紧通道永不失效。

**定义 306（共模可见性指标）** CMV = E_{f∈common-mode}[1 − Π_{i} miss_i(f)]（跨族至少一个见证者命中的概率）。验收要求 CMV ≥ 1 − ρ_div，并作为 J_FORGE 的强制字段。

**定义 307（FORGE 证书）** J_FORGE = (J_CALM, prov_root, diversity_matrix, reconfig_verdict, tier, auditor_consensus, corpus_version, forge_ver)。Valid ⇔ Valid(J_CALM) ∧ Prov 树闭合 ∧ min_{cross} ρ_fail ≤ ρ_div ∧ 任务层转移已认证 ∧ 单写者成立。

**定义 308（管线升级）** 离线：Γ 生成 → 双族训练/构建 → 契约注册 → 可复现构建 → MAC 初审。在线：每 60s 影子训练（继承 CAC）＋ 每 T_fork 评估分叉 ＋ 事件驱动 CXR ＋ 每 24h 语料库覆盖审计。所有在线写操作仍只发生在影子流。

```python
# IP-253 DRM：双族冗余网（快速族降噪 + 见证族抗共模）
class DiverseRedundancyMesh:
    def __init__(self, fast_family, witness_family, rho_div=0.3):
        self.fast, self.wit, self.rho_div = fast_family, witness_family, rho_div

    def judge(self, x):
        r_fast = [f(x) for f in self.fast]          # 同构，高 rho_noise
        r_wit  = [w(x) for w in self.wit]           # 异构，低 rho_fail
        r_hat  = trimmed_median(r_fast + r_wit)
        delta  = disagreement(r_fast + r_wit)       # Q90-Q10 / scale
        if delta > TAU_DIV:
            return {'verdict': 'FAULT_SUSPECT', 'r': r_hat, 'route': 'CXR'}
        cmv = common_mode_hit(r_wit)                # 见证族是否揭发共模
        return {'verdict': 'OK' if cmv else 'DEGRADED', 'r': r_hat, 'cmv': cmv}


# IP-254 CXR：契约治理的主动重构（FDI 后控制分配）
class ContractReconfiguration:
    def step(self, H_t, healthy_set, w_star, tier):
        if not x_in_reachable_set(healthy_set, tier):        # 定义 298
            return self.graceful_down(tier)                  # 定义 299
        u, feasible = control_allocation(healthy_set, w_star) # 定义 297
        if feasible and safety_margin(healthy_set) >= MU_MIN:
            return {'cmd': u, 'tier': tier, 'mode': 'CXR'}
        return self.graceful_down(tier)

    def graceful_down(self, tier):
        target = next_tier(tier)                             # T0->T1->T2
        assert dwell_ok(target) and mac_review(target)       # 驻留+多审计
        return {'cmd': safe_stop_or_reduced(tier), 'tier': target, 'mode': 'PASSIVE'}

# IP-256 MAC：多审计者共识
class MultiAuditorConsensus:
    def audit(self, case):
        votes = [(a.verdict(case), a.conf(case), self.weight(a)) for a in self.auditors]
        L = sum(w * logit(c) * (1 if v else -1) for v, c, w in votes)
        H = entropy([v for v, _, _ in votes])
        if H > TAU_AUDIT or any(v == 'VETO' for v, _, _ in votes):
            return 'ESCALATE'
        return 'PASS' if L > 0 else 'REJECT'


# IP-257 FCB：故障语料库 + 对抗赏金（覆盖驱动的红队）
class FaultCorpusBounty:
    def inject_round(self, n):
        new = []
        for _ in range(n):
            phi = self.sample_injector()
            nov = self.novelty(phi)
            if self.breaks_invariant(phi):
                new.append((phi, nov, self.severity(phi)))
        self.corpus.extend(new)                       # 反例入库
        self.regression_gate.extend(new)              # 自动挂回归
        return sorted(new, key=lambda t: -t[1]*t[2])  # 赏金排序


# IP-258 FMP：分叉-合并
class ForkMergePolicy:
    def maybe_fork(self, C):
        if degradation(C) > TAU_FORK and len(self.active_forks) < N_FORK:
            return shadow_fork(C)
        return None

    def maybe_merge(self, C):
        if pareto_dominates(C, self.live, keys=('safety','task','latency')) \
           and ProvenanceLedger.verify(C) and contract_ok(C) and regress_ok(C):
            return atomic_swap(self.live_ptr, C)
        return None

def FORGE_RAS_round(M, obs):
```

## 3. 推导

**引理 16（相关性的双刃：噪声相关 ≠ 失效相关）** 设快速族共享 trunk 误差 e。在良性扰动下，差异量 Δ = y_i − y_j 的方差为 `Var(Δ) = 2(1−ρ_noise)σ²`，ρ_noise↑ 使差异法降噪（R68 引理 15 成立的正确范围）。但失效不是噪声：若故障 f 使 trunk 产生同向错误，则各头**同时失效**，`P(∩_i miss_i | f) = P(miss_trunk | f) ≥ max_i P(miss_i | f)`，与 ρ_noise 无关。故 R68 的 SNR 增益**不可迁移到共模故障**；跨结构族见证者以 ρ_fail 打断该同向性，共模漏检 ≤ ρ_fail。系：**灵敏度与多样性必须分轴治理**，这正是双族架构存在的理由。

**引理 17（稳健表决界）** 离散：k 个见证者、至多 f 个任意失效，k ≥ 2f+1 时多数裁决正确。连续：截尾中位数的崩溃点为 ⌊(k−1)/2⌋/k；在 ≤ f 个失效下，估计误差被第 f+1 与第 k−f 顺序统计量夹住。系：见证族只需 3 个异构成员即可容忍 1 个任意失效，工程上远低于“三份大模型”的代价（见复杂度）。

**引理 18（重构可行性与任务层单调）** ρ_reconf 对故障集单调不增：ℋ′ ⊆ ℋ ⇒ 𝒰(ℋ′) ⊆ 𝒰(ℋ) ⇒ ρ_reconf(ℋ′) ≤ ρ_reconf(ℋ)。若 m_re > 0 且 x_t ∈ R_T(ℋ)，则存在分配 u* 保持 S_T；若 R_T 为空，则任何控制都必然越界或必须降层。系：**不存在“既不降级又不重构”的第三态**——这堵死了 R68 式的“静默继续”。

**引理 19（溯源可靠性）** 若哈希链与签名不可伪造（安全参数 λ_sec）且独立重构建要求逐位一致，则未检出的投毒件概率 ≤ `2^{-λ_sec} + ε_build`。非确定性/构建期注入若改变二进制，重构建以 1−ε_repro 揭发；若刻意逐位一致（如触发式后门），则由 Γ 的对抗注入侧面覆盖。系：**溯源保证“来源与构建”可信，但不保证“语义正确”**——语义正确仍依赖契约符合性与语料库覆盖（这是最大风险的结构性来源）。

**引理 20（审计共识的独立性收益与饱和）** n 个独立审计者单错率 p，多数错率 ≤ `exp(−n·D(1/2‖p))`（Chernoff）。若审计者存在相关性 ρ_audit（同底座模型 / 合谋 / 羊群），有效人数 `n_eff = n/(1+(n−1)ρ_audit)`，共识收益随 ρ_audit 快速饱和。系：**审计者必须异构**，与见证族同构要求一致；否则“多审计”只是同一双眼睛的复读。

**定理 16（FORGE-RAS 端到端风险一致性）** 在 R68 的 A87–A94 及 A95（跨族失效相关上界 ρ_div）、A96（溯源不可伪造）下，输出 τ_cmd 满足：
1. `P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + α_cm`，其中 `α_cm ≤ ρ_div`（引理 16）；
2. **共模覆盖**：对跨族共模故障，`CMV ≥ 1 − ρ_div`；R68 的缓变故障盲区被见证族截获；
3. **主动容错**：若 `ρ_reconf=1 ∧ x_t ∈ R_T`，任务层保持 T 且安全裕度 μ_T ≥ μ_min；否则单调降层至可行或 T₂ 安全停机（引理 18）；
4. **溯源闭合**：实时流出现未认证件概率 ≤ `2^{-λ_sec} + ε_build`（引理 19）；
5. **共识告警**：审计多数漏报率 ≤ `exp(−n_eff·D(1/2‖p))`，n_eff 计入 ρ_audit（引理 20）。

**定理 17（重构安全与无抖振降级）** 设任务层转移带驻留 τ_dwell 与滞回 h_tier。则：(i) 系统永远不处于“未认证的中间态”（单写者 + 驻留）；(ii) 层间切换次数在任意时长内 ≤ 2·(总需求变化量)/h_tier + 1（滞回界），无抖振；(iii) 下行只由 `R_T=∅` 触发、上行只由 `MAC=PASS ∧ 驻留` 触发，故不存在“为了性能悄悄升层”的通道。

## 6. 本轮最大风险

**一句话**：FORGE-RAS 的全部容错承诺押在「跨族见证者真的独立」这一假设上——若所谓“异构见证者”在深层仍共享同一数据源、同一预训练底座或同一物理盲区（**伪多样性 pseudo-diversity**），则 ρ_fail 被系统性低估，N-版本表决与多审计共识会**一致地错**，溯源只证明“来源可信”却不证明“语义正确”，系统将在“我们已经有多重独立校验”的错觉中失去对共模故障的检出能力——这是「开源式冗余」范式的原罪：**冗余越像仪式，独立性越像幻觉**。

**次级风险与缓解**：
1. **伪多样性**：ρ_fail 必须用 Γ 上的**失效对拍**实测而非架构自证；引入“独立性证伪实验”（故意让两族看同一坏数据，检验是否同步失效）；
2. **版本/分叉爆炸**：活跃分叉 ≤ N_fork + 帕累托淘汰 + 契约收敛；
3. **重构抖振**：驻留 τ_dwell + 滞回 h_tier + 定理 17 的切换上界；
4. **审计合谋/羊群**：异构底座 + n_eff 监控 + 随机化审计者抽样；
5. **供应链攻击面扩大**：溯源 + 可复现构建 + 最小依赖 + Γ 注入侧面覆盖；
6. **实时预算**：见证族用解析冗余（非大模型）+ 低频缓存，守住 2.9ms。

```python
    c, U, thr = M.cof.step(o['cal'], residuals(x_prime,o,...), sigma_stat(M))
    judge = M.drm.judge((x_prime, residuals(x_prime,o,...), o))   # 1) 双族裁决
    joint = M.cfa(residuals(x_prime,o,...), o['pi'], c, U)
    H_t, healthy = M.fdi(judge, joint)
    rec = M.cxr.step(H_t, healthy, w_star(x_prime), M.tier)   # 2) 主动重构
    if rec['mode'] == 'CXR':                                  # 3) 能换路就换路
        lam = max(M.efs.risk_scale(joint), thr['lam_floor'])
        k   = M.c_ras_wm.certified_prefix_reconf(...)
    else:                                                     #    换不了才收紧
        lam = max(M.efs.risk_scale(joint), thr['lam_floor'],
                  0.8 if (o['qual']['face']<0.8 or wm_drift) else 0.6)
        k   = M.c_ras_wm.certified_prefix(...)
    M.mac.audit({'fdi':(H_t,healthy),'recfg':rec,'cal':(c,U)})
    M.fcb.inject_round(M.bounty_batch)
    M.fmp.maybe_fork(M.shadow); M.fmp.maybe_merge(M.shadow)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)    # R68 认证提交
    return rec['tier'], lam, joint, (c,U), judge['cmv']
```

## 4. 推导

**引理 16（噪声相关 ≠ 失效相关）** 共享 trunk：良性扰动下 `Var(Δ)=2(1−ρ_noise)σ²`（ρ_noise↑ 降噪，R68 引理 15 的正确范围）；但故障 f 使 trunk 同向错时各头同时失效，`P(∩miss|f)=P(miss_trunk|f) ≥ max P(miss_i|f)`，与 ρ_noise 无关。故 R68 的 SNR 增益不可迁移到共模；跨族见证者以 ρ_fail 打断同向性，共模漏检 ≤ ρ_fail。**灵敏度与多样性必须分轴治理。**

**引理 17（稳健表决界）** 离散 k ≥ 2f+1 多数正确；连续截尾中位数崩溃点 ⌊(k−1)/2⌋/k，误差被顺序统计量夹住。3 个异构见证者即可容忍 1 个任意失效。

**引理 18（重构可行性单调）** ℋ′⊆ℋ ⇒ ρ_reconf(ℋ′) ≤ ρ_reconf(ℋ)。m_re>0 ∧ x∈R_T ⇒ 存在分配保持 S_T；R_T=∅ ⇒ 必越界或必须降层。**不存在“既不降级又不重构”的第三态。**

**引理 19（溯源可靠性）** 哈希链+签名不可伪造 + 独立重构建逐位一致 ⇒ 未检出投毒概率 ≤ `2^{-λ_sec} + ε_build`。但**溯源只保证来源/构建可信，不保证语义正确**——语义仍依赖契约与 Γ 覆盖。

**引理 20（共识独立性收益与饱和）** 独立审计者多数错率 ≤ `exp(−n·D(1/2‖p))`；相关性 ρ_audit 使 `n_eff=n/(1+(n−1)ρ_audit)`，收益随相关性饱和。审计者必须异构。

**定理 16（端到端风险一致性扩展）** A87–A96 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_cm`，`α_cm ≤ ρ_div`；
2. 共模覆盖 `CMV ≥ 1−ρ_div`，截获 R68 缓变故障盲区；
3. `ρ_reconf=1 ∧ x∈R_T ⇒ 任务层保持且 μ_T ≥ μ_min`，否则单调降层至可行或 T₂；
4. 实时流未认证件概率 ≤ `2^{-λ_sec}+ε_build`；
5. 审计多数漏报率 ≤ `exp(−n_eff·D(1/2‖p))`。

**定理 17（重构安全与无抖振）** 单写者+驻留 ⇒ 永不处于未认证中间态；滞回使层间切换次数 ≤ `2·(总需求变化)/h_tier + 1`；下行仅由 `R_T=∅`、上行仅由 `MAC=PASS ∧ 驻留` 触发 ⇒ 无“为提高性能悄悄升层”的通道。

## 7. 本轮最大风险

**一句话**：FORGE-RAS 的全部容错承诺押在「跨族见证者真的独立」这一假设上——若所谓“异构见证者”在深层仍共享同一数据源、同一预训练底座或同一物理盲区（**伪多样性 pseudo-diversity**），则 ρ_fail 被系统性低估，N-版本表决与多审计共识会**一致地错**，溯源只证明“来源可信”却不证明“语义正确”，系统将在“我们已有多重独立校验”的错觉中失去对共模故障的检出能力——这是「开源式冗余」范式的原罪：**冗余越像仪式，独立性越像幻觉**。

**次级风险与缓解**：伪多样性（Γ 上失效对拍 + 独立性证伪实验）；版本/分叉爆炸（N_fork + 帕累托淘汰 + 契约收敛）；重构抖振（驻留 + 滞回 + 定理 17 上界）；审计合谋/羊群（异构底座 + n_eff 监控 + 随机抽样）；供应链攻击面（溯源 + 可复现构建 + 最小依赖 + Γ 注入）；实时预算（解析冗余 + 低频缓存）。
