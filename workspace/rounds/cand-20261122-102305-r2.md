# 第 2 轮（本轮灵感：「闭环控制」×「可重构机构」）

> **基线**：v20 产出 MetricVoiceGauge-NCD-HUTDH-v20+IP-420–424（PCA/CTS/CFC/HPC/CFCtrl）。
> 本轮纪律：**安全不是静态几何的交集，而是闭环动态的不变式；证书不是单构型的快照，而是可重构流形上的层（sheaf）**。不推倒 v20：v20 的 PCA/CTS/CFC/HPC/CFCtrl 全部保留，作为 v21 的**感知前端**与**失效安全地板**。本轮只做一件事：**把“静态碰撞域”升级为“闭环生存域”，并让它在可重构机构的模式切换下仍然可粘合、可迁移、可监控**。

## 0. 直觉与动机

**灵感 1（闭环控制 → 证书必须是“可控不变集”，不是“安全点集”）**
直觉：v17–v20 的所有证书本质上是**开环快照**——在规划时刻用一个（越来越保守的）静态碰撞域 Θ_n^col 判断 θ 是否安全，然后交给控制器去执行。但真实系统有跟踪误差、扰动、执行器饱和与接触不确定性；一个“此刻零碰撞”的 θ，控制器完全可能在下 100ms 内把它推出安全域。于是后几轮只能不断放大 margin，活性被系统性吃掉。**反直觉点**：继续缩小安全域不是出路；出路是让证书“看见控制器”——把安全域从 `{θ : 零碰撞}` 换成 `{x : 存在反馈 u=π(x)，使闭环轨迹在 H 步内恒不碰撞}`，即**可控不变集 / 生存核 (viability kernel)**。控制器不再是证书的“执行者”，而成为证书的“证明部件”：它主动把状态维持在域内。于是同等安全等级下，静态 margin 可以变小，活性反而回来了。

**灵感 2（可重构机构 → 证书是分层流形上的层，不是单构型快照）**
直觉：可重构机构（模块化机械臂加减连杆、变形轮足、可切换夹爪、变刚度软手）在运行时改变**运动学结构与构型空间的拓扑**：自由度会变、参数空间维数会变、自碰撞与质心支撑多边形会突变。v20 的 Θ_n^col(o) 默认一个固定构型，一旦模式切换就整段失效。**反直觉点**：跨模式安全不能靠在切换点“重新算一遍证书”，因为切换瞬间存在一个**不属于任何稳定模式的过渡管 (transition tube)**——机构在变形途中既不是模式 m 也不是模式 m'。正确做法是把证书看成配置流形分层空间 `M = ⊔_m M_m` 上的一个**层 (sheaf)**：每个稳定模式一片生存核 V_n^{(m)}，模式之间用**迁移函子 R_{m→m'}` 与**切换守卫**粘合，过渡管用独立的瞬态证书覆盖。只有“两片证书在守卫上一致 + 过渡管可证安全”时，跨模式执行才被授权。

**灵感 3（两者统一 → 生存性证书的动态粘合）**
直觉：闭环给证书“时间维”（向前看 H 步），可重构给证书“模式维”（向旁看多个构型层）。两者合起来是一个**时空证书复形**：状态 (x, m) 在连续时间上演化，模式 m 在离散事件上跳变。核心创新：**闭环生存证书 (Closed-Loop Viability Certificate, CLVC)** 负责连续层的可控不变性；**可重构分层证书层 (Reconfigurable Stratum Sheaf, RSS)** 负责离散层的粘合；**模式切换生存调度器 (Mode-Switch Viability Governor, MSVG)** 负责在守卫集内触发切换并保证过渡管安全；**闭环证书监控器 (Closed-Loop Certificate Monitor, CLCM)** 在运行时把实际状态与生存核边界的距离当作反馈，逼近边界即触发最小限制回退。统一接口：**若 CLVC 给出见证控制律、RSS 给出跨层粘合见证、MSVG 确认切换在守卫内、CLCM 在线未越界，则计划被授权；否则逐级回退到 v20 静态证书（失效安全地板）**。

**与 v20 的关系（关键：安全契约的升级，而非继续收缩）**
v17→v20 的纪律是 `Exec_{v+1} ⊆ Exec_v`，代价是活性单调下降。v21 明确**改变安全契约**：
- **对真实零碰撞集 C_free 的可靠性 (soundness)** 仍是硬约束：`V_n ⊆ C_free`（生存核按定义要求 H 步内恒不碰撞），故 `Exec_v21 ⊆ C_free`；
- 但 v21 **不再机械要求** `Exec_v21 ⊆ Exec_v20`。因为 v20 的 Θ_n^col 只是 C_free 的一个过度保守子集，闭环恢复能力允许 v21 在**不降低安全等级**的前提下救回一部分被 v20 误杀的计划。形式化：`Exec_v21 = Exec_v20 ∪ Exec_v21^dyn`，其中 `Exec_v21^dyn` 的每一项都必须携带**动态见证**（见证控制律 + 扰动界 + H 步 rollout 证明）；当动态模型置信度不足时 `Exec_v21^dyn = ∅`，自动退回 v20。这是本轮最重要的方法论转向：**用动态证明换回活性，而不是继续用静态保守换安全**。

## 1. 研究问题（轮次升级版）

- **Q1（生存核的可计算性与保守性）**：如何在 50Hz 控制环内计算/近似 H 步可控不变集 V_n？用 HJ 可达性（低维精确但昂贵）还是 CBF-QP（高维实用但需构造 B）？如何保证近似 V̂_n 满足 `V̂_n ⊆ C_free`（不产生假安全）？跟踪误差与扰动界 D 如何标定，才能既不虚高（丢活性）又不虚低（丢安全）？

- **Q2（重构分层的粘合条件）**：如何定义配置流形 M 的分层与模式边界？迁移函子 R_{m→m'} 在参数空间维数变化（加/减连杆）时如何定义？两片生存核在切换守卫 G_{m→m'} 上的“一致”应如何判定（值一致、梯度一致、还是 barrier 一致）？过渡管证书如何覆盖变形途中的自碰撞与质心突变？

- **Q3（切换时序与瞬态安全）**：可重构机构的切换本身是耗时的（100ms–2s），切换期间动力学突变；如何用 MSVG 保证“只在守卫集内切换、且过渡管全程安全”？切换失败/卡死时如何回退到当前模式的可生存子集，而不是硬停在过渡态？

- **Q4（闭环监控与证书失效）**：CLCM 如何用 barrier 的边界距离构造运行时告警？当实际状态逼近生存核边界时，最小限制回退（减速/制动/切回 v20）如何与 APS 新鲜度阶梯、CFCtrl 的 τ_consensus 协调？如何避免监控器自身的延迟成为新的不安全源？

## 2. 设计原则（在 P31–P33 基础上新增 P34–P36）

**P34 闭环生存律（Closed-Loop Viability）**
设连续状态 `x=(q,q̇)`、控制 `u`、有界扰动 `d∈D`，闭环动力学 `ẋ=f(x)+g(x)u+d`。安全集 `C_free = {x : 无自碰撞 ∧ 无环境碰撞 ∧ 关节/力矩限 ∧ 质心在支撑多边形内}`。**生存核**定义为最大可控不变子集：
`V_n = ν(C_free) = { x∈C_free : ∀d∈D, ∃u=π(x), F(x,u,d)∈V_n }`。
证书必须携带**见证** `(π, D, B)`，其中 `B` 是控制屏障函数（CBF），满足 `sup_u [L_f B + L_g B·u] ≥ -α(B)`（`α` 为 class-κ 函数）。**只有 `V_n ⊆ C_free` 且见证可复核时证书才有效**；生存核只能用于证明“状态在 H 步内不越界”，不能绕过 C_free 的硬约束。

**P35 重构分层律（Reconfiguration Stratification）**
配置流形分层为 `M = ⊔_{m∈Modes} M_m`，每个模式 m 有独立生存核 `V_n^{(m)}`。证书是 M 上的层 F，满足：
- **限制映射**：模式边界上的点 `x∈∂M_m` 映射到相邻模式的参数空间；
- **粘合条件**：在切换守卫 `G_{m→m'} ⊆ ∂M_m ∩ ∂M_{m'}` 上，`V_n^{(m)}|_{G} = R_{m→m'}^{-1}(V_n^{(m')}|_{G})`（两片证书在守卫上互相包含）；
- **迁移函子**：`R_{m→m'}: Θ^{(m)} → Θ^{(m')}` 必须把源生存核映入目标安全集，`R_{m→m'}(V_n^{(m)}) ⊆ C_free^{(m')}`。
**没有粘合见证的跨模式执行一律拒绝**；单模式内退化为 v20。

**P36 切换瞬态保守律（Mode-Switch Transient Conservatism）**
切换期间机构经过过渡管 `T_{m→m'}(t)`（`t∈[0,τ_switch]`），可能不属于任何稳定模式。**过渡管必须单独认证**：存在瞬态 barrier `B_trans` 使 `B_trans ≥ 0` 全程成立；或切换只在**全模式通用收拢位** `S_stow ⊆ ⋂_m V_n^{(m)}` 内进行，此时瞬态退化为“保持收拢 + 缓慢变形”，可用 v20 静态证书覆盖。**切换只能收缩认证域**：切换开始后认证域收缩为 `V_n^{(m)} ∩ S_stow`，直到新模式的生存核被确认后才恢复。

## 3. 与基线的接口（如何退化）

- CLVC 失效（无动力学模型/无见证）⇒ 退回 v20 静态 Θ_n^col ⇒ 等价 v20（更保守）；
- RSS 失效（模式不可识别/无粘合见证）⇒ 锁定当前模式，禁止重构 ⇒ 等价 v20 单模式；
- RTF 失效（迁移函子无定义）⇒ 只允许在 `S_stow` 内切换，否则拒绝 ⇒ 等价 v20；
- MSVG 失效（切换调度不可用）⇒ 禁止切换，停留当前模式 ⇒ 等价 v20；
- CLCM 失效（监控器掉线/超时）⇒ 立即最小限制回退（制动 + v20 静态证书）⇒ 等价 v20；
- 过渡管证书缺失 ⇒ 只允许在全模式收拢位切换，否则拒绝 ⇒ 等价 v20；
- **安全继承（修正版）**：`Exec_v21 ⊆ C_free`（对真实自由空间 sound）；当 `Exec_v21^dyn = ∅` 时 `Exec_v21 = Exec_v20`。**v21 不保证 `Exec_v21 ⊆ Exec_v20`；它保证 `Exec_v21 ⊆ C_free`，并用动态见证换取活性。** 这是有意的方法论升级，风险见 §5。

## 4. 预期贡献

1. **闭环生存证书**：首次把碰撞证书从“静态安全点集”升级为“带见证控制律的可控不变集”，让控制器成为证书的证明部件，在同等安全下换回被静态 margin 吃掉的活性；
2. **可重构分层证书层**：把跨模式安全表述为配置流形上的层与粘合条件，给出迁移函子、切换守卫与过渡管证书，使可重构机构的安全从“切换点重算”升级为“分层可粘合”；
3. **切换瞬态证书**：识别“过渡管不属于任何稳定模式”这一被忽视的失效源，给出通用收拢位与瞬态 barrier 两条可证路径；
4. **运行时闭环监控**：用生存核边界距离构造最小限制回退，把证书从“规划期一次性检查”变成“执行期持续闭环”；
5. **安全契约升级**：明确提出“继续收缩换安全”已到瓶颈，给出 `Exec_v21 ⊆ C_free` 的 soundness 契约与动态见证机制，为后续版本提供活性恢复范式。

## 5. 本轮最大风险

**一句话**：闭环生存核的正确性完全押在**动力学模型与扰动界 D 的标定**上；若 D 被低估（未建模的接触、齿隙、柔性、负载突变）或迁移函子 R 在模式边界上不连续，则生存核会“形式上有见证、实际越界”，产生**动态模型失配下的伪安全**——即“证书在模型里活着，机器人在现实里撞了”。

```python
# IP-425 Closed-Loop Viability Certificate
class ClosedLoopViabilityCertificate:
    def __init__(self, dynamics, safety_set, horizon_H, D, alpha,
                 track_err_bound, dt=0.02):
        self.dyn = dynamics          # f, g, F
        self.C_free = safety_set     # 含自碰撞/环境/限位/质心
        self.H = horizon_H
        self.D = D                   # 扰动界（需标定，见 §7）
        self.alpha = alpha
        self.track_err = track_err_bound
        self.dt = dt

    def viability_kernel(self, X0):
        """最大可控不变子集的离散极大不动点（保守近似）"""
        V = set(self.C_free)                 # 初值：安全集本身
        for _ in range(self.H):
            V_next = set()
            for x in V:
                # 存在一个 u，使所有 d∈D 的后继仍在 V（保守：D 取上界）
                if self._exists_robust_successor(x, V):
                    V_next.add(x)
            if V_next == V:
                break
            V = V_next
        # 保守性：只删不加，故 V ⊆ C_free 恒成立
        return V

    def _exists_robust_successor(self, x, V):
        for u in self._sample_controls(x):
            ok = True
            for d in self._sample_disturbances(self.D):
                x_next = self.dyn.step(x, u, d, self.dt)
                if x_next not in V:
                    ok = False
                    break
            if ok:
                return True
        return False

    def synthesize_cbf_qp(self, x, u_ref, B):
        """CBF-QP：最小改动名义控制，满足前向不变约束"""
        # min ||u-u_ref||^2
        # s.t. Lf B(x) + Lg B(x)·u + alpha(B(x)) >= 0
        #      u ∈ U, 力矩/速度限
        return solve_qp(u_ref, B, x, self.dyn, self.alpha)

    def certify(self, plan):
        """为计划生成动态见证；失败返回 None（回退 v20）"""
        B = self._construct_barrier(plan)
        if B is None:
            return None
        witness = Witness(pi=self.policy, B=B, D=self.D, H=self.H)
        # 用见证做 H 步 rollout 自检（含 D 的最坏抽样）
        if not self._rollout_safe(plan, witness):
            return None
        rho_rec = self._recovery_margin(self.track_err, self.dt, self.H)
        return ViabilityCert(V=self.viability_kernel(plan.X0),
                             witness=witness, rho_rec=rho_rec)

    def _recovery_margin(self, e_max, dt, H):
        """由跟踪误差上界反推恢复余量：误差越大，静态余量越大"""
        return e_max + 0.5 * self.dyn.lipschitz * dt * H


# IP-426 Reconfigurable Stratum Sheaf
class ReconfigurableStratumSheaf:
    def __init__(self, modes, rtf, tol=1e-6):
        self.modes = modes
        self.rtf = rtf                 # IP-427
        self.kernels = {}              # m -> V_n^(m)
        self.tol = tol

    def register(self, mode, V_m):
        assert V_m.issubset(self._safe(mode)), "生存核必须 ⊆ C_free(m)"
        self.kernels[mode] = V_m

    def restriction(self, mode, boundary):
        """限制映射：把模式 m 的证书限制到边界上"""
        return self.kernels[mode].intersect(boundary)

    def gluing_check(self, m, m_prime):
        """粘合条件：守卫上两片证书经 R 后互含（保守双向检查）"""
        G = self.rtf.guard(m, m_prime)
        if G is None:
            return False, "NO_GUARD"
        left = self.rtf.map(m, m_prime, self.restriction(m, G))
        right = self.restriction(m_prime, G)
        if not left.issubset(right, self.tol):
            return False, "GLUE_L_SUBSET_FAIL"
        if not right.issubset(left, self.tol):
            return False, "GLUE_R_SUBSET_FAIL"
        return True, "OK"

    def certificate_at(self, x, mode):
        if mode not in self.kernels:
            return None, "MODE_UNREGISTERED"
        if not self.kernels[mode].contains(x):
            return None, "OUTSIDE_VIABILITY"
        return self.kernels[mode], "OK"

    def _safe(self, mode):
        return self.C_free[mode]


# IP-427 Reconfiguration Transfer Functor
class ReconfigurationTransferFunctor:
    def __init__(self, mode_graph):
        self.graph = mode_graph        # (m, m') -> transfer spec
        self.cache = {}

    def guard(self, m, m_prime):
        spec = self.graph.get((m, m_prime))
        return spec.guard if spec else None

    def map(self, m, m_prime, domain):
        """迁移函子 R_{m→m'}：维数变化时用提升/投影 + 关节嵌入"""
        spec = self.graph[(m, m_prime)]
        if spec.dim_src == spec.dim_tgt:
            return spec.matrix @ domain          # 同维：线性/仿射映射
        if spec.dim_tgt > spec.dim_src:
            # 加连杆：源参数嵌入到低维子流形，新增自由度取保守零空间
            lifted = spec.embedding @ domain
            return lifted.intersect(spec.nullspace_safe)
        # 减连杆：投影后按投影误差扩张（更保守）
        proj = spec.projection @ domain
        return proj.dilate(spec.proj_error_bound)

    def transfer_safe(self, m, m_prime):
        """R(V^m) ⊆ C_free(m') 是跨模式授权的必要条件"""
        Vm = self.kernels[m]
        return self.map(m, m_prime, Vm).issubset(self.C_free[m_prime])


# IP-428 Mode-Switch Viability Governor
class ModeSwitchViabilityGovernor:
    def __init__(self, rss, rtf, tau_switch, stow_set):
        self.rss = rss
        self.rtf = rtf
        self.tau_switch = tau_switch
        self.S_stow = stow_set
        self.transient = {}            # (m,m') -> B_trans

    def can_switch(self, x, m, m_prime):
        G = self.rtf.guard(m, m_prime)
        if G is None or x not in G:
            return False, "NOT_IN_GUARD"
        if x not in self.rss.kernels[m]:
            return False, "SOURCE_NOT_VIABLE"
        if self.rtf.map(m, m_prime, {x}) not in self.rss.C_free[m_prime]:
            return False, "TARGET_UNSAFE"
        B_trans = self.transient.get((m, m_prime))
        if B_trans is None:
            # 无瞬态证书：仅允许在通用收拢位切换
            if x not in self.S_stow:
                return False, "NO_TRANSIENT_CERT"
            return True, "STOW_ONLY"
        return B_trans(x) >= 0, "OK"

    def switch(self, x, m, m_prime):
        ok, why = self.can_switch(x, m, m_prime)
        if ok:
            # 切换期认证域收缩为 V^m ∩ S_stow
            self._shrink_certificate(m, self.S_stow)
            return m_prime, why
        return m, "SWITCH_DENIED:" + why

    def on_jam(self, x, m):
        """切换卡死：回退到当前模式的可生存子集，禁止硬停过渡态"""
        return self.rss.kernels[m].largest_safe_recovery(x)


# IP-429 Closed-Loop Certificate Monitor
class ClosedLoopCertificateMonitor:
    def __init__(self, hz=50, warn_frac=0.3, L_B=1.0, dt=0.02):
        self.warn = warn_frac
        self.L_B = L_B
        self.dt = dt

    def step(self, x, cert):
        b = cert.B(x)
        b_max = cert.B_max
        # 监控提前量：保证在下一个控制周期前触发，不会被采样延迟骗过
        if b < -self.L_B * self.dt:
            return "EMERGENCY_BRAKE"
        if b < self.warn * b_max:
            return "FALLBACK_V20"      # 最小限制回退到静态证书
        return "OK"

    def fallback(self, plan, cert):
        """最小限制回退：减速到 v20 静态域内，而非直接急停"""
        return plan.decelerate_until(lambda x: x in cert.v20_static_domain)
```

## 3. 推导

**引理 157（闭环生存可靠性）** 生存核按定义 `V_n ⊆ C_free`，且 `Exec_v21^dyn ⊆ V_n`，故 `Exec_v21^dyn ⊆ C_free`。v20 静态集 `Θ_n^col ⊆ C_free`。因此 v21 与 v20 都是对真实自由空间的可靠子集，但不必然满足 `Exec_v21 ⊆ Exec_v20`。∎

**引理 158（CBF-QP 前向不变性）** 若 `B_n` 在 `C_free` 的零超水平集上满足 `sup_u[L_f B_n + L_g B_n·u] ≥ -α(B_n)`，且 QP 可行，则 `{x : B_n(x) ≥ 0}` 在闭环 `u=π_n(x)` 下前向不变（标准 CBF 定理）。故见证控制律可把状态约束在生存核内。∎

**引理 159（近似生存核保守性）** 若 `U` 取子集近似（只采样部分控制）、`D` 取超集近似（放大扰动界）、`V̂` 用极大不动点从 `C_free` 只删不加地迭代，则 `V̂_n ⊆ V_n ⊆ C_free`。证明：每步 `V_next ⊆ V`，且保守 `∃u` 判据只会漏掉可行状态；故近似只会更小，不会产生假安全。∎

**引理 160（分层粘合安全性）** 若在守卫 `G_{m→m'}` 上 `V_n^{(m)}|_G = R^{-1}(V_n^{(m')}|_G)`（双向互含），且过渡管 `T_{m→m'}` 上 `B_trans ≥ 0`，则 `V_n^{(m)} ∪ R^{-1}(V_n^{(m')})` 在连通分层集上构成合法证书；切换轨迹不越出 C_free。∎

**引理 161（迁移函子保守性）** 若 `R_{m→m'}(V_n^{(m)}) ⊆ C_free^{(m')}`，则跨模式授权的目标状态必在目标安全集内；维数变化时“加连杆取零空间 + 减连杆投影后扩张”只会放大目标域、从而更保守（不遗漏）。∎

**引理 162（切换瞬态安全性）** 切换要么在 `S_stow`（全模式生存核交集）内进行，此时任一瞬间均落在各模式安全集；要么由 `B_trans ≥ 0` 覆盖整个过渡管。故切换过程不产生新的碰撞可能。∎

**引理 163（监控回退安全性）** 设 `B_n` 满足 Lipschitz 常数 `L_B`，采样周期 `Δt`。若在 `B_n(x_t) ≥ L_B·Δt` 时允许继续，且一旦 `B_n(x_t) < L_B·Δt` 即触发回退，则在一个采样周期内状态越出零水平集之前回退必已启动；结合回退控制律的衰减性，`x` 不会进入 `C_free` 之外。∎

**引理 164（v21 整体可靠性）** `Exec_v21 = Exec_v20 ∪ Exec_v21^dyn`，其中 `Exec_v20 ⊆ C_free`（v20 已有引理）且 `Exec_v21^dyn ⊆ V_n ⊆ C_free`（引理 157），故 `Exec_v21 ⊆ C_free`。当 `Exec_v21^dyn = ∅`（无动态见证/模型置信不足）时 `Exec_v21 = Exec_v20`。∎

## 7. 已知风险与失效模式

1. **扰动界 D 低估（首要风险）**：未建模接触、齿隙、柔性、负载突变会让真实扰动越出 D，生存核形同虚设。缓解：在线残差观测器估计 D、用 CLCM 的越界趋势反推 D 下界、D 随任务自适应放大。
2. **生存核近似不保守**：若用超集近似 `V̂ ⊇ V`，会放行实际不可恢复状态。缓解：坚持引理 159 的“只删不加”极大不动点，采样控制只取子集、扰动取超集。
3. **迁移函子不连续/维数变化无定义**：加/减连杆时 R 可能在边界跳变，导致目标状态落在 C_free 外。缓解：维变时零空间安全约束 + 投影误差扩张；R 的连续性用守卫互含检查兜底。
4. **过渡管未建模**：变形途中自碰撞、质心突变、驱动饱和可能只在过渡态出现。缓解：独立 B_trans、通用收拢位切换、过渡管离线采样认证。
5. **CBF 构造失败**：非凸安全集、高阶相对度、多约束冲突会让 QP 不可行。缓解：高相对度用指数 CBF、非凸集用多片 CBF、QP 不可行时立即最小回退。
6. **监控器延迟/抖动**：CLCM 自身若采样过慢，会漏掉快速越界。缓解：引理 163 的 Lipschitz 提前量、监控独立高频线程、硬件看门狗。
7. **活性回收破坏审计**：`Exec_v21 ⊄ Exec_v20` 意味着 v21 放行了 v20 会拒绝的计划，审计链需要额外记录动态见证。缓解：每条放行计划附 `(π,B,D,H,rollout)` 见证，独立验证器可复核。
8. **层粘合数值不一致**：浮点误差与离散化会让守卫上两片核“看似互含、实则缝隙”。缓解：显式 tol + 保守收缩 + 边界加密采样。
