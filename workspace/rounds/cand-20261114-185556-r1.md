# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「VLA」×「运动控制」）

> R69 给了闭环一张嘴：不确定就去看、去问、去触；它把 aleatoric 与 epistemic 分开，用流匹配把歧义显形，用 VoI 决定值不值得问。但 R69 的策略仍是一个**单体生成器**——语言只作为**输出**（g_ask）出现，从未作为**对身体的约束**被检查；同一个"动作"同时承担了"要做什么"和"怎么做到"两种含义。VLA 与运动控制的遭遇恰好把这个混淆撕开：
> - **VLA** 给的是开放词表的**语义**，但它在 5–10Hz 吐动作块，动力学上粗糙、不可审计，而且把"要什么"与"怎么动"糊成一个黑箱；
> - **运动控制** 给的是 1kHz 的**可行性与稳定**，但它语义盲——你让它抓错杯子，它也能又稳又快地抓起来。
>
> 核心命题：**语言与身体之间的接口是一份「契约」，不是一条流水线。** 把 VLA 从"动作生成器"改造为"约束程序生成器"（只写 *什么必须成立*，不写关节力矩），把运动控制从"执行器"升级为"可行性裁判 + 语义证人"（只写 *怎么在动力学内兑现，或拒绝兑现*）。不确定性因此三分：`U_sem`（到底指哪个约束程序）、`U_dyn`（接触/摩擦/负载的不可约噪声）、以及一个新的、诚实的 `U_grnd`（**语义可行错误**——语义错了，但身体做起来毫不费力）。三通道证据（传感器残差 R68、策略似然 R69、动力学可行性 R70）能覆盖前两者，唯独覆盖不了 `U_grnd`。命名 **DUET-RAS**（Declarative–dynamical Unified Embodied Tasking, Risk-Adaptive Supervision）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这句话约束的是哪一片可行运动；身体能不能兑现；当语义与物理冲突时，谁说了算**」——安全不是"执行得更稳"，而是"拒绝执行一个身体能做、但意思不对的任务"。

## 0. 直觉与动机

**灵感 1（VLA 应该输出约束，而不是动作）**
直觉：动作是"方法"，指令是"规格"。人对司机说"慢一点"，不是指定油门曲线，而是在施加一个约束。VLA 直接吐动作块，等于把"规格"偷偷翻译成"某一种具体方法"——于是既无法在交付前判断它动力学上能否实现，也无法换一个身体/负载复用。把它改成输出**约束程序** P（参考流形 + 硬约束 + 软目标 + 时序 + 未绑定语义槽），就得到一个可类型检查、可组合、可认证、且与具体动力学解耦的中间表示。同一句"把杯子放到架子上"，在七自由度臂与全向底盘上是**同一个 P**，由不同 MCC 去兑现。这与 TAMP/任务-运动规划的精神一致，但关键增量是：P 现在要承载 **R69 的不确定性语义**（槽、VoI、证据纪律），而不只是一个几何目标。

**灵感 2（运动控制是可行性裁判，也是语义证人）**
直觉：MCC 求解时会产生一个**活动集**——哪些约束真正在"顶"。如果指令说"轻轻放下"，但速度/力约束从不活跃、力矩却饱和，那说明语义接地错了（或被换成了"砸下去"）。约束活动签名 α、拉格朗日乘子、接触力旋量、稳定裕度，构成一段**身体对句子的证词**：物理不会撒谎，但它只对"约束是否可满足、哪条在起作用"作证。这把 R69 的"两通道"（传感器 + 策略似然）扩成"三通道"，而且这条通道是**标定与策略先验都伪造不了**的——因为它是被物理强制执行出来的。

**灵感 3（但物理只证明可行，不证明所指：一个诚实的不可能结果）**
直觉：错的指令如果做起来很容易，所有检查都会通过。两只关于夹爪对称的杯子，"拿那个杯子"的两种接地产生几乎相同的活动集、相同的力矩、相同的稳定裕度——动力学完全看不出你抓错了。这不是工程缺陷，而是**信息论上的盲区**：`S_feas = {P' : 语义错、可行、且在可达运动上 α(P')=α(P*)}` 非空。因此本轮必须显式定义 `U_grnd`，并且**拒绝**用"控制很稳"去为"语义正确"背书。能解决它的只有两样东西：更好的接地（看/问）与更保守的守护（慢/限幅/可逆试探）。这是本轮最重要的理论诚实——也是本方案最大风险的来源。

**灵感 4（频率就是语义：承诺前缀 × 临时后缀）**
直觉：VLA 10Hz，控制 1kHz，中间差两个数量级。R69 已指出"提问要花时间"，但没把时间做成**契约结构**。正确做法是：语义层只能在**承诺视界** H_c 内做不可撤销的承诺（H_c 由"还能安全刹停/满足硬约束"决定），H_c 之外全部是**带版本的临时后缀**。这样 VLA 的抖动、延迟、以及"新观察到了就改主意"都只作用于后缀，永远不会把一个已经交给身体的、无法撤回的承诺改坏。频率分离不是工程细节，它是"语义可修订、动力学不可反悔"这条安全边界的物理表达。

**灵感 5（语言歧义是槽位不是标量；不同槽位有不同的可观测性）**
直觉：R69 把歧义当成一个数 U_epi，用统一 VoI 去问。但 VLA 的歧义是**结构化的未绑定槽**：指代（哪个杯子）、空间关系（左边）、属性（热的）、方式（轻一点）、时序（先放再松）。关键区别是**可观测性**：指代靠看/问，重量靠探（试抬一下动力学立刻告诉你），而"轻一点"的阈值可能既看不见也问不清、只能靠守护。于是交互不该是"歧义大就问"，而应"按槽位的可观测类分配看/问/触/守"。这既省交互预算，也避免 R69 那种对不可观测槽的无效追问。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DUET-RAS 总览与四不变式）** DUET-RAS = (SIG, CTS, MCC, DBE, CIV, RAS-WM‡)。四不变式：
(i) **零学习写操作**继承 R68 定义 276-i；
(ii) **语义不可直达执行器**：SIG 只能写 CTS，任何时刻只有 MCC 能写力矩/关节指令；
(iii) **动力学否决权**：MCC 对不可认证的 CTS 拥有最终否决；语义层不得覆盖否决，只能**重协商**（改发 CTS）或触发交互；
(iv) **承诺分层**：只有承诺视界 H_c 内的前缀被承诺；后缀带版本、可修订，且修订不得违反已承诺前缀的硬约束。

**定义 311（任务约束语言 TCL 与约束程序）** 约束程序 P = (V, R, H, S, T, E)：
- V：参考流形/目标族（含容差 θ）；
- R：视觉接地得到的对象/区域集合；
- H：硬约束（安全、保持直立、禁入、保持接触，带裕度）；
- S：软目标与权重；
- T：时序/逻辑约束（先后、截止、until）；
- E：未绑定语义槽（指代、关系、属性、方式）及其先验与可观测类。
P 必须良构、可类型检查；**每个指令片段必须映射到至少一条约束或一个显式 `unsupported` 标记**——不允许静默丢约束（这是对抗"约束删除"攻击的结构保证）。

**定义 312（语义意图接地器 SIG）** SIG: (o_t, ℓ, memory) → (P, c_sem, slots)，由 VLA 骨干 + 结构化 TCL 头 + 类型检查器实现，**不输出关节**。语义证书 c_sem = (coverage, slot_posteriors, unsupported_spans)，coverage 指 ℓ 的每个片段 → P 中约束的映射覆盖度。

**定义 313（认证任务规格/契约 CTS）** CTS = (P, c_sem, O)，义务 O = O_sem ∪ O_dyn：
O_sem = {P 忠实于 ℓ、类型健全、槽后验校准}；
O_dyn = {存在裕度 ≥ ε_hard 的可行运动、时序可满足}。
契约**不对称**：只有 O_dyn 能否决；O_sem 只能被证据削弱并触发交互，不能单独放行或阻止执行。

**定义 314（运动控制核 MCC）** MCC 求解分层约束最优控制
`u* = argmin_u Σ_t [ Σ_s w_s ℓ_s(x_t,u_t) + ρ‖slack‖² ]  s.t. 动力学, H(slack 仅用于软约束), T`，
返回 (x*, τ*, A*, λ*, m)，A* 为活动集、λ* 为乘子、m 为可行裕度。硬约束不进入 slack 项。

**定义 315（可行性证书与不可行指纹）** m(P,x_t) = min_{h∈H} 有符号约束裕度；可行 ⇔ m ≥ ε_hard（含跟踪误差 δ）。不可行时返回**极小冲突约束集** IIS(P)——身体拒绝的"语义指纹"：到底是哪几条约束在打架。

**定义 316（约束活动签名）** α(P) = (A*, {λ_i}, {slack_i}, ‖τ‖_rms, W_contact, ξ_stab)。它是"哪一部分句子真正在约束身体"的动力学见证。

**定义 317（动力学证据 DBE）** 期望签名模型 p(α | P, x_t)，残差
`e_dyn = D(α_obs, α_exp(P)) + e_effort + e_wrench + e_stab`，
并分解为 e_manifest（超阈值、可检出）与 e_latent（落在噪声内、动力学不可辨）。接地分 g_score(P) 为观测动力学在 P 下的校准似然。

**定义 318（跨层不一致裁决 CIV）** 输入 (P, c_sem, α, e_dyn)：
- e_manifest > τ_dyn ⇒ 接地可疑，升级为 U_sem，触发看/问（复用 R69 MINT）；
- MCC 不可行 ⇒ 以最小语义损失重协商 P'；若 semantic_loss(P,P') > τ_reneg ⇒ 问人；
- e_dyn 低但 U_sem 仍高 ⇒ **语义可行歧义**：动力学不能作证，只能问或守护。
裁决原则：**语义定 what，动力学定 whether/how，二者都不能单独裁定 unobservable intent。**

**定义 319（三分不确定性）**
`U_sem = H(slot 后验 | ℓ, o)`（可由看/问/触消解）；
`U_dyn = E[tr Σ_contact] + 模型误差`（aleatoric，只能放缓/探——沿用 R68/R69 的 λ floor）；
`U_grnd = P(语义可行错误)`（三通道**都看不见**的部分，只能由语义先验 + 交互覆盖 + 守护来界定）。
三者分通道处置，不做简单加和。

**定义 320（承诺视界与临时后缀）** H_c(x_t) = 满足"任意已承诺前缀可达状态下仍存在安全停靠/回退"的最长前缀长度（viability）。P[0:H_c] 被承诺，P[H_c:H] 为带版本的临时后缀；任何后缀修订不得改变已承诺前缀的硬约束满足性。

**定义 321（槽位条件 VoI 与可观测类）** 对每个槽 s ∈ E，`VoI_s(g) = H(s|o) − E_y[H(s|o,y)]`，并按可观测类分配动作：
`gaze`（视觉可辨：指代/关系/属性）、`ask`（语言可辨：意图/命名/偏好）、`probe`（动力学可辨：重量/卡滞/柔顺/接触）、`guard`（不可观测：只能限速/限力/可逆试探）。选择 `argmax_g [VoI_s(g) − c(g)]` over 可观测类，且必须通过 R69 的证据纪律与信息动作认证。

**定义 322（动力学否决与重协商纪律）** MCC 否决在单周期内最终；重协商必须**单调降低语义损失**或升级为交互；硬约束永不静默放松，任何放松进入 renegotiation_log 并入证书。语言不能"用词买安全"。

**定义 323（三通道证据与"覆盖式"融合）** 证据通道 E1 = r_res（R68 传感器/标定）、E2 = Δa（R69 策略似然）、E3 = e_dyn（R70 动力学）。定义通道-故障**盲区矩阵** B[ch][f] ∈ [0,1]。融合规则：
- 只能用**覆盖该故障类**（B[ch][f] < 1）的通道去"洗清"；
- 任一覆盖通道报警即升级；
- 无覆盖通道 ⇒ 标记 `blind(f)`，进入 U_grnd，**不得 acquit**。
这是对 R69「两源一致」的修正：并非任意两个源都算正交，只有覆盖该故障类的源才作证。

**定义 324（证书 J_DUET）** J_DUET = (J_FLUID, hash(P), c_sem.coverage, m, hash(α), e_dyn_p95, H_c, renegotiation_log, slot_posteriors, dual_ver)。Valid ⇔ Valid(J_FLUID) ∧ type_sound(P) ∧ m ≥ ε_hard ∧ 无未记录的硬约束放松 ∧ 承诺前缀已认证。

**定义 325（威胁模型 ℰ_DUET 与语义可行错误集）** ℰ_DUET = ℰ_FLUID × ℰ_sem。ℰ_sem 含：语义错但可行（wrong-but-feasible）、释义漂移、对称/可逆指代、约束注入/删除（尤其 SIG 静默丢约束）、以及"服从式灾难合规"（obedient catastrophic compliance）。定义
`S_feas(P*) = {P' : P' 语义错 ∧ P' 可行 ∧ 在可达运动上 α(P') = α(P*)}`。
S_feas 对 E3 可证明不可观测，对 E1/E2 通常也不可辨。

**定义 326（语义守护）** 对不可观测槽 s（s 的任一取值都落在 S_feas 内、且看/问成本超预算），不得假装消解；改为降低该槽影响面的**暴露**：限速 v_guard(s)、限力 f_guard(s)、或插入可逆/可回退动作（先轻抬再判断）。守护是"承认不知道"的可执行形式。

```python
# IP-264 SIG：VLA 只产出约束程序，不产出关节指令
class SemanticIntentGrounder:
    def __init__(self, vla_backbone, tcl_decoder, type_checker):
        self.vla, self.dec, self.tc = vla_backbone, tcl_decoder, type_checker

    def ground(self, obs, instruction, memory):
        h = self.vla(obs, instruction, memory)
        P, slots = self.dec(h)                     # P=(V,R,H,S,T,E)
        assert self.tc.well_typed(P)               # 类型健全，否则拒绝
        cov = coverage(instruction, P)             # 每片段 -> 约束
        unsupported = find_unsupported(instruction, P)   # 显式，绝不静默丢
        return P, SemCert(cov, slots, unsupported), slots

# IP-265/273 CTS 契约 + 动力学否决 + 重协商
def contract_and_solve(P, x_t, c_sem, mcc):
    if not c_sem.ok():                      # O_sem 不过 -> 交互，不执行
        return VETO('grounding'), None
    for _ in range(MAX_RENEG):
        sol = mcc.solve(P, x_t)             # 分层约束 OCP
        if sol.feasible and sol.margin >= EPS_HARD:
            return sol, Cert(sol, P)        # O_dyn 通过 -> 可承诺
        IIS = sol.minimal_conflict_set()    # 哪几条约束打架（语义指纹）
        P2, loss = renegotiate(P, IIS)      # 最小语义损失地改 P
        if loss > TAU_RENEG:                # 语义代价太大 -> 问人
            return ASK(IIS), None
        log_renegotiation(P, P2, IIS)       # 硬约束不许静默放松
        P = P2
    return VETO('infeasible'), None         # 否决最终

# IP-267/268/269 FCM + CAS + DBE：物理作证
def dynamics_evidence(sol, P, expected):
    alpha = (sol.active_set, sol.multipliers, sol.slack,
             rms(sol.tau), sol.contact_wrench, sol.stability_margin)
    e = expected.residual(alpha, P)         # D(alpha_obs, alpha_exp(P)) + ...
    e_manifest = float(e > TAU_DYN)
    return e, e_manifest, alpha

# IP-271 TCH：承诺前缀 / 临时后缀
def commit_prefix(P, x_t, H):
    hc = viability_horizon(x_t, P.hard)     # 仍可安全停靠的最长前缀
    return P[:hc], VersionedSuffix(P[hc:H], v=next_version())

# IP-272 SVR：按槽位可观测类分配 看/问/触/守
def resolve_slots(slots, P, obs, budget):
    for s in slots:
        cls = observability_class(s)        # gaze / ask / probe / guard
        if cls == 'guard':                  # 不可观测 -> 只能守
            P = apply_guard(P, s); continue
        g = best_info_action(s, cls, P)     # 复用 R69 MINT
        if budget.allow(g) and c_ras_wm.certify_info(g, obs) \
           and voi(s, g) - cost(g) > 0:
            ans = execute_info(g)           # 走 R69 CIA + 证据纪律
            update_slot(s, ans)
    return P

# IP-274 TEF：覆盖式三通道证据（替换 R69 的“任意两源一致”）
def fuse(e1, e2, e3, faults, B):
    out = {}
    for f in faults:
        covering = [ch for ch, e in zip(('E1','E2','E3'), (e1,e2,e3))
                    if B[ch][f] < 1.0]       # 只有覆盖该故障类的通道能作证
        if not covering:
            out[f] = 'blind'                 # -> U_grnd，不得 acquit
        elif any(flag(ch, f) for ch in covering):
            out[f] = 'escalate'
        elif all(explain(ch, f) for ch in covering):
            out[f] = 'acquit'                # 仅当所有覆盖通道都解释得了
    return out

# IP-275 主闭环：两个时钟（慢语义 / 快控制）
def semantic_tick(M, obs, instruction):     # 5–10 Hz
    P, c_sem, slots = M.sig.ground(obs, instruction, M.memory)
    P = M.svr.resolve_slots(slots, P, obs, M.budget)   # 看/问/触/守
    pref, suffix = M.tch.commit_prefix(P, M.x, M.vista.H)
    return pref, suffix, c_sem

def control_tick(M, pref):                  # 500 Hz – 1 kHz
    sol, cert = contract_and_solve(pref, M.x, M.last_c_sem, M.mcc)
    if sol is None:                         # 否决 / 需交互
        return M.dvg.safe_hold_and_request(sol_reason=cert)
    e3, manifest, alpha = dynamics_evidence(sol, pref, M.exp)
    M.civ.observe(alpha, e3, manifest)      # 上报，不擅自改语义
    tau = M.mcc.apply(sol) * M.lam_floor(pref)   # 硬件/动力学层保守缩放
    return tau
```

## 3. 推导

**假设域 A99–A102。**
A99：TCL 良构且**无静默丢弃**（每个指令片段映射到约束或显式 unsupported）。
A100：MCC 可靠——若返回可行且 m ≥ ε_hard，则被执行轨迹满足硬约束，跟踪误差 ≤ δ。
A101：α 对"绑定约束的身份"局部单射且 Lipschitz；不同绑定集在噪声下不会被压成同一签名。
A102：语义先验与槽后验已校准（复用 R69 MCG）；交互覆盖满足 MINT 预算约束。

**引理 19（契约健全性）** 在 A99–A100 下，若 CTS 可容许（O_sem 通过且 MCC 返回 m ≥ ε_hard），则被执行运动满足 H(P) 且裕度 ≥ ε_hard − δ。要点：硬约束不进 slack、MCC 的可行解在跟踪误差内仍是可行集的内点；语义层无权旁路，故任何硬约束违反都必须先经过一次被记录的重协商或否决。

**引理 20（接地错误的可观测性）** 设 P、P' 两个接地。若它们在可达运动上的**绑定约束集合不同**（活动集/乘子支撑不同），则在 A101 下 DBE 可分离：`e_dyn(P') − e_dyn(P) ≥ c·dist(α(P),α(P')) − η`。逆否：**若对所有可达运动 α(P') = α(P*)，则任何纯动力学证据都不可能区分二者**。即：物理为"哪条约束在起作用"作证，不为"这条约束是否就是本意"作证。

**引理 21（语义可行盲区非空）** 存在指令与世界状态，使得两个接地 P*（正确）与 P'（语义错）都可行，且在可达运动上活动集、乘子、力矩、接触与稳定裕度完全一致（例：关于夹爪对称的两个杯子；或"把杯子放到桌上"中桌面上任意一点都等价）。因此对任何只用 (E1,E2,E3) 且阈值为正的检测器，都存在它无法检出的错误接地。故语义错误**不被任何动力学通道的带宽或精度所界定**，只能由语义先验与交互覆盖界定。系：必须把 `U_grnd = P(S_feas)` 作为一个独立的、不可被"控制更稳"削减的残余项写入安全声明——安全主张必须条件化在 S_feas 上。

**引理 22（重协商下的前缀安全）** 若承诺前缀长度 h ≤ H_c(x_t)，则任何只修改后缀 P'（保持已承诺前缀固定）的重协商都不改变前缀的硬约束满足性；且回退控制器把状态保持在 viability 核内时，闭环对所有后缀修订安全。系：VLA 的慢抖动/延迟只可能影响"未来做什么"，不可能破坏"已经承诺的运动学/动力学不变量"。

**定理 18（DUET 严格包含 FLUID-RAS）** 令 TCL 退化为单个"无约束参考等式"（P = {x_{t:t+H} = ξ_FMP}），SIG 取恒等映射，MCC 取直通，则 DUET 逐指令退化为 R69 的 FLUID；再关闭交互则退化为 R68。当 CIV 检出 manifest 不一致、或 MCC 否决、或语义证书不通过时，DUET 的 λ 不降地退回 FLUID/R68。因此同动作集下期望风险 ≤ FLUID，等式在"无约束边界"成立。**新层是旧层的严格泛化，而不是并列替代。**

**定理 19（三通道分离与盲区刻画）** 在 A99–A102 下，对任意故障 f：
- 若 f 至少被一条**覆盖**通道 manifest，则 DUET 以概率 ≥ 1−δ_ch 检出或升级；
- 若 f ∈ S_feas（语义可行），则不存在覆盖通道，检出率 ≤ 语义先验下的 P(f)，**即使继续增加动力学传感器、提高控制频率也无法改善**。
故安全论证干净地分解为：(a) 由物理与标定认证的 manifest 部分；(b) 只能由接地质量与交互覆盖界定的语义部分。系：**你不能用控制带宽买语义安全**——只能用好接地或好提问去买。这一条同时给出了 R70 的安全边界与最大风险。

## 6. 本轮最大风险

**一句话**：DUET-RAS 把安全性押在"动力学是语言的诚实证人"上，但物理只能证明**可行**、不能证明**所指**——一个语义错误但动力学上轻松可行的指令，会同时通过传感器、策略似然、可行性与稳定性全部检查，于是系统以最高置信、最快速度执行错误的任务；**最危险的错误，是身体觉得最容易的那种错误**。

**次级风险与缓解**：
1. **软/硬约束被静默放松**（尤其在"求快"的对抗指令下）→ 硬约束永不进 slack、放松必入 renegotiation_log、J_DUET 校验，定义 322/324。
2. **活动签名不可辨识**（不同接地压成同一 α）→ 引理 20 的逆否被显式化为 S_feas，禁止用 E3 为其 acquit，定义 325。
3. **VLA 慢环延迟/抖动**击穿实时性 → 承诺前缀 H_c + 临时后缀，慢环永远不直接写执行器，定义 310-iv/320、引理 22。
4. **不可观测槽被假装消解**（对称指代、遮挡、可逆目标）→ 定义 326 的 guard/可逆试探，禁止假确定性。
5. **TCL 表达力不足被当作"无约束"** → 类型检查强制显式 `unsupported`，E301 要求静默丢约束 = 0。

```python
    if sol is None: return M.dvg.safe_hold_and_request(cert)
    e3, manifest, alpha = dynamics_evidence(sol, pref, M.exp)
    M.civ.observe(alpha, e3, manifest)              # 上报，不擅自改语义
    return M.mcc.apply(sol) * M.lam_floor(pref)
```

## 4. 推导

**假设域 A99–A102**：TCL 良构且无静默丢弃；MCC 可靠（可行 ⇒ 硬约束满足，跟踪误差 ≤ δ）；α 对绑定约束身份局部单射且 Lipschitz；语义先验/槽后验已校准（R69 MCG）。

**引理 19（契约健全性）** CTS 可容许（O_sem 通过且 m ≥ ε_hard）⇒ 被执行运动满足 H(P) 且裕度 ≥ ε_hard − δ。语义层无权旁路，硬约束违反必须先经一次被记录的否决/重协商。

**引理 20（接地错误的可观测性）** 若 P、P' 的绑定约束集合不同，则 `e_dyn(P') − e_dyn(P) ≥ c·dist(α(P),α(P')) − η`。逆否：若所有可达运动上 `α(P')=α(P*)`，任何纯动力学证据都无法区分二者——物理为"哪条约束在起作用"作证，不为"这条约束是否是本意"作证。

**引理 21（语义可行盲区非空）** 存在语义错但可行、且 α 完全一致的接地对（对称杯子、等价落点）。因此任何仅用 (E1,E2,E3) 的正阈值检测器都有盲区；语义错误不被动力学带宽/精度界定。系：必须把 `U_grnd=P(S_feas)` 作为独立残余写入安全声明，安全主张须条件化在 S_feas 上。

**引理 22（重协商下的前缀安全）** 承诺前缀长度 h ≤ H_c 时，仅修改后缀的重协商不改变前缀硬约束满足性；回退控制器保持在 viability 核内则闭环对所有后缀修订安全。系：慢环抖动只影响"未来做什么"，不破坏"已承诺的不变量"。

**定理 18（DUET 严格包含 FLUID-RAS）** TCL 退化为单个无约束参考等式、SIG 取恒等、MCC 直通 ⇒ DUET 逐指令退化为 R69；再关交互 ⇒ R68。检出 manifest / 否决 / 证书不通过时 λ 不降地退回。故同动作集下期望风险 ≤ FLUID，等式在"无约束边界"成立；新层是旧层的严格泛化。

**定理 19（三通道分离与盲区刻画）** 覆盖通道 manifest 的故障以概率 ≥ 1−δ_ch 被检出/升级；`f ∈ S_feas` 时无覆盖通道，检出率 ≤ 语义先验 P(f)，**增加传感器或提高控制频率都无法改善**。安全论证分解为：(a) 物理/标定认证的 manifest 部分；(b) 只能由接地质量与交互覆盖界定的语义部分。系：**你不能用控制带宽买语义安全**，只能用好接地或好提问去买。

## 7. 本轮最大风险

**一句话**：DUET-RAS 把安全性押在"动力学是语言的诚实证人"上，但物理只能证明**可行**、不能证明**所指**——一个语义错误但动力学上轻松可行的指令，会同时通过传感器、策略似然、可行性与稳定性全部检查，于是系统以最高置信、最快速度执行错误的任务；**最危险的错误，是身体觉得最容易的那种错误**。

**次级风险与缓解**：软/硬约束被静默放松（硬约束不进 slack、放松入 renegotiation_log、J_DUET 校验，定义 322/324）；活动签名不可辨识（引理 20 逆否显式化为 S_feas，禁止 E3 acquit，定义 325）；VLA 慢环延迟/抖动（承诺前缀 + 临时后缀，慢环不写执行器，定义 310-iv/320）；不可观测槽被假装消解（guard/可逆试探，定义 326）；TCL 表达力不足被当作"无约束"（强制显式 unsupported，E301 静默丢约束 = 0）。
