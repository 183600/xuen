# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「多机评测」×「数据采集」）

> R69 把不确定性一分为二，并用「主动交互」消解 epistemic：看不清就看，拿不准就问，问完再用 k 个「正交证据源」定案。这个闭环很优雅，但它有两个没有说出口的前提：**(1) 用来校准模态权重的数据已经存在且可信；(2) 那 k 个证据源真的正交。** 真实系统里，一个机器人的眼睛、耳朵、本体感觉和策略权重共享同一个训练分布、同一个场景、同一次标定——它们不是 k 个证人，而是同一个证人的 k 种口音。于是 R69 自陈的最大风险（模态分布不可信 → 追问幻影、或给一句投毒回答盖上「已验证」的章）在根上不是 ECE 问题，而是**证据独立性无法自证**：用同一个模型的多个通道，去证明同一个模型的输出。
>
> 本轮两个灵感正好各补一块外部参考：
> - **多机评测**不是排行榜，而是一台**相关性测量仪**。多台机器人对同一场景的误差联合分布，给出单机永远看不到的量：哪些错误是个体的（idiosyncratic，可被交叉验证），哪些是共因的（common-mode，舰队会一起错）。它把 R69 的「k 个正交源」从一个**假设**变成一个可测、可购买、可审计的量 `n_eff`。
> - **数据采集**不是被动记录，而是**主动实验设计**。R69 的 VoI 是毫秒级、单机、消解当前歧义；R70 的 VoI 是小时/天级、舰队、消解「部署证书」的不确定性。它可以在不违反「实时零学习写操作」的前提下，为下一次部署买到更窄的证书。
>
> 核心命题：**先用多机误差相关结构估计「有效独立性」，再用定向数据采集把部署证书的不确定性降到阈值以下；评测数据只走离线闸门，实时策略冻结；没有外部锚就不发证书。** 命名 **FLEET-RAS**（Fleet-Level Epistemic Evaluation & Targeted data collection for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信这些答案不是同一群模型一起编的？我该花多少数据，把这个『凭什么』买下来？**」——评测不是成绩单，而是下一次部署的**证据采购单**。

## 0. 直觉与动机

**灵感 1（多机评测 → 被评测的是误差的联合分布，不是成功率的边缘分布）**
直觉：一张排行榜把每台机器人压成一个平均成功率，然后按大小排序。但安全是**尾事件**，而且往往是**共同事件**：真正危险的时刻，不是「A 模型平均比 B 模型低 2 个点」，而是「整个舰队在同一个场景族上一起失败」。平均值看不见这种结构，因为它把「所有机器人在同一处失败」和「每台机器人各自在不同处失败」平均成了同一个数。多机评测的第一性对象因此不是 `{mean_r}`，而是 `{p_{r,f}}` 的联合分布：族与族之间的风险集中度、机器人与机器人之间的误差相关、以及共失效事件 `C_f(q)`。**先声明你要评的泛函（均值 / 尾 / 共失效），再谈数据怎么采。** 这不是修辞：真实榜单上，按均值排和按尾部 CVaR 排已经会让 DM0、PI-0.5、GigaBrain-0 三者的名次互换（见产物区 §6-A）。

**灵感 2（多机 ≠ 独立 → 相关性的第一条定理是「共因底」）**
直觉：R69 的证据纪律说「k 个正交源多数一致才定案」，引理 18 给出错误率 `δ_p·ρ^{k−1}+ε_σ`。这条式子隐含 `ρ<1` 且**可以靠增大 k 把错误率压到零**。但只要存在一个共同原因 `C`（同一训练谱系、同一本体、同一次标定、同一个场景先验），使所有源同时错，那么任何 k 源多数投票的错误率都被 `P(C)=δ_c` 从下面顶住——**加机器不能消掉共因**。正确做法不是数机器，而是先**测量**有效独立性：等相相关 ρ 下 `n_eff = k/(1+(k−1)ρ)`；ρ=0.3、k=12 时只剩 2.79 个有效源。多机评测的第一个产物因此不是排名，而是 `(ρ_ij, δ_c, n_eff)` 这三个校准量。**「多机」不是「独立」的同义词；先测相关，再谈投票。**

**灵感 3（数据采集 → 慢时间尺度上的 VoI，买的是证书而不是动作）**
直觉：R69 花一次注视/一句提问去消解一个动作级的歧义；但「我的模态权重到底准不准」这种问题，问一次是问不出来的，它需要**一批**针对性的评测数据。于是出现了第二个 VoI：不是「选哪个信息动作」，而是「选哪些场景族、哪些机器人对、哪些锚标签去采集，才能使部署证书的不确定性下降最多」。这把数据采集从「日志」升级为「实验设计」：`argmax_B [VoI(B) − c(B)]`，约束是覆盖、锚覆盖、独立性与预算。关键是**时间尺度隔离**：采集数据永远不写进实时策略，只更新离线证书和下一版部署；R69 的实时闭环因此完全不被污染。

**灵感 4（异构性是唯一能买到的「独立性」）**
直觉：同一个模型复制 12 份，得到的是 12 个高度相关的证人，不是 12 票。真正能降低共因底的是**异构性**：不同视角、不同本体、不同传感器、不同训练谱系、不同标定历史。多机评测因此还是一项**资源分配**问题：在采集预算下，应该买「第 13 台同款」还是「第 1 台异构」？答案由去相关增益决定：`Δn_eff / cost`。这把「多机规模」从堆数量变成买多样性——**不是更多的眼睛，而是不同的眼睛。**

**灵感 5（评测即攻击面 → 观察者效应、投毒、共谋，以及外部锚的不可省）**
直觉：一旦评测结果能解锁效率、能决定部署，它就有了被攻击的价值。三种新威胁是 R69 没有的：(a) **数据投毒**——拜占庭机器人往共享校准集里灌偏置；(b) **评测感知 / Goodhart**——机器人在「被评测」时表现不同，于是测到的是演员，不是策略；(c) **共因欺骗**——所有机器人共享同一个错误，评测越一致越自信。前两者可以用来源证书、鲁棒聚合、盲评/随机探针处理；第三者**无法从舰队内部发现**，必须引入**外部锚**：人类专家、物理不变量、受控反事实、跨本体、独立传感器。于是本轮加一条硬不变式：**没有外部锚，就不发证书。** 否则「多机评测」只是把 R69 的单机循环论证，扩大成舰队规模的循环论证。

**R69 的隐含前提 → R70 的替换**

| R69 的隐含前提 | 现实 | R70 的替换 |
|---|---|---|
| k 个证据源正交 | 同模型/同谱系/同场景 ⇒ 高相关 | 测 `ρ_ij`，用 `n_eff` 替代 k；共因底 `δ_c` 显式建模 |
| 校准数据已存在且可信 | 数据本身可被投毒、可被评测感知污染 | 来源证书 DPC + 鲁棒聚合 BRA + 盲评 EGD |
| 幻影模态可被单机内部识别 | 单机的多个通道共享同一错误 | 舰队交叉核验 PX（只删个体幻影）+ 外部锚 AEG（删共因幻影） |
| epistemic 消解是实时动作级 | 校准/证书是慢变量 | 双时间尺度：R69 实时消歧；R70 离线宏观 VoI 采集 |
| 评测是为了排名 | 评测是为了决定能否部署 | 风险泛函（尾/共失效）+ 安全部署棘轮 SDR |

## 1. 形式化定义（增量：定义 310–327）

**定义 310（FLEET-RAS 总览与五不变式）** FLEET-RAS = (FEG, FDD, PX, AEG, MEV, TSC, DPC, BRA, EGD, SDR, J_FLEET)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i；采集/评测永远不写实时权重）；
(ii) **两时间尺度隔离**：评测数据只能更新离线证书与下一部署版本；版本钉扎、可回滚；
(iii) **无外部锚不证书**：`J_FLEET` 需要锚覆盖率 `≥ a_min`，且至少一个锚类与舰队的估计相关 `< ρ_max`；
(iv) **风险单调棘轮**：新部署仅在尾部/共失效风险不劣于当前且证书有效时被接受，否则保持旧版本；
(v) **采集预算、覆盖、来源硬约束**：覆盖率不是可选项，未覆盖族上的证书视为无效。

**定义 311（舰队证据图 FEG）** `G=(V,E,W)`：`V` 为机器人/评测单元；边权 `ρ_ij ∈ [0,1]` 为在共享探针集上的误差相关（模态选择或校准标量的残差相关）。节点带训练谱系哈希 `L_i`、本体/视角/传感距离 `d_ij^emb`、标定版本 `c_i`。定义
`n_eff(k) = k / (1 + (k−1) ρ̄)`，`δ_c = P(共同原因使所有源同时错)`。
ρ 的估计必须 **cross-fitting**：在探针族 A 上估 ρ，在互斥族 B 上验证，避免「用同一批数据既估独立性又发证书」。FEG 的产物不是排名，而是 `(ρ_ij, δ_c, n_eff)`。

**定义 312（舰队分歧分解 FDD）** 对场景族 `f`，各机器人输出模态分布。把总分歧 `D_fleet` 分成三块：
- `U_ale`：模态内、单机不可约噪声（继承 R69 定义 297）；
- `U_shared`：由共享潜因子（同谱系/同本体/同标定/同场景先验）解释的机间分歧；
- `U_idio`：不能被共享因子解释的残差。
形式：把机器人 `r` 在探针集上的偏置写成 `b_r = A z_{L(r)} + B c_{emb(r)} + ε_r`，则
`U_shared = E‖A(z_r−z_s)+B(c_r−c_s)‖²`，`U_idio = E‖ε_r−ε_s‖²`。
**只有 `U_idio` 能作为「外部第二意见」；`U_shared` 是舰队盲区。** R69 的 `U_epi` 因此进一步分成 `U_epi^idio` 与 `U_epi^shared`：前者可被 PX 交叉验证，后者只能靠 AEG 或定向采集。二者不做简单加和，分别路由。

**定义 313（幻影模态交叉核验 PX）** 模态 `m` 被「舰队证实」当且仅当存在至少两个机器人 `r,s`，满足 `ρ_rs ≤ ρ_orth`、且二者对 `m` 的后验权重均 `≥ w_min`；或用 `n_eff` 加权支持 `Σ_r 1[ρ_{r,0}≤ρ_orth]·ŵ_{r,m} ≥ τ_supp`。否则标为 **phantom-suspect**，降权且**不得触发交互**（继承 R69 的「认证先于交互」）。PX 是「外部交叉门」；R69 的 MCG 仍是「内部校准门」，两门都过才允许 MINT。**PX 只能删个体幻影；共享幻影检测不到，交给 AEG。**

**定义 314（外部锚证据门 AEG）** 锚类 `𝒜 = {human_expert, physics_invariant, controlled_counterfactual, cross_embodiment, independent_sensor}`。每个锚 `a` 有与舰队的误差相关 `ρ_a`、对场景族的覆盖率 `cov_a(f)`、与舰队共识的冲突分 `κ_a`。`J_FLEET` 要求：
(a) 至少存在一个锚类满足 `ρ_a ≤ ρ_max`；
(b) 每个高风险族 `f` 的锚覆盖率 `≥ a_min`；
(c) 不存在未解释的锚-舰队冲突：`κ_a ≤ τ_κ`，否则必须归因（是锚错、舰队错，还是场景本身不可辨识）。
任一不满足，证书降级为「仅内部一致性」，**不得用于解锁效率**。

**定义 315（评测单元与共失效事件）** 评测单元 `e=(r,f,ξ,δ)`，`r∈V` 为机器人，`f` 为场景族，`ξ` 为随机种子，`δ` 为受控扰动。共失效事件 `C_f(q) = {在族 f 中至少 q 台机器人失败}`。舰队评测的目标不是 `E_{r,f}[fail]`，而是估计 `{p_f}` 与共失效尾 `P(C_f(q))`。

**定义 316（舰队风险泛函）** 令 `p_f = P(失败 | f)`，`w_f` 为族权重。定义
`R_mean = Σ_f w_f p_f`；`R_tail = CVaR_β({p_f})`（或 `max_f p_f`）；`R_co = CVaR_β({P(C_f(q))})`。
**评测前必须先声明泛函**；FLEET 默认用 `R_tail + R_co`，因为安全是尾事件，均值会掩盖「全舰队在同一族上一起失败」。**均值序与尾序不可交换**：存在系统 A、B 使 `R_mean(A) < R_mean(B)` 而 `R_tail(A) > R_tail(B)`（真实榜单已出现名次互换，见 §6-A）。

**定义 317（宏观评测 VoI，MEV）** 设 `θ` 为证书参数（`R_tail, R_co, ECE, δ_c, n_eff`），后验 `p(θ|D)`。定义证书风险
`R_cert(D) = P_{θ~p(θ|D)}[ G(θ) ≠ G(θ_true) ]`（或 gate 决策熵）。
对采集批次 `B`：`VoI(B) = R_cert(D) − E_{D_B~p(·|B)}[ R_cert(D∪B) ]`。
选择 `B* = argmax_B [VoI(B) − c(B)]`，s.t. 每族覆盖 `≥ n_min`、锚覆盖 `≥ a_min`、谱系覆盖 `≥ l_min`、总预算 `≤ B_max`。单 episode 的 greedy 在 A99（边际递减）下 `≥ (1−1/e)OPT`。
**与 R69 的关系**：R69 的 VoI 是「选一个信息动作来消解当前歧义」；MEV 是「选一批评测来消解证书的不确定性」。二者是同一泛函在不同时间尺度、不同决策变量上的实例。R70 不替代 R69，而是为它提供可审计的校准来源。

**定义 318（尾/分层采集 TSC）** 采集分布 `q(f) ∝ w_f · g(p̂_f, target)`：
- `target=R_mean` ⇒ `g = √(p̂_f(1−p̂_f))`（Neyman，最小化均值估计方差）；
- `target=R_tail` ⇒ `g` 集中在上尾候选（`p̂_f` 接近或超过阈值）；
- `target=R_co` ⇒ `g` 按族对共失效的边际贡献排序。
必须带**覆盖下限** `n_min` 与**重要性重加权**，否则尾采样会给均值估计引入偏差。**采集策略必须与风险泛函匹配；不存在与泛函无关的最优采集策略**（引理 21）。

**定义 319（数据来源证书 DPC）** 每条数据 `d` 的来源元组
`π_d = (robot_id, model_hash, lineage_hash, calib_version, sensor_id, scenario_family, seed, perturbation, timestamp, auditor_sig)`。
批次 `B` 的 Merkle 根 `H(B)`。**LORO 影响**：`Δ_r(B) = |G(D) − G(D \ B_r)|`；若 `Δ_r > τ_infl`，隔离该机器人的数据并要求二次审计。**谱系覆盖率** `cov_lineage(B)` 用于检测「全舰队同源」——同源数据再多，也不增加独立性。

**定义 320（拜占庭鲁棒聚合 BRA）** 对来自 `n` 台机器的校准统计量，使用 coordinate-wise trimmed mean / median，破坏点 `α`。若恶意比例 `f/n ≥ α`，拒绝发证书。相关加权：`∝ 1/(1+(k−1)ρ̄)`。**注意**：鲁棒聚合只能防「少数异常」，不能防「多数共谋」；后者必须靠锚与谱系多样性。**独立来源数与恶意比例必须同时满足，否则「多机」是投毒放大器。**

**定义 321（评测感知 / Goodhart 检测 EGD）** 令 `π_announced` 与 `π_unannounced` 为机器人在「被告知在评测」与「未告知」下同一场景的行为分布。评测感知 gap
`γ_game = TV(π_announced, π_unannounced)`。
用随机盲评、未预告探针、以及「评测/部署分布差异」估计。若 `γ_game > τ_game`，该批次数据 quarantine，不得进入证书。**评测本身会改变被评测者**，所以评测必须持续、随机、部分隐藏。

**定义 322（安全部署棘轮 SDR）** 当前部署版本 `v`，候选 `v'`（新校准/新阈值/新策略）。接受 `v'` 当且仅当：
(a) `J_FLEET(v')` Valid；
(b) 在独立 held-out 评测上 `UCB_η(R_tail(v')) ≤ LCB_η(R_tail(v))` 且 `UCB_η(R_co(v')) ≤ LCB_η(R_co(v))`；
(c) 若只是效率更新（非安全），还需 `R_tail/R_co` 不劣化且 `n_eff`、锚覆盖满足阈值。
否则保持 `v`，并保留随时回滚。**这把「学习」关进一个只能收紧、不能偷偷放宽安全侧的棘轮。**

**定义 323（舰队证书 J_FLEET）**
`J_FLEET = (J_FLUID, n_eff, δ_c, anchor_coverage, R_tail_CI, R_co_CI, provenance_root, loro_max_influence, gaming_gap, lineage_coverage, data_budget, fleet_ver)`。
Valid ⇔ `Valid(J_FLUID)` ∧ `n_eff ≥ n_min` ∧ `δ_c ≤ δ_max` ∧ `anchor_coverage ≥ a_min` ∧ `gaming_gap ≤ τ_game` ∧ `loro_max_influence ≤ τ_infl` ∧ 证书置信 `≥ 1−η`。

**定义 324（参与式审计 VQAuditor-F）** 审计对象新增评测/采集决策：采集是否只挑「好看」的族、长尾是否被覆盖、锚是否真正独立、是否有机器人被系统性排除、LORO 是否被绕过、证书是否被评测感知污染。结论回灌 AuditBuf，成为下一轮 MEV 的成本与覆盖先验。

**定义 325（AIC-FLEET）** `ℰ_FLEET = ℰ_FLUID × ℰ_poison^fleet × ℰ_eval × ℰ_corr × ℰ_replay`。四类新攻击：数据投毒（Byzantine 机器人）、评测感知/Goodhart、共因欺骗（全舰队同错）、回放/旧数据冒充新数据。

**定义 326（采集预算与约束）** `B = (N_episodes, C_label, C_anchor, C_move)`。硬约束：每族覆盖 `≥ n_min`；锚覆盖 `≥ a_min`；谱系覆盖 `≥ l_min`；总成本 `≤ B_max`。采集策略在约束下最大化 VoI。**覆盖不是可选项**：没有覆盖的尾采样会让证书在未采样族上给出虚假置信；没有谱系覆盖的「多机」只是在同一口音上叠音量。

**定义 327（严格包含与退化映射）** 当 `|V|=1`、采集预算 `=0`、或无可用锚时，FLEET 的实时决策逐指令等于 FLUID（R69）；当 FLUID 再退化为「永不交互」时等于 R68。评测/采集只能通过 SDR 改变**下一版本**，且只在证书有效时；因此任意时刻的部署安全侧都不弱于当前版本。**R70 不是替代 R69，而是给 R69 的可信度提供外部计量。**

def estimate_fleet_graph(probe_A, probe_B, robots):
    # probe_A 估相关，probe_B 只用于验证，避免自证
    rho = pairwise_error_corr(probe_A, robots)

                  if graph.rho[source, r] <= RHO_ORTH and w >= W_MIN)

    if not (ucb(J.R_tail) <= lcb(current.R_tail) and
            ucb(J.R_co)   <= lcb(current.R_co)): return current
    return candidate

## 3. 推导

**引理 19（共因底与有效独立性）** 设每个源的错误 `E_i = C ∨ B_i`，`P(C)=δ_c`，`B_i` 相互独立，`P(B_i)=δ_i`。则任意多数投票的错误率 `≥ δ_c`；在等相相关 `ρ` 下，有效独立源数 `n_eff = k/(1+(k−1)ρ)`。**证明要点**：`C` 发生时所有源同时错，投票必错，故错误率至少 `P(C)`；`n_eff` 由等相相关下样本均值的方差反解。系：**当 `δ_c>0`，增大 k 不能把错误率压到 `δ_c` 以下；R69 引理 18 的上界只在测得的 `ρ≈0` 时成立，必须把 k 换成 `n_eff`。** 机制检验 B：`δ_i=0.25, δ_c=0.05` 时，k=12 的多数错误率 6.32%，而独立参考仅 1.41%；ρ=0.3 时 k=12 的 `n_eff=2.79`。

**引理 20（幻影交叉核验的检测与盲区）** 对**个体幻影**（仅一台机器幻觉），PX 的漏检率随 `n_eff` 下降：其他独立源以误报率 `α` 支持幻影，至少两个佐证的概率约 `C(n_eff,2)α²`，故 `n_eff` 越大越容易识破；对**共享幻影**（共同原因 `C` 发生），PX 的检测率为 0。**证明要点**：PX 只比较「源之间是否一致」，共享幻影在源之间完全一致。系：**PX 只能删个体幻影；共因幻影必须由 AEG 的外部锚发现。** 机制检验 C：`α=0.05, n=10, δ_c=0` 时幻影被 ≥2 个源「佐证」的概率为 7.03%；`δ_c=0.1` 时升到 16.58%；而真实模态在 `p_det=0.5, n=10` 时被 ≥2 源支持的概率是 98.05%。**一致性有判别力，但不是真理。**

**引理 21（采集策略必须匹配风险泛函）** 对 `R_mean`，Neyman 分配 `n_f ∝ w_f√(p_f(1−p_f))` 最小化估计方差；对 `R_tail=max_f p_f`，最优分配把样本集中到上尾候选。两者一般不同：尾采样对均值估计有偏（除非重要性重加权），均值采样对尾估计高方差。**证明要点**：分层估计方差 `Σ_f w_f² p_f(1−p_f)/n_f`，在 `Σn_f=N` 下用拉格朗日求极小即得 Neyman；尾泛函只依赖上尾坐标，其灵敏度集中在少数族。**不存在与泛函无关的最优采集策略。** 机制检验 D：均值目标下，均匀采样 RMSE 0.0116，尾采样 0.0197（差 70%）；尾目标下，均匀 0.2049，尾采样 0.1218（好 41%）。**同一个采集预算，换个泛函就换一个最优策略。**

**引理 22（来源影响与投毒可检测性）** 设单台恶意机器人的偏差为 `b`、共 n 台、鲁棒聚合破坏点 `α`。当 `b` 足够大且 `f/n<α`，trimmed/median 的误差有界；LORO 在**单一** rogue 时可检测，但在 `f≥2` 时会被互相掩护。**证明要点**：鲁棒聚合的 breakdown 只保证少数异常；LORO 的决策翻转依赖「移除一台后聚合值跨过 gate」，多台同向偏置会互相维持。机制检验 E：1 台 rogue 时，mean MAE 0.084、median 0.030、trimmed 0.028，robust residual 召回 99.85%、误报 0.46%；LORO gate-flip 召回 82.53%、误报 5.24%；2 台 rogue 时 trimmed MAE 退化到 0.109，LORO 召回跌到 9.30%。**「多机」在投毒下可能是放大器；独立来源数与恶意比例必须同时满足。**

**定理 18（FLEET 严格包含 FLUID）** 在 `|V|=1`、采集预算 `=0`、或锚不可用时，FLEET 的实时决策逐指令等于 FLUID；当 FLUID 的 `VoI≤成本` 时再退化为 R68。SDR 只接受不劣于当前 `CVaR/co-failure` 的候选，故任意时刻的部署风险 `≤` 当前版本；安全侧不做让步，效率收益只在证书通过后获得。**R69 是 FLEET 在「无舰队、无数据、无锚」边界上的退化；R68 是再往下的「永不交互」边界。**

**定理 19（评测棘轮的安全性）** 在 A99（`f/n<α`、`gaming_gap≤τ_game`、锚相关 `<ρ_max`、来源覆盖充分）下，SDR 的部署序列以概率 `≥1−η` 满足 `R_tail` 与 `R_co` 非增；若任一条件被违反，证书失效并回退到上一版本。**证明要点**：SDR 的接受条件是上置信界不劣于当前的下置信界；在 A99 下置信界覆盖真值，故每次接受都不会使真实尾风险上升；违反条件时证书不 Valid，按定义不部署。**代价**：安全单调性换来的是采集与锚成本，不是免费午餐。

**定理 20（宏观 VoI 的贪心近似）** 在 A100（episode 价值边际递减、覆盖约束可分离）下，greedy 采集达到 `(1−1/e)` 的 OPT；带覆盖下界时用 lazy greedy + 拉格朗日/ILP 修正。**注意**：A100 在重尾共失效场景可能失效（一个高风险族的价值不随已采集样本平滑递减），此时 greedy 无保证，必须用分层/对抗式设计。

## 6. 本轮最大风险

**一句话**：FLEET 把「多机一致性」当成外部真理，但舰队可以**一起错**——共享训练谱系、本体、标定与场景先验产生共因失效，而共因失效恰恰是评测内部最看不见的；如果外部锚也来自同一分布或缺失，证书就会用「很多台机器都同意」给一个共同幻觉盖章——**用评测证明评测可信，仍然是循环论证，只是循环变大了。**

**次级风险与缓解**：数据投毒（DPC + BRA + LORO；引理 22）；评测感知/Goodhart（随机盲评 + EGD + 持续评测；定义 321）；采集偏差/覆盖不足（TSC 覆盖下限 + 重要性重加权 + VQAuditor-F；定义 318/326）；共因盲区（AEG 外部锚 + 谱系覆盖 + E304/E316）；采集成本击穿预算（MEV 的 `VoI−c` 门控 + 分层/贪心 + E313）；尾估计的低估偏差（极值校正 + 锚校准；机制检验 D 的负 bias 已暴露该问题）。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 实时零学习写；两时间尺度隔离；无外部锚不证书；风险单调棘轮；采集预算/覆盖/来源硬约束。

**定义 311（FEG）** `ρ_ij` 在探针集上 cross-fitting 估计；`n_eff=k/(1+(k−1)ρ̄)`；`δ_c=P(共同原因使所有源同时错)`。产物是 `(ρ,δ_c,n_eff)`，不是排名。

**定义 312（FDD）** 机间偏置 `b_r=A z_{L(r)}+B c_{emb(r)}+ε_r`；`U_shared=E‖AΔz+BΔc‖²`，`U_idio=E‖Δε‖²`。只有 `U_idio` 可作外部第二意见；`U_shared` 是舰队盲区。

**定义 313（PX）** 模态被舰队证实 ⇔ 至少两个 `ρ≤ρ_orth` 的机器人以权重 `≥w_min` 支持，或 `n_eff` 加权支持 `≥τ_supp`；否则 phantom-suspect，降权且不得触发交互。PX 只能删个体幻影。

**定义 314（AEG）** 锚类 `{人类专家, 物理不变量, 受控反事实, 跨本体, 独立传感}`；要求至少一个 `ρ_a≤ρ_max`、高风险族锚覆盖 `≥a_min`、无未解释冲突 `κ_a≤τ_κ`；否则证书只算「内部一致性」，不得解锁效率。

**定义 315–316（评测单元与风险泛函）** `e=(r,f,ξ,δ)`；`C_f(q)` 为族 f 中 `≥q` 台共失效。`R_mean=Σw_f p_f`；`R_tail=CVaR_β({p_f})`；`R_co=CVaR_β({P(C_f(q))})`。**先声明泛函；默认尾+共失效。**

**定义 317（MEV）** `R_cert(D)=P[G(θ)≠G(θ_true)]`；`VoI(B)=R_cert(D)−E[R_cert(D∪B)]`；`B*=argmax[VoI−c]` s.t. 覆盖/锚/谱系/预算。与 R69 的实时 VoI 同泛函、不同决策变量；单 episode greedy 在 A99 下 `≥(1−1/e)OPT`。

**定义 318（TSC）** `q(f)∝w_f·g(p̂_f,target)`：均值→Neyman `√(p̂(1−p̂))`；尾→上尾候选；共失效→按边际贡献。覆盖下限 + 重要性重加权，防止尾采样给均值引入偏差。

**定义 319（DPC）** `π_d=(robot_id, model_hash, lineage_hash, calib_version, sensor_id, family, seed, perturbation, ts, sig)`；Merkle 根；`Δ_r=|G(D)−G(D\B_r)|`，超阈值隔离；谱系覆盖率检测全舰队同源。

**定义 320（BRA）** trimmed/median，破坏点 `α`；`f/n≥α` 拒发证书；相关加权 `∝1/(1+(k−1)ρ̄)`。防少数异常，不防多数共谋。

**定义 321（EGD）** `γ_game=TV(π_announced,π_unannounced)`；随机盲评/未预告探针；`γ_game>τ_game` ⇒ 批次 quarantine。

**定义 322（SDR）** 候选 `v'` 仅当 `J_FLEET` Valid 且 held-out `UCB_η(R_tail(v'))≤LCB_η(R_tail(v))`、`UCB_η(R_co(v'))≤LCB_η(R_co(v))`，或纯效率更新且尾风险不劣化时被接受；否则保持 `v`，可回滚。

**定义 323（J_FLEET）** 并入 `n_eff`、`δ_c`、锚覆盖、尾/共失效 CI、来源根、LORO 最大影响、gaming gap、谱系覆盖、预算、版本；全部阈值通过才 Valid。

**定义 324–325（VQAuditor-F / AIC-FLEET）** 审计采集是否只挑好看族、锚是否独立、是否系统性排除某机器人、LORO 是否被绕过、证书是否被评测感知污染；`ℰ_FLEET=ℰ_FLUID×ℰ_poison^fleet×ℰ_eval×ℰ_corr×ℰ_replay`。

**定义 326–327（预算/退化）** 覆盖 `n_min`、锚 `a_min`、谱系 `l_min`、成本 `≤B_max` 是硬约束；`|V|=1`、`B=0`、无锚时 FLEET ≡ FLUID，FLUID 再退化为 R68。评测只能通过 SDR 改变下一版本；任意时刻安全侧不弱于当前。

# IP-264 FEG：舰队证据图（离线；cross-fitting 估 ρ）
def estimate_fleet_graph(probe_A, probe_B, robots):
    rho = pairwise_error_corr(probe_A, robots)          # A 估相关
    rho_bar = mean_offdiag(rho)
    n_eff = {k: k / (1 + (k - 1) * rho_bar) for k in range(1, len(robots) + 1)}
    delta_c = estimate_common_mode_floor(probe_A, robots)
    if not validate_on_holdout(rho, delta_c, probe_B):     # B 只验证，不自证
        return FleetGraph.degraded()
    return FleetGraph(rho=rho, n_eff=n_eff, delta_c=delta_c)

# IP-265 FDD / IP-266 PX：分歧分解与幻影交叉核验
def fleet_disagreement(modes_per_robot, graph):
    U_ale = mean(within_robot_spread(r) for r in modes_per_robot)
    U_shared, U_idio = factor_decompose(modes_per_robot, graph.lineage, graph.emb)
    return U_ale, U_shared, U_idio

def phantom_crosscheck(mode, source, graph, tau_supp):
    support = sum(w for r, w in mode.support.items()
                  if graph.rho[source, r] <= RHO_ORTH and w >= W_MIN)
    return support >= tau_supp        # False ⇒ phantom-suspect，禁止触发交互

# IP-267 AEG：外部锚门（无锚不证书）
def anchor_gate(family, anchors):
    if not any(a.rho <= RHO_MAX for a in anchors): return False
    if any(family.coverage(a) < A_MIN for a in anchors if family.high_risk): return False
    return all(a.conflict <= TAU_KAPPA for a in anchors)

# IP-268 MEV / IP-269 TSC：为证书买数据（离线）
def select_collection_batch(posterior, candidates, budget, target):
    batch, spent = [], 0.0
    while spent < budget.max_cost:
        best = None
        for b in candidates:
            if not budget.allow(b):                  continue
            if not coverage_ok(batch, b, target):    continue   # 每族/锚/谱系
            score = far_bound_voi(posterior, b) - b.cost
            if best is None or score > best.score: best = (b, score)
        if best is None or best.score <= 0: break     # 无利可图 ⇒ 不采集
        batch.append(best[0]); spent += best[0].cost
        posterior = update_cert_posterior(posterior, best[0])
    return batch

# IP-270 DPC / IP-271 BRA / IP-272 EGD：采集后审计
def certify_batch(batch):
    root = merkle_root([provenance(d) for d in batch])
    stats = robust_trimmed_aggregate(batch, breakdown=ALPHA)   # 拜占庭鲁棒
    loro = {r: gate_influence(batch, r) for r in batch.robots}
    if max(loro.values()) > TAU_INFL:        return Quarantine("loro", loro)
    if eval_awareness_gap(batch) > TAU_GAME: return Quarantine("gaming")
    if lineage_coverage(batch) < L_MIN:       return Quarantine("lineage")
    return CertifiedBatch(root=root, stats=stats, loro=loro)

# IP-273 SDR：安全部署棘轮（只在证书通过后移动安全边界）
def safe_deploy(current, candidate, heldout):
    J = certify(candidate, heldout)
    if not J.valid: return current
    if not (ucb(J.R_tail) <= lcb(current.R_tail) and
            ucb(J.R_co)   <= lcb(current.R_co)): return current
    return candidate

# IP-277 主闭环：实时仍走 R69；FLEET 只在离线侧工作
def FLEET_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_shared, U_idio = M.fdd.decompose(samples, M.fleet_graph)
    if not M.px.corroborated(M.fmp.mode_head.mode(z), M.fleet_graph):
        U_idio = 0.0; U_shared = U_shared + U_idio  # 幻影降权，视同不可约
    g = M.mint.choose_interaction(...) if U_idio > TAU_EPI else None
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_idio if g is None else 0.0)))
    k = M.c_ras_wm.certified_prefix(...)
    M.audit.submit_async(M.last_decision, M.last_U)
    if M.eval_scheduler.due():                       # 离线，绝不写实时权重
        B = M.mev.select_collection_batch(M.cert_posterior, M.eval_candidates,
                                          M.budget, target=M.risk_functional)
        C = M.dpc.certify_batch(M.collect(B))
        if C.ok and M.anchor_gate(M.risk_functional.high_risk_families, M.anchors):
            M.safe_deploy(M.deployed, M.prepare_next_version(C), M.heldout)
    return k, lam

## 4. 推导

**引理 19（共因底与有效独立性）** `E_i=C∨B_i`，`P(C)=δ_c`，`B_i` 独立。则多数投票错误率 `≥δ_c`；等相相关 `ρ` 下 `n_eff=k/(1+(k−1)ρ)`。证明：`C` 发生时所有源同错，投票必错；`n_eff` 由样本均值方差反解。系：**`δ_c>0` 时增大 k 无法把错误压到 `δ_c` 以下；R69 引理 18 的 k 应换成 `n_eff`。** 机制检验 B：`δ_i=0.25, δ_c=0.05`，k=12 多数错误 6.32%，独立参考 1.41%；`ρ=0.3, k=12` 时 `n_eff=2.79`。

**引理 20（幻影交叉核验的检测与盲区）** 个体幻影：其他独立源以误报率 `α` 支持，至少两个佐证的概率约 `C(n_eff,2)α²`，故漏检随 `n_eff` 下降；共享幻影（`C` 发生）检测率为 0。系：**PX 只能删个体幻影；共因幻影必须由 AEG 发现。** 机制检验 C：`α=0.05,n=10,δ_c=0` 幻影被 ≥2 源佐证 7.03%；`δ_c=0.1` 升到 16.58%；真实模态 `p_det=0.5,n=10` 被 ≥2 源支持 98.05%。

**引理 21（采集策略必须匹配风险泛函）** `R_mean` 的方差 `Σw_f²p_f(1−p_f)/n_f`，在预算约束下用 Neyman `n_f∝w_f√(p_f(1−p_f))` 最优；`R_tail=max_f p_f` 只依赖上尾坐标，最优分配集中到上尾候选。两者一般不同；尾采样对均值有偏（除非重加权），均值采样对尾高方差。**不存在与泛函无关的最优采集策略。** 机制检验 D：均值目标 uniform RMSE 0.0116、tail_top2 0.0197；尾目标 uniform 0.2049、tail_top2 0.1218。

**引理 22（来源影响与投毒可检测性）** `f/n<α` 时 trimmed/median 误差有界；LORO 在单一 rogue 可检测，多 rogue 互相掩护。机制检验 E：1 rogue 时 mean MAE 0.084、median 0.030、trimmed 0.028，robust residual 召回 99.85%/误报 0.46%，LORO 召回 82.53%/误报 5.24%；2 rogue 时 trimmed MAE 0.109、LORO 召回 9.30%。

**定理 18（FLEET 严格包含 FLUID）** `|V|=1`、`B=0`、或锚不可用时逐指令等于 FLUID；FLUID 在 `VoI≤成本` 时退化为 R68。SDR 只接受不劣于当前 `CVaR/co-failure` 的候选，故任意时刻部署风险 `≤` 当前；安全不让步，效率只在证书通过后获得。

**定理 19（评测棘轮的安全性）** A99（`f/n<α`、`gaming_gap≤τ_game`、锚相关 `<ρ_max`、来源覆盖充分）下，SDR 部署序列以概率 `≥1−η` 满足 `R_tail` 与 `R_co` 非增；任一条件违反则证书失效并回退。证明：接受条件是上置信界不劣于当前下置信界，A99 下置信界覆盖真值。

**定理 20（宏观 VoI 的贪心近似）** A100（episode 价值边际递减、覆盖可分离）下 greedy 达到 `(1−1/e)OPT`；覆盖下界用 lazy greedy + 拉格朗日/ILP。注意：重尾共失效下 A100 可能失效，greedy 无保证，必须用分层/对抗式设计。

|---|---:|---:|---:|---:|
| `R_mean` | **0.0116** | 0.0135 | 0.0115 | 0.0197 |
| `R_tail` | 0.2049 | 0.1276 | 0.1687 | **0.1218** |

尾目标下 `tail_top2` 相对 uniform 降低 40.6% RMSE；但同一策略在均值目标下变差 69.8%。**采集策略不能脱离风险泛函被评价。** 另外尾估计整体偏低（bias −0.07 ~ −0.17），说明 `max_f p̂_f` 需要极值校正，否则会系统性低估尾部风险。

### E. 拜占庭与 LORO（S4 / 引理 22）

n=12，标定标量噪声 `σ=0.10`，rogue 偏差 `+1.0`，gate 阈值 0.05，4000 次重复：

| rogue 数 | mean MAE | median MAE | trimmed MAE | robust residual 召回/误报 | LORO gate-flip 召回/误报 |
|---|---:|---:|---:|---:|---:|
| 0 | 0.0228 | 0.0271 | 0.0234 | — / 0.70% | — / 2.21% |
| 1 | 0.0840 | 0.0304 | 0.0284 | 99.85% / 0.46% | 82.53% / 5.24% |
| 2 | 0.1659 | 0.0364 | 0.1091 | 98.80% / 0.24% | 9.30% / 0.00% |

**鲁棒聚合对 1 台 rogue 有效，对 2 台开始退化（trimmed 0.109）；LORO 在 2 台同向 rogue 时几乎失效（9.30%）——多台恶意机器人会互相掩护。** 因此 `f/n<α` 必须与来源多样性一起检查，不能只看「有几台机器同意」。

## 7. 实验设计 E301–E318

| 实验 | 核心问题 | 关键目标 |
|---|---|---|
| E301 舰队相关标定 | `ρ_ij,δ_c,n_eff` 是否准 | ρ 的 held-out 误差 < 0.05；n_eff 预测误差 < 10% |
| E302 幻影交叉核验 | PX 能否识破个体幻影 | 个体幻影误交互 ≤ 5%；真实模态召回 ≥ 95% |
| E303 共因底 | 多机为何不能无限变好 | k↑ 时错误率收敛到 δ_c；与引理 19 吻合 |
| E304 共因盲区 | 舰队一致但全错 | PX 检出率 ≈ 0；AEG 检出率 ≥ 80% |
| E305 均值 vs 尾排序 | 排行榜是否误导 | 复现名次互换；尾排序与安全事件更相关 |
| E306 泛函匹配采集 | 采集是否必须匹配目标 | 均值目标 Neyman 最优；尾目标 RMSE 降 ≥ 30% |
| E307 宏观 VoI | 定向采集 vs 均匀/随机 | 同等证书置信所需样本少 ≥ 30% |
| E308 来源/投毒 | Byzantine 机器人 | 1 rogue 下 trimmed MAE < mean 的 50%；2 rogue 触发隔离 |
| E309 LORO 影响 | 影响检测是否有效 | 单 rogue 召回 ≥ 80%；多 rogue 明确报告掩护失败 |
| E310 评测感知 | Goodhart / 观察者效应 | gap AUC ≥ 0.85；污染批次 100% quarantine |
| E311 安全棘轮 | 部署是否单调 | 接受版本 `R_tail/R_co` 不劣于上一版；违规 = 0 |
| E312 严格包含 | FLEET ≡ FLUID | `|V|=1/B=0/无锚` 时逐指令行为差 = 0 |
| E313 预算 Pareto | 采集成本-证书收益 | 给出 VoI/成本拐点与覆盖下限的边际价值 |
| E314 长时程 | 漂移 + 持续评测 | 24h 内证书失效可触发回滚；静默漂移 = 0 |
| E315 异构性消融 | 同款舰队 vs 异构舰队 | 同款 k=12 的 n_eff < 异构 k=4 的 n_eff（同预算） |
| E316 谱系投毒 | 全舰队同源污染 | lineage coverage 触发拒绝；证书不通过 |
| E317 真实榜单回放 | UniBot-V1 8×32 的尾结构 | 复现均值/尾名次差；共失效模拟给出族级风险 |
| E318 共谋欺骗 | 多数机器人一起撒谎 | 无外部锚时证书必然失效；有锚时错误采纳 ≤ 5% |

## 8. 本轮最大风险

**一句话**：FLEET 把「多机一致性」当成外部真理，但舰队可以**一起错**——共享训练谱系、本体、标定与场景先验产生共因失效，而共因失效恰恰是评测内部最看不见的；如果外部锚也来自同一分布或缺失，证书就会用「很多台机器都同意」给一个共同幻觉盖章——**用评测证明评测可信，仍然是循环论证，只是循环变大了。**

**次级风险与缓解**：数据投毒（DPC + BRA + LORO；引理 22）；评测感知/Goodhart（随机盲评 + EGD + 持续评测；定义 321）；采集偏差/覆盖不足（TSC 覆盖下限 + 重要性重加权 + VQAuditor-F；定义 318/326）；共因盲区（AEG 外部锚 + 谱系覆盖 + E304/E316）；采集成本击穿预算（MEV 的 `VoI−c` 门控 + 分层/贪心 + E313）；尾估计的低估偏差（极值校正 + 锚校准；机制检验 D 的负 bias 已暴露该问题）。
