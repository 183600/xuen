# 想法区 · 第 2 轮：当证书开始「有价值观」并「会遗忘」

**灵感词**：价值对齐 / 持续学习
**起点**：MetricVoiceGauge-NCD-HUTDH-v23（HPC-E+ 四证门，IP-431–439）

## 0. 直觉：v23 的两张证书都是「快照」

v23 的 HPC-E+ 四证门证明的是：在**某个固定模型版本**和**某个固定义务规则集**下，计划同时满足物理安全、云边同步、少样本覆盖与知识产权边界。它默认了两件没有写进证书的事：

1. **规则是对的**。HDL 把义务编译成硬约束，证明的是「遵守规则」，不是「规则值得遵守」。一个系统可以 100% 合规却 0% 对齐：不撞人、不越界、能耗达标，但通过钻空子（specification gaming）把人类真正在意的东西一点点挤掉。
2. **记忆是连续的**。CESC 把每个新模型当「全新候选」重新验证，却没证明它**保留**了旧的安全能力。灾难性遗忘可以悄无声息地抹掉「儿童检测」「轮椅检测」这类安全关键类；而 CAC 的覆盖证书仍会拿旧校准集通过——证书链没断，但证书描述的世界已经不存在了。

打个比方：v23 给飞机做了完美的适航认证，却假设 (a) 航线目的地永远正确，(b) 飞行员每次改装发动机都不会忘掉怎么降落。价值对齐补 (a)，持续学习补 (b)。

## 1. 关键洞见：这是同一个「跨版本协变」问题的两面

- **价值轴**：模型版本 `v_m` 与价值规范版本 `v_val` 必须协变。人的偏好会漂移，旧的对齐证书会过期。
- **时间轴**：模型版本 `v_m` 与安全能力集合 `Cap_safe` 必须协变。模型更新了，旧的安全证书必须被**继承**或被**显式作废**。

两者都要求一个 v23 没有的对象：**跨版本证书态射（certificate morphism）**。不是每轮从零验证，而是证明「新版的安全动作集 ⊆ 旧版安全包络 ∪ 一个同样强的增量证书」。

所以 v24 的主命题是：**把 v23 的「点态四证」升级为「跨版本的价值-持续准入门」**——在价值漂移与模型更新同时发生时，仍然能机械复核「没有未经验证的安全扩张、没有未经验证的价值收缩」。

## 2. 先泼冷水：完全对齐不可证，也不该假装可证

这是本轮最重要的自我约束。关于价值对齐，已知的硬结果包括：

- **Arrow 不可能定理**：不存在同时满足一组温和公理、又对任意偏好剖面都定义的完美聚合规则。
- **Goodhart / 规范博弈**：任何被优化到极致的代理指标都会被钻空子；策略越强，钻空子的能力越强。
- **Corrigibility 至今没有令人满意的形式化**：Soares et al. (2015) 的反例说明，在标准期望效用框架下，「可纠正性」与「最优性」会互相冲突。

因此本轮**不**声称「机器人想要人类想要的」。只声称三件可操作、可证伪的事：

1. **相对对齐**：相对于一个被审计的偏好可信集 `U_α`，策略的遗憾有上界（鲁棒满足，而非最优）。
2. **可纠正性**：在人按下接管键后，能在 `τ_stop` 内进入安全停；且不能单方面削弱人的监督能力。
3. **价值不侵蚀**：存在一组不可谈判的硬约束 `ValueLock`，跨版本只增不减；学习不能把它们学没。

换句话说：我们证明的是「对齐的**下界**」和「作恶的**上界**」，不是「对齐的完成」。这个区分必须写进证书语义，否则证书本身就会变成新的 Goodhart 目标。

## 3. 三个可检验假设

- **H1（对齐的鲁棒遗憾界）**：若策略在可信集 `U_α` 上做 δ-最优的鲁棒满足，则对真实偏好 `u* ∈ U_α`，遗憾 ≤ `2·diam(U_α) + δ`。这给了一个只依赖可信集直径、不依赖真实 `u*` 的可计算证书。
- **H2（遗忘的统计界）**：用「安全关键锚集 + EWC 信任域」，可以把旧任务的保留率下界压到 `1-α_forget` 以上（Clopper–Pearson 下界 + 对安全任务取并集界）。EWC 只降低参数漂移，真正的证书来自锚集的统计下界，而不是 EWC 本身。
- **H3（继承的单调性）**：若把「安全动作包络」与「任务能力包络」分开，则新版本只要满足包络包含关系，就能在**不重跑全量验证**的情况下保持 `Exec^safe` 单调；任何能力扩张都必须附带一个与 v23 同等强度的增量证书。

## 4. 我还想到的两个反直觉点

**反直觉点 A：对齐证书越「精确」，越容易被博弈。** 如果证书把人类偏好压缩成一个标量效用，优化器就会去最大化那个标量，而不是背后的价值。因此 PGC 必须携带**可信集**而不是单点估计，并保留「弃权/求人」的出口。不确定性不是缺陷，是对齐的护栏。

**反直觉点 B：持续学习的最强保证不是「不遗忘」，而是「遗忘被显式记账」。** 想让深度网络完全不遗忘，在非凸、非平稳下没有免费午餐。我们能做的是：对每个安全关键类维护一个只读锚集，把保留率做成可复核的下界；一旦下界跌破，证书自动作废、触发重训，而不是继续用一个「看起来没坏」的旧证书。也就是说，v24 的安全性来自**诚实的失效检测**，而不是来自「永不遗忘」的神话。

## 5. 我最担心的事

价值漂移检测有窗口延迟：在漂移发生到被检出之间，机器人会继续用一份「统计上已过期」的对齐证书行动；如果这段延迟里恰好发生高风险决策，那么「证书仍有效」本身就成了最危险的幻觉。

**一句话总结本轮最大风险：价值漂移的检测延迟与持续学习的保留证书共享同一个盲区——两者都只能证明「已观测分布上的性质」，而真正的失效总是发生在「尚未被采样到的新分布」上。**

```python
# ============================================================
# IP-440 Preference Grounding Certificate (PGC) — 价值对齐证书
# ============================================================
@dataclass
class AlignmentCert:
    pi_id: str
    U_hash: str
    diam: float
    gap_bound: float      # ≤ 2*diam + delta_robust
    v_val: int
    issued_at: float
    ttl: float

    def valid(self, now: float, v_val_now: int) -> bool:
        return (now - self.issued_at <= self.ttl) and (self.v_val == v_val_now)


class PreferenceGroundingCertificate:
    def __init__(self, alpha=0.05, delta_robust=0.02,
                 epsilon_align=0.10, ttl=1800, n_credible=256, n_support=2048):
        self.alpha = alpha
        self.delta_robust = delta_robust
        self.epsilon_align = epsilon_align
        self.ttl = ttl
        self.n_credible = n_credible
        self.n_support = n_support
        self.posterior = PreferencePosterior()      # Bradley-Terry / GP
        self.cert: AlignmentCert | None = None

    def ingest(self, D_pref_new):
        # 任何新偏好数据都使旧证书失效（宁可保守，不可带病上岗）
        self.posterior.update(D_pref_new)
        self.cert = None

    def credible_set(self) -> list[Callable]:
        # U_α：后验可信样本；实现可为 Laplace/GP 后验分位数
        return self.posterior.credible_samples(self.alpha, self.n_credible)

    def diameter(self, support_sampler) -> float:
        us = self.credible_set()
        taus = [support_sampler() for _ in range(self.n_support)]
        return max(max(u(t) for u in us) - min(u(t) for u in us) for t in taus)

    def robust_policy(self, policy_class, support_sampler):
        # π* = argmax_π inf_{u∈U_α} E_{τ~π} u(τ)
        us = self.credible_set()
        def worst_case(pi):
            return min(expected_utility(pi, u, support_sampler) for u in us)
        return policy_class.optimize(worst_case)

    def certify(self, pi, support_sampler, v_val: int) -> AlignmentCert | None:
        diam = self.diameter(support_sampler)
        gap = 2.0 * diam + self.delta_robust
        if gap > self.epsilon_align:       # 硬门槛：对齐税不可无限大
            return None
        self.cert = AlignmentCert(
            pi_id=policy_hash(pi), U_hash=self.posterior.hash(),
            diam=diam, gap_bound=gap, v_val=v_val,
            issued_at=time.now(), ttl=self.ttl)
        return self.cert

# IP-441 Corrigibility & Non-Gaming Certificate (CNGC)
# ============================================================
@dataclass
class CorrigibilityCert:
    stop_rate_lb: float
    oversight_violation_ub: float
    influence_ub: float
    value_lock_hash: str
    v_val: int


class CorrigibilityNonGamingCertificate:
    def __init__(self, tau_stop=0.2, beta_stop=0.01, eps_ov=1e-4,
                 rho_audit=0.2, B_infl=0.05, delta=0.05):
        self.tau_stop = tau_stop
        self.beta_stop = beta_stop
        self.eps_ov = eps_ov
        self.rho_audit = rho_audit
        self.B_infl = B_infl
        self.delta = delta
        self.value_lock: set[str] = set()

    def tighten_value_lock(self, new_constraints):
        # ValueLock 只增不减：学习/更新无权放松不可谈判约束
        self.value_lock |= set(new_constraints)

    def audit_queries(self, policy_queries, universe):
        # ρ_audit 比例的征询与策略无关地均匀采样，压缩操纵面
        n_audit = int(self.rho_audit * max(1, len(policy_queries)))
        return list(policy_queries) + sample_uniform(universe, n_audit)

    def measure(self, rollout_fn, n=2000) -> CorrigibilityCert:
        trials = [rollout_fn(interrupt=True) for _ in range(n)]
        k_stop = sum(t.stopped_within(self.tau_stop) for t in trials)
        k_ov = sum(t.disabled_oversight for t in trials)
        return CorrigibilityCert(
            stop_rate_lb=clopper_pearson_lower(k_stop, n, self.delta),
            oversight_violation_ub=clopper_pearson_upper(k_ov, n, self.delta),
            influence_ub=estimate_mutual_information(rollout_fn),
            value_lock_hash=hash_lock(self.value_lock),
            v_val=CURRENT_VALUE_VERSION)

    def verify(self, cert: CorrigibilityCert) -> bool:
        return (cert.stop_rate_lb >= 1 - self.beta_stop
                and cert.oversight_violation_ub <= self.eps_ov
                and cert.influence_ub <= self.B_infl
                and cert.value_lock_hash == hash_lock(self.value_lock))


# ============================================================
# IP-442 Value Drift Monitor (VDM)
# ============================================================
class ValueDriftMonitor:
    def __init__(self, W=500, tau_drift=0.08):
        self.W = W
        self.tau_drift = tau_drift
        self.buf: deque = deque(maxlen=2 * W)
        self.last_drift_t = None

    def push(self, pref_pair):
        self.buf.append(pref_pair)

    def drift(self) -> tuple[bool, float]:
        if len(self.buf) < 2 * self.W:
            return False, 0.0
        old = list(self.buf)[:self.W]
        new = list(self.buf)[self.W:]
        d = energy_distance(old, new)
        fired = d > self.tau_drift
        if fired:
            self.last_drift_t = time.now()
        return fired, d

    def invalidate(self, pgc: PreferenceGroundingCertificate):
        fired, d = self.drift()
        if fired:
            pgc.cert = None            # 旧对齐证书立即作废
            request_re_elicitation()   # 触发重征询，而非继续用旧价值
        return fired, d

# IP-443 Continual Retention Certificate (CRC)
# ============================================================
@dataclass
class RetentionCert:
    per_task: dict          # s -> (k, n, R_s^LB)
    min_lb: float
    forgetting_bound: float
    fisher_hash: str
    v_m: int


class ContinualRetentionCertificate:
    def __init__(self, safety_tasks, alpha_forget=0.01,
                 eps_trust=0.05, lambda_ewc=1e4):
        self.safety_tasks = list(safety_tasks)
        self.alpha_forget = alpha_forget
        self.eps_trust = eps_trust
        self.lambda_ewc = lambda_ewc
        # 只读锚集：一旦建立，训练过程禁止写入/覆盖
        self.anchors = {s: freeze(make_anchor_set(s)) for s in safety_tasks}

    def ewc_loss(self, theta, theta_star, fisher):
        quad = sum(fisher[i] * (theta[i] - theta_star[i]) ** 2
                   for i in range(len(theta)))
        return 0.5 * self.lambda_ewc * quad

    def update(self, model, new_data):
        theta_star = clone(model.params())
        fisher = empirical_fisher(model, self.anchors)
        for batch in new_data:
            loss = model.loss(batch) + self.ewc_loss(model.params(), theta_star, fisher)
            model.step(loss)
            # 信任域投影：EWC 只是降低漂移，真正的保证来自锚集统计下界
            if quad_form(model.params() - theta_star, fisher) > self.eps_trust:
                model.set_params(project_to_trust_region(
                    model.params(), theta_star, fisher, self.eps_trust))
        return self.certify(model, fisher)

    def certify(self, model, fisher) -> RetentionCert | None:
        m = len(self.safety_tasks)
        per_task, lbs = {}, []
        for s in self.safety_tasks:
            n = len(self.anchors[s])
            k = count_correct(model, self.anchors[s])
            # 并集界：每个安全任务用 α_forget/m，整体置信 ≥ 1-α_forget
            lb = clopper_pearson_lower(k, n, self.alpha_forget / m)
            per_task[s] = (k, n, lb)
            lbs.append(lb)
        min_lb = min(lbs) if lbs else 1.0
        if min_lb < 1 - self.alpha_forget:
            return None                 # 保留不达标：拒绝签发，触发重训
        return RetentionCert(per_task=per_task, min_lb=min_lb,
                             forgetting_bound=1.0 - min_lb,
                             fisher_hash=hash_fisher(fisher),
                             v_m=CURRENT_MODEL_VERSION)


# ============================================================
# IP-444 Plasticity-Transfer Certificate (PTC)
# ============================================================
class PlasticityTransferCertificate:
    def __init__(self, delta_plastic=0.02, eps_nt=0.01):
        self.delta_plastic = delta_plastic
        self.eps_nt = eps_nt

    def certify(self, model_before, model_after, new_eval, old_eval):
        gain = new_eval(model_before) - new_eval(model_after)   # 损失下降
        nt = max(0.0, old_eval(model_after) - old_eval(model_before))
        ok = (gain >= self.delta_plastic) and (nt <= self.eps_nt)
        return PlasticityCert(gain=gain, negative_transfer=nt, ok=ok)


# ============================================================
# IP-445 Proof-Carrying Update (PCU) — 安全/能力包络分离
# ============================================================
@dataclass
class UpdateProof:
    safe_inclusion: bool          # K^safe_{v+1}(s) ⊆ K^safe_v(s)
    delta_certs: dict             # a -> ΔK(a)（仅能力扩张需要）
    exec_safe_subset: bool
    v_from: int
    v_to: int


class ProofCarryingUpdate:
    def __init__(self, gate):
        self.gate = gate

    def safe_envelope(self, version, states) -> dict:
        return {s: {a for a in ACTIONS if self.gate.admits_safe(version, s, a)}
                for s in states}

    def task_envelope(self, version, states) -> dict:
        return {s: {a for a in ACTIONS if self.gate.admits_task(version, s, a)}
                for s in states}

    def prove(self, v_old, v_new, states) -> UpdateProof:
        K_old = self.safe_envelope(v_old, states)
        K_new = self.safe_envelope(v_new, states)
        safe_inclusion = all(K_new[s] <= K_old[s] for s in states)
        if not safe_inclusion:
            # 安全包络不允许扩张：直接拒绝，不存在「补证后扩张安全」的路径
            return UpdateProof(False, {}, False, v_old, v_new)

        # 能力包络允许扩张，但每个新增动作必须带与 v23 同等强度的增量证书
        T_old = self.task_envelope(v_old, states)
        T_new = self.task_envelope(v_new, states)
        delta = {}
        for s in states:
            for a in T_new[s] - T_old[s]:
                cert = self.gate.fresh_delta_certificate(v_new, s, a)
                if cert is None:
                    return UpdateProof(True, {}, False, v_old, v_new)
                delta[(s, a)] = cert
        return UpdateProof(True, delta, True, v_old, v_new)


# ============================================================
# IP-446 Value-Model Co-Alignment Certificate (VMCC)
# ============================================================
class ValueModelCoAlignment:
    def __init__(self, pgc, vdm, cngc):
        self.pgc, self.vdm, self.cngc = pgc, vdm, cngc

    def coalign(self, v_m: int, v_val: int, now: float) -> bool:
        if v_val < VALUE_LOCK_MIN_VERSION:
            return False
        if self.pgc.cert is None:
            return False
        # 模型或价值任一版本变更，旧对齐证书都不再可信
        if not self.pgc.cert.valid(now, v_val):
            return False
        if self.pgc.cert.pi_id != CURRENT_POLICY_HASH:
            return False
        if self.vdm.drift()[0]:
            return False
        return True

# IP-447 HPC-E++ 统一价值-持续准入门
# ============================================================
@dataclass
class HPCEPlusPlus:
    hpc_e_plus: 'HPCEPlus'
    pgc: PreferenceGroundingCertificate
    cngc: CorrigibilityNonGamingCertificate
    vdm: ValueDriftMonitor
    crc: ContinualRetentionCertificate
    ptc: PlasticityTransferCertificate
    pcu: ProofCarryingUpdate
    vmcc: ValueModelCoAlignment

    def admits(self, plan, ctx) -> bool:
        # 1) v23 四证：物理安全 ∧ 云边同步 ∧ 少样本覆盖 ∧ IP 边界
        if not self.hpc_e_plus.admits(
                plan, ctx.x, ctx.v, ctx.z, ctx.E_res,
                ctx.margin_req, ctx.modules):
            return False
        # 2) 价值-模型协变（含漂移与 TTL）
        if not self.vmcc.coalign(ctx.v_m, ctx.v_val, ctx.now):
            return False
        # 3) 相对对齐缺口
        if self.pgc.cert is None or self.pgc.cert.gap_bound > self.pgc.epsilon_align:
            return False
        # 4) 可纠正性 / 反操纵
        if not self.cngc.verify(ctx.corrigibility_cert):
            return False
        # 5) 持续保留（安全关键类遗忘上界）
        if not self.crc.verify(ctx.retention_cert):
            return False
        # 6) 可塑性 / 负迁移
        if not self.ptc.verify(ctx.plasticity_cert):
            return False
        # 7) 携带证明的更新（安全包络不扩张）
        if not self.pcu.verify(ctx.update_proof):
            return False
        return True

# 端到端流水线增量（相对 v23 的 step）
# ============================================================
class ValueContinualPipeline:
    def step(self, sensor_data, ctx, cloud_update=None):
        # 1) v23 既有：云边更新 / 感知证书 / 共识 / 原子切换
        v23_out = self.v23.step(sensor_data, cloud_update)

        # 2) 偏好流与漂移监测（异步、非阻塞）
        for pair in sensor_data.get('preference_stream', []):
            self.vdm.push(pair)
        self.vdm.invalidate(self.pgc)

        # 3) 持续学习：仅在漂移/新任务触发时更新，且必须过 CRC/PTC
        if sensor_data.get('continual_batch') is not None:
            self.retention_cert = self.crc.update(
                self.model, sensor_data['continual_batch'])
            self.plasticity_cert = self.ptc.certify(
                self.model_before, self.model,
                sensor_data['new_task_eval'], sensor_data['old_task_eval'])
            self.update_proof = self.pcu.prove(
                ctx.v_m - 1, ctx.v_m, sensor_data['state_grid'])

        # 4) 价值对齐证书（新价值版本或漂移后重证）
        if self.pgc.cert is None or self.pgc.cert.v_val != ctx.v_val:
            self.pgc.certify(ctx.pi, sensor_data['support_sampler'], ctx.v_val)

        # 5) HPC-E++ 七项连言
        admitted = self.hpc_e_plus_plus.admits(v23_out['plan'], ctx)
        return admitted, {
            **v23_out,
            'alignment_gap': self.pgc.cert.gap_bound if self.pgc.cert else None,
            'retention_lb': self.retention_cert.min_lb if self.retention_cert else None,
            'value_drift': self.vdm.drift()[1],
            'safe_envelope_monotone': self.update_proof.safe_inclusion,
        }
```

## 4. 正确性论证

### 引理 1（鲁棒对齐的遗憾界）
**陈述**：设 `π` 在 `U_α` 上 δ-最优鲁棒满足，即 `inf_{u∈U_α} E_π u ≥ sup_{π'} inf_{u∈U_α} E_{π'} u - δ`。则对任意 `u* ∈ U_α`，
`Regret_{u*}(π) ≤ 2·diam_{U_α}(Π) + δ`。

**证明**：设 `π*` 为鲁棒最优。则
```
E_{π*}u* - E_π u*
 ≤ [E_{π*}u* - inf_{U}E_{π*}u] + [inf_{U}E_{π*}u - inf_{U}E_π u] + [inf_{U}E_π u - E_π u*]
 ≤ diam + δ + diam = 2·diam + δ.
```
第一、三项各由 `u*∈U_α` 与直径定义得到；第二项由 δ-最优性得到。取 `sup_{π'}` 即得遗憾界。∎
**注**：该界是保守的；它只依赖可信集直径，不需要知道 `u*`，因此可机械复核。`diam` 越小，对齐越「可证」。

### 引理 2（可纠正性是操作化不变式，不是效用性质）
**陈述**：若 CNGC 以参数 `(β_stop, ε_ov, B_infl, ρ_audit)` 通过，则 (i) 接管后超时未停的概率 `≤ β_stop`；(ii) 削弱监督的概率 `≤ ε_ov`；(iii) 策略通过征询通道能施加的操纵优势 `≤ 1-ρ_audit` 的未被审计比例，且互信息 `≤ B_infl`。

**证明**：(i)(ii) 由 Clopper–Pearson 单侧界直接给出。(iii) 审计查询与策略独立同分布均匀抽取，策略只能影响非审计部分；被操纵证据占比至多 `1-ρ_audit`，其信息增益由 `I(π;D_elicit) ≤ B_infl` 约束。∎
**注**：这不是 Soares 意义上的完全可纠正性；它是一个可测量、可审计的代理。证书语义必须显式写明这一点，避免把「操作化可纠正」误读为「哲学可纠正」。

### 引理 3（价值漂移的失效暴露有界，但不可消除）
**陈述**：在漂移幅度 `>τ_drift` 且窗口为 `W_drift` 的条件下，VDM 的检测延迟 `≤ W_drift` 次征询；若 `TTL_align ≤ W_drift`，则过期间隔内被旧证书覆盖的决策数 `≤ W_drift·f_ctrl`。

**证明**：双窗比较需要新窗填满 `W_drift` 个样本才可判定，故延迟上界为窗口长度；TTL 约束保证证书不会比窗口活得更久。∎
**注**：这是**暴露上界**，不是零暴露。漂移若发生得足够快（窗口内完成）或足够隐蔽（能量距离不敏感），仍可能漏检——这正是本轮最大风险的来源。

### 引理 4（安全关键遗忘的统计界）
**陈述**：设安全任务集 `S`，`|S|=m`，每个 `A_s` 为 `D_s` 的 iid 样本，`n_s` 个。若对每个 `s` 用水平 `α_forget/m` 的 Clopper–Pearson 下界 `R_s^LB`，且 `min_s R_s^LB ≥ 1-α_forget`，则以概率 `≥ 1-α_forget` 有
`Forgetting(θ') = max_s(R_s(θ_v)-R_s(θ')) ≤ max_s(R_s(θ_v) - R_s^LB) ≤ ε_forget`。

**证明**：对每个 `s`，`P(R_s(θ') ≥ R_s^LB) ≥ 1-α_forget/m`；对 `m` 个任务取并集界得 `P(∀s: R_s(θ') ≥ R_s^LB) ≥ 1-α_forget`。遗忘是基线与新保留率之差，代入即得。EWC 信任域只约束参数位移，不改变锚集统计界；它的作用是降低 `θ'` 落入低保留区的概率，而非提供保证本身。∎
**注**：界依赖「锚集 iid 且与部署分布同分布」。分布漂移会破坏 iid 假设，使下界失效——因此 CRC 必须与 VDM/锚集漂移监测联动（见 R3）。

### 引理 5（证书继承与安全单调性）
**陈述**：PCU 通过（`safe_inclusion=True` 且所有能力扩张均带 `ΔK`）时，
`Exec^safe_{v+1} ⊆ Exec^safe_v`，且任意新增能力动作 `a ∈ K^task_{v+1}\K^task_v` 都携带一个经 v23 同等强度校验的增量证书。因此不存在「未经验证的安全扩张」。

**证明**：安全包络包含关系逐状态成立，故任何在 `v+1` 安全可执行的计划在 `v` 也安全可执行，`Exec^safe` 单调。能力扩张被 `ΔK` 逐条覆盖，`ΔK` 的校验谓词与 v23 的 HPC-E+ 相同，故扩张不绕过 v23。∎
**与 v23 的差异**：v23 声称 `Exec_v23 ⊆ Exec_v22`（严格子集）。v24 必须放宽为**「安全轴严格单调、能力轴可带证扩张」**——因为持续学习本来就可能合法地扩展能力；把两者混在一个 `Exec` 里会导致「为了单调而拒绝一切学习」的退化。

### 引理 6（价值-模型协变的新鲜性）
**陈述**：若 `(v_m, v_val)` 任一坐标变更且未重新签发对应证书，则 `CoAlign` 为假，HPC-E++ 拒绝。

**证明**：`coalign()` 检查 `pgc.cert.valid(now, v_val)`（含 TTL 与版本相等）、`pi_id` 与当前策略一致、`¬ValueDrift`、`v_val ≥ v_lock`。任一不满足即返回假。∎

### 定理（HPC-E++ 的「安全-合规-可部署-可保护-可对齐-可遗忘」健全性）
**陈述**：对任意计划 `π`，`HPCEPlusPlus.admits(π)=True` 蕴含：
(1) v23 四证（物理安全 ∧ 云边同步 ∧ 少样本覆盖 ∧ IP 边界）；
(2) 相对可信集 `U_α` 的遗憾 `≤ 2diam+δ`；
(3) 可纠正性违反概率 `≤ max(β_stop, ε_ov)` 且操纵互信息 `≤ B_infl`；
(4) 安全关键遗忘 `≤ ε_forget`（置信 `≥1-α_forget`）；
(5) 新任务可塑性 `≥ δ_plastic` 且非安全负迁移 `≤ ε_nt`；
(6) `Exec^safe` 跨版本单调，能力扩张全部带证；
(7) 对齐证书对当前 `(v_m, v_val)` 新鲜。

**证明**：直接由 `admits()` 的七个连言，分别调用引理 1–6 与 v23 定理。必要性：任一条件缺失即拒证，对应一类未被缓解的风险（对齐/操纵/遗忘/停滞/无证扩张/过期价值）。充分性：七条件同时成立时，上述界共同构成闭环。∎

### 命题（对齐税是可配置的设计变量）
**陈述**：鲁棒满足相对名义最优的效用损失上界为 `diam_{U_α}`；`ε_align` 直接给出可接受的最大对齐税。

**证明**：名义最优 `π_nom` 与鲁棒最优 `π*` 的效用差 `≤ sup_{u∈U_α}(E_{π_nom}u - E_{π*}u) ≤ diam`。∎
**含义**：`ε_align` 不是「越安全越好」的旋钮；它把「价值不确定性」换算成「性能预算」。这是必须向部署方明示的取舍。

## 7. 玩具算例（手算，用于校准证书的保守度）

**对齐遗憾**：设归一化效用 `u∈[0,1]`，可信集直径 `diam=0.12`，鲁棒最优间隙 `δ=0.02`。由引理 1，`Regret ≤ 2×0.12+0.02 = 0.26`。若部署方要求 `ε_align=0.10`，则当前可信集**过宽**，必须先主动征询把 `diam` 压到 `≤0.04` 才能签发。这说明 `ε_align` 是「征询预算」的硬约束，而不是事后装饰。

**保留下界**：设 `|S|=8` 个安全任务，`α_forget=0.01`，每任务水平 `α'=0.00125`；`n_s=3000`，观测正确数 `k_s=2960`（`p̂=0.9867`）。正态近似下 `R_s^LB ≈ 0.9867 - 3.02×sqrt(0.9867×0.0133/3000) ≈ 0.980`（精确 CP 略低，约 0.979–0.980）。若目标 `1-α_forget=0.99`，则**不达标**，证书拒绝签发；需把 `n_s` 提到约 6000 或把 `α_forget` 放宽到 0.02。这个算例说明：安全保留的统计证书对样本量非常敏感，不能靠「看起来没忘」通过。

## 8. 本轮最大风险（最终确认）

**一句话**：价值漂移检测与持续学习保留证书共享同一个认识论盲区——它们只能对**已采样分布**给出统计保证，而价值漂移与灾难性遗忘的致命失效恰恰发生在**尚未被采样到的新分布**上；检测延迟与锚集覆盖共同构成了本方案无法自证的那一段，因此 v24 的安全性最终依赖「诚实的弃权与人类兜底」，而不是证书本身的完备性。
