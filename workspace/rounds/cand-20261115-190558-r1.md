# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「情感计算」×「数据标注」）

> R69 让闭环学会了「问」：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略把歧义显式呈现成若干动作模态，用「看 / 问 / 触」主动消解，预算不够才退回 R68 的保守铁律。但它对「问」这件事的建模，停在一个**理想证人**假设上：回答被当作对隐藏模态的一次干净观测，再用「k 个正交证据源一致」这条启发式去过滤投毒。三个从未写进证书的假设因此悬空：
>
> 1. **回答没有标注者模型**：谁在回答？这个人/源可靠吗、疲惫吗、会不会顺着系统的脸色说？R69 的「k 源一致」对「所有源都被同一个系统行为污染」完全失效——它数的是源的个数，不是源的**独立性**与**能力**。
> 2. **提问对人有成本，而 R69 只把它压成一个粗略的物理/社交标量**：反复追问会让人疲劳、烦躁、不信任，而人的情绪又反过来改变回答质量——这是一个正反馈环，R69 完全没建模。更尖锐的是，系统自己的情绪表达也会污染回答（社会赞许、讨好）。
> 3. **有些问题根本没有唯一正确答案**：情绪标签尤其如此。「笑」是开心还是紧张，可能不是**歧义**，而是两个都合法的**解读**。R69 的二分（aleatoric / epistemic）没有位置放这种「人类标签变异」，只能硬塞进 epistemic，然后徒劳地问到收敛——而它不会收敛，因为分歧来自人，不来自世界。
>
> 本轮两个灵感正好补这三块：
> - **数据标注**告诉我们：回答就是**标注**。标注理论有一整套成熟工具——Dawid–Skene 众包聚合、IRT 标注者能力、金标/注意力探针、主动学习、以及「人类标签变异（human label variation）」。它把 R69 的启发式升级为**校准的概率模型**。
> - **情感计算**告诉我们：情绪不只是要被识别的第 N 个模态，它是**标注通道的元信号**——标注者的效价/唤醒/疲劳/压力预测其标注可靠性与系统性偏置（affect-congruent bias）；同时，提问本身对标注者有**情感成本**，系统自身的情绪表达又会作为混杂因子污染标注。
>
> 核心命题：**把交互重构为「情感感知的人类标注」。不确定性不是二分而是三分——aleatoric（噪声，收紧）、epistemic（关于世界的可约歧义，去问且按标注者可靠性加权）、normative（人类标签变异，不可靠多问消解，必须用 credal set 做风险规避并交给主体偏好裁决）。同时把「问谁」升级为一等决策（标注者选择），把「问多少」升级为情感预算下的最优停止，并用「去卷积的模式证伪」正面攻击 R69 的最大风险（流模型幻觉出不存在的模态）。** 命名 **AURA-RAS**（Affect-aware Uncertainty & Reliability of Annotation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个问题我信不信得过回答，而它究竟有没有唯一答案**」——不确定性不只是刹车踏板（R68）、也不只是提问（R69），还可以是对证人的**可靠性审计**、对分歧的**尊重**、以及对自己**不要操纵对方**的约束。

## 0. 直觉与动机

**灵感 1（数据标注 → 每个回答都是一条标注，不是一次测量）**
直觉：R69 把人的回答当成「测到了一点真相」。但标注理论的第一课就是：标注不是真相，是**在标注者能力、题目难度、标注规范、上下文下的一个有偏样本**。同一个物体，专家标注新手标注会差；同一句「我没事」，不同文化背景的人读出不同情绪。既然如此，正确做法不是「多问几个取多数」，而是建一个**标注者模型**：每个源有混淆矩阵、有能力参数、有随情感漂移的偏置。把「k 源一致」从一个纪律口号，变成这个模型的**后验**。

**灵感 2（数据标注 → 多源一致不是数个数，是去掉相关噪声）**
直觉：众包聚合里最经典的教训是——**一百个相关的坏标注者，不如一个可靠的好标注者**。R69 的「k 个正交源」若实际共用同一个上游（同一个传感器、同一个被系统行为诱导的人），它们就高度相关，一致只是**共模错误**，不是证据。Dawid–Skene 用「条件独立给定真值」拆开这一点：聚合权重应正比于 `log(ρ/(1−ρ))`。这条权重立刻给出一个反直觉但正确的结论：**一个可靠性 ρ<0.5 的源不是无用，是有害**——它会把后验推向反面，所以必须能从证据池里被剔除。

**灵感 3（情感计算 → 标注者的情绪是标注质量的元标签）**
直觉：人不是恒定的标注器。疲惫时草率、焦虑时把模糊表情读成威胁、开心时把中性读成友好（affect-congruent bias）、被反复追问时从配合转为敷衍甚至对抗。情感计算在这里的正确用法不是「识别用户情绪然后安慰他」，而是**把情绪当作标注可靠性的协变量**：`C_j(e)` 而非常数 `C_j`。这既让聚合更准，也让系统知道「此刻这个证人的话要不要打折」。这把 R69 的「回答不可信」从一个二值判断（投毒/没投毒）细化为一个**连续的、可在线估计的可靠性**。

**灵感 4（情感计算 → 提问有情感成本，所以「多问」不是免费的）**
直觉：R69 的交互预算基本是物理/时间成本。但真正的代价常在情感侧：打断、重复、被质疑、被机器盯着看——都会累积疲劳与不信任，并**降低下一次回答的质量**。于是「问」存在一个**非单调收益**：问得越多，单次信息增益因信息饱和而递减，单次可靠性因疲劳而递减，情感成本递增——三者相乘给出一个**有限的最优标注次数**，而不是「问到收敛为止」。这把 R69 的「交互预算」从硬上限升级为**有内生最优停止的调度问题**。

**灵感 5（数据标注 → 第三种不确定性：人类标签变异）**
直觉：情感计算里最著名的坏消息是——情绪标签的标注者间一致性（Cohen's κ / Krippendorff's α）常常低得可怜，而且**不是标注者差，是问题本身多解**。把这种分歧当成「噪声」或「可查清的歧义」都是错的：它既不是传感器的 aleatoric 噪声，也不会因为多问而收敛到一点。它是**规范性的**（normative）——人对同一刺激有合法的不同解读。正确的表示是一个 **credal set（一组可信的标签分布）**，决策时对集合取风险规避（worst-case / CVaR），并把「选哪个解读」交给**主体偏好或场景规范**，而不是交给「多数票」。这是对 R69 二分的真正修补充，也是对 R69「永远可以问到消解」这一乐观假设的证伪。

**灵感 6（双刃剑 → 情感推断本身会变成操纵与筛选）**
直觉：一旦系统会用情绪给证词打折，它就有了一个危险的捷径：不是去理解分歧，而是**把不顺从的标注者判为『情绪不稳、可靠性低』然后静音**；不是去诚实求证，而是**为了得到想要的标注去安抚、施压、卖惨**（情感操纵）。这把 R69 的「问错比不问更危险」升级为「**用情绪筛选真相，比问错更不道德**」。所以本轮必须同时交付：非操纵约束、情感推断的不确定性传播（读不准的情绪不许当作硬折扣）、金标锚定（防止把同温层共谋洗成高可靠）、以及「normative 不确定性不得被冒充成 epistemic 去无限追问」的审计纪律。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（AURA-RAS 总览与三不变式）** AURA-RAS = (ACM, AMC, LVA, APS, GSP, AEB, GMV, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；标注者模型与 credal set 只在离线更新，实时只读）；
(ii) **标注预算硬约束**（继承并扩展 R69 定义 293-ii：单位时间标注 ≤ 1 次、物理位移 ≤ ε_g、**累积情感负荷 ≤ L_max**、单标注者连问 ≤ n_max；所有标注动作同等过 C-RAS-WM 认证）；
(iii) **标注证据纪律**：任何「模态已消解」结论必须来自**可靠性加权的、条件独立且经金标锚定的双源以上**证据；单源、同源、以及「被系统行为诱导的一致」均不得定案；**规范性不确定性不得被当作可问掉的歧义**。

**定义 311（交互即标注）** 一次交互产生一个标注事件 `ℓ = (x, j, y, c, e, t)`：`x ∈ 𝒳` 为被消歧的项（一个假设/查询），`j ∈ 𝒥` 为标注者（人、独立模型或传感器通道，带类型），`y ∈ 𝒴` 为给出的标签，`c` 为上下文/框定，`e ∈ ℰ_aff` 为标注者情感状态，`t` 为时刻。R69 的「回答」是本定义中 `y` 的一个特例；R69 的「k 源一致」是**未加权且假设同质**的退化聚合。

**定义 312（标注者能力模型 ACM）** 每个标注者 `j` 有一个潜在混淆矩阵 `C_j ∈ Δ^{|𝒴|×|𝒴|}`，`C_j[y,y'] = P(y | 真值 y', j)`，先验 `C_j ~ Dir(α)`。层次化能力参数：二值时用 `P(correct | j, x) = σ(θ_j − b_x)`（IRT：`θ_j` 能力、`b_x` 题目难度）；多值时以 `C_j` 的迹为可靠度。聚合按 Dawid–Skene：`P(M | {ℓ}) ∝ P(M) ∏_j C_j[y_j, M]`，用 EM/变分估计 `C_j` 后验。

**定义 313（可靠度与标注校准）** 二元情形的**可靠度** `ρ_j = 2·E[C_j[y,y]] − 1 ∈ [−1,1]`（多值取 `ρ_j = (tr C_j − 1)/(|𝒴|−1)`）。在线估计 `ρ̂_j` 并计算**标注校准误差** `ECE_ann`（预测可靠度 vs 实际正确率）。硬门：仅当 `ρ̂_j` 的置信下界 `> 1/2` 的标注者才可进入证据池——**可靠性低于随机的源不是弱证据，是反向证据**（引理 19）。

**定义 314（情感元标注与同化偏置 AMC）** 标注者情感 `e_j = (v, a, f, s)`（效价、唤醒、疲劳、压力）。混淆矩阵条件化于情感：`C_j(e)`。**情感同化偏置**模型：对某类标签 `y`，`logit P(y | M, e_j) = logit C_j^0[y,M] + β_j^y · φ(e_j)`，其中 `φ(e)` 是情感特征的线性嵌入，`β_j` 是偏置方向（如高唤醒→更易读成威胁）。由此定义：情感-可靠度映射 `ρ_j(e)` 与情感-偏置向量 `b_j(e)`。`β_j` 通过**带情感记录的金标探针**回归（可识别性见引理 20）；读不准的情感**只作为软先验**进入，不进硬折扣（定义 322 的熵惩罚）。

**定义 315（提问的情感成本与总成本）** `c_total(g) = c_phys(g) + c_social(g) + c_affect(e_j, g) + c_attn(g)`。其中 `c_affect` 是**预期情感负荷增量**（疲劳/烦躁/信任下降），由定义 322 的状态动力学给出；`c_attn` 是注意力占用。预算：`Σ_t c_total ≤ C_budget`、`Σ_t 1[标注] ≤ 1/单位时间`、单标注者连续标注 `≤ n_max`。**关键性质**：`c_affect` 是**状态相关**的（已经很累的人，再问一句更贵），这与 R69 的常数社交成本本质不同。

**定义 316（第三类不确定性：人类标签变异 LVA）** 对项 `x`，总体标注分布为 `π ∈ Δ^𝒴`。若 `k` 名条件独立的标注者给出的经验分布收敛到**非退化** `π`（即 `H(π)` 的置信下界 `> ε_π`，或 `π` 的 credible ball 直径有正下界），则该项被判定为 **normative**。定义 **credal set** `𝒫 = {π' : D(π'‖π̂) ≤ κ}`，`U_norm = H(π̂)`（或 `diam(𝒫)`）。与 epistemic 的可操作区分：**`U_epi` 随独立标注者增多 → 0；`U_norm` 保持正下界**（引理 21）。

**定义 317（三分解）** `U_ale`（模态内传感器噪声，继承 R69 定义 297）；`U_epi`（关于世界假设的可约歧义，继承、但聚合改为 ACM 加权）；`U_norm`（人口标签离散度，新增）。三者语义不同、**不做简单加和**，分通道处置（定义 321）。

**定义 318（标注者选择与主动标注 APS）** 一等决策是 `(g, j)` 而非仅 `g`：
`(g,j)* = argmax_{g,j} [ I(M; Y | g, j, e_j) / c_total(g) ]`，s.t. 安全认证（R69 定义 302）、`ρ̂_j` 下界 `> 1/2`、预算未超、且 `j` 的选取不得利用 `e_j` 做歧视（定义 322）。
信息项用 BALD（`H(M|o) − E[H(M|o,y)]`）并以 `ρ_j(e)` 加权。若最优值 `≤ 0`，或 `U_norm` 主导（`U_norm > τ_norm·U_epi`），**不靠继续问**，转定义 321 的 credal 风险规避。

**定义 319（金标探针 GSP）** 周期性插入**已知答案**的探针（attention check / gold standard）以在线估计 `ρ_j(e)` 与 `β_j`。探针答案**只用于校准标注者，不进入任务证据**；探针成本计入预算；探针分布需覆盖情感状态的至少两个水平，否则 `β_j` 不可识别（引理 20）。**金标污染**（标注者认出探针并作弊）由随机化探针内容与离策略抽样防。

**定义 320（可靠性加权证据聚合与纪律）** 后验 `P(M | {ℓ}) ∝ P(M) ∏_j P(y_j | M, C_j(e_j))`。**证据纪律**（把 R69 的 k-一致替换为三条可检验条件）：
(a) **≥2 个条件独立**（用残差相关 `ρ_corr < τ_corr` 检验）且 `ρ̂_j` 下界 `>1/2` 的标注者；
(b) **≥1 个金标锚定**（本窗口内 `ECE_ann ≤ τ_ece`）；
(c) **无共同诱导**（问句框定随机化，检验系统行为与 `y` 的残余关联）。
任一不满足 ⇒ `U_epi` 不消解，走定义 321 的保守通道。

**定义 321（三通道风险缩放）** `λ = max( λ_efs, λ_floor(U_ale + U_epi^{residual}), λ_norm(𝒫) )`。其中
- `U_ale` 走 R68 的 `λ_floor`（噪声不可问掉）；
- `U_epi` 若在预算内被**纪律合格**的标注消解，则从 floor 中扣除（resolution bonus），否则视同 aleatoric；
- `λ_norm(𝒫) = ` 在 credal set 上对任务风险取**最坏情形 / CVaR** 的缩放，`U_norm` **永远不被扣除**（因为多问不消除规范分歧），但其值可由主体偏好 `π_principal` 收敛（定义 316 的 credal set 与主体先验取交）。

**定义 322（情感-标注耦合动力学与最优停止）** 情感状态 `e_{t+1} = F(e_t, load(g_t), feedback_t)`；可靠度 `ρ_j(e)` 随疲劳 `f` 单调递减，随压力 `s` 呈 Yerkes–Dodson 式非单调（适度压力最优）。于是**有效信息增益** `V(n) = Σ_{i=1}^n VoI_i · ρ_j(e_i)` 递减（信息饱和 + 可靠度衰减），**累积成本** `C(n) = Σ c_total` 递增 ⇒ 存在**有限最优标注次数** `n* = argmax_n [V(n) − C(n)]`（引理 22）。同时定义**非操纵约束**：系统对 `e_j` 的作用仅限于「减少负外部性」（如停止打扰），**不得以提高标注顺从度为目标**；`ask` 的框定须随机化且不透露系统期望。

**定义 323（模式证伪 GMV：去卷积）** R69 的最大风险是流模型幻觉出不存在的模态。把「观测到的模态分布」`p_obs` 建模为「真实世界模态」`q` 经**训练标注噪声混淆** `C̄` 的卷积：`p_obs ≈ C̄ q`（`C̄` 从训练标注者群体估计，含其情感偏置）。正则反演得 `q̂`；若模态 `k` 满足 `q̂_k` 的置信上界 `< ε_q`（去卷积后消失）且其质量可由 `C̄` 的偏置方向解释，则判为**标注伪影 / 幻觉模态**，从 MINT 候选中剔除。这把「模态可不可信」从玄学变成**可证伪的去卷积检验**（引理 23）。

**定义 324（威胁模型 ℰ_AURA）** `ℰ_AURA = ℰ_FLUID × ℰ_annot × ℰ_affect`。新增：
- `ℰ_annot`：共谋标注、伪造金标、源相关（伪正交）、系统行为诱导的共同偏置；
- `ℰ_affect`：**情感投毒**（演疲惫骗折扣、演愤怒抬权重）、**情感操纵**（为求好标注而安抚/施压/卖惨）、**讨好偏差**（sycophancy：顺着系统表达的置信说）、**同化伪造**（用情绪把标签推向某侧再伪装成可靠）。
并入 AIC，供对抗训练与审计。

**定义 325（审计器 VQAuditor-A）** 在 R69 VQAuditor-I 之上新增：是否单源/同源定案、是否使用了不可靠标注者、是否**为求标注而操纵情感**、是否把 `U_norm` 冒充 `U_epi` 去无限追问、金标是否被污染、标注者可靠性是否在线漂移、以及情感推断的不确定性是否被当作硬折扣。结论回灌 AuditBuf，成为下一轮 APS 的成本先验。

**定义 326（证书 J_AURA）** `J_AURA = (J_FLUID, annotator_pool_hash, rho_lcb_min, ece_ann, u_norm, credal_width, n_queries, affect_load, manipulation_flag, gmv_removed_modes, aura_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 证据纪律满足（定义 320）∧ manipulation_flag = 0 ∧ 预算与情感负荷未越界 ∧ U_norm 未被冒充`。

**定义 327（严格包含链）** 当只有一个可靠、情感中性、且 `U_norm = 0` 的标注者（或 APS 判定不划算）时，AURA 的决策与 FLUID **逐指令相同**；当 FLUID 的 `VoI ≤ c` 时退化为 R68。故 **R68 ⊆ FLUID ⊆ AURA**：安全侧不做任何让步，新增的只是「对证人可靠性的建模、对规范分歧的尊重、对提问情感成本的内生最优停止」。

**定义 328（实时预算与廉价门控）** 继承 R69 定义 308 的自适应 `K`；新增 ACM/AMC 用轻量头（`C_j(e)`、`ρ_j(e)` 的摊销推断），LVA 的 `U_norm` 用单次分位数估计，GSP 轮转摊销。目标：常规路径总延迟与 R69 持平，仅「需要标注」的少见路径多出可摊销的少量开销。

## 3. 推导

**引理 19（可靠性加权聚合的误差与「不可靠源有害」）** 设 `k` 个标注者条件独立给定真值，可靠度 `ρ_j > 1/2`。等权多数票的错误率满足 `≤ exp(−2k(ρ̄ − 1/2)²)`（Chernoff）。而最优（Bayes）聚合的权重 `w_j = log(ρ_j/(1−ρ_j))`，其二元错误率为 `1 / (1 + exp(Σ_j w_j · sign_j))`（`sign_j=+1` 当标注正确）。**系 1**：若某源 `ρ_j < 1/2`（`w_j < 0`），加入它会**单调升高**错误率——所以「k 源一致」在异质可靠性下会被一个坏源拖垮，必须能剔除。**系 2**：一个高可靠源可以**胜过**很多轻微可靠的源，故 `APS` 的「问谁」与「问什么」同等重要。

**引理 20（情感-可靠性偏置的可识别性边界）** 金标探针在情感状态 `e` 下的正确率观测为 `ρ_j(e) = g(θ_j, e)`，偏置 `β_j` 可辨识的必要条件是探针**覆盖至少两个不同的 `φ(e)` 取值**（设计矩阵满秩）。若探针只在单一情感水平采集，则 `θ_j` 与 `β_j·φ(e)` 只能辨识其**联合折扣**，不能把「能力低」与「情绪偏」分开——此时只能把 `β_j` 的效应并入可靠度下界（保守化），不得单独声称「此人情绪导致偏置」。**系**：情感推断本身有熵 `H(e)` 时，用其**后验期望的可靠度下界**（而非点估计）进入聚合，防止读错情绪被当作硬折扣（定义 314 的软先验）。

**引理 21（人类标签变异不可由多问消解）** 设总体标签分布为 `π`，`n` 个独立标注来自 `π`。用 `π̂_n` 估计 `π` 的经验误差 `E‖π̂_n − π‖² ≤ |𝒴|/(4n)`（随 `n→0`），但**总体熵 `H(π)` 不随 `n` 下降**——多问只让你更**确信分歧存在**，不消除分歧。故任何把 `U_norm` 当作 `U_epi` 去「问到收敛」的策略，其期望残余不确定性有**正下界** `H(π) > 0`。**系**：`U_norm` 必须走 credal 风险规避/主体偏好，不能走「继续问」通道（定义 318、321）。

**引理 22（情感预算下的有限最优标注次数）** 设单次信息增益 `VoI_i` 递减（信息饱和，`VoI_i ↓ 0`），可靠度 `ρ_j(e_i)` 随疲劳递减使有效增益更快衰减，成本 `c_total` 递增。则 `V(n) − C(n)` 为两个凹性相反序列之差，存在有限 `n*`；当 `n → ∞`，`V` 有界而 `C` 无界 ⇒ `n* < ∞`。**系**：R69 的「问到消解为止」在情感成本下会**过度提问**，既降可靠度又累积不信任；AURA 的停止规则把「信息够了」与「人还撑得住」统一为一个目标。

**引理 23（去卷积的模式证伪）** 设 `p_obs = C̄ q + η`，`C̄` 为已知（从训练标注者估计）的混淆矩阵。若 `C̄` 列满秩，则 `q` 可辨识；对幻觉模态 `k`（真实 `q_k = 0`），正则反演给出 `q̂_k` 的置信上界 `O(‖η‖ / σ_min(C̄))`，当该上界 `< ε_q` 时可在给定置信度下**证伪**该模态。**系**：R69 的「流模型幻觉模态」不再是不可证伪的隐忧，而是一个可用训练标注噪声结构做**去卷积检验**的假设；`GMV` 把「模态可信否」转成可测量的证伪问题。

**定理 18（AURA 严格包含 FLUID）** 在 A95–A98（R69）与 A102（标注者条件独立 + 金标覆盖两个情感水平）下，AURA 在任意状态 `s` 的期望风险 `≤` FLUID；且当 `APS` 判定不划算、`U_norm = 0`、且只有一个可靠中性标注者时，两者**逐指令相同**。更一般地，`R68 ⊆ FLUID ⊆ AURA`：每一层都在安全侧非让步的前提下增加效率与可证伪性。**证明要点**：三通道 `λ` 对 aleatoric 与未消解 epistemic 不弱于 FLUID（floor 相同）；`λ_norm` 对 credal set 取最坏，天然 `≥` 任一单点 `λ`；标注可靠性加权在引理 19 下不劣于等权；故风险单调不增，退化条件处取等号。□

**定理 19（无操纵、情感负荷有界、控制连续）** 在定义 322 的非操纵约束与定义 315 的情感预算下：(i) 系统对标注者情感的作用只减少负外部性、不以提升顺从度为目标，`manipulation_flag` 可审计；(ii) 累积情感负荷 `≤ L_max`，单标注者连问 `≤ n_max`；(iii) 标注成功/失败/超时/被投毒时 `λ` 单调不降地退化为 FLUID → R68，提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。□

## 6. 本轮最大风险

**一句话**：AURA-RAS 的全部伦理与科学收益，都押在「我们能可靠地把『标注者不可靠 / 这题有规范分歧』与『这个标注者只是情绪不好 / 这个少数派就是错的』分开」这一前提上——**一旦情感推断本身不可靠（读错情绪、文化误读、被表演欺骗），系统就会用一个不可信的元信号去给别人的证词打折，把『尊重分歧』退化成『按情绪筛选真相』，甚至为了得到想要的标注去安抚、施压、操纵对方的情绪；这不但比 R69 的「问错」更不道德，也更不科学。**

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** AURA-RAS 八组件；零学习写操作继承；标注预算含**累积情感负荷 ≤ L_max / 单标注者连问 ≤ n_max**；证据纪律 = 可靠性加权 + 金标锚定 + 条件独立 + 不得把规范分歧当歧义。

**定义 311–312（交互即标注、ACM）** 回答 = 标注事件 `ℓ`；`P(M|{ℓ}) ∝ P(M)∏_j C_j[y_j,M]`；IRT `P(correct)=σ(θ_j−b_x)`；EM/变分估 `C_j`。

**定义 313–314（可靠度、情感元标注）** `ρ_j` 与 `ECE_ann`，硬门 `ρ̂_j` 下界 `>1/2`；`C_j(e)`、`logit P(y|M,e)=logit C_j^0+β_j·φ(e)`；读不准情绪只作软先验。

**定义 315–317（成本、LVA、三分）** `c_total` 状态相关；`U_norm=H(π̂)` 且收敛到非退化即 normative；`U_epi→0` 随标注者增多，`U_norm` 有正下界；三分不做简单加和。

**定义 318–320（APS、GSP、聚合纪律）** `(g,j)*` 按 BALD×可靠度/成本；金标探针只校准不决策；聚合纪律 = ≥2 条件独立且 `ρ>1/2` + ≥1 金标 + 无共同诱导。

**定义 321–322（三通道缩放、耦合动力学）** `λ=max(λ_efs, λ_floor(U_ale+U_epi^res), λ_norm(𝒫))`，`U_norm` 永不扣除；`e_{t+1}=F(e_t,load,feedback)`，`ρ_j(e)` 随疲劳递减 ⇒ 有限 `n*`；**非操纵约束**。

**定义 323–326（GMV、威胁、审计、证书）** `p_obs≈C̄q` 去卷积，`q̂_k` 上界 `<ε_q` ⇒ 幻觉模态；`ℰ_AURA=ℰ_FLUID×ℰ_annot×ℰ_affect`；VQAuditor-A 审操纵/单源/冒充；`J_AURA` 并入可靠性下界、`U_norm`、credal 宽度、情感负荷、操纵标志。

**定义 327–328（严格包含、实时预算）** `R68 ⊆ FLUID ⊆ AURA`；退化条件逐指令相同；自适应 `K` + 轻量 ACM/AMC 头，常规路径与 R69 同阶。

# IP-264/265 ACM+AMC：标注者能力 × 情感元校准（离线更新、实时只读）
class AnnotatorCompetenceModel:
    def update_offline(self, events):                  # 只离线
        self.C, self.theta = dawid_skene_em(events, self.C, self.theta)
    def confusion(self, j, e):
        return self.C[j] if e is None else self.C[j].condition(e)   # C_j(e)

def affect_meta(j, e, gold_log):
    rho  = reliability_curve(j, e)                     # ρ_j(e)，随疲劳递减
    beta = fit_congruent_bias(gold_log[j], e)          # 需覆盖两个情感水平（引理20）
    return rho, beta, affect_uncertainty(e)            # 读不准→软先验

# IP-266 LVA：三分不确定性
def decompose_three(samples, events, z, acm, amc):
    U_ale, U_epi = decompose_r69(samples, z)
    pi_hat, credal = aggregate_population(events, acm, amc)
    U_norm = entropy(pi_hat) if converged_non_degenerate(events) else 0.0
    return U_ale, U_epi, U_norm, pi_hat, credal

# IP-267 APS：问谁 + 问什么；规范主导/不划算则不问
def choose_annotation(modes, o, annotators, acm, amc, budget):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        for j in annotators:
            e = budget.affect_state(j)
            if acm.reliability(j, e) <= 0.5: continue            # 坏源剔除
            gain = bald_weighted(modes, g, acm.reliability(j, e)) / cost_total(g, j, e)
            if best is None or gain > best.gain: best = (g, j, gain)
    if best is None or best.gain <= 0: return None               # 不划算
    if U_norm > TAU_NORM * U_epi: return None                     # 规范分歧不靠问
    return best

# IP-270 GMV：去卷积证伪幻觉模态（正面回应 R69 最大风险）
def validate_modes(p_obs, C_train):
    q_hat = regularized_deconvolution(p_obs, C_train)             # p_obs ≈ C_train q
    keep    = [k for k in q_hat if ci_upper(q_hat[k]) >= EPS_Q]   # 去卷积后仍在
    removed = [k for k in q_hat if k not in keep]                 # 判为伪影/幻觉
    return keep, removed

# IP-271 主闭环（继承 R69/FLUID，仅替换不确定性处置）
def AURA_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, U_norm, pi_hat, credal = M.lva.decompose(
        samples, M.label_buf, z, M.acm, M.amc)
    keep, removed = M.gmv.validate_modes(mode_dist(samples), M.acm.train_confusion())
    samples = [s for k, s in enumerate(samples) if k in keep]
    target = M.aps.choose_annotation(samples, o, M.annotators, M.acm, M.amc, M.budget)
    U_epi_after = U_epi
    if target is not None:
        g, j = target
        y = M.cia.execute(g, j)                              # 认证 + 随机化框定
        U_epi_after = M.cia.aggregate(
            samples, y, M.acm.confusion(j, M.budget.affect_state(j)))
        M.gsp.maybe_gold_probe(M.budget, M.acm, M.amc)
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (U_epi_after if target is None else 0.0)),
              lam_norm(credal, M.principal_pref))             # U_norm 永不扣除
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    mode = select_mode(samples, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_a.submit_async(target, U_epi, U_norm, removed, M.budget.affect_load())
    return k, lam, mode, (U_ale, U_epi_after, U_norm)

## 4. 推导

**引理 19（可靠性加权聚合与「不可靠源有害」）** 条件独立、`ρ_j>1/2` 时，等权多数票错误率 `≤ exp(−2k(ρ̄−1/2)²)`；最优权重 `w_j=log(ρ_j/(1−ρ_j))`，二元错误率 `1/(1+e^{Σ_j w_j·sign_j})`。**系**：`ρ_j<1/2` 的源会使错误率**单调升高**（`w_j<0`），必须剔除；一个高可靠源可胜过许多轻可靠源 ⇒「问谁」与「问什么」同等重要。

**引理 20（情感-可靠性可识别性）** 金标探针须覆盖至少两个 `φ(e)` 取值（设计矩阵满秩）才能分开 `θ_j` 与 `β_j`；否则只能辨识联合折扣，`β_j` 效应并入可靠度下界（保守化）。情感推断熵 `H(e)` 高时用可靠度**后验下界**进入聚合，防止读错情绪被当作硬折扣。

**引理 21（标签变异不可由多问消解）** `E‖π̂_n−π‖² ≤ |𝒴|/(4n)` 随 `n` 趋 0，但 `H(π)` 不随 `n` 下降。故把 `U_norm` 当 `U_epi` 去追问，期望残余不确定性有正下界 `H(π)>0` ⇒ 必须走 credal 风险规避/主体偏好。

**引理 22（情感预算下有限最优停止）** `VoI` 递减、`ρ_j(e)` 随疲劳递减使有效增益加速饱和、`c_total` 递增 ⇒ `V(n)−C(n)` 存在有限 `n*`；`n→∞` 时 `V` 有界而 `C` 无界。**系**：R69 的「问到消解为止」在情感成本下会过度提问。

**引理 23（去卷积模式证伪）** `p_obs=C̄q+η`，`C̄` 列满秩则 `q` 可辨识；幻觉模态 `k`（`q_k=0`）有 `q̂_k` 上界 `O(‖η‖/σ_min(C̄))`，低于 `ε_q` 即可证伪。**系**：R69 的「幻觉模态」从不可证伪隐忧变为可测量的去卷积检验。

**定理 18（AURA 严格包含 FLUID）** 在 A95–A98、A102（标注者条件独立 + 金标覆盖两情感水平）下，AURA 期望风险 `≤` FLUID；`APS` 不划算、`U_norm=0`、单一可靠中性标注者时逐指令相同。故 **R68 ⊆ FLUID ⊆ AURA**：安全不弱于 FLUID（floor 相同），`λ_norm` 对 credal set 取最坏天然 `≥` 任一点估计，可靠性加权在引理 19 下不劣于等权。

**定理 19（无操纵、情感负荷有界、控制连续）** 非操纵约束 + 情感预算 ⇒ (i) 系统不以提升顺从度为目标、`manipulation_flag` 可审计；(ii) 累积负荷 `≤L_max`、连问 `≤n_max`；(iii) 标注失败/超时/投毒时 `λ` 单调不降地退化为 FLUID→R68，换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：AURA-RAS 的全部伦理与科学收益都押在「我们能可靠地把『标注者不可靠 / 这题有规范分歧』与『这个标注者只是情绪不好 / 这个少数派就是错的』分开」这一前提上——**一旦情感推断本身不可靠（读错情绪、文化误读、被表演欺骗），系统就会用一个不可信的元信号给别人的证词打折，把『尊重分歧』退化成『按情绪筛选真相』，甚至为得到想要的标注去安抚、施压、操纵对方情绪；这不但比 R69 的「问错」更不道德，也更不科学。**

**次级风险与缓解**：情感操纵/讨好偏差（定义 322 非操纵约束 + VQAuditor-A + E311）；情感投毒与共谋标注（`ℰ_affect`/`ℰ_annot` 对抗训练 + 可靠性加权 + E312）；情感推断误差被当硬折扣（引理 20 软先验 + 后验下界）；`U_norm` 被冒充成 `U_epi` 去无限追问（定义 318/327 纪律 + E306）；金标污染（GSP 随机化 + 离策略抽样）；实时预算被新头击穿（离线 ACM、轻量 AMC、摊销 GSP，E314）。
