# 第 57 轮（承接第 56 轮 v32 GroundEdge-GenSim++++；灵感循环第 2 轮；本轮灵感：「协同控制」×「力矩控制」）

> 第 56 轮把证书链补到“动作对齐 → 接触可信 → 场景被覆盖、姿态坐标可信”。但整条链的最后一公里仍是空白：所有证书都停在**运动学 / 接触 / 场景**层，从未回答“这些接触所需的力矩，能否被执行器在饱和、热降额、时延约束下真正产生”；也从未回答“当多个肢体或多台机器人共同承担一个接触任务时，彼此的力矩如何协同”。本轮用「协同控制」×「力矩控制」补这一层。核心矛盾：**H26（力矩不可实现性）**：语义上可信、运动学上可行、姿态上确定的接触，仍可能因关节力矩饱和、热降额、摩擦锥在力矩坐标下不可达而不可实现；**H27（协同内力陷阱）**：多体协同中，局部各自安全的力矩分配会在耦合对象上产生内力对抗，内力不改变物体运动却吞噬执行器裕度，并使分布式护盾在“看起来收敛”时把系统推入滑移。

## 0. 直觉与动机

**灵感 1（协同控制 → 接触是力分配，不是姿态匹配）**
直觉：多肢体/多机器人共同搬运时，真正决定成败的不是各自把末端摆到哪里，而是**接触力怎样在参与者之间分配**。同样的接触几何可以对应无穷多组 `λ`，它们对物体的净作用相同，却对每个关节的力矩负担完全不同。协同控制的核心变量因此不是轨迹，而是**力分配的等价类**。

**灵感 2（力矩控制 → 可行性必须落到执行器包络）**
直觉：前几轮的 `C⁺(Σ,Ξ_α)` 只检查了摩擦锥与运动学，相当于假设“只要接触几何成立，力总能被产生”。力矩控制提醒我们：`τ = A(x)λ + b(x,u)`，接触力经雅可比映射回关节后必须落在 `T(x)`（力矩上下限、速度相关降额、热预算）内。于是“接触可行”应升级为 **力矩可实现接触集** `C⁺_τ`。

**灵感 3（两者耦合 → 内力的“力矩价格”）**
直觉：接触力可分解为外力 `w_ext = Gλ` 与内力 `λ_int = (I-G⁺G)λ`。内力对物体运动零贡献，却真实地流过每个关节。协同分配若只顾满足外力，就会把大量内力“烧”在关节上。必须定义**内力的力矩价格** `price(λ_int)`，并把“内力预算”与“价格预算”同时写进可采纳集。

**灵感 4（协同控制 → 分布式护盾要用邻居包络 + 收缩证书兜底）**
直觉：分布式力矩护盾各自求解局部 QP，但局部可行不等于耦合可行。正确做法是：用协同协议的**收缩率**给出邻居力/力矩的界 `ℬ(λ̂_{-i},Δ_{-i})`，让每个局部 QP 对邻居的最坏实现保持鲁棒可行；再用**被动性余量**（能量罐不低于阈值）保证通信丢包/时延时耦合系统仍不耗散失控。

**灵感 5（力矩控制 → 饱和/时延/热降额是证书维度，不是工程细节）**
直觉：力矩层最危险的失效是“证书说可行、执行器在下一拍饱和”。因此要把力矩扰动、执行器退化、控制时延纳入鲁棒性谱 `ρ_τ`，并把实测力矩/滑移日志作为证书证据。感知的“高置信”与运动学的“可行”都不能替代执行器的“已产生”。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（执行器力矩包络与力矩可实现接触集）**
关节力矩可行集 `T(x) = {τ | τ_min ≤ τ ≤ τ_max, |τ| ≤ τ_derate(v,T_j), (1/Δt)Σ_k τ_k² R ≤ P_thermal}`。给定期望状态轨迹，接触力经动力学映射
`τ = A(x)λ + b(x,u_des)`，其中 `A(x) = -(S^T)^+ J_c^T`、`b(x,u_des)=(S^T)^+(M q̈_des + h(q,q̇))`。
力矩可实现接触集 `C_τ(x) = {λ | λ∈FC(μ) ∧ A(x)λ+b(x,u_des)∈T(x)}`，保守版本 `C⁺_τ = C⁺(Σ,Ξ_α) ∩ C_τ`。
力矩裕度 `m_τ = min_{λ∈C⁺_τ} dist(τ(λ), ∂T(x))`，要求 `m_τ ≥ θ_τ`。

**定义 134（协同力分解与内力价格的力矩度量）**
接触矩阵 `G(x) ∈ R^{6×6m}`，外力 `w_ext = Gλ`，内力 `λ_int = (I - G⁺G)λ`，满足 `Gλ_int = 0`。内力对物体运动零贡献，但对关节力矩有非零投影。内力价格
`price(λ_int) = max_i ||A_i(x)λ_int||_∞ / τ_i^max`，
协同可采纳集
`Λ_co(x) = {λ∈C⁺_τ | ||λ_int||_W ≤ β_int ∧ price(λ_int) ≤ β_τ}`。
直觉：`β_int` 限制“力对抗的绝对量”，`β_τ` 限制“对抗在关节上的折算负担”，两者缺一不可。

**定义 135（协同收缩与被动性余量）**
协同图 `𝒢_c=(V,E_c)`、拉普拉斯 `L`，局部力/力矩一致性协议
`λ_i^+ = λ_i + κ Σ_{j∈N_i} a_ij(λ_j-λ_i)`，名义收缩率 `γ_c = ρ(I-κL)`。
在通信时延 `τ_d`、丢包率 `p_loss` 下，采用经验证的上界
`γ_c(τ_d,p_loss) ≤ γ_c(1+ατ_d) + βp_loss`。
每个智能体设能量罐 `E_i(t)=E_i(0)-∫P_i dt`，耦合功率 `P_i=Σ_j λ_i^T(v_i-v_j)`，被动性余量 `m_p = min_{i,t}(E_i(t)-θ_p)`。协同裕度
`m_c = min(1-γ_c(τ_d,p_loss)^H, m_p, ε_c-Δ_λ)`，
其中 `Δ_λ` 为由收缩率导出的 `H` 步分歧上界。证书要求 `m_c > 0`。

**定义 136（分布式力矩护盾）**
给定名义力矩 `τ_i^nom`，各智能体求解
`τ_i* = argmin_{τ_i} ||τ_i-τ_i^nom||²_{W_i}`
s.t. `τ_i∈T_i(x)`、`λ∈Λ_co(x)`、`x_{t+1}∈K_rob(Σ; ℬ(λ̂_{-i},Δ_{-i}))`、`λ_i=φ_i(τ_i)` 与一致性约束。
若不可行，回退到**协同制动**：先解 `λ_int→0` 的 QP，再执行安全制动。原因是带着内力的制动会让接触面在减速过程中滑移。

**定义 137（力矩鲁棒性谱）**
`ρ_τ(ε_τ;τ_d) = inf_{||δτ||≤ε_τ, τ_d'≤τ_d, T'∈𝒟_derate} P(viable(x) | τ+δτ, T')`，
`𝒟_derate` 为执行器退化集（饱和、降额、摩擦/热参数漂移）。它作为 v32 鲁棒性谱 `ρ` 的新增维度，与 `ρ_sem`、姿态/场景维度共用证书框架。

**定义 138（力矩-协同联合证书）**
`J_τ = (C⁺_τ, Λ_co, β_int, price_max, γ_c(τ_d,p_loss), m_p, ρ_τ, H, evidence)`：
- `C⁺_τ` 力矩可实现保守接触集，附带 `m_τ`；
- `Λ_co` 协同可采纳力分配集，`λ_int^max`、`price_max` 为其实测上界；
- `γ_c`、`m_p` 协同收缩与被动性余量；
- `ρ_τ` 力矩鲁棒性谱，`evidence` 含实测力矩、滑移、时延与降额日志。
若 `C⁺_τ ≠ ∅`、`m_τ ≥ θ_τ`、`price_max ≤ β_τ`、`||λ_int||_W ≤ β_int`、`m_c > 0`、`ρ_τ(ε_τ) ≥ ρ_min`、热裕度 `≥ θ_E` 且 `τ_d ≤ τ_c`，则力矩-协同可部署。

## 2. 关键算法 伪代码

### IP-133 TAE（Torque Actuation Envelope）

```python
def torque_realizable_contacts(C_plus, x, u_des, T_env, thermal, mu):
    C_tau, margins = set(), {}
    for (p, c) in C_plus:
        lam, ok = qp_feasible(
            constraints=[
                friction_cone(lam, mu, p),
                torque_map(x, u_des, lam) in T_env,      # A(x)lam + b(x,u) in T
                thermal.power(lam) <= P_thermal,
            ],
        )
        if ok:
            C_tau.add((p, c))
            margins[(p, c)] = torque_margin(x, u_des, lam, T_env)
    return C_tau, margins
```

### IP-134 TFD（Torque Force Decomposition）

```python
def coordinated_wrench_allocation(x, G, w_ext_des, mu, beta_int, beta_tau):
    lam = qp_solve(
        minimize=norm(internal(G, lam))**2_W,
        constraints=[G @ lam == w_ext_des,
                     friction_cone(lam, mu),
                     torque_map(x, lam) in T(x)],
    )
    if lam is None:
        return ('reject', 'no_torque_realizable_allocation')
    lam_int = internal(G, lam)                          # (I - G^+ G) lam
    price = max_torque_price(x, lam_int)
    if norm(lam_int) > beta_int or price > beta_tau:
        return ('reject', 'internal_force_budget', norm(lam_int), price)
    return ('ok', lam, lam_int, price)
```

### IP-135 CCC（Coordination Contraction Certificate）

```python
def coordination_contraction_cert(graph, kappa, delay, p_loss, horizon, eps_c, tanks):
    L = laplacian(graph)
    gamma = spectral_radius(np.eye(len(graph)) - kappa * L)
    gamma_eff = gamma * (1 + alpha * delay) + beta * p_loss
    bound = disagreement_bound(gamma_eff, horizon, initial_disagreement)
    m_p = min(tank.level - theta_p for tank in tanks)
    m_c = min(1 - gamma_eff**horizon, m_p, eps_c - bound)
    if gamma_eff >= 1 or m_c <= 0:
        return ('reject', 'no_coordination_margin', gamma_eff, bound, m_p)
    return ('ok', ContractionCert(gamma_eff, bound, m_p, m_c, horizon))
```

### IP-136 DTS（Distributed Torque Shield）

```python
def distributed_torque_shield(agent, neigh_hat, Delta_neg, Lambda_co, K_rob, W):
    tau = qp_solve(
        H=W, g=-W @ agent.tau_nom,
        constraints=[
            robust_viability(agent.x, agent.u, K_rob, neigh_hat, Delta_neg),
            contact_wrench_in(Lambda_co),
            actuator_envelope(agent.T, agent.thermal),
            consensus(agent, neigh_hat, Delta_neg),
        ],
    )
    if tau is None or projection_gap(tau, agent.tau_nom) > Delta_tau:
        return coordinated_brake(agent), 'shield_infeasible'   # lam_int -> 0 then brake
    return tau, 'ok'
```

### IP-137 TRS（Torque Robustness Spectrum）

```python
def torque_robustness_spectrum(ctrl, x0, eps_tau, delays, derates, sampler):
    worst = 1.0
    for dt in delays:
        for Tp in derates:
            for dtau in sampler.ball(eps_tau, worst_case=True):
                p = empirical_viability(ctrl.with_actuator(Tp), x0, dtau, dt)
                worst = min(worst, p)
    return worst
```

### IP-138 TCC（Torque-Coordination Certificate）

```python
def torque_coordination_certificate(traj, C_tau, m_tau, alloc, contraction,
                                    rho_tau, budgets):
    if not C_tau:
        return ('reject', 'no_torque_realizable_contact')
    if min(m_tau.values()) < budgets.theta_tau:
        return ('reject', 'torque_margin_fail')
    if alloc.price > budgets.beta_tau or norm(alloc.lam_int) > budgets.beta_int:
        return ('reject', 'internal_force_budget', alloc.price)
    if contraction.m_c <= 0:
        return ('reject', 'no_coordination_margin', contraction)
    if rho_tau(budgets.eps_tau) < budgets.rho_min:
        return ('reject', 'torque_robustness_fail')
    if budgets.delay > budgets.tau_c or thermal_margin(traj) < budgets.theta_E:
        return ('reject', 'actuator_budget_exceeded')
    return ('ok', TorqueCoordCert(C_tau, alloc, contraction, rho_tau,
                                  budgets.eps_tau, budgets.delay))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TAE | O(\|C⁺\|·QP) | O(\|C⁺\|) | 力矩包络辨识、热模型 sound |
| TFD | O(m³ + QP) | O(m²) | 内力分解精确、价格保守 |
| CCC | O(\|V\|³ + H) | O(\|V\|²) | 时延/丢包上界经验证、能量罐声测 |
| DTS | O(QP + \|N_i\|)/智能体/步 | O(\|A\|) | 邻居包络覆盖、耦合约束 sound |
| TRS | O(N_τ·N_delay·N_derate·\|X\|) | O(\|X\|) | 扰动/退化集合覆盖、最坏可复现 |
| TCC | O(\|轨迹\|·(\|C\|+QP) + \|V\|³) | O(\|C\|+\|V\|²) | 预算闭合、核心接触非空 |

**正确性定理（Torque-Coordination Soundness）**
假设 v32 的 (A26)–(A41) 成立；追加 **(A42)** 力矩包络 `T(x)` 经辨识与在线校准，`C⁺_τ` 对外部扰动 sound；**(A43)** 内力分解精确且 `price` 为上界；**(A44)** 收缩上界 `γ_c(τ_d,p_loss)` 在实测时延/丢包下成立，能量罐由力矩/功率传感声测；**(A45)** 力矩传感与执行延迟 `≤ τ_c`，且 `ρ_τ` 覆盖饱和、降额与力矩扰动。则部署后单步安全概率：
```
P_safe ≥ 1 - P(τ ∉ T) - P(||λ_int||_W > β_int) - P(price > β_τ)
           - P(m_c ≤ 0) - P(ρ_τ < ρ_min) - P(τ_d > τ_c)
           - [v31 动作 + SCT 语义 + SPACE 场景/姿态 证书项]
```
关键：**运动学可行不等于力矩可实现，力矩可实现不等于协同可采纳，协同局部可采纳不等于耦合可行**；三层任一层失守都只允许降级到协同制动，绝不允许把“局部 QP 可行”当作“耦合力分配已成立”。

## 6. 本轮最大风险

**一句话**：把证书链从“运动学/接触/场景”下沉到“力矩-协同”层后，整条链的最薄弱处变成**对执行器包络与协同收缩上界的双重信任**——一旦摩擦/热参数辨识偏乐观、或收缩上界在异常时延与丢包下失效，每个智能体的局部护盾都会“各自可行”，而耦合对象上的内力对抗已把关节推向饱和与滑移；因此必须以 **在线力矩包络辨识 + 内力价格实测 + 时延/丢包鲁棒收缩 + 被动性能量罐 + 协同制动兜底** 五重护栏，宁可协同降级，也绝不把“局部 QP 可行”当作“耦合力分配已实现”。

| `Λ_co` | 协同可采纳力分配集（内力 + 价格预算） |
| `β_int` / `β_τ` | 内力预算 / 力矩价格预算 |
| `𝒢_c=(V,E_c)` / `γ_c` | 协同图 / 名义收缩率 `ρ(I-κL)` |
| `γ_c(τ_d,p_loss)` | 时延与丢包下的收缩上界 |
| `E_i` / `m_p` | 能量罐 / 被动性余量 |
| `m_c` | 协同裕度 `min(1-γ_c^H, m_p, ε_c-Δ_λ)` |
| `K_rob` | 邻居包络下的鲁棒生存核 |
| `ρ_τ(ε_τ;τ_d)` | 力矩鲁棒性谱 |
| `J_τ` | 力矩-协同联合证书 |

## 2. 关键算法 伪代码

### 2.1 力矩可实现层（IP-133~134）

```python
# IP-133 TAE：把 C+ 投影到力矩包络
def torque_realizable_contacts(C_plus, x, u_des, T_env, thermal, mu):
    C_tau, margins = set(), {}
    for (p, c) in C_plus:
        lam, ok = qp_feasible(
            constraints=[
                friction_cone(lam, mu, p),
                torque_map(x, u_des, lam) in T_env,      # A(x)lam + b(x,u) in T
                thermal.power(lam) <= P_thermal,
            ],
        )
        if ok:
            C_tau.add((p, c))
            margins[(p, c)] = torque_margin(x, u_des, lam, T_env)
    return C_tau, margins

# IP-134 TFD：内力价格 + 协同分配
def coordinated_wrench_allocation(x, G, w_ext_des, mu, beta_int, beta_tau):
    lam = qp_solve(
        minimize=norm(internal(G, lam))**2_W,
        constraints=[G @ lam == w_ext_des,
                     friction_cone(lam, mu),
                     torque_map(x, lam) in T(x)],
    )
    if lam is None:
        return ('reject', 'no_torque_realizable_allocation')
    lam_int = internal(G, lam)                          # (I - G^+ G) lam
    price = max_torque_price(x, lam_int)
    if norm(lam_int) > beta_int or price > beta_tau:
        return ('reject', 'internal_force_budget', norm(lam_int), price)
    return ('ok', lam, lam_int, price)
```

### 2.2 协同可信层（IP-135~136）

```python
# IP-135 CCC：收缩 + 被动性证书
def coordination_contraction_cert(graph, kappa, delay, p_loss, horizon, eps_c, tanks):
    L = laplacian(graph)
    gamma = spectral_radius(np.eye(len(graph)) - kappa * L)
    gamma_eff = gamma * (1 + alpha * delay) + beta * p_loss
    bound = disagreement_bound(gamma_eff, horizon, initial_disagreement)
    m_p = min(tank.level - theta_p for tank in tanks)
    m_c = min(1 - gamma_eff**horizon, m_p, eps_c - bound)
    if gamma_eff >= 1 or m_c <= 0:
        return ('reject', 'no_coordination_margin', gamma_eff, bound, m_p)
    return ('ok', ContractionCert(gamma_eff, bound, m_p, m_c, horizon))

# IP-136 DTS：分布式鲁棒力矩护盾
def distributed_torque_shield(agent, neigh_hat, Delta_neg, Lambda_co, K_rob, W):
    tau = qp_solve(
        H=W, g=-W @ agent.tau_nom,
        constraints=[
            robust_viability(agent.x, agent.u, K_rob, neigh_hat, Delta_neg),
            contact_wrench_in(Lambda_co),
            actuator_envelope(agent.T, agent.thermal),
            consensus(agent, neigh_hat, Delta_neg),
        ],
    )
    if tau is None or projection_gap(tau, agent.tau_nom) > Delta_tau:
        return coordinated_brake(agent), 'shield_infeasible'   # lam_int -> 0 then brake
    return tau, 'ok'
```

### 2.3 鲁棒与证书层（IP-137~138）

```python
# IP-137 TRS：力矩/时延/退化最坏谱
def torque_robustness_spectrum(ctrl, x0, eps_tau, delays, derates, sampler):
    worst = 1.0
    for dt in delays:
        for Tp in derates:
            for dtau in sampler.ball(eps_tau, worst_case=True):
                p = empirical_viability(ctrl.with_actuator(Tp), x0, dtau, dt)
                worst = min(worst, p)
    return worst

# IP-138 TCC：力矩-协同联合证书
def torque_coordination_certificate(traj, C_tau, m_tau, alloc, contraction,
                                    rho_tau, budgets):
    if not C_tau:
        return ('reject', 'no_torque_realizable_contact')
    if min(m_tau.values()) < budgets.theta_tau:
        return ('reject', 'torque_margin_fail')
    if alloc.price > budgets.beta_tau or norm(alloc.lam_int) > budgets.beta_int:
        return ('reject', 'internal_force_budget', alloc.price)
    if contraction.m_c <= 0:
        return ('reject', 'no_coordination_margin', contraction)
    if rho_tau(budgets.eps_tau) < budgets.rho_min:
        return ('reject', 'torque_robustness_fail')
    if budgets.delay > budgets.tau_c or thermal_margin(traj) < budgets.theta_E:
        return ('reject', 'actuator_budget_exceeded')
    return ('ok', TorqueCoordCert(C_tau, alloc, contraction, rho_tau,
                                  budgets.eps_tau, budgets.delay))
```

| TCC | O(\|轨迹\|·(\|C\|+QP)+\|V\|³) | O(\|C\|+\|V\|²) | 预算闭合、核心接触非空 |

**正确性定理（GroundEdge v33 全链证据 Soundness）**
假设 v31 (A26)–(A28)、SCT (A29)–(A32)、SPACE (A38)–(A41) 成立；追加 **(A42)** 力矩包络经辨识与在线校准、`C⁺_τ` sound；**(A43)** 内力分解精确、`price` 为上界；**(A44)** `γ_c(τ_d,p_loss)` 在实测时延/丢包下成立、能量罐声测；**(A45)** 力矩传感/执行延迟 `≤ τ_c`、`ρ_τ` 覆盖饱和/降额/扰动。则端到端部署成功概率：
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(δ_a > Θ_a)                    # v31 动作-协同
            − P(‖Σ−Σ̂‖∞ > ε_s) − P(κ miscalibrated) − P(K_out\K_in ≠ ∅)   # SCT 语义-接触
            − P(ξ ∉ Ξ_α) − P(δ_pose > Θ_p) − P(d_R > Θ_r)                 # SPACE 姿态
            − (1 − Cov_LCB) − P(σ ∉ A)                                     # SPACE 场景覆盖
            − P(τ ∉ T) − P(‖λ_int‖_W > β_int) − P(price > β_τ)             # TC² 力矩可实现
            − P(m_c ≤ 0) − P(ρ_τ < ρ_min) − P(τ_d > τ_c)                   # TC² 协同可信
```
关键：**动作对齐 → 接触可信 → 场景覆盖 → 力矩可实现 → 协同可采纳**，任一环失守都只允许降级/制动，不允许用“局部 QP 可行”替代“耦合力分配已实现”。

## 5. 本轮最大风险

**一句话**：TC² 把“局部护盾可行”升级为“力矩可实现 + 协同可采纳”，但它的 soundness 同时压在**执行器包络的在线辨识**与**协同收缩上界在异常时延/丢包下仍然成立**这两块最容易被工程近似悄悄侵蚀的地基上；一旦摩擦/热参数辨识偏乐观或收缩上界失效，各智能体会在“各自可行”的局部 QP 里放行内力对抗，让耦合对象在“协同看起来收敛”的表象下滑移、饱和甚至失稳——故必须以 **在线力矩包络辨识 + 内力价格实测 + 时延/丢包鲁棒收缩 + 被动性能量罐 + 协同制动兜底** 五重护栏，宁可协同降级，也绝不把“局部可行”当作“耦合已实现”。
