# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「安全性」×「基线复现」）

> 第 54 轮把技能组合建立在动作占用剖面 α_S、动作兼容图 G_S、云边映射 γ_ce 与联合证书 J 之上，并用 Explain 反向驱动重剖分。但它默认了两件从未被检验的事：**（i）证书证明的是“能完成任务”，不是“完成得安全”；（ii）所有安全数字都相对某个基线，而基线从未被要求可复现**。本轮把“安全性”从证书旁注提升为与任务成功正交的第二通道，把“基线复现”从实验卫生提升为安全声明的**证据前提**。核心矛盾：**H24**：ρ 谱只度量成功退化，对“成功但不安全”（unsafe success）完全盲视——一个组合可以 success=1 且 collision=1；**H25**：若基线与本方法共享同一仿真器/场景生成器，基线复现会顺利通过而安全结论系统性错误，这是**共模失效**，不是安全。

## 0. 直觉与动机

**灵感 1（安全性是独立的反证义务，不是成功率的一维）**
直觉：`J` 的 `ρ` 回答“技能退化时还行不行”，不回答“行的时候会不会伤人”。安全应与任务成功正交：真正的危险格是 **unsafe success**——走捷径穿过人的工作区、夹持力超限但仍完成任务。因此必须把安全裕度 `m_safe` 提为一等输出，任务与安全双通道分别判定，任一失败都不得部署。

**灵感 2（安全阈值都是相对基线而言的）**
直觉：说“碰撞率降到 0.3%”没有意义，除非同时给出“基线多少、基线如何复现”。安全结论本质是**配对差值 + 置信区间**，不是绝对自评。基线不可复现时，改进可能只是种子噪声。于是把 `B_cert`（基线复现证书）设为安全声明的硬前提：没有它，任何安全结论降级为 `inconclusive`。

**灵感 3（复现粒度应是分布而非轨迹）**
直觉：机器人系统天然随机（感知、接触、时序）。要求逐位复现会诱导对单一 seed 过拟合，制造“复现出来的假安全”。正确目标是**分布级复现**：在分层种子/场景集合上，归档基线与重放基线的结果分布距离 `d_rep ≤ ε_rep`。复现是统计意义的可重放，既不放过真实回归，也不把自然抖动当失败。

**灵感 4（安全案例必须三值：unknown 阻断部署）**
直觉：沿用第 54 轮“未知不得当作可行”。安全案例 `SC` 的叶子证据若复现失败或覆盖不足，整棵树只能判 `inconclusive`，不能判 `pass`。二值逻辑会逼人在证据缺失时“二选一”，三值逻辑把缺失显式变成部署闸门。**只有全部叶子 pass 且 B_cert 均为 reproduced，才允许放行**。

**灵感 5（共模失效：安全与复现共享同一仿真器会一起说谎）**
直觉：若基线与本方法都在同一仿真器、同一场景生成器里评估，仿真器偏差会同时抬高两者，复现证书也顺利通过。这不是安全，是**共模失效**。需要跨仿真器/跨场景族的共模校验：安全集合取**交集**（保守），并显式报告两仿真器不一致区域 `D_xsv`。

**灵感 6（安全回归绊线：技能库演进不能静默降低安全）**
直觉：昨天的安全不等于今天的安全。每次技能库更新都要与**归档基线证书**比较 unsafe success 增量 `ΔU`；若其置信上界超过预算 `δ_safe`，回滚。用归档基线而不是现算基线，避免“移动靶”。

**灵感 7（证据金字塔：证书第一次要证明自己是怎么被证明的）**
直觉：第 53 轮有鲁棒性金字塔，第 54 轮有动作协同层；本轮加**证据层**。每层证书除 `ρ`、`A_cert` 外还必须携带 `B_cert` 与 `SC` 判定，形成“能力-动作-鲁棒-证据”四元证书。安全性因此成为跨层可追溯的证据链，而不是末端贴的标签。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（安全谓词与安全裕度）**
给定状态 `s`、动作 `a` 与危害约束族 `C={c_k}`（碰撞距离、接触力上限、速度、人机隔离区），`Safe(s,a) ⇔ ∀k, g_k(s,a) ≤ 0`；安全裕度 `m_safe(s,a) = min_k(-g_k(s,a))`。安全包络 `E_safe = {a : m_safe(·,a) ≥ m_min}`。安全通道与 `ρ` 独立记录，互不替代。

**定义 122（任务-安全双通道结果）**
单次结果 `o=(succ,safe)∈{0,1}²`，四格为：真成功、**unsafe success**、safe failure、unsafe failure。记 `U = P(¬safe)`，`U_succ = P(succ ∧ ¬safe)`。部署闸门同时约束 `U ≤ u_max` 与 `U_succ ≤ u_succ_max`。

**定义 123（基线复现等级与承诺）**
基线承诺 `H=(h_code,h_data,h_env,h_seed,h_scenario)`。等级：
- `R0` 无记录；`R1` 固定 seed；`R2` = seed + 代码 + 环境 + 场景版本哈希；`R3` = R2 + 跨机器/跨步长独立重跑。
安全声明至少 `R2`，高风险部署要求 `R3`。

**定义 124（分布级复现距离）**
对分层 `𝔖`（场景族 × 随机源），归档分布 `P_arch` 与重放分布 `P_rep` 的复现距离
```
d_rep = max_{σ∈𝔖} MMD_k(P_arch(·|σ), P_rep(·|σ))，且每层 n_σ ≥ n_min
```
可复现当且仅当 `d_rep ≤ ε_rep`。MMD 使用有界核，避免只比较均值而漏掉尾部危害。

**定义 125（基线复现证书）**
`B_cert = (H, R, 𝔖, {n_σ}, d_rep, CI, verdict)`，`verdict ∈ {reproduced, drifted, unreproducible}`。证据至少含种子清单、环境容器摘要与逐层统计。

**定义 126（安全案例证书 SC）**
`SC = (G, L, {B_cert_ℓ}, verdict)`，`G` 为目标结构化（GSN）安全案例树：顶层目标“组合部署安全”，子目标覆盖动作包络、接触力、人机隔离、鲁棒性、基线可比性、共模风险。叶子 `ℓ∈L` 携带证据与 `B_cert_ℓ`。
```
verdict = pass          若所有叶子证据成立且所有 B_cert = reproduced
        = fail          若任一叶子被反例证伪
        = inconclusive  其余（证据缺失 / 漂移 / 覆盖不足）
```

**定义 127（安全-复现联合证书与回归预算）**
`J^safe = (J, m_safe, U, U_succ, B_cert, SC, D_xsv, ΔU)`。部署条件：
```
dom_J = in ∧ SC.verdict = pass ∧ U_succ^{UCI} ≤ u_succ_max
∧ ΔU^{UCI} ≤ δ_safe ∧ D_xsv ⊆ D_allowed
```
其中 `ΔU = U_new - U_base^{arch}` 必须对**归档基线**计算，而非现算基线。

## 2. 关键算法 伪代码

### IP-121 SES（Safety Envelope & Margin）

```python
def safety_margin(skill, s, a, constraints):
    return min(-c.g(s, a) for c in constraints)

def safety_envelope(skill, A, constraints, m_min):
    return {a for a in A if safety_margin(skill, s_of(a), a, constraints) >= m_min}

def unsafe_success_rate(trials):
    return sum(1 for o in trials if o.succ and not o.safe) / len(trials)
```

### IP-122 BRC（Baseline Reproduction Certificate）

```python
def reproduce_baseline(baseline, strata, budget, eps_rep):
    H = commit_hash(baseline)          # code|data|env|seed|scenario
    if H != baseline.archived_H:
        return B_cert(H, baseline.R, strata, None, None, 'unreproducible')
    runs = stratified_runs(baseline, strata, budget)   # 每层 n >= n_min
    d = max(stratum_mmd(baseline.archived[s], runs[s]) for s in strata)
    lo, hi = bootstrap_ci(runs, B=1000)
    if d > eps_rep:
        return B_cert(H, baseline.R, strata, d, (lo, hi), 'drifted')
    return B_cert(H, baseline.R, strata, d, (lo, hi), 'reproduced')
```

### IP-123 DRD（Distributional Reproduction Distance）

```python
def distributional_distance(arch, rep, strata, kernel, n_min):
    d = 0.0
    for s in strata:
        if len(rep[s]) < n_min:
            return float('inf')        # 样本不足即不可复现，不做乐观插值
        d = max(d, mmd(kernel, arch[s], rep[s]))
    return d
```

### IP-124 SCC（Safety Case Certificate）

```python
def build_safety_case(skill_seq, constraints, hazard_log, eps):
    leaves = []
    for h in hazard_log.dimensions:        # 碰撞/力/隔离/速度/共模...
        ev = evaluate_hazard(skill_seq, h, constraints)
        bc = reproduce_baseline(ev.baseline, ev.strata, ev.budget, eps.rep)
        v = ('fail' if ev.counterexample else
             'pass' if ev.covered and bc.verdict == 'reproduced'
             else 'inconclusive')
        leaves.append(Leaf(h, ev, bc, v))
    if any(l.verdict == 'fail' for l in leaves):
        return SC(G, leaves, 'fail')
    if any(l.verdict != 'pass' for l in leaves):
        return SC(G, leaves, 'inconclusive')
    return SC(G, leaves, 'pass')
```

### IP-125 SRT（Safety Regression Tripwire）

```python
def safety_regression_gate(new, archived_base, delta_safe, alpha):
    U_new = estimate_unsafe_success(new, n_plan)
    U_base = archived_base.U
    delta = U_new - U_base
    lo, hi = bootstrap_ci(delta, alpha)
    if hi > delta_safe:
        return ('reject', 'safety_regression', hi)
    return ('ok', delta, (lo, hi))
```

### IP-126 XSV（Cross-Simulator Validation）

```python
def cross_sim_validate(case, sims, allowed):
    S = [sim.safe_set(case) for sim in sims]
    D = union(S) - intersection(S)
    if not D.issubset(allowed):
        return ('reject', 'common_mode_risk', D - allowed)
    return ('ok', intersection(S), D)
```

### IP-127 JSC（Joint Safety-Reproduction Certificate）

```python
def joint_safety_certificate(J, skill_seq, constraints, sims,
                             archived_base, hazards, eps, budgets):
    m = min(safety_margin(s, a, constraints) for s, a in rollout(J.plan))
    if m < budgets.m_min:
        return ('reject', 'safety_envelope', m)
    b = reproduce_baseline(archived_base, hazards.strata, eps.rep)
    if b.verdict != 'reproduced':
        return ('reject', 'baseline_unreproducible', b)
    sc = build_safety_case(skill_seq, constraints, hazards, eps)
    if sc.verdict != 'pass':
        return ('reject', 'safety_case_' + sc.verdict, sc)
    xs = cross_sim_validate(skill_seq, sims, budgets.D_allowed)
    if xs[0] != 'ok':
        return ('reject', 'common_mode', xs)
    g = safety_regression_gate(skill_seq, archived_base,
                               budgets.delta_safe, budgets.alpha)
    if g[0] != 'ok':
        return ('reject', 'regression', g)
    return ('ok', J_safe(J, m, b, sc, xs[2], g[1]))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SES | O(|C|·|rollout|) | O(|A|) | 约束连续、裕度可测 |
| BRC | O(|𝔖|·n_min·T) | O(|𝔖|·n_min) | 哈希锁定、分层充分 |
| DRD | O(|𝔖|·n²) | O(n) | 有界核、MMD 一致估计 |
| SCC | O(|L|·(T_eval + BRC)) | O(|L|) | 危害维度覆盖完备 |
| SRT | O(n_plan·T) | O(n_plan) | 归档基线不变、检验功效足够 |
| XSV | O(|sims|·|A|·|S|) | O(|sims|·|A|) | 不一致域审计、交集合规 |
| JSC | 上述之和 | 上述之和 | 各门独立 sound、组合不放松 |

**正确性定理（Safety-Reproduction Composition Soundness）**
承接第 54 轮 (A22)–(A28)，新增假设：
**(A29)** 危害约束 `g_k` 有界 Lipschitz，裕度测量误差 ≤ `ε_m`；
**(A30)** 归档基线在 `R≥2` 下可复现，`d_rep ≤ ε_rep`；
**(A31)** 安全案例叶子覆盖危害日志全部维度（覆盖完备），单叶证据错误率 ≤ `β_ℓ`；
**(A32)** 跨仿真器不一致域 `D_xsv` 被审计，且 `D_xsv ⊆ D_allowed` 时共模残余风险 ≤ `β_x`；
**(A33)** 安全回归检验的 I 类错误 ≤ `α`。
则对任一通过 `J^safe` 部署的组合：
```
P(¬Safe ∧ deploy) ≤ U_base^{arch} + d_rep + ε_m + Σ_ℓ β_ℓ + β_x + α
```
直觉：安全不是自评出来的，而是从**可复现基线**继承，再加上可界定的分布漂移、测量误差、证据缺口与共模残差。任一前提破坏，`SC` 只能给 `inconclusive`，部署被阻断——**宁可不部署，也不用不可复现的安全数字换部署**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 基线不可复现 / 漂移 | 高 | 哈希锁 + 容器归档 + 分层种子 + R3 抽检 |
| 危害维度漏项 | 高 | 独立危害日志 + 红队 + 覆盖完备性审计 |
| 共模仿真偏差 | 高 | 跨仿真器 + 真实小样本 + 安全集合取交 |
| 过拟合 seed 造成假安全 | 高 | 分布级复现 + 留出场景族 + 尾部指标 |
| 三值门过保守导致不可部署 | 中 | inconclusive 预算 + 主动补证 + 分级放行 |
| 回归检验统计功效不足 | 中 | 样本量规划 + 序贯检验 + 效应量报告 |

## 6. 本轮最大风险

**一句话**：安全性把证书从“能做什么”推进到“做起来会不会伤人”，基线复现把安全数字从自评推进到可重放，但二者都是**关于证据的证据**——一旦基线、安全案例与评估共享同一仿真器与场景生成器，复现会漂亮地通过而真实危害模型仍可能系统性错误（共模失效），同时过严的复现要求又会诱导 seed 过拟合并把“稳定”误当成“安全”；因此必须用**独立仿真器/真实小样本的共模隔离 + 哈希锁定的归档基线 + 三值阻断**三件套守住证据来源，宁可判 inconclusive 也绝不让不可复现的安全数字进入部署。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++S（SES×BRC×DRD×SCC×SRT×XSV×JSC）

```python
    lo, hi = bootstrap_ci(runs, B=1000)
    if d > eps_rep:
        return B_cert(H, baseline.R, strata, d, (lo, hi), 'drifted')
    return B_cert(H, baseline.R, strata, d, (lo, hi), 'reproduced')
```

### IP-123 DRD

```python
def distributional_distance(arch, rep, strata, kernel, n_min):
    d = 0.0
    for s in strata:
        if len(rep[s]) < n_min:
            return float('inf')        # 样本不足即不可复现，不做乐观插值
        d = max(d, mmd(kernel, arch[s], rep[s]))
    return d
```

### IP-124 SCC

```python
def build_safety_case(skill_seq, constraints, hazard_log, eps):
    leaves = []
    for h in hazard_log.dimensions:        # 碰撞/力/隔离/速度/共模...
        ev = evaluate_hazard(skill_seq, h, constraints)
        bc = reproduce_baseline(ev.baseline, ev.strata, ev.budget, eps.rep)
        v = ('fail' if ev.counterexample else
             'pass' if ev.covered and bc.verdict == 'reproduced'
             else 'inconclusive')
        leaves.append(Leaf(h, ev, bc, v))
    if any(l.verdict == 'fail' for l in leaves):
        return SC(G, leaves, 'fail')
    if any(l.verdict != 'pass' for l in leaves):
        return SC(G, leaves, 'inconclusive')
    return SC(G, leaves, 'pass')
```

### IP-125 SRT

```python
def safety_regression_gate(new, archived_base, delta_safe, alpha):
    U_new = estimate_unsafe_success(new, n_plan)
    U_base = archived_base.U
    delta = U_new - U_base
    lo, hi = bootstrap_ci(delta, alpha)
    if hi > delta_safe:
        return ('reject', 'safety_regression', hi)
    return ('ok', delta, (lo, hi))
```

### IP-126 XSV

```python
def cross_sim_validate(case, sims, allowed):
    S = [sim.safe_set(case) for sim in sims]
    D = union(S) - intersection(S)
    if not D.issubset(allowed):
        return ('reject', 'common_mode_risk', D - allowed)
    return ('ok', intersection(S), D)
```

### IP-127 JSC

```python
def joint_safety_certificate(J, skill_seq, constraints, sims,
                             archived_base, hazards, eps, budgets):
    m = min(safety_margin(s, a, constraints) for s, a in rollout(J.plan))
    if m < budgets.m_min:
        return ('reject', 'safety_envelope', m)
    b = reproduce_baseline(archived_base, hazards.strata, eps.rep)
    if b.verdict != 'reproduced':
        return ('reject', 'baseline_unreproducible', b)
    sc = build_safety_case(skill_seq, constraints, hazards, eps)
    if sc.verdict != 'pass':
        return ('reject', 'safety_case_' + sc.verdict, sc)
    xs = cross_sim_validate(skill_seq, sims, budgets.D_allowed)
    if xs[0] != 'ok':
        return ('reject', 'common_mode', xs)
    g = safety_regression_gate(skill_seq, archived_base,
                               budgets.delta_safe, budgets.alpha)
    if g[0] != 'ok':
        return ('reject', 'regression', g)
    return ('ok', J_safe(J, m, b, sc, xs[2], g[1]))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SES | O(|C|·|rollout|) | O(|A|) | 约束连续、裕度可测 |
| BRC | O(|𝔖|·n_min·T) | O(|𝔖|·n_min) | 哈希锁定、分层充分 |
| DRD | O(|𝔖|·n²) | O(n) | 有界核、MMD 一致估计 |
| SCC | O(|L|·(T_eval + BRC)) | O(|L|) | 危害维度覆盖完备 |
| SRT | O(n_plan·T) | O(n_plan) | 归档基线不变、检验功效足够 |
| XSV | O(|sims|·|A|·|S|) | O(|sims|·|A|) | 不一致域审计、交集合规 |
| JSC | 上述之和 | 上述之和 | 各门独立 sound、组合不放松 |

**正确性定理（Safety-Reproduction Composition Soundness）**
承接第 54 轮 (A22)–(A28)，新增：
**(A29)** 危害约束 `g_k` 有界 Lipschitz，裕度测量误差 ≤ `ε_m`；
**(A30)** 归档基线在 `R≥2` 下可复现，`d_rep ≤ ε_rep`；
**(A31)** 安全案例叶子覆盖危害日志全部维度，单叶证据错误率 ≤ `β_ℓ`；
**(A32)** `D_xsv` 被审计，`D_xsv ⊆ D_allowed` 时共模残余风险 ≤ `β_x`；
**(A33)** 安全回归检验 I 类错误 ≤ `α`。
则任一通过 `J^safe` 部署的组合满足：
```
P(¬Safe ∧ deploy) ≤ U_base^{arch} + d_rep + ε_m + Σ_ℓ β_ℓ + β_x + α
```
关键位移：**安全不是绝对自评，而是从可复现基线继承的可审计差值**；任一证据前提破坏，`SC` 退化为 `inconclusive` 并阻断部署。

## 5. 本轮最大风险

**一句话**：安全性把证书从“能做什么”推进到“做起来会不会伤人”，基线复现把安全数字从自评推进到可重放，但二者都是**关于证据的证据**——一旦基线、安全案例与评估共享同一仿真器与场景生成器，复现会漂亮地通过而真实危害模型仍可能系统性错误（共模失效），同时过严的复现要求又会诱导 seed 过拟合并把“稳定”误当成“安全”；因此必须用**独立仿真器/真实小样本的共模隔离 + 哈希锁定的归档基线 + 三值阻断**三件套守住证据来源，宁可判 inconclusive 也绝不让不可复现的安全数字进入部署。
