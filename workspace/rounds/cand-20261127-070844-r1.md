### 第 1 轮灵感驱动研究记录（少样本学习 × 消融实验）

**灵感词**：少样本学习、消融实验

**直觉与动机**：
现有 SRC-USC v25 的七证体系把「安全」堆到极高的保守度，但有两个未解的裂缝。第一，所有 conformal/统计证书都默认校准分布与部署分布同分布；真实机器人进入新任务时往往只有 K 个示教样本（few-shot），模型在支持集上更新后 exchangeability 被破坏，原先的覆盖承诺会静默失效。少样本学习提示我们：**适应过程本身必须被证书化**——不是给「模型」发证，而是给「从 θ₀ 到 θ_K 的适应算子」发证，其风险上界显式依赖 K 与任务相似度。第二，七证耦合使执行集 Exec_v25 可能趋近空集（R15），但我们从未形式化回答「哪张证书真正在起作用」。消融实验提供反向视角：把证书当作可被移除的干预变量，用边际安全贡献与 Shapley 归因量化每张证书的必要性，从而既证明非冗余、又为风险预算松弛提供可证依据。核心洞见：**少样本学习要求「适应即证书」，消融实验要求「证书亦可被证伪」；前者扩展准入门的输入端，后者校准准入门的内部结构。**

**形式化目标**：
1. 定义少样本适应证书（FSAC）：元初始化 θ₀、K-shot 支持集 S_K、适应算子 A: θ_K = A(θ₀, S_K)；给出 PAC-Bayes 与 conformal 联合风险界 ℙ(y ∈ C_{θ_K}(x)) ≥ 1-α-ε_trans(K,δ)，其中 ε_trans 显式含支持集规模 K、假设复杂度 KL 与元任务-目标任务散度 d(𝒯_meta, 𝒯_test)。
2. 定义证书消融证书（ABC）：消融算子 A_c（仅关闭证书 c、其余条件匹配），边际风险 Δ_c = R(admit \ c) - R(admit)，Shapley 归因 φ_c；证书 c 的「必要性」谓词为 Δ_c > τ_nec 且置信下界为正。
3. 定义适应感知风险预算分配器（ARBA）：在总风险预算 Σ_c w_c α_c ≤ α_total 的单纯形内，用 φ_c 重分配各证书容差，缓解 v25 的指数级保守性而不扩大基线执行集。
4. 构建 FAR-USC v26 九证准入门：SRC-USC ∪ FSAC ∪ ABC ∪ ARBA；Exec_v26 = Exec_v25 ∩ Fil_fs ∩ Fil_ab ⊆ Exec_v25。
5. 证明在少样本适应失败、消融归因失真与预算重分配三条件下的单调退化链保持性。

**本轮最大风险（一句话）**：FSAC 的 PAC-Bayes 界在「支持集本身被污染或来自异构任务」时会给出过于乐观的转移风险，而 ABC 的 Shapley 归因依赖有限场景分布，二者叠加可能让适应感知预算把风险从真正关键的物理安全证书挪走，导致部署时的静默失效。

# ============================================================
# IP-448 Few-shot Adaptation Certificate (FSAC) — 少样本适应证书
# ============================================================
@dataclass
class FewShotAdaptationCertificate:
    """面向适应算子 θ0 -> θK 的 PAC-Bayes + conformal 联合证书"""
    meta_init: 'MetaInit'                 # θ0
    support: 'TaskSupport'                # S_K = {(x_i, y_i)}, |S_K| = K
    adapter: 'Adapter'                    # A(θ0, S_K)
    calibrator: 'ConformalCalibrator'     # 元校准集上的分位数估计器
    alpha: float = 0.05
    delta: float = 0.01
    task_divergence: float = 0.0          # d(T_meta, T_test) 估计
    kl_complexity: float = 0.0            # KL(P||Q)
    support_penalty: float = 0.0          # ν_sup：标签噪声/覆盖空洞/离群率
    max_support_penalty: float = 0.02     # 超过即拒绝适应，回退零样本保守模式

    def adapt(self) -> 'AdaptedModel':
        """θ_K = A(θ0, S_K)，并记录适应前后参数位移"""
        return self.adapter.apply(self.meta_init, self.support)

    def transfer_risk(self) -> float:
        """ε_trans(K,δ,d) = sqrt((KL+ln(2/δ))/(2K)) + d + ν_sup"""
        K = max(len(self.support), 1)
        pac = math.sqrt((self.kl_complexity + math.log(2.0 / self.delta)) / (2.0 * K))
        return pac + self.task_divergence + self.support_penalty

    def verify_support_quality(self) -> bool:
        """支持集可用性：标签一致性 + 任务覆盖 + 离群率"""
        checks = [
            self.support.label_noise_rate <= 0.05,
            self.support.coverage_ratio >= 0.90,
            self.support.outlier_rate <= 0.05,
            self.support_penalty <= self.max_support_penalty,
        ]
        return all(checks)

    def inflated_quantile(self, scores: Tensor) -> float:
        """q̂_{1-α+ε_trans}：把转移风险折入分位数，做保守膨胀"""
        level = min(1.0 - self.alpha + self.transfer_risk(), 0.999)
        return torch.quantile(scores, level).item()

    def verify_coverage(self, x_test: Tensor, y_test: Tensor) -> bool:
        """经验覆盖检查 + 理论上界双保险"""
        if not self.verify_support_quality():
            return False
        model = self.adapt()
        scores = self.calibrator.nonconformity_scores(model, x_test, y_test)
        q_hat = self.inflated_quantile(self.calibrator.calibration_scores)
        covered = (scores <= q_hat + 1e-9)
        empirical = covered.float().mean().item()
        theoretical = 1.0 - self.alpha
        return empirical >= theoretical - 0.01 and self.transfer_risk() < 1.0 - self.alpha

    def verify_all(self, x_test: Tensor, y_test: Tensor) -> bool:
        return (self.verify_support_quality() and
                self.verify_coverage(x_test, y_test) and
                self.transfer_risk() < 1.0 - self.alpha)

    def zero_shot_fallback(self) -> 'AdaptedModel':
        """支持集不可信时禁用适应，退回元先验的保守预测"""
        return self.adapter.identity(self.meta_init)

# IP-449 Certificate Ablation Certificate (ABC) — 证书消融证书
# ============================================================
@dataclass
class CertificateAblationStudy:
    """证书作为干预变量：匹配消融 + 边际贡献 + Shapley 归因"""
    gate: 'FarUSC'                       # 完整九证门
    certificates: list[str]              # 𝒢，m <= 9
    seeds: int = 5                       # 匹配随机种子
    n_scenarios: int = 1000              # 评估场景数
    tau_nec: float = 1e-3                # 必要性阈值
    bootstrap: int = 2000                # 置信区间重采样次数

    def ablate(self, name: str) -> 'AblatedGate':
        """A_c：仅关闭证书 c；数据、种子、噪声、预算完全匹配"""
        if name not in self.certificates:
            raise KeyError(name)
        return AblatedGate(self.gate, disabled={name})

    def evaluate(self, gate, scenarios) -> Tensor:
        """在匹配场景集上返回逐场景安全价值（负风险/带约束收益）"""
        return torch.tensor([gate.value(s) for s in scenarios])

    def marginal_contribution(self, name: str, scenarios) -> tuple[float, float, float]:
        """Δ_c = V(𝒢) - V(𝒢\\{c})，返回均值与 bootstrap 置信区间"""
        full = self.evaluate(self.gate, scenarios)
        ablated = self.evaluate(self.ablate(name), scenarios)
        delta = (full - ablated).mean().item()
        lo, hi = bootstrap_ci(full - ablated, n=self.bootstrap)
        return delta, lo, hi

    def shapley(self, scenarios) -> dict[str, float]:
        """精确枚举 2^m 联盟（m<=9 => 512），计算 Shapley 值"""
        value_cache: dict[frozenset, float] = {}

        def V(coalition: frozenset) -> float:
            if coalition not in value_cache:
                gate = AblatedGate(
                    self.gate,
                    disabled=set(self.certificates) - set(coalition),
                )
                value_cache[coalition] = self.evaluate(gate, scenarios).mean().item()
            return value_cache[coalition]

        m = len(self.certificates)
        phi = {c: 0.0 for c in self.certificates}
        for c in self.certificates:
            others = [x for x in self.certificates if x != c]
            for r in range(len(others) + 1):
                for subset in itertools.combinations(others, r):
                    coalition = frozenset(subset)
                    weight = (math.factorial(len(subset)) *
                              math.factorial(m - len(subset) - 1) /
                              math.factorial(m))
                    phi[c] += weight * (V(coalition | {c}) - V(coalition))
        return phi

    def verify_protocol_validity(self) -> bool:
        """消融有效性：只改证书开关，不改变种子/噪声/预算/场景集"""
        return (self.seeds >= 5 and self.n_scenarios >= 1000 and
                self.gate.conditioning_hash() == self.ablate(
                    self.certificates[0]).conditioning_hash())

    def verify_necessity(self, scenarios) -> bool:
        """∀c∉𝒦_core：Δ_c 的置信下界 > τ_nec；核心证书豁免（不可消融）"""
        if not self.verify_protocol_validity():
            return False
        for c in self.certificates:
            if c in CORE_CERTIFICATES:
                continue
            _, lo, _ = self.marginal_contribution(c, scenarios)
            if lo <= self.tau_nec:
                return False
        return True

    def verify_all(self, scenarios) -> bool:
        phi = self.shapley(scenarios)
        efficiency = abs(sum(phi.values()) -
                         (self.evaluate(self.gate, scenarios).mean().item() -
                          self.evaluate(AblatedGate(self.gate, set(self.certificates)),
                                        scenarios).mean().item()))
        return (self.verify_protocol_validity() and
                self.verify_necessity(scenarios) and
                efficiency <= 1e-6)

# IP-450 Adaptation-aware Risk Budget Allocator (ARBA)
# ============================================================
@dataclass
class AdaptiveRiskBudget:
    """在固定总预算单纯形内按 |φ_c| 重分配；核心证书不可松弛"""
    total_budget: float                  # α_total = v25 基线总预算
    core_certificates: set[str]          # 𝒦_core
    min_budget: dict[str, float]         # 每证最小不可削减预算
    max_budget: dict[str, float]         # 每证最大预算（安全上界）

    def allocate(self, phi: dict[str, float]) -> dict[str, float]:
        weights = {c: abs(v) for c, v in phi.items()}
        z = sum(weights.values()) or 1.0
        weights = {c: w / z for c, w in weights.items()}
        budget = {}
        for c, w in weights.items():
            if c in self.core_certificates:
                budget[c] = self.min_budget[c]
            else:
                budget[c] = min(max(w * self.total_budget,
                                    self.min_budget[c]),
                                self.max_budget[c])
        # 归一化回总预算：只减不增
        scale = min(1.0, self.total_budget / max(sum(budget.values()), 1e-12))
        return {c: b * scale for c, b in budget.items()}

    def verify(self, phi: dict[str, float]) -> bool:
        budget = self.allocate(phi)
        return (sum(budget.values()) <= self.total_budget * (1 + 1e-9) and
                all(budget[c] >= self.min_budget[c] for c in budget))

@dataclass
class FewShotAblationResearchUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25 七证
    fsac: FewShotAdaptationCertificate
    abc: CertificateAblationStudy
    arba: AdaptiveRiskBudget

    def admits(self, multi_plan, sensor_data, x_test, y_test,
               ablation_scenarios) -> bool:
        # 1. v25 七证（含 USMC 四证 + SMC + RMC + MCC）
        if not self.src_usc.admits(
            multi_plan, sensor_data,
            gt_entities=sensor_data.get('gt_entities'),
            queries=sensor_data.get('queries'),
            retrieved=sensor_data.get('retrieved'),
        ):
            return False

        # 2. 少样本适应证书：支持集质量 + 转移风险 + 膨胀 conformal 覆盖
        if not self.fsac.verify_all(x_test, y_test):
            # 支持集不可信时只允许零样本保守回退，而不是直接放行
            if not self._zero_shot_conservative_ok(multi_plan, sensor_data):
                return False

        # 3. 证书消融证书：协议有效 + 必要性 + Shapley 效率
        if not self.abc.verify_all(ablation_scenarios):
            return False

        # 4. 适应感知风险预算：只重分配、不扩总预算
        phi = self.abc.shapley(ablation_scenarios)
        if not self.arba.verify(phi):
            return False

        return True

    def _zero_shot_conservative_ok(self, multi_plan, sensor_data) -> bool:
        """回退模式：禁用学习型适应，要求 v25 在更严 α 下仍通过"""
        return self.src_usc.admits(
            multi_plan, sensor_data,
            alpha_override=self.fsac.alpha * 0.5,
        )

# 辅助函数
def bootstrap_ci(values: Tensor, n: int = 2000, level: float = 0.95) -> tuple[float, float]:
    """对逐场景差值做 bootstrap，返回 (1-level)/2 与 1-(1-level)/2 分位数"""
    idx = torch.randint(0, len(values), (n, len(values)))
    means = values[idx].mean(dim=1)
    lo = torch.quantile(means, (1 - level) / 2).item()
    hi = torch.quantile(means, 1 - (1 - level) / 2).item()
    return lo, hi

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |

| ABC Shapley 精确枚举 | O(2^m · N_scen · T_gate) | O(2^m) 价值缓存 | m=9 → 512 联盟 |
| ABC 必要性验证 | O(m · N_scen · T_gate) | O(N_scen) | m=9 |
| ARBA 重分配 | O(m log m) | O(m) | m=9 |
| FAR-USC 在线准入 | v25 + O(N_cal log N_cal + K·d²) | +O(N_cal + d²) | 适应仅在任务起始触发 |
| FAR-USC 离线消融 | O(512 · N_scen · T_gate) | O(2^m) | 仅在版本发布/里程碑触发 |

**实时性保证**：ABC 与 ARBA 是离线/里程碑级审计，不进入控制环；FSAC 的适应只在任务起始执行一次，在线控制路径仅增加 O(1) 的风险界比较与一次分位数查表。因此 v26 控制环时延相对 v25 基本不变，九证门不会破坏 50Hz 协同环。

## 3. 正确性论证（增量）

### 引理 13（少样本适应证书的转移覆盖保证）
**陈述**：设目标任务 τ~𝒯_test 与元任务分布 𝒯_meta 的散度估计为 d，支持集 |S_K|=K、标签噪声与覆盖空洞惩罚为 ν_sup。若元校准集与目标任务的 conformal 分数满足可交换性、且 PAC-Bayes 后验复杂度为 KL(P‖Q)，则对任意 δ∈(0,1)，以至少 1-δ 的概率有
$$\mathbb{P}\big(y\in C_{\theta_K}(x)\big)\ \ge\ 1-\alpha-\varepsilon_{\text{trans}}(K,\delta,d),$$
其中 ε_trans = √((KL + ln(2/δ))/(2K)) + d + ν_sup。

**证明**：
1. PAC-Bayes 元学习界给出：以 1-δ 概率，目标任务风险 ≤ 经验元风险 + √((KL+ln(2/δ))/(2K))；该项随 K 增大以 O(1/√K) 收敛。
2. 若 𝒯_test≠𝒯_meta，经验元风险相对目标风险有偏差，最坏偏差由分布散度 d 控制（积分概率度量/MMD 上界），故追加 d 惩罚。
3. 支持集若含噪声或覆盖空洞，适应算子的有效样本量下降，用 ν_sup 惩罚；ν_sup 超过阈值时 `verify_support_quality=false`，强制零样本回退。
4. 将总转移风险 ε_trans 折入 conformal 分位数（`inflated_quantile` 取 1-α+ε_trans），由 split conformal 的边际覆盖定理，膨胀分位数保证覆盖率 ≥ 1-α-ε_trans。
5. 当 K→∞、d→0、ν_sup→0 时 ε_trans→0，退化为 v25 的同分布覆盖 ≥1-α，故 FSAC 是 v25 统计证书的严格推广。
∎

**注**：该保证是边际（marginal）覆盖，不是条件覆盖；对高风险子群需额外的分组 conformal 或 Mondrian 校准。

### 引理 14（消融证书的归因可靠性与必要性判定）
**陈述**：若消融算子 A_c 满足匹配条件（仅切换证书 c，种子、场景、噪声、预算、传感器输入完全相同），则边际贡献 Δ_c = V(𝒢)-V(𝒢\{c}) 是证书 c 反事实边际安全价值的无偏估计；Shapley 归因 φ_c 满足效率性 Σ_c φ_c = V(𝒢)-V(∅)、对称性、哑元性与可加性。在此条件下，`verify_necessity` 通过当且仅当所有非核心证书的 Δ_c 置信下界严格大于 τ_nec。

**证明**：
1. 匹配条件消除混杂：A_c 只改变一个二元干预变量，其余变量固定，故逐场景差值 V(s)-V_c(s) 的期望即平均处理效应（ATE）的无偏估计。
2. bootstrap 对逐场景差值重采样，得到 Δ_c 的置信区间；用下界与 τ_nec 比较，控制「偶然波动被误判为必要性」的第一类错误。
3. Shapley 值的四个公理由联盟价值函数 V 与精确枚举权重的标准构造直接满足（Shapley 1953）；效率性给出总归因等于完整门相对空门的增益，可作为归因自检。
4. 因此 ABC 通过 ⇒ 每张非核心证书在给定场景分布上确有可测贡献，且消融协议没有被种子/预算差异污染。
∎

**注**：Shapley 是联盟博弈的归因，不是分布外因果效应；场景分布漂移时 φ_c 只对审计分布有效。

### 引理 15（FAR-USC v26 的九证单调退化链）
**陈述**：在任意单点/组合失效下，
$$\text{Exec\_v26}\subseteq\text{Exec\_v25}\subseteq\cdots\subseteq\text{Exec\_v18}.$$
特别地，FSAC 失败只允许零样本保守回退，ABC 失败冻结风险预算重分配，ARBA 失败退回 v25 原始预算，均不会扩大执行集。

**证明**：
1. 定义层面 Exec_v26 = Exec_v25 ∩ Fil_fs ∩ Fil_ab ∩ Fil_budget，三个过滤器均取交集，故子集关系成立。
2. 少样本适应失败（支持集污染/转移风险超阈）→ `FSAC.verify_all=false` → 仅当零样本回退在 α/2 下仍通过 v25 时才放行；这是 Exec_v25 的进一步收缩，不新增计划。
3. 消融协议无效或必要性检验失败 → `ABC.verify_all=false` → 拒绝 v26 准入，退回 Exec_v25；此时不做任何预算重分配，v25 的原始安全证书仍有效。
4. ARBA 只在固定总预算 α_total 的单纯形内重分配，且核心证书预算锁定在 min_budget；由 `verify` 的 Σbudget≤α_total 约束，任一证书的松弛都被其他证书的收紧或核心证书的锁定所补偿，总风险不增。
5. 组合失效取交集；交集运算保持子集关系，故单调链在所有退化路径下成立。
∎

### 定理（FAR-USC 九证准入门的安全-适应-可审计-可松弛完备性）
**陈述**：对任意计划 π 与目标任务 τ，`FAR-USC.admits(π)=True` ⟺ π 同时满足：
(1) v25 的七证条件（物理接地、云边一致、少样本前覆盖、专利、结构、力控、轻量化、语义、重构、协同）；
(2) K-shot 适应后覆盖 ≥1-α-ε_trans，且支持集质量与转移风险在容许域内（或通过 α/2 零样本保守回退）；
(3) 消融协议有效、非核心证书边际贡献置信下界 >τ_nec、Shapley 效率性成立；
(4) 风险预算仅在同一 α_total 单纯形内重分配，核心证书不可松弛。

**证明**：充分性由 `admits` 的四个连言分支与引理 13–15 直接得到；必要性由任一分支失败即拒证得到。引理 13 保证输入端的统计有效性，引理 14 保证内部结构的可审计性，引理 15 保证组合后的单调安全链。四者共同把 v25 的「静态七证」扩展为「适应可证、结构可审、预算可解释」的闭环。
∎

## 6. 本轮最大风险（最终确认）

**一句话**：**FSAC 的 PAC-Bayes 转移界在支持集被污染或目标-元任务散度不可观测时会系统性低估 ε_trans，而 ABC 的 Shapley 归因只是在有限审计场景上的联盟博弈值、无法代表部署分布的因果边际，二者一旦被 ARBA 用于重分配风险预算，就可能把预算从真正承重的物理安全证书挪向「在消融基准上看起来更划算」的证书，导致 FAR-USC 在分布漂移的真实部署中静默放行一个九证齐全却不安全的计划。**
