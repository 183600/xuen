# 第 43 轮（新循环第 1 轮） · VLA-CertCommons：把 VLA 降格为「不可信提议者」，用开源证书生态做「可信执行护栏」（五层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR，四层架构 v7）。v19 把证书做成可进化的资产，但仍隐含假设「被证书约束的策略本身可信、可被形式化刻画」。本轮两个灵感词精准拆掉这个假设：**视觉-语言-动作模型（VLA）** 把感知、语言、动作压进端到端黑箱，开放语义泛化极强，却让「状态→动作」的证书无处附着；**开源生态** 既是解药也是毒药——它让证书可独立复现、众包反例、跨机器人复用、随模型流动，也让一条被投毒的权重或伪造的证书沿 fork 静默传播到所有下游。本轮的立场是：**不证书化 VLA，只证书化 VLA 与执行器之间的接口**。VLA 降格为不可信的「意图提议者」，证书护栏（Shield）是可验证的「执行裁决者」，开源生态则是证书的「版本库 + 众包测试场 + 供应链」。三者构成 Open-Cert 飞轮：VLA 提议 → Shield 裁决 → 运行时证据 → 社区反例 → CKB/证书更新 → 重新验证。

## 0. 直觉与动机

**灵感 1（VLA → 不可信提议者，而非被证书化的对象）**：OpenVLA / RT-2 / π0 / Octo / RDT 这类模型的共同点是「一个网络吃图像+语言、吐动作块（action chunk）」，泛化来自预训练互联网语义，而非可解析的动力学。直觉上，试图对 VLA 做逐状态证书是方向性错误：它的输入空间（开放语言 + 开放视觉）不可枚举，输出是高维连续/离散混合动作。**正确的抽象边界是「意图」**——VLA 擅长说「去把红杯子挪开」，不擅长保证「这一秒关节力矩不会撞到人」。于是把 VLA 视为一个**不可信提议 oracle**，其输出先经「语义意图抽取」，再由证书 Shield 做最小干预投影；投影失败才回退到已证控制器或 SafeStop。VLA 的泛化红利保留在「提议分布」，安全性完全由可验证的判决层承担。

**灵感 2（开源生态 → 证书成为一等公民，供应链成为新攻击面）**：开源生态真正稀缺的不是权重，而是**可独立复现的证据**。直觉是给每个 VLA 配一份「证书物料清单」CBOM（Certificate Bill of Materials），像 SBOM 一样把权重哈希、数据来源与许可、证书、评测脚手架、已知反例、签名与透明日志打包在一起，随模型在 HuggingFace/GitHub 上流动。好处有三：其一，**独立复算**——任何人可在自己的硬件上重跑 margin 复验，证书不再依赖单一厂商的「相信我」；其二，**众包反例**——社区提交的失败轨迹变成公开回归测试，证书成为「活文档」；其三，**组合复用**——技能子证书可跨机器人拼装（接 IP-47）。坏处同样尖锐：开源把信任边界扩展到所有 fork，投毒权重、伪造 CBOM、证书-模型错绑都会沿供应链放大。因此 CBOM 必须带哈希绑定、签名链与透明日志（借用 Certificate Transparency 的思路），把「下载即信任」改成「下载先验证」。

**灵感 3（耦合 → Open-Cert 飞轮 + Safety Rider 许可证）**：VLA 是提议源，Shield 是判决器，CBOM 是证据载体，社区反例是燃料，CKB 是记忆，SCV/Isaac Sim 是压力测试场。闭环为：**提议 → 裁决 → 运行证据 → 反例提交 → 证书降级/重验 → 新 CBOM 发布**。开源治理上引入 **Safety Rider（安全附加条款）**：模型许可证允许自由使用，但再分发时必须携带（可验证的）CBOM 或显式声明「无证书」，形成「无证书不静默」的生态规范。这把第 42 轮的内部飞轮升级为**跨组织、可审计的公共品**。

## 1. 形式化定义（增量：定义 38–44）

**定义 38（VLA 策略与动作块）**：π_θ:(I_{t-k:t}, ℓ, s_t) ↦ A_t=(a_t,…,a_{t+H−1})∈R^{H×d}，I 为视觉观测序列，ℓ 为语言指令，s_t 为本体状态，H 为动作块长度，d 为动作维。定义**语义意图抽取** z_t=E_int(A_t)（技能 token / 离散技能原语 + 连续参数），以及动作块解码 D_int(z_t)≈A_t。VLA 只被要求「提议质量」，不被要求「安全正确」。

**定义 39（动作安全集与证书 Shield）**：给定状态 x 与证书边际函数 m(x,a)（由 IP-56 ECR 的 L0 查表/L1 INT8 监控器给出），A_safe(x)={a:m(x,a)≥θ(x)}。Shield 定义为
S(x,a)= a（若 m≥θ）；= Proj_{∂A_safe}(a)（若 0<ρ≤ρ_max）；= ⊥（若 ρ>ρ_max），
其中 ρ=dist(a,A_safe)。**推导（线化投影的保守补偿）**：设 m 对 a 可微，∇m 为 L_g-Lipschitz，g=∇m(x,a)，ρ=(θ−m)/‖g‖。取 a*=a+((θ+ε_safe−m)/‖g‖²)g，则
m(a*) ≥ m(a)+gᵀ(a*−a)−(L_g/2)‖a*−a‖² = θ+ε_safe−(L_g/2)ρ²。
故取 ε_safe ≥ (L_g/2)ρ² 即可保证 m(a*)≥θ。**引理（Shield 单步 soundness）**：若每次执行的动作 ∈A_safe 或 a*，则不变式 Inv（由 CAR 给出）在单步内保持；投影预算 ρ_max 是显式的可用性旋钮。

**定义 40（语义接地证书 SGC）**：语言指令 ℓ 对应状态谓词 P_ℓ:X→{0,1}；接地器 G_ψ(z,s) 用保形预测给出谓词置信。定义**接地风险** R_g=Pr[G=1 ∧ x∉C]（C 为已证不变式域），SGC 要求 R_g≤δ_g，且开放集指令必须**弃权**（abstain）而非硬猜。SGC 把「几何安全」补上「意图安全」：证书不只问「动作危不危险」，还问「这个动作是不是用户真的想让它做的」。

**定义 41（证书物料清单 CBOM 与信任链）**：CBOM=(M,D,C,E,Ξ,L,Σ,T)，M=模型权重哈希与架构，D=数据来源与许可清单，C=证书（θ,L_m,有效域哈希），E=评测套件与硬件配置，Ξ=已知反例集，L=许可证（含 Safety Rider），Σ=签名链，T=透明日志条目（Merkle 包含证明）。**绑定关系** Bind(M,C)：hash(M) 写入 C 且可通过 E 独立复算 margin。验证谓词 Verify(CBOM,policy)=HashOK ∧ ReverifyOK ∧ SigOK ∧ LogOK ∧ LicenseOK。

**定义 42（证书注册表、等价与组合）**：注册表是只追加的 Merkle 日志；证书等价 C1≡C2 当且仅当在同一抽象域上 ∀x,m1(x)≥θ1 ⟺ m2(x)≥θ2（用抽样+区间覆盖检验近似）。组合 C1⊗C2 要求接口契约（输入/输出证书变量、坐标系、时基）兼容且乘积 Shield 存在；组合 soundness 继承 IP-47 的乘积自动机论证。

**定义 43（开放伪造循环 / 反例公共地）**：社区提交 ξ=(场景, 证据, 提交者签名)，用行为哈希 h(ξ)=hash(轨迹语义摘要) 去重；接受需独立复现。证书风险分 r(C)=w_s·severity+w_n·novelty−w_d·duplicate；当 r(C)>τ_risk，CBOM 标记 AtRisk 并触发重验/降级（回字第 42 轮定义 36 的飞轮）。

**定义 44（生态级成本—安全模型）**：单位部署生态成本 C_eco=(C_verify+C_registry+C_redteam)/N_reuse+C_edge·T_life；生态安全性要求验证法定人数 q 与透明日志包含。**命题**：C_eco 随复用数 N_reuse 单调下降，但信任放大系数（下游 fork 数）随 N_reuse 上升；因此存在最优「验证深度—复用广度」权衡，过度中心化验证会重新制造单点信任。

## 5. 本轮最大风险

**一句话**：开源生态把「一个本地失效」放大成「所有 fork 的失效」——若 CBOM 的模型-证书绑定可被伪造/投毒/降级，Shield 会拿着错误的 margin 在天量下游设备上「自信地放行」，因此 E90/E91（哈希绑定、签名链、透明日志、独立复算法定人数）必须作为发布红线，任一不达标即禁止自动分发。

## 2. 关键算法（伪代码）

### IP-57 VLA-SHIELD：提议—接地—裁决三段式
```
def vla_shield_step(obs, instruction, pi_vla, sgc, ecr, car, budget):
    # ---- 阶段 A：VLA 低频提议（不可信） ----
    chunk = pi_vla(obs, instruction)          # [H, d]，H 步动作块
    z = E_int(chunk)                          # 语义意图（技能 token + 参数）

    # ---- 阶段 B：语义接地门（意图合法性） ----
    ground = sgc.ground(z, obs, instruction)  # 谓词置信 + 已证域检查
    if ground.abstain:                        # 开放集/低置信 → 不硬猜
        return fallback_certified_skill(z, obs)
    if not ground.within_certified_domain:    # 意图本身越界（如去不可达区）
        return fallback_certified_skill(z, obs)

    # ---- 阶段 C：逐控制步最小干预裁决（可信） ----
    for k in range(H):
        a = chunk[k]
        x = obs_at(k)
        m, g, L_g = ecr.margin_grad(x, a)     # L1 INT8 前向 + 梯度通道
        if m >= theta(x):
            exec(a)                            # 提议本身安全：原样放行
            continue
        if budget.exhausted():                 # 预算保护
            return safe_stop()
        rho = (theta(x) - m) / max(EPS, norm(g))
        if rho > budget.rho_max:
            return fallback_certified_skill(z, x)   # 干预过大：不硬掰
        eps_safe = 0.5 * L_g * rho * rho           # 线化保守补偿
        a_star = a + ((theta(x) + eps_safe - m) / max(EPS, norm(g)**2)) * g
        # 可选：投影后复算一次 margin 做自检，失败则回退
        if ecr.margin(x, a_star) < theta(x):
            return fallback_certified_skill(z, x)
        exec(a_star)
        budget.consume(norm(a_star - a), grad_query=True)
    return OK
```

```
def chunk_tube_check(chunk, x0, dyn, cert, horizon):
    x = x0
    for k in range(horizon):
        r = cert.margin_radius(x)          # 当前状态的证书 tube 半径
        x = dyn.step(x, chunk[k])
        if cert.dist_to_unsafe(x) < r:     # 预测落入安全边界 tube
            return False
    return True
```

```
def verify_cbom(cbom, policy):
    # 1) 模型-证书绑定：哈希一致
    if sha256(read_weights(cbom.model.name)) != cbom.model.sha256:
        return REJECT("model_hash_mismatch")
    # 2) 独立复算：在评测套件上重跑 margin，证书与模型必须同时满足
    if reverify_margin(cbom.model, cbom.eval, cbom.certificate) < policy.min_conf:
        return REJECT("certificate_model_mismatch")
    # 3) 签名链 + 透明日志包含证明（防降级/回放）
    if not verify_sigs(cbom, quorum=policy.quorum):
        return REJECT("signature_quorum_failed")
    if not in_transparency_log(cbom.transparency, cbom.model.sha256):
        return REJECT("not_in_transparency_log")
    # 4) 许可证 + Safety Rider：再分发必须携带可验证 CBOM 或显式"无证书"
    if not license_ok(cbom.model.license, policy):
        return REJECT("license_or_safety_rider")
    # 5) 已知反例的风险分不得超过阈值
    if cert_risk(cbom) > policy.max_risk:
        return REJECT("at_risk_certificate")
    return ACCEPT

def cert_risk(cbom):
    r = 0.0
    for cex in cbom.counterexamples:
        if cex.state == "open": r += w_s*cex.severity + w_n*cex.novelty
    return r

def compose_cbom(c1, c2, contract):
    # 跨机器人/跨技能组合：先查接口契约，再查证书等价与乘积 Shield
    if not interface_compatible(c1.certificate, c2.certificate, contract):
        return REJECT("interface_contract_mismatch")
    if not equiv_on_overlap(c1.certificate, c2.certificate):
        return REJECT("certificate_not_equivalent_on_overlap")
    return build_product_shield(c1, c2, contract)  # 接 IP-47 乘积自动机
```

```
def submit_counterexample(cbom_id, scenario, evidence, submitter_sig):

                       "severity": assess_severity(evidence),
                       "novelty": novelty(h, registry)})

def ingest_counterexample(item):
    # 独立复现：由两名非提交者的验证节点在干净环境重跑
    if not independent_reproduce(item, quorum=2):
        return REJECT("not_reproducible")
    registry.add(item)
    # 风险分更新 → 触发证书 AtRisk / 重验 / 撤销
    cbom = registry.cbom(item.cbom_id)
    if cert_risk(cbom) > tau_risk:
        registry.mark_at_risk(cbom)
        trigger_reverification(cbom)       # 回到 IP-54 SCV + IP-55 CKB
        if cert_risk(cbom) > tau_revoke:
            registry.revoke(cbom)          # 撤销并广播 IP-45
    return ACCEPT
```

```
# CAR：AtRisk/Revoked 证书禁止迁移；Shield 失败进入显式回退状态
def car_guard_v3(e, x, cert, cbom_status):
    if cbom_status in ("AtRisk", "Revoked"):
        return FALSE, "certificate_untrusted"
    theta_real = cert.alpha_e[e] * cert.theta_sim[e]
    m = ecr.cert_lookup_L0(x).m_lo[e]
    return m >= theta_real, "ok"

# LCS：新增 T-2 Shield 投影档（一次梯度查询 + 一次复算）
def certify_light_v3(x, a, guards, budget_us):
    b = ecr.cert_lookup_L0(x)                 # T-1: 5us
    U = undecided_guards(b, guards)
    if not U: return b, -1
    if budget_us < 10: return downgrade_monotone(b), -1
    status, margin = ecr.monitor_step_INT8(quantize(x))  # T0: ~100us
    b.m_lo = margin
    U = undecided_guards(b, guards)
    if not U: return b, 0
    # T-2: Shield 投影需要的梯度（仅在预算允许时）
    if budget_us < 130: return downgrade_monotone(b), 0
    m, g = ecr.margin_grad(x, a)
    a_star = linear_project(a, m, g, theta=b.theta)
    if a_star is None: return downgrade_monotone(b), 1
    return b.with_action(a_star), 2

# CMC：导出 margin 与梯度（供 Shield 使用）
def export_shield_backend(interval_circuit):
    onnx = interval_circuit.to_onnx()
    grad_onnx = autodiff(onnx, wrt="action")     # 或低维有限差分回退
```

## 6. 本轮最大风险

**一句话**：开源生态把「一个本地失效」放大成「所有 fork 的失效」——若 CBOM 的模型-证书绑定可被伪造/投毒/降级，Shield 会拿着错误的 margin 在天量下游设备上「自信地放行」，因此 E90/E91（哈希绑定、签名链、透明日志、独立复算法定人数）必须作为发布红线，任一不达标即禁止自动分发。
