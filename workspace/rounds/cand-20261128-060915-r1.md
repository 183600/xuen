### 第 6 轮灵感驱动研究记录（新循环第 1 轮，承接 CADVS-v5）

**灵感词**：MuJoCo、创新点挖掘

**继承关系**：继承第 5 轮 CADVS-v5（IP-493~496）「认证的生成式执行（CGE）」：七硬门 kc_evidence_forged_v4 与 τ^4 冻结只读、定理 5~8、执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。v5 已把提议器从离散规则推广到任意生成分布，并用定理 6 证明证书与提议无关；但它仍留三个结构性缺口：(a) **证书没有独立的物理裁判**——铸证片段、结局验证、人工抽检都来自系统自身的执行历史，R57 的「自指回路」没有被真正打破；(b) **证书是静态的**——阈值一旦收紧就不知道它「离破裂还有多远」，也无法指出下一步该攻哪里；(c) **仿真只是实验台**——MuJoCo 在 v5 里只用来跑指标，没有进入认证回路，没有承担「攻击证书」的职责。本轮用「MuJoCo」补上独立物理裁判，用「创新点挖掘」把「发现证书缺口 → 编译为证书义务 → 提炼研究贡献」变成一条可执行流水线，主题定为「**物理可证伪的认证执行**（Physics-Falsifiable Certified Execution, PFCE）」，形成 CADVS-v6（IP-497~500）。自律延续前几轮：**硬门数量不增**（仍七门）；仿真器只准**证伪与收紧**，永不放行；执行集升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **MuJoCo → 把仿真器从「实验台」升级为「独立的证伪者」，而不是「验证者」**。直觉：v5 的证书系统像一个自己批改自己作业的学生——铸证数据、结局标签、价值自适应都来自同一闭环，R57 的病灶就在这里。MuJoCo/MJX 提供了一个**不参与学习、不读铸证数据**的物理先验：给定候选轨迹 x，它能做可微 rollout，并能沿初始状态、控制量、接触参数、模型参数搜索使安全裕度最小的扰动 δ。找到反例就是**可靠的负证据**（sound negative evidence）。关键的非对称性必须讲清楚：**证伪是可靠的，验证不是**——找到一个真实反例即可推翻证书；但「搜索不到反例」绝不等于「安全」。因此 v6 的仿真器只被允许做两件事：删候选、抬阈值。这正是 R57 缺的「外部真值」，但只是**仿真意义上的外部**，于是也埋下了本轮的新风险。

2. **创新点挖掘 → 把「发现缺口」变成「可度量的研究贡献」，而不是事后写 future work**。直觉：每一个被证伪器找到的反例都是**可复现、可定位、可度量**的缺口，比拍脑袋的「未来工作」硬得多。本轮把每个反例编译成**证书义务**（把对应门的安全裕度阈值抬高 δ_i，或在反例邻域加保护集 G），再按 (新颖度 N, 可行性 F, 覆盖增益 I) 打分，取 Pareto 前沿作为下一轮候选创新点。这样研究循环本身被算法化：**反例是原料，义务是工程产物，创新点是论文产物**。但必须立红线：创新点挖掘只产出「研究提案」，绝不产出「运行时许可」（定理 13）。

3. **Sim-to-Real → 用「裕度膨胀 + 集成一致」代替「点估计等价」**。直觉：数字孪生一定是错的，问题不是「像不像」，而是「错多少、能否定价」。做法是从系统辨识（SysID）后验抽一个孪生集成 M={m_k}，用集成直径 D(M) 估计仿真-现实偏差上界 ε_sim，并要求「仿真裕度 > ε_sim」才承认证书。这不是宣称 sim=real，而是把不可消除的模型误差**显式计入安全边际**；只有在校准域可交换、且偏差界以 1−δ 成立时，才得到条件性的迁移保证（定理 12）。

**关键洞见**：v5 回答「任意单轨迹提议器下，证书边界如何保持不变」；v6 回答「**当证书本身被一个物理预言机主动攻击、而这个预言机又只是一个会错的模型时，如何让信任仍然只减不增**」。七硬门与 v5 的定理 5~8 原样复用；本轮新增的只有：证伪预言机 MFO（IP-497）、缺口挖掘与创新台账 CGMI（IP-498）、仿真-现实裕度膨胀器 SRMI（IP-499）、装配器 EFA-v6（IP-500）。把每个门写成**规范安全裕度** g_i(x)（g_i ≥ 0 即通过，v5 的阈值/调制先折算进 g_i），则 v6 执行集为 Exec_v6 = {x ∈ Exec_v5 : min_i(g_i(x) − Δ_i^6) ≥ 0 且 x ∉ N_ε(V̂)}，其中 Δ_i^6 ≥ 0、V̂ 为已发现反例集。两条操作（抬阈值、加保护集）都只收缩，故嵌套自动成立。

**形式化目标（增量）**：
1. 规范裕度：对每个门定义连续安全裕度 g_i(x;m)，下界型取 g_i=(s_i−τ_i)/r_i、上界型取 g_i=(τ_i−s_i)/r_i，r_i 为归一化尺度；通过 iff g_i ≥ 0。鲁棒裕度 ρ(x;m)=min_i g_i(x;m)。
2. 数字孪生集成：M={m_1,…,m_n} 由 SysID 后验抽样；集成直径 D(M)=max_{k,l} sup_x |ρ(x;m_k)−ρ(x;m_l)|；仿真-现实偏差上界 ε_sim 由真实试点对做分裂共形分位数校准。
3. 证伪搜索：min_{δ∈Δ} ρ(x+δ;m)，MJX 可微梯度 + 接触处随机平滑 + CMA-ES 兜底；若 min ρ < −ε_sim 则记为**可靠反例**。
4. 缺口→义务：δ_i = clip(−min ρ_i, 0, δ_max)，保护集 G = X \ N_ε(V̂)；Δ_i^6 = Δ_i^5 + δ_i（规范裕度阈值只升不降）。
5. 创新点挖掘：缺口记录 γ=(x*,m*,δ*,i*,ρ*) → 义务 O(γ) → 候选创新点 I=(N,F,I_imp)，N=1−max cos(e_γ,e_corpus)、F 为可复现且能闭合、I_imp=Δ验证安全体积/Δ成本；取 Pareto 前沿，人工复核后才入账。
6. 定理 9（证伪可靠/验证有条件）、定理 10（单调收缩）、定理 11（挖掘覆盖下界与不完备）、定理 12（Sim-to-Real 迁移界）、定理 13（创新挖掘不可扩权）；引理 45~47（平滑梯度偏差、保护集体积、创新台账不扩权）。
7. Exec_CADVS-v6 = {x ∈ Exec_CADVS-v5 : min_i(g_i(x)−Δ_i^6) ≥ 0, x ∉ N_ε(V̂)} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**数字孪生自欺（digital-twin self-deception / sim-to-real overfitting）**——当 MuJoCo 成为唯一的「外部」裁判，优化与认证都会不可避免地朝它过拟合：证书可能只是「在 MuJoCo 里成立」，而真实接触、摩擦、柔性、传感延迟的偏差恰恰落在搜索分布之外；更危险的是「搜索不到反例」被误读成「安全」，于是 v5 的自指回路换了个更硬的外壳继续存在，集成膨胀与真实试点只能给它定价，不能证明它为零。

```python
@dataclass
class MuJoCoFalsificationOracle:
    """MFO：用 MJX 孪生集成主动攻击证书。
    红线：证伪只产生负证据；搜不到反例 ≠ 安全（定理 11 不完备）"""
    twins: list[Any]              # MJX 孪生集成 M，n=8，来自 SysID 后验
    eps_sim: float                # 仿真-现实偏差上界（SRMI 校准）
    eps_guard: float = 0.05       # 反例保护邻域半径 ε
    delta_max: float = 0.1        # 单轮裕度抬升上限
    sigma_smooth: float = 0.01    # 接触处随机平滑尺度

    def robust_margin(self, x, m) -> float:
        """ρ(x;m)=min_i g_i(x;m)：七门规范裕度的最小值"""
        g = [gate_margin_i(x, m) for i in SEVEN_GATES]   # VACK/BCK/EEK/... 复用
        return min(g)

    def _smoothed_grad(self, x, m, key=0) -> np.ndarray:
        """接触非光滑：对 ρ 做高斯平滑 ρ_σ=E_u ρ(x+σu)，
        用重参数化 u=σz, z~N(0,I) 的反向传播估计 ∇ρ_σ（引理 45）"""
        z = randn_like(x)
        return grad(lambda xx: self.robust_margin(xx + self.sigma_smooth * z, m), x)

    def falsify(self, x0, m, seeds_from_bck: list | None = None) -> Gap | None:
        """分层搜索 min_{δ∈Δ} ρ(x0+δ;m)：
        1) MJX 可微投影梯度（平滑后）；2) 接触拓扑变更点重启；
        3) CMA-ES 兜底（无梯度/强非光滑）。
        仅当 min ρ < −eps_sim 才返回『可靠反例』（定理 9）"""
        seeds = [x0] + (seeds_from_bck or [])
        best = min((self._local_search(s, m) for s in seeds), key=lambda r: r.rho)
        if best.rho >= -self.eps_sim:
            return None                      # 不确定，不是可靠反例
        i_star = argmin_i([gate_margin_i(best.x, m) for i in SEVEN_GATES])
        return Gap(x=best.x, m=m, delta=best.delta, gate=i_star, rho=best.rho)

    def certify_negative(self, gap: Gap) -> bool:
        """复核：换用 held-out 孪生重放，仍 < −eps_sim 才入 V̂（防单模型伪反例）"""
        return all(self.robust_margin(gap.x, m_k) < -self.eps_sim
                   for m_k in self.heldout_twins)

    def guard(self, V_hat: set) -> GuardSet:
        """G = X \\ N_ε(V̂)：保护集只排除，不新增允许域"""
        return GuardSet(exclude=union(ball(g.x, self.eps_guard) for g in V_hat))
```

### IP-499 SRMI：仿真-现实裕度膨胀器（校准离线；在线只读 ε_sim）

```python
@dataclass
class SimToRealMarginInflator:
    """SRMI：把模型误差定价成安全边际。
    只给 ε_sim，不宣称 sim=real（定理 12 条件性）"""
    twins: list[Any]              # SysID 后验集成
    alpha: float = 0.05           # 共形显著性（目标 1−alpha 覆盖）

    def ensemble_diameter(self, probe_set) -> float:
        """D(M)=max_{k,l} sup_x |ρ(x;m_k)−ρ(x;m_l)|，probe_set 分层覆盖"""
        return max(abs(self._rho(x, mk) - self._rho(x, ml))
                   for x in probe_set for mk in self.twins for ml in self.twins)

    def calibrate(self, real_pairs) -> float:
        """真实试点对 {(x_j, ρ_real_j)}：非一致性分数
        s_j = max_k |ρ_real_j − ρ(x_j; m_k)|，取分裂共形上分位数 → ε_sim"""
        scores = [max(abs(r - self._rho(x, mk)) for mk in self.twins)
                  for x, r in real_pairs]
        return conformal_quantile(scores, self.alpha)       # 有限样本 1−alpha

    def inflated_threshold(self, Delta5: dict, D: float) -> dict:
        """在线只读：Δ^6_i = Δ^5_i + clip(ε_sim 归一化项, 0, δ_max)"""
        return {i: d + clip(self.eps_sim, 0, self.delta_max) for i, d in Delta5.items()}
```

```python
    工程含义：接触处的梯度可信到 O(σ) 尺度，σ 以下必须 CMA-ES 兜底。
```

### IP-500 EFA-v6：七硬门冻结 + 证伪过滤 + 保护集 + 裕度膨胀

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：v5 全套七门与级联原样复用；只加『收缩型』前置过滤"""
    v5: EvidenceForgingAssemblerV5
    mfo: MuJoCoFalsificationOracle
    cgmi: CertificateGapMinerInnovationLedger
    srmi: SimToRealMarginInflator
    guard: GuardSet
    Delta6: dict                  # 每周期预计算：Δ^6 = Δ^5 + δ（只升）

    def select(self, x0_state, t_now, rule_id, context):
        # 1) v5 原样产出候选（七门 + 级联 + 情感调制）
        ok, x, reason = self.v5.select(x0_state, t_now, rule_id, context)
        if not ok:
            return False, None, reason
        # 2) 保护集过滤：落在已知反例邻域 → fail-closed 回退 v5 规则提议
        if x in self.guard:
            return self.v5.fallback_rule_proposal(context)
        # 3) 裕度膨胀：用最保守孪生复核，要求 ρ_sim ≥ ε_sim
        rho = min(self.mfo.robust_margin(x, m) for m in self.srmi.twins)
        if rho < self.srmi.eps_sim:
            return self.v5.fallback_rule_proposal(context)
        # 4) 规范阈值复核（等价 v5 门 + v6 抬升），取边际最大者由 v5 完成
        return True, x, 'FORGED_PFCE'

    def ecs_v6(self, ecs5: float, rho_min: float, D: float) -> float:
        eta_fals = sigmoid((rho_min - self.srmi.eps_sim) / BETA_F)
        eta_sim = math.exp(-D / D0)
        return ecs5 * eta_fals * eta_sim

    def offline_round(self, episodes, real_pairs):
        """离线闭环：证伪 → 挖缺口 → 编义务 → 校准 → 回归红队 → 上线/回滚"""
        self.srmi.eps_sim = self.srmi.calibrate(real_pairs)
        gaps = [g for ep in episodes
                if (g := self.mfo.falsify(ep.x0, sample_twin(self.srmi.twins)))
                and self.mfo.certify_negative(g)]
        cands = self.cgmi.mine(gaps)                    # 人工复核后入账
        for c in cands:
            self.Delta6[c.ob.gate] += c.ob.delta         # 只升
        self.guard = self.mfo.guard({g.x for g in gaps}) # 只缩
        assert regression_redteam_pass(self)             # 不通过则回滚
```

## 4. 正确性论证（增量更新）

### 引理 45（接触随机平滑的梯度偏差）
若 g 在 N_σ(x) 内局部 L-Lipschitz，则平滑裕度 g_σ=E_u g(x+σu) 满足 |g_σ(x)−g(x)| ≤ Lσ，且 ∇g_σ 为 L-Lipschitz；重参数化反向传播给出 ∇g_σ 的无偏估计。故 MFO 的梯度搜索只保证找到 σ-近似局部极小，σ 以下（强非光滑/接触切换）必须由 CMA-ES 兜底。∎

### 引理 46（保护集体积与收缩预算）
若 V̂ 有限、每个反例保护球半径 ε，则 vol(G^c) ≤ |V̂|·vol(B_ε)。加保护集造成的执行集收缩量有可审计上界，不会无界塌缩。∎

### 引理 47（创新台账不扩权）
CGMI 输出只进入 (a) Δ 单调抬升、(b) G 单调收缩、(c) 研究提案；三者都不修改门谓词、不降低 Δ、不扩大 X\G。故创新挖掘不改变信任边界。∎

### 定理 9（证伪可靠 / 验证条件性）
在一致偏差界 sup_x |g_real−g_sim| ≤ ε_sim 下：(i) g_sim < −ε_sim ⇒ g_real < 0（可靠反例）；(ii) g_sim ≥ ε_sim ⇒ g_real ≥ 0（条件验证）；(iii) 偏差界失效或只在校准域成立时，(ii) 失效，「搜不到反例」不构成任何保证。证明：三角不等式逐点推出；逻辑否定。∎

**诚实边界**：MuJoCo 给的是「无条件证伪 + 条件性验证」，不是无条件安全证明。v5 的自指回路被换成了「仿真裁判」，但裁判本身是模型。

### 定理 10（单调收缩）
若 v6 相对 v5 仅 (a) Δ_i^6 ≥ Δ_i^5、(b) 支撑限制到 G ⊆ X，则 Exec_v6 ⊆ Exec_v5。证明：超水平集随阈值单调缩，再交 G 只会更小。∎

### 定理 11（挖掘覆盖下界与不完备）
V̂ ⊆ V，故 vol(V̂) ≤ vol(V)：发现量是真实违例的体积下界；但接触动力学非光滑、最坏情形下接触轨迹裕度全局最小化无多项式保证，故 Cov_Q(V)=vol(V∩Q)/vol(V) 只是搜索分布 Q 下的经验覆盖率，不构成完备性；报告必须同时给出 Q 的分层覆盖与未覆盖区。∎

### 定理 12（Sim-to-Real 迁移界）
若 ε_sim 由真实试点对的分裂共形分位数在水平 α 校准，且部署上下文与校准集可交换，则 P(g_real < 0 | g_sim ≥ ε_sim) ≤ α。证明：标准分裂共形覆盖 + 定理 9(ii)。∎

**诚实边界**：可交换性一旦被分布漂移破坏（新物体/新接触/新传感），覆盖保证失效；必须在线共形跟踪并允许回退 v5。

### 定理 13（创新挖掘不可扩权）
CGMI 的任何输出都不能扩大 Exec_v6：义务只抬 Δ/加 G，创新点只是台账条目。故「挖掘创新」与「授予信任」在结构上分离。∎

### 定理 v6（物理可证伪执行的总装）
**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 一致偏差界 / 共形可交换性下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5（严格：当 Δ^6 > 0 或 V̂ ≠ ∅）；
(ii) 证伪可靠、验证条件性（定理 9）；
(iii) 收缩单调（定理 10）；
(iv) 挖掘覆盖只是下界、不完备（定理 11）；
(v) 迁移界条件性成立（定理 12）；
(vi) 创新挖掘不扩权（定理 13）。
**证明**：由定理 9~13 与引理 45~47 直接合成。∎

**诚实声明**：(B8) 是新增的**条件性**假设，不是定理能消除的；仿真-现实偏差界只在校准域、可交换、有限样本意义下成立；MuJoCo 的反例搜索不完备；创新点挖掘的「新颖度」是启发式评分，可能产出可发表但无用的贡献。
