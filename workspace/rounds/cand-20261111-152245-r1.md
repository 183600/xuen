# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「步态规划」×「数据标注」）

> 第 54 轮把技能组合升级为动作-鲁棒性双证书（ACS×SCOM×CEC×AEC×JTC）。本轮补上两个被忽略的第一性问题：**动作在时间上的周期性结构（步态）** 与 **定义动作/鲁棒性标签本身的可信度（数据标注）**。核心矛盾：H22：v54 的 α_S 是静态占用，缺少相位顺序，组合在“空间兼容”下仍可能因相位错位（支撑相 vs 摆动相）而不可执行；H23：α_S、θ_a、ρ 的根因标签都来自标注，标注歧义与标注者不一致会直接污染证书 soundness，而现有体系把标签当作无噪声真值。

## 0. 直觉与动机

**灵感 1（步态=动作空间上的极限环 → 相位化动作剖面）**
直觉：对足式/接触式具身，技能不是动作集合的静态占用，而是一条周期轨迹——支撑相、摆动相、落足事件按相位 φ∈S¹ 循环。把 v54 的 `α_S(a)` 升级为 `α_S(a,φ)`，组合匹配必须同时满足“动作空间重叠”和“相位对齐”。直觉上，两个技能即使动作集合几乎相同，如果一个要求支撑相出力、另一个要求腾空相出力，组合仍会在接触瞬间崩掉。

**灵感 2（步态图与相位锁定 → 转换成本是一等公民）**
直觉：技能间还存在“步态切换”——走→小跑→跳。切换不是瞬时的，需要过渡步态与相位锁定窗口。把步态建为图 `G_gait`，边权包含相位距离、周期差、稳定性差。组合规划因此是在“技能图 × 步态图”的乘积图上搜索，而不是单层技能图。

**灵感 3（相位转换带三重重合 → 本轮的关键洞察）**
直觉：步态相位转换带（触地/离地瞬间）同时是：①动作冲突高发区（两个技能的相位包络在此交叠最尖锐）；②标注歧义高发区（“何时算触地”本身有毫秒级主观模糊，标注者间一致性最低）；③鲁棒性最脆弱区（接触切换时最易失稳）。三者重合意味着 **证书在最需要它的地方最不可信**。这要求把“标注可信度”和“相位鲁棒性”联合起来，而不是分别优化。

**灵感 4（数据标注=证书的元证据 → 标注可信剖面）**
直觉：`α_S`、`θ_a`、`ρ` 的根因都来自标签（地形类别、接触事件、失败原因）。标签不是真值，而是带标注者、置信、时效、证据的“证据对象”。定义标注可信剖面 `β_L : 𝒴×A_φ → [0,1]`，由标注者间一致性 κ、多标注一致率、时效衰减合成。**动作交集只有在标签可信时才算数**：`compat_L = compat ∧ [β_L(A_i∩A_j) ≥ θ_lab]`。

**灵感 5（证书驱动的主动标注 → 把标注预算花在会翻转证书的样本上）**
直觉：传统主动学习按模型不确定度采样；这里应按 **证书翻转风险** 采样——优先标注那些“多一个标签就可能把某条组合边从可行翻成不可行（或反之）”的边界样本，尤其是相位转换带。这把标注从“训练数据工程”变成“证书可信度预算分配”。

**灵感 6（标注感知的 Explain → 区分模型错与标签错）**
直觉：v53–v54 的 Explain 把失败归因为动作/维度根因，但从未考虑“根因标签本身可能是错的”。增广 Explain 的根因类型为 `{model, annotation, action}`：当 β_L 低于阈值时，优先报“标注根因”，避免用坏标签去修好模型（负迁移的隐形来源）。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（相位化动作剖面）**
时空动作空间 `A_φ = A × S¹`，相位 `φ∈S¹`，`φ=0` 为触地、`φ=π` 为腾空。技能 S 的相位化剖面 `α_S : A×S¹ → [0,1]`，`∫_{A×S¹} α_S = vol_φ(S)`。任务给出相位包络 `A_T(φ)`。覆盖 `cover_φ(S,A_T)=1 ⟺ ∀φ, ∀a∈A_T(φ): α_S(a,φ) ≥ θ_cov`。

**定义 122（步态原语与步态图）**
步态原语 `g=(P_g, Φ_g, F_g, T_g)`：支撑/摆动占空比、相位偏移向量、落足调度、周期。步态图 `G_gait=(𝒢,E_g)`，边权
`c_gait(g_i,g_j)=w_φ·d_φ(Φ_i,Φ_j)+w_T·|T_i-T_j|+w_s·Δstab(g_i,g_j)`。
相位锁定条件 `lock(g_i,g_j)=1 ⟺ ∃φ: α_{g_i}(·,φ)∩α_{g_j}(·,φ) ≠ ∅`；不满足则必须插入过渡步态。

**定义 123（相位条件鲁棒性与周期鲁棒性）**
`ρ_S(d,φ)` 为维度 d 在相位 φ 下的鲁棒性；周期鲁棒性 `ρ^cyc_S(d)=min_{φ∈S¹} ρ_S(d,φ)`。步态稳定性由 Poincaré 返回映射 `P:Σ→Σ` 的谱半径给出：`ρ^stab_S = 1-σ(P)`，要求 `σ(P)<1`。

**定义 124（标注对象与标注可信剖面）**
标注 `ℓ=(x,y,u,c,τ,e)`：样本、标签、标注者 u、置信 c、时间 τ、证据 e。标注集 L。标注可信剖面
`β_L(y,a)=κ_L(y)·agree_L(y,a)·fresh_L(τ)`，
其中 κ_L 为 Fleiss' κ，agree 为多标注一致率，fresh 为时效衰减。可信覆盖 `cover_L(A_T)=1 ⟺ ∀(y,a)∈A_T: β_L(y,a) ≥ θ_lab`。标注误差上界由 κ 与有效样本量 n 的置信区间给出：`ε_lab = UCB_{1-α}(error | κ_L, n)`。

**定义 125（标注感知的动作兼容性与联合证书）**
`compat_L(S_i,S_j)=compat(S_i,S_j) ∧ [min_{a∈A_i∩A_j} β_L(y(a),a) ≥ θ_lab]`。证书扩展为 `C_comp^L=(A_overlap, ρ^cyc_comp, γ_ce, β_L|_{A_overlap}, ε_lab, evidence_L)`。

**定义 126（步态-标注联合证书 GAJC）**
`J^GA=(g, Φ_g, ρ^cyc, ρ^stab, A_cert, β_L, ε_lab, γ_ce, δ_a, evidence)`。部署可判定：
```
dom_{J^GA}(T)=in
∧ δ_a < Θ_a
∧ ρ^cyc(d) ≥ ρ_min(d) ∀d
∧ σ(P) < 1
∧ ε_lab ≤ Θ_lab
```

## 2. 关键算法 伪代码

### IP-121 GPA（Gait Phase Action）

```python
def phased_profile(skill, A, phases, sampler, beta_L, theta_lab):
    alpha = {}
    for phi in phases:
        for a in A:
            lab_key = (label_of(a), a)
            if beta_L.get(lab_key, 0.0) < theta_lab:
                alpha[(a, phi)] = None          # 标注不可信 → 剖面未定义，不得默认可行
                continue
            feas, conf = sampler.query(skill, a, phi)
            alpha[(a, phi)] = conf if feas else 0.0
    return alpha

def cover_phase(alpha, A_T_phi, theta_cov=0.8):
    return all(alpha.get((a, phi)) is not None
               and alpha[(a, phi)] >= theta_cov
               for phi in A_T_phi for a in A_T_phi[phi])
```

### IP-122 GTG（Gait Transition Graph）

```python
def build_gait_graph(gaits, alpha, theta_phi):
    G = nx.DiGraph()
    for gi in gaits:
        for gj in gaits:
            if gi.id == gj.id:
                continue
            overlap = phase_overlap(alpha[gi.id], alpha[gj.id])
            c_g = (w_phi * phase_distance(gi.Phi, gj.Phi)
                   + w_T * abs(gi.T - gj.T)
                   + w_s * stability_gap(gi, gj))
            if overlap >= theta_phi:
                G.add_edge(gi.id, gj.id, cost=c_g, phase_overlap=overlap)
    return G           # 组合规划在 G_S × G_gait 乘积图上做 A*

def compose_plan(G_comp, G_gait, task):
    return a_star(product_graph(G_comp, G_gait), start=task.start, goal=task.goal,
                  heuristic=lambda n: cost_align(n) + gait_heuristic(n))
```

### IP-123 LTP（Label Trust Profile）

```python
def label_trust(annotations, tau_half, now):
    kappa = fleiss_kappa(annotations)
    beta, ess = {}, {}
    for (y, a), items in group_by(annotations, lambda l: (l.y, l.a)):
        agree = max(Counter(l.value for l in items).values()) / len(items)
        fresh = exp(-(now - median(l.tau for l in items)) / tau_half)
        beta[(y, a)] = kappa * agree * fresh
        ess[(y, a)] = len(items)                 # 有效样本量
    return beta, ess

def epsilon_label(beta, ess, alpha=0.05):
    # 用 κ 与有效样本量给标注误差上界（Clopper–Pearson 型保守界）
    return {k: clopper_pearson_upper(1 - beta[k], ess[k], alpha) for k in beta}
```

### IP-124 AAC（Active Annotation Certifier）

```python
def active_annotate(alpha_hat, beta, ess, G_comp, budget):
    # 采集函数不是模型不确定度，而是“证书翻转风险”
    queue = []
    for (i, j) in G_comp.edges:
        for (a, phi) in phase_boundary(alpha_hat[i], alpha_hat[j]):
            flip = (compat_flip_prob(a, phi, alpha_hat, theta_a)
                    + robustness_flip_prob(a, phi, alpha_hat, rho_min))
            info = (flip * (1.0 - beta.get((label_of(a), a), 0.0))
                    * ess.get((label_of(a), a), 1) ** -0.5)
            queue.append((info, (a, phi, label_of(a))))
    queue.sort(key=lambda t: t[0], reverse=True)
    return queue[:budget]        # 优先标注相位转换带与证书边界样本
```

### IP-125 GAJC（Gait-Annotation Joint Certificate）

```python
def gait_annotation_certificate(skill_seq, gait, gamma_ce, beta_L, ess, budgets):
    rho_cyc = {d: min(phase_rho(skill_seq, d, phi) for phi in gait.phases) for d in DIMS}
    sigma_P = spectral_radius(poincare_map(skill_seq, gait))
    eps_lab = epsilon_label(beta_L, ess)
    if min(rho_cyc.values()) < budgets.rho_min:      return ('reject', 'robustness')
    if sigma_P >= 1.0:                               return ('reject', 'unstable_gait')
    if max(eps_lab.values()) > budgets.theta_lab:    return ('reject', 'annotation_untrusted')
    band = transition_band(gait)                     # 三重重合区
    if min(beta_L.get(k, 0.0) for k in band) < theta_lab:
        return ('reject', 'transition_band_untrusted')
    delta_a = max_alignment_error(gamma_ce, gait.A_core)
    if delta_a > budgets.delta_a:                    return ('reject', 'action_mismatch')
    return ('ok', GAJC(gait, rho_cyc, sigma_P, beta_L, eps_lab, delta_a))
```

### IP-126 ALX（Annotation-aware eXplanation）

```python
def explain_with_annotation(failure, sim_model, beta_L, theta_lab):
    cause = explain_failure(failure, sim_model)
    lab = cause.root_label
    if lab is not None and beta_L.get((lab.y, lab.a), 0.0) < theta_lab:
        return Cause(kind='annotation', label=lab,
                     evidence=disagreement_evidence(lab),
                     suggestion='relabel_before_repair')  # 先修标签，别修模型
    if cause.kind == 'unmodeled_dynamics':
        return Cause(kind='model', cause=cause)
    return Cause(kind='action', cause=cause)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| GPA | O(|S|·|A|·|Φ|) | O(|A|·|Φ|) | 相位覆盖 ≥ 95%；不可信标注不得默认可行 |
| GTG | O(|𝒢|²·|Φ|) | O(|𝒢|²) | 相位锁定 exists 判定 sound |
| LTP | O(n_ann + |𝒴|·|A|) | O(|𝒴|·|A|) | κ 估计无偏、时效单调 |
| AAC | O(|E|·|Φ|·log|E·Φ|) | O(|E|·|Φ|) | 翻转风险上界、贪心近似 submodular |
| GAJC | O(|S|·|Φ|·|𝔇|) | O(|A|·|Φ|) | 误差界保守、三带联合判定 |

**正确性定理（Gait-Annotation Joint Soundness）**
承接 (A22)–(A28)；新增 **(A29)** 步态相位由接触事件分割且相位对齐误差 ≤ δ_φ；**(A30)** 标注误差上界 `ε_lab` 由 κ_L 与有效样本量给出的置信界保守覆盖真实误差；**(A31)** Poincaré 谱半径估计的偏差 ≤ δ_P。则
```
P_success ≥ 1 - Σ_d (1-ρ^cyc_min(d)) - (1-σ(P)) - P(δ_a>Θ_a) - β_E - ε_lab - ε_φ
```
其中 `ε_φ = L_φ·δ_φ` 为相位对齐误差传播项。关键：**证书在相位转换带也 sound**，因为该处同时受 ρ^cyc 与 β_L 双重约束；标注误差不再被当作零。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 接触事件的相位标注主观歧义 | 高 | 多标注 + κ 门控 + 事件级证据（力/IMU） |
| 相位对齐误差 δ_φ 累积 | 高 | 相位锁定检测 + 过渡步态插入 + 在线重同步 |
| β_L 与模型自证循环（标签验证标签） | 高 | 独立标注源 + 金标准抽样 + 标注者盲化 |
| Poincaré 谱半径小样本偏差 | 中 | 自助法置信区间 + 保守 δ_P |
| 主动标注只追证书边界导致长尾盲区 | 中 | ε-greedy 探索 + 覆盖度约束 |
| 跨具身步态原语不对齐 | 高 | 步态本体共享 + 相位归一化 + 迁移绊线 |

## 6. 本轮最大风险

**一句话**：把步态相位与标注可信度引入证书，使“空间兼容”升级为“相位-标注-鲁棒性三重可判定”，但其 soundness **同时依赖相位对齐精度、标注误差界的保守性、以及两者在转换带的联合判定**；一旦相位分割与标注歧义在转换带同向放大，证书会在最需要它的接触瞬间既不可信又看似可信，故必须以 **事件级多源标注 + κ/ε_lab 硬门控 + 转换带专项绊线** 三重护栏，宁可拒绝组合，也不把“相位-标注双重假象”当作部署前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（GPA×GTG×LTP×AAC×GAJC×ALX）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书之上，增加 **时间周期性（步态）** 与 **标签可信度（数据标注）** 两个第一性维度：

```python
        fresh = exp(-(now - median(l.tau for l in items)) / tau_half)
        beta[(y, a)] = kappa * agree * fresh
        ess[(y, a)] = len(items)
    return beta, ess

def epsilon_label(beta, ess, alpha=0.05):
    return {k: clopper_pearson_upper(1-beta[k], ess[k], alpha) for k in beta}
```

```python
def gait_annotation_certificate(skill_seq, gait, gamma_ce, beta_L, ess, budgets):
    rho_cyc = {d: min(phase_rho(skill_seq, d, phi) for phi in gait.phases) for d in DIMS}
    sigma_P = spectral_radius(poincare_map(skill_seq, gait))
    eps_lab = epsilon_label(beta_L, ess)
    if min(rho_cyc.values()) < budgets.rho_min:  return ('reject', 'robustness')
    if sigma_P >= 1.0:                            return ('reject', 'unstable_gait')
    if max(eps_lab.values()) > budgets.theta_lab: return ('reject', 'annotation_untrusted')
    band = transition_band(gait)
    if min(beta_L.get(k, 0.0) for k in band) < theta_lab:
        return ('reject', 'transition_band_untrusted')
    delta_a = max_alignment_error(gamma_ce, gait.A_core)
    if delta_a > budgets.delta_a:                return ('reject', 'action_mismatch')
    return ('ok', GAJC(gait, rho_cyc, sigma_P, beta_L, eps_lab, delta_a))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GPA | O(|S|·|A|·|Φ|) | O(|A|·|Φ|) | 相位覆盖 ≥ 95%；不可信标注不默认可行 |
| GTG | O(|𝒢|²·|Φ|) | O(|𝒢|²) | 相位锁定 exists 判定 sound |
| LTP | O(n_ann+|𝒴|·|A|) | O(|𝒴|·|A|) | κ 无偏、时效单调 |
| AAC | O(|E|·|Φ|·log|E·Φ|) | O(|E|·|Φ|) | 翻转风险上界、贪心近似 submodular |
| GAJC | O(|S|·|Φ|·|𝔇|) | O(|A|·|Φ|) | 误差界保守、三带联合判定 |

**正确性定理（Gait-Annotation Joint Soundness）**
承接 (A22)–(A28)；新增 **(A29)** 相位由接触事件分割且对齐误差 ≤ δ_φ；**(A30)** `ε_lab` 置信界保守覆盖真实标注误差；**(A31)** Poincaré 谱半径估计偏差 ≤ δ_P。则
```
P_success ≥ 1 - Σ_d(1-ρ^cyc_min(d)) - (1-σ(P)) - P(δ_a>Θ_a) - β_E - ε_lab - ε_φ
```
其中 `ε_φ=L_φ·δ_φ`。关键：**证书在相位转换带仍 sound**——该处同时受 `ρ^cyc` 与 `β_L` 双重约束；标注误差不再被当作零。

## 5. 本轮最大风险

**一句话**：把步态相位与标注可信度引入证书，使“空间兼容”升级为“相位-标注-鲁棒性三重可判定”，但其 soundness **同时依赖相位对齐精度、标注误差界的保守性、以及两者在转换带的联合判定**；一旦相位分割与标注歧义在转换带同向放大，证书会在最需要它的接触瞬间既不可信又看似可信，故必须以 **事件级多源标注 + κ/ε_lab 硬门控 + 转换带专项绊线** 三重护栏，宁可拒绝组合，也不把“相位-标注双重假象”当作部署前提。
