# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；新一轮灵感循环第 1 轮；本轮灵感：「ROS2」×「UniBot」）

> 第 60 轮的 SGEC 已经把「场景→意图→约束→阻抗→执行→EV-exec→场景」串成闭环，并用 EPIR 处理了 ROS 消息的乱序/丢失。但它默认了一个**从未被言明的强假设**：策略、执行器、证据链都跑在**同一个 ROS 域、同一台机器、同一个时钟**里，网络只被当作「消息会不会丢」的问题。UniBot 世界挑战赛的真实形态打破了这一假设：**策略跑在参赛者自己的服务器上，评测器以 WebSocket（msgpack）作为客户端连入，N 台真机通过不同端口并发查询同一套推理后端**；官方还记录响应延迟、延迟稳定性与**动作规律性**。于是执行闭环实际跨越了三个互不信任的域：
> 1. **ROS2 机器人域（D1）**：DDS/QoS、executor 调度、ros2_control，受实时约束但时钟本地；
> 2. **网络传输域（D2）**：WebSocket + msgpack，可重连、可重放、可拥塞，时钟不可比；
> 3. **策略推理域（D3）**：远端多租户服务，N 个端口共享算力，状态必须按 episode 隔离。
>
> 三个结构性缺口：
> 1. **证据可靠性仍靠应用层打补丁**：第 60 轮的 EPIR 在应用层自己加 `seq_id + SHA256`，而 ROS2/DDS 本就有 Reliability/Durability/Deadline/Liveliness 的**中间件级契约**。继续在应用层叠协议，等于放弃 DDS 已能提供的确定性，也无法表达「安全证据的传递延迟必须小于 D0」这类时序语义。
> 2. **意图锁定的时序保证并不成立**：CIEC 假设约束锁定是 O(1)、一个周期内生效；但 ROS2 原生 executor 没有优先级继承、没有 EDF，一个重推理/重日志回调就能把安全回调挤到 τ_response 之后，造成「意图已下达、执行未生效」。
> 3. **跨域因果与多租户隔离被忽略**：EV-exec 在 D1、ACK 在 D2、action chunk 在 D3；WebSocket 重连后 seq 可能重放，N 个端口共享后端时一个端口的慢推理会拖垮另一个端口的延迟稳定性，而「动作规律性」正是 UniBot 的评分维度。第 60 轮的单域 EPIR 对此无能为力。

一句话先给押注：

> **第 60 轮解决「同一 ROS 域内的场景-执行闭环」；本轮把它升级为「跨域执行契约闭环 CDEC（Cross-Domain Execution Contract）」：用 ROS2 的 QoS 契约（QCEB）承载证据可靠性，用确定性执行器分区（DEP）兑现意图锁定时序，用多租户隔离与动作承诺（MPIAR）守住 UniBot 的并发与动作规律性，用跨域向量时钟证据链（CDCE）把 D1/D2/D3 的 happens-before 缝合起来。核心命题：可靠性来自中间件契约，时序来自调度证明，规律性来自动作承诺，因果完整性来自跨域逻辑时钟。**

## 0. 直觉与动机

**灵感 1（ROS2 的 QoS → 证据 QoS 契约总线 QCEB）**
直觉：第 60 轮的 EPIR 像一个「在快递盒上再贴一张手写编号」的人——而 DDS 快递公司本来就有「保价、限时达、签收、存活心跳」。ROS2 的 QoS 六元组（Reliability / Durability / Deadline / Liveliness / History / Depth）就是**可运行时监控的契约**。关键洞见：**先给证据分级，再让最重的证据走最硬的 QoS**。安全证据 E0（急停、ERTC 锁定确认、EV-exec 根）必须 `RELIABLE + TRANSIENT_LOCAL + Deadline D0 + Liveliness`；感知观测 E1 允许重传但可丢部分；诊断遥测 E2 可 `BEST_EFFORT`。并且 **QoS 违约不是「调大缓存」的理由，而是「证书降置信」的触发**：安全证据只能变慢，不能变成「不可靠却假装可靠」。

**灵感 2（ROS2 executor → 确定性执行器分区 DEP）**
直觉：ROS2 的 executor 是一个「没有 VIP 通道的食堂」：回调各自排队，谁先抢到线程谁先跑。要把 CIEC 的意图锁定从「经验上很快」变成「可证的上界」，必须给安全回调一个**带优先级天花板的独立窗口**。关键洞见：**把 τ_response 从测量值变成响应时间分析（RTA）的定理**——只要安全分区利用率 U_s<1 且优先级天花板封住阻塞，`R_c ≤ D_c` 就可离线证明，而不是祈祷重推理回调恰好没来。

**灵感 3（UniBot 多端口评测 → 多租户隔离与动作承诺 MPIAR）**
直觉：UniBot 让 N 台真机从 8765 起的 N 个端口并发敲同一台服务器。任何「全局上下文」「共享缓存」「一把大锁」都会把 A 机器人的慢推理传染给 B 机器人；而评测还看**动作规律性**——如果每个新观测到来就整块重规划，动作会抖成「锯齿」。关键洞见：**规律性来自承诺，而不是来自更快的重规划**。用「动作块承诺 ACL」：块内要重规划，新块首动作必须落在上一块续接的信赖域内；否则宁可 commit-and-hold 到块尾，也不输出互相矛盾的动作。多租户则用**无共享可变状态 + 预留服务份额**给出隔离上界。

**灵感 4（跨域因果 → 跨域证据链 CDCE）**
直觉：第 60 轮的 EPIR 用「单域 seq + 时间戳」判断因果；一旦跨越 DDS→WebSocket→Python 服务三层，墙钟不可比、重连会重放、端口会复用，单域序号立刻失效。必须用**向量时钟**把「机器人执行、网络确认、策略出块」三域的 happens-before 织成偏序图。关键洞见：**当因果不确定时，正确动作不是「猜一个最可能的顺序」，而是硬失败到安全停止**——一句「链可能断了」绝不能被一张「哈希看起来对」的证书掩盖。

**灵感 5（五灵感合流 → 跨域执行契约闭环 CDEC + 七维预算 PCE++++++）**
直觉：D1 用 QCEB 选 QoS，用 DEP 保时序；D2 用 CDCE 记因果，用 NES 选动作块长 H；D3 用 MPIAR 隔租户、守规律性；三者由 CEC 跨域执行证书绑定。预算从第 60 轮的四维扩为七维：`B_scene/B_intent/B_ros/B_exec/B_net/B_qos/B_iso`。降级阶梯遵循一条铁律：**任何一维耗尽只会降低性能或证书置信，绝不扩大安全执行集**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（证据 QoS 契约总线 QCEB）** 证据分级与 QoS 契约 ω = (E, q_min, QoS_sat, mon, esc)。其中：
- **证据等级** E = E0 ∪ E1 ∪ E2：E0 为安全证据（ERTC 锁定确认、急停、EV-exec 根、证书哈希），E1 为感知观测（力/位/场景/视觉），E2 为诊断遥测（日志、可视化、统计）。
- **QoS 元组** Q = (r, d, D, ℓ, h, k)，分别为 Reliability、Durability、Deadline、Liveliness lease、History、Depth。
- **最小契约** q_min(E)：E0 → `(RELIABLE, TRANSIENT_LOCAL, D0, ℓ0, KEEP_ALL)`；E1 → `(RELIABLE, VOLATILE, D1, ℓ1, KEEP_LAST k1)`；E2 → `(BEST_EFFORT, VOLATILE, D2, ℓ2, KEEP_LAST k2)`。
- **可满足性** `QoS_sat(Q,E) ⟺ r ≽ r_min(E) ∧ d ≽ d_min(E) ∧ D ≤ D_max(E) ∧ ℓ ≤ ℓ_max(E) ∧ k ≥ k_min(E)`（`≽` 表示「不弱于」）。
- **运行时监控** mon 统计 `(deadline_missed, liveliness_lost, sample_lost, incompatible_qos)`，每个窗口 W_mon 聚合一次。
- **升级阶梯** esc：E0 违约 → E0 切到独立 executor、增大 depth、暂停 E2 发布；仍违约 → 将 EV-exec 标记 `degraded_evidence` 并下调 CEC 置信，但**绝不把 E0 降级为 BEST_EFFORT**。
- **证书约束**：任何执行证书必须携带 `QoS_sat` 向量；缺失 `QoS_sat(E0)` 的证书一律视为无效（fail-closed）。

**定义 162（确定性执行器分区 DEP）** 设回调集合 C 划分为安全分区 P_s = {ERTC.lock, safety_stop, EV_exec.append, deadline_check} 与尽力分区 P_b = {规划、日志、可视化、学习更新}。每个 c∈C 有 WCET C_c、周期 T_c、相对截止 D_c：
- **调度**：P_s 采用固定优先级 + 优先级天花板协议（PCP），或 EDF；P_b 不得继承 P_s 线程。
- **响应时间上界**（RTA）：
  `R_c = C_c + Σ_{h∈hp(c)} ⌈R_c/T_h⌉·C_h + B_c`，其中 B_c 为低优先级任务经优先级天花板造成的最大阻塞。
- **可调度条件**：`∀c∈P_s: R_c ≤ D_c`，且安全分区利用率 `U_s = Σ_{c∈P_s} C_c/T_c < 1`。
- **隔离度**：若 P_s 与 P_b 共享线程池，则记为 `Iso=0`（存在无界干扰）；DEP 要求 P_s 至少独占 `⌈U_s⌉` 个线程并绑定 `SCHED_FIFO`，或使用独立 executor，此时 `Iso=1` 且 P_b 对 P_s 的干扰上界为 0。
- **结论**：CIEC 的 `τ_response = max_{c∈P_s} R_c` 从「经验值」升格为「可证界」，锁定生效 ≤ τ_deadline。

**定义 163（多租户策略隔离与动作承诺 MPIAR）** 租户 t_i = (port_i, episode_i, S_i)，i=1..N：
- **状态** S_i = (obs_hist_i, last_chunk_i, reset_epoch_i, model_ctx_i)。
- **隔离不变量**：任意 i≠j，S_i 与 S_j 无共享可变引用；`reset(port_i)` 只递增 episode_i、清空 S_i，对 S_j 恒等。
- **服务份额**：每租户预留份额 s_i，`Σ_i s_i ≤ 1`；队列等待上界 `W_i ≤ B_i/s_i + C_max`（B_i 为到达突发，C_max 为单次推理上界）。
- **动作块** A_t = (a_{t,1},…,a_{t,H})，执行周期 Δ；第 k 步已完成时收到新块 A_{t+1}。
- **动作承诺 ACL**：若块内重规划，则要求 `‖a_{t+1,1} − a_{t,k+1}‖_Σ ≤ ε_acl`；若不满足，则不切换，继续执行到块尾（commit-and-hold），或显式触发 `ACTION_REPLAN` 并在证书中记录（后者仍受 ε_acl 约束，超出即拒绝）。
- **规律性度量**：`J = Σ_t ‖a_{t+1}−2a_t+a_{t−1}‖²/Δ⁴`（jerk 能量）、`C_acl`（块间续接一致率）、`σ_L`（延迟抖动）；UniBot 的动作规律性以 `Reg = 1/(1+J) · C_acl · 1/(1+σ_L/L̄)` 的复合形式估计。

**定义 164（跨域因果证据链 CDCE）** 三个域 D1/D2/D3，每域维护向量时钟 `v_d ∈ ℕ³` 与本地序号 `seq_d`：
- **逻辑时标** `L(e) = (v(e), t_d(e), seq_d(e), port(e), episode(e))`。
- **happens-before**：跨域 `e1→e2 ⟺ v(e1) ≤ v(e2) ∧ v(e1) ≠ v(e2)`；同域 `e1→e2 ⟺ seq(e2)=seq(e1)+1 ∧ t(e2)≥t(e1)`。
- **跨域桥接**：D1 的 EV-exec 携带 `v_D1`；D2 的 ACK 携带 `max(v_D1,v_D2)+1`；D3 的 action chunk 携带 `v_D3`；每条桥接消息必须附带 `(port, episode, commit_epoch)` 三元组。
- **证据链** G_ev = (V, →)。完整性谓词：`Complete(G_ev) ⟺ ∀ 已执行动作 a_j，其 e_j ∈ V、前驱 e_{j−1}→e_j、且 chain_root = H(hash(e_1)‖…‖hash(e_j)) 一致`。
- **断链处理**：`gap = 期望 seq − 收到 seq`。若 gap>0 且影子缓冲/重放可补齐 → 因果重放；若补齐后向量时钟仍不可比或 episode 不匹配 → 标记 `causal_split` 并**硬失败到安全停止**（不是继续执行）。

**定义 165（跨域执行契约闭环 CDEC）** 算子 `CDEC(M, task, port_i, intent, delta_f_req)`：
```
① QCEB:   对证据分级 E，ω(E)→Q，配置 DDS QoS / 话题
② DEP:    ERTC.lock(ϕ(intent)) 绑定 P_s；预留 WCET；离线/在线 RTA 校验
③ MPIAR:  绑定租户 t_i；若新 episode → reset S_i；载入 last_chunk_i
④ SSM:    第 60 轮场景先验 π_scene → K_safe^scene
⑤ D3:     obs ⊕ language → get_action(obs) → action chunk A（远端）
⑥ CDCE:   盖向量时钟 → WebSocket 发送 → 收 ACK；校验因果与三元组
⑦ Exec:   按 ACL 执行 A；逐块采集 EV-exec（D1）
⑧ QCEB:   mon 检查 deadline/liveliness；违约 → esc 升级
⑨ CDCE:   追加证据；重连时按 (port,episode,commit_epoch) 对齐并补链
⑩ Return: (A, K_safe, EV-exec, Cert_cdec, evidence_status)
```

**定义 166（七维认知-网络-契约预算 PCE++++++）** `B_cog⁺ = (B_scene, B_intent, B_ros, B_exec, B_net, B_qos, B_iso)`：
- `B_net = (Latency_budget, Jitter_budget, RTT_p99, Reconnect_budget)`；
- `B_qos = (Deadline_miss_slack, Depth_budget, Liveliness_lease)`；
- `B_iso = (Concurrent_tenant_cap, Per_tenant_share, ACL_replan_budget)`；
- **VOI**：`voi⁺(π) = VOI_meta(π) − cost_cog − cost_exec − cost_net − cost_qos − cost_iso`，其中 `cost_net = λ_RTT·RTT_p99 + λ_jit·σ_L + λ_rec·Reconnect_count`，`cost_qos = λ_dm·deadline_missed + λ_lv·liveliness_lost`，`cost_iso = λ_conc·max(0,N−N_max) + λ_acl·replan_count`；
- **降级阶梯**：`B_net` 耗尽 → 增大 H 并 commit-and-hold；`B_qos` 耗尽 → E1/E2 降 QoS、E0 只升不降并标记证据置信；`B_iso` 耗尽 → 背压/拒绝新租户，保已接入租户的规律性；`B_scene/B_intent/B_ros/B_exec` 沿用第 60 轮策略。

**定义 167（跨域执行证书 CEC）** `Cert_cdec = (port, episode, model_hash, QoS_sat[], RTA_witness, Reg, chain_root, V_clock, J_exec, validity)`：
- **有效性** `Valid(Cert) ⟺ QoS_sat(E0) ∧ RTA_witness(P_s) ∧ Complete(G_ev) ∧ Reg ≥ ρ_min ∧ J_exec ≥ 0`。
- **可组合性**：机器人侧 `J_exec`、网络侧 `ACK`、策略侧 `model_hash` 通过 `chain_root` 绑定；任一缺失 → 证书无效 → 安全停止。
- **不可伪造性**：链根基于 SHA256 且绑定 `(port,episode,commit_epoch)`，跨端口/跨 episode 的重放无法生成有效证书。

**定义 168（网络-执行稳定域 NES）** 给定网络延迟均值 μ_L、队列等待 W_queue、动作块长 H、执行周期 Δ：
- **有效延迟** `τ_eff(H) = μ_L + W_queue + H·Δ`；
- **稳定裕度** `ρ_H = exp(−τ_eff(H)/τ_c)`，τ_c 为被控对象临界时间常数；
- **块长选择** `H* = max{ H : ρ_H ≥ ρ_min ∧ Reg(H) ≥ r_min ∧ cost_net(H) ≤ B_net }`；
- **单调性**：H↑ 提升 Reg、但 τ_eff↑ 降低 ρ_H；网络/QoS 恶化只缩小可行 H 集合。若无可行 H，则退到 `H=1` 且 commit-and-hold；仍不可行则安全停止。

## 2. 关键算法伪代码

### IP-161 QCEB（证据 QoS 契约总线）
```python
EVIDENCE_QOS = {
    'E0': dict(reliability='RELIABLE', durability='TRANSIENT_LOCAL',
               deadline=0.05, liveliness=0.1, history='KEEP_ALL'),
    'E1': dict(reliability='RELIABLE', durability='VOLATILE',
               deadline=0.2, liveliness=0.5, history='KEEP_LAST', depth=10),
    'E2': dict(reliability='BEST_EFFORT', durability='VOLATILE',
               deadline=1.0, liveliness=2.0, history='KEEP_LAST', depth=2),
}

class QoSEvidenceBus:
    def __init__(self, node):
        self.node, self.mon = node, Monitor(window=1.0)
        self.pubs = {e: node.create_publisher(EvMsg, f'/ev/{e}', qos_of(q))
                     for e, q in EVIDENCE_QOS.items()}

    def publish(self, e_level, msg):
        q = EVIDENCE_QOS[e_level]
        if not self.mon.healthy(e_level, q):          # deadline/liveliness 违约
            self.escalate(e_level)                     # 只升不降
        self.pubs[e_level].publish(msg)

    def escalate(self, e_level):
        if e_level == 'E0':
            self.node.pause_publishing('E2')           # 让出带宽
            self.pubs['E0'] = self.node.rebind(
                'E0', executor='safety_executor', depth=32)

    def certify(self):
        return {e: self.mon.satisfied(e, q) for e, q in EVIDENCE_QOS.items()}
```

### IP-162 DEP（确定性执行器分区）
```python
class DeterministicExecutorPartition:
    def __init__(self, safety_cbs, best_effort_cbs, tau_deadline=0.1):
        self.Ps, self.Pb = safety_cbs, best_effort_cbs
        self.tau_deadline = tau_deadline
        self.safe_executor = SingleThreadedExecutor()   # 独立、SCHED_FIFO
        for cb in self.Ps:
            self.safe_executor.add_node(cb.node)         # PriorityCeiling group

    def rta_check(self):
        ok, bound = True, 0.0
        for c in sorted(self.Ps, key=lambda x: -x.priority):
            R = c.wcet
            while True:
                nxt = c.wcet + sum(math.ceil(R/h.period)*h.wcet
                                   for h in self.Ps if h.priority > c.priority) \
                       + c.max_blocking
                if abs(nxt - R) < 1e-9: break
                R = nxt
            bound = max(bound, R); ok &= (R <= min(c.deadline, self.tau_deadline))
        u = sum(c.wcet/c.period for c in self.Ps)
        return ok and u < 1.0, bound, u

    def lock_intent(self, c_intent):
        ok, bound, u = self.rta_check()
        if not ok:
            return {'status': 'RTA_FAIL', 'fail_closed': True}
        return self.safe_executor.submit(ertc_lock, c_intent,
                                         deadline=self.tau_deadline)
```

### IP-163 MPIAR（多租户隔离 + 动作承诺）
```python
class MultiTenantPolicyIsolator:
    def __init__(self, n_max=8, eps_acl=0.05):
        self.n_max, self.eps_acl = n_max, eps_acl
        self.tenants = {}                              # port -> TenantState

    def bind(self, port, episode_id):
        t = self.tenants.get(port)
        if t is None or t.episode_id != episode_id:
            self.tenants[port] = TenantState(episode_id, reset_epoch=0)
        return self.tenants[port]                      # 与其他 port 无共享可变引用

    def commit_action(self, port, new_chunk, k_done):
        t = self.tenants[port]
        if t.last_chunk is None or k_done >= len(t.last_chunk) - 1:
            t.last_chunk = new_chunk; return new_chunk, 'commit'
        cont = t.last_chunk[k_done + 1]
        if np.linalg.norm(new_chunk[0] - cont, ord=np.inf) <= self.eps_acl:
            t.last_chunk = new_chunk; return new_chunk, 'replan_in_trust_region'
        return t.last_chunk[k_done + 1:], 'commit_and_hold'   # 拒绝抖动

    def schedule(self, ready_ports):
        if len(ready_ports) > self.n_max:
            return self.backpressure(ready_ports)      # 保已接入租户规律性
        return fair_share(ready_ports, shares=self.share)
```

class CrossDomainCausalChain:
    def __init__(self, domain_id, window=256):
        self.v = np.zeros(3, dtype=int); self.seq = 0
        self.chain = []; self.last = {}; self.window = window

        return dict(v=self.v.copy(), seq=self.seq, port=port,
                    episode=episode, epoch=commit_epoch,
                    ts=time.monotonic_ns())

    def observe(self, L, payload):
        key = (L['port'], L['episode'])
        prev = self.last.get(key)
        if prev is not None and L['seq'] > prev['seq'] + 1:
            gap = list(range(prev['seq'] + 1, L['seq']))
            if not self.replay_from_shadow(key, gap):
                return 'causal_split'                  # 硬失败到安全停止
        if prev is not None and not v_le(prev['v'], L['v']):
            return 'causal_split'
        self.last[key] = L
        self.chain.append((L, payload))
        return 'ok'

    def chain_root(self):
        return hashlib.sha256(b''.join(hash_of(p) for _, p in self.chain)).hexdigest()

def choose_chunk_horizon(mu_L, Wq, tau_c, H_max=16, dt=0.05,
                         rho_min=0.6, reg_min=0.7):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| QCEB | O(1)/事件，O(#topics·depth) 监控窗口 | O(#topics·depth) | QoS 违约检出 ≤ W_mon；E0 只升不降 |
| DEP | 离线 RTA O(n²)，在线 O(1)/锁定 | O(n) | `∀c∈P_s: R_c ≤ D_c`；干扰上界 0（Iso=1） |
| MPIAR | O(N log N)/调度周期，O(H)/动作校验 | O(N·H) | 状态隔离不变量 + ACL 信任域 |
| CDCE | O(1)/事件，O(|gap|) 重放 | O(window·#domains) | 因果完整性 ≥ 1−δ_cdce |
| CDEC | O(闭环) | 复用 | 安全单调（降级只减性能/置信） |

**正确性定理（SGEC+ / CDEC 契约定理）**：
假设 A22–A70 成立；新假设：**(A66)** QCEB 的 QoS 契约在给定负载下可被 DDS 满足，违约由 mon 可观测并触发 esc；**(A67)** DEP 的安全分区满足 RTA 且 `U_s<1`，PCP 无无界阻塞；**(A68)** MPIAR 租户状态无共享可变引用，ACL 信任域非空，服务份额 `Σs_i≤1`；**(A69)** CDCE 的向量时钟捕获域内全序与域间偏序，哈希碰撞概率 ≤ negl(λ)，重连按 `(port,episode,epoch)` 对齐；**(A70)** NES 中 `ρ_H` 关于 H 单调不增，预算单调消耗。则：

1. **证据可靠性（QCEB）**：若 `QoS_sat(E0)` 且 mon 健康，则 E0 证据在 D0 内送达的概率 ≥ 1−δ_qos；若违约，则证书置信单调下降，**不存在「证据丢失却被签成高置信」的路径**（fail-closed）。
2. **意图时序（DEP）**：若 RTA 通过，则所有 c∈P_s 的响应 `R_c ≤ D_c`，故 CIEC 的 `τ_response ≤ τ_deadline`；P_b 对 P_s 的干扰为 0（Iso=1）。
3. **隔离与规律性（MPIAR）**：任意租户 i 的等待 `W_i ≤ B_i/s_i + C_max`，跨租户无状态泄漏；在 ACL 约束下，块间动作续接偏差 ≤ ε_acl，故 `Reg` 不会因重规划抖动而无限退化。
4. **因果完整性（CDCE）**：若 G_ev 中每个已执行动作均有前驱且 chain_root 一致，则 Complete(G_ev) 成立；若出现 `causal_split`，系统进入安全停止，**不存在「链断裂仍继续执行」的路径**。
5. **安全单调性（PCE++++++ / NES）**：任一预算耗尽或 H 收缩，只会缩小可行动作集与证书置信；安全执行集 `K_safe` 不会因降级而扩大。

class DeterministicExecutorPartition:
    def __init__(self, safety_cbs, best_effort_cbs, tau_deadline=0.1):
        self.Ps, self.Pb = safety_cbs, best_effort_cbs
        self.tau_deadline = tau_deadline
        self.safe_executor = SingleThreadedExecutor()   # 独立 + SCHED_FIFO
        for cb in self.Ps:
            self.safe_executor.add_node(cb.node)

    def rta_check(self):
        ok, bound = True, 0.0
        for c in sorted(self.Ps, key=lambda x: -x.priority):
            R = c.wcet
            while True:
                nxt = (c.wcet
                       + sum(math.ceil(R/h.period)*h.wcet for h in self.Ps
                             if h.priority > c.priority)
                       + c.max_blocking)
                if abs(nxt - R) < 1e-9: break
                R = nxt
            bound = max(bound, R)
            ok &= (R <= min(c.deadline, self.tau_deadline))
        u = sum(c.wcet/c.period for c in self.Ps)
        return ok and u < 1.0, bound, u

### IP-164 CDCE
```python
class CrossDomainCausalChain:
    def __init__(self, domain_id, window=256):
        self.v = np.zeros(3, dtype=int); self.seq = 0
        self.chain, self.last, self.window = [], {}, window

    def stamp(self, port, episode, commit_epoch):
        self.v[domain_id] += 1; self.seq += 1
        return dict(v=self.v.copy(), seq=self.seq, port=port,
                    episode=episode, epoch=commit_epoch, ts=time.monotonic_ns())

    def observe(self, L, payload):
        key = (L['port'], L['episode'])
        prev = self.last.get(key)
        if prev is not None and L['seq'] > prev['seq'] + 1:
            if not self.replay_from_shadow(key, range(prev['seq']+1, L['seq'])):
                return 'causal_split'
        if prev is not None and not v_le(prev['v'], L['v']):
            return 'causal_split'
        self.last[key] = L; self.chain.append((L, payload)); return 'ok'

    def chain_root(self):
        return hashlib.sha256(b''.join(hash_of(p) for _, p in self.chain)).hexdigest()
```

def choose_chunk_horizon(mu_L, Wq, tau_c, H_max=16, dt=0.05,
                         rho_min=0.6, reg_min=0.7):
    best = None
    for H in range(1, H_max + 1):
        rho = math.exp(-(mu_L + Wq + H*dt) / tau_c)
        if rho >= rho_min and estimate_regularity(H) >= reg_min:
            best = H
    return best if best is not None else 1

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| QCEB | O(1)/事件，O(#topics·depth)/窗口 | O(#topics·depth) | 违约检出 ≤ W_mon；E0 只升不降 |
| DEP | 离线 O(n²)，在线 O(1) | O(n) | `R_c ≤ D_c`；Iso=1 时干扰 0 |
| MPIAR | O(N log N)/周期，O(H)/校验 | O(N·H) | 隔离不变量 + ACL |
| CDCE | O(1)/事件，O(|gap|) 重放 | O(window·3) | 完整性 ≥ 1−δ |
| CDEC | O(闭环) | 复用 | 安全单调 |

**正确性定理（CDEC 契约定理）**：若 A66–A70 成立，则
1. `QoS_sat(E0)` ∧ mon 健康 ⇒ E0 在 D0 内送达概率 ≥ 1−δ_qos；违约只降证书置信（fail-closed）。
2. RTA 通过 ⇒ `τ_response ≤ τ_deadline`，P_b 对 P_s 干扰为 0。
3. 租户隔离 + ACL ⇒ 跨租户无状态泄漏，块间续接偏差 ≤ ε_acl，`Reg` 有下界。
4. `Complete(G_ev)` ⇒ 每个已执行动作的因果前驱齐全；`causal_split` ⇒ 安全停止。
5. 任一预算耗尽/H 收缩 ⇒ 仅缩小动作集与置信，安全集不扩大。

## 6. 本轮最大风险

**一句话**：跨域 split-brain——DDS 显示按时、WebSocket 回了 ACK，但重连把旧 episode 的 action chunk 重放给新 episode，CEC 可能凭「哈希看起来对」宣布链完整，而机器人执行了因果前驱缺失的动作；必须把 `(port, episode, commit_epoch)`、向量时钟与链根绑进证书，并在任何因果歧义时硬失败到安全停止。
