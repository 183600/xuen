# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险自适应闭环」IP-233~242；灵感循环第 2 轮；本轮灵感：「平衡控制」×「多机协作」）

> 第 65~67 轮（VISTA→RAS→SimRAS）把闭环从「故障可归因」推进到「意图可感知」再到「未来可预演」。但三者共享一个未言明的前提：**被控对象是单机，支撑基座静态或缓变，安全是可以在一台机器上闭合的标量风险**。平衡控制打破了这个前提——安全是全身动力学中持续被消耗、又持续被补充的**动态余额**；多机协作进一步打破了「余额归我所有」——我可以倾斜，是因为你承诺配重；你能抬举，是因为我承诺锚定。
>
> 于是瓶颈从「我的风险多大」转移到：
>
> **这个动作在花谁的平衡余额？谁承诺在租约到期前还上？如果还不上，团队能否安全解散？**
>
> 本轮核心命题：
>
> **把 SimRAS 的「单机未来风险闭环」升级为「团队级平衡承诺闭环」：将平衡能力建模为带到期时间、不可再抵押的稳定性租约；用分布式账本结算「谁把稳定性借给谁」；用假设-保证合约与图世界模型预测耦合平衡演化；用团队级视觉问答审计反事实的租约撤销；当账本无法清算时，执行认证的安全解散。**
>
> 方案名：**BALLAST（Balance-Aware Ledger of Leased Stability for Teams，面向团队的平衡感知稳定性租约账本）**。它不问「这台机器人平衡吗」，而问「**这个团队在下一次续约之前，每一刻的平衡账本都是可清偿的吗？**」

## 0. 直觉与动机

**灵感 1（平衡控制 → 平衡余额，而非平衡布尔值）**
直觉：传统平衡控制器把 ZMP/CoM 约束在支撑多边形内，安全是「在内/在外」的二值判断。但在协作搬运、双足交接、异构团队中，支撑多边形会被队友和共同负载**共同撑大**。一台已经贴近自身边界的机器人，只要对队友的平衡裕度拥有一张有效「提款凭证」，就仍然可以行动。因此应当把「是否平衡」替换为「**还有多少可签发的平衡容量**」：一个带符号的裕度，加一条可转让的授信额度。
形式化映射：机器人 `i` 的可容许外力扳手集 `W_i(x_i)`；裕度 `m_i` 是到边界的带符号距离；容量 `c_i(d, δ)` 是沿任务方向 `d`、在保留裕度 `δ` 的前提下还能承担的外力扳手额度。

**灵感 2（多机协作 → 协作的原子是承诺，不是动作）**
直觉：协作搬运最危险的时刻不是每个机器人各自的动作，而是**接缝**：一方默认另一方会接住负载。单机动作分块无法表达这种跨体承诺。BALLAST 把接缝显式化为**租约**：债权人、债务人、额度、方向、到期时间、清算条件。租约既是控制承诺，也是证书对象。没有租约的负载转移，视为未投保的裸风险。

**灵感 3（租赁/账本 → 用金融账本驯服共享稳定性）**
直觉：若把平衡容量当钱，约束立刻变得清晰：不能把借来的容量再借出去（**不可再抵押**，否则会出现循环授信）；每个机器人有净头寸 `n_i = 基础容量 - 借出 + 借入`；可行动当且仅当所有净头寸非负且团队耦合约束可行。账本守恒意味着租约**只重新分配**容量，不凭空创造容量。更关键的是**到期**：通信丢失时，旧租约不能继续生效；到期即自动「抽贷」，因此信息丢失只会让系统更保守，绝不会更乐观。

**灵感 4（多机协作的共因失效 → 相关性是隐形杠杆）**
直觉：一块湿滑地面、一次负载滑移、一次协同推搡，可能同时击穿多台机器人的裕度。逐机独立假设会低估「同时失效」的尾部概率。BALLAST 因此需要共因压力测试、copula 尾部相关性估计，以及一个**共因门控**：相关性估计过高或未知时，禁止任何放宽容差的操作。

**灵感 5（图世界模型 → 团队平衡是可预测的耦合场）**
直觉：机器人、共同负载、接触点构成一张图。节点状态通过物理接触边和通信边耦合。用图消息传递预测下一步各节点的裕度与续约需求，可以在「承诺兑现前」发现耦合失稳。预测与本体感觉不一致时，触发重新议约，而不是直接下发动作。

**灵感 6（与 SimRAS 接合 → 前台结算，后台审计）**
直觉：SimRAS 的世界模型与 VQA 审计是单机长时程的；BALLAST 把它拆成「前台实时结算 + 后台异步审计」。实时环只做平衡裕度估计、租约验证/到期、C-RAS-B 认证与安全解散，全部是 `O(N²)` 以内的确定性计算；图世界模型与团队 VQA 在后台运行，审计结论只以**租约折扣（haircut）**和先验的形式回流，不直接写控制。这样既保留 SimRAS 的可解释性，又不让双黑箱进入硬实时安全路径。

## 1. 形式化定义（增量：定义 266–290）

- **定义 266（BALLAST 总览）**：`BALLAST = (BME, BLP, BLL, CBC, CGWM, C-RAS-B, CCMR, T-VQA, STD, J_BALLAST)`。定位：SimRAS 的「单机未来闭环」升级为「团队平衡承诺闭环」。不变式：实时环只含 BME、BLP、BLL、C-RAS-B、STD；CGWM 与 T-VQA 异步运行；实时环零学习写操作，租约到期是硬中断。
- **定义 267（团队平衡状态）**：`X = (x_1,...,x_N, x_O)`，其中 `x_i = (q_i, q̇_i, contacts_i, τ_i)` 为机器人 `i` 的构型、速度、接触模式与关节力矩，`x_O` 为共同负载/被操作物状态。
- **定义 268（可容许扳手集）**：对机器人 `i`，`W_i(x_i) = { w ∈ ℝ^6 | ∃ f_i ∈ FC_i, A_i f_i = w, τ_i ∈ [τ_min, τ_max] }`，`FC_i` 为摩擦锥，`A_i` 为接触雅可比映射。`W_i` 是线性化接触模型下的凸多面体。
- **定义 269（平衡裕度）**：`m_i(x_i, w_i) = dist_signed(w_i, ∂W_i(x_i))`，即 `w_i` 到可容许集边界的带符号距离；归一化裕度 `ρ_i = m_i / (m_req + ε)`，`m_req` 为任务要求的保留裕度。
- **定义 270（平衡容量/授信额度）**：沿方向 `d`、保留裕度 `δ` 的容量
  `c_i(d, δ) = max{ c ≥ 0 | w_i^0 + c·d ∈ W_i(x_i), m_i(x_i, w_i^0 + c·d) ≥ δ }`。
  一般方向下 `C_i(δ) = { Δw | m_i(x_i, w_i^0 + Δw) ≥ δ }` 为凸容量集。
- **定义 271（平衡租约）**：`ℓ = (j → i, c, d, t_0, T, σ, ν, h)`，表示债权人 `j` 在 `[t_0, T)` 内把沿 `d` 的 `c` 单位容量让渡给债务人 `i`；`σ` 为清算条件（如接触建立、扳手结算、负载释放），`ν` 为防重放 nonce，`h` 为审计折扣（haircut）。
- **定义 272（租约有效性）**：`valid(ℓ, t) ⇔ t ∈ [t_0, T) ∧ sign_j(ℓ) ∧ c ≤ remaining(j, t) ∧ NoRehypothecation(ℓ) ∧ (T - t) ≥ d_max + δ_clock + τ_renew ∧ ¬called(σ, t)`。其中 `d_max` 为最大网络时延，`δ_clock` 为最大时钟偏移，`τ_renew` 为续约处理时间。
- **定义 273（租约账本）**：`L_i(t) = { ℓ ∈ L(t) | creditor(ℓ)=i ∨ debtor(ℓ)=i }`，每个机器人只依据**本地持有且本地验证通过**的租约行动；安全不依赖全局共识，只依赖到期与签名。
- **定义 274（净头寸与账本守恒）**：`n_i(t) = c_i^base(t) - Σ_{ℓ∈out_i} c_ℓ(1-h_ℓ) + Σ_{ℓ∈in_i} c_ℓ(1-h_ℓ)`。可行动要求 `n_i(t) ≥ 0`。在无再抵押且租约图无环时，`Σ_i n_i(t) = Σ_i c_i^base(t) - Σ_ℓ c_ℓ h_ℓ ≤ Σ_i c_i^base(t)`；租约只转移容量，haircut 只销毁容量。
- **定义 275（团队耦合平衡约束）**：`W_team(X) = { w_team | ∃ {f_i}, A_team f = w_team, 摩擦锥、关节限幅、负载动力学均满足 }`。耦合惩罚 `κ(X) ≥ 0` 度量「各自可行但联合不可行」的裕度损失；`m_team = dist_signed(w_team, ∂W_team(X)) - κ(X)`。
- **定义 276（假设-保证合约）**：`K_i = (A_i, G_i)`。`A_i` 是对邻居质心加速度、接触扳手、通信迟到上界的假设；`G_i` 是自身在这些假设下能保证的平衡裕度与扳手范围。团队合约有效当且仅当对所有物理/通信边 `i→j`：`G_i ⊨ A_j`。
- **定义 277（偏差包络）**：`δ_i(t)` 为队友相对合约的最大可能偏差（由历史残差与 SimEngine 扰动集给出）；租约额度必须覆盖 `δ_i` 与耦合惩罚 `κ`，否则视为未投保。
- **定义 278（C-RAS-B 认证前缀）**：`k*_B = max{ k ≤ m_B | ∀s≤k: 所有启用的租约在 `t+s` 仍有效、`n_i(t+s) ≥ 0`、`m_team(t+s) ≥ 0`、团队合约有效 }`。最终 `k* = min(k_SimRAS, k*_B)`，`m_B = min_i m_i^base` 为团队不可逆视界。
- **定义 279（平衡风险缩放）**：`λ_B(t) = clip( λ_risk(t) · min_i (n_i(t) / load_i^req(t)) · (1 - α_B·R_cm(t)) · 1[ledger_solvent], 0.5, 1.1 )`。`R_cm` 为共因风险，`ledger_solvent` 为定义 274 的可行性。
- **定义 280（协作图世界模型）**：`CGWM_θ = (GraphEnc, MsgPass, NodeHeads)`。节点 `V = robots ∪ object ∪ contacts`，边 `E = physical ∪ communication`。潜状态 `z_t` 经消息传递后，三头分别预测 `(x_i, m_i)`、租约需求 `(c_i, d_i, T_i)`、共因风险 `R_cm`。
- **定义 281（图一致性）**：`d_graph(t) = max_i | m_i^CGWM(t) - m_i^BME(t) |`。若 `d_graph > τ_graph`，冻结新租约、`k*_B ← 0`，进入重新议约或安全解散。
- **定义 282（共因平衡故障）**：`E_cm = { slip, friction_drop, payload_shift, comm_blackout, external_push }`，共同冲击 `z_c` 同时影响多个节点的摩擦锥、负载或通信。`H_common ∈ E_cm`。
- **定义 283（相关尾部风险与共因门控）**：用 copula `C_ρ` 建模多机同时失效的尾部相关性，`R_cm = 1 - C_ρ(u_1,...,u_N)`，`u_i = P(m_i < 0)`。若 `ρ̄` 为相关性上置信界，则 `R_cm(ρ̄) ≥ R_cm(ρ)`；当 `ρ̄ > ρ_max` 或样本不足时，共因门控禁止 `λ_B > 1` 与 `k*_B > k_safe`。
- **定义 284（团队视觉问答审计）**：`T-VQA = (MultiViewRenderer, VQA_Model, PromptTemplate, StructParser)`。输入 CGWM 滚动的多视角渲染与账本快照；问题包括「哪张租约在承重」「若撤销租约 `ℓ`，谁先倾覆」「第一处失效接触在哪」；输出 `AuditReport = {load_bearing_leases[], counterfactual_tips[], haircut_recommend, cm_evidence}`。
- **定义 285（审计到租约定价）**：`h(ℓ) = clip(h_vqa(ℓ) + h_cm(ℓ), 0, 0.5)`；有效租约额度为 `c_ℓ(1-h_ℓ)`。审计不直接改控制，只通过折扣与租约准入回流。
- **定义 286（认证安全解散）**：`STD = (release_payload, widen_formation, lower_com, terminate_leases, safe_pose)`，是一段满足 `J_SimRAS` 与物理可行性、且每一步都单调降低团队势能/负载的认证动作序列。解散证书记 `J_STD`。
- **定义 287（J_BALLAST 证书）**：`J_BALLAST = (J_SimRAS, ledger_root, lease_set_hash, {n_i}, m_team_min, cm_flag, graph_consist_flag, std_ver)`。Valid ⇔ `Valid(J_SimRAS)` ∧ `ledger_root` 可验证 ∧ 所有启用租约有效 ∧ `min_i n_i ≥ 0` ∧ `m_team_min ≥ 0` ∧ (`cm_flag = False` ∨ `λ_B ≤ 1`)。
- **定义 288（BALLAST 干扰集）**：`E_BALLAST = E_SimRAS × E_lease × E_graph × E_cm`，其中 `E_lease = { 网络丢包、时延、时钟偏移、重放、循环授信、恶意违约 }`，`E_graph = { 图消息丢失、节点增删、接触模式误判 }`。
- **定义 289（平衡故障假设）**：`H_bal = { H_margin, H_lease, H_coupling, H_common, H_comm }`，分别对应裕度估计错误、租约失效/违约、耦合约束误判、共因失效、通信失效。后验 `P(H_bal | residual, ledger) ∝ p(residual | H_bal)·P(H_bal)`。
- **定义 290（BALLAST 总不变式）**：任何时刻执行的动作前缀必须满足：(1) 所有启用的租约在 `[t, t+k]` 内有效；(2) 所有机器人净头寸非负；(3) 合约偏差包络下的团队耦合裕度非负；(4) 共因门控通过；否则禁止执行，转入重新议约或认证安全解散。租约到期是硬中断，不允许「用旧信息续命」。

```python
class BalanceMarginEstimator:
    def estimate(self, x_i, X_O):
        # 线性化接触力锥 + 扳手平衡 + 关节限幅，求最大保留裕度
        sol = solve_wrench_lp(x_i, X_O)
        return {
            'W': sol.wrench_polytope,
            'm': sol.signed_margin,
            'capacity': sol.capacity_by_direction,
            'contact_mode': sol.contact_mode,
        }


class BalanceLease:
    def __init__(self, creditor, debtor, c, direction, t0, T, sigma, nonce, h=0.0):
        self.j, self.i, self.c, self.d = creditor, debtor, c, direction
        self.t0, self.T, self.sigma = t0, T, sigma
        self.nu, self.h = nonce, h

    def valid(self, t, ledger, d_max, skew, tau_renew):
        return (self.t0 <= t < self.T
                and t <= self.T - (d_max + skew + tau_renew)
                and self.c <= ledger.remaining_base(self.j, t)
                and not ledger.creates_cycle(self)
                and not self.sigma.called(t))


class LeaseLedger:
    def __init__(self, base_capacity):
        self.base = dict(base_capacity)
        self.out, self.in_ = defaultdict(list), defaultdict(list)
        self.active = []

    def net_position(self, i, t, d_max, skew, tau_renew):
        out = sum(l.c * (1 - l.h) for l in self.out[i]
                  if l.valid(t, self, d_max, skew, tau_renew))
        inn = sum(l.c * (1 - l.h) for l in self.in_[i]
                  if l.valid(t, self, d_max, skew, tau_renew))
        return self.base[i] - out + inn

    def can_issue(self, lease, t, d_max, skew, tau_renew):
        return (self.net_position(lease.j, t, d_max, skew, tau_renew) - lease.c >= 0
                and not self.creates_cycle(lease))

    def accept(self, lease):
        self.active.append(lease)
        self.out[lease.j].append(lease)
        self.in_[lease.i].append(lease)

    def expire(self, t, d_max, skew, tau_renew):
        self.active = [l for l in self.active
                       if l.valid(t, self, d_max, skew, tau_renew)]


class CoupledBalanceContract:
    def compose(self, contracts, X):
        # 假设-保证检查：G_i 必须覆盖邻居 A_j 的界
        for i, j in physical_and_comm_edges(X):
            if not implies(contracts[i].G, contracts[j].A):
                return False, {'violated_edge': (i, j)}
        return True, {}


class CooperativeGraphWorldModel:
    def rollout(self, X, act_seq, k=5):
        z = self.graph_enc(X)
        preds = []
        for s in range(k):
            z = self.msg_pass(z, act_seq[s])
            preds.append({
                'x': self.node_heads['state'](z),
                'm': self.node_heads['margin'](z),
                'lease_demand': self.node_heads['lease'](z),
                'r_cm': self.node_heads['common_mode'](z),
            })
        return preds


class ChunkSafetyCertificateB(ChunkSafetyCertificate):
    def certified_prefix_balance(self, A, ledger, margins, contracts,
                                 ccmr, m_B, t, d_max, skew, tau_renew):
        k_best = 0
        for k in range(1, min(len(A), m_B) + 1):
            if self._team_prefix_feasible(
                    A[:k], ledger, margins, contracts, ccmr,
                    t+k, d_max, skew, tau_renew):
                k_best = k
            else:
                break
        return k_best

    def _team_prefix_feasible(self, prefix, ledger, margins, contracts,
                              ccmr, t_horizon, d_max, skew, tau_renew):
        if any(ledger.net_position(i, t_horizon, d_max, skew, tau_renew) < 0
               for i in ledger.base):
            return False
        ok, _ = contracts.compose(contracts, margins)
        if not ok:
            return False
        if any(m_team(margins, p) < 0 for p in prefix):
            return False
        return ccmr.gate(t_horizon)


def BALLAST_round(M, obs_team):
    X, img_team = obs_team

    # 1) 实时：平衡裕度与容量
    margins = {i: M.bme.estimate(X.x[i], X.x_O) for i in X.robots}

    # 2) 实时：各机动作块提议
    A = {i: M.simras.ach.propose(X.x[i]) for i in X.robots}

    # 3) 后台：图世界模型滚动（与实时并行）
    wm = M.cgwm.rollout(X, {i: A[i][0] for i in X.robots}, k=5)

    # 4) 实时：生成租约请求 -> 本地账本撮合
    requests = M.blp.derive_requests(margins, wm, A)
    for req in requests:
        if M.bll.can_issue(req, M.t, M.d_max, M.skew, M.tau_renew):
            M.bll.accept(req)

    # 5) 实时：到期即抽贷（硬中断）
    M.bll.expire(M.t, M.d_max, M.skew, M.tau_renew)

    # 6) 实时：共因门控 + 图一致性
    r_cm = M.ccmr.estimate(wm)
    if M.cgwm.disagreement(margins) > M.tau_graph or M.ccmr.block(r_cm):
        return 0, 0.5, M.bll.snapshot(), margins, 'RENEGOTIATE'

    # 7) 实时：λ_B 与 C-RAS-B
    lam_B = M.cras_b.compute_lambda(margins, M.bll, r_cm)
    k_B = M.cras_b.certified_prefix_balance(
        A, M.bll, margins, M.cbc, M.ccmr, M.m_B,
        M.t, M.d_max, M.skew, M.tau_renew)

    # 8) 无法清算 -> 认证安全解散
    if k_B == 0:
        std_cmd = M.std.execute(X, M.bll)
        return 0, 0.5, M.bll.snapshot(), margins, ('STD', std_cmd)

    # 9) 下发控制（缩放 + 情绪风险塑造沿用 SimRAS）
    tau = {i: M.simras.pi_sigma.prefix_dispatch(A[i][:k_B]) for i in X.robots}
    tau = {i: M.simras.ers.shaping(tau[i] * lam_B) for i in X.robots}

    # 10) 后台：团队 VQA 审计，只回流 haircut
    M.team_vqa.submit_async(wm, {'X': X, 'ledger': M.bll.snapshot()})

    return k_B, lam_B, M.bll.snapshot(), margins, tau
```

## 3. 推导

**引理 14（账本守恒与无再抵押）** 若每份基础容量最多被抵押一次，且租约图无环，则对所有 `t`：
`Σ_i n_i(t) = Σ_i c_i^base(t) - Σ_ℓ c_ℓ h_ℓ ≤ Σ_i c_i^base(t)`。
因此租约不会凭空创造平衡容量；若所有 `n_i ≥ 0`，则团队总承诺不超过总基础容量。证明：对定义 274 求和，所有 `out` 与 `in` 逐项抵消，只剩 haircut 项；无环保证 `remaining_base` 不会重复计入同一份容量。

**引理 15（到期保守性）** 设最大时延为 `d_max`、最大时钟偏移为 `δ_clock`、续约处理上界为 `τ_renew`，且每个租约满足 `T - t ≥ d_max + δ_clock + τ_renew`。则在执行时刻被使用的租约，在债权人本地仍处于有效期内；若续约消息丢失，团队可用容量在下次成功续约前单调不增，故 `λ_B` 不会因通信丢失而上升。证明：由定义 272 的有效性条件，执行时刻 `t_exec ≤ T - (d_max+δ_clock+τ_renew) < T`；丢失续约只会使 `active` 集合收缩，`n_i` 中的正项减少或不变。

**引理 16（合约组合的裕度下界）** 若每个机器人 `i` 的保证 `G_i` 在偏差包络 `δ_i` 内成立，且团队耦合约束关于扳手是 `L_c`-Lipschitz 的，则
`m_team ≥ min_i m_i - L_c·Σ_i δ_i - κ(X)`。
证明：将真实联合扳手投影到各机合约扳手，利用三角不等式与 Lipschitz 性；`κ` 吸收「各自可行但联合不可行」的额外损失。

**引理 17（共因尾风险的保守上界）** 对等相关的 Gaussian copula，联合失效概率 `P_ρ(∩{m_i<0})` 关于相关系数 `ρ` 单调不减。因此若 `ρ̄ ≥ ρ` 是相关性上置信界，则 `P_ρ(∩) ≤ P_ρ̄(∩)`；用 `ρ̄` 计算 `R_cm` 得到保守估计。证明：Gaussian copula 的联合上尾概率随相关系数单调增加；阈值固定时结论成立。

**定理 14（BALLAST 端到端平衡风险一致性）** 在 A92–A97（BME 线性化误差有界、租约到期覆盖时延、合约偏差包络有效、CGWM 误差界、共因相关性有上界）下，执行 `k*_B` 前缀满足：
1. `P(团队平衡违约) ≤ α_chunk + δ_fi + α_emotion + α_gwm + α_lease + α_cm`；
2. `λ_B ≥ 0.6 ⇒ 实际团队平衡风险 ≤ 设定上限 × 1.1`；
3. 通信丢失或 `d_graph > τ_graph ⇒ k*_B` 单调不增，并自动退回单机保守前缀或 `STD`；
4. 共因门控触发时 `λ_B ≤ 1`，不允许任何放宽。

**定理 15（异步租约的分布式可靠性）** 若本地时钟单调、租约到期余量覆盖 `d_max + δ_clock + τ_renew`，则 BALLAST 在异步、丢包网络下允许执行的任何动作，均属于「同一基础容量、同一合约、同步集中式认证器」的安全动作集。证明：执行时刻每个启用租约在债权人本地有效（引理 15）；净头寸与团队耦合裕度在本地被检查（定义 278）；合约假设覆盖真实偏差（引理 16）。因此集中式认证器的所有约束在执行时刻均成立。

**定理 16（共因失效下的证书有效性）** 若 `ρ̄` 是真实尾相关性的上界且共因门控在 `ρ̄ > ρ_max` 时禁止放宽，则带 `R_cm(ρ̄)` 的联合机会约束是保守的；反之，若真实 `ρ > ρ̄`，则证书不再提供保证。该定理明确了 BALLAST 的保证边界：它不能防御「相关性被系统性低估」的共因事件。

## 6. 本轮最大风险

**一句话**：BALLAST 把「平衡容量」当作凸的、可加总、可签发租约的额度来结算，但真实接触动力学是状态相关、非线性甚至非凸的，且共因相关性可能被系统性低估——于是账本可能在纸面上完全平衡，物理上却因为一次未被建模的耦合失稳而整体倾覆，这是本轮所有理论依赖的核心假设：**平衡容量可被局部凸化并沿租约可靠转移，且团队失效的相关尾部可被有限样本估计所约束**。

## 2. 形式化定义（完整版）

**定义 266（BALLAST 总览）**
```
BALLAST = (BME, BLP, BLL, CBC, CGWM, C-RAS-B, CCMR, T-VQA, STD, J_BALLAST)
```
定位：SimRAS 的「单机未来闭环」升级为「团队平衡承诺闭环」。不变式：实时环只含 BME、BLP、BLL、C-RAS-B、STD；CGWM 与 T-VQA 异步运行；实时环零学习写操作；租约到期是硬中断，不允许用旧信息续命。

**定义 267（团队平衡状态）** `X = (x_1,...,x_N, x_O)`，`x_i = (q_i, q̇_i, contacts_i, τ_i)`，`x_O` 为共同负载/被操作物状态。

**定义 268（可容许扳手集）** 对机器人 `i`：
```
W_i(x_i) = { w ∈ ℝ^6 | ∃ f_i ∈ FC_i, A_i f_i = w, τ_i ∈ [τ_min, τ_max] }
```
`FC_i` 为摩擦锥，`A_i` 为接触雅可比映射。线性化接触模型下 `W_i` 为凸多面体。

**定义 269（平衡裕度）**
```
m_i(x_i, w_i) = dist_signed(w_i, ∂W_i(x_i))
ρ_i = m_i / (m_req + ε)
```
`m_i ≥ 0` 表示在保留裕度意义下可平衡；`m_i < 0` 表示已越界。

**定义 270（平衡容量/授信额度）**
```
c_i(d, δ) = max{ c ≥ 0 | w_i^0 + c·d ∈ W_i(x_i), m_i(x_i, w_i^0 + c·d) ≥ δ }
C_i(δ) = { Δw | m_i(x_i, w_i^0 + Δw) ≥ δ }
```
`c_i` 是沿任务方向 `d` 的可借贷额度，`C_i(δ)` 是凸容量集。

**定义 271（平衡租约）** `ℓ = (j → i, c, d, t_0, T, σ, ν, h)`：债权人 `j` 在 `[t_0, T)` 内把沿 `d` 的 `c` 单位容量让渡给债务人 `i`；`σ` 为清算条件（接触建立/扳手结算/负载释放），`ν` 为防重放 nonce，`h` 为审计折扣。

**定义 272（租约有效性）**
```
valid(ℓ, t) ⇔ t ∈ [t_0, T)
            ∧ sign_j(ℓ)
            ∧ c ≤ remaining(j, t)
            ∧ NoRehypothecation(ℓ)
            ∧ (T - t) ≥ d_max + δ_clock + τ_renew
            ∧ ¬called(σ, t)
```
`d_max` 为最大网络时延，`δ_clock` 为最大时钟偏移，`τ_renew` 为续约处理时间。

**定义 273（租约账本）** `L_i(t) = { ℓ ∈ L(t) | creditor(ℓ)=i ∨ debtor(ℓ)=i }`。每个机器人只依据本地持有且本地验证通过的租约行动；安全不依赖全局共识，只依赖到期与签名。

**定义 274（净头寸与账本守恒）**
```
n_i(t) = c_i^base(t) - Σ_{ℓ∈out_i} c_ℓ(1-h_ℓ) + Σ_{ℓ∈in_i} c_ℓ(1-h_ℓ)
```
可行动要求 `n_i(t) ≥ 0`。无再抵押且租约图无环时：
```
Σ_i n_i(t) = Σ_i c_i^base(t) - Σ_ℓ c_ℓ h_ℓ ≤ Σ_i c_i^base(t)
```
租约只转移容量，haircut 只销毁容量。

**定义 275（团队耦合平衡约束）**
```
W_team(X) = { w_team | ∃ {f_i}, A_team f = w_team,
              摩擦锥、关节限幅、负载动力学均满足 }
m_team = dist_signed(w_team, ∂W_team(X)) - κ(X)
```
`κ(X) ≥ 0` 度量「各自可行但联合不可行」的裕度损失。

**定义 276（假设-保证合约）** `K_i = (A_i, G_i)`：`A_i` 是对邻居质心加速度、接触扳手、通信迟到上界的假设；`G_i` 是自身在这些假设下能保证的平衡裕度与扳手范围。团队合约有效当且仅当对所有物理/通信边 `i→j`：`G_i ⊨ A_j`。

**定义 277（偏差包络）** `δ_i(t)` 为队友相对合约的最大可能偏差（由历史残差与 SimEngine 扰动集给出）；租约额度必须覆盖 `δ_i` 与耦合惩罚 `κ`，否则视为未投保。

**定义 278（C-RAS-B 认证前缀）**
```
k*_B = max{ k ≤ m_B | ∀s≤k:
        所有启用租约在 t+s 仍有效
        ∧ n_i(t+s) ≥ 0
        ∧ m_team(t+s) ≥ 0
        ∧ 团队合约有效 }
k* = min(k_SimRAS, k*_B)
```
`m_B = min_i m_i^base` 为团队不可逆视界。

**定义 279（平衡风险缩放）**
```
λ_B(t) = clip(
  λ_risk(t) · min_i (n_i(t) / load_i^req(t))
            · (1 - α_B·R_cm(t))
            · 1[ledger_solvent],
  0.5, 1.1 )
```

**定义 280（协作图世界模型）** `CGWM_θ = (GraphEnc, MsgPass, NodeHeads)`。节点 `V = robots ∪ object ∪ contacts`，边 `E = physical ∪ communication`。潜状态 `z_t` 经消息传递后，三头分别预测 `(x_i, m_i)`、租约需求 `(c_i, d_i, T_i)`、共因风险 `R_cm`。

**定义 281（图一致性）** `d_graph(t) = max_i | m_i^CGWM(t) - m_i^BME(t) |`。若 `d_graph > τ_graph`，冻结新租约、`k*_B ← 0`，进入重新议约或安全解散。

**定义 282（共因平衡故障）** `E_cm = { slip, friction_drop, payload_shift, comm_blackout, external_push }`，共同冲击 `z_c` 同时影响多个节点的摩擦锥、负载或通信。`H_common ∈ E_cm`。

**定义 283（相关尾部风险与共因门控）** 用 copula `C_ρ` 建模多机同时失效的尾部相关性：
```
R_cm = 1 - C_ρ(u_1,...,u_N),  u_i = P(m_i < 0)
```
若 `ρ̄` 为相关性上置信界，则 `R_cm(ρ̄) ≥ R_cm(ρ)`；当 `ρ̄ > ρ_max` 或样本不足时，共因门控禁止 `λ_B > 1` 与 `k*_B > k_safe`。

**定义 284（团队视觉问答审计）** `T-VQA = (MultiViewRenderer, VQA_Model, PromptTemplate, StructParser)`。输入 CGWM 滚动的多视角渲染与账本快照；问题包括「哪张租约在承重」「若撤销租约 `ℓ`，谁先倾覆」「第一处失效接触在哪」；输出：
```
AuditReport = {load_bearing_leases[], counterfactual_tips[],
               haircut_recommend, cm_evidence}
```

**定义 285（审计到租约定价）** `h(ℓ) = clip(h_vqa(ℓ) + h_cm(ℓ), 0, 0.5)`；有效租约额度为 `c_ℓ(1-h_ℓ)`。审计不直接改控制，只通过折扣与租约准入回流。

**定义 286（认证安全解散）** `STD = (release_payload, widen_formation, lower_com, terminate_leases, safe_pose)`，是一段满足 `J_SimRAS` 与物理可行性、且每一步都单调降低团队势能/负载的认证动作序列。解散证书为 `J_STD`。

**定义 287（J_BALLAST 证书）**
```
J_BALLAST = (J_SimRAS, ledger_root, lease_set_hash, {n_i},
             m_team_min, cm_flag, graph_consist_flag, std_ver)
```
Valid ⇔ `Valid(J_SimRAS)` ∧ `ledger_root` 可验证 ∧ 所有启用租约有效 ∧ `min_i n_i ≥ 0` ∧ `m_team_min ≥ 0` ∧ (`cm_flag = False` ∨ `λ_B ≤ 1`)。

**定义 288（BALLAST 干扰集）** `E_BALLAST = E_SimRAS × E_lease × E_graph × E_cm`，其中 `E_lease = { 网络丢包、时延、时钟偏移、重放、循环授信、恶意违约 }`，`E_graph = { 图消息丢失、节点增删、接触模式误判 }`。

**定义 289（平衡故障假设）** `H_bal = { H_margin, H_lease, H_coupling, H_common, H_comm }`，分别对应裕度估计错误、租约失效/违约、耦合约束误判、共因失效、通信失效。后验：
```
P(H_bal | residual, ledger) ∝ p(residual | H_bal)·P(H_bal)
```

**定义 290（BALLAST 总不变式）** 任何时刻执行的动作前缀必须满足：
1. 所有启用的租约在 `[t, t+k]` 内有效；
2. 所有机器人净头寸非负；
3. 合约偏差包络下的团队耦合裕度非负；
4. 共因门控通过。

否则禁止执行，转入重新议约或认证安全解散。租约到期是硬中断。

```python
# IP-244/IP-245 BLP + BLL：租约与账本
class BalanceLease:
    def __init__(self, creditor, debtor, c, direction, t0, T, sigma, nonce, h=0.0):
        self.j, self.i, self.c, self.d = creditor, debtor, c, direction
        self.t0, self.T, self.sigma = t0, T, sigma
        self.nu, self.h = nonce, h

    def valid(self, t, ledger, d_max, skew, tau_renew):
        return (self.t0 <= t < self.T
                and t <= self.T - (d_max + skew + tau_renew)
                and self.c <= ledger.remaining_base(self.j, t)
                and not ledger.creates_cycle(self)
                and not self.sigma.called(t))


class LeaseLedger:
    def __init__(self, base_capacity):
        self.base = dict(base_capacity)
        self.out, self.in_ = defaultdict(list), defaultdict(list)
        self.active = []

    def net_position(self, i, t, d_max, skew, tau_renew):
        out = sum(l.c * (1 - l.h) for l in self.out[i]
                  if l.valid(t, self, d_max, skew, tau_renew))
        inn = sum(l.c * (1 - l.h) for l in self.in_[i]
                  if l.valid(t, self, d_max, skew, tau_renew))
        return self.base[i] - out + inn

    def can_issue(self, lease, t, d_max, skew, tau_renew):
        return (self.net_position(lease.j, t, d_max, skew, tau_renew) - lease.c >= 0
                and not self.creates_cycle(lease))

    def accept(self, lease):
        self.active.append(lease)
        self.out[lease.j].append(lease)
        self.in_[lease.i].append(lease)

    def expire(self, t, d_max, skew, tau_renew):
        self.active = [l for l in self.active
                       if l.valid(t, self, d_max, skew, tau_renew)]

# IP-248 C-RAS-B：平衡认证前缀
class ChunkSafetyCertificateB(ChunkSafetyCertificate):
    def certified_prefix_balance(self, A, ledger, margins, contracts,
                                 ccmr, m_B, t, d_max, skew, tau_renew):
        k_best = 0
        for k in range(1, min(len(A), m_B) + 1):
            if self._team_prefix_feasible(A[:k], ledger, margins, contracts,
                                          ccmr, t+k, d_max, skew, tau_renew):
                k_best = k
            else:
                break
        return k_best

    def _team_prefix_feasible(self, prefix, ledger, margins, contracts,
                              ccmr, t_horizon, d_max, skew, tau_renew):
        if any(ledger.net_position(i, t_horizon, d_max, skew, tau_renew) < 0
               for i in ledger.base):
            return False
        ok, _ = contracts.compose(contracts, margins)

            return False

# IP-252 BALLAST 在线闭环
def BALLAST_round(M, obs_team):
    X, img_team = obs_team

    # 1) 实时：平衡裕度与容量
    margins = {i: M.bme.estimate(X.x[i], X.x_O) for i in X.robots}

    # 2) 实时：各机动作块提议（沿用 SimRAS 的 ACH）
    A = {i: M.simras.ach.propose(X.x[i]) for i in X.robots}

    # 3) 后台：图世界模型滚动（与实时并行）
    wm = M.cgwm.rollout(X, {i: A[i][0] for i in X.robots}, k=5)

    # 4) 实时：租约请求 -> 本地账本撮合
    for req in M.blp.derive_requests(margins, wm, A):
        if M.bll.can_issue(req, M.t, M.d_max, M.skew, M.tau_renew):
            M.bll.accept(req)

    # 5) 实时：到期即抽贷（硬中断）
    M.bll.expire(M.t, M.d_max, M.skew, M.tau_renew)

    # 6) 实时：共因门控 + 图一致性
    r_cm = M.ccmr.estimate(wm)
    if M.cgwm.disagreement(margins) > M.tau_graph or M.ccmr.block(r_cm):
        return 0, 0.5, M.bll.snapshot(), margins, 'RENEGOTIATE'

    # 7) 实时：λ_B 与 C-RAS-B
    lam_B = M.cras_b.compute_lambda(margins, M.bll, r_cm)
    k_B = M.cras_b.certified_prefix_balance(
        A, M.bll, margins, M.cbc, M.ccmr, M.m_B,
        M.t, M.d_max, M.skew, M.tau_renew)

    # 8) 无法清算 -> 认证安全解散
    if k_B == 0:
        return 0, 0.5, M.bll.snapshot(), margins, M.std.execute(X, M.bll)

    # 9) 下发控制（风险缩放 + SimRAS 的情绪/风险塑造）
    tau = {i: M.simras.pi_sigma.prefix_dispatch(A[i][:k_B]) for i in X.robots}
    tau = {i: M.simras.ers.shaping(tau[i] * lam_B) for i in X.robots}

    # 10) 后台：团队 VQA 审计，只回流 haircut
    M.team_vqa.submit_async(wm, {'X': X, 'ledger': M.bll.snapshot()})

    return k_B, lam_B, M.bll.snapshot(), margins, tau
```

## 4. 推导

**引理 14（账本守恒与无再抵押）** 若每份基础容量最多被抵押一次，且租约图无环，则
```
Σ_i n_i(t) = Σ_i c_i^base(t) - Σ_ℓ c_ℓ h_ℓ ≤ Σ_i c_i^base(t)
```
租约不会凭空创造平衡容量；若所有 `n_i ≥ 0`，则团队总承诺不超过总基础容量。证明：对定义 274 求和，所有 `out` 与 `in` 逐项抵消，只剩 haircut 项；无环保证 `remaining_base` 不会重复计入同一份容量。

**引理 15（到期保守性）** 设 `T - t ≥ d_max + δ_clock + τ_renew` 对所有租约成立。则执行时刻被使用的租约在债权人本地仍有效；若续约消息丢失，团队可用容量在下次成功续约前单调不增，故 `λ_B` 不会因通信丢失而上升。证明：由定义 272，`t_exec ≤ T - (d_max+δ_clock+τ_renew) < T`；丢失续约只会使 `active` 收缩，`n_i` 的正项减少或不变。

**引理 16（合约组合的裕度下界）** 若每个机器人 `i` 的保证 `G_i` 在偏差包络 `δ_i` 内成立，且团队耦合约束关于扳手是 `L_c`-Lipschitz 的，则
```
m_team ≥ min_i m_i - L_c·Σ_i δ_i - κ(X)
```
证明：将真实联合扳手投影到各机合约扳手，利用三角不等式与 Lipschitz 性；`κ` 吸收「各自可行但联合不可行」的额外损失。

**引理 17（共因尾风险的保守上界）** 对等相关的 Gaussian copula，联合失效概率 `P_ρ(∩{m_i<0})` 关于相关系数 `ρ` 单调不减。因此若 `ρ̄ ≥ ρ` 是上置信界，则 `P_ρ(∩) ≤ P_ρ̄(∩)`；用 `ρ̄` 计算 `R_cm` 得到保守估计。

**定理 14（BALLAST 端到端平衡风险一致性）** 在 A92–A97（BME 线性化误差有界、租约到期覆盖时延、合约偏差包络有效、CGWM 误差界、共因相关性有上界）下，执行 `k*_B` 前缀满足：
1. `P(团队平衡违约) ≤ α_chunk + δ_fi + α_emotion + α_gwm + α_lease + α_cm`；
2. `λ_B ≥ 0.6 ⇒ 实际团队平衡风险 ≤ 设定上限 × 1.1`；
3. 通信丢失或 `d_graph > τ_graph ⇒ k*_B` 单调不增，并自动退回单机保守前缀或 `STD`；
4. 共因门控触发时 `λ_B ≤ 1`，不允许任何放宽。

**定理 15（异步租约的分布式可靠性）** 若本地时钟单调、租约到期余量覆盖 `d_max + δ_clock + τ_renew`，则 BALLAST 在异步、丢包网络下允许执行的任何动作，均属于「同一基础容量、同一合约、同步集中式认证器」的安全动作集。证明：执行时刻每个启用租约在债权人本地有效（引理 15）；净头寸与团队耦合裕度在本地被检查（定义 278）；合约假设覆盖真实偏差（引理 16）。因此集中式认证器的所有约束在执行时刻均成立。

**定理 16（共因失效下的证书有效性）** 若 `ρ̄` 是真实尾相关性的上界且共因门控在 `ρ̄ > ρ_max` 时禁止放宽，则带 `R_cm(ρ̄)` 的联合机会约束是保守的；反之，若真实 `ρ > ρ̄`，则证书不再提供保证。该定理明确了 BALLAST 的保证边界：它不能防御「相关性被系统性低估」的共因事件。

## 7. 本轮最大风险

**一句话**：BALLAST 把「平衡容量」当作凸的、可加总、可签发租约的额度来结算，但真实接触动力学是状态相关、非线性甚至非凸的，且共因相关性可能被系统性低估——于是账本可能在纸面上完全平衡，物理上却因为一次未被建模的耦合失稳而整体倾覆，这是本轮所有理论依赖的核心假设：**平衡容量可被局部凸化并沿租约可靠转移，且团队失效的相关尾部可被有限样本估计所约束**。
