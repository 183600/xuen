# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「实时控制」×「抓取规划」）

> R69 把「不确定性」拆成 aleatoric 与 epistemic，学会去问、去看、去触。但它有一个从未被质疑的隐含假设：**思考是免费的，而且可以在世界停下来等你的时候完成**。R69 的 VoI 是「瞬时」的——它假设信息立刻到达、动作可以等到想清楚再发、模态在你犹豫时不发生变化。真实闭环不是这样：
> 1. **计算有截止期**：物体在下落、目标在移动、人只等 200ms；一次「再采 4 个样本」的决策本身就可能已经错过了执行窗口。R69 的 `K=1/K=4` 是一个粗糙的二元预算：它没有最坏执行时间（WCET）、不可抢占、也没有「算到一半也能用」的 anytime 语义。
> 2. **抓取是分阶段、不可逆的承诺**：R69 把信息动作当成随时可撤回的裸探针；但真实的抓取是 `approach → pre-shape → 接触 → 加载 → 抬起` 的阶梯，越过某一点就没有回头路。更根本的是，**接触信息本身只能通过施加负载（部分承诺）才能得到**——你不可能「先完全确认再抓」，因为确认所需的信息正是抓取本身产生的。
> 3. **信息会过期**：等来的答案，在到达时可能已经在描述一个不再存在的世界。R69 的 VoI 没有时间折扣项，因此会系统性高估「慢而准」的交互，甚至在慢答案与快答案之间选反。
>
> 两个灵感正好补上这两块：
> - **实时控制**：把「想多久」变成一等控制变量——anytime 算法、可抢占推理、最坏执行时间、临界时刻（critical time）测试、以及一个**永远可执行的安全兜底（incumbent）**。计算不是前提，而是被调度的资源。
> - **抓取规划**：把「承诺多深」变成一等决策变量——抓取选项的阶梯、可逆 / 笼闭（caging）/ 不可逆、点无归点、力闭合与形闭合的鲁棒裕度、把「试探性加载」当作接触力学假设检验。抓取是「时机（kairos）」的技艺：不是抓得最准，而是在正确的时刻、承诺到正确的深度。
>
> 核心命题：**R69 假设「先想清楚，再安全地做」；R70 承认「想」与「做」共享同一条截止期，而且接触任务的信息只能通过部分承诺换取。于是把策略重写为一个「可抢占的最优停止 + 分阶段承诺」问题：任意时刻都持有一个经认证、可在有界时间内执行的安全兜底；在临界时刻之前做 anytime 精化；用时间折扣的 VoI 决定是否值得获取信息；用承诺前沿决定能走多深；用笼闭作为可逆捕获的「免费实验」；用接触 SPRT 把试探性加载变成物理假设检验；一旦滑移 / 超时 / 证据不足 / 计时不可信，就逐指令退回 R69 的保守闭环。** 命名 **KAIROS-RAS**（Kinodynamic, Anytime, Interruptible, Risk-aware Option Scheduling）——kairos 不是钟表时间（chronos），而是「可被抓住的那一瞬」。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我还剩多少时间、在这一刻到来之前我该把自己承诺到多深；以及，我怎么保证在任何一个被打断的瞬间，我都还有一条安全的路可走**」。

## 0. 直觉与动机

**灵感 1（实时控制 → 计算是一种被调度的资源，不是一个前提）**
直觉：传统策略把「推理」和「执行」放在两个时间尺度上，仿佛可以先把世界冻结、把模型跑完、再把动作发出去。实时系统研究早就给出了正确图景：任务有截止期（deadline）、有最坏执行时间（WCET）、可以被抢占，而**任何时刻都必须持有一个可在有界时间内执行的安全兜底**。R69 的 `K=1/K=4` 是这条路上的第一步，但它把预算写成了常数，而不是一个「还能想多久」的在线判断。正确的对象不是「选 K」，而是**一个最优停止问题**：每多算一单位时间，期望收益的边际增量 `μ(j)` 递减，而等待的边际成本（世界漂移 + 机会损失）为 `λ_wait`；当 `μ(j) ≤ λ_wait·Δt` 时停手。截止期则给这条曲线加了一条硬边界：`t_crit = d_t − WCET_exec − τ_abort`，过了 `t_crit` 就必须执行兜底。**这把「安全」与「算了多少」解耦**：安全只依赖兜底与 WCET，效率才依赖计算。

**灵感 2（抓取规划 → 抓取是分阶段的不可逆承诺，笼闭是可逆的「免费实验」）**
直觉：抓取从来不是一次决策，而是一条承诺阶梯：接近 → 预成型 → 接触 → 加载 → 抬起。越往后越不可逆：接近失败可以重来，接触失败可以松开，但一旦抬起后滑落，损失不可挽回。于是存在一个**点无归点**，也存在一个**承诺前沿** `K(t)`：以当前剩余时间，最多能安全走到第几级、且仍来得及撤回。关键洞察是：并非所有接触都是赌注——**笼闭（caging）** 是一种「物体被手指围住、逃不出去、但仍可松开重来」的构型。它既是零不可逆性的捕获，又能压缩物体的位姿不确定性（物体必在捕获域内）。因此在信息-风险的意义上，**笼闭是接触任务里最优的第一次实验**：它用几乎为零的不可逆代价，换取一大块关于位姿的信息。R69 的自由探针空间，恰好漏掉了这个「可逆捕获」的中间态。

**灵感 3（信息-承诺对偶 → 接触信息只能用风险买，VoI 不能与风险解耦）**
直觉：R69 把「获取信息」与「执行承诺」当成两件可以分开定价的事：先算 VoI，再决定做不做。但在接触任务里，摩擦、质量、质心这些参数**只能通过施加法向/切向负载来观测**，而施加负载就是承诺。设探针载荷为 `f`：Fisher 信息 `I(f)` 随 `|f|` 单调上升，滑移风险 `R(f)` 也随 `|f|` 单调上升，且对任意 `f>0` 有 `R(f)>0`。**不存在零风险的接触信息**。所以正确的目标不是 `ΔH`，而是 `ΔH − η·R_irrev`：信息收益必须扣除它销毁的期权价值。R69 的「自由探针」正是 `η=0` 的边界——一个在接触世界里不存在的理想化。

**灵感 4（信息过期 → 时间折扣的 VoI 与信息半衰期）**
直觉：等待的代价不是中性的。世界以速率 `ρ` 漂移（最优动作分布随时间的变化率），于是一条在 `T` 时刻到达的信息，其价值大约按 `e^{−ρT}` 衰减；当 `ρT ≫ 1` 时，这条信息在到达时已经归零。定义**信息半衰期** `T_{1/2} = ln2/ρ`：任何预期时延远超半衰期的信息动作都不值得做。R69 的 VoI 等于 `ρ=0, T=0` 的边界，因此会在「慢而准」与「快而够用」之间系统性地选错。更狠的是，**截止期本身也是不确定的**：物体何时离开可达域、人还能等多久，都是估计量。于是一个自然的对偶出现了：R68 用 `λ_floor` 对**风险**取保守，R70 用 `d_t^{LCB}`（截止期的下置信界）对**时间**取保守。

**灵感 5（抓取即时机 → 用动作买时间，而不只是用时间买信息）**
直觉：实时控制里有一条被忽视的自由度：**你可以通过动作推迟截止期**。追着一个下落物一起减速、跟随目标运动以维持可达性、把相对速度压到零——这些动作不直接产生信息，却把 `d_t` 往后推，从而**为思考创造预算**。设时间的影子价格 `λ_d = ∂V/∂d`，则只要 `λ_d·Δd > cost`，买时间就是划算的。这把「截止期」从一个被动约束变成了一个可交易资源：有时最值钱的「信息动作」，恰恰是让自己多活 100 毫秒。

**灵感 6（严格包含 → 零预算 / 无分级 / 即时截止期时，KAIROS 逐指令退回 R69）**
直觉：新层必须是旧层的严格泛化，否则每加一层就多一个需要独立信任的黑箱（这是 R69 立下的理论姿态）。KAIROS 的退化边界非常干净：当剩余预算 `b_t ≤ WCET_exec`（没时间想）、或所有阶段都不可逆（没有可逆阶梯）、或 `TVoI ≤ 0`（信息不值钱）、或接触证据不足、或计时模型不可信时，KAIROS 就执行那个经 R69 认证的兜底动作——**逐指令等于 R69**。而当预算无穷、漂移为零、所有探针可逆、`η=0` 时，KAIROS 的「时间 VoI」退化为 R69 的静态 VoI。故 R69 是 KAIROS 在「免费、瞬时、可逆」边界上的退化，安全链 `KAIROS ⊆ R69 ⊆ R68` 单调不让步。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（KAIROS-RAS 总览）** KAIROS-RAS = (AIP, DAS, TVI, GOC, CAG, PHT, KRF, SCF, DSG, ICD, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **兜底恒在**：每个控制 tick 都存在一个经 C-RAS-WM 认证的兜底动作 `a^safe_t` 及其 WCET；除非显式、不可逆地跨越承诺阶梯， deliberation 不得使兜底不可执行；
(iii) **截止期可行**：任何承诺不得越过承诺前沿 `K(t)`；临界时刻测试强制生效；
(iv) **anytime 单调**：策略质量随计算量单调不降；在任意时刻截断都输出一个不劣于兜底的可执行动作；
(v) **单调包含**：计时模型不可信 / 截止期不可行 / 证据不足 ⇒ 逐指令退回 R69（再退 R68）。

**定义 311（不确定截止期与时间预算）** 控制周期 `Δt`；流失事件集合 `ℰ_loss`（物体离开可达域、到达时间-碰撞阈值、任务时间窗关闭、人类耐心耗尽）。截止期 `d_t = min_{e∈ℰ_loss} T_e` 是随机变量，其下置信界 `d_t^{LCB} = Quantile_α(d_t)`（`α` 与 R68 的安全档一致）。剩余预算 `b_t = d_t^{LCB} − t`。要求所有执行动作在 `d_t^{LCB}` 前完成。**截止期的不确定性单独走时间保守通道，不与空间不确定性混算**。

**定义 312（安全兜底与临界时刻）** 兜底 `a^safe_t` 经 C-RAS-WM 前缀认证，最坏执行时间 `WCET_exec(a^safe_t)`；从当前承诺阶段撤回到安全态的最坏时间 `τ_abort`。**临界时刻** `t_crit(t) = d_t^{LCB} − WCET_exec(a^safe_t) − τ_abort`。只有当 `t < t_crit(t)` 时才允许继续精化或继续承诺；否则立即执行兜底。这是硬实时约束，不依赖任何统计假设。

**定义 313（可抢占 anytime 策略 AIP）** 策略产生一个精化序列 `{π^{(j)}}_{j≥0}`，`π^{(0)} = δ(a^safe_t)`（兜底永远在支撑集内），质量 `Q(j)` 单调不降。截断规则：在任意 `j` 处，输出 `a_j = argmax_{a∈supp(π^{(j)}) ∪ {a^safe_t}} J_adj(a)`。**anytime 保证**：`∀j, V(a_j) ≥ V(a^safe_t)`（安全）且 `V(a_{j+1}) ≥ V(a_j)`（效率）。精化单元可以是流匹配的采样步 / 样本数 / 模态聚类分辨率。

**定义 314（时间折扣 VoI TVI）** 信息动作 `g` 的时延 `T_g ~ L_g(·)`，漂移率 `ρ_t`，等待的影子价格 `λ_wait`（单位时间的机会成本）。定义
`TVoI_t(g) = E_{T_g}[ e^{−ρ_t·T_g}·(H(M|o_t) − H(M|o_t,y_{T_g}))·1{T_g ≤ b_t − τ_abort} ] − λ_wait·E[T_g] − c(g)`。
`T_g > b_t − τ_abort` 的尾部计入 `−λ_miss·P(T_g > b_t−τ_abort)`。R69 的 VoI 是 `ρ=0, T_g≡0, b_t=∞` 的边界。

**定义 315（漂移率与信息半衰期）** `ρ_t = D_KL(π^*(·|o_t) ‖ π^*(·|o_{t+Δt}))/Δt`（或由 mode_head 的模态权重变化率估计）。信息半衰期 `T_{1/2} = ln2/ρ_t`。`ρ_t` 是**可在线测量**的实量：它同时告诉系统「该多急」和「慢答案值多少」。

**定义 316（抓取选项与承诺阶梯 GOC）** 选项 `O = (s_0,…,s_n)`，阶段 `s_k = (pre_k, post_k, τ_k, r_k, τ_abort,k)`，其中 `r_k ∈ {R (可逆), C (笼闭), I (不可逆)}`，`τ_k` 为阶段时长，`τ_abort,k` 为从 `s_k` 撤回安全态的最坏时间。点无归点 `k* = min{k : r_k = I}`。**承诺前沿** `K(t) = max{ k : t + Σ_{i≤k} τ_i + τ_abort,k ≤ d_t^{LCB} }`。阶段价值 `OV_k(t) = P_succ(k|U)·R_task − (1−P_succ)·R_fail − c_time(Στ_i)`；承诺深度 `k† = argmax_{k≤K(t)} OV_k`，若 `OV_{k†} < V_retreat` 则撤回。R69 是「只有 `s_0` 与 `s_1(I)`、无中间阶段」的退化阶梯。

**定义 317（笼闭安全集 CAG）** 捕获域 `C(g) = {物体位姿：不存在避开手指的逃逸路径}`；鲁棒笼闭 `CAG_ε(g,U) = P_{u∈U}(θ ∈ C(g)) ≥ 1−ε`。笼闭是**可逆**的（松指即可释放），故作为接触阶段的可恢复兜底；同时它把位姿约束到 `C(g)` 内，提供零不可逆代价的信息。笼闭裕度 `m_cag(g) = dist(θ, ∂C(g))`。

**定义 318（鲁棒力闭合裕度）** 对构型 `g` 与不确定集 `U`（位姿、摩擦、几何），`γ_rob(g) = min_{u∈U} γ(g,u)`，`γ(g,u)` 为接触力旋量凸包内最大内切球半径（以重力旋量归一化）。只有 `γ_rob ≥ γ_min` 且接触证据充分，才允许跨越点无归点进入加载/抬起。

**定义 319（接触物理假设检验 PHT）** 物理参数假设 `H ∈ {μ, m, c_CoM, κ_stiff}`；观测 `z_t` 为触觉力旋量与滑移指示。施加探针载荷 `f_probe`（试探性承诺），对数似然比 `Λ_t = Σ_s log[p(z_s|H_1)/p(z_s|H_0)]`。Wald 序贯检验：`Λ ≥ A` 接受、`Λ ≤ B` 拒绝、或时间/力预算耗尽即中止。探针选择 `f_probe* = argmax_f [ΔH(f) − η·R_slip(f)]`，s.t. `R_slip(f) ≤ ε_probe` 与力/位包络。**试探性加载是承诺，不是免费观测**。

**定义 320（信息-承诺对偶 ICD）** 接触实验集合 `E = {(f, R_irrev(f))}`。对任意接触信息动作，`∂I(f)/∂f > 0` 且 `∂R_irrev(f)/∂f > 0`，故 `R_irrev(f)>0`。定义净信息价值 `J(g) = ΔH(g) − η·R_irrev(g)`；R69 的 VoI 是 `η=0` 的分离边界。**系**：接触任务中「信息最优」与「风险最小」一般不在同一点，需在 Pareto 前沿上选。

**定义 321（运动学-动力学可达性过滤 KRF）** 抓取位姿 `g` 可行当且仅当存在满足执行器/加速度/速度约束的控制轨迹，在 `d_t^{LCB} − τ_commit` 内到达预抓取位姿，且相对速度满足 `‖v_rel‖ ≤ v_max`（动态抓取要求速度匹配或拦截）。时间最优到达时间 `τ_reach(g)`。可行集 `F_K(t) = {g : τ_reach(g) + τ_commit(g) ≤ d_t^{LCB}}`。R69 的静态可行域是 `F_K` 在 `d_t=∞` 的边界。

**定义 322（滑移应急回退 SCF）** 滑移检测器给出初始滑移指标与滑移加速度，估计**下落到失控的时间** `τ_fall`。恢复动作 `{减载、增握力、放置、受控释放}`，最坏恢复时间 `WCET_recover`。硬约束 `WCET_recover + margin ≤ τ_fall`；否则执行受控释放（从最小高度放下），把不可控跌落变成可控失败。滑移是**迟到但可信**的观测：它提供比预加载探针更真实的摩擦信息，但到达时已越过不可逆点——只能作最后防线，不能作首要信息源。

**定义 323（截止期松弛生成 DSG）** 动作 `u_buy` 使 `Δd(u_buy) > 0`（跟踪目标以维持可达、降低相对速度、退到延长碰撞时间的位形）。时间影子价格 `λ_d = ∂V/∂d`。当 `λ_d·Δd(u_buy) > cost(u_buy)` 且 `u_buy` 经认证时，执行买时间动作。这把截止期变成可交易资源：**用动作买时间**是实时版的「用成本买信息」。

**定义 324（两级回退）** 若出现任一：`b_t ≤ WCET_exec`、计时模型不可信（`d_t^{LCB}` 失效或 WCET 被违反）、所有阶段不可逆、`TVoI ≤ 0`、PHT 证据不足、笼闭未建立、滑移恢复不可行 ⇒ 关闭 KAIROS 时间/承诺层，**逐指令**执行 R69 的保守闭环（其内部再按条件退 R68）。

**定义 325（证书 J_KAIROS）** `J_KAIROS = (J_FLUID, wcet_bound, reaction_time_p99, deadline_slack, commit_depth, caging_margin, gamma_rob, tvoi_ratio, abort_time_max, slip_recovery_time, timing_audit_hash)`。`Valid ⇔ Valid(J_FLUID) ∧ t < t_crit ∧ K(t) ≥ k† ∧ γ_rob ≥ γ_min ∧ τ_recover + margin ≤ τ_fall`。

**定义 326（计时审计 VQAuditor-T）** 审计对象新增时间决策：是否采信了迟到信息、是否越过了承诺前沿、兜底是否过期、WCET 是否被实际执行时间违反、买时间动作是否自欺。结论回灌 AuditBuf，成为下一轮 `ρ_t`、`WCET`、`d_t` 估计算法的先验。

**定义 327（计时对抗集 AIC-TEMPO）** 时延注入（让答案迟到）、截止期压缩（世界加速）、WCET 超载（计算被抢占/降频）、滑移注入、传感器延迟伪造、以及「恰好逼出错误承诺」的对抗性时机。并入 AIC：`ℰ_KAIROS = ℰ_FLUID × ℰ_timing`。

    return None, 'refine'

## 3. 推导

**引理 19（临界时刻保证无逾期）** 设兜底 `a^safe` 的最坏执行时间为 `WCET_exec`，撤回时间为 `τ_abort`，且在 `t ≥ t_crit = d_t^{LCB} − WCET_exec − τ_abort` 时立即执行兜底。则无论 deliberation 消耗多少时间（即使被无限抢占），动作完成时刻 `≤ t_crit + WCET_exec ≤ d_t^{LCB}`。**系**：反应时间的上界是 `WCET_exec + τ_abort`，与「想了多久」无关——**安全是硬实时的，效率才是统计的**。

**引理 20（时间折扣的 VoI 与信息半衰期）** 设 `ΔH` 与 `ρ, λ_wait` 无关，则 `TVoI` 对 `E[T_g]` 单调不增、对 `ρ` 单调不增；存在阈值 `T*` 使 `TVoI ≤ 0` 对所有 `E[T_g] > T*` 成立，且 `T*` 随 `ρ` 与 `λ_wait` 递减。**系**：R69 的静态 VoI 会把「慢而准」高估约 `e^{−ρT}`，并漏掉 `λ_wait·T` 的机会成本；当两个信息动作的静态 `ΔH` 接近而时延差超过半衰期时，**R69 会选反**，而 KAIROS 选「快而够用」。

**引理 21（接触信息的非零风险 / 信息-承诺对偶）** 设接触观测关于物理参数的 Fisher 信息 `I(f)` 与滑移风险 `R(f)` 均随载荷 `|f|` 严格递增，且 `R(0)=0, R(f)>0 (f>0)`。则任何正信息量的接触实验都有正不可逆代价，最优实验解 `max_f I(f) − ηR(f)` 落在内部 Pareto 点。**系**：R69 的「先算 VoI 再决定是否承诺」只在 `η=0`（自由探针）成立；在接触世界里，`VoI` 必须与 `R_irrev` 联合定价，否则会系统性地过度试探。

**引理 22（笼闭是可逆信息 / 免费实验的主序）** 若 `g` 对不确定集 `U` 鲁棒笼闭，则从 `g` 出发的任何探针都可经「松指—重试」撤销（`R_irrev≈0`），且笼闭把位姿约束进 `C(g)` 从而降低 `H(θ)`。故在相同 Fisher 信息下，笼闭探针的净价值 `ΔH − ηR_irrev` 弱支配非笼闭探针。**系**：接触任务的最优首实验不是「最大力探针」，而是「先笼闭、再加载」；R69 的自由探针空间缺了「可逆捕获」这一层。

**引理 23（anytime 单调性与最优停止）** 在 A99（`Q(j)` 凹、边际收益 `μ(j)` 非增）下，任意截断 `j` 有 `V(a_j) ≥ V(a^safe)` 且 `V(a_{j+1}) ≥ V(a_j)`；最优停止点满足 `μ(j*) ≤ λ_wait·Δt < μ(j*−1)`。**系**：R69 的固定 `K∈{1,4}` 是 `λ_wait=0`（时间无价）且只允许两个截断点的特例；KAIROS 把「选 K」升级为「在任意点截断」。

**定理 18（KAIROS 严格包含 R69/R68）** 当 `b_t ≤ WCET_exec`、或所有阶段 `r_k=I`、或 `TVoI≤0`、或 PHT 证据不足、或笼闭未建立、或计时模型不可信时，KAIROS 执行 `a^safe` 并跳过时间/承诺层，其决策与 R69 的保守分支**逐指令相同**；反之，当 `b_t=∞, ρ=0, λ_wait=0`、所有探针可逆、`η=0` 时，`TVoI` 逐项化为 R69 的 VoI，承诺阶梯退化为单步。故 `KAIROS ⊆ R69 ⊆ R68` 单调包含，安全侧不做任何让步。

**定理 19（计算与安全解耦，效率随预算单调）** 在 `WCET` 与 `d_t^{LCB}` 有效的前提下，由引理 19，KAIROS 对认证兜底的逾期概率为 0，且不随计算负载变化；由引理 23，期望任务价值随可用计算预算单调不降。故「多想」只可能改善效率，不可能侵蚀安全。**注意**：此定理的两个前提（WCET 有效、截止期下界有效）正是本轮最大风险的来源。

**定理 20（承诺前沿是最大安全承诺深度）** 对任意策略若在 `t` 时刻越过 `K(t)` 进入 `s_{K(t)+1}`，则存在正概率使其在 `d_t^{LCB}` 前既无法完成该阶段、也无法撤回安全态；若撤回是安全所必需，则其风险 `> 0`。反之停留在 `K(t)` 内保留撤回可行性。**系（抓得准不如抓得及时）**：存在参数使「前沿内较低质量抓取」的期望收益严格高于「前沿外较高质量抓取」——因为后者以正概率把可控失败变成不可控跌落。

**定理 21（滑移是迟到但可信的观测；SCF 恢复上界）** 若 `τ_fall` 可由滑移加速度可靠估计且 `WCET_recover + margin ≤ τ_fall`，则 SCF 以概率 `≥ 1−δ` 在失控前回到安全态；且滑移对摩擦参数的 Fisher 信息严格高于预加载探针（它是尾部观测）。**系**：滑移不是「失败」，而是一个**被删失的实验**——它提供最多信息，却只在越过不可逆点后才到达；因此它只能作最后防线，不能替代前置的笼闭与 SPRT。

**定理 22（无新害与退避单调）** 所有 KAIROS 动作（含买时间、探针、笼闭、恢复）逐个过 C-RAS-WM 认证；兜底恒为 R69 安全动作；任一前提失败 ⇒ 逐指令 R69。故在计时模型有效的条件下 `risk(KAIROS) ≤ risk(R69)`，失败时 `= risk(R69)`，无新增物理风险。**前提**：计时/承诺模型本身可靠——若 `d_t^{LCB}` 或 WCET 被系统性低估，本定理不保，这正是本轮最大风险。

## 6. 本轮最大风险

**一句话**：KAIROS 把安全押在「我知道自己还剩多少时间、以及我一定能算完」这一前提上——**一旦计时模型本身被骗（截止期被高估、WCET 被降频/抢占击穿、滑移的时间-下落模型失准），那个本该保证安全的临界时刻测试就会在错误的时刻说「还可以再想」，于是系统会在最不该犹豫的一刻继续思考、在最该中止的一刻自信地抓下去——用一张精确的时间表，执行了一次错误的承诺；算错了时间，比想错了更致命。**

**次级风险与缓解**：
1. **WCET 被违反**（计算超载、GC、降频）→ 兜底路径与精化路径物理隔离 + 看门狗 + 周期性 WCET 实测 + 超限即锁死精化；
2. **截止期被高估**（世界加速/对抗时延）→ `d_t^{LCB}` 下置信界 + 多流失事件取 min + AIC-TEMPO 对抗训练；
3. **笼闭/力闭合模型失准**（摩擦、几何误差）→ 鲁棒裕度 `γ_rob` + 接触 SPRT 实测校正 + 裕度不足即退 R69；
4. **滑移来得太晚** → 不以滑移为主要信息源，只作最后防线；预加载前强制 `γ_rob ≥ γ_min`；
5. **承诺阶梯被误建模**（阶段时长/撤回时间低估）→ 在线校准 `τ_k, τ_abort` + 承诺前沿留安全余量 + 前沿越界即逐指令 R69。

# 第 70 轮产物 · 创新点清单 v1：KAIROS-RAS（Kinodynamic, Anytime, Interruptible, Risk-aware Option Scheduling：实时控制的 anytime 调度 × 抓取规划的分阶段承诺闭环；AIP×DAS×TVI×GOC×CAG×PHT×KRF×SCF×DSG×ICD×RAS-WM‡）

>
> 本轮把两个从未被定价的量提升为一等决策变量：**「想多久」（anytime + 临界时刻）** 与 **「承诺多深」（承诺前沿 + 点无归点）**。定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还剩多少时间、这一刻到来前我该把自己承诺到多深；以及任何被打断的瞬间，我是否都还有一条安全的路**」。
>
> IP 编号：IP-264~IP-277（共 14 个）。理论姿态与 R69 同构：**R69 是 KAIROS 在「免费、瞬时、可逆」边界上的严格退化**，安全链 `KAIROS ⊆ R69 ⊆ R68` 单调不让步。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 零学习写操作继承；兜底恒在（每 tick 有认证兜底 + WCET）；截止期可行（不越承诺前沿，临界时刻强测）；anytime 单调（任意截断可执行且不劣于兜底）；任一前提失败 ⇒ 逐指令 R69。

**定义 311–312（不确定截止期 / 兜底与临界时刻）** `d_t` 为流失事件最小时间，取 `d_t^{LCB}=Quantile_α`；`b_t=d_t^{LCB}−t`。兜底 `a^safe` 的 `WCET_exec`，撤回 `τ_abort`；`t_crit=d_t^{LCB}−WCET_exec−τ_abort`，`t≥t_crit` 立即执行兜底。

**定义 313–315（AIP / TVI / 漂移）** `π^{(0)}=δ(a^safe)`，`Q(j)` 单调；截断输出 `best-of-j ∪ 兜底`。`TVoI` 见符号表；`ρ_t=D_KL(π^*_t‖π^*_{t+Δt})/Δt`，`T_{1/2}=ln2/ρ_t`。

**定义 316（GOC 承诺阶梯）** 阶段 `s_k=(pre,post,τ_k,r_k,τ_abort,k)`，`k*=min{k:r_k=I}`；`K(t)=max{k:t+Σ_{i≤k}τ_i+τ_abort,k≤d_t^{LCB}}`；`k†=argmax_{k≤K(t)}OV_k`，`OV_k=P_succ R_task−(1−P_succ)R_fail−c_time`；`OV_{k†}<V_retreat` 则撤回。

**定义 317–318（笼闭 / 鲁棒力闭合）** `CAG_ε(g,U)=P_{u∈U}(θ∈C(g))≥1−ε`，可逆（松指重试），并提供位姿信息；`γ_rob(g)=min_{u∈U}γ(g,u)`，仅 `γ_rob≥γ_min` 且证据充分才越点无归点。

**定义 319–320（PHT / ICD）** Wald SPRT：`Λ_t=Σlog[p(z|H1)/p(z|H0)]`，`Λ≥A` 接受、`≤B` 拒绝、预算尽则中止；`f_probe*=argmax[ΔH−ηR_slip]` s.t. `R_slip≤ε_probe`。接触信息必 `R_irrev(f)>0`，故 `J=ΔH−ηR_irrev`，R69 的 VoI 是 `η=0` 边界。

**定义 321–323（KRF / SCF / DSG）** `F_K(t)={g:τ_reach(g)+τ_commit(g)≤d_t^{LCB}}` 且 `‖v_rel‖≤v_max`；滑移以 `τ_fall` 为预算，`WCET_recover+margin≤τ_fall` 否则受控释放；买时间 `λ_d·Δd>cost`。

**定义 324–327（回退 / 证书 / 审计 / 对抗）** `b_t≤WCET` 或计时不可信或全不可逆或 `TVoI≤0` 或证据/笼闭不足 ⇒ 逐指令 R69 ⇒ R68；`J_KAIROS` 并入时间指标；VQAuditor-T 审时；`ℰ_KAIROS=ℰ_FLUID×ℰ_timing`。

## 3. 关键算法伪代码

```python
# IP-264 AIP：可抢占 anytime 策略（兜底恒在，质量单调）
class AnytimePolicy:
    def __init__(self, trunk, v, safe): self.trunk, self.v, self.safe, self.j = trunk, v, safe, 0
    def incumbent(self, o):  return self.safe(o)                 # π^(0)：R69 认证兜底
    def refine(self, o):
        self.j += 1; self.best = self._sample_and_select(o, self.j); return self.best
    def best_so_far(self, o): return getattr(self, 'best', self.incumbent(o))

# IP-265 DAS：临界时刻 + 最优停止
def schedule(o, t, d_lcb, wcet, tau_abort, ap, lam_wait, dt):
    if t >= d_lcb - wcet - tau_abort: return ap.incumbent(o), 'incumbent'   # 硬边界
    if ap.marginal_value() <= lam_wait * dt: return ap.best_so_far(o), 'stop' # 边际不再值钱
    return None, 'refine'                                                    # 继续抢占式精化

# IP-266 TVI：时间折扣 VoI（时延 + 漂移 + 等待成本 + 迟到惩罚）
def temporal_voi(g, post, b_rem, rho, lam_wait, tau_abort):
    def term(T):
        timely = T <= b_rem - tau_abort
        return (math.exp(-rho*T)*(entropy(post) - expected_entropy(g, T)) if timely else 0.0) \
               - lam_wait*T - g.cost
    return expect(term, g.latency_dist) - g.miss_penalty * g.p_late

# IP-267 GOC：承诺前沿与深度
def commitment_frontier(t, stages, d_lcb):
    k, e = 0, t
    for s in stages:
        e += s.tau
        if e + s.tau_abort > d_lcb: break
        k += 1
    return k

def choose_depth(t, stages, U, d_lcb, retreat):
    best = (None, retreat)
    for k in range(commitment_frontier(t, stages, d_lcb) + 1):
        ov = P_succ(k, U)*R_task - (1-P_succ(k, U))*R_fail - c_time(k)
        if ov > best[1]: best = (k, ov)
    return best                                   # None ⇒ 撤回 / 退 R69

# IP-268 CAG：鲁棒笼闭（可逆捕获 = 免费实验）
def robust_caging(g, U): return P(all(inside_capture(u, g) for u in U.samples)) >= 1 - EPS_CAG

# IP-269 PHT：接触 SPRT（试探性加载 = 部分承诺）
def contact_sprt(h0, h1, f_probe, budget):
    loglr = 0.0
    while budget.remaining():
        z = apply_probe(f_probe)                   # 施加负载即承诺
        loglr += loglik(z, h1) - loglik(z, h0)
        if loglr >= A: return h1, 'accept'
        if loglr <= B: return h0, 'reject'
        if slip_detected(z): return None, 'slip'
    return None, 'inconclusive'                    # 证据不足 ⇒ 退 R69

# IP-277 主闭环（继承 R69，插入 anytime + 承诺阶梯）
def KAIROS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    d_lcb, rho = M.tvi.deadline_lcb(), M.tvi.drift_rate()
    a_safe = M.aip.incumbent(o)                                 # 先拿兜底
    while True:                                                 # 1) 截止期感知 anytime
        a, why = schedule(o, now(), d_lcb, M.wcet(a_safe), M.tau_abort(), M.aip, M.lam_wait, DT)
        if a is not None: break
        M.aip.refine(o)
        if now() > d_lcb: return M.fluid_round(obs)             # 计时失效 ⇒ 退 R69
    K = 1 if M.aip.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.aip.mode_head)
    g = M.tvi.choose(modes, rho, d_lcb - now(), M.budget)       # 2) 时间折扣 VoI
    K_max = M.goc.commitment_frontier(now(), M.grasp_stages, d_lcb)
    k_dag = M.goc.choose_depth(now(), M.grasp_stages[:K_max], U_epi, d_lcb, retreat=0.0)
    if k_dag[0] is None or not M.cag.robust_caging(M.grasp_stages[k_dag[0]].g, U_epi):
        return M.fluid_round(obs)                               # 3) 无安全阶梯 ⇒ 退 R69
    if M.goc.crosses_pnr(k_dag[0]):                             # 4) 越点无归点前先做 SPRT
        h, st = M.pht.contact_sprt(H0, H1, f_probe=..., budget=...)
        if st != 'accept' or M.grasp.gamma_rob(...) < GAMMA_MIN:
            return M.fluid_round(obs)                           # 证据/裕度不足 ⇒ 退 R69
    if M.scf.slip_detected(): return M.scf.recover_within_fall() # 5) 滑移应急
    if M.dsg.buy_time_profitable(rho, d_lcb): return M.goc.exec_stage(M.dsg.best_buy_time(...))
    M.vqa_t.submit_async(why, g, U_epi, d_lcb - now(), k_dag[0])
    return M.goc.exec_stage(k_dag[0], mode=..., lam=M.efs.risk_scale(...))
```

## 4. 推导

**引理 19（临界时刻无逾期）** 若 `t≥t_crit=d^{LCB}−WCET_exec−τ_abort` 即执行兜底，则完成时刻 `≤t_crit+WCET_exec≤d^{LCB}`，与 deliberation 时长无关。**系**：反应时间上界 `WCET_exec+τ_abort` 为硬实时，安全不随计算负载变化。

**引理 20（时间折扣 VoI 与半衰期）** `TVoI` 对 `E[T_g]`、`ρ` 单调不增；存在 `T*` 使 `E[T_g]>T*` 时 `TVoI≤0`，且 `T*` 随 `ρ,λ_wait` 递减。**系**：R69 静态 VoI 高估慢交互约 `e^{−ρT}` 且漏计 `λ_wait T`；当时延差超半衰期时会**选反**。

**引理 21（接触信息非零风险）** `I(f),R(f)` 随 `|f|` 严格递增且 `f>0 ⇒ R>0`，最优实验 `max_f I(f)−ηR(f)` 在内部 Pareto 点。**系**：自由探针（η=0）在接触世界不存在，VoI 必须与 `R_irrev` 联合定价。

**引理 22（笼闭是免费实验）** 鲁棒笼闭下探针可「松指—重试」撤销（`R_irrev≈0`），且把 `θ` 约束进 `C(g)` 降低 `H(θ)`；同 Fisher 信息下笼闭探针净价值弱支配非笼闭探针。**系**：最优首实验是「先笼闭、再加载」，而非最大力探针。

**引理 23（anytime 单调与最优停止）** A99（`Q(j)` 凹、`μ(j)` 非增）下，任意截断 `V(a_j)≥V(a^safe)` 且 `V(a_{j+1})≥V(a_j)`；最优停止满足 `μ(j*)≤λ_wait Δt<μ(j*−1)`。**系**：R69 固定 K 是 `λ_wait=0` 且只许两截断点的特例。

**定理 18（严格包含 R69/R68）** `b_t≤WCET`、全阶段不可逆、`TVoI≤0`、PHT 证据不足、笼闭未建立或计时不可信时，KAIROS 执行 `a^safe` 与 R69 保守分支**逐指令相同**；反向，`b=∞,ρ=0,λ_wait=0`、全可逆、`η=0` 时 `TVoI` 化为 R69 VoI、阶梯退化为单步。故 `KAIROS⊆R69⊆R68` 单调包含。

**定理 19（计算与安全解耦）** 在 WCET 与 `d^{LCB}` 有效时，由引理 19 认证兜底逾期概率为 0 且与负载无关；由引理 23 期望任务价值随计算预算单调不降。故「多想」只改善效率、不侵蚀安全（前提即最大风险）。

**定理 20（承诺前沿是最大安全深度）** 若 `t` 时越过 `K(t)` 进入 `s_{K(t)+1}`，则正概率既无法在 `d^{LCB}` 前完成也无法撤回；若撤回为安全必需则风险 `>0`；停留在 `K(t)` 内保留撤回可行性。**系（抓得准不如抓得及时）**：存在参数使前沿内较低质量抓取的期望收益严格高于前沿外较高质量抓取。

**定理 21（滑移是迟到可信观测；SCF 上界）** 若 `τ_fall` 可估且 `WCET_recover+margin≤τ_fall`，则 SCF 以概率 `≥1−δ` 在失控前回安全态；滑移对摩擦的 Fisher 信息高于预加载探针，但到达时已越不可逆点 ⇒ 只能作最后防线。

**定理 22（无新害与退避单调）** 所有动作逐个过 C-RAS-WM；兜底恒为 R69 安全动作；任一前提失败 ⇒ 逐指令 R69。故计时模型有效时 `risk(KAIROS)≤risk(R69)`，否则 `=risk(R69)`，无新增物理风险（前提：计时/承诺模型可靠——最大风险）。

## 7. 本轮最大风险

**一句话**：KAIROS 把安全押在「我知道自己还剩多少时间、以及我一定能算完」上——**一旦计时模型被骗（截止期被高估、WCET 被降频/抢占击穿、滑移的时间-下落模型失准），那个本该保证安全的临界时刻测试就会在错误的时刻说「还可以再想」：系统在最不该犹豫的一刻继续思考、在最该中止的一刻自信地抓下去——用一张精确的时间表执行了一次错误的承诺；算错了时间，比想错了更致命。**

**次级风险与缓解**：WCET 被违反（兜底/精化物理隔离 + 看门狗 + 周期实测 + 超限锁死精化）；截止期被高估（`d^{LCB}` + 多流失事件取 min + AIC-TEMPO 对抗训练）；笼闭/力闭合模型失准（鲁棒裕度 γ_rob + SPRT 实测校正 + 裕度不足退 R69）；滑移来得太晚（不作首要信息源，加载前强制 γ_rob≥γ_min，SCF 只作最后防线）；承诺阶梯误建模（在线校准 τ_k/τ_abort + 前沿留余量 + 越界即逐指令 R69）。
