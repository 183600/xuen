# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环新一轮；本轮灵感：「行为树」×「边缘计算」）

> R73 把证据计量做成了可组合的契约代数（EC / MReg / CCA / ΣREFLEX / J_MOD），并用热替换定理把「换本体零改核心」从实验希望升为结构性质。但 R73 的代数描述的是「证据**如何被组合**」，它默认了两个从未言明的前提：
> - **静态瞬时前提**：组合图在运行时是给定的、每拍求值一次的。R73 没有「这一拍该跑哪个模块、超时退到谁、连退三次还算不算安全」的**执行语义**。CCA 是值代数，不是过程代数。
> - **单信任域前提**：所有模块跑在同一个时钟、同一台机器、同一个信任边界内。R73 的 u_motion 是「曝光期间的运动模糊」，是**采集时刻**的量；它没有「证据到达消费者时已经旧了 a 毫秒」的量，更没有「算它的那台机器还可不可信」。
>
> 两个灵感正好补这两块，但都不是「加一个模块」，而是「加一个维度」：
> - **行为树** → 执行维。Sequence/Selector/Parallel/Decorator 与 R73 的 SER/PAR/VETO 形似神不同：CCA 组合的是**值**（不确定度、有效域、否决集），BT 组合的是**过程**（Running、记忆、抢占、失败恢复）。但朴素 BT 有一个与 R73 VETO 原则**正面冲突**的语义漏洞：Selector 只要任一孩子 Success 就 Success，于是「主感知失效 → 退到弱感知 → 任务照常完成」会被记成一次普通成功——**安全界被悄悄降级，日志上却没有任何违规**。所以本轮不拿 BT 替换 CCA，而是把 BT **计量化**：每个 tick 携带（状态，证书，退化标签，预算消耗），fallback 只能让标签**变弱不能变强**，退化本身再受**轨迹级退化预算**审计。
> - **边缘计算** → 时间维与信任维。边缘不是「更远的 CPU」，而是证据的**时间计量属性**：同一条深度证据，本地是 8ms 前、边缘是 60ms 前、云上是 300ms 前；世界在动，所以「旧」不是噪声而是**确定性漂移**，可闭式写成 u_age。边缘还在信任边界另一侧：远程证明、版本漂移、分区、拜占庭节点。更关键的是，**卸载决策本身是一个动作**——把分割网络放边缘换来更强模型（更准）但更旧（更漂移）——这与 R73 的视角反作用 χ_v 完全同构，是第五类反作用通道 χ_P。
>
> 核心命题：**不再问「证据能否被组合」，而问「证据的生产过程——它在何时、何地、以何种退化顺序被计算——能否像证据本身一样被契约化与被审计？」** 把 MODGAUGE 重构为 **ECHO-RAS**（Edge-Certified Hierarchical Orchestration：边缘认证的分层证据编排）——**执行 × 放置 × 计量**。

## 0. 直觉与动机

**灵感 1（行为树 → 执行语义是 R73 缺失的第三维）**
直觉：R73 的 CCA 回答「A 与 B 串/并/否决后不确定度是多少」，但不回答「这一拍该跑 A 还是 B」「A 超时了退到谁」「连续退三次还算不算安全」。真实机器人从不每拍把所有模块跑一遍求一个静态表达式，而是按任务状态**选择性执行**感知/估计/规划，并在失败时切换到备用分支——这正是行为树的语义。BT 带来三样 CCA 没有的东西：(1) **反应性**——每拍从根重新评估，可抢占 Running 子树；(2) **模块性**——子树可复用、可单测、可整体迁移；(3) **显式失败处理**——Selector/fallback 把「退化」写进控制结构，而不是写进 if-else 的暗角。

但经典 BT 语义与安全审计天然冲突：**fallback 会把失败洗成成功**。主深度模块因镜面失效 → Selector 退到「单目深度先验」→ 任务继续 → BT 报 Success，退化标签在日志里不存在。这与 R73 第 6 节的最大风险（契约表达力）是同一个病：系统「每一步都合规」地组合出一个错误的世界。因此本轮的核心机制不是 BT 本身，而是 **provenance-carrying tick（带溯源的 tick）**：每次 tick 返回一个**退化标签** δ，Selector 的结果标签 = 实际成功孩子中最弱者的标签（只能 meet 不能 join）；**安全主张只在 δ = CERTIFIED 时签发**，DEGRADED/ADVISORY 的 tick 只能推进任务、不能推进安全证书；再加一个**轨迹级退化预算 D_t**，防止「一万次局部合规退化」把安全稀释掉。BT 的安全性于是从设计直觉变成可证性质（引理 38、定理 32）。

**灵感 2（边缘计算 → 时间、放置、信任是新的证据计量维度）**
直觉：R73 的深度六分量把「接触模式」一般化为「（动作，场景）条件」，但没有把**时间**作为独立分量。边缘化把时间放大成主项：一条 30Hz 深度流经 Wi-Fi 回传，200ms 抖动是常态；机器人以 0.5 m/s 移动时，200ms 就是 10cm 世界位移。这 10cm 既不是传感器噪声、也不是模型误差，而是**证据年龄 × 世界速度**的确定性漂移，可闭式写成

  u_age² ≈ ‖v‖² a² + ¼‖a_acc‖² a⁴（a 为证据年龄，v/加速度取自本体与接触估计）。

更一般地，边缘证据有**时间六分量**：u_age（陈旧）、u_sync（时钟偏斜）、u_jitter（到达抖动）、u_loss（丢包/FEC 残余）、u_partition（分区）、u_trust（证明/版本）。前五个是统计量，第六个是**门控**：远程证明失败时模块降为 **advisory**（可服务任务，不可签发安全主张），而**不是**给一个大方差——因为「不可信」不是「很吵」，是「无权发言」。把不可信建模成大方差，恰恰会让 PAR 融合用方差加权把它当弱证据吸收掉，这是比拒绝更危险的错误。

边缘还让 ΣREFLEX 多出第五层：**卸载动作 o 改变证据质量**。放边缘 GPU：模型更强（u_model↓）但证据更旧（u_age↑）；放本地：新鲜但模型弱。于是「放到哪里算」本身是一个**主动感知动作**，与「走到哪个视角看」同构：**χ_P: o ↦ (L(p), q_model, p_partition)**，卸载成本 c_reflex^P = E[Δu_total | o] 进同一预算。这把边缘从「部署细节」升为「计量契约的放置字段 + 反作用通道」，也是 R73 热替换定理的自然外延：**换实现 → 换位置**。

**灵感 3（两者的交点：BT 是分布式的天然载体，边缘是 BT 的天然容错场）**
直觉：BT 与边缘不是两个独立补丁，而是互相成全。BT 的 Selector/fallback 正好是分区/超时的语义归宿——远程子树不可达，Selector 自动退到本地已认证子树，这就是**分区容错**，不需要额外中间件；反过来，边缘把 BT 从「单机调度树」变成「可迁移的执行计划」——子树可整体卸载/回迁，契约（BTEC）位置无关，迁移只改放置标签与时间预算。由此得到两条结构保证：

1. **局部安全核固定**：控制域（1kHz 硬实时）节点 pin 在本地、不可卸载。于是边缘只能影响任务效率与感知质量，**不能直接触及安全控制**；边缘从「安全威胁」降为「效率威胁」（前提是 u_age 单调地进入风险缩放，见引理 43）。
2. **退化零级联**：分区/卡顿 → 本地 fallback → 只降效率不降安全，退化标签沿树向上单调传播。这把 R73 的「热替换 + 模块级降级」扩展到**放置维与时间维**。

**灵感 4（研究姿态：新维度不推翻旧定理，只加宽契约）**
直觉：ECHO 必须**严格包含** MODGAUGE：把 BT 退化为单根 Sequence、放置全部 LOCAL、时间六分量全零、退化格退化为单点 {CERTIFIED}，则 J_TREE 逐项等于 J_MOD，退化链继续落到 R72/R71/R68。这也暴露一个诚实的代价：R73 的最大风险（契约表达力）**不但没被解决，反而被加宽了**——契约现在还要表达「时间有效性」「放置可信度」「退化语义」。所以本轮不是「消除风险」，而是**把风险显式化并加护栏**：时间用保守包络 + age 强制入风险；信任用门控而非方差；退化用轨迹预算防稀释。本轮最大风险因此落在「退化稀释」及其标签的正确性上。

**为什么不是把 CCA 直接编译成 BT？**
因为两者语义层不同。CCA 的 SER/PAR/VETO 是对**同一次求值**中证据值的合成，满足交换律/结合律（PAR）与单调性；BT 的 SEQ/SEL 带**时间顺序、Running 记忆、抢占**，不满足交换律，且 SEL 引入了 CCA 里禁止的「补偿」。正确的做法是保留 CCA 作为**叶内证据代数**，新增 BT 作为**叶间过程代数**，并用 BTEC 把两层缝起来：BT 只决定「跑谁、何时退」，退化的**安全性**仍由 CCA 的非补偿否决与退化标签保证。一句话：**CCA 管「证据合成得对不对」，BT 管「什么时候去合、失败了退到哪」**，两者不是替代而是分层。

**与既有工作的定位**：行为树（Colledanchise & Ögren）、BT 安全监控、机器人边缘卸载/ROS 2 分布式执行、conformal prediction、R73 的 MODGAUGE 都是已知工作。本方案的创新不在任何单项，而在「**把执行结构、放置决策、时间陈旧与信任门控统一为一等计量契约，并使系统级安全在反应式 fallback 与边缘分区下仍可证**」——尤其是**退化标签单调性 + 轨迹级退化预算**这一对机制，它直接对抗「合规退化导致的安全稀释」。

**本轮形式化增量（定义 383–400）的骨架**：
- **MBT（定义 384–386）**：带预算、证书、退化标签的 tick 语义；SEQ/SEL/PAR/Decorator 的计量规则；**fallback 只能 meet 不能 join**。
- **退化格与退化预算（定义 387–388）**：δ ∈ {CERTIFIED, DEGRADED(k), ADVISORY, UNKNOWN} 的偏序；D_t 轨迹级预算与 SAFE_STOP。
- **ECT / EPA（定义 389–393）**：边缘时间六分量、放置延迟包络 L(p)、放置代数与时间单调性、χ_P 放置反作用通道、OEP 卸载证据规划。
- **DMR / T-GATE / PINNED_LOCAL（定义 394–397）**：分布式 MReg 与子树迁移、可信门控组合、控制域本地固定；AIC-EDGE 威胁面。
- **CPB† / 结构上限 / 严格包含（定义 398–400）**：新增 C4（反应式执行认证）、C5（边缘时间计量）；复杂度成为树 + 放置的可审计性质；ECHO ⊃ MODGAUGE 的退化实例化。

**一句话最大风险**：ECHO 把 R73 的「契约表达力」风险沿两个新维度放大——它要求契约同时正确表达「证据有多旧」与「退化到什么程度仍算安全」；一旦 u_age 的运动学上界在非刚性场景（可变形物体、遮挡切换、多人）失效，或退化标签把一次「形式合规但实质已不安全」的 fallback 误判为 CERTIFIED，轨迹级退化预算也只能守住被喂进去的那个错误标签——于是系统会用一棵每一拍都通过审计、每一次 fallback 都有证书的行为树，沿着一条由合规退化铺成的路径，稳定地走到不安全的终点。

# 第 74 轮产物 · 创新点清单 v5：ECHO-RAS（Edge-Certified Hierarchical Orchestration：边缘认证的分层证据编排；MBT × BTEC × ECT × EPA × OEP × FBA × DMR × T-GATE × MODGAUGE-RAS†）

> 承接第 73 轮 IP-295~302（MODGAUGE-RAS）。R73 完成「证据计量 → 可组合契约代数」，但整座代数建立在两个隐含前提上：**组合图运行时静态且同信任域**。本轮以「行为树 × 边缘计算」补齐**执行维**与**时间/放置/信任维**：
> - **MBT / BTEC / FBA**：把行为树计量化——tick 携带证书与退化标签，fallback 只能弱化不能强化，轨迹级退化预算阻止「合规退化稀释安全」；
> - **ECT / EPA / OEP**：边缘证据有独立的时间六分量（age/sync/jitter/loss/partition/trust）；放置成为契约字段与反作用通道 χ_P；卸载即主动感知；
> - **DMR / T-GATE / PINNED_LOCAL**：子树可迁移、远程证据须经可信门控、控制域本地固定——边缘只威胁效率，不威胁安全；
> - **CPB†**：新增 C4（反应式执行认证）、C5（边缘时间计量），C1–C3 不变。
>
> 核心命题：**证据的生产过程（何时、何地、按何退化顺序计算）成为与证据本身同等级的契约对象；系统级安全在反应式 fallback 与边缘分区下仍可证。**
>
> IP 编号：IP-303~311（共 9 个）+ R73 组件的 † 化。理论姿态延续：**新维度是旧维度的严格泛化，安全侧只增不减，退化链逐指令等价。**

## 2. 形式化定义（要点版）

**定义 383（ECHO-RAS 总览与六不变式）** ECHO-RAS = (MBT, BTEC, ECT, EPA, OEP, FBA, DMR, T-GATE, MODGAUGE-RAS†)。六不变式：
(i) **契约完整性**（继承 R73）：无 EC/BTEC 节点不入树、不入图；
(ii) **计量 tick**：每次 tick 消耗可记账预算，携带证书与退化标签，不得黑箱返回 Success；
(iii) **退化单调性**：fallback/串联传播只能 meet（变弱），安全主张只在 δ = CERTIFIED 时签发；
(iv) **退化非稀释**：轨迹级 D_t ≤ D_max，越界即 SAFE_STOP；
(v) **放置可信**：安全组合中的远程证据必须通过 T-GATE（证明 ∧ 版本 ∧ 新鲜度）；
(vi) **局部安全核**：控制域节点 PINNED_LOCAL，边缘故障不得改变控制律安全包络；
(vii) **严格退化链**：ECHO → MODGAUGE → EMBODIED → R71/R68 逐指令包含。

**定义 384（MBT 语法与 tick 语义）** N 的 type ∈ {SEQ, SEL, PAR, RETRY(k), TIMEOUT(τ), RATE(f), LEAF}。`tick(n,b,B)` 返回 (r,b′,cert,δ,c)，r ∈ {SUCCESS, FAILURE, RUNNING}，b 为黑板（含 capture_ts / vel / acc / 风险参数），B 为剩余预算。规则：
- LEAF：执行模块 impl，计算本地不确定度与 u_age，按 ECT 与 T-GATE 生成标签；c = WCET + 时间等待。
- SEQ：顺序执行，全部 SUCCESS 才 SUCCESS，δ = meet 所有孩子；任一 FAILURE 即 FAILURE。
- SEL：顺序尝试，首个 SUCCESS 即返回，**δ = meet(已尝试失败孩子, 成功孩子)**——失败分支的退化不因被跳过而消失（关键：被跳过的弱分支若其失败原因是「不可信」而非「不可用」，其标签仍要计入轨迹退化）。
- PAR：并行执行，复用 R73 CCA 的 PAR 一致性审计；δ = meet 所有孩子；审计失败 ⇒ 保守并集 + `PAR_AUDIT_FAIL`。
- Decorator：RETRY 增加退化计数；TIMEOUT 超时视为 FAILURE 且计退化；RATE 限制频率，不改变标签。
- 预算约束：Σc ≤ B，否则 FAILURE 并触发预算否决。

**定义 385（BTEC 行为树证据契约）** BTEC = (kind, EC, tick_budget_us, fallback_depth_max, safety_claim, placement, seal_ref)。LEAF 的 EC 即 R73 证据契约，额外字段 `temporal`（ECT 参数）与 `trust`（证明/版本引用）；控制节点 EC 声明其对子树的预算分配、标签合成函数与安全主张（可为 None = 仅任务）。`fallback_depth_max` 限制单次 tick 内退化链长度。

**定义 386（计量 tick 与预算代数）** 每拍的预算 B_tick 由三部分组成：证据预算 Σu（R73）、反作用预算（R73 ΣREFLEX + c_reflex^P）、时间预算（tick WCET + 等待）。tick 必须满足：预算守恒（消耗记账）、活性（每个非 Running 节点有限步返回）、可重放（黑板与随机种子版本化）。

**定义 387（退化标签格 L 与 provenance）** L 为四层偏序：CERTIFIED（全有效域、可信、新鲜）≻ DEGRADED(k)（k 次退化，仍可服务任务，安全主张降级或需重证）≻ ADVISORY（不可进入安全组合，仅任务建议）≻ UNKNOWN。每个 cert 携带 provenance `(leaf_id, u, age, trust, fallback_path)`。**安全主张的签发规则**：只有 label=CERTIFIED 的 tick 可更新安全快照；其余进入 advisory 通道并记录 regime change。

**定义 388（轨迹级退化预算 FBA）** `D_t = Σ_{s≤t} deg_cost(δ_s)`，deg_cost(CERTIFIED)=0，DEGRADED(k)=w_k·k，ADVISORY=w_a≫1。约束 D_t ≤ D_max。越界 ⇒ 立即 SAFE_STOP（本地安全停机），且在停机前不得签发任何新的安全主张。**关键**：D_t 不是单拍约束，而是轨迹约束——它审计的是「合规退化的序列」，正是单拍审计的盲区。

**定义 389（ECT 边缘时间六分量）** 对到达消费者的证据 e：`u_edge² = u_age² + u_sync² + u_jitter² + u_loss² + u_partition² + u_trust²`。其中 u_age 由定义 386 的闭式给出（用本体/接触估计的 v 与加速度；不可变形假设失效时进入保守分段上界）；u_sync 由单调时钟与偏斜上界给出；u_jitter 用到达时间 P99；u_loss 用 FEC 残余 × payload 不确定度；u_partition 是**门控**（检测到/不确定 ⇒ 视为分区）；u_trust 也是**门控**（证明或版本失败 ⇒ ADVISORY，不给方差）。有效域 `D_edge` = 必须在 `a ≤ a_max` ∧ 证明有效 ∧ 版本匹配 ∧ 未分区。

**定义 390（放置模型与延迟包络）** 放置 p ∈ {LOCAL, EDGE, CLOUD}，包络 L(p)=(W_p, RTT_p99, JIT_p99, loss_p, p_partition, trust_p)。远程放置的有效 WCET 上界 `W_eff = W + RTT_p99 + JIT_p99`；deadline 闭合要求 `W_eff ≤ deadline_module`，否则该放置被禁止（demote）。

**定义 391（EPA 放置代数与时间单调性）** 放置算子 PLACE(module, p) 生成 EC@p：把 temporal 字段置为 L(p)、W_eff 更新、domain 与 deadline 域取交；若 deadline 不闭合或 trust 失败则降级。**时间单调性（引理 40）**：若 L(p′) 逐分量不优于 L(p)（rtt/jitter/loss/partition 更大、trust 更弱），则 u_temporal(EC@p′) ≥ u_temporal(EC@p) 且 D 收缩。注意：模型质量 q_model 可能随边缘变强而反向变化，故**总不确定度不单调**——这正是 OEP 需要优化而非用支配关系论证的原因；但**安全只用时间包络的保守上界**，与模型质量无关。

**定义 392（χ_P 放置反作用通道）** 扩展动作空间 a=(a_phys, o)，o 为卸载决策。χ_P: o ↦ (L(p(o)), q_model(o), p_partition(o))。`c_reflex^P = E[Δu_total | o]`，进 ΣREFLEX† 预算。与 χ_v 同构：视角改变「眼到场景的几何」，卸载改变「证据从产生到消费的时间与信任」。

**定义 393（OEP 卸载证据规划）** 10Hz 求解 `o* = argmax_o [Q(o) − λ_age·A(o) − MigCost(o)]`，s.t. deadline 闭合、T-GATE、DMR 可迁移性。Q 为期望后验质量（模型容量），A 为期望证据年龄，MigCost 含状态传输与重签证书。加 hysteresis 与最小驻留时间防抖。

**定义 394（DMR 分布式 MReg 与子树迁移）** MReg 节点带放置标签；`migrate(T, p→p′)` 要求：子树静默（无 Running）→ 有版状态传输 → 版本哈希匹配 → 在新节点重签证书 → 原子切换；任一步失败则回滚并触发 stub/本地 replica。迁移不改变 BTEC 语义（引理 42）。

**定义 395（T-GATE 可信门控组合）** `T-GATE(A,B)`：当且仅当 `attested(A) ∧ attested(B) ∧ version_match(A,B) ∧ fresh(A,B)` 时按 R73 PAR 组合（可缩窄）；否则两路均降为 advisory-only（服务任务、不签安全、不参与缩窄）。**门控而非大方差**：不可信 ≠ 高噪声。

**定义 396（局部安全核固定）** 所有控制域节点（1kHz、硬实时、认证前缀）标记 PINNED_LOCAL：不可卸载、不可远程替换、不可由远程 tick 直接写入其输入。控制域输入只来自本地快照，且快照中的证据年龄 a 强制进入风险缩放：λ = embodied_risk_scale(..., u_age)。由此边缘故障只能经「λ 膨胀 → 更短认证前缀」影响效率，不能改写控制律。

**定义 397（AIC-EDGE 边缘威胁面）** ℰ_edge = {证据重放（旧证据冒充新）、陈旧投毒（故意增加延迟使控制看到过时世界）、降级攻击（制造分区强迫 fallback）、拜占庭边（错误但带有效证明）、版本回滚、时钟偏斜}。防线：nonce + capture_ts + 单调时钟 + T-GATE + DMR 版本哈希 + FBA 退化预算 + 单源不定案（继承 E356/E357）。

**定义 398（CPB† 扩展）** 新增两条可证伪主张：
- **C4（反应式执行认证）** ← (MBT, BTEC, FBA) ← MB4 ← AB4（计量 BT vs 朴素 BT vs FSM vs 手写策略）← (unsafe_fallback_rate, trajectory_violation_rate, tick_overhead, recovery_time)；
- **C5（边缘时间计量）** ← (ECT, EPA, OEP, T-GATE) ← MB5 ← AB5（时间六分量+age→λ vs 朴素 RTT 超时 vs 永远本地）← (stale_violation_rate, latency_quality_pareto, partition_recovery, cert_cost)。
C1–C3 绑定不变；任何新组件仍须入绑定表，否则为工程附件。

**定义 399（ECHO 复杂度结构上限）** 树：|N| ≤ 64、tick 深度 ≤ 8、Running 节点 ≤ 8、单拍 fallback 深度 ≤ 4、黑板 ≤ 16 字段；图：|V_M| ≤ 32（24 本地 + 8 边缘视角）、组合深度 ≤ 4；时间：ECT 分量 ≤ 6。全部为部署期 + 运行时增量可审计的结构性质。

**定义 400（ECHO 严格包含 MODGAUGE）** 取 BT 为单根 Sequence、所有 placement=LOCAL、ECT 六分量=0、L 退化为单点 {CERTIFIED}、D_max=∞，则 tick ≡ CCA 静态求值、J_TREE ≡ J_MOD、退化链继续落到 R72/R71/R68。所有新定理在退化条件下逐指令等于 R73 定理。

# IP-303/304 MBT + BTEC：计量行为树
@dataclass(frozen=True)
class BTEC:
    kind: str                       # SEQ/SEL/PAR/RETRY/TIMEOUT/RATE/LEAF
    ec: EvidenceContract            # R73 EC（LEAF）；控制节点继承/扩展
    tick_budget_us: float
    fallback_depth_max: int = 4
    safety_claim: Optional[str] = None      # None = 仅任务
    placement: str = 'LOCAL'                # LOCAL/EDGE/CLOUD/PINNED_LOCAL
    seal_ref: str = 'SEAL-BT'

@dataclass
class TickResult:
    status: str                     # SUCCESS/FAILURE/RUNNING
    cert: Cert                      # (claim, label, tau, u, age, trust)
    delta: str                      # 退化标签
    spent_us: float
    bb: dict

def tick(n, bb, budget):
    kind = n.btec.kind
    if kind == 'LEAF':
        if n.btec.placement == 'PINNED_LOCAL' and not is_local():   # 定义 396
            return TickResult('FAILURE', CERT_UNKNOWN, 'UNKNOWN', 0.0, bb)
        a = now() - bb['capture_ts']
        u_age = sqrt(norm(bb['vel'])**2*a*a + 0.25*norm(bb['acc'])**2*a**4)  # 定义 389
        ev = n.impl.evaluate(bb)
        label = certify(ev, u_age, n.btec, bb['trust'], a)   # T-GATE + 有效域
        return TickResult('SUCCESS', Cert(label, u_age, ...), label, ev.wcet, bb)

    if kind == 'SEQ':
        worst, spent = 'CERTIFIED', 0.0
        for c in n.children:
            r = tick(c, bb, budget - spent)
            spent += r.spent_us
            if r.status != 'SUCCESS': return r
            worst = meet(worst, r.delta)          # 只能变弱（引理 38）
        return TickResult('SUCCESS', combine(n, worst), worst, spent, bb)

    if kind == 'SEL':                              # fallback
        worst, spent = 'CERTIFIED', 0.0
        for c in n.children:
            r = tick(c, bb, budget - spent)
            spent += r.spent_us
            worst = meet(worst, r.delta)           # 失败分支的退化仍计入
            if r.status == 'SUCCESS':
                return TickResult('SUCCESS', combine(n, worst), worst, spent, bb)
        return TickResult('FAILURE', CERT_UNKNOWN, 'UNKNOWN', spent, bb)

    if kind == 'PAR':
        rs = [tick(c, bb, budget / len(n.children)) for c in n.children]
        if any(r.status != 'SUCCESS' for r in rs):
            return TickResult('FAILURE', CERT_UNKNOWN, 'UNKNOWN', sum(r.spent_us for r in rs), bb)
        worst = meet_all(r.delta for r in rs)
        return TickResult('SUCCESS', merge_parallel(rs), worst, sum(r.spent_us for r in rs), bb)

# IP-308 FBA：轨迹级退化预算（防安全稀释）
class FallbackAuditor:
    def __init__(self, D_max, w=(0, 0.1, 1.0, 10.0)):
        self.D, self.D_max, self.w = 0.0, D_max, w
    def on_tick(self, r):
        self.D += self.w[label_index(r.delta)]
        if r.delta != 'CERTIFIED':
            log_regime_change(r.cert)              # 每次退化都是显式 regime change
        if self.D > self.D_max:
            return 'SAFE_STOP'
        return 'CONTINUE'

# IP-305 ECT：边缘时间六分量
def edge_temporal_unc(ev, now):
    a = now - ev.capture_ts
    u_age  = sqrt(norm(ev.vel)**2*a*a + 0.25*norm(ev.acc)**2*a**4)
    u_sync = ev.clock_skew_bound
    u_jit  = ev.jitter_p99
    u_loss = ev.p_loss * ev.u_payload
    part   = gate_partition(ev.p_partition, ev.detect_delay)   # 不确定 ⇒ 视为分区
    trust  = gate_trust(ev.attestation, ev.version_hash)      # 失败 ⇒ ADVISORY
    return TemporalU(u_age, u_sync, u_jit, u_loss, part, trust)

# IP-306 EPA：放置与 deadline 闭合
def place(module, p, link):
    L = link.envelope(p)
    ec = module.ec
    ec2 = replace(ec,
        temporal=TemporalEnvelope(L.rtt_p99, L.jit, L.loss, L.trust),
        wcet_eff=ec.wcet + L.rtt_p99 + L.jit)
    if ec2.wcet_eff > ec2.deadline: return demote(ec2, 'DEADLINE')
    if not L.trust: return downgrade_advisory(ec2)
    return ec2

# IP-307 OEP：卸载证据规划（10Hz，防抖）
def offload_plan(mods, links, risk, cur):
    def J(o):
        q = sum(expected_model_quality(m, o[m]) for m in mods)
        a = sum(expected_age(m, o[m]) for m in mods)
        mig = sum(migration_cost(o[m], cur[m]) for m in mods)
        return q - risk.lam_age*a - mig
    o = optimize(J, constraints=[deadline_closure, t_gate, migratable])
    return hysteresis(o, cur, min_dwell=0.5)       # 防止卸载震荡

# IP-309/310 迁移 + 可信门控
def migrate(T, p_new):
    quiesce(T)                                     # 等所有 Running 结束
    st = export_state(T); assert version_match(T, p_new)
    T2 = rebind(T, p_new); T2.cert = reseal(T2)
    atomic_swap(T, T2)                             # 失败则回滚 + local replica

def t_gate(a, b):
    if attested(a) and attested(b) and version_match(a, b) and fresh(a, b):
        return compose(a, b, 'PAR', audit)         # 可缩窄
    return advisory(a), advisory(b)                # 门控：无权签安全主张

# IP-311 ECHO 主闭环
def ECHO_round(M, obs, audio, tac, depth, links):
    d_ev = M.dpe.update(depth, rgb, M.cam_state, M.motion, M.peers)   # R73 DPEM†
    if M.clock.due_place():                        # 10Hz：放置决策（主动感知）
        M.place = offload_plan(M.mods, links, M.risk, M.place)
        M.dmr.migrate_if_needed(M.place)           # 子树迁移（引理 42）

    if M.clock.due_metric():                       # 50Hz：计量 BT 执行
        r = tick(M.root, M.bb, M.tick_budget)
        if M.fba.on_tick(r) == 'SAFE_STOP':
            return M.safe_stop()                   # 退化稀释 → 本地安全停机
        if r.cert.label == 'CERTIFIED':
            M.snapshot.write(r.cert, d_ev, ...)    # 只有 CERTIFIED 更新安全快照
        else:
            M.snapshot.write_advisory(r.cert)      # advisory 只服务任务
        M.mreg.audit()

    # 控制域（1kHz，PINNED_LOCAL，只读本地快照，零分配）
    snap = M.snapshot.read_latest()
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.cert.u_age),
                              M.risk_params)       # age 强制进入风险（引理 43）
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop)
    k = M.c_ras_wm.certified_prefix(A, lam)        # 安全核本地固定
    M.ctrl_out.publish(k, lam)
    return k, lam, J_TREE(M)                       # 树级组合证书

## 4. 推导

**引理 38（计量 tick 的退化单调性）** 对任意节点 n 与任意 tick，返回证书的标签 δ(n) ≤ min{ δ(leaf) : leaf 在本次 tick 中实际执行且未被可证明等价地跳过 }，在偏序 L 下成立。证明：对树结构归纳。LEAF 由 certify 直接给出；SEQ 取 meet；SEL 的关键是**失败分支的 δ 也参与 meet**，因此「试错后成功」不能洗掉失败分支的退化；PAR 取 meet + 一致性审计。系：**任务成功 ≠ 安全主张成立**——这是把 BT 从「控制流」提升为「可审计证据过程」的分水岭。

**引理 39（tick 预算吸收与活性）** 设每拍预算 B_tick 有限、树深 ≤ 8、Running 节点 ≤ 8、每个非 Running 叶子消耗 ≥ ε > 0 或返回 FAILURE，则每拍 tick 在有限步内终止，总时间 ≤ B_tick。证明：以「剩余预算」为秩函数，非 Running 路径严格下降；Running 节点数有界避免活锁。系：**反应性不是免费的，它被预算显式定价**。

**引理 40（放置的时间单调性）** 若 L(p′) 逐分量不优于 L(p)，则 EC@p′ 的 temporal 不确定度 ≥ EC@p，有效域 ⊆。证：u_age/u_jitter/u_loss/u_partition 均为对应包络分量的非减函数；deadline 闭合随 W_eff 单调收紧。系：**总不确定度不单调**（模型质量可反向变化），故安全论证只用时间包络上界，OEP 才需要真正的多目标优化。

**引理 41（局部安全核的信息隔离）** 若控制域节点 PINNED_LOCAL 且其输入只来自本地快照的风险参数与 λ，则任何边缘放置/分区/证明失败都不能改变控制律的安全包络；边缘影响只能通过 λ 的 u_age 项传导。证明：信息流隔离（远程数据无法进入控制域输入通道）+ 定义 396。系：**边缘威胁是效率威胁，不是安全威胁**——但该结论的条件是引理 43（age→λ 单调）。

**引理 42（子树迁移等价性）** 若 T 在静默状态下从 p 迁到 p′，BTEC 除 placement/temporal 字段外逐项相同，且状态版本匹配、证书重签成功，则系统级性质（退化链、风险单调、时序隔离、审计覆盖）保持。证明：同 R73 引理 35 的 DAG 归纳，把「实现替换」换成「放置替换」，temporal 字段作为契约参数被显式更新。系：**热替换定理从「换实现」外延到「换位置」**。

**引理 43（证据陈旧 → 风险强制膨胀）** 若 λ 对 u_age 单调不减、u_age 对年龄 a 单调不减，则认证安全集随证据年龄单调收缩：任何控制策略在 a 增大时可用认证前缀不会变长。证明：由 R72 风险单调定理 23 对输入不确定度的单调性 + u_age 的单调解构。系：**边缘延迟成为安全保守量而非隐藏风险**。

**定理 30（ECHO 严格包含 MODGAUGE）** 在 A111–A113 下，取定义 400 的退化实例化：单根 Sequence、全 LOCAL、ECT=0、L 单点、D_max=∞。则 tick ≡ CCA 静态求值、J_TREE ≡ J_MOD，退化链逐指令等于 R73 → R72 → R71/R68。**安全侧单调不减，效率仅在契约满足时获益。**

**定理 31（反应式-边缘证书可靠性）** 在 A111–A113（R73：契约表达力、conformal 校准、通道 Lipschitz）+ A114（叶子 tick 的本地不确定度与标签可靠、fallback 单调）+ A115（时间包络覆盖真实延迟、分区检测在其声明界内可靠）+ A116（T-GATE 健全：不可信模块不能进入安全组合）+ A117（PINNED_LOCAL + age→λ 单调）下，Valid(J_TREE) ⇒ 物理执行风险 ≤ ε。证明分解：控制域安全由引理 41/43 独立于边缘；感知/估计只影响任务级决策，且其时间不确定度被保守上界抬高；退化序列由引理 38 + 定理 32 约束。**证明重量落在「时间包络是否覆盖真实延迟」与「退化标签是否正确」上**。

**定理 32（轨迹级退化非稀释）** 定义势函数 Φ_t = D_t + κ·u_t（退化预算 + 实际不确定度）。在引理 38（fallback 只能弱化）与每拍退化成本有界下：若对所有 t 有 Φ_t ≤ Φ_max，则不存在通过审计却违反安全主张的轨迹；且当 D_t 将越过 D_max 时，FBA 在下一控制拍之前触发 SAFE_STOP。证明要点：每次非 CERTIFIED tick 使 D 单调增、可签发安全主张的「信用」单调减；CERTIFIED 只能在一次全有效域成功后恢复，故任意长退化序列的可签发信用有上界；势函数不增 ⇒ 不存在「无限次合规退化」的安全稀释路径。系：**回应了 R73 最大风险在控制流层的镜像——不再有「每一步都合规」的错误世界**。

**定理 33（边缘分区零级联）** 在检测界内检出分区/卡顿后，OEP 将该链路标记 dead，DMR 把远程子树降为 stub/local replica，BT 的 Selector 退到已认证本地子树；由引理 38/40/42 与定理 31，安全保持，任务效率至多下降为本地子树能力差；退化不传播到其他子树。系：**R73 的模块级零级联扩展到放置级零级联**。

## 7. 本轮最大风险

**一句话**：ECHO 把 R73 的「契约表达力」风险沿两个新维度放大——它要求契约同时正确表达「证据有多旧」与「退化到什么程度仍算安全」；一旦 u_age 的运动学上界在非刚性场景（可变形物体、遮挡切换、多人）失效，或退化标签把一次「形式合规但实质已不安全」的 fallback 误判为 CERTIFIED，轨迹级退化预算也只能守住它被喂进去的那个错误标签——于是系统会用一棵**每一拍都通过审计、每一次 fallback 都有证书**的行为树，沿着一条由合规退化铺成的路径，稳定地走到不安全的终点。

次级风险与缓解：
1. **任务成功/安全主张混淆** → 双通道证书（safety / advisory）；安全快照只接受 CERTIFIED；E397/E399 专门对抗。
2. **退化预算 D_max 难标定** → 离线最坏轨迹 + 在线保守初值 + 随部署数据单调收紧；D_max 作为契约审计项，不随任务任意放大。
3. **u_age 运动学上界失效**（非刚性/遮挡/切换）→ 分段上界 + 光流/接触/本体交叉验证；超出包络即降 ADVISORY；E400 覆盖。
4. **时钟同步/分区检测不可靠** → 单调时钟 + capture_ts + 心跳 deadline；「不确定」一律视为分区（保守）。
5. **OEP 卸载震荡** → hysteresis + 最小驻留 + 迁移成本显式入目标；E402 监测震荡率。
6. **子树迁移状态不一致** → quiescence + 有版状态 + 原子切换 + 失败回滚到 local replica/stub；E404。
7. **远程证明不可用或被攻陷** → T-GATE 门控为 advisory、本地 replica、单源不定案；E405/E406。
8. **BT 活性/活锁** → tick 预算 + Running 上限 + 深度上限 + FBA 每拍推进；E408。
9. **继承并加宽的契约表达力风险** → 明确列为开放问题；SEAL-Edge / SEAL-BT 密封审计集；分布外一律拒绝签发安全主张，只留 advisory。
