# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；灵感循环第 2 轮；本轮灵感：「动态避障」×「任务分解」）

> 第 57 轮用元少样本、跨模态对账、个性化有界信任把"证据"做厚，并给出五类证据门与组合证书 J_p；但它有两块从未被真正检验的地基：**(a) 世界是冻结的**——𝓜 是一张静态地图，证据一旦入账就可以无限期复用，承诺在某个"点"上被判定，仿佛区域安全性与时间无关；**(b) 任务是扁平的**——部署任务被当作一串检查点，子任务之间的边界被免费跨越，仿佛证据与风险会随分解自动相加。真实四足部署恰好在这两点上崩塌：**动态障碍**（人、其他机器人、滚落物、被踩松的踏板）让"某区域安全"退化为"某区域在某时窗内不被他人占据且地面仍成立"，证据有了**保质期**；**任务分解**（出坞→过湿滑区→穿人行走廊→上坡）让一次承诺裂成 n 次承诺与 n−1 个**界面假设**，而界面恰恰是没人采集证据的缝隙。本轮两个灵感各补一块地基：**动态避障**把区域证据升级为带视界证书的**时空证据场**，把避障动作本身当作探询（绕行可揭开遮挡、也可无限推迟承诺）；**任务分解**把扁平承诺升级为**假设-保证子任务契约**，要求边界**清账**、证据**局部**、风险预算**不膨胀**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"时空可保鲜、边界可清账、分解不膨胀的证据说可信"**。

核心矛盾：
- **H29（动态性 vs 证据保质）**：证据越老越不可信，但补证要花节拍；用预测替代探针能省时间，而预测校准随视界衰减——赌注从"证据质量"又滑向"预测视界的诚实性"，而"我的证据/预测还能信多久"本身需要一张证书。
- **H30（分解 vs 风险守恒）**：分解把一次承诺变成 n 次承诺加 n−1 个界面假设，联合界随承诺数增长；若界面只是"假定"而非"清账"，就出现**责任稀释**——每个子任务都合规，合成任务却在边界缝隙里无人负责。
- **H31（避障即探询 vs 活锁）**：朝能揭开遮挡的方向绕行既降险又增知；但一个总能找到理由"再绕一下"的机器人永不承诺——回避可以退化为"以安全为名的瘫痪"，产生安全但无用的原地循环。

## 0. 直觉与动机

**灵感 1（动态避障 → 时空证据场与承诺时窗）**
直觉：第 57 轮把区域当成一个"东西"，其实它捆了两件不同的事——**地面是什么**（摩擦/承载/坡度，慢变量，第 57 轮的静态证据）和**谁会占着它**（人/车/滚落物，快变量，本轮新增）。把两者解耦，安全就变成一次**时空预约**：承诺一次落脚，等于在 [t, t+τ_c] 内预约一块足迹，要求预测占据的上界在整个时窗内都不侵入、且地面证据仍在保质期内。于是"证据"不再永久有效，而是带 **T_val** 保鲜期；"预测"不再免费，而是只在自校准视界 **H_val** 内算数，越过视界一律退回"停下/补证"。这一刀把动态避障从"绕开移动物"重述为"承诺时窗与预测视界的对齐"。

**灵感 2（任务分解 → 假设-保证契约与边界清账）**
直觉：任务分解不是把一个目标切小，而是把一条承诺拆成一串**带前置/后置条件的子承诺**。每个子任务只在自己的时空包络里积累证据，组合它们并不免费：从"过湿滑区"交接到"穿人行走廊"时，前者建立的后置条件（"已到达干地且定位已重校准"）必须**真的**满足后者的前置假设。这正是形式验证里的 **assume-guarantee**：若界面是"假定"而非"证明"，安全就在边界处蒸发。因此引入**界面证书 H_i** 与**证据局部性**（证据只在其定义域内可用；跨域复用需显式迁移证书，否则就是**证据洗白**），再引入**风险预算守恒**：分解不得让全局失败预算变大，否则必须合并子任务或复用证据，而不是把预算摊薄到无人负责。

**灵感 3（合流 → 分层"分解-避障-承诺"闭环）**
直觉：动态障碍迫使重规划，重规划迫使重新分解，而分解粒度又决定了哪些动态障碍"在范围内"。合成起来是一个分层闭环：**局部避障**在子任务内改轨迹、**重新分解**在高一层改任务结构、**重新协商**在承诺层改时窗或降档。三者的选择不是拍脑袋，而是对"风险—进度—证据可得性"做一次带终止条件的联合裁决。

**灵感 4（融入证据门与证书 → 第六类证据 EV-resv）**
直觉：第 57 轮五类证据都在回答"地面/判断是否可信"；动态世界需要第六类：**预约证据 EV-resv**——"在承诺时窗内，预测占据以 ≥1−δ_res 的概率不侵入我的足迹"。它的边界必须焊死：EV-resv 只说"没人占"，绝不说"地面安全"，因此不能替代 EV-probe\* 或 EV-margin；它只在预测视界内有效；不可逆接触还要求整个时窗的预约再加上所在子任务的界面已清账。证书也从 J_p（单点）升级为 **J_c（组合）**。

**灵感 5（反活锁与可终止性）**
直觉：避障即探询最大的病是"再绕一下就更好"。给每个检查点加两个计数器——**推迟计数 d_cp** 与**累计进度 p_cp**；一旦推迟超界或进度不足，就强制在 {降档承诺, 升 L2 协商, 安全停} 中做决断。安全不能靠永不行动来购买。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（时空证据场 STEF）** 证据地图随时间变化：𝓜(t)={(r,b_r(t),c_r,T_val(r))}，其中 b_r(t)=staleness_decay(b_r, t−c_r)，c_r 为采集时刻，T_val(r) 为**证据保鲜期**（a_r=t−c_r>T_val(r) ⇒ 证据失效，须刷新）。动态占据预测 𝒪_{t:t+H}(x,τ) 附带共形带 C_occ(x,τ)⊆[0,1]，保证 ∀τ≤H_val：P(occ(x,τ)∈C_occ(x,τ))≥1−α_dyn；H_val 为**声明自校准视界**，超出视界的预测不带覆盖声明。**地面证据**与**占据预约**解耦：前者仍由第 57 轮 SMM/XMC 给出，后者由 𝒪 给出。**承诺时窗** W_c=[t,t+τ_c] 有效 ⇔ (i) τ_c≤H_val；(ii) ∀τ∈W_c：C_occ^+(footprint(r),τ)≤θ_occ；(iii) ∀τ：R_terrain(𝓜(t),r)+R_dyn(τ)≤δ_f(r)。承诺 = 一次**时空预约**，而非一次静态判定。

**定义 140（避障即探询 AVP）** 避障候选 A(cp)={a}，每个 a 带四元组 (ΔR_dyn(a), IG_occ(a), Δprog(a), cost(a))；IG_occ 为对**遮挡集** Occ(t)（被动态障碍遮住的区域）的后验熵下降量，绕到侧后方常能以运动换取对地面的观测。评分 S(a)=ΔR_dyn+λ_ig·IG_occ−λ_p·Δprog−cost。**反活锁**：每个检查点维护推迟计数 d_cp 与累计进度 p_cp；若 d_cp>D_max 或 p_cp<π_min，则强制执行 force_decision(cp)∈{commit@降档步态, escalate(L2), safe_stop}，不再接受"再绕一下"。**预约内/外**：子任务承诺期间持有时窗预约 R_i；在 R_i 内的避障只需局部检查，越出 R_i 即视为**预约失效**，必须重新承诺（续约）。

**定义 141（任务分解证据契约 TDEC）** 任务层级 T=({ST_i},≺)，ST_i=(P_i,Q_i,E_i,J_c^i)：P_i/Q_i 为前置/后置条件，E_i 为时空包络，J_c^i 为子任务证书。组合要求**界面清账** H_i：证明"在不确定下 Q_i ⇒ P_{i+1}"，界面残差 g_i 有界。**证据局部性**：证据 e 携带定义域 E(e)；e 可用于 ST_j ⇔ E(e)⊇E_j 且存在**迁移证书** 𝒯_{e→j} 声明域偏移 Δ_dom≤δ_dom；否则记**证据洗白**（非法复用）。**组合缝隙** G(T)=Σ_i g_i + ∞·1[∃ 未清账界面]。分解应沿**证据域边界**切分：同质证据域内切分可共享证据、近乎免费；跨证据域切分必然产生一条界面。

**定义 142（分解风险预算与证书组合律 RBC/J_c）** 全局失败预算 δ_f；分配 {δ_i}、{δ_i^ho} 满足 Σ_iδ_i+Σ_iδ_i^ho≤δ_f。**非膨胀**：δ_f(Dec(T))≤δ_f(T)。**分解悖论**：|承诺数| 增加使联合界变大，朴素切分必然膨胀；此时只能 (a) 合并子任务，(b) 复用/共享证据以压低逐子任务成本，或 (c) 拒绝分解。**组合证书** J_c(T)=⊕_i J_c^i ⊕ {H_i} ⊕ {δ_i 分配证明} ⊕ {𝒯_{e→j}}。健全性：若各子任务健全、界面均已清账、预算守恒，则合成任务健全，上界为 Σ_iδ_i+Σ_i g_i+δ_f。

**定义 143（时空证据门 STG，FSE+ / 第六类证据）** 证据类扩充为六类：EV-probe\*、EV-visit、EV-margin、EV-xmodal、EV-human、**EV-resv**。**EV-resv(r,W_c)** ⇔ C_occ^+ 在 W_c 全域以 ≥1−δ_res 排除 footprint，且 τ_c≤H_val，且第 57 轮静态证据类成立。**硬禁令**：(i) EV-resv 不可替代地面证据（它回答"谁会占"，不回答"地面是否安全"）；(ii) 过视界不加盖；(iii) 不可逆 L2 要求整个 W_c 的 EV-resv **且** 所在子任务界面已清账 H_i。第 57 轮的 β_req 举证门槛继续生效；单点证书 J_p 组合为 **J_c**。

**定义 144（分解-避障-承诺算子 DAC）** 在活动子任务 ST_i 的每个检查点：①**时空刷新**（STEF：过期则补证）；②**预约检查**（W_c 与 𝒪 冲突则进入重规划）；③**重规划裁决**：在 {局部避障 AVP, 重新分解 Dec（须过 RBC）, 延迟/协商} 中按风险—进度—证据可得性择优；④**承诺** ⇔ STG 通过 ∧ W_c 有效 ∧ 界面已清账；否则按元悲观 VOI 选探针；⑤**边界交接**：进入 ST_{i+1} 前须在运行时观测到 Q_i 成立（运行时清账），否则上抬一层重规划。终止性：D_max（推迟）、D_dec（分解深度）、有限探针预算共同保证有限步终止于 {承诺, 局部避障, 重新分解, L2 协商, 安全停}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def stef_refresh(M, r, t, dyn):                        # IP-139
    age = t - M.c[r]
    b = staleness_decay(M.b[r], age)
    fresh = age <= M.T_val[r]                          # 证据保鲜期
    occ = dyn.conformal_forecast(r, t, alpha_dyn)      # 带 H_val 的共形占据带
    return b, fresh, occ

def commit_window_ok(M, r, t, tau_c, occ, dyn):        # IP-139 / IP-143
    if tau_c > occ.H_val: return False                 # 视界外预测不算数
    for tau in ticks(t, t + tau_c):
        if occ.upper(footprint(r), tau) > theta_occ: return False
        if R_terrain(M, r, t) + R_dyn(tau) > delta_f(r): return False
    return True

def avoidance_as_probe(cp, M, occ):                    # IP-140: 避障即探询 + 反活锁
    best = argmax(A(cp), key=lambda a: dR(a) + lam_ig * IG_occ(a, occ)
                                      - lam_p * dprog(a) - cost(a))
    if cp.deferral > D_max or cp.progress < pi_min:    # 不能再"再绕一下"
        return force_decision(cp)                      # 降档承诺 / L2 / 安全停
    return best
```

```python
def decompose_with_conservation(T, delta_f):           # IP-141 / IP-142
    subs = Dec(T)                                      # 沿证据域边界切分
    if any(not dischargeable(H_i) for H_i in interfaces(subs)):
        return None                                    # 界面无法清账 ⇒ 拒绝分解
    alloc = allocate(delta_f, subs)                    # 含 handoff 预算
    if sum(alloc) > delta_f:                           # 分解悖论：预算膨胀
        subs = merge_or_reuse_evidence(subs)           # 合并/复用，否则拒绝
        alloc = allocate(delta_f, subs)
    return subs, alloc

def dac_operator(x0, T, delta_f, budget, consent, personas):  # IP-144
    T, alloc = decompose_with_conservation(T, delta_f)
    for cp in schedule_over(T):
        b, fresh, occ = stef_refresh(M, cp.r, now(), dyn)
        if not fresh:
            probe(M, cp.r); continue                   # 证据过期 → 补证
        if conflicts(cp.envelope, occ):
            act = avoidance_as_probe(cp, M, occ)
            if act == 'redecompose':
                T, alloc = decompose_with_conservation(T, delta_f)
            elif act == 'defer':
                return negotiate_or_stop(cp, tau_int(personas.active.auth))
            else:
                replan_local(cp, act)
        if stg_gate(cp, M, personas, occ, T)[0] == 'ok' \
           and commit_window_ok(M, cp.r, now(), cp.tau_c, occ, dyn) \
           and interface_discharged(cp, T):            # 运行时清账
            commit(cp); cp.progress += progress_of(cp); continue
    return Jc(T, alloc, M, probe_log, consent_log, occ_state, dec_log, auth_log)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| STEF | O(\|V\|·H_val/Δτ·d_occ) | O(\|V\|·H_val/Δτ) | 保鲜期诚实、视界外不带声明 |
| AVP | O(\|A_avo\|·d_occ) | O(\|Occ\|) | 反活锁（D_max/π_min）、遮挡估计保守 |
| TDEC | O(\|T\|·d_contract)（缓存） | O(\|T\|·d_contract) | 界面可清账、证据局部性 |
| RBC | O(\|T\| log\|T\|) | O(\|T\|) | 预算非膨胀、handoff 计入 |
| STG | O(\|σ\|+\|W_c\|/Δτ) | O(\|σ\|+\|W_c\|/Δτ) | EV-resv 不越级、不替代地面证据 |
| DAC | O(D_dec·(\|CP\|·k_d·(C_VOI+d_occ)+A\*)) | O(\|V\|+\|σ\|+\|T\|) | 有界推迟、D_dec 有界、四态+两支重规划 |

**正确性定理（Spatiotemporal Compositional Soundness, STCS）**：在 A22–A40 之上加 **(A41)** 预测共形：∀τ≤H_val 覆盖 ≥1−α_dyn，视界外声明失效且被遵守；**(A42)** 证据保鲜：T_val(r) 诚实，过期证据不得进入承诺；**(A43)** 界面清账：Q_i 在不确定下蕴含 P_{i+1}，残差 ≤g_i，且运行时被观测核验；**(A44)** 预算守恒与有界推迟：Σδ_i+Σδ_i^ho≤δ_f、分解非膨胀、d_cp≤D_max、分解深度 ≤D_dec。则：

1. **时序承诺健全性**：P(fail | commit within W_c) ≤ δ_f + α_dyn + ε_meta(k) + δ_probe + δ_res。
2. **组合健全性**：P(fail on composed T) ≤ Σ_i P_i(fail) + Σ_i g_i + δ_f；且分解非膨胀（δ_f 不因 Dec 增大，否则分解被拒）。
3. **活性/终止性**：有界推迟 + 有限预算 ⇒ 在 D_max、D_dec 内终止于 {承诺, 局部避障, 重新分解, L2 协商, 安全停}，不存在"以绕行代替决断"的无限循环。
4. **交互单调性延续**：动态预测、避障探询、分解契约只能经"更校准的信念（含加宽）"或"更保守的动作/时窗/预算"影响系统，不存在升险路径。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + α_dyn + ε_meta(k) + δ_probe + ε_h + δ_res·1[L2])
             − P(预测视界被越界使用) − P(界面清账在运行时失效)
             − P(有界推迟机制失效 ∧ 安全停失效)
```

关键：**地面与占据解耦**（两类证据各管各的，EV-resv 永不冒充地面证据）；**时窗与视界对齐**（预测只在自校准视界内算数，越界即停/补证）；**分解必须清账且不膨胀**（界面假设要么被证明、要么被拒绝，绝不允许责任稀释）；**避障有界**（绕行可以增知，但不能以无限推迟购买"安全"）。

## 6. 本轮最大风险

**一句话**：本轮把安全从"静态证据是否可信"接到"时窗内预测是否可信、分解边界是否清账"上，最大风险是**预测视界与界面假设的双重乐观**——预测在 H_val 边缘迅速退化成一个未经校准的猜测，而假设-保证链若把"保证"退化为对相邻子任务的信任，就会出现责任稀释（每个子任务都合规，合成任务却在边界缝隙里失控），再叠加"避障即探询"的推迟偏好，可能让系统要么在视界外自信承诺、要么在安全的名义下无限绕行；必须以硬视界 + 共形带、可机检的界面清账与预算守恒、以及有界推迟三把锁同时约束，宁可停下、补证或拒绝分解，也不越界预测、不假定边界、不以回避代替决断。

## 2. 关键算法伪代码

### IP-139 STEF（时空证据场：保鲜 + 时窗 + 共形视界）

```python
def stef_refresh(M, r, t, dyn):
    age = t - M.c[r]
    b = staleness_decay(M.b[r], age)                  # 静态地面证据随时间衰减
    fresh = age <= M.T_val[r]                         # 是否仍在保鲜期
    occ = dyn.conformal_forecast(r, t, alpha_dyn)     # 附带 H_val 的占据共形带
    return b, fresh, occ

def commit_window_ok(M, r, t, tau_c, occ, dyn):
    if tau_c > occ.H_val:                             # 视界外预测不带覆盖声明
        return False
    for tau in ticks(t, t + tau_c):
        if occ.upper(footprint(r), tau) > theta_occ:  # 占据上界侵入足迹
            return False
        if R_terrain(M, r, t) + R_dyn(tau) > delta_f(r):
            return False
    return True

def evidence_reservation(r, W_c, occ):
    # EV-resv 只回答"谁会占"，绝不回答"地面是否安全"
    return (occ.horizon_covered(W_c) and
            all(occ.upper(footprint(r), tau) <= theta_occ for tau in W_c))
```

### IP-140 AVP（避障即探询 + 反活锁）

```python
def avoidance_as_probe(cp, M, occ):
    cands = admissible_detours(cp, M)
    best = max(cands, key=lambda a: dR(a) + lam_ig * IG_occ(a, occ)
                                 - lam_p * dprog(a) - cost(a))
    if cp.deferral > D_max or cp.progress < pi_min:   # 不能无限"再绕一下"

    if not inside_reservation(best, cp):              # 越出预约 ⇒ 预约失效
        return 'recommit'
    return best

def force_decision(cp):
```

```python
def decompose_with_contract(T):

    for i in range(len(subs) - 1):

def evidence_usable(e, ST_j):
```

```python
def allocate_and_verify(subs, delta_f):
    alloc = spread(delta_f, subs)                     # Σδ_i + Σδ_i^ho ≤ δ_f
    if sum(alloc) > delta_f:                          # 分解悖论：联合界膨胀
```

### IP-144 DAC（分解-避障-承诺算子，分层闭环）

```python
def dac_operator(x0, T, delta_f, budget, consent, personas):
    built = decompose_with_contract(T)
    if built is None: return ('reject', 'interface_unprovable')
    T = built
    T, alloc = allocate_and_verify(T, delta_f)
    if T is None: return ('reject', 'budget_inflation')

    for cp in schedule_over(T):
        b, fresh, occ = stef_refresh(M, cp.r, now(), dyn)
        if not fresh:
            probe(M, cp.r); continue                  # 过期证据 → 补证
        if conflicts(cp.envelope, occ):
            act = avoidance_as_probe(cp, M, occ)
            if act == 'recommit':
                cp.W_c = renew(cp); continue
            if act == 'redecompose':
                T, _ = decompose_with_contract(T)
                T, alloc = allocate_and_verify(T, delta_f)
                if T is None: return ('reject', 'budget_inflation')
                continue
            if isinstance(act, tuple) and act[0] == 'escalate':
                return negotiate_or_stop(cp, tau_int(personas.active.auth))
            if isinstance(act, tuple) and act[0] == 'safe_stop':
                return ('safe_stop', act[1])
            replan_local(cp, act)
        if stg_gate(cp, M, personas, occ, T)[0] == 'ok' \
           and commit_window_ok(M, cp.r, now(), cp.tau_c, occ, dyn) \
           and interface_discharged(cp, T):           # 运行时边界清账
            commit(cp); cp.progress += progress_of(cp); continue
        p = argmax(admissible_probes(cp, M, F_abs),
                   key=lambda q: voi_meta_pessimistic(q, M) - cost(q))
        if voi_meta_pessimistic(p, M) >= theta_voi:
            execute_probe(p); continue
        if not reroute_or_redecompose(cp, T): return ('safe_stop', 'no_progress')
    return ('ok', compose_certificate(T, alloc))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| STEF | O(\|V\|·H_val/Δτ·d_occ) | O(\|V\|·H_val/Δτ) | 保鲜期诚实、视界外不带声明（A41/A42） |
| AVP | O(\|A_avo\|·d_occ) | O(\|Occ\|) | 反活锁有界、遮挡估计保守（A44） |
| TDEC | O(\|T\|·d_contract)（缓存） | O(\|T\|·d_contract) | 界面可清账、证据局部性（A43） |
| RBC | O(\|T\| log\|T\|) | O(\|T\|) | 预算非膨胀、handoff 计入（A44） |
| STG | O(\|σ\|+\|W_c\|/Δτ) | O(\|σ\|+\|W_c\|/Δτ) | EV-resv 不越级、不替代地面证据（A40/A43） |
| DAC | O(D_dec·(\|CP\|·k_d·(C_VOI+d_occ)+A\*)) | O(\|V\|+\|σ\|+\|T\|) | 有界推迟、D_dec 有界、四态+两支重规划（A44） |

**正确性定理（Spatiotemporal Compositional Soundness, STCS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 预测共形与视界诚实：∀τ≤H_val 覆盖 ≥1−α_dyn，视界外声明失效且被遵守；**(A42)** 证据保鲜：T_val(r) 诚实，过期证据不得进入承诺；**(A43)** 界面清账：Q_i 在不确定下蕴含 P_{i+1}，残差 ≤g_i，且运行时被观测核验，跨域复用有迁移证书；**(A44)** 预算守恒与有界推迟：Σδ_i+Σδ_i^ho≤δ_f、分解非膨胀、d_cp≤D_max、分解深度 ≤D_dec。则：

1. **时序承诺健全性**：P(fail | commit within W_c) ≤ δ_f + α_dyn + ε_meta(k) + δ_probe + δ_res；视界外承诺概率为 0（被硬规则拒绝）。
2. **组合健全性**：P(fail on composed T) ≤ Σ_i P_i(fail) + Σ_i g_i + δ_f；若 Σ_iδ_i+Σ_iδ_i^ho>δ_f 则分解被拒，故 δ_f 不因分解而膨胀。
3. **活性/终止性**：有界推迟、有限分解深度与有限探针预算 ⇒ 在 D_max、D_dec 内终止于 {承诺, 局部避障, 重新分解, L2 协商, 安全停}，不存在"以绕行代替决断"的无限循环。
4. **交互单调性延续**：动态预测、避障探询、任务分解只能经 (a) 更校准的信念（含强制加宽）或 (b) 更保守的动作/时窗/预算影响系统，不存在升险路径；EV-resv 的加入只能缩小可承诺时窗，不能扩大。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + α_dyn + ε_meta(k) + δ_probe + ε_h + δ_res·1[L2])
             − P(预测视界被越界使用) − P(界面清账在运行时失效)
             − P(有界推迟机制失效 ∧ 安全停失效)
```

关键：**地面与占据解耦**（EV-resv 永不冒充地面证据，跨模态/元证据仍由第 57 轮管辖）；**时窗与视界对齐**（预测只在 H_val 内算数，越界即停/补证）；**分解必须清账且不膨胀**（界面假设要么被证明、要么被拒绝，绝不允许责任稀释）；**避障有界**（绕行可以增知，但不能以无限推迟购买"安全"）。

云边协议 CEB++ → **CEB+++**：云端可下发动态预测模型与子任务分解模板，但**预测模型与分解模板也要过隔离区**——先以影子模式在边端探针流上运行，时序回归测试（视界内覆盖率不降 ∧ 视界外不越用 ∧ 界面清账率不降 ∧ 分解非膨胀）通过后才接管承诺判定；边端回传预测残差、界面交接失败事件与证据洗白告警，作为云端重校准与分解模板修补的依据。第 57 轮"一切判定器走隔离"在本轮推广为"**一切预测与分解走清账**"。

## 6. 本轮最大风险

**一句话**：本轮把安全从"静态证据是否可信"接到"时窗内预测是否可信、分解边界是否清账"上，最大风险是**预测视界与界面假设的双重乐观**——预测在 H_val 边缘迅速退化为未经校准的猜测，而假设-保证链若把"保证"退化为对相邻子任务的信任，就会出现责任稀释（每个子任务都合规，合成任务却在边界缝隙里失控），再叠加"避障即探询"的推迟偏好，可能让系统要么在视界外自信承诺、要么在安全的名义下无限绕行；必须以硬视界 + 共形带、可机检的界面清账与预算守恒、以及有界推迟三把锁同时约束，宁可停下、补证或拒绝分解，也不越界预测、不假定边界、不以回避代替决断。
