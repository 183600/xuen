## 1. 直觉（先讲人话）

### 1.1 文化适应性 = 读空气，而不是背字典
上轮的直觉是「多背几种文化」——用数据增广覆盖 5 类泛化轴（I1）。本轮更深的直觉是：**真正会适应的人不是背下所有文化，而是从眼前的线索推断「我现在处在哪种文化」，然后调整行为。** 训练集只给了「标称文化」的成功演示，320 次计分评测却都在「异文化」里（换桌布、加杂物、换材质、偏位置、真人闯入改世界）。与其要求增广覆盖测试分布（要求极高、伪影风险大），不如训练一个**文化推断器**：从 `obs_delta_indices` 指定的短历史里估计当前偏移，再把估计作为条件喂给策略。关键合规约束：这种适应必须在训练时学会、测试时只做前向推断，**不更新权重、不跨 episode 记忆**（`reset()` 清空），否则踩「在线学习」红线。

### 1.2 扩散策略 = 官方已经给了「带温度的行为生成器」
官方 DiT 动作头（F13）本质上是一个能表示多模态行为、可被外部信号引导、可做条件续写的生成器。它恰好给了文化适应性两个抓手：(a) 同一场景在不同文化下常有多种合法做法 → 多模态建模；(b) 推断出的文化要能「引导」生成 → 条件化 + 重排序/引导。代价是：**官方已是 4 步推理，延迟红利已经吃过一轮；真正的瓶颈从「去噪步数」转移到了「T_a 摊销、backbone 刷新、重排序预算」**。

### 1.3 合流：在官方 DiT 上加「文化条件 + 引导 + 修复」
本轮不重造扩散，而是把上轮散落的 I1/I2/I4/I5/I6 收束到官方 DiT 上：**文化上下文编码器（读历史）→ adaLN/交叉注意力条件化 → 进度/安全 critic 对 K 个候选 chunk 重排序 → 干预后在 chunk 边界做轨迹修复 → 固定 T_a 下的延迟-反应性联合设计**。这把「文化适应性」落成可测量的机制，把「扩散策略」落成对官方底座的正确利用方式。

## 2. 严谨定义

### 2.1 文化、文化偏移、适应间隙（操作化定义）
把「文化」操作化为一个决定观测-动作联合分布的潜变量 c。训练文化 `c_k` = 任务 k 的标称场景；测试文化 `c' = s(c_k)`，`s ∈ S = {位置, 干扰物, 背景, 外观, 人为}`。策略类为

`π_θ(a_{t:t+T_a−1} | o_{≤t}, ẑ_t)`，`ẑ_t = E_ψ(h_t)`，

其中 `h_t` 是 `obs_delta_indices` 选定的历史窗口（F9），θ、ψ 在测试时冻结。定义**适应间隙**

`Gap(π) = E_{c'~P_test}[R(π; c')] − E_{c~P_train}[R(π; c)]`，

**文化适应性** = 在无梯度更新、无跨 episode 记忆下，`ẑ` 条件化相对「忽略 ẑ 的官方基线」在最坏文化组上的风险下降：

`A(π) = max_g R_g(π_base) − max_g R_g(π_ctx)`。

这是可测量的（实验里直接算），不是隐喻。**可辨识性条件**：`ẑ` 必须是偏移的充分统计量而非任务 ID 的捷径，即 `I(c; ẑ | o)` 高、且对「同任务换文化 / 同文化换任务」的反事实测试稳定。合规边界一句话：**episode 内用观测做前向/滤波 = 闭环控制，合规；用评测数据更新权重或跨 episode 记忆 = 在线适应，红线。**

### 2.2 三类偏移：不变 / 等变 / 重规划
上轮 Q1 问「视觉变了、动作语义不变」对哪些轴成立。本轮给出三分法：

- **不变（nuisance）**：若 `π*(a|o) = π*(a|s(o))`，则 s 为 nuisance（背景、非接触干扰物、保 affordance 的外观变化）。训练加 `L_inv`：对表征与预测 chunk 施加一致性。
- **等变（位置）**：存在刚体 `T`，`π*(·|T·o) = T·π*(·|o)`。`ee` 控制空间下动作就是位姿，`T` 直接作用，`L_equi = ||T·a_chunk − π(T·o)||²` 可精确施加（官方「native relative representation」已部分等变，本点把它显式化）。`joint` 空间则需 FK→T→IK 且受关节限位约束，只在对可达域内施加。
- **重规划（人为干扰）**：世界状态被外力改写，旧 chunk 不再最优；既非不变也非等变。检测（手部 + ee 跟踪残差 + 运动不连续）→ 在下一个 chunk 边界用新观测重生成；可选「掩码轨迹修复」保证动作连续。

**结论**：背景/干扰物/外观 → 不变损失；位置 → 等变损失；人为干扰 → 事件检测 + 重规划。每类增广配对应损失，而不是把四类增广都当「像素扰动」——这是上轮 I1 缺失的因果约束。

### 2.3 文化条件扩散（在官方 DiT 上的最小改动）
官方 DiT 已用条件 `c = (VLM 特征, 机器人状态, language)` 做 4 步去噪。最小改动：把 `ẑ_t` 作为额外条件，经 **adaLN 调制（零初始化）** 或 **一个额外 cross-attention token** 注入 DiT；不改变扩散目标本身。训练总损失

`L = L_diff + λ_c L_ctx + λ_i L_inv + λ_e L_equi + λ_m L_mask`，

- `L_diff`：官方去噪/流匹配损失（ε 或 v 预测，F13）。
- `L_ctx`：文化推断辅助损失（增广伪标签上的分类或对比损失），迫使 `ẑ` 编码「偏移」而非「任务 ID」。
- `L_inv`：nuisance 轴上表征/动作一致。
- `L_equi`：位置轴上 ee 动作等变。
- `L_mask`：随机掩掉动作 horizon 的一段、用未掩前缀条件重建，为测试时「干预后续写」做准备。

### 2.4 固定 T_a 的延迟-反应性约束（本轮修正）
设控制周期 `Δt`，单 chunk 延迟 `C = L_backbone/K_b + K_r·L_DiT(4) + L_critic`（`K_b` = backbone 每几个 chunk 刷新一次，`K_r` = 重排序候选数）。因为 T_a 固定且整段执行（F11），有两条硬约束：

- **不饿死**：`C ≤ T_a·Δt`（否则执行完 T_a 步后机器人要等下一次推理）。
- **干预盲窗**：`T_a·Δt ≤ ρ`（ρ = 可接受的干预后陈旧时长）。

于是可行区间 `C/Δt ≤ T_a ≤ ρ/Δt`，**存在可行 T_a 当且仅当 `C ≤ ρ`**。这给出一条清晰的工程目标：把单 chunk 延迟压到「可接受干预延迟」以下；官方 horizon=30，故 T_a ∈ [1,30]。这取代了上轮「运行时动态 chunk」的错误设计。

### 2.5 引导与重排序（用扩散的多模态性换鲁棒性）
官方 4 步推理很便宜，可一次生成 `K_r` 个候选 chunk（不同噪声种子），用进度 critic `V_η` 与安全 critic `C_ω` 重排序：

`a* = argmax_{a^(1..K_r)} [ V_η(o, a) − λ C_ω(o, a) − μ·smooth(a) ]`。

这比每步梯度引导便宜、实现简单，且天然利用多模态。梯度引导作为备选；若采用，最好把引导蒸馏进训练以免推理开销。

# UniBot-V1 创新点清单（第 2 轮 v2.0 · 文化适应性 × 扩散策略）

> 承接上轮 v1.0；本轮把 5 类泛化重述为「文化偏移」，在**官方 4 步 DiT 扩散动作头**（F13）上加「文化条件化 + 引导重排序 + 轨迹修复 + 固定 T_a 延迟工程」。事实检索日 2026-11-27，新增 F9–F16；清单只增量深化与修剪。

## 0. 一句话方案

**Culture-Conditioned Diffusion VLA**：慢 VLM backbone（低频、特征缓存）→ 文化上下文编码器 `ẑ=E_ψ(h)`（读 `obs_delta_indices` 历史）→ 官方 DiT 以 adaLN 条件于 `ẑ`（4 步去噪、horizon 30）→ 进度/安全 critic 对 K 个候选 chunk 重排序 → 干预在 chunk 边界用新观测（可选掩码修复）重生成 → 固定 `T_a` 下联合优化延迟与反应性。**一个策略服务，无第二模型。**

---

## 1. 形式化与推导

### 1.1 符号

- 训练文化 `c_k`：任务 k 的标称场景；测试文化 `c'=s(c_k)`，`s∈S={位置,干扰物,背景,外观,人为}`（F2）。
- 历史窗口 `h_t` 由 `obs_delta_indices` 决定（F9）：例如图像 `[-10,-5,-2,0]`、状态 `[-4,-2,0]`。
- 文化编码器 `ẑ_t = E_ψ(h_t) ∈ R^d`；策略 `π_θ(a_{t:t+T_a−1}|o_{≤t},ẑ_t)`；θ、ψ 测试时冻结。
- 适应间隙 `Gap(π)=E_{c'}[R]−E_{c}[R]`；文化适应性 `A(π)=max_g R_g(π_base)−max_g R_g(π_ctx)`（g 为文化组）。**测试时只做前向推断、不更新权重、不跨 episode 记忆；`reset()` 清空（F12）。**

### 1.2 文化条件 DiT 的最小改动

官方 DiT（F13）条件为 `(VLM 特征, 机器人状态, language)`。最小改动：把 `ẑ` 经 **adaLN 零初始化调制**（`norm_type: ada_norm` 已具备）或额外 cross-attention token 注入；不改变去噪目标。总损失：

```
L = L_diff + λ_c·L_ctx + λ_i·L_inv + λ_e·L_equi + λ_m·L_mask
```

| 项 | 作用 | 备注 |
|---|---|---|
| `L_diff` | 官方去噪/流匹配（ε 或 v 预测） | 4 步推理，horizon 30 |
| `L_ctx` | 文化推断（增广伪标签分类 / 对比） | 迫使 `ẑ` 编码偏移而非任务 ID |
| `L_inv` | nuisance 轴表征/动作一致 | 背景、非接触干扰物、保 affordance 外观 |
| `L_equi` | 位置轴 ee 动作等变 | `||T·a−π(T·o)||²`，可达域掩码 |
| `L_mask` | 随机掩掉 horizon 一段、用前缀重建 | 为干预后「轨迹修复」做准备 |

### 1.3 三类偏移损失（回答上轮 Q1）

- **不变**：`π*(a|o)=π*(a|s(o))` → `L_inv`。用于背景/干扰物/外观。
- **等变**：`π*(·|T·o)=T·π*(·|o)` → `L_equi`。`ee` 空间动作即位姿，`T` 直接作用；官方「native relative representation」已部分等变，显式约束是把它钉死。`joint` 空间需 FK→T→IK，只在对可达域内施加。
- **重规划**：人为干扰改写世界状态，旧 chunk 失效 → 检测 + chunk 边界重生成（可选掩码修复）。既非不变也非等变。

### 1.4 固定 T_a 的延迟约束（本轮修正上轮 I4）

`T_a` 握手固定、整段执行完才回调（F11）。设控制周期 `Δt`、单 chunk 延迟

```
C = L_backbone/K_b + K_r·L_DiT(4) + L_critic
```

（`K_b` = backbone 每几个 chunk 刷新；`K_r` = 重排序候选数）。两条硬约束：

```
不饿死：   C ≤ T_a·Δt
干预盲窗： T_a·Δt ≤ ρ
⇒  C/Δt ≤ T_a ≤ ρ/Δt，且存在可行 T_a ⇔ C ≤ ρ
```

官方 horizon=30 ⇒ `T_a ∈ [1,30]`。工程目标因此明确：**把 C 压到可接受干预延迟 ρ 以下**；这取代上轮「运行时动态 chunk」的错误设计。

### 1.5 重排序目标

4 步推理便宜，可一次生成 `K_r` 个候选（不同噪声种子），用进度 `V_η`、安全 `C_ω` 打分：

```
a* = argmax_{a^(1..K_r)} [ V_η(o,a) − λ·C_ω(o,a) − μ·smooth(a) ]
```

比每步梯度引导便宜、实现简单，天然利用扩散多模态。梯度引导为备选；若用，优先蒸馏进训练以免推理开销。

## 2. 创新点清单（v2.0）

### I9 文化上下文编码与条件化 ★★★★★（本轮核心新增）
- **动机**：官方基线条件只有 VLM 特征 + 当前状态，无显式「当前处在哪种偏移」的推断；覆盖式增广要求高、伪影风险大（上轮最大风险）。
- **与现有方案差异**：把泛化从「覆盖测试分布」重构为「从历史推断偏移并条件化」。`ẑ` 是低维信息瓶颈，经 adaLN/交叉注意力注入 DiT；`L_ctx` 迫使它编码可迁移的偏移而非任务 ID。测试时仅前向推断，合规。
- **技术可行性**：高。backbone 已是 transformer（Qwen 系）；编码器可轻量（状态差分 + 池化视觉特征的 GRU/小 Transformer）。
- **资源**：复用 backbone；新增参数 < 50M；训练随主训练。
- **落地步骤**：①用增广定义文化伪标签；②训练 `E_ψ` + `L_ctx`；③留一文化组合消融；④反事实捷径测试（同任务换文化 / 同文化换任务）；⑤真机抽测。
- **风险**：捷径学习（任务 ID/背景）；短窗不可辨识。缓解：反事实增广 + 留出组合 + 低维瓶颈。

### I1 文化一致性增广与不变/等变约束 ★★★★★（深化上轮 I1）
- **动机**：5 轴偏移是全局乘性损失（P2）；上轮覆盖式增广的伪影风险。
- **差异**：目的从「覆盖」降为「监督推断」；每轴配因果损失：背景/干扰物/外观 → `L_inv`；位置 → `L_equi`；轨迹级用小型扩散模型生成变体，替代上轮刚性重拼接（避免物理不可行动作）。
- **可行性**：高-中。LeRobot 数据 4 相机 + 状态齐全；SAM/Grounded-SAM + inpainting 做视觉轴；ee 刚体变换做位置轴。
- **资源**：1×A100 + 2TB；轨迹扩散 1–2 GPU 天。
- **步骤**：①每任务抽 50 eps 做视觉 QA 门禁；②先上背景/干扰物（零动作风险）；③外观/位置小规模验证；④轨迹级生成式增广；⑤分轴消融。
- **风险**：`joint` 空间等变需 IK，可能奇异/不可达；生成轨迹物理不可行。缓解：IK 残差掩码 + 可达域限制 + QA 门禁。

### I2 文化分组鲁棒优化（Group DRO）★★★★★（深化上轮 I2）
- **动机**：平均分被最弱任务/最险场景支配（P1）；5 轴偏移。
- **差异**：从 `1/成功率` 软加权升级为**最坏组优化**：组 = `(任务族 × 偏移轴)`，`min_θ max_g E_g[L]`；指数梯度更新组权重；用 `ẑ` 做软组分配以覆盖未见组合。
- **可行性**：高。标准 Group DRO；官方支持全参/LoRA/action-expert 微调（F6/F13）。
- **资源**：LoRA 数天；全参视需要。
- **步骤**：①组定义与离线风险估计；②DRO 训练；③强组下限保护；④留出组验证。
- **风险**：组标签粗糙、未见组合；过拟合最坏组。缓解：软分配 + 留出组 + 强组下限。

### I3 接触族的 ee 跟踪残差代理 ★★★★（替换上轮 I3）
- **动机**：无触觉（F9）；接触密集/精密族约 15/32（见 §3），是结构性洼地（P4）。
- **差异**：不再引入规则伺服/第二模型。`ee` 模式下「观测 ee 位姿 − 上一指令 ee 位姿」= 跟踪残差 ≈ 接触/受阻/人推代理；作为额外输入 token 喂回同一策略。
- **可行性**：高。`ee` 控制下免费；数据集 + 单任务通道标定自由空间/接触分布。
- **资源**：工程 1 人周；无额外 GPU。
- **步骤**：①定义残差与滤波；②数据集标定阈值；③接入 I9 输入；④接触族单任务通道验证。
- **风险**：残差受动力学/延迟污染；阈值漂移。缓解：短窗滤波 + 学习式标定 + 置信门控。

### I4 干预感知的轨迹修复重规划 ★★★★（修正 + 深化上轮 I4）
- **动机**：人为干扰轴（F2）；`T_a` 固定使反应粒度 = `T_a`（F11）。
- **差异**：上轮「运行时动态 chunk」作废。本轮：手部检测 + ee 残差 + 运动不连续 → 检测「世界被改写」；在下一个 chunk 边界用新观测重生成；可选 `L_mask` 掩码轨迹修复保证动作连续。
- **可行性**：高-中。检测近零训练；掩码修复需训练改造。
- **资源**：1 人周 + 少量训练。
- **步骤**：①检测器在数据集视频上标定误检；②选 `T_a` 控制盲窗；③边界重生成；④掩码修复 vs 直接重生成 A/B；⑤真机。
- **风险**：盲窗内结构性无法反应；误检冻结；修复动作不连续。缓解：小 `T_a` + 滞回 + 平滑约束 + 每 episode 修复次数上限。

### I5 进度/安全引导的扩散重排序 ★★★★（深化上轮 I5）
- **动机**：步骤分 + 180s（F3）；卡死双输；扩散多模态可择优。
- **差异**：单候选 → best-of-`K_r` + 进度 `V_η` / 安全 `C_ω`；进度 critic 同时用于卡滞检测（进度导数≈0 触发重生成）。
- **可行性**：高。4 步 DiT 便宜；critic 小头。
- **资源**：1×GPU 训 critic；工程 1 人周。
- **步骤**：①里程碑/剩余时间标签；②critic 训练；③`K_r` 扫描；④卡滞判据；⑤真机。
- **风险**：critic 校准误差；`K_r` 增延迟。缓解：校准集 + 延迟预算内 `K_r≤3`。

### I6 固定 T_a 的延迟-反应性联合设计 ★★★★★（深化上轮 I6）
- **动机**：N 端口并发、p99 与动作统计被记录（F14/F15）。
- **差异**：官方已是 4 步推理，延迟红利已吃过一轮；本轮聚焦：`T_a` 摊销、backbone 特征缓存（每 `K_b` 个 chunk 刷新，干预强制刷新）、重排序预算 `K_r`、端口独立队列与 episode 隔离、断线重连与健康探针。
- **可行性**：高（纯工程）。
- **资源**：2×A100 80G 共享 backend；1–2 人周。
- **步骤**：①`run_client` 压测 `C` 的 p50/p99；②扫 `T_a × K_b × K_r`；③故障注入（并发/断网/显存）；④冻结配置过 PR4 门禁。
- **风险**：缓存导致场景陈旧；量化损失；并发竞态。缓解：干预强制刷新 + 量化回归 + 端口独立队列。

### I7 世界模型测试时前瞻 ★（裁撤）
- **决定**：**裁撤**。官方策略本身已是生成式去噪（F13），显式世界模型 rollout 与重排序功能重叠且延迟不合算。若未来延迟余量极大再议。

### I8 评测运营闭环 + 文化轴诊断 ★★★★（保留 + 深化上轮 I8）
- **动机**：榜单未上线 + 单任务通道免费（F7/F8）；先手迭代 = 排名复利（P7）。

## 4. 关键伪代码

### 4.1 训练（在官方 action expert 微调上加辅助损失）

```python
def train_step(batch):
    o, a, c_lab, h, mask = batch
    z = culture_encoder(h)                      # ẑ from obs_delta_indices history

    L_diff = diffusion_loss(dit, o, a, z)       # official 4-step DiT objective
    L_ctx  = ce(culture_head(z), c_lab) + contrastive(z, c_lab)
    L_inv  = consistency(dit, o, s_nuis(o), a)  # background / distractor / appearance
    T      = sample_rigid()
    L_equi = equiv_loss(dit, o, a, T) * ik_feasible(o, T)
    L_mask = diffusion_loss(dit, o, a, z, mask=mask)   # masked-trajectory denoising

    L = L_diff + lc*L_ctx + li*L_inv + le*L_equi + lm*L_mask
    group_dro_update(L.detach(), group=culture_group(c_lab))   # (task_family x shift_axis)
    return L
```

### 4.2 推理服务（固定 T_a；每次返回完整 chunk）

```python
class CultureDiffusionPolicy:
    T_A = 8          # fixed at handshake (F11); <= official horizon 30
    K_B = 2          # refresh backbone every K_B chunks
    K_R = 2          # rerank candidates
    def reset(self):
        self.chunk_idx = 0; self.cache = None; self.last_chunk = None
    def get_action(self, obs):
        h = history_from(obs)                        # obs_delta_indices window
        z = self.culture_encoder(h)                  # forward-only (compliant)
        if self.intervened(obs, h):                  # hand + ee residual + motion jump
            self.cache = None                        # force backbone refresh
        if self.cache is None or self.chunk_idx % self.K_B == 0:
            self.cache = self.backbone(obs)
        cands = [self.dit.sample(self.cache, z, steps=4) for _ in range(self.K_R)]
        best  = max(cands, key=lambda a: self.score(obs, a))   # progress - safety - smooth
        # optional: condition on executed prefix for continuity (masked-trajectory model)
        chunk = self.smooth(best)[:self.T_A]
        self.chunk_idx += 1; self.last_chunk = chunk
        return self.pack(chunk)                      # shape (T_A, ...) per F10/F11
```

### 4.3 部署拓扑（F14）

```
[N 台 G1] --WS--> [8765..8765+N-1 轻端点]
   每端点：独立队列 + episode 状态隔离（reset/历史哈希）
             │ 共享推理 backend：6B VLM + DiT-L(4步) + 文化编码器 + critics
             │ backbone 特征缓存（每 K_B chunk 刷新；干预强制刷新）
             │ 健康探针 + p99 监控 + 动作统计自检（F15 / PR4）
元参数：obs_delta_indices 含历史（文化推断/干预证据）
        image_resize 高位相机 240×320 / 腕相机 128×128
        action_chunk_size T_A=8（设计期固定；稳定与反应性的折中）
```

## 5. 延迟预算（量级假设，必须 `run_client` 实测）

| 量 | 符号 | 量级假设 | 备注 |
|---|---|---|---|
| 控制周期 | `Δt` | 33ms（30Hz） | 待核实 |
| backbone 前向 | `L_B` | 30–60ms（6B，fp8，batch） | 待实测 |
| DiT 4 步 | `L_DiT` | 15–40ms（DiT-L，16 层） | 官方 `num_inference_timesteps=4` |
| 重排序 | `K_r·L_DiT` | `K_r=2` → 30–80ms | 与 `K_r` 线性 |
| critic | `L_critic` | 2–5ms | 小头 |
| 单 chunk 延迟 | `C` | `L_B/K_b + K_r·L_DiT + L_critic` | 目标 `C ≤ ρ` |
| 干预盲窗 | `T_a·Δt` | `T_a=8` → 264ms | 要求 ≤ ρ（如 0.5s） |
| 可行 `T_a` | `[C/Δt, ρ/Δt]` | 例：`C=100ms, ρ=0.5s` → `[3,15]` | 存在 ⇔ `C≤ρ` |

> 官方配置 `max_delay: 10` 暗示训练时已做一定延迟补偿，但**服务端 p99 仍须自控**；`T_a` 越大摊销越好、盲窗越长，需按 ρ 选。

## 11. 本轮最值得押注（一句话）
