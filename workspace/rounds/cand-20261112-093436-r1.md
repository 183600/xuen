# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「实时推理」×「激光雷达」）

> 第 57 轮把承诺从「模型置信」推进到「少样本可校准、跨模态可对账、个性化有界的证据」，但它的风险自陈同时暴露了三个尚未处理的时间—空间问题：**(a)** 元推断 q_φ 的时延会进入控制回路，而它的校准契约 ECE_k≤ε_meta(k) 是「给足算力」下的条件校准——一个在 50 ms 算力下校准的模型，可能在 5 ms 算力下系统性过自信；把 50 ms 的证书借给 5 ms 的决策，是把**时延洗成置信**。**(b)** 地图 𝓜 与证据都没有保质期：两次到访之间世界会变（托盘被挪、冰面融化、行人进入），而「陈旧但自洽」的证据与「新鲜」的证据在当前框架里不可区分；第 57 轮把「地图陈旧」列为部署界里的一个减项，却没有把**新鲜度变成可检验的证据**。**(c)** XMC 只做「同一时刻、不同模态」的对账，不做「同一区域、不同时刻」的对账；更糟的是，同一传感器跨时间重复观测会被误当作独立佐证，而单模态共谋的跨时间版本——一个静止的欺骗面——恰恰在时间上最自洽。本轮两个灵感各补一条腿：**实时推理**把推断变成截止感知的任意时间算子，并给出按截止时间索引的校准与「时间压力单调性」；**激光雷达**把几何从视觉的附庸变成高频证伪通道，但以**删失射线语义**为第一原则（无回波≠自由空间）。再由两者合流出台第三个机制：**时空对账**——用高频几何做世界漂移见证，用时间否决权取代部分证据累积。核心命题由「少样本可校准、跨模态可对账、个性化有界的证据说可信」升级为 **「在截止时刻仍新鲜、并经高频几何通道证伪过的证据说可信」**。

核心矛盾：
- **H29（实时 vs 校准）**：风险界与校准通常是渐近、无时间预算的；实时系统要求在 5~50 ms 内给出可承诺的结论。若在短截止下复用长截止的校准证书，就产生「时延洗白」：越紧急越自信，而紧急恰恰是最需要保守的时候。
- **H30（高频 vs 删失）**：LiDAR 是唯一快到能见证世界漂移的模态，但它最有信息量的信号——「无回波」——是删失而非自由空间；透明、镜面、吸光表面恰好产生与自由空间相同的无回波签名。高频会把一个语义错误放大成「每秒三十次独立确认」。
- **H31（新鲜 vs 一致）**：时间一致可以被制造（静止欺骗面在时间上最一致），世界漂移又会让真实变化显得不一致。新鲜是必要的，但新鲜 + 一致仍可能只是「同一个盲区被数了很多遍」；必须区分世界漂移、信念漂移与物理欺骗，并禁止相关样本重复计数。

## 0. 直觉与动机

**灵感 1（实时推理 → 截止感知的任意时间证据）**
直觉：安全决策不是「你能算出的最好后验」的函数，而是「你在承诺那一刻能出具证书的后验」的函数。任意时间推断像限时素描：前几笔必然粗，问题不是「最终画得多像」，而是「在交卷时刻，这张画能担保什么」。于是每次推断都附带三元组（估计、证书、墙钟年龄）：估计会随算力变好，证书必须随截止时间变弱，年龄必须如实记录。**错过截止不是「证据来晚了」，而是「没有证据」**——它必须退回保守共形带，而不是拿半成品后验凑合。更进一步：时间不是调度器的私事，而是证据的一部分；同一观测在 t 与 t+Δ 进入似然时，后者必须更轻。

**灵感 2（激光雷达 → 高频几何证伪，而非高频相信）**
直觉：LiDAR 是一个「快枪手式的怀疑者」，不是一个「快枪手式的信徒」。它极擅长否决：射线穿过了地图声称有障碍的地方、或预测深度与回波系统性不符——这类矛盾便宜、即时、几乎不可伪造；但它不擅长确证机械属性：它看不见摩擦系数 μ、看不见轴承间隙 F_bear，也无法把「无回波」解释成「空」。所以给 LiDAR **否决优先权**：几何矛盾立刻加宽/降档/停；几何一致只在处理删失、入射角、反射率与天气后，才为**几何谓词**出具新鲜证书，绝不为机械谓词背书。物理直觉很直接：透明冰面在视觉上「干」、在触觉上「硬」、在 LiDAR 上「没有回波」——三种模态给出三种不同的「像自由空间」，只有把无回波显式建为删失事件，系统才不会把「没看见」当成「没有」。

**灵感 3（时空对账 → 用时间否决权取代部分证据累积）**
直觉：第 57 轮的跨模态对账是「空间交叉盘问」；本轮加「时间交叉盘问」——把连续 LiDAR 几何与旧的地图/探针信念对比。这里有一个反直觉但重要的经济学结论：**最便宜的安全动作往往不是积累新证据，而是作废旧证据**。旧探针证据每多活一秒，就多一分被世界漂移背叛的风险；一次覆盖该区域的非删失激光扫描，能把「陈旧的确定」降级为「待复核」，成本远低于再做一次接触探针。但激光只能刷新几何谓词，不能刷新 μ/k；「静止欺骗面在时间上一致」不构成对机械参数的更新。时间一致必须按有效样本量 n_eff 计入，否则同一盲区会被逐帧重复计数。

**灵感 4（实时推理 → 时间压力单调性）**
直觉：时间不够时，安全系统应当「做更少」，而不是「省步骤」。把降级写成一条单调阶梯：(1) 砍掉可选解释渲染；(2) 缩短规划视野/探针数；(3) 加宽信念；(4) 降步态/停/问人。被禁止的降级是：缩短证据 TTL、跳过几何矛盾检查、放弃新鲜度要求、静默吞掉截止 miss。一句话：**可以没时间，不可以没保守**。截止 miss 必须升级为告警与保守模式，而不是悄悄降级；调度器不能成为「把超时藏起来」的合法通道。

**灵感 5（合流 → 证据门从五类到七类、从空间对账到时空对账）**
直觉：第 57 轮证据门 EV-probe*/visit/margin/xmodal/human 在本轮各获时间维度：所有证据挂 TTL 与年龄；新增 **EV-ray**（几何否决与几何佐证，仅限几何谓词）与 **EV-fresh**（新鲜度证书，本身不是独立正证据）；不可逆接触的必要证据集新增两条硬约束：机械证据须在 TTL 内且「无新鲜几何矛盾」。深度再增一层：假承诺需要 陈旧自洽 ∧ 激光删失盲区 ∧ 无新鲜否决 ∧ 截止 miss 被静默忽略——时间与几何把赌注从「证据是否足够」推进到「证据在交卷时是否仍然算数」。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（截止感知任意时间推断 DAI）** 推断算子 I_φ(o_{1:k},z_r,D)→(θ̂,C,q,τ_ret,t_e)，D 为决策截止，q 为算力/迭代级，C 为认证集，t_e 为观测捕获时刻。任意时间单调性：D₁≤D₂ ⇒ C_{D₁}⊇C_{D₂}；截止索引校准：∀k,∀D，ECE_{k,D}(q_φ)≤ε_meta(k,D)，且 ε_meta 对 D 单调不增。时效契约：P(τ_ret>D)≤δ_deadline（τ_ret 由单调时钟测得，时间戳完整性见 A42）。**截止 miss ⇒ (θ̂,C) 不得进入承诺**，退回共形带 C_cf 或保守先验；定义证据年龄 age(e,t)=t−t_capture(e)，处理时延不使证据变新。登记 deadline_log。

**定义 140（证据时效与漂移检测 EVF）** 证据 e 带捕获时刻 t_e、存活期 TTL τ_e(r,type) 与新鲜度权重 φ_e(t)=2^{−(t−t_e)/τ_e(r,type)}；有效置信 p_eff=φ_e·(p−½)+½（向 ½ 收缩，等价于证据对数几率衰减）。世界漂移度 D_t(r;t)=discrepancy(当前非删失几何见证, 存储几何 𝓜_core(r))；漂移事件率 λ_d(r)。时效规则：(F1) 承诺所需每条必要证据须 age≤τ_e 或已被重新见证；(F2) age>τ_e 且无法重见证 ⇒ 降档/绕行/停，不得「带病承诺」；(F3) 新鲜度见证要求**非删失**射线覆盖该区域——「没见证」不等于「新鲜」；(F4) 漂移检测虚警率 ≤δ_drift。

**定义 141（激光几何证据 LGE）** 射线 j 于 t 的观测 z_j∈{hit(r_j), no_return, ghost}；几何假设 H=(n,d,σ_s,o)（法向/偏移/粗糙度/占用）。删失似然：p(no_return|H,geom)=c(θ_inc,range,reflectivity,weather,material)∈(0,1]，**不得令其恒为自由空间**；ghost/多路径建为混合分量。逐射线可靠性 ρ_ray 与「hit」「no_return」分开建模。几何证伪分 Λ_j=(r_j−r̂_j(H))²/(σ_s²+σ_r²)，当 m-of-n 条射线的 Λ_j 超阈值时宣告矛盾，虚警 ≤δ_ray（Chernoff/union bound）。**参数—证据兼容矩阵 C**：EV-ray 仅可为几何谓词 {占用,坡度,台阶高度,障碍存在} 背书，永不可为 {μ,k,F_bear} 背书。

**定义 142（时空对账 TGR）** 空间分歧 D_s(r)（承第 57 轮 D(r)）与时间漂移 D_t(r) 合并为证据场。规则：(R1) **快速否决**：m-of-n 几何矛盾 ⇒ 立即作废触及该几何谓词的全部正证据并降级，实时生效，审计；(R2) **新鲜见证**：TTL 内非删失激光重观测与存储几何在容差内一致 ⇒ 为几何谓词签发 EV-fresh，不刷新机械参数；(R3) **禁止重复计数**：同传感器/同视角/同机制的重复观测按有效样本量 n_eff 计入，无回波按覆盖几何记一次而非按帧记多次，避免「同一盲区数一百遍」；(R4) **欺骗≠漂移**：静止欺骗面的时间一致性不签发机械参数新鲜证书；只有实际探针证伪可撤回机械信念。

**定义 143（实时证据调度 RTS）** 任务按安全关键级 ℓ∈{hard,soft,optional} 与截止 D 入队；调度器为 hard 安全任务预留松弛量并做准入控制。降级阶梯 g₀≻g₁≻…≻g₄（正常→砍可选渲染→缩探针/视野→加宽信念→降步态/停/问人）单调。**时间压力单调性**：可用预算 b₁≤b₂ ⇒ 可行动作集 A(b₁)⊆A(b₂) 且信念宽度非减；任何降低安全性的参数（TTL、几何检查开关、新鲜度要求）不受调度器支配。**截止 miss 策略**：记录、升级为保守模式、进入审计；永不静默丢弃对应安全检查。

**定义 144（时空证据门 TEG 与证书 J_t）** 证据类：EV-probe*/EV-visit/EV-margin/EV-xmodal（限 L1）/EV-human（承第 57 轮），新增 **EV-ray**（几何否决于所有层级；几何正佐证仅限 L1 的几何谓词替代）与 **EV-fresh**（新鲜度证书，非独立正证据）。不可逆接触必要证据集 = ({EV-probe*∨EV-margin} ∪ 佐证) ∧ 全部必要证据 age≤TTL ∧ 无新鲜几何矛盾 ∧ 无未处理截止 miss；EV-ray/EV-fresh 不得满足机械必要集。J_t=(J_p, deadline_log, age_log, ray_log, censoring_params, drift_log, scheduler_log, degradation_log, clock_sync_log)，继承 J_p 全检。

def anytime_infer(o, z, D, budget):                 # IP-139: 截止感知
    t_e, t0 = capture_time(o), monotonic()
    res = init_estimate(o, z)
    while monotonic() - t0 < D - guard and budget.left:
        res = refine(res, o, z); budget.spend(refine_cost)
    if monotonic() - t0 > D:                        # 超时 = 无证据
        return Inf(cls='MISS', belt=conformal_belt(res.residuals))
    return Inf(post=res.post, cert=cal_cert(res, k=len(o), D=D), age=now()-t_e)

def lidar_ray_evidence(scan, H, geom):              # IP-141: 删失语义
    hits, frees, ghosts = partition(scan, H)
    for ray in scan:                                # 无回波是删失，不是自由
        w = rho_ray(ray.incidence, ray.range, ray.reflectivity, geom.weather)
        H = censored_update(H, ray, w, p_ret=censoring(ray, geom))
    contradict = m_of_n([falsify(ray, H) for ray in hits], m, n)
    return H, ('EV-ray', 'veto' if contradict else 'support_geom_only')

def temporal_reconcile(M, r, scan, e):              # IP-142: 时空对账
    if fast_veto(scan, M.geom[r]):                  # R1
        invalidate_geom_evidence(M, r); return M, 'demote'
    if non_censored_cover(scan, r) and within_tol(scan, M.geom[r]):
        M.fresh[r] = issue_fresh(r, predicates=GEOM_ONLY)   # R2
    M.drift[r] = D_t(scan, M.geom[r]); M.audit.log(('drift', r, M.drift[r]))
    return M, 'ok'

def real_time_schedule(tasks, budget):              # IP-143: 时间压力单调
    tasks = reserve_hard_safety(tasks)              # 安全关键先占松弛
    admit(tasks)                                    # 准入控制
    if overrun(tasks): escalate_deadline_miss()     # 不静默
    return degrade_ladder(budget)                   # 只做更少，不省安全检查

def temporal_evidence_gate(c, M, persona, D, ood_reg):
    if c.inf.cls == 'MISS' or c.age > ttl(c.region, c.type):
        return ('reject', 'stale_or_deadline_miss', c)     # 硬拒
    if fresh_geom_contradiction(M, c.region):
        return ('reject', 'geometric_veto', c)             # 硬拒
    if c.ev == 'EV-ray':
        return ('ok', c) if c.level == 'L1' and c.pred in GEOM_PREDICATES else \
               ('reject', 'ray_on_mechanical', c)
    return round57_gate(c, M, persona, ood_reg)            # 继承五类证据门

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DAI | O(q·d_φ)，q 由 D 决定；任意时间 | O(d_φ)+O(1) 证书 | 截止索引校准诚实、miss 即无证据（A41） |
| EVF | O(1)/证据 + O(N_ray) 见证 | O(\|V\|·\|type\|) | TTL/年龄可测、非删失才算新鲜（A42/A43） |
| LGE | O(N_ray·\|H\|) | O(N_ray) 扫描缓冲 | 删失语义、m-of-n 虚警界（A43） |
| TGR | O(N_ray+\|V\|)/区域 | O(\|V\|·d_geom) | 否决优先、n_eff 去相关（A45） |
| RTS | O(log n) 调度 | O(\|tasks\|) | 安全预留、时间压力单调（A44） |
| TEG | O(\|σ\|) | O(\|σ\|) | 无新鲜/无否决即拒 |

**正确性定理（Time-Geometric Calibrated Soundness, TGCS 概要）**：在 A33–A40 上加 **(A41)** 截止索引校准与任意时间单调：∀D，ECE_{k,D}≤ε_meta(k,D) 且声明诚实，P(τ_ret>D)≤δ_deadline；**(A42)** 时钟/时间戳完整性：age 可测、不可被处理时延或缓存重放「洗新」；**(A43)** 删失诚实：p(no_return|H) 按删失建模，射线可靠性有下界，m-of-n 虚警≤δ_ray；**(A44)** 调度时间压力单调且 hard 安全任务预留不被侵占；**(A45)** 漂移/欺骗分离：世界漂移在 λ_d 内可检，静止欺骗不产生机械参数新鲜证书。则：
(i) **时效承诺健全性**：P(fail) ≤ δ_f+ε_meta(k,D)+δ_probe+ε_h+δ_deadline+δ_censor+δ_ray+δ_drift；
(ii) **双向单调性**：实时、激光、对账、调度只能经「信念加宽/证据作废」或「动作更保守」影响系统；时间越少、删失越多、漂移越大，可行动作集单调收缩，不存在升险路径；
(iii) **截止终止性**：hard 安全任务在 D 内完成，否则安全停；PCE++ 在 k_probes+k_cons+k_scan 内终止于 {承诺,绕行,L2,安全停}；
(iv) **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f+ε_meta(k,D)+δ_probe+ε_h+δ_deadline+δ_censor+δ_ray+δ_drift)
             − P(时钟不同步未检出) − P(调度器静默吞 miss) − P(护盾回退失败)
```

关键：**实时给证据加保质期，激光给几何加证伪权**；二者只允许系统更快地变保守，不允许更快地变大胆；机械真值仍只能由探针/裕度提供，几何永远只是否决者与见证者。

def anytime_infer(o, z, D, budget, guard=DT_GUARD):
    t_e = capture_time(o)                     # 捕获时戳，不可被处理时延洗新
    t0 = monotonic()
    res = init_estimate(o, z)
    while monotonic() - t0 < D - guard and budget.left:
        res = refine(res, o, z)               # 任意时间：精度随算力单调
        budget.spend(refine_cost(res))
    if monotonic() - t0 > D:                  # 错过截止 = 无证据
        log_deadline_miss(D, monotonic() - t0)
        return Inf(cls='MISS', belt=conformal_belt(res.residuals),
                   age=now() - t_e, admissible=False)
    return Inf(cls='ID', post=res.post, cert=cal_cert(res, k=len(o), D=D),
               age=now() - t_e, admissible=True)

def cal_cert(res, k, D):
    # 只允许使用该截止下测得的校准曲线，禁止借用更长 D 的证书
    return {'ece': ece_table[k][D], 'delta_deadline': delta_deadline_table[D],
            'D': D, 'q': res.q, 'monotone_ok': check_anytime(res)}

### IP-140 EVF（证据时效与漂移检测）

def freshness(e, t):
    age = t - e.t_capture
    phi = 2.0 ** (-age / ttl(e.region, e.type))          # 半衰期衰减
    p_eff = phi * (e.p - 0.5) + 0.5                     # 向 ½ 收缩
    return age, phi, p_eff

def require_fresh(e, t, M):
    age, phi, p_eff = freshness(e, t)
    if age <= ttl(e.region, e.type):
        return True, p_eff
    # 过期且无法在本截止内重新见证 → 不进承诺
    return (revalidate_within(e, M, D=deadline_left()), p_eff)

def drift_test(scan, M, r):

### IP-141 LGE（删失激光几何证据）

def censored_update(H, ray, w, p_ret):
    if ray.z == 'hit':
        H = bayes_update(H, like_hit(ray.range, H), w=w * rho_hit(ray))
    elif ray.z == 'no_return':
        # 关键：no_return 是删失事件，不是“自由空间”
        H = bayes_update(H, {True: p_ret, False: 1.0 - p_ret}, w=w * rho_miss(ray))
    elif ray.z == 'ghost':
        H = bayes_update(H, ghost_mixture(ray, H), w=w * rho_ghost(ray))
    return H

def geometric_falsification(scan, H, m, n):
    stats = []
    for ray in scan.hits:
        r_hat = predict_range(ray, H)
        sigma2 = H.roughness ** 2 + sensor_noise(ray) ** 2
        stats.append(((ray.range - r_hat) ** 2) / sigma2)
    k = sum(s > theta_lambda for s in stats)
    return k >= m and len(stats) >= n            # m-of-n 稳健否决

def real_time_schedule(tasks, budget, deadline):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DAI | O(q·d_φ)，q=Q(D)；任意时间可截断 | O(d_φ)+O(1) | 截止索引校准、miss 不可承诺（A41） |
| EVF | O(1)/证据；漂移 O(N_ray) | O(\|V\|·\|type\|) | 年龄可测、非删失才新鲜（A42/A43） |
| LGE | O(N_ray·\|H\|) | O(N_ray) | 删失语义、m-of-n 虚警≤δ_ray（A43） |
| TGR | O(N_ray+\|V\|)/区域 | O(\|V\|·d_geom) | 否决优先、n_eff 去相关（A45） |
| RTS | O(log n) 调度 | O(\|tasks\|) | hard 预留、时间压力单调（A44） |
| TEG | O(\|σ\|) | O(\|σ\|) | 无新鲜/有否决即拒 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_s)·(C_VOI+d_φ+N_ray)) | O(\|V\|+\|σ\|+N_ray) | 三维预算终止、四态完备 |

**正确性定理（Time-Geometric Calibrated Soundness, TGCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 截止索引校准与任意时间单调：∀D，ECE_{k,D}≤ε_meta(k,D)，声明诚实，P(τ_ret>D)≤δ_deadline；**(A42)** 时钟与时间戳完整性：age 可测，缓存重放/处理时延不得把旧证据「洗新」；**(A43)** 删失诚实：p(no_return|H) 显式建模，射线可靠性有下界，m-of-n 虚警≤δ_ray；**(A44)** 调度时间压力单调：hard 安全任务预留不被侵占，降级只沿 g₀→g₄；**(A45)** 漂移/欺骗分离：世界漂移在 λ_d 内可检，静止欺骗不产生机械新鲜证书。则：

1. **时效承诺健全性**：P(fail) ≤ δ_f+ε_meta(k,D)+δ_probe+ε_h+δ_deadline+δ_censor+δ_ray+δ_drift；其中 EV-ray 仅在 L1 几何谓词上贡献 δ_ray，EV-fresh 本身不产生正证据。
2. **双向单调性与时间压力单调性**：实时、激光、时效、调度四机制只能经 (a) 证据加宽/作废或 (b) 动作更保守影响系统；预算 b₁≤b₂ ⇒ A(b₁)⊆A(b₂)，不存在「赶时间 ⇒ 更敢赌」的路径。
3. **截止终止性**：hard 安全任务在 D 内完成，否则安全停；PCE++ 在 k_probes+k_cons+k_scan 与墙钟硬截止内终止于 {承诺, 绕行, L2 协商, 安全停}。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k,D) + δ_probe + ε_h + δ_deadline
                  + δ_censor + δ_ray + δ_drift)
             − P(时钟不同步未检出) − P(调度器静默吞 miss)
             − P(护盾回退失败) − P(几何否决被降级为提示)
```

关键：**实时不等同新鲜、无回波不等同自由、一致不等同真实**；机械真值始终只能由 EV-probe*/EV-margin 提供，激光只拥有否决权与几何见证权；所有时间—几何机制只允许系统更快地变保守。

## 6. 本轮最大风险

**一句话**：本轮把安全的最后一道门押在「时间」与「几何」上，而这两者都极易被表面语义欺骗——若把「实时」误当「新鲜」、把「无回波」误当「无障碍」，系统就会以更高频率、更快速度，在过期或干脆缺失的几何证据上做出不可逆承诺；必须以单调时钟与捕获时戳、删失射线语义、几何否决优先、时间压力单调与截止 miss 强制升级五重护栏，宁可慢、宁可宽、宁可停，绝不让「快」与「没看见」冒充「新」与「安全」。
