# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环新周期第 1 轮；本轮灵感：「异常检测」×「文化适应性」×「目标检测」）

> R73 把 R72 的具身计量审计闭环重构为计量契约代数（MMS/DPEM/CCA/ΣREFLEX/CPB，后补 ECG 因果证据图 IP-302 与 MIC 形态无关契约），把「换模块=重审系统」升为「模块认证+组合校验」。但 R73 自认的最大风险暴露了体系的共同盲区：
> - **审计盲区问题**：全部组合定理（R73 定理 27/28/29）的证明重量落在「契约表达力」（A111–A113）上，但体系内**没有任何机制在运行时检验这个假设是否仍然成立**。组合代数只回答「契约内如何组合」，不回答「现实是否还在契约内」；PAR 的 conformal 一致性审计只在缩窄前做单点残差检验，对串联路径、慢漂移、以及「声明族过宽吸收违规」均无功效保证。**审计日志只能证明「每一步都合规」，不能证明「世界还在契约里」**。
> - **证据语义断层问题**：R73 的证据全部是连续几何/物理量（深度六分量、接触四分量、意图隐变量）。但机器人任务的最小语义单位是**物体**——类别、身份、持续性。检测证据是**离散错误过程**（类别混淆、漏检/重复、幻觉、开集新物体、跨模态关联错误），不是高斯噪声；把它压扁成标量 u 塞进 CCA，与 R72 批判的「把接触不确定度误读为位姿不确定度」同型。物体身份是下游安全动作（抓谁、不可碰谁）的最终依据，却没有任何否决语义。
> - **意图约定盲区问题（第三类先验）**：IRL 的似然 p(y_intent|z) 被当作普适物理，但意图解读依赖**约定**——个人空间半径、可触碰授权、手势/目光语义、称呼与节律。约定既非物理定律也非个体意图，是第三类先验来源；其跨人群变异与在线漂移和外参热漂移**同型**，却被当成常量。误读约定 = 系统性意图误识别 = 侵入/冒犯/拒绝配合，且**可被对抗利用**（社会工程：塑造交互历史把约定模型推向不安全授权区）。
>
> 本轮三个灵感正好补三块：
> - **异常检测** → **CAS（Contract-Anomaly Sentinel 契约异常哨兵）**：每个契约挂接一个 **anytime-valid e-process 赌局监控**——Ville 不等式保证预注册假阳率 α 在任意停止时刻成立；三态门控 GREEN/YELLOW/RED（YELLOW=证据降级：u 乘 SEAL 校准膨胀因子 γ、禁 PAR 缩窄；RED=非补偿自 stub）；恢复走重认证事件（滞回防抖）。**审计日志从『每步合规』升级为『对契约违规的赌局证书』**——R73 最大风险从「无解元问题」变为可证伪主张 C4。
> - **目标检测** → **OEM（Object Evidence Metrology 物体证据计量）**：检测证据五分量离散计量（u_cls 类别混淆 / u_det 漏检重复 / u_id 身份持续 / u_nov 开集新颖 / u_assoc 跨模态关联）+ 身份否决语义（单源不定案，双模态一致或接触确认才可定案）+ 视角反作用通道 χ_obj——「离散证据进契约代数」的第一个示范。
> - **文化适应性** → **NCM（Norm-Convention Metrology 约定计量与适应）**：意图似然条件化 p(y_intent|z,κ)，κ 为有界、版本化的约定画像；适应=**预算化计量过程**（KL 预算 β + 交互来源追溯 + 安全轴保守锚点：只放宽不缩窄，缩窄授权阈值必须人类再授权）+ **约定漂移哨兵**（意图残差 e-process 监控 κ 模型本身，漂移即冻结回滚）。文化适应性被表述为「带预算的校准漂移补偿」，与 u_calib 同型——不是自由漂移。
>
> 核心命题：**不再问「组合定理在契约表达力假设下成立吗」（不可检验），而问「系统能否用 anytime-valid 赌局哨兵，在现实越出契约可表达空间的时刻，以预注册假阳率与可界定检出延迟，自动降级到安全子图？」** 把 R73 的「自信地组合一个错误世界」改造为「诚实地发现并退出错误世界」。系统名 **SENTGAUGE-RAS**（SENTinel-audited evidence metrology with GAUGE audits for RAS）。

## 0. 直觉与动机

**灵感 1（异常检测 → 检验「世界还在契约里」，而不是检验「这个点是否离群」）**
直觉：经典异常检测回答「这个点怪不怪」，对 R73 无用——R73 需要的是**分布级、可组合、可审计**的假设检验：H0 =「现实分布 = 契约声明的似然族（含声明的依赖结构）」。工具选择：**anytime-valid e-process（测试即赌局）**。每帧把声明族白化后的残差 r_t 拿来下注：E_t = Π_{s≤t}(1+λ_s r_s)，λ_s 可预测且在 H0 下期望增益为零 ⇒ E_t 非负上鞅；Ville 不等式给出 P(∃t: E_t ≥ 1/α) ≤ α——**假阳率不依赖停止时刻与样本量**，这正是「无限时程运行时审计 + 预注册 α」需要的语义（SPRT/CUSUM 的 ARL 渐近界做不到）。三个衍生收益：(i) **可组合**——把 MReg 全部模块的残差流按时间合并成一条赌局流，联合 e-process 检验**联合契约**；依赖结构声明错误本身在检验功效内（R73 风险#5 的隐共享物理耦合从「无法审计」变为「以 KL 为速率可检出」）；(ii) **可证伪**——检出延迟 ≈ log(1/α)/δ（δ=声明族与真实分布的 KL 间隙），δ 可注入测量，MB4 上点验；(iii) **可审计**——e-process 日志可复算：审计员能重放「赌局何时以何速率增长」，误杀与漏检都有账。与 R73 conformal 单点审计的关系：conformal 是「横截面」检验（残差是否在校准集内），e-process 是「时间维度」检验（残差流的累积证据），正交互补：前者保覆盖，后者保契约。

**灵感 2（目标检测 → 离散证据也有计量结构，且身份需要否决语义）**
直觉：R73 证明了连续证据（接触四分量、深度六分量）可以计量化，但物体检测的证据结构是**离散错误过程**：类别混淆来自校准（温度校准 + 混淆矩阵后验）；漏检来自剂量-视角关系（远/小/遮挡时检出概率下降——与深度 σ∝d²/B 同型的「动作条件化证据质量」）；身份断裂来自遮挡与重关联（Markov 转移不确定度）；新颖物体来自长尾（开集 p 值，极值理论校准）；关联错误来自跨模态匹配的多假设性（关联假设集的熵——最易被忽略，却直接决定「深度 blob ↔ 检测框 ↔ 接触斑」身份一致性审计是否可信）。**身份是安全动作的最终依据**：抓错物体 = 安全事件。因此身份命题必须有否决语义：单模态不定案（继承 E356/E357「单源不定案」原则），需双模态一致（PAR on identity，含 u_assoc 折算）或接触确认。检测质量对动作的依赖（走近/换角度/等遮挡移开）给出 χ_obj 反作用通道——OEM 是 DPEM 的离散镜像，证明契约代数对离散证据同样成立。

**灵感 3（文化适应性 → 约定是第三类先验，适应必须计量化）**
直觉：体系里有两类先验：物理定律（不适应，只计量其观测噪声——u_calib）与个体意图（IRL 在线推断 z）。约定横跨两者：**因人群而异、随时间漂移、被个体内化**。机器人若用普适意图先验，跨文化场景会系统性误读：个人空间过近=侵入；把「客气的拒绝」读成「同意」=安全/伦理双重错误。但「让机器人自由适应文化」更危险：适应通道就是**攻击面**——对抗者可通过塑造交互历史（一批「热情好客」的共谋者）把 κ 推向不安全授权区（社会工程）。解法不是禁止适应，而是给适应上**计量纪律**（与 R71 对 z 的 KL 预算、R73 对契约的版本化同构）：KL 预算 β（适应速率有界）、交互来源全程追溯（每次 κ 更新可回放到具体交互集合）、**安全轴保守锚点**（个人空间/可触碰授权：适应只能放大不确定度或保持安全裕量，任何缩窄授权阈值的更新必须挂显式人类再授权 token，否则非补偿拒绝）、**约定漂移哨兵**（意图残差 e-process 监控 p_I(·|κ̂) 是否仍是真分布——κ 模型错误也是「契约违规」，YELLOW 意图证据 + 冻结适应 + 回滚版本）。系：**文化适应性从「社会科学愿景」变为「带预算的校准漂移补偿」——与深度外参热漂移完全同型，复用全部既有机制。**

**灵感 4（e-process 的可组合性 → 审计证据的组合代数）**
直觉：R73 的 CCA 组合的是**不确定度数值**（u 单调、域收缩、否决并集）；本轮新增的组合对象是**审计证据**：联合赌局流。关键观察：只要每个下注在联合域上可预测，合并流的 e-process 对联合零假设有效——**不需要模块独立假设**（比 R73 PAR 缩窄要求的 ρ 审计更弱的前提）。这给出「审计的组合代数」：模块图上的联合 e-process 是一个可复算、可截断（log 域维护）、可写进证书的量。J_SENT = J_MOD ⊗ 赌局日志：证书不再只说「结构合规」，还说「运行时未积累出对抗契约的赌注」。

**灵感 5（哨兵的元回归 → 第 0 层物理包络兜底）**
直觉：哨兵也是模块、也有契约、也会失效——无穷回归。截断方式：**第 0 层哨兵 = 物理包络监控**（力/力矩/温升/时序违例/断链），不依赖学习模型、不可 stub（硬件熔断级）；学习型哨兵全部在第 ≥1 层，其失效由第 0 层兜底；第 0 层失效 = 系统停机（唯一不可降级的终点）。这与 R72 的 RTM/R68 退化链衔接：哨兵层级是退化链向「审计自身」的延伸。

**灵感 6（ECG† 与 GATE-CCA† 的衔接：因果链也挂哨兵）**
直觉：R73 IP-302 的证据因果图要求「因果链断裂可追踪」；本轮把它哨兵化：每条因果边挂边级 e-process（下游对上游的条件残差），边越界 ⇒ 链上全部下游证据 YELLOW（比模块级更细的失效传播）、反事实重排在断裂链上禁用。同时 GATE-CCA 把哨兵状态纳入组合语义：SER 路径 γ 乘积化、PAR 缩窄要求全 GREEN + u_assoc 达标、RED 即 stub。**门控只做单调变换（u 不减、D 不增、I⊥ 不减），是 CCA 的保守扩张**——引理 34 与定理 29 无需重证。

## 1. 形式化定义（增量：定义 383–397）

**定义 383（SENTGAUGE-RAS 总览）** SENTGAUGE-RAS = (CAS, OEM, NCM, GATE-CCA†, SENT-REFLEX†, MODGAUGE†)。六不变式 = R73 五不变式 + **哨兵完备性**：每个参与组合的证据流必须挂接哨兵（哨兵可为「平凡哨兵」= 第 0 层物理包络，不依赖学习模型——元回归的基例），哨兵状态与证据可用性绑定，不可旁路。

**定义 384（残差流与赌局哨兵）** 模块 i 契约声明似然 p_θ_i(y|·)。定义标准化残差 r_t^i = φ_θ(Y_t^i)（白化映射到声明族的标准空间，如高斯族的 (y−μ)/σ 与二次型分量）。哨兵持有 e-process：
E_t^i = Π_{s≤t} (1 + λ_s^i r_s^i)，λ_s^i 可预测（仅依赖 F_{s-1}），取自有限混合网格 Λ（每档 λ 在 H0 下满足 E[1+λ r]=1；网格权重在线更新 ⇒ 混合 e-process）。log 域维护，log E_t 下界截断（防数值下溢）。**Ville：P_H0(sup_t E_t ≥ 1/α) ≤ α。**

**定义 385（三态门控与滞回）** state_i ∈ {GREEN, YELLOW, RED}：
- GREEN→YELLOW：log E_t^i ≥ log(1/α_y)。YELLOW 语义：u_eff = γ·u_decl（γ 在 SEAL 上校准使覆盖 ≥ 1−α′，γ ≥ 1）、该模块参与的一切 PAR 边禁缩窄、χ_R 输出加保守包络；
- YELLOW→RED：log E_t^i ≥ log(1/α_r)（α_r ≪ α_y，预注册如 α_y=10⁻², α_r=10⁻⁴）。RED 语义 = stub（定义 381），非补偿；
- 恢复：RED→YELLOW 仅在重认证事件 RC_i（新鲜窗口 conformal 重校准 + cert 刷新）后；YELLOW→GREEN 需 log E_t < log(1/α_y) 且稳定窗 W_stab 内无新增越界（滞回防抖）。α_y/α_r/γ/W_stab 全部预注册并写入契约 seal_ref。

**定义 386（联合哨兵与合取审计）** 把 MReg 全部模块的残差流按时间合并为单一赌局流（每个下注 λ_s^i 在联合域 F_{s-1} 上可预测），E_t^joint = Π_i Π_s (1+λ_s^i r_s^i) 是联合域上的 e-process——**联合契约零假设**（含声明的依赖结构）下 Ville 成立；依赖结构声明错误本身在检验功效内（任何偏离声明联合分布的偏离以 KL 为速率被检出）。E_t^joint 截面写入证书：**J_SENT = J_MOD ⊗ 赌局日志**（定义 396）。

**定义 387（OEM 物体证据计量）** 观测 y_obj =（检测集合 {(类, 框, 置信)}, 轨迹关联, RGB-D 帧）。五分量：
- u_cls：类别混淆（温度校准混淆矩阵的后验方差）；
- u_det：漏检/重复（剂量-视角检出模型 q(d, θ, occ) 的偏差项）；
- u_id：身份持续性（轨迹断裂/重关联错误的 Markov 转移不确定度）；
- u_nov：开集新颖度（EVT 校准的 novel p 值）；
- u_assoc：跨模态关联不确定度（深度 blob ↔ 检测框 ↔ 接触斑关联假设集上的熵）。
似然 p_obj(y_obj | O, κ_place) 为**离散似然**（检测集合上的多伯努利/点过程），以独立证据类型进 BSE†（T_out 类型系统强制，不与连续证据共用组合子）。**身份否决语义**：对命题「物体 o 具有身份 id」，单模态不定案——需 (a) 双独立模态身份一致（PAR on identity 审计通过，含 u_assoc 折算）或 (b) 接触确认；否则 I⊥ 投否决票。χ_obj：动作 g → (d, θ, occ, 曝光) 调制 (q, u_cls, u_nov)。有效域 D_obj = {d∈[d_min,d_max]} ∧ {遮挡率 < τ_occ} ∧ {u_nov < τ_nov 或已入保守处置}。

**定义 388（NCM 约定计量与适应）** 意图似然 p_I(y_intent | z, κ)，κ = (κ_space 个人空间, κ_touch 可触碰授权, κ_gest 手势语义, κ_addr 称呼/节律, …)，|κ 轴| ≤ 8，κ ∈ K 紧集、版本化。κ 估计是**计量过程**而非无监督漂移：
- 预算：KL(κ_{t+1} ‖ κ_t) ≤ β（每窗口适应预算）；
- 追溯：每次更新记录来源交互集合 S_t（可回放审计）；
- 锚点：安全轴（κ_space, κ_touch）**单调约束**——适应只能放大 b(κ) 不确定度或保持安全裕量下界 a_min；任何缩窄授权阈值的更新必须挂人类再授权 token，否则非补偿拒绝；
- 漂移哨兵：意图残差 e-process E_t^norm 监控「p_I(·|κ̂) 是否仍是真分布」——越界 ⇒ 意图证据 YELLOW + κ 适应冻结并回滚到最近锚点版本；
- 文化差异的可证伪形式：跨人群（≥3 标注画像）意图识别 ECE 与误触率，κ 条件化 vs 普适先验（MB4/E402）。

**定义 389（GATE-CCA†）** CCA 三算子在哨兵状态下的语义：
- SER：u_out ≥ (Π 路径 γ) · (u_A + L_B·u_A)；路径上任一 RED ⇒ 输出 stub；
- PAR：任一参与方非 GREEN ⇒ 禁缩窄（保守 max），分歧审计阈值收紧至 α′/2；身份级 PAR 额外要求 u_assoc < τ_assoc；
- VETO：不变（非补偿），但哨兵 RED 的 I⊥（本模态全集）并入否决集。
引理 34 在门控下保持：门控只做 (u, D, I⊥) 单调变换，无新路径使 u 变小。

**定义 390（SENT-REFLEX†）** ΣREFLEX 预算扩展两通道：
- **ν 通道（新颖处置）**：对 u_nov 高的物体，重观察/绕行动作的收益 E[Δu_nov | a] 计入预算；
- **ρ 通道（约定澄清）**：澄清动作（提问/示慢/退让）的收益 E[ΔH(b(κ)) | a] 计入预算（与 z 通道同型）；
- 稳态集扩展：N_safe = {E[u_nov^next] ≤ τ_nov}、K_safe = {H(b(κ)) ≤ τ_κ}——约定歧义过高 ⇒ 禁止授权级动作，只许澄清级动作。

**定义 391（哨兵元回归的基例与截断）** 哨兵本身是模块，其契约 =（残差类型, 检出延迟界, 假阳率 α, 恢复协议, WCET）。防无穷回归：**第 0 层哨兵 = 物理包络监控**（力/力矩/温升/时序违例/断链），不依赖学习模型、不可 stub（硬件熔断）；学习型哨兵位于第 ≥1 层，失效由第 0 层兜底；第 0 层失效 = 停机（唯一不可降级终点，衔接 R68/RTM）。**形式化**：哨兵层级的失效语义 = 逐层降级到更保守层，第 0 层是单调收敛的底。

**定义 392（ECG† 因果哨兵）** R73 IP-302 的每条因果边挂接边级 e-process（下游证据对上游证据的条件残差）；边越界 ⇒ 该链上全部下游证据 YELLOW（比模块级更细的失效传播）、该链上反事实重排禁用、回退保守路径。

**定义 393（假设 A114–A116）** A114（声明族非平凡）：契约声明似然族对真实分布在 SEAL 校准集上具有 ≥ δ_min 的功效间隙（存在可赌的偏差方向）；A115（赌局可预测性）：λ_s 仅依赖 F_{s-1}，白化 φ_θ 在有效域内 Lipschitz；A116（适应可观测性）：约定适应的输入交互流经 AIC-SOCIAL 威胁面防护（定义 395），无未检出注入。

**定义 394（MB4 最小基准）** MB4（哨兵审计）：契约违规注入矩阵（重尾/慢漂移/依赖结构错误 × 三强度）+ 长时程假阳运行；≤3h 单卡；预注册：α_y 下实测假阳率 ∈ [α_y/3, 3α_y]，检出延迟 ≤ log(1/α_r)/δ̂ + c。

**定义 395（AIC-SOCIAL 威胁面）** 社会威胁面 = {社会工程（塑造 κ 驻留不安全区）、身份欺骗（外观/纹理诱导类别幻觉）、关联投毒（伪造跨模态一致假身份）、哨兵致盲（带宽内噪声垫高声明 σ 使赌局无力）、规范迁移伪装（把个体偏好伪装成群体约定）}。防线：锚点 + 再授权 + 身份双源 + **σ 地板**（u_decl 下界 λ_floor，防「越声明越宽」的致盲）+ κ 版本可回滚。

**定义 396（J_SENT 证书）** J_SENT = J_MOD ⊗ Π_i sentinel-log_i ⊗ E_t^joint 截面。Valid(J_SENT) ⇔ Valid(J_MOD) ∧ 全部哨兵状态 ∈ {GREEN, YELLOW(已降级)} ∧ 联合 e-process 上界可由日志复算 ∧ 恢复事件链完整。**审计语义升级：审计员不仅重放「每步合规」，还能重放「赌局曾在何时以何速率增长」——检出与误杀都有账。**

**定义 397（CPB 扩展：C4）** C4（anytime-valid 哨兵审计）← (CAS, OEM 哨兵, NCM 漂移哨兵) ← MB4 ← AB4（有/无哨兵 × 宽/窄声明族）← (假阳率, 检出延迟, YELLOW 期覆盖率, 误杀率/可用性)。C1–C3 不变；新组件先填 C4 绑定才能入 MReg。

# IP-303 CAS：anytime-valid 赌局哨兵（每模块挂接，log 域维护）
class ContractAnomalySentinel:
    def __init__(self, ec, alpha_y=1e-2, alpha_r=1e-4):
        self.logE = 0.0; self.state = 'GREEN'
        self.bets = MixtureBets(ec.u_fields)               # 有限混合网格 Λ
    def step(self, resid, hist):
        lam = self.bets.predictable_bet(hist)              # λ_s 仅依赖 F_{s-1}（A115）
        self.logE += math.log(max(1.0 + lam*resid, 1e-12)) # log 域，防下溢
        if self.state == 'GREEN' and self.logE >= -math.log(self.alpha_y):
            self.state = 'YELLOW'                          # 降级：γ 膨胀、禁 PAR 缩窄
        elif self.state == 'YELLOW' and self.logE >= -math.log(self.alpha_r):
            self.state = 'RED'                             # stub（定义 381），非补偿
        return self.state, math.exp(self.logE)
    def request_recover(self, recert):                     # 滞回恢复（定义 385）
        if recert.valid and self.logE < -math.log(self.alpha_y):
            self.state = 'GREEN' if self.stable_window_ok() else 'YELLOW'

                else VETO_SINGLE_SOURCE                    # 身份否决语义

# IP-306 GATE-CCA†：哨兵门控组合（升级 IP-297 compose；单调变换）
def gated_compose(a, b, op, audit):
    if 'RED' in (a.sent_state, b.sent_state): return stub_of(a, b)  # 非补偿
    if op == 'SER':
        g = gamma_prod(a, b)                               # 路径 γ 乘积化
        return Ev(u=g*(a.u + lipschitz(b, a.u)), D=a.D & b.D,
                  tau=a.tau.merge(b.tau), veto=a.veto | b.veto)
    if op == 'PAR':
        narrowing = (audit.conformal_covers(resid(a, b))
                     and gamma_prod(a, b) == 1.0           # 有 YELLOW 即禁缩窄
                     and (a.kind != 'identity' or a.u_assoc < TAU_ASSOC))
        if narrowing and abs(audit.rho) < RHO_MAX: return fuse(a, b, audit.rho)
        return Ev(u=max(a.u, b.u), D=a.D & b.D, tau=a.tau.merge(b.tau),
                  veto=a.veto | b.veto | {'GATE_AUDIT_FAIL'})

# IP-307 SENT-REFLEX†：ν 通道 + ρ 通道并入 ΣREFLEX（层数仍由模块声明）
def sent_reflex_step(mods, g, state, budget):
    s2, cost = {}, 0.0
    for i, m in mods.items():
        chi = m.ec.chi_R(g); c_i, s_i = m.reflex_cost(state[i], chi)
        if i == 'OEM': c_i += E_delta_u_nov(g);      s_i &= N_safe
        if i == 'NCM': c_i += E_delta_H_kappa(g);    s_i &= K_safe  # 歧义高⇒仅澄清级
        if not s_i: return None, cost                     # 非补偿
        s2[i], cost = s_i, cost + c_i
    return (s2, cost) if budget.spent + cost <= budget.B else (None, cost)

## 3. 推导

**引理 38（赌局哨兵的 anytime-valid 性）** 若 λ_s 可预测且 E_{p_θ}[1+λ_s r_s | F_{s-1}] = 1（A115），则 E_t = Π(1+λ_s r_s) 是非负上鞅、E[E_t]=1；Ville ⇒ P_θ(∃t: E_t ≥ 1/α) ≤ α。**假阳率不依赖停止时刻与样本量**——与 SPRT/CUSUM（ARL 渐近界）的本质差异，使「预注册 α + 无限时程运行时审计」在语义上成立。

**引理 39（检出延迟界）** 若真实分布 q 与声明族最近点 p̂ 的逐步 KL ≥ δ > 0，则最优可预测赌局使 E[log E_t] ≥ δt − O(C_Λ)（C_Λ 为混合网格复杂度），检出延迟（log E_t 达 log(1/α_r) 的期望时刻）≤ (log(1/α_r) + C)/δ。系：**C4 的可证伪形式**——违规强度 δ̂ 可注入测量，延迟预测在 MB4 上点验（E397）。

**引理 40（门控单调性：门控不产生免费午餐）** GATE-CCA 的每个变换（γ ≥ 1 膨胀、PAR 禁缩窄、RED→stub、I⊥ 并入）在 (u, D, I⊥) 偏序上单调：u 不减、D 不增、I⊥ 不减。故引理 34 的组合下界在门控图上保持；YELLOW 期覆盖率由 γ 的 SEAL 校准给出（≥ 1−α′）。系：**哨兵层是 CCA 的保守扩张，不是新的信任来源。**

**引理 41（约定适应的安全性）** 若适应预算 KL ≤ β、安全轴单调（只放宽不缩窄）且再授权锚点生效，则任意适应序列下 P(授权错误 | 真约定) ≤ 初始保守界 + β·T·|κ 轴|/n_交互 的可审计上界；意图残差哨兵 E^norm 在 κ 模型偏离时以引理 39 速率检出并冻结回滚。系：**文化适应性是带预算的校准漂移补偿，与 u_calib 同型——不是自由漂移。**

**定理 30（SENTGAUGE 严格包含）** 在 A111–A116 下：MODGAUGE（R73）是 SENTGAUGE 的「全 GREEN 哨兵 + OEM stub + κ 冻结先验」实例化；由定义 383 与引理 40，退化条件下逐指令等于 R73，再退化等于 R72/R71/R68。**安全单调不减：哨兵层只在 (u, D, I⊥) 单调方向上作用。**

**定理 31（联合哨兵审计的完备性——对 R73 最大风险的正面回答）** 设联合契约零假设 H0_joint（全部模块的声明联合分布，含声明的依赖结构）。Valid(J_SENT) ⇒ (i) R73 定理 28 全部结论（契约内安全界）；(ii) 若现实偏离 H0_joint 且逐步 KL ≥ δ > 0，联合 e-process 以引理 39 速率增长，系统在期望延迟 (log(1/α_r)+C)/δ 内进入 YELLOW/RED 并降级到保守子图；(iii) 降级后性质由 stub/γ 语义保持（R73 定理 29 + 引理 40）。**证明重量从「契约表达力在分布外成立」（不可检验）转移到「声明族与真实分布间存在 ≥ δ 功效间隙且哨兵被正确校准」（可注入检验）**——不可检验假设被替换为可证伪主张 C4。

## 6. 本轮最大风险

**一句话**：哨兵把「自信地组合一个错误世界」改造为「诚实地发现并退出错误世界」，但这个转换的全部重量落在**声明族的先验选择**上——e-process 只能检验「现实偏离声明族」，若声明族选得过宽（大 σ、重尾兜底、宽依赖界），真实违规会被声明族「吸收」而赌局无力，检出延迟趋于无穷、哨兵沦为装饰，而系统对此**没有内省手段**（检不出「检不出」）；若声明族过窄则在有效域边缘频繁误杀，可用性-安全性权衡点没有任何内部基准可证明其正确——C4 把 R73 的不可检验假设替换成了一个可检验但**以校准集代表性为前提**的主张，而 SEAL 是否覆盖真实部署分布，重新成为整个体系的隐式地基。

次级风险与缓解：
1. **哨兵元回归** → 第 0 层物理包络（定义 391，不可 stub，硬件熔断）+ 学习型哨兵只在其上；E409/E401 验证层间降级。

## 2. 形式化定义（要点版）

**定义 383（总览与七不变式）** 继承 R73 五不变式；新增 (vi) 闭环可行：活跃 MEC 在声明延迟/驻留下满足 CCT 且 𝒯_ε ⊆ S_safe；(vii) 服务诚实：前台行为由后台证据支撑，恢复非补偿且可读。(iv) 升级为利益相关者索引，(v) 升级为服务恢复链。

**定义 384（MEC）** EC ⊕ (V, α, τ_d, T_dwell, A, R_rec, κ)；纯计量模块取 V=0、κ=0、A=∅、R_rec=0 退化为 EC。

**定义 385（CCT）** 由 ISS 不等式得前向不变管 𝒯_ε；「闭环认证」⇔ 服务时域内 𝒯_ε ⊆ S_safe 且饱和/接触切换不破不等式。**证据再准，超过 τ_d 也不算数。**

**定义 386（可容许热替换）** 驻留 ∧ 无扰 ∧ 公共度量 ∧ 证据连续；违例 ⇒ 证书**挂起**、进 hold/recover。**修正 R73 引理 35：逐指令等价 ⇏ 闭环切换安全。**

**定义 387（SBC）** journey DAG、关键时刻 MT、失败点 Fail、恢复脚本 Rec、前台 Front、SLO=(p,T,Q)、Legible 规则（不得把 DEGRADED 说成 NOMINAL）。

**定义 388（SBG / SLO 组合）** 串联 union bound；并联仅在独立故障审计通过时用乘积；Q_J 取关键时刻最小值；认证 SLO ⇔ (p_J≥p*)∧(T_J≤T*)∧(Q_J≥Q*)。

**定义 389（HEP）** 单源人证与所有独立机器模态冲突 ⇒ 只签服务置信；提升安全证书需 SEAL-H oracle ∧ 独立模态一致 ∧ 无近期自相矛盾；L_h 进 τ_d。

**定义 390（COMP-REC）** `valid = valid(A) ∨ recover(B, post(A))`；恢复期间 u 不变好；T_rec 有上界；复发超界升级为新名义模式；扣 D_svc/R_rec。

**定义 391（SDB）** D_svc ≤ D_max ∧ R_rec ≥ R_min；超限 ⇒ 前台明示能力边界/请求接管/停止，禁止静默继续。

**定义 392（AEB）** 三预算守恒；`a_recovery ≥ R_min` 锁定；固定预算下三项不可能同时无约束最优（保守性引理）；Δu/a_evidence 是主动感知的「汇率」。

**定义 393（J_SVC）** 模块 cert ∧ MReg ∧ CCT ∧ SBG ∧ REC ∧ front/back 一致 ∧ HEP 单源检查；按 k∈K 分别有效。

**定义 394（CPB†）** 绑定 (组件, 主张, 利益相关者, 关键时刻, 指标)；不在任何 (k,MT) 服务主张的组件 = 工程附件。

**定义 395（ℰ_ms）** 五类威胁与五道防线（驻留审计/复发检测/独立模态/储备锁/前后台一致性）。

**定义 396（STL）** 安全 ∧ 完成 ∧ 有界恢复 ∧ 诚实降级四合取项；CCT 管第一项，SBC 后三项。

**定义 397（复杂度扩展上限）** |V_M|≤24、深度≤4、|MT|≤12、|Rec|≤3/失败点、CCT 维数≤8、D_svc 窗口≤1 journey，均为可审计图性质。

**定义 398（严格退化）** (τ_d→∞, T_dwell→0, V≡0, K={robot}, |MT|=1, Rec=∅, L_h=∞) ⇒ 逐指令退化为 R73，再退化 R72/R71/R68；必须显式记录退化坐标。

# IP-303 MEC / CCT
@dataclass(frozen=True)
class MotionContract:
    ec: EvidenceContract
    V: Callable[[State, EvidenceError], float]
    alpha: float; kappa: float; delta: float
    tau_d: float; T_dwell: float
    authority: AuthorityEnvelope
    R_rec: float
    safe_set: Predicate

def cct_check(mc, x0, e_bound, H):
    eps = lambda t: exp(-mc.alpha*t)*mc.V(x0,0) + (mc.kappa/mc.alpha)*e_bound + mc.delta/mc.alpha
    return all(mc.safe_set(x) for t in grid(H) for x in tube(mc.V, eps(t)))

# IP-304 可容许切换
class SwitchManager:
    def request(self, old, new, t):
        if t - self.last_switch < old.T_dwell: return Hold('DWELL')
        if not self.bumpless(old, new):        return Hold('BUMPLESS')
        if not self.common_metric(old, new):   return Hold('NO_COMMON_V')
        if not self.evidence_chain_ok(old, new): return Hold('STALE_EVIDENCE')
        return Switch(new, suspend_certificate_until=self.settle_time(new))

# IP-305 服务蓝图编译
def compile_blueprint(mreg, journey):
    sbg = SBG(journey)
    for step in journey.steps:
        mods = mreg.modules_for(step)
        sbg.fail[step] = [f for m in mods for f in m.ec.fail_modes]
        sbg.rec[step]  = attach_recovery(step, sbg.fail[step])
    return sbg.verify_slo()          # union bound + 关键时刻木桶

# IP-306 恢复代数（非补偿 + 反洗白）
def compose_rec(a, b, ctx):
    v = a.valid or recovery_reaches(b, post(a), ctx)
    u = max(a.u, b.u)
    t_rec = detect(a) + switch(b) + restore(b)
    if ctx.recurrence(a.fail_id) >= ctx.n_recur:
        return Escalate(a.fail_id)
    return Ev(valid=v, u=u, t_rec=t_rec, slo=min(a.slo, b.slo))

# IP-307 人类证据
def human_evidence(h, machines):
    if calibrated_oracle(h, 'SEAL-H') and agrees_with_independent(h, machines):
        return Evidence(u=h.u, veto=set(), level='SAFETY')
    return Evidence(u=h.u, advisory=True, level='SERVICE')

# IP-308 SERVO 主闭环
def SERVO_round(M, journey, obs, audio, tac_frame, depth_img):
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    b_t  = M.bse.step_full(..., d_ev=stub_if_bad(d_ev), t_ev=t_ev)
    if not cct_check(M.mec(M.dpe), M.x, d_ev.u, H_svc):
        M.switch.hold(); M.cert.suspend('CCT')
    g = aeb_plan(b_t, M.mods, M.risk_params)              # 三预算
    if g:
        s2, _ = sigmareflex_step(M.mods, g, M.state, M.budget)
        if s2 is not None: M.last_g, M.state = g, s2
    svc = M.sbg.step(journey.current, b_t, d_ev, t_ev)
    if svc.failed: svc = compose_rec(svc, M.rec[svc.fail_id], M.ctx)
    front = M.front.explain(svc)
    assert M.front.back_consistent(front, svc)            # 服务诚实
    return M.ctrl_out.publish(...), J_SVC(M)

## 4. 推导（要点）

**引理 38（组合 ISS 管）** 各 MEC 的 ISS 不等式在 SER/PAR/VETO/REC 下组合增益有界（PAR 仅在一致性审计通过时缩窄，不放大 κ；VETO/REC 只取保守上界）⇒ `V̇ ≤ −α_min V + Σw_iκ_iē_i + δ`，𝒯_ε 前向不变。**CCT 对 R73 组合算子封闭。**

**引理 39（修正 R73 引理 35）** 存在两个各自 Hurwitz 的向量场，其切换系统不稳定（无公共二次 Lyapunov）。R73 契约只约束逐指令性质，不约束切换律 ⇒ 「同 EC 热替换 ⇒ 系统级性质保持」在闭环意义下为假。可容许切换（定义 386）下由多 Lyapunov 定理恢复稳定。**C3 改写为「可容许切换保持」。**

**引理 40（恢复可行/复发界）** `T_rec ≤ T_rec*` 且预算闭合 ⇒ T_rec 内回到认证 SLO'≤SLO；同 fail_id 在 T_recur 内复发 ≥ n_recur ⇒ 恢复证书失效，升级为新名义模式。**恢复不能无限续命。**

**引理 41（SLO 组合/关键时刻木桶）** 串联 p_J 用 union bound；Q_J ≤ min_MT Q_MT；恢复只能回到 `p_pre − Δ_recovery`。**最差关键时刻决定服务上限。**

**引理 42（HEP 非补偿）** 单源人证不能把安全证书抬到独立模态支持水平之上；仅 SEAL-H oracle ∧ 独立一致才可并入。**单源不定案扩展到人类。**

**定理 30（SERVO 严格包含 MODGAUGE）** 退化坐标下逐指令等于 R73，再等于 R72/R71/R68。**安全只增不减。**

**定理 31（J_SVC 有效 ⇒ 四合一）** 在 A114–A117 下：Valid(J_SVC) ⇒ 定义 396 的 STL 四合取项以概率 ≥1−α 成立。证明重量在 CCT 组合常数、SBG 独立故障审计、REC 非补偿与反洗白。

**定理 32（服务恢复零级联）** 模块失效 + 可容许恢复 ⇒ T_rec 内继续于已认证较低 SLO，无安全违例；解释与后台一致；复发超界 ⇒ 升级重认证。**零级联从安全扩展到服务。**
