# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「同步定位与建图」×「四足机器人」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**地图版本化 + 全身证书 + 步态相位治理**。两个灵感分别治理 v9 的两个隐含债：**地图债**（证书默认地图静止可信，risk_SLAM 只是一个进入门槛的标量，回环重写与漂移从未进入证书预算）与**身体债**（证书默认基座准静态，末端证书与平衡、接触、打滑解耦）。必须保证：地图修订、基座扰动、步态相位只能以「证书来源版本」和「保守界」的形式进入安全论证；任一模块失效可经中立元严格回退 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（SLAM → 地图不是背景，而是带版本、会跳变的信念）**
直觉：v9 的 SpatialCert 把地图当成一张固定的欧氏背景，risk_SLAM 只是一个进入 δ_trigger 的标量。但 SLAM 的真实输出是「带边缘协方差的因子图 + 若干数据关联假设 + 会被回环改写的拓扑」，它的坐标系本身会跳变。一个在旧地图上算出、当时完全正确的间隙证书，会在一次回环后变成「自信的错误」；而按全局绝对协方差保守膨胀，又会让正常局部操作因长路径漂移而寸步难行。核心创新：**地图版本证书（MapEpochCertifier, MEC）**——证书携带来源 π=(epoch, anchor, calib, gait)，用机器人—障碍的**相对协方差**（而非全局绝对协方差）算间隙下界，并在 epoch 变更时强制失效；数据关联歧义用**假设包络**取最坏自洽界。地图从「可信背景」降格为「有版本、有漂移、有歧义的可证来源」。

**灵感 2（四足机器人 → 证书必须长在一具会摔的身体上）**
直觉：v9 的证书默认基座准静态，机械臂证书只关心末端。四足把基座变成最大的不确定性源：腿式里程计在碎石/冰面上打滑且**滑移方向不可辨识**；机身俯仰/高度随步态起伏；支撑多边形在单支撑期收缩、在腾空期消失；「停下」本身可能不安全。核心创新：**全身证书（WholeBodyCertifier, WBC）**——把基座位姿信念经运动学雅可比传播到末端，得到 `g_ee = dist − κσ_ee − β_kin`；证书同时要求动态稳定裕度 m_stab ≥ m_min。即「够得到」与「站得稳」必须同时成立，证书从末端的几何谓词升级为身体—环境联合谓词。

**灵感 3（两者的耦合 → 步态相位是天然的调度器与失效边界）**
直觉：地图修订与步态切换都是**突发的、与证书生成不同步的**事件。v9 的 5Hz 重块可能恰好在腾空期生成，既烧算力又可能把身体推离平衡。四足给出的物理节拍可以把「何时重算、块能多长、何时必须中止」统一到步态相位上；SLAM 给出的地图版本则决定「旧块是否还算数」。核心创新：**步态相位治理器（GaitPhaseGovernor, GPG）**与**认证恢复规划器（CertifiedRecoveryPlanner, CRP）**：重生成只在双支撑/稳定单支撑窗口；K_eff 同时受 Δ_dom、地图漂移、稳定裕度门控；中止点从「减速停车」升级为「认证恢复步/坐/降重心」。

## 1. 研究问题（轮次升级版）

- **Q1（地图版本与相对证书）**：如何用相对协方差与来源版本，使证书在漂移下仍保守、在回环后立即失效？数据关联的离散歧义如何被定价，而不至于把整张地图判为不可用？
- **Q2（全身证书）**：基座信念经运动学传播后，在什么信任域/线性化残差界下是保守的？平衡裕度与末端证书如何合成，才能避免一个裕度「抵消」另一个的违反？
- **Q3（相位治理与双突发）**：步态相位门控能否在不牺牲 50Hz 实时性的前提下，保证任何中止点都存在可执行的认证恢复？地图 epoch 与步态切换的双突发如何消除「证书空窗」？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 地图版本律（Map-Epoch Certificate, MEC）**
地图元素携带 (μ_o, Σ_o, e_o, p_exist)；证书携带来源 π(C)。同一 epoch 内用相对协方差 `Σ_rel = Σ_x + Σ_o − Σ_xo − Σ_ox` 计算间隙下界并加分辨率/漂移/关联膨胀；跨 epoch 一律不复用，必须重算。关联歧义取满足最小置信的假设包络的最坏自洽界；包络不可信时 MEC 弃权，退回实时深度证书。

**P14 全身证书律（Whole-Body Certificate, WBC）**
末端证书必须由基座信念与关节信念共同传播：`Σ_ee = J_b Σ_b J_bᵀ + J_q Σ_q J_qᵀ`；`g_ee = dist − κ√(nᵀΣ_ee n) − β_kin`。全身证书 = 末端证书 ∧ 稳定裕度证书（m_stab ≥ m_min(φ)），二者为合取，且任一失效即整证书失效，不允许用「平衡尚可」掩盖「间隙不足」或反之。

**P15 相位治理律（Gait-Phase Governance, GPG）**
重模块仅在双支撑或稳定单支撑窗口获准；契约截止期随相位变化 D_m(φ)；腾空期只允许 ≤0.3ms 守卫与预认证动作。K_eff 同时受 Δ_dom、地图漂移 δ_map、步态不确定 δ_gait 与稳定裕度门控。每个被接受的块必须满足 P_t^rec ≠ ∅：任一可能的中止点都配有一个当前相位下可执行的认证恢复动作。

## 3. 与基线的接口（如何退化）

- MEC 失效（epoch 不一致 / 关联置信不足 / 协方差未标定）⇒ 地图视为空，证书 = 实时深度间隙（等价 v9 SpatialCert），risk_SLAM 标量保留；
- WBC 失效（基座信念不可用 / 运动学失配 / 线性化越界）⇒ 基座视为恒等零协方差，解除平衡约束，退回 v9 静态末端证书；
- GPG 失效（相位不可辨 / 接触计划不可信）⇒ 相位恒为双支撑、预算恒定，K_eff 退回 v9 定义 539；
- CRP 失效（恢复集不可认证）⇒ 中止退化为 v9 减速停车；若该停车在当前相位不可证安全，则拒绝块，退回单步 fallback；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 五级退化链；
- 全部失效 ⇒ 完整退回 v9 ACMD，再退回 v8 → v7 → v6。

## 4. 预期贡献

1. **地图版本证书**：把 SLAM 漂移、回环重写、数据关联歧义变成证书的可审计来源与可分解余量（相对协方差 vs 全局协方差、epoch 失效、假设包络）；
2. **全身证书**：把基座信念与动态平衡纳入操作证书，给出可证的「够得到且站得稳」，并把打滑引起的秩亏方向显式膨胀；
3. **步态相位治理**：让步态节拍同时充当算力调度器与安全边界；认证恢复步替代朴素停车；
4. **双突发鲁棒性**：地图修订 × 步态切换造成的证书空窗被来源感知分块与恢复证书消除；E571–E590 覆盖漂移、回环、关联、打滑、腾空、恢复与端到端。

## 5. 本轮最大风险

**一句话**：整个方案依赖「epoch 是地图修订的完备审计」——若回环/重定位被延迟检测，或漂移被平滑吸收而未触发版本递增，旧来源证书仍会通过校验，机器人在一张已经「瞬移」的地图上自信操作，廉价证书的代价是它只在来源诚实时才诚实。

## 1. 符号体系增量（定义 540–550）

| 符号 | 含义 |
|---|---|
| e ∈ ℕ | 地图版本（epoch）：任一次硬拓扑编辑后递增 |
| D_{e→e'} | 相邻 epoch 间的漂移变换，‖D‖ ≤ ρ_drift·L_path + ε_drift |
| μ_o, Σ_o, e_o, p_exist(o) | 地图元素 o 的均值、协方差、生成版本、存在概率 |
| Σ_xo | 机器人与障碍在同一因子图中的互协方差 |
| π(C) = (e_src, a_id, v_cal, φ_src, t_src) | 证书来源：地图版本、锚点 id、标定版本、相位版本、生成时刻 |
| Σ_rel | 相对平移协方差 = Σ_x + Σ_o − Σ_xo − Σ_ox |
| δ_res, δ_drift, δ_amb | 地图分辨率、跨子图漂移、关联误差的确定性膨胀项 |
| g_map, g_assoc | 地图锚定间隙下界、关联包络后的间隙下界 |

| s_t, Σ_slip | 打滑标志与滑移方向膨胀协方差（该方向秩亏） |

| K_eff(t) | 有效块长（定义 548，v9 定义 539 的严格扩展） |

**新增定义 540（地图版本 MapEpoch）** 地图 M 的版本 e∈ℕ 在任一硬编辑时递增：回环提交、子图合并、重定位跳变（‖Δx‖>δ_reloc 或 ‖Δθ‖>δ_reloc^rot）、标定坐标系变更。相邻版本间存在不可观测漂移 D_{e→e'}，满足 ‖D_{e→e'}‖ ≤ ρ_drift·L_path(e,e') + ε_drift；无界定向时按上界膨胀。地图元素 o 记录 (μ_o, Σ_o, e_o, p_exist(o))。**关键**：epoch 不是时间戳，而是「坐标语义」的版本；跨 epoch 的几何量必须重新表达，不能默认延续。

**新增定义 541（证书来源 CertificateProvenance）** 每个证书 C 携带 π(C)=(e_src, a_id, v_cal, φ_src, t_src)。C 在时刻 t 有效 ⇔ `e_src = e(t)` ∧ `a_id` 仍在地图中 ∧ `v_cal = v_cal(t)` ∧ `φ_src` 与当前相位相容（同相位或相邻且已通过过渡守卫）。来源是证书的一等字段，而非隐含假设。

**新增定义 542（地图锚定相对证书 MapAnchoredCertificate）** 对障碍 o 与机器人位姿 x（二者来自同一因子图边缘化，含互协方差），相对平移 r=o−x 的协方差
```
Σ_rel = Σ_x + Σ_o − Σ_xo − Σ_ox
g_map(o) = ‖μ_o−μ_x‖ − κ√(nᵀΣ_rel n) − δ_res − δ_drift(e,e_o) − δ_amb
```
其中 n 为单位方向，δ_drift 仅在跨子图/跨 epoch 锚定时计入。证书要求 `min_o g_map(o) ≥ d_safe` 且 `p_exist(o) ≥ p_min`。**相对协方差**而非全局绝对协方差，是让局部操作在长路径漂移下仍可用的关键（引理 88）。

**新增定义 543（关联包络 AssociationEnvelope）** 设数据关联假设 h∈ℋ，权重 w_h，每 h 给出一组障碍与间隙 g_map^h。证书取
```
g_assoc = min_{h: w_h ≥ w_min} g_map^h − δ_amb
```
若 `max_h w_h < p_min` 或 `g_assoc < d_safe`，则 MEC 弃权。此即「不知道是哪个障碍」时对最坏自洽假设取保守界；真相不在 ℋ 时的开放式失败由风险节单列，不假装被覆盖。

**新增定义 544（基座信念 BaseBelief）** `b_t ~ N(μ_b, Σ_b)` 由腿式里程计预积分、IMU、接触约束融合，含位置、roll/pitch/yaw 与高度。打滑检测 s_t∈{0,1}；s_t=1 时沿滑移不可辨方向膨胀 `Σ_b ← Σ_b + Σ_slip`（该方向观测矩阵秩亏，只能取先验上界）。基座信念随时间自然增长，不假设外部定位始终可用。

**新增定义 545（全身证书 WholeBodyCertificate）** 末端位姿 T_ee = T_b ⊗ T_arm(q)，一阶协方差
```
Σ_ee = J_b Σ_b J_bᵀ + J_q Σ_q J_qᵀ (+ J_bq Σ_bq J_bqᵀ)
g_ee = dist(p_ee, O) − κ√(nᵀΣ_ee n) − β_kin
```
证书有效 ⇔ `g_ee ≥ d_safe` ∧ 姿态锥约束（approach 方向与法向夹角 ≤ α_max(Σ_ee^rot)）∧ 稳定裕度证书。**全身证书 = 末端证书 ∧ 稳定裕度证书（定义 546）**，二者合取，任一方失效即整体失效，禁止用一个的高裕度去「抵消」另一个的违反。

**新增定义 546（动态稳定裕度 StabilityMargin）** 支撑多边形 P(φ,c)，捕获点 ξ = x_com + v_com/ω0。`m_stab = signed_dist(ξ, ∂P) − m_margin(terrain,v)`。稳定 ⇔ `m_stab ≥ m_min(φ)`：DS 时 m_min 最低，SS 时提高，TR 时按两者较严。**腾空期静态裕度无定义**，改用「腾空预算 + 落足可行性」：仅当块内腾空段已被预先认证，或块在腾空前结束，否则不接受。

**新增定义 547（步态相位与接触计划 GaitPhase）** φ(t)∈{DS, SS_L, SS_R, FL, TR}，接触计划 c(t) 给出四足预期接触/离地时刻。相位提供三样东西：(i) 稳定预算 m_min(φ)；(ii) 可执行中止集 R(φ)；(iii) 重计算窗口 W(φ)。TR 是「证书收紧」而非新的宽松状态。相位版本 φ_src 进入证书来源，防止用腾空期生成的证书去守卫支撑期动作。

**新增定义 548（相位门控预算与有效块长 PhaseGatedBudget）**
```
K_eff(t) = 1   若 ¬U_t(v9) ∨ e(t)≠e(t−1) ∨ φ(t)=FL ∨ m_stab(t)<m_min
         = max(1, ⌊K_max·(1 − max(Δ_dom/τ_dom, δ_map/τ_drift, δ_gait/τ_gait))⌋)  否则
```
δ_map 为自上次锚定以来的漂移估计，δ_gait 为相位不确定性。MW 契约截止期变为 D_m(φ)，且重模块只在 `φ∈W(φ)={DS, 稳定 SS}` 获准；FL 只允许 ≤0.3ms 守卫与预认证动作。K_eff 同时受三种不确定性门控，任一越阈立即 K=1。

**新增定义 549（认证恢复中止 CertifiedRecoveryAbort）** 恢复动作集 R={hold, step(f), lower_body, sit}。中止点 p 的恢复证书
```
Cert_rec(p) ⇔ ∃r∈R: m_stab(p,r) ≥ m_min(φ_p) ∧ g_ee(p,r) ≥ d_safe
                     ∧ τ_exec(r) ≤ remaining_time(φ_p)
```
`P_t^rec = {p : Cert_rec(p)}`。块被接受 ⇔ `P_t^rec ≠ ∅`；中块违规时选 ≤k_exec 的最大 p*，执行其恢复 r(p*)；无 p* 则只允许单步 fallback（等价 v9）。**停车只是 R 的一个元素，不是默认答案**——在单支撑/斜坡上，朴素停车的裕度可能为负。

**新增定义 550（中立元退化表 NeutralElementTable v10）**

| MEC | 地图置空（O=∅，min 取 +∞） | 证书 = 实时深度间隙，等价 v9 SpatialCert；risk_SLAM 标量保留 |

@dataclass(frozen=True)
class Provenance:
    epoch: int; anchor: str; calib: int; phase_ver: int; t: float

class MapEpochCertifier:                       # IP-357
    def __init__(self, kappa=3.0, d_safe=0.15, p_min=0.9,
                 delta_res=0.02, delta_amb=0.01, delta_reloc=0.3):
        self.kappa, self.d_safe, self.p_min = kappa, d_safe, p_min
        self.delta_res, self.delta_amb = delta_res, delta_amb
        self.delta_reloc = delta_reloc
        self.epoch = 0

    def on_map_edit(self, edit):
        hard = (edit.is_loop_closure or edit.is_submap_merge
                or edit.pose_jump > self.delta_reloc
                or edit.calib_frame_changed)
        if hard:
            self.epoch += 1                   # 定义 540：坐标语义版本递增
            invalidate_chunks_by_epoch(self.epoch)

    def certificate(self, x_node, obstacles, provenance, w_min=0.05):
        if provenance.epoch != self.epoch:    # 定义 541：来源失配即弃权
            return None
        g_best = float("inf")
        for h, w in association_hypotheses(obstacles):     # 定义 543
            if w < w_min:
                continue
            g_h = float("inf")
            for o in h:
                if o.p_exist < self.p_min:
                    continue
                Sigma_rel = (x_node.Sigma + o.Sigma
                             - x_node.Sigma_xo - o.Sigma_ox)   # 定义 542
                n = unit(o.mu - x_node.mu)
                drift = self.drift_bound(self.epoch, o.epoch)
                g = (norm(o.mu - x_node.mu)
                     - self.kappa * sqrt(n @ Sigma_rel @ n)
                     - self.delta_res - drift - self.delta_amb)
                g_h = min(g_h, g)
            g_best = min(g_best, g_h)
        if g_best < self.d_safe:
            return None
        return Certificate(g=g_best, provenance=provenance)

    def drift_bound(self, e_now, e_o):
        if e_now == e_o:
            return 0.0
        return rho_drift * path_length(e_now, e_o) + eps_drift


class WholeBodyCertifier:                      # IP-358
    def __init__(self, kappa=3.0, d_safe=0.15, beta_kin=0.01):
        self.kappa, self.d_safe, self.beta_kin = kappa, d_safe, beta_kin

    def certify(self, base: BaseBelief, q, q_cov, obstacle, phase):
        J_b, J_q = kinematic_jacobians(base.mu, q)
        Sigma_ee = J_b @ base.Sigma @ J_b.T + J_q @ q_cov @ J_q.T
        n = unit(obstacle.mu - forward_kinematics(base.mu, q).p)
        g_ee = (norm(obstacle.mu - forward_kinematics(base.mu, q).p)
                - self.kappa * sqrt(n @ Sigma_ee @ n) - self.beta_kin)
        m_stab = stability_margin(base, phase)             # 定义 546
        ok = (g_ee >= self.d_safe
              and orientation_cone_ok(base, q, Sigma_ee, obstacle)
              and m_stab >= m_min(phase))
        return WholeBodyCert(g_ee, m_stab, ok)


class GaitPhaseGovernor:                       # IP-359
    def __init__(self, T_gait=0.4, K_max=10):
        self.T_gait, self.K_max = T_gait, K_max

    def phase(self, t, contact_plan):
        return phase_lookup(contact_plan, t)               # 定义 547

    def budget(self, module, phase):                       # 定义 548
        if module in HEAVY_MODULES and phase not in STABLE_WINDOW:
            return 0.0
        return D_m.get((module, phase), D_m_default[module])

    def k_eff(self, delta_dom, tau_dom, delta_map, tau_drift,
              delta_gait, tau_gait, epoch_changed, trust_ok,
              phase, m_stab):
        if (not trust_ok or epoch_changed or phase == "FL"
                or m_stab < m_min(phase)):
            return 1
        r = max(delta_dom / tau_dom, delta_map / tau_drift,
                delta_gait / tau_gait)
        return max(1, int(self.K_max * (1.0 - min(1.0, r))))


class CertifiedRecoveryPlanner:                 # IP-360
    RECOVERY = ("hold", "step", "lower_body", "sit")

    def abort_set(self, state, chunk, phase_at):
        pts = {}
        for p in range(1, len(chunk.actions)):             # 定义 549
            for r in self.RECOVERY:

                    pts[p] = r

        if r == "lower_body":

        if r == "sit":
            return sit_certificate(s, phase)
        return stability_margin(s, phase) >= m_min(phase)   # hold

## 4. 推导

**引理 87（来源健全性与 epoch 失效必要性）** 设证书 C 于 epoch e 按定义 542 生成（漂移界、关联包络、高斯尾界均成立）。(i) 在 epoch e 内，C 的 g_map 以概率 ≥1−α 是真实间隙的下界；(ii) 若当前 epoch e' ≠ e 而未重算，则存在一个与漂移界相容的修订，使真实间隙低于 C 的 g_map。故「跨 epoch 强制重算」是保证健全性的最小安全策略。
证明：(i) 由 ‖Δr‖ 的高斯尾界 + 确定性膨胀项 δ_res/δ_drift/δ_amb 直接得下界；(ii) 构造修订 D 使障碍沿 r 方向平移 2δ_drift（仍在漂移上界内），则真实间隙减少 2δ_drift，可使原本 g_map≥d_safe 的证书失效。∎

**引理 88（相对协方差占优）** 对联合高斯的 (x,o)，`Var(o−x) = Σ_x + Σ_o − Σ_xo − Σ_ox ⪯ Σ_x + Σ_o`（Loewner 序），因此 `g_rel ≥ g_abs`：相对证书在不降低置信度的前提下比全局绝对膨胀更紧；局部操作不会因长路径漂移而不可用。
证明：`Σ_xo+Σ_ox` 为对称矩阵，其 PSD 性使差为 PSD（由联合协方差 PSD 推出 cross-covariance 的可行性）；半正定差 ⇒ 任意方向方差更小 ⇒ 减去的 κ 倍标准差更小。∎

**引理 89（全身证书组合保守性）** 设末端映射 T_ee=f(b,q) 在信任域 B 上 C¹，`sup_B‖f−f_lin‖ ≤ ε_lin`，且 Jacobian 有界。则真实末端误差以概率 ≥1−α 落在椭球 `{δ : δᵀΣ_ee⁻¹δ ≤ κ²}` 膨胀 ε_lin 内；姿态用 SO(3) 测地范数同理。故 g_ee 是保守下界。
证明：一阶 Taylor 展开余项由 ε_lin 控制；基座与关节误差的高斯传播给出协方差；线性化残差与随机项独立上界相加。∎

**引理 90（相位门控与实时性/安全性）** 若重模块仅在 `φ∈W(φ)` 且 `m_stab≥m_min` 时获准，契约满足 `Σ_m Ŵ_m(φ) ≤ B_dec(φ)`，且每个被接受的块满足 `P_t^rec ≠ ∅`，则 (i) 每周期执行时间不超预算；(ii) 任一中块违规（含腾空期）都有当前相位可执行的认证恢复，不产生「证书空窗」。
证明：(i) 由定义 548 的窗口与截止期，EDF 可调度性按相位分段成立；(ii) 接受条件给出每个 p 的 r(p)，建造块时保证腾空段要么在块结束前，要么其恢复已预认证；守卫选最大 p*≤k_exec，定义 549 保证 r(p*) 的执行时间在相位剩余内。∎

**引理 91（恢复中止支配停车）** 若 `stop ∈ R` 且停车在当前相位可证安全，则 `P_t^rec ⊇ P_t^{v9}`；若停车不可证安全，认证恢复步仍可能给出安全中止，故恢复集严格不弱于 v9 的停车中止。
证明：v9 的 P_t 对应恢复 r=stop；定义 549 的中止集对同一 p 只要存在一个 r 成立即可，集合包含关系成立。单支撑/斜坡上停车裕度可为负，而 step/lower_body 可恢复正裕度。∎

**引理 92（中立元退化 ⇒ v9 逐位等价）** 注入定义 550 的中立元后：MEC 的 O=∅ 使 `min` 取 +∞ ⇒ 证书等于实时深度间隙；WBC 的 Σ_b=0、m_stab=+∞ 使 g_ee 与约束退化为 v9 静态末端证书；GPG 的 φ≡DS 使 K_eff 化为定义 539；CRP 的 R={stop} 使中止化为定义 534；契约中立元与 v9 表 536 一致。故可观测行为与 v9 逐位等价。
证明：逐定义代数化简；MW 只改变调度顺序、不改变取值集合（v9 引理 83）；各中立元均为对应聚合/合取算子的恒等元（min 的空集元为 +∞，合取的恒等元为真，协方差恒等为零）。∎

**引理 93（关联包络保守性）** 若真实关联 h*∈ℋ 且 `w_{h*}≥w_min`，则 `g_assoc ≤ g_map^{h*}`，包络证书保守；(ii) 若 `max_h w_h < p_min` 或 `h*∉ℋ`，MEC 弃权，退实时证书——安全但可能不可用；开放世界错误不被「假装修复」。
证明：(i) 由 min 的定义直接得；(ii) 定义 543 的弃权条件触发，回退路径由引理 92 保证。∎

## 8. 本轮最大风险

**一句话**：整个方案依赖「epoch 是地图修订的完备审计」——若回环/重定位被延迟检测，或漂移被平滑吸收而未触发版本递增，旧来源证书仍会通过校验，机器人在一张已经「瞬移」的地图上自信操作，廉价证书的代价是它只在来源诚实时才诚实。
