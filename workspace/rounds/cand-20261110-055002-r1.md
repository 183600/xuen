# 第 41 轮 · 双资源落地 v18：情感状态证书 × 续航证书 × 情感-能量联合调度（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「情感计算、续航能力」把优化目标从「一次任务能否成功」推进到「长时陪伴能否被人类愿意地持续」：将人的情感状态与机器人的能量状态都抽象为**缓慢演化、可耗尽、可恢复、可被行为调控的资源变量**，并把二者纳入同一套 CBF、证书与课程框架，形成「双资源守恒」的可认证长时自治。

## 0. 直觉与动机

**灵感 1（情感计算 → 情感是慢变量，也是隐式安全约束）**：前 40 轮的安全几乎都是物理安全（碰撞、跌倒、几何 CBF）。但人形机器人在真实家庭/养老场景里可以「任务成功、体验失败」：它把杯子递到了，却因为过快、过近、语气生硬让用户紧张或反感。情感计算的价值不只是「识别情绪」，而是提供一个**可被机器人行为影响、演化较慢、只能带噪观测的状态量** a_t（效价、唤醒度、压力、投入度）。一旦把 a_t 看成受控慢变量，就能沿用第 40 轮的 CBF 语言：给「人的舒适/投入」定义安全集与障碍函数，机器人动作必须满足情感 CBF。情感估计的误差球 B_aff 与第 40 轮激光雷达漂移球 B_t 完全同构——证书第一次把「人的感受」纳入有效域。

**灵感 2（续航能力 → 能量是硬约束的随机过程，且计算也耗能）**：第 40 轮把执行误差与延迟写进证书，却没有写「焦耳」。流匹配每多一步积分就多一次前向，一致性蒸馏、VLM 推理、ESDF 更新都在吃电。续航不是电量百分比，而是一个**功率模型 + 随机消耗过程 + 热降额 + 安全返航储备**的复合约束。于是「续航证书」要回答的不是「还能跑多久」，而是「以 ≥1−δ 的概率，在未来 H 分钟内电量始终高于安全返航储备，且任务可达」。这把能量从工程指标提升为与 L_v、κ 同级的一等证书量。

**灵感 3（耦合 → 社交电池：表达是情感与能量之间的汇率）**：陪伴场景里存在一个残酷交换：更丰富的韵律、更慢更柔的动作、更多目光与语言能提升人的投入度，但显著增加功率；而「节能模式」（更快、更少表达、更少交互）会节省电量却让人投入度衰减。因此机器人同时持有两块电池：**物理电池 e_t** 与**社交电池 s_t**（维持高质量表达性交互的虚拟储备）。二者通过「表达强度」这一控制量耦合。最优策略不是最大化任一块，而是在长时域上维持两块都高于储备的**情感-续航运行包络**（AEOE）。这也给第 40 轮的韵律 s 一个经济学解释：韵律不是鲁棒性配置，而是**情感收益/能量成本的汇率旋钮**。

**与既有工作的耦合**：流匹配证书的 N* 从「满足误差的最小步数」升级为「在 ε_tol 与延迟约束下最省能的步数」；技能总线按能量成本与情感前置条件路由；课程难度增加「航程/情感负荷/能量稀缺」三轴；RCA 监控对象从权重与积分器扩展到「人的状态」与「电池状态」。

## 1. 形式化定义

**定义 27（情感状态与情感证书 CertAff）**：人的情感状态 a_t = (v_t, r_t, σ_t, g_t) ∈ A ⊂ R⁴，分别为效价、唤醒度、压力、投入度。观测 y_t（面部 AU、语音韵律、姿态/步态、可选 HRV）经估计器给出 â_t 与 (1−δ) 置信球 B_aff(t) = {a : (a−â_t)ᵀ Σ_aff⁻¹ (a−â_t) ≤ χ²₄(1−δ)}。情感响应模型 ȧ = f_a(a, u, c) + w_a，u 含速度、接近距离、韵律 s、目光与语言量，w_a 有界。情感谓词 φ_aff：σ_t ≤ σ_max ∧ g_t ≥ g_min（可用光滑 min 合成）。鲁棒情感 CBF：h_aff(a) = smoothmin(σ_max − σ, g − g_min)，约束 ḣ_aff ≥ −α_aff·h_aff；对估计球做最坏情况膨胀得可执行条件 h_aff(â) − L_aff·B_aff ≥ 0，其中 L_aff = Lip(h_aff∘f_a)。CertAff = {φ_aff, B_aff, f_a, L_aff, α_aff}。

**定义 28（功率模型与续航证书 CertEnergy）**：电量 e_{t+1} = clip(e_t − Δ_t·P_t + r_t, 0, E_max)。功率分解 P_t = P_motor(τ, gait) + P_comp(N, model) + P_sense + P_comm，其中 P_comp = c_f·FLOPs(π, N)（N 为流采样步数）。热模型 T_{t+1} = T_t + (P_t − h(T_t − T_env))·Δ_t/C_th，并产生降额 P_max(T_t, SOH_t)。随机功率的 (1−δ) 上界 P̂_t 由在线样本的 Bennett/经验 Bernstein 不等式给出，对 H 步做区间传播得累计消耗界。续航证书 CertEnergy = {P̂, B_P, e_res(H), T_safe}：以 ≥1−δ 概率，∀t∈[0,H]，e_t ≥ e_res(t) 且安全返航时间 ≥ T_req；其中 T_safe = (e_t − e_res)/P̂。能量 CBF：h_e(e) = e − e_res(t)，约束 ḣ_e ≥ −α_e·h_e。

**定义 29（情感-续航运行包络 AEOE 与社交电池）**：资源向量 R_t = (e_t, s_t)，社交电池 ḣ_s = r_s(rest) − c_s(u, s)（表达强度越高、交互越密，c_s 越大）。人的投入度受表达驱动：ġ = α_g·u_express − β_g·(1 − g) − γ_g·fatigue(H)。AEOE = {(a, e, s) : φ_aff(a) ∧ e ≥ e_res ∧ s ≥ s_res ∧ ValidRegion_geo}。长时目标：max_π E[∫₀^H (g_t + r_task − λ_e·P_t − λ_v·1[violation]) dt]，s.t. 情感/能量/社交三类 CBF。交换律：存在帕累托前沿 {(Δg, ΔP, Δs)}，u_express 是前沿上的调度参数。

**定义 30（情感-续航课程）**：在定义 26 基础上把边际集合扩展为 m_i ∈ {λ̂, 1/L̂, ĥ_min, 1/μ̂, ε̂_ode, B̂, ĥ_aff, ĥ_e, ĥ_s}，难度 D(τ) = Σ w_i·max(0, 1 − m_i/c_i)。三轴课程：航程 H（10min→2h）、情感负荷（用户压力/歧义/打断频率）、能量稀缺（起始电量/充电机会）。课程带自适应沿用 Robbins-Monro；新增「配速课程」：在固定 H 下学习表达强度调度。

## 2. 三大产出设计

### 2.1 IP-51 AFFECTIVE-STATE-CERTIFICATE（情感状态证书）
1. 多模态估计：面部 AU + 语音韵律 + 姿态/步速 + 可选腕带 HRV；深度集成/贝叶斯末层给 Σ_aff，温度缩放 + conformal 校准保证 B_aff 覆盖率。
2. 响应模型：以机器人动作（速度、距离、韵律、目光）与上下文为输入，学习 f_a 的集合；谱归一化 + Lipschitz 正则给出 L_aff 上界。
3. 鲁棒 CBF-QP：在（速度、距离、韵律）上求最小修正，估计球膨胀；QP 不可行时降级到最小扰动安全动作。
4. 个性化与漂移：每用户少样本校准基线，检测分布漂移触发重估与重颁证书。
5. 伦理与隐私：端侧推理、原始视频不出设备、知情同意；情感推断仅用于交互调节，不作医疗诊断。

### 2.2 IP-52 ENDURANCE-CERTIFICATE（续航证书与代谢规划器）
1. 功率分解与在线辨识：电流/电压/温度传感 + 学习残差，分离电机/计算/传感/通信。
2. 续航证书：Bennett 上界 + 区间传播 + 热模型 + 电池 SOH，输出 e_res(t) 与安全返航策略（保守图搜索）。
3. 能耗感知技能图：节点/边携带能量分布与热成本，规划转为资源约束最短路/随机最短路。
4. 能耗感知流采样：N*_e = argmin_N E(N) s.t. ε_ode(N) ≤ ε_tol ∧ latency ≤ L_max，与蒸馏档位联合选择。
5. 电池老化/温度：在线容量估计，储备随 SOH 调整；低电量触发返航/充电桩路由。

### 2.3 IP-53 AFFECTIVE-ENERGY-HOMEOSTAT（社交电池调度器）
1. 联合资源状态 (a, e, s) 与慢时间尺度 MPC（秒级）规划表达强度与任务节奏。
2. 表达调度：u_express 映射到韵律 s、移动速度、语言量；离散模式 comfort/calm/efficient/rest。
3. 休息与充电：任务交织，低需求时段充社交电池；物理充电桩与休息点锚定到语义图（IP-36）。
4. 多目标：在线估计帕累托前沿，按用户偏好与任务价值选点。
5. 降级与交接：能量低→efficient；情感风险高→comfort；两者冲突时安全优先并显式告知/请求人类。

### 2.4 IP-54 AFFECT-ENDURANCE-CURRICULUM（情感-续航课程）
1. 三轴课程：航程 H、情感负荷、能量稀缺，难度用证书赤字（定义 30）。
2. 配速课程：从短程高表达 → 长程混合配速，逐步加入能量稀缺与情感压力场景。
3. 闭环：采样 → 蒸馏 → 重颁 CertAff/CertEnergy → 契约热更新（复用 IP-50/IP-45）。
4. 反遗忘：按双资源赤字加权回放，保留短程高表达与紧急舒适模式。

## 5. 本轮最大风险

**一句话**：情感估计的跨人/跨文化校准与电池老化/低温造成的功率漂移是两座「不可证」暗礁——若 B_aff 与 B_P 被低估，CBF 会在最需要保护时给出虚假安全；若被高估，机器人会因过度保守而冻结或频繁返航，长时陪伴价值归零；故 E73/E75 必须先于任何端到端实验。

## 2. 关键算法

### IP-51 情感状态证书（伪代码）
```
def estimate_affect(y, user_id, delta=0.01):
    a_hat, Sigma = ensemble_predict(y)          # 深度集成 + 温度缩放
    Sigma = personal_warp(Sigma, user_id)        # 少样本个性化
    B_aff = sqrt(chi2_quantile(4, 1-delta) * trace(Sigma))
    return a_hat, B_aff

def affect_cbf_qp(u_ref, a_hat, B_aff, f_a, L_aff):
    h      = smoothmin(sigma_max - a_hat.stress, a_hat.engagement - g_min)
    dr     = jacobian(h, f_a, a_hat, u_ref)
    margin = L_aff * B_aff                       # 估计球最坏情况膨胀
    u_safe = solve_qp(min ||u-u_ref||^2, s.t. dr@u + alpha*h >= margin)
    return u_safe if feasible(u_safe) else least_disturbance_safe(a_hat)
```

### IP-52 续航证书与代谢规划（伪代码）
```
def endurance_certificate(e, T, soh, H, delta=0.01):
    P_hat = bennett_upper(power_samples, delta)   # 在线功率样本
    P_hat = apply_derating(P_hat, T, soh)          # 热 + 老化降额
    e_res = safe_return_reserve(H, P_hat)          # 保守返航所需能量
    T_safe = max(0.0, (e - e_res) / P_hat)
    return CertEnergy(P_hat, B_P, e_res, T_safe, coverage=1-delta)

def energy_aware_flow_steps(grid=[4,8,16,32], eps_tol=1e-2, lat_max=20e-3):
    feasible = [N for N in grid if eps_ode(N) <= eps_tol and latency(N) <= lat_max]
    return min(feasible, key=lambda N: energy(N))   # N*_e

def metabolic_route(skill_graph, e, H):
    return resource_constrained_path(skill_graph, energy=e-e_res(H),
                                     cost=lambda edge: edge.energy_dist)
```

def social_battery_mpc(a_hat, e, s, horizon, user_pref):
    modes = [comfort, calm, efficient, rest]
    best  = None
    for mode in modes:
        traj = predict(a_hat, e, s, mode, horizon)
        cost = -( engagement(traj) + task_value(traj)
                  - lam_e*energy(traj) - lam_v*violations(traj) )
        best = min(best, (cost, mode), key=lambda x: x[0])
    mode = best[1]
    if e < e_res or s < s_res:
        mode = safe_mode(mode)                      # 安全优先，显式告知/请求
    return mode_to_controls(mode)                   # prosody / 速度 / 语言量

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 情感估计跨人/跨文化校准差，B_aff 失真 | 高 | 少样本个性化 + conformal + 仅在中高置信时启用情感约束；E73 第一守门 |
| 电池老化/低温/坡道致功率模型漂移，续航界乐观 | 高 | 在线辨识 + SOH 在线估计 + 保守分位 + 滚动重认证；E75 第一守门 |
| 双目标冲突导致模式频繁切换/振荡 | 中 | 滞回 + 最小驻留时间 + 模式成本平滑 + 双时间尺度 |
| 情感约束过保守 → 任务冻结/成功率下降 | 中 | 仅在风险场景激活 + 可调 α_aff + 用户偏好权重 |
| 隐私与伦理（情感推断被滥用） | 高 | 端侧推理、原始视频不出设备、知情同意、最小化、不作诊断 |
| 长时域误差累积使续航证书失效 | 中 | 分段界 + 滚动重认证 + 充电桩/休息点语义锚定 |

| 三轴课程组合空间爆炸 | 低 | 每轴量化档位（H: 3 档；情感: 3 档；能量: 3 档） |

## 6. 本轮最大风险

**一句话**：情感估计的跨人/跨文化校准与电池老化/低温造成的功率漂移，是 CertAff 与 CertEnergy 共同的「不可证」命门——低估则 CBF 在最需要保护时给出虚假安全，高估则机器人冻结或频繁返航、长时陪伴价值归零，故 E73/E75 必须先于一切端到端实验。
