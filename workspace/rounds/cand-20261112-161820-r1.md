# 第 61 轮（新一轮灵感循环第 1 轮；承接第 60 轮「场景感知闭环」SGEC IP-153~160；本轮灵感：「视觉语言模型」×「迁移学习」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC 把「场景语义」与「执行约束」接成了闭环，但留下三个结构性缺口：
> 1. **封闭场景集**：SSM 的 Z_scene 只有 10 个固定类（桌面/楼梯/湿滑…），现实长尾场景（半湿大理石、带冷凝水的玻璃、软包装边缘）无法归类；且场景类别与阻抗先验是手工绑定的（`_init_priors`），换机器人/换末端就要重标定。
> 2. **语义-阻抗冷启动**：新场景、新本体的 `π_scene(K|z)` 无历史数据，只能退回通用先验，第 60 轮所谓「先认知后执行」在冷启动时退化为「先保守后试错」。
> 3. **语义缺少物理背书**：SSM 的场景信念完全来自力/位遥测，缺少「看到什么、听懂什么」的开放语义；CIEC 的意图也只是固定 5 词表。二者都没有视觉-语言通道，导致「抽象泄漏」风险只能靠置信度阈值硬压。

## 0. 直觉与动机

**灵感 1（视觉语言模型 → 开放词汇场景接地 OVSG）**
直觉：不要问 VLM「这是 10 类里的哪一类」，而要问它「这里有哪些**与接触相关的属性**」。把场景从离散类别 z 重参数化为连续属性向量 a = (μ 摩擦, h 硬度, d 可变形性, r 粗糙度, b 易损性, θ 坡度)。VLM 输入 (RGB-D, 任务语言 L)，输出属性分布 p(a|I,L) 及逐属性置信度。关键洞见：**属性空间是开放的、可组合的**——「半湿的光滑大理石」不必是第 11 个类别，它只是 μ↓、h↑、r↓ 的属性组合，从而天然覆盖长尾。

**灵感 2（迁移学习 → 语义-阻抗先验蒸馏 SIPD）**
直觉：语义属性是**本体无关（embodiment-invariant）**的，阻抗是**本体相关（embodiment-specific）**的。所以迁移的应是「属性→阻抗」的映射 Φ: A→P(K)，而非直接迁移 K 值。Φ 在海量源任务/源本体上离线学习（分层贝叶斯/元学习），部署到新场景时只需极少量接触试次做**目标域适配**。关键洞见：**在语义层迁移、在本体层翻译**——既避开 sim-to-real 的原始信号鸿沟，又让 UniBot 换本体时只重学一个薄的适配层。

**灵感 3（迁移风险 → 迁移风险证书 TRC）**
直觉：迁移会「负迁移」：把「玻璃 = 高刚性高阻抗」的先验搬到「带冷凝水的玻璃」上可能致命。必须给每次迁移发一张证书：源-目标域差异 δ_dom（嵌入空间的 Wasserstein 距离）+ 目标支撑覆盖 cov_tgt + VLM 校准误差 ECE。只有 R_transfer ≤ τ_TR 才允许用该先验收紧 K_safe。关键洞见：**没有证书就不迁移**（no transfer without certificate），把「迁移」从默认动作降级为需要被授权的动作。

**灵感 4（VLM 幻觉 → 语义-物理一致性 CSPC + 顾问-执行门控 VAEG）**
直觉：VLM 会说错（把黏手桌面说成光滑），而执行层有能力证伪（接触力频谱、滑移比、压痕）。于是把 VLM 定为**顾问**而非**权威**：语义先验只能「收紧」不能「放宽」安全集；且收紧前必须通过 VAEG 门控——只有语义主张被物理证据背书（GROUNDED），或高置信且低迁移风险（TRUSTED_SEMANTIC）时才解锁激进阻抗。关键洞见：**VLM 提案、物理裁决**（VLM proposes, physics disposes），把第 60 轮的抽象泄漏从「概率护栏」升级为「结构护栏」。

**灵感 5（合流 → 语义迁移闭环 STEL + PCE+++++）**
直觉：OVSG 给出开放属性分布 → SIPD 迁移出阻抗先验 → TRC 发证书 → VAEG 只在证书有效时收紧 K_safe → 执行 → EV-exec → CSPC 对账语义与物理 → CTML 用 EV-exec 回写 Φ 与属性置信。闭环：**看/听 → 属性 → (迁移) → 先验 → 证书 → 阻抗 → 执行 → 物理 → 回写语义**。预算从 PCE++++ 扩到 PCE+++++：B_vlm（推理时延/算力）、B_tr（域适配试次）、B_ground（物理背书次数）、B_exec（原有）。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（开放词汇场景接地 OVSG）** 语义属性空间 A = A_μ × A_h × A_d × A_r × A_b × A_θ（连续/离散混合）。接地算子：
```
G: (I, L) → (p(a | I, L), c(a)),   I ∈ RGB-D, L ∈ 语言指令
```
其中 p(a|I,L) 是属性联合分布（可因子化），c(a) 是逐属性置信度，开放谓词集 V 不预设场景类别。语义信念 B_sem = (p(a), c(a), tokens)。
- **属性充分性**：要求 I(K; A) ≥ (1−ε)·I(K; Z)，即属性对阻抗的预测信息量不弱于离散场景类别；否则属性空间设计不合格。
- **属性-本体解耦**：a 的语义定义与具体机器人无关，仅 K 的物理解释依赖本体。

**定义 162（语义-阻抗先验蒸馏 SIPD）** 设源域集合 {D_j^S}、目标域 D^T，映射族 Φ = {p(K|a, φ)}，迁移算子 T_ψ: Φ_source → Φ_target：
```
p(K | a) = ∫ p(K | a, φ) · p(φ | D^S) dφ          （元先验）
φ^T ← argmax_φ [ log p(φ | D^S) + Σ_{i=1}^{n_g} log p(K_i | a_i, φ) ]   （少样本适配）
```
并将 Φ 蒸馏为轻量映射 g_θ: A → (μ_K, Σ_K)，供实时编译调用。关键：**迁移的是 a→K 的关系，不是 K 的数值**。

**定义 163（迁移风险证书 TRC）** 迁移风险
```
R_tr = α·W_2(emb(a^S), emb(a^T)) + β·(1 − cov_tgt) + γ·ECE_vlm
Cert_tr = ⟨valid, R_tr, δ_dom, cov_tgt, ece⟩
valid ⇔ R_tr ≤ τ_TR ∧ cov_tgt ≥ c_min ∧ ece ≤ ece_max
```
- **负迁移界**：存在单调函数 g（g(0)=0）使目标域遗憾 regret_T ≤ g(R_tr)。证书是把该界兑现为可执行判据。
- **授权语义**：Cert_tr.valid = false 时，SIPD 先验不得用于收紧 K_safe。

**定义 164（顾问-执行门控 VAEG）** 权威层级 $\mathcal{L} = \{$BASE_ONLY, TRUSTED_SEMANTIC, GROUNDED$\}$。语义收紧定义为**只做交集**：
```
K_safe^sem = K_safe_base ∩ { K | p(K | a) ≥ τ_K }
```
门控规则：
```
if CSPC(belief, EV-exec) ≥ τ_sp:            mode = GROUNDED            # 物理背书，允许收紧
elif Cert_tr.valid and min_a c(a) ≥ τ_c:    mode = TRUSTED_SEMANTIC    # 证书+高置信，允许收紧
else:                                       mode = BASE_ONLY           # 仅用第 60 轮基线
```
**结构性约束**：VAEG 只允许求交，永不求并、永不放宽 K_safe_base。这是「语义错误不越出物理安全边界」的构造性来源。

**定义 165（语义-物理一致性 CSPC）** 将语义主张映射到可观测量 χ(a)：摩擦→滑移比，硬度→压痕，易损性→力峰值，粗糙度→力高频能量。一致性分数
```
C_sp = (1/|A_obs|) · Σ_{a∈A_obs} s_a,   s_a ∈ [0,1]
```
若 C_sp < τ_sp：标记 contradiction，回退 BASE_ONLY 并对相应 c(a) 做贝叶斯惩罚 p(a) ← p(a)·L(EV-exec)/Z。

**定义 166（持续迁移元学习 CTML）** 迁移记忆 M_tr = (replay buffer, Φ, adapter versions)。更新规则（EWC 式抗遗忘）：
```
Φ_{t+1} ← Φ_t + η·∇ log p(K_obs | a, Φ) − λ·Ω(Φ_t; F_t)
```
其中 F_t 为 Fisher 信息，Ω 抑制对旧场景支撑的破坏，避免「学了湿滑忘了楼梯」。

**定义 167（认知预算 PCE+++++）** B_cog+ = (B_vlm, B_tr, B_ground, B_exec) 并继承 B_scene/B_intent/B_ros。VOI：
```
voi(π) = VOI_meta_pessimistic(π) − cost_vlm − cost_tr − cost_ground − cost_exec
```
降级：B_vlm 耗尽 → 用缓存属性/几何启发式；B_tr 耗尽 → 用通用 Φ_general；B_ground 耗尽 → 仅允许 TRUSTED_SEMANTIC 或 BASE_ONLY；B_exec 耗尽 → 沿用第 60 轮降级。

**定义 168（语义迁移闭环 STEL）** 算子 STEL(M, I, L, δ_f_req)：
```
① OVSG:  B_sem ← G(I, L)
② SIPD:  π_sem(K|a) ← T_ψ(Φ_source)(B_sem)
③ TRC:   Cert_tr ← certify(emb_source, emb(B_sem))
④ BASE:  K_base ← EEIS.compile(δ_f_req, fused, ξ_exec, Z_env)
⑤ VAEG:  K_safe^sem, mode ← gate(K_base, π_sem, Cert_tr, B_sem)
⑥ Dispatch: send_impedance_params(K_safe^sem, Cert_eeis)
⑦ Execute:  telemetry ← wait_contact(); EV-exec ← build_exec_evidence(...)
⑧ CSPC:  C_sp ← cross_modal_consistency(B_sem, EV-exec)
⑨ CTML:  Φ ← update(Φ, B_sem, EV-exec, replay); B_sem ← bayes_update(B_sem, EV-exec)
⑩ EPIR+: S_local.append(EV-exec); S_sync.push()
⑪ Return: (K_safe^sem, mode, Cert_tr, C_sp, EV-exec)
```

## 2. 关键算法伪代码

### IP-161 OVSG（开放词汇场景接地）

```python
class OpenVocabSceneGrounder:
    ATTRS = ['friction', 'hardness', 'deformability',
             'roughness', 'fragility', 'slope']
    def __init__(self, vlm, bins):
        self.vlm, self.bins = vlm, bins

    def ground(self, rgbd, task_lang):
        logits = self.vlm.infer(
            rgbd, task_lang,
            prompt="List contact-relevant attributes and their evidence.")
        p = {a: softmax(logits[a]) for a in self.ATTRS}
        c = {a: float(max(p[a])) for a in self.ATTRS}
        return SemanticBelief(p=p, conf=c, tokens=logits.tokens)
```

### IP-162 SIPD（语义-阻抗先验蒸馏）

```python
class SemanticImpedancePrior:
    def __init__(self, phi_source, adapter_lr=0.1):
        self.phi = phi_source          # A -> P(K), 元先验
        self.lr = adapter_lr
        self.n_contact = 0

    def prior(self, belief):
        return gaussian_mixture(
            [(self.phi(a), belief.p[a]) for a in belief.support()])

    def adapt(self, belief, k_obs):
        self.phi = self.phi.posterior_update(
            belief, k_obs, lr=self.lr)
        self.n_contact += 1
```

### IP-163 TRC（迁移风险证书）

```python
class TransferRiskCertificate:
    def __init__(self, tau_tr=0.25, c_min=0.6, ece_max=0.10):
        self.tau_tr, self.c_min, self.ece_max = tau_tr, c_min, ece_max

    def certify(self, src_emb, belief, phi_source):
        delta = wasserstein2(src_emb, belief.embed())
        cov = support_coverage(belief, phi_source.support)
        ece = calibrated_ece(belief)
        R = 0.5 * delta + 0.3 * (1 - cov) + 0.2 * ece
        valid = (R <= self.tau_tr and cov >= self.c_min
                 and ece <= self.ece_max)
        return Cert(valid, R, delta, cov, ece)
```

### IP-164 VAEG（顾问-执行门控）

```python
class AdvisoryExecutionGate:
    def gate(self, k_base, prior, cert, belief, ev_exec=None):
        k_sem = intersect(
            k_base, {K: prior.density(K) >= TAU_K})
        if ev_exec is not None:
            if cspc(belief, ev_exec) >= TAU_SP:
                return k_sem, 'GROUNDED'
            return k_base, 'BASE_ONLY'
        if cert.valid and min(belief.conf.values()) >= TAU_C:
            return k_sem, 'TRUSTED_SEMANTIC'
        return k_base, 'BASE_ONLY'
```

### IP-165 CSPC（语义-物理一致性）

```python
def cross_modal_consistency(belief, ev_exec):
    checks = []
    if 'friction' in belief.p:
        checks.append(agree_low(belief.p['friction'], ev_exec.slip_ratio))
    if 'hardness' in belief.p:
        checks.append(agree_high(belief.p['hardness'], ev_exec.stiffness))
    if 'fragility' in belief.p:
        checks.append(agree_low(belief.p['fragility'], ev_exec.force_peak))
    return float(np.mean(checks)) if checks else 0.0
```

### IP-168 STEL（语义迁移闭环）

```python
def semantic_transfer_evolution_loop(M, rgbd, task_lang, delta_f_req):
    belief = M.ovsg.ground(rgbd, task_lang)
    prior = M.sipd.prior(belief)
    cert = M.trc.certify(M.src_emb, belief, M.sipd.phi)

    k_base = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.z_env)
    k_sem, mode = M.vaeg.gate(k_base, prior, cert, belief)

    M, fused, D_plus, ev_exec, ce = closed_loop_exec_probe(
        M, M.cp, delta_f_req, M.budget)
    c_sp = cross_modal_consistency(belief, ev_exec)

    if c_sp >= TAU_SP and mode == 'GROUNDED':
        M.sipd.adapt(belief, ev_exec.k_obs)
    M.sipd.phi = M.ctml.update(M.sipd.phi, belief, ev_exec, M.replay)

    M.epir.append(ev_exec.__dict__)
    return M, fused, D_plus, ev_exec, belief, cert, c_sp, mode
```

### IP-167 PCE+++++（认知预算扩展）

```python
class CognitiveBudgetV5:
    def __init__(self, vlm_ops=20, tr_trials=5,
                 ground_ops=8, exec_budget=None):
        self.B_vlm, self.B_tr = vlm_ops, tr_trials
        self.B_ground = ground_ops
        self.B_exec = exec_budget or ExecBudget()
        self.used = {'vlm': 0, 'tr': 0, 'ground': 0}

    def mode(self):
        if self.used['vlm'] >= self.B_vlm:
            return 'CACHED_ATTRIBUTES'
        if self.used['tr'] >= self.B_tr:
            return 'GENERAL_PHI'
        if self.used['ground'] >= self.B_ground:
            return 'TRUSTED_OR_BASE_ONLY'
        return 'FULL'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| OVSG | O(1) 次 VLM 推理（0.2–1.5s） | O(d_emb) | 属性 top-1 ≥ 88%，长尾覆盖 +30% |
| SIPD | O(|support|·|K|) 先验 / O(1) 适配 | O(|Φ|) | ≤ 3 接触达到 D⁺ ≤ ε；迁移后 50% 更少试次 |
| TRC | O(n log n) 经验 Wasserstein | O(n) | 负迁移检测 AUROC ≥ 0.9，误发证 ≤ 2% |
| VAEG/CSPC | O(|K| + |A_obs|) | O(|K|) | 不安全收紧率 = 0（构造性） |
| STEL | 单闭环 | 复用第 60 轮 | 长尾成功率 +25%，冷启动 −50% |

**正确性定理（STEL-Safe / STEL-Utility）**：
假设 A66–A70 成立：**(A66)** VLM 属性分布经校准且有 ECE 上界；**(A67)** 源域 Φ 在支撑内以 1−α 覆盖真实 K；**(A68)** R_tr 上界目标域遗憾；**(A69)** CSPC 分数对物理证据单调、不可伪造；**(A70)** B_vlm/B_tr/B_ground/B_exec 单调消耗。

则：
1. **安全单调性（构造性）**：对任意 VLM 分布与任意迁移先验，恒有 K_safe^sem ⊆ K_safe_base；语义/迁移错误最多使可行集收缩或触发降级，**不会放宽物理安全边界**。
2. **效用界**：若 Cert_tr.valid 且 C_sp ≥ τ_sp，则 E[D⁺] ≤ D⁺_base + g(R_tr)，且 g(0)=0；即正确迁移只会改善、不会变差（在证书有效的分布上）。
3. **降级完备性**：任一 B_cog+ 耗尽，STEL 退回第 60 轮 SGEC 路径，安全性质由 SGEC 定理继承。
4. **抗遗忘**：CTML 的 EWC 正则使旧场景支撑上的 D⁺ 增量 ≤ ε_forget。

> 注意：定理 1 只保证「不放宽」，不保证「不过度收缩」。收缩过度的后果是「永远降级」，这是安全但无效的失败模式。

## 5. 本轮最大风险

**一句话**：安全单调性只保证「语义/迁移错误不放宽物理安全边界」，却保证不了「不过度收缩」——若 VLM 漏检易碎性、且 TRC 因源域覆盖不足而低估了域差异，系统可能在错误维度上把 K_safe 收紧到近乎空集，于是长期以「保守降级」运行却不报警，最终用「安全」掩盖了真正的语义失效。

## 2. 关键算法伪代码

### IP-161 OVSG（开放词汇场景接地）

```python
class OpenVocabSceneGrounder:
    ATTRS = ['friction', 'hardness', 'deformability',
             'roughness', 'fragility', 'slope']
    def __init__(self, vlm, bins):
        self.vlm, self.bins = vlm, bins

    def ground(self, rgbd, task_lang):
        logits = self.vlm.infer(
            rgbd, task_lang,
            prompt="List contact-relevant attributes and their evidence.")
        p = {a: softmax(logits[a]) for a in self.ATTRS}
        c = {a: float(max(p[a])) for a in self.ATTRS}
        return SemanticBelief(p=p, conf=c, tokens=logits.tokens)
```

### IP-162 SIPD（语义-阻抗先验蒸馏）

```python
class SemanticImpedancePrior:
    def __init__(self, phi_source, adapter_lr=0.1):
        self.phi = phi_source          # A -> P(K), 元先验
        self.lr = adapter_lr
        self.n_contact = 0

    def prior(self, belief):
        return gaussian_mixture(
            [(self.phi(a), belief.p[a]) for a in belief.support()])

    def adapt(self, belief, k_obs):
        self.phi = self.phi.posterior_update(belief, k_obs, lr=self.lr)
        self.n_contact += 1
```

### IP-163 TRC（迁移风险证书）

```python
class TransferRiskCertificate:
    def __init__(self, tau_tr=0.25, c_min=0.6, ece_max=0.10):
        self.tau_tr, self.c_min, self.ece_max = tau_tr, c_min, ece_max

    def certify(self, src_emb, belief, phi_source):
        delta = wasserstein2(src_emb, belief.embed())
        cov = support_coverage(belief, phi_source.support)
        ece = calibrated_ece(belief)
        R = 0.5 * delta + 0.3 * (1 - cov) + 0.2 * ece
        valid = (R <= self.tau_tr and cov >= self.c_min
                 and ece <= self.ece_max)
        return Cert(valid, R, delta, cov, ece)
```

### IP-164 VAEG（顾问-执行门控）

```python
class AdvisoryExecutionGate:
    def gate(self, k_base, prior, cert, belief, ev_exec=None):
        k_sem = intersect(
            k_base, {K: prior.density(K) >= TAU_K})     # 只收紧
        if ev_exec is not None:
            if cspc(belief, ev_exec) >= TAU_SP:
                return k_sem, 'GROUNDED'
            return k_base, 'BASE_ONLY'
        if cert.valid and min(belief.conf.values()) >= TAU_C:
            return k_sem, 'TRUSTED_SEMANTIC'
        return k_base, 'BASE_ONLY'
```

### IP-165 CSPC（语义-物理一致性）

```python
def cross_modal_consistency(belief, ev_exec):
    checks = []
    if 'friction' in belief.p:
        checks.append(agree_low(belief.p['friction'], ev_exec.slip_ratio))
    if 'hardness' in belief.p:
        checks.append(agree_high(belief.p['hardness'], ev_exec.stiffness))
    if 'fragility' in belief.p:
        checks.append(agree_low(belief.p['fragility'], ev_exec.force_peak))
    return float(np.mean(checks)) if checks else 0.0
```

### IP-166 CTML（持续迁移元学习）

```python
class ContinualTransferMeta:
    def __init__(self, lam=0.05):
        self.lam, self.fisher = lam, None

    def update(self, phi, belief, ev_exec, replay):
        batch = replay.sample() + [(belief, ev_exec.k_obs)]
        grad = sum(grad_log_lik(phi, a, k) for a, k in batch)
        if self.fisher is not None:                 # EWC 抗遗忘
            grad -= self.lam * self.fisher * (phi - self.prev_phi)
        self.prev_phi = phi.copy()
        return phi + ETA * grad
```

### IP-168 STEL（语义迁移闭环）

```python
def semantic_transfer_evolution_loop(M, rgbd, task_lang, delta_f_req):
    belief = M.ovsg.ground(rgbd, task_lang)
    prior = M.sipd.prior(belief)
    cert = M.trc.certify(M.src_emb, belief, M.sipd.phi)

    k_base = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.z_env)
    k_sem, mode = M.vaeg.gate(k_base, prior, cert, belief)

    M, fused, D_plus, ev_exec, ce = closed_loop_exec_probe(
        M, M.cp, delta_f_req, M.budget)
    c_sp = cross_modal_consistency(belief, ev_exec)

    if c_sp >= TAU_SP and mode == 'GROUNDED':
        M.sipd.adapt(belief, ev_exec.k_obs)
    M.sipd.phi = M.ctml.update(M.sipd.phi, belief, ev_exec, M.replay)

    M.epir.append(ev_exec.__dict__)
    return M, fused, D_plus, ev_exec, belief, cert, c_sp, mode
```

### IP-167 PCE+++++（四级预算降级）

```python
class CognitiveBudgetV5:
    def __init__(self, vlm_ops=20, tr_trials=5,
                 ground_ops=8, exec_budget=None):
        self.B_vlm, self.B_tr = vlm_ops, tr_trials
        self.B_ground = ground_ops
        self.B_exec = exec_budget or ExecBudget()
        self.used = {'vlm': 0, 'tr': 0, 'ground': 0}

    def mode(self):
        if self.used['vlm'] >= self.B_vlm:
            return 'CACHED_ATTRIBUTES'       # 用缓存属性/几何启发式
        if self.used['tr'] >= self.B_tr:
            return 'GENERAL_PHI'             # 退回通用 Φ_general
        if self.used['ground'] >= self.B_ground:
            return 'TRUSTED_OR_BASE_ONLY'    # 不再解锁物理背书通道
        return 'FULL'
```

## 3. 一个落地样例（半湿大理石 + 薄壁玻璃杯）

输入：RGB-D 图 + 指令「把旁边的玻璃杯拿起来，别捏碎」。

1. **OVSG**：VLM 输出 μ=low(0.85)、h=high(0.90)、r=low(0.72)、b(fragility)=high(0.80)、θ≈0。
2. **SIPD**：源域「干燥大理石」的 Φ 给出 K_p 偏高、K_d 中等；目标域因「半湿」在摩擦维度发生偏移，先验在切向柔顺/速度上收紧。
3. **TRC**：硬度维度 δ_dom 小、摩擦维度 δ_dom 较大；cov_tgt 高、ECE 低 ⇒ R_tr=0.18 ≤ 0.25，证书有效。
4. **VAEG**：首接触前 → TRUSTED_SEMANTIC，允许用先验收紧 v_max、抬高 F_tol 约束；首接触后 slip_ratio 与 μ=low 一致 ⇒ CSPC=0.91 → GROUNDED。
5. **CTML**：把本次 (a, K_obs) 写回 Φ；EWC 保证不破坏「楼梯/地毯」旧支撑。

安全对照：若 VLM 漏检 b(fragility)=high，则 F_max 不被收紧——这正是「语义失效但未必不安全」的灰色地带，需要 E195 专门度量。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| OVSG | O(1) 次 VLM 推理 | O(d_emb) | 属性 top-1 ≥ 88% |
| SIPD | O(\|support\|·\|K\|) / O(1) 适配 | O(\|Φ\|) | ≤ 3 接触 D⁺ ≤ ε |
| TRC | O(n log n) | O(n) | AUROC ≥ 0.9，误发证 ≤ 2% |
| VAEG/CSPC | O(\|K\| + \|A_obs\|) | O(\|K\|) | 不安全收紧率 = 0 |
| STEL | 单闭环 | 复用第 60 轮 | 长尾 +25%，冷启动 −50% |

**正确性定理（STEL-Safe / STEL-Utility）**：若 A66–A70 成立，则
1. **安全单调性（构造性）**：K_safe^sem ⊆ K_safe_base 恒成立；VLM/迁移错误只收缩或降级，不放宽物理安全边界。
2. **效用界**：Cert_tr.valid ∧ C_sp ≥ τ_sp ⇒ E[D⁺] ≤ D⁺_base + g(R_tr)，g(0)=0。
3. **降级完备性**：任一 B_cog+ 耗尽 ⇒ 退回 SGEC，安全性质继承。
4. **抗遗忘**：CTML 的 EWC 使旧场景支撑上的 D⁺ 增量 ≤ ε_forget。

> 定理 1 的边界必须明说：它保证「不放宽」，不保证「不过度收缩」。收缩过度的失败模式是「安全但永远降级」。

## 6. 本轮最大风险

**一句话**：安全单调性只保证「语义/迁移错误不放宽物理安全边界」，却保证不了「不过度收缩」——若 VLM 漏检易碎性、且 TRC 因源域覆盖不足而低估了域差异，系统可能在错误维度上把 K_safe 收紧到近乎空集，于是长期以「保守降级」运行却不报警，最终用「安全」掩盖了真正的语义失效。
