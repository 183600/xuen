# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「世界模型」×「大语言模型」）

> 第 66 轮 RAS 把 VISTA 的「被动故障响应」升级为「主动意图感知」，但它仍有两个根本盲点：
> 1. **归因是回顾性的**：故障假设集 ℋ 由人手工枚举，归因靠残差签名匹配，只能回答「哪一层像坏了」，不能回答「如果按这个假设演化，未来会看到什么」；
> 2. **证书是短视的**：C-RAS 只校验当前块的前缀安全裕度，不做「执行后未来 k 步会怎样」的反事实推演。
>
> 本轮把「世界模型」与「大语言模型」接入闭环，核心命题是：
>
> **LLM 提议，世界模型证伪（LLM proposes, world model falsifies）：用大语言模型把开放世界的任务语义与安全规则编译为可测量的约束和候选故障假设；用世界模型对每个假设做反事实 rollout，把「签名匹配」升级为「模型证据归因」，把「当前块安全」升级为「想象中可证伪的动作块安全」。**
>
> 这套框架称为 **LWC（Language-grounded World-model Closure，语义接地的世界模型闭环）**。它不把 LLM 放进实时控制回路——LLM 只在语义流里生成「可被检验的命题」，世界模型在语义流里做「可复现的反驳」，实时流只执行已编译、已认证的前缀。这样既保留 LLM 的开放语义能力，又把它的幻觉隔离在控制之外。

## 0. 直觉与动机

**灵感 1（世界模型 → 从「签名匹配」到「反事实重现」）**
直觉：第 66 轮的 FIR/EFS 归因像是在做「指纹比对」——先定义故障签名 ρ，再看观测残差落在哪个签名附近。但真正的因果判断应该是：**如果故障假设 H 为真，未来几步的观测应该长什么样？** 世界模型 `z_{t+1} ~ p_θ(z_{t+1} | z_t, a_t)` 正好提供了这个「如果」算子。对每个候选 H，用世界模型从当前后验状态出发做 N 条 rollout，比较预测观测与真实观测的似然：能让当前观测最「像真的」的假设，才是最好的归因。这把归因从「模式识别」变成「模型证据比较」。

**灵感 2（大语言模型 → 语义编译器，而非控制器）**
直觉：LLM 最擅长的不是 1kHz 力矩控制，而是把「不要把热咖啡举到孩子头顶」「遇到人不确定时先停」这类自然语言规则，编译成结构化约束；同时能根据故障文本、日志和任务描述，提出人不容易手工枚举的故障假设（如「指令歧义导致的语义错配」）。因此 LLM 的定位是**语义流的编译器与提议者**：输出必须落在一个封闭的、可测量的符号表 Σ 上，任何无法接地到传感器的谓词一律拒收。

**灵感 3（接地审计 → 让幻觉变成「可驳回的提案」）**
直觉：LLM 的幻觉无法被彻底消除，但可以被**制度性隔离**。做法是给每条 LLM 输出配一个「接地审计层 GAL」：约束必须引用 Σ 中的谓词；假设必须引用组件本体 ℋ_ont 中的机制模板；每条主张要么被世界模型的 rollout 证据支持，要么被降权/隔离。LLM 可以「大胆假设」，但只有世界模型能「小心求证」。

**灵感 4（世界模型 → 想象式证书）**
直觉：第 66 轮 C-RAS 的前缀认证是「当前状态安全」；但动作块执行后可能进入更危险的状态。世界模型可以对候选前缀 A[:k] 做最坏情况 rollout，用 STL 鲁棒度 ρ_STL 衡量未来轨迹是否满足语义约束。于是认证前缀从「一步裕度 ≥ 0」升级为「**在集成世界模型的全部采样中，未来 STL 鲁棒度 ≥ δ**」。这让证书第一次具备「前瞻可证伪性」。

**灵感 5（两灵感合流 → LWC 的分层结构）**
LWC 在 RAS 的六层之上增加语义层，但严格保持「语义流 / 实时流」分离：
1. **WMG World Model Generator**：集成潜变量世界模型，提供反事实 rollout 与认知不确定性；
2. **LSC LLM Semantic Compiler**：把任务/安全自然语言编译为封闭符号表上的 STL 约束集；
3. **CGH Counterfactual Hypothesis Generator**：LLM 在本体约束下提议结构化故障假设；
4. **CEA Counterfactual Evidence Attribution**：以反事实似然替代残差签名，输出联合后验与贝叶斯因子；
5. **GAL Grounding Audit Layer**：审计每条语言主张的接地状态，不可接地则隔离；
6. **I-CSC Imagination-based Chunk Safety Certificate**：在集成 rollout 上认证前缀；
7. **CLR Counterfactual Language Repair**：语义型故障触发澄清/修复，而非硬件降级；
8. **SMB / WSR**：语义记忆库与世界模型自修复，负责版本、回放与漂移监测。

## 1. 形式化定义（增量：定义 245–256）

- **定义 245（LWC 总览）**：`LWC = (WMG, LSC, CGH, CEA, GAL, I-CSC, CLR, SMB, WSR)`。定位：RAS 的「意图闭环」升级为「语义-反事实闭环」。不变式：LLM 推理与反事实 rollout 只在语义流；实时流只读取已编译约束、已认证前缀和缓存证书，零 token 生成、零在线学习写操作。
- **定义 246（世界模型）**：编码器 `z_t = f_enc(o_t)`；潜动力学 `z_{t+1} ~ p_θ(z_{t+1} | z_t, a_t)`；解码器 `ô_{t+1} = f_dec(z_{t+1})`。集成 `Θ = {θ_1…θ_M}`，认知不确定性 `u_epi(z,a) = Var_m[f_dec(z_{t+1}^{(m)})]`；偶然不确定性由异方差头输出。
- **定义 247（语义编译器）**：`C = LSC(P_task, P_safety, Σ, ℋ_ont)`，输出有限约束集 `C = {φ_1…φ_L}`，其中每个 φ_i 是定义在封闭符号表 Σ 上的 STL 公式；输出附带 `(prompt_hash, constraint_hash, provenance)`。
- **定义 248（封闭符号表与接地谓词）**：`Σ = {p_1…p_n}`，每个原子谓词 `p` 必须绑定一个可测量函数 `g_p: state → ℝ` 与阈值 θ_p。若 LLM 生成的谓词 `p ∉ Σ`，则 GAL 直接拒绝，不允许「发明传感器」。
- **定义 249（结构化故障假设）**：`H = (layer, mechanism, expected_signature)`，其中 `layer ∈ {geo, force, model, sensor, semantic}`，`mechanism` 取自本体模板 `ℋ_ont`。LLM 给出先验 `P_LLM(H)`，但必须经 GAL 审计。
- **定义 250（反事实证据归因）**：对每个 H，在 `z_t` 后验上采样 N 条 rollout，得到预测观测分布 `q_H(o_{t:t+k})`；模型证据 `E_H = log q_H(o_{t:t+k})`；后验
  `P(H | o, C) ∝ exp(E_H) · P_LLM(H) · P(H | history)`。
  贝叶斯因子 `BF_{ij} = exp(E_{H_i} - E_{H_j})`。
- **定义 251（接地审计）**：`g(c) ∈ {VERIFIED, PLAUSIBLE, UNGROUNDED}`。VERIFIED 需有世界模型 rollout 或日志作为见证；UNGROUNDED 的主张被隔离，其先验乘以惩罚因子 `κ_g ∈ (0,1)`，且不得进入证书。
- **定义 252（想象式前缀证书）**：`k* = max{k ≤ m_LWC}`，使得对 top-M 假设与每条集成 rollout r：
  `ρ_STL(τ_{0:k}^{(r)}, C) ≥ δ` 且 `margin_phys(τ_{0:k}^{(r)}, H) ≥ 0`；
  其中 `m_LWC = min(m_VISTA, m_emotion, m_WM)`。
- **定义 253（语义流/实时流分离）**：实时流只做「查表 + 前缀派发 + 早停」；LLM 输出以 TTL 缓存，过期即回退到上一版已认证约束，绝不在控制周期内调用 LLM。
- **定义 254（反事实语言修复）**：当 `H_semantic`（指令歧义、指代不清、约束缺失）后验超过阈值时，`CLR` 生成澄清问题 `q* = argmax_q I(φ; answer_q)`，以最小期望信息代价消除约束歧义；不执行硬件降级。
- **定义 255（语义记忆与世界模型自修复）**：`SMB` 以不可变快照保存 `(φ, provenance, version, validation_stats)`；`WSR` 监测 WM rollout 残差，若连续超阈则触发 conformal 重校准或离线重训，并冻结证书版本。
- **定义 256（J_LWC 证书）**：
  `J_LWC = (J_RAS, wm_version, conformal_q, constraint_hash, prompt_hash, attribution_evidence, grounding_status, rollout_seed_hash)`。
  `Valid ⇔ Valid(J_RAS) ∧ conformal_q ≤ q_max ∧ grounding_status = VERIFIED ∧ attribution_coverage ≥ 0.9`。

## 2. 关键算法骨架

```python
class WorldModelGenerator:
    def rollout(self, z0, actions, n=16):
        # 返回集成分支下的预测观测与认知不确定性
        samples = []
        for theta in self.ensemble:
            z = z0
            traj = []
            for a in actions:
                z = theta.dynamics(z, a)
                traj.append(theta.decode(z))
            samples.append(traj)
        return samples, epistemic_var(samples)


class LLMSemanticCompiler:
    def compile(self, task_text, safety_text, Sigma, ontology):
        raw = self.llm(task_text, safety_text, schema=STL_SCHEMA)
        # 关键：只允许引用封闭符号表 Σ 与本体 ℋ_ont
        constraints = [phi for phi in raw.constraints if grounded(phi, Sigma)]
        rejected = [phi for phi in raw.constraints if not grounded(phi, Sigma)]
        return constraints, rejected, hash(raw)


class CounterfactualAttribution:
    def attribute(self, z0, obs_window, hypotheses, wm, constraints):
        evidence = {}
        for H in hypotheses:
            acts = H.counterfactual_actions(obs_window)
            samples, u = wm.rollout(z0, acts, n=self.n_rollout)
            evidence[H] = log_likelihood(samples, obs_window) - self.beta * u
        post = softmax({H: e + log(self.prior[H]) for H, e in evidence.items()})
        return post, evidence


class ImaginationCertificate:
    def certify(self, A, post, wm, constraints, delta):
        top = top_k(post, self.M)
        k_best = 0
        for k in range(1, min(len(A), self.m_lwc) + 1):
            ok = True
            for H in top:
                samples, _ = wm.rollout(self.z0, A[:k], n=self.R)
                for traj in samples:
                    if stl_robustness(traj, constraints) < delta:
                        ok = False; break
                    if physical_margin(traj, H) < 0:
                        ok = False; break
                if not ok: break
            if ok: k_best = k
            else: break
        return k_best


def LWC_round(M, obs):
    # 实时层：RAS/VISTA 前向 + 缓存查表
    face_gate = M.er.recognize(obs.img)
    A = M.vista.ach.propose(M.x_prime, H=M.vista.H)

    # 语义层（可异步、可在上一控制周期预计算）
    C, rejected, chash = M.lsc.compile(M.task_text, M.safety_text,
                                        M.Sigma, M.H_ont)
    H_set = M.cgh.propose(obs.log, C, M.H_ont)
    H_set = M.gal.audit(H_set, evidence=M.wm_recent)

    joint_post, evidence = M.cea.attribute(M.z0, obs.window, H_set,
                                           M.wmg, C)
    k_lwc = M.icsc.certify(A, joint_post, M.wmg, C, M.delta)

    if joint_post.get('H_semantic', 0) > M.tau_semantic:
        q = M.clr.propose_clarification(C, joint_post)
        return {'action': 'ASK', 'question': q, 'k': 0}

    tau = M.vista.pi_sigma.prefix_dispatch(A[:k_lwc])
    return {'action': 'EXEC', 'tau': tau, 'k': k_lwc,
            'post': joint_post, 'J': M.make_certificate(chash, evidence)}
```

## 3. 推导

**引理 11（反事实归因的可分性）** 若对任意一对假设 `H_i, H_j`，其 rollout 观测分布的期望对数似然差 `Δ_ij ≥ d`，且每条假设采样 N 条独立 rollout，则后验误判概率随 N 指数下降，错误上界形如 `(M-1)·exp(-N·d²/8)`。直觉：世界模型把「假设差异」变成了「可重复的预测差异」，采样越多，错误假设越难蒙混过关。

**引理 12（世界模型误差的 conformal 兜底）** 用离线校准集构造非一致性分数 `s = ||ô - o||`，取 `q = Quantile_{1-α}(s)`。若在线 rollout 与校准集可交换，则真实轨迹超出预测包络的概率 ≤ α。于是 I-CSC 的 `margin_phys` 可以扣除 `q`，把「想象安全」变成「带统计保证的想象安全」。

**定理 11（LWC 端到端安全）** 在 A92–A96 下，执行前缀违反语义约束的概率满足
`P(unsafe) ≤ α_wm + α_attr + α_sem + α_chunk`，
其中 `α_wm` 为 conformal 覆盖率、`α_attr` 为 top-M 假设未覆盖真假设的概率、`α_sem` 为 GAL 漏检的语义错误率、`α_chunk` 为前缀提前终止误差。只要四者均可独立标定，LWC 的安全性就是可审计的乘积式保证。

**命题 1（LLM 不进入实时回路）** 设 LLM 单次推理时延为 `T_llm`，控制周期为 `T_c`，缓存命中率为 h。则 LWC 实时回路的最坏时延不包含 `T_llm`，仅为 `O(k·M·R)` 的证书查找与 rollout 缓存读取；当缓存未命中时回退到上一版已认证约束，控制不中断。

**命题 2（接地审计的保守性）** 若 GAL 只接受 Σ 上的谓词，则 LLM 不能引入不可测量的安全约束；其代价是可能漏掉真实但未建模的风险（漏检而非虚构），因此 `α_sem` 应由「约束覆盖率实验」而非「约束条数」来评估。

## 6. 本轮最大风险

**一句话**：LWC 的最大风险不是「LLM 单独幻觉」，而是「**LLM 的语义先验与世界模型的反事实证据相互确认（double hallucination）**」——LLM 提议了一个错误但自洽的故障假设，世界模型又因训练分布偏差在想象中「证实」了它，于是系统在想象中安全、在现实中违规；这是本轮所有理论依赖的核心假设：**世界模型的 rollout 足够校准，且 LLM 的语义先验不会系统性地引导证据搜索方向**。

**次级风险与缓解**：
1. **想象-现实鸿沟**：用 conformal + 真实残差在线校准，想象裕度扣除 `q`；
2. **LLM 提示注入**：GAL 只接受封闭符号表与白名单本体，安全约束不可由任务文本覆盖；
3. **世界模型长程漂移**：限制 `m_WM`，用多步 bootstrap 与集成分歧早停；
4. **语义漏检**：用覆盖率实验度量 `α_sem`，并保留人工红队约束库；
5. **算力成本**：WMG rollout 与 LLM 都在语义流异步执行，实时流只读缓存。

## 2. 形式化定义（完整版）

**定义 245（LWC 总览）** LWC 是 RAS 的「意图闭环」升级为「语义-反事实闭环」：
```
LWC = (WMG, LSC, CGH, CEA, GAL, I-CSC, CLR, SMB, WSR)
```
不变式：LLM 推理、约束编译、反事实 rollout、接地审计、证书构建只在语义流；实时流只读取已编译约束、已认证前缀与缓存证书，零 token 生成、零在线学习写操作。

**定义 246（世界模型）** 编码器 `z_t = f_enc(o_t)`，潜动力学 `z_{t+1} ~ p_θ(z_{t+1} | z_t, a_t)`，解码器 `ô_{t+1} = f_dec(z_{t+1})`。集成 `Θ = {θ_1…θ_M}`，认知不确定性 `u_epi(z,a) = Var_m[f_dec(z_{t+1}^{(m)})]`；偶然不确定性由异方差输出头给出。世界模型同时输出 conformal 包络 `[ô-q, ô+q]`。

**定义 247（语义编译器）** `C = LSC(P_task, P_safety, Σ, ℋ_ont)`，输出有限约束集 `C = {φ_1…φ_L}`，每个 φ_i 是定义在封闭符号表 Σ 上的 STL 公式。输出附带 `(prompt_hash, constraint_hash, provenance)`，并进入 SMB 版本管理。

**定义 248（封闭符号表与接地谓词）** `Σ = {p_1…p_n}`，每个原子谓词 `p` 必须绑定可测函数 `g_p: state → ℝ` 与阈值 θ_p。若 `p ∉ Σ`，GAL 直接拒绝：LLM 不允许「发明传感器」或「引入不可测的安全概念」。

**定义 249（结构化故障假设）** `H = (layer, mechanism, expected_signature)`，其中 `layer ∈ {geo, force, model, sensor, semantic}`，`mechanism` 取自本体模板 `ℋ_ont`。LLM 输出先验 `P_LLM(H)`，但必须经 GAL 审计；`H_wm_drift` 为世界模型失效假设。

**定义 250（反事实证据归因）** 对每个 H，在 `z_t` 后验上采样 N 条 rollout，得到预测观测分布 `q_H(o_{t:t+k})`，模型证据 `E_H = log q_H(o_{t:t+k})`。联合后验：
```
P(H | o, C) ∝ exp(E_H) · P_LLM(H) · P(H | history)
BF_ij = exp(E_Hi - E_Hj)
```

**定义 251（接地审计）** `g(c) ∈ {VERIFIED, PLAUSIBLE, UNGROUNDED}`。VERIFIED 需有世界模型 rollout 或日志见证；PLAUSIBLE 仅可参与先验；UNGROUNDED 主张被隔离，其先验乘以 `κ_g ∈ (0,1)`，且不得进入证书。

**定义 252（想象式前缀证书）** 认证前缀
```
k*_LWC = max{k ≤ m_LWC}，使得 ∀H ∈ top-M(post), ∀r ∈ 集成 rollout:
  ρ_STL(τ_{0:k}^{(r)}, C) ≥ δ  ∧  margin_phys(τ_{0:k}^{(r)}, H) ≥ 0
```
其中 `margin_phys` 已扣除 conformal 包络 `q`。

**定义 253（语义流/实时流分离）** 实时流只做「查表 + 前缀派发 + 早停」；LLM 输出以 TTL 缓存，过期即回退到上一版已认证约束，绝不在控制周期内调用 LLM。

**定义 254（反事实语言修复）** 当 `P(H_semantic | o) > τ_semantic`（指令歧义、指代不清、约束缺失）时，CLR 生成澄清问题
```
q* = argmax_q I(φ; answer_q)
```
以最小期望信息代价消除约束歧义；语义故障不触发硬件降级。

**定义 255（语义记忆与世界模型自修复）** SMB 以不可变快照保存 `(φ, provenance, version, validation_stats)`。WSR 监测 WM rollout 残差，若连续超阈则触发 conformal 重校准或离线重训，并冻结当前证书版本。

**定义 256（J_LWC 证书）**
```
J_LWC = (J_RAS, wm_version, conformal_q, constraint_hash, prompt_hash,
         attribution_evidence, grounding_status, rollout_seed_hash)
Valid ⇔ Valid(J_RAS) ∧ conformal_q ≤ q_max
        ∧ grounding_status = VERIFIED ∧ attribution_coverage ≥ 0.9
```

```python
class WorldModelGenerator:
    def rollout(self, z0, actions, n=16):
        samples = []
        for theta in self.ensemble:
            z, traj = z0, []
            for a in actions:
                z = theta.dynamics(z, a)
                traj.append(theta.decode(z))
            samples.append(traj)
        return samples, epistemic_var(samples)

    def conformal_envelope(self, err_scores):
        return quantile(err_scores, self.alpha)


class LLMSemanticCompiler:
    def compile(self, task_text, safety_text, Sigma, ontology):
        raw = self.llm(task_text, safety_text, schema=STL_SCHEMA)
        kept = [phi for phi in raw.constraints if grounded(phi, Sigma)]
        rejected = [phi for phi in raw.constraints if not grounded(phi, Sigma)]
        return kept, rejected, stable_hash(raw)


class CounterfactualHypothesisGenerator:
    def propose(self, log_text, constraints, ontology):
        raw = self.llm(log_text, constraints, schema=HYPOTHESIS_SCHEMA)
        return [H for H in raw.hypotheses
                if H.layer in LAYERS and H.mechanism in ontology]


class GroundingAuditLayer:
    def audit(self, claims, evidence):
        out = {}
        for c in claims:
            if c.predicate not in self.Sigma and c.kind == 'constraint':
                out[c] = 'UNGROUNDED'
            elif has_witness(c, evidence):
                out[c] = 'VERIFIED'
            else:
                out[c] = 'PLAUSIBLE'
        return out

    def penalize(self, prior, status):
        return prior * (1.0 if status == 'VERIFIED'
                        else 0.8 if status == 'PLAUSIBLE' else 0.2)


class CounterfactualAttribution:
    def attribute(self, z0, obs_window, hypotheses, wm, constraints,
                  prior, n_rollout=32):
        evidence = {}
        for H in hypotheses:
            acts = H.counterfactual_actions(obs_window)
            samples, u = wm.rollout(z0, acts, n=n_rollout)
            evidence[H] = log_likelihood(samples, obs_window) - self.beta * u
        logp = {H: evidence[H] + log(prior[H]) for H in hypotheses}
        return softmax(logp), evidence


class ImaginationCertificate:
    def certify(self, A, post, wm, constraints, delta, z0, m_lwc):
        top = top_k(post, self.M)
        k_best = 0
        for k in range(1, min(len(A), m_lwc) + 1):
            ok = True
            for H in top:
                samples, _ = wm.rollout(z0, A[:k], n=self.R)
                for traj in samples:
                    if stl_robustness(traj, constraints) < delta:
                        ok = False; break
                    if physical_margin(traj, H) - wm.conformal_q < 0:
                        ok = False; break
                if not ok: break
            if ok:
                k_best = k
            else:
                break
        return k_best


def LWC_round(M, obs):
    # ---- 实时层（不调用 LLM）----
    face_gate = M.er.recognize(obs.img)
    A = M.vista.ach.propose(M.x_prime, H=M.vista.H)

    # ---- 语义层（异步/预计算）----
    C, rejected, chash = M.lsc.compile(M.task_text, M.safety_text,
                                        M.Sigma, M.H_ont)
    H_set = M.cgh.propose(obs.log, C, M.H_ont)
    status = M.gal.audit(H_set, evidence=M.wm_recent)
    prior = {H: M.gal.penalize(M.prior[H], status[H]) for H in H_set}

    post, evidence = M.cea.attribute(M.z0, obs.window, H_set,
                                     M.wmg, C, prior)
    k_lwc = M.icsc.certify(A, post, M.wmg, C, M.delta,
                           M.z0, M.m_lwc)

    # ---- 语义故障：先澄清，不降级 ----
    if post.get('H_semantic', 0.0) > M.tau_semantic:
        q = M.clr.propose_clarification(C, post)
        return {'action': 'ASK', 'question': q, 'k': 0}

    tau = M.vista.pi_sigma.prefix_dispatch(A[:k_lwc])
    return {'action': 'EXEC', 'tau': tau, 'k': k_lwc,
            'post': post, 'J': M.make_certificate(chash, evidence, status)}


class CounterfactualLanguageRepair:
    def propose_clarification(self, C, post):
        candidates = self.generate_questions(C)
        return max(candidates,
                   key=lambda q: self.expected_info_gain(q, C, post))
```

## 4. 推导

**引理 11（反事实归因的可分性）** 设假设 `H_i` 与 `H_j` 的 rollout 观测分布满足期望对数似然差 `Δ_ij = E[log q_Hi - log q_Hj] ≥ d`，且每条假设采样 N 条独立 rollout。由 Chernoff 界，后验误判概率满足
```
P(H_j 被误判为 H_i) ≤ exp(-N·d²/8)
```
对 |H| 个假设取并集界，错误率 ≤ `(|H|-1)·exp(-N·d²/8)`。直觉：世界模型把「假设差异」转化为「可重复的预测差异」，采样越多，错误假设越难蒙混。

**引理 12（世界模型误差的 conformal 兜底）** 在离线校准集上取非一致性分数 `s = ||ô - o||`，令 `q = Quantile_{1-α}(s)`。若在线轨迹与校准集可交换，则
```
P(||ô - o|| > q) ≤ α
```
因此 I-CSC 中把物理裕度替换为 `margin_phys - q`，可把「想象安全」升级为「带统计覆盖保证的想象安全」。

**定理 11（LWC 端到端安全）** 在 A92–A96（WM 覆盖、GAL 漏检率、top-M 覆盖、前缀终止误差）下，执行前缀违反语义或物理约束的概率满足
```
P(unsafe) ≤ α_wm + α_attr + α_sem + α_chunk
```
其中 `α_wm` 为 conformal 覆盖率，`α_attr` 为 top-M 未覆盖真假设的概率，`α_sem` 为 GAL 漏检的语义错误率，`α_chunk` 为前缀提前终止误差。四项可独立标定，因此 LWC 的安全性是可审计的乘积式保证，而非单一端到端经验值。

**命题 1（LLM 不进入实时回路）** 设 LLM 单次推理时延为 `T_llm`，控制周期为 `T_c`，缓存命中率为 h。LWC 实时回路最坏时延不包含 `T_llm`，仅为 `O(k·M·R)` 的证书查表；缓存未命中时回退到上一版已认证约束，控制不中断。

**命题 2（接地审计的保守性）** 若 GAL 只接受 Σ 上的谓词，则 LLM 不能引入不可测量的安全约束。其代价是可能漏掉真实但未建模的风险（漏检而非虚构），因此 `α_sem` 必须由「约束覆盖率实验」度量，而不能用「约束条数」自证安全。

**命题 3（语义修复优于降级）** 若语义故障的后验 `p_s > τ_semantic`，则执行硬件降级会以 `p_s` 的概率损失正常任务收益，而 CLR 的期望代价为 `E[T_clarify]`。当澄清成本低于误降级代价时，`ASK` 严格优于 `EXEC-DEGRADED`。这为「语义故障先问、不先降」提供了决策论依据。

## 7. 本轮最大风险

**一句话**：LWC 的最大风险不是「LLM 单独幻觉」，而是「**LLM 的语义先验与世界模型的反事实证据相互确认（double hallucination）**」——LLM 提议了一个错误但自洽的故障假设，世界模型又因训练分布偏差在想象中「证实」了它，于是系统在想象中安全、在现实中违规；这是本轮所有理论依赖的核心假设：**世界模型的 rollout 足够校准，且 LLM 的语义先验不会系统性地引导证据搜索方向**。

**次级风险与缓解**：
1. **想象-现实鸿沟**：用 conformal + 真实残差在线校准，想象裕度扣除 `q`；
2. **LLM 提示注入**：GAL 只接受封闭符号表与白名单本体，安全约束不可由任务文本覆盖；
3. **世界模型长程漂移**：限制 `m_WM`，用多步 bootstrap 与集成分歧早停；
4. **语义漏检**：用覆盖率实验度量 `α_sem`，并保留人工红队约束库；
5. **算力成本**：WMG rollout 与 LLM 都在语义流异步执行，实时流只读缓存；
6. **过度保守**：想象式证书可能把 `k*` 压得过短，需用 E254 监控 `k*` 与任务吞吐的折中。
