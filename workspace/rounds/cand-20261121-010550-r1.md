# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「嵌入式系统」×「数据标注」）

> **基线**：上一轮（灵感「大语言模型」×「机器人」×「智能体」）MetricVoiceGauge-NCD-HUTDH-v17（定义 657–674；引理 137–142；实验 E691–E710）。
> 本轮纪律：**先把认证管线做成硬实时外设，再把校准集做成有溯源的数据资产**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v13–v8 全部组件与历轮不变式原样保留。六个新组件——RTB（实时预算认证器）、DCA（确定性证书算术）、SMB（密封信箱桥）、ALC（主动标注策展器）、LPC（标签溯源证书）、CLA（金丝雀标签审计器）——一律以**中立元**接入 v17 语言层，失效即严格退回 v17，再沿 v17→v16→…→v6 退化链退回。本轮只做三件事：把"异步不阻塞"改写成**可证 WCET 的硬实时预算**、把"共形校准"改写成**带标签噪声与选择偏差修正的加权共形**、把"隔离靠纪律"改写成**硬件单向信箱**。

## 0. 直觉与动机

**灵感 1（嵌入式系统 → 认证管线是"硬实时外设"，不是"后台脚本"）**
直觉：v17 用"异步 + 典型 ≤12ms + LLM 完全在路径外"说服自己，但这是**平均性能叙事**，不是嵌入式系统的**可预测性叙事**。真实控制器上，S2C 的 O(T·|A|)、PSV 的 O(T·|NC|)、HCG 的语义打分仍跑在控制环里，浮点在不同编译器/板卡上结果不一致，LLM 与嵌入服务还和控制器共享内存与总线。嵌入式第一性原理是固定的四步：**先证 WCET，再证内存上界，再证确定性，最后证隔离**。核心新增：**实时预算认证器（RTB）**给每个阶段静态 WCET/内存预算并做准入控制；**确定性证书算术（DCA）**用定点 + 外向舍入把缝体积与包含判定做成逐位可复现；**密封信箱桥（SMB）**把 LLM/嵌入服务搬到伴生处理器，只留一条单向、MPU 保护、定长、CRC 校验的信箱——P28 从"代码评审承诺"升级为**硬件性质**。关键反直觉点：**给认证管线加约束反而让它更快更稳**——定点化消除浮点尾延迟，静态预算消除动态分配/GC 抖动，单向信箱消除跨核争用；"可预测的 8ms"严格优于"平均 3ms、p99 40ms"。

**灵感 2（数据标注 → 校准集是"被标注的数据资产"，不是"免费的真值"）**
直觉：v17 的引理 138 把校准标签当成真值，但每一条"该计划有效/无效"的标签都来自结局日志或 verifier LLM，**有噪声、有偏、且昂贵**。共形保证不是免费的，它**条件于标签质量**；标签错了，α 就是幻觉出来的 α。核心新增：**标签溯源证书（LPC）**给每条标签记来源、信任层级、认证噪声上界与哈希链，只有达到信任阈值的标签才进校准集；**主动标注策展器（ALC）**在有限标注预算下挑选"最值钱"的计划去标注（verifier 间分歧 + 不确定度 + 覆盖空洞），并用分层权重修正选择偏差；**金丝雀标签审计器（CLA）**注入已知真值的金丝雀计划，序贯检验标注管线是否漂移/被投毒。关键反直觉点：**标注不是越多越好，而是越"分层"越好**——随机标注把预算浪费在已确定区域；主动标注专挑分歧区与覆盖空洞（正是 v17 最大风险所指的"校准集从未覆盖的缝隙组合"），用更少标签换更窄置信带；而且**修正标签噪声可以合法地重新准入 v17 误拒的计划**，因为 v17 的阈值本身被噪声污染，真正该锚定的安全底座是 v16 而非 v17。

**两者如何统一**
v17 回答"哪些语言计划能被安全编译与调度"（`Exec_v17`）；v18 回答"在**固定内存、固定 WCET、确定性算术、硬件单向隔离**的嵌入式约束下，**用带溯源与噪声界的标注数据**，哪些计划能被认证为可执行"（`Exec_v18`）。统一视角：v17 把语言层当成"跑在通用机上的软件"，v18 把它当成"焊在实时控制系统里的认证外设 + 一套需要治理的标注数据"。共享状态 `ζ_emb=(B_tick, m*, h*, plan_cache, τ_fresh, q̂_w, L_cal, audit_state, wcet_state, mode_emb)`。**RTB 回答"这一帧有没有预算做认证"，DCA 回答"这个判定在所有板卡上是否同一个答案"，SMB 回答"语言进程能不能碰到控制内存"，ALC 回答"下一个标注预算花在哪"，LPC 回答"这条标签值多少信任、噪声多大"，CLA 回答"标注管线还干净吗"**。六者不是六个补丁，而是"预算—确定性—隔离—选样—溯源—审计"的嵌入式数据飞轮。

## 1. 研究问题（轮次升级版）

- **Q1（认证管线的硬实时预算）**：如何为 S2C/HCG/PSV/DCA 给出可复核的静态 WCET 上界与内存上界？准入控制如何在"突发 K 个计划请求"下仍保证 50Hz 控制任务零截止期错失？中断延迟、共享总线争用与缓存效应如何计入 WCET？
- **Q2（证书算术的确定性与保守度）**：定点格式 Q(i,f) 与外向舍入如何保证接受判定与运行时复验逐位一致、跨板卡可复现？区间包络 `[lo,hi]` 的保守膨胀在高维缝上会不会让接受率塌缩？如何度量并报告"保守度税"？
- **Q3（噪声与选择偏差下的共形有效性）**：标签噪声上界 η 与信任层级如何认证并传播到 `q̂_w`？主动标注造成的非均匀选样破坏可交换性后，分层/逆倾向加权能否恢复 `≤α+η` 的覆盖？修正标签后"重新准入 v17 误拒计划"的边界在哪里？
- **Q4（标注审计与最坏投毒）**：金丝雀应如何嵌入而不被标注者识别？序贯检验的检出延迟/误报如何权衡？检测到污染后冻结校准的活性代价上界是多少？在 SMB 单通道下如何保证审计结论本身不可被 LLM 侧伪造？

## 2. 设计原则（在 P28–P30 基础上新增 P31–P33）

**P31 认证管线硬实时律（Certified Pipeline as a Hard Real-Time Task）**
语言认证管线是有静态 WCET 上界 `C = Σ_s WCET_s + C_isr`、固定内存 `M ≤ M_budget`、固定优先级（低于控制任务）的周期任务；准入控制限制并发评估数 `K` 与每周期预算 `B_rt`；关键路径禁止动态分配、禁止浮点、禁止无界循环。仅当 `C ≤ B_rt` 且响应时间分析满足控制任务截止期时才允许启用 v18 增强。

**P32 证书确定性算术律（Deterministic Certificate Arithmetic）**
所有证书比较（缝体积、包含、分数、分位数）在 `Q(i,f)` 定点上做**外向舍入**，得到包络 `true ∈ [lo,hi]`；接受只在 `lo ≥ margin` 时成立（保守充分），运行时包含只在"确定在内"时通过、落在不确定带即 fail-safe 回退。以此保证**同输入在任何合规板卡/编译器上判定逐位一致**，并把保守度 `hi−lo` 作为可测量指标报告，而非隐式漂移。

**P33 标注真值分层律（Annotated Truth is Tiered and Bounded）**
每条校准标签携带溯源 `ℓ=(source, tier, η, chain, agree)`，`tier ∈ T0⊂T1⊂T2⊂T3`；只有 `tier ≥ τ_tier` 且哈希链校验通过的标签进入校准；标签只能改变 `q̂_w` 与 `L_cal`，**永远不能直接授权执行、不能修改 Anchors/NC/SC/margin**；主动选样必须记录选择倾向 `e(x)` 并加权；金丝雀审计失败即冻结校准并退回最近一次已审计分位数。

## 3. 与基线的接口（如何退化）

- RTB 失效（WCET 不可证/超预算）⇒ 关闭 v18 增强，退回 v17 异步非阻塞模式（仅保留实测 p99，不宣称 WCET）；
- DCA 失效（定点库不可用）⇒ 退回 v17 浮点算术，但判定标记"不可复现"并追加保守 margin；
- SMB 失效（伴生处理器掉线/CRC 连续错误）⇒ LLM 离线，计划缓存按 TTL → v16 默认；
- ALC 失效（预算调度器崩溃）⇒ 退化为均匀随机选样（仍有偏但可加权），共形仍有效但样本效率下降；
- LPC 失效（溯源链损坏）⇒ 全部标签降为 T0，只信运行时结局标签，`q̂_w` 取保守上界；
- CLA 失效（金丝雀被识别/审计停摆）⇒ 冻结校准于最近已审计值，不再滑动重校准；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v6 退化链退回；
- **安全继承**：RTB 只裁时间窗、DCA 只保守化判定、SMB 只暴露单向通道、ALC 只选样、LPC 只改校准、CLA 只审计；六者写集与锚/证书表**不相交**。故对任意标注内容（含投毒），`Exec_v18 ⊆ Exec_v16`（引理 146）。**注意本轮刻意不宣称 `Exec_v18 ⊆ Exec_v17`**：修正被噪声污染的阈值本应把 v17 误拒的计划重新准入，真正的安全底座是 v16，v17 只是退化回退点。

## 4. 预期贡献

1. **认证管线外设化**：首次把"LLM 不在实时路径"从经验叙事升级为 WCET 可证、内存有界、优先级可分析的硬实时任务，并给出准入控制下的零截止期错失条件；
2. **确定性证书算术**：把缝体积/包含判定做成跨板卡逐位可复现的外向舍入定点运算，给出保守度税的显式度量，堵住"离线通过、在线因浮点误差误判"的隐性失效；
3. **标签溯源共形**：把校准集从"免费真值"改写为"带信任层级、噪声上界与哈希链的数据资产"，给出主动选样 + 分层加权下 `≤α+η` 的覆盖界；
4. **金丝雀标注审计**：用已知真值金丝雀 + SPRT 给出投毒检测的样本复杂度与误报界，使"校准集被污染"从不可见风险变为可检测事件；
5. **反直觉的修正性再准入**：证明修正标签噪声可在**不削弱** v16 安全底座的前提下，安全地重新准入 v17 因噪声而误拒的计划，纠正"越保守越安全"的误区；
6. **嵌入式数据飞轮六层分离**：v16 管"允许什么行为"，v17 管"哪些语言计划被编译调度"，v18 管"在硬实时与标注治理下哪些计划被认证"，用 `Exec_v18⊆Exec_v16` 钉住安全底座；E711–E730 覆盖确定性、WCET、隔离、主动标注、噪声共形、审计、再准入、端到端与消融。

## 5. 本轮最大风险

**一句话**：v18 的全部有效性都压在"标注质量证书"上——信任层级、噪声上界 η 与选择倾向 `e(x)` 本身由**正在被审计的同一批 verifier/标注模型**估计，一旦标注者、审计者与验证者发生共模失效（同一系统性偏差同时污染标签、金丝雀与权重），`q̂_w` 会给出一个**看起来很严谨、实际无效的 α 保证**，并在"最有把握"的地方自信地重新准入错误计划——即"审计证书本身不可审计"的循环信任塌缩。

## 1. 关键算法骨架

```python
# IP-415 Real-Time Budget Certifier：静态预算 + 准入 + 响应时间分析
class RealTimeBudgetCertifier:
    def __init__(self, wcet, period, budget_frac=0.20, kmax=1, isr_overhead=0.2):
        self.wcet = wcet                  # {'s2c':, 'hcg':, 'psv':, 'dca':}
        self.P = period                   # 控制周期（如 20ms）
        self.B = budget_frac * period     # 认证预算
        self.kmax = kmax
        self.c_isr = isr_overhead
        self.inflight = 0

    def total_wcet(self):
        return sum(self.wcet.values()) + self.c_isr

    def admit(self):
        if self.total_wcet() > self.B:
            return False                  # 预算不足以认证：不启用增强
        if self.inflight >= self.kmax:
            return False                  # 准入：拒新，保控制环
        self.inflight += 1
        return True

    def done(self):
        self.inflight = max(0, self.inflight - 1)

    def certify(self, control_wcet, higher_prio_interf):
        # 固定优先级响应时间分析：R = C_control + Σ interference
        R = control_wcet + higher_prio_interf + self.total_wcet()
        return R <= self.P, R


# IP-416 Deterministic Certificate Arithmetic：外向舍入 + 区间包络
class DeterministicCertificateArithmetic:
    def __init__(self, fmt):             # fmt = (i, f) 整数位/小数位
        self.i, self.f = fmt

    def add(self, a, b):                 # 外向舍入：lo 向下、hi 向上
        return (down(a[0] + b[0]), up(a[1] + b[1]))

    def mul(self, a, b):
        return (down(a[0] * b[0]), up(a[1] * b[1]))

    def volume_interval(self, sc):
        lo, hi = self._measure(sc)
        return (down(lo), up(hi))        # true ∈ [lo, hi]

    def accept_seam(self, sc, margin):
        lo, hi = self.volume_interval(sc)
        return (lo >= margin), (lo, hi), (hi - lo)   # 保守充分 + 保守度税

    def contains(self, sc, x):
        # 确定在内→True；确定在外/不确定带→False（fail-safe 回退）
        inner, outer = self._enclosures(sc)
        if outer.definitely_contains(x):
            return True
        return False


# IP-417 Sealed Mailbox Bridge：单向、MPU、CRC、定长
class SealedMailboxBridge:
    FRAME_MAX = 64
    def __init__(self, seq_checker):
        self.seq = seq_checker
        self.last = 0

    def send(self, plan_bytes, now):
        assert len(plan_bytes) <= self.FRAME_MAX
        frame = pack(seq=self.last + 1, crc=crc32(plan_bytes),
                     ts=now, payload=plan_bytes)
        mpu_write_ring(self.tx_ring, frame)      # LLM 侧只能写 tx，不能读控制内存
        self.last += 1

    def recv(self):
        frame = mpu_read_ring(self.rx_ring)      # 控制器侧读，LLM 侧无写权限
        if frame is None:
            return None
        if crc32(frame.payload) != frame.crc:
            self.errors += 1
            return None
        if not self.seq.accept(frame.seq):       # 单调防重放/乱序
            return None
        return unpack(frame)


# IP-418 Active Label Curator：预算内主动选样
class ActiveLabelCurator:
    def __init__(self, budget, annotator, coverage_map, propensity_model):
        self.budget = budget
        self.annotator = annotator
        self.cov = coverage_map
        self.e = propensity_model

    def acquisition_score(self, plan, rec):
        unc = rec.uncertainty                 # HCG 分数接近 q̂ 的程度
        dis = rec.verifier_disagreement       # 多验证器分歧
        gap = self.cov.coverage_gap(rec.x)    # 覆盖空洞（v17 缝隙风险）
        return self.w[0] * unc + self.w[1] * dis + self.w[2] * gap

    def select(self, pool):
        scored = [(self.acquisition_score(p, r), p, r) for p, r in pool]
        chosen = [p for _, p, _ in sorted(scored, key=lambda z: -z[0])[:self.budget]]
        return chosen

    def propensity(self, x):
        return max(self.e(x), 1e-3)           # e(x) 用于逆倾向加权


# IP-419 Label Provenance Certificate：溯源 + 加权共形
class LabelProvenanceCertificate:
    def __init__(self, tau_tier=2, alpha=0.05, hash_ok=None):
        self.tau = tau_tier
        self.alpha = alpha
        self.hash_ok = hash_ok or (lambda r: True)

    def certify(self, rec):
        # 生成/校验溯源记录，返回 (tier, eta, chain_valid)
        tier = self._tier(rec.source, rec.agree)
        eta = self._noise_bound(rec.source, rec.agree)
        return tier, eta, self.hash_ok(rec)

    def weighted_quantile(self, L_cal, rho):
        kept = [r for r in L_cal
                if r.tier >= self.tau and r.chain_valid]
        if not kept:
            return float('inf')               # 无可信标签：全拒（保守）
        scores = [r.score for r in kept]
        weights = [rho / max(r.propensity, 1e-3) for r in kept]  # 逆倾向/分层
        return weighted_quantile(scores, weights, 1 - self.alpha)

    def eta_total(self, L_cal):
        return max((r.eta for r in L_cal if r.tier >= self.tau), default=1.0)


# IP-420 Canary Label Auditor：金丝雀 + SPRT
class CanaryLabelAuditor:
    def __init__(self, canaries, p0=0.02, p1=0.10, alpha_a=0.01, beta_a=0.01):
        self.canaries = {c.id: c for c in canaries}
        self.p0, self.p1 = p0, p1
        self.A = math.log((1 - beta_a) / alpha_a)
        self.Bnd = math.log(beta_a / (1 - alpha_a))
        self.llr = 0.0
        self.lam = math.log(p1 / p0)
        self.lam0 = math.log((1 - p1) / (1 - p0))

    def observe(self, labeled_batch):
        for r in labeled_batch:
            c = self.canaries.get(r.canary_id)
            if c is None:
                continue
            wrong = (r.label != c.y)
            self.llr += (self.lam if wrong else self.lam0)
        if self.llr >= self.A:
            return 'FREEZE'
        if self.llr <= self.Bnd:
            self.llr = 0.0
            return 'OK'
        return 'OK'
```

## 2. 推导

**引理 143（定点证书的保守一致性）** 设 DCA 对所有证书量以 `Q(i,f)` 外向舍入编码，输出包络 `[v_lo,v_hi]` 满足 `v_true ∈ [v_lo,v_hi]`；接受规则为 `v_lo ≥ margin`，运行时包含判定为"确定在内才 PASS，不确定带 FAIL-SAFE"。则：(a) 任何被接受的缝满足真实 `vol ≥ margin`（可靠性）；(b) 预验与运行时复验在任意合规板卡/编译器上逐位一致（可复现性）；(c) 不存在"离线通过、在线仅因浮点误差被判失败"的伪失败，运行时失败必对应真实越界或保守带内。证明：外向舍入保证包络单调包含（每一步 `[a_lo,a_hi] ⊇ a_true`，运算后仍包络真实结果）；`v_lo ≥ margin ⇒ v_true ≥ v_lo ≥ margin`；两处判定使用同一确定性函数、同一 `Q(i,f)`，故位级相同；不确定带一律 fail-safe，不会把"真在外"误判为在内。∎ 推论：**确定性不是免费的，其价格是 `cons=v_hi−v_lo`；只要报告并预算这笔保守度税，可靠性就不再依赖运行时舍入模式**。

**引理 144（认证管线硬实时预算保持）** 设认证管线为静态 WCET `C=Σ WCET_s+C_isr`、固定内存 `M≤M_budget` 的周期任务，优先级低于控制任务，准入控制保证并发评估 `≤K`；则控制任务响应时间 `R_control = C_control + C_interf + C`（`C_interf` 为更高优先级干扰），当 `R_control ≤ P` 时控制环截止期零错失，且与 LLM 推理延迟、件生处理器负载无关。证明：固定优先级响应时间分析（Liu–Layland）给出上界；认证管线只以 `C` 干扰控制任务一次/周期；准入控制把突发请求排队在下一周期，不改变单周期干扰上界；静态内存消除动态分配与 GC 抖动。∎ 推论：**"LLM 不在关键路径"从经验观测升级为可证条件 `C ≤ B_rt`；一旦预算不成立，系统必须退回 v17，而不是相信"通常很快"**。

**引理 145（溯源分层 + 加权主动标注的共形有效性）** 设校准记录由策略 `π_ann` 以倾向 `e(x)` 选中，标签在通过 `tier ≥ τ_tier` 与哈希链校验后保留，标签为真的概率至少 `1−η`，且采用逆倾向/分层权重 `w(x)=1/e(x)` 的加权分位数 `q̂_w`。则在加权可交换性成立时，`P(接受无效计划 | 标签通过溯源) ≤ α + η`。证明：加权共形秩论证给出 `P(s_new > q̂_w) ≤ α`（权重将选样分布还原到目标分布）；对标签翻转事件用并集界，翻转概率 `≤ η`，该事件下至多额外一次错误接受，故总上界 `α+η`。∎ 推论：**提高标签质量（η↓）会收紧保证，并在固定 α 下允许更高的 `q̂_w`——即修正标注可以合法地提高活性**。

**引理 146（标注不可改写证书格，安全底座锚定 v16）** ALC 只选择标注样本、LPC 只改变 `L_cal` 与 `q̂_w`、CLA 只做审计与冻结、RTB 只裁时间窗、DCA 只保守化判定、SMB 只暴露单向通道；六者写集与 `Anchors/NC/SC/margin` 表不相交，且 `q̂_w` 只作用于 HCG 的接受过滤。则对任意标注内容（含对抗投毒），`Exec_v18 ⊆ Exec_v16`。证明：S2C 值域仍含于 v16 认证锚集（v17 引理 137），SC 定义与 margin 未被任何新模块修改；HCG 只做接受/拒绝过滤，`q̂_w` 变化只改变过滤阈值而不新增可编译节点；SMB 单向且 CRC/单调校验阻断越权写入；RTB/DCA 只移除时间窗与保守化判定。故 v18 不能产生 v16 之外的动作。∎ 推论：**`Exec_v18 ⊆ Exec_v16` 是硬底座；`Exec_v18 ⊆ Exec_v17` 本轮不成立也不应成立——v17 的 `q̂` 被噪声污染，可能误拒合法计划，修正性再准入是特性而非漏洞**。

**引理 147（金丝雀审计的投毒检测下界）** 设金丝雀标签真值对标注者不可见、选样均匀，污染使被标注标签翻错的比例为 β，干净管线翻错率 `p0<β`。则 SPRT 以误报 `≤α_a`、漏报 `≤β_a` 区分"干净 vs 污染"，期望样本量 `O( (1/KL(p0‖p1)) · log(1/α_a) )`；检测到 `FREEZE` 后冻结校准，`q̂` 回到最近已审计值。证明：伯努利 SPRT 的 Wald 界；误报/漏报由 `A=log((1−β_a)/α_a)`、`B=log(β_a/(1−α_a))` 控制；冻结使后续标签无法进入校准，故授权集不再受污染阈值影响。∎ 推论：**投毒的最坏后果被压到"校准停滞（活性下降）"，而不是"阈值被悄悄放宽（安全下降）"**。

**引理 148（修正性再准入的活性—安全权衡）** 设 v17 的阈值 `q̂_17` 由含噪标签估计，目标风险 α；LPC 用溯源标签得到 `q̂_w` 且保证 `α+η`。则相对 v17，可安全再准入的计划比例不超过两条分位数之间被误拒的质量 `P(q̂_17 < s ≤ q̂_w | valid)`，且新增不安全接受的概率不超过 `η`（相对 v17 实际风险）。证明：由引理 145 的覆盖界，`q̂_w` 下的接受集相对 `q̂_17` 只多出分数落于 `(q̂_17,q̂_w]` 的计划；这些计划被 v17 拒绝源于噪声而非真实无效；其新增风险由标签翻错概率 `η` 界定，并仍受引理 146 的 v16 底座约束。∎ 推论：**"越保守越安全"是错的——被噪声污染的保守阈值既降低活性又给出虚假保证；正确的方向是"把标签做好，再安全地放宽"**。

## 6. 已知风险与失效模式

1. **WCET 估计不保守或不可证**：缓存、流水线、共享总线、DMA 使静态分析要么过于悲观要么漏算；测量法又可能漏掉罕见长尾。缓解：静态分析 + 测量混合、锁缓存/禁 DMA、按硬件版本固化 WCET 表、超预算即退回 v17。
2. **区间包络爆胀**：高维缝上 `cons=v_hi−v_lo` 可能大到接受率塌缩。缓解：按任务子空间投影、分解包络、自适应 Q 格式、把保守度作为可观测 SLA。
3. **倾向模型 `e(x)` 估计错误**：逆倾向加权在倾向误差大时方差爆炸或引入新偏差。缓解：分层而非纯逆倾向、倾向裁剪、双重稳健估计、覆盖率诊断。
4. **标签噪声与分数相关**：引理 145 的 `α+η` 依赖噪声事件与分数的可控关系；若噪声恰集中在高分区域，界会失效。缓解：按分数分层认证 η、分区噪声模型、保守并集界、人工抽检高分带。
5. **共模失效（本轮最大风险）**：标注者、审计者、验证者若共享同一系统性偏差，金丝雀与噪声界同时被污染。缓解：异构标注源、第三方金丝雀、跨模型审计、定期人工盲审、把审计器与被审计器物理/进程隔离。
6. **金丝雀泄漏**：标注者识别金丝雀后绕过。缓解：金丝雀随机化/轮换、隐入真实分布、加密 id、统计不可区分性检验。
7. **SMB 仍非绝对隔离**：DMA、共享缓存旁路、CRC 碰撞、重放。缓解：IOMMU/MPU、单调序号+时间窗、独立时钟、禁用 LLM 侧 DMA、消息认证。
8. **校准日志内存压力**：固定内存下环形缓冲覆盖旧样本，造成时间偏置。缓解：分层保留、按里程碑采样、压缩指纹、显式遗忘曲线。
9. **冻结校准的活性代价**：长期 FREEZE 使 `q̂` 停滞，分布漂移下误拒上升。缓解：冻结分级（部分冻结）、快速人工复核通道、自动解冻条件。
10. **再准入的边界依赖 v16 锚有效性**：若 v16 锚/证书本身在新硬件上过期，`Exec_v18⊆Exec_v16` 的底座失效。缓解：锚版本绑定、硬件变更强制重新认证、退化到 v15。
11. **优先级反转与共享资源争用**：认证任务与 WBC 共用总线/锁。缓解：优先级天花板、无锁单写环、预算隔离、总线仲裁预算。
12. **标注成本与部署期不可用**：实机部署时无人在环。缓解：金丝雀自审计、离线预标注、主动学习缓存待人工复核、冻结优先。

## 7. 本轮最大风险

**一句话**：v18 的可靠性证明链最终收敛到"标注质量证书"，而信任层级、噪声上界 η 与选择倾向 `e(x)` 都由**正在被审计的同一批 verifier/标注模型**估计——当标注者、审计者与验证者发生共模失效时，`q̂_w` 会给出一个看似严谨却无效的 α 保证，并在自以为最有把握处**安全地重新准入错误计划**，即"审计者无法审计自己"的循环信任塌缩。
