# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「分布外泛化」×「本体感知」）

> R69 把不确定性一分为二：aleatoric 走 R68 铁律，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去问、去看、去触。它赢得漂亮，却把整座大厦押在一个从未言明的前提上：**「我用来判断不确定性的那套东西，本身还在训练分布里」**。R69 自陈的最大风险正是这道裂缝——若流模型幻觉出模态、或把真模态坍缩，VoI 就在错误的信念上计算，系统会自信地追问一个幻影。更深一层：R69 的模态校准门（MCG）用 ECE 判「我的不确定性可信吗」，而 ECE 本身是在 in-distribution 校准集上估的；**一旦分布移位，连「我有多不确定」这个数都不可信**。
>
> 本轮两个灵感正好刺中这道裂缝：
> - **分布外泛化**告诉我们，OOD 不是「输入没见过」，而是**不变性假设失效**——要问的不是「新不新」，而是「**哪一条因果机制变了**」；正确的安全不是「更保守地继续」，而是「在可认证半径之外诚实地停」。
> - **本体感知**给出唯一的第一人称通道：它测的不是世界，而是**我自己**，其因果机制由身体物理决定，对外部协变量移位天然更不变。于是它成为判断「世界变了还是我变了」的参照系——不是因为它绝对准，而是因为它**与外部世界的分布解耦**。
>
> 核心命题：**把「分布移位」三分（世界型协变量移位 / 结构型移位 / 身体型移位 / 意图移位），用本体自模型与主动自探做可辨识归因；把安全证书升级为对移位球一致成立的分布鲁棒证书；并引入元-OOD 门，先问「我判断 OOD 的能力是否还 OOD」。** 命名 **SOMA-RAS**（Self-model, Out-of-distribution, Meta-Adaptive Risk-Aware System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**是我的身体变了，还是世界变了——而我用来判断的锚，还看得见自己漂吗？**」

## 0. 直觉与动机

**灵感 1（本体感知 = 唯一的第一人称通道 → 天然的条件不变性）**
直觉：外部传感器测「世界」，会被分布漂移污染；本体感知测「我自己」，其动力学（关节—力矩—运动学）由身体物理决定，跨环境更**不变**。所以它是判断「世界有没有变」的参照系——不是因为它绝对准，而是因为它的**因果机制更稳定**。类比：站在晃动的船上判断自己有没有站稳，靠的不是盯着船，而是脚下与耳内的本体/前庭反馈。这给 R69 的「第二意见」补上了**第三条、与外部分布解耦的通道**：R69 的流似然 △a 测「行为 vs 世界条件策略」，一旦世界 OOD，**所有**动作密度都下降，△a 失去判别力（全报警等于不报警）；SOMA 的 SPE 测「身体 vs 自模型」，对世界协变量移位不敏感，只在身体/结构变化时上升。两条通道正交，才能把「世界变了」与「我坏了」分开。

**灵感 2（OOD 不是「输入新」，而是「不变性假设失效」）**
直觉：把 OOD 当成「没见过」会导致一刀切保守：要么继续按训练分布外推（危险），要么全停（低效）。真正的分布外泛化要问：**哪一种机制变了？** 四种可能——
(a) 外观/协变量变了，但身体与任务机制没变 → 可适应，允许交互；
(b) 世界结构变了（外力、地形、接触性质），身体有效动力学被改变 → 不可外推，需分布鲁棒裕度；
(c) 身体本身变了（负载、磨损、增益、延迟、编码器偏置）→ 自模型失效，需主动自探重标定；
(d) 任务/意图变了 → 该问（R69 的 MINT 场景）。
R69 把「不确定性」二分；R70 要把「**分布移位**」三分，并映射到不同处置：适应 / 鲁棒保守 / 自探重标定 / 交互提问 / 停。这个归因必须由一个结构因果模型支撑，否则只是四个拍脑袋的阈值。

**灵感 3（本体感知给出「自生成」的分布外数据）**
直觉：外部 OOD 数据你没法主动采样（世界不配合），但本体 OOD 你可以**自己造**：抬一下、转一下、施加一个已知力矩。这是「主动 OOD 泛化」——用安全的自我激励（excitation）去**可辨识**身体参数（负载、摩擦、执行增益、编码器偏置、指令延迟）。没有激励，本体偏差与自模型偏差**共模**，不可辨识。这把 R69 的「主动交互」从「向世界问」扩展到「**向自己的身体问**」：`self-probe` 是动作空间里的新一族，与 gaze/probe/ask 并列。自我激励既是重标定手段，也是「让 OOD 检测器可被检验」的必要条件。

**灵感 4（分布鲁棒证书 → 安全不再假设 in-distribution）**
直觉：R66–R69 的所有安全证书都只在训练分布内成立。OOD 下它们既不是「保证失败」也不是「保证安全」，而是**没有保证**。正确姿态是把证书升级为**对移位球 ρ 一致成立**的分布鲁棒证书（robust reachability / distributionally robust risk），并用本体通道估计 ρ 的可观测代理。当 ρ 超出可认证半径，唯一诚实的输出是「降级/停」，而不是「更保守地继续」——后者只是把无保证伪装成保守。

**灵感 5（元-OOD：连「我不确定」这件事都可能不可信）**
直觉：R69 用 ECE 门控模态是否可信，但 ECE 是 in-distribution 估的；OOD 下它自身失配。于是需要一个**元层**：不仅问「世界是否 OOD」，还要问「**我判断 OOD 的能力是否仍 OOD**」。本体通道提供元层的锚：若身体自洽、外感受一致性也自洽，但策略密度异常 → 更可能是世界 OOD（可适应）；若身体自洽被破坏 → 连元层都不可信，直接停。这是「递归的诚实」：不知道就说不知道，连「我不知道」的可靠性也要标注。

**灵感 6（风险：锚可能共模漂移）**
直觉：本体感知是最后的不变锚，但编码器漂移、传动背隙、指令延迟会让「自模型预测」与「本体读数」用同一个偏差互相印证——得到的是**假的一致**。**可辨识性需要激励**：静止时偏置不可观测（自模型可以把偏差吸收进参数，数据上完全等价）。所以必须把「激励充分性」写进证书，否则 OOD 检测会在「我很好」的假象里失效。这是 R68「标定吸收缓变故障」在本体侧的镜像，也是本轮最深的隐患。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SOMA-RAS 总览）** SOMA-RAS = (SMP, PSD, SCA, MOG, ABP, DRC, RAS-WM‡)，并继承 FLUID-RAS 的 FMP/AUD/MINT/CIA/FMA。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）：在线只读自模型，慢更新只在停机/夜间；
(ii) **激励充分性**：任何「身体 in-distribution」结论必须在激励充分窗口内成立（定义 314），否则视为未认证；
(iii) **共模不坍缩**：身体移位判定需 ≥2 个机械独立的本体通道在剔除共模方向后一致（定义 315）；
(iv) **结构 OOD 安全退化**：移位半径估计 `ρ̂ > ρ_cert` 时只能降级/停，不得「更保守地继续」（定义 317、321）。

**定义 311（本体感知观测）** `q_t = (q^kin, q^dyn, q^int) ∈ ℝ^{d_q}`：运动学（关节角/角速度）、动力学（关节力矩/电机电流/足底接触力）、内感受（IMU 角速度与加速度、温度、电流纹波）。外部观测 `o_t` 与 `q_t` 分离；本体通道采样率更高、延迟更低，且**不经由外部场景**，故与世界协变量移位解耦。

**定义 312（自模型 / 身体图式 SMP）** 预测前向模型 `f_φ(q_t, a_t, c_t) → (q̂_{t+1}, ĉ_{t+1})`，`c` 为接触/外力项。以 efference copy（下发的动作 `a_t`）为输入、真实 `q_{t+1}` 为标签做自监督训练，不需任务标签。`φ` 为**慢变量**：只在离线/停机更新，实时环路只读。

**定义 313（本体惊奇 SPE 与参数化）** 局部线性化 `q_{t+1} ≈ A q_t + B(θ) a_t + d(θ) + E c_t + ε_t`，`θ ∈ Θ` 为身体参数（负载 m、关节摩擦 μ、执行增益 g、编码器偏置 b、指令延迟 τ）。本体惊奇 `s_t = ‖q_{t+1} − f_φ(q_t,a_t)‖²_{Σ^{-1}}`。SPE 的可归因子空间由 `θ` 的可辨识方向张成；不可辨识分量只作为 `s_noise` 处理，不得用于「身体正常」的结论。

**定义 314（激励与可辨识性）** 在窗口 `t:t+W` 上，令 `J_t = ∂q̂_{t+1}/∂θ`，Fisher 信息 `F(θ; a_{t:t+W}) = Σ_t J_tᵀ Σ^{-1} J_t`。若 `λ_min(F) < λ_exc`，则 `θ` 在该窗口**不可辨识**，任何「身体正常」的结论无效。系：静止或同构运动使 `F` 秩亏，偏置不可观测——**一致性可以被共模拟合伪造**。

**定义 315（共模不坍缩的多通道一致性 CMRC）** 本体通道按机械独立性分组（编码器 / IMU / 电机电流 / 足底力 / 视觉运动学）。定义共模方向 `v_cm` 为「使所有通道残差同号」的方向；身体归因只允许使用 `s⊥ = (I − v_cm v_cmᵀ) s`。要求至少两个独立通道组对 `s⊥` 的符号与量级一致，否则 body 归因作废。

**定义 316（三源移位归因 SCA）** 三类分数：`u_ext`（外感受 OOD，含 R69 的 △a 与表征 OOD 分）、`u_prop = ‖s⊥‖/σ_body`（本体 OOD）、`u_task`（目标/意图似然）。对位移类别 `{WORLD, STRUCTURE, BODY, TASK}` 做软后验 `p(cls | u_ext, u_prop, u_task)`：
- `u_ext↑, u_prop≈0` → **WORLD**：协变量移位，可适应，允许 FLUID 交互；
- `u_ext↑, u_prop↑` → **STRUCTURE**：世界改变了身体有效动力学（外力/地形/接触），不可外推，进入分布鲁棒；
- `u_ext≈0, u_prop↑` → **BODY**：负载/磨损/执行器退化，自模型失效，进入 ABP 重标定；
- `u_ext≈0, u_prop≈0, u_task↑` → **TASK**：意图移位，交给 MINT 提问。
用校准联合似然给后验，不做硬阈值；`argmax` 的不确定度本身进入 MOG。

**定义 317（分布鲁棒证书 DRC）** 对 `W₁` 移位球 `𝒫_ρ = {P : W₁(P, P_train) ≤ ρ}`，最坏情况风险 `R_ρ(π) = sup_{P∈𝒫_ρ} E_P[ℓ]`。证书 `J_SOMA` 仅在 `ρ̂ ≤ ρ_cert` 且归因可解释时有效；`ρ_cert` 由分布鲁棒可达集/鲁棒控制不变集计算，是**安全包络随移位膨胀**的显式上界。

**定义 318（ρ 的本体代理估计）** `ρ̂ = ψ(u_ext, u_prop, u_task)`，由本体通道校准得到的单调映射。关键：`ρ̂` 只在激励充分（定义 314）时可估；激励不足时令 `ρ̂ = +∞`，直接封死证书，避免「用不可观测的东西估安全」。

**定义 319（主动身体探针 ABP）** 信息动作空间扩展 `𝒜_info⁺ = 𝒜_world ∪ 𝒜_self`，其中 `g_self ∈ 𝒜_self` 为微幅激励轨迹（正弦扫频、已知力矩脉冲、阻抗探测、负载估计动作）。选择 `g_self* = argmax_{g_self} [IG(θ; q_{t:t+W}(g_self)) − c(g_self)]`，s.t. 力/位/时间安全包络与任务中断预算。`IG` 用 D-optimality（Fisher 行列式）近似。

**定义 320（元-OOD 门 MOG）** 不只检测 OOD，还检测「OOD 检测器自身是否失配」。定义解释残差 `r_meta = |u_obs − ū(cls)|`，即观测到的分数与归因类别预测分数之差。MOG 输出 `trust ∈ {FULL, PARTIAL, NONE}`：
- `FULL`：FLUID 的 VoI 决策可用；
- `PARTIAL`：只允许保守 + ABP 自探，禁止向世界交互；
- `NONE`：停/最小风险姿态，禁止任何学习与交互写操作。
MOG 是 R69 MCG 的**分布外推广**：ECE 门控只在 in-distribution 有意义，MOG 用不变锚替代它。

**定义 321（三级退化）** 
1. **in-support**（`ρ̂ ≤ ρ_cert`、`trust=FULL`、`cls≠BODY`）：FLUID，保留 resolution bonus；
2. **可适应 OOD**（`cls=WORLD/STRUCTURE` 且 `ρ̂ ≤ ρ_cert`）：FLUID + 分布鲁棒裕度 `λ_dr`，仅允许受限交互；
3. **不可认证 OOD**（`ρ̂ > ρ_cert` 或 `trust=NONE` 或 `cls=BODY` 未完成重标定）：R68 最保守 + 冻结合成 + 请求人类接管/停。
安全侧：in-support 下与 R69 逐指令一致；OOD 下 SOMA 的退化**强于** R69（更早停、更厚裕度），而非更弱。

**定义 322（证书 J_SOMA）** `J_SOMA = (J_FLUID, ρ̂, ρ_cert, s⊥, λ_min(F), meta_trust, body_param_CI, attribution, soma_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ ρ̂ ≤ ρ_cert ∧ λ_min(F) ≥ λ_exc ∧ CMRC 通过 ∧ trust ≠ NONE`。

**定义 323（自模型慢更新与变更点检测 CPD）** `φ` 只在停机/夜间离线更新；在线只允许变更点检测（CUSUM / 贝叶斯在线变点）与参数置信区间上报，**不得写回**。持续偏移触发「身体已变」标记，进入 BODY 归因，防止「适应」把真实损坏吃掉（对偶 R68 反吸收引理 13）。

**定义 324（分布外泛化训练目标 IRA）** 训练目标由 ERM 改为不变风险最小化（IRM / v-REx）+ 分布鲁棒优化：`min_π max_{P∈𝒫_ρ} E_P[ℓ]`，并加**本体不变性正则**：对多环境 `e`，要求表征 `Φ` 对 `(q,a) → q'` 的预测在 `e` 间一致。目标不是「见过更多 OOD」，而是「让不随环境变化的机制主导决策」。

**定义 325（本体锚的可信偏序）** 明确本体不是绝对真值，而是**有条件的局部参照**：自由运动（无外部接触）时本体可信度最高；接触/碰撞时须与触觉、视觉运动学交叉；静止时偏置不可辨识（定义 314）。偏序：`静止本体 ≺ 接触本体 ≈ 触觉 ≺ 自由运动本体`，据此决定 CMRC 的通道权重。

**定义 326（参与式审计 VQAuditor-S）** 审计对象新增：OOD 归因是否被单通道主导、激励是否被「为签发证书而制造」（gaming）、停/接管是否及时、重标定是否越界。结论回灌 AuditBuf，成为下一轮 ABP 预算与 `λ_exc` 的先验。

# IP-264/265 SMP + PSD：本体自模型与前向惊奇分解（含可辨识性闸门）
class SelfModel:
    def __init__(self, f_phi, sigma, meta):
        self.f, self.sigma, self.meta = f_phi, sigma, meta   # 慢变量，实时只读
    def surprise(self, q_prev, a_prev, q_now):
        q_hat = self.f(q_prev, a_prev)
        return maha(q_now - q_hat, self.sigma)                # s_t

def decompose_proprio(s_t, excite_window, channels):
    F = fisher_body_params(excite_window)                     # 定义 314
    if min_eig(F) < LAMBDA_EXC:
        return BodyShift(est=None, identifiable=False, F=F)   # 激励不足：不签"正常"
    s_body = project_identifiable(s_t, F)                     # 剔除不可辨识分量
    s_perp = reject_common_mode(s_body, channels)             # 定义 315
    agree  = (count_consistent(channels, s_perp) >= 2)
    return BodyShift(est=s_perp, identifiable=True, agree=agree, F=F)

# IP-266 SCA：世界 / 结构 / 身体 / 任务 的软归因
def attribute_shift(u_ext, u_prop, u_task, prior):
    return bayes_posterior([WORLD, STRUCTURE, BODY, TASK],
                           [u_ext, u_prop, u_task], prior)     # 软后验，非硬阈值

# IP-267 MOG：元-OOD 门（连归因是否解释得通）
def meta_ood_gate(u_ext, u_prop, u_task, post, body):
    resid = unexplained_residual(u_ext, u_prop, u_task, post)
    if resid > TAU_META:                    return Trust.NONE
    if (not body.identifiable) or (not body.agree): return Trust.PARTIAL
    if max(post.values()) < TAU_ATTR:       return Trust.PARTIAL
    return Trust.FULL

# IP-268 ABP：主动自探（激励以可辨识）
def choose_self_probe(theta_post, budget, safety):
    best = None
    for g in self_probe_candidates():                          # 扫频/力矩脉冲/阻抗探测
        if not budget.allow(g) or not safety.certify(g): continue
        score = d_optimal_gain(theta_post, g) - cost(g)        # IG ≈ log det(F)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-269 DRC：分布鲁棒裕度（Kantorovich-Rubinstein 闭式）
def robust_margin(rho_hat, L, lam0):
    return lam0 + L * rho_hat                                  # 定理 19

# IP-274 主闭环（继承 FLUID，仅在"是谁 OOD"处插入 SOMA 层）
def SOMA_RAS_round(M, obs, proprio):

    s_t   = M.smp.surprise(proprio.q_prev, M.last_a, proprio.q)
    body  = M.psd.decompose_proprio(s_t, proprio.excite_window, proprio.channels)
    u_ext = M.fma.flow_anomaly(...)                            # R69 世界侧第二意见
    u_prop = (norm(body.est)/SIG_BODY) if body.identifiable else INF
    post  = M.sca.attribute_shift(u_ext, u_prop, M.task_score, M.prior)
    trust = M.mog.gate(u_ext, u_prop, M.task_score, post, body)
    rho   = M.drc.estimate_radius(post, body) if body.identifiable else INF
    cls   = argmax(post)

    # 第三级：不可认证 → 停/接管（吸收态）
    if trust is Trust.NONE or rho > M.drc.rho_cert:
        return M.safety.safe_stop_or_handover(reason=(post, body, rho))

    # 身体型：只做自探重标定，在线不写；任务侧退回 R68
    if cls is BODY:
        g_self = M.abp.choose_self_probe(M.theta_post, M.budget, M.safety)
        M.smp.schedule_recalibration(g_self)                   # 停机/夜间写
        M.vqa_s.submit_async(cls, body, trust, g_self)
        return M.degrade_to_R68(M.efs.risk_scale(...))

    # 第二级：只保守 + 自探（不许向世界交互）
    if trust is Trust.PARTIAL:
        lam = max(M.efs.risk_scale(...),
                  lam_floor(M.aud.U_ale + M.aud.U_epi))
        return M.degrade_to_R68(lam)

    # 第一/二级：仍走 FLUID，但用 ρ̂ 加分布鲁棒裕度
    lam_dr = M.drc.robust_margin(rho, L_MARGIN, lam0=0.0)
    k, lam, mode, U = M.fluid.round_with_margin(obs, extra=lam_dr)
    M.vqa_s.submit_async(cls, body, trust, rho, M.fluid.last_interaction)
    return k, lam, mode, U
```

## 3. 推导

**引理 19（本体通道对世界协变量移位的条件不变性）** 设世界移位只改变外部观测 `o` 的边缘分布，而不改变身体动力学机制 `P(q_{t+1} | do(q_t,a_t), θ)`（A99：世界干预与身体机制可分离）。则 `E[s_body]` 对世界移位不变，而 R69 的 `u_ext = Δa` 随移位上升。⇒ 联合 `(u_ext, s_body)` 能区分 WORLD 与 BODY；只用 `u_ext`（R69）时两者混叠，且 OOD 下「全低密度」使 △a 失去判别力。

**引理 20（无激励不可辨识 → 共模盲区）** 在静止或同构激励下，Fisher 矩阵 `F` 对编码器偏置 `b` 与自模型偏置 `d` 秩亏，SPE 只依赖 `b+d`。故「身体正常 (`b=0`)」与「自模型吸收了偏置 (`d=−b`)」在数据上**完全等价**，任何检测器无法区分。系：长期低激励 ⇒ 缓变身体退化被自模型吸收而不报警，这是 R68 反吸收引理 13 的本体版镜像；可辨识性必须靠**主动激励**打破。

**引理 21（三源归因可分性）** 在 A100（四类移位在 `(u_ext,u_prop,u_task)` 上的条件分布两两 KL 可分，且观测噪声有界）下，贝叶斯归因的错误率随样本数指数下降；硬阈值归因在类边界处误差不降。故 SCA 用软后验，并把后验的**不可解释残差**交给 MOG，而不是强行选一个类。

**引理 22（主动自探的 D-optimal 收益与安全）** 自探 `g_self` 对 `θ` 的 Fisher 信息增益 `Δlog det F(g_self)` 在给定力/位包络下有上界；`g_self` 经安全认证后物理风险 ≤ ε_self。⇒ 自探能把不可辨识方向变成可辨识，但收益受包络约束，**不是无限精度**；这决定了 `ρ_cert` 的有限性——重标定只能缩小、不能消除 OOD 不确定性。

**定理 18（SOMA 在 in-support 严格包含 R69，OOD 下单调强退化）** 
(i) 当 `ρ̂≤ρ_cert`、`trust=FULL`、`cls∈{WORLD,TASK}` 且 `u_prop≈0` 时，SOMA 与 FLUID 逐指令相同（退化边界，`λ_dr=0`）；
(ii) 随 `ρ̂` 增大，`λ_dr` 单调不降，证书覆盖的风险上界单调收紧；`ρ̂>ρ_cert` 时转入停/接管吸收态。R69 的证书在 `ρ̂` 超出其隐含 in-dist 假设后**无保证**，故 OOD 下 SOMA 的安全侧严格优于 R69；
(iii) 交互与自探只改变归因/重标定，不改变安全包络；停止是吸收态，不会被后续「更保守的继续」解除。

**定理 19（分布鲁棒裕度的闭式上界）** 对 `W₁` 球 `𝒫_ρ`，若损失 `ℓ` 关于输入是 `L`-Lipschitz，则由 Kantorovich–Rubinstein 对偶，`R_ρ(π) ≤ E_{P_train}[ℓ] + L·ρ`。取 `λ_dr = λ0 + L·ρ̂` 即可在线给出保守裕度；该界随 `ρ` 线性、`O(1)` 可算，代价是保守性——但对安全侧恰好是正确方向。

## 6. 本轮最大风险

**一句话**：SOMA 把本体感知当作 OOD 下唯一的不变锚，而锚的可辨识性依赖激励——**若系统长期处于静止或同构运动，编码器偏置与自模型偏置在 SPE 中共模抵消，系统会在「身体自洽」的假象里把结构 OOD 判成 in-distribution**；最大的风险不是锚漂了，而是**锚看不见自己漂**（无激励 → 不可辨识 → 假安全）。

**次级风险与缓解**：
1. **本体通道被单源主导**（编码器坏了但 IMU 也同源）→ CMRC 机械独立分组 + 定义 315 的共模剔除；
2. **自探本身不安全或过度打扰**（激励越界、任务中断）→ ABP 安全认证 + 中断预算 + 定理 19 的包络约束；
3. **归因被对抗操纵**（外部制造「像身体正常」的激励）→ MOG 元残差 + VQAuditor-S 审计 + E315；
4. **分布鲁棒界过保守**（`L` 大、`ρ` 大导致长期停摆）→ 分层 `ρ_cert` + 只在不可认证时停，避免一刀切；
5. **跨本体迁移失效**（自模型绑定单一硬件）→ IRA 不变表征 + 定义 324 的多环境本体不变性正则 + E313。

    post  = attribute_shift(u_ext, u_prop, M.task_score, M.prior)
    trust = meta_ood_gate(u_ext, u_prop, M.task_score, post, body)
    rho   = M.drc.estimate_radius(post, body) if body.identifiable else INF
    cls   = argmax(post)
    if trust is Trust.NONE or rho > M.drc.rho_cert:
        return M.safety.safe_stop_or_handover((post, body, rho))   # 吸收态
    if cls is BODY:
        g = choose_self_probe(M.theta_post, M.budget, M.safety)
        M.smp.schedule_recalibration(g)                    # 停机写，在线只读
        return M.degrade_to_R68(M.efs.risk_scale(...))
    if trust is Trust.PARTIAL:
        lam = max(M.efs.risk_scale(...), lam_floor(M.aud.U_ale + M.aud.U_epi))
        return M.degrade_to_R68(lam)
    lam_dr = robust_margin(rho, L_MARGIN)                  # 第一/二级
    k, lam, mode, U = M.fluid.round_with_margin(obs, extra=lam_dr)
    M.vqa_s.submit_async(cls, body, trust, rho, M.fluid.last_interaction)
    return k, lam, mode, U
```

## 4. 推导

**引理 19（本体通道对世界协变量移位的条件不变性）** 若世界移位只改变 `o` 的边缘分布、不改身体机制 `P(q_{t+1}|do(q_t,a_t),θ)`（A99），则 `E[s_body]` 对世界移位不变，而 R69 的 `u_ext=Δa` 随移位上升。⇒ `(u_ext,s_body)` 可分离 WORLD 与 BODY；只看 △a 时两者混叠，且 OOD 下「全低密度」使 △a 失去判别力。

**引理 20（无激励不可辨识 → 共模盲区）** 静止/同构激励下 Fisher 对 `b,d` 秩亏，SPE 只依赖 `b+d`；「身体正常」与「自模型吸收偏置」数据等价。系：长期低激励 ⇒ 缓变身体退化被自模型吸收而不报警（R68 反吸收引理 13 的本体镜像），必须用主动激励打破。

**引理 21（三源归因可分性）** A100（四类移位条件分布两两 KL 可分、噪声有界）下，贝叶斯归因错误率随样本指数下降；硬阈值在类边界误差不降。故用软后验，并将不可解释残差交给 MOG，而非强行归类。

**引理 22（主动自探的 D-optimal 收益与安全）** 给定力/位包络，`Δlog det F(g_self)` 有上界，认证后物理风险 ≤ ε_self。⇒ 自探能把不可辨识方向变可辨识，但**只能缩小、不能消除** OOD 不确定性，故 `ρ_cert` 必为有限值。

**定理 18（SOMA 在 in-support 严格包含 R69，OOD 下单调强退化）** (i) `ρ̂≤ρ_cert ∧ trust=FULL ∧ u_prop≈0` 时与 FLUID 逐指令相同；(ii) 随 `ρ̂` 增大 `λ_dr` 单调不降，`ρ̂>ρ_cert` 转入停/接管吸收态；R69 证书在超出 in-dist 假设后无保证，故 OOD 下 SOMA 安全侧严格更优；(iii) 交互/自探只改归因与重标定，不改安全包络，停止不可被「更保守的继续」解除。

**定理 19（分布鲁棒裕度闭式界）** 对 `W₁` 球、`L`-Lipschitz 损失 `ℓ`，由 Kantorovich–Rubinstein 对偶 `R_ρ(π) ≤ E_{P_train}[ℓ] + L·ρ`。取 `λ_dr = λ0 + L·ρ̂` 即可在线给出保守裕度，`O(1)` 可算；保守性是安全侧的正确方向。

## 7. 本轮最大风险

**一句话**：SOMA 把本体感知当作 OOD 下唯一的不变锚，而锚的可辨识性依赖激励——**若系统长期静止或做同构运动，编码器偏置与自模型偏置在 SPE 中共模抵消，系统会在「身体自洽」的假象里把结构 OOD 判成 in-distribution**；最大的风险不是锚漂了，而是**锚看不见自己漂**（无激励 → 不可辨识 → 假安全）。

**次级风险与缓解**：本体通道被单源主导（CMRC 机械独立分组 + 共模剔除）；自探越界/过度打扰（ABP 安全认证 + 中断预算 + 包络约束）；归因被对抗操纵（MOG 元残差 + VQAuditor-S + E315）；分布鲁棒界过保守导致停摆（分层 ρ_cert，只在不可认证时停）；跨本体迁移失效（IRA 不变表征 + 本体不变性正则 + E313）。
