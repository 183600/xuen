# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「预训练」×「数字孪生」）

> R69 把不确定性一分为二，并让系统学会「问」。但它有两个未言明的前提：
> 1. **问什么、问谁，是由同一个可能出错的模型算出来的**——VoI 用策略自己的世界模型估计「哪一问最值」，流似然「第二意见」又复用了同一个 trunk；两条通道共享血缘，「一致」并不等于「独立」。
> 2. **交互一旦发出就不可撤回**——R69 只能在事后用证据纪律补救，不能在事前预演「这一问会不会问错、会不会问险」。
>
> 本轮两个灵感正好补上这两块：
> - **预训练**给出跨任务、跨本体的先验与可复用世界模型：让系统在没见过的地方也有「大概会怎样」的假设空间；
> - **数字孪生**给出可在现实之外执行反事实预演的实例化复制品：先在心里演一遍，再决定是否去现实里撞一次。
>
> 但二者合起来会制造一个比 R69 更隐蔽的病灶：**孪生与策略同源，孪生可以「证实」策略的错误，并把确认偏误自动化**。因此本轮的核心不是「用孪生确认」，而是：
>
> **预训练只许提议，孪生只许证伪，真实交互才是唯一的证实通道。**
>
> 命名 **TWIN-RAS**（Twin-verified, World-model-pretrained, Interactive, Non-confirming Risk-Adaptive System）。定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这一问，能不能先在孪生里演一遍？演过之后，我凭什么相信它？**」——孪生是排练厅，不是证人席。

## 0. 直觉与动机

**灵感 1（预训练 → 先验决定「假设空间」的大小，也决定「盲区」的形状）**
直觉：R69 的流策略在有限数据上采样 K 个模态；如果真模态根本不在训练分布里，采样再多也采不到。预训练把假设空间从「本任务」扩展到「任务族」：跨本体、跨场景的交互经验让模型知道「人类犹豫时通常在看什么、摸什么、问什么」。但预训练不是免费午餐：它同时规定了模型**看不见什么**。一个在「干净走廊」上预训练的模型，会把「镜像房间」当成噪声而不是一个新模态。所以预训练的第一贡献不是「更准」，而是**更大的候选集 + 一个可审计的先验**；它的风险是**先验把真模态剪掉了**。

**灵感 2（数字孪生 → 把「不可逆交互」变成「可预演的反事实」）**
直觉：R69 的每一次注视/探针/问句都要花物理或社交成本，而且可能不可撤回。数字孪生提供一个实例化的可执行副本：可以在里面先试「如果我把视线移到左下角，会看到什么」「如果我以 2N 的力探一下，接触会不会滑」「如果我这么问，人类模型最可能怎么答」。这把 R69 的「先做再学」变成「**先演再选，再做再证**」。但孪生只对**物理后果**可信；它无法模拟「人是否真诚」。因此孪生能预演「会不会撞」，不能预演「会不会被骗」——这条边界必须写进定义。

**灵感 3（孪生是证人还是被告 → 同源证据的独立性幻觉）**
直觉：R69 的流似然第二意见复用同一个 trunk，因此它和策略不是两个证人，而是**同一个证人的两种说法**。数字孪生如果也由同一批预训练数据、同一个世界模型初始化，那么「孪生同意策略」几乎不提供新信息——它只是把同一个偏差换了一种语言复述。更糟：孪生可以生成大量「看起来很像真的」合成证据，把策略的错误越喂越自信（model collapse 的闭环版）。所以本轮必须引入**血缘（lineage）与证据权威（authority）**：预训练 < 孪生 < 现实；只有现实（或与策略血缘独立的物理通道）能「证实」，孪生只能「证伪/排除/排序」。

**灵感 4（预训练 + 孪生 → 不确定性从「动作」抬升为「模型族」）**
直觉：R69 的 U_epi 是「动作该选哪个模态」。R70 发现这个歧义背后还有两层：
- **U_pre**：当前任务/本体到底属于预训练里的哪个「技能族/动力学族」？选错族，后面全错；
- **U_inst**：这个具体房间、这台具体机器人、这位具体人类的参数是什么？
- **U_assoc**：当前观测到底对应哪个假设？（R69 已处理）
三者需要不同的消解器：U_pre 靠检索/先验/少量适配；U_inst 靠孪生标定 + 针对性交互；U_assoc 靠真实交互。把它们混成一个标量 U_epi 会导致「用最贵的现实交互去解最便宜的先验问题」。R70 的第一条工程原则就是**分层消解，按成本从低到高**。

**灵感 5（孪生也会过期 → 需要「孪生-现实差异」作为一等公民）**
直觉：R68 的缓变故障会被标定吸收；R69 的误导回答会被证据纪律拦截；R70 的对应病灶是**孪生漂移**——孪生曾经很准，但环境变了、传感器老了、对手改了策略，孪生仍自信地给出「安全」预测。更阴险的是「太干净的孪生」：攻击者让孪生预测一切正常，诱导系统去做危险的现实交互。所以孪生的权威不能是常数，必须由一条**可观测的孪生-现实差异（TRD）**实时授予或撤销；TRD 超阈值即退回 R69 的纯保守——这与 R68 的「标定不可吸收」、R69 的「不可信模态不驱动交互」是同一味药。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（TWIN-RAS 总览）** TWIN-RAS = (PFC, TAC, DTL, TRD, CFR, NCD, SGEC, MVS, TPC, IBG-2, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **孪生无裁决权**：孪生输出只能用于**排除假设、排序候选、预筛动作**，不得单独将任何假设写入「已证实集」，也不得单独授权物理动作；
(iii) **血缘披露与独立性折扣**：每个证据源携带 lineage 标签与相关性估计 ρ；同源证据的「一致」按有效独立源数 k_eff 折扣，k_eff < k_min 不得定案；
(iv) **现实优先**：真实交互/独立物理通道是唯一的证实通道；孪生与先验只能在现实之前**缩小搜索空间**，不能在现实之后**替代现实**。

**定义 311（不确定性三层分解）** U = U_ale ⊕ (U_pre, U_inst, U_assoc)，其中：
- U_pre：预训练任务族/动力学族的选择不确定性（离线可约，运行时成本≈0）；
- U_inst：实例参数（几何、摩擦、人类习惯）不确定性（孪生标定可约，计算成本低、物理风险≈0）；
- U_assoc：数据关联/模态身份不确定性（真实交互可约，物理/社交成本高）。
每层有专属消解器 R_pre（检索/先验/少样本适配）、R_twin（孪生校准/反事实预演）、R_real（R69 的信息动作）。**不同层不做标量加和**；λ 只消费「各层消解后的残差」。

**定义 312（预训练基础核 PFC）** θ_pre 在任务族分布 D_pre 上预训练；提供表征 Φ_pre、技能/动力学族先验 π_pre(z_skill)、初始世界模型 f_pre。工程上 PFC 是 R69 trunk/世界模型的**预训练来源**，不是并行的第二黑箱：运行时复用同一 trunk，只增加只读先验头与孪生状态。目标域适配只允许轻量残差（避免灾难性遗忘与实时写）。定义**先验-数据冲突** C_pre = D_KL(p̂_target || p_pre) 的校准批估计；C_pre > τ_pre 或 ECE_pre > τ_ece ⇒ **PFC 停用**（不提议、不剪枝、不排序），防止先验把真模态剪掉（负迁移）。C_pre ≤ τ_pre 时 PFC 也只「提议/排序」，**不单独剪枝**；任何剪枝只由 CFR 在真实交互后执行，且保守回退模态 m₀ 永不被剪枝。

**定义 313（实例数字孪生 DTL）** DTL = (f_φ, g_ψ, Σ_twin, τ_fid)，f_φ 为潜动力学，g_ψ 为多传感器发射模型，二者由 PFC 初始化并用实例数据做**有界残差校准**。孪生支持反事实 rollout：给定候选动作序列 ξ，预测 ŷ_{t:t+H} 及其不确定度。**能力边界**：DTL 只对物理/几何/动力学后果建模；对人类回答的**内容与真诚度**不做建模（g_ask 的回答分布一律视为未知，交由 R69 的投毒威胁模型处理）。

**定义 314（孪生-现实差异 TRD 与权威函数）** TRD = E_{real}[d(y, ŷ_twin)] 的校准归一化，分解为 TRD = TRD_bias + TRD_var + TRD_epi（偏差/噪声/孪生自身 epistemic）。权威函数
Auth_twin = 1[TRD_bias ≤ τ_twin ∧ ¬DriftAlarm ∧ Inbreed ≤ ρ_max]，
其中 DriftAlarm 由 CUSUM/EWMA 检测（继承 R68 缓变故障检测），Inbreed 见定义 320。Auth_twin=0 ⇒ 孪生不得参与任何决策，逐指令退回 R69。**只有 TRD_bias 会毁灭证伪的可靠性；TRD_var 只降低效率。**

**定义 315（反事实证伪预演 CFR）** 对候选模态 {m_k} 与信息动作 g ∈ 𝒜_info，孪生给出 p_twin(y|g,m_k)。定义判别力 D(g) = min_{i≠j} d(p_twin(·|g,m_i), p_twin(·|g,m_j))。选择 g 使 D(g) 最大且孪生预测风险 ≤ ε_int；执行后用真实观测**只做排除**：若某 m_k 在孪生预测下与 y_obs 的偏差超过证伪裕度 δ_falsify + ε_twin，则排除 m_k；**不因「孪生预测对了」而提升任何 m_k 的置信度**。真实置信度更新只允许使用与策略血缘独立的传感器似然（R69 原通道）。保守回退模态 m₀ 永不参与剪枝。

**定义 316（证据权威格与非确认纪律 NCD）** 证据源 e ∈ {pre, twin, real}，权威偏序 pre ≺ twin ≺ real。允许的操作：pre/twin 可 **propose（提议）** 与 **falsify（排除）**；只有 real（或与策略血缘独立的物理通道）可 **certify（证实）**。形式化证据图为带血缘超边；两源 i,j 的独立性用 ρ_ij ∈ [0,1] 表示，有效独立源数 k_eff = k / (1 + (k−1)·ρ̄)，ρ̄ 为平均相关性。定案要求 k_eff ≥ k_min（默认 2）。R69 的 k 正交一致是本定义在 ρ̄=0、无 twin 源时的特例。

**定义 317（惊讶门控的证据信用 SGEC）** 对一次真实交互，令 s = −log p_twin(y_obs|g,o) 为孪生预测惊讶，s̄ = E_{p_twin}[s] 为孪生**预期**惊讶。定义模型级证据信用 κ = max(0, s − s̄ − margin)。**被孪生/先验已经预测到的观测，不能用于提升孪生/先验自身的可信度**——预测对了只说明「没被证伪」，不产生模型级新信息；只有超出预测的惊讶才携带「这个世界与我以为的不同」的判别信息。κ 只用于更新**模型/孪生权威**，不替代目标级模态后验的贝叶斯更新。备注：κ 天然惩罚「确认偏误」，并把「太干净的孪生」暴露为 κ≈0 的无效证据。

**定义 318（元 VoI 与悲观调度 MVS）** R69 的 VoI(g) 由自身模型估计，存在自指偏差。改用孪生估计的 VoI_hat，并做**权威折扣 + 悲观下界**：
VoI_LCB(g) = Auth_twin · [VoI_hat(g) − β·σ_twin(g)] + (1−Auth_twin)·VoI_R69(g)。
选 g* = argmax_g [VoI_LCB(g) − c(g) − c_twin(g)]，s.t. 物理认证与预算。若 g* 的得分 ≤ 0 则不交互（R69 兜底）。**对孪生乐观是不允许的**：σ_twin 越大，越只信 R69。孪生计算预算按「候选动作的 σ_twin × 风险敞口」分配，边际收益低于计算成本即停。

**定义 319（孪生预飞认证 TPC）** 对信息动作 g，孪生先做物理后果预演：若预测风险 > ε_int 或预测会越出安全包络，则**否决** g；通过者仍需过 R69 的物理 C-RAS-WM 认证（定义 302）。可执行安全集取**交集**：
S_exec = S_PHYS ∩ (Auth_twin ? S_TWIN : 𝒜)。
交集只减不增 ⇒ 孪生永远不能扩大安全动作集。孪生不通过 ≠ 物理不安全，只是「不预演就不做」的保守偏置。

**定义 320（同源繁殖防护 IBG-2）** 若用孪生生成的数据做预训练/微调（定义 321 TAC），孪生与策略血缘相关性 ρ 上升。硬约束：
(i) 合成数据**永不**用于更新证据后验或孪生权威；
(ii) 合成:真实比例 ≤ ρ_syn；
(iii) 以「惊讶一致率」而非「预测一致率」做血缘审计；
(iv) ρ > ρ_max ⇒ Auth_twin=0。
这是对 R69「单次交互不得定案」在**数据生成侧**的镜像：孪生不能既当出题人又当阅卷人。

**定义 321（孪生锚定课程 TAC）** 离线阶段用数字孪生生成**歧义课程**（故意制造镜像房间、遮挡、动态干扰、人类犹豫），用于预训练流策略的模态覆盖与先验校准；每条合成样本必须带**真实锚点**（真实数据片段或可验证的物理约束），并记录合成-真实血缘。TAC 只改善 U_pre 与 U_assoc 的**候选覆盖**，不改变安全认证链。

**定义 322（证书 J_TWIN）** J_TWIN = (J_FLUID, TRD_bias, Auth_twin, twin_ece, k_eff, κ_p95, lineage_hash, syn_ratio, twin_ver)。Valid ⇔ Valid(J_FLUID) ∧ TRD_bias ≤ τ_twin ∧ Auth_twin=1 ∧ k_eff ≥ k_min ∧ syn_ratio ≤ ρ_syn。

**定义 323（AIC-TWIN 威胁模型）** ℰ_TWIN = ℰ_FLUID × ℰ_twin × ℰ_inbreed × ℰ_twin_attack，其中 ℰ_twin 包含孪生过期/未建模动力学/发射模型失配；ℰ_inbreed 包含合成数据自证、模态坍缩、确认偏误自动化；ℰ_twin_attack 包含对孪生或预训练语料的投毒、以及「太干净的孪生」诱导危险现实交互。并入 AIC 统一对抗训练。

**定义 324（两级孪生退避与包含性）** (i) Auth_twin=1：孪生可预筛/排序/排除，物理交互仍由 R69 与 C-RAS-WM 认证；(ii) 记 Auth_TWIN = Auth_twin ∧ PFC_valid，其中 PFC_valid = 1[C_pre≤τ_pre] ∧ 1[ECE_pre≤τ_ece]。若 Auth_twin=0，孪生停用；若 PFC_valid=0，PFC 停用。二者同时为 0 时 TWIN 层完全关闭，**逐指令退回 R69**；若仅一方有效，则只保留其「排序/提议」能力，不改安全集与 λ，风险仍 ≤ R69。因此 TWIN-RAS 的可执行安全集 ⊆ R69 的可执行安全集，安全风险不高于 R69；效率增益只来自「更少更准的交互」与「更早排除不可行假设」。链条：R70 ⊆ R69 ⊆ R68。

**定义 325（统一不确定性账本）** U_ledger = (U_ale; U_pre, U_inst, U_assoc; reducer, cost, authority, residual)。每一轮记录各层「谁消解、花了多少、消解后残差、证据权威」。风险缩放沿用 R69 定义 307：λ = λ_floor(U_ale + 未消解残差)；孪生/先验的消解只有在「被现实确认或仅做排除」时才能获得 resolution bonus，且**永不把未确认的孪生结论当作已消解**。

# IP-264 PFC：预训练基础核（离线训练；运行时只读）
class PretrainedCore:
    def __init__(self, trunk, prior_head, world_model, calib):
        self.trunk, self.prior, self.wm, self.calib = trunk, prior_head, world_model, calib

    def propose(self, o):
        z = self.trunk(o)
        return self.prior(z), self.wm.init_state(z)      # 只提议，不裁决

    def prior_conflict(self, batch):
        return kl(self.calib.predict(batch), self.prior_predict(batch))

    def rank(self, modes, proposal):                   # 只排序，不剪枝
        return sorted(modes, key=lambda m: -self.prior.score(m, proposal))

# IP-265 TAC：孪生锚定歧义课程（离线；仅预训练用）
def build_ambiguity_curriculum(twin, real_anchors, n):
    out = []
    for _ in range(n):
        sc = twin.sample_ambiguous()                     # 镜像/遮挡/犹豫
        if not anchored(sc, real_anchors): continue      # 必须有真实锚点
        out.append((sc, lineage='synth', anchor=sc.anchor))
    return mix_with_real(out, max_ratio=RHO_SYN)         # 合成:真实有上限

# IP-266 DTL：实例数字孪生（有界残差校准；物理后果可预演，人心不可）
class DigitalTwin:
    def rollout(self, xi, o, H):
        s = self.f_phi.init(o)
        ys, sig = [], []
        for t in range(H):
            s = self.f_phi.step(s, xi[t])
            y, sd = self.g_psi(s)
            ys.append(y); sig.append(sd)
        return ys, sig, self.f_phi.epistemic(s)          # 预测 + 不确定度

# IP-267 TRD：孪生-现实差异 + 漂移 + 权威
class TwinAuthority:
    def update_and_measure(self, y, y_hat):
        self.ewma += (d(y, y_hat) - self.ewma) * self.alpha
        self.cusum = max(0, self.cusum + d(y, y_hat) - self.k)
        bias = self.calibrated_bias(self.ewma)
        drift = self.cusum > self.h
        return TRD(bias=bias, drift=drift)

def auth(trd, inbreed, tau_twin, rho_max):
    return (trd.bias <= tau_twin) and (not trd.drift) and (inbreed <= rho_max)

# IP-268 CFR：只证伪不确认
def falsify_only(modes, y_obs, twin, g, eps_twin, delta):
    kept = []
    for m in modes:
        if m.is_conservative_fallback:          # m0 永不被剪枝
            kept.append(m); continue
        lp = twin.logprob(y_obs, g, m)
        if -lp > delta + eps_twin: continue     # 证伪裕度
        kept.append(m)
    return kept

# IP-269/270 NCD + SGEC：血缘折扣 + 惊讶信用
def nonconfirm_update(modes, y, sensor_lik, rho, k_min=2):
    k_eff = 1.0 / (1.0 + rho)                   # 两源情形
    if k_eff < k_min:
        return modes, False                     # 不得定案，保持未消解
    return bayes_update(modes, sensor_lik), True

def surprise_credit(p_twin, y, g, margin):
    s  = -p_twin.logprob(y, g)
    s0 = p_twin.expected_surprise(g)
    return max(0.0, s - s0 - margin)            # 预测对了 ≈ 0 信用

# IP-271 MVS：悲观元 VoI（孪生不可信即逐指令回 R69）
def choose_info(modes, o, budget, auth_twin, twin, r69_voi):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        if auth_twin:
            voi = twin.voi_hat(modes, g, o) - BETA * twin.sigma(modes, g, o)
        else:
            voi = r69_voi(g)                    # Auth=0：R69 边界
        score = voi - cost(g) - twin.compute_cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-272 TPC：孪生预飞认证（交集，只减不增）
def twin_preflight(g, o, twin, eps_int):
    risk, succ = twin.predict_risk(g, o)
    return (not succ) or (risk <= eps_int)      # False => 否决

# IP-276 TWIN-RAS 主闭环（继承 R69；孪生只做预演与证伪）

## 3. 推导

**引理 19（有界孪生误差下的证伪健全性）** 设真实观测分布与孪生预测分布满足**有界似然比**：对任意 y，p_real(y|m) ≤ e^{ε_twin}·p_twin(y|m)（A99）。若某假设 m 在孪生下 p_twin(y_obs|m) ≤ e^{−M}，则 p_real(y_obs|m) ≤ e^{−M+ε_twin}。因此以 M − ε_twin 为证伪裕度排除 m 是**保守**的：被排除的假设在真实分布下也不可能高概率产生该观测。要点：**证伪对孪生误差是单侧稳健的，确认不是**——有界似然比只给出「孪生低概率 ⇒ 现实也低概率」的一个方向，不能反过来证明「孪生预测对了 ⇒ 假设为真」。这就是「只许证伪」的数学根据。

**引理 20（同源一致性的证据膨胀）** 设 k 个证据源两两相关性 ρ，单个源的错误率 δ。若把它们当独立源做多数表决，错误率按 δ^k 衰减；真实有效独立源数 k_eff = k/(1+(k−1)ρ)。当 ρ→1，k_eff→1，结论退化为单源。故「策略 + 流似然 + 同源孪生」三票一致，不等于三票；R69 的 k 正交纪律必须升级为**血缘加权**。系：当孪生与策略共享预训练语料时，必须引入至少一个物理独立通道（真实传感器/人类回答）才能达到 k_eff ≥ 2。

**引理 21（确认不产生模型级信息）** 设模型级变量 T 表示「孪生/先验是否可信」，观测 Y。若 T 已预测到 Y（s ≤ s̄ + margin），则 I(T;Y) ≈ 0：该观测不改变「孪生是否可信」的后验；只有超出预测的惊讶 κ>0 才携带模型判别信息。直观：一个模型预测对了，只能说明它没被这次观测证伪；要让「它可信」这一命题获得证据，必须看到它**没预料到**的东西。系：**若把「孪生预测对了」当证据，就会形成自我确认闭环**；SGEC 的 κ 是这条闭环的断路开关。

**引理 22（预训练先验的迁移-剪枝边界）** 设源域 D_pre 与目标域 D_t 的分布差异为 ε_transfer。先验在目标域的校准误差满足 ECE_t ≤ ECE_pre + L·ε_transfer（A100，L 为校准 Lipschitz 常数）。故存在 τ_pre 使得 ε_transfer > τ_pre 时，先验的「剪枝」可能把真模态排除（负迁移）；此时只允许「提议」不允许「剪枝」。系：**预训练越强，越要报告它离目标域有多远**——C_pre 是先验的「护照」，没有它，先验不能入境执法。

**定理 18（TWIN-RAS 对 R69 的严格包含）** 在 A99–A102（有界 TRD、证伪裕度、现实优先、安全集取交集、保守模态永不剪枝）下，任意状态 s：
(i) 可执行安全集 S_TWIN(s) ⊆ S_R69(s)；
(ii) 安全风险 R_safe(TWIN) ≤ R_safe(R69)；
(iii) 当 Auth_twin=0 且 PFC_valid=0 时，两者**逐指令相同**；效率上，只有被现实确认的消解才获得 resolution bonus，孪生预筛只减少无效/危险交互。
证明要点：安全集取交集且孪生不能扩大动作集 ⇒ (i)；未确认的孪生/先验结论全部按未消解 epistemic 进入 λ_floor，保守模态 m₀ 永不剪枝 ⇒ (ii)；权威关闭时所有分支显式退回 R69 ⇒ (iii)。**R69 = TWIN-RAS 在「孪生不可信/不存在」边界上的退化。**

**定理 19（非确认纪律下无自证错误）** 在 NCD、证伪裕度与「保守模态永不剪枝」下，任何仅由 pre/twin 证据组成的序列都不能把错误假设提升为「已证实」；孪生错误最多导致**漏排除（保守）**或**误排除非保守假设**，而 m₀ 始终保留，故最坏情形退化为 R69。因此「被孪生证实的错误」在构造上不可能；残余风险只剩「孪生误排除真模态导致效率损失」与「选择偏误（孪生诱导去测一个它擅长预测的维度）」。后者用 SGEC 的惊讶信用与 k_eff 约束缓解。**一句话：孪生可以让系统变笨，但不能让它变大胆。**

**定义 312–313（PFC 与 DTL）** PFC 提供表征/技能族先验/初始世界模型（是 R69 trunk 的预训练来源，不新增并行黑箱）；`C_pre>τ_pre` 或 `ECE_pre>τ_ece` ⇒ PFC 停用；C_pre 合格时也只提议/排序不剪枝，`m₀` 永不剪。DTL 由 PFC 初始化 + 有界残差校准；只建模物理/几何/动力学，**不建模人类回答的真诚度**。

**定义 314（TRD 与权威）** `TRD=TRD_bias+TRD_var+TRD_epi`；`Auth_twin=1[TRD_bias≤τ_twin ∧ ¬DriftAlarm ∧ Inbreed≤ρ_max]`；Auth=0 ⇒ 逐指令退回 R69。只有 bias 会毁灭证伪可靠性。

**定义 315–316（CFR 与 NCD/EAL）** 选 `argmax D(g)` 且风险≤ε_int；执行后**只排除**偏差超过 `δ_falsify+ε_twin` 的模态，不因预测正确而升置信。证据权威 `pre≺twin≺real`；pre/twin 只能 propose/falsify，只有 real 能 certify；`k_eff=k/(1+(k−1)ρ̄)≥k_min` 才可定案。R69 的 k 正交一致是 ρ=0 特例。

**定义 317（SGEC）** `s=−log p_twin(y|g,o)`，`s̄=E_p_twin[s]`，`κ=max(0,s−s̄−margin)`；被预测到的观测不提升孪生/先验可信度——**确认不产生模型级信息，惊讶才产生**。κ 只更新模型/孪生权威，不替代目标级后验。

**定义 318–319（MVS 与 TPC）** `VoI_LCB=Auth·[VoI_hat−βσ_twin]+(1−Auth)·VoI_R69`；得分≤0 不交互；Auth=0 逐指令回 R69。孪生预飞否决越界动作，通过者仍需物理 C-RAS-WM 认证；安全集取交集。

**定义 320–321（IBG-2 与 TAC）** 合成数据永不更新证据后验/孪生权威；合成:真实≤ρ_syn；以惊讶一致率审计血缘；ρ>ρ_max ⇒ Auth=0。TAC 用孪生生成歧义课程做预训练，但每条必须有真实锚点，只改善候选覆盖，不改安全链。

**定义 322–325（证书/威胁/退避/账本）** J_TWIN 并入 TRD_bias、Auth、twin_ece、k_eff、κ_p95、lineage_hash、syn_ratio；ℰ_TWIN=ℰ_FLUID×ℰ_twin×ℰ_inbreed×ℰ_twin_attack；Auth_twin=0 且 PFC 停用 ⇒ 逐指令退回 R69，故 R70⊆R69⊆R68；U_ledger 记录每层「谁消解/成本/权威/残差」，未确认结论一律视同未消解。

class PretrainedCore:
    def propose(self, o):

        return self.prior(z), self.wm.init_state(z)

    def rollout(self, xi, o, H):

def auth(trd, inbreed, tau_twin, rho_max):

    return [m for m in modes
            if m.is_conservative_fallback               # m0 保留
            or -twin.logprob(y, g, m) <= delta + eps_twin]

# IP-269/270 NCD + SGEC：血缘折扣与惊讶信用
def nonconfirm_update(modes, y, sensor_lik, rho, k_min=2):
    if 1.0 / (1.0 + rho) < k_min: return modes, False   # 不得定案
    return bayes_update(modes, sensor_lik), True

def surprise_credit(twin, y, g, margin):
    return max(0.0, -twin.logprob(y, g)
               - twin.expected_surprise(g) - margin)    # 预测对了 ≈ 0

# IP-271 MVS：悲观元 VoI；Auth=0 退 R69
def choose_info(modes, o, budget, auth_twin, twin, r69_voi):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi = (twin.voi_hat(modes, g, o) - BETA * twin.sigma(modes, g, o)
               if auth_twin else r69_voi(g))
        score = voi - cost(g) - twin.compute_cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-272 TPC：预飞认证（否决只减不增）
def twin_preflight(g, o, twin, eps_int):
    risk, unsafe = twin.predict_risk(g, o)
    return (not unsafe) and risk <= eps_int

# IP-276 主闭环（继承 R69）
def TWIN_RAS_round(M, obs):

## 4. 推导

**引理 19（有界孪生误差下的证伪健全性）** 若有界似然比 `p_real(y|m) ≤ e^{ε_twin} p_twin(y|m)`，且 `p_twin(y_obs|m) ≤ e^{−M}`，则 `p_real(y_obs|m) ≤ e^{−M+ε_twin}`。以 `M−ε_twin` 为裕度排除 m 是保守的。**证伪对孪生误差单侧稳健，确认不是**——有界比只给一个方向，不能证明「孪生预测对 ⇒ 假设为真」。这是「只许证伪」的数学根据。

**引理 20（同源一致性的证据膨胀）** k 个两两相关 ρ 的证据源，`k_eff = k/(1+(k−1)ρ)`；ρ→1 时 k_eff→1。「策略 + 流似然 + 同源孪生」三票一致 ≠ 三票；R69 的 k 正交纪律必须升级为血缘加权，且需至少一个物理独立通道才能达到 k_eff≥2。

**引理 21（确认不产生模型级信息）** 模型级变量 T（孪生/先验是否可信）与观测 Y：若 Y 已被 T 预测（`s≤s̄+margin`），则 `I(T;Y)≈0`；只有超额惊讶 κ>0 才携带模型判别信息。系：把「孪生预测对了」当证据会形成自我确认闭环，SGEC 的 κ 是断路开关。

**引理 22（预训练先验的迁移-剪枝边界）** 源-目标差异 ε_transfer 下，`ECE_t ≤ ECE_pre + L·ε_transfer`；ε_transfer>τ_pre 时先验剪枝可能排除真模态（负迁移），只许提议不许剪枝。C_pre 是先验的「护照」，没有它不能入境执法。

**定理 18（TWIN-RAS 对 R69 的严格包含）** A99–A102 下：`S_TWIN⊆S_R69`；`R_safe(TWIN)≤R_safe(R69)`；Auth_twin=0 且 PFC 停用（C_pre/ECE 越界）时逐指令相同。只有被现实确认的消解才获 resolution bonus；孪生预筛只减少无效/危险交互。R69 = 「孪生不可信/不存在」边界上的退化。

**定理 19（非确认纪律下无自证错误）** NCD + 证伪裕度 + m₀ 永不剪枝 ⇒ 任何仅由 pre/twin 组成的证据序列都不能把错误假设提升为「已证实」；孪生错误最多导致漏排除或误排除非保守假设，m₀ 保留故最坏退化为 R69。因此「被孪生证实的错误」在构造上不可能；残余风险只剩效率损失与选择偏误，由 SGEC 与 k_eff 缓解。**孪生可以让系统变笨，但不能让它变大胆。**

## 7. 本轮最大风险

**一句话**：TWIN-RAS 的全部收益押在「孪生-现实差异可被观测、且漂移能被及时检测」上——**如果孪生与策略同源，又用孪生生成的数据反复预训练，TRD 会被「同源一致」压低、惊讶信用被耗尽，系统进入「孪生说对、现实说错」的确认闭环：它不会当场出错，而是系统性地把错误练成常识；此时最危险的不是孪生会撒谎，而是它撒的谎与策略的偏见完全一致，且没有任何独立通道能察觉。**

**次级风险与缓解**：同源繁殖/model collapse（IBG-2 合成比例上限 + 真实锚点 + 惊讶一致率审计 + Auth 撤销）；孪生漂移/过期（TRD_bias + CUSUM，超阈值逐指令退 R69）；预训练负迁移（C_pre/ECE 越界即停用 PFC，m₀ 永不剪枝）；预演拖垮实时（异步 + 缓存 + 计算预算）；孪生预演「物理安全」但人类回答投毒（DTL 不建模真诚度，g_ask 仍走 R69 的 k 正交证据纪律与 ℰ_poison 对抗训练）。
