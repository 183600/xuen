# 灵感驱动研究循环 · 第 1 轮（新循环）
本轮灵感：「最优控制」×「LoRA」

> **基线**：MetricVoiceGauge-NCD-HUTDH-v24（HPC-E++ 六证准入门：HPC-E ∪ CESC ∪ FSVC ∪ IPAttest ∪ OASC ∪ CDL ∪ BRC；其上承 v23 的 CESC/FSVC/IPAM、v22 的 HDL/PGEV/ACSC/DCSC、v21 的 SDC/CAC/DCL/GIC、v20 的 PCA/CTS/CFC/HPC）。
> **本轮纪律**：不推倒 v24，不重写证书语义，只做两件事：**把"否决式证书过滤"升级为"证书域内的可证明最优控制"；把"冻结骨干的少样本适配"升级为"低秩可证明适配"**。一句话：v24 回答"能不能做"，v25 回答"在所有能做的计划里，哪个最不保守、为什么、这个'为什么'能否被审计"。

## 0. 直觉与动机

### 灵感 1（最优控制 → 从"点式过滤"到"集合式可行性核 + 影子价格"）

**直觉**：v24 是**否决式**安全——任何计划要么落在证书过滤器内，要么被拒绝。它安全，但保守的来源往往不是证书本身，而是"静态安全裕度 + 一次性过滤"这种实现方式：机器人并不知道"再靠近 5cm 是否还能在 200ms 内停住"，于是干脆对所有状态都用同一个更远的裕度。最优控制恰好补上两块：

1. **值函数把"点约束"变成"集合约束"**。HJI 安全值 `V(x)` 回答的不是"此刻是否越界"，而是"从此刻出发，是否存在一条既满足全部证书、又能在有限时域内进入已认证停靠集的轨迹"。它的非负水平集 `{V ≥ 0}` 是证书域 `D_v24` 内的**最大受控不变集（可行性核）**，因此它天然包含 v24 的静态保守子集，又绝不越出证书域。
2. **KKT 对偶变量给每张证书一个"影子价格"**。约束 `g_i ≤ 0` 的对偶 `λ_i ≥ 0` 精确回答"把证书 i 放松一个单位，最优代价能降多少"——也就是"这张证书到底牺牲了多少活性"。这把 v21/v22 反复出现的"保守性叠加导致活性坍缩"从定性抱怨变成可审计的定量账本。

**关键反直觉点**：最优控制通常被当作"冒险"的代名词，但在这里它反而**提升安全可用性**——因为它用"动态可达性证明"替换了"拍脑袋的静态裕度"；而"最优性"只是一张性能证书，**安全只依赖可行性**，不依赖求解器是否找到全局最优。

**严谨定义（VGC, Value-Gradient Certificate）**：设状态 `x ∈ X ⊆ ℝ^n`、控制 `u ∈ U`、扰动 `w ∈ W`、控制仿射动力学 `ẋ = f(x,u,w) = f_0(x,w) + B_u(x)u`。由 v24 各证书（SDC/CAC/OASC/DCL/ACSC/PGEV）合成为一个带符号裕度
`h(x) = min{ 到 ⋃_k CertBox_k 的距离 − ε_margin, 到 DCL 禁域边界的距离, 到臂配空间边界的距离, 能量裕度 }`，
`h(x) ≥ 0` 当且仅当 `x ∈ D_v24`。给定 v24 已认证的停靠集 `S_stop` 与有限时域 `H`，定义安全值
`V_H(x) = max_{π} min_{w(·)} min_{t∈[0,H]} h(x(t))`，约束 `x(H) ∈ S_stop`（π 为非预测控制器）。
它是如下 HJI 变分不等式的粘性解：
`min{ h(x) − V_H(x), − max_{u∈U} min_{w∈W} ∇V_H(x)ᵀ f(x,u,w) } = 0`。
安全集 `S_vg = {x : V_H(x) ≥ 0}`。用近似值 `V̂`（误差上界 `δ_V`）时，实际使用收紧的屏障函数
`B(x) = V̂(x) − δ_V`，并以鲁棒 CBF 约束 `∇Bᵀ f(x,u,w) ≥ −α B(x), ∀w ∈ W` 作为在线安全滤波。

### 灵感 2（LoRA → 低秩不是为了省参数，而是为了让"适配"可证明）

**直觉**：v24 的 FSVC 冻结骨干、只调原型，因此无法适应新用户/新光照/新动力学；而全量微调又会立刻作废 conformal 覆盖与值函数证书。LoRA 的低秩更新 `ΔW_l = B_l A_l` 提供了一条中间道路：**秩 r 很小 ⇒ 谱范数 `‖B_lA_l‖₂` 可廉价精确计算 ⇒ 特征漂移可被显式界定 ⇒ conformal 分位数只需按漂移膨胀 ⇒ 适配后覆盖仍 ≥ 1−α**。同样的论证可用于**值函数网络**：`|V_adapt − V_base| ≤ δ_V`，于是用 `V_adapt − δ_V` 作 CBF，其安全集必是基座安全集的子集。

**关键反直觉点**：LoRA 的低秩通常被理解为"省显存/省带宽"的工程技巧；在本框架里，**秩是安全预算**——它把"微调"从不可审计的分布漂移，变成一条可证明的证书迁移定理。适配器越"大"（秩越高、谱范数越大），可释放的活性越多，但必须付出更大的误差膨胀（更保守的证书）。这正是最优控制可以介入的地方：**在秩预算与漂移预算下分配适配容量**。

**严谨定义（LRCA, Low-Rank Certified Adapter）**：基座特征 `φ_0(x) = f_{W_0}(x)`，适配后 `W_l = W_{0,l} + B_lA_l`，秩 `r = Σ_l rank(B_lA_l)`。设 `R` 为运行域半径、`L_φ` 为网络对权重扰动的联合 Lipschitz 常数、`L_E` 为非一致性误差 `E(x)`（定位误差/1−置信度）对特征的 Lipschitz 常数、`L_V` 为值函数对特征的 Lipschitz 常数。定义
`ρ(ΔW) = L_φ · max_l ‖B_lA_l‖₂ · R`（特征漂移上界），
`q̂'_α = q̂_α + L_E · ρ(ΔW)`（膨胀后的 conformal 分位数），
`δ_V = L_V · ρ(ΔW)`（值函数漂移上界）。
**适配器证书** `AdapterCert ≜ (rank ≤ r_max) ∧ (max_l‖B_lA_l‖₂ ≤ ρ_max) ∧ (δ_V ≤ δ_V_max) ∧ (在 D_calib 上 q̂'_α 的经验覆盖 Hoeffding 下界 ≥ 1−α)`。

### 灵感 3（两者统一：低秩值函数 + 证书定价的最优安全滤波 + 不确定性定价的主动取证）

**直觉**：v24 的 CAC 把"未知"一律当作"有人"，这是安全的，但活性代价随未知体积线性增长。既然对偶变量 `λ` 已经能给出每张证书的活性影子价格，那么"未知"本身也有价格 `λ_unc`：**把传感器指向哪里、往哪里走一步以获得视野，本质上是在购买"把未知变成已知"的期权**。主动感知因此可以写成一个小规模最优控制问题：最大化"期望活性增益 − 感知能耗"，但**只允许通过 CAC 既有规则把未知转为已知，绝不直接释放自由空间**。

**统一**：低秩适配器同时适配感知骨干、值函数网络与动力学模型；最优控制在这些适配后的证书上求最不保守的可行轨迹；影子价格同时用于活性审计与主动取证的价值排序。共享状态扩展为
`ζ_v25 = ζ_v24 ∪ (V̂, δ_V, λ, A_active, ΔW, ρ, q̂', b_t, λ_unc)`。
统一准入门 **HPC-O = HPC-E++ ∪ VGC ∪ CPOC ∪ LRCA ∪ AEAC**，且
`Exec_v25 = Exec_v24 ∩ Fil_vg ∩ Fil_oc ∩ Fil_lr ∩ Fil_ae ⊆ Exec_v24`。

## 2. 设计原则（在 P42 基础上新增 P43–P46）

**P43 证书域内最优律（Optimal-within-Certificate-Domain）**
VGC 只在 `D_v24` 内求可行性核，`S_vg ⊆ D_v24`；v24 的静态裕度被视为 `D_v24` 的一个保守控制器，故 `S_static ⊆ S_vg`。CPOC 的最优性只做性能排序，**安全仅依赖可行性与 `S_stop` 可达**。`Exec_v25 = Exec_v24 ∩ Fil_vg ∩ Fil_oc ∩ Fil_lr ∩ Fil_ae ⊆ Exec_v24`。

**P44 影子价格只读律（Read-Only Shadow Prices）**
对偶变量 `λ` 只用于审计、解释与主动取证的价值排序，**绝不用于放松任何证书约束**；控制路径中不存在"用 λ 调阈值"的分支。每次决策输出最优性证书 `OC = (π*, λ*, A_active, δ_V, solver_status)`，其中 `A_active` 为活跃约束集，`λ*` 与 `OC` 一起进入 merkle 审计链。

**P45 低秩可证明适配律（Provable Low-Rank Adaptation）**
适配器 `ΔW = BA` 必须同时满足秩上限、谱范数上限、膨胀分位数后的覆盖下界、以及值漂移上限；值函数适配一律用 `V̂_adapt − δ_V` 作 CBF，从而 `S_adapt ⊆ S_base`。任一条件不满足即回退基座模型（等价 v24），绝不"带病上线"。

**P46 不确定性定价取证律（Uncertainty-Priced Evidence Acquisition）**
CAC 的"未知即有人"约束携带影子价格 `λ_unc ≥ 0`；主动感知只通过 CAC 既有规则把未知转为已知（可签发 AbsCert 或翻转为有人），**绝不直接释放自由空间**；感知预算超限或主动感知失效时，回退 v24 的保守假设。

## 3. 与基线的接口（如何退化）

- VGC 失效或 `S_vg` 为空 ⇒ 回退 v24 静态裕度与证书过滤（更保守）；
- CPOC 求解超时/不可行 ⇒ 使用 v24 的证书过滤 + 已认证安全停靠，安全不变；
- LRCA 适配器不达标 ⇒ 冻结基座模型（等价 v24）；多适配器切换失败 ⇒ 回退基座版本；
- AEAC 失效 ⇒ 不做主动感知，未知一律保守（等价 v24 的 CAC）；
- 四者全失效 ⇒ `Exec_v25 = Exec_v24`；
- **安全继承方向**：VGC 只在证书域内、CPOC 只增加约束、LRCA 只做收紧式适配、AEAC 只走 CAC；任意失效都向 v24 单调退化。

## 4. 预期贡献

1. **值函数证书**：把点式证书过滤升级为集合式可行性核，给出 `S_static ⊆ S_vg ⊆ D_v24` 的夹逼与安全单调性，用动态可达性替换静态保守裕度。
2. **证书影子价格**：把 KKT 对偶解释为"活性代价"，给出可审计的最优性证书 `OC` 与一阶活性损失分解 `Σ λ_i · slack_i`。
3. **低秩可证明适配**：LoRA 谱范数 → 特征/误差/值函数漂移 → 覆盖与安全迁移的显式定理；**秩即安全预算**，并给出秩预算的边际增益分配。
4. **不确定性定价的主动取证**：把 AbsCert 的活性价值变成可优化的感知控制目标，直接缓解 v21 的"缺席幻觉"与活性坍缩。
5. **统一准入门 HPC-O**：VGC ∪ CPOC ∪ LRCA ∪ AEAC 与 v24 六证合成，`Exec_v25 ⊆ Exec_v24` 闭环。

## 5. 本轮最大风险

**一句话**：整个方案把 v24 "保守但可靠"的保证，换成了"最优但依赖模型"的保证——HJI 值函数的近似误差、LoRA 漂移界在激活空间的失效、以及动力学/扰动模型失配，可能让"最小限制安全滤波"把真实不安全状态误判为可停靠，即**可证明的乐观（certified optimism）**。

## 1. 关键算法骨架

```python
# ============================================================
# IP-440 Value-Gradient Certificate (VGC)
# ============================================================
@dataclass
class ValueGradientCertificate:
    V_hat: Callable[[np.ndarray], float]          # 近似 HJI 值函数
    gradV: Callable[[np.ndarray], np.ndarray]     # ∇V̂
    delta_V: float                                # 近似误差上界（保守）
    S_stop: Callable[[np.ndarray], bool]          # v24 认证停靠集
    W_samples: list[np.ndarray]                   # 扰动采样（证书界导出）
    alpha: float = 1.0

    def margin(self, x: np.ndarray) -> float:
        # 近似误差只收紧：用 V̂ − δ_V 判定，绝不用 V̂ 本身
        return float(self.V_hat(x) - self.delta_V)

    def safe(self, x: np.ndarray) -> bool:
        return self.margin(x) >= 0.0

    def robust_cbf_row(self, x, f0, Bu):
        """控制仿射：f(x,u,w)=f0(x,w)+Bu(x)u。
        CBF: ∇Bᵀ(f0+Bu u) ≥ -α B, ∀w。
        取最坏扰动后得到线性约束 aᵀu ≥ b。"""
        g = self.gradV(x)
        worst = min(float(g @ f0(x, w)) for w in self.W_samples)
        a = Bu(x).T @ g
        b = -self.alpha * self.margin(x) - worst
        return a, b

    def hji_residual(self, x, H) -> float:
        """在线监控：|min{h−V̂, −max_u min_w ∇V̂ᵀf}|；超限则增大 δ_V 或回退 v24。"""
        g = self.gradV(x)
        h = H(x)
        second = -max(min(float(g @ f(x, u, w))
                           for w in self.W_samples) for u in self.U_samples)
        return abs(min(h - self.V_hat(x), second))

# IP-441 Certificate-Priced Optimal Control (CPOC)
# ============================================================
@dataclass
class OptimalityCertificate:
    plan: 'Plan'
    lam: np.ndarray              # λ_i ≥ 0，只读
    active: set[int]             # A_active
    delta_V: float
    solver_status: str
    cost: float

class CertificatePricedMPC:
    def __init__(self, horizon: int = 10, dt: float = 0.02):
        self.H, self.dt = horizon, dt

    def solve(self, x0, u_nom, vgc: ValueGradientCertificate,
              v24_filters, cost_fn) -> Optional[OptimalityCertificate]:
        """min Σ c(x,u)  s.t.  v24 全部证书硬约束 ∧ 鲁棒 CBF ∧ x(H)∈S_stop。
        安全只依赖可行解；最优性由 QP/SQP 的 KKT 提供。"""
        a, b = vgc.robust_cbf_row(x0, f0, Bu)
        prob = build_ocp(x0, u_nom, vgc, v24_filters, cost_fn,
                         extra_ineq=(a, b), terminal=vgc.S_stop)
        sol = solve_qp_or_sqp(prob, warm_start=self.last_sol)
        self.last_sol = sol
        if not sol.feasible:
            return None                      # 回退 v24 证书过滤 + 安全停靠
        lam = np.maximum(sol.dual, 0.0)      # 只读影子价格
        return OptimalityCertificate(sol.trajectory, lam, sol.active,
                                     vgc.delta_V, sol.status, sol.cost)

    def liveness_decomposition(self, oc: OptimalityCertificate,
                               slack_v24: np.ndarray) -> float:
        """一阶活性损失：Σ λ_i · slack_i。仅用于审计，不反馈控制。"""
        return float(oc.lam @ slack_v24)

# IP-442 Low-Rank Certified Adapter (LRCA)
# ============================================================
@dataclass
class LoRAAdapter:
    B: list[np.ndarray]
    A: list[np.ndarray]

    @property
    def rank(self) -> int:
        return sum(int(np.linalg.matrix_rank(b @ a)) for b, a in zip(self.B, self.A))

    def spectral_bound(self) -> float:
        return max(float(np.linalg.norm(b @ a, 2)) for b, a in zip(self.B, self.A))

@dataclass
class AdapterCert:
    adapter: LoRAAdapter
    q_inflated: float
    rho: float
    delta_V: float

class LoRACertifiedAdapter:
    def __init__(self, L_phi, L_E, L_V, R, r_max, rho_max,
                 delta_V_max, alpha=0.01, delta_hoeff=0.001):
        self.L_phi, self.L_E, self.L_V, self.R = L_phi, L_E, L_V, R
        self.r_max, self.rho_max, self.delta_V_max = r_max, rho_max, delta_V_max
        self.alpha, self.delta_hoeff = alpha, delta_hoeff

    def drift_bound(self, ad: LoRAAdapter) -> float:
        return self.L_phi * ad.spectral_bound() * self.R

    def coverage_transfer(self, ad: LoRAAdapter, q_base: float):
        """|E_adapt(x) − E_base(x)| ≤ L_E·ρ ⇒ 用 q' = q_base + L_E·ρ 时
        P(E_adapt ≤ q') ≥ P(E_base ≤ q_base) ≥ 1−α。"""
        rho = self.drift_bound(ad)
        return q_base + self.L_E * rho, rho

    def value_drift_bound(self, ad: LoRAAdapter) -> float:
        return self.L_V * self.drift_bound(ad)

    def certify(self, ad: LoRAAdapter, q_base: float,
                D_calib) -> Optional[AdapterCert]:
        if ad.rank > self.r_max:
            return None
        if ad.spectral_bound() > self.rho_max:
            return None
        q_infl, rho = self.coverage_transfer(ad, q_base)
        dV = self.value_drift_bound(ad)
        if dV > self.delta_V_max:
            return None
        # 经验覆盖下界（Hoeffding）仍需 ≥ 1−α
        n = len(D_calib)
        if n < 30:
            return None
        emp = sum(1 for e in D_calib if e <= q_infl) / n
        if emp - math.sqrt(math.log(1 / self.delta_hoeff) / (2 * n)) < 1 - self.alpha:
            return None
        return AdapterCert(ad, q_infl, rho, dV)

    def tightened_value(self, ad: LoRAAdapter, V_adapt):
        """用 V̂_adapt − δ_V 作 CBF ⇒ S_adapt ⊆ S_base。"""
        dV = self.value_drift_bound(ad)
        return lambda x: float(V_adapt(x) - dV)

# IP-444 HPC-O 统一准入 + IP-445 DAL 审计

@dataclass
class HPCOptimalGate:
    hpc_eplusplus: 'HPCEPlusPlus'
    vgc: ValueGradientCertificate
    mpc: CertificatePricedMPC
    lrca: LoRACertifiedAdapter
    dal: 'DualAuditLedger'

    def admits(self, plan, x, v24_args, v24_filters,
               adapter_cert: Optional[AdapterCert],
               base_model, adapted_model) -> tuple[bool, Optional[OptimalityCertificate]]:
        # 1) v24 六证
        if not self.hpc_eplusplus.admits(plan, *v24_args):
            return False, None
        # 2) 值函数可行性核（收紧 CBF）
        if not self.vgc.safe(x):
            return False, None
        # 3) 适配器：认证则用收紧值函数，否则回退基座
        V_eff = (self.lrca.tightened_value(adapter_cert.adapter, adapted_model.V)
                 if adapter_cert is not None else base_model.V)
        vgc_eff = replace(self.vgc, V_hat=V_eff,
                          delta_V=self.vgc.delta_V + (adapter_cert.delta_V
                                                      if adapter_cert else 0.0))
        # 4) 证书定价最优控制（安全仅依赖可行解）
        oc = self.mpc.solve(x, plan.u_nom, vgc_eff, v24_filters, plan.cost_fn)
        if oc is None:
            return False, None
        # 5) 审计落账（λ 只读）
        self.dal.append(oc, adapter_id=id(adapter_cert), V_version=id(V_eff))
        return True, oc

                   if adapter is not None else None)

            v24_filters=self._v24_filters(), adapter_cert=ad_cert,
```

## 3. 正确性论证

### 引理 5（VGC 夹逼与近似只收紧）
**陈述**：若 `V_H` 精确且 `S_stop ⊆ D_v24`，则 `S_static ⊆ S_vg ⊆ D_v24`。使用近似 `V̂` 与误差界 `δ_V ≥ |V̂ − V_H|` 时，`S_vg^δ = {V̂ − δ_V ≥ 0} ⊆ S_vg`。

**证明**：
1. `S_vg ⊆ D_v24`：`V_H` 是 `D_v24` 上带终端约束的可行性核，其非负水平集按定义是"存在满足 `h ≥ 0` 且终止于 `S_stop` 的轨迹"的状态集，故每个 `x ∈ S_vg` 有 `h(x) ≥ 0`，即 `x ∈ D_v24`。
2. `S_static ⊆ S_vg`：设 v24 静态控制器对任意 `x ∈ S_static` 保持 `h(x(t)) ≥ d_static ≥ 0` 并在 `H` 内进入 `S_stop`。则该控制器是可行策略，故 `V_H(x) ≥ min_t h ≥ d_static ≥ 0`，即 `x ∈ S_vg`。
3. 近似：`V̂ ≥ V_H − δ_V`，故 `V̂ − δ_V ≥ 0 ⇒ V_H ≥ 0`，即 `S_vg^δ ⊆ S_vg`。∎

### 引理 6（影子价格只读，不改变可行域）
**陈述**：CPOC 的准入判定与 `λ` 无关；`λ` 仅在求解后计算。对约束右端 `b_i` 的小扰动，`∂J*/∂b_i = −λ_i`，故一阶活性损失为 `Σ_i λ_i · slack_i`。

**证明**：`admits` 只检查 `sol.feasible` 与 v24 过滤器，`λ = max(sol.dual, 0)` 在可行性判定之后计算，且不写回任何阈值。KKT 包络定理给出 `∂J*/∂b_i = −λ_i`（`λ_i ≥ 0` 对应 `g_i ≤ 0` 的乘子），对 `slack` 作一阶展开即得活性损失分解。∎

### 引理 7（LoRA 覆盖迁移）
**陈述**：设非一致性误差满足 `|E_{W'}(x) − E_W(x)| ≤ L_E ρ(ΔW)` 对所有 `‖x‖ ≤ R` 成立，`q̂'_α = q̂_α + L_E ρ`。则适配后 `P(E_{W'} ≤ q̂'_α) ≥ P(E_W ≤ q̂_α) ≥ 1−α`。

**证明**：由 Lipschitz 界，`E_W(x) ≤ q̂_α ⇒ E_{W'}(x) ≤ E_W(x) + L_Eρ ≤ q̂_α + L_Eρ = q̂'_α`，故事件包含 `{E_W ≤ q̂_α} ⊆ {E_{W'} ≤ q̂'_α}`，取概率并用基座 conformal 覆盖即得。∎

### 引理 8（LoRA 值函数安全迁移）
**陈述**：若 `|V_adapt(x) − V_base(x)| ≤ δ_V` 于 `D_v24` 上一致成立，则以 `B = V_adapt − δ_V` 作 CBF 时 `S_adapt^δ = {V_adapt − δ_V ≥ 0} ⊆ S_base = {V_base ≥ 0}`。

**证明**：`V_adapt − δ_V ≥ 0 ⇒ V_base ≥ V_adapt − δ_V ≥ 0`。∎

### 引理 9（主动取证不扩张自由空间）
**陈述**：AEAC 的任意感知动作只更新信念 `b_t` 与 CAC 覆盖图 `Cov_t`；AbsCert 的签发仍要求 `x ∈ Cov_t ∧ 召回下界 κ_c ∧ 手势在场翻转检查`。故 AEAC 不改变 `Exec_v24` 的自由空间语义，只改变证据获得的时间。

**证明**：AEAC 的动作集合只作用于传感器/底座位姿，不写入证书阈值或规则库；所有新证据必须经 `CAC` 的既有判定才能签发 AbsCert。因此任何新释放的自由空间在 v24 的 CAC 下同样被允许，`Fil_ae` 只可能提前（而非扩大）可行集。∎

### 定理（HPC-O 的单调完备性）
**陈述**：`HPCOptimalGate.admits(π) = True` 当且仅当 π 同时满足：(1) v24 六证；(2) 收紧值函数可行性核；(3) CPOC 存在满足全部证书硬约束与终端停靠的可行解；(4) 若使用适配器则其 `AdapterCert` 通过（否则回退基座）；(5) AEAC 只经 CAC 产生证据。且 `Exec_v25 ⊆ Exec_v24`。

**证明**：必要性由 `admits` 的五个连言直接得到。充分性：五条件满足时，引理 5–9 分别保证值函数近似只收紧、影子价格不改变可行域、适配覆盖与值安全迁移、主动取证不扩张自由空间；又 CPOC 的约束集包含全部 v24 证书硬约束，故任何被准入的 π 必在 `Exec_v24` 中。∎

> **口径说明**：上述单调性采用"`Exec_v24` 由证书域 `D_v24` 定义，静态裕度只是其一个保守控制器"的口径。若审稿人把 `Exec_v24` 严格理解为"静态裕度过滤后的计划集"，则 `S_static ⊆ S_vg` 会使 v25 出现扩张——这是本方案必须在形式化层面明确的一个定义选择（见风险 R1）。

```python
class OntologyNode(Enum):
    HEAD = "head"
    TORSO = "torso"

class OntologyGraph(nx.DiGraph):
    """轻量本体图：节点为关键部件，边为尺度不变相对位置"""
    def __init__(self, category: str):
        super().__init__()
        self.category = category
        for node in OntologyNode:
            self.add_node(node)
        # 基于类别统计填充边：如 "人" 有头-肩、肩-躯干等边
        self._load_prior(category)
    
    def _load_prior(self, category: str):
        """从类别先验统计加载边：仅在尺度不变子集上有效"""
        prior_path = f"ontology_priors/{category}.json"
        if os.path.exists(prior_path):
            with open(prior_path) as f:
                prior = json.load(f)
            for edge, prob in prior.items():
                if prob > 0.5:  # 只保保留概率高的边
                    parts = edge.split("_")
                    self.add_edge(OntologyNode[parts[0]], OntologyNode[parts[1]], weight=prob)
    
    def consistency_score(self, detected_parts: set[OntologyNode]) -> float:
        """计算检测到的部件集合与本体图的一致性评分"""
        if len(detected_parts) < 2:
            return 0.0
        induced_subgraph = self.subgraph(detected_parts)
        if not nx.is_connected(induced_subgraph):
            return 0.0
        # 评分 = 平均边权 / 期望边权
        edges = list(induced_subgraph.edges(data='weight'))
        if not edges:
            return 0.0
        actual_avg = sum(w for _, _, w in edges) / len(edges)
        expected_avg = sum(self.out_degree(n, weight='weight', default=1.0) for n in induced_subgraph.nodes()) / (2 * len(induced_subgraph.nodes()))
        return min(1.0, actual_avg / max(expected_avg, 1e-3))

class CausalRule:
    """带因果前件的规则：φ = (premise, obligation, deadline, priority)"""
    def __init__(self, rule_id: str, premise: str, obligation: str, 
                 deadline: float, priority: int = 0):
        self.rule_id = rule_id
        self.premise = premise          # 因果前件描述
        self.obligation = obligation    # O/F/P 描述
        self.deadline = deadline        # τ：期限
        self.priority = priority
        self.active_window: tuple[float, float] = None  # (t_start, t_end)
    
    def check_premise(self, state_history: list[RobotState]) -> bool:
        """检查因果前件是否在时间窗口内被观测到"""
        # 简化：检查是否有观测到与 premise 匹配的状态变化
        # 实际实现将使用时间窗口滤波
        return self._match_causal_pattern(state_history)
    
    def _match_causal_pattern(self, state_history: list[RobotState]) -> bool:
        # 因果模式匹配：检查前件在前、义务在后的时序
        # 实际实现使用 LTL 或简化的时间窗口检查
        if len(state_history) < 2:
            return False
        # 简化检查：是否检测到人的移动方向远离机器人
        recent_states = state_history[-10:]  # 最近 10 帧
        approaching = any(
            s.distance_to_robot < s.prev_distance_to_robot 
            for s in recent_states[1:]
        )
        return approaching

class DeonticComplianceLayerHDL:
    """扩展版 HDL：包含因果前件编译与动态激活"""
    def __init__(self, rule_library: list[CausalRule], v20_geom_domain: GeometryDomain):
        self.rule_library = rule_library
        self.geom_domain = v20_geom_domain
        self.active_obligations: set[str] = set()
        self.rule_versions: dict[str, int] = {}  # Merkle 版本追踪
    
    def compile_rules(self, plan: Plan) -> Filters:
        """编译规则为过滤器链：F/O/P + 因果前件"""
        filters = {
            'domain_shrink': set(self.geom_domain),  # 初始为几何域
            'obligation_filters': {},              # O → {plan: φ_rule ∧ τ}
            'permission_unlocks': set()            # P → 解除的 DCL 限制
        }
        
        for rule in self.rule_library:
            # F 规则：域收缩
            filters['domain_shrink'] = filters['domain_shrink'] ∩ rule.domain_shrink()
            
            # O 规则：带因果前件的期限过滤器
            if rule.check_premise(plan.state_history):
                # 前件成立 → 义务激活
                obligation_set = {plan : 
                    ∃t' ≤ τ_rule, state(t') ∈ YieldSet ∧ φ_rule(t')}
                filters['obligation_filters'][rule.rule_id] = obligation_set
                self.active_obligations.add(rule.rule_id)
            else:
                # 前件失败 → 义务自动释放，不参与求交
                pass
            
            # P 规则：仅当高置信意图 ∧ AbsCert ∧ 模态佐证 ∧ φ_rule 成立时解除
            # (由 HPC-E+ 四证准入门协调)
        
        # 冲突消解 = 交（最严者胜）
        all_filters = [filters['domain_shrink']] + list(filters['obligation_filters'].values())
        if all_filters:
            filters['domain_shrink'] = all_filters[0].intersection(*all_filters[1:])
        
        # 记录版本用于 Merkle 审计
        for rule in self.rule_library:
            self.rule_versions[rule.rule_id] = rule.version
        
        return filters
    
    def apply_filters(self, plan: Plan, current_state: RobotState) -> bool:
        """对计划应用过滤器：域收缩 ∧ 激活义务 ∧ 许可检查"""
        # 1. 域收缩
        if current_state not in self.filters['domain_shrink']:
            return False
        
        # 2. 激活义务检查
        for rule_id in list(self.active_obligations):
            rule = next(r for r in self.rule_library if r.rule_id == rule_id)
            if not rule.check_premise(plan.state_history):
                # 因果前件失效 → 自动释放，继续检查下一个
                self.active_obligations.discard(rule_id)
                continue
            # 义务检查：计划必须满足让位条件
            if not self._check_obligation_compliance(plan, rule):
                return False
        
        # 3. 许可检查（由 HPC-E+ 协调）
        # P 规则仅在 AllCert 通过时解除 DCL 限制
        
        return True
    
    def _check_obligation_compliance(self, plan: Plan, rule: CausalRule) -> bool:
        """检查计划是否满足带期限义务"""
        # 简义化：检查计划在 τ_rule 时间窗口内是否包含让位状态
        τ = rule.deadline
        # 检查计划前缀 ≤ τ 是否进入让位状态
        prefix_state = plan.prefix(τ)
        return prefix_state in rule.yield_set

class BudgetReallocationEngine:
    """机构状态到证据预算的双映射引擎"""
    def __init__(self, config_path: str = "budget_config.yaml"):
        with open(config_path) as f:
            config = yaml.safe_load(f)
        self.mapping_fn = config['mapping_fn']  # B_evidence = f(Q_arm)
        self.budget_history: list[float] = []
        self.last_approved_budget: float = config['initial_budget']
    
    def compute_budget(self, Q_arm: Configuration) -> float:
        """根据机构状态计算当前证据预算"""
        try:
            B = self.mapping_fn(Q_arm)
            if B <= 0:
                B = self.last_approved_budget  # 失败回退
            self.budget_history.append(B)
            return B
        except Exception:
            self.budget_history.append(self.last_approved_budget)
            return self.last_approved_budget
    
    def request_reallocation(self, Q_arm_new: Configuration, 
                            Q_arm_old: Configuration) -> tuple[bool, float]:
        """请求预算重分配：机构配置变化时触发"""
        B_new = self.compute_budget(Q_arm_new)
        B_old = self.last_approved_budget
        
        # 预算变化比例
        ratio = B_new / max(B_old, 1e-3)
        
        # 安全边界检查：预算不得意外膨胀
        if ratio > self._max_expansion_factor():
            # 预算过度膨胀 → 拒绝，保持旧预算
            return False, B_old
        
        # 预算重分配通过，更新批准预算
        self.last_approved_budget = B_new
        return True, B_new
    
    def _max_expansion_factor(self) -> float:
        """最大膨胀因子：防止预算意外膨胀"""
        return 1.5  # 最大 50% 膨胀

class BudgetReallocationCertificate:
    """BRC：证据预算证书，随机构状态动态调整"""
    def __init__(self, budget_engine: BudgetReallocationEngine):
        self.budget_engine = budget_engine
        self.current_budget: float = budget_engine.last_approved_budget
    
    def update_with_arm_config(self, Q_arm: Configuration) -> bool:
        """随着机械臂配置变化更新预算"""
        success, budget = self.budget_engine.request_reallocation(Q_arm, Q_arm)
        if success:
            self.current_budget = budget
            return True
        else:
            # 预算重分配失败：回退至上一批准预算
            self.current_budget = self.budget_engine.last_approved_budget
            return False
    
    def admits(self, plan: Plan, current_budget: float) -> bool:
        """预算准入：计划的能量/证据负载不得超过当前预算"""
        plan_evidence_load = self._compute_evidence_load(plan)
        return plan_evidence_load <= self.current_budget
    
    def _compute_evidence_load(self, plan: Plan) -> float:
        """计算计划的证据负载（简化：能量消耗的代理）"""
        # 实际实现将统计障碍证书数量、义务复杂度等
        return plan.estimated_energy * 0.8  # 简化代理

class CertificateFederatedConsensusQuintuplePlus(CertificateFederatedConsensusPlusPlusHierarchical):
    """CFC++++：在 CFC+++ 基础上增加本体一致性、因果规则一致性、预算重分配一致性"""
    
    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            # 基础条件
            count_ok = len(votes) >= self.N - self.F
            modalities = {v.modality for v in votes.values()}
            modality_ok = len(modalities) >= self.M_MIN_MODALITIES
            layer_ok = self._check_layer_consistency(votes)
            
            # CFC+++ 新增三层一致性
            ce_sync_ok = all(v.ce_version == votes[next(iter(votes))].ce_version 
                           for v in votes.values())
            fs_valid_ok = all(v.few_shot_valid for v in votes.values())
            ip_attest_ok = all(v.ip_attested for v in votes.values())
            
            # CFC++++ 新增三层一致性
            ontology_ok = self._check_ontology_consistency(votes)
            causality_ok = self._check_causality_consistency(votes)
            budget_ok = self._check_budget_consistency(votes)
            
            if all([count_ok, modality_ok, layer_ok, ce_sync_ok, fs_valid_ok, 
                    ip_attest_ok, ontology_ok, causality_ok, budget_ok]):
                results[key] = self._majority_with_outlier_filter(votes)
            else:
                results[key] = "CI"
        return results
    
    def _check_ontology_consistency(self, votes: dict) -> bool:
        """检查本体一致性：所有投票者的本体图结构一致"""
        # 简化：检查是否所有投票者都检测到了相同类别的相同部件
        categories = {v.detected_category for v in votes.values()}
        if len(categories) > 1:
            return False  # 类别不一致
        # 检查部件检测一致性
        part_sets = {v.detected_parts for v in votes.values()}
        if len(part_sets) > 1:
            return False  # 部件检测不一致
        return True
    
    def _check_causality_consistency(self, votes: dict) -> bool:
        """检查因果规则一致性：因果前件评估结果一致"""
        premise_results = {v.causal_premise_result for v in votes.values()}
        if len(set(premise_results)) > 1:
            return False  # 因果前件评估不一致
        return True
    
    def _check_budget_consistency(self, votes: dict) -> bool:
        """检查证据预算一致性：预算评估结果一致"""
        budget_estimates = {v.budget_estimate for v in votes.values()}
        # 允许一定误差范围的一致性
        budget_set = set(budget_estimates)
        if len(budget_set) > 3:  # 超过 3 个不同的预算估计值视为不一致
            return False
        return True
```

```python
    cesc: CloudEdgeSyncCertificate
    fsvc: FewShotValidator
    ipam: IPAttestModule
    oasc: OntologyAwareSemanticCertificate
    cdl: DeonticComplianceLayerHDL
    brc: BudgetReallocationCertificate
    
    def admits(self, plan, x, v, z, E_res, margin_req, modules: list[str], 
               Q_arm: Configuration = None) -> bool:
        # 1. HPC-E 基础验证
        if not self.hpc_e.admits(plan, x, v, z, E_res, margin_req):
            return False
        
        # 2. 云边同步验证
        if not self.cesc.sync_predicate():
            return False
        
        # 3. 少样本有效验证
        V = self.cesc.current_version()
        if not self.fsvc.validate(V):
            return False
        
        # 4. 知识产权认证验证
        for mod in modules:
            if not self.ipam.verify_module(mod):
                return False
        
        # 5. 本体证书验证
        if not self.oasc.admits(plan, x, θ_ont=0.6):
            return False
        
        # 6. 因果义务验证
        if not self.cdl.admits(plan):
            return False
        
        # 7. 证据预算验证
        if Q_arm is not None:
            if not self.brc.admits(plan, current_budget=self.budget_engine.current_budget):
                return False
        else:
            # 无机构信息时使用默认预算
            if not self.brc.admits(plan, current_budget=DEFAULT_BUDGET):
                return False
        
        return True

# A.5 CFC++++（含本体/因果/预算三层一致性检查）
# ============================================================
class CertificateFederatedConsensusQuintuplePlus(CertificateFederatedConsensusPlusPlusHierarchical):
    """CFC++++：在 CFC+++ 基础上增加本体一致性、因果规则一致性、预算重分配一致性"""
    
    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            # 基础条件
            count_ok = len(votes) >= self.N - self.F
            modalities = {v.modality for v in votes.values()}
            modality_ok = len(modalities) >= self.M_MIN_MODALITIES
            layer_ok = self._check_layer_consistency(votes)
            
            # CFC+++ 新增三层一致性
            ce_sync_ok = all(v.ce_version == votes[next(iter(votes))].ce_version 
                           for v in votes.values())
            fs_valid_ok = all(v.few_shot_valid for v in votes.values())
            ip_attest_ok = all(v.ip_attested for v in votes.values())
            
            # CFC++++ 新增三层一致性
            ontology_ok = self._check_ontology_consistency(votes)
            causality_ok = self._check_causality_consistency(votes)
            budget_ok = self._check_budget_consistency(votes)
            
            if all([count_ok, modality_ok, layer_ok, ce_sync_ok, fs_valid_ok, 
                    ip_attest_ok, ontology_ok, causality_ok, budget_ok]):
                results[key] = self._majority_with_outlier_filter(votes)
            else:
                results[key] = "CI"
        return results
    
    def _check_ontology_consistency(self, votes: dict) -> bool:
        """检查本体一致性：所有投票者的本体图结构一致"""
        # 简化：检查是否所有投票者都检测到了相同类别的相同部件
        categories = {v.detected_category for v in votes.values()}
        if len(categories) > 1:
            return False  # 类别不一致
        # 检查部件检测一致性
        part_sets = {v.detected_parts for v in votes.values()}
        if len(part_sets) > 1:
            return False  # 部件检测不一致
        return True
    
    def _check_causality_consistency(self, votes: dict) -> bool:
        """检查因果规则一致性：因果前件评估结果一致"""
        premise_results = {v.causal_premise_result for v in votes.values()}
        if len(set(premise_results)) > 1:
            return False  # 因果前件评估不一致
        return True
    
    def _check_budget_consistency(self, votes: dict) -> bool:
        """检查证据预算一致性：预算评估结果一致"""
        budget_estimates = {v.budget_estimate for v in votes.values()}
        # 允许一定误差范围的一致性
        budget_set = set(budget_estimates)
        if len(budget_set) > 3:  # 超过 3 个不同的预算估计值视为不一致
            return False
        return True

class SixCertificatePipeline:
    def __init__(self, config: dict):
        # 核心证书模块
        self.cesc = CloudEdgeSyncCertificate(config['pk_cloud'])
        self.fsvc = FewShotValidator(config['backbone'], config['calibrator'])
        self.ipam = IPAttestModule()
        self.hpc_e = config['hpc_e']
        self.oasc = OntologyAwareSemanticCertificate(...)  # 初始化
        self.cdl = DeonticComplianceLayerHDL(...)  # 初始化
        self.brc = BudgetReallocationCertificate(...)  # 初始化
        self.hpc_eplusplus = HPCEPlusPlus(
            hpc_e=self.hpc_e,
            cesc=self.cesc,
            fsvc=self.fsvc,
            ipam=self.ipam,
            oasc=self.oasc,
            cdl=self.cdl,
            brc=self.brc
        )
        self.cfc = CertificateFederatedConsensusQuintuplePlus(config['N'], config['F'])
        
        # 注册核心模块专利标记（设计期一次性完成）
        self._register_patents()

        self.ipam.register_module("gic", ["IP-428"], ["asymmetric_threshold", "conformal_intent", "gesture_presence_flip"])
        self.ipam.register_module("pgev", ["IP-431", "IP-434"], ["hierarchical_energy", "energy_viability_kernel"])
        self.ipam.register_module("acsc", ["IP-432"], ["config_space_certbox", "arm_energy_integral"])
        self.ipam.register_module("dcsc", ["IP-433"], ["deep_conformal", "phi_privacy", "calibration_coverage"])

        self.ipam.register_module("hpc_eplusplus", ["IP-434a"], ["six_certificate_gate", "monotonic_exec_chain_v24"])
    
    def step(self, sensor_data: dict, cloud_update: Optional[dict] = None, 
             arm_config: Optional[Configuration] = None) -> tuple[bool, dict]:
        """单步执行：感知 → 六证生成 → 共识 → 六证准入 → 执行决策"""
        # 1. 处理云端更新（异步，非阻塞）
        if cloud_update:
            self.cesc.receive_cloud_update(cloud_update['V'], cloud_update['artifacts'])
        
        # 2. 边端感知 + 六证生成
        certs = self._generate_six_certificates(sensor_data, arm_config)
        
        # 3. 联邦共识（CFC++++）
        consensus = self.cfc.consensus_round()
        
        # 4. 尝试原子切换（若有待验证版本）
        if self.cesc.V_pending:
            self.cesc.atomic_switch()
        
        # 5. HPC-E++ 六证准入
        plan = self._plan_from_consensus(consensus)
        modules_involved = self._modules_in_plan(plan)
        admitted = self.hpc_eplusplus.admits(
            plan, sensor_data['x'], sensor_data['v'], sensor_data['z'],
            sensor_data['E_res'], sensor_data['margin_req'], modules_involved, Q_arm
        )
        
        return admitted, {
            'plan': plan if admitted else None,
            'consensus': consensus,
            'version': self.cesc.current_version(),
            'ontology_consistency': self.oasc.consistency if 'oasc' in dir() else 1.0,
            'causal_active': len(self.cdl.active_obligations),
            'budget': self.brc.current_budget,
            'offline_mode': self.cesc.offline_mode
        }
    
    def _generate_six_certificates(self, sensor_data: dict, arm_config: Configuration) -> dict:
        """生成六感知证书：SDC + CAC + DCSC + OASC + CDL洞察 + BRC预算"""
        certs = {}

        for det in sensor_data['detections']:
            certs[f"SDC_{det.id}"] = self._make_sdc(det)
        # CAC: 覆盖与缺席证书
        certs["CAC"] = self._make_cac(sensor_data)
        # DCSC: 深度 conformal 语义证书
        for frame in sensor_data['camera_frames']:
            certs[f"DCSC_{frame.id}"] = self.fsvc.calibrate_single(frame.data)
        # OASC: 本体感知语义证书
        for det in sensor_data['detections']:
            certs[f"OASC_{det.id}"] = self._make_oasc(det)
        # CDL: 因果义务层洞察
        certs["CDL"] = self._make_cdl_insight(sensor_data)
        # BRC: 证据预算证书
        if arm_config is not None:
            certs["BRC"] = self._make_brc(arm_config)
        return certs
```
