# 第 3 轮（灵感循环第 3 轮；本轮灵感：「状态隔离」×「智能体」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440）。
> 本轮纪律：**继续在前人基础上改进，而不是推倒重来**——ToolGauge 的六段闭环 6C、MTC/TCV 工具契约、
> MP-Φ 摊销校准、L-Box 共形假设、MODGAUGE 五不变式与严格退化链全部保留。
> 本轮只做一件事：把第 2 轮末尾点名的最大风险（跨盲区强相关污染）从「事后全局急停」升级为「结构性的状态隔离」，
> 并顺带修复第 2 轮伪代码中已暴露的并发共享状态竞态（见 §5）。

## 双灵感映射（隔离是一等安全机制，不是运维补丁）

| 灵感词 | 第 2 轮对象 | 升级为 | 一句话动机 |
|---|---|---|---|
| 状态隔离 | 全局共享 AP-Cal 先验 + 全局 P-Quarantine 断路器 | **快照隔离 + 私有先验头 + 先验 MVCC + 污点回滚** | 污染不该靠「事后全停」去猜，而应由「边界」在源头阻断，且能按溯源精确回滚 |
| 智能体 | 单体、内联、直接改共享 `M.mreg/M.dpe` 的 6C 函数 | **隔离修复智能体（actor）+ 唯一提交权监督者 + 事务化热替换** | 第 2 轮并发修复共享可变状态，本身就是「误差局部化」论证里的隐性竞态根源 |

**核心命题**：把 ToolGauge 的「找盲区 → 契约探测 → 摊销校准 → 局部热替换」升级为
「**隔离智能体 → 快照读 → 契约探测 → 私有先验适配 → 事务化提交（全局不变式 + 冲突检测）→ 溯源/可回滚**」。
安全论证的主工具从「统计相关性 + 在线断路器」换成「可串行化 + 事务原子性 + 污点溯源」：
第 2 轮的「一次错误先验污染所有被热替换子图」在串行化隔离下**在结构上不可能**，除非冲突图退化为完全图
（而那时已被串行化与提交门挡下）。

**不变式保持声明**：
- MODGAUGE 五不变式（契约完整性、组合单调性、反作用通道完备、主张绑定、严格退化链）全部保留；
- 组合单调性获得**并发版本**：任意已提交事务前缀可串行化等价于某串行执行（引理 51）；
- 严格退化链延长：IsoGauge 隔离设施失效（WAL/快照不可用、监督者失效）⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；
  隔离是工程增强，不是正确性依赖——即使完全不隔离，单盲区修复的正确性仍由 ToolGauge 保证（引理 56）。

## 0. 直觉与动机

**灵感 1（状态隔离：从「全局急停」到「边界 + 溯源回滚」）**
直觉：第 2 轮的 P-Quarantine 是「烟雾报警器 + 全楼断电」——它要等连续 3 次同向残差才触发，
那时污染早已提交进契约；而一旦触发，它暂停**所有**盲区修复，把「一个先验坏了」放大成「全系统停止修复」。
操作系统与数据库早就给过答案：不要指望全局熔断，要**隔离**。
每个盲区修复应是一个事务：读**快照**（看不到别人未提交的修改）、写**私有缓冲**（提交前他人不可见）、
提交时做**冲突检测 + 全局不变式校验**、失败**原子回滚**；每个已提交字段带**溯源标签**，
一旦某个先验版本被判定有害，就精确回滚「被它污染的那些字段」，而不是全停。
更深一层：**先验本身也要隔离**——共享主干在一轮内冻结只读，每个智能体只适配私有低秩头，提交即弃；
主干升级走「先验 MVCC + 历史重放非劣化门」，像软件发布一样可回滚、可灰度、可撤版。

**灵感 2（智能体：隔离状态 + 类型化消息 + 单一提交权）**
直觉：第 2 轮的 `toolgauge_6c(M, s)` 直接改共享的 `M.mreg`、`M.dpe`、`M.dbox`，而 `ToolGauge_round`
对多个盲区并发 `submit_async`——这是教科书式的**丢失更新**与 `last_gain` 竞态（缺陷 A2/A4）。
Actor 模型给的解药是：**每个盲区是一个只拥有私有状态的智能体**，彼此不共享可变内存，
只经监督者传类型化消息；**只有监督者持有提交权**（capability-secured commit）。
这让「局部修复、误差局部化」第一次可以被证明：串行化理论直接给出跨盲区污染的上界，
而不是靠统计假设。同时给智能体生命周期（spawn/reap）、预算划分、超时 abort 与确定性重放，
把第 2 轮的 `inflight` 泄漏（缺陷 A3）与不可复现事故一并治理。

**一句话总览**：ToolGauge 问「探测证据可不可信」，IsoGauge 问「修复与修复之间、修复与先验之间，
状态到底有没有串味」——答案是让它们不共享状态，并让每一次写入都可溯源、可回滚。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（修复智能体 RA）** 每个盲区 s 的修复被封装为一个隔离智能体
RA_s = (id_s, W_s, Φ_s, K_s, L_s)：
- W_s：私有工作集（对 R 与相关 EC 子图的读快照 + 待写缓冲）；
- Φ_s：私有先验租约（定义 437）；
- K_s：能力令牌，限定可调用工具集 ⊆ T₀ 与可写契约字段 ⊆ fields(s)；
- L_s：私有回执日志与决策日志（供确定性重放，定义 441）。
RA 之间**不共享可变状态**，只经监督者（定义 442）以类型化消息通信（actor 模型）。

**定义 433（读快照与纪元）** 全局状态带单调纪元 epoch；RA_s 在 spawn 时对 (R, EC, prior-version) 取读快照 σ_e，
其所有读操作落在 σ_e 上（快照隔离 SI）。未提交写不可见。
这条直接消除第 2 轮并发 `6C` 直接写共享 `M.mreg/M.dpe` 的竞态（缺陷 A2）。

**定义 434（写集、冲突图与幻读谓词）** WriteSet(RA_s) = 契约字段集 ∪ 格子集。
冲突图 G_c 中 s~s′ 当且仅当
(i) 写集相交（写-写冲突）；
(ii) 读集与对方写集相交且跨快照（写-读冲突）；
(iii) 二者盲区谓词重叠（phantom，例如共享同一未知材质簇）；
(iv) 先验特征邻域距离 ≤ ρ（**相关性先兆边**，把第 2 轮的「跨盲区相关偏差」显式建进图里）。
G_c 的独立集可并行提交；团内必须串行化（定义 436/444）。

**定义 435（事务化热替换 RepairTxn）** 一次修复是一个事务 T_s：
prepare（构造候选 EC 子图 + 本地交叉验证）→ validate（提交时全局不变式，定义 436）
→ commit（原子应用 + WAL 落盘）→ 或 abort（丢弃 W_s，零副作用）。
提交语义：全有或全无；崩溃后由 WAL 前滚/回滚，且重放幂等。

**定义 436（提交门 CommitGate 与可串行化）** commit 仅当在「提交后快照 σ_e ⊕ T_s」上
五不变式与契约完整性全部成立，且与所有已提交事务的串行化图无环。
即把第 2 轮的 `contract_regression`（**局部**子图回归）升级为**全局提交时验证**；失败 ⇒ abort（不是 stub），
原状态原样保留。区分二者的原因：两个各自局部合法的热替换，组合起来可能违反组合单调性（缺陷 A7）。

**定义 437（先验隔离：共享主干 + 私有头 PriorLease）** MP-Φ = (Φ_trunk, Φ_s)：
Φ_trunk 在一轮修复内**冻结只读**；每个 RA_s 只适配私有低秩头
Φ_s = f_θ(·; Φ_trunk, s)，生命周期随事务，提交即弃。
⇒ 单个智能体的先验幻觉无法写回共享主干，第 2 轮「一次错误先验污染所有子图」的传播路径被切断。
主干更新由独立的「先验合并」步骤（定义 438）触发，须通过历史重放回归。

**定义 438（先验 MVCC 与合并门）** 先验存在版本 v；每个事务引用其 spawn 时的 v。
新版本 v′ 激活前必须在历史回放集 ℋ（过去交易 episode）上重跑修复并满足：
(a) R̄(v′) ≤ R̄(v)（不劣化）；(b) 不下调任何已提交字段的置信度下限（commitment preservation）。
否则拒绝激活。这是把「先验发布」当作可回滚的软件发布（CI/CD 式），第 2 轮的 η 偏移不再是纯统计运气。

**定义 439（污染溯源与污点回滚 TaintRollback）** 每个已提交字段携带
provenance = (id_s, v, receipts)。当版本 v 被判定有害（审计或重放失败）⇒
精确回滚集合 = {字段 : v ∈ provenance}，逐个回滚到该字段的上一已提交版本（MVCC 链），**其他字段不动**。
这取代第 2 轮的全局 P-Quarantine（定义 428）：从「全停」变为「按污点最小回滚」，避免误伤可用性（缺陷 A1）。

**定义 440（隔离级别 ISOL-I0..I3）**
- I0 读已提交；I1 快照隔离（基线）；I2 冲突图可串行化；I3 = I2 + 先验隔离（定义 437）。
各级别保证由引理 51–53 给出；运行期按风险与负载自适应升降级，降级路径必须保持 ToolGauge 语义。

**定义 441（确定性重放）** 每个 RA 记录决策日志 L_s（输入、随机种子、先验版本、工具回执）。
重放同一 L_s 于沙箱产生逐指令一致轨迹；非确定来源（VLA 采样、时钟、调度）全部注入种子。
用于事故审计（E448）与安全回归。

**定义 442（监督者 Supervisor 与生命周期）** Supervisor 唯一持有提交权（capability）；
负责 spawn/reap、预算划分（继承 TB-Contract 定义 424）、agent 数上限、超时终止（⇒ abort）。
消除第 2 轮 `inflight` 只增不删的泄漏与无界并发（缺陷 A3）。

**定义 443（证人回执预留）** 拟合前从 cross.modal 中预留 ≥1 条未参与拟合的回执作为 witness(s)（容量 K_w）；
witness 不可用于 AP-Cal 拟合；预留失败 ⇒ 该事务降级为 ToolGauge 的 V 规则或 abort，
避免第 2 轮 V 阶段 `cross_receipt(s)` 证据饥饿导致的空校验或无限重试（缺陷 A5）。

**定义 444（冲突消解与活性）** 团内按确定性优先级 π(s) = （风险降序, id 升序）串行；
超过 τ_repair 即 abort 而非阻塞；可选证据加权仲裁：冲突双方的提交由一条共同 witness 回执裁决。
保证无死锁、无无界饥饿（引理 54）。

**定义 445（多智能体预算与公平）** 总预算 B_round 按 G_c 独立集与优先级划分；
单 agent 预算沿用 TB-Contract 的单盲区预算；预算耗尽只 abort 该事务，不影响他者（局部性保持）。

**定义 446（隔离下的严格退化链延长）** IsoGauge 失效（Supervisor 不可用 / 快照或 WAL 不可用 / witness 全耗尽）
⇒ ToolGauge（定义 431）⇒ LeanGauge ⇒ MODGAUGE。
隔离是工程增强而非正确性依赖：即使完全不隔离（I3→I0），ToolGauge 的单盲区正确性不变，只是失去并发安全。

**定义 447（继承与编号约定）** 未重定义记号沿用定义 398–431；令「单 agent、无并发、无 WAL、Φ_s = 全 Φ」
⇒ IsoGauge ≡ ToolGauge。本文所有增量结论必须在该退化点回落到第 2 轮结论。

## 2. 关键算法骨架

```python
# IP-321/322 隔离修复智能体 + 快照（actor；COW 快照）
@dataclass
class RepairAgent:
    sid: str
    epoch: int
    snap: Snapshot            # R/EC 的 COW 读快照（防读到半更新状态）
    wset: dict                # 私有写缓冲：field -> candidate
    lease: PriorLease         # Φ_trunk(只读) + 私有低秩头 θ_s
    cap: Capability           # tools ⊆ T₀, fields ⊆ fields(s), budget
    log: DecisionLog          # 决策/回执日志（确定性重放）

class StateStore:
    def fork(self, s):
        e = self.epoch.fetch()                       # 单调纪元
        return RepairAgent(s, epoch=e, snap=self.cow_snapshot(e),
                           wset={}, lease=self.prior.lease(s), cap=self.caps(s))
    def read(self, ag, key):   return ag.snap[key]   # 只读自己的快照
    def buffer(self, ag, field, val):
        assert field in ag.cap.fields
        ag.wset[field] = val                         # 未提交，他人不可见
```

```python
# IP-323 冲突图：写集 + 幻读谓词 + 先验特征邻域
def conflict_graph(agents):
    G = {a.sid: set() for a in agents}
    for a, b in combinations(agents, 2):
        wa, wb = writeset(a), writeset(b)
        if wa & wb:                       G[a.sid].add(b.sid); continue
        if (reads(a) & wb) or (reads(b) & wa):
            G[a.sid].add(b.sid); continue             # 写-读冲突
        if predicate_overlap(a.snap, b.snap):
            G[a.sid].add(b.sid); continue             # phantom
        if feat_dist(a.lease, b.lease) <= RHO:
            G[a.sid].add(b.sid)                       # 相关性先兆（定义 434.iv）
    return G

# IP-324 事务化热替换：prepare → CommitGate → commit/abort（WAL）
def repair_txn(store, ag):
    H    = LBox.hypothesize(ag, ag.snap)                       # 继承第 2 轮
    prog = TBox.select(H, ag.cap.tools, ag.lease, ag.cap.budget)
    rcpt = TCV.execute(prog, store.env, cap=ag.cap)            # 零副作用语义
    if len(rcpt) < n_min(ag):               return abort(ag, "insufficient")
    mu, Sig = APCal.calibrate(rcpt, H, ag, lease=ag.lease)     # 只写私有头，不碰主干
    if not APCal.cross_validate(mu, Sig, ag.witness):          # 预留见证（定义 443）
        return abort(ag, "cross_failed")
    store.buffer(ag, fields(ag.sid), (mu, Sig))
    with store.commit_lock(ag.sid):                            # 团内串行（定义 444）
        post = store.snapshot_for(ag)                          # 提交后快照
        if not CommitGate.check(post, ag.wset):                # 全局不变式（定义 436）
            return abort(ag, "invariant")
        store.wal.append(ag.sid, ag.wset, ag.epoch)            # 写前日志
        store.apply_atomic(ag.wset)                            # 原子应用
    store.provenance.tag(ag.wset, ag.sid, ag.lease.version, rcpt)  # 污点溯源
    ag.lease.discard()                                         # 私有头随事务丢弃
    return True

# IP-325/326 先验 MVCC 合并门 + 污点回滚
class PriorStore:
    def propose(self, v_new, replay_set):
        base = self.metrics(self.active,  replay_set)
        cand = self.metrics(v_new,         replay_set)
        if cand.risk  > base.risk:   return reject("degrade")        # 非劣化
        if cand.floor < base.floor:  return reject("commitment")     # 不降置信底
        self.active = v_new                                          # 原子切换
    def revoke(self, v):
        for f in self.provenance.fields_with(v):                     # 精确污点集
            self.rollback_to_prev(f)                                 # 逐字段回滚

# IP-327 监督者：生命周期 / 预算 / 见证 / 重放
class Supervisor:
    def round(self, M):
        G = conflict_graph(M.spawn_all_blindspots())
        for clique in maximal_cliques(G):                 # 独立集并行
            for ag in sort_by_priority(clique):           # 团内串行 + 超时 abort
                with deadline(ag, TAU_REPAIR):
                    repair_txn(M.store, ag)
                M.store.reap(ag)                          # 生命周期回收（修 A3）
        return MODGAUGE_round(M, *M.sensors)              # 50Hz 主控不变
```

## 3. 推导

**引理 51（可串行化 ⇒ 无跨盲区污染）** 若所有提交满足定义 436（可串行化 + 提交门），
则最终状态的任一字段等于「某串行序下逐事务单独提交」的结果；
特别地，单个错误事务（错误先验）的影响被限制在其 WriteSet 的并集内，不会因果传播到写集不相交的盲区。
证明思路：串行化理论——无环串行化图 ⇒ 存在等价串行执行；五不变式与契约完整性在每步归纳保持。
**系**：第 2 轮「一次错误先验污染所有热替换子图」在 I3 下不可能，除非冲突图为完全图，
而此时系统已退化为串行执行，污染被提交门挡下。

**引理 52（写隔离 ⇒ 丢失更新与写偏斜消除）** 快照隔离 + 提交时写-写冲突检测 + 谓词冲突（定义 434.iii），
保证无 lost update、无 write skew。
证明：SSI（Serializable Snapshot Isolation）标准论证；write skew 由谓词锁 (iii) 覆盖。

**引理 53（先验隔离的污染上界与回滚完备性）** 私有头 Φ_s 只影响事务 T_s 的候选后验，
故若版本 v 有害，其影响范围 ⊆ provenance 含 v 的字段；TaintRollback 的回滚集恰等于该集合（**完备性**），
且不触碰其他字段（**最小性**）；回滚后系统回到「不含 v 的某历史一致快照」。
证明：provenance 单调记录 + 每字段 MVCC 链 + 引理 51 的串行等价。

**引理 54（活性与无死锁）** 团内确定性 π 序串行 + 超时 abort ⇒ 无死锁、无无界饥饿；
最坏修复延迟 ≤ |团|·τ_repair。
证明：资源有序分配（π 给出全序）+ wait-die + 超时前向进展。

**引理 55（事务原子性下五不变式保持）** 每事务在 prepare/validate 保持五不变式，commit 原子应用
⇒ 任意提交前缀都满足五不变式；abort 零副作用 ⇒ 不变式不破。
**系**：严格退化链在 agent 崩溃/超时/隔离设施失效下仍成立（定义 446）。

**引理 56（隔离开销界与主路径零新增）** 快照用 copy-on-write：spawn O(1)、写冲突检测 O(|WriteSet| log N)、
提交门 O(|M_ver|)（与第 2 轮局部回归同阶）；全部位于 50Hz 计量路径之外。
⇒ 引理 45（硬实时）与引理 50（时序预算）保持；退化到 I0 时系统逐字段等价于 ToolGauge。

## 6. 本轮最大风险（一句话）

**一句话**：隔离边界的可靠性完全取决于冲突图（定义 434）的**完备性**——其中「先验特征邻域 ≤ ρ」
这条相关性边只是启发式，若真实长程相关经共享主干在「看似写集不相交」的智能体之间泄漏，
隔离会给出**虚假的局部性**；更糟的是，对主干 Φ_trunk 本身的供给链污染无法用污点溯源归因
（provenance 只精确到版本，而版本是全局的），此时所有事务共享同一个被污染的根，隔离层反而掩盖了单点失效。

**次级风险与缓解**：
1. **冲突图不完备（漏相关边）** → 定期「影子重放」：在不隔离模式下重跑已提交事务，对照检测漏网耦合；ρ 用历史残差相关性自适应（E441/E454）；
2. **共享主干供给链污染** → 主干版本签名 + 数据来源审计 + 回放集覆盖检查；主干不可信时整体退回物理锚 p_phys（E453）；
3. **近完全冲突图导致串行饥饿** → 分组批处理 + 预算硬顶 + stub 降级（局部性保持），E446 压力测试；
4. **隔离开销/内存膨胀** → COW 快照 O(1) spawn、写集大小上限、agent 数上限；E455 扩展性；
5. **能力令牌越权** → 令牌签名绑定 agent id + 字段/工具白名单 + 审计日志（定义 442）；
6. **WAL 崩溃一致性** → 幂等回放 + 校验点 + 半提交检测；E449 各阶段 kill 测试；
7. **合并门对回放集过拟合** → 留出未见历史片段做负控；E447；
8. **主路径时序** → 隔离设施全部异步于 50Hz 外，退化到 I0 与 ToolGauge 逐字段等价（引理 56）。

# 第 3 轮产物 · 创新点清单 v3：**IsoGauge**（State-Isolated Transactional Multi-Agent Metrology）

> 背景：第 2 轮 ToolGauge（IP-315–320）把「盲区发现与修复」武装成「契约化工具调用 + 预训练摊销校准 + 审计 VLA」，

## 2. 形式化定义（要点）

**定义 432（RA）** 每盲区一个 actor，持有私有读快照、写缓冲、私有先验头、能力令牌与决策日志；actor 间不共享可变状态，只经 Supervisor 传类型化消息。
**定义 433（快照/纪元）** spawn 时取 (R, EC, prior-version) 的快照 σ_e；所有读落在 σ_e；未提交写不可见（SI）。
**定义 434（冲突图）** 四类边：写-写、写-读、幻读谓词重叠、先验特征邻域 ≤ ρ；独立集并行、团内串行。
**定义 435（RepairTxn）** prepare→validate→commit/abort，全有或全无；WAL 保证崩溃一致与幂等重放。
**定义 436（CommitGate）** 在提交后快照上验证五不变式 + 契约完整性 + 串行化图无环；失败 abort 而非 stub，保留原状态。
**定义 437（PriorLease）** 主干 Φ_trunk 一轮内冻结只读，私有头 Φ_s 随事务提交即弃；幻觉不写回主干。
**定义 438（先验 MVCC/合并门）** v′ 激活须在 ℋ 上重放且不劣化风险、不下调已提交字段置信底；否则拒绝。
**定义 439（TaintRollback）** 字段级 provenance；坏版本 ⇒ 精确回滚该版本污染的字段到上一已提交版本，其他不动（取代定义 428 P-Quarantine）。
**定义 440（ISOL-I0..I3）** I0 读已提交 / I1 快照 / I2 冲突图可串行化 / I3 I2+先验隔离；按风险负载自适应。
**定义 441（确定性重放）** 决策日志 L_s 注入全部随机源；沙箱重放逐指令一致。
**定义 442（Supervisor）** 唯一提交权、spawn/reap、预算、agent 上限、超时 abort。
**定义 443（witness 预留）** 拟合前预留未参与拟合的 cross.modal 回执；预留失败显式降级，杜绝 V 阶段饥饿。
**定义 444（冲突消解/活性）** 团内 π 序串行、超时 abort、可选 witness 仲裁；无死锁无无界饥饿。
**定义 445（预算公平）** B_round 按独立集/优先级划分；单事务耗尽只 abort 自身。
**定义 446（退化链延长）** 隔离设施失效 ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE。
**定义 447（退化点）** 单 agent、无并发、无 WAL、Φ_s=全 Φ ⇒ IsoGauge ≡ ToolGauge。

## 3. 关键算法骨架

```python
# IP-321/322 隔离智能体 + COW 快照
@dataclass
class RepairAgent:
    sid: str; epoch: int
    snap: Snapshot            # R/EC 读快照（防半更新）
    wset: dict                # 私有写缓冲（提交前不可见）
    lease: PriorLease         # Φ_trunk(只读) + 私有低秩头
    cap: Capability           # tools/fields/budget 白名单
    log: DecisionLog          # 确定性重放用

class StateStore:
    def fork(self, s):
        e = self.epoch.fetch()
        return RepairAgent(s, e, self.cow_snapshot(e), {},
                           self.prior.lease(s), self.caps(s))
    def buffer(self, ag, field, val):
        assert field in ag.cap.fields
        ag.wset[field] = val

# IP-323 冲突图（写-写 / 写-读 / 幻读 / 先验邻域）
def conflict_graph(agents):
    G = {a.sid: set() for a in agents}
    for a, b in combinations(agents, 2):
        wa, wb = writeset(a), writeset(b)
        if wa & wb or (reads(a) & wb) or (reads(b) & wa) \
           or predicate_overlap(a.snap, b.snap) \
           or feat_dist(a.lease, b.lease) <= RHO:
            G[a.sid].add(b.sid)
    return G

# IP-324 事务化热替换
def repair_txn(store, ag):
    H    = LBox.hypothesize(ag, ag.snap)
    prog = TBox.select(H, ag.cap.tools, ag.lease, ag.cap.budget)
    rcpt = TCV.execute(prog, store.env, cap=ag.cap)
    if len(rcpt) < n_min(ag):           return abort(ag, "insufficient")
    mu, Sig = APCal.calibrate(rcpt, H, ag, lease=ag.lease)
    if not APCal.cross_validate(mu, Sig, ag.witness):
        return abort(ag, "cross_failed")
    store.buffer(ag, fields(ag.sid), (mu, Sig))
    with store.commit_lock(ag.sid):
        if not CommitGate.check(store.snapshot_for(ag), ag.wset):
            return abort(ag, "invariant")            # 全局不变式（定义 436）
        store.wal.append(ag.sid, ag.wset, ag.epoch)
        store.apply_atomic(ag.wset)                  # 原子提交
    store.provenance.tag(ag.wset, ag.sid, ag.lease.version, rcpt)
    ag.lease.discard()
    return True

# IP-325/326 先验 MVCC 合并门 + 污点回滚
class PriorStore:
    def propose(self, v_new, replay_set):
        base, cand = self.metrics(self.active, replay_set), self.metrics(v_new, replay_set)
        if cand.risk > base.risk or cand.floor < base.floor:
            return reject("degrade_or_commitment")
        self.active = v_new
    def revoke(self, v):
        for f in self.provenance.fields_with(v):
            self.rollback_to_prev(f)                 # 最小回滚

# IP-327 监督者
class Supervisor:
    def round(self, M):
        G = conflict_graph(M.spawn_all_blindspots())
        for clique in maximal_cliques(G):
            for ag in sort_by_priority(clique):
                with deadline(ag, TAU_REPAIR):
                    repair_txn(M.store, ag)
                M.store.reap(ag)
        return MODGAUGE_round(M, *M.sensors)          # 50Hz 主控不变
```

## 4. 推导

**引理 51（可串行化 ⇒ 无跨盲区污染）** 所有提交满足定义 436（可串行化图无环 + 提交门）⇒ 最终状态等价于某串行执行；单个错误事务影响 ⊆ 其 WriteSet 并集，不因果传播到写集不相交盲区。系：第 2 轮「一次错误先验污染所有子图」在 I3 下不可能（除非退化为完全图，此时已被串行化与提交门挡下）。
**引理 52（写隔离消除丢失更新/写偏斜）** SI + 写-写冲突检测 + 谓词冲突（434.iii）⇒ 无 lost update、无 write skew（SSI 论证 + 谓词锁）。
**引理 53（先验隔离污染上界 + 回滚完备/最小）** 私有头只影响本事务；坏版本 v 的影响 ⊆ provenance 含 v 的字段；TaintRollback 回滚集恰等于该集合且不误伤他者，回滚后回到不含 v 的一致快照（provenance 单调 + MVCC 链）。
**引理 54（活性/无死锁）** 团内 π 全序 + 超时 abort ⇒ 无死锁、无无界饥饿，最坏延迟 ≤ |团|·τ_repair（资源有序 + wait-die）。
**引理 55（原子性下五不变式保持）** prepare/validate 保持五不变式、commit 原子 ⇒ 任意提交前缀满足五不变式；abort 零副作用 ⇒ 退化链在崩溃/超时下仍成立。
**引理 56（开销与主路径零新增）** COW spawn O(1)、冲突检测 O(|W|log N)、提交门 O(|M_ver|)（与局部回归同阶）；全部异步于 50Hz 外 ⇒ 引理 45/50 保持；I0 退化点与 ToolGauge 逐字段等价。

## 8. 本轮最大风险

**一句话**：隔离边界的可靠性完全取决于冲突图（定义 434）的**完备性**——「先验特征邻域 ≤ ρ」这条相关性边只是启发式，
若真实长程相关经共享主干在「看似写集不相交」的智能体间泄漏，隔离会给出**虚假的局部性**；
而对主干 Φ_trunk 本身的供给链污染无法用污点溯源归因（provenance 只精确到全局版本），
此时所有事务共享同一个被污染的根，隔离层反而掩盖了单点失效——以 E441/E453/E454 证伪、影子重放与主干签名审计为兜底。
