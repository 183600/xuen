# 第 66 轮（承接第 65 轮「VISTA 故障可归因闭环」IP-214~223；灵感循环第 3 轮；本轮灵感：「世界模型」×「仿真到现实」）

> 第 65 轮把"几何可证伪"升级为"故障可归因"，其自述的最大风险是：**归因依赖有限故障假设集，且视觉与几何失效相互独立；未知复合故障与共因失效会让 FIR 把故障强行归入最近假设，系统因"已经归因"而更自信地继续执行。** 本轮追到更底层：VISTA 的 `p(ρ|H)`、`κ_fi`、AFA 的互信息、CSC 的越界概率，全部来自**离线故障注入与仿真标定**——也就是说，第 65 轮的"归因正确"本身是一个**仿真到现实的迁移命题**，而它从未被显式检验。本轮核心命题是：
>
> **世界模型不是更准的预测器，而是可做 `do()` 的故障反事实发生器；仿真到现实不是一个要调掉的误差，而是一条必须进入证书的不确定通道。先证明"仿真里的归因规则能迁移到现实"，再允许它支配真实的球与真实的执行。**

## 0. 直觉与动机

**灵感 1（世界模型 → 从"查表归因"到"反事实生成"）**
直觉：第 65 轮的 FIR 本质是**查表**：离线把 5 类故障注入仿真，拟合 `p(ρ|H)`，部署时拿 `ρ` 去比。这有三个隐含缺陷：(i) 故障集是封闭的，未知故障只能被硬塞进最近格子；(ii) 签名只覆盖仿真里出现过的载荷/位姿/材质；(iii) 故障之间不能**组合**。一个结构化世界模型给出完全不同的能力：它把"几何、力偏置、接触模型、视觉编码、任务参数"分成可干预的**机制槽**，于是可以对任意 `do(ψ)` 前滚出"如果力偏置是 3N、接触刚度降一半、同时相机有反光，签名会长什么样"。归因从"在固定表中查"变成"在反事实流形上做最近解释"。**世界模型的价值不是更准，而是可干预、可组合、可外推到没见过的幅度。**

**灵感 2（仿真到现实 → 把 gap 变成显式通道，而不是噪音）**
直觉：第 65 轮把仿真标定的签名当成真值，等于默认 `ρ_real = ρ_sim`。但真正致命的是：**仿真在"健康"时往往很准，恰恰在"故障"时最不准**（软接触、未建模摩擦、传感器饱和、透明材质在真实里与仿真差得最远）。所以 sim-to-real 不是均匀的噪声，而是一个**与故障幅度相关的、可能在最需要归因的地方最大的偏差** `δ_tr(ψ)`。正确做法不是"再调参把 gap 调小"，而是：(i) 用可安全实现的**锚点**（自由空间零力窗、已知标定物、以及**小幅度可逆的安全故障注入**）估计 `δ_tr`；(ii) 把它做成一个带覆盖保证的**差距管** `Δ_α`；(iii) 承认锚点主要覆盖健康区，用 gap 对故障幅度的 Lipschitz 界把管**向外膨胀**；(iv) 一旦当前情境落在迁移有效域 `𝒯` 之外，就**拒绝用世界模型归因**（abstain），退回第 65 轮的模型无关路径。

**灵感 3（合流 → 鲁棒归因而非点归因）**
直觉：第 65 轮输出的是点后验 `P(H|ρ)`，并据此定向膨胀某个球。若 `ρ` 只能在"仿真签名 + 差距管"内被解释，那么正确的对象不是点后验，而是**后验区间** `[P̲(H), P̄(H)]`：取遍管内的最坏偏差，问"最不利时我还能不能确定是谁坏了"。只有当**最坏情况下的最大后验仍然 ≥ 1−δ_fi**，才允许定向处置；否则判 ambiguous。这把第 65 轮"归因后过度自信"转成一个可计算的**鲁棒决策裕度** `γ`，并给出一个尖锐预言：当原始似然裕度大于阈值、但小于"阈值 + 差距惩罚"时，VISTA 会自信地下结论，而 RIFT 必须拒绝——存在一个 gap 的**相变点** `ε*`。

**灵感 4（世界模型 × 长预测短执行 → 长反事实、短现实）**
直觉：第 65 轮"长预测、短执行"把执行承诺截断在不可逆视界内。本轮把同一思想搬到仿真侧：**在世界上模型里可以尽量长、尽量野地做反事实前滚（长反事实），但真实世界的执行仍然只走认证过的短前缀（短现实）**。更进一步：任何**物理判别探针**在真正执行前，先在世界模型里"预演"，用带迁移惩罚的下界 `I_lb = I_W − L_I·rad(Δ)` 判断"这个探针在现实里是否真的能区分故障"；只有下界仍超过 `δ_fi` 且最坏风险 ≤ `f_safe` 才允许碰物体。这样"仿真里很有信息量"不再自动等于"值得在现实里冒险"。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → RBA**：点后验升级为差距管上的鲁棒后验区间；判据从"最大后验大"升级为"最坏后验仍大"。
- **AFA → CPE**：探针的互信息换成迁移惩罚后的下界；拒绝"仿真高信息、现实高风险"的探针。
- **离线故障库 → CFWM + PPC**：用结构化反事实世界模型生成签名；用后验预测检验发现"任何仿真机制都解释不了"的未知故障，并反演出连续故障幅度 `ψ*`。
- **RSC-V → RSC-T**：除 `r_geo/r_force/r_model` 外增加**迁移球** `r_trans`，当 `κ_tr→0` 时膨胀的是"我对仿真归因的信任"，而不是冤枉任何物理层。
- **WCV-V → WCV-T**：搜索域增加迁移有效性约束 `𝒯`；归因模糊时在差距管上做最坏边缘化。
- **CSP-V → CSP-T**：块边需 `Valid(J_rift)`；规划器可插入 `anchor_probe`（低成本锚点采集）与 `cf_probe`（反事实预演后才执行的判别探针）。
- **AIC-V → AIC-T**：干扰集增"仿真参数漂移、域随机化覆盖空洞、锚点-部署分布错配、现实差距与故障相关"。
- **J_vista → J_rift**：证书增 `transfer_cov、rad(Δ)、tvr、γ、κ_tr、ppc_p、unknown_flag、dr_cov、cf_gain_lb`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（RIFT 闭环）**：RIFT = (VISTA, CFWM, TRD, RBA, CPE, PPC/OSF, TVR, DRR, RSC-T, WCV-T, CSP-T, AIC-T, J_rift)。定位：VISTA 的"归因可迁移"升级。不变式：**反事实世界模型前滚、差距估计、鲁棒归因、探针预演、证书构建只在语义流；实时流仍只做残差采集、阶段判定、认证前缀执行与早停，零学习写操作。**
- **定义 234（结构化反事实故障世界模型 CFWM）**：`W = (z, m, f_phys, f_res, g_obs)`，`m=(m_geo,m_force,m_model,m_vis,m_task)` 为可解释机制槽，`ψ` 为槽参数（几何偏移、F/T 加性/乘性偏置与漂移、接触刚度/阻尼缩放、视觉编码偏置、任务质量/摩擦）。`p_W(ρ_{1:T}, y_{1:T} | x, A, do(h(ψ)))` 由可微物理前滚 + 学习残差生成。关键：`do(h(ψ))` 是**干预机制**而非条件于观测，因此支持组合故障与未见幅度。
- **定义 235（机制干预与可达签名流形）**：`do(h(ψ))` 把槽设为 `ψ`；可达签名流形 `ℳ_W(x,A) = { E[ρ|x,A,do(h(ψ))] : ψ∈Ψ_supp }`。归因 = 在 `ℳ_W ⊕ Δ_α` 上找最近解释；`ψ` 连续，因而故障假设从离散集合扩展为**参数化机制族**。
- **定义 236（现实差距与差距管）**：`δ_tr(x,A,ψ) = ρ_real − ρ_W(x,A,ψ)`。在锚点集 `I` 上估计 `Δ_α(x) = {δ : s(δ) ≤ q_tr(α)}`（`s` 为 Mahalanobis/Wasserstein 非一致性分数，`q_tr` 为 split-conformal 分位数）。**gap 连续性假设 A95**：`‖δ_tr(ψ)−δ_tr(ψ0)‖ ≤ L_ψ‖ψ−ψ0‖`；据此把健康区管膨胀为 `Δ_α(x,ψ) = Δ_α(x,ψ0) ⊕ Ball(L_ψ‖ψ−ψ0‖)`。
- **定义 237（锚点与安全故障锚点）**：锚点是"干预已知且可安全实现"的情境，用于成对估计 `δ_tr`。三类：(i) 自由空间零力窗 `null_test`（`ψ=0`）；(ii) 已知质量/刚度的标定物（小幅已知载荷）；(iii) **安全故障锚点**——在小幅、可逆、有界风险下故意注入已知 `ψ_I`（如已知小载荷测力偏置、已知柔顺面测模型误差），使 `Δ` 在故障区也有支撑。锚点采集受统一安全预算 `B_anchor` 约束。
- **定义 238（迁移有效域 TVR）**：`𝒯 = {x : d_T(x, I) ≤ r_T ∧ cov_DR(x) ≥ c_min ∧ drift_p > α_drift}`。`TVR(x)=0` 时**禁止**用 CFWM/RBA 归因，退回 VISTA 的模型无关路径或 `safe_idle`；`TVR=0` 必须显式写入证书。
- **定义 239（鲁棒贝叶斯归因 RBA 与决策裕度）**：对差距管内的最坏偏差取后验区间
  `P̲(H|x,A,ρ)=min_{δ∈Δ_α} p_W(ρ−δ|h,x,A)P(H)/Z`，`P̄` 取 max。定向处置仅当 `max_H P̲(H) ≥ 1−δ_fi`。可计算的充分条件用对数似然差裕度：`γ = min_{H'≠Ĥ}[Λ_{Ĥ,H'}(ρ)] − L_Λ·rad(Δ_α)`，其中 `Λ` 为对数似然比、`L_Λ` 为其对 `ρ` 的 Lipschitz 常数；`γ > log((1−δ_fi)/δ_fi)` 时鲁棒确定。
- **定义 240（迁移可辨识裕度）**：`d_Δ(H,H') = max(0, d(ρ_W(H),ρ_W(H')) − 2·rad(Δ_α))`，`κ_tr = min_{H≠H'} d_Δ(H,H') / max_{H≠H'} d(ρ_W(H),ρ_W(H'))`。若 `rad(Δ_α) ≥ d/2` 则 `κ_tr=0`：差距管已把两个故障的解释"粘"在一起，此时任何点归因都不可信。`κ_tr` 是 `κ_fi` 的迁移版本，且**随 gap 单调下降**。
- **定义 241（反事实探针估计 CPE）**：对探针 `a`，在 `W` 中算 `I_W(a)=I(ℋ;ρ_new|history,a)` 与最坏风险 `R_W(a)=max_{δ∈Δ_α} risk`。迁移惩罚下界 `I_lb(a)=I_W(a) − L_I·rad(Δ_α)`。选择 `a*=argmax_a I_lb(a) s.t. R_W(a)≤f_safe`；仅当 `I_lb(a*)≥δ_fi` 才执行，否则放弃物理探针（改 `anchor_probe`/被动观测）。即"仿真里再高信息，减去迁移惩罚后不够，也不许碰"。
- **定义 242（后验预测检验 PPC 与开放集故障）**：检验统计量 `T(ρ)=min_{ψ∈Ψ_supp} d_{Σ}(ρ, ρ_W(x,A,ψ) ⊕ Δ_α)`。若 `T(ρ) > q_ppc(α)`，拒绝"任何仿真可达机制能解释该签名"，判 `H_unknown`，并输出最近的 `ψ*` 作为**连续故障幅度解释**（若 `ψ*` 在支撑边界则提示外推）。这把离散 `ℋ` 升级为"离散标签 + 连续幅度 + 未知拒绝"。
- **定义 243（域随机化覆盖与迁移不变性）**：训练时在仿真参数 `ξ`（质量、摩擦、延迟、相机噪声、材质）上随机化，得覆盖 `cov_DR(ξ)`。要求归因规则在 `ξ` 上**迁移不变**：`∀ξ,ξ': |risk(ξ)−risk(ξ')| ≤ λ_inv`，用 IRM 式惩罚约束，避免规则依赖某个仿真伪影而无法迁移。
- **定义 244（迁移感知球 RSC-T / WCV-T）**：维护 `r_geo,r_force,r_model` 之外新增 `r_trans = f(rad(Δ_α), 1/κ_tr)`；融合半径 `r=√(r_geo²+r_force²+r_model²+r_trans²)`。`κ_tr→0` 时膨胀 `r_trans`（表达"归因不可信"）而非冤枉任一物理层。WCV-T 搜索域加 `𝒯`；归因模糊时在 `Δ_α` 上做最坏边缘化尾部。
- **定义 245（仿真到现实证书 J_rift）**：`J_rift=(J_vista, δ̂_tr, rad(Δ_α), tvr, transfer_cov, γ, κ_tr, ppc_p, unknown_flag, dr_cov, cf_gain_lb, anchor_hash, sim_real_hash)`。`Valid(J_rift) ⇔ Valid(J_vista) ∧ TVR(x) ∧ transfer_cov≥1−α_tr ∧ (鲁棒确定 ∨ (unknown/ambiguous 且已执行安全回退)) ∧ (所有物理探针均通过 CPE 下界) ∧ 被归因假设未被 PPC 拒绝`。
- **定义 246（RIFT 闭环算子）**：语义流 `[VISTA 骨架 → CFWM 反事实签名 → TRD 差距管 → TVR 判定 → RBA 鲁棒归因 → PPC/OSF → CPE 预演 → WCV-T → CSP-T → CSC 前缀 → AIC-T → J_rift]`；实时流 `[残差采集 → 阶段判定 → TVR 快速查表 → CSC 早停 → 前缀派发 → J_rift 构建]`。
- **定义 247（锚点主动设计 ABA）**：在安全预算 `B_anchor` 下选择下一批安全故障锚点，最大化对差距管在**故障相关区域**的覆盖：`I* = argmax_{I'⊆I_safe, cost≤B} min_{H} vol(Δ_α 在 H 邻域的残余)`。目标从"多采健康样本"改为"把 gap 估计推到真正会用到归因的地方"。
- **定义 248（迁移遗憾）**：`Reg_trans = R_real(π_RIFT) − R_real(π_oracle)`，其中 `π_oracle` 知道真实 `ψ*` 与真实 `δ_tr`。在上述假设下给出 `Reg_trans ≤ c·rad(Δ_α) + c'·1[TVR=0]`——迁移不确定性以**线性**代价进入遗憾，而非以指数级过度自信的形式爆发。

## 2. 关键算法骨架

```python
# CFWM：结构化反事实签名（语义流）
def cf_signature(W, x, A, psi, n=64):
    return W.rollout(do_slots(W.m, psi), x, A, n)   # 可微物理 + 学习残差

# TRD + RBA：现实差距管 → 鲁棒后验区间
Delta = fit_conformal_gap(anchors)                  # 含安全故障锚点
tube  = inflate_by_continuity(Delta, L_psi * norm(psi - psi0))
p_lo, p_hi, gamma = robust_posterior(rho, tube, lik_W, prior)

# PPC：任何仿真机制都解释不了？
T, psi_star = ppc_distance(rho, cf_signature, tube)
if T > q_ppc:
    declare_unknown(psi_star); return safe_fallback()

# CPE：先预演，再决定是否碰物体
a_star, I_lb = cpe.choose(post, x, W, tube, f_safe)  # I_lb = I_W - L_I*rad
if a_star is None: return anchor_probe_or_passive()

# RSC-T：膨胀"信任"而不是冤枉物理层
if kappa_tr < tau_tr:
    balls.r_trans = inflate_transfer(balls.r_trans, rad(tube), kappa_tr)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（差距管的归因覆盖）**：若 A94/A95 成立且锚点与 `𝒯` 内情境可交换，则 `ρ_real` 以 ≥`1−α_tr` 落入 `ℳ_W ⊕ Δ_α`；鲁棒后验区间以同概率覆盖真实后验，鲁棒确定时的错误率 ≤ `α_tr + exp(−n·κ_tr/2)`。
- **引理 10（迁移惩罚探针的安全与近最优）**：在互信息对条件分布的 Lipschitz 假设下，`I_real(a) ≥ I_lb(a) − α_tr`；故 `I_lb(a*)<δ_fi` 时不存在能在差距管内保证信息增益的探针。相对知道真 gap 的 oracle，遗憾 ≤ `2L_I·rad(Δ_α)`。
- **定理 9（RIFT 端到端：从"归因正确"到"归因可迁移"）**：`Valid(J_rift) ⇒` 要么鲁棒归因且迁移覆盖成立，要么显式 abstain 并安全回退；执行时的错误归因概率 ≤ `α_tr+δ_fi`；PPC 控制未知故障的误接受 ≤ `α_ppc`；`TVR=0` 时物理风险不高于 VISTA 的回退路径。
- **定理 10（开放集可发现性与相变）**：若真实故障到 `ℳ_W⊕Δ_α` 的迁移调整距离超过 `q_ppc`，PPC 以 ≥`1−β` 拒绝；VISTA 的过度自信在 gap 超过 `ε*=(γ0−τ)/L_Λ` 时必然发生，而 RIFT 在该区间转为 abstain——给出可实验验证的相变预测。
- **命题（锚点支撑失配的不可保证性）**：仅用健康区锚点估计的 `Δ`，对任意 `ε` 都存在一个故障使其真实 gap 远大于 `ε` 而锚点不可见；因此**没有 gap 连续性或故障区锚点，就不存在分布无关的迁移保证**。这正是安全故障锚点与 A95 存在的原因，也是本轮风险的形式化来源。
- **实时性**：CFWM 前滚、差距估计、RBA、PPC、CPE 全在语义流；实时流只增 TVR 查表（<0.03ms）、迁移残差残差（<0.1ms），目标 ≤2.7ms。

## 2. 形式化定义（完整版）

**定义 233（RIFT 闭环）** RIFT 是 VISTA 的"归因可迁移"升级：以第 65 轮"语义流 ∘ 实时流"骨架为基础，挂载 CFWM（反事实故障世界模型）、TRD/TVR（差距估计与迁移有效域）、RBA（鲁棒归因）、CPE（反事实探针）、PPC/OSF（后验预测检验与开放集），并原位升级 RSC-V→RSC-T、WCV-V→WCV-T、CSP-V→CSP-T、AIC-V→AIC-T、J_vista→J_rift。不变式：**反事实世界模型前滚、差距估计、鲁棒归因、探针预演、证书构建只在语义流与低频线程；实时路径只做残差采集、阶段判定、`𝒯` 查表、认证前缀执行与早停，零学习写操作。**

**定义 234（结构化反事实故障世界模型 CFWM）** 设潜状态 `z_t`、任务上下文 `x_t`、动作块 `A=(a_t,…,a_{t+H−1})`。`W` 由可微物理 `f_phys`、学习残差 `f_res`、观测模型 `g_obs` 组成，并暴露机制槽
`m=(m_geo,m_force,m_model,m_vis,m_task)`。
`ψ` 是槽参数：几何偏移、F/T 加性偏置 `b` 与乘性增益/漂移、接触刚度 `k_c` 与阻尼 `c_c` 的缩放、视觉编码偏置、任务质量/摩擦。干预 `do(h(ψ))` **直接设置机制**（而非条件于观测），前滚得

`p_W(ρ_{1:T}, y_{1:T} | x, A, do(h(ψ)))`，`ρ_W(x,A,ψ)=E_W[ρ|x,A,do(h(ψ))]`。

与第 65 轮查表式 `p(ρ|H)` 的本质区别：`ψ` 连续可组合，签名可外推到训练未覆盖的幅度与组合。**世界模型在此不是预测器，而是反事实证据发生器。**

**定义 235（机制干预与可达签名流形）** 可达签名流形
`ℳ_W(x,A) = { ρ_W(x,A,ψ) : ψ∈Ψ_supp }`。
归因不再是在 6 个标签里取 argmax，而是寻找最近解释
`ψ*(ρ) = argmin_{ψ∈Ψ_supp} d_Σ(ρ, ρ_W(x,A,ψ) ⊕ Δ_α)`。
离散标签 `H(ψ)` 只作为 `ψ` 的分区；真正的输出是"哪个槽、偏了多少、幅度是否可信"。

**定义 236（现实差距与差距管）** 现实差距
`δ_tr(x,A,ψ) = ρ_real − ρ_W(x,A,ψ)`。
在锚点集 `I` 上取非一致性分数 `s_i=‖δ_tr^{(i)}‖_{Σ_δ⁻¹}`，令 `q_tr(α)` 为其 split-conformal 分位数，得

`Δ_α(x) = { δ : s(δ) ≤ q_tr(α) }`，`P[δ_tr∈Δ_α] ≥ 1−α_tr`（锚点与部署可交换时）。

由于锚点主要在健康区（`ψ=ψ0`），引入 **A95 gap 连续性**：
`‖δ_tr(x,A,ψ) − δ_tr(x,A,ψ0)‖ ≤ L_ψ‖ψ−ψ0‖`，
从而故障区的差距管按故障幅度外推膨胀：

`Δ_α(x,ψ) = Δ_α(x,ψ0) ⊕ Ball(0, L_ψ‖ψ−ψ0‖)`。

**A95 是本轮最关键、也最脆弱的假设**：现实差距在故障发生时若发生跳变（软接触、饱和、透明材质），`L_ψ` 有界性失效，管会低估。

**定义 237（锚点与安全故障锚点）** 锚点是"干预已知且可安全实现"的情境：
(i) **健康锚点**：自由空间零力窗 `null_test`，`ψ=ψ0`；
(ii) **标定锚点**：已知质量/刚度物体，施加小幅已知载荷；
(iii) **安全故障锚点**：在统一风险预算 `B_anchor` 内故意注入小幅、可逆、有界的已知故障 `ψ_I`（已知小载荷测 F/T 偏置、已知柔顺面测模型误差、已知小几何偏移），使 `Δ` 在故障区也有支撑。
锚点不是随便采的：`ψ` 的选取必须满足预测力/形变在安全域内，且每次注入后能完全恢复。

**定义 238（迁移有效域 TVR）** 
`𝒯 = { x : d_T(x,I) ≤ r_T ∧ cov_DR(x) ≥ c_min ∧ drift_p(x) > α_drift }`。
`TVR(x)=c` 表示当前情境与锚点足够接近、域随机化覆盖足够、漂移检测未报警。`TVR=0` 时，**禁止**用 CFWM/RBA 归因，退回 VISTA 的模型无关路径（第 65 轮逻辑）或 `safe_idle`，并显式写入 `J_rift.tvr=0`。

**定义 239（鲁棒贝叶斯归因 RBA 与决策裕度）** 对差距管内最坏偏差定义后验区间
`P̲(H|x,A,ρ) = min_{δ∈Δ_α} p_W(ρ−δ|h,x,A)P(H) / Z(δ)`，
`P̄(H|x,A,ρ) = max_{δ∈Δ_α} (·)`。
定向处置仅当 `max_H P̲(H) ≥ 1−δ_fi`；否则判 ambiguous。可计算的充分条件：设
`Λ_{H,H'}(ρ)=log p_W(ρ|H)−log p_W(ρ|H')`，
若 `Λ` 对 `ρ` 的 Lipschitz 常数为 `L_Λ`，则

`inf_{δ∈Δ_α} Λ_{H,H'}(ρ−δ) ≥ Λ_{H,H'}(ρ) − L_Λ·rad(Δ_α)`。

定义鲁棒裕度
`γ(ρ) = min_{H'≠Ĥ} Λ_{Ĥ,H'}(ρ) − L_Λ·rad(Δ_α)`，
`γ > log((1−δ_fi)/δ_fi)` 时鲁棒确定。**注意 `γ` 把"仿真里分得很开"与"现实差距可能把两者粘在一起"分开计账。**

**定义 240（迁移可辨识裕度）** 对假设对 `(H,H')`，
`d_Δ(H,H') = max(0, d_Σ(ρ_W(H),ρ_W(H')) − 2·rad(Δ_α))`，
`κ_tr = min_{H≠H'} d_Δ(H,H') / max_{H≠H'} d_Σ(ρ_W(H),ρ_W(H'))`。
`rad(Δ_α) ≥ d_Σ/2` 时 `κ_tr=0`：差距管已使两个故障观测等价，任何点归因都不成立。`κ_tr` 是第 65 轮 `κ_fi` 的迁移版本，且随 gap 单调下降——**它度量的不是"传感器多准"，而是"仿真给出的区分在现实里还剩多少"。**

**定义 241（反事实探针估计 CPE）** 对探针 `a∈A={visual_probe,null_test,anchor_probe,press,rub,tap,lift}`，
在 `W` 中计算
`I_W(a) = I(ℋ; ρ_new | history, a)`，`R_W(a) = max_{δ∈Δ_α} risk(a,δ)`。
迁移惩罚下界
`I_lb(a) = I_W(a) − L_I·rad(Δ_α)`。
选择
`a* = argmax_{a} I_lb(a)  s.t.  R_W(a) ≤ f_safe(φ̂,f̂_vis)  ∧  strain ≤ ε_strain`，
仅当 `I_lb(a*) ≥ δ_fi` 才执行。若不存在，则改 `anchor_probe`（低成本降低 `rad(Δ)`）或被动观测。**判据从"仿真的信息增益"升级为"扣除迁移不确定性后的现实信息增益"**——直接对冲"仿真里探针很值、现实里又险又没用"。

**定义 242（后验预测检验 PPC 与开放集故障）** 
`T(ρ) = min_{ψ∈Ψ_supp} d_Σ(ρ, ρ_W(x,A,ψ) ⊕ Δ_α)`，
`q_ppc(α)` 为标定集上 `T` 的 conformal 分位数。若 `T(ρ) > q_ppc(α)`，拒绝"任何仿真可达机制能解释当前签名"，判 `H_unknown`，并输出最近的 `ψ*` 作为连续解释。若 `ψ*` 落在 `Ψ_supp` 边界，标记"外推/未知组合"。这把第 65 轮的离散 `ℋ` 扩展为 **离散标签 + 连续幅度 + 未知拒绝**，直接回应"未知故障被强行归入最近假设"。

**定义 243（域随机化覆盖与迁移不变性）** 训练时在仿真参数 `ξ`（质量、摩擦、延迟、相机噪声、材质、执行器带宽）上随机化，记录覆盖 `cov_DR(ξ)`。要求归因规则 `f_att` 在 `ξ` 上**迁移不变**：
`∀ξ,ξ' : |risk(f_att;ξ) − risk(f_att;ξ')| ≤ λ_inv`，
以 IRM/风险方差惩罚实现。目的：防止 `p_W(ρ|H)` 学到某个仿真引擎的特有伪影（例如某渲染器的反光模式），从而在真实中失效。

**定义 244（迁移感知球 RSC-T / WCV-T）** 维护 `r_geo,r_force,r_model` 与新增**迁移球** `r_trans`：
`r_trans = clip(c_Δ·rad(Δ_α)·(1/κ_tr + 1), 0, R_MAX)`。
融合半径
`r = √(r_geo² + r_force² + r_model² + r_trans²)`。
关键设计：当 `κ_tr→0`（差距把故障粘住）时，膨胀的是 `r_trans`——表达"我不再相信仿真给出的归因"，而不是冤枉几何或力传感器。WCV-T 搜索域
`B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ 𝒯`，
归因模糊时在 `Δ_α` 上做最坏边缘化尾部；交集为空则回退 `B(φ̂,r)` 并置 `transfer_conflict=True`。

**定义 245（仿真到现实证书 J_rift）** 
`J_rift=(J_vista, δ̂_tr, rad(Δ_α), tvr, transfer_cov, γ, κ_tr, ppc_p, unknown_flag, dr_cov, cf_gain_lb, anchor_hash, sim_real_hash)`。
验证规则：

```
Valid(J_rift) ⇔ Valid(J_vista)
  ∧ TVR(x) = 1
  ∧ transfer_cov ≥ 1−α_tr
  ∧ ( (γ > log((1−δ_fi)/δ_fi))                       # 鲁棒确定
      ∨ (unknown_flag ∧ fallback_executed) )          # 或显式未知 + 安全回退
  ∧ (所有物理探针均满足 I_lb ≥ δ_fi)
  ∧ (被归因假设未被 PPC 拒绝)
  ∧ dr_cov ≥ c_min ∧ sim_real_hash 为当前版本
```

审计链新增：**为什么相信仿真给出的归因**（`transfer_cov、rad(Δ)、κ_tr、γ`）、**是否出了迁移域**（`tvr`）、**是否有仿真解释不了的故障**（`ppc_p、unknown_flag`）、**探针是否在现实里有信息量**（`cf_gain_lb`）。

**定义 246（RIFT 闭环算子）** 语义流：
`[VISTA 骨架 → CFWM 反事实签名 → TRD 差距管 → TVR 判定 → RBA 鲁棒归因 → PPC/OSF → CPE 预演 → WCV-T → CSP-T 块规划 → CSC 认证前缀 → Shield → 执行 k* → AIC-T → J_rift]`；
实时流：
`[残差采集 → 阶段判定 → TVR 快速查表 → CSC 早停 → WCV-T 编译 → 前缀派发 → J_rift 构建]`。

**定义 247（锚点主动设计 ABA）** 在风险预算 `B_anchor` 下选下一批安全故障锚点
`I* = argmax_{I'⊆I_safe, cost(I')≤B} min_{H} vol( Δ_α 在 H 邻域的残余不确定 )`。
即从"多采健康样本"改为"把差距估计主动推进到真正会用到归因的故障区"。这是把主动学习从"估参数"再次转向"补迁移覆盖"。

**定义 248（迁移遗憾）** 
`Reg_trans = R_real(π_RIFT) − R_real(π_oracle)`，
`π_oracle` 已知真实 `ψ*` 与真实 `δ_tr`。在 A94–A97 下
`Reg_trans ≤ c₁·rad(Δ_α) + c₂·1[TVR=0] + c₃·α_tr`。
意义：迁移不确定性以**线性**代价进入遗憾，而不是以"看似确定、实则错误"的过度自信形式爆发；`TVR=0` 的弃权代价被单独计价，因而可与继续执行做显式权衡。

### IP-224/225 CFWM + TRD（反事实签名与差距管）

```python
class CounterfactualFaultWorldModel:
    """结构化机制槽 + 可微物理 + 学习残差；支持 do(h(psi)) 干预。"""
    SLOTS = ('m_geo', 'm_force', 'm_model', 'm_vis', 'm_task')

    def __init__(self, physics, residual, obs, psi_prior):
        self.phys, self.res, self.obs = physics, residual, obs
        self.psi_prior = psi_prior

    def set_slots(self, psi):
        m = dict(self.phys.default_slots)
        m['m_geo'] = self.phys.default_slots['m_geo'] + psi.geo_offset
        m['m_force'] = {'b': psi.bias, 'gain': psi.gain, 'drift': psi.drift}
        m['m_model'] = {'k_scale': psi.k_scale, 'c_scale': psi.c_scale}
        m['m_vis'] = {'bias': psi.vis_bias}
        m['m_task'] = {'mass': psi.mass, 'mu': psi.mu}
        return m

    def signature(self, x, A, psi, n=64):
        m = self.set_slots(psi)
        z = self.phys.reset(x, m)
        traj = []
        for a in A:
            z = self.phys.step(z, a, m)
            z = z + self.res(z, a, m)          # 学习残差
            traj.append(self.obs(z, m))
        return sample_signature(traj, n)

    def mean_signature(self, x, A, psi):
        return np.mean(self.signature(x, A, psi, n=256), axis=0)


class RealityGap:
    """锚点 -> 差距 conformal 管 -> 按故障幅度 Lipschitz 外推。"""
    def __init__(self, W, alpha_tr=0.05, L_psi=0.0):
        self.W, self.alpha_tr, self.L_psi = W, alpha_tr, L_psi
        self.q_tr, self.psi0 = None, None

    def fit(self, anchors):
        # anchors: list of (x, A, psi_known, rho_real)
        scores, psi_vals = [], []
        for x, A, psi, rho in anchors:
            delta = rho - self.W.mean_signature(x, A, psi)
            scores.append(float(delta @ np.linalg.solve(self.Sigma_delta, delta)))
            psi_vals.append(psi)
        self.q_tr = conformal_quantile(np.sqrt(scores), self.alpha_tr)
        self.psi0 = median_psi(psi_vals)          # 健康/标定中心
        return self

    def radius(self, psi):
        base = self.q_tr
        return base + self.L_psi * float(np.linalg.norm(psi - self.psi0))

    def in_tvr(self, x, drift_p, cov_dr, r_T, c_min, alpha_drift):
        return (dist_to_anchors(x) <= r_T and cov_dr >= c_min
                and drift_p > alpha_drift)
```

### IP-226 RBA（鲁棒归因与决策裕度）

```python
class RobustBayesianAttribution:
    def __init__(self, W, L_Lambda=None, delta_fi=0.15):
        self.W, self.delta_fi = W, delta_fi
        self.L_Lambda = L_Lambda or estimate_lipschitz_loglik(W)

    def posterior_interval(self, rho, x, A, psi_grid, tube_radius, prior):
        # 对每个候选机制取最坏/最好似然；psi_grid 由 CFWM 反事实生成
        lo, hi = {}, {}
        for H in prior:
            vals = []
            for psi in psi_grid[H]:
                base = loglik(self.W, rho, x, A, psi)
                vals.append(base - self.L_Lambda * tube_radius(psi))
            # 取各候选内最优解释；最坏情况对差距管取惩罚
            z = logsumexp(vals)
            lo[H] = np.log(prior[H]) + z - self.L_Lambda * max(tube_radius(p) for p in psi_grid[H])
            hi[H] = np.log(prior[H]) + max(vals)
        return softmax_interval(lo, hi)

    def decide(self, rho, x, A, post_iv, tube_radius):
        p_lo = post_iv['lower']
        h_star = max(p_lo, key=p_lo.get)
        gamma = (np.log(p_lo[h_star] / max(
                    (p for h, p in p_lo.items() if h != h_star), default=1e-12))
                 - self.L_Lambda * max(tube_radius(p) for p in tube_radius.psigrid))
        certain = p_lo[h_star] >= 1.0 - self.delta_fi and gamma > LOGIT(self.delta_fi)
        return h_star, certain, gamma

    def directed_demote(self, h_star, balls, w_vis, H, kappa_tr):
        # 复用第 65 轮定向处置；但若迁移不可辨识，膨胀 r_trans 而非物理球
        if kappa_tr < TAU_TR:
            balls['r_trans'] = inflate_transfer(balls.get('r_trans', 0.0), kappa_tr)
            return balls, w_vis, H                       # 不冤枉 r_geo/r_force/r_model
        return GRIP_directed_demote(h_star, balls, w_vis, H)
```

```python
class CounterfactualProbe:
    PROBES = ('visual_probe', 'null_test', 'anchor_probe',
              'press', 'rub', 'tap', 'lift')

    def __init__(self, W, L_I, delta_fi=0.15):
        self.W, self.L_I, self.delta_fi = W, L_I, delta_fi

    def choose(self, post, x, f_safe, object_fragile, tube_radius):
        if object_fragile:
            cands = ('visual_probe', 'null_test', 'anchor_probe')
        else:
            cands = self.PROBES
        best, best_lb = None, -np.inf
        for a in cands:
            Iw = self.W.expected_mutual_info(post, x, a)     # 仿真互信息
            lb = Iw - self.L_I * tube_radius(a)              # 迁移惩罚
            risk_ub = self.W.worst_case_risk(x, a, tube_radius(a))
            if risk_ub > f_safe or lb < self.delta_fi:
                continue
            if lb > best_lb:
                best, best_lb = a, lb
        return best, best_lb

    def execute_after_rehearsal(self, a, x, robot):
        # 先在世界模型里完整预演，确认阶段签名可区分、风险不越界，再碰现实
        sim = self.W.rehearse(a, x)
        if sim.violates(f_safe) or sim.info_gain < self.delta_fi:
            return 'abort'
        return robot.execute_probe(a)
```

## 4. 推导

**引理 9（差距管的归因覆盖）** 设 A94（锚点与 `𝒯` 内情境可交换）、A95（gap 对 `ψ` Lipschitz）成立。则对 `x∈𝒯`，
`P[ρ_real ∈ ℳ_W(x,A) ⊕ Δ_α(x,ψ_true)] ≥ 1−α_tr`。
对任意 `δ∈Δ_α`，鲁棒后验区间按定义取遍该管，故真实后验点落在 `[P̲,P̄]` 内。若 RBA 判鲁棒确定，则除 `α_tr` 概率外，真实最大后验亦为 `Ĥ`；在 Laplace 近似下，`P(Ĥ≠H_true) ≤ α_tr + exp(−n·κ_tr/2)`。`κ_tr` 取代 `κ_fi`，直接刻画"差距把故障粘住"导致的辨识能力损失。∎

**引理 10（迁移惩罚探针的安全与近最优）** 设 `I(ℋ;ρ|a)` 对条件分布 `p(ρ|a)` 在 Wasserstein-1 下 Lipschitz 常数为 `L_I`，且真实条件分布与仿真分布的距离 ≤`rad(Δ_α)`。则
`I_real(a) ≥ I_W(a) − L_I·rad(Δ_α) = I_lb(a)`，以 ≥`1−α_tr` 成立。
因此若 `max_a I_lb(a) < δ_fi`，则不存在能在差距管内保证信息增益 ≥`δ_fi` 的探针——CPE 的放弃是可证明必要的，而非保守。若执行 `a*`，实际获得信息以 ≥`1−α_tr` 不低于 `δ_fi`。相对知道真实 gap 的 oracle，
`Reg_I = I_oracle − I_real(a*) ≤ 2L_I·rad(Δ_α)`。
安全侧：`R_W(a)=max_{δ∈Δ_α} risk` 是定义 241 的硬约束，故执行探针的物理风险不超过 `f_safe`（在仿真可达范围内）。∎

**定理 9（RIFT 端到端：从"归因正确"到"归因可迁移"）** 在 A94–A97（差距管、gap 连续性、似然 Lipschitz、锚点可交换、探针安全界）下：
1. **归因可迁移**：`Valid(J_rift)` 之下，要么 RBA 鲁棒确定且引理 9 的覆盖成立，要么 `unknown_flag` 为真且已执行安全回退；不存在"点后验很大所以直接处置"的路径。
2. **不过度自信**：执行时的错误归因概率 ≤`α_tr + δ_fi`；第 65 轮的最坏情形（gap 使其置信度高而实际错误）被 `γ` 与 `κ_tr` 显式拦截。
3. **未知故障可控**：PPC 的误接受 ≤`α_ppc`；当真实故障离 `ℳ_W⊕Δ_α` 超过 `q_ppc` 时以 ≥`1−β` 拒绝（见定理 10）。
4. **物理风险不升**：CPE 探针 `R_W≤f_safe`；CSC 仍限制 `k*≤m`；`TVR=0` 时退回 VISTA 回退路径，故新增迁移层不引入新的物理承诺。
5. **证书可审计**：`J_rift` 显式记录"为何相信仿真"（`transfer_cov、rad、κ_tr、γ`）、"是否出域"（`tvr`）、"是否不可解释"（`ppc_p`）、"探针是否有现实信息"（`cf_gain_lb`）。
6. **实时性**：实时路径 ≤2.7ms，零学习写操作（A96）。∎

**定理 10（开放集可发现性与 gap 相变）** 设 `T(ρ)` 到 `ℳ_W⊕Δ_α` 的距离为 `d_T`，`q_ppc` 为标定阈值。
(i) **检测**：若真实故障满足 `d_T ≥ q_ppc + β`，则 PPC 拒绝概率 ≥`1−α_ppc`（conformal 秩检验），故未知故障不会被静默归入最近标签。
(ii) **相变**：定义原始似然裕度 `γ0=min_{H'≠Ĥ}Λ_{Ĥ,H'}(ρ)`，确定阈值 `τ=log((1−δ_fi)/δ_fi)`。VISTA 在 `γ0>τ` 时即宣布确定；RIFT 需要 `γ0>τ+L_Λ·rad(Δ_α)`。故
`ε* = (γ0−τ)/L_Λ`
是 gap 的**过度自信相变点**：`rad(Δ_α)<ε*` 时两者一致，`rad(Δ_α)>ε*` 时 VISTA 继续自信而 RIFT 转为 abstain。该式给出可直接实验验证的预测：随注入 gap 增大，VISTA 的"确定但错误"率单调上升，RIFT 的弃权率上升而"确定但错误"率被压住。
(iii) **开放集反演**：若 `ψ*` 在支撑内部，则给出连续故障幅度；若在边界，则提示"外推/未知组合"，与 `H_unknown` 一致。∎

**命题（锚点支撑失配的不可保证性）** 仅用健康区锚点（`ψ=ψ0`）估计 `Δ_α(x,ψ0)` 时，对任意 `ε>0` 与任意 `ψ` 都存在一个合法 gap 函数 `δ_tr` 使 `δ_tr(ψ0)=0`（锚点完全看不到）而 `‖δ_tr(ψ)‖≫ε`。因此**若没有 A95（gap 对故障幅度连续）或故障区锚点，就不存在分布无关的迁移保证。** 这解释了为什么必须引入安全故障锚点与 A95，也把本轮风险精确落在一个可陈述的假设上，而不是含糊的"仿真可能不准"。∎

**命题（迁移球降低误伤）** 第 65 轮在归因不可信时膨胀某个物理球 `r_geo` 或 `r_force`，体积增加 `κ_infl^{d_φ}`，等价于"因为不确定是谁坏了，就假定几何坏了"。RIFT 在 `κ_tr<τ_tr` 时只膨胀 `r_trans`，物理球保持不变；若真实故障是 F/T 而几何正确，RIFT 的几何搜索域体积比第 65 轮小 `κ_infl^{d_φ}`，避免把迁移不确定性错误地记到物理先验上。∎

**命题（长反事实、短现实）** 设世界模型前滚的方差随视界 `H_W` 增长为 `σ_W²·H_W`，而仿真前滚无物理风险；真实执行的风险在越过不可逆视界 `m` 后跃升。则总风险
`R(H_W,k) = c₁·(σ_W²·H_W)/H_W + c₂·1[k>m] + c₃·rad(Δ_α(H_W))`。
第一项因时间集成近似不随 `H_W` 增长，第二项要求 `k≤m`，第三项随时间外推的 gap 增长。故最优是"世界模型里尽量长（用于反事实与迁移评估），真实执行尽量短（`k*=min(H,m)`），并在 `H_W` 超过 gap 外推可靠视界时截断"。这把第 65 轮"长预测、短执行"严格扩展为"**长反事实、短现实**"。∎

## 7. 已知风险

**一句话**：RIFT 的全部保证依赖"锚点与部署条件在现实差距上可交换、且 gap 对故障幅度满足 Lipschitz 连续"；但锚点天然偏向健康与小幅已知故障，而真正致命的未知复合故障恰在锚点支撑之外——一旦 gap 与故障**相关**（故障时仿真更不准、发生跳变），`Δ_α` 会被系统性低估，RIFT 就会用"已通过迁移认证"的假象，把第 65 轮的过度自信重新包装一遍。

**次级风险与缓解**：
1. **gap-故障相关导致管低估**：A95 失效时外推不可靠；缓解：安全故障锚点主动覆盖故障区（ABA）、在线 PPC 一票否决、`κ_tr` 持续监测；仍应在文档中明确"无连续/无故障区锚点则不保证"。
2. **安全故障锚点本身造成伤害**：注入已知故障仍有风险；缓解：严格 `B_anchor` 预算、仅可逆小幅注入、每次注入后自动恢复校验，易损物体禁用。
3. **CFWM 容量不足**：世界模型无法表示某些真实故障（如粘滑、摩擦各向异性、传感器非线性饱和），PPC 会把"模型不能表示"与"未知故障"混为一谈；缓解：把 PPC 拒绝当作"不可解释"而非"确定有故障"，并保留模型无关回退；持续外推机制槽。
4. **鲁棒后验过保守**：`L_Λ·rad` 惩罚可能使 `γ` 长期为负、系统频繁弃权；缓解：用分视界/分阶段的局部 Lipschitz、按 `ψ` 方向分别估计 `L_ψ`，并优先用 `anchor_probe` 缩小管。
5. **conformal 交换性破坏**：部署分布漂移使 `α_tr` 名不副实；缓解：在线重校准 + 漂移检测 + TVR 出域弃权。
6. **仿真前滚成本**：128 组前滚可能超出语义流预算；缓解：缓存签名、低秩代理、只在归因模糊时展开全量。
7. **域随机化覆盖幻象**：`cov_DR` 高不代表真实覆盖；缓解：把 `cov_DR` 只作必要条件，最终仍由锚点与 PPC 兜底。
8. **相变点 ε* 的估计依赖 `L_Λ`**：Lipschitz 常数估计偏差会移动弃权边界；缓解：用对抗样本给出 `L_Λ` 上界、保守取大。
