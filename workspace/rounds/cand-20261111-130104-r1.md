# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「姿态估计」×「场景理解」）

> 第 54 轮把技能组合推进为动作空间剖面与云边双证书。但 `α_S`、`A_cert`、`γ_ce` 都默认“动作落在正确的场景锚点上”。本轮追问一个更前置的问题：**动作所指向的物体/区域，究竟是如何从场景理解与姿态估计中被“锚定”的？** 核心矛盾：H22：姿态协方差与语义置信度在遮挡、反光、小目标处耦合退化，产生“语义正确、几何错位”的假阳性动作目标；H23：场景理解的关系图与姿态估计的度量空间在坐标系与粒度上不一致，技能动作剖面建立在错误锚点上，组合在语义层兼容、在几何层失效。

## 0. 直觉与动机

**灵感 1（姿态估计是场景理解到动作空间的“度量桥”）**
直觉：场景理解给出的是**拓扑**——有哪些实体、它们之间是什么关系、每个实体具有什么可供性；姿态估计给出的是**度量**——实体在 `SE(3)` 中的位姿与协方差。一个可执行动作 = 拓扑目标 × 度量锚点。只做场景理解，动作知道“去抓杯子”，却不知道杯子在哪个坐标系、杯柄朝向哪里；只做姿态估计，动作知道“这个刚体在哪里”，却不知道它是一个可抓的杯柄还是不可抓的杯壁。于是应把二者融合为 **场景-姿态锚定图 `G_SP`**：节点是带位姿与协方差的实体，边是带不确定性的相对变换。

**灵感 2（把姿态不确定性传播进动作剖面，而不是事后补 `δ_a`）**
直觉：第 54 轮的 `δ_a` 是“执行后发现的对齐误差”。更正确的是**在规划前**就把姿态信念 `(ξ_e, Σ_e)` 通过锚定映射 `g` 的雅可比 `J_g` 传播为动作空间的协方差 `Σ_a = J_g Σ_e J_g^T`，得到**姿态不确定动作管 `U_a`**。只有当整个管 `U_a` 落在动作占用证书 `A_cert` 的容错带内，动作才算被认证。这把“姿态是不是够准”从一句经验判断变成一个可判定的集合包含问题。

**灵感 3（语义-几何一致性必须是独立证书）**
直觉：场景理解会幻觉或漏检，姿态估计也会“精确地错在错误物体上”。二者单独看都很自信，合起来可能是灾难。需要第三个视角做交叉验证：**重投影残差**（几何自洽）、**可供性-接触一致性**（语义到几何是否落得下去）、**跨视角位姿一致性**（多视图是否同一实体）。三者合成 `SGCS`。关键约束：`SGCS` 的证据源不能与姿态估计共享同一批特征，否则误差同向漂移，证书会系统性虚高。

**灵感 4（场景锚定身份的守恒）**
直觉：组合两个技能时，第 54 轮只检查动作空间交集 `compat`。但若技能 A 锚定在“左杯”的假设上、技能 B 锚定在“右杯”的假设上，`compat` 再高也只是“对着两个不同的杯子做同一个动作”。因此组合边必须同时满足：**动作重叠 ∧ 锚定身份一致 ∧ 动作管包含**。这把“同一物体假设”提升为组合的第一性约束，与动作空间并列。

**灵感 5（感知-行动门控：先看再动，而非先动再解释）**
直觉：第 54 轮的 `Explain` 回传发生在执行失败之后，而很多操作是不可逆的。应当把闭环前移：当 `SGCS < θ_sg` 或动作管半径超预算时，触发 **next-best-view / 主动姿态精化**，以“预期动作管体积缩减 / 信息增益”为目标选择下一个视角，在预算内降不确定；若预算耗尽仍不达标，则 **defer**（安全中止或请求人工），而不是硬做。这形成 **先感知认证 - 再动作执行** 的门控。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（场景-姿态锚定图）**
`G_SP = (E, R, ξ, Σ, T)`：`E` 为实体集，`R ⊆ E×E×ℛ` 为语义关系集；每个实体 `e` 带位姿 `ξ_e ∈ SE(3)` 与协方差 `Σ_e ∈ ℝ^{6×6}`；每条关系 `(e_i,e_j,r)` 带相对变换 `T_{ij}` 及其传播协方差 `Σ_{T,ij}`。锚定映射 `g : A_T → E × SE(3)` 把任务动作序列 `A_T` 绑定到实体假设与该实体的局部坐标系。

**定义 122（姿态条件动作剖面）**
技能 `S` 在实体 `e` 上的姿态条件剖面
`α_S(a | ξ_e, Σ_e) = P(a feasible | ξ_e, Σ_e)`。
给定姿态信念采样 `{ξ_e^{(k)} ∼ N(ξ_e,Σ_e)}_{k=1..n}`，其经验估计为 `α̂_S(a|e) = (1/n)Σ_k 1[S.feasible(a, ξ_e^{(k)})]`。**保守覆盖**定义为对 `α̂` 的置信下界 `α^-` 仍满足 `α^-(a|e) ≥ θ_cov`。

**定义 123（姿态不确定动作管）**
`U_a = { a' ∈ A : d_A(a', a) ≤ κ·√(λ_max(J_g Σ_e J_g^T)) }`，其中 `J_g = ∂g/∂ξ` 为锚定映射在 `ξ_e` 处的雅可比，`κ` 为覆盖分位数。若 `U_a ⊆ A_cert ∪ A_buffer`，称动作 `a` 在姿态不确定下**管包含**。

**定义 124（语义-几何一致性分数）**
`SGCS(e) = w_1·f_rp(e) + w_2·f_aff(e) + w_3·f_xv(e)`，其中 `f_rp` 为重投影残差的归一化得分，`f_aff` 为可供性-接触残差得分，`f_xv` 为跨视角位姿一致性得分，`w_i ≥ 0, Σw_i = 1`。认证要求 `SGCS(e) ≥ θ_sg` 且三路证据无单路否决。

**定义 125（场景-动作锚定证书）**
`SAGC = (g, G_SP, SGCS, {U_a}_{a∈A_T}, evidence)`，其中 `g` 为锚定映射，`G_SP` 为锚定图，`U_a` 为动作管，`evidence` 至少含多视图观测、重投影残差、跨视角反例。若 `∀a∈A_T`：锚定身份一致、`SGCS ≥ θ_sg`、`U_a` 管包含，则 `SAGC` 可传递。

**定义 126（姿态-场景-动作三元证书）**
`J_3 = (ρ, A_cert, γ_ce, δ_a, g, Σ_ξ, SGCS, SAGC, evidence)`，在第 54 轮联合证书 `J` 上增加锚定映射 `g`、姿态协方差 `Σ_ξ`、语义-几何一致性 `SGCS` 与锚定证书 `SAGC`。部署条件：
```
dom(T)=in ∧ δ_a<Θ_a ∧ SGCS≥θ_sg ∧ ∀a: U_a⊆A_cert∪A_buffer ∧ grounding_consistent(g)
```

## 2. 关键算法 伪代码

### IP-121 SPG（Scene-Pose Graph）

```python
def build_scene_pose_graph(views, pose_estimator, scene_parser, calib):
    G = ScenePoseGraph()
    for v in views:
        det = scene_parser.detect(v)
        for e in det.entities:
            xi, Sigma = pose_estimator.estimate(v, e, calib)   # calibrated
            G.add_entity(e.id, label=e.label, xi=xi, Sigma=Sigma,
                         affordances=e.affordances, view=v.id)
        for (e1, e2, r) in det.relations:
            T, Sigma_T = relative_transform(G[e1].xi, G[e2].xi,
                                            G[e1].Sigma, G[e2].Sigma)
            G.add_relation(e1, e2, r, T=T, Sigma_T=Sigma_T)
    G = fuse_multi_view(G, covariance_aware=True)   # robust fusion
    return G
```

### IP-122 PCAP（Pose-Conditioned Action Profile）

```python
def pose_conditioned_profile(skill, G, A_probe, n=256):
    alpha = {}
    for e_id, e in G.entities.items():
        samples = sample_poses(e.xi, e.Sigma, n)      # calibrated ellipsoid
        for a in A_probe:
            hits = sum(skill.feasible(a, pose) for pose in samples)
            lo, hi = clopper_pearson(hits, n, conf=0.95)
            alpha[(e_id, a)] = (lo, hi)               # conservative lower bound
    return alpha

def cover_check_conservative(alpha, target, e_id, theta_cov):
    return all(alpha[(e_id, a)][0] >= theta_cov for a in target)
```

### IP-123 SGCC（Semantic-Geometric Consistency Certifier）

```python
def semantic_geometric_consistency(e, G, rgbd, intrinsics):
    rp  = reprojection_residual(e.xi, e.mask, intrinsics)
    aff = affordance_contact_residual(e.label, e.xi, rgbd)
    xv  = cross_view_pose_residual(e.id, G)
    score = (w1 * (1 - squash(rp)) + w2 * (1 - squash(aff))
             + w3 * (1 - squash(xv)))
    return SGCS(score, parts=(rp, aff, xv))

def certify_grounding(e, G, theta_sg):
    s = semantic_geometric_consistency(e, G, rgbd, intrinsics)
    if s.value < theta_sg:
        return ('reject', 'low_sg_consistency', s)
    return ('ok', s)
```

### IP-124 PUAT（Pose Uncertainty Action Tube）

```python
def pose_uncertainty_action_tube(skill, e, a, kappa=3.0):
    Jg = grounding_jacobian(skill.grounding_map, e, a)
    Sigma_a = Jg @ e.Sigma @ Jg.T
    r_a = kappa * sqrt(max_eig(Sigma_a))
    return ActionTube(center=a, radius=r_a, cov=Sigma_a)

def certify_tube(U, A_cert, A_buffer):
    return set_contains_interval(A_cert | A_buffer, U)   # interval/采样验证
```

### IP-125 GAC（Grounded Action Certificate）

```python
def grounded_composition_certificate(S1, S2, g1, g2, G, A_cert, delta_budget):
    if not same_grounding(g1, g2):        # entity id + frame + label hypothesis
        return ('reject', 'grounding_identity_mismatch')
    U1 = pose_uncertainty_action_tube(S1, G[g1.entity], g1.action)
    U2 = pose_uncertainty_action_tube(S2, G[g2.entity], g2.action)
    if not (certify_tube(U1, A_cert) and certify_tube(U2, A_cert)):
        return ('reject', 'tube_escape')
    if max(U1.radius, U2.radius) > delta_budget:
        return ('reject', 'action_uncertainty_budget')
    return ('ok', GAC(g1, g2, U1, U2, evidence))
```

### IP-126 APG（Active Perception Gate）

```python
def active_perception_gate(G, targets, budget_views, theta_sg, delta_budget):
    while budget_views > 0:
        bad = [e for e in targets
               if SGCS(e) < theta_sg or tube_radius(e) > delta_budget]
        if not bad:
            return ('ok', G)
        v = argmax(views, key=lambda v: expected_tube_reduction(bad, v) / cost(v))
        G = fuse(G, observe(v), reestimate=True)
        budget_views -= 1
    return ('defer', G, explain_remaining_uncertainty(G, targets))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SPG | O(\|V\|·\|E\|·C_pose + \|R\|) | O(\|E\|+\|R\|) | 协方差校准、融合一致 |
| PCAP | O(\|E\|·\|A\|·n) | O(\|E\|·\|A\|) | 采样覆盖、置信下界 sound |
| SGCC | O(\|E\|·\|V\|·pixels) | O(\|E\|) | 三路证据独立、阈值 sound |
| PUAT | O(\|A\|·6³) | O(\|A\|) | `J_g` Lipschitz、管包含可判定 |
| GAC | O(\|S\|·\|A\|+\|E\|) | O(\|A\|+\|E\|) | 锚定身份守恒、预算闭合 |
| APG | O(k·\|views\|·\|bad\|) | O(\|E\|+\|V\|) | 门控终止、defer 安全 |

**正确性定理（Pose-Grounded Action Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 姿态估计的协方差经 conformal 校准，真实位姿落在 `κ`-椭球内的概率 `≥ 1-α_pose`；**(A30)** 锚定映射 `g` 在认证域上局部 `L_g`-Lipschitz；**(A31)** SGCS 的假接受率 `≤ β_SG`，且三路证据至少一路来自独立物理/视角探针；**(A32)** 主动感知门控在 `τ_ap` 内终止，超预算时 `defer` 不改变任务状态。
则对通过 `J_3` 部署的组合：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a) - α_pose - β_SG
```
该界用并集界，不要求各事件独立；但当姿态误差与语义误差正相关时，`α_pose` 与 `β_SG` 会同时升高，界会明显变松——这正是本轮最需要防守的方向。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 姿态协方差在遮挡/反光/小目标下失准 | 高 | conformal 校准 + 独立深度/触觉探针 + 最坏情况膨胀 |
| SGCS 与姿态共享特征导致相关性 | 高 | 独立证据源 + 反事实/红队场景 + 分歧即拒绝 |
| 场景图关系传递误差累积 | 中 | 仅局部锚定，关系作软先验，不经长链传播 |
| 主动感知延迟/能耗超预算 | 中 | 预算门控 + `defer` 安全回退 + 缓存视角 |
| 开放词汇本体跨场景漂移 | 高 | 开放词汇对齐 + 锚点回归 + 冷启动人工校准 |

## 6. 本轮最大风险

**一句话**：姿态-场景-动作三元证书把“动作指向哪里”从经验默认变成可判定锚定，但其 soundness **同时依赖姿态协方差的分布外校准、锚定映射的局部 Lipschitz 性、以及 SGCS 证据源的独立性**；一旦遮挡/反光/小目标让协方差系统性偏小、且 SGCS 与姿态估计共享同向视觉误差，`U_a` 会低覆盖却仍通过认证，系统将在“语义-几何共谋”的假锚点上执行不可逆动作，故必须以 **conformal 校准 + 独立物理探针 + 分歧即 defer** 三重护栏，宁可不动也不在未独立验证的锚点上动作。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SPG×PCAP×SGCC×PUAT×GAC×APG）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书之上，补上更前置的 **场景锚定层**：动作到底指向哪个实体、哪个坐标系、以多大几何置信度指向它。
> - **SPG（Scene-Pose Graph）**：场景语义拓扑 × 姿态度量锚点，带协方差传播；
> - **PCAP（Pose-Conditioned Action Profile）**：把姿态不确定性传播进 `α_S(a|ξ,Σ)`；
> - **SGCC（Semantic-Geometric Consistency Certifier）**：重投影/可供性/跨视角三路交叉验证；
> - **PUAT（Pose Uncertainty Action Tube）**：姿态协方差经 `J_g` 映射为动作管；
> - **GAC（Grounded Action Certificate）**：锚定身份守恒 + 管包含的组合边证书；
> - **APG（Active Perception Gate）**：先感知认证、再动作执行的 next-best-view 门控。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118 以纳入锚定与姿态不确定维度。

    Jg = grounding_jacobian(skill.grounding_map, e, a)
    Sigma_a = Jg @ e.Sigma @ Jg.T
    r_a = kappa * sqrt(max_eig(Sigma_a))
    return ActionTube(center=a, radius=r_a, cov=Sigma_a)

def certify_tube(U, A_cert, A_buffer):
    return set_contains_interval(A_cert | A_buffer, U)

### IP-125 GAC

```python
def grounded_composition_certificate(S1, S2, g1, g2, G, A_cert, delta_budget):
    if not same_grounding(g1, g2):
        return ('reject', 'grounding_identity_mismatch')
    U1 = pose_uncertainty_action_tube(S1, G[g1.entity], g1.action)
    U2 = pose_uncertainty_action_tube(S2, G[g2.entity], g2.action)
    if not (certify_tube(U1, A_cert) and certify_tube(U2, A_cert)):
        return ('reject', 'tube_escape')
    if max(U1.radius, U2.radius) > delta_budget:
        return ('reject', 'action_uncertainty_budget')
    return ('ok', GAC(g1, g2, U1, U2, evidence))
```

### IP-126 APG

```python
def active_perception_gate(G, targets, budget_views, theta_sg, delta_budget):
    while budget_views > 0:
        bad = [e for e in targets
               if SGCS(e) < theta_sg or tube_radius(e) > delta_budget]
        if not bad:
            return ('ok', G)
        v = argmax(views, key=lambda v: expected_tube_reduction(bad, v) / cost(v))
        G = fuse(G, observe(v), reestimate=True)
        budget_views -= 1
    return ('defer', G, explain_remaining_uncertainty(G, targets))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SPG | O(\|V\|·\|E\|·C_pose+\|R\|) | O(\|E\|+\|R\|) | 协方差校准、融合一致 |
| PCAP | O(\|E\|·\|A\|·n) | O(\|E\|·\|A\|) | 采样覆盖、置信下界 sound |
| SGCC | O(\|E\|·\|V\|·pixels) | O(\|E\|) | 三路证据独立、单路否决 |
| PUAT | O(\|A\|·6³) | O(\|A\|) | `J_g` Lipschitz、管包含可判定 |
| GAC | O(\|S\|·\|A\|+\|E\|) | O(\|A\|+\|E\|) | 锚定身份守恒、预算闭合 |
| APG | O(k·\|views\|·\|bad\|) | O(\|E\|+\|V\|) | 门控终止、defer 安全 |

**正确性定理（Pose-Grounded Action Soundness）**
假设第 54 轮 (A26)–(A28) 成立；新增 **(A29)** 姿态协方差 conformal 校准，真实位姿在 `κ`-椭球内概率 `≥1-α_pose`；**(A30)** `g` 在认证域局部 `L_g`-Lipschitz；**(A31)** SGCS 假接受率 `≤β_SG`，且至少一路证据独立于姿态特征；**(A32)** APG 在 `τ_ap` 内终止，超预算 `defer` 不改变任务状态。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a) - α_pose - β_SG
```
并集界不要求独立；但当姿态误差与语义误差正相关时，`α_pose` 与 `β_SG` 同时升高，界会变松，必须用独立探针收紧。

## 6. 本轮最大风险

**一句话**：姿态-场景-动作三元证书把“动作指向哪里”从经验默认变成可判定锚定，但其 soundness **同时依赖姿态协方差的分布外校准、锚定映射的局部 Lipschitz 性、以及 SGCS 证据源的独立性**；一旦遮挡/反光/小目标让协方差系统性偏小、且 SGCS 与姿态估计共享同向视觉误差，`U_a` 会低覆盖却仍通过认证，系统将在“语义-几何共谋”的假锚点上执行不可逆动作，故必须以 **conformal 校准 + 独立物理探针 + 分歧即 defer** 三重护栏，宁可不动也不在未独立验证的锚点上动作。
