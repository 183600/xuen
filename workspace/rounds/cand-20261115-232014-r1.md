# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「消融实验」×「多语言支持」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**跨语言配平 + 消融证书 + 语言中立退化**。两个灵感分别治理 v9 的两种债：**归因债**（ID 的 EMA 贡献是点估计，无覆盖保证、受非平稳与可选停止混淆）与**语用债**（单语言指令路径，多语言下没有不变性/安全性论证）。本轮的核心反转是：**多语言不是负担，而是免费的消融维度**——同一语义的 L 种表层实现是天然的反事实干预；而消融实验则为"多语言鲁棒性"提供统计上可辩护的归因。所有新模块保持可选：任一失效即注入语言中立元，严格退回 v9。

## 0. 直觉与动机

**灵感 1（消融实验 → 消融证书：从点估计到区间证据）**
直觉：v9 的 InnovationDistiller 用 500 周期消融加 EMA 得到 c_m，再靠 Schmitt 阈值让模块休眠。这在统计上很脆弱：非平稳、序列相关、可选停止、多模块同时比较——EMA 点估计既没有覆盖保证，也可能把"暂时没用"误判成"永远没用"，而一旦误睡的是语言桥模块，多语言任务会静默退化。更严谨的做法是把每个消融回合看作一次有界结果的序贯实验：用 e-value/置信序列给出 anytime-valid 区间，只允许"上界仍低于休眠阈"的模块休眠（保守方向），并用 e-BH 控制多模块错误发现。核心创新：**消融证书器（AblationCertifier, ABC）**——把 ID 的 c_m 升级为带覆盖保证的 [c⁻, c⁺]，把"提炼"从启发式变成可审计的统计决策。副产品：14 个 IP 的论文主张第一次拥有可复现的贡献区间。

**灵感 2（多语言支持 → 跨语言平行探针）**
直觉：多语言支持通常被当作"多接几个 ASR/翻译前端"的工程问题；但同一个意图用 L 种语言表达，恰好是对"表层语言"的一次受控消融——语义保持不变，表层变化。若策略对语言敏感，动作就会发散；若翻译或解析不可靠，语义骨架就会不一致。核心创新：**跨语言消融探针（CrossLingualAblationProbe, XLA）**：在指令边界生成/检索 L 个经双向蕴含校验的平行指令，抽取语言中立语义骨架 s=(意图, 实体, 关系, 约束, 风险类, 否定作用域, 单位量纲)，测量动作发散 D_t 与逐模块语言敏感度。配套 **多语言共识门（CrossLingualConsensusGate, XLCG）**：当语义一致度/动作一致度/视觉接地三者组成的共识分 κ 低而风险类高时，不执行不可逆动作，改为最小澄清或语言中立安全动作（停/退/保持）。

**灵感 3（综合 → 语言×模块的二维消融几何）**
直觉：把"模块"和"语言"同时作为消融因子做配对因子设计，可以得到语言条件贡献张量 C_{m,ℓ}——模块 m 在语言 ℓ 下的条件贡献。它回答 v9 回答不了的问题：某模块是"核心模块"（所有语言都重要）、"语言桥"（只在非主语言重要）、还是"语言捷径"（只对表层 token 敏感、换语言就失效）。这张张量可用于按语言重新分配计算，但安全关键模块永不消融；语言识别置信度不足时退回"全语言、全模块"的 v9 模式。需要提前声明一个认识论边界：共识只能发现"分歧"，不能证明"正确"；跨语言共因错误（所有语言被同一错误骨架误导）在纯语言观测下不可辨识，因此高风险动作还需独立的视觉/环境接地或人类确认，而不能只靠"多语言一致"。

## 1. 研究问题（轮次升级版）

- **Q1（消融统计）**：在非平稳、序列相关、可选停止的在线数据上，如何为每个可选模块构造 anytime-valid、多重比较可控的贡献证书？配对的语言×模块因子设计能否在不增加控制周期开销的前提下显著降低估计方差并识别交互效应？
- **Q2（跨语言不变性）**：在什么保真假设下，"平行指令动作发散小"能推出"策略对表层语言不变"？当发散大时，如何区分"指令本身歧义"、"翻译/解析失真"与"策略依赖语言捷径"三种原因？
- **Q3（共识门安全）**：如何设计门控使高风险动作集是 v9 动作集的子集（只加约束、绝不放大），同时在语义正确时不过度拦截？最小澄清问题如何选，才能以最少回合消除风险？
- **Q4（不可辨识边界）**：跨语言共因语义错误在什么条件下无法被任何仅依赖语言观测的门发现？需要哪种独立接地通道才能把"共识"升级为"可信"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 跨语言配平律（Cross-Lingual Parallelism, XLA）**
每个高风险/不可逆指令在执行前必须拥有一个经双向蕴含校验的平行指令族 U={u_ℓ} 与语言中立语义骨架 s；测得的动作发散 D 与语义一致度 S_sem 共同决定共识分 κ。平行族不可得、保真度不足或语言识别置信度低时，不做"假装多语言"的探测，直接退回单语言 v9 路径。

**P14 消融证书律（Certified Ablation, ABC）**
模块贡献是区间而非点：只有贡献上界 c⁺ 低于休眠阈 τ_off 的模块才可进入 dormant；下界 c⁻ 高于唤醒阈 τ_on 的模块保持 active；多模块休眠用 e-BH 控制 FDR；安全关键模块 φ^elig=false，永不消融，其"贡献"记为 ∞。非平稳数据一律使用 anytime-valid e-process，禁止用固定样本 p 值做可选停止决策。

**P15 语言中立退化律（Language-Neutral Degradation, LND）**
多语言资产、翻译保真、语言识别、消融证书任一失效 ⇒ 注入语言中立元：L={ℓ0}、D≡0、S_sem≡1、κ≡1（门直通）、LAM=∅、ID 回退 v9 EMA 或冻结全 active。语言中立元保证新模块只做"加法约束"：门通过时逐位等价 v9，门拦截时动作集是 v9 的保守子集；绝不产生 v9 不会产生的动作。

## 3. 与基线的接口（如何退化）

- XLCG 失效（语言识别失败 / 低资源语言未覆盖 / 接地不可用）⇒ L={ℓ0}，κ≡1，门直通，逐位等价 v9；
- XLA 失效（翻译保真不足 / 平行族为空）⇒ D≡0，不探测，门直通，等价 v9；
- ABC 失效（e-process 校准失败 / 证书不可计算）⇒ 回退 v9 ID 的 EMA 归因，或更保守地冻结全模块 active，等价 v9（ID 原语义）；
- LAM 失效（缓存过期 / 哈希不符 / 投毒嫌疑）⇒ 清空缓存，禁用探测，门直通，等价 v9；
- v9 ACMD 失效 ⇒ K_eff←1 + MW 网关，退 v8；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / weight≡1），退 v7；全失效退 v6。

## 4. 预期贡献

1. **消融证书**：把 v9 ID 的启发式 EMA 升级为 anytime-valid、FDR 可控的模块贡献区间；"休眠"变成可审计的统计决策，且误睡方向被上界规则严格约束；
2. **跨语言消融**：把多语言平行指令变成免费的受控干预，得到语言条件贡献张量 C_{m,ℓ}，首次能区分核心模块、语言桥与语言捷径，并支撑按语言的计算再分配；
3. **多语言共识门**：以"语义一致 + 动作一致 + 独立视觉接地"三元共识约束高风险/不可逆动作；门只加约束，安全性对 v9 单调，失效即直通；
4. **共因不可辨识边界**：形式化证明仅靠跨语言一致性无法排除系统性共因语义错误，从而把"多语言一致"从安全证明降级为风险信号，并给出独立接地/澄清的必要性；
5. **E571–E590**：覆盖平行指令保真、发度基准、证书覆盖、可选停止、FDR、因子设计方差、语言条件归因、IP 审计、语言捷径对抗、否定/量词/单位、共因压力、退化等价、实时预算、端到端多语言任务与长跑。

## 5. 本轮最大风险

**一句话**：跨语言消融与共识门把"语言间分歧"当作风险，却无法识别"跨语言共因错误"——当所有语言经由同一个翻译记忆/同一个语义骨架/同一套解析规则被系统性误导时，分歧反而变小、共识反而变高，系统会在最需要外部接地的时刻把"一致地错"误读成"安全"，即「共识门只能测分歧，不能证正确」。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-LAMBDA**（Language-Ablation Multilingual Bounded-Divergence Assurance）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「消融实验」×「多语言支持」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）全部保留；v9 的 AC/MW/ID 与 v8 的 DA-ML/SPR/Cal 原样继承。新组件一律为**可选增强**：任一新环节不可用 ⇒ 注入语言中立元，严格退回 v9 行为（引理 91），而非行为漂移。核心铁律：**多语言只提供风险信号，不提供安全证明；消融只做计算再分配，不做安全删码。**

**新增定义 540（语言指令族与语义骨架 Language Instruction Family & Semantic Skeleton）**
一次高风险指令 u 的平行族为 `U = {u_ℓ}_{ℓ∈L}`，要求所有 `u_ℓ` 表达同一意图。语义骨架为
```
s(u) = (ι, E, R, C, r, ν, υ)
```
其中 `ι` 为意图（导航/抓取/放置/协同/停止等），`E` 为实体与指代，`R` 为空间/时序关系，`C` 为硬约束（禁入区、力上限、速度上限），`r ∈ {low, high, irreversible}` 为风险类，`ν` 为否定/量词作用域，`υ` 为数值与单位量纲。骨架由解析器集成抽取，并作为后续一致度与门控的统一表示；**原始语言 token 不进入安全判据**。

**新增定义 541（平行族保真 Parallel-Family Faithfulness）**
设 `E(a ⇒ b) ∈ [0,1]` 为双向蕴含模型给出的 `a` 蕴含 `b` 的置信度。定义
```
S_sem(U) = min_{ℓ∈L} min( E(u_ℓ ⇒ s), E(s ⇒ u_ℓ) )
φ_fid(U) = [S_sem(U) ≥ τ_sem] ∧ [min_ℓ E(backtrans(u_ℓ) ⇒ u_{ℓ0}) ≥ τ_sem]
           ∧ [∀ℓ: 解析成功且单位/否定作用域一致]
```
`φ_fid=0` 时平行族整体视为**不可用**，不得用它做安全判断；XLA 与 XLCG 同时退回语言中立元（定义 547）。

**新增定义 542（跨语言消融矩阵与发散度 Cross-Lingual Ablation Matrix）**
对每个语言 ℓ 与可选模块 m，记录归一化输出/动作 `A_{ℓ,m} ∈ [0,1]`（连续动作用归一化 ℓ∞ 距离，离散动作用指示变量）。定义
```
D_t      = max_{ℓ≠ℓ'} d( A_{ℓ,·}, A_{ℓ',·} ) / d_max
D_{t,m}  = max_{ℓ≠ℓ'} | A_{ℓ,m} − A_{ℓ',m} |
```
其中 `d` 为动作空间距离（随机策略用成对总变差距离）。`D_t` 是"表层语言消融"下策略的敏感度；`D_{t,m}` 是模块 m 对语言表层的敏感度。注意：`D` 只度量**分歧**，不度量**正确性**。

**新增定义 543（消融证书 Ablation Certificate）**
对模块 m，消融结果为有界变量 `X_i ∈ [0,1]`（第 i 回合的归一化任务进展差，已扣安全罚）。对休眠阈值 `μ0=τ_off` 构造下尾 e-process
```
E_m^-(τ_off) = ∏_{i=1}^{r_m} (1 + λ_i (τ_off − X_i)),   0 ≤ λ_i ≤ 1/(1−τ_off)
```
检验 `H_m^sleep: E[X] ≥ τ_off`；拒绝即"贡献显著低于休眠阈"。对唤醒阈值 `τ_on` 构造上尾 e-process
```
E_m^+(τ_on) = ∏_{i=1}^{r_m} (1 + λ_i (X_i − τ_on)),   0 ≤ λ_i ≤ 1/τ_on
```
检验 `H_m^wake: E[X] ≤ τ_on`；拒绝即"贡献显著高于唤醒阈"。由 e-value 反演得到单侧界 `c_m^-, c_m^+`，证书为
```
C_m = ( [c_m^-, c_m^+], E_m^-(τ_off), E_m^+(τ_on), r_m )
```
多模块休眠使用 e-BH：把 `E_m^-(τ_off)` 降序排列，若第 k 大的 e-value `≥ M/(kα)` 则拒绝对应休眠原假设。**安全模块 φ^elig=false 不参与任何检验，贡献记为 ∞。**

**新增定义 544（语言条件贡献张量 Language-Conditional Contribution）**
在语言 ℓ 下对模块 m 做配对消融，得到
```
C_{m,ℓ} = E[ J_with(m,ℓ) − J_without(m,ℓ) | ℓ ]
```
其证书区间由定义 543 的分层 e-process 给出；交互效应定义为
```
I_{m,ℓ} = C_{m,ℓ} − C_{m,ℓ0}
```
`I_{m,ℓ}` 显著大于 0 ⇒ m 是"语言桥"；`C_{m,ℓ0}` 与 `C_{m,ℓ}` 都高 ⇒ "核心模块"；`C_{m,ℓ}` 随语言剧烈翻转或仅在表层扰动下高 ⇒ "语言捷径"嫌疑（结合 E581 判别）。张量用于按语言重新分配可选模块的计算，但 φ^elig=false 模块始终全语言常开。

**新增定义 545（多语言共识分与门控 Consensus Score & Gate）**
```
κ_t = min( S_sem(U), 1 − D_t, G_vis(s, obs) )
```
其中 `G_vis` 为独立视觉/环境通道对骨架中实体、关系与约束的接地置信度。门控谓词：
```
pass(t) = (r = low)        ⇒ κ_t ≥ τ_κ^low
          (r = high)       ⇒ κ_t ≥ τ_κ
          (r = irreversible) ⇒ κ_t ≥ τ_κ ∧ G_vis ≥ τ_g
```
`pass=0` 时：高风险/不可逆动作**不得执行**，转为最小澄清（定义 546）或语言中立安全动作（停/退/保持）；低风险动作降级为保守动作。门控只增加合取条件，因此通过门控的动作集是 v9 动作集的子集（引理 88）。

**新增定义 546（最小澄清集 Minimal Disambiguation Set）**
候选问题集 `Q`，每个问题 q 的答案为 `a_q`，待消歧变量为风险类 r、关键实体 E 与否定作用域 ν。最小澄清集为
```
Q* = argmax_{Q'⊆Q, |Q'|≤q_max} I( (r,E,ν); {a_q}_{q∈Q'} )
```
即在最多 `q_max` 个问题内最大化期望信息增益。澄清必须用用户原语言提问；超时或用户不答 ⇒ 执行语言中立安全动作，而不是猜测。

**新增定义 547（语言中立元 Language Neutral Element）**
```
v^⊥_lang = ( L←{ℓ0}, U←{u_{ℓ0}}, D≡0, S_sem≡1, κ≡1,
             φ_fid≡0, LAM←∅, C_{m,ℓ}←C_m^{v9}, gate←pass )
```
其中 `C_m^{v9}` 为 v9 ID 的 EMA 归因（或"全模块 active"冻结态）。注入后 XLA/XLCG/LAM 全部旁路，系统进入 v9 的单语言控制流；ID 仍按 v9 语义工作。语言中立元是"可选增强失效"的唯一合法后缀。

**新增定义 548（配对消融设计 Paired Ablation Design）**
因子集 `F = M_elig × L × S_env`（可选模块、语言、环境种子）。每回合用**配对块**：同一环境种子、同一初始状态、同一指令意图，只改变模块开关与语言渲染；用分数因子设计（分辨率 ≥ IV）估计主效应与模块×语言二阶交互。显著性由定义 543 的 e-process 给出；所有比较预注册，禁止事后挑选休眠模块。

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。

```
δ_trigger = {σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom

```

```python
# IP-357：跨语言消融探针
class CrossLingualAblationProbe:
    def __init__(self, translator, entailer, parser, lang_set, tau_sem=0.8):
        self.translator, self.entailer, self.parser = translator, entailer, parser
        self.L, self.tau_sem = lang_set, tau_sem

    def render(self, u, lang):
        """生成/检索平行族；返回 (U, S_sem, phi_fid)"""
        U = {l: self.translator.render(u, l) for l in self.L}
        s = self.parser.skeleton(U[self.L[0]])
        s_sem = min(min(self.entailer(u_l, s), self.entailer(s, u_l))
                    for u_l in U.values())
        bt_ok = min(self.entailer(self.translator.back(u_l), u)
                    for u_l in U.values()) >= self.tau_sem
        unit_ok = all(self.parser.units_consistent(u_l, s) for u_l in U.values())
        return U, s_sem, (s_sem >= self.tau_sem and bt_ok and unit_ok), s

    def probe(self, policy, U, state, modules):
        """指令边界执行；返回 A, D, D_m（影子/缓存，不在 50Hz 热路径）"""
        A = {}
        for l, u_l in U.items():
            out = policy.shadow(u_l, state)
            for m in modules:
                A[(l, m)] = normalize(out[m])
        D = max(pairwise_dist(A[(l, slice(None))], A[(l2, slice(None))])
                for l in U for l2 in U if l != l2)
        D_m = {m: max(abs(A[(l, m)] - A[(l2, m)]) for l in U for l2 in U)
               for m in modules}
        return A, D, D_m


# IP-358：消融证书器（ABC 是 ID 的估计器/证书层，不替代 ID 调度）
class AblationCertifier:
    def __init__(self, tau_off=0.01, tau_on=0.03, alpha=0.05):
        self.tau_off, self.tau_on, self.alpha = tau_off, tau_on, alpha
        self.e_sleep, self.e_wake, self.r = {}, {}, {}

    def _bet(self, x, mu0, upper):
        # 有界 e-value 的可预测下注；lambda 取保守常数
        lam = 0.5 / (1 - mu0) if upper else 0.5 / mu0
        return 1 + lam * ((x - mu0) if upper else (mu0 - x))

    def update(self, m, x):
        self.r[m] = self.r.get(m, 0) + 1
        self.e_sleep[m] = self.e_sleep.get(m, 1.0) * self._bet(
            x, self.tau_off, upper=False)          # 检验 μ ≥ τ_off
        self.e_wake[m] = self.e_wake.get(m, 1.0) * self._bet(
            x, self.tau_on, upper=True)            # 检验 μ ≤ τ_on

    def sleep_hypotheses(self):
        """e-BH：返回可休眠模块集合，控制 FDR ≤ alpha"""
        items = sorted(((self.e_sleep.get(m, 1.0), m) for m in self.e_sleep),
                       reverse=True)
        M = len(items)
        rejected = set()
        for k, (e, m) in enumerate(items, start=1):
            if e >= M / (k * self.alpha):
                rejected.add(m)
        return rejected

    def sleep_ok(self, m, rejected):
        return m in rejected and self.upper_bound(m) < self.tau_off

    def upper_bound(self, m):
        # 由 e-process 反演；实现中用网格/二分求最小 μ0 使 E^-(μ0) < 1/α
        return invert_e_process(self.e_sleep[m], self.alpha, side='upper')

    def lower_bound(self, m):
        return invert_e_process(self.e_wake[m], self.alpha, side='lower')


# IP-359：多语言共识门
class CrossLingualConsensusGate:
    def __init__(self, tau_kappa=0.7, tau_low=0.5, tau_g=0.6):
        self.tau_kappa, self.tau_low, self.tau_g = tau_kappa, tau_low, tau_g

    def score(self, s_sem, d, g_vis):
        return min(s_sem, 1.0 - d, g_vis)

    def verdict(self, risk, kappa, g_vis):
        if risk == 'irreversible':
            ok = kappa >= self.tau_kappa and g_vis >= self.tau_g
        elif risk == 'high':
            ok = kappa >= self.tau_kappa
        else:
            ok = kappa >= self.tau_low
        return 'pass' if ok else 'hold'

    def clarify(self, posterior, candidates, q_max=2):
        """按定义 546 最大化期望信息增益；返回 Q*"""
        return max(combinations(candidates, q_max),
                   key=lambda Q: expected_info_gain(posterior, Q))
```

## 4. 推导

**引理 87（消融证书的 anytime-valid 覆盖与 FDR 控制）** 设 `X_i ∈ [0,1]` 且下注系数 `λ_i` 关于历史可预测。对任意 `μ0∈(0,1)`，若 `H0: E[X_i|F_{i-1}] ≥ μ0`，则 `E_m^-(μ0)=∏(1+λ_i(μ0−X_i))` 为非负超鞅，且 `E[E_m^-]≤1`；由 Ville 不等式，
```
P( ∃r: E_m^-(μ0) ≥ 1/α ) ≤ α.
```
故反演所得单侧上界 `c_m^+` 满足 `P(∃r: c_m^+ < μ0) ≤ α`（对所有 μ0 同时成立），即 anytime-valid 覆盖。对 `H_m^sleep: E[X]≥τ_off`，`c_m^+<τ_off` 等价于在水平 α 下拒绝；因此误睡概率 ≤α。多模块用 e-BH：在任意相依下，若拒绝规则为第 k 大 e-value `e_(k)≥M/(kα)`，则 `FDR≤α`。故 `sleep_ok` 的误睡方向受控，且不会因可选停止而失效。∎

**引理 88（共识门的安全单调性）** 门控谓词 `pass(t)` 是 v9 触发条件之外的附加合取项；`pass=0` 时动作被替换为澄清或语言中立安全动作，`pass=1` 时 v9 仍须满足其全部条件。因此对任意状态，
```
Act_v10(t) ⊆ Act_v9(t),
```
即 v10 接受的高风险/不可逆动作集是 v9 的子集。特别地，`v^⊥_lang` 注入使 `pass≡1`，此时 `Act_v10=Act_v9`（逐位等价）。因此 v9 的任何安全不变式在 v10 下保持；门控只会"少做"，不会"多做"。∎

**引理 89（保真假设下的共识可靠性）** 设策略 π 关于语义嵌入 φ 是 L-Lipschitz：`d(π(u),π(u')) ≤ L·‖φ(u)−φ(u')‖`；设平行族与解析器对真实语义 `s*` 的误差有界 `‖φ(u_ℓ)−φ(s*)‖ ≤ ε`。则
```
d(π(u_ℓ), π(u_ℓ')) ≤ 2Lε.
```
故若观测到 `D_t > τ`，则必有 `ε > τ/(2L)`（翻译/解析失真）或 π 在语义邻域内非 Lipschitz（策略不稳定/语言捷径）。若 `D_t ≤ τ`，则平行族上的动作差异被 `τ` 界住。该引理是**条件诊断**而非绝对保证：它把发散分解为"输入失真"与"策略不稳定"两类可检验原因，但要求保真假设（定义 541）成立；保真失败时 XLA 直接注入中立元，不产生安全主张。∎

**引理 90（配对跨语言消融的方差缩减）** 对同一环境种子、同一初始状态的配对差 `Δ=X_with−X_without`，
```
Var(Δ) = Var(X_with) + Var(X_without) − 2Cov(X_with, X_without).
```
环境与任务难度是共同分量，通常 `Cov≥0`，故 `Var(Δ) ≤ Var(X_with)+Var(X_without)`；达到精度 δ 所需回合数从 `O((σ_with²+σ_without²)/δ²)` 降至 `O(σ_Δ²/δ²)`。进一步，语言与模块的因子设计把环境主效应块化，二阶交互 `I_{m,ℓ}` 的估计方差同样被配对块削减。故在相同控制周期预算下，ABC 的证书区间更窄、检出语言桥/语言捷径的功率更高。∎

**引理 91（语言中立元退化与 v9 等价）** 按表 547 注入 `v^⊥_lang` 后：XLA 不探测 ⇒ `D≡0, S_sem≡1`；XLCG 不评分 ⇒ `κ≡1, pass≡1`；LAM 清空 ⇒ 无缓存命中；ABC 回退 v9 EMA 或冻结全 active ⇒ ID 输入与 v9 相同。于是每周期调用的模块集合、注入的中立元、AC 的 `K_eff` 与 MW 的调度顺序全部与 v9 一致，可观测输出逐位相等。部分失效时：XLA 失效但 XLCG 仍在 ⇒ 无探测数据，门因 `φ_fid=0` 直通；XLCG 失效但 XLA 仍在 ⇒ 探针仅记录不门控；两者均不改变动作集。∎

**引理 92（实时预算与 50Hz 守恒）** XLA 只在指令边界运行（≤1Hz），且 LAM 命中时 ≤0.5ms；ABC 在 1Hz 非关键路径更新，e-BH 为 `O(M log M)`，M≈16；XLCG 每周期只做 `min` 与阈值比较，O(1) ≤0.1ms；视觉接地复用 v9 感知结果，不新增同步阻塞。故相对 v9 的决策侧增量 ≤0.2ms，典型 ≤8.2ms、p99 ≤20ms，50Hz 控制周期保持。若探针未在时限内完成，按中立元直通并在下一指令边界重试，绝不阻塞安全闭环。∎

**引理 93（跨语言共因语义不可辨识）** 存在两个世界 `w` 与 `w'`，其真实意图 `y≠y'`，但翻译/解析通道对两者输出**相同**的平行族 U 与相同骨架 s（例如系统性误译把"关门"统一译成"开门"）。任何仅以 U、s、A 为输入的决策规则在两个世界下观测分布完全相同，故其贝叶斯错误率不低于先验较小者；不存在仅靠跨语言一致性的检验能保证语义正确。因此 `κ` 只能作为"分歧/失真"风险信号，不能作为"语义正确"的证明；高风险/不可逆动作必须引入独立接地通道（视觉/环境约束/人类确认），这正是 `G_vis` 与澄清机制存在的理由。∎

## 8. 本轮最大风险

**一句话**：跨语言消融与共识门把"语言间分歧"当作风险，却无法识别"跨语言共因错误"——当所有语言经由同一个翻译记忆/同一个语义骨架/同一套解析规则被系统性误导时，分歧反而变小、共识反而变高，系统会在最需要外部接地的时刻把"一致地错"误读成"安全"，即「共识门只能测分歧，不能证正确」。
