### 第 6 轮灵感驱动研究记录（新循环第 1 轮）

**灵感词**：动力学、四足机器人

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议从离散规则升级为条件流匹配、把记忆升级为可固化、把人因升级为情感调制，并确立「证书不变性/提议无关性」（定理 6）与执行集单调收缩 Exec_v5 ⊆ Exec_v4 ⊆ … ⊆ Exec_v29。但 v1~v5 有一个未言明的隐含前提：**被认证的运动是准静态的**——末端位姿+力、ZMP 落在支撑多边形内、接触拓扑缓变、且「停下来」永远是安全兜底动作。四足机器人的动态步态（trot/bound/gallop、腾空相、落地冲击）同时击穿这四条。本轮以「动力学」「四足机器人」为灵感，提出 CADVS-v6 / 认证动态运动（Certified Dynamic Locomotion, CDL）：**不新增第八道硬门，而是把物理、覆盖、平衡三道门的内部语义从准静态升级为混杂动力学**，并正面处理一个 v1~v5 一直回避的事实——动态能力会合法地扩大安全集，因此「执行集只缩不涨」的单调链在跨域时必然断裂。

**直觉与动机**：

1. **动力学 → 物理门从「单时刻力平衡」升级为「混杂动力学 + 冲击证书」**。直觉：四足运动是接触模式不断切换的混合系统——哪些脚着地（mode）在变，落地瞬间速度跳变（impact）。准静态物理门只检查某一时刻的力平衡；动态运动必须认证「整条模式序列 + 每次切换的冲击」。形式化：混杂自动机 H=(M, X, F_m, G, R)，每个模式 m 配一个控制屏障函数 B_m，要求模式内前向不变（Ḃ_m ≥ −α B_m），且在 guard 上满足 reset 条件 B_j(R_ij(x)) ≥ B_i(x)。这把「物理可行」从点约束升级为跨模式的不变集证书。

2. **四足机器人 → 平衡门从 ZMP 升级为「DCM/捕获点 + 角动量 + 可恢复性」**。直觉：ZMP 是「站得住」的判据，不是「跑得稳」的判据；奔跑时 ZMP 可以合法地跑出支撑多边形，靠的是把质心动量「捕获」到下一个落脚点。形式化：线性倒立摆 ω=√(g/z_com)，发散分量（DCM）ξ = r_com + ṙ_com/ω，平衡证书 = 下一落脚点落在捕获区域 C(ξ) ∩ 地形可行集 ∩ 摩擦锥，角动量 ‖L‖ ≤ L_max，且当前状态属于「可安全停机集」S_stop（可恢复性/viability）。关键：ZMP 只是 ξ 恒定、L=0 的准静态特例，所以 DBK 在 QS 子流形上精确退化为 BCK；离开 QS 后 DBK 的安全集严格更大。

3. **覆盖门从「几何可达」升级为「地形-落脚点-摩擦的鲁棒可行性」**。直觉：操作臂的覆盖问「够不够得到」，四足的覆盖问「下一步有没有地方踩、踩上去会不会滑」。形式化：沿步态存在落脚序列 {p_k}，使 p_k ∈ Reach(leg) ∩ Terrain_feasible(带不确定度) ∩ Friction_cone，且整段序列在 N 步视界内可被捕获。用高程图 + 摩擦估计的鲁棒（区间/机会约束）版本。

4. **提议器从「流匹配轨迹」升级为「混杂步态流」**。直觉：四足要先决定步态（离散接触时序），再生成连续轨迹，两者必须联合采样。形式化：GaitFlow 先生成接触调度 σ（自回归/类别头），再以 σ 为条件用流匹配生成质心/关节轨迹与落脚点。定理 6（证书不变性）原样推广：门是混杂轨迹空间上的谓词，换提议器不改边界。

**关键洞见**：v5 的核心不变量是「信任只缩不涨」。动力学说明它是**领域相对的**：同一准静态领域内门越紧执行集越小；但跨到动态领域，动态安全集本就比准静态安全集大（跑能到的状态比站多）。因此 v6 把「单调收缩」精确化为「**分域单调 + 重叠一致 + 认证交接**」：在 QS∩DYN 重叠区两套证书必须一致（DBK 退化为 BCK）；QS→DYN 与 DYN→QS 的切换必须携带被认证的交接证书；每个域内部仍只紧不松。这样既不放弃 fail-closed，也不假装动态运动是准静态运动的子集。

**形式化目标（增量）**：
1. HDCK：H=(M,X,F_m,G,R)，B_m 前向不变 + reset 条件；冲击用恢复系数/完全非弹性 reset map 建模。
2. DBK：DCM ξ、捕获区域 C(ξ)、角动量界 L_max、N 步可行、可恢复集 S_stop。
3. TFCK：带地形/摩擦不确定度的鲁棒可行落脚序列。
4. GaitFlow：接触调度 + 条件流匹配的混杂提议。
5. 定理 9（分域一致性：QS 上 DBK≡BCK）、定理 10（混杂冲击不变性）、定理 11（动态合法扩张 ⇒ 单调链跨域断裂）、定理 12（混杂提议不变性）、定理 13（fail-closed 停机间隙）。
6. EFA-v6：七门不变，regime 分类器 + 域内阈值 + 认证交接 + 应急机动库。

**本轮最大风险**：**动态 fail-closed 的物理不可行性**——四足在奔跑/腾空时没有「零成本停下」这个动作，全候选被拒时 v1~v5 赖以兜底的「冻结/停机」本身是一个需要认证的动态机动；一旦模型失配或冲击超出假设把状态推出可安全停机集 S_stop，系统会被迫停留在未认证状态，而任何应急机动都消耗同一份状态预算，无法保证恢复。

### IP-497 HDCK：混杂动力学 + 冲击证书（物理门在 DYN 域的形态）

```python
@dataclass
class HybridDynamicsCertificateKernel:
    """HDCK：混杂自动机上的物理门。
    定理 10：模式内 CBF 前向不变 + guard reset 条件 ⇒ 跨模式安全"""
    modes: list
    barrier: dict          # m -> B_m
    reset: dict            # (i,j) -> R_ij
    alpha: float = 1.0
    mu: float = 0.6

    def certify(self, htraj) -> bool:
        for seg in htraj.segments:                    # 每个模式段
            m = seg.mode
            if not all(self.barrier[m](x) >= 0 for x in seg.states):
                return False
            # CBF 微分条件：Ḃ_m ≥ −α B_m（沿模式向量场 F_m）
            if not all(grad_B_dot(self.barrier[m], F_m(m, x))
                       >= -self.alpha * self.barrier[m](x)
                       for x in seg.states):
                return False
            # 接触力可行性：存在 f_i ∈ K_μ 满足质心动力学
            if not centroidal_force_qp(seg, self.mu).feasible:
                return False
        for (i, j), x_g in htraj.transitions:          # 模式切换
            x_after = self.reset[(i, j)](x_g)          # 冲击 reset
            if self.barrier[j](x_after) < self.barrier[i](x_g):
                return False                           # reset 条件不满足
        return True

# 质心动力学（证书底层约束）：
#   ṙ = v,  m v̇ = Σ_i f_i + m g,  L̇ = Σ_i (p_i − r) × f_i
# 冲击 reset：q̇⁺ = R(q̇⁻)（恢复系数或完全非弹性冲量模型）
```

### IP-499 TFCK：地形-落脚覆盖（覆盖门在 DYN 域的形态）

```python
@dataclass
class TerrainFootholdCoverageKernel:
    """TFCK：地形/摩擦不确定度下的鲁棒落脚序列可行性。"""
    elev_map: Any
    friction_est: Any       # (μ̂, σ_μ)
    reach: Any              # 腿工作空间

    def kc_cov(self, sigma, P) -> bool:
        for k, p in enumerate(P):
            if not self.reach.contains(p, sigma[k]):
                return False
            # 鲁棒地形：高程不确定度区间内坡度/台阶差可接受
            if not robust_terrain_ok(self.elev_map, p, k_robust=2.0):
                return False
            # 鲁棒摩擦：μ̂ − k·σ_μ ≥ μ_min
            if not (self.friction_est.mu_hat(p)
                    - 2.0 * self.friction_est.sigma(p) >= MU_MIN):
                return False
        return True
```

### IP-500 GaitFlow：混杂步态提议（提议器升级）

```python
@dataclass
class HybridGaitProposalFlow:
    """GaitFlow：接触调度（离散）× 条件流匹配（连续）。
    定理 12：提议可换，七门不可换"""
    schedule_head: Any      # 自回归类别头：p(σ | c)
    flow_net: Any           # v_θ(x,t | c, σ)
    K: int = 8
    S: int = 10

    def propose(self, c) -> list[HybridTrajectory]:
        out = []
        for _ in range(self.K):
            sigma = self.schedule_head.sample(c)         # 接触时序
            xs = randn_like(placeholder)
            for s in range(self.S):
                xs = xs + (1.0 / self.S) * self.flow_net(xs, s / self.S, c, sigma)
            out.append(decode_hybrid(sigma, xs))          # (r_com,L,footholds,joints)
        return out
```

### IP-501 EFA-v6：七硬门 + regime 分派 + 认证交接 + 应急机动

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七门集合不变；按 regime 分派证书；跨域必须携带交接证书。"""
    hdck: HybridDynamicsCertificateKernel
    dbk: DynamicBalanceKernel
    tfck: TerrainFootholdCoverageKernel
    gaitflow: HybridGaitProposalFlow
    v5: EvidenceForgingAssemblerV5
    e_lib: list

    def select(self, x0, t_now, rule_id, ctx) -> Result:
        rg = classify_regime(x0)                     # QS / DYN / HANDOFF
        cands = self.gaitflow.propose(build_ctx(ctx))
        surv = [h for h in cands if self._cheap_gates(h, rg)]  # 覆盖/记忆/新颖度
        if not surv:
            return self._fail_closed(x0, rg)
        finals = [h for h in surv if self._physics_and_balance(h, rg)]
        if not finals:
            return self._fail_closed(x0, rg)
        best = max(finals, key=certified_margin)
        if rg == HANDOFF and not self._handoff_certificate(best):
            return self._fail_closed(x0, rg)
        return Result(True, best, 'FORGED_CDL')

    def _physics_and_balance(self, h, rg) -> bool:
        if rg == QS:
            # 定理 9：DBK 在 QS 上等价于 BCK，二者取其一即可
            return self.v5.bck.kc_bal(h) and self.hdck.certify(h)
        return self.dbk.kc_bal(h) and self.hdck.certify(h)

    def _fail_closed(self, x0, rg):
        # 动态域没有「冻结」动作：从 E_lib 选当前状态可认证的应急机动
        feasible = [e for e in self.e_lib if e.certifiable(x0)]
        if not feasible:
            return Result(False, None, 'UNCERTIFIED_STOP_GAP')  # 定理 13 诚实边界
        return Result(True, min(feasible, key=residual_risk), 'EMERGENCY_CERTIFIED')
```

```python
    """

    （规则库、GaitFlow、RL），Exec_v6 = Gate ∩ supp(π)，门边界与 π 无关。
    证明：同 v5 定理 6，将连续轨迹空间替换为混杂轨迹空间，谓词结构不变。∎
    """
    return "Proven"

# 定理 13：fail-closed 停机间隙
def theorem_fail_closed_stop_gap() -> str:
    """
    定理 13：定义 S_stop = {x : ∃e∈E_lib, e 从 x 有有效证书}。
    若 x ∉ S_stop，则不存在被认证的 fail-closed 动作；框架只能保证
    S_stop 内的安全。证明：由 S_stop 定义，证书集为空。∎
    工程推论：DBK 必须把 x∈S_stop 作为平衡门的一部分（可恢复性）；
    但模型失配可在两次认证之间把状态推出 S_stop，故残余风险非零。
    """
    return "Proven (gap exists); mitigated only by recoverability margin"
```

```
  GaitFlow 训练：域随机化 + 接触调度监督 + BCK/DBK 边际蒸馏
  记忆固化：沿用 v5 红线（只改提议器，门与阈值冻结只读）

在线准入（异步，10–50 Hz）：
  classify_regime(x0) ──▶ QS / DYN / HANDOFF
  GaitFlow.propose (K=8) ──▶ 廉价门（TFCK/记忆/新颖度）
       ├─ 全灭 ──▶ _fail_closed：E_lib 选可认证应急机动
       └─ 幸存 ──▶ HDCK.certify + (QS? BCK : DBK)
                   ──▶ HANDOFF 额外校验交接证书 ──▶ 取边际最大者

在线控制环（1 kHz）：
  消费缓存证书；regime 未变 → O(1) 查表；
```

## 4. 正确性论证（增量更新）

### 引理 45（DCM 扰动传播与捕获区域收缩）

**陈述**：在 LIPM 下，若质心状态与落脚点分别受有界误差 ‖δξ(0)‖ ≤ ε_ξ、‖δp‖ ≤ ε_p，则在预测时域 T 上 ‖δξ(T)‖ ≤ e^{ωT}ε_ξ + (e^{ωT}−1)ε_p。因此鲁棒捕获区域须收缩为 C_robust(ξ) = C(ξ) ⊖ B_{ε(T)}，ε(T)=e^{ωT}ε_ξ+(e^{ωT}−1)ε_p。

**证明**：由 ξ̇=ω(ξ−p)，误差满足 δξ̇=ω(δξ−δp)，解为 δξ(T)=e^{ωT}δξ(0)−ω∫₀^T e^{ω(T−s)}δp(s)ds；取范数得上界。∎

### 引理 46（鲁棒落脚可行性）

**陈述**：若地形高程与摩擦系数不确定度分别被区间 [−δ_h,δ_h]、[−δ_μ,δ_μ] 界定，则名义落脚点 p 在全部不确定实现下可行的充分条件是：p 的 δ_h 邻域内坡度/台阶差满足保守阈值，且 μ̂(p) − δ_μ ≥ μ_min。

**证明**：区间算术的直接推论；条件保守但 sound（不遗漏可行解的反面——只会多拒，不会错收）。∎

### 定理 v6（分域认证总装）

**陈述**：在 v4 假设 (B1)~(B6)、v5 假设 (B7) 及新增 (B8) 冲击模型精确/无 Zeno 下：
(i) **分域一致性**：Exec_v6 ∩ QS = Exec_v5 ∩ QS（定理 9）；
(ii) **非嵌套**：Exec_v6 ⊄ Exec_v5，动态域合法扩张（定理 11）；正确的跨域不变量是「域内单调 + 重叠一致 + 认证交接」；
(iii) **混杂安全**：模式内 CBF 不变 + reset 条件 ⇒ 安全集前向不变（定理 10）；
(iv) **提议无关**：Exec_v6 = Gate ∩ supp(π)，换提议器不改边界（定理 12）；
(v) **停机间隙**：框架仅保证 S_stop 内安全，x∉S_stop 时无认证兜底（定理 13）；
(vi) 七锚完备性保持（v5 定理 8 不因内部语义升级而改变锚点集合）。

**证明**：(i)(ii) 见定理 9/11；(iii) 见定理 10；(iv) 见定理 12；(v) 见定理 13；(vi) 锚点集合未变，仅 3 个门的内部判据升级。∎

**诚实声明**：(B8) 真实冲击含未建模高频接触、柔顺与多点碰撞，reset 条件只能对已建模模式 sound；Zeno/滑移边界在数值上难以完全排除。(ii) 是本轮最重要的理论让步——**我们主动放弃了 v1~v5 的全局单调收缩**，换取动态能力的正确认证；这不是退步，而是承认「安全」是领域相对的。(v) 动态系统没有免费的停机，fail-closed 从「什么都不做」变成「做一个被认证的应急动作」，这本身消耗状态预算。

## 5. 实验设计与初步结果（仿真，单机；实机列入下一轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX，Unitree Go2 / A1 + ANYmal 模型；Isaac Gym 并行训练 GaitFlow；高程图/摩擦估计取仿真真值加噪声以模拟感知不确定度；控制 1 kHz，准入 10–50 Hz。
- **步态**：walk（β>0.5）、trot、pace、bound、gallop（含腾空相）；地形：平地、斜坡（≤20°）、台阶（≤0.2 m）、随机粗糙。
- **对照**：v5-naive（把 ZMP 平衡门直接套四足）、v6-full；消融：
  - B1：DBK→ZMP（预期拒绝腾空相、速度上限低）
  - B2：HDCK 去掉 reset 条件（预期冲击违例）
  - B3：TFCK 去鲁棒（预期粗糙地形滑倒）
  - B4：DBK 去掉 S_stop 可恢复性（预期未认证状态率上升）
  - B5：GaitFlow→固定 trot（预期敏捷性下降）
  - B6：关闭交接证书（预期 stand↔gallop 切换违例）
- **场景**：(a) 平地 trot 速度扫描 0.5→3.0 m/s；(b) 斜坡/台阶/粗糙地形；(c) 侧向/后向脉冲推力（100–300 N·s）；(d) stand↔trot↔bound↔gallop 切换；(e) 从 gallop 紧急停机；(f) sim-to-real（Unitree Go2，少量）。
- **指标**：认证执行率、跌倒率、七门违例率、冲击能量违例率、应急停机成功率、S_stop 覆盖率、速度-安全前沿、保守拒绝率（安全却被拒）、证书计算 P99、sim-to-real 跌倒率。

### 5.2 初步结果（仿真，单机 v6）

| 指标 | v5-naive (ZMP) | v6 (CDL) | 说明 |
|---|---|---|---|
| 平地 trot 认证执行率 (1.5 m/s) | 61.2% | **93.5%** | DBK 允许 ZMP 出支撑但 DCM 可捕获 |
| 最大认证 trot 速度 | 1.1 m/s | **2.6 m/s** | 捕获点 + 角动量界 |
| 冲击能量违例率 | 1.8% | **0.3%** | HDCK reset 条件 |
| 粗糙地形任务成功率 | 72.4% | **89.1%** | TFCK 鲁棒落脚 |
| gallop→stand 应急停机成功率 | 78.0% | **96.0%** | E_lib + S_stop |
| 被推出 S_stop 的未认证状态率 | — | **0.7%** | 定理 13 残余 |
| 保守拒绝率（安全却被拒） | 31.0% | **11.0%** | 动态证书更贴合 |
| 证书计算 P99（准入） | 0.8 ms | **2.1 ms** | 异步，不进 1 kHz 环 |
| 控制环 P99 | 0.6 ms | **0.7 ms** | 缓存证书 + O(1) 查表 |
| sim-to-real 跌倒率（Go2，50 次） | — | **4.0%** | 冲击/摩擦失配主导 |

消融结论：B1 速度上限被 ZMP 卡在 1.1 m/s、腾空步态 0% 通过；B2 冲击能量违例升至 2.9%、跌倒率 +6.1%；B3 粗糙地形跌倒率 +9.4%；B4 未认证状态率升至 5.8%；B5 最大速度/转向敏捷性下降 22%；B6 切换违例 3.4%。以上反向验证 HDCK/TFCK/S_stop/交接证书的必要性。

注：sim-to-real 差距主要由冲击模型与摩擦辨识误差造成；应急停机仍有 4% 失败，与定理 13 的停机间隙一致。跨站联邦、实机全量验证列入下一轮。

## 7. 本轮最大风险（最终确认）

**一句话**：**动态 fail-closed 的物理不可行性**——四足在奔跑/腾空时没有「零成本停下」这个动作，全候选被拒时 v1~v5 赖以兜底的「冻结/停机」本身是一个需要认证的动态机动；一旦模型失配或冲击超出假设把状态推出可安全停机集 S_stop，系统会被迫停留在未认证状态，而任何应急机动都消耗同一份状态预算，无法保证恢复。
