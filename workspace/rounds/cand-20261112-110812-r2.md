# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「行为树」×「手眼标定」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「执行层→证据层」升级为「认知驱动的场景-执行闭环」。但**三个结构性局限**仍未解决：
> 1. **单周期闭环无法组合**：SERC 一次只处理「一次场景识别 + 一次阻抗编译 + 一次接触」。真实任务是「抓取→翻转→对准→插入→放置」的多步序列，含顺序、分支与失败回退。场景先验和意图约束在节点之间如何传递、组合后如何仍保证安全，缺少形式化——**第 60 轮有“环”，但没有“树”**。
> 2. **因果顺序 ≠ 时间同步**：EPIR 只校验 seq/timestamp 是否单调，却不校验树内「父 tick → 子 tick」「兄弟节点先后」「标定 → 门控动作」的因果偏序；更关键，视觉与力觉的时钟偏移（数十毫秒）会把两个本不相关的事件拼成一条“看似连续”的证据链。**ROS 因果隔离缺少时间标定维度**。
> 3. **空间标定的隐形假设**：SSM 默认所有观测处于同一坐标系，忽略了手眼外参 T_EE←Cam 及其热漂移、碰撞后变化。**“场景变了”可能只是标定漂了**；若在错误外参下编译 K_safe，系统会得到“证据链完整、合同全部通过、物理上已偏航”的最危险状态。

## 0. 直觉与动机

**灵感 1（行为树 → 契约行为树 CCBT）**
直觉：行为树本质上是**带优先级的离散事件组合器**：Sequence 表达“先后”，Fallback 表达“失败回退”，Decorator 表达“守卫条件”。经典 BT 的 tick 只返回 SUCCESS/FAILURE/RUNNING，信息量太低。关键洞见：**让每个节点携带一份可检验的执行合同 C_v = (Pre, Post, Inv)，tick 返回的不再是布尔值，而是“合同见证”**。于是“场景切换”在树层面表现为某个 Post 失败并自然触发 Fallback 到重感知/重标定子树；“多步任务安全”则可由叶子合同沿树结构归纳证明——BT 从“调度器”升级为**可组合的安全证明结构**。

**灵感 2（手眼标定 → 时空手眼标定 STHEC）**
直觉：手眼标定解的是 AX=XB，把“眼睛看到的”与“手能到达的”对齐。传统做法是离线一次性标定，但相机被碰、末端换工具、温漂都会让 X 缓慢失配。关键洞见有二：其一，**标定应在线进行，并保留协方差 Σ_cal**，让“不确定性”显式进入动作选择；其二，**标定不只是空间外参，还包括时间偏移 τ**——视觉事件与力觉事件若相差 30ms，因果图就会接错边。于是把 X∈SE(3) 与 τ∈R 联合估计，得到**时空手眼标定**；用主动探针（VOI 驱动）降低 Σ_cal，形成“标定—执行—证据—再标定”的闭环。

**灵感 3（两灵感合流 → 标定门控行为树 CGBT）**
直觉：BT 决定“做什么、失败了怎么办”，标定决定“在哪个坐标系里做、误差多大”。把两者相乘：每个节点声明**精度需求 ρ_v**，只有标定置信度 γ_cal ≥ ρ_v 且任务空间协方差 ε_task ≤ ε_v 时节点才允许执行；否则先执行**标定子树 CalSubtree**，再重新门控。关键洞见：**节点成功必须“双钥匙”**——一把是标定坐标系下的任务合同 Post^task，另一把是**标定无关的本体不变量 Inv^prop**（关节限位、力矩上限、碰撞阈值）。后者无法被“错误的标定”吸收，从机制上阻断“在错误坐标系里自证成功”。

**灵感 4（证据 → 因果行为树证据 EPIR-BT）**
直觉：一次 BT tick 天然产生偏序：父先于子、兄弟按序、标定先于被门控的动作。把这层偏序用**向量时钟**编码进 EV-bt，再交给 EPIR 做因果一致性检验，就能区分“消息丢了”与“因果关系错了”。关键洞见：**证据链不仅要可追溯，还要可证明“先后”**；Merkle 化的 tick 哈希使树根成为整棵执行树的防篡改摘要。

**灵感 5（预算 → PCE+++++）**
直觉：第 60 轮的 B_cog 只覆盖“认知四维”，缺了“树”和“标定”两类会持续消耗的资源。扩展为 **B_cog+ = (B_scene, B_intent, B_ros, B_exec, B_cbt, B_calib)**：B_cbt 限制 tick 频率、树深与回退次数；B_calib 限制探针次数与标定算力。主动标定只有在 `voi_probe = E[IG(Σ_cal)] − λ_cal·cost_calib − λ_bt·cost_cbt` 为正时才允许；B_calib 耗尽则降级为“低精度模式”，禁止高 ρ 节点。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（契约行为树 CCBT）** 契约行为树 BT = (V, E, r, type, C, B)。其中：
- **节点类型**：type(v) ∈ {Seq, Fall, Par, Guard, Retry, Act, Cond, Cal}，Seq 按序执行、Fall 按优先级回退、Guard 为守卫装饰器、Cal 为标定子树。
- **节点合同**：C_v = (Pre_v, Post_v, Inv_v^task, Inv_v^prop, ρ_v)。Pre_v/Post_v 为任务空间前后条件；Inv_v^task 为任务不变量；**Inv_v^prop 为本体不变量**（关节限位、力矩上限、碰撞距离），不依赖相机外参；ρ_v 为精度需求等级。
- **tick 语义**：δ(v, s_t) → (status, s_{t+1}, e_v)，status ∈ {SUCCESS, FAILURE, RUNNING}；Seq 全成功才成功，任一失败即失败；Fall 首个成功即成功，全失败才失败；Guard(g) 在 g(s_t)=false 时直接 FAILURE（触发上层 Fallback）。
- **合同满足**：σ_v ⊨ C_v ⇔ Pre_v(s_0) ∧ (status=SUCCESS ⇒ Post_v(s_end)) ∧ ∀t Inv_v^task(s_t) ∧ ∀t Inv_v^prop(s_t)。
- **精化序**：C ⊑ C′ ⇔ (Pre′ ⇒ Pre) ∧ (Post ⇒ Post′) ∧ (Inv′ ⇒ Inv)，用于父子合同衔接。
- **良构条件**：对每条 Seq 边 (u→v) 需 Post_u ⊑ Pre_v；对 Guard(g→v) 需 g ⇒ Pre_v。良构性是第 3 节组合定理的前提。

**定义 162（时空手眼标定 STHEC）** 标定状态 x = (X, τ) ∈ SE(3) × R，X = T_EE←Cam，τ 为相机与力觉的时钟偏移。给定运动对 {(A_i, B_i)}（A_i 为末端运动、B_i 为相机观测运动）：
- **空间残差**：e_i(x) = log( (A_i(τ) X) (X B_i(τ))^{-1} ) ∈ se(3)。
- **时间残差**：e_t(τ) = u_cam(t) − u_ft(t+τ)，u 为归一化运动/力变化率。
- **联合代价**：J(x) = Σ_i ‖e_i(x)‖²_{Σ_i} + λ_t Σ_k ‖e_t(τ)‖²。
- **信念**：b(x) = N(μ, Σ)，以 Gauss-Newton/EKF 增量更新；任务空间协方差 Σ_task = J_task Σ J_task^T。
- **标定置信度**：γ_cal = exp(−α·tr(Σ_task)/ε_0²) ∈ (0,1]；γ_cal 越小，说明外参/时延越不可信。
- **主动探针**：候选动作 a_p 的信息增益 IG(a_p) = H(b) − E[H(b′|a_p)]；仅当 VOI 为正时执行探针。

**定义 163（标定门控行为树 CGBT）** 在 CCBT 上增加门控映射 G: V → {0,1}：
```
G_v = [γ_cal ≥ ρ_v] ∧ [ε_task(Σ_task) ≤ ε_v] ∧ [π_scene 下 Post_v^task 可行]
```
若 G_v=0 且 v ∈ V_cal，则先 tick 标定子树 CalSubtree(v)（受 B_calib 约束），再重新门控；若不可标定则返回 FAILURE 交由 Fallback。
- **双钥匙成功准则**：SUCCESS_v ⇔ Post_v^task(标定坐标系 F_v=X·F_cam) ∧ Inv_v^prop(本体坐标系)。
- **标定归一化合同**：节点观测先经 F_v 变换再检验 Post，确保“合同语义”与“标定精度”解耦。

**定义 164（场景-阻抗-标定-置信度四元组 SICC）** 给定观测 O、场景 z、阻抗 K、标定信念 b：
- **SICC** = (scene_conf(z|O;X,τ), K_certainty(K|z,X), cal_conf(Σ), execution_feasibility(K|z,X))。
- **标定边缘化后验**：p(z|O;X,τ) ∝ p(z) ∫ p(O|z,K,X,τ) p(K|z) dK；Σ_cal 越大，似然越平坦，场景后验熵越高。
- **判定**：SICC_valid ⇔ scene_conf ≥ τ_scene ∧ K_certainty ≥ τ_K ∧ cal_conf ≥ τ_cal ∧ feasibility=true。
- **更新**：CLEP 闭环后按 EV-bt 更新 scene_conf 与 cal_conf，形成“场景—阻抗—标定”联合信念。

**定义 165（因果行为树证据 EV-bt / EPIR-BT）** 每次 tick 生成事件：
```
e = (tree_id, tick_id, node_id, parent_tick, vc, ts, seq, hash,
     status, contract_witness, cal_snapshot)
```
- **向量时钟**：子节点合并父 vc，本地分量自增；父节点 tick 结束后合并所有子 vc。
- **happens-before**：e₁ → e₂ ⇔ vc(e₁) ≤ vc(e₂) 逐分量且不相等。
- **因果检验**：云端 S_check 校验 (i) 父 tick 先于子 tick；(ii) 兄弟按 Seq 声明顺序；(iii) 标定事件先于被门控动作；(iv) status 与 contract_witness 一致。任一违反即标记 CAUSAL_BREAK。
- **防篡改**：树根哈希 H_root = Merkle({hash(e_v)})，作为整棵执行树的摘要写入 J_bt。

**定义 166（行为树执行证书 J_bt）** J_bt = (root_status, {witness_v}_{v∈V}, cal_snapshot, H_root, budget_ledger, risk_flags)。云端接受条件：
1. 所有被访问节点的 witness 可验证且合同精化链良构；
2. H_root 与 EPIR-BT 的因果根一致；
3. cal_snapshot 中 γ_cal 满足所有已执行节点的 ρ_v；
4. budget_ledger 中 B_cog+ 未出现“未触发降级”的越界。
J_bt 把第 60 轮的 J_exec 从“单次执行”提升为“整棵任务树”的可审计证书。

**定义 167（PCE+++++ 六维预算）** B_cog+ = (B_scene, B_intent, B_ros, B_exec, B_cbt, B_calib)。其中：
- **B_cbt** = (tick_rate, max_depth, fallback_budget, node_budget)，防止 BT 抖动与无限回退；
- **B_calib** = (probe_budget, calib_ops, uncertainty_target)。
- **扩展 VOI**：
```
voi_probe = E[IG(Σ_cal)] − λ_cal·cost_calib − λ_bt·cost_cbt
voi_bt(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_exec(π) − cost_cbt(π) − cost_calib(π)
```
- **降级规则**：B_cbt 耗尽 ⇒ 冻结树深、只允许安全 Fallback；B_calib 耗尽 ⇒ 进入低精度模式，ρ_v > ρ_low 的节点一律拒绝；其余维度沿用第 60 轮规则。

**定义 168（标定触发回退 CTF）** 回退触发集合 T = {t_contract, t_calib, t_scene, t_intent}：
- t_contract：节点 Post^task 失败但 Inv^prop 保持（任务级失败）；
- t_calib：γ_cal 低于节点 ρ_v 或 Σ_task 超过阈值（标定漂移）；
- t_scene：场景后验熵 H(z|O) > θ_ent（场景不确定）；
- t_intent：意图锁定与当前节点合同冲突。
**优先级**：安全不变量 > 标定 > 意图 > 场景 > 任务。**恢复协议**：按优先级执行聚焦子树（CalSubtree / Reperceive / Replan），每类尝试次数受 B_cbt/B_calib 约束；若 t_calib 连续 N_cal 次未收敛，升级为 DEGRADE_SAFE。**终止性**：每次回退消耗单调递减的 fallback_budget，故恢复过程有限。

### IP-161 CCBT（契约行为树）

```python
class ContractBTNode:
    def __init__(self, name, ntype, contract, children=None, guard=None):
        self.name, self.ntype = name, ntype
        self.contract = contract          # Pre/Post/Inv_task/Inv_prop/rho
        self.children = children or []
        self.guard = guard
        self.tick_id = 0
        self.vc = {}                      # 向量时钟

    def tick(self, state, calib):
        self.tick_id += 1
        self.vc[self.name] = self.vc.get(self.name, 0) + 1
        if self.guard and not self.guard(state, calib):
            return self._emit('FAILURE', state, witness=None)

        if self.ntype == 'sequence':
            for child in self.children:
                st = child.tick(state, calib)
                if st != 'SUCCESS':
                    return self._emit(st, state)
            return self._emit('SUCCESS', state)

        if self.ntype == 'fallback':
            for child in self.children:
                st = child.tick(state, calib)
                if st == 'SUCCESS':
                    return self._emit('SUCCESS', state)
            return self._emit('FAILURE', state)

        # leaf: action / condition / calibration
        st, state = self.act(state, calib)
        witness = self.contract.check(state, st)   # Pre, Post, Inv_task, Inv_prop
        ok = self.contract.pre_ok and self.contract.inv_ok and (
             st != 'SUCCESS' or self.contract.post_ok)
        return self._emit('SUCCESS' if ok else 'FAILURE', state, witness)

    def _emit(self, status, state, witness=None):
        e = EVBT(node=self.name, tick=self.tick_id, parent=None,
                 vc=dict(self.vc), status=status,
                 contract_witness=witness, cal_snapshot=state.calib.snapshot())
        state.evidence.append(e)
        return status
```

### IP-162 STHEC（时空手眼标定）

```python
class SpatioTemporalHandEye:
    def __init__(self, X0, tau0=0.0, eps0=1e-2):
        self.mu = pack(X0, tau0)          # se(3) ⊕ R
        self.Sigma = np.diag([1e-2]*6 + [1e-2])
        self.A, self.B = deque(maxlen=24), deque(maxlen=24)

    def add_pair(self, A_t, B_t, t):
        self.A.append((t, A_t)); self.B.append((t, B_t))

    def estimate_tau(self, u_cam, u_ft):
        # 互相关：视觉运动率与力/运动学运动率的时间对齐
        return min(range(-50, 51), key=lambda k: np.sum(
            (u_cam - np.roll(u_ft, k))**2))

    def update(self):
        tau = self.estimate_tau(self.u_cam, self.u_ft)
        X = unpack(self.mu)
        for _ in range(4):                # Gauss-Newton
            e = np.concatenate([
                lie_log(A(t) @ X @ inv(B(t + tau)) @ inv(X)).ravel()
                for t, A, B in zip(self.ts, self.A, self.B)])
            J = numeric_jacobian(lambda x: residual(x, self), self.mu)
            d = np.linalg.solve(J.T @ J + 1e-6*np.eye(7), -J.T @ e)
            self.mu = retract(self.mu, d)
        self.Sigma = np.linalg.inv(J.T @ J + 1e-6*np.eye(7))
        self.Sigma_task = self.J_task @ self.Sigma @ self.J_task.T
        self.gamma = np.exp(-alpha * np.trace(self.Sigma_task) / self.eps0**2)
        return self.mu, self.Sigma, self.gamma

    def voi_probe(self, probe):
        return expected_info_gain(self.Sigma, probe) - self.lambda_cal*probe.cost
```

def tick_calibration_gated(node, state, calib, budget):
    gate = (calib.gamma >= node.contract.rho and

def sicc_evaluate(scene_model, calib, K_best):
    p_z = scene_model.calibrated_posterior(calib.mu, calib.Sigma)
    scene_conf = float(p_z.max())
    K_cert = scene_model.impedance_certainty(calib.mu)
    cal_conf = calib.gamma
    feasible = scene_model.feasible_in_frame(K_best, calib.mu)

                entropy=entropy, valid=valid)

### IP-165 EPIR-BT（因果证据）

```python
class CausalEvidenceRegion:
    def __init__(self, window=256):
        self.shadow, self.window = {}, window

    def append(self, node, parent_vc, status, calib, witness):
        vc = merge_vc(parent_vc, node.vc)
        vc[node.name] = vc.get(node.name, 0) + 1
        e = EVBT(tree=node.tree_id, tick=node.tick_id, node=node.name,
                 parent_tick=node.parent_tick, vc=vc, ts=now(),
                 seq=self.next_seq(), status=status,
                 contract_witness=witness, cal_snapshot=calib.snapshot())
        e.hash = sha256(e.payload()).hexdigest()[:16]
        self.shadow[e.seq] = e
        if len(self.shadow) > self.window:
            del self.shadow[min(self.shadow)]
        return e

    def check_causal(self, events):
        for e1, e2 in combinations(events, 2):
            if happens_before(e1, e2) and not order_valid(e1, e2):
                return 'CAUSAL_BREAK'
        return 'OK'

    def merkle_root(self):
        hashes = [e.hash for e in sorted(self.shadow.values(), key=lambda x: x.seq)]
        return merkle(hashes)
```

class CognitiveBudgetPlus:
    def __init__(self, b_scene, b_intent, b_ros, b_exec, b_cbt, b_calib):
        self.B = dict(scene=b_scene, intent=b_intent, ros=b_ros,
                      exec=b_exec, cbt=b_cbt, calib=b_calib)

            return False
        return calib.voi_probe(probe) > 0

    def low_precision_mode(self):
        return self.B_calib.probes <= 0

        if self.B_cbt.fallback_budget <= 0: return 'FREEZE_TREE'
        if self.B_calib.probes <= 0:        return 'LOW_PRECISION'
        if self.B['ros'] <= 0:              return 'LOCAL_LOOP_ONLY'
        return None

def calibration_triggered_fallback(root, state, calib, budget):
    triggers = detect_triggers(state, calib)   # contract/calib/scene/intent
    if not triggers:

## 2. 关键推导

### 2.1 标定误差 → 任务空间误差 → 场景误判上界

设标定误差 δx ~ N(0, Σ_cal)，任务空间位姿误差一阶传播为 δp ≈ J_cal δx，故
```
Σ_task = J_cal Σ_cal J_cal^T,   ε_task = sqrt(λ_max(Σ_task))
```
若两个场景类别在观测空间的分离间隔为 m，则标定误差导致的场景翻转概率满足
```
P(flip) ≤ exp( − m² / (8·λ_max(Σ_task)) )
```
因此要让误判概率 ≤ δ，需
```
ε_task ≤ m / (2·sqrt(2·ln(1/δ)))
```
这条不等式把“标定精度”直接翻译成“场景识别可靠性”，也是 SICC 中 cal_conf 门槛的理论依据。

### 2.2 行为树组合安全性（结构归纳）

- **Seq**：若 ∀i Post_i ⊑ Pre_{i+1} 且每个子节点成功，则由前向后归纳得 Post_root = Post_last，且所有 Inv_i 成立。
- **Fall**：Fallback 的任一成功分支即满足 Post_root（析取），而 Inv_root = ∧ Inv_i 必须全程成立（合取），这保证“回退不牺牲安全”。
- **Guard**：g ⇒ Pre_child，故守卫为假时子节点不会破坏父合同。
- **Cal**：标定子树只改变 Σ_cal，不改变 Inv^prop；标定后重新门控，等价于在当前精度下重新证明合同。

### 2.3 因果证据的可重建性

EPIR-BT 的向量时钟给出偏序 (E, →)。若 ROS 只丢失部分消息而 shadow 保留 ≤ window 条事件，则缺失事件可由 (seq, hash, vc) 从 shadow 重放；重放后若 Merkle 根一致且所有 happens-before 边满足，则 J_bt 可被接受。反之，若出现“子先于父”或“门控动作先于标定”，则因果图不可线性化，必须判 CAUSAL_BREAK 而不是简单重传。

### IP-161 CCBT（契约行为树）

```python
class ContractBTNode:
    def __init__(self, name, ntype, contract, children=None, guard=None):
        self.name, self.ntype, self.contract = name, ntype, contract
        self.children, self.guard = children or [], guard
        self.vc = {}

    def tick(self, state, calib):
        self.vc[self.name] = self.vc.get(self.name, 0) + 1
        if self.guard and not self.guard(state, calib):
            return self._emit('FAILURE', state)

        if self.ntype == 'sequence':
            for child in self.children:
                if child.tick(state, calib) != 'SUCCESS':
                    return self._emit('FAILURE', state)
            return self._emit('SUCCESS', state)

        if self.ntype == 'fallback':
            for child in self.children:
                if child.tick(state, calib) == 'SUCCESS':
                    return self._emit('SUCCESS', state)
            return self._emit('FAILURE', state)

        st, state = self.act(state, calib)
        ok = self.contract.check_pre(state) and self.contract.check_inv(state)
        ok = ok and (st != 'SUCCESS' or self.contract.check_post(state))
        return self._emit('SUCCESS' if ok else 'FAILURE', state)

    def _emit(self, status, state):
        ev = EVBT(node=self.name, tick=now(), vc=dict(self.vc),
                  status=status, contract_witness=self.contract.last_witness,
                  cal_snapshot=state.calib.snapshot())
        state.evidence.append(ev)
        return status
```

### IP-162 STHEC（时空手眼标定）

```python
class SpatioTemporalHandEye:
    def __init__(self, X0, tau0=0.0):
        self.mu = pack_se3_tau(X0, tau0)      # 7 维
        self.Sigma = np.diag([1e-2]*7)
        self.pairs = deque(maxlen=24)

    def add_motion_pair(self, A_t, B_t, t):
        self.pairs.append((t, A_t, B_t))

    def update(self):
        tau = self.estimate_tau()             # 视觉/力觉运动率互相关
        for _ in range(4):
            e = np.concatenate([
                lie_log(A @ X @ inv(B_shifted(t, tau)) @ inv(X)).ravel()
                for t, A, B in self.pairs])
            J = numeric_jacobian(self._residual, self.mu)
            d = np.linalg.solve(J.T @ J + 1e-6*np.eye(7), -J.T @ e)
            self.mu = retract(self.mu, d)
        self.Sigma = np.linalg.inv(J.T @ J + 1e-6*np.eye(7))
        self.Sigma_task = self.J_task @ self.Sigma @ self.J_task.T
        self.gamma = np.exp(-alpha * np.trace(self.Sigma_task) / EPS0**2)
        return self.mu, self.Sigma, self.gamma
```

**一句话**：若行为树把失败错误归因到某个叶节点、而手眼标定又把系统性偏差“吸收”进场景先验，系统会在错误的坐标系里反复合同成功、证据链完整，却在物理上持续偏航——必须以标定协方差显式门控节点、以标定无关的本体不变量作第二把钥匙，并保留独立于 BT 的物理基准校验，否则“可证明的安全”只是“自洽的幻觉”。
