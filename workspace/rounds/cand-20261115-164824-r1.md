# 第 1 轮（灵感循环第 1 轮；本轮灵感：「共享控制」×「开源硬件」）

> **基线纪律**：工作区现有 MetricVoiceGauge v7（OTL/GCT/ER，定义 493–529；实验 E513–E525）整体视为 **prior art**。本轮只继承三条工程常识——证书可发布、软→硬退化、50Hz 实时预算；新贡献必须落在 v7 的 claim space 之外：v7 回答“语音指令是否被指标层级安全地执行”，本轮回答“控制权凭什么、在什么硬件上、以多大权限交给自治”。二者可以叠加，但互不蕴含。

## 0. 直觉与动机

### 灵感 1：共享控制 —— 把「权限」从调参变成状态量

**直觉解释。** 传统共享控制像两个人抢方向盘，混合比例 α 往往是一个拍脑袋的常数：设成 0.7 就永远 0.7。可现实中真正该问的是三件事：此刻谁在开？他能开多大？什么事件必须立刻把方向盘还给人？只要这三个问题没有可观测、可审计的答案，共享控制就只能靠“手感”调参，无法给出保证。

**严谨定义。** 令权限 α ∈ [0,1]^k 为逐任务轴的连续状态（k=1 即单轴，k>1 可分别控制平移/旋转/夹爪）。人给出 u_H，自治给出 u_A=π_A(s)。守卫 G 把指令投影进安全集 U_safe(s)。采用“守卫-混合-再守卫（G-B-G）”：先把两条指令各自守卫、再凸混合、最后再投影一次。在 U_safe 凸时最终投影为恒等，执行指令恰为 u=B_α(G(u_H),G(u_A))；此时 **α 只改变性能与舒适，不改变安全性**。这把“安全”和“权限”两个问题解耦：安全由守卫负责，权限由分配律负责。

### 灵感 2：开源硬件 —— 让保障随能力走，而不是随整机走

**直觉解释。** 开源硬件的好处是可复现、可替换、可派生；代价是变体爆炸：同一份固件烧到不同板子、不同执行器、不同标定上，“整机认证”立刻作废。我们需要的不是又一个整机认证，而是一张像护照一样的**能力凭证**：它不承诺具体性能，只声明“这块硬件能把保障支撑到哪一级”，并允许证书在能力不劣的派生硬件之间携带。

**严谨定义。** 硬件 h 由能力向量 c_h 描述（控制带宽、延迟裕度、力矩裕度、传感带宽、故障覆盖率、冗余通道数，全部“越大越好”）。权限 α 对应需求向量 r(α)，且 r 逐分量单调不减。硬件可支撑 α 当且仅当 r(α) ≤ c_h。于是权限天花板 ᾱ_h = max{α : r(α) ≤ c_h ∧ τ_h ≥ τ_min(α)} 有定义；派生硬件 h' 若 c_{h'} ≥ c_h 且无未批准的安全相关差异，则 ᾱ_{h'} ≥ ᾱ_h，证书可携带。

### 协同：两种灵感的乘积

共享控制问“谁开、开多大”；开源硬件答“这块板子配不配开这么大”。二者相乘得到本轮的核心对象：**硬件能力约束下的权限分配**。安全由守卫兜底，权限取（人否决 × 自治能力 × 硬件护照）的交，退化沿一条四档全序链下落。

## 1. 研究问题（第 1 轮）

- **Q1（权限分离）**：守卫有效时，能否证明闭环安全性对任意权限调度 α_t 不变，从而把安全与权限彻底解耦？
- **Q2（护照与可携带）**：如何从开源硬件的可复现构建与可分析设计中，构造可验证的能力护照，并给出证书跨派生硬件携带的充分条件？
- **Q3（快降慢升）**：如何在人否决、感知退化、热插拔换板时做到“立即降权、需双钥匙才缓慢升权”，并给出权限抖动上界？
- **Q4（全序退化）**：护照失效、守卫失效、人否决、自治越界任意组合时，系统是否总能落到四档退化链的下一档，而不出现无定义状态？

## 2. 设计原则（P1–P6）

**P1 权限是状态量（Authority as State, AaS）**：α 进入状态向量、日志与证书，任意时刻可回答“谁在控制、依据是什么、有效期到何时”。

**P2 守卫-混合-再守卫（Guard-Blend-Guard, GBG）**：先分别守卫人/自治指令，再按 α 混合，最后再投影一次。最终投影保证安全；凸安全集上投影为恒等，保证权限保真。

**P3 能力护照（Capability Passport, CapP）**：硬件以（板卡/固件/标定哈希、能力向量、来源证明、安全相关差异清单、签名、时间戳）声明其可支撑的权限上限；护照由开源设计文件与可复现构建派生，可被第三方复核。

**P4 快降慢升（Fast-Down Slow-Up, FDSU）**：降权即时、无需确认；升权必须通过“硬件新鲜自检 + 人类确认”的双钥匙再认证，并受磁滞带 Δ 与最小驻留时间 T_dwell 约束。

**P5 能力占优可携带（Dominance Portability, DP）**：若派生硬件 h' 的能力向量逐分量不劣于 h，且安全相关差异为空，则 h 上的权限证书原样携带到 h'；否则只携带到 r(α) ≤ c_{h'} 的最大 α，或触发再认证。

**P6 四档全序退化（Total-Order Degradation, TOD）**：满权限 F → 受限 L → 被动共享 P → 安全停机 S，四档全序；每档有明确的进入条件、责任主体与可观测证据。

## 3. 与 prior art 的接口（如何退化）

- 护照服务不可用 ⇒ 视同未认证硬件，α=0，进入被动共享 P；
- 守卫滤波器失效或超时 ⇒ 自治权限立即归零，人指令经硬件级限幅/柔顺执行；
- 能力向量不足以支撑当前 α ⇒ 降到满足 r(α)≤c_h 的最大 α（进入 L）；
- 人否决/接管 ⇒ 1 个控制周期内 α→0；
- 以上全部不可用 ⇒ 安全停机 S（M₀ 级）。

这些退化只依赖 v7 的“证书可发布 + 软→硬退化”常识，不复用 v7 的语音、指标层级或情感主张。

## 4. 预期贡献

1. **权限不变安全定理**：守卫有效时，闭环安全对任意权限调度不变；凸安全集上还满足权限保真，把共享控制的安全问题与权限问题解耦；
2. **开源硬件能力护照与证书携带定理**：用能力占优偏序与安全相关差异，让保障跨硬件派生传播，而不是每换一块板就重新整机认证；
3. **快降慢升权限律与无静默升权定理**：降权无需确认，升权必须双钥匙再认证，并给出权限抖动上界；
4. **四档全序退化链**与完整性证明，配套 E526–E540 的预注册实验。

## 5. 本轮最大风险

**一句话**：能力护照只证明“纸面能力”，证明不了“物理现实”——被篡改、失标定或供应链替换的开源硬件可以伪造一份合法护照，于是这套机制可能恰好在最不可信的硬件上授予自治最高权限，制造“认证的虚假安全感”。

## 1. 符号体系增量（定义 530–542）

| 符号 | 含义 |
|---|---|
| `α ∈ [0,1]^k` | 逐任务轴权限向量（0=人全权，1=自治全权） |
| `c_h ∈ R^m_{≥0}` | 硬件 h 的能力向量，逐分量“越大越好” |
| `r(α) ∈ R^m_{≥0}` | 权限 α 所需资源向量，对 α 逐分量单调不减 |
| `τ_h(t) ∈ [0,1]` | 硬件信任度，随自检新鲜度指数衰减 |
| `ᾱ_h` | 硬件 h 的权限天花板：max{α : r(α)≤c_h ∧ τ_h≥τ_min(α)} |
| `HP` | 硬件护照（Hardware Passport） |
| `PAC` | 可携带权限证书（Portable Authority Certificate） |
| `κ_A(s) ∈ [0,1]` | 自治能力/域内置信（OOD 与验证域覆盖的保守估计） |
| `G_h` | 守卫滤波；`GV_h` 为其硬件有效性谓词 |
| `B_α` | 安全保持的权限混合子 |
| `π_passive` | 被动共享策略（人主 + 硬件限幅/柔顺） |
| `M = {F, L, P, S}` | 四档模式全序 |
| `ρ, Δ, T_dwell` | 升权速率、磁滞带、最小驻留时间 |
| `h' ⪰ h` | 能力占优：c_{h'} ≥ c_h 且安全相关差异为空 |
| `Δ_safety(h,h')` | 相对参考设计的安全相关差异集合 |

**定义 530（权限向量与权限格）** 权限 α ∈ [0,1]^k，偏序按逐分量 ≤。执行指令由混合子给出：
```
u_t = B_{α_t}( G_h(u_H,t), π_A(s_t) )
```
k>1 时各轴独立分配（如平移轴 α_xy、旋转轴 α_ψ、夹爪轴 α_g），从而可以“平移交给自治、夹爪留给人”。

**定义 531（能力向量、需求向量与覆盖）** 能力向量 c_h 与需求向量 r(α) 的分量取“越大越好”的统一取向（控制带宽、1/端到端延迟、力矩裕度、传感带宽、故障覆盖率、冗余通道数）。覆盖关系：
```
cov_h(α) ⇔ r(α) ≤ c_h   （逐分量）
```

**定义 532（权限天花板）** 给定信任度 τ，硬件 h 的权限天花板：
```
ᾱ_h(τ) = max { α ∈ [0,1] : r(α) ≤ c_h ∧ τ ≥ τ_min(α) }
```
其中 τ_min(α) 对 α 单调不减。因 r 与 τ_min 均单调，可行集是下集（down-set），天花板定义良定。

**定义 533（硬件护照 HP）**
```
HP = (board_id, hw_hash, fw_hash, cal_hash, c_h,
      Δ_safety(h,h_ref), provenance, signature, issued_at, self_test_at)
```

**定义 534（信任衰减与验证）** 若签名、三哈希白名单、Δ_safety ⊆ 批准集任一不成立，则 τ_h=0；否则
```
τ_h(t) = clip( τ_0 · exp(−λ · (t − self_test_at)), 0, 1 )
```
且当 t − self_test_at > T_fresh 时护照失效。

**定义 535（守卫-混合-再守卫 G-B-G）**
```
u_H^g = G_h(u_H),  u_A^g = G_h(π_A(s))
u_raw = (1−α)·u_H^g + α·u_A^g
u     = G_h(u_raw)        # 最终投影；凸安全集上为恒等
```
守卫有效性：
```
GV_h ⇔ c_h.bw_ctrl ≥ f_min ∧ c_h.inv_latency ≥ (1/τ_max) ∧ c_h.fault_coverage ≥ φ_min
```
若 GV_h 不成立，则数字守卫不可认证，自治权限必须归零。

**定义 536（权限下降律 ADL）** 设期望权限 α_des = ᾱ_h(τ_h) ⊓ κ_A(s)（逐分量取 min），则
```
降权（快降）：α_t = min(α_{t−1}, α_des)              # 立即，无需确认
升权（慢升）：仅当 rearm_t = 1 且 t − t_switch ≥ T_dwell 时
             α_t = min( α_des, α_{t−1} + ρ·Δt )       # 且仅对 α_des − α ≥ Δ 的分量
人否决：     α_t = 0（1 个控制周期内）
```

**定义 537（双钥匙再认证）** `rearm_t = 1` 当且仅当：
```
passport_valid(HP, t) ∧ (t − self_test_at ≤ T_fresh) ∧ human_ack ∧ ¬veto
```
缺任一钥匙都只允许降权，不允许升权。

**定义 538（可携带权限证书 PAC）**
```
PAC = (HP, α*, obligations O, issued_at, expiry)
```
有效期与义务 O（如“仅在 |v|≤v_max 时有效”）由签发方给出。PAC 在 (HP, t) 上有效当且仅当 HP 有效、α* ≤ ᾱ_h、t ≤ expiry、O 成立。

**定义 539（能力占优与安全相关差异）**
```
h' ⪰ h ⇔ c_{h'} ≥ c_h（逐分量） ∧ Δ_safety(h',h) = ∅
```
Δ_safety 由开源硬件设计文件（HDL/原理图/BOM/固件）逐项 diff 生成：安全相关项（限流、看门狗、急停回路、编码器分辨率、减速比、制动器）任一变化即非空。

**定义 540（四档全序退化）**
```
F（满权限）：HP 有效 ∧ GV_h ∧ α=1           责任：自治；证据：PAC + 权限日志
L（受限）  ：HP 有效 ∧ GV_h ∧ 0<α<1         责任：人机共担；证据：α 曲线 + 天花板
P（被动）  ：¬GV_h ∨ ¬HP ∨ α=0              责任：人；证据：硬件限幅 + 柔顺参数
S（停机）  ：投影不可行 ∨ 急停 ∨ 硬件故障    责任：安全回路；证据：停机原因码
```
进入条件逐档单调嵌套，故 F⊂L⊂P⊂S 构成全序。

**定义 541（权限抖动界）** 设磁滞 Δ、最小驻留 T_dwell、升权速率 ρ，则单轴权限的总变差满足
```
TV(α) ≤ Σ_降权 |Δα_down| + ρ·T
模式切换次数 ≤ ⌈T / T_dwell⌉ + (#降权事件)
```

**定义 542（权限不变安全）** 称系统满足权限不变安全，若对任意可测的权限调度 {α_t}（包括对抗性阶跃），只要每步 G_h 投影可行，则闭环轨迹满足硬约束 h(s_t) ≤ 0，∀t。

## 2. 形式化定义（要点）

**定义 530（权限向量）** —— α 是状态量而非超参数；它进入日志、证书与审计接口。

**定义 531（覆盖）** —— 统一“越大越好”取向，使“能力是否够用”退化为逐分量比较，避免延迟/带宽方向不一致导致的判定歧义。

**定义 532（天花板）** —— 因 r(α) 与 τ_min(α) 单调，可行集是下集，天花板可二分求得，这直接支撑在线 O(log(1/ε)) 计算。

**定义 535（G-B-G）** —— 安全由“最终投影”保证，“权限保真”（执行值等于B_α）只在凸安全集上成立；非凸时允许投影扭曲，但安全不降级。

**定义 536（ADL）** —— “快降慢升”是共享控制的核心时序不对称：危险方向零延迟，安全方向需证据。

**定义 540（全序退化）** —— 四档而非任意多档，保证审计与责任划分可穷举。

## 3. 关键算法骨架

```python
from dataclasses import dataclass
from typing import List, Tuple
import math


@dataclass(frozen=True)
class CapabilityVector:
    bw_ctrl: float           # 控制带宽 (Hz)，越大越好
    inv_latency: float       # 1/端到端延迟 (1/s)，越大越好
    torque_headroom: float   # 力矩裕度 (N·m)
    bw_sense: float          # 传感带宽 (Hz)
    fault_coverage: float    # 故障覆盖率 [0,1]
    redundancy: int          # 冗余通道数

    def ge(self, req: "CapabilityVector") -> bool:
        return (self.bw_ctrl >= req.bw_ctrl and
                self.inv_latency >= req.inv_latency and
                self.torque_headroom >= req.torque_headroom and
                self.bw_sense >= req.bw_sense and
                self.fault_coverage >= req.fault_coverage and
                self.redundancy >= req.redundancy)


def authority_requirement(alpha: float,
                          passive: CapabilityVector,
                          full: CapabilityVector) -> CapabilityVector:
    """r(alpha)：逐分量单调不减；r(0)=被动需求，r(1)=满权限需求"""
    a = max(0.0, min(1.0, alpha))
    def lerp(p, f):
        return p + a * (f - p)
    return CapabilityVector(
        bw_ctrl=lerp(passive.bw_ctrl, full.bw_ctrl),
        inv_latency=lerp(passive.inv_latency, full.inv_latency),
        torque_headroom=lerp(passive.torque_headroom, full.torque_headroom),
        bw_sense=lerp(passive.bw_sense, full.bw_sense),
        fault_coverage=lerp(passive.fault_coverage, full.fault_coverage),
        redundancy=int(round(lerp(passive.redundancy, full.redundancy))),
    )


@dataclass
class HardwarePassport:
    board_id: str
    hw_hash: str
    fw_hash: str
    cal_hash: str
    cap: CapabilityVector
    safety_diffs: List[str]      # 相对参考设计的安全相关差异
    signature: bytes
    issued_at: float
    self_test_at: float

    def dominates(self, other: "HardwarePassport") -> bool:
        return self.cap.ge(other.cap) and not self.safety_diffs


class PassportAuthority:
    """护照验证 + 信任衰减 + 权限天花板"""

    def __init__(self, registry, sig_verify, approved_srd,
                 tau0=1.0, lam=0.01, t_fresh=30.0,
                 trust_floor=0.2, trust_full=0.9):
        self.registry = registry            # hash -> 认可记录
        self.sig_verify = sig_verify
        self.approved_srd = set(approved_srd)
        self.tau0, self.lam, self.t_fresh = tau0, lam, t_fresh
        self.trust_floor, self.trust_full = trust_floor, trust_full
        self.passive_req = CapabilityVector(0, 0, 0, 0, 0, 0)
        self.full_req = CapabilityVector(1000, 1000, 30, 500, 0.99, 2)

    def trust(self, hp: HardwarePassport, now: float) -> float:
        age = max(0.0, now - hp.self_test_at)
        return max(0.0, min(1.0, self.tau0 * math.exp(-self.lam * age)))

    def verify(self, hp: HardwarePassport, now: float) -> Tuple[bool, float]:
        hashes_ok = all(h in self.registry
                        for h in (hp.hw_hash, hp.fw_hash, hp.cal_hash))
        srd_ok = set(hp.safety_diffs) <= self.approved_srd
        sig_ok = self.sig_verify(hp)
        fresh = (now - hp.self_test_at) <= self.t_fresh
        tau = self.trust(hp, now) if (hashes_ok and srd_ok and sig_ok) else 0.0
        return (hashes_ok and srd_ok and sig_ok and fresh and tau > 0.0), tau

    def trust_min(self, alpha: float) -> float:
        return self.trust_floor + alpha * (self.trust_full - self.trust_floor)

    def ceiling(self, hp: HardwarePassport, tau: float) -> float:
        """max alpha s.t. r(alpha) <= c_h 且 tau >= trust_min(alpha)"""
        def feasible(a: float) -> bool:
            req = authority_requirement(a, self.passive_req, self.full_req)
            return hp.cap.ge(req) and tau >= self.trust_min(a)

        if feasible(1.0):
            return 1.0
        if not feasible(0.0):
            return 0.0
        lo, hi = 0.0, 1.0
        for _ in range(32):             # 单调性保证二分有效
            mid = 0.5 * (lo + hi)
            if feasible(mid):
                lo = mid
            else:
                hi = mid
        return lo


class AuthorityDescentController:
    """快降慢升：降权即时；升权需双钥匙 + 磁滞 + 最小驻留"""

    def __init__(self, k=1, rho=0.2, dt=0.02, delta=0.05, t_dwell=0.5):
        self.alpha = [0.0] * k          # 冷启动零权限，必须显式再认证
        self.rho, self.dt = rho, dt
        self.delta, self.t_dwell = delta, t_dwell
        self.last_switch = -1e9

    def step(self, now, ceiling, competence, human_veto, rearm_ok):
        n = len(self.alpha)
        if isinstance(ceiling, (int, float)):
            ceiling = [ceiling] * n
        if isinstance(competence, (int, float)):
            competence = [competence] * n
        desired = [min(c, k) for c, k in zip(ceiling, competence)]

        if human_veto:
            self.alpha = [0.0] * n
            self.last_switch = now
            return self.alpha, "VETO"

        # 快降：逐分量立即取 min，不受驻留/磁滞限制
        down = [min(a, d) for a, d in zip(self.alpha, desired)]
        up = list(down)
        # 慢升：双钥匙 + 驻留 + 磁滞 + 速率限制
        if rearm_ok and (now - self.last_switch) >= self.t_dwell:
            for i, (a, d) in enumerate(zip(down, desired)):
                if d - a > self.delta:
                    up[i] = min(d, a + self.rho * self.dt)

        if up != self.alpha:
            self.last_switch = now
        self.alpha = up
        return self.alpha, "OK"


class GuardFilter:
    """守卫：带硬件有效性的安全投影；GV_h 不成立则数字守卫不可认证"""

    def __init__(self, safe_set, min_bw=200.0, min_inv_latency=50.0,
                 min_fault_cov=0.8):
        self.safe_set = safe_set
        self.min_bw = min_bw
        self.min_inv_lat = min_inv_latency
        self.min_fault = min_fault_cov

    def validity(self, cap: CapabilityVector) -> bool:
        return (cap.bw_ctrl >= self.min_bw and
                cap.inv_latency >= self.min_inv_lat and
                cap.fault_coverage >= self.min_fault)

    def project(self, u, x):
        return self.safe_set.project(u, x)   # CBF-QP / 最近点投影


def guarded_blend(G, u_h, u_a, alpha, x):
    """G-B-G：各自守卫 → 凸混合 → 最终再守卫"""
    uh = G.project(u_h, x)
    ua = G.project(u_a, x)
    u = [(1.0 - a) * h + a * aa for a, h, aa in zip(alpha, uh, ua)]
    return G.project(u, x)                   # 最终投影保证安全


def passive_shared_control(G, u_h, x, hw_limits):
    """人主 + 硬件级限幅/柔顺；不依赖自治与数字守卫"""
    return clip_to_hw_limits(G.project(u_h, x), hw_limits)


@dataclass
class PortableAuthorityCertificate:
    passport: HardwarePassport
    alpha_star: List[float]
    obligations: List[str]
    issued_at: float
    expiry: float

    def valid_at(self, now: float) -> bool:
        return now <= self.expiry


def port_certificate(pac, hp_prime, authority, now):
    """证书携带：能力占优 + 无安全相关差异 ⇒ 原权限或按新天花板截断"""
    if not pac.valid_at(now):
        return None
    valid, tau = authority.verify(hp_prime, now)
    if not valid or not hp_prime.dominates(pac.passport):
        return None
    ceiling = authority.ceiling(hp_prime, tau)
    alpha = [min(a, ceiling) for a in pac.alpha_star]
    if any(a <= 0.0 for a in alpha):
        return None
    return PortableAuthorityCertificate(
        hp_prime, alpha, pac.obligations, now, pac.expiry)


def sharepass_step(state, u_h, u_a, adl, authority, guard,
                   competence, human_veto, rearm_ok, now,
                   safe_stop=False):
    """四档全序退化的主步进：F → L → P → S"""
    hp = state.passport
    valid, tau = authority.verify(hp, now)
    ceiling = authority.ceiling(hp, tau) if valid else 0.0
    alpha, ev = adl.step(now, ceiling, competence, human_veto, rearm_ok)

    if safe_stop:
        return state.hard_stop(), alpha, "STOP", ev
    if (not guard.validity(hp.cap)) or all(a <= 0.0 for a in alpha):
        u = passive_shared_control(guard, u_h, state.x, state.hw_limits)
        return u, alpha, "PASSIVE", ev

    u = guarded_blend(guard, u_h, u_a, alpha, state.x)
    mode = "FULL" if all(a >= 0.999 for a in alpha) else "LIMITED"
    return u, alpha, mode, ev
```

## 4. 推导（引理与定理）

**引理 77（G-B-G 凸混合保真）** 若 U_safe 凸，且人/自治指令经 G_h 投影后均属于 U_safe，则凸混合 u_raw 仍属于 U_safe，最终投影为恒等，故 u_t = B_{α_t}(·) 精确执行，权限保真。
*证明*：U_safe 凸 ⇒ 两个端点的任意凸组合仍在 U_safe；最终投影对已在 U_safe 内的点不改变其值。∎

**引理 78（天花板对能力占优单调）** 若 h' ⪰ h 且 τ_{h'} ≥ τ_h，则 ᾱ_{h'}(τ_{h'}) ≥ ᾱ_h(τ_h)。
*证明*：对任意 α ≤ ᾱ_h，有 r(α) ≤ c_h ≤ c_{h'}（逐分量）且 τ_{h'} ≥ τ_h ≥ τ_min(α)，故 α 对 h' 可行。取上确界得证。∎

**定理 79（权限不变安全）** 在每步投影可行、且 G_h 的投影满足硬约束 h(s,u)≤0 的前提下，对任意权限调度 {α_t}（含对抗性阶跃），闭环满足 h(s_t)≤0，∀t。
*证明*：每步最终执行 u_t = G_h(u_raw) 必在 U_safe 内；由守卫的 CBF/投影证书，U_safe 前向不变；对 t 归纳即得。
*推论*：凸安全集上更进一步有权限保真，即 α 只改变性能与舒适，不改变安全性；非凸时允许投影扭曲保安全。∎
*注*：定理依赖“投影可行”；若投影不可行，则按定义 540 进入 S 档，不属定理覆盖范围。

**定理 80（证书携带）** 若 PAC=(HP,α*,O,expiry) 在 t 有效、h' ⪰ HP 对应硬件、且 HP' 在 t 有效，则 PAC 可携带到 h'，携带后权限为 α' = min(α*, ᾱ_{h'})，义务 O 不变。
*证明*：由引理 78，ᾱ_{h'} ≥ ᾱ_{HP} ≥ α*，故 α'=α* 或仅被更大天花板截断；O 是权限级义务，不含板级常量；Δ_safety 为空保证来源可传递。∎

**定理 81（无静默升权）** 权限增加当且仅当当前护照有效、自检新鲜、存在人类确认、且未超天花板四者同时成立；因此任何热插拔、伪造快板或时钟回拨都不能在无显式再认证的情况下提升 α。
*证明*：检查定义 536 的升权分支，其前置条件即定义 537 的 `rearm_t`；降权分支无前置条件。任一钥匙缺失时 `rearm_ok=0`，α 非增。∎

**定理 82（四档退化完整性）** 对任意失败模块子集，恰存在唯一的最高可行模式 m* = max{m∈{F,L,P,S} : pre(m)}，且 S 恒可行，故不存在未定义状态。
*证明*：定义 540 的进入条件逐档单调嵌套（pre(F)⇒pre(L)⇒pre(P)⇒pre(S)），S 的进入条件为恒真；取最大可行档即唯一。∎

**定理 83（权限抖动界）** 在磁滞 Δ、最小驻留 T_dwell、升权速率 ρ 下，区间 [0,T] 内单轴模式切换次数 ≤ ⌈T/T_dwell⌉ + N_down，其中 N_down 为降权事件数。
*证明*：相邻两次升权之间至少经过 T_dwell；降权可即时发生，每次降权至多计一次切换；升权幅度受 ρΔt 限制，不会跨过 Δ 反复横跳。∎

**定理 84（恢复活性）** 若护照与能力恢复有效、人给出再认证，则 α 从 0 恢复到期望值所需周期数 ≤ ⌈ᾱ_des / (ρ·Δt)⌉；故“快降”不会把自治永久锁死。*证明*：代入慢升递推 α_t = min(α_des, α_{t−1}+ρΔt)，几何级数上界即得。∎

## 8. 本轮最大风险

**一句话**：能力护照只证明“纸面能力”，证明不了“物理现实”——被篡改、失标定或供应链替换的开源硬件可以伪造一份合法护照，于是这套机制可能恰好在最不可信的硬件上授予自治最高权限，制造“认证的虚假安全感”。
