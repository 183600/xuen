# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「行为树」×「社会影响」）

> 第 54 轮把技能组合推进为动作空间上的可判定图搜索，并用联合证书 `J=(ρ,A_cert,γ_ce,δ_a)` 绑定云边对齐。但它仍隐含两个前提：**执行是一条预先给定的扁平动作序列**、**环境（尤其人）是外生的、不会因机器人的行为而改变**。本轮同时翻转这两点：把扁平路径升级为**带反应式回退的行为树**，把外生环境升级为**社会影响闭环**——人的响应由机器人可观察的行为签名决定，并反过来改变行为树的守卫条件。核心矛盾：H22：扁平序列证书只对单条执行迹 sound，真实部署中的失败会触发回退，实际执行迹由行为树的失败响应策略决定，路径最优的序列可能严格劣于一个扁平证书根本无法表达的回退丰富行为树；H23：社会影响使环境内生化，人会对回退激进度、等待、接近距离等行为签名作出响应，按固定人类模型签发的证书会得到“鲁棒但 socially unacceptable”或“礼貌但脆弱”的行为树，且影响回路可能正反馈放大（胁迫）或振荡。

## 0. 直觉与动机

**灵感 1（行为树 = 从“路径”到“策略代数”）**
直觉：第 54 轮的 `G_S` 路径本质是 `Sequence` 的特例；真实机器人需要 `Fallback`（失败后尝试替代）、`Parallel`（同时满足安全与任务）、`Decorator`（超时/重试/守卫）。行为树把**失败恢复**从事后 Explain 重规划提升为控制结构的一等公民。于是“组合”不再选一条路径，而是在技能集上选一个**控制策略**：`BT=(N,n_0,type,children,guard)`。扁平序列只是 `Sequence` 叶子链，证书体系必须覆盖整棵树，而不是一条迹。

**灵感 2（证书的 assume-guarantee 组合：把 J 变成行为树契约）**
直觉：给每个子树一个契约 `K_n=(A_n,G_n)`：在假设 `A_n`（世界状态 + 人类响应）下保证 `G_n`（第 54 轮的 `ρ、A_cert、γ_ce、δ_a` 等）。组合规则天然分层：`Sequence` 用第 54 轮的 `⊗` 链式组合；`Fallback` 用析取 `⊔`——只要某个分支在其失败前提被满足后能兜底，整体就成立；`Parallel` 用逐点 `⊓`（`ρ` 取 min、`A_core` 取交）。这把扁平路径“只对一条迹 sound”的缺陷，转成**结构化、可归纳验证**的契约树。

**灵感 3（社会影响 = 环境对策略的内生响应）**
直觉：机器人不是在人之外执行；回退顺序、等待时长、接近距离、是否会反复尝试，构成可观察的**行为签名** `sig(BT)`。人据此改变让路、协作、顺从或抵抗的概率，即 `π_H(·|x,sig(BT))`。行为树因此不只是控制结构，更是一个**社会策略**：`Fallback` 的顺序编码了规范（先询问？先等待？先绕行？）。社会影响算子 `𝕊[BT]` 把基线人类策略 `π_H^0` 映射为受机器人影响后的 `π_H^{BT}`，影响量 `SI(BT)` 是可测量、可预算的。

**灵感 4（社会影响球与影响感知鲁棒谱）**
直觉：真实人类既非固定也非任意，应在一个**校准过的影响球**里取最坏情形：`Π_ε(BT)={π_H: W_1(π_H,π_H^{BT})≤ε}`。于是鲁棒谱升级为 `ρ_BT^soc(d)=inf_{π_H∈Π_ε} P(success_d)`。关键区分：影响可以是正的外部性（人主动让路、帮忙），也可以是负的（抵抗、报复、模仿危险行为）；取 inf 使证书同时覆盖二者。社会规范则作为独立硬约束 `SI(BT)≤Θ_s`，不与鲁棒性混为一谈。

**灵感 5（社会约束合成 + 在线影响账本）**
直觉：不能先合成行为树再“看看社会影响大不大”，必须在**同一优化问题**里约束：可验证契约、任务覆盖、`ρ_BT^soc`、`SI≤Θ_s`、第 54 轮的 `δ_a`。部署后用**社会影响账本**累计影响并监控人类模型漂移；一旦越界或证书衰减，触发**收缩性修复**（降级为询问/等待、交还人类权威、Explain 重规划），并要求 `SI(Repair(BT))≤γ·SI(BT)`，防止“越修越强势”的升级螺旋。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（行为树与执行迹）**
行为树 `BT=(N,n_0,type,children,guard)`，节点类型 `Sequence(→)`、`Fallback(?)`、`Parallel(∥)`、`Decorator`、`Action`（技能 `s`）、`Condition`（守卫 `c`）。一次 tick 的转移 `step_n: X×H → {SUCCESS,FAILURE,RUNNING}×X'×H'`。给定初始状态 `x` 与人类响应 `π_H`，`BT` 诱导执行迹分布 `Traces(BT,x,π_H)`。扁平技能序列 `⟨s_1,...,s_k⟩ ≡ Sequence(s_1,...,s_k)`，故第 54 轮的 `G_S` 路径是 `BT` 的无回退特例。

**定义 122（行为树契约与 assume-guarantee 证书）**
节点 `n` 的契约 `K_n=(A_n,G_n)`，`A_n` 为对 `(x,h)` 的假设，`G_n=(ρ_n,A_cert_n,γ_{ce,n},δ_{a,n})`，是第 54 轮联合证书 `J` 的树化片段。组合：
```
Sequence:  G_{n1→n2} = G_{n1} ⊗ G_{n2},   A = A_{n1} ∧ (A_{n2} | G_{n1})
Fallback:  G_{n1?n2} = G_{n1} ⊔ G_{n2},   A = A_{n1} ∨ (fail(n1) ∧ A_{n2})
Parallel:  G_{n1∥n2} = G_{n1} ⊓ G_{n2},   A = A_{n1} ∧ A_{n2}
```
`⊔` 表示“至少一分支在其失败前提被满足后兜底”，`⊓` 为 `ρ` 逐点取 min、`A_core` 取交。`cert_BT` sound 当且仅当对所有节点子契约蕴含父契约且 `A_{n0} ⊆ A_env`。关键：`Fallback` 的析取保证是任何扁平路径证书都不具备的表达力。

**定义 123（行为签名、社会影响算子与影响量）**
行为签名 `sig(BT)=(回退顺序,询问/等待策略,接近距离剖面,重试激进度,可读性线索)`。人类响应 `π_H(·|x,sig(BT))`，社会影响算子 `𝕊[BT]:π_H^0 ↦ π_H^{BT}`。影响量
```
SI(BT) = E_{x~d}[ W_1( π_H^{BT}(·|x,sig(BT)), π_H^0(·|x) ) ]
```
其中 `W_1` 为人类轨迹分布的一阶 Wasserstein 距离（可换成任务相关的 KL/偏差）。规范预算 `SI(BT) ≤ Θ_s`。

**定义 124（社会影响感知鲁棒谱与行为树联合证书）**
校准影响球 `Π_ε(BT)={π_H : W_1(π_H,π_H^{BT}) ≤ ε}`（`ε` 由交互数据 conformal 校准）。影响感知鲁棒谱
```
ρ_BT^soc(d) = inf_{π_H∈Π_ε(BT)} inf_{tr~Traces(BT,·,π_H)} P(success_d | tr, π_H)
```
行为树联合证书 `J_BT = (K_BT, ρ_BT^soc, A_cert_BT, γ_ce, δ_a, sig(BT), SI(BT), ε, evidence)`。可部署条件：
```
cert_BT sound ∧ ρ_BT^soc(d) ≥ ρ_min ∀d ∧ SI(BT) ≤ Θ_s ∧ δ_a ≤ Θ_a
```
`evidence` 至少含：回退触发迹、人类响应校准集、社会影响审计记录。

**定义 125（社会约束行为树合成 SBS）**
```
BT* = argmin_{BT∈𝔅(G_S)} C(BT)=|N|+λ·depth(BT)+μ·max_{e∈BT} cost_align(e)
s.t. 定义 124 可部署 ∧ Cov(BT) ≥ 1-ε_cov
```
`𝔅(G_S)` 由行为树文法（对 `G_S` 中技能施加 `Sequence/Fallback/Parallel/Decorator`）生成；`Cov` 为任务覆盖。回退带来的有效成功率不是简单的 `1-∏(1-ρ)`，因为失败相关性与动作耦合会破坏独立性——这正是必须在树上而非在路径上验证的原因。

**定义 126（社会影响账本与证书时效）**
累计影响 `SI_cum(t)=Σ_{τ≤t} γ^{t-τ} SI(BT_τ)`，人类模型漂移 `Δ_H(t)=W_1(π_H^{BT}(t),π_H^{BT}(t_0))`。证书有效性
```
Val(J_BT,t)=1[ SI_cum(t)≤Θ_s ∧ Δ_H(t)≤δ_H ∧ ρ_BT^soc(t)≥ρ_min ]
```
失效触发修复 `Repair(BT)`：优先选择更少影响的回退（询问/等待）、交还人类权威、或第 54 轮 Explain 重规划。要求收缩性 `SI(Repair(BT)) ≤ γ·SI(BT), γ<1`，避免影响升级螺旋。

## 2. 关键算法 伪代码

### IP-121 BTC（Behavior Tree Compilation）

```python
def compile_bt(G, J_edges, task_guard, recovery_lib):
    path = shortest_certified_path(G, J_edges)        # 第54轮 SCOM 路径
    bt = Sequence([Action(s, J_edges[e]) for s, e in path])
    bt = wrap_guards(bt, task_guard)                  # Condition 守卫
    for node in fragile_nodes(bt, J_edges):           # 低 rho 边插回退
        node.replace_with(Fallback([node, recovery_lib.pick(node)]))
    return bt
```

### IP-122 BGC（Behavior-tree Assume-Guarantee Certificate）

```python
def verify_bt(n, env_assumption):
    if n.is_action:      K = (env_assumption, n.J)
    elif n.is_condition: K = (env_assumption & n.guard, TRIVIAL_G)
    elif n.type == 'sequence':
        K = compose_sequence([verify_bt(c, chain_env(i)) for i,c in enumerate(n.children)])
    elif n.type == 'fallback':
        K = compose_fallback([verify_bt(c, fail_env(i)) for i,c in enumerate(n.children)])
    elif n.type == 'parallel':
        K = compose_parallel([verify_bt(c, env_assumption) for c in n.children])
    sound = implies(env_assumption, K.A) and K.G.well_formed()
    return Contract(K.A, K.G, sound)
```

### IP-123 SIE（Social Influence Estimator）

```python
def estimate_social_influence(bt, human_data, baseline_data, alpha=0.05):
    sig = behavior_signature(bt)
    pi_bt = fit_response_model(human_data, sig)
    pi_0  = fit_response_model(baseline_data, sig_0)   # 无机器人/被动基线
    si = mean(wasserstein1(pi_bt[x], pi_0[x]) for x in sample_states)
    eps = conformal_radius(pi_bt, human_data, alpha)   # 影响球半径
    return pi_bt, si, eps
```

### IP-124 SRR（Socially-Robust Robustness）

```python
def socially_robust_spectrum(bt, pi_bt, eps, dims, n_adv=256):
    worst = {d: 1.0 for d in dims}
    for pi_h in adversarial_human_models(pi_bt, eps, n_adv):
        trs = sample_traces(bt, pi_h, n=512)
        for d in dims:
            worst[d] = min(worst[d], success_rate(trs, d))
    return worst
```

### IP-125 SBS（Socially-Bounded Synthesis）

```python
def synthesize_social_bt(skills, G, human_data, pi_0, rho_min, theta_s, budget):
    best = None
    for bt in bt_grammar_search(G, skills, budget):
        if not covers_task(bt): continue
        pi_bt, si, eps = estimate_social_influence(bt, human_data, pi_0)
        if si > theta_s: continue
        K = verify_bt(bt, env_assumption)
        if not K.sound: continue
        rho_soc = socially_robust_spectrum(bt, pi_bt, eps, DIMS)
        if min(rho_soc.values()) < rho_min: continue
        cost = bt_cost(bt)
        if best is None or cost < best.cost:
            best = SynthesisResult(bt, J_BT(K, rho_soc, sig=signature(bt), SI=si, eps=eps), cost)
    return best
```

### IP-126 SIL（Social Influence Ledger + Repair）

```python
def monitor_and_repair(bt, ledger, t, human_obs):
    ledger.update(human_obs)                       # 在线更新 pi_H 与漂移
    si_cum, drift = ledger.si_cum(), ledger.drift()
    rho_soc = socially_robust_spectrum(bt, ledger.pi_bt, ledger.eps, DIMS)
    if si_cum <= THETA_S and drift <= DELTA_H and min(rho_soc.values()) >= RHO_MIN:
        return ('valid', bt)
    candidates = [downgrade_to_ask(bt), wait_more(bt),
                  handover_to_human(bt), explain_replan(bt, ledger.exp)]
    for cand in candidates:
        _, si_c, eps_c = estimate_social_influence(cand, ledger.human_data, ledger.baseline)
        if si_c <= GAMMA * ledger.si_now() and verify_bt(cand, env_assumption).sound:
            return ('repaired', cand)
    return ('abort', handover_to_human(bt))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| BTC | O(|V|+|E|+|S|) | O(|N|) | 路径证书覆盖、回退补全 |
| BGC | O(|N|·|J|) | O(|N|·|A|) | 契约归纳、假设不被回退泄漏 |
| SIE | O(|D_H|·|X|·|sig|) | O(|X|·|sig|) | 响应模型校准、conformal 覆盖 |
| SRR | O(n_adv·|BT|·T) | O(|BT|·T) | 影响球包含真策略、worst-case 单调 |
| SBS | O(b^d·(|BGC|+|SRR|))（最坏） | O(b·d) | 证书剪枝 sound、社会预算闭合 |
| SIL | O(1) 摊销/tick | O(|W|) | 泄漏检测、修复收缩 γ |

**正确性定理（Socially-Robust Behavior Tree Soundness）**
承接第 54 轮 (A22)–(A28)；新增：
**(A29)** 行为树契约是归纳的：每个节点的假设由父节点的保证与环境模型蕴含，回退分支的假设显式包含“前序分支失败”；
**(A30)** 真实人类策略以概率 ≥ `1-β_H` 落在校准影响球 `Π_ε(BT)` 内；
**(A31)** 修复算子收缩：`SI(Repair(BT)) ≤ γ·SI(BT)`，`γ<1`，且 `SI_cum` 有界。
则部署后“任务成功 ∧ 社会规范不被突破”的概率
```
P_safe_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - β_H - P(δ_a>Θ_a) - P(SI(BT)>Θ_s)
```
证明要点：BGC 归纳给出 `cert_BT sound ⇒ 任意执行迹满足 J_BT`；SRR 在 `Π_ε` 上取 inf 覆盖人类响应不确定性；SIL 的收缩性保证修复不放大影响。注意：这里**不能沿用扁平路径的独立性假设**，回退分支的失败是相关的，故 `ρ_BT^soc` 必须在迹分布上估计而非用 `1-∏(1-ρ_i)`。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 人类策略非平稳/异质，影响球覆盖不足 | 高 | conformal 校准 + 分层人群 + 主动交互采样 |
| 回退契约假设泄漏导致虚假 sound | 高 | 显式失败前提 + 归纳验证 + 反例回放 |
| 行为树状态/节点爆炸 | 中 | 模块化子树缓存 + 对称性约简 + 深度预算 |
| 影响回路正反馈（升级螺旋） | 高 | 收缩约束 γ + 迟滞 + 人类权威/opt-out |
| 社会影响被用于操纵 | 高 | 只允许可观察、可拒绝、可撤销的影响；禁止隐蔽说服；伦理审查 + 透明日志 |
| 社会指标主观/不可比 | 中 | 只测任务相关可观察量；报告分布而非单一均值 |

## 6. 本轮最大风险

**一句话**：行为树把组合从“一条路径”升级为“带回退的控制策略”，社会影响把环境从外生升级为内生，二者叠加能同时修复扁平证书与“鲁棒但冒犯”的缺陷；但其 soundness **三重依赖影响球包含真实人类响应（A30）、回退契约不泄漏假设（A29）、以及修复算子严格收缩（A31）**——一旦人类策略非平稳或影响模型失准，一个“可验证社会鲁棒”的行为树可能恰好系统性地胁迫或冒犯它本应尊重的人，因此必须以 **conformal 人类响应校准 + 显式失败前提的契约归纳 + 人类权威与影响账本** 三重护栏，宁可选择保守、透明、可拒绝的行为树，也绝不把“影响可测量”误当作“影响可接受”。

### IP-122 BGC

```python
def verify_bt(n, env_assumption):
    if n.is_action:      K = (env_assumption, n.J)
    elif n.is_condition: K = (env_assumption & n.guard, TRIVIAL_G)
    elif n.type == 'sequence':
        K = compose_sequence([verify_bt(c, chain_env(i)) for i,c in enumerate(n.children)])
    elif n.type == 'fallback':
        K = compose_fallback([verify_bt(c, fail_env(i)) for i,c in enumerate(n.children)])
    elif n.type == 'parallel':
        K = compose_parallel([verify_bt(c, env_assumption) for c in n.children])
    sound = implies(env_assumption, K.A) and K.G.well_formed()
    return Contract(K.A, K.G, sound)
```

```python
def estimate_social_influence(bt, human_data, baseline_data, alpha=0.05):
```

### IP-124 SRR

```python
def socially_robust_spectrum(bt, pi_bt, eps, dims, n_adv=256):
    worst = {d: 1.0 for d in dims}
    for pi_h in adversarial_human_models(pi_bt, eps, n_adv):
        trs = sample_traces(bt, pi_h, n=512)
        for d in dims:
            worst[d] = min(worst[d], success_rate(trs, d))
    return worst
```

### IP-125 SBS

```python
def synthesize_social_bt(skills, G, human_data, pi_0, rho_min, theta_s, budget):
    best = None
    for bt in bt_grammar_search(G, skills, budget):
        if not covers_task(bt): continue
        pi_bt, si, eps = estimate_social_influence(bt, human_data, pi_0)
        if si > theta_s: continue
        K = verify_bt(bt, env_assumption)
        if not K.sound: continue
        rho_soc = socially_robust_spectrum(bt, pi_bt, eps, DIMS)
        if min(rho_soc.values()) < rho_min: continue
        cost = bt_cost(bt)
        if best is None or cost < best.cost:
            best = SynthesisResult(bt, J_BT(K, rho_soc, sig=signature(bt), SI=si, eps=eps), cost)
    return best
```

### IP-126 SIL

```python
def monitor_and_repair(bt, ledger, t, human_obs):
    ledger.update(human_obs)                       # 在线更新 pi_H 与漂移
    si_cum, drift = ledger.si_cum(), ledger.drift()
    rho_soc = socially_robust_spectrum(bt, ledger.pi_bt, ledger.eps, DIMS)
    if si_cum <= THETA_S and drift <= DELTA_H and min(rho_soc.values()) >= RHO_MIN:
        return ('valid', bt)
    candidates = [downgrade_to_ask(bt), wait_more(bt),
                  handover_to_human(bt), explain_replan(bt, ledger.exp)]
    for cand in candidates:
        _, si_c, eps_c = estimate_social_influence(cand, ledger.human_data, ledger.baseline)
        if si_c <= GAMMA * ledger.si_now() and verify_bt(cand, env_assumption).sound:
            return ('repaired', cand)
    return ('abort', handover_to_human(bt))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| BTC | O(\|V\|+\|E\|+\|S\|) | O(\|N\|) | 路径证书覆盖、回退补全 |
| BGC | O(\|N\|·\|J\|) | O(\|N\|·\|A\|) | 契约归纳、假设不被回退泄漏 |
| SIE | O(\|D_H\|·\|X\|·\|sig\|) | O(\|X\|·\|sig\|) | 响应模型校准、conformal 覆盖 |
| SRR | O(n_adv·\|BT\|·T) | O(\|BT\|·T) | 影响球包含真策略、worst-case 单调 |
| SBS | O(b^d·(\|BGC\|+\|SRR\|))（最坏） | O(b·d) | 证书剪枝 sound、社会预算闭合 |
| SIL | O(1) 摊销/tick | O(\|W\|) | 泄漏检测、修复收缩 γ |

**正确性定理（Socially-Robust Behavior Tree Soundness）**
承接第 54 轮 (A22)–(A28)；新增：
**(A29)** 行为树契约是归纳的：每个节点的假设由父节点的保证与环境模型蕴含，回退分支的假设显式包含“前序分支失败”；
**(A30)** 真实人类策略以概率 ≥ `1-β_H` 落在校准影响球 `Π_ε(BT)` 内；
**(A31)** 修复算子收缩：`SI(Repair(BT)) ≤ γ·SI(BT)`，`γ<1`，且 `SI_cum` 有界。
则部署后“任务成功 ∧ 社会规范不被突破”的概率：
```
P_safe_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - β_H - P(δ_a>Θ_a) - P(SI(BT)>Θ_s)
```
关键：**契约在树上归纳而非在单迹上成立**、**人类响应在最坏影响球内被覆盖**、**修复不放大社会影响**。回退分支失败相关，禁止用 `1-∏(1-ρ_i)` 近似 `ρ_BT^soc`。

## 5. 本轮最大风险

**一句话**：行为树把组合从“一条路径”升级为“带回退的控制策略”，社会影响把环境从外生升级为内生，二者叠加能同时修复扁平证书与“鲁棒但冒犯”的缺陷；但其 soundness **三重依赖影响球包含真实人类响应（A30）、回退契约不泄漏假设（A29）、以及修复算子严格收缩（A31）**——一旦人类策略非平稳或影响模型失准，一个“可验证社会鲁棒”的行为树可能恰好系统性地胁迫或冒犯它本应尊重的人，因此必须以 **conformal 人类响应校准 + 显式失败前提的契约归纳 + 人类权威与影响账本** 三重护栏，宁可选择保守、透明、可拒绝的行为树，也绝不把“影响可测量”误当作“影响可接受”。
