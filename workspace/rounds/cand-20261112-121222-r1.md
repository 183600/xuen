# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环新周期第 1 轮；本轮灵感：「共享控制」×「创新点挖掘」）

> 第 57 轮把"证据承诺"推到元认知-信任层：先验从跨区域摊销、证据按模态分账、人变成单向有界的信任状态机。但它仍把人类放在**离散的同意阶梯**上（L0 通知 / L1 异步 / L2 确认）：人要么是"门"，要么是"标注源"——**人从不真正与机器人共同握方向盘**。本轮两个灵感正面撞上这个缺口：**共享控制**要求把权威从离散门升级为连续、可仲裁、可问责的共同控制；**创新点挖掘**则要求我们不再"拍脑袋加模块"，而是把 57 轮积累的 IP 语料当作可计算的设计空间，用显式挖掘算子找出未覆盖、相矛盾、可反转、可迁移的维度，并为每个候选出具"新颖性 + 健全性"证书。本轮核心命题：**共享的是意图与权威，永不共享安全底线**；**创新点也必须像模型一样过隔离区**。于是"证据说可信"再进一步，变成 **"权威可共享、底线不可共享、创新可审计的证明式共同控制"**。

核心矛盾：
- **H29（混合 vs 证书）**：安全证书历来为"单一作者"的策略签发；两个各自安全的策略做混合，得到的却是**无人单独授权**的第三种动作——端点安全不保证混合安全（左避让与右避让各 50% 会直冲障碍），且事故后无法归责。共享控制必须先回答"谁为混合动作签字"。
- **H30（权威 vs 注意力）**：共享控制会改变人：自动化依赖、警觉衰减、习得性无助让"人始终在环"变成"人在环但不在状态"；而连续共控没有天然确认点，第 57 轮的离散 vig/auth 观测会失效，权威可能在"更顺手"的渐进让渡中悄悄滑走（authority creep）。
- **H31（新颖 vs 严谨）**：灵感驱动的第 1 轮最容易产出"新颖但不成立"或"成立但不新颖"的点；若不把"创新点挖掘"本身形式化并给候选发证书，研究循环会退化成 novelty theater——**用新词包装旧机制**。

## 0. 直觉与动机

**灵感 1（共享控制 → 安全底线不可共享）**
直觉：把"人机共驾"想成两个人抢方向盘是错的。真正的安全共享不是把两个输入平均，而是：**人决定"想去哪"（意图），机器人守住"不能怎么去"（底线），中间那层"谁来主导"（权威）连续可调**。于是关键不变量是——**认证模式下的执行动作必须永远先过同一个安全过滤器；共享控制共享的是过滤器之上的意图与权威，绝不共享过滤器本身**。人可以让机器人开得更快、更靠边、更激进，但不能让机器人绕过"这一步会不会翻/会撞"的硬约束；真要绕过，必须显式切到"手动/紧急模式"，承认风险、留下签名、并退出安全证书的覆盖范围。一句话：**底线是单点、不可让渡、不可协商的**。

**灵感 2（共享控制 → 权威是资源，问责是账本）**
直觉：权威不是布尔开关而是**可分割的资源**——纵向速度、横向避让、步态选择、落脚点可以有不同的主导方。既然是资源，就有"汇率"与"账本"：机器人要多拿一分权威，必须拿出证据（第 57 轮的证书）；人随时可以一分钱赎回全部权威（单向逃生），但赎回本身要经过交接协议，不能在人不清醒时突然接管。每个执行动作都记一条**问责溯源**：哪个通道由谁主导、依据哪张证书、在哪个 α 下产生——事故后能回答"这个动作是谁签的字"，避免混合动作成为"孤儿动作"。

**灵感 3（创新点挖掘 → 设计空间挖掘算子）**
直觉：57 轮的 IP 不是散点，而是一张**高维设计空间**：机制 × 安全通道 × 证据类 × 假设 × 失效模式 × 接口 × 层级。创新点挖掘不是头脑风暴，而是对这张图做六种可复算的操作：**找空洞（GAP）、找矛盾（CONTRADICT）、重组（RECOMBINE）、反转（INVERT）、迁移（TRANSFER）、推到极限（SCALE）**。每个候选必须过两道证：**新颖性证**（与语料中最近 IP 的语义距离 ≥ ν0，且没有同属性精确匹配）与**健全性证**（能挂到"信念更准/动作更保守"安全通道，且给出可证伪实验）。没过证的候选不是被丢掉，而是进"候选池"留痕——这样"为什么这轮没采纳某灵感"也可审计。

**灵感 4（两灵感合流 → 用挖掘算子挖出共享控制，再用共享控制检验挖掘算子）**
直觉：本轮不是"先有共享控制再硬凑创新"，而是**让挖掘算子自己在 v33 语料上跑一遍**：GAP 发现"人只在离散门出现"；CONTRADICT 发现"人可紧急接管"与"认证安全"冲突；SCALE 把 auth∈{A0,A1,A2} 推到 α∈[0,1] 连续权威；INVERT 把"人是门"反转为"人是共控者、但底线不是"；TRANSFER 把航空的人机交接（handover）与 CBF 安全过滤迁进来。挖出的候选再反向检验算子：若某个"很新"的候选其实无法挂安全通道，说明算子把"新"和"好"混为一谈——这就是 H31 的现场演示。

**灵感 5（PCE++ → 权威仲裁进入探-诺-演循环）**
直觉：第 57 轮的检查点只有"探/诺/演"，本轮在每个检查点插入**仲裁步**：先估意图置信与证据置信，再决定 α 的允许区间 A_cert，最后才承诺。权威仲裁只能经两个通道影响系统：**(a) 让意图/证据信念更准（含更宽）**，或 **(b) 让执行动作更保守（过滤器、降档、最小风险锚）**；权威本身**不能**成为绕过证书的第三条升险通道——因为它只改变喂给过滤器的参考，不改变过滤器。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（共享权威状态 SAS 与认证权威集）** 控制通道集 C={v_x, v_y, ω, gait, foot}；权威向量 α∈[0,1]^{|C|}，α_c 为机器人对通道 c 的主导份额，α_c=1−α_c^h。共享参考 ξ_α=⊕_c Blend_c(ξ_h,c, ξ_r,c, α_c)（在意图/参考层，不在执行层）。认证权威集 A_cert(x,β)={α : Filter 对 ξ_α 可行且证据门通过}；**安全底线不变量**：认证模式下 ∀α,ξ_h，执行 u=Filter(ξ_α) 必须满足与纯自主相同的 CBF/证据约束。A_cert 非空是共享控制可用的前提，空则退最小风险锚 a_mr。

**定义 140（意图混合-安全投影 ISF）** 给定参考映射 κ，u\*=argmin_u ||u−κ(ξ_α)||² s.t. L_f h_i+L_g h_i·u+κ_i h_i≥0（∀i∈硬约束），u∈U_act。性质：(P1) 端点安全不推出混合安全（参考层左/右平均可致直冲），故禁止执行层平均；(P2) 只要 h_i 有效且约束集非空，u\* 对任意 ξ_α 保持前向不变，故**共享控制不新增安全项**；(P3) 过滤器不可被人输入绕过，绕过只能经显式手动模式 M_man。

**定义 141（权威仲裁协议 AAP）** 状态 (α,s_o,auth)。规则：(R1) **人的单向逃生**：α_h 可瞬时升到 1（请求接管），系统不得拒绝，但须走交接协议 HOV；(R2) **机器升级有据有界**：α_r,c 增加需证据证书 ∧ 意图置信≥θ_int ∧ 速率≤Δ_α/T ∧ α∈A_cert；(R3) **汇率审计**：每次权威变动记 (Δα, 证据, 作者, t)，无证书的升权一律拒绝；(R4) 授权只参数化"升级速率与佐证数"，不触碰过滤器与证据门本体。

**定义 142（交接协议 HOV 与最小风险条件）** 交接 (A→B) 为四阶段 {请求, 就绪, 转移, 确认}，时限 τ_ho，期间系统处于最小风险条件 MRC（受控减速/原地稳定/步态降档）。就绪判据：接管方意图置信≥θ_rdy ∧ 接管方状态可观测（人：vig≥θ_vig；机：证书有效）。转移期间两方共享但**过滤器始终在环**；超时未确认 → 回退到 MRC 并重新仲裁。交接证书 J_ho 记录两端状态、τ_ho、MRC 轨迹与失败原因。

**定义 143（问责溯源证书 AAC 与"无孤儿动作"）** 每次承诺动作 a 附来源映射 prov(a)={c↦(作者, α_c, 证书 id, t)}，满足：∪_c prov 覆盖全部被执行通道；若 α_c∈(0,1) 则记双作者与混合权重；任何无法归因的通道 ⇒ 拒绝执行（no orphan action）。事故回溯函数 Attr(a)→(人/机/混合, 依据证书)，供事后定责与再训练。

**定义 144（创新挖掘算子 IMO 与双证书）** 语料 𝓘={IP_i}，每 IP 结构化属性 (机制, 安全通道, 证据类, 假设集, 失效模式, 接口, 层级)。挖掘算子 Ω={GAP, CONTRADICT, RECOMBINE, INVERT, TRANSFER, SCALE}，Ω(𝓘) 产出候选集 C。**新颖性证** N(c)：d_IP(c, NN_𝓘(c))≥ν0 且无属性精确匹配（d_IP 为结构化距离，非纯嵌入）；**健全性证** S(c)：∃安全通道 σ(c)∈{信念更准, 动作更保守} ∧ 假设可检验 ∧ 有证伪实验；**可行性证** F(c)：复杂度/数据/时延在预算内。仅当 N∧S∧F 才准入 IP；未过证者入候选池并留痕（可解释"为何本轮不采纳"）。IMO 自身走隔离：新 IP 先以影子插件在既有证书链上试跑，回归通过才升级为主 IP。

## 2. 关键算法伪代码（完整版见产物区）

```python
def shared_control_step(x, xi_h, M, s, budget):
    alpha = arbitrate_authority(s, M, budget)            # IP-141
    if alpha is None:                                     # A_cert 空
        return minimum_risk_anchor(x), 'mr_anchor'
    xi = blend_intent(xi_h, plan_intent(M), alpha)        # IP-140: 意图层混合
    u = safety_filter(xi, x, hard_constraints(M))         # 底线：不可共享
    if u is None: return minimum_risk_anchor(x), 'filter_infeasible'
    return u, prov_certificate(u, xi, alpha, s)           # IP-143

def arbitrate_authority(s, M, budget):
    if s.request_takeover: return handover('R->H', s, M)  # R1: 人可瞬时逃生
    A = certified_authority_set(M, s)                     # IP-139
    if not A: return None
    if can_escalate(s, M, budget):                        # R2: 有据有界
        return clamp_rate(s.alpha + delta_alpha, A, budget.dt)
    return s.alpha
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SAS | O(\|C\|) | O(\|C\|) | A_cert 非空、底线不变量 |
| ISF | O(m·n²)/步（QP） | O(n) | h 有效、约束集非空→前向不变 |
| AAP | O(\|C\|) | O(\|C\|) | 人逃生不被拒、机升权有证书 |
| HOV | O(τ_ho/dt) | O(1) | 就绪判据、超时回 MRC |
| AAC | O(\|C\|)/动作 | O(H_op) | 全通道归因、无孤儿动作 |
| IMO | O(\|𝓘\|²·d_attr) | O(\|𝓘\|) | 双证准入、未过留痕 |

**正确性定理（Certified Shared Control, CCSC 概要）**：在 A37–A40（第 57 轮）上新增 **(A41)** 安全过滤器健全（h_i 有效、约束集非空，否则回退 MRC）；**(A42)** 意图混合有界（ξ_α 落在声明意图集的凸包内，不外推）；**(A43)** 仲裁单调安全（α 恒在 A_cert、人逃生不可拒、机升权必有证书且限速）；**(A44)** 问责完备（全通道归因，手动模式显式出界）。则：(i) 认证模式下对任意 α、ξ_h，执行动作满足与纯自主相同的 CBF/证据约束，**共享控制不新增安全项**，失效率继承 v57 界；(ii) 手动模式不混入证书、风险显式归属操作者；(iii) 权威不构成第三条升险通道；(iv) 无孤儿动作；(v) IMO 准入必过 N∧S∧F，未过候选留痕。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 过滤器被"紧急接管"绕过，底线名存实亡 | 高 | 手动模式显式出界 + 限时 + 签名 + 不计入证书；底线不可协商 |
| 权威蠕变（渐进让渡不被察觉） | 高 | 汇率审计 + 有界速率 + 会话域重估 + 人逃生优先 |

| 混合动作定责不清 | 中 | AAC 全通道归因 + 双作者权重 + 无孤儿动作硬拒 |
| IMO 产出 novelty theater | 中 | 双证准入 + 候选池留痕 + 影子隔离 + 外部查新 |

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"权威蠕变"——在"更顺手、更协作"的持续压力下，人把一分分权威让渡给机器人，而安全底线又被"紧急时我能接管"的幻觉默许侵蚀，最终认证模式与手动模式的边界模糊、问责失效；必须以"底线不可共享 + 手动模式显式出界 + 汇率审计 + 无孤儿动作"四道硬护栏把共享控制锁死在过滤器之上，并让创新挖掘算子对每一个"新增共享"都先索要安全通道证书。

# 第 58 轮产物 · 创新点清单 v34：Shared-Authority-Certified（共享权威控制×意图层混合×问责溯源×创新挖掘，SAC×ISF×AAP×HOV×AAC×IMO）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与更早的 v16** 体系。本轮把部署前提从"证据承诺"升级为 **"权威可共享、底线不可共享、创新可审计的证明式共同控制"**：人从离散同意门升级为连续共控者，权威成为带汇率与账本的可分割资源，安全过滤器成为唯一不可让渡的底线；同时把"找创新点"本身形式化为设计空间挖掘算子，每个新 IP 必须持"新颖性+健全性+可行性"三证入场。第 57 轮"一切判定器走隔离"推广为"**创新点也走隔离**"。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-128/132/135/138 以纳入连续权威、交接与问责维度。

### IP-141 AAP（权威仲裁：人逃生优先、机升权有据有界）

```python
def arbitrate_authority(s, M, budget):
    if s.request_takeover:                            # R1: 单向逃生，不得拒绝
        return handover('R->H', s, M)
    A = certified_authority_set(M, s)
    if not A: return None
    if can_escalate(s, M, budget):                    # R2: 证书+置信+限速
        cand = clamp_rate(s.alpha + delta_alpha, A, budget.dt)
        audit.log(('escalate', s.op, cand, s.evidence_id, t_now))  # R3
        return cand
    return s.alpha

def can_escalate(s, M, budget):
    return (s.evidence_cert.valid and s.intent_conf >= theta_int
            and rate_ok(s.alpha, budget.dt) and s.auth >= 'A1')

def request_takeover(self):                           # 人的逃生是状态而非输入
    self.request_takeover = True; return self          # 系统只能安排交接，不能拒绝
```

### IP-142 HOV（交接协议与最小风险条件）

```python
def handover(direction, s, M):
    s.ho = HoState(direction, t0=now(), phase='request')
    while now() - s.ho.t0 <= tau_ho:
        if ready(direction, s, M):                    # 就绪：意图置信∧状态可观测
            s.ho.phase = 'transfer'
            u = transfer_with_filter(direction, s, M) # 转移期过滤器仍在环
            s.ho.phase = 'confirm'
            return u
        u = mrc(s)                                    # 未就绪：受控减速/原地稳定
    return mrc(s), 'ho_timeout'                       # 超时回 MRC 重新仲裁

def ready(direction, s, M):
    return s.intent_conf >= theta_rdy and observable(s, M) \
           and (s.vig >= theta_vig if direction == 'R->H' else s.cert_valid)
```

### IP-143 AAC（问责溯源与无孤儿动作）

```python
def prov_certificate(u, xi, alpha, s):
    prov = {}
    for c in channels(xi):
        a_r, a_h = alpha[c], 1 - alpha[c]
        prov[c] = (author_of(c, a_r, a_h), a_r, s.evidence_id[c], t_now())
    if not covers_all_channels(prov, u):              # 有通道无法归因
        raise OrphanAction(u)                         # 硬拒：无孤儿动作
    return AAC(u=u, xi=xi, alpha=alpha, prov=prov,
               manual=(s.mode == 'M_man'), sig=s.op)

def attribute(action_log):
    return [(a, 'manual' if a.manual else mix(a.prov)) for a in action_log]
```

### IP-144 IMO（创新挖掘算子 + 三证准入 + 影子隔离）

```python
def mine_innovation(corpus, frontier, budget):
    cands = []
    cands += GAP(corpus, frontier)                    # 低覆盖维度
    cands += CONTRADICT(corpus)                       # 冲突假设对
    cands += RECOMBINE(corpus, frontier)              # 未声明配对
    cands += INVERT(corpus)                           # 反转设计原则
    cands += TRANSFER(corpus, external_fields)        # 跨领域迁移
    cands += SCALE(corpus, limits)                    # 离散→连续/静态→动态
    admitted, pool = [], []
    for c in dedup(cands):
        cert = Cert(n=novelty(c, corpus), s=soundness(c),
                    f=feasibility(c, budget))
        (admitted if cert.all_pass(nu0) else pool).append((c, cert))
    return admitted, pool                             # 未过者留痕，可解释

def novelty(c, corpus):                               # 结构化距离，非纯嵌入
    return min(d_IP(c, ip) for ip in corpus)

def soundness(c):                                     # 必须挂安全通道 + 可证伪
    return (channel_of(c) in {'belief_accurate', 'action_conservative'}
            and falsifiable(c) and assumptions_testable(c))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SAC | O(\|C\|) | O(\|C\|) | A_cert 非空、底线不变量（A41/A43） |
| ISF | O(m·n²)/步（QP） | O(n) | h 有效、约束非空→前向不变（A41/A42） |
| AAP | O(\|C\|) | O(\|C\|) | 人逃生不被拒、机升权有证书（A43） |
| HOV | O(τ_ho/dt) | O(1) | 就绪判据、超时回 MRC（A41/A43） |
| AAC | O(\|C\|)/动作 | O(H_op) | 全通道归因、无孤儿动作（A44） |
| IMO | O(\|𝓘\|²·d_attr) | O(\|𝓘\|) | 三证准入、未过留痕 |

**正确性定理（Certified Shared Control, CCSC）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** 安全过滤器健全：硬约束 h_i 有效、每步约束集非空，空则回退 MRC；**(A42)** 意图混合有界：ξ_α∈Conv(声明意图集)，不外推；**(A43)** 仲裁单调安全：α 恒在 A_cert，人的接管请求不可被拒，机器升权必须有证据证书且速率 ≤Δ_α/T；**(A44)** 问责完备：全通道可归因，手动模式显式出界且签名。则：

1. **底线健全性**：认证模式下 ∀α,ξ_h，u\*=Filter(ξ_α) 满足与纯自主相同的 CBF/证据约束，故 P(fail) 继承第 57 轮界，共享控制**不新增安全项**；共享只影响 liveness（死锁/振荡/效率），不影响 soundness。
2. **出界显式性**：手动模式 M_man 不进认证证书、限时且签名，风险显式归属操作者；认证与手动之间无"静默混合"。
3. **权威单调安全**：α 转移不越 A_cert；人逃生不被拒；机升权无证书即拒；不存在绕过过滤器的升险通道。
4. **无孤儿动作**：任一执行动作全通道归因，混合动作记双作者与权重；归因不全即拒。
5. **创新可审计**：IMO 准入必过 N∧S∧F；未过候选入池留痕；新 IP 先以影子插件在既有证书链上试跑，回归通过才升级。

关键：**共享的是意图与权威，安全过滤器是单点、不可让渡、不可协商的底线**；**权威是带汇率与账本的资源，人可瞬时赎回、机须凭证赎买**；**创新点也要持证入场并过隔离区**，把"新颖"与"成立"分开审计。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"权威蠕变"——在"更顺手、更协作"的持续压力下，人把一分分权威让渡给机器人，而安全底线又被"紧急时我能接管"的幻觉默许侵蚀，最终认证模式与手动模式的边界模糊、问责失效；必须以"底线不可共享 + 手动模式显式出界 + 汇率审计 + 无孤儿动作"四道硬护栏把共享控制锁死在过滤器之上，并让创新挖掘算子对每一个"新增共享"都先索要安全通道证书。
