# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「机器人竞赛」×「自主导航」）

> R69 教会系统「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配多模态策略生成候选，用注视/探针/问句主动消歧，再用证据纪律防止被单源谎言骗到。但 R69 的整套交互 calculus 建立在三个从未写出的「和平假设」上：
> 1. **回答者不看着你**——问句只改变「我的信念」，不改变「对方关于我的信念」；
> 2. **地图是世界的复印件**——导航依赖的先验地图是一份中立、静止、可信的证言；
> 3. **路可以回头**——每一步都能在下一步撤销，所以「先做再学」永远有退路。
>
> 竞赛式自主导航同时击穿这三条：对手会观察你的每一次停顿与探询；地图可能是上一支队伍留下、被篡改或已经过期的证言；而走廊、坡道、单向门与截止期让某些动作**不可逆**。
>
> 因此本轮的核心不是再加一层「更聪明的问」，而是给「问」本身定价：
> **信息不是免费的，问一次就是广播一次；地图不是事实，是某个人在某个时刻说的话；路线不是状态序列，而是一串可能关上的门。**
>
> 命名 **COMPASS-RAS**（Competition-aware, Opponent-modeling, Provenance-audited, Signaling-aware, Safety-constrained Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我的求证会不会被对手听见、这张地图是谁说的、这条路还回不回得去**」——在竞赛里，知道得更多不一定赢，暴露得更少往往才活得久。

## 0. 直觉与动机

**灵感 1（机器人竞赛 → 不确定性多了「对手」这一维，而且对手会适应你）**
直觉：R69 的 U_epi 问的是「世界到底是哪个模态」；竞赛里更痛的是「对面到底想干什么、他知道我多少」。这不是噪声，不能靠多采样平均掉；它是一个**有意图、会反事实、会针对你更新策略**的对象。更糟的是共适应：你在估计他的类型，他在估计你的策略；你的每一次探询，都是他更新「你迷路了 / 你偏好左路 / 你不敢撞」的观测。所以 U_strat 必须与 U_epi 分开，并且**不能假定平稳**——对手策略会随你的信号漂移。

**灵感 2（竞赛 → 记分牌是相对量，裁判是可能出错的第三方）**
直觉：安全是绝对约束，名次是相对量。R69 的证书只说「我没违规、我没撞」；竞赛还要问「在同样安全的一群策略里，我是否被支配」。同时，记分牌和裁判制造 Goodhart 陷阱：可以靠钻规则、刷仿真漏洞、讨好裁判拿高分。故本轮把**评价与优化分离**：任何提交必须带可独立回放的证书；分数不能为安全/规则违约背书。裁判只是证据，不是主权者。

**灵感 3（自主导航 → 地图是「借来的记忆」，不是世界本身）**
直觉：R68 的残差问「传感器彼此自洽吗」，R69 的流似然问「行为在策略下自洽吗」，但导航还有更古老的证言源——**地图**。地图会过期（门关了、货架移了）、会被对手污染（假墙、假通路）、会被自己错误融合。故地图瓦片必须带 provenance（来源、时间、信任、链），安全认证只许踩在 trust ≥ τ_map 的瓦片上。更妙的是，流策略天然给出**地图条件似然**：同一动作在「可信地图」与「原始地图」条件下的似然差 Δa_M，正是地图撒谎的第二种意见——它与 R69 的 Δa（标定不可吸收）同构，但检验对象从「标定」换成了「证言」。

**灵感 4（自主导航 → 路线是承诺，承诺有价值也有代价）**
直觉：R69 的 λ 是逐帧、无记忆的；但导航的代价常常是**不可逆**的：进了单向走廊就回不了头，冲下坡就停不住，截止期前没到检查点就出局。可逆性本身就是一种资产（option value）。故未消解的 epistemic 落在不可逆动作上时，必须**升格为 aleatoric**——不能拿「我待会儿再问」当退路，因为待会儿可能已经没有回头路。逃生证书（能在预算内退回安全集）因此成为「是否允许拿 resolution bonus」的硬门槛。

**灵感 5（竞赛 × 导航 → 每一次「看」都是一次「被看」）**
直觉：这是本轮最核心、也最反直觉的一点。R69 的信息动作只花钱（时间、社交），不改变对手；竞赛里，**停下来环顾 = 告诉所有人你迷路了**，问裁判 = 暴露你不确定规则，探一条侧路 = 暴露你的路线偏好。于是信息增益必须减去**泄漏成本**与**对手据此获得的优势**。有些查询私下很值钱、战略上是负资产。最优策略有时不是「问清楚」，而是「在不暴露的前提下做最稳健的推断」，甚至用**等价动作掩蔽**（多个任务等价动作里选泄漏最小者）。一句话：**R69 的不确定性是认识论问题，R70 的不确定性是博弈论问题。**

**灵感 6（把 R69 包含为「无对手、可信图、可回头」的边界）**
直觉：新层必须是旧层的严格泛化。当对手缺席（U_strat=0）、地图可信（U_map=0）、动作完全可逆（R=1）、泄漏成本为零时，SVoI 退化为 VoI，COMPASS 逐指令退化为 FLUID-RAS。这样安全侧不做任何让步，新增的只是「在竞争与证言不可信时如何不输得更惨」的判据。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（COMPASS-RAS 总览）** COMPASS-RAS = (OTM, SLE, SVoI, MPM, MFMA, RCC, DRS, TCE, PWE, RAS-WM‡)。五不变式：
(i) **实时快环零学习写操作**（继承 R69 定义 293-i）；
(ii) **战略预算硬约束**：单位时间泄漏 ≤ L_max、信息动作必须过 C-RAS-WM 认证且满足竞赛规则集 ℛ_comp（安全 ≠ 合法）；
(iii) **证言纪律**：地图/裁判/对手回答均为证言；安全关键声明需 ≥2 个正交来源或显式降级，未信任瓦片不得进入安全认证；
(iv) **裁判非主权**：裁判/记分只作证据，证书必须可独立回放；分数不得为安全或规则违约背书；
(v) **截止期-可逆性安全**：P(fail before T_deadline) ≤ ε；不可逆动作在 U_epi 未消解时不得获得 resolution bonus。

**定义 311（竞赛导航状态）** s_t = (x_t, b_t(θ), M_t, ξ_{t:t+H}, Δscore_t, σ_t)，其中 b_t(θ) 为对手类型信念，M_t 为带 provenance 的地图，ξ 为同伦类路线，Δscore 为名次差，σ_t = T_deadline − Ê[T_finish] 为截止期松弛。

**定义 312（不确定性四分）** 在 R69 的 (U_ale, U_epi) 之外增加：
U_strat = H(θ|o)（对手意图/类型的认知不确定性，或对手策略类上的稳健半径）；
U_map = Σ_{τ∈M} (1−trust(τ))·margin_violation(τ)（证言不可信度 × 其危险程度）。
四者语义不同、**不做简单加和**，各走各的通道（定义 328）。R69 的 U_epi 只覆盖「世界状态歧义」，不覆盖「对方意图」与「证言真伪」。

**定义 313（对手类型与共适应）** θ ∈ Θ = {合作, 竞争, 欺骗, 剥削, 模仿}；对手策略 π_opp(a | θ, o^opp, b^opp(我们的策略))。允许 θ 非平稳（换招、联盟、针对）。定义共适应检测统计量 C_t = 对手动作分布在「我们上一窗口的信号」条件下的漂移量；C_t > τ_c 触发稳健模式。

**定义 314（信号泄漏）** 信息动作 g 在对手观测信道下诱导泄漏 ℓ(g) = I(g ; z_priv | o^opp)，z_priv ∈ {我们的不确定性、偏好路线、剩余时间、健康/电量}。ℓ 是「问一次 = 广播一次」的度量；被动观测（不改变行为分布）ℓ=0。

**定义 315（战略信息价值 SVoI）** SVoI(g) = I(M, θ ; y | g, o) − κ_ℓ·ℓ(g) − κ_o·E[ΔAdv_opp(g)] − c(g)，其中 ΔAdv_opp 为对手因该观测获得的相对优势。选择 g* = argmax SVoI(g)，s.t. ℓ(g) ≤ L_remaining、risk(g) ≤ ε_int、g ∈ ℛ_comp。若 max SVoI ≤ 0：不交互，转入**最小信号被动策略**（R69 的「永不交互」是 κ_ℓ=κ_o=0 的特例）。核心：**信息增益为正、战略价值为负的查询应被主动放弃。**

**定义 316（非剥削策略）** 策略 π 称为对手非剥削的，若 ∀θ ∈ Θ：worst-case 安全违约 ≤ ε，且 worst-case 相对遗憾 ≤ ρ。约束是稳健的（对最坏类型），不是对平均对手的期望；否则对手只需选择最坏类型即可剥削。

**定义 317（地图证言格 MPM）** 每个瓦片/路标带 provenance p = (source, timestamp, trust, chain, hash)。信任关系构成偏序 ⊑，融合算子 ⊓ 满足：冲突 ⇒ 取低信任并标记 disputed；过期 ⇒ trust 单调衰减。安全规划只允许使用 trust ≥ τ_map 的连通子图。U_map 度量「不可信质量 × 通行边界裕度」。

**定义 318（地图条件流似然 M-FMA）** a_score^M = −log p_θ(ξ | o, M_trusted)；Δa_M = |a_score^M(o, M_raw) − a_score^M(o, M_trusted)|。**Δa_M 高而定位残差低 ⇒ 疑似地图被污染/过期**（与 R69 定义 301 的 Δa 同构：一个防标定吸收，一个防证言吸收）。

**定义 319（可逆性指数）** 对路线 ξ，R(ξ) ∈ [0,1] = 在时间/能量/安全预算内从 ξ 的任意前缀退回安全集 S_safe 的可行概率。R=1 完全可逆，R=0 单向门。option value O(ξ) = E[|执行 ξ 后仍可行的动作集|]。

**定义 320（逃生证书）** 承诺前缀 ξ_{t:t+k} 可用，当且仅当存在认证的退回轨迹 χ_ret：time(χ_ret) ≤ τ_ret、energy ≤ e_ret、全程风险 ≤ ε_ret、且 R(ξ) ≥ R_min(H)。无逃生证书 ⇒ 视该前缀为不可逆，未消解 U_epi 按定义 328 升格。

**定义 321（截止期感知风险）** 风险预算在视界上分配：P(fail before T_deadline) ≤ ε，而非逐帧独立约束。截止期松弛 σ_t 缩小时，**安全包络不放松**；只允许调整探索/承诺/信息动作的时机——即「安全的进攻性」只在合法且可逆的集合内提升，不允许用安全换名次。

**定义 322（锦标赛分布与风险约束遗憾）** 竞技场/对手分布 D；目标 min_π E_D[Regret(π; Π_adm)] s.t. CVaR_α(risk) ≤ ε、rule_violation = 0。参考集 Π_adm 是**满足安全与规则的策略集**，不是记分最高的策略；held-out arena/opponent 必须与训练分布分离。

**定义 323（回放证书 J_COMPASS 与 Goodhart 防护）** J_COMPASS = (J_FLUID, leakage_used, map_provenance_hash, min_reversibility, deadline_margin_p01, regret_upper, replay_hash, compass_ver)。Valid ⇔ Valid(J_FLUID) ∧ leakage ≤ L_max ∧ rule_violation = 0 ∧ 回放一致。记分/排名只有在 J_COMPASS 有效时才被承认；**证书不可回放的成绩视为无效**，防止刷榜式 reward hacking。

**定义 324（证言加权证据纪律）** 证据源带 provenance 与相关结构；有效独立源数 k_eff = 1/(1 + Σ_{i≠j} ρ_ij)。定案需 k_eff ≥ 2（或 trust 加权后验熵 < τ_H）。对手回答的可信度按与物理证据 (r_res, Δa, Δa_M) 的一致性动态降权；单源声明永远只提供似然，不单独定案。

**定义 325（最小信号动作掩蔽 MSM）** 在任务等价动作集 𝒜_eq(o) = {a : Q(a) ≥ Q_max − δ} 内，选择泄漏最小的动作 a* = argmin ℓ(a)；允许在合法且安全中性时使用**诱饵/混合策略**提高对手推断熵。禁止以欺骗危害安全或违反规则；掩蔽只作用于「策略偏好」，不作用于「安全状态」。

**定义 326（共适应检测与稳健切换）** 监测对手动作分布相对我们信号的漂移 C_t；C_t > τ_c ⇒ U_strat 膨胀、进入窗口期 minimax/robust 模式，暂停一切高泄漏信息动作，直到漂移消失。共适应不是一次性估计，而是持续对抗。

**定义 327（干扰集 ℰ_COMPASS）** ℰ_COMPASS = ℰ_FLUID × ℰ_map × ℰ_signal × ℰ_referee × ℰ_coadapt：地图伪造/过期/删除、窃听与信号利用、跨队共谋、裁判偏置/记分篡改、针对我们策略的过拟合。并入 AIC 作为对抗训练与红队测试的基础。

**定义 328（两级退避扩展）** 若 SVoI ≤ 0、泄漏预算耗尽、U_strat 高、C_t 越界或 U_map 高：退回 R69 保守侧，并叠加「最小信号被动观测 + 仅本地感知导航 + 逃生优先」。有效风险 U_eff = U_ale + [未消解 U_epi]·(1 + (1−R)) + U_strat + U_map；λ = λ_floor(U_eff)。⇒ R69 恰为「无对手、可信图、全可逆、零泄漏」的边界，安全侧永不变弱。

# IP-265/266 战略信息价值：信息增益先扣泄漏与对手获益
def choose_info_action(modes, b_theta, mapM, o, budget, leak_budget):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g): continue
        if not c_ras_wm.certify_info(g, o): continue      # 信息动作也过安全认证
        if not rules.compliant(g): continue               # 安全 != 合法
        ig   = info_gain(modes, g)                        # R69 的 VoI
        leak = leakage_estimate(g, private_state(o))      # I(g; z_priv | o_opp)
        adv  = expected_opp_advantage(b_theta, g)         # 对手据此获得的相对优势
        s    = ig - KAPPA_L * leak - KAPPA_O * adv - cost(g)
        if best is None or s > best.s: best = (g, s, leak)
    if best is None or best.s <= 0: return None           # 最小信号被动（R69 边界）
    if best.leak > leak_budget.remaining: return None
    return best.g

# IP-268 地图条件流似然：防「证言吸收」
def map_fma(policy, xi, o, M_trusted, M_raw):
    a_t = -policy.log_likelihood(xi, o, cond=M_trusted)
    a_r = -policy.log_likelihood(xi, o, cond=M_raw)
    daM = abs(a_t - a_r)
    return daM, (daM > TAU_MAP and loc_residual(o) < TAU_LOC)

# IP-269 逃生证书：没有回头路就不拿 resolution bonus
def escape_certificate(route, mapM, S_safe):
    ret = find_retreat(route.prefix, mapM.trusted, S_safe)
    if ret is None: return False, 0.0
    R = retreat_feasibility_prob(route, ret)
    ok = (ret.time <= TAU_RET and ret.energy <= E_RET
          and ret.risk <= EPS_RET and R >= R_MIN)
    return ok, R

# IP-273 最小信号动作掩蔽：任务等价集内选泄漏最小者
def mask_action(equivalents, private_state):
    return min(equivalents, key=lambda a: leakage_estimate(a, private_state))

# IP-276 主闭环（继承 R69，在不确定性处置处插入 COMPASS 层）
def COMPASS_round(M, obs, b_theta, mapM):
    U_ale, U_epi, modes, _ = M.fluid_layer(obs)           # R69 快环
    U_strat = M.otm.entropy_or_radius(b_theta)
    U_map   = M.mpm.untrusted_mass(mapM)
    if M.otm.coadapt() > TAU_C:                           # 对手在适应我们
        M.mode = 'robust'; U_strat = max(U_strat, TAU_STRAT)
    # 证言第二意见：地图被污染/过期？
    daM, map_suspect = M.mfma.map_fma(M.fmp, M.last_action, obs, mapM)
    # 战略交互：只有不被听见的查询才值得问
    g = None
    if U_epi > TAU_EPI and not map_suspect and M.mode != 'robust':
        g = M.svoi.choose(modes, b_theta, mapM, obs, M.budget, M.leak_budget)
    if g is not None:
        U_epi = M.pwe.update(modes, M.cia.execute(g))     # 证言加权 + k_eff>=2
    # 承诺：先看有没有逃生路线
    route = M.ach.propose_route(modes, mapM)              # 同伦类 + 截止期
    ok, R = M.rcc.escape_certificate(route, mapM, M.safe_set)
    U_eff = U_ale + (U_epi if g is None else 0) + U_strat + U_map
    if not ok: U_eff += (1.0 - R) * U_epi                 # 单向门：歧义升格为噪声
    lam = max(M.efs.risk_scale(...), lam_floor(U_eff))
    k = M.c_ras_wm.certified_prefix(route, ..., wm_preds)
    if map_suspect or U_map > TAU_MAP:                    # 只信本地感知
        k = min(k, k_local_only(route)); lam = max(lam, LAM_LOCAL)
    if M.mode == 'robust': lam = max(lam, LAM_ROBUST)
    tau = M.pi_sigma.prefix_dispatch(route.a[:k]) * lam
    M.tce.submit_async(J_COMPASS(...), replay=True)       # 可回放证书
    return k, lam, route, (U_ale, U_epi, U_strat, U_map)

## 3. 推导

**引理 19（信号税）** 设信息动作 g 的观测 y 与私有状态 z 条件相关，则泄漏 ℓ(g)=I(g;z|o^opp) ≥ 0；若对手把观测转为相对优势的速率为 κ_o，则 SVoI(g) ≤ VoI(g) − κ_ℓℓ(g)。故存在阈值 ℓ*，使「信息上正、战略上负」的查询严格劣于被动观测。系：**R69 的 VoI 是 κ_ℓ=κ_o=0 的边界；在竞速中「多问不如少动」可以是最优而非保守。**

**引理 20（证言的安全单调性）** 若安全认证只用 trust ≥ τ_map 的瓦片，且每个承诺前缀都有逃生证书，则把真实地图替换为任意污染地图，不会扩大可认证动作集：污染只能缩小可行集、触发本地感知退避，不能在证书有效的前提下制造新的不安全动作。系：**地图投毒可以让系统输，但不能让系统在证书意义上不安全**——性能与安全被 provenance 层解耦。

**引理 21（不可逆性升格）** 对可逆性 R 的路线，未消解 epistemic 的有效风险贡献 ≥ (1−R)·U_epi；当 R=0 时必须完全按 aleatoric 处理。故 resolution bonus 的门槛应随 (1−R) 单调收紧。系：**「待会儿再问」不是退路；单向门把认识论不确定性变成物理风险。**

**定理 18（COMPASS 严格包含 R69）** 在无对手（U_strat=0）、可信地图（U_map=0）、全可逆（R=1）、零泄漏（ℓ=0）的退化设置下，SVoI≡VoI、COMPASS 与 FLUID-RAS 逐指令相同；一般设置下，COMPASS 的安全侧（最坏类型、污染地图、不可逆前缀）不弱于 R69，新增的战略/证言退避只收紧不放松。故 R69 是四维超立方体的一个顶点。

**定理 19（风险约束锦标赛遗憾）** 设 held-out 竞技场/对手分布与训练分布 D 的 W_1 距离 ≤ W、策略类 Lipschitz 常数为 L_p，则 E_D[Regret] ≤ O(L_p·W) + (安全预算 ε 的边际代价) + 估计误差。且任何通过违反 CVaR 或规则约束获得的分数提升都被 J_COMPASS 判为无效。系：**分数不能购买安全；泛化差距被显式计入后悔，而不是被排行榜掩盖。**

**定理 20（非剥削安全与无突变）** 对任意 θ ∈ Θ，COMPASS 的最坏安全违约 ≤ ε（安全集只依赖可信地图、逃生证书与本地退避）；策略层变化只影响认证集内的路线选择；共适应/投毒/裁判偏置触发时 λ 单调不降地退化为 R69+本地感知；提交/换装不变式保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：最大的风险不是对手更强，而是 COMPASS 把对手建模成一个可被自己稳定估计的对象，而对手正在根据 COMPASS 的每一次探询反过来塑形这个估计——于是「降低不确定性」的动作变成对手的免费梯度；系统可能同时做到安全、合规、可审计，却在战略上被完全支配（安全地输掉），或者因过度怕泄漏而退化成「从不提问、也从不探索」的保守瘫痪。

**次级风险与缓解**：
1. **泄漏估计本身不可信**（ℓ 是互信息的估计）→ 用保守上界 + 预算硬上限 + 只在低泄漏候选里决策；
2. **地图证言层被绕过**（紧急情况直接信原始图）→ 定义 317 的信任门 + 逃生证书，紧急路径也必须本地可验证；
3. **裁判/记分被腐蚀** → 证书可独立回放，裁判只作证据（定义 323、定理 20）；
4. **共适应导致策略过拟合单一对手** → held-out 对手池 + minimax 窗口 + E309；
5. **过度安全导致永远不进攻** → 只在「合法且可逆」集合内给安全进攻性，用 E303/E308 监控性能-安全 Pareto。

归根结底：**在一个会观察你的世界里，最大的风险是你以为自己在测量世界，其实世界也在测量你。**

# IP-266 战略信息价值：信息增益先扣泄漏与对手获益
def choose_info_action(modes, b_theta, mapM, o, budget, leak_budget):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g): continue
        if not c_ras_wm.certify_info(g, o): continue      # 信息动作也过安全认证
        if not rules.compliant(g): continue               # 安全 != 合法
        ig   = info_gain(modes, g)                        # R69 的 VoI
        leak = leakage_estimate(g, private_state(o))      # I(g; z_priv | o_opp)
        adv  = expected_opp_advantage(b_theta, g)         # 对手据此的相对优势
        s    = ig - KAPPA_L * leak - KAPPA_O * adv - cost(g)
        if best is None or s > best.s: best = (g, s, leak)
    if best is None or best.s <= 0: return None           # 最小信号被动（R69 边界）
    if best.leak > leak_budget.remaining: return None
    return best.g

# IP-268 地图条件流似然：防「证言吸收」
def map_fma(policy, xi, o, M_trusted, M_raw):
    a_t = -policy.log_likelihood(xi, o, cond=M_trusted)
    a_r = -policy.log_likelihood(xi, o, cond=M_raw)
    daM = abs(a_t - a_r)
    return daM, (daM > TAU_MAP and loc_residual(o) < TAU_LOC)

# IP-269 逃生证书：没有回头路就不拿 resolution bonus
def escape_certificate(route, mapM, S_safe):
    ret = find_retreat(route.prefix, mapM.trusted, S_safe)
    if ret is None: return False, 0.0
    R = retreat_feasibility_prob(route, ret)
    ok = (ret.time <= TAU_RET and ret.energy <= E_RET
          and ret.risk <= EPS_RET and R >= R_MIN)
    return ok, R

# IP-273 最小信号动作掩蔽
def mask_action(equivalents, private_state):
    return min(equivalents, key=lambda a: leakage_estimate(a, private_state))

# IP-276 主闭环（继承 R69，在不确定性处置处插入 COMPASS 层）
def COMPASS_round(M, obs, b_theta, mapM):
    U_ale, U_epi, modes, _ = M.fluid_layer(obs)           # R69 快环
    U_strat = M.otm.entropy_or_radius(b_theta)
    U_map   = M.mpm.untrusted_mass(mapM)
    if M.otm.coadapt() > TAU_C:                           # 对手在适应我们
        M.mode = 'robust'; U_strat = max(U_strat, TAU_STRAT)
    daM, map_suspect = M.mfma.map_fma(M.fmp, M.last_action, obs, mapM)
    g = None
    if U_epi > TAU_EPI and not map_suspect and M.mode != 'robust':
        g = M.svoi.choose(modes, b_theta, mapM, obs, M.budget, M.leak_budget)
    if g is not None:
        U_epi = M.pwe.update(modes, M.cia.execute(g))     # 证言加权 + k_eff>=2
    route = M.ach.propose_route(modes, mapM)              # 同伦类 + 截止期
    ok, R = M.rcc.escape_certificate(route, mapM, M.safe_set)
    U_eff = U_ale + (U_epi if g is None else 0) + U_strat + U_map
    if not ok: U_eff += (1.0 - R) * U_epi                 # 单向门：歧义升格为噪声
    lam = max(M.efs.risk_scale(...), lam_floor(U_eff))
    k = M.c_ras_wm.certified_prefix(route, ..., wm_preds)
    if map_suspect or U_map > TAU_MAP:                    # 只信本地感知
        k = min(k, k_local_only(route)); lam = max(lam, LAM_LOCAL)
    if M.mode == 'robust': lam = max(lam, LAM_ROBUST)
    tau = M.pi_sigma.prefix_dispatch(route.a[:k]) * lam
    M.tce.submit_async(J_COMPASS(...), replay=True)       # 可回放证书
    return k, lam, route, (U_ale, U_epi, U_strat, U_map)

## 4. 推导

**引理 19（信号税）** 设信息动作 g 的观测 y 与私有状态 z 条件相关，则 ℓ(g)=I(g;z|o^opp) ≥ 0；若对手把观测转为相对优势的速率为 κ_o，则 `SVoI(g) ≤ VoI(g) − κ_ℓℓ(g)`。故存在阈值 ℓ*，使「信息上正、战略上负」的查询严格劣于被动观测。系：R69 的 VoI 是 κ_ℓ=κ_o=0 的边界；竞速中「多问不如少动」可以是最优而非保守。

**引理 20（证言的安全单调性）** 若安全认证只用 trust ≥ τ_map 的瓦片且每个承诺前缀都有逃生证书，则把真实地图替换为任意污染地图不扩大可认证动作集：污染只能缩小可行集、触发本地感知退避，不能在证书有效时制造新的不安全动作。系：地图投毒可以让系统输，但不能让系统在证书意义上不安全。

**引理 21（不可逆性升格）** 对可逆性 R 的路线，未消解 epistemic 的有效风险贡献 ≥ (1−R)·U_epi；R=0 时必须完全按 aleatoric 处理。故 resolution bonus 门槛随 (1−R) 单调收紧。系：「待会儿再问」不是退路；单向门把认识论不确定性变成物理风险。

**定理 18（COMPASS 严格包含 R69）** 无对手（U_strat=0）、可信地图（U_map=0）、全可逆（R=1）、零泄漏（ℓ=0）时，SVoI≡VoI、COMPASS 与 FLUID-RAS 逐指令相同；一般设置下安全侧不弱于 R69，新增退避只收紧不放松。

**定理 19（风险约束锦标赛遗憾）** 设 held-out 分布与训练分布 W_1 距离 ≤ W、策略类 Lipschitz 常数 L_p，则 `E_D[Regret] ≤ O(L_p·W) + 安全预算边际代价 + 估计误差`；任何靠违反 CVaR/规则获得的分数提升被 J_COMPASS 判无效。系：分数不能购买安全，泛化差距被显式计入后悔。

**定理 20（非剥削安全与无突变）** 对任意 θ，最坏安全违约 ≤ ε（安全集只依赖可信地图、逃生证书、本地退避）；策略层只改认证集内的路线选择；共适应/投毒/裁判偏置触发时 λ 单调不降地退化为 R69+本地感知；提交/换装不变式保持 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：最大的风险不是对手更强，而是 COMPASS 把对手建模成一个可被自己稳定估计的对象，而对手正在根据 COMPASS 的每一次探询反过来塑形这个估计——于是「降低不确定性」的动作变成对手的免费梯度；系统可能同时做到安全、合规、可审计，却在战略上被完全支配（安全地输掉），或者因过度怕泄漏而退化成「从不提问、也从不探索」的保守瘫痪。

**次级风险与缓解**：泄漏估计不可信（保守上界 + 预算硬上限）；地图证言层被紧急路径绕过（信任门 + 逃生证书 + 本地可验证）；裁判/记分被腐蚀（可回放证书，裁判只作证据）；共适应过拟合单一对手（held-out 对手池 + minimax 窗口 + E309）；过度安全导致永不进攻（只在合法且可逆集合内给安全进攻性，E303/E308 监控 Pareto）。

归根结底：**在一个会观察你的世界里，最大的风险是你以为自己在测量世界，其实世界也在测量你。**
