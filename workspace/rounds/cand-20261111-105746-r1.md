# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「预训练」×「热管理」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S`、组合图 `G_S` 与云边联合证书 `J`。本轮引入两个过去被当作"外部条件"的变量：**预训练**（能力的离线先验）与**热管理**（边端执行的热预算）。核心矛盾：H22：预训练带来的通用先验在热分布漂移下会"能力尚在、证书失效"——标称温度下验证的 `ρ` 与 `α` 在结温升高、频率下调后不再成立；H23：热管理不是硬件附属问题，而是与计算频率、动作占空比、技能组合序强耦合的**资源约束**，会把第 54 轮的动作空间可行性进一步收缩为"热可行动作空间"。

## 0. 直觉与动机

**灵感 1（热流形预训练 → 把热管理从在线试错变成离线先验）**
直觉：结温 `T_j`、环境温度 `T_a`、功率 `P`、计算频率 `f`、动作占空比 `u` 的耦合是高维但**低秩、慢变**的：热响应由少数时间常数与热阻/热容决定。这正适合用自监督预训练学习一个**热流形** `φ_T : 热轨迹 → z_T` 与潜空间动力学 `g_T: (z_T, a) → z_T'`。预训练之后，新机器人的热标定不再是"从零拟合 RC 参数"，而是"在热流形上做少量后验校准"。**预训练的第一价值是压缩热辨识的样本复杂度，而不是直接提升任务成功率。**

**灵感 2（热条件化动作剖面 → `α_S` 不是静态的）**
直觉：第 54 轮的 `α_S(a)` 隐含"标称热状态"。真实边端上，同一动作在冷机时可行、在结温逼近上限时可能因降频/降额而不可行。因此应写成 `α_S(a|τ)`，并定义**热可行动作集** `A_S(τ) = {a | α_S(a|τ) ≥ θ_cov ∧ T_peak(a,τ) ≤ T_max - m}`。这把热从"运行监控"提升为动作空间的第一性约束：技能组合先问"在这个热状态下还能不能做"，再问"动作兼不兼容"。

**灵感 3（热组合图 → 累积热量是可加资源，冷却是重置）**
直觉：技能组合不仅要满足动作兼容 `compat` 与转换延迟 `c_trans`，还要满足一个**热预算**：路径上累积热量 `ΣΔH` 不能超过冷却能力允许的上限，且路径中途可以插入"冷却动作"（dwell / 降频 / 自然散热）作为资源重置。于是 `G_S` 升级为**热组合图** `G_S^th`：边带热量成本与峰值结温，节点带待机发热与冷却速率。组合规划变成**资源约束最短路**（RCSP），并要显式识别**热死胡同**（提前耗尽预算、后续无冷却机会的路径）。

**灵感 4（云边热契约 → 云端管长程预算，边端管实时回退）**
直觉：云端适合做**长程热预算分配**（整个任务的总热量、允许的降频窗口、冷却排程），边端适合做**实时热反馈**（MPC/DVFS、占空比、动作级回退）。契约 `C_th = (T_max, P_budget, δ_T, t_cool)`：云端承诺峰值结温不越过 `T_max - m`，边端保证在 `δ_T` 裕度内执行；若预测越界，边端触发冷却或请求云端**重剖分/重排程** `reprofile_th`。这形成"云分配 - 边控温 - 越界回传 - 重排程"的热闭环，与第 54 轮的动作-解释闭环同构。

**灵感 5（预训练的热迁移证书 → 把"省样本"变成可检验的界）**
直觉：预训练到底值不值？不能只说"效果更好"，而要给一个**热迁移证书** `TTC = (R_S, d_HΔ, λ*, n_req)`：目标热分布上的风险 `R_T` 被源域风险、热域间散度、理想联合风险与有限样本项共同上界。预训练通过 `φ_T` 对齐热潜空间降低 `d_HΔ` 与 `λ*`，从而降低达到同一热证书精度所需的真机热样本数 `n_req`。**如果 `n_req` 不比从零训练少，预训练在热维度上就是负价值**——这给"预训练是否值得"提供了可证伪判据。附带的工程洞见：边端后训练/微调本身也发热，因此适配窗口必须与冷却窗口联合排程。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（热状态与热流形）**
热状态 `τ = (T_j, T_a, P, f, u)`：结温、环境温度、功率、计算频率、动作占空比。一阶热模型：
```
C_th · dT_j/dt = P - (T_j - T_a)/R_th,   P = P_comp(f) + P_act(u)
```
预训练得到热编码器 `φ_T: 热轨迹 → z_T ∈ ℝ^{d_T}` 与潜动力学 `g_T: (z_T,a) → z_T'`。**热流形** `ℳ_T = φ_T(𝒯)`，其内在维度 `d_T ≪ dim(τ)`。

**定义 122（热条件化动作剖面与热可行集）**
`α_S: A × 𝒯 → [0,1]`，`α_S(a|τ)` 为热状态 `τ` 下动作 `a` 的可执行置信度。热可行动作集：
```
A_S(τ) = { a ∈ A | α_S(a|τ) ≥ θ_cov ∧ T_peak(a,τ) ≤ T_max - m }
```
热覆盖 `cover_th(S, A_T, τ) = 1` 当且仅当 `∀a∈A_T, a∈A_S(τ)`。

**定义 123（热鲁棒性谱）**
在 `ρ_S(d)` 上增加热维度 `d_T = max_t T_j(t)/T_max` 与热安全概率：
```
ρ_{S,T} = Pr[ max_t T_j(t) ≤ T_max - m | τ_0, plan_S ] ≥ 1 - α_th
```
组合谱在热维度上不取 `min` 而取**预算卷积**：`ρ_{S1⊗S2}(d_T) = ρ_{S1}(d_T) ⊛ ρ_{S2}(d_T)`，因为热量是累积的，不是取最坏值。

**定义 124（热组合图与热死胡同）**
`G_S^th = (V,E, h, c)`：节点 `v` 带待机发热 `h_v` 与冷却率 `c_v`；边 `(i,j)` 带热量成本 `ΔH_ij`、峰值 `T_peak,ij`。路径 `π` 热可行当且仅当：
```
Σ_{(i,j)∈π} ΔH_ij − Σ_{v∈π} c_v·t_dwell(v) ≤ H_budget
∧ max_{(i,j)∈π} T_peak,ij ≤ T_max - m
```
**热死胡同**：存在前缀 `π'⊂π` 使剩余热量预算不足以完成 `π\π'` 且无可插入冷却节点。

**定义 125（热迁移证书）**
源热域 `D_S`、目标热域 `D_T`，假设空间 `ℋ`。以至少 `1-δ` 概率：
```
R_T(h) ≤ R_S(h) + ½ d_HΔ(D_S,D_T) + λ* + √(log(2/δ)/(2n_s)) + √(log(2/δ)/(2n_t))
```
预训练通过 `φ_T` 最小化 `d_HΔ` 与 `λ*`。证书 `TTC = (R_S, d_HΔ, λ*, n_req)`，其中 `n_req` 为达到目标精度所需真机热样本数。

**定义 126（云边热契约）**
`C_th = (T_max, m, P_budget, δ_T, t_cool, reprofile_th)`：
- `T_max` 硬件结温上限，`m` 安全护栏；
- `P_budget` 长程功率预算，`t_cool` 允许冷却窗口；
- `δ_T` 热裕度容差；
- `reprofile_th: Explain_th → ΔP_c^th` 越界后的重排程通道。

**定义 127（热联合证书）**
`J_T = (J, z_T, τ_trace, δ_T, p_th, evidence)`：在 `J=(ρ,A_cert,γ_ce,δ_a)` 上增加热流形潜变量 `z_T`、热轨迹 `τ_trace`、热裕度 `δ_T`、热违背上界 `p_th`。若 `dom_J(T)=in`、`δ_a<Θ_a` 且 `δ_T<Θ_T ∧ p_th ≤ p_th^*`，则组合可部署。

## 2. 关键算法 伪代码

### IP-121 TMP（Thermal Manifold Pretraining）

```python
def pretrain_thermal_manifold(D_pre, encoder, dyn, physics, epochs):
    # D_pre: 多机器人/多负载/多环境的 (o_t, a_t, tau_t, tau_{t+1})
    for batch in D_pre:
        z      = encoder(batch.o, batch.tau)          # 热流形潜变量
        z_next = encoder(batch.o_next, batch.tau_next)
        tau_hat = dyn(z, batch.action)                 # 潜空间热动力学
        loss = mse(tau_hat, batch.tau_next) \
             + mse(z_next, dyn(z, batch.action)) \
             + contrastive(z, batch.robot_id, batch.load_profile) \
             + physics_penalty(tau_hat, RC_model(batch))
        update(loss)
    return encoder, dyn
```

### IP-122 TCP（Thermal-Conditioned Profiling）

```python
def thermal_profile(skill, A_c, A_e, tau_grid, sampler, calib):
    alpha = {}
    for tau in tau_grid:
        for a_c in A_c:
            for a_e in A_e:
                feas, conf = sampler.query(skill, a_c, a_e, tau)
                alpha[(a_c,a_e,tau)] = conf if feas else 0.0
    q = conformal_quantile(calib.residuals, alpha=0.1)   # 覆盖校准
    return ThermalAlpha(alpha, q)

def thermal_cover(alpha, A_T, tau, theta_cov=0.8):
    return all(alpha[(a, tau)] - alpha.q >= theta_cov for a in A_T)
```

### IP-123 THG（Thermal Heat Graph）

```python
def build_heat_graph(skills, theta_a, tau_e, thermal_model, T_max, m):
    G = nx.DiGraph()
    for i, s in enumerate(skills):
        G.add_node(i, h=s.standby_heat, c=s.cooling_rate, tau_range=s.tau_range)
        for j, s2 in enumerate(skills):
            if i == j: continue
            if jaccard(s.alpha, s2.alpha) < theta_a: continue
            if transition_cost(s, s2) > tau_e: continue
            dH, T_peak = thermal_model.transition(s, s2)
            feasible = (T_peak <= T_max - m)
            G.add_edge(i, j, compat=..., heat=dH, T_peak=T_peak, feasible=feasible)
    return G

def thermal_path(G, A_T, H_budget, T_max, m):
    # 资源约束最短路：label = (node, cum_heat, peak_T, cost)
    # 支配关系：(heat <=, peak_T <=, cost <=) 至少一项严格
    return label_setting_search(G, A_T, H_budget, T_max - m)
```

### IP-124 TCC（Thermal Cloud-Edge Contract）

```python
def cloud_thermal_plan(T_desc, G, H_budget, P_budget, t_cool):
    path, cert = thermal_path(G, T_desc, H_budget, T_max, m)
    if path is None:
        return ('reject', 'thermal_dead_end')
    slots = allocate_cooling(path, t_cool)          # 插入冷却/降频窗口
    return ('ok', ThermalPlan(path, slots, H_budget, P_budget))

def edge_thermal_refine(plan, dyn, tau0, T_max, m, dt):
    trace, tau = [], tau0
    for slot in plan.slots:
        f = thermal_mpc(dyn, tau, slot.H_budget, slot.P_budget)   # DVFS + 占空比
        T_next = predict(dyn, tau, f, slot, dt)
        if T_next > T_max - m - guard:
            if not insert_cooldown(slot):
                return ('reject', 'thermal_margin', explain_th(tau, slot))
            continue
        execute(slot, f); trace.append(tau); tau = T_next
    return ('ok', trace)
```

### IP-125 TTC（Thermal Transfer Certificate）

```python
def thermal_transfer_certificate(src, tgt, encoder, n_s, n_t, delta, risk_budget):
    dH  = domain_divergence(src.features(encoder), tgt.features(encoder))
    lam = ideal_joint_risk(src, tgt, encoder)
    bound = (src.risk + 0.5*dH + lam
             + sqrt(log(2/delta)/(2*n_s))
             + sqrt(log(2/delta)/(2*n_t)))
    if bound > risk_budget:
        return ('reject', 'thermal_transfer_risk', bound)
    return ('ok', TTC(bound, dH, lam, n_req(bound, risk_budget)))
```

### IP-126 JTC-T（Joint Thermal Certificate）

```python
def joint_thermal_certificate(skill_seq, gamma_ce, delta_a_budget, plan,
                              alpha_T, rho_min, p_th_budget):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if J[0] != 'ok':
        return J
    tau_trace = rollout_thermal(plan, skill_seq, alpha_T)
    p_th = conformal_violation(tau_trace, alpha_T.q) + transfer_gap(plan)
    if max(tau_trace.T) > T_max - m or p_th > p_th_budget:
        return ('reject', 'thermal_fail', max(tau_trace.T), p_th)
    return ('ok', JointThermalCert(J[1], tau_trace, p_th, alpha_T.q))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| TMP | O(E·|D|·d_T) | O(|φ_T|+|g_T|) | 物理一致性惩罚、热流形低秩 |
| TCP | O(|A_c|·|A_e|·|𝒯|) | O(|A|·|𝒯|) | conformal 覆盖、热状态网格完备 |
| THG | O(|S|²·|A| + |V|·|E|·log|V|) | O(|V|·|E|) | 热量可加、支配关系 sound |
| TCC | O(|π|·|slots|·T_mpc) | O(|π|) | MPC 递推可行、冷却重置合法 |
| TTC | O(n_s+n_t) | O(d_T) | 域散度估计、界非空 |
| JTC-T | O(|S|·|A| + |π|·H) | O(|A|+|π|) | 热预算闭合、联合证书 sound |

**命题 1（热迁移界）** 设 `φ_T` 由 IP-121 预训练、`n_s,n_t` 为源/目标热样本数，则定义 125 的界以 `1-δ` 成立；预训练降低 `d_HΔ` 与 `λ*`，从而降低 `n_req`。若 `n_req(φ_T) ≥ n_req(scratch)`，判定预训练在热维度上负价值。

**命题 2（资源约束路径的判定性）** 当热量严格可加、冷却为节点重置时，IP-123 的 label-setting 在支配剪枝下给出精确最优；若冷却与动作耦合导致非可加（如动作同时产热与改变冷却系数），问题归约为 RCSP/背包，判定 NP-hard，仅能给出拉格朗日下界与次优间隙证书。

**正确性定理（Thermal-Aware Cloud-Edge Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** `α_S(a|τ)` 经 conformal 校准，热覆盖误判率 ≤ `α_cal`；**(A30)** 热流形 `φ_T` 的迁移界成立；**(A31)** 边端 MPC 在 `δ_T` 裕度内可行。则
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(δ_a>Θ_a) − p_th
p_th ≤ α_cal + [R_T(h) − R_S(h) − ½d_HΔ − λ*]_+ + P(δ_T>Θ_T)
```
即：**热违背概率可由"校准误判 + 预训练迁移缺口 + 云边裕度超限"三部分显式扣除**，而不是笼统归入"环境噪声"。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 合成/实验室热数据与真机热域差距大 | 高 | 硬件在环 + 域随机化 + TTC 显式量化缺口 |
| 热不可逆，一次越界即硬件损伤 | 高 | 硬护栏 + 硬件级限温 + 冷却回退 + 保守 `m` |
| 热流形在老化/堵转/环境突变下漂移 | 高 | 在线热辨识 + 漂移检测 + 定期重校准 |
| RCSP 热组合规模爆炸/非可加 | 中 | 支配剪枝 + 分层抽象 + 拉格朗日下界证书 |
| 边端后训练自身发热挤占任务预算 | 中 | 适配窗口与冷却窗口联合排程 |
| Explain 热回传与动作回传互相震荡 | 中 | 双时间尺度（热慢环/动作快环）+ hysteresis |

## 6. 本轮最大风险

**一句话**：预训练把热管理从在线试错变成离线先验、热管理把预训练从静态能力变成受预算约束的动态证书，这条"热流形 + 热组合图 + 热联合证书"的链条看起来自洽，但其 soundness 同时依赖**热流形在真机上的迁移界不被打破、热动力学在老化/堵转/环境突变下保持准平稳、以及热越界前的回退永远来得及**；一旦热流形在训练分布外自信外推、或热截止时间短于回退延迟，整套热证书会在真实硬件上系统性失效且后果不可逆，故必须以**硬件级限温硬护栏 + 在线热漂移检测 + 保守热裕度 + 宁可降级不可越界**为不可协商的前置条件。

> - **TCC（Thermal Cloud-Edge Contract）**：云端长程热预算 ↔ 边端 MPC 实时控温；
> - **TTC（Thermal Transfer Certificate）**：量化"预训练省多少热样本"的可证伪迁移界；
> - **JTC-T（Joint Thermal Certificate）**：动作-鲁棒性-热三轴联合证书。
>
> IP 编号：IP-121~IP-127（共 7 个新增），升级 IP-115/116/118/120 以纳入热维度。

## 2. 关键算法 伪代码

### IP-121 TMP

```python
def pretrain_thermal_manifold(D_pre, encoder, dyn, physics, epochs):
    # D_pre: 多机器人/多负载/多环境的 (o_t, a_t, tau_t, tau_{t+1})
    for batch in D_pre:
        z       = encoder(batch.o, batch.tau)
        z_next  = encoder(batch.o_next, batch.tau_next)
        tau_hat = dyn(z, batch.action)
        loss = mse(tau_hat, batch.tau_next) \
             + mse(z_next, dyn(z, batch.action)) \
             + contrastive(z, batch.robot_id, batch.load_profile) \
             + physics_penalty(tau_hat, RC_model(batch))
        update(loss)
    return encoder, dyn
```

### IP-122 TCP

```python
def thermal_profile(skill, A_c, A_e, tau_grid, sampler, calib):
    alpha = {}
    for tau in tau_grid:
        for a_c in A_c:
            for a_e in A_e:
                feas, conf = sampler.query(skill, a_c, a_e, tau)
                alpha[(a_c,a_e,tau)] = conf if feas else 0.0
    q = conformal_quantile(calib.residuals, alpha=0.1)
    return ThermalAlpha(alpha, q)

def thermal_cover(alpha, A_T, tau, theta_cov=0.8):
    return all(alpha[(a, tau)] - alpha.q >= theta_cov for a in A_T)
```

### IP-123 THG + IP-127 THD

```python
def build_heat_graph(skills, theta_a, tau_e, thermal_model, T_max, m):
    G = nx.DiGraph()
    for i, s in enumerate(skills):
        G.add_node(i, h=s.standby_heat, c=s.cooling_rate, tau_range=s.tau_range)
        for j, s2 in enumerate(skills):
            if i == j: continue
            if jaccard(s.alpha, s2.alpha) < theta_a: continue
            if transition_cost(s, s2) > tau_e: continue
            dH, T_peak = thermal_model.transition(s, s2)
            G.add_edge(i, j, compat=..., heat=dH,
                       T_peak=T_peak, feasible=(T_peak <= T_max - m))
    return G

def thermal_path(G, A_T, H_budget, T_max, m):
    # label = (node, cum_heat, peak_T, cost)
    # 支配：(heat<=, peak_T<=, cost<=) 至少一项严格
    return label_setting_search(G, A_T, H_budget, T_max - m)

def detect_thermal_dead_end(path_prefix, remaining_tasks, G, H_left, T_left, cool_nodes):
    need = min_heat_to_cover(G, remaining_tasks)
    reachable_cool = any(n in cool_nodes for n in future_frontier(path_prefix, remaining_tasks))
    return (H_left < need) and not reachable_cool   # 判定为热死胡同
```

### IP-124 TCC

```python
def cloud_thermal_plan(T_desc, G, H_budget, P_budget, t_cool):
    path, cert = thermal_path(G, T_desc, H_budget, T_max, m)
    if path is None:
        return ('reject', 'thermal_dead_end')
    slots = allocate_cooling(path, t_cool)
    return ('ok', ThermalPlan(path, slots, H_budget, P_budget))

def edge_thermal_refine(plan, dyn, tau0, T_max, m, dt):
    trace, tau = [], tau0
    for slot in plan.slots:
        f = thermal_mpc(dyn, tau, slot.H_budget, slot.P_budget)
        T_next = predict(dyn, tau, f, slot, dt)
        if T_next > T_max - m - guard:
            if not insert_cooldown(slot):
                return ('reject', 'thermal_margin', explain_th(tau, slot))
            continue
        execute(slot, f); trace.append(tau); tau = T_next
    return ('ok', trace)
```

### IP-125 TTC

```python
def thermal_transfer_certificate(src, tgt, encoder, n_s, n_t, delta, risk_budget):
    dH  = domain_divergence(src.features(encoder), tgt.features(encoder))
    lam = ideal_joint_risk(src, tgt, encoder)
    bound = (src.risk + 0.5*dH + lam
             + sqrt(log(2/delta)/(2*n_s))
             + sqrt(log(2/delta)/(2*n_t)))
    if bound > risk_budget:
        return ('reject', 'thermal_transfer_risk', bound)
    return ('ok', TTC(bound, dH, lam, n_req(bound, risk_budget)))
```

### IP-126 JTC-T

```python
def joint_thermal_certificate(skill_seq, gamma_ce, delta_a_budget, plan,
                              alpha_T, rho_min, p_th_budget):
    J = joint_certificate(skill_seq, gamma_ce, delta_a_budget, rho_min)
    if J[0] != 'ok':
        return J
    tau_trace = rollout_thermal(plan, skill_seq, alpha_T)
    p_th = conformal_violation(tau_trace, alpha_T.q) + transfer_gap(plan)
    if max(tau_trace.T) > T_max - m or p_th > p_th_budget:
        return ('reject', 'thermal_fail', max(tau_trace.T), p_th)
    return ('ok', JointThermalCert(J[1], tau_trace, p_th, alpha_T.q))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TMP | O(E·|D|·d_T) | O(|φ_T|+|g_T|) | 物理一致性惩罚、热流形低秩 |
| TCP | O(|A_c|·|A_e|·|𝒯|) | O(|A|·|𝒯|) | conformal 覆盖、热网格完备 |
| THG | O(|S|²·|A| + |V|·|E|·log|V|) | O(|V|·|E|) | 热量可加、支配剪枝 sound |
| TCC | O(|π|·|slots|·T_mpc) | O(|π|) | MPC 递推可行、冷却重置合法 |
| TTC | O(n_s+n_t) | O(d_T) | 域散度估计、界非空 |
| JTC-T | O(|S|·|A| + |π|·H) | O(|A|+|π|) | 热预算闭合、联合证书 sound |

**命题 1（热迁移界）** 定义 125 的界以 `1-δ` 成立；预训练通过 `φ_T` 降低 `d_HΔ` 与 `λ*`，从而降低 `n_req`。若 `n_req(φ_T) ≥ n_req(scratch)`，判预训练在热维度负价值（可证伪）。

**命题 2（RCSP 判定性）** 热量严格可加且冷却为节点重置时，label-setting 给出精确最优；若冷却与动作耦合破坏可加性，问题归约 RCSP/背包，判定 NP-hard，仅给拉格朗日下界与次优间隙证书。

**正确性定理（Thermal-Aware Cloud-Edge Composition Soundness）**
承接第 54 轮 (A26)–(A28)；新增 **(A29)** `α_S(a|τ)` conformal 校准，热覆盖误判率 ≤ `α_cal`；**(A30)** 热流形迁移界成立；**(A31)** 边端 MPC 在 `δ_T` 裕度内可行。则
```
P_success ≥ 1 − Σ_d(1−ρ_min(d)) − β_E − P(δ_a>Θ_a) − p_th
p_th ≤ α_cal + [R_T(h) − R_S(h) − ½d_HΔ − λ*]_+ + P(δ_T>Θ_T)
```
**关键**：热违背概率不再被塞进"环境噪声"，而是拆成"校准误判 + 预训练迁移缺口 + 云边裕度超限"三个可审计项。

## 4. 推导：为什么预训练对热管理是"省样本"而不是"免样本"

设源热域与目标热域的经验风险分别为 `R_S,R_T`，热编码器 `φ_T` 诱导的特征域散度为 `d_HΔ`。由标准 domain adaptation 界（Ben-David 型）加两侧有限样本项得定义 125。要点：

1. **预训练只压 `d_HΔ` 与 `λ*`，不压 `n_t` 项**。因此目标域真机热样本永远有下界 `n_req ∝ log(2/δ)/(risk_budget)^2`，预训练不能把 `n_t→0`。
2. **热维度的 `d_HΔ` 主要来自负载/环境/老化，而非视觉外观**。所以热预训练必须是"多负载 + 多环境 + 多老化阶段"的，否则 `φ_T` 对齐的是错误的不变量。
3. **可证伪判据**：若在目标机器人上 `n_req(φ_T) ≥ n_req(scratch)`，说明预训练学到的热流形与目标热域不匹配，应拒绝该先验，而不是继续微调。
4. **热与动作的耦合项**：`p_th` 中的 conformal 项随热状态网格密度下降而收紧，但网格越密，`TCP` 采样成本 `O(|A|·|𝒯|)` 越高，形成"证书紧度 ↔ 采样成本"的权衡。

## 7. 本轮最大风险

**一句话**：预训练把热管理从在线试错变成离线先验、热管理把预训练从静态能力变成受预算约束的动态证书，这条"热流形 + 热组合图 + 热联合证书"的链条看起来自洽，但其 soundness 同时依赖**热流形在真机上的迁移界不被打破、热动力学在老化/堵转/环境突变下保持准平稳、以及热越界前的回退永远来得及**；一旦热流形在训练分布外自信外推、或热截止时间短于回退延迟，整套热证书会在真实硬件上系统性失效且后果不可逆，故必须以**硬件级限温硬护栏 + 在线热漂移检测 + 保守热裕度 + 宁可降级不可越界**为不可协商的前置条件。
