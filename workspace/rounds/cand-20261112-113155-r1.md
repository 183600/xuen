# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「开源硬件」×「具身智能」）

> 第 57 轮把安全赌注从"模型置信"移到"证据质量"：q_φ 从全体区域史摊销先验、证据按模态分账、操作者变成单向有界的信任状态机。但它仍默认了一个从未被检验的前提：**这些证据与先验都来自一个"名义身体"**——q_φ 的观测模型、XMC 的探针似然、FSE 的 EV-probe\* 校准，全部隐含"运动学/动力学/传感增益/固件就是设计里的那样"。本轮两个灵感从两侧拆掉这个前提：**开源硬件**让身体变成可替换、可维修、可被社区分叉的异构装配体——设计是开放的（人人可验），但**每一个具体实例不是**（供应链、装配、磨损、固件都可能偏离设计）；**具身智能**指出身体本身就是控制器的一部分（形态计算、本体感受、感觉运动偶发），身体参数一旦漂移，感知与动作的保证同时失效。核心命题升级为：**安全承诺必须绑定到"被验证过的身体实例"；设计证书不能转移为实例证书；具身系统的自证不能作为最终保底**。

核心矛盾：
- **H29（开放设计 vs 封闭实例）**：开源让设计可审计、可复现、可修复，却让"设计可信"与"这台机器可信"脱钩；同一份设计文件可以装配出无数行为不同的实例，社区分叉让"标称参数"失去唯一性。设计证书越容易被信任，越容易被误当成实例证书使用。
- **H30（具身自证 vs 观察者闭环）**：具身智能依赖本体感受与自模型，但自模型的观测者就长在它要验证的身体上；被篡改或磨损的硬件可以同时伪造"健康的样子"和"健康的自检"。越依赖自检，越把安全托付给被检验对象本身。
- **H31（可维修性 vs 信任重置）**：开源硬件的最大美德是坏了能换、能修、能升级；但每次换件/刷固件都是一次静默的身体变更，既可能恢复能力，也可能引入降规件、错型号、恶意件。安全若要求"永不变更"，就放弃具身系统的韧性；若允许变更却不重置信任，就把"维修"变成后门。

## 0. 直觉与动机

**灵感 1（开源硬件 → 设计证书与实例证书分离）**
直觉：开源硬件的承诺不是"这机器一定安全"，而是"**你可以自己验证它应该是什么**"。这两句话差着一整个信任层。设计文件（原理图、BOM、机械图、固件）是**可转移**的：任何人按同一设计复现，共享同一套设计级性质（机械限位、失效模式、被动安全）。但**具体实例**是**不可转移**的：同一 BOM 也可能装出摩擦不同、增益漂移、被换成降规件的机器。于是把证书拆成两层：**设计证书 𝒟_open**（开放、可审计、可转移，证明"这类设计在哪些假设下安全"）与**实例证书 J_ℬ**（绑定 instance id，必须在本机测出来，不可转移）。设计证书只在实例**符合设计假设**时才生效；一旦实例偏离（换件、分叉、磨损出包络），𝒟_open 立即作废——不是设计错了，而是**它不再描述这台机器**。这也修补了第 57 轮元先验的一个盲点：q_φ 只在"见过的区域×同一个身体"上被摊销校准，换了身体，摊销的迁移性没有保证。

**灵感 2（具身智能 → 身体条件化定位与自模型共形带）**
直觉：具身系统的知识不是"世界是什么"，而是"**这个身体能对世界做什么**"——动作空间由形态、关节限位、柔顺性、传感增益共同定义。第 57 轮的模态信念 b_r 与元后验 q_φ(θ|o,z_r) 其实是 b_r|ξ 在 ξ=ξ_nominal 处的一个切片。把身体参数 ξ=(运动学/动力学/传感增益/柔顺/磨损) 显式化，用在线估计 + 共形带 Ξ_β 给出 P(ξ\*∈Ξ_β)≥1−β；于是安全的信念/歧义集必须**对 ξ 取鲁棒并集**：身体越不确定，后验越宽、动作越保守。关键差别：这不是又一个先验，而是把"身体"从隐含常量变成**显式的不确定性来源**——而且它是唯一一个**既影响感知又影响执行**的变量，因此它错了，校准再好也只是在错误的身体上校准。

**灵感 3（维修即重置 → 一致性探针与有界再认证）**
直觉：开源硬件给了具身系统一种软件系统没有的韧性：**坏了可以换、可以修、可以现场升级**。但每次身体变更（换关节、换末端、刷固件、换电池/传感器）都是一次**静默的信任重置**。与其禁止变更，不如把变更变成一套**有界再认证**：变更事件 Δ 触发最小一致性探针族（针对该部件类的已知失效模式），配合独立见证，把身体信任从 B0 重新挣回 B2。关键是**单向有界**：任何硬件变更只能即时降级、作废缓存承诺；升级必须"有据（一致性通过）+ 有界（探针/时间预算）+ 有独立见证"。第 57 轮 PTM 对操作者的"信任赢得慢、失去快"，本轮原样搬到硬件上。

**灵感 4（形态计算 → 不依赖自模型的机械安全地板）**
直觉：具身智能里有一类安全是"免费的"：**柔顺关节、机械限位、被动保险丝、几何自锁**——它们不需要控制器计算、不需要相信自模型、甚至在软件崩溃时仍然生效。开源硬件让这类被动安全件可被选择、替换、并**在实例上物理验证**。于是给 BEC 加一条"**形态安全地板（MSH）**"：对落在已认证机械包络内的动作，其失效率由物理结构直接兜底，不需要任何软件证据；反过来，一旦动作要越出机械包络，就必须回到完整的软件证据链。地板的意义在于：**当自模型不可信（观察者在环里）时，还有一个不依赖自证的保底**。

**灵感 5（合流 → 身体先验自由、实例必须实测、地板独立兜底）**
直觉：第 57 轮说"证据说可信"。本轮再问一句：**证据的观测者，长在谁身上？** 如果它长在被检验的身体上，观测就可能被伪造。所以合流成三层：**设计层**开放可验、提供假设与包络；**实例层**必须在本机实测（一致性/自模型/来源），且自证最高只能到 B1；**形态层**提供不依赖前两层的机械兜底。三层纵深之后，攻破单点（设计分叉、自证伪造、元先验错误）都不足以让系统"更敢赌"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（身体清单与来源证书 BMC）** 物理实例的组件清单
ℬ={c_i=(id_i,ver_i,spec_i,cal_i,att_i,env_i)}，分量覆盖关节/执行器/传感器/连杆/计算/末端/固件；ι_ℬ 为实例指纹；att_i∈{self,community,independent} 为来源证明等级。**设计证书 𝒟_open** 证明"设计在假设集 ℋ_𝒟 下具备性质集 Π_𝒟"（机械限位、失效模式、被动安全），可转移；**实例证书 J_ℬ** 证明"本实例在约束集 Φ 上符合设计包络"，绑定 ι_ℬ、不可转移。证书合成规则：𝒟_open 仅在 ℬ 的组件/参数/固件落在 ℋ_𝒟 内时对 ι_ℬ 生效；否则 𝒟_open 作废（分叉/换件）。身体信任 σ_ℬ∈{B0 未认证,B1 自检,B2 一致性,B3 独立见证}；**单向性**：任何硬件变更 Δ（换件/维修/固件/漂移告警）⇒ σ_ℬ←B0 且作废以 ι_ℬ 为键的全部承诺缓存；升级需 CRX 证据且有界速率。

**定义 140（具身自模型 SMC，升级 MFSL）** 身体参数 ξ=(θ_kin,θ_dyn,g_sens,κ_comp,w_wear)，在线估计器输出共形域 Ξ_β(r) 满足 P(ξ\*∈Ξ_β)≥1−β（按负载/温度/磨损分层）。第 57 轮 MFSL 的摊销后验推广为**身体条件化** q_φ(θ|o_{1:k},z_r,ξ) 与 b_r|ξ；**鲁棒信念与歧义集**取
b_r^{rob}=⨁_{ξ∈Ξ_β} b_r|ξ，𝒫_α^{rob}(r,e)=∪_{ξ∈Ξ_β}𝒫_α(r,e|ξ)，
安全定位/承诺 ⇔ 拟执行动作对 𝒫_α^{rob} 集合鲁棒（或动作商单点且安全）。**漂移检测**：d_ξ(Ξ_β,Ξ_β^{ref})>θ_drift ⇒ 触发 CRX 与缓存作废。**自探针** u_self∈𝒯_self（本体感受/感觉运动一致性/空载-负载对比）只产生"关于 ξ 的证据"，**不能单独把 σ_ℬ 推过 B1**（观察者闭环，A42）。

**定义 141（一致性探针与再认证 CRX）** 对变更事件 Δ，选最小探针族 Q(Δ)={q_j}⊂𝒯_allow∪𝒯_self，使
Q(Δ)=argmin_{Q} |Q| s.t. ∀φ∈Φ_Δ: max_{q∈Q} Info(q;φ)≥ι_φ，
其中 Φ_Δ 为该部件类（定义 142）声明的失效模式约束（扭矩上限、间隙、增益、时延、柔顺、通信）。每条约束由物理测试给出区间 [l_j,u_j]，通过 ⇔ 区间⊂设计包络且（对 B2）存在**至少一个 independent 见证**或**跨实例复现**。再认证预算 k_rec；**再认证健全性**：B2 后对已认证约束的参数误差 ≤ε_ℬ；未通过 ⇒ 停留 B0/B1，禁止 L2/不可逆接触。

**定义 142（开源组件公会 OCG）** 组件类 C 的社区知识图 𝒢_C=(F_C,{variants},{attestations},forks)。给定 ℬ 的咨询集 K(ℬ)={C:c∈ℬ}。K_eff=(Σw)²/Σ_{C,C'}w_Cw_C'ρ_CC'，ρ 为共因相关（同厂/同批/同 fork）。**关键隔离**：OCG 是**不可信先验**——只允许影响 (i) 一致性探针的选择与先验排序、(ii) 失效模式的候选集，**永不进入证据类、永不改变 𝒫_α^{rob}、永不提升 σ_ℬ**。这与第 57 轮 XMC 的模态可靠性 ρ_m 不同：ρ_m 是**本机模态**的历史证伪，可进入信念；OCG 是**他机社区**的先验，只能导航。fork/版本声誉**按组件类与版本局部化**，禁止跨版本迁移（"在 A 版攒的信任"不适用于 B 版，防止供应链投毒式借壳）。分歧时取失效模式并集（不投票）。

**定义 143（身体条件化证据契约 BEC，升级 FSE，含形态安全地板 MSH）** 证据类：EV-probe\*、EV-visit、EV-margin、EV-xmodal、EV-human、**EV-self（新，自探针证据）**。门规则：
(i) 任何承诺需 σ_ℬ≥B1 且 ξ 落在 Ξ_β 内；L2/不可逆接触需 σ_ℬ≥B2 且无未决漂移告警；
(ii) EV-self **只可作佐证**，不得进入不可逆接触必要证据集，且不得把 σ_ℬ 推过 B1；
(iii) 身体不确定以鲁棒并集进入安全：Ξ_β 越宽 ⇒ b_r^{rob}/𝒫_α^{rob} 越宽 ⇒ 动作越保守，安全项含 β；
(iv) 来源 att_i 只改**适用范围/信任等级**，不新增证据类；
(v) **形态安全地板 MSH**：若动作 a 落在**已在本实例上认证**的机械包络 ℰ_mech 内，且由被动结构（限位/柔顺/保险丝/自锁）保证 a 有界，则 a 可由"机械证据"签字：P(fail|a∈ℰ_mech)≤δ_mech，**不依赖控制器与自模型**；越出 ℰ_mech ⇒ 回到 (i)–(iv) 的完整软件证据链。MSH 的认证本身须消耗 CRX 探针，且不得由自探针单独完成。
证书 J_b=(J_p,J_ℬ,Ξ_β,conformance_log,recert_log,ocg_log,self_probe_log,drift_log,floor_log)，继承第 57 轮 J_p 全检。

**定义 144（具身探-诺-演 EPC，升级 PCE+）** 每检查点：
①**身体闸**（manifest 指纹、漂移、σ_ℬ）；若 ι_ℬ 变或未认证 ⇒ 先 CRX 再谈承诺；
②SMC 估计 Ξ_β，身体条件化元推断与对账给出 b_r^{rob}；

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| BMC | O(\|ℬ\|) 校验/变更 | O(\|ℬ\|) | 实例指纹、设计/实例证书分离、变更即降级 |
| SMC | O(K_robust·\|𝒜\|·d_e) | O(\|Ξ_β\|·\|V\|) | 自模型共形覆盖 ≥1−β、分层、漂移检测 |
| CRX | O(k_rec·(C_test+\|Φ\|)) | O(\|Φ\|) | 再认证健全性、独立见证、B2 前禁 L2 |
| OCG | O(\|K\|·\|F\|) | O(\|𝒢\|) | 不可信先验、版本局部化、K_eff |
| BEC | O(\|σ\|) | O(\|σ\|) | 自证≤B1、自探针非必要证据、MSH 有界 |
| EPC | O(\|CP\|·(k_d+k_self+k_rec)·(C_VOI+\|𝒜\|)) | O(\|V\|+\|σ\|) | 身体闸先行、变更即保守、终止 |

**正确性定理（Embodied Instance Soundness, EIS）**：在 A37–A40 上再加 (A41) BMC 实例指纹/设计证书与实例证书分离/变更即降级；(A42) 自模型分层共形覆盖 P(ξ\*∈Ξ_β)≥1−β、漂移漏检 ≤δ_drift、自探针不得把 σ_ℬ 推过 B1；(A43) CRX 健全（B2 后已认证约束误差 ≤ε_ℬ，独立见证/跨实例复现诚实）；(A44) OCG 为不可信先验，只影响探针选择/排序、版本局部化、K_eff 估计误差 ≤ε_K；(A45) BEC/MSH：自证 ≤B1、自探针不作必要证据、L2 需 B2、MSH 机械包络在本实例认证且被动界不依赖控制器。则：

(i) **实例健全性**：若承诺放行，P(fail) ≤ δ_f + ε_meta(k) + β + δ_drift + ε_ℬ + δ_probe + ε_h；
(ii) **设计不可转移**：仅持 𝒟_open 而无 J_ℬ 时，对 ι_ℬ 无任何安全界——开放设计只降低验证成本，不降低实例风险；
(iii) **维修单调性**：任意硬件变更只可即时降级、作废承诺；再升级须一致性证据 + 独立见证，不存在"换件即更敢赌"的路径；PTM（第 57 轮）的单向有界原则在硬件上成立；
(iv) **机械地板独立兜底**：对 a∈ℰ_mech，P(fail|a)≤δ_mech，且该界不含自模型/LLM/操作者误差项——自证伪造不能突破物理界；
(v) **语言/社区先验零安全贡献**：OCG 与 MLA 再错，只改变探针数、拒绝率与时延，安全界不变（继承第 57 轮 XMC/第 56 轮证据门）；
(vi) **终止性**：每检查点探针 ≤k_d+k_self+k_rec，变更/漂移/UNRESOLVABLE 即转保守出口；
(vii) **部署联合界**：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + β + δ_drift + ε_ℬ + δ_probe + ε_h)
             − P(身体变更未触发闸) − P(漂移漏检) − P(MSH 失效/卡死) − P(安全停失效)
```

```python
def qac_certify(m, b, qcal):
    # 必须由部署位宽自身在量化校准集上测量，禁止由浮点证书外推
    f_q = quantize(m, b)
    ece = expected_calibration_error(f_q, qcal)
    d_ood = ood_detection_drop(f_q, qcal)
    d_bd = max(abs(margin(f_q(x)) - margin(m(x))) for x in boundary_band(qcal))
    cert = Cert(ece=ece, d_ood=d_ood, delta_bd=d_bd,
                calib_hash=hash(qcal), version=next_version(m, b))
    assert monotone_ok(cert, b)          # b 越低，风险分量只能越大
    cert_store.put((m.id, b, cert.calib_hash), cert)
    return cert

def qac_gate(m, b, decision):
    cert = cert_store.get((m.id, b, calib_hash=current))
    if cert is None:                                  return 'float_fallback'
    if cert.ece > eps_meta + theta_q:                 return 'float_fallback'
    if decision.irreversible and cert.delta_bd > theta_bd:
        return 'float_fallback'                       # 边界不可信 → 禁参与不可逆
    return cert
```

### IP-140 BBE（比特预算即证据预算）

```python
def allocate_bits(paths, bit_budget, lam):
    # 与探针预算同构：悲观 VOI 下的资源分配，安全关键硬下限
    for p in paths:
        p.b = max(p.b_min, p.b_min_bd if p.boundary else 0)
    while spent(paths) < bit_budget:
        p = argmax(paths, key=lambda p: dv(p.c, p.b) - lam * dcost(p.b))
        if dv(p.c, p.b) - lam * dcost(p.b) <= 0: break
        p.b = min(p.b_max, p.b + p.step)              # 关键处升比特
    save = bit_budget - spent(paths)                  # 省下的比特折算探针
    return paths, probe_budget_from_bits(save)

def exchange_budget(save_bits, probe_cost):
    return int(save_bits / probe_cost)                # 比特↔探针可交换
```

| 组件 | 时间 | 空间 | 正确性保证 |

**正确性定理（Quantized-Synthesis Integrity Soundness, QSIS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 量化证书诚实：C_q(m,b) 由部署位宽在量化校准集上测量，b↓⇒证书各风险分量不变窄，禁止浮点证书外推，边界带 Δ_bd 真实测量；**(A42)** 比特分配不绕过安全关键硬下限 b_min(c) 与浮点回退，省比特只能换探针不能换风险；**(A43)** 出站语音语义保真：ASR 回环内容不增不减，韵律满足 conf(a)≤g(u)，量化韵律误差超阈时降级中性 π₀；**(A44)** 入站语音确认带活体且 nonce 绑定，合成检测器失效时挑战-响应仍有效，弱人证不足以单独过 L2。则：

1. **量化承诺健全性**：P(fail) ≤ δ_f + ε_meta(k) + Δ_q(b) + δ_probe + ε_h(w_max) + δ_voice；其中 Δ_q(b) 取自**部署位宽**证书，绝不借用浮点证书；边界带路径若 Δ_bd>θ_bd 则已被浮点回退或降档，不进入该界。
2. **语音通道单调性**：出站保真只允许降低表达的确定性与紧迫度（conf(a)≤g(u)、urg(a)≤g′(u,severity)），入站防伪只允许提高确认门槛（活体 + 绑定 + 挑战）；不存在"合成/克隆/量化让系统更敢赌"的路径；弱人证只降不升。
3. **终止性**：每检查点共识探针 ≤k_cons、升比特 ≤k_bits，PCE++ 在 k_probes+k_cons+k_bits 内终止于 {承诺, 绕行, L2 协商, 安全停}；量化浮点回退只增加时延上界，不改变终止性。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + Δ_q(b) + δ_probe + ε_h + δ_voice)
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(量化证书过期未检出) − P(语音克隆 ∧ 活体失效 ∧ 挑战失效)
```

关键：**证书必须由部署位宽自签**（安全保证不能跨数值实现外推）；**比特与探针是同一张预算的两种形态**（可按风险交换，但安全关键有硬下限）；**语音是双向攻击面**（出站只许更保守、入站必须活体绑定）；量化与语音两机制全部经"信念更准或动作更保守"两个安全通道起作用，延续并强化第 57 轮的交互单调性。

`(v,a,m,q,ι,κ,g,λ,τ,σ,ρ,Explain,RUR_state,α_S,A_cert,γ_ce,δ_a, Σ/C+ 结构, 𝓜_core, J_m, probe_log, consent_state, w_h, q_φ/k*, D(r), ρ_ℳ, s_op/auth, m_E, ood_state, J_p, b/C_q, Δ_bd, D_q, a/conf(a), VoiceOK, J_q)`

其中新增：`b/C_q` 部署位宽与量化证书；`Δ_bd` 边界带裕度变形；`D_q` 量化诱导分歧；`a/conf(a)` 合成语音与其确定性；`VoiceOK` 入站确认有效性（活体 + 绑定）；`J_q` 量化-语音完整性证书。

云边协议 CEB++ → **CEB+++**：云端下发模型时必须同时下发**每个目标位宽的量化证书**与量化校准集哈希，边端校验 `(model_id, b, calib_hash)` 三元组匹配才允许该位宽参与承诺判定，否则浮点回退；云端不得用浮点证书"代表"低位宽证书。边端回传量化敏感带样本、边界带假承诺事件、语音克隆攻击样本与韵律违规样本，作为量化校准集补盲与 TTS 韵律控制的再训练数据。第 57 轮"一切判定器走隔离"在本轮推广为"**判定器的数值实现与语音接口各自持证、各自隔离**"。

## 6. 本轮最大风险

**一句话**：本轮把安全证书从浮点世界搬到定点世界、把人与系统的语音通道同时暴露给合成与克隆——最大风险是**证书在浮点上成立、在 int4 上静默失效，且量化 TTS 用过分自信的韵律或克隆的操作者声音，让人要么过度信任、要么被冒充**；必须以位宽自签证书 + 安全关键保底比特/浮点回退 + 出站韵律只许更保守 + 入站挑战-响应绑定活体四重护栏，宁可又慢又平淡，不可又自信又可伪造。
