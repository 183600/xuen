# 第 1 轮（新循环；承接第 69 轮「FLUID-RAS」IP-253~263；本轮灵感：「步骤分」×「多视角视觉」）

> R69 把不确定性拆成 aleatoric/epistemic，并用「流匹配多模态策略 + 主动多模态交互」去消解可约歧义。但它的证书仍是**整块**的：一个动作块 ξ 要么 Valid、要么退避；一整段长程任务被压成一个标量风险。真实的长程操作不是一次判决，而是一串**步骤**——「够到了吗」「抓住了吗」「提起来了吗」「放进去了吗」——每一步有不同的可观测性、不同的可逆性、不同的失败代价。R69 的「问不问」落到步级，其实是「**这一步到底算不算成了，而那个说它成了的视角，真的看得见吗**」。
>
> 本轮两个灵感正好补上两块缺失：
> - **步骤分**把二元证书变成**逐步骤的、带部分信用的向量**——不是「成/败」，而是「这一步做到几成、置信多少、还差什么」。它同时是密集奖励、风险预算与提交门限。
> - **多视角视觉**提供独立见证，但只有**有效独立**且**真正可观测**的视角才算证据；视角数量本身是一个会撒谎的数字。
>
> 核心命题：**把 R69 的整块证书分解为「步骤分解 → 逐视角步骤评分 → 可观测性门控 → 有效独立融合 → 分步预算/提交」；步骤分既驱动安全（分步风险会计），也驱动学习（密集信用），但只有在校准、可观测、有效独立三者同时满足时才允许提交。** 命名 **SPARC**（Stepwise Partial-credit Assessment & Robust Cross-view certification）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，本轮问「**这一步到底完成了没有——而且，那个说它完成了的视角，真的看得见吗**」。

## 0. 直觉与动机

**灵感 1（步骤分 → 证书是一条曲线，不是一个开关）**
直觉：R69 的 J_FLUID 是一个布尔：整块动作在安全与证据纪律下要么 Valid 要么退避。但「把杯子放到桌上」不是单点事件，而是接近、对齐、闭合、抬升、移动、下放、释放的连续过程；在第 3 步失败和第 6 步才失败，风险和可补救性完全不同。步骤分把证书从 `{Valid, Invalid}` 变成 `ρ_1..ρ_N` 一条曲线：它告诉你「已经完成了几成、下一步的把握多大、哪个步骤在拖后腿」。这在工程上等价于把**终点奖励**换成**过程奖励**，但本轮的野心不止于训练——它要成为**证书本身**。

**灵感 2（步骤分 → 信用分配 + 安全会计学）**
直觉：密集分数天然是信用分配：Δρ_i 就是这一步动作的贡献。它能让流策略在推理期做 best-of-K 重排，也能在训练期提供方差更小的梯度。但更重要的是它给了**风险预算一个可加的账本**：总失败预算 ε 可以按步骤的关键度 ε_i 分配；可逆步骤（可以撤回）允许更低的分数门限，不可逆步骤（释放、跨越、断电）要求更高。R69 只有「整体收紧」这一档；SPARC 有了「哪一步该紧、哪一步可以冒险」的分辨率。

**灵感 3（多视角 → 见证人，但「视角数」是个会撒谎的数字）**
直觉：一个相机看错了，另一个相机可以纠正——这是多视角最朴素的直觉。但**十个装在同一个刚性支架、同一光照、同一标定误差下的相机，本质上仍是一个相机**。R69 已经用「k 个正交证据源」防单源投毒；本轮把「正交」从一个口号变成可测量的量：由视角误差相关矩阵给出的**有效独立视角数 V_eff**。等相关 ρ 时 `V_eff = V/(1+(V−1)ρ)`：ρ=0.9 时 10 个视角只剩约 1.2 个独立见证。**不报 V_eff 的多视角，是在用数量伪造冗余。**

**灵感 4（多视角 → 可观测性，而不是分辨率）**
直觉：一个 4K 相机对着柜子背面，也看不见「杯子是否被抓住」；一张高分辨率图像若目标被手完全遮挡、或是透明/反光材质，它对「这一步成没成」的信息量可能为零。**看得清 ≠ 看得见该谓词**。所以必须有一个几何+物理的可观测性门：`o_{i,v} = P(步骤 i 的谓词可从视角 v 判定)`。不可观测的视角即使输出 0.99 的自信分，也必须被剔除——它不是证据，它是噪声的自信版。这就是「自信的瞎相机」问题。

**灵感 5（组合是双刃剑 → 精度的幻觉）**
直觉：步骤分让系统看起来更精细，多视角让系统看起来更可靠；两者叠加，很容易产生「每一步都被多个视角验证过」的虚假把握。真实危险有三重：(a) **奖励黑客**：策略学会把分数刷高而不是把任务做成（Goodhart）；(b) **相关视角共谋**：攻击者/共模故障让所有视角一致地错，V_eff 塌缩到 1；(c) **分数膨胀**：临近步骤边界时分数虚高，诱使系统提前提交不可逆动作。R69 说「问错，比不问更危险」；本轮必须补上一句：**「评分错，比不评分更危险」**——因为一个错误的细粒度分数会为错误动作盖上「逐步验证通过」的章。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SPARC 总览）** SPARC = (SD, PRM-V, PSC, MVF, VAG, SCA, SBA, BSV, SCR, RAS-WM‡)。五不变式：
(i) **步骤显式**：任何分数必须归属到可审计步骤 (τ_i, φ_i)，禁止端到端黑箱总分；
(ii) **部分信用必须校准**：ρ_i 是概率而非启发式，逐步骤报 ECE；
(iii) **视角必须可观测**：看不见该步骤谓词的视角不得计入证据（即使它很自信）；
(iv) **证据必须有效独立**：融合按误差相关矩阵校正，报 V_eff 而非视角计数；
(v) **分数不得闭环自证**：训练/调参用的分数与提交/审计用的分数在数据与时间上分离，否则退化为 R69 二元保守。

**定义 311（步骤分解 SD）** 给定语言任务 l 与轨迹 τ，分解 D = {(τ_i, φ_i, w_i, h_i)}_{i=1..N}：时间窗 τ_i、成功谓词 φ_i: 𝒮→{0,1}、关键度/风险权重 w_i（预算分配用）、可逆性 h_i ∈ [0,1]（1=完全可逆）。分解可由任务语法、里程碑检测或学习得到；分解不确定性 δ_D 单列为风险项，不允许被步骤分掩盖。

**定义 312（视角条件步骤评分 PRM-V）** 对每个视角 v ∈ V 与步骤 i：`s_{i,v}(h_t) = P(φ_i 在 τ_i 内成立 | o_{t,v}, h_t) ∈ [0,1]`，h_t 为历史。共享 trunk + 视角嵌入 + 步骤嵌入。训练目标 `L_PRM = BCE + 时序排序 + 语言接地 + 视角不变正则（定义 319）`。校准后 ρ_i 与真实频率一致；未校准的 s 只能作特征，不能作证书。

**定义 313（部分信用步骤证书 PSC）** 步骤 i 在 t 的证书 `c_i(t) = (ρ_i, κ_i, o_i, V_eff,i, e_i)`：融合分 ρ_i、校准置信 κ_i、可观测性 o_i、有效独立视角数 V_eff,i、证据哈希 e_i。三态：
- **PASS** ⇔ `ρ_i ≥ 1−α_i` ∧ `κ_i ≥ κ_min` ∧ `o_i ≥ o_min` ∧ `V_eff,i ≥ 2`；
- **FAIL** ⇔ `ρ_i ≤ α_i` 且证据一致；
- **PENDING** ⇔ 其余。
PENDING 不是失败，而是**拒绝给分**——它触发 R69 的保守退避，而不是二元否定。这是「步骤分」与普通阈值判定的根本区别。

**定义 314（有效独立视角融合 MVF）** 令 `z_{i,v}=logit(s_{i,v})`，测量模型 `z_{i,v}=z_i+b_v+ε_v`，`E[εεᵀ]=Σ`。GLS 融合：
`ẑ_i = (1ᵀΣ⁻¹1)⁻¹ 1ᵀΣ⁻¹(z−b)`，方差 `(1ᵀΣ⁻¹1)⁻¹`。
定义 `V_eff = σ_ref²·(1ᵀΣ⁻¹1)`；等相关 ρ 时 `V_eff = V/(1+(V−1)ρ)`。边际增益 `∂V_eff/∂V = (1−ρ)/(1+(V−1)ρ)² > 0`，但 ρ→1 时 V_eff→1：**继续加相机只是在给同一个见证人鼓掌**。

**定义 315（可观测性与主动视角 VAG）** `o_{i,v} = P(φ_i 可从视角 v 判定)`——由可见性、遮挡、分辨率、深度歧义、透明/反光材质共同计算。`o_{i,v} < o_min` 的视角对步骤 i **不可采纳**（防「自信的瞎相机」）。主动视角选择：
`v* = argmax_v E[IG(z_i; y_v)] − c(v)`，s.t. 视角运动过 C-RAS-WM 认证。这是 R69 MINT 的「注视」在自由视角上的推广，也是「多视角视觉」从被动输入变成主动动作的接口。

**定义 316（步骤信用分配 SCA）** 步骤增量 `Δ_i = ρ_i(after) − ρ_i(before)`。密集回报：
`R_t = Σ_i γ^{τ_i−t} Δ_i·1[c_i 已认证] − λ_hack·1[分数膨胀]`。
用于两处：(a) 流策略微调（仅已认证步骤）；(b) 推理期 best-of-K 重排：
`ξ* = argmax_{ξ^{(j)}} Σ_i ρ̂_i(ξ^{(j)})·w_i`，s.t. 安全认证。
**未认证步骤不得进入梯度或重排**——这是防 Goodhart 的第一道闸。

**定义 317（步骤预算分配 SBA）** 总预算 B（交互次数 + 验证算力 + 视角移动）。`ΔU_i(b_i)` 为步骤 i 的期望不确定性下降乘以下游关键度：
`max Σ_i ΔU_i(b_i)` s.t. `Σ_i b_i ≤ B, b_i ≥ 0`。
若 ΔU_i 单调子模，贪心达 `(1−1/e)`；独立线性情形贪心最优。不可逆步骤 h_i 低 ⇒ 门限 `1−α_i` 更高（定义 322）。这把 R69 的单一「交互/不交互」升级为「把预算花在哪一步最值」。

**定义 318（拜占庭鲁棒步骤验证 BSV）** 至多 f 个视角被攻陷/共谋。用坐标修剪均值或 median-of-means 聚合；仅当 `V_eff ≥ 2f+1` 时采信。这把 R69 的「k 个正交证据源一致」具体化为「**有效独立视角过半一致**」；若 V_eff 因共模故障塌到 1，任何 f≥1 都无法容忍。

**定义 319（步骤一致性 SCR）** 三正则：(a) **时序一致**：无状态转移事件时 ρ_i 不得跳变；(b) **视角不变**：同一物理状态在不同可观测视角下分数差 ≤ δ_inv；(c) **状态敏感**：不同步骤状态在同一视角下分数差 ≥ δ_sen。违例 ⇒ 标记「分数幻觉」，触发 PENDING 并进入审计。

**定义 320（步骤分证书 J_SPARC）** `J_SPARC = (J_FLUID, D_hash, {c_i}_{i=1..N}, step_ECE, V_eff,min, hack_audit, view_cal_ver, sparc_ver)`。有效性分层：
- **完全 Valid**：所有提交步骤 PASS；
- **部分 Valid**：报告步骤分向量 + PENDING 集合（允许继续但限制提交）；
- **退避 Valid**：`step_ECE > τ` 或 `V_eff < 2` ⇒ 回 R69 chunk 级保守。
证书是**向量**而非布尔——这正是「步骤分」的工程含义。

**定义 321（步骤校准门 SCG）** `step_ECE > τ_step` 时禁用密集信用与分步提交，退回 R69 chunk 级。另设**视角校准门**：某视角 ECE > τ_v 则从 V 中剔除。对应 R69 的 MCG，但把「模态权重校准」下沉到「步骤×视角校准」。

**定义 322（风险组合与安全提交）** 步骤 i 的失败预算 ε_i，`Σ_i ε_i ≤ ε_task`。对可逆步骤允许较低门限；不可逆步骤（释放、跨越、断电）要求更高：
`α_i(h_i) = α_0·(1−β·h_i)`，h_i 越小（越不可逆）门限越高。
提交规则：`execute_i ⇔ ρ_i ≥ 1−α_i(h_i) ∧ c_i.valid ∧ 后续步骤存在可行回退`。这把「步骤分」变成真正的**安全会计**，而不是一个好看的监控指标。

**定义 323（视角欺骗与共模故障）** 攻击者控制视角集 A，|A|=f，注入一致伪造；共模故障（同刚性支架、同光照、同传感器漂移）建模为 Σ 的非对角块。检测：视角残差聚类 + V_eff 突降 + 与 R69 的 `(r_res, Δa)` 联合判据。**多视角只有在误差不共模时才是冗余，否则只是复读机。**

**定义 324（步骤分数投毒与奖励黑客）** 策略可影响被评状态分布；若训练与评估同源，Goodhart 必然。防线：held-out verifier 集成、随机化步骤边界、审计分数膨胀、SCG 门、红队 AIC。定义「反馈污染度」`φ_fb` 为训练分数与提交分数共享的数据比例；`φ_fb > φ_max` 时禁用密集信用。

**定义 325（分步退避与回滚）** 步骤 FAIL/PENDING 时：可逆则回滚到上一个 PASS 状态；不可逆则冻结并请求交互（R69 MINT），交互预算由 SBA 分配。保证 λ 单调不降；任何分数恶化只会延长 PENDING，绝不会放宽提交门限。

**定义 326（退化边界）** N=1 ⇒ R69 整块证书；V=1 ⇒ R69 单证据；ρ∈{0,1} ⇒ R69 二元判定；无密集标签 ⇒ 仅时序弱监督的进度分类器。四种退化下指令级等价 ⇒ **SPARC 严格包含 R69，安全侧不让步，效率侧获得步骤分辨率的 bonus**。

## 2. 关键算法骨架

```python
# IP-264 PRM-V：视角条件步骤评分器（共享 trunk，视角/步骤嵌入）
class StepScorer:
    def score(self, obs, steps, views):
        z = self.trunk(obs)
        return {i: {v: self.head(z, v, i) for v in views} for i in steps}

# IP-265/266/267：部分信用证书 = 可观测门 × GLS 融合 × 有效独立
def step_certificate(scores_i, view_models, step_i):
    adm = {v: s for v, s in scores_i.items()
           if view_models[v].observability(step_i) >= O_MIN
           and view_models[v].ece() <= TAU_VIEW}
    if not adm:
        return StepCert.pending(reason="no admissible view")
    Sig   = view_error_covariance(adm)          # 视角误差相关矩阵
    w     = gls_weights(Sig)                    # Sigma^{-1}1 / (1^T Sigma^{-1}1)
    v_eff = sigma_ref**2 * (ones @ inv(Sig) @ ones)
    rho   = sigmoid(sum(w[v] * logit(adm[v]) for v in adm))
    kappa = calibration_confidence(adm)
    o     = min(view_models[v].observability(step_i) for v in adm)
    return StepCert(rho, kappa, o, v_eff, evidence_hash(adm))

# IP-270 BSV：拜占庭鲁棒共识（仅当有效独立数过半）
def robust_consensus(certs, f_max):
    if min(c.v_eff for c in certs) <= 2 * f_max + 1:
        return [c.pending("insufficient effective independence") for c in certs]
    return [c.with_rho(trimmed_mean(c.per_view, trim=f_max)) for c in certs]

# IP-269 SBA：子模贪心分配交互/验证预算
def allocate_budget(steps, certs, B):
    gains = {i: expected_voi(i, certs[i]) * w_i for i in steps}
    return greedy_submodular(gains, B, diminishing=True)   # (1-1/e) 近似

# IP-268 SCA：密集信用（只喂已认证步骤，防奖励黑客）
def dense_credit(certs, prev_rho):
    return [clip(c.rho - prev_rho[i], 0.0, 1.0) * c.valid for i, c in certs.items()]

# IP-275 主闭环（继承 R69，把整块判决替换成步骤分判决）
def SPARC_round(M, obs):
    base = M.fluid.step(obs)                         # R69 chunk 级候选 + J_FLUID
    steps = M.sd.decompose(obs, M.task)              # 步骤分解
    scores = M.prm_v.score(obs, steps, obs.views)    # 逐视角步骤分
    certs = {i: step_certificate(scores[i], M.views, i) for i in steps}

    if M.attack_suspected():                         # 共模/投毒怀疑
        certs = robust_consensus(certs, M.f_max)

    if M.scg.ece(certs) > TAU_STEP or M.scg.v_eff_min(certs) < 2:
        return M.fluid.fallback(obs, reason="step-calibration")   # 严格退回 R69

    plan = M.sba.allocate(steps, certs, M.budget)    # 预算只花在关键步骤
    for i in plan.order:                             # 分步提交，不可逆更严
        if not certs[i].passes(alpha_i(steps[i].h)):
            if steps[i].h > H_ROLLBACK:
                M.rollback_to(last_pass)             # 可逆则回滚
            else:
                M.mint.request_interaction(i)        # 不可逆则问
            break
        M.execute_step(i)

    dense = dense_credit(certs, M.last_rho)          # 仅已认证步骤进信用
    M.sca.train_or_rerank(dense)                     # 训练/推理重排
    M.vqa_s.submit_async(steps, certs, base)         # 审计并回灌
    return J_SPARC(base, steps, certs, dense)
```

## 3. 推导

**引理 19（密集信用的偏差-方差权衡）** 设成功率估计为 `log Ŝ = Σ_{i=1}^N log ρ̂_i`，每步 `log ρ̂_i` 的偏差 ≤ β_i、方差 ≤ ν_i。则 `|E log Ŝ − log S| ≤ Σ_i β_i`，`Var(log Ŝ) ≤ Σ_i ν_i`。Δ 方法下相对 MSE ≈ `Σ_i(β_i²+ν_i)`。**系：更多步骤会降低方差，但会按步累加校准偏差；步骤数 N 本身存在一个内点最优 N\*，无脑细化反而更差。** 这直接反驳「步骤分越细越好」的直觉。

**引理 20（有效独立与共模代价）** 在等相关 ρ 下 `V_eff = V/(1+(V−1)ρ)`，故 `∂V_eff/∂V = (1−ρ)/(1+(V−1)ρ)²`。若 f 个视角被攻陷，修剪均值在 `V_eff ≥ 2f+1` 时错误率随 `exp(−V_eff·D(δ‖ε))` 下降；ρ→1 时 V_eff→1，任何 f≥1 都突破鲁棒上界。**系：多视角的安全冗余来自误差的独立性，不来自相机数量；共模故障会把「十路投票」退化成「一路独裁」。**

**引理 21（可观测性下界）** 若视角 v 以概率 `1−o_{i,v}` 完全不携带 φ_i 的信息（遮挡/盲区/透明），则任何仅依赖该视角的估计器的 Bayes 误差 ≥ `(1−o_{i,v})·min(p_i, 1−p_i)`。**系：不可观测但高置信的视角必然失准；VAG 门不是保守，而是数学上必需。**

**定理 18（SPARC 严格包含 R69）** 在定义 326 的四种退化下，SPARC 与 FLUID-RAS 逐指令相同：N=1 时步骤分退化为整块证书，V=1 时 GLS 退化为单证据，ρ∈{0,1} 时三态判定退化为二元判定，无密集标签时 SCA 关闭。因此 R69 是 SPARC 在「一一步、单视角、二元信用」边界上的退化；安全侧不做任何让步，效率侧获得步骤分辨率与密集信用。

**定理 19（组合证书的可靠性）** 若步骤 i 的证书假通过概率 ≤ ε_i，则整条轨迹出现未被证书捕获的失败概率 ≤ `Σ_i ε_i`（联合界）。给定总预算 ε_task，最小化最坏失败的分配由拉格朗日水填充给出：边际风险下降/边际成本相等的步骤优先。**系：SBA 不是启发式，而是组合证书可靠性的对偶。**

**定理 20（Goodhart 不可能性）** 设策略类 VC 维为 d，若用同一分数既做选择又做评估，则对任意评分器都存在一个策略使报告分数趋近 1 而真实成功率不高于先验；held-out 校准集大小 m 只能为**固定**策略给出 `O(√((d+log(1/δ))/m))` 的一致界，不能覆盖自适应优化轨迹，除非 m 随轨迹增长。**系：held-out verifier、随机化步骤边界、审计分数膨胀不是工程选项，而是统计上的必要条件。**

**定理 21（拜占庭与共模鲁棒）** 若 `V_eff ≥ 2f+1` 且每视角分数有界影响，则修剪均值融合的错误率 ≤ `2exp(−V_eff·(δ−ε)²/2)`；若共模相关 ρ→1，则 V_eff→1，f≥1 即失效。**系：** 多视角给出的是条件性冗余，条件就是「误差不共模」；R69 的 `(r_res, Δa)` 与视角残差聚类必须联合使用，才能把「真一致」与「一起错」分开。

## 6. 本轮最大风险

**一句话**：SPARC 的最大风险是「**精度的幻觉**」——部分信用把证书从一位布尔变成一串看似精细的数字，多视角又给这些数字盖上「多源一致」的章；一旦步骤分数被奖励黑客、共模故障或分数膨胀污染，系统会比 R69 **更自信地执行错误步骤**——**评分错，比不评分更危险**。

**次级风险与缓解**：
1. **步骤分解本身错**（边界错位导致分数归错步骤）→ δ_D 单列 + 随机化边界 + 人审关键不可逆步骤；
2. **视角误差共模**（同一支架/光照/标定）→ V_eff 实测 + 残差聚类 + 与 R69 `(r_res, Δa)` 联合判据；
3. **奖励黑客/分数膨胀** → held-out verifier、`φ_fb` 门、SCG、E308/E310 红队；
4. **不可逆步骤被提前提交** → 可逆性相关门限 `α_i(h_i)` + 回滚约束 + 交互兜底；
5. **步骤分看似细却整体偏**（N 过大导致偏差累加）→ 引理 19 的 N\* 选择 + 逐步骤 ECE 门 + 全局 chunk 证书交叉校验。

# 第 1 轮产物 · 创新点清单 v1：SPARC（Stepwise Partial-credit Assessment & Robust Cross-view certification：步骤分 × 多视角视觉的分步部分信用风险自适应闭环；SD×PRM-V×PSC×MVF×VAG×SCA×SBA×BSV×SCR×RAS-WM‡）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 用 aleatoric/epistemic 二分 + 流匹配多模态策略 + 主动交互，把「不确定性」从刹车踏板变成提问、注视、轻触。但它的证书仍是**整块**的：一个动作块要么 Valid、要么退避，长程任务被压成一个标量风险；「问不问」是 chunk 级决策，而不是步骤级决策。更关键的是，R69 的「多源一致」只防了单源投毒，没有回答两个更基础的问题：**这个视角真的看得见这一步吗？这些视角真的独立吗？**
>
> 本轮两个灵感正好补上：
> - **步骤分**：把布尔证书变成逐步骤的部分信用向量，既作密集奖励，也作分步风险预算与提交门限；
> - **多视角视觉**：提供独立见证，但用「可观测性门 + 有效独立数 V_eff」把「多」与「独立」分开。
>
> 核心命题：**步骤分若脱离可观测性就是虚假精度；多视角若脱离有效独立性就是虚假共识。** SPARC 把两者接成一条可证明的链：步骤分解 → 逐视角评分 → 可观测性门控 → GLS 有效独立融合 → 分步预算/提交 → 审计。理论姿态：**R69 是本轮在「一步、单视角、二元分数」边界上的严格退化**，安全侧不让步。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，本轮问「**这一步到底完成了没有——而且，那个说它完成了的视角，真的看得见吗**」。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** 步骤显式；部分信用必须校准；视角必须可观测；证据必须有效独立；分数不得闭环自证。任一不满足 ⇒ 退化为 R69 二元保守。

**定义 311–312（SD 与 PRM-V）** 任务分解为 `(τ_i, φ_i, w_i, h_i)`；每视角每步骤输出 `s_{i,v}=P(φ_i|o_{t,v},h_t)`；训练含 BCE + 时序排序 + 语言接地 + 视角不变正则；未校准分数只能作特征，不能作证书。

**定义 313（PSC）** `c_i=(ρ_i,κ_i,o_i,V_eff,i,e_i)`；PASS ⇔ `ρ_i≥1−α_i ∧ κ_i≥κ_min ∧ o_i≥o_min ∧ V_eff,i≥2`；FAIL ⇔ `ρ_i≤α_i` 且证据一致；其余 PENDING（拒绝给分，非否定）。PENDING 走 R69 保守退避。

**定义 314（MVF）** `z_{i,v}=logit(s_{i,v})`，`z=z_i1+b+ε`，`Cov(ε)=Σ`；GLS `ẑ_i=(1ᵀΣ⁻¹1)⁻¹1ᵀΣ⁻¹(z−b)`，方差 `(1ᵀΣ⁻¹1)⁻¹`；`V_eff=σ_ref²(1ᵀΣ⁻¹1)`；等相关 ρ 时 `V_eff=V/(1+(V−1)ρ)`。

**定义 315（VAG）** `o_{i,v}=P(φ_i 可从 v 判定)`；低于 `o_min` 的视角不可采纳；主动视角 `v*=argmax_v E[IG]−c(v)`，运动过 C-RAS-WM 认证。

**定义 316（SCA）** `Δ_i=ρ_i(after)−ρ_i(before)`；`R_t=Σ_i γ^{τ_i−t}Δ_i·1[c_i 已认证]−λ_hack·1[膨胀]`；用于流策略微调与 best-of-K 重排；未认证步骤不得进梯度/重排。

**定义 317（SBA）** `max Σ_i ΔU_i(b_i)` s.t. `Σ b_i≤B`；子模贪心 `(1−1/e)`；不可逆步骤门限更高。

**定义 318（BSV）** 修剪均值/median-of-means；仅 `V_eff≥2f+1` 采信；把 R69 的「k 正交源」具体化为「有效独立视角过半一致」。

**定义 319（SCR）** 时序一致 + 视角不变（同状态跨视角差 ≤ δ_inv）+ 状态敏感（不同状态同视角差 ≥ δ_sen）；违例标记「分数幻觉」。

**定义 320–321（J_SPARC 与 SCG）** 证书分完全/部分/退避三层，输出步骤分向量；`step_ECE>τ` 或 `V_eff<2` ⇒ 禁用密集信用与分步提交，退回 R69；单视角 ECE 越界即剔除。

**定义 322–323（风险组合与视角欺骗）** `Σ ε_i≤ε_task`；`α_i(h_i)=α_0(1−βh_i)`，不可逆步骤更严；共模故障建模为 Σ 的非对角块，用残差聚类 + V_eff 突降 + R69 `(r_res,Δa)` 联合检测。

**定义 324–326（反馈污染与退化）** `φ_fb>φ_max` 禁用密集信用；可逆回滚/不可逆冻结问询；N=1/V=1/二值/无密集标签四种退化均逐指令等价于 R69。

## 3. 关键算法伪代码

```python
# IP-264 PRM-V：视角条件步骤评分
class StepScorer:
    def score(self, obs, steps, views):
        z = self.trunk(obs)
        return {i: {v: self.head(z, v, i) for v in views} for i in steps}

# IP-265/266/267：部分信用证书 = 可观测门 × GLS 融合 × 有效独立
def step_certificate(scores_i, view_models, step_i):
    adm = {v: s for v, s in scores_i.items()
           if view_models[v].observability(step_i) >= O_MIN
           and view_models[v].ece() <= TAU_VIEW}
    if not adm:
        return StepCert.pending(reason="no admissible view")
    Sig   = view_error_covariance(adm)
    w     = gls_weights(Sig)                       # Sigma^{-1}1 / (1^T Sigma^{-1}1)
    v_eff = sigma_ref**2 * (ones @ inv(Sig) @ ones)
    rho   = sigmoid(sum(w[v] * logit(adm[v]) for v in adm))
    kappa = calibration_confidence(adm)
    o     = min(view_models[v].observability(step_i) for v in adm)
    return StepCert(rho, kappa, o, v_eff, evidence_hash(adm))

# IP-270 BSV：有效独立数不足则拒绝采信
def robust_consensus(certs, f_max):
    if min(c.v_eff for c in certs) <= 2 * f_max + 1:
        return [c.pending("insufficient effective independence") for c in certs]
    return [c.with_rho(trimmed_mean(c.per_view, trim=f_max)) for c in certs]

# IP-269 SBA：子模贪心预算分配
def allocate_budget(steps, certs, B):
    gains = {i: expected_voi(i, certs[i]) * w_i for i in steps}
    return greedy_submodular(gains, B, diminishing=True)   # (1-1/e)

# IP-268 SCA：只把已认证步骤喂给信用
def dense_credit(certs, prev_rho):
    return [clip(c.rho - prev_rho[i], 0.0, 1.0) * c.valid for i, c in certs.items()]

# IP-275 主闭环（继承 R69）
def SPARC_round(M, obs):
    base  = M.fluid.step(obs)                      # R69 chunk 级 + J_FLUID
    steps = M.sd.decompose(obs, M.task)
    scores = M.prm_v.score(obs, steps, obs.views)
    certs  = {i: step_certificate(scores[i], M.views, i) for i in steps}
    if M.attack_suspected():
        certs = robust_consensus(certs, M.f_max)
    if M.scg.ece(certs) > TAU_STEP or M.scg.v_eff_min(certs) < 2:
        return M.fluid.fallback(obs, reason="step-calibration")
    plan = M.sba.allocate(steps, certs, M.budget)
    for i in plan.order:
        if not certs[i].passes(alpha_i(steps[i].h)):
            if steps[i].h > H_ROLLBACK:
                M.rollback_to(last_pass)
            else:
                M.mint.request_interaction(i)
            break
        M.execute_step(i)
    dense = dense_credit(certs, M.last_rho)
    M.sca.train_or_rerank(dense)
    M.vqa_s.submit_async(steps, certs, base)
    return J_SPARC(base, steps, certs, dense)
```

## 4. 推导

**引理 19（密集信用的偏差-方差权衡）** `log Ŝ=Σ log ρ̂_i`；若每步偏差 ≤ β_i、方差 ≤ ν_i，则 `|E log Ŝ − log S| ≤ Σβ_i`，`Var ≤ Σν_i`；相对 MSE ≈ `Σ(β_i²+ν_i)`。系：步骤数存在内点最优 N\*，更多步骤降低方差但累加校准偏差——**步骤分不是越细越好**。

**引理 20（有效独立与共模代价）** 等相关 ρ 下 `V_eff=V/(1+(V−1)ρ)`，`∂V_eff/∂V=(1−ρ)/(1+(V−1)ρ)²`；ρ→1 时 V_eff→1。f 个视角被攻陷时，`V_eff≥2f+1` 才能用修剪均值获得随 `exp(−V_eff·D(δ‖ε))` 下降的错误率。系：冗余来自误差独立性，不来自相机数量。

**引理 21（可观测性下界）** 若视角以概率 `1−o` 完全不携带 φ_i 信息，则任何仅依赖该视角的估计器 Bayes 误差 ≥ `(1−o)·min(p_i,1−p_i)`。系：不可观测却自信的视角必然失准，VAG 是数学必需而非保守。

**定理 18（SPARC 严格包含 R69）** N=1、V=1、ρ∈{0,1}、无密集标签四种退化下逐指令等价于 FLUID-RAS；安全侧不让步，效率侧获得步骤分辨率与密集信用。

**定理 19（组合证书可靠性）** 每步假通过 ≤ ε_i ⇒ 整条轨迹未捕获失败 ≤ `Σ_i ε_i`（联合界）；总预算约束下最坏失败最小化由拉格朗日水填充给出，SBA 即其对偶。

**定理 20（Goodhart 不可能性）** 同一分数既选择又评估时，对任意评分器存在策略使报告分趋近 1 而真实成功率不高于先验；held-out 集只对固定策略给出一致界，不能覆盖自适应优化轨迹。系：held-out verifier + 随机化步骤边界 + 审计是统计必要条件。

**定理 21（拜占庭/共模鲁棒）** `V_eff≥2f+1` 时修剪均值错误率 ≤ `2exp(−V_eff(δ−ε)²/2)`；共模 ρ→1 时 V_eff→1，f≥1 即失效。系：多视角是条件性冗余，必须与 R69 `(r_res,Δa)` 及残差聚类联合判定「真一致」与「一起错」。

## 7. 本轮最大风险

**一句话**：SPARC 的最大风险是「**精度的幻觉**」——部分信用把证书从一位布尔变成一串看似精细的数字，多视角又给这些数字盖上「多源一致」的章；一旦步骤分数被奖励黑客、共模故障或分数膨胀污染，系统会比 R69 **更自信地执行错误步骤**——**评分错，比不评分更危险**。

**次级风险与缓解**：
1. **步骤分解错位**（分数归错步骤）→ δ_D 单列 + 随机化边界 + 不可逆步骤人审；
2. **视角误差共模**（同支架/光照/标定）→ 实测 V_eff + 残差聚类 + 与 R69 `(r_res,Δa)` 联合判据；
3. **奖励黑客/分数膨胀** → held-out verifier、`φ_fb` 门、SCG、E308/E310 红队；
4. **不可逆步骤提前提交** → 可逆性门限 `α_i(h_i)` + 回滚约束 + 交互兜底；
5. **N 过大导致偏差累加** → 引理 19 的 N\* + 逐步 ECE 门 + 全局 chunk 证书交叉校验。
