# 第 44 轮（新循环第 4 轮） · Sem-Cert × Ground-Cert：把「视觉语言模型」与「自然语言指令」纳入可验证语义闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形边际覆盖被欺骗 + 多用户契约空集」，但它仍压着一个更底层的未言明假设：**(H) 语义层被当作可信输入**——VLM 对图像的理解、自然语言指令到形式目标的编译，都被默认为「给定」，证书链只在几何/人格/并发上做验证。可一旦 VLM 把「刀」认成「杯子」、把「放在桌子左边」解析成「右边」，下游所有几何证书都**完全 sound 却完全错误**——这是 v20 结构上无法察觉的「语义 soundness 缺口」。本轮灵感词「视觉语言模型」「自然语言指令」精确命中该假设：**VLM** 迫使我们把「感知语义」从不可验证的隐变量提升为带证书的集合值对象；**自然语言指令**迫使我们把「人话→形式规约」的编译过程显式暴露其欠定性，并把「追问」升格为安全关键动作。二者耦合处（多模态接地 × 指令歧义 × 澄清回环）是本轮真正的新问题：语义盲区无法被任何几何证书兜底。

## 0. 直觉与动机

**灵感 1（VLM → 不验证模型，验证「对模型错误的鲁棒性」）**：VLM 是开放世界的学习函数，永远无法被形式验证；但我们可以换一个被证明的对象——不证明「VLM 输出正确」，而证明「即使 VLM 输出落在某个合理误差集内，策略仍安全」。把接地 g 从单值变成**集合** Ĝ^α（共形），要求计划对所有 g∈Ĝ^α 都满足安全谓词。一句话：**别给模型发证书，给「对模型误差的鲁棒性」发证书。**

**灵感 2（自然语言指令 → 欠定性显式化 + 追问即安全动作）**：人话天然欠定（「放那儿」「快点」），传统做法是让 VLM 猜一个最可能解释，这是**把歧义偷偷压成赌注**。改为把指令编译成 (φ_core, U)——明确核心语义 + 显式欠定集，语义证书要求对所有 u∈U 都安全，否则**追问**。追问不是 UX 装饰，而是证书意义上的收缩动作：暂停运动等待澄清，永远不比继续猜更不安全。一句话：**能问就别猜，问是免费的 soundness。**

**灵感 3（跨模态冗余 → 用几何给语义发证，用语义给几何导航）**：几何层（LIO/深度/点云）度量可靠但语义贫乏；VLM 语义丰富但度量不可靠。二者的**一致区间**正是可认证语义：VLM 说「杯子在 (x,y,z)」，点云在该处确有杯状簇 → 接地获证；不一致 → 视为幻觉 → 不用于安全关键规划。这把「VLM-几何不一致」从工程告警升级为**有形式角色的幻觉检测器**。一句话：**语义证书 = VLM 置信 ∧ 几何一致 ∧ 共形成员。**

**耦合升级**：v20 的人格层提供「解释先验 + 追问风格」，并发层提供「接地/几何/编译的租约与交错」，本轮新增的语义层把二者缝合：接地集合按人格校准（Mondrian），语义租约随场景漂移衰减，澄清回环本身是双向自然语言（机器人问、人再答，答案又是一条待编译指令）。四层架构由 v8 升级为 v9：**仿真-检索-边缘飞轮 + 人格契约 + 并发证书 + 语义接地证书**。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（指令的欠定语义集与安全编译）**：自然语言指令 L 经带类型论域与欠定标记的文法编译为三元组 (φ_core, U, C_cmd)：φ_core 为无歧义核心目标；U 为**欠定细化集**（每个 u 是一个可行解释，如「哪只杯子」「哪个位置」「何种力度」）；C_cmd 为**指令合规约束**（该指令不得请求的动作集合）。**解释集** ⟦L⟧ = {φ_core ∧ u : u ∈ U}。**编译可靠性假设**：存在参考语义 M(L)（由人格先验 + 任务本体给出），且 ⟦L⟧ ⊇ M(L)（第 5 节最大风险即攻击此假设）。

**定义 45（跨模态接地证书）**：接地 g=(obj, pose, attrs, rel) 表示「某对象在某位姿、具某属性、与他物成某关系」。g **获证**当且仅当三条件同时成立：(1) VLM 置信 conf(g) ≥ θ_vlm；(2) **几何一致** geo_consistent(g)（点云支撑度、深度一致性、关系在度量空间可验证，如「left-of」由坐标判定）；(3) g ∈ Ĝ^α，即 g 属于按场景/人格分层的共形接地集，满足 P(g_true ∈ Ĝ^α) ≥ 1−α。未获证接地**禁止进入安全关键规划**，只能触发澄清或保守回退。

**定义 46（语义鲁棒证书与可靠性定理）**：计划 π 相对指令 L **语义获证**，当且仅当 ∀φ∈⟦L⟧、∀g∈Ĝ^α：要么 (π,g) ⊨ Safe(φ)（在解释 φ、接地 g 下满足安全谓词），要么 π 含一个**澄清动作**且在执行期间运动冻结（等待不变式）。**定理（语义鲁棒性）**：若 ⟦L⟧ 是真实语义的 sound 上近似（⟦L⟧ ⊇ M(L)）且 Ĝ^α 覆盖 ≥ 1−α，则执行语义获证的 π 违反真实意图安全约束的概率 ≤ α + δ_grammar（δ_grammar 为文法漏掉解释的概率质量）。**注**：这是首次把「几何 sound」升级为「语义 sound」，且其可靠性显式依赖一个文法完备性假设——这正是最大风险所在。

**定义 47（澄清动作与信息-安全权衡）**：澄清 q 是从当前欠定集 U 到细分 U_q 的查询，信息增益 IG(q)=H(U)−H(U|q)。**获证澄清**须满足：(a) **等待不变式**：机器人冻结/悬停期间状态处于鲁棒不变集 I_wait；(b) IG(q) ≥ θ_ig（避免追问疲劳）；(c) 澄清风格由人格契约 ≺_u 决定（粒度/措辞）。**定理（追问安全）**：若 I_wait 在等待期被监控器保持，则「追问并冻结」相对「猜测并执行」在安全域上是**收缩**，故永不降低 soundness；代价是可用性（时间）。**推论**：追问把「语义不确定性」兑换成「时间成本」，是唯一不引入新风险的消歧手段。

**定义 48（指令合规包络与拒绝单调性）**：合规策略 P_cmd: (L, context) → {allow, clarify, refuse}，基于安全本体与上下文（如「向儿童递刀」）。**单调性命题**：若 L 被 refuse，则任何更具体/更高风险的细化 u（u ≻ L 在风险序上）也被 refuse（refuse 集向上封闭）。拒绝是**获证安全动作**（零运动），与澄清并列为一等公民；系统绝不因「用户说了」而越过 C_global。

**定义 49（语义租约与场景漂移衰减）**：每条接地证书携带语义租约 ℓ_sem=(conf, τ, μ, scene_id)：conf 为获证置信，τ 为获证时刻，μ 为漂移率，scene_id 为场景指纹。**新鲜度判据**：conf − μ·(t−τ) ≥ θ_sem 且 scene_id 未变才可用于守卫；场景变化（物体移动、遮挡）触发接地重证或降级。**命题**：若 VLM 接地错误的增长率受场景变化速率 v_scene 界出，取 μ = L_g·v_scene 时判据 sound（不误用陈旧语义）。这使定义 41 的「度量租约」扩展到「语义租约」，二者在并发运行时统一调度。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 SEMANTIC-GROUNDING-CERTIFIER（语义接地认证器 SGC）
1. **跨模态接地验证**：VLM 输出接地候选 → 点云/深度/分割做几何一致检验（支撑度、位姿误差、关系可验证性）。
2. **共形接地集**：按场景/人格分层校准，输出 Ĝ^α 与逐候选 conf，未获证候选隔离到「仅澄清可用」区。
3. **幻觉检测与隔离**：VLM-几何不一致 → 标记 hallucination，写审计日志，触发语义租约失效。
4. **语义租约表**：维护 ℓ_sem=(conf,τ,μ,scene_id)，场景指纹变化即重证。

### 2.2 IP-61 INSTRUCTION-COMPILER（指令编译器 IC）
1. **欠定编译**：L → (φ_core, U, C_cmd)，显式枚举欠定维度（指代、位置、力度、时序），绝不静默取 argmax。
2. **合规过滤**：P_cmd 先于规划运行，refuse/clarify 向上封闭；拒绝动作零运动且带证书。
3. **语义可行性**：对 ⟦L⟧ 逐解释做几何可行性检查，不可行解释从 U 中剔除并记录（不静默放宽）。
4. **解释先验**：人格契约提供 U 上的先验（安全优先人格 → 更宽 U、更多追问）。

### 2.3 IP-62 CLARIFICATION-POLICY-ENGINE（澄清策略引擎 CPE）
1. **信息增益估计**：对每个候选澄清 q 估计 IG(q) 与等待成本，只在 IG≥θ_ig 时发问。
2. **等待不变式守卫**：冻结/悬停期间用 IP-58 监控器保 I_wait；监控失效则安全停机而非继续等。
3. **人格化措辞**：按 ≺_u 选择澄清粒度与措辞（IP-43 韵律调度复用）。
4. **递归编译**：用户的自然语言回答被重新编译为 (φ_core,U,C_cmd)，回环直到 U 单点或触发拒绝。

### 2.4 IP-63 SEMANTIC-VALIDATION-BENCH（语义验证基准 SVB）
1. **对抗改述**：同义/歧义/否定/嵌套指令集，测 ⟦L⟧ 完备性（是否漏掉危险解释）。
2. **视觉幻觉注入**：在 Isaac Sim 注入不存在物体、错误关系、遮挡，测接地误用率。
3. **澄清压力测试**：追问疲劳、恶意误导回答、快速切换，测等待不变式与递归收敛。
4. **语义-几何错位**：构造「几何 sound 但语义错」的陷阱场景（红杯误认成刀），验证语义证书是否兜住。

## 5. 本轮最大风险

**一句话**：语义鲁棒性定理的可靠性完全押在「⟦L⟧ ⊇ 真实语义」这个文法完备性假设上，而自然语言是开放世界的、有限文法与本体必然漏掉某些危险解释——叠加共形仅保边际覆盖，会形成任何几何证书都无法兜底的**语义盲区**（几何 sound、语义却错）；因此 E96（危险解释漏检）必须设为最高红线，且默认回退到「不在认证文法内就拒绝/追问，绝不自动编译执行」这条永不赌语义的底线。

## 2. 关键算法（伪代码）

### IP-61 IC：欠定编译、合规过滤与语义可行性
```
def compile_instruction(L, persona, ontology):
    phi_core, U = parse_underspecified(L, ontology)   # 指代/位置/力度/时序
    C_cmd      = extract_compliance(L, ontology)       # 不得请求的动作
    U          = apply_persona_prior(U, persona)       # 安全人格→更宽 U
    if violates_compliance(L, C_cmd):                  # 先于规划
        return Refuse(cert=zero_motion_cert()), U
    U = [u for u in U if geometrically_feasible(u)]    # 剔除不可行，不静默放宽
    if len(U) == 0:
        return Refuse(cert=zero_motion_cert()), U
    return (phi_core, U, C_cmd), U
```

### IP-60 SGC：跨模态接地证书与语义租约
```
def certify_grounding(vlm_claims, pointcloud, depth, alpha, scene_id):
    certified = []
    for g in vlm_claims:
        geo_ok = (support(pointcloud, g.pose) >= S_MIN
                  and depth_consistent(depth, g.pose)
                  and relation_verifiable(g.rel, pointcloud))
        conf_ok = g.conf >= THETA_VLM
        conf_ok = conf_ok and (g in conformal_set(scene_id, alpha))  # Mondrian
        if geo_ok and conf_ok:
            certified.append(g)
        else:
            audit_hallucination(g, reason=geo_ok, conf=conf_ok)     # 隔离
    return certified

def semantic_lease(g, t, scene_now):
    mu = L_g * v_scene_bound(scene_now)
    return LeaseSem(conf=g.conf, tau=t, mu=mu, scene_id=scene_now)

def lease_sem_valid(l, theta_sem, t, scene_now):
    return (l.scene_id == scene_now
            and l.conf - l.mu * (t - l.tau) >= theta_sem)
```

### IP-62 CPE：澄清策略、等待不变式与递归回环
```
def choose_clarification(U, persona, I_wait):
    best = None
    for q in candidate_questions(U):
        ig = entropy(U) - conditional_entropy(U, q)
        if ig >= THETA_IG and waiting_invariant_holds(I_wait):
            if best is None or ig > best.ig:
                best = Q(q, ig, style=persona_style(persona, q))
    return best  # None => 不追问，转安全停机或保守执行

def clarify_loop(U, persona, I_wait):
    while len(U) > 1:
        q = choose_clarification(U, persona, I_wait)
        if q is None:
            return safestop()                       # 不能安全等待
        ans = ask_user(q)                           # 冻结/悬停期间保持 I_wait
        (phi_core, U_new, C_cmd), _ = compile_instruction(ans, persona, ONTO)
        if refused(C_cmd):
            return Refuse(zero_motion_cert())
        U = refine(U, U_new)
    return U[0]                                     # 收敛到单点解释
```

### IP-39/51/53 升级：语义条件化规划与监控
```
def semantic_plan(phi_core, U, G_hat, C_global):
    for u in U:                                     # 逐解释检查，非取 argmax
        for g in G_hat:
            if not exists_safe_plan(phi_core & u, g, C_global):
                return ClarifyOrRefuse(u, g)        # 任一解释不安全→不放行
    return safe_plan(phi_core, argmin_risk(U), G_hat)

def car_guard_semantic(e, x, cert, persona, lease_m, lease_s):
    return (car_guard(e, x, cert, persona, lease_m)
            and lease_sem_valid(lease_s, THETA_SEM[e], now(), scene_id(x)))

def semantic_monitor(grounding, pointcloud, depth):
    # 最高关键级：接地-几何一致性的实时复核
    if not geo_consistent(grounding, pointcloud, depth):
        invalidate_semantic_lease(grounding); return DOWNGRADE
    return OK
```

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 文法/本体不完备，⟦L⟧ 漏掉危险解释（语义盲区） | 极高 | E96 最高红线；对抗改述实测 δ_grammar；不在认证文法内 → 拒绝/追问，绝不自动编译 |

## 6. 本轮最大风险

**一句话**：语义鲁棒性定理的可靠性完全押在「⟦L⟧ ⊇ 真实语义」这个文法完备性假设上，而自然语言是开放世界的、有限文法与本体必然漏掉某些危险解释——叠加共形仅保边际覆盖，会形成任何几何证书都无法兜底的**语义盲区**（几何 sound、语义却错）；因此 E96（危险解释漏检）必须设为最高红线，且默认回退到「不在认证文法内就拒绝/追问，绝不自动编译执行」这条永不赌语义的底线。
