# 第 41 轮 · 双灵感落地 v18：异常免疫 × 可信交付（「A-Plane 异常平面」横切层，四层架构 v6）

> 承接第 40 轮（v17：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹，四层架构 v5）。本轮灵感词「UniBot 世界挑战赛 / 异常检测」。这两个词不是「赛事背景 + 一个普通模块」：官方提交仓库 README §6 把「每步响应的时延平滑性」与「返回动作的统计规律性（无异常离群）」明写为**结果可信度依据，并可能与公布成绩一并展示**——也就是说，**组委会本身就在对每一份提交做异常检测**。v17 把热/时延/步数做成三账本，却默认「动作看起来正常」是免费的；而 v17 的 TO 精修与 governor 旋钮切换恰恰可能制造统计异常。v18 因此把「异常」升格为第四本账与一个横切平面（A-Plane）：**对外守护可信度，对内做早期失败检测，向上触发算力分配，向下约束 TO 的常态**。主轴从 v17 的「单位物理成本的得分效率」推进到「**异常可控的可信交付**」。

## 0. 联网核实（先事实后推理；检索口径 2026-11-10，来源链接见产物区 §5）

- **事实 F67（官方可信度条款，github.com/unitreerobotics/unibot_submission README §6，raw 复核，commit `edd0a1c`，2026-08-21；仓库 updated 2026-10-11）**：评测全程逐步调用策略，**每次 `get_action` 的时延与内容都被记录**；提交应保持交互时延平滑稳定，并让返回结果**尽量避免不必要的异常**；组委会在评估可信度时可能综合**每步时延及其波动**与**返回动作的统计规律性**，这些指标**可能与公布成绩一同展示**；因此建议保持每步推理时延稳定、动作格式规范且无异常离群、避免任何导致交互模式不规律的行为。旁证：官方 `/runs.html` 写明「每次运行、每个模型、每个任务」的记录，点击详情可看**完整评测视频**（当前 Coming Soon）。两个关键词是「**不必要**」与「**统计规律性**」：任务内在的抓取闭合、换向、接触冲击是必要事件，不应被当成异常；而离群动作、抖动时延、无规律模式会被外部看见。

- **事实 F68（公开成功示范集，HF collection `unitreerobotics/unibot-v1-challenge-dataset`，API 2026-11-10）**：集合公开列出 **32 个单任务数据集**，全部 `gated:false`、`private:false`、Apache-2.0、LeRobot v3.0、30fps、4 路 640×480 相机（head_stereo_left/right + wrist_left/right）；合计 **33,276 条 episode、18,282,246 帧 ≈ 169.3 小时**，单任务 969–1533 条。任务名含 HangCup、ArrangePlates、ZipUp、FoldTowel、PlugCharger、PlugInEthernet、PourOutMedicine、DisconnectEthernet、SyringeWaterTransfer 等。**对 v17 F61/A33 的修正**：聚合 API/匿名端点会 401，但 32 个任务数据集本身公开可发现、内容可读。**通道诚实**：这些是**成功示范**，没有失败/扰动标签（A41），因此只能做「常态分布」与「成功先验」，不能当异常监督。

- **事实 F69（VLA 失败检测：Hide-and-Seek，arXiv 2605.30834，2026-09-25）**：把 VLA 失败检测表述为**粗监督**问题：只用轨迹级成功/失败标签，通过轨迹间与轨迹内对比学习定位失败动作；结合 conformal prediction 给出准确率-及时性权衡；在 LIBERO、VLABench 与真机上超过最强分类基线最多 **+11.7% bACC**，并比 VLM 运行时监控快 **2000× 以上**。结论：失败信号不必等外部大模型，可从 VLA 轨迹本身以低开销提取。

- **事实 F70（机器人异常检测：RC-NF，CVPR 2026）**：Robot-Conditioned Normalizing Flow，只用**正样本**无监督训练，建模「机器人状态 + 任务相关物体轨迹」的联合密度，推理时用概率密度给异常分；提出 LIBERO-Anomaly-10 基准（Gripper Open / Gripper Slippage / Spatial Misalignment 三类）；较最强基线约 **+8% AUC / +10% AP**，真实部署 **<100ms**，可作为 π0 的 plug-and-play 模块触发 state-level rollback 或 task-level replanning。

- **事实 F71（校准式运行时监控，arXiv 2611.08425 VLA-Tug；arXiv 2604.16677 SentryVLA）**：VLA-Tug 在 VLA 主干潜层上做轻量探针，给出**漏检/误报的校准界**；监督在「失败前片段」上，在同等误报率下早期检测最多 **+30%**，对未见任务的界在 86% 运行中仍有效（基线 ≤21%），并能预测失败模式（top-3 +44%），附 3,180 条标注 episode。SentryVLA 用 conformalized quantile regression 给动作偏差上界 + 潜状态 Mahalanobis 异常分；UR5 真机成功/失败分离 **AUC 0.912**，把工作空间边缘的保护性停机从 20/20 降到 4/20（16/20 提前主动停）。

- **事实 F72（关系化异常，RAFAIL，arXiv 2609.18324，2026-09-16）**：不把 OOD 打在整幅图像上，而是检测**任务相关实体关系**（夹爪-物体、物体-目标）的异常；VLM 离线标注成功示范的任务进度与关系重要性，学习点云关系表示，运行时不用 VLM；无需失败数据，三类真实操作任务 balanced accuracy **73.4%**，优于 OOD/不确定性基线。结论：像素级 OOD 会被背景、光照、干扰物误触发；关系级 OOD 更贴近「任务是否在正常推进」。

- **事实 F73（标签高效的时间戳级监控，arXiv 2609.30715 RoboMonitor；arXiv 2609.04277 FailureSpot）**：RoboMonitor 用动作条件未来特征预测 + 逆动力学 + masked-present 预训练，再做时序 SFT；52 条标注 episode 达到 **93.1% 相位准确率 / 85.9% macro recall**，真实闭环 35/40 无假恢复触发。FailureSpot 用**无标注动作 chunk 的弱信号**（连续 chunk 不一致、冻结/空转、激进随机运动）预训练，再用主动学习选最不确定轨迹做时间戳标注；说明「动作统计异常」本身就是一个便宜且有效的监督源。

- **事实 F74（误报警告：Early Warning Signals for OpenVLA，arXiv 2606.29699，2026-08-13）**：冻结 OpenVLA、取每步一个 MLP 激活训练线性探针，在失败轨迹内部可达 **AUROC 0.972 / AUPRC 0.352**；但同一探针在干净 episode 上平均产生 **3.32 次警告起始**。作者明确结论：**强回顾可分性 ≠ 运行时安静可用**。这是本轮最重要的反面证据：在「步骤分 + 可信度」双重计分的赛事里，误报会直接触发多余重规划，比漏报更贵。

- **事实 F75（校准方法，记忆级，本轮未逐篇 API 复核）**：split conformal prediction 在可交换性下给出边际误报率 ≤ α（Vovk et al., *Algorithmic Learning in a Random World*, 2005）；adaptive conformal inference（ACI）在分布漂移下通过在线更新显著性水平维持长期误差（Gibbs & Candès, NeurIPS 2021）；CUSUM（Page, 1954）给出变化点检测的延迟-阈值权衡。它们不是新工具，但正好对应「漂移下的误报预算」这一核心难题。

- **事实 F76（官方接口复核，F60 仍成立）**：`metadata` 五字段（control_space / obs_delta_indices / image_resize / action_chunk_size / token）；joint 与 ee 互斥；chunk 一次返回 T_a 步顺序执行；N 台测试机、8765 起连续端口、不同端口可能并发、共享后端须每端口 reset/历史隔离；token 握手与每步双校验；每步时延与动作统计规律性会被记录。**A39**：可信度指标的具体聚合权重与「统计规律性」的操作定义未公开；**A40**：官方不提供异常/失败真值标签；**A41**：公开数据只有成功示范；**A42**：在线额外状态（torso/D435/waist 全量）是否可见仍未公开。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（异常检测是「官方已经写进评分表的接口」）**。F67 让我改变了对异常检测的定位：它不是调试工具，而是**外部评分面**。组委会不需要读我们的代码，只要看返回动作的离群率、时延方差、交互模式是否规律，就能给出可信度旁证；而 `/runs.html` 还要公开放完整评测视频。v17 的 IP-50 在追求末端精度时可能解出「统计上不像这个策略会做的动作」，IP-48 在热降额时可能在抓取中途切换 chunk/resize/模型分支，造成动作分布与时延的突变——这些在 v17 里都被当作工程副作用，在 v18 里必须被当作**失分项**。所以第一个结论是：**让输出「看起来正常」不是化妆，而是接口级正确性；但必须由真实执行的平滑性保证，不能只修饰返回数组**（否则就是 reward hacking，且视频会揭穿）。

**直觉 2（异常 = 惊讶 = 该花钱的信号）**。异常本质上是「模型预测与观测不符」——即惊讶。惊讶恰好是决定「要不要调用更贵的东西」的最优统计量：一切正常时继续用便宜的 VLA chunk；只有关系错位、进度停滞、动作离群、潜状态漂移时，才值得调用 TO 精修、LLM 重规划、高分辨率感知或 VLM 复核。这样 A-Plane 就不是第四本独立账，而是 **Δ-Plane 的触发器**：热账本、时延账本、步数账本回答「还能花多少」，异常账本回答「现在值不值得花」。我把这称为「**只在惊讶时花钱**」。它同时解释了为什么 v17 的 governor 需要异常信号：热降额不该在任务正常推进时打断它，而应在异常/段边界处换挡。

**直觉 3（误报是这套系统里最贵的异常）**。F74 的 3.32 次/干净 episode 是一个刺眼的数字：高 AUROC 完全可能伴随高频误报。在步骤分与可信度双计分的赛制下，一次误报 → 一次不必要的重规划/TO → 多走几步、多几次大模型调用、时延方差上升、动作模式更不规律 → 可信度更差 → 更容易被误判。这是一个**正反馈恶化环**。因此本轮的核心困难不是「检测得更准」，而是「**在 5 类泛化轴造成的分布漂移下，把误报控制在可证明的预算内**」：conformal + ACI + 迟滞 + 相位条件 + 代价敏感阈值，一个都不能少。检测器再强，若误报不受控，就不配上场。

**直觉 4（异常要「关系化」，不要「像素化」）**。赛事明确考跨物体、位置、背景、干扰物与人为干扰。像素级 OOD 会在换背景、来人、加干扰物时狂响，而这些大多**不影响任务**；真正该报警的是「夹爪与目标物体的关系错了」「物体不在支撑面上」「目标位置与规划前提不符」。RAFAIL（F72）的关系级 OOD 正好对上：把异常定义在任务相关的实体关系上，还能给出**可归因的异常**（是哪个物体、哪条关系、哪个阶段），从而让 IP-49 做定点修复而不是全局重规划。关系化还顺带解决了「必要异常」问题：抓取闭合、释放、换向是相位事件，不是关系异常。

**直觉 5（TO 与异常检测的张力，是本轮真正的创新点）**。v17 的 TO 用能量/时间/精度三目标精修 VLA 轨迹；但「更准」可能意味着「更不像策略分布」——而这正好撞上 F67 的统计规律性条款与 F70 的密度异常检测。反过来，VLA 在分布内但不够准。我的解法不是二选一，而是 **常态正则轨迹优化（Normality-Regularized TO）**：在 TO 目标里加一个「动作流形约束」——用 33,276 条成功示范（F68）训练动作密度模型，要求精修后的 chunk 落在校准后的高密度球内；精度损失可由「最优解到常态球的距离 × Lipschitz 常数」界定。这样 TO 既提升精度，又不把动作做成离群样本。更微妙的是：当异常分很高时，说明当前场景已偏离示范分布，**常态先验本身失效**，此时应放松常态约束、更多依赖 CBF/MuJoCo 的安全约束——即常态权重 β 应随异常分自适应。这是「分布内信先验、分布外信安全」的原则。

**直觉 6（修剪：异常监控让 v17 的若干装置变成冗余，公开数据让校准第一次可行）**。一旦有了 A-Plane：(a) IP-24 FAILURE-MONITOR 被 IP-51 吸收，不再单独存在；(b) IP-45 的注册/契约/追踪可降 P2，因为 A-Plane 日志 + 单 PolicyService 已提供可观测性；(c) IP-42 跨本体在单一 G1 赛题里边际最低，降 P2；(d) IP-32 语言变体不是本赛题主轴（指令为单 str、全 episode 不变），降 P2；(e) IP-44 的完整三阶段蒸馏简化为 LoRA + RARA。同时，F68 的 33k 成功示范第一次给「常态分布 / 动作流形 / 误报校准」提供了真实数据——v17 的最大风险「p_s 无官方数据源」由此降级为「有成功先验、缺失败标签」。**以删代加，并把数据用在最需要的地方，是本轮的方法论。**

## 2. 灵感词 → 落地线（新增 + 重构 + 修剪登记）

- 「**异常检测**」→ **IP-51 ANOMALY-IMMUNE-MONITOR（AIM，P0 新增）**：四尺度检测器栈——L0 动作统计（chunk 一致性/冻结/离群/NLL）、L1 VLA 潜层校准探针、L2 任务关系 OOD（夹爪-物体-目标）、L3 执行/轨迹失败信号（进度残差/跟踪误差/对比学习）——相位条件融合、conformal+ACI 阈值、迟滞告警、异常归因、每端口隔离；**吸收 IP-24**。
- 「**异常检测 × 可信度**」→ **IP-48 升级为 AΔ-PLANE-GOVERNOR（P0 升级，不新增编号）**：原热/时延/步数三账本 + **异常账本 A(t)** 成为第四本账；异常分作为「算力分层」的门控（VLA → +TO → +LLM 重规划 → +复核/高分辨率）；换挡只在相位边界或异常触发时进行；热降额不再盲切旋钮。
- 「**异常检测 × 轨迹优化**」→ **IP-52 NORMALITY-REGULARIZED-TO（NR-TO，P0 新增，重构 IP-50）**：成功示范训练动作密度模型，TO 目标加分布惩罚与校准常态球约束；给出「精度损失 ≤ L·dist(u*, N_α)」的投影界；β 随异常分自适应（分布内信先验、分布外信安全）。
- 「**UniBot 世界挑战赛**」→ **可信度证书（IP-46 升级）**：把「时延 p99 方差、动作离群率、告警率」写成可监控、可展示的证书，替代 v17 的 μ 分析残余；**IP-25 升级**为时延稳定性 SLO（含漂移检测）；**Runs 透明性**要求「真实执行轨迹的规律性」，禁止只修饰返回数组。
- 升级：**IP-49**（p_s 与失败记忆按相位/异常条件化；图世界模型违规预测作为异常先验；异常归因→定点修复）、**IP-28v2**（CTC 后验提供相位 φ_t）、**IP-30/IP-35**（VLM 复核与 MuJoCo 门改为**按需**，由异常触发，省算力降方差）、**IP-36**（语义关系图供 L2 关系 OOD 与异常归因）、**IP-43**（prosody 平滑作为**真实**动作规律性机制，非化妆）、**IP-21**（单模型旗舰 + 单 PolicyService + A-Plane 调度）。
- 修剪登记：**IP-42 CROSS-EMBODIMENT-MOTION → P2**（单一 G1 + G1/Dex1 公开数据，跨本体无直接得分）；**IP-32 LANG-ROBUST → P2**（指令单 str 全程不变、非赛题主轴）；**IP-45 的注册/契约/追踪 → P2**（保留 gateway/eco-endpoint，A-Plane 日志替代可观测性）；**IP-44 完整三阶段蒸馏 → P1 简化**（LoRA + RARA，MAML 保持 P2）；**IP-24 FAILURE-MONITOR → 合并进 IP-51**。

## 3. 形式化直觉（严格版见产物区 §3）

**定义 29（A-Plane 异常账本与四尺度检测）**：`L_A(t)=(s^act_t,s^lat_t,s^rel_t,s^exe_t,φ_t,a_t,A_t)`，其中 `φ_t` 为 IP-28v2 的相位后验；四个检测器都输出 `[0,1]` 的校准分：`s^act` 为动作 chunk 的统计异常（连续 chunk 不一致、冻结/空转、激进随机、动作密度 NLL、Mahalanobis），`s^lat` 为 VLA 潜层探针分，`s^rel` 为任务关系 OOD 分（实体关系点集），`s^exe` 为执行/轨迹失败分（进度残差、跟踪误差、对比失败信号）。融合 `a_t=F_θ(s_t,φ_t)`，告警 `A_t=1[a_t>ζ_t]`。

**定义 30（相位条件与「必要异常」）**：把常态集按相位条件化 `N_φ={a: phase=φ}`；定义任务内在事件掩码 `m_t`（抓取闭合、释放、换向、接触冲击、段切换），调整分 `ã_t=max(0,a_t−m_t)`。目的：官方只惩罚「**不必要**的异常」，相位条件使告警不被任务内在的离散事件污染；相位越可预测（CTC 后验越尖），条件化收益越大。

**定义 31（漂移下的校准告警）**：给定成功示范的校准集 `D_cal`，split conformal 阈值 `ζ=Q_{1−α}({ã_i}_{i∈D_cal})`，在可交换性下 `P(ã_t>ζ|nominal)≤α`。分布漂移下用 ACI 在线更新显著性：`α_{t+1}=Π_{[α_min,α_max]}(α_t+γ(α−err_t))`，再重算 `ζ_t`；配迟滞（进入阈值 `ζ_hi`、退出阈值 `ζ_lo<ζ_hi`、最小驻留）抑制抖动。**告警不是免费动作**：每次告警都带重规划/TO/时延成本，阈值必须按总成本选，而不是只按 F1。

**定义 32（惊讶门控的算力分层）**：算力层 `M={0:VLA, 1:+TO, 2:+LLM 重规划, 3:+VLM 复核/高分辨率}`；给定调整异常分 `ã_t`、相位、三账本剩余预算 `(B_H,B_L,B_S)`、期望成功率增益 `Δp_m(ã)` 与成本向量 `c_m=(ΔH,ΔL,ΔS)`，选择
`m* = argmax_{m∈M, c_m≤B} [V·Δp_m(ã) − λ_HΔH_m − λ_LΔL_m − λ_SΔS_m]`。
`ã` 作为「需要多少算力」的充分统计量；单调性假设为 `Δp_m` 对 `ã` 非减（越惊讶，越贵的层越值）。这就是 A-Plane 与 Δ-Plane 的接口：**异常账本决定分配，三账本决定上限**。

**定义 33（常态正则 TO）**：用成功示范与策略 rollout 训练条件动作密度 `q_φ(a|o,phase)`，校准常态球 `N_α(o)={u: NLL_φ(u|o)≤q_{1−α}}`；求解
`min_u J_prec(u)+w_E J_energy(u)+w_T T+β·D(p_u‖p_ref)`
s.t. 动力学/限位/自碰/物体包络/夹爪时间窗/pivot 准静态、`NLL_φ(u|o)≤q_{1−α}`、`ã^act(u)≤ζ_act`。
其中 `D` 可取 MMD 或 NLL 惩罚。**投影界**：若 `u*` 为无约束最优、`N_α` 近似闭凸，则约束最优 `u_α=Π_{N_α}(u*)`，且 `J(u_α)−J(u*)≤L·dist(u*,N_α)`——精度损失被「最优解离常态球的距离」控制。**β 自适应**：`ã_t` 高（分布外）时 β↓，因为示范先验失效；此时安全由 CBF/MuJoCo/包络约束兜底。这解决「TO 精修 vs 统计规律性」的张力，也诚实承认常态约束只在分布内有效。

## 4. 关键决断

1. **异常升格**：A(t) 为第四本账，但**不独立决策**；它是算力分层的门控与可信度守卫，预算仍由热/时延/步数三账本封顶。
2. **校准优先于检测力**：先保证漂移下误报 ≤ 预算（conformal+ACI+迟滞+相位条件），再谈 AUROC；误报引发的步数/时延/可信度代价必须进阈值目标。
3. **关系化 + 可归因**：异常必须落到（实体，关系，相位），才能让 IP-49 定点修复；拒绝只会说「这帧不对」的黑箱 OOD。
4. **常态正则 TO**：TO 在分布内受动作流形约束，分布外放松先验、收紧安全；精度与可信度同时优化，且给出可检验的投影界。
5. **诚实规律性**：平滑必须体现在实际执行轨迹（本体感知）而非返回数组；否则是 reward hacking，且 Runs 视频会揭穿。
6. **以删代加**：IP-24 合并、IP-42/32/45 部分/44 简化降级，P0 核心回到 6 项（IP-48/49/50/51/52/21）。

## 5. 本轮最大风险（一句话）

**若 32k 成功示范与评测分布之间存在未建模的偏移（5 类泛化轴），conformal 的交换性假设失效、误报与漏报同时上升：防御侧会因过度约束 TO 而丢精度，进攻侧会因误报触发重规划而反噬步数/时延/可信度——A-Plane 可能从「异常免疫」变成「异常放大器」；必须以 E73–E78 六重守门，并保留「L0 动作统计守卫 + v17 非 A-Plane 架构」的硬回退。**

**算法（监控与校准）**：
```

  φ_t ← IP28v2.phase_posterior()

  if t % k == 0:  s_rel, attribution ← rel_ood(semantic_rel, obs)   # L2 异步
  s_exe ← exec_monitor(proprio, progress, cmd_hist)     # L3

  err_t ← 1[ã_t > ζ_t]  on nominal shadow stream；α_t ← ACI(α_t, err_t, γ)

```

**正确性论证**：

- **P51（误报预算）**：在可交换性下，split conformal 阈值给出 `P(ã_t>ζ|nominal)≤α`；在分布漂移下，ACI 按 `α_{t+1}=Π(α_t+γ(α−err_t))` 更新，长期误差被拉回目标 α（漂移有界时）。因此误报率是**可调预算**，不是事后统计。
- **P52（相位条件增益）**：相位条件把常态集细化为 `N_φ`，并把抓取闭合/释放/换向等内在事件从告警中剔除；当相位对动作分布有预测力（抓取/放置类任务成立），同一误报预算下可提高对真异常的检出。该结论依赖相位后验质量，故设相位置信度门控。
- **P53（误报的步数代价上界）**：若每次误报触发一次重规划，代价 `c_replan` 步，视界 H，则 `E[浪费步数] ≤ α·c_replan·H`。选 α 使 `E[浪费] ≤ ε·E[N]`（如 ε=5%），把「可信度/步骤分」直接写进阈值目标，而不是只优化 F1。
- **P54（归因带来定点修复）**：若关系归因把失败定位到单个子目标/关系，则修复搜索空间从全局计划缩到局部契约，期望修复成本不高于全局重规划；归因错误时回退全局（IP-49 硬逃逸）。

**已知风险**：L2 关系点云需从 RGB 自建（在线无掩码，A44）；相位错误传播；干净场景的告警抖动；每端口并发下的监控状态隔离。缓解：异步/降级到 L0+L3、CTC 置信度、迟滞+最小驻留、独立 state 容器。

### 3.3 IP-48 升级：AΔ-PLANE-GOVERNOR（异常门控的四账本）

**IP 卡片（六字段）**：

- **动机**：v17 的热 governor 只看温度/时延，无法区分「热降额该换挡」与「任务正常推进不该打断」；F67 又要求动作/时延规律。异常账本提供「现在是否值得花算力」与「是否该换挡」的判据。
- **与现有方案差异**：v17 三账本 + 静态旋钮；v18 四账本 + **算力分层** + **相位边界换挡** + **每端口准入**。热/时延/步数回答「还能花多少」，异常回答「值不值得花」。
- **技术可行性**：账本更新 O(1)；算力分层是 4 档枚举；换挡只在相位边界/异常触发时执行，避免抓取中途切换。

### 3.4 IP-52 NORMALITY-REGULARIZED-TO（NR-TO，完整设计）

**IP 卡片（六字段）**：

- **动机**：v17 的 TO 追求末端精度，但可能输出「策略不会做的动作」→ 触碰 F67 的统计规律性条款，并可能进入不安全/不可跟踪区域；F68 提供 33k 成功示范训练动作密度；F70/F71 证明密度/校准监控可用；F74 警告不要用离群动作换精度。
- **与现有方案差异**：不是简单加平滑惩罚（那会牺牲精度且可被「化妆」），而是**分布约束**：精修轨迹必须落在校准后的动作流形内；给出投影界；β 随异常自适应（分布内信先验、分布外信安全）。这是「分布约束轨迹优化」，同时服务精度、可信度与安全。
- **技术可行性**：条件归一化流 NLL <1ms；TO 规模小（14 DoF 双臂+pivot）；约束可用惩罚+投影+拒绝实现；MuJoCo 门按需复核。
- **所需资源**：数据 = 32k 成功示范 + 自采 rollout（动作流形）；算力 = 流前向 <1ms/候选；接口 = 仍输出官方 joint/ee 目标。
- **落地步骤**：① 训练 `q_φ(a|o,phase)`（成功示范+策略 rollout）；② 在留出成功集标定 `q_{1−α}`；③ 把 NLL/MMD 惩罚接入 iLQR；④ β(ã) 调度与投影；⑤ MuJoCo/CBF 门；⑥ E75 验收（精度 vs 离群率）；⑦ 失败回退 β=0。
- **风险**：示范流形本身不够精确→约束压精度（→β 调度+局部放松）；流 OOD→NLL 无意义（→异常高时 β↓）；阈值过紧→TO 无效（→分任务/相位阈值）；TO 超时→VLA 伺服。

**符号表**：

| 符号 | 含义 | 来源 |
|---|---|---|
| `q_φ(a|o,phase)` | 条件动作密度 | 成功示范 + 策略 rollout |
| `N_α(o)` | 校准常态球 | `{u: NLL_φ(u|o)≤q_{1−α}}` |
| `D(p_u‖p_ref)` | 分布差异 | MMD / NLL 惩罚 |
| `β(ã)` | 常态权重 | 分布内高、分布外低 |
| `w_E,w_T,w_P` | 能量/时间/精度权重 | v17 + 热/异常调度 |
| `u*` | 无约束 TO 最优 | iLQR |
| `u_α` | 常态约束最优 | 投影/约束求解 |

**算法**：
```
输入：waypoints(IP-39)、VLA chunk 头 a^VLA_{0:k}、当前状态、包络 𝒪、相位 φ、异常 ã
1. 热启动：init = a^VLA 前 k 步 + 上解时移（IP-43）
2. 求解：
   min_u  ∫ τ̂(u)ᵀRτ̂(u)dt + w_T·T + w_P·‖x(T)−x_goal‖²_W + β(ã)·D(p_u‖p_ref)
   s.t.   ẋ=f_track(x,u)；关节限位；自碰撞(URDF)；d(x,𝒪)≥margin；
          夹爪时间窗；pivot 准静态；NLL_φ(u|o)≤q_{1−α}；ã^act(u)≤ζ_act
3. 求解器：iLQR/DDP + line search；若解落在常态球外→投影回 N_α 或提高 β 重解
4. 校验：MuJoCo(IP-35) 按需过自碰撞/可达/奇异；不过→收缩增益/丢弃
5. 输出：T_a 步官方 joint/ee 目标；IP-33 CBF 步级否决仍最高优先
6. 权重调度：
   - 放置/插入：w_P↑；转移：w_T↑；高热：w_E↑
   - ã 低（分布内）：β↑，信示范流形
   - ã 高（分布外）：β↓，信 CBF/包络/跟踪模型，避免用失效先验压死解
```

**正确性论证**：

- **P55（常态约束的精度损失界）**：设 `J` 在 `N_α` 邻域 L-Lipschitz，`u*` 为无约束最优，`u_α=Π_{N_α}(u*)`。则 `J(u_α)−J(u*)≤L·dist(u*,N_α)`。因此只要存在靠近最优的分布内解，精度损失可被「最优解到动作流形的距离」控制；若最优解远离流形（示范先验失效），损失可能大——这正是 β(ã) 在分布外放松约束的依据。
- **P56（可信度非恶化与反化妆）**：输出守卫拒绝 `ã^act>ζ_act` 的 chunk，使返回动作离群率按构造 ≤ ζ 分位；但要求用**实际执行轨迹**（本体感知）复核，避免只平滑返回数组。若执行轨迹仍异常，则告警并走 IP-49 恢复，而不是继续「看起来正常」。
- **P57（与 IP-33 的组合安全）**：常态约束是软/硬优化项，CBF 是步级否决；即使流形先验失效（分布外），CBF/包络/MuJoCo 仍兜底，故不会因常态约束放松而失去安全性。

```python
# ===== 离线：常态模型与动作流形（IP-51/IP-52 依赖，F68）=====
def build_nominal_models(demos, rollouts):
    flow = train_conditional_flow(demos + rollouts, cond=["obs_emb", "phase"])
    D_cal = score_nominal(flow, heldout_success_demos)     # 按任务/相位分桶
    rel_model = train_relationship_ood(demos, semantic_graph)  # L2
    latent_probe = train_latent_probe(rollouts)                # L1，需自采
    return flow, D_cal, rel_model, latent_probe

# ===== 离线：VT 跟踪模型（E38，沿用 v17）=====
def identify_tracking_model(robot_if):
    traj = collect_excitation_traj(minutes=30)
    return fit_residual_dynamics(URDF_planar, traj)

# ===== 运行期：AIM + AΔ-Plane + NR-TO =====
def act_v18(obs, state):
    # 1. 相位 + 四尺度异常
    phi = state.ctc.phase_posterior(obs)
    s_act = action_stats(state.chunk_hist, state.flow, phi)
    s_lat = state.latent_probe(obs) if state.has_latent else 0.0
    s_rel, attribution = state.rel_ood.maybe_update(obs, state.semantic_rel, t=state.t)
    s_exe = state.exec_monitor(obs, state.progress, state.cmd_hist)
    a = fuse([s_act, s_lat, s_rel, s_exe], phi)
    a_adj = max(0.0, a - intended_mask(phi, state.chunk_hist))
    A = state.aim.update(a_adj, state.port_id)          # 每端口独立 state
    # 2. AΔ-Plane：热/时延/步数 + 异常 → 算力分层（相位边界换挡）
    ledger = state.ledger.update(telemetry(), motor_heat_proxy(state.q_hist),
                                 state.steps, state.latency_ewma, A)
    if state.phase_transition or A.changed:
        state.tier = governor(ledger, a_adj, state.phase)   # 0/1/2/3
    # 3. 规划/修复（异常触发或需要时）
    if state.need_plan or A.level == "Alarm":
        state.plan = step_efficient_planner(obs.language, state.semantic_map,
                                            state.p_s, state.gwm, state.failure_mem,
                                            scenario=state.sigma, anomaly=attribution,
                                            budget=ledger)
    # 4. 常态正则 TO（档≥1 或精度任务）
    if state.tier >= 1 and state.need_refine:
        task = midlevel(state.waypoints, obs, budget=ledger, certify=state.cert_req)
        warm = stream_policy_head(state.plan.skill, obs)
        refined = nr_to(task, warm, flow=state.flow, q_alpha=state.q_alpha,
                        alpha_adj=a_adj, f_track=state.f_track,
                        envelopes=state.semantic_map.objects, phase=phi)
        state.traj = refined if refined is not None else warm
    # 5. 执行 + 守卫（官方 chunk 语义）
    chunk = state.traj.next_chunk(state.T_a)
    if not guard.cbf_check(chunk):                        # IP-33
        chunk = resample_or_fallback(state, r=2)
    return adapt(chunk, control_space=state.control_space)
```

**降级机制 v4（按优先序保底）**：
- **E73 失败（校准失效）** → 仅保留 L0 动作统计守卫 + 固定保守阈值；关闭 L1/L2，L3 退化为进度阈值。
- **E74 失败（门控无增益）** → 异常只做可信度守卫，不做算力分层；算力回到 v17 固定档。

- **E76 失败（误报过高）** → 提高阈值+相位条件+关系 OOD 单独用；关闭像素/潜层检测器。
- **E77 失败（漂移/串扰）** → 关闭 ACI，固定阈值+更短窗口；强制每端口独立进程。
- **六重全败** → 整体回退 v17 非 A-Plane 架构，仅保留「L0 动作统计输出守卫」这一最小可信度措施。

## 6. 清单迭代规则（继承 27–51 + 本轮新增 52–55）

- 继承规则 27–51（通道诚实/映射验证/SLO/fail-safe/灵感-现实校验/单模型合规/步骤分双解释/稠密监督/方法论遗产/元数据重照亮/语言口径分离/摊销/验证器分级/灵感词落地/层级联合规划/跨本体运动/流式韵律/渐进蒸馏/服务化/证书化/组合代数/热预算/期望得分/学习-TO/修剪优先）。
- **52（新增）：异常即信号原则**——异常 = 模型预测与观测不符（惊讶）；必须同时服务三件事：可信度守卫、早期失败检测、算力分层门控；异常信号必须可归因到（实体，关系，相位），否则不得触发高成本动作。
- **53（新增）：误报预算原则**——检测功效服从于漂移下可校准的误报控制；每个告警都要计入步数/时延/热/可信度成本；阈值由总成本选，不由 F1 选；必须有 conformal/ACI/迟滞/相位条件四件套与 L0 硬保底。
- **54（新增）：关系化异常原则**——异常检测优先落在任务相关实体关系上，而非像素/整帧外观；必须区分「必要异常」（抓取/释放/换向/接触）与「不必要异常」；背景/光照/干扰物变化不应触发。
- **55（新增）：常态正则与反化妆原则**——TO 在分布内受校准动作流形约束，分布外放松先验、收紧安全；规律性必须由实际执行轨迹保证，禁止只修饰返回数组；可信度证书只记录可复核的量。

**当前最值得押注**：**IP-51 AIM + IP-52 NR-TO 的组合**。AIM 把官方可信度条款、33k 成功示范的常态先验、早期失败检测与算力门控连成一个闭环；NR-TO 是唯一直接解决「TO 提精度 vs 动作统计规律性」张力的技术点，且可被 E75 一个专项实验快速证实/证伪（先在世界模型/仿真里验证「精度提升且离群率不升」）。若只选一项先做，选 **IP-51 的 L0+L3 最小版**：它最便宜、最贴近 F67、且失败时仍能保住可信度底线。

**本轮最大风险一句话**：若 32k 成功示范与评测分布之间存在未建模的偏移（5 类泛化轴），conformal 的交换性假设失效、误报与漏报同时上升——防御侧因过度约束 TO 而丢精度，进攻侧因误报触发重规划而反噬步数/时延/可信度，A-Plane 可能从「异常免疫」变成「异常放大器」；必须以 E73–E78 六重守门，并保留「L0 动作统计守卫 + v17 非 A-Plane 架构」的硬回退。
