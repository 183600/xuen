# 第 45 轮（承接第 44 轮 v21；本轮灵感：泛化能力 × UniBot世界挑战赛） · Gen-Cert × Score-Cert：把「泛化」升为可证的竞赛元证书，把「世界挑战赛」升为结构化移位算子族与字典序得分证书（v10：v9 + 横向 G 层）

> 承接第 44 轮 v21（Pose-Cert × Data-Cert）。v21 把姿态与校准数据做成了可审计的根信任，但它与整个 v19–v21 证书栈仍共享两个未言明的假设：**(H4a) 部署分布属于校准分布/已观测层**——定义 44 只在 ω∈Ω_obs 签发姿态证书，定义 47 假设加权可交换，定义 48 假设采集只会缩小证书宽度；**(H4b) 优化目标是平均准确率**——E95–E102 全部以「覆盖率/不安全事件」计，从未把竞赛的字典序计分当作一等目标。UniBot 世界挑战赛恰好同时否证二者：官方手册明确 32 项桌面任务、G1 + Dex1、通才单模型、选手自部署 + 官方远程真机 API；每任务 10 次独立运行覆盖 5 类泛化各 2 次——**位置、干扰物、背景、未见物品、人为干扰**；单次最长 180s，超时记失败；榜单按**字典序**（总平均成功率 > 总平均步骤分 > 提交日期）排序。也就是说，竞赛不是 iid 测试集，而是一个**沿五条已知轴结构化移位、按字典序计分、且有隐藏测试**的泛化考试。两个灵感词由此咬合：**泛化能力**要求我们把「泛化」从一句口号升级为**带信封、带退化率、带出界回退的元证书**；**UniBot 世界挑战赛**要求我们把「竞赛」从「多刷数据」升级为**五轴移位算子族 + 字典序得分证书 + 隐藏测试独立性审计**。二者耦合出本轮真正的新问题：**泛化证书需要目标分布的数据来校准，但隐藏测试的数据恰恰不可见；于是我们只能用自己的移位算子去「想象」竞赛——若审计集与公开榜单不独立，系统会沿「自己设计的泛化轴」自我确认（元 Goodhart），在真正的隐藏测试上静默失效。**

## 0. 直觉与动机

**灵感 1（泛化能力 → 不是更高的平均分，而是「证书在移位下仍 sound 且可用」的信封）**
直觉：一个 dev 上 80% 但在背景/未见物体移位下证书静默失效的模型，比一个 60% 但知道自己「不知道」的模型更危险。泛化不是标量，而是**区域**：存在一个信封 G，信封内证书的覆盖/边距/成功率退化有界；信封边界处必须能检测并回退。把「泛化能力」定义成「信封的大小 + 退化率 + 边界检测精度」，而不是「平均成功率」。这直接继承 v21 的核心哲学——不知道时不要猜——只是把「不知道」从姿态层抬到分布层：**我们不知道隐藏测试长什么样，那就把它写成信封外的显式状态，而不是用一个乐观的平均分假装知道。**

**灵感 2（UniBot 世界挑战赛 → 五条泛化轴是结构化移位算子，不是一坨 OOD）**
直觉：位置、干扰物、背景、未见物品、人为干扰，五者的数学性质完全不同：
- 位置是**群作用/nuisance**（可用等变性与规范化吸收，属于最容易形式化的轴）；
- 干扰物是**遮挡/杂波叠加**（感知歧义与碰撞风险同时上升，属于感知-几何耦合轴）；
- 背景是**协变量移位**（可用密度比/加权共形处理，但密度比一旦无界就失效）；
- 未见物品是**概念/支撑移位**（不能靠重加权，只能靠能力组合 + OOD 拒识）；
- 人为干扰是**策略性/对抗移位**（不满足可交换性，必须用鲁棒/博弈/守卫，且人是会主动改变环境的智能体）。
把它们当同一个「OOD 分数」处理，会浪费结构，也会给出错误保证。竞赛的字典序（成功率 > 步骤分 > 提交日期）进一步说明：**成功率的置信下界是主目标，步骤分是次目标，提交日期是第三目标**；任何「提高步骤分但降低成功率」的优化都是负价值。

**灵感 3（耦合 → 用「边际得分/成本」分配泛化预算，但审计必须对隐藏测试保持独立）**
直觉：备赛时间/数据/工程预算有限，每条轴的单位成本带来的字典序得分增量不同。应该按**边际得分/成本**分配，并加「最差轴下界」约束，而不是把预算全押在最容易涨分的轴上（那通常是位置轴，涨分快但对总分的边际贡献会很快饱和）。但分数是在隐藏测试上量的；若用公开 dev 调参，dev 分数会乐观偏置。解法是**预注册泛化声明 + 密封的五轴审计集 + 出信封拒答**：我们可以声明「在信封 G 内、以置信度 1−δ，成功率下界 ≥ S_min」，但必须同时声明「信封外我们不知道」，并让运行时真的回退。泛化不是「更自信」，而是「更诚实地划出自己能力的边界」。

**耦合升级**：GCE（泛化证书引擎）产出五轴移位算子、泛化信封与运行时移位检测；CCO（能力组合器）把 v9 的证书能力编译成可组合契约，用「已知能力重组」应对未见物品；SCC（得分证书控制器）产出字典序得分置信下界与预算分配；MGA（元泛化审计器）做预注册、密封审计与元 Goodhart 检测。架构由 v9 的「姿态根信任 + 数据治理」升级为 v10：**v9 四层不变，外加一个横向的 G 层（泛化元层）**——泛化不另起一条业务流水线，而是贯穿所有层的「信封与预算」。这与 v21 的教训一致：根信任失效必须级联；分布信任失效同样必须级联，而不能局部降级后继续用。

## 1. 形式化定义（增量：定义 50–56）

**定义 50（竞赛移位算子族与移位幅度）**
设基分布 P0 定义在 episode e=(τ,σ,O,λ,π_h) 上：任务 τ、场景 σ、物体集合 O、布局 λ、人类策略 π_h。五轴算子：
- T_pos(g)：g∈SE(3)（桌面任务可退化为 SE(2)），λ ↦ g·λ；
- T_dis(C)：O ↦ O∪C，C~clutter 分布；
- T_bg(b)：σ ↦ σ_b（背景/光照/纹理替换）；
- T_obj(O')：把实例替换为支撑外的 O'（O' ∉ supp(P0)）；
- T_hum(π_h')：π_h ↦ π_h'∈Π_adv（干预/阻挡/移动物体的策略）。
一次移位是词 s = T_{a_k}∘…∘T_{a_1}，所有词构成幺半群 S。移位幅度向量 d(s)=(d_pos,d_dis,d_bg,d_obj,d_hum)，分量分别取 ||g||、遮挡/杂波密度、特征 MMD/FID、OOD/语义距离、干预率或策略 TV。**关键差异**：T_bg 近似协变量移位，T_obj 破坏支撑重叠（概念移位），T_hum 破坏可交换性（策略移位）；后两者不存在无分布假设的有限样本保证，这一点必须在证书里如实写出。

**定义 51（泛化信封与迁移证书）**
对 v9 证书栈 C 与移位 s，定义条件覆盖保持 Cov_C(s)=inf_{ω∈Ω_obs}P(X∈P|ω,s)、最差边距 m_C(s)、成功率 Succ_C(s)。给定容差 ε_cov、θ、S_min，**泛化信封**
G = { s∈S : Cov_C(s) ≥ 1−α_p−ε_cov, m_C(s) ≥ θ, Succ_C(s) ≥ S_min }。
**迁移证书**为二元组 (G, δ_G)，δ_G(s) 是退化界（覆盖/边距/成功率随 d(s) 的下降率）。**可靠性声明**：∀s∈G，v9 的保证在退化 δ_G(s) 内继续成立；∀s∉G，不声明任何保证，必须回退。**诚实条款**：对 T_obj/T_hum，G 是可被密封审计证伪的经验声明，不是定理；运行时用检测器 D 判成员并允许弃权（abstain）。

**定义 52（能力契约与组合泛化）**
能力 c=(pre_c, eff_c, cert_c, G_c, cost_c, gain_c)：前置状态集、效果集、v9 证书、适用信封、成本、期望得分增益。任务 φ 可分解，若存在计划 c_1…c_n 使 pre/eff 链满足目标且 s∈⋂_i G_{c_i}。组合继承**信封交集**与**成本和**。定义**组合泛化间隙** Γ = Succ(信封内组合) − Succ(同任务端到端)。出信封任务只能走：请人/保守探索/拒答。未见物品的处理原则是**按 affordance 重组已知能力**，而不是按语义相似度假装能力相同；affordance 未知就拒答或探索，不幻觉。

**定义 53（字典序得分证书）**
每轴 a 有 n_a 次运行、成功 k_a 次。取单侧 Clopper–Pearson 下界 S_a^- = CP^{-1}(k_a,n_a,δ/5)（5 轴 Bonferroni）。总成功率下界 S^-=(1/5)Σ_a S_a^-（或按任务权重），步骤分下界 E^- 同理。**字典序证书** L=(min_a S_a^-, S^-, E^-)，有效当 min_a S_a^- ≥ S_target。**风险得分** score-at-risk = min_{s∈G} S^-(s)。控制器按字典序最大化 L，而不是最大化均值。每任务只有 10 次运行，方差极大，**必须用 LCB，禁止用点估计决定提交**。

**定义 54（泛化预算分配）**
预算 B，轴 a 的动作集 X_a，成本 c_a(x)，期望边际字典序增益 Δ_a(x)。分配问题：
max_x Lex(min_a S_a^-(x), mean_a S_a^-(x), E^-(x))  s.t. Σ_a c_a(x_a) ≤ B。
Δ 具边际递减（近子模）时用贪心，覆盖型目标有 (1−1/e) 保证；最差轴用注水（water-filling）抬底。**鲁棒版**：把 max 换成 max min_{s∈G}，即在信封内做分布鲁棒分配，避免把预算押在「只在自家仿真有效」的轴上。

**定义 55（隐藏测试独立性与元 Goodhart 界）**
公开 dev 集 D_dev、隐藏测试 H。若策略由 D_dev 选择，则 dev 分数有乐观偏置。**独立性公理**：H ⟂ σ(D_dev, 选择过程)。**预注册**：在看到审计结果前冻结「轴、阈值、协议、声明」。**污染检测**：场景/物体/背景/近重复帧重叠。**元 Goodhart**：若 Δ_dev>0 而 Δ_sealed≤0，判为对公开榜过拟合。有限样本选择偏置约 √(log|Π|/n)（对策略类 Π 做 union bound）。**铁律**：密封审计集永不参与调参，只用于签发/否决声明。

**定义 56（泛化租约与测试时自适应回滚）**
运行时移位检测输出 ŝ_t、OOD 分数与轴标签。泛化租约 ℓ_g=(ŝ_t, margin(ŝ_t,∂G), τ, adapt_budget)。自适应仅在 ŝ_t∈G 且「自适应后 soundness 不降」时允许，且必须在小规模**已认证缓冲**上验证。出信封或自适应违例 → 回滚到保守策略；检测置信度跌破阈值或 OOD 超界 → 租约过期。全程 fail-closed。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-63 GEN-CERT-ENGINE（泛化证书引擎 GCE）
1. **五轴算子库**：位置群作用、干扰物叠加、背景替换、支撑外物体、对抗人类策略；每轴带幅度度量与可组合词表。
2. **信封标定**：在 SCV 中做每轴扫描（位置网格/遮挡率/背景库/未见类别/干扰强度），加真机锚点；测 Cov/margin/success 保持曲线，拟合退化界 δ_G，划出 G 与边界。
3. **运行时移位检测**：单模型约束下用特征密度/能量分数/一致性 + 轴分类器，输出 (axis, magnitude, confidence, abstain)；**弃权是一等输出**。
4. **出信封回退**：保守策略/降速/请人/拒答；绝不「信封外继续认证」。
5. **迁移证书签发**：附假设、密封审计哈希、有效层集与版本号，可回滚。

### 2.2 IP-64 CAPABILITY-COMPOSER（能力组合器 CCO）
1. **能力契约抽取**：从 v9 的几何/抓取/导航/交互技能抽出 pre/eff/cert/envelope/cost。
2. **任务分解与组合**：符号规划 + 学习策略；逐步检查信封与 pre/eff 链，组合信封取交。
3. **未见物品**：已知 affordance 重组；未知 affordance → 探索/拒答，不把「语义相似」当「能力相同」。
4. **出界检测与优雅降级**：组合不可行时回退到更保守的已知能力，而不是硬做。
5. **单模型约束**：组合器是运行时路由器/提示器，不引入第二个模型；所有技能共享同一基础模型，满足赛事「通才单模型」要求。

### 2.3 IP-65 SCORE-CERT-CONTROLLER（得分证书控制器 SCC）
1. **分轴 LCB**：Clopper–Pearson + Bonferroni，10 次运行也不虚报。
2. **字典序证书**：L=(min_a S_a^-, S^-, E^-) 与 score-at-risk。
3. **预算分配**：边际得分/成本、最差轴注水、近子模贪心；明确拒绝「用步骤分换成功率」。
4. **提交调度**：按 LCB 而非点估计决定何时提交/回滚；提交是带不确定性的决策，不是刷榜冲动。
5. **风险敏感**：对信封内最差移位做 CVaR，而不是对均值乐观。

### 2.4 IP-66 META-GEN-AUDITOR（元泛化审计器 MGA）
1. **预注册声明**：轴、阈值、协议、失败判据在看结果前冻结并哈希。
2. **密封五轴审计集**：与采集/调参物理隔离，定期轮换/交换；采集策略不可读。
3. **污染/泄漏检测**：场景、物体、背景、近重复帧重叠；dev 与审计的分布对照。
4. **元 Goodhart 检测**：dev 增益 vs 密封增益，反向即报警；量化选择偏置。
5. **五轴红队**：生成信封边界与组合移位，报告违例与「未知区域」。

## 3. 架构 v10

```
G 层（横向泛化元层，贯穿所有层）:
  IP-63 GCE: 五轴移位算子 → 泛化信封 G + 退化界 δ_G + 运行时检测
  IP-64 CCO: 能力契约 → 任务分解/组合 → 信封交集 → 出界回退
  IP-65 SCC: 分轴 LCB → 字典序得分证书 → 预算分配/提交调度
  IP-66 MGA: 预注册 + 密封审计 + 污染/元Goodhart 检测
      ↑ 只读 v9 全部证书/日志；↓ 只写「信封/预算/回退」，不写穿安全谓词

v9 四层（不变）:
  根信任层: IP-60 PSE 姿态证书 + 姿态租约
  L1 几何/物体/人体 → L2 检索+仲裁 → L3 守卫+规划+监控
  L4 IP-61 DCL 数据闭环 ← IP-62 CCA 覆盖审计

运行期: 轴检测 → 信封判定 → 能力组合 → 得分证书 → 守卫/回退
        信封外 / 检测弃权 / 审计失败 → 保守回退 + 不提交（fail-closed）
```

## 4. 实验设计（E103–E110 硬门槛，承接 E95–E102）

def calibrate_envelope(stack, scv, axes, grid, alpha_p, eps_cov, theta, S_min):
    curves = {a: [] for a in axes}
    for a in axes:
        for mag in grid[a]:
            e = apply_shift(a, mag, scv.sample())
            curves[a].append((mag,
                              stack.conditional_coverage(e),
                              stack.worst_margin(e),
                              stack.success(e)))
    G = {s for s in product_grid(grid)
           if cov(s) >= 1 - alpha_p - eps_cov
           and mar(s) >= theta
           and suc(s) >= S_min}
    return Envelope(G, delta_G=fit_degradation(curves),
                    sealed_hash=audit.hash(), assumptions=axes)

def per_axis_lcb(runs, delta=0.05):
    out, k_axes = {}, len(runs)
    for a, (k, n) in runs.items():
        out[a] = clopper_pearson_lower(k, n, delta / k_axes)   # Bonferroni

def lexicographic_certificate(lcb_success, lcb_step, target):
    L = (min(lcb_success.values()), mean(lcb_success.values()), lcb_step)
    return ScoreCert(L, valid=(L[0] >= target),
                     score_at_risk=min_shift_score(lcb_success, G))

def allocate_budget(axes, budget, G):
    x = {a: 0 for a in axes}
    while budget > 0:
        a = max(axes, key=lambda a: marginal_gain(a, x[a]) / cost(a, x[a]))
        if marginal_gain(a, x[a]) <= 0:
            break
        x[a] += 1
        budget -= cost(a, x[a])
    return waterfill_worst_axis(x, G)   # 保证 min_a S_a^- 不被牺牲

def submit_decision(cert, current_best):
    if not cert.valid:
        return Hold('success_lcb_below_target')   # 不拿成功率换步骤分
    if lex_less(cert.L, current_best.L):
        return Rollback(current_best)
    return Submit(cert)

## 6. 本轮最大风险

**一句话**：泛化信封 G 是在我们自己设计的五轴移位族与公开 dev 上标定的；若隐藏测试产生信封外的移位（或我们没张成的轴组合），证书只对「我们想象中的竞赛」sound，而字典序得分证书可能在公开榜上很漂亮、在隐藏测试上静默失效——因此 E104（信封成员/出界回退）与 E108（隐藏测试独立性/元 Goodhart）必须设为红线，默认回退到「保守策略 + 显式拒答 + 绝不拿成功率下界换步骤分」这条永不自欺的底线。
