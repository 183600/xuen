# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环第 2 轮；本轮灵感：「大语言模型」×「抓取位姿估计」）

> R69 给闭环装上了一张嘴（看/问/触）和一把二分刀（aleatoric / epistemic），但它有一个从未言明的前提：**系统对自己所处的“语义框架”是正确的**——它知道自己看的是杯子而不是刀、知道任务是“倒水”而不是“收纳”、知道“抓对了”意味着什么。R69 的 epistemic 只是“在几个几何上都可行的动作模态里选哪个”，而不是“我对场景的语义解释本身是否成立”。
>
> 「抓取位姿估计」把这个隐藏前提撕开：一个抓取可以**几何上完美、语义上灾难**——抓住刀刃、捏住杯沿、握住易碎接口；而抓取位姿分布又因**物体旋转对称、夹爪翻转、接近轴 SO(2)** 而天然多峰。R69 的轨迹聚类不认识对称性，会把“同一个抓取绕接近轴转 90°”数成两个模态，于是**虚高 epistemic、问一个根本不需要问的问题**；同时它对“语义错配”这一整类失败完全无感。
>
> 「大语言模型」补的正是语义框架，但必须以最克制的方式补：LLM 擅长常识与任务语义（该抓把手、别碰刀刃、保持竖直），不擅长也不可信于毫米级几何。因此本轮的核心纪律是——
> **语言只能“提议”，几何/物理才能“认证”。** LLM 永不直接输出 6-DoF 位姿或控制量；每条语义主张都被编译成一个**可证伪的几何/物理谓词**，并附带**接地义务**（必须由 LLM 没看过的独立证据源确认，或明确标为未接地）。
>
> 核心命题：**把“语义”提升为一等公民，但把它关进可验证的笼子里**：LLM 提议语义框架 → 编译为带接地义务的谓词 → SE(3) 对称商空间上的流匹配生成抓取模态 → 谓词与几何证据共同仲裁 → 在**不可逆承诺边界之前**完成消歧；任何一步不可信，逐指令退化为 R69 的纯几何交互，再退化为 R68 的纯保守。命名 **CLASP-RAS**（Common-sense Language-grounded Affordance-Semantic Prior, Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我抓的这个地方，在语义上真的是我以为的那个东西吗；而这一抓，还收得回来吗**」。

## 0. 直觉与动机

**灵感 1（LLM 是“语义框架提议者”，不是“位姿回归器”）**
直觉：LLM 在抓取里最值钱的能力不是算坐标，而是**常识性的任务-物体-可供性映射**：倒水要抓把手并保持杯口朝上，切菜要避开刃口，插拔要抓壳体而不是线缆。把它直接接到 6-DoF 回归上，是让一个会一本正经胡说八道的模块去碰最不可逆的执行环节。正确姿势是**分层**：LLM 输出**带类型的语义主张**（区域、禁忌、抓取类型、任务约束），每条都写明“我怎么才能被证伪、由哪类证据证伪”；几何/物理层负责把主张编译成谓词并核验。LLM 有“提议权”，没有“认证权”，更没有“执行权”。

**灵感 2（抓取位姿的多峰性有“对称结构”，R69 会多数模态）**
直觉：一个圆柱杯，绕其轴转任意角度都是同一个抓取；一个平行夹爪，从对侧夹和从这侧夹在物理上等价（翻转对称）；对称物体还有镜像等价。R69 在原始 SE(3) 上聚类，会把这些**对称等价**的样本拆成多个“模态”，于是 `H_mode` 虚高、`Δ_min` 虚小，VoI 被高估，系统去追问一个“其实没有歧义”的问题。必须在**商空间 SE(3)/G_sym** 上定义模态、熵与间距：**真正的 epistemic 是“商空间里仍然分开的模态”，不是“样本看起来不一样”**。而且对称群只能**保守地少商**（宁可少合并，不可错合并）：错误地把两个物理上不同的抓取当成对称，会把一个不安全模态藏进安全模态的等价类里——这是本轮最锋利的一处。

**灵感 3（“语义错配”是第三种不确定性，不能塞进 ale 或 epi）**
直觉：R69 只有两种不确定：噪声（ale）与几何多峰（epi）。但“我以为是杯子其实是刀”“任务是倒水却抓了杯沿”“LLM 说这是把手、点云却找不到把手”既不是噪声，也不是“两个都合理的几何动作”。它是一种**语义-几何冲突**：先验与证据在吵架。把它硬塞进 epi 会让系统去“多采几个几何模态”，塞进 ale 会让系统“慢下来”，两者都不对——正确的动作是**诊断冲突类型**：是“框错了”（类别/可供性错，应问人或重感知）还是“位姿错了”（区域对、姿态错，应重采样）。因此定义独立的 `U_sem`，有自己的消解通道。

**灵感 4（抓取是不可逆承诺 → VoI 有“截止时刻”）**
直觉：抓取和 R69 的“看/问”不同——夹爪一合，物体可能已被挤压、已滑落、已碰撞，信息动作的价值窗口就关闭了。R69 的 VoI 是“做事之前先问值不值”，但它没处理**动作的不可逆性**：承诺之后的信息动作任务价值为零、风险为正。所以本轮的闭环必须有一条**承诺边界 τ_c**：所有有意义的消歧都发生在 τ_c 之前；τ_c 之后只剩保持/中止/释放。到点仍未消解，就只能选**最小后悔的保守抓取**（任务无关的稳定抓取或放弃），而不是“先抓了再问”。

**灵感 5（新的攻击面：语义可以被伪造，也可以“共谋”）**
直觉：一旦系统读语义，场景里的文字/标签/二维码、用户指令、物体类别都可能被伪造或注入；LLM 也会幻觉出一个不存在的把手。最危险的失败不是单点幻觉，而是**LLM 与感知的共谋幻觉**：LLM 说“这是把手”，感知也把一块像把手的区域分割出来，几何谓词于是“通过”——三方一致，却是同一个偏见的三次复读。因此接地的定义必须包含**独立性**：用于认证的至少一路证据，必须是 LLM 从未消费过的模态（触觉、本体、力闭合、运动学可行性），否则“已验证”只是给幻觉盖章。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（CLASP-RAS 总览）** CLASP-RAS = (LSP, SGC, SGF, QSD, PBA, ICC, CLASP-WM†)。四不变式：
(i) **继承不变式**：R69 的实时流零学习写操作、交互预算与证据纪律全部继承；
(ii) **提议/认证分离**：LLM 只输出带类型的语义主张，**永不输出位姿、轨迹或控制量**；每条主张必须有接地义务；只有几何/物理核验器能把主张判为 ⊤；
(iii) **独立接地**：任何用于剪枝或提交的语义主张，必须由至少一个 **LLM 未消费过的独立证据源**确认（触觉/本体/力闭合/运动学），否则标记为未接地，不得硬用；
(iv) **承诺前消歧**：信息动作只允许发生在承诺边界 τ_c 之前；τ_c 之后只允许保持/中止/释放；残余 U_epi + U_sem 只能通过保守抓取选择吸收，不得“先抓再问”。

**定义 311（语言语义先验 LSP）** 冻结 LLM 在约束解码下输出结构化元组
P_L = (R_aff, R_forbid, τ_grasp, C_task, ρ, prov)：
- R_aff：语义可抓区域（标签 + 开放词表描述符，如 “handle”“rim”“body”）；
- R_forbid：禁忌区域（刀刃、热源、易碎接口、按钮）；
- τ_grasp ∈ {top, side, pinch, wrap, …} 上的偏好分布；
- C_task：任务约束的**未编译形式**（如 “保持竖直”“不要溢出”“避开接口”）；
- ρ：每条主张的置信度；prov = (模型标识, prompt 哈希, 消费过的模态)。
LSP 是**语义先验**，不是答案：它只改变模态的先验权重与候选集合，不直接决定执行。

**定义 312（接地义务与三值核验 SGC）** 每条主张 c_i 编译为谓词
φ_i : (o_geo, ξ) → {⊤, ⊥, ?}，并附接地义务 gob(c_i) = (所需证据源, 容差)。
记 V_i = φ_i 的核验结果，V = (V_1, …, V_m)。**“?”不是“通过”**：未接地保持未接地。称 c_i 接地 ⇔ V_i ∈ {⊤,⊥} 且证据源满足 gob 的独立性要求。使用规则：只有 ⊤ 主张可**硬剪枝**；⊥ 主张需两路独立核验才可**硬删除**；未接地的 ? 只允许**软降权**，不得删除模态。

**定义 313（SE(3) 接地流匹配 SGF）** 抓取状态 ξ = (R, t, w) ∈ SE(3) × [0, w_max]，增广动作块含抓取位姿与接近轨迹。在黎曼流形上用测地线路径
x_s = exp_{x_0}(s · log_{x_0}(x_1)),  s ∈ [0,1]，
回归切向量：L_SGF = E_{s,x_0,x_1}‖u_θ(x_s, s | z_o, z_L) − log_{x_0}(x_1)‖²_g。
条件 z_L = Encode(P_L) 进入的是**接地门控引导**：引导强度 α_g = κ · GR(P_L)（GR 为语义主张的接地率），未接地语义对采样的影响被压到 ≈0。采样仍用 1–2 步 rectified/Heun，代价与 R69 同阶。

**定义 314（商空间模态分解 QSD）** 设对称群 G_sym ⊆ SE(3)（物体旋转对称 × 夹爪翻转 × 接近轴 SO(2)），商空间 𝒢 = (SE(3) × [0,w_max]) / G_sym，不变度量
d_G(ξ, ξ′) = min_{g ∈ G_sym} d_SE3(ξ, g·ξ′)。
在 𝒢 上聚类 K 个样本得模态 {m_k}、权重 ŵ_k、原型 ξ̄_k、商切空间内协方差 Σ_k；定义 H_mode^G = −Σ ŵ_k log ŵ_k，Δ_min^G 用 d_G。**U_ale、U_epi 一律在 𝒢 上计算**。对称群估计 Ĝ_sym 附置信度；硬规则：**只允许 Ĝ_sym ⊆ G_true（少商）**，绝不允许过商。

**定义 315（抓取语义效用与任务风险）** 对模态 m：
q_geo(m) = 力闭合/Ferrari–Canny ε × 无碰撞 × 运动学可达；
q_sem(m) = P(task-affordance | m, P_L) · ∏_{i: V_i = ⊤} 1[φ_i(m)] —— **只有已接地的 ⊤ 谓词参与乘积**；
J(m) = q_geo(m)·q_sem(m) − λ_s·R_sem-incompat(m) − λ_c·R_collision(m)。
语义效用是**乘性**的：一条已接地的禁忌谓词未过，效用直接归零；未接地主张只能通过先验权重软影响，不能归零。

**定义 316（先验-证据仲裁 PBA）** 由 LSP 得语义模态先验 π_L(m)，由几何得后验 p_geo(m | o)。定义冲突
D_conf = JS(π_L ‖ p_geo)（或 top-mode 上的分歧质量）。
若 D_conf > τ_conf ⇒ U_sem 升高，路由到：(a) 任务意图澄清（问人）；(b) 主动重感知；(c) 纯几何回退。**禁止简单相乘 π_L·p_geo**——那会让一个自信的 LLM 压过几何证据。

**定义 317（语义-几何冲突不确定性 U_sem）** 把冲突分解为两类：
- **框架错误**（类别/可供性本身错）：关于物体身份与可供性的谓词集体失败 ⇒ 应问人或重感知；
- **位姿错误**（区域对、6-DoF 姿态错）：身份谓词通过但轴向/间隙/倾角谓词失败 ⇒ 应重采样或换接近方向。
U_sem 为一等不确定性，不并入 U_epi；只能由证据消解或被保守抓取吸收。

**定义 318（承诺边界与不可逆 VoI ICC）** 承诺边界 τ_c 把回合切成承诺前（任务动作 + 信息动作）与承诺后（仅保持/中止/释放）。定义
VoI_irr(g) = E[L(直接提交)] − E[L(先执行 g 再提交)]，
并要求提交仅当残余风险 ≤ ε_commit。若到 τ_c 仍未消解且预算耗尽 ⇒ 选**最小后悔保守抓取**（任务无关稳定抓取或放弃），禁止把消歧推迟到承诺后。

**定义 319（抓取专用信息动作）** g = (g_gaze, g_probe, g_ask)：
- g_gaze：**下一最佳视角**，降低候选抓取区域的遮挡/位姿 aleatoric，须保持安全距离与无碰撞；
- g_probe：**限力轻触/按压**，估计摩擦、稳定性与力闭合，力矩受限，只减少对材质/滑移的 epistemic；
- g_ask：**任务意图澄清**（“要倒水还是只是搬运？”），只用于框架错误；回答以带来源的证据进入，硬决策仍需独立佐证。
全部信息动作须过 CLASP-WM† 的承诺前认证。

**定义 320（语义先验可信门 SPG）** 以留出集测语义主张校准误差 ece_sem 与接地率 GR 以及冲突率。若 ece_sem > τ_ece 或 GR < τ_gr ⇒ **禁用 LSP 的剪枝/引导**，逐指令退回 R69 纯几何闭环。这是 R69 的 MCG 在语义侧的镜像。

**定义 321（对抗语义干扰 ℰ_sem）** 场景文字/贴纸/二维码的伪指令、指令与标签的提示注入、类别伪造、可供性幻觉、**语义-几何共谋幻觉**、被投毒的人类回答。并入 AIC：ℰ_CLASP = ℰ_FLUID × ℰ_sem。场景文字一律视为**不可信输入**，除非来自认证通道。

**定义 322（证书 J_CLASP）** J_CLASP = (J_FLUID, ece_sem, grounding_rate, conflict_ratio, independent_evidence_hash, llm_prompt_hash, symmetry_group_est, commit_certificate, clasp_ver)。
Valid ⇔ Valid(J_FLUID) ∧ ece_sem ≤ τ_ece ∧ 每条参与提交的语义主张均有独立证据接地 ∧ 提交已通过承诺前认证 ∧ 无承诺后信息动作。

**定义 323（对称群估计与保守性）** 由类别先验 + 点云估计 Ĝ_sym 及置信度；不确定时取**子群**（少商）。若有多个候选对称群，则把“选哪个群”本身当作 epistemic，在候选群上取模态的并集（保守），绝不用并集之外的对称去合并。

**定义 324（任务约束编译 C_task）** 指令 → 类型化约束：朝向（保持竖直：angle(axis, gravity) ≤ θ_max）、容纳（不溢出：搬运中最大倾角）、接触（避开按钮/接口）、时序（先抓把手再倾倒）。每条编译为候选抓取 + 接近前缀上的谓词；**不可验证的约束 ⇒ 弃权或询问**，不得默认满足。

**定义 325（抓取-接近轨迹耦合）** SGF 联合输出（抓取位姿，接近轨迹）；CLASP-WM† 对**到接触为止的整段前缀**认证；提交发生在接触或合爪时刻；承诺后的后缀只允许释放。防止“位姿已认证、接近路径却撞了”的漏洞。

**定义 326（语义空值与 LLM 弃权）** 若类别未知、GR 过低或 LLM 主动弃权，则 P_L = ∅，走纯几何，记录“语义空值”；若 VoI > 成本，可发起一次人类询问。**LLM 应弃权而非幻觉**：弃权是被奖励的行为，不是失败。

**定义 327（严格包含与退化链）** 当 LSP 被禁用、U_sem 未消解、或 SPG 越界时，CLASP 逐指令退化为 R69 FLUID；再当 VoI ≤ 成本时退化为 R68。安全侧永不弱于两层前身，效率收益仅在语义**已接地**时兑现。

## 2. 关键算法骨架

```python
# IP-264 LSP：冻结 LLM 的语义框架提议（约束解码、只出主张不出位姿）
def language_semantic_prior(instruction, category_img, llm):
    schema = {"afford": [...], "forbid": [...], "grasp_type": [...],
              "task_constraints": [...], "confidence": [...], "provenance": {...}}
    P_L = llm.constrained_decode(instruction, category_img, schema)   # 冻结，无梯度
    return P_L

# IP-265 SGC：语义主张 -> 可证伪谓词 -> 三值核验（"?" 不是通过）
def compile_and_check(P_L, o_geo, xi):
    V = []
    for c in P_L.claims:
        phi = compile_predicate(c, o_geo)            # 区域/禁忌/朝向/间隙
        V.append(phi(xi, evidence=independent_sources(c.gob)))  # ⊤/⊥/?
    return V                                          # 只有 ⊤ 可硬剪枝

# IP-266 SGF：SE(3) 测地流匹配（接地门控引导 + 对称商采样）
def sgf_sample(o, z_L, GR, K, N_step=2):
    alpha = kappa * GR                               # 未接地语义 -> 引导≈0
    x = sample_tangent_noise(K, manifold=SE3)
    for i in range(N_step):
        s = i / N_step
        x = exp_map(x, (1.0 / N_step) * u_theta(x, s, z_o, z_L, alpha))
    return [lift_from_quotient(g) for g in x]        # 回到 SE(3) 代表元

# IP-267 QSD：商空间模态分解（绝不硬用过商）
def quotient_decompose(samples, G_hat):
    qs     = [quotient(x, G_hat) for x in samples]     # x ~ g·x
    modes  = cluster_invariant(qs, metric=d_G)
    U_ale  = sum(w[k] * trace(cov_quotient(modes[k])) for k in modes)
    U_epi  = entropy(mode_weights(modes)) * sep_factor(modes, d_G)
    return U_ale, U_epi, modes

# IP-268 PBA：先验-证据仲裁（禁止简单相乘）
def arbitrate(pi_L, p_geo):
    d = jensen_shannon(pi_L, p_geo)
    if d > TAU_CONF:
        kind = "frame" if identity_predicates_fail() else "pose"
        return U_sem(d, kind)                          # frame -> ask; pose -> resample
    return None

# IP-269 ICC：不可逆承诺控制器（承诺前消歧，承诺后只允许释放）
def commit_control(modes, U_epi, U_sem, budget, t, tau_c):
    while t < tau_c and (U_epi + U_sem > TAU_COMMIT) and budget.allow():
        g = mint_choose(modes, budget)                 # R69 MINT 的抓取特化版
        if g is None: break
        modes = update_belief(modes, execute(g))       # 看/触/问，带独立接地
    if U_epi + U_sem > TAU_COMMIT:
        return conservative_grasp(modes)               # 最小后悔，或放弃
    return argmax(J(m) for m in modes)                 # 定义 315

# IP-275 主闭环（继承 R69，只在语义与承诺两处插入新层）
def CLASP_RAS_round(M, obs, instruction):
    if not M.spg.ok():                                 # 语义先验不可信
        return M.fluid_ras_round(obs)                  # 逐指令退化 R69
    P_L = M.lsp(instruction, obs.category_img)
    K   = 1 if M.mode_head(obs.z) < TAU_MODE else 4
    samples = M.sgf.sample(obs, P_L, K)
    U_ale, U_epi, modes = M.qsd.decompose(
        samples, M.sym.estimate(obs))                  # 商空间模态三元组
    V  = M.sgc.check(P_L, obs.geo, M.last_xi)          # 语义谓词核验
    modes = prune_grounded(modes, V, P_L)              # 只剪 ⊤；? 只降权
    U_sem = M.pba.arbitrate(prior_from(P_L), posterior(modes))
    xi = M.icc.commit_control(modes, U_epi, U_sem, M.budget, M.t, M.tau_c)
    cert = M.clasp_wm.certify_commit(xi, obs, wm_preds=...)
    if not cert.ok: xi = M.icc.conservative_grasp(modes)
    M.vqa_s.submit_async(P_L, V, U_sem, cert)          # 语义审计
    return xi, cert, (U_ale, U_epi, U_sem)
```

## 3. 推导

**引理 19（商空间不增漏检，过商会藏险）** 设 G_true 为真实对称群。若用 Ĝ ⊆ G_true 聚类，则被合并的样本在物理上真正等价，可达抓取集合不变，故 H_mode^Ĝ ≤ H_mode（少商只会保留更多模态，不会漏掉真模态）；若 Ĝ ⊋ G_true（过商），则存在物理不同、风险不同的两个抓取被并入同一等价类，理想判别器在该类内无法区分二者，漏检不安全模态的概率随“多出来的对称”单调不降。**故对称估计必须保守少商**。

**引理 20（独立接地的幻觉衰减）** 设备选主张出错事件 H，LLM 与感知共享同一偏见时 P(H) = δ；若要求至少一路**条件独立**于 LLM 的模态证据同意，则在独立性假设 A99 下错误接地率 ≤ δ·ρ_ind（ρ_ind 为独立证据在 H 下误同意的概率，理想情形 ≈ 随机水平）；若独立性不成立（证据仍主要源于同一相机/同一分割器），则无此衰减，为 δ。**系：接地的强度等于证据独立性的强度，而不是“检查过”这个动作本身。**

**引理 21（承诺后信息无价）** 承诺后（合爪/接触之后），信息动作无法在本回合内改变已发生的抓取，其任务 VoI = 0 而物理/损坏风险 ≥ 0；故任何不可逆感知策略都不会把有效消歧排到 τ_c 之后。**系：τ_c 之前的预算是稀缺资源，VoI 应优先分配给“高模态间距 × 高不可逆损失”的冲突。**

**定理 18（CLASP 严格包含 R69 与 R68）** 在 A95–A99 下：SPG 越界、LSP 弃权、U_sem 未消解或 VoI ≤ 成本时，CLASP 逐指令等价于 R69 FLUID（再退化为 R68）；其余情形仅在“语义主张已独立接地”时启用剪枝与引导。故任意状态的期望**物理**风险 ≤ R69，安全侧不让步，效率收益来自已接地的语义剪枝与对称商修正。

**定理 19（提交安全与不可逆一致性）** 若提交仅在 CLASP-WM† 认证（力闭合、接近前缀无碰撞、可达、语义禁忌已接地谓词通过）之后发生，则单次抓取的物理风险 ≤ ε_grasp，且承诺后无信息动作 ⇒ 无“抓后再问”的突变。**但该定理只覆盖物理安全，不覆盖语义正确性**：若语义框架本身被共谋幻觉污染，几何认证可以在错误世界上通过——这正是本轮风险所在。

## 6. 本轮最大风险

**一句话**：CLASP 的整个语义收益押在“接地是独立的”这一假设上——**若 LLM 与感知共享同一偏见（同一相机、同一分割器、同一类别先验），所谓“几何认证”只是在同一个幻觉上盖了第二个章；系统会以“已验证”的姿态合爪，而抓取一旦发生便不可撤销，语义灾难（刀刃、杯沿、易碎接口）在物理上完全合规**——**共谋的“对”，比单独的“错”更危险**。

**次级风险与缓解**：
1. **过商藏险**（把物理不同抓取当对称）→ 保守少商（Ĝ ⊆ G_true）+ 候选群取并集 + E309；
2. **LLM 幻觉可供性** → 提议/认证分离 + “?”不当通过 + SPG 门控 + E301/E308；
3. **提示注入/场景伪文字** → 场景文字视为不可信 + ℰ_sem 对抗训练 + E306；
4. **承诺边界误设**（过早合爪）→ ICC 最小后悔保守抓取 + 引理 21 + E305；
5. **实时预算被 LLM 击穿** → LLM 永远环外、只消费缓存 z_L 与编译谓词 + E313；
6. **语义空值处理不当** → 弃权即回退纯几何，不惩罚弃权 + E312。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** `CLASP-RAS=(LSP,SGC,SGF,QSD,PBA,ICC,CLASP-WM†)`；继承 R69 的零学习写、交互预算、证据纪律；新增：提议/认证分离（LLM 不出位姿）、独立接地（认证须有 LLM 未消费的证据）、承诺前消歧（τ_c 后只允许释放）。

**定义 311（LSP）** 冻结 LLM 约束解码 `P_L`；主张为**类型化语义**而非自由文本：可抓区域、禁忌区域、抓取类型分布、任务约束、置信度与来源。LSP 只改先验与候选集，不直接决定执行。

**定义 312（SGC）** 主张 `c_i ↦ φ_i(o_geo,ξ) ∈ {⊤,⊥,?}`，附 `gob(c_i)=(证据源,容差)`。只有 ⊤ 可硬剪枝；⊥ 需两路独立核验才可硬删；未接地的 ? 只软降权。**“?”不是“通过”。**

**定义 313（SGF）** 在 SE(3) 上用测地线 `x_s=exp_{x_0}(s·log_{x_0}(x_1))` 做流匹配，回归切向量；语言引导强度 `α_g=κ·GR(P_L)`，未接地语义影响≈0；1–2 步采样，代价与 R69 同阶。

**定义 314（QSD）** 商空间 `𝒢=SE(3)×[0,w_max]/G_sym`，不变度量 `d_G=min_{g∈G_sym}d_SE3(ξ,g·ξ′)`；在 𝒢 上聚类得模态、`H_mode^G`、`Δ_min^G`；U_ale/U_epi 一律在 𝒢 上算；**只允许 `Ĝ_sym ⊆ G_true`**。

**定义 315（语义效用）** `q_geo=力闭合×无碰撞×可达`；`q_sem=P(affordance|m,P_L)·∏_{V_i=⊤}1[φ_i(m)]`；`J=q_geo·q_sem−λ_s R_sem−λ_c R_collision`。已接地禁忌未过 ⇒ 效用归零；未接地主张只软影响。

**定义 316–317（PBA 与 U_sem）** 冲突 `D_conf=JS(π_L‖p_geo)`；越界 ⇒ U_sem 升高并分解为**框架错误**（身份/可供性谓词集体失败 → 问人/重感知）或**位姿错误**（身份过、轴向/间隙失败 → 重采样）；禁止 `π_L·p_geo` 简单相乘。

**定义 318–319（ICC 与抓取信息动作）** 承诺边界 τ_c 前允许任务+信息动作，之后仅保持/中止/释放；`VoI_irr` 只奖励承诺前的信息；到点未消解 ⇒ 最小后悔保守抓取。信息动作 = 下一最佳视角 / 限力探针 / 任务意图询问，均过 CLASP-WM† 认证。

**定义 320–321（SPG 与 ℰ_sem）** `ece_sem>τ` 或 `GR<τ_gr` ⇒ 禁用 LSP，逐指令退回 R69。对抗集含伪文字/提示注入/类别伪造/共谋幻觉/投毒回答；场景文字视为不可信。

**定义 322–323（证书与对称保守性）** `J_CLASP` 增加语义校准、接地率、独立证据哈希、对称群估计与承诺证书。对称不确定时取子群；多候选群取模态并集（保守），绝不过商。

**定义 324–327（任务编译 / 轨迹耦合 / 弃权 / 包含）** 任务约束编译为朝向/容纳/接触/时序谓词，不可验证则弃权或询问；SGF 联合认证“位姿+接近前缀”；未知类别或 LLM 弃权 ⇒ 纯几何；LSP 禁用/U_sem 未消解 ⇒ 逐指令退化 R69，再退化 R68。

```python
# IP-264 LSP：只出语义主张，不出位姿
def language_semantic_prior(instruction, img, llm):
    return llm.constrained_decode(instruction, img, SCHEMA)   # 冻结、无梯度

# IP-265 SGC：主张 -> 谓词 -> 三值核验
def compile_and_check(P_L, geo, xi):
    V = []
    for c in P_L.claims:
        phi = compile_predicate(c, geo)
        V.append(phi(xi, evidence=independent_sources(c.gob)))  # ⊤/⊥/?
    return V                                                   # ? ≠ pass

# IP-266 SGF：SE(3) 测地流匹配（接地门控引导）
def sgf_sample(o, z_L, GR, K, N_step=2):
    x, alpha = sample_tangent_noise(K, SE3), kappa * GR
    for i in range(N_step):
        x = exp_map(x, (1.0/N_step) * u_theta(x, i/N_step, o, z_L, alpha))
    return [lift_from_quotient(g) for g in x]

# IP-267 QSD：商空间模态分解
def quotient_decompose(samples, G_hat):
    qs    = [quotient(x, G_hat) for x in samples]
    modes = cluster_invariant(qs, metric=d_G)
    U_ale = sum(w[k]*trace(cov_quotient(modes[k])) for k in modes)
    U_epi = entropy(mode_weights(modes)) * sep_factor(modes, d_G)
    return U_ale, U_epi, modes

# IP-268 PBA：冲突诊断（禁止简单相乘）
def arbitrate(pi_L, p_geo):
    d = jensen_shannon(pi_L, p_geo)
    if d <= TAU_CONF: return None
    return U_sem(d, "frame" if identity_fail() else "pose")    # frame->ask, pose->resample

# IP-269 ICC：承诺前消歧
def commit_control(modes, U_epi, U_sem, budget, t, tau_c):
    while t < tau_c and U_epi + U_sem > TAU_COMMIT and budget.allow():
        g = mint_choose(modes, budget)
        if g is None: break
        modes = update_belief(modes, execute(g))               # 看/触/问 + 独立接地
    return (conservative_grasp(modes) if U_epi + U_sem > TAU_COMMIT
            else argmax(J(m) for m in modes))

# IP-275 主闭环
def CLASP_RAS_round(M, obs, instruction):
    if not M.spg.ok(): return M.fluid_ras_round(obs)           # 退化 R69
    P_L = M.lsp(instruction, obs.img)
    samples = M.sgf.sample(obs, P_L, K=1 if M.mode_head(obs.z) < TAU_MODE else 4)
    U_ale, U_epi, modes = M.qsd.decompose(samples, M.sym.estimate(obs))
    V = M.sgc.check(P_L, obs.geo, M.last_xi)
    modes = prune_grounded(modes, V, P_L)                      # 只剪 ⊤；? 降权
    U_sem = M.pba.arbitrate(prior_from(P_L), posterior(modes))
    xi = M.icc.commit_control(modes, U_epi, U_sem, M.budget, M.t, M.tau_c)
    cert = M.clasp_wm.certify_commit(xi, obs)
    if not cert.ok: xi = M.icc.conservative_grasp(modes)
    M.vqa_s.submit_async(P_L, V, U_sem, cert)
    return xi, cert, (U_ale, U_epi, U_sem)
```

## 4. 推导

**引理 19（商空间不增漏检，过商会藏险）** `Ĝ ⊆ G_true` 时被合并样本物理等价，可达抓取集不变 ⇒ `H_mode^Ĝ ≤ H_mode`；`Ĝ ⊋ G_true`（过商）时存在物理不同、风险不同的抓取落入同一等价类，类内不可分，漏检不安全模态的概率随“多余对称”单调不降。**系：对称估计必须保守少商。**

**引理 20（独立接地的幻觉衰减）** 设共享偏见下语义主张出错概率 δ；若要求至少一路**条件独立**于 LLM 的证据同意（A99），错误接地率 ≤ `δ·ρ_ind`（理想 ρ_ind≈随机）；若独立性不成立（同一相机/同一分割器），无衰减，为 δ。**系：接地强度 = 证据独立性强度，而非“检查过”这一动作。**

**引理 21（承诺后信息无价）** 承诺后信息动作无法改变本回合已发生的抓取，任务 VoI=0 而损坏风险 ≥0；故有效消歧必在 τ_c 前，VoI 优先分配给“高模态间距 × 高不可逆损失”的冲突。

**定理 18（严格包含 R69/R68）** SPG 越界、LSP 弃权、U_sem 未消解或 VoI≤成本时，CLASP 逐指令等价 R69 FLUID（再退化 R68）；仅在语义已独立接地时启用剪枝/引导 ⇒ 期望**物理**风险 ≤ R69，安全侧不让步，效率来自已接地语义与对称商修正。

**定理 19（提交安全与不可逆一致）** 提交仅在 CLASP-WM† 认证（力闭合、接近前缀无碰撞、可达、已接地禁忌谓词通过）后发生 ⇒ 单次抓取物理风险 ≤ ε_grasp，且承诺后无信息动作 ⇒ 无“抓后再问”的突变。**该定理只覆盖物理安全，不覆盖语义正确性**：若语义框架被共谋幻觉污染，几何认证可在错误世界上通过——本轮风险正在此处。

## 7. 本轮最大风险

**一句话**：CLASP 的语义收益全押在“接地是独立的”这一假设上——**若 LLM 与感知共享同一偏见（同一相机、同一分割器、同一类别先验），所谓“几何认证”只是给同一个幻觉盖了第二个章；系统以“已验证”的姿态合爪，而抓取一旦发生便不可撤销，语义灾难（刀刃、杯沿、易碎接口）在物理上完全合规**——**共谋的“对”，比单独的“错”更危险**。

**次级风险与缓解**：过商藏险（保守少商 `Ĝ⊆G_true` + 候选群并集 + E309）；LLM 幻觉可供性（提议/认证分离 + ?≠pass + SPG + E301/E308）；提示注入/场景伪文字（视为不可信 + ℰ_sem + E306）；承诺边界误设（ICC 最小后悔 + 引理 21 + E305）；LLM 击穿实时预算（永远环外 + 缓存谓词 + E313）；语义空值处理（弃权即回退纯几何 + E312）。
