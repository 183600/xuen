# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；本轮灵感：「多机器人协作」×「跌倒恢复」）

> 第 60 轮用 SGEC 把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」闭合成单机器人认知驱动回路。但**两个长期被回避的失效域**尚未进入模型：
> 1. **多机器人协作的因果失序**：EPIR 只保证「单机」EV-exec 的序列-哈希连续性；当 N 台机器人互相依赖（A 递工具给 B、C 为 D 让路），执行证据是**分布式因果图**而非单链——时间戳先后 ≠ 因果先后，单机 seq_id 无法表达跨机 happens-before。
> 2. **跌倒作为「不可回避的中间态」**：SGEC 隐含假设「机器人始终直立可执行」。但真实人形机器人会跌倒；跌倒不是任务终点，而是**执行契约被迫降级、重构、恢复**的中间态。当前框架既无跌倒状态机，也无「跌倒后如何重新进入证据链与任务」的机制；更无「同伴机器人如何安全施救」的协商。

## 0. 直觉与动机

**灵感 1（多机器人协作 → 联邦执行证据 FEE）**
直觉：多机器人系统的「真相」不是某台机器人的日志，而是所有机器人事件的**因果全序的偏序闭包**。把每台机器人看作一个进程、EV-exec 看作事件，用**向量时钟 vc_r** 记录「我见过谁的哪些事件」。关键洞见：**证据的先后必须由 happens-before 定义，而不是墙钟时间戳**——B 的动作若因果依赖 A 的证据，则即使 B 的 timestamp 更早，B 也必须在 A 之后被提交。

**灵感 2（跌倒恢复 → 跌倒即契约重构 FRC）**
直觉：跌倒不是一个需要「绝对避免」的单一事件，而是一段**可分段控制的状态迁移**：稳定→失衡（可救）→受控倒地（保护）→安全卧倒→恢复（坐起/跪起/站起）→再稳定。每个状态有自己的阻抗/力矩/关节安全包络。关键洞见：**把跌倒建模为执行契约的降级-重编译-恢复（degrade→recompile→recover）**，而非执行的终止；保护性倒地优先于「硬撑」，因为硬撑会把可恢复失衡放大为结构损伤。

**灵感 3（协作施救 → 恢复拓扑与恢复权协商 CRT/RAN）**
直觉：一台机器人跌倒时，其余机器人不是旁观者，而是**潜在施救资源与潜在碰撞源**。需要分配角色（Guardian 警戒、Supporter 支撑、Observer 观察、TaskTaker 接任务），并用**安全气泡**把跌倒机器人的恢复扫掠体积围起来。关键洞见：**恢复权必须唯一**（避免两台机器人同时拉扯导致二次伤害），且**恢复动作本身必须被当作新的危险源**纳入安全包络。

**灵感 4（合流 → 协作跌倒恢复闭环 CFRC）**
直觉：FEE 保证「谁在何时因果地做了什么」可被跨机重建；FSM_fall/FRC 保证「跌倒—保护—恢复—再入」的状态与契约连续；CRT/RAN 保证「谁来救、怎么救、救的时候别人在哪」。三者合成闭环：**检测→冻结证据→契约重构→角色协商→安全气泡→执行恢复→证据提交→场景/阻抗重编译→任务再入**。

**灵感 5（预算 → PCE+++++ 的跌倒预算与协作预算）**
直觉：恢复不是免费的。新增 **B_fall**（检测时延、保护能量、恢复能量、恢复时间）与 **B_coord**（通信带宽、共识轮数、协商时延、同伴可用性）。若 B_fall 耗尽 ⇒ 只做「受控缓降 + 安全等待」，不做主动站起；若 B_coord 耗尽 ⇒ 退化为单机自主恢复，不依赖同伴施救。并用 **恢复价值 VOI_rec** 决定「现在恢复 / 等待人类 / 保持安全卧倒」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（联邦执行证据 FEE）** 设机器人集合 R={r₁,...,r_N}。每台机器人维护本地事件日志 E_r：事件 e=(vc, ts, seq, hash, payload)，其中 vc ∈ ℕ^N 为向量时钟。定义因果偏序：
- e → e' ⟺ vc(e) < vc(e')（逐分量 ≤ 且至少一分量 <）
- e ∥ e' ⟺ 二者不可比（并发）
联邦证据图 G_FEE = (∪_r E_r, →)。跨机提交采用**分布式快照（Chandy–Lamport 标记）**：当某检查点 c 被所有存活机器人的 vc 支配，或达到 quorum q，则 c 被全局提交。**因果一致性**要求：若 e → e' 且二者都已提交，则 e 在提交序中先于 e'。

**定义 162（跌倒状态机 FSM_fall）** FSM_fall=(S_fall, O, δ_fall, s₀)。其中：
- 状态 S_fall = {S0 稳定, S1 失衡可救, S2 受控倒地, S3 安全卧倒, S4 恢复中, S5 再稳定, S6 不可恢复}
- 观测量 O = (CoM 位置/速度, ZMP, 足底接触力, IMU 倾角 θ, 关节力矩 τ, 结构损伤信号 dmg)
- 迁移 δ_fall: S×O→S，且每个状态绑定**安全包络** κ(s)=(K_p, K_d, F_max, τ_max, q_min, q_max)
- 保护性倒地：在 S2 用柔顺控制与关节折叠最小化冲击能量 E_impact=∫‖F(t)‖dt，s.t. 关节限位与结构应力约束

**定义 163（跌倒契约重构 FRC）** 跌倒事件触发契约重构算子 FRC(C_task, s_fall)：
- **挂起**：C_task → suspended，冻结其探针预算 B_probe
- **重编译**：生成恢复契约 C_rec=(recovery_traj, impedance_schedule, energy_budget, time_budget)，并取 κ(S4) 为恢复安全包络
- **再入**：到达 S5 后，用场景先验（SSM）+ 后跌倒信任折损 γ_fall 重新编译 C_task'，满足 SIC_valid 方可再入

**定义 164（协作恢复拓扑 CRT 与恢复权协商 RAN）** 给定可用机器人 A⊆R、跌倒者 f、角色集 Role={Guardian, Supporter, Observer, TaskTaker}：
- **角色效用**：U(role,r)=α·cap_match(role,r) − β·d(r,f) − γ·risk(r,f) − δ·cost(r)
- **分配**：分布式拍卖最大化 Σ_{(role,r)∈Match} U(role,r)，s.t. 每台机器人至多一角色（多人支撑需显式声明）
- **恢复权**：RAN 以能力-邻近加权选举唯一 leader ℓ(f)；leader 持有恢复权，其余为辅助/警戒；leader 失联超过 τ_takeover 才允许接管（防分裂脑）
- **安全气泡**：Bubble(f)=ConvHull(f 的恢复扫掠体积)⊕ε；所有非施救机器人须满足 d(r, Bubble) ≥ d_safe

**定义 165（协作跌倒恢复闭环 CFRC）** 算子 CFRC({M_r}, fall_event, task)：
```
① FSM_fall: 各机更新 δ_fall；确定跌倒者 f 与状态 s_fall
② FRC: suspend C_task(f)；编译 C_rec(f)；S2 保护性倒地
③ FEE: f 广播 fall_event（带 vc、seq、hash）；各机冻结受影响证据切片
④ CRT/RAN: 分布式拍卖分配角色；选举唯一恢复权 leader ℓ(f)
⑤ Bubble: 计算恢复扫掠体积；非施救机进入警戒/避让位姿
⑥ Recover: ℓ(f) 执行 C_rec（自主站起或同伴支撑）；遥测→FEE
⑦ Commit: 恢复证据跨机因果提交；更新 dmg 与 γ_fall
⑧ Recompile: SSM 重识别场景；EEIS 重编译 K_safe；SIC 校验
⑨ Re-enter: TaskTaker 承接原任务；通过 S5 ∧ SIC_valid ∧ FEE consistent 后恢复任务
⑩ Return (recovered?, roles, leader, evidence_commit, C_task')
```

**定义 166（恢复价值 VOI_rec）** 对跌倒者 f：
```
VOI_rec = P(success | C_rec, B_fall, B_coord)·(V_task_resume − E_damage)
          − cost_energy − cost_opportunity − λ·P(secondary_fall)·E_secondary
```
决策：VOI_rec>0 且 B_fall/B_coord 充足 ⇒ 主动恢复；VOI_rec≤0 且无同伴 ⇒ 安全卧倒等待人类；leader 不可用 ⇒ 单机或等待。

**定义 167（跌倒预算 B_fall 与协作预算 B_coord，PCE+++++）**
- B_fall=(detection_latency, protective_energy, recovery_energy, recovery_time)
- B_coord=(comm_bw, consensus_rounds, negotiation_latency, peer_availability)
- 降级：B_fall 耗尽 ⇒ 只做受控缓降/安全卧倒，禁止主动站起；B_coord 耗尽 ⇒ 单机自主恢复；两者皆耗尽 ⇒ 安全卧倒 + 呼救
- VOI_cog+ = VOI_cog − λ_fall·cost_fall − λ_coord·cost_coord

**定义 168（跌倒后信任折损 PFT 与再入准入）** 跌倒/损伤后对机器人 r 的信任与先验折损：
- trust_r ← trust_r·(1 − α_fall·dmg_r)，其中 dmg_r∈[0,1]
- 后验置信折损：scene_conf_r ← scene_conf_r·(1 − β_fall·dmg_r)
- **再入准入**：Reenter(r) = [FSM_fall=S5] ∧ SIC_valid ∧ (FEE 因果一致) ∧ (trust_r ≥ τ_trust) ∧ (VOI_rec 允许)
- 不满足则保持 S3 安全卧倒并转交任务，禁止带伤再入

### IP-161 FEE（联邦执行证据）

```python
class FederatedEvidence:
    def __init__(self, robot_id, n_robots):
        self.id = robot_id
        self.vc = [0] * n_robots          # 向量时钟
        self.log = []                     # 本地事件
        self.committed = 0

    def local_event(self, payload):
        self.vc[self.id] += 1
        e = Event(vc=tuple(self.vc), ts=time.time(),
                  seq=len(self.log), hash=sha256(payload), payload=payload)
        self.log.append(e)
        return e

    def on_recv(self, e):
        self.vc = [max(a, b) for a, b in zip(self.vc, e.vc)]
        self.vc[self.id] += 1
        self.log.append(e)

    def happens_before(self, e1, e2):
        return all(a <= b for a, b in zip(e1.vc, e2.vc)) and e1.vc != e2.vc

    def commit(self, checkpoint, quorum):
        witnesses = sum(1 for r in checkpoint.acks if r)
        if witnesses >= quorum:
            self.committed = max(self.committed, checkpoint.seq)
```

```python
class FallStateMachine:
    ENVELOPE = {
        'S0': dict(Kp=1.0, Kd=1.0, Fmax=1.0),
        'S1': dict(Kp=0.8, Kd=1.4, Fmax=0.9),
        'S2': dict(Kp=0.2, Kd=0.3, Fmax=0.6),   # 保护性柔顺倒地
        'S3': dict(Kp=0.1, Kd=0.5, Fmax=0.4),   # 安全卧倒
        'S4': dict(Kp=0.6, Kd=1.2, Fmax=0.7),   # 恢复
        'S5': dict(Kp=1.0, Kd=1.0, Fmax=1.0),
    }
    def step(self, obs):
        s = self.state
        if s == 'S0' and self._imbalance(obs): return 'S1'
        if s == 'S1' and not self._recoverable(obs): return 'S2'
        if s == 'S2' and self._grounded(obs): return 'S3'
        if s == 'S3' and self._clearance_ok(obs): return 'S4'
        if s == 'S4' and self._upright(obs): return 'S5'
        if s in ('S1', 'S2') and self._damage(obs) > dmg_max: return 'S6'
        return s

    def protect(self):
        K = self.ENVELOPE['S2']
        fold_joints_safely(tau_max=K['Fmax'])
        apply_compliance(K['Kp'], K['Kd'])
        return minimize_impact_energy()

def fall_contract_recompile(task_contract, s_fall):
```

### IP-164 CRT/RAN（恢复拓扑与恢复权协商）

```python
def negotiate_recovery(robots, faller, roles):
    bids = []
    for r in robots:
        if r.id == faller.id or r.state != 'available':
            continue
        for role in roles:
            u = (alpha * capability_match(role, r)
                 - beta * dist(r, faller)
                 - gamma * risk(r, faller)
                 - delta * r.cost)
            bids.append((u, role, r))
    bids.sort(reverse=True, key=lambda b: b[0])
    assignment, used_r, used_role = {}, set(), set()
    for u, role, r in bids:                 # 贪心一致性拍卖
        if r.id in used_r or role in used_role:
            continue
        assignment[role] = r
        used_r.add(r.id)
        used_role.add(role)
    leader = elect_leader(robots, faller)   # 能力-邻近加权唯一 leader
    bubble = swept_volume(faller.recovery_plan) + epsilon
    return assignment, leader, bubble
```

```python
def collaborative_fall_recovery(robots, faller, task):
```

### IP-166/167 VOI_rec 与预算（PCE+++++）

```python
class FallBudget:
    def __init__(self, det_latency=0.1, prot_energy=50.0,
                 rec_energy=200.0, rec_time=8.0,
                 comm_bw=1.0, consensus_rounds=5,
                 neg_latency=0.5, peers=1):
        self.B_fall = dict(det=det_latency, prot=prot_energy,
                           rec=rec_energy, time=rec_time)
        self.B_coord = dict(bw=comm_bw, rounds=consensus_rounds,
                            lat=neg_latency, peers=peers)

    def recovery_allowed(self, used):
        return (used.get('energy', 0) < self.B_fall['rec'] and
                self.B_coord['peers'] > 0)

def voI_recovery(p_success, v_resume, e_damage, cost_e, cost_opp,
                 p_secondary, e_secondary, lam=1.0):
    return (p_success * (v_resume - e_damage)
            - cost_e - cost_opp
            - lam * p_secondary * e_secondary)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FEE | O(N) 向量时钟比较/事件 | O(Σ\|E_r\|) | 因果一致性；跨机提交无逆序 |
| FSM_fall | O(1)/周期 | O(1) | 检测时延 ≤ δ_fall；保护性倒地冲击能量降幅 |
| FRC | O(1) 契约重编译 | O(1) | 恢复包络可行；再入前 SIC 校验 |
| CRT/RAN | O(\|R\|·\|Role\| log) 拍卖 | O(\|R\|) | 唯一恢复权；无分裂脑；安全气泡硬约束 |
| CFRC | O(闭环) | 复用 | 无碰撞恢复 + 因果证据提交 |

**正确性定理（CFRC）**：假设 A66–A70 成立。
- **(A66)** FEE：向量时钟 + 哈希链；消息丢失由 EPIR 影子副本恢复，因果提交满足偏序。
- **(A67)** FSM_fall：观测量 O 为状态充分统计量，δ_fall 有界。
- **(A68)** FRC：C_rec 在关节/力矩/能量约束内可行，再入重编译 K_safe 非空。
- **(A69)** CRT/RAN：分布式拍卖有限轮收敛；leader 唯一（存活多数下）。
- **(A70)** PCE+++++：B_fall/B_coord 单调消耗，耗尽触发安全策略。

则：
1. **证据因果性**：若 e→e' 且均提交，则提交序保持 happens-before；跨机证据链不因消息乱序而断裂。
2. **保护优先性**：δ_fall ≤ δ_max ⇒ 冲击能量 E_impact 较无保护下降（目标 ≥ 30%）。
3. **施救安全无碰**：安全气泡不变式 d(r,Bubble) ≥ d_safe 在恢复全程成立。
4. **单一恢复权**：存活多数下无两个 leader 同时驱动恢复（无分裂脑）。
5. **再入安全**：仅当 S5 ∧ SIC_valid ∧ FEE 一致 ∧ trust ≥ τ_trust 才允许再入，否则任务转交。

## 5. 本轮最大风险

**一句话**：最大风险是「跌倒检测延迟/误判」与「恢复权协商分裂」叠加——恢复动作本身成为新的危险源，可能把一次可恢复跌倒放大为二次跌倒或同伴碰撞；必须以「保护性倒地优先于主动恢复」「安全气泡硬约束」「唯一恢复权 + 超时接管」「VOI_rec ≤ 0 时安全卧倒/呼救」四重护栏，确保恢复过程从不超过安全包络。

## 2. 关键算法伪代码

### IP-161 FEE（联邦执行证据）

```python
class FederatedEvidence:
    def __init__(self, robot_id, n_robots):
        self.id = robot_id
        self.vc = [0] * n_robots
        self.log = []
        self.committed = 0

    def local_event(self, payload):
        self.vc[self.id] += 1
        e = Event(vc=tuple(self.vc), ts=time.time(),
                  seq=len(self.log), hash=sha256(payload), payload=payload)
        self.log.append(e)
        return e

    def on_recv(self, e):
        self.vc = [max(a, b) for a, b in zip(self.vc, e.vc)]
        self.vc[self.id] += 1
        self.log.append(e)

    def happens_before(self, e1, e2):
        return all(a <= b for a, b in zip(e1.vc, e2.vc)) and e1.vc != e2.vc

    def commit(self, checkpoint, quorum):
        witnesses = sum(1 for r in checkpoint.acks if r)
        if witnesses >= quorum:
            self.committed = max(self.committed, checkpoint.seq)
```

```python
class FallStateMachine:
    ENVELOPE = {
        'S0': dict(Kp=1.0, Kd=1.0, Fmax=1.0),
        'S1': dict(Kp=0.8, Kd=1.4, Fmax=0.9),
        'S2': dict(Kp=0.2, Kd=0.3, Fmax=0.6),   # 保护性柔顺倒地
        'S3': dict(Kp=0.1, Kd=0.5, Fmax=0.4),   # 安全卧倒
        'S4': dict(Kp=0.6, Kd=1.2, Fmax=0.7),   # 恢复
        'S5': dict(Kp=1.0, Kd=1.0, Fmax=1.0),
    }
    def step(self, obs):
        s = self.state
        if s == 'S0' and self._imbalance(obs): return 'S1'
        if s == 'S1' and not self._recoverable(obs): return 'S2'
        if s == 'S2' and self._grounded(obs): return 'S3'
        if s == 'S3' and self._clearance_ok(obs): return 'S4'
        if s == 'S4' and self._upright(obs): return 'S5'
        if s in ('S1', 'S2') and self._damage(obs) > dmg_max: return 'S6'
        return s

    def protect(self):
        K = self.ENVELOPE['S2']
        fold_joints_safely(tau_max=K['Fmax'])
        apply_compliance(K['Kp'], K['Kd'])
        return minimize_impact_energy()
```

### IP-164 CRT/RAN（恢复拓扑与恢复权协商）

```python
def negotiate_recovery(robots, faller, roles):
    bids = []
    for r in robots:
        if r.id == faller.id or r.state != 'available':
            continue
        for role in roles:
            u = (alpha * capability_match(role, r)
                 - beta * dist(r, faller)
                 - gamma * risk(r, faller)
                 - delta * r.cost)
            bids.append((u, role, r))
    bids.sort(reverse=True, key=lambda b: b[0])
    assignment, used_r, used_role = {}, set(), set()
    for u, role, r in bids:
        if r.id in used_r or role in used_role:
            continue
        assignment[role] = r
        used_r.add(r.id)
        used_role.add(role)
    leader = elect_leader(robots, faller)
    bubble = swept_volume(faller.recovery_plan) + epsilon
    return assignment, leader, bubble
```

### IP-165 CFRC（协作跌倒恢复闭环）

```python
def collaborative_fall_recovery(robots, faller, task):
    fs = faller.fsm
    fs.step(faller.telemetry)
    if fs.state in ('S0', 'S5'):
        return None
    frc = fall_contract_recompile(task, fs.state)
    ev = faller.fee.local_event({'fall': fs.state, 'plan': frc})
    broadcast(ev)
    roles, leader, bubble = negotiate_recovery(
        robots, faller, ['Guardian', 'Supporter', 'Observer', 'TaskTaker'])
    enforce_safety_bubble(robots, bubble)
    executed = leader.execute(frc)
    if not executed and fs.state == 'S3':
        return safe_wait_or_call_human(faller)
    commit_evidence(faller.fee, roles)
    if fs.state == 'S5':
        resample_scene(faller)
        recompile_impedance(faller)
        if not reenter_admitted(faller):
            transfer_task(roles['TaskTaker'], task)
            return 'handover'
        return resume_task(task, roles)
    return 'recovering'
```

### IP-166/167 VOI_rec 与预算（PCE+++++）

```python
class FallBudget:
    def __init__(self, det_latency=0.1, prot_energy=50.0,
                 rec_energy=200.0, rec_time=8.0,
                 comm_bw=1.0, consensus_rounds=5,
                 neg_latency=0.5, peers=1):
        self.B_fall = dict(det=det_latency, prot=prot_energy,
                           rec=rec_energy, time=rec_time)
        self.B_coord = dict(bw=comm_bw, rounds=consensus_rounds,
                            lat=neg_latency, peers=peers)

    def recovery_allowed(self, used):
        return (used.get('energy', 0) < self.B_fall['rec'] and
                self.B_coord['peers'] > 0)

def voI_recovery(p_success, v_resume, e_damage, cost_e, cost_opp,
                 p_secondary, e_secondary, lam=1.0):
    return (p_success * (v_resume - e_damage)
            - cost_e - cost_opp
            - lam * p_secondary * e_secondary)
```

### IP-168 PFT（跌倒后信任与再入）

```python
def post_fall_update(robot, dmg, alpha_fall=0.5, beta_fall=0.3):
    robot.trust *= (1 - alpha_fall * dmg)
    robot.scene_conf *= (1 - beta_fall * dmg)
    return robot.trust, robot.scene_conf

def reenter_admitted(robot, sic_valid, fee_consistent, tau_trust=0.7):
    return (robot.fsm.state == 'S5'
            and sic_valid
            and fee_consistent
            and robot.trust >= tau_trust)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |

**正确性定理（CFRC）**：若 A66–A70 成立，则：
1. FEE 因果提交保持 happens-before ⇒ 跨机证据链完整率 ≥ 99.5%。
2. FSM_fall 检测时延 ≤ δ_fall ⇒ 保护性倒地冲击能量较无保护下降 ≥ 30%。
3. 安全气泡不变式成立 ⇒ 非施救机对恢复扫掠体积保持 d_safe，恢复全程无碰撞。
4. RAN 唯一 leader（存活多数）⇒ 无分裂脑、无双向拉扯式二次伤害。
5. Reenter=真 才允许再入 ⇒ 带伤/低信任机器人不进入任务执行，任务可安全转交。
