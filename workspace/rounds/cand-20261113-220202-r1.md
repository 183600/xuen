# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环第 2 轮；本轮灵感：「数据集构建」×「关节空间控制」）

> 第 68 轮把标定升为一等公民，教会系统问「我的测量还准吗」。但它留下两个连体盲点，恰好是 R65–R68 全部安全论证的共同边界：
>
> **盲点 A（实验盲点）**：所有标定与故障判据都建立在「已采到的数据」上，而数据是被动采集的。若轨迹从未激励某个关节/某个负载，某些标定参数与故障方向在信息论上**不可辨识**——此时 EKF 的 U(ĉ) 再小也只代表「对错误的参数很自信」（先验收缩会伪造低不确定度）。R68 自陈的最大风险（缓变故障被标定吸收）本质不是滤波器不够快，而是**系统从未做过能区分漂移与缓变故障的实验**。
>
> **盲点 B（执行盲点）**：R65–R68 的证书全部落在任务空间/观测空间，而执行发生在关节空间。任务空间里安全的前缀，提升到关节空间可能穿过奇异点、撞关节限位、或超出力矩包络。更关键：冗余零空间既是风险来源，也是**免费的实验自由度**——不改变末端输出的信息采集通道。
>
> 核心命题：
>
> **把「数据集」从被动日志升级为主动实验，把「关节空间」从执行细节升级为证书的一等维度；用双控制（dual control）在「为安全的控制」与「为可辨识性的激励」之间做显式折中——JEDI-RAS（Joint-space Excitation & Dataset Identifiability）。**
>
> 一句话定位：R68 问「我的测量还准吗」，R69 问「**我做的实验足以知道吗**」——测量是否可信不是传感器的属性，而是 (轨迹, 数据集) 对的属性。系统不再只能因不确定而退缩，而是获得一条**在安全预算内主动降低不确定度**的通道。

## 0. 直觉与动机

**灵感 1（数据集构建 → 数据集是实验，不是日志）**
直觉：工程上把「补数据」当成多采一点日志，但被动日志有三个内生偏差：选择偏差（控制器永远走同一条熟路）、混杂（构型 q 与负载、与故障同时变化，无法分离）、自确认（策略产生的数据又用来认证同一策略）。数据集构建的正确姿势是**干预**：主动把系统推到能区分假设的构型与负载上。经典工具现成——Fisher 信息、D-最优实验设计、持续激励（persistent excitation）、覆盖度（ε-net）。关键不是「数据更多」，而是「数据被设计得能让参数可辨识」。

**灵感 2（关节空间控制 → 缺失的执行层与免费的信息通道）**
直觉：任务空间证书（末端安全、风险阈值）与关节空间现实（奇异、限位、力矩、自碰撞）之间隔着一个多对一的映射，多对一意味着**冗余**：q̇ = J⁺ẋ + (I − J⁺J) q̇₀。末端不动的零空间运动，对任务是"隐形"的，对辨识是"可见"的——这是免费的激励通道。但它同时是免费的风险通道（零空间漂移、自碰撞、关节缠绕）。所以关节空间必须既被用来采集信息，又被独立认证。

**灵感 3（双控制 → 从「遇不确定就退」到「花风险买信息」）**
直觉：Feldbaum 的双控制（dual control）早就指出：控制与辨识耦合，最优控制会主动"试探"。R68 的 U(ĉ) 只能触发收缩（λ 升高、k 变短）——这是纯被动。JEDI 增加一个显式决策：**当降低 U 的期望安全收益 > 激励本身的瞬时风险时，主动做一次小型激励实验**。这把 R68 只能"等漂移变清楚"的被动，变成"设计实验让它变清楚"的主动。约束是硬的：激励附加风险 ≤ ε_exc，占空比 ≤ ρ_exc，且只在关节安全裕度充足时执行。

**灵感 4（合流 → 直接攻克 R68 最大风险：缓变故障）**
直觉：漂移是**构型不变**的系统性偏置；缓变故障（渐进老化、慢泄漏、缓慢松动）往往**构型/负载相关**。被动地在同一批构型里看，二者同向漂移、不可分；主动走遍「q × 负载」网格，漂移被共同模减掉，只剩故障的构型依赖签名——用 Schur 补投影后的**条件 Fisher 信息**度量可分性。这就是对 R68"标定能力越强、缓变故障越隐形"的解药：不是把标定变慢，而是**做能打破简并的实验**。代价是引入了它的对偶风险（见第 6 节）。

**灵感 5（JEDI-RAS 组件）**
1. **JOC Joint-space Observability Certificate**：关节裕度（奇异/限位/力矩/自碰撞/速度）+ 联合 FIM，输出可辨识方向与 U_id；
2. **DCE Dual-Control Excitation scheduler**：价值-风险比触发，带迟滞与全局预算；
3. **ADC Active Dataset Constructor**：激励原语库 + D-最优 + 覆盖约束，产出带 (info, risk, config) 标签的 episode；
4. **NSX Null-Space Excitation + JSL Joint-Space Lifting**：零空间注入激励，QP 把任务证书"提升"为关节证书；
5. **SEP/IVI Separability & Instrumental-Variable Identifiability**：慢故障-漂移可分性 + 用已知激励作工具变量破除数据自确认；
6. **IER/J_JEDI/Pipeline**：U_eff 重参数化所有阈值，证书加关节/数据集/IV 三项，闭环按"利用-激励"双模运行；
7. **RAS-WM†† 继承核**：CALM-RAS 全保留，只是把 U 换成 U_eff、把任务前缀换成 min(k_task, k_joint)。

## 1. 形式化定义（增量：定义 293–309）

**定义 293（JEDI-RAS 总览）** JEDI-RAS = (JOC, DCE, ADC, NSX, SEP, IVI, JSL, IER, RAS-WM††)。三不变式：
(i) **可辨识性优先**：任何证书必须携带累积信息矩阵 I_t 与 U_id；阈值一律用 U_eff = U(ĉ) + γ_id·U_id 而非 U(ĉ)；
(ii) **关节可实现性**：任务空间认证前缀 k 必须存在关节实现 q_{1:k} 且 JOC ≥ 0，否则截断为 k_joint；
(iii) **激励预算守恒**：单个激励 episode 附加风险 ≤ ε_exc，长期占空比 ≤ ρ_exc，且仅在关节安全裕度 h ≥ h_min 时允许激励。

**定义 294（联合参数与 Fisher 信息）** θ = (c, f) ∈ ℝ^{d_θ}，c 为定义 278 的 12 维标定潜变量，f 为故障参数。观测模型 o_t = h(q_t, τ_t; θ) + n_t，n ~ 𝒩(0, R)。累积信息矩阵与可辨识不确定度：
I_t(θ) = Σ_{s≤t} (∂h/∂θ)^T R^{-1} (∂h/∂θ)，
U_id(θ) = tr((I_t + εI)^{-1})，U_eff = U(ĉ) + γ_id·U_id。
方向可辨识裕度 m(v) = √(v^T I_t v)/‖v‖；不可辨识子空间 𝒩_t = {v : m(v) < ε_id}。**关键批评**：EKF 的 Σ 在不可观测方向会被先验压低（伪自信），故 U(ĉ) 单独不可作为可信度证据，必须并上信息矩阵的伪逆。

**定义 295（JOC 关节空间证书）** 对构型 q、Jacobian J(q)，五类归一化裕度：
s_sing = σ_min(J(q)) / σ_sing^0；s_lim = min_i 距离上下限 / Δq^0；s_tau = 力矩余量 / τ^0；s_col = 最近自碰撞距离 / d^0；s_vel = 速度余量 / q̇^0。
JOC(q, q̇, τ) = min(s_sing, s_lim, s_tau, s_col, s_vel)。Valid ⇔ JOC ≥ 0 且 s_sing ≥ s_sing^min。**零空间安全**：因 N 方向运动不进入任务证书，JOC 必须对整条零空间轨迹独立评估，不能只看末端。

**定义 296（提升算子与零空间分解）** q̇ = J⁺(q)ẋ + N(q) q̇₀，N = I − J⁺J，J N ≡ 0。
Lift(ξ_{1:k}, q_0) = argmin_{q̇_{1:k}, q̇₀} ‖J q̇ − ẋ‖²_Q − w_id·ΔI(q̇₀) − w_s·s_sing s.t. JOC ≥ 0、τ ∈ [τ_min, τ_max]。
一阶意义上零空间分量不改变末端路径，故 q̇₀ 是**不扰动任务的信息自由度**；二阶与约束耦合仍需由 JOC 兜底。

**定义 297（双控制激励调度 DCE）** 给定 U_eff、关节裕度 h、激励幅度 A：
VoI(A) = β·ΔI(A) − R_exc(A)，ΔI(A) ≈ (T/2)·log(1 + A²g/σ²)，R_exc(A) ≈ κA²T（在工况点附近对裕度侵蚀近似二次）。
DCE：A* = argmax_{A≥0} VoI(A) s.t. h(A) ≥ h_min。解析阈值条件见引理 17；用迟滞带 + 最小驻留时间防抖，用全局预算计数器限制占空比。

**定义 298（主动数据集构建 ADC）** 数据集 D = {episode}，每个 episode 带 (info_gain, risk, cov_cell, config, load, instrument)。
构建目标：max_D log det(I_0 + Σ_{e∈D} I_e(θ)) − η·cov_gap(D) s.t. risk(D) ≤ B_risk。
激励原语库：① q × 负载网格上的静态保持（分离力零偏与重力相关漂移）；② 低频 chirp 扫频（用频响分离"慢漂移"与"缓变故障"）；③ 零空间冗余扫掠（免费信息）；④ 负载位姿多样（力偏置 vs 机械故障）；⑤ canary 故障注入（覆盖失效模式）。每个 episode 都是一个"微型实验"，而非一段随机回放。

**定义 299（可辨识性覆盖度）** 风险相关流形 ℳ = 𝒞 × ℱ。核覆盖半径 cov(D) = sup_{θ∈ℳ} min_{e∈D} k(θ, θ_e)。要求 cov(D) ≤ ε_cov，且**信息加权覆盖**在不可辨识子空间 𝒩 的邻域内不得有空洞——覆盖是"去过那里"，信息是"在那里能分辨"，两者都要。

**定义 300（慢故障-漂移可分性）** 设漂移签名对构型一阶不变，故障签名有构型/负载敏感度 S_f。用条件（投影后）信息度量可分性：
I_{f|d} = I_{ff} − I_{fd} I_{dd}^{-1} I_{df}（Schur 补），S = √(λ_min(I_{f|d}))。
可辨识 ⇔ S > ε_sep。直觉：先把漂移方向 d 的信息"扣掉"，再看故障方向还剩多少**独特**信息。漂移的构型不变性正是可被扣掉的共同模。

**定义 301（激励作为工具变量 IVI）** e_t 为已知注入激励，q_t = g(e_t, 历史)。假设：
(A94-relevance) E[e_t q_t] ≠ 0（激励确实驱动构型）；
(A95-exclusion) e_t ⊥ f_t | 历史，且 e_t 仅经由 q_t、已知力矩输入影响观测，不直接进入故障通道。
则 IV 估计 θ̂_IV = (Z^T X)^{-1} Z^T o（Z = [e_t, …]）在 rank(E[Z^T X]) = d_θ 下一致：即使采样策略依赖过去的 θ，估计仍无偏。**激励把数据自确认从偏差问题降成方差问题。**

**定义 302（数据集循环性破除 CLD）** 部署策略 π_dep 产生 D_train；证书必须在由独立探索策略 π_exc（不同种子/不同激励幅值/不同零空间策略）产生的 D_eval 上重新计算，且 KL(π_dep‖π_exc) ≤ δ_div（允许不同行为，但排除"换了个完全不同的系统"）。自确认偏差 B_self = E_{D_eval}[loss] − E_{新数据}[loss]，要求 |B_self| ≤ β_self；IVI 有效时可放宽为方差界。

**定义 303（关节空间风险联动）** 总风险标度 λ_total = max(λ_task, λ_js)，其中 λ_js = 1 − c_js·min(0, JOC) 的单调映射，JOC 触底即 λ_js 顶到 1（满保守）。关节风险与任务风险不可互相抵消：任一侧不安全即整体收紧。

**定义 304（J_JEDI 证书）** J_JEDI = (J_CALM(U_eff), info_hash = hash(I_t), U_id, U_eff, JOC_min, k_joint, D_eval_hash, cov(D_eval), S, IV_rank, excite_budget, jedi_ver)。
Valid ⇔ Valid(J_CALM with U→U_eff) ∧ JOC ≥ 0 ∀k ≤ k_eff ∧ cov(D_eval) ≤ ε_cov ∧ IV_rank = d_θ ∧ 激励预算未超 ∧ 红线未越界。

**定义 305（管线）** 离线：在仿真里对激励原语库做 D-最优选择（最大化 log det FIM、最小化覆盖空洞）→ 预训练 → 标定 → IVI 校验。在线：默认利用（继承 CALM-RAS 主环）；当 U_eff 高且 JOC 裕度充足时，DCE 触发一次零空间/低频小型激励 episode，记录已知 e_t 作工具变量，增量更新 I_t 与 D_eval；若 SEP 显示某缓变故障已可辨识，立即把它移出 H_cal、进入 H_sensor^trans 并升级归因。所有提交仍走 CAC 五关。

**定义 306（信息-安全 Pareto）** 长期目标 J = E[Σ_t (risk_t + c_js·1[JOC<0] − β·ΔI_t)]。纯利用（R68）是 β=0 的角点解；JEDI 在 Pareto 前沿上仅在 ∂(安全收益)/∂I > ∂(激励风险)/∂I 时移动。激励调度是带约束的贝叶斯实验设计，其最优解由引理 17 的阈值给出。

**定义 307（任务证书 → 关节可实现前缀）** k_joint = max k 使得 Lift(ξ_{1:k}, q_0) 可行（含力矩 τ = M q̈ + C q̇ + g ∈ [τ_min, τ_max] 与 JOC ≥ 0）；k_eff = min(k_task, k_joint)。**推论**：纯任务空间认证可能高估安全前缀，关节可实现性只会缩短、不会延长它。

**定义 308（可辨识性感知阈值）** 定义 284–285 全部把 U 替换为 U_eff；另加 λ_id 纪律：若 S < ε_sep（存在"当前实验无法排除"的故障方向），按"未知活跃故障"处理，λ_floor ≥ 0.8 且禁止用标定吸收。语义与 R68 一致：不可辨识 → 只收紧，绝不放宽。

**定义 309（干扰集 ℰ_JEDI）** ℰ_JEDI = ℰ_CALM × ℰ_exc × ℰ_js × ℰ_ds。
ℰ_exc = {激励诱发故障、激励越出安全包络、激励泄漏进故障通道（违反排除性）}；
ℰ_js = {奇异、限位、力矩饱和、自碰撞、零空间漂移、关节缠绕}；
ℰ_ds = {选择偏差、数据自确认、覆盖空洞、IV 秩亏、分布漂移}。

```python
# IP-253 JOC：关节空间证书（五裕度 + 信息矩阵）
class JointObservabilityCertificate:
    def margins(self, q, qdot, tau):
        J = jacobian(q)
        s_sing = svd(J, compute_uv=False)[-1] / SIG0
        s_lim  = min(min(q - Q_MIN), min(Q_MAX - q)) / DQ0
        s_tau  = min(min(tau - TAU_MIN), min(TAU_MAX - tau)) / TAU0
        s_col  = self.collision_distance(q) / DCOL0
        return {'sing': s_sing, 'lim': s_lim, 'tau': s_tau,
                'col': s_col, 'joc': min(s_sing, s_lim, s_tau, s_col)}

    def update_info(self, q, tau, obs, theta):
        H = numeric_jacobian(lambda th: self.h(q, tau, th), theta)   # ∂h/∂θ
        self.I += H.T @ np.linalg.inv(self.R) @ H
        self.U_id = np.trace(np.linalg.inv(self.I + 1e-6*np.eye(len(theta))))
        return self.I, self.U_id


# IP-256 NSX + JSL：零空间激励 + 任务证书的关节提升（QP）
def lift_and_excite(xi_1k, q0, I, margins):
    q, qdot = q0.copy(), np.zeros_like(q0)
    for xdot_ref in xi_1k:
        J = jacobian(q)
        Jpinv = np.linalg.pinv(J)                       # damped near singularity
        N = np.eye(len(q)) - Jpinv @ J
        qdot0 = nsx_probe(I, N, margins)                # 只取可提升 FIM 的零空间方向
        qdot_cmd = Jpinv @ xdot_ref + N @ qdot0
        if JOC(q, qdot_cmd, torque(q, qdot_cmd)).joc < 0:
            return q, False                             # 提升失败 → k 截断
        q, qdot = integrate(q, qdot_cmd)
    return q, True


# IP-254 DCE：价值-风险比触发（带迟滞与预算）
class DualControlExcitation:
    def should_excite(self, U_eff, joc, budget):
        if joc < self.h_min or budget.left <= 0:
            return False
        A_star = self.argmax_voi(U_eff)                 # 引理 17 的闭式阈值
        if A_star <= 0 or U_eff < self.tau_low:         # 迟滞下界：不必激励
            return False
        return True


# IP-255/298 ADC：主动构建数据集（D-最优 + 覆盖）
class ActiveDatasetConstructor:
    def build(self, primitives, budget):
        D = []
        for cell in self.risk_relevant_cells():          # q × load × fault-mode
            e = self.d_optimal_pick(primitives, cell, D) # max log det FIM 增量
            if self.risk(e) <= budget.per_episode:
                e.instrument = self.known_excitation(e)  # IVI 的工具变量
                D.append(e)
        return self.enforce_coverage(D)                  # cov(D) ≤ ε_cov


# IP-262 主闭环：JEDI round（继承 CALM-RAS，加可辨识性与关节层）
def JEDI_RAS_round(M, obs, q, qdot):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)     # 同源潜状态
    r = residuals(x_prime, o, M.wm_residual_cache)
    c, U, _ = M.cof.step(o['cal'], r, sigma_stat(M))          # R68 标定滤波

    I, U_id = M.joc.update_info(q, M.tau_prev, o, M.theta)    # 可辨识性
    U_eff = U + M.gamma_id * U_id

    act_seq  = M.ach.propose_actions(x_prime, steps=5)
    wm_preds = M.mtm.rollout(z, act_seq, k=min(5, M.m))
    joint_post = M.cfa(rho, o['pi'], c, U_eff)                # 先标定后归因

    k_task = M.c_ras_wm.certified_prefix(A, joint_post, M.m_ras,
                                         M.alpha_chunk, wm_preds)
    k_joint, ok = M.jsl.liftable(A[:k_task], q)               # 关节可实现性
    k = k_joint if ok else M.jsl.largest_feasible(A, q)
    if U_eff > TAU_CAL:
        k = min(k, k_cal_shrink(A, U_eff))                    # 不可辨识 → 收缩

    if M.dce.should_excite(U_eff, M.joc.margins(q, qdot, M.tau), M.budget):
        e = M.dce.plan_nullspace(I, M.joc)                    # 免费信息通道
        M.adc.record(e, instrument=e.signal)                  # 已知激励作 IV
        q, qdot = M.nsx.execute(e, q, qdot)

    lam = max(M.efs.risk_scale(joint_post),
              M.car.thresholds(U_eff)['lam_floor'],
              M.jser.risk_scale(M.joc.margins(q, qdot, M.tau)),  # λ_js
              0.8 if (M.sep.uncertain(M.theta, I) or U_eff > TAU_CAL) else 0.6)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    tau = emotion_response_shaping_wm(tau, joint_post, wm_preds)

    M.vqa_c.submit_async(wm_preds, {'cal': (c, U_eff), 'I': I, 'joc': M.joc.last})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint_post, (c, U_eff, I)
```

## 3. 推导

**引理 16（持续激励 ⇔ 可辨识界）** 对线性参数化 o = Φ(q, τ)θ + n，I_T = Σ Φ^T R^{-1} Φ。若激励在 ≥ d_θ/2 个频点上功率非零且 λ_min(Σ_freq ΦΦ^T) ≥ α_pe，则 λ_min(I_T) ≥ α_pe·T/σ²，从而 U_id ≤ d_θσ²/(α_pe·T)。存在最小激励幅度 A_min ∝ √(σ²/(Tα_pe))，低于它 U_id 不可能降到 τ_cal 以下。**系**：R68 说"COF 2s 收敛"只在给定激励下成立；低激励轨迹会让 EKF 的 Σ 变小而 I_t 仍秩亏——此时 U(ĉ) 是伪自信，必须用 U_eff 纠正。

**引理 17（双控制激励阈值）** 令 VoI(A) = β·(T/2)log(1 + A²g/σ²) − κA²T。∂VoI/∂A = 0 给出 A*² = max(0, β/(2κT) − σ²/g)。故：**当且仅当 β/(2κT) > σ²/g 时 A* > 0**，否则最优是不激励。存在迟滞带 [τ_low, τ_high] 使触发频率有界；单 episode 附加风险 ≤ κA*²T ≤ β·ΔI/(2) 时，长期风险增量 ≤ ρ_exc·ε_exc。

**引理 18（构型多样性 ⇒ 缓变故障可分）** 设漂移方向 d 对构型一阶不变，故障方向 f 在 C 个构型间的响应变化因子为 S_f。则条件信息 I_{f|d} ≥ C·S_f²·A²/σ²（共同模被投影扣除后的残余），可分性 S = √λ_min(I_{f|d}) ∝ √C·S_f。检出概率 1−β ≥ Φ(√C·S_f·A/σ − z_α)。**系**：主动走遍构型/负载网格，可在不违反引理 13（快变故障反吸收界）的前提下，把 R68 的缓变故障从"不可辨识"抬到"可辨识"——这正是对 R68 最大风险的结构性修复。

**引理 19（IV 一致性 ⇒ 破除数据自确认）** 在 A94–A95 与秩条件下，θ̂_IV − θ = (Z^TX)^{-1}Z^Tn → 0（大数定律），即使采样策略 π_dep 依赖历史 θ。故由部署策略生成的数据在**有工具变量**时仍可用于认证；无 IV 时，自确认偏差 B_self = E[Z^Tn]/E[Z^TX] 一般非零，且随策略—故障相关性增大而增大。

**定理 16（JEDI 端到端风险一致性）** 在 A87–A95 下，输出 τ_cmd 满足：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_id + α_joint**，其中 α_id = P(U_eff ≥ τ_cal) 由引理 16 控制，α_joint = P(无可行关节提升) 由 JOC 控制；
2. U_eff > τ_cal ⇒ λ ≥ 0.8 ∧ k ≤ k_joint ∧（可辨识性不足时）触发激励或退避——不确定永远导向收缩；
3. 激励预算守恒 ⇒ 长期附加风险 ≤ ρ_exc·ε_exc；纯利用模式（ρ_exc = 0）退化为 CALM-RAS，故 JEDI 的安全性不低于 R68；
4. 缓变故障检出概率随构型多样性 C 单调上升，C ≥ C*(S_f, δ) 时 ≥ 1−δ（引理 18），覆盖 R68 的残余风险；
5. 任务空间证书若不存在关节提升则不成立：k_eff = min(k_task, k_joint)。

**定理 17（证书有效性 / 数据集自确认界）** 在 IVI 与独立探索种子下，J_JEDI 在 D_eval 上的估计偏差 ≤ B_iv/√N + δ_div·L；若放弃 IVI，则存在策略—故障相关性 c > 0 使偏差下界 ≥ c，证书在大 N 下仍不一致。**系**：CLD（独立探索集）+ IVI（工具变量）不是工程洁癖，而是证书渐近有效的必要条件。

## 6. 本轮最大风险

**一句话**：JEDI 用「主动运动换可辨识性」，而它的全部安全性押在 A95 这条排他性假设上——**一旦激励不只经由构型影响观测、还直接触达故障通道（例如激励激发的振动恰好加速了那个正在缓慢松动的关节），系统就会系统性地把机器人驱赶到最能暴露隐藏故障、也最危险的构型上，把「信息追求」变成「风险放大器」**；这是 R68「被动使缓变故障隐形」的精确对偶：R68 死于不敢动，R69 可能死于太会动。

**次级风险与缓解**：
1. **激励越界/奇异**：零空间二阶效应与自碰撞 → JOC 对整条零空间轨迹独立评估 + 阻尼最小二乘 + 硬 QP 约束；
2. **IV 排除性失效**：激励经振动/热通道直接影响故障 → 在线检验 e 与残差中故障分量的偏相关，超阈即关闭激励并冻结证书；
3. **覆盖幻觉**：D_eval 看似覆盖但信息加权仍有空洞 → 用条件 Fisher 信息而非样本计数定义覆盖；
4. **激励预算被安全目标挤占/滥用** → 全局占空比硬上限 + 预算纳入 J_JEDI 版本链 + 审计回放；
5. **多目标退化**：双控制把系统变成"为辨识而辨识" → VoI 中 β 由下游风险敏感度标定，且 ρ_exc → 0 时严格退化为 CALM-RAS（可证不劣）。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 可辨识性优先（证书必须带 I_t 与 U_id；阈值用 U_eff）；关节可实现性（任务前缀必须存在 JOC ≥ 0 的关节实现，否则截断）；激励预算守恒（单 episode 风险 ≤ ε_exc，占空比 ≤ ρ_exc，仅 h ≥ h_min 时激励）。

**定义 294（联合 Fisher 信息）** `o_t = h(q_t, τ_t; θ) + n_t`，`I_t = Σ ∂h^T R^{-1} ∂h`，`U_id = tr((I_t+εI)^{-1})`，`U_eff = U(ĉ) + γ_id U_id`。不可辨识子空间 `𝒩_t = {v : √(v^TI_tv)/‖v‖ < ε_id}`。关键批评：EKF 的 Σ 在不可观测方向被先验压低 → 伪自信，必须并上信息矩阵。

**定义 295（JOC）** 五裕度归一化后取 min；零空间轨迹必须独立评估，不能只看末端；Valid ⇔ JOC ≥ 0 ∧ s_sing ≥ s_sing^min。

**定义 296（提升与零空间）** `q̇ = J⁺ẋ + N q̇₀`；`Lift = argmin ‖Jq̇−ẋ‖² − w_id·ΔI(q̇₀) − w_s·s_sing` s.t. JOC ≥ 0、力矩界。零空间分量一阶不扰任务。

**定义 297（DCE）** `VoI(A)=β·(T/2)log(1+A²g/σ²) − κA²T`；最优幅度闭式解与阈值见引理 17；迟滞 + 最小驻留 + 全局预算。

**定义 298（ADC）** `max_D log det(I_0 + Σ I_e) − η·cov_gap(D)` s.t. `risk(D) ≤ B_risk`。五类激励原语：静态 q×负载网格、低频 chirp、零空间扫掠、负载位姿多样、canary 注入。每个 episode 是微型实验，带 (info, risk, config, load, instrument)。

**定义 299（覆盖度）** `cov(D) = sup_{θ∈ℳ} min_{e∈D} k(θ,θ_e) ≤ ε_cov`，并在 `𝒩_t` 邻域做信息加权覆盖，禁止「去过但分不清」的覆盖幻觉。

**定义 300（可分性）** `I_{f|d} = I_ff − I_fd I_dd^{-1} I_df`，`S = √λ_min(I_{f|d})`；`S > ε_sep` ⇔ 可辨识。漂移的构型不变性是被扣掉的共同模。

**定义 301（IVI）** 已知激励 `e_t`；relevance `E[e_t q_t] ≠ 0`；exclusion `e_t ⊥ f_t | 历史` 且只经 q/已知力矩影响观测；秩条件 `rank(E[Z^TX]) = d_θ` ⇒ `θ̂_IV = (Z^TX)^{-1}Z^To` 一致，破除自确认偏差。

**定义 302（CLD）** D_train（π_dep）/D_eval（π_exc）/D_canary 三分；`KL(π_dep‖π_exc) ≤ δ_div`；证书在 D_eval 复算；`|B_self| ≤ β_self`。

**定义 303–304（JSR / J_JEDI）** `λ_total = max(λ_task, λ_js)`，JOC 触底即 λ_js → 1；`J_JEDI = (J_CALM(U_eff), info_hash, U_id, JOC_min, k_joint, D_eval_hash, cov, S, IV_rank, excite_budget, jedi_ver)`，Valid 需全部满足且红线未越界。

**定义 305–309（管线 / Pareto / 前缀 / 阈值 / 干扰集）** 离线 D-最优实验设计 → 在线「默认利用 + 触发激励」；`J = E[Σ(risk + c_js·1[JOC<0] − βΔI)]`；`k_eff = min(k_task, k_joint)`；阈值全部 U → U_eff 且 `S < ε_sep ⇒ λ_floor ≥ 0.8`；`ℰ_JEDI = ℰ_CALM × ℰ_exc × ℰ_js × ℰ_ds`。

## 3. 关键算法伪代码

```python
# IP-253 JOC：五裕度 + Fisher 信息
class JointObservabilityCertificate:
    def margins(self, q, qdot, tau):
        J = jacobian(q); sv = svd(J, compute_uv=False)
        s = {'sing': sv[-1]/SIG0,
             'lim':  min(min(q-Q_MIN), min(Q_MAX-q))/DQ0,
             'tau':  min(min(tau-TAU_MIN), min(TAU_MAX-tau))/TAU0,
             'col':  self.collision_distance(q)/DCOL0}
        s['joc'] = min(s.values()); return s

    def update_info(self, q, tau, obs, theta):
        H = numeric_jacobian(lambda th: self.h(q, tau, th), theta)
        self.I += H.T @ np.linalg.inv(self.R) @ H
        self.U_id = np.trace(np.linalg.inv(self.I + 1e-6*np.eye(len(theta))))
        return self.I, self.U_id


# IP-256/259 NSX + JSL：零空间激励与任务证书的关节提升
def lift_and_excite(xi_1k, q0, I, margins):
    q, qd = q0.copy(), np.zeros_like(q0)
    for xdot_ref in xi_1k:
        J = jacobian(q); Jp = np.linalg.pinv(J)          # damped near singular
        N = np.eye(len(q)) - Jp @ J
        qd0 = nsx_probe(I, N, margins)                   # 只取能提升 FIM 的方向
        qd_cmd = Jp @ xdot_ref + N @ qd0
        if JOC(q, qd_cmd, torque(q, qd_cmd)).joc < 0:
            return q, False                              # 提升失败 → 截断 k
        q, qd = integrate(q, qd_cmd)
    return q, True


# IP-254 DCE：价值-风险触发（引理 17 闭式阈值 + 迟滞）
class DualControlExcitation:
    def should_excite(self, U_eff, joc, budget):
        if joc < self.h_min or budget.left <= 0: return False
        A2 = max(0.0, self.beta/(2*self.kappa*self.T) - self.sigma2/self.g)
        return A2 > 0 and U_eff >= self.tau_low


# IP-255 ADC：主动数据集构建（D-最优 + 覆盖）
class ActiveDatasetConstructor:
    def build(self, primitives, budget):
        D = []
        for cell in self.risk_relevant_cells():          # q × load × fault-mode
            e = self.d_optimal_pick(primitives, cell, D)  # max log det FIM 增量
            if self.risk(e) <= budget.per_episode:
                e.instrument = self.known_excitation(e)   # IVI 工具变量
                D.append(e)
        return self.enforce_coverage(D)                   # cov(D) ≤ ε_cov


# IP-264 主闭环：JEDI round（继承 CALM-RAS，加可辨识性与关节层）
def JEDI_RAS_round(M, obs, q, qd):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)     # R68 同源潜状态
    r = residuals(x_prime, o, M.wm_residual_cache)
    c, U, _ = M.cof.step(o['cal'], r, sigma_stat(M))

    I, U_id = M.joc.update_info(q, M.tau_prev, o, M.theta)    # 可辨识性
    U_eff = U + M.gamma_id * U_id
    act_seq  = M.ach.propose_actions(x_prime, steps=5)
    wm_preds = M.mtm.rollout(z, act_seq, k=min(5, M.m))
    joint_post = M.cfa(rho, o['pi'], c, U_eff)                # 先标定后归因

    k_task = M.c_ras_wm.certified_prefix(A, joint_post, M.m_ras, M.alpha_chunk, wm_preds)
    k_joint, ok = M.jsl.liftable(A[:k_task], q)               # 关节可实现性
    k = k_joint if ok else M.jsl.largest_feasible(A, q)
    if U_eff > TAU_CAL: k = min(k, k_cal_shrink(A, U_eff))

    if M.dce.should_excite(U_eff, M.joc.margins(q, qd, M.tau), M.budget):
        e = M.dce.plan_nullspace(I, M.joc)                    # 免费信息通道
        M.adc.record(e, instrument=e.signal)
        q, qd = M.nsx.execute(e, q, qd)

    lam = max(M.efs.risk_scale(joint_post),
              M.car.thresholds(U_eff)['lam_floor'],           # U_eff 重参数化
              M.jser.risk_scale(M.joc.margins(q, qd, M.tau)), # λ_js
              0.8 if (M.sep.uncertain(M.theta, I) or U_eff > TAU_CAL) else 0.6)
    tau = emotion_response_shaping_wm(
        M.pi_sigma.prefix_dispatch(A[:k]) * lam, joint_post, wm_preds)
    M.vqa_c.submit_async(wm_preds, {'cal': (c, U_eff), 'I': I, 'joc': M.joc.last})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)
    return k, lam, joint_post, (c, U_eff, I)
```

## 4. 推导

**引理 16（持续激励 ⇔ 可辨识界）** 线性参数化下 `I_T = Σ Φ^T R^{-1} Φ`。激励在 ≥ d_θ/2 个频点功率非零且 `λ_min(Σ_freq ΦΦ^T) ≥ α_pe` ⇒ `λ_min(I_T) ≥ α_pe T/σ²` ⇒ `U_id ≤ d_θσ²/(α_pe T)`。存在 `A_min ∝ √(σ²/(Tα_pe))`，低于它 U_id 无法降到 τ_cal 以下。**系**：R68 的「COF 2s 收敛」只在给定激励下成立；低激励时 EKF 的 Σ 变小而 I_t 仍秩亏，U(ĉ) 是伪自信，必须用 U_eff 纠正。

**引理 17（双控制激励阈值）** `VoI(A) = β(T/2)log(1+A²g/σ²) − κA²T`，`A*² = max(0, β/(2κT) − σ²/g)`。**当且仅当 β/(2κT) > σ²/g 时 A* > 0**，否则最优是不激励。迟滞带 `[τ_low, τ_high]` 保证触发频率有界；附加风险 `κA*²T ≤ βΔI/2` 时长期风险增量 ≤ ρ_exc·ε_exc。

**引理 18（构型多样性 ⇒ 缓变故障可分）** 漂移方向对构型一阶不变、故障响应在 C 个构型间变化因子 S_f ⇒ 条件信息 `I_{f|d} ≥ C·S_f²A²/σ²`，`S ∝ √C·S_f`，检出概率 `1−β ≥ Φ(√C·S_f A/σ − z_α)`。**系**：主动走遍 q×负载网格，可在不违反引理 13（快变故障反吸收界）的前提下把 R68 的缓变故障从「不可辨识」抬到「可辨识」——对 R68 最大风险的结构性修复。

**引理 19（IV 一致性 ⇒ 破除自确认）** 在 relevance + exclusion + 秩条件下 `θ̂_IV − θ = (Z^TX)^{-1}Z^Tn → 0`，即使策略依赖历史 θ。无 IV 时自确认偏差 `B_self = E[Z^Tn]/E[Z^TX]` 一般非零且随策略—故障相关性增大。故「独立探索集 + 工具变量」是证书渐近有效的必要条件。

**定理 16（JEDI 端到端风险一致性）** A87–A95 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_id+α_joint`（α_id 由引理 16、α_joint 由 JOC 控制）；
2. `U_eff > τ_cal ⇒ λ ≥ 0.8 ∧ k ≤ k_joint ∧（可辨识不足时）激励或退避`——不确定永远导向收缩；
3. 激励预算守恒 ⇒ 长期附加风险 ≤ ρ_exc·ε_exc；ρ_exc = 0 时严格退化为 CALM-RAS（安全性不劣于 R68）；
4. 缓变故障检出概率随 C 单调升，`C ≥ C*(S_f, δ)` 时 ≥ 1−δ（引理 18）；
5. 任务证书无关节提升即不成立：`k_eff = min(k_task, k_joint)`。

**定理 17（证书有效性 / 数据集自确认界）** IVI + 独立探索种子下，D_eval 上偏差 ≤ `B_iv/√N + δ_div·L`；放弃 IVI 时存在策略—故障相关 c>0 使偏差下界 ≥ c，大 N 下证书仍不一致。

## 7. 本轮最大风险

**一句话**：JEDI 用「主动运动换可辨识性」，全部安全性押在 A95 排他性假设上——**一旦激励不只经构型影响观测、还直接触达故障通道（例如激励激发的振动恰好加速了正在缓慢松动的关节），系统就会系统性地把机器人驱赶到最能暴露隐藏故障、也最危险的构型上，把「信息追求」变成「风险放大器」**；这是 R68「被动使缓变故障隐形」的精确对偶：R68 死于不敢动，R69 可能死于太会动。

**次级风险与缓解**：激励越界/奇异（JOC 全零空间评估 + 阻尼最小二乘 + 硬 QP 约束）；IV 排除性失效（在线检验 e 与故障残差偏相关，超阈即关闭激励并冻结证书）；覆盖幻觉（用条件 Fisher 信息而非样本计数定义覆盖）；预算滥用（全局占空比硬上限 + 纳入 J_JEDI 版本链 + 审计回放）；多目标退化（β 由下游风险敏感度标定，ρ_exc → 0 严格退化为 CALM-RAS，可证不劣）。
