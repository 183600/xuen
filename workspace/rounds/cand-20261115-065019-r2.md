# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；本轮灵感：「模型量化」×「用户需求分析」）

> R69 把不确定性一分为二（aleatoric / epistemic），并给 epistemic 一个主动通道：看、问、触。它悄悄假设了两件在这个循环里从未被检验的事：**(a) 策略与推理以全精度运行；(b) 优化目标（“什么叫好”）是给定且已知的。** 边缘部署打破 (a)，个性化交互打破 (b)。更微妙的是，这两件事会**互相伪装**：量化把两个本可分辨的模态糊成一个（或凭空造出一个），系统会把它误判成 aleatoric（于是永远刹车）或 epistemic（于是去问一个幻影）；反过来，量化后的偏好头把两个不同的用户需求舍入成同一个输出，系统会把它读成“用户无所谓”，于是自信地错下去。
>
> 本轮两个灵感各打一个洞，并**合成一个新方法论**：
> - **模型量化** → 引入第三类不确定性 **U_rep（表征/分辨率不确定性）**：它不可由“等”消除（不是 aleatoric），也不可由“问”消除（不是 epistemic），**只能由“提高精度”消除**；
> - **用户需求分析** → 把目标本身当作隐变量 **θ_u**，区分“世界是什么”的询问与“你想要什么”的询问，并正视陈述偏好的谄媚、非平稳与不可验证。
>
> 核心命题：**不确定性不该只按“来源”分类，而该按“哪种稀缺资源能消除它”分类——耐心（λ）、信息（交互）、分辨率（精度）、价值（需求引导）。** 四类不确定性各有唯一有效的执行器；错误归因（把 U_rep 当 U_epi、把 U_pref 当 U_ale）比不确定性本身更危险。命名 **QUIET-RAS**（Quantization-aware Uncertainty-typed Intent-Eliciting Triage）。
>
> 一句话定位：R66 问“谁控制”，R67 问“未来怎样”，R68 问“我的测量还准吗”，R69 问“我该向谁求证”，R70 问“**在什么精度下、为了谁的什么需求，我还负担得起问几次**”。

## 0. 直觉与动机

**灵感 1（量化 → 不确定性多了一种“分辨率”维度）**
直觉：R69 的 U_ale 是“世界在抖”，U_epi 是“我看不清是哪个世界”。量化引入第三种东西：**“我的表示装不下这个区别”**。两个动作模态相距 2cm，int8 的量化步长让它们在速度场里差不到一个最小刻度，系统就只看到一个模态——不是世界没有歧义，是我的尺子没有刻度。U_rep 的关键性质：**时间不会减小它（≠aleatoric），询问也不会减小它（≠epistemic），只有把相关层的精度升上去才会减小它。** 这把“不确定性”从二维平面变成一张“可按执行器分解”的表。

**灵感 2（三分诊断 → 用“旋钮”而不是“猜测”来归因）**
直觉：与其猜 U 从哪来，不如**拧三个旋钮看它响应谁**：给更多时间/样本（耐心旋钮）、给一次信息动作（交互旋钮）、给一档更高精度（分辨率旋钮）。谁能让这个 U 掉下来，它就是哪一类。这是实验设计里的“扰动-响应”思想，把一个不可观测的分解变成一个**可证伪的测量协议**。R69 的 aleatoric/epistemic 二分只是这张表里“忽略精度旋钮”的一个退化切片。

**灵感 3（用户需求 → 目标本身是隐变量，不是给定函数）**
直觉：R66~R69 都在优化一个**已经写好的**代价函数。但真实用户的需求是**潜在、随情境漂移、且用户自己也说不清**的：他要“快一点”还是“稳一点”、“别打扰我”还是“多确认一次”，是一个隐变量 θ_u。系统只能通过**揭示偏好**（看用户实际怎么纠正/接管）和**陈述偏好**（直接问）来估计它。关键是这两条通道的可靠性完全不同：陈述便宜但会谄媚、会受提问框架诱导；揭示真实但稀疏、滞后。于是“用户需求分析”不是一次问卷，而是一个**带非平稳与欺骗的概率推断**问题——和 R69 问世界问题是两回事。

**灵感 4（资源分诊 → 询问和精度花的是同一笔预算）**
直觉：在边缘设备上，“再问一句”和“把这一层升到 fp16”都在烧电、占时延、消耗用户耐心。但两者的**成本结构不同**：精度是**持久配置**（升上去对之后所有状态都生效，按焦耳摊销），交互是**一次性的、状态特异的**（问过就没了，按社交资本计费）。所以不存在“总是先问”或“总是先升精度”：**系统性、反复出现的歧义值得升精度（摊销回本）；偶发、个例的歧义值得问一次。** 这把 R69 的 VoI 扩展成 VoI 与 VoP（value of precision）的联合背包。

**灵感 5（双刃剑的叠加 → “静默错配”是新的最坏情况）**
直觉：量化不仅制造误差，还**压缩了对抗扰动的安全边际**——原本需要 ε 的扰动才能翻转的模态判定，在低位宽下可能只需 ε/2^k（死区/舍入边界更密）。而需求侧新增了谄媚与框架诱导。两者叠加出的最坏情况不是“问错”，而是**“不问也不错”的假象**：量化后的偏好估计把不同 θ_u 舍入成同一类，系统报告“用户无偏好分歧”，于是既不问也不升精度，**把“我分辨不出你的需求”伪装成“你没有需求”**。R69 把“诚实的不知道”升级成“被证实的错误”；R70 若不设防，会把“诚实的不知道”升级成**“被证实的无差异”**——这是错配里最难被发现的一种，因为它在所有指标上都像成功。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（QUIET-RAS 总览）** QUIET-RAS = (PQD, QAUD, KDP, MPE, UNA, PEQ, SDG, JBT, VQAuditor-Q, RAS-WM†)。四不变式：
(i) **实时零学习写操作**（继承 R69 定义 293-i）；
(ii) **精度清单不可否认**：任何时刻运行的精度配置 q 必须被记录并进入证书（effective-bits attestation），禁止“偷偷降精度”；
(iii) **双预算硬约束**：交互预算 B_int（次数/位移/社交成本）与精度预算 B_prec（焦耳·秒）共享一个能量池，越界即冻结升级；
(iv) **证据纪律不因精度放宽**：低位宽下的单源回答仍不得定案（继承 293-iii），且 U_rep 不得被当作“相信回答”的理由。

**定义 311（精度配置与有效比特）** 精度配置 q = {(ℓ, b_ℓ)}，b_ℓ ∈ {4,8,16,32} 为层 ℓ 的位宽；有效比特 e(q) = Σ_ℓ n_ℓ b_ℓ / Σ n_ℓ。参考场 v := v_{q*}（最高可用精度）；量化场 v_q。每档升级成本 c_q = 焦耳/次前向 + 时延。

**定义 312（三分不确定性的操作定义）** 在观测 o 与当前 q 下：
U_ale(o) := 所有旋钮调到最好（耐心→∞、q→q*、且有 oracle 交互）后**仍残留**的方差；
U_epi(o) := 拧“交互/观测”旋钮（q 固定）能消除的部分；
U_rep(o) := 拧“精度”旋钮（q→q*，交互固定）能消除的部分。
在正交假设 A99 下 U_total ≈ U_ale + U_epi + U_rep。**判别签名**：U_rep 对时间**非减**（等不会变清楚），对交互**不变**（问也问不出分辨率）——这正是它与另两者的区别。

**定义 313（旋钮差分诊断 KDP）** 定义 3×3 响应矩阵 S，S[i][j] = ∂U_i/∂knob_j（knob ∈ {time, interact, precision}）。KDP 每轮估计 S 并做归因：只响应 precision ⇒ U_rep；只响应 interact ⇒ U_epi；都不响应 ⇒ U_ale。**归因错误代价** c_err(i→j) 用“用错执行器”的期望损失加权（把 U_rep 当 U_epi 会去问不可分辨的幻影，损失 = 一次交互 + 一次无效等待）。

**定义 314（量化误差传播与可分辨下界）** 设速度场量化误差有界 ‖v_q − v‖_∞ ≤ δ_q（δ_q ∝ 2^{−b}·Lip(v)）。由 ODE 扰动 / Grönwall，生成分布 W_2(p_q, p) ≤ C·δ_q·(1 + H)。定义**可分辨下界** Δ_res(q) := κ·δ_q。若两模态 W_2 间距 Δ_min ≤ Δ_res(q)，它们在 q 下**不可分辨**：modes 合并 ⇒ U_epi 被系统性**低估**（假自信）；若 Δ_min 略大于 Δ_res，舍入噪声可**分裂**出幻影模态 ⇒ U_epi **高估**（去问幻影）。这把 R69 的 A95（Δ_min ≥ 3σ_in）升级为 **A95′：Δ_min ≥ max(3σ_in, Δ_res(q))**。

**定义 315（精度升级与 VoP）** 值-精度 VoP(q→q′; o) := E[ΔU_rep · v(ΔU_rep)] − c_q（v(·) 为“降低一份不确定性”折算成任务风险的系数）。MPE 选择使 VoP/焦耳最大的**层子集**做混合精度局部升级（只升速度场中贡献最大的层，而非整网）。摊销判据：设歧义状态频率 f，升级阈值 f·E[ΔU_rep]·v ≥ c_q ——系统性歧义升精度，偶发歧义留给询问。

**定义 316（用户需求隐变量与值不确定性）** 潜在需求 θ_u ∈ Θ（速度/力度/隐私/社交距离…的权重）。系统持后验 b(θ_u)。任务损失 ℓ(a, θ_u)。**值不确定性** U_pref := BayesRegret(b) = E_θ[ℓ(a*,θ)] − min_a E_θ[ℓ(a,θ)]。与熵不同，U_pref **按损失加权**：θ 的差异只在其导致不同最优动作且损失显著时才算“不确定”。

**定义 317（偏好引导查询 PEQ / 遗憾信息增益 RIG）** 查询 h（“你更希望我快点还是轻点？”）得回答 y。RIG(h) := E_b[Regret] − E_y[Regret(b′)]，b′ = P(θ|y,h)b。选择 h* = argmax RIG(h) − c_soc(h) − c_q(h)，s.t. 预算与打扰契约。**关键**：优化的是遗憾而非熵——“用户对两件不重要的事纠结”不该占用提问额度。

**定义 318（揭示-陈述哨兵 RPS）** 陈述偏好 y_s（问出来的）与揭示偏好 y_r（从接管/纠正/停留时长被动推断的）。RPS 维护一致性 κ = 1 − TV(y_s, y_r)：κ 低 ⇒ 陈述不可信（谄媚/框架效应）或已漂移，降低 y_s 权重、优先用 y_r 或换一种问法。R69 的“交互是主动信息动作”在这里被**反转**：被动揭示是默认，主动询问才是特例（对应 R69 的 R68 包含关系在需求侧的镜像）。

**定义 319（谄媚与非平稳守护 SDG）** 回答似然 P(y | θ, h, framing) 显式含谄媚率 β(θ,h)（用户倾向回答“系统想听的”或社会赞许答案）与漂移率 τ（θ_u 随时间/情境变化）。SDG 做两件事：用**对照框架**（同一 h 以正反两种 framing 各问一次，取其差）估计 β 并去偏；对答案施加**时间半衰期** exp(−Δt/τ) 的陈旧折扣，避免用旧需求指挥新情境。

**定义 320（联合预算分诊 JBT）** 设共享预算 B，单个信息动作成本 c_g，单档精度成本 c_q（持久、按剩余时程摊销）。JBT 解一个拉格朗日/水填充问题：max Σ_m [ΔU(g_m)+ΔU(q_m)]·v_m s.t. Σ c_g + Σ c_q ≤ B，得到三类执行的**边际价值相等**条件；边际价值都低于阈值时三者全不做 ⇒ 退化为纯保守。

**定义 321（四通道补救映射与严格包含）** 按 KDP 归因分派：U_ale → λ_floor（耐心/刹车，R68）；U_epi → 交互（R69）；U_rep → 精度升级（MPE）；U_pref → 需求引导（PEQ），残余以“保守默认偏好 θ_safe”兜底。**未消解/超预算/被污染的部分一律并入 λ floor（最保守通道）**。当 q=q*、B_pref=0 且需求已知时，QUIET-RAS 与 FLUID-RAS 逐指令相同；再令 B_int=0 退化为 R68。

**定义 322（精度感知证书 J_QUIET）** J_QUIET = (J_FLUID, q_manifest_hash, effective_bits, δ_q_bound, Δ_res(q), attribution_map, U_rep_before/after, voP_ratio, pref_posterior_hash, sycophancy_estimate, drift_age)。Valid ⇔ Valid(J_FLUID) ∧ effective_bits ≥ b_min ∧ δ_q ≤ δ_max ∧ 归因置信度 ≥ τ_attr ∧ 陈述偏好未被单源采纳。

**定义 323（量化与需求攻击面 AIC-QUIET）** ℰ_QUIET = ℰ_FLUID × ℰ_quant × ℰ_pref：
ℰ_quant：舍入死区诱导的模态翻转（小扰动跨量化边界）、位宽降级攻击（诱导系统“自己降精度”以扩大误差）、衰减累积（量化偏差逐层放大）；
ℰ_pref：谄媚诱导、framing 操纵、以“需求”为名的社交工程（诱导系统放宽安全默认）、隐藏偏好（用户故意不透露以测试系统）。
合并为鲁棒性对抗训练目标。

**定义 324（参与式审计 VQAuditor-Q）** 审计新增：精度升级是否可归因（是否被 AIC-QUIET 触发）、偏好查询是否诱导或过度打扰、陈述与揭示偏好分歧是否被记录、**“无差异”结论**是否经过去量化复核（见 325）。结论回灌 JBT 成本先验与 UNA 先验。

**定义 325（需求-精度对偶与静默错配判据）** 定义对偶观测：提高精度后**偏好后验是否分裂**。若 q 下 U_pref≈0（“用户无差异”）而在 q′>q 下 U_pref 显著回升 ⇒ **静默错配**：不是用户无差异，而是低位宽把差异舍掉了。**判据 D：任何“用户无差异/需求已知”的高置信结论，必须通过一次 q′ 复核（cheap dequantization probe），否则不得据此关闭需求引导。** 这是 R69 引理 17（标定不可吸收第二意见）在偏好侧的镜像：用一条不能被低位宽抹平的通道做第二意见。

**定义 326（打扰契约与最小打扰原则）** 显式契约 M = (max_queries/小时, max_interrupt_level, 可静默时段)。任何 PEQ/交互必须满足 M；违约等同不安全动作。目标不是“最大化信息”，而是**在契约内最小化期望遗憾**——信息可以为负价值（打扰本身是成本），故允许“明知有歧义也不问”。

# IP-264 PQD：精度可配置闭环（每层位宽可调，q_manifest 不可否认）
class PrecisionConfigurableRAS:
    def __init__(self, layers, q0, ref_q):          # ref_q = 最高可用精度
        self.q, self.ref = q0, ref_q                 # 当前 / 参考精度
        self.manifest = []                           # (t, q, effective_bits)
    def forward(self, o):
        self.manifest.append((now(), self.q, effective_bits(self.q)))
        return self.net(o, self.q)                   # 含 trunk / 速度场 / 偏好头

# IP-265/266 QAUD+KDP：三分 + 旋钮差分归因
def qaud_decompose(model, o, budget):
    base, _   = model.sample(o, K=4, q=model.q)
    rep, _    = model.sample(o, K=4, q=model.ref)                     # 拧精度
    inter, _  = model.sample(o, K=4, q=model.q, info=oracle_info(o))   # 拧交互
    U_rep = dist(base, rep); U_epi = dist(base, inter)
    U_ale = residual_var(base, rep, inter)                            # 三者都不动
    S = estimate_response_matrix(base, rep, inter)
    return QAUD(U_ale, U_epi, U_rep), attribute(S)                    # 定义 312–313

# IP-267 MPE：VoP 选层做混合精度升级
def value_of_precision(model, o, layer_grads, budget):
    cand = top_layers_by_sensitivity(layer_grads, k=3)
    for q_next in precision_ladder(model.q):
        gain = expected_Urep_drop(model, o, q_next, cand)
        if gain * risk_weight(gain) / joules(q_next, cand) > budget.marginal:
            return cand, q_next
    return None                                       # 升不起 → 不升

# IP-268/269 UNA+PEQ：需求推断 + 遗憾信息增益
def prefer_query(UNA, o, budget, contract):
    if not contract.allows_query(now()): return None
    best = None
    for h in UNA.candidate_queries(o):                # 陈述式 / 对照框架
        if h.cost > budget.left or h.interrupt > contract.max_interrupt: continue
        rig = regret(UNA.belief) - expected_regret(UNA.belief, h)
        score = rig - h.cost - h.frame_penalty
        if best is None or score > best.score: best = (h, score)
    return best if best and best.score > 0 else None  # 问了不划算 → 不问

# IP-270/318/319 SDG+RPS：对照框架去谄媚 + 揭示/陈述一致性
def ingest_answer(UNA, h, y_s):
    y_r = UNA.revealed_pref(window=W)                 # 被动揭示
    kappa = 1 - total_variation(y_s, y_r)
    beta  = UNA.estimate_sycophancy(h)                # 对照框架差分
    if kappa < TAU_KAPPA or beta > TAU_BETA:
        return UNA.update(None, weight=0)             # 单源不可信 → 不定案
    return UNA.update(y_s, weight=kappa * (1 - beta))

# IP-271 JBT：联合预算水填充（交互 vs 精度摊销）
def triage(model, o, budget, attribution):
    actions = []
    if attribution.U_rep  > T: actions.append(('prec', value_of_precision(...)))
    if attribution.U_epi  > T: actions.append(('ask',  mint_choose(...)))
    if attribution.U_pref > T: actions.append(('pref', prefer_query(...)))
    return waterfill(actions, budget)                 # 边际价值相等；空 → 纯保守

# IP-275 QUIET 主闭环

    z, o = M.pqd.forward(obs)

    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)   # R69 第二意见
    # 静默错配判据 D：无差异结论必须去量化复核

        M.una.force_recheck(M.pqd.ref)

        if kind == 'prec': M.pqd.apply(act); U_rep = post(act)
        if kind == 'ask':  U_epi_after = M.cia.update_belief(..., M.cia.execute(act))
        if kind == 'pref': U_pref_after = ingest_answer(M.una, *act)
    # 四通道退避：未消解的一切并入最保守通道
    U_floor = U_ale + U_epi_after + U_rep + U_pref_after
    if attr.unresolved_or_poisoned() or M.pqd.effective_bits < B_MIN:
        U_floor = U_ale + U_epi + U_rep + U_pref_after   # 不动点：全保守
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow_fault_suspect: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, U_epi_after, lam, pref=M.una.map_theta())
    M.vqa_q.submit_async(M.pqd.manifest, attr, plan, U_pref_after)
    return k, lam, mode, (U_ale, U_epi_after, U_rep, U_pref_after)
```

## 3. 推导

**引理 19（量化扰动界）** 若 ‖v_q − v‖_∞ ≤ δ_q，则 W_2(p_q, p) ≤ C δ_q (1+H)（A101：速度场 Lipschitz、ODE 解对漂移项连续）。系：**量化只引入受控、可证伪的分布偏移**，可作为证书项，而非不可解释噪声。

**引理 20（可分辨下界与假自信/幻影）** 令 Δ_res = κ δ_q。若 Δ_min ≤ Δ_res，则存在 ε 邻域使模态合并，AUD 报 H_mode↓ 而真实 H_mode 不变 ⇒ U_epi 低估、系统“假自信”；若 Δ_min ∈ (Δ_res, Δ_res + η)，舍入噪声可产生伪模态 ⇒ U_epi 高估、系统“问幻影”。故 **A95′ 是可分辨性的必要条件**；违反时正确动作是升精度，不是问。

**引理 21（VoP 摊销律）** 精度成本 c_q 对不同状态**可摊销**，交互成本 c_g **不可摊销**。设歧义状态频率 f，则“升精度优于逐个询问”当且仅当 f·E[ΔU_rep]·v ≥ c_g·n_ask / c_q 型条件成立；取小预算极限，得到**系统性歧义升精度、偶发歧义询问**的清晰边界。系：R69“总是问”在 f 高时是**指数级浪费**。

**引理 22（RIG 对谄媚的鲁棒性）** 设谄媚使回答与真实 θ 的互信息下降至 (1−β)I。熵贪心把额度花在“信念最分散”的敏感查询上，恰是 β 最大处，故其遗憾可退化为 ≥ 常数·U_pref；而 RIG 以**遗憾加权**，自动避开“高不确定但答了也不改变最优动作”的查询，遗憾 ≤ O(√(1/(1−β))·log|Θ|)。系：**问题选得对，比问得多更重要**。

**引理 23（需求-精度对偶 / 静默错配可辨识）** 若低位宽把 θ_1,θ_2 舍入到同一点，则 U_pref(q)≈0；去量化后 U_pref(q′) 回升。故“无差异”结论在 (q,q′) 上有可检验签名；判据 D 的一次复核即可把“真无差异”与“舍不掉的区别”分开。这是引理 17 在偏好侧的镜像。

**定理 18（QUIET 严格包含 FLUID 与 R68）** 当 q=q*、B_pref=0 且 θ_u 已知时，QUIET 与 FLUID 逐指令相同；再令 B_int=0 退化为 R68。安全侧（λ floor）在归因失败、预算耗尽、位数过低、偏好被污染时**单调不降**；效率侧只在“确证可消除”时获得 resolution bonus。

**定理 19（三分补救的非替代性）** 在 A99–A101 下，响应矩阵 S 对角占优；用错执行器（如用交互消 U_rep、用精度消 U_ale）的边际收益 ≤ 0，且引入额外成本。⇒ **归因是硬前提**：错误的分类会让系统把预算花在无效旋钮上，“越努力越保守”。

**定理 20（联合分诊的最优性与单调安全）** JBT 的水填充解在凸化近似下最优；当总预算 B 低于阈值 B₀ 时最优行动集为空（三者全不做），闭环连续退化为纯保守；随 B↑，行动集单调扩张且 λ 单调不增 ⇒ 无突变（继承 R69 定理 17）。

## 6. 本轮最大风险

**一句话**：QUIET-RAS 的全部正确性押在“**旋钮差分能把 U_rep、U_epi、U_pref 分开**”这一前提上——但三者并不正交：低位宽既会制造伪模态（让你去问幻影），又会抹平真实偏好（让你以为用户无需求），而“升精度后偏好后验分裂”既可能是分辨率恢复、也可能只是模型在另一精度下换了另一种错；若归因矩阵 S 被污染，系统会把预算持续投进**听起来最合理却无效的旋钮**，最终用“用户无差异 / 已消歧”的漂亮证书，**把“我分辨不出你要什么”盖章成“你什么都没要”**——这比 R69“问错”更隐蔽，因为它在所有成功指标上都表现为成功。

**次级风险与缓解**：
1. **归因而非不确定本身才是新故障源** → 定义 313 的显式代价矩阵 + 归因置信度门（<τ_attr 即全保守）；
2. **静默错配** → 判据 D 的去量化复核 + 定义 325 对偶签名，禁止未经复核的“无差异”结论；
3. **谄媚/框架操纵** → 对照框架差分 + RPS 揭示/陈述一致 + 引理 22 的 RIG 选择；
4. **精度预算被对抗诱导耗尽** → AIC-QUIET 降精度攻击集 + 精度清单不可否认 + 预算硬约束；
5. **量化放大对抗灵敏度** → 证书含 δ_q / Δ_res 项，低位宽自动提高 λ 下限（安全边际随精度收紧）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；精度清单不可否认（effective-bits attestation，禁止偷降精度）；双预算硬约束（B_int 与 B_prec 共享能量池）；证据纪律不因精度放宽（低位宽的单源回答仍不得定案）。

**定义 311–312（精度配置与三分）** `e(q)=Σn_ℓb_ℓ/Σn_ℓ`；操作定义：U_ale 为三旋钮全开后仍残留的方差，U_epi 为拧交互能消除的部分，U_rep 为拧精度能消除的部分。**U_rep 对时间非减、对交互不变**是判别签名。

**定义 313（KDP）** 估计 3×3 响应矩阵 S 并归因；配“用错执行器”的代价矩阵 c_err(i→j)，归因置信度 < τ_attr 即全保守。

**定义 314（可分辨下界）** `W_2(p_q,p) ≤ Cδ_q(1+H)`；`Δ_min ≤ Δ_res(q)` ⇒ 模态合并（U_epi 低估、假自信），`Δ_min` 略大于阈值 ⇒ 舍入造幻影（U_epi 高估）。R69 的 A95 升级为 **A95′：Δ_min ≥ max(3σ_in, Δ_res(q))**。

**定义 315（VoP / MPE）** `VoP=E[ΔU_rep·v]−c_q`，按焦耳选最敏感的层子集做混合精度；摊销阈值 `f·E[ΔU_rep]·v ≥ c_q`。

**定义 316–317（需求后验与 PEQ）** `U_pref=BayesRegret(b)`；`h*=argmax RIG(h)−c_soc−c_q`，以**遗憾**而非熵加权，避免“无关紧要的纠结”占用额度。

**定义 318–319（RPS 与 SDG）** `κ=1−TV(y_s,y_r)`，κ 低则陈述不可信；对照框架差分估 β 并去偏，时间半衰期 `exp(−Δt/τ)` 处理漂移。

**定义 320–321（JBT 与四通道退避）** 共享预算下水填充，边际价值 < 阈值则三者全不做；U_ale→λ、U_epi→交互、U_rep→精度、U_pref→需求引导，未消解项一律并入 λ floor。`q=q*、B_pref=0、θ 已知` ⇒ 与 FLUID 逐指令相同。

**定义 322–326（证书/攻击面/审计/对偶/契约）** J_QUIET 并入精度与归因项；ℰ_QUIET 增量化与需求两族；审计“无差异”是否复核；判据 D 用去量化复核分离“真无差异”与“舍不掉的区别”；打扰契约下最小化期望遗憾（允许“明知有歧义也不问”）。

class PrecisionConfigurableRAS:
    def forward(self, o):
        self.manifest.append((now(), self.q, effective_bits(self.q)))
        return self.net(o, self.q)                     # trunk / 速度场 / 偏好头

# IP-265/266 QAUD+KDP：三旋钮差分
def qaud_decompose(model, o, budget):
    base,_  = model.sample(o, K=4, q=model.q)
    rep,_   = model.sample(o, K=4, q=model.ref)                    # 拧精度
    inter,_ = model.sample(o, K=4, q=model.q, info=oracle_info(o))  # 拧交互
    U_rep, U_epi = dist(base, rep), dist(base, inter)
    U_ale = residual_var(base, rep, inter)
    return QAUD(U_ale, U_epi, U_rep), attribute(estimate_response_matrix(base, rep, inter))

# IP-267 MPE：VoP 选层升级
def value_of_precision(model, o, layer_grads, budget):
    cand = top_layers_by_sensitivity(layer_grads, k=3)
    for q_next in precision_ladder(model.q):
        gain = expected_Urep_drop(model, o, q_next, cand)
        if gain * risk_weight(gain) / joules(q_next, cand) > budget.marginal:
            return cand, q_next
    return None                                        # 升不起 → 不升

# IP-268/269 UNA+PEQ：遗憾信息增益
def prefer_query(UNA, o, budget, contract):
    if not contract.allows_query(now()): return None
    best = None
    for h in UNA.candidate_queries(o):
        if h.cost > budget.left or h.interrupt > contract.max_interrupt: continue
        score = regret(UNA.belief) - expected_regret(UNA.belief, h) - h.cost - h.frame_penalty
        if best is None or score > best.score: best = (h, score)
    return best if best and best.score > 0 else None    # 问了不划算 → 不问

# IP-270 SDG+RPS：去谄媚 + 揭示/陈述一致

    kappa = 1 - total_variation(y_s, UNA.revealed_pref(window=W))
    beta  = UNA.estimate_sycophancy(h)
    if kappa < TAU_KAPPA or beta > TAU_BETA: return UNA.update(None, weight=0)
    return UNA.update(y_s, weight=kappa * (1 - beta))

def QUIET_RAS_round(M, obs):
    M.pqd.q = M.jbt.current_precision()
    z, o = M.pqd.forward(obs)
    (U_ale, U_epi, U_rep), attr = qaud_decompose(M.pqd, o, M.budget)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_cal)   # R69 第二意见
    if M.una.claims_indifference() and not M.una.rechecked_at(M.pqd.ref):
        M.una.force_recheck(M.pqd.ref)                  # 判据 D
    U_epi_after, U_pref_after = U_epi, M.una.belief_regret()
    for kind, act in triage(M, o, M.budget, attr):
        if kind == 'prec': M.pqd.apply(act); U_rep = post(act)
        if kind == 'ask':  U_epi_after = M.cia.update_belief(..., M.cia.execute(act))
        if kind == 'pref': U_pref_after = ingest_answer(M.una, *act)
    U_floor = U_ale + U_epi_after + U_rep + U_pref_after
    if attr.unresolved_or_poisoned() or M.pqd.effective_bits < B_MIN:
        U_floor = U_ale + U_epi + U_rep + U_pref_after   # 不动点：全保守
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow_fault_suspect: lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    mode = select_mode(modes, U_epi_after, lam, pref=M.una.map_theta())
    M.vqa_q.submit_async(M.pqd.manifest, attr, U_pref_after)
    return k, lam, mode, (U_ale, U_epi_after, U_rep, U_pref_after)
```

## 4. 推导

**引理 19（量化扰动界）** `‖v_q−v‖_∞≤δ_q ⇒ W_2(p_q,p)≤Cδ_q(1+H)`（A101：速度场 Lipschitz、ODE 解对漂移连续）。系：量化是可证伪、可入证书的受控分布偏移，不是不可解释噪声。

**引理 20（可分辨下界与假自信/幻影）** `Δ_min≤Δ_res=κδ_q` ⇒ 模态合并、H_mode 被低估（假自信）；`Δ_min∈(Δ_res,Δ_res+η)` ⇒ 舍入噪声可造伪模态（去问幻影）。故 **A95′ 是可分辨性的必要条件**，违反时应升精度而非询问。

**引理 21（VoP 摊销律）** 精度成本可跨状态摊销、交互成本不可。歧义频率 f 高时升精度优于逐个询问，f 低时询问更省；R69“总是问”在 f 高时指数级浪费。

**引理 22（RIG 的谄媚鲁棒性）** 谄媚使互信息降至 `(1−β)I`；熵贪心恰把额度花在 β 最大的敏感查询上，遗憾可退化为 ≥ 常数·U_pref；RIG 遗憾 ≤ `O(√(1/(1−β))·log|Θ|)`。系：问题选得对比问得多更重要。

**引理 23（需求-精度对偶）** 低位宽把 θ_1,θ_2 舍成同点 ⇒ U_pref(q)≈0，去量化后回升；“无差异”在 (q,q′) 上有可检验签名，判据 D 一次复核即可分开“真无差异”与“舍不掉的区别”（引理 17 的偏好侧镜像）。

**定理 18（严格包含）** `q=q*、B_pref=0、θ 已知` ⇒ 与 FLUID 逐指令相同；再令 `B_int=0` 退化为 R68。归因失败/预算耗尽/位数过低/偏好被污染时 λ floor 单调不降；效率侧仅在“确证可消除”时获 resolution bonus。

**定理 19（三分补救非替代性）** A99–A101 下响应矩阵 S 对角占优，用错执行器边际收益 ≤ 0 且引入额外成本；归因是硬前提，错分类导致“越努力越保守”。

**定理 20（联合分诊最优性与单调安全）** JBT 水填充解在凸化近似下最优；`B<B₀` 时最优行动集为空、连续退化为纯保守；随 B↑ 行动集单调扩张且 λ 单调不增 ⇒ 无突变（继承 R69 定理 17）。

## 7. 本轮最大风险

**一句话**：QUIET-RAS 的全部正确性押在“**旋钮差分能把 U_rep、U_epi、U_pref 分开**”这一前提上——但三者并不正交：低位宽既会制造伪模态（让你去问幻影），又会抹平真实偏好（让你以为用户无需求），而“升精度后偏好后验分裂”既可能是分辨率恢复、也可能只是模型在另一精度下换了另一种错；若归因矩阵 S 被污染，系统会把预算持续投进**听起来最合理却无效的旋钮**，最终用“用户无差异 / 已消歧”的漂亮证书，**把“我分辨不出你要什么”盖章成“你什么都没要”**——这比 R69“问错”更隐蔽，因为它在所有成功指标上都表现为成功。

**次级风险与缓解**：归因失效（定义 313 代价矩阵 + 归因置信度门，<τ_attr 即全保守）；静默错配（判据 D 去量化复核 + 定义 325 对偶签名）；谄媚/框架操纵（对照框架差分 + RPS + RIG）；精度预算被对抗耗尽（AIC-QUIET 降精度攻击集 + 精度清单不可否认 + 硬预算）；量化放大对抗灵敏度（证书含 δ_q/Δ_res，低位宽自动抬高 λ 下限）。
