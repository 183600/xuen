# 第 56 轮（承接第 55 轮语义-接触接地；新灵感循环第 1 轮；本轮灵感：「创新点」×「面部表情识别」）

> 第 55 轮把“感知标签”推进到“可执行接触约束”，但只覆盖**物理表面**。本轮把“接触”扩展到**社会表面**：机器人与人共处时，真正约束动作的不只是“脚踩不踩得稳”，还有“人是否接受、是否读得懂”。灵感词「面部表情识别」提供的不只是情绪分类器，而是一整套方法论——**软标签与标注分歧、动作单元（AU）组合性、跨语料/跨主体漂移、低强度时序前兆**；灵感词「创新点」则要求反身自问：新在哪、凭什么说新。核心矛盾——**H24**：面部表情是社会可供性最直接的可观测通道，但它恰恰是**分布式的、边界模糊的、文化/主体条件化的**，与第 55 轮语义边界同构；**H25**：机器人不只应“读脸”，还应把自己的不确定性“写在脸上”，形成证书↔表达↔人类反应的闭环，而闭环本身可能放大误差；**H26**：实验室“识别率”式的创新自证在跨主体/跨语料下极易退化为重命名，需要可证伪的**创新点自证协议**。

## 0. 直觉与动机

**灵感 1（软标签与标注分歧 → 把“评价者分歧”写进证书）**
直觉：FER 里“愤怒/困惑”从来不是单标签，而是多个标注者的分布；同一表情在不同语境下含义不同。机器人技能的“成功/安全”同样如此——不同裁判/操作员对同一次演示的判定会分歧。于是把技能结论从点标签升级为**评价者分布**，证书只在标注分歧下的成功率置信下界仍达标时成立；这把“创新点”从“换模型结构”转向“可复现的评价证据”。

**灵感 2（表情 → 社会可供性，而非情绪标签）**
直觉：读脸的目的不是给情绪命名，而是判断“此刻能否靠近、能否加速、能否开玩笑”。定义社会可供性 `κ_soc(表情, 动作)`，把第 55 轮的接触可供性从“表面能承受什么”扩展到“人能接受什么”；动作空间由此被人类状态条件化。

**灵感 3（表情歧义集中在低强度/混合/遮挡 → 社会安全裕度）**
直觉：FER 最不可靠的恰是“似笑非笑、强忍恐惧”这类低强度与混合状态，而机器人此时的动作（突然靠近、启动）风险最大。与第 55 轮边界例外完全同构：**歧义大 → 站位距离增大、速度上限降低、动作更保守**。这把“读不准”显式变成控制裕度，而不是给感知打补丁。

**灵感 4（FACS 动作单元 → 共享 AU 基与“反向可读”）**
直觉：表情可分解为 AU 强度组合，天然是“可组合、可生成”的中间表示。让人脸编码器 `e_h` 与机器人表达执行器 `d_r` 共享同一 AU 基，就能把“识别”与“表达”接成一条可逆链：机器人根据自身证书裕度生成表情，再用逆 FER（`ê_r`）验证人是否能正确读出风险。表达不再是装饰，而是**证书的外部可观测投影**。

**灵感 5（微表情/时序事件 → 早期社会预警）**
直觉：微表情是 1/25~1/5 秒、低强度、类别极不平衡的“前兆事件”，与机器人接触微滑移、微失稳在统计形态上同构。把微表情 spotting 的时序方法迁移为**微前兆检测**，为护盾争取提前量；同时对人类“强忍不适”的微表情做早期社会预警。

**灵感 6（跨语料/跨主体漂移 + 「创新点」→ 自证协议）**
直觉：FER 社区用 subject-independent、cross-corpus、leakage 控制来防止“假泛化”。我们反过来用它审查本文每个 IP：它移除了哪条旧假设？有没有一个“只换名字、参数量匹配”的强基线能在同一指标上打平？若打平，它就不算创新点，只算重命名。

## 1. 形式化定义（增量：定义 127–134）

**定义 127（情感软标签、标注分歧与保形预测集）**
人脸观测 `f∈F`，情绪空间 `E`，标注者集合 `R`。软标签 `ψ(f)∈Δ(E)`，`ψ_e=(1/|R|)Σ_{r∈R} 1[y_r=e]`；标注分歧 `Δ_ann=H(ψ)`（或 `1-α_Krippendorff`）。校准后的保形预测集 `C_α(f)⊆2^E` 满足边际覆盖 `P(e*∈C_α(f))≥1-α`；连续情感 `(v,a)∈[-1,1]²` 用保形椭球 `C_α^{va}`。情感裕度 `m_a(f)=dist(ψ(f), ∂C_α(f))`，即预测分布到保形集边界的距离。

**定义 128（社会接受核）**
社会可供性 `κ_soc: E×A_WB→[0,1]` 表示在情绪 `e` 下执行动作 `a` 被人类判定为可接受/舒适的概率。保形稳健的社会动作集
`A_soc(f) = { a∈A_WB | min_{e∈C_α(f)} κ_soc(e,a) ≥ θ_s }`。
社会可行性 `viable_soc(x,f)=1 ⇔ ∃a∈A_soc(f): x_{t+1}∈𝒳_safe`。联合生存核
`K_joint(Σ,f)=K(Σ)∩K_soc(f)`，其中 `K_soc(f)={x | viable_soc(x,f)}`。

**定义 129（情感边界裕度与保守社会动作集）**
随情感裕度收缩的扰动半径 `ε_a(m_a)=ε_0·exp(-λ m_a)`；保守社会动作集
`A_soc^+(f)={a | min_{e∈B(ψ(f),ε_a(m_a))} κ_soc(e,a)≥θ_s}`。
控制耦合：最小人际距离与速度上限
`d_min^+(f)=d_0+β·1[v<0∧a>τ_a]+γ/(m_a+ε)`，`v_max^+(f)=v_0·σ(η·m_a)`。
即“越读不准，站得越远、动得越慢”。

**定义 130（共享动作单元基）**
AU 空间 `𝒜⊆[0,1]^K`。人脸编码 `e_h:F→𝒜`；机器人表达解码 `d_r:𝒜→O`（灯带/眼形/眉/嘴/头姿/手势）；机器人表达的逆感知 `ê_r:O→𝒜`。共享基有效当
`ℓ_AU=E_f[||e_h(f)-ê_r(d_r(e_h(f)))||]≤θ_AU` 且循环一致 `||z-e_h(render(d_r(z)))||≤θ_c`。

**定义 131（可读性证书）**
风险映射 `g:[0,1]→𝒜` 把证书裕度 `r` 映射为表达。人类读出的风险 `r̂~D(·|g(r))`。可读性证书
`L(g)=(ECE_a, mono, AUC)`：`ECE_a=Σ_k |P(r̂=r_k)-P(r=r_k)|`；单调 `r_i≤r_j ⇒ E[r̂|g(r_i)]≤E[r̂|g(r_j)]`；可分 `AUC(r̂;r)≥AUC_min`。可读当 `ECE_a≤θ_ece ∧ mono ∧ AUC≥AUC_min`。

**定义 132（情感鲁棒性谱）**
在表情扰动（遮挡、模糊、光照、文化/风格、主体）球 `||δ||≤ε` 内：
`ρ_aff(ε)=inf_{||δ||≤ε} P(viable_phys(x,Σ) ∧ viable_soc(x,f+δ))`；
少样本个性化校准后为 `ρ_aff^per(ε;k)`。它与第 55 轮 `ρ_sem`、第 53 轮 `ρ` 共用证书框架。

**定义 133（社会-物理-表达联合证书）**
`J_a=(Σ_core,C_core,K_margin,ρ_sem, ψ_core,C_α,A_soc^+,d_min^+,ρ_aff,g,L,δ_ann,evidence)`。
可部署 iff
(i) 第 55 轮物理条件成立；
(ii) `A_soc^+≠∅` 且 `ρ_aff≥ρ_min`；
(iii) `L(g)` 通过；
(iv) 标注分歧下成功率的置信下界 `LB_δ(δ_ann)≥θ_ann`。
闭环：执行后人类表情 `f'` 若离开 `C_α(f)`，立即重算 `K_soc(f')`、重选表达 `g(r')`，并把 `(f→a→f')` 作为反例写入 `evidence`。

**定义 134（创新点自证协议 NAP）**
一个 IP 记为四元组 `N=(type, assumption, falsifier, control)`：
`type∈{T1 新约束/形式对象, T2 新证书/界, T3 新接口/闭环, T4 新评价协议}`；
`assumption` 是被移除的旧假设；`falsifier` 是“移除该 IP 即使某定理/指标失效”的消融；`control` 是输入输出相同、参数量与数据匹配但无新内部结构的强基线。IP 成立 iff `falsifier` 显著退化，且 `control` 无法打平（否则判定为“重命名”）。

## 2. 关键算法伪代码

### IP-127 SAFE-CAL（Soft Affect + Conformal Calibration）

```python
def calibrated_affect(face, encoder, calib_set, alpha):
    logits = encoder(face)                       # soft label over E + AU intensity
    psi = temperature_scale(logits, T)           # temperature / quantile calibration
    C = conformal_set(psi, calib_set, alpha)     # e* in C with prob >= 1-alpha
    m_a = distance_to_boundary(psi, C)           # ambiguity margin
    return psi, C, m_a
```

### IP-128 SAK（Social Acceptance Kernel）

```python
def social_acceptance_kernel(psi, C, kappa_soc, theta_s, x):
    A_plus = set()
    for a in action_grid():
        worst = min(kappa_soc(e, a) for e in C)  # robust over conformal set
        if worst >= theta_s:
            A_plus.add(a)
    U = U_phys(x) & A_plus
    return (len(U) > 0), A_plus
```

### IP-129 ASF（Affective Social shield）

```python
def affect_shield(u_nom, x, K_joint, A_soc_plus, psi, m_a):
    d_min = d0 + beta * negative_arousal(psi) + gamma / (m_a + EPS)
    v_max = v0 * sigmoid(eta * m_a)
    u = qp_solve(
        H=W, g=-W @ u_nom,
        constraints=[viability_constraint(x, u, K_joint),
                     social_distance_constraint(x, u, d_min),
                     speed_constraint(u, v_max),
                     friction_cone_constraint(u, mu),
                     joint_limit_constraint(u)],
    )
    if u is None:
        return retreat(x), 'social_retreat'      # retreat != freeze
    return u, 'ok'
```

### IP-130 XAU（Shared Action-Unit Basis）

```python
def shared_au_basis(faces, robot_renders, K):
    e_h = train_encoder(faces)                   # face -> AU z
    d_r = train_decoder(robot_renders, K)        # AU z -> actuation
    e_r = train_inverse(robot_renders)           # robot display -> perceived AU
    loss = mean(||e_h(f) - e_r(d_r(e_h(f)))||) + cycle_consistency(e_h, d_r)
```

### IP-131 LCG（Legibility Certificate Generator）

```python
def legibility_certificate(g, risk_levels, human_study):
    perceived = {r: human_study.sample_perceived_risk(g(r)) for r in risk_levels}
    ece = expected_calibration_error(perceived, risk_levels)
    mono = all(mean(perceived[ri]) <= mean(perceived[rj])
               for ri, rj in consecutive(risk_levels))
    auc = separability(perceived, risk_levels)
    ok = (ece <= theta_ece) and mono and (auc >= auc_min)
    return ok, Legibility(ece, mono, auc)
```

### IP-132 ARS（Affect Robustness Spectrum）

```python
def affect_robustness_spectrum(psi_hat, eps, perturb, sampler):
    worst = 1.0
    for delta in perturb.ball(eps, worst_case=True):   # occlusion/culture/style/subject
        C = conformal_set(renormalize(psi_hat + delta), sampler.calib, alpha)
        feas_p, _ = social_acceptance_kernel(renormalize(psi_hat + delta), C,
                                             kappa_soc, theta_s, sampler.x)
        feas_w = physical_viable(sampler.x)
        p = empirical(sampler, feas_p and feas_w)
        worst = min(worst, p)
    return worst
```

### IP-133 APC（Affect-Physical Certificate）

```python
def affect_physical_certificate(traj, Sigma, psi, budgets):
    if not physical_certificate(traj, Sigma).ok:      # IP-124
        return ('reject', 'physical_fail')
    C, m_a = calibrated_affect(psi, encoder, calib, alpha)
    ok_soc, A_plus = social_acceptance_kernel(psi, C, kappa_soc, theta_s, traj.x0)
    if not ok_soc:
        return ('reject', 'social_blocked')
    rho_aff = affect_robustness_spectrum(psi, budgets.eps_aff, perturb, states)
    if rho_aff < budgets.rho_min:
        return ('reject', 'affect_robustness_fail', rho_aff)
    ok_leg, L = legibility_certificate(g, risk_levels, human_study)
    if not ok_leg:
        return ('reject', 'illegible_expression', L)
    delta_ann = annotator_disagreement(traj, raters)
    if lower_bound_success(traj, delta_ann) < budgets.theta_ann:
        return ('reject', 'evaluation_uncertain', delta_ann)
    return ('ok', JointAffectCert(Sigma.core, A_plus, rho_aff, g, L, delta_ann))
```

### IP-134 NAP（Novelty Audit Protocol）

```python
def novelty_audit(ip, metric, delta, data_budget):
    r_full = evaluate(ip, metric, data_budget)
    r_abl = evaluate(ablate(ip), metric, data_budget)      # falsifier
    r_ctl = evaluate(relabel_control(ip), metric, data_budget)  # matched capacity
    is_novel = (r_abl <= r_full - delta) and (r_ctl < r_full - delta)
    return NoveltyReport(ip.id, ip.type, ip.assumption, is_novel,
                         falsifier_gap=r_full - r_abl,
                         control_gap=r_full - r_ctl)
```

**正确性定理（Affect-Certified Social-Physical Soundness）**
假设第 55 轮 (A26)–(A32) 成立，并新增：
**(A33)** 保形集满足边际覆盖 `P(e*∈C_α)≥1-α`（可交换性或近可交换性）；
**(A34)** `κ_soc` 经跨主体人类研究校准，且在 AU 上单调；
**(A35)** 共享 AU 基满足循环一致 `ℓ_AU≤θ_AU`；
**(A36)** 可读性研究为 subject-independent 且样本量满足置信；
**(A37)** 人类情感状态相对控制频率慢变（或动作间有 dwell time）；
**(A38)** 评价者分歧经 Krippendorff α 检验，`δ_ann<Θ_ann`。
则单步“物理安全 ∧ 社会接受 ∧ 可读”的概率下界：
```
P ≥ 1 - P(||Σ-Σ̂||>ε_s) - P(e*∉C_α) - P(κ_soc miscalibrated)
      - P(ρ_aff<ρ_min) - P(¬L(g)) - P(retreat fails) - P(δ_ann>Θ_ann)
```
关键：**社会不确定性进证书、表达是证书的外部投影、评价分歧进成功判据**；三层任一层失守，都不允许把“看起来在笑”当作“可以靠近”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 保形覆盖依赖可交换性，部署分布漂移后失效 | 高 | 在线覆盖监控 + 自适应 conformal + OOD 拒识 |
| κ_soc 文化偏置，导致对某些人群过度保守/冒犯 | 高 | 分层文化标定 + 主体个性化 + 审计面板 |
| 表达可读性制造“虚假安心”，削弱物理安全 | 高 | 表达只增强不替代物理护盾 + 风险表达下限 |
| 人机闭环振荡（机器人表情改变人的表情） | 中 | dwell time + 变化率限制 + 闭环稳定性检验 |
| NAP 被“调参到通过”而失去证伪力 | 中 | 预注册判据 + 第三方复现 + 负对照盲测 |
| 多模态隐私（摄像头读脸） | 高 | 端侧处理、不存原图、最小化情感表征 |

## 6. 本轮最大风险

**一句话**：把面部表情提升为社会可供性与表达闭环，等于把“人类反应”接进控制回路，而保形覆盖只在可交换性下成立、`κ_soc` 又必然带文化与主体偏置——一旦跨域漂移或可供性失准，机器人要么陷入“社会性冻结”，要么用可读的表情给出**虚假安心**，让物理护盾被社会信任绕过；因此必须以**在线覆盖监控 + 分文化/分主体标定 + 表达永不替代物理安全**三重护栏，宁可保守后退，绝不把“人看起来接受”当作“人已经安全”。

### IP-131 LCG

```python
def legibility_certificate(g, risk_levels, human_study):
    perceived = {r: human_study.sample_perceived_risk(g(r)) for r in risk_levels}
    ece = expected_calibration_error(perceived, risk_levels)
    mono = all(mean(perceived[ri]) <= mean(perceived[rj])
               for ri, rj in consecutive(risk_levels))
    auc = separability(perceived, risk_levels)
    return (ece <= theta_ece) and mono and (auc >= auc_min), Legibility(ece, mono, auc)
```

### IP-132 ARS

```python
def affect_robustness_spectrum(psi_hat, eps, perturb, sampler):
    worst = 1.0
    for delta in perturb.ball(eps, worst_case=True):
        psi = renormalize(psi_hat + delta)
        C = conformal_set(psi, sampler.calib, alpha)
        feas_s, _ = social_acceptance_kernel(psi, C, kappa_soc, theta_s, sampler.x)
        p = empirical(sampler, feas_s and physical_viable(sampler.x))
        worst = min(worst, p)
    return worst
```

### IP-133 APC

```python
def affect_physical_certificate(traj, Sigma, psi, budgets):
    if not physical_certificate(traj, Sigma).ok:
        return ('reject', 'physical_fail')
    C, m_a = calibrated_affect(psi, encoder, calib, alpha)
    ok_soc, A_plus = social_acceptance_kernel(psi, C, kappa_soc, theta_s, traj.x0)

    if rho_aff < budgets.rho_min:

    if not ok_leg:
        return ('reject', 'illegible_expression', L)
    delta_ann = annotator_disagreement(traj, raters)
    if lower_bound_success(traj, delta_ann) < budgets.theta_ann:

    return ('ok', JointAffectCert(Sigma.core, A_plus, rho_aff, g, L, delta_ann))
```

### IP-134 NAP

```python
def novelty_audit(ip, metric, delta, data_budget):
    r_full = evaluate(ip, metric, data_budget)
    r_abl = evaluate(ablate(ip), metric, data_budget)
    r_ctl = evaluate(relabel_control(ip), metric, data_budget)
    is_novel = (r_abl <= r_full - delta) and (r_ctl < r_full - delta)
    return NoveltyReport(ip.id, ip.type, ip.assumption, is_novel,
                         falsifier_gap=r_full - r_abl,
                         control_gap=r_full - r_ctl)
```

**正确性定理（Affect-Certified Social-Physical Soundness）**
假设第 55 轮 (A26)–(A32) 成立，并新增：
**(A33)** `P(e*∈C_α)≥1-α`（可交换性或近可交换性）；
**(A34)** `κ_soc` 经跨主体人类研究校准且对 AU 单调；
**(A35)** `ℓ_AU≤θ_AU`；
**(A36)** 可读性研究 subject-independent 且样本量满足置信；
**(A37)** 人类情感状态相对控制频率慢变（或动作间有 dwell time）；
**(A38)** `δ_ann<Θ_ann` 且 Krippendorff α 检验通过。
则单步“物理安全 ∧ 社会接受 ∧ 可读”的概率下界：
```
P ≥ 1 - P(||Σ-Σ̂||>ε_s) - P(e*∉C_α) - P(κ_soc miscalibrated)
      - P(ρ_aff<ρ_min) - P(¬L(g)) - P(retreat fails) - P(δ_ann>Θ_ann)
```
关键：**社会不确定性进证书、表达是证书的外部投影、评价分歧进成功判据**。

## 8. 本轮最大风险

**一句话**：社会-情感层把“人类反应”接进控制回路，而保形覆盖只在可交换性下成立、`κ_soc` 必然带文化与主体偏置——一旦跨域漂移或可供性失准，机器人要么“社会性冻结”，要么用可读表情给出**虚假安心**，让物理护盾被社会信任绕过；因此必须以**在线覆盖监控 + 分文化/分主体标定 + 表达永不替代物理安全**三重护栏，宁可保守后退，绝不把“人看起来接受”当作“人已经安全”。
