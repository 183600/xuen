# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 1 轮；本轮灵感：「社会规范理解」×「多模态大模型」）

> 第 54 轮把技能组合推进为「动作剖面 `α_S` + 云边协同 `γ_ce` + 动作-鲁棒性联合证书 `J`」。但它仍默认一个更深的单源假设：**「可执行且安全」就等于「该做」**。本轮用两个灵感词正面击穿它：**H22（规范的伪单源）**——多模态大模型（MLLM）给出的规范判断被当成真值，没有任何第二来源去反驳，规范违背因此是静默的；**H23（规范的情境性与多元性）**——规范不是全局标量，而是随文化、场景、在场者、角色关系、紧急度变化的分布，脱离有效域签发的规范证书必然跨情境失效；**H24（规范-任务-安全的三角冲突）**——合规动作可能不可行或不安全，安全动作可能失礼，过度合规会把机器人退化成「什么都不做的礼貌机器」。核心命题：**把社会规范当作「多源含噪测量 + 有效域 + 可弃权」的对象，而不是一个标签；用多模态冗余接地、规范剖面 `β_S`、三向可行域与询问/弃权通道，把「懂礼貌」变成可证伪、可签发、可撤销的证书。**

## 0. 直觉与动机

**灵感 1（规范是含噪的多源测量，不是单点真值）**
直觉：让一个 MLLM 判断「现在把老人搀起来是否失礼」，它会给出一个很像答案的答案，但它没有告诉你：这个判断在什么文化下成立、它有多确定、别的来源是否同意。若再问五个由同一基座微调出的「人格」，它们会高度相关地一起错——**相关源投五票不等于五个证据**。规范理解更像用多个含噪传感器测一个不可直接观测的量 `μ*`：多源要按可信度加权，相关源要按**有效样本量 `n_eff`** 折价，点估计要换成**可信下界**。
→ 把「规范判断」建模为对潜在规范度 `μ*(x,a)` 的多源观测，用 `n_eff` 与 Beta 可信下界签发；**分歧本身就是「此处有规范歧义」的报警器**，而不是被多数投票抹平的噪声。

**灵感 2（规范剖面 `β_S`：给每个动作一个「得体度」，与 `α_S` 对偶）**
直觉：第 54 轮的 `α_S(a)` 回答「这个技能能不能做出动作 a」；本轮补上 `β_S(a|x)` 回答「在情境 x 下做动作 a 有多得体」。两者共同构成动作的**双剖面**：`α_S` 是能力约束，`β_S` 是规范约束。组合技能时不能只看动作交集，还要看**规范一致性**——「先打招呼再立刻背过身」每个动作都合规，连起来却失礼。于是组合图 `G_S` 的边要附加「规范张力 `T_seq`」，规范不是终点检查，而是沿路径累积的约束。
→ 规范进入**规划的第一性约束**，与第 54 轮的动作空间并列，而不是事后过滤器。

**灵感 3（有效域：规范证书必须带「在哪儿、对谁、到何时有效」）**
直觉：一句「这样很礼貌」离开情境就是空话。同一个递物动作，在东亚双手递、在北欧单手递都可能得体；面对儿童、长者、同事的规范也不同。更麻烦的是规范会变：节日、疫情、新礼仪都会让旧证书过期。因此规范证书必须携带**情境有效域 `V_S`** 与**规范时域 `T_norm`**，出域或过期即撤销，像药品的有效期与适应症。
→ 用分布外检测 + conformal 覆盖保证「在 `V_S` 内误差有界」，用 `T_norm` 做证书的**时效管理**，杜绝全局复用。

**灵感 4（三向可行域：合规 ∩ 安全 ∩ 可行，且「弃权」是一等动作）**
直觉：现实中常常三者不可兼得：帮人捡药是合规且安全但当前任务要迟到；快速穿过人群任务可行但失礼；在不确定对方是否愿意被触碰时，**最得体的动作可能是先询问或后退半步**。因此动作集不该只有「做/不做」，而应有 `{act, ask, defer, halt}` 四类，且当可行域为空时，弃权/询问不是失败，而是**唯一可证成（justified）的动作**。
→ 定义三向可行域 `F(x)=N(x)∩Safe(x)∩Task(x)`，并给「审慎规范性（prudent normativity）」一个显式代价函数：不确定时宁可先问/先停，也不把单源规范当部署前提。

**灵感 5（多模态接地 = 规范的冗余传感器 + 跨模态一致性证据）**
直觉：规范谓词依赖「谁在场、什么关系、什么表情/语气、物体归谁」。视觉给人物与场景，语音给语气与称呼，手势/近距学（proxemics）给距离与朝向，文本给任务意图。多模态的价值不是「更炫」，而是**对同一规范谓词提供独立观测**：当视觉说「对方在微笑」、语音说「语气僵硬」时，跨模态一致性 `c_mm` 下降，这正是规范歧义的证据。仅由单一模态支撑的谓词要被标为**单源谓词**，与 H22 同构。
→ 把「多模态」用成**可证伪的冗余观测**，而不是新的黑箱；同时明确隐私与同意边界（读取面部/情绪需最小化与授权）。

**灵感 6（云边分工：慢思辨在云、快评论在边、拿不准就询问/停下）**
直觉：云端大模型适合慢速、多源、长上下文的规范思辨与证书更新；边端需要毫秒级判断，只能跑**蒸馏后的规范评论器**并输出不确定性；一旦 `κ` 低、`x∉V`、或 `F=∅`，边端触发**规范延迟/询问通道 `NDC`**，把「拿不准」显式交还给人类，而不是赌一把。这把第 54 轮的云规划-边校验扩展成「**云思辨-边评论-人兜底**」的三级闭环。
→ 规范接地必须是**可弃权**的：会说自己「不知道」的系统，才可能被信任去处理社会规范。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（规范情境与规范谓词）**
规范情境 `x = (s, 𝒜, R, c, τ, e)`：`s` 场景、`𝒜` 在场者集合、`R` 角色/关系、`c` 文化/群体先验、`τ` 任务、`e` 紧急度与可观测情绪。规范束 `N = {n_k}`，每个 `n_k = (scope_k, pre_k, exc_k, sev_k, eval_k)` 分别是适用范围、前提、例外、严重度 `sev_k∈[0,1]`、评价者群体。规范谓词 `μ_k(x,a)∈[0,1]` 表示动作 `a` 在 `x` 下满足 `n_k` 的程度。**规范区域图** `H_x` 是 `(𝒜, R, s, τ)` 上的带角色标注图，谓词在图上组合求值（如「递物给长者需双手」是 `(agent, elder, give, two_hands)` 的四元约束）。

**定义 122（多源规范观测、共识与有效样本量）**
来源群体 `P`（不同 MLLM 人格/基座、人类评分、符号规则、轻量验证器），来源 `j` 给 `y_j(x,a)∈[0,1]`，可信度 `w_j` 由留出集校准给出。聚合估计
```
μ̂(x,a) = Σ_j w_j y_j / Σ_j w_j
n_eff    = (Σ_j w_j)² / Σ_j w_j²          # 相关源被折价
κ(x,a)   = max(0, 1 - 2·sqrt(Σ_j w_j (y_j-μ̂)² / Σ_j w_j))   # 加权共识
```
**可信下界**：把 `k_eff = n_eff·μ̂` 看作 Beta 后验 `Beta(k_eff+1, n_eff-k_eff+1)`，取单侧下界 `μ_lo(x,a)`。**签发只认 `μ_lo`，不认点估计 `μ̂`**——这是对相关源「抱团互证」的结构性防线。

**定义 123（规范动作空间与情境有效域）**
规范动作空间 `N_θ(x) = {a∈A : μ_lo(x,a) ≥ θ_norm ∧ κ(x,a) ≥ θ_con}`。情境有效域 `V_S ⊆ X` 由 conformal 校准给出：对 `x∈V_S`，以概率 `≥1-δ` 有 `|μ̂(x,·) - μ*_true(x,·)| ≤ ε_norm`；`x∉V_S` 视为规范分布外。规范时域 `T_norm`：证书仅在 `t - t_sign ≤ T_norm` 内有效，规范漂移超过 `Δ_norm` 或出现新群体锚点即触发重认证。

**定义 124（规范剖面与规范一致性）**
技能 `S` 的规范剖面 `β_S(a|x) = μ_lo(x,a)`（与第 54 轮 `α_S(a)` 对偶）。技能序列 `σ=⟨S_1,...,S_k⟩` 的**规范张力**
```
T_seq(σ,x) = max_t  [ max_{a∈A_t, a'∈A_{t+1}} (β(a|x) + β(a'|x) - 2·β_pair((a,a')|x)) / 2 ]
```
其中 `β_pair` 为相邻动作对的联合得体度（捕捉「礼貌承诺后立刻反悔」这类**组合性失礼**）。规范一致当且仅当 `T_seq ≤ τ_norm`。

**定义 125（三向可行域与规范不可行）**
`F(x) = N_θ(x) ∩ Safe(x) ∩ TaskFeasible(x)`。**规范不可行度** `g(x) = dist(TaskFeasible(x)∩Safe(x), N_θ(x))`（到规范域的距离，空集时为罚项）。当 `F(x)=∅` 时称情境**规范不可行**，此时唯一可证成动作落在 `{ask, defer, halt}`，不允许「硬做 + 事后道歉」。

**定义 126（规范证书 `NC`）**
`NC = (μ̂, μ_lo, κ, n_eff, V_S, θ_norm, θ_con, T_norm, T_seq, conflict_set, c_mm, provenance)`：
- `conflict_set` 记录冲突的规范对及严重度；
- `c_mm` 为跨模态一致性（定义 127）；
- `provenance` 保存各来源身份、权重与反例。
**可部署条件**：`x∈V_S ∧ t≤T_norm ∧ μ_lo≥θ_norm ∧ κ≥θ_con ∧ T_seq≤τ_norm ∧ F(x)≠∅`（否则走询问/弃权）。

**定义 127（跨模态规范接地一致性）**
把情境图上的每个谓词 `p` 在各模态 `m` 上的接地结果记为 `z_{p,m}∈[0,1]`，跨模态一致性
```
c_mm(x) = 1 - (1/|P_x|) Σ_p  (2·sd_m(z_{p,m}) / (mean_m(z_{p,m})+ε))
```
若某谓词仅由单一模态支撑，标记为**单源谓词**，其权重按 `1/n_eff(p)` 折价，并在 `NC.provenance` 中显式记录。涉及面部/情绪/身份等敏感模态时，遵循同意与最小化原则：默认只取完成规范判定所需的最低粒度。

**定义 128（规范仲裁与询问/弃权策略）**
`π_norm : (F(x), μ_lo, κ, g, sev, task_cost) → {act(a*), ask(q), defer, halt}`。目标为
```
min_π  E[ task_cost + λ_n·Σ_k sev_k·1[violate n_k] + λ_s·interaction_cost + λ_d·delay ]
```
约束：**安全是硬约束**；**规范在有效域内是硬约束**；当 `κ<θ_con` 或 `x∉V_S` 或 `F=∅` 时，`act` 被**定义域排除**，只能 `ask/defer/halt`。这就是「审慎规范性」的显式定义：不确定性直接映射为**降低自主性**，而不是提高动作幅度。

## 2. 关键算法 伪代码

### IP-121 NPE（Norm Profile Elicitation）

```python
def norm_profile(x, a, sources, weights, theta_norm, theta_con):
    ys = [s.query(x, a) for s in sources]            # 各来源的规范观测
    w  = [weights[s.id] for s in sources]
    mu = sum(wi*yi for wi, yi in zip(w, ys)) / sum(w)
    n_eff = sum(w)**2 / sum(wi**2 for wi in w)       # 相关源折价
    var = sum(wi*(yi-mu)**2 for wi, yi in zip(w, ys)) / sum(w)
    kappa = max(0.0, 1.0 - 2.0*var**0.5)
    mu_lo = beta_ppf(0.05, n_eff*mu + 1, n_eff*(1-mu) + 1)   # 单侧 95% 下界
    return NormObs(mu, mu_lo, kappa, n_eff)
```

### IP-122 NVC（Norm Validity Certificate）

```python
def valid_domain(calib_contexts, alpha=0.05):
    # split-conformal / 密度水平集给出情境有效域
    scores = [conformity(c) for c in calib_contexts]
    q = quantile(scores, 1 - alpha)
    return ValidityDomain(q), alpha

def certify(x, nc_obs, V, t_sign, T_norm, t_now, c_mm, T_seq):
    if x not in V:                 return ('out_of_domain', V)
    if t_now - t_sign > T_norm:    return ('expired', T_norm)
    if nc_obs.mu_lo < THETA_NORM:  return ('weak_norm', nc_obs.mu_lo)
    if nc_obs.kappa < THETA_CON:   return ('ambiguous', nc_obs.kappa)
    if c_mm < THETA_MM:            return ('single_source', c_mm)
    if T_seq > TAU_NORM:           return ('incoherent_seq', T_seq)
    return ('valid', NC(nc_obs, V, T_norm, c_mm, T_seq))
```

### IP-123 NAS（Norm-Action-Safety Arbitration）

```python
def arbitrate(x, candidates, beta, safe, task, policy):
    F = [a for a in candidates
         if beta(x, a).mu_lo >= THETA_NORM
         and beta(x, a).kappa >= THETA_CON
         and safe(a) and task.feasible(a)]
    if not F:
        return policy.choose('defer', reason='empty_three_way_feasible')
    a = min(F, key=lambda a: task.cost(a) + LAM_N*(1-beta(x, a).mu_lo))
    if beta(x, a).kappa < THETA_CON or x not in policy.V:
        return policy.choose('ask', target='human', question=clarify(x))
    return ('act', a)
```

### IP-124 DNC（Distilled Norm Critic）

```python
def distill(teacher, V, calib_loader, epochs):
    edge = MultimodalCritic(heads=('mu', 'sigma', 'abstain'))
    for x, a, y in calib_loader:                       # 只在 V 内蒸馏
        mu, sigma = teacher(x, a), teacher.uncertainty(x, a)
        loss = huber(edge.mu(x, a), mu) + calib_loss(edge.sigma(x, a), sigma) \
             + bce(edge.abstain(x, a), float(sigma > SIGMA_MAX))
        edge.step(loss)
    return edge, fidelity_report(edge, teacher, V), ece(edge, calib_loader)
```

### IP-125 NDC + IP-126 NGTC（Deferral Channel / Norm-Grounded Transfer Certificate）

```python
def norm_deferral(x, nc, F, human_budget):
    if nc.mu_lo < THETA_NORM or nc.kappa < THETA_CON or not F:
        if human_budget > 0 and sev_max(nc) >= SEV_ASK:
            return ('ask', clarify_question(nc))
        return ('halt' if sev_max(nc) >= SEV_HALT else 'defer', None)
    return ('act', None)

def transfer_certify(NC_src, x_tgt, delta_norm_budget, delta_mm_budget):
    if x_tgt not in NC_src.V:
        return ('reject', 'context_out_of_domain')
    drift = norm_drift(NC_src.provenance, x_tgt)
    if drift > delta_norm_budget:
        return ('reject', 'norm_drift_exceeds', drift)
    if mm_shift(NC_src.c_mm, x_tgt) > delta_mm_budget:
        return ('reject', 'modality_shift', mm_shift(NC_src.c_mm, x_tgt))
    return ('ok', NGTC(NC_src, x_tgt, drift, ttl=min(NC_src.T_norm, T_LOCAL)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| NPE | `O(|P|·|A|)` | `O(|P|)` | 权重校准、`n_eff` 折价、Beta 下界 |
| NVC | `O(|X_calib|·log|X_calib|)` | `O(|X_calib|)` | conformal 覆盖、有效域与时域 |
| NAS | `O(|A|·|N| + QP)` | `O(|A|)` | 三向约束 sound、弃权完备 |
| DNC | `O(|V|·epochs)` | `O(|θ_edge|)` | 保真度、校准、弃权覆盖 |
| NDC | `O(|N|)` | `O(1)` | 低置信不接受、人类预算不超 |
| NGTC | `O(|X_tgt|·|P|)` | `O(|P|)` | 漂移预算闭合、时域相交 |

**正确性定理（Norm-Grounded Compliance Soundness）**
假设：(A29) 来源权重在留出集校准，且 `n_eff ≥ n_min`，故 Beta 下界有效；(A30) `x∈V_S`，conformal 覆盖给出 `|μ̂-μ*_true|≤ε_norm`（概率 `≥1-δ`）；(A31) 边端评论器保真 `|μ̂_e-μ̂|≤ε_fid` 且校准误差 `ECE≤ε_cal`；(A32) 安全滤波把动作投影回 `Safe(x)`，干预残差 `≤β_max`；(A33) `t≤T_norm` 且 `conflict_set` 已解决（`T_seq≤τ_norm`）。
则当策略在 `F(x)=∅` 或 `κ<θ_con` 时弃权，有
```
P(norm violation | act) ≤ (1-θ_norm) + ε_norm + ε_fid + ε_cal + P(x∉V_S)·1
```
**证明思路**：对「真实规范度低于阈值」与「估计误差超界」两个事件做并集界；`n_eff` 折价保证 `μ_lo` 是保守下界，因此 `μ_lo≥θ_norm` 蕴含 `μ*_true≥θ_norm-ε_norm` 以高概率成立；弃权分支把「空可行域」从违背事件中移出（代价是任务延迟，而非规范违背）。证毕。

**推论（弃权的代价守恒）**：`E[task_cost]` 最多增加 `λ_d·P(defer) + λ_s·P(ask)`；但只要 `P(ask)+P(defer)` 可观测且被预算约束，系统就能在**自主性与得体性之间显式换取**，而不是隐式地牺牲一方。

**消融**：去 `n_eff`（用多数投票）、去 `V_S`（全局证书）、去 `c_mm`（仅文本规范）、去 NDC（禁止弃权）四组，分别检验 H22/H23/H24。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 相关源虚假共识（多个人格一起错） | 高 | `n_eff` 折价 + 独立基座/人类锚点 + 规则源 + Beta 下界 |
| 规范标签本身带文化偏见 | 高 | 多群体锚点、显式 `provenance`、少数群体红队、可申诉 |
| 有效域欠覆盖导致静默复用 | 高 | conformal + OOD 拒答 + `T_norm` 过期 + 迁移证书 |
| 过度弃权使机器人「无用」 | 中 | 弃权预算 + 分级 `ask/defer/halt` + 主动学习补标 |
| 多模态隐私（面部/情绪） | 高 | 同意与最小化、边缘脱敏、只取判定所需粒度 |
| 三角冲突下「礼仪压过安全」 | 高 | 安全硬约束优先，规范冲突显式上报人类 |

## 6. 本轮最大风险

**一句话**：把社会规范做成「多源共识 + 有效域 + 弃权」的证书，最大的风险不是模型不够聪明，而是**相关源制造的虚假共识会被统计上「看起来更可信」地下界认证成规范真值**——多个同源 MLLM 人格一起错时 `μ̂` 很高、`κ` 也高，若不对 `n_eff` 做结构性折价，系统就会以高置信度、跨情境地系统性伤害少数群体与跨文化规范；因此必须以**独立来源 + 有效样本量折价 + 人类/少数群体锚点 + 强制弃权**作为不可绕过的前置，宁可让机器人先说「我不确定」，也绝不把「投出来的多数」当成「规范的真理」。

## 2. 关键算法 伪代码

### IP-121 NPE

```python
def norm_profile(x, a, sources, weights):
    ys = [s.query(x, a) for s in sources]
    w  = [weights[s.id] for s in sources]
    W  = sum(w)
    mu = sum(wi*yi for wi, yi in zip(w, ys)) / W
    n_eff = W**2 / sum(wi**2 for wi in w)          # 相关源折价
    var = sum(wi*(yi-mu)**2 for wi, yi in zip(w, ys)) / W
    kappa = max(0.0, 1.0 - 2.0*var**0.5)
    mu_lo = beta_ppf(0.05, n_eff*mu + 1, n_eff*(1-mu) + 1)
    return NormObs(mu, mu_lo, kappa, n_eff)
```

def build_valid_domain(calib_contexts, alpha=0.05):

def certify(x, obs, V, t_sign, T_norm, t_now, c_mm, T_seq):

### IP-123 NAS

```python
def arbitrate(x, candidates, beta, safe, task, V, human_budget):
    F = [a for a in candidates
         if beta(x, a).mu_lo >= THETA_NORM
         and beta(x, a).kappa >= THETA_CON
         and safe(a) and task.feasible(a)]
    if not F:
        return deferral(x, candidates, beta, human_budget, reason='empty_F')
    a_star = min(F, key=lambda a: task.cost(a) + LAM_N*(1-beta(x, a).mu_lo))
    if beta(x, a_star).kappa < THETA_CON or x not in V:
        return deferral(x, [a_star], beta, human_budget, reason='uncertain')
    return ('act', a_star)
```

### IP-124 DNC

```python
def distill(teacher, V, loader, epochs, SIGMA_MAX):
    edge = MultimodalCritic(heads=('mu','sigma','abstain'))
    for epoch in range(epochs):
        for x, a, y in loader:
            if x not in V:                       # 只在有效域内蒸馏
                continue
            mu, sigma = teacher(x, a), teacher.uncertainty(x, a)
            loss = huber(edge.mu(x, a), mu) \
                 + calib_loss(edge.sigma(x, a), sigma) \
                 + bce(edge.abstain(x, a), float(sigma > SIGMA_MAX))
            edge.step(loss)
    return edge, fidelity(edge, teacher, V), ece(edge, loader)
```

def deferral(x, candidates, beta, human_budget, reason):

def norm_coherence(skill_seq, beta_pair):
    T = 0.0
    for s1, s2 in zip(skill_seq, skill_seq[1:]):
        for a in s1.actions:
            for a2 in s2.actions:
                T = max(T, (beta(a) + beta(a2) - 2*beta_pair(a, a2)) / 2)
    return T

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| NPE | `O(|P|·|A|)` | `O(|P|)` | 权重校准、`n_eff` 折价、Beta 下界单调 |
| NVC | `O(|X_calib| log|X_calib|)` | `O(|X_calib|)` | conformal 覆盖 `1-α`，时域单调查 |
| NAS | `O(|A|·|N| + QP)` | `O(|A|)` | 三向约束 sound，`F=∅` 必弃权 |
| DNC | `O(|V|·epochs)` | `O(|θ_edge|)` | 保真 ≤ ε_fid、ECE ≤ ε_cal、弃权覆盖 |
| NDC | `O(|N|+|A|)` | `O(1)` | 人类预算不超、低置信不接受 |
| NGTC | `O(|X_tgt|·|P|)` | `O(|P|)` | 漂移预算闭合、TTL 正 |

**正确性定理（Norm-Grounded Compliance Soundness）**
假设 (A29)–(A33) 承接想法区，则弃权策略下：
```
P(norm violation | act) ≤ (1-θ_norm) + ε_norm + ε_fid + ε_cal
```
**代价界**：`E[task_cost] ≤ E[task_cost | 无约束] + λ_d·P(defer) + λ_s·P(ask) + λ_n·E[sev]`。
**关键**：`μ_lo` 是保守下界，故「签发」这一步已把相关源的乐观偏差**结构性扣掉**；弃权把「空可行域」从违背事件中移除，只付出延迟/交互代价。

## 4. 示意性数值结果（合成数据，非真实实验）

用于说明 `n_eff` 折价的必要性。设 5 个同源 MLLM 人格，共同偏差使真实规范度 `μ*=0.45`，但观测均值 `μ̂=0.80`：

| 配置 | `n_eff` | `μ_lo`（95% 单侧下界） | 误签发率 | 规范违背率 |
|---|---|---|---|---|
| 多数投票（忽略相关） | 5.0 | 0.62 | 4% | 11% |
| 仅 `n_eff` 折价（ρ=0.9） | 1.2 | 0.43 | 18% | 6% |
| `n_eff` + Beta 下界阈值 | 1.2 | 0.43 | 3% | 3% |
| 加入人类/规则锚点 | 3.6 | 0.63 | 2% | 2.5% |

**读法**：光有 `n_eff` 不够，还要**用下界而非点估计**做签发；加入独立锚点后 `n_eff` 与下界同时回升，说明「真正的独立性」不能被同源人格的数量伪造。
