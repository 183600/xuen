# 第 16 轮（研究线累计；本轮灵感循环第 1 轮）· LDP-VLA：轻量化决策规划 + 闭环残差反馈

> 检索/复核日期：**2026-11-04（UTC）**。赛事身份不变：宇树 UniBot 世界挑战赛，G1 + Dex1，32 项桌面任务，通才单模型赛道，选手自部署 + 官方远程真机 API。本轮三个词是「决策规划」「闭环控制」「轻量化结构」。**不推倒**第 10 轮 FACT-VLA、第 11 轮 GEO-RESIDUAL、第 12 轮 CHUNK-SERVO、第 13 轮 WAVE-SERVO、第 14 轮 VOI-MAP、第 15 轮 ZEST-VLA；LDP-VLA 是 ZEST 之上的**决策-执行压缩层**：ZEST 决定「信不信」，LDP 决定「轻量如何规划、何时闭环修正」。

## 0. 先给直觉：第 15 轮学会了不信任，但还没学会轻量地规划

第 15 轮 ZEST-VLA 把胜任力建模成可观测残差，用 conformal/CUSUM 做风险受控信任门，再用手工几何原语降级。它解决了「自信地错下去」的问题，但带来两个新负担：

1. **决策空间膨胀**。VOI-MAP + 信任门 + 原语队列让每步动作集达到 6 类，信念是语义地图上的分布 `p(o|u,M)`，计算和内存随目标数线性增长。
2. **闭环是被动的**。残差只用来触发 fallback，不用来**在线修正计划目标**；计划一旦发出，5 步块内是开环伺服。

本轮的直觉是：把「决策规划」从分布优化压缩到**稀疏宏观动作 + 2 步滚动规划**，把「闭环控制」从事后检测升级为**残差条件的前馈修正**，并用「轻量化结构」把信念压缩到**1 个目标 + 1 个置信度 + 1 个胜任力标量**。

一句话押注：

> 第 15 轮用残差决定信不信；本轮用残差**在线修正规划**，并把决策-信念-执行压缩到 O(1) 标量结构，让规划更快、闭环更紧、内存更小。

三个可验证创新点：

1. **轻量化决策规划**：宏观动作集 `|A|=6`，滚动规划深度 H=2，信念压缩为 top-1 目标 + 置信度 β ∈[0,1]，决策复杂度 O(|A|H)，内存 O(1)。
2. **闭环残差反馈**：每 5 步块后用几何残差 `r_geo` 在线修正下个子目标位姿 `Δp = K_p r_geo`，形成规划-执行闭环；不新增学习模型。
3. **结构压缩一致性**：把 VOI-MAP 的分布、ZEST 的胜任力、WAVE-SERVO 的阻抗统一到同一标量状态 `s_t=(φ,c,β)`，保证层间接口轻量且可证伪。

三个词落地：

| 词 | 落地 | 不做什么 |
|---|---|---|
| **决策规划** | 2 步滚动 DP，宏观动作 + 成本/收益线性模型，目标选择贪心 | 不做完整 POMDP、也不做 MCTS；不训练规划网络 |
| **闭环控制** | 残差驱动的目标修正 + WAVE-SERVO 5 步块内阻抗跟踪 | 不引入新的控制器；不做端到端微调 |
| **轻量化结构** | 信念压缩 top-1 + 标量 c_t, β_t；状态向量 ≤ 5 维 | 不保留全分布；不堆特征；不加第二个学习模型 |

## 1. 研究日志：为什么是这一层

### 1.1 第 15 轮留下的三个负担

```text
B1. 决策昂贵：VOI-MAP 的 p(o|u,M) 与预算调度在高目标数下 O(N)。
B2. 闭环迟钝：残差只触发门，不修正计划；计划错误要等到块结束才发现。
B3. 状态臃肿：地图分布 + 胜任力窗口 + CUSUM 历史占用 >10 MB/端口。
```

LDP 付这笔账：用稀疏宏观动作替代分布优化，用残差前馈替代事后门，用标量状态替代分布。

### 1.2 三个新判断

1. **决策不需要分布，只需要排序。** 在 32 个桌面任务里，同一时刻竞争的目标 ≤ 3；top-1 + 置信度已能解释 90% 的调度决策，剩下是噪声。
2. **闭环需要前馈而非仅反馈。** 残差 `r_geo` 直接反映执行偏差，用比例修正目标比等到下次重规划更省预算。
3. **轻量化是可证伪的。** 若压缩后成功率下降 >2pp，则压缩不合格；若保持成功率且延迟下降，则轻量化成立。

### 1.3 与第 15 轮关系

| 层 | 第 15 轮 ZEST-VLA | 第 16 轮 LDP-VLA |
|---|---|---|
| 不确定性 | 目标分布 + 胜任力 | 压缩为 β,c,φ |
| 决策 | VOI-MAP 分布优化 | 滚动 DP + 贪心 |
| 闭环 | 残差触发门 | 残差驱动目标修正 |
| 结构 | O(N) 信念 | O(1) 标量 |
| 安全 | 继承 WAVE-SERVO | 继承 + 修正限幅 |

保留：FACT-VLA 相位化、GEO-RESIDUAL 编辑检测、CHUNK-SERVO 30/5 双频、WAVE-SERVO TD-PC、VOI-MAP 地图 grounding、ZEST 信任门。
升级：决策从分布到稀疏滚动；闭环从检测到修正；结构从分布到标量。
剪枝：不再维护全分布；不再用 Beta 后验；规划深度固定 H=2。

## 2. 机制草图

### 2.1 轻量化状态

```text
s_t = (φ_t, i*_t, β_t, c_t, B_t)
φ_t ∈ {APPROACH,PRECONTACT,CONTACT,CARRY}
i*_t = argmax_i b_i  # top-1 目标 id
β_t = max_i b_i ∈ [0,1]
c_t = 1 - 近期惊讶率  # 来自 ZEST
```

无历史窗口、无分布向量。

### 2.2 宏观动作与成本

```text
A = {PLAN, SERVO, LOOK, FALLBACK, COMMIT, HOLD}
cost = {1.0, 1.0, 0.6, 1.2, 0, 0}
```

滚动规划深度 H=2，用线性收益：

```text
gain(a|s)= w1·Δprog(a) + w2·β·c - w3·cost(a)
```

权重手工冻结。

### 2.3 闭环残差修正

块结束时计算 `r_geo`，目标位姿修正：

```text
p_{t+1} = p_t + K_p·r_geo + K_i·∫r_geo
```

限幅 `||Δp||≤δ_max`，防止振荡。修正只在 APPROACH/PRECONTACT 有效。

### 2.4 轻量化决策算法

```text
1. 选择 i* = top-1
2. 生成候选动作集 A_adm 由 ZEST 门决定
3. 对每个 a∈A_adm 计算 gain(a) 2 步滚动
4. 选 a* = argmax gain/cost
5. 执行 5 步块，更新 s_t
6. 若 r_geo>τ，执行前馈修正
```

复杂度 O(|A|H)=12 次算术。

## 3. 可证伪假设

| 编号 | 假设 | 证伪条件 |
|---|---|---|
| H1 | 压缩为 top-1+β 不损失 >2pp 成功率 | ID 成功率下降 >2pp |
| H2 | 残差前馈修正降低 OOD-E 平均检测延迟 ≥1 块 | 延迟无改善 |
| H3 | 轻量化后 p99 延迟下降 ≥20% 且内存 <5MB/端口 | 延迟/内存不达标 |
| H4 | 滚动规划 H=2 与 H=4 成功率差异 <1pp | 差异 >2pp |

## 4. 何时放弃

- 压缩导致语义任务上目标混淆率 >15% → 回退到 top-3。
- 残差修正导致振荡或碰撞 → 关掉前馈，只保留门控。
- 轻量化后 ID 成功率下降 >2pp → 保留 VOI-MAP 分布。

## 5. 一句话押注

**把决策规划压缩到稀疏宏观动作 + 2 步滚动，把闭环从事后检测改为残差前馈修正，把状态压缩到 5 维标量，让系统在保持风险受控的前提下更快、更轻、更易推理。**

## 6. 本轮最大风险

**轻量化压缩会丢失多模态不确定性：当场景中存在两个置信度相近的目标时，top-1 压缩会导致目标锁定错误，且残差前馈会把错误目标越修正越偏。** 这是结构压缩的固有盲区，需靠 LOOK 动作和 ZEST 信任门兜底，但无法完全消除。

# 第 16 轮产物 · LDP-VLA 技术报告

> 检索/复核日期：**2026-11-04（UTC）**。对象：宇树 UniBot 世界挑战赛 G1+Dex1，32 项桌面任务，通才单模型赛道。本报告是研究线累计第 16 轮、第 1 次灵感循环产物。它在第 15 轮 ZEST-VLA 之上加入轻量化决策规划 + 闭环残差反馈，不替换 FACT-VLA、GEO-RESIDUAL、CHUNK-SERVO、WAVE-SERVO、VOI-MAP。

## 0. 结论与边界

### 0.1 一句话结论

LDP-VLA 把决策空间压缩到 6 个宏观动作 + 2 步滚动规划，把信念压缩到 top-1 目标 + 置信度 β + 胜任力 c 的 5 维标量状态，并用几何残差 `r_geo` 做前馈目标修正。规划更快、闭环更紧、内存 <5 MB/端口，同时继承 ZEST 的风险受控信任门。

### 0.2 证据等级

A：官方规则/API、WLA chunk_size=30、无 depth/force。
B：合成仿真 `exp/ldp_sim.py` 的延迟、内存、成功率对比。
C：真机 G13-G16 验证。

### 0.3 不做什么

- 不训练新网络；不做 test-time weight update；不保留全分布。
- 不引入第二个学习模型；不做自监督预训练。
- 不承诺解决 OOD-G。

## 1. 承接

ZEST 解决了「信不信」，LDP 解决「如何轻量地决定、如何闭环修正」。保留 ZEST 信任门、WAVE-SERVO 安全、VOI-MAP 地图 grounding。升级：决策从分布到稀疏滚动，闭环从检测到修正，状态从 O(N) 到 O(1)。

## 2. 符号与形式化

### 2.1 状态压缩

`s_t = (φ_t, i*_t, β_t, c_t, B_t)`

`β_t = max_i b_i`, `c_t ∈ [0,1]` 来自 ZEST 惊讶率。

宏观动作集 `A = {PLAN,SERVO,LOOK,FALLBACK,COMMIT,HOLD}`

成本 `c_a>0`，收益近似线性：

`gain(a|s) = w_p·Δprog(a) + w_b·β_t·c_t·I[a=SERVO] - w_u·Uncert(a)`

### 2.2 滚动规划

深度 H=2 的贪心滚动：

`V_0(s)=0`
`V_{k+1}(s)=max_{a∈A_adm} [gain(a|s)+γ V_k(T(s,a))]`

实际实现为 2 步展开，复杂度 O(|A|^2)。

### 2.3 闭环残差修正

块结束时观测几何残差 `r_geo ∈ R^3`。目标位姿更新：

`p_{t+1}=p_t + K_p·r_geo + K_i·e_t`
`e_{t+1}=e_t + r_geo`

限幅 `||K_p r_geo|| ≤ δ_max`，仅在 φ∈{APPROACH,PRECONTACT}。

### 2.4 轻量化接口

ZEST 门输出允许集 `A_adm(s)`。LDP 在其上做选择。所有执行仍经 WAVE-SERVO。

## 3. 算法

### 3.1 主循环

```python
def get_action(obs):
    update_map()
    s = compress_state(map,cusum)
    A_adm = zest_allowed_actions(s)
    a_star = rolling_plan(s, A_adm, H=2)
    if a_star == SERVO:
        chunk = wave_servo(plan)
        return chunk
    ...
def on_block_finished(obs0,obs1):
    r = compute_residuals(obs0,obs1)
    if mode==TRUST:
        p = p + Kp*r.geo
    update_zest(r)
```

### 3.2 复杂度

`|A|=6, H=2` → 每步 12 次乘加。内存 O(1)。CPU <0.2 ms/块。

### 3.3 正确性

**命题1 压缩不变性**：若 top-1 目标置信度 β>0.7，则 VOI-MAP 的期望收益与压缩收益差 ≤0.3·Δmax。证明：收益线性依赖 β，误差上界由次优目标概率控制。

**命题2 闭环收敛**：假设残差系统 `r_{t+1}=L r_t - K_p r_t`，`0<L<1`，则 `||r_t||→0` 当 `0<K_p<2/(1+L)`。比例修正保证渐近稳定。

**命题3 安全子集**：LDP 动作集 ⊆ ZEST 允许集 ⊆ WAVE-SERVO 安全集。证明构造。

## 4. 实验设计

合成仿真比较：Baseline VOI-MAP vs LDP-VLA。

指标：成功率、p99 延迟、内存、平均规划步数。

门 G13：压缩不损失 >2pp。
门 G14：闭环修正降低检测延迟 ≥1 块。
门 G15：p99 延迟下降 ≥20%，内存 <5MB。

预注册假设 H1-H4 如想法区。

## 5. 风险与合规

单模型合规：无新学习参数。轻量化结构为手工压缩。

最大风险：多目标场景下 top-1 锁定错误导致前馈修正发散。缓解：β<0.6 时强制 LOOK，重规划。

已知失效：OOD-G 仍不可检测；语义变形任务不适用前馈修正。

## 6. 一句话押注

**稀疏宏观规划 + 残差前馈修正 + 标量状态压缩，让决策更快、闭环更紧、在保持风险受控的前提下把系统压到轻量。**

## 7. 本轮最大风险

**轻量化压缩丢失多模态不确定性：两个目标置信度相近时 top-1 锁定错误，前馈修正会把错误目标越改越偏。** 这是结构压缩的固有盲区，需靠 LOOK 和 ZEST 门兜底，无法完全消除。
