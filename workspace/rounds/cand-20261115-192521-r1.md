# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态 × 主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环第 2 循环第 3 轮；本轮灵感：「碰撞避免」×「机器人操作系统」）

> R69 把不确定性拆成 **aleatoric / epistemic**，并让系统学会「问」。但它默认了一个从未被质疑的前提：**观测是「此刻」的、原子到达的、单一来源的**。真实的机器人不是一台同步的计算机，而是一张 ROS 2 图：节点分布、消息经 DDS 异步传递、时钟不同步、QoS 会静默丢弃、执行器会饿死、节点会「活着但僵死」。在这种系统里，一个数值完美平滑的位姿可能已经过期 300ms；一个加了 `transient_local` 的晚期订阅者，会把几秒前的旧位姿当成最新值收下。**R68 的标定层对此毫无察觉——过期数据往往比新鲜数据更平滑，残差 r_res 反而更低。** 这正是 R69 自陈风险的又一次变体：标定能吸收缓变故障，也同样能吸收**时间上的腐坏**。
>
> 本轮两个灵感正好从两端逼近同一个洞：
> - **碰撞避免**把问题从「值域」逼回「时域」——安全从来不是一个状态不等式，而是一个**时间不等式**：你必须在 TTC 耗尽前完成感知—决策—执行。陈旧观测直接等价于**未知的未来运动**，必须把障碍物的可达管膨胀。
> - **机器人操作系统**提供真实的故障面与真实的语义：QoS、时钟域、provenance、生命周期、执行器。它让「时间不确定性」不再是抽象的，而是**可命名、可审计、可认证**的。
>
> 核心命题：**安全证书必须是观测「年龄」的函数，而不只是观测「值」的函数。** 在 R69 的值域二分之外补上第三条正交轴——**时域不确定性 U_time**：陈旧观测不可通过「问」消解（问本身也要时间），只能通过**等待 / 重取 / 冗余 / 降速**消解，而等待消耗的正是碰撞避免里最稀缺的资源——时间。命名 **KAIROS-RAS**（Kairos：恰当的瞬间；*Kairos-aware, Attested, Interval-safe, Redundancy-orthogonal, Staleness-monotone* 的风险自适应闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的这个世界，还是这一刻的吗？**」——在碰撞避免里，**时间是唯一不能借、不能问、只能省的东西**。

## 0. 直觉与动机

**灵感 1（碰撞避免 → 安全是时间不等式，陈旧 = 未知运动）**
直觉：几何碰撞检查问的是「此刻两物是否相交」，但安全的真正问题是「在我能反应之前，它们会不会相交」。经典 CBF / 可达集早已隐含这一点，却默认状态是即时的。一旦观测有年龄 a，真实的相对状态就落在一个前向可达管里；碰撞检查必须对整条管做，而不是对一个点。于是「陈旧」不再是一个软件工程指标，而是一个**几何量**：年龄乘上最大相对速度，直接变成需要额外保持的距离。安全裕度因此是年龄的单调函数——越旧越保守，且这份保守**物理可解释**。

**灵感 2（ROS → 时间腐坏有多种形态，且互相伪装）**
直觉：ROS 2 里「旧」至少有五种来源：网络延迟、重传积压、QoS 静默丢弃后的最后一次值、`transient_local` 的锁存旧值、以及「节点心跳正常但内部滤波器冻结」。它们到达下游时都自称一条合法消息，唯一能区分的是**时间戳、provenance 与功能性证据**。因此需要一个「时间取证」层：不仅问值是多少，还要问它是谁、何时、经由哪条链生成，以及它是否真的依赖了近期输入。心跳证明「活着」，但活着不等于「在感知」。

**灵感 3（时间是不可约资源 → 等待有硬截止）**
直觉：R69 的 MINT 把交互成本当成一个温和的标量惩罚。但在碰撞避免里，等待 w 毫秒不是「花点钱」，而是**直接从 TTC 里扣掉 w 毫秒**。所以「等一个新鲜观测」与「用旧观测立刻刹车」之间存在一个由物理决定的临界点：当 TTC 逼近反应时延时，等待的期望收益永远追不上时间的代价，最优策略必然退化为**立即以膨胀裕度保守动作**。这把 R69 的 VoI 变成**带硬截止的 VoI**（deadline-VoI），也让「保守」第一次有了时间上的精确含义——**临撞时不等待不是启发式，而是引理的必然**。

**灵感 4（冗余 ≠ 独立 → 正交性要测量，不能假设）**
直觉：R69 的证据纪律说「k 个正交证据源一致才定案」。但在 ROS 图里，两个 LiDAR 接同一台主机、共享同一个时钟域、经由同一段 DDS 发现与同一个执行器，它们的失效是**共因**的。把它们当两票，是把相关性当成独立性——最危险的一种自我欺骗。所以 R70 必须把「正交」从假设降格为**要在线估计的量**（有效票数 k_eff），并承认 provenance 重叠会系统性压低 k_eff。真正的冗余必须跨主机、跨时钟域、跨传感模态，且被拓扑审计证明。

**灵感 5（安全会成为攻击面 → DoS-via-safety）**
直觉：一旦「不新鲜就停」成为铁律，攻击者不必让机器人撞墙，只需**让消息永远差一点点新鲜**——注入微小延迟、制造 QoS 不匹配、拖慢执行器——就能让机器人永久安全停机。也就是说 R70 把攻击目标从「撞」改成了「瘫」。因此必须同时有可用性预算与降级谱：安全停机是有成本的，认证必须同时记录「为安全牺牲了多少可用性」，并区分「真的坏」与「被拖慢」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（KAIROS-RAS 总览）** KAIROS-RAS = (TEM, SAFE-TUBE, T-VoI, PROV, FFC, QOS-G, SMI, TDUAL, RAS-WM††)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **时间有效性优先**：任何进入控制的量必须携带可比较的年龄上界 ā 与 provenance，缺一即视为不可用；
(iii) **陈旧单调制动**：可行速度上界是「最早失效话题的 ā」的非增函数；ā 越界时只允许安全停机集；
(iv) **理想 DDS 退化**：当延迟→0、无丢包/乱序/重放、单时钟域、QoS 合规、无分区、节点功能新鲜时，KAIROS 与 R69 逐指令相同。

**定义 311（带时间戳的消息与时钟域）** 节点 i 的输出消息 m_i = (x_i, τ_i^src, t_i^recv, d_i, q_i, π_i)：x_i 为值；τ_i^src 为源时钟时间戳；t_i^recv 为本地接收时间；d_i 为时钟域；q_i = (reliability, durability, deadline, lifespan, liveliness) 为 QoS 元组；π_i 为 provenance（根传感源、变换节点链、主机 id、执行器 id）。时钟域 d 相对本地的偏移误差上界 ε_d、漂移率上界 κ_d。

**定义 312（年龄区间）** 本地时刻 t 对 m_i 的年龄不是点而是区间：
a_i(t) ∈ [ (t−τ_i^src) − ε_{d_i} − κ_{d_i}(t−τ_i^src), (t−τ_i^src) + ε_{d_i} + κ_{d_i}(t−τ_i^src) ]（同域）；
跨不可比域时只保留保守上界 ā_i(t) = t − t_i^recv + ε_{d_i}。安全只用上界 ā_i(t)。若 τ 缺失或倒序（乱序/重放），置 ā_i = +∞（不可用）。**禁止把未同步时钟的先后当作因果顺序——这是逻辑错误，不是数值误差。**

**定义 313（陈旧膨胀可达管 SAFE-TUBE）** 对年龄上界 ā、相对速度上界 v̄、相对加速度上界 ācc，定义状态 x 的可达膨胀
Tube_ā(x) = { x' : ‖p' − p‖ ≤ v̄·ā + ½ ācc·ā² }。
对距离型安全函数 h，定义 h_ā(x) = min_{x'∈Tube_ā(x)} h(x') ≈ h(x) − v̄ā − ½ācc ā²。核心：**年龄直接变成几何裕度**。

**定义 314（时延感知碰撞安全条件）** 设反应时延上界 τ_r（感知→决策→执行）、观测年龄上界 ā，总时间预算 Δ = ā + τ_r。安全条件：
h_Δ(x) := h(x) − v̄Δ − ½ācc Δ² ≥ 0，且沿闭环满足鲁棒 CBF：ḣ ≥ −α h_Δ。
等价于把安全集收缩为 K_Δ = {x : h_Δ(x) ≥ 0}。**Δ 增大 ⇒ K_Δ 单调收缩**（引理 19）。

**定义 315（时域不确定性 U_time）** U_time = v̄·ā + ½ācc·ā²（可达管半径）。它与 U_ale、U_epi 正交：不可通过「问」消解（问也要时间），只能通过等待新鲜消息、切换冗余源（降 ā）、或降低速度（降低有效 v̄）来消解。三轴分通道：U_ale→λ floor；U_epi→MINT 交互；U_time→SAFE-TUBE 裕度 + SMI 制动。

**定义 316（带截止的时域 VoI，T-VoI）** 候选时间动作 g_t ∈ {wait(τ), requery(j), reroute(跨域/跨主机)}。设当前 TTC 上界 T_tcc。收益是年龄上界的下降 Δā = ā − ā'，代价是消耗时间 w(g_t)。定义
TVoI(g_t) = E[U_time(ā) − U_time(ā')] − v̄·w(g_t)，可行域 T_tcc ≥ w(g_t) + τ_r + δ_margin。
选择 g_t* = argmax TVoI s.t. 可行性。若可行域为空或 max TVoI ≤ 0：**不等待，立即以 ā 膨胀裕度保守执行（或进入 SMI 停机集）**。系：TTC 越紧等待越不值；**临撞时系统永远不会「再等等看」**。

**定义 317（provenance 图与有效独立性）** provenance 图 G_π = (V,E)：节点为传感源/变换/主机/时钟域/执行器，边为数据流与共享资源。对证据源集合 S，失效指示 F_i，共因相关上界 ρ_ij = corr(F_i,F_j)（由共享祖先、同主机、同域、同执行器在线估计）。有效票数
k_eff(S) = (Σ_i 1)² / Σ_{i,j} ρ_ij（ρ_ii = 1）。
只有 k_eff ≥ 2 才允许把多源当「冗余」；否则按单源处理并走 R69 证据纪律最弱分支。**同主机双 LiDAR 的 k_eff ≈ 1。**

**定义 318（功能性新鲜证明 FFC）** 节点 i 在时刻 t 功能新鲜 ⇔ 其输出 x_i(t) 是「t − a_max 之后到达的输入」的可测函数。操作化：节点随每个输出发布**输入水位** w_i(t)（已消费输入序列号的单调摘要 / 哈希链）。下游验证 w_i(t) 严格递增且覆盖最近 a_max 窗口内到达的输入。**心跳只能证明「活着」，水位才能证明「没僵死」**；冻结滤波器 / 锁存旧值会通过心跳但通不过水位。

**定义 319（QoS-安全兼容契约 QOS-G）** 安全关键话题强制契约：RELIABLE（不静默丢）、VOLATILE（禁 TRANSIENT_LOCAL 锁存）、DEADLINE ≤ d_max、LIFESPAN ≤ l_max、LIVELINESS lease ≤ a_max。违反任一 ⇒ 该话题年龄置 +∞。特别地，**transient_local + 晚期加入 = 旧位姿冒充新值**，是明确禁止的 hazard 配置。

**定义 320（偏斜安全区间融合）** 多源融合不做点估计平均，而在年龄区间上做**悲观时间对齐**：各源值外推到统一时刻 t，外推量用各自 ā 上界；融合输出的年龄上界取 max_i ā_i + 外推误差。**禁止用未同步时钟做先后比较。**

**定义 321（陈旧-运动联锁 SMI）** 定义认证新鲜度 F(t) = ∧_{关键话题} (ā_i ≤ a_max) ∧ FFC_i ∧ QOS-G_i ∧ provenance 可信。若 ¬F(t)：仅允许安全停机集 𝒜_stop（在剩余制动距离内减速到零，含膨胀裕度）；速度上界 v_max(t) 是对「最早失效的 ā」的非增函数。**认证的是「运动基于可认证新鲜的数据」，而不是「数据看起来合理」。**

**定义 322（时域对偶通道 TDUAL）** R69 的 FMA 用策略似然对「值偏移」敏感；R70 增加对「时间腐坏」敏感的第二意见：对同一物理量，比较**独立时钟域 / 独立主机**的估计在共同时刻的差 d_ij(t) 与其年龄差。若 d_ij 随年龄差增大而系统性发散，说明某源在「用旧值外推」，即便其残差与似然都正常。TDUAL 与 FMA 构成本轮对偶：**FMA 测行为自洽，TDUAL 测时间自洽**。

**定义 323（时域审计 VQAuditor-T 与威胁 ℰ_TIME）** 审计新增：等待是否超预算、是否在 TTC 过紧时仍等待、冗余是否被高估 k_eff、是否有源长期「活着但僵死」、QoS 是否被静默降级、安全停机是否被滥用。威胁
ℰ_TIME = {dropout, delay/jitter, reorder, clock skew/offset 攻击, replay 重放, stale-latch, transient_local 晚期加入, QoS 不匹配静默丢, executor 饥饿 / 优先级反转, 分区, 节点冻结(alive-but-dead), provenance 伪造, DoS-via-safety}。
并入 AIC：ℰ_KAIROS = ℰ_FLUID × ℰ_TIME。

**定义 324（证书 J_KAIROS）** J_KAIROS = (J_FLUID, age_p95/age_max, skew_bound_used, qos_compliance_rate, provenance_coverage, k_eff_min, tvoi_ratio, stale_stop_events, availability_cost, kairos_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有关键话题 QOS-G 合规 ∧ FFC 全通过 ∧ k_eff 记录完整 ∧ SMI 事件有账。

**定义 325（理想 DDS 边界与严格包含）** 理想边界：ā→0、无丢包/乱序/重放、单时钟域（ε=κ=0）、QoS 合规、无分区、节点功能新鲜、k_eff 充分。此时 SAFE-TUBE 退化（Tube_0 = {x}）、T-VoI 无可行等待、SMI 恒真、TDUAL 无发散，KAIROS 逐指令等于 R69。**R69 = KAIROS 在「零时间不确定性」边界上的退化。**

**定义 326（时间预算账本 TBL）** 每个控制周期维护时间预算账本：剩余 TTC、观测年龄上界、反应时延、等待已用、制动所需。所有决策必须使账本余额 ≥ 0；等待/交互从余额扣除，传感更新只补充「年龄」而**不补充「TTC」**。**TBL 是安全与交互共用的一份不可透支预算。**

```python
# IP-264 TEM：带时间戳消息与年龄上界
class TimedObservation:
    def age_upper(self, t_local, clock):
        if self.tau_src is None or self.domain != clock.domain:
            return t_local - self.t_recv + clock.eps(self.domain)      # 跨域保守
        dt = t_local - self.tau_src
        return dt + clock.eps(self.domain) + clock.drift(self.domain) * dt

# IP-265 SAFE-TUBE：年龄膨胀可达管 + 时延感知 CBF
def safety_margin(h_val, age_bar, v_bar, a_bar, tau_r):
    D = age_bar + tau_r
    return h_val - v_bar * D - 0.5 * a_bar * D * D                    # >=0 才安全

def delay_aware_safe(x_est, obs, cfg):
    age = max(o.age_upper(cfg.t, cfg.clock) for o in obs.critical)
    return safety_margin(distance_margin(x_est), age, cfg.v_bar, cfg.a_bar, cfg.tau_r) >= 0

# IP-266 T-VoI：带硬截止的等待 / 重取 / 重路由决策
def temporal_voi(cands, age_bar, ttc, cfg):
    best = None
    for g in cands:                                                   # wait / requery / reroute
        w = g.expected_latency()
        if ttc < w + cfg.tau_r + cfg.delta_margin:                    # 硬截止：不许等
            continue
        gain = tube_radius(age_bar, cfg) - tube_radius(age_bar_after(g), cfg)
        cost = cfg.v_bar * w
        s = gain - cost
        if best is None or s > best.s: best = (g, s)
    return best if best and best.s > 0 else None                      # 无利可图 → 立即保守

# IP-267 PROV：有效独立性（共因校正）
def effective_votes(sources, prov_graph):
    R = [[prov_graph.corr_upper(i, j) for j in sources] for i in sources]
    return (len(sources) ** 2) / sum(sum(row) for row in R)           # k_eff；同主机≈1

# IP-268 FFC：功能性新鲜证明（输入水位）
def functionally_fresh(node_out, recent_inputs, a_max):
    return (node_out.watermark.covers(window=recent_inputs.after(a_max))
            and node_out.watermark.monotone())

# IP-269 QOS-G：QoS 契约校验（transient_local 是 hazard）
def qos_compliant(topic):
    q = topic.qos
    return (q.reliability == 'RELIABLE' and q.durability == 'VOLATILE'
            and q.deadline <= D_MAX and q.lifespan <= L_MAX
            and q.liveliness.lease <= A_MAX)

# IP-270 SMI：陈旧-运动联锁（速度对年龄非增）
def stale_motion_interlock(obs, cfg):
    fresh = all(o.age_upper(cfg.t, cfg.clock) <= cfg.a_max
                and functionally_fresh(o.node, cfg.recent_in, cfg.a_max)
                and qos_compliant(o.topic) and prov_trusted(o)
                for o in obs.critical)
    if fresh:
        return {'stop_only': False, 'v_max': cfg.v_nom}
    a_old = max(o.age_upper(cfg.t, cfg.clock) for o in obs.critical)
    return {'stop_only': True, 'v_max': cfg.v_nom * decay(a_old, cfg)}  # 非增降级

# IP-271 TDUAL：时域对偶通道（独立时钟 / 主机发散）
def temporal_duel(x_a, x_b, cfg):
    common = min(cfg.t, x_a.tau, x_b.tau)
    d = dist(extrapolate(x_a, common), extrapolate(x_b, common))
    return d - kappa * abs(x_a.age_upper(cfg.t, cfg.clock)
                           - x_b.age_upper(cfg.t, cfg.clock))

# IP-274 KAIROS 主闭环（在 R69 的不确定性处置前插入时间取证层）
def KAIROS_RAS_round(M, obs):
    # 0) 时间取证：年龄上界 + 功能新鲜 + QoS + provenance
    ages  = {o.id: o.age_upper(M.t, M.clock) for o in obs.all}
    fresh = M.smi.temporal_interlock(obs, M.cfg)
    if fresh['stop_only']:
        return M.stop(M.brake_profile(ages), cert=M.cert(ages, safe_stop=True))
    # 1) 继承 R69：不确定二分 + 多模态策略
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 2) 时延感知裕度（年龄直接进几何）
    age_bar = max(ages[o.id] for o in obs.critical)
    h_delay = M.safe_tube.margin(M.distance_margin(), age_bar, M.cfg)
    # 3) 带硬截止的时域 VoI：TTC 不够绝不等待
    g_t = (M.tvoi.choose(obs, age_bar, M.ttc(), M.cfg)
           if (U_epi > TAU_EPI and h_delay > 0) else None)
    if g_t is not None:
        obs     = M.tvoi.execute(g_t)                 # wait / requery / reroute，须在截止内
        age_bar = max(x.age_upper(M.t, M.clock) for x in obs.critical)
    # 4) 时间对偶：独立源发散 + 共因校正
    d_ij    = M.tdual.score(obs)
    k_eff   = M.prov.effective_votes([x.node for x in obs.critical], M.prov_graph)
    prov_ok = (d_ij <= TAU_DUAL) and (k_eff >= 2)
    # 5) 两级退避 + 时间膨胀（安全侧永不弱于 R69）
    U_epi_after = 0.0 if (g_t is not None and prov_ok) else U_epi
    U_floor = U_ale + U_epi_after
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(M.x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if h_delay <= 0:                                  # 时间不安全 ⇒ 最保守停机谱
        lam, k = max(lam, 0.9), M.smi.stop_prefix(A)
    # 6) 执行 + 时间审计 + 证书
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(g_t, ages, k_eff, d_ij, fresh['availability_cost'])
    return k, lam, mode, (U_ale, U_epi_after, age_bar)
```

## 3. 推导

**引理 19（年龄→裕度的单调膨胀）** 对距离型安全函数 h 与有界相对运动 (v̄, ācc)，Tube_ā 半径 r(ā) = v̄ā + ½ācc ā² 关于 ā 严格单调递增；故时延感知安全集 K_Δ = {x : h(x) ≥ r(Δ)} 关于 Δ 单调收缩，且 h_Δ(x) = h(x) − r(Δ)。系：**任何使年龄上界增大的操作（丢包、锁存、跨域、执行器饥饿）都只会收紧安全集**——「陈旧」自动落入 R68「不确定只收紧」的旧铁律，无需额外假设。

**引理 20（带截止等待的不可能性）** 设剩余 TTC 上界为 T、反应时延 τ_r、安全余量 δ。若 T < τ_r + δ + w(g_t)，则任何等待/重取动作都不可行，最优动作必在「立即执行」集合内。进一步令风险泛函 R(Δ) = r(Δ)/h(x)，在临撞区间 h→r 时 ∂R/∂Δ → ∞，等待的期望收益 Δr 有界而时间代价随 Δ 发散，故 TVoI < 0。系：**临撞时不等待不是启发式，而是引理的必然**；R69 的「先看清再决定」在 TTC 耗尽时被时间本身否决。

**引理 21（共因对冗余的折损）** 若证据源 i,j 的失效相关系数上界为 ρ，则多源多数表决相对单源的错误率改进因子 ≤ 1 − ρ；更精确地，k_eff = k² / (k + k(k−1)ρ̄)，当 ρ̄ = 1 时 k_eff = 1。系：**「两个传感器」不构成「两个证据」，除非 provenance 证明它们跨主机、跨时钟域、跨模态**；ROS 拓扑直接决定 k_eff，因此冗余必须被拓扑审计，而不能被节点数量欺骗。

**定理 18（KAIROS 严格包含 R69）** 在理想 DDS 边界（定义 325）下，ā→0 ⇒ r(ā)→0、T-VoI 可行集为空、SMI 恒真、k_eff 由真冗余给出，KAIROS 的每一条控制指令与 R69 相同；在任意非理想边界下安全集 K_Δ ⊆ K_0，故安全侧风险 ≤ R69。**R69 = KAIROS 的零时延退化；KAIROS 只在时间维更保守，在值域上不改变 R69 的任何结论。**

**定理 19（陈旧-运动无违规与可用性有界）** 若所有安全关键话题满足 QOS-G 且 FFC 正确实现，则 SMI 保证「不存在基于未认证新鲜数据的运动」；速度上界对最早失效年龄非增 ⇒ 控制连续、无突变（继承 R69 定理 17）。同时 SMI 每次触发都记账为 availability_cost，若攻击者持续制造「差一点新鲜」，系统进入**可观测的降级态**而非无声的乐观态。系：**安全可证，但可用性会被攻击；证书必须同时报告「为安全付了多少时间」。**

## 6. 本轮最大风险

**一句话**：KAIROS 的整套证书建立在**假设的界**上——最大时延、最大时钟偏斜、最大相对加速度——而 ROS 2 是软实时图，这些界在尾部只是统计期望、不是保证；**一次尾延迟事件或无界偏斜，就会让「已认证新鲜」这个标志说谎，而证书仍然亮绿灯**——因为被信任的正是证书本身，失败因此是静默的。换句话说，R70 把「值域的谎」搬到了「时域的谎」，但并没有消灭说谎，只是把信任边界推到了没人认证的中间件最坏时序上。

**次级风险与缓解**：
1. **DoS-via-safety / 可用性崩塌**（攻击者只制造「差一点新鲜」）→ availability_cost 记账 + 降级谱 + 区分「真坏」与「被拖慢」（定理 19）；
2. **k_eff 估计错误**（相关失效伪装成独立）→ provenance 拓扑审计 + 保守上界 ρ + 同主机强制降为单票（引理 21）；
3. **FFC 实现缺口**（水位可被伪造）→ 哈希链 / 输入序列号签名 + 参与式审计；
4. **TDUAL 大年龄外推误差**→ 仅在共同时刻短外推内有效，超出即判不可用；
5. **时间预算账本记账 bug**（漏扣等待成本）→ 账本与证书同源、可回放复算（E311、E315）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** KAIROS-RAS 九元组；零学习写操作继承；时间有效性优先（不可比即不可用）；陈旧单调制动；理想 DDS 退化。

**定义 311–312（消息与年龄）** `m=(x,τ,t,d,q,π)`；同域年龄区间含偏斜 ε 与漂移 κ；跨不可比域只保留 `t−t^recv+ε`；缺失/倒序置 `ā=+∞`。

**定义 313–314（SAFE-TUBE 与时延 CBF）** `Tube_ā` 半径 `r(ā)`；`h_Δ=h−r(Δ)`；安全集 `K_Δ={h_Δ≥0}` 随 Δ 单调收缩（引理 19）。

**定义 315（U_time）** `U_time=r(ā)`，不可通过「问」消解，只能等待/重取/降速；与 U_ale、U_epi 分通道。

**定义 316（T-VoI）** `g_t* = argmax [E[ΔU_time] − v̄·w]`，s.t. `T_tcc ≥ w+τ_r+δ`；不可行或 ≤0 则立即保守执行（引理 20）。

**定义 317（PROV）** provenance 图 + 共因相关上界 ρ 的 `k_eff`；`k_eff<2` 即按单源处理。

**定义 318（FFC）** 功能新鲜 = 输出依赖最近 `a_max` 内输入；用输入水位/哈希链验证；心跳≠健康。

**定义 319（QOS-G）** 安全关键话题必须 RELIABLE + VOLATILE + 有界 DEADLINE/LIFESPAN/LIVELINESS；违反即年龄 +∞；`transient_local` 晚期加入是明令 hazard。

**定义 320–321（偏斜安全融合与 SMI）** 悲观时间对齐外推；`F(t)` 不成立时只允许 `𝒜_stop`，`v_max` 对最早失效年龄非增。

**定义 322（TDUAL）** 独立时钟/主机在共同时刻的发散 `d_ij` 扣年龄差；系统性发散 = 旧值外推，即使残差/似然正常。

**定义 323–324（审计/威胁/证书）** VQAuditor-T 审等待与冗余；`ℰ_KAIROS=ℰ_FLUID×ℰ_TIME`；`J_KAIROS` 并入年龄、偏斜、QoS、prov、k_eff、TVoI 比、停机与可用性成本。

**定义 325–326（理想边界与时间账本）** 零时延/无丢包/单时钟/QoS 合规 ⇒ 逐指令退化为 R69；TBL 是不可透支的统一预算，等待扣时应、传感只补年龄不补 TTC。

```python
# IP-264 TEM：年龄上界
class TimedObservation:
    def age_upper(self, t_local, clock):
        if self.tau_src is None or self.domain != clock.domain:
            return t_local - self.t_recv + clock.eps(self.domain)      # 跨域保守
        dt = t_local - self.tau_src
        return dt + clock.eps(self.domain) + clock.drift(self.domain) * dt

# IP-265 SAFE-TUBE：年龄膨胀 + 时延感知 CBF
def safety_margin(h_val, age_bar, v_bar, a_bar, tau_r):
    D = age_bar + tau_r
    return h_val - v_bar * D - 0.5 * a_bar * D * D

def delay_aware_safe(x_est, obs, cfg):
    age = max(o.age_upper(cfg.t, cfg.clock) for o in obs.critical)
    return safety_margin(distance_margin(x_est), age, cfg.v_bar, cfg.a_bar, cfg.tau_r) >= 0

# IP-266 T-VoI：带硬截止的时间动作
def temporal_voi(cands, age_bar, ttc, cfg):
    best = None
    for g in cands:                                   # wait / requery / reroute
        w = g.expected_latency()
        if ttc < w + cfg.tau_r + cfg.delta_margin:    # 硬截止：不许等
            continue
        s = (tube_radius(age_bar, cfg) - tube_radius(age_bar_after(g), cfg)) - cfg.v_bar * w
        if best is None or s > best.s: best = (g, s)
    return best if best and best.s > 0 else None      # 无利可图 → 立即保守

# IP-267 PROV：共因校正的有效票数
def effective_votes(sources, prov_graph):
    R = [[prov_graph.corr_upper(i, j) for j in sources] for i in sources]
    return (len(sources) ** 2) / sum(sum(row) for row in R)   # 同主机 ≈ 1

# IP-268 FFC：输入水位证明
def functionally_fresh(node_out, recent_inputs, a_max):
    return (node_out.watermark.covers(recent_inputs.after(a_max))
            and node_out.watermark.monotone())

# IP-269 QOS-G：QoS 契约
def qos_compliant(topic):
    q = topic.qos
    return (q.reliability == 'RELIABLE' and q.durability == 'VOLATILE'
            and q.deadline <= D_MAX and q.lifespan <= L_MAX
            and q.liveliness.lease <= A_MAX)

# IP-270 SMI：陈旧-运动联锁
def stale_motion_interlock(obs, cfg):
    if all(o.age_upper(cfg.t, cfg.clock) <= cfg.a_max
           and functionally_fresh(o.node, cfg.recent_in, cfg.a_max)
           and qos_compliant(o.topic) and prov_trusted(o) for o in obs.critical):
        return {'stop_only': False, 'v_max': cfg.v_nom}
    a_old = max(o.age_upper(cfg.t, cfg.clock) for o in obs.critical)
    return {'stop_only': True, 'v_max': cfg.v_nom * decay(a_old, cfg)}

# IP-271 TDUAL：时间自洽第二意见
def temporal_duel(x_a, x_b, cfg):
    common = min(cfg.t, x_a.tau, x_b.tau)
    return (dist(extrapolate(x_a, common), extrapolate(x_b, common))
            - kappa * abs(x_a.age_upper(cfg.t, cfg.clock)
                          - x_b.age_upper(cfg.t, cfg.clock)))

# IP-274 KAIROS 主闭环
def KAIROS_RAS_round(M, obs):
    ages  = {o.id: o.age_upper(M.t, M.clock) for o in obs.all}
    fresh = M.smi.temporal_interlock(obs, M.cfg)
    if fresh['stop_only']:
        return M.stop(M.brake_profile(ages), cert=M.cert(ages, safe_stop=True))
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    age_bar = max(ages[o.id] for o in obs.critical)
    h_delay = M.safe_tube.margin(M.distance_margin(), age_bar, M.cfg)
    g_t = (M.tvoi.choose(obs, age_bar, M.ttc(), M.cfg)
           if (U_epi > TAU_EPI and h_delay > 0) else None)
    if g_t is not None:
        obs     = M.tvoi.execute(g_t)
        age_bar = max(x.age_upper(M.t, M.clock) for x in obs.critical)
    d_ij    = M.tdual.score(obs)
    k_eff   = M.prov.effective_votes([x.node for x in obs.critical], M.prov_graph)
    prov_ok = (d_ij <= TAU_DUAL) and (k_eff >= 2)
    U_epi_after = 0.0 if (g_t is not None and prov_ok) else U_epi
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + U_epi_after))
    A = M.ach.propose(M.x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if h_delay <= 0:
        lam, k = max(lam, 0.9), M.smi.stop_prefix(A)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_t.submit_async(g_t, ages, k_eff, d_ij, fresh['availability_cost'])
    return k, lam, mode, (U_ale, U_epi_after, age_bar)
```

## 4. 推导

**引理 19（年龄→裕度单调膨胀）** `r(ā)=v̄ā+½ācc ā²` 严格单增 ⇒ `K_Δ` 关于 `Δ=ā+τ_r` 单调收缩，`h_Δ=h−r(Δ)`。系：丢包/锁存/跨域/饿死等一切增大年龄的操作都只会收紧安全集，自动并入 R68「不确定只收紧」的旧铁律。

**引理 20（带截止等待不可能）** 若 `T_tcc < τ_r+δ+w(g_t)` 则等待不可行；临撞区间 `h→r` 时 `∂R/∂Δ→∞`，收益有界而时间代价发散 ⇒ `TVoI<0`。系：临撞不等待是必然，不是启发式。

**引理 21（共因折损冗余）** 失效相关上界 ρ 下，多源多数表决相对单源的改进因子 ≤ `1−ρ`；`k_eff=k²/(k+k(k−1)ρ̄)`，`ρ̄=1 ⇒ k_eff=1`。系：两传感器 ≠ 两证据；ROS 拓扑即冗余上限。

**定理 18（KAIROS 严格包含 R69）** 理想 DDS 边界下 `ā→0` ⇒ `r→0`、T-VoI 可行集空、SMI 恒真、k_eff 由真冗余给出，逐指令等于 R69；非理想时 `K_Δ⊆K_0`，安全侧风险 ≤ R69。R69 = 零时延退化。

**定理 19（陈旧-运动无违规与可用性有界）** QOS-G + FFC 成立 ⇒ SMI 保证不存在基于未认证新鲜数据的运动；`v_max` 对最早失效年龄非增 ⇒ 连续无突变（继承 R69 定理 17）；SMI 触发记账 availability_cost ⇒ 攻击导致的是**可观测降级**而非无声乐观。系：安全可证，但可用性会被攻击，证书须同时报告为安全付出的时间代价。

## 7. 本轮最大风险

**一句话**：KAIROS 的整套证书建立在**假设的界**上——最大时延、最大时钟偏斜、最大相对加速度——而 ROS 2 是软实时图，这些界在尾部只是统计期望、不是保证；**一次尾延迟事件或无界偏斜，就会让「已认证新鲜」这个标志说谎，而证书仍然亮绿灯**——因为被信任的正是证书本身，失败因此是静默的。R70 把「值域的谎」搬到了「时域的谎」，但并没有消灭说谎，只是把信任边界推到了没人认证的中间件最坏时序上。

**次级风险与缓解**：DoS-via-safety（availability_cost 记账 + 降级谱 + 区分真坏/被拖慢）；k_eff 估计错误（provenance 拓扑审计 + ρ 保守上界 + 同主机降为单票）；FFC 水位伪造（哈希链/签名 + 参与式审计）；TDUAL 大年龄外推误差（仅短外推有效，超出判不可用）；时间账本记账 bug（账本与证书同源、可回放复算，E311/E315）。
