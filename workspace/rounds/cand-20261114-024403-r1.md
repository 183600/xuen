# 第 71 轮（承接第 70 轮「BELIEF-RAS」IP-264~274；灵感循环新循环第 1 轮；本轮灵感：「数据集构建」×「姿态估计」）

> R70 把「我该向谁求证」升级为「我的世界信念 b_t 是什么」，用贝叶斯状态后验承载 epistemic。但 R70 有两块从未被审视的地基：
> 1. **数据地基**：b_t 的观测模型、FMA 的流似然、CIA 的交互似然、MCG† 的校准集，全部来自一个固定数据集 D。R70 的 epistemic 只是「D 支持范围内的后验熵」；一旦观测落在 D 覆盖之外，后验会自信地错。R70 自陈的最大风险正是观测模型失配，却没有给出度量或修复数据失配的手段。更糟的是：R70 每轮产出大量高价值困难样本（歧义、交互、缓变故障），却全部丢弃——它是数据的消费者，不是生产者。
> 2. **表示地基**：R70 把姿态塞进连续状态 s，却忘了 SE(3) 有对称群。对一个对称物体，「这是正面还是背面」不是噪声（aleatoric），也不是多看一眼就能消解的歧义（epistemic），而是一种**规范（gauge）不确定性**：物理状态本身是商空间 [s]∈SE(3)/G，估计器却强行输出一个代表元。把它当 aleatoric → 对对称姿态求平均，几何被毁；把它当 epistemic → 无论看多少眼、问多少句都消不掉（同视角信息增益为 0），系统永远在问一个物理上不可答的问题。
>
> 本轮两个灵感正好对应这两块地基：
> - **数据集构建**不是预处理，而是**构造观测模型本身**：数据集是「状态空间区域 → 可信证据」的映射。R71 给它一个可度量的对象：覆盖（coverage）× 来源（provenance）× 轨道感知的有效样本（orbit-aware effective size）。
> - **姿态估计**不是回归一个 6D 向量，而是**规范固定（gauge fixing）**：输出商空间上的后验 + 对称群上的 gauge 后验，并按任务是否依赖 gauge 决定要不要消歧。
>
> 核心命题：**把「数据支撑」与「对称规范」提升为与 aleatoric/epistemic 并列的两类独立不确定性；数据集构建从离线预处理升级为闭环、带来源、防投毒的数据引擎；姿态估计从点回归升级为商空间后验 + gauge 后验；BELIEF-RAS 的所有似然项都乘以可审计的支撑权重。** 命名 **GAUGE-RAS**（Gauge-Aware Uncertainty & Grounded-data Engine for Robot Active Sensing）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我相信世界处于哪个状态」，R71 问「**我凭什么相信我的模型、我的数据、以及我对物体朝向的那一个代表元**」。

## 0. 直觉与动机

**灵感 1（数据集构建 → 数据集是观测模型的承重墙，不是原料）**
直觉：数据不是越多越好，而是「在哪些状态上、有多少条独立可追溯的证据」。真正决定 b_t 可信度的，不是样本总量，而是覆盖图上每个单元（物体类别 × 商姿态 × 视角 × 遮挡 × 光照）的独立证据密度。一条由同一段视频切出的 1000 帧，覆盖上只算 1 个独立单元；把对称物体的 8 个增广副本堆进去，数据量涨 8 倍而商空间覆盖一比特没多。所以「数据集构建」应被形式化为覆盖测度的设计与维护，而不是收集与清洗的堆叠。

**灵感 2（姿态估计 → 估计的是等价类，不是代表元）**
直觉：对称物体的标注真值本质上是任意的代表元；两个标注者给出差 90° 的标签，按物理意义都对。用普通 L2 / ADD 损失训练，等于把对称性当噪声，学出一个「平均朝向」这种物理上不存在的姿态。正确做法是：损失在群轨道上取下确界（商度量），网络同时输出商姿态分布与 gauge 分类分布。推理时若任务只依赖商（圆柱插入），gauge 无关紧要；若任务依赖代表元（贴标签面朝上、键槽对齐），必须先做 gauge fixing，否则越自信越危险。

**灵感 3（四分法 → 把数据支撑与规范从旧的不确定性里拆出来）**
直觉：R69/R70 只有两分法。R71 必须四分：
- **U_ale**（观测噪声，不可约）→ 沿用 λ_floor；
- **U_epi**（可约歧义）→ MINT 主动看/问/触；
- **U_gauge**（对称规范，问不出来）→ GGR 门 + 商化策略/规范固定动作；
- **U_sup**（数据支撑之外，只能补数据或降级）→ 数据请求 + R68 兜底。
最关键的理论姿态：R70 恰是「G 平凡（无对称）+ 覆盖满 + 数据不更新」的边界，而不是被替代。四类不确定性不做标量加和，各自进入不同通道。

**灵感 4（对称让投毒隐形 → 数据层的新威胁模型）**
直觉：普通标签翻转是 outlier，几何一致性/密度清洗容易检出；但对对称物体，把 gauge 标签 h·g 改成 h'·g，得到的仍是**同一轨道上的合法姿态**——gauge 不变残差为 0，任何基于「姿态是否自洽」的清洗都查不出来。这不是随机噪声，而是**沿对称群整圈复制的系统性偏见**：它会让姿态估计在一整类物体上系统性偏 90°，而所有自洽性检查都通过。必须引入**规范锚点**（非对称特征、标记、跨视角运动视差）与跨 episode 的 gauge 一致性审计；否则数据引擎会把偏见洗成「已验证」。

**灵感 5（数据飞轮的纪律 → 学习只能发生在离线、可回滚、可审计的窗口）**
直觉：R70 已区分实时环与离线审计。若让交互回答直接进训练集，就会形成确认偏误：系统问什么、得到什么、就学什么，最后把自己的错误变成数据。数据构建必须离线、批处理、带版本、可回滚，并保留一个永不训练的审计集；实时环只能把候选样本**排队**，不能写。部署时的信任域必须与数据版本 D_k 的覆盖证书绑定：覆盖之外一律降级。

## 1. 形式化定义（增量：定义 331–350）

**定义 331（GAUGE-RAS 总览）** GAUGE-RAS = (PGE, DSE, QUAD, SWL, ACQ, ORB-CUR, PGD, GGR, D-Cert, RAS-Baselines v2, BELIEF-RAS†)。四不变式：
(i) **实时流零学习写操作**：控制环只读数据与证书，候选样本仅入队；
(ii) **来源纪律**：任一进入信任集 D_trust 的样本必须有完整 provenance，且至少经一次独立审计；
(iii) **规范纪律**：对称状态不得以单一点估计参与依赖 gauge 的决策，必须先给出 gauge 后验或商化；
(iv) **覆盖纪律**：观测落在认证覆盖 τ_cov 之外时，禁止使用高置信似然，强制按 U_sup 升级保守。

**定义 332（对称群、轨道与商状态）** 设物体对称群 G ≤ SE(3)（刚体常为有限群，回转体为连续紧群），G 自由作用于全姿态空间 𝒫_full。轨道 [p] = {h·p : h∈G}，商姿态 p ∈ 𝒫 = 𝒫_full/G。一个 gauge 选择是截面 σ : 𝒫 → 𝒫_full；gauge 自由度是纤维方向。连续对称（圆柱绕轴）没有全局截面，只能相对锚点定义（如标记点/纹理）。状态记为 s = (s_disc, p, g)，g ∈ G 为 gauge 坐标。

**定义 333（规范感知姿态后验）** 姿态估计器输出 q_t(p, g) = p(p, g | o_{1:t}, D)，满足 G-等变约束 q(h·p, h·g) = q(p, g)。gauge 边缘 q(g) = ∫ q(p,g) dp，gauge 后验 q(g|p)。定义 gauge 熵 U_gauge = E_{p∼q(p)}[H(q(·|p))]；商姿态不确定性 U_pose 用商空间上的熵/协方差。**均值只在商空间上取**，代表元均值无物理意义。

**定义 334（任务的规范依赖性）** 任务 τ 的代价 ℓ_τ(s,a) 若满足 ℓ_τ(h·s,a) = ℓ_τ(s,a) ∀h∈G，称 **gauge 不变**（如圆柱轴孔插入、质心放置）；否则称 **gauge 依赖**（如标签面朝上、键槽对齐、指定把手方向）。记 d_τ ∈ {0,1}。GGR 只约束 gauge 依赖任务；gauge 不变任务始终可在商空间执行。

**定义 335（数据集支撑与轨道覆盖）** 数据集 D = {(o_i, y_i, p_i, g_i, π_i)}。在规范不变的嵌入 φ([p], v, c)（商姿态 × 视角 × 上下文）上定义支撑密度 ρ_D（kNN / 核密度）。覆盖 C_D(Ω) = ∫_Ω min(1, ρ_D(x)/ρ_min) dx。**轨道覆盖**要求每个商单元在多个 gauge 代表上都有独立样本，而非只覆盖一个代表元；脏样本与未审计样本不计入 D_trust 的支撑。

**定义 336（有效样本量与轨道数据效率）** 对 G-等变模型，轨道 {h·o}_{h∈G} 关于商标签 [p] 的互信息等于单样本互信息 I([p]; o)，故对称增广把原始样本量放大 |G| 倍却不增加商信息；定义有效样本量 n_eff 为 D_trust 中独立商单元数。增广真正增加的是 gauge 信息，上界 I(g; orbit) ≤ log|G|。⇒ 数据构建必须**分别预算商覆盖与 gauge 锚点**，不能拿原始样本数冒充数据规模。

**定义 337（四类不确定性）**
- U_ale = E_{s∼b_t}[tr Σ_obs(s)]（R70 定义 315–316）；
- U_epi = H[b_t]（对可辨识的商/语义状态的后验熵）；
- U_gauge = E_p[H(q(·|p))]（对称规范熵，单视角下界为 log|G|）；
- U_sup = [log(ρ_min) − log ρ_D(x_o)]_+（支撑外新颖度）。
四者语义不同，不求和；分别路由到 λ_floor、MINT、GGR、ACQ/降级（定义 344、340）。

**定义 338（支撑加权观测模型）** 将 R70 的观测模型（定义 312）乘以数据支撑势：
log p_D(o|s) = log p_θ(o|s) − β·U_sup(s,o)。
U_sup > τ_nov 时置 out-of-support 标记，禁止对该似然做高置信更新；β 由覆盖率校准集确定。该式把「模型不确定」与「数据没覆盖」显式分开。

**定义 339（来源画像与信任集）** provenance π = (sensor_id, calib_id, source/annotator, policy_version, timestamp, gauge_anchor_used, audit_status)。D_trust = {i : π_i 完整 ∧ audit_status=pass}；D_audit 与训练完全隔离、只增不减、永不进入梯度。来源缺失或审计失败的样本只能进候选池，不能进信任集。

**定义 340（数据价值与主动获取 ACQ）** 对候选数据请求 d（新演示、新视角、gauge 锚点、重新标注），
VoD(d) = E[Δ(H[b] + γ·U_sup + δ·U_gauge) | d] − c(d)，
选 d* = argmax VoD，受安全、采集预算与「不得扰动部署」约束。ACQ 只在离线窗口执行；实时环只产生请求队列。

**定义 341（轨道覆盖核心集 ORB-CUR）** 在候选池中选 S，最大化 ΔC_{D∪S}(Ω_all) − λ|S|，满足 provenance 完整、去重（商单元哈希 + 嵌入距离）与预算 |S|≤B。覆盖函数对集合次模 ⇒ 贪心达到 (1−1/e) 近似最优。去重必须先商化再哈希，否则对称副本会被误当独立样本。

**定义 342（规范锚点与投毒清洗 PGD）** 规范锚点 A 为带非对称签名（标记、纹理、非对称子部件、运动视差）的观测集合。样本通过 gauge 一致性检验，当且仅当其在 ≥2 个独立锚点上得到一致的 gauge 标签；再叠加 k 源多数一致与影响函数上界 ‖∇ℓ_i‖ ≤ B_inf。仅靠 gauge 不变残差的清洗在对称物体上检测率 ≤ 1/|G|（引理 26），故锚点是必要条件。

**定义 343（自训练反馈守卫）** 信任集与候选池严格分离；候选转正需通过审计。参数更新加信赖域 KL(θ_{k+1}‖θ_k) ≤ ε_tr，数据更新只允许由覆盖目标驱动、且被 B_inf 截断。任何不满足守卫的更新回滚到上一版 D_{k−1}。

**定义 344（规范门 GGR）** 若 ECE_gauge > τ_g，或任务 gauge 依赖且 U_gauge > τ_gauge，则禁止 gauge 依赖动作：优先执行 gauge 不变回退策略，或用一次规范固定交互（旋转/视差/问询）消歧；仍未消解则退化为 R68 最保守。GGR 的输出是「允许的动作子空间」，不是风险缩放，故不会用平滑掩盖规范错误。

**定义 345（姿态校准与度量）** 采用规范不变误差：ADD-G = min_{h∈G} mean‖h·p_est − p_gt‖，GDD-G 同理。分别校准商姿态置信与 gauge 置信，报告 ECE_pose 与 ECE_gauge；可靠的 gauge 后验是 GGR 是否可信的前提。

**定义 346（数据证书 D-Cert）** D-Cert(D) = (dataset_hash, coverage_map, n_eff_per_cell, provenance_completeness, contamination_audit, gauge_anchor_coverage, audit_set_hash, version, date)。Valid ⇔ 覆盖图完整 ∧ provenance=100% ∧ 污染审计通过 ∧ 锚点覆盖 ≥ τ_anchor ∧ 审计集未泄漏。

**定义 348（数据版本、回滚与部署信任域）** 数据按 D_0, D_1, … 版本化，每版带哈希与证书。部署时仅当当前观测的覆盖分数 ≥ τ_cov 且 D-Cert Valid 才使用全置信路径；否则按 U_sup 升级保守并向 ACQ 排队。任一审计失败可原子回滚到 D_{k−1}，回滚后证书重签。

**定义 349（RAS-Baselines v2）** 在 R70 v1 基础上新增姿态/数据基线：R70-BELIEF、Pose-Point（点回归）、Sym-Aug-Only（仅对称增广）、AL-Uncertainty（无来源主动学习）、Data-NoProvenance（有数据无来源审计）。固定种子/划分/审计集；指标新增 ADD-G、ECE_gauge、OOD 覆盖-AUROC、投毒检出率、n_eff 样本效率；仍用 Wilcoxon p<0.01（Bonferroni）。

**定义 350（与 R70 的接口与严格退化）** 当 G 平凡、U_sup≡0、D 固定不更新时，PGE 退化为 R70 姿态头、SWL 退化为原似然、GGR 恒开、ACQ 不触发 ⇒ GAUGE-RAS 逐指令等于 BELIEF-RAS；再关闭交互则等于 FLUID-RAS；再令 λ 只收紧则等于 R68。安全侧永不弱于任一前序层。

```python
# IP-275 PGE：规范等变姿态估计（复用 R70 MTM trunk，输出商后验 + gauge 后验）
class GaugePoseEstimator:
    def __init__(self, trunk, quotient_head, gauge_head, G):
        self.trunk, self.qh, self.gh, self.G = trunk, quotient_head, gauge_head, G

    def posterior(self, o):
        z = self.trunk(o)
        qp = self.qh(z)                      # 商姿态分布（SE(3)/G 上的参数化）
        qg = softmax(self.gh(z))             # |G| 类 gauge 后验
        return qp, qg

    def invariant_loss(self, pred, gt):      # 轨迹/姿态损失在群轨道取下确界
        return min(geodesic(pred, act(h, gt)) for h in self.G)

# IP-276 DSE：数据支撑与新颖度（ANN 索引，只读）
class DatasetSupport:
    def __init__(self, phi, trusted_index, rho_min):
        self.phi, self.index, self.rho_min = phi, trusted_index, rho_min

    def novelty(self, p, view, ctx):
        x = self.phi(p, view, ctx)           # 规范不变嵌入
        d = self.index.knn_dist(x)           # 到信任集的最近邻
        return max(0.0, math.log(self.rho_min) - log_density(d))

# IP-277 QUAD：四类不确定性分解（互不求和，分别路由）
def quad_decompose(b_t, qp, qg, dse, o):
    U_ale   = expectation(b_t, lambda s: trace(obs_noise_cov(s)))
    U_epi   = entropy(b_t)
    U_gauge = expected_gauge_entropy(qp, qg)
    U_sup   = dse.novelty(qp.mode, o.view, o.ctx)
    return U_ale, U_epi, U_gauge, U_sup

# IP-279 ACQ：离线数据价值（实时环只入队）
def select_data_requests(b_t, qp, qg, U_sup, pool, budget):
    best = None
    for d in pool:
        gain = expected_expectation_drop(b_t, d) \
             + GAMMA * expected_novelty_drop(U_sup, d) \
             + DELTA * expected_gauge_drop(qg, d)
        score = gain - cost(d)
        if best is None or score > best.score: best = (d, score)
    return best if best and best.score > 0 else None

# IP-280 ORB-CUR：商感知覆盖核心集（先商化去重，再贪心覆盖）
def orbit_coreset(candidates, D, budget):
    cells = {quotient_cell(c): c for c in dedup_by_quotient(candidates)}
    S = greedy_max_coverage(cells.values(), D.coverage_map, budget)  # (1-1/e)
    return S

# IP-281 PGD：来源 + 锚点 + 影响上界三重清洗
def data_audit(cand, anchors, D):
    if not provenance_complete(cand):                 return False
    if not gauge_consistent(cand, anchors, k=2):      return False   # 对称投毒唯一有效防线
    if influence_norm(cand) > B_INF:                  return False
    if not independent_of(D.audit_set, cand):         return False
    return True

# IP-285 主闭环：实时环只读，数据只入队
def GAUGE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    b_t  = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)
    qp, qg = M.pge.posterior(o)
    U_ale, U_epi, U_gauge, U_sup = quad_decompose(b_t, qp, qg, M.dse, o)
    # 1) 支撑加权：覆盖外不允许高置信似然
    b_t = M.bse.reweight(b_t, math.exp(-BETA * U_sup))
    # 2) 规范门：gauge 依赖任务先固定，再决策
    need_gauge = M.task.gauge_dependent and U_gauge > TAU_GAUGE
    if need_gauge and M.ggr.can_resolve(M.budget):
        g = M.mint.choose_interaction_belief(
                b_t, M.fmp, M.budget, M.c_ras_wm, mode='gauge')   # 旋转/视差/问询
        if g is not None:
            y = M.cia.execute(g)
            b_t = M.bse.step(b_t, o, M.last_action, g, y)
            qp, qg = M.pge.posterior_fused(o, y)
            U_gauge = expected_gauge_entropy(qp, qg)
    gauge_ok = (not need_gauge) or (U_gauge <= TAU_GAUGE)
    # 3) 风险缩放：aleatoric + 未消解 epistemic + 支撑外惩罚
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (U_epi if not gauge_ok else 0.0) + GAMMA_SUP * U_sup))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    # 4) 规范未解：动作限制在商空间；覆盖外：回 R68 最保守
    if not gauge_ok:
        mode = M.gauge_invariant_policy.select(qp, b_t, lam)
        lam  = max(lam, 0.8)
    else:
        mode = M.pi.select(qp, qg, b_t, lam)
    if U_sup > TAU_NOV:
        lam = max(lam, 0.8)
        M.data_queue.enqueue(obs, reason='out_of_support')        # 离线处理
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_iii.submit_async(b_t, qp, qg, (U_ale, U_epi, U_gauge, U_sup))
    M.b_prev = b_t
    return k, lam, mode, (U_ale, U_epi, U_gauge, U_sup)

# IP-285 离线数据轮（与控制环解耦，可回滚）
def OFFLINE_DATA_ROUND(M, queue):
    cand = dedup_by_quotient(queue)
    cand = [c for c in cand if data_audit(c, M.anchors, M.D)]
    S    = orbit_coreset(cand, M.D, budget=M.data_budget)
    D_new = certify(M.D, S)                     # 生成 D-Cert
    if D_new.valid: M.D = D_new
    else:           M.D = rollback(M.D)         # 失败原子回滚
    return M.D
```

## 3. 推导

**引理 23（规范分解与「问不出来」）** 设 G 有限且自由作用，q(p,g) 满足 G-等变。由链式法则
H(q(p,g)) = H(q(p)) + E_{p∼q(p)}[H(q(g|p))]。
若观测是单视角且对 G 不变、估计器严格等变，则 q(g|p) = Unif(G)，U_gauge ≡ log|G|，且任何同视角新观测都不改变 q(g|p)，故 gauge 的 VoI 恒为 0。三种处理方式的后果：(i) 当 aleatoric → λ_floor 永久背上 log|G|，过度保守且拿不到 resolution bonus；(ii) 当 epistemic → MINT 算出 VoI=0，要么永不交互、要么浪费预算问一个物理上不可答的问题；(iii) 正确做法 → 商化状态，仅当存在**破对称观测**（锚点/非对称特征/运动视差/主动旋转）时才固定 gauge。系：R70 在对称物体上的「自信错误」不是校准失败，而是**把规范当成了概率**。

**引理 24（轨道数据效率）** 对 G-等变 f 与商标签 [p]，轨道增广样本 {(h·o, h·p)}_{h∈G} 关于 [p] 的互信息等于单样本互信息：I([p]; orbit) = I([p]; o)。因此原始样本量可被增广放大 |G| 倍而商信息不变；n_eff 必须以独立商单元计。反过来，轨道增广新增的恰是 gauge 信息，其上界 I(g; orbit) ≤ log|G|。系：**对称增广制造「数据规模幻觉」**；数据构建必须显式分开「商覆盖预算」与「gauge 锚点预算」。

**引理 25（支撑加权风险上界）** 设损失 L-Lipschitz、似然比有界，新颖度 n(o)=[log(ρ_min/ρ_D)]_+。则
R(π) ≤ R_in(π) + L·E[n(o)] + c·E[U_gauge·1_{d_τ=1}] + o(1)。
即部署风险由三部分显式构成：分布内风险、覆盖外推惩罚、规范依赖惩罚。这把 R70 的「观测模型失配」从一个口头风险变成可度量、可证书化的三项预算。系：D-Cert 的覆盖图就是 R_in 之外那两项的上界凭证。

**引理 26（规范投毒的隐形性）** 对 gauge 翻转标签 (o, h·p)，gauge 不变残差 min_{h'∈G} d(h'·h·p, h·p) = 0，故任何仅基于商残差/几何一致性的清洗都无法区分；在对称先验下检测率 ≤ 1/|G|（接近随机）。必须依赖带非对称签名的锚点、跨 episode gauge 一致性或独立来源；否则投毒会被数据引擎「验证通过」。这是 IP-281 的理论依据。

**定理 20（严格包含链）** 在 A99–A103（R70 的识别性/子模性/Lipschitz，加 A102 覆盖可估、A103 规范可分）下，期望风险
R(GAUGE) ≤ R(BELIEF) ≤ R(FLUID) ≤ R(R68)；
且当 G 平凡、U_sup≡0、D 固定不更新时四者逐指令相同（定义 350）。安全侧层层不让步，效率侧获得覆盖与规范两个 resolution bonus。

**定理 21（数据飞轮稳定性）** 在 (a) 信任集/候选池分离、(b) provenance 完整、(c) 影响上界 B_inf、(d) 信赖域 KL≤ε_tr、(e) 仅覆盖目标驱动获取 下，信任集分布满足
W_1(D_k^trust, D_ref) ≤ W_1(D_0, D_ref) + C·ε_tr/(1−κ)，κ<1；
且信任集中被投毒比例 ≤ δ·ρ^{k−1} + ε_σ。即数据飞轮不会自我放大，回滚条件明确。系：数据引擎可以「越用越好」，但前提是它先被证明「不会越用越偏」。

**定理 22（安全保持与无实时突变）** GGR + 商化回退 + 离线写 下：gauge 未解时不存在依赖 gauge 的控制指令；实时环不写任何学习状态，R68 的提交/换装不变式（定理 15）保持；覆盖外强制降到 R68 保守路径。故规范翻转或数据污染都不能在同一 episode 内改变已认证的安全前缀，控制连续、无突变。

## 6. 本轮最大风险

**一句话**：GAUGE-RAS 全部筹码押在「覆盖与来源可以被可靠估计」上——但高维（商姿态 × 视角 × 物体 × 遮挡）的支撑密度外推极差，而沿对称群整圈复制的 gauge 偏见恰好是低残差、自洽、覆盖率证书最查不出的那类错误；**系统可能为一份系统性教错朝向的数据集盖上合格章，再拿它自信地做依赖朝向的操作**。

**次级风险与缓解**：
1. **覆盖估计高维失效** → 规范不变嵌入降维 + 单元化覆盖图 + 覆盖-AUROC 在线监控（E324）；
2. **锚点本身被投毒** → 多锚点、多来源、k-一致 + 审计集隔离（定义 342、定理 21）；
3. **连续对称无全局 gauge** → 只允许相对锚点的局部 gauge；轴对齐任务强制走商化策略（定义 332、334）；
4. **数据飞轮确认偏误** → 信任集/候选池分离 + 信赖域 + 影响上界 + 可回滚（定义 343、348）；
5. **实时开销击穿预算** → PGE/DSE 复用 trunk 与 ANN，数据侧全部离线（复杂度表）。

**定义 342（PGD）** 来源完整 + ≥2 独立规范锚点一致 + k 源多数 + 影响上界 B_inf。仅靠 gauge 不变残差检测率 ≤1/|G|（引理 26）。

**定义 343（反馈守卫）** 信任集/候选池分离；信赖域 KL≤ε_tr；覆盖目标驱动；失败回滚 D_{k−1}。

**定义 344（GGR）** 若 ECE_gauge>τ_g 或（gauge 依赖且 U_gauge>τ_gauge）：禁止 gauge 依赖动作，执行商化回退或一次规范固定交互，仍未解则回 R68。

**定义 345（姿态校准）** 商姿态与 gauge 分别校准；报告 ECE_pose 与 ECE_gauge；用 ADD-G/GDD-G 评估。

**定义 346（D-Cert）** 覆盖图完整、provenance=100%、污染审计通过、锚点覆盖≥τ_anchor、审计集未泄漏 ⇒ Valid。

**定义 347（J_GAUGE）** Valid ⇔ Valid(J_BELIEF) ∧ Valid(D-Cert) ∧ ECE_pose≤τ_pose ∧ ECE_gauge≤τ_g ∧ 规范/覆盖纪律满足。

**定义 348（版本与信任域）** 数据版本 D_k 带哈希与证书；部署仅当覆盖分数≥τ_cov 且 D-Cert Valid 走全置信路径，否则升级保守并排队；审计失败原子回滚。

**定义 349（RAS-Baselines v2）** 5 基线：R70-BELIEF、Pose-Point、Sym-Aug-Only、AL-Uncertainty、Data-NoProvenance；固定种子/划分/审计集；指标加 ADD-G、ECE_gauge、覆盖-AUROC、投毒检出、n_eff 效率；Wilcoxon p<0.01（Bonferroni）。

**定义 350（严格退化）** G 平凡 ∧ U_sup≡0 ∧ D 不更新 ⇒ GAUGE≡BELIEF；关闭交互 ⇒ FLUID；只收紧 ⇒ R68。

## 3. 数据引擎协议（D-Cert schema 与信任集生命周期）

```text
D-Cert v1 {
  dataset_hash:      sha256(all sample hashes + provenance)     # 可比特级复现
  coverage_map:      {cell_id -> {rho, n_eff, last_update}}      # 商姿态×视角×遮挡×光照
  provenance:        {completeness: %, missing_fields: [...]} 
  contamination:     {audit_pass: bool, suspect_ratio: %, method: "anchor+k-source+influence"}
  anchors:           {count, types: [fiducial, texture, parallax], coverage: %}
  audit_set_hash:    sha256(audit split)                         # 永不训练
  version:           D_k
  rollback_parent:   D_{k-1}
}
```

**生命周期（每步可回滚）**：
1. 部署实时环只把 out-of-support / 高 U_gauge / 交互失败样本写入 `data_queue`（不训练、不落信任集）；
2. 离线批处理：商化去重 → provenance 过滤 → 锚点一致性 → k 源多数 → 影响上界截断；
3. ORB-CUR 在预算内最大化商覆盖，**先商化后哈希**，避免对称副本伪造独立样本；
4. `certify(D ∪ S)` 生成 D-Cert；Valid 才替换，否则回滚；
5. 训练后重签 J_GAUGE；覆盖图与审计集哈希进入证书，部署据此决定信任域。

## 4. 关键算法伪代码

```python
# IP-275 PGE：等变姿态头，输出商后验与 gauge 后验
class GaugePoseEstimator:
    def posterior(self, o):
        z  = self.trunk(o)
        return self.qh(z), softmax(self.gh(z))     # p(p|o), p(g|o)

    def invariant_loss(self, pred, gt):
        return min(geodesic(pred, act(h, gt)) for h in self.G)

# IP-276 DSE：支撑/新颖度（只读 ANN 索引）
def novelty(dse, p, view, ctx):
    x = dse.phi(p, view, ctx)
    return max(0.0, math.log(dse.rho_min) - log_density(dse.index.knn_dist(x)))

# IP-277 QUAD：四分解，分别路由
def quad(b_t, qp, qg, dse, o):
    return (expectation(b_t, lambda s: trace(obs_noise_cov(s))),
            entropy(b_t),
            expected_gauge_entropy(qp, qg),
            novelty(dse, qp.mode, o.view, o.ctx))

# IP-280 ORB-CUR：商感知核心集
def orbit_coreset(cand, D, budget):
    cells = {quotient_cell(c): c for c in dedup(cand)}   # 先商化再去重
    return greedy_max_coverage(cells.values(), D.coverage, budget)

# IP-281 PGD：三重审计（对称投毒的必要防线）
def audit(c, anchors, D):
    return (provenance_complete(c)
            and gauge_consistent(c, anchors, k=2)
            and influence_norm(c) <= B_INF
            and not leaks(D.audit_set, c))

# IP-285 实时环（只读）
def GAUGE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs)
    b_t  = M.bse.step(M.b_prev, o, M.last_action, M.last_g, M.last_y)
    qp, qg = M.pge.posterior(o)
    U_ale, U_epi, U_gauge, U_sup = quad(b_t, qp, qg, M.dse, o)
    b_t = M.bse.reweight(b_t, math.exp(-BETA * U_sup))
    need_gauge = M.task.gauge_dependent and U_gauge > TAU_GAUGE
    if need_gauge and M.ggr.can_resolve(M.budget):
        g = M.mint.choose_interaction_belief(b_t, M.fmp, M.budget, M.c_ras_wm, mode='gauge')
        if g is not None:
            y = M.cia.execute(g)
            b_t = M.bse.step(b_t, o, M.last_action, g, y)
            qp, qg = M.pge.posterior_fused(o, y)
            U_gauge = expected_gauge_entropy(qp, qg)
    gauge_ok = (not need_gauge) or (U_gauge <= TAU_GAUGE)
    lam = max(M.efs.risk_scale(...),
              lam_floor(U_ale + (U_epi if not gauge_ok else 0.0) + GAMMA_SUP * U_sup))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not gauge_ok:
        mode = M.gauge_invariant_policy.select(qp, b_t, lam); lam = max(lam, 0.8)
    else:
        mode = M.pi.select(qp, qg, b_t, lam)
    if U_sup > TAU_NOV:
        lam = max(lam, 0.8); M.data_queue.enqueue(obs, reason='out_of_support')
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_iii.submit_async(b_t, qp, qg, (U_ale, U_epi, U_gauge, U_sup))
    M.b_prev = b_t
    return k, lam, mode, (U_ale, U_epi, U_gauge, U_sup)

# IP-285 离线数据飞轮（与控制环解耦）
def OFFLINE_DATA_ROUND(M, queue):
    cand = [c for c in dedup_by_quotient(queue) if audit(c, M.anchors, M.D)]
    S = orbit_coreset(cand, M.D, budget=M.data_budget)
    D_new = certify(M.D, S)
    M.D = D_new if D_new.valid else rollback(M.D)
    return M.D
```

## 5. 推导

**引理 23（规范分解与不可问性）** H(q(p,g))=H(q(p))+E_p[H(q(g|p))]。单视角 G-不变观测 + 严格等变估计 ⇒ q(g|p)=Unif(G)，U_gauge=log|G|，同视角新观测不改变 q(g|p)，VoI_gauge=0。故：当 aleatoric 会永久过度保守；当 epistemic 会问一个物理不可答的问题；正解是商化 + 破对称观测（锚点/视差/旋转）。

**引理 24（轨道数据效率）** I([p]; orbit)=I([p]; o)，对称增广放大原始样本量但不增加商信息；n_eff 以独立商单元计，gauge 信息增量上界 log|G|。系：数据规模幻觉来自把增广当覆盖。

**引理 25（支撑加权风险上界）** R(π) ≤ R_in + L·E[U_sup] + c·E[U_gauge·1_{d_τ=1}] + o(1)。风险被显式拆成分布内、覆盖外推、规范依赖三项，分别由 D-Cert 与 GGR 约束。

**引理 26（规范投毒隐形性）** gauge 翻转标签的商残差恒为 0，任何仅基于商一致性的清洗检测率 ≤1/|G|；必须用非对称锚点或跨 episode gauge 一致性。系：对称数据集的「干净」可能只是「偏见自洽」。

**定理 20（严格包含链）** A99–A103 下 R(GAUGE)≤R(BELIEF)≤R(FLUID)≤R(R68)；G 平凡 ∧ U_sup≡0 ∧ D 固定时逐指令相同。安全侧不让步，效率侧获得覆盖/规范 resolution bonus。

**定理 21（数据飞轮稳定性）** 信任集/候选池分离 + provenance 完整 + 影响上界 + 信赖域 + 覆盖驱动获取 ⇒ W_1(D_k^trust,D_ref) ≤ W_1(D_0,D_ref)+C·ε_tr/(1−κ)，κ<1；投毒比例 ≤ δ·ρ^{k−1}+ε_σ。数据可以越用越好，但必须先被证明不会越用越偏。

**定理 22（安全保持）** GGR + 商化回退 + 离线写 ⇒ gauge 未解时无 gauge 依赖指令；实时不写学习状态，R68 提交/换装不变式保持；覆盖外强制回 R68 保守。规范翻转与数据污染都不能在同一 episode 内改变已认证安全前缀。

## 8. 本轮最大风险

**一句话**：GAUGE-RAS 押注「覆盖与来源可被可靠估计」，但高维支撑密度外推极差，而沿对称群整圈复制的 gauge 偏见低残差、自洽、最难过覆盖检查——**系统可能为一份系统性教错朝向的数据集盖章，再用它自信地执行依赖朝向的操作；数据层被污染时，前面所有贝叶斯层只会把错误算得更精确**。

**次级风险**：(1) 覆盖估计高维失效 → 规范不变降维 + 单元覆盖图 + 覆盖-AUROC 监控；(2) 锚点被投毒 → 多锚点/k 源/审计隔离；(3) 连续对称无全局 gauge → 仅局部 gauge + 强制商化；(4) 飞轮确认偏误 → 分离/信赖域/影响上界/回滚；(5) 实时预算 → PGE/DSE 复用与 ANN，数据侧全离线。
