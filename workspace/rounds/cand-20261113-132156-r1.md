# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「SLAM」×「模型蒸馏」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，但它自述的最大风险一针见血：**VISTA 假设故障属于有限假设集、且视觉与几何的失效相互独立；一旦遇到未知复合故障或共因失效，FIR 会把未知故障强行归入最近假设、只膨胀错误的球，而且系统会因为「已经归因」而更自信地继续执行（隐藏假设 A88）。** 换成结构化的话：VISTA 的归因是**一次性、无记忆、闭集、同步**的。本轮不换模态、也不堆假设，而是换提问方式：第 65 轮问「谁坏了、该不该继续」，DRIFT 问「**我们过去对『谁坏了』的判断现在还站得住吗？那个便宜的实时判断器，凭什么代表慢的那个说话？**」本轮核心命题：
>
> **把故障归因从「一次性后验」升级为「可回环、可重定位、可追溯修订的持久故障地图」，并把实时安全判断做成一个带有认证师生差界的蒸馏学生——它必须知道自己何时不知道，并主动把话语权交回慢教师。** 目标从「归因更准」转为「**信念可被证伪、错误可被追溯、委托可被认证**」。

## 0. 直觉与动机

**灵感 1（SLAM → 故障信念也是一张会漂移的地图）**
直觉：SLAM 的核心既不是「定位」也不是「建图」，而是**在噪声、部分可观测、数据关联歧义下，维持一个全局一致、可被回环修正、并且知道自己何时迷路的估计**。VISTA 的 FIR 恰好缺这三件事：它每个块独立算后验，误差随时间累积（信念漂移）；遇到未知故障无法回环纠正；从不承认「我丢了」。把故障状态（力偏置、几何偏移、接触模型误差幅度）看成地图里的位姿，把阶段签名看成观测，把「同一物体 / 同一接触制度 / 同一光照桶」的重访看成回环——**VISTA 的 FIR 就只是 SLAM 的前端，缺的正是后端。**

**灵感 2（SLAM 的三个硬机制 → 逐条补 VISTA 的三个洞）**
直觉：(i) **鲁棒后端（switchable constraints / max-mixture）**：SLAM 不会因为一条错误回环就毁掉整张地图，而是允许「先把这条件关掉」。对应 VISTA：未知复合故障不该被强行分配，而应允许「关联不确定」的软边——**故障空间的数据关联歧义（fault aliasing）与 SLAM 的感知歧义（perceptual aliasing）是同一个病**。(ii) **回环 + 全局一致性检验（NEES / 卡方）**：新证据与旧归因冲突时触发**追溯性重归因**，而不是让错误归因固化；全局不一致超界就判 `belief_lost`。(iii) **绑架恢复 / 重定位**：迷路时不做假设，而是回到已知锚点做安全重定位（零力窗 + 视觉已知地标）。这三件事恰好逐条对冲第 65 轮的「强行归因 + 教条自信」。

**灵感 3（模型蒸馏 → 慢教师、快学生，以及认证差界）**
直觉：VISTA 反复的工程矛盾是：最强的推理（世界模型、FIR、conformal、图优化）只能在语义流跑，而实时流要在 2.5ms 内做安全判断。蒸馏给出正解：把慢教师蒸成快学生（故障后验 + 认知不确定度 + **弃权头**）。但蒸馏有一个常被忽视的安全前提——**学生不是教师的等价物，分布漂移下会更差，而且学生会继承教师的系统偏差**。所以不能「蒸完就信」：必须给师生**决策分歧**一个分布无关的 conformal 上界（Mondrian，按上下文分桶），学生只在「被认证的桶」里说话，否则**升级 / 弃权**。这把「性能优化」变成了「可证的安全委托」。

**灵感 4（两灵感合流：SLAM 的图 + 蒸馏的委托，其实是同一个结构）**
直觉：SLAM 里，**里程计是便宜、局部准、会漂移的**；**地图 / 全局优化是昂贵、全局一致、偶尔也会错的**；回环是二者对账的机制。蒸馏里，**学生是便宜、局部准、会漂移的**；**教师是昂贵、全局一致、偶尔也会错的**；CDG 正是「师生对账」的门控。于是：**学生 ≈ 里程计，教师 ≈ 地图，CDG ≈ 里程计协方差，回环 ≈ 追溯重归因，重定位 ≈ 绑架恢复。** 这不是两个灵感的拼贴，而是同一个「快慢双估计器 + 定期对账 + 可恢复」结构在两层的实例化。DRIFT 的主循环因此是：快的先走（猜测执行）→ 慢的异步对账（认证）→ 不一致就回滚并重定位 → 回环把过去的错误一次性修正，但**审计账本永不重写**。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → FAM**：从「每块一个后验」变成「关键帧故障图 + 鲁棒签名因子 + 多假设关联」，输出边缘协方差而不只是点后验。
- **AFA → AFA-LC**：探针目标从「降低当前故障熵」扩为「降低**全局图熵** + 提高回环可能性」，把「主动探测」变成「主动回环」（Active SLAM 的对偶）。
- **CSC → SVE**：从「认证前缀」升级为「猜测执行 + 异步教师认证 + 可回滚」；**可逆区才猜测，不可逆区必须同步**。
- **RSC-V → RSC-M**：球半径不再拍脑袋膨胀，而由故障图的边缘协方差 + CDG 界导出，统计上可解释。
- **WCV-V**：搜索域用图的边缘分布替代独立球，天然处理 r_geo / r_force / r_model 的相关性（协方差交叉）。
- **AIC-V → AIC-D**：干扰集增分布漂移、教师偏差注入、回环投毒、容量差、延迟；认证目标从「归因正确」改为「**该升级时升级、该停下时停下**」。
- **J_vista → J_drift**：证书增 fault_graph_hash、NEES、CDG 桶界、推测视界 s*、重定位事件、审计纪元。
- **新增 TSD / CDG**：把「教师-学生」从隐藏实现细节升为一等公民。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（DRIFT 闭环）**：DRIFT = (VISTA, FAM, FLC, KBD, AFA-LC, TSD, CDG, SVE, RSC-M, AIC-D, J_drift)。定位：VISTA 的「可修订信念 + 认证委托」升级。不变式：**图优化、回环、教师推理、证书只在语义流 / 低频线程；实时流只做学生推理、CDG 门控、猜测派发、回滚检查；审计账本只追加不重写；零学习写操作。**
- **定义 234（故障归因图 FAM）**：关键帧 k=1..K，状态 x_k=(θ_k,h_k)，θ_k∈ℝ^{d_H} 为故障幅度，h_k∈ℋ 为离散故障类。边含 (i) 故障里程计因子 x_{k+1}=f(x_k,Δ)+w，w∼N(0,Σ_Δ)（故障慢漂移）；(ii) 签名因子 r_k=ρ_k−S(θ_k,h_k)，信息 Ω_k。MAP：x̂=argmin Σ‖r_k‖²_{Ω_k}+Σ‖x_{k+1}−f‖²_{Σ_Δ}。
- **定义 235（鲁棒签名因子）**：每条签名 / 回环边带开关变量 s_e∈[0,1]（switchable constraints）或 max-mixture：cost=Σ s_e‖r_e‖²_{Ω_e}+Ψ(s_e)，Ψ(s)=(1−s)²/(2σ_s²)；或 p(r_e)=max_i w_i N_i(r_e)。**未知故障表现为被开关关掉的边，而不是被强行塞进最近假设。**
- **定义 236（多假设关联 MHT）**：维护关联树，第 m 个假设给每个关键帧分配 (h_k, 数据关联)，权重 w^{(m)}∝p(ρ_{1:K}|m)P(m)。惰性剪枝：仅当 w^{(m)}<w_min 或与最优的 KL>τ_mh 才删。输出后验边缘 P(h_k|ρ_{1:K}) 与 θ_k 的边缘协方差 Σ_k，而非单一点估计。
- **定义 237（故障空间回环 FLC）**：上下文指纹 c_k=(物体嵌入, 接触制度直方图, 光照/曝光桶, 技能 id, 位姿格)。若 ‖c_k−c_j‖<τ_ctx 且**至少两个独立通道**（视觉 + 力签名）一致，则提出回环因子 θ_k−θ_j=0，并做卡方门控：若与中间里程计链不一致（χ²>χ²_thr）则拒绝或降权。回环的目的不是「确认现在对」，而是「**修正过去错**」。
- **定义 238（追溯性重归因与只追加审计）**：FLC 后重优化图，得到过去关键帧的修订信念 θ_k^{+}、h_k^{+}。**已发证书不可改写**；修订只产生补偿动作（复检历史接触、把已加工件标记为可疑、重标定传感器），并以 (audit_epoch, keyframe_id, old→new, reason) 追加进审计账本。非回溯不变式：**改信念，不改历史凭证。**
- **定义 239（全局一致性与绑架检测 KBD）**：以交叉验证参考或物理不变量作参照，计算 NEES_k=e_k^{T}Σ_k^{-1}e_k，e_k=θ̂_k−θ_k^{ref}。若连续 W 个关键帧 NEES>χ²_{d,1−α_nees}，判 `belief_lost=True`。**这是唯一能抓到「教师与学生一起错」的独立信号。**
- **定义 240（安全重定位）**：`belief_lost` 时不归因，执行安全重定位：回到已知锚点位姿 → `null_test` 估零力偏置 → 视觉已知地标/基准件核验 → 用新先验重置图并清零漂移 → 记录 `relocalization_event`。若无法安全锚定，则 `safe_idle` + 柔顺撤退。
- **定义 241（带回环增益的主动归因 AFA-LC）**：a*=argmax_a [ΔH(FAM|a) + λ_lc·p_lc(a)·ΔH_lc(a)]，s.t. f_n≤f_safe、形变≤ε_strain、可早停。ΔH 用边缘协方差做 D-最优近似；p_lc 为由上下文指纹预测的回环概率。**探针从「分清楚谁坏了」升级为「让整张故障图更可分辨」。**
- **定义 242（教师-学生蒸馏 TSD）**：教师 T（FIR+FAM+VPG+conformal）与学生 S。S 输出三头：p_S^τ(H|ρ,ctx)、log σ_S²（认知项，用集成蒸馏得到）、abstain 分数（energy / margin）。损失 L=CE(p_T^τ,p_S^τ)+λ_u·U+λ_a·L_abstain+λ_z·‖z_S−z_T‖²。**学生被明确训练成「该弃权时弃权」，而不是硬猜。**
- **定义 243（认证蒸馏差 CDG）**：上下文桶 b(x)=(故障类 × 阶段熵分位 × OOD energy 分位)。安全决策 δ∈{接收,膨胀球,升级,停机}。决策分歧 d(x)=1[δ_S(x)≠δ_T(x)]。对每桶在标定集上取 Mondrian split-conformal 分位 q_b=⌈(n_b+1)(1−α_d)⌉/n_b。**可信桶**：q_b≤ε_d 且 n_b≥n_min；则对可交换新样本 P[d=1|b]≤α_d。不可信桶→升级教师或弃权。
- **定义 244（升级策略）**：三档 {trust_student, query_teacher_async, hard_stop}，由 (q_b, 学生 margin, 剩余推测视界, 任务可逆性) 决定。不可逆区禁止 trust_student；无教师响应时按硬实时下降级为保守动作（k=1 或停）。
- **定义 245（猜测执行 SVE）**：设可逆视界 m_rev（可在不造成不可逆后果前停下/回滚的步数，m_rev≤m）。学生起草长度 s 的前缀与归因；执行需 s≤min(H,m_rev) 且（教师已 ACK ∨ 处于可信桶）。教师异步核验延迟 τ_T；若在 s 内否决或 CDG 违约 → 回滚到最近认证检查点 C_j 并重归因。**不可逆区不猜测**（s=1，同步教师或保守）。
- **定义 246（图一致球校准 RSC-M）**：r_geo=√(κ·λ_max(Σ_geo))+q_cdg,geo，r_force、r_model 同理；融合用协方差交叉 CI(Σ_a,Σ_b) 而非独立球相加，天然处理相关。球随图优化更新，**不再用固定 κ_infl 拍脑袋膨胀**。
- **定义 247（AIC-D 蒸馏/漂移对抗认证）**：ℰ_D=ℰ_V×ℰ_shift×ℰ_teacher×ℰ_loop×ℰ_gap。ℰ_shift 协变量/新物体漂移；ℰ_teacher 教师系统性偏差注入；ℰ_loop 回环投毒 / 感知歧义；ℰ_gap 容量差 / 量化 / 延迟。**认证目标不是「归因正确」，而是「在共因失效下仍能升级/停机」。** 显式标注：教师与学生共享数据，误差相关，CDG 只认证分歧、不认证正确性。
- **定义 248（J_drift 证书）**：J_drift=(J_vista, fault_graph_hash, nees, consistency_ok, cdg_bounds, trusted_buckets, s*, relocalization_event, audit_epoch, aic_d_ver)。Valid ⇔ Valid(J_vista) ∧ (图一致 ∨ 已完成安全重定位) ∧ (每个执行决策 ∈ 可信桶 ∨ 已被教师同步认证) ∧ 推测步 s*≤m_rev ∧ 回环均过双通道门控 ∧ 审计只追加完整。

## 2. 关键算法骨架

```python
# 语义流：图更新 + 回环 + 绑架检测 + 教师归因 + 蒸馏监督
graph.update(phases, visual)                    # 关键帧 + 鲁棒签名因子
if loop := loop_detector.match(context_fp):     # 上下文指纹回环
    if two_channel_agree(loop) and chi2_gate(loop):
        graph.add_loop_factor(loop)             # θ_k - θ_j = 0
        graph.optimize_robust()                 # switchable / max-mixture
        revisions = graph.retro_reattribute()   # 修订过去信念
        audit.append(revisions)                 # 只追加，不改旧证书
        compensate(revisions)                   # 复检/标记可疑件/重标定
if graph.nees() > chi2_thr for W frames:
    belief_lost = True                          # 不做假设
    relocalize_safely(anchor_pose)              # null_test + 视觉地标
post_T, z_T = teacher.attribute(graph)          # 慢教师
student.train_step(distill(post_T, z_T))        # 离线/低频：蒸馏 + 弃权头
a = afa_lc.choose(graph, f_safe)                # 全局图熵 + 回环增益

# 实时流：学生 + CDG + 猜测执行（零学习写）
p_S, sigma_S, abstain = student.infer(rho, ctx)
b = bucket(ctx)
trusted = cdg.trusted(b) and (not abstain)
s = sve.draft_horizon(p_S, trusted, m_rev)      # 可逆视界内
for a in prefix[:s]:
    dispatch(a)
    if not trusted: teacher.verify_async(a)     # 异步对账
    if teacher.rejected(a) or sve.monitor(a).abort:
        rollback(last_certified_checkpoint)     # 回滚 + 重归因
        break
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（鲁棒故障图不被有界坏边腐蚀）**：在截断/开关型鲁棒代价下，只要坏边比例低于鲁棒估计器的 breakdown point、且内点子图连通（信息下界 λ_min^{+}>0），则 ‖θ̂−θ*‖ ≤ 2c√m_out/λ_min^{+} + 噪声项。**因此一条错误回环或一个未知复合故障不会污染整张地图，只会被关掉并留下审计痕迹。**
- **引理 10（学生委托的可证误差）**：对可信桶 b 的可交换样本，Mondrian conformal 给出 P[d=1|b]≤α_d；若 q_b=0 且 n_b≥1/α_d−1，则 P[d=1|b]≤1/(n_b+1)≤α_d。结合 s*≤m_rev 与回滚，蒸馏引入的额外风险 ≤ α_d+α_rollback+α_stop。
- **定理 9（DRIFT 端到端可修订-安全）**：在 A94–A98 下，Valid(J_drift) ⇒ 信念一致或已安全重定位 ∧ 可信桶内决策的师生分歧有界 ∧ 执行前缀在可逆视界内且可回滚 ∧ 审计只追加完整 ∧ GRIP/VISTA 仍然有效。**故障归因第一次具备「过去可被修、错误可被追、委托可被证」三重性质。**
- **定理 10（猜测执行的速度-安全折中）**：设学生单步代价 c_S、教师延迟 τ_T、接受率 p_acc(s)。期望延迟 E[L(s)]=s·c_S+(1−p_acc(s))·τ_T；安全风险 R(s)=c_risk·1[s>m_rev]+α_d·(1−p_acc(s))。故最优 s*=min(H,m_rev,argmax_s(E[L]−λR))。**可逆区尽量猜、不可逆区必须同步。**
- **命题（可修订性破除固化）**：VISTA 一次性错误在无回环时以概率 1 永久保留；DRIFT 下其存续时间服从参数 λ_lc 的几何分布，期望修正时间 ≈1/λ_lc，且修正不重写历史证书。
- **实时性**：学生推理 <0.1ms、CDG 桶查询 <0.02ms、SVE 派发/回滚检查 <0.08ms；图优化、回环、教师、CDG 标定全在语义流。实时路径目标仍 ≤2.5ms。

## 2. 形式化定义（完整版）

**定义 233（DRIFT 闭环）** DRIFT 是 VISTA 的「可修订信念 + 认证委托」升级：保留 GRIP/VISTA 的语义流 ∘ 实时流骨架，新增 FAM（故障因子图）、FLC（故障空间回环）、KBD（绑架检测）、AFA-LC（全局信息探针）、TSD（师生蒸馏）、CDG（认证差界）、SVE（猜测执行）、RSC-M（图一致球），并原位升级 AIC-V→AIC-D、J_vista→J_drift。不变式：**图优化、回环重归因、教师推理、CDG 标定、证书构建只在语义流/低频线程；实时路径只做学生推理、CDG 桶查询、猜测派发与回滚检查；审计账本只追加；零学习写操作。**

**定义 234（故障归因图 FAM）** 关键帧 k=1..K，状态 x_k=(θ_k,h_k)，θ_k∈ℝ^{d_H} 为故障幅度（力偏置、几何偏移、模型误差系数等），h_k∈ℋ 为离散故障类。因子图含：
- **故障里程计因子**：x_{k+1}=f(x_k,Δ)+w，w∼N(0,Σ_Δ)，刻画故障的**慢漂移**（传感器偏置、软接触参数随温漂缓慢变化）；
- **签名因子**：r_k=ρ_k−S(θ_k,h_k)，信息矩阵 Ω_k，其中 ρ_k 为第 65 轮定义 220 的阶段签名；
- **回环因子**：见定义 237。
MAP 估计 x̂=argmin_x Σ_k‖r_k‖²_{Ω_k}+Σ_k‖x_{k+1}−f(x_k,Δ)‖²_{Σ_Δ}。FAM 的输出不是单点后验，而是每个关键帧的**边缘后验** P(h_k|ρ_{1:K}) 与边缘协方差 Σ_k——后者直接喂给 RSC-M（定义 246）。**关键差别：VISTA 的 FIR 每块「算完即弃」，误差无法累积校正；FAM 把历史变成可优化变量。**

**定义 235（鲁棒签名因子）** 对每条签名/回环边 e 引入开关变量 s_e∈[0,1]（switchable constraints），代价
cost_e = s_e‖r_e‖²_{Ω_e}+(1−s_e)²/(2σ_s²)，
或等价的 max-mixture p(r_e)=max_i w_i·N(r_e;0,Ω_{e,i}⁻¹)。最优点处若边与全局估计严重不符，s_e→0：**该边被「关掉」而非强行参与优化**。这为「未知复合故障 / 数据关联歧义」提供了正式出口——对应 SLAM 中鲁棒位姿图对错误回环的抑制（Sünderhauf 2012；Agarwal 2013）。**VISTA 的「强行归入最近假设」在此被替换为「暂时不关联，等待更多证据」。**

**定义 236（多假设关联 MHT）** 维护关联假设树，第 m 个假设给每个关键帧指定 (h_k, 数据关联)；权重
w^{(m)} ∝ p(ρ_{1:K}|m)·P(m)，
惰性剪枝：仅当 w^{(m)}<w_min 或与最优假设的对称 KL>τ_mh 时删除。输出边缘 P(h_k|ρ_{1:K}) 与 Σ_k。**归因不再是一个 argmax，而是一个可保留多个候选、可被后续回环/探针分离的后验分布**——这直接对冲 A88「有限假设集 + 强行归类」。

**定义 237（故障空间回环 FLC）** 上下文指纹 c_k=(物体嵌入, 接触制度直方图, 光照/曝光桶, 技能 id, 位姿格)。若存在历史关键帧 j 使 ‖c_k−c_j‖<τ_ctx，且**至少两个独立通道**（视觉足迹/形变 与 力/力矩签名）对「此处应属同一故障状态」一致，则提出回环因子 θ_k−θ_j=0。门控：若该因子与中间里程计链的预测不一致（χ²>χ²_thr）则拒绝或强降权——这防止感知歧义导致的**回环投毒**。回环通过后做鲁棒图优化，**目的不是确认「现在对」，而是修正「过去错」**。

**定义 238（追溯性重归因与只追加审计）** FLC 后重优化得过去关键帧的修订信念 θ_k⁺、h_k⁺。**已发证书不可改写**；修订只产生补偿动作：复检历史接触、把已加工件标记为可疑、触发零力窗重标定、更新 Σ_w。每次修订以 (audit_epoch, keyframe_id, old→new, evidence, reason) 追加进审计账本。非回溯不变式：**改信念，不改历史凭证**；`audit_epoch` 单调递增，任何证书都能被定位到其签发时的信念版本。

**定义 239（全局一致性与绑架检测 KBD）** 以交叉验证参考或物理不变量（已知质量、已知位姿的基准件、零力窗读数）作参照，计算
NEES_k = e_kᵀΣ_k⁻¹e_k，e_k=θ̂_k−θ_k^{ref}。
对一致估计，NEES_k 应近似 χ²_d。若连续 W 个关键帧 NEES_k>χ²_{d,1−α_nees}，判 `belief_lost=True`。**这是整套架构中唯一能不依赖教师、独立抓到「师生共因失效」的信号**（见定理 9 与最大风险）。

**定义 240（安全重定位）** `belief_lost` 时**不做归因**，执行安全重定位：回到已知锚点位姿 → `null_test`（自由空间零力读数，估计当前力偏置）→ 视觉已知地标/基准件核验（已知尺寸/位姿，估计几何偏移）→ 用新先验重置 FAM 并清零漂移 → 记录 `relocalization_event` 与新的 `audit_epoch`。若无法安全锚定（无基准件、空间受限、易损物体），则 `safe_idle` + 柔顺撤退。对应 SLAM 的 kidnapped-robot recovery：**迷路时最危险的动作是「假装没迷路继续走」。**

**定义 241（带回环增益的主动归因 AFA-LC）** 探针集 A={press,rub,tap,lift,visual_probe,null_test,revisit}，选择
a* = argmax_{a∈A} [ ΔH(FAM|a) + λ_lc·p_lc(a)·ΔH_lc(a) ]，
s.t. 预测 f_n≤f_safe(φ̂,f̂_vis)、预测形变≤ε_strain、支持视觉早停。
ΔH(FAM|a) 用边缘协方差的 D-最优近似（≈½log det(I+J_aΣ)）；p_lc(a) 为动作后命中可回环上下文的概率；ΔH_lc 为该回环可减少的图熵。即从第 65 轮「降低当前故障假设熵」升级为「**让整张故障图更可分辨 / 更可回环**」——Active SLAM 的安全对偶。

**定义 242（教师-学生蒸馏 TSD）** 教师 T（慢：FIR+FAM+VPG+conformal）与学生 S（快）。S 三头输出：p_S^τ(H|ρ,ctx)、log σ_S²（认知项，用多教师集成蒸馏得到）、abstain 分数（energy / max-margin）。损失
L = CE(p_T^τ, p_S^τ) + λ_u·U(σ_S², Var_T) + λ_a·L_abstain + λ_z·‖z_S−z_T‖²，
其中 U 对齐学生认知方差与教师集成方差，L_abstain 在「学生与教师不一致且学生自信」时惩罚。**学生被显式训练成「该弃权时弃权」，而非被迫给出一个 argmax。** VISTA 中隐含的「实时流只执行、不推理」被替换为「实时流做受限推理 + 会弃权」。

**定义 243（认证蒸馏差 CDG）** 上下文桶 b(x)=(故障类 × 阶段熵分位 × OOD energy 分位)。安全决策 δ∈{接收, 膨胀球, 升级, 停机}。决策分歧 d(x)=1[δ_S(x)≠δ_T(x)]。在标定集上对每桶取 Mondrian split-conformal 分位
q_b = ⌈(n_b+1)(1−α_d)⌉/n_b。
**可信桶**定义：q_b≤ε_d 且 n_b≥n_min（样本足够）。对桶内可交换新样本，P[d=1|b]≤α_d（有限样本修正后）。不可信桶一律升级教师或弃权。**注意 CDG 认证的是「师生是否分歧」，不是「教师是否正确」——这是刻意且必须写进证书的边界。**

**定义 244（升级策略）** 三档动作 {trust_student, query_teacher_async, hard_stop}，由 (q_b, 学生 margin, 剩余推测视界, 任务可逆性) 决定：
- 可信桶且 margin 足够且处于可逆区 → `trust_student`；
- 可信桶但处于不可逆区 → `query_teacher_async`（同步等待或退 k=1）；
- 不可信桶 / 学生弃权 / 教师否决 → 视可逆性 `query_teacher_async` 或 `hard_stop`。
无教师响应且硬实时到期时，按保守动作下降级（k=1 或停）。

**定义 245（猜测执行 SVE）** 设可逆视界 m_rev——可在不造成不可逆后果前停下/回滚的步数，m_rev≤m（m 为 VISTA 的不可逆视界）。学生起草长度 s 的前缀与归因；执行条件：
s ≤ min(H, m_rev) ∧ (教师已 ACK ∨ 处于可信桶)。
教师异步核验延迟 τ_T；若在 s 内否决或 CDG 违约 → 回滚到最近认证检查点 C_j 并重归因。**不可逆区不猜测**（s=1，同步教师或保守动作）。检查点 C_j 存最近一次 Valid(J_drift) 的控制状态与信念版本。

**定义 246（图一致球校准 RSC-M）** 由 FAM 边缘协方差导出
r_geo = √(κ·λ_max(Σ_geo)) + q_cdg,geo，r_force、r_model 同理，
其中 q_cdg,· 为该维度的 CDG 界。融合用协方差交叉
Σ_fuse = CI(Σ_a,Σ_b)，
替代 VISTA 的 r=√(r_geo²+r_force²+r_model²)。**好处：正确处理 r_geo/r_force/r_model 的相关性（同一物体可能同时影响几何与视觉），且膨胀量由数据驱动、可审计。**

**定义 247（AIC-D 蒸馏/漂移对抗认证）** 干扰集
ℰ_D = ℰ_V × ℰ_shift × ℰ_teacher × ℰ_loop × ℰ_gap，
ℰ_shift 为协变量/新物体漂移；ℰ_teacher 为教师系统性偏差注入（错误标定、错误先验）；ℰ_loop 为回环投毒 / 感知歧义；ℰ_gap 为容量差 / 量化 / 通信延迟。ρ_dir 在 ℰ_D 上重算（n_cert 128→160，其中 32 给漂移/教师/回环/容量）。**认证目标改变：不再要求「归因正确」，而要求「在共因失效 / 教师错误下仍能触发升级或安全停机」。** 显式建模：教师与学生共享训练数据，其误差**相关**，故 CDG 不能当作独立误差界。

**定义 248（J_drift 证书）** J_drift=(J_vista, fault_graph_hash, nees, consistency_ok, cdg_bounds, trusted_buckets, s*, relocalization_event, audit_epoch, aic_d_ver)。验证规则：
Valid(J_drift) ⇔ Valid(J_vista)
∧ (consistency_ok ∨ relocalization_event 已完成)
∧ (每个执行决策 ∈ trusted_buckets ∨ 已被教师同步认证)
∧ s*≤m_rev ∧ 所有回环过双通道门控
∧ 审计账本只追加且 `audit_epoch` 单调
∧ aic_d_ver 为当前版本。
审计链新增：为何信任这个学生（cdg_bounds / trusted_buckets）、为何只猜 s* 步（SVE）、过去哪个信念被修订过（audit_epoch）、系统是否曾经迷路（relocalization_event）。

## 3. 关键算法伪代码

### IP-224/IP-225/IP-226 FAM + FLC + KBD

```python
class FaultAttributionGraph:
    """关键帧因子图。语义流更新，输出边缘后验与协方差。"""
    def add_keyframe(self, phases, visual, ctx):
        k = self.new_node(phases, visual)          # 状态 x_k=(theta_k,h_k)
        self.add_prior(k, self.last_prior)
        self.add_odometry(k-1, k, dt=self.dt)      # 故障慢漂移
        self.add_signature(k, phases, visual)      # r_k = rho_k - S(x_k)
        return k

    def optimize_robust(self, max_iter=10):
        # switchable constraints 或 max-mixture；坏边 s_e -> 0
        for _ in range(max_iter):
            self.linearize()
            self.solve_sparse()
            self.update_switches()                 # s_e = sigmoid(-||r_e||^2/2sigma_s^2)
        return self.marginals(), self.nees()

    def loop_candidates(self, ctx):
        return [j for j, c in self.contexts.items()
                if np.linalg.norm(c - ctx) < TAU_CTX]

    def add_loop(self, k, j, evidence):
        if not two_channel_agree(evidence):        # 视觉 + 力
            return False
        if self.chi2_gate(k, j) > CHI2_THR:        # 与里程计链不一致
            return False
        self.add_factor(k, j, rel=np.zeros(d_H), info=OMEGA_LOOP)
        return True

    def retro_reattribute(self):
        """回环后修订过去信念；只产生补偿动作与审计条目。"""
        revisions = []
        for k in self.reoptimized_nodes():
            old = self.history[k]
            new = (self.theta[k], self.argmax_h(k))
            if not np.allclose(old, new, equal_nan=True):
                revisions.append((k, old, new, self.last_loop_evidence))
        return revisions

    def nees(self, ref=None):
        return {k: float(e.T @ np.linalg.inv(S) @ e)
                for k, (e, S) in self.residual_vs_ref(ref).items()}


class KidnappedBeliefDetector:
    def check(self, graph, W=3, alpha=0.01):
        bad = [k for k, v in graph.nees().items()
               if v > chi2.ppf(1 - alpha, graph.dim)]
        self.consecutive = self.consecutive + 1 if len(bad) >= W else 0
        return self.consecutive >= W                 # belief_lost

    def relocalize(self, robot, anchor):
        robot.goto_pose(anchor.pose)                 # 安全回锚点
        b_hat = robot.null_test()                    # 零力窗估偏置
        geo = robot.visual_landmark_check(anchor)    # 视觉已知地标
        if geo is None:
            return robot.safe_idle_and_retreat()
        return robot.reset_graph(prior=(b_hat, geo))
```

```python
class DistilledFaultMonitor:
    """学生三头：posterior / log-variance / abstain。"""
    def infer(self, rho, ctx):
        h = self.encoder(rho, ctx)
        p = softmax(self.head_post(h) / TAU)

class CertifiedDistillationGap:
    """Mondrian split-conformal on decision disagreement. 语义流标定。"""
    def calibrate(self, calib, student, teacher, buckets):
        self.q = {}
        for b, xs in group_by(buckets, calib).items():
            d = [int(decide(student(x)) != decide(teacher(x))) for x in xs]
            n = len(d)
            if n < self.n_min:
                self.q[b] = 1.0                    # 样本不足 -> 永不可信
            else:
                k = int(np.ceil((n + 1) * (1 - self.alpha_d)))
                self.q[b] = float(np.sort(d)[min(k, n) - 1])

    def trusted(self, bucket):
        return self.q.get(bucket, 1.0) <= self.eps_d
```

### IP-230 SVE（猜测执行 + 异步核验 + 回滚）

```python
class SpeculativeExecutor:
    def run(self, student, teacher, prefix, ctx, m_rev):
        p, var, abstain = student.infer(self.rho_now, ctx)
        b = self.bucket(ctx)
        trusted = self.cdg.trusted(b) and not abstain
        s_star = self.draft_horizon(p, var, trusted, len(prefix), m_rev)
        self.checkpoint()                          # C_j
        for i, a in enumerate(prefix[:s_star]):
            self.dispatch(a)
            if not trusted:
                self.teacher_async.verify(a, ctx)  # 异步对账
            verdict = self.teacher_async.poll(a)
            if verdict == 'reject' or self.monitor(a).abort:
                self.rollback()                    # 回到最近认证检查点
                self.request_reattribution()
                return 'rolled_back'
        return 'ok', s_star

    def draft_horizon(self, p, var, trusted, H, m_rev):
        if not trusted:
            return 1 if self.reversible else 0     # 不可逆区不猜
        # 认知方差越大 / margin 越小，越保守
        margin = p.max() - np.sort(p)[-2]
        s = int(np.clip(np.floor(margin / (var.mean() + 1e-9)), 1, H))
        return min(s, m_rev)
```

```python
def rsc_m_compile(graph, post, f_lim, cdg, n_worst=8, eps=0.05):
    radii = {}
    for name in ('geo', 'force', 'model'):
        S = graph.marginal_cov(name)
        radii[name] = np.sqrt(KAPPA * np.linalg.eigvalsh(S).max()) + cdg.bound(name)
    # 用协方差交叉融合，而非独立球相加
    Sigma_fuse = cov_intersection(
        graph.marginal_cov('geo'), graph.marginal_cov('force'))
    candidates = []
    for _ in range(n_worst):
        H = sample_from(post)
        phi_c = sample_consistent(radii, Sigma_fuse, H, f_lim)
        if phi_c is None:
            return None, -np.inf, True             # attribution_conflict
        candidates.append(phi_c)
    return intersect_shrink(candidates), min_margin(candidates), False
```

## 4. 推导

**引理 9（鲁棒故障图不被有界坏边腐蚀）** 考虑定义 234–235 的 MAP 问题，代价为截断最小二乘 / switchable constraints，其影响函数有界（红降 M-估计器）。设内点边集合 E_in 连通、其信息矩阵最小特征值 λ_min⁺>0，坏边数 m_out、截断阈值 c。由鲁棒位姿图的标准 breakdown 分析，最优估计满足
‖θ̂−θ*‖ ≤ (2c√(m_out))/λ_min⁺ + O(σ_noise)，
且坏边对应的开关变量 s_e→0。故只要坏边比例低于 breakdown point，估计不被腐蚀；回环的错误影响被局部化为「一条被关掉的边 + 一条审计记录」，而非整图污染。∎
**要点**：VISTA 的不可辨识（第 65 轮引理 7）说的是「未知故障无法被分配」；引理 9 补上「无法分配时可以不分配」，两件事并不矛盾——前者限制**可辨识性**，后者保证**不因不可辨识而中毒**。

**引理 10（学生委托的可证误差）** 在桶 b 内假设样本可交换。Mondrian split-conformal 用标定集非一致性分数 d_i∈{0,1} 取 q_b=⌈(n_b+1)(1−α_d)⌉/n_b 分位。由 conformal 的有限样本覆盖定理，对新样本 P[d(x)>q_b]≤α_d；若 q_b=0（标定集内全一致）则 P[d=1]≤1/(n_b+1)，当 n_b≥1/α_d−1 时 ≤α_d。结合 SVE：只有可信桶（q_b≤ε_d）或教师已 ACK 的决策被执行，且 s*≤m_rev、失败可回滚到认证检查点。由联合界，蒸馏引入的额外越界风险 ≤ α_d+α_rollback+α_stop。∎
**边界（必须写进证书）**：该界只约束「学生与教师分歧」，不约束「教师本身错误」。故引理 10 不能替代定义 239 的独立一致性检验。

**定理 9（DRIFT 端到端可修订-安全）** 在 A94–A98 下：
1. **信念可修**：FLC 通过双通道门控时，鲁棒优化使错误归因被追溯修正（引理 9、定义 238），且只产生补偿动作与只追加审计，不改写历史证书。
2. **迷路可恢复**：KBD 以独立于教师的 NEES 触发 `belief_lost`，安全重定位重锚定，避免 A88 的「强行归因」。
3. **委托可证**：可信桶内学生决策的师生分歧 ≤α_d（引理 10）；不可信桶一律升级/弃权。
4. **执行不越界**：SVE 仅在 s*≤m_rev 内猜测，教师否决即回滚到认证检查点；不可逆区 s=1（定义 245）。
5. **证书完整**：Valid(J_drift) ⇒ Valid(J_vista) ∧ 一致性/重定位 ∧ 委托有界 ∧ 审计只追加（定义 248）。
6. **优雅降级**：学生失效→升级教师；教师延迟→硬实时保守动作；图不一致→重定位；无法重定位→`safe_idle`+柔顺撤退。
7. **实时性**：学生 <0.1ms、CDG <0.02ms、SVE <0.08ms，实时路径 ≤2.5ms（A99）。∎
**诚实缺口**：若教师系统性错误且与学生共享同一失效源，则第 3 条的分歧界不报警，第 2 条的独立一致性是唯一兜底；若独立参照也缺失，定理 9 不成立（见第 7 节）。

**定理 10（猜测执行的速度-安全折中）** 设学生单步耗时 c_S、教师延迟 τ_T、长度 s 的前缀被教师接受的期望概率 p_acc(s)（随 s 递减，因长前缀更易偏离教师）。期望延迟
E[L(s)] = s·c_S + (1−p_acc(s))·(τ_T + c_rollback)，
期望风险
R(s) = c_risk·1[s>m_rev] + α_d·(1−p_acc(s)) + α_stop。
目标 max_s E[L(0)]−E[L(s)] − λ·R(s)。对 s≤m_rev 风险项主要为 α_d(1−p_acc)，随 s 缓增；对 s>m_rev 风险跃升 c_risk。故最优
s* = min( H, m_rev, argmax_{s≤m_rev}[s·(E[L(0)]/H − c_S) − λ α_d(1−p_acc(s))] )。
**结论：可逆区尽量猜、不可逆区必须同步**——这是第 65 轮「长预测、短执行」在双估计器结构下的推广。∎

**命题（可修订性破除固化）** VISTA 的一次性错误若之后无新证据，概率 1 永久保留（FIR 无记忆）。DRIFT 下，若相邻关键帧发生可回环重访的概率为 λ_lc，则错误信念存续的关键帧数 T∼Geom(λ_lc)，E[T]=1/λ_lc；且修正不改写历史证书，只追加补偿动作。故「错误可被修」的代价是额外的审计与补偿开销，而非安全性回退。∎

**命题（球体积与协方差一致）** VISTA 对任意拒绝把单一 r 膨胀 κ_infl 倍，几何搜索域体积膨胀 κ_infl^{d_φ}（与故障源无关）。RSC-M 由边缘协方差导出 r_i，只膨胀真实相关的分量，且用协方差交叉处理相关性：若 r_geo/r_force 完全相关，CI 不比独立相加更保守；若独立，CI 反而更紧。故 E248 预测球体积下降而覆盖率不降。∎

## 7. 已知风险

**一句话**：DRIFT 的自我修正能力被一个隐藏的循环依赖绑死——**学生由教师蒸馏而来、回环与一致性又都以教师产出的故障地图为参照；当教师本身系统性错误（或师生共享同一个分布外失效源）时，CDG 只会证明「学生像教师」，回环会把一个错误信念优化成一张全局自洽的错误地图，于是系统不仅不会被纠正，反而会因为「图一致、师生一致、审计完整」而更自信**——这是全部可修订性与认证委托论证共同依赖的隐藏假设（A95：教师是更强的独立参照）。

**次级风险与缓解**：
1. **师生共因失效（最大风险的具体化）**：蒸馏使学生误差与教师相关，CDG 不覆盖；缓解：保留独立物理一致性通道（零力窗、已知基准件、IMU/本体感觉）、KBD 的 NEES 不依赖教师标签、AIC-D 显式注入教师偏差并要求升级；无法重定位时 `safe_idle`。
2. **回环投毒 / 感知歧义**：透明/重复纹理/对抗 patch 可制造假回环；缓解：双通道门控 + 卡方一致性 + 鲁棒代价 breakdown point，并把每次回环写入审计以供事后追责。
3. **Mondrian 桶稀疏 → 过度升级**：小样本桶被永久标为不可信，导致可用性下降；缓解：分层桶（先粗后细）、层级 conformal、把「不可信」显式暴露给上层规划而非静默硬停。
4. **图规模与延迟增长**：长期运行 K 增大；缓解：滑动窗口 + 边缘化 + 把旧子图蒸馏/压缩成先验（map compression），只在语义流做。
5. **追溯修订与责任/审计冲突**：改写过去信念可能引发合规问题；缓解：只追加审计、证书版本化、修订必须附证据与补偿动作，不删除旧记录。
6. **蒸馏容量差与漂移**：学生在大漂移下退化；缓解：漂移检测触发重标定与重新蒸馏、学生置信低于阈值即弃权。
7. **可逆视界可能为 0**：接触后形变/装配等不可逆阶段无猜测空间；缓解：不可逆区强制同步教师或保守 k=1，接受延迟。
8. **重定位需要安全锚点**：野外可能无已知基准件；缓解：无锚点不变量（质量/重力方向/自由度约束）+ 主动寻找安全锚点，否则停机。
9. **conformal 可交换性被破坏**：在线非平稳使覆盖失准；缓解：加权/在线 conformal + 分桶重标定 + 漂移告警。
