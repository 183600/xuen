# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC：IP-153~160；灵感循环第 7 轮；本轮灵感：「产学研合作」×「轨迹优化」）

> 第 60 轮的 SGEC 把「场景→意图→约束→阻抗→执行→证据」闭了起来，但**轨迹始终是缺席的**：SSM 只把场景编译成阻抗先验 $\pi_{scene}(K|z)$，CIEC 只把意图映射成阻抗/速度约束，CESC 只在安全集交集中挑一个 $K_{safe}$；所谓 $\varepsilon_{traj}$ 仅是一个约束符号，系统从未真正求解一条轨迹。于是留下三个结构性缺口：
> 1. **轨迹级安全缺位**：阻抗安全不等于轨迹安全。即使 $K_{safe}$ 收敛正确，速度/加速度/奇异位形/自碰撞仍可能让轨迹在两点之间失效；「接触点安全、连线路径危险」是第 60 轮无法表达的风险。
> 2. **知识孤岛与产学研鸿沟**：场景先验、意图映射、阻抗参数都由单一机构在本地累积。高校有理论证书却缺现场数据，企业有海量执行轨迹却缺泛化保证，研究院有基准场景却缺部署反馈。原始数据因隐私、知识产权与责任边界不可直接共享，导致**实验室最优轨迹到产线不可用**——这正是「产学研合作」要跨越的死亡之谷。
> 3. **多主体责任不可分配**：第 60 轮的 $J_{exec}$ 是单方签发的执行证书；当轨迹由高校模型、企业数据、研究院基准共同决定时，一旦失效，**谁贡献了多少、谁该担多少责**无从归因；没有契约，就没有可持续的跨机构协作。

## 0. 直觉与动机

**灵感 1（产学研合作 → 多主体契约化轨迹优化）**
直觉：产学研合作本质上不是「一起写论文」，而是**多个目标不同、数据不同、风险偏好不同的主体，围绕同一个决策变量（轨迹）达成可执行的契约**。高校 $U$ 关心平滑性、能量与理论可证；企业 $I$ 关心节拍、吞吐与产线安全；研究院 $R$ 关心跨场景泛化与基准可复现。把这三方建模为轨迹优化问题里的**目标权重、约束集与私有数据分布**，合作就变成「在约束交集里最小化加权风险，并按贡献分配合作剩余」。关键洞见：**不共享数据也能共享轨迹知识**——交换轨迹片段与对偶变量即可，原始样本不出域。

**灵感 2（轨迹优化 → 显式轨迹取代隐式 $\varepsilon_{traj}$）**
直觉：第 60 轮把安全压进一个静态阻抗矩阵，这是「点安全」；轨迹优化关心的是「线安全」。给定场景先验给出的 $K_{safe}^{scene}$，把它当作**可行流形**，在其内用约束序列凸规划（SCP）/iLQR 生成显式轨迹 $\xi=\{q_k,\dot q_k,\ddot q_k\}_{k=0}^{T-1}$。场景先验不再是终点，而变成**轨迹先验** $\xi_{prior}$；CIEC 的意图约束也不再只改阻抗，而变成**时变轨迹约束**（如「慢点」= 速度上限随时间收紧）。关键洞见：**阻抗是轨迹的边界条件，轨迹是阻抗的时间展开**。

**灵感 3（信任加权分布鲁棒 → 产学研数据的可信度差异）**
直觉：高校仿真数据、企业现场数据、研究院基准数据的可信度 $\tau_p$ 不同，且目标域与源域存在分布偏移。用**信任加权分布鲁棒优化（TW-DRTO）**：可信度越低，Wasserstein 模糊集半径越大，优化越保守。$\varepsilon_p=\varepsilon_0/\tau_p$。关键洞见：**信任不是一句口号，而是可以直接写进约束半径的数值**。

**灵感 4（迁移安全证书 → 死亡之谷的可证跨越）**
直觉：产学研合作最怕「实验室里 cert 很漂亮，产线上第一次跑就撞」。需要一张**迁移安全证书 TSC**：用源域经验风险 + Lipschitz×Wasserstein 距离 + PAC-Bayes 泛化项，给出目标域风险的**上界**；上界不超过 $J_{max}$ 才允许部署。关键洞见：**证书不是「我相信它能迁移」，而是「我能给出迁移后仍安全的概率上界」**。

**灵感 5（合作剩余博弈 → 多主体责任归因）**
直觉：合作只有在**个体理性**（每方收益 ≥ 单独干）与**激励相容**（诚实共享知识最优）下才稳定。用 Shapley 值分合作剩余保证公平，用 VCG 外部性支付保证真实共享；失效时用**反向 Shapley** 把风险增量归因到各方——这就是产学研的「责任账本」。关键洞见：**公平分配与责任归因是同一套边际贡献计算的正反两面**。

**灵感 6（五者合流 → 产学研协同轨迹优化闭环 IUR-Loop）**
直觉：SSM 给场景 $z$ 与 $K_{safe}^{scene}$ → 各主体本地 SCP 生成 $\xi_p$ → FedSCP 只交换带差分隐私噪声的轨迹副本与对偶变量完成共识 → TW-DRTO 按信任鲁棒化 → TSC 给迁移证书 → 执行并写 EPIR 证据 → CSE 结算合作剩余与责任。闭环为：**场景→本地轨迹→联邦共识→鲁棒化→迁移认证→执行证据→贡献结算→知识更新**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（产学研协同轨迹优化问题 IUR-CTO）**
设参与主体集合 $P=\{U,I,R\}$（高校/企业/研究院），轨迹 $\xi=\{q_k,\dot q_k,\ddot q_k\}_{k=0}^{T-1}$，主体 $p$ 的私有数据 $D_p\sim\mathcal{P}_p$、风险 $R_p(\xi)=\mathbb{E}_{x\sim D_p}[f_p(\xi;x)]$、约束集 $\mathcal{C}_p$、合作权重 $w_p$、可信度 $\tau_p\in(0,1]$。协同问题为
$$\min_{\xi}\ F(\xi)=\sum_{p\in P}w_p R_p(\xi)\quad \text{s.t.}\ \xi\in\mathcal{C}_{joint}=\bigcap_{p\in P}\mathcal{C}_p,\ \ \text{且原始 } D_p \text{ 不出域}.$$
三类目标异质：$f_U$ 为平滑/能量/可证性，$f_I$ 为节拍/吞吐/产线安全，$f_R$ 为跨场景泛化/基准可复现。约束含关节限位、速度/加速度、力矩、自碰撞、环境碰撞、CIEC 接触力上限与 $K\in\mathcal{K}_{safe}^{scene}$。

**定义 162（知识贡献契约 KCC）**
契约 $\pi=(w,\mathcal{M}_{ex},\phi)$：$w=(w_p)$ 为权重；$\mathcal{M}_{ex}$ 为知识交换协议（只交换 DP 轨迹副本 $\tilde\xi_p$ 与对偶变量 $\tilde u_p$）；$\phi=(\phi_p)$ 为合作剩余分配。契约须满足：
- **个体理性 IR**：$u_p=\phi_p-c_p\ge 0$（$c_p$ 为参与成本）；
- **激励相容 IC**：诚实上报本地最优 $\xi_p^\*$ 与真实可信度 $\tau_p$ 使 $u_p$ 最大；
- **隐私预算**：交换量满足 $(\varepsilon_{dp},\delta_{dp})$-差分隐私。

**定义 163（信任加权分布鲁棒轨迹优化 TW-DRTO）**
主体 $p$ 的模糊集 $\mathcal{A}_p(\tau_p)=\{Q: W_1(Q,\hat{\mathcal{P}}_p)\le \varepsilon_0/\tau_p\}$。鲁棒问题
$$\min_{\xi}\ \max_{Q_p\in\mathcal{A}_p(\tau_p)}\sum_p w_p\,\mathbb{E}_{Q_p}[f_p(\xi)]\quad\text{s.t.}\ \ \sup_{Q_p\in\mathcal{A}_p}\mathbb{E}_{Q_p}[g_p(\xi)]\le 0,\ \forall p.$$
若 $f_p$ 关于轨迹 $L_f$-Lipschitz、$g_p$ 关于轨迹 $L_g$-Lipschitz，则可用闭式上界
$$\sup_{Q_p\in\mathcal{A}_p}\mathbb{E}_{Q_p}[f_p]\le \hat{R}_p(\xi)+L_f\cdot\frac{\varepsilon_0}{\tau_p},$$
约束用 $\mathrm{CVaR}_\alpha$ 的鲁棒版本 $\widehat{\mathrm{CVaR}}_\alpha(g_p)+L_g\varepsilon_0/\tau_p\le 0$ 近似。**可信度越低，鲁棒半径越大，轨迹越保守**。

**定义 164（联邦序列凸轨迹优化 FedSCP）**
以 ADMM 共识 + SCP 局部凸化求解定义 161：
- 本地步：$\xi_p^{k+1}=\arg\min_{\xi\in\mathcal{C}_p,\ \|\xi-\xi^k\|_\infty\le\Delta_p}\ \hat{f}_p(\xi)+\frac{\rho}{2}\|\xi-\xi^k+u_p^k\|_2^2$，其中 $\hat f_p$ 为在 $\xi^k$ 处 Gauss-Newton 凸化；
- 共识步：$\xi^{k+1}=\dfrac{\sum_p w_p(\tilde\xi_p^{k+1}+\tilde u_p^k)}{\sum_p w_p}$；
- 对偶步：$u_p^{k+1}=u_p^k+\xi_p^{k+1}-\xi^{k+1}$；
- 交换步：仅上传 $\tilde\xi_p=\xi_p+\mathrm{Lap}(\Delta_p/\varepsilon_{dp})$、$\tilde u_p=u_p+\mathrm{Lap}(\Delta_u/\varepsilon_{dp})$。
收敛判据 $\|\xi^{k+1}-\xi^k\|_2\le\epsilon_{adm}$。

**定义 165（知识蒸馏轨迹先验 KTTP）**
各主体本地最优 $\xi_p^\*$ 与局部代价 Hessian（知识曲率）$H_p=\nabla^2\hat f_p(\xi_p^\*)$。全局轨迹先验
$$\xi_{prior}=\arg\min_{\xi}\ \sum_p \alpha_p\cdot\frac12(\xi-\xi_p^\*)^\top H_p(\xi-\xi_p^\*)+\lambda R_{smooth}(\xi),\quad \alpha_p=\frac{\tau_p}{\sigma_p^2+\lambda_{reg}},$$
其中 $\sigma_p^2$ 为本地代价方差。$\xi_{prior}$ 不含任何原始样本，只含「最优点 + 曲率 + 可信度」，实现**可迁移的知识蒸馏**。

**定义 166（迁移安全证书 TSC）**
源域经验分布 $\hat{\mathcal{P}}_U$、目标域 $\hat{\mathcal{P}}_I$，损失 $f$ 有界且 $L_f$-Lipschitz，后验 $Q$、先验 $P$、样本数 $n$。以置信度 $1-\delta$：
$$R_{\mathcal{P}_I}(\xi)\le \hat{R}_{\mathcal{P}_U}(\xi)+L_f\,W_1(\hat{\mathcal{P}}_U,\hat{\mathcal{P}}_I)+\sqrt{\frac{\mathrm{KL}(Q\|P)+\ln(2/\delta)}{2n}}=:B_{TSC}(\xi,\delta).$$
**证书有效** $\mathrm{Cert}_{transfer}(\xi)=1$ 当且仅当 $B_{TSC}(\xi,\delta)\le J_{max}$ 且 $\xi\in\mathcal{C}_I$（目标域约束）。约束迁移同理用 $L_g W_1$ 修正。

**定义 167（合作剩余均衡 CSE）**
联盟价值 $v(S)=\bar{J}_{local}-J_{robust}(S)$，即联盟 $S$ 共享知识相对于各自单干的鲁棒代价改善。Shapley 分配
$$\phi_p=\sum_{S\subseteq P\setminus\{p\}}\frac{|S|!\,(|P|-|S|-1)!}{|P|!}\big[v(S\cup\{p\})-v(S)\big].$$
VCG 外部性支付 $t_p=\sum_{q\ne p}\big[v_q(P\setminus\{p\})-v_q(P)\big]$，净收益 $u_p=\phi_p-t_p$。**责任归因**用反向 Shapley：以「失效概率增量」为价值函数 $\hat v_{fail}(S)$，得到各方边际风险贡献 $\psi_p$。IR/IC 任一不满足则联盟不成立，回退到本地保守轨迹。

**定义 168（轨迹-证据-契约三元组 TEC 与 IUR-Loop）**
$\mathrm{TEC}=(\xi,\,EV_{exec},\,\mathcal{C}_{collab},\,\mathrm{Cert}_{transfer})$，其中
$$\mathrm{TEC}_{valid}=\underbrace{[\xi\in\mathcal{C}_{joint}]}_{轨迹可行}\wedge\underbrace{[\text{EPIR 证据链完整}]}_{第60轮}\wedge\underbrace{[\text{Shapley/VCG 已结算且 IR/IC}]}_{契约}\wedge\underbrace{[\mathrm{Cert}_{transfer}=1]}_{迁移}\wedge\underbrace{[\mathrm{SIC}_{valid}]}_{第60轮}.$$
IUR-Loop 算子：
```
① SSM: z_scene, K_safe^scene ← SSM.update_and_compile(scene_obs)      # 承接第60轮
② Seed: ξ0 ← SERC.seed(K_safe^scene); ξ0 ← CIEC.project(ξ0, intent)     # 意图→时变约束
③ Local: 对每个 p∈P: ξ_p ← p.local_scp(ξ0, Δ_p)                        # 私有数据本地求解
④ FedSCP: ξ_cons ← ADMM({(ξ_p, u_p, w_p, τ_p)})                        # 只交换 DP 轨迹/对偶
⑤ Robust: ξ_rob ← TW-DRTO(ξ_cons, {τ_p}, {ε0})                         # 信任加权鲁棒化
⑥ Certify: (ok, Cert_transfer) ← TSC(ξ_rob, source=federation, target=I)
⑦ Execute: EV_exec ← run_and_log(ξ_rob, EPIR)                          # 承接第60轮证据链
⑧ Settle: φ ← Shapley(v); t ← VCG(v); ψ ← ReverseShapley(v_fail)        # 剩余+责任
⑨ Update: knowledge ← KTTP({ξ_p*}, {H_p}, {τ_p}); 返回 TEC
⑩ if not TEC_valid: ξ_rob ← I.local_conservative(); goto ⑦
```

### IP-161/164 IUR-CTO 与 FedSCP

```python
class PartyTrajectoryOptimizer:
    def __init__(self, party_id, cost, constraints, w, trust, eps0, dp_eps):
        self.id, self.cost, self.constraints = party_id, cost, constraints
        self.w, self.trust, self.eps0, self.dp_eps = w, trust, eps0, dp_eps
        self.trust_region = 0.2

    def local_scp(self, xi_ref, n_iter=8):
        xi = xi_ref.copy()
        for _ in range(n_iter):
            H, g = self.cost.gauss_newton(xi)
            A, b = self.constraints.linearize(xi)
            # 置信域 |δ|∞ ≤ Δ 写成两组线性不等式
            A = np.vstack([A, np.eye(xi.size), -np.eye(xi.size)])
            b = np.concatenate([b,
                                self.trust_region - xi,
                                self.trust_region + xi])
            d = solve_qp(H + 1e-6*np.eye(xi.size), g, A, b)
            xi = xi + d
            if np.linalg.norm(d) < 1e-5:
                break
        return xi


class FederatedTrajectoryOptimizer:
    def __init__(self, parties, rho=1.0, adm_tol=1e-4, max_iter=60):
        self.parties, self.rho = parties, rho
        self.adm_tol, self.max_iter = adm_tol, max_iter

    def _dp(self, vec, sensitivity, eps):
        scale = sensitivity / max(eps, 1e-9)
        return vec + np.random.laplace(0.0, scale, size=vec.shape)

    def solve(self, xi0, coalition=None):
        ps = coalition or self.parties
        xi = xi0.copy()
        u = {p.id: np.zeros_like(xi) for p in ps}
        for _ in range(self.max_iter):
            new_xi, shared = {}, {}
            for p in ps:
                local = p.local_scp(xi - u[p.id])
                new_xi[p.id] = local
                shared[p.id] = (self._dp(local, p.trust_region, p.dp_eps),
                                self._dp(u[p.id], p.trust_region, p.dp_eps))
            wsum = sum(p.w for p in ps)
            xi_next = sum(p.w * (shared[p.id][0] + shared[p.id][1])
                          for p in ps) / wsum
            for p in ps:
                u[p.id] = u[p.id] + new_xi[p.id] - xi_next
            if np.linalg.norm(xi_next - xi) <= self.adm_tol:
                xi = xi_next
                break
            xi = xi_next
        return xi
```

### IP-163 TW-DRTO（信任加权鲁棒化）

```python
def trust_weighted_drto(xi, parties, alpha=0.95):
    robust = xi.copy()
    for p in parties:
        L_f = p.cost.lipschitz()
        L_g = p.constraints.lipschitz()
        radius = p.eps0 / max(p.trust, 1e-6)     # τ 越低 → 半径越大
        # 目标侧：经验风险 + Lipschitz×Wasserstein 闭式上界
        p.robust_risk = p.cost.empirical(robust) + L_f * radius
        # 约束侧：鲁棒 CVaR
        p.robust_cvar = empirical_cvar(
            [p.constraints.value(robust + d) for d in p.perturbations],
            alpha) + L_g * radius
    for _ in range(10):
        active = [p for p in parties if p.robust_cvar > 0]
        if not active:
            break
        robust = project_to_intersection(robust, [p.constraints for p in active])
    return robust
```

### IP-166 TSC（迁移安全证书）

```python
def transfer_safety_certificate(xi, source, target, J_max, delta=0.05):
    emp = source.cost.empirical(xi)
    w1 = wasserstein1(source.feature_samples(), target.feature_samples())
    L_f = source.cost.lipschitz()
    gen = np.sqrt((source.kl_divergence + np.log(2.0 / delta))
                  / (2.0 * source.n_samples))
    upper = emp + L_f * w1 + gen
    feasible = target.constraints.is_feasible(xi)
    cert = bool(upper <= J_max and feasible)
    return cert, {
        "risk_upper": upper, "empirical": emp,
        "domain_gap": L_f * w1, "generalization": gen,
        "feasible": feasible,
    }
```

### IP-167 CSE（合作剩余与责任归因）

```python
def coalition_value(S, federation, baseline):
    if not S:
        return 0.0
    xi_S = federation.solve(federation.xi0, coalition=list(S))
    return baseline - federation.robust_cost(xi_S)


def shapley_values(parties, v):
    M, phi = len(parties), {p.id: 0.0 for p in parties}
    ids = [p.id for p in parties]
    for pid in ids:
        others = [q for q in ids if q != pid]
        for r in range(len(others) + 1):
            for S in combinations(others, r):
                coef = factorial(r) * factorial(M - r - 1) / factorial(M)
                Sset = set(S)
                phi[pid] += coef * (v(Sset | {pid}) - v(Sset))
    return phi


def marginal(q, S, v):
    return v(S) - v(S - {q})


def vcg_payment(pid, parties, v):
    ids = [p.id for p in parties]
    P, others = set(ids), set(ids) - {pid}
    # p 的参与对他人边际贡献的外部性：正值为收费，负值为补贴
    return sum(marginal(q, others, v) - marginal(q, P, v) for q in others)


def reverse_shapley_attribution(parties, failure_prob):
    # 与 shapley_values 同构，仅把价值函数换成「失效概率增量」
    return shapley_values(parties, failure_prob)
```

### IP-168 IUR-Loop（端到端闭环）

```python
def iur_collaborative_loop(M, scene_obs, intent, parties, target):
    # ①-② 承接第60轮：场景→阻抗，意图→时变约束，生成轨迹种子
    z_scene, K_safe_scene = M.ssm.update_and_compile(scene_obs)
    xi0 = M.serc.seed_trajectory(K_safe_scene)
    xi0 = M.ciec.project_temporal_constraints(xi0, intent)

    # ③-⑤ 联邦本地求解 → 共识 → 信任加权鲁棒化
    fed = FederatedTrajectoryOptimizer(parties)
    fed.xi0 = xi0
    xi_cons = fed.solve(xi0)
    xi_rob = trust_weighted_drto(xi_cons, parties)

    # ⑥ 迁移安全证书
    ok, cert = transfer_safety_certificate(
        xi_rob, source=parties[0], target=target, J_max=M.J_max)

    # ⑦ 执行 + EPIR 证据链（承接第60轮）
    if not ok:
        xi_rob = target.local_conservative(xi_rob)
    ev_exec = execute_and_log(xi_rob, M.epir)

    # ⑧ 合作剩余 + 责任归因
    base = M.baseline_robust_cost
    v = lambda S: coalition_value(S, fed, base)
    phi = shapley_values(parties, v)
    fees = {p.id: vcg_payment(p.id, parties, v) for p in parties}
    psi = reverse_shapley_attribution(
        parties, lambda S: M.failure_prob(S))

    # ⑨ 知识蒸馏更新 + TEC 校验
    prior = kttp_update({p.id: p.last_opt for p in parties},
                        {p.id: p.last_hessian for p in parties},
                        {p.id: p.trust for p in parties})
    M.knowledge.update(prior)
    tec = {
        "trajectory": xi_rob, "evidence": ev_exec,
        "contract": {"shapley": phi, "vcg": fees, "risk_attr": psi},
        "transfer": cert, "valid": ok,
    }
    return tec
```

## 3. 复杂度与正确性

**正确性定理（IUR-CTO）**：假设 A66–A70 成立。

1. **轨迹可行性**：$\xi_{rob}\in\mathcal{C}_{joint}$ 的概率 $\ge 1-\delta_g$（由鲁棒 CVaR 保证）。
2. **隐私性**：任意单主体原始数据对联邦轨迹的影响被 $(\varepsilon_{dp},\delta_{dp})$-DP 限制。
3. **迁移有效性**：$\mathrm{Cert}_{transfer}=1\Rightarrow R_{\mathcal{P}_I}(\xi_{rob})\le J_{max}$ 以 $1-\delta$ 成立。
4. **合作稳定性**：$u_p\ge 0\ \forall p$（IR）且诚实共享使 $u_p$ 最大（IC）时联盟不瓦解。
5. **责任可归因**：反向 Shapley 给出唯一满足有效性/对称性/零贡献零归因的风险分摊 $\psi$。

### IP-161/164 IUR-CTO 与 FedSCP

```python
class PartyTrajectoryOptimizer:
    def __init__(self, party_id, cost, constraints, w, trust, eps0, dp_eps):
        self.id, self.cost, self.constraints = party_id, cost, constraints
        self.w, self.trust, self.eps0, self.dp_eps = w, trust, eps0, dp_eps
        self.trust_region = 0.2

    def local_scp(self, xi_ref, n_iter=8):
        xi = xi_ref.copy()
        for _ in range(n_iter):
            H, g = self.cost.gauss_newton(xi)
            A, b = self.constraints.linearize(xi)
            A = np.vstack([A, np.eye(xi.size), -np.eye(xi.size)])
            b = np.concatenate([b,
                                self.trust_region - xi,
                                self.trust_region + xi])
            d = solve_qp(H + 1e-6*np.eye(xi.size), g, A, b)
            xi = xi + d
            if np.linalg.norm(d) < 1e-5:
                break
        return xi


class FederatedTrajectoryOptimizer:
    def __init__(self, parties, rho=1.0, adm_tol=1e-4, max_iter=60):
        self.parties, self.rho = parties, rho
        self.adm_tol, self.max_iter = adm_tol, max_iter
        self.xi0 = None

    def _dp(self, vec, sensitivity, eps):
        scale = sensitivity / max(eps, 1e-9)
        return vec + np.random.laplace(0.0, scale, size=vec.shape)

    def solve(self, xi0, coalition=None):
        ps = coalition or self.parties
        xi = xi0.copy()
        u = {p.id: np.zeros_like(xi) for p in ps}
        for _ in range(self.max_iter):
            new_xi, shared = {}, {}
            for p in ps:
                local = p.local_scp(xi - u[p.id])
                new_xi[p.id] = local
                shared[p.id] = (self._dp(local, p.trust_region, p.dp_eps),
                                self._dp(u[p.id], p.trust_region, p.dp_eps))
            wsum = sum(p.w for p in ps)
            xi_next = sum(p.w * (shared[p.id][0] + shared[p.id][1])
                          for p in ps) / wsum
            for p in ps:
                u[p.id] = u[p.id] + new_xi[p.id] - xi_next
            if np.linalg.norm(xi_next - xi) <= self.adm_tol:
                xi = xi_next
                break
            xi = xi_next
        return xi
```

### IP-163 TW-DRTO（信任加权鲁棒化）

```python
def trust_weighted_drto(xi, parties, alpha=0.95):
    robust = xi.copy()
    for p in parties:
        L_f = p.cost.lipschitz()
        L_g = p.constraints.lipschitz()
        radius = p.eps0 / max(p.trust, 1e-6)     # τ 越低 → 半径越大
        p.robust_risk = p.cost.empirical(robust) + L_f * radius
        p.robust_cvar = empirical_cvar(
            [p.constraints.value(robust + d) for d in p.perturbations],
            alpha) + L_g * radius
    for _ in range(10):
        active = [p for p in parties if p.robust_cvar > 0]
        if not active:
            break
        robust = project_to_intersection(robust, [p.constraints for p in active])
    return robust
```

### IP-165 KTTP（知识蒸馏轨迹先验）

```python
def kttp_update(local_opt, local_hessian, trust, lam=1e-2, reg=1e-3):
    alpha = {i: trust[i] / (local_hessian[i].var() + reg) for i in trust}
    z = sum(alpha.values())
    # 闭式解：加权曲率度量的重心，等价于一次 Newton 型知识平均
    H_sum = sum(alpha[i] * local_hessian[i] for i in alpha) + lam*np.eye(n)
    b_sum = sum(alpha[i] * local_hessian[i] @ local_opt[i] for i in alpha)
    return np.linalg.solve(H_sum, b_sum)
```

### IP-166 TSC（迁移安全证书）

```python
def transfer_safety_certificate(xi, source, target, J_max, delta=0.05):
    emp = source.cost.empirical(xi)
    w1 = wasserstein1(source.feature_samples(), target.feature_samples())
    L_f = source.cost.lipschitz()
    gen = np.sqrt((source.kl_divergence + np.log(2.0 / delta))
                  / (2.0 * source.n_samples))
    upper = emp + L_f * w1 + gen
    feasible = target.constraints.is_feasible(xi)
    cert = bool(upper <= J_max and feasible)
    return cert, {
        "risk_upper": upper, "empirical": emp,
        "domain_gap": L_f * w1, "generalization": gen,
        "feasible": feasible,
    }
```

### IP-167 CSE（合作剩余与责任归因）

```python
def coalition_value(S, federation, baseline):
    if not S:
        return 0.0
    xi_S = federation.solve(federation.xi0, coalition=list(S))
    return baseline - federation.robust_cost(xi_S)


def shapley_values(parties, v):
    M, phi = len(parties), {p.id: 0.0 for p in parties}
    ids = [p.id for p in parties]
    for pid in ids:
        others = [q for q in ids if q != pid]
        for r in range(len(others) + 1):
            for S in combinations(others, r):
                coef = factorial(r) * factorial(M - r - 1) / factorial(M)
                Sset = set(S)
                phi[pid] += coef * (v(Sset | {pid}) - v(Sset))
    return phi


def marginal(q, S, v):
    return v(S) - v(S - {q})


def vcg_payment(pid, parties, v):
    ids = [p.id for p in parties]
    P, others = set(ids), set(ids) - {pid}
    # p 的参与对他人边际贡献的外部性：正值为收费，负值为补贴
    return sum(marginal(q, others, v) - marginal(q, P, v) for q in others)


def reverse_shapley_attribution(parties, failure_prob):
    # 与 shapley_values 同构，仅把价值函数换成「失效概率增量」
    return shapley_values(parties, failure_prob)
```

### IP-168 IUR-Loop（端到端闭环）

```python
def iur_collaborative_loop(M, scene_obs, intent, parties, target):
    # ①-② 承接第60轮：场景→阻抗，意图→时变约束，生成轨迹种子
    z_scene, K_safe_scene = M.ssm.update_and_compile(scene_obs)
    xi0 = M.serc.seed_trajectory(K_safe_scene)
    xi0 = M.ciec.project_temporal_constraints(xi0, intent)

    # ③-⑤ 联邦本地求解 → 共识 → 信任加权鲁棒化
    fed = FederatedTrajectoryOptimizer(parties)
    fed.xi0 = xi0
    xi_cons = fed.solve(xi0)
    xi_rob = trust_weighted_drto(xi_cons, parties)

    # ⑥ 迁移安全证书
    ok, cert = transfer_safety_certificate(
        xi_rob, source=parties[0], target=target, J_max=M.J_max)

    # ⑦ 执行 + EPIR 证据链（承接第60轮）
    if not ok:
        xi_rob = target.local_conservative(xi_rob)
    ev_exec = execute_and_log(xi_rob, M.epir)

    # ⑧ 合作剩余 + 责任归因
    base = M.baseline_robust_cost
    v = lambda S: coalition_value(S, fed, base)
    phi = shapley_values(parties, v)
    fees = {p.id: vcg_payment(p.id, parties, v) for p in parties}
    psi = reverse_shapley_attribution(
        parties, lambda S: M.failure_prob(S))

    # ⑨ 知识蒸馏更新 + TEC 校验
    prior = kttp_update({p.id: p.last_opt for p in parties},
                        {p.id: p.last_hessian for p in parties},
                        {p.id: p.trust for p in parties})
    M.knowledge.update(prior)
    tec = {
        "trajectory": xi_rob, "evidence": ev_exec,
        "contract": {"shapley": phi, "vcg": fees, "risk_attr": psi},
        "transfer": cert, "valid": ok,
    }
    return tec
```
