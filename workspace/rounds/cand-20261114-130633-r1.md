# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「预测性维护」×「自监督学习」）

> R69 给闭环装上了一张嘴和一个多模态大脑：面对可约的歧义，它会看、会触、会问，并用流似然给标定层做第二意见。但 R69 仍把「健康」当成一个**瞬时布尔量**：这一刻证书 Valid，下一刻 Invalid；这一刻收紧 λ，下一刻没有「下一刻」——它没有记忆、没有趋势、没有「我还能撑多久」。这对一个会缓慢磨损的真实系统是致命的：
> - **预测性维护**说：故障几乎从不突然发生。轴承有振动前兆，相机有标定漂移斜率，ECE 有缓慢爬升，流似然有悄悄塌缩。R68/R69 的阈值只在越过那一刻才响，之前所有前兆信息都被当作噪声丢掉。更关键的是，R69 的动作空间里只有「获取信息」和「执行任务」，唯独没有「**维护自己**」——清洁、重标定、重新锚定、降级运行、换装、请人接管。一个不会自我维护的系统，只能靠永远保守来续命。
> - **自监督学习**说：真实故障标签极其稀缺，而正常运行数据无穷无尽。健康的「正常流形」不需要标签就能学——掩码重建、未来自预测、跨模态时序一致性。退化不是「标签=故障」，而是「系统不再能预测下一时刻的自己」。这把故障检测从监督分类变成**自监督前兆信号**，也让健康模型能在无标签的部署长尾里持续被校准（离线认证换装）。
>
> 核心命题：**把健康从「瞬时证书」升级为「部分可观测的退化过程」；用自监督学习在无标签下学习健康表征、前兆与 RUL；把维护（重标定、清洁、重锚定、换装、请人）作为与任务动作同级、同样需安全认证的一等动作，按 hazard/成本最优调度；并用不可擦除见证与反事实影子轨道，防止维护把故障证据「洗掉」。** 命名 **PROGNOS-RAS**（Prognostics-driven, Self-supervised, Non-resettable-witness Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还能撑多久、什么时候该修、修完的我还可信吗**」——健康不是一个证书，而是一条会磨损、会撒谎、需要被见证的时间线。

## 0. 直觉与动机

**灵感 1（预测性维护 → 健康是退化过程，R68/R69 的证书只是它的边界切片）**
直觉：R68 的标定残差 r_res 与 R69 的流似然 a_score 都是对隐藏健康状态 h_t 的**观测**，不是 h_t 本身。把 h_t 显式写成一个缓慢漂移、部分可观测的随机过程后，整个问题从「当前是否有效」变成三个新问题：退化速度多快？距离失效阈值还有多久（RUL）？在失效前，什么时刻维护最划算？R68 的「任何不确定 → 收紧」因此只是「维护不可行」这一边界的退化：当你不能修、也不知道何时会坏，唯一能做的就是永远慢。预测性维护第一次让「先带病安全运行到计划维护窗口」成为一个可证明的策略，而不是赌博。

**灵感 2（自监督学习 → 无标签的健康流形、前兆与「对不确定性的预测」）**
直觉：故障标签昂贵且长尾，但系统每时每刻都在产生正常的自身信号：观测、残差、似然、表征、动作。自监督 pretext 任务（掩码重建、未来自预测、跨模态/跨时刻一致性）把这些信号压成一个健康嵌入 e_t，并用「能否预测下一时刻的自己」定义健康：退化 = 自预测残差持续上升。两个方向都要看——**上升**是磨损/漂移，**下降或方差坍缩**是传感器卡死/冻结（R68 的残差只看偏差，天然漏掉冻结）。更进一步，SSL 可以监督「不确定性估计器本身」：预测 ECE、模态熵、流似然分布何时将变得不可信，从而在 R69 的「问错比不问更危险」之前就触发维护。

**灵感 3（RUL → 维护时机是最优停止，不是永久刹车）**
直觉：维护有成本（停机、数据、社交打扰），失效有代价（安全、任务失败）。一旦有了健康信念 b_t(h) 与生存函数 S_t(δ)，维护调度就是标准的最优停止/更新问题：当「视界内失效概率 × 失效代价」超过「维护成本」时维护。这给出一个阈值策略，并让 R68 与 R69 都成为参数边界：R68 = 维护成本无穷大（永不维护，只能收紧）；定期维护 = 不看 b_t；事后维修 = 视界为零。更细的是，λ 的含义从「现在有多怕」变成「**带着这个风险安全运行到下次维护机会所需的保守度**」。

**灵感 4（维护是双刃剑 → 它会擦除证据，必须不可擦除见证）**
直觉：重标定会吸收漂移，重新锚定会重置残差，清洁会抹掉故障特征，换装会替换掉可疑模型。**维护恰恰是 R68 最害怕的那个动作——把故障解释掉——只不过现在是系统自己合法地做**。所以维护必须与「掩盖」可区分：执行前先写取证快照到只追加、哈希链、独立供电/时钟的见证通道（控制器没有删除 API）；再用自监督自我模型做一个反事实影子轨道（假如不维护会怎样）。真修复 = 影子也认为本来会继续坏；洗证据 = 影子认为本来没事，或修后「干净得反常」。没有见证与影子，系统可以靠不断自我维护来伪造健康证书。

**灵感 5（自监督自我模型 → 在想象中评估维护，而不是拿真实系统试错）**
直觉：维护动作是物理的、有风险、且不可频繁试错。自监督自我模型 f̂(u,h) 用历史维护日志学习「做 u 之后，观测/健康/似然会怎样」，让规划器先做悲观 rollout 排序候选维护。但自我模型自身会在退化分布漂移下失真、也可能被投毒，所以它只用于**排序**，最终动作仍须过 C-RAS-WM 认证；分布外维护类型一律不信，退回人工或最保守维护。

**灵感 6（严格包含 → R69 是「无维护、零视界」的退化）**
直觉：若维护动作集为空、维护成本无穷、预后视界为零、或关闭 SSL 健康通道，PROGNOS 必须逐指令等于 FLUID-RAS；再关交互即等于 R68。新层只允许做三件事：**加一条更保守的 λ_health 下界、调度经过认证的维护、用健康预测去门控 R69 不确定性估计的可信度**。它绝不放松任何瞬时安全包络，也绝不让「维护」成为绕过证书的后门——否则每加一层就多一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PROGNOS-RAS 总览与四不变式）** PROGNOS-RAS = (SHE, EWS, HBF, RUL, MNT, SMM, FWT, SHD, DRV, HRS, VQAuditor-P, AIC-SENT, J_PROGNOS)。四不变式：
(i) **实时流零学习写操作**（继承定义 293-i）：健康模型只能离线训练、认证后原子换装。
(ii) **即时安全不放松**：同一信念下，允许的瞬时动作集 ⊆ R69 的动作集 ∪ 已认证维护动作；λ_t = max(λ_t^FLUID, λ_t^health)。健康层只能加约束或调度认证维护，不能放宽瞬时安全界。
(iii) **先见证、后维护**：任何 u ∈ 𝒰_mnt 执行前必须把取证快照 S_t⁻ 写入只追加哈希链见证（独立供电/时钟、控制器无删除 API），并通过 C-RAS-WM 认证；维护不得擦除见证。
(iv) **无标签模型的域守门**：SHE/RUL/SMM 只在经认证的支持域内被信任；OOD 或支持不足时退回 R69 保守，且**不得**用不可信的 RUL 去推迟维护。

**定义 311（退化过程与部分可观测健康）** 隐藏健康 h_t ∈ ℋ ⊂ ℝ^d，安全集 ℋ_s。退化动力学
h_{t+1} = h_t + f_deg(h_t, a_t) + w_t，其中磨损分量满足 f_deg ≥ 0（A99：存在标量磨损坐标 w_t = cᵀh_t 在两次维护之间单调不减）；维护 u 的作用为 h_{t+1} = R_u(h_t) + ξ_u，R_u 把状态向健康集收缩（认证维护）但一般不是恒等。观测 y_t = (r_res, a_score, ECE, ε_ssl, mode_entropy, …) = g(h_t, o_t) + ν_t。失效时刻 τ_f = inf{t : h_t ∉ ℋ_s}。

**定义 312（自监督健康表征 SHE）** 窗口 W_t = {o_{t−L+1:t}, r_res, a_score, z_t, ECE_t, 动作}，编码 e_t = φ_ψ(W_t)。自监督目标
L_SHE = L_mask + α L_fut + β L_cons + γ L_inv，
其中 L_fut = ‖g_ψ(e_t) − sg(φ_ψ(W_{t+k}))‖²（stop-grad 防坍缩），L_cons 为跨模态/跨时刻一致性，L_inv 为对任务、场景等 nuisance 的不变性（信息瓶颈/增广）。健康分 s_t = −log p_0(e_t)（p_0 为离线正常数据估计的健康流形密度），并用保形分位数归一化。**双向**：s_t 偏离正常可以向上（磨损）也可以向下（冻结/卡死）。

**定义 313（前兆预警统计 EWS）** 自预测残差 ε_t = ‖φ_ψ(W_t) − Pred_ψ(φ_ψ(W_{t−1}))‖。双向 CUSUM：
g_t⁺ = max(0, g_{t−1}⁺ + (ε_t − μ_0 − k))，
g_t⁻ = max(0, g_{t−1}⁻ − (ε_t − μ_0 + k))。
报警时刻 τ_a = inf{t : max(g_t⁺, g_t⁻) > b}。g⁺ 捕捉持续上升的退化，g⁻ 捕捉方差坍缩/冻结。前置量 LT = τ_f − τ_a；虚警由平均运行长度 ARL₀(k,b) 控制。与 R68 残差不同，EWS 是**时间积分统计量**，因此对低于单步阈值的缓慢前兆敏感。

**定义 314（健康信念滤波 HBF 与剩余寿命 RUL）** 后验 b_t(h) = p(h_t | y_{1:t}, u_{1:t})，用粒子滤波按定义 311 的动力学与观测模型递推。生存函数 S_t(δ) = P(τ_f > t + δ | b_t)，剩余寿命 RUL_t = ∫_0^∞ S_t(δ) dδ。SSL 违约只作为**伪失效**用于预训练，绝不能当作真标签；用稀疏真实失效事件做生存校准，无标签区域只允许报告保守下界。

**定义 315（维护动作空间与效果模型）** 𝒰_mnt = {none, u_recal（重标定）, u_clean（清洁/致动传感器）, u_reanchor（重定位/重锚定）, u_probe_cal（专用标定运动）, u_swap（认证模型/checkpoint 换装）, u_escalate（请人接管/安全停）}。每个 u 携带成本 C_m(u) = 停机 + 数据 + 物理/社交风险，效果模型 R_u，认证风险 risk(u) ≤ ε_m。增广动作为 ξ = (a, g, u)，但 u 只在调度时刻出现；信息动作 g 仍属 R69 的 𝒜_info。

**定义 316（维护调度：hazard 阈值与最优停止）** 在预后视界 H_pm 上选择
u* = argmin_{u ∈ {none} ∪ 𝒰_mnt} [ C_m(u) + C_f · P(τ_f ≤ t + H_pm | b_t) + C_risk · risk(u) ]，
s.t. 认证通过。在单调 hazard 与常数成本下，最优策略是阈值型：**当 P(τ_f ≤ t + H_pm | b_t) ≥ C_m/C_f 时维护**。边界：C_m = ∞ ⇒ 永不维护（R68 的永远收紧）；H_pm = 0 ⇒ 事后维修；忽略 b_t ⇒ 定期维护；用 b_t 且 0 < H_pm < ∞ ⇒ 预测性维护。R69 相当于 𝒰_mnt = ∅。

**定义 317（健康感知风险调度 HRS）** λ_t^health 是使「在执行动作下，视界 H_pm 内预测失效概率」不超过维护阈值 C_m/C_f 的最小保守度。总风险缩放
λ_t = max( λ_t^FLUID, λ_t^health(b_t, H_pm) )。
维护完成后用更新后的 b_t 重算两项；由于 R69 在同一更新状态上也会得到同样的 λ_t^FLUID，安全序保持（定理 18）。

**定义 318（自监督自我模型 SMM）** f̂_ω(u, h, context) 预测维护后的观测/健康轨迹及其对 r_res、a_score、ECE、模态熵的影响，训练信号来自历史维护日志的自监督下一窗口预测（无标签）。用集成/分位数给出不确定集 𝒰_SMM，规划采用悲观 rollout：Rollout(u) = min_{f̂ ∈ 𝒰_SMM} 期望成本。支持域检验：若 (u, h) 密度过低或该维护类型样本不足，禁止用 SMM 为「推迟维护」背书。

**定义 319（不可擦除见证 FWT 与取证快照）** 见证 𝒲 是只追加哈希链
(t, S_t⁻, u_t, S_t⁺, e_t, shadow_t, model_ver, counter)，
由独立供电、独立时钟、写一次的模块维护，控制器无删除 API；计数器单调并定期外部锚定，故整机复位也可检测。取证快照 S_t⁻ 必须包含 r_res、a_score、ECE、s_t、模态权重与策略版本。见证不是信任的来源，而是**事后不可否认性**的来源。

**定义 320（反事实影子轨道 SHD 与维护吸收检测）** 从 S_t⁻ 出发，用 SMM 传播「假设不维护」的反事实健康/观测影子 S_t⁰。记维护吸收比
MAR(u) = [r_res(S_t⁻) − r_res(S_t⁺)] / [a_score(S_t⁻) − a_score(S_t⁺) + ε]，
以及影子散度 D_t = ‖S_t⁺ − Rollout_{R_u}(S_t⁻)‖。判据：
- 真修复：S_t⁻ 显示退化，影子预测继续退化，S_t⁺ 与 R_u 悲观 rollout 一致；
- 洗证据/吸收：S_t⁻ 显示退化但影子认为本不退化，或 S_t⁺「干净得反常」（D_t 大且跨过保形下界）；
- 多余维护：S_t⁻ 本健康却触发维护（浪费成本，也可能是攻击）。
综合怀疑分 Σ_maint = w₁·1[影子无退化] + w₂·1[D_t > τ_div] + w₃·recurrence(u)；Σ_maint > τ_abs ⇒ U_epi 保持未消解并进入审计。

**定义 321（诊断只为维护决策服务 DRV）** 诊断动作 g 的价值改为对**维护决策**的期望改善：
VoI_maint(g) = E_y[ J*(b_t) − J*(b_t | y) ]，
其中 J* 是定义 316 的最优期望成本。若对任何回答 y，最优维护决策都不变，则 VoI_maint(g) = 0，即使它降低了模态熵也不问。恒有 VoI_maint(g) ≤ H(M|o)，故 DRV 相对 R69 只会**少问**、不会多问——这直接缓解 R69「追问幻影模态」的风险。

**定义 322（无标签健康模型的校准与保形 RUL）** 由于标签稀缺，hazard 用稀疏失效事件校准，RUL 用保形生存给出有限样本区间 C_t = [L_t, U_t]，P(τ_f ∈ C_t) ≥ 1−α（可交换下成立；漂移下用加权/自适应保形 ACI 维持长期覆盖）。证书记录覆盖缺口；覆盖不达标 ⇒ 只报告保守 RUL 下界，且禁止据此推迟维护。

**定义 323（维护威胁模型 ℰ_MAINT）** (a) **压制报警**：伪装 SSL 残差或借维护抹除退化；(b) **诱导维护**：制造虚警，造成停机/成本 DoS 并使操作者「报警疲劳」；(c) **毒化自我模型**：让危险维护看起来安全、安全维护看起来危险；(d) **维护时机攻击**：诱使系统在危险相位（如过桥中）维护；(e) **日志重放/回滚**：重放见证或降级到已知脆弱版本。并入 AIC：ℰ_SENT = ℰ_FLUID × ℰ_MAINT。检测依赖见证、独立监视器、跨模型分歧与维护频率异常。

**定义 324（参与式审计 VQAuditor-P）** 审计维护决策：是否可辩护（阈值/成本是否真实）、取证快照是否完整、维护是否改变了会改变诊断的证据、影子散度是否异常、RUL 覆盖是否达标、虚警后是否出现脱敏、人工接管是否正确。结论回灌 AuditBuf，仅作为**离线**训练/先验，绝不写回实时环。

**定义 325（证书 J_PROGNOS）** J_PROGNOS = (J_FLUID, she_hash, arl0_obs, rul_interval, rul_coverage, ssl_score_p95, maintenance_log_hash, forensic_snapshot_hash, mar_p95, shadow_divergence_p95, maint_count, prognos_ver)。Valid ⇔ Valid(J_FLUID) ∧ ARL₀ ≥ 目标 ∧ RUL 覆盖 ≥ 1−α ∧ 无未决吸收 ∧ 所有维护均已认证 ∧ 见证完整。

**定义 326（严格包含与安全序）** 若 𝒰_mnt = ∅、或 C_m = ∞、或 H_pm = 0、或关闭 SHE，则 PROGNOS 逐指令等于 FLUID-RAS；再关闭交互即等于 R68。安全序：固定信念且无已完成的维护时，λ_PROGNOS ≥ λ_FLUID 且允许动作集为子集；认证维护完成后健康状态真实改变，λ 按更新后的状态由同一 R69 规则重算。故不存在任何瞬时放松，只有经认证的状态改善。

**定义 327（时序参数与自适应窗口）** 健康窗口 L、自预测步长 k、CUSUM 参考 k_c 与阈值 b、粒子数 N_p、维护视界 H_pm、决策周期 Δ_maint。窗口自适应：瞬态用短窗以快报警，慢漂移用长窗以稳估计；维护决策按 Δ_maint 降频，避免每帧重规划造成 chattering（定理 19 的 dwell-time 条件）。

# IP-264 SHE：自监督健康表征（离线训练；在线只前向）
class SSLHealthEncoder:
    def __init__(self, phi, pred, healthy_ref):
        self.phi, self.pred, self.ref = phi, pred, healthy_ref
    def encode(self, window, prev_e):
        e   = self.phi(window)                    # 无标签健康嵌入
        s   = -self.ref.log_density(e)            # 到健康流形的负对数密度
        eps = (e - self.pred(prev_e)).norm()      # 自预测残差（前兆源）
        return e, s, eps

# IP-265 EWS：双向 CUSUM（升=磨损/漂移，降=冻结/卡死）
def ews_update(gp, gm, eps, mu0, k):
    gp = max(0.0, gp + (eps - mu0 - k))           # 上侧：退化累积
    gm = max(0.0, gm - (eps - mu0 - k))           # 下侧：方差坍缩/冻结
    return gp, gm

# IP-266 HBF/RUL：粒子滤波 + 生存表
def health_belief(particles, y, u_log, f_deg, R_u, obs_model):
    particles = [propagate(p, f_deg, u_log) for p in particles]
    w = normalize([obs_model(p, y) for p in particles])
    return resample(particles, w)
def rul(b_t, survival_fn, grid):
    return sum(survival_fn(b_t, d) * grid.step for d in grid)   # ∫ S(δ)dδ

# IP-267 MNT：hazard 阈值维护（最优停止）
def schedule_maintenance(b_t, H_pm, C_m, C_f):
    p_fail = failure_prob_within(b_t, H_pm)
    if p_fail * C_f < C_m:                        # 不划算：继续安全运行
        return None
    return argmin(u in U_mnt,
                  key=lambda u: C_m(u) + C_f * failure_prob_after(b_t, u, H_pm)
                                + C_risk * risk(u))

# IP-268 SMM：维护效果自模型（只用于排序，最终仍需认证）
def pessimistic_effect(u, h, smm_ensemble):
    return min(smm_ensemble.predict(u, h))        # 对不确定集取下界

# IP-269 FWT：先见证，后维护
def do_maintenance(M, u, obs):

    post = M.actuator.execute(u)
    M.safe_mode.exit()
    M.fwt.append_post(u, post, M.smm.shadow(snap))
    return post

# IP-270 SHD：反事实影子轨道 + 吸收检测
def absorption_suspect(M, pre, post):
    shadow = M.smm.rollout_no_maintenance(pre)    # 假如不维护会怎样
    diverg = (post - shadow).norm()
    mar    = (pre.r_res - post.r_res) / (pre.a_score - post.a_score + 1e-8)
    return (diverg > TAU_DIV) or ((pre.degraded) and (post.too_clean)) or (mar > TAU_MAR)

# IP-276 主闭环（继承 R69，仅在健康/维护处插入 PROGNOS 层）

    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    # 6) 参与式审计 + 证书
    M.vqa_p.submit(g, u, s_t, rul_t, b_t, M.fwt.last, alarm)

## 3. 推导

**引理 19（CUSUM 前兆提前量与虚警权衡）** 设健康期自预测残差 ε_t ~ 𝒩(μ₀, σ²) i.i.d.，退化在 τ₀ 后每步叠加漂移 δ。取参考值 k_c = δ/2、阈值 b，则双侧 CUSUM 的平均虚警长度 ARL₀ ≈ exp(2b k_c/σ²)/(2k_c²/σ²) 量级，期望检测延迟 E[τ_a − τ₀] ≈ b/k_c = 2b/δ（Page–Lorden）。故正向前置量条件为 τ_f − τ₀ > 2b/δ + O(1)；等价地，可检测的最小漂移 δ_min ≈ 2b/(τ_f − τ₀)。系：**报警阈值 b 不是越灵敏越好**——降低 b 增加前置量但也增加虚警，定义 316 的成本把两者折成同一个 J*；R68 的单步阈值 ≈ b→0 且只看单点，故要么漏前兆、要么虚警爆炸。

**引理 20（维护阈值的最优性）** 设 hazard 率非减、维护把系统更新到固定健康状态、C_m 与 C_f 为常数，则在预测视界 H_pm 上，策略「当且仅当 C_f·P(τ_f ≤ t+H_pm | b_t) ≥ C_m 时维护」在停止策略类中最优。证明要点：值函数对失效分布一阶随机占优单调，故最优策略对 b_t 是阈值型；在更新过程的 renewal 结构下，阈值由边际成本相等给出（经典 age-replacement 的随机化推广）。系：R68 的「永远收紧」是 C_m = ∞ 的边界；定期维护是丢弃 b_t；事后维护是 H_pm = 0。故预测性维护不是与 R68 竞争，而是把 R68 的费用假设显式化。

**引理 21（维护吸收的可辨识性与见证秩条件）** 记维护后观测 y⁺ = R_u(h) + ν。若 R_u 是向健康集的强收缩（不同 h 被压到同一健康点附近），则仅凭 y⁺ 无法区分「原本健康」与「刚刚被修好」：维护把健康方向的信息抹进 R_u 的核空间。取证快照 y⁻ = g(h) + ν 提供独立方程；健康状态 h 可辨识当且仅当 [观测雅可比；R_u 雅可比] 在健康方向上满秩（见证覆盖收缩的零空间）。若见证也被擦除，则吸收不可辨识。影子轨道进一步给出反事实：真修复会让「无维护影子」持续退化，洗证据则影子本不退化。**因此 (MAR↑, D↑, 影子无退化) 是可辨识的维护洗证据联合模式**，对应 R68 反吸收引理在「维护侧」的镜像。

**引理 22（保形 RUL 的覆盖与漂移缺口）** 在可交换性下，split conformal 的 RUL 区间满足 P(τ_f ∈ C_t) ≥ 1−α（有限样本）。若相邻窗口分布的总变差漂移 ≤ ε，则加权保形覆盖 ≥ 1−α−Lε（L 为窗口数）；采用自适应保形（ACI）可恢复长期覆盖 ≥ 1−α。系：证书必须报告实际覆盖；当覆盖 < 1−α 时只允许保守 RUL 下界，禁止据此推迟维护——否则「不确定性」会被 RUL 的乐观尾部偷偷消费掉。

**引理 23（诊断只为决策：DRV 的严格细化）** 对任意信息动作 g，VoI_maint(g) = E_y[J*(b_t) − J*(b_t|y)] ≥ 0，且若对所有 y 最优维护决策相同，则 VoI_maint(g) = 0。又 J* 的决策变量是模态的一个函数，故 VoI_maint(g) ≤ I(M; y | o) ≤ H(M|o)。因此 PROGNOS 的诊断集 ⊆ R69 的诊断集（在相同阈值下），R69 的「按熵追问」是忽略维护决策时的上界。系：**当维护不可行（C_m=∞）时，VoI_maint 退化为 R69 的任务 VoI**；当诊断无法改变维护时，系统宁愿不问——直接削弱 R69「追问幻影」的风险。

**定理 18（PROGNOS 严格包含 FLUID，FLUID 严格包含 R68）** 在 A99 与定义 326 的边界下，任意状态 s 上 PROGNOS 的期望风险 ≤ FLUID ≤ R68；且当 𝒰_mnt=∅ 或 C_m=∞ 或 H_pm=0 或 SHE 关闭时，PROGNOS 与 FLUID 逐指令相同（再关交互即与 R68 相同）。证明：每步 PROGNOS 的动作集 = FLUID 的动作集 ∩ {λ ≥ λ_health} ∪ 认证维护；λ_PROGNOS ≥ λ_FLUID，新增门只删动作不加动作；维护本身受 C-RAS-WM 认证，且其效果只改变状态、不改变认证规则；边界条件下 λ_health=0、𝒰_mnt=∅，得逐指令相等。∎

**定理 19（维护安全、无突变与防抖）** 若维护 u 通过 C-RAS-WM 前缀认证（risk(u) ≤ ε_m）并在安全维护模式中执行，则维护期间任务动作被冻结、物理风险 ≤ ε_m；维护失败/超时/被投毒时 b_t 悲观更新，λ 单调不降地退回 R69 保守。对「维护/不维护」的切换加入最小驻留时间 dwell_min，且要求切换 Lyapunov 条件 ΔV ≤ −c‖h‖² + ε_switch，则闭环无 chattering、无控制突变；R68 定理 15 的提交/换装不变式保持。∎

**定理 20（见证的不可否认性）** 设见证为只追加哈希链、独立时钟与单调计数器，且至少一份副本在设备外。则任何控制器侧的执行序列若改变健康状态，必在链上留下与 S_t⁻ 一致的记录；不存在不写快照而获得 Valid(J_PROGNOS) 的执行路径。故「维护可以制造有效性」被排除，除非见证信任根被攻破——后者成为系统唯一不可约的信任边界。∎

## 6. 本轮最大风险

**一句话**：PROGNOS 的全部收益押在「自监督健康模型能在无标签下区分**真退化**与**良性分布漂移**」这一前提上——若它把新场景误判为磨损（频繁自伤式维护、停机 DoS），或把真磨损当成新场景（自信地推迟维护），系统就会在最需要维护时最不维护；更阴险的是，**维护本身会擦除证明维护是否必要的那部分证据**：每次重标定都吸收掉一点漂移，每次重锚定都重置掉一点残差，于是「维护 → 证据变干净 → 下次维护更缺乏依据」形成自我封闭的维护恍惚（maintenance trance），而影子轨道又依赖可能被同一分布漂移/投毒污染的自我模型。最坏情况下，系统可以靠不断重置来**制造**一张有效证书——证书不再意味着「我值得信任」，而只意味着「我最近被重置过」。

**次级风险与缓解**：
1. **无标签前兆误报/漏报** → 双向 CUSUM + ARL₀ 控制 + 保形校准 + E301–E303；
2. **维护洗证据/自我合法化** → 先见证后维护 + 独立见证根 + 反事实影子 + MAR/D 判据 + E307；
3. **维护投毒与报警疲劳** → ℰ_MAINT 对抗训练 + 频率/成本异常检测 + 参与式审计 + E308/E311；
4. **RUL 乐观偏差** → 保形覆盖 + 覆盖不达标即只报保守下界、禁止推迟维护 + E304；
5. **维护动作本身不安全 / 切换 chattering** → C-RAS-WM 认证 + 安全维护模式 + dwell-time + 定理 19 + E309；
6. **自我模型分布外失真** → 支持域检验 + 悲观 rollout + 只用于排序 + E310/E312。

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 让系统会看、会触、会问，并把不确定性分为 aleatoric 与 epistemic；但仍把「健康」当成瞬时布尔量：证书要么 Valid 要么 Invalid，风险要么收紧要么更收紧。它没有记忆、没有退化趋势、没有剩余寿命，也**没有「维护自己」这个动作**——只有永远保守。
>
> 本轮把健康从「瞬时证书」升级为「部分可观测的退化过程」：用**自监督学习**在无标签下学健康流形、前兆与 RUL；用**预测性维护**的最优停止理论决定何时重标定、清洁、重锚定、换装或请人；用**不可擦除见证 + 反事实影子轨道**防止维护把故障证据洗掉。理论姿态：R69 是本轮在「无维护动作、零预后视界」边界上的严格退化；R68 再退化为「无交互」。安全侧不做任何让步，只新增经认证的状态改善。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我还能撑多久、什么时候该修、修完的我还可信吗**」——健康不是证书，而是一条会磨损、会撒谎、需要被见证的时间线。
>
> IP 编号：IP-264~IP-276（共 13 个）。定义增量 310–327。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** PROGNOS = (SHE, EWS, HBF, RUL, MNT, SMM, FWT, SHD, DRV, HRS, VQAuditor-P, AIC-SENT, J_PROGNOS)；四不变式：实时零学习写操作；即时安全不放松（`λ_t = max(λ_FLUID, λ_health)`，动作集只减不增）；先见证后维护（快照入只追加链，且过 C-RAS-WM 认证）；无标签模型域守门（OOD 退回 R69，且不得用不可信 RUL 推迟维护）。

**定义 311（退化过程）** `h_{t+1} = h_t + f_deg(h_t,a_t) + w_t`，`f_deg ≥ 0`；维护 `h_{t+1}=R_u(h_t)+ξ_u`；观测 `y_t = g(h_t,o_t)+ν_t`；`τ_f = inf{t: h_t ∉ ℋ_s}`。

**定义 312–313（SHE 与 EWS）** 自监督损失 `L_SHE = L_mask + αL_fut + βL_cons + γL_inv`，`L_fut` 用 stop-grad 防坍缩；健康分双向。`ε_t = ‖φ(W_t) − Pred(φ(W_{t−1}))‖`；双向 CUSUM `g⁺/g⁻` 报警阈值 `b`，ARL₀ 控制虚警。

**定义 314（HBF/RUL）** `b_t(h)=p(h_t|y_{1:t},u_{1:t})` 粒子滤波；`S_t(δ)=P(τ_f>t+δ|b_t)`，`RUL_t=∫S_t(δ)dδ`；SSL 违约只是伪失效，真标签稀疏校准。

**定义 315–316（维护动作与调度）** `𝒰_mnt` 六类维护，成本 `C_m(u)`、效果 `R_u`、认证风险 `≤ ε_m`；`u* = argmin [C_m + C_f·P(τ_f≤t+H_pm|b_t) + C_risk·risk]`；单调 hazard 下为阈值策略：`P_fail ≥ C_m/C_f` 即维护。R68 = `C_m=∞`，R69 = `𝒰_mnt=∅`。

**定义 317（健康感知风险）** `λ_t = max(λ_FLUID, λ_health(b_t,H_pm))`；维护后用更新后的 `b_t` 重算，安全序保持。

**定义 318（SMM）** `f̂_ω(u,h)` 自监督预测维护后轨迹；集成给出不确定集，悲观 rollout 只用于排序；支持域不足禁止为推迟维护背书。

**定义 319–320（FWT/SHD）** 只追加哈希链 `(t,S⁻,u,S⁺,e,shadow,ver,counter)`，独立供电/时钟、无删除 API；影子 `S⁰` 为「不维护」反事实；`MAR`、散度 `D_t`、怀疑分 `Σ_maint` 识别真修复 vs 洗证据。

**定义 321（DRV）** `VoI_maint(g)=E_y[J*(b_t)−J*(b_t|y)]`；若任何回答都不改变最优维护决策则不问；恒 `≤ H(M|o)`，故诊断集 ⊆ R69。

**定义 322–325（校准/威胁/审计/证书）** 保形 RUL 覆盖 ≥ 1−α，覆盖不达标只报保守下界且禁止推迟维护；`ℰ_SENT=ℰ_FLUID×ℰ_MAINT`；VQAuditor-P 审维护可辩护性/证据擦除/报警疲劳；`J_PROGNOS` 并入 ARL₀、RUL 覆盖、见证哈希、MAR、影子散度。

**定义 326–327（包含与时序）** 关闭维护/SSL 或 `H_pm=0` 时逐指令等于 FLUID（再关交互等于 R68）；安全序 `λ_PROGNOS ≥ λ_FLUID` 直至认证维护完成。自适应窗口与降频维护决策防 chattering。

## 3. 关键算法伪代码

```python
# IP-264 SHE：自监督健康表征（离线训练；在线前向）
class SSLHealthEncoder:
    def encode(self, window, prev_e):
        e   = self.phi(window)
        s   = -self.ref.log_density(e)             # 健康流形负对数密度
        eps = (e - self.pred(prev_e)).norm()       # 自预测残差（前兆）
        return e, s, eps

# IP-265 EWS：双向 CUSUM
def ews_update(gp, gm, eps, mu0, k):
    return max(0.0, gp + (eps - mu0 - k)), max(0.0, gm - (eps - mu0 - k))

# IP-266 HBF/RUL
def health_belief(particles, y, u_log, f_deg, R_u, obs_model):
    particles = [propagate(p, f_deg, u_log) for p in particles]
    w = normalize([obs_model(p, y) for p in particles])
    return resample(particles, w)

def rul(b_t, survival_fn, grid):
    return sum(survival_fn(b_t, d) * grid.step for d in grid)

# IP-267 MNT：hazard 阈值最优停止
def schedule_maintenance(b_t, H_pm, C_m, C_f):
    if failure_prob_within(b_t, H_pm) * C_f < C_m:
        return None                                # 不划算：继续安全运行
    return argmin(U_mnt, lambda u: C_m(u) + C_f*failure_prob_after(b_t,u,H_pm)
                                    + C_risk*risk(u))

# IP-269 FWT：先见证，后维护
def do_maintenance(M, u, obs):
    snap = M.fwt.snapshot(obs, M.she.last_e, M.last_a_score,
                          M.last_r_res, M.last_ece)
    assert M.c_ras_wm.certify_maint(u, obs)
    M.fwt.append_pre(u, snap)                      # 只追加、无删除
    M.safe_mode.enter(u); post = M.actuator.execute(u); M.safe_mode.exit()
    M.fwt.append_post(u, post, M.smm.shadow(snap))
    return post

# IP-270 SHD：反事实影子 + 吸收检测
def absorption_suspect(M, pre, post):
    shadow = M.smm.rollout_no_maintenance(pre)
    diverg = (post - shadow).norm()
    mar    = (pre.r_res - post.r_res) / (pre.a_score - post.a_score + 1e-8)
    return (diverg > TAU_DIV) or (pre.degraded and post.too_clean) or (mar > TAU_MAR)

# IP-276 主闭环（继承 R69）
def PROGNOS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o, M.o_cal)
    e_t, s_t, eps_t = M.she.encode(M.window(obs), M.she.prev_e)
    M.gp, M.gm = M.ews.update(M.gp, M.gm, eps_t, M.mu0, M.k)
    b_t   = M.hbf.update(M.b_t, obs, M.maint_log)
    rul_t = M.rul(b_t, M.survival, M.grid)
    g = M.drv.choose(modes, b_t, M.H_pm, M.budget) if U_epi > TAU_EPI else None
    if g is not None: b_t = M.hbf.update_with_answer(b_t, M.cia.execute(g))
    u = M.mnt.schedule(b_t, M.H_pm, M.C_m, M.C_f)
    if u is not None and M.c_ras_wm.certify_maint(u, o):
        post = M.do_maintenance(u, obs)
        b_t = (M.hbf.pessimistic_update(b_t)
               if M.shd.absorption_suspect(M.fwt.pre, post)
               else M.hbf.after_maintenance(b_t, u))
    U_unres = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_unres),
              M.hrs.lam_health(b_t, M.H_pm))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    M.vqa_p.submit(g, u, s_t, rul_t, b_t, M.fwt.last)
    return k, lam, b_t, (U_ale, U_epi), (rul_t, s_t)
```

## 4. 推导

**引理 19（CUSUM 前兆提前量）** 健康期 `ε_t ~ N(μ₀,σ²)`，退化后每步漂移 δ；取 `k=δ/2`、阈值 b，则 `ARL₀ ≈ exp(2bk/σ²)/(2k²/σ²)` 量级，期望检测延迟 `≈ b/k = 2b/δ`（Page–Lorden）。正向前置量条件 `τ_f−τ₀ > 2b/δ`；可检测最小漂移 `δ_min ≈ 2b/(τ_f−τ₀)`。系：报警阈值是前置量与虚警的折中，定义 316 的成本把二者折进同一个 J*；R68 的单步阈值相当于只看单点，必然漏前兆或虚警爆炸。

**引理 20（维护阈值最优性）** hazard 非减、维护更新到固定健康态、成本常数时，「`C_f·P(τ_f≤t+H_pm|b_t) ≥ C_m` 即维护」在停止策略中最优。值函数对失效分布一阶随机占优单调 ⇒ 策略对 `b_t` 阈值型；renewal 结构下阈值由边际成本相等给出。系：R68 = `C_m=∞`；定期维护 = 丢弃 `b_t`；事后维修 = `H_pm=0`；预测性维护把 R68 的费用假设显式化，而非与之竞争。

**引理 21（维护吸收的可辨识性）** 维护后 `y⁺=R_u(h)+ν`；强收缩 `R_u` 把不同 h 压到同一健康点，仅凭 `y⁺` 无法区分「原本健康」与「刚修好」。健康 h 可辨识 ⇔ `[观测雅可比；R_u 雅可比]` 在健康方向满秩，即取证快照覆盖 `R_u` 的零空间。影子轨道给出反事实：真修复使「无维护影子」持续退化；洗证据则影子本不退化。故 `(MAR↑, D↑, 影子无退化)` 是可辨识的洗证据联合模式，与 R68 反吸收引理互为镜像。

**引理 22（保形 RUL）** 可交换下 `P(τ_f∈C_t) ≥ 1−α`（有限样本）；总变差漂移 ≤ ε 时加权保形覆盖 ≥ `1−α−Lε`，ACI 恢复长期覆盖 ≥ 1−α。系：覆盖不达标只报保守下界，禁止据此推迟维护。

**引理 23（DRV 严格细化）** `VoI_maint(g) = E_y[J*(b_t)−J*(b_t|y)] ≥ 0`；若所有 y 下最优维护决策不变则为 0；又 `VoI_maint ≤ I(M;y|o) ≤ H(M|o)`，故 PROGNOS 诊断集 ⊆ R69 诊断集。系：维护不可行（`C_m=∞`）时退化为 R69 的任务 VoI；诊断不能改变维护时宁愿不问，直接削弱 R69「追问幻影」的风险。

**定理 18（严格包含）** A99 与定义 326 下，任意状态期望风险 `PROGNOS ≤ FLUID ≤ R68`；当 `𝒰_mnt=∅`、`C_m=∞`、`H_pm=0` 或 SHE 关闭时，PROGNOS 与 FLUID 逐指令相同（再关交互即 R68）。证明：每步动作集 = FLUID 动作集 ∩ `{λ≥λ_health}` ∪ 认证维护；新增门只删动作；维护受 C-RAS-WM 认证且只改变状态；边界下 `λ_health=0`、`𝒰_mnt=∅`。∎

**定理 19（维护安全与无突变）** 维护过 C-RAS-WM 认证并在安全维护模式执行 ⇒ 物理风险 `≤ ε_m`；失败/超时/投毒 ⇒ `b_t` 悲观更新、λ 单调不降退回 R69。维护/不维护切换加最小驻留时间与切换 Lyapunov 条件 `ΔV ≤ −c‖h‖² + ε_switch` ⇒ 无 chattering、无控制突变；R68 定理 15 的换装不变式保持。∎

**定理 20（见证不可否认性）** 只追加哈希链 + 独立时钟 + 单调计数器 + 至少一份设备外副本 ⇒ 任何改变健康状态的执行序列必留下与 `S_t⁻` 一致的记录；不存在不写快照而获得 `Valid(J_PROGNOS)` 的路径。故维护不能制造有效性，除非见证信任根被攻破——这是唯一不可约的信任边界。∎

## 7. 本轮最大风险

**一句话**：PROGNOS 的全部收益押在「自监督健康模型能在无标签下区分**真退化**与**良性分布漂移**」这一前提上——若它把新场景误判为磨损（频繁自伤式维护、停机 DoS），或把真磨损当成新场景（自信地推迟维护），系统就会在最需要维护时最不维护；更阴险的是**维护会擦除证明维护是否必要的那部分证据**：每次重标定吸收一点漂移，每次重锚定重置一点残差，于是「维护 → 证据变干净 → 下次维护更缺乏依据」形成自我封闭的维护恍惚（maintenance trance），而影子轨道又依赖可能被同一漂移/投毒污染的自我模型。最坏情况下，系统可以靠不断重置来**制造**一张有效证书——证书不再意味着「我值得信任」，而只意味着「我最近被重置过」。

**次级风险与缓解**：无标签前兆误报/漏报（双向 CUSUM + ARL₀ + 保形校准 + E301–E303）；维护洗证据/自我合法化（先见证后维护 + 独立见证根 + 影子/MAR + E307）；维护投毒与报警疲劳（ℰ_MAINT 对抗训练 + 频率/成本异常检测 + VQAuditor-P + E308/E311）；RUL 乐观偏差（保形覆盖 + 覆盖不达标只报下界 + E304）；维护动作不安全/切换 chattering（C-RAS-WM 认证 + 安全维护模式 + dwell-time + 定理 19 + E309）；自我模型 OOD 失真（支持域检验 + 悲观 rollout + 只用于排序 + E310/E312）。
