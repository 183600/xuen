# 第 68 轮（承接第 67 轮「SimRAS 仿真增强风险闭环」IP-233~242；灵感循环第 1 轮；本轮灵感：「机器人基础模型」×「技能组合」）

> 第 65~67 轮把闭环从「故障可归因」推进到「意图可感知」再到「未来可预演」。但三者共享一个未言明的前提：控制器面对的是单一任务、单一策略（或单一动作块生成器）。机器人基础模型（Robot Foundation Model, RFM）改变了这个前提——它不再直接输出动作，而是在测试时**组合**出训练中未显式见过的技能序列。于是瓶颈从「哪个故障 / 谁的意图 / 什么未来」转移到：
>
> **当每个技能单独都安全时，组合起来的技能程序整体还可信吗？**
>
> 本轮核心命题：
>
> **把「单体技能的风险闭环」升级为「技能组合的安全代数」：用带类型与契约的技能，把 RFM 生成的技能程序约束为一个可组合、可验证、可修复的范畴；使 SimRAS 的证书沿组合算子逐层提升为整程序证书。**
>
> 方案名：**MOSAIC（Modular Safety-Aware Interface Calculus，模块化安全接口演算）**。它不问「这个技能安不安全」，而问「**这个技能和下一个技能接得上吗？接缝处谁负责？**」

## 0. 直觉与动机

**灵感 1（机器人基础模型 → 技能先验，而非控制器）**
直觉：把 RFM 想成一位“见多识广但不保证靠谱”的工头：它见过海量任务，能凭直觉报出一串“先抓、再转、后放”的技能名，却不清楚每个技能在当前工地的精确边界。若让它直接输出关节力矩，安全无法审计；若让它只输出**技能符号**，我们就可以在符号层做类型检查与契约验证。因此 MOSAIC 把 RFM 的定位从 policy 降级为 **skill prior / proposal distribution**：它负责“提方案”，不负责“签字”。

**灵感 2（技能组合 → 范畴里的态射复合，风险藏在接缝）**
直觉：技能像乐高积木，单块积木再结实，拼错接口也会塌。组合的安全风险不是各技能风险的简单相加，而是集中在**接口（seam）**：前一个技能的后置条件是否满足后一个技能的前置条件？两个技能之间的隐状态（夹持力、物体姿态、人的意图）是否被正确交接？这正是单体 VISTA/RAS 从未建模的“组合缝隙”。把技能看成范畴里的态射，组合就是态射复合；复合是否有定义，由前后置条件决定。

**灵感 3（证书 → 从技能到风险预算代数的幺半函子）**
直觉：若每个技能都带一张“风险发票”，组合就应该是“发票求和”，而不是“重新审计整个程序”。数学上，这要求证书构造是一个**幺半函子（monoidal functor）**：它把技能范畴里的态射复合，映射为风险预算代数的乘法，并保持单位元。函子律一旦成立，整程序证书可由叶技能证书**归纳合成**，无需指数级重验。这把“组合安全”从一次性全局搜索，降为可缓存的局部折叠。

**灵感 4（基础模型幻觉 → “类型正确但语义错误”的技能）**
直觉：RFM 最危险的失败不是语法错误，而是**类型检查通过、语义却错**——例如它提议“把杯子放到桌上”，类型上是 Place 技能，但当前杯子是满的、桌面是斜的。MOSAIC 因此需要三层防线：类型检查（挡住语法错）、接口契约（挡住前置/后置错）、接缝残差（挡住隐状态耦合错）。三层对应三类组合故障假设 H_comp。

**灵感 5（技能组合 → 可修复的组合，而非一次性判定）**
直觉：组合验证不该只有“通过/拒绝”二元输出。当接缝风险超预算时，系统应能**插入适配技能（adapter）**、**重排顺序**或**替换同类型技能**，把程序修复到预算内。这把安全从“守门”变成“编辑”：安全不是一个布尔谓词，而是一个可优化的预算约束。

**灵感 6（与 SimRAS 的接合点）**
直觉：第 67 轮的 SimRAS 已经能对**单段**动作块做世界模型滚动与 VQA 审计。MOSAIC 不替换它，而是把它包在技能内部：每个技能沿用 SimRAS 的在线闭环作为“技能执行器”，MOSAIC 只在技能边界处做类型/契约/接缝检查。于是安全预算沿“叶技能证书 → 接缝 → 整程序证书”三级折叠，形成一个**分形闭环**。

## 1. 形式化定义（增量：定义 266–290）

- **定义 266（技能）**：技能 `s = (π_s, τ_s, C_s, J_s)`，其中 `π_s` 为技能策略，`τ_s` 为技能类型，`C_s` 为接口契约，`J_s` 为技能证书（承接 `J_SimRAS`）。
- **定义 267（技能类型）**：`τ_s = (In_s, Out_s, Frame_s)`，分别描述输入类型、输出类型与框架条件（frame conditions：技能执行后确定不改变的状态谓词集合）。
- **定义 268（接口契约）**：`C_s = (Pre_s, Post_s, Res_s, Rev_s, ε_s)`，即前置条件、后置条件、资源配额、可逆性等级（0 不可逆 / 1 可补偿 / 2 可逆）、风险预算。
- **定义 269（技能范畴 Sk）**：对象为类型化世界状态，态射为技能；复合 `s2 ∘ s1` 有定义当且仅当 `Post_{s1} ⊨ Pre_{s2}` 且 `Frame` 不冲突；单位态射为 `id`（空技能）。
- **定义 270（风险预算代数）**：`𝔅 = ([0,1], ⊕, ⊗, 0)`，其中串行复合 `a ⊗ b = 1 - (1-a)(1-b)`，分支选择 `a ⊕ b = max(a,b)`，单位元为 `0`（零失败概率）。`⊗` 对 `⊕` 单调且分配，故 `(𝔅, ⊗, 0)` 构成幺半结构。
- **定义 271（证书幺半函子）**：`Cert: Sk → (𝔅, ⊗, 0)`，满足 `Cert(id) = 0`，且对可复合的 `s1, s2`：
  `Cert(s2 ∘ s1) = 1 - (1 - Cert(s1))·(1 - Cert(s2))·(1 - Seam(s1, s2))`。
- **定义 272（接缝残差）**：`Seam(s1,s2) = min(1, L_post·gap(Post_{s1}, Pre_{s2}) + β·KL(P_out^{s1} ‖ P_in^{s2}))`，`gap` 为交接状态到目标前置条件集合的加权距离。
- **定义 273（接缝风险上界）**：若 `Post_{s1}` 与 `Pre_{s2}` 的 Lipschitz 常数为 `L_post`，则接缝真实风险不超过定义 272 的值；`KL` 项刻画“状态满足但分布不匹配”的隐状态耦合。
- **定义 274（基础模型技能提议）**：RFM 输出技能程序分布 `P ~ p_θ(P | task, scene)`，`P = (V, E)` 为技能 DAG；实际只取 top-k 提案进入验证。
- **定义 275（MOSAIC 程序）**：程序 `P` 合法当且仅当 (1) 每条边类型正确：`Post_{s_i} ⊨ Pre_{s_j}`；(2) 整程序证书 `Cert(P) ≤ B_task`；(3) 每条边接缝 `Seam(s_i,s_j) ≤ B_seam`。
- **定义 276（组合验证条件）**：`∀e=(s_i,s_j) ∈ E: Cert(s_i) ⊗ Cert(s_j) ⊗ Seam(s_i,s_j) ≤ B_e`，其中 `B_e` 为边预算。
- **定义 277（修复算子）**：`Repair: P × Budget → P'`，操作集为 `{insert_adapter, reorder, substitute, split}`；只在 `Cert(P') ≤ Cert(P)` 时接受。
- **定义 278（整程序证书）**：`J_MOSAIC = (Cert(P), seam_log, repair_trace, skill_hashes, fm_ver)`。
- **定义 279（适配技能）**：`adapter a` 满足 `Pre_a = 缺口状态`、`Post_a = 目标状态`、`Rev_a ≥ 2`，用于填补接缝缺口。
- **定义 280（组合鲁棒性）**：程序在状态扰动 `ε` 下仍满足 `Cert(P) ≤ B_task` 的最大 `ε`，记作 `ε*_comp`。
- **定义 281（技能等价类）**：`s1 ~ s2` 当且仅当 `τ_{s1} = τ_{s2}` 且 `Pre/Post` 双向蕴含，用于安全替换。
- **定义 282（RFM 提议校准）**：`p_θ` 的 top-k 提案中，类型正确率为 `Acc_type`，语义正确率为 `Acc_sem`；语义错误是“类型通过但契约被违反”。
- **定义 283（接缝观测器）**：用视觉-力-本体残差估计交接状态，输出 `Seam` 及其可信区间 `[Seam_lo, Seam_hi]`。
- **定义 284（组合不可逆视界）**：`m_comp = min_{seam} Rev`，即从当前接缝起、在仍需回退前可继续执行的最大技能数。
- **定义 285（修复单调性）**：接受修复当且仅当 `Cert(P') ≤ Cert(P) ∧ m_comp(P') ≥ m_comp(P)`，否则回退原程序。
- **定义 286（分层证书缓存）**：`Cache[(τ_s, hash(C_s))] = J_s`；命中即复用，避免重复验证。
- **定义 287（组合故障假设）**：`H_comp ∈ {H_seam, H_type, H_semantic, H_resource}`，分别对应接缝、类型、语义与资源四类组合故障。
- **定义 288（接缝归因后验）**：`P(H_comp | residual, seam) ∝ p(residual | H_comp)·P(H_comp)`。
- **定义 289（技能替换安全距离）**：`d_sub(s,s') = W_1(π_s, π_{s'}) + ‖C_s - C_{s'}‖`，仅当 `d_sub ≤ τ_sub` 且 `s ~ s'` 时允许替换。
- **定义 290（MOSAIC 总不变式）**：任何时刻执行的技能前缀都满足 `Cert ≤ B_task`；接缝未验证或 `Seam > B_seam` 时，禁止进入下一技能，只能修复、回退或降级为单技能。

## 2. 关键算法骨架

```python
class Skill:
    def __init__(self, policy, type_sig, contract, cert):
        self.pi, self.tau, self.C, self.J = policy, type_sig, contract, cert

    def pre_ok(self, state):  return self.C.Pre(state)
    def post_ok(self, state): return self.C.Post(state)


class SkillCategory:
    def compose(self, s1, s2):
        if not implies(s1.C.Post, s2.C.Pre) or frames_conflict(s1, s2):
            raise TypeMismatch(s1, s2)
        return ComposedSkill(s1, s2)


class SeamEstimator:
    def estimate(self, s1, s2, state, residual):
        gap = state_distance(s1.C.Post, s2.C.Pre, state)
        kl = kl_div(s1.out_dist(state), s2.in_dist(state))
        return min(1.0, self.L_post * gap + self.beta * kl)


class CompositionalCertificate:
    def certify(self, P):
        c = {}
        for node in topo_order(P):
            preds = predecessors(P, node)
            if not preds:
                c[node] = node.J.epsilon
            else:
                acc = 1.0
                for p in preds:
                    seam = self.seam.estimate(p, node, self.state, self.residual)
                    acc *= (1 - (1 - c[p]) * (1 - seam))
                c[node] = 1 - (1 - node.J.epsilon) * acc
        return c[root(P)]


class SkillRepair:
    def repair(self, P, budget):
        for seam in seams_sorted_by_risk(P, reverse=True):
            if seam.risk <= budget:
                continue
            for op in (insert_adapter, reorder, substitute):
                P2 = op(P, seam)
                if self.cert.certify(P2) <= self.cert.certify(P) and reversible_ok(P2):
                    P = P2
                    break
        return P


def MOSAIC_round(M, task, scene):
    proposals = M.rfm.propose(task, scene, top_k=5)
    P = M.sta.typecheck(proposals[0])
    if P is None:
        return fallback_single_skill(M, task)
    P = M.srr.repair(P, M.budget)
    J = M.cmc.certify(P)
    if not valid(J) or J.cert > M.budget:
        return fallback_single_skill(M, task)
    for s in P.topological_order():
        seam = M.seam.estimate(P.prev, s, M.state, M.residual)
        if seam > M.budget_seam:
            P = M.srr.repair(P, M.budget_seam)
            if not valid(M.cmc.certify(P)):
                return fallback_single_skill(M, task)
        M.simras.execute(s)          # 技能内部仍走第 67 轮 SimRAS 闭环
        M.prev = s
    return P, J
```

## 3. 推导

**引理 13（证书函子性）** 若 `Cert` 按定义 271 构造，则对任意可复合三元组 `s3∘s2∘s1`，有
`Cert(s3∘s2∘s1) = 1 - ∏_{i=1}^3 (1-Cert(s_i)) · ∏_{j=1}^2 (1-Seam(s_j,s_{j+1}))`。
即证书与复合的结合顺序无关，可对 DAG 做任意拓扑折叠。

**引理 14（接缝风险次可加）** 设每条接缝的估计误差为 `δ_s`，则整程序接缝总风险满足
`Seam_total ≤ Σ_j Seam(s_j,s_{j+1}) + (n-1)·δ_s`。
因此只要逐边校验 `Seam ≤ B_seam`，总接缝风险被 `(n-1)·B_seam` 线性约束，不会随组合深度指数爆炸。

**定理 14（组合风险上界）** 在定义 266–283 下，整程序真实风险满足
`R(P) ≤ 1 - ∏_{i}(1-ε_i) · ∏_{j}(1-Seam_j) + δ_fm`，
其中 `δ_fm = (1-Acc_type) + (1-Acc_sem)·C_sem` 为基础模型提议误差，`C_sem` 为语义错误的风险放大系数。只要 `Cert(P) ≤ B_task - δ_fm`，整程序即满足任务预算。

**定理 15（修复可靠性）** 若每次修复只在 `Cert(P') ≤ Cert(P)` 且适配技能契约可靠时被接受，则修复序列终止时 `Cert(P_final) ≤ Cert(P_0)`；若初值超预算且存在可修复解，则 `Repair` 至多 `O(|E|)` 次操作后使 `Cert ≤ B_task`。

**定理 16（缓存复用可靠性）** 在哈希碰撞概率 `≤ 2^{-128}` 且 `Cache` 键同时包含类型与契约哈希的前提下，缓存命中的证书与重新验证的证书在 `ε`-容差内一致；即 `|Cert_reuse - Cert_verify| ≤ ε_hash`。

**定理 17（组合不可逆视界单调性）** 沿任意执行前缀，`m_comp` 关于剩余技能数单调不增；当 `m_comp = 0` 时，任何进一步执行都不可回退，故 MOSAIC 必须在 `m_comp = 0` 前完成接缝验证或降级。

## 6. 本轮最大风险

**一句话**：MOSAIC 的全部可靠性依赖“技能接缝可被局部观测并以可加方式估计”，但真实组合的隐状态耦合（夹持力、物体姿态、人的意图）往往在接口处不可见，且 RFM 可能给出“类型正确、语义错误”的技能提案——此时函子性只保证了**局部证书的代数自洽**，却无法保证**全局语义安全**，整程序会带着一张漂亮的证书在真实世界里失效。

# 第 68 轮产物 · 创新点清单 v1：MOSAIC（Modular Safety-Aware Interface Calculus：技能组合的安全代数；SFP×STA×SIC×CRB×SEAM×CMC×SRR×SVC）

> 承接第 67 轮 IP-233~242（SimRAS：仿真增强的风险自适应闭环）。第 65~67 轮解决的是「单段闭环内」的故障、意图与未来风险；本轮解决的是「**多技能程序之间**」的组合安全：机器人基础模型只提出技能符号，不直接签安全字；安全由带类型与契约的技能代数、可折叠的证书函子、以及可修复的接缝共同保证。
>
> IP 编号：IP-243~IP-252（共 10 个），覆盖技能基础先验、类型代数、接口契约、风险预算、接缝估计、组合证书、修复、缓存及与 SimRAS 的闭环集成。

## 2. 形式化定义（完整版）

**定义 266（技能）** 技能 `s = (π_s, τ_s, C_s, J_s)`，其中 `π_s` 为技能策略，`τ_s` 为技能类型，`C_s` 为接口契约，`J_s` 为承接 `J_SimRAS` 的技能证书。

**定义 267（技能类型）** `τ_s = (In_s, Out_s, Frame_s)`。`Frame_s` 是技能执行后确定不改变的状态谓词集合，用于检测框架冲突（例如两个技能都声称拥有同一资源）。

**定义 268（接口契约）** `C_s = (Pre_s, Post_s, Res_s, Rev_s, ε_s)`：
- `Pre_s`：前置条件谓词；
- `Post_s`：后置条件谓词；
- `Res_s`：资源配额（力、时间、算力）；
- `Rev_s ∈ {0,1,2}`：不可逆 / 可补偿 / 可逆；
- `ε_s`：技能自身风险预算。

**定义 269（技能范畴 Sk）** 对象为类型化世界状态，态射为技能。复合 `s2 ∘ s1` 有定义当且仅当：
```
Post_{s1} ⊨ Pre_{s2}   且   Frame_{s1} ∩ Frame_{s2} = ∅
```
单位态射为 `id`（空技能，`Pre=Post=True`）。

**定义 270（风险预算代数）** `𝔅 = ([0,1], ⊕, ⊗, 0)`：
```
a ⊗ b = 1 - (1-a)(1-b)      # 串行复合：至少一次失败
a ⊕ b = max(a, b)           # 分支选择：保守取最大
```
`0` 为零失败概率（幺元）。`⊗` 对 `⊕` 单调且分配，故 `(𝔅,⊗,0)` 构成幺半结构。

**定义 271（证书幺半函子）** `Cert: Sk → (𝔅,⊗,0)`：
```
Cert(id) = 0
Cert(s2 ∘ s1) = 1 - (1-Cert(s1))·(1-Cert(s2))·(1-Seam(s1,s2))
```
对 DAG 程序，递归折叠为：
```
Cert(s) = 1 - (1-ε_s)·∏_{s'∈pred(s)} (1 - (1-Cert(s'))·(1-Seam(s',s)))
```

**定义 272（接缝残差）**
```
Seam(s1,s2) = min(1, L_post·gap(Post_{s1}, Pre_{s2}) + β·KL(P_out^{s1} ‖ P_in^{s2}))
```
`gap` 为交接状态到 `Pre_{s2}` 的加权距离，`KL` 项刻画“状态满足但分布不匹配”的隐状态耦合。

**定义 273（接缝风险上界）** 若 `Post_{s1}` 关于状态的 Lipschitz 常数为 `L_post`，则真实接缝风险不超过定义 272 的估计值加上观测噪声 `δ_s`。

**定义 274（基础模型技能提议）** RFM 输出 `P ~ p_θ(P|task,scene)`，`P=(V,E)` 为技能 DAG。在线只取 top-k 提案进入验证，`k=5`。

**定义 275（MOSAIC 程序）** 程序 `P` 合法当且仅当：
1. 每条边类型正确：`Post_{s_i} ⊨ Pre_{s_j}`；
2. 整程序证书 `Cert(P) ≤ B_task`；
3. 每条边接缝 `Seam(s_i,s_j) ≤ B_seam`。

**定义 276（组合验证条件）**
```
∀e=(s_i,s_j)∈E:  Cert(s_i) ⊗ Cert(s_j) ⊗ Seam(s_i,s_j) ≤ B_e
```
其中 `B_e` 为边预算，`B_task` 由 `⊕` 聚合各边预算。

**定义 277（修复算子）** `Repair: P × Budget → P'`，操作集：
- `insert_adapter`：在缺口接缝插入适配技能；
- `reorder`：重排无依赖技能；
- `substitute`：用等价类内技能替换；
- `split`：把长技能拆为可验证子技能。
仅当 `Cert(P') ≤ Cert(P)` 且 `m_comp(P') ≥ m_comp(P)` 时接受。

**定义 278（整程序证书）**
```
J_MOSAIC = (Cert(P), seam_log, repair_trace, skill_hashes, fm_ver)
```

**定义 279（适配技能）** `adapter a` 满足 `Pre_a = 缺口状态`、`Post_a = 目标状态`、`Rev_a ≥ 2`（可逆），用于填补接缝缺口；其自身证书参与组合折叠。

**定义 280（组合鲁棒性）** 程序在状态扰动 `ε` 下仍满足 `Cert(P) ≤ B_task` 的最大 `ε`，记 `ε*_comp`。

**定义 281（技能等价类）** `s1 ~ s2` 当且仅当 `τ_{s1}=τ_{s2}` 且 `Pre/Post` 双向蕴含；仅等价类内允许替换。

**定义 282（RFM 提议校准）** top-k 提案中类型正确率 `Acc_type`、语义正确率 `Acc_sem`；语义错误定义为“类型检查通过但契约被违反”。

**定义 283（接缝观测器）** 用视觉-力-本体残差估计交接状态，输出 `Seam` 及可信区间 `[Seam_lo, Seam_hi]`；若区间跨过 `B_seam`，保守判定为超预算。

**定义 284（组合不可逆视界）** `m_comp = min_{seam} Rev`，即从当前接缝起、在仍需回退前可继续执行的最大技能数。

**定义 285（修复单调性）** 接受修复当且仅当 `Cert(P') ≤ Cert(P) ∧ m_comp(P') ≥ m_comp(P)`，否则回退原程序。

**定义 286（分层证书缓存）** `Cache[(τ_s, hash(C_s))] = J_s`；命中即复用，避免重复验证。

**定义 287（组合故障假设）** `H_comp ∈ {H_seam, H_type, H_semantic, H_resource}`，分别对应接缝、类型、语义与资源四类组合故障。

**定义 288（接缝归因后验）**
```
P(H_comp | residual, seam) ∝ p(residual | H_comp)·P(H_comp)
```

**定义 289（技能替换安全距离）**
```
d_sub(s,s') = W_1(π_s, π_{s'}) + ‖C_s - C_{s'}‖
```
仅当 `d_sub ≤ τ_sub` 且 `s ~ s'` 时允许替换。

**定义 290（MOSAIC 总不变式）** 任何时刻执行的技能前缀都满足 `Cert ≤ B_task`；接缝未验证或 `Seam > B_seam` 时，禁止进入下一技能，只能修复、回退或降级为单技能。

## 3. 关键算法伪代码

```python
# IP-243 SFP：基础模型技能提议
class SkillFoundationPrior:
    def __init__(self, rfm, top_k=5):
        self.rfm, self.k = rfm, top_k

    def propose(self, task, scene):
        progs = self.rfm.sample_programs(task, scene, k=self.k)
        return sorted(progs, key=lambda p: p.score, reverse=True)


# IP-244/245 STA+SIC：类型与契约检查
class SkillTypeAlgebra:
    def typecheck(self, P):
        for s in P.nodes:
            if not self._well_typed(s):
                return None
        for (a, b) in P.edges:
            if not implies(a.C.Post, b.C.Pre):
                return None
            if frames_conflict(a, b):
                return None
        return P

    def _well_typed(self, s):
        return s.tau.In == s.tau.In and s.C.Pre is not None


# IP-246 CRB：风险预算代数
class RiskBudgetAlgebra:
    def seq(self, a, b):  return 1 - (1 - a) * (1 - b)
    def alt(self, *xs):   return max(xs) if xs else 0.0


# IP-247 SEAM：接缝估计与归因
class SeamEstimator:
    def __init__(self, L_post=1.0, beta=0.5):
        self.L_post, self.beta = L_post, beta

    def estimate(self, s1, s2, state, residual):
        gap = state_distance(s1.C.Post, s2.C.Pre, state)
        kl = kl_div(s1.out_dist(state), s2.in_dist(state))
        seam = min(1.0, self.L_post * gap + self.beta * kl)
        h_comp = self.attribute(residual, seam)
        return {'seam': seam, 'h_comp': h_comp,
                'interval': (max(0.0, seam - 0.05), min(1.0, seam + 0.05))}

    def attribute(self, residual, seam):
        if seam > 0.5:
            return 'H_seam'
        if residual.type_violation:
            return 'H_type'
        if residual.contract_violation:
            return 'H_semantic'
        return 'H_resource'


# IP-248 CMC：组合证书（幺半函子折叠）
class CompositionalCertificate:
    def __init__(self, seam, algebra):
        self.seam, self.alg = seam, algebra

    def certify(self, P, state, residual):
        c = {}
        for node in topo_order(P):
            preds = predecessors(P, node)
            if not preds:
                c[node] = node.J.epsilon
                continue
            acc = 1.0
            for p in preds:
                seam = self.seam.estimate(p, node, state, residual)['seam']
                acc *= (1 - (1 - c[p]) * (1 - seam))
            c[node] = 1 - (1 - node.J.epsilon) * acc
        return c[root(P)]


# IP-249 SRR：技能修复
class SkillRepair:
    def __init__(self, cert, budget_seam):
        self.cert, self.budget_seam = cert, budget_seam

    def repair(self, P, budget):
        current = self.cert.certify(P, P.state, P.residual)
        for seam in seams_sorted_by_risk(P, reverse=True):
            if seam.risk <= budget:
                continue
            for op in (insert_adapter, reorder, substitute, split):
                P2 = op(P, seam)
                new = self.cert.certify(P2, P2.state, P2.residual)
                if new <= current and m_comp(P2) >= m_comp(P):
                    P, current = P2, new
                    break
        return P


# IP-250 SVC：证书缓存
class SkillVerificationCache:
    def __init__(self):
        self.store = {}

    def get_or_verify(self, skill, verifier):
        key = (skill.tau, hash_contract(skill.C))
        if key in self.store:
            return self.store[key]
        cert = verifier(skill)
        self.store[key] = cert
        return cert


# IP-252 MOSAIC 闭环集成
def MOSAIC_round(M, task, scene):
    proposals = M.sfp.propose(task, scene)
    P = M.sta.typecheck(proposals[0])
    if P is None:
        return M.fallback_single_skill(task)

    P = M.srr.repair(P, M.budget)
    J = M.cmc.certify(P, M.state, M.residual)
    if J > M.budget or not valid(J):
        return M.fallback_single_skill(task)

    M.prev = None
    for s in P.topological_order():
        if M.prev is not None:
            seam = M.seam.estimate(M.prev, s, M.state, M.residual)
            if seam['seam'] > M.budget_seam:
                P = M.srr.repair(P, M.budget_seam)
                J = M.cmc.certify(P, M.state, M.residual)
                if J > M.budget:
                    return M.fallback_single_skill(task)
        M.simras.execute(s)     # 技能内部沿用第 67 轮 SimRAS
        M.prev = s

    return P, J
```

## 4. 推导

**引理 13（证书函子性）** 按定义 271 构造的 `Cert` 对任意可复合三元组 `s3∘s2∘s1` 满足
```
Cert(s3∘s2∘s1) = 1 - ∏_{i=1}^3 (1-Cert(s_i)) · ∏_{j=1}^2 (1-Seam(s_j,s_{j+1}))
```
与结合顺序无关，因此可对 DAG 做任意拓扑折叠。证明：`⊗` 结合律由 `1-(1-a)(1-b)` 的乘积形式直接得到，`Seam` 作为额外因子并入同一乘积。

**引理 14（接缝风险次可加）** 设每条接缝估计误差为 `δ_s`，则
```
Seam_total ≤ Σ_j Seam(s_j,s_{j+1}) + (n-1)·δ_s
```
故逐边校验 `Seam ≤ B_seam` 可将总接缝风险线性约束，不随组合深度指数爆炸。

**定理 14（组合风险上界）** 在定义 266–283 下，整程序真实风险满足
```
R(P) ≤ 1 - ∏_i (1-ε_i) · ∏_j (1-Seam_j) + δ_fm
```
其中 `δ_fm = (1-Acc_type) + (1-Acc_sem)·C_sem` 为 RFM 提议误差，`C_sem` 为语义错误的风险放大系数。只要 `Cert(P) ≤ B_task - δ_fm`，整程序即满足任务预算。

**定理 15（修复可靠性）** 若每次修复仅在 `Cert(P') ≤ Cert(P)` 且适配技能契约可靠时被接受，则修复序列终止时 `Cert(P_final) ≤ Cert(P_0)`；若初值超预算且存在可修复解，则 `Repair` 至多 `O(|E|)` 次操作后使 `Cert ≤ B_task`。

**定理 16（缓存复用可靠性）** 在哈希碰撞概率 `≤ 2^{-128}` 且缓存键同时包含类型与契约哈希的前提下，命中证书与重新验证证书在 `ε`-容差内一致：`|Cert_reuse - Cert_verify| ≤ ε_hash`。

**定理 17（组合不可逆视界单调性）** 沿任意执行前缀，`m_comp` 关于剩余技能数单调不增；当 `m_comp=0` 时任何进一步执行都不可回退，故 MOSAIC 必须在 `m_comp=0` 前完成接缝验证或降级。

## 7. 本轮最大风险

**一句话**：MOSAIC 的全部可靠性依赖“技能接缝可被局部观测并以可加方式估计”，但真实组合的隐状态耦合（夹持力、物体姿态、人的意图）往往在接口处不可见，且 RFM 可能给出“类型正确、语义错误”的技能提案——此时函子性只保证了**局部证书的代数自洽**，却无法保证**全局语义安全**，整程序会带着一张漂亮的证书在真实世界里失效。
