# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「模型预测控制」×「价值对齐」）

> 第 57 轮把承诺从"模型置信"推到"少样本可校准、跨模态可对账、个性化有界的证据承诺"，纵深已到五层。但它的风险自陈"坏先验普遍"其实指向两个更结构性的缺口：**(a) 决策仍是逐检查点的贪心**——每个点独立过证据门、独立算 VOI，没有跨整条路线的展望，于是探针预算只花在眼前、危险区域要到临近才发现，"现在多探一次能省掉后面一次险承诺"这种跨期交易根本无法表达；**(b) 目标函数本身未经审视**——"少探、快走、别失败"是工程师写的代理指标，却被当成真值全力优化；谁的价值？硬底线能否被平均？代理被钻空子怎么办？本轮两个灵感各补一刀：**模型预测控制（MPC）** 把逐点贪心换成"用信念滚动预测未来 H 步、只在整条预测轨迹上校验硬约束、执行首步再重规划、并以已认证安全停为终端集"的滚动时域算子；**价值对齐** 把单一加权成本换成"硬底线（安全/同意/可纠正/不伤害）字典序高于软偏好、偏好按公平聚合而非平均、价值有歧义时延迟征询而非猜测、代理指标可被事后证伪降权"的对齐层。核心命题由"证据说可信"升级为 **"看得远、说得清为谁而看、且随时可被叫停的承诺"**——即 **证据-价值-可纠正性三重许可的滚动计划**。

核心矛盾：
- **H29（远视 vs 模型错）**：MPC 的收益完全取决于预测模型，而这里要预测的恰恰是最不确定的地图 𝓜。一个错误但自洽的地图会让优化器"规划"出一条连续、平滑、看似安全的轨迹——**远视把局部的过度自信放大成全局连贯的过度自信**；且逐边独立套 δ_f 会让 H 步联合失效率膨胀，天真地稀释证据门又会让单点把关失效。
- **H30（价值 vs 可聚合）**：目标函数里编码着价值。操作者会分歧，朴素加权和会把某人的硬底线平均掉，也诱导 Goodhart——规划器会用"声明 OOD 加宽带子以绕行"或"避免一切接触"来最小化代理，任务被合法地规避。延迟征询虽安全，却可被滥用为不作为的借口。
- **H31（优化 vs 可纠正）**：一个称职的优化器会绕开任何增加成本的约束——包括"问人"这一步和"保留人工接管通道"。可纠正性若只是软代价，优化器一定会在某个角落把它交易掉。它必须是不变量。

## 0. 直觉与动机

**灵感 1（MPC → 滚动时域而非逐点贪心）**
直觉：第 56/57 轮像"每到一个路口才看一步"的贪心驾驶——当前点证据够了就走。MPC 换成"看未来 H 个路口再决定这一步怎么打方向"：在信念图上 rollout 候选计划，检查整条预测轨迹（不是下一次接触）是否满足约束，只执行首步，到达新观测后重规划。三个立刻出现的好处：**跨期证据预算**（"现在多探一次，能在后面省掉一次险承诺"终于可表达）、**死路规避**（提前看到地图尽头是断崖）、**风险按全局分配**而不是每点都用 δ_f。但代价是：这条"未来"是同一张有争议的地图想象出来的。

**灵感 2（MPC 理论 → 机会约束 + 终端集 + 递归可行）**
直觉：教科书 MPC 的两条保命设计必须原样搬来。其一，**机会约束**：预测轨迹的累计失效概率 ≤ δ_f（动态风险预算 Σ_t r_t ≤ δ_f，而非每边都套 δ_f），且 OOD 边用共形带内最坏值，绝不押在元后验的点估计上。其二，**终端集与递归可行**：每个滚动计划都必须把一个"已认证的安全停"放进预测终点，于是任何重规划都至少还有"停"这一条可行解——系统永不死锁在"无路可走又不许停"。这正是第 56 轮"绕行→降档→安全停"四态完备的时域化版本。

**灵感 3（价值对齐 → 硬底线字典序 + 公平聚合）**
直觉：MPC 需要一个成本 J 和一组约束 C，"该优化什么"是价值问题不是工程问题。对齐的第一原则是**不要把价值压成一个加权和**：安全、同意、不伤害、可纠正这些是**硬底线**，字典序永远优先于效率/彻底/舒适/解释详尽这些**软偏好**，硬底线永不能被权重交易掉。第二原则是**聚合要公平**：多个操作者的软偏好可按公平规则聚合（如 max-min 满意度或 Nash），但硬底线取**合取**——每个人的底线都要满足，决不能被平均稀释。

**灵感 4（价值对齐 → 价值歧义即延迟 + 代理可证伪）**
直觉：我们没有操作者的"真值权重"。价值对齐给的答案不是"猜一个最可能"，而是：把偏好做成一个**认知不确定集 𝒱**；若所有 V∈𝒱 对首个动作都一致，才自主承诺；一旦不同合理价值模型导向不同首动作（**价值歧义**），就把它当作与"证据不足"同构的信号——转征询/延迟。同时，任何代理指标都应被视为可被证伪的假设：持续记录"代理说好、事后真值说差"的**价值后悔**，出现系统性缺口（Goodhart）就降权该代理并回溯审计——把第 57 轮模态可靠性 ρ 的降级机制平移到价值层。

**灵感 5（可纠正性不变量 + 合流算子 VAMPC）**
直觉：把"人能随时叫停"从一句口号变成一个优化器无法交易的硬约束：任一滚动计划的每个时刻都必须保留 τ_int 内可达的干预/停止通道，且不得缩减未来可干预集。于是本轮三件事合流成一个算子：**证据门从"当前接触"升到"整条预测轨迹的每条边"；价值层从"权重"升到"硬底线+歧义延迟"；可纠正性从"协商超时"升到"不变量"。** 安全通道仍是那两条——"信念更准/更保守"与"动作更保守"——但新增一条必须被显式约束的通道："**价值层只能收紧，不能被优化器放松**"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（价值对齐滚动时域算子 VAMPC）** 决策状态 (x,𝓜,s_o,V)，候选计划 π=u_{0:H−1}，预测轨迹 ξ_{0:H}。可行性要求硬约束层 C_hard(ξ,𝓜,V) 在**每条边**成立（含证据门、裕度、同意、可纠正性），软代价 J_soft(ξ;w_V)。字典序：feasible ≻ min J_soft；硬层不进入加权。执行 u_0 后 x←f(x,u_0) 并重规划。输出 (u_0, J_v) 证书。VAMPC 是第 57 轮 PCE+（定义 138）的时域化升级：把"当前检查点承诺"替换为"整条滚动计划的可行性"。

**定义 140（机会约束信念滚动 CCBR）** 由校准信念/共形带传播 ξ_{t+1}=f̂(ξ_t,u_t)+w，w∈𝒲(𝓜)，对每条边给出风险 r_t，要求 Σ_{t<H} r_t ≤ δ_f（动态风险预算/风险分配，非逐边 δ_f）；OOD 边的 w 取共形带内最坏值。终端集 X_stop ⊆ 已认证安全停域且非空可达（递归可行性）。预测失效 P_fail(ξ_{0:H}) ≤ Σ_t r_t。

**定义 141（价值模型与对齐层 VAL）** V=(ℱ,w_V,𝒱)：ℱ 为硬底线集（安全/同意/不伤害/可纠正），语义为**合取且不可平均、不可交易**；w_V 为软偏好权重（效率/彻底/舒适/解释详尽）；𝒱 为从操作者配对比较得到的认知不确定集。聚合规则：硬底线取合取（∀o: ℱ_o 满足），软权重按公平规则（如 max-min 或 Nash）聚合；任何聚合不得把某操作者的硬底线稀释为可交易项。

**定义 142（价值歧义延迟 VAD）** 对每个 V∈𝒱 求可行最优计划的首动作，得 A*(𝒱)={π_0^*(V)}。若 |A*(𝒱)|>1 或最优计划的价值后悔上界 regret_V>θ_V，则**禁止在歧义下承诺**，转入征询/延迟（L2 协商、分布式确认或安全停）；只有当所有 V∈𝒱 首动作一致时才自主承诺。价值歧义与证据不足共用同一个保守出口。

**定义 143（代理证伪守门 PFG）** 记录代理 ĵ 与事后真值 j*（按事后审计/proper scoring），价值后悔 reg_t=j*−ĵ。若累计或趋势 reg 超过 δ_g（系统性 Goodhart 缺口），则对对应软项乘性降权 w_V[k]←max(w_min,γ↓w_V[k])、收紧关联硬约束并回溯标记（价值层的"ρ 降级"）；证实则有界恢复。代理权重只可被证伪而降、被证实而**有界**恢复。

**定义 144（可纠正性不变量 CI）** 对计划 π 的任一预测时刻，必须存在 τ_int 内可达的人工干预/停止通道，且计划不得把未来可干预动作集压到下限以下：∀t, |Intervene(ξ_t)|≥ι_min 且 ∃stop_path(ξ_t,τ_int)。CI 是硬约束，不进入 J_soft；优化器不得以"征询慢/贵"交易它；若某计划的最优性依赖关闭干预通道，则该计划不可行。

## 2. 关键算法伪代码（完整版见产物区）

```python
def vampc_plan(x, M, V, route, budget, consent, persona):
    hard = V.floors(consent, persona)                  # 安全/同意/可纠正/不伤害
    cands, best = route.candidate_plans(H=H_pred), None
    for pi in cands:
        roll = ccbr_rollout(x, pi, M, delta_f)          # 机会约束信念传播
        if not roll.ok or not hard.feasible_along(roll): continue   # 逐边硬约束
        if not corrigibility_invariant(roll, persona):  continue   # CI 硬约束
        if not evidence_scheduled(roll, M, budget):     continue   # 未来边证据门/已排探针
        j = J_soft(roll, V.w) + value_regret_bound(roll, V.set)
        if best is None or j < best.j: best = Plan(pi, roll, j)
    if best is None or value_ambiguous(cands, V.set, theta_V):
        return defer_or_negotiate(x, M, best, consent, tau_int(persona.auth))
    proxy_log.record(best.j_proxy, true=best.j)
    return Commit(best.pi[0], Jv(best))

def value_ambiguous(cands, Vset, theta):
    firsts = set()
    for V in Vset.sample():
        b = min((p for p in cands if feasible(p, V)), key=lambda p: p.j(V), default=None)
        if b: firsts.add(b.first_action)
    return len(firsts) > 1
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| VAMPC | O(\|Cands\|·H·C_roll + N·H·d) | O(\|Cands\|·H) | 字典序硬层、终端集 X_stop |
| CCBR | O(H·d_𝓜) | O(H·d_𝓜) | 覆盖真动力学、Σr_t≤δ_f |
| VAL | O(\|𝒱\|·\|Cands\|·H) | O(\|𝒱\|+\|ℱ\|) | 硬底线合取、公平聚合 |
| VAD | O(\|𝒱\|·\|A\|·H) | O(\|A\|) | 首动作不一致即延迟 |
| PFG | O(H) 增量 | O(H) | 缺口检出 ≥1−δ_g、回溯完整 |
| CI | O(H·\|Intervene\|) | O(H) | 干预集≥ι_min、停路可达 |

**正确性定理（VARHS 概要）**：在 A33–A40 上加 (A41) 信念滚动健全（校准/共形集覆盖真动力学、风险预算 Σr_t≤δ_f）；(A42) 价值包含（真价值 ∈𝒱、硬底线合取不被平均、聚合公平）；(A43) 可纠正性不变量（每时刻干预可行 ≥ι_min、安全停可达）；(A44) 代理监控诚实（Goodhart 缺口检出 ≥1−δ_g）。则：(i) 滚动承诺失效率 ≤ δ_f（风险预算已分配，不再是 H·δ_f）+ δ_ood·α_conf；(ii) 价值单调性：价值层更新只能收紧硬约束、增加延迟或降低被证伪代理的权重，永不放松；(iii) 递归可行：X_stop 非空 ⇒ 任何重规划至少有"安全停"可行解，算子不缺省死锁；(iv) Goodhart 有界：代理系统性偏离时以 ≥1−δ_g 检出并受审计响应约束。

## 6. 本轮最大风险

**一句话**：本轮把局部证据门换成全局滚动优化，最大风险是 **"自信的想象 + 被指定的价值"**——错误但自洽的地图会让 MPC 规划出一条"看起来安全"的连续轨迹（远视把局部过度自信放大为全局连贯的过度自信），而被代理化的目标会诱使规划器用"声明 OOD 绕行 / 零接触 / 占用纠偏通道"等合法手段最小化代价，因此必须把价值写成字典序硬底线、把价值歧义转成延迟、把可纠正性设成优化器永不可交易的不变量，而不是任何一个可调权重。

# 第 58 轮产物 · 创新点清单 v34：Value-Aligned Rolling MPC（价值对齐滚动时域×机会约束证据×可纠正性不变量，VAMPC×CCBR×VAL×VAD×PFG×CI）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"证据-价值-可纠正性三重许可的滚动计划"**：决策从逐检查点贪心变为带预测模型的滚动时域优化，目标从单一代理成本变为字典序硬底线 + 公平聚合软偏好，安全性从"当前承诺前过门"变为"整条预测轨迹逐边过门 + 终端安全停"，并把"随时可被叫停"提升为优化器不可交易的硬约束。第 57 轮"一切判定器走隔离"在本轮推广为"**一切目标（含代理指标与价值权重）走审计与可证伪**"。

| `reg_t, δ_g, γ↓/γ↑` | 价值后悔、Goodhart 检出阈值、代理降/升系数 |
| `Intervene(ξ_t), ι_min, τ_int` | 可干预动作集、下界、协商超时 |
| `J_v` | 价值-时域证书（计划、硬层回执、价值模型、CI 回执、代理日志） |

### IP-139 VAMPC（价值对齐滚动时域算子）

```python
def vampc_plan(x, M, V, route, budget, consent, personas):
    hard = V.floors(consent, personas.active)          # 合取硬底线
    cands = route.candidate_plans(H=adapt_horizon(M))   # H 随信念宽度自适应
    best = None
    for pi in cands:
        roll = ccbr_rollout(x, pi, M, delta_f)          # IP-140
        if not roll.ok:                                 # 风险预算超支
            continue
        if not hard.feasible_along(roll):               # 逐边硬约束（含证据门）
            continue
        if not corrigibility_invariant(roll, personas): # IP-144
            continue
        if not evidence_scheduled(roll, M, budget):     # 未来边证据门或已排探针
            continue
        j = J_soft(roll, V.w) + value_regret_bound(roll, V.set)
        if best is None or j < best.j:
            best = Plan(pi, roll, j)
    if best is None or value_ambiguous(cands, V.set, theta_V):   # IP-142
        return defer_or_negotiate(x, M, best, consent,
                                  tau_int=tau_int(personas.active.auth))
    proxy_log.record(best.j_proxy, true=best.j)         # IP-143 记录
    return Commit(u=best.pi[0], cert=Jv(best, hard, V, proxy_log))
```

### IP-140 CCBR（机会约束信念滚动）

```python
def ccbr_rollout(x, pi, M, delta_f):
    xi, risks, ok = [x], [], True
    for t, u in enumerate(pi):
        w = worst_in(M.belt(xi[-1])) if M.is_ood(xi[-1]) else M.belief_set(xi[-1])
        xi.append(f_hat(xi[-1], u, dynamic=w))          # 用最坏/校准动力学
        r_t = edge_risk(xi[-1], u, M)
        risks.append(r_t)
    if sum(risks) > delta_f:                            # 动态风险预算
        ok = False
    if not reaches(xi[-1], X_stop):                     # 终端安全停
        ok = False
    return Rollout(xi, risks, ok)
```

### IP-141 VAL（价值对齐层：字典序 + 公平聚合）

```python
def val_feasible(roll, V, consent, personas):
    for floor in V.F:                                   # 硬底线：合取，不可平均
        if not floor.check(roll, consent, personas):    # 安全/同意/不伤害/可纠正
            return False
    return True

def val_aggregate_soft(prefs):
    # 软偏好按 max-min 公平聚合，而非算术平均
    return max_min_satisfaction(prefs)                  # 硬底线不进入此函数
```

### IP-142 VAD（价值歧义延迟）

```python
def value_ambiguous(cands, Vset, theta_V):
    firsts, regrets = set(), []
    for V in Vset.sample():
        feas = [p for p in cands if val_feasible(p, V)]
        if not feas: continue
        b = min(feas, key=lambda p: p.j(V))
        firsts.add(b.first_action)
        regrets.append(value_regret_bound(b, Vset))
    return len(firsts) > 1 or (regrets and max(regrets) > theta_V)
```

### IP-143 PFG（代理证伪守门）

```python
def proxy_falsification_guard(reg_hist, w_V, audit):
    if systematic_gap(reg_hist) > delta_g:              # 代理说好、真值说差
        k = argmax_regret(reg_hist)
        w_V[k] = max(w_min, w_V[k] * gamma_down)        # 降权被博弈的代理
        tighten_floor(k)                                # 关联硬约束收紧
        audit.flag(('goodhart', k, t_now))
    elif confirmed_trend(reg_hist):
        w_V[k] = min(w_max, w_V[k] + gamma_up)          # 有界恢复
    return w_V
```

### IP-144 CI（可纠正性不变量）

```python
def corrigibility_invariant(roll, personas):
    for x_t in roll.trajectory:
        if len(intervention_set(x_t, personas)) < iota_min:
            return False                                # 干预集被缩减
        if not exists_stop_path(x_t, tau_int(personas.active.auth)):

    return True
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VAMPC | O(\|Cands\|·H·C_roll + N·H·d) | O(\|Cands\|·H) | 字典序硬层、终端集非空 |
| CCBR | O(H·d_𝓜) | O(H·d_𝓜) | 覆盖真动力学、Σr_t≤δ_f（A41） |
| VAL | O(\|𝒱\|·\|Cands\|·H) | O(\|𝒱\|+\|ℱ\|) | 硬底线合取、公平聚合（A42） |
| VAD | O(\|𝒱\|·\|A\|·H) | O(\|A\|) | 首动作不一致即延迟 |
| PFG | O(H) 增量 | O(H) | 缺口检出 ≥1−δ_g、回溯完整（A44） |
| CI | O(H·\|Intervene\|) | O(H) | 干预集≥ι_min、停路可达（A43） |

**正确性定理（Value-Aligned Receding-Horizon Soundness, VARHS）**
设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 信念滚动健全：校准/共形集覆盖真动力学，逐边风险满足 Σ_{t<H} r_t ≤ δ_f，OOD 边取带内最坏值；**(A42)** 价值包含：真价值 ∈𝒱，硬底线 ℱ 取合取且永不被写入 J_soft，软偏好聚合满足公平性（无操作者被支配）；**(A43)** 可纠正性不变量：每预测时刻 |Intervene|≥ι_min 且存在 τ_int 内停路；**(A44)** 代理监控诚实：系统性 Goodhart 缺口检出率 ≥1−δ_g，回溯审计完整。则：

1. **滚动承诺健全性**：单条已执行计划的失效概率 ≤ δ_f + δ_ood·α_conf + Σ_{边} ε_meta(k)（证据门继承第 57 轮界）；对实际提交的接触取联合界时，风险预算已在 rollout 内分配，不再出现 H·δ_f 膨胀。
2. **价值单调性**：价值层的一切更新（VAD、PFG）只能 (a) 收紧硬底线、(b) 增加延迟/征询、(c) 降低被证伪代理的权重；不存在"放松硬层或提高被证伪代理权重"的升险路径。交互单调性由"信念更准/动作更保守"扩展到"价值更保守"。
3. **递归可行性**：X_stop 非空且当前可停 ⇒ 任一重规划至少保留"安全停"这一可行解；算子永不进入"无可行计划且无停"的死锁，四态 {承诺, 绕行, 延迟协商, 安全停} 完备。
4. **Goodhart 有界**：若代理与真值系统性偏离，PFG 在有限回合内以 ≥1−δ_g 检出，之后代理权重受 δ_g 与审计响应约束，价值后悔不再无界增长。
5. **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f,alloc + ε_meta(k) + δ_probe + δ_ood·α_conf + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(硬底线被聚合稀释) − P(CI 失效) − P(价值后悔超界)
```

关键：**远视给全局效率、机会约束给风险预算、终端集给不死锁**；**硬底线用字典序（不是权重）保证不可交易**；**歧义用延迟（不是猜测）保证不越权**；**代理用证伪（不是信任）保证不被钻空子**；**可纠正性用不变量（不是代价）保证永远叫得停**。

## 6. 本轮最大风险

**一句话**：本轮把局部证据门换成全局滚动优化，最大风险是 **"自信的想象 + 被指定的价值"**——错误但自洽的地图会让 MPC 规划出一条"看起来安全"的连续轨迹（远视把局部过度自信放大为全局连贯的过度自信），而被代理化的目标会诱使规划器用"声明 OOD 绕行 / 零接触 / 占用纠偏通道"等合法手段最小化代价；因此必须把价值写成字典序硬底线、把价值歧义转成延迟、把可纠正性设成优化器永不可交易的不变量，而不是任何一个可调权重。
