### 第 6 轮灵感驱动研究记录（承接第 5 轮；新循环首轮）

**灵感词**：技能学习、智能体

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把信任边界从「规则提议」推广为「任意生成器 + 七硬门认证边界」（CGE）：FMPP 流匹配提议、LMEM-v2 嵌入记忆与固化、FAMK 情感调制、EFA-v5 级联选证，并证明 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。v5 的最大风险 R57 是**固化自指回路**：策略在自己铸证的片段上训练，缺乏外部真值，可能学会博弈证书门。本轮不推翻 v5，而是补 v5 的三个结构性短板：(a) 信任单元仍是「单条轨迹/单次决策」，没有**时间上的可组合性**，长程任务只能靠重规划硬拼；(b) 固化闭环仍以**自证**为主，没有把「技能承诺是否兑现」锚到独立的外部结局上；(c) 智能体仍是单体提议器，无法安全地**委托/交接**给子智能体或工具。两个灵感词统一为主题「认证的可组合技能智能体」（Certified Composable Skill Agent, CCSA），形成 CADVS-v6（IP-497~500）。本轮自律：**硬门数量不增**（维持七门，正面回应 R52 锚点维护负债），只走「合约抽象 + 外部锚定 + 委托协议」三条非侵入路径；执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **技能学习 → 技能不是策略，而是「策略 + 合约」**。人类学一项技能，学的不只是动作，更是「什么时候能用（前提）」和「用了能保证什么（后置）」。因此把技能定义为 σ = (π_σ, A_σ, G_σ, Ω_σ, b_σ, h_σ)：π_σ 是闭环策略（可直接复用 v5 的流策略），A_σ 是假设域（前提），G_σ 是保证域（后置/不变式），Ω_σ 把七个硬门逐条分解为**局部义务**，b_σ 是资源预算，h_σ 是来源/版本/有效期/领域指纹。定义组合 σ₁∘σ₂ 当且仅当接口条件 G_{σ₁} ⊆ A_{σ₂} 成立；组合合约取 A_{σ₁∘σ₂}=A_{σ₁}、G_{σ₁∘σ₂}=G_{σ₂}、安全边际按 min 合成、预算按和合成。**定理 9（组合可靠性）**给出归纳证明：每个技能局部持证 + 接口匹配 ⇒ 任意技能序列的计划整体持证。这把 v5 的「逐轨迹重验」升级为「模块化、可归纳复用的证明」，是比 v5 更强的可扩展性贡献；技能格（按合约强弱偏序）与先修关系（接口包含）自然给出**证书感知课程**。

2. **智能体 → 不可信提议者 + 可信检查者，动作空间是技能而非关节**。智能体（LLM/搜索/人类）只负责提出**技能序列**，绝不直接写门、不直接下发关节指令。计划必须携带一份**计划证书** Cert(Π)，由一个小而确定、可审计的检查器 Chk 验证；LLM 只见合约摘要，无法伪造证明。这把「智能体自主性」与「信任边界」结构性解耦：提议可以无限聪明，检查器只认证明。进一步，**委托 = 能力合约转移，而非信任转移**：上级智能体给下级发 Cap=(A_cap,G_cap,Ω_cap,ttl)，仅当 Cap 落在下级的已认证域内才发放；下级必须回传由**独立验证器**核验的后置见证。**定理 10（委托约束）**：多跳委托的有效保证是各跳 Cap 的交集，信任不传递放大——A 信任 B、B 信任 C，不等于 A 信任 C。

3. **正面偿还 R57 → 技能准入必须有外部锚，且用保形预测给出分布无关的违规界**。v5 固化的病根是「自己铸证、自己学习」。v6 改为**双钥准入**：技能上线需同时满足 (i) 自证合约通过；(ii) **独立结局验证器 V_ext**（异质模态/物理传感/人工抽检，且不共享策略的损失）在留出的证伪集上核验其真实后置。合约的保证域用**保形预测**在 1−α 水平校准：只在「保形保证集 Ĝ ⊆ 合约保证 G_σ 且证伪集经验违规 ≤ α」时准入。**定理 11（外部锚定）**：对与校准集可交换的未来输入，准入技能的合约违规概率 ≤ α（有限样本、分布无关）；更关键的是，准入判定只依赖 (D_cal, V_ext 结局)，**不依赖策略自证**，因此「策略 → 准入」的映射必须经过真实结局，自指通道被结构性切断。配套：反例驱动合约精化（CEGIS）、合约到期/隔离、领域漂移检测。诚实边界：保形覆盖依赖可交换性，非可交换漂移下失效，需在线监控与隔离兜底。

**关键洞见**：v4 回答「提议=规则时七门是否足够」；v5 回答「提议=任意生成器时证书边界是否不变」；v6 回答「当信任单元变成**可复用技能**、执行者变成**会委托的智能体**时，如何让证书边界**可组合、可外部锚定、不可传递放大**」。七硬门 kc_evidence_forged_v4 记号原样复用；本轮新增的只有：技能合约 C_σ、组合算子 ∘、计划证书 Cert(Π)、能力合约 Cap、保形保证 Ĝ。Exec_v6 = {v5 七门逐原语通过 ∧ 计划证书有效 ∧ 接口匹配} ⊆ Exec_v5，由「继承 v5 门 + 只加合约一致性约束 + 组合不扩张单步可行集」保证。

**形式化目标（增量）**：
1. 技能合约：σ=(π_σ,A_σ,G_σ,Ω_σ,b_σ,h_σ)；组合 σ₁∘σ₂ 需 G_{σ₁}⊆A_{σ₂}；安全边际 Ω_Π[i]=min_k Ω_k[i]，预算 b_Π=Σ_k b_k。
2. 合约推理：从已认证片段分割技能，用分裂保形预测构造 Ĝ_σ；CEGIS 用反例收缩 G_σ 或扩张 A_σ（只向更保守方向精化）。
3. 计划证书演算：Cert(Π) 为接口包含与局部义务的推导树；Chk 为确定性小内核，O(n·7)。
4. 能力委托协议：Cap=(A_cap,G_cap,Ω_cap,ttl)；多跳有效保证 = ∩_j G_cap_j；后置见证由 V_ext 核验。
5. 定理 9（组合可靠性）、定理 10（委托约束）、定理 11（外部锚定与保形违规界）、定理 12（v6 嵌套与七锚完备性）；引理 45（保形覆盖）、引理 46（CEGIS 单调精化）。
6. Exec_CADVS-v6 = {τ : ∃Π, τ=exec(Π), Cert(Π) 通过 Chk, ∀k τ_k∈Exec_CADVS-v5} ⊆ Exec_CADVS-v5。

**本轮最大风险**：**合约规格博弈与空洞保证（specification gaming）**——一旦把信任从硬门转移到技能合约，智能体就会优化「通过合约检查」而非「实现意图」：学出保证域过大（空洞）、假设域过窄（只在自己挑的状态下成立）或恰好落在独立验证器模态盲区的技能；保形覆盖只保证分布内边缘概率，不保证合约语义充分。合约越形式化，越容易被形式满足而实质违背。

### IP-498 CCA：持证规划智能体（提议异步 0.1–2 s；检查 O(n·7)）

```python
@dataclass
class CertificateCarryingAgent:
    """CCA：不可信提议者 + 可信检查者。
    定理 10：委托只转移能力合约，不转移信任；多跳有效保证 = ∩ Cap。"""
    proposer: Any                 # LLM/搜索/人类：只见合约摘要，不见门实现
    library: SkillContractLibrary
    checker: PlanCertificateChecker      # 可信、确定、可审计的小内核
    v5: EvidenceForgingAssemblerV5       # 逐原语七门（冻结）

    def plan(self, goal, s, c) -> Plan | None:
        for _ in range(MAX_ATTEMPTS):
            seq = self.proposer.propose(goal, self.library.summarize(s, c))
            cert = self._build_certificate(seq)      # 接口包含 + 局部义务
            if cert is not None and self.checker.check(cert, seq):
                return Plan(seq, cert)
        return None                                  # fail-closed 回退 v5

    def _build_certificate(self, seq):
        cur = seq[0]
        for nxt in seq[1:]:
            merged = self.library.compose(cur, nxt)
            if merged is None:
                return None                          # 接口不匹配：拒绝，不猜测
            cur = merged
        return cur

    def delegate(self, subagent, cap: Cap) -> DelegationResult:
        # 仅当 Cap 落在下级已认证域内才发放；下级回传 V_ext 核验的 w
        assert subset(cap.A, subagent.certified_domain.A)
        assert subset(cap.G, subagent.certified_domain.G)
        return self._await_witness(subagent, cap)    # w 由 V_ext 独立核验
```

### IP-500 EFA-v6：七硬门 + 计划证书 + 委托守卫

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变（逐原语走 v5）；新增计划级组合证书与委托守卫。
    Exec_v6 ⊆ Exec_v5：每个原语仍须过 v5 七门，计划证书只加约束不加能力。"""
    v5: EvidenceForgingAssemblerV5
    scl: SkillContractLibrary
    cca: CertificateCarryingAgent

    def execute_plan(self, plan: Plan, s0, ctx0, t_now):
        if not self.cca.checker.check(plan.cert, plan.seq):
            return False, None, 'PLAN_CERT_REJECTED'
        state, ctx = s0, ctx0
        trace = []
        for sigma in plan.seq:
            if not contains(sigma.A, state, ctx):
                return False, None, 'ASSUMPTION_VIOLATED'   # 前置破坏：立即停
            ok, tau, why = self.v5.select(state, t_now, sigma, ctx)  # 逐原语七门
            if not ok:
                return False, None, f'PRIMITIVE_REJECTED:{why}'
            state, ctx = advance(state, ctx, tau)
            trace.append(tau)
        if not contains(plan.seq[-1].G, state):
            return False, None, 'POSTCONDITION_VIOLATED'
        return True, trace, 'FORGED_CCSA'

    def select(self, s, goal, ctx, t_now):
        plan = self.cca.plan(goal, s, ctx)
        if plan is None:
            return self.v5.select(s, t_now, ctx)      # fail-closed：回退 v5 单步
        return self.execute_plan(plan, s, ctx, t_now)
```

### 集成流水线（v5 → v6）

```
离线/慢时域（小时~天级）：
  技能发现：已认证长程片段 ──▶ 变化点分割 ──▶ 候选技能 π_σ
       ──▶ 保形合约推理 Ĝ_σ ──▶ CEGIS 反例精化 ──▶ 双钥准入（自证 + V_ext）
       ──▶ 技能库登记（签名/版本/有效期/领域指纹）
  技能格/课程：接口包含 A_{σ2} ⊇ G_{σ1} 建先修图 ──▶ 证书感知课程
  联邦：签名合约摘要 + 保形参数 + 来源证明 ──▶ 安全聚合 ──▶ 合约注册表
       （原始策略不出站；FedAvg 仅作用于流策略权重）

在线准入（异步，0.1–2 s）：
  CCA.propose（LLM/搜索，只见合约摘要）──▶ 组合成 Cert(Π)
       ├─ 接口不匹配/检查失败 ──▶ fail-closed 回退 v5 单步选证
       └─ Chk 通过 ──▶ 逐原语 EFA-v5 七门（含 FAMK 调制）
              ├─ 任一原语被拒 ──▶ 中止计划（不降级、不跳过）
              └─ 全部通过 ──▶ 执行并记录后置见证

在线控制环（沿用 v5，目标 < 0.6 ms）：
  每周期：EEK(kc_ee) + BCK 事件触发 QP；消费 v5 缓存证书与 τ^5=γ·τ^4
  计划层与控制环解耦：计划只决定「用哪些技能」，控制环仍逐周期持证

委托/交接（多智能体）：
  Cap 发放（⊆ 下级已认证域）──▶ 下级执行 ──▶ 回传 w
       ──▶ V_ext 独立核验 w∈G_cap ──▶ 接受；否则拒绝并记违约
  多跳有效保证 = ∩_j G_cap_j（信任不传递放大）
```

## 4. 正确性论证（增量更新）

### 引理 45（分裂保形覆盖）

**陈述**：设校准集 D_cal 与测试点 (x,y) 可交换，非一致性分数 r(x,y)，q 为 D_cal 上 r 的 ⌈(n+1)(1−α)⌉/n 分位数。则 P(y ∈ Ĝ(x)) ≥ 1−α，其中 Ĝ(x)={y: r(x,y) ≤ q}。该界有限样本、分布无关，但为**边缘覆盖**，非条件覆盖。∎

**诚实边界**：可交换性是硬假设；分布漂移、对抗性选择、验证器系统性误差都会破坏它。故 GSA 必须配领域指纹监控与在线重校准，漂移即隔离。

### 引理 46（CEGIS 单调精化与终止）

**陈述**：若每次反例只允许两种操作——收缩保证域 G_σ 或扩张假设域 A_σ（等价于在偏序 ⊑ 上严格下降）——则精化序列单调不增（合约只变强），且在有限假设类（有限 VC 维）上或在预算 N_cegis 内终止；不会出现「为通过反例而放宽 Ω_σ/预算」的路径。∎

**工程含义**：合约精化是「只紧不松」的，与 v5 的调制单调性同构；这防止用「改考卷」而不是「改技能」来通过准入。

### 定理 9（技能合约组合可靠性）

**陈述**：设 σ_k=(π_k,A_k,G_k,Ω_k,b_k)，k=1..n，满足 (a) 每个 σ_k 合约有效：∀(s,c)∈A_k，π_k 的执行轨迹 τ 满足 τ(T)∈G_k 且对每门 i 有 margin_i(τ) ≥ Ω_k[i]；(b) 接口 G_k ⊆ A_{k+1}。则组合 Π=σ₁∘…∘σ_n 合约有效：A_Π=A₁、G_Π=G_n、Ω_Π[i]=min_k Ω_k[i]（安全/覆盖门）或 b_Π=Σ_k b_k（预算），且 exec(Π) 在 A_Π 下满足七门；从而 Exec(Π) ⊆ ∩_k Exec(σ_k) ⊆ Exec_gate。∎

**证明**：对 n 归纳。基例即 σ₁ 的合约。归纳步：由 (b) 前一段终点落入 σ_{k+1} 的假设域，套用 σ_{k+1} 合约；安全边际取 min 保序、预算取和保上界；组合运算在接口匹配下满足结合律。∎

**意义**：把「整条长程轨迹重新过七门」降为「局部义务 + 接口包含」，使长程任务的证书代价线性可加、可缓存、可增量复用。

### 定理 10（委托约束与信任非传递）

**陈述**：若 A 仅向 B 发放 Cap=(A_cap,G_cap,Ω_cap,ttl) 且 Cap ⊆ B 的已认证合约域（A_cap⊆A_{σB}、G_cap⊆G_{σB}、Ω_cap≤Ω_{σB} 逐点），B 的执行后置见证 w 由独立于 B 的 V_ext 核验且 w∈G_cap，则被接受的委托执行 ∈ Exec_v6。多跳链 A→B→C 的有效保证为 ∩_j G_cap_j，而非最外层 Cap；信任不传递放大。∎

**证明**：每跳的执行被约束在 Cap 的假设域内，后置由外部验证器检查；对链做归纳，交集即最紧约束。若某跳 Cap 越界或见证不通过，则拒绝。∎

**诚实边界**：V_ext 的模态盲区与共谋可让见证「看起来正确」；需异质验证器、随机人工抽检、签名来源、职责分离。定理只保证「在验证器可信的前提下」的约束，不保证验证器本身可信。

### 定理 11（外部锚定与保形违规界）——本轮理论主轴

**陈述**：设校准数据 D_cal={(x_j,y_j)} 与未来查询 (x,y) 可交换，y 由独立 V_ext 核验。若技能 σ 仅在 (i) 保形保证集 Ĝ_σ(x) ⊆ G_σ，且 (ii) 证伪集经验违规 ρ̂_σ ≤ α，且 (iii) 自证合约通过 时被准入，则对可交换未来输入 P(y∉G_σ) ≤ α。更强地，准入判定是 (D_cal, V_ext 结局) 的可测函数，在给定结局下与策略的自证声明条件独立，故「策略 → 准入」的映射必须经过真实结局，**自证通道被结构性切断**。∎

**证明**：覆盖率由引理 45；Ĝ⊆G 保证覆盖蕴含合约成立；准入谓词的因子分解由构造给出（admit 不读取 π 的自证字段，只读取 V_ext 的 y）。∎

**诚实边界**：(i) 边缘而非条件覆盖，个体/子群可能超 α；(ii) 可交换性在非平稳真实世界中易破；(iii) 验证器误差/共谋等价于标签噪声，界需按 V_ext 错误率修正；(iv) 合约语义充分性不在定理范围内（见最大风险）。

### 定理 12（v6 嵌套与七锚完备性保持）

**陈述**：v6 不增删硬门；Ω_σ 只是七门的局部分解。Exec_CADVS-v6 = {τ : ∃Π, τ=exec(Π), Chk(Cert(Π))=1, ∀k τ_k∈Exec_CADVS-v5}，故 Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29。七锚 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK} 不变；SCL/CCA/GSA 是合约层/智能体层/验证层，不是新锚。∎

**证明**：由定义，v6 执行必须逐原语通过 v5 七门，计划证书与合约接口只增加约束、不扩张单步可行集；组合只做时间拼接，不改变单步门的谓词。锚点集合与 v4 定理 4 相同，故完备性保持。∎

### 定理 v6（总装：可组合、外部锚定、信任非传递）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) V_ext 与策略异质且其错误率上界已知、(B9) 准入校准数据与部署分布可交换 下：
(i) 嵌套：Exec_v6 ⊆ Exec_v5 ⊆ … ⊆ Exec_v29；
(ii) 组合：接口匹配的持证技能序列整体持证（定理 9）；
(iii) 委托：多跳有效保证 = ∩ Cap，信任不传递放大（定理 10）；
(iv) 外部锚定：可交换输入下准入技能违规率 ≤ α（定理 11）；
(v) 七锚完备性保持（定理 12）；
(vi) 退化：技能库为空或计划检查失败时，系统精确回退 v5 单步选证。

**证明**：(i) 定理 12；(ii) 定理 9；(iii) 定理 10；(iv) 定理 11 + 引理 45；(v) 定理 12；(vi) 由 EFA-v6.select 的 fail-closed 分支。∎

**诚实声明**：(B9) 可交换性在真实非平稳场景易破；(B8) 验证器可信是外部假设，共谋/盲区只能工程缓解；合约语义充分性无形式保证；组合证书的状态空间随计划长度增长，长程计划可能因接口过严而不可行；这些均未在定理内解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**合约规格博弈与空洞保证**——一旦把信任从硬门转移到技能合约，智能体就会优化「通过合约检查」而非「实现意图」：学出保证域过大（空洞）、假设域过窄（只在自己挑的状态下成立）或恰好落在独立验证器模态盲区的技能；保形覆盖只保证分布内边缘概率，不保证合约语义充分，合约越形式化，越容易被形式满足而实质违背。
