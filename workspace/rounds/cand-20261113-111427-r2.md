# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序」IP-214~223；灵感循环第 2 轮；本轮灵感：「文化适应性」×「强化学习」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，用视觉、动作分块与主动判别探针把「谁坏了」从不可辨识变成可分离，并用「长预测、短执行」把块级承诺压回不可逆视界。它自述的最大风险是：**归因依赖「故障属于有限假设集、且视觉与几何失效相互独立」这两个隐藏假设；真实世界常出现未知的复合故障与共因失效（透明/镜面/对抗 patch 同时骗过几何与视觉），此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统因「已经归因」而更自信地继续执行。** 本轮不试图把假设集再扩大一格，而是换一个提问方式：第 65 轮问「**这一次是谁坏了**」，CARE 问「**在这个部署里，什么才算坏、什么算正常，以及我们凭什么相信这个判断本身**」。本轮核心命题是：
>
> **把「故障可归因」升级为「规范可适应、假设可生长」：文化先验提供跨部署的少样本上下文，强化学习提供「何时探、探什么、何时问人、何时扩容假设」的元策略，证书保证适应只在安全壳内、每次更新可归因、可回滚。**

## 0. 直觉与动机

**灵感 1（文化适应性 → 可证伪的部署先验，而非身份标签）**
直觉：VISTA 的阈值与先验是「文化无差」的：`f_light`、`TAU_C`、`α_chunk`、各故障先验 `P(H)` 都由实验室统一设定。但部署不是实验室。同一句「把抽屉关好」，有的家庭习惯轻推到位，有的场所习惯用力压合；同一个力残差，在手术室是异常，在木工房是日常；哪些物体可抓、哪些区域可近、什么速度算「慢」，都是部署级约定。**因此「文化」在本轮不是国籍/族群标签，而是一个从行为与环境推断出的隐变量 z：它刻画该部署对任务顺序、物体可供性、交互距离、力度风格与风险容忍的约定。** 它至少给 VISTA 补三样东西：(i) 故障假设的**先验**——这个部署里哪类异常更可能；(ii) 软安全裕度的**起点**——冷启动时不必从零试错；(iii) 未知故障的**合理范围**——新假设不是从全空间均匀冒出，而是从该部署的约定附近生长。但必须同时承认：文化先验极易退化为刻板印象，甚至被用来「合法化」安全违规。因此它必须**软、可证伪、可被个体证据推翻**，且只能移动软壳，绝不能移动硬安全约束。

**灵感 2（强化学习 → 只学「如何适应」，不学「物理真值」）**
直觉：VISTA 的适应是手工规则：归因到 H_force 就重标定，归因模糊就做 AFA。它没有回答一个序列决策问题：**在有限的风险/时间/人类耐心预算下，应该先探物理、先问人、先看演示，还是先什么都不做？** 这正是约束部分可观测 MDP（CPOMDP）的形态，强化学习（尤其是离线元 RL + 保守在线 bandit）适合求解。但 RL 只能被允许学习**元策略** π_η：选择适应动作、安排取证顺序、决定何时提交更新；它不得学习物理真值、不得修改硬约束、不得在实时环内更新。文化先验是元 RL 的层级先验，让跨部署冷启动样本效率更高；元 RL 反过来更新文化后验。二者构成「先验—取证—更新」的双层闭环，而底层物理策略仍由 VISTA 证书逐块认证。

**灵感 3（文化 × RL × VISTA → 把「有限假设集」升级为「开放世界假设生长」）**
直觉：VISTA 的最大风险是有限 ℋ 遇到未知复合故障时被迫归因。文化先验帮不上「无限假设」本身，但它能改变**新假设的先验质量**：在某个部署里，某些新故障更合理。真正解决「被迫归因」需要三件事同时发生：(i) **可生长**——新故障可作为新假设被接纳，而不是塞进最近邻；(ii) **可拒绝**——证据不足时必须允许输出 `unknown_fault`，并保守膨胀一个「未知球」；(iii) **可审计**——接纳新假设要有统计保证，不能因为「看起来像」就加。用 e-value + e-BH 控制新假设的误发现率，用文化先验（CRP 的浓度参数）给出新假设的先验质量，再用 RL 决定「是否值得花一次探针去区分新假设与已知假设」。**这样，文化提供先验，RL 提供取证，e-value 提供门槛，三者共同替代「强行归入最近假设」。**

**灵感 4（合流 → CARE：Culture-Aware, Risk-bounded Evolution，文化知情、风险有界的策略进化）**
CARE 闭环：文化后验（CLP）→ 文化条件故障先验 → 开放世界假设生长（OGH）→ 元适应策略（MAR）选择「探针/问人/演示/扩容/重标定/不动」→ 干预因果审计（ICA）判断更新是否真的有效 → 文化安全壳（CSE）限制只能动软参数 → 适应证书与悔界（RCB）决定提交或影子运行 → 影子适应与回滚（SAR）→ VISTA 执行。核心原则是**「适应即实验」**：每次更新都是一次带随机化/重叠性检查的因果干预；不能识别的更新只进影子，不进线上。第 65 轮是「几何-技能-干扰-接触-归因」五层，CARE 在其上增加「**部署上下文层**」与「**适应元层**」，并让这两层都受同一张证书约束。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → FIR-C**：故障先验变为文化条件 `P(H|z)`；当 OGH 输出 `unknown` 时，不得强行取 argmax，转入联合未知球。
- **AFA → CPE**：探针集从物理探针扩到文化探针（问人、看演示、被动观察），目标从 `I(ℋ;ρ)` 扩为 `I((ℋ,z);ρ_new)`，并对易损物体优先非接触探针。
- **RSC-V → RSC-C**：不确定球增 `r_cult`（文化先验失配）与 `r_open`（未知故障），只在对应证据出现时膨胀，避免「一有不确定就全膨胀」。
- **WCV-V → WCV-C**：搜索域增文化软约束与开放世界未知鲁棒化；归因模糊时对 `(H,z)` 联合边缘化。
- **CSP-V → CSP-C**：技能代价增文化规范代价；技能选择以 z 为条件，但硬前置条件不变。
- **AIC-V → AIC-C**：干扰集增文化漂移、欺骗性演示、奖励黑客、刻板印象利用，以及「文化被当作放宽安全裕度的借口」。
- **OLP / DIR / SSB**：元学习与因果审计只在语义流；实时流只保留硬约束守卫、软壳检查与回滚触发。
- **J_vista → J_care**：证书增 `cult_posterior`、`cult_kl`、`hyp_set_ver`、`og_status`、`adapt_ate_lcb`、`regret_ucb`、`causal_id`、`soft_only`、`rollback_hash`、`fair_ver`。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（CARE 闭环）**：CARE = (VISTA, CLP, OGH, MAR, CSE, ICA, CPE, RCB, SAR, J_care)。定位：VISTA 的「部署自适应 + 开放世界」升级。不变式：**硬物理约束、实时安全路径与 VISTA 的认证前缀不随文化改变、不被 RL 更新；只有软规范、故障先验、探针策略与假设集可在语义流中适应；所有提交式更新必须通过因果审计与安全壳检查。**

- **定义 234（文化隐变量与层级先验 CLP）**：文化隐变量 `z ∈ Z` 表示部署级行为约定（任务顺序、物体可供性、交互距离、力度风格、风险容忍）。总体先验 `p_0(z)` 由多个部署离线得到；部署后验 `p(z|D_t) ∝ p_0(z) ∏_{ξ∈D_t} p(ξ|z)`。约束：(i) **KL 预算** `KL(p(z|D_t)‖p_0(z)) ≤ ε_cult`，防止少样本过拟合；(ii) **个体覆盖**：当个体似然比 `LR_ind = p(D_ind|z_ind)/p(D_ind|z_group) > τ_ind` 时，个体模型优先；(iii) **文化只由行为/环境特征推断，不使用受保护属性**（定义 247）。

- **定义 235（文化条件故障先验）**：`P(H|z) ∝ exp(ψ(H,z))`，其中 ψ 由离线跨部署数据拟合。文化只调制**先验与软阈值**（如「该部署中大力压合是否常见」「多大距离算过近」），不调制硬力限、碰撞距离、关节限位。形式化：`p(ρ|H,z)` 与 `P(H|z)` 可依赖 z，但硬约束集 `Θ_hard` 对任意 z 不变。

- **定义 236（开放世界假设生长 OGH）**：已知假设集 `ℋ_t`，新残差簇 `C`。以已知混合 `p_mix` 为零假设，构造 prequential e-value
  `e(C)=∏_{i∈C} p_new(ρ_i|ρ_{<i}) / p_mix(ρ_i)`。
  在零假设下 `E[e(C)]≤1`。若 `e(C)≥1/α_og`，接纳新假设 `H_new`，其 CRP 先验质量 `P(H_new)=γ/(γ+n)`（γ 可由文化后验给出）；若多个簇同时候选，用 e-BH 控制 FDR≤α_og。若未通过，则输出 `unknown_fault`，**禁止强行归因**，转入保守联合未知球 `r_open`。

- **定义 237（元适应约束 POMDP）**：元状态 `s_t=(x_t, post_t, p(z|D_t), ℋ_t, cert_t)`；元动作 `a_t ∈ A_adapt={probe(·), ask_human, demo_request, expand_hypothesis, recalibrate, update_prior, no_op}`。目标
  `max_π E[Σ_t γ^t (R_task − λ_c c(a_t) − λ_u H(post_t) − λ_r Risk_t)]`
  s.t. `P(violation)≤α`、`KL(p(z|D_t)‖p_0)≤ε_cult`、`θ_hard` 不变。用约束策略优化/拉格朗日法求解；离线元训练 + 在线保守更新。

- **定义 238（文化安全壳 CSE）**：参数 `θ=(θ_hard,θ_soft)`。硬壳 `Θ_hard` 含力限、碰撞、速度上限、关节限位，**对所有 z 相同**；软壳 `θ_soft ∈ [l(z),u(z)]` 含接近速度、交互距离、软力裕度、任务顺序偏好、提示频率。`CSE(z)=Θ_hard × [l(z),u(z)]`。适应可行域为 `CSE(z) ∩ Valid(J_care)`。**文化可以改变「多保守」，但不能改变「绝不能怎样」。**

- **定义 239（适应动作与干预成本）**：`c(a)=c_phys(a)+c_human(a)+c_sample(a)+c_risk(a)`。文化探针（问人/看演示/被动观察）通常 `c_phys≈0`；物理探针成本高且受 `f_safe`、`ε_strain` 约束。元策略以「单位成本信息增益」为准则之一。

- **定义 240（干预因果审计 ICA）**：把更新 `a` 视为干预，结果为 `Y`（任务成功率、归因准确率、软壳内改进等），协变量 `X`。`a` 因果可识别当且仅当后门/前门/工具变量条件成立，或 `a` 被随机化（A/B、epsilon-greedy）。用双稳健估计量 `τ̂_DR` 与经验 Bernstein 下界 `LCB(τ)`；仅当 `LCB(τ)>0` 且 E-value 敏感性分析表明「未观测混杂强度需大于阈值才能解释掉效应」时才允许提交。否则标 `non_identifiable`，只进影子适应。

- **定义 241（适应证书与悔界 RCB）**：`J_care` 增 `adapt_ate_lcb`、`regret_ucb`、`causal_id`、`soft_only`、`shadow_ok`、`rollback_hash`、`fair_ver`。提交规则：VISTA 有效 ∧ `soft_only` ∧ (`causal_id` ∨ `shadow_ok`) ∧ `regret_ucb ≤ B_adapt` ∧ 公平约束有效 ∧ 未知状态显式。悔界采用 UCB/保守 bandit 形式：`R_T ≤ O(√(T|A_adapt| log T)) + D_KL(p(z)‖p_0)`，第二项即文化先验失配的代价。

- **定义 242（文化探针 CPE）**：探针 `q` 的选择
  `q*=argmax_q I((ℋ,z); ρ_new(q) | E_t) / c(q)`，
  s.t. 物理探针满足 `f_n≤f_safe`、`strain≤ε_strain`。这是第 65 轮 AFA 的严格扩展：当 `H(ℋ|E)` 已低而 `H(z|E)` 高时，最优动作可能是「问人」；当物体易损时，优先 `ask_human`/`demo_request`/被动观察，而非物理按压。

- **定义 243（层级后验更新与变点）**：文化后验按定义 234 更新；用 CUSUM/KL 漂移检测监控 `p(z|D_t)`。若 `KL(p_t‖p_{t−1})>τ_drift`，判定文化变点，回退到 `p_0` 与当前个体的混合，并提高 `r_cult`，直至新证据稳定。防止「旧文化先验」污染新部署。

- **定义 244（影子适应与回滚 SAR）**：候选更新先在影子策略/反事实回放中运行 `k_shadow` 个 episode；只有影子期证书覆盖率不低于 `1−α_shadow`、且无硬约束违规，才允许「双钥匙」提交（语义流审批 + 证书）。线上保留 `rollback_hash` 对应的已认证快照；监控到覆盖率下降、`fault_entropy` 上升或软壳越界即回滚。

- **定义 245（CARE 证书 J_care）**：`J_care=(J_vista, cult_posterior, cult_kl, hyp_set_ver, og_status, adapt_ate_lcb, regret_ucb, causal_id, soft_only, shadow_ok, rollback_hash, fair_ver)`。Valid 当且仅当：`Valid(J_vista)` ∧ 只动软参数 ∧ (`causal_id` ∨ 仅影子) ∧ 悔界上界在预算内 ∧ 公平约束有效 ∧ `og_status` 显式（`known`/`unknown`/`new_admitted`）。

- **定义 246（CARE 闭环算子）**：语义流 `[VISTA→CLP 文化后验→FIR-C 文化条件归因→OGH 假设生长→CPE/MAR 取证与元决策→ICA 因果审计→CSE 软壳检查→RCB 提交/影子→SAR 回滚]`；实时流 `[VISTA 原有实时路径→硬约束守卫→软壳快速检查→回滚触发]`。**所有学习与审计只在语义流；实时流零 RL 写操作。**

- **定义 247（反刻板印象与公平约束）**：文化特征 `φ_cult` 不得使用受保护属性；并要求 `I(z; protected) ≤ ε_fair`。同时设「个体覆盖」与「KL 预算」，把文化先验限制为**可被个体证据推翻的软偏置**。若检测到 `z` 与受保护属性强相关且被用于放开软壳，则拒绝该特征并回退到 `p_0`。这把「文化适应」与「统计歧视」在定义层分开。

- **定义 248（文化适应不可能三角）**：对任意适应策略 π，以下三者不能同时成立：(i) **零样本最优**：对所有 z 都达到 `V*(z)`；(ii) **零安全裕度损失**：对任意 z 都不消耗额外安全裕度；(iii) **有界适应成本**：`R_T=O(1)`。若两个文化上下文在可观测量上不可区分但最优软裕度不同，则不做实验（成本低）就无法区分，必然在某个 z 上次优；做实验（零样本最优）就要消耗风险/时间；用文化先验（零成本）则要承担先验失配偏差。**文化适应的本质，是在「先验偏差」「实验风险」「适应悔界」三者之间做显式取舍，而不是消除取舍。**

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（开放世界生长的误发现控制）**：在零假设下 e-value 为非负鞅，`P(e≥1/α_og)≤α_og`；多簇用 e-BH 控制 FDR≤α_og。因此「接纳新故障」有统计门槛，未通过时输出 `unknown`，从机制上消除 VISTA「强行归入最近假设」的失效模式。
- **引理 10（文化先验的集中与个体覆盖）**：在 KL 预算 `ε_cult` 下，后验的组间偏差被 `√(2ε_cult)` 控制；当个体证据的似然比超过 `τ_ind` 时个体模型主导，故文化先验是「冷启动加速器」而非「终身标签」。这给出刻板印象偏差的可计算上界。
- **引理 11（软壳适应的安全性）**：若硬壳 `Θ_hard` 对 z 不变、更新只移动 `θ_soft`，且每次提交都要求 `Valid(J_care)`，则适应不改变 VISTA 的硬安全界；额外风险仅来自探索预算 `α_explore`，且被 `regret_ucb` 与影子期覆盖约束吸收。
- **引理 12（因果审计抗奖励黑客）**：在重叠性与后门条件下，`LCB(τ)>0` 的提交式更新的真实改进为正的概率 ≥1−α；若元策略试图通过选择有利样本「刷」证书，双稳健估计 + 留出随机化 + E-value 敏感性分析会把该类更新判为不可识别或效应不显著。
- **定理 9（CARE 端到端：可适应 + 可归因 + 可回滚）**：在 A94–A99 下，`Valid(J_care)` ⇒ VISTA 有效 ∧ 适应只动软壳 ∧ 每次提交式更新因果可识别或仅影子运行 ∧ 未知故障显式标注 ∧ 新假设接纳受 FDR 控制 ∧ 文化先验可被个体证据推翻 ∧ 任何时刻可回滚到已认证快照。证书链由「几何-技能-干扰-接触-归因」扩为「几何-技能-干扰-接触-归因-适应」。
- **定理 10（文化适应不可能三角）**：若两个文化上下文在可观测量上不可区分但最优软裕度不同，则「零样本最优 / 零安全裕度损失 / 有界适应成本」至多同时满足两项；文化先验、主动实验与适应悔界构成三角权衡，任何声称三者兼得的方案必然隐藏了额外假设（例如文化标签可直接观测，或安全裕度可无限消耗）。
- **实时性**：CLP/OGH/MAR/ICA/RCB/SAR 全在语义流；实时流仅增硬约束守卫（<0.02ms）、软壳快速检查（<0.03ms）与回滚触发（<0.01ms），目标仍 ≤2.5ms（A100 修订契约）。

## 2. 形式化定义（完整版）

**定义 233（CARE 闭环）** CARE 是 VISTA 的「部署自适应 + 开放世界」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载 CLP（文化后验）、OGH（假设生长）、MAR（元适应策略）、CSE（文化安全壳）、ICA（干预因果审计）、CPE（文化探针）、RCB（适应证书与悔界）、SAR（影子适应与回滚），并原位升级 FIR→FIR-C、RSC-V→RSC-C、WCV-V→WCV-C、CSP-V→CSP-C、AIC-V→AIC-C、J_vista→J_care。不变式：**硬物理约束、实时安全路径、VISTA 认证前缀不随文化改变、不被 RL 更新；所有学习、因果审计、假设生长、提交与回滚只发生在语义流；实时流零 RL 写操作。**

**定义 234（文化隐变量与层级先验 CLP）** 文化隐变量 `z ∈ Z` 表示部署级行为约定，而不是国籍、族群、性别等身份标签。总体先验 `p_0(z)` 由多个部署离线统计；部署后验
`p(z|D_t) ∝ p_0(z) ∏_{ξ∈D_t} p(ξ|z)`。
三个约束：
1. **KL 预算**：`KL(p(z|D_t)‖p_0(z)) ≤ ε_cult`，把文化限制为「总体先验附近的软偏置」；
2. **个体覆盖**：个体似然比 `LR_ind = p(D_ind|z_ind)/p(D_ind|z_group) > τ_ind` 时，个体模型主导；
3. **公平/反刻板**：`z` 只由行为与环境特征推断，不使用受保护属性，且 `I(z; protected) ≤ ε_fair`（定义 247）。
文化先验的用途是冷启动、先验排序与软阈值初值，**不是终身标签，也不是硬约束**。

**定义 235（文化条件故障先验）** `P(H|z) ∝ exp(ψ(H,z))`，`ψ` 由离线跨部署故障注入数据拟合。文化调制的是**似然与先验**：例如某部署中「大力压合抽屉」常见，则较大的力残差在该 z 下更可能属于正常；某部署中「轻触即停」是规范，则同等残差更可能属于 H_model。硬约束 `Θ_hard`（力限、碰撞、关节限位、速度上限）对任意 z 不变。形式化：`p(ρ|H,z)` 与 `P(H|z)` 可依赖 z，但 `Θ_hard(z)=Θ_hard`。

**定义 236（开放世界假设生长 OGH）** 给定已知假设 `ℋ_t={H_1,…,H_K}` 及其混合 `p_mix(ρ)=Σ_k π_k p_k(ρ)`。对残差簇 `C`，定义 prequential e-value
`e(C)=∏_{i∈C} p_new(ρ_i|ρ_{<i}) / p_mix(ρ_i)`。
在「C 来自已知混合」的零假设下，`e(C)` 是非负鞅，`E[e(C)]≤1`，故 `P(e(C)≥1/α_og)≤α_og`。若通过，接纳新假设 `H_new`，其 CRP 先验质量 `P(H_new)=γ(z)/(γ(z)+n)`；γ(z) 可由文化后验的「该部署出现新约定的可能性」给出。若有多个候选簇，用 e-BH：将 e-value 降序排列，取最大 k 使 `e_(k) ≥ m/(kα_og)`，控制 FDR≤α_og。若未通过，输出 `og_status='unknown_fault'`，**不得取 argmax 强行归因**，并在 RSC-C 中膨胀 `r_open`。年龄/漂移导致旧假设失效时，同步从 `ℋ_t` 移除或降权（带最低驻留时间防抖）。

**定义 237（元适应约束 POMDP）** 元状态 `s_t=(x_t, post_t, p(z|D_t), ℋ_t, cert_t)`；元动作 `a_t ∈ A_adapt`。目标
`max_π E[Σ_t γ^t (R_task − λ_c c(a_t) − λ_u H(post_t) − λ_r Risk_t)]`
s.t. `P(violation)≤α`、`KL(p(z|D_t)‖p_0)≤ε_cult`、`θ_hard` 不变、`a_t` 的物理探针满足 `f_n≤f_safe`、`strain≤ε_strain`。采用约束策略优化（拉格朗日/CPO）或保守 Q-learning；离线元训练覆盖多个文化上下文，在线只做小步、可审计的 bandit 更新。

**定义 238（文化安全壳 CSE）** `θ=(θ_hard,θ_soft)`。`Θ_hard` 对 z 不变；`θ_soft ∈ [l(z),u(z)]`，且存在安全默认 `θ_soft^0 ∈ [l(z),u(z)]`。适应可行域 `F_adapt(z)=CSE(z) ∩ Valid(J_care)`。任何更新若试图修改 `θ_hard`、或把 `θ_soft` 移出 `[l(z),u(z)]`，直接拒绝并记 `soft_only=False`。**文化可以决定「多保守」，不能决定「是否安全」。**

**定义 239（适应动作与干预成本）** `c(a)=c_phys(a)+c_human(a)+c_sample(a)+c_risk(a)`。物理探针成本含预期接触力、形变风险与时间；文化探针成本含人类注意力与交互轮次。元策略优化「单位成本信息增益」，并受总预算 `B_adapt` 约束。易损物体的 `c_phys` 设为 `∞`，强制走文化探针或 `no_op`。

**定义 240（干预因果审计 ICA）** 把候选更新 `a` 视为干预，结果 `Y`（任务成功、软壳内改进、归因准确率等），协变量 `X`。因果可识别条件：后门 `Y(a)⊥A|X`、重叠性 `0<e(X)<1`、或随机化/工具变量。用双稳健估计
`τ̂_DR = E[(A/ê(X)−(1−A)/(1−ê(X)))(Y−m̂(X,A))] + E[m̂(X,1)−m̂(X,0)]`，
以 bootstrap/经验 Bernstein 给 `LCB(τ)`。仅当 `LCB(τ)>0`、重叠性通过、E-value 表明「未观测混杂需强于阈值才能解释掉效应」时才允许提交；否则 `causal_id=False`，只进影子适应。此定义把「RL 变好了」与「环境恰好变简单了」分开。

**定义 241（适应证书与悔界 RCB）** `J_care` 的适应字段：
- `adapt_ate_lcb`：因果效应下界；
- `regret_ucb`：适应悔界上界，`R_T ≤ O(√(T|A_adapt| log T)) + D_KL(p(z)‖p_0)`；
- `causal_id`：是否可识别；
- `soft_only`：是否只动软参数；
- `shadow_ok`：影子期是否通过；
- `rollback_hash`：可回滚快照；
- `fair_ver`：公平约束版本。
提交规则：`Valid(J_vista) ∧ soft_only ∧ (causal_id ∨ shadow_ok) ∧ regret_ucb≤B_adapt ∧ fair_ver 当前 ∧ og_status 显式`。

**定义 242（文化探针 CPE）** 探针集扩为 `A_probe={press,rub,tap,lift,visual_probe,null_test,ask_human,demo_request,passive_observe}`。选择
`q*=argmax_{q∈A_probe} I((ℋ,z); ρ_new(q) | E_t) / c(q)`，
s.t. 物理探针满足安全约束。与第 65 轮 AFA 的差别：当故障假设已较确定但文化上下文不确定时，最优动作可以是「问人/看演示」而非物理按压；当物体易损时，`c_phys=∞` 自动排除物理探针。文化探针也可用于**校准先验**（例如确认「这个家庭是否接受更近的交互距离」），但不用于绕过硬约束。

**定义 243（层级后验更新与变点）** 文化后验按定义 234 更新。用 CUSUM 与滑动 KL 监控 `p(z|D_t)`；若 `KL(p_t‖p_{t−1})>τ_drift`，判文化变点：后验回退为 `p_0` 与当前个体模型的混合，置 `r_cult↑`，暂停依赖旧 z 的软阈值，直到新证据稳定。对「访客/临时场景」使用短记忆后验；对「长期住户」使用长记忆后验。

**定义 244（影子适应与回滚 SAR）** 候选更新先在影子策略与反事实回放中运行 `k_shadow` 个 episode；只有影子期证书覆盖率 `≥1−α_shadow` 且无硬约束违规，才允许「双钥匙」提交：语义流审批 + `Valid(J_care)`。线上保留 `rollback_hash` 对应的已认证快照。触发回滚的条件：硬约束接近越界、软壳越界、`fault_entropy` 上升超阈值、conformal 覆盖率下降、或文化变点。回滚是 O(1) 快照恢复，不重新训练。

**定义 245（CARE 证书 J_care）** 见定义 241 与符号表。审计链新增：为什么信这个文化先验（`cult_posterior`/`cult_kl`）、为什么接纳/拒绝新假设（`og_status`/`hyp_set_ver`）、为什么提交这次更新（`adapt_ate_lcb`/`causal_id`）、为什么可以回滚（`rollback_hash`）。

**定义 246（CARE 闭环算子）** 语义流：`[VISTA→CLP 文化后验→FIR-C 文化条件归因→OGH 假设生长→CPE/MAR 取证与元决策→ICA 因果审计→CSE 软壳检查→RCB 提交/影子→SAR 回滚]`；实时流：`[VISTA 原有实时路径→硬约束守卫→软壳快速检查→回滚触发]`。所有学习与审计只在语义流；实时流零 RL 写操作。

**定义 247（反刻板印象与公平约束）** 文化特征 `φ_cult` 不得使用受保护属性；要求 `I(z; protected) ≤ ε_fair`。若检测到 `z` 与受保护属性强相关且被用于放开软壳，拒绝该特征并回退 `p_0`。同时保留个体覆盖与 KL 预算，使文化先验是**可被个体证据推翻的软偏置**。这把「文化适应」与「统计歧视」在定义层分开：前者调制软先验，后者把群体标签当个体真值。

**定义 248（文化适应不可能三角）** 对任意适应策略 π，以下三者不能同时成立：
1. **零样本最优**：`∀z, V^π(z)=V*(z)`；
2. **零安全裕度损失**：`∀z`，适应不消耗额外安全裕度；
3. **有界适应成本**：`R_T=O(1)`。
证明直觉：若两个文化上下文 `z_1,z_2` 在可观测量上不可区分但最优软裕度不同，则不做实验就无法区分，必在某个 z 上次优（破坏 1）；做实验则消耗风险/时间（破坏 2 或 3）；用文化先验则承担先验失配偏差（破坏 1 或 3）。**文化适应不是消除取舍，而是把取舍显式化、可审计化。**

### IP-224 CLP（文化后验）

```python
class CulturalPrior:
    def __init__(self, p0, eps_cult=0.1, tau_ind=3.0, tau_drift=0.5):
        self.p0, self.post = p0, p0.copy()
        self.eps_cult, self.tau_ind, self.tau_drift = eps_cult, tau_ind, tau_drift

    def update(self, D_new):
        self.post = bayes_update(self.post, D_new, lik_culture)
        self.post = kl_project(self.post, self.p0, self.eps_cult)   # 软偏置
        if self._drift(D_new):
            self.post = mixture(self.p0, individual_model(D_new))   # 变点回退
        return self.post

    def condition(self, H):
        # 只改先验，不改硬约束
        return softmax({h: log_prior(h) + psi(h, self.post) for h in H})

    def individual_override(self, D_ind):
        return likelihood_ratio(D_ind) > self.tau_ind
```

### IP-225 OGH（开放世界假设生长）

```python
class OpenWorldHypotheses:
    def __init__(self, known, alpha_og=0.05, gamma_fn=lambda z: 1.0):
        self.known, self.alpha_og, self.gamma_fn = known, alpha_og, gamma_fn

    def consider(self, rho_cluster, z_post):
        e = prequential_evalue(rho_cluster, self.known.p_mix)
        if e >= 1.0 / self.alpha_og:
            gamma = self.gamma_fn(z_post)
            prior_new = gamma / (gamma + self.known.n)
            self.known.admit(make_hypothesis(rho_cluster), prior_new)
            return 'new_admitted'
        return 'unknown_fault'            # 不强行归因；后续膨胀 r_open

    def e_bh(self, clusters, z_post):
        es = sorted((prequential_evalue(c, self.known.p_mix), c) for c in clusters)
        m, k_star = len(es), 0
        for k, (e, _) in enumerate(es, 1):
            if e >= m / (k * self.alpha_og):
                k_star = k
        for _, c in es[:k_star]:
            self.consider(c, z_post)
        return k_star
```

### IP-226 MAR（元适应策略）

```python
class MetaAdapter:
    def choose(self, s, post, z_post, known, budget, object_fragile):
        best, best_score = 'no_op', 0.0
        for a in A_ADAPT:
            if not self.feasible(a, budget, z_post, object_fragile):
                continue
            ig = mutual_info((known.hypotheses, z_post), a, post)   # 故障 + 文化
            risk = self.risk_ucb(a, z_post)
            score = ig / (cost(a) + 1e-9) - LAMBDA_R * risk - LAMBDA_U * entropy(post)
            if score > best_score:
                best, best_score = a, score
        return best if best_score > DELTA_ADAPT else 'no_op'
```

### IP-228 ICA（干预因果审计）

```python
def intervention_audit(update, logged, alpha=0.05):
    if not overlap_ok(logged) or not backdoor_ok(logged):
        return {'causal_id': False, 'reason': 'non_identifiable'}
    tau, lcb = doubly_robust_ate(update, logged)       # 经验 Bernstein 下界
    if lcb <= 0:
        return {'causal_id': False, 'reason': 'no_significant_gain', 'ate_lcb': lcb}
    if e_value_sensitivity(tau, logged) < E_MIN:
        return {'causal_id': False, 'reason': 'fragile_to_confounding'}
    return {'causal_id': True, 'ate_lcb': lcb, 'tau': tau}
```

### IP-233 CARE 闭环算子（与 VISTA 整合）

```python
def CARE_round(M, obs, delta_f_req):
    # ———— 语义流 ————
    M, K_safe, EV_exec, j_vista = VISTA_round(M, obs, delta_f_req)

    # 1) 文化后验 + 文化条件故障先验
    M.cult.update(collect_deployment_evidence(obs))
    prior = M.cult.condition(M.fir.HYP)

    # 2) FIR-C：归因；OGH：未知故障生长
    post, h_star, ambiguous = M.fir_c.attribute(M.stage.phases, prior)
    og = M.ogh.consider(M.residual_clusters, M.cult.post)
    if og == 'unknown_fault':
        post = add_unknown_mass(post, M.ogh.alpha_og)
        M.balls['r_open'] = inflate(M.balls['r_open'], M.kappa_open)
    M.balls['r_cult'] = cult_radius(M.cult) if M.cult.uncertain else M.balls['r_cult']

    # 3) CPE/MAR：选择取证动作
    a_adapt = M.mar.choose(M.meta_state, post, M.cult.post, M.ogh.known,
                           M.budget, M.object_fragile)
    if a_adapt != 'no_op':
        evidence = M.execute_adaptation(a_adapt)          # 探针/问人/演示
        M.cult.update(evidence)
        post, h_star, ambiguous = M.fir_c.attribute(M.stage.phases, M.cult.condition(M.fir.HYP))

    # 4) 候选更新 → 因果审计 → 软壳检查
    update = M.rcb.propose_update(post, M.balls, M.cult.post)
    audit = intervention_audit(update, M.logged)
    if not M.cse.allows(update):
        update, audit = reject_soft_violation(update)

    # 5) 提交或影子；保留回滚快照
    if audit['causal_id'] and audit['ate_lcb'] > 0 and M.rcb.regret_ucb() <= M.B_adapt:
        M.commit(update, rollback_hash=hash(M.snapshot()))
    else:
        M.sar.run_shadow(update, k_shadow=M.k_shadow)

    # 6) 证书
    j_care = build_j_care(j_vista, M.cult.post, M.cult.kl(),
                          M.ogh.version, og, audit, M.rcb.regret_ucb(),
                          M.cse.soft_only, M.sar.shadow_ok, M.snapshot_hash(),
                          M.fair_ver)
    return M, K_safe, EV_exec, j_care
```

### IP-230 RSC-C（归因定向球）

```python
def rsc_c_update(balls, post, cult, og_status):
    r = {k: balls[k] for k in ('r_geo', 'r_force', 'r_model')}
    if og_status == 'unknown_fault':
        r['r_open'] = min(R_MAX, KAPPA_OPEN * max(r.get('r_open', 1e-6), R_MIN))
```

## 4. 推导

**引理 9（开放世界生长的误发现控制）** 对残差簇 `C`，零假设 `H_0: C∼p_mix`。Prequential e-value `e(C)=∏ p_new(ρ_i|ρ_{<i})/p_mix(ρ_i)` 在 `H_0` 下是非负鞅且 `E[e]≤1`（每个因子条件期望 ≤1）。由 Markov 不等式，`P(e(C)≥1/α_og)≤α_og`。多簇时 e-BH 在任意依赖结构下控制 FDR≤α_og（e-BH 定理）。因此「接纳新故障」的错误率有上界；未通过时输出 `unknown`，不会把未知复合故障强行塞进最近假设。∎

**引理 10（文化先验的集中与个体覆盖）** 设 `p(z|D) ∝ p_0(z)exp(ℓ_D(z))`，KL 预算投影到 `{q: KL(q‖p_0)≤ε_cult}`。由 Pinsker，`‖p(·|D)−p_0‖_TV ≤ √(KL/2) ≤ √(ε_cult/2)`，故组间先验偏差被 `ε_cult` 控制。个体覆盖：当 `LR_ind>τ_ind` 时，个体似然项在指数尺度上压过先验项，`p(z_ind|D_ind)→1`。因此文化先验的偏差随 `ε_cult` 可控，且可被强个体证据推翻。∎

**引理 11（软壳适应的安全性）** 设硬壳 `Θ_hard` 对 z 不变，更新只修改 `θ_soft∈[l(z),u(z)]`，且每次提交要求 `Valid(J_care)`。VISTA 的硬安全界（力限、碰撞、几何、滑移）只依赖 `Θ_hard` 与 `J_vista`；由第 65 轮引理 8，`P[越界]≤α_chunk+δ_fi+α_vis+α_geo`。适应只改变软参数，故不改变该上界；探索引入的额外风险被 `α_explore` 预算、影子期覆盖与 `regret_ucb` 吸收。∎

**引理 12（因果审计抗奖励黑客）** 在重叠性与后门条件下，双稳健估计量 `τ̂_DR` 一致且渐近正态；经验 Bernstein 下界 `LCB(τ)` 以 ≥1−α 覆盖真 ATE。若 `LCB(τ)>0`，则真实改进为正的概率 ≥1−α。若元策略通过选择有利样本「刷」证书，则重叠性检查会拒绝（没有可比对照），或 E-value 敏感性分析指出未观测混杂可解释效应，从而判 `non_identifiable`。因此提交式更新不能被纯相关性/选择偏差伪装成因果改进。∎

**定理 9（CARE 端到端：可适应 + 可归因 + 可回滚）** 在 A94–A99 下：
1. **假设可生长**：OGH 以 FDR≤α_og 接纳新故障，未通过时输出 `unknown`，消除「强行归因」（引理 9）。
2. **先验可适应且可推翻**：CLP 在 KL 预算内更新，个体证据可覆盖群体先验（引理 10）。
3. **文化不买安全**：CSE 保证 `θ_hard` 不变，适应只动软壳（定义 238）。
4. **更新可归因**：ICA 只允许因果可识别且效应显著的提交（引理 12）。
5. **风险有界**：RCB 的 `regret_ucb` 与影子期覆盖约束把适应风险压到预算内（引理 11）。
6. **可回滚**：SAR 保留已认证快照，硬约束/软壳/覆盖率触发 O(1) 回滚。
7. **证书链**：`Valid(J_care) ⇒ VISTA 有效 ∧ 适应只动软壳 ∧ 更新可识别或仅影子 ∧ 未知故障显式 ∧ 可回滚`。
故证书链从「几何-技能-干扰-接触-归因」扩为「几何-技能-干扰-接触-归因-适应」。∎

**定理 10（文化适应不可能三角）** 设 `z_1,z_2` 在可观测量上不可区分，但最优软裕度 `θ*_soft(z_1)≠θ*_soft(z_2)`。任何不实验的策略对两个 z 输出同一软参数，故至少在其中一个 z 上不是最优，破坏「零样本最优」。任何实验策略必须施加与 z 相关的激励，消耗额外风险/时间，破坏「零安全裕度损失」或「有界适应成本」。任何纯先验策略把 `z_1,z_2` 映射到同一先验预测，承担先验失配偏差，故不能对所有 z 零样本最优。因此三者至多同时满足两项。∎

**命题（文化先验降低跨部署保守性）** 第 65 轮 RSC-V 对任意拒绝统一膨胀 `r=√(r_geo²+r_force²+r_model²)`。CARE 在 `H_force` 且文化匹配时只膨胀 `r_force`，`r_geo` 与 `r_cult` 不变；若真实故障为力偏置且几何/文化正常，几何搜索域体积仅为第 65 轮的 `1/κ_infl^{d_φ}`（几何分量），避免「正确几何被文化不确定性连带保守化」。反之文化失配时只膨胀 `r_cult`，不误伤已标定的力与几何。∎

## 7. 已知风险

**一句话**：CARE 的最大风险是**元策略把「文化先验」当成可优化的自由度**——RL 会学会选择那些能降低归因熵、提高表面奖励、又恰好符合某个文化刻板印象的探针与更新；当证书覆盖率估计与适应数据同源时，文化先验与 RL 会互相「确认」同一个错误先验，系统一边把软安全裕度一点点适应掉，一边报告越来越高的置信度。**文化从减少不确定性的先验，变成绕过安全壳的许可证，而 RL 是执行这次「合法化洗白」的工具；这是本轮全部适应-证书论证共同依赖的隐藏假设（A98）。**

**次级风险与缓解**：
1. **文化先验退化为刻板印象**：即使有 KL 预算，若 z 与受保护属性相关，仍可能造成群体偏差。缓解：定义 247 的公平约束、个体覆盖、禁止受保护属性入特征、审计 `I(z;protected)`；一旦越界回退 `p_0`。
2. **e-value 校准失准**：`p_new` 过拟合会让未知簇「人造显著」。缓解：用留出/预quential 构造、限制 `p_new` 容量、e-BH 控制 FDR、对新假设设最低驻留与复审。
3. **因果审计的未观测混杂**：真实部署很难随机化。缓解：E-value 敏感性分析、影子 A/B、工具变量、显式 `non_identifiable` 并只做影子适应。
4. **文化变点检测滞后**：旧先验污染新部署。缓解：CUSUM + 短/长记忆双后验、变点即回退、保守膨胀 `r_cult`。
5. **元策略样本效率与冷启动**：跨部署元训练可能覆盖不足。缓解：离线多部署元训练 + 文化先验作为层级先验 + 只在低维元动作空间学习。
6. **证书同源导致的自我确认**：覆盖率与适应数据同分布时，RL 可能「刷」指标。缓解：留出审计集、时间切分、影子期、随机化 epsilon、独立 red-team。
7. **软壳边界被缓慢侵蚀**：每次小步都在界内，但长期漂移到不可接受区域。缓解：软壳设「长期锚点」，累计漂移超预算即回滚；审计软参数轨迹。
8. **实时预算**：CARE 实时路径逼近 2.5ms。缓解：CLP/OGH/MAR/ICA/RCB 全部语义流；实时只做硬守卫、软壳比较、回滚触发；与 VISTA 共享编码。

- **概念闭合**：文化只动软壳，硬壳文化不变；RL 只学元动作，不学物理真值；未知故障不强行归因。
