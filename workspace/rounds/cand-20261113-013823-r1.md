# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰联合闭环」IP-193~203；灵感循环 III 第 1 轮；本轮灵感：「数据采集」×「痛点分析」）

> 第 63 轮把 LIRO 推到「稠密几何 × 通用技能 × 干扰免疫」，但其自述的最大风险暴露了一个比算法更根本的问题：**A77 假设 E_geo 不在分布外几何上产生系统性幻觉、GeoInit 满足 ‖φ\*−φ̂₀‖ ≤ δ_geo < δ_bias——而这两条恰恰是「数据问题」，不是「模型问题」**。E_geo / GeoInit / DIR / USL 全部在固定离线数据上训练，其覆盖盲区与部署痛点（透明/镜面/新拓扑/罕见材质）高度重合；第 63 轮只在推理端做在线适应，却**没有任何机制决定「下一步该采集什么数据」**。换言之，63 轮的闭环在「数据入口」处是断开的。
>
> 本轮不再叠加新的推理模块，而是把**数据采集（data collection）本身提升为一等公民的控制变量**，并用**痛点分析（pain-point analysis）**决定采集目标、优先级与预算分配。核心转向：**从「算法中心的在线适应」转向「数据中心的能力构建」——真正关闭长尾的不是更复杂的在线投影，而是采到对的数据。**

## 0. 直觉与动机

**观察 1（痛点证据早已存在，却只被用于局部修补）**
LIRO 每次执行都会留下大量「哪里痛」的证据：J_liro 失效项、Shield-Skill 的 `ask_clarify`、AIC 的 ρ_dir < 0、SSB 的险情记账、OLP-Geo 的遗憾尖峰、执行残差 e_t、RSC 半径异常膨胀。这些本质上构成了一条**天然带标注的失败流**（failure stream）。但在第 63 轮里，它们只被用于当步的 OLP 更新与 RSC 校准，**从未被聚合为跨任务、跨场景的痛点分布，也从未反向驱动数据采集**。这是巨大的信息浪费。

**观察 2（采集通常「无目标、无预算、无质检」，且被可得性偏差劫持）**
真实数据采集往往是「方便采什么就采什么」：仿真里容易生成的、实验室里容易摆放的、标注员容易理解的。结果是数据分布 ≈ 可得性分布，而非**风险分布**。透明物体、镜面反射、罕见对抗扰动这些真正高危的痛点，恰恰难采、难标、难仿真，于是被系统性忽略——即经典的「路灯下找钥匙」（streetlight effect）。**没有显式的痛点加权，采集越多，飞轮越可能空转。**

**观察 3（数据到达与证书脱钩）**
即使新数据来了，也没有机制保证 J_liro 变好而非变坏：新数据可能引入标签噪声、与旧分布冲突导致灾难性遗忘、或只在容易的痛点上过拟合。**采集必须带质检、重加权与安全刷新门控，否则「数据闭环」会变成「风险闭环」。**

**灵感 1（痛点分析 → PPA + RCA：痛点分析器与因果归因）**
直觉：把失败证据流聚类为**痛点 pp =（失败签名 ψ，根因 κ，上下文 C，频次 f，严重度 s，认知不确定度 u）**，并做**反事实归因**：若把某个候选根因「修好」，痛点风险会下降多少？根因空间刻意区分五类：D（数据覆盖缺口）、M（模型/几何幻觉）、S（分布漂移）、L（标签/标定噪声）、I（任务本身不可行）。PPA 输出排序后的痛点清单 + 每项归因置信区间；并强制包含一条**盲区审计（blind-spot audit）**：随机抽取未被 PPA 标记的上下文做主动探查，用于估计「被漏掉的痛点」——直接对抗可得性偏差与幸存者偏差。

**灵感 2（数据采集 → AQP + APP：主动采集规划 + 主动物理探针）**
直觉：采集是一个**预算约束下的序贯决策**。动作空间 A = {真人遥操作演示, 定向标注, 靶向仿真, **主动物理探针**, 对抗样本生成}，每个动作有成本 c(a) 与产出（覆盖增益、信息增益）。把训练数据在 DIR 表征空间中的 **k-NN 覆盖场 cov(z)** 与痛点风险密度做乘积，得到**痛点加权覆盖缺口 Φ_gap**；采集目标 = 最大化「期望风险下降 + λ·期望信息增益 EIG − μ·成本」。离线数据用**次模贪心**求解（(1−1/e) 近似保证）；在线物理参数不确定则由 **APP 主动物理探针**（主动戳/抓/压，选 EIG 最大的探针动作）直接收缩 WCV 球，而不是被动等 RSC 慢慢缩。

**灵感 3（靶向仿真 → SRG：仿真靶向生成与 sim-real 门控）**
直觉：痛点上最便宜的数据是仿真，但仿真数据可能「假得很自信」。因此对每个痛点区域做**靶向域随机化**，并用 Gromov-Wasserstein / MMD 度量仿真批与真实流的分布距离；**只有 d_sim-real ≤ ε_sim 才准入库**，否则退回真人采集。仿真不是无条件的填充物，而是**需要通过质检门的候选数据源**。

**灵感 4（合流 → PACE：痛点驱动的数据中心进化闭环）**
四者咬合：PPA/RCA 回答「哪里痛、为什么痛」→ CGM 回答「缺哪块数据」→ AQP/APP 回答「采什么、怎么采、值不值」→ DQG/SRG 回答「采到的能不能用」→ RWT 回答「怎么用才不偏」→ SMR 回答「换模型安不安全」→ DCC 回答「凭什么是真的变好了」。闭环：**痛点 → 缺口 → 采集 → 质检 → 重加权训练 → 安全刷新 → 新证书 → 新痛点**。第 63 轮 LIRO 是「推理端的在线鲁棒闭环」，PACE 是「数据端的离线能力进化闭环」；两者相乘，才构成完整的「感知-决策-数据」三环飞轮。

**灵感 5（LIRO 组件的原位升级）**
- **SSB → SSB-P（Pain-annotated Scenario Bank）**：场景签名增入痛点标签 `pp_id` 与严重度；Mine 时把「险情」直接挂到痛点节点，形成痛点-场景二部图。
- **DIR → DIR-C（Calibrated Coverage Representation）**：在不变表征之外增加**校准的覆盖头**，输出 cov(z) 与局部风险密度，供 CGM 使用；表征目标中增加「覆盖可分性」正则。
- **AIC → AIC-P（Pain-conditioned Certifier）**：认证集 ℰ 增加**痛点子集 ℰ_pp**（由 PPA 高频/高严重度区域诱导），ρ_dir 报告最坏痛点裕度而非全局平均。
- **WCV-Geo → WCV-Probe**：球半径 r 的收缩由「被动 RSC」升级为「主动探针 + RSC」双通道；APP 的 EIG 增益直接折算为 r 的下降。
- **OCB-Skill → OCB-P**：臂空间增加「是否触发采集/探针」的动作维度，用 EXP3 在「继续执行」与「停下来采数据」之间做预算调度。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（PACE 闭环）**：PACE = (LIRO, PPA, RCA, CGM, AQP, APP, SRG, DQG, RWT, SMR, DCC, J_pace)。定位：LIRO 的「数据中心进化」外层闭环；**所有采集/训练发生在离线或低频线程，绝不进入 1–10kHz 实时路径**。
- **定义 202（痛点与风险泛函）**：痛点 pp = (ψ, κ, C, f, s, u)，ψ 为失败签名（残差/证书失效模式/技能+几何上下文），κ∈{D,M,S,L,I} 为根因，C 为上下文分布，f 为频次，s∈[0,1] 为严重度，u 为认知不确定度。痛点风险泛函 R_pp = Σ_pp s_pp·f_pp·(1−u_pp)，其中 (1−u_pp) 表示「已确证程度」。
- **定义 203（PPA 痛点分析器）**：PPA: ℰvidence → {pp_i}，输入证据流（EV_exec、J_liro 失效、Shield 日志、AIC 违规、SSB 险情、OLP 遗憾尖峰、残差），按 ψ 在度量空间聚类（HDBSCAN），每簇估计 (f,s,u)。强制输出**盲区审计集** A_blind = 在「未被标记上下文」上的均匀/风险分层采样，用于估计漏检风险 R_miss。
- **定义 204（RCA 根因归因）**：在失败结构因果模型（SCM）G_fail 上，对每个根因因子 k 定义反事实风险 R_pp^{(k)} = R_pp(do(F_k := ideal))，归因 α_k = Shapley_k({R_pp^{(k)}})。要求 Σ_k α_k = R_pp（可加性），并给出自助法置信区间；G_fail 未识别时降级为「诊断电池」消融近似并标记 `causal_confidence`。
- **定义 205（覆盖场与痛点加权缺口）**：在 DIR-C 表征空间 ℤ 上，cov(z) = 到训练集第 k 近邻的距离（局部稀疏度）。痛点加权覆盖缺口 Φ_gap = ∫ w(z)·cov(z) dP_risk(z) / ∫ w(z) dP_risk(z)，其中 w(z) 为痛点风险密度。Φ_gap 是「风险加权后的数据荒芜度」。
- **定义 206（采集动作模型）**：A = {demo, label, sim, probe, adv}；每动作 a 有成本 c(a)、覆盖增益增益场 g_a(z)≥0、信息增益场 eig_a(θ)、以及产出可靠性 q_a。一次采集批次 b = (a, target region Ω, size n)；总预算 B。
- **定义 207（AQP 主动采集规划）**：选批集合 S 最大化 F(S) = Σ_pp w_pp·[1−exp(−λ·Σ_{a∈S} g_a(pp))] + λ_e·EIG(S) − μ·Σ c(a)，s.t. Σ c(a) ≤ B。在 g_a 单调递减回报假设下 F 次模，贪心给出 (1−1/e) 近似；在线阶段用 EXP3/汤普森采样在非平稳可得性下自适应分配预算。
- **定义 208（APP 主动物理探针与 EIG）**：探针动作 u∈𝒰（轻压/侧推/夹持/微滑移），观测 y_u（力-位移曲线、滑移事件）。EIG(u) = H(φ|D) − E_{y_u}[H(φ|D∪{(u,y_u)})]，φ 为 WCV 球内物理参数。执行 a* = argmax_u EIG(u)/c(u)，其后验更新φ̂、r；EIG 与半径关系 r_{t+1}² ≈ r_t²·(1−EIG_t/H₀)（高斯近似）。
- **定义 209（SRG 靶向仿真门控）**：对痛点区域 Ω_pp 做靶向域随机化生成 D_sim(Ω)。门控：接受当且仅当 GW(D_sim, D_real) ≤ ε_sim 且物理合理性残差 ≤ ε_phys；被拒批次计入 `sim_reject_rate`，并回退到 demo/probe。
- **定义 210（DQG 数据质检）**：每样本可靠性 q_i = σ(w₁·label_consistency + w₂·calibration_residual + w₃·physical_plausibility + w₄·provenance_score)。q_i < q_min 拒绝入库；q_i∈[q_min,1] 作为训练权重。
- **定义 211（RWT 风险重加权训练）**：风险加权经验风险 + 痛点分布 DRO：min_θ max_{P: D_f(P‖P_pain)≤ρ} E_P[q·ℓ]，用对偶重加权 w_i ∝ q_i·(1+β·s_{pp(i)}) 近似；给出尾部风险上界。
- **定义 212（SMR 安全模型刷新）**：候选模型 θ' 仅在满足「回归门」时上线：∀ 核心基准 |Δ| ≤ δ_reg，且 R_pp^{UCB}(θ') ≤ R_pp^{UCB}(θ) − δ_improve，且 J_pace 影子验证通过；否则回滚。上线采用影子/金丝雀部署。
- **定义 213（数据谱系）**：每条数据 d = (data_hash, source, sim_flag, action, pp_id, q, ts, license, parent_ids)，构成可审计 DAG；禁止无谱系数据进入训练。
- **定义 214（J_pace 数据中心证书）**：J_pace = (J_liro, R_pp^{UCB}, Φ_gap, coverage_cert, provenance_root, refresh_ver, audit_ver)。Valid ⇔ Valid(J_liro) ∧ R_pp^{UCB} ≤ R_budget ∧ Φ_gap ≤ Φ_max ∧ provenance DAG 完整 ∧ audit_fresh。
- **定义 215（痛点关闭判据）**：痛点 pp 关闭 ⇔（i）R_pp^{UCB} 下降 ≥ δ_close；（ii）盲区审计未在邻近上下文发现同族新痛点；（iii）AIC-P 在 ℰ_pp 上 ρ_dir ≥ 0。否则保持 open 并升级优先级。
- **定义 216（PACE 闭环算子）**：语义流/离线：[证据聚合 → PPA → RCA → CGM → AQP → (APP 在线探针 ∥ SRG 靶向仿真) → DQG → RWT 训练 → SMR 门控 → DCC 认证 → 痛点关闭判定]；实时流不变：仍为 LIRO 的 [锚点读 → OLP-Geo 前向 + Shrink → WCV-Geo 编译 → π_σ1 展开派发 → J_liro 构建]，**新增组件零实时开销**。

## 2. 关键算法骨架（完整伪代码见产物区）

```python
# 1) 痛点分析：从证据流到排序痛点
pps = PPA.mine(evidence_stream, blind_audit=True)      # 聚类 + 频次/严重度/不确定度
for pp in pps: pp.attribution = RCA.shapley(pp)        # α_D, α_M, α_S, α_L, α_I
# 2) 覆盖缺口：风险加权稀疏度
cov = DIRC.coverage_field(train_data)                  # k-NN 距离
phi_gap, hot = CGM.gap(pps, cov)                       # 高缺口区域
# 3) 主动采集：次模贪心 + 在线探针 + 靶向仿真
S = AQP.select(hot, budget=B, actions={demo,label,sim,probe,adv})
D_probe = APP.probe(argmax EIG(u)/c(u))                # 主动物理探针（收缩 φ 球）
D_sim = SRG.generate(Omega=hot); reject if GW > eps_sim
# 4) 质检 + 重加权训练 + 安全刷新
D = DQG.filter_and_score(S, D_probe, D_sim)
theta_new = RWT.train(base_theta, D, weights_by_pain=True, dro=True)
if SMR.regression_gate(theta_new, theta_old): deploy_canary(theta_new)
# 5) 证书 + 痛点关闭
J = DCC.issue(J_liro, R_pp_ucb, phi_gap, provenance)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（覆盖-误差上界）**：设表征 E_dir 为 L-Lipschitz、任务头为 L_ŷ-Lipschitz，训练集在 ℤ 上为 ε-覆盖，则痛点区域期望误差 ≤ L_ŷ·(L·ε + η_label)，其中 η_label 为 DQG 后的标签噪声上界——**覆盖缺口是泛化误差的可计算代理**。
- **引理 6（归因可加性）**：若 G_fail 正确且根因可干预，则 Shapley 归因满足 Σ_k α_k = R_pp；识别不足时，诊断电池给出偏差受控的近似（偏差 ≤ 未建模交互项）。
- **定理 4（采集次模近似）**：若各动作覆盖增益边际递减，则 F 单调次模，贪心在预算 B 下达到 ≥ (1−1/e)·OPT；批次多样性用 DPP 去冗余，进一步降低方差。
- **定理 5（主动探针收缩球半径）**：在高斯-线性化模型下，执行 EIG 最优探针后 r_{t+1}² = r_t²(1−EIG_t/H₀)；达到目标半径 δ 所需探针数 n = O(d·log(r₀/δ)/EIG)，**主动探针把「被动等 RSC 收敛」的 O(1/β_c) 时间换成信息最优的少量探针**。
- **定理 6（安全刷新支配）**：若回归门以置信度 1−δ 通过，则新模型在核心基准上不劣于旧模型超过 δ_reg，且痛点风险以 1−δ 下降；漂移下界由 DRO 尾部界保证。
- **定理 7（J_pace 证书有效性，含审计偏差修正）**：盲区审计给出漏检风险无偏估计 R_miss；以 R_pp^{UCB} = R̂_pp + R̂_miss + 置信半径作为证书输入，则 Valid(J_pace) ⇒ 真实部署痛点风险 ≤ R_budget 的概率 ≥ 1−α_audit−δ_cert。**证书报的是上界，不是点估计——这是对抗「采集越多、风险看起来越低」的关键。**

## 5. 本轮最大风险

**一句话**：若 PPA 的痛点聚类把「相关」误判为「因果」、且 AQP 被**可得性偏差**劫持（只采容易采/容易标的痛点），数据飞轮就会在「路灯下」空转——高危但难采集的痛点（透明/镜面/罕见对抗）被系统性漏检，R_pp 因采集偏差而**虚假下降**，J_pace 以漂亮的上界通过，部署时却在真实长尾上失败；**这是「数据中心闭环」特有的、比单点模型错误更隐蔽的失效模式**。

# 第 64 轮产物 · 创新点清单 v4：PACE（Pain-point-driven Active data-Centric Evolution：痛点分析 × 主动采集 × 质检重加权 × 安全刷新的数据中心进化闭环；PPA×RCA×CGM×AQP×APP×SRG×DQG×RWT×SMR×DCC×PCE）

## 2. 形式化定义（完整版）

**定义 201（PACE 闭环）** PACE 是 LIRO 的「数据中心进化」外层闭环：在 LIRO 的「语义流 ∘ 实时流」骨架之外，新增一条**低频/离线数据流** `[证据聚合 → PPA → RCA → CGM → AQP → (APP ∥ SRG) → DQG → RWT → SMR → DCC → Close]`。不变式（时序隔离）：**PACE 的任何训练、采集、聚类、归因、认证都不进入 1–10kHz 实时路径**；实时路径仍严格为 LIRO 的 `[锚点读 → LSF/DIR 前向 → OLP-Geo 前向+Shrink → WCV-Geo 编译 → π_σ1 展开 → J_liro]`。PACE 以「分钟–小时」为节拍更新模型与数据，实时路径以「微秒–毫秒」执行。

**定义 202（痛点与风险泛函）** 痛点 `pp = (ψ, κ, C, f, s, u)`：
- `ψ`：失败签名，由 (失效证书字段, 技能 σ, 几何指纹 fp_cloud, 干扰类型 η, 残差 e_t 的分位特征) 拼接并归一化；
- `κ`：根因类型，取值 `{D（数据覆盖缺口）, M（模型/几何幻觉）, S（分布漂移）, L（标签/标定噪声）, I（任务不可行）}`；
- `C`：上下文分布（场景簇 + 任务族 + 本体配置）；
- `f ∈ [0,1]`：在证据流中的归一化频次；`s ∈ [0,1]`：严重度（安全事件 > 违规 > 任务失败 > 性能下降）；`u ∈ [0,1]`：认知不确定度（样本少、归因不显著则高）。
- 风险泛函 `R_pp = Σ_pp s_pp·f_pp·(1−u_pp)`，归一化到 [0,1]。注意 `(1−u)`：**未确证的痛点不被当作已解决，也不被当作已消失**。

**定义 203（PPA 痛点分析器）** 输入 `ℰvidence`，按 `ψ` 在加权度量空间（证书字段 Hamming + 表征余弦 + 几何指纹汉明）上做 HDBSCAN 聚类，得到痛点簇；每簇用 Beta 后验估计 `f`、用分层严重度表估计 `s`、用簇内样本量与归因显著性估计 `u`。PPA 强制附加**盲区审计**：`A_blind = StratifiedSample(𝒞_unflagged, n_audit, strata=risk_proxy)`，即从「未被 PPA 标记」的上下文中按风险代理分层抽取 `n_audit` 条做回放/诊断，估计漏检风险 `R_miss`。审计的作用是**打破「只统计已发生失败」的幸存者偏差**。

**定义 204（RCA 根因归因）** 构造失败 SCM `G_fail`：节点含「数据覆盖/表征/几何编码/物理先验/技能库/规划/执行/环境」，边为机制依赖。对根因因子 `F_k` 定义反事实风险 `R_pp^{(k)} = R_pp(do(F_k := ideal_k))`（如 do(数据覆盖:=全支撑) 即假设该区域有充足训练数据）。归因 `α_k = Shapley_k`，由所有子集的边际风险下降平均得到，故 `Σ_k α_k = R_pp`。当 `G_fail` 不可识别时，用**诊断电池**（定向消融/替换/重训）近似 `R_pp^{(k)}`，并输出 `causal_confidence`；`α_D` 高 ⇒ 派给 AQP 采集，`α_M` 高 ⇒ 派给模型改进，`α_S` 高 ⇒ 派给域适配，`α_L` 高 ⇒ 派给 DQG 质检，`α_I` 高 ⇒ 标记任务不可行并从 USL 移除或请求人类重定义。**归因的价值在于把「采集」与「改模型」这两种截然不同的干预区分开，避免用数据采集去治模型幻觉（或反之）。**

**定义 205（覆盖场与痛点加权缺口）** DIR-C 输出表征 `z`（在定义 189 的 DIR 基础上增加覆盖头）。`cov(z) = d_k(z; D_train)`（第 k 近邻距离，k=5）。风险密度 `w(z)` 由 PPA 痛点上下文在 `z` 空间核密度估计。`Φ_gap = ∫ w(z)cov(z)dP_risk(z) / ∫ w(z)dP_risk(z)`。结构上：`Φ_gap` 大 ⇔ 「高风险区域的训练数据稀疏」——这正是 A77 幻觉的温床。CGM 同时输出缺口热区 `hot = {z: w(z)·cov(z) > τ_gap}`，作为 AQP 的采集目标。

**定义 206（采集动作模型）** 动作空间 `A = {demo（真人遥操作演示）, label（定向标注/物理属性测量）, sim（靶向仿真）, probe（主动物理探针）, adv（对抗样本生成）}`。每个动作 `a` 定义：
- 成本 `c(a)`（人时 / 机时 / 风险）；
- 覆盖增益场 `g_a(z) ≥ 0`（该动作能在多大的表征邻域内新增有效覆盖）；
- 信息增益场 `eig_a(θ)`（对物理参数/模型参数的后验熵下降）；
- 可靠性 `q_a`（demo 高、label 中、sim 需门控、adv 需质检）。
批次 `b = (a, Ω, n)` 表示在区域 `Ω` 采 `n` 个样本；预算 `B`。

**定义 207（AQP 主动采集规划）** 选批集合 `S`：
```
max_S  F(S) = Σ_pp w_pp·[1 − exp(−λ·Σ_{a∈S} g_a(pp))] + λ_e·EIG(S) − μ·Σ_{a∈S} c(a)
s.t.   Σ_{a∈S} c(a) ≤ B,  |S| ≤ K_batch
```
`w_pp` 为痛点权重（严重度×频次）。在 `g_a` 边际递减假设下 `F` 单调次模，贪心达到 `(1−1/e)·OPT`；批次内部用 DPP（行列式点过程）选多样性样本，避免重复采集同一邻域。在线阶段（部署中可得性/分布漂移变化）用 EXP3 / 汤普森采样在「动作类型 × 区域」臂上自适应分配预算，奖励为「单位成本风险下降」。**这是把「采集什么」从经验直觉变成有近似保证的组合优化。**

**定义 208（APP 主动物理探针）** 探针动作 `u ∈ 𝒰`（轻压测刚度、侧推测摩擦、夹持测滑移、微振测阻尼），观测 `y_u`（力-位移曲线关键点、滑移事件二值）。后验 `p(φ|D)` 为 WCV 球内物理参数的信念。`EIG(u) = H(φ|D) − E_{y_u}[H(φ|D∪{(u,y_u)})]`。执行 `u* = argmax_u EIG(u)/c(u)`，仅当 `EIG(u*) ≥ δ_eig` 且探针动作本身落在安全集内才执行。高斯-线性化近似下后验协方差 `Σ_{t+1} = (Σ_t^{-1} + I_u)^{-1}`，球半径 `r_{t+1}² ≈ r_t²(1 − EIG_t/H₀)`。**主动探针把「被动等 RSC 用执行残差慢慢缩球」替换为「用信息最优的动作主动缩球」**，且探针可行集由 Shield-Skill 前置约束保证。

**定义 209（SRG 靶向仿真门控）** 对缺口热区 `Ω_pp` 做**靶向域随机化**（在痛点相关参数上加大随机化：透明/镜面反射率、摩擦系数尾部、拓扑变异、LiDAR 材质响应），生成 `D_sim(Ω)`。门控：
- 分布距离 `GW(D_sim, D_real) ≤ ε_sim`（Gromov-Wasserstein，捕捉几何/拓扑层面的结构差异，优于逐点 MMD）；
- 物理合理性 `resid_phys(D_sim) ≤ ε_phys`（穿透、超弹性、非物理法向）；
- 通过才入库并标 `sim_flag=True`；拒绝批次计入 `sim_reject_rate` 并回退 demo/probe。
**仿真不是免费数据，而是必须过质检的候选数据源**——这直接针对 A77 的「仿真预训练域差距」风险。

**定义 210（DQG 数据质检）** 每样本可靠性：
```
q_i = σ( w1·label_consistency_i      # 多标注者一致性 / 时序一致性
        + w2·calibration_residual_i   # 传感器标定残差
        + w3·physical_plausibility_i  # 几何/力/运动学物理合理性
        + w4·provenance_score_i )     # 来源可信度（真实>门控仿真>未门控）
```
`q_i < q_min` 拒绝入库；`q_i ∈ [q_min, 1]` 作为训练权重（软使用优于硬丢弃，保留信息但降权）。

**定义 211（RWT 风险重加权训练）** 痛点分布 DRO：
```
min_θ  max_{P: D_f(P‖P_pain) ≤ ρ}  E_{(x,y)~P}[ q(x)·ℓ(θ; x,y) ]
```
对偶形式给出样本权重 `w_i ∝ q_i·(1 + β·s_{pp(i)})·exp(ℓ_i/η)`（η 为 DRO 温度），实现「痛点样本加权 + 尾部再加权」。相比均匀经验风险，RWT 优化的是**痛点分布上的最坏情况**，因而不会用「大量容易样本」稀释掉少量高危痛点。

**定义 212（SMR 安全模型刷新）** 候选模型 `θ'` 上线需同时通过：
1. **回归门**：`∀ 核心基准 b: |metric_b(θ') − metric_b(θ)| ≤ δ_reg`；
2. **改进门**：`R_pp^{UCB}(θ') ≤ R_pp^{UCB}(θ) − δ_improve`；
3. **影子验证**：`J_pace` 在 shadow 回放集上 Valid；
4. **金丝雀**：小流量部署 `T_canary` 内违规率不升。
任一失败则回滚并记录 `refresh_reject(reason)`。刷新记录进入数据谱系（`refresh_ver`），保证「哪个模型用了哪批数据」可追溯。

**定义 213（数据谱系）** 每条数据 `d = (data_hash, source, sim_flag, action, pp_id, q, ts, license, parent_ids)`，所有入库数据构成 DAG。规则：**无谱系不入库、无 q 不训练、被拒仿真批次留痕**。谱系根 `provenance_root` 进入 J_pace，使「证书—模型—数据」三者可反向审计。

**定义 214（J_pace 数据中心证书）** `J_pace = (J_liro, R_pp^{UCB}, Φ_gap, coverage_cert, provenance_root, refresh_ver, audit_ver)`。验证：
```
Valid(J_pace) ⇔ Valid(J_liro)
              ∧ R_pp^{UCB} ≤ R_budget
              ∧ Φ_gap ≤ Φ_max
              ∧ provenance DAG 完整且无未授权源
              ∧ audit_fresh (audit_ver ≥ curr_ver − 1)
              ∧ refresh_ver 与当前部署模型一致
```
`R_pp^{UCB} = R̂_pp + R̂_miss + β_conf`，其中 `R̂_miss` 来自盲区审计。**证书报上界而非点估计**，这是防止「采集越多、风险看起来越低」的统计护栏。

**定义 215（痛点关闭判据）** 痛点 `pp` 关闭当且仅当：
1. `ΔR_pp^{UCB} ≥ δ_close`（风险上界确实下降，而非点估计噪声）；
2. 盲区审计在 `pp` 邻近上下文（`‖z−z_pp‖ ≤ δ_nbhd`）未发现同族新痛点；
3. `AIC-P` 在痛点诱导干扰集 `ℰ_pp` 上 `ρ_dir ≥ 0`；
4. `SMR` 刷新后 J_pace 仍 Valid。
否则保持 `open`，并按 `s·f·(1−u)/c_fix` 升级优先级（`c_fix` 为估计修复成本）。

**定义 216（PACE 闭环算子）** 见下方 IP-214 伪代码。语义流/离线链：`[证据聚合 → PPA → RCA → CGM → AQP → (APP ∥ SRG) → DQG → RWT → SMR → DCC → Close]`；实时流严格继承 LIRO，**零新增实时组件**。

## 3. 关键算法伪代码

### IP-204 PPA（痛点分析器）

```python
class PainPointAnalyzer:
    """从失败证据流挖掘痛点 + 强制盲区审计。离线/低频运行。"""
    def __init__(self, eps=0.08, min_cluster=5, n_audit=128):
        self.eps, self.min_cluster, self.n_audit = eps, min_cluster, n_audit

    def signature(self, ev) -> np.ndarray:
        return concat_norm([
            cert_failure_fields(ev.J_liro),      # 失效项 one-hot
            skill_onehot(ev.skill),              # 技能标识
            cloud_fp(ev.P_cloud),                # 几何指纹（SimHash 64bit）
            disturbance_type(ev.eta),            # 干扰类型
            residual_quantiles(ev.e_t, q=[0.5, 0.9, 0.99]),
        ])

    def mine(self, evidence: List[Evidence]) -> Tuple[List[PainPoint], float]:
        psi = np.stack([self.signature(e) for e in evidence])
        labels = hdbscan(psi, min_cluster_size=self.min_cluster)
        pps = []
        for c in unique(labels[labels >= 0]):
            evs = [e for e, l in zip(evidence, labels) if l == c]
            f = normalized_frequency(evs, evidence)          # Beta 后验均值
            s = severity_table(evs)                          # 安全>违规>失败>降级
            u = epistemic_uncertainty(evs)                   # 样本量 + 归因显著性
            kappa = 'unknown'                                # 由 RCA 填充
            pps.append(PainPoint(psi=psi_mean(evs), kappa=kappa, C=context_of(evs),
                                 f=f, s=s, u=u, ids=[e.id for e in evs]))
        # —— 盲区审计：从未被标记上下文中抽样回放 ——
        unflagged = [e for e, l in zip(evidence, labels) if l < 0]
        audit = stratified_sample(unflagged, self.n_audit, strata=risk_proxy)
        r_miss = estimate_missed_risk(audit)                 # 无偏漏检风险估计
        return pps, r_miss
```

### IP-205 RCA（根因归因）

```python
class RootCauseAttributor:
    """失败 SCM 上的 Shapley 反事实归因。无法识别时退回诊断电池。"""
    FACTORS = ['D', 'M', 'S', 'L', 'I']   # 数据/模型/漂移/标签/不可行

    def __init__(self, scm: FailureSCM, battery: DiagnosticBattery):
        self.scm, self.battery = scm, battery

    def risk_under(self, pp, fixed: Set[str]) -> float:
        # do(F_k := ideal) 的反事实风险
        if self.scm.identifiable:
            return self.scm.counterfactual_risk(pp, fixed)
        return self.battery.estimate(pp, fixed)   # 消融/替换/重训近似

    def shapley(self, pp) -> Dict[str, float]:
        alphas = {k: 0.0 for k in self.FACTORS}
        n = len(self.FACTORS)
        for k in self.FACTORS:
            for subset in powerset([x for x in self.FACTORS if x != k]):
                w = factorial(len(subset)) * factorial(n - len(subset) - 1) / factorial(n)
                alphas[k] += w * (self.risk_under(pp, set(subset) | {k})
                                  - self.risk_under(pp, set(subset)))
        ci = bootstrap_ci(lambda: self.shapley(pp), n_boot=200)
        return {'alpha': alphas, 'ci': ci,
                'confidence': self.scm.identifiability if self.scm.identifiable else 'battery'}
```

### IP-206 CGM（覆盖缺口映射）

```python
class CoverageGapMapper:
    """DIR-C 表征空间：覆盖场 = k-NN 距离；风险密度加权。"""
    def __init__(self, dir_c, k=5, tau_gap=0.6):
        self.dir_c, self.k, self.tau_gap = dir_c, k, tau_gap

    def coverage_field(self, z_query, D_train):
        d, _ = nearest_neighbors(z_query, D_train, k=self.k)
        return d[:, -1]                     # 第 k 近邻距离 cov(z)

    def gap(self, pps, D_train):
        z_pp = np.stack([self.dir_c.encode(pp.context) for pp in pps])
        w = kernel_density(z_pp, bandwidth='scott')        # 风险密度 w(z)
        cov = self.coverage_field(z_pp, D_train)
        phi_gap = np.sum(w * cov) / (np.sum(w) + 1e-9)
        hot = [z for z, wv, cv in zip(z_pp, w, cov) if wv * cv > self.tau_gap]
        return float(phi_gap), hot
```

### IP-207 AQP（主动采集规划）

```python
class ActiveQueryPlanner:
    """预算约束下次模贪心 + DPP 多样性 + 在线 EXP3。"""
    def __init__(self, actions, budget, lam=1.0, lam_e=0.5, mu=0.1, K_batch=8):
        self.actions, self.B = actions, budget
        self.lam, self.lam_e, self.mu, self.K_batch = lam, lam_e, mu, K_batch

    def _marginal(self, S, a, hot, pps) -> float:
        gain = sum(pp.w * (1 - np.exp(-self.lam * self.actions[a].g_at(pp)))
                   for pp in pps) if (a, pp) not in S else 0.0
        eig = self.actions[a].expected_info_gain()
        return gain + self.lam_e * eig - self.mu * self.actions[a].cost

    def select(self, hot, pps) -> List[Batch]:
        S, spent = [], 0.0
        while spent < self.B and len(S) < self.K_batch:
            best = max(self.actions, key=lambda a: self._marginal(tuple(S), a, hot, pps))
            if self._marginal(tuple(S), best, hot, pps) <= 0: break
            batch = Batch(action=best, region=select_region(best, hot),
                          n=choose_batch_size(best, self.B - spent))
            # DPP 去冗余：在候选区选多样性样本
            batch.samples = dpp_sample(candidates(batch.region), k=batch.n)
            S.append(batch); spent += self.actions[best].cost(batch.n)
        return S

    def online_budget(self, arm_stats, t) -> str:
        # EXP3 在「动作类型×区域」臂上自适应（非平稳可得性）
        return exp3_select(arm_stats, t, gamma=0.1)
```

```python
class ActivePhysicalProber:
    """EIG 最优探针，直接收缩 WCV 球。仅低频/交互时触发，探针本身受 Shield 约束。"""
    PROBES = ['press_stiffness', 'push_friction', 'grasp_slip', 'vibrate_damping']

    def __init__(self, delta_eig=0.05, c_probe=1.0):
        self.delta_eig, self.c_probe = delta_eig, c_probe

    def expected_info_gain(self, u, posterior: GaussianPosterior) -> float:
        # 高斯-线性化：EIG = 0.5 * log det(I + Sigma * J_u^T R^{-1} J_u)
        J = probe_jacobian(u, posterior.mean)
        return 0.5 * np.log(np.linalg.det(
            np.eye(len(posterior.mean)) + posterior.cov @ J.T @ J))

    def probe(self, posterior, shield, phi_hat, r):
        scored = [(u, self.expected_info_gain(u, posterior) / self.c_probe)
                  for u in self.PROBES]
        u_best, eig = max(scored, key=lambda t: t[1])
        if eig < self.delta_eig:
            return None                              # 信息不值得探
        if not shield.safe(u_best, phi_hat, r):      # 探针必须安全
            return None
        y = execute_probe(u_best)                    # 力-位移/滑移观测
        posterior = posterior.update(u_best, y)
        r_new = r * np.sqrt(max(0.0, 1 - eig / H0))  # 球半径收缩
        return ProbeResult(u_best, y, posterior, r_new)
```

### IP-211 RWT（风险重加权训练）

```python
def risk_weighted_train(base_model, data, pps, q_scores,
                        beta=2.0, rho=0.1, eta=0.5, epochs=10):
    """痛点严重度重加权 + DRO 对偶重加权。"""
    w = np.array([q * (1 + beta * pain_severity(d, pps)) for d, q in zip(data, q_scores)])
    for epoch in range(epochs):
        losses = np.array([base_model.loss(d) for d in data])
        # DRO 对偶：按损失指数重加权，压尾部
        w_dro = w * np.exp(np.clip(losses / eta, 0, 20))
        w_dro /= w_dro.sum()
        base_model.sgd_step(data, weights=w_dro)
    return base_model
```

```python
def PACE_cycle(M, evidence_buffer, core_benchmarks, budget_B):
    # —— 1) 痛点分析（离线/低频）——
    pps, r_miss = M.ppa.mine(evidence_buffer)

    refresh = M.smr.refresh(theta_new, M.model, core_benchmarks,
                            M.rpp_ucb, rpp_new, jpace_shadow(pp_data=M))
    if refresh.result == 'deploy': M.model = theta_new

    for pp in pps:
```

## 4. 推导

**引理 5（覆盖-误差上界）** 设表征 `E_dir` 为 `L`-Lipschitz、任务头为 `L_ŷ`-Lipschitz，训练集在表征空间 ℤ 上构成 `ε`-覆盖（即 `sup_{z∈𝒵} cov(z) ≤ ε`），DQG 后的标签噪声满足 `E|y − y*| ≤ η_label`。对任意风险区域上下文 `x`，令 `z*` 为最近训练表征、`x*` 为其原像，则
```
E[ℓ(θ; x)] ≤ L_ŷ·(L·‖z − z*‖ + η_label) + ℓ_train(x*)
            ≤ L_ŷ·(L·ε + η_label) + ℓ_train(x*)
```
对风险分布取期望并注意 `∫w·cov = Φ_gap`（加权平均），得 `E_risk[ℓ] ≤ L_ŷ·(L·Φ_gap + η_label) + E_risk[ℓ_train]`。**故 Φ_gap 是风险区域泛化误差的可计算代理**：CGM 的缺口热区就是「最该补数据」的区域。∎

**引理 6（归因可加性）** 若失败 SCM `G_fail` 正确且根因因子可独立干预，则 Shapley 值满足效率性 `Σ_k α_k = R_pp(do(∅)) − R_pp(do(all ideal)) = R_pp`（取理想修复后风险为 0）。当存在未建模交互 `I_unmodeled` 时，诊断电池给出的 `R̂_pp^{(k)}` 有偏，偏差由交互项上界控制：`|Σ_k α̂_k − R_pp| ≤ ‖I_unmodeled‖_∞`。因此 RCA 输出必须带 `causal_confidence`，低置信时 AQP 只做保守采集（见定理 4 的鲁棒版本）。∎

**定理 4（采集次模近似）** 若每个动作的覆盖增益 `g_a(z)` 对已采集集合边际递减（自然假设：同一邻域重复采集收益衰减），则 `F(S) = Σ_pp w_pp[1−exp(−λΣ_{a∈S}g_a(pp))] + λ_e EIG(S) − μΣc(a)` 中第一项为覆盖函数的凹变换（次模），EIG 对独立观测次模，成本线性，故 `F` 单调次模。标准贪心在预算 `B` 下满足 `F(S_greedy) ≥ (1−1/e)·OPT`。若归因低置信导致 `w_pp` 有界误差 `Δw`，则目标扰动 `≤ Δw·Σ_pp |1−exp(...)| ≤ Δw·|P|`，贪心解近似比降为 `(1−1/e)` 对扰动后目标的保证——**风险可控但需审计**。∎

**定理 5（主动探针收缩球半径）** 设 `φ` 后验近似高斯 `N(φ̂, Σ)`，探针观测线性化 `y = J_u φ + ε`，`ε~N(0,R)`。则一次探针的 EIG 为 `½log det(I + Σ J_u^T R^{-1} J_u)`。后验协方差更新 `Σ' = (Σ^{-1}+J_u^T R^{-1}J_u)^{-1}`。若探针选择各向同性且 `EIG_t = ½log(1+σ_t²/σ_obs²)`，则各向同性球半径满足 `r_{t+1}² = r_t²·(1 − EIG_t/H₀)`，迭代得 `r_n² = r_0²·Π_t(1−EIG_t/H₀) ≈ r_0²·exp(−Σ_t EIG_t/H₀)`。达到 `r_n ≤ δ` 需 `Σ_t EIG_t ≥ H₀·log(r_0²/δ²) = O(d·log(r_0/δ))`。**主动探针把「被动 RSC 的 O(1/β_c) 收敛时间」替换为「信息最优的少量探针」，且每步 EIG 可在线计算。**∎

**定理 6（安全刷新支配）** 设回归门检验水平为 `δ`、痛点风险上界估计的集中不等式给出置信半径 `β_conf`。若 `SMR` 通过全部四门，则：
1. 核心基准 `|Δ| ≤ δ_reg`（按构造）；
2. `P[R_pp(θ') ≤ R_pp^{UCB}(θ')] ≥ 1−δ` 且 `R_pp^{UCB}(θ') ≤ R_pp^{UCB}(θ) − δ_improve`，故以 `1−δ` 概率 `R_pp(θ') ≤ R_pp(θ) − δ_improve + 2β_conf`；
3. 金丝雀违规率不升，给出部署期在线保护。
因此刷新不会以 `1−δ` 以上概率使痛点风险变差，且持续改进受 `δ_improve` 控制。∎

**定理 7（J_pace 证书有效性，含审计偏差修正）** 设盲区审计 `A_blind` 从未标记上下文中按风险代理分层抽样，`R̂_miss` 为其风险的无偏估计，抽样数 `n_audit` 给出 Hoeffding 半径 `β_audit = Δ·√(log(2/δ_a)/(2n_audit))`。令证书输入 `R_pp^{UCB} = R̂_pp + R̂_miss + β_conf + β_audit`。若 `Valid(J_pace)`，则真实部署痛点风险 `R_pp^{true} ≤ R_pp^{UCB} ≤ R_budget` 的概率至少 `1 − α_audit − δ_cert`。**关键点：`R̂_miss` 项把「未被采集/未被观测的痛点」显式计入上界，从而阻断「采集偏差 → 风险虚低」的退化路径。**∎

**命题（审计的偏差检测力）** 设真实漏检痛点占比为 `π_miss`，审计抽样 `n_audit` 的检出数为 `B~Binomial(n_audit, π_miss)`。当 `π_miss ≥ π₀` 时，`P[B=0] = (1−π₀)^{n_audit} ≤ exp(−n_audit·π₀)`。取 `n_audit=128, π₀=0.03`，漏检概率 `≤ e^{−3.84} ≈ 2.1%`。故审计能在一个批次内以高概率发现「被 PPA 系统性忽略」的痛点族，**这是对「路灯效应」的统计级防护**。∎

**命题（DQG 软门控优于硬丢弃）** 设被拒样本的真实信息量 `I` 与噪声 `N` 之比为 `r`。硬丢弃保留信息 `(1−p)·I`；软加权（权重 `q` 与噪声负相关）保留信息 `(1−p)·I + p·q·I` 且引入噪声 `p·q·N`。当 `q > N/(I+N)` 时，软加权在 MSE 意义下优于硬丢弃。故 DQG 采用「拒绝极端 + 降权中间」的双阈值策略。∎

## 5. 复杂度与正确性

| DCC 证书 | `O(1)` 哈希 + 谱系校验 `O(n_dag)` | `O(n_dag)` | 定理 7：`Valid ⇒ R_pp^{true}≤R_budget` |
| **PACE 实时开销** | **0**（全部离线/低频） | — | **实时路径严格继承 LIRO，零新增组件** |

**正确性定理（PACE-Complete）** 假设第 63 轮 A61–A82 及：
- **(A83)** 证据流至少覆盖已执行上下文的失败模式；未执行上下文的漏检由审计抽样控制（定义 203）。
- **(A84)** 失败 SCM `G_fail` 结构正确，或诊断电池的未建模交互偏差有界 `‖I_unmodeled‖_∞ ≤ ι`。
- **(A85)** 表征/任务头 Lipschitz 有界（引理 5 前提），训练集在 ℤ 上可被 `ε`-覆盖。
- **(A86)** 采集增益边际递减（次模性），成本可加。
- **(A87)** APP 的高斯-线性化后验近似有效；探针动作经 Shield-Skill 验证安全。
- **(A88)** SRG 的 GW/MMD 估计集中（样本量足够大），门控误接受率 ≤ δ_gate。
- **(A89)** DQG 的可靠性分数与标签噪声单调负相关。
- **(A90)** RWT 的 f-散度球 `{P: D_f(P‖P_pain)≤ρ}` 包含真实痛点分布。
- **(A91)** SMR 回归门与改进门统计有效（水平 δ）。
- **(A92)** 盲区审计分层采样覆盖未标记上下文的风险代理。

则：
1. **痛点可诊断**：PPA 输出带频次/严重度/不确定度的痛点簇，盲区审计给出漏检风险无偏估计（定义 202–203，命题）。
2. **缺口可度量**：`Φ_gap` 是风险区域泛化误差的可计算上界代理（引理 5）。
3. **采集可最优**：次模贪心在预算下达到 `(1−1/e)` 近似，归因低置信时扰动有界（定理 4）。
4. **探针可缩球**：主动探针以 `O(d log(r₀/δ))` 的累计 EIG 达到目标半径（定理 5）。
5. **刷新可安全**：SMR 四门通过则以 `1−δ` 概率不劣化且痛点风险下降（定理 6）。
6. **证书可审计**：`Valid(J_pace) ⇒ R_pp^{true} ≤ R_budget`（概率 `1−α_audit−δ_cert`），且谱系可反查数据/模型来源（定理 7，定义 213–214）。
7. **实时性不变**：PACE 全部离线/低频，实时路径零新增开销（定义 201）。

## 7. 已知风险

**一句话**：若 PPA 的痛点聚类把「相关」误判为「因果」、且 AQP 被**可得性偏差**劫持（只采容易采/容易标的痛点），数据飞轮就会在「路灯下」空转——高危但难采集的痛点（透明/镜面/罕见对抗）被系统性漏检，`R_pp` 因采集偏差而**虚假下降**，`J_pace` 以漂亮的上界通过，部署时却在真实长尾上失败；**这是「数据中心闭环」特有的、比单点模型错误更隐蔽的失效模式**，因为它的自我评估恰恰依赖于被它污染的数据。

**次级风险与缓解**：
1. **RCA 因果误判**：`G_fail` 不可识别 → 强制输出 `causal_confidence`，低置信时只做保守采集（不改变模型），并触发诊断电池而非直接干预。
2. **审计本身被污染**：若 PPA 的失败签名空间遗漏某类痛点，审计的 `risk_proxy` 也可能漏掉 → 审计采用**独立于 PPA 的模态/场景分层**（如按物理属性、按外观材质、按任务族），并周期性做「对抗性盲区注入」。
3. **采集-训练反馈回路不稳定**：重加权可能造成分布坍缩（只关注痛点、丢失核心能力）→ 保留核心基准回放集（≥20% 干净数据），RWT 的 DRO 球半径 `ρ` 设上限，SMR 回归门硬约束。
4. **主动探针安全**：探针可能扰动系统或损坏物体 → 探针动作必须过 Shield-Skill 前置约束 + 力/位移硬限幅，且仅在准静态、无外部负载时执行。
5. **仿真门控误接受**：GW 估计在小样本下方差大 → 门控采用保守阈值 + 序贯检验（SPRT），误接受率 `≤ δ_gate`，并对门控通过的仿真样本保留 `sim_flag` 以便事后审计。
6. **刷新振荡**：频繁刷新导致行为不一致 → 每次刷新设最小间隔 `T_refresh`，金丝雀期冻结再训练，版本回滚保留最近 3 版。
7. **数据合规与隐私**：真人演示/遥操作含操作者信息 → 谱系记录 license 与脱敏标记，合规数据才可进入 `provenance DAG`。
