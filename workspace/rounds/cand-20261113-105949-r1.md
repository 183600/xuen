# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 1 轮·新循环；本轮灵感：「动态避障」×「数据质量」）

> 第 66 轮 RAS 把闭环从「故障响应」推进到「意图感知」，却仍默认一个前提：**进入闭环的数据本身是可信的**。RAS 讨论了情绪观测的噪声，但没有回答更底层的问题——**这些观测凭什么被相信？** 当障碍是动态的（行人横穿、叉车抢道、传送带物体滑落），数据就不再是静态地图上的一枚点，而是一份**会过期的证词**：它在采集时刻为真，却可能在机器人抵达时已经失效。
>
> 本轮灵感的核心命题：
>
> **把「数据质量」从工程指标提升为避障证书的一等公民：动态避障不再问「障碍在哪」，而问「我凭什么相信它在那儿，并且在我抵达时它仍在那儿、仍在我算的位置」。**
>
> DQ-DAO（Data-Quality-certified Dynamic Obstacle Avoidance）把 VISTA 的「哪层坏了」、RAS 的「谁控制、控制多少」推进到 **「哪份数据值得信、何时必须重新观测」**。它把数据的**新鲜度、覆盖度、一致性、溯源**四条质量轴，直接编译进避障管的膨胀半径与认证前缀。

## 0. 直觉与动机

**灵感 1（动态避障 → 数据的「保质期」）**
直觉：静态避障里，地图是一次性测好的资产；动态避障里，每个障碍样本都像**生鲜**——它有一个采集时刻，也有一个随障碍运动而加速贬值的保质期。传统做法把「感知延迟」当作一个固定常数塞进安全裕度，但动态场景下延迟的危害与**障碍速度**乘积相关：同一个 100ms 的旧样本，对静止纸箱几乎无害，对 2m/s 的横穿行人却是 20cm 的位置偏差。**数据质量不是布尔值，而是随时间与相对运动衰减的连续量。**

**灵感 2（数据质量 → 四轴张成的时空场）**
直觉：如果只用一个标量「质量分」去概括数据，就会丢失方向性——一张很新但被遮挡的图，与一张很旧但覆盖完整的图，谁更值得信取决于「你要问什么」。因此质量应是**四轴张成的可分解场**：
- **新鲜度 freshness**：`τ = t - t_capture`，与相对速度耦合；
- **覆盖度 coverage**：障碍预测包络落在已观测/无遮挡区域的比例；
- **一致性 consistency**：多源（多帧、多传感器、地图先验）互相印证的程度；
- **溯源 provenance**：传感器标定龄期、固件版本、时间同步健康度。
质量泛函 `Q = q_fresh · q_cover · q_consist · q_prov`，任一轴归零则整份数据不可用于决策——这是「木桶」而非「加权平均」。

**灵感 3（动态避障 × 数据质量 → 质量膨胀的避障管）**
直觉：与其在规划后「加一个安全裕度」，不如让**质量直接决定几何**。把障碍预测的位置协方差按 `1/Q` 放大：质量越低，同一份观测对应的**不确定性管越粗**；管越粗，可通行通道越窄，直到认证视界归零。这把「数据质量」翻译成了规划器唯一听得懂的语言——**几何**。安全边界从「障碍半径 + 固定裕度」变成「障碍半径 + κ·σ/Q + v·τ」。

**灵感 4（数据质量 → 主动数据续期 ADR）**
直觉：如果质量会过期，那么最优策略不是「更保守地停」，而是**在对的时间去重新看一眼**。主动数据续期（Active Data Renewal）把「感知」当成为证书「续签」的动作：当沿前瞻轨迹的最小预测质量跌破 `Q_min`，就选择预期质量增益/成本比最高的一次重观测（转向、变焦、换传感器、请求协同）。这形成一条与 RAS 同构、但以**数据保质期**为时钟的闭环。

**灵感 5（组件升级：质量优先的降级阶梯）**
- **VISTA-FIR → DQ-FIR**：故障假设集新增数据维度 `D = {D0 正常, D1 陈旧, D2 遮挡, D3 不一致, D4 损坏}`；
- **CSC/C-RAS → DQ-Cert**：认证前缀不是被「算」出来的，而是被「质保」出来的——`k*_DQ` 是沿轨迹质量首次跌破 `Q_min` 的位置；
- **RAS 的 λ_risk → 质量门控 α_Q**：情绪/风险仍可缩放控制量，但**质量是乘性前置门**——质量不过关时，任何情绪放宽都不得生效；
- **AIC-V → DQ-AIC**：干扰集新增**相关陈旧**（所有传感器同源时钟偏移）与**共因遮挡**；
- **J_RAS → J_DQ**：证书附质量台账 `quality_ledger = [(source, τ, Q_axes, hash)]`，可审计、可复现。

## 1. 形式化定义（增量：定义 245–258）

- **定义 245（DQ-DAO 总览）**：DQ-DAO = (DQO, QAT, DQC, ADR, DQ-FIR, QDL, DQ-AIC)。定位：RAS 的「意图闭环」再下沉一层，升级为「证据闭环」。不变式：质量评估、台账、证书构建只在语义流；实时流只做质量阈值早停与续期触发，零学习写操作。
- **定义 246（数据项与溯源）**：数据项 `d = (x, t_capture, src, Σ, cov, ver, hash)`，其中 `x` 为观测（障碍中心/速度/包络），`t_capture` 为采集时刻，`src` 为源标识，`Σ` 为观测协方差，`cov` 为覆盖掩码，`ver` 为标定/固件版本，`hash` 为内容摘要。
- **定义 247（数据质量泛函）**：`Q(d,t) = q_fresh(τ) · q_cover(cov) · q_consist(d, peers) · q_prov(src, ver)`，其中 `τ = t - t_capture`。四轴取值均在 `[0,1]`，任一分量为 0 时 `Q = 0`（木桶律，不做加权平均）。
- **定义 248（新鲜度衰减与相对速度耦合）**：`q_fresh(τ) = exp(-λ_f · τ · (1 + β_f·||v_obs||))`。静止障碍的保质期最长；相对速度越高，同一份数据的半衰期越短。
- **定义 249（质量膨胀的避障管）**：在预测时刻 `t`，障碍不确定性半径 `r_tube(d,t) = r_obs + κ_Q · σ_base / max(Q(d,t), ε) + ||v_obs||·τ`。认证要求对轨迹上所有 `s ≤ H`：`dist(path(s), center(d,s)) > r_tube(d,s)`。
- **定义 250（质量契约与认证视界）**：给定沿轨迹的质量下界 `Q_min`，认证视界 `H_dq = max{ h : ∀s≤h, Q(d,t+s) ≥ Q_min }`。证书只对 `[0, H_dq]` 内的执行前缀有效；`H_dq = 0` 意味着当前数据不足以支撑任何运动。
- **定义 251（质量-故障联合假设）**：`ℋ_DQ = H_VISTA × D`，`D = {D0 正常, D1 陈旧, D2 遮挡, D3 不一致, D4 损坏}`；后验 `P(H,D | ρ, d) ∝ p(ρ|H)·p(d|D)·P(H)·P(D|H)`。质量与故障共享「数据 DNA」，用于区分「世界变了」与「我看错了」。
- **定义 252（DQ-FIR 数据故障归因）**：数据故障签名 `ψ(d) = (τ, c, KL_peer, prov_age)` 映射到 32 维签名的数据子空间；当 `D1/D2/D3` 后验占优时，**不膨胀几何球、也不放宽容差，而是把认证视界截短**。
- **定义 253（主动数据续期 ADR）**：续期动作 `a ∈ 𝒜_renew`（转向/变焦/切换传感器/请求协同/等待），其净收益 `G(a) = κ_g·E[ΔQ(a)]·V_horizon − (c_sense(a) + λ_l·latency(a))`；当 `min_{s≤H} Q < Q_min` 时触发 `a* = argmax G(a)`。
- **定义 254（质量驱动的降级阶梯 QDL）**：`L0` 全速认证；`L1` 降速并膨胀管；`L2` 停扫式主动续期；`L3` 安全停车。转移条件由 `H_dq` 与 `Q_min` 的比值决定，**只允许逐级下降、验证后逐级恢复**（避免质量抖动引发振荡）。
- **定义 255（质量门控控制）**：`u_ctrl = α_Q(Q) · clip(λ_risk · u_base)`，`α_Q = 0` 当 `Q < Q_min`。质量是**乘性前置门**：情绪/风险只能收缩控制量，不能越过质量约束放行。
- **定义 256（DQ 证书）**：`J_DQ = (J_RAS, quality_ledger, H_dq, Q_min, dq_aic_ver, clock_sync_health)`。`Valid ⇔ Valid(J_RAS) ∧ H_dq ≥ h_req ∧ clock_sync_health ≥ 0.9`。
- **定义 257（质量-规划安全集）**：`S_Q = { (x,u) : ∀s≤H_dq, tube_safe(d,s) ∧ Q(d,t+s) ≥ Q_min }`。规划在 `S_Q` 上求解，而非在原始自由空间上求解。
- **定义 258（质量台账的可审计性）**：对任意执行前缀，存在可重放的台账序列 `{(src_i, τ_i, Q_i, hash_i)}`，使第三方能独立复算 `H_dq` 与证书有效性。

## 2. 关键算法骨架

```python
class DataQualityObserver:
    def __init__(self, lam_f=1.0, beta_f=0.5, eps=1e-3):
        self.lam_f, self.beta_f, self.eps = lam_f, beta_f, eps

    def assess(self, d, t, peers, coverage):
        tau = t - d.t_capture
        q_fresh = exp(-self.lam_f * tau * (1 + self.beta_f * norm(d.v_obs)))
        q_cover = coverage.mask_ratio(d.predicted_extent())
        q_consist = exp(-mahalanobis(d, peers))
        q_prov = self.provenance_score(d.src, d.ver, d.calib_age)
        Q = q_fresh * q_cover * q_consist * q_prov
        return {'Q': Q, 'axes': (q_fresh, q_cover, q_consist, q_prov),
                'tau': tau, 'sigma_Q': d.Sigma / max(Q, self.eps)}


class QualityAvoidanceCertifier:
    def certified_horizon(self, d, path, Q_min):
        for s in range(len(path)):
            if self.qo.predict(d, self.dt * s) < Q_min:
                return s
        return len(path)

    def tube_safe(self, d, path, s, Q):
        t = self.dt * s
        sigma = d.Sigma / max(Q, 1e-3)
        r = d.r_obs + self.kappa * sigma + norm(d.v_obs) * t
        return dist(path(s), d.center_at(t)) > r

    def certified_prefix(self, dq, path, Q_min):
        k = 0
        for s in range(len(path)):
            Q = self.qo.predict(dq, self.dt * s)
            if Q < Q_min or not self.tube_safe(dq, path, s, Q):
                break
            k = s
        return k


class ActiveDataRenewal:
    def triggered(self, d, horizon, Q_min):
        return min(self.qo.predict(d, s) for s in horizon) < Q_min

    def choose(self, actions, value):
        best, best_g = None, -inf
        for a in actions:
            gain = self.expected_quality_gain(a)          # E[ΔQ(a)]
            cost = a.sense_cost + self.lam_l * a.latency   # 续期成本
            g = self.kappa_g * gain * value - cost
            if g > best_g:
                best, best_g = a, g
        return best


class DQDcertificate:
    def build(self, J_ras, ledger, H_dq, Q_min, clock_health):
        valid = (J_ras.valid and H_dq >= self.h_req
                 and clock_health >= 0.9)
        return {'J_ras': J_ras, 'ledger': ledger, 'H_dq': H_dq,
                'Q_min': Q_min, 'clock_health': clock_health,
                'valid': valid}


def DQ_DAO_round(M, obs, goal):
    # 1) 质量评估：每个数据项四轴分解
    dq = M.dqo.assess_all(obs, t=M.clock.now())

    # 2) 在质量-规划安全集 S_Q 上求解
    path = M.planner.plan(goal, safe_set=M.safe_set(dq, M.Q_min))

    # 3) 沿轨迹计算认证视界；若质量不足则主动续期
    H_dq = min(M.cert.certified_horizon(d, path, M.Q_min) for d in dq)
    if H_dq < len(path):
        a = M.adr.choose(M.renew_actions(), value=len(path) - H_dq)
        if a is not None:
            obs = M.execute_renew(a)
            dq = M.dqo.assess_all(obs, t=M.clock.now())
            path = M.planner.plan(goal, safe_set=M.safe_set(dq, M.Q_min))

    # 4) DQ-FIR：区分「世界变了」与「我看错了」
    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    post_HD = M.dq_fir.attribute(rho, dq)

    # 5) 质量门控 + 认证前缀
    k_dq = M.cert.certified_prefix(dq, path, M.Q_min)
    alpha_Q = M.qdl.gate(H_dq, M.Q_min)
    u_cmd = alpha_Q * M.ras.scale(post_HD) * M.pi_sigma.dispatch(path[:k_dq])

    # 6) 证书
    J_dq = M.dqc.build(M.ras.certificate(post_HD), M.dqo.ledger(dq),
                       H_dq, M.Q_min, M.clock.health())
    return k_dq, H_dq, alpha_Q, J_dq
```

## 3. 推导

**引理 11（质量衰减 → 认证视界收缩）** 设 `q_consist, q_cover, q_prov` 在短视界内近似常数 `c > 0`，则 `Q(t+s) = c·exp(-λ_f(1+β||v||)s)` 单调递减，认证视界满足 `H_dq = (1/(λ_f(1+β||v||)))·ln(c/Q_min)`。即：**相对速度翻倍，认证视界近似减半**；数据质量天然把「动态」编码成「可执行的时间预算」。

**引理 12（主动续期的收益上界）** 若续期将质量从 `Q` 恢复到 `Q' > Q_min`，则恢复的认证视界增量为 `ΔH = (1/(λ_f(1+β||v||)))·ln(Q'/Q)`。只有当 `κ_g·ΔH·V > c_sense + λ_l·latency` 时续期才划算。这给出了「**该看还是该停**」的显式判据，避免无脑停车。

**定理 11（DQ-DAO 端到端质量-安全一致性）** 若质量估计满足 `|Q̂ - Q| ≤ ε_Q`，且安全裕度满足 `m ≥ κ_Q·σ_base/(Q_min - ε_Q)`，则对任意执行前缀 `[0,k_dq]`：
1. `P(collision) ≤ α_chunk + δ_fi + P(|Q̂ - Q| > ε_Q)`；
2. `Q̂ ≥ Q_min ⇒ 质量调整后的管不侵入真实占用区`；
3. `Q̂ < Q_min ⇒ α_Q = 0`，控制量被质量门直接截断，**情绪/风险不得越过质量约束**。

**定理 12（质量-故障的可分离归因）** 在 `D` 与 `H_VISTA` 条件独立、且数据签名子空间与几何/传感签名子空间近似正交时，联合可辨识矩阵 `S_DQ ≈ diag(S_H, S_D)`，`κ_dq = min(κ_fi, κ_data)`。当 `D1/D2/D3` 后验占优时，截短认证视界而不膨胀几何球，可避免把「数据陈旧」误归因成「几何故障」、从而触发不必要的激进降级。

## 6. 本轮最大风险

**一句话**：DQ-DAO 用「数据质量」来认证数据本身，却无法跳出**自我指涉的盲区**——质量估计器读的仍是同一批可能已整体退化（全源时钟偏移、共因遮挡、标定漂移）的数据；一旦相关退化让 `Q̂` 系统性虚高，证书就会把「过期的证词」判为新鲜，从而在**看似有质量保障**的外壳下放行本应停车的动作——这是本轮全部理论所依赖的核心假设：**质量退化是可被独立观测的、且各源退化不相关**，而这一假设在共因故障下恰恰最脆弱。

# 第 67 轮产物 · 创新点清单 v1：DQ-DAO（Data-Quality-certified Dynamic Obstacle Avoidance：数据质量认证的动态避障；DQO×QAT×DQC×ADR×DQ-FIR×QDL）

> 承接第 66 轮 IP-224~233（RAS：情绪驱动的闭环控制）与第 65 轮 IP-214~223（VISTA：故障可归因闭环）。VISTA 解决「哪层坏了」，RAS 解决「谁控制、控制多少」，本轮解决更底层的问题：**凭什么相信数据、何时必须重新观测**。把「数据质量」编译进避障几何与认证前缀，构成以数据保质期为时钟的证据闭环。
>
> IP 编号：IP-234~IP-243（共 10 个），全部为 DQ-DAO 的核心组件。

## 0. 核心 IP 设计

## 2. 形式化定义（完整版）

**定义 245（DQ-DAO 总览）** DQ-DAO 是 RAS「意图闭环」再下沉一层的「证据闭环」：
```
DQ-DAO = (DQO, QAT, DQC, ADR, DQ-FIR, QDL, DQ-AIC)
```
不变式：质量评估、台账、证书构建只在语义流；实时流只做质量阈值早停与续期触发，零学习写操作。

**定义 246（数据项与溯源）** 数据项 `d = (x, t_capture, src, Σ, cov, ver, hash)`；`x` 为障碍观测，`t_capture` 为采集时刻，`Σ` 为观测协方差，`cov` 为覆盖掩码，`ver` 为标定/固件版本，`hash` 为内容摘要。

**定义 247（数据质量泛函）**
```
Q(d,t) = q_fresh(τ)·q_cover(cov)·q_consist(d,peers)·q_prov(src,ver,calib_age)
```
四轴均取 `[0,1]`，任一分量为 0 则 `Q=0`（木桶律，不做加权平均）。

**定义 248（新鲜度衰减与相对速度耦合）**
```
q_fresh(τ) = exp(-λ_f·τ·(1 + β_f·‖v_obs‖)),  τ = t - t_capture
```
静止障碍保质期最长；相对速度越高，同一份数据的半衰期越短。

**定义 249（质量膨胀的避障管）** 预测时刻 `t` 的不确定性半径
```
r_tube(d,t) = r_obs + κ_Q·σ_base / max(Q(d,t), ε) + ‖v_obs‖·τ
```
认证要求对轨迹上所有 `s≤H`：`dist(path(s), center(d,s)) > r_tube(d,s)`。

**定义 250（质量契约与认证视界）**
```
H_dq = max{ h : ∀s≤h, Q(d,t+s) ≥ Q_min }
```
证书只对 `[0,H_dq]` 内的执行前缀有效；`H_dq=0` 表示当前数据不足以支撑任何运动。

**定义 251（质量-故障联合假设）**
```
ℋ_DQ = H_VISTA × D,  D = {D0 正常, D1 陈旧, D2 遮挡, D3 不一致, D4 损坏}
P(H,D|ρ,d) ∝ p(ρ|H)·p(d|D)·P(H)·P(D|H)
```

**定义 252（DQ-FIR 数据故障归因）** 数据签名 `ψ(d)=(τ, c, KL_peer, prov_age)` 映射到 32 维签名的数据子空间；当 `D1/D2/D3` 后验占优时，**不膨胀几何球、不放宽容差，而是截短认证视界**。

**定义 253（主动数据续期 ADR）** 续期动作 `a∈𝒜_renew`（转向/变焦/换传感器/请求协同/等待）：
```
G(a) = κ_g·E[ΔQ(a)]·V_horizon − (c_sense(a) + λ_l·latency(a))
```
当 `min_{s≤H} Q < Q_min` 时触发 `a* = argmax G(a)`。

**定义 254（质量驱动降级阶梯 QDL）** `L0` 全速认证；`L1` 降速并膨胀管；`L2` 停扫续期；`L3` 安全停车。只允许逐级下降、验证后逐级恢复，避免质量抖动引发振荡。

**定义 255（质量门控控制）**
```
u_ctrl = α_Q(Q)·clip(λ_risk·u_base),  α_Q(Q)=0 当 Q < Q_min
```
质量是乘性前置门：情绪/风险只能收缩控制量，不能越过质量约束放行。

**定义 256（DQ 证书）**
```
J_DQ = (J_RAS, quality_ledger, H_dq, Q_min, clock_sync_health, dq_aic_ver)
Valid ⇔ Valid(J_RAS) ∧ H_dq ≥ h_req ∧ clock_sync_health ≥ 0.9
```

**定义 257（质量-规划安全集）**
```
S_Q = { (x,u) : ∀s≤H_dq, tube_safe(d,s) ∧ Q(d,t+s) ≥ Q_min }
```
规划在 `S_Q` 上求解，而非在原始自由空间上求解。

**定义 258（质量台账可审计性）** 对任意执行前缀，存在可重放台账 `{(src_i, τ_i, Q_i, hash_i)}`，第三方可独立复算 `H_dq` 与证书有效性。

## 3. 关键算法伪代码

```python
# IP-234 DQO
class DataQualityObserver:
    def __init__(self, lam_f=1.0, beta_f=0.5, eps=1e-3):
        self.lam_f, self.beta_f, self.eps = lam_f, beta_f, eps

    def assess(self, d, t, peers, coverage):
        tau = t - d.t_capture
        q_fresh = exp(-self.lam_f * tau * (1 + self.beta_f * norm(d.v_obs)))
        q_cover = coverage.mask_ratio(d.predicted_extent())
        q_consist = exp(-mahalanobis(d, peers))
        q_prov = self.provenance_score(d.src, d.ver, d.calib_age)
        Q = q_fresh * q_cover * q_consist * q_prov
        return {'Q': Q, 'axes': (q_fresh, q_cover, q_consist, q_prov),
                'tau': tau, 'sigma_Q': d.Sigma / max(Q, self.eps)}


# IP-235/IP-236 QAT + DQC
class QualityAvoidanceCertifier:
    def certified_horizon(self, d, path, Q_min):
        for s in range(len(path)):
            if self.qo.predict(d, self.dt * s) < Q_min:
                return s
        return len(path)

    def tube_safe(self, d, path, s, Q):
        t = self.dt * s
        sigma = d.Sigma / max(Q, 1e-3)
        r = d.r_obs + self.kappa * sigma + norm(d.v_obs) * t
        return dist(path(s), d.center_at(t)) > r

    def certified_prefix(self, dq, path, Q_min):
        k = 0
        for s in range(len(path)):
            Q = self.qo.predict(dq, self.dt * s)
            if Q < Q_min or not self.tube_safe(dq, path, s, Q):
                break
            k = s
        return k


# IP-237 ADR
class ActiveDataRenewal:
    def triggered(self, d, horizon, Q_min):
        return min(self.qo.predict(d, s) for s in horizon) < Q_min

    def choose(self, actions, value):
        best, best_g = None, -inf
        for a in actions:
            gain = self.expected_quality_gain(a)          # E[ΔQ(a)]
            cost = a.sense_cost + self.lam_l * a.latency   # 续期成本
            g = self.kappa_g * gain * value - cost
            if g > best_g:
                best, best_g = a, g
        return best


# IP-238 DQ-FIR
class DataQualityFaultAttribution:
    def attribute(self, rho, dq):
        post_H = self.fir.attribute(rho)          # 7 类几何/传感/模型
        post_D = self.data_classifier(dq)         # 5 类数据
        joint = {(h, d): post_H[h] * post_D[d]
                 for h in post_H for d in post_D}
        return normalize(joint)


# IP-239 QDL
class QualityDegradationLadder:
    LEVELS = ['L0', 'L1', 'L2', 'L3']
    def gate(self, H_dq, Q_min):
        r = H_dq / max(self.h_req, 1e-6)
        if r >= 1.0: return 1.0
        if r >= 0.6: return 0.7
        if r >= 0.2: return 0.3
        return 0.0


# IP-242 闭环
def DQ_DAO_round(M, obs, goal):
    dq = M.dqo.assess_all(obs, t=M.clock.now())
    path = M.planner.plan(goal, safe_set=M.safe_set(dq, M.Q_min))

    H_dq = min(M.cert.certified_horizon(d, path, M.Q_min) for d in dq)
    if H_dq < len(path):
        a = M.adr.choose(M.renew_actions(), value=len(path) - H_dq)
        if a is not None:
            obs = M.execute_renew(a)
            dq = M.dqo.assess_all(obs, t=M.clock.now())
            path = M.planner.plan(goal, safe_set=M.safe_set(dq, M.Q_min))

    rho = M.vista.fir.signature(M.vista.stage.split(M.vista.residual_log))
    post_HD = M.dq_fir.attribute(rho, dq)
    k_dq = M.cert.certified_prefix(dq, path, M.Q_min)
    alpha_Q = M.qdl.gate(H_dq, M.Q_min)
    u_cmd = alpha_Q * M.ras.scale(post_HD) * M.pi_sigma.dispatch(path[:k_dq])

    J_dq = M.dqc.build(M.ras.certificate(post_HD), M.dqo.ledger(dq),
                       H_dq, M.Q_min, M.clock.health())
    return k_dq, H_dq, alpha_Q, J_dq
```

## 4. 推导

**引理 11（质量衰减 → 认证视界收缩）** 若 `q_cover,q_consist,q_prov ≈ c`，则 `Q(t+s)=c·exp(-λ_f(1+β‖v‖)s)` 单调递减，`H_dq = ln(c/Q_min)/(λ_f(1+β‖v‖))`。相对速度翻倍，认证视界近似减半。

**引理 12（主动续期收益上界）** 续期把质量从 `Q` 恢复到 `Q'>Q_min`，认证视界增量 `ΔH = ln(Q'/Q)/(λ_f(1+β‖v‖))`。仅当 `κ_g·ΔH·V > c_sense + λ_l·latency` 时续期划算，给出「该看还是该停」的显式判据。

**定理 11（DQ-DAO 端到端质量-安全一致性）** 若 `|Q̂−Q|≤ε_Q` 且 `m ≥ κ_Q·σ_base/(Q_min−ε_Q)`，则对 `[0,k_dq]`：
1. `P(collision) ≤ α_chunk + δ_fi + P(|Q̂−Q|>ε_Q)`；
2. `Q̂ ≥ Q_min ⇒ 质量调整后的管不侵入真实占用区`；
3. `Q̂ < Q_min ⇒ α_Q=0`，控制量被质量门直接截断，情绪/风险不得越过质量约束。

**定理 12（质量-故障可分离归因）** 在 `D ⟂ H_VISTA` 且签名子空间近似正交时，`S_DQ ≈ diag(S_H,S_D)`，`κ_dq = min(κ_fi,κ_data)`。当 `D1/D2/D3` 后验占优时，截短认证视界而不膨胀几何球，避免把「数据陈旧」误归因为「几何故障」。

## 7. 本轮最大风险

**一句话**：DQ-DAO 用「数据质量」认证数据本身，却跳不出**自我指涉的盲区**：质量估计器读的仍是同一批可能已整体退化（全源时钟偏移、共因遮挡、标定漂移）的数据；一旦相关退化让 `Q̂` 系统性虚高，证书就会把过期证词判为新鲜，在看似有质量保障的外壳下放行本应停车的动作——本轮全部理论依赖的核心假设是「质量退化可被独立观测且各源退化不相关」，而它在共因故障下恰恰最脆弱。
