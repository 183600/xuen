# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 8 轮；本轮灵感：「视觉语言模型」×「工具调用」）

> 第 61 轮构建了 ESEC：USR 统一语义表征、MEL 多模态具身大模型、DMS 多轮对话、SRT-Dual 语义-实时双流、PCE+++++ 六维预算。其核心是让「场景→意图→约束→执行→证据」在共享语义空间中闭环。但**四个更深层的局限**在本轮暴露：
> 1. **MEL 是单体模型，无法复用专门能力**：物理属性、抓取规划、标定、碰撞检查、仿真验证全被塞进一个 VLM+多头网络。真实具身系统需要按需调用**外部工具**（触觉物理探针、抓取规划器、运动学求解器、安全验算器、标定例程、经验数据库）。单体模型既难更新、难审计，也无法享受专用工具的精度与可解释性。
> 2. **语义嵌入不可执行、不接地**：USR 中的 `scene_emb` 是不可解释的稠密向量，VLM 能说「抓那个杯子」，却没有把「那个」绑定到具体的**实例 ID、掩码、3D 位姿、坐标系与单位**。而工具调用恰恰要求精确参数；没有视觉接地，工具参数只能由语言模型「编」，于是出现**参数幻觉**（错误实例、毫米/米混用、相机系/基座系混用）。
> 3. **组合可靠性缺失**：第 61 轮只有 MEL 的一对不确定性标量 `(U_ep, U_al)`，没有**跨工具链的不确定性传播**，也没有工具前置/后置条件、失败模式与证书。多工具串联时误差与失效静默累积，最终以「看起来很合理」的语义锚点污染实时控制。
> 4. **工具调用与实时性的三重矛盾**：工具调用比 MEL 更慢、更长尾；VLM 可能生成语法合法但物理错误的调用图；工具失败后缺少**回滚与降级阶梯**。SRT-Dual 只解耦了「一个模型」与实时环，尚未解耦「一张工具调用图」与实时环。
>
> 本轮把「工具」提升为一等公民：VLM 不直接输出控制量，也不直接输出不可执行的嵌入，而是生成**类型化、视觉接地、带契约、可证书化**的工具调用 DAG，并让整张图在语义流中运行，实时流仍只消费一只经过证书门控的语义锚点。

## 0. 直觉与动机

**灵感 1（视觉语言模型 → 视觉工具编排器 VTO）**
直觉：VLM 最强的不是「端到端回归一个数」，而是「看图说话 + 按格式输出」。这正好适合做**工具编排**：输入目标、图像、深度、本体状态与工具清单，输出一张「先调用哪个工具、参数是什么、结果喂给谁」的调用图。关键洞见：VLM 的角色从「感知头 + 策略头」升级为**编译器前端**——把自然语言目标与视觉场景编译成一张类型化的工具调用 DAG；真正的数值计算与物理交互交给专用工具。这样模型可以替换、工具可以插拔、每一步可审计。

**灵感 2（视觉语言模型 → 视觉接地约束的参数绑定 GAB）**
直觉：人类说「抓左边那个红色的」，听者会先用眼睛把「左边/红色」落到一个具体物体上，再动手。VLM 的工具调用也必须先「用眼睛落地」：每个实体类参数（杯子、把手、放置区）都必须绑定到视觉场景图中的一个**指代记录**——实例 ID、像素掩码、3D 位姿、坐标系、单位、置信度。关键洞见：**参数不是文本，而是指向视觉证据的引用**；任何无法接地的参数都应触发「重接地 / 澄清 / 降级」而不是被自由生成。这把工具调用的幻觉从「非法输出」变成「可检测的接地失败」。

**灵感 3（工具调用 → 类型化工具契约代数 TCA）**
直觉：软件工程里函数调用靠类型与契约保证组合正确；机器人工具更需要——因为参数错一个单位就可能撞坏东西。关键洞见：给每个工具定义**前置条件、后置条件、延迟/失败分布、成本、幂等性、证书 schema**；当 VLM 把工具串成 DAG 时，用「契约代数」做静态闭合检查：`post(A)` 必须与 `pre(B)` 在类型、单位、坐标系上可合一。只有**契约闭合**的 DAG 才允许进入执行候选集，执行后每个工具产出可验证证书。

**灵感 4（工具调用 → 工具链不确定性传播与验证 VOI TUPT）**
直觉：多个工具串联时，误差不是简单相加，而是被雅可比放大/压缩；一个 90% 可靠的抓取检测器接一个 90% 可靠的规划器，端到端可能只有 81%。关键洞见：把每个工具输出视为带协方差的随机量，沿 DAG 传播得到**任务级不确定性 `U_task`**；当 `U_task` 超过风险预算时，用**价值 of 信息（VOI）**决定是否值得调用一个更慢但更准的验证工具（如仿真回放、二次触觉探测）。不确定性因此从「一个标量」变成「可路由的预算信号」。

**灵感 5（工具调用 → 投机工具执行与单调降级阶梯 STE/TFL）**
直觉：人类用工具时会「先按经验预取下一步要用的扳手」，也会在扳手不合适时换小一号、再不行就用手拧、最后叫人。关键洞见：VLM 可预测接下来最可能的 k 个工具调用并**投机预执行**（只允许幂等或可回滚工具），命中则省一个往返；未命中则取消。工具失败时走**单调保守的降级阶梯**：精确工具 → 蒸馏代理 → 解析先验 → 保守安全动作 → 中止/澄清。投机减少延迟，阶梯保证失败不失控。

**灵感 6（三者合流 → 工具增强语义锚点与联合证书 TASA/J_tool）**
直觉：第 61 轮的语义锚点只说「我相信这个嵌入」，却说不清「这个结论由哪些工具、哪些接地记录、哪张契约图支撑」。关键洞见：锚点必须携带**工具溯源图**——每个语义维度来自哪个工具、绑定了哪些视觉实例、契约是否闭合、端到端不确定性多大。实时流只接受通过 `J_tool` 门控的锚点，实现「可审计的语义先行」。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（视觉场景图与接地指代空间 VSG）** 时刻 t 的视觉场景图
```
G_t = (O_t, R_t, A_t, F_t, P_t)
```
- `O_t`：实例集合，`o = (id, mask, pose ∈ SE(3), bbox, attrs, conf, frame)`；
- `R_t`：关系集合（on / in / near / occludes / part_of / graspable_by）；
- `A_t`：可供性集合，`a = (object_id, region_mask, grasp_type, score)`；
- `F_t`：坐标帧树（世界系 / 基座系 / 相机系 / 末端系），带 `T_frame ∈ SE(3)`；
- `P_t`：溯源，记录每个节点由哪一传感器/工具/时刻写入。
接地算子 `g(ℓ | G_t) ∈ Δ(O_t)` 把指代表达 `ℓ`（文本 + VLM 视觉 token）映射为实例分布；候选召回由掩码/属性/关系检索完成，VLM 只做重排序，避免纯语言先验主导。

**定义 174（工具注册表与类型化工具契约 TTC）** 工具
```
τ = (name, cap, Sig, Pre, Post, Lat, Fail, Cost, Cert, Idem, SafeSpec)
```
- `Sig`：类型化签名，参数类型含 `EntityRef / Region / Pose6D / Quantity[u] / Enum / Tensor`；
- `Pre`：关于参数与世界的逻辑前置条件（如 `pose ∈ Workspace ∧ |v| < v_max`）；
- `Post`：关于输出与世界的后置断言（如 `grasp_plan.success ∧ clearance > 0`）；
- `Lat`：延迟分布；`Fail`：失败模式分布；`Cost`：算力/能量/时间成本；
- `Cert`：执行证书 schema；`Idem`：是否幂等；`SafeSpec`：是否允许投机执行。
工具注册表 `T = {τ_i}`，能力检索 `Retrieve(cap, G_t) → 候选工具子集`。

**定义 175（视觉工具编排 VTO）** VLM 生成的工具调用计划是一张带参数绑定的有向无环图
```
π_tool = (V_π, E_π, β, ord)
```
其中节点 `v = (τ_v, arg_v)`，边 `(u,v)` 表示 `out(u)` 作为 `v` 的输入；`β` 是参数绑定映射；`ord` 是拓扑序。计划合法需同时满足：类型可合一、每个 `EntityRef` 已接地、每条边的 `post(u)` 与 `pre(v)` 可合一、拓扑序存在。VTO 的目标是最大化 `P(success | π_tool) - λ·Cost(π_tool)`，而非最大化语言似然。

**定义 176（视觉接地约束的参数绑定 GAB）** 对参数 `a` 的绑定记录
```
b(a) = (var, referent_id, mask, pose, frame, unit, conf_ground, source, ambiguity)
```
绑定有效谓词：
```
ValidBind(b) ⇔ conf_ground ≥ τ_g
             ∧ frame ∈ F_t ∧ unit_dim_ok(a)
             ∧ pose ∈ Workspace_safe
             ∧ ambiguity_margin(b) ≥ τ_Δ
```
其中 `ambiguity_margin = p_(1) - p_(2)`（最高与次高指代概率差）。若 `ValidBind` 失败，修复动作集
`R = {reground(ℓ), clarify(ℓ), constrain_search(ℓ), fallback_tool(cap), abort}`；
**禁止**在绑定无效时让语言模型自由补全参数。

**定义 177（工具契约代数 TCA）** 支持三种组合：
- 顺序 `A ; B`：若 `unify(post_A, pre_B, μ_frame, μ_unit)` 成立，则
  `pre = pre_A`，`post = post_B`，`Lat = Lat_A ⊕ Lat_B`，`Fail = 1-(1-Fail_A)(1-Fail_B)`；
- 并行 `A ∥ B`：要求无写冲突，`pre = pre_A ∧ pre_B`，`post = post_A ∧ post_B`；
- 条件 `if c then A else B`：`post = (c ∧ post_A) ∨ (¬c ∧ post_B)`。
DAG 契约闭合定义为
```
Closed(π_tool) ⇔ ∀(u,v) ∈ E_π : unify(post_u, pre_v) ∧ ∀a ∈ args : ValidBind(b(a))
```
闭合 DAG 的最弱前置条件由后向替换 `wp(π_tool, Post_goal)` 给出；不可满足即拒绝执行。

**定义 178（工具链不确定性传播 TUPT）** 每个工具输出 `y_i` 带协方差 `Σ_i`（由 `Fail` 与校准残差估计）。沿 DAG 用一阶传播
```
Σ_out = Σ_i J_i Σ_i J_iᵀ + Σ_model + Σ_bind
```
（`Σ_bind` 来自接地位姿误差）或蒙特卡洛 `M` 次采样得 `U_task`。端到端风险
```
Risk(π_tool) = P(g_exec(s,a) ∈ Unsafe) 
```
以保守分位数上界估计；验证工具 `τ_ver` 的调用价值
```
voi(τ_ver) = E[ΔRisk] - λ_lat·E[Lat_ver] - λ_c·Cost_ver
```
仅当 `voi > 0` 且 `B_tool.verify` 允许时调用。

**定义 179（投机工具执行 STE）** 给定 VLM 的下一调用预测分布 `q(v_{i+1} | π, G_t)`，取 top-k 投机集 `S_k`。仅当 `τ ∈ S_k ∧ τ.Idem ∧ τ.SafeSpec` 才可预执行；提交条件
```
Commit(v) ⇔ v ∈ π_tool_final ∧ ValidBind(b(arg_v)) ∧ Post_v(y_v)
```
否则取消；对非幂等工具只允许「预取只读前驱」而不允许副作用。投机浪费受 `B_tool.spec` 硬约束。

**定义 180（工具降级阶梯 TFL）** 对每种能力 `cap` 定义有序阶梯
```
Ladder(cap) = [τ_1 ⊐ τ_2 ⊐ ... ⊐ τ_L]
```
`τ_i ⊐ τ_{i+1}` 表示 `τ_i` 更精确但更慢/更贵，`τ_{i+1}` 更保守且不确定性区间包含前者。失败或预算不足时沿阶梯下降；所有层级都必须满足 ERTC 安全约束。阶梯耗尽 ⇒ `ask_clarify` 或 `abort`，绝不「硬凑一个参数继续」。

**定义 181（工具增强语义锚点 TASA）** 升级定义 161 的语义锚点：
```
Anchor_t = (version, scene_emb, intent_emb, phys_prior,
            tool_prov, contract_cert, U_task, grounding_set, ts)
```
- `tool_prov`：工具 DAG 哈希 + 每个语义维度的来源工具集合；
- `contract_cert`：契约闭合证明 + 各工具执行证书根；
- `grounding_set`：被引用的 `{b(a)}`；
- 融合按证书质量与不确定性加权：
  `fused_emb = Σ_i w_i·emb_i`，`w_i ∝ exp(-U_i - λ·¬CertOk_i)`。
实时流只读 TASA，不直接触发任何工具。

**定义 182（工具-执行联合证书 J_tool）** 扩展定义 170 的 `J_sem_exec`：
```
J_tool = (J_sem_exec, dag_hash, binding_validity_vector,
          contract_closure_proof, U_task, fallback_tier,
          tool_budget_used, grounding_calibration)
```
验证规则：
```
Valid(J_tool) ⇔ Valid(J_sem_exec)
              ∧ ∀b ∈ grounding_set : ValidBind(b)
              ∧ Closed(π_tool)
              ∧ U_task ≤ U_max
              ∧ grounding_calibration.ECE ≤ ε_ece
              ∧ fallback_tier ≤ tier_max
```

**定义 183（七维认知-工具预算 B_cog6 / PCE++++++）** 在第 61 轮六维基础上增加工具维：
```
B_cog6 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_tool)
B_tool = (Tool_calls, Tool_latency, Spec_waste, Verify_budget, Ground_retries)
```
成本：
```
cost_cog6 = cost_cog5
          + λ_call·(calls/Tool_calls)
          + λ_lat·(lat_used/Tool_latency)
          + λ_spec·(spec_waste/Spec_waste)
          + λ_ver·(verify_used/Verify_budget)
```
降级顺序（单调更保守）：`full tools → 缓存/蒸馏工具 → 解析先验 → 冻结锚点 → 澄清/中止`；任何一维耗尽只能触发**预定义**降级，不允许临时放宽安全约束。

**定义 184（工具-VLM 具身闭环 TVEL）** 统一第 61 轮 ESEC 与本轮工具层：
```
TVEL(M, V, D, P, L, goal):
  # 语义流（~10-100Hz，允许 100-500ms 长尾）
  G_t ← UpdateSceneGraph(V, D, P)
  π_tool ← VTO.plan(goal, G_t, L, Retrieve(cap, G_t))
  π_tool, Bindings ← GAB.bind_and_repair(π_tool, G_t)
  if not (all ValidBind(Bindings) and Closed(π_tool)):
      return ClarifyOrAbort(...)

      U_task ← TUPT.propagate(π_tool, Results)
  M.anchor ← TASA.commit(π_tool, Results, U_task, Bindings)
  M.J_tool ← BuildJointCert(M.anchor, π_tool, Results, U_task)
  # 实时流（~1-10kHz，永不调用工具）
  anchor ← TASA.read_latest()
  if anchor.fresh and Valid(M.J_tool):
      K_prior ← Π(anchor.scene_emb + anchor.intent_emb)
  else:
      K_prior ← conservative_expand(anchor or last_stable)
  K_safe ← EEIS.compile(delta_f_req, fused, ξ_exec, Z_env, K_prior, anchor.phys_prior)
  dispatch(K_safe)
```

### IP-183 VTO（视觉工具编排器）

```python
class VisualToolOrchestrator:
    def __init__(self, vlm, registry, usr, budget, tau_ground=0.8):
        self.vlm = vlm
        self.registry = registry
        self.usr = usr
        self.budget = budget
        self.tau_ground = tau_ground

    def plan(self, goal, images, depth, proprio, history):
        scene_graph = VisualSceneGraph(images, depth, proprio)
        caps = self.vlm.infer_capabilities(goal, scene_graph, history)
        tools = [self.registry.retrieve(c) for c in caps]
        prompt = build_tool_prompt(goal, scene_graph.summary(), tools)
        dag = self.vlm.generate_typed_dag(prompt)      # JSON schema 约束
        dag = self.typecheck(dag)
        dag, bindings = GroundedArgumentBinder(scene_graph, self.vlm).bind(dag)
        closure = ToolContractAlgebra.close(dag)
        if not closure.ok:
            dag = self.repair_or_replan(dag, closure)
        return ToolPlan(dag, bindings, closure)

    def typecheck(self, dag):
        for v in dag.nodes:
            tau = self.registry[v.name]
            assert self.registry.unify_types(v.args, tau.Sig)
            assert not self.registry.has_cycle(dag)
        return dag
```

### IP-184 GAB（视觉接地约束的参数绑定）

```python
class GroundedArgumentBinder:
    def __init__(self, scene_graph, vlm, tau_g=0.8, tau_delta=0.15):
        self.G = scene_graph
        self.vlm = vlm
        self.tau_g, self.tau_delta = tau_g, tau_delta

    def bind(self, dag):
        bindings = []
        for v in dag.topo_order():
            for a in v.args:
                if a.type == 'EntityRef':
                    b = self.bind_entity(a)
                elif a.type == 'Quantity':
                    b = self.bind_quantity(a)
                elif a.type == 'Pose6D':
                    b = self.bind_pose(a)
                else:
                    b = Binding.status('ok')
                if b.status != 'ok':
                    return dag, [b], RepairPlan(v, b.reason)
                bindings.append(b)
                a.binding = b
        return dag, bindings

    def bind_entity(self, arg):
        cands = self.G.retrieve(arg.referent_expr)     # mask/attr/relation
        scores = self.vlm.ground_score(arg.expr, cands.visual_tokens)
        p = softmax(scores)
        if p.max() < self.tau_g or (p.max() - p.second()) < self.tau_delta:
            return Binding.status('needs_clarify', dist=p, reason='ambiguous')
        r = cands[p.argmax()]
        return Binding.ok(referent_id=r.id, mask=r.mask, pose=r.pose,
                          frame=r.frame, unit=None, conf=p.max(),
                          source='vlm+vsg', ambiguity=p.max()-p.second())

    def bind_quantity(self, arg):
        u = Unit(arg.value, arg.unit)
        if not u.dimension_matches(arg.expected):
            return Binding.status('unit_mismatch', reason=f'{u} vs {arg.expected}')
        if not arg.range.contains(u.to_si()):
            return Binding.status('out_of_range', reason=str(u))
        return Binding.ok(value=u.to_si(), unit=arg.expected)

    def bind_pose(self, arg):
        T = self.G.frame_transform(arg.frame, 'world') @ arg.pose
        if not self.G.workspace_safe(T):
            return Binding.status('unsafe_pose')
        return Binding.ok(pose=T, frame='world')
```

### IP-185 TCA（工具契约代数）

```python
class ToolContractAlgebra:
    @staticmethod
    def unify(post, pre, frame_map=None, unit_map=None):
        return (post.predicate.substitute(frame_map, unit_map)
                .implies(pre.predicate))

    @classmethod
    def close(cls, dag):
        proof = []
        for u, v in dag.edges:
            if not cls.unify(dag.nodes[u].post, dag.nodes[v].pre):
                return ClosureResult(ok=False, edge=(u, v), reason='contract_gap')
            proof.append((u, v, cls.unify(...)))
        goal = dag.goal_post
        wp = backward_substitute(dag, goal)       # 最弱前置条件
        return ClosureResult(ok=wp.satisfiable(), proof=proof, wp=wp)

    @staticmethod
    def sequential(ca, cb):
        return ToolContract(pre=ca.pre, post=cb.post,
                            latency=ca.latency + cb.latency,
                            fail=1 - (1-ca.fail) * (1-cb.fail),
                            cost=ca.cost + cb.cost)
```

```python
class ToolDAGUncertainty:
    def __init__(self, n_mc=256, risk_budget=0.01):
        self.n_mc = n_mc
        self.risk_budget = risk_budget

    def propagate(self, dag, results):
        Sigma = {}
        for v in dag.topo_order():
            Js = [self.jacobian(v, u, results) for u in dag.predecessors(v)]
            S = results[v].sigma_model + results[v].sigma_bind
            for J, u in zip(Js, dag.predecessors(v)):
                S += J @ Sigma[u] @ J.T
            Sigma[v] = S
        samples = self.monte_carlo(dag, results, Sigma, self.n_mc)
        U_task = self.conservative_quantile(samples, self.risk_budget)
        return TaskUncertainty(U_task, Sigma, samples)

    def choose_verifier(self, dag, results, budget):
        best = None
        for tau in self.registry.verifiers(dag):
            gain = self.expected_risk_reduction(tau, dag, results)
            cost = tau.latency_est + tau.cost
            if gain - cost > 0 and budget.can_verify(tau):
                if best is None or gain - cost > best.score:
                    best = VerifierChoice(tau, score=gain - cost)
        return best
```

```python
class SpeculativeToolExecutor:
    def execute_speculative(self, plan, budget):
        preds = self.vlm.predict_next_calls(plan, k=budget.spec_k)
        futures = {}
        for v in preds:
            tau = self.registry[v.name]
            if tau.Idem and tau.SafeSpec and budget.can_speculate(v):
                futures[v.id] = self.pool.submit(self.run, v)   # 预执行
        results, fallback_tier = {}, 0
        for v in plan.topo_order():
            try:
                r = futures.pop(v.id).result(timeout=v.deadline) \
                    if v.id in futures else self.run(v)
                if not self.check_post(v, r):
                    raise ToolContractError(v)
            except (ToolContractError, TimeoutError) as e:
                v2, tier = ToolFallbackLadder.next(v, e, budget)
                if v2 is None:
                    raise SafeAbort(v)
                r = self.run(v2)
                fallback_tier = max(fallback_tier, tier)
            results[v.id] = r
        for f in futures.values():
            f.cancel()
        return results, fallback_tier
```

```python
class GroundedArgumentBinder:
    def __init__(self, G, vlm, tau_g=0.8, tau_delta=0.15):
        self.G, self.vlm = G, vlm
        self.tau_g, self.tau_delta = tau_g, tau_delta

    def bind(self, dag):
        bindings = []
        for v in dag.topo_order():
            for a in v.args:
                b = {'EntityRef': self.bind_entity,
                     'Quantity':  self.bind_quantity,
                     'Pose6D':    self.bind_pose}.get(a.type, lambda x: Binding.ok())(a)
                if b.status != 'ok':
                    return dag, bindings + [b], RepairPlan(v, b.reason)
                a.binding = b
                bindings.append(b)
        return dag, bindings, None

    def bind_entity(self, a):
        cands = self.G.retrieve(a.referent_expr)
        p = softmax(self.vlm.ground_score(a.expr, cands.visual_tokens))
        if p.max() < self.tau_g or p.max()-p.second() < self.tau_delta:
            return Binding.status('needs_clarify', dist=p, reason='ambiguous')
        r = cands[p.argmax()]
        return Binding.ok(referent_id=r.id, mask=r.mask, pose=r.pose,
                          frame=r.frame, conf=p.max(),
                          ambiguity=p.max()-p.second())

    def bind_quantity(self, a):
        u = Unit(a.value, a.unit)
        if not u.dimension_matches(a.expected):
            return Binding.status('unit_mismatch')
        if not a.range.contains(u.to_si()):
            return Binding.status('out_of_range')
        return Binding.ok(value=u.to_si(), unit=a.expected)

    def bind_pose(self, a):
        T = self.G.frame_transform(a.frame, 'world') @ a.pose
        return Binding.ok(pose=T, frame='world') \
            if self.G.workspace_safe(T) else Binding.status('unsafe_pose')
```

### IP-185 TCA（工具契约代数）

```python
class ToolContractAlgebra:
    @classmethod
    def close(cls, dag):
        proof = []
        for u, v in dag.edges:
            if not unify(dag.nodes[u].post, dag.nodes[v].pre):
                return ClosureResult(False, edge=(u, v), reason='contract_gap')
            proof.append((u, v))
        wp = backward_substitute(dag, dag.goal_post)
        return ClosureResult(wp.satisfiable(), proof=proof, wp=wp)

    @staticmethod
    def sequential(ca, cb):
        return ToolContract(pre=ca.pre, post=cb.post,
                            latency=ca.latency + cb.latency,
                            fail=1-(1-ca.fail)*(1-cb.fail),
                            cost=ca.cost + cb.cost)
```

```python
class ToolDAGUncertainty:
    def propagate(self, dag, results, n_mc=256):
        Sigma = {}
        for v in dag.topo_order():
            S = results[v].sigma_model + results[v].sigma_bind
            for u in dag.predecessors(v):
                J = self.jacobian(v, u, results)
                S += J @ Sigma[u] @ J.T
            Sigma[v] = S
        samples = self.monte_carlo(dag, results, Sigma, n_mc)
        return TaskUncertainty(self.quantile(samples, 0.99), Sigma, samples)

    def choose_verifier(self, dag, results, budget):
        best = None
        for tau in self.registry.verifiers(dag):
            score = self.expected_risk_reduction(tau, dag, results) \
                    - tau.latency_est - tau.cost
            if score > 0 and budget.can_verify(tau):
                if best is None or score > best.score:
                    best = VerifierChoice(tau, score)
        return best
```

```python
class SpeculativeToolExecutor:
    def execute(self, plan, budget):
        futures = {v.id: self.pool.submit(self.run, v)
                   for v in self.vlm.predict_next_calls(plan, k=budget.spec_k)
                   if self.registry[v.name].Idem and self.registry[v.name].SafeSpec
                   and budget.can_speculate(v)}
        results, tier = {}, 0
        for v in plan.topo_order():
            try:
                r = futures.pop(v.id).result(timeout=v.deadline) \
                    if v.id in futures else self.run(v)
                if not self.check_post(v, r):
                    raise ToolContractError(v)
            except (ToolContractError, TimeoutError) as e:
                v2, t = ToolFallbackLadder.next(v, e, budget)
                if v2 is None:
                    raise SafeAbort(v)
                r, tier = self.run(v2), max(tier, t)
            results[v.id] = r
        for f in futures.values(): f.cancel()
        return results, tier


class ToolFallbackLadder:
    LADDERS = {
        'friction_est':   ['tactile_probe', 'vlm_physics_prior', 'mu_lower_bound'],
        'grasp_plan':     ['affordance_planner', 'analytic_grasp', 'top_down_safe'],
        'collision_check':['mesh_check', 'capsule_check', 'envelope_conservative'],
        'calibration':    ['full_calib', 'partial_calib', 'frozen_prior'],
    }
    @classmethod
    def next(cls, call, error, budget):
        ladder = cls.LADDERS[call.cap]
        for j in range(ladder.index(call.name)+1, len(ladder)):
            if budget.can_call(registry[ladder[j]]):
                return registry[ladder[j]], j
        return None, len(ladder)
```

**正确性定理（TVEL-Sound）**：在 A61–A76 下（接地校准、工具契约、组合闭合、不确定性保守、投机安全、实时隔离），有：
1. **接地忠实性**：全部 `ValidBind` 时，以概率 ≥ `(1-δ_g)^{|bindings|}` 操作到意图实例，位姿误差 ≤ `ε_pose`。
2. **组合安全性**：`Closed(π_tool)` 且证书有效 ⇒ 满足目标或派发前触发 TFL；安全违规概率 ≤ `max(α, δ_τ·|V_π|)`。
3. **不确定性可靠性**：`U_task > U_max` 必然验证或降级，真实风险 ≤ `U_task`。
4. **实时独立性**：实时流不调用工具，抖动 ≤ 1ms；锚点失效则保守扩展。
5. **预算安全性**：任一 `B_tool` 耗尽只触发预定义单调降级，不放宽 ERTC。
6. **可审计性**：`K_safe → J_tool → 工具 DAG → 接地记录 → 工具证书` 全链路可追溯。

## 5. 本轮最大风险

**一句话**：若接地置信度过自信、工具契约有未建模隐式前置、或 TUPT 低估跨工具误差累积，VLM 会产出「语法合法、证书齐全、看似可审计」却物理上指向错误实例/单位的工具调用图，形成**比语言幻觉更危险的工具幻觉**；必须以「接地校准 + 契约闭合硬门控 + 保守不确定性上界 + 单调降级阶梯 + 实时流零工具调用」构成工具安全护栏，确保未接地/未闭合/未验证的工具图永不触达执行层。
