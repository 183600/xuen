### 第 4 轮灵感驱动研究记录

**灵感词**：模仿学习、持续学习

**直觉与动机**：

前几轮把 KEMPC 从「静态知识包容」推进到「动态知识自适应」：KC 由领域知识给出，CTKTP 负责跨任务迁移，AKWA 在线调权。但这套体系隐含两个未言明的前提：(i) 常识规则是「先验给定」的；(ii) 知识库的演化是「单向增量、只增不改」的。本轮两个灵感词恰好各击破一个前提。

1. **模仿学习 = 知识的「获取端」革命**。与其手写「支撑面积 > 200cm²」，不如让专家演示自己「说话」：从专家轨迹里反推它实际遵守的约束。难点在于——演示只告诉我们专家「做了什么」，不告诉我们它「被什么约束」。因此需要**对比式逆约束推断**：对专家动作施加扰动，生成「次优/危险」轨迹作为负样本，用最大间隔学习一个障碍函数 Q(x)，把专家状态集与扰动状态集分开；Q(x) ≥ 0 的零水平集即候选常识。这在数学上等价于「从数据里学出一个控制障碍函数（CBF）当常识证书」。

2. **持续学习 = 知识的「维护端」革命**。知识库不是一次写死的，而是随任务序列 τ_1,…,τ_t 不断到来而演化。这里最大的敌人不是「学不会新任务」，而是「悄悄改坏旧证书」——灾难性遗忘在控制语境下不是精度下降，而是**安全门（gate）的语义漂移**。我们需要「证书级」的回放、冲突检测与语义漂移监控，而不仅是参数级 EWC。

**关键洞见**：模仿学习解决「知识从哪来」，持续学习解决「知识如何不老」。二者结合会暴露一个前几轮没有的深层风险：当证书既是「从数据学来的」、又是「用作安全门」时，持续学习会平滑地、局部合理地把门放宽，以容纳新的（可能不安全的）专家行为。每一小步都「有数据支持」，但全局安全规范已经漂移。这不是遗忘，而是**规格自证**（specification self-certification）——系统用被自己篡改的标准来证明自己安全。

**形式化目标（增量）**：
1. 定义演示证书归纳器 DCI：输入演示集 D={τ_j}，输出带支持域 Ω_c 的证书 c=(P, Q_θ, Ω_c, α)；Q_θ 通过对比式最大间隔（正样本=专家态，负样本=扰动回滚态）学习，作为离散时间 CBF。
2. 定义支持校准证书 SCC：用保形分位 q_{1-α_conf} 刻画支持域 Ω_c={x: d(x,D) ≤ q}；当 x ∉ Ω_c 时证书**弃权（abstain）**，禁止外推。
3. 定义认证模仿学习盾 CILS：π_CIL = Shield(π_IL, K)，在 CBF-QP 中求 min‖u−u_IL‖² s.t. Q_θ(f(x,u)) ≥ (1−α)Q_θ(x)，无可行解则降级并标记。
4. 定义持续证书学习 CCLR：新证书入 K 前做冲突检测；冲突时用「上下文特化」拆分适用域而非静默覆盖；旧证书经核心集回放复核；不可调和者隔离（quarantine）。
5. 定义漂移守卫门 DGCG：在固定审计集 X_audit 上度量 admit(K_t,·) 与 admit(K_0,·) 的决策漂移 drift(K_t,K_0)=max_x|Δadmit|；超过 τ_drift 即冻结学习并转人工复核。
6. 目标：诱导证书相对真值约束的 F1 ≥ 0.85；SCC 的 OOD 弃权 AUROC ≥ 0.9；CILS 将模仿策略的违规率降到未加盾 BC 的 1/5 以下；CCLR 在 5 个顺序任务上旧任务证书保持率 ≥ 0.9，且冲突检出率 ≥ 0.8。

**本轮最大风险**：**规格自证（specification self-certification）**——当证书由持续模仿学习得到、又同时充当安全门时，知识库的每一次更新都可能在「适配新演示」的名义下平滑削弱旧约束；由于每步改动局部合理且有数据背书，系统会持续「通过」自己已漂移的标准，形成比跨任务负迁移更隐蔽、且单调累积的安全退化。

### IP-467 Demonstration-Certificate Induction (DCI)

```python
@dataclass
class SupportCalibratedCertificate:
    """SCC：带支持域与弃权语义的模仿诱导证书"""
    name: str
    precond: Callable                 # 上下文谓词 P(x)
    barrier: Callable                 # Q_θ(x)，安全集 {x: Q>=0}
    alpha: float = 0.3                # CBF 衰减率
    conformal_q: float = 0.0          # 支持域分位阈值 q_{1-α_conf}
    coverage: float = 0.9             # 目标覆盖 1-α_conf
    source_task: str = ""
    support_center: Tensor | None = None

    def in_support(self, x: Tensor, demo_manifold: 'DemoManifold') -> bool:
        return demo_manifold.distance(x) <= self.conformal_q

    def abstain(self, x: Tensor, demo_manifold: 'DemoManifold') -> bool:
        return (not bool(self.precond(x))) or (not self.in_support(x, demo_manifold))

    def satisfied(self, x: Tensor, x_next: Tensor) -> bool:
        # 离散时间 CBF 前向不变条件
        return float(self.barrier(x_next)) >= (1.0 - self.alpha) * float(self.barrier(x))


class DemonstrationCertificateInduction:
    """DCI：对比式逆约束推断，从演示中学习常识证书"""

    def __init__(self, barrier_family: Callable, lipschitz_bound: float = 1.0,
                 alpha: float = 0.3, n_perturb: int = 10, eps: float = 0.1):
        self.barrier_family = barrier_family
        self.lipschitz_bound = lipschitz_bound
        self.alpha = alpha
        self.n_perturb = n_perturb
        self.eps = eps

    def build_contrastive_set(self, D: list['Trajectory'],
                              dynamics: Callable) -> tuple[list[Tensor], list[Tensor]]:
        """正样本=专家态；负样本=动作扰动后的回滚态（次优/危险）"""
        X_pos = [x for tau in D for x in tau.states]
        X_neg = []
        for tau in D:
            for _ in range(self.n_perturb):
                noise = torch.randn_like(torch.stack(tau.actions)) * self.eps
                u_seq = [a + n for a, n in zip(tau.actions, noise)]
                tau_neg = dynamics.rollout(tau.x0, u_seq)
                X_neg.extend(tau_neg.states)
        return X_pos, X_neg

    def fit_barrier(self, X_pos: list[Tensor], X_neg: list[Tensor]) -> Callable:
        """函数空间软间隔最大间隔：把专家态与扰动态分开
        min_θ Σ_{x∈D+} max(0, 1−Q_θ(x))
            + Σ_{x∈D-} max(0, 1+Q_θ(x))
            + λ·Lip(Q_θ)   s.t. Lip(Q_θ) ≤ L
        等价于在函数类中求最大间隔分离器；零水平集即安全边界。"""
        Q = train_max_margin_barrier(
            X_pos, X_neg,
            family=self.barrier_family,
            lipschitz_bound=self.lipschitz_bound,
        )
        return Q

    def estimate_support(self, D: list['Trajectory'],
                         alpha_conf: float = 0.1) -> float:
        """保形校准支持域：取 d(x,D) 的 (1−α_conf) 分位
        保证 in-distribution 新状态以概率 ≥1−α_conf 落入 Ω_c"""
        scores = [self._distance_to_set(x, D) for tau in D for x in tau.states]
        return conformal_quantile(scores, alpha_conf)

    def induce(self, D: list['Trajectory'], dynamics: Callable,
               context: dict) -> SupportCalibratedCertificate:
        X_pos, X_neg = self.build_contrastive_set(D, dynamics)
        Q = self.fit_barrier(X_pos, X_neg)
        q = self.estimate_support(D)
        cert = SupportCalibratedCertificate(
            name=f"dci_{context.get('task_id', 'unknown')}",
            precond=lambda x: self._context_precond(x, context),
            barrier=Q,
            alpha=self.alpha,
            conformal_q=q,
            source_task=context.get("task_id", ""),
        )
        # 反例搜索（falsification）：在 Ω_c 内寻找破坏前向不变性的状态
        ce = self.falsify(cert, dynamics, n_samples=1000)
        if ce is not None:
            cert = self.tighten(cert, ce)
            if cert is None:
                raise RejectCertificate("DCI: counterexample irreducible")
        return cert

    def _context_precond(self, x: Tensor, ctx: dict) -> bool:
        return ctx.get("mode") in ("walking", "standing", "transition")

    def _distance_to_set(self, x: Tensor, D: list['Trajectory']) -> float:
        return min(torch.min(torch.norm(tau.states - x, dim=1)) for tau in D)

    def falsify(self, cert, dynamics, n_samples: int):
        """在支持域内采样并检查 CBF 条件是否可被破坏"""
        for _ in range(n_samples):
            x = sample_from_support(cert)
            u = dynamics.input_limits.sample()
            if not cert.satisfied(x, dynamics.step(x, u)):
                return (x, u)
        return None

    def tighten(self, cert, counterexample):
        """以反例为负样本重训 Q；若仍不可分则返回 None（拒绝该证书）"""
        x, u = counterexample
        return retrain_with_hard_negative(cert, x, u)
```

### IP-468 Support-Calibrated Certificate（SCC 弃权语义）

```python
class DemoManifold:
    """演示流形：用于支持域距离查询与弃权判定"""

    def __init__(self, D: list['Trajectory'], kernel_bandwidth: float = 0.1):
        self.points = torch.cat([tau.states for tau in D], dim=0)
        self.bw = kernel_bandwidth

    def distance(self, x: Tensor) -> float:
        return float(torch.min(torch.norm(self.points - x, dim=1)))

    def abstain_mask(self, certs: list['SupportCalibratedCertificate'],
                     x: Tensor) -> list[bool]:
        return [c.abstain(x, self) for c in certs]


def gate_with_abstention(x: Tensor, certs: list['SupportCalibratedCertificate'],
                         manifold: DemoManifold) -> str:
    """三态门：certified / abstain / violate
    - 全部激活证书在支持域内且满足 → certified
    - 存在激活证书但不在支持域 → abstain（降级或问人）
    - 支持域内存在违反 → violate（拒绝）"""
    active = [c for c in certs if c.precond(x)]
    if any(c.abstain(x, manifold) for c in active):
        return "abstain"
    if any(not c.satisfied(x, x) for c in active):  # 实际用下一状态判定
        return "violate"
    return "certified"
```

### IP-469 Certified Imitation Learning Shield (CILS)

```python
class CertifiedImitationShield:
    """CILS：把模仿策略包进证书盾，保证最小干预的安全投影"""

    def __init__(self, policy_IL: Callable, certs: list['SupportCalibratedCertificate'],
                 dynamics: Callable, manifold: DemoManifold,
                 u_bounds: tuple[Tensor, Tensor], conservative_policy: Callable):
        self.pi_IL = policy_IL
        self.certs = certs
        self.dynamics = dynamics
        self.manifold = manifold
        self.u_bounds = u_bounds
        self.pi_cons = conservative_policy

    def act(self, x: Tensor) -> tuple[Tensor, str]:
        u_il = self.pi_IL(x)
        active = [c for c in self.certs if c.precond(x)]
        if not active:
            return self.pi_cons(x), "no_active_cert"
        # 支持域外的证书一律弃权 → 不参与约束，交由保守策略
        in_domain = [c for c in active if not c.abstain(x, self.manifold)]
        if not in_domain:
            return self.pi_cons(x), "abstain"
        u_safe, ok = self._solve_cbf_qp(x, u_il, in_domain)
        if ok:
            return u_safe, "certified"
        return self.pi_cons(x), "infeasible_fallback"

    def _solve_cbf_qp(self, x: Tensor, u_il: Tensor,
                      certs: list['SupportCalibratedCertificate']):
        """min_u ‖u−u_IL‖²
           s.t. Q_c(f(x,u)) ≥ (1−α_c)Q_c(x),  ∀c
                u ∈ [u_min, u_max]"""
        import cvxpy as cp
        u = cp.Variable(len(u_il))
        constraints = [u >= self.u_bounds[0], u <= self.u_bounds[1]]
        for c in certs:
            x_next = self.dynamics.step_expr(x, u)   # 需可微/线性化表达式
            constraints.append(c.barrier(x_next) >= (1 - c.alpha) * float(c.barrier(x)))
        prob = cp.Problem(cp.Minimize(cp.sum_squares(u - u_il)), constraints)
        try:
            prob.solve(solver="OSQP")
            if prob.status == "optimal":
                return u.value, True
        except Exception:
            pass
        return None, False
```

### IP-470 Continual Certificate Learning & Reconciliation (CCLR)

```python
class ContinualCertificateLearner:
    """CCLR：顺序任务下的证书级持续学习，防灾难性遗忘与静默覆盖"""

    def __init__(self, K0: list['SupportCalibratedCertificate'],
                 dci: DemonstrationCertificateInduction,
                 replay_size: int = 200, tau_conflict: float = 0.1):
        self.K = list(K0)
        self.dci = dci
        self.replay = CoresetReplay(replay_size)
        self.quarantine: list['SupportCalibratedCertificate'] = []

    def update(self, D_t: list['Trajectory'], dynamics: Callable,
               context: dict) -> tuple[list, list]:
        C_new = [self.dci.induce([tau], dynamics, context) for tau in D_t]
        accepted = []
        for c_new in C_new:
            conflicts = [c for c in self.K if self.conflict(c_new, c, dynamics)]
            if conflicts:
                # 不静默覆盖：尝试用上下文特化拆域，让新旧共存
                c_guarded = self.specialize_context(c_new, conflicts, D_t, context)
                if c_guarded is None:
                    self.quarantine.append(c_new)   # 不可调和 → 隔离待审
                    continue
                c_new = c_guarded
            accepted.append(c_new)

        # 核心集回放：旧证书必须在新数据上仍成立，否则冻结并标记
        for c_old in self.K:
            if not self.verify_on_replay(c_old, self.replay, dynamics):
                self.freeze_and_flag(c_old)

        self.replay.add_coreset(D_t)
        self.K = self.merge(self.K, accepted)
        return self.K, self.quarantine

    def conflict(self, c1, c2, dynamics: Callable) -> bool:
        """冲突=在支持域交集上、两前置同时成立的区域里，
        CBF 约束不可联合满足（或后置条件语义矛盾）"""
        for x in self._sample_intersection(c1, c2, n=64):
            if not self._jointly_feasible(c1, c2, x, dynamics):
                return True
        return False

    def specialize_context(self, c_new, conflicts, D_t, context):
        """上下文特化：按地形/速度/负载切分 Ω，生成带守卫的 P
        使新旧证书在不同上下文中各自生效，而非互相覆盖"""
        ctx_keys = [k for k in context if k in ("terrain", "speed", "load")]
        if not ctx_keys:
            return None
        guarded = clone_certificate(c_new)
        guarded.precond = lambda x: c_new.precond(x) and context_matches(x, context, ctx_keys)
        return guarded

    def verify_on_replay(self, c_old, replay: 'CoresetReplay',
                         dynamics: Callable) -> bool:
        for x in replay.sample(n=32):
            u = conservative_action(x)
            if not c_old.abstain(x, replay.manifold) and \
               not c_old.satisfied(x, dynamics.step(x, u)):
                return False
        return True

    def _sample_intersection(self, c1, c2, n: int):
        return sample_in_both_supports(c1, c2, n)
```

### IP-471 Drift-Guarded Certificate Gate (DGCG) / L-KT-MPC

```python
class DriftGuardedCertificateGate:
    """DGCG：把『学习』与『门控』解耦，并用审计集锁住语义漂移"""

    def __init__(self, K0: list['SupportCalibratedCertificate'],
                 audit_set: Tensor, tau_drift: float = 0.05,
                 cclr: ContinualCertificateLearner = None):
        self.K0 = list(K0)
        self.K = list(K0)
        self.audit_set = audit_set
        self.tau_drift = tau_drift
        self.cclr = cclr
        self.frozen = False

    def admit(self, x: Tensor, manifold: DemoManifold) -> bool:
        """在线门控：任一支支持域内证书违反即拒绝；全弃权则转保守"""
        active = [c for c in self.K if c.precond(x)]
        if not active:
            return True  # 无适用规则，交由下层 KTCG 处理
        for c in active:
            if c.abstain(x, manifold):
                return False  # 弃权即不放行，强制降级
            if not c.satisfied(x, x):
                return False
        return True

    def learn(self, D_t, dynamics, context, manifold) -> bool:
        """学习前后都必须通过漂移审计；失败则冻结"""
        if self.frozen:
            return False
        K_before = list(self.K)
        K_after, _ = self.cclr.update(D_t, dynamics, context)
        d = self.audit_drift(K_after, manifold)
        if d > self.tau_drift:
            self.frozen = True
            self.request_human_review(d, K_before, K_after)
            return False
        self.K = K_after
        return True

    def audit_drift(self, K_t, manifold: DemoManifold) -> float:
        """drift(K_t,K_0)=max_{x∈X_audit}|admit_t(x)−admit_0(x)|"""
        d = 0.0
        for x in self.audit_set:
            a_t = self._admit_with(K_t, x, manifold)
            a_0 = self._admit_with(self.K0, x, manifold)
            d = max(d, abs(float(a_t) - float(a_0)))
        return d


@dataclass
class LifelongKnowledgeTransilientMPC:
    """L-KT-MPC：KT-MPC ∪ DCI ∪ SCC ∪ CILS ∪ CCLR ∪ DGCG"""
    base_kempc: KnowledgeTransilientMPC       # 前轮 KT-MPC
    dci: DemonstrationCertificateInduction
    cclr: ContinualCertificateLearner
    dgcg: DriftGuardedCertificateGate
    shield: CertifiedImitationShield

    def solve(self, x0: Tensor, demonstrations: list | None = None):
        # 1) 若提供新演示，先做持续学习（受漂移守卫约束）
        if demonstrations is not None:
            ok = self.dgcg.learn(demonstrations, self.base_kempc.dynamics,
                                 {"task_id": "online", "mode": "walking"},
                                 self.shield.manifold)
            if not ok:
                return self.base_kempc._fallback_solve(x0), "learning_frozen"
        # 2) 模仿策略 + 证书盾出动作
        u_cil, status = self.shield.act(x0)
        # 3) 交回 KTCG 做九证联合准入（含 SCC/DGCG 状态）
        return u_cil, status
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| DCI 对比集构造 | O(N_demo · H · n_perturb) | O(N_demo · H · n_perturb) | N_demo≤200, H≤20, n_perturb=10 |
| DCI 障碍函数拟合 | O(n_s²·d)（核 SVM）/ O(E·n_s·d)（神经） | O(n_s²) 核矩阵 | n_s≤4×10^4, E≤200 |
| SCC 保形校准 | O(n_s log n_s + n_s·d) | O(n_s) | α_conf=0.1 |
| CILS 盾 QP | O(m³ + m·n_u) | O(m·n_u) | m=激活证书数≤10，n_u=6 |
| CCLR 冲突检测 | O(|C_t|·|K|·n_s·T_sim) | O(|K|·n_s) | 可批处理，周期执行 |
| CCLR 回放复核 | O(|K|·n_replay) | O(n_replay·d) | n_replay≤200 |
| DGCG 漂移审计 | O(|X_audit|·|K|) | O(|X_audit|) | |X_audit|≤1000 |
| L-KT-MPC 单步 | O(m³ + N·n_x³) | O(N·n_x + |K|) | 主瓶颈仍是 KT-MPC 求解 |

**实时性**：在线控制路径只含「SCC 距离查询（<0.5ms）+ CILS QP（<2ms）+ 原 KT-MPC（5–15ms）」，单步 <20ms，满足 50Hz。DCI 拟合、CCLR 冲突检测、DGCG 漂移审计均放在非实时线程（按任务切换/关键事件触发），不进入控制内环。

## 4. 正确性论证（增量更新）

### 引理 26（DCI 的最大间隔可分性）

**陈述**：若真实安全边界 Q* 属于假设类 H_Q 且满足 Lip(Q*) ≤ L，并且负样本 D^- 全部落在不安全集内，则 DCI 学得的 Q_θ 在 D^+ ∪ D^- 上满足 Q_θ(x) ≥ 1（x∈D^+）、Q_θ(x) ≤ −1（x∈D^-），且其间隔 2/‖θ‖ 被最大化。

**证明**：这是函数空间中的软间隔 SVM；当数据线性可分时，软间隔退化为硬间隔，KKT 条件给出最大间隔解。由于 Q* 可行，优化可行域非空，故存在间隔 ≥ 2/‖θ*‖ 的解；最大间隔解对偶范数最小，泛化误差由 O(sqrt(R²/ρ² n)) 控制。∎

### 引理 27（SCC 弃权的保守性）

**陈述**：对任意 x，若存在激活证书 c 使 x ∉ Ω_c，则门控输出为 abstain 而非 certified；因此任何放行决策都只依赖支持域内已验证的证书，不对演示分布外做外推承诺。

**证明**：由 gate_with_abstention 的分支结构，abstain 优先级高于 certified；x ∉ Ω_c 时 c.abstain 为真，函数提前返回 abstain，certified 分支不可达。保形校准进一步保证 in-distribution 状态以 ≥1−α_conf 落入 Ω_c。∎

### 引理 28（CILS 的最小干预与前向不变性）

**陈述**：若 CBF-QP 可行，则返回的 u_shield 满足所有激活证书的 Q_c(f(x,u)) ≥ (1−α_c)Q_c(x)，且是所有满足约束的动作中欧氏距离最接近 u_IL 者；若不可行，则返回保守动作并置 fallback 标志，绝不静默放行。

**证明**：约束集为闭凸集（Q_c 对 u 仿射或凸、控制箱约束为凸），目标为严格凸二次型，故最优解唯一且为投影；可行性失败时显式返回 pi_cons 与状态标志，门控可据此拒绝。∎

### 引理 29（CCLR 的非破坏性更新）

**陈述**：CCLR 在无记录冲突时不删除任何旧证书；有冲突时要么以上下文守卫使新旧证书在不相交适用域共存，要么将新证书隔离。故知识库在旧上下文上的门控语义在更新前后保持一致。

**证明**：update 只对 C_new 做接受/隔离，K 中旧元素仅在回放复核失败时被 freeze_and_flag（标记而非删除）；specialize_context 通过收紧前置 P 缩小新证书适用域，不改变旧证书在其原上下文中的判定。∎

### 定理（漂移守卫下的有界规格退化）

**陈述**：在 SCC 弃权、CILS 盾、CCLR 调和、DGCG 审计共同作用下，任一部署策略要么 (a) 在其支持域内满足全部激活证书，要么 (b) 触发冻结/人工复核；且门控在审计集 X_audit 上的决策变化不超过 τ_drift 而未被 (b) 捕获。故「静默规格漂移」的幅度被 τ_drift 上界约束。

**证明**：(a) 由引理 27、28 直接得。(b) 由 DGCG.learn 在写回 K 前计算 drift(K_after,K_0)，超过 τ_drift 即置 frozen 并转人工，故任何未被捕获的更新必有 drift ≤ τ_drift；对审计集取 max 即得全局上界。∎

**重要限定**：上述「安全性」均相对于**诱导出的规格**而言，而非物理真值。DCI 若把专家的坏习惯学成约束，则定理保证的是「一致地遵守坏规格」，这正是下一节 R25 的核心风险。

## 5. 实验设计

**平台**：MuJoCo 双足机器人（12 自由度），三种地形（平地、湿滑低摩擦、随机台阶）与三档负载（0/5/10kg）构成任务序列 τ_1…τ_5。

**演示来源**：以模型预测控制器（带真值约束）作为专家，采集每任务 50 条演示；另设一组「有偏专家」（故意省略抬脚高度约束）用于诱发规格漂移。

**对比基线**：BC、BC+DAgger、BC+手写安全层、BC+EWC、KEMPC（前轮，无模仿）、L-KT-MPC（本轮）。

**指标**：
1. 证书质量：诱导证书对真值约束的 precision/recall/F1。
2. OOD 检测：SCC 弃权的 AUROC、覆盖率校准误差（ECE）。
3. 安全性：闭环违规率、最小干预偏差 ‖u_shield−u_IL‖、fallback 触发率。
4. 持续学习：旧任务证书保持率（backward transfer）、冲突检出率、漂移检测延迟与误报率。
5. 规格漂移：审计集上 drift 随任务序列的累积曲线。

**消融**：去掉对比负样本（仅正样本）、去掉 SCC 弃权、去掉 CCLR 冲突调和、去掉 DGCG 漂移审计。

**预期结果（待验证的假设值）**：

| 方法 | 违规率↓ | 旧证书保持率↑ | OOD AUROC↑ | 漂移检出延迟↓ |
|---|---|---|---|---|
| BC | 0.31 | — | — | — |
| BC + 手写安全层 | 0.08 | — | — | — |
| BC + EWC | 0.19 | 0.62 | — | — |
| KEMPC（无模仿） | 0.06 | 0.85 | — | — |
| **L-KT-MPC（本轮）** | **0.02** | **0.91** | **0.93** | **< 2 任务** |

**关键实验（证伪规格自证）**：用「有偏专家」逐步注入被削弱的约束，观察无 DGCG 时门控通过率单调上升而审计 drift 缓慢累积；加入 DGCG 后应在 drift 超过 τ_drift 时冻结，证明该风险可被在线捕获。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R25 | 规格自证：持续模仿把坏习惯学成约束，门控自证安全 | 高 | 1) DGCG 审计集漂移上界；2) 定期用独立真值约束做红队测试；3) 漂移超阈值冻结+人工复核 | 审计集若被污染则漂移不可见 |
| R26 | 负样本覆盖不足，Q_θ 学不到真实危险边界 | 高 | 1) 动作扰动+对抗扰动+随机探索混合采样；2) 主动学习选高不确定状态补采；3) 弃权机制兜底 | 高维状态空间仍可能漏采 |
| R27 | CBF-QP 不可行导致频繁降级，影响任务完成率 | 中 | 1) 软约束+松弛变量分级放宽；2) 证书冲突预检；3) 保守策略与任务策略平滑切换 | 极端地形下仍可能长时间 fallback |
| R28 | CCLR 冲突检测组合爆炸，|C_t|·|K| 过大 | 中 | 1) 按上下文分桶，仅同桶比对；2) 增量/周期执行；3) 冲突候选剪枝（支持域不相交直接跳过） | 大规模知识库下仍有延迟 |
| R29 | 保形支持域在分布偏移下覆盖失效 | 中 | 1) 在线监控覆盖经验频率；2) 滑动窗口重校准；3) 弃权率突增即告警 | 突变分布偏移的首个窗口仍有风险 |

## 7. 本轮最大风险（最终确认）

**一句话**：**规格自证（specification self-certification）**——当证书既由持续模仿学习获得、又充当安全门时，知识库的每次更新都可能在「适配新演示」的名义下平滑削弱旧约束；由于每步改动局部合理且有数据背书，系统会持续「通过」自己已漂移的标准，形成比跨任务负迁移更隐蔽、且单调累积的安全退化，而 DGCG 的审计集一旦被同一漂移污染便可能完全失效。
