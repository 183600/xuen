# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语言指令」×「能耗优化」）

> R69 给了闭环一张「嘴」（主动问）和一个「鼻子」（流似然第二意见），并用 aleatoric / epistemic 的二分取代了 R68 的单一标量。但它仍把两件事当成理所当然：
>
> 1. **语言指令是一次性解析的输入，而不是不确定性的源头、也不是可预算的资源。** FLUID-RAS 里语言只出现在「输出侧」——把 `g_ask` 解码成一句问句；任务指令本身被默认已经接地。可真实具身任务里最贵的歧义恰恰在意图侧：指代（「那个」是哪只杯）、关系（「放旁边」是左是右）、容差（「轻一点」多轻）、次序与停止条件。更隐蔽的是：两个不同意图可能**当前动作完全一样、十步后才分叉**——这时 R69 的动作熵 `U_epi≈0`，它对歧义完全失明。
> 2. **能耗是一个手调常数 `c(g)`，而不是跨时间耦合、必须与安全储备竞争的稀缺资源。** 多采样一次流策略、跑一次 Hutchinson 散度、解码一句 LLM 问句、转头注视、伸探针、等待——都要花焦耳；人形机器人有硬电池与安全返航储备。R69 的 `argmax[VoI−c]` 用一个固定 `c` 抹掉了三件事：电越少、一焦耳越贵；消歧要和行走/操作抢同一个预算；电量低会压缩算力，而算力低又抬高不确定性——**低电量因此是一种认知危害**，不只是移动危害。
>
> 本轮两个灵感正好补上这两块：
> - **语言指令**给出一个高带宽、低焦耳的信息通道，但它必须被建模成一张**带孔的契约**（意图图 + 孔洞上的后验），而不是一句已被理解的话；
> - **能耗优化**给出一个真正的资源经济学视角：焦耳是货币，影子价格 `μ_t` 是汇率，消歧是投资，协商是重新定价。
>
> 核心命题：**把语言从「输出通道」提升为一等的不确定性来源（意图图 LIG），把能量从标量成本提升为硬预算与影子价格（JEL + μ_t），再用「能量定价信息价值」EPV 把二者统一：按每焦耳信息增益相对当前能量价格来选择问 / 看 / 触 / 加采样 / 不问，并给安全储备上锁。于是系统可以「花焦耳买确定性」，也可以「拿确定性换焦耳」，沿一条显式、可认证的 Pareto 前沿运行；当指令在当前能量下不可满足时，它协商修改契约，而不是静默执行或静默失败。FLUID-RAS 退化为「指令已接地 + μ 为常数 + 预算宽松」的特例，R68 退化为「μ=∞ / 不消歧」的边界。** 命名 **LEAN-RAS**（Language-Energy-Aware uNcertainty resolution，语言-能量感知的不确定性消解）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这句话到底要我做什么、我为它愿意且能够花多少焦耳；花不起时，能不能改契约**」——语言不是免费的，能量也不是免费的，二者是同一门信息经济学的两端。

## 0. 直觉与动机

**灵感 1（语言指令 → 一张带孔的契约，而不是一句已懂的话）**
直觉：人说「把桌上的杯子放到架子那边」，没有给出指代（哪个杯子）、目标（架子哪一格）、容差（放稳即可还是对齐标签）、停止条件（松手还是等确认）。这不是噪声，是**结构化的缺省**：语法给了骨架，孔洞留给感知与对话。把它画成意图图 `G_L` 后，「不确定性」不再是动作分布的熵，而是**孔洞上的后验**：指代候选集、关系候选集、参数区间、可行性标记。于是「问什么」有了精确对象——不是笼统地问「你要什么」，而是问当前 EPV 最高的那个孔；「看哪里」也有了精确对象——注视能最大程度缩小哪个指代的后验。语言指令从一次性输入，变成一张**可增量填孔的契约**。

**灵感 2（能耗优化 → 焦耳有影子价格，而且价格随时间上涨）**
直觉：可靠性工程与 SRE 都懂「预算」：不是「能不能付」而是「还剩多少、下一笔该不该花」。电池同理。设安全储备 `e_safe`、剩余电量 `e_t`、松弛 `s_t=e_t−e_safe`。当 `s_t` 很厚，多花一焦耳几乎无感，影子价格 `μ_t≈0`，应该大方地多采样、多问；当 `s_t→0`，一焦耳的机会成本趋于无穷，`μ_t→∞`，任何非安全必需的消歧都该停。把 `μ_t` 写成一个障碍函数 `κ/(s_t+δ)` 后，R69 的固定成本 `c` 立刻显出问题：同一个问句在 90% 电量和 8% 电量下的真实价格差一个数量级。**能耗优化不是「省着点用」，而是给每个决策标一个随状态变化的价。**

**灵感 3（统一 → 语言与能量是同一门信息经济学）**
直觉：语言是**便宜的信息通道**（一句话可能省掉几分钟的搜索与试错），能量是**昂贵的通用货币**。二者可以用同一个汇率 `μ_t` 结算：一次澄清值不值，不取决于它「重要不重要」，而取决于 `信息增益 / 焦耳 ≥ μ_t`。这带来一个反直觉但正确的推论：**该不该问，会随电量变化**。满电时值得为一个中等歧义问一句；低电时同样的歧义应该直接保守执行，把焦耳留给返航。反过来，当系统发现自己正要做大量昂贵探索时，**主动向人要一句更具体的指令**可能是一笔正回报投资——「问」不只是花钱，它还能赚钱（省焦耳）。语言因此既是支出项，也是资产项。

**灵感 4（R69 的盲区 → 动作等价、意图分叉）**
直觉：两个意图「递给我」与「放到桌上」在机器人走到桌边之前可能产生**完全相同的动作轨迹**；到某个时刻（手伸向人 vs 伸向桌面）才分叉。R69 在当前时刻算动作模态，看到的是单峰，`U_epi≈0`，于是它既不问也不减速；等分叉发生，已经进入不可逆区间。LEAN 显式建模「latent fork」：意图后验 × 在未来窗口内发生可观测分叉的概率。它允许系统**提前**用一句便宜的话消解一个尚未显形的歧义——这正是语言相对被动感知的最大优势：语言可以在动作分叉之前介入。由此得到一个可计算的「消歧地平线」：分叉越远、损失越大、折扣越小，就越值得现在问。

**灵感 5（低电量 → 认知危害，不只是移动危害）**
直觉：电量低不只是「走不远」。它压缩算力：流采样从 K=4 降到 K=1、LLM 问句从完整解码降到模板、Hutchinson 估计从多次回放降到一次。算力下降直接抬高 `U_epi` 的地板，使系统在最需要看清的时候最看不清。更糟的是，低电量往往伴随长任务尾段与高风险收尾。所以安全储备必须同时覆盖「移动 + 停止 +**最低认知算力**」。这把 R69 的 `λ_floor` 从「不确定就收紧」扩展为「先保证还有算力把不确定性算清楚，再谈收紧」。

**灵感 6（不可满足的指令 → 协商契约，而不是执行或放弃）**
直觉：如果指令要求「把 20 kg 箱子搬到三楼」而剩余能量只够 12 kg，R69 只有两个坏选项：执行到一半没电（危险），或直接拒绝（任务失败）。真实的人会协商：「我可以搬到二楼，或者分两趟，或者你先给我充电。」把指令形式化为契约 `C=(scope, tolerance, deadline, energy_cap, success_target)` 后，协商就是一个有 EPV 的动作：它改变契约、改变可行性、也改变后续预算分配。**语言在这里不是澄清语义，而是重新定价任务**——这是 R69 完全没有的能力。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（LEAN-RAS 总览与四不变式）** LEAN-RAS = (LIG, JEL, EPV, ECR, NEG, SEL, LAC, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **安全储备不可侵犯**：对任意 `t ≤ H`，`e_t ≥ e_safe`，且安全认证在决策序上严格优先于能量可行性（字典序，定义 319）；
(iii) **能量账本守恒**：任何任务/信息/计算/等待动作必须先记账后执行；账本与电池遥测的对账误差 `≤ ε_e`，越界即降级；
(iv) **指令契约显式化**：执行前必须声明意图后验与满足度判据；若在当前能量下不可满足，必须显式协商并留痕，禁止静默执行或静默放弃。

**定义 311（语言意图图 LIG）** 指令 `ξ_L` 解析为有向图 `G_L=(V,E)`，节点类型 `{GOAL, REFERENT, RELATION, CONSTRAINT, STOP}`，边表示子目标次序与约束依赖。每个节点 `v` 带：接地候选 `ρ_v ∈ 𝒮_v`、连续参数 `θ_v`、可行性标记 `feasible_v`。信念 `b_L(v) = p(ρ_v, θ_v, feasible_v | ξ_L, o_t, h_t)`，`h_t` 为对话历史。定义两类不混同的不确定性：结构/语义熵 `H_sem = H(parse(G_L) | ξ_L, h_t)`、接地熵 `H_grd = Σ_v w_v H(ρ_v | o_t, h_t)`；记 `U_L = (H_sem, H_grd)`，**不相加**（对应 R69 定义 297 的姿态：不同语义走不同通道）。另记指代多重度 `M_ref = max_v |supp(ρ_v)|`。

**定义 312（意图不确定性传播与 latent fork）** 策略条件于 `b_L` 得 `π_θ(a | o, b_L)`。定义瞬时传播 `U_epi^act = U_epi^policy(b_L) + ‖T_L‖·U_L`，其中 `T_L = ∂π/∂b_L` 为意图敏感度算子（可用 Fisher 信息或有限差分估计）。定义**分叉事件** `D = {∃ t' ∈ (t, t+H] : W_2(π(·|b_L^1,o), π(·|b_L^2,o)) > δ_f}`；**latent fork 不确定性** `U_fork = U_L · P(D | b_L, o_t)`。关键性质：可以出现 `U_epi^act ≈ 0` 而 `U_fork` 很大——R69 只测前者，故对其失明。

**定义 313（指令条件效用与偏好解析）** 语言可能同时表达取舍（「快点」「小心点」「省点电」）。解析为偏好权重 `w = (w_s, w_t, w_e, w_r)`（成功 / 时间 / 能量 / 风险），得 `J = w_s·S − w_t·T − w_e·E − w_r·R`，其中 `R ≤ R_max` 为硬约束（`w_r` 只在安全域内塑形）。由语言诱导的**偏好能量价格** `μ_pref = w_e / max(w_s, ε)`：人愿意为「多一分成功」付多少焦耳。`w` 的不确定性并入 `H_sem`。

**定义 314（焦耳能量账本 JEL）** 电量状态 `e_t`，动力学
`e_{t+1} = e_t − c_task(a_t) − c_info(g_t) − c_comp(K_t, q_t) − c_wait − η_t`，
其中 `η_t` 为损耗/热漂移；硬约束 `e_t ≥ e_safe`（∀t）且 `e_H ≥ e_reserve`（返航/安全停止）。松弛 `s_t = e_t − e_safe`。能量模型 `ĉ` 带可信度 `τ_E = P(|ĉ−c| ≤ ε_E)`；不可信时按分布鲁棒放大储备边际 `e_margin = Quantile_{1−β}[energy_need]`。账本分四类焦耳：任务 / 信息 / 计算 / 等待，分别可审计。

**定义 315（能量影子价格 μ_t）** `μ_t = ∂V_t^*/∂e_t`，即最优受限值对电量的边际价值（能量约束的 Lagrange 乘子）。可计算近似：
`μ_t = max(μ_pref, μ_res(e_t)) · ρ_τ`，
其中 `μ_res(e_t) = κ/(s_t+δ)`（障碍函数，电量越薄越贵），`ρ_τ = 1+(1−τ_E)κ_τ ≥ 1`（能量模型越不可信，越保守地抬价）。性质：`μ_t ≥ 0`；`∂μ_t/∂e_t ≤ 0`；预算宽松时 `μ_t ≈ μ_pref`，储备告急时 `μ_t → ∞`。`μ_t` 由轻量对偶/半步前瞻求解，单调裁剪并缓存。

**定义 316（能量定价信息价值 EPV）** 对候选信息动作 `g`（问 / 注视 / 探针 / 等待 / 加采样）：
`EPV(g) = VoI(g) − μ_t·c_E(g)`，`RoI(g) = VoI(g)/c_E(g)`；
选择 `g* = argmax_g EPV(g)`，s.t. `c_E(g) ≤ s_t − e_margin`、`g` 过 C-RAS-WM 认证、证据纪律满足。若所有 `EPV ≤ 0` 或不可承受：记 `g=∅`，走 R69 兜底。这里 `VoI` 同时包含对意图后验（`H_sem,H_grd`）与动作模态的期望熵减，并对 latent fork 计折扣损失。**R69 的 `VoI−c` 是 `μ` 为常数、且不区分焦耳类别时的特例。**

**定义 317（语言-能量协商 NEG）** 可行性判据：`P_finish(ξ_L, e_t, H) ≥ 1−δ_fin` 且 `E_need(ξ_L) ≤ s_t − e_margin`。不满足则触发协商，候选包括：放宽范围、放宽容差、延长期限、请求补能、交接/安全停靠。协商动作 `g_neg` 按 EPV 选择（其 `VoI` 是「契约修改后可行性与成功率的提升」）。协商产物是显式契约 `C = (scope, tolerance, deadline, energy_cap, success_target)`；执行必须落在 `C` 内。**安全约束永不可协商**，只可协商任务范围与容差；每次放宽写入审计。

**定义 318（能量-算力-消解耦合 ECR）** 流采样数 `K`、语言解码档位 `q ∈ {template, small, full_llm}` 共同决定信息增益与能耗。`U_epi(K,q)` 随 `K`、`q` 单调不增；计算能耗 `c_comp(K,q) = αK + βK^γ + c_llm(q)`。选择 `(K,q)* = argmax [ΔVoI_resolution(K,q) − μ_t·c_comp(K,q)]`，s.t. 实时预算与 `c_comp ≤ s_t`。定义**认知饥饿**：当 `s_t` 低于 `c_comp(K_min,q_min)` 时，可达的 `U_epi` 存在正下界，任何安全论证都必须把这个下界计入。

**定义 319（安全-能量字典序守卫 SEL）** 决策序：安全认证 ≻ 能量可行 ≻ 任务效用 ≻ 效率。`e_safe` 为**围栏**，信息/计算动作不得侵入。降级阶梯 **EDL**：`L0_full`（问+多采样+LLM）→ `L1_high_value`（只问高 EPV、模板问句）→ `L2_perception_only`（仅感知消歧、K=1）→ `L3_park`（安全停靠/交接）。层级由 `(s_t, τ_E, cert_valid)` 单调决定，带滞回防抖；任何层级都不得削弱安全认证。

**定义 320（能量-语言证书 J_LEAN）** `J_LEAN = (J_FLUID, LIG_hash, energy_ledger_hash, s_min, μ_t_path, τ_E, (K,q)_path, instruction_contract, negotiation_log_hash, pareto_point, lean_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ (∀t: s_t ≥ 0) ∧ U_epi^min(e_t) 已计入 ∧ (契约满足 ∨ 已协商留痕) ∧ 对账误差 ≤ ε_e ∧ EDL 单调`。

**定义 321（语言-能量威胁模型 ℰ_LEAN）** `ℰ_LEAN = ℰ_FLUID × ℰ_energy × ℰ_semantic`。其中 `ℰ_energy`：紧迫性注入（「快点」「别检查了」诱导跳步）、电量遥测欺骗、能耗模型投毒（让机器人低估关键消歧的成本）、重复提问的拒绝服务；`ℰ_semantic`：指代混淆、范围偷换、契约注入、把有害问题包装成澄清。证据纪律：**单一来源（人、遥测、模型）不得解锁安全储备，也不得放宽安全约束**；`k` 个正交来源一致方可改契约或动用储备。

**定义 322（语言-能量审计 LAC）** 对每一焦耳做归因审计：这次提问值不值它的焦耳？契约与实际执行是否一致？是否尊重了语言表达的偏好（快 / 稳 / 省）？是否逼近过 `e_safe`？并做**反事实能量审计**：与「不交互」影子策略比较真实能耗与成功率，量化语言通道的真实回报。结论回灌 `τ_E` 先验与 `μ_t` 校准。

**定义 323（信息-焦耳 Pareto 点）** 对给定任务族定义可达集 `𝒫 = {(S, E) : 存在策略使成功率 ≥ S 且期望能耗 ≤ E}`；LEAN 的**认证运行点**为 `(S*, E*) = argmax_{𝒫} w_s S − w_e E`，s.t. 安全与储备约束；R69 是 `μ` 常数下 `𝒫` 的一个角点，R68 是 `E` 最小但 `S` 较低的另一个角点。该定义把「省电」与「成功率」的取舍显式化，供 E299/E303 比较。

## 2. 关键算法骨架

```python
# IP-264 LIG：语言意图图（解析一次、缓存；对话只增量更新未接地节点）
class IntentGraph:
    def update(self, xi_L, o_t, h_t):
        G = self.parser.parse(xi_L)                     # GOAL/REFERENT/RELATION/CONSTRAINT/STOP
        for v in G.nodes:
            v.belief = self.grounder(v, o_t, h_t)       # p(rho_v, theta_v, feasible_v)
        return G

    def uncertainty(self, G):
        H_sem = entropy_over_structures(G)              # 语义/结构
        H_grd = sum(v.w * entropy(v.belief.referents) for v in G.nodes)
        return H_sem, H_grd, max(len(v.belief.referents) for v in G.nodes)

# IP-273 LFD：意图歧义 -> 动作歧义 + latent fork
def propagate_intent(G, policy, o_t, horizon):
    H_sem, H_grd, _ = G.uncertainty()
    U_L    = H_sem + H_grd
    T_L    = jacobian_action_dist_wrt_intent(policy, G, o_t)   # 敏感度
    U_act  = policy.action_epistemic(o_t) + norm(T_L) * U_L
    D      = probability_of_divergence(G, policy, horizon)     # 当前等价、未来分叉
    U_fork = U_L * D
    return U_act, U_fork

# IP-265 JEL：能量账本（先记账、后执行；与遥测对账）
class EnergyLedger:
    def slack(self):            return self.e - self.e_safe
    def reserve_margin(self):   return self.e_reserve * (1 + (1 - self.tau_E) * KAPPA_TAU)
    def can_afford(self, c_e):  return c_e <= self.slack() - self.reserve_margin()
    def commit(self, c_e):      self.e -= c_e
    def reconcile(self, e_tel):
        if abs(self.e - e_tel) > EPS_E:
            self.tau_E = max(0.0, self.tau_E - DELTA_TAU)
            return "DEGRADE"                            # 账本不可信 -> EDL 降级
        return "OK"

# IP-266 SPC：影子价格（偏好价 x 稀缺价 x 模型不可信惩罚；单调裁剪）
def shadow_price(ledger, w):
    mu_pref = w.e / max(w.s, EPS)
    mu_res  = KAPPA / (ledger.slack() + DELTA)
    rho_tau = 1.0 + (1.0 - ledger.tau_E) * KAPPA_TAU
    return max(mu_pref, mu_res) * rho_tau

# IP-268 EPV：能量定价信息价值（R69 的 VoI-c 是 mu 为常数的特例）
def choose_info_action(modes, G, ledger, o_t):
    mu, best = shadow_price(ledger, G.preference), None
    for g in info_action_candidates(modes, G):          # ask/gaze/probe/defer/sample
        if not c_ras_wm.certify_info(g, o_t):      continue
        c_e = energy_cost(g)                            # 运动 + 计算 + 社交，单位焦耳
        if not ledger.can_afford(c_e):             continue
        voi = info_gain(modes, G, g, o_t)               # 意图后验 + 动作模态 + fork
        epv = voi - mu * c_e
        if best is None or epv > best.epv: best = (g, epv, c_e)
    return best if best and best.epv > 0 else None

# IP-269 ECR：算力-消解调度（K 与语言解码档位都按每焦耳回报选）
def choose_compute(modes, G, ledger, o_t):
    mu, best = shadow_price(ledger, G.preference), ((1, "template"), -INF)
    for K in (1, 2, 4):
        for q in ("template", "small", "full_llm"):
            c = compute_energy(K, q)
            if not ledger.can_afford(c): continue
            epv = resolution_gain(K, q) - mu * c
            if epv > best[1]: best = ((K, q), epv)
    return best[0]

# IP-270 NEG：指令-能量可行性检查与协商（付不起不许静默执行）
def negotiate_if_needed(G, ledger, o_t, horizon):
    feasible = (ledger.finish_probability(G, horizon) >= 1 - DELTA_FIN
                and ledger.expected_need(G) <= ledger.slack() - ledger.reserve_margin())
    if feasible: return None
    g_neg = choose_info_action(contract_relaxations(G), G, ledger, o_t)
    return g_neg if g_neg else ("SAFE_HANDOVER", 0.0)

# IP-271 SEL：安全-能量字典序守卫 + 降级阶梯（滞回防抖）
class SafetyEnergyGuard:
    LEVELS = ("L0_full", "L1_high_value", "L2_perception_only", "L3_park")
    def level(self, ledger, cert_valid, prev):
        s = ledger.slack()
        if not cert_valid or s <= 0:                raw = "L3_park"
        elif s < ledger.reserve_margin():           raw = "L2_perception_only"
        elif s < 2 * ledger.reserve_margin():       raw = "L1_high_value"
        else:                                       raw = "L0_full"
        return demote_at_most_one(raw, prev)          # 只允许逐级下降，禁止跳变

# IP-275 LEAN 主闭环（继承 FLUID-RAS，只在不确定性处置处插入语言/能量层）
def LEAN_RAS_round(M, obs, xi_L):
    G = M.lig.update(xi_L, obs, M.history)              # 语言意图图（增量）
    z, o = M.mtm.forward(...); M.jel.reconcile(obs.battery)
    lvl = M.sel.level(M.jel, M.cert.valid, M.prev_lvl)
    U_ale = M.aud.aleatoric(M.fmp.sample(o, 1))
    U_act, U_fork = M.lfd.propagate_intent(G, M.policy, o, M.vista.H)
    # 1) 先判付不付得起；付不起就协商契约，绝不静默执行
    neg = M.neg.negotiate_if_needed(G, M.jel, o, M.vista.H) if lvl != "L3_park" else None
    if neg is not None: G = M.neg.apply_contract(G, neg); M.lac.log_contract(neg)
    # 2) 能量定价地决定：问 / 看 / 触 / 加采样 / 不问
    g = (M.epv.choose_info_action(M.modes, G, M.jel, o)
         if lvl in ("L0_full", "L1_high_value") and (U_act > TAU_EPI or U_fork > TAU_FORK)
         else None)
    K, q = (M.ecr.choose_compute(M.modes, G, M.jel, o) if lvl == "L0_full"
            else (1, "template"))
    # 3) 交互（若选）——同样过安全认证与证据纪律；记账后才执行
    if g is not None:
        ans = M.cia.execute(g, G)
        M.jel.commit(energy_cost(g))
        M.aud.update_belief(M.modes, ans, G)
        U_act, U_fork = M.lfd.propagate_intent(G, M.policy, o, M.vista.H)
    # 4) 两级保守退避：aleatoric + 未消解 epistemic + 未出清 fork（打折计入）
    U_floor = U_ale + (U_act if g is None else 0.0) + M.beta * U_fork
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 5) 安全-能量字典序：只允许缩短已认证前缀，不改安全包络
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not M.jel.can_afford(energy_cost(A[:k])):
        k = M.sel.energy_bounded_prefix(A, M.jel)       # 只缩短
    # 6) 审计 + 证书
    M.lac.submit_async(G, g, neg, (K, q), shadow_price(M.jel, G.preference), M.jel, (U_ale, U_act, U_fork))
    return k, lam, G, (U_ale, U_act, U_fork)
```

## 3. 推导

**引理 19（EPV 的门限结构与单调比较静态）** 设信息动作 `g` 的 `VoI` 单调子模、能量成本可加，预算 `Σc_E(g_t) ≤ B`。Lagrange 化得 `Σ[VoI(g_t) − μ c_E(g_t)]`，最优解满足门限结构 `g ∈ G* ⇔ RoI(g) ≥ μ`（`μ` 为能量约束乘子）；贪心按 `RoI` 选择具 `(1−1/e)` 近似保证。比较静态：`μ` 上升 ⇒ 最优集合关于 `RoI` 向上闭合、动作数不增，即 `d|G*|/dμ ≤ 0`。**系**：R69 的固定 `c` 等价于 `μ` 为常数且 `c=μc_E`，无法表达「同一个问句在 8% 电量时变贵」；LEAN 的价格随 `s_t` 上升而自动放弃低回报消歧。

**引理 20（动作等价但意图分叉：R69 的盲区）** 构造两意图 `m_1,m_2`，在 `t<t_0` 动作分布相同、`t_0` 处分叉且损失为 `L`。则 `t<t_0` 时 `U_epi^act=0`，而 `U_fork = H(M)·P(D) > 0`。R69 只看前者，故不会消歧；LEAN 的期望收益增量为 `γ^{t_0−t}·L·ΔH`，与成本比较得**消歧地平线**：当 `t_0−t < log(μ c_E/(L ΔH))/log γ` 时提前消歧为正回报。**系**：语言之所以比被动感知更适合消解此类歧义，是因为它可以在分叉前的任意时刻以低焦耳介入。

**引理 21（语言的信息-能量回报）** 在「探索能耗随先验信息线性下降」的代理模型下，`E_explore(b_L) = E_0 − κ·I(ξ_L; task)`。一次澄清给出信息 `I(g)`、成本 `c_ask`，则净回报 `κ·I(g) − μ·c_ask`；值得问当且仅当 `κ·I(g)/c_ask ≥ μ`。**系**：任务越陌生（指代多、搜索空间大、`κ` 大），语言越值钱；当系统预计要做昂贵探索时，主动索要更具体的指令是一笔「省焦耳的投资」，而非单纯开销。反之，在熟悉场景中反复提问会被 `μ` 自动抑制。

**引理 22（能量-算力耦合下的认知下界）** 设 `U_epi(K) ≥ U_epi^∞ + C/K^α`（采样复杂度型下界），`c_comp(K) ≥ αK`。给定松弛 `s`，最大可行 `K_max(s)` 满足 `c_comp(K_max) ≤ s`，于是 `U_epi^min(s) ≥ U_epi^∞ + C/K_max(s)^α`。当 `s → c_comp(K_min)` 时认知下界显著上升。因此安全储备必须满足 `e_safe ≥ e_move + e_stop + c_comp(K_min,q_min) + e_margin`。**系**：低电量不仅缩短可达距离，还抬高不确定性地板；R69 的 `λ_floor` 若不含这一项，会在尾段低估风险。

**定理 18（LEAN 在能量可行域内严格包含 R69）** 在 A95–A99（模态可分、流密度 Lipschitz、能量模型有界误差、安全前缀闭合）下：
(a) 当 `U_L=0`、`U_fork=0`、`μ_t=常数`、预算宽松且 `NEG` 不触发时，LEAN 与 FLUID-RAS **逐指令相同**；
(b) 对任何能量可行的 FLUID-RAS 策略，LEAN 取相同动作时行为相同；若 FLUID-RAS 的动作会使 `s_t<0`，LEAN 拒绝或降级该动作，故在受限回报上 `LEAN ≥ FLUID-RAS`；
(c) 当指令在预算内不可满足时，R69 不存在「既执行又保持可行」的动作，只能静默失败；LEAN 通过 `NEG` 产出可行契约，其成功率不低于 R69 的静默失败基线。
故 R69 = LEAN 在「指令已接地 + 能量价格恒定 + 预算宽松 + 无需协商」边界上的退化，R68 = `μ=∞ / EDL=L3` 边界。**安全侧不做任何让步**。

**定理 19（安全-能量字典序与降级单调 / 无突变）** SEL 的层级对 `(s_t, τ_E)` 单调：`s_t` 下降或 `τ_E` 下降只会保持或降低层级；每层都保留 `J_FLUID` 的安全认证；`energy_bounded_prefix` 只截短已认证前缀，而安全集对前缀闭合，故安全包络不变；滞回保证层级不抖动；账本误差超过 `ε_e` 时在对账点触发降级，早于储备被侵入。结合 R69 定理 17（提交/换装不变式），控制连续、无突变。

## 6. 本轮最大风险

**一句话**：LEAN-RAS 的全部取舍都建立在「能量代价模型 `ĉ` 与影子价格 `μ_t` 可信」这一前提上——一旦 `ĉ` 失准（地形/负载/温度/电池非线性）或语言偏好被误接地，系统会滑向两种同样致命的失败：**为省电而拒绝一次便宜且安全关键的求证（认知饥饿）**，或**为一句听起来合理的低价值提问花掉安全储备（能量破产）**；而证书审计的是「申报的焦耳」而非「真实的焦耳」，两种失败都能以完全合规的姿态发生。

**次级风险与缓解**：1) `μ` 近似误差 → 障碍函数保守 + E317 对偶对照 + 单调裁剪；2) 意图图孔洞错估 → ECE/可靠图校准 + 证据纪律 + E314 OOD 门控；3) 协商被滥用为逃避任务 → 契约留痕 + 人类批准 + E306 监督；4) 低电量认知饥饿 → 定义 318 认知下界 + 安全储备含 `c_comp(K_min)` + E305/E313；5) 紧迫性/遥测攻击 → ℰ_LEAN 对抗训练 + 单一来源不得解锁储备（定义 321）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** LEAN-RAS = (LIG,JEL,EPV,ECR,NEG,SEL,LAC,RAS-WM‡)。四不变式：实时流零学习写操作；安全储备不可侵犯且安全认证字典序优先；能量账本守恒并对账（误差 ≤ ε_e 否则降级）；指令契约显式化（不可满足必须协商留痕）。

**定义 311（LIG）** `ξ_L → G_L=(V,E)`；节点带接地候选 `ρ_v`、参数 `θ_v`、可行性标记；`b_L(v)=p(ρ_v,θ_v,feasible_v|ξ_L,o_t,h_t)`；`H_sem`（结构）与 `H_grd`（指代/参数）分通道；`M_ref=max_v|supp(ρ_v)|`。

**定义 312（传播与 latent fork）** `U_epi^act=U_epi^policy+‖T_L‖U_L`；分叉事件 `D`；`U_fork=U_L·P(D)`。允许 `U_epi^act≈0` 而 `U_fork` 很大——R69 的盲区。

**定义 313（指令条件效用）** 语言解析为偏好 `w=(w_s,w_t,w_e,w_r)`；`J=w_sS−w_tT−w_eE−w_rR`，`R≤R_max` 硬约束；`μ_pref=w_e/w_s`。

**定义 314（JEL）** `e_{t+1}=e_t−c_task−c_info−c_comp−c_wait−η_t`；`e_t≥e_safe`，`e_H≥e_reserve`；`s_t=e_t−e_safe`；`τ_E` 低时按分布鲁棒放大 `e_margin`；四类焦耳可审计。

**定义 315（SPC）** `μ_t=∂V_t^*/∂e_t≈max(μ_pref,μ_res(s_t))·ρ_τ`；`∂μ/∂e≤0`；宽松时 `≈μ_pref`，告急时 `→∞`。

**定义 316（EPV）** `g*=argmax[VoI(g)−μ_t c_E(g)]`，s.t. `c_E(g)≤s_t−e_margin`、安全认证、证据纪律；`VoI` 含意图后验 + 动作模态 + fork 折扣；全负则 `g=∅` 走 R69。

**定义 317（NEG）** 可行性：`P_finish≥1−δ_fin` 且 `E_need≤s_t−e_margin`；否则协商 `C`；安全约束不可协商，仅可谈范围/容差/期限/补能/交接；每次放宽留痕。

**定义 318（ECR）** `U_epi(K,q)` 单调不增；`c_comp(K,q)=αK+βK^γ+c_llm(q)`；`(K,q)*=argmax[ΔVoI−μ_t c_comp]`；定义认知饥饿与 `U_epi^min(s)` 正下界。

**定义 319（SEL/EDL）** 安全认证 ≻ 能量可行 ≻ 效用 ≻ 效率；`e_safe` 围栏；四级阶梯由 `(s_t,τ_E,cert_valid)` 单调决定，带滞回；任何层不得削弱安全认证。

**定义 320（J_LEAN）** `Valid ⇔ Valid(J_FLUID) ∧ s_t≥0 ∧ U_epi^min(e_t) 已计 ∧ (契约满足∨已协商) ∧ 对账≤ε_e ∧ EDL 单调`。

**定义 321（ℰ_LEAN）** `ℰ_FLUID × ℰ_energy × ℰ_semantic`：紧迫性注入、遥测欺骗、能耗模型投毒、重复提问 DoS；指代混淆、范围偷换、契约注入、有害澄清。单一来源不得解锁储备或放宽安全；`k` 正交来源一致方可改契约。

**定义 322（LAC）** 每焦耳归因审计 + 契约一致性 + 偏好尊重度 + 储备逼近告警；反事实能量审计（对比「不交互」影子策略）量化语言真实回报；回灌 `τ_E`、`μ` 校准。

**定义 323（信息-焦耳 Pareto 点）** `𝒫={(S,E): 存在策略成功率≥S 且期望能耗≤E}`；认证运行点 `(S*,E*)=argmax_{𝒫} w_sS−w_eE`，s.t. 安全与储备；R69/R68 是 `𝒫` 的两个角点。

## 3. 关键算法伪代码

```python
# IP-264 LIG / IP-272 LFD
def lean_intent(G, policy, o_t, horizon):
    H_sem, H_grd, M_ref = G.uncertainty()          # 结构熵 / 接地熵 / 指代多重度
    U_L = H_sem + H_grd
    T_L = jacobian_action_dist_wrt_intent(policy, G, o_t)
    U_act = policy.action_epistemic(o_t) + norm(T_L) * U_L
    U_fork = U_L * probability_of_divergence(G, policy, horizon)
    return U_act, U_fork, M_ref

# IP-265 JEL / IP-266 SPC
def shadow_price(ledger, w):
    return max(w.e / max(w.s, EPS), KAPPA / (ledger.slack() + DELTA)) \
           * (1 + (1 - ledger.tau_E) * KAPPA_TAU)

# IP-267 EPV：能量定价信息价值
def choose_info_action(modes, G, ledger, o_t):
    mu, best = shadow_price(ledger, G.preference), None
    for g in info_action_candidates(modes, G):
        if not c_ras_wm.certify_info(g, o_t):  continue
        c_e = energy_cost(g)
        if not ledger.can_afford(c_e):         continue
        epv = info_gain(modes, G, g, o_t) - mu * c_e
        if best is None or epv > best.epv:     best = (g, epv, c_e)
    return best if best and best.epv > 0 else None      # 负回报 -> 不交互

# IP-268 ECR：算力-消解联合调度
def choose_compute(modes, G, ledger, o_t):
    mu, best = shadow_price(ledger, G.preference), ((1, "template"), -INF)
    for K in (1, 2, 4):
        for q in ("template", "small", "full_llm"):
            c = compute_energy(K, q)
            if not ledger.can_afford(c): continue
            epv = resolution_gain(K, q) - mu * c
            if epv > best[1]: best = ((K, q), epv)
    return best[0]

# IP-269 NEG：不可行则协商，绝不静默执行
def negotiate_if_needed(G, ledger, o_t, horizon):
    ok = (ledger.finish_probability(G, horizon) >= 1 - DELTA_FIN
          and ledger.expected_need(G) <= ledger.slack() - ledger.reserve_margin())
    if ok: return None
    g = choose_info_action(contract_relaxations(G), G, ledger, o_t)
    return g if g else ("SAFE_HANDOVER", 0.0)

# IP-275 主闭环（继承 FLUID-RAS，只插入语言/能量层）
def LEAN_RAS_round(M, obs, xi_L):
    G = M.lig.update(xi_L, obs, M.history)
    z, o = M.mtm.forward(...); M.jel.reconcile(obs.battery)
    lvl = M.sel.level(M.jel, M.cert.valid, M.prev_lvl)
    U_ale = M.aud.aleatoric(M.fmp.sample(o, 1))
    U_act, U_fork, _ = lean_intent(G, M.policy, o, M.vista.H)
    neg = M.neg.negotiate_if_needed(G, M.jel, o, M.vista.H) if lvl != "L3_park" else None
    if neg is not None: G = M.neg.apply_contract(G, neg); M.lac.log_contract(neg)
    g = (M.epv.choose_info_action(M.modes, G, M.jel, o)
         if lvl in ("L0_full", "L1_high_value") and (U_act > TAU_EPI or U_fork > TAU_FORK)
         else None)
    K, q = (M.ecr.choose_compute(M.modes, G, M.jel, o) if lvl == "L0_full"
            else (1, "template"))
    if g is not None:
        ans = M.cia.execute(g, G); M.jel.commit(energy_cost(g))
        M.aud.update_belief(M.modes, ans, G)
        U_act, U_fork, _ = lean_intent(G, M.policy, o, M.vista.H)
    U_floor = U_ale + (U_act if g is None else 0.0) + M.beta * U_fork
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not M.jel.can_afford(energy_cost(A[:k])):
        k = M.sel.energy_bounded_prefix(A, M.jel)       # 只缩短已认证前缀
    M.lac.submit_async(G, g, neg, (K, q), shadow_price(M.jel, G.preference), M.jel, (U_ale, U_act, U_fork))
    return k, lam, G, (U_ale, U_act, U_fork)
```

## 4. 推导

**引理 19（EPV 门限结构与单调比较静态）** `VoI` 子模、成本可加时，能量约束的 Lagrange 乘子 `μ` 给出门限 `g∈G* ⇔ RoI(g)≥μ`，贪心按 `RoI` 有 `(1−1/e)` 保证；`μ` 上升则最优集合关于 `RoI` 向上闭合、动作数不增。系：R69 的固定 `c` = 常数 `μ`，无法表达「同问句在 8% 电量时更贵」。

**引理 20（动作等价、意图分叉）** 存在 `U_epi^act=0` 而 `U_fork>0` 的构造；LEAN 的提前消歧收益为 `γ^{Δt}LΔH`，得消歧地平线 `Δt < log(μc_E/(LΔH))/log γ`。系：语言可在分叉前以低焦耳介入，这是被动感知做不到的。

**引理 21（语言的信息-能量回报）** `E_explore=E_0−κ·I(ξ_L;task)`；澄清净回报 `κI(g)−μc_ask`，值得问当且仅当 `κI(g)/c_ask ≥ μ`。系：任务越陌生、`κ` 越大，语言越值钱；主动索要更具体指令是省焦耳的投资。

**引理 22（能量-算力-认知下界）** `U_epi(K)≥U_epi^∞+C/K^α`、`c_comp(K)≥αK`，得 `U_epi^min(s)≥U_epi^∞+C/K_max(s)^α`；故 `e_safe ≥ e_move+e_stop+c_comp(K_min,q_min)+e_margin`。系：低电量是认知危害，`λ_floor` 必须含此项。

**定理 18（在能量可行域内严格包含 R69）** (a) `U_L=U_fork=0`、`μ` 常数、预算宽松、`NEG` 不触发 ⇒ 与 FLUID-RAS 逐指令相同；(b) 对能量可行的 FLUID 策略行为相同，对会侵入储备的动作 LEAN 拒绝/降级，受限回报不劣；(c) 指令不可满足时 R69 只能静默失败，LEAN 的 `NEG` 产出可行契约，成功率不低于该基线。R68 = `μ=∞ / L3`。

**定理 19（安全-能量字典序与无突变）** EDL 对 `(s_t,τ_E)` 单调并带滞回；每层保留安全认证；`energy_bounded_prefix` 只截短已认证前缀（安全集对前缀闭合），安全包络不变；对账越界先于储备侵入触发降级；结合 R69 定理 17 得控制连续、无突变。

## 7. 本轮最大风险

**一句话**：LEAN-RAS 的全部取舍都押在「能量代价模型 `ĉ` 与影子价格 `μ_t` 可信」这一前提上——`ĉ` 一旦失准（地形/负载/温度/电池非线性）或语言偏好被误接地，系统会滑向两种同样致命的失败：**为省电拒绝一次便宜且安全关键的求证（认知饥饿）**，或**为一句低价值提问花掉安全储备（能量破产）**；而证书审计的是「申报的焦耳」而非「真实的焦耳」，两种失败都能以完全合规的姿态发生。

**次级风险与缓解**：`μ` 近似误差 → 障碍函数保守 + E317 对照 + 单调裁剪；意图孔洞错估 → 可靠图/ECE 校准 + 证据纪律 + E314 门控；协商被滥用为逃任务 → 契约留痕 + 人类批准 + E306；低电量认知饥饿 → 定义 318 认知下界 + 储备含 `c_comp(K_min)` + E305/E313；紧迫性/遥测攻击 → ℰ_LEAN 对抗训练 + 单一来源不得解锁储备（定义 321）。
