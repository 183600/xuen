# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「腕部相机」×「指令泛化」）

> 第 57 轮把承诺的判定权下沉到"元推断 + 跨模态对账 + 信任状态机"，但它的证据始终回答同一个问题：**"这个世界是什么样"**；它默认了两个从未被审视的前提：**(a)** 系统知道自己被要求做什么——指令被当成一个已正确接地的任务标签，而不是一段可能被改写、组合、指代模糊的自然语言；**(b)** 证据的空间分辨率足以覆盖它即将触碰的那一小块接触面——地图与探针给出的是区域级信念，而真正决定不可逆接触成败的是接触点级的指称。于是出现两种"自信的错位"：**指称错位**（把"桌边"接地到错误的边，或把"这个杯子"指向了旁边的杯子）与**泛化错位**（换一种说法、加一个否定、组合两个子任务，任务语义悄悄漂移，而安全义务没有跟着收紧）。本轮两个灵感各补一层：**腕部相机**把证据从区域级推进到接触点级，并带来一个新的认识论问题——"看得见"不等于"看得清"更不等于"看得对"；**指令泛化**把任务从单一标签变成带语义半径与组合闭包的指令空间，并迫使我们承认一条不对称原则——**任务可以泛化，安全不许泛化**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"指称可接地、视角可辨识、泛化有边界的证据承诺"**。

核心矛盾：
- **H35（接地 vs 分辨率）**：地图级证据无法为"这里/这个/边缘"这类接触点级指称负责；腕部相机可以，但它只看得到局部，且局部与全局的尺度冲突既可能是"指错了"，也可能是"手眼标定漂了"——系统必须在没有额外证据时区分这两种病因。
- **H36（泛化 vs 安全不变性）**：任务策略应当对改写、组合、否定泛化，安全义务却不允许随措辞漂移；但生成任务泛化与判定释义一致性的往往是同一个语义模型，于是"五种说法都一致"可能只是"同一个错误被问了五遍"，不构成独立证据。
- **H37（看得见 vs 看得对）**：腕部相机是主动传感器——机器人可以凑近、换角度、补光；这提高了信息量，也引入了确认偏误（指令让看什么就只看什么）、视角依赖的物理欺骗（透明/反光/遮挡）与手眼标定漂移（证据被注册到错误的位置）。主动去看，可能只是更努力地看错。

## 0. 直觉与动机

**灵感 1（腕部相机 → 接触前局部证据 + 视角可辨识性 + 手眼标定证书）**
直觉：把腕部相机当成"另一只眼"是浪费的。它真正独特的地方是**它长在将要接触的那个末端上**：它能回答"我马上要碰的这一小块，到底是什么、有没有危险、我的指尖会落在哪"。但这带来三个必须先证的环节：**看得见**（可达、无遮挡、分辨率够）、**看得清**（光照、反光、透明、形变不把证据糊掉）、**看得对**（手眼标定没漂，看到的点确实是将要接触的点）。因此本轮不把腕部视觉当免费证据，而把它变成一类需要**视角可辨识性证书 VIC** 的证据：一个视角只有在"若危险存在，该视角能以足够功效把它区分出来"，并且标定漂移在容差内时，才允许进入承诺；否则它最多只是探索，不能算证据。更进一步，腕部相机让"看"成为一种**非接触探针**：可以主动规划视角，用信息增益换掉一次有风险的接触。

**灵感 2（指令泛化 → 指令泛化契约 + 双尺度接地 + 安全泛化不对称）**
直觉：人类说"把杯子放到桌边"，机器人接到的不是一个任务 ID，而是一段可以被改写（"把那个杯子挪到桌子边缘"）、被组合（"先擦桌子再放杯子"）、被否定（"别碰桌边那个杯子"）的语言。指令泛化的危险不在于"没听懂"，而在于**听懂了一个稳定但错误的映射**：同一个语义解析器把十种说法都映射到同一个错误指称，于是释义投票全票通过。本轮把指令变成一纸**指令泛化契约 IGC**：在认证语义半径内，改写必须保持任务等价；组合必须在闭包内；否定与量词必须显式处理，处理不了就澄清而不是猜。最关键的纪律是**安全泛化不对称**：任务成功可以随泛化下降，安全义务必须在改写前后逐字不变——不允许"换一种说法"就把不可逆接触降级为可逆。与此同时，语言中的"这里/这个/边缘"必须做**双尺度接地**：地图给全局候选，腕部相机给接触点级确认，两者不一致就拒绝 EV-instr 并触发澄清或补看。

**灵感 3（两灵感合流 → 指令条件的看，与反指令盲区扫描）**
直觉：指令和腕部相机天然互补——指令告诉你"要找什么"，腕部相机告诉你"眼前是什么"。但把两者直接耦合会制造最隐蔽的失败：**指令条件的注意**。如果视角规划只优化"验证指令提到的危险"，那么指令没提到的危险就永远不在视野里；机器人会越来越擅长确认自己已经相信的东西。因此本轮强制一条**反指令盲区扫描预算**：每次高风险接触前，必须留出一部分视角/探针预算给**与指令无关**的危险假设（未知材质、意外障碍、语义外物体）；指令只能增加扫描，不能减少扫描。这把"看得见"从"看得见我想看的"改造成"至少看过一次我没想到的"。

**灵感 4（两灵感再合流 → 证据独立性核算：释义投票与多视角投票都不算独立）**
直觉：第 57 轮已经知道"同一模态问五遍"不是独立证据；本轮要补上两个更隐蔽的版本：**同一语义解析器生成的五种改写**是同一失效模式，**同一光学/光照下的五个腕部视角**也是同一失效模式。于是引入**证据独立性核算 EIA**：先把证据按失效模式分组，再按组而非按样本做联合界。EV-instr 与 EV-wrist 只有在至少两个独立失效模式组同侧，或有一个物理上异质的模态（触探/本体）交叉佐证时，才允许计入 P_fail；否则它们只是"更努力地看同一个方向"。

**灵感 5（PCE-IG → 探-诺-演·指令泛化版）**
直觉：在第 57 轮 PCE+ 的每个检查点上前后各加一道闸：**入口**查指令是否在认证支撑域内、指称是否双尺度一致；**过程**把"看"作为一种可规划、可计价的非接触探针，并强制反指令盲区预算；**出口**要求泛化证据与既有证据按失效模式组独立核算。探询预算、共识探针、个性化协商全部继承，只是证据门多了 EV-instr 与 EV-wrist 两类，且它们都带"证书才作数"的前置。三个新机制（指令契约、双尺度接地、视角可辨识）仍然只经"信念更准或动作更保守"两个安全通道起作用——这是对第 56/57 轮交互单调性的第三次强化。

## 1. 形式化定义（增量：定义 146–151）

**定义 146（指令泛化契约 IGC）** 指令空间 (ℒ,d_ℒ)，接地函数 g:ℒ→𝒯（任务语义与安全义务），释义距离 d_ℒ 同时计入表层改写、逻辑形式与指称集合。认证支撑域 𝒮_cert 满足：(i) 覆盖 Pr_{l~𝒟_L}[l∈𝒮_cert]≥1−α_L；(ii) **改写不变性** ∀l∈𝒮_cert, d_ℒ(l,l')≤ρ_sem ⇒ g(l')∈B_{ε_sem}(g(l))；(iii) **组合闭包** l1,l2∈𝒮_cert ∧ op∈𝒪_cert ⇒ l1 op l2∈𝒮_cert 且 g 按 op 组合；(iv) 否定/量词/条件句必须显式建模，否则判"语义未认证"；(v) OOD 指令分数 s_instr(l)>θ_instr ⇒ 退出认证域，只能澄清或切最保守任务模板，**禁止外推**。**安全泛化不对称（SGA）**：对任意 l' 为 l 的认证改写，安全义务 O_safe(l')=O_safe(l) 逐项相等；任务回报可降，安全界不可降。

**定义 147（双尺度指称接地 DSG）** 指称集合 Ref(l) 分为全局指称（地图可解析）、局部指称（接触点级）与指示指称（"这里/这个/边缘"）。全局接地 R_g=map_ground(r,𝓜)（第 56 轮地图，分辨率 μ_𝓜）；局部接地 R_l=wrist_ground(r,e_w,T_he)（末端坐标系与手眼变换）。接地一致性 A(R_g,R_l)=max_{T∈B(T_he,δ_he)} overlap(R_g,T(R_l))；若 A<θ_gnd ⇒ 判**尺度冲突**，EV-instr 失效，触发澄清/补看。指示指称必须同时有 R_l；非指示指称仅在任务精度要求 ≤μ_𝓜 时可只用 R_g。

**定义 148（腕部视角可辨识性与手眼证书 VIC）** 视角 v=(p,o,ν)（位姿/内参/光照），危险假设 H，可辨识功效 β(v,H)=P(该视角证据能区分 H 与 ¬H | v)；遮挡率 κ(v)、有效分辨率 r(v)、高光/透明风险 σ(v)、手眼漂移 δ_he。**VIC 通过** ⇔ β(v,H)≥β_min ∧ κ(v)≤κ_max ∧ r(v)≥r_min ∧ σ(v)≤σ_max ∧ δ_he≤ε_cal ∧ reachable(v) ∧ collision_free(v)。只有 VIC 通过的视角才可产出 EV-wrist；δ_he 由接触事件/标定物在线估计，超差时全部腕部证据标记为"标定降级"，禁止单独支撑不可逆接触。

**定义 149（证据独立性核算 EIA）** 证据源按**失效模式组**划分 𝒢：同一光学/光照下的多视角同组，同一语义解析器生成的多种改写同组，同一先验驱动的多次探针同组。有效独立数 n_eff(E)=支撑证据所在的、在给定世界状态下条件独立的组数（保守估计）。规则：EV-instr/EV-wrist 计入 P_fail 需 n_eff≥2，或存在物理异质模态（tap/prop）交叉佐证；联合界按组而非按样本取，禁止"释义投票=五条证据"与"多视角投票=五次独立观测"。审计记录每条证据的 group_id 与独立性声明，重算时不得重复计数。

**定义 150（指令条件视角规划与反指令盲区扫描 ICP/CIB）** 危险假设 H(l)=instruction_hazards(l)∪{H_⊥}，其中 H_⊥ 为指令外未知危险。视角选择 v\*=argmax_v [EIG(v;H(l))−cost(v)]，受 VIC 与机械臂安全约束。**盲区配额**：高风险接触/指示指称/接地冲突/OOD 指令触发时，至少 θ_blind 比例的视角-探针预算分配给**与 l 无关**的 H_⊥ 扫描；预算不足时选择更保守动作，而非取消盲区扫描。**单调性**：加入指令条件只能增加扫描项，不能删除盲区项。

**定义 151（指令接地证据门 IGE 与算子 PCE-IG）** 证据类 = EV-instr / EV-wrist / EV-probe\* / EV-visit / EV-margin / EV-xmodal / EV-human。**EV-instr** ⇔ l∈𝒮_cert ∧ s_instr(l)≤θ_instr ∧ DSG 一致 ∧ 安全义务已编译；**EV-wrist** ⇔ VIC 通过 ∧ δ_he≤ε_cal ∧ EIA 通过 ∧（不可逆接触还须物理异质模态交叉佐证）。不可逆接触必要证据集 = {EV-instr} ∪ {EV-probe\*∨EV-margin} ∪ 佐证 ∪（EV-wrist 仅当有物理交叉），显式不含 EV-xmodal。证书 J_g=(J_p, instr_cert, grounding_log, view_log, calib_log, independence_log, blindspot_log)。**算子 PCE-IG** 每检查点：①指令闸（IGC/OOD）；②双尺度接地；③元推断与跨模态对账（第 57 轮）；④视角规划 + 反指令盲区扫描；⑤探询/共识探针；⑥承诺 ⇔ 证据门过 ∧ 可交互承诺；否则按降级阶梯绕行/L2/安全停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def certify_instruction(l, igc, sources):             # IP-139 IGC
    if igc.ood_score(l) > igc.theta_instr:
        return Cert('OOD', action='clarify_or_conservative_template')
    P = independent_paraphrases(l, sources)          # 独立来源，非同一生成器
    for l2 in P + compositions(l, igc.ops):
        if not igc.equiv(l, l2, rho_sem, eps_sem):
            return Cert('unstable', action='clarify')
    O = igc.safety_obligations(l)                    # 改写前后逐项不变（SGA）
    return Cert('certified', obligations=O, groups=igc.groups(l, P))

def dual_scale_ground(l, M, wrist, T_he, theta_gnd): # IP-140 DSG
    refs = parse_referents(l)
    Rg = {r: map_ground(r, M) for r in refs.global_}
    Rl = {r: wrist_ground(r, wrist, T_he) for r in refs.local}
    for r in refs.deictic:
        if overlap(Rg.get(r), Rl.get(r), T_he) < theta_gnd:
            return Ground('scale_conflict', ref=r)   # 指错或标定漂，不许猜
    return Ground('ok', Rg=Rg, Rl=Rl)

def plan_views(cp, l, M, arm, budget):               # IP-141/150
    H = instruction_hazards(l) | {H_UNKNOWN}
    cand = [v for v in reachable_views(arm, cp, M)
            if vic(v, H) and arm_collision_free(v, M)]
    pick = argmax(cand, key=lambda v: eig(v, H) - cost(v))
    blind = max([v for v in cand if covers(v, H_UNKNOWN)],
                key=lambda v: eig_unknown(v), default=None)
    return select_with_quota(pick, blind, theta_blind, budget)

def wrist_evidence(res, cal, groups, phys_xcheck):   # IP-141/149
    if not vic_pass(res.v, res.hyp, cal) or cal.drift > eps_cal:
        return None                                  # 看得见≠看得对
    if n_eff(groups + [res.group]) < 2 and not phys_xcheck:
        return None                                  # 多视角同光学不算独立
    return Evidence('EV-wrist', group=res.group, level=res.level)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| IGC | 离线 O(\|𝒮_cert\|·\|P\|·C_parse)；在线 O(\|P\|·C_parse) | O(\|𝒮_cert\|) | 改写不变性、组合闭包、SGA（A41） |
| DSG | O(\|Ref\|·(C_map+C_view)) | O(\|Ref\|) | 双尺度一致、冲突可检出（A42） |
| VIC | O(\|V\|·d_H)/规划 | O(\|V\|) | β 下界诚实、手眼漂移 ≤ε_cal（A43） |
| EIA | O(\|E\|²) 小规模分组 | O(\|E\|) | 按失效模式组取界、禁止重复计数（A44） |
| IGE | O(\|σ\|) | O(\|σ\|) | 无证书不作数、不可逆不单靠腕部 |
| PCE-IG | O(\|CP\|·(k_p+k_c+k_v)·(C_VOI+C_view+d_φ)) | O(\|V\|+\|σ\|+\|𝒮_cert\|) | 盲区配额、有限终止 |

**正确性定理（Instruction-Grounded Viewpoint-Soundness, IGVS 概要）**：在 A33–A40 上加 (A41) IGC 诚实：认证覆盖 ≥1−α_L、OOD 漏检 ≤β_L、改写不变性成立、SGA 逐项满足；(A42) DSG 的接地与手眼误差有界、尺度冲突检测漏检 ≤δ_gnd；(A43) VIC 的 β/κ/r/σ 声明诚实、手眼漂移 ≤ε_cal；(A44) EIA 的失效模式分组诚实且按组取联合界。则：(i) **指令接地健全性**：认证域内 P(fail)≤δ_f+ε_instr+ε_gnd+ε_meta+δ_probe+ε_h+δ_wrist·1[EV-wrist]；OOD 指令只澄清/走保守模板，不产生承诺；(ii) **反自证**：释义投票与同光学多视角只有在 n_eff≥2 或有物理交叉时才降低 P_fail，因此"自洽的错误"不能靠换说法洗白；(iii) **安全泛化不对称**：任何认证改写 l' 的安全义务与 l 逐项相等，任务回报的泛化不改变安全界；(iv) **交互单调性**：IGC/DSG/VIC/EIA 只能增加义务、加宽信念、缩短超时或转入澄清/保守动作，不存在升险路径；(v) PCE-IG 在 k_p+k_c+k_v 内终止于 {承诺, 绕行, L2, 安全停}。

## 2. 关键算法伪代码

### IP-139 SMH（语义世界假设集 + 可信集最坏风险）

```python
def credible_set(beta, r, mass=1 - ALPHA_MAP):
    # 以最小质量原则取可信世界集；共形残差可校准覆盖
    order = sorted(beta.worlds, key=lambda w: -beta.weight[w])
    Wc, acc = [], 0.0
    for w in order:
        Wc.append(w); acc += beta.weight[w]
        if acc >= mass: break
    return restrict_to_corridor(Wc, r)          # 只保留与走廊相交的假设

def trajectory_risk(pi, Wc):
    # 对可信集取最坏，显式禁止 argmax 坍缩
    return max(collision_prob(pi, w) for w in Wc)

def commit_ok(pi, Wc, delta_coll, anchor):
    return trajectory_risk(pi, Wc) <= delta_coll and anchor_ok(pi, anchor)
```

### IP-140 SCM（单向膨胀裕度与限速）

```python
def semantic_margin(M, r, Wc, v):
    m_geo = v*TAU_REACT + v*v/(2*A_WC) + EPS_GEO          # 不含任何语义量
    d_sem = (K_H*normalized_entropy(M.label[r])
             + K_T*staleness(r)/TTL
             + K_D*disagreement(Wc, r))                    # 三项均 >= 0
    return m_geo + d_sem, v_max*exp(-GAMMA*d_sem)          # 语义只加宽/降速

def monotonicity_guard(m_new, m_geo, m_old):
    if m_new < m_geo: raise Violation('semantics_shrank_floor')
    if m_new < m_old and not new_observation_since(m_old):
        raise Violation('decay_without_evidence')          # 与 CARL R1 同源
    return m_new
```

### IP-141 EGA（外生几何锚，未知即占用）

```python
def anchor_envelope(x, v, obstacles, mu_floor):
    a_wc = mu_floor * g                                   # 站点最坏，不用逐区估计
    m_geo = v*TAU_REACT + v*v/(2*a_wc) + EPS_GEO
    U = conservative_occupancy(obstacles, unknown='occupied')  # 未知一律占用
    inflate = minkowski_sum(U, ball(m_geo))               # 几何膨胀
    return keep_out(inflate)                              # 不进包络之外

def anchor_ok(pi, anchor):
    return all(anchor_envelope(x_t, v_t, occ_t, MU_FLOOR).contains(x_t)
               for x_t, v_t, occ_t in rollout(pi))
```

### IP-142 CARL（认知强制 + 信息保全型避让）

```python
def collision_aware_replan(x, M, traj, Wc, budget):
    for r in forward_corridor(traj):                      # R1: 认知强制
        if disagreement(Wc, r) > THETA_DIS or age(r) > TTL:
            if budget.b_sem_left <= 0:
                traj = inflate_without_new_info(traj, r)  # 无预算 → 不降膨胀
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SMH | O(\|𝕎^α\|·N_cell) / 重规划 | O(\|𝕎\|·N_cell) | 真世界覆盖 ≥1−α_map；参数化禁用 argmax 安全判定（A41） |
| SCM | O(N_cell) | O(N_cell) | `Δ_sem≥0` 且对熵/陈旧/分歧单调不降、语义不缩 `m_geo`（A42） |
| EGA | O(N_cell·log N_cell) 占用膨胀 | O(N_cell) | 未知视为占用、`μ_floor/τ_react` 为站点最坏界（A43） |
| CARL | O(\|走廊\|·\|可行避让\|·N_rollout) | O(\|走廊\|) | 无观测不降膨胀；避让不牺牲可观测性（A44） |
| SCG-S/J_c | O(\|π\|·\|𝕎^α\|) | O(\|π\|) | `EV-semantic` 永不足以为不可逆/高速作保 |
| SPCE | O(\|CP\|·(b_sem+\|𝕎^α\|)·C_plan) | O(\|𝕎\|+N_cell) | 每点 `b_sem` 终止、四态完备 |

**正确性定理（Semantic-Conditioned Collision Soundness, SCCS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 假设覆盖：真世界 `w*∈𝕎_t^α` 概率 ≥1−α_map，且在声明的分布漂移条件（材质/光照/季节/人群密度）内成立，漂移超界即触发锚模式；**(A42)** 裕度单调：`Δ_sem≥0` 且对熵、陈旧度、假设分歧单调不降，任何语义置信不得使 `m_t<m_geo`；**(A43)** 锚健全：`μ_floor`、`τ_react` 为站点级最坏界，未知空间按占用处理；**(A44)** 闭环可观测：CARL 的每条降膨胀路径之前必须有新观测，或由回退裕度支付。则：

1. **几何地板（不依赖语义正确性）**：存在一个退路模式（anchor-only），其碰撞概率 ≤δ_anchor，且与 `β_t`、`𝕎_t^α`、任何标签无关。即使 `w*∉𝕎_t^α`，锚仍把碰撞风险压在 δ_anchor。
2. **语义单向性（无升险通道）**：`∂v_cap/∂Δ_sem≤0`、`∂m/∂uncertainty≥0`，且 `EV-semantic` 只可支持 L0；语义变好至多把裕度降到 `m_geo`、把速度升到 `v_max` 的锚上限，不能越过锚。故语义假置信心不构成升险通道。
3. **闭环有界（反自我锁定）**：CARL R1 使 `Δ_sem` 的每次下调都对应一次观测或回退裕度，R2 使避让不减少对不确定区域的观测，故不存在"越避越瞎、越瞎越敢"的无界正反馈；SPCE 在每点 `b_sem` 内终止于 `{承诺, 改道, L0 爬行, 协商, 安全停}`。
4. **部署界**（对检查点与假设取联合界）：

```
P_safe ≥ 1 − Σ_cp [ δ_coll·1(有可信集) + α_map·1(无锚) + δ_anchor·1(退锚) ]
             − P(锚假设被违反) − P(共享图导致的相关失准) − P(陈旧未检出)
```

关键：**可信集给"最坏世界"，锚给"不需要世界"**（前者的失效被后者的几何保守兜住）；**语义只能踩刹车**（`Δ_sem` 单向，`EV-semantic` 仅 L0）；**闭环强制观测**（不确定性不能被时间或避让"做小"）；三者把"地图正确性"从安全前提降级为效率变量。

## 6. 本轮最大风险

**一句话**：本轮把碰撞安全的最终退路押在"外生几何锚"上，但锚之所以外生，只是因为它不经过语义图——它仍押在站点级 `μ_floor`、平地假设与"没有突然闯入的快速体"上，而这些恰是"语料里没有的世界"最容易击穿的东西；更致命的是，若云端共享语义地图让所有机器人的可信集以同一方式出错，`α_map` 覆盖证书会静默失效，锚便成了唯一、却从未被真正检验的退路——必须让锚的每条假设在线可证伪（制动/滑移/入侵自检），并坚持"共享地图只是先验、永远不是证据"。
