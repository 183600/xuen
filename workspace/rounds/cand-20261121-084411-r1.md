# 第 2 轮（新灵感循环第 2 轮；本轮灵感：「抗干扰」×「电池管理」）

> **基线**：上一轮 MetricVoiceGauge-NCD-HUTDH-v17（定义 657–686；引理 137–142；实验 E691–E710）。
> 本轮纪律：**能量是证书、裕度是账本、预留退出是底线**。不推倒 v17：v17 的 CLP/S2C/HCG/PSV/APS/AMC、v16 的 BTS/TRM/WBC/CSC/NCS/MCA/WCB、v15 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v14 的 SCD/DSD/DCA/EDC、v13 的 AIO/RTIC/CPD/DGC/DDL/RTCR、v12 的 USG/TGC/BAA/GAGP/UC、v11 的 HAS/HCC/HATD/HDT、v10 的 NGE/DSL/CC/CWM/CAE/NCP、v9 的 AC/MW/ID、v8 的 DA/SPR/Cal 与历轮不变式全部保留。六个新组件——BECE（电池包络证书估计器）、DLPC（双账本计划认证器）、MLO（裕度账本观测器）、AIRG（带证书守卫的主动抗扰）、TPG（退化感知功率调度器）、SAM（预留防火墙/安全退出管理器）——一律以**中立元接入 v17 语言—行为层之上**，失效即严格退回 v17（引理 148），再沿 v17→v16→v15→…→v6 退化链退回。本轮只做三件事：把"抗干扰"改写为**可观测的裕度记账与退出预留**，把"电池管理"改写为**带不确定区间的能量/功率包络证书**，把"实时安全"改写为**双账本前缀可行 + 任意前缀可退出**。

## 0. 直觉与动机

**灵感 1（抗干扰 → 干扰不是要消灭的噪声，而是从"证书裕度"里扣款的支出）**
直觉：传统抗扰（H∞、ADRC、扰动观测器）追求把干扰压到零，或把闭环做硬；但 v16 的节点证书（Pre/Run/Post）本来就自带裕度。干扰的真实作用往往不是"让系统立刻坏"，而是**悄悄花掉裕度**：传感器噪声、接触推力、通信干扰、对抗性观测扰动，每一样都在消耗 Post 条件的余量。核心创新：**裕度账本观测器（Margin Ledger Observer, MLO）**——用扰动观测器残差 `r_t`、新颖性（v17 的 OOD/词表漂移）与计划缝应力构造"支出" `c_t`，维护带恢复项的裕度余额 `M_t`；`M_t` 低于阈值就降级。关键反直觉点：**最强的抗干扰不是把干扰压到零，而是让干扰可观测、可记账、可预留退出**——一个"知道自己在被推、并提前留好退路"的控制器，比一个"很硬但不知道自己快撑不住"的控制器更安全。冗余若不可观测只会带来相关失效；可观测性才是抗扰的第一性资源。

**灵感 2（电池管理 → 证书也会没电：能量是有健康度、会自我衰减的状态，不是一次性预算）**
直觉：BMS 的核心不是"读一个电量百分比"，而是同时估计 SoC（当前可用）、SoH（长期健康）、功率包络（温度/老化决定的瞬时上限），并在这些估计都不确定时仍保证不越界。机器人安全证书恰好缺这一层：v17 默认"证书是真的、能量是无限的"。核心创新：**电池包络证书估计器（Battery Envelope Certificate Estimator, BECE）+ 双账本计划认证器（Dual-Ledger Plan Certifier, DLPC）**。每个行为节点带能量画像（期望能耗、峰值功率、**从该节点安全退出的能耗**、退化代价）；计划证书在 v17 的 `PC` 上追加 `EC`：不仅总能耗够，而且**每个前缀**都满足"已花 + 退出预留 + 应急预留 ≤ 可用能量下界"，且每个前缀的峰值功率 ≤ 当前 `P_max(β)`。关键反直觉点：**省电不等于慢**——慢动作可能因更长的保持力矩、更长的暴露时间和更差的散热而更费电、更危险；能量最优往往是"快爆发 + 休息"的内点，而不是"全程最慢"。更反直觉的是：**安全证书本身需要"充电"**——重校准（v17 的 HCG 滑动窗、锚集扩充）要花时间和能量，必须被当作可调度资源预留，而不是免费维护。

**灵感 3（两者统一 → 双账本、两时间尺度、一个退出底线）**
直觉：能量账本慢（单调消耗 + 充电恢复，分钟级），裕度账本快（干扰涨落 + 恢复，毫秒–秒级），但它们在**退化阶梯**上耦合：低电量迫使温和动作，温和动作延长暴露，暴露消耗裕度，裕度不足又迫使更保守……核心创新：**退化感知功率调度器（TPG）+ 预留防火墙（SAM）**，把 `(能量等级, 干扰等级)` 映射到一条**全序**运行模式阶梯：NORMAL → CONSERVE → PREFIX → SAFE_PARK → DOCK → V16_DEFAULT → V15_FALLBACK，并证明该映射对两个账本的偏序都单调（引理 144）。**预留防火墙**是不变式而非策略：任何时刻 `E_remaining ≥ A(t) + R_emerg`，其中 `A(t)` 是到达安全集/充电桩的退出能耗上界；违反即立刻执行退出，绝不"再试一步"。关键反直觉点：**安全不是"计划成功"，而是"任何前缀都能体面地失败"**——v17 的前缀截断只管"少做"，v18 的前缀退出保证"随时能停"。

**三者如何统一**
v17 回答"哪些语言计划能被编译为证书节点序列"（`Exec_v17`），v18 回答"在这些计划里，哪些在**当前电池包络与干扰裕度下、每个前缀都还付得起退出代价**"（`Exec_v18`）。BECE 提供带区间的能量/功率包络（感知），DLPC 把 `PC` 扩成双账本证书 `DC=PC∧EC∧IC`（裁决），MLO+AIRG 提供干扰的可观测与在证书域内的主动抑制（抗扰），TPG 做两时间尺度调度（节拍），SAM 守退出底线（兜底）。共享状态 `ζ_ei=(β_t, BE_t, M_t, e_level, i_level, abort_set, reserve, mode_ei, drift_ei)`。五者不是补丁，而是"估计—认证—抗扰—调度—退出"的闭环：**BECE 回答"还剩多少、能出多大力"，DLPC 回答"这个计划每个前缀是否都付得起且退得出"，MLO 回答"干扰花掉了多少裕度"，AIRG 回答"能否在证书域内把干扰压回 D_n"，TPG 回答"这一帧用哪一档功率/模式"，SAM 回答"还来不来得及停"**。

## 1. 研究问题（轮次升级版）

- **Q1（能量包络的可证性）**：在 SoC/SoH/温度都不可直接观测时，如何给出 `E_lo`/`P_max` 的有限样本或区间保证？BECE 的估计误差如何传播到 `EC` 而不被点估计吞掉？充电/回桩是否必须作为认证锚？
- **Q2（前缀退出可行性）**：`A_k`（从任意前缀安全退出的能耗）如何定义与估计？高维状态下"最近安全集"是否唯一？退出路径本身是否需要 v17 缝证书与 v18 能量证书（递归）？
- **Q3（干扰的可观测与记账）**：扰动观测器残差如何映射为裕度支出而不误报？新颖性与物理干扰是否共用同一本账？`M_t` 的恢复项如何避免"账面安全、实际已坏"？
- **Q4（双账本耦合与死螺旋）**：能量—干扰耦合下如何保证调度单调而不进入"低电→温和→长暴露→更耗→更低电"的死螺旋？TPG 阈值如何与 v17 的 TTL/α 联合校准？多计划竞争时如何把能量价值并入 `V(π)`？

## 2. 设计原则（P28–P30 基础上新增 P31–P33）

**P31 能量前缀可行律（Prefix-Abort Energy Feasibility）**
`DC(π)` 要求对每个前缀 `k`：`E_k + A_k + R_emerg ≤ E_lo(t)`，且前缀峰值功率 `≤ P_max(β_t)`、估计温升 `≤ T_max`。只允许用**能量下界**与**能耗上界**，禁止用点估计；任一前缀不满足即整计划不授权。计划价值必须扣除退化代价，不得用"额定电量"替代"当前可用下界"。

**P32 干扰记账律（Interference Is Debit, Not Rewrite）**
干扰只能从裕度账本扣除，不能直接改写节点证书；AIRG 只能在节点认证的扰动集 `D_n` 内抑制干扰（把实际残差压回 `D_n`），残差离开 `D_n` 即**失效该节点证书**而不是放宽它。MLO 的支出必须是保守上界（`c_t ≥` 真实裕度损失），恢复项必须有可证来源（校准、静止、可观测性提升），不得凭空"回血"。

**P33 预留退出律（Reserve Firewall）**
`E_remaining ≥ A(t) + R_emerg` 是**不变式**，不是优化目标。任何调度、仲裁、新计划、语言修复都不得消耗应急预留；退出动作必须是已认证锚（回桩、安全姿态或 v16 默认策略），不得临时生成；退出路径本身也要通过缝证书与能量前缀检查（递归一层，见定义 691）。

## 3. 与基线的接口（如何退化）

- BECE 失效（电池模型/传感器损坏）⇒ 用最保守固定包络（额定 `P_max`、`E_lo =` 当前 SoC 下界 − 安全折扣）——**等价 v17（更保守）**；
- DLPC 失效（能量画像缺失）⇒ 退回 v17 的 `PC`（无能量/干扰约束）——**等价 v17**；
- MLO 失效（观测器不可用）⇒ 干扰按认证 `D_n` 的静态最坏界计——**等价 v17（更保守）**；
- AIRG 失效（抑制器饱和）⇒ 不主动抑制，只用静态鲁棒裕度——**等价 v17**；
- TPG 失效（调度器异常）⇒ 固定 NORMAL 模式 + v17 四级新鲜度阶梯——**等价 v17**；
- SAM 失效（预留防火墙不可用）⇒ 禁止一切非单步计划（只允许可立即停的节点）——**等价 v17（单步执行）**；
- 六者全失效 ⇒ MetricVoiceGauge-NCD-HUTDH-v17，再沿 v17→v16→…→v6 退化链退回；
- **安全继承**：BECE 只收紧包络，DLPC 只加约束，MLO 只扣裕度，AIRG 只在 `D_n` 内抑制，TPG 只降级，SAM 只退出；六端口互不相交，均不能新增授权或放宽任何阈值；`Exec_v18⊆Exec_v17` 由引理 148 保证。

## 4. 预期贡献

1. **抗干扰的记账转向**：把"抗扰=压噪声"改写为"可观测裕度记账 + 退出预留"，给出 MLO 的支出/恢复模型与"失效即降级"语义，使抗扰强度第一次可以与证书裕度直接对账；
2. **电池包络证书**：把"电量百分比"改写为带不确定区间的能量/功率包络证书，首次让机器人安全证书显式依赖 SoC/SoH/温度，并给出点估计不可用的反例；
3. **前缀退出能量不变式**：提出 `E_k + A_k + R_emerg ≤ E_lo`，把 v17 的"前缀截断（少做）"升级为"任意前缀可体面退出（能停）"；
4. **能量—干扰死螺旋**：发现并形式化双账本耦合导致的全局不可行，给出全序单调阶梯与预留防火墙来阻断；
5. **证书需要充电**：把重校准/锚扩充当作可调度资源预留，给出长期运行的吞吐—校准可行性条件；
6. **双账本统一**：用 `Exec_v18⊆Exec_v17` 把能量、干扰、语言、行为、路线、动力学、实时、蒸馏全解耦；E711–E730 覆盖包络覆盖、前缀退出、抗扰记账、死螺旋、充电调度、端到端与消融。

## 5. 本轮最大风险

**一句话**：能量账本与裕度账本各自都可证可行，但它们的耦合项（低电→温和→长暴露→高耗/高干扰）可能让系统在"每个账本单独看都安全"的区间里滑向"退出预留本身也付不起"的状态——即双账本局部可行、耦合全局不可行，而 SAM 的退出能耗 `A(t)` 又依赖正在退化的 SoH 估计。

# IP-415 Battery Envelope Certificate Estimator：带区间的电池包络
class BatteryEnvelopeEstimator:
    def __init__(self, soc_model, soh_model, thermal_model, alpha_e=0.05):
        self.soc = soc_model          # 区间观测器：z_lo <= z <= z_hi
        self.soh = soh_model          # 容量/内阻的慢变区间估计
        self.thermal = thermal_model
        self.alpha_e = alpha_e

    def estimate(self, z_meas, i_meas, T_meas, dt):
        z_lo, z_hi = self.soc.interval_update(z_meas, i_meas, dt)
        h_lo, h_hi = self.soh.interval_update(z_meas, i_meas, T_meas, dt)
        T_hi = self.thermal.upper_temperature(T_meas, i_meas, dt)
        E_lo = z_lo * self.soh.capacity_lower(h_lo, T_hi)     # 只用下界
        E_hi = z_hi * self.soh.capacity_upper(h_hi, T_meas)
        P_max = self.power_envelope(z_lo, h_lo, T_hi)          # 随 SoC/SoH/温度收缩
        return BE(E_lo, E_hi, P_max, -P_max, T_max, self.alpha_e)


# IP-416 Dual-Ledger Plan Certifier：PC ∧ EC ∧ IC
class DualLedgerPlanCertifier:
    def __init__(self, pc_verifier, bece, mlo, safe_set, dock, r_emerg, margin_sc):
        self.pc = pc_verifier         # v17 的 PC（NC + 缝 + 门控）
        self.bece = bece
        self.mlo = mlo
        self.safe, self.dock = safe_set, dock
        self.r_emerg = r_emerg
        self.margin_sc = margin_sc

    def abort_energy(self, node, beta):
        # 退出路径本身必须是认证锚序列；取到 Safe ∪ Dock 的最小上界
        cands = [self.safe.upper_cost(node.Post, beta),
                 self.dock.upper_cost(node.Post, beta)]
        return min(c for c in cands if c is not None)

    def energy_certificate(self, nodes, beta):
        E = 0.0
        peak = 0.0
        for k, n in enumerate(nodes):
            e_n, p_n, _, d_n = n.energy_profile(beta)     # EP_n
            E += e_n + d_n
            peak = max(peak, p_n)
            A_k = self.abort_energy(n, beta)              # 前缀退出预留
            if E + A_k + self.r_emerg > beta.E_lo:
                return False, k, ('ENERGY', E + A_k + self.r_emerg)
            if peak > beta.P_max:
                return False, k, ('POWER', peak)
        return True, None, None

    def interference_certificate(self, nodes, r_t, M_t):
        for i, n in enumerate(nodes):
            if r_t not in n.D:                            # 残差离开 D_n
                return False, i, ('DISTURBANCE', i)
            if M_t < n.m_min:                             # 裕度账本见底
                return False, i, ('MARGIN', M_t)
        return True, None, None

    def certify(self, pi, nodes, beta, r_t, M_t):
        ok_pc, seam_i, _ = self.pc.verify(nodes)          # v17 PSV 预验
        if not ok_pc:
            return False, seam_i, 'PC'
        ok_e, e_i, why = self.energy_certificate(nodes, beta)
        if not ok_e:
            return False, e_i, why
        ok_i, i_i, why = self.interference_certificate(nodes, r_t, M_t)
        if not ok_i:
            return False, i_i, why
        return True, None, 'DC'


# IP-417 Margin Ledger Observer：干扰 → 裕度支出/恢复
class MarginLedgerObserver:
    def __init__(self, M0, M_cap, M_min, w=(1.0, 0.5, 0.5)):
        self.M, self.cap, self.min = M0, M_cap, M_min
        self.w = w

    def debit(self, r_t, D_n, novelty, seam_stress):
        over = max(0.0, distance(r_t, D_n))                # 只对越界部分扣款
        return self.w[0]*over + self.w[1]*novelty + self.w[2]*seam_stress

    def recover(self, calibrated, still, observability_gain):
        # 恢复必须有可证来源：重校准、静止、观测性提升
        if calibrated:
            return 1.0
        if still and observability_gain:
            return 0.25
        return 0.0

    def update(self, r_t, D_n, novelty, seam_stress, recovery):
        c = self.debit(r_t, D_n, novelty, seam_stress)
        self.M = min(self.cap, max(0.0, self.M - c + recovery))
        return self.M, c


# IP-418 Active Interference Rejection Guard：只在 D_n 内抗扰
class ActiveInterferenceRejectionGuard:
    def __init__(self, dob, certified_sets):
        self.dob = dob                    # 扰动观测器 / ADRC 残差估计
        self.D = certified_sets          # 每个节点的认证扰动集

    def reject(self, x, node):
        d_hat = self.dob.estimate(x)
        u_ff = self.dob.compensate(d_hat)  # 前馈补偿，降低实际残差
        r = self.dob.residual(x, u_ff)
        if r not in self.D[node]:
            return None, ('CERT_INVALID', node, r)   # 不扩证书，直接失效
        return u_ff, ('OK', r)


# IP-419 Thermal–Power Governor：双账本 → 全序模式阶梯
class ThermalPowerGovernor:
    LADDER = ['NORMAL', 'CONSERVE', 'PREFIX', 'SAFE_PARK',
              'DOCK', 'V16_DEFAULT', 'V15_FALLBACK']

    def __init__(self, thresholds_e, thresholds_i):
        self.te, self.ti = thresholds_e, thresholds_i

    def level_e(self, E_lo, A, r_emerg):
        slack = E_lo - (A + r_emerg)
        return clip(int(slack / self.te), 0, 3)     # 越高越充裕

    def level_i(self, M):
        return clip(int(M / self.ti), 0, 3)

    def mode(self, e_level, i_level, drift):
        if drift:
            return 'V15_FALLBACK'
        # 对 (e_level,i_level) 的偏序单调：任一等级下降，模式只会更保守
        score = min(e_level, i_level)
        if score >= 3:
            return 'NORMAL'
        if score == 2:
            return 'CONSERVE'
        if score == 1:
            return 'PREFIX'
        return 'SAFE_PARK'          # 0 级先退到安全姿态，再由 SAM 决定是否 DOCK


# IP-420 Safe-Abort Manager：预留防火墙 + 安全退出
class SafeAbortManager:
    def __init__(self, safe_set, dock, r_emerg, abort_paths):
        self.safe, self.dock = safe_set, dock
        self.r_emerg = r_emerg
        self.paths = abort_paths      # 预认证的退出锚序列（含缝证书）

    def firewall_ok(self, E_remaining, A_t):
        return E_remaining >= A_t + self.r_emerg

    def enforce(self, E_remaining, A_t, mode):
        if not self.firewall_ok(E_remaining, A_t):
            return 'ABORT_NOW', self.best_abort_path(A_t)
        if mode == 'SAFE_PARK':
            return 'SAFE_PARK', self.best_abort_path(A_t)
        if mode == 'DOCK':
            return 'DOCK', self.dock_path()
        return 'CONTINUE', None

    def best_abort_path(self, A_t):
        return min(self.paths, key=lambda p: p.upper_cost)


# 主闭环集成：MetricVoiceGauge-NCD-HUTDH-v18（能量—干扰层）
def metricvoicegauge_round_18_energy_interference(M, s, obs, ...):

    results = middleware.run_cycle(runners={...}, ctx=ctx)

    # ---- BECE：带区间电池包络（慢时间尺度，低频更新）----
    beta = ctx.bece.estimate(obs.z, obs.i, obs.T, ctx.dt)
    E_remaining = beta.E_lo - ctx.energy_spent_since_estimate

    # ---- MLO：干扰支出/恢复（快时间尺度，每帧）----
    M_t, c_t = ctx.mlo.update(obs.r, obs.D_n, obs.novelty,
                              ctx.psv.seam_stress(), ctx.recovery_signal())

    # ---- v17 计划候选 + 双账本认证 ----
    ctx.aps.poll(now(), obs, m_star, h_max, ctx.clp, ctx.hcg, ctx.s2c, ctx.psv)
    plan_nodes, rung = ctx.aps.current(now(), drift)

    if plan_nodes is not None:
        ok, idx, why = ctx.dlpc.certify(ctx.last_plan, plan_nodes, beta, obs.r, M_t)
        if not ok:
            plan_nodes = None                      # 不授权；保留旧缓存但不执行
            ctx.tpg.force_at_most('PREFIX')        # 双账本失败只降不升

    # ---- AIRG：只在 D_n 内主动抗扰；越界即失效 ----
    u_ff, airg_state = (0.0, ('OK', None))
    if plan_nodes is not None:
        u_ff, airg_state = ctx.airg.reject(obs, plan_nodes[0])
        if airg_state[0] != 'OK':
            plan_nodes = None

    # ---- TPG：能量/干扰等级 → 模式阶梯 ----
    A_t = ctx.dlpc.abort_energy(plan_nodes[-1], beta) if plan_nodes else ctx.sam.safe_cost(obs)
    e_level = ctx.tpg.level_e(beta.E_lo, A_t, ctx.sam.r_emerg)
    i_level = ctx.tpg.level_i(M_t)
    mode = ctx.tpg.mode(e_level, i_level, drift)

    # ---- SAM：预留防火墙优先于一切计划 ----
    sam_state, abort_path = ctx.sam.enforce(E_remaining, A_t, mode)
    if sam_state == 'ABORT_NOW':
        execute_abort(abort_path)
        return ctx.inherited_v17_path(ctx)

    # ---- 模式落地：FULL/PREFIX/CONSERVE 都只能在 DC 内截短 ----
    if mode in ('NORMAL', 'CONSERVE', 'PREFIX') and plan_nodes is not None:
        plan_nodes = ctx.tpg.apply(plan_nodes, mode)   # 只截短/降速，不拼接
    else:
        plan_nodes = None                              # v16 默认或退出路径

    action, c_low, c_up, fb, m_exec, h_exec = ctx.csc.schedule(
        x=obs, plan_nodes=plan_nodes,
        hw_state=hw_state, sw_cert=sw_cert, data_cov=data_cov, drift=drift
    )
    tau_cmd = ctx.wbc.compute_control(obs, task_spec=action) + u_ff
    execute(tau_cmd if h_exec > 0 else fb)

    # ---- 重校准作为可调度资源：预留 R_cal，避免"证书饿死" ----
    if ctx.cycle_idx % ctx.T_cal == 0:
        if E_remaining >= ctx.dlpc.abort_energy(plan_nodes[-1], beta) + ctx.R_cal:
            ctx.hcg.recalibrate(ctx.amc.store.recent(k))
            ctx.mlo.recover(calibrated=True)

    C, spatial_cert, claims, metrics, rewards = M.inherited_v17_path(ctx)
    return C, spatial_cert, claims, metrics, rewards

## 2. 推导

**引理 143（能量前缀退出安全）** 设 `DC(π)` 成立、预留防火墙 `RF` 全程成立，且 `A_k` 是退出能耗的严格上界，则对任意前缀 `k`，从第 `k` 个节点末端执行退出都能在剩余能量内到达 `Safe∪Dock`；能量耗尽只会导致活动性丧失，不会导致不安全状态。证明：由 `EC`，`E_lo ≥ E_k + A_k + R_emerg`。执行到前缀 `k` 已消耗至多 `E_k`（`E_k` 取上界），剩余 `E_remaining ≥ A_k + R_emerg`；退出路径能耗至多 `A_k`，故退出后仍保留 `R_emerg`。退出路径由 P33 规定为已认证锚序列，故 v17 引理 139 的缝证书仍覆盖退出全程；退出过程中若缝复验失败，v16 引理 131 的 Fallback 链继续兜底。对 `k` 归纳即得全程。∎ 推论：**能量安全是"前缀全称"而非"总量存在"——总量够但某个前缀退不出，计划仍不安全**。

**引理 144（双账本单调退化）** 定义偏序 `(e,i) ≼ (e',i') ⇔ e≤e' ∧ i≤i'`，若 `μ` 对两个分量均单调不增（分量越低模式越保守），且各模式只移除可执行项、不新增，则 `Exec_v18⊆Exec_v17`，且阶梯无拼接、无跨级。证明：`DC` 在 `PC` 上追加合取项，故 `DC⇒PC`，即 `Exec_v18⊆Exec_v17`；`μ` 的单调性保证等级下降只能走向更保守的模式；`CONSERVE/PREFIX` 只降速/截短（v17 引理 140），`SAFE_PARK/DOCK/V16/V15` 只切换为已认证兜底路径，均不新增动作。∎ 推论：**低电或高干扰永远不会"解锁"任何新动作，只会让机器人做得更少、更慢、更早停**。

**引理 145（裕度账本的保守健全性）** 设 (a) 扰动残差 `r_t∈D_n` 时节点 Post 裕度成立；(b) 记账支出是真实裕度损失的保守上界（`c_t≥Δmargin_t`）；(c) 恢复项 `ρ_t` 有可证来源且不超过真实恢复量。则 `M_t≤` 真实剩余裕度，且 `M_t≥M_min` 时执行节点不会越出 Post。证明：对 `M_t−M_true,t` 归纳；初值 `M_0≤M_true,0`；每步 `M_t−M_true,t = (M_{t−1}−M_true,t−1) − (c_t−Δmargin_t) + (ρ_t−Δrecovery_t) ≤` 前值，因 `c_t≥Δmargin`、`ρ_t≤Δrecovery`。故 `M_t` 是真实裕度的下界；`M_t≥M_min` 蕴含真实裕度 `≥M_min>0`，Post 成立。∎ 推论：**MLO 的错误方向必须是"多扣少补"；任何"账面回血"若无观测性依据，引理立即失效**。

**引理 146（双账本非可加性与死螺旋）** 存在能量—干扰耦合系统，使得在某一时刻 `EC` 与 `IC` 分别成立，但 `DC` 不成立；且按"每个账本各自贪心"的调度会进入可行域单调收缩的死螺旋。构造：设慢模式 `s` 与快模式 `f`，慢模式功率较低但持续时间更长、保持力矩/散热开销更大，故总能耗 `E_s>E_f` 且暴露时间 `τ_s>τ_f`，裕度支出 `c_s=κτ_s>c_f=κτ_f`；又设 `P_max(β)` 随 SoC 下降而收缩。在高 SoC 时两模式均可行，单账本贪心因"慢模式峰值低"选 `s`；执行 `s` 使 SoC 下降、暴露变长，`P_max` 收缩到 `f` 不再可行，同时 `A(t)` 上升，最终 `E_remaining < A(t)+R_emerg`——此时 `EC`（用总量而非前缀退出）与 `IC`（用静态 `D_n` 而非账本）在早期均成立，却已无法安全退出。形式化地，可行速度集合在高 SoC 是区间 `[v_min,v_max]`，在低 SoC 退化为 `{v_min}`，而 `E(v)` 与 `c(v)` 在 `v_min` 处取极大——贪心下降方向与可行域收缩方向一致，构成正反馈。∎ 推论：**必须用联合证书 `DC` 与预留防火墙 `RF` 同时约束两个账本；分开优化会把系统推到"每个约束都刚好满足、合起来刚好退不出"的刀尖上**。

**引理 147（重校准的可调度性）** 设平均消耗率 `c̄`、平均充电/恢复率 `ḡ`、单次重校准能量成本 `R_cal`、周期 `T_cal`，则长期运行不耗尽应急预留的必要条件为 `ḡ ≥ c̄ + R_cal/T_cal`。证明：一个周期内净能量变化为 `(ḡ−c̄)T_cal − R_cal`；若为负，每周期净减，任何有限初始预留终将耗尽；由引理 143，耗尽后系统退化为活动性丧失（仍安全）。充分性需加上峰值功率与充电窗口约束，此处只证必要。∎ 推论：**"证书充电"不是免费维护——若不计入 `EC`，系统会在看似能量充足的账面上慢慢饿死校准能力**。

**引理 148（v18 安全继承）** 若 BECE 只输出保守包络、DLPC 只在 `PC` 上追加 `EC∧IC`、MLO 只扣裕度、AIRG 只在 `D_n` 内抑制且越界即失效、TPG 只降级、SAM 只退出，则对任意输入（含对抗输入）`Exec_v18⊆Exec_v17`，且 `|NewAuth|=0`。证明：每个组件都是对 v17 可执行集的过滤或对已认证兜底路径的切换；BECE 的保守性保证 `EC` 不会因估计乐观而放行未认证能量状态；AIRG 的补偿 `u_ff` 只在 `r∈D_n` 时施加，而 `D_n` 是节点证书已覆盖的扰动集，故不扩大证书域；SAM 的退出路径是预认证锚，不生成新动作。复合仍为子集。∎ 推论：**能量/干扰层的最坏失效模式仍是单向的——机器人更早停、更少做，而不是更危险**。

## 6. 已知风险与失效模式

1. **SoC/SoH 估计误差**：区间观测器若未覆盖老化/温度耦合，`E_lo` 可能乐观，导致 `EC` 假可行。缓解：区间观测器 + 保守折扣 + 周期性满充校准；任何乐观越界即回退固定包络。
2. **区间过度保守**：高维/强非线性下 `E_lo` 塌缩，计划通过率趋零，系统退化为 v17 默认。缓解：分温度/老化分区标定、自适应 `α_e`、活性监视。
3. **扰动不可观测**：某些干扰（慢漂移、未建模柔顺）落在观测器盲区，`r_t` 长期落在 `D_n` 内但真实裕度已被耗尽。缓解：加多源观测（力矩/视觉/电流）、注入微激励做可观测性检测、`M_t` 定期用独立探针校准。
4. **记账与真实裕度脱钩**：`c_t` 权重标定错误导致"账面安全、实际已坏"。缓解：引理 145 的保守方向硬约束（只许多扣）、离线对账、人工抽检。
5. **死螺旋（引理 146）**：低电→温和→长暴露→更耗→更低电。缓解：联合证书 `DC`、预留防火墙、快速回桩、禁止单账本贪心。
6. **退出路径本身不可行**：`A(t)` 估计乐观或退出路径被占用/阻塞。缓解：多条预认证退出路径、`A(t)` 取最坏上界、退出路径也做能量前缀检查。
7. **校准饿死（引理 147）**：长期任务中重校准被无限推迟。缓解：把 `R_cal` 计入 `EC`、事件触发、低活动窗口自动校准。
8. **热失控/功率骤降**：温度保护突然收紧 `P_max`，正在执行的计划瞬间不可行。缓解：热前馈、降 C-rate、热约束进 `EC`、提前降级。
9. **充电桩不可用/被占**：`Dock` 锚不可达导致退出无终点。缓解：多桩、备选安全集、`Safe` 永远可用。
10. **能量价值被博弈**：多计划仲裁中虚报低能耗以抢占执行权。缓解：能量画像由 BECE 独立核验、执行后对账、异常画像隔离。
11. **传感器攻击**：伪造 SoC 或扰动残差使系统误判。缓解：交叉校验（电压/电流/温度/里程）、签名、异常检测；安全继承保证最坏只损活动性。
12. **五重约束过度保守**：`PC∧EC∧IC∧HCG∧SAM` 叠加可能使接受率接近零。缓解：加权而非纯合取（除安全硬约束外）、分级阈值、活性报警与人工接管。

## 7. 本轮最大风险

**一句话**：能量账本与裕度账本各自都可证可行，但它们的耦合项（低电→温和→长暴露→高耗/高干扰）可能让系统在"每个账本单独看都安全"的区间里滑向"退出预留本身也付不起"的状态——即双账本局部可行、耦合全局不可行，而 SAM 的退出能耗 `A(t)` 又依赖正在退化的 SoH 估计。
