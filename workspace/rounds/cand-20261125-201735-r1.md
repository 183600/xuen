灵感驱动研究循环·新灵感三元组第 1 轮；本轮灵感：「模型量化」×「关节驱动」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–439（CESC/FSVC/IPAM/HPC-E+）；其上承 v22 的 HDL/ACSC/DCSC/HPC-E/CFC++、v21 的 SDC/CAC/DCL/GIC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 与 v19/v17 全部模块。**v20–v23 全部保留，一律不推倒。**
> **本轮纪律**：此前每一轮都在"数学世界"里签名——浮点模型、理想力矩、无限精度能量积分。本轮只补一个被所有轮次默认掉的缺口：**证书必须在整数硅片上算出、在真实关节上兑现**。两个灵感恰好是同一枚硬币的两面：**模型量化 = 计算的可实现性；关节驱动 = 执行的可实现性**。二者统一为 **物理实现层 (Physical Realization Layer, PRL)**，用一个 **实现裕度账本 (Realization Slack Ledger, RSL)** 把两类误差变成可扣减、可审计的"支出"，并顺手把驱动本身变成一路**独立感知模态**，去堵 v21 留下的最大风险（合规的缺席幻觉）。

## 0. 直觉与动机

### 灵感 1（模型量化 → 证书要由整数硅片签发，而不是由浮点假设背书）

**直觉**：v23 的 conformal 覆盖、CESC 的版本一致性，全部是在"浮点模型 + 浮点校准"上证明的；可真正部署的是 INT8/INT4 NPU、定点能量积分、整数共识投票。量化从来不只是"压一压显存"：它是一个**系统性的、与输入相关的确定性扰动**。把浮点证书原封不动搬上整数管线，等于拿一张写着别人名字的保单去理赔。最阴险的失效不是"量化掉点"，而是**证书在 README 里通过、覆盖已经静默失效**。

反直觉之处有两层：

1. **更低精度未必更不安全**。整数算术是 **bit-exact、可逐位重放**的，反而关掉了"浮点不确定性"这个审计黑洞——证书可以逐帧复算、逐位核对。真正危险的不是数值变小，而是**校准与部署不同管线**导致 exchangeability 被破坏。量化可以成为安全的盟友，前提是"为证书而量化"而非"为精度而量化"。
2. **离散分数会制造并列 (ties)，而确定性 tie-break 会吃掉覆盖**。conformal 的边际保证建立在分数的次序统计上；量化把连续分数压到格点，若部署时用确定性规则处理并列，最坏会损失"等于阈值那一档概率质量"的覆盖。**必须在校准后的同一整数管线上重新打分，并随机化 tie-break**，覆盖才真正迁移到硅片。

**严谨定义（部署算术可实现性）**：

- 量化映射 `Q_l(x)=clamp(round(x/Δ_l)+z_l, -2^{b_l-1}, 2^{b_l-1}-1)`，反量化 `D_l(n)=(n-z_l)Δ_l`；未饱和时 `|D_l(Q_l(x))-x| ≤ Δ_l/2`，饱和则置 `clamp_flag_l`。
- **组合误差界**：若第 `l` 层在认证输入盒 `X` 上对输入 `L_l`-Lipschitz，则
  `δ_out ≤ Σ_l A_l·Δ_l/2 + Σ_l A_l·δ_clamp_l`，其中放大因子 `A_l = Π_{k>l} L_k`。
  这一条把"哪一层该多给比特"说清楚了：**要被下游放大的层，误差更贵**。
- **证书保持量化 (certificate-preserving quantization)**：位宽分配不是最小化任务损失，而是
  `min Σ_l A_l Δ_l/2  s.t.  δ_out ≤ σ_alloc ∧ Σ_l b_l ≤ B`；对 `Δ_l ∝ 2^{-b_l}` 做拉格朗日可得闭式
  `b_l* ≈ clamp(log2(A_l/λ), b_min, b_max)`——**按放大因子成比例地分配比特**，λ 由位宽预算 `B` 二分确定。
- **量化后 conformal**：校准集必须在**已量化管线**上重新打分；阈值取第 `⌈(n+1)(1-α)⌉` 个次序统计，并对分数加 `U~Unif(-Δ_s/2, Δ_s/2)` 抖动（或对并列随机择一）。确定性 tie-break 的覆盖下界是 `1-α-P(S=q̂)`；随机化 tie-break 恢复到 `1-α`。
- **定点能量积分**：`E_Q` 以 LSB `Δ_E` 累加，`N` 步表示误差 `≤ NΔ_E/2`；采用 **checked/saturating** 加法，溢出置 `overflow_flag`——证书见 flag 即吊销，绝不 wrap-around。

**核心创新**：量化可实现性证书 **QRC (Quantization Realizability Certificate)**。

### 灵感 2（关节驱动 → 刹车权限是会被用光的守恒预算，饱和是吊销而非降级）

**直觉**：证书里"规划了一条力矩轨迹"这句话，隐含假设电机能瞬时、精确地给出这个力矩。真实关节有 `τ_max(q̇,T,V)`，会随**温度与电池电压衰减**；还有 backlash、cogging、齿隙和跟踪误差。更要命的是：**你无法在需要刹车的那一刻"再多用一点力"**。权威不是想有就有，它是此刻就已被决定的守恒预算。因此"饱和"不是可以靠 PID 补救的跟踪问题，而是一个**证书事件**：必须吊销、进入已验证的 SafeStop，而不是"尽力而为"。

反直觉之处：**越柔顺（低刚度 / 高背驱）跟踪越差，但越安全、也越可观测**。柔顺降低接触力与伤害严重度，同时让外部力矩在关节电流或弹性体形变上更加可见——**柔顺–可观测–安全三位一体**，代价是灵巧度与活性。这把"关节驱动"从单纯的风险源，翻转为一种可主动调度的安全资源。

**严谨定义（关节权威可实现性）**：

- 降额力矩上限 `τ_max,j(q̇,T,V)=τ_nom,j·κ_T(T)·κ_V(V)`，`κ_T,κ_V∈(0,1]` 单调递减。
- 单关节权威 `A_j(t)=τ_max,j-|τ_req,j(t)|`；**权威预算约束** `A_j ≥ A_brake,j + A_disturb,j + A_margin,j`。
- **权威可行核 (authority viability kernel)** `W = {x : ∃u(·), |u_j(t)|≤τ_max,j ∀t, x(t)∈X_safe, 制动距离(x)≤d_safe}`；`W` 对降额动力学**前向不变**。准入门只允许进入"从该状态用**降额**力矩一定刹得住"的 `W`——把"尽力刹车"换成"只进入刹得住的状态"。
- 执行误差合成 `|e_act| ≤ η_track + η_backlash + η_cog`，作为账本的一笔支出。

**核心创新**：关节权威证书 **JAC (Joint Actuation Authority Certificate)**。

### 灵感 3（驱动即感知 → 电机既是权威风险，也是独立的在场证据）

**直觉**：v21 的缺席证书 CAC 押在一个经验假设 `κ_c`（检测器召回下界）上，这是已知的最大风险——"合规地、可审计地撞上没被看见的人"。而关节其实是一个被忽略的、**物理上独立**的传感器：比较"指令力矩 / 模型预测力矩"与"实测力矩"（电流环或串联弹性体形变），**残差本身就是外部力矩估计**。任何非预期外部力矩都构造性地意味着"那里有东西 / 有人"。于是同一路信号可以三用：

- 残差超阈 → **低门槛**触发急停（fail-safe：假接触只损失活性）；
- 若此刻正要签发 AbsCert，则**迫使缺席证书拒发并翻转为"有人"**——用一路独立召回冗余，正面堵 v21 的最大风险；
- 该通道的失效模式（模型误差、传感器漂移、热漂移）与视觉/手势**不同源**，因此可作为 CFC 共识的**新独立模态**，结构性增强模态多样性。

**严谨定义（驱动-感知对偶）**：广义动量观测器 `p=M(q)q̇`，
`r=K_O(p-∫(τ_m+C^Tq̇-g+r)dt)`；在模型误差界 `η_model` 下，`‖r‖>η_model+3σ` 判为接触。它给出**独立于视觉的在场证据**，记为 PDC（本体感知扰动证书）。

### 三者如何统一（实现裕度账本）

两类灵感其实问的是同一个问题：**数学证书里还剩多少裕度，能支付多少"实现误差"？** 定义统一账本：

`σ_cert(π) = M_float(π) - M_min(π)`（证书的浮点裕度），
`δ_total = δ_quant + δ_track(η) + δ_model + δ_fixed + δ_act_uncertainty`，
**准入门只接受 `δ_total ≤ σ_cert` 的计划**。任何一项无界（饱和、溢出、观测器失效）⇒ **吊销而非透支**。

统一门 **HPC-R = HPC-E+ ∧ QRC ∧ JAC ∧ RSL**（PDC 作为 CAC 的独立证据源并入 CAC 的判据）。于是
`Exec_v24 = Exec_v23 ∩ Fil_q ∩ Fil_act ∩ Fil_rsl ⊆ Exec_v23`。
一句话概括本轮：**量化把"算得出"变成可审计，关节把"刹得住"变成可预算，而电机顺带把"有没有人"变成多一路证据。**

## 1. 研究问题（轮次升级版）

- **Q12（量化误差的可证界与 conformal 迁移）**：`δ_quant` 该用区间/仿射的**最坏界**（用于能量、权威等安全临界量）还是校准集上的**统计界**（用于感知分数）？两者如何在同一账本里拼接而不重复计费？post-quant conformal 在何种并列结构与 tie-break 下严格保持 `1-α`？证书保持的位宽闭式分配 `b_l*=log2(A_l/λ)` 在非线性/注意力层上的 `A_l` 如何取得既可用又不过松的估计？

- **Q13（权威可行核与降额）**：如何在热/电压降额、backlash、cogging 下计算并在线维护 `W`，既保守又不至于让活性坍缩？饱和吊销如何与 v22 的分层过滤器链、v20 的 CFC 时序协调而不产生"刹车—重启"振荡？跟踪误差 `η` 与 v21 的 `margin_col`、v20 的 `τ_consensus` 如何在同一账本里叠加而不重复计费？

- **Q14（驱动即感知的独立性与门槛）**：如何论证力矩残差通道相对视觉/手势的**失效独立性**足以计入 CFC 模态数（模型误差、传感器漂移、热漂移是否同源）？接触阈值如何设为"假接触只损失活性、真接触必吊销 AbsCert"的非对称门槛？柔顺度如何作为可调变量，在三目标（跟踪精度、可观测性、接触严重度）之间权衡？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P45）

**P43 部署算术可实现律（Deployment Arithmetic Realizability）**
每个证书要么由部署整数管线签发，要么附带"量化可实现性证明"；量化误差是账本上的显式支出。conformal 必须在量化后同管线重校准并随机化 tie-break；安全临界累加器（能量、权威）用 checked/saturating 定点，溢出即吊销。任何从浮点管线继承的证书，未附 `δ_quant ≤ σ_alloc` 证明一律不下发。故 `Exec_v24 ⊆ Exec_v23`。

**P44 关节权威可实现律（Joint Authority Realizability）**
只允许进入降额力矩下的权威可行核 `W`；沿已验证的制动轨迹，要求力矩永不越过降额 `τ_max`（越过即吊销，不是降级）；权威不可按需生成，只能作为守恒预算被预算与保留。故 `Exec_v24` 只收缩不扩张。

**P45 驱动-感知对偶律（Actuation-Sensing Duality）**
同一批关节既是权威风险，也是独立感知通道：外部力矩残差超阈 ⇒ 低门槛急停 + 否决 AbsCert + 计入独立模态。更高柔顺以跟踪精度换取更低接触严重度与更高可观测性；该权衡由 DCL 按规范状态调度，且任何调度都不得越过 P44 的权威边界。

## 3. 与基线的接口（如何退化）

- **QRC 失效**（位宽不满足 / 溢出 / 校准不足）⇒ 安全临界路径退回已验证的浮点或高精度基线子集（更慢、更保守）⇒ 子集；
- **JAC 失效**（降额未知 / 观测器故障）⇒ 只允许准静态低速、假设最小权威 ⇒ 子集；
- **PDC 失效** ⇒ 缺席证书失去驱动冗余，退回 v21 仅手势翻转 ⇒ 更保守；
- **定点溢出 / 力矩饱和** ⇒ 立即吊销 + SafeStop，绝不 wrap-around、绝不"尽力而为"；
- **全部失效** ⇒ 回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`（延续引理 162 的单调链）。

**安全继承方向**：量化只允许"证书保持"位宽、权威只允许"刹得住"状态、感知只允许"有证据"的在场判断；任一失效都向更保守方向单调退化。QRC/JAC/PDC 均以事件方式接入 v17 APS 新鲜度阶梯：降额、溢出、接触事件携带时间戳，控制路径只做 O(1) 查表与阈值比较。

## 4. 预期贡献

1. **量化可实现性证书（QRC）**：首次要求证书在整数硅片上"兑现"，把量化从精度问题升级为可审计的误差预算问题；
2. **证书保持位宽分配**：给出按 Lipschitz 放大因子的闭式分配 `b_l*`，把"为证书而量化"变成可求解的约束优化；
3. **量化后 conformal 的并列分析**：给出离散分数下确定性/随机化 tie-break 的覆盖上下界，明确覆盖迁移到部署管线的充分条件；
4. **关节权威可行核（JAC）**：把"尽力刹车"改写为"只进入刹得住的状态"，并把饱和定义为吊销事件；
5. **驱动即感知（PDC）**：用关节力矩残差构造物理独立的在场/接触证据，否决 AbsCert 并充当 CFC 的独立模态，正面加固 v21 最脆弱处；
6. **实现裕度账本 + HPC-R**：`δ_total ≤ σ_cert` 的统一准入与 `Exec_v24 ⊆ Exec_v23` 闭环，使"物理安全—规范安全—云边可部署"链条补齐"硬件可实现"这一环。

## 5. 本轮最大风险

**一句话**：量化误差包络与关节权威预算都是"出厂 / 室温 / 满电"下的**静态标定**，而量化误差会随输入离群相关放大、力矩上限会随温度与电池电压持续衰减——两者可能在最需要刹车的那一刻同时吃光纸面裕度，形成"证书仍然成立、物理裕度已经归零"的**静默失效**。

# ============================================================
# IP-440/441 QRC + QuantizedConformal — 证书保持量化与量化后校准
# ============================================================
def allocate_bits(A: list[float], B: int, b_min: int = 4, b_max: int = 8) -> list[int]:
    """按放大因子 A_l 成比例分配位宽：b_l* = clamp(log2(A_l / λ))。
    对 λ 二分，使 Σb_l 逼近预算 B（误差贡献 A_l·2^{-b_l} 的水填充解）。"""
    lo, hi = 1e-12, max(A) + 1.0
    best = [b_max] * len(A)
    for _ in range(60):
        lam = 0.5 * (lo + hi)
        b = [min(b_max, max(b_min, int(round(math.log2(max(a, 1e-12) / lam)))))
             for a in A]
        if sum(b) > B:
            lo = lam
        else:
            best, hi = b, lam
    return best


def quant_error_envelope(A: list[float], deltas: list[float],
                         clamp_terms: list[float]) -> float:
    """δ_out ≤ Σ A_l·Δ_l/2 + Σ A_l·δ_clamp_l（最坏界，用于安全临界量）。"""
    return sum(a * d / 2.0 for a, d in zip(A, deltas)) \
         + sum(a * c for a, c in zip(A, clamp_terms))


@dataclass
class QuantizationRealizabilityCertificate:
    deltas: list[float]          # 每层 Δ_l
    bits: list[int]              # 每层 b_l（由 allocate_bits 得出）
    A: list[float]               # 下游放大因子 A_l
    sigma_alloc: float           # 预留给量化的裕度份额
    clamp_terms: list[float]     # 饱和项（通常置 0，除非 clamp_flag 触发）

    def worst_case_delta(self) -> float:
        return quant_error_envelope(self.A, self.deltas, self.clamp_terms)

    def certifies(self, max_bits: int, clamp_flags: list[bool]) -> bool:
        if any(clamp_flags):
            return False                           # 饱和 → 最坏界失效 → 吊销
        if sum(self.bits) > max_bits:
            return False                           # 超预算
        return self.worst_case_delta() <= self.sigma_alloc


class QuantizedConformal:
    """在已量化管线上重新校准；随机化 tie-break 保持边际覆盖。"""
    def __init__(self, alpha: float, score_lsb: float):
        self.alpha = alpha
        self.ds = score_lsb
        self.q_hat = math.inf
        self.scores: list[float] = []

    def calibrate(self, deployed_scores: list[float]) -> None:
        # 关键：deployed_scores 必须来自同一整数推理管线，不得用浮点分数
        self.scores = sorted(deployed_scores)
        n = len(self.scores)
        if n < 30:
            raise ValueError("校准集不足")
        k = math.ceil((n + 1) * (1.0 - self.alpha))
        self.q_hat = self.scores[min(k, n) - 1]

    def dither(self, s: float, rng) -> float:
        # 随机化 tie-break：U(-Δ_s/2, +Δ_s/2)
        return s + rng.uniform(-self.ds / 2.0, self.ds / 2.0)

    def coverage_floor_if_deterministic(self) -> float:
        # 确定性 tie-break 的最坏覆盖：1-α-P(S=q̂)；此处用并列质量近似
        tie_mass = (self.scores.count(self.q_hat) / max(len(self.scores), 1))
        return 1.0 - self.alpha - tie_mass


# ============================================================
# IP-442 Checked Fixed-Point Energy Ledger — 定点能量积分
# ============================================================
class CheckedFixedPointEnergy:
    def __init__(self, lsb: float, max_abs: float):
        self.lsb = lsb
        self.max_abs = max_abs
        self.e = 0                  # 整数累加器（单位：LSB）
        self.steps = 0
        self.overflow = False

    def add_power(self, p: float, dt: float) -> None:
        inc = int(round(p * dt / self.lsb))
        new = self.e + inc
        if abs(new) * self.lsb > self.max_abs:
            self.overflow = True              # 饱和并吊销，绝不 wrap-around
            self.e = int(math.copysign(self.max_abs / self.lsb, inc))
        else:
            self.e = new
        self.steps += 1

    def energy(self) -> float:
        return self.e * self.lsb

    def error_bound(self) -> float:
        return self.steps * self.lsb / 2.0    # 每步 ≤ LSB/2

    def valid(self, margin: float) -> bool:
        return (not self.overflow) and (self.error_bound() <= margin)


# ============================================================
# IP-443 JAC — 降额力矩与权威可行核
# ============================================================
def derated_tau_max(tau_nom, T, V, T0, V0, kT_min, kV_min, a, p):
    kT = min(1.0, max(kT_min, 1.0 - a * (T - T0)))
    kV = min(1.0, max(kV_min, (V / V0) ** p))
    return tau_nom * kT * kV


class JointActuationAuthorityCertificate:
    def __init__(self, tau_nom, A_brake, A_disturb, A_margin,
                 T0=25.0, V0=48.0, kT_min=0.6, kV_min=0.7, a=0.004, p=1.0):
        self.tau_nom, self.A_brake = tau_nom, A_brake
        self.A_disturb, self.A_margin = A_disturb, A_margin
        self.T0, self.V0, self.kT_min, self.kV_min, self.a, self.p = \
            T0, V0, kT_min, kV_min, a, p
        self.saturated = False

    def tau_max(self, qd, T, V):
        return [derated_tau_max(tn, T, V, self.T0, self.V0,
                                self.kT_min, self.kV_min, self.a, self.p)
                for tn in self.tau_nom]

    def authority(self, tau_req, tau_max):
        return [tmax - abs(t) for t, tmax in zip(tau_req, tau_max)]

    def authority_ok(self, tau_req, tau_max) -> bool:
        A = self.authority(tau_req, tau_max)
        ok = all(a >= ab + ad + am
                 for a, ab, ad, am in zip(A, self.A_brake,
                                          self.A_disturb, self.A_margin))
        # 饱和是吊销事件：需求力矩越过降额上限即失败
        if any(abs(t) > tmax for t, tmax in zip(tau_req, tau_max)):
            self.saturated = True
            return False
        return ok

    def in_viability_kernel(self, q, qd, braking_rollout) -> bool:
        """W 的在线校验：用降额动力学前向模拟制动，必须停在 X_safe 内
        且制动距离 ≤ d_safe；否则拒绝进入该状态。"""
        traj = braking_rollout(q, qd, self.tau_max(qd, *self._env()))
        return traj.stops_within_safe_set and traj.distance <= self.d_safe

    def _env(self):
        return self._T, self._V


# ============================================================
# IP-444 PDC — 广义动量观测器（外部力矩=在场证据）
# ============================================================
class MomentumDisturbanceObserver:
    def __init__(self, K_O, eta_model, sigma, k_sigma=3.0):
        self.K_O = K_O
        self.eta_model = eta_model
        self.sigma = sigma
        self.k_sigma = k_sigma
        self.r = 0.0
        self.p_prev = None

    def update(self, M, q, qd, tau_m, C, g, dt) -> float:
        p = M @ qd
        if self.p_prev is None:
            self.p_prev = p
        integrand = tau_m + C.T @ qd - g + self.r
        self.r = self.r + self.K_O * (p - self.p_prev - integrand * dt)
        self.p_prev = p
        return self.r

    def contact(self) -> bool:
        return float(np.linalg.norm(self.r)) > \
               self.eta_model + self.k_sigma * self.sigma

# IP-445 RSL + HPC-R — 实现裕度账本与统一准入
# ============================================================
@dataclass
class RealizationSlackLedger:
    sigma_cert: float
    d_quant: float
    d_track: float
    d_model: float
    d_fixed: float
    d_act_unc: float = 0.0

    def total(self) -> float:
        return (self.d_quant + self.d_track + self.d_model
                + self.d_fixed + self.d_act_unc)

    def admits(self) -> bool:
        return self.total() <= self.sigma_cert


@dataclass
class HPCR:
    hpc_e_plus: 'HPCEPlus'
    qrc: QuantizationRealizabilityCertificate
    qconf: QuantizedConformal
    jac: JointActuationAuthorityCertificate
    pdc: MomentumDisturbanceObserver
    cac: 'CoverageAbsenceCertificate'
    d_safe: float

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               tau_req, tau_max, q, qd, M, C, g, tau_m, dt, rng,
               braking_rollout) -> bool:
        # 1) 继承 v23 的四证门
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2) 量化可实现性
        if not self.qrc.certifies(max_bits=self.max_bits,
                                  clamp_flags=self.clamp_flags):
            return False
        if not (self.qconf.dither(self.qconf.quantize_score(plan.score), rng)
                <= self.qconf.q_hat + self.qconf.ds / 2.0):
            return False
        # 3) 关节权威 + 可行核
        if not self.jac.authority_ok(tau_req, tau_max):
            return False
        if not self.jac.in_viability_kernel(q, qd, braking_rollout):
            return False
        # 4) 驱动即感知：接触残差否决缺席证书
        self.pdc.update(M, q, qd, tau_m, C, g, dt)
        if self.pdc.contact():
            self.cac.revoke_absence()          # 翻转为"有人在场"
            return False                       # 低门槛急停
        # 5) 实现裕度账本
        ledger = RealizationSlackLedger(
            sigma_cert=plan.sigma_cert,
            d_quant=self.qrc.worst_case_delta(),
            d_track=sum(self.jac.track_error_bound(tau_req)),
            d_model=self.pdc.eta_model,
            d_fixed=self.fixed_point.error_bound(),
        )
        if not ledger.admits():
            return False
        return True

# ============================================================
class CertificateFederatedConsensusQuantized(
        CertificateFederatedConsensusPlusPlusHierarchical):
    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            count_ok = len(votes) >= self.N - self.F
            modalities = {v.modality for v in votes.values()}
            # 只有观测器健康的 actuation 票才计入独立模态
            if any(v.modality == "actuation" and not v.observer_healthy
                   for v in votes.values()):
                modalities.discard("actuation")
            modality_ok = len(modalities) >= self.M_MIN_MODALITIES
            # 量化后整数票按 bit-exact 摘要去重，避免"并列分数"伪造额外票
            dedup = {v.integer_digest: v for v in votes.values()}
            count_ok = count_ok and len(dedup) == len(votes)
            if count_ok and modality_ok and self._check_layer_consistency(votes):
                results[key] = self._majority_with_outlier_filter(votes)
            else:
                results[key] = "CI"
        return results

## 3. 正确性论证

### 引理 5（量化误差放大与位宽守恒）
**陈述**：设每层未饱和，局部 Lipschitz 常数为 `L_l`，则组合输出误差满足 `δ_out ≤ Σ_l A_l·Δ_l/2`，其中 `A_l=Π_{k>l}L_k`；若 Σ b_l ≤ B 且 `δ_out ≤ σ_alloc`，则 QRC 可签发。

**证明**：
1. 单层舍入误差 ≤ Δ_l/2（round-to-nearest，未饱和）。
2. 下游 L_{l+1..L} 层的复合映射对输入是 `Π_{k>l}L_k`-Lipschitz，故第 l 层误差被放大 `A_l` 倍后进入输出。
3. 线性叠加（三角不等式）得 `δ_out ≤ Σ_l A_lΔ_l/2`。饱和时 `clamp_flag` 置位，由 `certifies` 直接拒签。
4. 位宽分配最小化 `Σ A_l 2^{-b_l}`（Δ_l∝2^{-b_l}）subject to Σb_l≤B；KKT 条件给出 `A_l 2^{-b_l} = λ`，即 `b_l*=log2(A_l/λ)`，与算法一致。∎

### 引理 6（量化后 conformal 的覆盖迁移）
**陈述**：若校准分数与部署分数取自**同一整数管线**且样本可交换，则随机化 tie-break 的边际覆盖 `= 1-α`（有限样本下 `≥1-α`）；确定性 tie-break 的覆盖下界为 `1-α-P(S=q̂)`。

**证明**：
1. 标准 split-conformal 在可交换样本上，取 `⌈(n+1)(1-α)⌉` 次序统计给出边际覆盖 `≥1-α`（Vovk et al. 2005）。
2. 若部署分数来自不同管线（浮点校准→整数部署），校准与测试分数不再可交换，保证不迁移；故必须在量化后重校准。
3. 离散分数产生并列质量 `P(S=q̂)`；确定性规则最多只能把并列中的一部分纳入预测集，最坏损失该档全部质量，覆盖 `≥1-α-P(S=q̂)`。
4. 加 `U~Unif(-Δ_s/2,Δ_s/2)` 抖动后分数连续且保持对称，并列被打散，边际覆盖恢复到 `≥1-α`（随机化只增加方差、不降低均值覆盖）。∎

### 引理 7（权威可行核的前向不变性与饱和吊销）
**陈述**：若计划只进入 `W` 内状态，且沿已验证制动轨迹 `|τ_req,j(t)|≤τ_max,j(t)`，则认证停止一定可实现；饱和永不发生于认证轨迹上，故 `Exec_v24` 不因"刹不住"而失效。

**证明**：
1. `W` 定义为存在一条满足 `|u_j|≤τ_max,j` 且终止于 `X_safe` 的控制轨迹的初始状态集，构造上即为降额动力学的可控不变集。
2. 由前向不变性，`x(t)∈W ⇒ x(t+dt)∈W`，故从 `W` 内任意状态出发的认证制动始终留在 `X_safe` 且满足力矩界。
3. 若某在线指令 `|τ_req|>τ_max`，由 `authority_ok` 置 `saturated=True` 并拒证——这是吊销，不是把 `Exec` 扩张到未验证区，故单调性保持。∎

### 引理 8（实现裕度账本与单调退化链）
**陈述**：若对每个被准入计划有 `δ_total ≤ σ_cert` 且所有安全临界累加器 `overflow=False`，则 `Exec_v24 ⊆ Exec_v23`；任一失效（溢出/饱和/观测器失效/校准不足）只会减少账本裕度或吊销证书，故子集关系对任意故障组合保持。

**证明**：
1. HPC-R 是 HPC-E+ 与三个新过滤器的合取，任何一项不满足即拒证，故 `Exec_v24 ⊆ Exec_v23`。
2. 量化只允许"证书保持"位宽并把 `δ_quant` 计入支出；权威只允许 `W` 内且非饱和；感知只在有独立证据时否决缺席——三者都只会增加约束，不会新增可达计划。
3. 溢出/饱和/观测器故障对应 `overflow=True`、`saturated=True` 或无 `AbsCert`，均导向吊销或更保守默认；对故障取交集，单调性保持。
4. 全失效时三个过滤器退化为恒假或恒保守，`Exec_v24` 退回 `Exec_v23`，再由引理 162 得完整链。∎

### 定理（HPC-R 五证准入的必要—充分性）
**陈述**：对任意计划 π，`HPCR.admits(π)=True` ⟺ π 同时满足：(1) v23 四证（物理接地∧云边同步∧少样本覆盖∧IP 完备）；(2) 量化可实现（`δ_quant≤σ_alloc` 且无饱和/溢出）；(3) 关节权威可实现（`W` 内且 `A_j≥A_brake+A_disturb+A_margin`）；(4) 无未解释的外部力矩（`‖r‖≤η_model+3σ`）；(5) 实现裕度账本不透支（`δ_total≤σ_cert`）。

**证明**：直接由 `HPCR.admits` 的五个连言分支与引理 5–8 可得。必要性：任一分支假即拒证，对应一类"纸面成立、物理不成立"的风险未被封堵。充分性：五分支全真时，量化/权威/感知/裕度四类误差均被显式界定并可审计，执行集落在 `Exec_v23` 内且物理可实现。∎

## 4. 已知风险与缓解

| 编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R1 | 静态标定 vs 物理漂移：量化误差随输入离群相关放大、`τ_max` 随温度/电压衰减，二者在刹车时刻共振 | 最高 | 1) `δ_quant` 在线用滑动校准集重估并取分位上界；2) 温度/电压传感器实时降额，账本每步重算；3) 预留 `δ_act_unc` 并定期再认证 | 极端热失控 + 分布外输入同时发生时，静态包络可能已失真 |
| R2 | 量化后覆盖未真正迁移（tie-break 实现错误或校准集不足） | 高 | 1) 强制同管线重校准；2) 随机化抖动；3) CI 中做覆盖经验检验（目标 `≥1-α-1e-3`） | 小样本 + 高并列分数下经验覆盖波动 |
| R3 | 权威可行核过于保守，导致活性坍缩（尤其重载/高温） | 高 | 1) 分层退化（v22 HDL 战略→战术→操作）；2) 柔顺度调度换取可观测性；3) `W` 的保守度可审计地调参 | 制动核与能量核交集可能过小 |
| R4 | PDC 假接触（模型误差/温漂）造成频繁误停 | 中 | 1) 非对称阈值（真接触低门槛、假接触仅损活性）；2) 模型误差在线辨识但须证书约束；3) 与视觉/手势交叉确认再否决 AbsCert | 强耦合负载下模型误差可能持续超阈 |
| R5 | "bit-exact" 假设被硬件打破（FTZ、融合乘加、NPU 非确定调度） | 中 | 1) 安全临界路径禁用非确定 kernel；2) 黄金向量逐位回归；3) 整数票摘要审计回放 | 厂商固件级舍入差异难以完全枚举 |

## 6. 本轮最大风险（最终确认）

**一句话**：量化误差包络与关节权威预算都是"出厂 / 室温 / 满电"下的**静态标定**，而量化误差会随输入离群相关放大、力矩上限会随温度与电池电压持续衰减——两者可能在最需要刹车的那一刻同时吃光纸面裕度，形成"证书仍然成立、物理裕度已经归零"的**静默失效**。
