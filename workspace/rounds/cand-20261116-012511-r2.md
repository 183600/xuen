# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「视觉感知」×「可解释性」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**视觉接地 + 自解释证书 + 单向可解释**。两个灵感分别治理 v9 的两种债：**证据债**（块证书是标量前瞻，未与真实视觉证据空间对齐，β 是离线常数，信任域靠 20 帧标量 Δ_dom，天然滞后）与**解释债**（ID 只做模块级贡献归因，不解释单次证书/中止的因果依据，人无法复核"凭什么敢走这一步"）。关键安全转向：**可解释性只允许收缩信任域、绝不允许扩张信任域**（P14 单向律），使解释器的不可靠性只能带来"更保守"，不能带来"更冒险"。

## 0. 直觉与动机

**灵感 1（视觉感知 → 视觉证据场与共形块证书）**
直觉：v9 的块证书本质是"前向模型说未来 K 步间隙够"——一个无法指着图像复核的标量预言；β 是离线拍定的常数，信任域靠 20 帧标量 Δ_dom 判断。视觉感知提供的恰是**空间上可定位、可复核**的证据。核心创新：**视觉证据场（VisualEvidenceField, VEF）**——把 RGB-D、实例分割、光流融合成局部栅格上的间隙下界 ℓ̂(x) 与异方差不确定半径 σ̂(x)，再用**共形预测**把"下界"变成带分布无关覆盖保证的集合值证书：证书不再说"我说够"，而说"这些体素的下界都 ≥ d_safe，覆盖失败率 ≤ α"。这把 v9 的常数 β 换成随场景自适应、可标定、可复核的视觉证据。

**灵感 2（可解释性 → 解释作为单向传感器 + 反事实中止解释）**
直觉：可解释性通常被当作"事后给人看"的装饰；但在 v9 的风险里，真正缺的是一个**比 DA-ML 更快、更贴因果**的"模型要错了"的先行信号。若前向模型在某种视觉概念组合上没见过，概念激活会在 1–2 帧内异常，而 DA-ML 要 20 帧才滑出警报。核心创新 1：**解释一致性监测器（ExplanationConsistencyMonitor, ECM）**——概念瓶颈编码器输出人可命名的概念 h_t，比较"概念应许的证书"与"实际证书"、以及概念模式相对标定集的新颖度，得到 Ψ_t，作为领先指标提前收缩 K_eff。核心创新 2：**反事实中止解释器（CounterfactualAbortExplainer, CAE）**——中止时给出最小视觉反事实编辑 δ*（"若区域 R 不是玻璃 / 若该体素可通行，本块即可认证"），既经语音通道向操作员解释，又把困难反例回灌共形标定集。**关键纪律**：Ψ_t 只能否决、不能放行（P14）——解释错了最多变慢，不会变险。

## 1. 研究问题（轮次升级版）

- **Q4（视觉证据的覆盖）**：如何用共形预测给出空间证据场的分布无关间隙下界，并在 K 步块上取得**同时覆盖**而非逐点覆盖？机器人持续运行必然破坏交换性，覆盖如何优雅退化并被检测，而不是静默失效？
- **Q5（解释作为先行信号）**：概念新颖度 Ψ_t 与真实前向误差之间是否存在单调关系？在什么条件下解释一致性是前向误差的领先指标、领先多少帧？若该关系不成立，单向门控是否仍能保证不劣于 v9？
- **Q6（单向可解释的安全边界）**：如何形式化"解释只收缩信任域"，使 v10 在**任意解释器错误**下 safety ≥ v9、代价仅为效率？反事实解释的忠实度如何被**审计**而不是被相信？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P14）

**P13 视觉接地证据律（Visually-Grounded Evidence, VEF）**
块证书必须由空间局部化的视觉证据支撑：存在证据场 E_t 与共形下界 L(x)，使证书有效 ⇔ min_{x∈执行管(a^{1:K})} L(x) ≥ d_safe + d_brake(v_K) 且 γ̂_grasp=valid。标量前向模型不再独占证书权威；VEF 失效时 L_min ← ĝ_min−β（退回 v9 定义 533 的标量证书）。证据不确定度过宽时允许**主动再观察**（改变视角/头部朝向）作为可选增强，失败即用缓存证据、不改变 K_eff。

**P14 可解释性单向律（One-Way Interpretability, ECM/CAE）**
解释信号只能收缩信任域：
```
trust_ok(t) = trust_ok^{v9}(t) ∧ (Ψ_t ≤ τ_Ψ)
K_eff(t)    = min( K_eff^{v9}(t), K_eff^{expl}(t) )
```
禁止任何"解释一致 ⇒ 放行/延长块"的正向授权；K_eff^{expl} 只随 Ψ_t 单调不增。解释器失效 ⇒ Ψ_t≡0 / 无解释 ⇒ 严格退回 v9。

## 3. 与基线的接口（如何退化）
- VEF 失效（深度不可用 / 分割超时）⇒ 用 v9 前向模型标量证书（β 固定），等价 v9；
- ECM 失效（概念编码器超时 / 冻结）⇒ Ψ_t≡0，trust 门控退化为 v9，等价 v9；
- CAE 失效 ⇒ 中止照常执行、无文字解释，等价 v9；
- 主动再观察（AEA）失效 ⇒ 用当前缓存证据，K_eff 不因它改变，等价 v9；
- VEF+ECM 同时失效 ⇒ 完整 v9；再沿 v9 契约链退回 v8/v7/v6，无行为漂移。

## 4. 预期贡献

1. **视觉接地共形证书**：把块证书从"标量预言 + 常数 β"升级为"空间证据场 + 分布无关覆盖"，并给出块级同时覆盖构造（避开逐点 Bonferroni 过保守）；
2. **解释即单向传感器**：P14 使可解释性首次可作为安全关键信号而不必假设其忠实——解释错误只付效率代价，最坏安全性由 v9 下界托底；
3. **反事实中止解释**：可审计的中止理由 + 困难反例回灌共形标定，形成"解释 → 标定 → 覆盖"闭环，并复用 MetricVoiceGauge 的语音通道把解释说给操作员听；
4. **E571–E590**：覆盖共形覆盖、块级同时覆盖、领先时延、单向 Pareto、反事实忠实度审计、视觉失效（玻璃/镜面/暗光/遮挡）、操作员信任与端到端任务。

## 5. 本轮最大风险

**一句话**：解释一致性可能**根本不是**前向误差的传感器——玻璃/镜面这类"视觉上熟悉、物理上陌生"的场景里 Ψ_t 可能很低而证书已经错了；此时单向门控不会触发，系统退化回 v9 的滞后风险，却额外制造了"系统能自我解释"的虚假安全感。

## 1. 符号体系增量（定义 540–547）

| 符号 | 含义 |

| E_t: X → (ℓ̂, σ̂, a, r) | 视觉证据场：间隙估计、异方差不确定度、可通行性、语义风险 |
| L(x) = ℓ̂(x) − q·σ̂(x) | 共形间隙下界（定义 541） |
| q / q_block | 单点 / 块级共形分位数 |

| h_t ∈ [0,1]^C | 概念瓶颈激活：C 个人工命名概念 |
| R_t = (c_{1:k}, a_{1:k}, S_t) | 解释：top-k 概念、归因强度、空间支撑 |
| Ψ_t | 解释一致性分数（定义 544），越小越一致 |
| τ_Ψ | 一致性阈值（标定集 95% 分位） |
| δ*, R_viol, Δ_cert | 反事实最小编辑、违规区域、证书差（定义 546） |
| AEA | 主动证据获取（Active Evidence Acquisition，P13 可选增强） |

**新增定义 540（视觉证据场 VisualEvidenceField）** 局部证据栅格 E_t: X→(ℓ̂, σ̂, a, r)，X 为执行管内的空间单元（体素或极坐标栅格）。ℓ̂(x) 为沿管到最近障碍表面的间隙估计；σ̂(x) 由深度方差、分割置信、光流残差合成；a 为可通行性；r 为语义风险。VEF 在 10–15Hz 更新（GPU 侧），50Hz 守卫只读缓存快照，不进入 20ms 决策预算的关键路径。

**新增定义 541（共形间隙下界 ConformalClearanceBound）** 标定集 D_cal={(x_i, ℓ_i)}，非一致性分数 s_i=(ℓ̂_i−ℓ_i)/σ̂_i（σ̂>0）。取 α∈(0,1)，
```
q = Quantile_{⌈(n+1)(1−α)⌉/n}({s_i}),   L(x) = ℓ̂(x) − q·σ̂(x)
```
单点满足 P(ℓ(x) ≥ L(x)) ≥ 1−α（交换性下）。**块级同时覆盖**：以"整块/执行管"为可交换单位，令 S(block)=max_{x∈block} s(x)，用块级分位数 q_block，得 P(∀x∈block: ℓ(x)≥L(x)) ≥ 1−α，避免逐点 Bonferroni 的 K 倍保守。可选 **Mondrian 共形**：按场景/概念类别分层标定，改善条件覆盖。

**新增定义 542（视觉块证书 VisualChunkCertificate）**
```
L_min = min_{x∈管(a^{1:K})} L(x)
Ĉ_t^vis 有效 ⇔ L_min ≥ d_safe + d_brake(v_K) ∧ γ̂_grasp=valid ∧ Ψ_t ≤ τ_Ψ
```
与 v9 定义 533 的关系：v9 的 ĝ_min 是 L_min 的退化下界；VEF 失效时 L_min ← ĝ_min−β，逐位退回 v9。

**新增定义 543（概念瓶颈解释 ConceptBottleneckRationale）** 概念编码器 f_θ: I → h ∈ [0,1]^C，C 为人工命名概念（clear_floor / person / glass / occlusion / narrow_passage / unknown_object / reflective_surface / …）。解释 R_t=(c_{1:k}, a_{1:k}, S_t)：top-k 概念、归因强度（h_c 对 ℓ̂ 的梯度×输入或 Shapley 近似）、空间支撑 S_t⊆X。概念瓶颈使解释在**概念层**构造性忠实（预测确由 h 中介），牺牲部分精度换取可审计性。

**新增定义 544（解释一致性分数 ExplanationConsistency）**
```
Ψ_t = λ₁·N_t + λ₂·|Ĉ(h_t) − Ĉ_t^vis| / Δ_c + λ₃·(1 − IoU(S_t, S_t^viol))
```
其中 N_t 为概念模式相对 D_cal 的新颖度（kNN / Mahalanobis / 密度比），Ĉ(h_t) 为标定集上学习的"概念→证书"查表映射，S_t^viol 为证书判定的违规区域。λ_i 由标定集网格搜索使 Ψ 对留出误差的 AUC 最大；τ_Ψ 取标定集 95% 分位。

**新增定义 545（单向信任门控 OneWayTrustGate）**
```
trust_ok(t) = trust_ok^{v9}(t) ∧ (Ψ_t ≤ τ_Ψ)
K_eff^{expl}(t) = max(1, ⌊K_max·(1 − min(1, Ψ_t/τ_Ψ))⌋)
K_eff(t) = min( K_eff^{v9}(t), K_eff^{expl}(t) )
```
性质：∀t，K_eff^{v10}(t) ≤ K_eff^{v9}(t)；解释只能收缩，永不扩张。

**新增定义 546（反事实中止解释 CounterfactualAbortExplanation）**
中止时求
```
δ* = argmin_δ ‖δ‖  s.t.  Ĉ_t^vis(edit(I_t, δ)) 有效 ∧ δ ∈ D_phys
```
D_phys 为物理可实现编辑集（对象移除 / 小位移 / 视角改变）。输出 (δ*, R_viol, Δ_cert)；δ* 不回写现实，只作解释与标定数据（把"近似合规"反例并入 D_cal 困难集）。语音通道在安全停驻后 ≤200ms 播报。

**新增定义 547（单向可解释退化表 OneWayDegradationTable）**

| 模块 | 失效/中立语义 | 等价行为 |
|---|---|---|
| VEF | L_min ← ĝ_min−β（v9 标量证书） | v9 定义 533 |
| ECM | Ψ_t ≡ 0 ⇒ trust_ok = trust_ok^{v9} | v9 定义 539 |
| CAE | 无解释文本，中止逻辑不变 | v9 |
| AEA（主动再观察） | 用缓存 E_t，K_eff 不变 | v9 |

## 2. 形式化定义（要点与升级）

**定义 532/533（动作块 / 块证书）** 结构继承 v9；Ĉ_t 升级为视觉锚定的 Ĉ_t^vis=(L_min, γ̂_grasp, E_t, R_t^cert)；v9 标量 Ĉ_t 保留为 VEF 失效时的退化值。
**定义 539（有效块长门控）** 升级为 `K_eff = min(K_eff^{v9}, K_eff^{expl})`，见定义 545。
**升级定义 496（软证书六条件）** `δ_trigger = {σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t^vis valid ∧ Ψ_t≤τ_Ψ}`；任一条越界均触发 M₀ 硬检查。
**升级定义 531（软硬约束衔接）** 增加视觉直接证据：若 live depth 在管外邻近区域检出 L(x)<d_safe，立即切最近中止点 p*，不等块边界，也不等 Ψ_t。
**定义 493/495/521/524** 继承 v9 不变；SpatialCert 仍为硬不变式，VEF 是其"可选精化"，VEF 失效即回退 v9 SpatialCert。

## 3. 关键算法骨架

```python
class VisualEvidenceField:                      # IP-357
    def __init__(self, backbone, D_cal, alpha=0.05, d_safe=0.15, K_max=10):
        self.backbone, self.D_cal, self.alpha = backbone, D_cal, alpha
        self.d_safe, self.K_max = d_safe, K_max
        self.q_point, self.q_block = self._calibrate(D_cal)   # 定义 541

    def update(self, rgbd, seg, flow, pose):    # 10–15 Hz，GPU 侧
        l_hat, sigma, afford, risk = self.backbone(rgbd, seg, flow)
        return EvidenceMap(l_hat, sigma, afford, risk, stamp=pose.t)

    def _calibrate(self, D_cal):
        s = [(m.l_hat(x) - l) / m.sigma(x) for m, x, l in D_cal]
        q_point = quantile(s, 1 - self.alpha)
        q_block = quantile([max_block_score(b) for b in D_cal_blocks],
                           1 - self.alpha)                    # 块级同时覆盖
        return q_point, q_block

    def lower_bound(self, E, tube_cells, mode="block"):
        q = self.q_block if mode == "block" else self.q_point
        L = {x: E.l_hat[x] - q * E.sigma[x] for x in tube_cells}
        return L                                     # 逐单元下界

    def active_reobserve(self, E, tube_cells):       # AEA，可选
        widths = [E.sigma[x] for x in tube_cells]
        if max(widths) <= self.sigma_cap:
            return None                              # 不确定度可接受
        return ViewpointProposal(gain=self._info_gain(E, tube_cells))


class ConceptBottleneckEncoder:                 # ECM 的视觉前端
    def __call__(self, img):
        return self.f(img)                       # h ∈ [0,1]^C，人可命名概念


class ExplanationConsistencyMonitor:            # IP-358
    def __init__(self, encoder, concept_table, D_cal, tau_psi, lambdas):
        self.encoder, self.table = encoder, concept_table
        self.D_cal, self.tau_psi, self.lam = D_cal, tau_psi, lambdas

    def novelty(self, h):
        return self._knn_dist(h, self.D_cal) / self._scale     # N_t

    def score(self, img, cert_vis, viol_region):
        h = self.encoder(img)
        cert_from_concepts = self.table.predict(h)            # Ĉ(h_t)
        mismatch = abs(cert_from_concepts - cert_vis) / self.delta_c
        support = self._concept_support(h, img, viol_region)   # S_t
        sup_term = 1 - iou(support, viol_region)
        psi = (self.lam[0] * self.novelty(h)
               + self.lam[1] * mismatch + self.lam[2] * sup_term)
        return psi, Rationale(h, support)


class OneWayTrustGate:                          # 定义 545
    def __init__(self, K_max, tau_psi): self.K_max, self.tau_psi = K_max, tau_psi
    def apply(self, k_v9, psi):
        k_expl = max(1, int(self.K_max * (1 - min(1.0, psi / self.tau_psi))))
        return min(k_v9, k_expl)                 # 只收缩，不扩张


class CounterfactualAbortExplainer:             # IP-359
    def explain(self, I_t, E_t, viol_region, cert_vis):
        best = None
        for delta in self.edit_candidates(I_t, viol_region):   # 移除/位移/换视角
            if not self.is_physically_valid(delta):
                continue
            c2 = visual_certify(self.edit(I_t, delta), E_t)
            if c2.valid:
                cost = self.edit_cost(delta)                   # L1 / 语义最小
                if best is None or cost < best.cost:
                    best = (delta, c2)
        if best is None:
            return None                                        # 无解释；中止照旧
        return AbortExplanation(delta=best[0], region=viol_region,
                                gap=cert_vis - best[1])


# ---- 主闭环集成：MetricVoiceGauge-VEX ----
def metricvoicegauge_round_10(M, s, obs, audio_stream=None, ...):
    ctx = mw_default_ctx()
    # 感知侧契约（v9 不变）+ 新增 VEF/ECM 契约（GPU/旁路，超时即 v^⊥）
    results = middleware.run_cycle(runners={
        "DA_ML": lambda c: domain_adapter.update_and_measure(obs),
        "SPR":   lambda c: slam_risk.compute(M.slam_backend.get_latest_state()),
        "CAL_FI":lambda c: calib_fi.get_weights_kappa(),
        "VEF":   lambda c: vef.update(obs.rgbd, obs.seg, obs.flow, obs.pose),
        "ECM":   lambda c: ecm.evaluate(obs.rgb, ctx.cert_vis, ctx.viol_region),
        "OTL":   lambda c: online_learner.update_and_thresholds(c),
    }, ctx=ctx)
    E = results.get("VEF", ctx.last_evidence)              # VEF 失效→缓存
    psi = results.get("ECM", (0.0, None))[0]               # ECM 失效→Ψ≡0

    # v9 的 K_eff（定义 539）
    k_v9 = chunker.effective_K(ctx.delta_dom, ctx.tau_dom, ctx.trust_ok_v9)
    # 单向门控：解释只收缩（定义 545）
    k_eff = OneWayTrustGate(K_max, tau_psi).apply(k_v9, psi)

    if current_chunk is None or current_chunk.exhausted:
        # 视觉证据门控的块生成（VEF 失效→v9 标量证书）
        current_chunk = chunker.generate_chunk(
            ctx.state, ctx.delta_dom, ctx.tau_dom,
            trust_ok=(ctx.trust_ok_v9 and psi <= tau_psi),
            k_eff_override=k_eff, evidence=E)

    verdict, k_next = chunker.midchunk_guard(current_chunk, k_exec, live_obs)
    if verdict == "abort":
        current_chunk.execute_safe_stop_at(k_next)
        # 反事实解释（旁路，安全停驻后执行，不阻塞 50Hz）
        exp = cae.explain(obs.rgb, E, live_obs.viol_region, current_chunk.cert)
        if exp is not None:
            voice.speak(exp.to_natural_language(), deadline_ms=200)  # 复用 CVC 通道
            calib_buffer.add_hard_case(exp)                          # 回灌 D_cal
        current_chunk = None
    else:
        execute(current_chunk.actions[k_next])

    C, spatial_cert, claims, metrics, rewards = M.inherited_v8_path(ctx)
    distiller.step(cycle_idx, ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 4. 推导（引理 87–90 与命题 1）

**引理 87（共形视觉证书的覆盖）** 设标定样本与部署样本可交换、σ̂>0。(i) 单点下界满足 P(ℓ(x) ≥ L(x)) ≥ 1−α。(ii) 若以整块为可交换单位、分数 S(block)=max_{x∈block}s(x)，则 P(∀x∈block: ℓ(x) ≥ L(x)) ≥ 1−α。
证明：(i) 标准分裂共形，ℓ(x) ≥ ℓ̂(x)−s(x)σ̂(x) 且 P(s(x) ≤ q) ≥ 1−α。(ii) 把"块"视为单一样本，S 关于块内逐点分数保序取 max，故分位数事件 {S ≤ q_block} 蕴含块内所有点成立，概率下界同为 1−α。∎
**诚实边界**：α 是**边际**覆盖而非条件覆盖；长时运行交换性不成立，故不声称无条件保证，覆盖退化由引理 89 的检测与 E572/E573/E584 实测处理。

**引理 88（单向解释的弱支配 / Pareto 安全）** 假设 (A1) 相同状态与策略下，较短有效块长不增加最坏碰撞概率（以经认证的 v8 K=1 为参照）；(A2) 解释只作用于 trust 门控，不改策略、证书余量与动作集。则对**任意**解释器实现（含完全错误者），∀t：K_eff^{v10}(t) ≤ K_eff^{v9}(t) 且 trust_ok^{v10} ⇒ trust_ok^{v9}。故 v10 最坏安全不低于 v9，差异仅在必要时更保守地重规划；代价为假阳性不一致导致的效率损失，期望重规划增量 ≤ P(Ψ>τ | 证书有效)。
证明：由定义 545 取 min 与合取，两不等式逐点成立；再由 A1 得最坏碰撞概率单调不增。∎
**诚实边界**：A1 非普适（过短时域可能近视），但本架构重规划落回经认证的 v8 逐步模式，故以 v8 为安全下界成立；E576 用对抗性解释错误直接检验该弱支配。

**引理 89（领先指标假设，可检验）** 设 (A3) 概念误差单调性：‖F̂−F‖∞ ≤ g(Ψ_t)，g 单调不减且 g(0)≤β。则 Ψ_t > g^{-1}(β) ⇒ v9 块证书失效，ECM 的收缩是正确的。ECM 仅依赖视觉特征，响应时延 w_Ψ≈1–2 帧；DA-ML 滑窗 W_DA=20 帧。A3 成立时，失效证书的暴露窗口从 W_DA 收缩到 w_Ψ。
**关键立场**：A3 **不被假设为真**。E574 检验 Ψ 与留出前向误差的秩相关（预注册 ρ≥0.6），E575 测领先帧数；若 A3 不成立，引理 88 仍保证不劣于 v9，仅失去效率收益——这是本设计把"解释不可靠"从安全性问题降级为性能问题的核心。

**引理 90（绕回退化 / 中立元）** 按表 547 注入：VEF 失效 ⇒ L_min=ĝ_min−β，逐位等于 v9 定义 533；ECM 失效 ⇒ Ψ≡0，定义 545 退化为 v9 定义 539；CAE 失效 ⇒ 中止逻辑不含解释，逐位等于 v9；AEA 失效 ⇒ 缓存证据，等价 v9。故 v10 在任意子模块失效下逐位退回 v9，再沿 v9 契约链退回 v8/v7/v6，无行为漂移。∎

**命题 1（反事实解释可审计而非忠实）** CAE 输出的**有效性**可构造验证（在 edit(I,δ*) 上重跑证书必然有效）；但**忠实度**（δ* 是否真是中止的因果原因）与**最小性**只能经验审计，不能由构造保证。故 CAE 输出禁止参与任何放行决策，仅用于人机解释、日志审计与标定集扩充。∎（这是"可解释性不可信"的工程姿态，而非数学定理。）
