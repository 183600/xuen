# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「语音识别」×「对比实验」）

> 第 54 轮把技能组合推进为「动作空间剖面 + 云边映射 + 动作-鲁棒性联合证书」。本轮换两条看似外围、实则直击根部的线索：**语音识别**（指令不是干净符号，而是带后验的噪声观测）与**对比实验**（结论不是来自组件叠加，而必须来自可归因的配对反事实）。核心矛盾：H22：语音识别把任务意图压成 N-best 假设，若错误假设落在动作空间上“看似可行”的另一技能，则第 54 轮的动作 `compat/cover` 检查会给出**虚假通过**；H23：大量消融实验以非配对、单种子、择优汇报的方式进行，证书栈的“提升”可能只是**混杂因素与选择偏差**，从而无法证伪。

## 0. 直觉与动机

**灵感 1（语音是指令到动作空间的有损投影，必须升格为第一性观测通道）**
直觉：任务意图 `T` 先被说话人编码为声学信号，再被 ASR 解码为文本假设 `h`，最后被语言 Grounding 映射为动作序列 `A_T`。这条链每一环都丢信息：同音词、口音、噪声、端点检测。过去我们把 `T` 当作干净输入，等于把最脆弱的一环藏在假设里。本轮把语音信道显式建模为 `(声学 → 词元 → 意图 → 动作)` 的四级投影，并让每一级都携带后验与置信度。

**灵感 2（用“语音诱导动作漂移”替代 WER 作为风险预算）**
直觉：WER 低不代表安全。若被误识的词恰好把“抓取杯子”变成“抓取叉子”，WER 只错一个词，动作空间却整体偏移。真正该度量的是**后验加权后的动作序列距离** `D_voice(I)=Σ_h p(h)·d_A(π(h),π(ĥ))`。只有当 `D_voice ≤ Θ_v` 时才允许直接执行；否则进入澄清或云端重解码。这把语音不确定性翻译成动作空间里可花销的预算。

**灵感 3（云边语音协同：粗意图在云、细声学在边）**
直觉：云端大模型可做高精度重解码与上下文纠错，但延迟高；边端小模型可做实时唤醒与端点检测，但易受口音/噪声影响。二者天然是第 54 轮“粗动作 `A_c` / 细动作 `A_e`”的语音对偶：云端负责**粗意图 `I_c`**，边端负责**细词元 `I_e`**。当边端置信度低或 `D_voice` 超预算，通过反向解释信道请求云端 `redecode(I_e)` 或向用户 `ask_repeat`，形成 **边说—边听—边校验—边澄清** 的闭环。

**灵感 4（把对比实验从“仪式”变成可判定的归因算子）**
直觉：本文最容易被审稿人击穿的不是公式，而是“你的提升到底来自哪个组件”。因此把对比实验形式化：`CED = (C,T,P,S,G,claim)`，其中 `C/T` 为控制/处理组，`P` 为**同场景同种子配对**，`S` 为分层（口音、信噪比、指令长度），`G` 为预注册的归因主张。配对差值用 bootstrap 置信区间与 Wilcoxon 符号秩检验，多重消融用 Holm–Bonferroni 校正。只有通过 `Q` 元证书的对比，才能写进结论。这把“对比实验”变成证书栈的**证伪接口**。

**灵感 5（金字塔再加两层：语音层 𝕍 与实验层 ℂ）**
直觉：在第 54 轮 `𝕃`（鲁棒性）与 `𝔸`（动作协同）之上叠加 `𝕍`：`𝕍_0` 声学信噪比、`𝕍_1` 词元混淆、`𝕍_2` 意图后验、`𝕍_3` 动作落地；再叠加 `ℂ`：`ℂ_0` 主张、`ℂ_1` 设计、`ℂ_2` 统计、`ℂ_3` 复现。跨层证书从此同时携带 `ρ`、`A_cert`、`V_cert` 与 `Q`，形成**动作-语音-鲁棒性-实验有效性**四联证书。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（语音指令信道）**
语音指令信道 `SC = (I, H, p, τ_q)`：`I` 为观测（音频 + 上下文），`H={h_1,...,h_n}` 为 N-best 词元/意图假设，`p: H→[0,1]` 为校准后后验（`Σ_h p(h)=1`），`τ_q` 为允许的澄清查询预算（时间/次数）。

**定义 122（语音-技能可分配性）**
令 Grounding 映射 `π: H → A_T` 把假设映射为任务动作序列。技能 `S_i` 的语音可分配概率 `β_i(I)=Σ_{h: π(h)∈dom(S_i)} p(h)`。两技能的语音可分性
```
sep(S_i,S_j|I) = |β_i(I) - β_j(I)|
```
当 `sep(S_i,S_j|I) < θ_sep` 且二者动作剖面 `compat(S_i,S_j) < θ_a` 时，语音上“分不清”会直接变成动作上的**错选**，记为 **语音-动作歧义对** `(S_i,S_j)`。

**定义 123（语音诱导动作漂移 VIAD）**
```
D_voice(I) = Σ_{h∈H} p(h) · d_A(π(h), π(ĥ)),   ĥ = argmax_{h'} p(h')
```
其中 `d_A` 为动作空间加权编辑距离：动作替换代价按 `1-α_S(a)` 与鲁棒性谱差加权。`D_voice` 是语音不确定性的**动作后果**，而非词面错误率。

**定义 124（语音-动作联合证书）**
`V = (β, D_voice, ρ_voice, focus, clarify, evidence)`：
- `β` 语音可分配剖面；
- `D_voice` 语音诱导动作漂移；
- `ρ_voice` 语音维度鲁棒性谱（WER、ECE、端点误差）；
- `focus` 热词/技能名焦点集合；
- `clarify` 澄清策略；
- `evidence` 至少包含 N-best 日志、置信度校准曲线与混淆对反例。
若 `D_voice ≤ Θ_v`、`max_{d∈𝔇_voice}(1-ρ_voice(d)) ≤ β_V` 且 `sep ≥ θ_sep`，则记 `V` 为 `pass`。

**定义 125（主动澄清策略）**
澄清策略 `cl: State → {execute, ask_repeat, cloud_redecode, fallback}`。其期望效用
```
EU(cl) = E[Δrisk(cl)] - λ_t·E[Δt(cl)] - λ_q·E[queries(cl)]
```
选择 `cl* = argmax EU`，且受 `τ_q` 硬约束；当 `EU(execute) ≤ 0` 时禁止直接执行。

**定义 126（配对对比实验设计 CED）**
`CED = (C, T, P, S, G, claim)`：控制组 `C` 与处理组 `T` 在**同场景、同随机种子、同指令集**上配对；`P` 为配对映射；`S` 为分层因子（口音、SNR、指令长度、技能数）；`G` 为分组/交叉设计；`claim` 为预注册的归因主张（哪一组件导致哪一指标变化）。配对差值 `δ_i = metric(T_i) - metric(C_i)`。

**定义 127（对比实验有效性元证书 Q）**
`Q = (ident, power, effect, ci, mult, confound, replication)`，要求：
```
ident=1 ∧ power ≥ 1-β_stat ∧ |effect| ≥ δ_min
∧ CI_{1-α}(effect) 不含 0 ∧ mult 已校正 ∧ confound 已分层覆盖
```
否则对比结论不可写入主张区。`Q` 是对**实验本身**的证书，防止“把混杂当因果”。

**定义 128（语音-实验金字塔扩展）**
`𝕍_0` 声学（SNR/端点）、`𝕍_1` 词元（同音/口音）、`𝕍_2` 意图（后验校准）、`𝕍_3` 动作（VIAD）；`ℂ_0` 主张、`ℂ_1` 设计、`ℂ_2` 统计、`ℂ_3` 复现。跨层迁移需同时满足 `V pass` 与 `Q pass`，否则降级为“仅观测、不部署”。

## 2. 关键算法（伪代码）

### IP-121 SVAP（Speech-Voice Action Profiling）

```python
def voice_action_profile(audio, asr, grounder, skills):
    H = asr.nbest(audio, n=10)
    p = asr.calibrate(H)                 # 温度缩放/ECE 校准
    beta, drift = {s.id: 0.0 for s in skills}, 0.0
    best = max(H, key=lambda h: p[h])
    A_best = grounder.to_action(best)
    for h in H:
        A_h = grounder.to_action(h)
        for s in skills:
            if grounder.lands_in(A_h, s): beta[s.id] += p[h]
        drift += p[h] * action_edit_distance(A_h, A_best, skills)
    return beta, drift, p
```

### IP-122 VCS（Voice Command Separability）

```python
def separability_check(skills, beta, theta_sep, theta_a):
    conflicts = []
    for i, s1 in enumerate(skills):
        for s2 in skills[i+1:]:
            sep = abs(beta[s1.id] - beta[s2.id])
            if sep < theta_sep and compat(s1.alpha, s2.alpha) < theta_a:
                conflicts.append((s1.id, s2.id, sep))
    return conflicts          # 空集才允许免澄清执行
```

### IP-123 ACD（Active Clarification Decider）

```python
def decide_clarification(V, tau_q, risk_model, latency_model):
    options = ['execute', 'ask_repeat', 'cloud_redecode', 'fallback']
    best, best_eu = None, -inf
    for cl in options:
        d_risk = risk_model.expected_reduction(V, cl)
        d_time = latency_model.estimate(cl)
        eu = d_risk - lam_t*d_time - lam_q*(cl != 'execute')
        if cl != 'execute' and tau_q <= 0: continue
        if eu > best_eu:
            best, best_eu = cl, eu
    return best if best_eu > 0 else 'fallback'
```

### IP-124 PCED（Paired Comparative Experiment Design）

```python
def paired_comparison(scenes, seeds, build_control, build_treat, metric):
    deltas = []
    for scene in scenes:
        for seed in seeds:
            c = build_control(scene, seed)
            t = build_treat(scene, seed)      # 同场景同种子
            deltas.append(metric(t) - metric(c))
    est = mean(deltas)
    ci = bootstrap_ci(deltas, B=10000, alpha=0.05)   # 配对 bootstrap
    p = wilcoxon_signed_rank(deltas)
    return est, ci, p
```

### IP-125 VJC（Voice Joint Certificate）

```python
def voice_joint_certificate(audio, skills, gamma_ce, budgets):
    beta, drift, p = voice_action_profile(audio, asr, grounder, skills)
    if drift > budgets.Theta_v:
        return ('reject', 'voice_drift', drift)
    conflicts = separability_check(skills, beta, budgets.theta_sep, budgets.theta_a)
    if conflicts:
        cl = decide_clarification(beta, drift, budgets.tau_q, risk_model, latency_model)
        return ('clarify', conflicts, cl)
    rho_v = voice_robustness_spectrum(audio, asr)
    return ('pass', VCert(beta, drift, rho_v, p))
```

### IP-126 MEC（Meta-Experiment Certificate）

```python
def meta_experiment_certificate(deltas, claim, alpha=0.05, delta_min=0.02):
    est, ci, p = paired_bootstrap(deltas, alpha)
    power = posthoc_power(deltas, alpha)
    p_adj = holm_bonferroni(p, m=claim.num_comparisons)
    if ci[0] <= 0 <= ci[1] or p_adj >= alpha: return ('reject', 'not_significant')
    if abs(est) < delta_min:                  return ('reject', 'below_effect_floor')
    if power < 0.8:                           return ('reject', 'underpowered')
    return ('pass', QCert(est, ci, p_adj, power, claim))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SVAP | O(|H|·|A| + |H|·|S|) | O(|H|·|A|) | N-best 覆盖、后验校准 |
| VCS | O(|S|²) | O(|S|²) | 可分阈值 sound、歧义对完备 |
| ACD | O(|Cl|)（策略数） | O(1) | 效用可估、预算硬约束 |
| PCED | O(N·B)（N 配对，B 重采样） | O(N) | 配对同种子、分层覆盖 |
| VJC | O(|H|·|A| + |S|²) | O(|H|·|A|) | 漂移预算闭合 |
| MEC | O(B + m log m) | O(N+m) | 多重校正、功效充分 |

**正确性定理（Voice-Action Composition Soundness with Comparison Validity）**
承接第 54 轮 (A26)–(A28)，新增：**(A29)** ASR 后验经温度缩放校准，ECE ≤ ε；**(A30)** Grounding `π` 在技能名焦点集合 `focus` 上 Lipschitz 常数 `L_g<∞`；**(A31)** `D_voice` 用同一 `d_A` 计算且满足三角不等式；**(A32)** 对比实验采用同场景同种子配对，分层因子覆盖主要混杂。
则对任意通过 `V pass ∧ Q pass` 的部署：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - P(D_voice>Θ_v) - P(compat<θ_a)
            - β_E - (1 - P(Q pass | 真实无提升))
```
其中最后一项显式惩罚“把统计噪声或混杂当作真实提升”的误归因概率；注意 `V pass` 只保证语音不确定性在预算内，不保证动作剖面本身完备。

## 4. 实验设计 E162–E168

| 实验 | 指标 | 目标 | 对比方式 |
|---|---|---|---|
| E162 语音意图准确度与校准 | Acc / ECE | Acc ≥ 92%，ECE ≤ 0.05 | 云端大模型 vs 边端小模型 vs 协同 |

| E164 云边语音 Pareto | 延迟-准确率曲线 | P95 ≤ 80ms 时 Acc 不掉 5% | 串行重解码 vs 触发式重解码 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| ASR 在口音/噪声下校准失效 | 高 | 温度缩放 + 分层 ECE 监控 + 拒绝执行阈值 |
| 同音技能名导致虚假可分 | 高 | 热词/唯一唤醒词 + VCS 歧义检测 + 强制澄清 |
| 澄清过频拖垮交互 | 中 | ACD 效用模型 + 预算 τ_q + 缓存个性化发音 |
| 配对实验仍有隐藏混杂（设备/场景顺序） | 高 | 随机化顺序 + 交叉设计 + 分层审计 |
| 多重消融导致 p-hacking | 高 | 预注册 claim + Holm–Bonferroni + 效应量下限 |
| 云边重解码延迟抖动 | 中 | 触发式重解码 + 超时回退边端 + 冷启动锚点 |

## 6. 本轮最大风险

**一句话**：把语音升格为第一性信道、把对比实验升格为归因证书，方向正确，但其 soundness **同时押注 ASR 后验的真实校准与对比实验的可识别性**；一旦模型在口音/噪声下过度自信，或配对设计漏掉设备与场景顺序这类隐性混杂，系统就会把“听错但听起来很确定”与“提升但其实是选择偏差”双双写进证书，形成比单纯错误更危险的**自证式幻觉**，故必须以 **分层 ECE 监控 + 同种子配对/随机化/预注册 + 效应量与功效下限** 作为双重护栏，宁可拒绝部署，也不让语音与统计一起替错误背书。

### IP-121 SVAP

```python
def voice_action_profile(audio, asr, grounder, skills, theta_cov=0.8):
    H = asr.nbest(audio, n=10)
    p = asr.calibrate(H)                       # 温度缩放，输出校准后验
    beta = {s.id: 0.0 for s in skills}
    best = max(H, key=lambda h: p[h]); A_best = grounder.to_action(best)
    drift = 0.0
    for h in H:
        A_h = grounder.to_action(h)
        for s in skills:
            if cover(grounder.landing(A_h), s.alpha) >= theta_cov:
                beta[s.id] += p[h]
        drift += p[h] * action_edit_distance(A_h, A_best, skills)
    return {'beta': beta, 'drift': drift, 'posterior': p}
```

### IP-122 VCS

```python
def voice_conflicts(skills, beta, theta_sep, theta_a):
    out = []
    for i, s1 in enumerate(skills):
        for s2 in skills[i+1:]:
            if abs(beta[s1.id] - beta[s2.id]) < theta_sep:
                if compat(s1.alpha, s2.alpha) < theta_a:
                    out.append((s1.id, s2.id, 'voice_action_ambiguity'))
    return out
```

### IP-123 ACD

```python
def decide(V, tau_q, risk_model, latency_model, lam_t, lam_q):
    best, best_eu = 'fallback', 0.0
    for cl in ['execute', 'ask_repeat', 'cloud_redecode', 'fallback']:
        if cl != 'execute' and tau_q <= 0: continue
        eu = (risk_model.expected_reduction(V, cl)
              - lam_t*latency_model.estimate(cl)
              - lam_q*(cl != 'execute'))
        if eu > best_eu: best, best_eu = cl, eu
    return best
```

### IP-124 PCED

```python
def paired_design(scenes, seeds, strata, build_control, build_treat, metric, claim):
    deltas, meta = [], []
    for scene in scenes:
        for seed in seeds:
            c, t = build_control(scene, seed), build_treat(scene, seed)
            deltas.append(metric(t) - metric(c))
            meta.append(strata(scene))          # 口音/SNR/指令长度
    est = mean(deltas); ci = bootstrap_ci(deltas, B=10000)
    p = wilcoxon_signed_rank(deltas)
    return {'deltas': deltas, 'meta': meta, 'est': est, 'ci': ci, 'p': p, 'claim': claim}
```

### IP-125 VJC

```python
def voice_joint_certificate(audio, skills, budgets):
    prof = voice_action_profile(audio, asr, grounder, skills)
    if prof['drift'] > budgets.Theta_v:
        return ('reject', 'voice_drift', prof['drift'])
    conflicts = voice_conflicts(skills, prof['beta'], budgets.theta_sep, budgets.theta_a)
    if conflicts:
        cl = decide(prof, budgets.tau_q, risk_model, latency_model,
                    budgets.lam_t, budgets.lam_q)
        return ('clarify' if cl != 'fallback' else 'reject', conflicts, cl)
    rho_v = voice_robustness_spectrum(audio, asr)   # WER/ECE/端点误差
    if max(1-rho_v[d] for d in rho_v) > budgets.beta_V:
        return ('reject', 'voice_robustness', rho_v)
    return ('pass', VCert(prof['beta'], prof['drift'], rho_v, prof['posterior']))
```

### IP-126 MEC

```python
def meta_certificate(design, alpha=0.05, delta_min=0.02, power_min=0.8):
    est, ci, p = design['est'], design['ci'], design['p']
    p_adj = holm_bonferroni(p, m=design['claim'].num_comparisons)
    power = posthoc_power(design['deltas'], alpha)
    strata_ok = all_same_sign_by_stratum(design['deltas'], design['meta'])
    if ci[0] <= 0 <= ci[1] or p_adj >= alpha: return ('reject', 'not_significant')
    if abs(est) < delta_min:                  return ('reject', 'below_effect_floor')
    if power < power_min:                     return ('reject', 'underpowered')
    if not strata_ok:                         return ('reject', 'confounded_strata')
    return ('pass', QCert(est, ci, p_adj, power, design['claim']))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SVAP | O(\|H\|·\|A\| + \|H\|·\|S\|) | O(\|H\|·\|A\|) | N-best 覆盖 + 后验校准 |
| VCS | O(\|S\|²) | O(\|S\|²) | 歧义对完备、阈值 sound |
| ACD | O(\|Cl\|) | O(1) | 效用可估、τ_q 硬约束 |
| PCED | O(N·B) | O(N) | 同种子配对、分层覆盖 |
| VJC | O(\|H\|·\|A\| + \|S\|² + \|𝔇_voice\|) | O(\|H\|·\|A\|) | 漂移预算闭合 |
| MEC | O(B + m log m) | O(N+m) | CI 覆盖、多重校正、功效 |

**正确性定理（Voice-Action Composition Soundness with Comparison Validity）**
在第 54 轮 (A26)–(A28) 基础上，新增：
**(A29)** ASR 后验温度缩放后 ECE ≤ ε；**(A30)** Grounding `π` 在焦点集合上 Lipschitz；**(A31)** `d_A` 为度量且 `D_voice` 满足三角不等式；**(A32)** PCED 同场景同种子配对且主要混杂被分层覆盖。
则对 `V pass ∧ Q pass` 的部署：
```
P_success ≥ 1 - Σ_{d∈𝔇_ρ∪𝔇_voice}(1-ρ_min(d))
            - P(D_voice>Θ_v) - P(compat<θ_a) - β_E
            - P(误归因)
```
其中 `P(误归因) = P(Q pass | 真实无提升)` 由 `α`、功效与效应量下限共同约束。**关键**：语音证书只保证“听错的动作后果在预算内”，不替代动作剖面完备性；实验元证书只保证“提升可归因”，不保证外部效度。

## 6. 本轮最大风险

**一句话**：把语音升格为第一性信道、把对比实验升格为归因证书，方向正确，但其 soundness **同时押注 ASR 后验的真实校准与对比实验的可识别性**；一旦模型在口音/噪声下过度自信，或配对设计漏掉设备与场景顺序这类隐性混杂，系统就会把“听错但听起来很确定”与“提升但其实是选择偏差”双双写进证书，形成比单纯错误更危险的**自证式幻觉**，故必须以 **分层 ECE 监控 + 同种子配对/随机化/预注册 + 效应量与功效下限** 作为双重护栏，宁可拒绝部署，也不让语音与统计一起替错误背书。
