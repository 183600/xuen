# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；新循环第 1 轮；本轮灵感：「通用操作」×「动作空间」）

> R69 把动作空间从「任务动作」扩成「任务动作 × 信息动作」的**扁平向量积** 𝒜_+ = 𝒜_task × 𝒜_info，再用流匹配在 ℝ^D 上采样。它解决了两件事（多峰歧义、主动求证），却埋下一个结构性问题：**动作空间是一个盒子，不是一套语法**。盒子假设每个坐标独立有意义、每个点都合法；可现实里「抓」需要对象类型、「问」需要受话人与谓词、「等」需要截止时间，把它们直接拼接，绝大多数点是语义真空。流模型被迫在一个大部分无意义的空间里学习密度——于是 R69 自陈的最大风险（幻觉模态）其实有一个更深的来源：**动作空间本身没有被结构化**。
>
> 本轮两个灵感正好把这层结构补上：
> - **通用操作**：用一小组带类型签名的算子（primitive + 组合子 Seq/Par/Branch/Guard/Retry + Abstain）而不是一串坐标来生成行为——**通用性来自组合，不来自加维度**；
> - **动作空间**：一旦动作变成程序，不确定性就从「ℝ^D 上的轨迹聚类」变成「程序假设上的离散熵」，R69 的模态校准难题降级为普通多分类校准；安全也从「逐个动作认证」升级为「契约代数上的组合认证」。
>
> 核心命题：**把扁平动作空间替换为类型化算子代数；用两级程序生成（离散程序先验 + 连续参数流）替代单层流匹配；用 assume-guarantee 契约代数实现可组合的安全认证；用结构化不确定性 (U_ale, U_epi, U_cov) 替代轨迹聚类，并引入显式 Abstain 处理「基里没有合适操作」。** 命名 **OPAL-RAS**（Operator-Program Algebra for Legality-typed action spaces）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底能做什么动作，以及这些动作怎样组合仍然安全**」——动作空间不是一块空地，而是一门有类型的语言。

## 0. 直觉与动机

**灵感 1（通用操作 → 通用性来自组合，不来自维度）**
直觉：R69 的 𝒜_+ 是「任务坐标 ⊕ 信息坐标」，每加一种能力（新传感器、新工具、新问法）就要加维度、重训流场、重做认证。这条路的成本随能力数线性增长，而数据覆盖随维度指数塌缩。人类不是这样扩展动作的：人只有一小组基本动作（移动、取放、看、问、等、重试），却能组合出无穷行为——这正是组合子逻辑的洞见：少数算子 + 组合规则 = 极大多样性。**「通用操作」的通用性应当是可组合性，而不是坐标的无限膨胀。** 因此本轮把动作空间从「向量盒」改成「类型化程序代数」：`ξ = (a, g)` 被替换成 `p = Seq(Move, Query, Grasp)` 这样的程序。

**灵感 2（动作空间 → 一旦是程序，不确定性就变成语法层面的）**
直觉：R69 用 K 条轨迹做 DTW/Fréchet 聚类来发现模态，再用 ECE 校准聚类权重——可「模态身份」从来不是可观测量，聚类又依赖距离度量，校准很难。若动作是程序，多峰就变成**结构性的**：模态 = 不同的算子程序（`Sense→Grasp` vs `Query→Wait→Grasp`），是一个小规模离散假设类；程序内部的参数在给定程序后近似单峰。于是 `U_epi = H(程序后验)`、`U_ale = 参数噪声`，前者是普通多分类校准问题，后者由构造近乎单峰。**R69 最脆弱的「模态校准」，在这里被降级为「程序分类校准」。**

**灵感 3（安全必须组合 → assume-guarantee 契约代数）**
直觉：R69 对每个信息动作单独过 C-RAS-WM 认证，但危险恰恰来自组合：单看「注视」安全、单看「伸手」安全，`注视→转身→伸手` 可能撞到人。逐个动作认证对组合行为是不封闭的。若每个算子携带契约 (Pre, Post, ρ)，并定义 Seq/Par/Branch/Guard/Retry 的合成规则，则整段程序的安全性可用**结构归纳/assume-guarantee**证明，无需枚举执行。这让证书从「一次轨迹的哈希」升级为「一棵可检查的证明项」——安全第一次变成**可模组化**的。

**灵感 4（通用性是双刃剑 → 新失效模式：契约幻觉）**
直觉：一旦宣称基是「通用」的，一个错误契约就不再是局部 bug，而是**全局不可靠**：所有用到该算子的程序都继承同一个误差，而通用性意味着这样的程序很多。更微妙的是「类型正确 ≠ 语义安全」——`Reach;Move` 类型完全合法，却可能在人经过时危险。所以本轮必须同时交付：契约校准（ρ 是否可信）、契约残差监测（真实风险是否越界）、算子级归因（是哪个叶子的契约错了）、以及组合走私（两个各自安全的算子组成不安全程序）的威胁模型。

**灵感 5（覆盖不确定性 → 通用基也需要一个「不知道」符号）**
直觉：任何有限算子基都不可能在所有任务上完备；真正危险的是**基外行为**被强行用一个「差不多」的程序表达，制造 R69 式的幻影模态。语言给了我们最好的示范：当没有合适的词，人会说「我不知道」而不是随便挑一个词。因此动作空间必须显式含 `Abstain ⊥`：当覆盖不确定性 U_cov 高、或契约不可信、或类型检查失败时，策略输出一个**已认证的 ⊥**（安全停/请求人类），而不是幻觉一个程序。这让策略成为**全域定义**的：对任意观测都有合法输出，这是 R69 不具备的性质。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（OPAL-RAS 总览）** OPAL-RAS = (UOB, TAS, PGR, SCA, CCR, SPU, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **类型健全**：只有良类型程序 p ∈ 𝒜_+^τ 可被执行，非良类型在静态阶段被拒；
(iii) **契约可组合**：程序被认证当且仅当每个叶子的契约在序列/并行/分支规则下可被消解（assume-guarantee），风险预算可加（或次可加）；
(iv) **覆盖诚实**：若不存在同时满足类型、契约、似然阈值的程序，必须输出已认证的 Abstain ⊥，禁止伪造程序。

**定义 311（通用操作基 UOB）** 有限算子集 𝒪 = {o_i}，每个 o = (τ_o, Θ_o, Pre_o, Post_o, ρ_o, realize_o)：类型签名 τ_o: X_o ⇀ Y_o、参数空间 Θ_o、前后条件、风险预算 ρ_o、低层实现 realize_o。控制组合子 {Seq, Par, Branch, Guard, Retry} 为「通用操作」本体，感知/执行 primitive {Move, Reach, Grasp, Release, Sense, Probe, Query, Wait} 为类型叶子，Abstain 为常驻叶子。**相对通用性**：对行为类 ℬ 与容差 ε，若 ∀b∈ℬ 存在程序 p 使 d(b, exec(p)) ≤ ε 且 |p| ≤ L(ε)，称基为 (ε,L)-完备。**通用性永远是相对 (ℬ, ε, L) 的断言，不是无条件宣称。**

**定义 312（类型化动作空间 TAS）** 类型化状态 𝒮 = ∏_α S_α（对象/主体/资源/时间）。程序语法 p ::= o_i(θ) | Seq(p1,p2) | Par(p1,p2) | Branch(φ,p1,p2) | Guard(ψ,p) | Retry(p,n) | Abort。类型判定 Γ ⊢ p : τ。可执行动作空间 𝒜_+^τ = {p : ⊢ p : τ_exec} ⊂ 2^{𝒜_+}。**包含关系**：R69 的每个 primitive 是长度为 1 的程序，故 𝒜_task ∪ 𝒜_info ⊂ 𝒜_+^τ（同构意义下）。

**定义 313（程序生成器 PGR，两级）** 给定观测 o_t 与复用 trunk 的 z_t：第一级离散先验 p_ψ(p|o_t)（类型化文法网络或受约束解码）给出至多 M 个候选程序 {p_k, w_k}；第二级对每个候选用流匹配 v_θ 在 Θ(p_k) 上采样参数（N_step=2）。R69 的 FMP 是文法退化为「单一非终结符、长度 H」的特例。

**定义 314（结构化不确定性 SPU）** 程序后验 {p_k, w_k}_{k≤M}，参数协方差 Σ_k：
- `U_ale = Σ_k w_k · tr(Σ_k)`（程序内参数噪声，给定程序后近似单峰）；
- `U_epi = H(w)`（程序间歧义，离散熵）；
- `U_cov = Tail_α({−log p_ψ(p|o)})`（覆盖不确定性：后验落在基外/⊥/契约不可满足区域的保形尾部质量）。
三者语义不同，分通道处置（定义 325），不做简单加和。相较定义 296–297：DTW 聚类与 Δ_min 被文法结构与分类熵取代。

**定义 315（安全契约代数 SCA）** 每个叶子携带 ⊢ {Pre_o} o {Post_o} 且风险 ≤ ρ_o。合成规则（assume-guarantee）：
- **Seq**：{P}p1{Q}, {Q}p2{R} ⇒ {P}Seq(p1,p2){R}，风险 ≤ ρ1+ρ2；
- **Par**：要求 p1,p2 资源帧不相交（非干涉），否则需显式干扰界 ρ_inter，风险 ≤ ρ1+ρ2+ρ_inter；
- **Branch**：两分支在细化前置下各自可证；
- **Guard**：若守卫 φ 不可证则整程序不可认证；
- **Retry**：成功概率 q 下风险 ≤ ρ·(1−q^n)/(1−q)。
认证输出是**证明项 π**（推导树），而非执行轨迹。

**定义 316（契约校准与残差 CCR）** 契约残差 `r_κ(p) = R_obs(p) − ρ_cert(p)`；契约校准误差 ECE_κ 在已执行程序集上统计。任一 r_κ>0 或 ECE_κ>τ_κ ⇒ 触发算子降级与重证。**算子级归因**：用留一算子（leave-one-operator-out）与使用频率 f_o 定位是哪个叶子契约失真——因为契约错误会沿使用频率传播（引理 22）。

**定义 317（覆盖不确定性与 Abstain 纪律）** `Abstain ⊥` 是常驻算子，携带 certify(Pre=⊤, Post=安全停, ρ=ε_abstain)。若 `U_cov > τ_cov ∨ ECE_κ > τ_κ ∨ 类型检查失败 ∨ 任一运行时契约残差 > 0`，输出 ⊥ 或升级人类。**禁止**在无认证程序时用「最接近的程序」兜底。

**定义 318（程序精化 VoI，PRV）** 信息算子集合 𝒪_info = {Sense, Probe, Query, Wait}；VoI 在**程序空间**上计算，且动作以「给当前最优程序加前缀」的结构化方式引入：
`g* = argmax_{g∈𝒪_info} [ H(P|o) − E_{y~p(·|g,o)} H(P|o,y) − c(g) ]`，s.t. `typecheck(g·p*)`、`certify(g·p*)`、预算未越界。若无利可图则返回 None，退化为不交互。相较定义 298：不再在自由动作向量里搜 `g`，而是在**保持类型与契约的合法精化**里选。

**定义 319（程序级流似然 OPL）** `a_score(p|o) = −log p_ψ(p|o) − log p_θ(Θ(p)|p,o)`，分解为**结构通道**（程序 OOD/错算子序列）与**参数通道**（给定程序下的参数异常）。R69 的 Δa 对偶升级为二分：结构惊讶高 ⇒ 世界模型预期另一套操作；参数惊讶高 ⇒ 执行/标定偏移。缓变故障仍用 (r_res↓, Δa↑) 判别，但可定位到程序层。

**定义 320（操作注入威胁 ℰ_op）** 新增攻击面：①**类型混淆**（把算子强塞进错误类型）；②**契约投毒**（篡改 Pre/ρ）；③**组合走私**（两个各自安全的算子因资源干涉组成不安全程序）；④**算子幻觉**（策略提出基中不存在/未定义的算子）。ℰ_OPAL = ℰ_FLUID × ℰ_op。

**定义 321（程序审计 VQAuditor-P）** 审计对象升级为程序：证明项是否可检查、契约残差、基覆盖率、算子归因、Abstain 决策是否恰当。结论回灌 AuditBuf，成为算子降级与基扩展的输入。

**定义 322（证书 J_OPAL）** `J_OPAL = (J_FLUID, program_hash, proof_term_hash, contract_residual_p95, ECE_κ, U_cov, basis_version, coverage_audit)`。Valid ⇔ Valid(J_FLUID) ∧ ECE_κ≤τ_κ ∧ U_cov≤τ_cov ∧ 证明项可检查 ∧ 类型健全。

**定义 323（基扩展与开放式通用性 OBE）** 当 U_cov 持续高且有专家示范/人类纠偏时，**离线且门控地**新增算子（含其契约与实现）并升 basis_version；这是唯一允许「学习写」的地方，在线环路仍零学习写。于是「通用」是**开放基下的渐近性质**：完备性随基扩展逼近，而非一次性宣称。

**定义 324（运行时契约监测与执行）** 程序编译为算子时间线；流只生成每个算子的参数；执行在每个算子边界检查 Pre/Post 与累计风险是否越过证明项给出的预算；任一失败立即切到 ⊥。这使静态证明与动态监测构成双保险。

**定义 325（三级结构化退避）** (a) 程序歧义在预算内消解 ⇒ `λ=λ_floor(U_ale)`（resolution bonus）；(b) 未消解/超时 ⇒ `λ=λ_floor(U_ale+U_epi)`（epistemic 视同 aleatoric）；(c) 覆盖失败/契约残差/投毒/类型失败 ⇒ 执行已认证 `⊥`（风险 ≤ ε_abstain）并请求人类。R69 是 (a)/(b) 在「长度 1 程序」上的退化；R68 是「永不交互且无组合子」的进一步退化；第三级 (c) 是 R69 完全没有的**全域安全兜底**。

```python
# IP-264/265 UOB + TAS：带类型与契约的通用操作基
OPS = {Move, Reach, Grasp, Release, Sense, Probe, Query, Wait,
       Retry, Branch, Guard, Seq, Par, Abstain}      # 组合子 + 类型叶子 + ⊥

def typecheck(prog, ctx):  ...                       # Γ ⊢ p : τ，O(|p|)
def certify(prog, ctx):                              # assume-guarantee 结构归纳
    proofs = []
    for o in leaves(prog):
        if not discharge(o.pre, ctx): return None
        proofs.append(leaf_proof(o))
    return compose(prog, proofs, side_conditions=noninterference)  # 证明项 π

# IP-266 PGR：两级生成（离散程序先验 × 连续参数流）
class ProgramGenerator:
    def sample(self, o_t, M=4):
        z = self.trunk(o_t)
        cands = self.grammar_prior.topk(z, M)          # {(p_k, w_k)} 小规模离散假设
        ok = [(p, w) for (p, w) in cands if typecheck(p, ctx) and certify(p, ctx)]
        return [(p, w, self.param_flow.sample(p, z)) for (p, w) in ok]

# IP-267 SPU：结构化不确定性三分
def decompose(cands, param_cov, novelty):
    U_ale = sum(w * trace(param_cov[p]) for (p, w, _) in cands)   # 程序内参数
    U_epi = entropy([w for (_, w, _) in cands])                   # 程序间
    U_cov = conformal_tail(novelty)                               # 基外质量
    return U_ale, U_epi, U_cov

# IP-268/269 SCA + CCR：组合认证与契约残差
def certified_execute(prog, proof, runtime):
    ctx = runtime.context()
    for o in program_order(prog):
        if not runtime.check(o.pre, ctx):      return runtime.abstain()
        ctx = runtime.exec(o, ctx)
        if not runtime.check(o.post, ctx):     return runtime.abstain()
        if runtime.risk_so_far() > proof.bound_so_far(o):
            M.ccr.report(o, runtime.risk_so_far() - proof.bound_so_far(o))
            return runtime.abstain()          # 契约被违反 → 立即 ⊥
    return ctx

# IP-271 PRV：在「类型 + 契约合法」的程序空间内做 VoI 精化
def refine(cands, o_t, budget):
    best = None
    for g in [Sense, Probe, Query, Wait]:
        p_new = g.prefix_to(top_program(cands))           # 结构化精化
        if not typecheck(p_new) or not certify(p_new): continue
        if not budget.allow(g): continue
        score = (entropy(cands) - expected_entropy(cands, g, o_t)) - cost(g)
        if best is None or score > best.score: best = (p_new, score)
    return best if best and best.score > 0 else None       # 无利可图 → 不交互

# IP-277 主闭环
def OPAL_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)      # 继承 R68/R69
    cands = M.pgr.sample(o, M=M_W)
    U_ale, U_epi, U_cov = M.spu.decompose(cands, M.param_cov, M.uob.novelty(o))
    a_hat = M.opl.structural_anomaly(cands, o, o_cal)               # R69 FMA 升级
    # 1) 基外/契约不可信 → 已认证 Abstain（全域兜底）
    if U_cov > TAU_COV or M.ccr.ece_kappa() > TAU_K:
        M.vqa_p.submit_async('abstain', U_cov, a_hat)
        return M.abstain.certified()
    # 2) 可约则做结构化交互，否则保守
    g = (M.prv.refine(cands, o, M.budget)
         if U_epi > TAU_EPI and a_hat < TAU_OPL else None)
    if g is not None: U_epi = M.prv.update(cands, g)
    # 3) 三级退避确定 λ，选择最安全且契约完整的程序
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    prog, proof = M.sca.select_certified(cands, U_epi, lam)
    # 4) 静态证明 + 运行时契约监测双保险
    out = M.sca.certified_execute(prog, proof, M.runtime)
    M.vqa_p.submit_async(prog, proof, U_cov, a_hat)
    return out if out is not None else M.abstain.certified()
```

## 3. 推导

**引理 19（相对通用性与误差累积）** 设基 𝒪 中每个算子实现其规格的误差 ≤ δ（d(o(θ), spec_o(θ)) ≤ δ），则长度 n 的程序执行误差 ≤ n·δ（三角不等式 + 组合子度量相容）。因此若行为类 ℬ 可被深度 ≤ L 的程序以规格误差 0 覆盖，则总误差 ≤ Lδ。**系**：「通用」不是免费的强断言，而是一个必须审计的三元组 (ℬ, ε=Lδ, L)；宣称「万能」而不报 (ε,L) 在方法学上不成立。

**引理 20（类型健全严格弱于语义安全）** 类型检查只保证 arity/类型相容。存在反例：`Seq(Reach(区域 A), Move(路径 B))` 类型合法，但当人类预测轨迹穿过 B 时物理风险超界。故 𝒜_+^τ 只排除「语法无意义」，不排除「语义危险」——这解释了为什么必须有 SCA 而非只做类型系统。

**定理 18（契约组合的可靠性）** 设每个叶子契约在真实执行下成立（风险 ≤ ρ_o），且 Par 的资源帧不相交或干扰 ≤ ε_inter，则任意良类型程序 p 的真实风险 `R(p) ≤ Σ_{o∈leaves(p)} ρ_o + (#Par)·ε_inter`；Retry 情形由几何级数给出。**证明**：对程序推导树做结构归纳；Seq 由风险次可加性、Par 由非干涉、Branch 取两分支上界、Guard 收缩可行域、Retry 用成功概率 q 的几何和。**系**：C-RAS-WM 的认证第一次对组合封闭——认证可模组化，证据是证明项 π 而非轨迹哈希。

**引理 21（结构化不确定性更易校准）** 程序后验是小规模 M≤8 的类别分布，其校准是标准多分类问题：在可达 ECE 意义下有 `O(√(M log M / n))` 的与轨迹维数 D 无关的界。R69 的模态身份不可观测、依赖 DTW 度量与 K̂，无此维数无关界。**系**：把 U_epi 从「几何聚类」搬到「文法分类」，直接缓解了 R69 的模态校准风险；U_cov 则用保形预测得到分布无关的覆盖上界（引理 23）。

**引理 22（契约幻觉的传播界）** 若算子 o 的契约低估真实风险 δ_o，则每个含 o 的已认证程序真实风险至多高出 `δ_o·n_o`。设 o 在基中程序分布的使用频率为 f_o，则全行为空间中被误认证的风险质量为 `Σ_o δ_o·f_o`（按程序长度归一）。**系**：通用性把单点契约错误放大为**频率加权**的全局误差——契约校准必须按使用频率优先修高频算子，而不是均匀修。

**引理 23（覆盖不确定性的保形上界）** 在可交换性假设下，以 −log p_ψ 为新颖度分数的保形预测给出 `P(b ∉ 基的 (1−α) 覆盖集) ≤ α`；故 U_cov 是**校准的上界**而非拍脑袋分数。**重要警告**：分布外会破坏可交换性，此时保形保证失效——这正是本轮最大风险的第二来源。

**定理 19（OPAL 严格包含 FLUID 与 R68）** 取文法 G0 = {长度 1 的 primitive，无组合子}，则：PGR 退化为 FMP（在 Θ(o) ≅ 动作向量上做流匹配）；SPU 退化为 R69 的 (U_ale, U_epi)（不同 primitive 对应 Δ_min→∞）；SCA 退化为逐动作 C-RAS-WM 认证；PRV 退化为受限 MINT。故 `OPAL|_{G0} ≅ FLUID`；再令 VoI≤成本且禁止交互即得 R68。安全侧不放松，OPAL 只增加结构。

**定理 20（Abstain 的全域定义性与无突变）** 若 `U_cov>τ_cov ∨ ECE_κ>τ_κ ∨ 类型失败 ∨ 运行时契约残差>0`，则输出已认证 ⊥，风险 ≤ ε_abstain；切换时 λ 单调不降，且执行/⊥ 交界处的加速度差有界 ⇒ 控制在 ε_abstain 内连续。因 ⊥ 常驻动作空间，策略对任意观测都有合法输出（全定义），这是 R69「可能幻觉程序」所不具备的。

## 6. 本轮最大风险

**一句话**：OPAL-RAS 的安全全部押在「叶子契约是对的」这一前提上——**若某个契约被学错或被投毒，结构归纳会用一个严格的证明把错误合法化，而它对高频算子（引理 22：风险质量 = δ_o·f_o）的放大，使通用性把单点契约幻觉扩散成整个行为空间的系统性不安全；类型正确不等于安全，模组化证明反而可能制造虚假信心。**

**次级风险与缓解**：
1. **契约幻觉传播**（引理 22）→ 按使用频率优先校准、r_κ 在线监测、算子级留一归因、Contract Poisoning 对抗训练；
2. **保形覆盖在 OOD 下失效**（引理 23 警告）→ 多源 OOD 检测 + 人类升级通道 + 宁可 ⊥ 不可幻觉；
3. **组合走私/资源干涉** → Par 强制资源帧不相交 + ρ_inter 显式建模 + E309；
4. **两级生成时间预算** → 默认 M=1、仅歧义升 M=4 + 参数流批处理 + E313；
5. **基不完备被误当完备** → (ε,L) 必须审计上报，OBE 只离线门控扩展，拒绝在线「造算子」。

```python
        return M.abstain.certified()                    # 基外/契约不可信 → ⊥
    g = (M.prv.refine(cands, o, M.budget)
         if U_epi > TAU_EPI and a_hat < TAU_OPL else None)
    if g is not None: U_epi = M.prv.update(cands, g)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    prog, proof = M.sca.select_certified(cands, U_epi, lam)
    out = M.sca.certified_execute(prog, proof, M.runtime)
    M.vqa_p.submit_async(prog, proof, U_cov, a_hat)
    return out if out is not None else M.abstain.certified()
```

## 4. 推导

**引理 19（相对通用性与误差累积）** 每个算子实现误差 ≤ δ ⇒ 长度 n 程序误差 ≤ nδ。故「通用」必须报 (ℬ, ε=Lδ, L)，无条件「万能」断言不成立。

**引理 20（类型健全严格弱于语义安全）** `Seq(Reach(A), Move(B))` 类型合法却在人穿过 B 时危险；类型只排除语法无意义，语义危险须由 SCA 处理。

**引理 21（结构化不确定性更易校准）** 程序后验是 M≤8 的类别分布，ECE 有与轨迹维数 D 无关的 `O(√(M log M/n))` 界；R69 的模态身份不可观测、依赖 DTW/K̂，无此保证。U_cov 由保形预测给分布无关上界（引理 23）。

**引理 22（契约幻觉的传播界）** 若算子 o 低估风险 δ_o、使用频率 f_o，则全空间误认证风险质量 `Σ_o δ_o f_o`。**系**：通用性把单点契约错误放大为频率加权全局误差；应优先修高频算子。

**引理 23（覆盖不确定性保形上界）** 可交换性下 `P(b∉基覆盖集)≤α`；OOD 破坏可交换性时失效——本轮最大风险的第二来源。

**定理 18（契约组合可靠性）** 叶子契约成立 + Par 非干涉 ⇒ 任意良类型程序 `R(p) ≤ Σρ_o + (#Par)ε_inter`（结构归纳；Retry 用几何和）。系：认证对组合封闭，证书为证明项 π。

**定理 19（严格包含 FLUID 与 R68）** 文法 G0 = 长度 1 primitive、无组合子 ⇒ PGR→FMP、SPU→R69 二分、SCA→逐动作认证、PRV→受限 MINT，即 `OPAL|_{G0} ≅ FLUID`；再禁交互/令 VoI≤成本 ⇒ R68。安全侧不放松。

**定理 20（Abstain 全域性与无突变）** 任一失败条件触发已认证 `⊥`（风险 ≤ ε_abstain），λ 单调不降、交界加速度有界 ⇒ 连续；⊥ 常驻使策略对任意观测均有合法输出（全定义），强于 R69。

## 7. 本轮最大风险

**一句话**：OPAL-RAS 的安全全部押在「叶子契约是对的」这一前提上——**若某个契约被学错或被投毒，结构归纳会用一个严格证明把错误合法化，而它对高频算子的放大（风险质量 = δ_o·f_o）使通用性把单点契约幻觉扩散成整个行为空间的系统性不安全；类型正确不等于安全，模组化证明反而可能制造虚假信心。**

**次级风险与缓解**：契约幻觉传播（按使用频率优先校准 + r_κ 在线监测 + 算子级留一归因 + 对抗训练）；OOD 下保形覆盖失效（多源 OOD + 人类升级 + 宁 ⊥ 不幻觉）；组合走私/资源干涉（Par 强制帧不相交 + ρ_inter + E309）；两级生成预算（默认 M=1、歧义升 M=4 + 批处理 + E313）；基不完备被误当完备（(ε,L) 必须审计上报；OBE 仅离线门控扩展，拒绝在线造算子）。
