# 第 69 轮（承接第 68 轮「CALM-RAS 自标定风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「评测基准」×「材料选型」）

> 第 68 轮把「标定」升级为在线潜变量，用自监督驱动、用单模型多任务保证同源一致，看似补齐了计量层。但它自陈的最大风险——**缓变故障落在标定带宽内会被「标好」而隐形**——不是工程细节，而是它的**模型设定使然**：R68 用自由随机游走 `c_{t+1}=c_t+w_t, w~𝒩(0,Q_cal)` 描述标定漂移，这在贝叶斯上等价于宣称「任何慢变量都能被标定解释」。自由游走对「良性温漂/蠕变」与「材料退化/缓变故障」赋予了不可区分的先验支撑，二者在观测上**根本不可辨识**。
>
> 更深的元失败在评测侧：R68 的全部安全声明（E271–E285、CAC 五关、canary 不可修复性）都建立在一组**设计师手写的 canary / 金标集**之上。它的安全性严格等于「基准对故障的覆盖率」，而这个覆盖率从未被度量、从未被证明。设计与评测，是同一个盲区的两面。
>
> 本轮两个灵感各堵一个洞，并且惊人地同构：
> - **材料选型**：真实慢漂移大多有「形状」——粘弹性蠕变（标准线性固体）、Arrhenius 老化、Paris 疲劳、材料热膨胀。把标定从「自由游走」换成「本构律先验」，退化就表现为**本构参数/形状空间的偏离**而非幅度偏离，从而重新可辨识；更进一步，可辨识性可以被**设计**出来（选低蠕变材料、加 witness 试片、注入主动激励）。
> - **评测基准**：把故障写成流形 ℱ，用 δ-网覆盖 + Lipschitz 外推得到 **worst-case 上界**（而非平均分），并把「在预算下挑用例」建成与 Ashby 材料选型**同一个**多目标/子模优化问题。
>
> 核心命题：
>
> **用材料本构把「慢漂移」从不可辨识的自由随机游走，变成可辨识、可设计、可证的物理过程；用接地的、覆盖率可证的评测基准，把 R68 的「设计师拍的 canary」升级为「对故障流形的 δ-网覆盖证书」——MAT-RAS（Material-grounded, Attribution-identifiable, Test-certified RAS）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**当测量慢慢变坏时，我怎么证明我仍然知道？**」

## 0. 直觉与动机

**灵感 1（材料选型 → 慢漂移是本构律，不是自由随机游走）**
直觉：柔性传感皮肤在受力后不是「随机漂一点」，而是按粘弹性蠕变曲线回弹（标准线性固体：ε(t)=σ/E₁+(σ/E₂)(1−e^{−t/τ})）；压阻接触随时间是松弛；胶层老化服从 Arrhenius（k=A·e^{−E_a/(RT)}）；反复加载下的微裂纹服从 Paris 律（da/dN=C·ΔK^m，先慢后加速）。这些漂移都有**低维形状**。R68 之所以无法区分「良性漂移」与「退化」，是因为它的 c 是无形状的自由游走，形状信息被当成噪声扔掉了。若把漂移写成
`y = y_true + c + g(m; θ_mat) + e`，
其中 g 是材料本构律、m 是材料状态（温度/应力/龄期/损伤）、θ_mat 是本构参数，那么**标定只应吸收 c 与 θ_mat 名义演化所预测的 g**；而「退化」是 θ_mat 本身漂移或本构律切换——偏离发生在**形状空间**。于是「先标定后归因」从不可辨识（R68）升级为在激励充分时可辨识。

第二层更关键：**材料本身就是可设计的自由度**。既然可辨识性取决于本构形状、材料时间常数与故障带宽的分离度、以及是否有独立参考，那么就应该「为了可辨识性选材料」——选本构已知且稳定、蠕变/热膨胀小、并带同批 witness 试片的材料。这把 R68 的物理防线从「在线速率限制（事后）」前移到「设计期可观性（事前）」。这正是控制论意义上的 Design-for-Observability。

**灵感 2（评测基准 → 评测本身就是系统最薄弱的假设）**
直觉：R68 说「若金标集未覆盖该故障模式则放行」——即系统的安全上限由基准覆盖率决定，而覆盖率从未被度量。评测基准研究给出三条解药：
(i) 覆盖度量必须是 **worst-case 而非 average**（故障流形上的最坏点，而非随机抽样的均值）；
(ii) 必须防「评测污染 / 对基准过拟合」——自适应系统会博弈静态测试；
(iii) 自适应系统的评测必须**闭环、对抗、held-out、轮转**，并把「冻结评测」与「适应后评测」分开报告。
于是我们把故障写成流形，用 δ-网 + Lipschitz 外推把「在 K 个用例上的实测」转成「对整个流形的上界证书」，并把这张证书挂进证书链。

**灵感 3（两灵感的同构：材料选型 ≡ 基准选型）**
材料选型的内核是 Ashby 图：在「性能指标」空间里做多目标 Pareto 剪枝，用材料指数（如 M=σ/ρ）选最优。基准选型的内核**是同一个数学**：给定候选故障用例与预算 K，挑子集 S 使「覆盖故障流形的增益」最大、成本最小。于是「选材料」与「选用例」共用一套多目标 + 子模覆盖工具。本轮最漂亮的结构对应：**为可辨识性选材料，与为覆盖率选用例，是同一个 Pareto 问题的两个实例。**

**灵感 4（合流 → MAT-RAS 六组件）**
1. **MOM Material Observer Model**：材料本构漂移模型（蠕变 / 老化 / 疲劳 / 热膨胀四族），把漂移分解为 c + g(θ_mat) + e；
2. **DID Design-for-Identifiability**：以 Fisher 信息最小特征值为目标，在材料/几何/试片/激励上做 Ashby 式选型，最大化漂移分解的可辨识裕度；
3. **DCA Degradation-vs-Calibration Attribution**：在**形状空间**做广义似然比变点检测，而非幅度检测；
4. **MPB MAT-Bench**：材料接地的故障流形基准（type × 带宽 × 幅度 × 起始时刻 × 材料龄期 × 环境）；
5. **ASP Ashby Suite Planner**：把基准用例选择建成子模覆盖 + 成本约束的多目标选型；
6. **BCC Benchmark Coverage Certificate**：δ-网覆盖 + Lipschitz 外推的 worst-case 上界证书。
另加 **WIT Witness/主动探针**（同批参考试片 + 微激励，直接扩大 Fisher 信息），并保留 **RAS-M† 继承核**（CALM-RAS 的 MTM/SSG/COF/CFA/CAC 全保留，只把 COF 的漂移模型换成 MOM、把 CAC 的金标集换成 MAT-Bench）。

**灵感 5（对症下药）**
- R68「缓变故障被标定吸收」：MOM 把良性漂移限制在本构流形上，DCA 在形状空间检测偏离 → 缓变故障不再隐形；
- R68「金标集未覆盖即放行」：MAT-Bench + BCC 把「未覆盖」从静默风险变成**可量化上界 Lδ**，并强制 held-out 轮转；
- R67「Sim2Real 偏移/长尾」：故障流形显式含环境与材料龄期维度，长尾是流形的边缘区而非意外；
- R66/R65 的「观测链路不可信」：本构先验 + witness 试片给观测链路一个独立锚点，使「传感器歪了 / 材料老了 / 世界变了」三分可辨。

## 1. 形式化定义（增量：定义 293–305）

**定义 293（MAT-RAS 总览）** MAT-RAS = (MOM, DID, DCA, MPB, ASP, BCC, WIT, RAS-M†)。不变式继承并升级 R68：
(i) 实时流零学习写操作（更新只在影子流、经 CAC 认证原子换装）；
(ii) 标定安全红线不变（|b_F|≤5% FS、‖δR_ext‖≤2°、|Δt_sync|≤20ms）；
(iii) **形状红线**：标定只可吸收「落在 MOM 良性流形内」的漂移，超出本构包络（定义 295 的 Θ₀）即判退化/故障，禁止吸收；
(iv) **覆盖红线**：任何安全声明必须附带覆盖率证书 BCC；未覆盖区域的风险计入 Lδ，不得默认忽略。

**定义 294（材料基元与漂移三分量）** 每个传感元件 j 绑定材料基元 `m_j=(E, τ, α, θ_age, D)`（弹性模量、松弛时间、热膨胀系数、老化参数、损伤度）。观测：
`y_j(t) = y_j^true(t) + c_j(t) + g_j(m_j(t); θ_mat,j) + e_j(t)`，
其中 c 为自由标定项（电子零偏、外参等），g 为本构漂移，e~𝒩(0,σ_j²) 为噪声。R68 等价于 `g≡0`、c 为自由游走。

**定义 295（本构漂移律族与良性包络）** 四族基函数：
- 蠕变（标准线性固体）：`g_creep(t)=σ/E₁ + (σ/E₂)(1−e^{−t/τ})`，θ=(E₁,E₂,τ)；
- 老化（Arrhenius）：`g_age(t)=g_∞(1−e^{−k(T)t})`, `k(T)=A·e^{−E_a/(RT)}`，θ=(A,E_a,g_∞)；
- 疲劳（Paris）：`dD/dN=C(ΔK)^m`, `g_fat ∝ φ(D)`，θ=(C,m)，单调加速；
- 热膨胀：`g_th=α·ΔT`，θ=α。
良性包络 `Θ₀ = Θ₀^spec ⊕ Θ₀^age`：材料规格书给定参数区间再叠加工况内老化轨迹。**良性 = θ_mat(t) 始终在 Θ₀ 内**；退化 = θ_mat 越出 Θ₀ 或发生律切换。

**定义 296（漂移分解与可辨识性）** 在激励窗口上堆叠观测 y=[y_sensor; y_wit]，对 ψ=(c, θ_mat) 的雅可比 `J=∂y/∂ψ`，Fisher 信息 `F=JᵀΣ⁻¹J`。称 (c, θ_mat) **可辨识**当且仅当 F 满秩；定义可辨识裕度 `μ=λ_min(F)`。退化不可辨识当且仅当退化引起的漂移方向落在 c 的（近）零空间内——这正是 R68 的自由游走情形（c 的解释空间 = 全慢变子空间）。

**定义 297（Design-for-Identifiability，材料选型目标）** 在候选材料/几何/是否带 witness/激励模式 x∈𝒳 上，求解
`max_x λ_min(F(x))  s.t.  cost(x)≤B,  g(x)⊆Θ₀`。
这是以「可辨识裕度」为性能指标、以成本与包络为约束的 Ashby 式多目标选型：在 (μ, cost) 平面上取 Pareto 前沿。关键结论：加入 witness 试片等价于给 F 增加独立行，由 Schur 补知 λ_min 非降（引理 17）。

**定义 298（形状空间退化检测）** 滑窗拟合 `θ̂_mat`，做广义似然比：
`Λ = 2[ max_ψ log p(y | ψ) − max_{θ_mat∈Θ₀} log p(y | c, θ_mat) ]`。
c 已在标定中吸收**幅度**，故剩余统计量度量的是**形状失配**；退化判据 `Λ>τ_shape`（H₀ 下渐近 χ²_{dim θ}）。这是 R68「幅度不可分」的直接修复。

**定义 299（WIT 见证试片与主动探针）** WIT = 与传感器同批、同工艺、屏蔽真值信号的参考元件（如未加载应变片、遮光参考贴片）+ 微激励（小幅已知载荷/温升斜坡）。其观测 `y_wit=c_wit+g(m)+e` 提供材料状态的独立锚点；主动激励 u 按 D-最优准则选取，最大化 `λ_min(F(u))`，把 c 与 g 的分离从「被动等待激励」升级为「主动制造激励」。

**定义 300（MAT-Bench 故障流形）** `ℱ = {(type, ω_f, A, t_on, s, env)}`，type∈{阶跃, 斜坡, 振荡, 缓变退化}, s 为材料龄期阶段，env 为温湿度/负载剖面。配归一化度量 d_ℱ。R68 的 E271–E285 只是 ℱ 上若干手挑点。

**定义 301（基准索引与 Ashby 选型）** 候选用例 i 有三元评分：判别力 `D_i`（H_cal 与 H_fault 的 JS 散度/AUC）、覆盖增益 `ΔCov_i`、成本 `C_i`。定义基准指数 `I_i = D_i^a·ΔCov_i^b / C_i^c`（与材料指数 M=σ^a/ρ^b 同构）。选 K 个用例：`max_{|S|≤K} Cov(S)  s.t. Σ_{i∈S} C_i ≤ B`，Cov 为覆盖函数（定义 302）。

**定义 302（δ-网覆盖证书 BCC）** 若选定集 S 在 d_ℱ 下是 ℱ 的 δ-网（∀f∈ℱ, ∃s∈S: d(f,s)≤δ），且系统风险泛函 R(·) 关于 d_ℱ 为 L-Lipschitz，则
`sup_{f∈ℱ} R(f) ≤ max_{s∈S} R(s) + L·δ`。
证书 `BCC=(S, δ, L, bound, bench_ver)`。构造 δ-网用低差异序列（Sobol/星差异界）保证 δ 可计算。

**定义 303（闭环对抗评测协议 CEP）** 评测在 held-out `ℱ_hold`（与训练/canary 不相交）上进行；用例**轮转**；对抗器在覆盖空洞区（BCC 的 max 空隙）生成新用例（co-evolution）；分别报告 frozen-eval（关闭适应）与 adaptive-eval（允许适应）两组数字，二者差距度量「对基准的博弈程度」。任何适配器只有在 held-out 上通过才计入安全声明。

**定义 304（MAT-RAS 证书 J_MAT）** `J_MAT=(J_CALM, material_spec_hash, θ̂_mat, μ, bench_ver, BCC, adversarial_verdict, mat_ver)`。Valid ⇔ `Valid(J_CALM) ∧ μ≥μ_min ∧ BCC.bound≤safety_budget ∧ held-out PASS ∧ 形状/覆盖红线未越界`。

**定义 305（管线）** 离线：材料表征 → 拟合 θ_mat 与 Θ₀ → DID 选材料/试片 → 构造 MAT-Bench + BCC → 部署。在线：MOM/DCA 与 COF 并行（COF 只吸收 c 与本构预测 g，DCA 监视 θ̂_mat 形状失配）；WIT 周期微激励刷新可辨识性；CAC 的金标关替换为 MAT-Bench held-out 关；BCC 随材料龄期增长周期重算（流形漂移）。

```python
# IP-253 MOM：材料本构漂移模型（替代 R68 的自由随机游走）
class MaterialObserverModel:
    FAMILIES = {'creep': creep_sls, 'age': arrhenius, 'fatigue': paris, 'thermal': cte}
    def fit(self, y, wit, window):
        # y = [sensor, witness]；在良性包络 Θ₀ 内做带约束非线性最小二乘
        psi = nls_constrained(obs=[y, wit], basis=self.FAMILIES,
                              bounds=THETA0, init=self.theta_prev)
        return psi.c, psi.theta_mat, psi.F, psi.residual

    def benign_drift(self, c, theta, t):        # 本构预测的良性漂移
        return c + sum(self.FAMILIES[f](theta, t) for f in theta.active)


# IP-254 DID：为可辨识性选材料 / 试片 / 激励
def design_for_identifiability(candidates, budget):
    front = []
    for x in candidates:                        # 材料×几何×witness×激励模式
        F = fisher_info(x, sigma=NOISE)         # JᵀΣ⁻¹J
        mu = np.linalg.eigvalsh(F)[0]           # 可辨识裕度
        if cost(x) <= budget and within_envelope(x):
            front.append((x, mu, cost(x)))
    return pareto_front(front, key=lambda r: (r[1], -r[2]))  # Ashby 前沿


# IP-255 DCA：形状空间退化检测（广义似然比）
def degradation_test(y, c, theta0, envelope=THETA0):
    ll_free = max_loglik(y, c, theta_free=True)          # 形状自由
    ll_benign = max_loglik(y, c, theta=theta0, box=envelope)  # 良性包络内
    Lambda = 2 * (ll_free - ll_benign)
    return Lambda > TAU_SHAPE, Lambda                     # 幅度已由 c 吸收


# IP-256/257 MPB + ASP：故障流形基准 + Ashby 式用例选型
class MatBench:
    def build(self):
        return FaultManifold(types=['step','ramp','osc','degrade'],
                             bands=logspace(w_cal/10, 10*w_cal, 20),
                             amps=..., onsets=..., stages=['new','mid','aged'],
                             envs=ENV_PROFILES)

    def ashby_select(self, K, budget):
        S, cov = set(), 0.0
        while len(S) < K and budget > 0:
            best = max(self.cands - S,
                       key=lambda i: (discriminability(i) * delta_cov(S, i))
                                     / cost(i))
            if cost(best) > budget: break
            S.add(best); budget -= cost(best); cov += delta_cov(S, best)
        return S, cov                              # 子模贪心 ≥(1−1/e)OPT


# IP-258 BCC：δ-网覆盖证书（worst-case 外推）
def coverage_certificate(S, manifold, L):
    delta = max(min(d(f, s) for s in S) for f in manifold.sample_dense())
    bound = max(risk(s) for s in S) + L * delta
    return {'S': S, 'delta': delta, 'L': L, 'bound': bound}


# IP-262 主闭环（在 CALM-RAS 上叠加 MOM/DCA/BCC）
def MAT_RAS_round(M, obs):
    y, wit = obs.sensor, obs.witness
    c, theta, F, r = M.mom.fit(y, wit, M.window)          # 1) 本构分解
    benign = M.mom.benign_drift(c, theta, t=M.t)          # 2) 良性漂移预测
    c_eff, U, thr = M.cof.step(r - benign, M.sigma_stat)  #    标定仅吸收 c
    deg, Lambda = M.dca(y, c_eff, theta)                  # 3) 形状空间退化检测
    if deg:                                               #    退化 ⇒ 禁止吸收
        U, thr['lam_floor'] = np.inf, 0.8
        c_eff = M.cof.freeze()
    joint = M.cfa(r, c_eff, U)                            # 4) 继承 R68 归因
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), joint, ...)
    if U > TAU_CAL or deg: k = min(k, M.k_cal_shrink(U, deg))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'])
    tau = M.pi_sigma.prefix_dispatch(M.ach.propose(...)[:k]) * lam
    if M.t % M.PROBE_PERIOD == 0:                         # 5) 周期微激励
        M.wit.active_probe(u=d_optimal(M.mom.F))
    if M.t % M.BENCH_PERIOD == 0:                         # 6) 覆盖证书重算
        S, cov = M.bench.ashby_select(K, B)
        M.bcc = coverage_certificate(S, M.bench.manifold, L=L_RISK)
    M.cac.maybe_commit(M.shadow, gate=M.bcc)              # 7) 用 held-out 金标
    return k, lam, joint, (c_eff, U, theta, deg, M.bcc)
```

## 3. 推导

**引理 16（形状可辨识界）** 设退化漂移 r_deg 投影到标定可解释子空间的特征为 P_c。R68 中 P_c ≈ 全慢变子空间 ⇒ `(I−P_c)r_deg≈0`，形状无关的检出统计量恒为零。引入 MOM 后，良性子空间收缩为 `P_benign = P_c ⊕ P_{g(Θ₀)}`，检出统计量 `Λ` 的均值正比于 `‖(I−P_benign)r_deg‖`。故退化检出 SNR = `‖(I−P_benign)r_deg‖/(τ_shape·σ)`，在退化方向不落于良性流形时严格为正——**这是 R68 做不到的**。系：慢不再等于不可见，决定可见性的是「是否在良性本构流形内」，而非「是否慢」。

**引理 17（设计可辨识性与 CRB）** 对 ψ=(c,θ_mat)，无偏估计满足 `Cov(ψ̂) ⪰ F⁻¹`，故 θ_mat 的任意线性泛函的方差下界由 `λ_min(F)` 控制；DID 选型最大化 λ_min 即最小化 CRB，从而最小化检测阈值 τ_shape。witness 试片给 F 增加独立观测行：`F' = F + J_witᵀΣ_wit⁻¹J_wit ⪰ F`，由 Weyl 单调性 `λ_min(F')≥λ_min(F)`——**加试片永不降低可辨识性**，为其成本提供单调收益依据。

**引理 18（δ-网覆盖外推界）** 若 R 为 L-Lipschitz 且 S 是 δ-网，则 `sup_ℱ R ≤ max_S R + Lδ`。证：∀f 取最近 s∈S，`R(f)≤R(s)+L·d(f,s)≤max_S R+Lδ`。系：给定安全预算 ε，取 `δ=ε/(2L)` 即可保证上界；低差异序列使 δ 可用星差异界显式算出，而非经验猜测。

**引理 19（Ashby 式选型的子模保证）** 覆盖函数 Cov(S) 单调子模 ⇒ 无成本约束时贪心达 `(1−1/e)OPT`；带预算约束时按 `ΔCov/C` 比率贪心给出 bicriteria 近似（成本不超、覆盖 ≥ 常数倍）。这为「基准规模」与「安全上界」之间提供了可计算的权衡曲线。

**定理 16（MAT-RAS 端到端风险，含退化项）** 在 R68 定理 14 的 A87–A94 与新增 A95（材料本构可近似、良性包络 Θ₀ 覆盖工况）下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_deg`，其中 `α_cal` 为良性漂移误判，`α_deg` 为退化漏检；
2. 退化漏检界：`α_deg ≤ P(Λ≤τ_shape | θ_mat∉Θ₀) ≤ exp(−½·SNR²)`（引理 16 的高斯尾界，SNR 由 μ 经引理 17 保证）；
3. 未覆盖区域：`sup_{ℱ∖N_δ(S)} R ≤ BCC.bound`（引理 18），且该上界进入 J_MAT；
4. 结论：R68 的「慢故障隐形」被转化为**受 μ 与 δ 两个可设计量控制的有限风险**，而非结构性盲区。

**定理 17（基准不可无成本博弈）** 在 held-out 轮转 + co-evolution + 适应预算约束下，适配器「过拟合 canary 却通过 held-out」的概率满足
`P(pass_heldout | fail_canary_regime) ≤ exp(−2mδ_h²)`（m 个独立 held-out 用例、间隔 δ_h，Hoeffding），叠加 CAC 的 canary 关后总误放 ≤ `(1−r_canary)p_h + exp(−2mδ_h²)`。frozen 与 adaptive 两组数字之差给出博弈强度的可观测量。

## 6. 本轮最大风险

**一句话**：MAT-RAS 把安全性押在「材料本构模型正确 + 良性包络 Θ₀ 覆盖真实工况」上，而 MAT-Bench 又由**同一套本构假设**生成——一旦该假设在真实材料上系统性偏离（环境相关老化、批次缺陷、罕见蠕变律），MOM 会把良性漂移误判为退化（误冻结、机器人过度保守）或把退化误判为良性（漏检），并且覆盖证书会因与模型**共享同一盲区**而给出虚假的安全保证——这是「用模型证明模型」的**认知循环**，也是把物理先验引入安全论证时最危险的一步。

**次级风险与缓解**：
1. **本构误设**：多族本构并行 + 包络外失配告警 + 定期破坏性 witness 抽检；
2. **Θ₀ 过窄/过宽**：过窄 → 误冻结；过宽 → 退化被吸收。用 held-out 材料批次估计包络，纳入版本链；
3. **覆盖证书的乐观**：Lipschitz 常数 L 本身需标定，取保守上界并做 E291 紧致性检验；
4. **基准泄漏**：canary 与 held-out 严格不相交 + 轮转 + 博弈差距监控（定理 17）；
5. **主动探针干扰**：探针幅度纳入红线（< 感知阈值），探针期间冻结控制增益。

## 2. 形式化定义（要点版）

**定义 293（总览与四不变式）** 继承 R68 的实时流零学习写操作、标定红线；新增 **形状红线**（标定只吸收 Θ₀ 内漂移，越界即判退化、禁止吸收）与 **覆盖红线**（任何安全声明须附 BCC，未覆盖区风险计 Lδ，不得默认忽略）。

**定义 294–295（材料基元与本构律族）** `y=y_true+c+g(m;θ_mat)+e`；g 取自四族：蠕变（标准线性固体）、老化（Arrhenius `k=Ae^{−E_a/RT}`）、疲劳（Paris `da/dN=CΔK^m`）、热膨胀（`αΔT`）。良性 = θ_mat(t) 始终在 Θ₀ 内；退化 = 越出 Θ₀ 或律切换。

**定义 297（DID 材料选型）** `max_x λ_min(F(x)) s.t. cost(x)≤B, g(x)⊆Θ₀`；在 (μ,cost) 平面取 Pareto 前沿。witness/主动激励通过给 F 增加独立行提升 μ（引理 17 单调性）。

**定义 298（形状空间退化检测）** 滑窗拟合 θ̂_mat，`Λ=2[ℓ_free−ℓ_benign(Θ₀)]`，`Λ>τ_shape` 判退化（H₀ 下渐近 χ²_{dim θ}）。c 已吸收幅度，故 Λ 只度量形状失配。

**定义 299（WIT 与主动探针）** 同批、同工艺、屏蔽真值的参考元件提供材料状态独立观测；微激励 u 按 D-最优 `max λ_min(F(u))` 选取，主动制造可辨识激励。

**定义 300（MAT-Bench 故障流形）** `ℱ={(type,ω_f,A,t_on,s,env)}`；R68 的 E271–E285 只是 ℱ 上手挑的若干点。

**定义 301（基准索引与 Ashby 选型）** `I_i=D_i^a·ΔCov_i^b/C_i^c`；`max_{|S|≤K} Cov(S) s.t. ΣC_i≤B`。与材料指数 `M=σ^a/ρ^b` 同构——为可辨识性选材料与为覆盖率选用例是同一个 Pareto 问题。

**定义 302（BCC）** S 为 ℱ 的 δ-网、R 为 L-Lipschitz ⇒ `sup_ℱ R ≤ max_S R + Lδ`；低差异序列（Sobol）使 δ 可计算，证书入 J_MAT。

```python
# IP-253 MOM：材料本构漂移模型（替代 R68 自由随机游走）
class MaterialObserverModel:
    FAMILIES = {'creep': creep_sls, 'age': arrhenius, 'fatigue': paris, 'thermal': cte}
    def fit(self, y, wit, window):
        psi = nls_constrained(obs=[y, wit], basis=self.FAMILIES,
                              bounds=THETA0, init=self.theta_prev)
        return psi.c, psi.theta_mat, psi.F, psi.residual

    def benign_drift(self, c, theta, t):               # 本构预测的良性漂移
        return c + sum(self.FAMILIES[f](theta, t) for f in theta.active)


# IP-254 DID：为可辨识性选材料 / 试片 / 激励
def design_for_identifiability(candidates, budget):
    front = []
    for x in candidates:                               # 材料×几何×witness×激励
        F = fisher_info(x, sigma=NOISE)
        mu = np.linalg.eigvalsh(F)[0]                  # 可辨识裕度
        if cost(x) <= budget and within_envelope(x):
            front.append((x, mu, cost(x)))
    return pareto_front(front, key=lambda r: (r[1], -r[2]))  # Ashby 前沿


# IP-255 DCA：形状空间退化检测（广义似然比）
def degradation_test(y, c, theta0, envelope=THETA0):
    ll_free   = max_loglik(y, c, theta_free=True)              # 形状自由
    ll_benign = max_loglik(y, c, theta=theta0, box=envelope)   # 良性包络内
    Lambda = 2 * (ll_free - ll_benign)
    return Lambda > TAU_SHAPE, Lambda                          # 幅度已由 c 吸收

    def ashby_select(self, K, budget):
        S, cov = set(), 0.0
        while len(S) < K and budget > 0:
            best = max(self.cands - S,
                       key=lambda i: (discriminability(i) * delta_cov(S, i)) / cost(i))
            if cost(best) > budget: break
            S.add(best); budget -= cost(best); cov += delta_cov(S, best)
        return S, cov                               # 子模贪心 ≥(1−1/e)OPT

    return {'S': S, 'delta': delta, 'L': L,
            'bound': max(risk(s) for s in S) + L * delta}


# IP-262 主闭环（在 CALM-RAS 上叠加 MOM/DCA/BCC）
def MAT_RAS_round(M, obs):
    y, wit = obs.sensor, obs.witness
    c, theta, F, r = M.mom.fit(y, wit, M.window)           # 1) 本构分解
    benign = M.mom.benign_drift(c, theta, t=M.t)           # 2) 良性漂移预测
    c_eff, U, thr = M.cof.step(r - benign, M.sigma_stat)   #    标定仅吸收 c
    deg, Lambda = M.dca(y, c_eff, theta)                   # 3) 形状空间退化检测
    if deg:                                                #    退化 ⇒ 禁止吸收
        U, thr['lam_floor'] = np.inf, 0.8
        c_eff = M.cof.freeze()
    joint = M.cfa(r, c_eff, U)                             # 4) 继承 R68 归因
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), joint, ...)
    if U > TAU_CAL or deg: k = min(k, M.k_cal_shrink(U, deg))
    lam = max(M.efs.risk_scale(joint), thr['lam_floor'])
    tau = M.pi_sigma.prefix_dispatch(M.ach.propose(...)[:k]) * lam
    if M.t % M.PROBE_PERIOD == 0:                          # 5) 周期微激励
        M.wit.active_probe(u=d_optimal(M.mom.F))
    if M.t % M.BENCH_PERIOD == 0:                          # 6) 覆盖证书重算
        S, cov = M.bench.ashby_select(K, B)
        M.bcc = coverage_certificate(S, M.bench.manifold, L=L_RISK)
    M.cac.maybe_commit(M.shadow, gate=M.bcc)               # 7) held-out 金标关
    return k, lam, joint, (c_eff, U, theta, deg, M.bcc)
```

## 4. 推导

**引理 16（形状可辨识界）** R68 中标定可解释子空间 P_c ≈ 全慢变子空间 ⇒ `(I−P_c)r_deg≈0`，形状无关统计量恒零。MOM 把良性子空间收缩为 `P_benign=P_c⊕P_{g(Θ₀)}`，Λ 均值 ∝ `‖(I−P_benign)r_deg‖`，退化检出 SNR = `‖(I−P_benign)r_deg‖/(τ_shape·σ)`。系：**决定可见性的不是"快慢"，而是"是否在良性本构流形内"**——这直接拆掉 R68 的"慢即隐形"。

**引理 17（设计可辨识性与 CRB）** `Cov(ψ̂)⪰F⁻¹`，θ_mat 线性泛函方差由 λ_min(F) 控制；DID 最大化 λ_min 即最小化检测阈值。witness 增加独立观测行：`F'=F+J_witᵀΣ_wit⁻¹J_wit⪰F`，Weyl 单调性 ⇒ `λ_min(F')≥λ_min(F)`，为试片成本给出单调收益。

**引理 18（δ-网覆盖外推界）** R 为 L-Lipschitz、S 为 δ-网 ⇒ `sup_ℱ R ≤ max_S R+Lδ`。给定预算 ε，取 δ=ε/(2L) 保证上界；低差异序列使 δ 有星差异显式界。

**引理 19（Ashby 子模选型）** 覆盖函数单调子模 ⇒ 无预算贪心达 (1−1/e)OPT；有预算时按 ΔCov/C 贪心给 bicriteria 近似，给出 (基准规模, 安全上界) 的可计算权衡曲线。

**定理 16（MAT-RAS 端到端风险，含退化项）** 在 A87–A94 与新增 A95（本构可近似、Θ₀ 覆盖工况）下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_deg`；
2. `α_deg ≤ P(Λ≤τ_shape|θ_mat∉Θ₀) ≤ exp(−½SNR²)`（引理 16 高斯尾界，μ 由引理 17 保证）；
3. 未覆盖区 `sup_{ℱ∖N_δ(S)} R ≤ BCC.bound`（引理 18），进入 J_MAT；
4. 结论：R68 的结构性盲区被转化为由 μ、δ 两个**可设计量**控制的有限风险。

**定理 17（基准不可无成本博弈）** held-out 轮转 + co-evolution + 适应预算下，`P(pass_heldout | 过拟合 canary) ≤ exp(−2mδ_h²)`（Hoeffding）；叠加 canary 关后总误放 ≤ `(1−r_canary)p_h+exp(−2mδ_h²)`。frozen/adaptive 差值即博弈强度可观测量。

## 7. 本轮最大风险

**一句话**：MAT-RAS 把安全性押在「材料本构模型正确 + 良性包络 Θ₀ 覆盖真实工况」上，而 MAT-Bench 又由**同一套本构假设**生成——一旦该假设在真实材料上系统性偏离（环境相关老化、批次缺陷、罕见蠕变律），MOM 会把良性漂移误判为退化（误冻结、过度保守）或把退化误判为良性（漏检），且覆盖证书会因与模型**共享同一盲区**而给出虚假的安全保证——这是「用模型证明模型」的**认知循环**，也是把物理先验引入安全论证时最危险的一步。

**次级风险与缓解**：本构误设（多族并行 + 包络外失配告警 + 定期破坏性 witness 抽检）；Θ₀ 过窄/过宽（用 held-out 材料批次估包络，纳入版本链）；覆盖证书乐观（L 取保守上界 + E291 紧致性检验）；基准泄漏（canary 与 held-out 严格不相交 + 轮转 + 博弈差距监控）；主动探针干扰（幅度纳入红线、探针期间冻结控制增益）。
