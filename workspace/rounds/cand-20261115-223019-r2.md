# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「机器人竞赛」×「跨物体泛化」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**竞赛即分布、泛化即安全、安全不可交易**。v9 的最大风险是「Δ_dom 的 20 帧滑窗滞后于真实分布跳变，分块在最需要安全时暴露最不可靠的证书」。本轮不再沿时间轴做更多平滑，而是引入**单帧、物体级**的新颖度信号，把信任域从"域级"细化到"物体级"；同时把"竞赛"形式化为一个**留出物体 + 计分预算**的评估算子，让泛化能力第一次可被证伪。

## 0. 直觉与动机

**灵感 1（跨物体泛化 → 物体级信任域）**
直觉：v9 的域偏移 Δ_dom 是一个标量、慢变量；而一个陌生物体在**第一帧**就已经陌生。人类操作员看到从未见过的水壶时，不会等 20 帧才变谨慎。核心创新：**物体新颖度门控（ObjectNoveltyGate, ONG）**——冻结编码器 φ 给出物体嵌入，kNN 距离 ν(o) 给出单帧新颖度；用**按新颖度分层的保形预测**把 v9 的全局常数 β 升级为单调函数 β(ν)，域越陌生证书余量越大。K_eff 增加物体维门控：K_eff = min(K_eff^dom, K_eff^obj)，**只缩不放**。再加一个**物理一致性通道** ν_phys（首次接触后的力/滑移预测残差），专门捕捉"看起来熟、物理上生"的对抗物体。

**灵感 2（跨物体泛化 → 有界迁移而非仅弃权）**
直觉：只会"陌生就慢下来"的系统在竞赛里拿不到分。泛化的正面能力需要机制：同类物体共享可供性结构。核心创新：**类别-可供性迁移（CategoryAffordanceTransfer, CAT）**——每个类别 c 维护可供性原型 A_c（抓取位姿分布/接近方向/期望刚度），新物体按嵌入到原型的距离加权迁移，残差网络修正；迁移误差有 Lipschitz 界，界随 ν 增大而增大，正好与 β(ν) 对齐。

**灵感 3（机器人竞赛 → 计分调度与可证伪评估）**
直觉：竞赛不是演示，是**带时间预算和未知物体分布的分布外压力测试**。它同时施加两种压力：安全（0 碰撞/0 损坏）与得分（任务推进/时间）。核心创新：**竞赛计分调度器（CompetitionScoreGovernor, CSG）**——在"物体类别×任务"臂上做 UCB 探索/利用；探索新颖物体只在**低风险探针任务**里进行（K=1、限速、可随时停驻）。关键纪律：**P14 安全不可交易律**——CSG 的动作空间与安全参数（K_eff、限速、证书检查）不相交，任何得分策略都不能放宽安全门。配套 **泛化锦标赛协议（GTP）**：留出物体实例/类别，定义泛化差 G 与记忆化指标 M，竞赛前预注册。

**灵感 1×3 的耦合（本轮真正的锋利处）**
竞赛组织者会**故意**选择"嵌入近邻但物理属性对抗"的物体（透明杯、反光金属、可变形袋），这恰是视觉 ν 的假阴性区。因此单靠视觉新颖度不够，必须让物理残差通道在接触后**单步**接管，并让保形覆盖在交换性破裂时明确降级为保守证书——这正是本轮最大风险所在。

## 1. 研究问题（轮次升级版）

- **Q1（物体级滞后闭合）**：单帧物体新颖度 ν(o) 能否把 v9 中块中止的最坏检测滞后从 O(W=20 帧) 降到 O(1 帧)？视觉假阴性下，物理残差通道能否在接触后一个控制周期内补位？
- **Q2（物体条件证书）**：能否用分层保形预测给出随 ν 单调、在交换性下分布无关的误差界 β(ν)，使 K_eff 的物体门控是 v9 的**单调收缩**而非替换？
- **Q3（有界迁移）**：类别-可供性迁移的误差能否被 L_A·dist(φ(o), μ_c) 界定，并在 ν 超阈时退化为通用安全抓取而非错误迁移？
- **Q4（竞赛可证伪）**：计分调度能否在**不触碰安全门**的前提下提升竞赛得分？记忆化与泛化差如何被留出协议稳定检测？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 物体条件信任律（Object-Conditioned Trust, ONG）**
信任域从 U_t 扩展为 U_t^obj = U_t ∧ ν(o_t) < τ_nov ∧ 校准样本充足。ν(o) 由视觉与物理双通道取最大；任一通道不可用则按该通道的保守默认值处理，绝不默认"熟悉"。K_eff 增加物体门控且满足 K_eff^obj(t) ≤ K_eff^dom(t)（点态）。

**P14 安全不可交易律（Safety-Non-Tradable, CSG）**
计分调度器的动作空间禁止包含任何安全参数；禁止通过增大 K_eff、提高限速、跳过证书检查来"换分"。安全门在调度器之外、且在其上游。形式化为：对任意 CSG 策略 π，执行轨迹的 K_eff 与 v9 门控结果一致（当 CSG 失效时）。

**P15 迁移有界律（Bounded Affordance Transfer, CAT）**
类别迁移只在"到原型距离 × Lipschitz 常数 + 原型逼近误差 + 残差误差"不超过证书余量时启用；超过 τ_nov 或误差界不可证时退化为通用安全抓取（低速、正交接近、力闭环），而非强行使用类别先验。

**P16 竞赛可证伪律（Competition-Falsifiable, GTP）**
泛化结论必须在预注册的留出物体划分上报告：实例级留出与类别级留出分开；报告泛化差 G 与记忆化 M；任何未在留出集上验证的"泛化"只算叙事，不算证据。

## 3. 与基线的接口（如何退化）

- GTP 失效（无留出协议/无法评估）⇒ 只报告 v9 的在线指标，不改变运行行为；
- CSG 失效（调度异常/预算信号缺失）⇒ 固定利用策略（选当前最熟物体/最高分任务），行为等价 v9 任务选择；
- CAT 失效（原型缺失/迁移界不成立）⇒ 通用安全抓取，等价 v9 的原始抓取原语；
- ONG/保形校准失效 ⇒ ν≡0、τ_nov=∞、β(ν)≡β_v9，等价 v9 的域级门控；
- 再往下按 v9 五级链：AC→K=1、MW→手写网关、ID→全激活、DA/SPR/Cal→v7、全失效→v6。

## 4. 预期贡献

1. **物体级信任域与单帧新颖度**：把 v9 的滞后风险从"时间窗"转移到"物体身份"，给出 O(1) 检测滞后的机制性论证与假阴性兜底；
2. **物体条件保形证书 β(ν)**：误差界随新颖度单调、分层覆盖，K_eff 点态单调收缩，安全性可由 v9 引理 82 直接继承；
3. **有界类别-可供性迁移**：泛化从"弃权"升级为"有界外推"，迁移误差与证书余量同尺度对齐；
4. **安全不可交易的竞赛调度 + 可证伪评估协议**：计分与安全解耦，泛化差/记忆化可预注册、可复现；
5. **新实验族 E571–E590**：覆盖跨物体留出、对抗物体、保形覆盖、滞后对比、迁移界、竞赛计分、记忆化检测与端到端锦标赛。

## 5. 本轮最大风险

**一句话**：物体新颖度 ν 主要来自视觉嵌入，而竞赛最有杀伤力的恰恰是"外观近邻、物理对抗"的物体（透明/反光/可变形），视觉假阴性会让 β(ν) 在错误的小值上给出过窄证书——若物理残差通道在接触前不可用、接触后又晚于抓取闭合，那么"跨物体泛化"会在最需要保守的物体上表现得最自信。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-COGC**（Metric Voice Gauge with Object-Conditioned Certificates, Category Affordance Transfer & Competition Score Governance）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「机器人竞赛」×「跨物体泛化」
> **继承纪律**：v9 的 AC（分块证书）、MW（契约中间件）、ID（创新蒸馏）与 v8 的 DA-ML/SPR/Cal 全部保留。新组件一律为**可选安全增强**：任一环节不可用 ⇒ 注入中立元，逐级退回 v9→v8→v7→v6，而不是行为漂移。**物体级信任域只允许收缩 v9 的决策块长，不允许放宽任何既有安全门。**

**新增定义 540（物体嵌入与多通道新颖度 ObjectNovelty）** 设 φ: O→R^d 为冻结编码器，Z_ref={φ(o_i)} 为校准物体嵌入集，r_0 = Quantile_{0.95}({d_k(φ(o_i), Z_ref\{φ(o_i)\})})。定义
```
ν_vis(o) = d_k(φ(o), Z_ref) / r_0
ν_phys(o) = || ŵ(s, a) − w_obs || / σ_w      （首次接触后一个控制周期可用）
ν(o)     = max( {ν_vis(o)} ∪ {ν_phys(o) | 物理通道可用} )
```
视觉通道缺失时 ν_vis 取 +∞ 并强制 K_eff=1；物理通道在接触前不可用，此时证书额外增加接触余量 δ_phys（定义 542），而不是把 ν 虚高。**关键点**：ν_vis 是单帧量，不依赖时间窗；这使它能在物体替换的第一帧触发，而 v9 的 Δ_dom 需要 W=20 帧累积。

**新增定义 541（物体条件信任域与替换事件 ObjectTrustDomain）**
```
U_t^obj = U_t ∧ ν(o_t) < τ_nov ∧ n_{b(ν(o_t))} ≥ n_min
```
物体替换事件 E_sub(t)：ν_vis(o_t) 相对上一帧跳变 ≥ τ_swap，或接触残差 ν_phys ≥ τ_nov。命中 E_sub 即视为"域信任被单帧推翻"，无论 Δ_dom 当前读数如何，立即令 K_eff(t)=1 并进入保守抓取；这是对 v9 时间窗滞后的**前馈式补位**，而非替代品。

**新增定义 542（物体条件保形误差界 ObjectConditionalBound）** 将新颖度轴划为有序桶 B_0 < B_1 < … < B_m（按 ν 分位），在校准物体上记录非一致性分数 e_i = max_{k≤K} |F̂(s,a^{1:k}) − F(s,a^{1:k})|。对桶 b：
```
q̂_b  = EmpiricalQuantile( {e_i : b(ν(o_i)) = b}, ⌈(n_b+1)(1−α)⌉/n_b )
q̄_b  = max_{b' ≤ b} q̂_{b'}                       # 单调包络，只增不减
β(ν) = q̄_{b(ν)} + λ·ν + δ_phys·1[物理通道不可用]
```
当 n_b < n_min 时，退回全局分位 `q̄_global` 并额外加 `λ·(τ_nov−ν)` 保守项；若连全局校准都不可用，则 β≡β_v9（Level-3 退化）。β(·) 单调不减是**构造性**的，不是事后拟合。

**新增定义 543（物体条件块长 ObjectConditionedChunkLength）**
```
K_eff^obj(t) = 1                                                    若 ¬U_t^obj
             = max(1, ⌊K_max · (1 − ν(o_t)/τ_nov)⌋)                 否则
K_eff(t)     = min( K_eff^dom(t), K_eff^obj(t) )
```
其中 K_eff^dom 为 v9 定义 539。**点态单调**：K_eff^obj 与 K_eff^dom 都是 v9 上界的收缩，故 v10 的块长永远不长于 v9——物体门控只能让系统更保守。

**新增定义 544（类别-可供性迁移 CategoryAffordanceTransfer）** 类别集合 C，每类 c 维护原型 (μ_c, Σ_c) 与可供性映射 A_c: R^d→P(Grasp)（位姿、接近方向、力上限、期望刚度）。对物体 o：
```
d_c(o) = sqrt( (φ(o)−μ_c)^T Σ_c^{-1} (φ(o)−μ_c) )
w_c(o) = softmax_c( −d_c(o)^2 / (2σ_c^2) )
g(o)   = Σ_c w_c(o) · A_c( φ(o) − μ_c ) + r_θ( φ(o) )
```
残差 r_θ 离线训练、在线冻结。若 `L_A·min_c d_c(o) + ε_cat + ε_res > β(ν(o))`，P15 触发：禁用迁移，输出通用安全抓取 g_⊥（低速、正交接近、力闭环），其行为等价 v9 的原始抓取原语。

**新增定义 545（竞赛计分、预算与臂 CompetitionScore）**
```
J_comp = Σ_t [ progress_t · 1{success_t} − λ_T·Δt − λ_R·R_t ]，  s.t.  t ≤ B
```
任何安全违规（碰撞、超力、越界）使该次试验 J_comp := −∞（硬否决，不参与平均）。调度臂 a=(c,task)，奖励样本为一次完整任务的 J_comp。

**新增定义 546（安全不可交易约束 SafetyNonTradable）** 令 Θ_safe = {K_eff, v_max, cert_check, P_t} 为安全参数空间，A_csg 为 CSG 可选动作空间。要求
```
A_csg ∩ Θ_safe = ∅
∀π_csg:  K_eff_executed(t) = min(K_eff^dom(t), K_eff^obj(t))
```
即调度器**无法表示**"提高限速/延长块/跳过证书"这类动作。CSG 只能在 A_safe(t) = {a=(c,task) : ν(o_c)<τ_nov} ∪ ProbeTasks 上选择；ProbeTasks 预定义为 K=1、v≤v_probe、可随时停驻的低风险任务。

**新增定义 547（泛化锦标赛与记忆化 GeneralizationTournament）**
```
D_seen^inst, D_unseen^inst, D_unseen^cat      # 预注册划分
G = J(D_unseen) − J(D_seen)
M = max(0, J(D_seen) − J(D_unseen)) / max(ε, |J(D_seen)|)
```
通过判据：`G ≥ −ε_g ∧ M ≤ τ_mem ∧ 安全违规(D_unseen)=0`。协议由独立进程重放；划分哈希、判据与阈值在实验开始前写入只读清单，事后不得修改。

**新增定义 548（中立元退化表扩展 NeutralElementTable v10）** 在 v9 表 536 之上追加：
| 模块 | 中立元 v^⊥ | 等价退化级 |
|---|---|---|
| ONG 视觉通道 | ν_vis≡0 | Level-3（v9 域级门控） |
| ONG 物理通道 | ν_phys≡0 且 δ_phys=0 | Level-3 |
| 分层保形 | β(ν)≡β_v9、τ_nov=∞ | Level-3 |
| CAT | g(o)≡g_⊥ | Level-2（v9 原语） |

# IP-357 ObjectNoveltyGate：物体级信任域 + 分层保形证书
class ObjectNoveltyGate:
    def __init__(self, encoder, ref_embeddings, r0, tau_nov=1.0,
                 alpha=0.01, lam=0.05, delta_phys=0.02, n_min=30):
        self.phi, self.ref, self.r0 = encoder, ref_embeddings, r0
        self.tau_nov, self.alpha, self.lam = tau_nov, alpha, lam
        self.delta_phys, self.n_min = delta_phys, n_min
        self.bins = []                    # [(lo, hi)] 按 ν 分位
        self.qbar = []                    # 每桶单调包络后的分位

    def novelty(self, obs, contact_residual=None):
        z = self.phi(obs)                                  # 单帧嵌入
        nu_vis = self._knn(z, self.ref) / self.r0          # 定义 540
        if contact_residual is None:
            return nu_vis, "vis_only"
        nu_phys = contact_residual / self.sigma_w
        return max(nu_vis, nu_phys), "vis+phys"

    def beta(self, nu, phys_available):
        b = self._bucket(nu)                               # 定义 542
        if self.n[b] < self.n_min:
            base = self.q_global + self.lam * (self.tau_nov - nu)
        else:
            base = self.qbar[b]
        return base + self.lam * nu + (0.0 if phys_available else self.delta_phys)

    def trust(self, obs, delta_dom, tau_dom, risk_slam, tau_slam,
              contact_residual=None):
        nu, mode = self.novelty(obs, contact_residual)
        b = self._bucket(nu)
        trust = (delta_dom < tau_dom and risk_slam < tau_slam
                 and nu < self.tau_nov and self.n[b] >= self.n_min)
        return trust, nu, mode

    def fit_conformal(self, calib_objects, forward_errors):
        """离线：按 ν 分位划桶，算每桶 (1−α) 分位，再做单调包络。"""
        pairs = sorted(zip((self.novelty(o)[0] for o in calib_objects),
                           forward_errors))
        self._split_bins(pairs, target_per_bin=self.n_min)
        self.qbar = monotone_max([self._quantile(b, 1 - self.alpha)
                                  for b in self.bins])
        self.q_global = self._quantile(pairs, 1 - self.alpha)


# IP-358 CategoryAffordanceTransfer：有界可供性迁移
class CategoryAffordanceTransfer:
    def __init__(self, encoder, prototypes, residual, L_A, eps_cat, eps_res):
        self.phi = encoder; self.protos = prototypes     # {c: (mu, Sigma)}
        self.r = residual; self.L_A = L_A
        self.eps_cat, self.eps_res = eps_cat, eps_res

    def transfer(self, obs, beta_nu):
        z = self.phi(obs)
        ds = {c: mahalanobis(z, mu, Sigma)
              for c, (mu, Sigma) in self.protos.items()}
        dmin = min(ds.values())
        bound = self.L_A * dmin + self.eps_cat + self.eps_res   # 定义 544
        if bound > beta_nu:                                     # P15 触发
            return self.generic_safe_grasp(obs), bound, False
        w = softmax({c: -(d ** 2) / (2 * self.sigma_c ** 2)
                     for c, d in ds.items()})
        g = sum(w[c] * self.protos[c].A(z - self.protos[c].mu)
                for c in w) + self.r(z)
        return g, bound, True

## 4. 推导

**引理 87（物体门控的单调收缩与单帧滞后闭合）**
设 v9 的域级门控块长为 K_eff^dom(t)，物体级门控如定义 543。则：
(i) 对任意 t，K_eff(t) ≤ K_eff^dom(t)，故 v10 的决策粒度**永不粗于** v9，安全性可由 v9 引理 82 单调继承；
(ii) 若 t0 时刻发生物体替换且视觉通道可用、ν_vis(o_{t0}) ≥ τ_nov，则 K_eff(t0)=1；而 v9 的 Δ_dom 若要越过 τ_dom，至少需要 W 个连续帧的累积证据，故最坏检测滞后从 W−1 个周期降为 0；
(iii) 若视觉假阴性（ν_vis<τ_nov）但接触后物理残差 ν_phys ≥ τ_nov，则自接触后第一个控制周期起 K_eff=1，且中块守卫在同一个 50Hz 周期内可切换至 p* ∈ P_t，残余风险不超过一次抓取闭合时间。
证明：(i) 由 min 的定义；K_eff^obj 与 K_eff^dom 均以 v9 为上界。(ii) ν_vis 是单帧函数，不依赖历史；Δ_dom 的滑窗长度为 W=20（v8 定义），故证据累积的固有下限为 W−1。(iii) 接触残差在一次前向-观测比对后可用（定义 540）；守卫按定义 534 的停车不变式选择 p*，引理 82(ii) 保证停驻轨迹终点距障碍 ≥ d_safe。∎

**引理 88（分层保形覆盖与单调性）**
若校准物体与测试物体在每一新颖度桶内可交换（exchangeable），则对任意测试物体，
```
P( e ≤ β(ν(o)) ) ≥ 1 − α
```
且 β(ν) 关于 ν 单调不减。证明：桶内为标准的 split conformal，有限样本分位修正 ⌈(n_b+1)(1−α)⌉/n_b 给出桶内覆盖 ≥1−α；当 n_b<n_min 时退回全局分位并加保守项，覆盖只增不减。单调包络 q̄_b = max_{b'≤b} q̂_{b'} 只会放大阈值，故覆盖保持；λ·ν 与 δ_phys 均为非负项，故 β 单调不减。∎

**引理 89（类别-可供性迁移的误差界）**
设 A_c 关于嵌入满足 L_A-Lipschitz，类内原型逼近误差 ≤ ε_cat，残差网络误差 ≤ ε_res。则对任意物体 o，
```
|| g(o) − g*(o) || ≤ L_A · min_c d_c(o) + ε_cat + ε_res
```
当右端 > β(ν(o)) 时 P15 触发，迁移被禁用并输出通用安全抓取 g_⊥。证明：g 是 {A_c(φ(o)−μ_c)} 的凸组合（权重 w_c≥0、Σw_c=1）加残差；对每个 c，||A_c(φ(o)−μ_c) − A_c^*(φ(o))|| ≤ L_A·||φ(o)−μ_c||（Lipschitz）≤ L_A·d_c（Mahalanobis 与欧氏在 Σ_c 归一化下同阶）；取加权平均并用三角不等式得上界；g_⊥ 的选择由 P15 定义。∎

**引理 90（安全不可交易与有界遗憾）**
(i) 对任意 CSG 策略 π，执行轨迹的 K_eff 与 v9 的域级/物体级门控一致，故 v9 引理 82–86 全部成立，CSG 无法通过任何动作放宽安全门；
(ii) 在 A_safe(t) 上运行的 UCB 相对最佳固定安全臂的累积遗憾为 O(√(T log T))。
证明：(i) 由定义 546，A_csg ∩ Θ_safe=∅，且 K_eff_executed 由 min(K_eff^dom,K_eff^obj) 在调度器之外计算；安全门位于调度器上游，任何臂选择都不改变其输入。(ii) 标准 UCB 遗憾界（Auer et al. 2002），奖励有界且臂集稳定时成立；A_safe(t) 随时间单调收缩不影响上界。∎

**引理 91（v10 的中立元退化等价）**
将 ONG 置为 ν≡0、τ_nov=∞、β(ν)≡β_v9，CAT 置为 g≡g_⊥，CSG 置为固定利用策略，GTP 关闭，则对每个控制周期，v10 主闭环的端口读数与 v9 逐位一致。证明：逐行对照表 548。ONG 关闭后 K_eff^obj≡K_max，故 K_eff=min(K_eff^dom,K_max)=K_eff^dom；β 回到 v9 常数；CAT 关闭后输出 v9 原语；CSG 关闭后任务选择等价 v9；GTP 不进入闭环。故 v10 ⇒ v9。∎
