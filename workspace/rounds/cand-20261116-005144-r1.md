# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「参数高效微调」×「本体感知」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**冻结主干 + 低秩自适应 + 本体自模型**。两个灵感分别治 v9 的两种债：**适配债**（任何在线学习都动主干、无法逐位回滚、适配与安全证书相互污染）与**时延债**（v9 最大风险：DA-ML 的 20 帧滑窗在分布跳变时滞后，分块执行在最需要安全的时刻信任了已失效的证书）。硬约束：新模块一律中立元可退化；本体通道遵循**只收紧不放松**的单向安全律；所有安全信号锚定**冻结参考**，适配只作用于控制副本。

## 0. 直觉与动机

**灵感 1（参数高效微调 → 冻结主干上的低秩自适应）**
直觉：v9 的在线学习（OTL/DA/前向模型代理）一旦更新就动主干权重，"更新"与"安全证书"互相污染，且无法逐位回滚到基线。PEFT 的洞察不是"省参数"，而是"能力在冻结主干里，适配只加一个低秩增量"。核心创新：**低秩适配器库（LowRankAdapterBank, LRAB）**：W = W₀ + B A，rank r ≤ r_max，主干 W₀ 永久冻结；关闭残差分支时逐位等价 v9（ΔW=0 中立元）；每模块谱范数上界 ξ 把适配折算成"证书余量的确定性收紧"，而不是免费的午餐。安全关键模块（M₀、SpatialCert、FaultCert、MW、AC 证书检查、F̂₀ 证书模型、DA 检测特征 f₀）**无适配口**（φ^peft=false）。合并（merge）只允许发生在影子/回放通道，主控制路径保持"未合并残差"的可回滚形态。

**灵感 2（本体感知 → 动作条件化的快速身体自模型）**
直觉：v9 的安全信任域建立在外感知（DA 的视觉/语义特征漂移）上，而外感知恰在域跳变时最慢（20 帧滑窗）。本体感知不同：它由 **efference copy（发出的动作）** 因果驱动——"我命令关节这样动，身体实际这样动了吗？"残差 ε_prop 在 50–100Hz 可得、无需标签、与外感知域偏移解耦。核心创新：**本体感知自模型（ProprioceptiveSelfModel, PSM）**：以冻结参考自模型 G₀ 预测下一拍本体状态，残差作为**只收紧不放松**的旁路信任通道，直接补上 v9 的"DA 滞后"缺口。与 AC 结合：块证书增补本体预测轨迹 q̂₀^{1:K}，中块守卫变成"外感知间隙 + 本体执行一致性"双通道，任一通道越阈即中止。

**两者合起来看（不是拼接，而是双参考）**
直觉：PEFT 解决"怎么便宜地改"，本体感知解决"身体有没有照做"。但若让可适配模型去拟合安全残差，故障会被"学没"；若让适配器改掉 DA 的检测特征，域偏移会被"自适应没了"。因此本轮真正的耦合点是**双参考结构**：`G₀/f₀/F̂₀` 永久冻结、只用于安全判定；`G_ψ/f_ψ` 低秩适配、只用于控制预测与候选生成。安全归安全，适配归适配——**P15 冻结参考安全律**。这条约束让两个灵感互相加固，而不是互相污染。

## 1. 研究问题（轮次升级版）

- **Q1（低秩可回滚性）**：如何在冻结主干上加低秩增量，使 ΔW=0 逐位等价 v9、任意 ΔW≠0 的输出偏差被 ξ 确定性界定，且多适配器组合/路由不破坏安全证书？
- **Q2（本体信号的可判边界）**：本体残差在什么激励/可辨识条件下对执行异常有检验功效？它对哪类异常（作动器、碰撞、负载、磨损、传感器缺失）有效、对哪类（纯外感知域跳变）天然无效？准静态或 G₀ 失配时如何避免"残差小=安全"的静默失效？
- **Q3（单向融合与参考新鲜度）**：如何把本体通道并入信任域，使融合只可能收紧 K_eff、永不放松？冻结参考如何做新鲜度审计，避免"越适配越自信、越自信越盲"的安全-性能发散？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 冻结主干低秩律（Frozen-Backbone Low-Rank, LRAB）**
每可适配模块 W_m = W₀,m + B_m A_m，A_m ∈ R^{r×d_in}、B_m ∈ R^{d_out×r}，r ≤ r_max=4，主干 W₀,m 永久冻结。部署期校验 Σ_m r_m(d_in+d_out) ≤ N_peft（≤主干参数 1%）与逐模块谱界 ‖B_mA_m‖₂ ≤ ξ_m。关闭残差分支是**精确中立元**（逐位等价 v9）；A=B=0 的数值零矩阵因 IEEE `-0.0 + 0.0` 变号问题不作为精确回滚承诺。适配器不得进入安全信号路径（见 P15）。

**P14 本体单向信任律（Proprioceptive One-Sidedness, PSM）**
本体残差 ε_prop 由冻结参考 G₀ 计算（与适配参数无关）。本体门 g_prop ∈ {trust, shrink, unknown}：只有 `shrink`（ε_prop 越阈且 u_t 可辨识）能缩短 K_eff 或触发中止；`unknown`（低激励/传感器缺失）等价中立，绝不放宽外感知门；`trust` 也绝不把 K_eff 提到外感知门之上。形式化：K_eff(t) = min(K_eff^exo(t), K_eff^prop(t))，而 K_eff^prop ∈ {K_max，或按残差幅度连续缩短}。

**P15 冻结参考安全律（Frozen-Reference Safety, FRS）**
所有安全/检测信号（Δ_dom、risk_SLAM、ε_prop、块证书 Ĉ、停车不变式）一律在冻结参考（f₀、G₀、F̂₀）上计算；适配器（f_ψ、G_ψ、策略适配）只影响控制预测与候选取样，且策略输出必须投影回 F̂₀ 的信任域。推论：安全信号对适配参数偏导为零 ⇒ 在线适配**不可能**降低任何安全信号（无故障掩蔽、无检测器自毁）；适配只买性能，不买安全。

## 3. 与基线的接口（如何退化）

- 本体通道失效（低激励 u_t<u_min / 编码器或 IMU 缺失 / G₀ 失配告警）⇒ ε_prop≡⊥，K_eff^prop≡K_max，主闭环逐位回到 v9 单通道门控；
- 低秩通道失效（适配器越界 / 合并证书过期 / 影子更新失败）⇒ 关闭残差分支，ΔW≡0，逐位等价 v9 冻结主干；
- AC 失效 ⇒ K_eff←1，逐步执行，等价 v9/v8 决策粒度；
- MW 失效 ⇒ 切回 v8 手写网关代码路径（代码保留）；
- ID 失效 ⇒ 全模块 active、归因冻结，等价 v8 全模块常开；
- v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-OTL-GC-ER v7，再退回 v6。

## 4. 预期贡献

1. **可回滚低秩适配**：冻结主干 + 谱界证书 + 分支取消式精确中立元，使"在线适配"第一次同时满足可回滚、可界定、可与安全证书共存；
2. **本体单向信任通道**：把 v9 的 20 帧外感知滞后，在"执行偏差类"异常上压缩到 1–2 拍（20–40ms），并用单向融合保证不比 v9 更危险；
3. **冻结参考安全律**：安全信号与适配参数彻底解耦，给出"适配不可能掩蔽检测"的不可逆代数论证；同时把"参考新鲜度"显式列为可监测对象；
4. **诚实的能力边界**：E576（低激励盲区）与 E589（纯外感知域跳变负面实验）主动证伪"本体万能论"；E571–E590 覆盖中立性、谱界、组合干扰、检测时延、防掩蔽、参考漂移与端到端。

## 5. 本轮最大风险

**一句话**：冻结参考安全律把"适配"与"安全"解耦得太干净，以致适配器让控制越来越顺、而冻结的 G₀/f₀ 可能先于身体与域过时，ε_prop 与 Δ_dom 同步变钝；更危险的是本体残差对纯外感知域跳变天然无响应，系统可能把"身体照做了"误读成"世界如证书所预测"，即**越适配越自信、越自信越盲**。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-PALM**（Proprioceptive-Anchored Low-rank adaptation & Motor self-model）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「参数高效微调」×「本体感知」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 全部保留。新组件一律为**可选增强 + 中立元可退化**；本轮新增更高优先级约束——**安全信号只读冻结参考，适配只写控制副本**（P15）。任一环节不可用 ⇒ 逐位退回 v9，再退回 v8/v7/v6。

## 1. 符号体系增量（定义 540–548）

| 符号 | 含义 |
|---|---|
| q_t ∈ R^{d_q} | 本体观测：关节位置/速度、力矩/电流、接触、IMU；d_q≈40 |
| a_t | efference copy：本拍实际下发的动作（控制自模型的因果输入） |
| G₀, G_ψ | 冻结参考自模型（安全）与低秩适配自模型（控制）；G_ψ = G₀ + ΔG |
| q̂₀,t | G₀ 预测的本体状态，q̂₀,t = G₀(q_{t−1}, a_{t−1}) |
| ε_prop(t) | 本体残差（标准化 Mahalanobis）：‖q_t − q̂₀,t‖_{Σ⁻¹} |
| u_t ∈ [0,1] | 激励/可辨识置信：回归器最小特征值代理，非"安全概率" |
| τ_prop | 本体残差阈值；u_t < u_min 时门不可判 |
| g_prop | 本体门 ∈ {trust, shrink, unknown}（单向） |
| K_eff^prop, K_eff | 本体门控块长与融合块长（定义 543/544） |
| ΔW_m = B_m A_m | 低秩适配增量；r_m = rank，ξ_m = 谱界 |
| N_peft | 全系统可训练参数预算（≤主干参数 1%） |
| M_m | 合并证书 MergeCert（ξ_ok, δ_fp, δ_task, TTL） |
| ρ_ij | 适配器相干度 ‖(B_iA_i)ᵀ(B_jA_j)‖₂（组合干扰） |

**新增定义 540（本体观测与 efference copy）** q_t 为全部本体通道的拼接向量；a_t 为控制回路实际下发的动作（不是规划意图）。对 (q_t, a_t) 做时间对齐（≤1 个控制周期）后，本体残差才具有因果解释；对齐误差计入 τ_prop 的保守余量。本体观测不依赖外感知标签，故其残差可在无监督下逐拍计算。

**新增定义 541（身体自模型与残差）** 双自模型：
```
q̂₀,t = G₀(q_{t−1}, a_{t−1})                 # 冻结参考，安全残差专用
q̂ψ,t = G_ψ(q_{t−1}, a_{t−1})                # 低秩适配，控制预测专用
ε_prop(t) = sqrt( (q_t − q̂₀,t)ᵀ Σ⁻¹ (q_t − q̂₀,t) ) / s_nom
```
Σ 与 s_nom 由标定期名义残差估计；G₀ 永不更新，G_ψ 仅经 LRAB 更新。安全残差与适配参数严格解耦（P15）。

**新增定义 542（激励可辨识置信）** 设回归窗口 Φ_t = [φ(q_{t−k}, a_{t−k})]_{k=1..w}，φ 为自模型对故障参数的灵敏度特征。定义
```
u_t = 1[sensor_ok] · sigmoid( (λ_min(Φ_tᵀΦ_t / w) − λ₀) / s_λ )
```
u_t 衡量"当前运动是否足以把故障从模型误差中区分出来"，**不是**安全概率。准静态、匀速、少接触时 u_t→0，此时本体检验无功效，必须标 unknown。持续激励（persistent excitation）是本体可判性的硬前提。

**新增定义 543（本体单向信任门）** 
```
g_prop = unknown   若 ¬sensor_ok ∨ u_t < u_min
       = shrink    若 ε_prop > τ_prop
       = trust     若 ε_prop ≤ τ_prop
K_eff^prop = K_max                         若 g_prop = unknown ∨ trust
           = max(1, ⌊K_exo·(1 − ρ)⌋)       若 g_prop = shrink
ρ = min(1, (ε_prop − τ_prop)/τ_prop)        # 残差越大，块越短
```
注意 K_eff^prop 的上界恒为 K_exo 或 K_max，因此本体通道**不可能**把块长提到外感知门之上。

**新增定义 544（融合有效块长）**
```
K_eff(t) = min( K_eff^exo(t), K_eff^prop(t) )
```
当本体不可判时 K_eff^prop=K_max，融合退化为 v9：`K_eff = K_eff^exo`（逐位等价）。当本体可判且越阈时，融合严格收紧。该定义是引理 89（单向安全单调）的算术语义。

**新增定义 545（低秩适配器与秩预算）** 对可适配模块 m：
```
W_m = W₀,m + B_m A_m,   A_m ∈ R^{r_m×d_in}, B_m ∈ R^{d_out×r_m}
r_m ≤ r_max = 4
N_peft = Σ_m r_m(d_in^(m)+d_out^(m)) ≤ 0.01·|W₀|
```
可适配集合 = {策略候选生成器、G_ψ、奖励/情感映射的轻量头、感知特征的控制副本 f_ψ}；不可适配集合 = {M₀ 硬检查、SpatialCert、FaultCert、MW、AC 证书检查、F̂₀ 证书模型、DA 检测特征 f₀、G₀}。后者 φ^peft=false，部署期静态拒绝任何适配口。

**新增定义 546（适配器中立性与谱偏差证书）** 关闭残差分支（不执行 BA 路径）⇒ y = W₀x，逐位等价 v9（引理 87）。启用时对任意 ‖x‖≤X：
```
‖y − W₀x‖₂ = ‖B A x‖₂ ≤ ‖BA‖₂‖x‖₂ ≤ ξ_m X
```
若证书使用冻结 F̂₀，适配策略的输出必须投影回 F̂₀ 的信任域半径 R_trust（引理 88 路径 b）；若改用适配 F̂_ψ 出证书，则余量必须追加 ξ_F。两条路径择一，默认路径 b（更安全）。数值注意：A=B=0 时 IEEE 的 `-0.0 + 0.0 = +0.0` 会改变符号位，故精确回滚只承诺"分支关闭"，不承诺"零矩阵合并"。

**新增定义 547（合并证书）** 
```
MergeCert(m) = ( ‖BA‖₂ ≤ ξ_m,
                 max_{(x,y)∈D_cal} ‖merge(W₀,BA)x − (W₀x + (BA)x)‖∞ ≤ δ_fp,
                 task_regression(D_held) ≤ δ_task,
                 age ≤ TTL )
```
证书有效只允许在**影子/回放通道**使用合并权重；主控制路径始终保留未合并残差，以便随时 `ΔW←0` 精确回滚。证书过期或任一失败 ⇒ 强制 unmerge，记 Level-2 退化。

**新增定义 548（适配器路由与组合干扰界）** 默认硬路由：每模块每回合**恰好激活一个**适配器，行为集合为 {W₀, W₀+ΔW_i}，逐项独立认证。允许软组合仅当：
```
Σ_i ξ_i ≤ ξ_Σ,max   且   max_{i≠j} ρ_ij ≤ ρ_max
```
此时组合偏差界为 ‖Σ_i ΔW_i x‖ ≤ (Σ_i ξ_i)‖x‖，证书按 Σξ 收紧；否则拒绝组合、退回硬路由。该界对逐层非线性适配器需用 Lipschitz 常数复合形式（附录）。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变；其轻量映射头可经 LRAB 适配，但情感安全阈值的判定仍用冻结映射。
**定义 521（DA-OTL）** 继承 v9 不变；Δ_dom 仍由冻结特征 f₀ 计算，`f_ψ` 的适配不进入检测路径（P15）。

**升级定义 496（软证书，v10）** 
```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
              ∧ risk_SLAM < τ_SLAM ∧ Ĉ_t valid
              ∧ (g_prop ≠ shrink) }
```
最后一项是**单向**的：本体 unknown 时该条件自动为真（不放松也不额外收紧）；本体 shrink 时直接触发 M₀ 硬检查。避免"本体安静 = 世界安全"的误读。

**升级定义 531（软硬约束衔接，v10）** M₀ 判据增加两类块级入口：(i) 外感知中块违规；(ii) 本体执行不一致（g_prop=shrink）。任一发生 ⇒ 立即切换最近中止点 p* 或安全停驻，不等块边界。

**升级定义 533（块证书，v10）** 
```
Ĉ_t = ( ĝ_min, ê_max, γ̂_grasp, q̂₀^{1:K} )
q̂₀^{k} = G₀(q̂₀^{k−1}, a^{k−1})     # 冻结参考的本体预测轨迹
```
证书有效性额外要求：q̂₀^{1:K} 与当前本体状态一致（‖q̂₀^{1} − q_t‖ ≤ δ_align），否则块在生成阶段即被拒绝（efference-copy 对齐失败）。证书仍用冻结 F̂₀ 计算；适配策略候选须投影进 F̂₀ 信任域。

**升级定义 534（中止点与停车不变式，v10）** 停车不变式不变；新增本体中止触发：若 g_prop=shrink，则切换到 ≤ 当前执行步的最大 p* ∈ P_t；若 P_t 为空（只可能发生在 K=1 fallback），执行 a^⊥ 安全停驻。

**升级定义 539（有效块长门控，v10）** 外感知门 K_eff^exo 保持 v9 定义；最终 K_eff = min(K_eff^exo, K_eff^prop)（定义 544）。当本体 unknown 时逐位退化为 v9。

# IP-357 低秩适配器：冻结主干 + 分支取消式中立元
class LowRankAdapter:
    def __init__(self, W0, r=4, xi=0.02):
        self.W0 = freeze(W0)                 # 永不更新
        self.A = zeros(r, W0.in_dim)         # 仅这两项可训练
        self.B = zeros(W0.out_dim, r)
        self.xi, self.enabled = xi, False

    def disable(self):
        self.enabled = False                 # 残差分支不执行（精确中立，引理 87）

    def __call__(self, x):
        y0 = self.W0(x)
        if not self.enabled:
            return y0                        # 逐位等价 v9
        dW = self.B @ self.A
        assert spectral_norm(dW) <= self.xi + 1e-9
        return y0 + dW @ x                   # 偏差 ≤ ξ‖x‖（引理 88）

    def merge_certificate(self, calib_io, held_out, delta_fp, delta_task, ttl):
        dW = self.B @ self.A
        if spectral_norm(dW) > self.xi:
            return False
        dev = max(max_abs(merge(self.W0, dW)(x) - (self.W0(x) + dW @ x))
                  for x, _ in calib_io)
        return dev <= delta_fp and self.task_regression(held_out) <= delta_task


# IP-358 本体自模型：安全残差只用冻结 G0，适配只改控制副本 Gψ
class ProprioceptiveSelfModel:
    def __init__(self, G0, adapter, tau_prop=3.0, u_min=0.1,
                 lam0=1e-2, s_lam=1e-2):
        self.G0 = freeze(G0)                 # 安全参考，永不更新
        self.Gpsi = LowRankAdapter(G0)       # 控制预测副本
        self.Sigma_inv, self.s_nom = None, 1.0
        self.tau_prop, self.u_min = tau_prop, u_min
        self.lam0, self.s_lam = lam0, s_lam

    def residual(self, q_prev, a_prev, q_now):
        q_hat0 = self.G0(q_prev, a_prev)     # 安全残差与适配参数无关（P15）
        d = q_now - q_hat0
        return sqrt(d @ self.Sigma_inv @ d) / self.s_nom

    def excitation(self, regressor_window, sensor_ok):
        if not sensor_ok:
            return 0.0
        lam_min = min_eig(regressor_window.T @ regressor_window / len(regressor_window))
        return sigmoid((lam_min - self.lam0) / self.s_lam)

    def gate(self, eps_prop, u_t, sensor_ok, K_exo):
        if (not sensor_ok) or u_t < self.u_min:
            return 'unknown', K_exo                 # 中立，不放松
        if eps_prop <= self.tau_prop:
            return 'trust', K_exo                   # 不放松
        rho = min(1.0, (eps_prop - self.tau_prop) / self.tau_prop)
        return 'shrink', max(1, int(K_exo * (1 - rho)))


# IP-359 本体分块守卫：双通道 + 单向融合
class ProprioceptiveChunkGuard:
    def fused_K(self, K_exo, eps_prop, u_t, sensor_ok):
        g, K_prop = self.psm.gate(eps_prop, u_t, sensor_ok, K_exo)
        return g, min(K_exo, K_prop)                # 定义 544

    def midchunk_guard(self, chunk, k, live_obs, prop):
        verdict, k_next = super().midchunk_guard(chunk, k, live_obs)  # v9 外感知
        if verdict == 'abort':
            return verdict, k_next
        if prop.gate == 'shrink':                   # 本体执行不一致（只收紧）
            return 'abort', self._nearest_abort(chunk, k)
        if not self._efference_aligned(chunk, k, prop.q_now):
            return 'abort', self._nearest_abort(chunk, k)
        return 'continue', k + 1

    def _efference_aligned(self, chunk, k, q_now):
        return norm(q_now - chunk.q_hat0[k]) <= chunk.delta_align


# 主闭环集成：MetricVoiceGauge-PALM

## 4. 推导

**引理 87（低秩中立与精确回滚）** 设主干 W₀ 冻结且适配残差以"分支取消"实现（enabled=False 时不执行 BA 路径）。则任意输入 x 有 y=W₀x，与 v9 逐位一致。若以 A=B=0 的数值零矩阵走合并路径，则因 IEEE 754 中 `-0.0 + 0.0 = +0.0`，负零输入的符号位可能改变，故不承诺逐位等价。影子通道的合并只承诺定义 547 的 δ_fp/δ_task 界，不承诺逐位等价。∎

**引理 88（适配偏差与证书收紧）** 设 ‖BA‖₂ ≤ ξ_m，输入 ‖x‖≤X，则 ‖(W₀+BA)x − W₀x‖ ≤ ξ_m X。两条证书路径：(a) 用适配 F̂_ψ 出证书时，余量取 β' = β + ξ_F，由三角不等式保持证书保守；(b) 默认路径，证书用冻结 F̂₀，但策略候选必须满足 ‖a − Proj_{T(F̂₀)}(a)‖=0（投影进 F̂₀ 信任域半径 R_trust），故 F̂₀ 的误差界 β 不被适配破坏。两条路径均不产生"适配免费提升安全"的结论。∎

**引理 89（单向融合与安全单调性）** 在假设 A1（块长缩短后重新生成块；P_t 非空或退回 K=1 安全停驻）下，v10 接受块集合 A₁₀ = A₉ ∩ {g_prop ≠ shrink} ∩ {K_eff ≤ K_eff^exo} ⊆ A₉。因此 v9 上成立的安全性质在 v10 上仍成立：本体通道只可能收紧、不可能放松。特别地，u_t<u_min 时 K_eff^prop=K_max，A₁₀=A₉（逐位退化）。∎

**引理 90（激励可辨识边界）** 设故障参数 δθ 产生本体残差的一阶近似为 ε_prop ≈ ‖Φ_tᵀ δθ‖。若 λ_min(Φ_tᵀΦ_t/w) < λ₀，则存在非零 δθ 使全窗残差 ≤ τ_prop：此时"残差小"不能推出"无故障"，本体检验无功效。故 u_t<u_min 必须判 unknown 而非 trust；这是定义 542/543 的必要性证明，也界定了本体感知的能力边界。∎

**引理 91（冻结参考防掩蔽）** 安全残差 ε_prop = ‖q−G₀(q₋,a₋)‖_{Σ⁻¹} 不含适配参数 ψ；Δ_dom 由冻结 f₀ 计算；块证书由冻结 F̂₀ 计算。故 ∂ε_prop/∂ψ = ∂Δ_dom/∂ψ = ∂Ĉ/∂ψ = 0。任何在线适配（含恶意或被故障数据污染的适配）都不能降低安全信号；适配只能改变控制预测与候选分布，且候选受信任域投影约束。推论：不存在"把故障学没"的适配路径。∎

**引理 92（本体时延优势与其边界）** 设外感知检测时延 L_dom=20 拍（400ms），本体检测时延 L_prop=1–2 拍（20–40ms）。对**在执行层可观测**的异常（作动器故障、碰撞、负载突变、编码器漂移），v10 的最早中止时刻 ≤ L_prop + 守卫开销，显著早于 v9 的 L_dom。对**纯外感知域跳变**（光照、新物体、同类新实例），本体残差无响应，L_prop 无定义，v10 不优于 v9——这是能力边界而非缺陷，必须由 E589 显式验证。∎

**引理 93（适配器组合干扰界）** 硬路由下行为集合有限且逐项认证，无组合干扰。软组合下 ‖Σ_i ΔW_i x‖ ≤ (Σ_i ξ_i)‖x‖；若进一步要求两两相干 ρ_ij ≤ ρ_max，则组合后的有效秩与谱界可由 Σξ + (k−1)ρ_max 控制。超过预算即拒绝组合、退回硬路由（定义 548）。非线性逐层适配器以局部 Lipschitz 常数替换 ξ_i 后同式成立。∎

## 8. 本轮最大风险

**一句话**：冻结参考安全律把"适配"与"安全"解耦得太干净，以致适配器让控制越来越顺、而冻结的 G₀/f₀ 可能先于身体与域过时，ε_prop 与 Δ_dom 同步变钝；更危险的是本体残差对纯外感知域跳变天然无响应，系统可能把"身体照做了"误读成"世界如证书所预测"，即**越适配越自信、越自信越盲**。
