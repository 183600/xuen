# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「三维感知」×「评测基准」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**视域健全 + 基准保真**。两个灵感分别治理 v9 的两笔暗债：**空间债**（δ_trigger 与块证书里的 clearance 仍是"到最近障碍的标量距离"，把三维几何压成一维，无法区分"可通行"与"被围死"、更无法区分"已知自由"与"根本没看见"）、**证据债**（E551–E570 多为一次性组件实验，缺少污染隔离、置信区间与抗退化基线，"0 碰撞"不等于"健全率可证"）。任何新模块仍须经中立元严格退化回 v9；但须诚实声明：退化保证**行为等价**，不保证**安全等价**——v10 的三维约束是相对 v9 的单调增强，丢掉它即退回 v9 的已知威胁模型（遮挡盲区），必须同时记入日志与风险。

## 0. 直觉与动机

**灵感 1（三维感知 → 从标量间隙到扫掠体双间隙证书）**
直觉：v9 的块证书回答"离最近障碍多远"，却不回答三个更要命的问题：(a) 这段轨迹扫过的**三维体积**里有没有障碍（标量最近距离可能来自侧后方一个与路径无关的障碍，既保守又误导）；(b) 扫掠体里有多少是**根本没观测到**的空间——未知不是自由，遮挡背后可能正藏着障碍；(c) 到站后是否**被围死**（间隙足够但四壁合拢，无逃逸方向）。核心创新：**扫掠体三值证书器（SweptVolumeCertifier, SVC）**：占据图三值化 {FREE, UNK, OCC}，证书从标量 ĝ_min 升级为双间隙 Ĉ^{3D}=(g_B, g_X, ê_max, γ̂_grasp, ℓ)——g_B 为扫掠体到 OCC 的最小 ESDF，g_X 为**刹车包络内**到 UNK 的最小距离（未知在刹车距离内一律视为占据）。附带 **逃逸/活性证书 ℓ**（安全与活性分离：不可用活性换安全，只可用安全换活性）。再加 **主动感知规划器（APP）**：在证书安全集内选信息增益最大的块，让"看哪里"也进入决策。

**灵感 2（评测基准 → 证书健全率基准与污染隔离）**
直觉：v9 用"中止成功率 ≥99%、0 碰撞"证明安全，但这是**点估计且无对照**：若策略学会"永远急停"，安全率 100% 而任务全废；若测试场景与 β 标定场景同源，"0 碰撞"只是过拟合。严谨的安全主张必须给出**健全率的下置信界**，并同时报告**可用率**与**紧致度**，否则"安全"可以靠不作为刷出来。核心创新：**证书基准（CertificateBench, CB）**：以 (Soundness, Coverage, Tightness, Utility) 四元组 + Wilson 下界为主指标；校准/验证/测试三段隔离、测试集封存且预注册；内建抗退化基线（always-abort / always-continue / random）与判别力检验（若 always-abort 得分高则基准失效）；配套**证书回放**（离线按日志逐条复验证书）与**影子基准监控**（在线低成本回放封存小场景，检测健全率漂移）。

## 1. 研究问题（轮次升级版）

- **Q1（三维健全性）**：在"占据图无假自由 + 未知在刹车包络内视为占据"假设下，扫掠体双间隙证书能否给出与逐步执行同阶的碰撞界？遮挡导致 UNK→FREE 的误判率如何进入该界？
- **Q2（安全/活性可分）**：如何把"停得下来"（安全）与"走得出去/看得见"（活性/认知）形式化为两类独立证书，使策略无法用牺牲活性换取虚高的安全指标，也无法用探索换取碰撞风险？
- **Q3（基准可证性）**：给定样本数 n 与观测失败数，健全率 S 的下置信界如何决定"可以宣称多安全"？如何用污染隔离、封存测试与抗退化基线防止基准被策略"刷分"？

## 2. 设计原则（新增 P13–P14）

**P13 视域健全律（Fov-Sound Certificate, FV）**
证书必须在**三维扫掠体**上成立，且显式区分三值占据：安全证书 S3D = (g_B ≥ d_safe) ∧ (g_X ≥ d_safe on braking envelope)，其中未知在刹车包络内视同占据；活性证书 ℓ 独立报告逃逸锥立体角与可观测自由体积。安全与活性**不可互换**：安全不达标则拒绝块，活性不达标仅降评分；绝不因活性牺牲安全，也绝不用"停住不动"冒充安全达标（由可用率与任务效用反向约束）。

**P14 基准保真律（Benchmark Fidelity, BF）**
任何安全/性能主张必须由**预注册、污染隔离、可回放**的基准给出：报告健全率 S 的 Wilson 下界而非点估计，同时报告覆盖 C、紧致 T、效用 U 与 Pareto 前沿；测试集封存且只评一次；必须击败 always-abort / always-continue / random 三类退化基线，否则判定基准失效而非系统有效。

## 3. 与基线的接口（如何退化）

- SVC/三维感知不可用（占据图过期、ESDF 超时）⇒ 注入中立元（空附加约束）⇒ 退回 v9 标量证书，**行为等价 v9**；注意这是**行为等价而非安全等价**，安全性回落到 v9 已知威胁模型（遮挡盲区），须记入日志；
- APP 不可用 ⇒ 候选选择退回 v9 评分 argmax，等价 v9；
- CB 不可用 ⇒ 离线评测缺失，运行期不变（CB 永不 gate 实时闭环）；
- 影子监控（SBM）超时/不可用 ⇒ 跳过本回合（中立元），运行期等价 v9；
- 其余层级沿 v9：AC 失效⇒K=1（v8）；MW 失效⇒手写网关（v8）；ID 失效⇒全激活（v8）；DA/SPR/Cal 失效⇒v7；全失效⇒v7→v6。

## 4. 预期贡献

1. **扫掠体三值证书**：把 clearance 从标量升级为"对 OCC 的距离 + 对 UNK 的刹车包络约束"，并证明"未知即自由"在任何有限 d_safe 下都不可能健全（引理 88）——为三维感知的必要性给出不可能性论证；
2. **安全/活性分离**：逃逸锥与信息增益作为独立于安全的活性维度，堵住"以停代安"的指标漏洞；
3. **可证基准**：健全率下界 + 污染隔离 + 抗退化基线 + 证书回放，把"0 碰撞"升级为"可宣称的安全水平"；
4. **E571–E590** 覆盖遮挡注入、未知误判、逃逸陷阱、主动感知、健全率/覆盖/紧致 Pareto、样本量与置信界、回放一致性、影子漂移与封存测试。

## 5. 本轮最大风险

**一句话**：三维证书的健全性建立在"占据图不把未知误标为自由"这一前提上，而遮挡、薄障碍漏检、动态物体与地图过期恰恰使**即将被扫掠的空间**成为最易被误标为 FREE 的地方——证书在最该怀疑的位置最自信，且若封存基准与部署共享同一遮挡分布偏差，健全率下界会把盲区系统性漏检为"已验证安全"。

**新增定义 540（三值占据图 TrichotomyOccupancy）** 占据图 O_t: Z³→{FREE,UNK,OCC}。F_t={ℓ=FREE}，X_t={ℓ=UNK}，B_t={ℓ=OCC}。**无假自由假设 A_ff**：ℓ(v)=FREE ⇒ v 实际可通行。地图龄期 τ_map = t − t_last_update(v)；τ_map>T_stale（默认 1.5s）的体素强制降为 UNK。遮挡（ray-casting 未穿透）、薄障碍漏检、动态物体与传感器盲区是 A_ff 的主要违反源。

**新增定义 541（三维扫掠体 SweptVolume）** 相邻位姿 s_{k−1},s_k 的扫掠为凸包 Conv(R(s_{k−1}),R(s_k))（纯平移精确；含旋转时用包围球保守放大），外扩 d_safe：
```
V_{1:K} = ( ⋃_{k=1}^{K} Conv(R(s_{k−1}), R(s_k)) ) ⊕ B(d_safe)
```
`⊕B` 为 Minkowski 膨胀。

**新增定义 542（双间隙安全证书 BiClearanceCertificate）**
```
g_B = min_{x∈V_{1:K}} d_B(x),   g_X = min_{x∈W_K} d_X(x)
S3D(ζ) 成立 ⇔ g_B ≥ d_safe ∧ g_X ≥ d_safe ∧ ê_max ≤ τ_eff ∧ γ̂_grasp = valid
```
`g_X` 在**刹车包络** W_K 上取最小：未知只要可能被刹车轨迹触达，就必须先被看见或被排除。注意 V_{1:K}⊆W_K，故 epistemic 约束严格强于几何约束。

**新增定义 543（刹车包络 BrakingEnvelope）** 从任一步 s_k 以最大减速度 a_brake 制动至停的轨迹扫掠 Brake(s_k)，W_K=⋃_{k≤K}(V_{1:k}∪Brake(s_k))。刹车距离 d_brake(v)=v²/(2a_brake)+v·t_react。

**新增定义 544（逃逸锥与活性证书 EscapeCone & Liveness）**
```
E(s_K) = { u ∈ S² : ∠(u, v_K) ≤ θ_esc ∧
          Conv(R(s_K), R(s_K)+u·(d_brake(v_K)+d_safe)) ⊕ B(d_safe) ∩ B_t = ∅ }
ℓ(ζ) = solidangle(E(s_K)) / (2π)        （E=∅ ⇒ ℓ=0，记 "dead-end"）
```
ℓ 只降评分、不否决安全：ℓ=0 的块仍可安全停驻，但被标记为"活性不足"，触发反向/换向候选优先级。此定义是 P13"安全/活性不可互换"的形式化落点。

**新增定义 545（主动感知信息增益 ActivePerceptionGain）**
```
IG(ζ) = H( X_t ∩ W_K ) − E_{obs|ζ}[ H( X_t ∩ W_K | obs ) ]
```
实现上用"未来传感器视锥内未知体素占比 × 期望清除率"近似；APP 仅在 S3D 安全集内 argmax `w_t·task + w_l·ℓ + w_i·IG`，且 w_i 只在安全集非空时生效。安全集为空 ⇒ 走 K=1 fallback，不做"为看清而冒进"。

**新增定义 546（证书基准四元组 CertificateBench Quad）** 对封存测试集上的每个候选块/时刻统计：
```
S = 1 − (#{证书有效 ∧ 实际不安全}) / #{证书有效}     （健全率）
C = #{证书有效} / #{候选块}                          （覆盖率/可用率）
T = E[ (g_B^cert − g_B^true) / max(g_B^true, ε) ]     （紧致度，越小越紧）
U = 任务进展 / 时间                                  （效用）
S_LCB = Wilson_{1−α}(成功数=#{有效且安全}, n=#{证书有效})
```
主报告是 (S_LCB, C, T, U) 与 S–C–U 的 Pareto 前沿；禁止用单一标量把安全-效用权衡藏起来。

**新增定义 547（污染隔离与预注册 ContaminationIsolation）** 数据三段互斥：D_cal（标定 β、τ、阈值）、D_val（选模型/调参）、D_test（封存，冻结 F̂/β/阈值并记哈希后**只评一次**）。回放管线确定性（固定种子、固定浮点顺序、固定版本）。污染审计：报告 D_test 与 D_cal 的分布距离与最近邻重合率；任何在 D_test 上的重复调参即判污染，结果作废。

**新增定义 548（抗退化基线与判别力 AntiGamingBaseline）** 基准必须同时跑 π_abort（永远急停）、π_cont（永远继续）、π_rand（随机停/走）与 v8/v9 基线。要求：π_abort 的 U 低于任务门槛（安全但无用不得高分）；判别力 D_auc = AUROC(证书预测"安全" ↔ 实际安全) ≥ 0.8；若 π_abort 或 π_cont 在某指标上"最优"，判基准失效，先修指标再评系统。

**新增定义 549（证书回放与影子监控 CertificateReplay & ShadowMonitor）** 日志记录 (s_t, ζ_t, Ĉ_t^{3D}, obs, τ_map)；离线回放按真值占据重算每条证书的 (有效, 实际安全)，得到 S/C/T（定义 546）。影子监控每 M_sbm 周期在沙箱回放 B_sbm 个封存小场景，估计当前 F̂/β 的 S_LCB；若 S_LCB < 1−ε_s 则（仅）触发 β 重标定、K_max 收缩与告警，绝不直接改写真实控制指令。

# IP-357 SweptVolumeCertifier：扫掠体三值证书器
class SweptVolumeCertifier:
    def __init__(self, map3d, esdf, K_max=10, d_safe=0.15,
                 a_brake=2.0, t_react=0.08, theta_esc=1.0,
                 n_checkpoints=4, T_stale=1.5):
        self.map, self.esdf = map3d, esdf
        self.K_max, self.d_safe = K_max, d_safe
        self.a_brake, self.t_react, self.theta_esc = a_brake, t_react, theta_esc
        self.n_cp, self.T_stale = n_checkpoints, T_stale

    def _d_brake(self, v):
        return v * v / (2 * self.a_brake) + v * self.t_react

    def _swept(self, poses):
        vols = []
        for a, b in zip(poses[:-1], poses[1:]):
            vols.append(conv_hull(robot_volume(a), robot_volume(b)))
        return inflate(union(vols), self.d_safe)

    def _braking_envelope(self, poses, speeds):
        V = self._swept(poses)
        for s, v in zip(poses, speeds):
            V = union(V, inflate(self._swept(brake_traj(s, v, self.a_brake,
                                                         self.t_react)),
                                  self.d_safe))
        return V

    def _escape_cone(self, s_K, v_K, occ):
        if v_K < 1e-3:
            return 1.0
        u_ok = 0
        for u in sphere_samples(256):
            if angle(u, v_K) > self.theta_esc:
                continue
            path = [s_K, s_K + u * (self._d_brake(v_K) + self.d_safe)]
            if not intersects(self._swept(path), occ):
                u_ok += solid_angle(u)
        return u_ok / (2 * math.pi)

    def certificate(self, state, poses, speeds):
        if state.map_age > self.T_stale:                 # 地图过期 ⇒ 全部判 UNK
            return None                                   # 中立元：退回 v9 标量证书
        V = self._swept(poses)
        W = self._braking_envelope(poses, speeds)
        g_B = self.esdf.min_dist_to_occupied(V)           # 定义 542
        g_X = self.esdf.min_dist_to_unknown(W)            # 定义 542
        ell = self._escape_cone(poses[-1], speeds[-1], self.map.occupied)
        if g_B < self.d_safe or g_X < self.d_safe:        # 安全不达标 ⇒ 拒绝块
            return None
        cp = subsample(V, self.n_cp)                       # 预计算检查点（供 50Hz 守卫）
        return Cert3D(g_B, g_X, ell, checkpoints=cp)

    def guard_checkpoint(self, cert, k_exec, live_map):
        """50Hz 廉价守卫：只查 k_exec 对应检查点，预算 ≤0.3ms"""
        for x in cert.checkpoints[k_exec]:
            if live_map.d_B(x) < self.d_safe or live_map.d_X(x) < self.d_safe:
                return False
        return True


# IP-358 ActivePerceptionPlanner：主动感知规划器
class ActivePerceptionPlanner:
    def __init__(self, w_task=1.0, w_live=0.3, w_info=0.2):
        self.w_task, self.w_live, self.w_info = w_task, w_live, w_info

    def select(self, safe_chunks, state):
        if not safe_chunks:                                   # 安全集空 ⇒ 不探索
            return None
        def score(c):
            return (self.w_task * task_score(c)
                    + self.w_live * c.cert.ell
                    + self.w_info * expected_info_gain(state, c))
        return max(safe_chunks, key=score)                    # 只在 S3D 内选择

## 4. 推导

**引理 87（三维证书健全性 Soundness under Trichotomy）** 设在块执行期间检测并立即制动；假设 A_ff（无假自由）与"W_K 内未知视为占据"成立，则任一 S3D 有效块在制动策略下无碰撞。证明：由 g_B≥d_safe，V_{1:K} 与外扩 d_safe 内的 OCC 不相交；由 g_X≥d_safe，W_K 与外扩 d_safe 内的 UNK 不相交。机器人沿 V_{1:K} 行进时，任何真实障碍若进入 d_safe 必属 B_t∪X_t（A_ff 排除"被标 FREE 的障碍"），矛盾。故任意时刻制动，刹车轨迹（含于 W_K）终点距真实障碍 ≥d_safe。∎

**引理 88（未知即自由的不可能性 Impossibility of Unknown≡Free）** 对任意有限 d_safe，若把 UNK 当作 FREE（不做 g_X 约束），存在静止障碍配置使证书验证通过而执行碰撞。证明：构造遮挡物 O_occ 使路径前方障碍 b 在机器人推进到 b 之前始终处于 X_t（射线被 O_occ 遮挡，b 所在体素保持 UNK）。反对者令 b 位于机器人首次看见它的距离 r<d_brake(v) 处；由于证书从不检查 X_t，V_{1:K} 与 B_t 不相交（b 未被标 OCC），S3D 通过；但首次观测时剩余距离 r 小于刹停距离，制动必然撞上 b。因 r 由遮挡几何而非 d_safe 决定，任意 d_safe 都无法消除。∎

**引理 89（主动感知的安全支配 Safety Dominance of APP）** APP 仅在 S3D 安全集内选择，故其决策不改变健全性（健全性是证书集性质，非选择器性质）；FVC 的约束集是 v9 证书集的子集，因此 v10 安全集 ⊆ v9 安全集。故在引理 87 假设下，APP 的任何信息增益追求都不增加碰撞风险；APP 失效退回 v9 argmax 仍在该子集内。∎

**引理 90（健全率的统计可辨识性 Statistical Identifiability）** 设证书有效样本 n 条、其中不安全 f 条，则 S 的 Wilson 单侧 (1−α) 下界为 S_LCB；特别地 f=0 时，95% 置信下 S ≥ 1−3/n（rule of three 形式）。欲以置信 1−δ 宣称不安全率 ≤ε_s 且零失败，需 n ≥ ln δ / ln(1−ε_s) ≈ (1/ε_s)·ln(1/δ)。故"0/100 碰撞"只支持"不安全率 ≲3%"；报告必须给 n 与 S_LCB，禁止只报点估计。∎

**引理 91（回放无偏与污染隔离 Replay Unbiasedness）** 若回放确定性、D_test 与 D_cal∪D_val 互斥、且 F̂/β/阈值在评 D_test 前冻结，则回放得到的 S、C、T 是测试分布上的无偏估计；若在 D_test 上反复调参或复用，则产生选择偏差，估计失效。证明：确定性 ⇒ 每条记录的可观测结果固定；互斥+冻结 ⇒ 记录间在给定场景下 i.i.d. 且与调参无关；期望线性性给出无偏。重复使用破坏独立性并引入多重比较偏差。∎

**引理 92（中立元退化 ≡ v9）** SVC 中立元=空附加约束：去掉 (g_X, ℓ) 与三维 g_B，即 v9 标量证书；APP 中立元=argmax task_score，即 v9 选择器；SBM 中立元=跳过；CB 离线不进入控制回路。故在相同输入下运行期可观测轨迹与 v9 逐位一致。**注**：一致性是行为等价，SVC 失效时安全回落到 v9 威胁模型（引理 88 的遮挡盲区重新生效），日志须显式标注 `degradation_semantics="behavioral_only"`。∎

**引理 93（50Hz 预算守恒 Budget Conservation）** 三维全量 ESDF 查询只在 5Hz 块生成期执行（≤4ms/次，摊销 ≤0.4ms/cycle）；50Hz 守卫仅查 n_cp 个预计算检查点（≤0.3ms）。故决策侧仍满足典型 ≤8ms、p99 ≤20ms；三维化不破坏 v9 的 50Hz 守恒。∎

## 8. 本轮最大风险

**一句话**：三维证书的健全性建立在"占据图不把未知误标为自由"这一前提上，而遮挡、薄障碍漏检、动态物体与地图过期恰恰使**即将被扫掠的空间**成为最易被误标为 FREE 的地方——证书在最该怀疑的位置最自信，且若封存基准与部署共享同一遮挡分布偏差，健全率下界会把盲区系统性漏检为"已验证安全"。
