# 第 44 轮（本轮灵感循环第 1 轮） · Pain-Map × Grasp-Cert：用「痛点分析」做风险比例的验证预算分配，用「抓取位姿证书」把接触富集的长尾抓取纳入可验证闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 已把证书闭环覆盖到「个性化 + 并发」两个维度，但它压着一个更根本的单点假设：**(H3) 验证 / certificate 的努力是均匀投放的**——每个守卫、每个分支、每个人格都按相近 rigor 认证，而真实世界的失败与事故高度集中在少数长尾（遮挡下的对称物体、透明/反光导致点云缺失、重物摩擦系数估低、软体形变、堆叠边缘碰撞）。于是本轮灵感词「痛点分析」把验证预算从**均匀税**变成**风险比例投资**；「抓取位姿估计」给这套抽象架构一个接触富集、可测量、长尾极重的落点：把单点位姿估计升级为带证明的**抓取位姿证书**（位姿集合 + 闭合类型 + 最坏摩擦裕度 + 有效域 + 租约）。二者耦合处才是本轮真正的新问题：痛点图谱若被仿真偏差污染，会**系统性地少保护从未被采样到的灾难性长尾**，而证书"看起来严谨"恰好会掩盖这个盲区。

## 0. 直觉与动机

**灵感 1（痛点分析 → 验证不是均匀税，而是按痛点密度投放的投资）**：直觉上，100 次抓取里多数失败集中在少数几个模式（对称物体把 180° 当成两个解、透明/反光物体点云缺失、重物摩擦系数估低导致滑移、堆叠边缘碰撞）。若对每个模式投放同样的认证成本，就会在低痛点上浪费、在高痛点上欠保护。所以先做**痛点图谱**：把失败分解成可枚举的失败模式族，给每个「区域 × 模式」估计 **频次 × 严重度 × (1−可检测性)** 的痛点强度，再在预算约束下做**覆盖率投资**——安全关键模式必须由至少一条 **sound 义务**（解析证明或认证监测）兜底，其余按「边际损失下降 / 成本」排序。一句话：**验证预算跟着痛点走，而不是跟着代码结构走**。

**灵感 2（抓取位姿估计 → 点估计的置信度不是证书，位姿集合才是）**：抓取位姿估计器通常输出单个 6-DoF 位姿 + 一个 softmax 置信度；这个置信度**不承诺任何事**——它没说"对有效域内任意位姿、任意有界物性扰动，都能力闭合且摩擦裕度 ≥ ε"。所以把输出升级为 **抓取位姿证书**：一个位姿集合 P、闭合类型 ψ、最坏摩擦锥裕度 ε_f、有效域 V（物体位姿 / 几何 / 质量 / 摩擦的有界不确定集）与签发租约 τ_g。learned 部分（共形）负责覆盖分布内，解析部分（力闭合 / 摩擦锥 / SDF）负责兜住分布外长尾：**分布内靠共形，长尾靠解析，二者取并集但各自持证**。这就是把 v20「收缩免费、扩张持证」搬到抓取几何上。

**灵感 3（耦合 → 痛点决定证书粒度，证书反哺痛点统计）**：痛点图谱告诉抓取证书引擎**哪些不确定维度**要认证、认证到多细（哪些对称性要枚举、哪些面要重采样）；反过来，证书的结局（certified / refused / expired / violated）是痛点频次的**免费样本**，尤其 violated 是长尾的直接证据，必须回灌图谱与 CKB。于是形成**验证经济闭环**：痛点 → 预算 → 证书 → 回灌 → 痛点更新；当图谱漂移时，用共形鞅 / CUSUM 检出并重分配。不可行时输出**最小修复集**（换视角重感知 / 换抓取族 / 放松哪条被证伪的物性假设 / 请人确认），绝不静默降低 ε_f。

**耦合升级**：PPA（痛点图谱）把「验证预算」变成风险比例投资；GPC（抓取证书）把「抓取位姿估计」变成可证明的位姿集合；PGV（痛点驱动验证器）在仿真与实机里按痛点定向注入长尾、压测证书 soundness、并闭环回灌。四层架构由此从 v8 的「仿真-检索-边缘飞轮 + 人格契约层 + 并发证书层」升级为 v9 的同类飞轮 + **痛点经济层 + 抓取几何证书层**。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（痛点分解与痛点密度）**：给定任务分布 D、上下文区域划 R、失败模式族 M={m_1..m_K}（对称歧义、遮挡缺失、摩擦/滑移、软体形变、堆叠碰撞、运动学不可达、感知漂移…）。模式 m 在区域 R 的**痛点强度** ρ_m(R) = E_{x~D|R}[freq_m(x)] · sev_m · (1 − det_m)，其中 sev_m∈[0,1] 为损失严重度，det_m∈[0,1] 为现有监控对它的检出率（可检测性越低越危险）。**痛点密度** ρ(R)=Σ_m ρ_m(R)；**痛点图谱** A={(R,m,ρ_m(R),CI)}。注：ρ 是**估计量**，必须带置信区间与稀有事件修正（重要性采样/子采样），否则"按痛点分配"会把估计偏差直接写进安全策略。

**定义 45（痛点加权证书义务与风险比例分配）**：每条证书义务 o 有成本 c(o) 与对模式 m 的损失削减覆盖 ℓ(o,m)∈[0,1]。分配问题：max Σ_{R,m} ρ_m(R)·[1 − Π_{o∈O_R}(1−ℓ(o,m))] s.t. Σ c(o) ≤ B，且**安全约束**：∀m∈M_safe，∃o∈O_R 为 sound 义务（解析证明或认证监测），不得仅由 learned 估计兜底。**命题**：覆盖率函数对义务集单调子模，故贪心近似最优（≥(1−1/e)OPT）；均匀分配在低密度模式上浪费预算、在高密度长尾上欠保护。**风险**：ρ 由仿真/可观测样本估计，偏差会把"未采样到的灾难模式"分配为 0 预算——必须叠加定义 48 的回灌与 §5 的**固定地板预算**。

**定义 46（抓取位姿证书）**：对物体（完整模型或部分点云）与末端执行器，抓取位姿证书 γ=(P, ψ, ε_f, V, τ_g)：
- P ⊆ SE(3)：**认证位姿集合**（不是单点）；
- ψ ∈ {force_closure, ε_closure, form_closure, suction_seal}：闭合类型 / 质量保证；
- ε_f ≥ 0：最坏摩擦锥裕度下界；
- V ⊆ U：**有效域**（物体位姿、几何、质量、摩擦参数的有界不确定集）；
- τ_g：签发时刻（租约，随物体运动 / 形变衰减）。

**sound 性**：∀p∈P, ∀u∈V，在 u 下于 p 抓取达到 ψ 且摩擦裕度 ≥ ε_f。**有效域之外证书作废**，必须重导。**组合**：C_grasp = C_global ∩ Π_u ∩ γ，仍为集合求交，故不破坏 v20 的 soundness 单调性。

**定义 47（共形-解析混合的抓取位姿证书）**：估计器输出候选 {(p_i,s_i)}，用非一致性分数 r(p)=1−analytic_quality(p) 做 split-conformal 得到 P^α，在可交换性下 P(success)≥1−α；但接触富集分布破坏可交换性（新物体/新材质）。故加解析轨：若 p 落在**可证明力闭合**区域（SDF 几何 + 摩擦锥线性规划可行且裕度≥ε_f），则无论共形覆盖如何都**已 sound**。**混合有效判据**：γ 有效 ⟺ [p∈P_analytic ∧ u∈V_analytic] ∨ [p∈P^α_conformal ∧ conditional_coverage_ok ∧ shadow_zero_violation]。**命题**：该判据对分布内保持 1−α 覆盖，对分布外由解析轨兜底；代价是解析轨可用率随物体复杂度 / 遮挡程度下降。

**定义 48（证书结局回灌与痛点漂移）**：证书结局 o∈{certified, refused, expired, violated} 作为痛点频次的在线观测（violated 权重最高，是长尾直接证据）。**痛点漂移** = ρ 分布变化；用共形鞅 / CUSUM 检出，检出即触发预算重分配与图谱更新。**命题（闭环单调性）**：平稳分布下，"violation → 痛点更新 → 重分配"使期望损失单调不增；漂移下检出延迟被鞅阈值界定，代价是误报率。**推论**：把 violated 当免费长尾样本回灌，是唯一能在部署后继续发现未采样痛点、又不牺牲 soundness 的机制。

**定义 49（不可行抓取的最小修复集）**：当 C_grasp=∅ 或 ε_f<ε_min 时，在痛点维度上求最小修复集：命中所有未满足证书义务的最小代价动作集（重感知视角 v、换抓取族、松动被证伪的物性假设、请人确认），即**最小命中集**。**命题**：修复集只改变"从哪里获取信息 / 改变哪个假设"，不直接降低 ε_f 或放宽 V；任何真正放松必须走 v20 的协商通道并由操作员确认。对应 v20 定义 38 的最小让步集，但对象从"人格契约"换成"抓取证书义务"。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 PAIN-POINT ATLAS ENGINE（痛点图谱引擎 PPA）
1. **失败模式分解**：以骨架化 taxonomy 把抓取 / 操作失败归入 M，用仿真故障注入 + 实机日志估计 freq / sev / det。
2. **带区间的痛点估计**：重要性采样 + 稀有事件估计 + 共形区间，输出 A 而非点估计。
3. **风险比例分配**：把定义 45 的覆盖投资解成预算分配；安全模式强制 sound 义务地板预算（不随 ρ 估计缩小）。
4. **最小修复集生成**：不可行时输出最小命中集供协商，绝不静默放松。

### 2.2 IP-61 GRASP-POSE CERTIFICATE ENGINE（抓取位姿证书引擎 GPC）
1. **位姿集合输出**：估计器候选 → conformal P^α + 解析 P_analytic，取混合有效判据（定义 47）。
2. **解析抓取质量**：SDF 几何 + 摩擦锥 LP / 力闭合判据，输出 worst-case ε_f 与 ψ。
3. **有效域 V 推导**：由标定误差、分割不确定性、质量 / 摩擦置信界构造有界不确定集，随状态更新收缩 / 扩张。
4. **证书租约**：τ_g 随物体运动 / 形变按 Lipschitz 界衰减，复用 IP-58 的租约与新鲜度判据。

### 2.3 IP-62 PAIN-DRIVEN GRASP VALIDATOR（痛点驱动抓取验证器 PGV）
1. **痛点定向对抗采样**：按 ρ 优先注入高痛点模式（对称、透明、重物滑移、软体），并为每模式注入稀有事件。
2. **证书 soundness 压力测试**：在 V 内、V 边界与 V 外采样，验证"V 外必作废、V 内必闭合"。
3. **漂移检测与闭环回归**：模拟 / 实机痛点漂移，验证预算重分配与 CKB 回灌。
4. **长尾发现**：把 violated 结局聚成新候选模式，人工 / 主动学习确认后入图谱。

```

    IP-51 CAR(grasp 守卫 + γ 有效域 + 租约) ← IP-58 CCR(租约/RG/混合关键级)
    → IP-39 规划(CBF margin=min(查表, 租约衰减, ε_f)) → IP-45 总线
    → IP-53 CMC(闭合/摩擦监控, 最高关键级)
L4: IP-57 PCE + IP-61 GPC + IP-55 CKB(痛点/证书指纹)
    ← IP-62 PGV(痛点定向对抗 + soundness 压测 + 漂移闭环) + IP-54 SCV
    → IP-44 蒸馏 + IP-50 痛点课程 → RCA 重颁(痛点/抓取 conditioned) → 热更新
运行期：痛点分配预算 → 抓取位姿集合并行认证 → 混合判据取有效集 → 一致选择
        → 证书签发租约 → 监控快照守卫 → 结局回灌痛点图谱
        不可行 → 最小修复集协商 → 绝不静默放松 ε_f
```

## 5. 本轮最大风险

**一句话**：痛点图谱是从仿真 + 可观测日志估计出来的有偏样本，"按痛点密度分配预算"可能给一个**从未被采样到的灾难性长尾模式分配 0 预算**，而量化严谨的外观反而让这种遗漏更难被察觉——因此 E95/E96 必须设为红线，并强制保留一份**不随 ρ 估计收缩的安全模式固定地板预算**（全安全模式由 sound 义务覆盖）+ 稀有事件重要性采样 + violated 结局回灌，作为永不失 sound 的底线。

### IP-60 PPA：痛点谱、风险比例分配与最小修复集
```
def build_pain_atlas(logs, sim, taxonomy):
    atlas = {}
    for (R, m) in regions_x_modes(taxonomy):
        freq = rare_event_estimate(logs, sim, R, m)   # 重要性采样 + 置信区间
        sev  = severity[m]                            # 损失回放/人为标定
        det  = detectability(m, monitors)             # 现有监控检出率
        atlas[(R, m)] = Pain(freq=freq,
                             rho=freq.mean * sev * (1 - det),
                             ci=freq.ci)
    return atlas

def allocate_budget(atlas, obligations, B):
    # 安全地板：所有安全模式必须由 sound 义务覆盖，预算先扣，不随 rho 缩
    floor = choose_sound_cover(obligations, modes=SAFETY_MODES)
    B_rem = B - sum(o.cost for o in floor)
    if B_rem < 0:
        return floor, INSOLVENT               # 触发人工/降级，不静默削减
    # 其余：覆盖函数单调子模 => 按 边际损失下降/成本 贪心
    def marginal(o, S):
        return sum(rho_gain(atlas, k, S | {o}) - rho_gain(atlas, k, S)
                   for k in atlas) / o.cost
    chosen = list(floor)
    while True:
        cand = [o for o in obligations
                if o not in chosen and o.cost <= B_rem]
        if not cand:
            break
        o = max(cand, key=lambda o: marginal(o, set(chosen)))
        chosen.append(o); B_rem -= o.cost
    return chosen, B_rem

def minimal_repair_set(unsat, actions):
    # 最小命中集：选最少代价动作覆盖所有未满足证书义务
    # actions: 重感知视角/换抓取族/松动某物性假设/请人确认
    return min_cost_hitting_set(unsat, actions)
```

### IP-61 GPC：位姿集合证书、混合有效判据与组合
```
def grasp_certificate(obj, ee, candidates, alpha, V, calib):
    # (1) 解析轨：对每个候选证明力闭合，且落在有效域内
    P_ana, eps = [], []
    for p in candidates:
        lp = friction_cone_lp(obj.sdf, ee, p)        # 摩擦锥线性规划
        if lp.feasible and lp.margin >= EPS_MIN and p_in_V(p, V):
            P_ana.append(p); eps.append(lp.margin)
    # (2) 共形轨：分布内覆盖（r = 1 - analytic_quality）
    scores = [1 - analytic_quality(p, obj) for p in calib]
    q = quantile(scores, 1 - alpha)
    P_conf = [p for p in candidates
              if 1 - analytic_quality(p, obj) <= q]
    # (3) 混合有效判据：解析优先；共形需条件覆盖 + 影子证书零违例
    P_valid = list(P_ana)
    for p in P_conf:
        if p not in P_valid and conditional_coverage_ok(alpha) \
           and shadow_cert.zero_violation(p, obj, V):
            P_valid.append(p)
    if not P_valid:
        return None, minimal_repair_set(unsat_obligations(obj), REPAIR_ACTIONS)
    eps_f = min(eps) if eps else empirical_lower_bound(P_valid, obj)
    tau_g = monotonic_now()
    return GraspCert(P=P_valid, psi=FORCE_CLOSURE, eps_f=eps_f,
                     V=V, tau=tau_g, lam=L_grasp * v_obj_max)

def grasp_cert_valid(cert, p, u, t):
    # 有效域内 + 租约未衰减到阈下，才可用于守卫
    return (p in cert.P and u in cert.V
            and cert.eps_f - cert.lam * (t - cert.tau) >= EPS_MIN)

def compose_with_all(cert, C_geo, persona, C_global):
    # 抓取证书作为可容许集参与求交；只收缩，天然保 sound
    return intersect_all([C_global, C_geo, persona, cert.as_admissible()])
```

### IP-62 PGV：痛点定向对抗、soundness 压测与漂移闭环
```
def pain_directed_fuzz(atlas, budget):
    # 预算按痛点密度分配，高 rho 模式获得更多注入（含稀有事件放大）
    for (R, m), b in proportional(atlas, budget).items():
        inject_scenes(R, m, rare_event_boost(b))

def soundness_stress(cert, obj):
    # V 内（含边界、对抗样本）：必须闭合
    for u in sample_uncertainty(cert.V, boundary=True, adversarial=True):
        if grasp_cert_valid(cert, chosen_p(cert), u, now()):
            assert grasp_succeeds(cert, obj, u)     # 违例即证伪证书
    # V 外：证书必须作废（不得被陈旧放宽使用）
    for u in sample_complement(cert.V):
        assert not grasp_cert_valid(cert, chosen_p(cert), u, now())

def drift_detect_and_reallocate(atlas, outcomes):
    atlas.update(outcomes)                 # violated 权重最高（长尾直接证据）
    if cusum(atlas.rho_change) > H:
        return reallocate(atlas)           # 触发风险比例预算重分配
    return atlas
```

### IP-51/52/53 升级：抓取-痛点感知的守卫与证书栈
```
def car_grasp_guard(e, x, cert, persona, lease, t):
    theta = cert.alpha_e[e] * cert.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau)
    m_cap    = persona_cap[e](persona)          # 人格契约只做上限收缩
    m_grasp  = cert.grasp_eps_f                 # 抓取证书的最坏摩擦裕度
    return (min(m_lookup, m_lease, m_cap, m_grasp) >= theta
            and lease_valid(lease, theta, t)
            and grasp_cert_valid(cert.grasp, x.grasp_p, x.u, t))

def certify_grasp_tiered(x, candidates, budget_us, criticality):
    # 高关键级优先解析轨（sound 地板），低关键级可用共形轨
    P_ana = analytic_grasp_certify(x, candidates)
    if P_ana and budget_us >= PARSE_MIN_US:
        return P_ana, -1                      # 解析成功，最高可信
    if criticality < K_GEOMETRY:
        return downgrade_monotone(P_ana), -1  # 过载：单调降级，不冒进
    P_conf = conformal_grasp_certify(x, candidates)
    return merge_hybrid(P_ana, P_conf), 0
```

## 6. 本轮最大风险

**一句话**：痛点图谱是从仿真 + 可观测日志估计出来的有偏样本，"按痛点密度分配预算"可能给一个**从未被采样到的灾难性长尾模式分配 0 预算**，而量化严谨的外观反而让这种遗漏更难被察觉——因此 E95/E96 必须设为红线，并强制保留一份**不随 ρ 估计收缩的安全模式固定地板预算**（全安全模式由 sound 义务覆盖）+ 稀有事件重要性采样 + violated 结局回灌，作为永不失 sound 的底线。
