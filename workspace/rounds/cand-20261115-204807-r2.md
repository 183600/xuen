# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语言指令」×「跨物体泛化」）

> R69 把不确定性一分为二：aleatoric 走 R68 的保守铁律，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去消解。它的效率收益押在一个前提上——**流模型的模态分布可信**。但 R69 仍隐含一个更根本的假设：**指令本身是给定的、已接地的、无歧义的单条符号**。它把「不确定」全部放在世界侧（是哪个动作、测量准不准、该问谁），却从未问过：**这句话到底是什么意思？它指的是哪一个物体？换成一个从没见过的物体，同一个词还成不成立？**
>
> 本轮两个灵感正好补上语义侧与对象侧：
> - **语言指令**：语言不是一条命令，而是一张**有类型、可分解、可欠指定、可含否定与量词**的语义图。它天然携带**指称歧义、谓词歧义、辖域歧义**；这些歧义不能像高斯噪声一样被一个标量 U 吸收，而应被枚举、校准、证伪。
> - **跨物体泛化**：迁移的粒度不是「整个策略」，而是「**每个语义原子 × 每个物体**」。同一个「抓」在熟杯子上可信，在一个透明、无把手、可变形的陌生物体上可能立刻失效；而「已知原子拼成一个没见过的组合」有时反而可以零样本成立——**这两种泛化必须分开认证**。
>
> 核心命题：**语言指令给出的是「意义的假设集」，跨物体泛化给出的是「原子-物体级的迁移契约」；执行前必须先认证「解释」再认证「动作」，且只在可信解释集下都安全的公共前缀上执行。** 命名 **PRISM-RAS**（Parsed-Reference Instruction Semantics with object-level Migration）：像棱镜一样把一句指令折射成可独立认证、又可重新复合的语义原子。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这句话到底指什么、换成一个没见过的物体还成不成立**」——**听错动作还能靠闭环纠正，理解错意义却会带着一张合格的证书把错事做完。**

## 0. 直觉与动机

**灵感 1（语言指令 → 意义不是标量，而是一个可枚举的假设集）**
直觉：R69 的 `U_epi` 描述的是「同一个意图下动作有多个模态」。但真实指令的歧义发生在更上游：「把左边那个大的放到它旁边」至少有三种不确定性——**指称**（左边那个大的是杯子还是盒子）、**谓词/关系**（「旁边」是左、右、前、还是紧贴）、**辖域与共指**（「它」指第一个物体还是另一个）。这些不是动作噪声，而是**意义的多个候选世界**。把它们平均成一个动作，等于用「0.5 的速度同时执行两种解释」；把它们折叠成一个 MAP 解析，则等于**在没验证前就替人做了决定**。正确的对象是一个带权重的解释集合，以及一个「哪些解释仍然可信」的阈值集。

**灵感 2（跨物体泛化 → 迁移的最小单位是「原子 × 物体」）**
直觉：R69 的流策略在动作空间里插值，看起来「平滑地」泛化到新物体，但**平滑不等于正确**。一个在熟物体上校准的「抓取」谓词，面对透明物体、软物体、无把手物体时，其动作分布可能整体偏移到低质量区。跨物体泛化因此应被拆成两份可分别度量的东西：**(a) 属性泛化**——同一个语义原子（抓/放/推/叠）迁移到一个属性分布不同的新物体；**(b) 结构泛化**——已知原子组成一个训练中没出现过的句法/关系结构（例如「把 A 放到 B 的左边且不与 C 共线」）。前者要靠**对象级迁移契约**，后者要靠**组合证书代数**；二者混在一起谈「泛化好」，就无法定位失败到底出在词义还是出在物体。

**灵感 3（合并陷阱 → 接地并置 ≠ 指令理解）**
直觉：最危险的不是单个词判错，而是**每个词单独看都对，拼起来意思却变了**。三种机制：(i) **指称纠缠**——两个指称短语可能共指，分开 grounding 会把同一物体绑成两个；(ii) **可供性耦合**——「叠」同时依赖两个物体的支撑面，「插入」依赖孔洞与刚度的联合属性，单原子契约各自成立，联合风险却可能翻倍；(iii) **前置条件耦合**——「先抓 A 再抓 B」中，抓 A 改变了 B 的可见性与可达性，顺序不能交换。这些恰好躲在「逐原子认证」的盲区里。**组合证书必须重算，不能由原子证书并置继承。**

**灵感 4（澄清可以自证 → 需要可证伪的提问 + 独立证据通道）**
直觉：R69 的 VoI 交互默认「问了就会得到信息」。但在语义层，最隐蔽的失败是**自证**：澄清问题由同一个可能出错的解析器生成，问题只覆盖领先解释已经蕴含的答案，人（或模型复述）只要回答「是」，系统就得到一张「已验证」的错误理解证书。**能区分两个解释的问题，才是问题；只能确认领先解释的问题，只是回音。** 因此澄清动作必须带**可证伪性**约束，并至少有一条独立于语言解析的证据通道：让人**指**、让系统**看另一视角**、让系统**轻推试探可供性**、或让人**演示一遍**。

**灵感 5（语言也是攻击面 → 指令注入、指称投毒、语义幻觉）**
直觉：一旦语言进入闭环，攻击面就从「传感器」扩展到「意义」。环境里的文字（标签、屏幕、包装）可以构成**具身提示注入**；人可以故意把手指向错误物体（**指称投毒**）；解析器可以**幻觉**出一个场景里不存在的指称或谓词；跨物体场景里的颜色/纹理捷径会让系统「自信地」把新物体认成旧类别。更糟的是，语义错误会被下游动作执行放大，而且**带着证书**——审计看到的是一张「解释已认证」的合格证。

**灵感 6（对偶通道 → 用改写不变性与反事实换物检验「真理解」）**
直觉：解析器的置信度不能证明自己。需要两条**不依赖解析器自评**的通道：(a) **改写一致性**——保持意义不变的改写（主动/被动、同义替换、语序调整）应当导出同一个动作计划；若计划随改写漂移，说明接地不稳；(b) **反事实换物**——把一个与指令无关的物体实例换成同类另一实例，计划不应改变；若改变，说明系统依赖了虚假的捷径线索。`(解析置信度, 改写不一致度, 换物不一致度)` 三元组可分离「真理解」与「自信的表面拟合」——这是 R69 的 `(r_res, Δa)` 标定-似然对偶在语义层的镜像。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PRISM-RAS 总览）** PRISM-RAS = (SGP, RGC, OTC, CCA, CSP, SVC, SCG, RAS-WM§)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **解析一次、缓存复用**：语言解析与冻结 LLM 解码在控制环之外完成，每句指令只解析一次，控制步内只做查表/几何核验；
(iii) **语义不确定性显式化**：`U_sem` 以可信解释集 `H_α` 表示，认证前不得折叠为 MAP；
(iv) **禁止静默组合**：语义原子的组合必须过组合证书代数 CCA，不过则 `⊕ = ⊥`，不得执行；
(v) **保守语义**：执行动作必须对 `H_α` 中所有解释都安全；语言不得扩张物理安全包络。

**定义 311（类型化语义图 SGP）** 指令 `ℓ` 解析为类型化有向无环图 `G = (V, E, τ)`，节点类型 τ ∈ {指称 ρ, 谓词 π, 关系, 量词, 否定, 时序}。`G` 的指称是**解释集** `⟦G⟧ = {h = (β, γ, σ)}`：绑定 β（指称→物体）、谓词接地 γ（谓词→参数化技能流形）、辖域/否定 σ。解析器返回分布 `P(G | ℓ)`，**保留 beam 内多个解析**，不取 MAP。

**定义 312（语义假设与语义不确定性）** 语义假设 `h ∈ H`，权重 `w_h ∝ P(G|ℓ)·∏ p(β,γ,σ | G, O)`（O 为物体中心场景图）。`U_sem = H(H) = −Σ_h w_h log w_h`，另记歧义质量 `m_amb = 1 − max_h w_h`。**关键区分**：即使世界状态完全已知（`U_ale = U_epi = 0`），只要 `|⟦G⟧| > 1`，仍有 `U_sem > 0`；反之语义唯一时 `U_sem = 0`。`U_sem` 是第三类不确定性——**意向/语义不确定性**，不可与 R69 的 aleatoric/epistemic 相加混用。

**定义 313（指称后验与物体新颖度）** 对每个指称 ρ，`p(ρ→o | ℓ, O) = CalibratedSoftmax(score_ρ(o))`；指称新颖度 `ν(o) = d_obj(o; D_ρ)`（外观/几何/可供性/动力学联合距离，D_ρ 为接地支撑集）。强制**绑定一致性**：共指约束（「它」与首个指称）在同一解释内必须绑定同一物体，跨解释才允许不同；违反一致性的解释直接剔除。

**定义 314（原子-物体迁移契约 OTC）** 对语义原子 `(π, o)`，契约 `T_{π,o} = (δ_π, κ_π, R_π)`：当 `d_obj(o; D_π) ≤ δ_π` 时，目标风险 `risk_T(π,o) ≤ risk_S(π,o) + κ_π`；`R_π` 是失效见证（无把手、透明、可变形、支撑面不足、超出力包络等）。`d_obj > δ_π` 时契约未认证，该原子不得作为「已知」使用，必须探索/演示/拒绝。

**定义 315（组合证书代数 CCA）** 组合算子 `⋄` 把原子合成语义图 `G = ⋄_j (π_j, o_j)`。联合证书：
`Cert(G) Valid ⇔ (∀j Cert(π_j,o_j) Valid) ∧ Λ_obj ≤ δ_obj ∧ I_cross(G) ≤ δ_sem ∧ 绑定一致性成立`。
其中 `Λ_obj = Σ_j κ_{π_j,o_j}` 是对象迁移缺口之和；`I_cross` 是三类交互项的可计算上界：
(a) **指称纠缠**：共指/同物体多谓词的绑定熵；
(b) **可供性耦合**：共享物体表面/孔洞/刚度的谓词对的联合失效概率；
(c) **前置条件耦合**：时序算子的状态改变对后续原子可达性的影响。
任一超界 ⇒ `⊕ = ⊥`（未认证），禁止「逐原子都合格所以整体合格」的静默组合。

**定义 316（可信解释集与保守执行 CSP）** 可信集 `H_α` 为后验质量 ≥ 1−α 的最小解释集。对每个 `h` 计算安全动作集 `S(h)`。执行 `a` 当且仅当存在一个**公共安全前缀** `a ∈ ⋂_{h∈H_α} S(h)`，且 `a` 在**所有** `h` 下都推进任务；否则不执行 `a`，转澄清或安全停止。若交集为空，取最坏情形 `min_h` 的风险上界；不允许「按 MAP 解释先做、出事再改」。

**定义 317（语义 VoI 与可证伪澄清 SVC）** `VoI_sem(g) = H(H_α) − E_{y~p(·|g)}[H(H_α | y)]`。可证伪性 `F(g) = E_y[D_KL(p_lead ‖ p_alt | y)]`，即在领先解释与任一可信替代解释下，答案分布的期望可分性。选择
`g* = argmax_g [VoI_sem(g) − c(g)]`，s.t. `F(g) ≥ f_min`、`risk(g) ≤ ε_int`、预算未超、证据纪律（继承 R69 定义 293-iii）。
`F(g) < f_min` 的问题**即使 VoI 估计很高也不许问**——它只会产生自证。

**定义 318（澄清/探索动作空间）** `g = (g_ask, g_point, g_paraphrase, g_demo, g_explore)`：问句、指向/指示、要求改写复述、要求人类演示一次、物理轻探（推/触/换视角）以测可供性。跨物体时优先 `g_demo` / `g_explore`——它们提供**独立于语言解析**的可供性证据。所有 g 必须通过与任务动作相同的 C-RAS-WM 认证（继承 R69 定义 302）。

**定义 319（语言-安全编译 LSC）** 对每个解释 `h`，把指令的约束编译为 `S(h)`；若指令在**所有** `h` 下都要求不安全动作 ⇒ 拒绝执行；若仅在部分 `h` 下不安全 ⇒ 在该 `h` 被排除前不得执行；语言**不能**扩大物理安全集 `S_phys`。否定、量词、辖域必须显式编译（用最小对立句对做测试），禁止把「不要碰红色的」解析成「碰红色的」。

**定义 320（语义校准门 SCG）** 解析权重与指称权重需校准：`ECE_sem ≤ τ_sem`。越界 ⇒ 禁用 VoI/澄清驱动的执行决策，只允许执行「唯一可信解释（`|H_α|=1`）∧ 物体在支撑集内（`d_obj=0`）」的原子，其余一律走 R69 保守路径。这是 R69 的 MCG 在语义层的对应物。

**定义 321（三级保守退避与 Resolution Bonus）**
- **已认证**（语义唯一/已消解、组合有效、对象在契约内）：`λ = λ_floor(U_ale) + slack_obj`，获得 resolution bonus；
- **未消解**（语义或组合未认证，但存在公共安全前缀）：`λ = λ_floor(U_ale + U_epi + U_sem + Δ_obj)`，未消解部分视同 aleatoric 兜底；
- **不可认证/被投毒/注入**：`λ = λ_max`，不执行任务动作，只允许澄清、探索或安全停止。
R69 恰为「唯一解析 + 物体在支撑集内 + 无交互」边界。

**定义 322（语义干扰集 ℰ_LANG）** `ℰ_LANG = ℰ_FLUID × ℰ_semantic_hallucination × ℰ_reference_poison × ℰ_compositional_shift × ℰ_instruction_injection`：解析器幻觉指称/谓词、指称投毒（故意指错/共指诱导）、组合分布偏移（未见过的结构）、具身提示注入（环境文字/标签）、虚假线索捷径（颜色/纹理）、谄媚式人类回答。

**定义 323（证书 J_PRISM）** `J_PRISM = (J_FLUID, parse_hash, H_α, ECE_sem, atom_contracts, Λ_obj, I_cross, ν_obj, clarification_lineage, falsifiability_stats, injection_flags, prism_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ SCG 通过 ∧ CCA 非 ⊥ ∧ H_α 中无未处理的不安全解释 ∧ 证据纪律满足 ∧ 澄清可证伪性达标`。

**定义 324（语义-对象对偶）** 两条独立于解析器自评的通道：
(a) **改写一致性** `Δs = D(plan(ℓ), plan(ℓ'))`，`ℓ'` 为保持意义的改写；`Δs` 高 ⇒ 接地不稳；
(b) **反事实换物** `Δo = D(plan(O), plan(O[o→o']))`，`o'` 为与任务无关的同类替代实例；`Δo` 高 ⇒ 依赖虚假捷径。
`(置信度, Δs, Δo)` 联合可分离「真理解」与「自信的表面拟合」。

**定义 325（嵌套退化监控）** 运行时可判定的三边界逐指令退化为 R69：`|H_α|=1`（语义唯一）、`d_obj=0`（物体在支撑集）、`I_cross=0`（无交叉交互）。监控当前层级并写入 J_PRISM；语义未消解时**只收紧**，不弱于 R69。

**定义 326（澄清终止与预算）** 单位指令的澄清次数 `≤ K_clar`、总交互成本 `≤ C_clar`；每轮用贝叶斯更新 `H_α`，并以可证伪性问题优先。达到预算仍未消解 ⇒ 走定义 321 的保守/拒绝分支，禁止无限追问。

## 2. 关键算法骨架

```python
# IP-264 SGP：类型化语义图解析（冻结、离线、保留 beam，不取 MAP）
class SemanticParser:
    def parse(self, instruction, scene):
        parses = constrained_decode(instruction, grammar="typed_dag", beam=8, model=self.frozen_llm)
        return [G for G in parses if binding_consistent(G, scene)]   # 剔除共指矛盾

# IP-265 RGC：指称后验 + 校准 + 共指约束
def ground_referents(G, O):
    post = {(rho, o): calibrated_softmax(score(rho, o)) for rho in G.refs for o in O}
    return enforce_coref(post, G)          # 同一解释内共指必须同物体

# IP-266 OTC：原子-物体迁移契约（属性泛化）
def atom_contract(atom, o):
    d = d_obj(o, atom.support)             # 外观/几何/可供性/动力学联合距离
    ok = d <= atom.T.delta
    return ok, (atom.T.kappa if ok else INF), affordance_witness(o)

# IP-267 CCA：组合证书重算（结构泛化，绝不继承）
def certify_composition(H, contracts):
    if any(not ok for ok, _, _ in contracts): return None
    lam_obj = sum(k for _, k, _ in contracts)
    i_cross = (ref_entanglement(H) + affordance_coupling(H) + precondition_coupling(H))
    if lam_obj > D_OBJ or i_cross > D_SEM: return None      # ⊕ = ⊥
    return Certificate(lam_obj, i_cross, slack=slack(lam_obj, i_cross))

# IP-268 CSP：可信解释集下的保守执行
def robust_execute(H_alpha, planner):
    common = intersect_all(safe_prefix(h) for h in H_alpha)
    if common: return planner.select(common)
    return CLARIFY_OR_REFUSE                                 # 不按 MAP 冒险

# IP-269 SVC：可证伪澄清（问题必须能区分解释）
def choose_clarification(H_alpha, budget):
    best = None
    for g in (ask(), point(), paraphrase(), demonstrate(), explore()):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, H_alpha): continue
        if falsifiability(g, H_alpha) < F_MIN: continue      # 防自证
        score = voi_sem(g, H_alpha) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-274 PRISM 主闭环（严格包含 R69）
def PRISM_round(M, obs, instruction):
    Gs = M.sgp.parse(instruction, obs.scene)                 # 解析一次，缓存
    H  = M.rgc.posterior(Gs, obs.scene)
    if M.scg.ece > TAU_SEM:                                  # 语义不可信 → 只做无歧义原子
        return R69_round(M, obs, restrict(H, singleton=True, in_support=True))
    C = M.cca.certify_composition(H, M.otc.contracts(H))     # 原子×物体
    while C is None and M.svc.budget_left():
        g = M.svc.choose_clarification(H, M.budget)
        if g is None: break
        H = M.svc.update(H, M.execute(g))                    # 指/演示/探/问
        C = M.cca.rerecertify(H)
    a = M.csp.robust_execute(H, M.planner)                   # 可信集公共安全前缀
    if a is CLARIFY_OR_REFUSE:
        return M.svc.ask_or_safe_stop()
    # 将认证后的解释与对象契约交给 R69 动作层
    k, lam, mode, U = R69_round(M, obs, condition(a, C))
    # 记账：未消解语义 / 对象缺口 / 组合交互项一律收紧
    lam = max(lam, lam_floor(U[0] + U[1] + unresolved(H) + C.slack))
    M.vqa_s.submit_async(H, C, M.svc.log, M.sgp.parse_hash,
                         delta_s(H), delta_o(H))             # 语义审计 + 对偶通道
    return k, lam, mode, (U, H, C)
```

## 3. 推导

**引理 19（语义熵-澄清收益）** 在语义校准（A104）与可证伪澄清（A106）下，若一次澄清使可信解释集的熵下降 `ΔH_sem`，则相较按 MAP 直接执行，期望语义误差下降 `≥ c · L_sem · (1 − e^{−ΔH_sem})`，其中 `L_sem` 是解释错误的代价（错物体/错关系/错时序的最大损失）。系：**语义歧义越大、解释间代价差越大，澄清越值钱；两个解释对应同一动作时，澄清价值为零。**

**引理 20（对象迁移的证据价格）** 若目标证据预算 B 使单原子可约缺口按 `Δ_obj(B) ≤ Δ_0/√B` 收缩，则存在 `B* = (Δ_0/δ_obj^OK)²` 使该原子契约重新认证；组合需要 `Σ_j B*_j`。系：**属性泛化有明确价格；预算不足以支付组合中所有原子的 `B*` 时，不应假装组合已认证，而应演示/分解/拒绝。**

**引理 21（接地并置 ≠ 理解：组合失效构造）** 存在两个语义原子，各自满足 `risk(π_j,o_j) ≤ ε`，但共享同一指称或存在可供性耦合，使联合风险 `risk(⋄_j) ≥ 2ε − o(1)`；即 `∀j Cert(π_j,o_j) Valid` 不蕴含 `Cert(⋄_j) Valid`。系：**组合证书必须显式计算 `I_cross`；「每个词都对」不是「整句话对」的充分条件。** 这是「耦合失效」在**语义层**的镜像：耦合不会被逐项认证看见，只会被联合认证看见。

**引理 22（可证伪澄清的防自证上界）** 设每个问题对领先解释与替代解释的答案分布可分性为 `f`，人类回答噪声 ≤ η；则错误领先解释在 k 次澄清后仍存活的概率 `≤ (1 − f + η)^k`（在问题独立选取下）。若 `f = 0`（问题只确认领先解释），存活概率恒为 1。系：**没有可证伪性的澄清只是在给错误理解盖章；`F(g) ≥ f_min` 是语义安全的必要条件。**

**定理 18（PRISM 严格包含 R69）** 在 A103–A107 下，PRISM 的期望风险 ≤ R69；当 `|H_α|=1`、`d_obj=0`、`I_cross=0` 时，两者**逐指令相同**（定义 325）。语义未消解、组合未认证、对象出契约、SCG 越界或检测到注入时，PRISM **单调不降地**退化为 R69 保守路径或安全停止。故 R69 是 PRISM 在「唯一解析、零对象差、零交互」边界上的退化：安全侧不做任何让步。

**定理 19（语义安全无突变）** 澄清/解释切换只改变「选哪个可信解释」，不改变物理安全包络；CSP 把执行限制在 `H_α` 的公共安全前缀，语言-安全编译保证 `S(h) ⊆ S_phys`；无公共前缀时拒绝或澄清。提交/换装不变式（R68 定理 15、R69 定理 17）保持 ⇒ 无突变、无越界。

**定理 20（跨物体/组合泛化的收益条件）** 正迁移 `> 0` ⇔ 所有相关原子的对象契约 Valid ∧ 组合交互 `I_cross ≤ δ_sem` ∧ 目标证据可支付（`Σ B*` 在预算内）。否则存在负迁移风险，必须降级为演示/探索/拒绝。⇒ **不是所有词都能跨物体迁移；也不是所有新组合都能由组合性免费获得——可证明「此处不该泛化」本身就是有效结论。**

**定理 21（澄清终止性）** 在有限可信集、可证伪问题集与硬预算（定义 326）下，PRISM 要么在 `K_clar` 次内使 `|H_α|` 收缩到可认证，要么进入保守/拒绝分支；不存在无限追问。系：**澄清是有预算的认识论行动，不是万能钥匙。**

## 6. 本轮最大风险

**一句话**：PRISM-RAS 的全部语义安全押在「解析器与指称后验的置信度是诚实的」这一前提上——但最隐蔽的失败是**语义自证**：语义假设与澄清问题都由同一个可能自信出错的解析器生成，问题只覆盖领先解释已蕴含的答案，人（或模型复述）一句「是」就把幻觉出的指称/谓词盖上「已验证」的章；于是系统**带着一张合格的 J_PRISM 执行了错误的理解**——**听错动作还能闭环纠正，理解错意义却会把错事做完；语义幻觉比动作幻觉更危险。**

**次级风险与缓解**：
1. **组合交互项被低估**（指称纠缠/可供性耦合/前置条件）→ CCA 显式重算（定义 315）+ 引理 21 + E305；
2. **指称投毒/共指诱导** → 独立指向/演示通道 + k-正交证据纪律 + E310；
3. **具身指令注入**（环境文字/标签）→ 指令来源血统 + 注入干扰集 `ℰ_instruction_injection` + E309；
4. **解析器延迟击穿实时预算** → 解析一次/缓存 + 控制环只做查表与几何核验 + 复杂度表；
5. **澄清疲劳/谄媚式回答** → 可证伪性门槛 `f_min` + 预算硬约束 + E316 成本-收益 Pareto；
6. **校准门被「表面相似」骗过** → 语义-对象对偶（`Δs, Δo`）+ SCG 越界即退回 R69 纯保守（定义 320）。

## 3. 关键算法伪代码

```python
# IP-264 SGP：类型化语义图解析（冻结、离线、beam，不取 MAP）
class SemanticParser:
    def parse(self, instruction, scene):
        parses = constrained_decode(instruction, grammar="typed_dag",
                                    beam=8, model=self.frozen_llm)
        return [G for G in parses if binding_consistent(G, scene)]

# IP-266 OTC：原子-物体迁移契约（跨物体属性泛化）
def atom_contract(atom, o):
    d  = d_obj(o, atom.support)                 # 外观/几何/可供性/动力学
    ok = d <= atom.T.delta
    return ok, (atom.T.kappa if ok else INF), affordance_witness(o)

# IP-267 CCA：组合证书重算（结构泛化，绝不继承）
def certify_composition(H, contracts):
    if any(not ok for ok, _, _ in contracts): return None
    lam_obj = sum(k for _, k, _ in contracts)
    i_cross = (ref_entanglement(H) + affordance_coupling(H)
               + precondition_coupling(H))
    if lam_obj > D_OBJ or i_cross > D_SEM: return None       # ⊕ = ⊥
    return Certificate(lam_obj, i_cross, slack(lam_obj, i_cross))

# IP-268 CSP：可信解释集的公共安全前缀
def robust_execute(H_alpha, planner):
    common = intersect_all(safe_prefix(h) for h in H_alpha)
    return planner.select(common) if common else CLARIFY_OR_REFUSE

# IP-269 SVC：可证伪澄清（防自证）
def choose_clarification(H_alpha, budget):
    best = None
    for g in (ask(), point(), paraphrase(), demonstrate(), explore()):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, H_alpha): continue
        if falsifiability(g, H_alpha) < F_MIN: continue       # 只确认不问
        score = voi_sem(g, H_alpha) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-274 主闭环（严格包含 R69）
def PRISM_round(M, obs, instruction):
    Gs = M.sgp.parse(instruction, obs.scene)                  # 解析一次，缓存
    H  = M.rgc.posterior(Gs, obs.scene)                       # 指称 + 辖域
    if M.scg.ece > TAU_SEM:
        return R69_round(M, obs, restrict(H, singleton=True, in_support=True))
    C = M.cca.certify_composition(H, M.otc.contracts(H))      # 原子×物体
    while C is None and M.svc.budget_left():
        g = M.svc.choose_clarification(H, M.budget)
        if g is None: break
        H = M.svc.update(H, M.execute(g))                     # 指/演示/探/问
        C = M.cca.rerecertify(H)
    a = M.csp.robust_execute(H, M.planner)                    # 公共安全前缀
    if a is CLARIFY_OR_REFUSE: return M.svc.ask_or_safe_stop()
    k, lam, mode, U = R69_round(M, obs, condition(a, C))      # R69 动作层
    lam = max(lam, lam_floor(U[0] + U[1] + unresolved(H) + C.slack))
    M.vqa_s.submit_async(H, C, M.svc.log, M.sgp.parse_hash,
                         delta_s(H), delta_o(H))
    return k, lam, mode, (U, H, C)
```

## 4. 推导

**引理 19（语义熵-澄清收益）** 校准（A104）+ 可证伪（A106）下，一次澄清使可信集熵降 `ΔH_sem`，则相较 MAP 直接执行，期望语义误差下降 `≥ c·L_sem·(1−e^{−ΔH_sem})`；`L_sem` 为解释错误代价。系：歧义越大、解释间代价差越大，澄清越值钱；两解释对应同一动作时澄清价值为零。

**引理 20（对象迁移的证据价格）** 若预算 B 使单原子缺口按 `Δ_obj(B)≤Δ_0/√B` 收缩，则 `B*=(Δ_0/δ_obj^OK)²` 可重新认证该原子；组合需 `Σ_j B*_j`。系：属性泛化有明确价格；预算不足时不应假装组合已认证，应演示/分解/拒绝。

**引理 21（接地并置 ≠ 理解）** 存在两原子各自 `risk≤ε`，但共享指称或可供性耦合使联合 `risk(⋄)≥2ε−o(1)`；故 `∀j Cert(π_j,o_j) Valid ⇏ Cert(⋄_j) Valid`。系：组合证书必须显式计算 `I_cross`；「每个词都对」不是「整句话对」的充分条件。

**引理 22（可证伪澄清的防自证上界）** 问题对领先/替代解释的答案可分性 f、回答噪声 ≤η 时，错误领先解释经 k 次独立澄清后存活概率 `≤(1−f+η)^k`；`f=0` 时恒为 1。系：不可证伪的澄清只是在给错误理解盖章；`F(g)≥f_min` 是语义安全必要条件。

**定理 18（PRISM 严格包含 R69）** A103–A107 下，PRISM 期望风险 ≤ R69；当 `|H_α|=1`、`d_obj=0`、`I_cross=0` 时逐指令相同。语义未消解/组合未认证/物体出契约/SCG 越界/检测到注入时，单调不降地退化为 R69 保守路径或安全停止。R69 = 「唯一解析、零对象差、零交互」边界。

**定理 19（语义安全无突变）** 澄清/解释切换只改「选哪个可信解释」，不改物理安全包络；CSP 限制在 `H_α` 公共安全前缀，LSC 保证 `S(h)⊆S_phys`；无公共前缀即澄清/拒绝。R68 定理 15、R69 定理 17 的换装不变式保持 ⇒ 无突变、无越界。

**定理 20（跨物体/组合泛化的收益条件）** 正迁移 >0 ⇔ 相关原子对象契约 Valid ∧ `I_cross≤δ_sem` ∧ 证据可支付 `ΣB*` 在预算内；否则存在负迁移风险，必须降级为演示/探索/拒绝。⇒ 不是所有词都能跨物体迁移，也不是所有新组合都能由组合性免费获得；证明「此处不该泛化」本身是有效结论。

**定理 21（澄清终止性）** 有限可信集 + 可证伪问题集 + 硬预算下，PRISM 要么在 `K_clar` 次内收缩到可认证，要么进入保守/拒绝分支；不存在无限追问。澄清是有预算的认识论行动。

## 7. 本轮最大风险

**一句话**：PRISM-RAS 的全部语义安全押在「解析器与指称后验的置信度是诚实的」这一前提上——但最隐蔽的失败是**语义自证**：语义假设与澄清问题都由同一个可能自信出错的解析器生成，问题只覆盖领先解释已蕴含的答案，人（或模型复述）一句「是」就把幻觉出的指称/谓词盖上「已验证」的章；系统于是**带着一张合格的 J_PRISM 执行了错误的理解**——**听错动作还能闭环纠正，理解错意义却会把错事做完；语义幻觉比动作幻觉更危险。**

**次级风险与缓解**：组合交互项被低估（CCA 显式重算 + 引理 21 + E305）；指称投毒/共指诱导（独立指向/演示 + k-正交证据 + E310）；具身指令注入（来源血统 + `ℰ_instruction_injection` + E309）；解析延迟击穿预算（解析一次/缓存 + 控制环只查表 + 复杂度表）；澄清疲劳/谄媚（可证伪门槛 `f_min` + 预算硬约束 + E316）；校准门被「表面相似」骗过（`Δs,Δo` 对偶 + SCG 越界即退 R69 纯保守）。
