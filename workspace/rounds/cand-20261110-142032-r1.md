# 第 45 轮（承接第 44 轮 v9；本轮灵感：安全性 × 多模态交互） · Safety-Case × Multimodal-Intent：把「安全」从谓词 soundness 升为「危险完备性的可审计安全案例」，把「多模态交互」升为「失败独立、冲突感知、带权威证明的意图根信任」（五层架构 v10）

> 承接第 44 轮 v9（Pose-Cert × Data-Cert）。v9 把「姿态」做成根信任、把「数据采集」做成审计闭环，解决了 (H3)「位姿只是点估计 + 粗糙噪声界」。但 v9 与整个 v17–v9 证书栈仍共享一个更上位、也更危险的未言明假设：**(H4) 谓词集合与危险模型是完备的，且人类意图 g 是已正确接收的既成事实**。v9 证明的是「给定 φ 与 g，动作是否 sound」，却从未证明「φ 覆盖了所有会杀人的 h」、也从未给「g 是否真是人类想要的那个 g」发过证书。本轮两个灵感词精确命中 (H4)：**安全性**迫使我们把「安全」从逐谓词 soundness 升级为**可追溯、可审计、承认不完备的危险—约束—谓词—证书安全案例**（sound ≠ safe，安全是证据而非证明）；**多模态交互**迫使我们把「意图」从 VLM 的既成事实升级为**分层覆盖、失败独立、冲突感知、带来源与权威证明的意图根证书**。二者耦合出本轮真正的新问题：**安全关键度由动作语义决定，动作语义由多模态解释决定；多模态通道既是安全冗余（可澄清、可交叉验证），又是共因/欺骗/冲突的入口——若把「跨模态一致」误当成正确性证据，系统会在共同幻觉上给出几何完美、语义致命的一击**。

## 0. 直觉与动机

**灵感 1（安全性 → 从「谓词 sound」到「危险完备性的安全案例」）**
直觉：证明「每个写下的谓词都成立」不等于「没有会出事的危险」。漏掉的那个危险，不会被任何证书覆盖，而且恰恰在系统最自信时静默发生。真实安全工程（STPA / UL 4600 / ISO 26262）从不宣称危险模型完备，而是维护一条**可审计的论证链**：危险 h → 安全约束 c → 谓词 φ → 证书 cert，外加**残余危险登记**（哪些 h 尚无强制约束）、**安全绩效指标 SPI**、**近失挖掘**与**保守降级**。于是「安全」是一个 claim–argument–evidence 结构（GSN 式），可机器检查、可在每次迭代被红队攻击，而不是一句口号。

**灵感 2（多模态交互 → 意图本身需要一张根证书）**
直觉：人类说「把那个杯子给我」，同时手指向左边、眼睛看着右边。「杯子」有多个候选，「那个」的指代靠手势与注视接地，「给我」隐含接收者，「左边/右边」反映意图冲突。多模态不是加权平均，而是**保守求交**：每路模态给出一个意图集合与可靠性分层，真实意图必须落在交集里；交集为空就是冲突，交集太大就是歧义，某路未观测就是覆盖不足——三种情况都不许执行，只能**安全澄清或停机**。且和 v9 的审计独立性同构：**只有各模态失败相互独立时，「多路一致」才是正确性证据**，否则只是共因幻觉。

**灵感 3（耦合 → 语义根租约与双根级联）**
直觉：姿态根回答「东西在哪」，语义根回答「要做什么、谁让做的、指向谁」。执行证书必须**同时**持有∠有效的几何根租约与语义根租约；语义根一旦失效（出现新冲突话语、指代物离开其姿态证书、权威被撤销、澄清超时），所有依赖它的执行证书立刻级联作废。这补上了 v9 一个隐蔽漏洞：v9 能证明「我把 A 撞向 B 是安全的」，却没有人问过「人类根本没让你动 B」。

**耦合升级**：新增 **IP-63 SCE（安全案例引擎）**、**IP-64 MIC（多模态意图证书）**、**IP-65 APG（权威与来源守卫）**、**IP-66 SSM（语义一致性监控）**。五层架构 v10 在 v9 的姿态根之上增加**语义/安全案例层**：多模态输入 → 意图证书 → 指代接地 → 权威证明 → 危险追溯 → 语义根租约；只有语义根 ∧ 姿态根同时有效，才签发执行证书。

## 1. 形式化定义（增量：定义 50–55）

**定义 50（危险—约束—谓词—证书安全案例与残余危险）**
设危险集 H（开放世界，含 unknown），安全约束 C(h)，谓词 φ_c，证书 cert(φ_c, P_t)。追溯关系 τ: H → 2^C → 2^Φ → certs。**安全案例** SC = (H, τ, R, SPI)，其中残余危险 R = {h∈H : τ(h) 无强制且 sound 的证书}。SC **有效**当且仅当：(i) 每个 h∉R 都被至少一条强制且 sound 的约束覆盖；(ii) 残余聚合风险 risk(R) ≤ 可接受预算，且每个 h∈R 都配有监控 + 遏制；(iii) SPI 在阈值内；(iv) 证据未过期。**完备性不可证**：SC 只保证「已建模部分 sound」，故必须维护 unknown-hazard 储备并允许近失挖掘把新危险回灌 τ——这与 v9 的「未观测姿态层不发证书」同构：**未建模危险 → 保守模式，而非默认安全**。

**定义 51（多模态意图证书与失败独立交集融合）**
模态集 M = {语音, 手势, 注视, 表情, 触屏, 屏幕文本, …}，每路可靠性分层 ω_m（语音 SNR/混响、手势可见性/遮挡、注视有效性、触屏精度、UI 可信度）。在**封闭意图本体 𝓘**（含 unknown/other 兜底 token）上，每路给出意图集 I^m ⊆ 𝓘 满足条件覆盖 P(I*∈I^m | ω_m=ω) ≥ 1−α_m。**融合取交集**（保守，安全类禁止加权平均）：
I_t = ∩_{m∈M_present} I^m，其覆盖由联合界 P(I*∈I_t) ≥ 1 − Σ_m α_m − ε_cc，ε_cc 为共因膨胀。**失败独立公理**：只有当各模态失效相互独立（或 ε_cc 被界住）时，「多路一致 ⟹ 更可信」才成立；否则一致只是共因幻觉。这正是 v9「审计必须独立于采集」的语义对偶。

**定义 52（冲突、歧义与安全澄清）**
状态 S_t ∈ {CONSISTENT, CONFLICT, AMBIGUOUS, UNCOVERED}：交集为空 → CONFLICT；交集熵/intent 集合基数超过关键度阈值 τ_amb → AMBIGUOUS；任一路未观测或覆盖不足 → UNCOVERED。只有 CONSISTENT 且完成接地才允许执行。否则选择澄清动作 a ∈ A_clarify，最大化「意图不确定度下降 / (安全风险 + 人类负担)」；**澄清本身必须是可认证的安全动作**（无运动/安全停机/纯提问），澄清期间禁止任何影响安全的执行，形成 fail-closed on semantics。须显式对抗**澄清疲劳/狼来了**：频繁误澄清会训练人类盲确认，故澄清阈值需按告警式误报率校准。

**定义 53（指代接地证书）**
意图 i ∈ I_t 蕴含指代集 R(i) = {o : o ⊨ i}，每个候选物带姿态证书 P_t^o。**接地证书** G_t=(i*, R, {P_t^o}) 有效当且仅当存在唯一 o 使其余候选在 1−β 置信下被排除（姿态盒两两不相交或可判别），否则须经澄清消歧。手势/注视指向本身是带可观测性分层的姿态证书，故**接地链把语义根焊回姿态根**：语义歧义可退化为几何可判别性不足。

**定义 54（权威与来源证书，反欺骗/提示注入）**
每条指令携带来源 π_cmd = (主体 p, 通道 m, 认证级别, 活体/反重放分, 注入分, 新鲜度)。权威函数 Auth(p, action_class) ∈ {allow, deny, confirm}，action_class 按安全影响分级。**安全影响类动作**必须由已认证且权威足够的主体签发；**不可信内容不得提升权威**（文档/标牌/屏幕文字/他人语音里的"忽略之前指令"永远不携带权限，防混淆代理），即指令—数据分离。声纹/活体/手势重放/注入分类任一超阈值 → deny 或强制 confirm。

**定义 55（语义根租约与双根级联）**
语义根租约 ℓ_s = (I_t, S_t, G_t, A_cmd, τ_s, Δ_s)，有效当且仅当 S_t=CONSISTENT ∧ G_t 唯一接地 ∧ A_cmd∈{allow} ∧ 未过期。**双根命题**：执行证书 c 的可靠性依赖几何根租约 ℓ_p（定义 46）与语义根租约 ℓ_s；任一失效则 c 级联作废，只允许安全停机/澄清。语义根因新冲突话语、主体撤销、指代物离开其姿态盒、澄清超时而失效——语义必须与物理同步失效，不能"先执行完再说"。

## 2. 四大新增产出与既有 IP 升级

### 2.1 IP-63 SAFETY-CASE-ENGINE（安全案例引擎 SCE）
1. **危险登记与追溯**：维护 H→C→Φ→cert 的机器可检查追溯图；标注强制/非强制、sound/未证。
2. **残余危险与安全预算**：显式列出未覆盖 h、其监控与遏制、聚合风险是否在预算内；承认完备性不可证。
3. **SPI 与近失挖掘**：以领先指标（近失、澄清率、否决率、语义漂移）驱动危险再分析；新危险回灌 τ 并触发保守模式。
4. **保守降级**：unmodeled hazard / SPI 越界 / 证据过期 → 进入保守安全模式，禁止依赖未覆盖能力的执行。

### 2.2 IP-64 MULTIMODAL-INTENT-CERT（多模态意图证书 MIC）
1. **分层共形意图集**：每路模态在其可靠性层上产出封闭本体上的意图集合与覆盖保证。
2. **失败独立交集融合**：保守求交 + 联合界 + 共因膨胀 ε_cc；检测"伪共识"。
3. **冲突/歧义/未覆盖状态机**：显式区分四种状态，非 CONSISTENT 一律不执行。
4. **指代接地**：意图→指代集→物体姿态证书，唯一接地才放行；手势/注视指向复用姿态证书。
5. **安全澄清策略**：以信息增益/安全风险/人类负担为效用，抗澄清疲劳，澄清动作自身可认证。

### 2.3 IP-65 AUTHORITY-PROVENANCE-GUARD（权威与来源守卫 APG）
1. **来源与认证**：主体/通道/活体/反重放/新鲜度，声纹与手势重放检测。
2. **权威矩阵**：主体角色 × 动作安全类 → allow/deny/confirm；安全影响动作强制已认证主体。
3. **指令—数据分离 / 反提示注入**：屏幕文本、标牌、他人语音、VLM 读取的文档内容永不提升权限；注入分类超阈值拒绝。
4. **混淆代理防护**：不可信通道不能借可信通道的权限执行其内容；权威不随内容传播。

### 2.4 IP-66 SEMANTIC-SAFETY-MONITOR（语义一致性监控 SSM）
1. **意图—动作一致性**：运行时校验实际动作蕴含已认证意图；语义漂移即否决。
2. **语义根有效性守卫**：ℓ_s 失效/指代越界/权威撤销 → 即时否决而非事后回滚。
3. **双根联检**：安全关键步同时检查几何根与语义根，任一失效即 fail-closed。

## 3. 五层架构 v10

```
语义/安全案例层（新，位于姿态根之上）:
  语音/文本/手势/注视/表情/触屏/UI
    → IP-64 MIC: 各模态分层意图集 → 失败独立交集 → CONSISTENT/CONFLICT/AMBIGUOUS/UNCOVERED
    → IP-53' 指代接地: 意图 → 指代集 → 物体姿态证书（唯一接地）
    → IP-65 APG: 来源/认证/权威/反注入 → A_cmd（内容不得提升权限）
    → IP-63 SCE: H→C→Φ→cert 追溯 + 残余危险 + SPI/近失 → 不完备即保守
    → 语义根租约 ℓ_s（一致 ∧ 唯一接地 ∧ 权威有效 ∧ 新鲜）
    → ℓ_s 无效 → 澄清 / 安全停机（fail-closed on semantics）
姿态根（v9）:
  PSE(ω,P_t,ℓ_p) → 未观测/退化 → P_max / fail-closed
L1: 几何/物体位姿 → C_ms/B_t/L_m；人 → H_u（以 P_t 为条件）
L2: CTC + VLM + 仲裁 → 分支池（检索键含 ω/护照/意图类/权威）
L3: CAR(margin = min(查表,租约,persona) − L_φ·rad(P_t)，前置 ℓ_s)
    → IP-49 □ 提升 → IP-47 组合 → IP-39 规划
    → IP-45 总线(intent/authority/safety-case) → IP-53 CMC + IP-66 SSM
L4: DCL/CCA（含语义与近失层）→ 重校准 → 证书热更新
运行期：意图证书 → 接地 → 权威 → 危险追溯 → 双根校验 → 执行
        任一语义状态非 CONSISTENT 或 ℓ_s 失效 → 澄清/停机，绝不"先执行"
```

## 4. 实验设计（E103–E110 硬门槛，承接 E95–E102）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E103 安全案例完备性 | 危险追溯覆盖率；残余危险登记完整性；近失挖掘召回；SPI 越界检出 | ≥90% 已建模危险；100% 登记；≥95%；≥95% |
| E104 多模态意图覆盖 | 各 ω_m 层条件覆盖；最差层覆盖；四状态分类准确率；共因膨胀校准 | ≥1−α_i；≥1−α_i−2%；≥95%；ε_cc 误差<20% |
| E105 冲突与澄清安全 | 冲突/歧义下不安全执行；澄清成功率；解除时延；澄清疲劳率 | 0 起；≥95%；<2s；<10% |
| E106 指代接地 | 歧义检出率；错物抓取率；唯一接地准确率；接地时延 | ≥99%；0；≥99%；<100ms |
| E107 权威与来源 | 伪装语音/手势重放/注视伪装拒绝率；提示注入拒绝率；越权拦截；混淆代理 | ≥99%；≥99%；100%；0 起 |
| E108 语义一致性监控 | 语义漂移检出；误否决率；否决时延；双根联检覆盖 | ≥99%；<2%；<50ms；100% |
| E109 100h 语义-物理闭环 | 语义层面不安全动作；残余危险逃逸；误澄清；双根一致率 | 0 起；0；<5%；≥99.9% |
| E110 对抗多模态套件 | 共因误解/伪共识；通道欺骗组合；语义-几何联合攻击 | ≥95% 检出；≥95%；0 起 |

## 5. 本轮最大风险

**一句话**：安全案例的危险模型本质不可证完备（sound ≠ safe），而语义根的"正确性"又依赖多模态解释——一旦审计与采集、或模态间失效不独立（共因/伪共识），或权威模型被错误配置，系统就会在"几何完美、语义做错"的动作上静默失效；因此 E103（危险完备性追溯）与 E107（权威/来源/反注入）必须设为红线，默认回退到「只响应单一已认证可信通道 + 姿态保守盒 + 语义不确定即澄清或安全停机」这条永不失 sound 的底线。

### IP-63 SCE：危险追溯、残余危险、近失挖掘与保守模式

```
def build_safety_case(hazards, constraints, predicates, certs):
    trace = {h: [c for c in constraints.get(h, []) if c.enforced_by(predicates)]
             for h in hazards}
    residual = [h for h in hazards
                if not trace[h] or not all(cert_sound(c, certs) for c in trace[h])]
    return SafetyCase(trace=trace, residual=residual, hazards=hazards)

def safety_case_valid(sc, spi, risk_budget):
    modeled_ok = all(sc.enforced(h) for h in sc.hazards if h not in sc.residual)
    residual_ok = (aggregate_risk(sc.residual) <= risk_budget
                   and all(h.has_monitor() and h.has_containment()
                           for h in sc.residual))
    return modeled_ok and residual_ok and spi.within_thresholds() \
           and not sc.evidence_stale()

def near_miss_mining(logs, hazard_model):
    # 近失是"差一点出事"的领先指标，用于发现未登记危险
    return [nm for nm in detect_near_misses(logs, hazard_model)
            if nm.hazard not in hazard_model.registered]

def on_unknown_hazard(sc, h_new):
    sc.residual.append(h_new)                        # 登记，不假装不存在
    return enter_conservative_mode('unmodeled_hazard')  # sound≠safe，保守
```

## 6. 本轮最大风险

**一句话**：安全案例的危险模型本质不可证完备（sound ≠ safe），而语义根的"正确性"又依赖多模态解释——一旦审计与采集、或模态间失效不独立（共因/伪共识），或权威模型被错误配置，系统就会在"几何完美、语义做错"的动作上静默失效；因此 E103（危险完备性追溯）与 E107（权威/来源/反注入）必须设为红线，默认回退到「只响应单一已认证可信通道 + 姿态保守盒 + 语义不确定即澄清或安全停机」这条永不失 sound 的底线。
