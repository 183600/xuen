# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；本轮灵感：「人形机器人」×「多端口部署」）

> R69 让系统学会了「问」，并把不确定性一分为二（aleatoric / epistemic）。但它有一个从未被点破的隐含前提：**系统始终站在同一具身体、同一个端口上**——动作空间固定、安全包络固定、证书是单点签发的。两个新灵感把这个前提直接击穿：
> - **人形机器人**不是「多几路传感器的手臂」。浮基、~30–50 自由度、接触丰富，让同一任务拥有**连续的零空间自运动族**；R69 的 K 个离散模态只是这个连续族的粗糙投影。更致命的是，人形最大的风险不是「选左还是选右」，而是**整条全身动作会摔倒、自碰撞、超力矩**——这类不确定性不在任务语义里，交互问不出来。
> - **多端口部署**意味着同一个策略被复制到 N 个身体 / 总线 / 站点 / 软件版本上。R69 的证书 J_FLUID 是**端口局部**的；把它复制到另一个端口，是把「认证」偷换成「拷贝」——这是安全剧场。
>
> 核心命题：**证书不应被「复制」，只应被「运输」。** 引入端口契约、端口间形态同态 φ、以及显式的风险膨胀 ρ_trans；把不确定性扩成三分解 (U_ale, U_epi, U_emb)，其中 U_emb（可执行性 / 具身不一致）既不能靠交互消解，也不能靠拷贝掩盖，只能靠机械投影或带证明的运输；舰队安全取**最坏端口**而非平均。命名 **PORTAL-RAS**（Portable, Outcome-certified, Redundancy-aware, Transport-Audited Loop）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我在这具身体、这个端口上认证的安全，换一具身体、换一个端口还算数吗**」。

## 0. 直觉与动机

**灵感 1（人形机器人 → 冗余把「模态」变成流形，任务等价 ≠ 机械等价）**
直觉：你让一个人形机器人「把杯子放到桌上」，它有无数种肘部 / 腰部 / 腕部的自运动都能完成同一任务。这些自运动在任务空间里**没有差别**，但在机械空间里差别巨大：有的省力矩、有的逼近关节限位、有的让手臂挡住视野、有的在下一步会失去平衡。R69 用 DTW / Fréchet 对轨迹聚类，会把这些自运动误判成「不同的 epistemic 模态」，于是把宝贵的交互预算浪费在「问一个任务上根本不需要问的问题」。正确做法是先按任务映射做**商**（quotient），把零空间纤维折叠掉；零空间内部的差异交由机械代价（力矩裕度、自碰撞、可操作性、平衡）处理。**任务歧义与机械歧义必须分开，因为它们由完全不同的手段消解。**

**灵感 2（人形机器人 → 平衡是全身包络，不是逐关节盒子）**
直觉：每个关节都在限位内，不代表机器人不会倒。真正的安全集是 CoM / ZMP 支撑多边形、接触力锥、力矩上限、自碰撞共同定义的**全身可行流形** ℱ_𝒫。一个「看起来温和」的动作可以逐关节安全却动态不可行；反之一个大幅动作可能完全在包络内。R69 的风险缩放 λ 作用在动作幅值上，但**幅值小 ≠ 平衡裕度大**。所以本轮必须把安全判据从「动作大小」换成「到可行域边界的裕度 m(ξ)」，并在采样后立即投影 / 拒绝。

**灵感 3（多端口部署 → 证书有定义域，拷贝不是运输）**
直觉：软件里把一个二进制从 A 机器拷到 B 机器，能不能跑取决于 ABI / 依赖 / 硬件；你不会因为「在 A 上测过」就宣称「在 B 上安全」。机器人证书同理：它绑定 (策略哈希, 契约哈希, 标定哈希)。多端口部署的正确动作不是 copy(cert)，而是 **transport(cert, φ)**：给出一个把 A 的动作空间映射到 B 的形态同态 φ，证明它双 Lipschitz、近似保持任务、把可行域装进 B 的可行域（允许 ε_env 松弛），再为风险付一笔**显式的、可审计的膨胀** ρ_trans。ρ_trans 超预算 ⇒ 拒绝部署；没有 φ ⇒ 不是「同款机器人」，必须本地重认证。

**灵感 4（多端口部署 → 舰队安全是最坏端口，且证据不可跨具身搬运）**
直觉：100 台机器人里 99 台完美、1 台会摔，不能说舰队「99% 安全」然后上线——安全是**全称命题**，不是平均值。所以 FCM 的判据是 max_p R_p，任何单端口越界都否决整批。与此同源的一个更隐蔽的坑：在 A 上通过交互得到的答案，哪些能搬到 B？「杯柄在左边」是任务语义，可搬；「关节 3 需要 8 N·m」是具身事实，不可搬。R69 的证据纪律假设证据可共享，在多端口下必须加上**可迁移类**的过滤，否则 A 的标定 / 交互会污染 B。

**灵感 5（运输也是攻击面 → 假同态比不同态更危险）**
直觉：一旦系统信任 φ 和 ρ_trans，攻击就集中到「让 φ 看起来合法」：投毒的重定向映射、伪造的契约指纹、版本回滚、热切换竞态。**一个被认证为安全的错误部署，比一个明确拒绝的部署危险得多**——因为它让所有人放下了戒心。所以本轮必须交付：契约指纹与来源链、运输门 STG、对抗性 φ 干扰集、热切换安全交接、以及「运输失败即 fail-closed」的四级退化。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（PORTAL-RAS 总览与四不变式）** PORTAL-RAS = (HMC, RSP, EUD, CTP, STG, BFE, PIP, FCM, VQAuditor-P, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i；端口自适应亦不得在线改参）；
(ii) **契约绑定**：任何进入实时环的动作与证必须绑定三元组 (h_π, h_𝒫, h_cal)；未绑定者拒绝执行；
(iii) **运输健全性**：跨端口复用证书只能经 STG 并满足 ρ_trans ≤ ρ_max；**拷贝不等于运输**，无 φ 的复用按无效处理；
(iv) **最坏端口安全**：舰队 Valid ⇔ ∀p Valid(J_p)，均值 / 通过率不得覆盖任一单端口越界。

**定义 311（端口与部署契约 HMC）** 一个端口 p = (身体拓扑, 总线 / 接口, 站点, 软件栈)。契约 𝒫_p = (𝒯_p, n_p, q_min, q_max, τ_max, q̇_max, 传感器集与延迟 ℓ_p, 平衡模型 ℬ_p, 控制器版本)；其可行动作集 𝒜_{𝒫_p} 与可行包络 ℱ_{𝒫_p}（定义 315）。契约指纹 h_{𝒫_p} = H(规范化契约)。

**定义 312（任务映射与零空间）** 任务映射 T_𝒫: 𝒜→𝒯（末端位姿、CoM、接触旋量等），雅可比 J_T = ∂T/∂a。零空间 𝒩_𝒫(a) = ker J_T(a)。若 T(a)=T(a')，称 a 与 a' **任务等价**；商空间 𝒜/𝒩 为任务相关动作空间。纤维 a+𝒩 称为自运动族。

**定义 313（不确定性三分解）** U = (U_ale, U_epi, U_emb)：
- U_ale = Σ_k ŵ_k tr(Σ_k)（模态内噪声，不可约）；
- U_epi = H_mode·g(Δ_min)（任务相关模态间歧义，可由 R69 交互消解）；
- **U_emb**（具身 / 可执行性）= 𝔼_{ξ~π}[ max(0, −m(ξ)) ] + D(π_B ‖ φ_#π_A)，即到可行域边界的期望越界量 + 跨端口分布失配。三者语义不同，进入三条不同通道（定义 326），**不做简单加和**。

**定义 314（冗余感知采样 RSP）** 对 K 条流样本，先经 BFE 投影到 ℱ_𝒫，再按任务类 T(ξ) 聚类：任务等价的样本归为同一 **任务模态**，其内部自运动差异记为纤维方差 V_fib（进入机械代价，不进入 U_epi）。仅当两个任务类在 𝒯 中可分（Δ_min^𝒯 ≥ 3σ_in^𝒯）时才算真歧义。A100：任务类聚类与零空间投影可交换（在投影为仿射的邻域内）。

**定义 315（平衡与可行包络 BFE）** ℱ_𝒫 = { ξ : q∈[q_min,q_max], τ(q,q̇,q̈)∈[−τ_max,τ_max], CoM(q)∈𝒵(contacts), 接触旋量∈摩擦锥, 无自碰撞 }。裕度 m(ξ) = dist(ξ, ∂ℱ_𝒫)（带符号，内正外负）。安全执行要求 m(ξ) ≥ m_safe；投影 Π_ℱ 由全身 QP 实现。

**定义 316（端口同态 φ）** φ_{A→B}: 𝒜_A→𝒜_B（重定向 / 形态映射），附任务对应 φ_T: 𝒯_A→𝒯_B，需满足：
- **双 Lipschitz**：l_φ‖a−a'‖ ≤ ‖φ(a)−φ(a')‖ ≤ L_φ‖a−a'‖；
- **任务近似交换**：‖T_B(φ(a)) − φ_T(T_A(a))‖ ≤ ε_task；
- **包络保持**：φ(ℱ_A) ⊆ ℱ_B ⊕ ε_env·B₁；
- **分布等变**：W_2(φ_#π_A, π_B) ≤ δ_ret。
任一条无法界定 ⇒ 两端**不可运输**。

**定义 317（证书运输与风险膨胀 CTP）** 给定有效 J_A 与同态 φ，运输证书 J_{A→B} = (J_A, h_φ, ρ_trans)，其中
ρ_trans = L_risk·(L_φ·δ_ret + ε_task + ε_env) + L_π·max(0, L_φ/l_φ − 1)·U_epi,A + ε_est，
L_risk 为风险泛函对动作 / 结果的 Lipschitz 常数，L_π 为策略对动作扰动的敏感度，ε_est 为常数估计误差。Valid ⇔ ρ_trans ≤ ρ_max ∧ 三哈希一致或已在 B 重导出。**无 φ 的拷贝按无效论处。**

**定义 318（安全运输门 STG）** 仅当 φ 的双 Lipschitz 常数有界、ε_env ≤ ε_env^max、ε_task ≤ ε_task^max、δ_ret ≤ δ_ret^max、来源链一致、且 ρ_trans ≤ ρ_max 时放行；否则拒绝运输，转端口本地重认证；本地认证亦不可得 ⇒ 拒绝部署（fail-closed）。

**定义 319（端口身份与来源链 PIP）** 证携带 (h_π, h_𝒫, h_cal, h_code, h_φ, nonce)；任一不匹配即拒部署。检测版本偏移（策略 / 契约 / 标定漂移）与伪造契约；replay log hash 把证与真实执行绑定，防重放。

**定义 320（舰队认证管理 FCM）** 端口语义 P={p_1..p_N}；R_fleet = max_p R_p；Valid_fleet ⇔ ∀p Valid(J_p) ∧ ∀ 运输 ρ_trans ≤ ρ_max。**均值、通过率、P99 成功率均不得替代 max**。

**定义 321（端口漂移隔离）** 每个端口的标定 c_p 与残差 r_res,p 为端口私有；跨端口聚合标定统计被禁止，除非在 φ 下运输；共享学习只在离线进行。防止 A 的在线自适应污染 B（跨端口灾难性混染）。

**定义 322（交互证据可迁移类）** τ(e) ∈ {task, embodiment, mixed}：任务语义（「杯柄在左」）可跨端口迁移；具身事实（「关节 3 需 8 N·m」）不可迁移，必须在目标端口重新获取。只有 τ(e)=task 的证据可进入跨端口后验更新。

**定义 323（热切换与安全交接）** 中途切换活动端口需存在重叠动作前缀 k_∩，使两端口包络均包含该前缀且 m ≥ m_safe；无重叠 ⇒ 冻结并重规划（stop-and-replan），**禁止盲切**。

**定义 324（证书 J_PORTAL）** J_PORTAL = (J_FLUID, h_𝒫, h_φ, ρ_trans, U_emb, m_min, provenance_hash, fleet_worst_case, portal_ver)。Valid ⇔ Valid(J_FLUID) ∧ U_emb ≤ τ_emb ∧ m_min ≥ m_safe ∧ 来源链一致 ∧（运输有效 ∨ 本地认证有效）。

**定义 325（组合审计 VQAuditor-P）** 审计跨端口复用（每次部署须有运输证明或本地证）、版本偏移、最坏端口偏差、端口漂移隔离、证据可迁移越界、热切换竞态；结论回灌契约注册表与 STG 阈值。

**定义 326（四级保守退化）** 运输无效 → 端口本地重认证（R69 FLUID）；本地证不可得 → R69 纯保守（不交互）；契约不匹配 / 不可验证 → R68 纯保守；契约未知 → **拒绝动作（安全停机）**。严格包含：单端口 + φ=id + ρ=0 + U_emb=0 ⇒ PORTAL 逐指令等于 FLUID，再退化为 R68。

## 2. 关键算法骨架

```python
# IP-264 HMC：加载并校验端口契约（来源链）
def load_contract(port):
    c = ContractRegistry.get(port.fingerprint)
    if c is None or c.hash != port.contract_hash or c.code_hash != port.code_hash:
        raise ContractMismatch(port)          # fail-closed
    return c

# IP-265/266 RSP+EUD：冗余感知的三分解
def decompose_portal(samples, z, contract):
    feas = [project_feasible(xi, contract) for xi in samples]   # BFE Π_ℱ
    m    = [margin(xi, contract) for xi in feas]                 # 到边界裕度
    classes = group_by_task_class(feas, contract.T)              # 按任务商聚类
    U_ale = mean_trace_cov_within(classes)
    U_epi = entropy(class_weights(classes)) * sep_factor_tau(classes)
    U_emb = mean_relu_neg(m) + dist_shift(classes, contract)     # 不可由交互消除
    return U_ale, U_epi, U_emb, classes, min(m)

# IP-267/268 CTP+STG：证书运输（部署期，非实时环）
def transport_certificate(J_A, phi, contract_B):
    pr = fit_morphism(phi)        # L_phi, l_phi, eps_task, eps_env, delta_ret
    rho = (L_risk*(pr.L_phi*pr.delta_ret + pr.eps_task + pr.eps_env)
           + L_pi*max(0, pr.L_phi/pr.l_phi - 1)*J_A.U_epi + pr.eps_est)
    return J_A.with_(port=contract_B.hash, phi_hash=pr.hash, rho_trans=rho)

def safe_transport_gate(J_A, phi, contract_B):
    pr = fit_morphism(phi)
    if not (pr.bi_lipschitz_ok and pr.eps_env <= EPS_ENV
            and pr.eps_task <= EPS_TASK and pr.delta_ret <= DELTA_RET):
        return None                                   # 拒绝运输
    J_B = transport_certificate(J_A, phi, contract_B)
    if J_B.rho_trans > RHO_MAX or not provenance_ok(J_B):
        return None
    return J_B

# IP-275 主闭环（继承 R69，仅在不确定性处置前插入端口层）
def PORTAL_RAS_round(M, obs, port):
    contract = load_contract(port)
    z, o = M.mtm.forward(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, U_emb, modes, m_min = M.rsp.decompose_portal(samples, z, contract)
    # 1) 具身不确定性不可问：先机械投影，再决定是否还值得问
    if U_emb > TAU_EMB or m_min < M_SAFE:
        mode = M.bfe.project_safe(modes, contract)
        lam  = lam_floor(U_ale + U_epi)               # 机械侧已收紧
        return M.exec_conservative(mode, lam, contract)
    # 2) 任务歧义才交给交互，且只接收可迁移证据
    g, ans = None, None
    if U_epi > TAU_EPI and not M.fma.slow_fault_suspect:
        g = M.mint.choose_interaction(modes, o, M.budget)
        if g is not None:
            ans = M.cia.execute(g)
            if M.pip.transfer_class(ans) != "task":
                ans = None                            # 具身证据不跨端口
    U_epi_after = M.cia.update_belief(modes, ans) if ans else U_epi
    # 3) 证书：运输有效则用，否则本地重认证，再否则退化 / 停机
    J = M.stg.use_transported(port) or M.stg.recertify_local(port)
    if J is None:
        return M.fail_closed(port)                    # 定义 326
    # 4) 最坏端口门：本端口合格才允许进入执行
    if not M.fcm.admit(port, J):
        return M.fail_closed(port)
    mode = select_mode(modes, U_epi_after, J.min_margin)
    k    = M.c_ras_wm.certified_prefix(mode, contract, J)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam_floor(U_ale + (U_epi_after if g is None else 0))
    M.vqa_p.submit_async(port, J, g, ans, U_emb, m_min)   # 组合审计
    return k, tau, mode, J
```

## 3. 推导

**引理 19（零空间的任务 VoI 恒为零）** 若 a' ∈ a+𝒩_𝒫，则 T(a')=T(a)，对任何只改变自运动、不改变任务类别的信息动作 g，有 I(M_task; y|g)=0。故 R69 的 MINT 会把预算花在任务上无差别的纤维上；而该纤维仍可能越界（U_emb>0）。**系：任务歧义与机械歧义必须分离——前者可问，后者只能投影。**

**引理 20（风险运输上界）** 在 A99（风险泛函 L_risk-Lipschitz、φ 双 Lipschitz、任务近似交换、包络松弛 ε_env、分布失配 δ_ret）下，目标端口风险满足 R_B ≤ R_A + ρ_trans，ρ_trans 如定义 317。证明：用 Wasserstein 耦合把 π_A 推到 π_B，风险差异被三段分解——任务偏移（ε_task）、包络越界（ε_env）、分布失配经 L_φ 放大（δ_ret）——再乘风险 Lipschitz 与策略敏感度；常数估计误差计入 ε_est。**系：ρ_trans 是可审计的「保险费」，不是拍脑袋的折扣。**

**引理 21（最坏端口支配均值）** R_fleet = max_p R_p。若 ∃p: R_p > ε，则无论其余 N−1 台多好，R_fleet > ε。故「平均成功率」「99% 通过」都不能作为舰队认证依据。**系：多端口部署的第一原则是排除不合格端口，而不是稀释它。**

**定理 18（PORTAL 严格包含 FLUID / R68）** 取单端口、φ=id（L_φ=l_φ=1, ε_task=ε_env=δ_ret=0）、U_emb=0，则 RSP 的任务商聚类退化为 R69 的模态聚类，ρ_trans=0，STG 恒放行，PORTAL 的每条指令与 FLUID 相同；再取 VoI≤成本 / ECE 越界，则退化为 R68。运输无效时按定义 326 单调退化，安全侧永不变弱。

**定理 19（运输安全与热切换连续性）** 经 STG 放行的证书满足部署端口风险 ≤ ε；热切换仅在存在满足双端口包络的重叠前缀 k_∩ 时执行，此时控制指令在切换点连续（有界 jerk）；无重叠则 stop-and-replan，不产生任何未认证动作 ⇒ 无突变、无越界。

## 6. 本轮最大风险

**一句话**：PORTAL-RAS 的全部可移植性押在「形态同态 φ 及其 Lipschitz 常数是可信的」这一前提上——**若 φ 本身是学出来的、估偏的、或被投毒，ρ_trans 就会被系统性低估，系统会带着一张「已认证」的证书把策略部署到一具它其实覆盖不了的身体上**；一个被认证的错误部署，比一个被拒绝的部署危险得多——**假同态，比不同态更致命**。

**次级风险与缓解**：
1. **U_emb 估计过高导致过度保守**（大量动作被投影掉）→ 裕度-风险 Pareto 曲线 + E303 调参，宁可保守不可越界；
2. **任务商聚类不可交换**（投影非线性时）→ A100 的仿射邻域假设 + 局部重投影 + E301 验证；
3. **热切换竞态**（两端同时认为自己活动）→ 单写者令牌 + 定义 319 的 nonce + E311；
4. **版本偏移被忽略**（新代码复用旧证）→ PIP 哈希绑定 + E306 零静默错部署；
5. **证据跨具身污染** → 定义 322 可迁移类过滤 + E308 越界迁移零容忍。

    c = ContractRegistry.get(port.fingerprint)
    if c is None or c.hash != port.contract_hash or c.code_hash != port.code_hash:
        raise ContractMismatch(port)                  # fail-closed

# IP-265/266 RSP+EUD：冗余感知三分解
def decompose_portal(samples, z, contract):
    feas = [project_feasible(xi, contract) for xi in samples]   # Π_ℱ
    m    = [margin(xi, contract) for xi in feas]
    classes = group_by_task_class(feas, contract.T)              # 任务商聚类
    U_ale = mean_trace_cov_within(classes)
    U_epi = entropy(class_weights(classes)) * sep_factor_tau(classes)
    U_emb = mean_relu_neg(m) + dist_shift(classes, contract)     # 交互消不掉
    return U_ale, U_epi, U_emb, classes, min(m)

# IP-267/268 CTP+STG：证书运输（部署期）
def transport_certificate(J_A, phi, contract_B):

    rho = (L_risk*(pr.L_phi*pr.delta_ret + pr.eps_task + pr.eps_env)
           + L_pi*max(0, pr.L_phi/pr.l_phi - 1)*J_A.U_epi + pr.eps_est)
    return J_A.with_(port=contract_B.hash, phi_hash=pr.hash, rho_trans=rho)

def safe_transport_gate(J_A, phi, contract_B):
    pr = fit_morphism(phi)
    if not (pr.bi_lipschitz_ok and pr.eps_env <= EPS_ENV
            and pr.eps_task <= EPS_TASK and pr.delta_ret <= DELTA_RET):
        return None                                  # 拒绝运输
    J_B = transport_certificate(J_A, phi, contract_B)
    return J_B if (J_B.rho_trans <= RHO_MAX and provenance_ok(J_B)) else None

# IP-275 主闭环（继承 R69）
def PORTAL_RAS_round(M, obs, port):
    contract = load_contract(port)
    z, o = M.mtm.forward(obs)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, U_emb, modes, m_min = M.rsp.decompose_portal(samples, z, contract)

## 4. 推导

**引理 19（零空间的任务 VoI 恒为零）** 若 a' ∈ a+𝒩_𝒫 则 T(a')=T(a)，任何只改变自运动、不改变任务类别的信息动作 g 满足 I(M_task; y|g)=0。故 R69 的 MINT 会把预算花在任务上无差别的纤维上；而该纤维仍可能越界（U_emb>0）。系：任务歧义可问，机械歧义只能投影——两者必须分离。

**引理 20（风险运输上界）** 在 A99（风险泛函 L_risk-Lipschitz、φ 双 Lipschitz、任务近似交换、包络松弛 ε_env、分布失配 δ_ret）下 `R_B ≤ R_A + ρ_trans`。证明：以 Wasserstein 耦合把 π_A 推到 π_B，风险差分解为任务偏移 ε_task、包络越界 ε_env、分布失配经 L_φ 放大 δ_ret，再乘风险 Lipschitz 与策略敏感度，常数估计误差计入 ε_est。系：ρ_trans 是可审计的保险费，不是拍脑袋的折扣。

**引理 21（最坏端口支配均值）** `R_fleet=max_p R_p`；若存在 p 使 `R_p>ε`，则其余端口再好也有 `R_fleet>ε`。故平均成功率、99% 通过率都不能作为舰队认证依据。系：多端口部署的第一原则是排除不合格端口，而不是稀释它。

**定理 18（PORTAL 严格包含 FLUID / R68）** 单端口、φ=id（L_φ=l_φ=1，ε_task=ε_env=δ_ret=0）、U_emb=0 时，任务商聚类退化为 R69 模态聚类，ρ_trans=0，STG 恒放行，PORTAL 与 FLUID 逐指令相同；再取 VoI≤成本 / ECE 越界即退化为 R68。运输无效时按定义 326 单调退化，安全侧永不变弱。

**定理 19（运输安全与热切换连续性）** 经 STG 放行的证书使部署端口风险 ≤ ε；热切换仅在存在满足双端口包络的重叠前缀 k_∩ 时执行，切换点指令连续（有界 jerk）；无重叠则 stop-and-replan，不产生任何未认证动作 ⇒ 无突变、无越界。

## 7. 本轮最大风险

**一句话**：PORTAL-RAS 的全部可移植性押在「形态同态 φ 及其 Lipschitz 常数可信」这一前提上——**若 φ 是学出来的、估偏的或被投毒，ρ_trans 会被系统性低估，系统会带着一张「已认证」的证书把策略部署到一具它其实覆盖不了的身体上**；一个被认证的错误部署，比一个被拒绝的部署危险得多——**假同态，比不同态更致命**。

**次级风险与缓解**：U_emb 估计过高致过度保守（裕度-风险 Pareto + E303，宁保守不越界）；任务商聚类在非线性投影下不可交换（A100 仿射邻域 + 局部重投影 + E301）；热切换竞态（单写者令牌 + nonce + E311）；版本偏移被忽略（PIP 哈希绑定 + E306）；证据跨具身污染（定义 322 可迁移类过滤 + E308 零容忍）。
