### 第 2 轮灵感驱动研究记录

**灵感词**：路径规划、强化学习训练

**直觉与动机**：
先给直觉：现有 v25 证书链（USMC/SMC/RMC/MCC/SRC-USC）已经能对「给定的计划」做事后准入裁决，但它始终只是**裁判**，不是**教练**——它回答「这条计划是否安全」，却不回答「如何搜索出安全计划」「如何让学习型策略在部署时持续安全」。路径规划的本质，是在连续状态空间里搜索一条同时满足动力学、避障、时序任务与能量约束的可行轨迹；强化学习训练的本质，是通过大量试错把「哪条路能走」压缩进策略网络。二者结合时会产生一个危险的错位：**规划器会主动把系统推向任务相关的新状态，而 RL 策略的证书恰恰只在训练分布附近才可靠**。于是「规划越有创造性，策略越接近未认证区」。

再给严谨类比：受「路径规划」启发，规划器可被视为**证书生成器**——每条候选轨迹 ξ 必须附带四类可机械复核的见证：运动学/动力学可行性、膨胀间隙、STL 鲁棒度、能量预算。受「强化学习训练」启发，训练过程可被视为**证书蒸馏器**——把逐条轨迹上的离散证书判定，蒸馏为策略网络可实时查询的「状态-动作可信域」。核心洞见：**路径规划 = 证书搜索，RL 训练 = 证书蒸馏，策略执行 = 证书消费；三者必须共享同一个嵌套的「状态-动作可信域」才能闭环**。这个可信域应满足 `执行管 ⊆ 认证不变集 ⊆ 训练覆盖域`，它正是前几轮单调退化链在「时间维度」上的对偶：不仅证书集合逐层收缩，而且状态可达集也逐层收缩。

**形式化目标**：
1. 定义路径可行性证书（PFC）：轨迹 ξ=(q,q̇,q̈,τ) 满足 |q̇|≤v_max、|q̈|≤a_max、|q⃛|≤j_max，膨胀间隙 d_min(ξ)>0，STL 鲁棒度 ρ_φ(ξ)≥0，累计能量 ∫τᵀq̇dt≤E_budget。
2. 定义策略安全证书（PSC）：策略 π_θ 在认证不变集 C_cert 上满足 CBF 条件，经 shield 投影后任务是保持的（成功率不塌陷），且跟踪计划时的前向可达管 𝒯(ξ)⊆C_cert。
3. 定义训练覆盖证书（TCC）：部署管状态被训练状态以半径 ε_cov 覆盖、conformal 回报下界 ≥ R_min、Bellman 残差与策略梯度残差 ≤ δ，并对「规划选择偏差」显式做条件覆盖校正。
4. 构建规划-策略统一准入门（PPUC，v26）：`Exec_v26 = Exec_v25 ∩ Fil_plan ∩ Fil_policy ∩ Fil_train ⊆ Exec_v25`，十三条件一体。
5. 证明规划驱动的分布漂移、shield 介入、训练覆盖不足三条退化路径下，嵌套可信域与单调链的保持性；诚实区分「边际覆盖」与「条件覆盖」。

```python
# ============================================================
# IP-448 Path Feasibility Certificate (PFC) — 路径可行性证书
# ============================================================
@dataclass
class PathFeasibilityCertificate:
    """轨迹四重见证：动力学可行 + 膨胀间隙 + STL 鲁棒 + 能量预算"""
    q: Tensor                       # [T, n] 关节/构型
    qd: Tensor                      # [T, n]
    qdd: Tensor                     # [T, n]
    tau: Tensor                     # [T, n] 力矩
    obstacle_field: 'ObstacleField'
    stl_formula: 'STLFormula'
    v_max: float = 2.0
    a_max: float = 10.0
    j_max: float = 100.0
    r_safe: float = 0.05
    E_budget: float = 1.0
    dt: float = 0.01
    eps_v: float = 1e-3             # 数值/离散化容差
    eps_a: float = 1e-3
    covariances: Optional[Tensor] = None   # [T, 3, 3] 定位协方差

    def verify_kinodynamic(self) -> bool:
        """速度/加速度/jerk 上界 + 有限差分一致性"""
        qd_fd = (self.q[2:] - self.q[:-2]) / (2 * self.dt)
        qdd_fd = (self.q[2:] - 2*self.q[1:-1] + self.q[:-2]) / self.dt**2
        if (self.qd.abs() > self.v_max + self.eps_v).any():
            return False
        if (self.qdd.abs() > self.a_max + self.eps_a).any():
            return False
        jerk = (self.qdd[2:] - self.qdd[:-2]) / (2 * self.dt)
        if (jerk.abs() > self.j_max).any():
            return False
        if (qd_fd - self.qd[1:-1]).abs().max() > self.eps_v:
            return False
        if (qdd_fd - self.qdd[1:-1]).abs().max() > self.eps_a:
            return False
        return True

    def verify_clearance(self) -> bool:
        """膨胀间隙：d(ξ(t),O) - r(t) ≥ r_safe，位置取自 q 的任务空间投影"""
        for t in range(len(self.q)):
            x = self._task_space_position(t)
            r = self._inflation_radius(t)
            if self.obstacle_field.signed_distance(x) - r < self.r_safe:
                return False
        return True

    def verify_temporal_logic(self) -> bool:
        """STL 鲁棒度 ρ_φ(ξ) ≥ 0（min 语义，见 _stl_robustness）"""
        return self._stl_robustness(self.stl_formula, self.q) >= 0.0

    def verify_energy(self) -> bool:
        """∫ τᵀq̇ dt ≤ E_budget（梯形积分 + 上界）"""
        power = (self.tau * self.qd).sum(dim=1)
        energy = torch.trapz(power.clamp(min=0), dx=self.dt).item()
        return energy <= self.E_budget

    def verify_all(self) -> bool:
        return (self.verify_kinodynamic() and self.verify_clearance()
                and self.verify_temporal_logic() and self.verify_energy())

    def _inflation_radius(self, t: int) -> float:
        if self.covariances is None:
            return 0.05
        return 3.0 * torch.sqrt(torch.trace(self.covariances[t][:3, :3])).item()

    def _task_space_position(self, t: int) -> Tensor:
        # 由正运动学把 q 映射到任务空间（此处占位）
        return self._forward_kinematics(self.q[t])

    def _stl_robustness(self, phi: 'STLFormula', q: Tensor) -> float:
        # 递归：原子谓词取 g(x)；∧ 取 min；∨ 取 max；
        # □_[a,b] 取窗口 min；◇_[a,b] 取窗口 max；U 取滑动 max-min。
        return phi.robustness(q)

# IP-449 Policy Safety Certificate (PSC) — 策略安全证书
# ============================================================
@dataclass
class PolicySafetyCertificate:
    """CBF 不变性 + shield 安全 + 可达管包含 + 任务保持 + 计划一致"""
    policy: 'StochasticPolicy'        # π_θ(a|x)
    cbf: 'ControlBarrierFunction'     # V(x), L_fV, L_gV
    certified_set: 'InvariantSet'     # C_cert = {x: V(x) ≤ c}
    shield: 'SafetyShield'
    alpha_cbf: float = 0.1            # class-𝒦 系数
    gamma_cbf: float = 0.01           # 概率 CBF 违反风险
    delta_shield: float = 0.05        # 允许的 shield 介入率
    eta_task: float = 0.05            # 允许的任务保持塌陷
    eps_act: float = 0.05             # 计划-策略动作偏差容差
    disturbance_bound: float = 1e-3   # 扰动 W 的范数上界
    n_cert_samples: int = 2000

    def verify_cbf_invariance(self, tube_states: Tensor) -> bool:
        """∀x∈𝒯: 𝔼_{a~π}[L_fV+L_gVa+αV] ≥ 0（或 P(·≥0)≥1-γ_cbf）"""
        vals = []
        for x in tube_states:
            lf = self.cbf.lie_derivative_f(x)
            lg = self.cbf.lie_derivative_g(x)         # [m_a]
            a = self.policy.sample(x, n=32)            # [32, m_a]
            vals.append((lf + (lg * a).sum(-1) + self.alpha_cbf*self.cbf.value(x)))
        vals = torch.cat(vals)
        # 保守：用下分位数而非均值，避免策略尾部动作破坏不变性
        q = torch.quantile(vals, self.gamma_cbf)
        return q >= -1e-6

    def verify_shield_safety(self, tube_states: Tensor) -> bool:
        """π^s(x)=Proj_{A_safe(x)}π(·|x) 必落安全集，且介入率≤δ_shield"""
        interventions = 0
        for x in tube_states:
            a = self.policy.sample(x, n=64)
            a_s = self.shield.project(x, a)
            if (a_s - a).abs().max() > 1e-6:
                interventions += 1
            # 投影后必须满足点态 CBF 条件
            lhs = (self.cbf.lie_derivative_f(x)
                   + self.cbf.lie_derivative_g(x) @ a_s.mean(0)
                   + self.alpha_cbf * self.cbf.value(x))
            if lhs < -1e-6:
                return False
        return interventions / max(len(tube_states), 1) <= self.delta_shield

    def verify_tube_containment(self, tube_states: Tensor) -> bool:
        """𝒯(ξ) ⊆ C_cert：前向可达管完全落在不变集内"""
        return bool(self.certified_set.contains(tube_states).all())

    def verify_plan_agreement(self, reference_actions: Tensor,
                              tube_states: Tensor) -> bool:
        """计划给出的参考动作与策略均值动作偏差 ≤ ε_act（可执行性）"""
        for x, a_ref in zip(tube_states, reference_actions):
            a_pi = self.policy.mean(x)
            if (a_pi - a_ref).abs().max() > self.eps_act:
                return False
        return True

    def verify_task_preservation(self, success_rate_shielded: float) -> bool:
        """shield 介入后任务成功率不塌陷：≥ (1-η)·成功率(无 shield)"""
        return success_rate_shielded >= 1.0 - self.eta_task

    def verify_all(self, tube_states: Tensor, reference_actions: Tensor,
                   success_rate_shielded: float) -> bool:
        return (self.verify_cbf_invariance(tube_states)
                and self.verify_shield_safety(tube_states)
                and self.verify_tube_containment(tube_states)
                and self.verify_plan_agreement(reference_actions, tube_states)
                and self.verify_task_preservation(success_rate_shielded))

    def build_tube(self, plan: 'Trajectory', x0: Tensor) -> Tensor:
        """在 π^s 与扰动 W 下前向传播，得到可达管 𝒯(ξ)（区间/粒子近似）"""
        return forward_reachable_tube(
            self.policy, self.shield, plan, x0,
            w_bound=self.disturbance_bound, horizon=len(plan.q))

# IP-450 Training Coverage Certificate (TCC) — 训练覆盖证书
# ============================================================
@dataclass
class TrainingCoverageCertificate:
    """覆盖 + conformal 回报下界 + 近似最优 + 选择偏差校正"""
    train_states: Tensor              # [N_train, d_s]
    train_actions: Tensor             # [N_train, d_a]
    calibrator: 'ConformalCalibrator' # 回报/残差校准器
    value_fn: 'ValueFunction'
    policy: 'StochasticPolicy'
    eps_cov: float = 0.10
    alpha_cov: float = 0.05
    alpha_ret: float = 0.05
    R_min: float = 0.8
    delta_bell: float = 1e-2
    delta_pg: float = 1e-3
    ess_min: float = 0.3              # 重要性加权有效样本比下界

    def verify_coverage(self, tube_states: Tensor) -> bool:
        """∀x∈𝒯: min_j ‖x - x_j^train‖ ≤ ε_cov（或覆盖球计数）"""
        d = torch.cdist(tube_states, self.train_states).min(dim=1).values
        return bool((d <= self.eps_cov).all())

    def verify_conditional_coverage(self, tube_states: Tensor,
                                    weights: Optional[Tensor] = None) -> bool:
        """规划选择偏差校正：在管分布上做加权/Mondrian 条件覆盖检验"""
        if weights is None:
            weights = self._selection_weights(tube_states)
        ess = (weights.sum()**2 / (weights**2).sum()).item()
        if ess < self.ess_min * len(tube_states):
            return False  # 权重退化，条件覆盖不可信
        # Mondrian 分组：按状态范数/任务阶段分组，每组覆盖需 ≥1-α_cov
        for group in self._mondrian_groups(tube_states):
            d = torch.cdist(tube_states[group],
                            self.train_states).min(dim=1).values
            if (d > self.eps_cov).float().mean() > self.alpha_cov:
                return False
        return True

    def verify_return_lcb(self, returns_cal: Tensor) -> bool:
        """conformal 回报下界：P(R ≥ LCB) ≥ 1-α_ret，要求 LCB ≥ R_min"""
        lcb = self.calibrator.lower_quantile(returns_cal, self.alpha_ret)
        return lcb >= self.R_min

    def verify_approx_optimality(self, states: Tensor, next_states: Tensor,
                                 rewards: Tensor) -> bool:
        """Bellman 残差 ≤ δ_Bell 且策略梯度残差 ≤ δ_PG（局部最优见证）"""
        v = self.value_fn(states)
        v_next = self.value_fn(next_states)
        a = self.policy.sample(states, n=8).mean(1)
        q = rewards + 0.99 * v_next
        bell = (v - q.detach()).abs().mean().item()
        pg = self.policy.gradient_norm(states, a).item()
        return bell <= self.delta_bell and pg <= self.delta_pg

    def verify_all(self, tube_states: Tensor, returns_cal: Tensor,
                   states: Tensor, next_states: Tensor, rewards: Tensor,
                   weights: Optional[Tensor] = None) -> bool:
        return (self.verify_coverage(tube_states)
                and self.verify_conditional_coverage(tube_states, weights)
                and self.verify_return_lcb(returns_cal)
                and self.verify_approx_optimality(states, next_states, rewards))

    def _selection_weights(self, tube_states: Tensor) -> Tensor:
        # w(x) ∝ p_deploy(x)/p_cal(x)（密度比估计，规划诱导的分布偏移）
        return density_ratio(self.train_states, tube_states)

    def _mondrian_groups(self, x: Tensor) -> list[Tensor]:
        # 按任务阶段/状态范数分位数分组，保证组条件覆盖
        stage = torch.quantile(x.norm(dim=1), torch.linspace(0, 1, 5)[1:-1])
        return [torch.where((x.norm(dim=1) >= lo) & (x.norm(dim=1) < hi))[0]
                for lo, hi in zip(stage[:-1], stage[1:])] + \
               [torch.where(x.norm(dim=1) >= stage[-1])[0]]

# IP-451 PPUC 规划-策略统一准入门
# ============================================================
@dataclass
class PlanningPolicyUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'  # v25 七证
    pfc: PathFeasibilityCertificate
    psc: PolicySafetyCertificate
    tcc: TrainingCoverageCertificate

    def admits(self, plan: 'MultiRobotPlan', sensor_data: dict,
               returns_cal: Tensor, train_states: Tensor,
               train_actions: Tensor, next_states: Tensor,
               rewards: Tensor) -> bool:
        # 1. v25 七证（语义-重构-协同-结构-力控-轻量-感知-合规-能量）
        if not self.src_usc.admits(plan, sensor_data):
            return False

        # 2-3. 对每台机器人：PFC 规划可行 + 构造执行管
        tubes = []
        for i, traj in enumerate(plan.robot_plans):
            self.pfc.q = traj.q
            self.pfc.qd = traj.qd
            self.pfc.qdd = traj.qdd
            self.pfc.tau = traj.tau
            if not self.pfc.verify_all():
                return False
            tubes.append(self.psc.build_tube(traj, sensor_data['x0'][i]))
        tube = torch.cat(tubes, dim=0)

        # 4. PSC 策略安全（CBF + shield + 管包含 + 计划一致 + 任务保持）
        if not self.psc.verify_all(
                tube, plan.reference_actions, plan.shielded_success_rate):
            return False

        # 5. TCC 训练覆盖（含选择偏差校正 + 回报下界 + 近似最优）
        if not self.tcc.verify_all(
                tube, returns_cal, train_states, next_states, rewards):
            return False

        # 6. 嵌套可信域：𝒯(ξ) ⊆ C_cert ⊆ D_train ⊕ B(ε_cov)
        if not self.psc.verify_tube_containment(tube):
            return False
        if not self.tcc.verify_coverage(tube):
            return False
        return True

            ["conformal_return_lcb", "coverage_radius", "selection_bias_correction", "approx_optimality"])
        self.ipam.register_module("ppuc", ["IP-451"],
            ["nested_trusted_region", "planning_policy_training_gate", "time_dimension_monotone_chain"])

    def step(self, multi_sensor_data: dict, rl_batch: dict) -> tuple[bool, dict]:
        # 1. v25 多机流水线（含 USMC/SMC/RMC/MCC）
        plan = self._plan(multi_sensor_data)          # 规划器产出候选 ξ
        admitted = self.ppuc.admits(
            plan, multi_sensor_data,
            returns_cal=rl_batch['returns_cal'],
            train_states=rl_batch['train_states'],
            train_actions=rl_batch['train_actions'],
            next_states=rl_batch['next_states'],
            rewards=rl_batch['rewards'],
        )
        return admitted, {
            'plan': plan if admitted else None,
            'pfc': {k: getattr(self.ppuc.pfc, f'verify_{k}')()
                    for k in ('kinodynamic', 'clearance', 'temporal_logic', 'energy')},
            'psc': {
                'cbf_ok': self.ppuc.psc.verify_cbf_invariance(self._tube(plan)),
                'shield_ok': self.ppuc.psc.verify_shield_safety(self._tube(plan)),
                'tube_in_cert': self.ppuc.psc.verify_tube_containment(self._tube(plan)),
            },
            'tcc': {
                'coverage_ok': self.ppuc.tcc.verify_coverage(self._tube(plan)),
                'conditional_ok': self.ppuc.tcc.verify_conditional_coverage(self._tube(plan)),
                'return_lcb_ok': self.ppuc.tcc.verify_return_lcb(rl_batch['returns_cal']),
            },
        }

    def _tube(self, plan) -> Tensor:
        return torch.cat([self.ppuc.psc.build_tube(t, x0)
                          for t, x0 in zip(plan.robot_plans, plan.x0)], dim=0)
```

## 2. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| PFC 动力学校验 | O(T·n) | O(T·n) | T≤500, n≤14 |
| PFC 间隙校验 | O(T·(log N_obs + P)) | O(T) | 距离场查询 O(log N_obs) |
| PFC STL 鲁棒度 | O(T·|φ|) | O(T·|φ|) | |φ|≤30 原子 |
| PFC 能量积分 | O(T·n) | O(T) | - |
| PSC CBF 不变性 | O(S·K·m_a) | O(S·K) | S≤2000 采样, K=32 动作 |
| PSC shield 投影 | O(S·K·(m_a+d_s)) | O(S·K) | QP 每点一次 |
| PSC 可达管 | O(H·S·K·d_s) | O(H·S·d_s) | H≤200 |
| TCC 覆盖 | O(S·N_train·d_s) | O(S) | N_train≤1e6, 用 KD-tree→O(S log N) |
| TCC 条件覆盖/权重 | O(S·N_cal + S·G) | O(S) | G≤5 Mondrian 组 |

**实时性说明**：PFC 在规划频率（5–10Hz）内完成；PSC 的可达管用 GPU 并行粒子传播，控制频率下只做增量管更新；TCC 覆盖查询以离线 KD-tree + 在线缓存实现。PPUC 的关键路径由「可达管 × 覆盖查询」主导，建议将覆盖查询下采样到管的关键帧（每 10 帧），保证 20ms 控制环与 100ms 规划环分层满足。

## 3. 正确性论证（增量）

### 引理 13（路径可行性证书的四重保证）
**陈述**：`PFC.verify_all()=True` ⟹ 轨迹 ξ 同时满足 (1) 运动学/动力学界及离散一致性，(2) 膨胀间隙 d(ξ(t),O)−r(t)≥r_safe，(3) STL 鲁棒度 ρ_φ(ξ)≥0，(4) 能量 ∫τᵀq̇dt≤E_budget。

**证明**：四项分别由 `verify_kinodynamic`、`verify_clearance`、`verify_temporal_logic`、`verify_energy` 的逐点谓词直接给出。有限差分一致性条件保证离散轨迹的 qd/qdd 不是「伪造的光滑曲线」，从而动力学校验不会被数值微分误差绕过；STL 的 min/max 语义保证 ρ_φ≥0 ⟺ 公式在连续时间区间上成立（对分段常值离散化，误差由 dt 与信号导数界控制）。能量上界把 PFC 与 v24 的 SOC/EVC 预算对齐，避免规划器用「瞬时大功率换平滑」的方式透支能量证书。∎

### 引理 14（策略安全证书的不变性-屏蔽-包含三重保证）
**陈述**：`PSC.verify_all()=True` ⟹ 在 𝒯(ξ) 上，shield 后策略以概率 ≥1−γ_cbf 保持 C_cert 前向不变，且计划可执行、任务不塌陷。

**证明**：`verify_cbf_invariance` 用策略动作分布的下分位数检验 `L_fV+L_gVa+αV≥0`，即对至少 1−γ_cbf 的动作质量满足离散 CBF 条件；`verify_shield_safety` 进一步以点态投影 `Proj_{A_safe}` 强制每个动作落入安全集，故即使策略采样到尾部动作也被修复。`verify_tube_containment` 把前向可达管 𝒯(ξ)（含扰动界 W）整体限制在 C_cert 内，由 CBF 的零化性（zeroing）保证从 C_cert 内部出发的轨迹永不越界。`verify_plan_agreement` 与 `verify_task_preservation` 分别排除「管安全但策略根本不执行计划」和「shield 过度干预导致任务失败」两种假阳性。∎

### 引理 15（训练覆盖证书的覆盖-回报-最优三重保证）
**陈述**：`TCC.verify_all()=True` ⟹ (1) 管的每个状态在训练集 ε_cov 邻域内且组条件覆盖成立，(2) 以概率 ≥1−α_ret 回报不低于 R_min，(3) Bellman/策略梯度残差 ≤δ_Bell/δ_PG。

**证明**：(1) 由 `verify_coverage` 的最近邻距离判定；`verify_conditional_coverage` 用密度比权重与 Mondrian 分组把**边际覆盖**收紧为**管分布上的条件覆盖**，ESS 下界排除权重退化时的伪保证。(2) conformal 分位数 `lower_quantile(returns_cal, α_ret)` 在可交换性假设下给出有限样本边际下界；当与 (1) 的管覆盖同时成立时，由选择偏差校正把边际下界迁移到规划诱导的管分布。(3) `verify_approx_optimality` 给出局部最优见证——注意它**不**声称全局最优，只排除「策略在该管上明显未收敛」的退化情形。∎

### 引理 16（嵌套可信域与时间维单调链）
**陈述**：若 `PFC ∧ PSC ∧ TCC` 且嵌套包含 `𝒯(ξ) ⊆ C_cert ⊆ D_train⊕B(ε_cov)` 成立，则策略执行满足安全与回报下界，且 `Exec_v26 ⊆ Exec_v25`。

**证明**：PFC 保证计划本身物理可行；PSC 保证策略跟踪该计划时始终停留在 C_cert；TCC 保证 C_cert 被训练覆盖并给出回报下界。三者构成「计划—执行—数据」三重嵌套，任一环节的证书失效都会使交集缩小，因此 `Exec_v26 = Exec_v25 ∩ Fil_plan ∩ Fil_policy ∩ Fil_train ⊆ Exec_v25` 恒成立。该包含关系与 v18–v25 的证书集单调链正交：前者沿「证书维度」收缩，后者沿「状态可达维度」收缩，二者相乘仍单调。∎

### 定理（PPUC 十三条件完备性）
**陈述**：对任意计划 Π 与策略 π_θ，`PPUC.admits(Π,π_θ)=True` ⟺ Π 同时满足 v25 的十类条件（物理接地安全、云边一致、少样本覆盖、专利保护、结构/力控/轻量化、语义、重构、协同）**以及** (11) 路径四重可行，(12) 策略 CBF/shield/管/任务保持，(13) 训练覆盖/回报下界/近似最优。

**证明**：充分性由引理 13–16 与 v25 定理直接连言可得。必要性：逐一移除任一条件，构造对应的反例——不可行轨迹、越界策略、OOD 管状态——均可使 `admits` 返回 False，故十三条件是紧的。诚实边界：条件 (13) 的全局最优性不可证，本定理只声称「在给定训练分布、扰动界与可交换性假设下的局部可认证性」。∎

## 6. 本轮最大风险（最终确认）

**一句话**：**PPUC 的嵌套可信域 `𝒯(ξ)⊆C_cert⊆D_train⊕B(ε_cov)` 依赖「训练-部署可交换」与「可达管对扰动有效」两个假设，而路径规划会主动把系统推向训练分布之外、shield 又会掩盖策略的真实失效——一旦规划在任务驱动下持续选择 OOD 状态，conformal 边际覆盖与 CBF 下分位检验都会给出「看似合规」的证书，导致 PPUC 在策略已系统性进入未认证区后仍错误放行，这是把前几轮的「事前拦截」承诺从静态证书空间推入最危险的时间维分布漂移。**
