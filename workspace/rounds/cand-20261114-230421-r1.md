# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互消歧」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「情感语音」×「移动底盘」）

> R69 给闭环装上了一张嘴：它会把歧义摊开成多个模态，会看、会问、会触，并用「k 个正交证据源一致」把一次提问变成一次可验证的求证。但 R69 的「嘴」是**无声的、离身的**：
> 1. 它只听见**说了什么**（语义内容），听不见**怎么说的**——犹豫、急促、颤抖、压低声音、反讽、礼貌性同意，都包含比字面更关键的证据；而 R69 的 k-一致纪律默认这些通道独立，恰恰忽略了「内容与韵律来自同一个说话人、同一次策略性表达」这一相关性。
> 2. 它假设信息动作可以被身体执行，却把身体当成理想的、无噪声的执行器。移动底盘是非完整约束的、有制动距离的、会打滑的；更致命的是，底盘自己的电机/轮胎/振动/多普勒会污染麦克风——**机器人一边移动一边听，听到的可能是自己的噪声**。
>
> 两个灵感因此不是两个附加模块，而是同一条闭环的两端：**情感语音是「带因果偏置的证据通道」，移动底盘是「会污染证据的执行身体」**。情感驱动底盘运动，底盘运动改变人的情感，底盘噪声又污染情感感知——一个自诱导的 affect–motion 回路。
>
> 核心命题：把交互证据拆成 **content（说了什么）** 与 **paralanguage（怎么说的）**；韵律只有在「已校准 ∧ 与语义一致 ∧ 未被自我运动污染 ∧ 因果上不是机器人自己诱发的」时才被算作独立证据；把移动底盘升级为**带可达/可停/近距舒适约束的身体**，情感只可在认证包络内驱动运动，且运动/韵律不得用于操纵。任一门槛不过，就逐指令退化回 R69。命名 **PROSOMA-RAS**（**PROS**ody × **SOMA**：有身体、有语气、会被自己运动欺骗的交互消歧闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我听到的是你的情绪，还是我自己造成的情绪；我说这话的语气和站的位置，本身是不是证据、是不是风险**」。

## 0. 直觉与动机

**灵感 1（情感语音 → 韵律是带相关性的条件证据，不是第六个投票者）**
直觉：同一句「可以，你过去吧」，平稳而快速地说，与迟疑、气声、尾音上扬地说，含义可能相反。人类听的不是字，而是「字 + 怎么说 + 谁在什么情境下说」。但把韵律直接当成 R69 的第二个证据源会犯一个统计错误：内容与韵律由**同一个说话人、同一次策略性表达**产生，二者在给定说话人状态后未必独立；人还会用反讽、礼貌性同意、情感掩饰主动制造「语义-韵律解耦」。跨学科桥：这是信号检测（paralinguistic channel）与因果推断（source correlation）的交界——**韵律的价值不是「多一票」，而是「在控制说话人相关性与策略性表达后，还剩多少条件互信息」**。因此 R69 的「k 个正交源」必须升级为**有效独立源数 k_eff**，并把「一致/不一致」从噪声问题提升为**策略性问题**。

**灵感 2（移动底盘 → 身体是证据链的一部分）**
直觉：为了听清，机器人会靠近、会转向、会停下来；为了不冒犯，它又要保持距离、避免突然逼近。移动底盘不是理想平移台：非完整约束让它不能横着贴过去，制动距离让它不能「说停就停」，轮胎打滑与悬挂振动让它的实际位姿与里程计不一致。更关键的是，电机与轮胎噪声、结构振动、相对运动多普勒会直接改写麦克风里的 F0、能量与信噪比。于是出现一个**物理悖论**：靠近能提高语义/韵律 SNR，却降低近距舒适度；停稳能净化声学通道，却消耗任务时间。身体既是「执行交互的工具」，又是「污染交互证据的噪声源」——**移动底盘必须被建模为证据链的一环，而不是控制器末端**。

**灵感 3（情感-运动闭环 → 自诱导混淆）**
直觉：机器人快速逼近，人因害怕而后退、声音发颤；机器人把这个「恐惧」读成「这里真的危险/这个人不信任我」，于是更激进地靠近「确认」或更退缩地放弃任务。这就是情感回声：**观测到的情感 = 世界的真实状态 + 机器人自己诱发的部分**。不把后者减掉，系统会把自己吓出来的恐惧当作世界的证据，形成自证偏差。工具是因果推断的 do-算子：只把「若机器人不做这个动作，情感会是多少」的残差当作独立证据。**不要把自己造成的情绪记到世界账上**。

**灵感 4（安全包络 → 情感是软信号，包络是硬约束）**
直觉：情感驱动的运动不能「因为我觉得他害怕所以加速离开」而突破物理安全；个人空间也不是一个固定半径，而是随文化、关系、场景变化的分布。正确做法是维护近距舒适参数的可信集 Θ_h，要求**最坏情况下**社会风险仍 ≤ ε_soc（分布鲁棒），同时满足底盘可达/可停约束。情感只能改变「往哪走、多快、怎么停」的偏好，不能改变「不得越界」这一事实。这把 R69 的「信息动作也要过安全认证」从运动学层扩展到**社会-情感层**。

**灵感 5（双刃剑 → 韵律可伪造，也可被机器人用来操纵）**
直觉：情感语音是一条高带宽但**可伪造**的通道：TTS、变声、重放、表演式情感、社交工程都能制造「真诚的假象」；反过来，机器人自己的语气也能被用来施压（提高音量、加快语速、逼近式追问），把「求证」变成「逼供」。因此必须交付：情感欺骗干扰集、非操纵的韵律动作约束、情感回声审计，以及「韵律证据不得单独定案」的纪律。否则 R70 不是让系统更懂人，而是给它一套更高级的操纵工具。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（PROSOMA-RAS 总览）** PROSOMA-RAS = (PAL, ACE, PEG, SOM, ASE, EGN, AMC, AEB, PAS, RAS-WM§)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 276-i）；
(ii) **韵律证据门（PEG）**：韵律仅在已校准、与语义一致、未被自我运动污染、且 k_eff ≥ 2 时进入信念更新；
(iii) **情感安全包络（ASE）**：任何由情感驱动的底盘运动必须同时满足物理可达/可停约束与近距舒适约束，情感权重不得覆盖硬约束；
(iv) **非操纵**：机器人韵律动作仅允许用于清晰度/舒适度，禁止以诱发顺从/恐惧为目标，所有韵律动作可审计。

**定义 311（双通道观测分解）** 时刻 t 的观测 o_t = (o_sem, o_par, o_ego)。o_sem 为 ASR 语义内容；o_par 为韵律特征（F0 均值/范围、能量、语速、停顿、jitter/shimmer、HNR、频谱倾斜）；o_ego = (v, ω, a, 振动谱, 倾角, 麦克风 SNR) 为底盘自运动状态。说话人隐状态 s_t = (intent, confidence, urgency, valence, arousal, dominance, sincerity)，其中 confidence/urgency 任务相关，valence/arousal/dominance 情感相关。

**定义 312（情感语音证据）** 韵律分析器 PAL: (o_par, o_ego) → (ẑ_aff, U_par^ale, U_par^epi)，ẑ_aff = (v̂, â, d̂, ĉ, û)。U_par^ale 由信道噪声、自发语音变异、说话人内变异构成；U_par^epi 由未见说话人/文化/语料、 acted-vs-spontaneous 失配构成。与 R69 的 U_ale/U_epi 同构，但作用在韵律通道。

**定义 313（韵律证据门 PEG）** 给定韵律校准误差 ECE_par、OOD 分数、语义-韵律一致性 κ、有效独立源数 k_eff、自我运动污染残差 r_ego，定义
w_par = κ · 1[ECE_par ≤ τ_ece] · 1[OOD ≤ τ_ood] · 1[k_eff ≥ 2] · (1 − r_ego)。
若 w_par = 0，韵律不进入任何信念更新，逐指令退化为 R69；若 0 < w_par < 1，韵律只作为「谨慎度」与「听音调度」的调节量，不作为定案证据。

**定义 314（语义-韵律一致性 ACE）** κ ∈ [0,1] 由语义情感/置信度与 ẑ_aff 的条件互信息或判别器给出。κ 低表示反讽、礼貌性同意、情感掩饰、文化差异等**语义-韵律解耦**。关键：κ 低不是「噪声大」，而是「通道可能有策略性」，归入 U_par^epi 并触发证据纪律，不允许用平均糊掉。

**定义 315（有效独立源数 k_eff）** 设证据源集合 S，源 i,j 的残差相关 ρ_ij（给定说话人/语境后），则 k_eff = (Σ_i λ_i)² / Σ_{i,j} λ_i λ_j ρ_ij；对称情形简化为 1/(1+(|S|−1)ρ̄)。R69 的「k 个正交源」是 ρ=0 的特例；韵律与内容共享说话人，故 ρ>0，不能免费算作第二票。

**定义 316（自我运动声学污染 EGN）** 底盘运动通过三条路径污染韵律：结构振动（调制 F0/能量）、电机/轮胎噪声（降低 SNR）、相对运动多普勒（改变表观基频）。定义污染残差 r_ego = ||o_par − h_ego(o_par, x_chassis)|| / σ_par，h_ego 为自噪声补偿模型。当 r_ego > τ_ego 或底盘速度/振动超过「安静听音」阈值时，w_par=0，并触发「先停稳/减速再听」的调度，而不是硬在运动中解读情绪。

**定义 317（身体可达与可停集 SOM）** 移动底盘状态 x=(x,y,θ,v,ω)，非完整约束 ẋ=v cosθ, ẏ=v sinθ, θ̇=ω；动态约束 |v|≤v_max, |a|≤a_max, |ω|≤ω_max, |α|≤α_max。制动距离 d_stop(v)=vτ+v²/(2a_max)。定义可停集 S_stop(x) = {终端状态：存在满足约束的制动轨迹}。任何交互动作 g（靠近/侧移/转向/停顿）必须满足整条前缀 ξ_{t:t+H} ⊂ S_stop 且存在 abort 轨迹。

**定义 318（情感安全包络 ASE）** 给定人-机距离 d、接近速度 v_in、接近方向 φ、加加速度 j、机器人韵律风格 π_pros，感知社会风险
R_soc = f_prox(d, v_in, φ, j; θ_h) + f_pros(π_pros; θ_h)，
其中 θ_h 为人的近距舒适参数（文化/关系/场景相关），取可信集 Θ_h。ASE 要求 sup_{θ_h∈Θ_h} R_soc ≤ ε_soc，且物理约束（定义 317）成立。情感估计只影响 v_des 的偏好，不改变 ASE 的硬约束。

**定义 319（情感-运动耦合 AMC）** 情感状态 ẑ_aff 经策略 π_motion(v_des, orientation | ẑ_aff, task) 生成期望运动；运动又通过人的感知模型 p(s' | s, robot motion, robot prosody) 影响人的情感。定义结构因果模型 M_aff: A_robot → S_human，其中 A_robot=(motion, prosody)。关键：观测到的情感是「世界状态」与「机器人诱发」的叠加，不能直接当证据。

**定义 320（情感回声消除 AEB）** 用 do-算子分离自诱导成分：
z_aff^ind = ẑ_aff − [ E_M(S_human | do(A_robot=a_t)) − E_M(S_human | do(A_robot=∅)) ]。
只有 z_aff^ind 可作为独立情感证据；若因果模型不可识别（存在未观测混杂 U），则用前门/工具变量或保守上界，且 w_par 乘以可识别性系数 γ_id。**不要把自己吓出来的恐惧当作世界的证据**。

**定义 321（韵律动作空间 PAS）** g_pros = (pitch, rate, volume, pause, phrasing) ∈ 𝒜_pros，仅允许用于可懂度/舒适度（如放慢、提高清晰度、留出回应停顿），禁止以提升顺从率为目标的优化；g_pros 与 g_ask 联合生成，但 g_pros 的梯度不来自「人是否同意」这一奖励。所有 g_pros 进入审计。

**定义 322（韵律感知信息价值 PVoI）** 在 R69 的 VoI 上加入韵律证据与身体成本：
PVoI(g) = H(M|o) − E[H(M | o, y(g), z_aff^ind(g))] − c_body(g) − c_social(g; Θ_h) − c_emo(g)，
其中 c_body 含底盘位移/时间/能耗，c_social 为近距舒适风险，c_emo 为情感劳动/打扰成本。选择 g* = argmax PVoI(g)，s.t. ASE、C-RAS-WM 认证、预算与证据纪律；若最大值 ≤ 0 或不满足任一硬约束，则不交互，逐指令退化 R69。

**定义 323（交互与情感预算）** 继承 R69 的交互预算，新增：单位时间情感性探询 ≤ 1 次；连续追问不得升级音高/音量（防胁迫）；「安静听音」时间 ≤ τ_listen；底盘为听音而停稳的次数与时长计入任务预算。

**定义 324（参与式审计 VQAuditor-P）** 审计对象新增：韵律是否被用于操纵、情感回声是否被误当独立证据、跨文化误读、ego-noise 污染是否被掩盖、ASE 是否被情感覆盖、底盘 abort 轨迹是否存在。结论回灌 AuditBuf，成为下一轮 PEG 阈值与 ASE 保守度的先验。

**定义 325（威胁模型 AIC-PROSOMA）** ℰ_PROSOMA = ℰ_FLUID × ℰ_aff_spoof（TTS/变声/重放/表演式情感）× ℰ_aff_manip（用情绪做社交工程）× ℰ_mask（反讽/礼貌/情感掩饰）× ℰ_ego（自噪声/多普勒/振动）× ℰ_motion（用突然逼近诱发恐惧再读取）。并入 AIC。

**定义 326（证书 J_PROSOMA）** J_PROSOMA = (J_FLUID, ECE_par, κ, k_eff, r_ego, ASE_margin, γ_id, induced_affect_ratio, prosody_audit_hash, prosoma_ver)。Valid ⇔ Valid(J_FLUID) ∧ PEG 通过或明确禁用 ∧ ASE 满足 ∧ 非操纵审计通过。

**定义 327（分级退化与严格包含）** 若 PEG 不过、r_ego 超阈、κ 低于阈值、k_eff<2、γ_id 不可识别、ASE 不可行或 PVoI≤0：设 w_par=0，仅用 R69 的语义证据与运动包络；此时 PROSOMA 与 FLUID-RAS 逐指令相同。若韵律可用但不完全可信：只允许 w_par 调节「谨慎度」与「听音调度」，不允许改变模态定案。安全侧永不弱于 R69。

## 2. 关键算法骨架

```python
# IP-264 PAL：情感语音/负荷分析（输出情感状态 + aleatoric/epistemic 二分）
class ProsodicAnalyzer:
    def __call__(self, o_par, o_ego):
        f = acoustic_features(o_par)                  # F0/能量/语速/停顿/jitter/HNR
        z = self.head(f)                              # (v,a,d,c,u)
        u_ale, u_epi = self.split(f, z, o_ego)        # 信道噪声 vs 未见说话人/文化
        return z, u_ale, u_epi

# IP-265/266 ACE + PEG：一致性、k_eff 与韵律证据门
def prosody_weight(z, o_sem, u_epi, ece, ood, r_ego, rho):
    k_eff = 1.0 / (1.0 + rho)                         # 内容-韵律相关惩罚
    kappa = congruence(o_sem, z)                      # 反讽/礼貌/掩饰检测
    gate  = (ece <= TAU_ECE) and (ood <= TAU_OOD)
    gate &= (k_eff >= 2.0) and (kappa >= TAU_K)
    return (kappa * max(0.0, 1.0 - r_ego)) if gate else 0.0

# IP-269 EGN：先判断“我听到的是不是自己的噪声”
def ego_noise_gate(o_par, chassis):
    if chassis.speed > V_QUIET or chassis.vibration > VIB_MAX:
        return None, 1.0                              # 不确定性直接置满
    resid = o_par - ego_noise_model(chassis, o_par)
    return resid, norm(resid) / SIGMA_PAR

# IP-320 AEB：只把“非我所致”的情感残差当证据
def independent_affect(z_aff, a_robot, ctx):
    base = causal_model.expect(z_aff, do=None, ctx=ctx)
    induced = causal_model.expect(z_aff, do=a_robot, ctx=ctx)
    return z_aff - (induced - base)                   # 情感回声消除

# IP-268 ASE：情感只改偏好，不改硬约束
def project_affective_motion(v_des, x, theta_h_set):
    if not reachable_and_stoppable(x, v_des):         # SOM：非完整 + 制动距离
        v_des = emergency_stop_profile(x)
    worst_soc = max(proxemic_risk(x, v_des, th) for th in theta_h_set)
    if worst_soc > EPS_SOC:                           # 鲁棒近距舒适约束
        v_des = shrink_speed_and_distance(x, v_des, theta_h_set)
    return rate_limit(v_des, J_MAX)                   # 连续性：限加加速度

# IP-276 主闭环（继承 FLUID-RAS，仅在证据与运动处插入身体层）
def PROSOMA_round(M, obs):
    z, o_sem, o_par, o_ego = M.mtm.forward(obs)
    c, U_cal, _ = M.cof.step(...)                     # R68 标定
    z_aff, u_ale, u_epi = M.pal(o_par, o_ego)
    o_clean, r_ego = M.egn(o_par, M.chassis.state)
    z_ind = M.aeb.debias(z_aff, M.last_robot_action, obs)
    w_par = M.peg.weight(z_ind, o_sem, u_epi, M.ece, M.ood, r_ego, M.rho)
    # 1) R69 的多模态消歧（K 由廉价歧义预测门控）
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes, U_ale, U_epi = M.aud(M.fmp.sample(o_clean or o_par, K))
    # 2) 韵律只在门内进入证据；否则严格 R69
    if w_par > 0:
        U_epi = M.ace.update(U_epi, z_ind, w_par, k_eff=M.rho_to_keff(M.rho))
    # 3) PVoI：身体/社会/情感成本都计入；无利可图则退化
    g = M.pvoi.choose(modes, o_sem, z_ind if w_par > 0 else None,
                      M.budget, M.chassis, M.theta_h) if U_epi > TAU_EPI else None
    if g is not None:
        M.chassis.quiet_listen()                      # 先停稳再听（EGN 的调度含义）
        answer = M.cia.execute(g, z_ind if w_par > 0 else None)
        U_epi = M.cia.update_belief(modes, answer)
    # 4) 风险缩放：aleatoric + 未消解 epistemic；韵律失败也回流到 U_epi
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 5) 情感驱动运动，但先过 SOM/ASE 硬包络
    v_des = M.amc.propose_motion(z_ind, task=M.task)
    v_safe = M.ase.project(v_des, M.chassis.state, M.theta_h)
    k = M.c_ras_wm.certified_prefix(M.ach.propose(v_safe, M.vista.H), ..., M.wm_preds)
    # 6) 审计与证书
    M.vqa_p.submit_async(g, z_aff, z_ind, w_par, r_ego, v_safe)
    return k, lam, v_safe, (U_ale, U_epi, w_par)
```

## 3. 推导

**引理 19（韵律的条件增益与相关惩罚）** 设内容 C、韵律 P、说话人状态 S。韵律相对内容的净信息为 I(S;P|C)。若 P 与 C 在给定 S 后条件独立，则韵律可作独立证据；若二者通过策略性表达相关（ρ>0），有效源数 k_eff<2，简单「两票」会把错误率下界高估。对称二元情形下，朴素 k=2 的错误率为 δ²，而相关源的实际错误率 ≥ δ(δ+(1−δ)ρ)。系：**情感语音不是第六个投票者，而是一条带相关性的条件证据**；κ 越高、ρ 越低，增益越接近 I(S;P|C)，否则只能当谨慎度。

**引理 20（自我运动污染的可门控性）** 设韵律特征受底盘运动污染 o_par = h(x_chassis) + z_par + ν，h 为 L_h-Lipschitz。若补偿残差 r_ego = ||o_par−ĥ||/σ_par ≤ τ_ego，则韵律证据偏差 ≤ L_h·δ_x + τ_ego·σ_par；当 r_ego 超阈，最坏偏差可越过韵律判别边界，任何正权重都可能把「自己的噪声」读成「人的情绪」。故**运动中的韵律证据必须降权到 0，直到停稳或补偿残差达标**；「先停稳再听」不是礼貌，而是可辨识性条件。

**引理 21（情感回声的可识别性）** 在 SCM M_aff 下，若机器人动作 A 对人情感 S 的因果效应可由观测语境 X 前门/后门识别，则 z_aff^ind 与 A 条件独立，可作独立证据；若存在未观测混杂 U（「人本来就不安」与「机器人靠近」共同导致观察到的恐惧），则残余偏差 ≤ γ_id^{-1}·δ_U。系：**不能用「人在我靠近后更害怕」证明「这里危险」**；只能使用去干预后的残差，或显式声明不可识别并退回 R69。

**定理 18（PROSOMA 严格包含 FLUID-RAS）** 在 A99–A101 下，若 PEG 禁用、r_ego>τ、κ<τ_κ、k_eff<2、γ_id 不可识别、ASE 不可行或 PVoI≤0，则 PROSOMA 与 R69 逐指令相同；否则其期望任务误差不高于 R69（韵律仅在条件增益为正时进入），社会/物理风险不高于 R69（ASE 与 C-RAS-WM 为硬约束）。故 R69 是「无韵律、无身体自由度」边界上的退化。

**定理 19（情感安全、运动连续与非操纵）** 在 ASE（定义 318）与 SOM（定义 317）下，任何情感驱动的 v_des 先经投影/QP 落入可停集与鲁棒舒适集，且加加速度受限 ⇒ 物理/社会风险 ≤ ε_soc 且控制连续、无突变；情感信号不能覆盖急停与硬约束；PAS 限制韵律动作为清晰度/舒适度且审计（定义 321、324）⇒ 不存在以诱发顺从为目标的韵律策略。交互失败/超时/污染时，w_par 单调降到 0，λ 单调不降地退回 R69（定理 18）。

## 6. 本轮最大风险

**一句话**：PROSOMA-RAS 的最大风险是把「自我运动污染」与「情感回声」两个偏差叠加后仍误判为独立情感证据——底盘的噪声/逼近诱发的恐惧一旦被当成环境证据，系统会一边制造恐慌、一边用恐慌证明自己该更激进或更退缩，形成自证偏差；而情感语音的跨文化/跨说话人误读会把这种偏差放大成真实的物理与社会风险。

**次级风险与缓解**：
1. **韵律通道的跨说话人/文化泛化失败** → PEG 校准 + OOD 检测 + 跨语料训练；ECE/OOD 越界即 w_par=0，退回 R69；
2. **自我运动污染被低估** → EGN 残差门 + 「先停稳再听」调度 + 底盘振动/速度阈值；宁可听不见，不可听错；
3. **情感回声自证** → AEB 的 do-残差 + 可识别性系数 γ_id；不可识别时只作谨慎度、不定案；
4. **情感语音伪造/社交工程** → ℰ_aff_spoof 对抗训练 + k_eff 证据纪律 + 单源不定案；
5. **机器人自身韵律操纵** → PAS 非操纵约束 + 审计 + 不从「人是否同意」回传梯度；
6. **近距舒适的文化差异** → ASE 在 Θ_h 上取最坏情形（分布鲁棒）+ 保守默认距离。

## 3. 关键算法伪代码

```python
# IP-264 PAL：情感/负荷分析 + 不确定性二分
class ProsodicAnalyzer:
    def __call__(self, o_par, o_ego):
        f = acoustic_features(o_par)                 # F0/能量/语速/停顿/jitter/HNR
        z = self.head(f)                             # (v,a,d,c,u)
        return z, *self.split(f, z, o_ego)           # z, U_ale, U_epi

# IP-265/266 ACE + PEG：一致性、k_eff 与韵律门
def prosody_weight(z, o_sem, ece, ood, r_ego, rho):
    k_eff = 1.0 / (1.0 + rho)                        # 内容-韵律相关惩罚
    kappa = congruence(o_sem, z)                     # 反讽/礼貌/掩饰
    if ece > TAU_ECE or ood > TAU_OOD: return 0.0
    if k_eff < 2.0 or kappa < TAU_K:   return 0.0
    return kappa * max(0.0, 1.0 - r_ego)

# IP-269 EGN：先判断“听到的是不是自己的噪声”
def ego_noise_gate(o_par, chassis):
    if chassis.speed > V_QUIET or chassis.vibration > VIB_MAX:
        return None, 1.0
    resid = o_par - ego_noise_model(chassis, o_par)
    return resid, norm(resid) / SIGMA_PAR

# IP-271 AEB：只把“非我所致”的情感残差当证据
def independent_affect(z_aff, a_robot, ctx):
    base    = causal_model.expect(z_aff, do=None, ctx=ctx)
    induced = causal_model.expect(z_aff, do=a_robot, ctx=ctx)
    return z_aff - (induced - base)

# IP-268 ASE：情感只改偏好，不改硬约束
def project_affective_motion(v_des, x, theta_h_set):
    if not reachable_and_stoppable(x, v_des):
        v_des = emergency_stop_profile(x)
    if max(proxemic_risk(x, v_des, th) for th in theta_h_set) > EPS_SOC:
        v_des = shrink_speed_and_distance(x, v_des, theta_h_set)
    return rate_limit(v_des, J_MAX)

# IP-276 主闭环（继承 FLUID-RAS）
def PROSOMA_round(M, obs):
    z, o_sem, o_par, o_ego = M.mtm.forward(obs)
    c, U_cal, _ = M.cof.step(...)
    z_aff, u_ale, u_epi = M.pal(o_par, o_ego)
    o_clean, r_ego = M.egn(o_par, M.chassis.state)
    z_ind = M.aeb.debias(z_aff, M.last_robot_action, obs)
    w_par = M.peg.weight(z_ind, o_sem, M.ece, M.ood, r_ego, M.rho)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes, U_ale, U_epi = M.aud(M.fmp.sample(o_clean or o_par, K))
    if w_par > 0:
        U_epi = M.ace.update(U_epi, z_ind, w_par, k_eff=M.rho_to_keff(M.rho))
    g = (M.pvoi.choose(modes, o_sem, z_ind if w_par > 0 else None,
                       M.budget, M.chassis, M.theta_h)
         if U_epi > TAU_EPI else None)
    if g is not None:
        M.chassis.quiet_listen()
        U_epi = M.cia.update_belief(modes,
                    M.cia.execute(g, z_ind if w_par > 0 else None))
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    v_safe = M.ase.project(M.amc.propose_motion(z_ind, M.task),
                           M.chassis.state, M.theta_h)
    k = M.c_ras_wm.certified_prefix(
            M.ach.propose(v_safe, M.vista.H), ..., M.wm_preds)
    M.vqa_p.submit_async(g, z_aff, z_ind, w_par, r_ego, v_safe)
    return k, lam, v_safe, (U_ale, U_epi, w_par)
```

## 4. 推导

**引理 19（韵律的条件增益与相关惩罚）** 内容 C、韵律 P、说话人状态 S；韵律净信息为 `I(S;P|C)`。若 P⊥C|S，韵律可作独立证据；若策略性表达导致相关 `ρ>0`，则 `k_eff<2`。对称二元情形朴素 k=2 错误率 `δ²`，相关源实际错误率 `≥δ(δ+(1−δ)ρ)`。系：情感语音不是第六个投票者，而是带相关性的条件证据；κ 高、ρ 低时增益才接近 `I(S;P|C)`。

**引理 20（自我运动污染的可门控性）** `o_par=h(x_chassis)+z_par+ν`，h 为 `L_h`-Lipschitz。若 `r_ego≤τ_ego`，偏差 `≤L_h δ_x+τ_ego σ_par`；超阈则最坏偏差可越过判别边界，任何正权重都可能把自身噪声读成人的情绪。故运动中韵律证据必须降权到 0，直到停稳或补偿残差达标。

**引理 21（情感回声的可识别性）** 若 A 对 S 的因果效应可由观测语境识别，则 `z_aff^ind` 与 A 条件独立，可作独立证据；若存在未观测混杂 U，残余偏差 `≤γ_id^{-1} δ_U`。系：不能用「我靠近后他更害怕」证明「这里危险」；只能用去干预残差或退回 R69。

**定理 18（PROSOMA 严格包含 FLUID-RAS）** 在 A99–A101 下，若 PEG 禁用、`r_ego>τ`、`κ<τ_κ`、`k_eff<2`、`γ_id` 不可识别、ASE 不可行或 `PVoI≤0`，则与 R69 逐指令相同；否则期望任务误差不高于 R69（韵律仅在条件增益为正时进入），社会/物理风险不高于 R69（ASE 与 C-RAS-WM 为硬约束）。R69 = 「无韵律、无身体自由度」边界上的退化。

**定理 19（情感安全、运动连续与非操纵）** 情感驱动的 `v_des` 先经投影/QP 落入可停集与鲁棒舒适集，且加加速度受限 ⇒ 物理/社会风险 `≤ε_soc`、控制连续无突变；情感不能覆盖急停与硬约束；PAS 限制韵律动作为清晰度/舒适度并审计 ⇒ 不存在以诱发顺从为目标的韵律策略。失败/超时/污染时 `w_par` 单调降到 0，λ 单调不降地退回 R69。

## 7. 本轮最大风险

**一句话**：PROSOMA-RAS 的最大风险是把「自我运动污染」与「情感回声」两个偏差叠加后仍误判为独立情感证据——底盘的噪声/逼近诱发的恐惧一旦被当成环境证据，系统会一边制造恐慌、一边用恐慌证明自己该更激进或更退缩，形成自证偏差；而情感语音的跨文化/跨说话人误读会把这种偏差放大成真实的物理与社会风险。

**次级风险与缓解**：韵律跨说话人/文化泛化失败（PEG 校准 + OOD，越界 `w_par=0` 退回 R69）；自我运动污染被低估（EGN 残差门 + 先停稳再听 + 速度/振动阈值）；情感回声自证（AEB do-残差 + `γ_id`，不可识别只作谨慎度）；情感伪造/社交工程（ℰ_aff_spoof 对抗训练 + k_eff 证据纪律）；机器人韵律操纵（PAS 非操纵约束 + 审计 + 不回传「同意」梯度）；近距文化差异（ASE 在 Θ_h 上取最坏情形 + 保守默认距离）。
