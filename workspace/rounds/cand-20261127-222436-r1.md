### 第 4 轮灵感驱动研究记录

**灵感词**：边缘计算、研究空白

**继承关系**：第 3 轮 CADVS-v3（IP-485~488）在 v2 三锚点（3DCF/Γ_3D、MSRG/S2RC、HICK/HIC）之上追加末点锚 EEK（EEC/kc_ee）与记忆锚 LTEM（kc_mem），并引入联邦聚合器 FFA（本地充分统计量 + DP + 安全聚合 + FedAvg）维护全局先验 Φ_global，形成五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem。v3 自陈的最大风险 R43/R44 是「联邦聚合成为跨站伪神谕」：non-IID 使 FedAvg 收敛到对无一处成立的平均证书，单站毒化又可把错误先验扩散到舰队。本轮不推翻 v3，而是**替换其聚合语义、并补上一个被所有前序轮次忽略的锚点**，形成 CADVS-v4（IP-489~492），执行集升级为 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **边缘计算：真正该下沉的不是算力，而是「证据主权」**。v3 的 FFA 把各站充分统计量做 FedAvg 得到唯一 Φ_global 再下发，这一步恰好是 R43/R44 的病根——它默认「存在一个可平均的全局真值」。边缘计算的核心教训不是「在本地算」，而是「在本地签发、在本地持有、全局不得覆盖本地」。因此 v4 让每个边缘站点独立签发边缘证书 Cert_i（含正证据、gap 账本、已收缩执行域），全局服务器无权放大任何站点的执行域；联邦只聚合**负空间**（不知道的部分），不聚合**正空间**（知道的部分）。正证据主权归边缘，负证据共识归舰队。

2. **研究空白：把「无知」升级为一等公民证书**。v1~v3 只证书化正证据（被覆盖、物理成立、人背书、末点真实、历史可靠）。fail-closed 只处理「单次查询的未知」，却没有对**系统性无知**记账：机器人可以永远待在一个被覆盖的小气泡里，却从不知道自己的运行域还有多大没被检验。文献侧的空白也在此——runtime assurance / shielding 假定安全集已知或可学，safe-RL/reachability 算出安全集却不审计估计的盲区，联邦安全默认 IID 并做平均；没有人把「负证据/未知」作为可审计、可披露、可驱动主动探索的一等对象。v4 引入 Gap Ledger（空白账本）与 gap 测度 μ_gap，并设硬门 kc_gap：规则准入时不是问「有没有证据」，而是同时问「你声称的执行域里，未被证据覆盖的比例是否被界定并在 g_tol 内；否则必须收缩执行域并披露剩余空白」。这把「研究空白」从一句论文措辞变成一个可计算、可拒绝的对象。

3. **关键洞见：用格论式安全聚合替代均值聚合，让联邦「只会缩小、永不放大」**。v3 的 FedAvg 是线性平均，天然可能放大（把局部未证伪的东西平均成「都成立」）。v4 的联邦空白聚合器 FGA 改用**覆盖取交、空白取并**：全局闭域 D_global = ∩_i D_i（更严格：需 ≥ k 站独立佐证才闭），全局空白 G_global = ∪_i G_i。二者都是单调保守算子：新增站点或新增轮次只能让执行域**缩小或持平**，绝不可能把未证区域变成已证。于是毒化只能「多加空白」（fail-safe 的 DoS），无法「关闭空白」（除非 ≥ k 站合谋）；non-IID 也不再坍塌，因为根本没有平均，全局可执行集是各站可执行集的交，对每个参与站都 sound。v3 的最大风险在此被结构性消解，而非被工程缓解。

**形式化目标（增量）**：
1. 定义空白原子 g = (kind, descriptor, severity ∈ [0,1], t_created, ttl)，kind ∈ {uncovered, physics_unproven, ee_unproven, cold_start, human_unendorsed}；空白账本 G_i = {g}；gap 测度 μ_gap(D) = Σ_{g 覆盖 D} severity(g) · w(g) / Σ_{g 覆盖 D} w(g)（w 为运行分布权重，估计自在线访问频次）。
2. 定义 gap 硬门 kc_gap(rule, D_claim)：若 μ_gap(D_claim) ≤ g_tol 则放行并披露 D_exec = D_claim；否则收缩到无空白子域 D_exec ⊂ D_claim，若 μ_gap(D_exec) ≤ g_tol 且 meas(D_exec) ≥ d_min 则以受限域放行并披露剩余空白；否则拒绝。
3. 定义边缘证书 Cert_i = (site_id, anchors_{coverage,physics,human,ee,mem}, G_i, D_i, issued_at, version)，并规定边缘主权不变式：任何全局摘要都不得使某站可执行域大于其本地 Cert_i.D_i。
4. 定义联邦空白聚合器 FGA：以安全集合并 + DP 基数发布聚合空白/覆盖；对每个原子 a 记 c(a) = 覆盖 a 的站点数，全局闭域 = {a : c(a) ≥ k}，全局空白 = {a : c(a) < k}；D_global = ∩_i D_i 且受 k-佐证约束；不做任何先验平均。
5. 定义 EFA-v4 六硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_gap，fail-closed；软评分 ECS_v4 = ECS_v3 · (1 − μ_gap)，仅用于分级与探索排序，不参与安全决策。
6. 定义 Exec_CADVS-v4 ⊆ Exec_CADVS-v3：在 v3 每条路径上再要求 (a) 查询域 ⊆ 本地 Cert_i.D_i 且 (b) kc_gap 通过（必要时域收缩），故只缩不涨。

**本轮最大风险**：**空白账本退化为「完整性的伪证书」**——它只能枚举我们想到要去查的已知未知（known-unknowns），却极易被系统与读者误读为对未知未知（unknown-unknowns）的封口；一旦「账本内无 gap」被当成「全域已证」，v4 会比 v3 的联邦伪神谕更隐蔽地制造虚假安全感。

## 2. 关键算法骨架

### IP-490 GAEB：空白账本与 gap 硬门（准入时 O(|G|) 最坏，可索引到 O(log)）

```python
@dataclass
class GapAtom:
    kind: str            # 'uncovered' | 'physics_unproven' | 'ee_unproven' | 'cold_start' | 'human_unendorsed'
    descriptor: str      # 体素键 / 上下文指纹 / rule_id / 域标签
    severity: float      # [0,1]
    t_created: float
    ttl: float

@dataclass
class GapLedger:
    """GAEB：显式负证据账本；kc_gap 使执行域按空白收缩并披露"""
    g_tol: float = 0.05
    d_min: float = 0.10
    w: dict = field(default_factory=dict)   # descriptor -> 运行分布权重

    def __post_init__(self):
        self.atoms: dict[str, GapAtom] = {}

    def add(self, atom: GapAtom):
        self.atoms[self._key(atom)] = atom

    def close(self, kind: str, descriptor: str):
        """仅在对应正证据真正补齐后由签发流程调用（不可由联邦远程调用）"""
        self.atoms.pop(f"{kind}|{descriptor}", None)

    def _key(self, a: GapAtom) -> str:
        return f"{a.kind}|{a.descriptor}"

    def gap_measure(self, domain: set[str], t_now: float) -> float:
        """域内未过期空白原子的加权 severity 占比；无原子则 0"""
        num = den = 0.0
        for a in self.atoms.values():
            if a.descriptor not in domain or t_now > a.t_created + a.ttl:
                continue
            wt = self.w.get(a.descriptor, 1.0)
            num += wt * a.severity
            den += wt
        return num / den if den > 0 else 0.0

    def kc_gap(self, rule_id: str, D_claim: set[str], t_now: float
               ) -> tuple[bool, float, set[str]]:
        """返回 (pass, mu_gap, disclosed_D_exec)。先试全域，再收缩到无空白子域。"""
        mu = self.gap_measure(D_claim, t_now)
        if mu <= self.g_tol:
            return True, mu, D_claim
        D_exec = self._covered_subdomain(D_claim, t_now)   # D_claim 去掉空白原子覆盖部分
        if len(D_exec) / max(len(D_claim), 1) >= self.d_min:
            mu_exec = self.gap_measure(D_exec, t_now)
            if mu_exec <= self.g_tol:
                return True, mu_exec, D_exec                # 受限域放行，披露剩余空白
        return False, mu, set()                            # GAP_UNBOUNDED
```

### IP-489 ECA：边缘证书与主权不变式

```python
@dataclass
class EdgeCertificate:
    site_id: int
    anchors: dict          # {'coverage':..., 'physics':..., 'human':..., 'ee':..., 'mem':...}
    gap_ledger: GapLedger
    exec_domain: set[str]
    issued_at: float
    version: int

@dataclass
class EdgeCertificateAuthority:
    """ECA：证书只在边缘签发；全局只能收紧，不能放宽"""
    site_id: int

    def issue(self, anchors: dict, ledger: GapLedger,
              D_claim: set[str], t_now: float) -> EdgeCertificate:
        ok, mu, D_exec = ledger.kc_gap(rule_id=anchors['rule_id'],
                                       D_claim=D_claim, t_now=t_now)
        if not ok:
            raise InadmissibleRule('GAP_UNBOUNDED')
        return EdgeCertificate(self.site_id, anchors, ledger, D_exec, t_now, version=+1)

    @staticmethod
    def admit(cert: EdgeCertificate, query_domain: set[str],
              global_hint: set[str] | None = None) -> set[str]:
        """边缘主权：全局提示只能取交，绝不放大"""
        allowed = cert.exec_domain
        if global_hint is not None:
            allowed = allowed & global_hint
        if not query_domain <= allowed:
            raise ScopeViolation('SCOPE_NOT_ATTESTED')
        return allowed
```

### IP-491 FGA：联邦空白聚合（覆盖取交、空白取并、k-佐证，不做平均）

```python
@dataclass
class FederatedGapAggregator:
    """FGA：只聚合负空间与基数，不平均先验；毒化只能加空白（fail-safe）"""
    epsilon: float = 1.0
    delta: float = 1e-5
    k: int = 2                     # k-佐证：闭域至少需 k 站独立覆盖
    clip_norm: float = 1.0

    def local_gap_set(self, cert: EdgeCertificate) -> set[str]:
        return set(cert.gap_ledger.atoms.keys())

    def local_cover_set(self, cert: EdgeCertificate) -> set[str]:
        # 覆盖 = 声称域 \ 空白域；provenance 由 cert.site_id 提供
        return set(cert.exec_domain) - self.local_gap_set(cert)

    def secure_union(self, sets: list[set[str]]) -> set[str]:
        """秘密共享/PSI-union：服务器只得到并集，不见单站集合"""
        ...

    def dp_count(self, atom: str, cover_sets: list[set[str]]) -> int:
        """发布 c(a) 的 DP 基数；拉普拉斯/高斯机制，灵敏度 1"""
        true = sum(1 for s in cover_sets if atom in s)
        noise = np.random.laplace(0.0, 1.0 / self.epsilon)
        return max(0, int(round(true + noise)))

    def aggregate(self, certs: list[EdgeCertificate]) -> tuple[set[str], set[str]]:
        """返回 (D_global, G_global)"""
        universe = self.secure_union([c.exec_domain | self.local_gap_set(c) for c in certs])
        cover_sets = [self.local_cover_set(c) for c in certs]
        D_global, G_global = set(), set()
        for a in universe:
            if self.dp_count(a, cover_sets) >= self.k:
                D_global.add(a)
            else:
                G_global.add(a)
        # 覆盖取交：仅保留所有站执行域之内的原子
        D_global &= set.intersection(*[c.exec_domain for c in certs]) if certs else set()
        G_global |= universe - D_global
        return D_global, G_global
```

### IP-492 EFA-v4：六硬门（v3 五门 + 空白门）

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：六硬门 fail-closed；软评分仅分级/探索排序"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    mu_S: float = 0.75

    def hard_gate(self, x, t_now, rule_id, hic, eec, ctx,
                  cert: EdgeCertificate, query_domain: set[str]
                  ) -> tuple[bool, str]:
        if self.hic.veto_active(hic):           return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):   return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):              return False, 'EE_UNPROVEN'
        pass_mem, eta_mem, novelty = self.ltem.query(*ctx)
        if not pass_mem:                         return False, 'MEMORY_REJECT'

        # ---- v4 新增：边缘主权 + 空白门 ----
        try:
            allowed = EdgeCertificateAuthority.admit(cert, query_domain)
        except ScopeViolation:
            return False, 'SCOPE_NOT_ATTESTED'
        ok_gap, mu_gap, D_exec = cert.gap_ledger.kc_gap(rule_id, allowed, t_now)
        if not ok_gap:                           return False, 'GAP_UNBOUNDED'
        scoped = '|SCOPED' if D_exec != allowed else ''
        return True, 'FORGED' + ('|NOVELTY' if novelty else '') + scoped

    def ecs_v4(self, x, t_now, rule_id, mu_gap: float,
               A_att=0.0, eta_mem=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now) ** 0.4
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0) ** 0.4
                * (1 + 0.2 * A_att))
        return base * eta_mem * (1.0 - mu_gap)
```

### 集成流水线（v3 → v4）

```
边缘站点 i（签发，本地主权）：
  正证据：3DCF/Γ_3D + MSRG/S2RC + HICK/HIC + EEK/EEC + LTEM/M
        ──▶ ECA.issue ──▶ Cert_i = (anchors, G_i, D_i)
  负证据：未覆盖体素 / 未证规则域 / 冷启动 / 末点未证 / 未背书
        ──▶ GAEB.add(GapAtom) ──▶ G_i，并触发 kc_gap 收缩 D_i

联邦（慢时域，只聚合负空间，不平均正先验）：
  各站 Cert_i ──▶ FGA.local_cover_set / local_gap_set
        ──▶ 安全集合并 + DP 基数 ──▶ c(a)
        ──▶ D_global = {a: c(a) ≥ k} ∩ (∩_i D_i)
        ──▶ G_global = {a: c(a) < k} ∪ (∪_i G_i)
        ──▶ 下发「全局空白 G_global」仅用于探索排序与告警；不下发可执行先验

在线规则准入（异步，< 2 s/规则）：
  DAKI κ_i^new ──▶ MSRG.sprt_gate ──▶ S2RC
        ──▶ EFA-v4.hard_gate（含 cert.admit 与 kc_gap）──▶ KC 库 v+1
        ──▶ 若 GAP_UNBOUNDED：规则进入「受限域 + 探索队列」

在线控制环（< 0.1 ms 增量）：
  每周期：EEK → EEC → kc_ee；域包含检查 query_domain ⊆ Cert_i.D_i（O(1) 哈希）
  证书消费前：EFA-v4.hard_gate
      ├─ HIC_STOP          → S_stop
      ├─ COVERAGE_BLIND    → 回退 STCK 球域 + 教师 + 写 uncovered 原子
      ├─ PHYSICS_UNPROVEN  → 规则降权 + 写 physics_unproven 原子
      ├─ EE_UNPROVEN       → 末端复位/重触 + 写 ee_unproven 原子
      ├─ MEMORY_REJECT     → 教师介入或重新 MSRG
      ├─ SCOPE_NOT_ATTESTED→ 拒绝（全局不得放大本地域）
      └─ GAP_UNBOUNDED     → 收缩域或进入探索队列（fail-closed）
```

## 4. 正确性论证（增量更新）

### 1.x 文献空白定位（研究空白的显式化）

- **Runtime assurance / simplex / shielding**：假定安全集已知或由离线模型给出，不审计「安全集估计的盲区」。
- **Safe RL / reachability analysis**：能算出（近似）安全集，但以模型正确为前提，且不把「未覆盖/未验证」作为可签发、可拒绝的证书对象。
- **联邦学习用于安全**：默认 IID 或对异构做加权平均，正证据被平均后可能对无一处成立（v3 R43）。
- **本文空白**：无人把**负证据（无知）**作为一等证书，也无人用**格论式单调聚合（覆盖取交、空白取并）**替代均值聚合来保证联邦「只会缩小、永不放大」。v4 同时填补这两个空白。

### 引理 41（空白测度的样本一致性）

**陈述**：设 μ_gap(D) 用在线访问频次估计权重 w，样本量 n，且运行分布平稳。则以概率 ≥ 1−2exp(−2nε²)，对所有域 D 的一致偏差 ≤ ε（Dvoretzky–Kiefer–Wolfowitz / Hoeffding）。故 kc_gap 以 μ̂_gap ≤ g_tol 通过时，真实 μ_gap ≤ g_tol + ε。

**证明**：权重经验分布对真实分布的一致收敛由 DKW 不等式给出；μ_gap 是权重的加权比值，偏差被同一 ε 界定。∎

**诚实声明**：平稳性是本引理的关键假设；分布漂移会使历史权重失效（见 R47）。

### 引理 42（k-佐证聚合的单调保守性与毒化界）

**陈述**：设全局闭域 D_global = {a : c(a) ≥ k} ∩ (∩_i D_i)，全局空白 G_global = {a : c(a) < k} ∪ (∪_i G_i)。则：
(a) **单调性**：新增站点/轮次只可能使 c(a) 增大，D_global 只增不减，但其增长受 ∩_i D_i 约束，永不超出任一参与站点的本地执行域；
(b) **保守性**：对任意真实未覆盖原子 a（所有诚实站均未覆盖），若被腐化站点数 < k，则 c(a) < k，a 恒在 G_global，不会被闭合；
(c) **毒化界**：要错误闭合一个真实未覆盖原子，至少需 k 个站点合谋（Sybil/被攻陷），单站或 <k 站毒化只能增加空白（DoS），不能放大执行域。

**证明**：(a) c(a) 为计数，单调；D_global ⊆ ∩_i D_i ⊆ 任一 D_i。(b) c(a) = 腐化站点中覆盖 a 者 ≤ 腐化数 < k。(c) 由 (b) 逆否，闭合需 c(a) ≥ k，即 ≥k 站声称覆盖。∎

**工程含义**：这正是对 v3 最大风险 R43/R44 的结构性消解——用「取交/取并」取代「平均」，把毒化的最坏后果从「扩散错误证书」降级为「过度保守」。代价是 k 越大越保守、可用域越小。

### 引理 43（FGA 的隐私与集合泄漏边界）

**陈述**：FGA 以安全集合并计算 universe、以灵敏度 1 的拉普拉斯机制发布 c(a)，满足 ε-差分隐私（或高斯机制的 (ε,δ)-DP）；服务器不见单站集合，只见到并集与带噪基数。

**证明**：拉普拉斯机制对计数查询灵敏度 1 的标准 DP 结论；安全并集通过秘密共享使单站输入不可见。∎

**诚实声明**：集合**并集本身**仍可能泄漏「某原子至少被一站覆盖」，故隐私保护强于「是否被特定站点覆盖」，弱于「完全不泄漏存在性」。高敏场景需只发布聚合统计而非逐原子 c(a)。

### 定理 v4（执行集再收缩、负证据锚补全、联邦风险消解）

**陈述**：在假设 (C1) 引理 41 的平稳性与样本一致性成立；(C2) 空白账本忠实记录所有已识别的负证据；(C3) 腐化站点数 < k；(C4) 继承 v3 的 (B1)~(B4) 时：
(i) Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29（严格收缩，严格性由 kc_gap 在 v3 未检查的空白域上关闭路径保证）；
(ii) 全局聚合单调保守：D_global ⊆ ∩_i D_i，且毒化 <k 站无法闭合任何真实空白（引理 42）；
(iii) non-IID 下不存在「对无一处成立的平均证书」：因无平均，全局可执行集是各站可执行集之交，对每个参与站 sound；
(iv) FGA 满足 DP 且单站原始数据/集合不外泄（引理 43）；
(v) 六硬门 fail-closed，任一不通过即拒，仅 HIC veto 旁路至 S_stop。

**证明**：(i) v4 在 v3 每条路径追加 Cert_i 域包含检查与 kc_gap，故只缩不涨。(ii) 引理 42。(iii) D_global ⊆ 每个 D_i，故任取站 i，D_global 内动作在 i 的本地证书下均已被证；无平均即无「平均后对谁都不成立」的伪证书。(iv) 引理 43。(v) 由 EFA-v4 hard_gate 合取结构。∎

**诚实声明**：(C2) 是本轮最脆弱假设，且它只能保证「已识别的负证据被忠实记账」，无法保证「负证据被穷尽」——这正是本轮最大风险（见 §7）。

## 5. 实验设计与初步结果（计划中，第 5 轮实机）

### 5.1 实验设计

- **平台**：N=4~6 个边缘站点（Jetson Orin + Panda），MuJoCo/MJX 仿真预演；站点间可注入网络分区与延迟。
- **对照**：v3-full（FFA/FedAvg）、v4-full（ECA+FGA）、消融 C1（去 kc_gap，退化为 v3 域）、C2（去边缘主权，允许全局写回）、C3（k=1 vs k=2 vs k=3）。
- **协议**：
  (a) **非 IID 坍塌**：站点 A 只见光滑物体、B 只见多孔物体，测全局证书对两者的 soundness；
  (b) **单站毒化**：1 站上传虚假覆盖，测能否闭合真实空白（预期 0%）；
  (c) **k 站合谋**：k−1 与 k 站合谋，测闭域被错误放大的临界点；
  (d) **边缘分区**：站点离线时仅用本地 Cert_i，测安全性与可用域退化；
  (e) **空白召回**：注入已知未知区域，测 Gap Ledger 是否捕获（known-unknown recall）；
  (f) **未知未知探针**：注入账本未枚举的新失效模式，测系统是否产生虚假安全感（关键负结果）。
- **指标**：错误闭合率（gap 已闭但实际未覆盖）、毒化闭合阈值、可执行域占比、任务成功率、探索命中率、DP 效用（ε vs 域估计误差）、known-unknown recall。

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R45 | v1/v2/v3 全部既有风险 | — | 原样继承；R43/R44 由 FGA 结构性消解 | 见前序表 |
| R46 | **认识论傲慢（伪完整性）**：Gap Ledger 只枚举 known-unknowns，被误读为对 unknown-unknowns 的封口 | **极高** | 账本只声明为「无知下界」而非「完整性证明」；强制探索预算与红队注入；对外文档明示不可证完整性 | 未知未知永远无法被账本穷尽 |

## 7. 本轮最大风险（最终确认）

**一句话**：**空白账本退化为「完整性的伪证书」**——它只能枚举我们想到要去查的已知未知，却极易被系统与读者误读为对未知未知的封口；一旦「账本内无 gap」被当成「全域已证」，v4 会比 v3 的联邦伪神谕更隐蔽地制造虚假安全感。
