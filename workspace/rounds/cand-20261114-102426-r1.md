# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 3 轮；本轮灵感：「位姿估计」×「语义地图」）

> R72 把 GAUGE 从「认知层算法」下沉为「具身实时系统」（REG×IRL×DMEM×EREFLEX），确立了调度级时序隔离、意图/接触不确定度入风险分母、三层反作用合算预算与严格退化链。但 R72 仍压着两块**未审计的地基**：
> - **位姿估计视角**：R72 的所有状态、证据、风险界都写在某个坐标系里，却从未审计「这个坐标系本身是否有效」。位姿估计天然带**规范自由（gauge freedom）**、**累积漂移**、**对称/重复场景混叠**、**协方差失准**、**外参与时同步误差**。若位姿错了，R71/R72 的计量证书会**真空成立**——它证明了一条「在错误坐标里自洽」的测量链。R71 的 GAP 只是语义/测量规范间隙，**空间规范**从未被显式审计。
> - **语义地图视角**：R72 把先验塞进意图 p(z) 与接触 c_prior，却没有审计「地图这个先验从哪来、是否过期、是否与当前观测独立」。语义地图是**跨会话、跨机器人共享的公共账本**：会因物体移动而过期，会被机器人自己写入后再读回（**data incest / 循环证据**），会被对抗投毒，会因本体（ontology）版本不同而标签错配。把地图当「又一个独立观测」送进 BSE，会**双重计数、过度自信、风险缩放失效**。
>
> 本轮两个灵感正好补两块地基：
> - **位姿估计**：把「空间规范」升级为一等审计对象——SE(3) 多假设后验、坐标系图一致性、位姿不确定度五分量分解（协方差/漂移/外参/时同步/混叠）、对称混叠集上的风险缩放。
> - **语义地图**：把「语义先验」升级为带**溯源、时效、本体版本、独立性**的账本——每条地图证据携带来源谱系，循环证据被去相关，过期/投毒/本体错配触发降级；**写地图本身成为一个受门控的安全动作**。
>
> 核心命题：**不再只问「我的测量链可信吗」，而问「我的测量链所依附的坐标系是否规范有效、所用语义先验是否新鲜且与观测独立、证据谱系是否无环？」** 把 R72 的具身闭环再下沉一层为 **GROUNDED-GAUGE-RAS**（Grounded Reference-frame & Ontology-audited, Uncertainty-propagated, Non-circular Dataflow GAUGE for RAS）——**空间-语义接地计量闭环**。

## 0. 直觉与动机

**灵感 1（位姿估计 → 计量是「相对于某个坐标系」的，坐标系本身是估计量）**
直觉：工程师说「杯子在 (0.42, 0.11, 0.03)」，这句话隐含「相对于 map 系」。但 map 系与 odom 系之间的变换是估计出来的，odom 又是由轮速/IMU 积分出来的，会漂移；相机外参是标定的，有误差；图像时间戳与 IMU 有同步偏差；对称杯子旋转 180° 后观测几乎不变。**这些都不是「噪声」，而是「参考系本身的无效性」**。R72 的 SPINE 若只审测量协方差，而不审「这个协方差是在哪个系、这个系还对不对」，就会得到一条**在漂移坐标系里越来越精确地错误**的轨迹。**空间规范有效性（spatial gauge validity）是计量有效性的前提，而不是它的一个子项。**

**灵感 2（语义地图 → 地图不是观测，地图是「带账本和时效的公共先验」）**
直觉：机器人看到桌上有个杯子，把它写进语义地图；下一轮它读到地图「这里有杯子」，于是更确信。**这看起来像融合，其实是回声。** 地图元素有生命周期：物体被拿走、标签被换、别的机器人写错、本体从 `cup` 变成 `mug`。把地图当独立证据，等价于**把自己的旧猜测复制一遍当新证据**，后验精度被虚假放大。正确做法是：地图是**先验**（可被观测修正），不是**证据**（除非能证明其来源与当前观测独立）；每次读图必须携带**来源谱系**并做**独立性折扣**。

**灵感 3（规范 → 只审计规范不变量，或把规范显式携带）**
直觉：绝对位姿在换世界系后会变，但「两物体相对位姿」「闭环残差」「点云配准残差」在换系后不变。**规范不变量（gauge-invariant quantities）才是可跨会话、跨机器人比较、可审计的量**。审计器应只对不变量下结论；若必须用绝对量，则必须显式携带 `(gauge_fixing, Σ_gauge)`，并在跨系迁移时传播规范不确定度。R71 的 GAP 是「语义规范间隙」，R73 补上「空间规范间隙 ι_spatial」与「本体规范间隙 ι_ont」。

**灵感 4（混叠 → 位姿后验天然多峰，风险必须在模态上算）**
直觉：对称物体、走廊、重复货架会让位姿后验出现多个几乎等概率的峰。用一个高斯去拟合多峰后验，会得到一个「在几个峰之间、哪都不对」的均值与一个虚假的小方差。**风险不能只在均值点算，必须在混叠集（aliasing set）上按模态加权/取最坏模态**。位姿混叠熵 H_pose 与意图熵 H_z、接触熵 H_c 一样，是风险缩放的直接分母。

**灵感 5（接地反作用 → 机器人写地图会改变自己未来的证据）**
直觉：R72 有三层反作用（情感 ψ、意图 z、接触 c）。语义地图带来**第四层、也是更隐蔽的一层**：机器人把估计写进地图，未来又读回来当作先验/证据，**机器人的认知行为改变了它自己未来的认知输入**。这不是「人反作用于机器人」，而是**「机器人的记忆反作用于机器人的感知」**。若不追踪写-读谱系，系统会进入**自证循环（self-confirmation loop）**：越写越信、越信越写，且所有审计指标都在有效域内。**接地反作用必须与三层反作用合算预算，且地图写入必须门控。**

## 1. 形式化定义（增量：定义 366–382）

**定义 366（GROUNDED-GAUGE-RAS 总览与六不变式）** GROUNDED-GAUGE-RAS = (SPINE, PAS, SEMAP, CEG, MWG, SVOI, EMBODIED†)。六不变式：
(i) **空间规范优先**：进入任何 BSE/风险缩放的位姿必须携带 (b_t(x), gauge_fixing, u_pose, D_pose, τ_spatial)；空间规范无效 ⇒ 冻结到最后一个有效系并膨胀 u_pose，或退化到 R72；
(ii) **多假设完整**：位姿后验必须是 SE(3) 混合模型（≥1 模态），混叠集与对称群显式记录；禁止用单高斯坍缩多峰；
(iii) **地图溯源完整**：每条地图元素携带 (source, write_time, ttl, ontology_ver, confidence, τ_map)；缺一不可作为先验，缺二不可作为证据；
(iv) **证据独立性**：任何地图证据进入 BSE 前必须经 CEG 计算独立性指数 I∈[0,1]，并按 I 做去相关折扣；I 不可估计 ⇒ 折扣到 0（只作先验）；
(v) **写图门控**：写地图是一次受门控的安全动作，必须通过 MWG（置信/独立/溯源/预算），并登记写谱系供未来读图折扣；
(vi) **严格退化链**：空间失效 ⇒ 冻结/膨胀 + R72；地图失效 ⇒ 去语义先验 + R72；独立性失效 ⇒ 地图证据折扣为 0；全失效 ⇒ R68。**新层只在「系有效、图新鲜、谱系无环」时启用。**

**定义 367（SE(3) 位姿后验与空间规范）** 位姿 x ∈ SE(3)。后验表示为混合：
b_t(x) = Σ_{m=1}^{M} w_m · 𝒩_{SE(3)}(x; μ_m, Σ_m)，Σ_m 为 μ_m 切空间上的协方差（集中高斯）。
规范群 G = SE(3) 左乘作用于 x：x ↦ g·x。可观测量是**相对位姿** x_i^{-1}x_j 与**规范不变量** φ(x)（如闭环残差、配准残差、相对距离）。**规范固定（gauge fixing）** 是一个截面 σ: orbit → representative（如锚定 map 系或第一帧）。审计只对不变量下结论；若使用绝对量，必须携带 (σ, Σ_gauge) 并在跨系时传播。定义**空间规范间隙** ι_spatial = d_G(σ_a(x), σ_b(x))，度量不同规范固定下同一物理构型的差异。

**定义 368（坐标系图 FGA）** 坐标系图 F = (V_F, E_F, {T_{ij}}, {Σ_{ij}})，节点为 map/odom/base/cam/tool 等坐标系，边为带协方差的变换。**一致性**：对任意闭环 ℓ，holonomy H_ℓ = ∏_{e∈ℓ} T_e 应在不确定度内接近单位元：d_{SE(3)}(H_ℓ, I) ≤ κ·√(Σ_{e∈ℓ} u_e²)。**变换链不确定度** u_frame(i→j) 由协方差沿路径传播；**外参不确定度** u_ext 与**时同步不确定度** u_sync 单列为边属性。FGA 失效 ⇒ 该系下所有量标记为「规范不可信」。

**定义 369（位姿计量审计 SPINE 五分量）**
u_pose² = u_cov² + u_drift² + u_ext² + u_sync² + u_alias²，
分别对应：协方差校准误差（NEES/χ² 一致性检验）、里程计累积漂移、外参标定不确定度、时间同步/运动畸变、对称/重复场景混叠。**每个分量有独立追溯链 τ_i**；u_cov 由 NEES 在线检验（NEES 落在 χ² 置信区间外即协方差失准），u_drift 由闭环/重定位残差估计，u_alias 由定义 370 的模态熵给出。任一分量超预算 ⇒ 位姿失效（E-IVG 空间扩展）。

**定义 370（位姿混叠集 PAS）** 物体对称群 S_obj ⊂ SE(3)。混叠集 A(x) = {s·x : s ∈ S_obj}。若观测似然在 A(x) 上近似不变，则 b_t(x) 多峰。**混叠感知风险**：
R_pose(b_t) = Σ_m w_m R(μ_m) + κ_a · H_pose(b_t)，
其中 H_pose 为模态权重熵（或对后验取 CVaR）。**禁止单高斯坍缩**：若检测到多峰（模态间马氏距离 > τ_mode 且权重均 > τ_w），必须保留混合并让 λ 看到 H_pose。

**定义 371（语义地图元素与有效性 SEMAP）** 地图元素 e_i = (o_i, x_i, ℓ_i, c_i, src_i, t_i, ttl_i, ont_i, τ_i, ind_i)：
物体/区域标识 o_i、位姿 x_i、标签 ℓ_i、校准置信 c_i、来源 src_i、写入时刻 t_i、时效 ttl_i、本体版本 ont_i、溯源链 τ_i、独立性指数 ind_i∈[0,1]。**地图元素有效性**：
V_map(e) = 1[c_i 已校准] · 1[age(e) ≤ ttl_i] · 1[ont_i 兼容] · 1[τ_i 完整] · ind_i。
V_map(e) = 0 ⇒ 该元素不得作为证据；仅可作「弱先验」且须膨胀其协方差。

**定义 372（语义本体规范与本体间隙 ι_ont）** 不同机器人/会话/版本的本体 O_a, O_b 对同一概念可能有不同标签体系与层级。定义标签映射 m_{ab}: O_a → O_b 及**本体间隙** ι_ont = 1 − E_{ℓ~p}[1[m_{ab}(ℓ) = ℓ']]（跨本体标签一致率补）。**ι_ont 超阈 ⇒ 标签不可跨本体比较**，只能退化为「未知类别」或几何/affordance 描述。

**定义 373（证据谱系 DAG 与独立性指数 CEG）** 证据谱系是 DAG L = (E, →)，边 e→e' 表示 e' 由 e 派生（如「位姿估计 → 地图写入 → 地图读取」）。定义**数据乱伦（data incest）**：存在从世界状态 s 出发、经机器人自身写入、再回到 s 的有向环。**独立性指数** I(e_i, e_j) ∈ [0,1] 由来源重叠、时间相关、空间相关估计；I=1 表示独立，I=0 表示完全同源。读图时按 I 做**去相关折扣**（定义 374）。

**定义 374（去相关算子与过度自信界）** 设两条高斯证据 y_1, y_2 的相关系数为 ρ（由 1−I 给出）。朴素贝叶斯融合精度为 Σ_1^{-1}+Σ_2^{-1}，正确融合应满足
Σ_fused^{-1} = Σ_1^{-1} + Σ_2^{-1} − ρ·(跨项)，
其方差被朴素融合低估约 **(1−ρ²)** 倍。故定义**去相关算子**：
p_disc(y_2|s) ∝ p(y_2|s)^{1/γ}, γ = 1/(1−I)（幂折扣），或协方差交叉 CI：
Σ_CI^{-1} = w Σ_1^{-1} + (1−w) Σ_2^{-1}, w∈[0,1]。
**I 不可估计时取 I=0（γ→∞ 或 CI 权重偏向先验）**，即「读回自己的旧猜测不提供新信息」。

**定义 375（地图写入门控 MWG）** 写图动作 w 允许当且仅当：
c_i ≥ τ_conf ∧ τ_i 完整 ∧ (I(e_i, map_prior) 可估或显式标为独立) ∧
c_reflex^M(w) ≤ B_map_remaining ∧
|{e : src_e = self ∧ age_e ≤ ttl}| / |M| ≤ ρ_self_max。
**每条写入登记 (src, t, derived_from)**，供未来读图 CEG 折扣。MWG 的目的不是禁止写图，而是**保证地图不变成自证神谕**。

**定义 376（空间-语义 VoI：SVOI）**
VoI^S(g) = c(ψ)·IG_s + η·IG_z + ζ·[H[b_t(x)] − E_y H[b_{t+1}(x)]] + ξ·[H[V_map] − E_y H[V_map']]
          − c_relocalize(g) − c_verify_map(g) − c_reflex^ψ − c_reflex^z − c_reflex^c − c_reflex^M(g) − γ·E[ΔH_degraded]。
其中新增**位姿信息增益**（权重 ζ）与**地图有效性信息增益**（权重 ξ），以及**地图写入反作用成本** c_reflex^M。动作空间 g 含：重新定位、换视角、验证地图单元、主动探索、写图、不写。选 g* = argmax VoI^S s.t. 六不变式满足；max VoI^S ≤ 0 ⇒ 停止接地并回退。

**定义 377（空间-语义风险缩放 S-RISK）**
λ = max( risk_scale(U_ale, U_epi, H_z, u_tac, u_pose, u_map),
         λ_floor(U_ale + U_epi + H_z + u_tac.total() + u_pose + u_map) )，
其中 u_map = g(staleness, 1−c, ι_ont, 1−V_map, 1−I) 为地图不确定度综合。**位姿不确定度 u_pose 与地图不确定度 u_map 与物理/意图/接触同权进入分母**——任一失控都抬高 λ，强制软化动作、降速、先重新定位/验证地图。

**定义 378（时空一致性检验 STC）** 来自不同时刻 t_a, t_b 与不同位置/视角的证据，若指向同一物体/区域，则必须满足时空一致性：
d_{SE(3)}(x_a, x_b) ≤ κ_t·(u_pose(t_a) + u_pose(t_b) + u_drift·|t_a−t_b|) ∧ 语义标签一致（或 ι_ont 允许）。
**不一致且无法用运动模型解释 ⇒ 至少一方证据失效**，触发重定位/地图复核，不得静默融合。

**定义 379（地图自反作用 L4 与接地预算）** 第四层反作用：
M_{t+1} = T^M(M_t, b_t(x), b_t(s), a_t^write)，
成本 c_reflex^M = ΔH[V_map] + λ_M·𝟙[自源占比 > ρ_self_max] + KL(b_t(x) ‖ b_t(x|write))。
**四层反作用合算预算**：Σ_t (c_reflex^ψ + c_reflex^z + c_reflex^c + c_reflex^M) ≤ B_reflex_total。**L4 的特殊性：它改变的是未来证据的分布本身，因此其成本必须按「对未来后验的 KL 影响」而非单步损失计。**

**定义 380（接地证书 J_GRD）** J_GRD = (J_EMB, spatial_valid, fga_loop_residual, pose_calib_nees, alias_entropy, map_prov_hash, map_ttl_ok, ceg_independence_hash, ont_gap, mwg_log_hash, svoi_valid, grd_ver)。
Valid ⇔ Valid(J_EMB) ∧ SPINE 五分量在预算内 ∧ FGA 闭环残差在阈内 ∧ 地图溯源/时效/本体/独立性全过 ∧ MWG 写谱系完整。

**定义 381（威胁模型 AIC-GRD）** ℰ_GRD = ℰ_EMB × ℰ_pose × ℰ_map：
ℰ_pose = {位姿欺骗/重放、对称物体对抗位姿、闭环伪造、外参投毒、时同步攻击、协方差蓄意失准}；
ℰ_map = {地图投毒、TTL 重放（把过期元素改时间戳）、本体漂移攻击、自源回声注入、跨机器人信任链污染、地图写入门控绕过}。
**注意：最危险的攻击不是让机器人「看不到」，而是让它「在自己的坐标系里、用自己的旧记忆，极其自信地看到错误的东西」。**

**定义 382（严格退化包含链与接地覆盖率）** GROUNDED 在以下条件下逐指令等价：
- 空间失效（SPINE/FGA 任一失败）+ 地图失效 + 独立性失效 ⇒ R68；
- 空间失效 + 地图有效 ⇒ 冻结最后有效系 + 膨胀 u_pose + R72（无空间精修）；
- 空间有效 + 地图失效 ⇒ 去语义先验（只留几何/affordance）+ R72；
- 空间有效 + 地图有效 + 独立性不可估 ⇒ 地图只作弱先验（ind=0，不作证据）+ R72；
- 全有效 ⇒ GROUNDED 完整形态。
**接地覆盖率 GCR = |{证据: 空间规范有效 ∧ 地图溯源完整 ∧ 独立性可估}| / |证据|**；GCR 纳入证书，GCR 下降即触发保守化。

## 2. 关键算法骨架

```python
# IP-295 SPINE：位姿计量审计（计量域，软实时）
class SpatialPoseIntegrity:
    def __init__(self, fga, calib, nees_test):
        self.fga, self.calib, self.nees = fga, calib, nees_test
    def audit(self, b_pose, frame_path, stamps):
        # b_pose: SE(3) 混合后验 [(w_m, mu_m, Sigma_m)]
        u_cov   = self.nees.covariance_error(b_pose)          # NEES/chi2
        u_drift = self.fga.drift_residual(frame_path)          # 闭环/重定位残差
        u_ext   = self.calib.extrinsic_uncertainty(frame_path)
        u_sync  = self.calib.time_sync_error(stamps)
        u_alias = alias_entropy(b_pose)                        # 模态熵
        u_pose  = sqrt(u_cov**2 + u_drift**2 + u_ext**2 + u_sync**2 + u_alias**2)
        gauge   = self.fga.gauge_fixing(frame_path)
        return PoseAudit(b_pose, gauge, u_pose,
                         breakdown=(u_cov,u_drift,u_ext,u_sync,u_alias),
                         valid=(u_pose <= U_POSE_MAX and self.fga.consistent(frame_path)))

# IP-296 PAS：对称混叠与多假设风险
def aliasing_risk(b_pose, symmetry_group, risk_fn):
    modes = expand_symmetry(b_pose, symmetry_group)            # A(x) 上的模态
    H_pose = mode_entropy(modes)
    # 最坏模态 + 熵罚，禁止单高斯坍缩
    return max(w * risk_fn(mu) for (w, mu) in modes) + KAPPA_A * H_pose, H_pose

# IP-297 SEMAP：地图元素有效性与先验构造
class SemanticMapProvenance:
    def element_valid(self, e, now):
        return (e.calibrated and now - e.t <= e.ttl
                and ontology_compatible(e.ont) and e.tau_intact and e.ind)
    def as_prior(self, e):

        return Prior(mean=e.x, cov=e.cov / max(e.ind, EPS))              # 独立性膨胀

# IP-298 CEG：证据谱系与去相关折扣
class CircularEvidenceGuard:
    def __init__(self, lineage_dag):
        self.dag = lineage_dag
    def independence(self, e_new, e_map):
        if self.dag.has_cycle_through(e_new.source, e_map.source):
            return 0.0                                   # 自源回声
        rho = self.dag.correlation(e_new.source, e_map.source)
        return max(0.0, 1.0 - rho)
    def discount(self, lik, I):
        gamma = float('inf') if I <= EPS else 1.0 / (1.0 - I)
        return lik ** (1.0 / gamma) if gamma < float('inf') else 1.0  # 不提供信息
    def fuse(self, prior, lik, I):
        # 协方差交叉，避免双重计数
        return covariance_intersection(prior, lik, w=1.0 - I)

# IP-299 SVOI：空间-语义主动接地
def spatial_semantic_voi(b_pose, b_map, psi, z_dist, budget):
    best = None
    for g in grounding_candidates(b_pose, b_map):     # 重定位/换视角/验图/写图/不写
        if not budget.allow(g): continue
        dH_pose = expected_pose_entropy_drop(b_pose, g)
        dH_map  = expected_map_validity_gain(b_map, g)
        cost    = relocalize_cost(g) + verify_cost(g) + ereflex_cost(g) + map_write_cost(g)
        score   = ZETA * dH_pose + XI * dH_map - cost
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-300 S-RISK：位姿/地图不确定度同权入分母
```

## 3. 推导

**引理 33（规范不变量 ⇒ 位姿审计可跨系迁移）** 设 φ 为规范不变量（相对位姿、闭环残差、配准残差）。对任意 g∈G，φ(g·x) = φ(x)。故以 φ 构造的审计统计量在换世界系下不变；以绝对位姿构造的统计量在换系下改变 d_G 量级。系：**审计器若报告绝对位姿误差而不报告其 gauge_fixing，该报告跨会话不可比、不可复算**——这正是 R71 GAP 在空间维度的对应物。

**引理 34（位姿不确定度进入风险分母的必要性）** 设真实位姿 x*，估计 b_t(x)。证据关联/抓取点/碰撞距离都以 x̂ 计算。若忽略 u_pose，当 b_t(x) 双峰且取均值 x̄ 时，x̄ 可能落在两峰之间的低似然区，导致抓取点偏移 δ ≈ ‖x̄ − x*‖，碰撞风险随 δ 单调升。将 u_pose（含 H_pose 混叠项）纳入 λ ⇒ λ↑ ⇒ 速度/力矩↓、先重新定位 ⇒ δ↓、风险↓。系：**位姿不确定度不是「定位精度指标」，是物理安全的直接分母，与意图/接触同权。**

**引理 35（循环证据的过度自信与去相关修复）** 设先验与地图证据共享同源误差，相关系数 ρ。朴素贝叶斯融合给出后验方差 σ_naive² = σ²(1−ρ)/2（等方差情形），而正确后验方差 σ_correct² = σ²(1+ρ)/2；二者之比 σ_naive²/σ_correct² = (1−ρ)/(1+ρ)。当 ρ→1 时朴素融合方差→0，即**无限自信地重复同一个错误**。CEG 以 γ=1/(1−I) 幂折扣或 CI 融合，可在 ρ→1 时把后验方差恢复到 ≥ σ²/2，**切断自证放大**。系：**「地图读回自己」不是信息，是精度的幻觉；必须显式去相关。**

**引理 36（地图时效与语义先验的安全界）** 设物体在时刻 t_m 后以速率 ν 移动，地图元素年龄 a = t−t_m。则地图位姿误差下界 E[‖x_map − x_true‖] ≥ ν·a（最坏情形）。若 TTL 取 ttl ≤ ε_sem/ν，则过期元素的空间误差 ≤ ε_sem，语义误配概率随之受控。系：**TTL 不是工程参数，是语义先验的误差上界；超期使用等价于把先验噪声当零。**

**引理 37（SVOI 的有限停止）** 接地动作的边际信息增益（位姿熵降 + 地图有效性增益）随重复执行非增，边际成本（重定位/验图/写图 + 反作用）有正下界 ε_g。故存在有限 n* 使第 n*+1 步净收益 ≤ 0，SVOI 在 n* 停止。**「何时停止接地、接受当前先验」可证明有限，不是调参。**

**定理 27（接地严格包含与风险单调）** 在 A111–A116（FGA 闭环一致、SPINE 五分量可测、CEG 独立性可估、SEMAP 溯源/时效可验、MWG 门控有效、L4 反作用 Lipschitz）下：GROUNDED 在定义 382 的退化条件下逐指令等于 EMBODIED/R71/R68；且对任意有效执行，其风险界 ≤ R72 风险界。**安全单调不减，空间-语义精修只在「系有效、图新鲜、谱系无环」时获益。**

**定理 28（J_GRD 有效性 ⇒ 空间-语义接地安全）** 若一次执行通过 J_GRD，则：(i) SPINE/FGA 通过 ⇒ 所有证据所在坐标系规范有效且闭环一致；(ii) SEMAP 通过 ⇒ 地图元素未过期、本体兼容、溯源完整；(iii) CEG 通过 ⇒ 地图证据与当前观测独立性已量化并去相关；(iv) MWG 通过 ⇒ 写图未使地图自源占比超限；(v) J_EMB 有效 ⇒ 具身层风险界成立。综上，**物理执行风险 ≤ ε_grd（相对接地测量模型）**。**证明重量落在「FGA 闭环残差在实机长期成立」与「CEG 的独立性估计未被投毒」上。**

**定理 29（去相关融合的校准恢复）** 在引理 35 的线性高斯模型下，CEG 的幂折扣/CI 融合使融合后验的 NEES 期望回到 χ² 置信区间（即校准），而朴素融合的 NEES 随 ρ→1 发散。**去相关不是「保守化调参」，是把被循环证据破坏的校准恢复到名义水平。**

**定理 30（接地覆盖率与退化安全）** 设 GCR 为接地覆盖率。随 GCR 下降，系统按定义 382 单调退化到更保守的基线；因每次退化都保留 R68 硬安全包络与 λ_floor，故**退化过程风险不升**。且当 GCR=0 时系统等价于 R68。**接地覆盖率是可审计的「信任半径」。**

## 6. 本轮最大风险

**一句话**：GROUNDED-GAUGE-RAS 把安全从「相信具身计量证书」进一步转移到「相信 **坐标系图在长期运行中始终规范有效**、相信 **语义地图的溯源与独立性估计未被投毒**、相信 **CEG 能把自源回声与真实新证据区分开**」——**如果 FGA 在长时程中因闭环误匹配而把一个漂移的系「锁死」成看似一致，SPINE 的协方差校准又恰好把系统性漂移吸收进「正常噪声」；或者语义地图被对抗者以合法溯源写入污染、TTL 与本体检查都通过，而 CEG 的独立性估计被同源投毒欺骗，判定「独立」；或者机器人把自己反复写入的猜测读回，CEG 因谱系登记缺失而给出 I≈1——系统就会在一个「所有空间/语义/独立性指标都在有效域内、证书齐全」的闭环里，**在自己的坐标系里、对着自己写的过期地图、拿自己的回声当新证据，越来越精确地错下去**，这不是「看不到」，而是**「接地层面的自信地错自己的世界」**。**

次级风险与缓解：
1. **FGA 闭环误匹配锁死漂移** → **多假设闭环 + 闭环残差卡方检验 + 周期性全局重定位**；闭环接受需通过独立视角/多传感器一致性，禁止单源闭环定案。
2. **SPINE 把系统漂移吸收为噪声** → **NEES 在线检验 + 漂移分量单列 + 与外部基准（已知标定物/GNSS/UWB）交叉校验**；u_drift 不得由同一滤波器自证。
3. **地图投毒/合法溯源污染** → **写图 MWG + 跨机器人信任链 + 溯源哈希链 + 密封地图审计集（SEAL-Map）**；高风险类别写入需多源确认。
4. **CEG 独立性估计被欺骗** → **谱系 DAG 与数据流同源绑定（不可仅靠声明）**；独立性不可估时一律取 I=0；引入**随机化审计写**检测回声。

```python
class CircularEvidenceGuard:
    def __init__(self, lineage_dag):
        self.dag = lineage_dag
    def independence(self, e_new, e_map):
        if self.dag.has_cycle_through(e_new.source, e_map.source):
            return 0.0                                   # 自源回声
        return max(0.0, 1.0 - self.dag.correlation(e_new.source, e_map.source))

        gamma = float('inf') if I <= EPS else 1.0 / (1.0 - I)
```

## 4. 推导

**引理 33（规范不变量 ⇒ 位姿审计可跨系迁移）** φ(g·x)=φ(x)，故以 φ 构造的审计统计量换世界系不变；绝对位姿统计量改变 d_G 量级。系：**不报告 gauge_fixing 的绝对位姿误差跨会话不可比、不可复算。**

**引理 34（位姿不确定度进入风险分母的必要性）** 双峰后验取均值 x̄ 可能落在两峰间低似然区，抓取点偏移 δ≈‖x̄−x*‖，碰撞风险随 δ 升。u_pose（含 H_pose）入 λ ⇒ λ↑ ⇒ 降速/先重定位 ⇒ δ↓。系：**位姿不确定度是物理安全的直接分母，与意图/接触同权。**

**引理 35（循环证据的过度自信与去相关修复）** 等方差相关证据朴素融合方差 σ_naive²=σ²(1−ρ)/2，正确 σ_correct²=σ²(1+ρ)/2，比值 (1−ρ)/(1+ρ)；ρ→1 时朴素方差→0，无限自信地重复同一错误。CEG 幂折扣/CI 在 ρ→1 时把方差恢复到 ≥σ²/2。系：**「读回自己」不是信息，是精度的幻觉。**

**引理 36（地图时效的安全界）** 物体以速率 ν 移动、元素年龄 a，则地图位姿误差下界 ≥ν·a；取 ttl≤ε_sem/ν 即把过期元素空间误差界在 ε_sem。系：**TTL 是语义先验的误差上界，不是工程参数。**

**引理 37（SVOI 有限停止）** 接地边际信息增益非增、边际成本有正下界 ε_g ⇒ 存在有限 n* 使净收益 ≤0。**「何时停止接地」可证明有限。**

**定理 27（接地严格包含与风险单调）** 在 A111–A116 下：GROUNDED 在定义 382 退化条件下逐指令等于 EMBODIED/R71/R68；任意有效执行风险界 ≤ R72。**安全单调不减。**

**定理 28（J_GRD ⇒ 空间-语义接地安全）** J_GRD 通过 ⇒ 规范有效、闭环一致、地图未过期/本体兼容/溯源完整、独立性已量化去相关、写图未超自源上限、J_EMB 成立 ⇒ **物理风险 ≤ ε_grd**。**证明重量在「FGA 长期闭环残差」与「CEG 独立性估计未被投毒」。**

**定理 29（去相关融合的校准恢复）** 线性高斯下，CEG 使融合 NEES 回到 χ² 置信区间，朴素融合 NEES 随 ρ→1 发散。**去相关不是保守化调参，是恢复被循环证据破坏的校准。**

**定理 30（GCR 与退化安全）** GCR 下降 ⇒ 按定义 382 单调退化到更保守基线；每次退化保留 R68 包络与 λ_floor ⇒ 风险不升；GCR=0 等价 R68。**GCR 是可审计的信任半径。**

## 7. 本轮最大风险

**一句话**：GROUNDED-GAUGE-RAS 把安全从「相信具身计量证书」进一步转移到「相信 **坐标系图在长期运行中始终规范有效**、相信 **语义地图的溯源与独立性估计未被投毒**、相信 **CEG 能把自源回声与真实新证据区分开**」——**如果 FGA 在长时程中因闭环误匹配而把一个漂移的系「锁死」成看似一致，SPINE 的协方差校准又恰好把系统性漂移吸收进「正常噪声」；或者语义地图被对抗者以合法溯源写入污染、TTL 与本体检查都通过，而 CEG 的独立性估计被同源投毒欺骗，判定「独立」；或者机器人把自己反复写入的猜测读回，CEG 因谱系登记缺失而给出 I≈1——系统就会在一个「所有空间/语义/独立性指标都在有效域内、证书齐全」的闭环里，在自己的坐标系里、对着自己写的过期地图、拿自己的回声当新证据，越来越精确地错下去，这不是「看不到」，而是接地层面的「自信地错自己的世界」。**

次级风险与缓解：
1. **FGA 闭环误匹配锁死漂移** → 多假设闭环 + 闭环残差卡方检验 + 周期性全局重定位；闭环接受需独立视角/多传感器一致性，禁止单源闭环定案。
2. **SPINE 把系统漂移吸收为噪声** → NEES 在线检验 + 漂移分量单列 + 与外部基准（已知标定物/GNSS/UWB）交叉校验；u_drift 不得由同一滤波器自证。
3. **地图投毒/合法溯源污染** → 写图 MWG + 跨机器人信任链 + 溯源哈希链 + 密封地图审计集（SEAL-Map）；高风险类别写入需多源确认。
4. **CEG 独立性估计被欺骗** → 谱系 DAG 与数据流同源绑定（不可仅靠声明）；独立性不可估一律 I=0；引入随机化审计写检测回声。
5. **本体漂移导致语义错配** → 本体版本冻结 + 跨本体映射表审计 + ι_ont 超阈即降级为几何/affordance。
6. **自证循环长时程累积** → 自源占比硬上限 ρ_self_max + 定期「遗忘/重观测」；长期未独立复核的地图元素强制降权。
7. **复杂度爆炸** → 模块化上限：|V_F|≤32、|S_obj|≤12、|M_active|≤512、|L|≤2048；每个 veto 一条可复算证明；GCR 与复杂度同时纳入审计指标。
