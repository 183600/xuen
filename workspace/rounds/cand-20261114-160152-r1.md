# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 4 轮；本轮灵感：「碰撞避免」×「数据增强」）

> R73 把证据变成契约、把组合变成代数、把反作用变成通道。它证明的是「**系统级安全性质在模块热替换下保持**」。但 R73 留下一个比「契约表达力」更尖锐的漏洞：**它的安全仍然是标量风险，而不是可证伪的物理事件。**
>
> - **碰撞避免缺席为一等证书。** R73 只有 C1 的下游指标「碰撞率」与 λ_floor 标量门槛。λ 能说「风险高」，却不能说「还剩多少厘米余量、这份余量由哪几项证据支付、在什么假设下成立」。不确定度在 CCA 里是**加性**的，碰撞在物理上是**几何的、非补偿的**：0.01 的位姿均值误差与 0.01 的深度方差在碰撞语义下并不等价。R73 组合的是 u，不是间距。
> - **数据增强缺席，而且是危险地缺席。** DPEM 的材质网、BSE 的深度补全都需要增强；但 R73 的 conformal 审计、SEAL 校准、P_out 估计都默认数据是「采集来的」。一旦训练/校准集被增强，覆盖率会被增强本身抬高，而独立信息没有增加——这是 R73「审计覆盖」不变式的后门，也是「审计独立性」问题在数据侧的对应物。**增强可以让系统在证书上变安全，在物理上变危险。**
> - **ECG 只有拓扑，没有碰撞语义。** R73 补丁引入证据因果图，但碰撞是有明确因果机制的事件（遮挡→几何→间距→动作→碰撞），而反事实近失（near-miss）数据正是最有价值、也最容易被模型自证的数据。
>
> 本轮两个灵感正好补两块，并在第三处交汇：
> - **碰撞避免 → CEM / SBA（Collision Evidence Metrology / Separation Budget Accounting）**：碰撞不是风险分数，而是**间距账本**。把每个证据不确定度按敏感度 κ 折算成「安全间距税」，得到可审计的分离预算 `B_col = d_clear − Σ_i κ_i·û_i`；`B_col ≥ 0` 才是碰撞证书。
> - **数据增强 → AAC / AAP（Admissible Augmentation Contract / Augmentation Algebra）**：增强不是免费数据，而是**以假设为抵押的贷款**。由数据处理不等式，增强不增加关于目标量的信息；任何「认证不确定度下降」必须记账到显式假设 `A_α`，否则就是 **coverage laundering（覆盖洗白）**。
> - **交汇 → AEGIS-RAS**：间距赤字只能由两种东西偿还——**独立的真实证据**或**显式、可证伪、尾部有效的假设**；没有第三种方式。
>
> 核心命题：**不再问「碰撞率有多低」，而问「碰撞避免能否被写成可审计的间距账本，且数据增强只能通过显式、可证伪的假设来偿还间距赤字，而不能凭空制造安全？」** 把 MODGAUGE 上升为 **AEGIS-RAS**（**A**ssumption-grounded **E**vidence with **G**uaranteed **I**nflated **S**eparation for RAS）——**间距账本 × 增强审计**。

## 0. 直觉与动机

**灵感 1（碰撞避免 → 碰撞不是概率，是间距账本）**
直觉：人开车不会实时计算「碰撞概率 0.03」，而是保留一个可分解的余量：车距、反应时间、路面湿滑、前车可能急刹。这个余量是**可谈判、可审计**的。机器人同理：`d_clear` 是物理量，误差来自位姿、深度、意图预测、执行延迟、遮挡；每一项都要求把障碍或自身**膨胀**一定量。碰撞避免 = 膨胀后的两个集合不相交。
关键洞察有两条：
(1) **不确定度是加性的，碰撞是几何的、非补偿的。** 风险分数可以把两种误差线性平均掉，间距不能——深度差 2cm 在近接触时可能就是碰撞，在 2m 外则无关紧要。所以必须有 **证据→间距的转换函数 `κ_i = ∂d_clear/∂e_i`**，且 κ 由几何与证据契约共同决定，不是全局常数。
(2) **碰撞避免的对偶是证据计量。** 每一单位证据不确定度都必须以间距「缴税」；反过来，想缩小安全间距，就必须先缩小某个 `u_i` 或声明一个尾部有效的假设。这把「安全」从规划器的属性变成了**账本的属性**。
比喻：R73 的 λ 是体温计，只告诉你发烧；SBA 是血液化验单，告诉你哪一项超标、超多少、参考区间是什么、哪项是「假设性正常」。

**灵感 2（数据增强 → 假设抵押贷款，DPI 是审计的会计恒等式）**
直觉：数据增强（旋转、裁剪、颜色抖动、场景重排、生成式补全、仿真合成）在感知论文里几乎免费地提升指标。但**认证不是指标**。设 `θ` 是碰撞相关的目标量（尾部间距分位数、合同外质量 `P_out`、或碰撞率）。增强是 `α(D)`，是数据的函数。由数据处理不等式（DPI）：
`I(θ; α(D)) ≤ I(θ; D)`。
增强**没有创造任何关于 θ 的新信息**。它之所以有帮助，是因为把假设（旋转不变、光照不变、语义等变、物理可实现）作为先验注入了估计器。因此：
- 若一个流水线声称「用了增强后认证不确定度下降」，那下降**必须**记账到某个显式假设 `A_α`；
- 若账本上没有这个假设，那下降只能来自（i）用了真实独立数据（那不是增强的功劳），或（ii）覆盖洗白（把校准集分布改得更容易覆盖）。
比喻：增强是贷款，假设是抵押物。审计不禁止贷款，审计要评估抵押物在**碰撞尾部**是否贬值。平均值上抵押物很值钱，尾部上可能一文不值——而碰撞只发生在尾部。

**灵感 3（尾部是碰撞的全部 → 平均覆盖不是证据）**
直觉：99% 的操作/驾驶数据无碰撞；碰撞率由 0.1% 的尾部决定。平均覆盖率与尾部覆盖率是两件不同的事，且**平均覆盖可以完全掩盖尾部失效**（构造一个混合分布即可，引理 41）。增强最擅长改变平均分布，最不擅长、也最危险地改变尾部——近接触几何、遮挡、透明/镜面、人的不可预测性，恰是增强假设最易失效的地方。
所以本轮把 admissibility（可采信性）定义在**尾部集合 `T_δ`** 上，而不是全分布上；证书只在尾部签章。这把 R73 的「有效域 D」从均值域收紧为**尾部有效域**。

**灵感 4（反事实增强的因果性 → 近失数据不能自证）**
直觉：近失（near-miss）数据最值钱，因为它的价值在反事实：「如果当时多打 5°，就会撞」。但这个反事实标签来自模型。用模型生成的反事实去训练/验证**同一个模型**，是自证循环；它会让碰撞预测在留出集上变好，却不增加关于模型误差的信息（引理 42）。
正确做法：用碰撞因果图（CCG）区分**可识别反事实**（由观测与因果结构可算，权重 w=1 或由界给出）与**模型依赖反事实**（权重 w=0，只能进训练集，不能进认证集）。这把 R73 的 ECG 从「证据拓扑」升级为「碰撞机制图」，也让「增强」第一次有了可审计的因果语义。

## 1. 形式化定义（增量：定义 383–398）

**定义 383（AEGIS-RAS 总览与五不变式）** AEGIS-RAS = (CEM, SBA, CCG, AAC, AAP, CTEA, CCS, MODGAUGE†)。五不变式：
(i) **间距非负**：控制域执行的任何动作（含回退刹车）必须满足 `B_col ≥ 0`；
(ii) **账簿可追溯**：每个间距税项 `κ_i·û_i` 必须可追溯到某个 EC 的 `u_i` 字段与一次 SEAL 校准，缺链即不得计入证书；
(iii) **增强负债披露**：任何进入训练或校准的增强必须携带假设账本 `A_α` 与独立性声明；未披露增强不得进入认证集 `D_cert`；
(iv) **尾部审计**：碰撞证书只在尾部集 `T_δ` 上有效，平均覆盖率不构成证据；
(v) **退化链扩展**：碰撞模块失效 ⇒ 最小风险状态（MRM，停车/退回安全位）stub，**不得静默降级为「继续运动」**；安全侧只增不减。

**定义 384（碰撞证据契约 CEC）** CEC = (T_in, T_out, {u_i}, κ, H, ρ_dyn, T_δ, I⊥, τ_merge, seal_ref)，是 EC 的碰撞特化：
- T_out = 分离证据（separation evidence），与深度/触觉证据类型隔离；
- `{u_i}` = 证据分量（位姿、深度/几何、意图预测、执行延迟、遮挡），每项继承上游 EC 的追溯链；
- `κ_i: X × 𝒢 → ℝ_{≥0}` = 间距敏感度（Lipschitz 常数），在有效域内取值，**不是全局常数**；
- H = 递归校验时域；`ρ_dyn` = 动力学/可达集包络；
- `T_δ` = 碰撞尾部集合；`I⊥` 至少含 `COLLISION` 否决指示；
- `seal_ref ∈ {SEAL-Sep, SEAL-Tail}`。

**定义 385（间距预算 SBA）** 给定状态 x、动作 a、证据 y：
`d_clear(x,a;y) = dist(S(x,a), O(y))`，S 为机器人扫掠体，O 为证据估计的障碍集。
`û_i(y)` 为 `(1−δ_i)` 上界（由 SEAL 的 conformal/区间校准给出）。
`r_cert = r_0 + Σ_i κ_i·û_i`（r_0 为硬性物理余量，如表面粗糙度/标称尺寸）。
`B_col(x,a;y) = d_clear − r_cert`。
**碰撞证书成立** ⇔ `B_col ≥ 0` ∧ CCG 因果链可识别/有界（定义 387）∧ 增强账本可采信（定义 389）。
**递归形式**：`∀x′ ∈ Reach_H(x,a): B_col(x′, a) ≥ 0`（含刹车回退动作）。

**定义 386（间距谱 SMS 与尾部）** 策略 π 与证据过程下的间距预算分布记为 **SMS**（Separation Margin Spectrum）。尾部 `T_δ = {B_col ≤ q_δ}`，`q_δ` 为 δ 分位。碰撞避免证书要求：
(i) `quantile_δ(B_col) ≥ 0`；(ii) `r_cert` 在 `T_δ` 上的实际覆盖率 ≥ `1−δ`（尾部覆盖，而非平均覆盖）；(iii) 尾部有效样本量 `ESS_tail ≥ n_min`，否则证书必须**加宽**（δ 上调），不得缩窄。

**定义 387（碰撞因果图 CCG）** 有向无环图 `CCG = (V_C, E_C)`，节点 `V_C = {证据(深度/材质/位姿), 障碍几何, 意图/轨迹预测, 间距, 动作, 碰撞}`，边带机制说明。对每条边 e 标注可识别性 `id(e) ∈ {identified, bounded, non-identified}`：
- identified：反事实可由观测与结构计算；
- bounded：给出上下界（最坏情形膨胀）；
- non-identified：**禁用点估计**，只能取契约有效域内的最坏值。
碰撞证书要求「证据→间距→动作」路径上不存在未处理的 non-identified 边。CCG 是 R73 ECG 的碰撞特化，不是替代。

**定义 388（增强算子与信息账本）** 增强算子 `α = (φ, A_φ, L_φ)`：
- `φ: 𝒳 → 𝒳`（可随机），把样本变换为增强样本；
- `A_φ` = 显式假设集合（不变性/等变性/物理可实现性/反事实可识别性），每条假设带**证伪测试**与**有效区域**；
- `L_φ = (ESS_φ, prov_φ, Δout_φ, tail_φ, conflict_φ)`：有效样本量、独立溯源数（独立采集场次/地点/设备）、声称的合同外质量变化、尾部有效性、与其他增强的假设冲突标记。

**定义 389（可采信增强 AAC）** α 对**认证**可采信 ⇔ 六条同时成立：
(a) **域保持**：`φ` 在 `A_φ` 的有效区域内不产生契约外场景；
(b) **标签等变**：语义标签在 φ 下不变（检测框、材质类、碰撞/非碰撞标签的变换规则显式声明）；
(c) **假设可证伪**：`∀a ∈ A_φ` 存在对应测试 `T_a` 与失效判据；
(d) **溯源完整**：每个增强样本可追溯到原样本 + 变换参数 + 随机种子；
(e) **覆盖诚实**：在**密封真实尾部集** `D_tail^seal` 上，`|coverage_cert − coverage_audit| ≤ β`；没有独立真实样本时不得声称 `Δout < 0`；
(f) **尾部有效**：`A_φ` 的有效区域 ⊇ `T_δ`。
`Admissible(α)` ⇒ α 可进入 `D_cert`；否则 `α(D) ⊆ D_train`（仅训练，非证据）。

**定义 390（增强代数 AAP）** 三种组合：
- **串联** `α_2 ∘ α_1 = (φ_2∘φ_1, A_1 ∪ A_2, L)`，其中 `ESS ≤ min(ESS_1, ESS_2)`，且做**假设冲突检测**（如「水平翻转等变」与「左右手语义标签」冲突）；
- **并联加权** `α_1 ⊕_w α_2`：按权重混合，`ESS ≤ w²ESS_1 + (1−w)²ESS_2 + 2w(1−w)·corr`，相关性未知时取 `ESS ≤ min`；
- **拒绝** `α_1 ⊘ α_2`：若假设在尾部不相容，组合结果降级为 `D_train`。
**可采信性对组合封闭** ⇔ 假设一致 ∧ 尾部有效保持；否则只保训练、不保证书。

**定义 391（证据权重与训练/认证分离）** 证据权重 `w(α) ∈ [0,1]`：真实独立样本 w=1；假设背书且尾部有效的增强 w∈(0,1)，按 `ESS/溯源` 折减；模型依赖反事实 w=0。认证集
`D_cert = {真实独立样本} ∪ {α(D): Admissible(α) ∧ w>0}`，
SEAL 校准只允许使用 `D_cert` 并按 w 加权；`D_train` 可含任意增强，但**不得**进入证书。

**定义 392（尾部位移与有效样本量）** 协变量位移下用密度比 `r(x)=p_tail(x)/p_data(x)` 重加权，`ESS_tail = (Σr)²/Σr²`。若 `ESS_tail < n_min`，则 `δ` 必须上调（证书加宽），**不得**用增强样本补足 ESS——增强样本与真实样本不是同一随机变量。

**定义 393（碰撞触发证据采集 CTEA）** 当 `LCB(B_col) < τ_col` 或 `ESS_tail < n_min` 时，触发定向真实采集/主动感知/近失挖掘；调度受 REG 时序契约约束；在假设未通过尾部检验前，**不得**用合成数据替代真实数据填入 `D_tail^seal`。

**定义 394（认证碰撞屏障 CCS）** 控制域 1kHz：对候选动作 a 与刹车回退 b，分别检查 `B_col(x,a) ≥ 0` 与 `B_col(x,b) ≥ 0`（b 含最坏障碍运动界 `ρ_dyn`）；任一不满足则执行 b。膨胀量在 50Hz 计量域预计算，控制域只做查表与一维比较；输出经 R72 `certified_prefix`。

**定义 395（AEGIS 组合证书）** `J_AEGIS = J_MOD ⊗ J_col ⊗ J_aug`：
- `J_col` 校验间距预算、CCG 可识别性、SMS 尾部覆盖；
- `J_aug` 校验 AAC 六条、账本闭合（`Σ` 债务/资产平衡）、尾部审计通过；
- `Valid(J_AEGIS) ⇒ Valid(J_MOD)`（R73 为其特例）。

**定义 396（最小基准 MB4/MB5）** MB4（碰撞尾部：近接触抓取/人机共处/动态障碍，含真实近失与受控注入）、MB5（增强审计：真实采集 vs 各类增强，预注册尾部集与洗白攻击）。各 ≤3h 单卡可复现，固定种子，`SEAL-Tail` 密封。

**定义 397（复杂度结构上限扩展）** 在 R73 基础上新增：`|κ 项| ≤ 6`、`H ≤ 1.5s`、`CCG 节点 ≤ 16`、`增强账本深度 ≤ 4`、`D_cert 增强比例 ≤ ρ_cert`（预注册，默认 0.3）——全部为可审计图/账本性质。

**定义 398（严格包含条件）** AEGIS 退化为 MODGAUGE 当且仅当：碰撞模块置为 `stub_col`（恒不否决、`B_col ≡ +∞`）、增强账本为空、`T_δ = ∅`、`w(α)=0`。此时逐指令等于 R73，再退化等于 R72/R71/R68。

```python
# IP-303 CEM/SBA：碰撞证据计量与间距预算（感知 100Hz + 计量 50Hz）
class CollisionEvidenceMetrology:
    def separation_budget(self, x, a, ev, horizon):
        O = self.obstacle_from_evidence(ev)          # 深度/触觉/本体 → 障碍集
        d = self.geometry.clearance(x, a, O)         # dist(S(x,a), O)
        tax = self.hard_margin                      # r_0
        for i, u in ev.u_components.items():         # 6 分量，逐项追溯
            kappa = self.sensitivity.kappa(i, x, a, ev)   # κ_i（几何/有效域）
            ub = self.seal.upper_bound(i, ev, delta=ev.delta[i])
            tax += kappa * ub
        B = d - tax
        return SeparationEvidence(B=B, d=d, tax=tax,
                                  items=self.ledger(ev, tax),      # 账簿
                                  tail_ok=self.tail_probe(B))

# IP-304 CCG：碰撞因果图与反事实可识别性
def ccg_certificate(ccg, evidence, action):
    for e in ccg.path('evidence', 'separation'):        # 证据→间距
        if ccg.id(e) == 'non-identified':
            evidence = ccg.worst_case(evidence, e)       # 禁用点估计
    for e in ccg.path('separation', 'action'):
        if ccg.id(e) == 'non-identified':
            return Certificate(valid=False, why=f'CCG_GAP:{e}')
    return Certificate(valid=True, ccg=ccg, evidence=evidence)

                and self.falsifiable(self.assumptions)          # 每条假设有测试
                and self.ledger.provenance_complete()
                and self.ledger.coverage_gap(seal_tail) <= BETA  # 尾部诚实
                and self.validity_region() >= T_delta)           # 尾部有效

def admissible_to_cert(alpha, T_delta, seal_tail):
    if alpha.admissible(T_delta, seal_tail):
        w = alpha.ledger.evidential_weight()      # ∈ (0,1]，按 ESS/溯源折减
        return ('D_cert', w)
    return ('D_train', 0.0)                       # 只能训练，不得进证书

# IP-306 AAP：增强代数（串联/并联/拒绝）
def compose_aug(a1, a2, op):
    if op == 'SER':
        A = a1.assumptions | a2.assumptions
        if not consistent(A): return Augmentation(..., tag='D_train')
        ess = min(a1.ledger.ess, a2.ledger.ess)          # 信息不增
        return Augmentation(phi=lambda s: a2.phi(a1.phi(s)),
                            assumptions=A, ledger=Ledger(ess=ess, ...))
    if op == 'PAR':
        if conflict(a1, a2): return Augmentation(..., tag='D_train')
        ess = min(a1.ledger.ess, a2.ledger.ess)          # 相关性未知 → 保守
        return Augmentation(phi=mix(a1, a2), assumptions=A, ledger=Ledger(ess=ess, ...))
    return Augmentation(..., tag='D_train')

# IP-307 CTEA：碰撞触发证据采集（仅在真实证据上记账）
def collision_triggered_acquisition(B_lcb, ess_tail, sched, budget):
    if B_lcb >= TAU_COL and ess_tail >= N_MIN:
        return None
    plan = sched.propose_real_collection(target=tail_gap(B_lcb, ess_tail))
    if plan.reg_ok and plan.cost <= budget:          # REG 时序契约
        return plan                                   # 主动靠近/换视角/采近失
    return 'DEGRADE_TO_MRM'                           # 无预算 → 最小风险状态

# IP-308 CCS：认证碰撞屏障（控制域 1kHz，只读快照）
def certified_collision_shield(snap, a_candidates, fallback_brake):
    B_fb = snap.B_col[fallback_brake]                 # 50Hz 预计算
    if B_fb < 0: return fallback_brake, 'MRM'         # 回退都不可行 → MRM
    for a in a_candidates:
        if snap.B_col[a] >= 0 and snap.ccg_ok[a]:
            return a, 'CERTIFIED'                     # 账簿非负 + 因果链完好
    return fallback_brake, 'FALLBACK'

# IP-309 AEGIS 主闭环（R73 MODGAUGE† + 间距/增强层）
def AEGIS_round(M, x, obs, depth_img, tac_frame):
    d_ev = M.dpem.update(depth_img, ...)              # R73 DPEM†
    t_ev = M.dmem.update(tac_frame, ...)
    s_ev = M.cem.separation_budget(x, M.last_a, merge(d_ev, t_ev), M.H)
    if not M.ccg.certificate(s_ev).valid: s_ev = stub_col()   # 因果断链 → MRM 语义
    if s_ev.B < M.tau_col: M.ctea.request(...)         # 碰撞触发采集
    a = M.ccs.select(s_ev, M.planner.candidates(x))    # 认证屏障
    M.aug.audit(M.d_cert, M.seal_tail)                 # 增强尾部审计（低频）
    return a, J_AEGIS(M.mreg, s_ev, M.aug.ledger)       # 组合证书
```

## 3. 推导

**引理 38（增强信息不等式 / DPI：没有免费的信息）** 对任意目标量 θ 与任意逐样本增强 α（可含共享随机性），有 `I(θ; α(D)) ≤ I(θ; D)`。因此任何认证不确定度的下降只能分解为
`ΔRisk = ΔRisk_info(≤0) + ΔRisk_assumption(A_α)`。
若流水线声称 `ΔRisk<0` 而账本中未提供新增独立样本或显式假设 `A_α`，则该下降不可能是信息性的，只能是**分布/覆盖层面的洗白**。系：**增强是假设的载体，不是信息的来源；认证必须向假设收费。**

**引理 39（间距税单调性与无免费间距）** `r_cert` 对每个 `û_i` 与 `κ_i` 单调不减。对可采信 α，`û_i` 只允许在 `A_α` 的有效区域内收缩，且收缩量不得超过独立证据给出的下界；故
`Δr_cert(α) ≥ −Σ_i κ_i·Δû_i^{ind}`。
只有当 `Δû_i^{ind}>0`（新的真实独立样本）或假设 `A_α` 在尾部有效时，间距才可合法缩小。系：**增强可以降低训练误差，但降不了已认证的间距税——除非它为某个假设付息。**

**引理 40（间距预算的递归安全性）** 若 `B_col(x_t,a_t) ≥ 0` 且 `∀x′∈Reach_H(x_t,a_t): B_col(x′,a_t) ≥ 0`，则在契约有效域、CCG 已识别/有界机制下，`[t,t+H]` 内无碰撞。证明：`B_col≥0` ⇒ 膨胀集 `S⊕r_cert` 与障碍集 `O` 不交；可达集包络保证任意实际轨迹仍落在膨胀集内；执行延迟已计入 `r_act`。系：**碰撞证书是一个关于集合不相交的、非补偿的几何命题，而不是关于期望的命题。**

**引理 41（尾部覆盖不可由平均覆盖推出）** 存在分布使平均覆盖率 `≥1−δ` 而尾部覆盖率 `<1−δ`：取 `P = (1−ε)P_tail + εP_easy`，在 `P_easy` 上过度覆盖、在 `P_tail` 上欠覆盖即可。因此「平均覆盖达标」不构成碰撞证据；证书必须使用尾部条件覆盖或极值理论分位数。系：**平均指标是碰撞审计的伪证据——这正是增强最容易伪造的量。**

**引理 42（反事实增强的自证不可能性）** 设反事实标签由模型 `M` 生成，且 CCG 中相应边 non-identified。则对 `M` 的误差参数 `θ_M`，`I(θ_M; α_M(D)) = I(θ_M; D)`——模型自生成的反事实没有带来关于模型误差的新信息；把它计入 `D_cert` 只会降低留出误差的估计，而不降低真实尾部风险。故其证据权重必须为 `w=0`（仅可进 `D_train`）。系：**近失数据必须先通过因果可识别性，才配称为证据。**

**定理 30（AEGIS 严格包含）** 取 `stub_col`（`B_col≡+∞`、不否决）、空增强账本、`T_δ=∅`、`w≡0`，则 AEGIS 逐指令退化为 R73 MODGAUGE；再退化等于 R72/R71/R68。安全侧只增不减（新增的 `B_col≥0` 是额外合取项，不是替代项）。

**定理 31（认证碰撞避免）** 若 `Valid(J_AEGIS)`，则
`P(collision) ≤ δ + ε_tail + ε_assump`，
其中 `ε_tail` 为尾部估计误差（由 `ESS_tail` 与尾部 conformal 校准给出），`ε_assump` 为假设在尾部的违反质量（由 AAC 的尾部检验上界）。等号在 `κ` 精确、CCG 完全识别、假设零违反时取到 `δ`。证明由引理 40 + 引理 41 + AAC 六条 + 并集界。**证明重量落在尾部交换性与 κ 的 Lipschitz 上界上。**

**定理 32（增强不可洗白）** 若某流水线在无新增独立真实样本、且未披露尾部有效假设的情况下，使认证不确定度下降 `Δ>0`，则存在覆盖洗白缺口 `LG > 0`；`SEAL-Tail` 审计以至少 `1−γ` 的概率检出（在溯源完整时可确定性检出）。系：**改善碰撞证书只有两条合法路径——(i) 采到新的真实独立证据；(ii) 披露一个尾部有效、可证伪的假设。不存在第三条。**

**定理 33（碰撞证书的组合非补偿性）** 在 SER/PAR/VETO 组合下，间距预算按**下界**组合：
`B_col(A∘B) ≤ min(B_col,A, B_col,B)`；PAR 只有在跨模态一致性审计通过且独立证据支持时才允许取融合改善，否则取 min；VETO 中任一 `B_col<0` 即整体否决。故任何组合路径都不可能把一次负间距「平均掉」。系：**这是碰撞语义与 R73 标量不确定度代数的关键差异：u 可以并联缩小，间距的下界不能靠并联无证据地抬升。**

## 6. 本轮最大风险

**一句话**：AEGIS 把碰撞避免的成败押在**尾部间距预算的校准**上，而尾部恰是样本最少、`κ` 最难验证、尾部分位数最难估的地方——如果尾部非交换（环境/人/材质漂移）、`κ` 的 Lipschitz 上界在近场或极端角度失效、或假设账本里的某条「尾部有效」假设本身不可证伪，那么系统会在 `B_col>0`、`J_AEGIS` 有效、增强审计通过的情况下，撞上唯一没有被真实数据覆盖的那类碰撞，而日志会证明每一步都「有账簿、有假设、有签名」。

次级风险与缓解：
1. **κ 的全局化误用** → κ 必须由有效域与几何在线计算，离线只做包络；有效域外用最坏界，禁用解析式。
2. **尾部 ESS 不足** → 证书自动加宽（定义 386/392）+ CTEA 定向采集 + 极值理论保守分位，绝不用合成样本补 ESS。
3. **假设账本不可证伪/被滥用** → 每条假设必须有预注册证伪测试与失效判据；AAC 只接受可测假设，不可测假设一律 w=0。
4. **CCG 结构错误导致反事实误判** → CCG 版本化 + 干预实验（do-calculus）+ non-identified 边保守化，禁止点估计。
5. **增强洗白变得更隐蔽（条件洗白）** → 不仅查平均覆盖，还查**分层尾部覆盖**与 provenance 独立性；`SEAL-Tail` 由独立团队采集。
6. **MRM 本身不安全**（急停导致后车/失稳）→ MRM 也必须过 `B_col` 与动力学可达集校验；保留多条回退轨迹并选最大间距者。
7. **C4/C5 主张重叠导致归因不清** → 联合归因树：C4 只认间距账本，C5 只认「同一账本下增强 vs 真实采集」的差；E407 用 2×2 设计隔离。
8. **MB4/MB5 过拟合** → 密封尾部集 + 预注册 + 三方复现（E408），主张只认预注册尾部指标。

| `SMS, T_δ = {B_col ≤ q_δ}` | 间距谱与碰撞尾部集合 |
| `id(e) ∈ {identified,bounded,non-identified}` | CCG 边可识别性；non-identified 禁用点估计 |
| `α = (φ, A_φ, L_φ)` | 增强算子：变换 / 假设集 / 信息账本 |
| `L_φ = (ESS, prov, Δout, tail, conflict)` | 有效样本量 / 独立溯源 / 合同外变化 / 尾部有效性 / 冲突 |
| `w(α) ∈ [0,1]` | 证据权重：真实=1，假设背书∈(0,1)，模型反事实=0 |
| `D_cert = {真实独立} ∪ {α(D): Admissible ∧ w>0}` | 认证集；SEAL 只用它 |
| `ESS_tail = (Σr)²/Σr²` | 尾部位移下有效样本量；不足则证书加宽 |
| `J_AEGIS = J_MOD ⊗ J_col ⊗ J_aug` | 组合证书：模块 ⊗ 间距/CCG ⊗ 增强账本 |
| `MB4 / MB5` | 碰撞尾部 / 增强审计 最小基准 |
| `stub_col = (B_col≡+∞, 不否决, χ_R 平凡)` | 碰撞模块失效语义 ⇒ 实际执行 MRM，禁止「继续运动」 |

## 2. 形式化定义（要点版）

**定义 383（五不变式）** 间距非负（含回退）/ 账簿可追溯（每税项挂 EC 的 u 字段与 SEAL 校准）/ 增强负债披露（未披露不入 D_cert）/ 尾部审计（平均覆盖不算证据）/ 退化链扩展（碰撞失效 ⇒ MRM，安全只增）。

**定义 384（CEC）** EC 的碰撞特化；`κ_i` 是随状态/动作/有效域变化的间距敏感度，不是全局常数；`T_δ` 为尾部有效域；`I⊥` 含 `COLLISION`。

**定义 385（SBA）** `B_col = d_clear − (r_0 + Σ κ_i û_i)`；证书 = `B_col≥0 ∧ CCG 可识别/有界 ∧ AAC 可采信`；递归要求 `∀x′∈Reach_H: B_col(x′)≥0`。

**定义 386（SMS/尾部）** 证书 = 尾部下分位 ≥0 + 尾部覆盖 ≥1−δ + `ESS_tail≥n_min`；不足则加宽 δ，不得缩窄。

**定义 387（CCG）** 证据→几何→间距→动作→碰撞的机制图；边可识别性三态；non-identified 边取有效域最坏值；碰撞证书要求「证据→间距→动作」路径无未处理 non-identified 边。

**定义 388（增强账本）** `α=(φ,A_φ,L_φ)`；`A_φ` 每条假设带证伪测试与有效区域；`L_φ` 记录 ESS、溯源、声称的 Δout、尾部有效性、冲突。

**定义 389（AAC 六条）** 域保持 / 标签等变 / 假设可证伪 / 溯源完整 / 覆盖诚实（`|coverage_cert−coverage_audit|≤β`，无独立样本不得声称 Δout<0）/ 尾部有效（`A_φ` 有效域 ⊇ `T_δ`）。全部通过 ⇒ 入 `D_cert`；否则只入 `D_train`。

**定义 390（AAP）** 串联 ESS≤min、假设并集+冲突检测；并联相关性未知取 ESS≤min；尾部不相容则降级 `D_train`。可采信性对组合封闭当且仅当假设一致且尾部有效保持。

**定义 391（证据权重）** 真实=1；假设背书且尾部有效按 ESS/溯源折减∈(0,1)；模型依赖反事实=0。SEAL 只用 `D_cert` 并加权。

**定义 392（尾部位移）** 密度比重加权；`ESS_tail<n_min` ⇒ 加宽 δ；禁止用增强样本补 ESS（不是同一随机变量）。

**定义 393（CTEA）** `LCB(B_col)<τ_col` 或 `ESS_tail<n_min` ⇒ 定向真实采集/主动感知/近失挖掘；受 REG 约束；合成数据不得替代真实尾部。

**定义 394（CCS）** 1kHz 对候选与刹车回退双检 `B_col≥0`；回退含最坏障碍运动界；输出经 `certified_prefix`；回退不可行 ⇒ MRM。

**定义 395（J_AEGIS）** `J_AEGIS=J_MOD⊗J_col⊗J_aug`；`J_col` 校验 SBA/CCG/SMS 尾部；`J_aug` 校验 AAC 六条与账本闭合；`Valid(J_AEGIS)⇒Valid(J_MOD)`。

**定义 396（MB4/MB5）** MB4：碰撞尾部（近接触抓取 / 人机共处 / 动态障碍 / 真实近失 + 受控注入）；MB5：增强审计（真实采集 vs 各类增强 vs 洗白攻击）。各 ≤3h 单卡，`SEAL-Tail` 密封。

**定义 397（结构上限）** 新增 `|κ项|≤6`、`H≤1.5s`、`|V_C|≤16`、`账本深度≤4`、`D_cert 增强比例≤ρ_cert(默认0.3)`——可审计图/账本性质。

**定义 398（严格包含）** 取 `stub_col`、空账本、`T_δ=∅`、`w≡0` ⇒ 逐指令退化为 R73 MODGAUGE，再退化为 R72/R71/R68。

```python
# IP-303 CEM/SBA：间距预算（计量 50Hz）
class CollisionEvidenceMetrology:
    def separation_budget(self, x, a, ev):
        O = self.obstacle_from_evidence(ev)
        d = self.geometry.clearance(x, a, O)
        tax, items = self.hard_margin, []
        for i, u in ev.u_components.items():
            kappa = self.sensitivity.kappa(i, x, a, ev)     # 有效域内在线计算
            ub    = self.seal.upper_bound(i, ev, ev.delta[i])
            items.append(TaxItem(i, kappa, ub, ev.trace[i]))  # 逐项追溯
            tax += kappa * ub
        B = d - tax
        return SeparationEvidence(B=B, d=d, tax=tax, items=items,
                                  tail_ok=self.tail_probe(B))

# IP-304 CCG：碰撞因果证书（non-identified → 最坏值）
def ccg_certificate(ccg, ev, action):
    for e in ccg.path('evidence', 'separation'):
        if ccg.id(e) == 'non-identified':
            ev = ccg.worst_case(ev, e)                        # 禁点估计
    if any(ccg.id(e) == 'non-identified'
           for e in ccg.path('separation', 'action')):
        return Certificate(False, why='CCG_GAP')
    return Certificate(True, evidence=ev, ccg=ccg)

# IP-305 AAC：六条可采信性
def admissible(alpha, T_delta, seal_tail):
    return (alpha.domain_preserving() and alpha.label_equivariant()
            and alpha.assumptions_falsifiable()
            and alpha.ledger.provenance_complete()
            and alpha.ledger.coverage_gap(seal_tail) <= BETA
            and alpha.validity_region() >= T_delta)

def route(alpha, T_delta, seal_tail):
    if admissible(alpha, T_delta, seal_tail):
        return 'D_cert', alpha.ledger.evidential_weight()      # ∈(0,1]
    return 'D_train', 0.0                                      # 非证据

# IP-306 AAP：增强代数（信息不增）
def compose_aug(a1, a2, op):
    if op == 'SER':
        if not consistent(a1.assumptions | a2.assumptions):
            return Augmentation(phi=..., tag='D_train')
        ess = min(a1.ledger.ess, a2.ledger.ess)
        return Augmentation(phi=lambda s: a2.phi(a1.phi(s)),
                            assumptions=a1.assumptions | a2.assumptions,
                            ledger=Ledger(ess=ess, ...))
    if op == 'PAR':
        ess = min(a1.ledger.ess, a2.ledger.ess)                # 相关性未知→保守
        return Augmentation(phi=mix(a1, a2), ledger=Ledger(ess=ess, ...))
    return Augmentation(phi=..., tag='D_train')

# IP-307 CTEA：碰撞触发真实采集
def collision_triggered_acquisition(B_lcb, ess_tail, sched, budget):
    if B_lcb >= TAU_COL and ess_tail >= N_MIN:
        return None
    plan = sched.propose_real_collection(tail_gap(B_lcb, ess_tail))
    return plan if (plan.reg_ok and plan.cost <= budget) else 'MRM'

# IP-308 CCS：认证碰撞屏障（控制 1kHz，只读快照）
def certified_collision_shield(snap, candidates, fallback):
    if snap.B_col[fallback] < 0: return fallback, 'MRM'
    for a in candidates:
        if snap.B_col[a] >= 0 and snap.ccg_ok[a]:
            return a, 'CERTIFIED'
    return fallback, 'FALLBACK'

# IP-309 AEGIS 主闭环
def AEGIS_round(M, x, depth_img, tac_frame):
    d_ev = M.dpem.update(depth_img, ...)                       # DPEM†
    t_ev = M.dmem.update(tac_frame, ...)                       # DMEM†
    s_ev = M.cem.separation_budget(x, M.last_a, merge(d_ev, t_ev))
    if not M.ccg.certificate(s_ev).valid: s_ev = stub_col()    # 因果断链→MRM
    if s_ev.B < M.tau_col: M.ctea.request(...)                 # 碰撞触发采集
    a = M.ccs.select(s_ev, M.planner.candidates(x))            # 认证屏障
    M.aug.audit(M.d_cert, M.seal_tail)                         # 增强尾部审计
    return a, J_AEGIS(M.mreg, s_ev, M.aug.ledger)
```

## 4. 推导

**引理 38（增强 DPI / 没有免费的信息）** `I(θ;α(D)) ≤ I(θ;D)`。故 `ΔRisk = ΔRisk_info(≤0) + ΔRisk_assumption(A_α)`；无新增独立样本且无显式假设却声称风险下降 ⇒ 覆盖洗白。系：**增强是假设的载体，不是信息的来源。**

**引理 39（无免费间距）** `r_cert` 对 `û_i,κ_i` 单调；可采信 α 只在假设有效域内收缩 `û_i`，且 `Δr_cert ≥ −Σκ_i Δû_i^{ind}`。系：**增强降不了已认证的间距税，除非为假设付息。**

**引理 40（递归安全性）** `B_col≥0` 且 `∀x′∈Reach_H: B_col(x′)≥0` ⇒ 膨胀集不交障碍集 ⇒ 无碰撞（延迟已入 r_act）。系：**碰撞证书是集合不相交的几何命题，不是期望命题。**

**引理 41（尾部≠平均）** 存在混合分布使平均覆盖 ≥1−δ 而尾部覆盖 <1−δ。系：**平均覆盖是碰撞审计的伪证据，恰是增强最易伪造的量。**

**引理 42（反事实自证不可能）** 模型 M 生成的反事实在 CCG non-identified 边上不增加关于 M 误差的信息（`I(θ_M;α_M(D))=I(θ_M;D)`）⇒ `w=0`，只能训练。系：**近失数据先过因果可识别性，才配称为证据。**

**定理 30（AEGIS 严格包含）** 取 `stub_col`、空账本、`T_δ=∅`、`w≡0` ⇒ 逐指令退化为 R73；再退化 R72/R71/R68。安全侧只增不减。

**定理 31（认证碰撞避免）** `Valid(J_AEGIS) ⇒ P(collision) ≤ δ + ε_tail + ε_assump`，其中 `ε_tail` 由尾部 conformal 与 `ESS_tail` 给出，`ε_assump` 为假设尾部违反质量。证明由引理 40/41 + AAC + 并集界。**重量落在尾部交换性与 κ 的 Lipschitz 上界。**

**定理 32（增强不可洗白）** 无新增独立真实样本、无尾部有效假设却使认证不确定度下降 ⇒ `LG>0`；`SEAL-Tail` 以 ≥1−γ 检出（溯源完整时确定性检出）。系：**改善碰撞证书只有两条路：真实证据，或尾部有效的可证伪假设。**

**定理 33（组合非补偿性）** `B_col(A∘B) ≤ min(B_col,A,B_col,B)`；PAR 仅在一致性审计+独立证据支持时允许融合改善，否则 min；VETO 任一负即否决。系：**u 可以并联缩小，间距下界不能无证据抬升。**

## 7. 本轮最大风险

**一句话**：AEGIS 把碰撞避免的成败押在**尾部间距预算的校准**上，而尾部恰是样本最少、`κ` 最难验证、尾部分位数最难估的地方——若尾部非交换、`κ` 的 Lipschitz 上界在近场/极端角度失效、或假设账本中「尾部有效」本身不可证伪，那么系统会在 `B_col>0`、`J_AEGIS` 有效、增强审计全部通过的情况下，撞上唯一没有被真实数据覆盖的那类碰撞，而日志会证明每一步都「有账簿、有假设、有签名」。

次级风险与缓解：
1. **κ 全局化误用** → κ 在线按有效域计算，离线只做包络；域外用最坏界。
2. **尾部 ESS 不足** → 自动加宽 δ + CTEA 定向采集 + EVT 保守分位，绝不用合成补 ESS。
3. **假设不可证伪/被滥用** → 每条假设预注册证伪测试；不可测假设一律 w=0。
4. **CCG 结构错误** → 版本化 + 干预实验 + non-identified 边保守化。
5. **条件洗白更隐蔽** → 查分层尾部覆盖与 provenance 独立性；`SEAL-Tail` 独立采集。
6. **MRM 本身不安全** → MRM 也过 `B_col` 与可达集校验，多条回退取最大间距。
7. **C4/C5 归因重叠** → E407 用 2×2 设计 + 联合归因树隔离。
8. **MB4/MB5 过拟合** → 密封尾部集 + 预注册 + 三方复现（E408），只认预注册尾部指标。
