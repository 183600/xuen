# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；新一轮灵感循环第 1 轮；本轮灵感：「碰撞检测」×「激光雷达」）

> 第 60 轮把「场景→意图→约束→阻抗→执行→EV-exec→场景」串成了 SGEC 闭环，并用 EPIR 处理了 ROS 消息的乱序/丢失。但它仍有一个**从未被挑战的方向性假设**：闭环是「接触后」的——EV-exec 依赖力/位遥测，碰撞或接触已经发生，系统才获得证据，本质上仍是「先失败、后回退」。由此暴露三个结构性缺口：
> 1. **安全证明的时序错位**：第 60 轮的 SIC 三元校验与 K_safe 收敛都发生在「接触后」，只能在失败后收窄阻抗，缺失**接触前的可证安全边界**。碰撞检测若只做「发生/未发生」的布尔判定，就永远是事后报警器。
> 2. **场景识别的接触式偏置**：SSM 用力的频谱、位置抖动推断场景，属于「摸出来」的场景；对桌面边缘、悬空线缆、玻璃隔板这类**几何先验强、接触信号弱**的障碍，力觉后知后觉，LiDAR 本可提前看见。
> 3. **证据层的标量/事件化**：第 60 轮的 EV-exec 是标量事件（力、位、D⁺），无法表达「未来 H 步内某条轨迹的扫掠体与障碍的最小距离」这类**几何连续命题**；没有几何证据，就无法在动作下发前给出「无碰撞证书」。
>
> 一句话先给押注：
>
> **第 60 轮解决「接触后如何用证据修正执行」；本轮把它前移为「接触前如何用几何证据证明安全」——提出预接触安全闭环 PCSL：用激光雷达构造带不确定性的几何证据层 GEL，用扫掠体 + 距离场 Lipschitz 界给出连续碰撞证书 CCC，用碰撞风险场 CRF 把几何风险映射为阻抗/速度约束，用几何-接触对账 GCR 把「看见的」与「摸到的」缝合，最后用碰撞安全证书 CSC 把几何无碰撞证明绑进执行证书。核心命题：安全不是碰撞后的补丁，而是碰撞前可审计的几何证明；未知空间必须按占据处理，几何与接触必须互相对账。**

## 0. 直觉与动机

**灵感 1（碰撞检测 → 从「碰撞布尔」到「连续碰撞证书」CCC）**
直觉：传统碰撞检测像烟雾报警器，火烧起来才响；离散碰撞检测更像「隔一段路才摸一次墙」，两个采样点之间若恰好穿过一根细杆或一片薄玻璃，采样点都在自由空间，系统会**隧穿（tunneling）**并自信地撞上去。我们要的是「安全距离场 + 扫掠体连续检测」：在轨迹执行前就证明「未来 H 步内扫掠体到障碍的最小距离 ≥ ε_col」，并把这份证明变成可审计的证书。关键洞见：**只要距离场是 Lipschitz 的、采样步长满足 ‖Δξ‖ ≤ ε_col/L_d，离散采样就能覆盖连续轨迹**——连续性不是靠加密采样「碰运气」，而是靠一个可证的界。

**灵感 2（激光雷达 → 三态几何证据层 GEL）**
直觉：LiDAR 给出的是「几何目击证词」，但证词有盲区：遮挡背后、玻璃/镜面、深色细线、稀疏远点都可能「没扫到」。**「没扫到」绝不能等于「自由空间」**。关键洞见：把点云压成占据场，并显式区分 `observed-free / observed-occupied / unknown` 三态；安全计算一律使用保守占据 `O⁺ = O ∪ U`（unknown-as-occupied）。碰撞检测的保守性不是靠调大阈值，而是靠**三态语义 + 未知即占据**这条铁律。

**灵感 3（合流 → 预接触安全闭环 PCSL）**
直觉：第 60 轮的闭环在「接触后」闭合（力/位→EV-exec→场景更新），先失败后回退。LiDAR 让闭环前移：几何→距离场→碰撞风险→在接触前收窄 K_safe 与 v_max→执行→接触证据→几何-接触对账→反哺占据场。关键洞见：**把「阻抗安全」拆成「几何安全」与「接触安全」两级**——几何层负责「别撞上」，接触层负责「撞上了也别坏」，两级通过同一张证书绑定。

**灵感 4（风险预算 → 碰撞-几何预算 PCE+++++++）**
直觉：几何安全不是免费的：LiDAR 处理算力、点云带宽、占据更新频率、安全裕度、风险容忍都是稀缺资源。把第 60 轮的四维预算扩为**六维碰撞-几何预算** `B_cog⁺⁺ = (B_scene, B_intent, B_ros, B_exec, B_col, B_geo)`。降级铁律不变：**任何一维耗尽只收缩安全集与证书置信，绝不把 unknown 当 free、绝不扩大可行动作集**。

**灵感 5（证书 → 碰撞安全证书 CSC + 几何-接触对账 GCR）**
直觉：一张「无碰撞证书」若只由几何单独签发，就会重演「证据层高度确定、执行层灾难性失效」的抽象泄漏。必须让几何与接触**互相作证**：预测「不碰」却碰到 = `phantom_free`（假自由），预测「要碰」却没碰 = `ghost_collision`（假障碍）。关键洞见：**对账不是为了判谁对，而是为了立刻更新占据场并降置信**——`phantom_free` 必须把该体素永久标为占据并安全停，而不是「再采样看看」。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（几何证据层 GEL）** 给定 LiDAR 点云序列 P_{1:t} 与位姿 T_t，几何证据 `EV-geo = (H_cloud, t, O, F, U, σ_geo, T)`。其中：
- **三态占据**：对体素 v，`O(v) ∈ [0,1]`（占据后验）、`F(v) ∈ [0,1]`（观测自由后验）、`U(v) = 1 − O(v) − F(v)`（未知），满足 `O+F+U = 1`；用 log-odds 射线更新：命中体素 `l ← l + l_hit`，射线穿过体素 `l ← l + l_miss`（`l_miss<0`）。
- **保守占据**：`O⁺(v) = 1` 若 `O(v) + U(v) ≥ τ_occ`，否则 `0`；即「未知即占据」的阈值化。
- **自由置信**：`conf_free(v) = F(v) / (F(v) + U(v) + 1e-9)`；只有 `conf_free ≥ τ_free` 才允许把 v 视为自由。
- **几何不确定性**：`σ_geo(v) = f(点密度, 入射角, 反射率, 测距, 运动畸变)`，用于膨胀 `O⁺` 与给证书降置信。
- **证据摘要**：EV-geo 不传原始点云，而传 `(O⁺ 的体素集合, hash, 时间戳, 位姿, σ_geo 上界)`，以控制 B_geo 带宽；原始点云仅在本地影子区保留。
- **新鲜度**：`age(EV-geo) = t_now − t`；`age > T_geo` 时 `O⁺` 按 `σ_geo·age` 膨胀。

**定义 162（连续碰撞证书 CCC）** 给定轨迹 `ξ:[0,T]→SE(3)`、机器人几何体 `R(ξ(t))`、保守占据集 `O⁺`、安全裕度 `ε_col>0`：
- **扫掠体**：`S(ξ) = ⋃_{t∈[0,T]} R(ξ(t))`。
- **距离场**：`d_{O⁺}(x) = min_{v∈O⁺} ‖x − center(v)‖ − r_v`（到最近保守占据体素表面的有符号距离）。
- **连续无碰撞谓词**：`CCFree(ξ, O⁺, ε_col) ⟺ ∀t∈[0,T]: d_{O⁺}(S(ξ(t))) ≥ ε_col`。
- **Lipschitz 无隧穿条件**：设 `|d_{O⁺}(x) − d_{O⁺}(y)| ≤ L_d‖x−y‖`。若采样步长 `δt` 满足 `max_t ‖ξ(t+δt) − ξ(t)‖ ≤ ε_col / L_d`，则「所有采样点均满足 `d ≥ ε_col`」蕴含 `CCFree` 成立（采样覆盖连续轨迹，不隧穿）。
- **证书**：`CCC = (ξ, ε_col, L_d, δt, d_min = min_t d_{O⁺}(S(ξ(t))), hash(O⁺), valid)`；`valid ⟺ CCFree ∧ 无隧穿条件成立`。
- **保守单调性**：`O⁺` 只增不减（对账发现假自由时），故 `CCFree` 一旦失败不可被后续同帧证据「洗白」。

**定义 163（碰撞风险场 CRF）** 对位置 x 与预测相对速度 `ṡ(x)`：
- **风险**：`R_col(x) = exp(−(d_{O⁺}(x) − ε_col)/σ_col) · (1 + λ_TTC · max(0, 1 − TTC(x)/τ_TTC))`，其中 `TTC(x) = d_{O⁺}(x) / max(‖ṡ(x)‖, η)`。
- **单调性**：`R_col` 关于 `d_{O⁺}` 单调不增、关于 `‖ṡ‖` 单调不减。
- **约束映射**：`K_safe^col = {K ∈ K_safe^scene | R_col(K) ≤ R_max}`；`v_max^col = v_nom · (1 − min(1, R_col))`。
- **斥力项（可选）**：`F_rep = −k_rep · ∇_x R_col`，作为阻抗控制器的几何前馈，使「看见障碍就提前让开」而非「碰到才后退」。

**定义 164（预接触安全闭环 PCSL）** 算子 `PCSL(M, task, δ_f_req)`：
```
① GEL:    P_t, T_t → 更新 O, F, U；O⁺ ← threshold(O + U)；EV-geo
② SDF:    d_{O⁺}, ∇d_{O⁺}（局部近邻体素）
③ CCC:    对候选轨迹集 Ξ 做连续无碰撞检测 → CCC(ξ)，筛掉 valid=false
④ CRF:    R_col, TTC → 收窄 K_safe^col 与 v_max^col
⑤ SSM:    第 60 轮场景先验 π_scene(K|z) → K_safe^scene（接触前先验）
⑥ Compile: K_safe ← EEIS.compile(δ_f_req, fused, ξ_exec, Z_env, K_safe^scene ∩ K_safe^col)
⑦ Dispatch: 下发 K_safe.best + v_max^col + Cert(CSC)
⑧ Execute: 执行并按块采集 EV-exec（力/位）
⑨ GCR:    几何预测接触 vs 接触实测 → phantom_free / ghost_collision / consistent
⑩ Update: phantom_free ⇒ O⁺(v)←1、安全停；ghost_collision ⇒ σ_geo↑、ε_col 放宽（有界）
⑪ Return: (K_safe, CCC, EV-exec, CSC, GEL.status)
```

**定义 165（六维碰撞-几何预算 PCE+++++++）** `B_cog⁺⁺ = (B_scene, B_intent, B_ros, B_exec, B_col, B_geo)`：
- `B_col = (R_max, ε_col, τ_TTC, T_geo)`：风险容忍、安全裕度、TTC 阈值、几何证据新鲜度。
- `B_geo = (LiDAR_fps, Cloud_bandwidth, Occupancy_update_rate, Voxel_resolution)`。
- **VOI**：`voi⁺⁺(π) = VOI_meta(π) − cost_cog − cost_exec − cost_col − cost_geo`，其中 `cost_col = λ_risk·max(0, R_col−R_max) + λ_margin·(1/ε_col)`，`cost_geo = λ_bw·Cloud_bw + λ_occ·Occ_update + λ_lat·LiDAR_latency`。
- **降级阶梯**：`B_geo` 耗尽 → 体素膨胀/降频/复用上一帧 `O⁺`（带 `σ_geo·age` 膨胀），**绝不把 unknown 当 free**；`B_col` 耗尽 → `ε_col↑`、`v_max↓`，最后安全停；`B_scene/B_intent/B_ros/B_exec` 沿用第 60 轮策略。

**定义 166（碰撞安全证书 CSC）** `CSC = (CCC, R_col_max, unknown_fraction, σ_geo_max, GCR_status, valid)`：
- `unknown_fraction = |U ∩ S(ξ)| / |S(ξ)|`。
- **有效性**：`Valid(CSC) ⟺ CCC.valid ∧ R_col_max ≤ R_max ∧ unknown_fraction ≤ τ_unknown ∧ GCR_status ≠ phantom_free`。
- **组合性**：CSC 与第 60 轮的 `J_exec` 通过 `(task_id, episode, chain_root)` 绑定；几何证书与接触证书必须同时有效，执行证书才有效（fail-closed）。
- **不可伪造性**：`hash(O⁺)` 与 `chain_root` 绑定时间戳与位姿，跨帧重放的旧占据场无法通过新鲜度检查。

**定义 167（未知空间保守性原理 USCP）** 对任意安全计算 `f ∈ {CCC, CRF, CSC}`：
- **保守替换**：`f(O, F, U) := f(O⁺)`，其中 `O⁺` 按「unknown-as-occupied」阈值化。
- **不可逆性**：对账确认的占据体素永久加入 `O`，不因后续「没扫到」而回退为 free（除非显式物理移除事件）。
- **声明的安全边界**：`Safe(ξ) ⟺ CCC.valid(O⁺)`；系统绝不在 `O`（仅观测占据）上签发证书，避免把盲区当自由。

**定义 168（几何-接触对账 GCR）** 给定几何预测 `(d_pred, x_pred)` 与接触实测 `(F_contact, x_contact)`：
- **残差**：`r_gc = |d_pred − d_actual|`，其中 `d_actual = 0` 若 `F_contact > F_thr`。
- **对账状态**：
  - `phantom_free`：`d_pred > ε_col` 且 `F_contact > F_thr`（预测不碰却碰了）；
  - `ghost_collision`：`d_pred ≤ ε_col` 且 `F_contact ≤ F_thr`（预测要碰却没碰）；
  - `consistent`：其余。
- **自愈**：`phantom_free ⇒ O⁺(x_contact) ← 1`，`GCR_status=phantom_free`，CSC 立即失效并安全停；`ghost_collision ⇒ σ_geo ← σ_geo·(1+γ)`（有界），`ε_col ← min(ε_col·(1+γ), ε_max)`，避免过度保守长期锁死任务。

### IP-161 GEL（三态几何证据层）
```python
class GeometricEvidenceLayer:
    def __init__(self, res=0.02, l_hit=0.85, l_miss=-0.4,
                 tau_occ=0.5, tau_free=0.9, t_geo=0.5):
        self.res, self.l_hit, self.l_miss = res, l_hit, l_miss
        self.tau_occ, self.tau_free, self.t_geo = tau_occ, tau_free, t_geo
        self.logodds = {}                 # voxel -> log-odds
        self.locked_occ = set()           # GCR 确认的永久占据

    def integrate(self, cloud, pose, t_now):
        free, hit = set(), set()
        for ray in cast_rays(cloud, pose):
            for v in ray.traversed_voxels():
                if v not in hit:
                    free.add(v)
            hit.add(ray.endpoint_voxel())
        for v in free:
            self.logodds[v] = self.logodds.get(v, 0.0) + self.l_miss
        for v in hit:
            self.logodds[v] = self.logodds.get(v, 0.0) + self.l_hit
        O, F, U = set(), set(), set()
        for v, l in self.logodds.items():
            p = 1.0 / (1.0 + math.exp(-l))
            (O if p >= self.tau_occ else F if p <= 1 - self.tau_free else U).add(v)
        O |= self.locked_occ
        # unknown-as-occupied：U 一律并入保守占据
        O_plus = O | U
        return EVGeo(hash=sha256(serialize(sorted(O_plus))),
                     t=t_now, pose=pose, O=O, F=F, U=U,
                     O_plus=O_plus, sigma=self._sigma_bound(cloud))

    def mark_phantom(self, voxel):
        self.locked_occ.add(voxel)        # 不可逆：假自由 → 永久占据
```

### IP-162 CCC（连续碰撞证书）
```python
def continuous_collision_certificate(traj, O_plus, robot, eps_col, L_d):
    v_max = max_speed(traj)
    dt = eps_col / (L_d * v_max + 1e-9)        # Lipschitz 无隧穿步长
    t, d_min, valid = 0.0, float('inf'), True
    while t <= traj.T + 1e-12:
        S = robot.swept_volume(traj, t, min(dt, traj.T - t))
        d = sdf_min(S, O_plus)                # 到保守占据集的最小距离
        d_min = min(d_min, d)
        if d < eps_col:
            valid = False
            break
        t += dt
    return CCC(traj=traj, eps_col=eps_col, L_d=L_d, dt=dt,
               d_min=d_min, hash_O=hash_set(O_plus), valid=valid)
```

### IP-163 CRF（碰撞风险场 → 阻抗/速度约束）
```python
def collision_risk(d, eps_col, sigma_col, speed, tau_ttc, lam=0.5, eta=1e-6):
    ttc = d / max(speed, eta)
    return math.exp(-(d - eps_col) / sigma_col) * \
           (1.0 + lam * max(0.0, 1.0 - ttc / tau_ttc))

def constrain_by_geometry(K_safe_scene, R_col, R_max, v_nom):
    if R_col > R_max:
        return None, 0.0                      # 触发收缩/安全停
    K_col = [K for K in K_safe_scene if risk_of(K) <= R_max]
    v_max = v_nom * (1.0 - min(1.0, R_col))
    return K_col, v_max

def geometric_repulsion(d, k_rep=0.1, d0=0.1):
    return -k_rep * (1.0 / max(d, 1e-3) - 1.0 / d0) if d < d0 else 0.0
```

### IP-164 PCSL（预接触安全闭环）
```python
def pre_contact_safety_loop(M, task, delta_f_req):
    # ① 几何证据
    ev_geo = M.gel.integrate(M.lidar.latest_cloud, M.tf.lidar_pose(), time.time())
    # ②③ 连续碰撞检测
    feasible = []
    for xi in M.planner.candidates(task):
        ccc = continuous_collision_certificate(
            xi, ev_geo.O_plus, M.robot, M.b_col.eps_col, M.b_col.L_d)
        if ccc.valid:
            feasible.append((xi, ccc))
    if not feasible:
        return safe_stop(M, reason='NO_CCFREE_TRAJECTORY')
    xi, ccc = min(feasible, key=lambda p: p[1].d_min * -1)  # 取裕度最大
    # ④ 风险场
    d = sdf_min(M.robot.at(xi.start), ev_geo.O_plus)
    R = collision_risk(d, M.b_col.eps_col, M.b_col.sigma_col,
                       xi.speed0, M.b_col.tau_ttc)
    # ⑤⑥ 场景先验 ∩ 几何约束
    K_scene = M.eeis.compile_with_scene_prior(
        M.scene_model.get_scene_impedance_prior(), delta_f_req)
    K_col, v_max = constrain_by_geometry(K_scene, R, M.b_col.R_max, task.v_nom)
    if K_col is None:
        return safe_stop(M, reason='COLLISION_RISK')
    K_safe = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.env,
                            allowed=K_col, v_max=v_max)
    # ⑦⑧ 执行 + 接触证据
    ev_exec = M.execute(xi, K_safe, v_max)
    # ⑨⑩ 几何-接触对账
    status = M.gcr.reconcile(ev_geo, ev_exec)
    if status == 'phantom_free':
        M.gel.mark_phantom(ev_exec.contact_voxel)
        return safe_stop(M, reason='PHANTOM_FREE', ev=ev_exec)
    if status == 'ghost_collision':
        M.b_col.widen_margin(gamma=0.1, eps_max=M.b_col.eps_max)
    csc = CSC(ccc=ccc, R_col_max=R, unknown_fraction=unknown_frac(ccc, ev_geo),
              sigma_geo_max=ev_geo.sigma, GCR_status=status,
              valid=ccc.valid and R <= M.b_col.R_max and status != 'phantom_free')
    return K_safe, ccc, ev_exec, csc
```

### IP-165 PCE+++++++（六维碰撞-几何预算）

**正确性定理（PCSL / 几何-接触安全定理）**：
假设 A22–A65 与第 60 轮假设成立；新增：**(A66)** 距离场满足 Lipschitz 常数 `L_d`，采样步长满足 `‖Δξ‖ ≤ ε_col/L_d`；**(A67)** GEL 的 log-odds 更新对命中/穿过事件可靠，`O⁺` 采用 unknown-as-occupied；**(A68)** LiDAR 位姿与时间戳对齐误差 ≤ δ_T；**(A69)** GCR 的接触检测阈值 `F_thr` 与几何预测使用同一坐标系；**(A70)** 预算单调消耗且降级只收缩安全集。则：

1. **无隧穿（CCC）**：若 `L_d` 与 `δt` 满足条件且所有采样点 `d ≥ ε_col`，则 `CCFree(ξ)` 成立——不存在「采样点自由、轨迹中间穿障」的路径。
2. **保守安全（USCP）**：由于安全计算一律基于 `O⁺ = O ∪ U`，任何未知体素都被视为占据，故证书绝不会把盲区签成自由；`O⁺` 单调不减保证证书不会被后续同帧证据「洗白」。
3. **风险单调（CRF）**：`R_col` 关于 `d_{O⁺}` 单调不增、关于速度单调不减，故收窄 `K_safe^col` 与 `v_max^col` 只会缩小可行动作集，不会引入新的危险动作。
4. **对账自愈（GCR）**：`phantom_free` 触发该体素永久占据与安全停，`ghost_collision` 只在有界范围内放宽 `ε_col`；因此「几何自信地错」会在一个接触事件内被纠正，而不是持续放大。
5. **证书组合（CSC）**：`Valid(CSC)` 要求 `CCC.valid ∧ R_col ≤ R_max ∧ unknown_fraction ≤ τ_unknown ∧ GCR_status ≠ phantom_free`；与 `J_exec` 通过 `chain_root` 绑定，任一缺失即 fail-closed。
6. **预算安全（PCE+++++++）**：`B_geo/B_col` 耗尽只触发体素膨胀、降速或安全停，**绝不把 unknown 当 free、绝不扩大安全集**。

```python
class GeometricEvidenceLayer:
    def __init__(self, res=0.02, l_hit=0.85, l_miss=-0.4,
                 tau_occ=0.5, tau_free=0.9, t_geo=0.5):
        self.res, self.l_hit, self.l_miss = res, l_hit, l_miss
        self.tau_occ, self.tau_free, self.t_geo = tau_occ, tau_free, t_geo
        self.logodds = {}; self.locked_occ = set()

    def integrate(self, cloud, pose, t_now):
        free, hit = set(), set()
        for ray in cast_rays(cloud, pose):
            for v in ray.traversed_voxels():
                if v not in hit: free.add(v)
            hit.add(ray.endpoint_voxel())
        for v in free:
            self.logodds[v] = self.logodds.get(v, 0.0) + self.l_miss
        for v in hit:
            self.logodds[v] = self.logodds.get(v, 0.0) + self.l_hit
        O, F, U = set(), set(), set()
        for v, l in self.logodds.items():
            p = 1.0 / (1.0 + math.exp(-l))
            (O if p >= self.tau_occ else F if p <= 1 - self.tau_free else U).add(v)
        O |= self.locked_occ
        O_plus = O | U                     # unknown-as-occupied
        return EVGeo(hash=sha256(serialize(sorted(O_plus))), t=t_now, pose=pose,
                     O=O, F=F, U=U, O_plus=O_plus, sigma=self._sigma_bound(cloud))

    def mark_phantom(self, voxel):
        self.locked_occ.add(voxel)         # 不可逆
```

### IP-162 CCC
```python
def continuous_collision_certificate(traj, O_plus, robot, eps_col, L_d):
    v_max = max_speed(traj)
    dt = eps_col / (L_d * v_max + 1e-9)    # Lipschitz 无隧穿步长
    t, d_min, valid = 0.0, float('inf'), True
    while t <= traj.T + 1e-12:
        S = robot.swept_volume(traj, t, min(dt, traj.T - t))
        d = sdf_min(S, O_plus)
        d_min = min(d_min, d)
        if d < eps_col:
            valid = False; break
        t += dt
    return CCC(traj=traj, eps_col=eps_col, L_d=L_d, dt=dt,
               d_min=d_min, hash_O=hash_set(O_plus), valid=valid)
```

### IP-163 CRF
```python
def collision_risk(d, eps_col, sigma_col, speed, tau_ttc, lam=0.5, eta=1e-6):
    ttc = d / max(speed, eta)
    return math.exp(-(d - eps_col) / sigma_col) * \
           (1.0 + lam * max(0.0, 1.0 - ttc / tau_ttc))

def constrain_by_geometry(K_safe_scene, R_col, R_max, v_nom):
    if R_col > R_max:
        return None, 0.0                   # 触发收缩/安全停
    K_col = [K for K in K_safe_scene if risk_of(K) <= R_max]
    return K_col, v_nom * (1.0 - min(1.0, R_col))
```

```python
def pre_contact_safety_loop(M, task, delta_f_req):
    ev_geo = M.gel.integrate(M.lidar.latest_cloud, M.tf.lidar_pose(), time.time())
    feasible = []
    for xi in M.planner.candidates(task):
        ccc = continuous_collision_certificate(
            xi, ev_geo.O_plus, M.robot, M.b_col.eps_col, M.b_col.L_d)
        if ccc.valid:
            feasible.append((xi, ccc))
    if not feasible:
        return safe_stop(M, reason='NO_CCFREE_TRAJECTORY')
    xi, ccc = max(feasible, key=lambda p: p[1].d_min)
    d = sdf_min(M.robot.at(xi.start), ev_geo.O_plus)
    R = collision_risk(d, M.b_col.eps_col, M.b_col.sigma_col,
                       xi.speed0, M.b_col.tau_ttc)
    K_scene = M.eeis.compile_with_scene_prior(
        M.scene_model.get_scene_impedance_prior(), delta_f_req)
    K_col, v_max = constrain_by_geometry(K_scene, R, M.b_col.R_max, task.v_nom)
    if K_col is None:
        return safe_stop(M, reason='COLLISION_RISK')
    K_safe = M.eeis.compile(delta_f_req, M.fused, M.xi_exec, M.env,
                            allowed=K_col, v_max=v_max)
    ev_exec = M.execute(xi, K_safe, v_max)
    status = M.gcr.reconcile(ev_geo, ev_exec)
    if status == 'phantom_free':

        return safe_stop(M, reason='PHANTOM_FREE', ev=ev_exec)
    if status == 'ghost_collision':
        M.b_col.widen_margin(gamma=0.1, eps_max=M.b_col.eps_max)
    csc = CSC(ccc=ccc, R_col_max=R, unknown_fraction=unknown_frac(ccc, ev_geo),
              sigma_geo_max=ev_geo.sigma, GCR_status=status,
              valid=ccc.valid and R <= M.b_col.R_max and status != 'phantom_free')
```

1. `L_d` 与 `δt` 满足条件且采样 `d≥ε_col` ⇒ `CCFree(ξ)`，无隧穿。

3. `R_col` 关于 d 单调不增、关于速度单调不减 ⇒ 收窄约束只缩小动作集。
4. `phantom_free` ⇒ 永久占据 + 安全停；`ghost_collision` ⇒ 有界放宽 ⇒ 假自由一接触即被纠正。
5. `Valid(CSC)` 与 `J_exec` 通过 `chain_root` 绑定 ⇒ 几何/接触/执行任一缺失即 fail-closed。
6. `B_geo/B_col` 耗尽 ⇒ 体素膨胀/降速/停，**绝不 unknown→free、绝不扩大安全集**。

## 6. 本轮最大风险

**一句话**：若激光雷达把玻璃、镜面、深色细线或遮挡背后判成「自由空间」，连续碰撞证书又基于这份「假自由」签发 `CCFree`，系统就会自信地撞上一个证据层声称不存在的障碍——这是比第 60 轮更危险的抽象泄漏；必须以「未知即占据（O⁺=O∪U）」「Lipschitz 无隧穿步长」「phantom_free 不可逆占据 + 安全停」「几何-接触对账」四重护栏，确保几何证明永远不超越物理安全。
