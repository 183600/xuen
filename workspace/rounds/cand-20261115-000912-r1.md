# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「故障诊断」×「主动交互」）

> R69 第一次让闭环学会「问」：把不确定性拆成 aleatoric / epistemic，用流匹配策略把歧义显式呈现为多个动作模态，用注视 / 探针 / 问句去消解，并用流似然给出一条标定不可吸收的第二意见。它的提问对象是**世界与意图**——「我该选哪个动作模态」「对方想要什么」。
>
> 但 R69 的故障处理仍然只有一个标量：`FMA` 给出「可能坏了」的信号（`Δa↑ ∧ r_res↓`），系统对此的全部回应是把 `λ` 抬到 0.8、把认证前缀缩短。**这是一个症状，不是诊断。**「哪里坏了、坏多大、是传感器还是执行器还是模型、能不能修、修完敢不敢切过去」——R69 一概回答不了。回答不了，就只能全局保守：把整台机器当成「可能全身有病」，用一个大而化之的 `λ_floor` 兜住。代价是：一个左轮编码器 4% 的标度漂移，会让整台机器降速、缩窗、放弃本可完成的精细任务。
>
> 本轮两个灵感正好补上这两块：
> - **故障诊断**指出一个被忽略的结构：故障不是一个标量，而是一个**结构化的假设**（传感器增益 / 偏置 / 卡死 / 漂移，执行器增益损失 / 死区 / 时延，模型惯量 / 摩擦 / 运动学偏差，标定外参 / 同步，接触 / 几何，以及「未知」）。经典 FDIR 把它拆成**检测 → 隔离 → 辨识 → 重构**四级。R69 停在检测，于是所有后续能力都被压在同一个保守开关上。
> - **主动交互**指出：R69 已经造好的注视 / 探针 / 问句，**恰好就是主动故障诊断的工具**——主动诊断的本义就是「设计一个安全、有信息量的激励，让故障假设彼此可分」。只是提问对象从「世界 / 意图」换成了「机器自身」。R69 向人问世界；R70 先向机器问机器，机器问不出来时，才向人问机器。
>
> 核心命题：**把 R69 的标量异常升级为结构化故障假设集上的后验；把「选哪个动作模态」的交互升级为「哪个故障假设成立」的主动隔离；并正面承认一条硬边界——安全壳内可注入的激励信息量有上界，超出上界的故障在物理上不可辨识。可辨识时做定向（targeted）恢复，不可辨识时诚实地声明「未诊断」并对整个并集取最坏情况。所有定向恢复必须满足「无后悔」：按当前仍可能成立的假设集取最坏情况，其风险不得高于保守兜底——于是误诊再也不可能比不诊断更危险。** 命名 **MEDIC-RAS**（Model-based Epistemic Diagnosis with Interactive Certification）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证、还能问什么」，R70 问「**到底哪里坏了、我能不能安全地查出来、查出来之后敢不敢修**」。

## 0. 直觉与动机

**灵感 1（故障是结构，不是标量 → 诊断取代告警）**
直觉：发烧是症状，不是诊断。R69 的 `Δa` 就像体温计：它告诉你「有事」，但不会告诉你是感染、脱水还是刚跑完步。真实系统里，「左轮编码器标度偏 4%」「IMU 与轮速计时延错 20ms」「膝关节摩擦进入 Stribeck 段」「外参标定被碰撞带偏」在残差通道上都可能表现为同一种「行为似然异常」，但它们的**处置完全不同**：前者换用右轮 + IMU 融合，第二个重估时延，第三个切换摩擦补偿，第四个重新标定。把它们压成一个标量，就只能得到一种处置——全局变慢。**诊断的价值不在「知道坏了」，而在「知道该动哪一颗螺丝」。**

**灵感 2（主动交互 = 主动故障隔离，但提问对象反了）**
直觉：医生不会只看化验单，会做**激发试验**（负荷试验、诱发试验）——给一个安全的刺激，看哪个假设被证伪。这正是 control 里的主动故障诊断（active fault diagnosis）：设计输入/探针，使不同故障假设产生**可区分**的响应。R69 的 `g_probe` 只被用来「看清动作模态」；R70 把它升格为「看清机器」的激发试验。更强的反转是：R69 向人问**世界**，R70 让机器先向**自己**取证（探针 / 自检 / 冗余通道交叉），只有机器在安全壳内确实分不开时，才向人问**机器**（「它是不是在往左拽？」）。这既省社交成本，又天然满足证据纪律——人的回答只是一个证据源。

**灵感 3（安全与可诊断性是一对硬矛盾 → 需要上界，而不是更努力的分类器）**
直觉：诊断想要「充分激励」（persistently exciting input），安全想要「最小扰动」。这不是工程细节，而是一条**信息论天花板**：在安全包络内，你能注入的 Fisher 信息有上界；若两个故障在单位参数差下产生的残差差，在这个上界内低于噪声，那么**无论探多久都分不开**。诚实的做法不是让分类器更自信，而是**预先算出可辨识半径 `δ*_safe`，承认「此故障在本安全壳内不可诊断」，然后对假设并集取最坏情况**。这把 R69「不知道 → 只能收紧」的被动保守，升级成「知道哪些不知道、为什么不知道、以及知道到什么程度」的**有结构的保守**——它和 R69 的保守同向，但能解释、能审计、能在可辨识时退出。

**灵感 4（误诊攻击 → 用「无后悔」而不是「更准的分类」来兜底）**
直觉：一旦系统会「定向修复」，就有了新的攻击面：让故障伪装成另一个良性 / 可修故障（fault masking），诱导系统切换到一个在此故障下不安全的控制器。**误诊后换错控制器，可能比 R69 那种盲目保守更危险。** 这里最漂亮的防守不是把分类器训得更准（对抗样本总会存在），而是改变决策规则：**只有当候选恢复控制器在「当前仍可能成立的所有假设」上的最坏风险都不高于保守兜底时，才允许切换。** 因为真实故障必在这个集合里，所以即使诊断错了，风险也不超过兜底——「误诊不后悔」。可辨识性不足时集合退化为并集，恢复自动被禁止。

**灵感 5（间歇故障 → 看不见不等于不存在）**
直觉：接触不良、温漂、间歇性编码器故障，常常在你探针落下的瞬间「消失」。R69 的瞬时似然会把「这次没看到」误读成「没有故障」，从而**自信地排除真故障**。诊断必须把故障看成有持续性的潜状态：`看到故障` 是强证据，`没看到` 只是弱证据（取决于占空比与探测窗对齐）。于是需要证据记忆、故障持续性转移、以及「inactive ≠ absent」的似然——否则主动诊断反而会主动骗自己。

**灵感 6（新层必须是旧层的严格泛化）**
直觉：沿用全系列的理论姿态。若假设集只有 `{h_0}`（无故障），MEDIC 必须逐指令退化为 FLUID（不探测、`U_diag=0`、同一个 `λ`）；若可辨识性不足或预算耗尽，必须退化为 FLUID + 并集保守（安全侧不弱于 R69）；再往前，若连交互都没有，就是 R68。**R70 不是在 R69 旁边加一个黑箱，而是把 R69 当作「永不诊断」的边界包进去。**

## 1. 形式化定义（增量：定义 310–328）

**定义 310（MEDIC-RAS 总览）** MEDIC-RAS = (FHB, MDR, DAA, AIP, SEC, DTR, DBG, HDQ, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；参数再辨识只写影子模型，控制器读数须持证书；
(ii) **诊断预算硬约束**：单位时间激励能量 ≤ e_max、单次探测时长 ≤ τ_p、停机时间 ≤ d_max、人类问询 ≤ 1 次/区间；所有信息动作（含激励）必须通过与任务动作相同的 C-RAS-WM 前缀认证，并**可逆**（存在回到已认证安全集的返回轨迹）；
(iii) **证据纪律**（继承定义 293-iii）：单次探测 / 单源回答不得单独确认隔离，需 k 个正交证据一致，或可辨识裕度高于高置信阈值；
(iv) **无后悔恢复**：任何定向重构只有在「当前仍可能成立的假设集上的最坏风险 ≤ 保守兜底风险」时才被允许（定义 320）。⇒ 误诊永远不会比不诊断更危险。

**定义 311（结构化故障假设集 FHB）** ℋ = {h_0} ∪ ℋ_f，h_0 为名义。每个假设 h = (class, location, θ_h, S_h, onset)，class ∈ {sensor(gain/bias/stuck/drift), actuator(loss/deadzone/latency), model(inertia/friction/kinematics), calibration(extrinsic/time-sync), contact/geometry, unknown}。先验 w_h(0)；持续性转移 P(h_t | h_{t−1}) 为粘性马尔可夫（故障倾向于持续；间歇故障有占空比 d_h）。

**定义 312（故障潜状态与证据记忆）** 故障模式 h_t 按粘性链演化。对残差序列 r_{1:t}，后验 `w_h(t) ∝ w_h(t−1)·P(h_t|h_{t−1})·p(r_t|h_t, o_t, g_t)^{γ}`，γ 为遗忘因子（应对非平稳）。关键：`r_t` 在故障未激活时按「inactive」似然计，而非按「nominal」计；`看不到 ≠ 不存在`（定义 324）。

**定义 313（残差生成与诊断后验 MDR）** 残差束 r = (Δa, r_res, r_geo, r_sync, r_zero, innovation)。逐假设似然 ℓ_h = p(r | h, o, g)。检测 `P_det = 1 − w_0`；隔离 `ĥ = argmax_{h≠0} w_h`；辨识 `θ̂_h = argmax_θ p(r|h,θ)` 并给出置信椭球 Σ_θ。三者是不同对象，不合并成单一 U。

**定义 314（诊断不确定性三分）** `U_det = H(1_{h≠0})`（是否坏的二值熵）；`U_iso = H(w_{ℋ_f}/Σ_{ℋ_f} w)`（坏在哪一类的熵）；`U_id = tr(Σ_θ)`（坏多狠的方差）。三者分别进入检测阈值、隔离决策、恢复裕度，不做简单加和。

**定义 315（故障签名与可辨识半径）** 在工作点线性化残差：`r ≈ S(g; θ_0)·θ + n`，`S = ∂r/∂θ` 为**故障签名矩阵**，显式依赖激励 g。定义 `δ*(g) = σ_min(S̃(g))`（S̃ 为按噪声白化并归一化各假设参数尺度后的签名）。**可辨识半径** `δ*_safe = max_{g∈𝒢_safe} δ*(g)`；两个假设 i,j 为 ε-混叠（aliased）当且仅当 `‖S̃_i − S̃_j‖_F ≤ ε`。若 `δ*_safe < δ_min`，该故障集在本安全壳内**不可诊断**。

**定义 316（安全激励集 SEC）** 𝒢_safe = { g : 过 C-RAS-WM 前缀认证 ∧ 力/力矩/速度/工作空间在包络内 ∧ 能量 ≤ e_max ∧ 时长 ≤ τ_p ∧ 可逆（存在返回已认证安全集的有界轨迹） ∧ 不持续激发不稳定模态 }。激励证书 = (g, 各包络裕度, 可逆性见证, 失效时间)。

**定义 317（风险敏感主动隔离 AIP）** 对候选 g，定义价值
`V(g) = E_{h~w}[Risk(π_fallback|h)] − E_{h~w, y~p(·|h,g)}[Risk(π_after|h)] − c(g) − risk(g)`。
选 `g* = argmax_{g∈𝒢_safe} V(g)`，s.t. 预算未超。**若 max V ≤ 0 或 δ*_safe < δ_min：不探测。** 这是对 R69 MINT（纯 VoI−成本、探测风险只作约束）的修正：探测本身的风险被**减去**而不仅是**约束**，否则「为获取信息而冒的风险」不进目标函数，会产生「高风险高信息」的坏探针。

**定义 318（诊断定向重构 DTR）** 已认证控制器库 Π = {π_h}。给定后验 w 与**歧义支撑集** `H_w = {h : w_h ≥ w_min}`，选
`π* = argmin_{π∈Π} max_{h∈H_w} Risk(π | h)`。
仅当 `max_{h∈H_w} Risk(π*|h) ≤ Risk(π_fallback | H_w)`（定义 320）且 `w` 达 β-置信时启用；切换须持**无扰切换证书**（状态/输入跳变有界，继承 R68 定理 15 的换装不变式）。

**定义 319（辨识与有界再参数化）** 隔离后对 θ_h 做约束最小二乘，得置信椭球 Σ_θ。再参数化只写**影子模型**；控制器只有在「椭球落在已验证域内 ∧ 证书有效」时才可读取新参数，否则保留名义参数 + 保守包络。**在线不写学习参数**，保证可回滚、可审计。

**定义 320（恢复可容许性与无后悔引理式判据）** 对真实故障 `h*∈H_w`（必然成立），若所选 π 满足 `max_{h∈H_w} Risk(π|h) ≤ max_{h∈H_w} Risk(π_fallback|h)`，则 `Risk(π|h*) ≤ Risk(π_fallback|h*)`。即**无论隔离对错，切换都不劣于兜底**。这是 DTR 唯一的准入判据，也是 R70 安全叙事的支点。

**定义 321（人类诊断查询 HDQ）** 仅当 (a) 机器内部安全激励**无法分离**（`δ*_safe < δ_min` 或所有候选 V ≤ 0），且 (b) 问题关于**外部可验证行为**（「它是不是在往左拽」而非「编码器坏没坏」），且 (c) 最坏风险下降足以覆盖社交成本，且 (d) 频率 ≤ 1 次/区间，才向人问。人的回答是**一个证据源**，受定义 293-iii 的 k 正交一致约束，**永不得单独确认隔离**。这是 R69 向人问世界的镜像：R70 向人问机器，且先问机器。

**定义 322（诊断预算治理 DBG）** 管理激励能量、探测次数、停机时间、人类问询率；耗尽即拒绝探测。附加铁律：**诊断不得透支安全预算**——任何使安全裕度低于阈值的探测被直接否决（哪怕信息量再大）。

**定义 323（故障感知的三级风险缩放）** 
- Level 0（名义且已诊断）：`λ = λ_floor(U_ale)`（继承 FLUID 的 resolution bonus）；
- Level 1（已隔离且恢复可容许）：切换到 π_h，按其自身已认证包络取 λ；
- Level 2（检测到但未隔离 / 混叠 / 未知 / 预算耗尽）：`λ = λ_floor(U_ale + U_epi_after + U_diag(H_w))`，`U_diag` 取假设并集的最坏情况。
单调性：`λ_MEDIC ≥ λ_FLUID ≥ λ_R68-floor`；Level 1 的风险由定义 320 保证 ≤ Level 2 兜底。

**定义 324（间歇故障与观测窗）** 故障占空比 d_h、探测间隔 τ、证据记忆窗 T_m。若探测窗落在故障不活跃相位，按 `p(r|h inactive)` 更新（弱证据），不得按 `p(r|h_0)` 更新。检测延迟下界与漏检概率见引理 21。

**定义 325（参与式诊断审计 VQAuditor-D）** 审计对象新增：探测是否真有信息量、是否安全可逆、人类问询是否被滥用、未知故障是否被强行塞进已知假设、恢复切换是否满足无后悔。结论回灌 AuditBuf，成为下一轮 DBG/AIP 的先验。

**定义 326（诊断对抗威胁 ℰ_diag）** 与良性假设混叠的**隐蔽故障**；伪装成另一可修故障以诱发错误切换的**故障掩蔽 / 误诊攻击**；卡在探测窗外出现的**间歇规避**；人类诊断神谕投毒；**激励诱发的失稳**。`ℰ_MEDIC = ℰ_FLUID × ℰ_diag`。

**定义 327（证书 J_MEDIC）** `J_MEDIC = (J_FLUID, hypothesis_posterior_hash, δ*_safe, isolation_margin, excitation_cert, recovery_cert 或 UNDIAGNOSED 标志, medic_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ [（β-置信隔离 ∧ 恢复满足无后悔）∨（显式 `UNDIAGNOSED` ∧ 并集保守包络）] ∧ 探测在安全包络内 ∧ 预算未越界。

**定义 328（快慢双通道与自适应）** 快通道每步跑 MDR 的廉价残差似然 + 签名条件数检查（<0.1ms）；慢通道仅在 `V(g*)>0 ∧ δ*_safe ≥ δ_min` 时规划完整激励，且规划与物理时间解耦、证书可缓存。诊断复杂度的昂贵部分因此只出现在「值得诊断且诊断得起」的少数时刻。

## 2. 关键算法骨架

```python
# IP-264 FHB：结构化故障假设集（粘性转移 + 开集“unknown”）
class FaultHypothesisBank:
    def __init__(self, nominal, spec):
        self.H  = [nominal] + spec.known_faults + [spec.unknown]
        self.w  = spec.priors.copy()
        self.P  = spec.sticky_transition          # 持续性转移

    def posterior_update(self, r, o, g, gamma=0.98):
        pred = self.P.T @ self.w                  # 故障持续性预测
        lik  = [self.model(h).likelihood(r, o, g) for h in self.H]
        post = pred * np.array(lik) ** gamma      # 遗忘因子应对非平稳
        return post / post.sum()

    def support(self, w_min=1e-2):                 # 歧义支撑集 H_w
        return [h for h, p in zip(self.H, w) if p >= w_min]

# IP-266 DAA：签名矩阵 + 可辨识半径 + 混叠类
def diagnosability(fhb, w, g, envelope):
    S    = fhb.signature(g)                       # S(g) = ∂r/∂θ
    S    = whiten_normalize(S, fhb.noise_cov)     # 按噪声白化、按尺度归一
    dstr = svd(S, compute_uv=False)[-1]           # δ*(g)=σ_min(S̃)
    alias = [ (i,j) for i<j if norm(S[:,i]-S[:,j]) <= EPS_ALIAS ]
    return dstr, alias

    if dbg.exhausted(): return None
    best = None
    for g in candidate_probes(modes, w):          # 激励 / 自检 / 人类问询
        if not sec.in_safe_envelope(g):      continue
        if not c_ras_wm.certify_info(g, o):  continue
        if not sec.reversible(g):            continue
        base = expected_risk(w, fallback_policy)
        post = expected_posterior(fhb, w, o, g)
        val  = base - expected_risk(post, select_policy(post, sec)) \
               - cost(g) - probe_risk(g)          # ← risk(g) 进目标函数
        if val > 0 and (best is None or val > best.val):
            best = Probe(g, val)
    return best                                   # None ⇒ 不探测，诚实保守

# IP-269 DTR：无后悔定向重构（worst-case over H_w ≤ fallback）
def select_recovery(fhb, w, controllers, sec):
    H_w = fhb.support()
    worst = {pi: max(risk(pi, h) for h in H_w) for pi in controllers}
    fallback_worst = max(risk(sec.fallback_policy, h) for h in H_w)
    pi = min(worst, key=worst.get)
    if worst[pi] <= fallback_worst and fhb.confident(w, BETA):
        return pi if sec.switch_certified(pi, fhb) else None
    return None                                   # 不可容许 ⇒ Level 2 兜底

# IP-275 主闭环（继承 R69/R68，仅在故障处置处插入诊断层）
def MEDIC_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    smp = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(smp, z, M.fmp.mode_head)
    # 1) 结构化诊断：残差 → 假设集后验（快通道）
    r = M.mdr.residuals(o, M.last_action)          # Δa / r_res / r_geo / ...
    w = M.fhb.posterior_update(r, o, M.last_g)
    # 2) 可辨识性：安全壳内到底分不分得开
    dstr, alias = M.daa.diagnosability(M.fhb, w, M.last_g, M.sec.envelope)
    undiagnosable = (dstr < DELTA_MIN) or M.fhb.has_unknown(w)
    # 3) 主动隔离：仅在“可分 + 值钱 + 安全 + 有预算”时做激发试验
    g = None
    if (not undiagnosable) and M.fhb.entropy_iso(w) > TAU_ISO:
        probe = M.aip.plan_isolation(M.fhb, w, modes, o, M.sec, M.dbg)
        if probe is not None:
            M.sec.certify(probe.g); M.dbg.spend(probe.g)
            w = M.fhb.posterior_update(M.aip.execute(probe.g), o, probe.g)
            g = probe.g
    # 4) 恢复：无后悔切换，否则三级保守
    pi = M.dtr.select_recovery(M.fhb, w, M.controllers, M.sec)
    if pi is not None:
        A = pi.propose(o, M.vista.H); return M.dtr.switch_to(pi, A), w, 'targeted'
    U_diag = M.fhb.union_uncertainty(M.fhb.support())
    U_floor = U_ale + (U_epi if g is None else 0.0) + U_diag
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if (dstr < DELTA_MIN) or M.fhb.is_slow_fault(w):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    M.vqa_d.submit_async(g, w, alias, pi, dstr)
    return k, lam, mode, (U_ale, U_epi, U_diag)
```

## 3. 推导

**引理 19（混叠的不可诊断性）** 若假设 i,j 在 𝒢_safe 上 ε-混叠，即对任意 g∈𝒢_safe，两者观测律的全变差 ≤ ε，则任何限制在 𝒢_safe 的诊断策略对 {i,j} 的（假阳 + 假阴）之和 ≥ 1 − ε（Le Cam / Pinsker）。要点：**这不是分类器不够强，而是信息不存在**。系：此时正确输出是并集的保守包络与显式 `UNDIAGNOSED`，而不是更自信的 `argmax`。

**引理 20（安全激励的信息上界）** 对线性化残差 `r = S(g)θ + n, n~𝒩(0,Σ), g∈𝒢_safe`，关于 θ 的最大期望熵降 ≤ `½ log det(I + F_max Σ_prior^{-1})`，其中 `F_max = max_{g∈𝒢_safe} S(g)ᵀΣ^{-1}S(g)`。且 `δ*_safe ≤ σ_max(F_max)^{1/2}`。要点：**可诊断性被安全包络封顶**；探得更久不会突破 Fisher 上界，只会更快到达它。系：诊断规划应求「在预算内最接近上界的激励」，而不是无休止探测。

**引理 21（间歇故障的检测延迟）** 故障占空比 d、探测间隔 τ、记忆窗 T_m。探测窗错过活跃相位的单次概率为 (1−d)，则 T_m 内漏检概率 `(1−d)^{T_m/τ}`，期望检测延迟 ≥ `τ(1−d)/d`。系：低占空比故障必须靠证据记忆与窗对齐；否则「这次没看到」会被误当「不存在」，**主动诊断反而主动致盲**。

**定理 18（MEDIC 严格包含 FLUID 与 R68）** 在 A99–A102（假设集完备性、签名可微、包络可认证）下：若 ℋ={h_0}，则 MEDIC 与 FLUID **逐指令相同**（`U_diag=0`、不探测、同一个 λ）；若混叠 / 未知 / 预算耗尽 / 探测价值 ≤0，则 MEDIC = FLUID + 并集保守，故安全侧不弱于 R69；定向恢复由定义 320 保证风险不高于兜底，故任意状态期望风险 ≤ FLUID。再令交互为空，即得 R68。**R69 是 MEDIC 的「永不诊断」边界，R68 是再一层的「永不交互」边界。**

**定理 19（无后悔恢复）** 若 DTR 可容许（`max_{h∈H_w} Risk(π|h) ≤ max_{h∈H_w} Risk(π_fallback|h)`），则对任意真实 `h*∈H_w`（含误诊情形）有 `Risk(π|h*) ≤ Risk(π_fallback|h*)`。结合引理 19：混叠时 `H_w` 保持并集、任何恢复都不被容许，因而自动退回 Level 2。加上无扰切换证书（R68 定理 15），切换过程控制连续、无突变。**结论：误诊不后悔——坏诊断最多退化为保守，绝不会主动失稳。**

## 6. 本轮最大风险

**一句话**：MEDIC-RAS 的全部收益押在「**故障假设集覆盖真实故障 ∧ 安全壳内签名可辨识**」这两个前提上——一旦真实故障落在假设集之外（未知故障），或与某个良性/可修假设在安全激励下混叠，系统会算出一个「可诊断性已证明」的错误隔离，并据此触发**定向重构**；此时最坏情况判据本应拦住它，但如果 `H_w` 因错误的先验/被投毒的证据而**没有包含真实故障**，无后悔判据算的就不再是真实最坏情况——于是系统会把 R68/R69 那种「盲目的保守（至少安全）」升级成「有证书的主动失稳」：**错修，比不修更危险。**

**次级风险与缓解**：
1. **假设集不完备 / 未知故障** → 开集 `unknown` 假设 + 残差新颖性检测 + 覆盖条件门，未知即并入并集走最保守（定义 311、定理 18）；
2. **激励本身不安全 / 不可逆** → SEC 安全-可逆证书 + 能量/时长上界 + 「诊断不得透支安全预算」（定义 316、322）；
3. **安全壳内不可辨识** → 预先计算 `δ*_safe`，`< δ_min` 即显式 `UNDIAGNOSED` + 并集保守，不做更多无谓探测（定义 315、引理 19–20）；
4. **间歇故障在探测窗消失** → 证据记忆 + 占空比似然 + 窗对齐，坚持 `inactive ≠ absent`（定义 312、324、引理 21）；
5. **误诊攻击 / 故障掩蔽** → ℰ_diag 对抗训练 + 无后悔切换把误诊风险压到不高于兜底 + k 正交证据纪律（定义 320、326、引理 18 继承）；
6. **修复引入切换抖动** → 滞回 + 无扰切换证书 + 换装不变式 + 影子模型回滚（定义 318–319）。

**定义 321–322（人类问询与预算）** 仅机器不可分离时问、问外部可验证行为、回答仅一证据源；DBG 管能量/次数/停机/问询率，诊断不得透支安全预算。

**定义 323（三级风险缩放）** Level 0 名义 → `λ_floor(U_ale)`；Level 1 已隔离且可容许 → 按 π_h 包络；Level 2 未隔离/混叠/未知 → `λ_floor(U_ale+U_epi_after+U_diag(H_w))`。单调 `λ_MEDIC ≥ λ_FLUID ≥ λ_R68`。

**定义 324–328（间歇故障/审计/对抗/证书/双通道）** 占空比 + 观测窗 + 证据记忆；VQAuditor-D；`ℰ_MEDIC`；`J_MEDIC`；快通道 <0.1ms，慢通道与物理时间解耦。

## 3. 关键算法伪代码

```python
# IP-264 FHB：结构化假设集 + 粘性持续性 + 开集 unknown
class FaultHypothesisBank:
    def __init__(self, nominal, spec):
        self.H, self.w, self.P = [nominal]+spec.known+[spec.unknown], spec.priors, spec.sticky
    def posterior_update(self, r, o, g, gamma=0.98):
        pred = self.P.T @ self.w
        lik  = np.array([self.model(h).likelihood(r, o, g) for h in self.H])
        post = pred * lik ** gamma            # 遗忘因子，应对非平稳
        return post / post.sum()
    def support(self, w_min=1e-2):            # H_w：无后悔判据的定义域
        return [h for h,p in zip(self.H,self.w) if p >= w_min]

# IP-266 DAA：签名矩阵 → 可辨识半径 + 混叠类
def diagnosability(fhb, w, g, envelope):
    S = whiten_normalize(fhb.signature(g), fhb.noise_cov)   # S(g)=∂r/∂θ
    dstr = svd(S, compute_uv=False)[-1]                     # δ*(g)=σ_min
    alias = [(i,j) for i<j if norm(S[:,i]-S[:,j]) <= EPS_ALIAS]
    return dstr, alias

# IP-267/268 AIP+SEC：风险敏感主动隔离
def plan_isolation(fhb, w, modes, o, sec, dbg):
    if dbg.exhausted(): return None
    best, base = None, expected_risk(w, sec.fallback_policy)
    for g in candidate_probes(modes, w):
        if not (sec.in_safe_envelope(g) and sec.reversible(g)): continue
        if not c_ras_wm.certify_info(g, o):                     continue
        post = expected_posterior(fhb, w, o, g)
        val  = base - expected_risk(post, select_policy(post, sec)) \
               - cost(g) - probe_risk(g)                        # risk(g) 进目标函数
        if val > 0 and (best is None or val > best.val): best = Probe(g, val)
    return best                                                 # None ⇒ 诚实保守

# IP-269 DTR：无后悔定向重构
def select_recovery(fhb, w, controllers, sec):
    H_w = fhb.support()
    worst = {pi: max(risk(pi,h) for h in H_w) for pi in controllers}
    fb    = max(risk(sec.fallback_policy,h) for h in H_w)
    pi    = min(worst, key=worst.get)
    return pi if (worst[pi] <= fb and fhb.confident(w,BETA)
                  and sec.switch_certified(pi, fhb)) else None

# IP-275 主闭环（继承 R69/R68，仅故障处置处插入诊断层）
def MEDIC_RAS_round(M, obs):
    z,o = M.mtm.forward(...); c,U_cal,thr = M.cof.step(...)
    K   = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale,U_epi,modes,_ = M.aud.decompose(M.fmp.sample(o,K), z, M.fmp.mode_head)
    r = M.mdr.residuals(o, M.last_action)                       # Δa/r_res/r_geo/...
    w = M.fhb.posterior_update(r, o, M.last_g)
    dstr, alias = M.daa.diagnosability(M.fhb, w, M.last_g, M.sec.envelope)
    undiag = (dstr < DELTA_MIN) or M.fhb.has_unknown(w)
    g = None
    if (not undiag) and M.fhb.entropy_iso(w) > TAU_ISO:
        pr = M.aip.plan_isolation(M.fhb, w, modes, o, M.sec, M.dbg)
        if pr is not None:
            M.sec.certify(pr.g); M.dbg.spend(pr.g)
            w = M.fhb.posterior_update(M.aip.execute(pr.g), o, pr.g); g = pr.g
    pi = M.dtr.select_recovery(M.fhb, w, M.controllers, M.sec)
    if pi is not None:
        A = pi.propose(o, M.vista.H); return M.dtr.switch_to(pi, A), w, 'targeted'
    U_diag = M.fhb.union_uncertainty(M.fhb.support())
    U_floor = U_ale + (U_epi if g is None else 0.0) + U_diag
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if (dstr < DELTA_MIN) or M.fhb.is_slow_fault(w):
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    M.vqa_d.submit_async(g, w, alias, pi, dstr)
    return k, lam, mode, (U_ale, U_epi, U_diag)
```

## 4. 推导

**引理 19（混叠的不可诊断性）** 若 i,j 在 𝒢_safe 上 ε-混叠（观测律全变差 ≤ ε），则任何限制在 𝒢_safe 的诊断策略对 {i,j} 的假阳+假阴之和 ≥ 1−ε。系：正确输出是并集保守 + 显式 `UNDIAGNOSED`，不是更自信的 argmax。

**引理 20（安全激励的信息上界）** 线性化 `r=S(g)θ+n`，`g∈𝒢_safe` 下最大期望熵降 ≤ `½ log det(I + F_max Σ_prior^{-1})`，`F_max=max_{g∈𝒢_safe} S(g)ᵀΣ^{-1}S(g)`，且 `δ*_safe ≤ σ_max(F_max)^{1/2}`。系：可诊断性被安全包络封顶，探更久不突破上界。

**引理 21（间歇故障检测延迟）** 占空比 d、探测间隔 τ、记忆窗 T_m ⇒ 漏检概率 `(1−d)^{T_m/τ}`，期望延迟 ≥ `τ(1−d)/d`。系：低占空比必须靠证据记忆与窗对齐，否则主动诊断主动致盲。

**定理 18（严格包含 FLUID 与 R68）** A99–A102 下：ℋ={h_0} ⇒ MEDIC 与 FLUID 逐指令相同；混叠/未知/预算耗尽/V≤0 ⇒ MEDIC = FLUID + 并集保守，安全不弱；定向恢复由定义 320 保证不劣于兜底 ⇒ 任意状态期望风险 ≤ FLUID。交互为空即 R68。**R69 = 「永不诊断」边界，R68 = 「永不交互」边界。**

**定理 19（无后悔恢复）** DTR 可容许时，对任意真实 `h*∈H_w`（含误诊）有 `Risk(π|h*) ≤ Risk(π_fallback|h*)`；混叠时 `H_w` 为并集、恢复被禁止，自动退回 Level 2；无扰切换证书保证控制连续、无突变。**误诊不后悔——坏诊断最多退化为保守。**

## 7. 本轮最大风险

**一句话**：MEDIC-RAS 的全部收益押在「故障假设集覆盖真实故障 ∧ 安全壳内签名可辨识」上——一旦真实故障在假设集之外，或与被投毒先验下的良性假设混叠，系统会算出「可诊断性已证明」的错误隔离并触发定向重构；此时无后悔判据本应拦住它，但若 `H_w` 因先验错误或证据投毒**未包含真实故障**，它算的就不是真实最坏情况——系统于是把 R68/R69「盲目的保守（至少安全）」升级成「有证书的主动失稳」：**错修，比不修更危险。**

**次级风险与缓解**：假设集不完备（开集 unknown + 新颖性检测 + 覆盖门，未知即并集保守）；激励不安全/不可逆（SEC 证书 + 能量/时长上界 + 诊断不得透支安全预算）；安全壳内不可辨识（预算 `δ*_safe`，`<δ_min` 即 `UNDIAGNOSED` + 并集保守）；间歇故障探测窗消失（证据记忆 + 占空比似然 + 窗对齐）；误诊攻击/故障掩蔽（ℰ_diag 对抗 + 无后悔切换 + k 正交证据）；修复切换抖动（滞回 + 无扰切换证书 + 影子模型回滚）。
