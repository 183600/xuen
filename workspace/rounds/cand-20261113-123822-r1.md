# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「双臂协调」×「强化学习」）

> 第 66 轮 RAS 把「被动故障闭环」升级为「主动意图闭环」：用面部表情捕获风险态度，用标量 `λ_risk` 缩放控制量，用 ERS 沿情绪风险梯度做局部整形。但 RAS 的控制抽象有一个从未被追问的前提：**整条闭环只作用于“一路指令流”**——`λ_risk·τ_cmd` 被假定存在唯一、可执行的对应。单臂任务里这近似成立；双臂任务里它当场失效。
>
> 双臂抓持同一物体时，两臂经物体构成闭链：物体只约束“合力”，不约束“内力”。同一个物体运动对应无穷多组 `(w_L, w_R)`，它们相差一个**内力零空间**分量。于是「该发多大指令」不再是标量问题，而是「**这条任务扳手如何在两臂之间、以及在内力方向上分配**」的问题。
>
> 本轮的核心命题是：
>
> **把「标量风险缩放」升级为「扳手分布闭环」；把「双臂冗余」从需要消除的自由度，升级为强化学习可以安全花掉的探索预算。即 CRADLE（Certified Redundancy-Aware Dual-arm Learning Engine，认证冗余感知双臂学习引擎）。**
>
> CRADLE 追问的不是「控制多少」，而是「**在两条手臂的闭链里，哪些自由度改变任务、哪些只改变内力；强化学习只许在前者被证书锁死的前提下，拿后者去做实验**」。

## 0. 直觉与动机

**灵感 1（双臂协调 → 闭链把标量控制律变成扳手分布）**

直觉：用双手端一个托盘时，托盘的位置只取决于两手的**合力**，而两手各自用多大力、往哪个方向对抗，托盘并不知道。这正是双臂协调与单臂最本质的差别：单臂的可行指令是一条曲线，双臂的可行指令是一个**纤维丛**——每个任务状态上挂着一层内力。RAS 的 `λ_risk` 假定“把指令乘小一点”是良定义的，但在闭链里，`λ_risk·(w_L, w_R)` 会同时改变任务分量和内力分量，而后者根本不该被这个标量支配。

严谨地说：设抓取矩阵 `G = [G_L, G_R] ∈ ℝ^{6×12}`，接触扳手 `w = [w_L; w_R]`，物体平衡为 `G w + w_ext = 0`。该方程只确定 `w` 在 `G` 的行空间上的投影，齐次解空间 `ker(G)` 就是**内力空间**。对于两个刚性 6 维抓取，`rank(G)=6`，因此 `dim ker(G)=6`——有整整 6 个方向的指令变化，对物体运动**完全不可见**。

**灵感 2（双臂协调 → 风险越高越要“抱紧、走慢”，但 RAS 只会“一起变松”）**

直觉：人在感到危险时的第一反应不是把手里东西松开，而是**抱得更紧、移动更慢**。也就是说，任务安全与内力安全在风险上升时朝**相反方向**调节：任务分量要收缩，内力分量要膨胀（在力矩上限内）。RAS 的标量 `λ_risk < 1` 会让两者一起收缩——任务变慢是对的，但内力也变小，摩擦锥半径 `μN` 随之下降，切向载荷稍有扰动就打滑。这是一个“**越怕越松手**”的悖论。

把它写成滑移裕度：若法向内力为 `N = n^T w_int`、切向载荷为 `F_t`，则 `S = μN - ||F_t||`。标量缩放给 `S(λ) = λS`，风险越大裕度越小；双通道缩放给 `S(λ) = μ λ_int N - λ_task ||F_t||`，只要 `λ_int` 上升得足够快，裕度反而增大。**风险缩放不能是一个数，必须是一对相互拮抗的数**。

**灵感 3（强化学习 → 冗余是唯一“免费的物理实验”）**

直觉：在真实双臂上做 RL，最贵的不是算力，而是每次探索的物理代价：随机扰动可能扯坏物体、拉伤关节、触发急停。但闭链冗余提供了一个罕见的结构性礼物：沿 `ker(G)` 的扰动**不改变物体位姿、不改变外力**，只改变内力分配。因此它是“对任务免费”的实验方向。RL 的探索维度可以从 12 维压到 6 维，而且大部分探索天然落在任务证书之外——不是被过滤掉，而是**根本不进入**任务证书的约束。

于是我们可以把“冗余”重新定义：它不是运动学里要消掉的零空间，而是一笔可以被**预算化**、被**证书托管**的探索资源。这正好把「双臂协调」与「强化学习」缝在一起：前者提供可探索的子空间，后者提供如何花这笔预算的策略。

**灵感 4（强化学习 → 证书不能只做事后裁剪，要进优化目标与护盾）**

直觉：如果 RL 先输出一个动作、再被硬裁剪到安全集里，策略学到的梯度与真实执行的动作不一致，训练会“以为自己在做 A，实际一直在做 B”。更稳的做法是双管齐下：**训练时**把包络裕度作为约束/Lagrangian 惩罚，让策略学会主动留在包络内部；**部署时**用最小范数 QP 把动作投影回包络切空间。二者共用同一个证书，于是 sim-to-real 时策略已经“习惯”被投影，不会在真机上突然性能塌陷。

**灵感 5（合流 → CRADLE 七件套）**

1. **WCD Wrench Coordination Decomposer**：把期望外力分解为任务扳手 `w_task` 与内力 `w_int = N z`；
2. **CEE Coordination Envelope Estimator**：在接触力多面体上计算协调安全包络 `C` 与归一化裕度 `h`；
3. **ESP Exploration Safety Projector**：用离散 CBF-QP 把 RL 的内力动作投影到 `{h ≥ h_min}` 的切空间；
4. **RPO Redundancy-Partitioned Policy Optimization**：只在 `ker(G)` 上学习，任务侧由认证标称控制器提供；
5. **BUD Budgeted Uncertainty Director**：把裕度 `B = h - h_min` 换算成信任域半径 `r = κB`，控制探索强度；
6. **DCR Dual-Channel Risk scaler**：把 RAS 的标量 `λ_risk` 升级为 `(λ_task, λ_int)` 拮抗缩放；
7. **CAF Coordination Attribution & Feedback**：新增双臂故障维 `D0..D5`，把滑移/失衡/失配回灌 VISTA-RAS 归因。

再叠加 **CRC**（双臂认证前缀）、**SRT**（包络膨胀的 sim-to-real 迁移）与 **J_CR**（证书）。VISTA 问「哪一层坏了」，RAS 问「谁该控制、控制多少」，CRADLE 问「**两只手该怎么分这条力，学习又该被允许在这条力的哪些零空间里发生**」。

## 1. 形式化定义（增量：定义 245–260）

- **定义 245（CRADLE 总览）**：`CRADLE = (WCD, CEE, ESP, RPO, BUD, DCR, CAF, CRC, SRT, J_CR)`。定位：把 RAS 的「标量风险闭环」升级为「双臂扳手分布闭环 + 证书保持学习」。不变式：学习只发生在离线训练与语义流；实时流只执行 QP 投影、裕度检查、前缀早停，零学习写操作。
- **定义 246（双臂闭链状态）**：状态 `s = (q, x_o, 𝒞, w_ext)`，其中 `q = (q_L, q_R)` 为两臂关节角，`x_o ∈ SE(3)` 为物体位姿，`𝒞` 为接触点集，`w_ext ∈ ℝ^6` 为外力旋量。抓取矩阵 `G = [G_L, G_R] ∈ ℝ^{6×12}`，接触扳手 `w = [w_L; w_R] ∈ ℝ^{12}`，物体平衡为 `G w + w_ext = 0`。
- **定义 247（任务/内力分解）**：`w_task = -G^+ w_ext`（最小范数特解），`N = I_12 - G^+ G`（内力投影），`w_int = N z`，`z ∈ ℝ^{12}`。于是 `w = w_task + w_int`，且 `G w_int = 0`。内力维数 `d_int = 12 - rank(G)`；刚性双 6 维抓取下 `d_int = 6`。
- **定义 248（协调安全包络）**：`C = { (x_o, w_ext, q) : ∃z，使 w = w_task + Nz 满足 w_i ∈ FC_i、τ_i = J_i^T w_i + g_i(q_i) ∈ T_i、关节限位、自碰撞自由、无源裕度 ≥ 0 }`。`C` 是 12 维接触力多面体在任务空间上的投影，通常非凸（因 `G^+` 与摩擦锥的组合）。
- **定义 249（包络裕度）**：对约束族 `{s_j(q,z) ≥ 0}`，定义归一化裕度
  ```
  h(q,z) = min_j s_j(q,z) / s_j^0 ,   s_j^0 > 0 为标定尺度
  ```
  `h > 0` 当且仅当严格在 `C` 内；`∇_z h` 指向提升裕度最快的内力方向（通常对应“夹得更紧/载荷重新分配”）。
- **定义 250（双通道风险缩放）**：给定 RAS 的标量风险 `R ∈ [0,1]` 与裕度 `h`，
  ```
  λ_task = clip(1 - α_t·R, 0.3, 1.0)
  λ_int  = clip(1 + α_i·R + β_i·max(0, h* - h)/h*, 1.0, 1.5)
  ```
  输出 `λ = (λ_task, λ_int)`。任务分量随风险收缩，内力分量随风险与裕度亏空膨胀。
- **定义 251（安全缩放前沿）**：设 `S(λ) = μ λ_int N - λ_task ||F_t||`，要求 `S(λ) ≥ S_min`。等价地
  ```
  λ_int ≥ (S_min + λ_task·||F_t||) / (μN)
  ```
  这是 `(λ_task, λ_int)` 平面上的可行半平面，称为**安全缩放前沿**。
- **定义 252（探索预算）**：`B_t = max(0, h_t - h_min)`，信任域半径 `r_t = κ·B_t`，`κ ∈ (0,1)`。预算越大，允许的内力探索步长越大；预算耗尽即退化为纯标称控制。
- **定义 253（证书保持投影 ESP）**：RL 提议 `a ∈ ℝ^{d_int}`，执行
  ```
  a_safe = argmin_{a'} ||a' - a||²
           s.t.  ∇_z h^T a' + α_cbf·(h - h_min) ≥ 0,
                 ||a'|| ≤ r_t
  ```
  这是最小范数 CBF-QP；输出 `a_safe` 落在 `C` 的切空间内。
- **定义 254（冗余隔离策略 RPO）**：策略 `π_θ(a | s)`，动作维数仅为 `d_int`。目标
  ```
  max_θ  E[ Σ_t γ^t ( r_task(s_t) - c_τ||τ_t||² - c_h·max(0, h_min - h_t) ) ]
  s.t.   E[h_t] ≥ h_min ,   τ_t ∈ T
  ```
  用自适应 Lagrangian 乘子求解；任务侧指令由 VISTA/RAS 的认证标称控制器给出，RL 只能分配内力。
- **定义 255（协调故障假设）**：`H_dual ∈ D = {D0 正常, D1 滑移, D2 载荷失衡, D3 内力饱和/过压, D4 双臂时序失配, D5 闭链奇异}`。其中 `D5` 对应 `rank(G) < 6`，内力空间突然扩张但任务方向不可控。
- **定义 256（协调归因后验）**：
  ```
  P(D | ρ, w, s_slip) ∝ p(ρ | H_VISTA)·p(w_int | D)·p(s_slip | D)·P(D)
  ```
  并加入共因项 `ℰ_common_dual`：物体质量/摩擦突变会同时触发 `D1` 与 `D2`，不可当作独立证据重复计数。
- **定义 257（双臂认证前缀 CRC）**：`k*_CR = min(k_RAS, k_dual)`，其中
  ```
  k_dual = max k  s.t. ∀s≤k: h_s ≥ h_min ∧ S(λ_s) ≥ S_min ∧ rank(G_s) = 6
  ```
  任一条不满足即截断，且截断点之后的内力指令回落至标称 `z0`。
- **定义 258（探索审计与再认证）**：若滑动残差 `s_slip` 或裕度下降速率 `-ḣ` 超过阈值 `τ_audit`，则冻结策略、清空信任域 `B←0`、触发 CEE 重标定。这是 RL 的**物理断路器**。
- **定义 259（Sim-to-real 证书迁移）**：设包络估计误差满足 `|h - ĥ| ≤ L_h·δ_model`。仅当 `ĥ - L_h·δ_model ≥ h_min` 时才允许迁移；否则先做端口标定。迁移后的证书使用膨胀裕度 `ĥ - L_h·δ_model`。
- **定义 260（J_CR 证书）**：
  ```
  J_CR = (J_RAS, λ_task, λ_int, h, B, P(D|·), policy_hash, envelope_ver, sim2real_inflation)
  ```
  `Valid ⇔ Valid(J_RAS) ∧ h ≥ h_min ∧ S(λ) ≥ S_min ∧ (policy_frozen ∨ B ≥ 0)`。

## 2. 关键算法骨架

```python
class WrenchCoordinationDecomposer:
    def decompose(self, w_ext, G):
        G_pinv = pinv(G)                 # 6 x 12
        w_task = -G_pinv @ w_ext         # 最小范数任务扳手
        N = np.eye(12) - G_pinv @ G      # 内力投影, G @ N == 0
        return w_task, N

    def to_torque(self, w, q, J, g):
        return J.T @ w + g(q)            # w = [w_L; w_R], J = blkdiag(J_L, J_R)


class CoordinationEnvelopeEstimator:
    def __init__(self, fc, tau_lim, q_lim, h_min=0.2):
        self.fc, self.tau_lim, self.q_lim, self.h_min = fc, tau_lim, q_lim, h_min

    def margin(self, q, z, w_task, N, J, g):
        w = w_task + N @ z
        slacks = (self._friction_slacks(w) +
                  self._torque_slacks(J.T @ w + g(q)) +
                  self._joint_slacks(q) +
                  [self._self_collision_slack(q)])
        j = argmin(slacks)
        h = slacks[j]
        # 活跃约束对 z 的梯度链：w = w_task + N z
        grad_h = self._constraint_grad(j, q, w) @ N
        return h, grad_h


class ExplorationSafetyProjector:
    def project(self, a, h, grad_h, h_min, alpha_cbf, r):
        if grad_h @ a + alpha_cbf * (h - h_min) >= 0 and norm(a) <= r:
            return a
        # min ||a' - a||² s.t. grad_h·a' + alpha_cbf(h - h_min) >= 0, ||a'|| <= r
        return solve_qp_min_norm(a, grad_h, alpha_cbf * (h - h_min), r)


class DualChannelRiskScaler:
    def scale(self, R, h, h_star=1.0):
        lam_t = clip(1 - 0.6 * R, 0.3, 1.0)
        lam_i = clip(1 + 0.5 * R + 0.3 * max(0, h_star - h) / h_star, 1.0, 1.5)
        return lam_t, lam_i


class CoordinationAttribution:
    H = ['D0', 'D1', 'D2', 'D3', 'D4', 'D5']

    def attribute(self, rho, w_int, s_slip, tau):
        lik = {
            'D0': 1.0,
            'D1': slip_likelihood(s_slip, w_int),
            'D2': imbalance_likelihood(tau),
            'D3': saturation_likelihood(w_int, tau),
            'D4': desync_likelihood(rho),
            'D5': singularity_likelihood(self.G, self.q),
        }
        return normalize({d: lik[d] * self.prior[d] for d in self.H})


def CRADLE_round(M, obs):
    # 0) VISTA / RAS 语义前向：得到 x', 动作块 A, 联合后验, 标量风险 R
    x_prime, A, joint_post, R = M.ras_forward(obs)

    # 1) 扳手分解与标称内力
    w_ext = M.task.desired_wrench(x_prime)
    G = M.grasp.matrix(M.q, M.object_pose, M.contacts)
    w_task, N = M.wcd.decompose(w_ext, G)
    z0 = M.load_balance.solve(w_task, G)          # 对称/最小内力分配

    # 2) 包络裕度 + 双通道风险缩放
    h, grad_h = M.cee.margin(M.q, z0, w_task, N, M.J, M.g)
    lam_t, lam_i = M.dcr.scale(R, h)

    # 3) RL 提议内力残差，CBF 投影
    a = M.rpo.act(M.obs_to_state(obs, h))
    B = max(0.0, h - M.h_min)
    a_safe = M.esp.project(a, h, grad_h, M.h_min, M.alpha_cbf, M.kappa * B)

    # 4) 合成指令、力矩、认证前缀
    w_cmd = lam_t * w_task + lam_i * (N @ (z0 + a_safe))
    tau_cmd = M.wcd.to_torque(w_cmd, M.q, M.J, M.g)
    k_cr = M.crc.certified_prefix(A, tau_cmd, joint_post, M.h_hist, M.h_min)

    # 5) 协调归因与物理断路器
    D_post = M.caf.attribute(M.residual_log, N @ (z0 + a_safe), M.slip, tau_cmd)
    if M.audit.trip(M.slip, h, M.h_hist):
        M.rpo.freeze(); B = 0.0; M.cee.recalibrate()
        w_cmd = lam_t * w_task + lam_i * (N @ z0)
        tau_cmd = M.wcd.to_torque(w_cmd, M.q, M.J, M.g)

    # 6) 证书
    J = M.cert.build(joint_post, lam_t, lam_i, h, B,
                     D_post, M.rpo.hash, M.cee.version)
    return k_cr, lam_t, lam_i, h, a_safe, D_post, J
```

## 3. 推导

**引理 11（双通道安全前沿）** 记 `S(λ) = μ λ_int N - λ_task ||F_t||`。若 `λ_int ≥ 1` 且 `λ_task ≤ 1`，则
```
S(λ) ≥ S_min  ⇔  λ_int ≥ (S_min + λ_task||F_t||) / (μN)
```
这是 `λ` 空间中的可行半平面。相对地，RAS 的标量缩放（`λ_task = λ_int = λ_risk`）给出 `S(λ) = λ_risk·S_0`；当 `λ_risk < S_min/S_0` 时必然违反滑移约束。**证明**：代入定义直接得到；标量情形的 `S` 对 `λ_risk` 线性，故风险越大越危险。**推论**：RAS 的标量 `λ_risk` 在双臂抓持下只有在“原裕度足够大”或“不做缩放”时才安全，因此它不是双臂的合法风险算子。

**引理 12（内力的任务不可见性与探索隔离）** 对任意 `z, z'`，`G(Nz) = G(Nz') = 0`，故物体位姿、外力旋量与任务级安全证书对内力残差完全不变。`dim ker(G) = 12 - rank(G)`；刚性双 6 维抓取 `rank(G)=6`，故 `d_int=6`。**含义**：把 RL 动作空间限制在 `ker(G)`，不改变任务最优解所在的任务子空间，却把有效探索维数从 12 降到 6。

**定理 11（证书保持探索的前向不变性）** 若 `h_0 ≥ h_min`，且每个执行动作都经 ESP 投影（CBF 类 K 函数 `α_cbf`），则对所有 `t`
```
h_{t+1} ≥ (1 - α_cbf)·h_t + α_cbf·h_min ≥ h_min
```
因此探索过程中包络约束零违规；投影问题可行（`a'=0` 恒可行），且最小范数投影是唯一最接近提议动作的安全动作。**证明**：离散 CBF 条件改写即得递推；可行性与唯一性来自凸二次规划严格凸性。

**定理 12（样本复杂度与子最优界）** 在冗余隔离下，策略的有效动作维数为 `d_int`。达到 `ε`-最优的样本复杂度为 `O(d_int / (ε²(1-γ)³))`（线性 MDP 口径）；相对“不受限 12 维动作在 `C` 上的最优解”，CRADLE 的子最优性满足
```
J* - J_CRADLE ≤ g_comp + L_r·κ·B_0
```
其中 `g_comp` 是闭链耦合损失，`L_r` 是奖励对内力动作的 Lipschitz 常数。**含义**：用“最多花掉 `κB_0` 的即时奖励”换取“探索期零约束违规”。

**定理 13（Sim-to-real 证书可迁移性）** 设真实裕度与估计裕度满足 `|h - ĥ| ≤ L_h·δ_model`。若 `ĥ - L_h·δ_model ≥ h_min`，则膨胀裕度 `h̃ = ĥ - L_h·δ_model` 在真机上仍满足 `h ≥ h_min`，`J_CR` 可迁移；否则必须重标定。这是部署前可执行的**一票否决条件**，也是 Theorem 11 从仿真走到真机的桥。

## 6. 本轮最大风险

**一句话**：CRADLE 把整个安全论证押在「抓取矩阵 `G` 与协调包络 `C` 准确」之上，但真实双臂接触是部分不可观的（软指尖、未知接触点、物体惯量未知），而 RL 恰恰最擅长在**模型误差的方向上**把探索预算花到最大——于是“证书保持的零违规探索”可能退化为对包络估计误差的定向利用：估计裕度 `h` 仍为正，真实裕度已经为负，物体在证书的盲区里滑落。

**次级风险与缓解**：
1. **包络过乐观**：用悲观包络 + 触觉/滑移传感做独立旁路；`ĥ - L_h δ < h_min` 直接冻结迁移（定理 13）；
2. **`G` 估计错误**：在线手眼/接触点标定，`rank(G)` 掉秩立即触发 `D5` 与再认证；
3. **RL 钻证书空子**：训练时随机化 `C`（域随机化包络参数）并加入“对抗包络扰动”课程，避免策略过拟合单一包络；
4. **双通道过紧**：`λ_int` 上限受力矩与物体压强约束，设置硬上限并允许“宁可停机不压碎”；
5. **实时算力**：双臂 QP + 策略前向在嵌入式平台可能超周期，采用事件触发（仅当 `|h-h_min|` 或动作变化超阈值时重算）。

## 3. 关键算法伪代码

```python
# IP-234 WCD：扳手分解与合成
class WrenchCoordinationDecomposer:
    def decompose(self, w_ext, G):
        G_pinv = pinv(G)
        w_task = -G_pinv @ w_ext
        N = np.eye(12) - G_pinv @ G          # G @ N == 0
        return w_task, N

    def to_torque(self, w, q, J, g):
        return J.T @ w + g(q)


# IP-235 CEE：包络裕度
class CoordinationEnvelopeEstimator:
    def margin(self, q, z, w_task, N, J, g):
        w = w_task + N @ z
        slacks = (self._friction_slacks(w)
                  + self._torque_slacks(J.T @ w + g(q))
                  + self._joint_slacks(q)
                  + [self._self_collision_slack(q)])
        j = argmin(slacks)
        return slacks[j], self._constraint_grad(j, q, w) @ N


# IP-236 ESP：证书保持投影
class ExplorationSafetyProjector:
    def project(self, a, h, grad_h, h_min, alpha_cbf, r):
        if grad_h @ a + alpha_cbf * (h - h_min) >= 0 and norm(a) <= r:
            return a
        return solve_qp_min_norm(a, grad_h, alpha_cbf * (h - h_min), r)


# IP-239 DCR：双通道风险缩放
class DualChannelRiskScaler:
    def scale(self, R, h, h_star=1.0):
        lam_t = clip(1 - 0.6 * R, 0.3, 1.0)
        lam_i = clip(1 + 0.5 * R + 0.3 * max(0, h_star - h) / h_star, 1.0, 1.5)
        return lam_t, lam_i


# IP-240 CAF：协调归因
class CoordinationAttribution:
    H = ['D0', 'D1', 'D2', 'D3', 'D4', 'D5']

    def attribute(self, rho, w_int, s_slip, tau, G, q):
        lik = {'D0': 1.0,
               'D1': slip_likelihood(s_slip, w_int),
               'D2': imbalance_likelihood(tau),
               'D3': saturation_likelihood(w_int, tau),
               'D4': desync_likelihood(rho),
               'D5': singularity_likelihood(G, q)}
        return normalize({d: lik[d] * self.prior[d] for d in self.H})


# IP-241 CRC：双臂认证前缀
class CertifiedRedundancyPrefix:
    def certified_prefix(self, A, tau, joint_post, h_hist, h_min, S_hist, S_min, G_hist):
        k_best = 0
        for k in range(1, len(A) + 1):
            if (h_hist[k - 1] >= h_min
                    and S_hist[k - 1] >= S_min
                    and rank(G_hist[k - 1]) == 6):
                k_best = k
            else:
                break
        return k_best


# IP-243 CRADLE 闭环
def CRADLE_round(M, obs):
    x_prime, A, joint_post, R = M.ras_forward(obs)

    w_ext = M.task.desired_wrench(x_prime)
    G = M.grasp.matrix(M.q, M.object_pose, M.contacts)
    w_task, N = M.wcd.decompose(w_ext, G)
    z0 = M.load_balance.solve(w_task, G)

    h, grad_h = M.cee.margin(M.q, z0, w_task, N, M.J, M.g)
    lam_t, lam_i = M.dcr.scale(R, h)

    a = M.rpo.act(M.obs_to_state(obs, h))
    B = max(0.0, h - M.h_min)
    a_safe = M.esp.project(a, h, grad_h, M.h_min, M.alpha_cbf, M.kappa * B)

    w_cmd = lam_t * w_task + lam_i * (N @ (z0 + a_safe))
    tau_cmd = M.wcd.to_torque(w_cmd, M.q, M.J, M.g)
    k_cr = M.crc.certified_prefix(A, tau_cmd, joint_post,
                                  M.h_hist, M.h_min, M.S_hist, M.S_min, M.G_hist)

    D_post = M.caf.attribute(M.residual_log, N @ (z0 + a_safe), M.slip, tau_cmd, G, M.q)
    if M.audit.trip(M.slip, h, M.h_hist):
        M.rpo.freeze(); B = 0.0; M.cee.recalibrate()
        w_cmd = lam_t * w_task + lam_i * (N @ z0)
        tau_cmd = M.wcd.to_torque(w_cmd, M.q, M.J, M.g)

    J = M.cert.build(joint_post, lam_t, lam_i, h, B,
                     D_post, M.rpo.hash, M.cee.version)
    return k_cr, lam_t, lam_i, h, a_safe, D_post, J
```

## 4. 推导

**引理 11（双通道安全前沿）** `S(λ) = μλ_int N - λ_task||F_t|| ≥ S_min ⇔ λ_int ≥ (S_min + λ_task||F_t||)/(μN)`。标量缩放 `λ_task=λ_int=λ` 时 `S=λS_0`，只要 `λ < S_min/S_0` 就必然违反滑移约束。故 RAS 的标量 `λ_risk` 不是双臂的合法风险算子。

**引理 12（内力的任务不可见性与探索隔离）** `G(Nz)=0`，故任意内力残差不改变物体位姿、外力与任务证书。`dim ker(G)=12-rank(G)=6`（双 6 维刚性抓取）。把 RL 动作限制在 `ker(G)`，任务最优子空间不变，有效探索维数 12→6。

**定理 11（证书保持探索的前向不变性）** 若 `h_0≥h_min` 且每步经 ESP 投影，则 `h_{t+1} ≥ (1-α_cbf)h_t + α_cbf h_min ≥ h_min`。投影可行（`a'=0`）且最小范数解唯一。故探索期包络约束零违规。

**定理 12（样本复杂度与子最优界）** 冗余隔离下有效动作维数 `d_int`，`ε`-最优样本复杂度 `O(d_int/(ε²(1-γ)³))`；相对 `C` 上不受限 12 维最优解的差距满足 `J* - J_CRADLE ≤ g_comp + L_r κ B_0`。即用最多 `κB_0` 的即时奖励换取探索期零违规。

**定理 13（Sim-to-real 证书可迁移性）** 若 `|h-ĥ| ≤ L_hδ_model` 且 `ĥ - L_hδ_model ≥ h_min`，则真机膨胀裕度仍满足 `h≥h_min`，`J_CR` 可迁移；否则必须重标定。

## 6. 本轮最大风险

**一句话**：CRADLE 的安全论证完全依赖抓取矩阵 `G` 与协调包络 `C` 的准确性，而真实接触部分不可观、物体惯量未知，RL 又最擅长在模型误差方向把探索预算花到最大——于是“证书保持的零违规探索”可能退化为对包络估计误差的定向利用：估计裕度仍为正，真实裕度已为负，物体在证书盲区里滑落。

**次级风险与缓解**：
1. **包络过乐观**：悲观包络 + 触觉/滑移独立旁路；`ĥ-L_hδ<h_min` 直接否决迁移；
2. **`G` 估计错误**：在线接触点/手眼标定，`rank(G)<6` 触发 `D5` 与再认证；
3. **RL 钻证书空子**：训练时随机化包络参数并加入对抗包络扰动课程；
4. **双通道过紧**：`λ_int` 与物体压强设硬上限，“宁可停机不压碎”；
5. **实时算力**：事件触发重算，仅在 `|h-h_min|` 或动作变化超阈值时更新 QP。
