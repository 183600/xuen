# 灵感驱动研究循环·第 1 轮；本轮灵感：「步骤分」×「移动底盘」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–439（云边同步 CESC / 少样本 FSVC / 知识产权认证 IPAM / 四证一体 HPC-E+）；其上承 v22 分层 PGEV + 机械臂 ACSC、v21 语义-规范层（SDC/CAC/DCL/GIC）、v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）。
> **本轮纪律**：不推倒 v23。CESC/FSVC/IPAM/HPC-E+/HDL/ACSC/DCSC/CFC++ 全部保留。本轮只做一件事：**把 v23 的“全对或全停”二元证书，升级为“有序步骤 + 每步校准分 + 非补偿分级”的步骤分证书；并把移动底盘的位姿-扫掠足迹-非完整可行性核补进几何层**。

## 0. 直觉与动机

### 灵感 1：步骤分 → 安全证书的部分分代数

**直觉**：考试按步骤给分：最终答案错了，前面正确的推导仍有分。安全证书却长期是“全对或全错”：v23 的 HPC-E+ 是四证连言，任一证失败就拒证或退模式。现实中的证据是**逐步累积且有程度**的——定位可能只是“有点漂”，语义覆盖可能只是“这个角落不确定”，云边同步可能只是“晚了一拍”。二元门把这些连续退化全部压成一次 SafeStop，正是 v23 最大风险“共振崩塌”的来源。

**反直觉点**：部分分不能把安全分数相加。加权求和会让“便宜的步骤”补偿“关键步骤”的失分，等于允许用高置信语义去抵消不可靠位姿——这是灾难。正确做法是沿**安全关键性排序做非补偿分级**：后面的步骤只有在前面（更关键）的步骤及格后才计分；等级只映射为**活性预算**（速度、工作空间、接近权限）与**安全裕度膨胀**，绝不映射为“允许更靠近障碍”。于是“部分分”永远只会让机器人更保守，而不会让它更激进。

**严谨定义**：设证书步骤集 `S={0,…,m}`，每步产出原始分 `s_i∈[0,1]` 与其 split-conformal 下界 `L_i`，使 `P(s_i ≥ L_i) ≥ 1−α_i`；取 `α_i=α/m`，由并集界得 `P(∀i: s_i ≥ L_i) ≥ 1−α`。按关键性排序 `π`（`π(0)` 最关键），定义等级

```
G(c) = max{ k ∈ {0,…,m} : ∀ j ≤ k,  L_{π(j)} ≥ θ_{π(j)} },   c=(L_0,…,L_m)
```

模式族满足 `M_0 ⊆ M_1 ⊆ … ⊆ M_m ⊆ Exec_v23`，活性预算 `ρ(G)` 单调不减，裕度膨胀 `h(ρ)=1+κ(1−ρ)` 单调不增。准入集

```
Exec_v24(c) = Exec_v23(h(ρ(G(c)))) ∩ { π : activity(π) ≤ ρ(G(c))·A_max }
```

**非补偿性**：`G` 是有序阈值/字典序，不是 `Σ w_i L_i`；任一关键步骤跌破阈值，`G` 立即降级，其他步骤再高也无法补回。

### 灵感 2：移动底盘 → 位姿-扫掠足迹-非完整可行性核

**直觉**：v21/v22 的几何证书基本把机器人当“会动的点 / 静态足迹 + 机械臂配空间”。移动底盘一加入，三件事变了：足迹是**扫掠体**（随时间扫过一片区域）、位姿有**漂移与打滑**（真实足迹可能整体错位）、运动受**非完整约束**（差速/阿克曼不能横移，能停住的距离与方向受限）。“安全”不再只是“当前位置不碰”，而是“我还在一个能刹住、能靠站、能退出人区的**可行性核**里”。

**反直觉点**：底盘安全的核心量不是距离，而是**速度**。速度越快，制动距离越长，可行性核越小；同一个速度既决定活性，又决定安全边界。因此移动底盘的物理量天然适合做“步骤分”的参数：每一步的分数最终都可以折算成“当前允许多大的速度 / 多近的接近”。

**严谨定义**：位姿真值 `ξ ∈ Ξ(ξ̂) = { ξ : ‖ξ−ξ̂‖_Σ ≤ ε_ξ }`。足迹 `F(q)` 含底盘多边形、载荷与臂扫掠体。扫掠足迹

```
S_T = ⋃_{t∈[0,T]} ( R(θ(t))·F(q(t)) + p(t) ) ⊕ B_{ε_ξ + ε_slip(t) + ε_track(t) + ε_sample}
```

`CertBox_base = S_T`，且 `Obs_t ⊇ S_T`。非完整可行性核

```
K_viab = { (ξ,v) : ∃ u(·) 满足非完整/加速度约束，在 T_stop 内到达 Safe 且不进入 Obs }
```

工程上采用保守、可审计的充分条件：

```
NVK(ξ,v) ⇔ C(ξ,v) ∩ Obs = ∅  ∧  E_res ≥ E_brake(v) + E_margin
```

其中 `C(ξ,v)` 是沿航向的制动扫掠走廊，`d_brake(v)=v·τ_react + v²/(2·a_brake)`。`NVK` 是**硬约束**：与步骤分无关，分数再高也不能补偿不可行。

### 灵感 3：二者如何统一

移动底盘的执行链天然是**有序步骤**：

```
0 定位(位姿界) → 1 足迹(载荷/打滑膨胀) → 2 可行性核(制动/靠站)
→ 3 能量(底盘+臂) → 4 规范(DCL) → 5 语义/负信息(CAC/SDC)
→ 6 云边/少样本/IP(CESC/FSVC/IPAM)
```

步骤分给每一步一个**校准过的分数与可审计的失分记录**；移动底盘给每一步**物理含义与硬约束**。统一为 **Step-Graded Mobile-Base Certificate (SGMBC)**：

- 每步分数只决定“我还能保留多少活性”；
- 每步硬约束（足迹包含、NVK、F 规则、能量不变量）始终是硬门；
- 分级模式 `M_G` 是嵌套的安全阶梯，替代 v23 的二元 SafeStop。

这样既保留 `Exec_v24 ⊆ Exec_v23`，又把 v23 的“共振崩塌”改造成“逐级降档”。

## 1. 研究问题（轮次升级版）

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 步骤分非补偿律（Step-Score Non-Compensation）**
证书等级沿安全关键性排序做有序阈值/字典序聚合，禁止跨关键步骤的加权求和补偿；部分分只映射为活性预算 `ρ(G)` 与裕度膨胀 `h(ρ)`，`ρ` 单调不减、`h` 单调不增；`Exec_v24(c)=Exec_v23(h(ρ(G))) ∩ {activity ≤ ρ(G)·A_max}`。

**P44 底盘位姿-足迹单调律（Base Pose-Footprint Monotonicity）**
`ε_ξ、ε_slip、ε_track、ε_sample` 与载荷不确定度只增不减地膨胀 `S_T`；任何标定失效使 `Obs` 只增、`v_max` 只降；`F(q)` 变化必须重算 `S_T`，禁止复用旧足迹。扫掠足迹是位姿不确定集上的并集，而非单点足迹。

**P45 非完整可行性核律（Nonholonomic Viability Kernel）**
任何被准入的计划必须满足 `(ξ,v) ∈ K_viab`：存在满足非完整约束、加速度限制与能量储备的到 `Safe` 的轨迹；`NVK` 是硬约束，不可被步骤分补偿；不可行即拒绝或降为原地制动。

**P46 分级可审计律（Graded Auditability）**
每步分数、校准集版本、阈值、等级、触发步骤写入 Merkle 步骤账本；重校准以新账本版本生效，禁止就地改写历史；模式切换携带时间戳与滞回带。

## 3. 与基线的接口（如何退化）

- 步骤分校准器失效 ⇒ 退化为 v23 二元门（`G∈{0,m}`），更保守；
- 底盘证书失效 ⇒ 最大膨胀 `S_T` + 最低速度，等价/更保守于 v23；
- `NVK` 不可计算 ⇒ 只允许原地制动（`v=0`），子集；
- 分级映射失效 ⇒ 全落 `M_0`（SafeStop）；
- 云边/少样本/IP 任一步失败 ⇒ 只降对应等级，不再整链 SafeStop；
- 全失效 ⇒ 完全回退 v23，`Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v20`。
- **安全继承**：`M_G` 嵌套且 `⊆ Exec_v23`；分数下降只使 `G` 下降、`ρ` 下降、`h` 上升 ⇒ 执行集单调收缩。

## 4. 预期贡献

1. **步骤分证书代数**：有序步骤 + 每步 conformal 下界 + 非补偿分级 + 并集覆盖界，首次把“部分分”形式化为**只买活性、不买安全**的证书；
2. **移动底盘扫掠足迹证书**：位姿/打滑/里程计/载荷/臂姿态联合膨胀，给出 `S_T` 的 ≥1−δ 包含性；
3. **非完整可行性核**：把“停得住 / 靠得上 / 退得出”变成可审计的 backward-reachable 硬约束；
4. **分级活性调节器**：把 v23 的二元 SafeStop 改为嵌套安全阶梯，直接封堵“共振崩塌”；
5. **步骤审计账本**：失分可定位到具体步骤与校准版本，支持事后诊断与合规审计；
6. **统一门 HPC-E++**：`Exec_v24 ⊆ Exec_v23` 闭环，且任意单点失效只降档、不越界。

## 5. 本轮最大风险

**一句话**：步骤分的在线校准漂移与移动底盘的位姿/打滑漂移会同向叠加——每一步的分数都“及格”，但足迹已经整体错位，形成“满分的错位”式假自由空间。

## 1. 关键算法骨架

```python
# ============================================================
# IP-440 Step-Scored Certificate Algebra (SSCA)
# ============================================================
@dataclass
class StepCredit:
    name: str
    raw_score: float          # s_i ∈ [0,1]
    lower: float              # L_i：split-conformal 下界
    alpha: float              # α_i
    calib_version: str        # 校准集/账本版本

class StepScoredCertificateAlgebra:
    def __init__(self, order: list[str], theta: dict[str, float],
                 rho_table: dict[int, float], kappa: float = 0.5,
                 alpha_total: float = 0.05):
        self.order = order              # π：关键性从高到低
        self.theta = theta              # 每步及格阈值
        self.rho_table = rho_table      # 等级 -> 活性预算
        self.kappa = kappa
        self.alpha_total = alpha_total

    def calibrate(self, stage: str, calib_scores: list[float]) -> float:
        """split-conformal 下界：L = 1 - q_{1-α_i}(1 - s)。"""
        m = len(self.order)
        alpha_i = self.alpha_total / m          # 并集界分摊
        n = len(calib_scores)
        if n < 30:
            return 0.0                          # 校准不足 -> 不给分（保守）
        k = math.ceil((n + 1) * (1 - alpha_i))
        k = min(max(k, 1), n)
        sorted_nc = sorted(1.0 - s for s in calib_scores)
        return 1.0 - sorted_nc[k - 1]

    def grade(self, credits: dict[str, StepCredit]) -> int:
        """有序阈值分级：后面的步骤只有前面（更关键）全过才计分。"""
        G = 0
        for j, stage in enumerate(self.order):
            if credits[stage].lower >= self.theta[stage]:
                G = j + 1
            else:
                break
        return G

    def activity_budget(self, G: int) -> float:
        return self.rho_table[G]

    def margin_inflation(self, rho: float) -> float:
        return 1.0 + self.kappa * (1.0 - rho)


# ============================================================
# IP-441 Mobile Base Swept-Footprint Certificate (MBSFC)
# ============================================================
class MobileBaseSweptFootprintCertificate:
    def __init__(self, base_poly, arm_fk, pose_calib, slip_model,
                 delta: float = 1e-3, n_sample: int = 64):
        self.base_poly = base_poly      # 底盘多边形
        self.arm_fk = arm_fk            # 臂正运动学 -> 扫掠体
        self.pose_calib = pose_calib    # conformal 位姿误差标定
        self.slip_model = slip_model    # ε_slip(v, terrain)
        self.delta = delta
        self.n_sample = n_sample

    def pose_bound(self, xi_hat) -> float:
        """位姿误差半径：P(‖ξ-ξ̂‖ ≤ r) ≥ 1-δ。"""
        return self.pose_calib.radius(xi_hat, 1.0 - self.delta)

    def footprint(self, q_arm, payload) -> Polygon:
        return convex_hull(self.base_poly,
                           self.arm_fk.swept(q_arm),
                           payload.poly)

    def swept_certbox(self, traj, q_arm_fn, T: float) -> Region:
        """位姿不确定集上的扫掠足迹；每个采样点的误差只增不减地膨胀。"""
        S = empty_region()
        for t in linspace(0.0, T, self.n_sample):
            xi = traj.pose(t)
            eps = (self.pose_bound(xi)
                   + self.slip_model.bound(traj.v(t), traj.terrain(t))
                   + traj.odom_drift(t)
                   + traj.sample_error(t))
            F = self.footprint(q_arm_fn(t), traj.payload(t))
            S = S.union(transform(F, xi).dilate(eps))
        return S    # CertBox_base

    def certify(self, traj, q_arm_fn, obs):
        S = self.swept_certbox(traj, q_arm_fn, traj.T)
        ok = not intersects(S, obs)
        return ok, S, S.area_ratio()


# ============================================================
# IP-442 Nonholonomic Viability Kernel (NVK)
# ============================================================
class NonholonomicViabilityKernel:
    def __init__(self, v_max, a_brake, tau_react, energy_model,
                 eps_base, margin=0.05, n_sweep=32):
        self.v_max = v_max
        self.a_brake = a_brake
        self.tau_react = tau_react
        self.energy_model = energy_model
        self.eps_base = eps_base
        self.margin = margin
        self.n_sweep = n_sweep

    def braking_distance(self, v: float) -> float:
        return abs(v) * self.tau_react + v * v / (2.0 * self.a_brake)

    def braking_corridor(self, xi, v, footprint) -> Region:
        """沿航向的保守制动扫掠走廊（含侧向容差 ε_base）。"""
        d = self.braking_distance(v) + self.margin
        corridor = empty_region()
        for s in linspace(0.0, d, self.n_sweep):
            pose = advance(xi, s, sign(v))
            corridor = corridor.union(
                transform(footprint, pose).dilate(self.eps_base))
        return corridor

    def viable(self, xi, v, footprint, obs, E_res) -> bool:
        C = self.braking_corridor(xi, v, footprint)
        if intersects(C, obs):
            return False
        E_need = (self.energy_model.brake_energy(abs(v))
                  + self.energy_model.stop_margin)
        return E_res >= E_need

    def emergency_mode(self, footprint, obs) -> Plan:
        """NVK 不可计算/不通过时的失效安全：只允许原地制动。"""
        return Plan(v=0.0, omega=0.0, action="brake_in_place")


# ============================================================
# IP-443 Step-Graded Execution Governor (SGEG)
# ============================================================
class StepGradedExecutionGovernor:
    def __init__(self, ssca, mode_lattice, hysteresis=0.05):
        self.ssca = ssca
        self.mode_lattice = mode_lattice   # M_0 ⊆ ... ⊆ M_m
        self.hysteresis = hysteresis
        self.last_G = 0

    def step(self, credits, exec_v23_fn):
        G_raw = self.ssca.grade(credits)
        if G_raw < self.last_G:
            G = G_raw                                   # 降级立即
        elif G_raw == self.last_G:
            G = self.last_G
        else:
            stage = self.ssca.order[self.last_G]        # 一次只升一档
            if credits[stage].lower >= self.ssca.theta[stage] + self.hysteresis:
                G = self.last_G + 1
            else:
                G = self.last_G                          # 升级滞回
        rho = self.ssca.activity_budget(G)
        h = self.ssca.margin_inflation(rho)
        self.last_G = G
        return G, rho, self.mode_lattice[G](exec_v23_fn, h, rho)


# ============================================================
# IP-444 Partial-Credit Degradation Controller (PCDC)
# ============================================================
class PartialCreditDegradationController:
    def __init__(self, ssca, safe_modes, base_cert, nvk):
        self.ssca = ssca
        self.safe_modes = safe_modes      # M_0 ... M_m
        self.base_cert = base_cert
        self.nvk = nvk

    def degrade(self, credits, obs, plan):
        G = self.ssca.grade(credits)
        # 硬约束始终检查，绝不因分数高而跳过
        fp_ok = self.base_cert.certify(plan.traj, plan.q_arm_fn, obs)[0]
        nvk_ok = self.nvk.viable(plan.xi, plan.v, plan.footprint,
                                 obs, plan.E_res)
        if not (fp_ok and nvk_ok):
            G = 0
        mode = self.safe_modes[G]
        return G, mode, self._audit(credits, G, plan)

    def _audit(self, credits, G, plan):
        return {
            "grade": G,
            "lost_steps": [s for s in self.ssca.order
                           if credits[s].lower < self.ssca.theta[s]],
            "credits": {s: asdict(c) for s, c in credits.items()},
            "plan": plan.id,
        }


# ============================================================
# IP-445 HPC-E++ Step-Graded Gate (SGG)
# ============================================================
class HPCEStepGradedGate:
    def __init__(self, hpce_plus, ssca, base_cert, nvk,
                 governor, pcdc, ledger, a_max):
        self.hpce_plus = hpce_plus
        self.ssca = ssca
        self.base_cert = base_cert
        self.nvk = nvk
        self.governor = governor
        self.pcdc = pcdc
        self.ledger = ledger
        self.a_max = a_max

    def admits(self, plan, credits, obs) -> tuple[bool, dict]:
        # 1) v23 四证门（硬）
        if not self.hpce_plus.admits(plan, plan.x, plan.v, plan.z,
                                     plan.E_res, plan.margin_req,
                                     plan.modules):
            return False, {"grade": 0, "reason": "v23_gate"}

        # 2) 底盘扫掠足迹硬约束
        fp_ok, S, ratio = self.base_cert.certify(plan.traj, plan.q_arm_fn, obs)
        if not fp_ok:
            return False, {"grade": 0, "reason": "swept_footprint"}

        # 3) 非完整可行性核硬约束（分数不可补偿）
        if not self.nvk.viable(plan.xi, plan.v, plan.footprint,
                               obs, plan.E_res):
            return False, {"grade": 0, "reason": "viability"}

        # 4) 步骤分分级：只决定活性，不决定安全
        G, rho, mode = self.governor.step(credits, plan.exec_v23_fn)
        admitted = (plan in mode) and (plan.activity <= rho * self.a_max)
        self.ledger.append(credits, G, plan.id)
        return admitted, {
            "grade": G,
            "rho": rho,
            "mode": G,
            "certbox": S,
            "footprint_area_ratio": ratio,
            "lost_steps": [s for s in self.ssca.order
                           if credits[s].lower < self.ssca.theta[s]],
        }


# ============================================================
# 步骤审计账本（P46）
# ============================================================
class StepAuditLedger:
    def __init__(self):
        self.root = GENESIS
        self.leaves = []

    def append(self, credits, G, plan_id):
        leaf = H(canonical(credits) + str(G) + plan_id + str(time.now()))
        self.root = H(self.root + leaf)
        self.leaves.append((leaf, self.root))
        return self.root

    def replay(self, leaves) -> bool:
        root = GENESIS
        for leaf in leaves:
            root = H(root + leaf)
        return root == self.root
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| SSCA 校准 | `O(n log n)` 离线 | `O(n)` | `n` 校准样本，`m=6` |
| SSCA 分级 | `O(m)` | `O(m)` | `m=6` |
| MBSFC 扫掠足迹 | `O(N_T·V_F log(N_T·V_F))` | `O(N_T·V_F)` | `N_T=64`, `V_F≤32` |

| SGEG 调节 | `O(m)` | `O(1)` | 滞回 0.05 |

## 3. 正确性论证

### 引理 1（每步覆盖与并集覆盖）
**陈述**：若各步校准集与测试样本可交换，则 `P(s_i ≥ L_i) ≥ 1−α_i`，进而 `P(∀i: s_i ≥ L_i) ≥ 1−Σα_i = 1−α`。

**证明**：split-conformal 的有限样本边际覆盖保证给出第一步；对 `m` 个事件取并集界得 `P(∩ A_i) ≥ 1−Σ P(A_i^c) ≥ 1−Σα_i`。取 `α_i=α/m` 即得。注意这是边际覆盖而非条件覆盖；条件覆盖需 Mondrian/自适应 conformal，见 Q1。∎

### 引理 2（等级对步骤分单调）
**陈述**：若 `c' ≤ c` 逐分量成立，则 `G(c') ≤ G(c)`。

**证明**：设 `G(c')=k`，则对所有 `j≤k` 有 `L'_{π(j)} ≥ θ_{π(j)}`。由 `L_{π(j)} ≥ L'_{π(j)}` 得 `L_{π(j)} ≥ θ_{π(j)}`，故 `G(c) ≥ k`。∎

### 引理 3（模式嵌套与执行集收缩）
**陈述**：`M_0 ⊆ M_1 ⊆ … ⊆ M_m ⊆ Exec_v23`，且 `Exec_v24(c) = M_{G(c)}`；若 `c'≤c`，则 `Exec_v24(c') ⊆ Exec_v24(c) ⊆ Exec_v23`。

**证明**：`ρ(G)` 单调不减、`h(ρ)` 单调不增，且 v23 的安全裕度单调性（P31/P37：裕度越大执行集越小）给出 `Exec_v23(h(ρ_G))` 随 `G` 增大而扩大；活动约束 `activity≤ρ_G·A_max` 亦随 `G` 增大而放宽，故 `M_G` 嵌套。`M_m` 的裕度为 `h(1)=1`、活动上界为 `A_max`，即 `Exec_v23` 本身，故 `M_m ⊆ Exec_v23`。结合引理 2 得 `Exec_v24(c')=M_{G(c')} ⊆ M_{G(c)}=Exec_v24(c)`。∎

### 引理 4（扫掠足迹包含性）
**陈述**：若对每个采样时刻 `t`，真实位姿误差 ≤ `ε_base(t)=ε_ξ+ε_slip+ε_track+ε_sample` 的概率 ≥ `1−δ_t`，则 `S_T` 包含真实扫掠足迹的概率 ≥ `1−Σ_t δ_t`。

**证明**：真实足迹在时刻 `t` 为 `transform(F(q(t)), ξ_true(t))`。若 `ξ_true(t) ∈ Ξ(ξ̂(t))`，则由 Minkowski 膨胀定义，`transform(F,ξ_true) ⊆ transform(F,ξ̂) ⊕ B_{ε_base(t)} ⊆ S_T`。对全部采样时刻取并集界即得。时间离散化误差已由 `ε_sample` 吸收；若需连续时间保证，可令 `ε_sample = ½·v_max·Δt`。∎

### 引理 5（NVK 充分性）
**陈述**：若 `C(ξ,v) ∩ Obs = ∅` 且 `E_res ≥ E_brake(v)+E_margin`，则执行最大制动可保持无碰撞并最终静止。

**证明**：`C(ξ,v)` 按 `d_brake(v)` 覆盖了整个制动过程的足迹扫掠（含反应时间与侧向容差），故制动全程不与 `Obs` 相交；能量下界保证制动所需能量可支付，最终速度为零。保守性来自：用沿航向走廊近似任意转向制动，故 `C` 是真实可达制动扫掠的超集。∎

### 定理（HPC-E++ 的可靠性与优雅降级）
**陈述**：对任意计划 `π` 与步骤分 `c`，若 `HPCEStepGradedGate.admits(π,c)=True`，则：
(1) `π ∈ Exec_v23`；
(2) `π` 满足底盘扫掠足迹包含与 `NVK` 硬约束；
(3) `Exec_v24(c) ⊆ Exec_v23`，且 `c` 逐分量下降时 `G` 与活性单调不增；
(4) 任一硬约束失败或 `NVK` 不可计算时，`G=0` 或拒证，绝不越界。

**证明**：(1)(2) 由 `admits` 的硬门与引理 4/5 直接可得；(3) 由引理 2/3；(4) 由 `PCDC` 在硬约束失败时强制 `G=0` 与 `NVK.emergency_mode`。∎
