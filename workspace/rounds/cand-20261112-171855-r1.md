# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；新灵感循环第 1 轮；本轮灵感：「伦理与合规」×「抓取」）

> 第 60 轮的 SGEC 把「场景→意图→约束→阻抗→执行→证据」串成闭环，但它所说的「安全」**只是物理安全**（净空、力闭合、摩擦锥、阻抗可行域 K_safe）。一旦机器人真的要「抓」，这个假设在最敏感的一步失效：抓取是**唯一会与外部世界（物体、人、隐私、文化物）发生不可逆物理接触**的动作，而物理上安全的抓取可以同时是**伦理上禁止、法律上违规、未经授权**的。三个结构性缺口：
> 1. **物理安全 ≠ 规范许可**：K_safe 只回答「能不能安全地抓」，不回答「准不准抓」。抓人的手臂、抓他人私有物、抓受保护文物、抓含个人数据的设备，可能全部落在 K_safe 内——系统会「非常安全地做一件不该做的事」。
> 2. **证据链只记录「发生了什么」，不记录「为何被允许」**：EPIR/EV-exec 是因果证据（时间戳-序列号-哈希），不是**正当性证据**。审计者要重建的是「哪条规则、哪个版本、谁的同意、哪级人工监督授权了这次抓取」，且要求在不可信第三方那里**防篡改可验证、隐私最小披露**。
> 3. **意图 ≠ 授权/同意**：第 60 轮 CIEC 把人话（「轻触」）映射为实时约束，却没有任何**同意与权限模型**——谁有权同意？同意范围多大？能否撤回？一句话把「行为参数」说清楚了，但没说清「行为的道德与法律资格」。更危险的是：合规一旦被写成可优化的软约束，就会被奖励/预算"优化掉"（specification gaming）。

## 0. 直觉与动机

**灵感 1（伦理与合规 → 道义抓取约束 DGC）**
直觉：物理约束是「能不能」，道义约束是「该不该」。把法律/伦理/组织规范写成**道义规则**：禁止（F）、允许（P）、义务（O）——例如「禁止抓取人类身体部位（F）」「接触人类前必须获得知情同意（O）」「抓取文物必须双人复核（O）」「不得抓取额定载荷外物体（F）」。关键洞见：**道义约束是词典序在任务奖励之前的硬闸门（hard gate），不是可以拿预算换的软惩罚**。可行抓取集应是 `N_eth(c) ∩ K_safe`：物理可行给出「能抓」，道义可行给出「可抓」，二者交集为空时必须**拒抓/升级给人**，哪怕物理 K_safe 很宽。一句话：**合规不是一个分数，是一个前置的允许性判定。**

**灵感 2（抓取 → 知情同意与授权链 GCAM）**
直觉：抓取常常需要「许可」。但许可不是布尔值，而是**带范围、目的、期限、可撤回、可委托但不可放大的能力令牌（capability token）**。授权链 A₀→A₁→…→A_k 必须**逐级收窄**：委托方不能授出自己没有的权限（无放大），范围只能缩小（单调），且执行接触瞬间要**再次核验是否被撤回**（防 TOCTOU）。关键洞见：**同意是过程而非快照**——知情同意要求披露力/时长/风险并留痕确认；撤回必须能在接触前最后一刻生效。一句话：**要带"许可证"去抓，不是"抓了再说"。**

**灵感 3（合规 → 可审计合规账本 CEL + 选择性披露）**
直觉：合规的证明责任在「被审计方」。把每一次抓取写成**追加式、Merkle 哈希链、外部锚定**的账本条目：规则版本哈希、规则求值轨迹（哪条规则命中/被优先级击败）、同意令牌哈希、人工监督哈希。关键洞见：**审计只需"可验证的正当性"，不需"看到原始隐私数据"**——用承诺 + 零知识范围证明，向审计方证明「本次抓取峰值力 ≤ 法定上限 ∧ 目标属于允许类别 ∧ 存在有效同意」而不泄露目标身份、人的身份或原始传感数据。一句话：**账本证明"为什么可以"，零知识只证明"谓词为真"。**

**灵感 4（合规的不确定性 → 人在回路监督 HOG + 规范冲突聚合 NUA）**
直觉：伦理无法完全形式化。规则会冲突（「效率」vs「保护」）、边界会模糊、场景会新颖。此时正确做法不是"猜一个"，而是**升级到人**——但"人在回路"必须满足**有意义的人类控制三元组**：有足够时间、有足够信息、有真实否决权。同时用**预防性否决（precautionary veto）**处理规范不确定性：只要任一有分量的伦理立场判「禁止」，就按禁止处理；无法裁决则**弃权（abstain）→ 安全保持**。一句话：**宁可停在原地被审计为"保守"，也不要动起来被审计为"越界"。**

**灵感 5（三灵感合流 → 合规感知抓取闭环 CAGL + PCE++++++++ + 可校验合规证书 CCC）**
直觉：把 DGC（允许性）、GCAM（授权）、CEL（可审计）、HOG/NUA（人类监督与不确定性）并入 SGEC 的抓取闭环，形成 **CAGL**：场景→意图→**规范判定→同意核验→物理编译→执行→证据→账本→证书→（必要时）人类复核**。预算扩展为 PCE++++++++，但**合规相关预算是 fail-closed 的**：审计预算耗尽 ⇒ 不能出证 ⇒ 禁止执行；监督超时 ⇒ 安全保持；隐私预算耗尽 ⇒ 减少数据或拒抓。最终每次抓取持一张**可被独立第三方验证的合规证书 CCC**。一句话：**系统可以证明自己"按规则做了"，但必须诚实地说：它不能证明"规则本身是善的"。**

## 1. 形式化定义（增量：定义 161–168）

**定义 161（道义抓取约束 DGC）** 设上下文 c = (target_class, fragility, human_presence, human_dist, required_force, data_access, purpose, jurisdiction)。道义规则 r = (ψ_r, mod_r, π_r, ref_r, ver_r)，其中 ψ_r 为条件谓词（作用于 c 与 g），mod_r ∈ {O, P, F}（义务/允许/禁止），π_r 为优先级，ref_r 为标准/法条引用，ver_r 为规则版本哈希。记命中集 Fired(g,c) = {r | ψ_r(c,g) 成立}。**规范可行集**
N_eth(c) = { g ∈ SE(3)×K | ∄ r∈Fired: mod_r=F，且 ∀ r∈Fired: mod_r=O ⇒ satisfied_r(g,c) }。
决策为**词典序**：`max reward(g)  s.t.  g ∈ N_eth(c) ∩ K_safe`。规定：
- **硬闸门公理**：任何预算、任何奖励、任何时间压力都不得把 g∉N_eth(c) 变为可执行；
- **规范残差** ρ_eth(g,c) 只用于**升级/解释**，绝不进入目标函数做"优化"（避免把合规当 reward shaping）；
- 若 N_eth(c) ∩ K_safe = ∅ ⇒ 返回 `NO_PERMISSIBLE_GRASP` 并升级。

**定义 162（知情同意与授权链 GCAM）** 同意令牌 τ = (grantor, grantee, scope S, purpose p, issued, expiry, revocation_id, disclosure_hash, comprehension_attestation, sig)。授权链 D = (τ₀,…,τ_k)，τ₀ 为权限根。**有效** iff：
1. 签名逐级可验（unforgeability）；
2. **单调收窄**：S_i ⊆ S_{i-1} 且 p_i ⊆ p_{i-1}（无权限放大）；
3. 未过期、未撤回：`now ≤ expiry` 且 revocation_id ∉ Revoked(now)；
4. 目的匹配：purpose(c) ∈ p_k；
5. 若为人体接触：disclosure_hash≠∅ ∧ comprehension_attestation=true（知情同意）。
**TOCTOU 防护**：在 `pre_contact` 与 `during_contact` 两处复核 3–5；撤回延迟上界 τ_revoke，要求 `τ_revoke ≤ τ_contact_approach`，否则降速接近直至复核完成。

**定义 163（可审计合规账本 CEL）** 账本 L 为哈希链，条目 e_t = (payload_t, rule_version_hash, trace_hash, consent_hash, oversight_hash, h_{t-1})，h_t = H(e_t)，周期性地把 h_t 锚定到外部时间戳/存证服务。**防篡改**：改动任一 e_t 会破坏其后所有 h。**选择性披露**：对隐私字段做承诺 `Cm = Commit(target_id, human_id, force, raw_sensor; r)`，审计方只收 `π_ZK`，证明谓词
`P = (force ≤ F_limit) ∧ (target_class ∈ Allowed) ∧ (∃ valid consent) ∧ (entry ∈ anchored_root)`，
而不打开任何承诺。规定**最小披露原则**：默认只证谓词，不传原始数据。

**定义 164（人在回路监督 HOG）** 监督策略在以下情形升级：`status ∈ {ABSTAIN, CONFLICT}`、`stakes ≥ θ_s`、`confidence < θ_c`、`novelty > θ_n`、或涉及人体接触。要求**有意义人类控制三元组** MHC = (τ_ov, info, auth)：监督者须有响应时间 τ_ov、可理解的信息 info（含备选与反事实）、真实否决权 auth。若无人在 τ_ov 内响应 ⇒ **HOLD（fail-closed）**。系统必须显式**指派责任主体**，禁止把责任塌缩到操作员（moral crumple zone）；高stakes场景要求主动确认而非默认勾选，以抑制自动化偏见。

**定义 165（规范不确定性聚合 NUA）** 给定一组伦理立场 Σ={σ_i} 及权重 w_i（如"预防原则""自主性优先""效率优先"）。先做可废止（defeasible）优先级/特异性裁决；若仍冲突：
- **预防性否决**：若存在 w_i ≥ θ_w 的 σ_i 判 Forbidden ⇒ 聚合结果 Forbidden；
- 否则按加权多数判 Permitted；
- 若仍无多数 ⇒ **Abstain**（交 HOG）。
聚合必须**可解释**：输出每个立场的判定与权重，供审计。

**定义 166（合规感知抓取闭环 CAGL）** 算子 CAGL(M, T)：
```
① 感知: 对象/目标类别/人类距离/场景（复用 SSM）
② 意图: CIEC 得行为约束 C_intent
③ DGC: c ← build_context(...); N_eth(c) ← evaluate_deontic(candidates, c)
④ GCAM: 校验授权链 D、撤回状态、知情同意（人体接触时）
⑤ 交集: A ← N_eth(c) ∩ K_safe；若 A=∅ → HOG(NO_PERMISSIBLE_GRASP)
⑥ 物理编译: 对 g∈A 用 GIC/EEIS 得 K_g（承接第60轮）
⑦ 选择: 词典序 max reward s.t. g∈A（合规不可交易）
⑧ HOG: 若需升级 → 请求人类，超时 HOLD
⑨ 执行: CLEP 闭环；pre/during contact 复核同意
⑩ 证据: EPIR.append(EV-exec)；CEL.append(条目 + 规则轨迹 + 同意 + 监督)
⑪ 证书: CCC ← build_certificate(...)；若 B_audit 不足 → 不出证、禁止执行
⑫ Return: (g*, K*, CCC, N_eth 轨迹, ledger_root, status)
```

**定义 167（PCE++++++++ 合规预算）** B = (B_cog, B_grasp, B_view, B_norm, B_consent, B_audit, B_oversight, B_privacy)。
- B_norm=(Rule_eval_ops, Rule_cache)：耗尽 ⇒ 用**已缓存的保守规则集**，不得放宽；
- B_consent=(Verify_ops, Revocation_checks)：耗尽 ⇒ 无法确认授权 ⇒ 拒抓；
- B_audit=(Ledger_ops, Proof_gen)：耗尽 ⇒ 不能出证 ⇒ **禁止执行**；
- B_oversight=(Human_latency, Escalation_slots)：耗尽 ⇒ HOLD；
- B_privacy=(ZK_cost, Disclosure_budget)：耗尽 ⇒ 最小化数据，若无法证明谓词则拒抓。
**Fail-closed 规则**：任一"合规关键预算"（B_consent/B_audit/B_oversight/B_privacy）耗尽都**降低**可执行集，绝不提高。

**定义 168（可校验合规证书 CCC）** J_comp = (rule_coverage, consent_validity, oversight_level, ledger_integrity, privacy_proof_ok, trace_completeness, verifier_version)。证书有效 iff 全部边缘达标且账本根与外部锚定一致。**独立验证**：给验证者 (政策哈希, 账本根, 选择性披露证明 π_ZK, 工具版本) 即可验证，无需信任执行方。**诚实性铁律**：无证明即不合规；证书只声明「在规则集 R@ver 下、凭授权链 D、经监督 L 的合规性」，**从不声明「R 本身在道德上正确」**。

### IP-161 DGC（道义抓取约束）

```python
class DeonticGraspConstraint:
    def __init__(self, ruleset, version_hash):
        self.rules = sorted(ruleset, key=lambda r: -r.priority)
        self.version_hash = version_hash

    def evaluate(self, g, c):
        fired = []
        for r in self.rules:
            if r.applies(c) and r.matches(g):
                fired.append(r)
                if r.mod == 'F':
                    return dict(status='FORBIDDEN', fired=fired)
                if r.mod == 'O' and not r.satisfied(g, c):
                    return dict(status='OBLIGATION_UNMET', fired=fired)
        return dict(status='PERMITTED', fired=fired)

    def normative_feasible(self, candidates, c):
        kept = [g for g in candidates if self.evaluate(g, c)['status'] == 'PERMITTED']
        return kept, self.version_hash

    def gate(self, candidate_set, k_safe, c):
        allowed, ver = self.normative_feasible(candidate_set, c)
        A = [g for g in allowed if g.K in k_safe]
        if not A:
            return None, 'NO_PERMISSIBLE_GRASP', ver   # 硬闸门：不降级为"偷偷抓"
        return A, 'OK', ver
```

### IP-162 GCAM（同意与授权链）

```python
class ConsentAuthorityModel:
    def __init__(self, revoked_registry, tau_revoke=0.2):
        self.revoked = revoked_registry
        self.tau_revoke = tau_revoke

    def verify_chain(self, D, now, purpose):
        if not self._root_authority(D[0]):
            return False
        for prev, cur in zip(D, D[1:]):
            if not cur.scope <= prev.scope:          # 只能收窄
                return False
            if not cur.purpose <= prev.purpose:
                return False
            if not verify_sig(cur, prev.grantee):
                return False
        tail = D[-1]
        if now > tail.expiry or tail.revocation_id in self.revoked(now):
            return False
        if purpose not in tail.purpose:
            return False
        return True

    def informed_consent_ok(self, D, human_contact):
        if not human_contact:
            return True
        t = D[-1]
        return bool(t.disclosure_hash) and bool(t.comprehension_attestation)

    def contact_time_recheck(self, D, human_contact):
        ok = self.verify_chain(D, now=time.time(), purpose=D[-1].purpose) \
             and self.informed_consent_ok(D, human_contact)
        if not ok:
            return 'REVOKED_OR_INVALID'   # 触发安全保持/脱离接触
        return 'OK'
```

### IP-163 CEL（可审计合规账本）

```python
class ComplianceEvidenceLedger:
    def __init__(self, anchor_client):
        self.chain = []
        self.anchor = anchor_client

    def head(self):
        return self.chain[-1]['h'] if self.chain else b'\x00' * 32

    def append(self, ev, rule_ver, trace, consent_hash, oversight_hash, commitments):
        payload = dict(ev=ev, rule_version=rule_ver, trace_hash=H(trace),
                       consent=consent_hash, oversight=oversight_hash,
                       commits=commitments)
        h = sha256(self.head() + canonical(payload))
        self.chain.append(dict(h=h, payload=payload))
        return h

    def prove_predicate(self, idx, F_limit, allowed_classes, policy_hash):
        e = self.chain[idx]
        return zk_prove({
            'force_commit': e['payload']['commits']['force'],
            'class_commit': e['payload']['commits']['target_class'],
            'entry_in_root': merkle_path(self.chain, idx),
            'force_le': range_proof_le(F_limit),
            'class_in': set_membership(allowed_classes),
            'policy_hash': policy_hash,
        })

    def verify(self, anchor_value):
        return merkle_root(self.chain) == anchor_value
```

### IP-164 HOG（人在回路监督）

```python
class HumanOversightGovernor:
    def __init__(self, tau_oversight=3.0, theta_stakes=0.7, theta_conf=0.6):
        self.tau = tau_oversight
        self.theta_s = theta_stakes
        self.theta_c = theta_conf

    def gate(self, status, stakes, confidence, novelty, human_contact):
        need = (status in ('ABSTAIN', 'CONFLICT')
                or stakes >= self.theta_s
                or confidence < self.theta_c
                or novelty > 0.5
                or human_contact)
        if not need:
            return 'AUTO'
        return self._request_human(status, stakes, confidence)

    def _request_human(self, status, stakes, confidence):
        resp = ask_human(timeout=self.tau,
                         info=dict(status=status, stakes=stakes,
                                   confidence=confidence,
                                   alternatives=self._counterfactuals(),
                                   veto=True))
        if resp is None:
            return 'HOLD'          # fail-closed：超时不执行
        if not resp.auth:
            return 'HOLD'
        return 'APPROVED' if resp.approve else 'REJECTED'
```

### IP-165 NUA（规范不确定性聚合）

```python
def aggregate_normative(stances, theta_w=0.3):
    verdicts = [s.evaluate() for s in stances]      # P / F / ABSTAIN
    for s, v in zip(stances, verdicts):
        if v == 'F' and s.weight >= theta_w:
            return 'FORBIDDEN', 'precautionary_veto'
    p_w = sum(s.weight for s, v in zip(stances, verdicts) if v == 'P')
    f_w = sum(s.weight for s, v in zip(stances, verdicts) if v == 'F')
    if p_w > f_w:
        return 'PERMITTED', 'weighted_majority'
    return 'ABSTAIN', 'no_majority'                 # → HOG
```

```python
def compliance_aware_grasp_loop(M, task):
    c = build_context(M.scene, task.target, M.human, task.purpose)
    cand = M.grasp_estimator.sample(task)                      # 复用第60轮
    A, st, ver = M.dgc.gate(cand, M.eeis.k_safe, c)
    if A is None:
        return M, HOG_decision(M.hog, 'NO_PERMISSIBLE_GRASP', c)
    if not M.gcam.verify_chain(task.authority, now=time.time(), purpose=task.purpose):
        return M, HOG_decision(M.hog, 'NO_CONSENT', c)
    if not M.gcam.informed_consent_ok(task.authority, c.human_contact):
        return M, HOG_decision(M.hog, 'NO_INFORMED_CONSENT', c)
    g = select_lexicographic(A, reward=task.reward)           # 合规不可交易
    dec = M.hog.gate(st, stakes=task.stakes, confidence=task.conf,
                     novelty=c.novelty, human_contact=c.human_contact)
    if dec != 'APPROVED' and dec != 'AUTO':
        return M, dec
    M, ev_exec = execute_grasp(M, g)                          # CLEP
    if M.gcam.contact_time_recheck(task.authority, c.human_contact) != 'OK':
        return M, safe_hold(M)

                        hash_consent(task.authority), hash_oversight(dec),
                        commitments(ev_exec, task))
    if M.budget.audit_left() <= 0:
        return M, 'NO_CERTIFICATE_NO_EXECUTE'
    cert = build_ccc(M.cel, root, M.policy_hash, M.dgc.version_hash)
    return M, cert
```

### IP-167 PCE++++++++（合规预算）

```python
class ComplianceBudget:
    def __init__(self, norm_ops=200, consent_ops=100, audit_ops=50,
                 oversight_slots=3, zk_budget=20):
        self.B_norm, self.B_consent = norm_ops, consent_ops
        self.B_audit, self.B_oversight = audit_ops, oversight_slots
        self.B_privacy = zk_budget

    def can_execute(self):
        return (self.B_consent > 0 and self.B_audit > 0
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DGC | O(|R|·|Cand|) | O(|R|) | 硬闸门：F 规则命中即排除；O 未满足即排除 |
| GCAM | O(k) 链验证 + O(1) 撤回查询 | O(k) | 单调收窄防放大；接触前/中双复核防 TOCTOU |
| CEL | O(1) 追加摊销 / O(log N) 证明 | O(N) | 哈希链防篡改；零知识只暴露谓词真值 |
| HOG | O(1) 判定 + τ_ov 等待 | O(1) | 超时 fail-closed；MHC 三元组 |
| NUA | O(|Σ|) | O(|Σ|) | 预防性否决：少数有分量禁止即禁止 |
| CAGL | 上述之和 | 复用 | 合规不可被奖励/预算交易；无证不执行 |

**正确性定理（CGEC，Compliance-Grasp Evidence Certificate）**：
假设 **A66**（规则集 R@ver 被忠实编码并版本锁定；注意：只保证"符合 R"，不保证"R 在道德上正确"）、**A67**（签名不可伪造，授权链严格单调）、**A68**（哈希抗碰撞且账本已外部锚定）、**A69**（监督者在 τ_ov 内可用且拥有真实否决权）、**A70**（合规关键预算单调消耗）、**A71**（零知识证明满足可靠性与零知识性）、**A72**（物理层 K_safe 与执行证据如第 60 轮假设成立）。则：
1. **规范闸门可靠性**：若 N_eth(c) ∩ K_safe = ∅，则系统返回 NO_PERMISSIBLE_GRASP，且不存在任何经由预算/奖励绕过该闸门的执行路径（词典序 + 硬闸门公理）。
2. **授权可靠性**：CCC 中 consent_validity=true ⇒ 授权链逐级签名有效、范围单调不放大、未过期未撤回、目的匹配、人体接触时知情同意成立。
3. **防篡改与可审计**：账本任一条目被修改 ⇒ 其后哈希链断裂 ⇒ 验证失败（概率 ≥ 1−2^{-k}）；第三方凭 (政策哈希, 锚定根, π_ZK, 版本) 可独立重建"为何被允许"。
4. **隐私最小披露**：验证者从 π_ZK 仅获得谓词 P 的真值，不获得目标身份、人的身份或原始传感数据（零知识性）。
5. **Fail-closed 活性**：任一合规关键预算耗尽、或监督超时、或接触期同意失效 ⇒ 均导向 HOLD/拒抓，绝不导向更宽松的执行。

**推论（合规 ≠ 伦理）**：上述定理只保证「相对于规则集 R 的合规性」。若 R 本身有偏、缺失或过时，系统会**自信地、可审计地做错事**——这是本方案不能自我消解的边界，必须靠规则来源治理与外部伦理复核。

## 5. 本轮最大风险

**一句话**：本方案能证明「系统严格遵守了编码进去的规则集 R」，却**无法证明 R 本身合乎伦理**——若规则有偏、缺失或被利益方篡改版本，「合规证书」会把不道德行为包装成**可审计、可验证、看起来无懈可击的正当行为**（合规洗白 / specification gaming）；必须以「规则版本哈希 + 外部伦理复核 + 预防性否决 + 无法出证即禁止执行」四重治理护栏，并始终把 CCC 的语义限定为"相对于 R 的合规"，绝不让"合规"冒名"善"。

### IP-161 DGC（道义抓取约束）

```python
class DeonticGraspConstraint:
    def __init__(self, ruleset, version_hash):
        self.rules = sorted(ruleset, key=lambda r: -r.priority)
        self.version_hash = version_hash

    def evaluate(self, g, c):
        fired = []
        for r in self.rules:
            if r.applies(c) and r.matches(g):
                fired.append(r)
                if r.mod == 'F':
                    return dict(status='FORBIDDEN', fired=fired)
                if r.mod == 'O' and not r.satisfied(g, c):
                    return dict(status='OBLIGATION_UNMET', fired=fired)
        return dict(status='PERMITTED', fired=fired)

    def gate(self, candidates, k_safe, c):
        allowed = [g for g in candidates
                   if self.evaluate(g, c)['status'] == 'PERMITTED']
        A = [g for g in allowed if g.K in k_safe]
        if not A:
            return None, 'NO_PERMISSIBLE_GRASP', self.version_hash  # 硬闸门
        return A, 'OK', self.version_hash
```

```python
class ConsentAuthorityModel:
    def verify_chain(self, D, now, purpose):
        if not self._root_authority(D[0]):
            return False
        for prev, cur in zip(D, D[1:]):
            if not (cur.scope <= prev.scope and cur.purpose <= prev.purpose):
                return False                      # 委托只能收窄，禁止放大
            if not verify_sig(cur, prev.grantee):
                return False
        t = D[-1]
        return (now <= t.expiry
                and t.revocation_id not in self.revoked(now)
                and purpose in t.purpose)

    def informed_consent_ok(self, D, human_contact):
        return (not human_contact) or (bool(D[-1].disclosure_hash)
                                       and bool(D[-1].comprehension_attestation))

    def contact_time_recheck(self, D, human_contact):
        ok = (self.verify_chain(D, time.time(), D[-1].purpose)
              and self.informed_consent_ok(D, human_contact))
        return 'OK' if ok else 'REVOKED_OR_INVALID'
```

```python
class ComplianceEvidenceLedger:
    def head(self):
        return self.chain[-1]['h'] if self.chain else b'\x00' * 32

    def append(self, ev, rule_ver, trace, consent_hash, oversight_hash, commits):
        payload = dict(ev=ev, rule_version=rule_ver, trace_hash=H(trace),
                       consent=consent_hash, oversight=oversight_hash,
                       commits=commits)

        self.chain.append(dict(h=h, payload=payload))
        return h

            'policy_hash': policy_hash,
```

```python
def aggregate_normative(stances, theta_w=0.3):
    verdicts = [s.evaluate() for s in stances]
    for s, v in zip(stances, verdicts):
        if v == 'F' and s.weight >= theta_w:
            return 'FORBIDDEN', 'precautionary_veto'
    p_w = sum(s.weight for s, v in zip(stances, verdicts) if v == 'P')
```

| E195 HOG/NUA | 升级时延；弃权校准；漏升级率；默认接受率 | P95 ≤ 3s；ECE ≤ 0.05；≤ 1%；↓50% |
| E196 端到端 | vs 第60轮：违规率、审计完整率、开销、人工介入 | 违规→0；≥ 99.9%；≤ 15%；≤ 10%/任务 |

**消融预期**：去 DGC ⇒ 违规率 ~7%；去 GCAM ⇒ 未授权接触 ~4%；去 CEL ⇒ 审计重建 0；去 HOG ⇒ 冲突场景误执行 ×5；去 ZK ⇒ 审计暴露身份/传感字段 ×N。四模块各守「该不该 / 准不准 / 证不证得出 / 拿不准时谁来」四道不同闸门。

## 5. 本轮最大风险

**一句话**：本方案能证明「系统严格遵守了编码进去的规则集 R」，却**无法证明 R 本身合乎伦理**——若规则有偏、缺失或被利益方篡改版本，「合规证书」会把不道德行为包装成**可审计、可验证、看似无懈可击的正当行为**（合规洗白 / specification gaming）；必须以「规则版本哈希 + 外部伦理复核 + 预防性否决 + 无法出证即禁止执行」四重治理护栏，并始终把 CCC 的语义限定为"相对于 R 的合规"，绝不让"合规"冒名"善"。
