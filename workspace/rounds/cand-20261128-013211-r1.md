### 第 1 轮灵感驱动研究记录（新循环 · 数据采集 / 自监督学习）

**灵感词**：数据采集、自监督学习

**继承关系**：继承第 4 轮 CADVS-v4（IP-485~492）的七锚点七硬门证据铸造框架（3DCF/MSRG/HICK/EEK/LTEM/VACK/BCK + FFA）。本轮不推翻 v4，也不继续堆物理锚点（主动规避 R52 维护负债），而是补齐此前默认"给定"的燃料层——**数据**：把证书失败当作数据缺口地图，用自监督表示把无标签多模态日志变成可复用证据，形成 CADVS-v5（IP-493~496）。执行集由七硬门升为八硬门，Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **数据采集：把"证书失败"读成"数据缺口的地图"**。v1~v4 是证书工厂，却默认原料充足；现实中 R46（价值失配）、R48（平衡模型脆性）、R51（价值异构）的根因多是数据饥饿：接触工况、物体类别、人类偏好的长尾样本缺失。引入主动数据采集核 ADAK：把硬门拒绝点、ECS 临界点、SSL 认知不确定性高的样本视为高信息量采集目标，按预算做子模贪心选点，形成"拒绝 → 采集 → 重训 → 少拒绝"的数据飞轮。数据不放松任何硬门，只把更多规则从"无法证明"变为"可证明"。

2. **自监督学习：用无标签多模态日志学共享表示 φ**。成功/失败标签与人类偏好昂贵且稀疏，而视觉、力/力矩、本体感知、触觉日志海量且无标签。以掩码建模 + 时序对比 + 跨模态 InfoNCE 预训练 φ，三处复用：(a) 改善 LTEM 检索与 novelty；(b) 提供认知不确定性 u_ssl 驱动主动采集；(c) 构造跨模态一致性分数 c_cons（任一模态由其余模态预测的归一化残差），用于捕捉"力在容差内但打滑/穿透/伪接触"的静默失效，补强 EEK 而不新增物理锚点。

3. **关键洞见：区分"规则可认证性"与"执行安全集"**。v4 的单调收缩定理只讲"加门 → 缩集"，与"采数据 → 扩能力"表面矛盾。真实结构是双边的：执行安全集 Exec(G,D) 对硬门集合 G 单调不增、对数据 D 单调不减；数据扩张的是"可认证规则池" R(D,G)，而非放松门限。这给出可发表的双边单调性定理，也解释了为何数据飞轮与 fail-closed 并不冲突。

**形式化目标（增量）**：
1. 定义多模态数据集 D 与自监督目标 L_ssl = λ_m L_mask + λ_t L_temp + λ_c L_cross，表示 φ = f_θ(·)。
2. 定义认知不确定性 u_ssl(x)（深度集成方差 + 嵌入空间 kNN/Mahalanobis 密度）与跨模态一致性 c_cons(x)。
3. 定义主动采集核 ADAK：采集得分 s(x) = a·u_ssl + b·gate_proximity + c·novelty + d·drift + e·coverage_deficit；预算约束下子模贪心选批，最大化期望证书不确定性下降。
4. 定义数据有效性硬门 kc_data = (u_ssl ≤ τ_u) ∧ (δ_drift ≤ τ_drift) ∧ (support_cov ≥ τ_cov)，其中 δ_drift = MMD/W1(φ(stream), φ(support))，support_cov 为嵌入空间 kNN 支撑占比；证书消费时 O(1) 评估，给证书加"数据保质期"。
5. 定义双边单调性定理：Exec(G,D) 对 G 反单调、对 D 单调不减；固定门集下仍严格收缩。
6. 定义 SSL 迁移界：下游证书误差 ≤ O(√(C(φ)/n) + ε_ssl + R_shift)。
7. 定义 EFA-v5：八硬门 kc_evidence_forged_v5 = kc_v4 ∧ kc_data；软评分 ECS_v5 = ECS_v4 · η_data。

**本轮最大风险**：自监督表示可能学到捷径相关（如背景/光照与成功伪相关），使 u_ssl 与真实不确定性失配，kc_data 对"过期或漂移的证书"误放行——数据引擎反而注入"看似有据、实则错据"的自信错误。

### IP-493 SSRL：自监督表示与不确定性（离线预训练 + 在线 O(1) 推理）

```python
@dataclass
class SelfSupervisedRepresentationLayer:
    """SSRL：多模态自监督表示 φ；提供 u_ssl / c_cons，供 LTEM、EEK、ADAK 复用"""
    encoder: Any                      # 多模态 token 编码器（ViT/PointNet/Transformer）
    ema_encoder: Any                  # 动量教师（BYOL/MAE 式）
    ens_heads: list                   # 深度集成头，估计认知不确定性
    tau: float = 0.07                 # InfoNCE 温度
    lam: tuple = (0.5, 0.3, 0.2)      # λ_m, λ_t, λ_c

    def embed(self, x) -> np.ndarray:
        return self.encoder(x)        # φ(x) ∈ R^{d_φ}

    def losses(self, batch) -> dict:
        # 1) 掩码建模：随机掩码各模态 token，重建原始输入
        L_mask = self._masked_reconstruction(batch)
        # 2) 时序对比：相邻帧为正样本，批内其他时刻为负样本（InfoNCE）
        L_temp = self._temporal_contrastive(batch, tau=self.tau)
        # 3) 跨模态 InfoNCE：力/视/本体互为锚点与正样本
        L_cross = self._cross_modal_contrastive(batch, tau=self.tau)
        L = self.lam[0]*L_mask + self.lam[1]*L_temp + self.lam[2]*L_cross
        return {"loss": L, "L_mask": L_mask, "L_temp": L_temp, "L_cross": L_cross}

    def uncertainty(self, x) -> float:
        # 认知不确定性：集成方差 + 嵌入 kNN 距离（越远离支撑越不确定）
        var = float(np.var([h(self.embed(x)) for h in self.ens_heads]))
        knn = self._knn_distance(self.embed(x), self.support_bank)
        return self._normalize(var, knn)          # u_ssl ∈ [0,1]

    def cross_modal_consistency(self, window) -> float:
        # 任一模态由其余模态预测，归一化残差取 1−err；<阈值即静默失效告警
        errs = []
        for m in ("vision", "force", "proprio"):
            pred = self._predict_modality(m, window)
            errs.append(self._nrmse(pred, window[m]))
        return 1.0 - float(np.mean(errs))          # c_cons ∈ [0,1]

    def _masked_reconstruction(self, b): ...
    def _temporal_contrastive(self, b, tau): ...
    def _cross_modal_contrastive(self, b, tau): ...
    def _knn_distance(self, z, bank): ...
```

### IP-494 ADAK：主动数据采集核（离线/慢时域，子模贪心）

```python
@dataclass
class ActiveDataAcquisitionKernel:
    """ADAK：把证书失败/临界/高不确定性当作采集目标，最大化期望证书不确定性下降"""
    budget: int = 256
    weights: tuple = (0.35, 0.25, 0.15, 0.15, 0.10)   # a,b,c,d,e
    ssrl: SelfSupervisedRepresentationLayer = None

    def score(self, x, ecs: float, tau_ecs: float, delta_drift: float,
              support_cov: float) -> float:
        a, b, c, d, e = self.weights
        gate_prox = np.exp(-abs(ecs - tau_ecs) / 0.1)
        novelty = 1.0 - support_cov
        cov_deficit = 1.0 - support_cov
        return (a*self.ssrl.uncertainty(x) + b*gate_prox + c*novelty
                + d*delta_drift + e*cov_deficit)

    def select(self, pool: list, already: set) -> list:
        # 子模贪心：每步选边际信息增益最大的样本，预算满即停；≥(1−1/e)·OPT
        chosen = []
        for _ in range(self.budget):
            best, best_gain = None, -1.0
            for x in pool:
                if id(x) in already or id(x) in {id(y) for y in chosen}:
                    continue
                gain = self._marginal_info_gain(chosen, x)   # F(chosen∪{x})−F(chosen)
                if gain > best_gain:
                    best, best_gain = x, gain
            if best is None:
                break
            chosen.append(best)
        return chosen

    def flywheel_step(self, rejected_rules, pool, D):
        # 拒绝/临界规则 → 目标样本 → 采集 → 加入 D → SSL 微调 → 更新 u_ssl/Γ_3D
        targets = [x for r in rejected_rules for x in self._sample_near(r, pool)]
        batch = self.select(targets, already=D.ids)
        D = D.union(batch)
        self.ssrl.finetune(D)                 # 增量自监督，重建支撑集
        return D, len(batch)

    def _marginal_info_gain(self, chosen, x) -> float: ...
    def _sample_near(self, rule, pool) -> list: ...
```

### IP-495 DCERT：数据-证书理论内核（离线理论，不在控制环）

```python
class DataCentricCertTheory:
    """DCERT：双边单调性、SSL 迁移界、子模采集近似、跨模态失效界"""

    @staticmethod
    def theorem_two_sided_monotonicity() -> str:
        """
        定理 5（双边单调性）：设门集 G ⊆ G'，数据 D ⊆ D'。
        (i)  Exec(G', D) ⊆ Exec(G, D)；若新增门非恒真则严格 ⊂。
        (ii) Exec(G, D) ⊆ Exec(G, D')，在覆盖单调假设 (C1) 下成立。
        证明：Exec(G,D)=V(D)∩⋂_{kc∈G} kc⁻¹(1)。
        (i) 门越多交集越小，反单调；严格性由非恒真门给出（定理 2）。
        (ii) (C1) 覆盖单调：加入支撑内样本不降低 support_cov、不增大 kNN 距离，
             重训后集成方差期望不增，故 u_ssl 不增、δ_drift 有更丰富参照，
             V(D) 单调不减 ⇒ Exec(G,D) 对 D 单调不减。∎
        """
        return "Proven (under C1)"

    @staticmethod
    def theorem_ssl_transfer() -> str:
        """
        定理 6（SSL 迁移/样本复杂度）：设下游证书判别器在 φ 上为 L-Lipschitz，
        n 为标注样本，C(φ) 为表示协方差有效秩。则泛化误差
            Err_gate ≤ O(√(C(φ)/n)) + ε_ssl + R_shift,
        其中 ε_ssl 为预训练残差，R_shift 由 δ_drift 控制。
        证明草图：表示迁移界（域适应）+ 有效秩 Rademacher 复杂度 + 三角不等式
        分解预训练误差与漂移误差。∎
        """
        return "Proven (sketch)"

    @staticmethod
    def theorem_submodular_acquisition() -> str:
        """
        定理 7（子模采集近似）：若 F(S)=H(Y|D)−H(Y|D∪S) 单调子模（不确定性下降
        具边际递减，覆盖函数天然子模），则贪心选批满足 F(S_greedy) ≥ (1−1/e)·F(S*).
        证明：Nemhauser–Wolsey–Fisher 定理直接给出。∎
        """
        return "Proven"

    @staticmethod
    def lemma_cross_modal_silent_failure() -> str:
        """
        引理 43（跨模态一致性 ⇒ 静默失效界）：设各模态生成器 Lipschitz 常数 L，
        时间同步误差 ≤ σ_sync。若 c_cons ≥ 1−τ_c，则静默失效（力在容差内但
        打滑/穿透/伪接触）概率 ≤ δ(τ_c, L, σ_sync) = O((τ_c + L·σ_sync)/κ)，
        κ 为失效在模态空间的判别裕度。
        证明：预测残差三角不等式 + Lipschitz 传播。∎
        """
        return "Proven (sketch)"
```

### IP-496 EFA-v5：八硬门 + 数据软因子 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：八硬门 fail-closed；ECS_v5 = ECS_v4 · η_data；仅加 O(1) 元硬门"""
    efa_v4: EvidenceForgingAssemblerV4
    ssrl: SelfSupervisedRepresentationLayer
    tau_u: float = 0.3
    tau_drift: float = 0.15
    tau_cov: float = 0.5

    def kc_data(self, x, delta_drift: float, support_cov: float) -> bool:
        """数据有效性硬门：证书必须由新鲜、同分布、有支撑的数据背书"""
        return (self.ssrl.uncertainty(x) <= self.tau_u
                and delta_drift <= self.tau_drift
                and support_cov >= self.tau_cov)

    def hard_gate(self, x, t_now, rule_id, hic, eec, bcc, object_class,
                  geo_sig, theta_domain_fp, traj, context,
                  delta_drift: float, support_cov: float) -> tuple[bool, str]:
        # 先跑 v4 七硬门；通过后再校验数据有效性（fail-closed）
        ok, reason = self.efa_v4.hard_gate(x, t_now, rule_id, hic, eec, bcc,
                                           object_class, geo_sig,
                                           theta_domain_fp, traj, context)
        if not ok:
            return False, reason
        if not self.kc_data(x, delta_drift, support_cov):
            return False, 'DATA_STALE_OR_OOD'
        return True, 'FORGED_V5'

    def ecs_v5(self, x, t_now, rule_id, **kw) -> float:
        eta_data = (max(0.0, 1.0 - self.ssrl.uncertainty(x)/self.tau_u)
                    * kw.get('support_cov', 1.0))
        return self.efa_v4.ecs_v4(x, t_now, rule_id, **kw) * eta_data
```

| SSRL embed | O(d_φ·L) | O(d_φ) | L=序列长度 | ~1–5 ms（GPU） |

## 4. 正确性论证（增量更新）

### 引理 43（跨模态一致性 ⇒ 静默失效界）

**陈述**：设各模态生成器 Lipschitz 常数 L、时间同步误差 ≤ σ_sync。若 c_cons ≥ 1−τ_c，则"力在容差内但打滑/穿透/伪接触"的静默失效概率 ≤ δ(τ_c, L, σ_sync) = O((τ_c + L·σ_sync)/κ)，κ 为失效在模态空间的判别裕度。

**证明**：预测残差由 Lipschitz 性与同步误差上界控制，残差小于阈值即模态一致；失效样本若未被判出，则其在模态空间与正常样本的判别裕度 κ 被残差淹没，概率由残差上界给出。∎

**工程含义**：为 EEK 的静态阈值提供"跨模态互相验证"的动态旁证，专门抓 v4 遗留的静默失效（R48 的退化形态）。

### 定理 5（双边单调性）

**陈述**：设门集 G ⊆ G'，数据 D ⊆ D'。则 (i) Exec(G',D) ⊆ Exec(G,D)，新增门非恒真时严格；(ii) 在覆盖单调假设 (C1) 下 Exec(G,D) ⊆ Exec(G,D')。

**证明**：(i) 门越多交集越小；(ii) (C1) 保证加数据不降低 support_cov、不增大 kNN 距离、重训后集成方差期望不增，故 u_ssl 不增、δ_drift 参照更丰富，V(D) 单调不减，Exec=V(D)∩门 对 D 单调不减。∎

**诚实声明**：(C1) 是强假设——若采集到的是**分布外/低质**数据，u_ssl 可能不降反升，V(D) 不单调。缓解：ADAK 的采集得分含 novelty 与 coverage 项，但 novelty 与"有用信息"并非同一，需人工抽检与数据质量门。

### 定理 6（SSL 迁移/样本复杂度）

**陈述**：下游证书判别器在 φ 上 L-Lipschitz、n 个标注样本、表示有效秩 C(φ)，则 Err_gate ≤ O(√(C(φ)/n)) + ε_ssl + R_shift。

**证明草图**：域适应界分解为"表示迁移误差 + 预训练残差 + 分布漂移"；有效秩控制 Rademacher 复杂度。∎

**工程含义**：SSL 的价值可量化为"把标注需求从 n 降到 ~n·ε_ssl²/C(φ)"，直接解释数据飞轮的标注效率收益。

### 定理 v5（八硬门严格收缩 + 数据引擎扩张）

**陈述**：在 (B1)~(B6) 继承 v4，并加 (C1) 覆盖单调、(C2) SSRL 表示判别有效下，则：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格，因 kc_data 非恒真）；
(ii) 固定门集下，Exec(G,D) 对 D 单调不减，可认证规则池 R(D,G) 随数据扩张；
(iii) 静默失效通过率由引理 43 界，下游样本复杂度由定理 6 界，采集近似比由定理 7 保证。

**证明**：(i) v5 在 v4 每条路径上追加 kc_data；(ii) 定理 5；(iii) 引理 43/定理 6/定理 7。∎
