# 第 1 轮（灵感循环第 1 轮；本轮灵感：「自适应控制」×「电池管理」）

> **基线**：承接产物区 v2 的 **ToolGauge**（工具契约 MTC/TCV + 摊销校准 AP-Cal + 6C 闭环 + 严格退化链）。
> **本轮概念**：**SoCGauge**（State-of-Confidence Gauge）——把「校准」从一次性摊销后验，升级为
> 带稳定性证书的**自适应闭环**；把「探测预算」从静态标量，升级为带健康管理的**可耗尽能量池**。
> 本轮纪律：先直觉后定义；每个新机制都必须能被证伪，并能退化回 ToolGauge。

## 0. 直觉：两个灵感其实在描述同一个闭环

**灵感 1（自适应控制 → 误差契约是「会漂的被控对象」）**
ToolGauge 的 AP-Cal 假设误差契约参数 θ_s 在修复后保持不变，于是「一次摊销、一次热替换」。但真实世界的 θ_s 会随材质老化、光照周期、温漂缓慢变化。控制论的第一反应是：不要重新求解，而要**在线调节**。把 θ_s 建模为随机游走 plant，把工具回执 r_k 建模为带噪观测，用带投影、死区、抗积分饱和与持续激励监测的递推估计器去跟踪它——这就是自适应控制里的自校正调节器（STR）思想。它比「重算后验」多给了一件东西：**无 PE 时的有界性证书**，而不只是概率界。

**灵感 2（电池管理 → 探测预算是「会耗尽、会老化」的储量）**
ToolGauge 的 B_tools 是一个静态预算常量，没有储备、没有退化、没有均衡。电池管理系统的语言几乎逐条可映射：
- 探测消耗能量 ↔ 放电；被动观测/免费回执 ↔ 充电；
- SoC 库仑计数 ↔ 预算账本；OCV-SoC 曲线 ↔ 「剩余预算的边际信息增益曲线」；
- 深度放电保护/储备容量 ↔ 安全关键盲区的探测保留额；
- C-rate 限制与热降额 ↔ 每秒探测速率上限与副作用风险预算；
- 电芯均衡 ↔ 盲区后验方差均衡；
- SoH/RUL ↔ 误差契约的剩余有效寿命与预测性再校准；
- 热失控保护 ↔ 「坏先验 → 多探测 → 预算耗尽 → 更不自信 → 更多探测」的正反馈熔断。

**灵感 3（合流 → SoC 的双关）**
两条线在同一个量上会师：**SoC 既是 State of Charge，也是 State of Confidence**。校准问题因此可以重述为：
> 在有限「置信电量」下，用最少的探测焦耳，把每个误差契约的置信荷电状态维持在安全带内，并在其健康度跌破阈值前安排再校准。

由此自然浮现一个具体算法：**CC-CV 探测**（恒流激进探测 → 恒压收敛维护 → 涓流抗漂移），以及一个具体风险：**假油表**（模型失配让 SoC 读数很健康，实际预算被错误耗尽）。

## 1. 可检验假设

- **H1（有界性）**：带投影 + 死区 + 抗积分饱和的自适应律，在无 PE、存在随机游走漂移时仍保持误差一致最终有界（UUB），不发散。
- **H2（收敛性）**：在持续激励窗口内，自适应估计以指数速率收敛到真参数；PE 不足时应主动「冻结 + 保守加宽」而非过拟合。
- **H3（资源安全）**：带储备与 DoD 限制的能量池满足不变式 SoC ∈ [SoC_min, 1]，安全关键盲区永不被饿死。
- **H4（调度近优）**：在边际增益凹的假设下，CC-CV 调度是能量约束下终端置信最大化的 bang-singular-bang 近最优解。

## 2. 形式化草图（先给骨架，产物区给完整版）

**定义 A（自适应计量被控对象）**
θ_{s,k+1} = θ_{s,k} + w_k，w_k ~ N(0, Q_s)；回执观测 r_k = φ_k^T θ_{s,k} + v_k，v_k 亚高斯(σ_obs²)。
θ_s 是误差契约的可辨识参数（偏置、尺度、温漂系数等），Q_s 是环境漂移强度。

**定义 B（自适应估计器 A-Box）**
θ̂_{k+1} = Proj_Θ( θ̂_k + Γ_k φ_k e_k / (1 + φ_k^T Γ_k φ_k) )，
Γ_{k+1} = λ⁻¹( Γ_k − Γ_k φ_k φ_k^T Γ_k / (λ + φ_k^T Γ_k φ_k) )，
e_k = dz_δ(r_k − φ_k^T θ̂_k)，dz_δ(x)=sign(x)(|x|−δ)_+。
初值 (θ̂_0, Γ_0) 与参考模型 θ_ref 直接复用 AP-Cal / MP-Φ；预算耗尽或回执无效时冻结更新（抗积分饱和）。

**定义 C（置信能量池 SoC）**
SoC_{k+1} = clip( SoC_k − (1/Q_ref)Σ_{i∈P_k} c_i + η_k, 0, 1 )，
其中 η_k 为免费回执的充电信用；硬约束 Σ c_i ≤ Q_ref(SoC_k − SoC_min)（DoD 限制）。
边际信息增益曲线 g(SoC) 是「OCV-SoC」类比量，假设凹且饱和。

**定义 D（健康度 SoH / 剩余寿命 RUL）**
漂移模型下 e_s(t) ~ N(μ_s, Σ_s + σ_drift² t)，SoH_s(t)=P(|e_s(t)|≤ε_sla)；
RUL_s 为 SoH 跌破 h_min 的时间；再校准安排在 RUL_s − L_lead 之前，且受循环寿命 N_cycle 约束。

**定义 E（CC-CV 调度 + 方差均衡）**
SoC < SoC_knee：以 C_max·D(T_k) 恒流探测，按单位焦耳边际增益贪心分配；
SoC_knee ≤ SoC < SoC_target：速率按 exp(−(SoC−SoC_knee)/β_cv) 衰减；
否则仅涓流维护。均衡器每轮把下一个探测分配给归一化方差最大的盲区。

**定义 F（门控与退化链）**
热替换前新增 A 门：物理投影内 ∧ Lyapunov 差分 ≤ 0 ∧ PE 状态可信 ∧ RUL > L_lead ∧ 储备充足。
任一不满足 ⇒ 不热替换；A-Box 失效 ⇒ 回退 AP-Cal；再失效 ⇒ 回退 ToolGauge/LeanGauge/MODGAUGE 原链。

## 3. 与 ToolGauge 的差异（一句话版）

| 维度 | ToolGauge v2 | SoCGauge |
|---|---|---|
| 校准 | 一次性摊销后验 | 在线自适应 + 稳定性证书 |
| 预算 | 静态 B_tools | SoC 库仑计数 + 储备 + 热降额 |
| 退化 | 无显式生命周期 | SoH/RUL 预测性再校准 + 循环寿命 |
| 公平 | 无 | 盲区方差均衡 |
| 调度 | 贪心背包 | CC-CV 近最优 |
| 失效 | 事后 P-Quarantine | 事前 RUL 门 + 事后断路双保险 |

## 4. 证伪计划（什么会杀死这个想法）

1. 若在强非平稳漂移下，自适应律的 UUB 界比「每轮重算 AP-Cal」还差，则 H1 不成立。
2. 若 PE 监测无法区分「真激励不足」与「模型失配」，冻结策略会长期锁死自适应，则 H2 不成立。
3. 若 g(SoC) 的估计误差导致 CC-CV 的能耗显著高于贪心基线，则 H4 不成立。
4. 若 SoH 的漂移模型（高斯随机游走）在真实退化（突变、非线性老化）下 RUL 预测失效，则预测性门控只是装饰。

## 5. 本轮最大风险

**一句话**：自适应律与能量池共享状态，一旦「OCV-增益曲线」或漂移模型失配，系统会**自信地把预算耗在错误的盲区上**——SoC/SoH 读数健康、实际置信却在流失，形成「假油表」，把 ToolGauge 原有的 AP-Cal 分布偏移风险放大成跨盲区的系统性资源错配。

# 本轮产物 · 创新点清单 v3：**SoCGauge**（State-of-Confidence Gauge — Adaptive-Control Metrology with a Health-Managed Probing Reservoir）

> 背景：承接产物区 v2 的 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其下依次为 LeanGauge、MODGAUGE。本轮灵感：「自适应控制」×「电池管理」。
>
> **基线继承**：ToolGauge 的 D-Box / L-Box / T-Box / MP-Φ+AP-Cal / TCV / 6C 闭环全部保留；
> MODGAUGE 五不变式与 4CV 骨架不动；50Hz 数值路径零改动。
> 本轮只做两件事：把「校准」改成带稳定性证书的在线自适应；把「预算」改成带健康管理的能量池。
> SoCGauge 是增强层，不是新依赖：任一新模块失效都沿严格退化链回落。

## 2. 形式化定义（要点）

**定义 432（自适应计量被控对象）** 对每个盲区 s，误差契约参数满足 θ_{s,k+1} = θ_{s,k} + w_k，w_k ~ N(0,Q_s)；工具回执给出 r_k = φ_k^T θ_{s,k} + v_k，v_k 为亚高斯(σ_obs²)。Q_s 刻画环境漂移强度，Q_s→0 退化为 ToolGauge 的静态假设。

**定义 433（A-Box 自适应估计器）** 令 dz_δ(x)=sign(x)(|x|−δ)_+，
θ̂_{k+1}=Proj_{Θ_phys}(θ̂_k + Γ_k φ_k e_k/(1+φ_k^TΓ_kφ_k))，e_k=dz_δ(r_k−φ_k^Tθ̂_k)；
Γ_{k+1}=λ⁻¹(Γ_k − Γ_kφ_kφ_k^TΓ_k/(λ+φ_k^TΓ_kφ_k))，0<λ≤1。
抗积分饱和：预算耗尽、回执无效、或前置失败时令 e_k:=0 且 Γ_{k+1}:=Γ_k（冻结，不累积错误能量）。
投影 Proj 把 θ̂ 限制在物理可行域（偏置非负、尺度为正、温漂系数有界）。

**定义 434（参考模型与初值）** θ_ref、Γ_0 = Σ_prior⁻¹ 由 MP-Φ 供给；MRAC 参考轨迹取 e_ref(t)=e_0·exp(−t/τ_ref)。AP-Cal 的角色从「求解器」降为「初始化器 + 回归失败时的兜底」。

**定义 435（持续激励 PE 监测）** 在长度 N_pe 的滑动窗口上 Φ_k=Σ_{j=k−N_pe+1}^k φ_jφ_j^T。若 Φ_k ⪰ α_pe I 则称窗口 PE；否则 A-Box 冻结更新并把 Σ_post 保守加宽 κ_pe·I。PE 判定与「模型失配」用互相独立的统计量，避免把失配误判为激励不足。

**定义 436（Lyapunov 证书与可允许集）** V_k=ẽ_k^TΓ_k⁻¹ẽ_k，ẽ_k=θ̂_k−θ_{s,k}。热替换要求 ΔV_k ≤ 0 或 V_k 已落入噪声球 B_δ；否则判为「未收敛」。

**定义 437（置信能量池 SoC）** SoC_{k+1}=clip(SoC_k−(1/Q_ref)Σ_{i∈P_k}c_i+η_k,0,1)；
硬约束 Σ_{i∈P_k}c_i ≤ Q_ref(SoC_k−SoC_min)（DoD 限制）；η_k 来自正常运行的免费回执。

**定义 438（OCV-增益曲线）** g(SoC)=∂(预期信息增益)/∂(焦耳)，满足 g′>0、g″<0、g(1)=g_max。它由历史（SoC, 实测收缩）回归/分段线性估计；g 的置信带进入审计。

**定义 439（安全包络）** 储备 SoC_min 与安全关键盲区保留额 R_min 不得动用；速率 |P_k|/Δt ≤ C_max·D(T_k)；
热负载 T_{k+1}=ρ_T T_k+(1−ρ_T)R_side(P_k)，降额 D(T)=clip(1−(T−T₀)/(T_trip−T₀),0,1)；
熔丝：SoC<SoC_fuse 或 T>T_trip ⇒ 硬中断，仅保留 R_min 的只读观测。

**定义 440（SoH / RUL / 循环寿命）** 漂移模型下误差 e_s(t)~N(μ_s, Σ_s+σ_drift²t)，
SoH_s(t)=1−Φ((ε_sla−|μ_s|)/√(Σ_s+σ_drift²t))；RUL_s 为 SoH 跌破 h_min 的时间；
再校准安排在 t*_s=RUL_s−L_lead 之前。每次热替换消耗 1/N_cycle 的循环寿命，SoH_cycle<0 ⇒ 该契约退役并强制全量重标定。

**定义 441（盲区方差均衡）** v_s=tr(Σ_s)/tr(Σ_ref)；目标是 min max_s v_s。每轮把下一个探测分配给 argmax_s v_s（max-gap 均衡），并对安全关键盲区加权。

**定义 442（CC-CV 探测调度）** 若 SoC<SoC_knee，速率 u=C_max·D(T)，按单位焦耳边际增益 g(SoC_s)·w_s/c 贪心分配；
若 SoC_knee≤SoC<SoC_target，u=C_max·D(T)·exp(−(SoC−SoC_knee)/β_cv)（收敛维护）；
否则 u=C_float（涓流）。切换面由 g 的估计与储备约束共同确定。

**定义 443（6C-A 闭环）** H（共形假设）→ C（TCV 编译）→ E（执行）→ C（AP-Cal 初始化 + A-Box 在线更新）→ V（独立回执交叉验证）→ **A（A/G 五元门）** → U（热替换 + 证书绑定）。

**定义 444（严格退化链）** 条件序列：A-Gate 任一失败 ⇒ 不热替换并保留旧契约；
A-Box 连续 K 次 PE 失败或 ΔV>0 ⇒ 回退 AP-Cal；AP-Cal 失败 ⇒ ToolGauge 贪心；ToolGauge 失败 ⇒ LeanGauge；LeanGauge 失败 ⇒ MODGAUGE。退化只允许单向向下。

**定义 445（证据绑定扩展）** 每条服务主张除绑定回执外，还必须绑定 (SoC_k, SoH_s, RUL_s, PE 状态, Audit_EI)；任一证据缺失则序列化时剥离主张，数值行为不变。

**定义 446（能量-信息守恒审计）** 恒等式：Q_ref(SoC_0−SoC_k)=Σ放电 c_i−Q_refΣη_i+残差。
若 |残差|/Q_ref > ε_audit，判为账本故障，冻结调度并回退静态预算。

**定义 447（失配告警）** 对新息 z_k=(r_k−φ_k^Tθ̂_k)/√(φ_k^TΓ_kφ_k+σ_obs²) 做双侧 CUSUM；连续同向漂移超过阈值 ⇒ 判为「模型失配」而非「激励不足」，触发假油表告警。

# IP-321 A-Box：带死区/投影/抗积分饱和/PE 的在线自适应
class AdaptiveBox:
    def __init__(self, theta_ref, Gamma0, lam=0.995, delta=3*SIGMA_OBS):
        self.theta = {s: theta_ref[s] for s in theta_ref}
        self.Gamma = {s: Gamma0[s] for s in Gamma0}
        self.lam, self.delta = lam, delta
        self.pe = {s: PEWindow(N_pe=20, alpha_pe=ALPHA_PE) for s in theta_ref}

    def update(self, s, phi, r, writable=True):
        if not writable:                       # 抗积分饱和：不累积错误能量
            return self.theta[s]
        e = deadzone(r - phi @ self.theta[s], self.delta)
        G, lam = self.Gamma[s], self.lam
        denom = 1.0 + phi @ G @ phi
        self.theta[s] = project(self.theta[s] + G @ phi * e / denom, THETA_PHYS)
        num = G @ phi @ phi.T @ G
        self.Gamma[s] = (G - num / (lam + phi @ G @ phi)) / lam
        self.pe[s].push(phi)
        if not self.pe[s].exciting():
            self.Gamma[s] += KAPPA_PE * np.eye(len(G))   # 保守加宽，而非过拟合
        return self.theta[s]

    def certificate_ok(self, s):
        return self.pe[s].exciting() or self.theta_in_noise_ball(s)

# IP-322 R-Box：置信能量池（电池管理类比）
class ReservoirBox:
    def __init__(self, Q_ref, SoC0, SoC_min, SoC_knee, SoC_target, C_max):
        self.Q, self.soc = Q_ref, SoC0
        self.soc_min, self.soc_knee, self.soc_target = SoC_min, SoC_knee, SoC_target
        self.C_max, self.T, self.fuse = C_max, 0.0, False

    def discharge(self, cost):
        self.soc = clip(self.soc - cost / self.Q, 0.0, 1.0)

    def recharge(self, free_receipts):
        self.soc = clip(self.soc + free_receipts / self.Q, 0.0, 1.0)

    def allowed_rate(self):
        if self.fuse or self.soc < self.soc_min:
            return 0.0
        derate = clip(1 - (self.T - T0) / (T_TRIP - T0), 0.0, 1.0)
        return self.C_max * derate

    def reserve_ok(self, s):
        return self.soc - self.soc_min >= RESERVE[s]

# IP-323 H-Box：SoH / RUL / 循环寿命
class HealthBox:
    def __init__(self, sigma_drift, eps_sla, h_min, N_cycle, L_lead):
        self.sigma_drift, self.eps_sla = sigma_drift, eps_sla
        self.h_min, self.N_cycle, self.L_lead = h_min, N_cycle, L_lead
        self.swaps = Counter()

    def soh(self, s, mu, Sig, t):
        slack = max(self.eps_sla - abs(mu), 1e-12)
        z = slack / np.sqrt(Sig + self.sigma_drift**2 * t)
        return 1.0 - norm.cdf(z)

    def rul(self, s, mu, Sig):
        slack = max(self.eps_sla - abs(mu), 1e-12)
        z = norm.ppf(1.0 - self.h_min)
        return max((slack / z)**2 - Sig, 0.0) / self.sigma_drift**2

    def gate_ok(self, s, mu, Sig):
        return (self.soh(s, mu, Sig, 0) >= self.h_min
                and self.rul(s, mu, Sig) > self.L_lead
                and self.swaps[s] < self.N_cycle)

# IP-324 B-Box：盲区方差均衡
class VarianceBalancer:
    def __init__(self, key_cells, weight):
        self.key_cells, self.weight = key_cells, weight

    def pick(self, Sig_map, k):
        score = {s: self.weight.get(s, 1.0) * np.trace(Sig_map[s]) for s in Sig_map}
        return sorted(score, key=score.get, reverse=True)[:k]

# IP-325 CC-CV 调度
def cc_cv_rate(soc, res, g):
    if soc < res.soc_knee:
        return res.allowed_rate()                       # CC：恒流激进探测
    if soc < res.soc_target:
        return res.allowed_rate() * np.exp(-(soc - res.soc_knee) / BETA_CV)
    return C_FLOAT                                       # CV/涓流：抗漂移维护

# IP-326/327：6C-A 主闭环
def socgauge_6c_a(M, s, t):
    H = M.lbox.hypothesize(s, M.dbox.R[s])
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget_left(s))
    receipts = M.tcv.execute(prog, M.env)
    M.res.discharge(sum(r.cost for r in receipts))
    M.res.recharge(free_credit(M.env))

    writable = M.res.allowed_rate() > 0 and not M.res.fuse
    for r in receipts:
        if r.valid:
            M.abox.update(s, phi(r), r.mu, writable=writable)

    mu, Sig = M.abox.theta[s], clamp_min(M.abox.posterior_cov(s), KAPPA_PHYS)
    if not M.apcal.cross_validate(mu, Sig, M.cross_receipt(s)):
        return stub_and_red(s, "cross_failed")

    gate = (M.abox.certificate_ok(s)
            and M.hbox.gate_ok(s, mu, Sig)
            and M.res.reserve_ok(s)
            and M.audit_ok())
    if not gate:
        # 不热替换；退回 ToolGauge/AP-Cal 路径
        return toolgauge_6c(M, s)

    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s)
    if not contract_regression(new_ec):
        return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.hbox.swaps[s] += 1
    bind_claims_ext(new_ec, H, prog, receipts,
                    (M.res.soc, M.hbox.soh(s, mu, Sig, 0), M.hbox.rul(s, mu, Sig)))
    M.cusum.update(innovation(receipts, M.abox))
    return True


def socgauge_round(M, obs, audio, tac, depth, det):
    # 均衡 + CC-CV 决定本轮探测目标；其余仍走 ToolGauge 异步骨架
    k = int(cc_cv_rate(M.res.soc, M.res, M.g))
    for s in M.balancer.pick(M.abox.cov_map(), k):
        if s not in M.inflight and M.res.reserve_ok(s):
            M.inflight.add(s)
            submit_async(socgauge_6c_a, M, s, M.clock.now())
    if M.cusum.mismatch():
        M.res.fuse = True                     # 假油表：先熔断，再诊断
        M.abox.freeze_all()
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导

**引理 51（无 PE 时的一致最终有界性）**
设 ‖φ_k‖≤φ_max，0<λ≤1，δ≥2 sup_k|v_k|，Θ_phys 有界。则存在 c>0 使
V_{k+1} ≤ λ⁻¹V_k − c·ẽ_{a,k}²/(1+φ_max²‖Γ_k‖) + C(δ²+tr Q_s)，
故 limsup‖θ̂_k−θ_{s,k}‖² ≤ C(δ²+tr Q_s)/((1−λ)λ_min(Γ⁻¹))。
即：即使激励不足，误差也不会发散；代价是 λ<1 带来的稳态泄漏项。

**引理 52（PE 指数收敛）**
若每 N_pe 步窗口满足 Φ_k⪰α_pe I，则存在 ρ∈(0,1)（由 α_pe、λ、φ_max 决定）使
‖θ̂_k−θ_{s,k}‖ ≤ ρ^{k/N_pe}‖θ̂_0−θ_{s,0}‖ + O(δ+√(tr Q_s))。
推论：PE 监测宁可冻结也不要在弱激励下强行更新——后者会把噪声拟合进 θ，等价于「用错档位充电」。

**引理 53（能量池安全不变式）**
若 SoC_0∈[SoC_min,1]，DoD 约束被调度器强制执行，且 η_k∈[0,η_max] 有界，
则对一切 k 有 SoC_k∈[SoC_min,1]；熔丝阈值 SoC_fuse<SoC_min 仅在账本故障时触发，故安全关键保留额 R_min 永不被普通探测侵占。

**引理 54（CC-CV 近最优）**
在 max ∫_0^T g(u(t))dt s.t. ∫_0^T u≤E, 0≤u≤C_max, g 凹增下，KKT 给出 bang-singular-bang 结构：
u*=C_max 直到切换时刻 t₁，随后进入 g′(u*)=ν 的奇异弧（即指数锥形衰减），最后为 0。
若调度器使用与真实 g 一致的分段线性估计，则 CC-CV 的终端增益与最优值之差 ≤ O((C_max·Δt)·g″·Δ²)，即网格离散误差。

**引理 55（均衡收敛）**
设每给盲区 s 增加一次探测使 v_s 至少下降 κ>0（凹增益的曲率下界），则势函数 Φ=Σ_s exp(η v_s) 在每次 max-gap 分配后至少乘以 e^{−ηκ}；
经 O((1/η)log(m/ε)) 次探测达到 max_s v_s−min_s v_s≤ε。

**引理 56（健康门控相对反应式断路器的优势）**
前瞻门在 t*_s=RUL_s−L_lead 安排再校准，把 SLA 违约概率压到 h_min+O(σ_drift L_lead/ε_sla)+模型误差；
而 P-Quarantine 需观测到连续 q 次同向偏差才动作，期间至少累积 q 次违约。故在漂移可建模时，健康门控严格减少期望违约次数；在突变退化（模型失配）时由 CUSUM 熔断兜底。
