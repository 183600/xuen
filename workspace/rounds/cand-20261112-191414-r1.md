# 第 61 轮（承接第 60 轮 SGEC「场景感知闭环」IP-153~160；新一轮灵感循环第 1 轮／全局第 61 轮；本轮灵感：「域随机化」×「传感器融合」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 把「执行层→证据层」升级为「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知闭环。但它仍建立在**四个未经审计的假设**上：
> 1. **场景先验是「点先验」，不是「世界族」**：π_scene(K|z)=N(μ_scene(z),Σ_scene(z)) 默认「场景→阻抗」的映射可由有限场景和离线标定唯一确定。真实世界的摩擦 μ、接触刚度 k_n、阻尼 c_n、物体质量、传感器安装误差都是连续变化的；一旦真机落在标定/仿真分布之外，SSM 会**更早、更自信地**收敛到错误的 K_safe——第 60 轮警示的「抽象泄漏」从执行层回移到了**先验层**。
> 2. **融合是「同步且独立」的假融合**：SSM 的 Kalman 观测与 XMC+ 的跨模态对账隐含「同源时钟、同步到达、互不相关、已校准」。真实的 RGB-D、IMU、触觉阵列、六维力、轮速是**异步、带时延、时钟漂移、相关性与标定偏置未知、含外点**的；未对齐的融合会产生**虚假的置信度**。
> 3. **SIC 置信度是自证的，不可校准**：scene_conf(z)≥τ 与 exp(−D⁺) 只是内部一致性，不是「真实 K 落在 K_safe 内」的频率保证。面对分布漂移，系统无法区分「我真不知道」与「我以为我知道」——缺少**弃权（abstention）**与**覆盖保证**。
> 4. **证据丢失只能重传，不能重建**：EPIR 用 seq+hash 保证「到达」，但节点死亡/断链时 EV-exec 丢了就是丢了；而多模态观测之间存在冗余，融合本可在**带溯源、带不确定度**的前提下重建部分证据。

## 0. 直觉与动机

**灵感 1（域随机化 → 场景先验从「点」到「包络」DRSP）**
直觉：域随机化不是「给仿真加噪声」，而是**承认现实是仿真参数族中的一个未知成员**。把接触摩擦、法向刚度、阻尼、物体质量、传感器外参/时延/标定偏置都视为 θ∈Θ_DR；场景 z 的先验不再是单个高斯，而是**随机化先验族** {π_scene(·|z,θ)}。关键洞见：**安全集合应看「随机化边缘分布」的高密度区域，而不是名义世界中的最优点**——E_DR^ε(z) 是 p_DR(K|z)=∫π_scene(K|z,θ)P_DR(dθ) 的 1−ε 最高密度区域。这样，先验在「世界不确定」时自动变宽，避免「仿真里安全、真机上灾难」。**但随机化只允许放宽先验，绝不允许放宽硬安全约束 K_safe^base。**

**灵感 2（传感器融合 → 证据把包络「收紧」而非「投票」CAF）**
直觉：融合的第一性作用不是给出一个更准的点估计，而是**对 DR 包络做可校准的收缩**。每个模态提供的是似然 L_s(K|y_s)，而不是一个必须被平均的标量；异步测量先重投影到统一时钟，标定偏置在线估计，未知相关性用协方差交叉，外点用鲁棒核抑制。关键洞见：**宽先验保证覆盖，紧证据保证锐度**——两者不是替代关系，而是**交集关系**：K_safe^WPTE = E_DR^ε(z) ∩ E_ev^τ(y) ∩ K_safe^base。若交集为空，不是「再融合一次」，而是**先验-证据矛盾（PEC）**，必须触发探测、扩随机化或弃权。

**灵感 3（域随机化 × 传感器融合 → S2R 差距雷达与保形证书）**
直觉：DR 也不能无限宽，否则 K_safe 退化为「什么都安全」。真正的裁判是**真机标定证据**：用保形预测（split conformal）在留出的「仿真-真机配对」上校准非一致性分数，得到有限样本覆盖证书；再用融合冲突与残差监测分布漂移。关键洞见：**随机化提供假设空间，融合提供反证据，保形提供频率保证**——三者构成「可证伪的鲁棒性」，而不是「更大的仿真」。

**灵感 4（三灵感合流 → DRSC 闭环）**
直觉：DRSP 给出宽包络 → CAF 给出紧证据 → WPTE 求交并签发证书 → 空集触发 PEC → SARS 把随机化预算投向「最容易失败」的 θ 区域 → 证据回填 EPIR。闭环：**随机化→包络→融合→收缩→证书→执行→证据→随机化**。核心原则是「**先验可宽，证书须紧**」。

**灵感 5（PCE+++++ → 鲁棒性预算）**
直觉：DR 采样、融合对齐、保形校准都要算力/时延。新增 B_dr（随机化样本数）、B_caf（融合与对齐时延）、B_conf（保形/漂移监测样本）。若 B_dr 耗尽⇒用缓存包络并**膨胀**；若 B_caf 耗尽⇒降级为「少模态+保守协方差」；若 B_conf 耗尽⇒固定 ε 并**禁止签发覆盖证书**（只报经验值）；若 B_exec 耗尽⇒原有降级。**不能把「没算完」伪装成「很安全」。**

## 1. 形式化定义（增量：定义 161–168）

**定义 161（域随机化场景先验 DRSP）** 随机化三元组 (Θ_DR, P_DR, Π_scene)。其中：
- **随机化参数**：θ=(θ_phys, θ_sens, θ_task)∈Θ_DR；θ_phys 含摩擦/刚度/阻尼/质量，θ_sens 含外参/时延/时钟偏置/标定偏置，θ_task 含负载/接触几何。
- **随机化分布**：P_DR 可分解、可非均匀（默认由 SARS 维护，见定义 168）。
- **场景先验族**：π_scene(K|z,θ)=N(μ_scene(z,θ), Σ_scene(z,θ))。
- **随机化边缘先验**：p_DR(K|z)=∫_{Θ_DR} π_scene(K|z,θ) P_DR(dθ)。
- **ε-包络**：E_DR^ε(z)={K : p_DR(K|z) ≥ q_ε(z)}，其中 q_ε 为最高密度阈值，使 ∫_{E_DR^ε} p_DR dK ≥ 1−ε。
- **覆盖**：Cov_DR(E,z)=P_{θ~P_DR, K~π_scene(·|z,θ)}[K∈E]；**保守度**：W(E)=Vol(E)（或 tr Cov(E)）。
- **覆盖引理（A66）**：若真实世界 θ*~P_DR 且 K_true~π_scene(·|z,θ*)，则 K_true 的边缘分布正是 p_DR，故 P(K_true∈E_DR^ε) ≥ 1−ε。**注意这是边缘保证，不是对任意 θ 的最坏情况保证**；θ* 越出 P_DR 支撑时，必须由 S2R-CP 报警（定义 164）。
- **单调性**：ε↑ ⇒ E_DR 变宽、Cov↑、W↑。ε 是「世界不确定性旋钮」，不是安全旋钮；硬约束 K_safe^base 与 ε 无关，且始终参与交集。

**定义 162（校准感知鲁棒融合 CAF）** 融合算子 F=(A_c, B_cal, Φ_rob, L_ev, κ)。其中：
- **测量结构**：m_i=(s_i, y_i, t_i^src, τ_i, c_i, b_i, Σ_i, π_i)，s_i 为模态，c_i 为时钟域，b_i 为标定偏置，π_i 为溯源标签。
- **时间对齐**：A_c(t_i)=t_i^src+τ_i+δ_c(c_i)，δ_c 为在线估计的时钟偏置；仅接受 |A_c(t_i)−t_now|≤δ_sync 的测量，其余降权或丢弃；时效权重 w_i^age=exp(−(t_now−A_c(t_i))/τ_age)。
- **标定状态**：b_i(t+1)=b_i(t)+η_i，η_i~N(0,Q_i)；由标定板/已知工装或跨模态一致性估计 b̂_i。标定健康度 h_i=exp(−‖b̂_i−b_i^nom‖²_{Σ_b})·Whiteness_i，低于 h_min 的模态退出**证据**（但仍进入安全监测）。
- **鲁棒融合**：
  ```
  x̂ = argmin_x  Σ_i w_i ρ(‖y_i − h_i(x,b̂_i)‖²_{Σ_i}) + (x−x_prior)ᵀΣ_prior⁻¹(x−x_prior)
  w_i = w_i^age · h_i / (1+κ_i)
  κ_i = max_{j≠i} d_M(y_i, y_j)        # 成对冲突，Mahalanobis 或 DS 冲突
  ρ ∈ {Huber(δ), Cauchy(γ)}            # 外点抑制
  ```
- **未知相关性**：对相关性未知的模态对使用**协方差交叉** CI(μ_i,Σ_i,μ_j,Σ_j,ω)，或把 Σ 膨胀 (1+ρ_max) 倍，保证 Σ_ev ⪰ Σ_true，避免「独立假设导致的过度自信」。
- **证据输出**：L_ev(K)=p(y_{1:M}|K,x̂,b̂)≈N(K;x̂_K,Σ_ev)；证据集 E_ev^τ={K : −log L_ev(K) ≤ τ}（二维/三维时为椭球）。
- **冲突门控**：κ=max_i κ_i；若 κ>κ_max，标记 FUSION_CONFLICT，禁止把 Σ_ev 收缩到 ρ_min 以下。
- **覆盖假设（A67）**：若 L_ev 经标定且外点/漂移门控有效，则 P(K_true∈E_ev^τ) ≥ 1−δ。

**定义 163（宽先验-紧证据 WPTE）** 给定场景 z、测量 y、随机化水平 ε、证据水平 τ：
```
K_safe^WPTE(z,y) = E_DR^ε(z) ∩ E_ev^τ(y) ∩ K_safe^base
```
- **证书**：Cert_WPTE=(ε, τ, Cov_lb, W_DR, W_ev, W_WPTE, κ, ρ_gap, status)。
- **覆盖下界（联合界）**：若 P(K_true∈E_DR)≥1−ε 且 P(K_true∈E_ev)≥1−δ，则
  ```
  P(K_true∈K_safe^WPTE) ≥ 1−ε−δ
  ```
  证书必须报告这个**保守下界**，不能报告单模态的乐观值。
- **锐度比**：η_sharp=W(WPTE)/W(E_DR)；目标 η_sharp≤ρ_sharp（证据确实在收缩），同时 W(WPTE)≥W_min（不得收缩到过度自信）。
- **PEC（先验-证据矛盾）协议**：若 K_safe^WPTE=∅，按以下顺序判别，**绝不静默回退到单证据**：
  1. 若 E_DR 或 E_ev 本身为空 ⇒ INVALID_INPUT；
  2. 增大 ε（扩随机化）后交集非空 ⇒ PRIOR_TOO_NARROW，提高 DR 支撑并重采样；
  3. 移除冲突最大的模态后交集非空 ⇒ EVIDENCE_BIASED，触发该模态重标定；
  4. 以上皆否 ⇒ GENUINE_ANOMALY，主动探测（BUQ）或弃权/请求人类确认。
- **硬约束不变量**：K_safe^WPTE⊆K_safe^base 恒成立；DR 只能改变先验的宽度，不能改变硬安全边界。

**定义 164（仿真-现实差距雷达与保形证书 S2R-CP）** 校准数据 D_cal={(z_i,y_i,K_i)}：
- **非一致性分数**：s_i=d(K_i, E_DR^ε(z_i))（或仿真预测响应与真机响应的残差）。
- **Split conformal**：q=第 ⌈(n+1)(1−α)⌉ 小的 s_i；E_conf={K : s(K)≤q}。在可交换性假设下，P(s_test≤q)≥1−α（有限样本）。
- **差距半径**：ρ_gap=Q_{0.95}(‖θ_real−θ_sim‖) 或匹配工况残差的分位数。
- **漂移监测**：对真机测量与 DR 生成测量做 MMD/能量距离置换检验；若 p<α_shift 或 ρ_gap>ρ_max ⇒ GAP_ALARM，提高 ε、扩大 Θ_DR 或**弃权**；**不得降低 K_safe^base**。
- **证书诚实性**：仅当 D_cal 可交换、gap 未报警且 B_conf 充足时，status=CERTIFIED；否则 status=EMPIRICAL_ONLY。

**定义 165（DRSC 闭环）** 在 SERC 上增加随机化包络、融合收缩与保形校准：
```
DRSC(M, z, intent, δ_f_req):
  ① DRSP: θ_1..θ_B ← SARS.sample(z)；p_DR(K|z) ← Σ π_scene(K|z,θ_b)；E_DR^ε ← HPD(p_DR,1−ε)
  ② CAF: ms ← align(measurements)；b̂ ← calibrate(ms)；x̂,Σ_ev,L_ev,κ,h ← robust_fuse(ms,p_DR)
```

**定义 166（融合可恢复证据 FRE）** 给定缺失序列 G=[a,b]：
- **重建**：ÊV_t=argmax_E P(E | y_{t−Δ:t+Δ}, S_shadow, seq_id, causal_constraints)。
- **可恢复性**：R(t)=1[P(ÊV_t|evidence)≥1−δ_rec ∧ provenance(ÊV_t)≠∅]。
- **标记**：重建证据必须标注 inferred=true、confidence、derivation；若与后续观测冲突，保留两者并标 CONFLICT。
- **链健康度**：H_chain=1−|inferred|/|total|；因果顺序由 EPIR 的 seq/hash 保证。
- **安全不变量**：inferred 证据只能用于**修复与解释**，不能单独用于 J_exec 安全签发；除非 Cert 显式允许 δ_rec 级证据。

**定义 167（鲁棒性预算 PCE+++++）** B_rob=(B_dr,B_caf,B_conf,B_exec)：
- B_dr=(N_DR, T_sim, Θ_memory)：随机化样本数、仿真/重采样时间、参数记忆。
- B_caf=(T_align, T_fuse, M_max)：对齐搜索、鲁棒融合迭代、最大模态数。
- B_conf=(N_cal, T_monitor, α)：保形校准样本、漂移监测频率、显著性。
- B_exec=(WCET_slack, Bus_bw_slack, Thermal_slack, Prio_headroom)（沿用第 60 轮）。
- **成本**：cost_rob=λ_dr·N_DR·C_sim+λ_caf·T_fuse+λ_conf·N_cal·C_cal。
- **VOI**：voi_rob(π)=VOI_meta(π)−cost_rob(π)−cost_exec(π)。
- **降级规则**：B_dr 耗尽⇒缓存包络+膨胀 Δε；B_caf 耗尽⇒top-k 标定模态+Σ 膨胀 ρ_min；B_conf 耗尽⇒EMPIRICAL_ONLY（禁止 CERTIFIED）；B_exec 耗尽⇒第 60 轮降级。
- **诚实性不变量**：status=CERTIFIED ⇒ B_conf>0 ∧ gap 未报警 ∧ D_cal 可交换；否则一律 EMPIRICAL_ONLY。

**定义 168（场景自适应随机化调度 SARS）** 维护失败缓冲 F={θ : WPTE=∅ ∨ residual>ρ_max ∨ κ>κ_max}：
- **提议分布**：π_DR^t(θ) ∝ exp(β·U_t(θ))，U_t 为估计失败风险（GP/贝叶斯优化/Thompson 采样）。
- **无偏保护**：每轮保留比例 ρ_uniform（默认 0.2）从 P_DR 均匀采样；或用重要性权重 w(θ)=p_DR(θ)/π_DR^t(θ) 参与保形校准。**否则自适应采样会悄悄破坏覆盖保证。**
- **预算分配**：N_DR^t=min(B_dr_remaining, N_min+λ·|F|)；F 越大，越向失败区域倾斜。
- **漂移检测**：对残差做 CUSUM；检测到突变时重置提议分布并提高均匀采样比例。
- **正确性**：只要 ρ_uniform>0 或使用重要性加权，E_DR 的经验覆盖率不被自适应采样系统性偏置；否则证书降级。

## 2. 关键算法伪代码

### IP-161 DRSP（随机化包络）

```python
class DomainRandomizedScenePrior:
    def __init__(self, scene_model, theta_sampler, eps=0.05, n_dr=256):
        self.scene_model = scene_model
        self.sample_theta = theta_sampler
        self.eps = eps
        self.n_dr = n_dr
        self.envelope = None
        self.theta_cache = []

    def build(self, z, n_dr=None):
        thetas = [self.sample_theta(z) for _ in range(n_dr or self.n_dr)]
        comps = [self.scene_model.prior(z, th) for th in thetas]
        self.theta_cache = thetas
        self.envelope = hp_region_of_mixture(comps, level=1.0 - self.eps)
        return self.envelope

    def membership(self, K, z):
        return self.envelope.contains(K)   # p_DR(K|z) >= q_eps

    def coverage(self, K_true_samples, z):
        return sum(self.membership(k, z) for k in K_true_samples) / len(K_true_samples)

    def inflate(self, delta_eps):
        # 预算耗尽时的安全回退：只能变宽，不能变窄
        self.eps = min(0.5, self.eps + delta_eps)
        return self.build(self.z_cache)
```

### IP-162 CAF（校准感知鲁棒融合）

```python
class CalibrationAwareFusion:
    def __init__(self, delta_sync=0.03, tau_age=0.5, h_min=0.5,
                 kappa_max=3.0, rho_max=0.3, rho_unknown=0.3):
        self.delta_sync = delta_sync
        self.tau_age = tau_age
        self.h_min = h_min
        self.kappa_max = kappa_max
        self.rho_max = rho_max
        self.rho_unknown = rho_unknown

    def align(self, measurements, now, clock):
        out = []
        for m in measurements:
            t_ref = m.t_src + m.tau + clock.offset(m.clock_domain)
            age = now - t_ref
            if abs(age) > self.delta_sync:
                continue
            out.append(replace(m, t_ref=t_ref, w_age=math.exp(-age / self.tau_age)))
        return sorted(out, key=lambda m: m.t_ref)

    def calibrate(self, measurements, x_prior):
        for m in measurements:
            m.b_hat, m.health = self._robust_bias_update(m, x_prior)
        return measurements

    def robust_fuse(self, measurements, K_prior):
        ms = [m for m in measurements if m.health > self.h_min]
        if not ms:
            return None, None, None, float('inf'), []
        kappas = self._pairwise_conflict(ms)
        weights = [m.w_age * m.health / (1.0 + k) for m, k in zip(ms, kappas)]
        x_hat = self._irls_robust_map(ms, weights, K_prior)   # Huber/Cauchy
        Sigma = self._covariance_intersection(ms, weights, self.rho_unknown)
        logL = lambda K: gaussian_logpdf(K, x_hat, Sigma)
        kappa = max(kappas)
        return x_hat, Sigma, logL, kappa, [m.health for m in ms]

    def evidence_set(self, logL, tau):
        return lambda K: -logL(K) <= tau
```

### IP-163 WPTE（宽先验-紧证据交集与证书）

```python
def wpte(z, logL_ev, drsp, base_safe, eps, tau, gap_radar, budget):
    E_dr = drsp.envelope(z)
    E_ev = lambda K: -logL_ev(K) <= tau
    K_safe = intersect(E_dr, E_ev, base_safe)
```

```python
class SceneAdaptiveRandomizer:
    def __init__(self, p_dr, proposal, rho_uniform=0.2, beta=1.0):
        self.p_dr = p_dr
        self.proposal = proposal
        self.rho_uniform = rho_uniform
        self.beta = beta
        self.failure_buffer = []

    def sample(self, z, n):
        n_uni = max(1, int(self.rho_uniform * n))
        uniform = self.p_dr.sample(n_uni)
        active = self.proposal.sample(n - n_uni, z)
        weights = importance_weights(uniform, active, self.p_dr, self.proposal)
        return uniform + active, weights

    def update(self, failures, residuals):
        self.failure_buffer = failures
        self.proposal.fit(failures, residuals)
        if cusum_detect(residuals):
            self.proposal.reset()
            self.rho_uniform = min(0.5, self.rho_uniform + 0.1)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DRSP | O(N_DR·d³+N_grid·N_DR) 建包络；O(1) 查询 | O(N_DR·d²+N_grid) | 边缘覆盖 ≥1−ε（A66）；ε 可调 |
| CAF | O(M log M+I·M·d³) | O(M·d²) | 标定/外点门控下证据覆盖 ≥1−δ（A67） |
| WPTE | O(N_grid) 求交 + O(N_mc) 体积 | O(N_grid) | 覆盖 ≥1−ε−δ；空集必触发 PEC |
| S2R-CP | O(n log n) 校准；O(1) 测试 | O(n) | 可交换性下有限样本覆盖 ≥1−α |
| DRSC | O(∑上述) | 复用 | 闭环证书一致；不静默回退 |
| FRE | O(|G|·M·d³) | O(|G|·M) | inferred 证据可溯源，不冒充观测 |
| SARS | O(|F| log|F|) 更新 | O(|F|) | 均匀保留/重要性加权下覆盖无偏 |

**正确性定理（DRSC）**：
假设 A66（DR 边缘覆盖）、A67（CAF 标定证据覆盖）、A68（S2R-CP 可交换性）、A69（预算单调且诚实）、A70（SARS 保留均匀采样或重要性加权）成立，则：
1. **覆盖性**：P(K_true∈K_safe^WPTE) ≥ 1−ε−δ；若再叠加 S2R-CP，则最终报告 min(1−ε−δ, 1−α)。
2. **锐度性**：W(K_safe^WPTE) ≤ min(W(E_DR), W(E_ev))；当 W(E_ev)≪W(E_DR) 时，η_sharp→W(E_ev)/W(E_DR)。
3. **矛盾可见性**：K_safe^WPTE=∅ ⇒ 必输出 PEC 类别与最小修复动作，不会返回一个「看起来安全」的非空集。
4. **证据修复性**：FRE 重建的证据带 inferred 标记与溯源；若不可恢复则 H_chain 如实下降，不伪造完整性。
5. **预算诚实性**：CERTIFIED ⇒ B_conf>0 ∧ gap 未报警 ∧ D_cal 可交换；任一不满足 ⇒ EMPIRICAL_ONLY。

**关键引理（宽先验-紧证据的联合界）**：对任意两个事件 A={K_true∈E_DR}、B={K_true∈E_ev}，有 P(A∩B)≥1−P(A^c)−P(B^c)≥1−ε−δ。该引理不要求 A、B 独立；这是 WPTE 证书可以保守但可靠的根本原因。

```python
class DomainRandomizedScenePrior:
    def __init__(self, scene_model, theta_sampler, eps=0.05, n_dr=256):
        self.scene_model = scene_model
        self.sample_theta = theta_sampler
        self.eps = eps
        self.n_dr = n_dr
        self.envelope = None
        self.theta_cache = []
        self.z_cache = None

    def build(self, z, n_dr=None):
        self.z_cache = z
        thetas = [self.sample_theta(z) for _ in range(n_dr or self.n_dr)]
        comps = [self.scene_model.prior(z, th) for th in thetas]
        self.theta_cache = thetas
        self.envelope = hp_region_of_mixture(comps, level=1.0 - self.eps)
        return self.envelope

    def membership(self, K, z):
        return self.envelope.contains(K)   # p_DR(K|z) >= q_eps

    def coverage(self, K_true_samples, z):
        return sum(self.membership(k, z) for k in K_true_samples) / len(K_true_samples)

    def inflate(self, delta_eps):
        # 预算耗尽时的安全回退：只能变宽，不能变窄
        self.eps = min(0.5, self.eps + delta_eps)
        return self.build(self.z_cache)
```

```python
class CalibrationAwareFusion:
    def __init__(self, delta_sync=0.03, tau_age=0.5, h_min=0.5,
                 kappa_max=3.0, rho_max=0.3, rho_unknown=0.3):
        self.delta_sync = delta_sync
        self.tau_age = tau_age
        self.h_min = h_min
        self.kappa_max = kappa_max
        self.rho_max = rho_max
        self.rho_unknown = rho_unknown

    def align(self, measurements, now, clock):
        out = []
        for m in measurements:
            t_ref = m.t_src + m.tau + clock.offset(m.clock_domain)
            age = now - t_ref
            if abs(age) > self.delta_sync:
                continue
            out.append(replace(m, t_ref=t_ref, w_age=math.exp(-age / self.tau_age)))
        return sorted(out, key=lambda m: m.t_ref)

    def calibrate(self, measurements, x_prior):
        for m in measurements:
            m.b_hat, m.health = self._robust_bias_update(m, x_prior)
        return measurements

    def robust_fuse(self, measurements, K_prior):
        ms = [m for m in measurements if m.health > self.h_min]
        if not ms:
            return None, None, None, float('inf'), []
        kappas = self._pairwise_conflict(ms)
        weights = [m.w_age * m.health / (1.0 + k) for m, k in zip(ms, kappas)]
        x_hat = self._irls_robust_map(ms, weights, K_prior)   # Huber/Cauchy
        Sigma = self._covariance_intersection(ms, weights, self.rho_unknown)
        logL = lambda K: gaussian_logpdf(K, x_hat, Sigma)
        return x_hat, Sigma, logL, max(kappas), [m.health for m in ms]

    def evidence_set(self, logL, tau):
        return lambda K: -logL(K) <= tau
```

```python
        self.b_conf = n_cal
        self.b_exec = exec_budget or ExecBudget()
        self.delta_ev = 0.05

    def status(self):
        if self.b_conf <= 0:
            return "EMPIRICAL_ONLY"
        if self.b_dr <= 0:
            return "INFLATE_ENVELOPE"
        if self.b_caf <= 0:
            return "CONSERVATIVE_FUSION"
        return "CERTIFIED"

    def cost_rob(self, action):
        return (LAMBDA_DR * action.n_dr * C_SIM
                + LAMBDA_CAF * action.t_fuse
                + LAMBDA_CONF * action.n_cal * C_CAL)
```

### IP-168 SARS（自适应随机化调度）

```python
class SceneAdaptiveRandomizer:
    def __init__(self, p_dr, proposal, rho_uniform=0.2, beta=1.0):
        self.p_dr = p_dr
        self.proposal = proposal
        self.rho_uniform = rho_uniform
        self.beta = beta
        self.failure_buffer = []

    def sample(self, z, n):
        n_uni = max(1, int(self.rho_uniform * n))
        uniform = self.p_dr.sample(n_uni)
        active = self.proposal.sample(n - n_uni, z)
        weights = importance_weights(uniform, active, self.p_dr, self.proposal)
        return uniform + active, weights

    def update(self, failures, residuals):
        self.failure_buffer = failures
        self.proposal.fit(failures, residuals)
        if cusum_detect(residuals):
            self.proposal.reset()
            self.rho_uniform = min(0.5, self.rho_uniform + 0.1)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| DRSP | O(N_DR·d³+N_grid·N_DR) | O(N_DR·d²+N_grid) | 边缘覆盖 ≥1−ε（A66） |
| CAF | O(M log M+I·M·d³) | O(M·d²) | 证据覆盖 ≥1−δ（A67） |
| WPTE | O(N_grid)+O(N_mc) | O(N_grid) | 覆盖 ≥1−ε−δ；空集触发 PEC |
| S2R-CP | O(n log n) | O(n) | 有限样本覆盖 ≥1−α（A68） |
| FRE | O(\|G\|·M·d³) | O(\|G\|·M) | inferred 可溯源，不冒充观测 |
| SARS | O(\|F\| log\|F\|) | O(\|F\|) | 均匀保留/重要性加权下无偏 |

**正确性定理（DRSC）**：
若 A66（DR 边缘覆盖）、A67（CAF 标定证据覆盖）、A68（S2R-CP 可交换性）、A69（预算单调且诚实）、A70（SARS 保留均匀采样或重要性加权）成立，则：
1. **覆盖下界**：P(K_true∈K_safe^WPTE) ≥ 1−ε−δ；叠加保形后最终报告 min(1−ε−δ, 1−α)。
2. **锐度**：W(K_safe^WPTE) ≤ min(W(E_DR), W(E_ev))；η_sharp=W(WPTE)/W(E_DR) 可度量证据收缩效果。
3. **矛盾可见**：K_safe^WPTE=∅ ⇒ 必输出 PEC 类别与最小修复动作，绝不静默返回单证据集。
4. **修复诚实**：FRE 只生成 inferred 证据，链健康度 H_chain 如实下降，不伪造「观测完整」。
5. **预算诚实**：CERTIFIED ⇒ B_conf>0 ∧ gap 未报警 ∧ D_cal 可交换；否则 EMPIRICAL_ONLY。

**关键引理（联合界）**：P(A∩B)≥1−P(A^c)−P(B^c)≥1−ε−δ，不要求 DR 与融合证据独立。这是 WPTE 证书可以保守但可靠的根本原因；也是不能把 ε、δ 设得过小的原因。

## 5. 合成 Monte Carlo 初步验证（非真机，仅验证代数与证书逻辑）

**目的**：在 2D 阻抗 K=(Kp,Kd) 上验证「DR 包络保证覆盖、融合证据提供锐度、WPTE 取交」是否按定理工作，不代表真机性能。

**设置**：
- 名义先验 N(0, 0.30²I)；真实 sim-to-real 偏移 ~N(0, σ_gap²I)，σ_gap=0.60。
- 随机化 θ~N(0, σ_DR²I)，σ_DR=0.75；N_DR=400；ε=0.05。
- 融合：4 模态，测量噪声 0.10，标定偏置 0.13，20% 外点（额外偏置 0.9）；鲁棒门控+协方差膨胀 1.6。
- 3000 次 Monte Carlo；网格 601×601；95% 集合。

| 方案 | 经验覆盖率 | 2D 体积（面积） | 解释 |
|---|---:|---:|---|
| Nominal（点先验） | 0.530 | 1.69 | 忽略 sim-to-real gap，过度自信 |
| DR-only（仅包络） | 0.988 | 11.01 | 覆盖高，但过宽、几乎不可执行 |
| Fusion-only（仅证据） | 0.981 | 0.405 | 锐利，但依赖标定；偏差时不可救 |
| **WPTE（本轮）** | **0.969** | **0.398** | 覆盖≈DR，体积≈融合（约 DR 的 3.6%） |

- **空集率**：0.20%（可由 PEC 显式处理，而非静默失败）。
- **Out-of-support 压力测试**（σ_gap 从 0.6 增到 1.2/1.5）：

| σ_gap | Nominal 覆盖 | DR 覆盖 | 结论 |
|---:|---:|---:|---|
| 0.6 | 0.511 | 0.994 | 在支撑内，DR 有效 |
| 1.2 | 0.170 | 0.724 | 超出支撑，**必须 GAP_ALARM/弃权** |
| 1.5 | 0.124 | 0.558 | 随机化不能替代真机校准 |

- **CAF toy（20% 外点）**：RMSE 0.248→0.175（−29.5%）；95% 证据集覆盖 0.920→0.976。说明鲁棒门控+未知相关膨胀能同时降误差、修覆盖。
- **结论**：WPTE 的代数行为符合预期——**DR 单独太宽，融合单独太信，交集在保持覆盖的同时把体积压到 3.6%**；但 out-of-support 结果同时证明：一旦世界越出 P_DR，覆盖会断崖式下降，必须由 S2R-CP 与 PEC 兜底。

## 6. 本轮最大风险

**一句话**：若真机世界落在 P_DR 支撑之外，且融合证据又因共模标定偏差而系统性地偏向同一个错误区域，则 DR 包络与融合证据会「一致地错」——交集非空、证书看似通过，却把「覆盖保证」变成了「共同偏差的伪装」；因此必须以「S2R-CP 的分布外报警 + 标定健康门控 + PEC 的弃权/主动探测」把「不确定」显式暴露，而不是用更宽的随机化掩盖它。
