# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 1 轮；本轮灵感：「基准测试」×「三维感知」）

> 第 60 轮 SGEC 把「场景」升级为阻抗先验 π_scene(K|z)，用 SSM×CIEC×EPIR×SERC 实现了「场景先验提前收敛 K_safe、意图即时锁定约束、证据链防消息丢失」。但整条「理解→执行→证据」链仍有两个根基未经检验：
> 1. **场景是"标签"，不是"几何"**：SSM 的 z ∈ {table_smooth, stairs_up, floor_wet, ...} 是离散语义标签，π_scene(K|z) 只在标签内部做统计。可同一个「桌面」标签下，平坦台面中心、锐利桌角、悬空桌沿的接触几何天差地别；同一个「楼梯」标签下，踏步高度、踏面摩擦、边缘陡度决定的是完全不同的 K_safe。**三维感知**（点云/深度/法向/主曲率/接触面片/摩擦代理）才能把阻抗先验锚定在真实接触几何上，而不是锚定在一个词上。
> 2. **证据是"自证"，不是"可证伪"**：第 60 轮宣称「场景识别准确率 ≥85%」「K_safe 收敛改善 ≥15%」「因果一致性 ≥99.5%」，但**没有可复现基准、没有置信区间、没有隐藏场景族、没有污染审计、没有 sim-to-real 分层**。这些数字是断言，不是证据。**基准测试**的价值不是"跑个分"，而是把每一条安全声明变成**带版本、带隐藏集、带置信下界、带撤销机制的可证伪契约**。
> 3. **基准与执行之间缺少防 Goodhart 的结构**：一旦系统"为基准优化"，就会过拟合公开场景族，证书退化为「基准表演证书」而非「安全证书」。三维感知与基准测试必须**互相制衡**：几何负责「只能更紧」的单向否决，基准负责「能证伪、能撤销」的外部检验。

## 0. 直觉与动机

**灵感 1（三维感知 → 接触几何场 CGF）**
直觉：机器人真正"摸到"的从来不是标签，而是一小块曲面。决定阻抗的不是"这是桌子"，而是"接触点法向朝哪、曲率多大、面片多糙、摩擦多低、离边缘多近"。关键洞见：把场景先验从 π(K|z) 升级为 **π(K|g)**，其中 g 是**接触几何场**（法向 n、主曲率 κ₁/κ₂、粗糙度 h_rms、接触面积 A_c、摩擦代理 μ̂、边缘/悬崖置信 c_edge）。几何是连续、可微、可插值的——因此**没见过的场景也能从邻近几何外推 K_safe**，不必先等语义标签收敛。

**灵感 2（基准测试 → 场景基准契约 SBC）**
直觉：基准的价值不是排行榜，而是**可证伪性**。一条声明「该 K_safe 使 D⁺ ≤ ε」只有在"隐藏的、未污染的、分层的、可复现的"测试族上、以**下置信界**通过，才算被证实；一旦新版基准上掉下阈值，证书必须**自动撤销**。关键洞见：把声明写成契约 claim=(指标 m, 阈值 θ, 置信 δ, 版本 V, 隐藏集 D_hid, 污染报告 C)，并在执行证书里附带基准溯源 J_bench——**没有 J_bench 的执行证据只能标 unverified，不得用于更新场景先验**。

**灵感 3（三维感知 × 基准测试 → 几何-语义一致性 GSC 与几何否决）**
直觉：语义分割会说"这是桌面"，几何却可能发现"这是桌沿外 2cm 的悬崖"。两者冲突时，安全不能投票平均——**几何优先，且只许单向收紧**。关键洞见：GSC 检测语义-几何冲突；一旦 c_edge/坡度/粗糙度越过安全阈值而标签仍判「平坦安全」，就触发**几何否决**：K_safe ← K_safe^geo ∩ K_safe^conservative，并把该冲突作为一次长尾层 L3 的事件喂回基准。否决只能使约束更紧，永不更松。

**灵感 4（基准测试 → 变形测试 MTR，防过拟合）**
直觉：只报平均分的基准会被"刷分"：把公开场景的每个边角都记住即可。关键洞见：用**变形关系**（旋转/平移不变、曲率单调、摩擦单调、边缘收缩、局部性、尺度一致性）做「物理常识级」的对抗检验——这些关系不依赖标签、不需隐藏集也能查；违反率 VR 高的策略，几乎必然在隐藏集上掉分。变形测试把"泛化"从一句口号变成一组**可自动执行的否定式检验**。

**灵感 5（分层基准 → 最差层指标，拒绝平均掩盖灾难）**
直觉：长尾灾难永远发生在平均分看不见的角落。关键洞见：把隐藏测试按难度分层 L0~L4（同分布、近分布变换、新场景族、对抗长尾、sim-to-real），**只认最差层的下置信界** W_m = min_l LCB_m^l，而不是总平均。这样"95% 常见场景很好、湿滑边缘崩溃"的方案，不会因平均分高而被采纳。

**灵感 6（三灵感合流 → 基准驱动三维接地闭环 BGSL）**
直觉：串联成闭环：三维点云→接触几何场 g→几何先验 π(K|g)→GSC 几何否决→EEIS 编译 K_safe→执行→EV-exec→SBC 审计并签发 J_bench→基准版本/隐藏集轮换→（若撤销）回到保守先验。与第 60 轮的关系是正交的：SERC 管「场景怎么安全落地」，BGSL 管「落地所依赖的场景理解与安全声明本身是否可信」。

**灵感 7（预算 → PCE+++++++ 几何-基准预算）**
直觉：三维感知与基准审计都昂贵、可耗尽。新增 B_geo（点云配准/法向曲率/摩擦回归）、B_bench（基准审计与隐藏集轮换）、B_simreal（sim-to-real 校准）。策略：B_geo 耗尽⇒退化为 2.5D 深度+标签先验且区间加宽；B_bench 耗尽⇒不得签发 J_bench、证据标 unverified、禁止更新场景先验；B_simreal 耗尽⇒关闭跨域迁移，仅用域内校准。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（接触几何场 CGF）** 给定接触点邻域点云 P ⊂ R³ 与支撑半径 r，局部面片几何描述子
g = (n, κ₁, κ₂, h_rms, A_c, μ̂, c_edge) ∈ G，
其中 n 为单位法向；κ₁,κ₂ 为主曲率；h_rms 为面片相对拟合曲面的粗糙度均方根；A_c 为夹爪投影与点云占据估计的接触面积；μ̂∈[0,1] 为摩擦代理（视觉纹理+触觉历史+材质分类回归）；c_edge∈[0,1] 为边缘/悬崖置信（深度断崖+法向突变）。场景-阻抗先验升级为
π_scene(K|g) ∝ π_scene(K|z) · N(K; μ_g(g), Σ_g(g))，
即**几何为主、标签为共轭先验**。几何安全核与单向几何约束：
- K_safe^geo = {K | P(K|g) ≥ τ_geo} ∩ K_inv（K_inv 为第 60 轮不可违背物理安全核）；
- 曲率约束：κ_max↑ ⇒ K_d 下界不降、v_max 上界不增；
- 摩擦约束：μ̂↓ ⇒ F_max 上界不增、K_d 下界不减；
- 边缘约束：c_edge↑ ⇒ K_safe^geo 收缩（集合包含关系）。

**定义 162（场景基准契约 SBC）** 基准契约 B = (V, D_tr, D_cal, D_hid, L, M, δ, C)，其中 V 为基准版本（内容哈希）；D_tr/D_cal/D_hid 分别为公开开发/校准/隐藏测试场景族；L={L0,…,L4} 为难度分层；M 为指标集（安全违约率、适应接触数、K_safe 超调、证据链完整率、几何误差、最差层指标）；δ 为置信水平；C 为污染审计报告（场景指纹近重复率、与 D_tr 的重叠率、时间泄漏）。声明 φ=(m, θ_m, δ, V) 被**基准证实**当且仅当
LCB_m^l(D_hid; δ) ≥ θ_m, ∀ l∈L，且 Δ_contam(C) ≤ ε_contam，且 VR(φ) ≤ τ_mtr。
**撤销规则**：若在版本 V′ 上任一层 LCB 跌破阈值或污染超标，则 φ 自动置为 REVOKED，引用 φ 的所有 K_safe 先验退回通用先验，直至重新校准。

**定义 163（几何-语义一致性 GSC 与几何否决）** 给定标签后验 p(z|O) 与几何描述子 g：
- 一致性分数 s_gsc = exp(−D_KL(π(K|z) ‖ π(K|g)))，归一化到 [0,1]；
- 危险冲突集：若 (c_edge > τ_edge ∨ slope(g) > τ_slope ∨ h_rms > τ_rough) 且 z 属于 SAFE_FLAT_LABELS（如 table_smooth/floor_dry），则判为冲突；
- **几何否决**（单向）：Veto(g,z)=true ⇒ K_safe ← K_safe^geo ∩ K_safe^label ∩ K_safe^conservative，并生成 ConflictEvent(g,z) 供 SBC 的 L3 层使用。否决算子满足单调性：K_safe_after ⊆ K_safe_before，即**几何只能收紧、不能放松**。

**定义 164（变形测试关系 MTR）** 关系集 R={R1…R6}，对策略 π_K: G→K_safe：
- R1 SE(3) 不变：π_K(T·g)=π_K(g)，T∈SE(3) 作用于点云；
- R2 曲率单调：κ_max(g₁)≤κ_max(g₂) ⇒ K_d号(g₁)≥K_d号(g₂)、v_max(g₁)≤v_max(g₂)（号=安全方向）；
- R3 摩擦单调：μ̂(g₁)≥μ̂(g₂) ⇒ F_max(g₁)≥F_max(g₂)、K_d(g₁)≤K_d(g₂)；
- R4 边缘收缩：c_edge(g₁)≤c_edge(g₂) ⇒ K_safe(g₁) ⊇ K_safe(g₂)；
- R5 尺度一致：点云等比缩放 s 后，F_max 按接触面积缩放律 F_max(s)≤s²·F_max(1) 且方向保守；
- R6 局部性：远离接触点（>r）的几何变化不改变 π_K(g)。
违反率 VR = |{(scene,R) 被违反}| / (|D|·|R|)；VR>τ_mtr ⇒ 判「基准过拟合」，即使隐藏集暂时通过也拒绝采纳。

**定义 165（分层基准与最差层指标 SBS）** 隐藏集按 L0~L4 分层，每层至少含 n_min 个独立场景族。契约的通过判据不是均值而是**最差层下置信界** W_m = min_{l∈L} LCB_m^l，并要求各层样本量满足 Hoeffding/Clopper-Pearson 可算下界。定义覆盖缺口 Gap_l = θ_m − LCB_m^l，报告**分层向量而非标量**，禁止用总体平均掩盖单层灾难。

**定义 166（基准驱动三维接地闭环 BGSL）** 算子 BGSL(M, φ, δ_f_req)：
```
① CGF:  g ← M.cgf.update(P, pose, grasp_proj)
② Prior: π(K|g) ∝ π(K|z)·N(μ_g(g),Σ_g(g))；π(K|z) ← M.ssm.scene_prior()
③ Compile: K_geo ← EEIS.compile_with_geometry_prior(π(K|g), δ_f_req)
④ GSC:  (veto, K_safe) ← geometry_semantic_consistency(z*, g, K_label, K_geo)
⑤ Exec: M, fused, D⁺, EV-exec, Cert ← closed_loop_exec_probe(M, cp, δ_f_req, budget)
⑥ Audit: J ← SBC.issue_j_bench(φ, metrics(M), VR, contamination)
⑦ Gate: if J.status ≠ VALID: M.safe_mode ← 'conservative_prior'; freeze_prior_update()
⑧ Evid: msg ← EPIR.append(EV-exec); XMC+ 融合
⑨ Return (g, K_safe, J, msg, veto)
```

**定义 167（基准证书 J_bench）** 执行证据的基准溯源证书
J_bench = (V, hash(D_hid), φ.id, {LCB_m^l}, W_m, VR, Δ_contam, τ_edge/slope/rough, timestamp, signer)。
J_bench 与第 60 轮 Cert_eeis/J_exec **并列而非替代**：无 J_bench 的 EV-exec 标 `unverified`，且**不得用于更新 π_scene 或场景置信度**；J_bench.status=REVOKED 时强制回到通用先验 π_general。

**定义 168（几何-基准预算 PCE+++++++）** B_bench = (B_geo, B_bench_audit, B_simreal)，扩展第 60 轮 B_cog：
```
cost_geo   = λ_pc·Points + λ_norm·Normals_update + λ_mu·Friction_regress
cost_audit = λ_hid·Hidden_eval + λ_cont·Contamination_scan + λ_mtr·MTR_eval
cost_sim   = λ_gap·Sim2Real_calib
VOI_bench  = VOI_cog(π) − cost_geo − cost_audit − cost_sim
```
耗尽策略：B_geo<θ_g ⇒ 2.5D 深度 + 标签先验，Σ 加宽 λ_w；B_bench_audit<θ_b ⇒ 不签发 J_bench，证据 unverified，冻结先验更新；B_simreal<θ_s ⇒ 仅域内校准，禁用跨域迁移。

### IP-161 CGF（接触几何场）

```python
class ContactGeometryField:
    def __init__(self, support_radius=0.03, voxel=0.005):
        self.r, self.voxel = support_radius, voxel

    def update(self, point_cloud, pose, grasp_proj):
        P = voxel_downsample(point_cloud, self.voxel)
        patch = local_ball(P, pose.contact_point, self.r)
        n, k1, k2 = fit_quadric_surface(patch)      # 法向 + 主曲率
        h_rms = roughness_rms(patch, n)
        A_c   = contact_area(patch, grasp_proj)
        mu_hat = friction_proxy(patch, tactile_history())   # [0,1]
        c_edge = edge_confidence(patch)                    # 深度断崖+法向突变
        return GeometryDescriptor(n, k1, k2, h_rms, A_c, mu_hat, c_edge)

    def impedance_prior(self, g, pi_label):
        mu_g, sig_g = geometry_to_impedance(g)      # 曲率→K_d下界, 摩擦→F_max上界
        return gaussian_product(pi_label, Normal(mu_g, sig_g))
```

### IP-162 SBC（场景基准契约）

```python
class SceneBenchmarkContract:
    def __init__(self, version, hidden, layers, delta=0.05,
                 eps_contam=0.01, tau_mtr=0.03):
        self.V, self.D_hid, self.L = version, hidden, layers
        self.delta, self.eps_contam, self.tau_mtr = delta, eps_contam, tau_mtr

    def issue_j_bench(self, claim, metrics_by_layer, contamination, vr):
        if contamination.overlap > self.eps_contam:
            return JCert(claim, status='REVOKED', reason='CONTAMINATED')
        lcbs = {l: lower_confidence_bound(metrics_by_layer[l][claim.m],
                                          self.delta) for l in self.L}
        worst = min(lcbs.values())
        ok = (worst >= claim.theta) and (vr <= self.tau_mtr)
        status = 'VALID' if ok else 'REVOKED'
        return JCert(claim, status, lcbs, worst, vr, contamination.overlap)
```

### IP-163 GSC（几何否决）

```python
SAFE_FLAT_LABELS = {'table_smooth', 'floor_dry', 'floor_carpet'}

def geometry_semantic_consistency(z_post, g, K_label, K_geo):
    danger = (g.c_edge > TAU_EDGE or slope(g) > TAU_SLOPE
              or g.h_rms > TAU_ROUGH)
    conflict = danger and (z_post in SAFE_FLAT_LABELS)
    if conflict:                       # 单向收紧
        K_safe = intersect(K_label, K_geo, K_conservative(g))
        return True, K_safe, ConflictEvent(g, z_post)
    return False, intersect(K_label, K_geo), None
```

### IP-164 MTR（变形测试）

```python
def metamorphic_audit(policy, families, relations):
    violations = 0; total = 0
    for scene in families:
        g = perceive(scene); K0 = policy(g)
        for R in relations:
            g2, tf = R.transform(scene, g)
            K1 = policy(g2); total += 1
            if not R.holds(K0, K1, tf):
                violations += 1
    return violations / max(1, total)
```

### IP-165 SBS（分层最差指标）

```python
def worst_layer_lcb(metrics_by_layer, metric, delta):
    return {l: lower_confidence_bound(v[metric], delta)
            for l, v in metrics_by_layer.items()}

def claim_passes(metrics_by_layer, claim, delta):
    lcbs = worst_layer_lcb(metrics_by_layer, claim.m, delta)
    return min(lcbs.values()) >= claim.theta, lcbs
```

```python
def benchmark_grounded_scene_loop(M, claim, delta_f_req):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CGF | O(N_pc) 降采样 + O(k) 局部拟合/周期（缓存体素可 O(1)） | O(N_pc + voxel) | 法向误差 ≤ 5°，曲率相关 ≥ 0.95 |
| SBC | 离线 O(|claims|·|L|·|M|)；在线 O(1) 签发 | O(|D_hid| 指标摘要) | 隐藏集 LCB 覆盖 ≥ 1−δ |
| GSC | O(1)/冲突检测 | O(1) | 几何否决单向不放松（集合包含） |
| MTR | O(|R|) / 样本 | O(1) | 违反率可检出旋转/缩放/局部性过拟合 |
| SBS | O(|L|) / 指标 | O(|L|) | 最差层指标不被平均掩盖 |
| BGSL | O(闭环) | 复用 | 无有效 J_bench ⇒ 冻结先验更新 |

**正确性定理（BGS, Benchmark-Grounded Safety）**：
假设 A22–A65 成立，且新增：**(A66)** CGF 曲面拟合误差 ≤ δ_g，几何描述子在 1−α 覆盖真实接触几何；**(A67)** 各层 D_hid 与部署族可交换、污染重叠 ≤ ε_contam；**(A68)** GSC 的 c_edge/slope/rough 检测召回足够，且否决算子只做交集；**(A69)** MTR 六条关系是物理安全的必要条件（违反即过拟合/分布漂移）；**(A70)** BGSL 每周期终止，撤销后先验冻结；**(A71)** B_geo/B_audit/B_sim 单调消耗，任一耗尽触发对应安全模式。

1. **几何接地性**：若 δ_g→0 且 π(K|g) 覆盖真值，则 K_safe^geo 相对仅标签先验严格收窄，D⁺ 不增；同等接触预算下收敛接触数减少。

3. **单向安全**：GSC 否决满足 K_safe_after ⊆ K_safe_before，几何信息永不使约束变松。
4. **过拟合可检测**：若策略在隐藏集最差层明显退化，则其 MTR 违反率 VR 以高概率超过 τ_mtr（否则关系集不完备，需扩充 R）。
5. **证书溯源**：不存在绕过 SBC 的"自证"：无 VALID 的 J_bench ⇒ 证据 unverified，且被禁止用于先验更新。

### IP-161 CGF（接触几何场）

```python
class ContactGeometryField:
    def __init__(self, support_radius=0.03, voxel=0.005):
        self.r, self.voxel = support_radius, voxel

    def update(self, point_cloud, pose, grasp_proj):
        P = voxel_downsample(point_cloud, self.voxel)
        patch = local_ball(P, pose.contact_point, self.r)
        n, k1, k2 = fit_quadric_surface(patch)
        h_rms = roughness_rms(patch, n)
        A_c   = contact_area(patch, grasp_proj)
        mu_hat = friction_proxy(patch, tactile_history())
        c_edge = edge_confidence(patch)
        return GeometryDescriptor(n, k1, k2, h_rms, A_c, mu_hat, c_edge)

    def impedance_prior(self, g, pi_label):
        mu_g, sig_g = geometry_to_impedance(g)
        return gaussian_product(pi_label, Normal(mu_g, sig_g))
```

### IP-162 SBC（场景基准契约）

```python
class SceneBenchmarkContract:
    def __init__(self, version, hidden, layers, delta=0.05,
                 eps_contam=0.01, tau_mtr=0.03):
        self.V, self.D_hid, self.L = version, hidden, layers
        self.delta, self.eps_contam, self.tau_mtr = delta, eps_contam, tau_mtr

    def issue_j_bench(self, claim, metrics_by_layer, contamination, vr):
        if contamination.overlap > self.eps_contam:
            return JCert(claim.id, 'REVOKED', reason='CONTAMINATED')
        lcbs = {l: lower_confidence_bound(metrics_by_layer[l][claim.m],
                                          self.delta) for l in self.L}
        worst = min(lcbs.values())
        ok = (worst >= claim.theta) and (vr <= self.tau_mtr)
        return JCert(claim.id, 'VALID' if ok else 'REVOKED',
                     lcbs, worst, vr, contamination.overlap, self.V)
```

### IP-164 MTR（变形测试关系）

```python
def metamorphic_audit(policy, families, relations):
    violations = total = 0
    for scene in families:
        g = perceive(scene); K0 = policy(g)
        for R in relations:
            g2, tf = R.transform(scene, g)
            total += 1
            if not R.holds(K0, policy(g2), tf):
                violations += 1
    return violations / max(1, total)
```
