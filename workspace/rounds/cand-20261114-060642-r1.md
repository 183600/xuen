# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「示教学习」×「伦理与合规」）

> R69 把不确定性一分为二：aleatoric 收紧，epistemic 去问。它最诚实的一句话是——**「问错，比不问更危险」**：因为整个交互收益都押在「流模型的模态后验可信」上，而模态后验来自同一个会幻觉的模型。R69 的补救是 MCG（模态校准门），但校准的参照对象仍是模型自己的输出；它缺一个**外部的、诚实的、会犹豫也会拒绝的**参照物。
>
> 「示教学习」正好提供这个参照物：人类示范者在岔口会停顿、会凑近看、会问一句、会说「这个我不能替你决定」——**犹豫、注视、求证、拒绝，本身就是「何时该消歧、向谁求证、以及何时不该继续」的标签**。示教把 R69 的 VoI 从「模型对自己歧义的信念」换成「人类如何处理同类歧义的行为证据」。
>
> 但示教是**描述性**的：它会连人的偏见、捷径、操纵与非合规一起抄下来。「伦理与合规」是**规范性**的。于是本轮的核心架构命题不是「用伦理给奖励加个罚项」，而是一道**休谟式防火墙**：
> **示教只能塑造价值（descriptive），永远不能扩张可行集（prescriptive）；合规是独立的、版本化的、可审计的规范库，不是从示范里学出来的偏好。**
>
> 由此得到第三种不确定性——**规范不确定性 U_deon**（这动作到底允不允许？管辖区是谁？同意是否有授权？）。它与前两种的消解算子**本质不同**：aleatoric→收紧，epistemic→询问，deontic→**升级/拒绝**。把 R69 的 VoI 套到 U_deon 上是范畴错误：**「我问了用户能不能」不等于「我被授权了」**——同意是规范源，不是传感器读数。一句话定位：R69 问「我该向谁求证」，R70 问「**我有没有资格问、问了算不算数、以及什么时候必须把决定交还给人**」。

## 0. 直觉与动机

**灵感 1（示教 → 给「要不要问」一个外部锚）**
直觉：R69 的 MINT 在算 `VoI(g)=H(M|o)−E[H(M|o,y)]`，可 `M` 是从模型采样里聚出来的，模型若幻觉出一个模态，VoI 就会为一个幻影动作买单。人类解决这个问题不是靠更强的自校准，而是靠**看别人怎么做**：一个熟练的示范者在「该看还是该走」「该问还是该等」上有稳定的行为分布。把这些示范当作监督，等于给「何时交互」装了一个模型外的投票器。更严格地说，示范数据提供了模态身份与交互时机的**联合标签**，使我们可以对模态后验做分布无关的共形校准，而不是在模型自己的软最大化上打转。

**灵感 2（示教 → 拒绝与升级是正样本，不是失败样本）**
直觉：在纯 RL / 纯模仿任务里，「拒绝执行」「请求人工」「停下来」常被当成负样本或异常。但一个可信的自主系统最该学会的动作之一就是**体面地不干**。人会在信息不足、越权、价值冲突时升级或拒绝；这些示范恰恰定义了系统的伦理边界。把拒绝当作一等动作（带前置条件、带解释、可审计），比事后加一个「拒绝分类器」更根本——因为它进入了策略空间与认证流程。

**灵感 3（伦理 → 可行集，不是奖励项）**
直觉：如果把伦理写成奖励里的罚项，系统就会学会「划算地违规」：只要收益够大，违规就是最优。合规的本质是**硬约束**，是不可交易的那一类。所以架构上必须把「描述性偏好」与「规范性可行集」分开：示教参数只能影响 `U_task` 与先验，绝不能改变 `C_feas`。这条防火墙就是休谟的 is–ought gap 在系统层的操作化——**从「人怎么做」推不出「人应当怎么做」**。

**灵感 4（三分不确定性 → 三种互不替代的算子）**
直觉：R69 的二分漏了一类。噪声（aleatoric）问不出来，只能收紧；歧义（epistemic）问得出来，应该询问；**规范不确定性（deontic）既问不出来、也不该靠询问解决**——环境的回答不是授权。对 `U_deon` 的正确算子是**升级或拒绝**。三者混用会出三类事故：把噪声当歧义（无谓打扰）、把歧义当噪声（过早保守）、**把规范不确定性当歧义（用「问一句」把越权洗成合意）**。最后一种最危险，因为它会把不合法变成「用户同意了」。

**灵感 5（示教投毒与规范漂移 → 新的威胁模型）**
直觉：R69 已经担心「交互投毒」，R70 多两个更上游的攻击面：**示教投毒**（喂入带偏见/捷径/操纵的示范，污染模态先验与交互倾向）与**规范漂移**（法规/管辖区/同意状态随时间变化，旧证书失效）。防御必须分层：示范要有来源与同意（provenance/consent）、聚合要抗离群（trimmed/median-of-means）、规范库要版本化并在运行时钉住、证书要能因规范变更而作废。否则「合规」会变成一张盖给错误动作的橡皮图章。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（ETHOS-RAS 总览）** ETHOS-RAS = (FMP†, AUD†, DNG, NUF, CGD, DVoI, REF, CIA†, FMA†, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **交互预算硬约束**（继承 R69 定义 293-ii）；
(iii) **证据纪律**（继承定义 293-iii）；
(iv) **规范防火墙（is–ought firewall）**：示教参数 θ_desc 只能进入效用与先验，不得进入可行集 `C_feas`；`C_feas` 仅由版本化规范库 N 决定；
(v) **三值合规与拒绝优先**：合规判定 ∈ {Permitted, Forbidden, Undetermined}；Undetermined ⇒ 不得执行，只能升级/拒绝；拒绝是一等动作且必须可解释。

**定义 311（示教语料与三分割）** 示教语料 `D = {(o_i, ξ_i=(a_i,g_i), y_i, r_i, κ_i, π_i)}`：`y_i` 为示范者选择的模态/意图（可为空），`r_i∈{0,1}` 表示示范者是否执行了信息动作，`κ_i=(norm_id, verdict, jurisdiction, time)` 为规范标注，`π_i=(demonstrator_id, consent, timestamp, source_hash)` 为来源。三分割 `D = D_val ⊎ D_cal ⊎ D_norm`，其中 **D_norm 只用于约束验证、永不参与梯度更新**。共形保证只要求每个分割内可交换，不要求全语料可交换。

**定义 312（共形模态集 M_α）** 非一致性分数 `s(o,m)=1−ŵ_m(o)`；在 D_cal 上取经验分位 `q_{1−α}`；`M_α(o)={m : s(o,m) ≤ q_{1−α}}`。在可交换假设下有覆盖保证 `P(y* ∈ M_α(o)) ≥ 1−α`。**幻影模态 = 模型采样出但不在 M_α 中的模态，禁止其触发任何交互**。若 D_val 上运行覆盖率低于 1−α（分布漂移），置 `β=1`（退回示教先验，定义 315）。

**定义 313（三值合规门 CGD）** 规范库 N 由带优先级的道义规则组成（义务 O / 禁止 F / 许可 P），规则带管辖区与生效窗口。判定：
- **Forbidden**：存在适用的硬禁止（或高优先级禁止）；
- **Permitted**：存在显式许可且无适用禁止；
- **Undetermined**：缺规则、管辖区不明、规范过期、同意缺失，或同优先级冲突。
同优先级冲突**不得任意裁决**，一律升级。CGD 对任务动作、信息动作与拒绝动作一视同仁。

**定义 314（示教—规范防火墙 NUF）** 策略在 `ξ ∈ C_feas(N, ctx)` 上优化 `U_task(ξ; θ_desc) + λ·VoI_D(ξ)`；其中 `C_feas = Feas(N, ctx)` **与 θ_desc 无关**。形式上：`∂C_feas/∂θ_desc = ∅`。任何试图由示范统计改变可行集的信号被判定为「描述性泄漏（descriptive leak）」，拒绝并写入审计。这是休谟 is–ought gap 的架构实现。

**定义 315（示教校准的 VoI，DVoI）** `VoI_D(g) = (1−β)·[H(M_α|o) − E_{y}H(M_α|o,y)] + β·[H_D(r|o) − E_{y}H_D(r|o,y)]`，其中 `H_D(r|o)` 为示教者「在此处是否会执行信息动作」的行为熵，`β∈[0,1]` 在共形失效/ECE 越界时置 1。伦理成本 `c_eth(g)=c_phys+c_social+c_privacy+c_manip`。只在 `CGD(g)=Permitted` 的候选里选 `g*=argmax[VoI_D−c_eth]`；若最大值 ≤ 0 则不交互。

**定义 316（拒绝与升级动作 𝒜_ref）** `𝒜_ref = {defer_to_human, request_consent, decline_task, safe_stop}`。可从示范学习其触发条件，但**可采纳性仍由 CGD 决定**。每个拒绝必须携带 `Explanation=(trigger, norm_trace, M_α, U_deon)`。拒绝不是信息寻求动作，**不参与 VoI 排序**（它是权利保全动作，不是收益动作）。

**定义 317（规范不确定性 U_deon）** `U_deon` 为 {Permitted, Forbidden, Undetermined} 上的不确定性质量，来源包括：规则缺失、管辖区歧义、规范过期、未裁决冲突、同意缺失/过期。算子为**升级/拒绝**，不是询问。核心命题：`U_deon` 不能被任何 `g∈𝒜_info` 消解——除非 N 中存在一条**授权规则**把该信息源指定为权威（定理 19）。

**定义 318（三分不确定性与算子组合）** `U=(U_ale, U_epi, U_deon)`，对应算子：`κ_ale=收紧`（R68 λ_floor）、`κ_epi=询问`（R69 MINT）、`κ_deon=升级∨拒绝`（R70 REF）。组合为**字典序**：先 `CGD`（合规硬层），再 `λ_safety`（安全硬层），最后 `VoI_D`（认知软层）。硬层之间不做数值折中；只有软层允许 resolution bonus。

**定义 319（示教投毒与影响界）** 设投毒语料 D_poison，采用来源过滤 + 按示范者分组的中位数/截尾均值聚合；影响函数界 `‖Δp_D‖ ≤ ε_inf`。若 `ε_inf > ε_max`：置 `β=1`，退回「模型先验 + CGD」路径，并记审计事件。来源缺失、同意失效或重复来源的样本在进入 D_cal 前即被拒。

**定义 320（规范库版本与漂移）** `N=(version, jurisdiction, effective_window, hash)`。运行时钉住版本；两次审计之间若 hash/生效窗口变化，则 `J_ETHOS` 立即作废直至重审计。未知管辖区 ⇒ Undetermined ⇒ 拒绝/升级。

**定义 321（合规证书 J_ETHOS）** `J_ETHOS = (J_FLUID, norm_trace_hash, compliance_verdict, U_deon, conformal_coverage, demo_provenance_hash, consent_ledger_hash, refusal_log_hash, norm_version)`。`Valid ⇔ Valid(J_FLUID) ∧ verdict=Permitted ∧ coverage ≥ 1−α ∧ 规范版本已钉住 ∧ 无未裁决冲突`。

**定义 322（参与式审计 VQAuditor-E）** 审计对象：示范来源与同意、描述性泄漏、未裁决规范冲突、拒绝解释的充分性、共形覆盖率。结论回灌 AuditBuf，作为下一轮 `c_eth` 与 `ε_max` 的先验。

**定义 323（解释契约）** 每个动作/拒绝必须输出三段式解释：**descriptive**（我依据什么信念，含 M_α）、**prescriptive**（依据哪条规范/授权）、**epistemic**（还剩什么不确定）。解释必须非诱导（不得用于说服用户放弃异议），且可被用户反驳（contestable）。

**定义 324（权限委托模型）** 权威 `Auth=(who, scope, resource, time, revocable)`。同意/覆盖必须有明确、限定范围、可撤销、可审计的委托。**模型或环境的回答在被某条规范指定为权威之前，不构成授权**。此定义支撑定理 19。

## 2. 关键算法骨架

```python
# IP-264 DNG：示教锚定 + 共形模态集（封死幻影模态）
class DemoGroundedModes:
    def __init__(self, calib_set, alpha=0.05):
        self.scores, self.alpha = calib_set, alpha
        self.q = quantile(calib_set.scores, 1 - alpha)
    def mode_set(self, o, model):
        return [m for m in model.modes(o)
                if 1 - model.weight(o, m) <= self.q]      # M_alpha
    def coverage_ok(self, val_set):
        return empirical_coverage(val_set) >= 1 - self.alpha   # 否则 beta=1

# IP-265 CGD：三值合规门（对 a / g / a_ref 一视同仁）
def compliance_gate(o, act, N):
    rules = N.applicable(o, act)
    if any(r.is_hard_prohibition for r in rules): return "Forbidden", trace(rules)
    if any(r.is_permission for r in rules):
        conflict = N.unresolved_conflict(rules)
        return ("Undetermined", trace(rules)) if conflict else ("Permitted", trace(rules))
    return "Undetermined", trace(rules)

# IP-267 DVoI：只在 Permitted 候选、M_alpha 模态上算 VoI
def choose_interaction_ethos(modes, o, budget, beta, demo_prior):
    best = None
    for g in info_action_candidates(modes):
        verdict, _ = compliance_gate(o, g, N)
        if verdict != "Permitted":          continue       # 合规先于 VoI
        if not budget.allow(g):             continue
        if not c_ras_wm.certify_info(g, o): continue       # 安全认证
        voi = (1-beta) * model_voi(modes, g, o) + beta * demo_voi(demo_prior, g, o)
        score = voi - eth_cost(g)                          # 物理+社交+隐私+操纵
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268 REF：规范不确定 → 升级/拒绝（不参与 VoI 排序）
def refuse_or_escalate(verdict, U_deon, stakes, trace):
    if verdict == "Forbidden":  return safe_stop(explain=("forbidden", trace))
    if verdict == "Undetermined": return defer_to_human(
        explain=("undetermined", trace, U_deon), require_authority=True)
    return None

# IP-274 主闭环（合规硬层 → 安全硬层 → 认知软层）
def ETHOS_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    # 0) 前置：规范版本与来源校验
    if not M.norm.pinned_and_current(): return M.ref.safe_stop(("norm_drift",))
    # 1) R69 流采样 + 模态分解；再用共形集过滤幻影
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = M.fmp.sample(o, K)
    M_alpha = M.dng.mode_set(o, M.fmp)
    modes = [m for m in modes if m in M_alpha]
    if not modes: return M.ref.defer_to_human(("no_admissible_mode",))
    beta = 1.0 if not M.dng.coverage_ok(M.val_set) else 0.0
    # 2) 合规硬层：任一候选 Forbidden → 弃；Undetermined 且无 Permitted → 升级
    verdicts = [(m, compliance_gate(o, m.a, M.norm)[0]) for m in modes]
    perm = [m for m, v in verdicts if v == "Permitted"]
    if not perm:
        return M.ref.refuse_or_escalate(verdicts[0][1], M.U_deon, M.stakes)
    # 3) 认知软层：DVoI 决定问不问
    g = (M.dvoi.choose_interaction_ethos(perm, o, M.budget, beta, M.demo_prior)
         if M.aud.U_epi(perm) > TAU_EPI else None)
    if g is not None:
        answer = M.cia.execute(g)
        perm   = M.cia.update_belief(perm, answer)        # 仍需 k 源一致
    # 4) 安全硬层（继承 R68/R69，只在 C_feas 内缩放）
    U_floor = M.aud.U_ale(perm) + (M.aud.U_epi(perm) if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(perm, M.aud.U_epi(perm), lam)
    # 5) 证书 + 解释 + 审计
    M.vqa_e.submit_async(g, verdicts, beta, M.dng.coverage_ok(M.val_set))
    return k, lam, mode, Explanation(...), J_ETHOS(...)
```

## 3. 推导

**引理 19（共形覆盖 ⇒ 幻影模态上界）** 若 D_cal 与测试可交换，则 `P(y* ∉ M_α) ≤ α`。由于定义 312 规定只有 `M_α` 内模态可触发交互，故「系统追问一个幻影模态」的概率 ≤ `α + δ_cal`（`δ_cal` 为有限样本分位误差）。系：R69 E300 的「幻影追问 ≤ 5%」从经验目标升级为**可证书化的统计承诺**；这也正面回应 R69 自陈的最大风险——不再用模型自校准去判断模型是否幻觉。

**引理 20（is–ought 防火墙）** 对任意投毒示教 `D'`，`C_feas(N,ctx)` 不变（定义 314 中 D' 不是 `C_feas` 的自变量）；`D'` 只能按影响界 `ε_inf` 改变 `U_task` 与先验。故**任意示教都无法把一个 Forbidden 动作变成可行**。这是与「伦理当奖励罚项」的根本差别：罚项可被更高收益抵消，可行集不能。

**引理 21（拒绝的支配性）** 在 Undetermined 判定下，执行动作的期望成本含 `p_v·C_v`（`C_v` 为违规成本，按硬约束视为不可交易），拒绝的成本仅为有限延迟/打扰成本 `c_def`。当 `p_v·C_v > c_def`（合规场景的常态）时，拒绝严格支配执行。故「Undetermined ⇒ 拒绝/升级」不是保守偏好，而是硬约束下的最优策略。

**定理 18（严格自上而下包含）** ETHOS ⊆ FLUID ⊆ R68（在可采纳与安全意义上）：ETHOS 只在 `M_α ⊆ M`、`C_feas ⊆ 𝒜` 上行动，且从不放松 λ，故其每条输出轨迹对 FLUID 也可采纳，FLUID 对 R68 同理。且当 `verdict=Permitted`、共形覆盖有效、`U_deon=0`、`VoI_D=VoI_model` 时，三者**逐指令相同**。⇒ 安全侧零退步，认知效率保留，规范侧为新增硬层。

**定理 19（同意不可被 VoI 制造）** 道义状态不是观测的函数：`verdict = f(N, Auth, o)`，其中 `N` 必须包含一条把某信息源指定为权威的授权规则。故对任意 `g_ask` 及其回答 `y`，若 N 未授权该源，则 `U_deon` 不变。系：**「问用户能不能」不是 U_deon 的消解算子**；它至多是为一条已授权规范补充证据。这正是对 R69 把 VoI 用于一切不确定性的关键纠正——用询问消解规范不确定性，会把越权洗成合意。

**定理 20（示教投毒鲁棒与有界影响）** 在来源过滤 + 分组稳健聚合下，模态后验漂移 `‖Δp‖ ≤ ε_inf`，DVoI 漂移 `≤ L_H·ε_inf`；若 `ε_inf > ε_max`，置 `β=1` 退回示教无关路径，且 `C_feas` 不受影响。故最坏情况是**性能有界下降、合规零损失**，而不是「学会一个自信的坏习惯」。

## 6. 本轮最大风险

**一句话**：ETHOS-RAS 把「合规」当成一个可判定的谓词，但规范库本身是**不完备、会漂移、且可能被编写者操纵**的——系统会用一张 `J_ETHOS` 证书为一个伦理上错误、但形式上 Permitted 的动作盖章，把 R69 的「被证实的错误」升级成「**被合法化的错误**」；再叠加上示教带来的偏见，它会非常自信地做一件「有据可查地不该做」的事。

**次级风险与缓解**：
1. **规范库不完备/冲突** → 三值判定 + Undetermined 强制升级 + 同优先级冲突零静默裁决（定义 313、E306）；

# IP-264 DNG：共形模态集（封死幻影模态）
class DemoGroundedModes:
    def __init__(self, D_cal, alpha=0.05):
        self.q, self.alpha = quantile(scores(D_cal), 1-alpha), alpha
    def mode_set(self, o, model):
        return [m for m in model.modes(o) if 1-model.weight(o,m) <= self.q]
    def coverage_ok(self, D_val):
        return empirical_coverage(D_val) >= 1-self.alpha        # 否则 beta=1

# IP-265 CGD：三值合规门（a / g / a_ref 一视同仁）
def compliance_gate(o, act, N):
    R = N.applicable(o, act)
    if any(r.hard_prohibition for r in R): return "Forbidden", trace(R)
    if any(r.permission for r in R):
        return ("Undetermined", trace(R)) if N.unresolved_conflict(R) else ("Permitted", trace(R))
    return "Undetermined", trace(R)

# IP-267 DVoI：只在 M_alpha ∧ Permitted 上算 VoI
def choose_interaction_ethos(modes, o, budget, beta, demo_prior):
    best = None
    for g in info_action_candidates(modes):
        if compliance_gate(o, g, N)[0] != "Permitted":   continue
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi = (1-beta)*model_voi(modes, g, o) + beta*demo_voi(demo_prior, g, o)
        score = voi - eth_cost(g)                         # 物理+社交+隐私+操纵
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None

# IP-268 REF：规范不确定 → 升级/拒绝（不参与 VoI 排序）
def refuse_or_escalate(verdict, U_deon, trace):
    if verdict == "Forbidden":    return safe_stop(("forbidden", trace))
    if verdict == "Undetermined": return defer_to_human(("undetermined", trace, U_deon),
                                                        require_authority=True)
    return None

# IP-274 主闭环：合规硬层 → 安全硬层 → 认知软层
def ETHOS_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    if not M.norm.pinned_and_current(): return M.ref.safe_stop(("norm_drift",))
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes = [m for m in M.fmp.sample(o, K)
             if m in M.dng.mode_set(o, M.fmp)]            # 幻影过滤
    if not modes: return M.ref.defer_to_human(("no_admissible_mode",))

    verdicts = [(m, compliance_gate(o, m.a, M.norm)[0]) for m in modes]
    perm = [m for m, v in verdicts if v == "Permitted"]

## 4. 推导

**引理 19（共形覆盖 ⇒ 幻影上界）** `P(y*∉M_α) ≤ α`；只有 M_α 内模态可触发交互 ⇒ **幻影追问概率 ≤ α+δ_cal**。R69 E300 的经验目标升级为可证书化统计承诺，正面回应「模态后验不可信」。

**引理 20（is–ought 防火墙）** 任意投毒示教 `D'` 都不改变 `C_feas(N,ctx)`（D' 不是其自变量），只能按影响界改变效用/先验。故**任意示教都无法把 Forbidden 变可行**——与「伦理当罚项」的根本差别：罚项可被高收益抵消，可行集不能。

**引理 21（拒绝的支配性）** Undetermined 下执行含 `p_v·C_v`（硬违规成本不可交易），拒绝仅付有限 `c_def`；当 `p_v·C_v>c_def`（常态）时拒绝严格支配执行。故「Undetermined⇒拒绝/升级」是硬约束下的最优，而非保守偏好。

**定理 18（严格自上而下包含）** ETHOS ⊆ FLUID ⊆ R68（可采纳/安全意义）：ETHOS 只在 `M_α⊆M`、`C_feas⊆𝒜` 上行动且从不放松 λ。当 `Permitted ∧ 覆盖有效 ∧ U_deon=0 ∧ VoI_D=VoI_model` 时三者逐指令相同。⇒ 安全零退步、认知效率保留、规范新增硬层。

**定理 19（同意不可被 VoI 制造）** `verdict=f(N,Auth,o)`；若 N 未把某信息源指定为权威，则该源的回答不改变 `U_deon`。系：**「问用户能不能」不是 U_deon 的消解算子**，至多为已授权规范补证。这是对 R69「用 VoI 解一切不确定性」的关键纠正——否则会把越权洗成合意。

**定理 20（示教投毒鲁棒）** 来源过滤 + 分组稳健聚合下 `‖Δp‖≤ε_inf`、`ΔVoI_D≤L_H·ε_inf`；`ε_inf>ε_max` 时 β=1 退回示教无关路径，`C_feas` 不变。⇒ 最坏是**性能有界下降、合规零损失**。

## 7. 本轮最大风险

**一句话**：ETHOS-RAS 把「合规」当成可判定的谓词，但规范库本身**不完备、会漂移、且可能被编写者操纵**——系统会用一张 `J_ETHOS` 证书为一个伦理上错误、但形式上 Permitted 的动作盖章，把 R69 的「被证实的错误」升级成「**被合法化的错误**」；叠加示教带来的偏见，它会非常自信地做一件「有据可查地不该做」的事。

**次级风险与缓解**：规范不完备/冲突（三值+强制升级+零静默裁决，E306）；描述性泄漏（NUF 隔离+泄漏审计+影响界，引理 20/定理 20）；把同意当授权（U_deon 独立算子+委托模型+定理 19+E308）；规范漂移（版本钉住+变更即作废，E311）；拒绝被滥用（解释+NormTrace+效率指标+人工复核，E305/E312）。
