# 第 44 轮（新循环第 4 轮） · Grasp-Cert × Test-Cert：把「抓取/接触」与「用户测试」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约空集」，但它仍压着两个更硬的隐含假设：**(H1) 动作连续、证书在接触处仍满足 Lipschitz/CBF**——真实抓取是混合、非光滑、含冲击的，接触模式切换会让基于 v_max 的租约衰减与 CBF 边际在切换瞬间静默失效；**(H2) 验证数据可交换、且验证发生在离线**——用户测试恰恰是自适应、低样本、分布漂移的，固定样本共形的可交换性假设在「真的有人在使用」时直接崩塌。本轮灵感词「抓取」「用户测试」精确命中这两个假设：**抓取**把「接触」从动作细节提升为独立的混合证书层；**用户测试**把「测试」从事后评估提升为带统计保证的在线认证机制。二者耦合处（人-机交接 / 共享抓取）是真正的新问题：接触奇点与人的不可预测性在同一时刻相遇，而用户测试又是在最不能失败的时刻唯一可能发现失效的手段。

## 0. 直觉与动机

**灵感 1（抓取 → 接触是证书的「奇点」，必须单独持证）**：任务级证书默认「动作连续、加速度有界」，但抓取的本质是**接触模式的离散切换**：接近→接触→粘滞→搬运→释放，切换瞬间法向速度跳变、冲击脉冲进入、摩擦锥与接触几何同时改变。此时基于 `λ=L_m·v_max` 的租约衰减**不再是一个下界**——不是数值偏小，而是模型前提被违反。因此必须：(a) 给抓取建立**接触级证书** G（力封闭边际、摩擦锥鲁棒半径、抗滑移边际）；(b) 用**混合接触自动机**显式刻画模式切换，每次切换附**冲击界 + 后置证书**；(c) 每次切换 **bump 接触 epoch**，强制让所有旧租约失效、要求重取。直觉一句话：**接触处不许沿用旧边际，必须重新持证**。

**灵感 2（用户测试 → 从「事后评测」变成「在线认证」，且测试本身必须安全）**：传统用户测试是「跑一批被试，看有没有出事」，这在三处不可证：(1) 被试会自适应地挑难例，破坏可交换性；(2) 可选停止与事后挑选让固定样本 p 值失真；(3) 失败样本极稀少，二元失效统计功效几乎为零。本轮的解法是双管齐下：**其一，安全探索包络**——把用户输入经过一个受控不变集上的安全过滤器，试验按构造不越界；**其二，任意时间有效的 e-process**——允许自适应采样与随时停止而不虚增假阳性；**其三，认证连续边际而非二元失效**——用 `force-closure/slip` 边际的分布做 e-process，即使零事故也能积累证据，绕开「越安全越无法证明安全」的悖论。再叠加 **falsification-guided 采样**：把用户当成「被主动挑选的探针」，用采集函数选择最可能压垮证书的测试条件。

**灵感 3（耦合 → 人-机交接是接触奇点 × 人的不可预测性的交点）**：交接 / 共享抓取时，控制权威在机器人与人间流动，物体受力是**双方合wrench**；机器人过早释放、或人类抓取尚未牢固，就会掉落。于是需要一个**交接证书**：共享相内合wrench 必须落在摩擦锥内并留边际；只有「人类抓取证书的有效下界」成立时才允许释放。用户测试必须专门覆盖交接，并按**手部功能 / 经验分层**，因为交接安全对人群异质性最敏感。

**耦合升级**：GCC（接触证书引擎）把抓取编译成可查表的力封闭/摩擦/滑移证书与混合接触自动机；UTC（用户测试认证器）提供安全包络、anytime-valid e-process 与 falsification 采样；HOC（交接证书）把共享权威、合wrench 与释放守卫纳入同一套守卫。四层架构由此从 v8 的「个性化 + 并发」升级为 v9 的「仿真-检索-边缘飞轮 + 人格契约层 + 并发证书层 + 接触证书层 + 测试证书层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（抓取接触证书）**：对物体 O、接触集 𝒞={(p_i,n_i)} 与摩擦不确定性集 U_μ（含质量/惯量/柔性不确定性），抓取证书
G = (Φ_fc, ρ_fric, m_slip, 𝒞)，其中
- Φ_fc = max{δ : δ·B₆ ⊆ W(𝒞,U_μ)} 为**力封闭边际**（可达 wrench 集 W 内最大内切六维球半径）；
- ρ_fric = min_{μ∈U_μ} dist(所需接触力, 摩擦锥边界) 为**摩擦锥鲁棒半径**；
- m_slip = min_i (μ_i f_{n,i} / f_{t,i}) 为**抗滑移边际**。
G 有效当且仅当 Φ_fc≥θ_fc ∧ ρ_fric≥θ_fric ∧ m_slip≥θ_slip。**命题（保守性）**：若真实 (μ,m,I)∈U_μ 且证书按最坏情形计算，则 G 有效 ⟹ 真实抓取稳定（在刚体+库仑摩擦模型内）；模型集偏小则结论不成立——这正是本轮第一风险。

**定义 45（混合接触自动机与切换证书 + 接触 epoch）**：接触动力学为混合系统，模式 q∈Q_c={free, approach, stick, slip, hold, release}，切换 q→q′ 附切换证书
T_{q→q′} = (G_q, γ, J_max, G_{q′})，
其中 γ 为守卫（相对法向速度 v_n≤v_impact、接触几何可行），J_max 为**冲击脉冲上界**（J = m(1+e)v_n）。切换 sound 当且仅当 G_q 成立、γ 成立、实际脉冲 ≤ J_max 且 G_{q′} 成立。**接触 epoch 命题**：定义 epoch e_c，每次模式切换 e_c←e_c+1。任何在 e_c 签发的租约 ℓ 在 e_c 改变后**必须失效**——因为 `m−λ(t−τ)` 的衰减界依赖同一模式内的 Lipschitz 常数，跨切换（速度跳变）不再构成下界。**推论**：本命题把第 43 轮定义 41 的租约 sound 性收紧为「**模式内有效**」，接触 epoch 是强制重取的形式化触发器。

**定义 46（证书提升 / Certificate Lifting）**：任务级安全集 C_global 只对「不涉及接触奇点」的动作 sound。定义提升证书
C_global↑G = {(x,a) : a 在 G 下接触可行 ∧ x 在提升后的可达域内}。
**定理（提升义务）**：若动作 a 会建立/改变/释放接触，则 a 的 sound 性要求 G 有效且相应 T_{q→q′} 成立；否则任务级证书给出的是**未经论证的外推**。**推论**：任何「接触动作」必须显式携带 G 与 epoch，缺一即拒绝（fail-closed）。

**定义 47（测试证书与安全探索包络）**：一次用户测试试验是一串人类触发输入 {u_t}。测试证书
𝒯 = (E_safe, monitor, abort)，
其中 E_safe ⊆ C_global 为**安全探索包络**，即对任意用户输入 u 都存在运行时守卫把状态限制在 E_safe 内的**受控不变集**。**命题（按构造成安全）**：若 E_safe 是受控不变集且守卫每步执行，则任意用户行为下的试验轨迹都不离开 E_safe，故试验安全与用户是否理性无关。**代价命题**：E_safe 越保守，越难覆盖危险边界；合法扩大 E_safe 必须走第 43 轮「扩张持证」三重闸门，不能为测试方便而放宽。

**定义 48（任意时间有效的用户测试认证）**：用户测试具有自适应采样与可选停止，固定样本共形的可交换性不成立。改用 **e-process**：在零假设 H₀: p≤p₀（p 为边际违约率）下，(E_t) 为非负上鞅且 E₀=1，当 E_t≥1/α 拒绝 H₀。由 Ville 不等式，P_{H₀}(sup_t E_t ≥ 1/α) ≤ α，**对任意停时与自适应选择成立**。采用 betting e-process：E_t=∏_s (1+λ_s(x_s−p₀))，λ_s∈[0,1/p₀) 且可预测。**关键替代**：把 `x_s=1[m_s<θ]` 取为**连续边际跌破阈值**的指示，而非灾难性失效，从而在零事故下仍有非平凡功效。**命题**：e-process 覆盖在分布漂移与自适应采样下仍有效，直接修补 v20 的「边际覆盖可被欺骗」缺陷。

**定义 49（人-机交接证书）**：共享抓取期控制权威 α∈[0,1]（α=1 全机器人、α=0 全人类），合wrench w = α·w_r + (1−α)·w_h。交接证书
H = (wrench_guard, release_guard, abort)：
- **共享相守卫**：w ∈ W(𝒞,U_μ) 且 ρ_fric(w) ≥ θ_fric；
- **释放守卫**：仅当人类抓取证书的**有效下界** Ĝ_h^{lo}（由触觉/视觉在 U_μ 下保守估计）满足 Φ_fc≥θ_fc ∧ m_slip≥θ_slip 时才允许释放；
- **abort**：滑移监测触发即降 α（回收权威）并可安全停机。
**命题**：若共享期 wrench 始终在摩擦锥内且释放时 Ĝ_h^{lo} 有效，则（在模型假设内）交接不掉落；模型误差是唯一的 soundness 缺口。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 GRASP-CONTACT-CERTIFICATE（接触证书引擎 GCC）
1. **抓取证书编译**：物体模型 + 接触集 + 摩擦/质量/柔性不确定性 → G=(Φ_fc, ρ_fric, m_slip, 𝒞)，编译为可查表的守卫谓词与力矩约束。
2. **混合接触自动机**：模式集合、切换守卫、冲击界 J_max 与后置证书；每次切换 bump 接触 epoch。
3. **证书提升接口**：把 G 与 epoch 注入任务级守卫（定义 46），接触动作缺证即 fail-closed。
4. **不确定性集管理**：摩擦/质量/柔性区间来自 CKB 与在线辨识；区间偏小即触发重标定，而不是静默收紧。

### 2.2 IP-61 USER-TEST-CERTIFIER（用户测试认证器 UTC）
1. **安全探索包络**：在 C_global 上求受控不变集 E_safe，用户输入经安全过滤器；越界即截断/回退。
2. **anytime-valid 统计**：betting e-process + 置信序列；允许自适应采样、可选停止、事后不挑样本。
3. **falsification-guided 采样**：以「预期边际下降 × 可达性权重」为采集函数，主动选择测试条件（质量/摩擦/速度/交接时相）。
4. **分层用户测试协议**：预注册、知情同意、按手部功能与经验分层、within-subject、对照组（无证书/纯收缩）、主客观指标与安全排除标准。

### 2.3 IP-62 HANDOVER-CERT（交接证书 HOC）
1. **共享权威与合wrench 守卫**：α 调度 + 摩擦锥边际监测，滑移即回收权威。
2. **释放守卫**：人类抓取证书有效下界 Ĝ_h^{lo} 成立才释放，杜绝过早松手。
3. **交接压力测试**：按人群分层、随机时相、干扰（拉拽/迟疑/反复）注入，纳入 ICV 回放。

```
    + IP-55 CKB(抓取/测试语料) ← IP-59 ICV(接触 fuzz + 用户测试回放) + IP-54 SCV(接触丰富仿真)

```

**用户测试协议（UTC 内建）**：预注册假设与主指标；知情同意与安全排除标准；按手部功能/经验分层；within-subject 随机顺序；对照组为「纯收缩个性化 + 无测试包络」；主指标任务成功/掉落/恢复；主观指标 NASA-TLX、信任、感知安全、证书解释理解度；统计用 e-process 实时监测，禁止事后挑样本；触发 abort 即回收权威并存档反例回灌 CKB/SCV。伦理与 IRB 前置。

**回退**：E95/E96 不达标 → 接触动作退化为「保守准静态抓取 + 不切换模式」，牺牲速度保安全；E98 包络过小 → 只在仿真/受控台架做高风险测试，实机只做保守包络内测试；E99 功效不足 → 改用仿真增广 + 边际认证，并在报告中显式声明实机统计功效上限；E100 无收益 → 退回均匀分层采样；E101 交接不达标 → 禁止共享抓取，只允许「放置后由人拾取」的单向交接；任何红线失败 → 全链路熔断回退 v20。

## 5. 本轮最大风险

**一句话**：抓取证书的 soundness 完全依赖摩擦/质量/柔性接触模型的不确定性集是否「保守而不失真」，而人-机交接恰好是模型最易失真、样本最少、后果最重的场景；一旦不确定性集偏小，接触切换会在用户测试中把「证书完备」变成「静默失真」，而 anytime-valid 统计在零失效下功效极低，形成「**越安全越难以证明安全**」的认证悖论。

## 2. 关键算法（伪代码）

### IP-60 GCC：抓取证书、接触切换与证书提升
```
def grasp_certificate(obj, contacts, U_mu):
    G = grasp_matrix(contacts, obj.geometry)
    W = achievable_wrench_set(G, U_mu)              # 含摩擦/质量不确定性
    phi_fc = max_inner_ball_radius(W, dim=6)        # 力封闭边际
    rho    = min_mu_dist_to_friction_cone(contacts, U_mu)
    m_slip = min(friction_ratio(contacts[i], U_mu, obj.load) for i in contacts)
    return GraspCert(phi_fc, rho, m_slip, contacts,
                     valid=(phi_fc >= TH_FC and rho >= TH_FRIC and m_slip >= TH_SLIP))

def contact_transition_cert(q, q_next, x, obj, U_mu):
    v_n = relative_normal_velocity(x)                # 切换瞬间法向速度
    J   = obj.mass * (1 + restitution) * max(v_n, 0) # 冲击脉冲上界
    if J > J_max or not grasp_certificate(obj, contacts_of(q_next), U_mu).valid:
        return INVALID
    return TransitionCert(J_max=J, guard=(v_n <= v_impact),
                          post=grasp_certificate(obj, contacts_of(q_next), U_mu))

def bump_contact_epoch(state):
    state.epoch_c += 1                              # 失效所有旧租约（Lipschitz 跨切换不成立）
    return state.epoch_c

def lifted_guard(e, x, task_cert, grasp, lease, state):
    if lease.epoch_c != state.epoch_c:              # 接触 epoch 变了，旧边际不可信
        return REACQUIRE
    if touches_contact(e) and not grasp.valid:      # 接触动作缺抓取证书 => fail-closed
        return REJECT
    return car_transition_guard(e, x, task_cert, grasp, lease, monotonic_now())
```

### IP-61 UTC：安全包络、e-process 与 falsification 采样
```
def safe_envelope(C_global, model, guard_any_user_input):
    # 满足：∀u∈U, 守卫后状态仍留在 E；即最大受控不变集
    return maximal_controlled_invariant(C_global, model, guard_any_user_input)

class EProcess:                                     # betting e-process，anytime-valid
    def __init__(self, p0, alpha):
        self.logE, self.p0, self.alpha = 0.0, p0, alpha
    def update(self, x, lam):                        # x∈{0,1}; 0<=lam<1/p0 且可预测
        self.logE += math.log(1.0 + lam * (x - self.p0))
        return self.logE >= math.log(1.0 / self.alpha)   # Ville: 可选停止/自适应有效

def certify_margin_sequence(margins, theta, p0, alpha):
    ep = EProcess(p0, alpha)
    for m in margins:
        x  = 1 if m < theta else 0                   # 认证连续边际跌破阈值，而非灾难性失效
        ep.update(x, lam=bet_predictor(m))           # 零事故下仍有非平凡功效
    return ep

def run_user_trial(u_seq, E_safe, monitor):
    for u in u_seq:
        u_safe = safety_filter(u, E_safe)            # 任意用户输入被夹住
        if not monitor.step(u_safe):
            return abort_and_reclaim_authority()     # 触发 abort：回收权威、存档反例
    return trial_ok()

def falsification_select(test_space, E_safe, surrogate):
    cand = [t for t in test_space if reachable(t, E_safe)]
    return max(cand, key=lambda t: surrogate.expected_margin_drop(t)   # 采集函数
                                  * reachability_weight(t))
```

### IP-62 HOC：交接守卫
```
def handover_guard(grasp, human_est, state):
    w = combine_wrench(robot_wrench(state), human_est.wrench, alpha=state.alpha)
    if not inside_friction_cone(w, grasp.mu_lower):      # 合wrench 越界
        return BLOCK
    if state.release_requested:
        # 释放前人类抓取证书的有效下界必须成立，否则继续托住
        return RELEASE if human_est.cert_lower.valid else HOLD
    return SHARED

def on_slip_detected(state):
    state.alpha = max(0.0, state.alpha - DELTA)          # 滑移即回收权威给人类/停
    return state
```

**用户测试协议（UTC 内建，预注册）**：目的——验证 G/HOC 在真实人群下的安全与可用，并为主张提供 anytime-valid 证据。设计——按手部功能（正常/受限）与经验（新手/熟练）分层；within-subject，条件随机顺序；对照组＝「纯收缩个性化 + 无测试包络」；主指标＝任务成功、掉落、恢复时间、包络越界（应为 0）；主观＝NASA-TLX、信任、感知安全、证书解释理解度；安全＝知情同意、安全排除标准、实时 e-process 监测、abort 即回收权威并存档反例；统计＝e-process + 置信序列，禁止事后挑样本；伦理＝IRB 前置。分析——报告边际与分层（Mondrian）结果，并显式给出实机统计功效上限。

**回退**：E95/E96 不达标 → 接触动作退为「保守准静态抓取 + 不切换模式」，牺牲速度保安全；E98 包络过小 → 高风险测试只在仿真/受控台架，实机限保守包络；E99 功效不足 → 仿真增广 + 边际认证，报告中声明实机功效上限；E100 无收益 → 退回均匀分层采样；E101 交接不达标 → 禁共享抓取，只允许「放置后由人拾取」单向交接；任何红线失败 → 全链路熔断回退 v20。

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 摩擦/质量/柔性不确定性集偏小 → 抓取证书假 sound | 高 | E95 红线；U_μ 由在线辨识与 CKB 保守下界共同维护；每批次力封闭边际实机抽检；区间缩小需重标定 |
| 接触切换冲击不可建模 → 冲击界/epoch 失效 | 高 | E96 红线；准静态优先；冲击速度硬限；切换即 bump epoch 强制重取；高速接触只在仿真认证 |
| 用户测试零失效导致统计功效极低（认证悖论） | 高 | 认证连续边际而非二元失效；仿真增广 + 分层蒙特卡洛；显式报告功效上限，不把「无事故」当「已证明安全」 |
| 测试过拟合 / Goodhart（为通过测试而优化指标） | 中-高 | 协议预注册 + 测试协议哈希绑定证书；falsification 主动找反例；独立验证方签发测试证书；部署后在线 e-process 持续监测 |
| 人类抓取证书估计误差 → 释放过早掉落 | 高 | E101 红线；释放守卫用有效下界 Ĝ_h^{lo}；滑移即回收权威；失败案例回灌 SCV/ICV |
| 安全包络过小 → 测试覆盖不到危险边界 | 中 | 包络扩大走「扩张持证」三重闸门；仿真内用更大包络找反例；分层报告覆盖缺口 |
| 混合自动机组合爆炸 / 切换守卫冲突 | 中 | IP-47 组合接口 + 冲突检测；模式数受限；CI 静态检查守卫全覆盖 |
| e-process/包络计算在边缘端超时 | 中 | 离线预计算包络；e-process 仅低频更新；紧要路径只读缓存 |

## 6. 本轮最大风险

**一句话**：抓取证书的 soundness 完全依赖摩擦/质量/柔性接触模型的不确定性集是否「保守而不失真」，而人-机交接恰好是模型最易失真、样本最少、后果最重的场景；一旦不确定性集偏小，接触切换会在用户测试中把「证书完备」变成「静默失真」，而 anytime-valid 统计在零失效下功效极低，形成「越安全越难以证明安全」的认证悖论。
