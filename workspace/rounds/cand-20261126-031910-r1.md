（灵感驱动研究循环·新灵感三元组第 1 轮；本轮灵感：「数据集」×「迭代验证」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-431–439（其上承 v22 分层 PGEV/机械臂/深度 conformal、v21 语义-规范层 SDC/CAC/DCL/GIC、v20 联邦感知证书、v19 证书体系 DCM/OGCC/CCV/DRS/OGC、v17 感知链 CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**数据集是证书的证据地基，迭代验证是证书的时间维度**。不推倒 v23：SDC/CAC/DCL/GIC、分层 PGEV、ACSC、DCSC、CESC/FSVC/IPAM/HPC-E+ 全部保留。本轮只做一件事：**给 v23 的每一个统计性承诺加装"数据集证人"与"任意时刻有效的持续验证"，把"一次性认证"升级为"可撤回、可增补、可审计的证书生命周期"，并顺手把前几轮最大风险（缺席幻觉 / 版本共振）变成结构性保守**。

## 0. 直觉与动机

**灵感 1（数据集 → 证据地基、分层覆盖与"数据近亲繁殖"）**
直觉：v23 里所有漂亮的界——召回下界 κ_c、1-α conformal、原型漂移 Δ_proto、云边 KL 漂移——本质上都是"相对于某个数据集分布"的陈述，但文档从未把数据集本身当作证书对象。数据集不是背景，而是**证据地基**；一张没有 provenance、没有分层覆盖统计、没有有效样本量的数据集，签出的证书是"无源之证"。
核心创新：**数据集来源与覆盖证书 (Dataset Provenance & Coverage Certificate, DPCC)**。关键反直觉点一：**把 κ_c 从全局标量升级为分层 κ_c(s)，并把未覆盖分层的 κ_c(s) 直接设为 0**。缺席证书 (AbsCert) 在"从未见过儿童/轮椅/蹲姿/强逆光"的分层上自动拒签——v21 的"合规的缺席幻觉"从工程风险变成一条可证明的保守性定理（Clopper–Pearson 下界在 n_s→0 时趋于 0）。关键反直觉点二：联邦共享数据会让"样本量"虚高——同一段原始采集被增强/回放/重标注后重复计数，破坏了 conformal 所依赖的可交换性。所以数据集证书必须携带**血缘去重后的有效样本量 n_eff**，把"数据近亲繁殖"挡在置信界之外——这是 v21 的 NMS 证据去重、v22 的模态 quorum 在**数据层**的同构。

**灵感 2（迭代验证 → 任意时刻有效的证据过程与单调撤回）**
直觉：一次性认证是一个善意的谎言——分布会漂移、κ_c 会失效、模型会衰减。证书应是一条**持续运行的证据过程**，而不是静态快照。关键反直觉点一：如果在固定样本上算 conformal 再"持续监控"，反复看结果会膨胀第一类错误（peeking problem）。正解是用 **betting e-process / 置信序列**：任意时刻停止都保持 anytime-valid 的 δ 保证（Ville 不等式），于是"每来一帧更新一次、随时可撤回"在统计上合法，且 O(1) 更新。关键反直觉点二：**撤回应单调、扩张要有 hysteresis**——两次验证事件之间证书只能收缩（更保守），扩张必须等一次全新的、通过 DPCC+AVIV 的验证事件，且扩张阈值严于撤回阈值（δ_expand < δ_retract）。这既保证 `Exec_v24 ⊆ Exec_v23`，又避免"证书抖动 / 分层振荡"（v22 遗留风险）。
核心创新：**任意时刻有效迭代验证器 (Anytime-Valid Iterative Validator, AVIV) + 单调撤回控制器 (Monotone Retraction Controller, MRC)**。

**灵感 3（两者如何闭环 → 主动补数据的迭代验证环）**
直觉：光会撤回还不够——撤回后活性会长期塌陷。需要一条**从违规到补数据再到重新认证**的闭环：某分层 s 的 e-process 报警/覆盖跌破 → MRC 撤回 → **主动数据增补控制器 (Active Dataset Augmentation Controller, ADAC)** 按"风险加权 deficit"分配标注预算去补 s → 新数据经 DPCC 与 ELD 去重 → 触发再验证事件 → 满足 δ_expand 才扩张。关键反直觉点：**补数据不是越多越好，而是"补最缺证据的分层"最划算**——把标注预算看成对"证书赤字"的贪心消除，可在同样预算下最快恢复活性。

**三者如何统一**
统一为 **证书生命周期管理 (Certificate Lifecycle Management, CLM)**：DPCC 回答"这张证书凭哪份数据、在哪些分层上成立"，AVIV 回答"它此刻还成立吗、能否随时撤回"，MRC/ADAC 回答"撤回后如何单调地恢复、靠补什么数据恢复"。共享状态由 ζ_ce 扩展为 **ζ_life = ζ_ce ∪ (D_prov, S, n_eff, E_t, L_t, C_eff, retract_ledger, deficit)**。统一准入门：**HPC-D = HPC-E+ ∩ DPCC ∩ AVIV**——只有"物理接地（v23 HPC-E+）∧ 数据集接地（DPCC）∧ 时刻有效（AVIV 未撤回）"才进入执行；任一缺失退回 v23 的保守收缩，再退 v22…v18。新执行集 **`Exec_v24 = Exec_v23 ∩ Fil_dpc ∩ Fil_aviv ⊆ Exec_v23`**。

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 数据集接地保证律（Dataset-Grounded Guarantee）**
任何统计承诺都必须携带数据集证人 `D = (id, ver, h_merkle, prov_chain, S, n_s, n_eff_s)`，且只在其认证分层上成立：分层 s 若 `n_eff_s < n_min(s)` 则 `κ_c(s) = 0`，AbsCert 在 s 上拒签。**无证人则无保证**：provenance 断裂、merkle 校验失败或数据损坏时，所有 κ_c(s) 归零、退化为全域保守（比 v23 更保守）。分层召回下界取 Clopper–Pearson：`κ_c(s) = Beta^{-1}(δ; TP_s, FN_s+1)`（TP_s=0 时 κ_c(s)=0）。

**P44 任意时刻有效迭代验证律（Anytime-Valid Iterative Validation）**
验证是运行中的 e-process：`E_t = ∏_{i=1}^t (1 + λ_i(m_0 − X_i))`，其中 `m_0 = 1-α`、`X_i ∈ {0,1}` 为第 i 次独立验证的覆盖指示、`λ_i` 可预测且 `λ_i < 1/(α+ε)`。在零假设"覆盖 ≥ 1-α"下 `E_t` 为非负上鞅，Ville 保证 `P(∃t: E_t ≥ 1/δ) ≤ δ`。覆盖另以任意时刻有效置信序列下界 `L_t` 表示，仅在 `L_t ≥ 1-α ∧ E_t < 1/δ` 时维持"覆盖有效"。**持续监控不膨胀第一类错误，可选停止合法。**

**P45 单调撤回律（Monotone Retraction）**
在偏序格 (C, ⊑) 上（C1 ⊑ C2 表示 C1 至少与 C2 一样保守、Exec(C1) ⊆ Exec(C2)）：验证事件 τ 处刷新 `C(τ)`；两次事件之间 `C_eff(t) = C(τ_last) ⊓ R(τ_last, t)`，只降不升（只更保守）。**扩张必须由新的验证事件驱动，且 `δ_expand < δ_retract`**（扩张比撤回更"难"，非对称）。故段内 Exec 单调不增，且任意时刻 `Exec_v24(t) = Exec_v23 ∩ Fil_dpc ∩ Fil_aviv(t) ⊆ Exec_v23`；撤回扩张有滞回，不振荡。

**P46 证据独立律（Evidence Independence）**
共享/联邦数据必须按血缘去重：`lineage(x)` 追溯到原始采集事件，同源（增强/回放/重标注）样本只计一次；有效样本量 `n_eff = (Σw)²/Σw²`（Kish）或簇内相关修正 `n_eff = n/(1+(m-1)ρ)`。**相关样本不得计入分层配额，也不得计入共识 quorum**；任何"同源重复"都不得提升置信。

## 3. 与基线的接口（如何退化）

- DPCC 失效（无 provenance / 数据损坏 / merkle 不匹配）⇒ 所有 κ_c(s)=0、AbsCert 全域拒签 ⇒ 比 v23 更保守（等价于人形共享区限速），安全继承方向不变；
- AVIV 失效（e-process 无法计算 / 时钟异常）⇒ 回落 v23 的固定样本 conformal（一次性、不扩张），不放松；
- MRC 失效（撤回控制器崩溃）⇒ `C_eff` 冻结为最近一次有效验证的最保守值 ⇒ 子集；
- ADAC 失效（无法补数据）⇒ 只保持撤回、不主动扩张 ⇒ 子集；
- ELD 失效（血缘不可追溯）⇒ 全部共享数据视为强相关，n_eff 退化为最保守（按单一来源计）⇒ 子集；
- 全失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。
- **安全继承**：DPCC 只按分层收紧保证（未覆盖归零）、AVIV 只提供撤回（不直接放松）、MRC 只交/收缩、ADAC 只补数据不改门、ELD 只降 n_eff；任意失效都向更保守方向退化。DPCC/AVIV/MRC 以事件方式接入 v17 APS 新鲜度阶梯与 v23 CESC 版本切换：每次验证/撤回携带时间戳，控制路径仅 O(1) 查询。

## 4. 预期贡献

1. **数据集即一等证书对象**：provenance merkle 链 + 分层覆盖 + 有效样本量，首次把"证据地基"纳入可机械复核的证书体系；
2. **分层召回下界 κ_c(s) 与未覆盖归零**：把 v21 的缺席幻觉从工程风险升级为结构性、可证明的保守性（未覆盖分层 AbsCert 拒签）；
3. **任意时刻有效迭代验证**：betting e-process + 置信序列，使持续监控与可选停止在统计上合法（Ville），封堵"固定样本 + 持续偷看"的 peeking 漏洞；
4. **单调撤回 + 非对称扩张**：证书生命周期的偏序格投影，可证明不振荡、不越界，保留 `Exec_v24 ⊆ Exec_v23`；
5. **证据独立 / 有效样本量**：血缘去重使联邦数据"近亲繁殖"不虚增置信，是 NMS 去重 / 模态 quorum 在数据层的同构；
6. **主动分层补数据闭环**：风险加权 deficit 的预算贪心，使撤回后活性以近最优速率恢复；
7. **HPC-D 门 + 证书账本**：签发/撤回/扩张/补数据全事件 append-only merkle，全生命周期可审计。

## 5. 本轮最大风险

**一句话**：当"迭代验证"的标注与"数据集"的来源都与被验证的感知系统同源（自标注、同批增强、基准污染 / 应试数据集）时，e-process 会以任意小的 δ 高效地"验证"一个自我印证的闭环、DPCC 也会被精心挑选的数据集满足——系统因此持有一张**分布内无懈可击、分布外系统性失效**的证书，即"可审计的自我印证幻觉"。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 Dataset Provenance & Coverage Certificate (DPCC)
# ============================================================
@dataclass
class DatasetCertificate:
    ds_id: str
    version: int
    merkle_root: bytes
    prov_chain: list[bytes]           # 采集→标注→增强→入库 签名链
    n_raw: dict[str, int]             # 分层 -> 原始样本数
    n_eff: dict[str, float]           # 分层 -> 有效样本数（ELD 去重后）
    recall_stats: dict[str, tuple[int, int]]  # 分层 -> (TP_s, FN_s)

    def prov_ok(self) -> bool:
        return (verify_sig_chain(self.prov_chain)
                and self.merkle_root == merkle_root_of(self.prov_chain))

    def kappa_c(self, s: str, delta: float = 0.01) -> float:
        """分层召回 Clopper–Pearson 下界；无正例则归零"""
        tp, fn = self.recall_stats.get(s, (0, 0))
        if tp == 0:
            return 0.0
        # 用有效样本量收缩（保守）：把 n_eff 映射为等效整数计数
        n_eff = max(1.0, self.n_eff.get(s, 0.0))
        tp_eff = tp * (n_eff / max(tp + fn, 1))
        fn_eff = fn * (n_eff / max(tp + fn, 1))
        return float(beta.ppf(delta, tp_eff, fn_eff + 1.0))

    def stratum_covered(self, s: str, kappa_release: float,
                        delta: float = 0.01, eps: float = 0.02) -> bool:
        return (self.n_eff.get(s, 0.0) >= n_min(s, delta, eps)
                and self.kappa_c(s, delta) >= kappa_release + eps)

    def admits(self, kappa_release: float = 0.9) -> bool:
        """DPCC(D)：来源可信 且 所有目标分层覆盖达标"""
        return self.prov_ok() and all(
            self.stratum_covered(s, kappa_release) for s in TARGET_STRATA)

    def kappa_for_release(self, s: str) -> float:
        """AbsCert 释放自由空间时调用：未覆盖分层直接给 0（拒签）"""
        return self.kappa_c(s) if self.stratum_covered(s, KAPPA_RELEASE) else 0.0


# ============================================================
# IP-441 Anytime-Valid Iterative Validator (AVIV)
# ============================================================
class AnytimeValidValidator:
    """betting e-process + 任意时刻有效覆盖下界。"""
    def __init__(self, alpha=0.01, eps=0.02, delta=1e-4, lam_max=0.5):
        assert lam_max < 1.0 / (alpha + eps)      # 保证 (1+λ(m0-X)) > 0
        self.alpha = alpha
        self.m0 = 1.0 - alpha
        self.delta = delta
        self.lam_max = lam_max
        self.log_E = 0.0          # 累积 log e-value（避免下溢）
        self.t = 0
        self.n = 0
        self.mean = 0.0           # 覆盖率经验均值

    def _predictable_lambda(self) -> float:
        # 可预测下注：随 t 收缩，兼顾功效与数值稳定
        return min(self.lam_max, 1.0 / math.sqrt(self.t + 1.0))

    def update(self, covered: bool) -> bool:
        """每来一条独立验证样本更新一次；返回证书是否仍有效。"""
        x = 1.0 if covered else 0.0
        lam = self._predictable_lambda()
        # 覆盖跌破 m0 时 (m0 - x) > 0 累积，E_t 增长
        self.log_E += math.log1p(lam * (self.m0 - x))
        self.t += 1
        self.n += 1
        self.mean += (x - self.mean) / self.n
        return self.valid()

    def lower_bound(self) -> float:
        """任意时刻有效下界（简化：经验均值 − 时间均匀半径）"""
        if self.n == 0:
            return 0.0
        # 时间均匀 Hoeffding 型半径，对任意停止时刻有效
        radius = math.sqrt(math.log(math.log(2.0 * self.n + 2.0) / self.delta)
                           / (2.0 * self.n))
        return self.mean - radius

    def valid(self) -> bool:
        """AVIV_valid(t)：未检出违规 且 覆盖下界达标"""
        return (self.log_E < math.log(1.0 / self.delta)
                and self.lower_bound() >= 1.0 - self.alpha)

    def e_value(self) -> float:
        return math.exp(self.log_E)


# ============================================================
# IP-442 Monotone Retraction Controller (MRC)
# ============================================================
class MonotoneRetractionController:
    """偏序格上的单调撤回 + 非对称扩张闸门。"""
    def __init__(self, delta_retract=1e-4, delta_expand=1e-6):
        assert delta_expand < delta_retract          # 扩张比撤回更难
        self.delta_retract = delta_retract
        self.delta_expand = delta_expand
        self.C_validated = None   # 最近一次验证通过的证书
        self.C_eff = None         # 有效证书（只降不升）

    def on_validation_event(self, C_new) -> bool:
        """新验证事件：收缩即时接受；扩张须更严证据。"""
        if self.C_eff is None or is_more_conservative(C_new, self.C_eff):
            self.C_validated = C_new
            self.C_eff = C_new
            return True
        if self._expansion_ok(C_new):
            self.C_validated = C_new
            self.C_eff = C_new
            return True
        # 证据不足的"扩张"被忽略，保持保守
        return False

    def on_retract(self, R) -> None:
        """其间撤回：与当前有效证书取下确界（只降）"""
        self.C_eff = meet(self.C_eff, R) if self.C_eff else R

    def _expansion_ok(self, C_new) -> bool:
        return C_new.evidence >= math.log(1.0 / self.delta_expand)

    def admits(self, plan) -> bool:
        return self.C_eff is not None and contains(self.C_eff, plan)


# ============================================================
# IP-443 Active Dataset Augmentation Controller (ADAC)
# ============================================================
class ActiveDatasetAugmentationController:
    def __init__(self, budget: int, severity: dict, prior: dict):
        self.budget = budget
        self.severity = severity    # 分层 -> 风险权重
        self.prior = prior          # 分层 -> 先验出现概率 P(s)

    def allocate(self, deficit: dict[str, float]) -> dict[str, int]:
        """风险加权 deficit 贪心分配：单位预算期望风险消除最大者优先"""
        score = {s: deficit[s] * self.severity[s] * self.prior[s]
                 for s in deficit if deficit[s] > 0}
        order = sorted(score, key=score.get, reverse=True)
        alloc, remaining = {}, self.budget
        for s in order:
            take = int(min(math.ceil(deficit[s]), remaining))
            if take > 0:
                alloc[s] = take
                remaining -= take
            if remaining <= 0:
                break
        return alloc


# ============================================================
# IP-444 Evidence Lineage Deduplicator (ELD)
# ============================================================
class EvidenceLineageDeduplicator:
    def __init__(self):
        self.seen_roots: set[bytes] = set()
        self.cluster_size: dict[bytes, int] = {}

    def dedup(self, samples):
        kept = []
        for x in samples:
            root = lineage_root(x)          # 追溯到原始采集事件
            if root in self.seen_roots:
                self.cluster_size[root] += 1
                continue
            self.seen_roots.add(root)
            self.cluster_size[root] = 1
            kept.append(x)
        return kept

    def effective_n(self, kept, weights=None) -> float:
        """Kish 有效样本量；同源样本不虚增 n"""
        if not kept:
            return 0.0
        if weights is None:
            return float(len(kept))
        sw = sum(weights)
        sw2 = sum(w * w for w in weights)
        return (sw * sw / sw2) if sw2 > 0 else 0.0

    def icc_corrected(self, n: int, cluster_mean: int, rho: float) -> float:
        """簇内相关修正：n_eff = n / (1 + (m-1)ρ)"""
        return n / (1.0 + max(cluster_mean - 1, 0) * rho)

# IP-445 Drift-Triggered Revalidation (DTR)
# ============================================================
class DriftTriggeredRevalidator:
    """MMD 双样本 e 检验：分布漂移超阈值即触发再验证事件。"""
    def __init__(self, ref_feats, kernel=mmd_kernel, delta=1e-3):
        self.ref = ref_feats
        self.kernel = kernel
        self.delta = delta

    def should_revalidate(self, new_feats) -> bool:
        stat = mmd2(self.ref, new_feats, self.kernel)
        # 置换/e 值风格阈值（简化）：超阈值视为漂移
        return stat > self.delta

    def emit_event(self, ds_cert, aviv):
        """构造再验证事件：DPCC 重算分层 + AVIV 新 e-process 段"""
        return RevalidationEvent(ds_version=ds_cert.version,
                                 e_value=aviv.e_value())

@dataclass
class HPCD:
    hpc_e_plus: 'HPCEPlus'
    dpcc: DatasetCertificate
    aviv: AnytimeValidValidator
    mrc: MonotoneRetractionController
    kappa_release: float = 0.9

    def admits(self, plan, x, v, z, E_res, margin_req, modules) -> bool:
        # 1. v23 物理接地（几何∧规范∧负信息∧能量∧差距）
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2. 数据集接地：来源可信 + 分层覆盖达标

            return False
        # 3. 任意时刻有效：未撤回

            return False
        # 4. 有效证书包含该计划
        if not self.mrc.admits(plan):
            return False
        return True

# IP-447 Certificate Lifecycle Ledger (CLL)
# ============================================================
class CertificateLifecycleLedger:
    def __init__(self):
        self.head = b"\x00" * 32
        self.entries = []

    def append(self, event) -> bytes:
        e = {"prev": self.head.hex(),
             "type": event.type,          # ISSUE/RETRACT/EXPAND/AUGMENT
             "ts": now(),
             "ds_version": event.ds_version,
             "e_value": event.e_value,
             "payload_hash": sha256(repr(event)).hexdigest()}
        self.head = sha256(json.dumps(e, sort_keys=True).encode()).digest()
        self.entries.append(e)
        return self.head

    def verify(self) -> bool:
        h = b"\x00" * 32
        for e in self.entries:
            body = dict(e); body.pop("prev")
            if e["prev"] != h.hex():
                return False
            h = sha256(json.dumps({**body, "prev": e["prev"]},
                                  sort_keys=True).encode()).digest()
        return h == self.head


# ============================================================
# 端到端生命周期环：感知 → 证书 → 共识 → 验证 → 撤回/补数据
# ============================================================
class CertificateLifecyclePipeline:
    def __init__(self, cfg):
        self.dpcc = cfg["dpcc"]
        self.aviv = AnytimeValidValidator(cfg["alpha"], cfg["eps"],
                                          cfg["delta"])
        self.mrc = MonotoneRetractionController(cfg["delta_retract"],
                                                cfg["delta_expand"])
        self.eld = EvidenceLineageDeduplicator()
        self.adac = ActiveDatasetAugmentationController(cfg["budget"],
                                                        cfg["severity"],
                                                        cfg["prior"])
        self.dtr = DriftTriggeredRevalidator(cfg["ref_feats"])
        self.ledger = CertificateLifecycleLedger()
        self.hpcd = HPCD(cfg["hpc_e_plus"], self.dpcc, self.aviv, self.mrc)

    def step(self, sensor, validation_sample=None) -> tuple[bool, dict]:
        # 1. 漂移检测 → 触发再验证事件
        if self.dtr.should_revalidate(sensor["feats"]):
            self.mrc.on_retract(self._conservative_shrink("drift"))
            self.ledger.append(Event("RETRACT", self.dpcc.version,
                                     self.aviv.e_value()))

        # 2. 有独立验证样本 → 更新 e-process
        if validation_sample is not None:
            kept = self.eld.dedup([validation_sample])
            if kept:
                covered = self._is_covered(validation_sample)
                self.aviv.update(covered)
                if not self.aviv.valid():
                    self.mrc.on_retract(self._conservative_shrink("coverage"))
                    self.ledger.append(Event("RETRACT", self.dpcc.version,
                                             self.aviv.e_value()))

        # 3. 分层赤字 → 主动补数据（异步、非阻塞）
        deficit = {s: max(0, n_min(s, self.aviv.delta, 0.02)
                          - self.dpcc.n_eff.get(s, 0.0))
                   for s in TARGET_STRATA}
        if any(v > 0 for v in deficit.values()):
            alloc = self.adac.allocate(deficit)
            self.ledger.append(Event("AUGMENT", self.dpcc.version,
                                     self.aviv.e_value(), alloc))

        # 4. HPC-D 准入
        admitted = self.hpcd.admits(sensor["plan"], sensor["x"], sensor["v"],
                                    sensor["z"], sensor["E_res"],
                                    sensor["margin_req"], sensor["modules"])
        return admitted, {"C_eff": self.mrc.C_eff,
                          "e_value": self.aviv.e_value(),
                          "coverage_lb": self.aviv.lower_bound(),
                          "deficit": deficit}
```

## 3. 正确性论证

### 引理 5（分层召回下界与未覆盖归零）
**陈述**：对任意分层 s，`P(recall_s ≥ κ_c(s)) ≥ 1-δ`；且 `TP_s = 0 ⇒ κ_c(s) = 0`；用 n_eff ≤ n 替代 n 只会放宽区间，仍是合法（保守）下界。
**证明**：
1. Clopper–Pearson 下界 `Beta^{-1}(δ; TP_s, FN_s+1)` 是二项比例的单侧 1-δ 下置信界（标准结果，Clopper & Pearson 1934）。
2. `TP_s=0` 时 Beta(0, FN+1) 的 δ 分位数为 0，故 κ_c(s)=0，AbsCert 在 s 上无法释放自由空间——缺席幻觉被结构性拒签。
3. 置信界关于样本量 n 单调收窄；把 n 替换为 n_eff ≤ n（ELD 去重后）使区间变宽而非变窄，故仍是合法下界。∎

### 引理 6（Ville 任意时刻有效性）
**陈述**：零假设 H0（覆盖 ≥ 1-α）下，取可预测 `λ_i ∈ [0, 1/(α+ε))`，`E_t = ∏(1+λ_i(m_0−X_i))` 为非负上鞅，`E[E_t] ≤ 1`，故 `P(∃t: E_t ≥ 1/δ) ≤ δ`。
**证明**：
1. 因子非负：`X_i∈{0,1}`，最坏 `X_i=0` 时因子 `1+λ_i m_0 > 0`；`X_i=1` 时因子 `1-λ_i(1-m_0) > 0` 由 `λ_i < 1/(1-m_0)=1/(α+ε)` 保证。
2. 上鞅性：H0 下 `E[X_i | F_{i-1}] ≥ m_0`，`λ_i` 可预测，故 `E[1+λ_i(m_0−X_i)|F_{i-1}] ≤ 1`，乘积条件期望 ≤ 前一值。
3. Ville 不等式给出 `P(sup_t E_t ≥ 1/δ) ≤ δ E[E_0] = δ`。持续监控、可选停止不改变该界。∎

### 引理 7（单调撤回不越界、不振荡）
**陈述**：两次验证事件之间 `C_eff` 关于保守偏序单调不增（Exec 单调不增）；扩张仅由新验证事件且 `evidence ≥ log(1/δ_expand)` 触发，δ_expand<δ_retract；故任意时刻 `Exec_v24(t) ⊆ Exec_v23`，且证书不抖动。
**证明**：
1. `on_retract` 取格下确界 `C_eff ⊓ R ⊑ C_eff`，故段内 Exec 只减不增。
2. `on_validation_event` 仅当 (a) 新证书更保守（⊑，即时接受）或 (b) 满足更严的扩张证据闸门时才替换；否则忽略。扩张证据要求严于撤回（δ_expand<δ_retract），故两次相反方向变更之间必累积独立新证据，排除零成本来回（chattering）。
3. `Exec_v24 = Exec_v23 ∩ Fil_dpc ∩ Fil_aviv`，任何 C_eff 的扩张都被 v23 的几何/规范/能量门（HPC-E+）上界截断，故永不越过 v23。∎

### 引理 8（有效样本量下置信不虚高）
**陈述**：若同源簇内样本相关系数 ρ>0，用 `n_eff = n/(1+(m-1)ρ) ≤ n` 计算召回/覆盖下界，得到的仍是合法保守界；用原始 n 会高估置信（错误）。
**证明**：簇内相关使估计量方差膨胀为 `Var ∝ [1+(m-1)ρ]·p(1-p)/n`（设计效应）；以 n_eff 替代 n 恰好抵消膨胀，等价于独立样本的方差。因置信界随 n 单调收窄，`n_eff ≤ n` 给出更宽区间，故保守且合法。∎

### 定理（HPC-D 四维准入完备性）
**陈述**：`HPCD.admits(π) = True` ⟺ π 同时满足 (1) v23 物理接地安全，(2) 数据集来源可信且目标分层覆盖达标，(3) 迭代验证未撤回且覆盖下界达标，(4) 有效证书包含 π。
**证明**：由 `HPCD.admits` 的四个连言与引理 5–8 直接可得；任一条件缺失即拒证，对应"无源之证 / 时刻失效 / 已撤回 / 越界"四类风险之一未缓解。∎

### 定理（证书生命周期单调链）
**陈述**：对任意 t，`Exec_v24(t) ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。
**证明**：v24 = v23 再交两个只收紧的过滤器；MRC 段内只降、扩张被 v23 上界截断（引理 7）；DPCC 失效向全保守退化、AVIV 失效回落 v23 固定样本；组合失效取交集，单调性保持。∎

## 6. 本轮最大风险（最终确认）

**一句话**：当"迭代验证"的标注与"数据集"的来源都与被验证的感知系统同源（自标注、同批增强、基准污染 / 应试数据集）时，e-process 会以任意小的 δ 高效地"验证"一个自我印证的闭环、DPCC 也会被精心挑选的数据集满足——系统因此持有一张**分布内无懈可击、分布外系统性失效**的证书，即"可审计的自我印证幻觉"；证书体系越是形式严密，这种闭环越难被外部发现。
