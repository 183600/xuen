# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「基线复现」×「演示数据」）

> R69 把不确定性一分为二，用交互去消解 epistemic，并用 ECE 校准门兜底。但整轮有一个从未被检验的默认前提：**「流模型的模态分布本身可信」**。R69 试图用「模态校准」来担保这一点，却把两个不同的信任问题混为一谈：
> - **校准（calibration）** 问的是「在我采过的分布上，我的置信度对得上频率吗」——这是**分布内**的性质；
> - **复现（reproduction）** 问的是「换个种子、换块 GPU、换个人重跑，结论还在吗」；**覆盖（coverage）** 问的是「这块区域我到底见没见过」——这是**分布外 / 工程实现**的性质。
>
> 本轮两个灵感词正好击中这两块软肋，而且都带着一点反身性（meta）：
> - **基线复现**：R69 的定理 16「R68 是退化边界」只是纸上证明；它没有**执行**过。重构、丢分支、GPU 非确定性、计时抖动，任何一样都能让「逐指令相同」变成空话。**包含性必须是可执行的证明义务，而不是一句定理。**
> - **演示数据**：「演示」既是模仿学习的训练数据，也是给别人看的展示样本。两者都受选择偏差污染。流策略只认识它见过的东西；**在演示荒漠里，模态分布是幻觉，VoI 是在幻觉上做算术。** 这是一种既不属于 aleatoric、也不属于本轮可交互消解的 epistemic 的**第三类不确定性**。
>
> 核心命题：**给闭环补上「信任层」——先把 R68 的退化边界逐轨迹复现（BRH/PCF），再把不确定性做三分解 U=(U_ale, U_epi, U_demo)，用演示覆盖账本与支撑门控决定「能不能问」，用预注册留出防火墙决定「结论能不能信」。** 命名 **ECHO-RAS**（Exact-replay Certified, Holdout-fenced, Overlap-gated Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我该向谁求证、还能问什么**」，R70 问「**我的结论别人能复现吗、它是不是只活在我的演示数据里**」——前四轮都在让系统更聪明，这一轮先证明它没有在骗自己。

## 0. 直觉与动机

**灵感 1（基线复现 → 包含性是证明义务，不是一句定理）**
直觉：R69 的定理 16 说的是「理想策略在退化边界逐指令相同」。但一个真系统不是定理：重构时少走一个分支、采样器换了随机源、Heun 步与 RK2 的实现细节、浮点累加顺序、GPU 归约的不确定性，都会让「相同」在工程上不成立。**数学上的包含性若不落到可执行回放，就只是一句自我安慰。** 做法：记录规范化回放轨迹 τ，用固定种子与锁版本重跑；定义**复现债 D_rep**；在退化边界做 R68/R70 的**差分回放**，只要有一条动作不同，就判定「包含性未被复现、禁止发布」。把定理 16 从论文里的一行，变成 CI 里的一个 gate。

**灵感 2（演示数据 → 第三类不确定性：覆盖）**
直觉：R69 的二分假设「歧义可以通过本轮交互消解」。但这个假设只在**演示数据支撑覆盖到当前状态**时成立。流策略的密度只在训练分布的主脊上有意义；到了演示荒漠，它仍会自信地吐出 K 个模态、算出漂亮的 VoI——**那不是歧义，是幻觉**。这类不确定性既不是 aleatoric（它是可约的，只是不靠"问一句"约），也不是本轮能消解的 epistemic（现在问谁都没用，因为模型压根没这个区域的数据），而是**覆盖不确定性 U_demo**：只能靠**离线采集新演示**来约。在线必须把它当成不可约，直接进 λ_floor，并且**禁止在荒漠里发起交互**。

**灵感 3（校准 ≠ 覆盖：ECE 是分布内的，支撑缺口是分布外的）**
直觉：R69 的 MCG 用 ECE 校准门担保「模态权重可信」。但 ECE 是对**演示分布**取的期望；支撑空洞在演示分布的补集上，而补集在演示测度下测度为零——**校准对看不见的区域没有任何约束力**。一个在演示集上 ECE=0 的模型，可以在荒漠里离谱到任意程度。这是本轮最锋利的一刀：**校准误差与覆盖亏空是正交的两个量，前者不能推出后者。** 所以 R69 的校准门是必要的，但远不是充分的。

**灵感 4（演示数据 = 展示数据 → 留出防火墙 + 配对反事实）**
直觉：「demo」的双关不是文字游戏：训练用的演示集，和最终拿出去展示的样本，是同一批人用同一种偏好挑的。**在演示集上调参、又在演示集上报告，测的是记忆，不是泛化。** 做法：实验前对协议（指标/阈值/样本量/种子/分析脚本）取哈希预注册；留出集密封、访问留痕；最终结论只在留出集上报。进一步，交互收益不能靠「跑两次系统比成功率」（环境与种子混杂），必须用**配对反事实回放**：同一条轨迹，一次允许 g、一次禁用 g，逐轨迹作差，用公共随机数降方差——这才是交互的因果效应。

**灵感 5（复现是持续的债，不是一次性的验收）**
直觉：每加一层、每次重构、每次改配置，都会累积**复现债**。把它当技术债管理：有预算、有发布门、有账本。同时，U_demo 这个"我没见过"的安全出口，不能变成在线乱动——它只能生成**离线数据指令**（我需要哪个区域、哪种模态、补多少演示），进入采集管线，而**永不实时执行**。这条纪律让"诚实地不知道"有一条正确的下游通道，而不是被逼成"硬猜"或"乱问"。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（ECHO-RAS 总览）** ECHO-RAS = (BRH, PCF, DPL, CDE, SGI, DCQ, PHF, DOQ, RAS-WM†)。四不变式：
(i) **零在线学习写操作**（继承 R68 定义 276-i）；
(ii) **复现即证明义务**：任何「R70 ⊇ R68」的主张，必须在退化边界轨迹集上通过差分回放且 D_rep = 0，否则主张不可采信、禁止发布；
(iii) **支撑诚实**：VoI 决策仅在 κ(o) ≥ κ_min 时可采信；支撑不足一律不交互，U_demo 按不可约处理；
(iv) **留出防火墙**：所有对外指标只在预注册留出集上报告；开发/演示集不得用于最终结论。

**定义 311（回放轨迹）** τ = (id, t, o_t, z_t, θ_hash, env_hash, seed, U_cal, c_t, ξ_t, k_t, λ_t, cert_fields)。给定 seed 与锁版本，Replay(stack, τ) 是确定函数；θ_hash / env_hash 锁定权重与环境（驱动、库版本、硬件标识）。

**定义 312（行为等价与复现债）** Eq(τ)=1 ⇔ ‖Replay(ξ)−ξ‖_∞ ≤ ε_bit 且证书决策字段一致。复现债 D_rep(T) = 1 − |{τ∈T : Eq(τ)=1}|/|T|。差分等价 Eq_diff(τ)=1 ⇔ 在退化边界（VoI≤成本 / ECE 越界 / slow_fault）上 R70 与 R68 同种子动作一致。**发布门**：D_rep ≤ ε_rep 且 ∀τ∈T_deg, Eq_diff(τ)=1。

**定义 313（配对反事实回放 PCF）** 对触发交互的轨迹 τ，构造 τ^{−g}：同一切片、同种子，仅禁用 g（走 R68 分支）。配对因果效应 Δ_τ = R(τ) − R(τ^{−g})；交互收益的**唯一**可采信估计 Δ̂ = mean_τ Δ_τ，用公共随机数降方差。跨系统各跑一遍再比成功率因环境/种子混杂，不作为因果证据。

**定义 314（演示数据账本 DPL）** 𝒟 = {(o_i, ξ_i, p_i)}_{i=1}^N，来源 p_i = (collector, time, site, sensor_cfg, task_id, dedup_hash, split, lineage)。账本维护：新异性、冗余（有效样本量 ESS）、可疑分 q_i、split 归属（dev / holdout）、被哪些轮次用于训练或调参。

**定义 315（覆盖亏空与 U_demo）** z = Φ(o)。状态覆盖 κ(o) 为 z 到最近演示簇的归一化密度；模态覆盖 κ_k 为模态原型邻域（半径 Δ_min）内是否存在演示轨迹。U_demo(o) = max{1−κ(o), Σ_k ŵ_k(1−κ_k)} ∈ [0,1]；κ<κ_min 的区域称**演示荒漠**。

**定义 316（演示污染隔离 DCQ）** 用留一 / 交叉验证的稳健策略集成：演示 i 若似然离群或标签与集成多数不一致，得可疑分 s_i，q_i = 1[s_i>τ_q]。被隔离样本降权 w_i = e^{−λ_q s_i}，且**永久排除出留出集**。检测器本身须在已知污染率基准上评估，避免用污染数据自证清白（循环论证）。

**定义 317（支持门控 VoI SGI）** VoI_eff(g) = VoI(g)·ρ(κ(o), κ_mode(g)) − c(g)，ρ 单调且 κ<κ_min 时 ρ=0。仅当 max_g VoI_eff > 0 才交互。语义：**数据荒漠里不提问**——不是"少问"，是"不许问"。

**定义 318（三分解）** U = (U_ale, U_epi, U_demo)。U_ale：任何动作都不可约；U_epi：本轮信息动作可约；U_demo：仅离线采集可约，在线**视同不可约**。处置：U_ale+U_demo → λ_floor；U_epi → 交互（须过支撑门）；消解失败 → 并入 floor。R69 恰为「U_demo≡0 且 κ≡1」的特例。

**定义 319（预注册留出防火墙 PHF）** 实验前提交协议哈希 h_pre（指标、阈值、样本量、种子、分析脚本）。留出集 H 密封，任何访问写审计日志。最终结论要求 h_pre 匹配 ∧ H 在冻结前零访问 ∧ 𝒟_dev ∩ H = ∅。

**定义 320（数据指令 DOQ）** U_demo ≥ τ_demo 或某模态覆盖连续缺失时，向离线采集管线发出 DataOrder(order_id, 状态区域 z, 缺失模态, 目标覆盖, 优先级)。**它不是在线动作**，永不实时执行——这是「我没见过」的安全出口，替代「在荒漠里硬猜或乱问」。

**定义 321（复现包 RPK）** R = (code_hash, config_hash, seed_manifest, env_lock, data_manifest, h_pre, replay_logs, D_rep)。独立复现者须在容差内复现 J_ECHO 与关键指标，否则本轮结论不得对外声称可复现。

**定义 322（参与式审计 VQAuditor-R）** 审计对象：回放失败、留出泄漏、覆盖估计器的 OOD 行为、污染检测假阳/假阴、DataOrder 是否被兑现。结论回灌 AuditBuf 与下一轮发布门。

**定义 323（干扰集 AIC-ECHO）** ℰ_ECHO = ℰ_FLUID × ℰ_demo（偏置/污染演示、支撑空洞、演示投毒）× ℰ_rep（非确定性、日志篡改、留出泄漏、预注册漂移）。

**定义 324（证书 J_ECHO）** J_ECHO = (J_FLUID, D_rep, Eq_diff_flag, κ_at_decision, U_demo, holdout_hash, pre_hash, quarantine_frac, reproducer_id)。Valid ⇔ Valid(J_FLUID) ∧ D_rep≤ε_rep ∧ 退化边界 Eq_diff=1 ∧ 所有已执行交互满足 κ≥κ_min ∧ holdout/pre 哈希匹配。

## 2. 关键算法骨架

```python
# IP-264 BRH：把定理 16 变成可执行测试（差分回放）
def differential_replay(stack70, stack68, traces):
    rep_fail, deg_fail = [], []
    for tau in traces:
        a70 = stack70.replay(tau)                    # 固定 seed + 锁版本
        a68 = stack68.replay(tau)
        if not bit_equal(a70.action, tau.action): rep_fail.append(tau.id)
        if tau.degenerate:                            # VoI<=c / ECE越界 / slow_fault
            if not bit_equal(a70.action, a68.action): deg_fail.append(tau.id)
    return len(rep_fail)/len(traces), deg_fail    # deg_fail 非空 ⇒ 定理16未被复现

# IP-265 PCF：配对反事实——交互收益的因果估计
def paired_counterfactual(stack70, tau):
    with_g    = stack70.replay(tau)                   # 允许信息动作 g
    without_g = stack70.replay(tau, disable=["g"])    # 同种子，仅禁用 g → R68 分支
    return risk(with_g) - risk(without_g)             # 公共随机数降方差

# IP-267 CDE：覆盖亏空（状态 + 每模态）
def coverage_deficit(o, modes, w, ledger, trunk):
    z = trunk(o)
    kappa = ledger.knn_density(z)                     # 演示支撑密度（LSH 查表）
    kappa_k = [ledger.mode_support(m, trunk) for m in modes]
    return clip(max(1 - kappa,
                    sum(w[k]*(1 - kappa_k[k]) for k in modes)), 0, 1)

# IP-268 SGI：支持门控的 VoI
def support_gated_voi(modes, w, g, kappa, cost):
    voi = entropy(w) - expected_entropy(w, g)
    return voi * support_factor(kappa) - cost        # kappa<kappa_min ⇒ 0

# IP-275 主闭环：在线只加一个廉价覆盖门；重活全在离线
def ECHO_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_demo = M.cde.coverage_deficit(o, modes, w, M.dpl, M.mtm.trunk)   # <0.05ms
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # 支撑门：支撑不足 ⇒ 不交互（不是少交互，是不许交互）
    g = (M.mint.choose_interaction(modes, o, M.budget, kappa=1-U_demo)
         if (U_epi > TAU_EPI and U_demo < TAU_DEMO and not slow) else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    elif U_demo >= TAU_DEMO:
        M.doq.submit(o, modes, U_demo)               # 离线数据指令，非在线动作
    # 三分解：ale + demo 一律进 floor；只有消解掉的 epi 才拿 resolution bonus
    U_floor = U_ale + M.cde.to_floor(U_demo) + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    return k, lam, mode, (U_ale, U_epi, U_demo)

# 离线发布门：复现不过，指标再漂亮也不许发布
def release_gate(stack70, stack68, traces, holdout, protocol):
    assert sha(protocol) == protocol.pre_hash
    D_rep, deg = differential_replay(stack70, stack68, traces)
    assert D_rep <= EPS_REP and not deg, "R68 包含性未被复现：禁止发布"
    deltas = [paired_counterfactual(stack70, t) for t in holdout]
    return bootstrap_ci(deltas), D_rep
```

## 3. 推导

**引理 19（校准–覆盖正交性）** 模态校准误差 ECE 是对演示分布 𝒟_dev 取的期望；支撑亏空发生在 𝒟_dev 的补集上，而该补集在 𝒟_dev 下测度为零。故存在策略在 𝒟_dev 上 ECE=0，却在荒漠上误差无界。系：**ECE ≤ τ_ece（R69 的 MCG）不能推出「模态权重可信」**；必须额外用 κ 门控。这是 R69 校准门的必要非充分性。

**引理 20（支撑门控的 minimax 最优性）** 在演示荒漠上，真实模态分布在 𝒟_dev 下不可辨识（演示对该区域不携带信息），任何后验都与数据相容。设损失有界、交互成本 c>0 且名义 VoI 有界，则对任意真实模态分布的最坏情形有 VoI_eff − c ≤ 0；故**拒绝交互是 minimax 最优**，且 λ=λ_floor(U_ale+U_demo) 是 minimax 最优的风险缩放。系：R69 在荒漠里仍按名义 VoI 提问，等价于假设不可辨识处可辨识——这是一个未被声明的前提。

**引理 21（覆盖估计的乐观偏差）** 有限样本密度估计器的支撑会外推：在演示凸包外侧的薄壳区域，估计覆盖 κ̂ 在期望上 ≥ 真实 κ（它把"空洞"平滑成"低密度"）。故 U_demo 是真实覆盖亏空的**下界**，支撑门是**必要非充分**条件——它仍可能放进一个幻影模态。系：账本只能在演示凸包**内部**出具覆盖证明；包外它保持沉默。这正是本轮最大风险的来源。

**定理 18（复现即证明：R70 包含 R68 的可执行版）** 若退化边界轨迹集 T_deg 上差分回放返回 deg_fail=∅（ε_bit 容差），且 D_rep ≤ ε_rep，则在这些轨迹上 R70 的动作与证书决策字段与 R68 一致；于是任何在非退化轨迹上测得的收益，都不可能以「改变安全兜底」为代价。**这是一个关于实现而非只关于定理的条件保证。**

**定理 19（配对反事实的因果收益）** 在无干扰（同轨迹两分支互不影响）且种子公共的假设下，配对估计 Δ̂ 是交互平均因果效应的无偏估计；公共随机数使方差降低 1−ρ_seed；配合预注册留出集（h_pre 匹配）报告，可排除选择偏差。系：任何宣称的 VoI 收益必须通过此估计器与留出防火墙，否则只是「在演示集上更会背答案」。

## 6. 本轮最大风险

**一句话**：**覆盖账本是用同一批有偏演示数据来审计它自己的覆盖**——你无法用从未采过的区域去证明「我哪里没采过」；密度估计器在支撑外会外推，把「没数据」平滑成「低密度」，于是 U_demo 系统性低估真实的支撑空洞，支撑门可能放一个幻影过去；而基线复现也只能复现「我们记录下来的那条轨迹」，不是真实世界里未记录的随机性——**通过复现测试，可能只证明了「我们的日志和我们的代码一致」，而不是「我们的结论与世界一致」。**

**次级风险与缓解**：
1. **回放的工程非确定性**（GPU 归约、浮点顺序、计时）→ ε_bit 容差 + 确定性内核 + 固定归约顺序 + E311 跨环境复现；
2. **污染检测的循环论证**（用污染数据判断污染）→ 已知污染率基准 + 留出隔离 + 检测器独立评估；
3. **留出集随轮次被慢慢泄漏**（多轮调参事实上用到了 H）→ 预注册哈希 + 访问审计 + 定期更换新留出集；
4. **覆盖估计器自身 OOD 失效**（密度估计在远域不可靠）→ 只在凸包内出具证明，包外默认「未知 → 保守」；
5. **元成本**（复现/数据治理拖慢迭代）→ 全部离线化，在线仅 +0.1ms 覆盖查表；把复现债当技术债管理，而非每轮从零重来。

```python
# IP-264 BRH：包含性的可执行证明（差分回放）
def differential_replay(stack70, stack68, traces):
    deg = []
    for tau in traces:
        a70, a68 = stack70.replay(tau), stack68.replay(tau)
        if tau.degenerate and not bit_equal(a70.action, a68.action):
            deg.append(tau.id)
    D_rep = mean(not bit_equal(stack70.replay(t).action, t.action) for t in traces)
    return D_rep, deg                                   # deg 非空 ⇒ 定理16未复现

# IP-265 PCF：交互的因果收益（同轨迹配对）
def paired_counterfactual(stack70, tau):
    return risk(stack70.replay(tau)) - risk(stack70.replay(tau, disable=["g"]))

# IP-267 CDE：覆盖亏空
def coverage_deficit(o, modes, w, ledger, trunk):
    z = trunk(o); kappa = ledger.knn_density(z)
    kappa_k = [ledger.mode_support(m, trunk) for m in modes]
    return clip(max(1-kappa, sum(w[k]*(1-kappa_k[k]) for k in modes)), 0, 1)

# IP-268 SGI：支撑门控 VoI
def support_gated_voi(modes, w, g, kappa, cost):
    return (entropy(w) - expected_entropy(w, g)) * support_factor(kappa) - cost

# IP-275 主闭环
def ECHO_RAS_round(M, obs):

    U_demo = M.cde.coverage_deficit(o, modes, w, M.dpl, M.mtm.trunk)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)

         if (U_epi > TAU_EPI and U_demo < TAU_DEMO and not slow) else None)
    if g is not None: U_epi = M.cia.update_belief(modes, M.cia.execute(g))
    elif U_demo >= TAU_DEMO: M.doq.submit(o, modes, U_demo)     # 离线数据指令
```

## 4. 推导

**引理 19（校准–覆盖正交性）** ECE 是对 𝒟_dev 取的期望；支撑空洞位于 𝒟_dev 补集（其测度为零），故存在策略在 𝒟_dev 上 ECE=0 而荒漠误差无界。系：R69 的 ECE 校准门必要非充分，必须叠加 κ 门控。

**引理 20（支撑门控 minimax 最优）** 荒漠上真实模态分布在 𝒟_dev 下不可辨识；损失有界、c>0、名义 VoI 有界时，最坏情形 VoI_eff−c≤0，拒绝交互为 minimax 最优；λ=λ_floor(U_ale+U_demo) 亦为 minimax 最优。系：R69 在荒漠提名 VoI 等于默认「不可辨识处可辨识」。

**引理 21（覆盖估计乐观偏差）** 有限样本密度估计支撑外推，凸包外薄壳上 κ̂ 期望 ≥ 真 κ，故 U_demo 是真实亏空的下界，支撑门必要非充分，仍可能放入幻影模态。系：账本只在凸包内可出具证明。

**定理 18（复现即证明）** 若退化边界差分回放 deg_fail=∅ 且 D_rep≤ε_rep，则这些轨迹上 R70 与 R68 动作及证书字段一致；非退化轨迹上的收益不可能以改变安全兜底为代价。

**定理 19（配对反事实因果性）** 无干扰 + 公共随机数下 Δ̂ 为交互平均因果效应无偏估计，方差降 1−ρ_seed；配合预注册留出与哈希匹配可排除选择偏差。任何 VoI 收益须过此估计器与防火墙。

## 7. 本轮最大风险

**一句话**：**覆盖账本用同一批有偏演示数据审计它自己的覆盖**——你无法用没采过的区域证明「哪里没采过」；密度估计器在支撑外外推，把空洞平滑成低密度，U_demo 系统性低估真实支撑空洞，支撑门仍可能放进幻影；而基线复现只复现「记录下来的那条轨迹」，不是真实世界未记录的随机性——**通过复现测试，可能只证明了「日志与代码一致」，而不是「结论与世界一致」。**

**次级风险与缓解**：回放工程非确定性（ε_bit + 确定性内核 + 固定归约 + E311）；污染检测循环论证（已知污染基准 + 留出隔离 + 独立评估）；留出随轮次泄漏（预注册哈希 + 访问审计 + 定期换新 H）；覆盖估计器远域失效（仅在凸包内出证，包外默认未知→保守）；元成本拖慢迭代（全部离线，在线仅 +0.1ms 查表，复现债当技术债管理）。
