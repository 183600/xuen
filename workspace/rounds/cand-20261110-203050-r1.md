# 第 47 轮（承接第 46 轮 v10 + v23；本轮灵感：6D位姿估计 × 语义分割） · Semantic-Pose Mutual Certification：语义支撑与姿态商空间的互证证书（五层架构 v11）

> 承接第 45/46 轮的 v10 能量-上下文-深度与 v23 记忆-语音-安全。v10 的姿态证书 P_t 是几何层的分层条件覆盖，v23 把记忆与语音安全接入决策，但二者共同隐含假设 H5：**姿态假设空间的可辨识性由几何/深度独立决定，语义只用于检索、任务规划与掩码辅助**。UniBot 实机抓取透明杯、对称零件、可形变物时，6D 位姿存在对称群 gauge 与遮挡歧义，几何残差可以很小却对应物理错误的姿态；语义分割给出实例支撑与部件拓扑，但边界像素与类别混淆会让掩码“看起来对”而支撑错。两个灵感词精确命中 H5：**6D位姿估计**提供 SE(3) 假设与对称商空间，**语义分割**提供稠密支撑与部件图。耦合出的新问题：**如何让语义与姿态互相签发证书——语义错误被姿态的刚体一致性拦截，姿态歧义被语义部件/对称性消解——并保证联合 soundness 不被静默破坏**。

## 0. 直觉与动机

**灵感 1（6D位姿估计 → 姿态商空间与对称 gauge）**
直觉：对称物体的位姿天然不可唯一辨识。杯子的绕轴旋转、方形盒的 90° 翻转、螺栓的 n 次旋转都给出同一观测。若仍把证书写成 SE(3) 上的一个盒子，就会把“对称等价的正确姿态”误判为“矛盾”，或反过来用一个过大的盒子掩盖真实歧义。正确做法是把证书搬到商空间 SE(3)/G_o，其中 G_o 是物体对称群；证书只声称可辨识的自由度。

**灵感 2（语义分割 → 稠密支撑与部件图）**
直觉：分割不只是给姿态网络做 ROI。像素级类别给出实例支撑集 S_i，进一步给出部件图 H_i（如 handle / rim / body / spout），它是姿态的**拓扑约束**：部件之间的刚体连接关系必须在任何合法姿态下保持。边界带 B_ε 的像素本质不可判，必须显式给弃权标签 ⊥，而不是强行归类制造伪支撑。

**灵感 3（互证 → 双向证书与一致性残差）**
直觉：语义与姿态应互相“签字”。语义→姿态：支撑与部件图压缩假设空间，并选择对称 gauge；姿态→语义：把位姿假设集刚体投影回图像，检验非边界像素的类别一致性。任一方向残差超阈值就升级为主动重分割/重求解/请求深度/fail-closed，而不是静默采信单侧结果。

**耦合升级**：在 v10 四层架构上新增 **L2.5 语义-姿态互证层 SPMC**。五层 v11：根信任层（能量租约 ℓ_e + 姿态租约 ℓ_p + 语义质量租约 ℓ_s）、L1 几何层、L2 上下文/记忆层、**L2.5 互证层（SPMC）**、L3 CAR 守卫、L4 DCL 覆盖驱动采集。SPMC 输出联合证书 J_t=(P̃_t, S_t^pose, q_s)，PSE 用商空间证书签发，DCL 把“互证失败样本”作为高价值采集任务，CCA 增加对称误设与掩码投毒红队。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（语义支撑与部件图）**
分割器输出逐像素分布 f_s(k|p)，k∈{1..K+1}（含背景）。实例支撑 S_i={p: argmax_k f_s(k|p)=i}；部件图 H_i=(V_i,E_i)，节点为部件，边表示刚体连接/邻接。边界带
B_ε={p: max_k f_s(k|p)<1-ε 或 top-2 概率差<ε}。
内部支撑 S_i° = S_i \ B_ε。语义质量
q_s = min{ 覆盖率(S_i°) , 1-|B_ε|/|S_i| , 部件图一致性 }。
**只对内部支撑主张语义 soundness**，边界带标签为 ⊥。

**定义 60（对称群与姿态商证书）**
物体 o 的对称群 G_o⊂SE(3)（离散 C_n/D_n，或连续旋转对称）。姿态等价类 [T]={T·g : g∈G_o}，商空间 SE(3)/G_o。商空间度量
d_G([T_1],[T_2]) = min_{g∈G_o} ‖T_1 - T_2 g‖_F。
姿态商证书 P̃_t⊂SE(3)/G_o，其覆盖为
P( [X_t]∈P̃_t | ω_t, G_o 正确 ) ≥ 1-α_p。

**定义 61（语义条件姿态证书与姿态一致语义证书）**
语义条件姿态证书 P_t^sem：用 S_i° 与 H_i 约束求解后签发，
P( X_t∈P_t^sem | q_s≥q_min, ω_t ) ≥ 1-α_p。
姿态一致语义证书 S_t^pose：逐像素标签集
L_t(p) = { ℓ : ∃T∈P̃_t, proj_T(Model_o(ℓ,p)) 与观测一致 } ∪ {⊥}，
要求 P( ℓ(p)∈L_t(p), ∀p∈S_i° | X_t∈P̃_t ) ≥ 1-α_s。
即姿态假设集刚体投影回图像后，非边界像素的真实标签必须落在标签集内。

**定义 62（互证残差与联合 soundness）**
双向残差：
R_sem→pose = d_G( [T_from_parts(S_i°,H_i)], P̃_t )（部件质心/主轴预测姿态与证书的距离）；
R_pose→sem = |{p∈S_i° : argmax_k f_s(k|p) ∉ L_t(p)}| / |S_i°|（刚体投影与观测标签的不一致率）。
联合证书 J_t=(P̃_t, S_t^pose, q_s, ℓ_p, ℓ_e)，**联合 soundness**：
P( [X_t]∈P̃_t ∧ ℓ(p)∈S_t^pose ∀p∈S_i° ) ≥ 1-α_p-α_s，
且约束 R_sem→pose≤τ_R、R_pose→sem≤τ_R、q_s≥q_min、ℓ_p/ℓ_e 有效。
**互证接受规则**：仅当双向残差与语义质量同时达标才接受；否则升级。

**定义 63（边界带语义证书与主动重分割策略）**
语义不确定度 U_s(p)=H(f_s(·|p))，姿态歧义度 U_p=rad_G(P̃_t)。策略
π(U_s,U_p)=
- re-segment：在 B_ε 内用主动采样/更高分辨率重分割；
- re-solve：在商空间内用部件图约束重新求解并收缩 P̃_t；
- request-depth：请求深度/多视角消解 gauge；
- fail-closed：U_p 超界或对称群置信低。
边界带标签 ⊥ 不参与 soundness 主张，只参与“是否需要升级”的判据。

## 2. 三大新增产出与既有 IP 升级

**IP-69 SPMC（Semantic-Pose Mutual Certifier）**
- 语义支撑/部件图抽取与 q_s 估计
- 语义条件姿态求解 + 姿态一致语义投影
- 双向残差计算与升级决策（re-segment / re-solve / request-depth / fail-closed）
- 联合证书 J_t 签发与失效级联（q_s 过期→ℓ_s 失效→CAR fail-closed）

**IP-70 SYM-CERT（Symmetry-aware Pose Quotient Certifier）**
- 逐实例对称群假设检验与置信度（离散群投票、连续旋转对称检测）
- 商空间度量 d_G 与商空间共形校准
- 对称误设告警：当对称置信<τ_sym 时禁用商证书，回退全 SE(3) 保守盒
- gauge 锁定：用部件图选择规范 representative，避免下游抓取用错等价姿态

**IP-71 SEMBOUND（Boundary-band Semantic Certificate）**
- 边界带检测与弃权标签 ⊥
- 内部支撑覆盖率校准（共形）
- 主动重分割触发与采样预算分配
- 语义质量租约 ℓ_s=(q_s, τ_s, 失效条件)

**既有 IP 升级**
IP-60 PSE：签发 P̃_t 而非 P_t，半径在商空间校准；gauge 由 SYM-CERT 选定。
IP-61 DCL：采集效用加入“互证失败样本”权重，优先采集对称/边界/透明难例。
IP-62 CCA：新增对称群误设红队、掩码投毒红队、部件图伪造红队。
IP-51 CAR：守卫加入 R≤τ_R、q_s≥q_min、ℓ_s 有效；任一失效 fail-closed。
IP-66 MVR：记忆检索键加入对称群与部件图签名，防止跨对称类误复用。
IP-45 总线：新增 semantic-support / pose-quotient / mutual-residual / symmetry-confidence 话题。

## 3. 算法骨架

SPMC 每个感知周期：
1. 读 I_t、深度、上下文 c_t、姿态/能量租约
2. 分割得 f_s → S_i、H_i、B_ε、q_s
3. SYM-CERT 估计 G_o 与置信；低置信 → 禁用商证书
4. 用 S_i°、H_i 在 SE(3)/G_o 求解并签发 P̃_t
5. 刚体投影得 S_t^pose，计算 R_sem→pose、R_pose→sem
6. 若 q_s<q_min 或 R>τ_R 或 租约失效 → 升级/ fail-closed
7. 否则签发联合证书 J_t，交 CAR 守卫与下游抓取
PSE 用 P̃_t 与规范 gauge 生成抓取候选；DCL 把升级样本入采集队列。

## 4. 本轮最大风险

**一句话**：若物体的真实对称群被误设（例如把连续旋转对称当成离散 C_n，或漏掉翻转对称），商空间证书会过度自信，而部件图又可能被对称掩码“喂”成一致的假象，使联合证书在数学上 sound 却对应物理错误的抓取；因此必须逐实例审计对称群置信度、在低置信时禁用商证书回退全 SE(3) 保守盒，并把对称误设样本强制回灌 DCL 与 CCA 红队。

## 2. 关键算法 伪代码

### IP-70 SYM-CERT
```
def estimate_symmetry(pts, model, tau_sym=0.9):
    # 离散对称候选：对 canonical frame 做群作用投票
    cands = [C_n(n) for n in (2,3,4,6)] + [D_n(n) for n in (2,3,4)] 
    best, best_score = {e}, -inf
    for G in cands:
        score = symmetry_fit(pts, model, G)   # 变换后点云/法向残差
        if score > best_score:
            best, best_score = G, score
    # 连续旋转对称检测：主轴方向法向方差≈0 且绕轴残差平坦
    if revolution_fit(pts, model) > tau_rev:
        best = SO(2)_axis(model.axis)
        best_score = revolution_fit(pts, model)
    conf = calibrate_sym_conf(best_score, n_pts=len(pts))
    return best, conf

def quotient_distance(T1, T2, G_o):
    return min(np.linalg.norm(T1 - T2 @ g, 'fro') for g in G_o)

def lock_gauge(P_tilde, H_i):
    # 用部件图选择规范 representative（如 handle 朝向 +x）
    reps = representatives(P_tilde)
    return min(reps, key=lambda T: part_graph_mismatch(T, H_i))
```

### IP-71 SEMBOUND
```
def semantic_support(f_s, eps=0.15):
    lab = argmax(f_s, axis=0)
    top2 = topk(f_s, k=2, axis=0)
    B_eps = (max_prob(f_s) < 1-eps) | (top2.gap < eps)
    S = {i: (lab == i) for i in range(1, K+1)}
    S_deg = {i: S[i] & ~B_eps for i in S}
    q_s = min(coverage(S_deg), 1 - B_eps.mean(), part_graph_consistency(f_s))
    return S, S_deg, B_eps, q_s

def active_resegment(I, B_eps, budget):
    # 在边界带内做高分辨率/多视角采样，只更新 B_eps
    patches = sample_uncertain(B_eps, budget)
    f_s2 = segment_hr(crop(I, patches))
    return merge_segmentation(f_s, f_s2, patches)
```

### IP-69 SPMC
```
def spmc_certify(I, depth, o, calib, lease_p, lease_e, tau_R=0.1, q_min=0.8):
    f_s = segment(I)
    S, S_deg, B_eps, q_s = semantic_support(f_s)
    H = part_graph(f_s, S)
    G_o, sym_conf = estimate_symmetry(depth, o)
    if sym_conf < tau_sym:
        # 禁用商证书，回退全 SE(3) 保守盒
        P_t = solve_pose_conservative(I, depth, S_deg, H, calib)
        return JointCert(P_t, full_sem_labels(S), q_s, mode='conservative')
    P_tilde = solve_pose_quotient(I, depth, S_deg, H, G_o, calib)
    P_tilde = shrink_by_parts(P_tilde, H, calib)
    S_pose = rigid_project(P_tilde, o, H, calib)
    r_sp = quotient_distance(pose_from_parts(S_deg, H), P_tilde, G_o)
    r_ps = label_inconsistency(S_deg, S_pose)
    if q_s < q_min:
        return escalate('re-segment', q_s)
    if r_sp > tau_R or r_ps > tau_R:
        return escalate('re-solve' if r_sp > r_ps else 're-segment', (r_sp, r_ps))
    if not (lease_p.valid and lease_e.valid):
        return 'fail-closed'
    T_gauge = lock_gauge(P_tilde, H)
    return JointCert(P_tilde, S_pose, q_s, gauge=T_gauge, mode='quotient')

def escalate(action, reason):
    # re-segment / re-solve / request-depth / fail-closed
    return Escalation(action=action, reason=reason, sample_for_dcl=True)
```

### 联合守卫（升级 IP-51 CAR）
```
def car_guard(J_t, v_t, theta_safe):
    if J_t.mode == 'fail-closed':
        return 'fail-closed'
    if not (J_t.lease_p.valid and J_t.lease_e.valid and J_t.lease_s.valid):
        return 'fail-closed'
    if J_t.q_s < q_min or J_t.r_sp > tau_R or J_t.r_ps > tau_R:
        return 'fail-closed'
    # 下游安全绑定复用 v23 的 B(v_t, P_t)
    if safety_bind(v_t, J_t.P_tilde, J_t.gauge) < theta_safe:
        return 'queue'
    return 'execute'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SYM-CERT 对称检验 | O(|G|·n_pts) | O(n_pts) | 对称置信 ≥ τ_sym 时商证书覆盖成立；否则回退保守盒 |
| SEMBOUND 支撑/边界 | O(HW·K) | O(HW) | 仅内部支撑 S° 主张 soundness；边界带 ⊥ 不主张 |
| SPMC 姿态求解 | O(HW·K + n_pts) | O(HW + n_pts) | q_s≥q_min 且双向残差≤τ_R ⇒ 联合证书 sound |
| 联合守卫 CAR | O(1) | O(1) | 任一租约/残差/质量失效 ⇒ fail-closed |

**正确性定理（互证 soundness）**：设对称群 G_o 正确、语义质量 q_s≥q_min、双向残差 R_sem→pose≤τ_R 且 R_pose→sem≤τ_R、姿态与能量租约有效。则联合证书 J_t=(P̃_t,S_t^pose) 满足
P( [X_t]∈P̃_t ∧ ℓ(p)∈L_t(p) ∀p∈S_i° ) ≥ 1-α_p-α_s。
证明要点：姿态商证书给出 [X_t]∈P̃_t 的 1-α_p 覆盖；在 q_s≥q_min 下内部支撑 S_i° 的语义标签以 1-α_s 覆盖真实标签；姿态一致语义证书由 P̃_t 刚体投影构造，故在 X_t∈P̃_t 时 L_t(p) 必含真实标签；双向残差阈值排除“证书 sound 但部件图与观测矛盾”的伪一致。**注意**：若 G_o 误设，则 P̃_t 的覆盖前提不成立，定理失效——这正是本方案的核心脆弱点。

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 对称商证书覆盖 | 商空间覆盖率、gauge 选择正确率 | 覆盖率 ≥ 95%（α_p=0.05）；gauge 正确率 ≥ 98% |
| E116 语义质量-姿态误差相关 | q_s 分箱后姿态误差单调性、AUC | 单调；AUC ≥ 0.85 |
| E117 互证残差阈值标定 | 假接受率、升级率 | 假接受 ≤ 1%；升级率 ≤ 15% |
| E118 边界带弃权 | ⊥ 覆盖率、边界带内标签错误率 | 内部错误率 ≤ 1%；⊥ 占比 ≤ 20% |
| E119 联合 soundness 红队 | 对称误设/遮挡/透明/掩码投毒下的违例率 | 违例 0 起（含 fail-closed 计入成功） |
| E120 100h 闭环抓取 | 抓取成功率、静默失效、DCL 难例增益 | 成功率 ≥ 96%；静默失效 0；难例增益 ≥ 8% |

**回退策略**：E115 商覆盖率 < 90% → 全量回退 SE(3) 保守盒；E117 假接受 > 2% → 收紧 τ_R 并强制 request-depth；E119 出现对称误设违例 → 禁用商证书直到逐实例审计通过；E120 静默失效 > 0 → 全局 fail-closed + 人工复核。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 对称群误设导致商证书过度自信 | 高 | 逐实例对称检验 + 置信<τ_sym 回退全 SE(3)；CCA 红队强制覆盖连续/翻转对称 |
| 掩码投毒/边界伪支撑 | 高 | 仅内部支撑主张 soundness；边界带 ⊥；DCL 高权重采集互证失败样本 |
| 部件图抽取错误导致互证残差失真 | 中 | 部件图与姿态联合求解，残差双阈值；低置信升级重分割 |
| 双向残差阈值过松造成假接受 | 中 | 独立审计集共形校准 τ_R；E117 监控假接受率 |
| 商空间求解器局部极小 | 中 | 多假设 + gauge 锁定 + 部件图约束初始化 |
| 计算开销增加 | 低 | SYM-CERT 每 N 帧缓存；SPMC 仅在姿态租约将过期时全量执行 |

## 6. 本轮最大风险

**一句话**：整个联合证书的 soundness 建立在“对称群 G_o 正确”这一前提上，一旦对称误设或部件图被伪造成一致，商证书与互证残差会同时“通过”却指向物理错误的抓取，形成最危险的静默失效；因此必须把对称群置信度提升为一等公民——低置信即禁用商证书回退全 SE(3) 保守盒并 fail-closed，同时用独立红队与 DCL 回灌持续攻击该前提。
