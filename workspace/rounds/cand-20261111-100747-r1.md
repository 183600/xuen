# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「数据标注」×「分布外泛化」）

> 第 54 轮已把技能组合升级为动作-鲁棒性双证书（ACS/SCOM/CEC/AEC/JTC），但其隐含前提是「标注/仿真数据与部署分布同源」。本轮转向 **数据标注的分布几何** 与 **OOD 泛化的可证界**。核心矛盾：H22：标注不是中立的监督信号，而是在数据空间钉下的「支撑桩」，标注覆盖几何直接决定 OOD 泛化上界；H23：OOD 泛化不能被单点鲁棒性谱 ρ 线性外推，它是标注覆盖、语义不变性、动作支撑三者的联合几何性质，一旦发生标注偏移（annotation shift），动作-鲁棒性证书在 OOD 区域会系统性失效。

## 0. 直觉与动机

**灵感 1（标注即分布探针 → 用覆盖场取代样本计数）**
直觉：一条标注不是「给一个点贴标签」，而是在特征×动作空间里钉下一根支撑桩，标注置信 q 决定桩的「承重半径」。用核函数把离散标注变成连续的 **标注覆盖场** `ℓ(z)`：`ℓ≈1` 表示该处有高置信标注支撑，`ℓ≈0` 表示纯外推区。OOD 泛化差，本质是测试点落进了 `ℓ` 的低洼处。这解释了为什么「多标 10% 数据」未必有用——若都钉在已饱和区，覆盖几何几乎不变。

**灵感 2（标注偏移是分布偏移的独立轴 → 五分分解）**
直觉：通常把 OOD 归因于 covariate shift / label shift / concept shift。但还有一条最常被忽略的轴：**标注偏移**——标注协议、标注者偏好、采集场景本身扭曲了标签语义。模型可能「忠实学会了标注偏差」，在标注分布内表现良好、在真实部署分布外崩溃。必须把 `δ_lab` 从概念漂移中单列，否则会把标注错误误诊为模型鲁棒性不足，进而错配补数据/改结构的手段。

**灵感 3（OOD 分层谱 → 不同偏移需要不同标注算子）**
直觉：OOD 不是单一现象。按「偏离训练支撑的几何方式」分层：`O0` 同分布、`O1` 协变量偏移（x 移动但语义支撑仍在）、`O2` 标签偏移（类别比例变）、`O3` 语义/概念漂移（P(y|x) 变）、`O4` 动作空间偏移（进入 α_S 未覆盖动作区）、`O5` 任务/目标偏移（goal 变）。每层需要不同标注策略与证书：`O1` 靠覆盖补点，`O2` 靠重加权，`O3` 靠反事实/因果标注，`O4` 靠动作剖面主动采样，`O5` 靠任务分解重标注。把「泛化」从单一数字拆成可路由的分层问题。

**灵感 4（主动标注 → 在泛化包络上做子模覆盖最大化）**
直觉：标注预算有限，应把桩钉在「能最大化泛化包络覆盖」的位置，而不是随机或只按不确定性挑点。采集分数应同时考虑覆盖缺口 `gap(z)`、该处最差鲁棒维度 `1-ρ_min(g(z))`、标注者分歧 `disagree(z)`，再除以标注成本。这是带权子模最大化，贪心有 `(1-1/e)` 近似保证。关键隐喻：**把标注预算当作购买泛化包络的货币**。

**灵感 5（标注共识证书 → 让标签携带可审计的质量证明）**
直觉：标注不是真理，而是多方证据的收敛。对每个标注区域产出 **标注共识证书** `L_cert=(Ω,κ,div,prov,cf,ε_lab)`：区域、标注一致率、标注者/模型多样性、来源 provenance、反事实稳定度、噪声上界。这样下游联合证书 `J+` 可以引用数据质量，而不是默认标签无噪。

**灵感 6（标注捷径探针 → 防止标注协议自身制造伪相关）**
直觉：标注者常利用上下文捷径（背景、物体共现、时间先验）快速贴标签，模型会继承这些捷径。这是最隐蔽的 OOD 失效源：标注质量看似很高，但高在与任务无关的捷径因子上。用 **反事实/遮挡/背景替换探针** 检测：若标签在保持语义、替换捷径因子后大幅翻转，则该区域携带捷径风险，需重标或做反事实增广。

**灵感 7（从鲁棒性金字塔到数据-泛化金字塔）**
直觉：第 54 轮的金字塔是「动作-鲁棒性」双证书。本轮在其底部插入 **数据层 `𝔻`**：`𝔻_0` 采集协议、`𝔻_1` 标注覆盖场、`𝔻_2` 标注共识证书、`𝔻_3` OOD 分层谱。证书自底向上传递：`L_cert → J → J+`，形成 **数据-动作-鲁棒性三证书体系**。没有合格的 `L_cert`，上层 `J` 只是「在噪声标签上自洽」的幻觉。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（标注覆盖场）**
标注集 `D_L={(z_i,y_i,q_i)}`，`z_i=(x_i,a_i)`，`q_i∈[0,1]` 为标注置信，核 `K_h`。覆盖场
```
ℓ(z) = 1 - ∏_{i}(1 - q_i·K_h(z,z_i))
```
（软 OR；单桩近似 `ℓ(z)=max_i q_i K_h(z,z_i)`）。覆盖缺口 `gap(z)=1-ℓ(z)`。任务区域 `Ω_T` 的覆盖取 `cov(Ω_T)=min_{z∈Ω_T} ℓ(z)` 或体积加权下分位 `Q_τ`。

**定义 122（偏移分解与标注偏移）**
部署分布 `P_d` 与数据分布 `P_{d0}`，总偏移分解为
```
δ_total = (δ_cov, δ_y, δ_concept, δ_lab, δ_act)
```
- `δ_cov = W1(P_x^{d0}, P_x^d)`；
- `δ_y = TV(P_y^{d0}, P_y^d)` 标签边缘偏移；
- `δ_concept = sup_x ||P(y|x)^{d0} - P(y|x)^d||`；
- `δ_lab = ε_lab + δ_protocol`，标注噪声与协议偏移；
- `δ_act` 为第 54 轮 `α_S` 的未覆盖动作体积比。
`δ_lab` 与 `δ_concept` 正交：即使 `δ_cov=δ_concept=0`，若标注协议系统性偏置，`δ_lab>0`。

**定义 123（OOD 分层谱）**
`𝕆 = {O0,...,O5}`，每层 `O_k` 关联可达性条件与推荐标注算子 `Λ_k`：
`O0→Λ_none`，`O1→Λ_cov`，`O2→Λ_reweight`，`O3→Λ_counterfactual`，`O4→Λ_action`，`O5→Λ_task`。
路由函数 `route(δ_total) → (O_k, Λ_k)`。

**定义 124（OOD 感知标注获取）**
采集分数
```
acq(z) = [gap(z)^α · (1-ρ_min(g(z)))^β · disagree(z)^γ] / cost(z)
```
预算 `B` 下选择 `S* = argmax_{|S|≤B} Σ_{z∈S} acq(z)`（或边际覆盖增益），目标 `cov(Ω_gen) ≥ 1-ε_cov`，`Ω_gen` 为泛化包络。

**定义 125（标注共识证书）**
```
L_cert = (Ω, κ, div, prov, cf, ε_lab)
```
`κ` 一致率、`div` 标注者/模型多样性、`prov` 来源、`cf` 反事实稳定度、`ε_lab` 噪声上界。有效当 `κ≥κ_min ∧ cf≥cf_min ∧ ε_lab≤ε_max`；区域外推须显式标 `extrapolation=true`。

**定义 126（数据-鲁棒性联合证书 J+）**
在第 54 轮 `J=(ρ,A_cert,γ_ce,δ_a,evidence)` 上扩展：
```
J+ = (J, L_cert, δ_lab, gap_T, gen_domain)
```
部署条件：`dom_{J+}(T)=in` 且 `cov(Ω_T)≥1-ε_cov` 且 `δ_lab≤Δ_lab` 且 `J` 原有条件成立。

## 2. 关键算法 伪代码

### IP-121 LCF（Label Coverage Field）

```python
def label_coverage_field(D_L, grid, h):
    alpha = np.ones(len(grid))
    for z, y, q in D_L:
        k = rbf_kernel(grid, z, h)
        alpha *= (1.0 - q * k)
    return 1.0 - alpha                 # ℓ(z)

def coverage_gap(ell, Omega_T, tau=0.05):
    return 1.0 - np.quantile(ell[Omega_T], tau)
```

### IP-122 OODS（OOD Stratification）

```python
def decompose_shift(D_src, D_tgt, model, alpha_src):
    d_cov = wasserstein(D_src.x, D_tgt.x)
    d_y   = tv(D_src.label_hist, D_tgt.label_hist)
    d_con = concept_divergence(D_src, D_tgt, model)     # P(y|x) 变
    d_lab = annotation_shift(D_src.labels, D_src.consensus)
    d_act = action_uncovered_ratio(alpha_src, D_tgt.actions)
    return OODProfile(d_cov, d_y, d_con, d_lab, d_act)

def route_strategy(prof, theta):
    if prof.d_act     > theta.act:   return ('O4', LAMBDA_ACTION)
    if prof.d_concept > theta.con:   return ('O3', LAMBDA_COUNTERFACTUAL)
    if prof.d_lab     > theta.lab:   return ('O_lab', LAMBDA_RELABEL)
    if prof.d_cov     > theta.cov:   return ('O1', LAMBDA_COV)
    if prof.d_y       > theta.y:     return ('O2', LAMBDA_REWEIGHT)
    return ('O0', LAMBDA_NONE)
```

### IP-123 OALA（OOD-Aware Label Acquisition）

```python
def ood_aware_acquisition(D_L, pool, rho_min, budget, a, b, c):
    ell = label_coverage_field(D_L, pool)
    score = np.array([
        ((1-ell[i])**a) * ((1-rho_min(pool[i]))**b)
        * (disagreement(pool[i])**c) / cost(pool[i])
        for i in range(len(pool))
    ])
    S = greedy_submodular(score, gain=coverage_gain, k=budget)
    return S                       # (1-1/e) 近似
```

### IP-124 LCC（Label Consensus Certificate）

```python
def label_consensus_certificate(Omega, annotations, model_zoo):
    kappa = fleiss_kappa(annotations)
    div   = annotator_diversity(annotations)
    cf    = counterfactual_stability(Omega, model_zoo)   # 遮挡/背景替换
    eps   = estimate_noise_upper(annotations)
    ok = kappa >= K_MIN and cf >= CF_MIN and eps <= EPS_MAX
```

### IP-125 SHP（Shortcut Probe）

```python
def shortcut_probe(region, shortcut_factors, semantic_factors):
    hits = []
    for f in shortcut_factors:
        flip = label_flip_rate(do(f), preserve=semantic_factors)
        if flip > tau_shortcut:
            hits.append(('shortcut', f, flip))
```

### IP-126 DRJC（Data-Robustness Joint Certificate）

```python
def joint_cert_plus(skill_seq, J, D_L, Omega_T, eps_cov, delta_lab_max):
    L = label_consensus_certificate(Omega_T, D_L.ann, model_zoo)
    if not L.ok:
        return ('reject', 'label_quality', L)
    gap = coverage_gap(label_coverage_field(D_L, Omega_T), Omega_T)
    if gap > eps_cov:
        return ('reject', 'coverage_gap', gap)
    dlab = annotation_shift(D_L, deployment_spec)
    if dlab > delta_lab_max:
        return ('reject', 'annotation_shift', dlab)
    return ('ok', J_plus(J, L, dlab, gap, gen_domain=Omega_T))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| LCF | O(\|D_L\|·\|Ω_T\|) | O(\|Ω_T\|) | 核带宽与 q 校准、覆盖下确界 |
| OODS | O(n·d + n·\|Y\|) | O(\|Y\|) | 五轴正交、路由阈值 sound |
| OALA | O(B·\|pool\|·\|D_L\|) | O(\|pool\|) | 子模性、增益单调 |
| LCC | O(\|ann\|·\|Ω\|) | O(\|ann\|) | κ/cf 可复核、ε_lab 上界 |
| SHP | O(\|F\|·n) | O(n) | 语义保持变换可交换 |
| DRJC | O(\|D_L\|·\|Ω_T\|+\|S\|·\|A\|) | O(\|Ω_T\|+\|A\|) | 预算闭合、联合证书 sound |

**正确性定理（Data-Aware OOD Generalization Soundness）**
在第 53/54 轮 (A22)–(A28) 成立的基础上，新增：**(A29)** 标注噪声上界 `ε_lab`，且标注协议被记录（prov 完整）；**(A30)** 覆盖场 `ℓ` 关于 `z` 为 `L_h`-Lipschitz，且标注噪声与区域无关；**(A31)** 语义漂移 `δ_sem` 由嵌入距离有界；**(A32)** 获取策略使 `gap(Ω_T) ≤ ε_cov`。则对任意 `T⊆Ω_T`：
```
R_OOD(T) ≤ R̂_D(T) + ε_lab + L_h·gap_T + δ_sem + Σ_d(1-ρ_min(d)) + β_E
```
若 `dom_{J+}(T)=in` 且 `gap_T≤ε_cov` 且 `δ_lab≤Δ_lab`，则部署满足证书保证。关键：**数据侧误差可加分解**，且 `ε_lab`、`gap` 均为可审计量，而非黑箱。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 标注置信 q 被系统性高估 | 高 | 共识证书 + 反事实校准 + 悲观 q |
| 覆盖场核带宽敏感 | 高 | 多尺度核 + 带宽敏感性报告 |
| δ_lab 与 δ_concept 不可辨识 | 高 | 双标注者干预实验 + 因果图分离 |
| 子模贪心在大动作空间失效 | 中 | 动作分层 + lazy greedy |
| OOD 分层路由误判 | 中 | 保守回退到最严格层 + 人工复核 |
| 捷径探针语义保持不严格 | 中 | 因果干预 + 人类抽检 |

## 6. 本轮最大风险

**一句话**：把 OOD 泛化归约为「标注覆盖几何」给出了可审计的上界，但整条链的可信度系于 `q_i` 与核带宽——一旦标注者过度自信使 `q_i` 系统性偏高，覆盖场会在最危险的外推区伪造出「已覆盖」的假象，令 `J+` 在最需要保守的地方给出最乐观的证书；因此必须以 **悲观 q 校准 + 反事实共识证书 + 外推区显式豁免** 三重护栏，宁可把覆盖判低、把 OOD 判外推，也绝不让标注的自信冒充泛化的保证。

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LCF | O(\|D_L\|·\|Ω_T\|) | O(\|Ω_T\|) | 核带宽校准，覆盖下确界 sound |
| OODS | O(n·d + n·\|Y\|) | O(\|Y\|) | 五轴正交，路由保守 |
| OALA | O(B·\|pool\|·\|D_L\|) | O(\|pool\|) | 子模，`(1-1/e)` 近似 |
| LCC | O(\|ann\|·\|Ω\|) | O(\|ann\|) | κ/cf 可复核，`ε_lab` 上界 |
| SHP | O(\|F\|·n) | O(n) | 语义保持变换可交换 |
| DRJC | O(\|D_L\|·\|Ω_T\|+\|S\|·\|A\|) | O(\|Ω_T\|+\|A\|) | 预算闭合，联合证书 sound |

**正确性定理（Data-Aware OOD Generalization Soundness）**
在 (A22)–(A28) 基础上新增：**(A29)** `ε_lab` 有界且 prov 完整；**(A30)** `ℓ` 为 `L_h`-Lipschitz，噪声与区域无关；**(A31)** `δ_sem` 由嵌入距离有界；**(A32)** `gap(Ω_T) ≤ ε_cov`。则
```
R_OOD(T) ≤ R̂_D(T) + ε_lab + L_h·gap_T + δ_sem + Σ_d(1-ρ_min(d)) + β_E
```
部署判据：`dom_{J+}(T)=in ∧ gap_T≤ε_cov ∧ δ_lab≤Δ_lab ∧ J 达标`。数据侧误差 `ε_lab + L_h·gap + δ_sem` 为可审计可加项，与模型侧 `ρ`、动作侧 `δ_a` 解耦诊断。

## 6. 本轮最大风险

**一句话**：数据层把 OOD 泛化变成可审计的「覆盖几何 + 标注偏移」上界，但整条链的信誉系于标注置信 `q_i` 与核带宽——一旦标注者过度自信使 `q` 系统性偏高，覆盖场会在最危险的外推区伪造「已覆盖」的假象，令 `J+` 在最需要保守处给出最乐观证书；故必须以 **悲观 q 校准 + 反事实共识证书 + 外推区显式豁免** 三重护栏，宁可判低覆盖、判外推，也绝不让标注的自信冒充泛化的保证。
