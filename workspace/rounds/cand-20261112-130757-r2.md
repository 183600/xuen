# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 2 轮；本轮灵感：「人机协作」×「文化适应性」）

> 第 60 轮 SGEC 用 SSM×CIEC×EPIR×SERC×PCE++++ 把「场景」升级为可预测的阻抗先验，把「对话意图」升级为实时约束锁定，把「ROS 丢包」升级为因果隔离区。但它对**人的建模仍是文化无差别的**：
> 1. **意图语义被当成普适常量**：CIEC 的意图集与映射 `ϕ('轻触')=(K_p↓,K_d↑,F_max↓)` 是硬编码的，默认同一句话、同一个手势对所有用户含义相同。真实协作里，同一句「可以」在低语境文化中可能是明确同意，在高语境文化中可能只是礼貌性不拒绝；沉默可能是默认同意，也可能是强烈反对。**文化差异首先不是“偏好不同”，而是“同一观测的似然不同”**。
> 2. **人机协作被降维成单向指令**：CIEC 只处理“人→机”的意图注入，缺少“机→人”的期望对齐、解释、澄清、退让，也缺少**同意（consent）与顺从（compliance）的区分**——人不反抗不等于人允许。机器人若把“未阻止”当成“被授权”，会在接触、隐私、不可逆动作上越界。
> 3. **文化适应可能退化为刻板印象与安全侵蚀**：若按国籍/人群给一个硬标签并据此放宽速度、缩短距离、增强接触力，就会同时犯两个错：统计上把群体先验当个体真值，安全上让“文化”成为绕过硬约束的借口。**适应必须只能在软壳内移动，且必须可逆、可审计、可被个体证据推翻。**

## 0. 直觉与动机

**灵感 1（文化适应性 → 文化意图模型 CIM）**
直觉：跨文化 HRI 的第一性事实不是“某国人喜欢慢一点”，而是**语用推理的似然不同**。人类学里的高语境/低语境、直接/间接言语行为、面子与礼貌策略，落到机器人这里就是同一个观测 `o`（词、语气、停顿、眼神、距离）在不同 `θ_c` 下对应不同的意图后验 `p(I|o,θ_c)`。关键洞见：**不要把文化做成一个标签，而要做成一个层级先验**——`θ_u ~ p(θ_u|θ_c)`，个体证据 `D_u` 通过贝叶斯更新把群体先验“收缩”掉。文化先验只负责冷启动，个体数据负责最终解释。

**灵感 2（人机协作 → 不变量安全壳 SHEL）**
直觉：协作里“舒服”和“安全”必须分层。接近距离、语速、解释详略、注视、轮流发言的节奏是**文化可变的软壳**；力/力矩/速度/工作空间/人机最小间距/急停是**文化不变的硬壳**。关键洞见：`K_safe(c) = K_hard ∩ K_soft(c)`，并且对任意文化 `c` 都有 `K_safe(c) ⊆ K_hard`。于是“文化模型错了”最坏只会让交互变别扭、任务变慢，**绝不会让硬安全失效**。这是一条可证明的“适应安全单调性”。

**灵感 3（人机协作 → 权威-同意账本 ACL）**
直觉：协作不是“人发命令、机执行”，而是有权威层级的共同决策：急停/否决 > 明确覆盖 > 明确同意 > 推断偏好 > 机器人自主。最隐蔽的危险是**把顺从当同意**：人因为礼貌、惊讶、或不确定而没有制止，机器人却据此继续接触。关键洞见：同意是一个**显式、可撤销、可审计的状态机**，且在“社会风险”高的动作上，必须由明确信号授权；账本用哈希链记录，事后可复核。

**灵感 4（人机协作 → 共享心智与期望差 SMM）**
直觉：人机协作的失败常常不是“做错”，而是“做的和人以为你要做的不一样”。人有一个对机器人行为的期望模型 `q_h(b)`，机器人有自己的策略 `p_robot(b)`；两者之间的 KL/ Wasserstein 距离就是**期望差**。期望差大时，继续执行会让信任崩塌；正确动作是先解释/澄清/放慢，而不是“我按最优策略做了”。这把“信任”从玄学变成一个可观测、可干预的量。

**灵感 5（文化适应性 → 误沟通修复协议 CRP）**
直觉：跨文化沟通必然误判，关键不是“永不误解”，而是**误解可检测、可修复、可退让**。修复是一个有成本的阶梯：隐式调整 → 澄清提问 → 示范/协商 → 退让/停止。每一步都要消耗人的注意力预算 `B_confirm`，所以修复本身也要做 VOI 决策：**只有当澄清带来的风险下降大于打扰成本时才问**。修复失败必须落到最保守动作，而不是继续猜。

**灵感 6（合流 → 文化自适应协作闭环 CAL 与 PCE-C）**
直觉：CIM 给出带歧义集的意图约束，SHEL 保证硬安全不被文化穿透，ACL 把同意/权威纳入时序，SMM 检测期望落差，CRP 负责修复，五者构成闭环：**观测→文化后验→意图歧义→鲁棒约束→权威/同意→执行→期望差→修复→更新**。新增文化认知预算 `B_culture/B_repair/B_confirm/B_trust`：文化证据不足就用宽先验+保守交集；修复预算耗尽就退让；澄清预算耗尽就取最保守可行动作；**任何降级都不许放宽硬安全**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（文化意图模型 CIM）** 设用户 `u`、交互语境 `x`、观测 `o`（语句、韵律、手势、注视、停顿、距离、历史）。文化/个人交互风格 `θ ∈ Θ` 分解为
`θ = (θ_pragma, θ_prox, θ_tempo, θ_contact, θ_consent, θ_repair)`，
分别刻画语用（直接/间接、高/低语境）、近距学（个人空间）、节奏（偏好速度、停顿容忍）、接触风格（轻/稳，但仍在硬安全内）、同意表达规范、纠错规范。

- **层级先验**：`p(θ_u) = ∫ p(θ_u|θ_c) p(θ_c) dθ_c`，其中 `θ_c` 是群体/站点层，`θ_u` 是个体层；用部分池化（partial pooling）避免“一人一模型”与“一群一标签”两个极端。
- **文化条件意图后验**：`β(I|o,D_u) = ∫ p(I|o,θ) p(θ|D_u) dθ`。
- **歧义集合**：`H_τ(o) = {(I,θ) : p(I,θ|o,D_u) ≥ τ_amb}`。
- **鲁棒约束（关键）**：`C_rob(o) = ⋂_{(I,θ)∈H_τ(o)} ϕ_θ(I) ∩ K_hard`。
  即：文化/语义不确定时，取所有“仍可能为真”的解释所对应约束的**交集**——只会更保守，绝不取“最大后验意图”直接放行。
- **文化歧义指数**：`Amb(o) = H(β(I|o,D_u)) / log|I|`；若 `Amb(o) > τ_amb` 或 `H_τ` 同时含“停止”和“继续”，则进入澄清/修复分支。
- **刻板印象约束**：群体先验对个体决策的影响受控，`D_KL(p(θ_u|D_u,θ_c) ‖ p(θ_u|D_u)) ≤ κ_stereo`；且当个体样本 `n_u ≥ n_min` 后，个体似然必须在后验中占主导。

**定义 162（不变量安全壳 SHEL）** 行为 `b = (u, ξ)`，`u` 为物理动作，`ξ` 为交互软参数（接近距离、语速、解释详略、注视/朝向、轮流节奏、接触礼貌度）。定义：
- **硬安全集**：`K_hard` 对所有 `c` 恒定（力/力矩/速度/工作空间/人机最小间距/急停/不可逆动作禁止）。
- **软壳**：`Ξ_soft(c)` 文化可变，但 `Ξ_soft(c) ⊆ Ξ_safe`。
- **可容许集**：`B_adm(c) = {(u,ξ) : u ∈ K_hard, ξ ∈ Ξ_soft(c), Safe(u,ξ)}`。
- **适应算子**：`A: θ_u ↦ θ_u'`，只更新 `ξ' = π_ξ(θ_u')`，且强制 `K_safe(c) = K_hard ∩ K_soft(c) ⊆ K_hard`。
- **适应安全单调性**：`∀c,c': K_safe(c) ⊆ K_hard`，故文化误判不改变硬安全可行域。
- **文化不变量拒绝**：若某个文化偏好要求越出 `K_hard`（如“再快一点”“再近一点”“用力一点”），机器人必须拒绝并解释，而不是“入乡随俗”。

**定义 163（权威-同意账本 ACL）** 权威偏序：
`emergency_stop ≻ explicit_override ≻ explicit_consent ≻ inferred_preference ≻ robot_autonomy`。
- **同意状态机**：`s_consent ∈ {granted, denied, unknown, revoked}`；转移只允许由显式或社会无歧义信号触发；`revoked` 立即生效。
- **同意≠顺从**：仅凭“人未阻止/未反抗”不得转移到 `granted`；`compliance` 不构成 `consent` 的证据。
- **社会风险**：动作 `u` 的社会风险 `R_soc(u)`（接触人体、隐私采集、不可逆、近距离、长时间占用）；若 `R_soc(u) > θ_soc` 且 `s_consent ≠ granted`，则禁止执行，转澄清或退让。
- **账本**：`L = [(t, event, actor, hash, prev_hash)]` 为哈希链，支持审计与用户重置；账本只追加不删改。

**定义 164（共享心智与期望差 SMM）** 机器人维护：
- 自身策略分布 `p_robot(b)`；
- 对人类期望的推断 `q_h(b) = ∫ p_h(b|θ, cues) p(θ|D_u) dθ`；
- **期望差**：`D_exp = max{D_KL(q_h‖p_robot), D_KL(p_robot‖q_h)}`（或 2-Wasserstein）。
观测线索 `cues` 包括迟疑、重复指令、纠正、注视转移、后退、语气变化、停止使用。若 `D_exp > τ_exp`，触发“规范修复”，优先解释/放慢/澄清，而不是继续最优执行。
注意：`q_h` 不可直接读心，只能由线索做后验推断，因此 `D_exp` 本身带不确定度，必须用下界触发（`D_exp - δ ≥ τ_exp`）避免误触发。

**定义 165（误沟通修复协议 CRP）** 修复动作集 `R = {implicit_adjust, clarify, demonstrate, defer}`。
- **修复 VOI**：`VOI_repair(r) = E[ΔAmb + ΔD_exp + ΔR_soc] − λ_a·Attention(r) − λ_t·Latency(r)`。
- **阶梯**：默认从 `implicit_adjust` 起，若 `VOI_repair(clarify) > VOI_repair(implicit_adjust)` 且预算允许则升级；`demonstrate` 需要额外同意（可能涉及动作示范/接触）；`defer` 为最终保守动作。
- **修复预算**：`B_repair`（轮数）与 `B_confirm`（人类注意力，单位可为“提问次数/等待秒数”）；超过 `R_max` 轮仍无法消除歧义，强制 `defer` 到 `P_min`（最小可行动作）或停止。
- **修复不可越界**：任何修复动作本身也必须满足 `K_hard` 与同意约束（例如不得未经同意拉人手臂做示范）。

**定义 166（文化自适应协作闭环 CAL）** 算子 `CAL(M, u, o, x, δ_f_req)`：
```
① Observe: 采集人类线索 cues、场景观测、机器人状态、历史 D_u
② CIM: 更新 p(θ|D_u)；计算 β(I|o,D_u) 与歧义集 H_τ、Amb(o)
③ SMM: 推断 q_h，计算期望差 D_exp
④ ACL: 检查权威/同意；若紧急停止或未授权的高社会风险动作 → STOP/DEFER
⑤ SHEL: 选取软壳 ξ ∈ Ξ_soft(c)，锁定硬安全 K_hard
⑥ RobustCompile: C_rob = ⋂_{H_τ} ϕ_θ(I) ∩ K_hard；EEIS.compile 得 K_safe
⑦ Decide: 在 {act, clarify, demonstrate, defer} 上按 VOI 选混合主动动作
⑧ Execute: 执行并采集 EV-exec、人类反馈
⑨ CRP: 若期望差/歧义仍高，修复并回到 ②（受 B_repair 限制）
⑩ Update: θ 后验、q_h、信任校准、同意账本、预算
⑪ Return: (K_safe, ξ, action, Cert_care, 状态)
```
其中 `P_min` 为第 60 轮的“最小证书程序/最小可行动作”（只接近、只轻触、不移动重物、不越界）。

**定义 167（文化认知预算 PCE-C）** `B_cogC = (B_culture, B_repair, B_confirm, B_trust, B_scene, B_intent, B_exec)`：
- `B_culture`：文化/个体证据采集与后验更新的算力/交互轮次；
- `B_repair`：修复轮数；
- `B_confirm`：澄清/确认所消耗的人类注意力；
- `B_trust`：解释/不确定性披露的沟通预算；
- 旧预算 `B_scene/B_intent/B_exec` 沿用第 60 轮。
成本：`cost_culture = λ_evid·Evidence_cost + λ_repair·Repair_cost + λ_confirm·Attention_cost + λ_trust·Disclosure_cost`。
VOI：`voi_care(π) = VOI_meta_pessimistic(π) − cost_culture(π) − cost_exec(π)`。
**降级规则（单调保守）**：
- `B_culture` 耗尽 ⇒ 用宽先验 `p(θ)=p_0` + 最大歧义集交集（最保守），不硬套群体标签；
- `B_repair` 耗尽 ⇒ 直接 `defer` 到 `P_min` 或停止；
- `B_confirm` 耗尽 ⇒ 禁止提问，取 `C_rob` 最保守点并降低自主性；
- `B_trust` 耗尽 ⇒ 只做最小必要披露，不解释但也不隐藏安全风险；
- `B_exec` 耗尽 ⇒ 沿用第 60 轮执行降级。
铁律：**任一预算耗尽都只能让行为更保守，不能放宽 `K_hard`，也不能绕过同意。**

**定义 168（文化适应证书 CAC）** 证书 `Cert_care = (C1..C5, G1..G4, metrics)`：
- **C1 硬安全不变量**：`∀θ: K_safe(θ) ⊆ K_hard`；
- **C2 歧义鲁棒性**：约束由 `H_τ` 的交集生成，非最大后验单点；
- **C3 同意/权威**：高社会风险动作有 `granted` 同意或落入 `denied/unknown → defer`；
- **C4 证据可逆**：文化更新有证据下界、幅度上限 `Δ_max`、可回滚/可重置；
- **C5 非操纵**：信任/同意只经允许通道更新，不利用认知偏差诱导，不确定度披露是校准的。
- **G1 文化不变安全**：文化模型任意错误都不导致硬安全违规；
- **G2 误文化只降性能**：最坏是任务变慢/变保守，不是变危险；
- **G3 刻板印象有界**：群体先验影响 ≤ `κ_stereo`，个体证据足够后主导；
- **G4 可审计可撤销**：账本可复核，用户可重置适应状态。

### IP-161 CIM（文化意图模型）

```python
class CulturalIntentModel:
    def __init__(self, intent_set, tau_amb=0.15, n_min=8, kappa_stereo=0.2):
        self.I = intent_set                     # {'slow','light','stable','danger',...}
        self.tau_amb = tau_amb
        self.n_min = n_min
        self.kappa_stereo = kappa_stereo
        self.group_prior = {}                   # theta_c -> Gaussian
        self.user_post = {}                     # u -> posterior over theta

    def update(self, u, o, feedback=None):
        # 层级贝叶斯：先验来自群体/站点，个体证据按似然更新
        prior = self.group_prior.get(u.site, self._default_prior())
        lik = self._likelihood(o, feedback)     # p(o|theta,u)
        self.user_post[u.id] = self._posterior(prior, lik, self.user_post.get(u.id))
        # 刻板印象限幅：群体先验对个体决策的影响不得超过 kappa_stereo
        self.user_post[u.id] = self._cap_stereotype(self.user_post[u.id], prior)

    def intent_posterior(self, u, o):
        theta_samples = self.user_post[u.id].sample(K=64)
        beta = {}
        for I in self.I:
            beta[I] = np.mean([self._p_intent(I, o, th) for th in theta_samples])
        return normalize(beta)

    def ambiguity_set(self, u, o, tau=None):
        tau = tau if tau is not None else self.tau_amb
        # 保留所有后验质量 >= tau 的 (I, theta) 假设，而不是只留 top-1
        return [h for h in self._joint_hypotheses(u, o)
                if h.prob >= tau]

    def robust_constraint(self, u, o, K_hard):
        H = self.ambiguity_set(u, o)
        if not H:
            return K_hard & self._most_conservative()   # 无可用假设 -> 最保守
        C = K_hard
        for (I, theta) in H:
            C = C & self._map_intent_to_constraint(I, theta)
        if C.is_empty():
            return None                                  # 交给 CRP/defer
        return C

    def ambiguity_index(self, beta):
        p = np.array(list(beta.values()))
        return -np.sum(p * np.log(p + 1e-12)) / np.log(len(p))
```

### IP-162 SHEL（不变量安全壳）

```python
class SafetyEnvelopeLayer:
    def __init__(self, K_hard, xi_bounds):
        self.K_hard = K_hard                # 与 theta/culture 无关
        self.xi_bounds = xi_bounds          # 软壳的合法范围（文化可变子集）

    def admissible(self, u, xi, theta):
        if not self.K_hard.contains(u):
            return False                     # 硬安全不变量：文化不能穿透
        if not self.xi_bounds.contains(xi):
            return False
        return self._soft_safe(u, xi)

    def adapt_shell(self, theta):
        xi = self._map_theta_to_shell(theta)  # 只改距离/语速/详略/节奏
        xi = clamp(xi, self.xi_bounds)        # 文化偏好越界 -> 拒绝并解释
        return xi, (not self.xi_bounds.contains(self._map_theta_to_shell(theta)))

    def compile(self, u, xi, theta):
        if not self.admissible(u, xi, theta):
            return None, 'culture_invariant_refusal'
        return self.K_hard & self._soft_region(u, xi), 'ok'
```

### IP-163 ACL（权威-同意账本）

```python
class AuthorityConsentLedger:
    def __init__(self, social_risk_threshold=0.6):
        self.s_consent = 'unknown'
        self.ledger = []
        self.social_risk_threshold = social_risk_threshold
        self.authority = ['emergency_stop', 'explicit_override',
                          'explicit_consent', 'inferred_preference', 'robot_autonomy']

    def observe(self, event):
        # 只允许显式/社会无歧义信号改变同意状态；顺从(compliance)不算同意
        if event.kind == 'emergency_stop':
            self.s_consent = 'revoked'
        elif event.kind == 'explicit_consent':
            self.s_consent = 'granted'
        elif event.kind == 'explicit_deny':
            self.s_consent = 'denied'
        elif event.kind == 'compliance':
            pass                                  # 关键：不升级为 granted
        self.ledger.append(self._hash_append(event))

    def may_execute(self, u):
        if self.s_consent == 'revoked':
            return False, 'veto'
        if self._social_risk(u) > self.social_risk_threshold:
```

```python
def expectation_gap(q_h, p_robot, delta=0.05):
    kl1 = kl_divergence(q_h, p_robot)
    kl2 = kl_divergence(p_robot, q_h)
    gap = max(kl1, kl2)
    # 用下界触发，避免模型误差异触发频繁澄清
    return gap, gap - delta

def should_repair(q_h, p_robot, tau_exp=0.3, delta=0.05):
    gap, lower = expectation_gap(q_h, p_robot, delta)
    return lower > tau_exp, gap
```

```python
def choose_repair(ambiguity, gap, social_risk, budget, R_max=3):

        return 'defer'                            # 预算/风险兜底
```

```python
    # ② 文化条件意图后验 + 歧义集
    M.cim.update(user, obs)
    beta = M.cim.intent_posterior(user, obs)
    amb = M.cim.ambiguity_index(beta)

    # ③ 期望差
    q_h = M.smm.human_expectation(user, obs)
    need_repair, gap = should_repair(q_h, M.policy)

    # ④ 权威/同意
    ok, why = M.acl.may_execute(M.candidate_action)
    if not ok and why == 'veto':
        return M, 'STOP', M.policy, 'veto'

    # ⑤⑥ 软壳 + 硬安全 + 鲁棒编译
    xi, refused = M.shel.adapt_shell(M.cim.user_post[user.id])
    C_rob = M.cim.robust_constraint(user, obs, M.shel.K_hard)
    if C_rob is None:
        act = choose_repair(amb, gap, M.candidate_action.social_risk, M.budget)
        return maybe_defer(M, act)

    K_safe, status = M.shel.compile(M.candidate_action, xi, M.cim.user_post[user.id])
    K_safe = M.eeis.compile(delta_f_req, M.fused, C_rob, K_safe)

    # ⑦ 混合主动决策：执行/澄清/示范/退让
    if amb > M.tau_amb or need_repair or refused:
        act = choose_repair(amb, gap, M.candidate_action.social_risk, M.budget)
    else:
        act = 'act'

    if act == 'act':
        M, EV = execute(M, K_safe, xi)
    else:
        M, EV = repair_and_reobserve(M, act)

    # ⑨⑩ 证据/账本/预算/信任更新

    M.acl.observe(EV.human_event)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CIM | O(K·\|I\|·\|Θ\|) 采样/更新 | O(\|Θ\| + n_u) | 歧义集覆盖真实意图 ≥ 1−α；群体先验影响 ≤ κ_stereo |
| SHEL | O(1) 软壳映射 + O(约束数) 编译 | O(\|Ξ\|) | `K_safe(c) ⊆ K_hard` 对所有 c 成立 |
| ACL | O(1) 状态转移 + O(log N) 账本 | O(N_ledger) | 否决即时；compliance 不升级为 consent |
| SMM | O(K·\|B\|) 期望差 | O(\|B\|) | `D_exp` 下界触发，误报率可控 |
| CRP | O(\|R\|) VOI 选择 | O(1) | 修复失败必落到 P_min/STOP |
| CAL | O(闭环 + 修复轮数) | 复用 | 安全不变量 + 同意约束贯穿全程 |

**正确性定理（CARE：文化不变安全 + 歧义鲁棒）** 假设 A66–A70 成立：
- **(A66)** CIM：`H_τ(o)` 以概率 ≥ 1−α 包含真实 `(I,θ)`；层级后验可计算且先验影响受限；
- **(A67)** SHEL：`K_hard` 与 `θ` 独立，`Ξ_soft(c) ⊆ Ξ_safe`；
- **(A68)** ACL：同意状态只由允许信号转移，账本不可篡改；
- **(A69)** SMM：人类期望 `q_h` 可由线索后验逼近，期望差下界有效；
- **(A70)** CRP：修复预算有限且失败可检测，`defer` 动作集合非空。

则：
1. **文化不变安全性**：对任意推断 `θ̂` 与真实 `θ*`，执行行为均满足 `u ∈ K_hard`；文化误判不产生硬安全违规（最坏是 `ξ` 不合口味或任务降级）。
2. **歧义鲁棒性**：若 `H_τ` 同时包含“继续”和“停止”，交集必含停止类约束，故不会在文化歧义下执行危险动作；`Amb > τ_amb` 时进入修复而非最大后验放行。
3. **同意不可被顺从伪造**：`compliance` 不转移 `s_consent`；高社会风险动作在 `unknown/denied/revoked` 下必被阻断；否决即时生效。
4. **适应不侵蚀安全且可审计**：C4/C5 保证更新有界、可逆、可复核；G1–G4 由 C1–C5 推出。
5. **刻板印象有界**：`κ_stereo` 限制群体先验对个体的影响，`n_u ≥ n_min` 后个体证据主导；文化标签不能单独决定动作。

**与第 60 轮 / 第 59 轮的边界**：第 60 轮解决“场景先验→约束”，第 59 轮解决“执行层→证据层”的接地；本轮把“人”从**外部指令源**升级为**带文化先验、权威、同意、期望的协作对象**，并把“文化适应”严格限制在软壳内。三者正交：场景管物理先验，执行层管证据闭环，CARE 管社会-认知层的安全边界。

### IP-161 CIM（文化意图模型）

```python
class CulturalIntentModel:
    def __init__(self, intent_set, tau_amb=0.15, n_min=8, kappa_stereo=0.2):
        self.I = intent_set                 # {'slow','light','stable','danger',...}
        self.tau_amb, self.n_min = tau_amb, n_min
        self.kappa_stereo = kappa_stereo
        self.group_prior = {}               # theta_c -> Gaussian
        self.user_post = {}                 # u -> posterior over theta

    def update(self, u, o, feedback=None):
        prior = self.group_prior.get(u.site, self._default_prior())
        lik = self._likelihood(o, feedback)             # p(o|theta,u)
        post = self._posterior(prior, lik, self.user_post.get(u.id))
        self.user_post[u.id] = self._cap_stereotype(post, prior)  # 刻板印象限幅
        if self._n_obs(u) >= self.n_min:
            self.user_post[u.id] = self._individual_dominant(post)  # 个体证据主导

    def intent_posterior(self, u, o):
        samples = self.user_post[u.id].sample(K=64)
        beta = {I: np.mean([self._p_intent(I, o, th) for th in samples])
                for I in self.I}
        return normalize(beta)

    def robust_constraint(self, u, o, K_hard):
        H = [h for h in self._joint_hypotheses(u, o) if h.prob >= self.tau_amb]
        if not H:
            return K_hard & self._most_conservative()   # 无有效假设 -> 最保守
        C = K_hard
        for (I, theta) in H:
            C = C & self._map_intent_to_constraint(I, theta)
        return None if C.is_empty() else C              # 空则交 CRP/defer

    def ambiguity_index(self, beta):
        p = np.array(list(beta.values()))
        return -np.sum(p * np.log(p + 1e-12)) / np.log(len(p))
```

**要点**：`robust_constraint` 从不使用 `argmax I`；只要“停止/危险”仍在 `H_τ` 中，其约束就进入交集，歧义自动变成保守。

```python
            return 'defer_min_action'

            return 'no_question_conservative'
        if self.used['trust'] >= self.B['trust']:
            return 'minimal_disclosure'

    def charge(self, action):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| CIM | O(K·\|I\|·\|Θ\|) 采样/更新 | O(\|Θ\|+n_u) | 歧义集覆盖真实意图 ≥ 1−α；群体先验影响 ≤ κ_stereo |
| SHEL | O(1) 软壳 + O(约束数) 编译 | O(\|Ξ\|) | `K_safe(c) ⊆ K_hard` 对所有 c 成立 |
| ACL | O(1) 转移 + O(log N) 账本 | O(N_ledger) | 否决即时；compliance 不升级为 consent |
| SMM | O(K·\|B\|) | O(\|B\|) | `D_exp` 下界触发，误报可控 |
| CRP | O(\|R\|) | O(1) | 修复失败必落 `P_min`/STOP |
| CAL | O(闭环 + 修复轮数) | 复用 | 安全不变量与同意约束贯穿全程 |

**正确性定理（CARE：文化不变安全 + 歧义鲁棒 + 同意不可伪造）** 若 A66–A70 成立：
- **(A66)** `H_τ(o)` 以概率 ≥ 1−α 覆盖真实 `(I,θ)`，层级后验可计算且先验影响受限；
- **(A67)** `K_hard` 与 `θ` 独立，`Ξ_soft(c) ⊆ Ξ_safe`；
- **(A68)** 同意状态只由允许信号转移，账本不可篡改；
- **(A69)** `q_h` 可由线索后验逼近，期望差下界有效；
- **(A70)** 修复预算有限且失败可检测，`defer` 动作集非空。

则：
1. **文化不变安全性**：任意推断 `θ̂` 与真实 `θ*` 下，执行动作 `u ∈ K_hard`；文化误判不产生硬安全违规。
2. **歧义鲁棒性**：`C_rob` 为歧义集交集；若 `H_τ` 同时含“继续/停止”，停止类约束必在交集中，故不会在文化歧义下执行危险动作。
3. **同意不可被顺从伪造**：`compliance` 不转移 `s_consent`；高社会风险动作在 `unknown/denied/revoked` 下必被阻断，否决即时生效。
4. **适应不侵蚀安全且可审计**：更新有界、可逆、可复核；G1–G4 由 C1–C5 推出。
5. **刻板印象有界**：`κ_stereo` 限制群体先验影响，`n_u ≥ n_min` 后个体证据主导，文化标签不能单独决定动作。

**与第 60 轮的边界**：第 60 轮解决“场景先验→执行约束”的物理-认知闭环；本轮只改“人”的建模层：把文化从**标签**变成**分布**，把意图从**命令**变成**信念**，把适应从**全局**限制到**软壳**，把同意从**默认**变成**显式状态**。物理执行层与证据层复用 IP-153~160，不重复发明。

## 4. 实验设计 E192–E196

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 CIM | 跨文化 profile 意图识别准确率；歧义句不安全放行率 | 准确率 ≥ 85%；不安全放行 ≤ 0.1%（对照：固定 `ϕ` 在高语境“沉默/可以”场景不安全放行显著升高） |

| E195 SMM/CRP | 误解检出率；修复成功率；平均澄清轮数；人类注意力成本 | 检出 ≥ 90%；修复 ≥ 90%；澄清 ≤ 2 轮；成本 ≤ 预算 |
| E196 CAL 端到端 | vs 第 60 轮 SGEC：跨 profile 成功率、硬安全、信任校准 ECE、刻板印象漂移 | 成功率 +25%；0 违规；ECE ≤ 0.05；漂移 ≤ 阈值 |

**最小可行实验（MVE）**：脚本化 3 个交互 profile（低语境直接型、高语境间接型、安全优先型），指令集含“可以/随便/沉默/请轻一点”等歧义句，对比「固定 CIEC 映射」与「CIM 歧义集 ∩ 鲁棒约束」。只看一个数：**歧义句触发的不安全动作率是否显著下降**。若不降，说明文化先验+交集鲁棒化是空转，本轮核心假设被证伪。

## 5. 本轮最大风险

**一句话**：本轮最大风险是“文化模型把刻板印象当成个体真值、并把适应当成绕过硬约束与同意授权的借口”——当系统对“沉默=同意”“客气=可以”做出自信误判时，越适应越可能在人机接触、隐私或不可逆动作上越界；因此必须以“文化只调软壳、`K_hard` 恒不变”“歧义取交集而非最大后验”“compliance≠consent 的权威账本”“修复失败必 `defer`”四道硬护栏，保证适应永远只能更保守，不能更危险。
