# 第 11 轮（本轮灵感：「平衡控制」×「预训练」）

> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**误差会计 + 覆盖契约**。两个灵感合治 v10 的**前提债**：v10 把安全拆成「显著突变（守卫 1 帧捕获）」与「非显著误差（β_STF 覆盖）」，但这条分割线由语义探测器决定，而探测器本身可被欺骗；一旦出现「静默显著」（误差大而 ν 小），β_STF 按非显著校准、守卫不响，证书错误地保持有效。v11 不再要求探测器正确分类误差，而是（i）用**平衡控制**把安全裕量当作可充放电的储备，持续审计、永不因「探测器沉默」而放松；（ii）用**预训练**提供冻结的、共形校准的误差带与覆盖债，把「猜误差」换成「有有限样本保证地量误差」。继承纪律不变：任一新模块失效 ⇒ 严格退化到 v10（或支配），九不变式、STF/NRB/LS 语义保留。

## 0. 直觉与动机

**灵感 1（平衡控制 → 从「检测误差」到「误差会计」）**
直觉：v10 像一个只靠眼睛保持平衡的走钢丝者——看得见突变就收，看不见就照常走；对手只要让他「看不见」就能让他摔。真正稳的平衡器不依赖「看见每一次扰动」，而是维持一个**能量/裕量储备**：脚一滑（可测的残余）就扣储备，储备见底就必然收缩；而「没看见异常」从不给储备充值。核心创新：**余量储备平衡器（Margin Reserve Governor, MRG）**。把块执行写成离散控制障碍函数（CBF）问题：h_t = 实际净空 − d_safe − R_t ≥ 0，其中 R_t 是**安全储备**（对未建模误差的预留）。控制器只允许选择使 h 沿预测轨迹不下降过快的动作；R_t 的充放电有**反卷绕（anti-windup）律**：只有「审计通过」（一步状态残差落在共形带内）才允许缓慢充电，探测器沉默 = 零信用；任何审计失败立即抽干并锁定充电 T_lock。这把「安全」从「分类正确」变成「会计恒等式 h≥0」，即使语义通道被完全欺骗，物理残差通道仍会记账。

**灵感 2（预训练 → 冻结的误差先验与可计算的覆盖债）**
直觉：v10 的 β_STF 与 τ_sem 是部署期手调的经验量；预训练的真正价值不是再训一个大模型，而是**离线买保险**：用冻结的预训练表示与动力学模型，在一个可审计的校准集上做**分裂共形预测（split conformal）**，给出有限样本、分布无关（仅需可交换性）的误差带 β_conf(x)=q_{1−α}·σ̂(x)。更进一步，预训练告诉我们「哪里没训到」：在冻结特征空间里定义**覆盖债 D_cov(x)**（到校准流形的距离/局部密度缺口），并把它折算进储备 R_t。核心创新：**预训练共形惊讶（Pretrained Conformal Surprise, PCS）** + **覆盖契约（Pretraining Coverage Contract, PCC）**。PCC 是部署门槛：运营走廊上 D_cov 必须 ≤ d̄，否则拒绝部署或强制收缩剖面 Π_r；这把「预训练覆盖不足」这一最容易被忽略的债，变成部署期可检查、运行期可计价的量。冻结也带来廉价：运行期只算前向嵌入与方差头（≤0.3ms），不再训练。

**两者咬合 → 平衡共形证书**
语义惊讶 s_sem、动力学惊讶 s_dyn、一步残差审计 A_t 三通道进入同一个**平衡共形证书** Ĉ_t^EQ=(g_min, e_max, R_t, β_conf, D_cov, n_t)。v10 问「这是显著还是非显著误差？」；v11 改问「**当前储备够不够覆盖任何一种误差，且我省下的每一分裕量都有证据吗？**」——前者依赖不可证的分割召回，后者是储备恒等式与共形覆盖，可测、可审计、可退化。

## 1. 研究问题（轮次升级版）

- **Q1（静默显著）**：如何在不假设语义探测器正确的前提下，使「误差大而探测器沉默」的事件在 ≤1 个控制步内被计量，并把最坏暴露限制在储备可覆盖的范围内？
- **Q2（共形覆盖）**：如何用冻结预训练模型 + 分裂共形 + 分组校准，给出边缘与分组条件覆盖 ≥1−α 的误差带，并把未覆盖区域（覆盖债）折算为可执行的储备与收缩？
- **Q3（平衡活性）**：储备—裕量平衡如何在 50Hz/25W 下保持前向不变，同时不让保守性吞掉任务活性（完成率 ≥ 基线 −5%）？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 误差会计律（Error Accounting, MRG）**
安全不得依赖「误差分类正确」；必须存在一个可测的会计恒等式（裕量 − 储备 ≥ 0）。任何未计量误差只能通过储备显式预留，不能通过「未检测」隐式豁免；证书的保守性写成可审计的收支，而非对探测器召回的信任。

**P17 沉默非证据律（Silence-Is-Not-Evidence, MRG）**
探测器/守卫的沉默不得用于降低储备或延长块；储备设定点只由可复算的量（共形分位、覆盖债、语义惊讶）决定，充值只认显式证据（共形带内残差、通过的校准窗），且充值速率有上限、审计失败后锁定（反卷绕）。「没报警」不是「没问题」的证据。

**P18 预训练覆盖契约律（Coverage Contract, PCC）**
冻结预训练先验必须附带可审计的覆盖债；运营走廊上覆盖债超阈即拒绝部署或强制 Π_r；共形保证按声明分组（Mondrian）给出，未声明组不得默认继承边缘覆盖。预训练不是一次性许可证，而是需要持续对账的合同。

## 3. 与基线（v10）的接口（如何退化）

- PCS 失效（冻结模型/校准集不可用/嵌入超时）⇒ β_conf←β_STF、D_cov←0、s_dyn←0：等价 v10 的 STF 信任域（含其全部风险），MRG 仍可用 β_STF 做储备；
- MRG 失效 ⇒ R_t←0、无 CBF、无审计：等价 v10 的 Ĉ⁺ 证书与四检守卫（严格退化）；
- PCC 失效（覆盖债不可计算）⇒ 视 D_cov=d̄_max，强制 Π_r 或拒绝部署（支配于 v10 的收缩行为）；
- STF/NRB/LS 失效沿 v10 六级退化链；AC 证书失效 ⇒ K=1；ID 失效 ⇒ 全模块 active、归因冻结；MW 失效 ⇒ v9 手写网关；v8 组件失效 ⇒ 中立元注入 ⇒ v7 ⇒ v6；
- 新增安全组件（残差审计、CBF 投影、共形带、覆盖检查）一律 φ^elig=false，永不消融；仅「PCS 的离线校准刷新」可在停机维护时重标。

## 4. 预期贡献

1. **静默显著事件的可计量化**：残差审计 + 储备会计使 v10 最大风险（对抗纹理下 ν≤τ_sem 穿透）从「不可见」变为「可观测则 ≤1 步可见，不可观测则储备/覆盖债兜底」（引理 94）；
2. **有限样本误差带**：预训练 + 分裂/分组共形给 β_conf 覆盖保证，替代手调 β_STF 的经验前提（引理 92）；
3. **覆盖债作为一等公民**：PCC 把预训练分布外区域变成部署门槛与运行期储备，防止「校准集很干净、部署域很脏」的隐性失配（引理 92、96）；
4. **平衡控制器**：CBF + 反卷绕储备律在最坏情况下仍保持 h≥0，并给出保守性—活性 Pareto（引理 93、95、96）；
5. **E591–E612** 覆盖共形覆盖、静默攻击、残差审计、CBF 前向不变、覆盖债、分布偏移、投毒与长跑。

## 5. 本轮最大风险

**一句话**：整套保证以**可交换性 + 覆盖债估计正确**为前提——对抗性分布偏移或预训练投毒可以让 σ̂ 与 D_cov 同时低估：「看起来被覆盖」的区域其实残差重尾，储备被少充，CBF 只对错误的 R 维持 h≥0；而残差审计本质是事后量，若承诺块内裕量小于单步暴露，仍可能在记账前撞上，且过度保守的储备会把系统推入「安全瘫痪」。

**新增定义 549（一步残差与审计统计量）** 执行动作 u_t 后，于下一帧测得 x_{t+1}，定义 r_t = x_{t+1} − F̂_q(x_t,u_t)。协方差 Σ̂ 由静止标定与在线鲁棒估计给出，σ̂(x_t) 为 PCS 的方差头输出。A_t = ‖r_t‖_{Σ̂^{-1}}/max(σ̂(x_t),ε_σ)。审计通过 ⇔ A_t ≤ q_{1−α}。审计是**物理可观测通道**：它不依赖语义标签，也不要求探测器先分类误差。

**新增定义 550（冻结预训练惊讶表示）** φ_pre 与类原型表 e_c 冻结（预训练产物，部署期只读）；s_sem = d_z(φ_pre(obs), e_{ĉ})/τ_emb 与 v10 ν̄ 同构，但**只作为加速触发通道，不再作为证书前提**。σ̂(x) 由 F̂_q 上挂的异方差分位头给出（不是独立大模型；+0.4MB，INT8）。s_dyn = max(0, A_t/q_{1−α} − 1) 为动力学惊讶。

**新增定义 551（分裂/分组共形残余带）** 校准集 D_cal={(x_i,u_i,r_i)}_{i=1}^{n} 来自预训练回放与验收通过的在线日志。归一化分数 A_i 的经验分位
q_{1−α} = Quantile_{⌈(n+1)(1−α)⌉/n}({A_i})。
β_conf(x)=q_{1−α}·σ̂(x)。在可交换性下，P(‖r‖ ≤ β_conf(x)) ≥ 1−α（边缘覆盖）。按声明分组 G 做 Mondrian 共形，得到每组条件覆盖 ≥1−α；未声明组不继承边缘保证，D_cov 置 1。

**新增定义 552（覆盖债）** 记 ρ_cal(z) 为校准特征在 z 空间的 kNN 局部密度，ρ_ref 为走廊内参考密度：
D_cov(x) = clip(1 − ρ_cal(φ_pre(x))/ρ_ref, 0, 1)，
并对未声明分组取 D_cov=1。D_cov=0 表示「该区域被校准覆盖」，D_cov=1 表示「完全未校准」。覆盖契约要求运营走廊上 sup D_cov ≤ d̄。

**新增定义 553（安全储备与设定点）** 储备 R_t ∈ [R_floor, R_max]，设定点
R*_t = min(R_max, β_eff(x_t) + κ·D_cov(x_t) + λ_s·s_sem(t))。
R_floor=β_min（不允许零储备），R_max=κ_max（物理上界，由制动距离与形体决定）。κ 经 E593 标定：一单位覆盖债折算多少米净空。

**新增定义 554（平衡律与反卷绕锁）** 未锁定时
R_{t+1} = Π_{[R_floor,R_max]}( R_t + λ_R·(R*_t − R_t) )，0<λ_R≤1；
审计失败（A_t>q_{1−α}）⇒ R_{t+1}←R_max 且置锁 T_lock 步；解锁需连续 W 步审计通过且期间无新失败。**沉默不改变 R***：R* 只由 β_eff、D_cov、s_sem 决定，而这三者只在有校准证据/显式惊讶时变化。故「探测器一直不响」不会使储备漂低（反卷绕，引理 95）。

**新增定义 555（平衡余量与离散 CBF）** h_t = g(x_t) − d_safe − R_t，g 为最近净空（v9 定义）。对候选块 ζ=(u_t,…,u_{t+K−1}) 与预测轨迹，要求
h_{t+k} ≥ (1−γ)^k·h_t，k=0..K，且 h_{t+k} ≥ 0；
若不存在满足者，拒绝该候选；全体候选皆不可行 ⇒ 单步 fallback 或安全停驻。γ 越小越保守（要求余量衰减越慢）。

**新增定义 556（平衡共形证书）** Ĉ_t^EQ=(g_min, e_max, R_max^chunk, β_conf, D_cov, n_t, s_max, A_t)，valid ⇔
(i) min_k(g_k − d_safe) ≥ max_k R_{t+k}（储备会计）；
(ii) 定义 555 的 CBF 条件成立；
(iii) e_max ≤ τ_eff；
(iv) n_t 全通过（或 NRB 修复后重验）；
(v) A_t ≤ q_{1−α}（未锁）且 D_cov ≤ d̄（或 Π_r 下的声明例外）。
当 R_t≥β_STF、D_cov=0、s_sem=0 时 Ĉ_t^EQ 退化为 v10 Ĉ_t⁺（引理 97）。

**新增定义 557（覆盖契约参数）** κ_PCC=(α, d̄, W, T_lock, G, n_min)。部署门：在声明走廊网格上估计 sup D_cov 并以置信上界判定 ≤d̄；否则拒绝部署或强制 Π_r。运行期每 C_w=64 块复核一次；覆盖债务记账入 Λ/BalanceLedger。

**新增定义 558（平衡门控有效块长）**
```
U_t^EQ ⇔ 校准有效 ∧ D_cov≤d̄ ∧ ¬locked ∧ R_t ≥ (1−ε)R*_t
K_eff^EQ(t) = 1                                          若 ¬U_t^EQ 或 Ĉ_t^EQ 不可行
            = 2                                          若 NRB 失效（Π_r）
            = max(1, ⌊K_max·(1 − min(1, max(Δ_dom/τ_dom,
                          R_t/R_max, D_cov/d̄)))⌋)        否则
```
与 v10 的 539 相比，门控从「语义信任域」升级为「储备是否收敛到位 + 覆盖债是否可接受」；语义惊讶仍可令 K 收缩，但不再是唯一前提。

**定义 493/495/521/496/531/540–548** 继承 v10。δ_trigger 五条件中的「Ĉ_t⁺ valid」升级为「Ĉ_t^EQ valid」；块证书失效与单步条件同样触发 M₀ 硬检查，v9 引理 82+81 的无空洞论证原样保持。

# IP-362 PretrainedConformalSurprise：冻结嵌入 + σ̂ 头 + 共形校准 + 残差审计
class PretrainedConformalSurprise:
    def __init__(self, frozen_encoder, Fq, sigma_head, tau_emb=1.0,
                 alpha=0.05, dz=64, k_cal=16):
        self.phi = frozen_encoder          # 冻结，只读；定义 550
        self.Fq = Fq                       # 共享 v10 的 INT8 前向模型
        self.sigma = sigma_head            # F̂_q 上的异方差分位头
        self.alpha, self.k_cal = alpha, k_cal
        self.q = None                      # 共形分位 q_{1-α}
        self.cal_feats = []                # 校准特征（kNN 密度）
        self.groups = {}                   # Mondrian 分组分位
        self._d_cov_cache = 1.0            # 最新覆盖债（5Hz 缓存）

    def calibrate(self, D_cal):
        scores = [self._score(x, u, r) for (x, u, r) in D_cal]
        self.q = empirical_quantile(scores, 1 - self.alpha)   # 定义 551
        for g, xs in group_by(D_cal, key='declared_group').items():
            self.groups[g] = empirical_quantile(
                [self._score(*d) for d in xs], 1 - self.alpha)
        self.cal_feats = [self.phi(x) for (x, _, _) in D_cal]

    def _score(self, x, u, r):
        return norm(r, inv_cov=Sigma_inv(x)) / max(self.sigma(x), EPS)

    def beta_conf(self, x):                # 定义 551
        return self.q * self.sigma(x)

    def s_sem(self, obs):                  # 定义 550：只作加速通道
        z = self.phi(obs)
        return clip(dist(z, self.prototype(obs.cls)) / self.tau_emb, 0, 1)

    def coverage_debt(self, obs):          # 定义 552：kNN 局部密度缺口
        z = self.phi(obs)
        rho = knn_density(z, self.cal_feats, k=self.k_cal)
        self._d_cov_cache = clip(1 - rho / RHO_REF, 0, 1)
        return self._d_cov_cache

    def coverage_debt_latest(self):        # 5Hz 缓存值，供块边界复核
        return self._d_cov_cache

    def audit(self, x, u, x_next):         # 定义 549：一步后验
        r = x_next - self.Fq.predict(x, u)
        A = norm(r, inv_cov=Sigma_inv(x)) / max(self.sigma(x), EPS)
        q = self.groups.get(group_of(x), self.q)
        return A, (A > q), r


# IP-361 MarginReserveGovernor：储备设定点 + 平衡律 + 反卷绕锁 + CBF
class MarginReserveGovernor:
    def __init__(self, beta_min=0.02, R_max=0.35, lam_R=0.2,
                 lam_s=0.1, kappa=0.5, gamma=0.15,
                 T_lock=100, W=50):
        self.R = R_max                   # 冷启动最保守
        self.locked = True
        self.lock_left, self.pass_streak = T_lock, 0
        self.beta_min, self.R_max = beta_min, R_max
        self.lam_R, self.lam_s, self.kappa = lam_R, lam_s, kappa
        self.gamma, self.T_lock, self.W = gamma, T_lock, W

    def setpoint(self, beta_eff, D_cov, s_sem):        # 定义 553
        R_star = beta_eff + self.kappa * D_cov + self.lam_s * s_sem
        return clip(R_star, self.beta_min, self.R_max)

    def propagate(self, R0, beta_eff, D_cov, s_sem, K):
        """沿候选块按设定点推进储备（与 step 同一平衡律）。"""
        R_star = self.setpoint(beta_eff, D_cov, s_sem)
        R_path, R = [], R0
        for _ in range(K):
            R = clip(R + self.lam_R * (R_star - R),
                     self.beta_min, self.R_max)
            R_path.append(R)
        return R_path

    def force_restrictive(self):           # PCC 失配/Π_r：储备取上界并加锁
        self.R, self.locked = self.R_max, True
        self.lock_left, self.pass_streak = self.T_lock, 0

    def step(self, beta_eff, D_cov, s_sem, audit_ok, locked_by_nrb=False):
        R_star = self.setpoint(beta_eff, D_cov, s_sem)
        if locked_by_nrb:
            self.R, self.locked = self.R_max, True
            self.lock_left = self.T_lock
            return self.R
        if not audit_ok:                   # 定义 554：失败即抽干并锁
            self.R, self.locked = self.R_max, True
            self.lock_left, self.pass_streak = self.T_lock, 0
            return self.R
        if self.locked:
            self.lock_left -= 1
            self.pass_streak += 1
            if self.lock_left <= 0 and self.pass_streak >= self.W:
                self.locked = False   # 仅显式证据解锁；沉默不解锁
            self.R = self.R_max
            return self.R
        self.R = clip(self.R + self.lam_R * (R_star - self.R),
                      self.beta_min, self.R_max)        # 速率受限跟踪
        return self.R

    def cbf_ok(self, clearances, R_path):  # 定义 555
        h0 = clearances[0] - D_SAFE - R_path[0]
        for k, (g, R) in enumerate(zip(clearances, R_path)):
            h = g - D_SAFE - R
            if h < 0 or h < ((1 - self.gamma) ** k) * h0:
                return False
        return True

    def project(self, cand, pred, R_path): # 不可行即拒绝；全拒即单步
        return self.cbf_ok(pred.clearances, R_path)


# IP-363 PretrainingCoverageContract：部署门 + 运行期复核
class PretrainingCoverageContract:
    def __init__(self, d_bar=0.2, C_w=64, n_min=200):
        self.d_bar, self.C_w, self.n_min = d_bar, C_w, n_min

    def gate(self, corridor_grid, pcs):
        sup = max(pcs.coverage_debt(x) for x in corridor_grid)
        if sup > self.d_bar:
            return False, sup        # 拒绝部署或强制 Π_r
        return True, sup

    def runtime_check(self, chunk_idx, pcs):
        if chunk_idx % self.C_w == 0:
            return pcs.coverage_debt_latest() <= self.d_bar
        return True


# IP-354（升级）：平衡共形分块执行器
class EquilibriumChunkCertifier(StructuredChunkCertifier):
    def __init__(self, *a, mrg=None, pcs=None, pcc=None, **kw):
        super().__init__(*a, **kw)
        self.mrg, self.pcs, self.pcc = mrg, pcs, pcc

    def generate_chunk(self, state, ctx):
        K = self.effective_K_eq(ctx)       # 定义 558
        if K == 1:
            return self._single_step_fallback(state)
        R0 = self.mrg.R
        best = None
        for cand in self.policy.sample_sequences(state, K, n=64):
            pred = self.Fq.rollout(state, cand)          # INT8 前向模型
            beta_stf = (self.beta_base
                        + self.lam * self.stf.field_on_footprint(pred.corridor))
            beta_eff = max(self.pcs.beta_conf(state.x), beta_stf)
            D_cov = self.pcs.coverage_debt(state.obs)
            s_sem = self.pcs.s_sem(state.obs)
            R_path = self.mrg.propagate(R0, beta_eff, D_cov, s_sem, K)
            if not self.mrg.project(cand, pred, R_path):  # 定义 555
                continue
            g_min = pred.min_clearance - max(R_path)     # 定义 556
            e_max = pred.max_effort + max(R_path)
            if g_min < self.d_safe or e_max > state.tau_eff:
                continue
            pts = self._abort_points(state, cand, pred)
            if not pts:
                continue
            chunk = Chunk(cand, CertEQ(g_min, e_max, max(R_path),
                                       beta_eff, D_cov, R_path), pts)
            chunk.reserve = R_path                            # 守卫检 3 对照
            chunk, verdict = self.nrb.review_chunk(chunk, self.stf, ctx)
            if chunk is None:
                continue
            score = self.policy.score(chunk, pred)
            if best is None or score > best.score:
                best = chunk
        return best or self._single_step_fallback(state)

    def midchunk_guard(self, chunk, k_exec, live_obs):
        """50Hz 五检 ≤0.6ms；返回 ('continue', k+1) 或 ('abort', p*)"""
        if not chunk.cert_still_valid(live_obs):              # 检 1（v10）
            return self._nearest_abort(chunk, k_exec)
        stop_inv = (live_obs.nearest_clearance
                    - self.d_brake(live_obs.speed) - self.d_safe)
        if stop_inv < chunk.remaining_len(k_exec):            # 检 2（v10）
            return self._nearest_abort(chunk, k_exec)
        A, failed, _ = self.pcs.audit(live_obs.prev_x, live_obs.prev_u,
                                      live_obs.x)             # 检 3（新）
        if failed or self.mrg.R > chunk.reserve[k_exec] + EPS:
            return self._nearest_abort(chunk, k_exec)
        if self.stf.surprise_near(live_obs.pose) > self.stf.tau_sem:  # 检 4
            return self._nearest_abort(chunk, k_exec)
        if self.nrb.fast_norms(live_obs).violated:            # 检 5
            return self._nearest_abort(chunk, k_exec)
        return ('continue', k_exec + 1)

## 4. 推导

**引理 92（分裂/分组共形的覆盖保证与覆盖债的代价）**
设 (A1) 校准样本与测试样本在声明分组内可交换；(A2) σ̂ 为固定正函数、分数 A 按定义 551 归一化；(A3) 冻结特征空间的局部校准密度 ρ_cal 关于 z 为 L_ρ-Lipschitz。则 (i) 边缘覆盖：P(‖r‖≤β_conf(x)) ≥ 1−α−1/(n+1)；(ii) 对每个声明组 g，Mondrian 共形给出该组条件覆盖 ≥1−α−1/(n_g+1)；(iii) 对未声明/低密度区域，条件覆盖 ≥1−α−L_ρ·d̄−1/(n+1)，其中 d̄ 为覆盖债上界。
证明：(i)(ii) 为分裂共形标准结论（有限样本修正取 ⌈(n+1)(1−α)⌉/n 分位）；(iii) 由 ρ_cal 的 Lipschitz 性，D_cov≤d̄ ⇒ 该点特征与校准支撑的密度差 ≤L_ρ d̄，非一致性分数分布偏移被该差值界定，代入共形分位即得。注意 (iii) 是**有假设的**退化保证，不是分布无关；PCC 的作用正是把这条假设变成部署期可检查的量。∎

**引理 93（平衡会计与前向不变）**
设 (A1) 真实一步误差 e_t 满足 ‖e_t‖ ≤ β_eff(x_t)（概率 ≥1−α，引理 92）；(A2) R_t ≥ β_eff(x_t)；(A3) 候选块满足定义 555 的离散 CBF 条件。则沿该块执行，真实净空 g_t^true ≥ d_safe，且 h_t^true ≥ h_t^pred − β_eff + (R_t − β_eff) ≥ 0。
证明：预测净空 g^pred_k 与真实净空满足 g^true_k ≥ g^pred_k − β_eff（A1）。由证书 (i) g^pred_k ≥ d_safe + R_k，故 g^true_k ≥ d_safe + (R_k − β_eff) ≥ d_safe（A2）。CBF 保证预测余量不塌缩，树形归纳得全块成立。∎
关键点：R 是**会计科目**，不是对探测器的信任——即使语义检不响，只要 R≥β_eff 且 CBF 成立，证书仍真。

**引理 94（静默显著事件：可观测则 1 步审计，不可观测则储备兜底——v10 最大风险的正面拆除）**
设 t 时刻真实动力学误差由 δ 跳变至 δ'，而语义惊讶 s_sem≤τ_sem（静默）。二分：
(i) **物理可观测**：若该跳变使一步状态残差满足 A_t>q_{1−α}（即变化超出测量噪声与共形带），则定义 549 的审计在下一帧（≤1 步，20ms）检出，MRG 立即锁定并 R←R_max，定义 547 检 3 使证书失效 ⇒ 切最近中止点 p*。
(ii) **物理不可观测**：若 A_t≤q_{1−α}（残差仍在共形带内），则该步误差被 β_eff 覆盖；由引理 93，只要 R≥β_eff，证书仍保守有效，最坏暴露 ≤ 单步 β_eff，且该单步净空由 R 预留。
在 (i) 中，v10 的四检可能全程不响（ν 小），而 v11 的物理通道仍记账；在 (ii) 中，v11 不声称「检测到」，而是显式用储备覆盖——这比 v10「暗默假设 β_STF 覆盖」更诚实。代价：不可观测误差的上界只能由覆盖契约 d̄ 与 R_max 约束。∎
与 v10 的差别：v10 把「显著/非显著」的分割交给语义探测器（对手可操纵），v11 把分割交给**物理可观测性**（测量残差）与**覆盖契约**（离线可审计），前者的欺骗面小得多，且失手时由储备兜底而非由「未检测」豁免。

**引理 95（反卷绕与储备稳定性）**
(i) 设定点 R*_t 仅依赖 β_eff、D_cov、s_sem，三者只在校准证据/显式惊讶时变化；探测器沉默不改变 R*，故 R_t 不会因沉默而漂低。(ii) 平衡律为速率受限一阶跟踪：‖R_{t+1}−R*_t‖ ≤ (1−λ_R)‖R_t−R*_t‖（未饱和），且 R_t∈[R_floor,R_max]；饱和时截断而非累积，故无积分卷绕。(iii) 审计失败锁定时 R=R_max 且至少 T_lock 步不降；解锁需 W 步连续通过，故「反复沉默」不能释放锁。
证明：(i) 由定义 554 的 R* 表达式；(ii) 一阶跟踪的标准压缩性 + 投影非扩张；(iii) 锁状态机直接检查。∎

**引理 96（储备—活性 Pareto 与可行域）**
设任务收益随允许的净空余量单调增，储备 R 越大可行动作集越小。则在覆盖债 D_cov 与共形带 β_eff 给定下，存在单调 Pareto 前沿；以影子价格 ρ=∂J/∂R 做拉格朗日分配，可在「完成率 ≥ v10−5%」与「越界概率 ≤ε」之间取均衡点。R_max→∞ 时退化为安全瘫痪（完成率→0）；R→β_min 时退化回 v10 风险。证明：可行域关于 R 单调收缩，收益关于 R 单调不增；中值定理即得前沿存在性；端点行为由定义 553/558 直接得到。∎

**引理 97（严格退化与保守性支配）**
(i) 关闭 PCS（β_conf←β_STF、D_cov←0、s_dyn←0）且关闭 MRG（R←0、无 CBF/审计）⇒ 定义 556 退化为 v10 定义 543 的 Ĉ⁺，五检退化为四检，K_eff^EQ 退化为 v10 定义 539，逐行为等价。(ii) 仅关闭 MRG 时，因 β_eff=max(β_conf,β_STF)≥β_STF，v11 证书不弱于 v10（保守性支配）；仅关闭 PCS 时，MRG 以 β_STF 为设定点，仍不弱于 v10。(iii) PCC 失效强制 Π_r，动作集 ⊆ v10 可行集（支配）。
证明：(i) 逐定义代入；(ii) 由 max 与 R*≥β_eff 的单调性；(iii) 由 v10 引理 89 的收缩支配论证。∎

## 8. 本轮最大风险

**一句话**：整套保证以**可交换性 + 覆盖债估计正确**为前提——对抗性分布偏移或预训练投毒可以让 σ̂ 与 D_cov 同时低估：「看起来被覆盖」的区域其实残差重尾，储备被少充，CBF 只对错误的 R 维持 h≥0；而残差审计本质是事后量，若承诺块内裕量小于单步暴露，仍可能在记账前撞上，且过度保守的储备会把系统推入「安全瘫痪」。
