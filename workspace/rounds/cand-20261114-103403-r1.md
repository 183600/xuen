# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「语音识别」×「语音合成」）

> R69 给出了一个漂亮的闭环：把不确定性拆成 aleatoric/epistemic，后者交给「流匹配多模态策略 + 主动交互」消解，并用流似然 FMA 给出一条标定不可吸收的第二意见。但 R69 仍藏着一个未言明的不对称——**它只会「看/问/触」，却从不检验自己是否听懂了**。它的 epistemic 是一个标量化的 U_epi，被整体丢给「问」；于是系统既会把「问不出来的噪声」当成「该问的歧义」，也会把「问一句就能分开的同音」与「怎么问都分不开的多峰」混为一谈。
>
> 两个灵感正好补上这块：
> - **语音识别（ASR）** 提醒：理解天然是**格（lattice）**，不是一个点；歧义是有结构的后验，而不是必须被消灭的「错误」。
> - **语音合成（TTS）** 提供 ASR 的**伴随（adjoint）**：既然能从观测推断假设，就能把假设渲染回观测。**分析-综合（analysis-by-synthesis）** 由此成为一条观测侧的独立证据通道，与 R69 的动作侧通道 FMA 互补。
>
> 核心命题：**给 R69 装上一对「耳朵和嘴」——用识别格承载理解的不确定性，用合成做前向重建与复诵确认；把 epistemic 再精确拆成「可问的混叠 U_alias」与「问不出的分叉 U_branch」，VoI 只花在混叠上、分叉靠时间积分；而往返一致性只有在「识别与综合被证明去相关」时才计为独立证据。** 命名 **REVERB-RAS**（Recognition–Evidence Verification via Echo Round-trip & Backchannel, Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我是否听懂了它、我能不能把它说回去，而那声回响是真的，还是我自己制造的**」——理解不是点估计，而是一段可以被复诵、被反驳、被伪造的回声。

## 0. 直觉与动机

**灵感 1（语音识别 → 歧义是「格」，不是「错误」）**
直觉：ASR 从不假装声学信号是干净的。它输出 lattice / n-best + 逐假设置信度，而不是一个字符串；下游（对话、命令执行）在格上做决策。R69 的流策略对**动作**已经有了多模态思想（K 个样本聚类），但对「我听到/看到的到底是什么」仍习惯先 argmax 成 z_t 再条件生成。把理解本身升格为**后验格**，等于承认：**观测到语义是一个逆问题，病态、依赖先验；先验越强，越可能自信地听错**。保留格，才能在「听懂」这件事上计算 VoI，而不是在「已经确定的理解」上假装计算。

**灵感 2（语音合成 → 前向模型是逆问题的第二只眼）**
直觉：TTS 是 ASR 的伴随——前者 h→o，后者 o→h。语音界有一条古老而有效的原则：**分析-综合（analysis-by-synthesis）**，把候选假设重新渲染成观测，看能否重建真实观测。R69 只训练了「从观测推断动作」，缺一个「把假设渲染回观测再比对」的前向通道。补上它，系统就有第二条第二意见：**FMA 检查「动作是否像我会做的」，A2S 检查「观测是否像这个假设本应产生的」**。两条通道测的是不同东西，因而可以三角定位。

**灵感 3（往返 → 把 epistemic 拆成「可问的混叠」与「问不出的分叉」）**
直觉：语音里的两类歧义本质不同。**同音词**（two/too/to）：多个 h 被渲染成同一观测，识别是**非单射**——但换一种说法、拼写、给个上下文就能分开，这是**可问的**。**口音与噪声**：同一个 h 会渲染出多种观测，综合是**多峰**的——只能多听几遍、等时间积分，**问不出来**。R69 把二者一起塞进 U_epi 交给「问」，于是对着后一种白花预算、还会打扰人。用「去噪渲染」把 U_epi 精确拆成 U_alias 与 U_branch：**VoI 只对混叠计算，分叉交给重复观测**。

**灵感 4（复诵 → 最好的问句是把你的理解说出来）**
直觉：航空复诵协议（readback）从不开放式地问「你什么意思」，而是把理解复述回去请对方确认或纠正：「左转，在红楼，确认？」。它便宜、具体、把识别先验显式摊开供对方纠错，而对方的纠正天然是一个**区别性观测**。用 TTS 生成复诵、用 ASR 识别纠正，正好落在 R69 的增广动作空间里——信息动作从「看/问/触」扩成「看/听/说/问/触」。而且复诵可以直接针对**关键槽位**（方向、对象、数值），比整句重问更省。

**灵感 5（防伪 → 合成也是攻击面，挑战-应答是解药）**
直觉：TTS 既能帮我们复诵，也能被攻击者用来**伪造观测**（deepfake 语音、合成传感器流、重放确认）；更阴险的是，攻击者若能调用与防守方同源的合成器，就能做出「完美回声」去过往返检验。因此往返只是**一致性**，不是**真实性**。真实性需要**私有随机挑战**：用只有防守方能预测的 nonce 内容（随机短语/随机指代/要求复述随机数）去检验应答是否为活体，并对合成器查询限速。这把「防伪造」变成一个可量化的安全参数问题，而不是一句「我们做了 anti-spoofing」。

**灵感 6（回声室 → 往返证据的独立性前提）**
直觉：如果 R 与 S 共训、共享先验或共享数据，它们会**一起错得自洽**：R 把 h 错认成 h'，S 又把 h' 渲染成恰好像观测 o 的样子，往返残差照样很小。这不是证据，是**同义反复（echo chamber / tautology of the echo）**。所以往返能否算作独立证据，必须由一张**去相关证书 SDC** 裁决：只有 ρ_RS = I(R 的误差; S 的误差) 足够小、且训练来源可审计地分离时，才承认「识别 + 综合」是两条正交证据源。这是 R69「k 个正交源一致」纪律在**同一传感器内部**的延伸：**识别并不天然与综合正交，除非被证明正交。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（REVERB-RAS 总览）** REVERB-RAS = (RAS-WM†, SOM, RCL, A2S, ABD, RBP, CRS, SDC)。四不变式：
(i) **实时零学习写操作**（继承 R69 定义 293-i）；
(ii) **识别-综合不可同源定案**：R 与 S 的往返残差只有在 SDC 有效时才计作独立证据，否则只算一个证据源（定义 318、323）；
(iii) **复诵/挑战不改安全责任**：信息动作必须过 C-RAS-WM 前缀认证与 R69 交互预算，只改变「选哪个假设」，不改变安全包络；超时/未应答/被抢占一律退化为 R69→R68（定义 320–321、326）；
(iv) **合成侧最小暴露**：私有合成器仅以限速、随机 nonce 方式对外，避免被当成伪造预言机（定义 317）。

**定义 311（识别通道 RCL）** 识别器 R: 𝒪 × 𝒞 → Δ(ℋ) 输出**格**而非点：n-best {h_i, p_i}，逐假设校准置信 conf_i（ECE 校准）、混淆图与语义槽位对齐。流式下增量更新。核心纪律：**保留格，不 argmax**——理解是一个后验对象。
（相对 R69：z_t = Φ(o_t) 从「点条件」升级为「格加权条件」z_t(h) ~ p(h|o_t)。）

**定义 312（综合/前向观测模型 SOM）** 生成器 S: ℋ × 𝒞 → Δ(𝒪)，把假设 h 与上下文 c 渲染为「若 h 为真，我应当观测到什么」。语音侧即 TTS；机器人侧即「若意图/状态是 h，传感器应读到的合成观测」。定义**均值渲染器** S̄(h,c)=E_{o~S(h,c)}[o]（去噪/去噪化渲染）。R 是逆问题（病态、依赖先验），S 是前向问题（良定但欠定）——二者信任结构不对称，见定义 318。

**定义 313（分析-综合双往返 A2S）** 两个往返残差：
- **S→R（重建，analysis-by-synthesis）**：r_SR(o) = d_O(o, S(R(o),c))，用识别结果重合成，看能否重建观测；
- **R→S（复诵，synthesis-by-analysis）**：r_RS(h) = d_ℋ(h, R(S(h,c),c))，把假设说出去再听回来，看是否还原。
d_O、d_ℋ 为感知/语义距离（不要求欧氏；语音侧为声学距离，机器人侧为观测流距离）。往返一致 ⇔ 残差低于校准分位阈值。**A2S 测观测侧自洽，与 FMA 的动作侧似然互补。**

**定义 314（混叠-分叉二分 ABD）** 在 R69 的 (U_ale, U_epi) 之外，对**理解后验**再分解：
- **U_alias（混叠，识别非单射）** := H(H | S̄(H))，即把观测噪声完全去掉（用均值渲染）后仍存在的后验熵——多个 h 渲染成同一观测、**零噪声也分不开**。只能在干预下改变观测似然（问一个能区分的问题/换视角/复诵）来消除。
- **U_branch（分叉，综合多峰）** := H(H | O) − U_alias（截断于 0），即生成谱展宽额外造成的后验熵——同一 h 可有多种合理观测，**只能靠重复观测/时间积分**降低，问不出来。
恒等：U_epi^obs = H(H|O) = U_alias + U_branch。**两个反事实通道使分解可计算**：(a) 把 S 换成 S̄ 得到 alias；(b) 对同一 h 重复观测取平均得到 branch。
（与 R69 的关系：R69 的 U_ale/U_epi 分解的是**动作**多峰；ABD 分解的是**观测到语义**的混叠/分叉，二者经 z_t(h) 耦合、不可替代。）

**定义 315（别名感知 VoI）** R69 的 VoI 改为只对混叠计算：VoI_reverb(g) = H_alias(H|o) − E_{y~p(·|g,o)}[H_alias(H|o,y)]。对 U_branch 的探询问句**理论增益 ≤ 0**，硬性剔除（定义 314、正式见引理 19）。这修正 R69 在「分叉主导」场景下的过度交互。VoI_reverb 与 R69 的 FMP 动作 VoI 各自独立、分别入账。

**定义 316（复诵协议 RBP）** 信息动作新增 g_readback = S(h_k, focus=slot)（把最可能假设 k 合成回用户/环境，请其确认或纠正）。回应 o' 经 R 识别后贝叶斯更新。三重收益：(a) 比开放式提问社会成本低（航空复诵协议）；(b) 把识别先验显式摊开供对方纠错（对抗先验幻觉）；(c) 回应是天然的**区别性观测**，直接消解 U_alias。纪律：复诵**必须包含被质疑的关键槽位**，否则不构成证据。

**定义 317（挑战-应答防伪 CRS）** 针对「合成观测注入 / deepfake / 重放确认」：系统用**私有** S 生成不可预测的一次性挑战（随机 nonce 短语、随机指代、要求复述随机数/方向），只有应答通过私有 S 的往返检验才计为 liveness。安全参数：nonce 比特数 b 与 S-查询预算 Q。伪造成功概率随 b 指数下降、随 Q 线性上升（定理 19）。

**定义 318（综合-识别去相关证书 SDC）** 往返一致性只有在 R 与 S **不同源**时才是独立证据。定义 ρ_RS = I(R_err; S_err)，用留出数据估计。SDC 有效 ⇔ ρ_RS ≤ τ_ρ 且 provenance_disjoint(R,S)=True（训练数据/增广/先验来源可审计地分离）。SDC 无效 ⇒ R∘S 往返只算 **1 个证据源**，不满足 R69 的 k-正交一致纪律，**禁止单独定案**。

**定义 319（最小可辨查询 MDQ）** 对混叠，存在一组最小可辨查询 g*_alias，使假设对之间的观测差异最大化：g* = argmax_g min_{i≠j} D_KL(p(y|h_i,g) ‖ p(y|h_j,g))。这是 ASR 里「请拼写 / 请换一种说法」的形式化——问那个能让两个假设**产生最大观测差异**的问题，而不是问最「自然」的问题（定义 315 的候选生成器）。

**定义 320（流式复诵与打断 SRL）** 复诵/挑战按流式增量生成（增量 TTS），可被用户打断（barge-in）。控制与复诵并行：复诵未完成、或应答在决策截止后到达 ⇒ 视为**未消解**，走定义 307 保守分支。保证「说」不阻塞「做」。

**定义 321（优先级与抢占）** 安全关键动作与复诵冲突时，抢占序：安全动作 > 复诵 > 追问。复诵可被安全动作抢占并记为 dropout；dropout 率进入 MINT 成本先验（R69 定义 303 的审计回灌）。

**定义 322（语义-声学双分辨率一致 DRCR）** 往返在**两个分辨率**上检查：语义层（离散假设是否一致）与声学/原始层（细粒度残差）。对抗同音攻击（在识别器分辨率下不可分、在原始信号上可分）靠原始层检出；「听起来对但意思错」的先验幻觉靠语义层检出。**只有两层都一致，才升级为强证据。**

**定义 323（REVERB 证据强度）** 单次往返给出 e = (r_SR, r_RS, ρ_RS, resolution) 的**似然**而非判决。分级：E0（无）、E1（通过但 SDC 无效 → 单源）、E2（SDC 有效 → 正交证据）、E3（双分辨率 + 挑战应答 → 强证据）。只有 E2/E3 可参与 R69 的 k-一致定案。

**定义 324（合成注入干扰集 ℰ_reverb）** 并入 R69 的 AIC：ℰ_reverb = {同音/近音对抗观测、deepfake 合成观测、复诵重放、格注入（伪造 n-best）、先验诱导（用高频短语劫持识别先验）}。ℰ_REVERB = ℰ_FLUID × ℰ_reverb。

**定义 325（证书 J_REVERB）** J_REVERB = (J_FLUID, r_SR_p95, r_RS_p95, ρ_RS, SDC_valid, alias_ratio, readback_dropout, crs_nonce_bits, reverb_ver)。Valid ⇔ Valid(J_FLUID) ∧ SDC_valid（当声称 E2/E3）∧ 复诵预算未越界 ∧ 双分辨率一致（当声称 E3）。

**定义 326（两级包含与退化）** REVERB 是 R69 的**严格推广**：当 U_alias ≤ τ_alias、或 VoI_reverb ≤ c、或 SDC 无效（对需定案者）、或 CRS 未通过、或复诵超时 ⇒ 不发起 REVERB 证据，**逐指令退化为 R69**（再退化为 R68）。安全侧永不让步，效率侧只从「消解混叠」获利。

```python
# IP-264 SOM：综合/前向观测模型（TTS 角色；与 R69 FMP 共享 trunk、不共享识别头）
class SynthesisObservationModel:
    def __init__(self, trunk, render_head, decoder):
        self.trunk, self.render, self.dec = trunk, render_head, decoder  # z -> p_S(o|h,c)
    def render(self, h, c):                      # 合成观测（可采样，可流式）
        return self.dec(self.render(encode_hypothesis(h, c)))
    def mean_render(self, h, c):                 # S̄：去噪渲染，用于 alias
        return self.dec.mean(self.render(encode_hypothesis(h, c)))
    def prompt(self, h, focus):                  # 复诵/挑战的人类可懂内容
        return self.dec.verbalize(h, focus=focus)

# IP-265 RCL：格状识别（ASR 角色），保留 n-best，不 argmax
class LatticeRecognizer:
    def recognize(self, o, c, streaming=True):
        z = self.enc(o)
        return self.beam_decode(z, top_n=8, calibrate=True)   # [(h_i, p_i, conf_i, slots)]

# IP-266/267 A2S + ABD：双往返残差与混叠-分叉分解
def analyze_by_synthesis(R, S, o, c):
    lat      = R.recognize(o, c)
    r_sr     = min(d_obs(o, S.mean_render(h, c)) for h,_,_,_ in lat)      # S→R 重建
    r_rs     = {h: d_h(h, R.recognize(S.render(h, c), c)) for h,*_ in lat} # R→S 复诵
    # 反事实：同一个 o，用去噪渲染 vs 真实渲染，比较后验熵
    U_alias  = H_posterior(lat, channel=S.mean_render)                    # H(H|S̄(H))
    U_epi    = H_posterior(lat)                                           # H(H|O)
    U_branch = max(0.0, U_epi - U_alias)                                  # 定义 314
    return lat, r_sr, r_rs, U_alias, U_branch

# IP-268/269 REVERB-VoI + MDQ：只对混叠算 VoI；问最能区分的问题
def choose_reverb_action(lat, U_alias, o, budget):
    if U_alias <= TAU_ALIAS: return None                                  # 无可约混叠 → R69
    for (i, j) in confused_pairs(lat):                                    # 高混淆假设对
        g = argmax_min_KL(pair=(i, j), o=o)                               # 定义 319 MDQ
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi = H_alias(lat) - expected_H_alias(lat, g, R)
        if voi - cost(g) > 0: yield g
    g_rb = readback_candidate(lat)                                        # 定义 316 复诵
    if budget.allow(g_rb) and c_ras_wm.certify_info(g_rb, o):
        yield g_rb

# IP-270 CRS：私有综合挑战-应答（防注入/重放）
def challenge_response(S_priv, R, o, bits=64):
    nonce  = sample_nonce(bits)                                           # 不可预测
    prompt = S_priv.prompt(nonce, focus='nonce')
    o_resp = yield prompt                                                 # 等应答（可中断）
    if not S_priv.roundtrip_ok(o_resp, nonce): return 'spoof'
    return 'live'

# IP-271 SDC：去相关证书（决定往返能否算两个源）
def decorrelation_certificate(R, S, holdout):
    rho = mutual_info(R.errs(holdout), S.errs(holdout))
    return SDC(rho <= TAU_RHO, rho, provenance_disjoint(R, S))

# IP-275 REVERB 主闭环（继承 R69，仅在消歧证据处插入往返）
def REVERB_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) ABD：把理解歧义拆成「可问的混叠」与「问不出的分叉」
    lat, r_sr, r_rs, U_alias, U_branch = analyze_by_synthesis(M.R, M.S, o, c)
    sdc = M.sdc.check()
    # 2) REVERB-VoI：只对混叠；分叉不花预算（等重复观测）
    g = next(choose_reverb_action(lat, U_alias, o, M.budget), None) \
        if (U_alias > TAU_ALIAS and not sdc.conflicts()) else None
    evidence = None
    if g is not None:
        evidence = M.cia.execute_reverb(g)                  # 复诵/MDQ，带认证
        # 3) 防伪：任何「会被采纳」的应答先过挑战-应答（防注入/重放）
        if evidence.would_decide and M.crs.challenge(o) == 'spoof':
            evidence = None                                 # 丢弃，不加权
    # 4) 证据纪律：单源/同源往返不得定案（SDC 决定 E1 还是 E2）
    if evidence is not None and evidence.strength in ('E2', 'E3'):
        U_epi_after = M.cia.update_belief(modes, evidence)
    else:
        U_epi_after = U_epi
    # 5) 风险缩放与安全：完全沿用 R69/R68；REVERB 不碰安全包络
    U_floor = U_ale + (U_epi_after if evidence is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(g, evidence, U_alias, U_branch, r_sr, r_rs, sdc)
    return k, lam, mode, (U_ale, U_epi_after, U_alias, U_branch)
```

## 3. 推导

**引理 19（混叠-分叉的可分辨性与「问不出分叉」）** 在 A99（R、S 局部 Lipschitz，S̄ 存在）下，ablation 通道给出恒等 U_epi^obs = U_alias + U_branch（定义 314）。设信息动作 g 只通过改变观测似然 p(y|h,c,g) 起作用，不改变生成器本身的谱展宽。则：(a) 任意 g 对 U_branch 的期望降幅 ≤ 0（分叉是 H(O|H) 的性质，与「问什么」无关）；(b) 存在 g（MDQ，定义 319）使 U_alias 降幅 ≥ max_{i≠j} D_KL(p(y|h_i,g)‖p(y|h_j,g)) − ε。**系：VoI_reverb(g) 是「可分的混叠」的函数；对分叉提问是纯浪费。** 这解释了 R69 在口音/噪声主导场景中「越问越打扰、却越不确定」的病根。

**引理 20（往返证据的信噪比与去相关折扣）** 设真实观测来自 S，攻击者使用 S'。S→R 重建残差对真实观测期望 ≤ ε_align（R∘S 的对齐误差），对 S' 生成观测期望 ≥ D(S,S') − ε_align，故**一致性检测间隙 = D(S,S') − 2ε_align**。但当 S'=S（攻击者拥有同源合成器）时间隙 → 0：**往返只是自洽性，不是真实性**。进一步，若 R 与 S 误差相关 ρ_RS，则对错误假设的往返残差也下降，等效证据比特被折扣为 (1−ρ_RS)·(−log r_SR/thr)。**系：SDC 无效时，往返最多算 E1 单源，绝不可与 R69 的其它证据「凑成 k 个」。**

**引理 21（复诵相较开放式提问的 Pareto 优势）** 设假设空间 |ℋ| 大而真正歧义只集中在关键槽位 s。开放式提问的期望熵降 ≤ H(h_k)，成本 c_open 随 |ℋ| 增长；复诵把 h_k 的槽位显式呈现，回应只需确认/纠正该槽位，故熵降 ≥ H(h_k) − H(confusion neighborhood of s)，且 c_rb < c_open（更短、更具体、可打断）。**系：在槽位级混叠上，复诵 Pareto 优于开放式提问；这也解释了为什么航空与人机协作都收敛到复诵。**

**定理 18（REVERB 严格包含 R69）** 在 A99–A102 下，REVERB 的期望风险 ≤ R69 于任意状态；且当 U_alias ≤ τ_alias、VoI_reverb ≤ c、SDC 无效（对需定案者）、CRS 未通过或复诵超时时，二者**逐指令相同**（定义 315、323、326）。因此 R69 是 REVERB 在「永不回声」边界上的退化：安全侧不做任何让步，效率侧只获「消解混叠」的 resolution bonus，不靠「问分叉」刷收益。

**定理 19（合成注入下界与 CRS 上界）** 无 CRS 时，拥有 S 的攻击者对合成观测欺骗的成功率 ≥ 1 − ε（完美 deepfake 不可区分）。启用 b 比特私有 nonce 与查询预算 Q 的 CRS 后，单次欺骗成功率 ≤ 2^{−b} + Q·2^{−b}·(1−2^{−b})；序列成功概率随交互轮数指数衰减。**系：b 与 Q 是显式安全参数，必须写进 J_REVERB（定义 325），不能隐式「默认安全」。**

**定理 20（复诵无突变与抢占安全）** 复诵经 R69 定义 302 同等认证后，物理风险 ≤ ε_int；流式/打断/抢占（定义 320–321）只改变证据到达时序，不改变安全包络；超时/被抢占/被判定 spoof ⇒ λ 单调不降地退化为 R69→R68。结合换装不变式（R68 定理 15），控制连续、无突变。

## 6. 本轮最大风险

**一句话**：REVERB-RAS 把「往返一致」当成独立证据，但若识别器与综合器共享先验、共训数据或同源标注（ρ_RS 偏高），往返就会退化成**回声室/同义反复**——R 和 S 可以一起错得自洽，把错误假设盖上「已验证」的章；此时若 SDC 估不准，系统不是更谨慎，而是**更有底气地错**：回声可以是最像真相的假象。

**次级风险与缓解**：
1. **同源往返被误当正交证据**（R 与 S 共训）→ SDC 去相关证书 + E1/E2 分级 + 「SDC 无效只算单源」硬纪律（定义 318、323）；
2. **合成观测注入 / deepfake / 重放**（完美回声）→ CRS 私有 nonce + 查询限速 + ℰ_reverb 对抗训练 + 定理 19 显式安全参数（定义 317、324）；
3. **识别先验幻觉被复诵放大**（说出来的是错的、对方随手确认）→ 双分辨率一致 + 只对关键槽位复诵 + E311 人类研究（定义 316、322）；
4. **复诵/挑战打扰与预算击穿** → 优先级抢占 + 异步流式 + dropout 回灌成本先验 + E312（定义 320–321）；
5. **ABD 分解在分布外失准**（S̄ 估偏把 branch 记成 alias）→ 反事实双通道交叉校验 + U_alias≤τ 即退回 R69 + E298/E302（定义 314、326）。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** REVERB-RAS = (RCL, SOM, A2S, ABD, RBP, CRS, SDC, RAS-WM†)；零学习写操作继承；识别-综合不可同源定案；复诵/挑战不改安全责任、超时即退化；私有合成器限速随机暴露。

**定义 311–312（RCL 与 SOM）** R 输出 n-best 格 + 校准置信；S 把假设渲染回观测，`S̄` 为均值渲染。R 是病态逆问题、依赖先验；S 是良定但欠定的前向问题——信任结构不对称。

**定义 313（A2S 双往返）** `r_SR`（重建，看观测能否被假设重建）与 `r_RS`（复诵，看假设说出去能否被听回）；一致性是**似然**不是判决，观测侧第二意见与 FMA 互补。

**定义 314（混叠-分叉二分）** `U_epi^obs = H(H|O) = U_alias + U_branch`，其中 `U_alias = H(H|S̄(H))`、`U_branch` 为残差。两反事实通道使之可算：去噪渲染得 alias，重复观测平均得 branch。

**定义 315–316（REVERB-VoI 与复诵）** VoI 只对 `U_alias`；分叉提问增益 ≤ 0 被剔除。复诵 `g_readback=S(h_k, focus=slot)` 请对方确认/纠正，比开放式提问便宜、具体、可消解混叠。

**定义 317–318（CRS 与 SDC）** 私有 nonce 挑战 + 查询限速防注入/重放；`ρ_RS≤τ_ρ ∧ provenance_disjoint` 时往返才算两源，否则只算 E1 单源、禁止定案。

**定义 319–321（MDQ、流式复诵、抢占）** 问 `argmax min KL` 的区分性问题；复诵流式可打断；抢占序「安全动作 > 复诵 > 追问」，dropout 回灌成本先验。

**定义 322–323（双分辨率与证据强度）** 语义层 × 声学/原始层须同时一致；证据分 E0–E3，仅 E2/E3 可参与 k-一致定案。

**定义 324–326（干扰集、证书、包含）** `ℰ_REVERB=ℰ_FLUID×ℰ_reverb`（同音对抗/合成注入/重放/格注入/先验诱导）；`J_REVERB` 并入 SDC、别名比、CRS 参数；`U_alias≤τ / VoI≤c / SDC 无效 / CRS 失败 / 复诵超时` ⇒ 逐指令退化为 R69→R68。

## 3. 关键算法伪代码

```python
# IP-267 ABD + IP-266 A2S：双往返残差与混叠-分叉分解
def analyze_by_synthesis(R, S, o, c):
    lat      = R.recognize(o, c)                                   # [(h,p,conf,slots)]
    r_sr     = min(d_obs(o, S.mean_render(h, c)) for h,*_ in lat)  # S→R
    r_rs     = {h: d_h(h, R.recognize(S.render(h, c), c)) for h,*_ in lat}
    U_alias  = H_posterior(lat, channel=S.mean_render)             # H(H|S̄(H))
    U_epi    = H_posterior(lat)                                    # H(H|O)
    return lat, r_sr, r_rs, U_alias, max(0.0, U_epi - U_alias)     # U_branch

# IP-268/269 REVERB-VoI + MDQ：只问混叠，问最能区分的
def choose_reverb_action(lat, U_alias, o, budget):
    if U_alias <= TAU_ALIAS: return None
    for (i, j) in confused_pairs(lat):
        g = argmax_min_KL((i, j), o)                               # IP-269
        if budget.allow(g) and c_ras_wm.certify_info(g, o):
            if H_alias(lat) - expected_H_alias(lat, g, R) - cost(g) > 0:
                yield g
    yield readback_candidate(lat)                                  # IP-270

# IP-271 CRS：私有 nonce 挑战-应答
def challenge_response(S_priv, R, o, bits=64):
    nonce = sample_nonce(bits)
    o_resp = yield S_priv.prompt(nonce, focus='nonce')
    return 'live' if S_priv.roundtrip_ok(o_resp, nonce) else 'spoof'

# IP-275 REVERB 主闭环（继承 R69）
def REVERB_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    lat, r_sr, r_rs, U_alias, U_branch = analyze_by_synthesis(M.R, M.S, o, c)
    sdc = M.sdc.check()
    g = (next(choose_reverb_action(lat, U_alias, o, M.budget), None)
         if (U_alias > TAU_ALIAS and not sdc.conflicts()) else None)
    ev = M.cia.execute_reverb(g) if g is not None else None
    if ev and ev.would_decide and M.crs.challenge(o) == 'spoof':
        ev = None                                                  # 注入/重放丢弃
    U_epi_after = M.cia.update_belief(modes, ev) if (ev and ev.strength in ('E2','E3')) else U_epi
    U_floor = U_ale + (U_epi_after if ev is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_e.submit_async(g, ev, U_alias, U_branch, r_sr, r_rs, sdc)
    return k, lam, mode, (U_ale, U_epi_after, U_alias, U_branch)
```

## 4. 推导

**引理 19（混叠-分叉可分辨，「问不出分叉」）** 恒等 `U_epi^obs=U_alias+U_branch`。信息动作只改变观测似然而不改生成谱展宽 ⇒ 任意 g 对 `U_branch` 期望降幅 ≤ 0；存在 MDQ 使 `U_alias` 降幅 ≥ `max KL − ε`。系：VoI_reverb 是「可分的混叠」的函数，对分叉提问是纯浪费——解释 R69 在噪声主导场景「越问越不确定」。

**引理 20（往返信噪比与去相关折扣）** 真实观测重建残差期望 ≤ ε_align；异构合成器 S' 观测 ≥ D(S,S')−ε_align，检测间隙 = D(S,S')−2ε_align；S'=S 时隙 → 0（往返只是自洽）。R、S 误差相关 ρ_RS 时，等效证据比特折扣为 `(1−ρ_RS)·(−log r_SR/thr)`。系：SDC 无效只能算 E1，不得与他人凑 k。

**引理 21（复诵 Pareto 优于开放式提问）** 槽位级混叠下，复诵熵降 ≥ `H(h_k)−H(confusion nbhd)` 且成本 `c_rb<c_open`；故复诵在槽位级歧义上 Pareto 占优（航空/人机协作均收敛到复诵的经验由此解释）。

**定理 18（REVERB 严格包含 R69）** A99–A102 下，REVERB 任意状态期望风险 ≤ R69；且 `U_alias≤τ_alias / VoI_reverb≤c / SDC 无效 / CRS 失败 / 复诵超时` 时逐指令相同。R69 = 「永不回声」边界；安全不让步，效率只从消解混叠获利。

**定理 19（合成注入下界与 CRS 上界）** 无 CRS 时，拥有 S 的攻击者 deepfake 成功率 ≥ 1−ε；b 比特私有 nonce + 查询预算 Q 下，单次成功率 ≤ `2^{−b} + Q·2^{−b}(1−2^{−b})`，序列指数衰减。系：b、Q 必须写进 J_REVERB，不能隐式默认安全。

**定理 20（复诵无突变与抢占安全）** 复诵过 R69 同等认证 ⇒ 物理风险 ≤ ε_int；流式/打断/抢占只改证据时序、不改安全包络；超时/抢占/spoof ⇒ λ 单调不降地退化为 R69→R68，结合 R68 定理 15 ⇒ 控制连续无突变。

## 7. 本轮最大风险

**一句话**：REVERB-RAS 把「往返一致」当成独立证据，但若识别器与综合器共享先验/共训数据/同源标注（ρ_RS 偏高），往返就退化成**回声室/同义反复**——R 与 S 能一起错得自洽，把错误假设盖上「已验证」的章；此时若 SDC 估不准，系统不是更谨慎，而是**更有底气地错**：回声可以是最像真相的假象。

**次级风险与缓解**：同源往返误当正交（SDC + E1/E2 分级 + 无效只算单源）；合成观测注入/deepfake/重放（CRS 私有 nonce + 限速 + ℰ_reverb 对抗训练 + 定理 19）；识别先验幻觉被复诵放大（双分辨率 + 关键槽位复诵 + E311）；复诵打扰与预算击穿（抢占 + 异步 + dropout 回灌 + E312）；ABD 分布外失准（反事实双通道交叉校验 + U_alias≤τ 退回 R69 + E298/E302）。
