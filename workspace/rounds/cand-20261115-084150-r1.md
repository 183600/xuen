# 第 4 轮（承接第 3 轮 InstructGauge；灵感循环第 1 轮；本轮灵感：「双臂协调」×「步骤分」）

> **基线**：第 3 轮 InstructGauge（IP-321–327；定义 432–447；引理 51–58；实验 E441–E456）。第 2 轮 ToolGauge、第 1 轮 LeanGauge / MODGAUGE 骨架不变。
> 本轮纪律：**增量升级 + 严格退化**。双臂协调与步骤计分都是**可选增强**，不是依赖项；任一环节不可用都必须能逐级退回单臂 InstructGauge。

## 0. 直觉与动机

**灵感 1（双臂协调 → 第二只手臂既是资源，也是「会移动世界」的扰动源）**
直觉：前 3 轮的系统像一位很强的「单手外科医生」——发现盲区、就地探测、更新契约。加入第二只手臂，最直接的好处是**吞吐**（两臂并行探测不同盲区）和**固定**（一臂按住/夹持工件，另一臂探测，减少工件抖动）。但真正的范式变化不是多了一个执行器，而是**对象坐标系不再是静止的已知量**：当两臂同时接触同一工件或工具时，它们经由工件形成一个闭环运动链，一臂的力/位姿误差会通过工件传到另一臂。此时「两臂测量结果一致」并不能证明正确——它们可能共享同一个相对位姿标定误差、同一个工件柔顺误差，形成**共模幻觉**。因此双臂协调的核心不是轨迹插值，而是**把协调关系写成可审计的契约**：当前处于哪种协调模式、谁拥有对象系、另一臂允许多大扰动、相对位姿证书还有多久有效。没有契约，就不允许隐式协调。

**灵感 2（步骤分 → 把「任务完成」从 0/1 变成可认证的分级进度）**
直觉：机器人竞赛很少只判「成功/失败」，而是按步骤给分：接近、对准、抓取、搬运、放置各有权重。步骤分的价值有两面。**规划面**：它给出一个天然的 anytime 目标——在时间/能量预算内最大化**期望已认证分**，而不是赌一次全成。**审计面**：每一步的分数必须绑定可验证的后置条件与回执，否则分数只是自我报告。危险也在这里：标量分数会诱发 Goodhart 行为——只做容易的步骤、跳过困难前置、把一个联合步骤拆成两半各领一次分、或用同一份证据重复计分。因此步骤分不能是自由浮动的 reward，而必须定义在**带前置约束的进度自动机**上，并由**计分证书 + 证据账本**产生；分数账本只允许因证据失效而**向下修正**，绝不允许静默上涨。

**灵感 3（两者耦合 → 联合步骤、跨臂失效与「分数压力下的模式降级」）**
直觉：双臂一旦协调，就会出现**联合步骤**：后置条件是两臂回执的合取（例如「一臂夹持且另一臂完成测量」）。这带来两个新问题。第一，**部分分怎么记**：只完成一臂不能算联合步骤完成，否则分数会虚高；但也不能把已完成的单臂工作全部作废，否则降级就失去意义。第二，**追溯性失效**：如果持工件的那一臂把工件移动超出漂移预算，另一臂此前基于旧对象系的测量证书必须被**失效**，已计的分也要相应回退——这不是「更新」，而是「撤回」。最危险的耦合是：步骤分压力会诱导系统更频繁地进入高吞吐的闭环协调模式，而闭环模式恰恰是共模误差最大、证书最脆弱的模式。解法不是禁止协调，而是四根结构支柱：**协调契约显式化**、**跨臂失效与协调屏障**、**计分证书化**、**按（模式 × 步骤类型）分层校准**；再用**模式感知的步骤-臂调度器**把分数压力引导到安全可行的模式组合上。

## 1. 研究问题（本轮要回答什么）

- **Q1（双臂认识论）**：双臂测量在什么条件下是可信的？「两臂一致」何时是独立证据，何时只是同一相对位姿误差的共模放大？最小的可审计证书是什么？
- **Q2（步骤分公理化）**：如何定义步骤分，使它既是可优化的规划目标，又是不可虚报的审计量？单调性、无重复计分、前置约束与安全字典序需要哪些条件？
- **Q3（耦合的局部性）**：当协调模式切换、工件被移动或联合步骤失败时，失效能否被限制在依赖闭包内，而不是推翻全部已完成工作？分数压力能否被结构约束在安全模式内？

## 2. 四条设计原则（雏形，正式化见产物区定义 448–463）

**P1 协调契约显式化（Explicit Coordination Contract）**
任何涉及两臂的动作都必须声明 `(模式 M, 角色 ρ, 对象系 owner o*, 相对位姿证书 RelCert, 扰动预算 δ_obj)`。三种模式：独立 `Ind`（互不接触、各自独立工作区）、主从 `LF`（一臂夹持/固定、一臂探测）、闭环 `CC`（两臂同时接触同一工件/工具）。没有有效契约 ⇒ 只能 `Ind`。证书必须携带模式与角色，不允许「隐式协调」。

**P2 跨臂失效与协调屏障（Cross-Arm Invalidation & Barrier）**
对象系 owner 的运动会改变依赖该坐标系的证书真值。定义依赖边 `dep(c)`：凡引用 `RelCert` 或对象系的证书都依赖 owner 的动作。当 owner 使工件漂移超过 `δ_obj`（或相对位姿证书过期）时，依赖闭包内的证书**立即失效**，相关步骤分回退；在联合/不可逆步骤之前必须重新出证（`RelCert` 新鲜、漂移在预算内、两臂 CVC 通过），否则降级到 `LF`（静态夹具）或 `Ind`，并强制 `K=1`。

**P3 计分证书化（Certified Step Credit）**
步骤分定义在进度自动机 `A_step` 上：每个 milestone 有可测后置条件 `π_m`、权重 `w_m` 与前置 guard。只有回执验证通过才产生 `StepCert`；联合 milestone 需要两臂回执的合取；同一 milestone 只允许一个账本条目（无重复计分）；`credit` 是有效证书集合的函数，不是执行动作数的函数。安全是字典序第一目标：`Safety ≻ Score ≻ Cost`，任何分数都不能补偿安全违规。

**P4 模式分层校准（Mode-Stratified Calibration）**
协调模式改变误差分布（相对位姿误差、柔顺误差、接触力噪声），因此共形校准必须按 `stratum = (模式, 步骤类型, 单臂/联合, 臂, RelCert 年龄桶)` 分层；联合步骤的覆盖用联合界（两臂各 `α/2`）保守保证；低样本层回退到模式级，再回退全局。否则「整体覆盖 90%」可能掩盖闭环模式下的系统性失效。

## 3. 与基线的接口（如何严格退化）

- 仅一臂可用 / 两臂工作区不相交 / `RelCert` 不可用 / 耦合接触契约不成立 ⇒ `Ind` 或 `LF`，每个臂各自退化为独立的 InstructGauge；
- 步骤自动机缺失 / 无任何可验证 milestone / 计分证书不可用 ⇒ 不使用步骤分做规划，只保留二元任务完成判据，退回 InstructGauge 目标；
- 协调屏障触发 / 工件漂移超预算 / 联合步骤前置失败 ⇒ 强制 `K=1`、退出 `CC`，保留已验证前缀与已认证分，再从 `LF/Ind` 继续；
- 跨臂失效不可追踪（依赖记录缺失）⇒ 禁止 `CC`，只允许静态夹具下的 `LF`；
- InstructGauge 失效 ⇒ ToolGauge；ToolGauge 失效 ⇒ LeanGauge；LeanGauge 失效 ⇒ MODGAUGE 原样。双臂与步骤分都是增强项，不是依赖项。

## 4. 预期贡献

1. 一个**双臂测量的可审计语义**：用协调契约、相对位姿证书、耦合接触契约与跨臂失效，把「两臂一致」从直觉变成有条件的证据，并显式区分独立证据与共模幻觉；
2. 一个**步骤分公理系统**：基于带前置的进度自动机与计分证书，给出单调性、无重复计分、前置保持、安全字典序与 Goodhart 上界；
3. 一个**模式感知的步骤-臂调度器 + 协调屏障**：在吞吐/分数收益与共模风险之间做显式仲裁，失败时按依赖闭包局部回退，而不是全量推翻；
4. 一条可证伪路径：E457–E472 覆盖相对位姿误差传播、耦合契约、跨臂失效、计分完整性、联合步骤覆盖、调度收益、对抗计分与 50Hz 时序保全。

## 5. 本轮最大风险

**一句话**：双臂的「相互印证」很可能只是同一相对位姿/柔顺误差的共模放大——两臂越一致，越可能一起错；而步骤分又会奖励系统更多进入高吞吐的闭环模式，从而把这种共模错误进一步放大成「已计分、已执行、无法追回」的物理动作。

## 2. 形式化定义（要点）

**定义 448（协调模式与角色分配）** 令 `M ∈ {Ind, LF, CC}`。
`Ind`：两臂各自在互不接触的独立工作区执行，`o* = ∅`，无共享对象系；
`LF`：一臂为 `H`（夹持/固定），另一臂为 `P`（探测），`o* = H` 的臂编号，工件被视为由夹具/夹持臂锚定；
`CC`：两臂同时接触同一工件或工具，形成闭环运动链，`o* = shared`，必须携带定义 450 的耦合接触契约。
角色映射 `ρ_t: {1,2} → {P,H,I}`，每个时刻每臂恰好一个角色。协调契约 `CoordContract_t = (M, ρ_t, o*, RelCert_id, δ_obj, H_cc)` 必须显式随每个联合动作提交；缺失或过期 ⇒ 强制 `Ind`。

**定义 449（相对位姿证书与共模分解）** `RelCert = (T̂₁₂, Σ_rel, ε_rel, θ_rel, H_rel, anchor)`：`T̂₁₂` 为臂 2 坐标系到臂 1 坐标系的估计，`Σ_rel` 为其协方差，`ε_rel = c·√(λ_max(Σ_rel))`，`θ_rel` 为旋转误差界，`H_rel` 为有效期，`anchor` 为标定所依赖的公共基座/标定板。`still_valid(t) ≡ (t − t_cal ≤ H_rel) ∧ anchor 未被移动`。
把任一对象点 `p` 的两臂估计误差写成 `e = e_cm + e_ind`，其中 `e_cm` 为两臂共享的相对位姿/基座误差，`e_ind` 为各臂独立误差。定义共模占比 `γ_cm = ||e_cm|| / (||e_cm|| + ||e_ind||)`（按分量取上界）。`γ_cm` 高时「两臂一致」主要是同一个误差的重复，不是独立证据。

**定义 450（耦合接触契约）** `K_cc = (obj, o*, W_budget, κ_c, δ_obj, H_cc)`。设两臂接触力旋量 `W₁, W₂`，工件重力/外载 `W_g`，净旋量 `W_net = W₁ + W₂ + W_g`。契约成立当且仅当：
(i) **力闭合** `FC(W₁,W₂)`：存在内力的严格正组合，使工件在接触法向/摩擦锥内不可移动；
(ii) `||W_net|| ≤ W_budget`；
(iii) 工件柔顺模型给出漂移 `δ_obj = κ_c·||W_net||·H_cc`，且 `δ_obj ≤ δ_obj^max`（任务允许的测量漂移）；
(iv) 滑移裕度 `m_slip = min_i(μ_i N_i − ||t_i||) ≥ m_min > 0`。
任一不成立 ⇒ `CC` 不可用，必须降级 `LF`（静态夹具）或 `Ind`。

**定义 451（步骤进度自动机与步骤分）** `A_step = (Q, q₀, T, F, S, ≼)`：`Q` 为进度状态，`q₀` 为初始态，`T ⊆ Q × M × Q` 为带 milestone 标签的迁移，`F ⊆ Q` 为终止态，`≼` 为前置偏序。每个 milestone `m` 有：
- 可测后置谓词 `π_m(q, receipts)`（只能由回执/几何/力信号评估，不能由自然语言声明）；
- 非负权重 `w_m`，归一化 `Σ_m w_m = 1`；
- 前置 guard `g_m(q)`，由 `≼` 与已认证 milestone 决定。
步骤分势函数 `S(q) = Σ_{m ∈ M(q)} w_m·1[π_m(q)]`，要求沿合法迁移单调不减。联合 milestone `m = (m₁, m₂)` 的后置条件是 `π_{m₁} ∧ π_{m₂}`，权重只记一次 `w_m`，不允许拆成两个可独立计分的子分。

**定义 452（步骤计分证书）** `StepCert(m) = (m, ρ, M, receipts, RelCert_id, deps, valid)`。单臂 milestone 至少需要被分配臂的一个有效回执；联合 milestone 需要两臂各至少一个回执，且两回执引用兼容的 `RelCert_id`（同一有效期窗口内的证书）。`deps ⊆ Obj ∪ Milestones ∪ Certs ∪ {RelCert}` 是证书真值所依赖的对象/前置/变换集合。`valid` 不是写死字段，而是由定义 454 的失效过程重算：`valid(c) = 1 ⇔ (回执可命中) ∧ (guard 成立) ∧ (deps 中无失效项)`。

**定义 453（计分账本与 credit）** 账本 `L` 是 milestone 到证书的**单射**：`L: Milestones ⇀ StepCert`，同一 milestone 只允许一个条目；若有两臂回执支持同一联合 milestone，仍只计一次。已认证分为
`credit(L) = Σ_{m ∈ dom(L)} w_m·1[L(m).valid ∧ g_m]`。
关键：`credit` 是**有效证书集合**的函数，不是执行动作数、不是回执数、不是语言主张数的函数。没有 `StepCert` 的动作可以发生，但**不得计分**。

**定义 454（依赖图与跨臂失效）** 构造依赖有向图 `D`：证书/账本条目 → 其依赖的 milestone、对象、`RelCert`、坐标系。对事件 `x = (object, Δpose, t)`（owner 臂使对象系变化，或 `RelCert` 过期/重标定），定义受影响节点
`I(x) = Reach_D({object 或 RelCert})`，
并令 `∀c ∈ I(x): c.valid ← 0`，账本保留条目但 `credit` 重算；若步骤自动机前缀封闭，则 `credit(L) = S(q*)`，`q*` 为最远仍全部有效的已认证前缀。失效是**单调**的：只允许把 `valid` 从 1 置 0；重新出证必须创建新证书/新条目，不能把旧证书「修回」。`I(x)` 的计算必须传播到传递闭包（引理 61）。

**定义 455（协调屏障）** `Barrier(m,t)` 为真当且仅当：
(i) 若 `m` 为联合步骤或跨不可逆动作，则 `RelCert.still_valid(t)` 且 `||Δobj(t)|| ≤ δ_obj`；
(ii) 两臂的 CVC（定义 435）均通过，且联合预置 `φ_pre` 成立；
(iii) 自碰撞/共享工作区检查通过；
(iv) 不存在未处理的失效事件（`I(x)` 已清空）。
`Barrier` 失败时：联合步骤不可提交；若仍要执行，只允许 `LF`（静态夹具）或 `Ind`，并强制 `K=1`；已认证的前缀分保留，未认证的联合分**不计**。

**定义 456（步骤-臂调度）** `Sched = {(m_i, arm_i, M_i, t_i)}`，满足：
- 前置：`m_j ≼ m_i ⇒ t_j + dur_j ≤ t_i`；
- 资源：每臂同一时刻至多一个动作；
- 耦合：联合 step 需 `arm_i = {1,2}` 在同一 rendezvous 窗口内完成，或按定义 450 的接触顺序执行；
- 安全：`∀i, Barrier(m_i, t_i)`。
目标：`max E[credit(L)]`，约束为时间/能量预算与安全字典序（定义 457）。`SAS` 用滚动地平线求解：先按 `w_m / cost_m` 与前置可行性做贪心，联合步骤作为超级步骤，失败则回退到 `LF/Ind` 重排。

**定义 457（安全字典序目标）** 记 `Safety(Sched) ∈ {0,1}` 为所有步骤满足硬约束与 `Barrier`。目标为字典序
`max Sched (Safety, E[credit(L)], −Cost(Sched))`。
即：先在 `Safety=1` 的可行集中最大化期望认证分；分数永远不能补偿安全违规；在分数相同时最小化时间/能量。任何把 `credit` 放进安全约束内部做加权的做法都被禁止（防止「用分数买风险」）。

**定义 458（协调放大因子与块长）** `κ_co = K·(H(ι|ℓ) + H(M|obs) + H(T₁₂|cal))`，其中三项分别为指令歧义、模式不确定性、相对位姿不确定性。约束
`K ≤ K_MAX^co(ι,M) = ⌊K₀ / (1 + κ_co)⌋`。
若 `RelCert` 无效或 `M = CC` 且 `δ_obj` 接近预算 ⇒ `K=1` 并退出 `CC`。这是第 3 轮 `κ_sem` 的双臂扩展：把「语义 × 时间」放大再乘上「协调 × 相对位姿」放大。

**定义 459（协调静默点）** `q_co` 指：无在途联合块、无待处理失效事件、两臂均在安全 hold、`RelCert` 未在更新、账本无未提交条目。热替换/重新标定/模式切换只允许在 `q_co`；在途联合块要么 drain 到边界，要么按 `abort` 截断到安全前缀并让两臂回到 hold，绝不允许一个块观察到「混合协调契约」。

**定义 460（联合前缀封闭块）** `C_joint = (C₁, C₂, φ_pre, ψ_post, rendezvous, abort)`，其中 `C_i` 为第 i 臂的单臂块。联合前缀封闭要求：对任意 `j ≤ min(K₁,K₂)`，单臂前缀 `a_{1:j}^i` 均合法，且联合前缀 `(a_{1:j}^1, a_{1:j}^2)` 满足 rendezvous 与接触约束；若一臂在 `j` 处中止，另一臂必须有安全 hold/retreat 原语 `h_i`，使 `(a_{1:j}^1, h_2)` 或 `(h_1, a_{1:j}^2)` 仍是合法程序。该条件强于逐臂前缀封闭：**单臂可停不等于联合可停**。

**定义 461（双臂修复证书）** `RepairCert‴(s) = (ι, M, ρ, RelCert, K_cc, C_joint, CVC/STVC, {StepCert}, receipts, claims)`。审计链从第 3 轮的五级扩展为七级：指令 → 协调契约 → 联合块 → 逐臂 CVC → 步骤证书 → 回执 → 语言主张。

**定义 462（模式分层共形校准）** `stratum(ι,M) = (M, step 类型, joint/single, arm, RelCert 年龄桶)`。对每层 `s` 用校准集 `C_cal^s` 取阈值 `q_s`，使层内 `P(h* ∈ H_s | s) ≥ 1−α`。联合步骤需要两臂证书同时成立：对两臂各用 `α/2`，由联合界得联合覆盖 `≥ 1−α`；若两臂证书共享 `RelCert`，则先按 `RelCert_id` 聚类再做 cluster-level 校准，避免把共模误差当独立样本。低样本层 ⇒ 回退模式级 ⇒ 回退全局；覆盖按 `−2η` 优雅降级（引理 65）。

**定义 463（Goodhart 差距与分数膨胀界）** 对任意执行前缀，定义
`G_hat = credit(L) − score_true(executed_prefix)`，
其中 `score_true` 由独立的人类评分/离线真值给出。要求：
(i) **不高报** `G_hat ≤ 0`（认证分不得超过真值加容差）；
(ii) **可审计误差** `|credit(L) − score_true| ≤ ε_score` 对有效证书成立；
(iii) 对抗下 `G_hat^adv = sup_{伪造回执/重放/拆分联合步骤} (credit − score_true) = 0`。
`G_hat > 0` 视为设计级失败：说明计分证书可被绕过或重复计数。该定义把「步骤分」从 reward shaping 变成可证伪的审计量。

class CoordArbiter:

# IP-329 RPC：相对位姿证书（含共模分解）
class RelPoseCertifier:
    def certify(self, calib, base):
        T, Sigma = calib.estimate(base)               # 手眼/基座标定
        eps = CONF * sqrt(max_eig(Sigma))
        theta = CONF * sqrt(trace(Sigma[3:, 3:]))
        common = calib.common_mode_component(base)    # 共享基座/标定板误差
        gamma = norm(common) / (norm(common) + eps + 1e-12)
        return RelCert(T, Sigma, eps, theta, H_rel=calib.horizon,
                       anchor=base, gamma_cm=gamma)

# IP-330 CCC：耦合接触契约
class CoupledContactContract:
    @staticmethod
    def check(obj, scene, rel):
        W1, W2 = scene.wrench(1), scene.wrench(2)
        if not force_closure(W1, W2, obj.friction):
            return False
        if norm(W1 + W2 + obj.gravity) > obj.W_budget:
            return False
        drift = obj.compliance * norm(W1 + W2 + obj.gravity) * H_CC
        if drift > obj.delta_max:
            return False
        if min_slip_margin(W1, W2, obj.friction) < M_MIN:
            return False
        return True

# IP-331 SPA：步骤进度自动机（带前置/联合 milestone）
class StepProgressAutomaton:
    def advance(self, q, receipts):
        for m in self.enabled(q):                     # enabled 已含前置 guard
            if m.joint:
                ok = self.post_joint(m, receipts[1], receipts[2])
            else:
                ok = self.post(m, receipts[m.arm])
            if ok:
                q = self.delta(q, m)
        return q

    def score(self, q):
        return sum(self.w[m] for m in self.reached(q))  # 单 milestone 单权重

# IP-332 SCC：步骤计分证书 + 账本（无重复计分）
class StepCreditCertifier:
    def certify(self, m, q, receipts, rel):
        if m.joint:
            if not (receipts[1] and receipts[2]):
                return None                            # 联合步骤缺一臂 ⇒ 不计分
            if receipts[1].rel_id != receipts[2].rel_id:
                return None                            # 不同相对位姿窗口不可拼
        else:
            if not receipts[m.arm]:
                return None
        if not self.guard(m, q):
            return None                                # 前置不成立 ⇒ 不计分
        cert = StepCert(m, m.role, m.mode, receipts, rel.id,
                        deps=self.deps(m), valid=True)
        if m in self.ledger:
            return None                                # 单 milestone 单条目
        self.ledger[m] = cert
        return cert

    def invalidate(self, x):
        for m in self.reach_dep(x):                    # 传递闭包
            if m in self.ledger:
                self.ledger[m].valid = False           # 只向下修正，不删除
        self.credit = sum(self.w[m] for m, c in self.ledger.items()
                          if c.valid and self.guard(m, self.q))

# IP-333 SAS：步骤-臂调度（滚动地平线，联合步骤为超级步骤）
class StepArmScheduler:
    def schedule(self, automaton, q, horizon, budget):
        todo = [m for m in automaton.frontier(q)
                if automaton.guard(m, q) and barrier_ok(m)]
        todo.sort(key=lambda m: m.w / max(m.cost, 1e-9), reverse=True)
        plan = []
        for m in todo:
            mode = Mode.CC if m.joint else Mode.LF if m.needs_fixture else Mode.Ind
            arm = {1, 2} if m.joint else {m.preferred_arm}
            if self.feasible(plan, m, arm, mode, budget):
                plan.append((m, arm, mode, self.next_slot(plan)))
        return plan                                    # 失败/超预算 ⇒ 截断，保留前缀

## 4. 推导

**引理 59（相对位姿与双臂测量误差传播）** 设臂 `i` 对同一对象点的估计误差为 `(ε_i, θ_i)`（平移/旋转），相对位姿证书误差为 `(ε_rel, θ_rel)`，对象点距臂 2 末端的杠杆臂长为 `L`。则臂 1 坐标系中的合成误差满足
`ε_meas ≤ ε₁ + ε₂ + ε_rel + L(θ₁ + θ₂ + θ_rel) + ε_noise`。
因此「两臂一致」的差
`||p̂₁ − p̂₂|| ≤ ε₁ + ε₂ + ε_rel + L(θ₁+θ₂+θ_rel) + 2ε_noise`，
它**不会**因为取平均而消失；若两臂共享同一 `T̂₁₂`，其共模分量按 `γ_cm` 保留。推论：只有当 `ε_rel + L·θ_rel ≤ ε_budget` 且 `γ_cm ≤ γ_max` 时，双臂一致性才可以作为独立证据。
*证明骨架*：把两次估计都写成真值加误差，经同一变换链复合；对复合用三角不等式与旋转的 Lipschitz 性（`||R(θ)x − x|| ≤ Lθ`）放大，合并同类项即得。共模项由 `e = e_cm + e_ind` 分解直接得到。

**引理 60（耦合接触契约的测量有效性）** 在准静态、线性柔顺假设下，若 `K_cc` 成立（力闭合、`||W_net|| ≤ W_budget`、滑移裕度 `≥ m_min`），则块执行期间对象系漂移
`δ_obj(H_cc) ≤ κ_c·W_budget·H_cc`。
若实际漂移在该界内，则任何基于对象系的测量满足
`ε_meas^obj ≤ ε_meas + J_obj·δ_obj`，
其中 `J_obj` 为对象系漂移对测量量的敏感度。反之，若力闭合失败或滑移裕度耗尽，`K_cc` 失效，必须把 `CC` 降级为 `LF/Ind`，且不得用旧对象系证书计分。
*证明*：线性柔顺 `Δx = κ_c W` 沿时间积分；力闭合保证接触不脱开；滑移裕度正保证无单边滑移；Lipschitz 给出测量误差放大。准静态假设失效时加入惯性项 `M·a`，界变为 `κ_c(W_budget + ||M a||_∞)H_cc`。

**引理 61（跨臂失效的可靠性/完备性）** 设依赖图 `D` 是真实依赖关系的**过近似**（sound dependency recording），`I(x)` 为从变化对象/`RelCert` 出发的传递闭包。则：
(i) **完备性**：任何真值依赖 `x` 的证书 `c` 都有 `c ∈ I(x)`；
(ii) **可靠性**：任何 `c ∉ I(x)` 的依赖都不含 `x`，其真值不变；
(iii) 失效后账本 `credit` 等于删除 `I(x)` 后剩余有效证书的权重和；若步骤自动机前缀封闭，则等于最远全有效前缀的 `S(q*)`。
*证明*：`D` 过近似 ⇒ 所有真实依赖边都在 `D` 中，传递闭包必覆盖受影响节点；反向由 `I` 的定义与「依赖未变则真值不变」直接得。前缀封闭下有效 milestone 集合是链，`credit = S(q*)` 由定义 451/453 逐项相加得到。

**引理 62（计分账本的单调性、无重复计分与前置保持）** 对任意执行：
(i) `credit(L)` 对有效证书集合单调不减；
(ii) 一个联合 milestone 即使有两臂回执也只计一次（账本单射）；
(iii) 失效只会使 `credit` 减少，且减少量恰为失效 milestone 的唯一权重（含依赖它的条目），不会出现「先扣后加」的静默回补；
(iv) 若 `A_step` 前缀封闭且 guard 只依赖已认证前缀，则 `credit(L) = S(q*)`，且 `q*` 之前的每个 milestone 都有有效证书。
*证明*：`credit` 是互不重叠 milestone 权重之和；单射保证无重复；`valid` 单调递减；guard 的前缀依赖保证不会跳过前置；对前缀长度归纳得 (iv)。

**引理 63（步骤-臂调度的近似界）** 记 `OPT` 为预算内最大期望认证分。
(i) 若步骤相互独立、预算为基数约束、边际收益递减（子模），贪心按 `w_m/cost_m` 取得 `(1−1/e)·OPT`；
(ii) 若前置为 out-forest、成本为单位、两臂可并行，贪心 list schedule 对分数最大化取得 `≥ 1/2·OPT`；
(iii) 联合步骤作为超级步骤（成本取 rendezvous 窗口长度，收益为单一 `w_m`）不破坏上述界；
(iv) 模式切换的额外代价可加性上界为 `Σ c_switch`，故 `OPT − GREEDY ≤ (1−1/e)OPT + Σ c_switch`（或 `1/2` 情形同理）。
*证明*：子模贪心的标准 `(1−1/e)` 界；out-forest 单位成本用 list scheduling 的 `1/2` 交换论证；超级步骤只合并节点、不改变可行性结构；切换代价由三角不等式累加。

**引理 64（协调模式降级的安全性）** 若 `RelCert` 失效或 `K_cc` 不成立，则从 `CC` 降级到 `LF`（静态夹具）或 `Ind` 只会**缩小**可采纳联合动作集；在 `Ind` 下系统等价于两个独立的 InstructGauge 实例，因此第 3 轮的全部安全定理（引理 51/52/55/57）逐臂继承。联合步骤的分数在降级后不再被认证，但已验证的单臂前缀分保留。
*证明*：`CC` 的动作集是 `LF/Ind` 动作集与额外耦合约束的交集，去掉约束只会扩不能缩；但联合步骤**要求**额外证书，故在降级后该步骤不可提交，动作集对联合步骤是缩小的；`Ind` 下两臂无共享对象系，证书互不依赖，逐臂回到 InstructGauge。

**引理 65（模式分层的共形覆盖）** 层内可交换时 `P(h* ∈ H_s | s) ≥ 1−α`。联合步骤若两臂各用 `α/2`，由联合界得 `P(两臂同时覆盖) ≥ 1−α`；若各用 `α`，得 `≥ 1−2α`。边缘覆盖为 `P(h* ∈ H_s) ≥ 1−α − Σ_s π_s·TV_s`，其中 `TV_s` 为层间分布漂移。低样本层回退模式级/全局 ⇒ 覆盖按 `−2η` 优雅降级。共享 `RelCert` 的样本必须先按 `RelCert_id` 聚类，否则共模误差会破坏层内可交换性。
*证明*：标准共形覆盖 + 联合界；聚类后用 cluster-level 校准恢复可交换性；TV 分解为边缘覆盖的标准不等式。

**引理 66（协调开销与 50Hz 保全）** `CMA` 每决策 `O(1)`；`RPC` 查询 `O(1)`（周期标定在 `q_co`）；`CCC` 为 `O(n_c)` 力闭合检查（`n_c ≤ 4`）；`SPA` 每 milestone `O(1)` 增量更新（或用 Fenwick 树 `O(log|M|)` 查询）；`SCC` 为 `O(|deps(c)|)`；`CIB` 的失效传播按依赖边摊还 `O(1)`，最坏 `O(|L|)`；`SAS` 贪心 `O(n log n)` 异步执行。故 50Hz 主路径新增周期 `< 0.2ms`，继承 ToolGauge 引理 50 的硬实时结论；最坏失效风暴被 `q_co` 屏障与依赖图分区限制在非实时路径。
*证明*：逐组件计数；失效只在对象事件或 `RelCert` 过期时触发，且事件率由 `H_cc/H_rel` 限制；主循环只做标志位合并。

## 8. 本轮最大风险

**一句话**：`RPC` 的 `ε_rel` 与 `CCC` 的柔顺模型共同构成双臂证书的**共同锚点**，一旦相对位姿或工件柔顺被低估，两臂会以高度一致的方式一起错，而步骤分又会奖励系统更多进入这种高吞吐闭环模式——于是「两臂相互印证」变成共模误差的放大器，且错误会在计分账本里表现为「已认证、已执行、无法追回」。
