# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 1 轮；本轮灵感：「移动操作」×「安全交互」）

> 第 57 轮把安全的赌注从"模型置信"换到"证据质量"，并用元摊销、跨模态对账、个性化有界信任给证据质量加了三道保险；但它仍隐含两个静态假设：**(a) 证据采集的坐标系不变**——默认"在 A 点探到的性质，在 B 点仍然成立"，仿佛机器人是钉在地上的；**(b) 交互是单点、单向、被动的**——安全被化约为"这次接触可不可信"，默认人只是障碍或标注者，而不是一个会移动、会误读、也会救援的共处主体。本轮两个灵感正好戳破它们：**移动操作**告诉我们，基座既是运输工具、又是感知平台、还是施力反作用面与逃生资源，一次移动会同时改变可达性、稳定性、遮挡与退路，**证据是有坐标系的、会随移动而衰老**；**安全交互**告诉我们，安全不是"不碰撞"这个点事件，而是机器人**穿过共享空间的一整段可预测契约**——速度-分离、功率-力限、分区同意、交接与让行缺一不可。更尖锐的是：基座移动使"移动到更安全的位置"本身成为逃生动作，而这一动作又制造新的移动风险——**逃生与危险共用同一个自由度**。本轮因此把命题升级为 **"站位可证、证据可搬运且会过期、交互可预测的双向安全承诺"**。

核心矛盾：
- **H29（移动 vs 证据保鲜）**：坐标系相关证据（相对位姿、可达、遮挡、接触几何、退路）随基座移动而失效，坐标系无关证据（质量、材质、易碎性、语义身份）却可跨站位摊销；若一律重探则移动操作昂贵到不可用，若一律搬运则旧证据会给新站位的不可逆操作背书。
- **H30（站位 vs 交互）**：让操作最顺的站位（贴近物体、正对、伸臂最短）往往让交互最危险（挡住人的通路、挤占退路、以高速接近人）；可达、稳定、感知、逃生与人的通行争夺同一个基座位姿，操作与交互在同一个自由度上目标冲突。
- **H31（可预测 vs 可反应）**：安全交互要求机器人动作可读、可预测，人才不会误判；移动操作却需要基座实时调整以够到、避让、顺应。过度反应使人的预测失效（更易撞），过度预测使系统不能躲、不能让、不能停——需要"包络层可预测、动作层有界反应"的分层。
- **H32（单向防护 vs 双向安全）**：传统安全只保护人免受机器人伤害；但在共享空间里机器人也依赖人的配合（让行、不抓取、正确交接），人既是被保护者，也是扰动源与独立验证者/救援者。把交互建成单向防护，会漏掉交接、共享控制与"人作为外部证据"的协作安全。

## 0. 直觉与动机

**灵感 1（移动操作 → 站位是操作的一部分，移动会让证据过期）**
直觉：固定机械臂把"在哪"当成给定；移动操作把"在哪操作"变成决策。基座不是底盘，而是**一个四重角色**：够得到（可达/可操作度）、站得稳（支撑/滑移/倾覆）、看得见（遮挡/视角）、退得掉（逃生方向）。同一个基座位姿同时决定这四件事，所以"选站位"不是导航的收尾，而是操作的第一步。更关键的是：**证据不是真的，它只是在一个坐标系里、在一段时间内是真的**。质量、材质、易碎性这类性质换个站位仍成立（不变量），相对位姿、可达性、遮挡、接触几何、退路却随移动失效（变量）。移动操作的经济性来自这条区分：只对变量重探，不变量跨站位摊销；安全性来自另一半：变量证据在搬运超限时必须降级为"线索"，不得为不可逆操作背书。

**灵感 2（安全交互 → 安全是穿过共享空间的整段契约，而非单点不碰撞）**
直觉：把一个会移动、会伸臂、会递物的机器人放进有人空间，安全就不再是"末端别碰到人"。人需要能**预测**机器人要去哪、要停多久、下一步是伸手还是后退；机器人需要**分区**地获得同意（可以接近≠可以伸臂≠可以接触≠可以交接）；接触时力/压强要按身体部位限；任何时刻都要留一条不压住人的退路。于是安全被写成一份**空间-时间契约**：速度-分离（离得近就减速）、功率-力限（真接触也不伤人）、分区同意（Z0 通行/Z1 接近/Z2 交互/Z3 接触）、最坏人动作下的应急集、以及不阻断人的 egress。同意是**分区、分动作、限时**的，不是一张一次性通行证。

**灵感 3（合流 → 基座-臂-人三体耦合，逃生与危险共用自由度）**
直觉：这是本轮最尖锐处。基座移动改善可达，却让证据过期、让耦合动力学变化、让人对机器人的预测失效；而"移动到更安全站位"这个逃生动作，本身要在人的共享空间里移动——**逃生动作会制造新的交互风险**。所以不能把"移动—操作—交互"拆成三个各自安全的模块再串联：每个模块局部安全，串联起来在**迁移瞬间**可能出事。正确做法是把站位、证据、耦合、交互写成**同一组带有效期的证书**，并让所有逃生动作（后撤/重定位/降下/交接/安全停）也必须先过交互包络与可预测性契约。

**灵感 4（证据门从五类到八类 + 坐标系限定词）**
直觉：第 57 轮证据门 EV-probe*/visit/margin/xmodal/human 判定的是"证据本身够不够强"，本轮再问两个新问题：**它是在当前站位/坐标系下有效的吗？**（坐标系限定词 FRE，挂在所有证据上）；**这个站位与这次交互允许操作吗？**（新增 EV-stance、EV-coupled、EV-interact）。击穿安全现在需要：证据坐标系错判 ∧ 站位耦合失稳 ∧ 证据搬运超期 ∧ 交互包络漏人 ∧ 可预测性失效 ∧ 第 57 轮五类证据全错——纵深从五层到八层，且新增三层都在"移动与共处"这一侧。

**灵感 5（PCE+ → PCE-MI：移-锚-探-诺-互-撤）**
直觉：探-诺-演从"检查点循环"变成"移动操作回合"：先在站位图上规划"在哪操作"，移动时维护交互包络与人的预测；到站后先**锚定**（刷新站位证书、按不变量类判定搬运证据是否过期、重锚变量），再做第 57 轮的探询与承诺；跨不可逆边界（承重/抬起/交接）须同时有耦合兑现证书与释放证书；一旦人进入包络或任一守卫失效，切**规范安全动作**（停/退/让/降下/交接），而不是任意急停。三个安全通道不变：**信念更准（含加宽）/ 动作更保守（含可撤回、可让行、可重定位）**，只是"更保守"现在多了两个可证形式：**站位不可证就不操作，交互不可证就不移动**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（移动站位证书 MSC）** 候选站位 s=(x_b∈SE(2), 支撑域 S_b, 局部地形 h_s)，操作对象 o 与操作方案 g。MSC(s,o,g) ⇔ 六条同时成立：(M1) **可达**：o 的位姿落入臂工作空间，可操作度 μ_arm(J)≥μ_min；(M2) **耦合稳定**：在臂最坏反作用扳手 W_req(g) 与动态惯性下，ZMP/支撑裕度 ξ(s)≥ξ_min，牵引需求 ≤ μ_trac·N 留 margin，滑移概率 ≤p_slip；(M3) **感知**：所需模态对 o 的可见性/质量 q_m≥q_min（含腕相机遮挡）；(M4) **精度**：基座运动引起的末端误差 σ_ee(s)≤σ_max(g)；(M5) **逃生**：存在后撤/重定位动作 ρ_esc，τ_ρ≤τ_esc 且 ρ_esc 全程满足 SIE——不能把人或障碍留在退路上；(M6) **交互相容**：站位不把机器人交互包络压入未同意的个人空间，且不阻断人的 egress。任一不成立 ⇒ 站位不可用。**站位图** G_st=(S,E_st)，边为满足 SIE 与 LPC 的安全迁移；基座落点 = argmax_s [任务进度 − 成本] s.t. MSC(s,o,g) ∧ SIE(s)。

**定义 140（坐标系相对证据与保鲜 FRE）** 证据 e=(π,v,F_e,t_e,h_e,mod,prov)，π 为被证性质，F_e 为采集时的基座/局部锚定坐标系。**不变量类** inv(π)∈{I,D}：I 为坐标系无关（质量、材质/摩擦类、易碎性、语义身份、任务目标）；D 为坐标系相关（相对位姿、可达性、遮挡、接触几何、局部坡度/柔顺、人的接近度、退路方向）。基座由 F_e 移到 F' 时，D 类证据按 T_{F_e→F'} 搬运，误差上界
ε_F = κ_Δ‖Δ‖ + κ_θ‖Δθ‖ + κ_s∫|slip|dt + κ_z∫|a_z|dt + κ_dyn∫‖a_b‖dt。
证据有效 ⇔ ε_F≤θ_F(π,risk) ∧ (t−t_e)+λ_m∫‖v_b‖dt+λ_a∫‖a_b‖dt ≤ h_e(π)（**运动比时间更催老证据**）。失效 ⇒ 进隔离：只可作 VOI/规划线索，不得计入 R2 不可逆证据。**重锚三途**：(A) 当前坐标系重观测（探针/到访）；(B) 不变量豁免（π∈I，无需重探）；(C) 关系搬运（物体刚连于已重定位的锚定地标）。**只有 D 类需要重探**——这是移动操作经济性的来源；把 D 误判为 I 则是本轮最危险的错误。

**定义 141（基座-臂耦合兑现证书 CFC）** 基座状态 s_b=(x_b,v_b,a_b,支撑,滑移,悬挂)，臂状态 s_a。**耦合可达扳手集**
C_cpl(s_b,s_a)={(w_e,w_b): w_e=J^{-T}τ_a, w_b=reaction, |τ_i|≤τ_i^max(T_i), |q̇_i|≤q̇_i^max, τ_iq̇_i≤P_i^max, Σ∫τq̇≤E_budget, ξ(s_b,w_b)≥ξ_min, P_slip≤p_slip, σ_ee≤σ_max}。
CFC(g,s) ⇔ (C1) W_req(g)=W_g⊕W_inertial⊕W_disturb⊕W_margin ⊆ C_cpl；(C2) 接触力∈摩擦锥 ∧ F_obj（法向/切向/压强/变形）；(C3) 末端精度 σ_ee²=σ_kin²+σ_base²(v_b,a_b)+σ_comp²+σ_slip²≤σ_max(g)；(C4) 保持时长 T_hold≤h_cpl（热/能量/滑移漂移的有效期）；(C5) 存在释放/交接/降下方案 ρ_rel，τ_ρ≤τ_esc、E_ρ≤E_budget−E_probe−E_hold（**撤退预算未被探针与保持吃掉**）。关键：C_cpl 是**闭环耦合集**，不是"臂力闭合 ∧ 基座不翻倒"的笛卡尔积；开环分别成立不等于耦合成立。

**定义 142（安全交互包络 SIE）** 人集 H={h}，机器人扫掠体 V_r(t)。分离速度-距离 d_req(v_rel,T_react)=v_rel·T_react+d_margin；接触力/压强按身体区域限 f_lim。**空间同意区** Z0 公共/通行、Z1 接近、Z2 交互（伸臂/递物）、Z3 接触/交接，所需同意级 L_req(Z) 严格递增（Z0→L0，Z1→L1，Z2→L1+意图发布，Z3→L2）。SIE(t) ⇔ ∀h∈H：(S1) d(V_r(t),h)≥d_req(v_rel,T_react)；(S2) 若接触，f,p≤f_lim(区域)；(S3) 对预测集内**最坏人的动作**（迈步/伸手/转身）存在安全应急集，无不可避免越限接触；(S4) 不阻断人的 egress，且机器人逃生不需侵入人的个人空间；(S5) 当前区 Z 满足 L≥L_req(Z)，且注意力/确认带输入误差模型（承接 MXI）。同意是**分区、分动作、限时**的：接近同意≠接触同意≠交接同意。

**定义 143（双向可预测性契约 LPC）** 机器人发布意图 I_t=(路径包络,相位,预计停留,下一步规范动作)、偏离预算 Δ_pred、规范安全动作集 M_safe={stop,retreat,yield,lower,handover}。LPC ⇔ (L1) 实际轨迹要么落在 I_t 的 Δ_pred 包络内，要么切换到某个 m∈M_safe 且有声明触发条件；(L2) 无"静默任意偏离"；(L3) 意图更新率 ≥1/T_react，使人的预测误差有界；(L4) 人的可能响应被**防御性**建模——系统安全不依赖"人会避让"；(L5) 人可作为独立验证者/救援者（双向：人既是被保护者，也是扰动源与协助者）。LPC 把反应性装进有限个可读动作：**可预测性在包络层保证，反应性在规范动作层释放**，以此化解 H31。

**定义 144（探-诺-移-互算子 PCE-MI）** 每个移动操作回合：①**规划**：路线 × 站位图 G_st，标注 stance-object 对与预期交互区；②**移动**：沿 SIE 与 LPC 迁移，维护人的预测与最坏应急集；③**锚定**：到站刷新 MSC，按 FRE 判定搬运证据有效性，重锚 D 类，更新 b_r；④**探询**：在 PCE+ 基础上，VOI 计入"重锚价值 + 交互风险 + 迁移成本"，只做非破坏探针，保留撤退预算；⑤**承诺**：操作前须 EV-stance ∧ EV-coupled ∧（D 类的 EV-frame）∧ 第 57 轮证据门；跨不可逆边界（承重/抬起/交接）须 CFC ∧ 释放证书；⑥**交互**：进入 Z2/Z3 切交互模式，请求分区同意，必要时执行 M_safe；⑦**撤退/重定位**：任一守卫失效触发释放树 {降下,后撤,交接,安全停}；**重定位是一等安全动作，但重定位本身须过 SIE/LPC**；⑧**终止**：在有限站位迁移+探针+规范动作内终止于 {完成, 交接, 撤退, 安全停}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def frame_valid(e, F_now, risk):                    # IP-140: 证据有坐标系与保鲜期
    if inv(e.pi) == 'I': return True, e             # 不变量：跨站位摊销
    eps = transport_error(e.F, F_now)               # 滑移/振动/动态耦合
    age = (now - e.t) + lam_m * motion(e.F, F_now) + lam_a * accel(e.F, F_now)
    if eps <= theta_F(e.pi, risk) and age <= e.h: return True, e
    return False, quarantine(e)                     # 只作线索，不得背书 R2

def stance_certificate(s, o, g, humans):            # IP-139: 六条同时成立
    return (reach(s, o, g) and coupled_stable(s, g) and sensing(s, o)
            and accuracy(s, g) and escape_exists(s, humans)
            and interaction_compatible(s, humans))

def coupled_feasible(g, s, budget):                 # IP-141: 闭环耦合兑现
    if not subset(w_req(g), c_cpl(s)): return False
    if not within_friction_and_fragility(g): return False
    if sigma_ee(s, g) > sigma_max(g): return False
    if hold_time(g) > h_cpl(s): return False
    return reserve_escape(budget, g)                # 撤退预算仍够

def interaction_ok(r, humans, mode):                # IP-142: 速度-分离+力限+分区同意
    for h in humans:
        if dist(swept(r), h) < d_req(rel_speed(r, h), T_react): return False
        if contact(r, h) and force_pressure(r, h) > f_lim(h.body): return False
        if not contingency_set_safe(r, h, predict(h)): return False
    return egress_ok(r, humans) and consent_level(r, mode) >= L_req(zone(r))

def legible_step(r, intent, humans):                # IP-143: 包络内可预测
    if within(r.traj, intent.envelope, intent.delta_pred):
        return r.traj
    return canonical_maneuver(r, intent.M_safe)     # 只允许可读的有限动作
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MSC | O(\|S\|·(d_arm+\|H\|)) / 站位 | O(\|S\|) | 六条件保守、逃生路径在 SIE 内 |
| FRE | O(1)/证据；O(\|E\|)/站位 | O(\|E\|) | 不变量分类正确、搬运误差上界诚实 |
| CFC | O(d_arm+\|W\|)/抓取 | O(\|W\|) | 闭环耦合集保守、撤退预算未被挪用 |
| SIE | O(\|H\|·T_pred)/控制步 | O(\|H\|·T_pred) | 最坏人动作、力限、egress 保守 |
| LPC | O(1)/步 + 意图发布 | O(\|M_safe\|) | 偏离在预算内或切规范动作、更新率≥1/T_react |
| PCE-MI | O(\|S\|·\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+\|H\|·T_pred) | O(\|V\|+\|σ\|) | 有限迁移+探针+规范动作终止 |

```python
        return Evidence(e.pi, e.v, F_now, e.t, e.h, e.mod, e.prov)   # 不变量：直接摊销
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MSC | O(\|S\|·(d_arm+\|H\|)) / 站位；建图 O(\|S\|²) | O(\|S\|) | 六条件保守、逃生路径在 SIE 内（A45） |
| FRE | O(1)/证据；O(\|E\|)/站位 | O(\|E\|) | 不变量分类正确、搬运误差上界诚实（A41） |

| LPC | O(1)/步 + 意图发布 | O(\|M_safe\|) | 偏离在预算内或切规范动作、更新率≥1/T_react（A44） |
| FSE-M | O(\|σ\|·(1+\|H\|)) | O(\|σ\|) | 无证据类即拒、坐标系失效隔离、越级硬禁 |
| PCE-MI | O(\|S\|·\|CP\|·(k_p+k_c)·(C_VOI+d_φ)+\|H\|·T_pred) | O(\|V\|+\|σ\|) | 有限迁移+探针+规范动作终止、四态完备 |

**正确性定理（MICS, Mobile Interaction Certified Soundness）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** FRE 搬运误差上界 ε_F 与不变量分类诚实，重锚覆盖所有 D 类；**(A42)** CFC 的 C_cpl 是真实耦合可达集的保守内近似，稳定/滑移/精度界诚实；**(A43)** SIE 对预测集内最坏人动作保守，力/压强限与 egress 诚实；**(A44)** LPC 偏离不超 Δ_pred 或切换 M_safe，意图更新率 ≥1/T_react；**(A45)** MSC 六条件保守，释放树对可达状态集完备。则：

1. **移动承诺健全性**：`P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_frame + δ_cpl + δ_int`；其中 δ_frame 仅对 D 类证据计，I 类只留分类错误 δ_inv；EV-interact 不进入不可逆必要证据集。
2. **交互安全**：对预测集内人的任何动作，不存在不可避免的越限接触；预测集外事件以 δ_pred 计，且由防御性建模与力限/安全停兜底（系统安全不依赖"人会避让"）。
3. **交互单调性强化**：MSC/FRE/CFC/SIE/LPC 只能经 (a) 校准信念更新（含强制加宽）或 (b) 更保守动作（后撤/重定位/降速/让行/交接/安全停）影响系统，不存在升险路径；**重定位只有在 SIE∧LPC 通过时才算保守动作**。
4. **终止性**：PCE-MI 在有限站位迁移 + k_probes+k_cons 探针 + 有限规范动作内终止于 {完成, 交接, 撤退, 安全停}。
5. **部署界**（对回合与检查点取联合界）：

```
P_safe ≥ 1 − Σ_ep Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_frame·1[D] + δ_cpl + δ_int)
             − P(迁移段证书失效未检出) − P(人的动作超出预测集) − P(重定位逃生失败)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**站位给可达、耦合给兑现、FRE 给证据的坐标系与保鲜、SIE 给共处的空间契约、LPC 给可预测的反应性**；五者全部是"带有效期的局部证书 + 迁移段整段证书"，逃生动作必须先自证，绝不把"移动到更安全处"当成无条件的安全动作。


JCPS 输出扩展为：
`(..., q_φ/k*, D(r), ρ_ℳ, s_op/auth, m_E, ood_state, J_p, s*/G_st, {e:(F_e,h_e,inv)}, C_cpl, Z/L, I_t/Δ_pred/M_safe, J_mi)`

其中新增：`s*/G_st` 选定站位与站位图；`{e:(F_e,h_e,inv)}` 带坐标系与保鲜期的证据账本；`C_cpl` 耦合可达扳手集；`Z/L` 交互区与同意级；`I_t/Δ_pred/M_safe` 意图包络/偏离预算/规范动作集；`J_mi` 移动-交互证书。

云边协议 CEB++ → **CEB-MI**：云端可下发站位图先验、人的行为先验与耦合模型增量，但**移动/交互先验也要过隔离区**——先以影子模式在边端迁移段上运行，回归测试（站位证书误判率不升 ∧ 交互包络违规不升 ∧ 不变量分类精度不降）通过后才接管；边端回传迁移段坐标系漂移残差、耦合失效事件与人的实际响应，作为云端补盲与防御性建模的校准集。第 57 轮"一切判定器走隔离"在本轮推广为"**一切带坐标系的判定器与其迁移段证书走隔离**"。

## 6. 本轮最大风险

**一句话**：本轮把安全建立在"站位可证、证据可搬运、交互可预测"三张**局部**证书上，而真正的危险恰恰发生在证书之间的**迁移瞬间**——基座一动，坐标系证据同时过期、耦合动力学同时改变、人的预测同时失效，而"移动到更安全站位"这一逃生动作本身又在共享空间里制造新的移动风险；若迁移守卫只做逐点检查而不做整段证书，系统就会在每个点上都安全、却在两点之间出事。
