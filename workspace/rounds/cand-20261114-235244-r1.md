## 0. 直觉与动机

### 灵感 1（语义建图：盲区不是格子，而是“地图上的一个待解释命题”）

直觉：第 2 轮 D-Box 的覆盖矩阵是**无宾语**的：格子 (d,m,i) 只记录“没有有效回执”。但同一个空格子可能对应完全不同的世界命题：
- 一个透明杯子的 **物体级** 未验证（它的深度从未被独立确认）；
- 桌沿的 **地点级** 未验证（跨越自由空间的支撑关系）；
- “杯子在桌上”这条 **关系级** 未验证（两物体都验证过，但接触/支撑关系没有）；
- 一次 **数据关联** 未验证（两帧里的杯子是不是同一个杯子）。

语义建图把这些命题显式化为带属性的图：地点 P、物体 O、关系 R；节点有几何协方差、语义标签分布、关系协方差、时间戳与 provenance；边有相对位姿与支撑/包含/可达等谓词。
于是盲区从“格子”升级为“**地图组件上的不确定命题**”，L-Box 的假设有了 grounding，探测工具的选择也有了语义先验（透明物体→双目/偏振/敲击；镜面→多视/结构光；可动物体→先轻推再测）。
但语义建图自身有两个致命失败模式，必须在设计里正面处理：
1. **假闭环（false loop closure）**：把两个相似的角落认成同一个地点，一下子把两处的不确定度“合并”并错误降低；
2. **感知别名（perceptual aliasing）**：两个相同杯子被当成同一个物体，导致一处修复被“转移”到另一处。

这两者都会制造**跨节点的相关误差**，恰好是第 2 轮最大风险（摊销先验污染）的地图版本。因此本轮不把地图当作真值，而把它当作**可错证人**：多假设、显式 provenance、闭环一致性证书，三者缺一不可。

### 灵感 2（闭环控制：修复是一个调节问题，不是一次性事件）

直觉：第 2 轮的 6C 是开环的：D-Box 发现盲区 → 触发一次 6C → 成功/失败 → 结束。
它没有回答：如果场景持续漂移，修复速度跟得上不确定度增长吗？如果预算有限，应该先修哪些节点？如果一次修复让别处变差，谁来发现？如果控制器一直失败，是执行器不够，还是地图错了？
闭环控制的语言恰好补上这一层：把每个地图节点的认知不确定度看作被控状态 x(t)，把探测程序/热替换看作控制输入 u(t)，把场景变化、传感器漂移、先验偏移看作扰动 d(t)，把回执、覆盖率、跨模态残差看作测量 y(t)。参考 r(t) 由任务风险预算经共形风险控制反解得到；误差 e=x−r；控制器用事件触发 MPC/PI 在预算、速率、PROBING 包络与安全门下分配动作。
关键不是“加一个 PID”，而是三件事：
(a) **稳定性/收敛性**：在标定的扰动界内，不确定度收敛到 r 的邻域，而不是越修越乱；
(b) **抗饱和与延迟补偿**：探测是秒级、异步、可能失败的执行器，必须有 anti-windup、速率限制与在飞请求去重；
(c) **模型-对象失配检测**：如果实际收缩持续低于预测，残差会暴露“地图错了/先验错了/执行器坏了”，而不是把失败归因于“再修一次”。

闭环也带来新的危险：**控制器可能把系统稳定在一个错误的地图上**。因此必须有独立于控制器的结构化残差观测器（MPM），以及多假设地图；不能让控制器自己给自己打分。

### 合流（Map–Control 对偶：地图给出相关结构，控制器给出可检验的动力学）

第 2 轮的相关性风险之所以难查，是因为所有盲区共享同一个先验，但系统没有显式的“共享来源”结构。语义地图恰好提供了这个结构：
- 同一个物体/材质/地点/闭环分支下的节点，其证据通过 provenance DAG 共享未验证叶子，因此**不应被当作独立样本**；
- 控制器要做的不是“多采几个样本”，而是“**用不同来源的探测打破相关性**”——这正是有效样本量 n_eff 而非原始样本数 n 的含义（引理 53）；
- 反过来，如果控制器在某个地图组件上反复无法收敛，而其他组件正常，结构化残差就把怀疑定位到该组件的 provenance 割集，触发**局部回滚**而不是全局 quarantine。

一句话：**地图告诉控制器“哪些东西一起错”，控制器告诉地图“你哪里可能错了”。**

## 1. 形式化定义（增量：定义 432–447）

**定义 432（语义-度量地图 SAM）** 语义地图是带属性的多层图
`G_A = (V, E, φ, ℓ, π, τ)`：
- `V = P ∪ O ∪ R` 分别是地点、物体、关系节点；每个节点 v 携带几何支撑 `g_v`（SE(3) 位姿或区域及其协方差）、
  语义标签分布 `ℓ_v ∈ Δ(𝒞)`、关系协方差 `Σ_rel(v)`、新鲜度 `age_v`、状态 `status_v` 与 provenance DAG `π_v`；
- `E` 是空间/功能/支撑边，每条边携带相对位姿协方差与谓词标签；
- `φ: 格子 x ↦ 至多一个活动节点集合`，给出度量格子到语义节点的归属与归属置信度；
- `τ` 是版本号；地图允许 **K 个全局假设** `G_A^(1..K)` 并存（多假设），每个带权重 w_k。

**定义 433（语义盲区与不确定度场）** 对节点/组件 C，定义不确定度场
`U(C) = w₁·tr(Σ_geo) + w₂·H(ℓ) + w₃·tr(Σ_rel) + w₄·stale + w₅·prov_unverified`（各项先归一化）。
语义盲区 `s = (C, d_s)` 满足以下任一：
(i) `U(C) > τ_U`；(ii) 时间窗内无有效回执；(iii) 节点间出现语义-几何冲突。
语义描述子 `d_s = (标签集合, 关系模式, 几何类别, 失败指纹)` 交给 L-Box；D-Box 的格子覆盖矩阵是它在 `φ` 下的特例。

**定义 434（provenance DAG 与 k-独立性）** 每条证据/地图元素 e 的 provenance 是一个 DAG
`π(e) = (N_e, A_e)`，叶子是有效回执、物理先验、闭环假设与 VLA 假设；根是主张或契约字段。
记 `U(π)` 为其中**未验证叶子**集合。对两条证据 `e_i, e_j`，定义依赖指数
`ρ_ij = Σ_{l∈U(π_i)∩U(π_j)} ω_l / sqrt(Σ_{l∈U(π_i)}ω_l · Σ_{l∈U(π_j)}ω_l) ∈ [0,1]`，
其中 `ω_l` 是未验证叶子的权重。`ρ_ij = 0` 称 **k-独立**；V 阶段的“独立交叉验证”只接受 k-独立回执。
`k` 表示最多允许共享的已验证公共祖先层数（默认 k=0，即不共享未验证叶子）。

**定义 435（多假设地图与一致性证书 MCC）** 对候选数据关联/闭环 z，定义环路残差 `r_cycle(z)` 与语义-回执一致度。
`MCC(z)` 成立当且仅当：① `r_cycle(z) ≤ ε_cycle`；② 语义标签与回执模式的一致度 ≥ 1−α_map；
③ 时间变化检测未发现“同一节点被移动/替换”；④ provenance 闭合。
不成立时**不得合并**：保留多个地图假设并按贝叶斯权重维护，直到新的独立证据将某一假设的后验权重压到阈值以下。
MCC 是地图层的“契约回归测试”。

**定义 436（已验证地图状态与事务更新）** 节点状态
`status_v ∈ {UNVERIFIED, PROBING, VERIFIED, STALE, STUB, RED}`。
地图更新是事务 `T = (pre, edit, post)`：pre 要求被触及节点全部 VERIFIED 或显式 PROBING；
post 要求 MCC 成立且 provenance 闭合；失败则原子回滚。
只有 VERIFIED 快照可以进入数值契约；PROBING 节点对控制器可见，但对数值层只读为“未知”。

**定义 437（认知不确定度被控对象）** 在节点/组件粒度上，状态
`x_t ∈ R_+^{|V|}` 为归一化不确定度，控制 `u_t ≥ 0` 为探测/热替换分配，扰动 `d_t` 为场景变化、传感器漂移与地图误差注入：
`x_{t+1} = A x_t − B u_t + E d_t + w_t`，
其中 `A = diag(a_v), a_v ≥ 1` 表示无探测时不确定度随陈旧增长；`B = diag(b_v), b_v ≥ b_min > 0` 表示探测的收缩能力；
`0 ≤ u_t ≤ u_max`，`‖d_t‖ ≤ D`，`w_t` 为零均值有界噪声。该式是真实非线性动态在运行点附近的**可审计线性化**；
实际系统只要求在 `CL-Cert` 标定的区域内满足单调性 `∂x_{t+1}/∂u_t ≤ −b_min I`。

**定义 438（CL-Box 事件触发闭环调节器）** 设定点 `r_t` 由定义 439 给出；误差 `e_t = x_t − r_t`。
控制器为
`u_t = Sat_{U_adm}( K_P e_t + K_I z_t + K_F r_t + u_ff )`，
`z_{t+1} = z_t + e_t Δt` 带 anti-windup（饱和时停止积分，`z_t` 夹紧在 `[−z_max, z_max]`）。
事件触发条件：`‖e_t‖_W ≥ δ_e` 或预测自由响应在 `H_c` 步内越过 `δ_p`；否则不分配新动作。
`safe_filter` 把候选动作投影到同时满足风险门 λ≥γ、增益注 β≥γ_B、PROBING 包络与 CBC 预算的集合。
`Sat` 是速率/累计预算/在飞请求上限的三重饱和。

**定义 439（风险标定设定点）** 任务风险预算 `ε_task` 按节点风险贡献分配到 `ε_v`（CVaR 或共形风险控制），
再由预注册校准集反解 `r_v`，使 `P(task_fail | U(v) ≤ r_v) ≤ ε_v`（可交换性下；漂移下按引理 48 修正）。
若不存在有限 `r_v` 满足预算，则标记该节点/任务 **infeasible**，控制器不得用“多做几次探测”伪装可达。

**定义 440（相关性感知的有效样本量）** 对节点/组件 g，观测误差协方差为 `σ² C_g`（`C_g` 单位对角），
标量后验方差为
`σ_post² = (σ_0^{-2} + σ^{-2}·1ᵀ C_g^{-1} 1)^{-1}`，
定义 **有效样本量** `n_eff(g) = 1ᵀ C_g^{-1} 1`。等相关 `C_g = (1−ρ)I + ρ11ᵀ` 时 `n_eff = n / (1 + (n−1)ρ)`。
`C_g` 由定义 434 的 `ρ_ij` 经收缩估计得到（保证正定）；原始样本数 n 不再进入任何样本复杂度结论。

**定义 441（地图-对象失配观测器 MPM）** 由被控对象模型预测 `ŷ_t`，残差 `ε_t = y_t − ŷ_t`。
对每个地图组件 c 定义结构化投影 `s_c(t) = P_c ε_t`（P_c 是该组件的故障签名投影），
用 e-process / CUSUM `M_t^c` 检测 `s_c` 的持续偏移：告警当 `M_t^c ≥ 1/δ`。
e-process 保证任意停止时刻的虚警率 ≤ δ；告警时输出嫌疑组件 `c* = argmax_c M_t^c` 与 provenance 嫌疑割集。
P-Quarantine 成为 MPM 在“只有一个全局组件”时的退化特例。

**定义 442（局部回滚）** 给定嫌疑组件 `c*`，计算 provenance 割集
`D(c*) = descendants(U(π_{c*}) \ Verified)`；只回滚 `D(c*)` 覆盖的契约与地图元素，其余保持 VERIFIED。
若存在备选地图假设 `G_A^(k)` 使残差显著更低，则切换到该假设；若无备选且回滚后仍告警，才对 `D(c*)` 执行 stub + RED。
局部回滚是“最小撤销”，避免第 2 轮 P-Quarantine 的一次误报停掉整机。

**定义 443（控制器证书 CL-Cert）** 证书
`CL-Cert = (A,B,E 的辨识区间, K_P,K_I,K_F, τ_d, u_max, δ_e, δ_p, V(·), D, γ_ISS, safety_margin)`。
有效条件：在标定区域 `Ω` 内存在 Lyapunov/ISS 函数 V 使
`V(x_{t+1}) ≤ (1−η)V(x_t) + γ_ISS‖d_t‖²`（`0<η<1`），且 `γ_ISS·D < safety_margin`；
延迟上界 `τ_d < τ_max`，事件触发最小间隔下界 > 0（Zeno-free）。
证书不含“全局稳定”的过度声明：只声明 `Ω` 内的区域稳定性与有界扰动下的 ISS。

**定义 444（闭环预算/执行器契约 CBC）** `CBC = (B_cum, rate_max, wear_max, τ_d, u_max, recovery)`：
在 TB-Contract 之上增加**时间索引**的累计预算、速率上限、磨损/热预算、执行器延迟上界与恢复条件。
`u_t` 同时受瞬时速率与累计预算约束；预算耗尽触发降级而不是排队赌博。
CBC 是定义 424 的时序细化，引理 45/50 的硬实时结论按原样继承。

**定义 445（语义迁移证书 STC）** 从源节点 v 向目标 v′ 迁移校准，当且仅当：
① 标签兼容 `D_KL(ℓ_v‖ℓ_v′) ≤ κ_sem`（或共形标签匹配）；② 几何兼容 `d_geo(v,v′) ≤ ε_geo`；
③ SNC 指纹匹配；④ provenance 不共享同一未验证叶子（`ρ_{vv′} = 0`）。
通过后迁移作为**伪观测**：均值取源后验，方差放大为 `σ²_src / w_tr + σ²_geo`，`0 < w_tr < 1`；
STC 迁移永远不计入 V 阶段的独立证据，也不能把 `n_eff` 提高到源节点以上。

**定义 446（AtlasGauge 退化链）** AtlasGauge 需要：所有 VERIFIED 节点 MCC 成立、CL-Cert 有效、
MPM 无持续告警、CBC 未耗尽。否则按以下顺序退化：
AtlasGauge ⇒ ToolGauge（冻结地图为扁平 D-Box、恢复一次性 6C 与全局 P-Quarantine）⇒ LeanGauge ⇒ MODGAUGE。
包含关系为 `AtlasGauge ⊃ ToolGauge ⊃ LeanGauge ⊃ MODGAUGE`；所有地图/控制层均在 50Hz 计量路径之外运行。

## 2. 关键算法骨架（要点；完整伪代码见产物区）

```python
# S → H → C → E → K → V → U（7C）
def atlas_7c(M, s):
    S = M.sbox.index(s)                                   # 语义索引：节点/关系/provenance
    H = M.lbox.hypothesize(S, M.sbox)                     # 共形假设（定义 422）
    prog = M.tbox.select(H, M.tools, M.tcv, M.budget(S))  # TCV + 双层闸门
    receipts = M.tcv.execute(prog, M.env)                 # PROBING 态，零副作用收尾
    if M.sbox.n_eff(S, receipts) < n_min(S):              # 定义 440：相关样本不算独立
        return M.sbox.stub_and_red(S, "correlated_or_insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, S)           # K：摊销校准
    if not M.apcal.cross_validate(mu, Sig, M.independent_receipt(S)):  # V：k-独立
        return M.sbox.stub_and_red(S, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, S)   # U：热替换
    if not contract_regression(new_ec): return M.sbox.stub_and_red(S, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.sbox.commit_verified(S, receipts, new_ec)           # 事务 + MCC
    return True
```

主循环把 `sbox.update`、`mpm.observe`、`clbox.plan` 全部异步化；50Hz 路径只保留 MODGAUGE 原逻辑与
O(1) 摊销的残差/回执哈希，不因地图或控制器增加周期抖动。

## 3. 推导（引理 51–56）

**引理 51（语义地图的验证可靠性）** 若每个 VERIFIED 节点的数值字段只来自有效回执或 STC 迁移，
MCC 的假接受率 ≤ α_map，共形假设覆盖为 1−α_h，STC 误迁移率 ≤ α_tr，
则任一契约主张为假的概率 ≤ α_map + α_h + α_tr + Σ_i α_receipt,i。
证明：对 provenance DAG 做结构归纳；每个数值字段的推导要么终止于有效回执（假概率 ≤ α_receipt），
要么经过一次 MCC/共形/STC 门（各贡献一次 union bound）。系：假闭环不能直接产生数值主张，
除非同时通过 MCC 与下游 V；多假设地图保证备选不被静默删除。

**引理 52（闭环收敛与 ISS）** 在定义 437 的单调被控对象上，若 `A ⪰ I`、`B ⪰ b_min I`、
`‖d_t‖ ≤ D`，且 CL-Cert 在区域 Ω 内给出 `V(x_{t+1}) ≤ (1−η)V(x_t) + γ_ISS‖d_t‖²`，
则 `‖x_t − r‖ ≤ β^t‖x_0 − r‖ + (γ_ISS/η)·D`（β = √(1−η)）；
若事件触发阈值 δ_e > 0 且执行器延迟 `τ_d < τ_max`，则触发间隔有正下界，闭环不产生 Zeno 行为。
证明：标准离散 ISS/Lyapunov 递推；事件触发的最小间隔由 `δ_e/(L_u u_max + L_d D)` 给出；
饱和由 anti-windup 保证不破坏 Lyapunov 下降；安全过滤器保证风险门是硬约束，收敛不以安全为代价。

**引理 53（相关性感知的样本复杂度）** 在定义 440 的高斯观测下，要把后验标准差压到 ε，需
`n_eff ≥ σ²(ε^{-2} − σ_0^{-2})`，且必须 `ε² < σ_0²`。
等相关情形 `n_eff = n/(1+(n−1)ρ)`，因此达到 `n_eff = m*` 所需的原始样本数为
`n = m*(1−ρ)/(1−m*ρ)`，仅当 `m*ρ < 1` 时可行。
系：当 `ρ ≥ 1/m*` 时，**无论再采多少同源样本都无法达到目标**；必须换工具/传感器/地图分支来打破相关性。
这正式解释了第 2 轮“摊销先验污染”为何不能靠“多修几次”解决。

**引理 54（MPM 的虚警与定位）** 在零假设下，e-process 满足 `P(∃t: M_t^c ≥ 1/δ) ≤ δ`（anytime 有效）。
单组件故障且各组件故障签名满足分离裕度 `κ_c` 时，期望检测延迟
`E[τ] ≤ log(1/δ)/KL(P_1‖P_0) + O(1)`，且定位到最小 provenance 割集的概率 ≥ 1−δ。
多组件故障时若签名不可分，输出“歧义”并触发定义 442 的保守回滚，而不是强行归因。
证明：e-process 的 Ville 不等式给虚警；CUSUM/e-process 的标准检测延迟界给延迟；
签名投影的分离裕度给定位。系：P-Quarantine 是本引理在单组件、二值残差下的特例。

**引理 55（语义迁移的安全性）** 若 STC 成立，则迁移后验相对目标真值的误差满足
`err(v′) ≤ err(v) + 2η_tr + δ_sem + δ_geo`，其中 η_tr 为源/目标分布 TV，δ_sem/δ_geo 为标签/几何失配项；
且迁移观测的方差按 `1/w_tr` 放大、provenance 共享源叶子，故 `n_eff` 不增加。
系：迁移可以加速冷启动，但不能把“语义相似”冒充为“独立验证”；V 阶段若只收到迁移证据，必须拒绝热替换。

**引理 56（退化与等价保持）** 在定义 447 的退化参数下 AtlasGauge ≡ ToolGauge；
AtlasGauge 的任何失效条件都按定义 446 触发降级，且地图/控制层不进入数值通道。
因此 MODGAUGE 五不变式、引理 44 的热替换等价性、引理 45/50 的硬实时与预算结论全部保持。
证明：按构造逐项检查；地图只改“索引/调度”，控制器只改“动作分配”，二者都不直接写契约字段；
V/U 门与第 2 轮完全相同；降级路径是 ToolGauge 的已验证运行模式。

**定义 438（CL-Box）** `u_t=Sat_{U_adm}(K_P e_t+K_I z_t+K_F r_t+u_ff)`，`z` 带 anti-windup；
事件触发 `‖e_t‖_W≥δ_e` 或预测越界；`safe_filter` 投影到 λ/β/PROBING/CBC 的可行集；三重饱和含在飞请求上限。
**定义 439（风险标定设定点）** `ε_task` 按 CVaR/共形风险控制分配到 `ε_v`，反解 `r_v` 使
`P(task_fail|U(v)≤r_v)≤ε_v`；不存在有限解则标 infeasible，禁止用多探测伪装可达。
**定义 440（有效样本量）** `σ_post²=(σ_0^{-2}+σ^{-2}1ᵀC_g^{-1}1)^{-1}`，`n_eff=1ᵀC_g^{-1}1`；
等相关时 `n_eff=n/(1+(n−1)ρ)`；`C_g` 由 `ρ_ij` 收缩估计并保证正定。
**定义 441（MPM）** 残差 `ε_t=y_t−ŷ_t`；组件签名投影 `s_c=P_c ε_t`；e-process/CUSUM 告警 `M_t^c≥1/δ`；
anytime 虚警 ≤δ；输出 `c*=argmax_c M_t^c` 与 provenance 嫌疑割集；P-Quarantine 为单组件特例。
**定义 442（局部回滚）** `D(c*)=descendants(U(π_{c*})\Verified)`；只回滚 `D(c*)` 覆盖的契约/地图元素；
有更低残差备选假设则切换，否则才对 `D(c*)` stub+RED。
**定义 443（CL-Cert）** 记录模型区间、增益、延迟 `τ_d`、饱和 `u_max`、触发阈值、V(·)、扰动界 D、ISS 增益、安全裕度；
有效条件为标定区域 Ω 内 `V(x_{t+1})≤(1−η)V(x_t)+γ_ISS‖d_t‖²` 且 `γ_ISS D<safety_margin`，`τ_d<τ_max`，触发间隔有正下界。
**定义 444（CBC）** 在 TB-Contract 上增加时间索引累计预算、速率、磨损/热预算、延迟上界与恢复条件；
预算耗尽即降级，不排队赌博。
**定义 445（STC）** 标签兼容 + 几何兼容 + SNC 指纹 + `ρ=0` 四条件；迁移为伪观测，方差放大 `1/w_tr`，
`0<w_tr<1`；不计入 V 独立证据，不提高 `n_eff`。
**定义 446（退化链）** AtlasGauge ⇒ ToolGauge ⇒ LeanGauge ⇒ MODGAUGE；
包含关系 `AtlasGauge ⊃ ToolGauge ⊃ LeanGauge ⊃ MODGAUGE`；地图/控制层在 50Hz 计量路径之外。
**定义 447（等价）** 扁平地图 + 单次贪心 + `w_tr=0` + MCC 恒真 ⇒ AtlasGauge ≡ ToolGauge；定义 398–431 全部沿用。

# ============================================================
# IP-321 S-Box：语义地图、provenance、语义盲区
# ============================================================
@dataclass
class AtlasNode:
    id: str
    geom: Gaussian3D                 # SE(3) 位姿/区域 + 协方差
    label: Categorical               # ℓ_v ∈ Δ(𝒞)
    rels: dict                       # edge_id -> (relative_pose, cov, predicate)
    epi: EpiState                    # sigma_geo, H(label), sigma_rel, stale
    prov: ProvenanceDAG
    status: str                      # UNVERIFIED/PROBING/VERIFIED/STALE/STUB/RED
    version: int

class SBox:
    def __init__(self, hypotheses, alpha_map, tau_u):
        self.hypotheses = hypotheses          # 多假设 G_A^(1..K), weights
        self.alpha_map, self.tau_u = alpha_map, tau_u
        self.txn_log = []

    def update(self, obs, det, receipts):
        # 1) 多假设数据关联：不立即合并，先保留 K 个候选
        candidates = self.associate(obs, det, self.hypotheses)
        candidates = [a for a in candidates if self.mcc(a) or self.keep_alternative(a)]
        # 2) 事务式提交：失败原子回滚
        for a in candidates:
            self.apply_transaction(a)
        return self.semantic_blind_spots()

    def semantic_blind_spots(self):
        out = []
        for comp in connected_components(self.active_atlas()):
            if (self.U(comp) > self.tau_u
                    or not self.has_recent_valid_receipt(comp)
                    or self.semantic_geometric_conflict(comp)):
                out.append((comp, self.descriptor(comp)))
        return out

    def U(self, comp):
        return (W1 * trace_geo(comp) + W2 * entropy(label(comp))
                + W3 * trace_rel(comp) + W4 * staleness(comp)
                + W5 * prov_unverified_mass(comp))

    def mcc(self, assoc):
        return (cycle_residual(assoc) <= EPS_CYCLE
                and semantic_receipt_agreement(assoc) >= 1 - self.alpha_map
                and temporal_change_test(assoc)
                and provenance_closed(assoc))

    def n_eff(self, comp, receipts):
        C = correlation_matrix([r.prov for r in receipts], self.prov_graph)
        C = shrink_to_pd(C)          # 收缩估计，保证正定
        return float(ones @ inv(C) @ ones)

    def commit_verified(self, comp, receipts, new_ec):
        with self.transaction(pre=[comp], post=lambda: self.mcc(comp)):
            self.attach_provenance(comp, receipts)
            self.set_status(comp, "VERIFIED")
            self.bind_contract(comp, new_ec)

    def stub_and_red(self, comp, reason):
        with self.transaction(pre=[comp], post=lambda: True):
            self.set_status(comp, "STUB")
            self.emit_red(comp, reason)
        return False

# ============================================================
# IP-322 MCC / STC：地图一致性 + 语义迁移证书
# ============================================================
def transfer_certificate(src, dst, atlas, snc_lib):
    if kl(atlas[src].label, atlas[dst].label) > KAPPA_SEM:       return None
    if mahalanobis_geom(atlas[src], atlas[dst]) > EPS_GEO:       return None
    if not snc_match(atlas[src], atlas[dst], snc_lib):           return None
    if provenance_overlap(atlas[src].prov, atlas[dst].prov) > 0: return None
    return STC(src, dst, w=W_TRANSFER,
               sigma2=atlas[src].epi.sigma2 / W_TRANSFER + SIGMA_GEO2)

# ============================================================
# IP-323 CL-Box：风险设定点 + 事件触发闭环
# ============================================================
class CLBox:
    def __init__(self, Kp, Ki, Kf, cert, cbc, tools):
        self.Kp, self.Ki, self.Kf = Kp, Ki, Kf
        self.cert, self.cbc, self.tools = cert, cbc, tools
        self.z = zeros(n_nodes)
        self.inflight = set()

    def setpoint(self, atlas, task):
        eps_v = allocate_risk(task.eps, atlas, method="cvar_conformal")
        r = {}
        for v in atlas.nodes:
            r[v] = inverse_conformal_quantile(v, eps_v[v])   # 不可达 -> inf
            if not isfinite(r[v]):
                atlas.mark_infeasible(v)
        return r

    def event_trigger(self, e, x_hat):
        free_response = self.cert.predict_free(x_hat, self.Hc)
        return norm_W(e) >= self.cert.delta_e or norm(free_response - self.r) >= self.cert.delta_p

    def anti_windup(self, u_raw, budget):
        u = clip(u_raw, 0, budget.rate_left)
        if not np.allclose(u, u_raw):
            # 条件积分：饱和时冻结积分项，避免 windup
            self.z = self.z_prev
        return u

    def step(self, x_hat, r, budget, dt):
        self.z_prev = self.z.copy()
        e = x_hat - r
        self.z = clip(self.z + e * dt, -self.cert.z_max, self.cert.z_max)
        u = self.Kp @ e + self.Ki @ self.z + self.Kf @ r + self.uff
        u = self.anti_windup(u, budget)
        if not self.event_trigger(e, x_hat):
            return []
        u = safe_filter(u, self.tools, self.probing_envelope)   # λ/β/PROBING
        u = saturate(u, budget.rate_left)
        return allocate(u, atlas)

# ============================================================
# IP-324 MPM：结构化残差 + 局部回滚
# ============================================================
class MPM:
    def __init__(self, plant, atlas, delta):
        self.plant, self.atlas, self.delta = plant, atlas, delta
        self.eproc = defaultdict(EProcess)

    def observe(self, y, control):
        y_hat = self.plant.predict(control)
        eps = y - y_hat
        for c in self.atlas.components:
            self.eproc[c].update(dot(self.atlas.signature[c], eps))
            if self.eproc[c].stat >= 1.0 / self.delta:
                self.localize_and_rollback(c)

    def localize_and_rollback(self, c_star):
        cut = self.atlas.provenance_cut(c_star)          # descendants of unverified leaves
        self.atlas.rollback(cut)                         # 只撤销受影响子图
        alt = self.atlas.best_alternative(c_star)
        if alt is not None and self.residual(alt) < self.residual(c_star):
            self.atlas.switch_hypothesis(alt)
        elif self.still_alarming(c_star):
            self.atlas.stub_and_red(cut, "persistent_mismatch")

# ============================================================
# IP-325 Atlas-7C：S→H→C→E→K→V→U
# ============================================================
def atlas_7c(M, s):
    S = M.sbox.index(s)                                    # S：语义索引 + provenance
    H = M.lbox.hypothesize(S, M.sbox)                      # H：共形假设（定义 422）
    prog = M.tbox.select(H, M.tools, M.tcv, M.cbc.left(S)) # C：TCV + 双层闸门
    receipts = M.tcv.execute(prog, M.env)                  # E：PROBING，零副作用收尾
    if M.sbox.n_eff(S.comp, receipts) < n_min(S):          # 定义 440 / 引理 53
        return M.sbox.stub_and_red(S.comp, "correlated_or_insufficient")
    mu, Sig = M.apcal.calibrate(receipts, H, S)            # K：摊销后验 + 夹紧
    r_ind = M.independent_receipt(S)                       # V：只接受 ρ=0
    if r_ind is None or not M.apcal.cross_validate(mu, Sig, r_ind):
        return M.sbox.stub_and_red(S.comp, "no_independent_cross_check")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, S)    # U：热替换
    if not contract_regression(new_ec):
        return M.sbox.stub_and_red(S.comp, "regression_failed")
    M.mreg.hot_replace(M.dpe, new_ec)
    M.sbox.commit_verified(S.comp, receipts, new_ec)       # 事务 + MCC
    M.mpm.record_expected(S.comp, predicted_gain(receipts))
    return True

# IP-326 主闭环：50Hz 路径不动，地图/控制全异步
# ============================================================
def AtlasGauge_round(M, obs, audio, tac, depth, det):
    # 监管层（异步）：地图更新 + MPM + 控制器
    M.sbox.update_async(obs, det, M.receipt_buffer)
    M.mpm.observe_async(M.coverage_stats(), M.last_control)
    if M.mpm.alarm():
        M.mpm.localize_and_rollback(M.mpm.suspect)
    targets = M.sbox.semantic_blind_spots()
    M.clbox.plan_and_dispatch(targets, M.cbc)       # 事件触发，预算/速率/在飞上限
    # 失效检测：任何一条不满足即显式退化
    if (not M.sbox.mcc_all() or not M.clbox.cert_valid()
            or M.cbc.exhausted() or M.mpm.persistent_alarm()):
        return ToolGauge_fallback(M)                # 扁平 D-Box + 一次性 6C
    return MODGAUGE_round(M, obs, audio, tac, depth, det)

## 4. 推导（引理 51–56）

**引理 51（语义地图的验证可靠性）** 若每个 VERIFIED 节点的数值字段只来自有效回执或 STC 迁移，
MCC 假接受率 ≤ α_map，共形假设覆盖 1−α_h，STC 误迁移率 ≤ α_tr，则任一契约主张为假的概率
≤ α_map + α_h + α_tr + Σ_i α_receipt,i。
证明：对 provenance DAG 结构归纳；每条数值字段路径要么终止于有效回执，要么经过一次 MCC/共形/STC 门；
每道门贡献一次 union bound。系：假闭环不能直接产生数值主张，除非同时通过 MCC 与下游 V；
多假设地图保证备选不被静默删除。

**引理 52（闭环收敛与 ISS）** 在定义 437 的单调对象上，若 `A⪰I`、`B⪰b_min I`、`‖d_t‖≤D`，
且 CL-Cert 在区域 Ω 内满足 `V(x_{t+1})≤(1−η)V(x_t)+γ_ISS‖d_t‖²`，则
`‖x_t−r‖ ≤ β^t‖x_0−r‖ + (γ_ISS/η)D`（`β=√(1−η)`）；
若 `δ_e>0` 且 `τ_d<τ_max`，触发间隔有正下界，闭环无 Zeno 行为。
证明：离散 ISS/Lyapunov 递推；事件触发最小间隔由 `δ_e/(L_u u_max+L_d D)` 给出；
anti-windup 在饱和时停止积分，保持 Lyapunov 下降；安全过滤器把 λ/β/PROBING/CBC 作为硬约束，
因此收敛不以安全或预算为代价。

**引理 53（相关性感知样本复杂度，替代定义 426）** 在定义 440 的高斯观测下，要把后验标准差压到 ε 需
`n_eff ≥ σ²(ε^{-2}−σ_0^{-2})`，且必须 `ε²<σ_0²`。
等相关 `n_eff=n/(1+(n−1)ρ)`，达到 `n_eff=m*` 需 `n=m*(1−ρ)/(1−m*ρ)`，仅当 `m*ρ<1` 可行。
系：`ρ≥1/m*` 时，无论再采多少同源样本都不可达；必须换工具/传感器/地图分支打破相关性。
这把第 2 轮“摊销先验污染不能靠多修几次解决”的直觉变成了可计算的判据。

**引理 54（MPM 虚警与定位）** 零假设下 e-process 满足 `P(∃t: M_t^c≥1/δ)≤δ`（anytime 有效）；
单组件故障且签名分离裕度 `κ_c` 时，期望检测延迟 `E[τ]≤log(1/δ)/KL(P_1‖P_0)+O(1)`，
定位到最小 provenance 割集的概率 ≥1−δ；多组件签名不可分时输出“歧义”并保守回滚。
证明：Ville 不等式给虚警；CUSUM/e-process 标准延迟界给检测；签名投影的分离裕度给定位。
系：P-Quarantine 是本引理在单组件、二值残差下的特例。

**引理 55（语义迁移安全性）** 若 STC 成立，则迁移后验误差
`err(v′) ≤ err(v)+2η_tr+δ_sem+δ_geo`（η_tr 为源/目标 TV，δ_sem/δ_geo 为标签/几何失配）；
迁移观测方差按 `1/w_tr` 放大且 provenance 共享源叶子，故 `n_eff` 不增加。
系：迁移可加速冷启动，但不能把“语义相似”冒充为“独立验证”；V 阶段只有迁移证据时必须拒绝热替换。

**引理 56（退化与等价保持）** 在定义 447 的退化参数下 AtlasGauge ≡ ToolGauge；
任何 AtlasGauge 失效条件按定义 446 触发降级，且地图/控制层不进入数值通道。
因此 MODGAUGE 五不变式、引理 44 的热替换等价性、引理 45/50 的硬实时与预算结论全部保持。
证明：按构造逐项检查；地图只改索引/调度，控制器只改动作分配；V/U 门与第 2 轮完全相同；
降级路径是 ToolGauge 的已验证运行模式。

  6. V 的“独立回执”未验证独立性 → provenance DAG 与 k-独立性；
  7. 单次预算缺累计磨损/速率/延迟 → CBC；
  8. 50Hz 回执验证成本低估 → 批量哈希 + 异步抽检；
  9. 共形 SLA 魔数 → 风险标定设定点；
  10. 地图（新增）假闭环风险 → 多假设 + MCC + 事务 + 局部回滚。
- **新增**：S-Box 语境化盲区（432–436）、CL-Box 闭环调节（437–440、443–444）、
  MPM 局部故障处理（441–442）、STC 迁移安全（445）、Map–Control 对偶（§0 合流）。

## 8. 本轮最大风险（一句话）

**次级风险与缓解**：
1. **地图过度自信** → 多假设 + MCC + provenance 独立性 + 局部回滚；
2. **控制器把错误地图稳定住** → MPM 独立于控制器、结构化残差、CL-Cert 只在标定区域有效；
3. **探测频率/磨损上升** → CBC 速率/磨损硬约束 + 事件触发 + 死区；
4. **相关性饱和导致目标不可达** → 引理 53 显式告警，切换依赖打破探测或提升为 infeasible；
5. **语义迁移污染** → STC 四条件 + `w_tr<1` + V 阶段不把迁移当独立证据；
6. **地图/控制层拖慢实时路径** → 全部异步，50Hz 只保留摊销 O(1) 残差与回执哈希（引理 56）。

**一句话**：本轮最大风险是「语义地图的错误数据关联（假闭环/感知别名）把本应相关的不确定性伪装成独立证据，使闭环控制器在错误地图上稳定收敛到假目标」——控制器越稳，这个错误越难被残差发现，因此必须用多假设地图、provenance 独立性与结构化残差把它变成可检测、可局部回滚的故障。
