# 第 4 轮（灵感驱动研究循环·新灵感二元组第 1 轮；本轮灵感：「多语言支持」×「轻量化结构」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21+IP-425–430（v21 语义-合规层：SDC/CAC/DCL/GIC/HPC+/CFC+，其上承 v20 联邦感知证书与 v19/v17 模块）。
> 本轮纪律：**「语言」首先是本体与规则方言的互操作，其次才是人类自然语言；「轻量」首先是证明生成与证明核验的结构分离，而不是降低安全**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 全部保留。本轮只做一件事：**在 v21 的语义-规范层之外再加一层「可互译、可轻验」的证书互操作骨架，把单机可审计证书升级为跨厂商/跨本体/跨人类语言都可消费的联邦证书，并把「翻译只能变保守」「验证只能漏拒、不能误收」做成两条硬约束**。

## 0. 直觉与动机

**灵感 1（多语言支持 → 证书的语义互操作，而不是无损翻译）**
直觉：v21 的所有证书都隐含一个假设——全队共享同一本体（谁是人、什么是杯子）、同一套规则方言（`yield` 与 `cede` 同义）、同一种人类语言。异构队列里这个假设立刻破产：A 厂检测器说 "cup"，B 厂说 "cylindrical obstacle"，C 厂把人分成 "adult/child"；同一句「让一下」在三种语言里对应三个意图槽。朴素做法是接一个翻译器，但**证书翻译一旦被当成无损编解码就会制造假自由空间**：把 "child" 翻成 "person" 是安全的（障碍变粗），把 "obstacle" 翻成 "cup" 是致命的（障碍变细、禁区变可通行）。所以多语言支持的正确问题不是「如何译得准」，而是「如何译得**只能更保守**」。核心创新：**语义互译证书 (Semantic Translation Certificate, STC)**——每个本地标签映射到公共核心本体 C 的一个含义区间 `[lo, hi]` 与保真度 η；**加宽语境（障碍/禁止）取上界 hi，收窄语境（许可/解锁）只有当区间塌缩为单类且高保真时才放行，未知/低保真一律映射到 ⊤（最严）**。关键反直觉点：**互操作的目标不是让所有机器人说同一种话，而是让「听不懂」必然表现为更多限制、而不是更少限制**。用公共核心 C 做星型枢纽而非两两翻译，避免 O(n²) 与不可传递的语义漂移。人类自然语言（语音/手势）是同一问题的实例：多语言意图槽 → 核心意图槽，配每语言 conformal 校准与同样的非对称门槛。

**灵感 2（轻量化结构 → 重证明、轻验证）**
直觉：v21 的证书体系已经很重——merkle、conformal、覆盖图、义务编译、三证组装，却要求在 50Hz 控制环里被反复消费。轻量化不是删证明（删了就没安全），而是**结构分离**：把「生成证明」（重、可离线、可来自不可信方）与「核验证明」（轻、在线、可信）拆开。证书不必廉价地产生，只需廉价地被检查。核心创新：**轻量证书信封 (Lightweight Certificate Envelope, LCE)**——对每条规则离线预计算一个**激活包络**（保守的特征盒，盒外必不触发），在线只用区间树查询「当前快照会激活哪一小撮规则」，其余规则由包络**可证地排除**；再配合 Merkle Mountain Range 的稀疏见证与**增量证书差量 (Incremental Certificate Delta, ICD)** 只传变化的叶子。关键反直觉点：**近似必须单向**——在线路径可以多查（把不活跃规则也当活跃，只是多花时间），但绝不能少查（漏掉一条真活跃规则就是安全漏洞）；所以「轻」来自可证的排除，而不是概率性抽样。这套「包络 + 稀疏见证 + 防回滚差量」恰好也是互译层最需要的载体：翻译表同样离线预计算、在线 O(log n) 查询、哈希钉住。

**两者如何统一**
统一为 **v21 之上的「证书互操作层」**：STC 回答「对方的话在我这里是什么意思、能信到什么程度」，LCE/ICD 回答「我如何用最小代价、可防篡改地核验这份意思」，CLIG 回答「人用哪种语言表达的意图如何落到核心槽位」，SQ+ 回答「跨本体的票何时才算数」，ODM 回答「意思有没有在悄悄漂移」。共享状态扩展为 **ζ_interop = ζ_sem ∪ (C_snapshot, STC_set, envelope, drift_state)**。统一准入门升级为 **HPC++ = (HPC+, STC*, LCE, DriftState)**：几何 SAFE ∧ 规范允许 ∧ 负信息可靠 ∧ **语义可互译且未漂移**，任一缺失退回 v21 的保守收缩。CFC+ 升级为 **SQ+（模态 ≥2 ∧ 本体谱系 ≥2 ∧ 翻译保真达标）**，把 v21 封堵的「单模态相关误判」再扩展为封堵「同词异义的相关误判」。

## 1. 研究问题（轮次升级版）

- **Q1（互译的保守性）**：如何从双语/多本体标注中估计含义区间 `[lo,hi]` 与保真度 η，使 `⟦lo⟧ ⊆ ⟦ℓ⟧ ⊆ ⟦hi⟧` 在统计意义下成立？区间抽象在长尾标签上退化为 ⊤ 时，活性会被压到多低？星型核心 C 的版本不一致、扩展画像冲突时如何 fail-closed？两两翻译与星型枢纽的误差如何对比？

- **Q2（轻量验证的单向性）**：如何从规则谓词自动构造可靠的激活包络（区间抽象 vs 抽象解释），并证明「包络外必不触发」？包络过宽使前沿膨胀、过窄会误排除，如何把「宁可多查、绝不漏查」写成可机械检查的单向性条件？MMR/增量差量如何同时做到防回滚、防跨快照拼接、防对等体间 equivocation？在线核验如何守住 p99 ≤2ms？

- **Q3（跨语言意图）**：每语言 conformal 校准在低资源语言、方言、口音下如何维持 1-α 覆盖？池化兜底的 slack ε_pool 如何界定？跨语言「停/走」混淆与语言切换攻击如何防？模型蒸馏/量化到边缘设备后，conformal 覆盖是否仍成立、需要何种重校准？

- **Q4（语义仲裁与漂移）**：如何定义「本体谱系独立性」，使同词异义无法凑成共识、而真正独立的跨本体证据仍能达成 SAFE？语义漂移（新物体、新术语、季节/衣着变化）如何在线的、低误报地被发现并降级到 ⊤？语义多样性门槛与 v21 的模态多样性、任务活性如何联合调参？

## 2. 设计原则（在 P34–P36 基础上新增 P37–P39）

**P37 保守互译律（Conservative Translation）**
对任意本地标签 ℓ，其互译证书给出区间 `[lo, hi]` 满足 `⟦lo⟧ ⊆ ⟦ℓ⟧ ⊆ ⟦hi⟧`。**加宽语境**（障碍、禁止、未知）取 `hi`，保证目标侧障碍 ⊇ 源侧、禁止域 ⊇ 源侧；**收窄语境**（许可、解锁）仅当 `lo = hi` 且 `η ≥ η_hi` 时取该唯一类，否则拒绝提权。未知/低保真标签一律映射到核心顶元 ⊤（障碍取全域、许可取空集）。**任何翻译路径都不得扩大许可集合**；所有对等体原生实现核心 C，避免两两翻译的不可传递漂移。

**P38 重证明-轻验证律（Prove-Heavy, Verify-Light）**
证书生成可重、可离线、可来自不可信方；在线核验必须 `O(|A_t| + log|R|)`（A_t 为激活前沿，R 为规则集）。一切近似**单向**：在线路径允许把不活跃规则误当活跃（只多花时间、可拒绝有效证书），但绝不允许把活跃规则排除在核验之外。被省略的内容全部以哈希承诺绑定快照、本体、规则版本；核验通过 ⇒ 活跃核心已被完整核验，否则拒绝。增量差量必须绑定基根与单调序号，禁止回滚与跨快照拼接。

**P39 语义多样性仲裁律（Semantic-Diversity Quorum）**
SAFE 共识需要**三重多样性**：证据模态 ≥2（v21 CFC+）、**已校验本体谱系 ≥2**、以及每条票的翻译保真 ≥η_min。同词异义而未经保真校验的别名票计零票；同义冲突映射在障碍/禁止方向折到 ⊤（最严），在许可方向直接拒绝。翻译保真不是事后审计，而是投票权重的一等约束。

## 3. 与基线的接口（如何退化）

- STC 缺失/核心版本失配 ⇒ 外部标签一律按 ⊤ 消费（障碍取全域、许可全拒）⇒ 比 v21 更保守，子集成立；
- LCE 核验失败/索引损坏 ⇒ 退回离线全量证书核验并暂停新许可（hold），不进入执行；
- ICD 基根或序号失配 ⇒ 拒绝差量、请求全量快照，期间不新增许可；
- CLIG 遇到不支持语言/低资源语言 ⇒ 不得提权，义务仍按低门槛 fail-safe 施加（可能误触发，只损失活性）；
- SQ+ 无法满足本体谱系多样性 ⇒ 仲裁落 CI ⇒ 退回 v21 CFC+ 行为；
- ODM 告警（η 跌破或未知率超限）⇒ 受影响标签降级到 ⊤、撤销依赖它们的许可，重校准离线进行；
- 互操作层整体失效 ⇒ 完全回退 v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 169）。
- **安全继承**：STC 只加宽障碍/禁止、只收缩许可；LCE 只做可证排除与哈希绑定；ICD 只接受正确基根的增量；CLIG 保持非对称门槛；SQ+ 只加约束。任意失效都向更保守方向退化。

## 4. 预期贡献

1. **保守互译证书**：首次把跨本体/跨厂商的标签互操作形式化为含义区间的单向安全嵌入，给出「翻译只能变保守」的可审计证书与保真度标定；
2. **重证明-轻验证结构**：以激活包络 + 区间树 + MMR 稀疏见证 + 防回滚增量差量，把在线证书核验从 O(|R|) 降到 O(|A_t| + log|R|)，并给出单向性的可机械检查条件；
3. **跨语言意图落地**：多语言意图槽 → 核心槽位，每语言 conformal 校准 + 池化 slack，配 v21 的非对称门槛，使「停/走」混淆的假许可概率有显式上界；
4. **语义多样性共识**：把 CFC+ 的模态多样性扩展为本体谱系多样性，结构性封堵「同词异义」的相关误判；
5. **语义漂移治理**：ODM 在线监控保真度与未知率，漂移时降级到 ⊤ 并撤销依赖许可，把最大的语义风险显式化；
6. **HPC++ 四证一体**：HPC+ ∪ STC* ∪ LCE ∪ Drift，`Exec_v22 ⊆ Exec_v21` 闭环，跨异构队列可互操作。

## 5. 本轮最大风险

**一句话**：STC 的保守翻译与 LCE 的轻量核验各自都「形式正确」，但二者复合起来只证明了**语法/承诺层的一致**、没有证明**指称层的一致**——两个机器人可以对同一个词 "clear" 都通过合规证书，却指的是不同区域或不同类别，于是机器人在双方都合规、审计也通过的证书下协同撞人，即**「轻量互译的语义幻觉」**。

## 1. 关键算法骨架

```python
# IP-431 Semantic Translation Certificate
class SemanticTranslationCertificate:
    """把本地本体标签保守地嵌入公共核心 C；任何翻译都不得扩大许可集合。"""

    def __init__(self, core, registry, eta_widen=0.60, eta_narrow=0.95):
        self.core = core                  # 公共核心本体 C（所有对等体原生实现）
        self.registry = registry          # 校准得到的区间 [lo,hi] + 保真度 η + calib_hash
        self.eta_widen, self.eta_narrow = eta_widen, eta_narrow

    def to_core(self, onto, label, ctx):
        """ctx=WIDEN（障碍/禁止）取上界；ctx=NARROW（许可）须区间塌缩且高保真。"""
        rec = self.registry.lookup(onto, label)
        if rec is None or rec.eta < self.eta_widen or not rec.version_matches(self.core):
            return self.core.TOP                  # 未知/低保真/版本失配 → 最严 ⊤
        if ctx == "WIDEN":
            return rec.hi                         # 上界：目标障碍 ⊇ 源障碍
        if rec.lo == rec.hi and rec.eta >= self.eta_narrow:
            return rec.lo                         # 唯一类且高保真：许可可提权
        return None                               # 拒绝提权（不放行，但不误停）

    def conservative(self):
        """可机械检查：区间包含 + 版本一致 + 保真度单调。"""
        return all(
            self.core.refines(r.lo, r.label) and self.core.refines(r.label, r.hi)
            and r.eta >= self.eta_widen and r.version_matches(self.core)
            for r in self.registry
        )


# IP-432 Lightweight Certificate Envelope
class ActivationEnvelope:
    """规则 r 的保守激活包络：由谓词经区间抽象/抽象解释离线导出。
    单调性：φ ∉ box_r ⇒ Pre_r(φ) = false（可证不触发）。"""

    def __init__(self, rule_id, box, predicate_hash):
        self.rule_id = rule_id
        self.box = box                    # 特征空间中的闭盒（保守外包）
        self.predicate_hash = predicate_hash

    def excludes(self, phi):
        return not self.box.contains(phi)


class LightweightCertificateEnvelope:
    def __init__(self, trusted_registry, index, hash_fn):
        self.registry = trusted_registry  # 已签名的包络集（注册表哈希钉住）
        self.index = index                # R-tree/区间树：φ → 候选规则（返回超集）
        self.h = hash_fn

    def build(self, full_cert, snapshot):
        leaves = [self.h(commit(env)) for env in self.registry.envelopes]
        mmr = MMR(leaves)                                # 离线/重生成
        candidates = self.index.query(snapshot.phi)       # 超集查询，O(log|R| + |A_t|)
        active = [r for r in candidates if not r.envelope.excludes(snapshot.phi)]
        return CertificateEnvelope(
            seq=full_cert.seq,
            snapshot_hash=self.h(snapshot),
            ontology_id=full_cert.ontology_id,
            mmr_root=mmr.root,
            active_frontier=active,
            witness=SparseWitness([full_cert.full(r.id) for r in active],
                                  mmr.paths([r.id for r in active])))

    def verify(self, env, snapshot, approved_roots):
        # 1) 绑定：快照/本体/规则版本任一失配 → fail-closed
        if env.snapshot_hash != self.h(snapshot):
            return False
        # 2) 本地可信索引重算前沿：只允许包络排除，绝不按概率/启发式排除
        frontier = [r for r in self.index.query(snapshot.phi)
                    if not r.envelope.excludes(snapshot.phi)]
        # 3) 前沿必须是见证的子集（少一条活跃规则 = 安全漏洞，直接拒绝）
        if not env.witness.covers(frontier):
            return False
        # 4) 仅对前沿做完整核验；其余规则已被包络可证排除
        if not all(verify_full(c, snapshot) for c in env.witness.core):
            return False
        # 5) 稀疏见证必须落在已批准（签名/先前全量核验）的承诺根上
        return env.mmr_root in approved_roots


# IP-433 Incremental Certificate Delta
class IncrementalCertificateDelta:
    def __init__(self, mmr, anti_rollback):
        self.mmr = mmr
        self.seq = anti_rollback          # 单调序号 + 基根链

    def diff(self, prev_env, next_env):
        changed = [(i, leaf) for i, leaf in enumerate(next_env.leaves)
                   if leaf != prev_env.leaves[i]]
        return Delta(base_root=prev_env.mmr_root, seq=prev_env.seq + 1,
                     changed=changed, new_root=next_env.mmr_root,
                     multiproof=self.mmr.multiproof([i for i, _ in changed]))

    def apply(self, env, delta):
        # 基根与序号必须严格衔接：既防回滚到旧的宽松证书，也防跨快照拼接
        if delta.base_root != env.mmr_root or delta.seq != env.seq + 1:
            return None
        root = self.mmr.apply_and_check(env.mmr_root, delta.changed, delta.multiproof)
        if root != delta.new_root:
            return None
        return env.with_root(root, delta.seq)


# IP-434 Cross-Lingual Intent Grounder
class CrossLingualIntentGrounder:
    def __init__(self, model, calibrators, stc, cac, alpha=0.01, slack=0.005,
                 q_low=0.3, q_high=0.9, ttl_intent=1.0, n_min=200):
        self.model = model                # 蒸馏的多语言意图模型（语言无关槽位）
        self.calib = calibrators          # 每语言 conformal 校准器 + 池化兜底
        self.stc, self.cac = stc, cac
        self.alpha, self.slack = alpha, slack
        self.q_low, self.q_high, self.ttl = q_low, q_high, ttl_intent
        self.n_min = n_min

    def update(self, utt, lang, tost, t_now):
        slots, q = self.model.infer(utt, lang)
        core = self.stc.to_core(tost.onto_id, slots.intent, ctx="NARROW")
        if self.calib[lang].n < self.n_min:
            # 低资源语言：池化校准 + union-bound slack（覆盖 ≥1-α-ε_pool）
            gamma = self.calib.pooled_set(utt, alpha=self.alpha - self.slack)
        else:
            gamma = self.calib[lang].conformal_set(utt, alpha=self.alpha)
        # 非对称门槛（P36 延续）：急停/义务低门槛 fail-safe，可跨语言直接触发
        if slots.intent == "STOP" or (q >= self.q_low and core in OBLIGATION_INTENTS):
            return IntentState("STOP" if slots.intent == "STOP" else core,
                               mode="OBLIGATION", ttl=self.ttl)
        # 许可高门槛：核心翻译唯一 + conformal 集塌缩 + 目标区覆盖有效
        if (core is not None and q >= self.q_high and gamma <= {core}
                and self.cac.covers(slots.target_region)):
            return IntentState(core, mode="PERMISSION_CANDIDATE", ttl=self.ttl)
        return self.expire_if_stale(t_now)   # 不支持语言/歧义 → 不提权，回落最严默认


# IP-435 Semantic Quorum
class SemanticQuorumPlus(CertificateFederatedConsensusPlus):
    N_MIN_LINEAGES = 2
    ETA_MIN = 0.95

    def consensus_round(self):
        out = {}
        for key, votes in self.votes.items():
            count_ok = len(votes) >= self.N - self.F
            mods = {v.modality for v in votes.values()}
            # 只有「翻译校验通过 + 核心标签一致 + 保真达标」的票才是语义票
            sem = [v for v in votes.values()
                   if v.stc_valid and v.core_label == key and v.fidelity >= self.ETA_MIN]
            lineages = {lineage(v) for v in sem}
            # 同词异义的未校验别名不进入 sem；冲突映射在障碍/禁止方向已折到 ⊤
            if (count_ok and len(mods) >= 2
                    and len(lineages) >= self.N_MIN_LINEAGES
                    and len(sem) >= self.N - self.F):
                out[key] = self._majority_with_outlier_filter(sem)
            else:
                out[key] = "CI"           # 语义不足 → 置信区间 → 保守
        return out

# IP-437 Ontology Drift Monitor
class OntologyDriftMonitor:
    def __init__(self, eta_min=0.95, unknown_rate_max=0.02, width_max=1, window=200):
        self.eta_min, self.unknown_rate_max = eta_min, unknown_rate_max
        self.width_max, self.window = width_max, window
        self.stats = {}                   # (onto, label) → 滑动窗口统计

    def observe(self, onto, label, confirmed_core, mapped_core, width):
        self.stats.setdefault((onto, label), WindowStats(self.window)).update(
            correct=(confirmed_core == mapped_core), width=width)

    def demote(self):
        """告警标签降级到 ⊤，并触发依赖许可撤销 + 离线重校准。"""
        return [(onto, label) for (onto, label), s in self.stats.items()
                if s.eta < self.eta_min
                or s.unknown_rate > self.unknown_rate_max
                or s.width > self.width_max]

    def fidelity_ok(self):
        return not self.demote()
```

## 3. 推导

**引理 163（保守互译的可靠性）** 设互译记录满足 `⟦lo⟧_C ⊆ ⟦ℓ⟧_i ⊆ ⟦hi⟧_C`。WIDEN 返回 hi，故目标侧障碍解释 ⊇ 源侧、禁止域 ⊇ 源侧；NARROW 仅当 `lo=hi` 且 `η≥η_hi` 才返回唯一类，此时目标许可解释 = 源许可。未知/低保真/版本失配返回 ⊤：障碍取全域、许可取空集。故任一翻译都不会扩大许可集合，`Exec` 只会收缩。∎

**引理 164（星型枢纽无漂移累积）** 所有对等体原生实现核心 C。i→j 的传输等价于单跳 `α_i` 后由 j 在 C 语义下消费，即 `τ_{j←i} = id_C ∘ α_i`，不存在多段有损复合；核心版本以 `ontology_id + calib_epoch` 钉住，版本不一致即 fail-closed（⊤）。故轮转 `i→C→i` 在安全方向上幂等：结果要么是原标签、要么是更粗的核心类，绝不回到更细的（更宽松的）类。∎

**引理 165（激活包络与轻量核验的单向性）** 由区间抽象/抽象解释构造的包络满足 `φ∉box_r ⇒ Pre_r(φ)=false`。区间树查询返回活跃规则的超集，故在线前沿 `A_t` 覆盖所有真实活跃规则，完整核验 `A_t` 即不漏任何可触发规则；未核验规则均可证不触发。见证被篡改 ⇒ MMR 根不匹配 ⇒ 拒绝；承诺根只能来自已批准（签名或先前全量核验）集合。核验成本 `O(|A_t| + log|R|)`。允许误拒（包络过宽时多核验或拒绝），不允许误收（除非哈希碰撞或包络构造不健全）。∎

**引理 166（增量差量的防回滚性）** 差量仅在 `base_root` 等于当前根且 `seq` 严格递增 1、且重算根等于 `new_root` 时被接受。哈希链绑定快照与序号：回滚到旧的宽松证书会使 `seq` 失配；跨快照拼接会使 `base_root` 失配；伪造新根需破坏第二原像抗性。残余风险是同一序号下向不同对等体广播不同证书（equivocation），由对等体间 gossip 根哈希缓解（见风险 6）。∎

**引理 167（跨语言意图的失稳界）** 单一语言内样本可交换时，conformal 保证 `P(intent ∈ Γ_lang) ≥ 1-α`。低资源语言使用池化校准并以 slack `ε_pool` 支付语言条件偏移，覆盖 `≥1-α-ε_pool`（对语言做 union bound）。许可要求核心翻译唯一且 `Γ ⊆ {core}`，故假许可率 `≤ α+ε_pool`。不支持语言 → 无有效核心翻译 → 不提权；义务/急停仍走低门槛（可能误触发，仅损失活性），错误方向与危害方向对齐。∎

**引理 168（语义多样性共识抗别名）** 若两票共享表层词但指称不同，则其 STC 区间不可能同时「塌缩为同一核心类且保真达标」——否则按定义映射错误；未校验映射被排除在语义票之外。`quorum++` 要求 `\#votes ≥ N-F ∧ |Mod| ≥ 2 ∧ |lineage| ≥ 2`，故单一故障本体谱系的别名无法凑成 SAFE；伪造 SAFE 需至少两个独立谱系同时出错。残余风险：不同厂商若共享同一训练语料/标注源，谱系并非统计独立（见风险 1）。∎

**引理 169（v22 整体安全继承）** 同一快照、规则库与队列下：STC 不扩大许可（163、164）；LCE 只做可证排除与哈希绑定、可能误拒但不误收未核验的活跃规则（165）；ICD 只接受正确基根的增量（166）；CLIG 保持非对称门槛（167）；SQ+ 只在 CFC+ 之上加约束（168）；ODM 只降级到 ⊤。故 `Exec_v22 = Exec_v21 ∩ Fil_interop ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 7. 已知风险与失效模式

1. **语义别名与漂移（最大风险，见第 8 节）**：保守翻译 + 轻量核验各自健全，复合并不能保证指称一致；共享训练语料还会让「本体谱系独立」名不副实。缓解：ODM 在线监控 η/未知率（E823/E824）、指称核对（E805）、SQ+ 谱系门槛（E820）、受影响标签降级 ⊤（E821 保活性）。
2. **核心本体 C 的治理与厂商锁定**：C 太粗会压垮活性，太细又不可能全员共享。缓解：强制最小核心 + 可扩展 profile、版本化与 fail-closed、E821 监控活性。
3. **轻量核验的信任边界**：若在线核验信任被污染的本地索引/注册表，可能「健全地」排除掉真实活跃规则。缓解：索引与包络集哈希钉住 + 远程证明 + 周期性全量核验（E806/E809/E813）。
4. **保真度数据稀缺 / 长尾语言与类别**：小语种、罕见物体缺少双语对照，η 估计方差大。缓解：池化 + 保守 slack、未知一律 ⊤、主动学习补样（E815）。
5. **保守性叠加导致活性坍缩**：⊤ 回退 + 语义谱系门槛 + 义务过滤叠加，混行区活性可能趋零。缓解：分层 profile、按区放宽、E821/E825/E827 监控活性损失。
6. **承诺层攻击（回滚/equivocation）**：序号 + 基根链可防回滚与拼接，但同一序号向不同对等体广播不同证书仍可能。缓解：对等体 gossip 根哈希、轻量共识锚、E810/E812。
7. **多语言语音的隐私与胁迫**：语音含生物特征，且可能被录音重放/胁迫手势绕过。缓解：端上处理、原始音频不出域、挑战式确认与多模态佐证（E817/E818）。

## 8. 本轮最大风险

**一句话**：STC 的保守翻译与 LCE 的轻量核验各自都「形式正确」，但二者复合只证明了语法/承诺层的一致、没有证明指称层的一致——两个机器人可以对同一个词 "clear" 都通过合规证书却指向不同区域或类别，于是机器人在双方都合规、审计也通过的证书下协同撞人，即**「轻量互译的语义幻觉」**。
