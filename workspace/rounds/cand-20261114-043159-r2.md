# 第 71 轮（承接第 70 轮「BELIEF-RAS 贝叶斯状态估计层」IP-264~274；灵感循环第 3 轮；本轮灵感：「专利布局」×「轨迹优化」）

> R70 把 epistemic 从「动作模态」抬升为「世界状态后验」b_t，并交付了 RAS-Baselines v1 与 Proto-Val v1，把实验变成协议、把算法变成原型。但它留下两个尚未被正面处理的结构性缺陷：
> 1. **规划是逐点贪心的**：MINT 每步用一个瞬时 VoI 选一个信息动作，代价函数里没有「未来」。于是系统会重复问、会在一个两秒后自然免费澄清的问题上付社交成本，也会错过唯一的时间窗——**短视的双控制**。
> 2. **保证是逐动作局部的**：C-RAS-WM 只认证前缀，A99–A101 的 Lipschitz/可识别性假设被当成**全局成立**。真实系统里这些假设只在状态空间的某些局部区域成立。R70 的「自信地错」，本质就是**把局部有效的证书误当成全局有效的证书**。
>
> 本轮两个灵感正好各补一半：
> - **轨迹优化**把「一次问一句」升级为在**信念空间上规划整条轨迹**：任务动作与信息动作在同一时域上联合优化（双控制），前瞻性自然回答「何时问、问几次、要不要等、能不能边走边看」。
> - **专利布局**把「一张全局证书」升级为**证书组合（portfolio of claims）**：每张证书有覆盖范围 R_i、显式假设 A_i、有效性 ρ_i；范围与有效性此消彼长，用冗余防单点失效，用「分案/续展」在被挑战时细化边界，用「无效性检索」主动证伪。
>
> 核心命题：**把安全从「一个全局证明」重构为「一张有边界、有白空间、可被无效性搜索挑战的权利要求书」；把规划从「逐点 VoI」重构为「覆盖约束下的信念空间轨迹优化」。只有在已覆盖区（FTO 裕度达标）才执行；白空间要么用信息动作进入、要么退化为 R68 保守。** 命名 **CLAIM-RAS**（Coverage-Layered Assured Information-seeking Motion，名字直接借用专利「权利要求 claim」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「我该信哪个状态」，R71 问「**我凭什么说这块地方我保证得了？**」——安全不是一张证书，而是一张有边界、有白空间、会被反复挑战的权利要求书。

## 0. 直觉与动机

**灵感 1（轨迹优化 → 双控制是唯一同时处理「做」与「问」的框架）**
直觉：贪心 VoI 只看一步。真实决策里，「现在问」与「等两秒自然看清」是竞争关系；「先做 A 再问」可能比「先问再做」更省；「边看边走」比「停下—注视—再走」更平滑。轨迹优化把整段增广轨迹 Ξ=ξ_{t:t+H} 当作一个整体，目标里同时放任务代价与信息增益 β·IG，约束是硬安全集与交互预算。它自动产出这些行为：能等到免费信息就等；时间窗快关就先问；连续小信息动作替代一次大打扰。**贪心是 H=1 的退化，双控制是 H>1 的一般情形。**

**灵感 2（专利布局 → 证书的「宽度–有效性守恒」）**
直觉：没有人能用一条专利覆盖整个设计空间。安全证书也一样：想让覆盖区域 R_i 更大，就必须在更弱的假设下证明，或接受更低的置信 ρ_i；想要 ρ_i 高，R_i 只能小。这是**宽度–有效性 Pareto 前沿**，不是可以绕过的工程细节。R70 的隐含错误是默认存在一个「全局、宽、且有效」的证书。正确做法是维护一组**窄而有效**的证书，用**重叠（overlap）**防单点失效，用**分案/续展（division/continuation）**在被挑战时细化边界，用**标准必要（硬包络）**钉住不可谈判的核心。

**灵感 3（无效性搜索 → 把「假设」变成可攻击对象）**
直觉：专利会被无效性检索（invalidity search）攻击；安全证书也应被**主动证伪**。R70 的 A99–A101 从未被主动搜索过反例，于是「尚未被推翻」被误读为「成立」。CLAIM 引入后台 IVS：在每张证书的 R_i 内搜索违反 A_i 或越界的轨迹；一旦找到反例，就缩小或作废该证书，并写入审计。这把「自信地错」从一个不可见的概率问题，变成一个**可报告、有证据、可追溯的事件**。

**灵感 4（design-around → 优化器是最诚实的攻击者）**
直觉：竞争对手会绕着专利权利要求写产品；分布漂移会绕着证书假设把状态推到边界。更尖锐的是：**我们自己的轨迹优化器会主动找到覆盖地图的每一处缺口并利用它**——因为缺口边界往往正是性能最优的方向。只要覆盖地图高估 1%，BTO 就会把这条缝走成高速公路。所以覆盖必须取保守下置信界，并保留 FTO 安全裕度 m_fto，让「优化」永远够不到证书的悬崖边。

**灵感 5（专利丛林 / 标准必要 → 分层，而不是一张大证书）**
直觉：专利丛林里真正的安全靠标准必要专利（不可绕过的核心）和交叉许可（冗余组合）。映射到系统：**硬安全层**（碰撞距离、力矩上限、速度包络）是标准必要的，任何规划都不可谈判，作为约束而非代价；**软证书层**（覆盖组合）是可博弈、可替代、可失效的；性能优化只能发生在软层内部。绝不允许优化器用「性能收益」去交换硬约束。

## 1. 形式化定义（增量：定义 331–345）

**定义 331（CLAIM-RAS 总览）** CLAIM-RAS = (BTO, CCP, COV, IVS, CPO, FTO, BELIEF-RAS†)。四不变式：
(i) **实时零学习写操作**（继承 R70 定义 310-i）；证书的降级/分案是带审计的**安全状态转移**，不是梯度学习；
(ii) **硬安全层不进优化变量**：碰撞/力矩/速度包络作为约束集 𝒮_hard，绝不作为可交易的代价项；
(iii) **覆盖约束**：执行轨迹每步须满足 FTO(b_τ, ξ_τ) ≥ m_fto；否则进入回退（定义 342）；
(iv) **证书纪律**：任何「保证」主张必须附带 (R_i, A_i, ρ_i, ℓ_i)，并通过 IVS；无法通过者标记为白空间，只允许 R68 兜底。

**定义 332（增广决策变量与信念轨迹）** 轨迹 Ξ = ξ_{t:t+H} ∈ 𝒜_+^H（ξ=(a,g) 继承 R69 定义 294），信念轨迹 B = b_{t:t+H}，信念动力学 b_{τ+1} = BSE(b_τ, o_τ, ξ_τ, y_τ)（继承 R70 定义 314）。

**定义 333（信念空间轨迹优化 BTO）**
min_Ξ  J(Ξ) = E[ Σ_{τ=t}^{t+H} ( c_task(a_τ) + c_int(g_τ) − β·IG_τ ) + V(b_{t+H}) ]
s.t.  b_{τ+1}=BSE(b_τ,o_τ,ξ_τ,y_τ)； ξ_τ ∈ 𝒮_hard； FTO(b_τ,ξ_τ) ≥ m_fto； Σ_τ c_int(g_τ) ≤ B_H。
其中 IG_τ = I(s; y_τ | b_τ, g_τ) = H[b_τ] − E_{y_τ}[H[b_τ^+]] 是贝叶斯实验设计信息增益（R70 定义 317）。求解：FMP 采样做热启动，MPPI/CEM 在 K 条 rollout 上做局部精化，末端用 CBF/QP 投影回 𝒮_hard；滚动时域执行前 h_exec 步。

**定义 334（双控制分解与退化链）** β 是探索-利用温度；β→0 退化为纯任务规划（无交互）；H=1 且在线贪心取 argmax 退化为 R70 的 MINT；FTO 恒真且 H=1 时退化为 BELIEF-RAS。此退化链是本轮「严格包含」的骨架（定理 20）。

**定义 335（证书声明 Claim）** 证书 C_i = (R_i, A_i, ρ_i, ℓ_i, κ_i)：覆盖区域 R_i ⊆ 𝒮×𝒜×ℬ；显式假设集 A_i（可测、可证伪）；有效性置信 ρ_i（在 R_i 上、A_i 成立时，单步风险超 ε_cert 的概率 ≤ 1−ρ_i）；性能档 ℓ_i（该证书允许的最大 λ/最小安全裕度）；失效模式标签 κ_i。C_i 有效 ⇔ 在 R_i 上 A_i 成立时风险 ≤ ε_cert 以概率 ≥ ρ_i。

**定义 336（宽度–有效性结构）** 宽度 w(C)=μ(R_i)（覆盖测度）；有效性 v(C)=ρ_i·Pr_{deploy}(A_i 成立)。**宽度单调假设**：同一证明框架下 R_i ⊇ R_j ⇒ v(C_i) ≤ v(C_j)。证书族在 (w, v) 平面上的非支配集称为**宽度–有效性 Pareto 前沿**。

**定义 337（证书组合 CCP 与自由行动 FTO）** 组合 𝒫={C_i}。cov(s)={i : s∈R_i}；FTO(s)=1[ cov(s)≠∅ ∧ max_{i∈cov(s)} v(C_i) ≥ v_min ]；覆盖深度 d(s)=max_{i∈cov(s)} v(C_i)；冗余度 r(s)=|{i∈cov(s): 失效模式近似独立}|。联合担保界 risk(s) ≤ min_{i∈cov(s)} (ε_cert + (1−ρ_i)·R_max)（单证书取最强；冗余见引理 26）。

**定义 338（覆盖地图 COV）** 覆盖地图 M:(s,ξ) ↦ [0,1] 是 FTO 的**保守下置信估计**；白空间 W={M < m_fto}。M 由证书组合 + 局部校准（密度比、时序一致性、R70 的 ECE_state）给出，且必须取下界（宁可把安全区标成白空间，不可反过来）。M 随后验漂移在线更新，但只做单调安全修正。

**定义 339（无效性搜索 IVS）** 在 R_i 内求解反例：
(s*,ξ*) = argmax_{s∈R_i} violation(s,ξ; C_i)  s.t.  A_i，预算 B_search。
violation > 0 ⇒ 证书收缩到 R_i \ N_ε(s*) 或整体降级（demote）。IVS 在后台/离线运行，输出写 AuditBuf，实时侧只读。实现：可微仿真梯度、CEM 对抗采样、或场景生成（对应专利 invalidity search）。

**定义 340（分案/续展证书管理）** 当有效性下降或边界被挑战时，按分案规则把 C_i 拆为 {C_{i,1},…,C_{i,m}}（划分 R_i，每个子区在更强假设 A_{i,j}⊃A_i 下有效）；保留一张**宽而低置信的监测声明**仅用于触发告警，绝不用于放行。对应专利的 divisionals/continuations。

**定义 341（设计规避威胁模型 ℰ_design）** 分布漂移把状态推出证书；**边界利用**（BTO 主动找覆盖缺口）；证书伪造/投毒（ρ 被高估）；**时序规避**（在证书交替窗口穿越白空间）。并入 AIC：ℰ_CLAIM = ℰ_BELIEF × ℰ_design（继承 R70 定义 271）。

**定义 342（证书失效回退）** 若预测轨迹将进入白空间，或覆盖证书在途中被 IVS 降级：λ 单调不降，回退到最大覆盖子证书的保守 λ；若无有效覆盖 ⇒ 执行 R68 最保守策略或安全停。回退必须是**连续**的（无控制突变，继承 R68 定理 15、R70 定理 18）。

**定义 343（分层规划接口）** 决策频率三层：FMP 作为 proposal 与轨迹跟踪（高频）；BTO 滚动时域（低频 10–20Hz）；硬约束 CBF/QP 投影（最高频）。BTO 只输出覆盖内的参考轨迹，低层不得越出 𝒮_hard，也不得越过 FTO 安全带。

**定义 344（证书 J_CLAIM）** J_CLAIM = (J_BELIEF, coverage_ratio, min_FTO_margin, ivs_pass_rate, demotion_events, bto_feasibility_gap, claim_ver)。Valid ⇔ Valid(J_BELIEF) ∧ coverage_ratio ≥ γ_cov ∧ min_FTO ≥ m_fto ∧ ivs_pass_rate ≥ δ_ivs。

**定义 345（组合优化 CPO）** 选证书组合以最大化 ∫_{covered} ℓ(s) ds，s.t. 全局有效性 ≥ v_min、冗余 ≥ r_min、|𝒫| ≤ N_max、预算 ≤ B_cert。覆盖是子模的，贪心达 (1−1/e) 近似（引理 27）；对应专利组合的预算分配。

## 2. 关键算法骨架

```python
# IP-275 BTO：信念空间轨迹优化（flow 热启动 + MPPI + 硬约束投影）
def bto_plan(fmp, bse, b_t, o_t, budget):
    Xi0 = fmp.sample(o_t, b_t, K=K0)                  # flow proposal（R70 FMP†）
    def rollout(xi):
        b, cost, ig = b_t, 0.0, 0.0
        for tau in range(H):
            a, g = xi[tau]
            if not in_hard_set(a, g):            return INF, False   # 硬层
            if cov_map(b, xi[tau]) < M_FTO:      return INF, False   # 覆盖层
            y  = sample_answer(b, g)             # 对回答取期望（粒子）
            b2 = bse.predict_update(b, o_t, xi[tau], y)
            ig   += entropy(b) - entropy(b2)
            cost += task_cost(a) + int_cost(g)
            b = b2
        return cost - BETA * ig, True
    xi_star = mppi_cem(Xi0, rollout, N=K_mppi, sigma=SIGMA)
    if xi_star is None: raise InfeasibleCoverage
    xi_safe = project_hard_constraints(xi_star, cbf)  # QP / CBF 投影
    return xi_safe[:h_exec]

# IP-277 COV：FTO 安全监控（实时只读）
def fto_margin(portfolio, b, xi):
    best = -1.0
    for c in portfolio:
        if c.contains(b, xi):
            best = max(best, c.rho * c.assumption_support(b))  # 下置信界
    return best                                   # < m_fto 即白空间

# IP-278 IVS：无效性搜索（后台，带审计）
def invalidity_search(claim, sim, budget):
    worst, witness = 0.0, None
    for _ in range(budget):
        s = adversarial_sample(claim.R, claim.A) # 梯度 / CEM
        v = violation(s, claim)                 # 风险 - ε_cert
        if v > worst: worst, witness = v, s
    if worst > 0:
        shrink_or_demote(claim, witness)        # 分案/续展（定义 340）
    return worst, witness

# IP-276 CCP：证书组合的组合优化（子模贪心）
def optimize_portfolio(candidates, v_min, r_min, N_max):
    P = []
    while len(P) < N_max:
        gains = [(marginal_coverage(P + [c], v_min, r_min), c)
                 for c in candidates if valid_under_v(c, v_min)]
        if not gains: break
        gain, c = max(gains, key=lambda t: t[0])
        if gain <= 0: break
        P.append(c)
    return enforce_redundancy(P, r_min)          # 冗余补张

# IP-283 CLAIM-RAS 主闭环
def CLAIM_RAS_round(M, obs):
    b_t = M.bse.step(M.b_prev, obs, M.last_action, M.last_g, M.last_y)  # R70
    # 低频：覆盖约束下的滚动时域轨迹优化
    if M.clock.due_plan():
        try:
            xi_ref = M.bto.plan(M.fmp, M.bse, b_t, obs, M.budget)
            M.feasible = True
        except InfeasibleCoverage:
            xi_ref = M.fallback.r68_conservative(b_t, obs)   # 白空间兜底
            M.feasible, M.lam = False, max(M.lam, 0.8)
    # 高频：跟踪 + 硬约束投影（绝不信任 BTO 之外）
    a = M.cbf.project(M.fmp.track(xi_ref, obs))
    # 覆盖安全带（每步只读检查）
    if M.cov.fto_margin(M.portfolio, b_t, a) < M.m_fto:
        a = M.fallback.safe_stop_or_conservative(M.portfolio, b_t)
        M.lam = max(M.lam, M.lam_floor_conservative)
    # 交互回答 + 证据纪律（R70 MINT†/CIA†）
    g = xi_ref[0][1] if M.feasible else None
    if g is not None:
        y = M.cia.execute(g); b_t = M.bse.step(b_t, obs, a, g, y)
    U_ale, U_epi = decompose_from_belief(b_t, M.fmp, obs)  # R70 AUD†
    M.lam = max(M.lam, lam_floor(U_ale + (U_epi if g is None else 0.0)))
    # 后台：无效性搜索 + 分案 + 参与式审计
    M.ivs.submit_async(M.portfolio, M.audit_buf)
    M.vqa_ii.submit_async(b_t, g, y, M.portfolio, M.cov)
    M.b_prev, M.last_action, M.last_g = b_t, a, g
    return a, M.lam, (U_ale, U_epi)
```

## 3. 推导

**引理 23（宽度–有效性 Pareto 前沿）** 设同一证明框架下 R_i ⊆ R_j，则有效假设更弱 A_j ⊆ A_i、且违规率在更大区域上不减，故 v(C_j) ≤ v(C_i)。系：**不存在同时最大覆盖与最大有效性的非平凡证书**；R70 假设的「全局且有效」证书要么宽度退化、要么 A 为空（vacuous），这正是「自信地错」的形式根源。

**引理 24（BTO 的前瞻收益与「等待」判据）** 设 IG 子模。若在 t+1 存在免费（或更廉价）观测使 I(s;y_{t+1}|a_{t+1}) ≥ I(s;y_t|g)、且无时间窗风险，则贪心在 t 支付 c(g)>0 严格劣于 BTO 的「等待」；一般地，H 步滚动时域的期望 IG 不低于贪心序列在任意前缀上的 IG，且交互成本不高。系：**贪心会过度提问**，前瞻会把提问压缩到真正必要的时间点。

**引理 25（无效性搜索把「未知」变「已知」）** 设违规测度 μ 在 R 上有界、violation 对状态 L_v-Lipschitz。IVS 以预算 B 找到最大违规点 s* 后，收缩半径 δ 的邻域，则残余违规质量 ≤ μ(R∖N_δ) ≤ μ(R) − c·δ^d。故「通过 IVS」的区域其自信错误质量可被量化压低；N_max 与 B_search 共同决定可承诺的 ρ_i。系：ρ_i 不是先验许愿，而是**可复算的下界**。

**引理 26（证书冗余的失效界）** 若覆盖某点的 r 张证书失效近似独立、单张有效率 ρ，则「全部失效」概率 ≤ (1−ρ)^r；若相关性上界 ρ_corr<1，则 ≤ (1−ρ)·ρ_corr^{r−1}+ε_σ。系：**冗余是安全界的乘性折扣**，与 R69 引理 18 的多源一致纪律同构——安全不是更宽的证书，而是更多互不相关的窄证书。

**引理 27（组合优化的子模近似）** 覆盖函数 cov(𝒫) 子模、单调；在基数约束 |𝒫|≤N_max 与有效性门槛下，贪心达 (1−1/e) 近似。系：专利组合的「预算—覆盖」分配有可证明的近似保证，不是拍脑袋。

**定理 20（严格包含链）** 在 A99–A102（覆盖可估、IVS 可判、violation Lipschitz）下：CLAIM-RAS 在「覆盖满、IVS 全过、H=1、β=0、B_H=0」时逐指令退化为 BELIEF-RAS；而 BELIEF ⊂ FLUID ⊂ R68（R70 定理 18）。故安全侧永不弱于 R70，效率侧只在**已被有效证书覆盖**处获得前瞻与 resolution bonus。

**定理 21（覆盖约束下的安全性）** 若执行轨迹全程 FTO ≥ m_fto 且每张覆盖证书有效（概率 ρ_i），则单点风险 ≤ min_{i∈cov} ε_cert + (1−ρ_i)·R_max；冗余 r 时降为 ε_cert + (1−ρ)^{r}·R_max（引理 26）。FTO 监控使白空间不可执行，故安全性 modulo **证书有效性假设**成立。**注意：证明的全部重量落在「覆盖地图没有高估」上。**

**定理 22（BTO 可行性与无突变）** FMP 热启动 + MPPI 在 K 采样下逼近约束最优（标准 MPPI 界）；QP/CBF 投影保证 𝒮_hard 可行；滚动时域的 InfeasibleCoverage 一律触发 λ 单调不降的回退（定义 342），且低频重规划之间由高频 CBF 保证安全 ⇒ 控制连续、无突变（延伸 R68 定理 15、R70 定理 18）。

## 6. 本轮最大风险

**一句话**：CLAIM-RAS 把全部安全重量从「后验是否可信」转移到「覆盖地图是否保守」——**而覆盖地图本身是估计出来的；一旦它对某块白空间高估了安全性，覆盖约束就从刹车变成了许可证，轨迹优化器会以最高效率把这块「伪证书区」走成高速公路，系统于是从 R70 的「自信地错状态」升级为「自信地错安全边界」——问错只是信错，证错是担保错。**

次级风险与缓解：
1. **IVS 预算不足导致假证书** → ρ_i 只承认可复算下界，预算不足即降级为白空间；E325/E338 强制校准；
2. **BTO 被覆盖缺口诱导** → FTO 保守下界 + m_fto 安全裕度 + E326 边界攻击；
3. **滚动时域实时性** → BTO 低频、CBF 高频、flow 热启动，E330 守时；
4. **证书组合管理抖动/级联降级** → 单调安全修正 + 分案规则，E335；
5. **硬层被软层「交换」** → 𝒮_hard 不进优化变量（定义 331-ii），E334 投影零越界。

# IP-275 BTO：信念空间轨迹优化（flow 热启动 + MPPI/CEM + 硬约束投影）
def bto_plan(fmp, bse, b_t, o_t, budget):
    Xi0 = fmp.sample(o_t, b_t, K=K0)                  # R70 FMP† 热启动
    def rollout(xi):
        b, cost, ig = b_t, 0.0, 0.0
        for tau in range(H):
            a, g = xi[tau]
            if not in_hard_set(a, g):             return INF, False  # 硬层
            if cov_map(b, xi[tau]) < M_FTO:       return INF, False  # 覆盖层
            y  = sample_answer(b, g)              # 粒子对回答取期望
            b2 = bse.predict_update(b, o_t, xi[tau], y)
            ig   += entropy(b) - entropy(b2)
            cost += task_cost(a) + int_cost(g)
            b = b2
        return cost - BETA * ig, True
    xi_star = mppi_cem(Xi0, rollout, N=K_mppi, sigma=SIGMA)
    if xi_star is None: raise InfeasibleCoverage
    return project_hard_constraints(xi_star, cbf)[:h_exec]

# IP-276 CCP + IP-279 CPO：证书组合的子模贪心
def optimize_portfolio(candidates, v_min, r_min, N_max):
    P = []
    while len(P) < N_max:
        gains = [(marginal_coverage(P + [c], v_min, r_min), c)
                 for c in candidates if valid_under_v(c, v_min)]
        if not gains: break
        gain, c = max(gains, key=lambda t: t[0])
        if gain <= 0: break
        P.append(c)
    return enforce_redundancy(P, r_min)

# IP-277 COV/FTO：保守覆盖监控（实时只读）
def fto_margin(portfolio, b, xi):
    best = -1.0
    for c in portfolio:
        if c.contains(b, xi):
            best = max(best, c.rho * c.assumption_support(b))  # 下置信界
    return best                                   # < m_fto ⇒ 白空间

# IP-278 IVS：无效性搜索（后台）
def invalidity_search(claim, sim, budget):
    worst, witness = 0.0, None
    for _ in range(budget):
        s = adversarial_sample(claim.R, claim.A) # 梯度 / CEM / 场景生成
        v = violation(s, claim)                 # 风险 - ε_cert
        if v > worst: worst, witness = v, s
    if worst > 0:
        shrink_or_demote(claim, witness)        # 分案/续展（定义 340）
    return worst, witness

# IP-283 CLAIM-RAS 主闭环
def CLAIM_RAS_round(M, obs):
    b_t = M.bse.step(M.b_prev, obs, M.last_action, M.last_g, M.last_y)
    if M.clock.due_plan():                        # 低频 10–20Hz
        try:
            xi_ref = M.bto.plan(M.fmp, M.bse, b_t, obs, M.budget)
            M.feasible = True
        except InfeasibleCoverage:
            xi_ref = M.fallback.r68_conservative(b_t, obs)
            M.feasible, M.lam = False, max(M.lam, 0.8)
    a = M.cbf.project(M.fmp.track(xi_ref, obs))   # 高频 1kHz
    if M.cov.fto_margin(M.portfolio, b_t, a) < M.m_fto:   # 每步安全带
        a = M.fallback.safe_stop_or_conservative(M.portfolio, b_t)
        M.lam = max(M.lam, M.lam_floor_conservative)
    g = xi_ref[0][1] if M.feasible else None
    if g is not None:
        y = M.cia.execute(g); b_t = M.bse.step(b_t, obs, a, g, y)
    U_ale, U_epi = decompose_from_belief(b_t, M.fmp, obs)
    M.lam = max(M.lam, lam_floor(U_ale + (U_epi if g is None else 0.0)))
    M.ivs.submit_async(M.portfolio, M.audit_buf)  # 后台证伪
    M.vqa_ii.submit_async(b_t, g, y, M.portfolio, M.cov)
    M.b_prev, M.last_action, M.last_g = b_t, a, g
    return a, M.lam, (U_ale, U_epi)

## 4. 推导

**引理 23（宽度–有效性 Pareto 前沿）** 同一证明框架下 R_i ⊆ R_j ⇒ A_j ⊆ A_i 且大区域违规率不减 ⇒ v(C_j) ≤ v(C_i)。**不存在非平凡的「全局且有效」证书**；R70 的隐含全局证书必然退化为宽而空假设或窄而局部。此引理把「自信地错」形式化。

**引理 24（前瞻收益与「等待」判据）** IG 子模时，若 t+1 有免费观测且其 IG 不小于 t 时刻信息动作，则 BTO 的等待严格优于贪心（同后验、省成本）；H 步滚动优于任意贪心前缀。系：贪心系统性过度提问。

**引理 25（IVS 把未知变已知）** violation 为 L_v-Lipschitz、预算 B 找到最大违规点后收缩 δ 邻域，残余违规质量 ≤ μ(R) − c·δ^d。故 ρ_i 是**可复算下界**，不是先验许愿；IVS 决定可承诺的置信上限。

**引理 26（证书冗余失效界）** r 张近似独立覆盖证书全失效概率 ≤ (1−ρ)^r；相关上界 ρ_corr 时 ≤ (1−ρ)·ρ_corr^{r−1}+ε_σ。冗余是安全界的乘性折扣，与 R69 引理 18 多源纪律同构。

**引理 27（组合子模近似）** 覆盖函数子模单调，基数约束下贪心 (1−1/e)。

**定理 20（严格包含链）** A99–A102 下，CLAIM-RAS 在「覆盖满、IVS 全过、H=1、β=0、B_H=0」时逐指令退化为 BELIEF-RAS；BELIEF ⊂ FLUID ⊂ R68。安全侧永不让步，效率收益只在有效覆盖内。

**定理 21（覆盖约束安全性）** 全程 FTO≥m、每证书有效率 ρ_i ⇒ 单点风险 ≤ min_i ε_cert + (1−ρ_i)R_max；冗余 r 时 ≤ ε_cert+(1−ρ)^r R_max。安全性 modulo「覆盖未高估」，这是**全部重量所在**。

**定理 22（BTO 可行性与无突变）** FMP 热启动 + MPPI 逼近约束最优；QP/CBF 保证硬可行；InfeasibleCoverage 触发 λ 单调不降回退，低频重规划间由高频 CBF 兜底 ⇒ 连续无突变。

## 7. 本轮最大风险

**一句话**：CLAIM-RAS 把安全重量压在「覆盖地图 M 保守、证书有效性 ρ 可复算」上——**若 M 高估了白空间的安全性（IVS 预算不足、密度比校准失效、或分布漂移把新区域误判为已覆盖），覆盖约束就从刹车变成许可证，而 BTO 这个优化器会以最高效率钻过每一处「伪证书区」；于是系统从 R70 的「自信地错状态」升级为「自信地错安全边界」——信错只是决策错，证错是担保错，后者无法用保守回退兜住**。

**次级风险与缓解**：
1. 假证书 → ρ_i 只认可复算下界，预算不足即降白空间；E325/E338 校准门；
2. BTO 边界利用 → FTO 保守下界 + m_fto 裕度 + E326 对抗攻击；
3. 实时性 → BTO 低频 + CBF 高频 + flow 热启动，E330；
4. 组合抖动/级联降级 → 单调安全修正 + 分案规则，E335；
5. 硬层被软层交换 → 𝒮_hard 不进优化变量，E334 投影零越界。
