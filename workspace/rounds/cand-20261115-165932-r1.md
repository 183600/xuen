# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「情感计算」×「视觉语言模型」）

> R69 把「不确定性」劈成两半：**aleatoric（噪声，只收紧）** 与 **epistemic（歧义，去问）**，再用「流匹配多模态策略 + 主动多模态交互（看/问/触）」把 epistemic 消解掉，并用流似然做标定不可吸收的第二意见。它的理论姿态很漂亮：R68 是「永不交互」的退化，安全不让步。
>
> 但 R69 的三条隐含假设，在遇到「人」的时候同时失效：
> 1. **存在可收敛的真相**——问对了就能知道。可「他是不舒服还是在专注」「这个笑是礼貌还是开心」「这句『可以』是同意还是不敢拒绝」往往**没有 oracle**，连当事人自己都可能说不清（self-opaque），甚至情感范畴本身是可争议的社会建构；
> 2. **证据源条件独立（ρ<1）**——所以 k 个模态一致就能把投毒率压到 `δ_p·ρ^{k−1}`。可当证据来自一个**有策略的人**时，脸、声音、姿态、口头回答全由同一个「展示意图」生成（ρ→1），一致性可以被**制造**；R69 引理 18 在此退化为毫无保证的 δ_p；
> 3. **消解歧义总是好的**——所以有 resolution bonus。可对「人的意义」而言，**过度消解本身就是伤害**：误把不适读成配合、把沉默读成同意、把情感推断用于说服与操纵，都是「更准」反而更危险。
>
> 本轮两个灵感正好把问题**上移一层**：
> - **情感计算**告诉我们，情感/意图不是可标注的固定标签，而是**带策略、带语境、随情境 appraisal 变化的潜变量**；观测到的「情感展示」与内部状态之间系统性错位（masking / 表演 / 顺从）；
> - **视觉语言模型**给出一个开放词表、语言接地的**解释提案器**，能把「我可能把你读成了什么」摆到人面前、让人纠正；但 VLM 会幻觉、会谄媚（顺着提问者的假设编故事），所以它只能是**证人，不能是法官**。
>
> 核心命题：**把不确定性从二分升级为三分——aleatoric / epistemic-fact（可验证事实，交给 R69）/ hermeneutic（不可 oracle 的「意义」）；对 hermeneutic，目标不是最大化消解，而是最小化「在不可辨识处做出不可逆判断」的期望伤害：用 VLM 做盲描述提案、用因果通道审计破除共性因、用 appraisal 后果探针做可证伪检验、用可逆动作与解释权威兜底。** 命名 **HERMES-RAS**（Hermeneutic Evidence, Reversible Meaning & Empathic Safety；取 Hermes 信使之义：在人与机器之间传递并**可被退回**的解释）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我有没有资格替你把这件事定义清楚**」——不确定性不只是刹车踏板、也不只是一句提问，它还可以是「**把解释权还给你**」。

## 0. 直觉与动机

**灵感 1（情感计算 → 情感是带策略的潜变量，不是标签）**
直觉：R69 的模态分解假设动作有 K 个可分的峰；但「人」这一侧的歧义更麻烦：同一个皱眉既可能是疼痛，也可能是专注，还可能是对机器人的戒备。情感计算几十年的教训是：**展示（display）≠ 状态（state）**。人会掩蔽（masking）、会表演（social display）、会顺从（compliance theater，嘴上说没事身体在后退）。所以真正要估的不是一个情绪标签，而是一个**带策略的潜变量** `h`：意图 × 情感 × 社会姿态 × 对机器人的信任/控制感。`h` 不是被动的噪声源，它会**回应机器人的动作**——这让「探询」从读取变成博弈。

**灵感 2（视觉语言模型 → 语言是可纠正的解释接口，但 VLM 是谄媚的证人）**
直觉：R69 的交互是「看/问/触」；但真正能让人**参与纠错**的接口是语言——「我以为你可能不太舒服，是这样吗？」。VLM 的独特价值不是更准的分类器，而是**开放词表地把解释说出来、落到具体时空片段（grounded span）**，从而可审计、可反驳。危险也在这里：VLM 有强谄媚性，你问「他是不是在生气」，它很容易顺着说「是的，他在生气」。**用 VLM 去确认 VLM（或确认机器人自己的假设），是循环论证**。所以必须让它先**盲描述、预注册**，再允许其进入证据。

**灵感 3（上游歧义 → 目标本身可能是错的：构造论与不可辨识）**
直觉：R69 把歧义放在动作空间（选哪条路），默认观测是干净输入。但对人而言，歧义常常**在观测语义里**，而且不是「标签没标对」，而是「标签体系本身不唯一」。情感科学的构造论（constructed emotion）主张基本情绪类别并非天然离散；把连续、情境依赖的情感强行塞进 6 个类，再用更准的 ECE 去校准，是在**给一个错误的假设做更精致的拟合**。这带来一个比 R69 更尖锐的判断：R69 的最大风险被它自己定义为「模态权重没校准」；本轮指出其中一大块**根本不是校准问题，而是可辨识性问题**——无论后验多准，两个不同的 `h` 产生完全相同的可观测量，误差下界仍为正（见定理 19）。

**灵感 4（共性因 → 多模态一致不是独立证据）**
直觉：R69 的证据纪律「k 个正交源一致才定案」在传感器故障下是对的；但当所有模态都从**同一个人**发出，人就是共同原因。他可以让表情、语气、姿态、回答**一起**演出一个「没事」。此时多模态一致不是独立证据的叠加，而是**同一个谎言的多路复制**。要破除它，只能引入**不服从自愿展示**的通道：生理反应、以及最关键的——**行动后果**（appraisal 被扰动后，行为是否按预测改变）。

**灵感 5（可逆性与解释权威 → 在不可辨识处，最好的消歧是「让步」）**
直觉：R69 的答案是「不确定就去问、问完就更有把握、于是可以更不保守」。但对不可辨识的意义，更稳健的做法常常相反：**不要急着问，先做一个可撤销的动作，同时把你的解释摊开让人纠正**。人后退一步，你就多给一点空间（可逆）；人没纠正，你才继续。**可逆行动 + 解释权威**，把「纠正成本」从「事后伤害」降到「一次撤销」。这也是本轮的伦理核心：系统的谦逊不应表现为「问不完的问题」，而应表现为「不擅自替人下定义」。

**灵感 6（双时间尺度 → VLM 进不了 3ms 反射环）**
直觉：R69 的实时预算 <2.6ms 是硬约束，而 VLM 推理是 30–150ms 量级。硬塞进去必然击穿。所以架构必须分层：**快反射环**（沿用 R69，原样不动）与**慢解释环**（VLM、账本、授权，事件触发、异步、带时效）。慢环只向快环提交「已预注册的解释先验 + 时效戳」；快环若拿到过期解释，就把 `U_herm` 重置为未消解。这不是工程妥协，而是理论上正确的：**意义的时效本来就短于控制周期**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（HERMES-RAS 总览）** HERMES-RAS = (HPU, AHL, VLM-HG, BDP, CCA, CFP, IAR, ASE, ILA, RAS-WM‡)。四不变式：
(i) **实时反射环零学习写操作**（继承 R68 定义 276-i、R69 定义 293-i）；
(ii) **双时间尺度契约**：任何不可逆动作不得阻塞等待慢解释环；快环只能使用「年龄 ≤ τ_age 且已预注册」的解释；
(iii) **非坍缩原则**：对不可逆动作，不得仅凭 hermeneutic 证据把解释集坍缩成一个点后执行；
(iv) **解释权威**：人的覆写（override）永远被接受、被记录、且立即生效；不得基于推断的情感/顺从移除人的控制权。

**定义 311（三类不确定性）** 给定观测 o，把不确定性分为三束：`U_ale`（噪声，不可约，沿用 R69 λ_floor）；`U_epi^fact`（关于**可验证事实**的歧义，如「障碍在左还是在右」，R69 的交互消解适用）；`U_herm`（关于**人的意义**的歧义：情感、意图、同意、社会姿态）。三者在观测层划分；**R69 是 `U_herm ≡ 0` 的边界情形**（定义 324）。三者语义不同，不做标量加和，分别进入不同通道。

**定义 312（解释学潜变量与解释格）** 设人的意义状态 `h ∈ ℋ`，稠密且非全序；定义解释偏序 `≼`（一个解释比另一个更具体/更强），允许**不可比** `h ⊥ h'`。范畴情感标签集 `ℒ = ℋ/∼` 只是 ℋ 的一个商集；在 ℒ 上取 argmax 隐含了「总可比」的假设，这在情感/意图上通常是范畴错误。故 HERMES 保留的是**格上的可容许集合**，而非标签上的点后验。

**定义 313（可容许解释集与后果直径）** `ℋ_adm(o) = { h : 现有证据 e 未证伪 h }`。对每个 h 定义其最优动作 `π*(h) = argmin_a E[L(a,h)]`，后果散度 `D(a,a')` 为两动作在结果空间的距离（或 1−重叠）。定义 `U_herm(o) = max_{h,h' ∈ ℋ_adm} D(π*(h), π*(h'))`。**关键**：`U_herm` 度量的是「歧义是否改变该做什么」，不是标签熵。标签熵很高但所有 h 指向同一动作 ⇒ `U_herm = 0`，不应交互；标签熵很低但最坏 h 指向危险动作 ⇒ `U_herm` 很大，必须处理。

**定义 314（VLM 假设生成器 VLM-HG）** `VLM-HG: (o, prompt) → {(h_i, span_i, conf_i)}`，输出开放词表、时空接地的解释提案。它在系统中的角色是**证人（witness）而非裁判（judge）**：可提案、可描述、可被质询，但**不得单独授权动作**。其谄媚率 `σ_syc` 与幻觉率有登记档案（定义 325）。

**定义 315（盲描述预注册 BDP）** 在把当前假设 `H_t` 透露给 VLM 之前，先取得盲描述 `d_0 = Describe(o)`，并提交承诺 `c_t = Hash(d_0 ‖ hash(o) ‖ t)`。只有**先于 H_t 提交**的描述可作为证据；事后（见到假设后）生成的描述权重置零，或在下一轮重新做一次「当时假设未泄露」的注册。这是对抗 VLM 谄媚的**预注册协议**：把「顺着你说」挡在证据之外。

**定义 316（因果通道审计 CCA）** 把证据通道分为两组：**自愿展示** `V`（表情、语气、姿态、口头回答）与**后果/非自愿** `C`（appraisal 扰动后的行为改变、生理反应、与环境交互的结果）。用共享原因因子估计有效独立性 `ρ_eff`。只有当一致性**跨 V 与 C** 成立时，才计为独立证据；若 `ρ_eff ≥ ρ_max`（即所有通道都可由同一个展示意图解释），则一致性退化为单源，证据纪律回落到 R69 的 δ_p 下界而非 `δ_p·ρ^{k−1}`。

**定义 317（证伪优先探询 CFP 与 VoF）** 记最小最大风险 `R(ℋ_adm) = min_a max_{h∈ℋ_adm} E[L(a,h)]`。信息动作 g 的价值定义为**证伪价值**：`VoF(g) = R(ℋ_adm) − E_{y∼p(·|g,o)}[ R(ℋ_adm ∩ {h : y 不证伪 h}) ]`。选择 `g* = argmax_g [VoF(g) − c(g)]`，约束安全、预算、可逆性；并按 `V → C` 的次序优先选择**appraisal 后果探针**（给控制权、降低不确定性、增加距离、给出选择），而不是质问式探针。注意：VoF 惩罚的是「最坏情形没被排除」，熵式 VoI 奖励的是「平均更确定」——在代价不对称时二者会选出相反的探针（引理 20）。

**定义 318（可逆动作集与解释权威 IAR）** `𝒜_rev = { a : 存在撤销 u，其代价 ≤ c_rev 且无可逆的物理/社会后果 }`。任何**仅由**未验证的 `h ∈ ℋ_adm` 辩护的动作，必须属于 `𝒜_rev ∪ 𝒜_auth`（`𝒜_auth` 为人类显式授权）。Override 规则：人一旦覆写，系统必须接受、记录、并据此修正 `ℋ_adm`；不得要求人「证明自己」。

**定义 319（情感安全包络 ASE）** 硬约束集合：禁止推断受保护属性；禁止把推断的情感/顺从用于说服或操纵（affect-conditioned persuasion）；禁止在仅凭推断的负向情感或「配合」时执行移除人类控制的动作；情感数据的隐私预算 `b_priv`；私人场景下禁止隐蔽推断。所有动作最后与 `𝒜_ase` 取交（定义 324）。

**定义 320（保持歧义动作 g_hold）** 与 R69 的时间性「等」不同，`g_hold` 是一个**语义性的一等动作**：主动维持 `ℋ_adm` 不坍缩，选择承诺最小、可逆、信息中性的动作，或显式请求授权。当 `VoF − c ≤ 0` 且 `c_rev` 很小时，`g_hold` 优于任何探询——**能撤销，就不必审问**（引理 21）。

**定义 321（解释账本 ILA）** 只追加、哈希链式的记录 `(h 提案, span, 证据来源, BDP 承诺, ρ_eff, 动作, override, 时间戳)`。它使「当时系统把你读成了什么、凭什么」可被事后归因与修正，并为 VQAuditor-H 提供审计对象。

**定义 322（解释学干扰集 ℰ_herm）** 情感掩蔽/表演、跨模态共性因欺骗（表情+语气一起演）、VLM 诱导性提问与谄媚确认、VLM 幻觉解释、场景文字提示注入、环境对 appraisal 的对抗操纵、「顺从剧场」。并入 AIC：`ℰ_HERMES = ℰ_FLUID × ℰ_herm`。

**定义 323（证书 J_HERMES）** `J_HERMES = (J_FLUID, U_herm_before/after, ρ_eff, bdp_hash, reversibility_status, authority_log_hash, sycophancy_score, ase_verdict, hermes_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ (ρ_eff < ρ_max 或已按单源纪律处理) ∧ BDP 满足 ∧ 无 ASE 违反 ∧ (不可逆 ⇒ 已授权)`。

**定义 324（三级退避，严格包含 R69/R68）**
1. **fact 可验证且动作可逆/已授权** → 走 R69 的 FLUID 路径，允许 resolution bonus；
2. **hermeneutic 且动作可逆** → 执行可逆动作 + 摊开解释（人可即时纠正），`λ = λ_floor(U_ale + U_epi^fact 未消解 + U_herm)`；
3. **hermeneutic 且动作不可逆** → 必须取得人类授权，或改选保守的可逆替代；人在 `τ_live` 内不可达时 → 安全保持 + 记录 + 升级求助。
特别地 `U_herm ≡ 0` 时第 1 条覆盖全域，HERMES 逐指令退化为 R69；再令 `U_epi^fact ≡ 0` 且 VoI≤成本则退化为 R68。

**定义 325（VLM 谄媚门 SCG）** 用盲描述 `d_0` 与见到假设后描述 `d_1` 的散度估计 `σ_syc`。若 `σ_syc > τ_syc` 或 VLM 的校准误差 `ECE_VLM > τ_vlm`，则 VLM **降级为仅提供语境**，不得贡献证据，仅可在 ILA 里留痕。

**定义 326（解释时效与双时间尺度契约）** 解释带年龄 `age(h) = t − t_reg`；`age > τ_age` 或情感/场景非平稳检测触发 ⇒ `U_herm` 重置为未消解，`ℋ_adm = ℋ`。快环（<2.6ms）只读缓存中的已注册解释；慢环（30–150ms）异步更新缓存。任何不可逆动作不得等待慢环（定义 310-ii）。

```python
    if best and best.score > 0: return best[0]
    return None                                    # 无利可图 → g_hold / 可逆动作

    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    slow = M.cache.read()                          # 只读已注册、未过期解释
    H_adm, U_herm = (slow.H_adm, consequence_diameter(slow.H_adm, M.policy)) \
                    if slow.valid(TAU_AGE) else (FULL_LATTICE, INF)
    # ---- 证伪优先：能排除最坏解释才去探 ----
    if U_herm > TAU_HERM and M.vlm_ok(SCG) and not slow_fault_suspect:
        g = M.cfp.choose_probe(H_adm, modes, o, M.budget, c_rev)
        if g is not None:
            y = M.execute_and_observe(g)           # 动作本身就是实验
            H_adm = M.cia.update_lattice(H_adm, y) # 跨 V/C 一致才显著更新
            U_herm = consequence_diameter(H_adm, M.policy)
    # ---- 三级退避（定义 324）----
    A = M.ach.propose(x_prime, H=M.vista.H)
    if U_epi > TAU_EPI and not slow_fault_suspect:      # 事实歧义 → R69 路径
        A = M.fluid_choose(A, modes, o)
    if U_herm <= TAU_HERM:
        lam = lam_floor(U_ale + (U_epi if not fact_resolved else 0.0))
    elif A in A_rev and M.ase.ok(A):                    # 可逆：做，但摊开解释
        lam = lam_floor(U_ale + U_epi + U_herm)
        M.expose_interpretation(H_adm, mode='reversible')   # 人可即时纠正
    else:                                               # 不可逆：要授权/换保守可逆
        A = M.authorize_or_alt(A, H_adm, tau_live=M.tau_live)
        lam = lam_floor(U_ale + U_epi + U_herm)
    A = A & M.ase.feasible(obs)                          # ASE 最后取交
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    M.ila.log(H_adm, M.bdp.hash, M.cca.rho, A, override=M.last_override)
    return k, lam, H_adm, (U_ale, U_epi, U_herm)
```

## 3. 推导

**引理 19（共性因下的一致性坍缩）** 设人的展示意图 `S ∈ {honest, mask}` 是各模态的共同父节点，`y_i = f_i(S, ε_i)` 条件独立于 S。若掩蔽时人选择令 `y_{1:k}` 全部自洽，则一致性事件在 `S=mask` 下概率≈1，故 `P(S=mask | y_{1:k} 一致)` 不随 k 下降；在确定性掩蔽极限，`P(错 | k 源一致) = P(S=mask | 先验)`，即 R69 引理 18 的 `δ_p·ρ^{k−1}` 退化为 `δ_p`。**系**：跨模态一致只在「跨过自愿/非自愿边界」时才提供独立信息；因此 CCA 的 `ρ_eff` 必须显式进入证书，否则「多模态验证」会给人虚假的确定感。

**引理 20（不对称代价下证伪优于确认）** 设损失不对称 `c_漏报 ≫ c_误报`，最坏解释 `h*` 先验较小但损失极大。熵式 `VoI` 会优先选择降低平均熵、从而**确认多数派**的探针，可能把 `h*` 留在 `ℋ_adm`；而 `VoF` 直接度量「最坏风险是否被排除」，故在 `c(·)` 相近时选 `VoF` 更大者。误差界：若探针 g 以概率 `p_f(g)` 证伪 `h*`，则其相对熵式的期望损失改进 ≥ `p_f(g)·Δ_loss(h*) − c(g)`，而熵式的改进口径不含 `Δ_loss(h*)`，二者在 `Δ_loss` 大时排序相反。**系**：越危险的误解，越应被**证伪**而非被「问得更确定」。

**引理 21（可逆性替代审问）** 若动作 `a ∈ 𝒜_rev`、撤销代价 `c_rev`，且人可覆写，则在任一 `h ∈ ℋ_adm` 下执行 a 的期望伤害 ≤ `c_rev + c_expose`（摊开解释被纠正的代价）。比较「先探询」：其代价 ≥ `c(g) + r·Δ_loss`（`r` 为探询后残余 `U_herm` 风险）。故当 `c_rev + c_expose < c(g) + r·Δ_loss` 时，**可逆行动优于一切探询**。**系**：在不可辨识且代价不对称处，「先做可撤销的小事并公开你的解释」比「追问一个可能被谎言污染的问题」更安全——这直接解释了为什么 `g_hold` 需要是语义性一等动作。

**定理 18（HERMES 对 R69/R68 的严格包含与安全单调性）** 在 A99（`U_herm` 可分解为 0 或非 0 且定义 313 可测）与 A100（人类接管时延 ≤ `τ_live`）下：
(i) 当 `U_herm ≡ 0` 时 HERMES 的第 1 级与 R69 逐指令相同；
(ii) 一般情形下 HERMES 执行的动作集 ⊆ `(FLUID 安全动作) ∪ 𝒜_rev ∪ 𝒜_auth`，且最后与 ASE 取交，故负向安全（不执行被 R69 判为不安全的动作）不退步；
(iii) 当 `A100` 成立时，任何不可逆动作都有人类授权或改选可逆替代，故期望伤害 ≤ R69；
(iv) 当 `A100` 失效时，上界失效——这正是本轮最大风险（§6）。

**定理 19（可辨识性壁垒：校准救不了坍缩）** 存在观测模型使 `h → o` 非单射：例如「不适」与「高度专注」产生完全相同的静止皱眉与沉默。则任何估计器的贝叶斯误差 ≥ `min(π_不适, π_专注) > 0`，且**完美校准（ECE=0）只是精确复现这个混合后验，不能降低误差**；任何把解释坍缩为 argmax 再执行不可逆动作的策略，期望损失 ≥ 该误差 × `Δ_loss`。反之，保留 `ℋ_adm`、执行可逆动作或请求授权的策略，其伤害被 `c_rev`（引理 21）界定。**系**：R69 的 MCG 校准门会**通过**（ECE 很小）却仍然不安全——因为问题在可辨识性而非校准；这正面修正了 R69 对自身最大风险（「模态未校准」）的定性。

**定理 20（解释权威的可纠错保证）** 若 (a) override 永远被接受并即时生效，(b) 仅在 `𝒜_rev ∪ 𝒜_auth` 上执行由未验证 `h` 辩护的动作，则人的纠正能力在任意时刻保持，系统不会在「纯解释学证据」上造成不可逆后果。代价是活性（liveness）：若人在 `τ_live` 内不可达且必须行动，则必须回落到保守可逆集合，可能牺牲任务完成率。该代价不可被消除，只能被显式记录与升级——**把不可消除的代价说清楚，是比假装能读懂人更诚实的工程姿态**。

**定义 310（总览与四不变式）** 反射环零写操作继承；双时间尺度（不可逆动作不得阻塞慢环，快环只读「年龄 ≤ τ_age 且已注册」解释）；非坍缩（不可逆动作不得仅凭 hermeneutic 证据坍缩执行）；解释权威（override 永接受、即生效，不得因推断情感移除人的控制）。

**定义 314–315（VLM-HG 与 BDP）** VLM 输出开放词表、span 接地的解释提案，角色是**证人**；先盲描述并提交哈希承诺，见到假设后的描述不计为证据（阻断谄媚确认）。

**定义 316（CCA）** 通道分「自愿展示 V」与「非自愿/后果 C」；估 `ρ_eff`。`ρ_eff ≥ ρ_max` ⇒ 一致性退化为单源（δ_p，而非 `δ_p·ρ^{k−1}`）；只有跨 V/C 的一致才算独立。

**定义 317（CFP/VoF）** `R(ℋ_adm)=min_a max_h E[L]`；`VoF(g)=R−E[R(更新后)]`；`g*=argmax[VoF−c]`，优先后果探针；`VoF−c≤0` ⇒ 不探，转 `g_hold`/可逆动作。

**定义 318–320（IAR/ASE/g_hold）** 未验证解释只驱动 `𝒜_rev ∪ 𝒜_auth`；ASE 硬约束（禁保护属性、禁 affect 操纵、隐私预算、控制权）；`g_hold` 是语义性一等动作，承诺最小、可逆、信息中性。

**定义 321–323（ILA/ℰ_herm/J_HERMES）** 哈希链解释账本；`ℰ_HERMES=ℰ_FLUID×ℰ_herm`；证书并入 `U_herm` 前后、`ρ_eff`、BDP 哈希、可逆状态、授权日志、谄媚分、ASE 判定。

**定义 324（三级退避）** fact 且可逆/已授权 → R69（允许 resolution bonus）；herm 且可逆 → 可逆动作 + 摊开解释；herm 且不可逆 → 授权或改保守可逆，人不可达 → 安全保持 + 记录 + 升级。`U_herm≡0` ⇒ 逐指令退化 R69。

**定义 325–326（SCG 与时效）** 盲/非盲描述散度估 `σ_syc`，越界则 VLM 降级为语境；解释带年龄，过期或非平稳 ⇒ `U_herm` 重置。快环不等待慢环。

```python
def decompose3(obs, fmp, vlm, cache):
    U_ale, U_epi, modes, _ = R69_decompose(fmp.sample(obs, K_of()), ...)
    if slow_loop_due(obs):
        d0 = vlm.blind_describe(obs)                 # 未泄露假设
        registry.commit(hash(d0, hash_obs(obs), now()))   # BDP
        H_adm = vlm.hypotheses(d0)                   # 格，非点后验
        cache.put(d0, H_adm, now())
    d0, H_adm = cache.get()
    if age(H_adm) > TAU_AGE or nonstationary(obs):
        H_adm = FULL_LATTICE
    U_herm = consequence_diameter(H_adm, policy)     # 只算"是否改动作"
    return U_ale, U_epi, U_herm, modes, H_adm

# IP-265 CCA：共性因审计
def audit_evidence(evidence):
    V, C = split_by_voluntariness(evidence)
    rho = estimate_shared_cause(V, C)
    return (single_source(V + C), rho) if rho >= RHO_MAX \
           else (cross_group_agree(V, C), rho)

# IP-266 CFP：证伪优先探询（非熵式 VoI）
def choose_probe(H_adm, modes, o, budget, c_rev):
    best = None
    for g in appraisal_probes(H_adm) + info_actions(modes):
        if not budget.allow(g) or not ase.ok(g) or not c_ras_wm.certify(g, o):
            continue
        score = (minimax_risk(H_adm) - expected_risk_after(H_adm, g)) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best[0] if best and best.score > 0 else None   # 否则 g_hold/可逆

# IP-267 HERMES 主闭环（快环与 R69 逐位相同）
def HERMES_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, ...)
    slow = M.cache.read()
    H_adm, U_herm = (slow.H_adm, consequence_diameter(slow.H_adm, M.policy)) \
                    if slow.valid(TAU_AGE) else (FULL_LATTICE, INF)
    if U_herm > TAU_HERM and M.vlm_ok(SCG) and not slow_fault_suspect:
        g = M.cfp.choose_probe(H_adm, modes, o, M.budget, c_rev)
        if g is not None:
            H_adm = M.cia.update_lattice(H_adm, M.execute_and_observe(g))
            U_herm = consequence_diameter(H_adm, M.policy)
    A = M.ach.propose(x_prime, H=M.vista.H)
    if U_epi > TAU_EPI and not slow_fault_suspect: A = M.fluid_choose(A, modes, o)
    if U_herm <= TAU_HERM:
        lam = lam_floor(U_ale + (U_epi if not fact_resolved else 0.0))
    elif A in A_rev and M.ase.ok(A):
        lam = lam_floor(U_ale + U_epi + U_herm)
        M.expose_interpretation(H_adm, mode='reversible')   # 人可纠正
    else:
        A = M.authorize_or_alt(A, H_adm, tau_live=M.tau_live)
        lam = lam_floor(U_ale + U_epi + U_herm)
    A = A & M.ase.feasible(obs)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    M.ila.log(H_adm, M.bdp.hash, M.cca.rho, A, override=M.last_override)
    return k, lam, H_adm, (U_ale, U_epi, U_herm)
```

## 4. 推导

**引理 19（共性因下的一致性坍缩）** 展示意图 `S∈{honest,mask}` 为各模态共同父节点，`y_i=f_i(S,ε_i)`。掩蔽时 `y_{1:k}` 自洽概率≈1，故 `P(S=mask|k 源一致)` 不随 k 下降；确定性极限 `P(错|一致)=P(S=mask|先验)=δ_p`，R69 的 `δ_p·ρ^{k−1}` 失效。**系**：一致性只在跨自愿/非自愿边界时提供独立信息，`ρ_eff` 必须进证书。

**引理 20（不对称代价下证伪优于确认）** `c_漏报 ≫ c_误报` 时，熵式 VoI 倾向选择「确认多数派」的探针，可能把最坏 `h*` 留在 `ℋ_adm`；`VoF` 直接度量最坏风险排除。若 g 以 `p_f(g)` 证伪 `h*`，其期望损失改进 ≥ `p_f(g)·Δ_loss(h*) − c(g)`；熵式口径不含 `Δ_loss(h*)`，在 `Δ_loss` 大时二者排序相反。**系**：越危险的误解越应被证伪，而非被「问得更确定」。

**引理 21（可逆性替代审问）** 若 `a∈𝒜_rev`、撤销代价 `c_rev`且人可覆写，则执行 a 的期望伤害 ≤ `c_rev+c_expose`；先探询代价 ≥ `c(g)+r·Δ_loss`。当 `c_rev+c_expose < c(g)+r·Δ_loss`，可逆行动优于一切探询。**系**：不可辨识处「先做可撤销的小事并公开解释」比「追问可能被污染的问题」更安全。

**定理 18（严格包含与安全单调性）** A99–A100 下：(i) `U_herm≡0` 时第 1 级与 R69 逐指令相同；(ii) 动作集 ⊆ FLUID 安全动作 ∪ `𝒜_rev` ∪ `𝒜_auth`，再与 ASE 取交，负向安全不退步；(iii) A100（接管时延 ≤ τ_live）成立时不可逆动作必授权或改可逆，期望伤害 ≤ R69；(iv) A100 失效则上界失效——即 §7 最大风险。

**定理 19（可辨识性壁垒：校准救不了坍缩）** 存在非单射观测（「不适」与「高专注」产生相同静止皱眉/沉默）。任何估计器贝叶斯误差 ≥ `min(π_不适, π_专注) > 0`；完美校准（ECE=0）只是精确复现混合后验，不能降误差；坍缩到 argmax 再执行不可逆动作的损失 ≥ 误差 × `Δ_loss`。保留 `ℋ_adm` + 可逆/授权则伤害被 `c_rev` 界定。**系**：R69 的 MCG 校准门会通过（ECE 小）却仍不安全——问题在可辨识性而非校准；正面修正 R69 对自身最大风险的定性。

**定理 20（解释权威的可纠错保证）** 若 override 永接受即生效、且未验证解释只驱动 `𝒜_rev∪𝒜_auth`，则人的纠正能力任意时刻保持，系统不会在纯解释学证据上造成不可逆后果。代价是活性：人不可达且必须行动时须回落到保守可逆集，可能牺牲完成率；该代价不可消除，只能显式记录与升级。

## 7. 本轮最大风险

**一句话**：HERMES 的全部伦理收益押在「**动作可逆 + 人类能及时接管**」这一前提上；而在最需要读懂情感的时刻——失能、儿童、紧急、不可逆动作——这个前提恰恰失效，于是「我不替你判断」会被说成尊重，实际是**礼貌的不作为**：系统既不作为、也不求助，把责任与风险原样退回给一个已经无法承担的当事人。

**次级风险与缓解**：
1. **VLM 幻觉仍能污染解释格**（开放词表的伪解释被「尊重」）→ BDP 预注册 + span 接地核验 + CCA 跨组一致 + 幻影解释定向扰动训练；
2. **`ρ_eff` 估计错误**导致把同源当独立 → 保守先验 `ρ_max` + 证书记录 + E302 压力测试；
3. **不可逆场景的活性缺失**（礼貌的不作为）→ 显式 `τ_live` 升级协议 + 保守可逆回退 + E313 专项 + 人类接管 SLA；
4. **隐私与尊严**（隐秘推断情感）→ ASE 隐私预算 + 私人场景禁推断 + 本地化处理 + E307；
5. **慢环时效失配**（过期解释驱动快环）→ `τ_age` + 非平稳检测 + 过期即重置 `U_herm` + 快环永不等待慢环。
