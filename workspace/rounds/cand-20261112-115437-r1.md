# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「少样本学习」×「传感器标定」）

> 第 57 轮把"证据是否可信"做成了分层判定：q_φ 从全体区域史摊销先验、证据按模态分账对账、操作者变成单向有界的信任状态机。但它默认了一个更底层、从未被写进形式化的前提：**产生证据的仪器本身是已知且不变的**——q_φ 的观测模型、XMC 的探针似然、FSE 的 EV-probe\* 校准，全都隐含"传感增益、零偏、外参、时延、非线性就是出厂证书上的那样"。真实部署里，标定不是一张静态证书，而是一个随温度、负载、磨损、固件与装配漂移的**状态**；更麻烦的是，标定误差是**系统性**的——它不会因为多探几次而平均掉，反而会让所有共享同一张证书的证据一起错。本轮两个灵感各补一刀：**少样本学习**把标定从"出厂一次性离线"变成"跨实例/跨环境摊销先验 + 少量参考点快速收敛"，并用可辨识性证书说清"哪些方向根本学不出来"；**传感器标定**把证据可靠性显式绑定到"标定状态"上——每条证据携带证书、有效期、漂移时钟与不确定度预算，证书失效则证据降级或拒收。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"仪器可辨识、标定可漂移检测、证据可溯源到证书的标定感知承诺"**。

核心矛盾：
- **H29（少样本 vs 可辨识性）**：标定参数常含规范自由度/不可辨识方向（单目尺度、IMU 零偏与重力耦合、外参尺度）；少样本无法凭空造出这些方向的信息，元先验只能"软填"——一个在零空间上过度自信的先验，恰好是最不可证伪的错误。
- **H30（标定 vs 世界）**：标定与世界估计强耦合，误差可互相抵消（把地形刚度低估与力传感器增益高估配成一对"自洽"解释）；同一张错证书下的多元证据会共同把错误世界证成"一致"，重复测量只压缩随机噪声、压不动共模偏差。
- **H31（标定经济 vs 安全）**：标定动作与世界探针抢同一份预算，且标定的收益是"之后所有证据"的、滞后的；延后标定省下眼前的探针，却积累一笔**标定债**——未标定方向的不确定度乘性污染后续全部承诺，直到某次不可逆接触一次性把它揭穿。

## 0. 直觉与动机

**灵感 1（少样本学习 → 摊销标定先验 + 可辨识性证书）**
直觉：每个传感器实例、每次换季都做全量标定太贵，不做又让证据带系统偏差。元学习换一种问法：**标定参数不从零估，而从"同类硬件/同批次/同类环境"的标定史里摊销**；现场只需少量参考观测（已知靶标、回环闭合、静止重力对齐、热平衡点）即可把后验收窄。但标定不是普通回归：它常有**规范自由度/不可辨识方向**。少样本造不出这些方向的信息，元先验只能软化地填。于是必须把参数空间拆成可辨识子空间与零空间：**可辨识方向用数据校准，零空间方向显式声明为 gauge 不确定度**，只许以最坏值进入风险。安全再一次不押在元先验上，而押在"可辨识性证书 + gauge 保守传播"上；元先验只买效率，不买真相。

**灵感 2（传感器标定 → 证书化证据与漂移监测）**
直觉：标定不是一次性事件，而是一条随时间演化的状态轨迹。把每条观测的不确定度拆成三本账：**aleatoric（随机噪声，可平均）、calibration-epistemic（标定不确定度，同证书证据共享，不可平均）、gauge（不可辨识，永远只能保守）**。每条证据携带 CSC 证书（θ̂、U、零空间、有效期 V_valid、漂移统计、参考物溯源）。漂移监测用残差序列序贯检验 + 独立参考（回环/已知靶标/跨模态）判定"证书是否过期"；一经过期，证据降权或拒收。关键洞察：**同一张错证书下探五遍，置信区间不会变窄**——这是第 57 轮"同一模态问五遍"的更底层版本，噪声可以平均，标定偏差不行。

**灵感 3（三灵感合流 → 标定-世界联合主动学习与标定债）**
直觉：标定动作和世界探针抢同一个预算，收益结构却不同：世界探针买"这块地"的局部信息，标定动作买"之后所有证据"的系统性折扣。把 PCE+ 的 VOI 从"世界后验"升级为"联合后验 (θ_cal, world)"上的风险下降；最优动作有时不是踩一脚，而是看一次已知靶标、走一段回环、做一次热平衡。延后标定不是免费：未标定方向的不确定度会乘性地污染后续所有承诺，记成**标定债**，承诺时按债务加宽风险。

**灵感 4（溯源与失效隔离 → 标定域回滚）**
直觉：证书的可信度不可能超过其参考链。把"证据→传感器→标定参考→方法→环境→证书"建成 provenance DAG，任一声明的 soundness 受最弱环节约束。若事后接触证伪了某张证书，只回溯作废"使用该证书"的证据，而非全盘回滚——**标定域回滚**比第 57 轮的证据域回滚更精确、误伤更少；它同时是防"标定投毒"的关键：假靶标/被操纵的参考会沿 DAG 污染一大片证据，必须以参考认证、多参考交叉、稳健有界影响估计限制单参考杠杆。

**灵感 5（系统合流 → 五类证据门加"证书有效性"前置）**
直觉：第 57 轮的五类证据在本轮统一加一道前置：EV-probe†（升级 EV-probe\*）要么有有效 CSC，要么以 gauge 最坏值加宽；EV-xmodal† 额外要求两条**标定路径互不共享**（否则共模标定误差会伪造一致性）；EV-human 的解释必须展示"读数来自哪张证书、还剩多少有效期"。承诺前多一个检查点：证书有效 ∧ 漂移统计合格 ∧ 溯源完整；任一不满足就退回"最坏 gauge 的保守带"，宁可慢、不可带着错证书赌。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（标定状态与证书 CSC）** 传感器组 S 的观测模型 o_t=h(ξ_t;θ_cal)+ε_t，ε_t~N(0,Σ_a)，θ_cal=(b,g,ext,τ_d,nl)（零偏/增益/外参/时延/非线性系数）。标定状态 s_cal=(θ̂,Σ_θ,G_null,V_valid,t_cal,ref_ids,unit_id,hash)，G_null=ker(J_A) 为参考集 A 下不可辨识子空间，J_A 为观测对标定参数的雅可比。证书 C_cal=(s_cal,U_cal)，U_cal=U_a⊕U_θ⊕U_gauge⊕U_ref（GUM 式合成）。证据只使用可辨识投影 Π_id=P_{G_null^⊥}；gauge 分量以 ±‖Π_null θ̂‖ 的最坏包络进入风险。有效性域 V_valid 声明证书仅在（温度,负载,姿态,龄期,固件版本）内成立，越界即失效。所有观测证据必须携带 C_cal，否则视为未标定证据。

**定义 140（元标定先验与可辨识性证书 MCP）** 元标定集 𝒟_cal={(u,e,A,θ̂_{u,e})}；摊销先验 q_ψ(θ_cal|z)，z=(硬件修订/批次/环境/初始自观测)。少样本标定选择参考集 A（|A|≤k_cal）：A\*=argmax_{A:rank(J_A)≥r_min} I(Π_id θ_cal;o_A|q_ψ)−λ·cost(A)，即以 D-最优/信息增益选点并强制可辨识秩。证书声明四项：(i) 留出单元的校准覆盖 ≥1−α_cal；(ii) 可辨识秩 r_id 与 G_null；(iii) 样本效率 k_cal\*(ε)=min{k:tr Σ_θ^{(k)}≤ε}；(iv) 单元 OOD 门 n_unit(z)>θ_unit（新硬件修订/未知传感器）⇒ 禁用摊销先验，退回无信息先验+现场自标定，无法自标定则拒收相关证据。严禁把 q_ψ 在 G_null 上的输出当作已知；元先验只在 Π_id 上被采信。

**定义 141（漂移监测 CDM）** 残差 r_t=o_t−h(ξ_t;θ̂)；有效标定下 r_t~N(0,Σ_a+JΣ_θJ^T)。序贯统计量 g_t=GLR/CUSUM(r_{1:t})。漂移判定 g_t>h_d 或独立参考交叉检验失败 ⇒ 证书置 suspect。归因器区分两类失效：环境越界（V_valid 不满足）⇒ 切环境域并放宽门限；真实漂移（磨损/温漂/固件）⇒ 证书作废并计标定债。漂移期间证据权重乘 κ_drift<1，不可逆接触一律禁用。

**定义 142（标定感知证据门 CEG）** 证据 e 携带 C_cal(e)、时间戳与所用传感器链。有效判定 valid(e)=(t−t_cal≤τ_recal)∧env∈V_valid∧g_t≤h_d∧unit_id 匹配。似然对 θ_cal 积分而非插值：P(o|world)=∫P(o|θ_cal,world)q(θ_cal)dθ_cal；同一证书下 n 条证据的有效样本量 n_eff=n/(1+(n−1)ρ_cal)，ρ_cal 为共模相关系数上界。证据类升级：EV-probe† 须 valid 或挂 gauge 包络；EV-xmodal† 另须 calibration-disjoint（两路径无共享参考/传感器）；EV-human 的解释须含证书来源。不可逆接触硬规则：证据链上所有传感器证书 valid 或以 gauge 包络最坏值仍满足 δ_f，否则拒绝。

**定义 143（标定-世界联合主动学习 CWA）** 联合后验 p(θ_cal,w|history)；动作集 A=A_cal∪A_probe∪A_reroute；VOI(a)=E_p[Δrisk(commit)]−cost(a)。标定动作（观测已知靶标、回环、静止重力对齐、热平衡采样）只经"收窄有效证书/降低系统不确定度"影响系统；世界探针只经"收窄局部后验"影响。标定债 B_cal(t)=Σ_{未覆盖方向}‖Π_null Σ_θ^{1/2}‖ 的累积（或未覆盖 V_valid 的风险积分），承诺时以 B_cal 加宽 P_fail。预算 k_cal+k_probe+k_cons≤k_max，按边际 VOI 分配。

**定义 144（标定溯源与失效隔离 CPT）** provenance DAG 𝒢_cal：sensor→reference→method→environment→certificate→evidence。声明 soundness 受最弱链路约束：U(claim)≥max_{ℓ∈path}U(ℓ)。参考物认证等级 auth_ref∈{verified,cross-checked,untrusted}；untrusted 参考不得单独支撑不可逆接触。事后证伪证书 c ⇒ 仅作废 desc(c) 中引用 c 的证据并重算受影响区域（标定域回滚），不牵连其他证书；稳健估计限制单参考杠杆（影响函数有界），多参考交叉一致性检验检出投毒。

## 2. 关键算法伪代码（完整版见产物区）

```python
def meta_calibrate(S, ctx, refs, meta):             # IP-139/140 合流
    z = calib_context(S, ctx)
    if meta.unit_ood(z) > theta_unit:               # 新硬件/未知传感器
        return self_calibrate(S, refs, prior='noninformative')
    A = greedy_d_optimal(refs, meta.q_psi, z,
                         constraint=lambda A: rank(jac(A)) >= r_min)
    theta = meta.q_psi(A, z)
    G = null_space(jac(A))                          # 不可辨识方向显式声明
    U = compose_uncertainty(aleatoric, theta,
                            gauge=project(theta, G), refs=refs)
    return CalCert(theta=theta, G_null=G, U=U,
                   V_valid=validity_region(ctx), t_cal=now(), ref=refs)

def calibration_aware_likelihood(o, world, cert):
    if not valid(cert, o.t, o.env):                 # 过期/越界 → 最坏包络
        return integrate(theta, P(o | theta, world) * cert.gauge_posterior(theta))
    return integrate(theta, P(o | theta, world) * cert.posterior(theta))

def drift_monitor(cert, residuals, refs):
    g = cusum_glr(residuals)
    if g > h_d or not cross_ref_ok(refs):
        cause = attribute(residuals, cert.V_valid)
        cert.state = 'suspect' if cause == 'drift' else 'env_shift'
        if cause == 'drift': cert.debt += gauge_debt(cert)
        return cert, cause
    return cert, 'ok'

def calibration_world_voi(a, joint, cert):
    scope = 'all_future' if a in CALIB_ACTIONS else 'local'
    return E_risk_reduction(joint, a, scope=scope) - cost(a)

def calibration_evidence_gate(e, certs):            # IP-142: 证书前置
    if not valid(certs[e.sensor], e.t, e.env) and not gauge_bounded(e, certs):
        return ('reject', 'calibration_invalid', e)
    if e.ev == 'EV-xmodal' and not calibration_disjoint(e.paths, certs):
        return ('reject', 'common_mode_calibration', e)
    if e.irreversible and not all(valid(certs[s], e.t, e.env) for s in e.sensors):
        return ('reject', 'irreversible_needs_valid_cert', e)
    e.n_eff = e.n / (1 + (e.n - 1) * rho_cal(certs[e.sensor]))
    return ('ok', e)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| CSC | O(\|S\|³)/次标定；O(\|S\|²)/证据 | O(\|S\|²) | 零空间显式、gauge 包络保守 |
| MCP | O(d_ψ+\|refs\|·d)/步 | O(\|𝒟_cal\|) 静态 | 覆盖声明诚实、单元 OOD 漏检 ≤δ_unit |
| CDM | O(1)/样本 | O(窗口) | 漂移检出/归因、V_valid 诚实 |
| CEG | O(\|e\|)/证据 | O(\|e\|) | 似然积分不插值、n_eff 计共模 |
| CWA | O(\|A\|·(C_VOI+d))/检查点 | O(\|A\|) | 只经收窄证书或更保守动作 |
| CPT | O(V+E) 回滚 | O(V+E) | 溯源完整、回滚不多伤 |

**正确性定理（Calibration-Scoped Soundness, CSS 概要）**：继承 A33–A40，加 (A41) 元标定在可辨识子空间上的覆盖声明诚实、单元 OOD 漏检 ≤δ_unit、G_null 声明完整、gauge 包络有效；(A42) 漂移监测检出/误报与归因诚实、V_valid 声明诚实；(A43) 证据似然对 θ_cal 积分且 n_eff 计共模相关，禁止 plug-in；(A44) provenance DAG 诚实、参考物认证/有界影响成立、标定域回滚完备。则：(i) 承诺失效率 ≤δ_f+ε_meta(k)+ε_cal(k_cal)+δ_drift+δ_unit·α_cal+δ_gauge+δ_probe+ε_h；(ii) 单调性：标定动作只能经"证书更窄更有效"或"动作更保守"影响系统，不存在升险路径，不可逆接触在证书失效时被硬拒；(iii) CWA 在 k_cal+k_probe+k_cons 内终止于 {承诺,绕行,重标定,L2 协商,安全停}。

## 6. 本轮最大风险

**一句话**：本轮把"证据可信"的前置条件压到一张标定证书上，最大的新风险是**证书被当作信任令牌**——一张看起来合法但源自坏参考、未辨识 gauge 或被投毒的证书，会以"已标定"的名义把系统性偏差洗白成证据，而共模误差让一次坏标定同时污染一大片承诺；必须以 gauge 显式化的不确定度、漂移监测、参考溯源与标定域回滚四重护栏，让证书只证明"误差有界"，绝不证明"误差为零"。

### IP-139 + IP-140 CSC/MCP（标定状态证书与元少样本标定）

```python
def meta_calibrate(S, ctx, refs, meta):
    z = calib_context(S, ctx)                     # 硬件修订/批次/环境/初始自观测
    if meta.unit_ood(z) > theta_unit:             # 新硬件/未知传感器：不信先验
        return self_calibrate(S, refs, prior='noninformative')

    A = select_refs_d_optimal(refs, meta.q_psi, z,
                              k_max=k_cal,
                              constraint=lambda A: rank(jac(A)) >= r_min)
    theta = meta.q_psi(A, z)                      # 摊销后验（只在 Π_id 上采信）
    J = jac(A)
    G = null_space(J)                             # 显式零空间：gauge 方向
    U = compose_uncertainty(aleatoric=Sigma_a,
                            theta=meta.sigma(A, z),
                            gauge=gauge_envelope(theta, G),
                            ref=ref_uncertainty(refs[A]))
    return CalCert(theta=theta, Sigma=meta.sigma(A, z), G_null=G,
                   U=U, V_valid=validity_region(ctx),
                   t_cal=now(), ref_ids=refs[A], unit_id=S.unit_id)

def select_refs_d_optimal(refs, q_psi, z, k_max, constraint):
    A = []
    while len(A) < k_max:
        cand = max(refs - set(A),
                   key=lambda r: info_gain(project_identifiable(jac(A + [r])),
                                           q_psi, z) - cost(r))
        if not constraint(A + [cand]): break      # 秩不足则宁可不加
        A.append(cand)
    return A

def caveat_zero_space(theta, G):
    # 零空间分量永不当作已知，只进 worst-case 包络
    return ConicBound(direction=G, radius=norm(project(theta, G)))
```

### IP-141 CDM（漂移监测与归因）

```python
def drift_monitor(cert, obs_stream, refs):
    r = residuals(obs_stream, cert.theta)
    g = cusum_glr(r, cert.Sigma)
    cross_ok = all(cross_reference_ok(ref, obs_stream) for ref in refs)
    if g <= h_d and cross_ok:
        return cert, 'ok'

    if not in_validity(cert.V_valid, obs_stream.env):
        cert.domainswitch(obs_stream.env)         # 环境切换 ≠ 标定坏了
        return cert, 'env_shift'

    cert.state = 'suspect'                        # 真漂移：作废并计债
    cert.debt += gauge_debt(cert)
    cert.evidence_weight *= kappa_drift
    cert.irreversible_block = True
    return cert, 'drift'
```

### IP-142 CEG（标定感知证据门）

```python
def calibration_aware_likelihood(o, world, cert):
    if valid(cert, o.t, o.env):
        return integrate(t, P(o | t, world) * cert.posterior(t))
    # 证书失效：只用 gauge/漂移最坏包络，绝不用点估计
    return integrate(t, P(o | t, world) * cert.worst_case_posterior(t))

def calibration_evidence_gate(e, certs, P_fail_budget):
    c = certs[e.sensor]
    ok_valid = valid(c, e.t, e.env)
    if not ok_valid and not gauge_bounded_below(c, e, P_fail_budget):
        return ('reject', 'calibration_invalid', e)

    if e.ev == 'EV-xmodal':
        if not calibration_disjoint(e.paths, certs):   # 共模标定→假一致
            return ('reject', 'common_mode_calibration', e)
        if e.level != 'L1':
            return ('reject', 'xmodal_on_irreversible', e)

    if e.irreversible and not all(valid(certs[s], e.t, e.env) for s in e.sensors):
        return ('reject', 'irreversible_needs_valid_cert', e)

    e.n_eff = e.n / (1 + (e.n - 1) * rho_cal(c))
    e.cert_id = c.hash
    return ('ok', e)

def gauge_bounded_below(cert, e, budget):
    # 以零空间最坏包络重算最坏情况失效概率
    return worst_case_fail(cert.gauge_envelope, e) * (1 + cert.debt) <= budget
```

### IP-143 CWA（标定-世界联合主动学习，嵌入 PCE++）

```python
def probe_calibrate_commit(x0, M, task, budget, consent, personas, certs):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        certs = refresh_certs(certs, cp.env)      # 环境域切换检查
        for c in certs.in_scope(cp):
            if c.state == 'suspect':
                c = re_calibrate(c, known_targets(cp), budget)
        sigma = foothold_schedule(x0, cp, M)
        R = schedule_risk(sigma, M, certs=certs, debt=B_cal(certs))
        while select_gait(R) == 'halt' and budget.left > 0:
            a = argmax(admissible_actions(cp, M, certs),
                       key=lambda a: calibration_world_voi(a, joint_posterior(M, certs)) - cost(a))
            if calibration_world_voi(a, joint_posterior(M, certs)) < theta_voi:
                break
            if a in CALIB_ACTIONS:
                certs = execute_calibration(a)    # 只经“证书更窄更有效”影响系统
            else:
                M, _, D = xmodal_fuse(M, cp.region, execute_probe(a, cap=F_abs))
                if D > theta_D and 'consensus' not in cp.done:
                    M, _, D = xmodal_fuse(M, cp.region,
                                          execute_probe(most_disagreeing_probe(M, cp.region),
                                                        cap=F_abs))
                    cp.done.add('consensus')
            budget.spend(a)
            R = schedule_risk(foothold_schedule(x0, cp, M),
                              M, certs=certs, debt=B_cal(certs))

        g = select_gait(R)
        ev = tag_evidence_calibrated(sigma, M, certs, contact_level(cp))
        if g != 'halt' and calibration_evidence_gate(
                core_contact(cp), certs, P_fail_budget)[0] == 'ok':
            sched.append(commit(sigma, g)); log.append(ev); continue

        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M, certs=certs)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth),
                                 certs=certs)      # 协商时展示证书来源与剩余有效期
    return sched, log, M, certs
```

### IP-144 CPT（溯源、标定域回滚与抗投毒）

```python
def build_provenance(cert, refs, method, env):
    return DAG(nodes=[cert.sensor, refs, method, env, cert.cert_id],
               edges=[(cert.sensor, cert.cert_id),
                      (refs, cert.cert_id),
                      (method, cert.cert_id),
                      (env, cert.cert_id)])

def weakest_link_bound(claim, G_cal):
    return max(U(node) for node in G_cal.path_to(claim))

def provenance_rollback(falsified_cert, G_cal, evidence_db, M):
    scoped = [e for e in evidence_db if falsified_cert.cert_id in e.cert_chain]
    for e in scoped:
        e.invalidate(reason='calibration_falsified')
    for r in affected_regions(scoped):
        M.recompute(r, exclude=scoped)            # 只撤该证书的证据，不牵连他人
    G_cal.mark_falsified(falsified_cert)
    return evidence_db, M

def robust_calibration(references):
    # 有界影响估计 + 多参考交叉，限制单参考杠杆
    thetas = [estimate(ref) for ref in references]
    return huber_aggregate(thetas), cross_consistency(thetas)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSC | O(\|S\|³)/次标定；O(\|S\|²)/证据 | O(\|S\|²) | 零空间显式、gauge 包络保守（A41） |
| MCP | O(d_ψ+\|refs\|·d)/步 | O(\|𝒟_cal\|) 静态 | 可辨识覆盖诚实、单元 OOD 漏检 ≤δ_unit（A41） |
| CDM | O(1)/样本 | O(窗口) | 漂移检出/归因、V_valid 诚实（A42） |
| CEG | O(\|e\|)/证据 | O(\|e\|) | 积分不插值、n_eff 计共模（A43） |
| CWA | O(\|A\|·(C_VOI+d))/检查点 | O(\|A\|) | 只经收窄证书或更保守动作（A44） |
| CPT | O(V+E) 回滚 | O(V+E) | 溯源完整、回滚不多伤（A44） |

**正确性定理（Calibration-Scoped Soundness, CSS）**
继承 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）；本轮新增：**(A41)** 元标定在可辨识子空间上的覆盖声明诚实（留出单元 ≥1−α_cal），单元 OOD 漏检率 ≤δ_unit，`G_null` 声明完整，gauge 包络为真上界；**(A42)** 漂移监测检出/误报与"环境切换 vs 真漂移"归因诚实，`V_valid` 声明诚实；**(A43)** 证据似然对 `θ_cal` 积分而非点代入，`n_eff` 公式覆盖共模相关上界 `ρ_cal`；**(A44)** provenance DAG 诚实、参考物认证或有界影响成立、标定域回滚完备且不牵连无关证据。则：

1. **标定感知承诺健全性**：
   `P(fail) ≤ δ_f + ε_meta(k) + ε_cal(k_cal) + δ_drift + δ_unit·α_cal + δ_gauge + δ_probe + ε_h`
   其中 `ε_cal` 为标定后验覆盖误差，`δ_gauge` 为不可辨识零空间的最坏包络贡献，`δ_drift` 为漏检漂移贡献；EV-xmodal† 仅在 L1 且 `calibration_disjoint` 时贡献 `δ_xm`。
2. **不变式（证书只证有界，不证为零）**：任何证据的 `U` 不得小于其 provenance 最弱链路的 `U`；证书失效时似然必须退化为 worst-case 包络，禁止回退到点估计。
3. **交互单调性**：标定动作、漂移降权、标定债加宽只能经 (a) 证书更窄更有效或 (b) 动作更保守（不可逆禁用、重标定、绕行、降档、L2 超时缩短）影响系统，不存在升险路径。
4. **终止性与部署界**：每检查点 `k_cal+k_probe+k_cons≤k_max`，CWA 终止于 {承诺,绕行,重标定,L2 协商,安全停}；对检查点取联合界：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + ε_cal(k_cal) + δ_drift + δ_unit·α_cal
                    + δ_gauge + δ_probe + ε_h + δ_xm·1[L1∧disjoint])
             − P(𝒢_cal 溯源缺失) − P(标定域回滚失败) − P(τ_int∧τ_mm 超时∧安全停失效)
```

关键：**少样本给效率、可辨识性给边界、gauge 给保守**；**漂移监测把一次性证书变成可失效状态**；**n_eff 与 calibration-disjoint 让"多测几次"和"多模态一致"都不能伪装成独立证据**；**标定域回滚把失效隔离在一张证书内**。

## 6. 本轮最大风险

**一句话**：本轮把"证据可信"的前置条件压到一张标定证书上，最大的新风险是**证书被当作信任令牌**——一张看起来合法但源自坏参考、未辨识 gauge 或被投毒的证书，会以"已标定"的名义把系统性偏差洗白成证据，而共模误差让一次坏标定同时污染一大片承诺；必须以 gauge 显式化的不确定度、漂移监测、参考溯源与标定域回滚四重护栏，让证书只证明"误差有界"，绝不证明"误差为零"。
