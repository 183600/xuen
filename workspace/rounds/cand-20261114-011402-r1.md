# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「视觉语言模型」×「真实世界泛化」）

> R69 把不确定性拆成 aleatoric 与 epistemic，并让系统学会「问」。但它有一个未言明的前提：**能被策略采样出来的模态集合，就是这个世界可能性的全部**。真实世界泛化恰恰打破这个前提——失败往往不是「两个已知模态选哪个」，而是「我自信地生成了一个训练分布里很合理、但在真实世界物理上错误的模态」。此时 H_mode 很低、流似然很高、R69 的 λ 很松，系统不是「犹豫」，而是**自信地错**。
>
> 本轮两个灵感补上这个缺口：
> - **视觉语言模型**提供开放词表的语义先验，能把「没见过的实例」锚定到「见过的概念邻域」，并给出可检验的物理属性假设；
> - **真实世界泛化**要求我们把「语义熟悉」与「物理熟悉」分成两个独立坐标——真实失败集中在二者不一致的 off-diagonal（看着熟、物理变）。
>
> 核心命题：**VLM 只做提案者，不做权威；它把开放世界的新颖性转成一组可证伪的物理假设，由 R69 的安全信息动作去接地检验，再由分层共形预测与因果等价图决定这份「泛化」是否配得上放宽 λ。** 命名 **TERRA-RAS**（Test-time Epistemic Real-world Risk Adaptation with semantic-physical grounding）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我以为我认识的世界，真的还是那个世界吗**」——泛化不是把训练分布铺得更大，而是知道自己的认识在哪儿失效。

## 0. 直觉与动机

**灵感 1（VLM → 开放世界的语义先验，而不是另一个传感器）**
直觉：R69 的流策略能告诉你「在这个观测下我会怎么动」，却无法告诉你「这个观测里的东西我到底认不认识」。VLM 的独特价值不是多一路模态，而是把**开放词表的概念结构**带进来：即使没见过具体实例，它也能用「杯子 / 抽屉 / 湿滑地面 / 疲惫的人」这类概念，把当前观测锚定到一个**可迁移的语义邻域**，并给出与之相关的物理属性先验（可抓、可拉、易碎、会滑）。这把「分布外」从「像素陌生」变成「概念距离」。

**灵感 2（真实世界泛化 → 失败集中在语义-物理的 off-diagonal）**
直觉：sim-to-real 的经典失败不是「完全没见过」，而是**看着熟、物理不一样**：同样的杯子，这次装满水；同样的抽屉，这次卡住了；同样的地面，这次有一层油；同样的人，这次不配合。此时 R69 的流似然与标定残差都可能正常（观测在训练分布附近），但真实动力学已经变了。**语义熟悉度与物理熟悉度是两个独立坐标**；R70 的核心对象是二者的不一致（SPD），而不是任一单独通道。

**灵感 3（VLM 是提案者，不是权威）**
直觉：VLM 会幻觉、会被对抗纹理骗、会把视觉相似当成物理等价。如果允许它直接决定 λ 或直接执行动作，等于把一个在互联网数据上训练出来的模型变成安全权威。R70 的纪律：**VLM 只产生可证伪的物理假设**（「这个物体是刚性的、质量在 [0.2,0.5] kg」），由 R69 的安全信息动作去检验；只有通过接地测试、且落在共形认证分层内的假设，才允许换取 resolution bonus。

**灵感 4（泛化需要证书，不是平均分）**
直觉：真实世界泛化最危险的形态是「平均成功率上升、尾部灾难增加」。R69 的 resolution bonus 是效率收益，来自「我能想象到的模态」，不能自动外推到「我还没想象到的世界」。R70 用**分层共形预测 + 因果等价图**给泛化发证书：在一个可交换的「已接地分层」内，给出分布无关的风险上界；跨出分层，λ 立刻回到 R69 的保守底。证书不是装饰，而是放宽 λ 的**唯一货币**。

**灵感 5（测试时纪律 → 泛化不能靠实时写权重）**
直觉：最自然的「真实世界适应」是测试时更新，但这会同时违反 R69 的零学习写操作不变式，并制造不可审计的漂移。R70 把适应限制在**只读的语义缓存 + 有界情景记忆 + 离线审计后的等价图更新**：实时路径不改权重，只改「相信哪个已认证假设」；任何持久改变都必须离线、可复现、过因果检验。这样 VLM 的失败最多让系统变保守，不会让系统悄悄变错。

**灵感 6（对 R69 的理论姿态：新层是旧层的严格泛化）**
直觉：R69 把 R68 包含为「永不交互」边界；R70 必须把 FLUID 包含为「无新颖性、无迁移」边界。否则每加一层就多一个需要独立信任的黑箱。定义 325 明确：当 N_sem=N_phy=0 且不启用等价图迁移时，TERRA 逐指令等价于 FLUID；再叠加 VoI≤成本，则逐指令等价于 R68。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（TERRA-RAS 总览）** TERRA-RAS = (VSP, SPN, GHT, CTP, AEG, TERRA-WM†)。继承 R69 定义 293 的三不变式，并新增三条：
(i) **语义权限分离**：VLM 只能提出假设，不能直接设置 λ、不能直接执行动作；任何 λ 放宽必须同时具备物理接地证据与有效证书；
(ii) **支撑纪律**：在未认证分层之外，λ 不得低于 R69 的 FLUID 底线；
(iii) **可审计性**：每条语义主张、每次探针、每个等价图边都写入审计缓冲，可离线复现。

**定义 311（语义状态与开放词表先验）** 冻结 VLM f_V: o_t → (c_t, e_t, G_t)，其中 c_t ∈ Δ(𝒞_open) 为开放词表概念分布，e_t ∈ ℝ^{d_e} 为语义嵌入，G_t 为场景关系图。语义熵 H_sem = −Σ_c c_t(c) log c_t(c)。同时由概念到物理属性的先验 A_sem(c) → P(φ | c)，φ = (m, μ, κ, fragility, …) 为质量、摩擦、刚度、易碎性等物理属性向量。VLM 冻结，梯度不回传。

**定义 312（语义新颖度 / 物理新颖度）** 训练支撑集 𝒮_train；语义新颖度 N_sem(o) = 语义嵌入到 𝒮_train 的校准化 k-NN 非一致性分（见定义 318），物理新颖度 N_phy(o) = w₁·a_score(o) + w₂·|r_res(o)| + w₃·‖ε_prop(o)‖，其中 a_score 为 R69 流似然异常分，r_res 为标定残差，ε_prop 为本体感受预测误差。二者分别阈值化，得到四象限：Q00 已知-已知；Q10 仅语义新颖（外观/标签漂移）；Q01 语义伪装（看着熟、物理变，风险最高）；Q11 真正新颖。

**定义 313（语义-物理不一致度 SPD）** 由接地测试或本体感受得到物理属性估计 φ̂_phy；定义单状态不一致度 SPD(o) = D(A_sem(c_t) ‖ δ_{φ̂_phy})（归一化 Mahalanobis 距离）。对 VLM 判定为语义等价的两个状态 o₁,o₂，定义成对不一致度 SPD_pair = ‖φ̂_phy(o₁) − φ̂_phy(o₂)‖ / s_φ。**SPD 是本轮的核心新信号：它测的不是「像不像」，而是「被当成一样的东西，物理上是否真的一样」。**

**定义 314（语义校准门 SCG）** VLM 的概念/属性先验需校准：分层共形覆盖率与语义 ECE。若覆盖率低于 1−α 或 ECE > τ_sem，则禁用语义通道，整体退化为 R69 FLUID。SCG 是 R69 MCG（模态权重校准）在「概念层」的对应物。

**定义 315（接地假设空间）** ℋ = {(h_c, Φ_h, afford_h, ŷ_h)}，其中 h_c 为概念假设，Φ_h ⊂ ℝ^{d_φ} 为物理属性区间，afford_h 为可执行动作集合，ŷ_h 为对探针结果的预测分布。VLM 给出先验 p_V(h) ∝ exp(−λ_V·dist(e_t, e_h))；物理交互给出似然 p(y | h, g)。

**定义 316（接地测试 GHT）** 选择信息动作 g ∈ 𝒜_info，使期望信息增益 IG(φ; y | g) 最大，同时满足 R69 定义 302 的 C-RAS-WM 认证与交互预算。执行后更新 p(h | y, g)。**接受判据**：后验集中度 max_h p(h | y,g) ≥ 1−δ_H，且后验预测检查不矛盾（探针观测落在 ŷ_h 的高密度区）。不满足则假设保持未接地。

**定义 317（物理等价图 AEG）** 节点 u = (c, context)；边 e = (u,v) 附带证书。**边只有在设计干预能以功效 ≥ 1−β、显著水平 α_eq 拒绝「两者动力学差异 > δ_eq」时才可加入**；仅语义相似绝不加边。只有带证书的边允许迁移策略、经验与先验。

**定义 318（分层共形迁移预测 CTP）** 非一致性分 s(o, φ) = SPD(o) + λ_a·a_score(o) + λ_p·N_phy(o)。按 context 分层（Mondrian conformal），在真实世界校准集 D_cal 上构造预测集 C_α(o)，满足在层内可交换假设下 P(φ ∈ C_α(o)) ≥ 1−α，且对层内任意有界损失 ℓ 有风险控制 E[ℓ] ≤ E_cal[ℓ] + α·L_max + δ。若 |C_α(o)| > 1 或 C_α(o) = ∅，则迁移状态为**未认证**。

**定义 319（分层风险控制与 λ_TERRA）** 定义迁移不确定度 U_transfer = 0，当且仅当 o 落在已认证分层、C_α(o) 为单点、且 GHT 接受；否则 U_transfer = U_base（R69 的未消解上界）。风险缩放：
λ = λ_floor(U_ale + U_epi_unresolved + U_transfer)，
仅当 U_transfer = 0 时才允许 R69 的 resolution bonus。**没有证书，就没有 bonus。**

**定义 320（异步语义调度与陈旧度）** VLM 不在实时关键路径：语义守护线程以 ≤ f_V Hz 更新缓存，实时路径使用蒸馏语义头（<0.1 ms）。缓存年龄 age_sem > τ_sem 或查询预算耗尽时，N_sem 视为 unknown（按高新颖处理），语义通道不得放宽 λ。**陈旧语义不能换来安全裕度。**

**定义 321（真实世界泛化证书 J_TERRA）** J_TERRA = (J_FLUID, sem_ECE, N_sem, N_phy, SPD, conformal_coverage_hat, stratum_id, GHT_log_hash, AEG_edge_ids, staleness, terra_ver)。Valid ⇔ Valid(J_FLUID) ∧ SCG 通过 ∧ 分层已认证 ∧ 无陈旧 ∧（若使用 bonus）GHT 接受。

**定义 322（语义威胁模型 ℰ_sem）** VLM 幻觉、对抗纹理/遮挡、语义伪装（视觉熟悉但物理危险）、概念漂移、预训练/标注投毒、场景文字提示注入。并入 R69：ℰ_TERRA = ℰ_FLUID × ℰ_sem。

**定义 323（测试时适应纪律）** 实时路径：不写梯度、不改持久图、不新增未认证等价边；只允许有界情景记忆检索与对预认证假设的信念更新。持久更新（AEG 加边、共形重校准）必须离线、有干预证据、过审计。称为**只读适应**。

**定义 324（双通道序贯检验）** 将语义先验与物理证据合成 e-value：E_t = Π_{i≤t} (p(y_i | h₁, g_i) / p(y_i | h₀, g_i))，配合先验 odds。用 Ville 不等式做 anytime-valid 的错误认证控制，允许在不膨胀 α 的前提下提前停止探针。

**定义 325（退化边界）** 若 N_sem = N_phy = 0、AEG 不启用迁移，则 TERRA 逐指令等价于 FLUID；若再满足 R69 的 VoI(g*) ≤ c(g*) 或 ECE 越界，则逐指令等价于 R68。**R68 ⊂ FLUID ⊂ TERRA，且安全侧逐层不变弱。**

**定义 326（认证泛化半径）** r_cert(o) = 在 (语义, 物理) 联合空间中，CTP 覆盖率仍成立且 AEG 存在认证路径的最大半径。r_cert 是「我可以从当前状态安全外推多远」的显式度量；越界即保守。

# IP-264 VSP：冻结 VLM 语义提案（异步）+ 蒸馏语义头（实时）
class SemanticProposer:
    def propose(self, o_t):
        c, e, G = self.vlm(o_t)                    # 低频，缓存
        H_sem = entropy(c)
        H = sample_hypotheses(c, G, self.A_sem)    # 概念 -> 物理属性区间
        return SemanticState(c, e, G, H_sem, H)

# IP-265 SPN：语义/物理新颖度与四象限
def novelty_split(o, sem, policy):
    N_sem = conformal_semantic_score(sem.e, policy.train_support)
    a     = -policy.log_likelihood(o.action, o.obs)      # R69 FMA
    N_phy = w1*a + w2*abs(o.r_res) + w3*norm(o.eps_prop)
    return quadrant(N_sem, N_phy), N_sem, N_phy

# IP-266 GHT：把语义假设变成安全探针
def ground_hypotheses(H, o, budget):
    if not budget.allow_probe(): return None
    g = argmax(info_gain_phi(H, g) - cost(g)
               for g in probe_candidates(H)
               if c_ras_wm.certify_info(g, o))           # R69 认证
    y = execute_safe(g)
    H_post = bayes_update(H, y, g)
    ok = concentration(H_post) >= 1 - DELTA_H and predictive_check(H_post, y)
    return H_post if ok else None

# IP-267 CTP：分层共形迁移预测
def transfer_set(o, stratum, calib):
    s = SPD(o) + la*a_score(o) + lp*N_phy(o)
    C = mondrian_conformal(calib[stratum], s, alpha)
    return C if len(C) == 1 else None                   # 多点/空 => 未认证

# IP-268 AEG：只在干预拒绝等动力学后才加边
def certify_edge(u, v, budget):
    if not budget.allow_intervention(): return None
    if reject_equal_dynamics(u, v, delta_eq, alpha_eq, power=1-BETA):
        return None                                     # 不能证明等价
    return Edge(u, v, evidence=intervention_log)

# IP-275 主闭环（继承 R69，仅在支撑边界处插入 TERRA 层）
def TERRA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    sem  = M.vsp.cached_or_query(o)                     # 异步；可能 stale
    q, N_sem, N_phy = M.spn.novelty_split(o, sem, M.fmp)

    # 1) 已知-已知：完全走 R69
    if q == Q00 and not M.stale(sem):
        return M.fluid_round(obs)                       # 逐指令等价

    # 2) 语义伪装 / 物理新颖：先探针接地，再谈 bonus
    U_transfer = M.base_transfer_penalty(q)
    if q in (Q01, Q11) and not M.stale(sem):
        H_post = M.ght.ground_hypotheses(sem.H, o, M.budget)
        if H_post is not None:
            strat = M.ctp.stratum(o)
            C = M.ctp.transfer_set(o, strat, M.calib)
            if C is not None and M.ctp.coverage_ok(strat):
                U_transfer = 0.0                     # 证书换 bonus
                sem.H = H_post

    # 3) 只读适应：检索已认证等价经验（不写权重/不加未认证边）
    exp = M.aeg.retrieve_certified(o, sem.e)

    # 4) 风险缩放：未认证新颖性直接进入 λ floor
    U_ale, U_epi, modes = M.aud.decompose(M.fmp.sample(o, M.k_for(q)), z)
    U_floor = U_ale + U_epi + U_transfer
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))

    # 5) 执行：探针风险已被 R69 认证，控制包络不因语义而改变
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam, prior=exp)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam

    # 6) 审计与证书
    M.vqa_t.submit_async(sem, q, N_sem, N_phy, U_transfer, H_post)
    return k, lam, mode, (U_ale, U_epi, U_transfer)

## 3. 推导

**引理 19（支撑失配不可由模态分解消除）** R69 的 (H_mode, U_epi, a_score) 都是「在策略支撑内采样的函数」。存在真实状态 o*，其观测在训练分布附近、流似然高、H_mode 低，但真实动力学参数 φ* 落在支撑之外。于是 R69 得到 U_epi ≈ 0、λ 松弛，而真实风险可以任意大。故**仅靠增加采样数 K 无法发现「没被采样到的世界」**；必须引入支撑外的先验（VLM）或干预（探针）。这是本轮存在性的根据，也是 R69「问」的边界。

**引理 20（单语义通道的伪装盲区）** 设语义检测器在嵌入空间 L_s-Lipschitz。对任意 Δφ > 0，存在物理差异为 Δφ 的状态对，其语义嵌入距离可 ≤ ε，从而检测器误判为同一概念，假阴性至少 1 − O(L_s ε / Δφ)。系：**语义只提供候选，不提供认证；认证必须经过物理通道（SPD 与 GHT）。**

**引理 21（接地测试的信息增益）** 先验在 k 个物理假设上，探针以信噪比 ρ 分离属性，则在 A95′（探针可分辨 Δφ ≥ 3σ_φ）下，期望后验熵下降 ≥ c·log k·(1 − e^{−ρ²/2})，且探针物理风险 ≤ ε_int（由 R69 定义 302 保证）。系：VLM 先验越集中且越可分，接地越便宜；先验分散时，探针仍能以对数代价消歧。

**引理 22（AEG 过泛化上界）** 若仅凭语义相似加边并迁移动力学，两节点真实动力学差为 Δ_dyn，则迁移误差下界 ≥ c·Δ_dyn。若边经干预检验（功效 1−β、等价裕度 δ_eq），则迁移误差 ≤ Δ_dyn·β + δ_eq。系：**等价图必须由干预而非相似度生长**；VLM 的相似度只能作为「候选边」，不能作为「已证边」。

**定理 18（TERRA 严格包含 FLUID/R68）** 在无新颖性（N_sem=N_phy=0）、无迁移、且 SCG 通过时，TERRA 与 FLUID 逐指令相同；当 VoI≤成本或 ECE 越界时进一步与 R68 逐指令相同。因此 TERRA 是 FLUID 在「同分布 + 不迁移」边界上的严格退化，安全侧不做让步。

**定理 19（分层共形风险保证）** 在认证分层内、校准集与部署分布可交换、损失有界时，以概率 1−δ 有 R_real ≤ R_cal + α·L_max + δ。跨出分层或 C_α 非单点时，TERRA 自动令 U_transfer = U_base，退回 R69 的保守底，故该保证的失效方向是**变保守**，不是变危险。

**定理 20（语义权限分离的安全定理）** 由定义 310-i 与 319，VLM 的任何输出（包括幻觉、对抗、投毒）都不能直接降低 λ；λ 的每次放宽都必须携带 J_TERRA 的物理接地与共形证书。故对任意语义攻击，TERRA 的物理风险 ≤ R69 风险 + ε_int（探针认证预算），即**VLM 失败只损失效率，不损失安全**。

## 4. 推导

**引理 19（支撑失配不可由模态分解消除）** R69 的 `(H_mode, U_epi, a_score)` 都是策略支撑内采样的函数；存在观测在训练分布附近、流似然高、`H_mode` 低但真实动力学落在支撑外的状态。此时 R69 令 λ 松弛而真实风险任意大。故增加采样数 K 无法发现「没被采样到的世界」，必须引入支撑外先验（VLM）或干预（探针）。

**引理 20（单语义通道的伪装盲区）** 语义检测器 L_s-Lipschitz 时，存在物理差异 Δφ 的状态对，其语义距离 ≤ ε，假阴性 ≥ 1 − O(L_s ε/Δφ)。系：语义只给候选，认证必须经 SPD 与 GHT。

**引理 21（接地测试的信息增益）** k 个物理假设、探针信噪比 ρ，在 A95′（Δφ ≥ 3σ_φ）下期望后验熵下降 ≥ `c·log k·(1−e^{−ρ²/2})`，探针风险 ≤ ε_int（R69 定义 302）。系：先验越集中越可分，接地越便宜。

**引理 22（AEG 过泛化上界）** 仅凭语义相似迁移，误差下界 ≥ `c·Δ_dyn`；经干预检验（功效 1−β、等价裕度 δ_eq）后误差 ≤ `Δ_dyn·β + δ_eq`。系：等价图必须由干预而非相似度生长。

**定理 18（TERRA 严格包含 FLUID/R68）** 无新颖性、无迁移、SCG 通过时与 FLUID 逐指令相同；再满足 VoI≤成本或 ECE 越界时与 R68 逐指令相同。安全侧不做让步。

**定理 19（分层共形风险保证）** 认证分层内、可交换、有界损失下，以概率 1−δ 有 `R_real ≤ R_cal + α·L_max + δ`；跨层或非单点集时自动退回 `U_transfer = U_base`，保证失效方向是**变保守**。

**定理 20（语义权限分离的安全定理）** VLM 的任何输出（幻觉/对抗/投毒）都不能直接降低 λ；每次放宽都需 J_TERRA 的物理接地与共形证书。故任意语义攻击下物理风险 ≤ R69 风险 + ε_int，**VLM 失败只损失效率，不损失安全**。

## 7. 本轮最大风险

**一句话**：TERRA 的证书建立在「校准集与部署分布可交换」这一假设上，而真实世界泛化的本质恰恰是该假设不成立；若 VLM 与共形校准被同一个分布偏移同时欺骗，系统会拿着过期的证书、在分布外自信地放宽 λ——**证书越漂亮，越可能是分布外**。

**次级风险与缓解**：VLM 幻觉/对抗伪装（语义权限分离 + SCG + 定理 20）；AEG 过泛化（只允许干预认证边 + 引理 22 + 离线审计）；共形交换性失效（分层 + staleness 门控 + 越界回 U_base）；VLM 延迟/算力（异步守护 + 蒸馏头 + 事件触发）；测试时漂移（只读适应，持久更新离线可复现）。
