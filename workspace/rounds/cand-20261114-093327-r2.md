# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「移动底盘」×「长期记忆」）

> R69 给了系统一张嘴（问句）、一次注视、一次轻触，还用流似然补了一条「标定不可吸收」的第二意见。但它所有知识都活在**当下、自我中心、一次性**的框架里：问完就丢，下一次任务从零再问；U_epi 只是一个「此刻的熵」，没有「在哪里、到什么时候仍然成立」的维度。更尖锐的是，R69 的交互很贵（社交、时间、位移），系统却反复为同一个问题付钱——它没有**把答案存起来、并对答案何时过期负责**的能力。
>
> 本轮两个灵感正好补上「空间」与「时间」两条轴：
> - **移动底盘**：移动不只是运输。它同时是（a）一种信息动作——换视角、绕到背面、回到上次取证的地方；（b）一种**不确定性来源**——里程计漂移、坐标系改变，会让旧知识「对不上号」；（c）记忆的物理索引——知识天然锚定在「在哪里看到的」。
> - **长期记忆**：记忆不是更大的回放池，而是一份**关于未来仍会成立的断言，会过期、会被污染、可被回滚、需要治理**。把记忆当事实，是 R70 最大的诱惑，也是最大的陷阱。
>
> 核心命题：**把 R69 的每一次「消歧结果」升格为一条带时空锚、有效性模型、证据链与租期的断言；移动底盘既可以作为信息动作去「重新落地/证伪」它，也必须为移动引入的坐标系不确定性负责；在线永不改写整合记忆与策略（只追加不可变情景日志），过期、失配、来源不可信或被投毒的记忆一律视为「未消解」，逐指令退回 R69。** 命名 **ATLAS-RAS**（Anchored Temporal-Located Assertion Store for Risk-Adaptive Systems，「记忆不是仓库，是租约」）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我所知道的东西，在哪里、到什么时候还成立，凭什么**」——移动底盘让知识有了地址，长期记忆让知识有了租期。

## 0. 直觉与动机

**灵感 1（移动底盘 → 位置是知识的一部分）**
直觉：同一句话，在 A 房间亲眼看到和在 B 房间猜到，价值完全不同。R69 的 U_epi 是一个标量，没有「地址」；而移动机器人一旦走动，所有观测、标定、策略条件都换了坐标。于是「杯子在左边」离开那个观测位姿后，就不再是可无条件复用的命题，而是一条**需要平移、旋转、时效与上下文检验的断言**。把知识锚定到（位姿，时间，上下文），是移动底座给这套框架带来的第一个结构性变化。

**灵感 2（移动底盘 → 移动本身是信息动作，也是风险源）**
直觉：人看不清会走近、会绕到背后、会退一步看全貌——移动是最强的主动感知之一。但移动同时让机器人「更不确定自己在哪里」：里程计漂移、建图误差、被人推动。于是出现 R69 没有的张力——**为了看得更清而移动，可能让已有记忆更不可信**。这不是 bug，而是必须显式建模的权衡：最优的「重新落地」通常不是走得越远越好，而是走到刚好能分辨、又不过度破坏坐标一致性的地方（定义 318、引理 20）。

**灵感 3（长期记忆 → 记忆是带租期的断言，不是事实库）**
直觉：把记忆写成「事实」，系统就会在物体被挪走后依然自信地去老地方抓。正确的对象不是「事实」，而是**断言 + 证据 + 有效期 + 失效条件**。每条记忆都要能回答四个问题：谁说的（provenance）、在哪看到（anchor）、凭什么现在还可信（validity model）、错了怎么撤（rollback）。过期不是异常，是常态；忘记不是失败，是治理。

**灵感 4（长期记忆 → 零在线学习与可复用性的统一）**
直觉：R68 立过铁律「实时流零学习写操作」，R69 又强调证据纪律。长期记忆若允许在线写入整合层，就等于给投毒开了一条直达行为的快车道，也违背可审计性。因此把记忆分层：**在线只追加不可变的情景日志（MERL），语义记忆（SAM）只由离线整合器产生、在线只读**。这样「学到东西」与「立刻改变行为」被时间隔开：既能复用，又不给单次输入即时控制权（定义 313–314、定理 19）。

**灵感 5（威胁模型 → 记忆让错误穿越时间）**
直觉：R69 的投毒是「这一次回答不可信」；R70 的投毒是「这一次被写进记忆，下一次、下十次都不可信」。攻击者不再需要持续在线，只需成功一次。更隐蔽的是**陈旧记忆陷阱**：先让机器人正确记住，再悄悄移动物体，让它在错误的地方高度自信；还有**坐标系欺骗**：篡改定位，使一条本已失效的记忆「看起来仍在有效范围内」。记忆把一次性错误变成长期负债，因此必须交付独立的记忆审计与回滚。

**灵感 6（与 R69 的关系 → 记忆是交互预算的摊销器，不是新的安全层）**
直觉：R69 的交互很贵。长期记忆的第一性价值是**摊销**：同一问题只付一次问价，之后付很低的检索/复核成本。但记忆只能改变「如何消解 epistemic」，绝不能降低安全下限；任何记忆失效都退回 R69 的纯保守。记忆的经济学判据很朴素：**只有当「过期概率 × 过期损失 + 复核成本」低于「重新询问成本」时，记忆才值得用**（引理 21）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ATLAS-RAS 总览）** ATLAS-RAS = (SAM, MERL, MTE, MVG, SEG, REX, MINT⁺, CONSOL, MPA, VQAuditor-M, RAS-WM§)。四不变式：
(i) **零在线学习写**（继承 R68 定义 276-i）：在线不写策略权重；在线追加 MERL，但**绝不写 SAM**；
(ii) **记忆不放宽安全包络**：任何由记忆驱动的动作仍需 C-RAS-WM 前缀认证，λ 不低于 R69 的 λ_floor(U_ale)；
(iii) **来源完整与可回滚**：每条断言带哈希证据链，任一时刻可回到某个已认证 SAM 版本；
(iv) **失效即退避**：过期 / 失配 / 来源不可信 / 被隔离的记忆一律视为「不存在」，其曾消解的 M 重新计入 U_epi，逐指令退回 R69。

**定义 311（时空锚断言）** 一条记忆是七元组 μ = (c, φ, E, τ, π, w, κ)：
- c：可判定命题（「蓝杯在托盘右侧」「这种透明物体适合两指侧抓」）；
- φ：上下文谓词（场景、任务、光照、物体类别）；
- E：证据集（—log 似然、交互回答哈希、标定读数），不可变；
- τ = (p_τ ∈ SE(3), t_τ, Σ_τ)：**时空锚**（取证位姿、时刻、位姿协方差）；
- π：来源与签名（人 / 传感器 / 外部服务 / 离线整合器）；
- w ∈ [0,1]：校准后的置信；
- κ ∈ {static, movable, agentic, episodic}：**有效性类别**，决定租期与失效动力学（墙与门把手慢，可移动物体快，人的意图最快）。
**记忆不是事实，是一份带租期的断言。**

**定义 312（记忆传输与可信度衰减 MTE）** 当前帧 F_t = (p_t, t, Σ_t)。定义空间应力 d_s = √(Δpᵀ (Σ_τ ⊕ Σ_t)⁻¹ Δp)（SE(3) 上的 Mahalanobis 距离），时间年龄 a = t − t_τ，上下文失配 m = 1[¬φ(F_t)]。传输置信
w_t(μ) = w · exp(−α_κ d_s² − β_κ a/τ_κ − γ_κ m) · 1[π 通过校验]，
并定义**有效性商** V_t(μ) = w_t(μ)/w ∈ [0,1]。静态类 τ_κ ≫ 任务时长，agentic 类 τ_κ 以秒计；这不是调参技巧，而是把「什么知识会多快过期」写成可校准的先验。

**定义 313（分层记忆：MERL 与 SAM）** 
- **MERL（情景日志）** 只追加、不可变、哈希链 h_i = H(h_{i−1} ‖ record_i)，在线允许写，但**不能被当作信念直接读取**，只能作为证据进入整合或审计；
- **SAM（语义记忆）** 版本化的整合断言库，每条带整合证书；在线**只读**，只能由离线整合器 CONSOL 升版。
在线行为路径与 MERL 写入路径物理分离：写日志不会立刻改变控制。

**定义 314（在线零写不变式的扩展）** 在线阶段允许的操作只有：读 SAM、追加 MERL、查询失效事件。禁止写 SAM、禁止训练、禁止把单次输入提升为语义断言。因此任何单次投毒至多污染一条情景记录，无法在同一会话内改变行为（定理 19）。

**定义 315（情境认知图 SEG）** 节点是「地点 × 类别」的空间锚，边是相对位姿与共视关系；既有几何回环，也有**命题依附**：μ 挂在若干地点节点上。SEG 的形变（定位漂移）会直接改变 d_s，从而改变 V_t。语义回环（定义 320）用来校正「信念地图」，而不只是「位姿地图」。

**定义 316（记忆知情信念）** 召回集 ℛ_t = {μ : V_t(μ) ≥ τ_v ∧ φ(F_t) ∧ π 通过}。记忆提供先验
P_mem(M) ∝ exp(Σ_{μ∈ℛ_t} V_t(μ) · log p(M | c_μ))，
后验 P_t(M) ∝ P_obs(M | o_t) · P_mem(M)。定义**记忆知情 epistemic 不确定性** U_epi^mem = H(M | o_t, ℛ_t)。注意 U_epi^mem 只可**替代** R69 的现场 U_epi，不可把二者相加后压低安全下限。

**定义 317（检索价值 VoR）** VoR(μ) = [H(M | o_t) − H(M | o_t, μ)] − P_stale(μ, F_t)·ℓ_mis − c_ret。检索成本 c_ret 近零，但**过期损失 ℓ_mis 可能极高**（抓空、撞人、错抓）。VoR ≤ 0 时不检索，等价于「这条记忆当前无效」。

**定义 318（移动作为信息动作与情境 VoI）** 底盘/全身位移 b ∈ SE(3)（或可行路点），增广信息动作 𝒜_info⁺ = {gaze, probe, ask, move(b), revisit(τ)}。移动到 F_{t'} 的净价值
VoI_situated(b) = E[H(M|o_t) − H(M|o_{t'}, b)] − c_move(b) − λ_Σ · ΔH_frame(b)，
其中 ΔH_frame(b) 是移动引入的位姿熵增（里程计 + 模型误差），它经定义 312 抬高**所有**记忆的传输风险。因此移动可能净负价值。**重定位半径 d\* = argmax_b VoI_situated(b)** 一般内点存在（引理 20）。

**定义 319（MINT⁺ 情境交互控制器）** 在 R69 的 MINT 上增加 retrieve / revisit / move 三类候选：
g\* = argmax_{g ∈ {retrieve, move, revisit, gaze, probe, ask}} [VoI(g) − c(g) − risk(g)]，
s.t. 交互预算、C-RAS-WM 认证、全身平衡与力/位包络。若最优值 ≤ 0：不交互，走 R69 兜底。**记忆只是让「问」变得更少，而不是让「安全」变得更松。**

**定义 320（语义回环与重锚 SLC）** 当机器人重新接近锚 τ 时，用记忆预测「此刻应看到什么」，与实际观测比对：
- 一致 ⇒ 重锚：t_τ ← t，p_τ ← p_t，Σ_τ ← Σ_t，w ← min(1, w + δ)，Wasserstein 距离进入证书；
- 不一致 ⇒ 记一次**矛盾事件**，启动证伪（R70 的 VoF 变体）：优先设计一个能区分「物体变了」与「自己看错了」的最小动作，而不是立刻删除记忆。
语义回环是「信念地图」的回环闭合，区别于纯几何回环。

**定义 321（失效与遗忘）** 失效事件 ∈ {过期, 矛盾, 来源吊销, 类别风险越界, 外部回滚}。遗忘不是删除证据：SAM 断言降权/隔离，MERL 保留哈希以审计。遗忘策略最小化 E[陈旧损失] + λ_s·存储，但对安全相关断言设硬下限（永不因省空间而忘记「此处有台阶」这类负向约束）。

**定义 322（离线整合器 CONSOL）** 把 MERL 升为 SAM 需同时满足：
(a) **时空独立复现**：k_eff ≥ 2 次、锚点间 d_s ≥ d_min 且时间跨度 ≥ Δ_min，避免「同一相机同一秒的多个 seed」伪装成多证据；
(b) 一次主动证伪尝试未能拒绝（否则记 Refuted）；
(c) 由类别 κ 估计租期与风险率，写入整合证书。
**单次情景永不升为语义断言**；未升版的证据保持为「候选」，不参与行为。

**定义 323（记忆投毒干扰集 ℰ_mem）** 植入假断言、陈旧记忆陷阱（先正确记忆、再移动物体）、坐标系欺骗（让失效记忆显得有效）、回放/回滚攻击（用旧好版本掩盖故障）、自我确认回声室（整合器在自己的历史上过拟合）、跨任务负迁移。并入 AIC：ℰ_ATLAS = ℰ_FLUID × ℰ_mem。

**定义 324（记忆审计 VQAuditor-M）** 审计召回是否越权、有效性判定是否校准、整合是否满足时空独立、矛盾是否被恰当处理、回滚点是否可用；把陈旧复用率与 V_t 校准误差回灌 MVG 与 CONSOL 的先验。

**定义 325（证书 J_ATLAS）** J_ATLAS = (J_FLUID, validity_ece, stale_reuse_rate, provenance_ok, rollback_point, mem_growth, transport_auc, sam_version)。Valid ⇔ Valid(J_FLUID) ∧ validity_ece ≤ τ_vce ∧ 在线零写不变式成立 ∧ 无未审计回滚。

**定义 326（两级退避与严格包含）** 若记忆有效且 VoR > 0：用 U_epi^mem 消解，获得 R69 同等的 resolution bonus（仅省交互成本）；若记忆无效/未复现/被污染/超时：其命题重新计入 U_epi，λ = λ_floor(U_ale + U_epi)，即 R69 纯保守。**空 SAM + 零移动时，ATLAS 逐指令等于 FLUID-RAS。**

## 2. 关键算法骨架

```python
# IP-264/265 SAM + MERL：在线只读语义记忆、只追加情景日志
class SituatedAssertionMemory:
    def __init__(self):  self.sam, self.merl, self.head = {}, [], GENESIS
    def recall(self, F_t, M, k=8):
        cand = self.sam.topk(anchor_near(F_t), context=M.context, k=k)
        return [mu for mu in cand if mvg.passes(mu, F_t)]      # 定义 315
    def append_episode(self, record):                          # 在线唯一写操作
        rec = dict(record, prev=self.head); self.head = H(self.head, rec)
        self.merl.append(rec)                                  # 不可变、哈希链
    def install(self, version, cert):                          # 仅离线调用
        assert cert.consolidated and verify_chain(cert); self.sam = version

# IP-266 MTE + IP-267 MVG：传输置信与有效性门
def transport(mu, F_t):
    ds = mahalanobis_se3(F_t.p - mu.tau.p, F_t.Sigma + mu.tau.Sigma)
    return mu.w * exp(-A[mu.k]*ds**2 - B[mu.k]*(F_t.t-mu.tau.t)/TAU[mu.k]
                      - G[mu.k]*(not mu.phi(F_t))) * mu.prov_ok
def mvg_passes(mu, F_t):
    return transport(mu, F_t)/mu.w >= TAU_V and mu.prov_ok and not mu.quarantined

# IP-269 REX：移动是信息动作，但移动本身抬高所有记忆的传输风险
def situated_voi(b, M, F_t, memories):
    dH_obs   = expected_entropy_drop(M, b, F_t)
    dH_frame = pose_entropy_gain(b) * L_TR * sum(mu.w for mu in memories)  # 定义 312/318
    return dH_obs - move_cost(b) - LAMBDA_S * dH_frame

# IP-270 MINT⁺：检索 < 移动/回访 < 看/触/问，统一用净价值排序
def choose_action(modes, M, F_t, budget, ras):
    cands = []
    for mu in sam.recall(F_t, M): cands.append(('retrieve', mu, vor(mu, M, F_t)))
    for b in reachable_poses(F_t): cands.append(('move', b, situated_voi(b, M, F_t, sam.sam)))
    for g in info_action_candidates(modes):
        if budget.allow(g) and ras.certify_info(g, F_t):
            cands.append(('sense', g, voi(g, modes) - cost(g)))
    _, arg, val = max(cands, key=lambda c: c[2])
    return arg if val > 0 else None                            # ≤0 → R69 兜底

# IP-271 SLC：语义回环，先分辨「物体变了」还是「自己看错了」
def revisit(mu, obs, F_t):
    pred = render_prediction(mu, F_t)
    if w2(pred, obs) < TAU_SLC:
        mu.tau = F_t.anchor(); mu.w = min(1.0, mu.w + DELTA); return 'refreshed'
    mu.merl.append(('contradiction', mu.id, H(obs)))
    return 'open_falsification'                                # 进入 VoF，不立即删除

# IP-272 CONSOL：离线整合，要求时空独立 + 主动证伪
def consolidate(merl, sam):
    for c in group_by_claim(merl):
        if spatiotemporal_independence(c) < K_EFF: continue    # 单次情景不升版
        if run_falsifiers(c, budget=c.b) == 'refuted': continue
        sam.install(sam.version + 1, cert(c, hazard_class(c)))  # 生成整合证书

# IP-273 主闭环：记忆先行，失效即退回 R69
def ATLAS_RAS_round(M, obs, F_t):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    recalled = M.sam.recall(F_t, M)                            # 只读 + MVG 门控
    U_epi_mem = memory_informed_entropy(U_epi, recalled)       # 定义 316
    g = M.mint_plus.choose_action(modes, M, F_t, M.budget, M.ras) if U_epi_mem > TAU_EPI else None
    resolved = False
    if g is not None:
        if g.kind == 'retrieve':  resolved = M.sam.apply(g.mu, modes)
        elif g.kind in ('move','revisit'): resolved = M.slc.revisit_or_reground(g, M, F_t)
        else:                     resolved = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + (0.0 if resolved else U_epi)              # 失效/未解 → R69 保守
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., wm_preds)
    if not resolved: k = min(k, k_cal_shrink(...))              # 与 R69 相同，无额外放宽
    mode = select_mode(modes, U_epi_mem if resolved else U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.merl.append_episode(record(F_t, mode, resolved, recalled, g))  # 只追加
    M.vqa_m.submit_async(F_t, recalled, resolved, g)            # 参与式记忆审计
    return k, lam, mode, (U_ale, U_epi_mem, resolved)
```

## 3. 推导

**引理 19（记忆时效的陈旧概率上界）** 设类别 κ 的失效强度为 λ_κ(s)，传输误差满足 Lipschitz 条件（A99）。则在帧 F_t 处该断言已陈旧的概率
P_stale(μ, F_t) ≤ 1 − exp(−∫_{t_τ}^{t} λ_κ(s) ds) + ε_loc(d_s)，
其中 ε_loc(d_s) ≤ L_tr·d_s·√tr(Σ_τ ⊕ Σ_t)。故 V_t 可作为陈旧概率的**校准上界**：取 τ_v 使 E[陈旧损失] ≤ ε_mem，即 MVG 的阈值可由损失预算反解，而不是拍脑袋。

**引理 20（框架–记忆权衡：移动的两面性）** 移动距离 d 使观测熵下降 ΔH_obs(d)（通常凹、随 d 饱和），同时使位姿熵上升 ΔH_pose(d)（通常凸）。由定义 312，所有已召回记忆的传输风险平均上升至少 L_tr·ΔH_pose(d)。因此
VoI_situated(d) ≤ ΔH_obs(d) − c_move(d) − λ_Σ·L_tr·ΔH_pose(d)。
右端先正后负（ΔH_obs 饱和、ΔH_pose 与成本增长），故存在有限最优 d\*；系：**当目标物已在当前视野可分时，移动的边际信息价值为 0，而坐标风险为正，最优是「不动」**——这解释了为什么「能看清就不必走近」。

**引理 21（记忆摊销的盈亏平衡）** 每回合重新询问成本 c_a；复用记忆的复核成本 c_r；每回合失效概率 h；失效损失 ℓ。复用优于重问 ⇔ h·ℓ + c_r < c_a，盈亏平衡风险率 h\* = (c_a − c_r)/ℓ。系：对高失效类（movable/agentic）应降低复用、提高现场复核；对 static 类可大幅摊销。**记忆不是越多越好，而是只在 h < h\* 的类别上赚钱。**

**定理 18（ATLAS 严格包含 FLUID-RAS）** 在 A99 下，ATLAS 在任意状态 s 的期望风险 ≤ FLUID-RAS；且当 SAM 为空、移动动作不可用、或所有 V_t < τ_v 时，两者逐指令相同。证明要点：记忆只通过 U_epi^mem **替代**而非压低 U_epi，安全项仍为 λ_floor(U_ale)，且所有动作过同一 C-RAS-WM；失效路径强制 recovered=False 并回到 R69 保守分支。故 R69 是「无记忆、无移动」边界上的严格退化，安全侧不让步，效率侧获得摊销。

**定理 19（在线投毒遏制与不可瞬时生效）** 在线唯一写路径是 MERL 追加，且 MERL 不进入控制读取路径；行为改变必须经 CONSOL 升版 SAM。设单条投毒被整合的概率为 δ_p，时空独立证据间欺骗相关 ρ<1，则单条投毒在 N 次后续任务内改变行为的概率 ≤ δ_p·ρ^{k_eff−1} + ε_p；且哈希链 + 版本快照保证可回滚到投毒前状态。系：**长期记忆的攻击面被从「在线」推到「离线整合」这一可审计、可复现、可回滚的关口。**

**定理 20（记忆安全与无突变）** 记忆只影响「选哪个已认证模态 / 是否省一次交互」，不改变安全包络；移动动作经全身 C-RAS-WM（平衡、力/位、时间）认证；回滚恢复已认证 SAM 版本；失效时 λ 单调不降地退回 R69。故提交/换装不变式（R69 定理 17）保持，控制连续、无突变。

## 6. 本轮最大风险

**一句话**：ATLAS-RAS 的全部收益押在「**有效性模型是校准的**」这一前提上——若机器人无法判断世界已变、或无法判断自己的锚点/坐标系已错，长期记忆就会把 R69 那种「诚实的当下不确定」升级成**自信的过时**：它会走到世界曾经在的地方，对一个已经不存在的过去高度确定地行动；而移动底盘让这个错误**更远、更贵、更难撤回**——**记得越久、走得越远，错得越自信。**

**次级风险与缓解**：
1. **有效性过度自信（陈旧复用）** → V_t 校准 + 引理 19 损失预算反解 τ_v + E302；
2. **定位漂移/坐标系欺骗** → Σ 膨胀、多锚一致性、本体感觉交叉校验、E306；
3. **记忆投毒与整合回声室** → 在线零写 SAM、k_eff 时空独立、主动证伪、哈希链回滚、E306–E309；
4. **记忆膨胀与负迁移** → 类别化租期、预算化遗忘、上下文谓词 φ 门控、E310/E314；
5. **移动本身不安全**（平衡、碰撞、力/位越界）→ 全身 C-RAS-WM 认证 + E303；
6. **人类数据隐私** → 作用域检索、同意与可验证遗忘（定义 321、E311）。

```python
    mode = select_mode(modes, U_epi_mem if resolved else U_epi, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.merl.append_episode(record(F_t, mode, resolved, recalled, g))
    M.vqa_m.submit_async(F_t, recalled, resolved, g)
    return k, lam, mode, (U_ale, U_epi_mem, resolved)
```

## 4. 推导

**引理 19（陈旧概率上界）** `P_stale ≤ 1 − exp(−∫λ_κ) + L_tr·d_s·√tr(Σ_τ⊕Σ_t)`。故取 `τ_v` 使期望陈旧损失 ≤ ε_mem，MVG 阈值由损失预算反解（A99）。

**引理 20（框架–记忆权衡）** `VoI_situated(d) ≤ ΔH_obs(d) − c_move(d) − λ_Σ L_tr ΔH_pose(d)`；`ΔH_obs` 凹而饱和、`ΔH_pose` 凸，故最优重定位半径 `d*` 为内点。系：目标已可分时最优为「不动」。

**引理 21（记忆摊销盈亏平衡）** 复用优于重问 ⇔ `h·ℓ + c_r < c_a`，平衡风险率 `h*=(c_a−c_r)/ℓ`。系：高失效类（movable/agentic）少复用、多复核；static 类可大幅摊销。

**定理 18（严格包含 FLUID-RAS）** 空 SAM + 零移动 ⇒ 逐指令等于 R69；一般情形期望风险 ≤ R69（记忆只替代 U_epi、不压低 λ_floor，且全动作过 C-RAS-WM）。安全不让步，效率获摊销。

**定理 19（在线投毒遏制）** 在线仅追加 MERL 且不进入控制读取，行为改变必须经离线 CONSOL；单条投毒改变行为的概率 ≤ `δ_p·ρ^{k_eff−1}+ε_p`，且哈希链 + 版本快照可回滚。系：攻击面被推到可审计、可复现、可回滚的离线关口。

**定理 20（记忆安全与无突变）** 记忆只影响已认证模态选择；移动经全身 C-RAS-WM（平衡/力位/时间）认证；回滚恢复认证版本；失效时 λ 单调不降退回 R69 ⇒ 控制连续、无突变（继承 R69 定理 17）。

## 8. 拟落地步骤（UniBot / Unitree G1 语境）

1. **只读先跑通**：先实现 SAM=空、MERL 只记录不召回，验证与 R69/基线逐指令等价（E316），零风险接入。
2. **离线整合器**：用历史轨迹构建「地点×物体类别」统计，估计类别风险率与租期；先在仿真做投毒/陈旧/回滚红队（E306–E309）。
3. **MVG + MTE 上线**：只允许 static 类记忆复用，movable/agentic 一律现场复核；测陈旧复用率与 ECE（E302）。
4. **移动重定位**：在遮挡/背面任务上启用 revisit/move 候选，接入全身平衡认证，验证 d* 与 E303/E304。
5. **跨任务泛化**：在 UniBot 五类泛化场景上做 E315；负迁移超阈值则收紧 φ 门控，宁可退回 R69。

## 9. 本轮最大风险

**一句话**：ATLAS-RAS 的全部收益押在「有效性模型是校准的」这一前提上——若机器人无法判断世界已变、或无法判断自己的锚点/坐标系已错，长期记忆就会把 R69 的「诚实的当下不确定」升级成**自信的过时**：它会走到世界曾经在的地方，对一个已经不存在的过去高度确定地行动；移动底盘让错误更远、更贵、更难撤回——**记得越久、走得越远，错得越自信。**

**次级风险与缓解**：有效性过度自信（V_t 校准 + 引理 19 + E302）；定位漂移/坐标欺骗（Σ 膨胀 + 多锚一致性 + E306）；投毒与整合回声室（在线零写 SAM + k_eff 时空独立 + 主动证伪 + 哈希回滚 + E306–E309）；记忆膨胀与负迁移（类别租期 + 预算化遗忘 + φ 门控 + E310/E314）；移动不安全（全身 C-RAS-WM + E303）；人类数据隐私（作用域检索 + 可验证遗忘 + E311）。
