（跨轮研究循环·新灵感第 1 轮；本轮灵感：「在线学习」×「开源软件」）

> **基线**：承 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（其上承 v21 的语义-规范层 SDC/CAC/DCL/GIC 与 v20 的联邦感知证书 PCA/CTS/CFC/HPC）。
> 本轮纪律：**不推倒 v22**。HPC-E / EVC / RGC / HDL / ACSC / DCSC / CFC++ 全部保留。本轮只做一件事：v22 的每一张证书都默认了两个**未言明的静态前提**——(i) 校准分布平稳、数据可交换；(ii) 工件由单一可信作者离线签发。**在线学习攻击 (i)，开源软件攻击 (ii)**。本轮把"静态签发的证书"升级为"**可持续更新、可开源审计、可证伪**的证书供应链"，并顺手封堵 v22 残余的最大风险（相关失效）向"供应链相关失效"的迁移。

## 0. 直觉与动机

**灵感 1（在线学习 → 证书参数不是常量，而是一条带护栏的轨迹）**
直觉：v22 的 κ_c（召回下界）、α（conformal 水平）、ε_loc（定位误差界）、能耗模型 P=f_θ、规则先验，全都在部署前一次性冻结。但真实部署必然漂移：新用户、新手势、逆光、地面摩擦变化、电池老化。在线学习想持续改进这些参数，却正踩在证书命门上——conformal 与召回下界都要求"校准样本与测试样本可交换"，而机器人策略一旦随学习改变，它采到的数据就是**自诱导的、非可交换的**（performative / closed-loop covariate shift）。悖论由此产生：**学得越勤，证书越可能"形式有效、事实失效"**。核心创新：**证书保持的在线刷新（Certificate-Preserving Online Refresh, CPOR）**——学习只在影子通道进行，任何参数进入执行路径前必须过一道**晋升闸门**；证书参数被安置在一个**保守性偏序**上，在线更新只允许朝"不更冒险"的方向滑动，朝冒险方向的滑动必须换取一次完整重认证。关键反直觉点：**在线学习的目标不是"更准"，而是"在证书不被证伪的前提下更活"**；冻结不是失败，而是护栏的默认态。

**灵感 2（开源软件 → 证书是带依赖图、fork 与供应链攻击的社会技术工件）**
直觉：v22 把规则库、检测器、校准器、先验当作"我们自己的、可信的、单一版本"的工件。开源现实恰好相反：它们是**多人协作、可 fork、可回滚、带依赖闭包**的供应链。开源带来两件好事——可复现审计（人人可验）与对抗性众包（"足够多的眼睛"、bug bounty、模糊测试）；也带来两件坏事——供应链投毒（被污染的预训练权重/校准集/依赖库）与**fork 悄悄放宽约束**（删一条 F 规则、调低 q_high，证书却仍挂着父版本的名）。核心创新：**开源证书供应链（Open Certificate Supply Chain, OCSC）**——把每张证书视为依赖 DAG 上的一个节点，定义**证书污点传播**（任一祖先失效，全部下游失效）与**证书保持 diff**（只有"收缩型"改动可继承父证书，"放宽型"改动一律触发重认证）；再配一个**开放对抗审计协议（AOAP）**，把外部证伪者变成证书的持续压力测试。关键反直觉点：**"开源=更不安全"是错觉；真正危险的是"开源了代码却没开源证书的依赖图"**——你看得见算法，却看不见它信任了谁。

**二者如何统一**
统一为 **"可证伪造的持续学习供应链"层**：在线学习回答"证书参数如何随时间演进而不失效力"，开源软件回答"这些参数、模型、规则由谁签发、依赖谁、能否被独立复核与攻击"。共享状态扩展为 `ζ_supply = ζ_pgev ∪ (F_v, C_cand, drift_stat, G_art, taint, audit_log)`。统一准入门升级为 **HPC-L = HPC-E ∧ Refresh-Valid ∧ Provenance-Clean ∧ No-Live-Witness**：在几何∧能量∧规范∧负信息之外，还要求"当前证数参数经晋升闸门批准、依赖闭包无污点、且无未消解的公开反例"。CFC++ 升级为 **CFC+++**：仲裁不仅要求"模态多样"，还要求**来源多样（provenance diversity）**——共享同一上游模型/同一训练集/同一依赖的两个投票者，其错误是相关的，不能算两票。

## 1. 研究问题（轮次升级版）

- **Q12（非可交换下的 conformal 与召回）**：在自适应采样与自诱导漂移下，如何重估 α 与 κ_c 使覆盖/召回界仍然成立？自适应 conformal 推断（ACI）给出的长期覆盖能否转成**逐步**安全界？如何用"反馈分离"把机器人自身动作造成的分布变化从外部漂移中识别出来？

- **Q13（保守性偏序与无放宽更新）**：证书参数空间上的保守性偏序 ≼_c 如何定义并**机械可检**？能否把在线更新约束为单调算子（单调网络/约束投影）使 `C_{t+1} ≼_c C_t` 或经全量重认证？当"更活"必然要求"更冒险"时，如何把这次冒险定价为可审计的重认证事件而非静默放宽？

- **Q14（供应链污点与证书保持 diff）**：证书效力的污点如何沿依赖 DAG 传播（含传递性、时效性、许可证与构建可复现性）？什么算"证书保持 diff"、什么必须判为 WIDENING？fork 隔离与回滚如何保证不会把父证书的名誉借给一个已放宽约束的子版本？

- **Q15（对抗审计的激励与可重放性）**：外部证伪者提交的见证如何进入 W_sim 而不被投毒（伪造/垃圾 witness）？在线学习流是非确定性的，"可重放审计"（数据摘要 + 规则哈希 + RNG 种子 + 闸门逐项输出）如何做到逐位复现判定？bounty 机制如何设计才能让"发现放宽"比"发现崩溃"更值得上报？

## 2. 形式定义（先直觉、后严格）

**定义 922（证书参数状态）**：`C = (θ, κ_c, α, ε_loc, f_E, R)`，其中 θ 为感知/能耗模型参数，R 为 F/O/P 规则库，其余沿用 v22 语义。

**定义 923（保守性偏序 ≼_c）**：称 `C'` 不弱于 `C`（记 `C ≼_c C'`），当且仅当
`κ_c' ≥ κ_c ∧ α' ≤ α ∧ ε_loc' ≤ ε_loc ∧ Θ_F(R') ⊇ Θ_F(R) ∧ Θ_P^{allow}(R') ⊆ Θ_P^{allow}(R) ∧ K_energy' ⊆ K_energy`。
即召回不降、覆盖水平不降、误差界不收窄、禁止域不收窄、许可域不放宽、能量核不放宽。**命题（单调性）**：`C ≼_c C' ⟹ Exec(C') ⊆ Exec(C)`（逐项对应 v22 的过滤器语义，故可机械核验）。

**定义 924（晋升闸门 Predicate）**：`Promote(C_cand | F_v) = (a) ∧ (b) ∧ (c) ∧ (d) ∧ (e) ∧ (f)`：
(a) `C_cand ≼_c F_v`（无放宽）**或** `FullReCert(C_cand)` 通过；
(b) 在可交换性筛查后的缓冲 B 上，ACI 覆盖单侧检验不拒绝 `1-α`（容许松动 η）；
(c) 召回下界 `κ̂_c^{LB}(B) ≥ κ_c^{min}`；
(d) 漂移检测器判定 B 与部署分布可交换，且**非自诱导**（反馈分离）；
(e) `W_sim(C_cand) = ∅`（回归 + 模糊测试后无见证）；
(f) 依赖闭包 `G_art` 无污点且构建哈希可复现。
任一项不通过 ⇒ 维持冻结证书 `F_v`；**永不允许"部分通过即上线"**。

**定义 925（证书污点 taint）**：对工件 DAG `G_art`，节点 n 的 `taint(n)=1` 当且仅当：签名无效 ∨ 构建不可复现 ∨ 许可证不兼容 ∨ 自身证书谓词为假 ∨ `∃ m→n, taint(m)=1`。部署合法性要求 `taint(n)=0` 且无被污染祖先；污点单向下游传播，上游修复**不自动**清除下游缓存，必须重放重认证。

**定义 926（证书保持 diff / WIDENING）**：规则库差分 d 是**证书保持的**，当且仅当它只增 F、只增 O、只收紧 P，使 `Exec(R⊕d) ⊆ Exec(R)` 且不削弱任何已校准量；否则判为 WIDENING，强制走 FullReCert。fork 默认继承**空证书**，而非父证书。

**定义 927（可重放更新记录）**：`UpdateRecord = (h(B), h(C_cand), h(F_v), seed, verdict, per-check trace, ts, sig)`；确定性重放必须复现同一 verdict，否则晋升视为未发生。

## 3. 设计原则（在 P37/P41/P42 基础上新增 P43–P46）

**P43 证书保持的在线更新律（Certificate-Preserving Online Update）**
在线学习仅在影子通道演进候选 `C_cand`；执行路径永远读取**最近一次通过晋升闸门的冻结证书** `F_v`。演进不得直接写执行参数；闸门失败即回退 `F_v`。故任意时刻 `Exec_v23(t) ⊆ Exec_v22(t)`。

**P44 保守性偏序律（Conservativeness Partial Order）**
一切自动更新必须以 `≼_c` 为方向约束；朝冒险方向的任何一步，要么被 `≼_c` 拒绝，要么显式升级为 `FullReCert` 事件并留 audit record。**禁止"阈值微调"式静默放宽**——放宽是一个需要重新举证的离散事件，不是一次梯度步。

**P45 供应链污点律（Supply-Chain Taint）**
证书效力是 `G_art` 上的污点传播；下游不得比上游更可信。仲裁（CFC+++）除模态多样性外，要求**来源多样性**：同一上游模型的多个副本合并为一个 provenance 组，一组只计一票。

**P46 可重放审计律（Replayable Audit）**
每次晋升/回滚都写入 proof-carrying `UpdateRecord`；审计者可用摘要与种子逐位重放并复核 verdict。不可重放的更新在规范上**不存在**——即便它悄悄改了参数。

## 4. 与基线的接口（如何退化）

- 在线学习失效（闸门/漂移检测崩溃）⇒ 永久冻结在最近认证证书 ⇒ 等价 v22（更保守），活性回落到离线水平；
- 反馈分离不可信 ⇒ 禁止任何自动化更新（仅允许人工 FullReCert）⇒ 子集；
- OCSC 失效（依赖图不可得）⇒ 只接受"单一签发者 + 本地重放"的工件，拒绝一切 fork/第三方 ⇒ 子集；
- AOAP 失效（审计通道不可用）⇒ 保留上次审计通过的见证语料，冻结新增信任 ⇒ 子集；
- CFC+++ provenance 不可分辨 ⇒ 退回 v22 的 CFC++（模态多样）⇒ 等价 v22；
- 全部失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`（承接引理 162）。
- **关键不变式**：更新只经闸门、冻结可回退、污点只下游传播、放宽必重认证——四条都使失效方向单调指向"更保守"。

## 5. 预期贡献

1. **证书保持的在线学习**：把 conformal/召回/能耗等证书参数纳入保守性偏序，给出"无放宽晋升"的可机械核验闸门与 ACI + 反馈分离的漂移处置；
2. **开源证书供应链**：首次把证书效力定义为依赖 DAG 上的污点传播，并给出证书保持 diff / WIDENING 的机械判据与 fork 隔离语义；
3. **可证伪造的证书观**：把"通过攻击"而非"未被攻击"作为证书的正面证据，AOAP 让外部证伪者持续入场，bounty 激励对准"放宽"而非仅"崩溃"；
4. **来源多样的联邦共识**：CFC+++ 用 provenance 分组封堵"共享上游导致的伪独立共识"，把 v22 的相关失效风险延伸到供应链维度；
5. **可重放治理**：proof-carrying 更新记录使在线系统的每一次自适应都可事后逐位复核，衔接 v22 的 merkle 审计链。

## 6. 本轮最大风险

**一句话**：晋升闸门、漂移检测器与学习器消费的是**同一条闭环数据流**，一个缓慢的自诱导漂移可以让候选参数与验证缓冲"同步漂移"，于是闸门用一份看起来合格的证据**认证了漂移本身**——系统带着形式上有效的证书，自信地晋升了一张早已被自己的动作证伪的证书（"自我认证的漂移"；若闸门与学习器还共享同一被污染的上游工件，provenance 多样性只会提供虚假的安心）。

## 1. 关键算法骨架

```python
# ---------- IP-436 / 定义 923-924：保守性偏序与晋升闸门 ----------
@dataclass
class CertState:
    theta: object; kappa_c: float; alpha: float; eps_loc: float
    f_E: object; rules: RuleSet

def no_widening(C: CertState, Cp: CertState) -> bool:
    # C ≼_c Cp ：Cp 部署不弱于 C（不能更冒险）
    return (Cp.kappa_c >= C.kappa_c and Cp.alpha <= C.alpha
            and Cp.eps_loc <= C.eps_loc
            and C.rules.forbidden <= Cp.rules.forbidden
            and Cp.rules.permit  <= C.rules.permit
            and Cp.energy_core() <= C.energy_core())

class OnlineCertificateRefreshGovernor:
    def __init__(self, frozen: CertState, clsg, ocsc, aoap, recert):
        self.F_v = frozen; self.clsg = clsg; self.ocsc = ocsc
        self.aoap = aoap; self.recert = recert

    def promote(self, C_cand: CertState, B, now) -> tuple[bool, str]:
        # (a) 无放宽，或走完整重认证
        a = no_widening(self.F_v, C_cand) or self.recert.full(C_cand)
        # (b)(c) 在通过筛查的缓冲上检验覆盖与召回
        b = self.clsg.aci_coverage_ok(B, C_cand.alpha, eta=0.01)
        c = self.clsg.recall_lower_bound(B, C_cand) >= self.clsg.kappa_min
        # (d) 缓冲与部署可交换，且非自诱导漂移
        d = self.clsg.exchangeable_and_not_selfinduced(B, now)
        # (e) 回归 + 模糊后无见证
        e = len(self.aoap.active_witnesses(C_cand)) == 0
        # (f) 依赖闭包无污点 + 构建可复现
        f = self.ocsc.taint(self.ocsc.root_for(C_cand)) == 0
        verdict = all([a, b, c, d, e, f])
        self.log(UpdateRecord(B, C_cand, self.F_v, now, verdict, (a,b,c,d,e,f)))
        if verdict:
            self.F_v = C_cand            # 原子切换
        # 失败：保持 F_v（冻结回退），绝不做部分晋升
        return verdict, "OK" if verdict else "FROZEN"

# ---------- IP-437：ACI 覆盖 + 反馈分离 ----------
class ClosedLoopShiftFeedbackGuard:
    def aci_coverage_ok(self, B, alpha, eta):
        # 在线 conformal：alpha_t = alpha_{t-1} + gamma*(alpha - err_t)，检验长期覆盖
        return self.aci.running_coverage() >= 1 - alpha - eta
    def recall_lower_bound(self, B, C):
        # 以 C 的检测阈值在 B 上估计召回，取单侧置信下界（Clopper-Pearson）
        return clopper_pearson_lower(self.recall_on(B, C), conf=self.delta)
    def exchangeable_and_not_selfinduced(self, B, now):
        # 反馈分离：用机器人动作 a_t 作为协变量，检验 B 的条件分布
        # 与部署分布于给定 a 下是否同分布（条件可交换性，而非边缘）
        p_exch = self.exch_test.pvalue(B, condition_on=self.actions)
        p_feedback = self.feedback_test.pvalue(B, self.actions, self.rewards)
        return p_exch > self.p_min and p_feedback > self.p_min

class OpenCertificateSupplyChain:
    def taint(self, n) -> int:
        if self.attestation_invalid(n) or not self.build_reproducible(n):
            self.mark(n); return 1
        if any(self.taint(m) for m in self.deps(n)):   # 单向下游传播
            self.mark(n); return 1
        return 0
    def cert_diff(self, R, d) -> str:
        Rp = R.apply(d)
        if (Rp.forbidden >= R.forbidden and Rp.permit <= R.permit
                and not d.weakens_any_threshold()):
            return "PRESERVING"          # 只收缩：可继承父证书
        return "WIDENING"                # 放宽：强制 FullReCert + fork 隔离
    def fork(self, parent):
        # fork 默认继承空证书，禁止借父版本名誉
        return CertState.invalid_with_provenance(parent.id, "FORK_UNTRUSTED")
```

## 2. 命题与证明骨架

**引理 928（刷新单调）**：若每次晋升满足 `no_widening(F_v, C_cand)` 或 `FullReCert(C_cand)`，则任意时刻 `Exec_v23(t) ⊆ Exec_v22(t)`。
*证明骨架*：执行路径只读 `F_v`（P43/定义 924 的原子切换）。晋升或保持 `≼_c`（定义 923 逐项对应 v22 过滤器语义），或经 `FullReCert` 等价于离线重认证。失败路径保持旧 `F_v`。故不变式在每次切换点保持，归纳得证。

**引理 929（污点可靠）**：若 `taint(root)=0`，则部署所用工件闭包内不存在"签名无效 / 构建不可复现 / 篡改 / 已证伪"的祖先。
*证明骨架*：`taint` 对 `deps(n)` 递归且单向下游传播（定义 925）；任何违规祖先使自身及全部下游置 1，与 `taint(root)=0` 矛盾。

**引理 930（重放一致）**：若 `UpdateRecord` 的确定性重放复现同一 verdict 与逐项 trace，则审计者与签发者对同一次更新的判定一致；不可复现者按 P46 规范上"未发生"。

**引理 931（来源多样封堵相关共识）**：若所有投票共享同一 `provenance_group`，则 `provenance_ok=False`，仲裁退化为 `CI`（保守），即使计数与模态条件满足。

## 3. 实验设计

**E1 闭环漂移（在线学习）**：仿真中令用户姿态/衣着在 30 分钟内平滑漂移（held-out 分阶段注入）。对比（冻结 / 朴素在线学习 / CPOR 闸门）。指标：经验覆盖误差 `|1-α - cov|`、假晋升率（接受了实际放宽的更新比例）、任务成功率（活性）、`time-to-freeze`。预期：朴素在线学习覆盖崩坏但活性高；CPOR 覆盖保持而活性仅小幅下降。

**E2 fork 放宽攻击（开源）**：构造一个"只删一条 F 规则 / 调低 q_high"的恶意 fork，观察 `cert_diff=WIDENING` 是否必然拦截、`FullReCert` 是否触发、旧证书是否被错误继承。指标：放宽拦截率、误报（把收缩 diff 误判 WIDENING）率。

**E3 供应链投毒 + 来源多样**：两台机器人共享同一被污染的预训练检测器权重；对比 CFC++（模态多样）与 CFC+++（provenance 分组）。指标：错误共识率、攻击成功率。预期：CFC++ 因"两个副本=两票"而误合并，CFC+++ 退化为 CI。

**E4 开放审计对抗循环**：模拟外部审计者按 bounty 提交见证（含伪造垃圾 witness）。指标：真见证受理率、垃圾注入率、`time-to-invalidation`、回归语料增长、重放复现率（应为 100%）。消融：去掉闸门 / 去掉反馈分离 / 去掉污点传播，分别量化各模块贡献。

**E5 可重放审计**：对 E1–E4 的全部晋升记录做逐位重放，统计 verdict 复现率与不可复现根因（RNG 泄漏、浮点非确定、时钟依赖）。

## 4. 与基线的退化闭合

`Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`：OCRG/CLSG/OCSC/AOAP/PDC 任一失效均只使更新更难被接受或使仲裁更保守（P43–P46），不会放宽 v22 的域；全部失效即返回冻结的 v22 证书。**证书的新增维度（时间自适应、来源信任）只被"收紧"进入执行路径，从不被单独用来"放宽"几何/能量/规范/负信息的既有边界。**
