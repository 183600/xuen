# 第 69 轮（承接第 68 轮「CALM-RAS」IP-243~252；灵感循环第 2 轮；本轮灵感：「关节空间控制」×「自适应控制」）

> 第 68 轮给出了一句自陈死穴：**「标定能力越强，缓变故障越隐形」**。COF 是一个单帧集总的残差最小化器，它不区分「世界变了 / 传感器歪了 / 慢故障在长」——三者都投影到同一个残差空间 r_t，滤波器只做一件事：把残差压小。要把它压小，就把慢故障「标定」掉。这不是参数没调好，而是**信息结构缺失**：判据不在 r_t 的大小里，而在「同一物理事件在不同测量帧里留下的形状里」。
>
> 本轮两个灵感恰好提供了缺的两把尺：
> - **关节空间控制**提供一把「不依赖相机/外参标定的内感受尺」——关节编码器、电机电流、关节力矩构成自洽的动力学闭环；外部标定漂移动不了它，关节级故障也躲不进它。两把尺（外感受 vs 内感受）一交叉，故障/漂移/世界变化就有了可分辨的「签名」。
> - **自适应控制**提供一套现成的「什么时候允许改模型」的理论——持续激励（PE）、参数投影、复合/并发学习、对偶控制。它把 R68 那条粗暴的 0.1Hz 速率限制，替换成一条有信息论含义的纪律：**只有被激励、且在安全集内的方向才允许自适应；其余方向冻结并抬高不确定度**。
>
> 核心命题：**JAC-RAS（Joint-space Adaptive Control, Risk-Adaptive System）——用关节空间作为标定无关的计量锚，用自适应控制律把「校准」与「控制」统一到同一个带投影与激励门的双帧估计器里；测量可信度低时不是简单把 λ 抬高，而是把控制权限从任务空间收缩回关节空间的柔顺保持。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**我对自己身体的模型还成立吗**」——当身体模型与外感受测量冲突时，先信身体，退守关节空间。

## 0. 直觉与动机

**灵感 1（关节空间控制 → 内感受是标定无关的第二把尺）**
直觉：R68 的跨模态一致性（视觉 vs 触觉、事件对齐、零偏）全都在「外感受帧」里，而这个帧本身要被外参标定 c_ext 参数化——用一个可能已经歪掉的尺去校准另一个尺，天然存在共模盲区。但机器人的关节编码器 + 电机电流 + 关节力矩构成一个**内感受闭环**：逆动力学 τ = Y(q,q̇,q̈)π_j 只依赖本体测量，完全不需要相机外参。于是有了第二条独立方程。最关键的一条是**运动学锚约束**：τ_meas ≈ J(q;c_kin)^T F_meas + Y π_j——它把「关节力矩」和「外部力」钉在同一个静态等式上。若力传感器存在缓慢零偏 b_F，COF 会把它吸进标定；但关节力矩是独立测量，b_F 无法同时骗过 τ 和 F 两侧，于是 b_F 被这条锚约束「钉死」，无法隐形。**漂移可以骗过外感受一致性，却骗不过内外感受的交叉约束。**

**灵感 2（关节空间控制 → 任务空间控制把标定误差放大成控制误差）**
直觉：R68 的整个风险链其实经过一个被忽视的放大器——雅可比 J(q;c_kin)。任务空间控制把期望位姿经 IK 变成 q_d，再用 J^T 把笛卡尔误差映射成力矩；当 c_kin 有漂移，IK 的目标就偏，J^T 的映射也偏，标定误差被**投影进控制回路**，表现为「世界变了」或「执行器故障」。关节空间控制绕开了这个放大器：直接在 q 上闭环，力矩限制、速度限制、奇异位形都与外参无关。它给了一个**结构性的安全退路**：一旦外感受不可信，系统不是继续在任务空间里带着可疑标定飞，而是收缩回关节空间的柔顺保持——这是 R68 的 λ 标量缩放做不到的「换帧」。

**灵感 3（自适应控制 → 该不该改模型，是激励问题不是速度问题）**
直觉：R68 用 0.1Hz 速率限制来保证「快故障不被吸收」，但它对**慢故障**束手无策——慢故障恰好落在带宽内。自适应控制早就给出了更本质的判据：一个参数能否被辨识，取决于回归量是否**持续激励（PE）**，以及估计是否被**投影**在已知安全集内。于是纪律变成：
- 只有 G = ∫Y^TY 的特征值 ≥ α_pe 的方向才允许自适应（有信息才学）；
- 估计被投影到 Θ_safe（出厂辨识 + 负载包络给出的凸安全集），越界即判故障而非吸收（有界才学）；
- 无激励方向冻结并放大协方差 → U↑ → λ_floor↑（不知道就保守）。
这比速率限制更精细：它不再赌「快慢」，而是问「有没有信息、在不在界内」。

**灵感 4（自适应控制 → 对偶控制：可以用安全探针主动把隐形故障逼出来）**
直觉：慢故障之所以隐形，往往是因为它躲在「无激励方向」里（机器人长时间静止，力零偏就是一个 DC 模态）。自适应控制里的**对偶控制（dual control）**思想是：控制信号既执行任务，又同时用于辨识——必要时注入微小、任务安全的激励（关节 dither / 微量探测运动），把可疑方向的回归量秩抬高，让原本不可辨识的故障变得可观测。但要设**激励预算**：只在任务关键度允许、情绪风险低时探测（延续 R66 的高风险不冒险纪律），并保证探测不越出力矩/速度/工作空间不变集。**主动把它逼出来，而不是被动等它长大。**

**灵感 5（两灵感合流 → JAC-RAS 七组件与「换帧安全」）**
1. **JDM 关节空间动力学模型**：线性参数逆动力学 τ=Yπ_j，提供标定无关残差 r_j；
2. **KAC 运动学锚**：τ≈J^T F + Yπ_j，内外感受交叉约束，钉死力零偏与负载；
3. **SMX 签名矩阵**：把每个物理原因（外参漂移/关节零偏/执行器退化/力零偏/真实世界变化）在 (r_x,r_j,r_τF,r_F,r_e,r_w,r_c) 上的**形状**写成矩阵，故障判别变成结构化稀疏归因；
4. **FCR 帧对比归因**：升级 R68 的 CFA，用签名矩阵 + 世界变化一致性流形做稀疏 MAP，而不是集总后验；
5. **PAG 激励门**：升级 COF，自适应只在被激励且在界内方向进行，无激励方向冻结并抬高 U；
6. **DAC 双帧自适应控制**：关节空间自适应计算力矩 + 任务空间阻抗，按测量可信度分配权限 μ，可信度低 → μ→1 退守关节保持；
7. **EXB 激励预算 + PAC 投影有界提交**：安全探针与认证式参数提交，继承 CALM-RAS 的 CAC/SSG/MTM/RAS-WM†。

对 R68 风险的对症下药：
- R68「慢故障被标定吸收」→ 内外感受交叉签名 + 投影界 + 激励门，凡签名落在可吸收子空间 𝒜 之外的故障可检出；落在 𝒜 内的，明确标注为结构性盲区并靠主动探测或绝对计量溯源兜底。
- R68「标定越强故障越隐形」→ 从「压小残差」改为「解释残差的结构」：标定只允许解释它该解释的那些方向，剩下的必须留给故障假设。
- R68「任务空间带病运行」→ 权限换帧：可信度低时退回关节空间柔顺保持，力矩硬约束与标定无关。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（JAC-RAS 总览）** JAC-RAS = (JDM, KAC, SMX, FCR, PAG, DAC, EXB, PAC, CALM-RAS†)。三条新不变式：
(i) **关节力矩硬安全**：任何下发力矩先经投影 τ ← Π_𝒯(τ)，τ ∈ 𝒯（逐关节力矩/速度/功率上限），与标定无关；
(ii) **自适应许可证**：参数更新只在被持续激励且投影在 Θ_safe 内的子空间进行，其余方向冻结；
(iii) **权限换帧**：测量可信度低于阈值时，控制权限从任务空间收缩到关节空间柔顺保持（μ↑），而非在任务空间带病运行。

**定义 294（关节空间动力学模型 JDM）** 刚性体逆动力学线性参数化：τ = Y(q,q̇,q̈) π_j，π_j ∈ ℝ^{p_j}（质量/质心/惯量/粘滞与库仑摩擦/电机增益）。残差 r_j = τ_meas − Y(q,q̇,q̈) π̂_j。**r_j 只依赖本体测量，不含任何相机外参 c_ext，故对标定漂移免疫。**

**定义 295（运动学锚 KAC）** 在准静态或已知加速度段，τ_meas = J(q;c_kin)^T F_meas + Y(q,q̇,q̈)π_j + ε。定义交叉残差 r_τF = τ_meas − [J^T F_meas + Y π̂_j]。它在**不依赖绝对外参**的前提下，把关节力矩与外部力绑在同一个等式：力零偏 b_F 使 r_F 与 r_τF 同号偏移，而外参漂移只动 r_x 不动 r_τF——两者签名正交。

**定义 296（多帧残差向量）** r = (r_x, r_j, r_τF, r_F, r_e, r_w, r_c)，其中 r_x = x_vis − T(q;ĉ_kin)（任务空间运动学残差）、r_F = F_tac − F_vis（力通道残差）、r_e/r_w/r_c 继承 R68（情绪环、世界模型、标定残差）。

**定义 297（签名矩阵 SMX）** 在工况点线性化，S ∈ ℝ^{m×p}，S_{k,h} = ∂E[r_k]/∂θ_h，h 遍历物理原因参数 θ = (δc_ext, δc_kin, δπ_j^f, δb_F, ΔF_w)。每个原因有结构化稀疏签名（多数通道为 0）。**世界变化**不是任意向量，而被约束在一致性流形 𝒲 上（定义 305）——真实外部扰动必须同时解释 r_x、r_τF、r_F 且由同一 (ΔF,Δx) 生成；故障则做不到。

**定义 298（帧对比归因 FCR）** 升级 CFA：
θ̂ = argmin_θ ‖r − Sθ‖²_{Σ^{-1}} + λ_s‖θ‖_0，s.t. 若含世界变化分量则 (ΔF,Δx) 满足 𝒲 约束；用 OMP/组 lasso 近似求解。输出稀疏原因集合 Ĥ 与后验 p(H|r)。**判据从「哪个假设让残差最小」升级为「哪个最小的原因集合能同时解释所有帧」。**

**定义 299（自适应律与投影）** 关节空间自适应计算力矩：s = ė + Λe，e = q_d − q；π̂̇_j = Proj_{Θ_j}(Γ Y^T s)。Proj 保证 π̂_j 恒在凸安全集 Θ_safe 内（出厂辨识 + 负载包络给出半径 ρ）。

**定义 300（持续激励门 PAG）** 滑窗 T_pe 内回归量 Gram G = ∫ Y^T Y dt = V Λ V^T。仅允许在 λ_i ≥ α_pe 的特征方向 i 上自适应：π̂̇_j ← V diag(1[λ_i≥α_pe]) V^T π̂̇_j。未被激励方向的估计协方差 ≥ σ²/α_pe，注入 U(ĉ) 与 Θ_safe 的松弛量，触发 λ_floor↑。

**定义 301（双帧自适应控制 DAC）** u = μ·u_joint + (1−μ)·u_task，μ ∈ [0,1] 为关节空间权限：
u_joint = Y(q,q̇,q̈_d)π̂_j + K_p e + K_d ė + u_robust；
u_task = J^T [K_x(x_d − x) + K_v(ẋ_d − ẋ)]；
μ = clip(1 − w_U·U(ĉ) − w_H·P(fault) + w_m·λ_early, 0, 1)，且任务空间速度上限 v_safe·(1−μ)。语义：测量越不可信、故障后验越高，越退回关节空间（此时 v_safe→0 即柔顺保持）。

**定义 302（激励预算 EXB）** 探针 v_p ∈ ℝ^n，‖v_p‖_∞ ≤ B_ex，加到 q_d 上；选择 v_p 最大化信息价值 VoI(v_p) = E[ΔH(belief)] − c_risk(v_p) − c_task(v_p)，受不变集约束 (q,q̇,τ) ∈ 𝒮_safe。当情绪风险 ≥ τ_emo 或任务关键度过高时暂停探测（继承 R66 纪律）。

**定义 303（投影有界认证提交 PAC）** 升级 CAC，新增三关：
(a) 参数变更必须满足 π̂′ ∈ Θ_safe 且 Δπ̂ 在激励子空间内（无激励方向冻结）；
(b) canary 故障签名在更新后仍落在故障子空间（未被吸收）；
(c) 回放上 Lyapunov 函数下降 V̇ < 0（稳定性关）。
全过才原子换装。

**定义 304（可吸收子空间与吸收指数）** 𝒜 = span{可辨识且在界内的自适应方向}。故障签名 s_f 的**吸收指数** κ_abs = ‖P_𝒜 s_f‖ / ‖s_f‖ ∈ [0,1]。κ_abs≈0 ⇒ 结构性可检出；κ_abs≈1 ⇒ 结构性不可辨识（必须靠另一帧或绝对计量）。这是 R68「慢故障隐形」问题的精确刻画。

**定义 305（世界变化一致性流形）** 𝒲 = {S_world[ΔF;Δx] : (ΔF,Δx) ∈ ℝ^6×ℝ^3}。世界变化假设仅当 dist(r,𝒲) ≤ ε_w 时允许；故障假设无此约束。**一致性 vs 不自洽，是世界变化与故障的分水岭。**

**定义 306（JAC 证书 J_CALM⁺）** 在 J_CALM 基础上增加 joint_model_hash、excitation_spectrum（G 的特征值）、authority_mu、projection_margin、probe_log、κ_abs。Valid ⇔ Valid(J_CALM) ∧ τ∈𝒯 ∧ π̂∈Θ_safe ∧ 无激励方向未变更 ∧ authority_mu 与 U 单调一致。

**定义 307（干扰集扩展）** ℰ_JAC = ℰ_CALM × ℰ_proj × ℰ_pe × ℰ_probe；ℰ_proj = {投影越界, 安全集误设}，ℰ_pe = {激励饥饿, 虚假可辨识}，ℰ_probe = {探测失稳, 探测与情绪冲突}。

**定义 308（管线）** 离线：出厂辨识 π_j → 定义 Θ_safe → 训练关节自适应控制律 → 估计签名矩阵 S（注入式标定实验）。在线：每控制周期 JDM/KAC 残差 → SMX/FCR 结构化归因 → PAG 门控自适应 + DAC 权限分配 + EXB 按需探测 → PAC 认证提交。

**定义 309（稳定性）** Lyapunov V = ½ s^T M(q) s + ½ π̃_j^T Γ^{-1} π̃_j，π̃_j = π̂_j − π_j。投影 + 有界扰动下 V̇ ≤ −k‖s‖² + ε_d，跟踪误差一致最终有界；力矩硬约束由 Π_𝒯 保证。

**定义 310（退化一致性）** 当 μ=0、𝒜=全空间、S=I、𝒲=ℝ^m 时，JAC-RAS 退化为 CALM-RAS；故 R68 全部保证被继承，R69 是严格细化。

# IP-253 JDM：关节空间逆动力学残差（标定无关）
class JointDynamicsModel:
    def __init__(self, pi_hat, Theta_safe):
        self.pi, self.Theta = pi_hat, Theta_safe          # 参数 + 凸安全集

    def residual(self, q, qd, qdd, tau_meas):
        Y = rigid_body_regressor(q, qd, qdd)             # τ = Y π，线性参数化
        return tau_meas - Y @ self.pi, Y


# IP-254 KAC：运动学锚（内外感受交叉约束）
def kinematic_anchor_residual(q, tau_meas, F_meas, pi_hat, c_kin):
    Y = rigid_body_regressor(q, qd, qdd)
    return tau_meas - (jacobian(q, c_kin).T @ F_meas + Y @ pi_hat)


# IP-255/256 SMX + FCR：签名矩阵 + 结构化稀疏归因
class FrameContrastResolver:
    def __init__(self, S, Sigma, W_manifold, eps_w):
        self.S, self.Sigma, self.W, self.eps_w = S, Sigma, W_manifold, eps_w

    def resolve(self, r):
        # 世界变化假设必须落在一致性流形 W 附近，否则不支持
        allow_world = dist_to_manifold(r, self.W) <= self.eps_w
        Hs = hypotheses(include_world=allow_world)
        theta = omp_sparse(r, self.S[:, Hs], self.Sigma, l0=2)   # 稀疏原因集合
        cause = argmin_over_subsets(Hs, lambda h: mse(r, self.S[:, h] @ theta[h]))
        return cause, theta, manifold_consistency(r, self.W)


# IP-257 PAG：持续激励门 + 投影
class ExcitationGate:
    def __init__(self, alpha_pe, T_pe, Theta_safe):
        self.alpha, self.T, self.Theta = alpha_pe, T_pe, Theta_safe

    def gate_and_project(self, Y_hist, pi_dot, pi_hat):
        G = integrate_outer(Y_hist, self.T)               # G = ∫ YᵀY
        lam, V = eigh(G)
        keep = (lam >= self.alpha).astype(float)          # 只学被激励方向
        pi_dot = V @ np.diag(keep) @ V.T @ pi_dot
        pi_hat = project_convex(pi_hat + pi_dot, self.Theta)  # 有界才学
        U_pe = 1.0 / max(lam.min(), 1e-6)                 # 无激励 → 不确定度
        return pi_hat, pi_dot, U_pe, lam


# IP-258 DAC：双帧自适应控制 + 权限分配
def dual_frame_control(q, qd, e, ed, x, xd, xdot, pi_hat, U, P_fault, c_kin):
    u_joint = rigid_body_regressor(q, qd, acc_des(e, ed)) @ pi_hat \
              + Kp @ e + Kd @ ed + robust_term(e, ed)
    u_task  = jacobian(q, c_kin).T @ (Kx @ (xd - x) + Kv @ (xdot_d - xdot))
    mu = clip(1 - w_U*U - w_H*P_fault, 0.0, 1.0)          # 不可信 → 退守关节
    return mu*u_joint + (1-mu)*u_task, mu, v_safe*(1-mu)


# IP-259 EXB：激励预算 / 安全探针
def excitation_budget(suspect_dir, risk_emo, task_crit, S_safe, B_ex):
    if risk_emo >= tau_emo or task_crit >= tau_crit:
        return 0.0                                        # 高风险不冒险
    v_p = argmax_voi(suspect_dir, B_ex, S_safe)            # 信息价值 − 风险
    return v_p if within_invariant_set(v_p, S_safe) else 0.0


# IP-262 主闭环：JAC-RAS round
def JAC_RAS_round(M, obs):
    q, qd, qdd, tau, F, x_vis = obs.robot_state, obs.F_meas, obs.x_vis
    # 1) 内感受残差（标定无关）+ 运动学锚
    r_j,  Y = M.jdm.residual(q, qd, qdd, tau)
    r_tF    = M.kac.residual(q, qd, qdd, tau, F, M.pi_hat, M.c_kin)
    r_x     = x_vis - forward_kinematics(q, M.c_kin)
    r       = pack(r_x, r_j, r_tF, obs.r_F, obs.r_e, obs.r_w, obs.r_c)

    # 2) 帧对比结构化归因（替代 R68 集总后验）
    cause, theta, w_consistency = M.fcr.resolve(r)

    # 3) 激励门 + 投影自适应（只学有信息且在界内的方向）
    M.pi_hat, pi_dot, U_pe, lam = M.pag.gate_and_project(
        M.Y_hist, M.adapt_law(r), M.pi_hat)
    U = M.calm.cof.calibration_uncertainty(theta) + U_pe

    # 4) 权限换帧：可信度低 → 关节空间柔顺保持
    u, mu, v_lim = M.dac.control(q, qd, e, ed, x_vis, obs.x_d,
                                 obs.xdot_d, M.pi_hat, U, cause.p_fault, M.c_kin)

    # 5) 按需安全探针（情绪/任务门控）
    v_p = M.exb.probe(cause.suspect_dir, obs.risk_emo, obs.task_crit, M.S_safe, M.B_ex)

    # 6) 力矩硬投影 + 风险下限（继承 R68 λ_floor）
    u = project_torque(u + v_p, M.Torque_set)
    lam_risk = max(M.calm.efs.risk_scale(cause), M.calm.lam_floor(U))

    # 7) 认证提交 + 异步审计（继承 CAC/VQAuditor-C，增加投影/激励/稳定性三关）
    M.vqa_c.submit_async(cause, {'U': U, 'mu': mu, 'kappa_abs': cause.kappa_abs})
    M.pac.maybe_commit(M.shadow, M.time_since_last_commit)
    return u, mu, lam_risk, cause, (U, lam)
```

## 3. 推导

**引理 16（跨帧可分性——为什么关节空间能补 R68 的盲）** 设标定漂移与故障在残差空间的均值签名分别为 s_c、s_f，噪声同方差 σ²I。二假设 Bayes 误判率 ≤ ½·exp(−‖s_f−s_c‖²/(8σ²))。可分性由**签名的角度分离**决定，而非 R68 的标定带宽。R68 只用外感受帧时，慢故障与漂移的签名近似共线（‖s_f−s_c‖ 小）；引入关节空间后，故障在 r_j/r_τF 上有非零投影而漂移没有，‖s_f−s_c‖² 至少增加 ‖P_{r_j,r_τF} s_f‖²，误判率指数下降。**系：R68 的「带宽即盲区」被替换为可量化的「签名分离度」。**

**引理 17（投影有界吸收——吸收的边界在哪里）** 参数投影到半径 ρ 的凸集 Θ_safe。故障参数偏移 θ_f 若满足 ‖θ_f‖ > ρ + margin，则自适应后残差 ≥ ‖θ_f‖ − ρ > 0，恒可检出；反之 ‖θ_f‖ ≤ ρ 的故障可被吸收。**故「小故障隐形」不是工程失误而是结构性事实，必须靠另一帧或绝对计量兜底——本轮第一次把它写清楚，而不是假装能解决。**

**引理 18（激励饥饿的保守性）** 在 λ_i(G) < α_pe 的方向，估计协方差 ≥ σ²/α_pe，U_pe 抬高，λ_floor 触发，控制权限 μ 抬升。**无信息的方向永远不会被静默适配**；主动探针可把 λ_i 抬到 α_pe 以上，以有界风险换取可辨识性。

**定理 16（JAC-RAS 安全与可分性）** 在 A95–A101 下：
1. **硬力矩安全**：由 Π_𝒯 与关节空间控制，τ(t) ∈ 𝒯 对所有 t 成立（与标定无关，任务空间方法无法给出此保证）；
2. **故障可分性**：对签名 s_f ∉ 𝒜 的故障，检出概率 ≥ 1−δ 且**不随标定自适应增强而下降**（引理 16、17）；误判率 ≤ ½·exp(−σ_min²(Δ)/8σ²)；
3. **保守收缩**：无激励方向或越界方向 ⇒ U↑ ⇒ λ_floor ≥ 0.8、μ↑、任务速度 ≤ v_safe(1−μ)——测量不可信永远导向收缩；
4. **稳定性**：投影 + 有界扰动下 V̇ ≤ −k‖s‖² + ε_d，跟踪误差一致最终有界；
5. **零静默吸收**：无激励/越界方向冻结，故障无法被这些方向吸收（由构造保证）。

**定理 17（对偶探测安全性）** EXB 的不变集守卫保证探测保持 (q,q̇,τ) ∈ 𝒮_safe；单次探测信息增益 ≥ ΔI_min 否则拒绝；情绪风险 ≥ τ_emo 时暂停探测。探测不能越出力矩/速度上限（Π_𝒯 + 不变集）。

**定理 18（退化一致性）** μ=0、𝒜=全空间、S=I 时 JAC-RAS ≡ CALM-RAS，R68 全部保证被继承；JAC-RAS 是严格细化而非替换。

## 6. 本轮最大风险

**一句话**：JAC-RAS 的可分性定理完全押在「关节空间刚性体模型与其安全集 Θ_safe 是对的」这一假设上——**若存在未建模动力学（负载突变、柔性模态、摩擦迟滞），或 Θ_safe 被误设，则一个慢故障与一次合法负载/模型变化会在同一个「未建模子空间」里投影出几乎相同的签名；投影器会把故障当作「该自适应的模型误差」吸收掉**，R68 的「标定吸收」失败就以「自适应吸收」的新面孔原地复活——而且这次连速率限制这道旧防线也没有了，因为自适应恰恰被设计成允许慢变。**最危险的故障，是那个看起来像合法负载变化的故障。**

**次级风险与缓解**：
1. **模型误设 / 参数不可辨识**：Θ_safe 误设 → 投影有界吸收（引理 17）→ 靠绝对计量溯源 + 定期注入式标定 + E290 如实暴露盲区；
2. **签名矩阵病态**：跨帧签名近似共线 → 条件数监控 + 主动探针增加秩 + 降级为保守归因；
3. **探针风险**：探测引入扰动/情绪冲突 → 不变集守卫 + 情绪/任务门控 + 单次信息增益门槛（定理 17）；
4. **激励饥饿常态化**：长期静止导致普遍不可辨识 → 用「不可辨识即保守」纪律兜底，但吞吐下降；
5. **自适应与控制耦合失稳**：高频自适应引发抖振 → 投影 + 激励门 + 复合学习 + PAC 的 Lyapunov 关；
6. **换帧抖动**：μ 频繁切换引起控制不连续 → μ 加变化率限制与滞环，换装窗口冻结权限。

# IP-253 JDM：关节空间逆动力学残差（标定无关）
class JointDynamicsModel:
    def residual(self, q, qd, qdd, tau_meas):
        Y = rigid_body_regressor(q, qd, qdd)              # τ = Y π，线性参数化
        return tau_meas - Y @ self.pi, Y

# IP-254 KAC：运动学锚（内外感受交叉约束）
def kinematic_anchor_residual(q, qd, qdd, tau_meas, F_meas, pi_hat, c_kin):
    Y = rigid_body_regressor(q, qd, qdd)
    return tau_meas - (jacobian(q, c_kin).T @ F_meas + Y @ pi_hat)

# IP-255/256 SMX + FCR：签名矩阵 + 结构化稀疏归因
class FrameContrastResolver:
    def resolve(self, r):
        allow_world = dist_to_manifold(r, self.W) <= self.eps_w   # 世界变化须自洽
        Hs = hypotheses(include_world=allow_world)
        theta = omp_sparse(r, self.S[:, Hs], self.Sigma, l0=2)    # 稀疏原因集合
        cause = argmin_over_subsets(Hs, lambda h: mse(r, self.S[:, h] @ theta[h]))
        return cause, theta, manifold_consistency(r, self.W)

# IP-257 PAG：持续激励门 + 投影
class ExcitationGate:
    def gate_and_project(self, Y_hist, pi_dot, pi_hat):
        G = integrate_outer(Y_hist, self.T)               # G = ∫ YᵀY
        lam, V = eigh(G)
        keep = (lam >= self.alpha).astype(float)          # 只学被激励方向
        pi_dot = V @ np.diag(keep) @ V.T @ pi_dot
        pi_hat = project_convex(pi_hat + pi_dot, self.Theta)   # 有界才学
        return pi_hat, pi_dot, 1.0 / max(lam.min(), 1e-6), lam

    u_joint = rigid_body_regressor(q, qd, acc_des(e, ed)) @ pi_hat \
              + Kp @ e + Kd @ ed + robust_term(e, ed)
    u_task  = jacobian(q, c_kin).T @ (Kx @ (xd - x) + Kv @ (xdot_d - xdot))
    mu = clip(1 - w_U*U - w_H*P_fault, 0.0, 1.0)          # 不可信 → 退守关节
    return mu*u_joint + (1-mu)*u_task, mu, v_safe*(1-mu)

# IP-259 EXB：激励预算 / 安全探针
def excitation_budget(suspect_dir, risk_emo, task_crit, S_safe, B_ex):
    if risk_emo >= tau_emo or task_crit >= tau_crit:
        return 0.0                                        # 高风险不冒险
    v_p = argmax_voi(suspect_dir, B_ex, S_safe)            # 信息价值 − 风险
    return v_p if within_invariant_set(v_p, S_safe) else 0.0

# IP-262 主闭环
def JAC_RAS_round(M, obs):
    r_j,  Y = M.jdm.residual(obs.q, obs.qd, obs.qdd, obs.tau)
    r_tF    = M.kac.residual(obs.q, obs.qd, obs.qdd, obs.tau, obs.F, M.pi_hat, M.c_kin)
    r_x     = obs.x_vis - forward_kinematics(obs.q, M.c_kin)
    r       = pack(r_x, r_j, r_tF, obs.r_F, obs.r_e, obs.r_w, obs.r_c)

    cause, theta, w_consistency = M.fcr.resolve(r)        # 结构化帧对比归因
    M.pi_hat, pi_dot, U_pe, lam = M.pag.gate_and_project( # 激励门 + 投影
        M.Y_hist, M.adapt_law(r), M.pi_hat)
    U = M.calm.cof.calibration_uncertainty(theta) + U_pe

    u, mu, v_lim = M.dac.control(obs.q, obs.qd, obs.e, obs.ed, obs.x_vis,
                                 obs.x_d, obs.xdot_d, M.pi_hat, U,
                                 cause.p_fault, M.c_kin)   # 双帧 + 权限换帧
    v_p = M.exb.probe(cause.suspect_dir, obs.risk_emo,
                      obs.task_crit, M.S_safe, M.B_ex)     # 按需探针
    u = project_torque(u + v_p, M.Torque_set)              # 力矩硬投影
    lam_risk = max(M.calm.efs.risk_scale(cause), M.calm.lam_floor(U))

    M.vqa_c.submit_async(cause, {'U': U, 'mu': mu, 'kappa_abs': cause.kappa_abs})
    M.pac.maybe_commit(M.shadow, M.time_since_last_commit)
    return u, mu, lam_risk, cause, (U, lam)
```

## 4. 推导

**引理 16（跨帧可分性）** 标定/故障签名 s_c、s_f，同方差 σ²I，误判率 ≤ ½·exp(−‖s_f−s_c‖²/(8σ²))。分离由签名角度决定；引入关节空间后 ‖s_f−s_c‖² 至少增加 ‖P_{r_j,r_τF}s_f‖²，误判率指数下降——把 R68 的「带宽即盲区」替换为可量化的「签名分离度」。

**引理 17（投影有界吸收）** 投影到半径 ρ 的 Θ_safe：‖θ_f‖ > ρ+margin ⇒ 自适应后残差 ≥ ‖θ_f‖−ρ > 0，恒可检出；‖θ_f‖ ≤ ρ 可被吸收——「小故障隐形」是结构性事实，须靠另一帧/绝对计量兜底。

**引理 18（激励饥饿的保守性）** λ_i(G) < α_pe 方向估计协方差 ≥ σ²/α_pe，U_pe 抬高，λ_floor 与 μ 触发；无激励方向永不静默适配；探针可抬秩，以有界风险换可辨识性。

**定理 16（JAC-RAS 安全与可分性）** A95–A101 下：
1. τ(t) ∈ 𝒯 ∀t（投影 + 关节控制，与标定无关）；
2. 对 s_f ∉ 𝒜，检出概率 ≥ 1−δ 且不随标定自适应增强而下降；
3. 无激励/越界 ⇒ U↑、λ_floor ≥ 0.8、μ↑、任务速度 ≤ v_safe(1−μ)；
4. 投影 + 有界扰动 ⇒ V̇ ≤ −k‖s‖²+ε_d，一致最终有界；
5. 无激励/越界方向冻结 ⇒ 零静默吸收（构造保证）。

**定理 17（对偶探测安全性）** 不变集守卫使探测保持 (q,q̇,τ)∈𝒮_safe；单次信息增益 ≥ ΔI_min 否则拒绝；情绪风险 ≥ τ_emo 暂停；探测不越力矩/速度上限。

**定理 18（退化一致性）** μ=0、𝒜=全、S=I ⇒ JAC-RAS ≡ CALM-RAS；R68 全部保证被继承，R69 为严格细化。

## 7. 本轮最大风险

**一句话**：JAC-RAS 的可分性完全押在「关节空间刚性体模型与其安全集 Θ_safe 是对的」这一假设上——**若存在未建模动力学（负载突变、柔性模态、摩擦迟滞）或 Θ_safe 被误设，一个慢故障与一次合法负载/模型变化会在同一个「未建模子空间」里投影出几乎相同的签名；投影器会把故障当作「该自适应的模型误差」吸收掉**，R68 的「标定吸收」失败以「自适应吸收」的新面孔复活，而且这次连速率限制这道旧防线也没了，因为自适应恰恰被设计成允许慢变。**最危险的故障，是那个看起来像合法负载变化的故障。**

**次级风险与缓解**：模型误设/参数不可辨识（Θ_safe 误设 → 投影有界吸收 → 绝对计量溯源 + 定期注入式标定 + E290 如实暴露盲区）；签名矩阵病态（条件数监控 + 探针增秩 + 保守降级）；探针风险（不变集守卫 + 情绪/任务门控 + 信息增益门槛）；激励饥饿常态化（「不可辨识即保守」兜底，吞吐下降）；自适应-控制耦合失稳（投影 + 激励门 + 复合学习 + PAC 的 Lyapunov 关）；换帧抖动（μ 变化率限制 + 滞环 + 换装窗口冻结权限）。
