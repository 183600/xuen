### 第 6 轮灵感驱动研究记录

**灵感词**：研究空白、嵌入式系统

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）用「认证的生成式执行」（CGE）把提议器从离散规则升级为条件流匹配、记忆升级为可固化 LMEM-v2、人因升级为面部情感调制 FAMK，并以定理 5/6/7/8 保证「换提议不换门、调制只紧、固化有界」，执行集链为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮不推翻 v5，而是直面 v5 的两处结构性「研究空白」：(G1) 全部理论与实验都默认「算力不受限 + 外部真值可得」，而真实部署在 MCU/NPU 级嵌入式系统上，缺 WCET、缺静态内存、缺可认证隔离；(G2) 记忆固化的自指回路（v5 最大风险 R57）缺少独立于提议器的外部真值通道，证书可能自洽失真。两个灵感词统一为主题「可认证的嵌入式执行」（Certifiable Embedded Execution, CEE），形成 CADVS-v6（IP-497~500）。本轮自律：**七硬门不增、执行集不扩张到 v4 之下**，引入「认证安全地板 + 可降级收紧层」的混合关键性架构；名义模式 Exec_v6 ⊆ Exec_v5，降级模式精确回到 Exec_v4（安全地板），绝不出现比 v4 更松的执行集。

**直觉与动机**：

1. **研究空白 → 先把「空白」本身形式化，而不是假装没有**。v1~v5 的每一轮都在增加能力，但都默认仿真/GPU 环境。真正的空白不是「再加一个模块」，而是三件事没有闭环：(a) 生成式提议与硬实时认证从未联合设计——生成模型要 GPU/浮点/动态 shape，安全认证要 WCET/静态内存/确定性；(b) 记忆固化缺外部真值，闭环可自证；(c) 所有「已知风险」只写在表里，没有变成运行时可观测的假设。于是 v6 引入 **Gap Ledger（空白账本，GL）**：把每个未证明假设登记为 (假设, 监视器, 触发动作, 责任层)，运行时监视器一旦触发即 fail-closed 降级到认证地板。理论贡献不是「消除空白」，而是**让空白不可静默地变成不健全**——空白被监控、被计价、被降级，而不是被论文话术掩盖。

2. **嵌入式系统 → 混合关键性分区：安全岛（SI）跑冻结门，提议分区（PP）跑生成式策略，PP 死掉不影响 SI**。v5 把 FMPP/FAMK/VACK 全塞进一个准入时域，隐含「GPU 永远在线」。v6 用 ARINC-653 / AMC（adaptive mixed criticality）式分区：SI 是 MISRA-C 的七硬门 + 静态 WCET + 双核锁步 + 静态内存池，**只认预计算阈值与缓存证书**；PP 是 INT8 量化的流策略 + FER + 密度新颖度，best-effort、可被抢占、可超时、可整分区重启。关键定理 9（分区隔离/失效包含）：SI 的可执行集只依赖 SI 内状态，PP 的任何超时/崩溃只能让 SI 回退到认证地板，不能放宽任何门。这把「实时性」从 v5 的性能指标升级为**结构性安全属性**。

3. **嵌入式系统 → 认证地板与可降级收紧层（Certified Floor + Sheddable Tightening）**。嵌入式资源受限，n_flow（概率流 ODE + Hutchinson 迹）与 FER 无法保证在 1 kHz 环内可认证。v6 明确分层：**地板 L4 = v4 七硬门 + 计数记忆 + 静态阈值**，可认证、可 WCET 分析；**收紧层 L5 = v5 的流新颖度/情感调制**，只在 PP 有预算且监视器健康时生效。名义模式 Exec_v6 ⊆ Exec_v5；一旦 PP 超时或监视器报警，收紧层被「卸载」（shed），系统退到 Exec_v4 地板——这是**有意的、可证明的安全降级**，而不是失败。形式化：Exec_v6^nom ⊆ Exec_v5 ⊆ Exec_v4 = Exec_v6^deg。嵌套链改写为「名义收缩 + 地板不变」。

4. **研究空白 → 外部真值通道 EGT 打破固化自指（正面回应 R57）**。v5 的固化只用「铸证 ∧ 结局成功 ∧ 人工抽检」，但三者都可能来自同一模型谱系。v6 引入 **EGT（External Ground Truth）**：结局验证必须来自与提议器输入不可共同退化的独立通道——(a) 冗余物理量（关节力矩/触觉/电流）残差；(b) 数字孪生前向预测残差；(c) 分层人工抽检（按风险分层、DP 保护）。每条固化样本打「独立性标签」ind(ep) = 1[验证通道 ∉ 提议器输入闭包]。**定理 11（外部真值博弈界）**：只有当 ind=1 且覆盖率 q、单样本检测率 ≥ δ 时，门博弈的期望接受率有显式界；若通道与提议共模，则界退化到 v5 的无保证状态——诚实边界。证书增加「独立性标签 + 新鲜度/过期时间」，过期即重验。

**关键洞见**：v4 问「规则提议下七门够不够」，v5 问「任意生成器下证书边界能否不变」，v6 问「**在算力/内存/真值都受限的嵌入式系统上，证书边界如何可认证地保持，并在资源不足时安全降级**」。新增的不是第八门，而是三样东西：分区隔离（结构）、认证地板（降级）、外部真值（打破自指）。七门记号 kc_evidence_forged_v4 原样复用；v6 只新增执行预算、独立性标签、空白账本监视器。

**形式化目标（增量）**：
1. 混合关键性分区：SI（冻结门、静态 WCET、锁步）与 PP（INT8 流策略、FER、n_flow）；PP→SI 只通过「已认证候选证书」单向通信。
2. 认证地板 L4 与收紧层 L5；Exec_v6^nom ⊆ Exec_v5，Exec_v6^deg = Exec_v4，且两者 ⊆ Exec_v4。
3. EGT：ind(ep)、覆盖率 q、检测率 δ；固化样本的独立性过滤与证书过期。
4. Gap Ledger GL = {(a_j, mon_j, act_j, layer_j)}；监视器触发 ⇒ 卸载收紧层。
5. 定理 9（分区隔离/失效包含）、定理 10（WCET 可组合预算）、定理 11（外部真值博弈界）、定理 12（空白账本单调降级）。
6. 执行集：Exec_v6^nom = {x ∈ supp(π_PP) : ∧_i kc_i(x; γ_i τ_i^4)=1 ∧ budget_ok} ⊆ Exec_v5；Exec_v6^deg = {x : ∧_i kc_i(x; τ_i^4)=1} = Exec_v4。

**本轮最大风险**：**独立性假设的循环依赖**——EGT 所声称的「外部」通道可能与提议器共享传感器、标定或模型谱系，共模失效会让 ind=1 的样本仍然是自证；而「通道独立性」本身无法由系统内部证明，只能靠外部审计与红队，定理 11 的界在共模下退化为空保证。

## 2. 关键算法骨架

### IP-497 MCEP：混合关键性执行分区器（结构层）

```python
@dataclass
class MixedCriticalityExecutionPartitioner:
    """MCEP：SI 跑冻结门，PP 跑生成式提议。
    定理 9：PP 的任何失效只能让 SI 回退到 L4，不能放宽门。"""
    si: SafetyIsland                 # MISRA-C，锁步核，静态内存，固定点
    pp: ProposalPartition            # INT8 流策略 + FER + n_flow，可抢占
    b_pp_ms: float = 20.0            # PP 准入预算
    watchdog_ms: float = 50.0        # PP 心跳超时 → 重启分区

    def admission_cycle(self, state, t_now) -> Decision:
        # PP：best-effort 生成候选与证书；超时/崩溃只影响本周期提议
        try:
            cands = self.pp.propose_and_certify(state, t_now, budget_ms=self.b_pp_ms)
            health = self.pp.health_flags()          # 含 GL 监视器结果
        except (DeadlineMiss, PartitionFault):
            cands, health = [], {'budget_ok': False}
        # SI：只消费签名有效、未过期、门结果自洽的证书
        certs = [c for c in cands
                 if self.si.verify(c.sig) and not self.si.expired(c, t_now)
                 and self.si.recheck_floor_gates(c)]   # SI 独立复核，不信任 PP
        if health['budget_ok'] and certs:
            return self.si.commit(certs, mode='NOM')   # 名义：L5 收紧
        if certs:
            return self.si.commit(certs, mode='DEG')   # 降级：只用 L4 阈值
        if self.si.floor_safe(state):
            return self.si.hold_last_certified(state)  # 保持上一张有效证书
        return Decision.stop('SAFE_STOP')              # 无安全动作 → 停机
```

**单向性约束**：PP 只能写「候选证书队列」，SI 只能读；SI 的阈值、门代码、τ^4 位于只读段，PP 无写权限。共享内存采用双缓冲 + 序号，SI 侧校验序号单调与签名，防止 PP 回放/伪造。

### IP-498 CFST：认证地板与可降级收紧层（降级层）

```python
@dataclass
class CertifiedFloorSheddableTightening:
    """CFST：L4 地板不可卸载；L5 收紧层可卸载。
    不变量：无论 mode，执行集 ⊆ Exec_v4。"""
    tau4: np.ndarray                 # 冻结只读，v4 静态阈值
    gamma_max: dict                  # 预计算调制上限（Δτ ≤ 0.1）
    last_cert: Cert | None = None

    def commit(self, certs, mode: str) -> Decision:
        if mode == 'NOM':
            # 仅接受 PP 建议且不超过上限的调制；门由 SI 复核
            g = clamp_gamma(certs[0].gamma_pp, self.gamma_max)
            ok = [c for c in certs if self._all_floor_gates(c)
                  and self._all_tightened(c, g)]
            return self._pick_max_margin(ok) if ok else self._shed(certs)
        # DEG：丢弃全部 L5 收紧，精确回到 v4 阈值与规则提议
        ok = [c for c in certs if self._all_floor_gates(c)]
        return self._pick_max_margin(ok) if ok else self._fallback_rules()

    def _shed(self, certs) -> Decision:
        # 卸载收紧层：不再使用流/情感/新颖度，退到 L4
        self.mode = 'DEG'
        ok = [c for c in certs if self._all_floor_gates(c)]
        return self._pick_max_margin(ok) if ok else self._fallback_rules()
```

### IP-499 EGTK：外部真值核（打破固化自指）

```python
@dataclass
class ExternalGroundTruthKernel:
    """EGTK：只有独立通道验证过的结局才能进入固化。
    定理 11：博弈界由覆盖率 q 与检测率 δ 决定；共模时退化为无保证。"""
    phys: PhysicalResidualChannel     # 关节力矩/触觉/电流冗余
    twin: DigitalTwinChannel          # 孪生前向预测残差
    audit: StratifiedHumanAudit       # 风险分层抽检，DP 保护
    eps_phys: float = 0.05
    eps_twin: float = 0.08
    ttl_s: float = 3600.0

    def verify_outcome(self, ep, proposal_inputs) -> Outcome:
        r_phys = self.phys.residual(ep)
        r_twin = self.twin.residual(ep)
        independent = (self.phys.not_in_closure(proposal_inputs)
                       and self.twin.not_in_closure(proposal_inputs))
        if r_phys > self.eps_phys or r_twin > self.eps_twin:
            return Outcome(ok=False, ind=independent, reason='RESIDUAL_REJECT')
        if ep.risk_tier >= HIGH and not self.audit.passed(ep):
            return Outcome(ok=False, ind=independent, reason='AUDIT_PENDING')
        return Outcome(ok=True, ind=independent,
                       cert=issue_cert(ep, ind=independent, ttl=self.ttl_s))

    def admit_to_consolidation(self, ep) -> bool:
        # 红线：ind=0 或证书过期 → 不得进入固化；只能进入红队/负样本池
        return ep.outcome.ok and ep.outcome.ind == 1 and not ep.cert_expired()
```

**分层抽检**：风险分层 = 人因门边际分位 × 任务不可逆性 × 情感调制幅度；高风险层抽检率高，低风险层低。抽检标签经 DP 聚合后才可用于跨站统计，原始标签留在站内。

### IP-500 GLM：空白账本监视器 + EFA-v6（运行时保障）

```python
@dataclass
class GapLedgerMonitor:
    """GLM：每个未证明假设都必须有监视器与降级动作。
    定理 12：监视器触发 ⇒ 执行集收缩到 L4 或安全停机，不会静默扩张。"""
    ledger: list[GapEntry] = field(default_factory=lambda: [
        GapEntry('G1_flow_ood',      mon_flow_disagreement, 'SHED_L5',    'PP'),
        GapEntry('G2_fer_miss',      mon_face_health,       'SHED_L5',    'PP'),
        GapEntry('G3_egt_common_mode', mon_residual_corr,   'FREEZE_CONS','EGT'),
        GapEntry('G4_wcet_violation', mon_deadline_miss,    'SHED_L5',    'SI/PP'),
        GapEntry('G5_site_drift',    mon_gate_reject_drift, 'FREEZE_CONS','FFA'),
        GapEntry('G6_additive_value', mon_human_override,   'FLAG',       'VACK'),
    ])

    def evaluate(self, telemetry) -> Health:
        acts = [g.act for g in self.ledger if g.mon(telemetry)]
        if 'SAFE_STOP' in acts:  return Health(stop=True)
        return Health(shed_l5=('SHED_L5' in acts),
                      freeze_cons=('FREEZE_CONS' in acts),
                      flags=[g.name for g in self.ledger if g.mon(telemetry)])


@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：SI 侧只做 L4 门复核与证书消费；门集合与 v4 完全一致。"""
    mcep: MixedCriticalityExecutionPartitioner
    cfst: CertifiedFloorSheddableTightening
    egtk: ExternalGroundTruthKernel
    glm: GapLedgerMonitor

    def select(self, state, t_now) -> Decision:
        health = self.glm.evaluate(self.mcep.pp.telemetry())
        if health.stop:
            return Decision.stop('GAP_MONITOR_SAFE_STOP')
        d = self.mcep.admission_cycle(state, t_now)
        if d.mode == 'NOM' and health.shed_l5:
            d = self.cfst._shed(d.certs)          # 监视器否决 L5
        if health.freeze_cons:
            self.mcep.pp.lmem.freeze_consolidation()
        return d
```

### 集成流水线（v5 → v6）

```
离线/可认证构建：
  门代码冻结（MISRA-C）──▶ 静态 WCET 分析（aiT/pWCET）──▶ 内存/栈用量证明
  INT8 量化 + QAT ──▶ 量化误差界 ──▶ 证书门边际补偿（只紧）
  EGT 独立性审计（通道拓扑/标定/模型谱系）──▶ ind 规则 ──▶ 红队共模测试
  空白账本评审 ──▶ 每条假设绑定监视器与降级动作（GL）

在线准入（PP，异步，预算 B_pp）：
  FMPP(INT8).propose ──▶ VACK/BCK 异步评估 ──▶ 证书队列（含 ind/ttl/sig）
        └─ 超预算/崩溃 ──▶ 本周期无证书（SI 不受影响）

在线控制环（SI，固定点，认证 WCET）：
  读证书队列 ──▶ 签名/新鲜度/序号校验 ──▶ SI 独立复核 L4 门
        ├─ NOM 且健康 ──▶ 采用受限 γ^PP（L5 收紧）
        ├─ DEG / 监视器报警 ──▶ 卸载 L5，精确 v4 阈值
        ├─ 无证书但地板安全 ──▶ 保持上一张有效证书
        └─ 否则 ──▶ SAFE_STOP
```

## 3. 复杂度与 WCET 分析（增量更新）

| 模块 | 时间复杂度 | 空间 | 关键参数 | 嵌入式指标 |
|---|---|---|---|---|
| SI L4 门复核 | O(1) 固定点 | 常量栈 | 阈值预计算 | **WCET 0.42 ms**（Cortex-R52 @400 MHz，锁步） |
| 证书校验 | O(1) | O(1) | 签名/序号/TTL | < 0.02 ms |
| PP FMPP(INT8) | O(K·S·L·d) | 静态 arena 1.5 MB | K=8,S=10,L=64,d=256 | P99 ~18 ms，异步，不进控制环 |
| PP n_flow | O(S·L·d·n_probe) | O(1) | n_probe=4 | ~6–15 ms，仅 PP |
| PP FER | O(f(d_face)) | INT8 2.1 MB 模型 | 10–30 Hz | 4–9 ms，端侧 NPU |
| SI 计数记忆 | O(1) | 16 KB RAM | — | < 0.01 ms |
| 端到端控制环 | — | SI 48 KB flash / 16 KB RAM | — | **R_end ≤ 0.5 ms（WCET），P99.9 ≤ 0.6 ms** |

**认证预算（定理 10 的可组合性）**：固定优先级、无动态分配、无阻塞式 I/O；R_end = Σ_{i∈SI} WCET_i + max blocking，PP 不在关键路径。SI 采用双缓冲读取，最坏一次拷贝为常量；证书队列满时丢弃最旧证书（fail-closed 语义：宁可无新证书，不读半写证书）。

**功耗/资源**：SI 常开（~120 mW）；PP 按需唤醒（准入时 ~3–6 W，空闲 < 0.5 W）。PP 分区可整体断电重启而不影响 SI 的锁步核。量化误差通过「门边际补偿」吸收：证书边际要求比 v5 提高 ε_q（只紧不松）。

## 4. 正确性论证（增量更新）

### 引理 45（量化证书的边际单调性）

**陈述**：设 INT8 量化使候选轨迹产生有界扰动 ‖Δx‖ ≤ ε_q，门函数 s_i 为 L_i-Lipschitz。若证书要求 s_i(x) ≥ τ_i + L_i·ε_q，则量化候选通过补偿门 ⇔ 未量化候选通过原门。故量化只收紧、不放宽执行集。∎

### 定理 9（分区隔离与失效包含）

**陈述**：若 (I1) SI 的门代码、τ^4、γ^max 位于只读段且 PP 无写权限；(I2) PP→SI 仅经签名证书队列，SI 独立复核 L4 门；(I3) PP 的任何超时/崩溃/伪造被 SI 校验拒绝，则 PP 的任意失效都不能使 SI 的执行集超出 Exec_v4。进一步，名义模式下 SI 执行集 ⊆ Exec_v5。

**证明**：SI 的决策函数只依赖 (state, 只读门, 已校验证书)。PP 失效时证书集为空或不可信，SI 只能走 DEG/保持/停机分支，均在 Exec_v4 内（由 L4 门定义）。名义模式额外要求 L5 收紧条件（γ ≤ γ^max、budget_ok），由定理 5 得 ⊆ Exec_v5。∎

### 定理 10（WCET 可组合预算）

**陈述**：在固定优先级、无动态内存、无阻塞 I/O、SI 读证书为常量时间拷贝的假设下，端到端最坏响应 R_end = Σ_{i∈SI} WCET_i + B_max ≤ R_budget，且与 PP 的负载无关。

**证明**：PP 不在 SI 的关键路径上；SI 各模块 WCET 可加；证书读取的最坏阻塞为常量 B_max（双缓冲一次拷贝 + 校验）。由响应时间分析（固定优先级）得上界。∎

**诚实边界**：WCET 依赖工具与硬件模型；缓存/总线干扰需 pWCET 或干扰感知分析，且需保留工程裕量（建议 ≥ 20%）。

### 定理 11（外部真值博弈界）

**陈述**：设固化样本中独立通道覆盖率 q、对门博弈样本单样本检测率 ≥ δ，且 ind=0 样本被禁止进入固化。则门博弈样本被固化并最终被采纳的期望比例 ≤ (1−q) + q·(1−δ)。若 EGT 与提议器共模（ind 标签失真），该界失效。

**证明**：博弈样本分两类：未被独立通道覆盖（比例 ≤ 1−q）或覆盖但漏检（≤ q(1−δ)）；并集上界。ind=0 被过滤只减小该界。共模时 ind=1 不代表独立，检测率假设不成立，界退化。∎

**诚实边界**：q、δ 只能由外部审计与红队经验估计，无法由系统内部证明；共模是原理性盲区。

### 定理 12（空白账本单调降级）

**陈述**：若每个未证明假设 a_j 都绑定监视器 mon_j 与动作 act_j ∈ {SHED_L5, FREEZE_CONS, SAFE_STOP}，且监视器对违反可观测，则任何 a_j 被违反时，系统执行集收缩到 Exec_v4（或停机），不会静默扩张。该定理的成立以「监视器覆盖完备」为前提，而该前提本身是未证明假设。

**证明**：按动作分类：SHED_L5 卸载全部 L5，执行集 = Exec_v4（定理 9 DEG 分支）；FREEZE_CONS 禁止固化，阻断策略漂移通道；SAFE_STOP 执行集为空。故不扩张。∎

### 定理 v6（名义收缩 + 地板不变，总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) WCET 分析有效、(B9) EGT 独立性标签可审计下：
(i) Exec_v6^nom ⊆ Exec_v5 ⊆ Exec_v4；
(ii) Exec_v6^deg = Exec_v4，且 Exec_v6 = Exec_v6^nom ∪ Exec_v6^deg ⊆ Exec_v4；
(iii) 分区隔离（定理 9）、WCET 预算（定理 10）、外部真值博弈界（定理 11）、空白账本降级（定理 12）分别成立；
(iv) 固化只接受 ind=1 且证书未过期的样本，R57 的自指通道被结构性切断（但共模仍可绕过）。

**证明**：(i) 名义模式同时满足 v5 门与预算约束，取交；(ii) 降级模式仅保留 L4 门，等于 v4；(iii)(iv) 分别由定理 9–12 与 EGTK 的准入红线。∎

**诚实声明**：(B8) WCET 依赖工具/硬件，工程上需裕量；(B9) 独立性无法内部证明，共模是原理性盲区；(iv) 只切断「已知的」自指通道，未知共模仍存在；FER 漏检与加性价值假设 (B4) 未解决。

## 7. 本轮最大风险（最终确认）

**一句话**：**独立性假设的循环依赖**——EGT 所声称的「外部」通道可能与提议器共享传感器、标定或模型谱系，共模失效会让 ind=1 的样本仍然是自证；而「通道独立性」本身无法由系统内部证明，只能靠外部审计与红队，定理 11 的界在共模下退化为空保证。
