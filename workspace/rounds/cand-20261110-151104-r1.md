# 第 46 轮（承接第 45 轮 v10；本轮灵感：传感器标定 × 竞赛策略） · Calib-Strategy：标定租约与竞赛风险预算驱动的分层证书组合优化（四层架构 v11）

> 承接第 45 轮 v10 Energy-Context-Depth。v10 用能量租约把感知决策纳入 fail-closed，但留下隐含假设 H5：**分层共形半径 r_ω(m) 是静态的、其标定分布与部署一致、且标定本身免费**。UniBot 实机上，相机内参/外参、双目基线、IMU 零偏会随热漂移、振动、老化缓慢变化；共形覆盖保证只在「标定集分布 ≈ 部署分布」且「标定状态未越出漂移包络」时成立。另一方面，比赛是有限资源博弈：赛前标定时间有限、多个任务场地（arena）权重不同、对手与光照会主动制造退化。两个灵感词正好命中 H5：**传感器标定**把 r_ω 变成漂移标定状态 κ_t 的函数，并把「标定证书」升为根信任的第三条腿；**竞赛策略**把「标定哪些层、何时信任旧标定、把感知预算投到哪个 arena」变成有限预算下的风险约束组合优化。二者耦合出新问题：**在标定漂移、分布偏移与竞赛期望得分压力下，如何分配有限的标定/感知预算，使分层姿态证书在真正高权重的 arena 上仍 sound，而不是用期望得分优化悄悄卖掉稀有但致命的退化层安全**。

## 0. 直觉与动机

**灵感 1（传感器标定 → 标定租约与漂移包络）**
直觉：所有共形半径都建立在一次标定之上，标定一旦漂移，半径的覆盖保证就整体失效，而系统「看起来」仍在正常签发证书。把标定状态 κ_t=(内参,外参,基线,零偏,噪声模型) 建模为带漂移包络 D_cal 的随机过程，并签发**标定租约** ℓ_c=(κ̂_t, δ_κ, D_cal, FP_cal, τ_c, α_cal)：只有当实际标定残差在 δ_κ 内、且部署分布落在标定指纹 FP_cal 的 ε-球内、且未过期时，共形半径才有效。半径必须因标定不确定度膨胀：r_total=r_ω^conf + L_cal·δ_κ。标定租约与姿态租约、能量租约并列为根信任三条腿。

**灵感 2（竞赛策略 → 风险预算组合而非期望得分最大化）**
直觉：比赛不需要处处完美，只需在权重高的 arena 上稳、在低权重 arena 上可接受地退化。但若直接用 E[Score] 做标定与感知预算分配，优化器会天然砍掉「概率低、权重看似低、一旦发生却直接安全违例」的退化层标定，因为期望损失被概率稀释。正确姿势是把安全写成**尾部约束**（P(violation)≤β 或 CVaR 约束），在风险预算内做标定/感知的组合配置；这是一个两阶段随机规划：赛前选标定投入 x_a，赛中按上下文选模态与策略 π。

**灵感 3（耦合：标定预算 × 竞赛权重 → 战略性标定优先级）**
直觉：标定资源有限，应优先标定「高权重 × 高退化敏感 × 证书会真正被使用」的 (arena, ω, m) 组合。定义战略性标定价值 V_cal(a,ω,m)=∂E[Score_a]/∂r_ω(m) · 半径可缩减量 / 标定成本，并用它驱动赛前标定排序与 DCL 采集排序。竞赛策略决定标定花在哪，标定租约决定哪些证书在赛中可被声称。

**耦合升级（四层架构 v11）**：根信任层由「姿态租约 + 能量租约」升级为「姿态 + 能量 + 标定」三租约；L1 几何层的 r_ω(m) 改为 r_ω(m,ℓ_c)，并因 δ_κ 膨胀；L2 上下文/策略层新增竞赛策略组合器 SP（Strategy Portfolio）；L3 CAR 守卫增加标定租约校验与三租约级联失效；L4 DCL 采集任务加入「战略性标定价值」排序与标定数据分布指纹维护。

## 1. 形式化定义（增量：定义 54–57）

**定义 54（标定状态与漂移过程）**
标定状态 κ_t∈K（内参/外参/基线/零偏/噪声）。漂移过程
κ_{t+1}=A·κ_t+η_t，‖η_t‖≤η_max。
可观测量 e_t=h(κ_t)-h(κ̂_t)（标定板残差、自标定重投影误差）。漂移告警：‖e_t‖>D_cal，或对 κ̂ 的在线估计 ‖κ_t-κ̂_t‖>δ_κ。

**定义 55（标定租约与有效共形覆盖）**
标定租约 ℓ_c=(κ̂_t, δ_κ, D_cal, FP_cal, τ_c, α_cal, ε)。有效判据
Valid(ℓ_c,t)=[‖κ_t-κ̂_t‖≤δ_κ] ∧ [MMD(P_dep, FP_cal)≤ε] ∧ [t≤τ_c]。
**有效覆盖**：若 Valid(ℓ_c,t) 且原共形保证在 FP_cal 上成立，则对模态 m、层 ω
P(X_t∈P_t(ω,m) | ω,m,ℓ_c 有效) ≥ 1-α_p，
且半径膨胀 r_total(ω,m)=r_ω^conf(m)+L_cal·δ_κ，L_cal 为标定残差对姿态的 Lipschitz 常数。

**定义 56（竞赛 arena 与计分/风险模型）**
arena 集合 A，权重 w_a≥0。单次运行
Score=Σ_{a∈A} w_a·s_a(φ,run) - λ_safety·1[∃ 安全违例]。
风险预算 β∈(0,1)：P(∃ 安全违例)≤β；等价尾部约束 CVaR_β(-Score)≤Risk_budget。

**定义 57（标定-策略组合的两阶段规划）**
赛前标定投入 x∈X（按 arena/层/模态分配），赛中策略 π(c_t,m,ℓ)。求解
max_{x,π} E[Score(x,π)]
s.t. Σ_a c_a·x_a + E[cost(π)] ≤ B_tot，
     CVaR_β(-Score) ≤ Risk_budget，
     对每个被声称证书：Valid(ℓ_c,t) ∧ ℓ_p 有效 ∧ ℓ_e 有效。
**战略性标定价值** V_cal(a,ω,m)= [∂E[Score_a]/∂r_ω(m)]·Δr_ω(m,ℓ_c) / c_cal(a,ω,m)，用于赛前排序。

## 2. 三大新增产出与既有 IP 升级

**IP-66 CALIB-LEASE（标定租约与漂移监控）**
- 标定状态在线估计：标定板/自然特征自标定残差 + 温漂模型
- 漂移包络 D_cal 的保守设定与在线告警
- 分布指纹 FP_cal（特征嵌入的 MMD 参考集）与偏移检测
- 标定租约签发/续期/失效，半径膨胀接口

**IP-67 STRATEGY-PORTFOLIO（竞赛风险预算组合器）**
- 两阶段规划：赛前标定分配 + 赛中上下文策略
- CVaR/机会约束求解，风险预算 β 显式
- 战略性标定价值排序，输出给 DCL 采集
- 对手/光照/场地的对抗情景集（红队情景）

**IP-68 ARENA-SCORER（arena 计分与情景模型）**
- 每个 arena 的得分模型 s_a、权重 w_a、退化敏感度
- 尾部风险情景采样（稀有高严重度场景注入）
- 策略回放与赛后归因（哪次标定/切换贡献了分数与风险）

**既有 IP 升级**

IP-63 ECPS：模态效用分母加入标定成本 c_cal 与标定租约可行性。
IP-61 DCL：采集效用加入 V_cal 战略价值，护照新增 calibration_fingerprint / drift_snapshot。

IP-45 总线：新增 calib-lease / drift-alarm / strategy-decision / arena-score 话题。

## 3. 算法骨架

1. 赛前：ARENA-SCORER 给出 arena 权重/情景；SP 在预算与风险约束下求解标定分配 x*，排序生成标定任务。
2. 运行中：CALIB-LEASE 持续估计残差与分布偏移，维护 ℓ_c。
3. 每个控制周期：ECPS 在「标定可行 + 能量可行」的模态集合上求 m_t^*；PSE 用膨胀半径签发 P_t。
4. SP 按上下文与当前租约状态选择 arena 策略与是否触发重标定/保守降级。
5. CAR 三租约守卫；任一失效→级联 fail-closed。
6. 赛后：ARENA-SCORER 归因，DCL 回灌高 V_cal 标定/采集样本。

## 4. 本轮最大风险

**一句话**：竞赛策略若以期望得分而非尾部安全为目标分配有限的标定预算，会系统性少标定「低概率、高严重度」的退化 arena，而漂移包络或分布指纹阈值一旦低估，标定租约就会错误地「验证通过」，使三租约 soundness 恰恰在策略省下预算的地方静默失效；因此必须用 CVaR/分布鲁棒约束替代期望优化，并以独立审计集校准 D_cal 与 ε，在标定租约存疑时默认 fail-closed 或强制保守重标定。

## 2. 关键算法 伪代码

### IP-66 CALIB-LEASE
```
def calib_residual(obs, kappa_hat):
    # obs: 标定板/自然特征重投影观测
    return norm(obs_to_param(obs) - kappa_hat)

def calib_lease_valid(lease, kappa_est, dep_fp, t):
    if norm(kappa_est - lease.kappa_hat) > lease.delta_kappa:
        return False, 'drift'
    if mmd(dep_fp, lease.FP_cal) > lease.eps:
        return False, 'shift'
    if t > lease.tau_c:
        return False, 'expired'
    return True, 'ok'

def inflate_radius(r_conf, lease):
    # 标定不确定度按 Lipschitz 常数膨胀半径
    return r_conf + L_cal * lease.delta_kappa

def update_lease(lease, obs, dep_fp, t):
    ok, why = calib_lease_valid(lease, estimate_kappa(obs), dep_fp, t)
    if not ok:
        return invalidate(lease, why)          # 触发级联 fail-closed
    return lease.refresh(estimate_kappa(obs), t)
```

### IP-67 STRATEGY-PORTFOLIO
```
def allocate_calibration(arenas, budget, risk_budget):
    # 两阶段随机规划：x 为赛前标定投入
    # max E[Score] s.t. sum(c_a*x_a) <= budget, CVaR_beta(-Score) <= risk_budget
    x = solve_cvar_opt(arenas, budget, risk_budget)
    return x

def strategy_step(context, leases, score_model):
    # 只允许在「三租约均有效」的 arena 上声称高置信得分
    feasible = [a for a in arenas if all_leases_valid(leases[a])]
    if not feasible:
        return ConservativeMode('no_valid_lease')
    a_star = argmax_a (w_a * expected_score(a, context)
                       - lambda_safety * cvar_tail_risk(a, beta))
    if cvar_tail_risk(a_star, beta) > risk_budget:
        return ConservativeMode('risk_budget')
    return a_star, perception_policy(a_star)

def strategic_value(arena, omega, m, calib):
    dscore = score_sensitivity(arena, omega)
    dr = calib.r_conf[omega][m] - inflate_radius(calib.r_conf[omega][m], calib.lease)
    return dscore * dr / calib.cost(arena, omega, m)
```

def car_guard_v7(e, x, cert, persona, lease_p, lease_e, lease_c, m_t, t, dep_fp):
    if not pose_lease_valid(lease_p, t):
        cascade_invalidate('pose');   return FailClosed()
    if not energy_lease_valid(lease_e, t, E_min(e)):
        cascade_invalidate('energy'); return FailClosed()

    if st != 'ok':
        return FailClosed()

### IP-68 ARENA-SCORER 尾部情景审计
```
def cvar_tail_risk(arena, beta, scenarios):
    losses = sorted(-score(arena, s) for s in scenarios)
    k = max(1, int((1 - beta) * len(losses)))
    return mean(losses[-k:])

def redteam_strategy(policy, arenas, adversarial_set):
    # 稀有高严重度退化场景注入，检查期望优化是否卖掉尾部安全
    for a in arenas:
        for s in adversarial_set[a]:
            if policy.select(a, s.context).violates_safety(s):
                return Counterexample('strategy_sells_tail_safety', a, s)
    return None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| Calib-Lease 校验 | O(d_κ) 残差 + O(1) MMD 缓存查表 | O(d_κ+|FP_cal|) | 漂移≤δ_κ ∧ MMD≤ε ∧ 未过期 ⇒ 共形覆盖有效 |
| 半径膨胀 | O(1) | O(|Ω|·|M|) | r_total=r_conf+L_cal·δ_κ ⇒ 覆盖 slack 由 L_cal·δ_κ 吸收 |
| Strategy 赛前分配 | 凸规划 O((|A||X|)^3) 离线 | O(|A||X|) | CVaR 约束满足 ⇒ P(violation) 受控 |
| Strategy 赛中步 | O(|A|) | O(|A|) | 可行集仅含三租约有效 arena ⇒ 不声称无效证书 |
| CAR v7 | O(1) | - | 三租约级联 fail-closed ⇒ 无陈旧标定/能量透支/姿态越界 |

正确性定理：若 ℓ_p、ℓ_e、ℓ_c 均有效（漂移在 δ_κ 内、部署分布与 FP_cal 的 MMD≤ε、未过期），且 r_ω^conf(m) 在 FP_cal 上满足 1-α_p 覆盖，则膨胀半径 r_total(ω,m)=r_ω^conf(m)+L_cal·δ_κ 给出 1-α_p 覆盖（标定误差项被 Lipschitz 界吸收），联合证书 J_t=(P_t,ℓ_p,ℓ_e,ℓ_c,m_t) 的鲁棒提升 φ^□(P_t) 在能量与标定约束下保持 sound；若任一租约失效或策略可行性/风险预算不满足，系统进入 fail-closed。

|---|---|---|
| 漂移包络 D_cal 低估导致租约错误有效 | 高 | 独立审计集校准 D_cal + 在线残差监测 + 保守放大 + 快速过期 |
| 期望得分优化系统性牺牲尾部安全 | 高 | CVaR/分布鲁棒约束替代 E[Score]；稀有高严重度情景注入红队 |
| 分布指纹阈值 ε 误设 | 高 | MMD 置换检验校准 + 多重参考指纹 + 偏移即重标定 |
| 标定预算被高权重 arena 独占，稀有层欠标定 | 中 | V_cal 设下限配额；DCL 强制覆盖退化层 |
| 赛中重标定造成姿态证书空窗 | 中 | 租约冻结窗口 + 重标定期间保守姿态盒 |

## 6. 本轮最大风险

**一句话**：竞赛策略若以期望得分而非尾部安全为目标分配有限标定预算，会系统性少标定「低概率、高严重度」的退化 arena，而漂移包络或分布指纹阈值一旦低估，标定租约就会错误地「验证通过」，使三租约 soundness 恰在策略省下预算处静默失效；因此必须以 CVaR/分布鲁棒约束替代期望优化，用独立审计集校准 D_cal 与 ε，并在标定租约存疑时默认 fail-closed 或强制保守重标定。
