灵感驱动研究循环·新灵感第 1 轮；本轮灵感：「桌面操作」×「语音合成」（承接 v22 证书体系）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HPC-E、HDL、ACSC、DCSC、CFC++），其上承 v21 语义-规范层（SDC/CAC/DCL/GIC）、v20 联邦感知证书（PCA/CTS/CFC/HPC）、v19 证书体系与 v17 感知链。本轮不推倒 v22：所有模块原样保留。
> 本轮纪律：**桌面操作不是"多了张桌子"，而是把"接触"从二值违规升级为"可签发、可撤销的契约"；语音合成不是"多了个喇叭"，而是把"机器人的话"升级为"可审计的自我承诺"**。本轮只做一件事：在 v22 之上加一层 **契约层（Contract Layer, CL）**，它有两个**内生规范来源**——物理任务结构（接触契约）与机器人自身的言语行为（语音承诺）——并**诚实地标出全链第一个非单调扩展点**（接触许可），用"非预期接触集合不增长"的保守包络引理把它锁住。

## 0. 直觉与动机

**灵感 1（桌面操作 → 接触是"需要签发的许可"，桌子是"几何锚点"）**
直觉：v22 的整个安全链把 `接触 = 碰撞 = 违规`。这对移动导航正确，但对桌面操作是**致命的过保守**——抓取一个杯子本质上就是"受控接触"，按旧谓词机械臂永远抓不了任何东西，活性直接归零。桌面操作真正暴露的，是一个被旧体系掩盖的**类型漏洞**：接触不是标量，而是**带类型、带力包络、带意图的受控事件**。核心创新：**接触意图证书（Contact Intention Certificate, CIC）**——接触必须像自由空间一样"被赎回"：只有被一张**事先声明、多方同意**的契约覆盖的接触才允许执行，未被契约覆盖的接触一律判为碰撞（fail-safe）。契约 `C = (物体 id, 接触域, 接近锥, 力包络, 时长, 见证)` 同时被三个"同意票"约束：**规范允许（DCL 的 P 规则）、几何可信（物体确实在那）、接触域内无人（CAC 的 AbsCert + GIC 撤销）**。任一同意票撤回，契约立即作废、动作回退为"把接触当碰撞"。第二件事：桌子是机器人遇到的第一个**大尺度、静止、已知位姿的平面**——它是一个天然的**几何锚点**，提供**支撑谓词**（物体躺在桌面上 → 位姿被约束到平面 ±ε_plane，可收紧 Hull）和**锚定帧**（对抗里程计漂移），还能做"**物体不在桌上 → 弃权而非幻觉**"的负信息检查。核心创新：**桌面锚定证书（Table Anchor Certificate, TAC）**。关键反直觉点：**接触契约不是"扩大"了执行集，而是把"碰撞"这个集合做了类型细分——它可能让某些原本被禁的计划变得可执行（这是全链第一次、也是唯一一次非单调），但"非预期接触"这个真正危险的集合必须严格不增长**。这条必须单独证明（见 §5 精化引理），不能靠"Exec ⊆ 前代"一句话糊弄过去。

**灵感 2（语音合成 → 说话是一个自我约束的行为，不是一块显示屏）**
直觉：v22 里机器人是"沉默而保守"的；引入语音合成后它第一次能"开口"。但言语行为理论（Austin/Searle）告诉我们：**说话即行动**。"我要停了""请让一让""我要放杯子了"不是装饰音，而是制造了**期望、义务与承诺**——尤其危险的是**机器人自己的承诺**：说了"1 秒内停"就必须在 1 秒内停，否则它就成了"喊狼来了的机器人"，比沉默更危险（人会对它产生错误信任）。核心创新：**言语行为证书（Speech Act Certificate, SAC）**：每条 utterance 是一个签名记录 `(illocution, proposition, deadline, evidence)`，类型分 **WARN（警告）/ COMMIT（自我承诺）/ REQUEST（请求，只制造人类侧期望，不给机器人任何许可）/ INFO**；**COMMIT 与 WARN 生成计划过滤器 `Fil_speech`，只能收缩执行集**（承诺绝不扩大可达集）。配套 **宣告-承诺协议（Announcement-Commitment Protocol, ACP）**：任何降低人类可预测性的动作，必须提前 `T_lead` 发出 WARN；任何 COMMIT 必须在期限内兑现或**显式、可听地撤回**，否则触发审计升级。第二个关键：**警告只有"真的发出、足够及时、确实可懂、韵律忠实"时才是安全机制**。故需 **可听性证书（Audibility Certificate, AuC）**：`P(可懂 | 噪声, 距离) ≥ 1-β`（conformal 校准），不达标则依赖该警告的动作**阻塞**或升级到非语音通道（灯光/停顿）。再加 **意图力忠实性（Illocutionary Fidelity）**：合成的"STOP"必须听起来就是"STOP"——韵律（音高、语速、能量）必须落在该意图力类别的规范包络内，平静地说"STOP"是语义失败。关键反直觉点：**语音是"输出"通道，因此它不能增加任何感知证据、不能给人任何物理许可；它唯一能做的就是"自我约束 + 请求确认"**——把它当感知证据用（"我说了安全所以安全"）是范畴错误，正是最大风险之源。

**三者如何统一（v22 + 契约层）**
统一为 **v22 义务逻辑层之上的"契约层"**：v22 的 DCL 只编译**外部规则**；v23 补上两类**内生规范**——**接触契约**（来自物理任务结构，回答"哪些接触是被同意的"）与**语音承诺**（来自机器人自己的话，回答"机器人刚刚把自己绑成了什么样"）。共享状态扩展为 **ζ_contract = ζ_pgev ∪ (C_act, τ_table, ψ_log, u_audio, f_prosody)**。统一准入门：**HPC-E+ = (HPC-E, CIC 一致, SAC 兑现, AuC 达标)**——只有"几何∧规范∧能量∧现实差距（v22）∧ 接触被契约覆盖 ∧ 未违背已发出承诺 ∧ 依赖的警告可听"才进入执行。安全继承被**精化**为两条：**(a) 非预期接触集合 `Unintended` 严格不增长**（真正的安全属性）；**(b) 新增的 `Exec_v23 \ Exec_v22` 只包含"被契约覆盖的接触"这一类计划，且每一条都附带独立证明义务**。`Fil_speech`、`Fil_contact`、AuC 闸门均只收缩，绝不扩张。

## 1. 研究问题（轮次升级版）

- **Q12（接触契约的类型安全）**：如何定义 CIC 的接触域与力包络，使"任务接触"与"碰撞"之间**不存在类型漏洞**——尤其"顺手擦碰（incidental brushing）"这种既非明确抓取又非高速撞击的灰区该归哪一类（必须归碰撞）？力闭合条件与 conformal 质量/摩擦界如何给出抓取可行性 ≥1-δ？人手进入接触域时的**撤销延迟**与 50Hz 控制环如何协调（撤销必须比接触更快）？

- **Q13（桌面锚定的可靠性）**：桌平面的 conformal 误差界 ε_plane 如何标定？支撑谓词在**物体堆叠、部分遮挡、桌面反光**下如何失效安全（不确定即回退"不在支撑上"的保守假设）？锚定帧与 v20 PCA/CTS、v21 SDC 类先验如何衔接而不引入假自由空间？"物体不在桌上"的弃权如何与 CAC 的缺席证书统一？

- **Q14（言语承诺的可审计性）**：utterance 的 merkle 记录如何与 DCL 规则库版本链**合并成一条审计链**？"承诺—兑现—撤回"如何在控制环里 O(1) 查询？**承诺冲突**（新命令要求违反旧承诺，或两条承诺互相矛盾）如何消解——最严者胜、还是必须显式可听地撤回旧承诺？撤回本身失败（TTS 崩溃）时如何升级？

- **Q15（可听性与实时性）**：TTS 延迟（100–500ms）+ 人类反应时间 T_react 如何折入 `T_lead`？环境噪声/距离下的可懂度 conformal 校准如何在线维持 1-β 覆盖？韵律忠实性如何**机器可检**（比较合成韵律特征与意图力类别包络，而非人耳抽检）？语音警告与 v21 GIC 的手势警告、v22 的急停通道如何做**多通道冗余**且不互相淹没？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P46）

**P43 接触即同意律（Contact-as-Consent）**
接触仅在被一张**有效 CIC** 覆盖且三张同意票（DCL-P、几何可信、域内无人）齐全时允许；未被覆盖的接触（含擦碰灰区）一律判为碰撞。定义 `UnintendedContact(π) = {t : contact(t) ∉ ⋃ C_act(t)}`。安全属性重述为 **`UnintendedContact(π) = ∅`**，而**不是** `contact(π) = ∅`。人手进入接触域时，CIC 以**低门槛**撤销（复用 P36 非对称：撤销 fail-safe，授权需高门槛）；撤销必须在 `t_contact - t_revoke_min` 前生效。

**P44 桌面锚定律（Table-Anchored Geometry）**
桌平面 `(n, d)` 由带 conformal 误差界的估计给出；物体 `o` 满足支撑谓词 `Support(o) ⇔ |n·p_o + d| ≤ ε_plane` 时，其 Hull 可在**支撑子集**上收紧（与 P34 类先验同一接口）。**支撑谓词不确定即判 `¬Support`**（向保守）。锚定帧用于抵消里程计漂移，但**只用于收紧、不用于放宽**几何证书。"预期在桌上却测不到"→ **弃权（abstain）**，绝不幻觉出一个物体。

**P45 言语自缚律（Speech-as-Self-Binding）**
每条 utterance 是 `(illocution, proposition, deadline, evidence)` 的签名记录，入 merkle 审计链。**WARN / COMMIT 生成 `Fil_speech`，只能收缩 Exec**：`COMMIT(proposition, deadline)` ⇒ `Exec_v23 ⊆ {π : π 在 deadline 前满足 proposition} ∪ {π 含对旧承诺的显式撤回}`。承诺冲突取**最严者**，且旧承诺的解除**必须**留下一条可听的撤回记录；撤回通道失效 ⇒ SafeStop 升级。**REQUEST 与 INFO 不产生任何机器人侧许可**。

**P46 可听性-忠实性律（Audibility & Illocutionary Fidelity）**
任何**依赖警告**的动作，其 WARN 必须满足：`t_warn ≤ t_action - (T_tts + T_react + T_margin)` 且 `AuC: P(可懂 | 噪声, 距离) ≥ 1-β`。不达标 ⇒ 动作阻塞或升级非语音通道。合成语音的韵律特征 `f_prosody` 必须落在意图力类别 `I` 的规范包络 `E_I` 内；`f_prosody ∉ E_I` 视为**语义失败**，降级为"未忠实发出"，依赖它的动作同样阻塞。

## 3. 与基线的接口（如何退化）

- CIC 失效（契约引擎崩溃 / 撤销超时）⇒ **接触全部判为碰撞** ⇒ 完全回退 v22 的保守行为（比 v22 更保守，因为连抓取都禁）⇒ 安全方向不变；
- TAC 失效（桌平面不可信）⇒ 支撑谓词恒 `¬Support`，收紧不可用 ⇒ Hull 退回原始膨胀 ⇒ 等价 v22；
- SAC 失效（审计链/承诺引擎崩溃）⇒ 无 COMMIT 过滤、也无"已承诺"的自我约束 ⇒ 但**此时禁止一切依赖语音的交互式动作** ⇒ 比 v22 更保守；
- AuC 失效（噪声过高 / TTS 故障）⇒ 依赖警告的动作全部阻塞，退化为"沉默 + 纯几何保守" ⇒ 子集；
- 韵律忠实性失败 ⇒ 该 utterance 视为未发出 ⇒ 依赖它的动作阻塞；
- 全部失效 ⇒ 回退 v22 ⇒ **`Unintended_v23 = ∅ ⊆ Unintended_v22 = ∅`**，且 `Exec_v23 ⊆ Exec_v22`（见 §5，唯一例外是接触维度的受控扩张，需独立证明）。
- **安全继承**：语音侧（SAC/AuC/Fidelity）纯收缩；接触侧是"把碰撞集合类型细分"，其**非预期接触**集合严格不增长；桌面侧只在支撑子集上收紧、且不确定即保守。控制路径仅做 O(1) 查询：`query_contact_permission(t)`、`query_speech_commitment(t)`、`query_audibility(t)`。

## 4. 预期贡献

1. **接触契约类型系统**：首次把桌面操作中的"任务接触 vs 碰撞"形式化为带同意票与力包络的 CIC，给出"接触必须被赎回、擦碰灰区归碰撞"的单调证据扩展，并**明确标出全链第一个非单调扩展点**及其证明义务；
2. **桌面锚定证书**：把"大尺度静止平面"变成可 conformal 标定的几何锚点，给出支撑谓词、Hull 收紧与"测不到即弃权"的负信息接口，与 v21 SDC/CAC 统一；
3. **言语行为证书与自我约束**：把机器人语音从"输出装饰"升级为"签名、带期限、可审计的自我承诺"，给出 `Fil_speech` 纯收缩、承诺冲突最严消解与显式撤回机制；
4. **可听性-忠实性证书**：把"警告是否算数"变成可机器复核的统计证书（AuC + 韵律包络），使"依赖警告的安全"不再依赖人耳抽检；
5. **审计链合并**：接触契约、语音承诺与 DCL 规则库版本统一到一条 merkle 链，实现"物理接触 + 规范义务 + 言语承诺"的联合可追溯；
6. **HPC-E+ 四证一体**：HPC-E ∪ CIC ∪ SAC ∪ AuC 统一准入门，并给出**精化的安全继承引理**（非预期接触不增长）。

## 5. 单调性精化引理（本轮必须单独证明的唯一非单调点）

旧链一直靠 `Exec_v{k} ⊆ Exec_v{k-1}` 一句话继承。接触契约**第一次打破**这条：受契约覆盖的接触在 v22 里是被禁的（判碰撞），在 v23 里被允许，故 `Exec_v23 \ Exec_v22 ≠ ∅` 在接触维度上成立。**这不是 bug，而是必须显式管理的证明义务**。正确提法：

- 令 `Safe(π) ⇔ UnintendedContact(π) = ∅`（真正要保的安全属性）；
- v22 的保守谓词是 `Safe_v22(π) ⇔ contact(π) = ∅`，显然 `Safe_v22 ⇒ Safe`；
- v23 允许 `contact(π) ≠ ∅`，但要求**每一段接触都被某张有效 CIC 覆盖**，即 `contact(π) ⊆ ⋃ C_act`，故 `UnintendedContact(π) = ∅`，仍满足 `Safe(π)`；
- 于是得到**精化继承**：`{π : Safe_v23(π)} ⊇ {π : Safe_v22(π)}`（允许受控接触），但**两者都 ⊆ {π : Safe(π)}**；真正单调的是 `¬Safe`（不安全集合）从不增长。

**证明义务**：(i) CIC 的接触域与力包络必须**闭合**（任何实际接触要么落在某 CIC 内、要么落在碰撞类），灰区一律归碰撞；(ii) 撤销必须**快于接触**（`t_revoke_min > 0` 且撤销状态机独立于 50Hz 控制环的事件路径）；(iii) 契约的"几何可信"票必须用 conformal 下界，禁止用点估计。任一义务失守，则退回 `Safe_v22`。

## 6. 本轮最大风险

**一句话**：接触契约与语音承诺都把安全从"几何事实"偷换成了"社会约定"——**约定只在双方对同一符号有一致解释时才成立**；一旦人的解释与机器人的证书语义漂移（把"放置"听成"交接"、把"授权这次接触"当成"随时可接触"、或机器人平静地说"STOP"而人没当真），系统就会在"双方都以为自己合规"的瞬间发生物理接触——**安全被稀释成共识，而共识可以错**。

| f_prosody, E_I | 合成韵律特征、意图力类别 I 的规范包络 |

## 1. 关键算法骨架（在 IP-431–435 骨架上扩展）

from dataclasses import dataclass, field
import numpy as np

# ---------- IP-436 接触意图证书 ----------
@dataclass
class ContactIntent:
    object_id: str
    region: np.ndarray          # 接触域（世界系 AABB / 网格）
    approach_cone: tuple        # (axis, half_angle)
    force_env: tuple            # (f_min, f_max) 牛顿
    duration: float             # 最长接触时长
    witness: bytes              # 计划签名 / 演示来源

class ContactIntentionCertificate:
    """接触必须被契约赎回；未覆盖接触（含擦碰灰区）= 碰撞。"""
    GREY_ZONE_IS_COLLISION = True          # P43：灰区一律归碰撞
    REVOKE_LOW_THRESHOLD = True            # P36 非对称：撤销 fail-safe

    def __init__(self, dcl, sdc, cac, gic, t_revoke_min=0.08):
        self.dcl, self.sdc, self.cac, self.gic = dcl, sdc, cac, gic
        self.active: dict[str, ContactIntent] = {}
        self.t_revoke_min = t_revoke_min

    def consent(self, C: ContactIntent, t) -> tuple[bool, list[str]]:
        votes = {
            "dcl": self.dcl.permits_contact(C.object_id, t),      # 规范允许(P)
            "geom": self.sdc.is_where_expected(C.object_id, C.region),  # 几何可信
            "human": self.cac.absent_in(C.region, t) and not self.gic.human_present(C.region, t),
        }
        return all(votes.values()), [k for k, v in votes.items() if not v]

    def admit_contact(self, contact, t):
        # 覆盖判定：实际接触必须落在某张已同意契约的域内
        for C in self.active.values():
            if self._in_region(contact, C.region) and self._in_cone(contact, C.approach_cone):
                ok, missing = self.consent(C, t)
                if ok and self._force_ok(contact, C.force_env):
                    return True, C
        return False, None   # 未覆盖 → 碰撞（fail-safe）

    def revoke_on_human(self, region, t):
        # 人手进入接触域：低门槛撤销，必须早于接触
        for cid, C in list(self.active.items()):
            if self._overlaps(region, C.region):
                self.active.pop(cid)
                self._audit("REVOKE", cid, t, deadline=t + self.t_revoke_min)

    # 力闭合 + conformal 质量/摩擦界：抓取可行性 ≥1-δ
    def grasp_viable(self, C: ContactIntent, mass_ci, mu_ci) -> bool:
        return self._force_closure(C.force_env, mass_ci.upper, mu_ci.lower)

    @staticmethod
    def _in_region(contact, region): ...
    @staticmethod
    def _in_cone(contact, cone): ...
    @staticmethod
    def _force_ok(contact, env): ...
    @staticmethod
    def _overlaps(a, b): ...
    @staticmethod
    def _force_closure(env, m_up, mu_lo): ...
    def _audit(self, kind, cid, t, deadline): ...

# ---------- IP-437 桌面锚定证书 ----------
class TableAnchorCertificate:
    """桌平面 = 可 conformal 标定的锚点；只在支撑子集收紧，不确定即保守。"""
    def __init__(self, plane_calibrator, eps_plane, delta=0.01):
        self.calib = plane_calibrator
        self.eps_plane = eps_plane
        self.delta = delta

    def estimate_plane(self, points):
        (n, d), score = self.calib.fit(points)      # 带残差打分
        return (n, d), self.calib.quantile(score, self.delta)  # ε_plane 下界

    def support(self, p_o) -> bool:
        (n, d), eps = self._cached_plane
        # 不确定即 False：ε 取保守上界
        return abs(float(n @ p_o) + d) <= eps

    def tighten_hull(self, obj_hull, p_o):
        if not self.support(p_o):
            return obj_hull                          # 不回退成假自由空间
        # 支撑子集上沿法向收紧（与 P34 类先验同一接口）
        return self._project_to_plane(obj_hull, p_o)

    def missing_object(self, expected_id) -> bool:
        # "预期在桌上却测不到" → 弃权，绝不幻觉
        return self._detect(expected_id) is None

    def _project_to_plane(self, hull, p): ...
    def _detect(self, oid): ...

# ---------- IP-438 言语行为证书 + 宣告-承诺协议 ----------
@dataclass
class Utterance:
    ill: str                    # WARN / COMMIT / REQUEST / INFO
    prop: str                   # 命题（如 "STOPPED" / "PLACING(cup)"）
    deadline: float | None
    evidence: bytes             # 证书引用 / 计划哈希
    t_emitted: float
    prosody: dict = field(default_factory=dict)

class SpeechActCertificate:
    """说话即行动：COMMIT/WARN 只收缩 Exec；撤回必须可听且留痕。"""
    def __init__(self, tts, audit_chain, auc, fidelity):
        self.tts, self.chain = tts, audit_chain
        self.auc, self.fidelity = auc, fidelity
        self.log: list[Utterance] = []

    def emit(self, ill, prop, deadline, evidence, urgency, t):
        if ill in ("WARN", "COMMIT"):
            lead_ok = self.auc.lead_time_ok(urgency, t)
            if not lead_ok:
                return None                      # 来不及 → 动作不得依赖此警告
        text = self._render(ill, prop, urgency)
        prosody = self.tts.synthesize(text, urgency)
        if not self.fidelity.in_envelope(prosody, urgency):   # P46
            self._audit("FIDELITY_FAIL", ill, t)
            return None
        u = Utterance(ill, prop, deadline, evidence, t, prosody)
        self.log.append(u)
        self.chain.append(u)                     # merkle 审计链
        return u

    def filter(self, plan, t) -> bool:
        # Fil_speech：兑现全部 COMMIT，或含对旧承诺的显式撤回
        for u in self._open_commits(t):
            if u.deadline is not None and t > u.deadline and not self._fulfilled(u, plan):
                if not plan.has_audible_retraction(u):
                    return False                 # 违背承诺 → 收缩
        return True

    def _render(self, ill, prop, urgency): ...
    def _open_commits(self, t): ...
    def _fulfilled(self, u, plan): ...
    def _audit(self, kind, ill, t): ...

# ---------- IP-439 可听性 & 意图力忠实性证书 ----------
class AudibilityCertificate:
    """警告只有在真的可懂时才算安全机制。"""
    def __init__(self, calibrator, beta=0.01, u_min=0.6):
        self.calib, self.beta, self.u_min = calibrator, beta, u_min

    def intelligible(self, noise_db, dist_m) -> bool:
        # conformal 下界：P(u_audio ≥ u_min | noise, dist) ≥ 1-β
        lo = self.calib.lower_quantile((noise_db, dist_m), self.beta)
        return lo >= self.u_min

    def lead_time_ok(self, urgency, t) -> bool:
        need = self.calib.t_tts(urgency) + self.calib.t_react() + self.calib.margin()
        return self.calib.available_lead(t) >= need

class IllocutionaryFidelity:
    """平静地说 STOP = 语义失败。"""
    ENVELOPES = {"STOP": dict(pitch=(180, 400), rate=(1.2, 2.0), energy=(0.8, 1.0)),
                 "INFO": dict(pitch=(80, 200), rate=(0.8, 1.3), energy=(0.3, 0.7))}
    def in_envelope(self, prosody, ill) -> bool:
        e = self.ENVELOPES.get(ill, self.ENVELOPES["INFO"])
        return all(e[k][0] <= prosody[k] <= e[k][1] for k in e)

# ---------- IP-440 HPC-E+ 统一准入门 ----------
@dataclass
class HPCEPlus:
    hpce: HPCE                 # v22 原样保留
    cic: ContactIntentionCertificate
    sac: SpeechActCertificate
    auc: AudibilityCertificate

    def admits(self, plan, t, noise_db, dist_m):
        # v22 的几何/规范/能量/差距门
        if not self.hpce.admits(plan, plan.x, plan.v, plan.z, plan.E_res, plan.margin_req):
            return False
        # 接触门：非预期接触必须为零（唯一受控扩张维度）
        for contact in plan.contacts:
            ok, _ = self.cic.admit_contact(contact, t)
            if not ok:
                return False
        # 承诺门：兑现全部 COMMIT 或显式撤回（纯收缩）
        if not self.sac.filter(plan, t):
            return False
        # 可听性门：若计划依赖警告，警告必须可懂且及时
        if plan.depends_on_warning and not self.auc.intelligible(noise_db, dist_m):
            return False
        return True

## 2. 单调性精化引理的证明草稿（对应想法区 §5）

**命题**：在 P43 的三条证明义务成立时，`{π : Safe_v23(π)} ⊆ {π : Safe(π)}`，且 `{π : ¬Safe(π)}` 相对 v22 不增长；同时 `{π : Safe_v22} ⊆ {π : Safe_v23}`（受控接触扩张）。

**证明骨架**：
1. v22：`Safe_v22(π) ⇒ contact(π)=∅ ⇒ UnintendedContact(π)=∅ ⇒ Safe(π)`。
2. v23：`Safe_v23(π) ⇒ ∀t, contact(t) ∈ ⋃ C_act(t)`（P43 覆盖闭合）`⇒ UnintendedContact(π)=∅ ⇒ Safe(π)`。
3. 不安全集合：`¬Safe_v23(π) ⇒ ∃t, contact(t) ∉ ⋃ C_act(t)`；该条件与 v22 的 `contact(π)≠∅` 定义在同一"未覆盖接触"语义下**恰好等价于** `¬Safe_v22` 的触发条件——故不安全集合不变。
4. 扩张项：`π ∈ Safe_v23 \ Safe_v22` 必须满足 `contact(π)≠∅ ∧ contact(π)⊆⋃C_act`，即只含受契约覆盖的接触；每条都带 `grasp_viable`、`consent`、`t_revoke_min` 三项独立检查，任一失败退回 v22。

**义务失守的退化**：灰区若被误判为任务接触（`GREY_ZONE_IS_COLLISION` 被关闭），或撤销晚于接触（`t_revoke_min ≤ 0`），或"几何可信"用点估计代替 conformal 下界——则引理前提破坏，系统强制回到 `Safe_v22`（接触全禁）。

## 3. 实验设计（可证伪）

**E1 接触契约类型安全（仿真）**
- 平台：桌面抓取/放置，含"顺手擦碰"脚本化扰动；对照组 = v22（接触全禁，无法抓取）。
- 指标：任务成功率、`UnintendedContact` 事件数（必须为 0）、人手入侵到撤销生效的延迟分布（须 < t_revoke_min 的 90% 分位）、灰区误判率（须为 0，因强制归碰撞）。
- 通过准则：任务成功率 > 90% 且 `UnintendedContact = 0` 且撤销延迟 p99 < t_revoke_min。

**E2 桌面锚定与弃权（仿真 + 真机）**
- 场景：堆叠物体、部分遮挡、桌面反光、里程计漂移注入。
- 指标：`Support` 误判率（假阳性 = 把悬空物当支撑，必须为 0）、Hull 收紧量、弃权率 vs 幻觉率（幻觉率须为 0）。
- 对照：v21 SDC 无桌面锚点。

**E3 语音承诺审计与兑现（真机 + 日志回放）**
- 场景：机器人发 `COMMIT("STOPPED", dl)` / `WARN` 后执行动作；注入 TTS 延迟、噪声、以及"新命令要求违反旧承诺"。
- 指标：承诺违背次数（须为 0，或全部伴随可听撤回）、承诺冲突消解正确率、merkle 链可复核率（100%）。
- 对照：无 SAC 的"哑"机器人（无法审计违背）。

**E4 可听性与韵律忠实性（人因小样本）**
- 场景：不同噪声（50–85 dB）与距离（0.5–4 m）下的可懂度；"平静 STOP" vs "急促 STOP"的响应时间。
- 指标：AuC 预测覆盖（须 ≥1-β 的经验频率）、韵律包络漏检率（平静 STOP 被判失败的比例须 ≥95%）、警告到人类开始避让的时间 vs `T_lead`。
- 风险控制：人因实验需伦理审批，先做声学代理指标（可懂度模型）再上人。

**E5 端到端非预期接触（压力测试）**
- 联合 E1–E4，随机组合失效（CIC 崩溃 / TTS 挂起 / 高噪声 / 人手突然进入），统计 `UnintendedContact` 与承诺违背。通过准则：全部为 0 或全部向 `Safe_v22` 退化。

## 4. 本轮最大风险

**一句话**：接触契约与语音承诺把安全从几何事实偷换成社会约定，而约定只在双方解释一致时成立——**"放置"被听成"交接"、"授权这次接触"被当成"随时可接触"、或机器人平静地说"STOP"而人没当真，都会让系统在"双方都以为自己合规"的瞬间发生物理接触**；缓解只能靠把"非预期接触"与"韵律忠实性"做成机器可复核的硬门，而非寄望于人的理解。
