# 第 43 轮（新循环第 3 轮） · 惯性见证的共享权限证书（IW-SAC）：把 IMU 变成扰动的「压力计」，把权限交接变成可证的混合转移（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR 的 Sim-Cert-RAG 飞轮）。第 42 轮自陈最大风险是「仿真偏差累积 + 检索幻觉」导致证书在自信中静默失效。本轮灵感词「惯性测量单元」「人机交互」从两个此前被当作背景假设的维度补上闭环缺口：**IMU** 是全栈里唯一 1kHz+、亚毫秒延迟、且直接量测「物理世界此刻对人/机施加了多大扰动」的通道——它把第 42 轮只能靠仿真去猜的扰动包络，变成在线可测、可收窄的**实测扰动集**，从而在不牺牲安全的前提下收窄保守界、缓解可用性；**人机交互 (HCI)** 则撕开了此前「全自主封闭世界」的隐含假设：人一旦进入回路，**权限在人与机之间的交接本就是一个带反应时延的混合系统转移**，它可能比稳态运行更危险，必须被证书显式覆盖。二者合一，得到本轮主线：**惯性见证的共享权限证书（Inertial-Witnessed Shared-Authority Certificate, IW-SAC）**——把「人」当作由 IMU 实证、有界、且可合作改善的扰动源，而不是不可建模的最坏情形，让人-机共同体既能被证明安全，又不至于长期困在 SafeStop。

## 0. 直觉与动机

**灵感 1（惯性测量单元 → 证书的「秒表」与「扰动压力计」）**：IMU 有两个对证书特别关键、却一直被当成普通传感器用掉的性质。其一是**频率**：证书的保守性有一部分纯粹来自「两次判定之间扰动可能变化多少」，即采样保持误差 ≈ L_h·Δt。把证书时钟从视觉/力觉的 ~100Hz 提到 IMU 的 1kHz，Δt 缩小一个数量级，同一套控制律能多换来约一个数量级的可用裕度——这正好对症第 42 轮「保守界导致滞留 Degraded/SafeStop」的旧疾。其二是**含义**：扣掉重力（用 LIO 提供的姿态 R_t）与在线偏置 b_t 后，IMU 残差 r_t 近似正比于**未建模外力/接触**。它是「刚才是谁、用多大力推了机器人」的直接读数，于是静态的 worst-case 扰动界可以被替换为在线椭球包络 D_t——不是「假设人可能用最大力」，而是「刚才人实际用了多大力，按此留一点余量」。附带好处：r_t 是 Sim-to-Real 偏移最快的报警器，第 42 轮用分布统计量 S_t 发现漂移要等一窗数据，IMU 残差几乎即时。

**灵感 2（人机交互 → 人类既是「有界扰动源」，又是「权限持有者」）**：旧证书栈默认任务全自主、人只在环外监督。HCI 引入两类必须建模的新对象。(a) **物理人因扰动**：接触、推挤、协作搬运——它们可被 IMU 见证，进入扰动集 W_h，于是「协作」不再是安全证书的例外，而是它的一个输入项。(b) **权限交接**：自动驾驶式地假设「人随时能接管」是幻觉；A→S→H 的转移带有人类反应时 τ_h、注意力与误操作，且**交接瞬态**（混合控制、责任模糊、人类尚未接手）往往比两端稳态更危险。因此证书必须覆盖一个「共享权限区」：混合控制 u=βu_R+(1−β)u_H 在移交期间仍满足鲁棒 CBF，机器人必须在 τ_h 内保持 fallback 前向不变，给人类留出真实反应时间。**「未就绪则拒绝交接」是安全策略，不是体验取舍**。

**灵感 3（耦合 → 人作为「实测-有界-可合作」扰动，安全与可用同向改善）**：IMU 把 W_h 从「假设的最坏情形」变成「实测的包络」；HCI 则提供另一条杠杆——**意图对齐**。当界面把证书安全集与「人类当前意图」的差距清楚地投影给人（视觉/触觉），人会主动把操作拉回安全集，从而缩小 ||w_h|| → 收紧 D_t → 放宽动态裕度 → 更可用。这形成正反馈：**对齐越好 → 扰动越小 → 包络越紧 → 裕度越大 → 越敢用**。但反向失效链同样存在：过度信任 (automation bias) 或意图误判会让人在包络外发力，此时必须由「包络覆盖率」与「交接前向不变性」两条红线兜底，而不是靠界面。

**耦合升级**：IMU 残差 → 实测包络 D_t →（IP-49 动态裕度、IP-51 守卫、IP-56 1kHz 刷新）→ 共享权限自动机（IP-58）→ 意图对齐接口（IP-59）再反向缩小 D_t；同时 IMU 残差作为飞轮 S_t 的快通道，触发第 42 轮的 Sim 重跑与 KB 更新。证书由此从「自主系统的证书」升级为「**人-机共同体的证书**」。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（惯性扰动残差与实测扰动包络）**：设 IMU 比力测量 a_t^m，姿态 R_t 由 IP-49 LIO 给出，重力 g，在线偏置估计 b_t。**重力补偿残差** r_t = a_t^m − R_t^T g − b_t − â(x_t,u_t)，其中 â 为动力学模型预测的比力。外部（人/接触/环境）等效力估计 f̂_t = m·(r_t − b_t)。在滑窗 W 上取鲁棒均值 μ_W 与协方差 Σ_W（Huber/Student-t + 指数遗忘），定义**实测扰动包络** D_t = { f : (f−μ_W)^T Σ_W^{-1} (f−μ_W) ≤ χ²_{3,1−δ} } ⊕ B_ε，其中膨胀项 B_ε 吸收偏置漂移、姿态误差与模型失配的上界。**接触检测**用残差 CUSUM：G_t = max(0, G_{t−1} + ||r_t|| − ν)，G_t > h_c 判为接触/碰撞，冲量 J = ∫ r dt。**命题 38**：若偏置与模型误差落在 B_ε 内，则真实外力 w_h ∈ D_t 以概率 ≥ 1−δ 成立。

**定义 39（扰动感知动态裕度与概率 soundness）**：对控制屏障 h(x)，鲁棒条件 ḣ = L_f h + L_g h u + L_{g_h} h w ≥ −α(h)，∀w∈W_h。给定 D_t ⊇ W_h（w.p. 1−δ），定义**扰动感知边际** m(x;D_t) = max_{u∈U} min_{w∈D_t} [L_f h + L_g h u + L_{g_h} h w + α(h)]。若 m(x;D_t) ≥ θ，则一步安全以概率 ≥ 1−δ 成立。**单调性**：D_t ⊇ D_t′ ⟹ m(x;D_t) ≤ m(x;D_t′)，故包络越紧越可用；因实测 D_t 通常严格包含于静态最坏界 D_static，动态裕度在同等安全置信下更宽。**注**：δ 是「包络覆盖失败」的概率，不是控制失败的概率，二者相乘进入证书置信度，须显式记录。

**定义 40（1kHz 离散证书与采样保持安全）**：IMU 帧间隔 Δt（≈1ms），控制 ZOH。离散鲁棒 CBF 要求 m(x_k;D_k) − L_h·Δt ≥ θ，其中 L_h = sup||ḣ|| 为屏障导数的 Lipschitz 上界。由于 Δt 比视觉环小一个数量级，L_h·Δt 的保守扣除相应缩小。定义**证书时钟** t_cert = 1/Δt，与传感频率绑定。**丢帧单调降级**：若 IMU 丢帧或饱和，则回退到上一级时钟 Δt′（如力觉/视觉 100Hz）并按 L_h·Δt′ 重算更保守的裕度；若仍超出预算，则进入 SafeStop。证书对象显式携带 (Δt, L_h, δ) 三元组，禁止在运行时偷偷用乐观值。

**定义 41（共享权限混合自动机 SA-HA）**：增广状态 (x, σ, β)，权限状态 σ∈{A 自主, S 共享, H 人类, SS 安全停}，混合系数 β∈[0,1]，控制 u = β·u_R + (1−β)·u_H。转移边带守卫 g_e(x,σ,β,D_t,τ_h) 与不变式：A→S（人类请求，或机器人检测到意图歧义/接触）、S→H（人类就绪且交接证书成立）、S→A（人类释放或就绪丧失）、任意→SS（任一证书不成立）。**权威不变式** Inv_auth：u∈U 且鲁棒 CBF ḣ ≥ −α(h) 在 β 变化全程成立。自动机的「状态」不再只是机器人的，而是人-机联合的。

**定义 42（交接证书 HC 与反应时截止期）**：对 t0 时刻请求目标权限 σ′，交接证书 HC(t0,σ′) 成立当且仅当三条同时满足：(i) **反应时缓冲**：存在 fallback 控制 u_fb∈U，使安全集在 [t0, t0+τ_h] 上前向不变，其中 τ_h 为由 IMU 就绪判据估出的反应时**保守上界**；(ii) **权威不变式可满足**：存在速率受限的 β(t)（|β̇|≤ρ）从 β0 过渡到 β′，使 ∀t∈[t0, t0+τ_b]、∀u_H∈U_H(Î_t)（IMU 意图估计的一致集），混合控制 u(t)∈U 且鲁棒 CBF 成立；(iii) **可回退**：任一时刻违约都可单调反向 β 回到 σ 或进入 SS。若 HC 不成立，则**拒绝交接并保持机器人权限（deny-by-default）**，绝不「先交接再看」。τ_h 的估计误差按保守方向进入 (i) 的缓冲长度，宁可多等 100ms，不可少留 100ms。

**定义 43（意图对齐投影与信任校准）**：人类意图估计 Î_t = g_I(IMU_wearable / 遥操作主手, 操作模型)，附带一致集 U_H(Î_t)。证书安全控制集 S_cert(x) = {u : 鲁棒 CBF ∧ 权威不变式}。**证书投影**把 S_cert(x) 与 Î_t 的可行方向投影到人类可感知通道（视觉箭头/力反馈/触觉脉冲），引导人类输入落入 S_cert。**意图对齐差** Δ_I = dist(Î_t, S_cert(x))，界面同时显示包络半径 |D_t| 作为「当前可信扰动裕度」。**信任状态** T_t 为有界标量，由交互更新：过信任 = Δ_I 超阈值却仍不干预；欠信任 = 频繁不必要干预。校准律要求「展示的置信度 ≈ 真实置信度」，以抑制 automation bias。效果链：对齐↑ ⟹ ||w_h||↓ ⟹ |D_t|↓ ⟹ m↑ ⟹ 可用性↑（正反馈，受 E92/E93 红线约束）。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-45/47/49/50/51/52/53/56）

### 2.1 IP-57 INERTIAL-CERT-WITNESS（ICW，惯性证书见证器）
1. **重力补偿与偏置联合估计**：用 IP-49 姿态做重力投影；静止段初始化偏置；在线递推偏置不确定度 → 膨胀项 ε；IMU 饱和/温漂/重力混叠自检。
2. **实测扰动包络**：Huber 鲁棒均值 + 指数遗忘协方差（半衰期 ~0.5s），χ²_{3,1−δ} 椭球；对非高斯重尾用 Student-t 分位数替换。
3. **接触/CUSUM 检测**：残差 CUSUM，<2ms 报警，冲量 J 估计；触发共享权限自动机的 A→S 候选边。
4. **1kHz 证书刷新**：每 IMU 帧计算 m(x;D_t) 与离散安全扣除 L_h·Δt；丢帧按定义 40 单调降级。
5. **飞轮快通道**：r_t 的漂移统计 S_t^{imu} 与第 42 轮 W_1 慢通道互补，任一超阈值即请求 Sim 重跑。
6. **见证语义**：每条证书写入「该结论所依赖的 IMU 包络版本与 δ」，形成可追溯的扰动见证。

### 2.2 IP-58 SHARED-AUTHORITY-CERTIFIED-CONTROL（SACC，共享权限可证控制）
1. **SA-HA 实现**：4 态、β 速率受限调度、带守卫与不变式；状态与人机责任显式绑定。
2. **交接证书求解**：fallback 前向不变性用 CBF 近似或 HJ 可达性小片预计算；反应时缓冲 τ_h 保守取值。
3. **就绪判据**：由 IMU 握持/手势/运动一致性估计 engagement 与反应时上界；未就绪即 deny。
4. **权威不变式监控**：混合控制全程 clamp 在 U 内；人类输入经安全滤波投影到 S_cert，绝不直接透传到执行器。
5. **平滑交接**：β 斜坡避免权限突变的 jerk 爆炸；交接完成/失败均有明确单调回退。
6. **人机责任记录**：每次交接写入 (时刻, β 轨迹, HC 见证, 人类输入, 结果)，供合规审计。

### 2.3 IP-59 INTENT-ALIGNED-HCI（IAH，意图对齐交互）
1. **意图估计**：可穿戴 IMU / 主手 IMU → 期望运动或力；操作模型 + 卡尔曼，输出一致集 U_H(Î_t)。
2. **证书投影界面**：把 S_cert(x) 与 Δ_I 投影为视觉安全锥/箭头 + 触觉梯度；不显示未经证书支持的「安全」承诺。
3. **触觉权威反馈**：交接时以力/振动脉冲编码权限变化，让人类「摸到」责任转移。
4. **信任校准**：监测过信任/欠信任事件，调节信息粒度与频率；拒绝「全绿」式误导展示。
5. **意图条件扰动先验**：把 Î_t 作为 IP-57 包络的贝叶斯先验，减少冷启动时的包络膨胀，提高早期可用性。

## 5. 本轮最大风险

### IP-57 ICW：惯性扰动见证与包络估计
```
def inertial_witness_step(imu, state_hat, lio_pose, bias_hat, envelope, dt):
    # 1. 重力补偿残差（姿态由 IP-49 LIO 提供）
    a_pred = dynamics_specific_force(state_hat)        # â(x,u)
    r = imu.a - lio_pose.R.T @ GRAVITY - bias_hat - a_pred

    # 2. 偏置不确定度 → 膨胀项 ε（IMU 自检失败时放大）
    eps = bias_uncertainty(bias_hat, imu.temperature, imu.saturated)
    if imu.saturated or imu.dropped:
        return envelope.inflate(3.0), FORCE_DEGRADE   # 单调降级

    # 3. 鲁棒包络更新（Huber 均值 + 指数遗忘协方差）
    mu, Sigma = robust_update(envelope.mu, envelope.Sigma, r*MASS, dt, half_life=0.5)
    radius = chi2_quantile(3, 1-DELTA) + eps
    D_t = Ellipsoid(mu, Sigma, radius)

    # 4. CUSUM 接触检测 + 冲量
    envelope.g = max(0.0, envelope.g + norm(r) - CUSUM_NU)
    contact = envelope.g > CUSUM_H
    impulse = integrate(r, window=CONTACT_WINDOW) if contact else None

    # 5. 1kHz 证书刷新：动态裕度 + 离散采样扣除
    m_dyn = robust_cbf_margin(state_hat, D_t)
    m_disc = m_dyn - L_H * dt          # 定义 40：采样保持扣除
    status = 'OK' if m_disc >= THETA else ('TRIP' if m_disc < 0 else 'WARN')

    # 6. 飞轮快通道
    drift_fast = wasserstein_1d_approx(project(r*MASS), SIM_RESIDUAL_HIST)
    return Witness(D_t, contact, impulse, m_disc, status, drift_fast, version=hash(D_t))
```

def handover_certificate(x, sigma_from, sigma_to, D_t, readiness, horizon):
    # (i) 反应时缓冲：τ_h 取 IMU 就绪判据给出的保守上界
    tau_h = readiness.reaction_time_upper_bound
    # fallback 在 [0, tau_h] 内保持安全集前向不变
    if not forward_invariant_fallback(x, u_fb, tau_h, D_t):
        return False, 'reaction_buffer_violated'

    # (ii) 权威不变式：搜索速率受限 β(t) 与人类输入一致集
    for beta_traj in schedule_beta(sigma_from, sigma_to, rate=RHO):
        ok = all(
            blend_in_admissible(b, u_R(x,t), u_H, U) and
            robust_cbf_holds(x, blend(b,u_R,u_H), D_t)
            for t, b in beta_traj
            for u_H in human_input_consistency_set(readiness.intent_hat)
        )
        if ok:
            return True, beta_traj

    # (iii) 可回退：任一时刻可单调回退到 sigma_from 或 SS
    if not monotone_recoverable(sigma_to, sigma_from, D_t):
        return False, 'no_recovery'
    return False, 'authority_invariant_violated'


def shared_authority_step(x, sigma, beta, obs, D_t):
    # deny-by-default：未就绪绝不交接
    if sigma == 'A' and obs.human_request:
        ok, plan = handover_certificate(x, 'A', 'S', D_t, obs.readiness, HORIZON)
        if not ok:
            bus.publish('handover_denied', reason=plan)
            return 'A', 0.0, safe_control(x, D_t)
