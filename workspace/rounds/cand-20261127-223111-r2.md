### 第 4 轮灵感驱动研究记录

**灵感词**：数据质量、虚拟仿真

**继承关系**：第 3 轮 CADVS-v3（IP-485~488）在 v2 三锚点之上追加末点锚 EEK（EEC，kc_ee）、记忆锚 LTEM（kc_mem）与联邦聚合 FFA，形成五硬门 kc_evidence_forged_v3 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem，执行集 Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v3，而是补上「证据赖以生成的数据是否可信、仿真是否配得上其结论、证据是否在自我循环」三个上游问题，形成 CADVS-v4（IP-489~492），执行集升级为 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29（承接第 3 轮，记为第 4 轮）。

**直觉与动机**：

1. **数据质量：v3 的门都在审「证据」，却没人审「喂给证据的数据」。** 覆盖体素可能来自一次过期、漂移或外参失准的观测；SPRT 的通过/失败计数可能来自同一条轨迹切出的上千个高度相关样本——原始 n=1000，有效独立样本量 n_eff 也许只有 10，而 SPRT 的 Type-I 错误界只在独立样本下成立；手势标签可能带标注噪声；联邦统计可能被低质量站点主导。数据质量不是一个标量，而是（准确、完整、时效、一致、来源）五维向量；更关键的是「有效样本量」而非「原始样本量」。引入数据质量证书 DQC 与硬门 kc_quality，把「证据可信」建立在「数据可信」之上。

2. **虚拟仿真：v3 的 kc_physics 只证明「规则在 MuJoCo 里成立」，却把 sim2real 差距当成可忽略的常数。** 仿真保真度本身是一个可度量、会漂移、且极易被系统性高估的量：物理参数（摩擦、质量、延迟）有后验不确定性；sim2real 的结果分布有经验差距；验证场景对部署上下文覆盖不足；最危险的是——用仿真生成合成数据去填补覆盖空洞，再用同一个仿真验证规则，形成自证循环。引入仿真保真证书 SFC 与硬门 kc_sim，把「仿真成立」升级为「在保真度已被实机数据验证、且验证集不是仿真自身后代的仿真中成立」；合成数据只允许在「真实数据锚定比例 ≥ f_real_min」的前提下补覆盖，不能替代真实证据。

3. **溯源与循环：数据质量与仿真保真都可能被「证据洗白」绕过。** 同一条幸运轨迹可被同时计入覆盖、物理、人因、末点、记忆五个锚，制造「五重独立」的假象（证据复用/laundering）；合成数据可经「仿真→训练→再验证」回环抬高自身保真度。建立溯源 DAG G_prov 与循环检测，要求 SFC 的验证集不是待测仿真的后代，并对跨锚复用做独立性折扣 κ_cross（以真实 episode 的并集而非各锚计数之和来度量证据）。

**关键洞见**：v3 回答「证据链的每个锚是否成立」；v4 追问「构成这些锚的数据本身有多可信、仿真是否配得上它的结论、证据是否在自我循环」。七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_quality ∧ kc_sim，其中 kc_physics 内部要求 kc_sim 通过，kc_coverage 内部要求真实数据比例 ≥ f_real_min，kc_quality 内部同时约束逐项 DQC 与规则级有效独立支持 N_ind。软评分 ECS_v4 = ECS_v3 · q_eff 仅用于分级与仪表盘，不参与安全决策。

**形式化目标（增量）**：
1. 定义数据质量证书 DQC = (q_acc, q_comp, q_time, q_cons, q_prov, n_eff, q_score) 与质量代数（派生统计量的质量是输入质量的 meet，即逐维 min），及硬门 kc_quality。
2. 定义有效样本量 n_eff = n / (1 + (n−1)ρ̄)（ρ̄ 由溯源聚类估计），要求统计门以 n_eff 而非原始 n 计算置信界。
3. 定义仿真保真证书 SFC = (U_θ, Δ_sim2real, C_scen, H_val, n_val, s_fid) 与硬门 kc_sim（含 Δ 上界、参数不确定度、场景覆盖、验证集为实机数据且非仿真后代）。
4. 定义溯源 DAG G_prov、可达性/无环不变量、合成数据真实锚定比例 f_real，以及跨锚独立支持 N_ind 与折扣 κ_cross。
5. 定义 EFA-v4 七硬门与执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3：在 v3 每条路径上追加 kc_quality（逐证据/规则级）与 kc_sim（物理锚内部），并把覆盖门收紧为「真实锚定 + 有效独立支持」，故只缩不涨。

**本轮最大风险**：**元质量自指**——DQC 与 SFC 本身由未经验证的数据与仿真产出；若质量/保真估计器系统性偏乐观（或指标被 Goodhart 化），低质量证据会被「洗白」为高置信证书，而由于 kc_quality 位于所有锚的最上游，这一偏差会乘性放大到整条证据链，形成比 v3 联邦毒化更根本的单点系统性失效。

## 2. 关键算法骨架

### IP-489 DQK：数据质量证书与有效样本量（控制环内 O(1)/项）

```python
@dataclass
class DataQualityKernel:
    """DQK：五维数据质量 + 有效样本量；kc_quality 硬门（逐项 + 规则级）"""
    q_dim_min: dict = field(default_factory=lambda: {
        "acc": 0.70, "comp": 0.90, "time": 0.60, "cons": 0.70, "prov": 0.90})
    q_score_min: float = 0.75
    n_eff_min: int = 30
    n_ind_min: int = 12          # 跨锚有效独立 episode 数
    f_real_min: float = 0.5      # 覆盖证据中真实数据最低比例
    tau_q: float = 5.0           # s，时效衰减常数
    acc_tol: float = 0.01        # 跨模态残差容忍

    def assess(self, item: EvidenceItem, t_now: float) -> DQC:
        """逐项质量：跨模态残差、字段完整度、时效、模态间一致性、溯源完整性"""
        q_acc = float(item.cross_modal_residual <= self.acc_tol)
        q_comp = item.present_fields / max(item.required_fields, 1)
        q_time = float(np.exp(-max(t_now - item.t, 0.0) / self.tau_q))
        q_cons = 1.0 - item.normalized_disagreement
        q_prov = item.provenance.integrity          # 哈希链 + 来源信任
        q_score = float(np.prod([q_acc, q_comp, q_time, q_cons, q_prov]) ** 0.2)
        return DQC(q_acc, q_comp, q_time, q_cons, q_prov,
                   n_eff=item.n_eff, q_score=q_score)

    def kc_quality(self, dqcs, n_ind: int, real_fraction: float) -> bool:
        """硬门：任何一维/综合分/有效样本/独立支持/真实锚定不达标即拒"""
        per_item = all(
            all(d.q[k] >= self.q_dim_min[k]
                for k in ("acc", "comp", "time", "cons", "prov"))
            and d.q_score >= self.q_score_min
            and d.n_eff >= self.n_eff_min
            for d in dqcs)
        return (per_item and n_ind >= self.n_ind_min
                and real_fraction >= self.f_real_min)

    @staticmethod
    def effective_n(n: int, rho_bar: float) -> float:
        """等相相关下 Var(x̄)=σ²/n·(1+(n−1)ρ)，故 n_eff=n/(1+(n−1)ρ)"""
        return n / (1.0 + (n - 1) * max(rho_bar, 0.0))

    @staticmethod
    def meet(a: DQC, b: DQC) -> DQC:
        """质量代数：派生统计量质量 = 输入质量逐维 meet（不高于最弱输入）"""
```

### IP-490 SFK：仿真保真证书（离线/慢时域，不在控制环）

```python
@dataclass
class SimulationFidelityKernel:
    """SFK：仿真保真证书；kc_sim 硬门；仿真是有界神谕而非无界真值"""
    delta_sim_max: float = 0.05     # |p_sim − p_real| 上界
    U_theta_max: float = 0.15       # 参数后验不确定度
    c_scen_min: float = 0.80        # 场景覆盖
    n_val_min: int = 100            # 实机验证样本下限
    delta_conf: float = 0.05        # 置信水平

    def certify(self, sim_id, theta_post, real_val, scen_ctx) -> SFC:
        U_theta = float(np.trace(theta_post.cov)) / len(theta_post.mean)
        p_sim = sim_success_rate(sim_id, scen_ctx)
        p_real = real_success_rate(real_val)
        eps_dkw = np.sqrt(np.log(2.0 / self.delta_conf) / (2 * len(real_val)))
        delta = abs(p_sim - p_real) + eps_dkw      # 系统偏差 + 实机经验误差
        C_scen = scenario_coverage(scen_ctx, real_val.scenarios)
        H_val = hash_manifest(real_val)            # 实机验证集哈希（溯源锚）
        return SFC(U_theta, delta, C_scen, H_val, len(real_val),
                   s_fid=float(np.exp(-delta) * C_scen * (1 - U_theta)))

    def kc_sim(self, sfc: SFC, prov) -> bool:
        return (sfc.delta_sim2real <= self.delta_sim_max
                and sfc.U_theta <= self.U_theta_max
                and sfc.C_scen >= self.c_scen_min
                and sfc.n_val >= self.n_val_min
                and prov.is_real(sfc.H_val)                     # 验证集为实机数据
                and not prov.reachable(sfc.sim_id, sfc.H_val))  # 非自证循环

    def propose_active_probes(self, sfc: SFC) -> list:
```

### IP-491 PCG：溯源、无环与跨锚独立性（审计旁路，O(V+E) 摊销）

```python
@dataclass
class ProvenanceCircularityGuard:
    """PCG：溯源 DAG、无环检测、自证循环、跨锚复用折扣"""
    def __post_init__(self):
        self.parents: dict[str, set[str]] = {}
        self.tags: dict[str, dict] = {}

    def add(self, node, parents, synthetic=False):
        self.parents.setdefault(node, set()).update(parents)
        self.tags[node] = {"synthetic": synthetic}
        if self.reachable(node, node):
            raise ValueError("溯源 DAG 出现环：证据自指")

    def reachable(self, src, dst) -> bool:
        """src 是否为 dst 的祖先（迭代 DFS，O(V+E)，结果可缓存）"""
        ...

    def is_real(self, h) -> bool:
        return self.tags.get(h, {}).get("synthetic", False) is False

    def real_fraction(self, evidence_ids) -> float:
        reals = sum(1 for e in evidence_ids if self.is_real(e))
        return reals / max(len(evidence_ids), 1)

    def independent_support(self, anchor_sets) -> tuple[int, float]:
        """N_ind=|∪ S_a|；κ_cross=N_ind/Σ|S_a|（同批证据复用会拉低 κ_cross）"""
        union = set().union(*anchor_sets)
        total = sum(len(s) for s in anchor_sets)
        return len(union), (len(union) / total if total else 0.0)
```

### IP-492 EFA-v4：七硬门 + 质量加权软评分 + 流水线

```python
@dataclass
class EvidenceForgingAssemblerV4:
    """EFA-v4：七硬门 fail-closed；质量/仿真门位于最上游，软评分仅分级"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict                       # rule_id -> S2RC（携带 SFC）
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    dqk: DataQualityKernel
    sfk: SimulationFidelityKernel
    pcg: ProvenanceCircularityGuard
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec, evidence, ctx) -> tuple[bool, str]:
        if self.hic.veto_active(hic):                  return False, "HIC_STOP"
        dqcs = [self.dqk.assess(e, t_now) for e in evidence.items]
        n_ind, _ = self.pcg.independent_support(evidence.anchor_sets)
        if not self.dqk.kc_quality(dqcs, n_ind,
                                   self.pcg.real_fraction(evidence.coverage_ids)):
            return False, "DATA_QUALITY"
        if not self.scf.kc_coverage(x, t_now):         return False, "COVERAGE_BLIND"
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != "accept" or s2rc.mu_pass < self.mu_S:
            return False, "PHYSICS_UNPROVEN"
        if not self.sfk.kc_sim(s2rc.sfc, self.pcg):    return False, "SIM_UNPROVEN"
        if not self.eek.kc_ee(eec):                    return False, "EE_UNPROVEN"
        pass_mem, eta_mem, novelty = self.ltem.query(*ctx)
        if not pass_mem:                               return False, "MEMORY_REJECT"
        return True, "FORGED" + ("|NOVELTY" if novelty else "")

    def ecs_v4(self, x, t_now, rule_id, dqcs, kappa_cross,
               A_att=0.0, eta_mem=0.5) -> float:
        q_eff = float(np.prod([d.q_score for d in dqcs]) ** (1.0 / max(len(dqcs), 1)))
        base = (self.scf.gamma3d(x, t_now) ** self.w[0]
                * getattr(self.msrg_cache.get(rule_id), "mu_pass", 0.0) ** self.w[1]
                * (1 + self.w[2] * A_att))
        return base * eta_mem * q_eff * kappa_cross
```

### 集成流水线（v3 → v4）

```
离线/慢时域（SFK + FFA，不在控制环）：
  SFK：参数后验 + 实机 held-out 验证 ──▶ SFC（Δ_sim2real, U_θ, C_scen, H_val）
       ──▶ 若 Δ_sim2real 超界：propose_active_probes → 实机补数据 → 重认证（主动缩小 sim2real）
  FFA：各站 Δ_i（带 DQC、n_eff）──▶ 质量加权聚合 ──▶ Φ_global
  PCG：所有数据/统计/证书入 G_prov，维护无环；合成数据标 synthetic=true

在线规则准入（异步，< 2 s/规则）：
  DAKI κ_i^new ──▶ MSRG.sprt_gate（以 n_eff 计，联邦校准 Θ_domain）──▶ S2RC + SFC
       ──▶ EFA-v4.hard_gate（含 dqk.kc_quality 与 sfk.kc_sim）──▶ KC 库 v+1

在线控制环（< 0.1 ms 增量）：
  每周期：EEK 读力/力矩/触觉 → EEC；DQK 只做 O(1) 增量质量更新
  证书消费前：EFA-v4.hard_gate(x, t, rule, hic, eec, evidence, ctx)
      ├─ HIC_STOP        → S_stop（MSRV 预验证制动集）
      ├─ DATA_QUALITY    → 丢弃该证据/降级到统计模式 + 教师
      ├─ COVERAGE_BLIND  → 回退 STCK 球域 + 教师
      ├─ PHYSICS_UNPROVEN→ 规则降权（统计模式）
      ├─ SIM_UNPROVEN    → 该规则不得由仿真单独授信，转实机验证队列
      ├─ EE_UNPROVEN     → 末端复位/重触 + 教师
      └─ MEMORY_REJECT   → 教师介入或重新 MSRG
```

## 4. 正确性论证（增量更新）

### 引理 41（有效样本量修复相关样本的伪置信）

**陈述**：设观测 x_1,…,x_n 同分布、方差 σ²、两两相关系数 ρ≥0（等相相关）。则样本均值方差 Var(x̄)=σ²/n_eff，其中 n_eff=n/(1+(n−1)ρ)。任何基于独立性的集中不等式（Hoeffding、Chebyshev、SPRT 的 Wald 错误界）以 n_eff 代入仍成立（保守）；若以原始 n 代入，则证据被高估至多 1+(n−1)ρ 倍。因此 kc_quality 要求 n_eff ≥ n_eff_min，可在相关数据上恢复名义 Type-I 错误。

**证明**：Var(x̄)=1/n²[nσ²+n(n−1)ρσ²]=σ²/n·(1+(n−1)ρ)=σ²/n_eff。代入 n_eff 后与独立样本公式完全相同，故集中不等式以 n_eff 成立。ρ→1 时 n_eff→1；ρ=0 时 n_eff=n。∎

**工程含义**：把一条轨迹复制 1000 次只会得到 n_eff≈1 而非 1000；覆盖与 SPRT 的置信度不再被相关样本灌水。

### 引理 42（仿真保真的 sim2real 下界与不可消除的系统偏差）

**陈述**：设规则 r 的仿真成功率 p_sim、实机成功率 p_real。若 SFC 以置信 1−δ 证明 |p_sim−p_real| ≤ Δ_sim（Δ_sim 由实机 held-out 验证与 DKW 两样本界给出），则 kc_sim 通过 ⇒ p_real ≥ p_sim − Δ_sim；若再有 p_sim ≥ p_min（S2RC），则 p_real ≥ p_min − Δ_sim。且 Δ_sim ≥ β（系统偏差下界），β 不随仿真样本数增大而减小，只能通过实机验证降低经验项 ε_dkw(n_val)。

**证明**：由三角不等式 p_real ≥ p_sim − |p_sim−p_real| ≥ p_sim − Δ_sim。DKW：以概率 ≥1−δ 有 sup_x|F_n−F| ≤ √(ln(2/δ)/(2n))，故差距估计误差随 n_val 收缩；系统偏差 β 是仿真与实机分布的固有距离，仿真采样再多也不改变。∎

**工程含义**：仿真从「无界真值」降为「带显式误差界的有界神谕」；仅靠增加仿真样本无法把 Δ_sim 压到 0。

### 引理 43（溯源无环阻断自证与跨锚复用）

**陈述**：若 G_prov 无环且 ¬Reach(sim_fit, H_val)，则仿真自身的合成输出不能用于验证该仿真（无自证抬升）。若规则各锚共享原始 episode，则 N_ind<Σ_a|S_a| 且 κ_cross<1；要求 N_ind ≥ n_ind_min 即强制真实独立支持，七锚合取不能凭空制造独立可靠性。

**证明**：若用仿真 S（拟合集 F）生成的合成数据验证 S，则存在路径 F→synthetic→H_val，即 Reach(F,H_val)，与条件矛盾。复用侧：并集大小 ≤ 各集合大小之和，等号当且仅当两两不交；要求并集 ≥ n_ind_min 即对复用设下上界。∎

**工程含义**：封堵「仿真→训练→再验证」回环与「一条幸运轨迹喂满五锚」的证据洗白。

### 定理 v4（执行集再收缩与质量/保真补全）

**陈述**：在假设 (C1) DQC 各维与 ρ̄ 估计已校准（元质量成立）；(C2) 等相相关模型足以刻画 episode 内依赖；(C3) SFC 的验证集为实机、held-out 且溯源无环；(C4) 继承 v3 的 (B1)~(B4) 下，则：
(i) Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29（严格收缩）；
(ii) 低质量/相关样本的伪置信通过率由引理 41 界；
(iii) 规则真实成功率下界为 p_min − Δ_sim（引理 42）；
(iv) 自证循环与跨锚复用被阻断（引理 43）；
(v) 七硬门 fail-closed，任一不通过即拒，仅 HIC veto 旁路至 S_stop；
(vi) 合成数据替代真实覆盖的比例不得超过 1−f_real_min。

**证明**：(i) v4 在 v3 每条路径上追加 kc_quality 与 kc_sim，并把 kc_coverage 收紧为「真实锚定 + 有效独立支持」，故只缩不涨；严格性由 v3 未检查的低质量/高相关/仿真自证处被关闭保证。(ii)~(iv) 分由引理 41、42、43。(v) 由 EFA-v4 hard_gate 合取结构。(vi) 由 kc_quality 内 f_real ≥ f_real_min。∎

**诚实声明**：(C1) 是本轮最脆弱假设——质量与保真估计器本身是模型，训练它们的数据/仿真质量未被独立认证，存在「谁来认证认证者」的元质量循环；且 q 指标一旦被优化目标盯上，会诱发 Goodhart 化（选对指标友好而非对任务有代表性的数据）。缓解：外部独立审计通道、与部署分布无关的 red-team 质量注入、定期人工元评审、质量指标不可由被审计管线自报。

## 5. 实验设计与初步结果（单机仿真已做；舰队/实机列入第 5 轮）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX（仿真）+ N 台实机 Panda（N=3~5，不同端 effector/摩擦/光照）。
- **对照**：v3-full、v4-full、消融 C1（去 DQK，退化到信任原始样本数）、C2（去 SFK，退化到「MuJoCo 成立即物理成立」）、C3（去 PCG，允许自证与跨锚复用）、C4（去 f_real_min，允许纯合成覆盖）。
- **协议**：(a) 数据质量注入：传感器漂移、过期观测、标注噪声、重复轨迹（相关样本）；(b) 有效样本量攻击：把 1 条轨迹复制 n 次伪造 n 个样本，测 SPRT 误通过率；(c) 仿真保真度攻击：故意低估摩擦不确定性、用合成数据自证，测 kc_sim 是否拒绝；(d) 跨锚复用：同一条轨迹喂五个锚，测 N_ind/κ_cross 是否触发拒绝；(e) 元质量偏移：给质量估计器注入系统性乐观偏置，量化「洗白」放大倍数。
- **指标**：低质量数据误通过率、n_eff 估计误差、SFC 认证界对真实 sim2real 的覆盖率、自证循环检出率、跨锚复用检出率、任务成功率、ECS_v4 与失败 AUC。

## 7. 本轮最大风险（最终确认）

**一句话**：**元质量自指**——DQC 与 SFC 本身由未经验证的数据与仿真产出；若质量/保真估计器系统性偏乐观（或指标被 Goodhart 化），低质量证据会被「洗白」为高置信证书，而由于 kc_quality 位于所有锚的最上游，这一偏差会乘性放大到整条证据链，形成比 v3 联邦毒化更根本的单点系统性失效。
