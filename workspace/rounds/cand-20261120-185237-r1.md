# 第 2 轮（UniBot 线 · 第 2 轮；本轮灵感：「智能体」×「谐波减速器」）

> **承接关系**：第 1 轮 SAGE 用「抓握隐变量 × 技能路由 × 推理期适配」搭起三层栈，其最大风险是**抓握误判的不对称代价**（漏判把可救失败变成硬失败），且唯一真值只有数据集里的间接代理标签。本轮不推倒重来，而是用两个新灵感正面修补这条风险：把"抓住没有"从**被动分类**改写成**可主动做实验的物理量**，把决策者从固定策略升级为**愿意花少量动作买确定性的智能体**。

## 0. 一句话直觉

**谐波减速器**平时被当作"误差源"（回差、传动误差、迟滞、扭转变形）去补偿；反过来看，它恰恰是机器人身上**唯一一个每关节都有、高分辨率、宽带宽的力传感器**：减速器的扭转柔度把力矩变成微小角位移，双编码器把角位移读出来 ⇒ 不需要触觉皮肤，也能"感觉到"夹爪里有没有东西、插头有没有对准、桌面有没有顶住。

**智能体**回答的是"谁来决定去感觉"。第 1 轮的策略是开环执行一条 chunk 直到超时或结束；本轮的策略会在关键处**故意做一个 2 毫米的抬升实验**：抓住 ⇒ 关节力矩随重力发生阶跃；没抓住 ⇒ 力矩几乎不变。这不是更好的分类器，而是**物理对照实验**。于是"抓握确认"从概率猜测变成假设检验，误判代价被实验设计压下去。

## 1. 灵感 A · 谐波减速器 → 本体即传感器（body-as-sensor）

**直觉层**：人的指尖有触觉；UniBot 的 Dex1 在接口里只有 1 维开合标量（5.5→0），既无指关节也无触觉阵列。但机器人的手臂不是"只有位置"的：每个关节里都有一个减速器，它在传递扭矩时必然发生弹性扭转。若我们能读出"指令让关节去哪"与"关节实际在哪"的差，以及电机侧与关节侧编码器的差，我们就在物理上拥有一个**扭矩计**。7 个臂关节的扭矩经雅可比转置映射，就是一个**虚拟六维腕力/力矩传感器**。

**严谨层**（细节见产物区 U13–U15）：设电机侧角 `q_m`、关节侧角 `q_j`、减速比 `N`，则
`q_j = q_m/N + e_0(q_m) + δ(τ)`，
其中 `e_0` 是无载传动误差（对谐波而言以波发生器转角为周期，主导谐波为 2），`δ` 是负载扭转柔度（含迟滞）。双编码器同时给出 `q_m` 与 `q_j` ⇒ 传动误差 `e = q_m/N − q_j` 可观测 ⇒ 在辨识出 `e_0` 与柔度/摩擦模型后，外部力矩 `τ_ext` 可估。即使接口只给"动作指令 `q_cmd` + 关节实测 `q`"，稳态跟踪残差 `r = q_cmd − q` 在 PD 环下也近似正比于 `τ_ext`，可用数据学出"残差→力矩"的观测器。两种通道互为备份。

**为什么这是本轮的关键解锁**：第 1 轮所有关于"抓握/接触/插入"的判断都只能靠视觉几何 + 1 维开合 + EE 位姿间接推断，在未见物体上分布漂移。力矩通道是**物理量**，不随背景/光照漂移；它把第 1 轮最脆弱的一环换成了最稳的一环。

## 2. 灵感 B · 智能体 → 会做实验的决策者（agent-as-experimenter）

**直觉层**：第 1 轮的抓握确认器是一个"分类器 + 阈值"：置信度低于阈值就重抓。但重抓是有代价的（可能碰倒别的物体、浪费时间），而不重抓继续走可能是硬失败。真正的智能不是"更准地猜"，而是**在猜不准的时候，做一个最便宜、最能区分两种假设的动作**。人类就是这么做：不确定杯子拿稳没有，会轻轻抬一下；不确定钥匙插正没有，会轻轻晃一下。

**严谨层**（细节见产物区 U16–U18、U23）：智能体维护一个接触信念 `b_t = P(c_t | o_{1:t})`，`c_t ∈ {free, contact_stable, slip, collision, inserted, jammed}`。它可以选择两类动作：**任务动作**（推进目标）与**探针动作** `u_probe`（抬升 / 轻晃 / 点触 / 微推）。探针的收益是信息量，成本是运动与风险：
`VoI(u) = I(c; o' | b, u) − λ_c·cost(u) − λ_r·risk(u)`，
仅当 `VoI(u) > 0` 且预算允许时执行。这给出一个三区决策：
- **确信已抓住** → 不干预，直接推进；
- **确信未抓住** → 不浪费探针，直接重抓/换原语；
- **不确定（模糊带）** → 执行最便宜的判别实验。

这正是把第 1 轮"高精度、低召回、只在确信未抓住时介入"的保守准则，升级为"**用信息买风险**"：不是降低介入率，而是把介入从"重抓"换成"先做一个可逆的小实验"。

智能体还带一个**身体模型**（body model）：从官方数据学 `r_{t+1} = f(r_t, a_t, c_t)`，于是能在"想象中"先模拟几种探针的力矩响应，再选一个最划算的（model-based VoI，省真机时间）。这不改权重，只是推理期规划，合规风险低。

## 3. 情报核实：G1 的手臂到底是谐波还是行星？（一个必须诚实面对的分歧）

本轮检索出现**互相矛盾的一手/二手信息**，这本身要写进方案而不是藏起来：

1. **拆机报告**（2026-07，EEWorld / humanoid.guide）：G1 关节采用"电机 + **两级行星减速器** + 双编码器 + 驱动"四合一模块，总减速比约 **20.58**，走 QDD 准直驱路线；并明确说这不同于工业界常用的谐波减速器。
2. **学术论文**（arXiv 2606.15915，2026-06，G1 左臂功耗建模）：明确写"每个关节由 BLDC 电机 + **谐波减速器**驱动；关节位置/速度/**估计力矩**以 100 Hz 经 ROS2 发布"。
3. **官方文档**（support.unitree.com）：只承诺**双编码器**（更精确的位置/速度反馈），未在公开参数页钉死减速器类型。

**结论**：不押注型号，押注**可辨识的物理事实**——(a) 双编码器存在；(b) 减速器有扭转柔度与回差；(c) 存在可建模的传动误差。**第一件事就是用官方数据做模型辨识**（谐波 / 行星 / 混合），让数据选模型，而不是让我们对型号的信念选模型。这反而使方案更稳：行星低减速比、可背驱 ⇒ 残差更大、力矩更易辨；谐波高减速比、回差小 ⇒ 精度高但迟滞大。两种情形我们都有对应的观测器与补偿器。

## 4. 瓶颈重述（承接第 1 轮 T1–T3，本轮更新为 T4–T6）

- **T1 不变**：终态成功是唯一计分货币；力矩通道的价值必须最终翻译成"最后一环被完成"。
- **T4 断点在"接触后的一厘米"**：第 1 轮定位到插入/旋转/释放最差，但这些任务共同需要的是**力闭环**（对准、卡滞检测、释放确认），而第 1 轮只有视觉 + 开合标量。视觉能告诉你"大致对齐"，只有力能告诉你"真的进去了"。
- **T5 力闭环带宽被接口结构限制**：`get_action` 是 chunk 级调用，接触反馈频率约 `f_loop = 1/(T_a·Δt + T_infer)`。所以第 1 轮的"自适应短 chunk"不只是降抖动，而是**力控能否成立的前提**：插入相位必须用 `T_a ∈ {1,2,3}` 才能把环路抬到 10–30 Hz。这是本轮把 IP-03 与接触控制绑定的原因。
- **T6 决策的信息结构错了**：第 1 轮把"验证"当分类器，只能被动接受误判；把它当实验，就能主动降低不确定性。成本是几毫米的运动，收益是把"漏判导致的硬失败"换成"一次可逆的探测"。

## 5. 研究问题（本轮）

- **Q6（缩减器可观测性）**：在只有关节位置/速度（可能加估计力矩）的接口下，减速器柔度 + 双编码器/跟踪残差能否给出**带误差界**的腕部六维力估计？分辨率与带宽的权衡是什么？型号未定时如何用数据辨识？
- **Q7（主动验证是否真的优于被动分类）**：在误判代价不对称（漏判 ≫ 误判）时，带 VoI 的探针策略是否严格优于"被动分类 + 阈值重抓"？最优探针集合与阈值如何由数据定？
- **Q8（位置接口上的柔顺）**：动作空间是关节/EE 位置，如何在**不用额外力控接口**的前提下，用虚拟导纳在接触相位实现柔顺插入？在 chunk 级反馈与延迟下，稳定的刚度/阻尼区间是什么？
- **Q9（智能体的合规形态）**："LLM 规划器 + 工具调用"是否会被判为多模型/非通才？最严格的单 checkpoint 形态（潜变量规划头 + 确定性 VoI 调度器 + 动作专家）能保留多少收益？必须准备可实测的降级形态。
- **Q10（跨实例指纹）**：每台机器人的减速器参数（柔度、回差、传动误差相位）不同；在线辨识这组参数能否同时充当**硬件指纹**（跨实例迁移 + 可信度自证 + 异常检测）？

## 6. 设计原则增补（P7–P10）

- **P7 本体即传感器**：优先从已有本体信号（双编码器、跟踪残差、估计力矩）中提取新物理量，而不是假设能加装传感器；任何"需要新硬件"的方案一律降级。
- **P8 主动验证优于被动分类**：当不确定性的期望代价 > 探针成本时，必须把"做实验"作为一等动作；探针必须**可逆、有界、可回退**。
- **P9 物理先验必须可辨识**：任何物理模型（谐波/行星、柔度、迟滞）都要能从官方数据辨识出来；型号有分歧时，用模型选择实验裁决，不写死假设。
- **P10 智能体内化、可降级**：对外仍是一个 policy service / 一个 checkpoint / 一个 API；智能体能力以潜变量规划头 + 推理期算法实现；必须准备"无智能体"的纯基线并与完整形态实测差距。

## 7. 合成：HARMONIA 五环（谐波智能体）

把两个灵感与第 1 轮三层栈合并为一条闭环：

**感知环（减速器→力）→ 信念环（接触状态 + 共形校准）→ 实验环（VoI 探针 + 身体模型）→ 柔顺环（接触相位自适应导纳 + 短 chunk 力环）→ 审计环（决策/延迟/jerk 可导出）**。

- **感知环**替换第 1 轮的"视觉 + 开合"接地层；
- **信念环**用共形预测给出**有限样本假阳率保证**，直接回应第 1 轮"漏判不对称"；
- **实验环**替换第 1 轮的"阈值即重抓"，改为"模糊带做实验"；
- **柔顺环**把第 1 轮的 chunk 缝合升级为"接触相位最小 chunk + 虚拟导纳"，直击插入/旋转；
- **审计环**把第 1 轮的可信度要求变成"信念-决策-探针"全轨迹可导出。

一句话：**第 1 轮让机器人"看得更准"，第 2 轮让机器人"摸得到、会试一下"。**

## 0. 本轮结论摘要

**一句话路线**：把机器人**自己的减速器**变成缺失的力觉通道（感知环），把"抓握确认"变成**有有限样本保证的接触信念**（信念环），把策略从"开环执行者"升级为"**在模糊带做可逆实验的智能体**"（实验环），再用**接触相位最小 chunk + 虚拟导纳**把力闭环落到位置接口上（柔顺环），最后用**信念-决策全轨迹**满足可信度审计（审计环）。

| 第 1 轮的痛点 | 第 1 轮做法 | 本轮升级 | 关键量化目标 |
|---|---|---|---|
| 抓握状态不可直接读出，只有视觉 + 1 维开合 | GraspVerify 三信号分类器 | **力矩接地**：减速器柔度 + 双编码器/跟踪残差 → 腕部六维力 | 力矩估计误差 ≤ 0.5 N（准静态）；抓握 AUROC ≥ 0.95 |
| 漏判不对称，只能保守低召回 | 高阈值、只在高置信时重抓 | **主动抬升实验 + VoI**：在模糊带用 2–5 mm 可逆运动做假设检验 | 决策 regret 相对被动分类 ↓ ≥ 40%；探针成本 ≤ 0.3 s/次 |
| 插入/旋转/释放断在"最后一厘米" | 视觉闭环 + 缝合 | **虚拟导纳 + 短 chunk 力环** | 插入类任务相对提升 ≥ 25%；力峰 ↓ ≥ 50%；卡滞率 ↓ ≥ 40% |
| 跨实例/跨 episode 适配有合规风险 | ContextAdapter 在线改权重 | **减速器指纹在线辨识**（不改主干） | 跨 N 台迁移误差 ↓ ≥ 30%；零主干权重更新 |
| 可信度审计只到延迟/jerk | AuditLayer | **AgentTrace**：信念、探针、决策可导出 | 决策可复现率 100%；p99 仍 ≤ 预算 |

**核心命题（本轮要证伪的）**：在 UniBot 的接口约束下，**"减速器 = 力传感器" + "验证 = 实验"** 能以零额外硬件，把第 1 轮最脆弱的环节（抓握/接触判断）变成最稳的环节，并顺带解锁插入/旋转的力闭环。

**合规红线不变**：一个 checkpoint、一个 API 服务；不读评测侧私有信息；不硬编码任务分支。智能体能力用**潜变量规划头 + 确定性推理期算法**实现，并准备无智能体降级形态（对应 Q9）。

## 1. 情报核实：减速器型号的公开分歧与处置

| 来源（检索 2026-11-20） | 说法 | 可信度 |
|---|---|---|
| EEWorld / humanoid.guide 拆机（2026-07 / 2026-09） | G1 关节为"电机 + **两级行星**减速器 + 双编码器 + 驱动"四合一，总减速比 ≈ 20.58，QDD 路线 | 二手拆机，细节具体 |
| arXiv 2606.15915（2026-06，G1 左臂功耗建模） | "每关节由 BLDC + **谐波减速器**驱动；位置/速度/**估计力矩**以 100 Hz 经 ROS2 发布" | 学术论文，与拆机冲突 |
| Unitree 官方 G1 文档 | 明确"**双编码器**"；公开参数页未钉死减速器类型 | 一手，但信息有限 |

**处置（P9）**：不赌型号，赌可辨识物理。把"减速器类型"当作**模型选择问题**：用官方数据在三个候选模型（纯行星 QDD / 纯谐波 / 混合）上做辨识，以留出残差与 BIC 选模。物理上二者都满足本方案所需的两条性质：**扭转柔度可观测** + **存在周期性传动误差**；差别只影响参数范围：
- 行星低减速比、可背驱 ⇒ 跟踪残差大、力矩分辨率好，但传动误差小、迟滞小；
- 谐波高减速比、回差小 ⇒ 精度高，但迟滞/柔度非线性强，需显式迟滞算子。

这条分歧反而说明：**任何写死"某型号"的力估计都不可靠**，只有"辨识 + 误差界"才是可迁移的。

**零成本探测协议（先于一切建模，1–2 天）**：
1. 检查 obs 是否含 `estimated_torque` / motor current / 双编码器原始值 / motor-side position；
2. 判定 `observation.state.*_arm` 是"实测关节角"还是"上一指令角"；
3. 在自由空间回放官方动作，统计 `r = q_cmd − q` 的可重复性与噪声底；
4. 用官方 client 复刻 chunk 语义（是否插值、是否 hold 末动作、是否重置控制器）；
5. 测 `get_action` 端到端延迟与抖动。
> 若第 1 步全阴性 → 退化为"残差通道"；若残差也不可复现 → 退化为"视觉 + 开合 + 短 chunk 准静态探针"（仍有主动实验，但精度下降），方案不死。

## 3. 创新点详述

### IP-09 · ReducerProprio 减速器本体感知（P0）

- **动机**：Dex1 在接口里只有 1 维开合，无触觉；但每个臂关节都有减速器与双编码器。减速器的扭转柔度把力矩变成角位移 ⇒ 本体自带扭矩计。这是第 1 轮"抓握隐变量"最缺的物理接地。
- **与现有方案的差异**：现有 VLA 把本体状态当作"位置输入"；我们把本体当作**力觉观测通道**，并显式建模传动误差/迟滞（而不是当噪声丢掉）。
- **技术可行性**：中–高。**通道优先级**：① 接口若直接给估计力矩 → 直接用 + 校准；② 若给双编码器 → 直接算传动误差 `e`；③ 若只给跟踪残差 → 学"残差→力矩"观测器。三条通道可融合。
- **落地步骤**：
  1. 零成本探测（§1）；
  2. 自由空间段辨识 `e_0` 的周期结构与柔度 `K_r`、摩擦（Coulomb+viscous+Stribeck）；
  3. 模型选择（行星/谐波/混合）；
  4. 训练/标定力矩观测器 `τ̂_ext`，用"已知质量物体抬升"做真值锚点；
  5. 雅可比转置映射成腕部六维力 `ŵ`，并给出误差界；
  6. 在难任务上验证力信号的可分性（抓握/滑移/碰撞/插入到底）。
- **风险**：① 低层控制器强前馈/平滑会抹平残差 ⇒ 用双编码器通道兜底；② 摩擦/温漂导致零漂 ⇒ 每次 episode 前用静止段自零；③ 型号误判 ⇒ 模型选择先行，不写死。

### IP-10 · ConformalGrasp+ 共形抓握/滑移信念（P0）

- **动机**：第 1 轮最大风险是"漏判把可救失败变硬失败"，且真值只有间接代理标签。力矩通道让"抓住没有"有了物理对照，但**任何观测器都有分布外失效**，所以需要**有保证的不确定性**，而不是又一个 softmax 置信度。
- **与现有方案的差异**：现有方案输出一个未校准的概率；我们用**分裂共形预测（split conformal）**把"未抓住"判定阈值校准到**有限样本假阳率 ≤ α**，并把滑移建模为力矩的时序异常。
- **技术可行性**：高。校准集来自官方数据的"抓住/未抓住"弱标签（夹爪闭合后物体随臂运动 + 抬升力矩阶跃）；滑移用短时窗力矩能量/振荡特征。
- **落地步骤**：
  1. 在官方数据上生成弱标签（夹爪闭合 + 物体相对腕部位移一致性 + 抬升力矩阶跃）；
  2. 训练力矩接地特征 + 滑移检测器；
  3. 分裂共形校准（按任务/物体类型分层，避免 OOD 破坏可交换性）；
  4. 输出 `b_t`（接触信念）与"未抓住"的共形 p 值；
  5. 对 OOD 用**加权共形 / 在线重校准**（只校准阈值，不动模型，合规安全）。
- **风险**：① 共形保证依赖可交换性，未见物品会破坏 ⇒ 分层 + 加权 + 保守 α；② 滑移标签噪声 ⇒ 用多信号交叉验证；③ 校准集与评测集任务分布不同 ⇒ 每类任务单独校准。

### IP-11 · AgentProbe 智能体主动验证（P0）

- **动机**：验证不应是"更准的猜"，而应是"更便宜的实验"。第 1 轮把验证当分类器，误判代价只能被动承受；本轮把"抬升一下"作为一等动作，用 VoI 决定何时做。
- **与现有方案的差异**：现有 VLA 的 chunk 是纯任务动作；我们在模糊带插入**探针动作**（micro-lift / wiggle / tap / micro-push），并配一个**身体模型**在想象中预筛（model-based VoI），减少真机试错。
- **技术可行性**：中–高。探针库小（4–6 个参数化原语），每个都有界、可逆、可回退；身体模型是小型残差/力矩预测器。
- **落地步骤**：
  1. 定义探针库与安全边界（位移 ≤ 5 mm、力 ≤ 3 N、时长 ≤ 0.5 s）；
  2. 训练身体模型 `r_{t+1} = f(r_t, a_t, c_t)`（官方数据自监督）；
  3. 实现确定性 VoI 调度器（<1 ms）：三区决策（确信抓住/确信未抓住/模糊带）；
  4. 潜变量规划头（单 checkpoint 内）输出技能 + 是否探针；LLM 规划器仅作**异步低频**（episode 开始/失败后）可选插件（Q9）；
  5. 探针后更新信念，若仍模糊且预算耗尽 → 回退"保守重抓/换原语"（第 1 轮 IP-02 行为）。
- **风险**：① 探针本身可能碰倒物体 ⇒ 限幅 + 单物体场景优先 + 禁区；② VoI 模型不准 ⇒ 用保守先验 + 硬预算；③ 智能体被判非"单模型" ⇒ 双层形态（§9）。

### IP-12 · ContactAdmittance 接触相位导纳 + 短 chunk 力环（P0）

- **动机**：插入/旋转/释放需要力闭环，而动作接口是位置指令且是 chunk 级反馈。第 1 轮的"自适应短 chunk"在本轮获得新语义：**chunk 长度 = 力反馈带宽旋钮**。
- **与现有方案的差异**：现有方案在位置空间开环执行；我们在位置指令上叠加**虚拟导纳**：根据 `ŵ` 与期望力修正目标，并在接触相位把 `T_a` 降到 1–3 以抬高环路频率。
- **技术可行性**：中–高，但**必须先复刻 chunk 执行语义**（Q5/§1）。导纳只在准静态（低速接触）启用，避免高频不稳定。
- **落地步骤**：
  1. 用官方 client 复刻闭环，确认 chunk 内部如何执行；
  2. 实现一阶导纳：`q_des = q_nom + J^+ · K^{-1}(w_d − ŵ)`（或积分形式），并对回差做死区补偿；
  3. 相位相关刚度调度：横向软（对准）、轴向硬（插入）、旋转软（找牙）；
  4. 接触相位 `T_a = 1–3`，自由相位 `T_a = 8–16`；切换带最小驻留；
  5. 稳定/能量监测：检测到振荡立即降增益或回退纯位置；
  6. 导出力峰、卡滞、延迟审计。
- **风险**：① 延迟 + 导纳导致极限环 ⇒ 无源性条件 + 2–3× 余量 + 回退；② 力矩零漂导致稳态偏差 ⇒ 每 episode 自零 + 高通滤波；③ 短 chunk 抬高调用频率 ⇒ 按 N 端口压测延迟。

### IP-13 · GearFingerprint 减速器指纹（P1）

- **动机**：每台机器人的减速器柔度、回差、传动误差相位不同（制造与磨损）。在线辨识这组参数，既是**跨实例适配的上下文**，也是**硬件健康/异常检测**的指纹。
- **与现有方案的差异**：现有 sim2real 靠域随机化；我们把"真实机器人的减速器参数"在线辨识出来，作为显式上下文，比随机化更贴。
- **落地步骤**：自由空间短辨识 → 参数后验 → 作为 `c_t` 的一部分输入 FiLM/门控（不动主干）→ 跨实例验证。
- **风险**：辨识在接触段受负载污染 ⇒ 只用自由空间/轻载段；参数不可辨识 ⇒ 只保留对力矩观测影响最大的 2–3 个参数。

### IP-14 · ResonanceProbe 微振动阻抗谱（P2）

- **动机**：谐波/行星传动有扭转共振；注入有界微抖动、测响应，可估接触刚度与负载惯量，区分"夹住了/夹空了/插到底了/卡住了"。
- **风险**：高频可能超出接口带宽、可能扰动场景 ⇒ 仅 P2 探索，严格限幅，默认关闭。
- **验收集**：接触刚度估计相对误差 ≤ 25%；对抓握/插入状态的额外可分性 ≥ +10% AUROC。

### IP-15 · AgentTrace 可审计智能体轨迹（P2，并入 IP-12 工程交付）

- **动机**：官方明确会看延迟波动与动作统计规律性；智能体的"实验动作"若不可解释，容易被误判为不规则交互。把信念-探针-决策全轨迹导出，既自证又便于调试。
- **落地步骤**：埋点（`b_t`, `VoI`, `probe`, `ŵ`, `T_a`, 延迟, jerk）→ 每 episode 摘要 → 可导出 JSON；对"探针动作"标注为**有界、可复现、有目的**。

## 4. 符号与定义（U13–U24）

| 符号 | 含义 |
|---|---|
| `N` | 减速比 |
| `q_m, q_j` | 电机侧 / 关节侧角 |
| `e, e_0, δ` | 传动误差 / 无载传动误差 / 负载扭转 |
| `K_r` | 减速器扭转刚度（可非线性） |
| `r_t` | 跟踪残差 `q_cmd − q` |
| `τ̂_ext` | 外部关节力矩估计 |
| `ŵ` | 腕部六维力/力矩估计 |
| `c_t` | 接触状态（free / stable / slip / collision / inserted / jammed） |
| `b_t` | 接触信念 `P(c_t | o_{1:t})` |
| `𝔓` | 探针库 {micro-lift, wiggle, tap, micro-push} |
| `VoI` | 价值 of information |
| `K(φ)` | 相位相关导纳刚度 |
| `f_loop` | 接触力环频率 |
| `ψ_j` | 第 j 关节减速器指纹参数 |
| `τ_α` | 共形阈值 |

**定义 U13（减速器传动模型）** `q_j = q_m/N + e_0(q_m) + δ(τ_ext)`，其中 `e_0` 以波发生器转角为周期（谐波主导谐波为 2），`δ` 由带回差的非线性柔度算子 `C_r` 给出：`τ_ext = K_r·δ + H[δ](t) + τ_f(δ̇)`，`H` 为迟滞算子，`τ_f` 为摩擦。
**定义 U14（力矩观测器）** 给定观测 `o`，`τ̂_ext = Φ_θ(q, q̇, q_cmd, q_m, q_j, a_{t-k:t})`；训练以自由空间逆动力学残差为自监督，真机以已知质量抬升为锚点。
**定义 U15（虚拟腕力）** `ŵ_t = (J(q)^T)^† τ̂_ext`，冗余臂用加权伪逆；接触点力由 `ŵ` 与指尖几何反解。
**定义 U16（接触信念）** `b_t = P(c_t | o_{1:t})`，由视觉 + 开合 + `ŵ` 融合；`c_t ∈ {free, stable, slip, collision, inserted, jammed}`。
**定义 U17（抬升检验统计量）** 对抬升 `Δz` 前后沿重力方向的力矩差 `Δτ_g`，检验 `H_0: 未抓住` vs `H_1: 抓住`；统计量 `T = Δτ_g / σ_Δ`，`σ_Δ` 由静止段估计。
**定义 U18（VoI 探针）** `VoI(u) = E_{o'|b,u}[ H(b) − H(b|o') ] − λ_c·cost(u) − λ_r·risk(u)`；仅当 `VoI(u) > 0` 且预算允许时执行 `u ∈ 𝔓`。
**定义 U19（导纳整形）** `q_des = q_nom + J^+ K(φ)^{-1}(w_d − ŵ)`；`K(φ)` 在 reach/align 横向软、insert 轴向硬、rotate 扭转软。
**定义 U20（接触环带宽）** `f_loop = 1/(T_a·Δt + T_infer)`；要求 `f_loop ≥ β·f_contact`（`β ≈ 5–10`），由此反解各相位允许的最大 `T_a`。
**定义 U21（减速器指纹）** `ψ_j = (K_r, backlash, {a_n, φ_n}_{n≤3}, τ_f)`；在线 MAP 估计后作为上下文 `c_t` 的一部分。
**定义 U22（共形阈值）** 在分层校准集上，取非一致性分数 `s` 的 `⌈(n+1)(1−α)⌉/n` 分位为 `τ_α`；当"未抓住"分数 `> τ_α` 时拒绝"已抓住"，给有限样本假阳率保证。
**定义 U23（智能体策略）** `π_agent(u, skill | b_t, ℓ, g) = argmax_{u,skill} [ Q(skill|b_t,ℓ) + VoI(u|b_t) ]`，实现为单 checkpoint 内的潜变量规划头 + 确定性 VoI 调度器；LLM 规划器仅作可选异步插件。
**定义 U24（审计轨迹）** `A = {(b_t, u_t, skill_t, ŵ_t, T_a,t, latency_t, jerk_t)}`，每 episode 可导出、可复现。

## 5. 推导（引理 L8–L14）

**引理 L8（力矩可观测性与分辨率权衡）** 若双编码器可读 `q_m, q_j` 且 `e_0` 辨识误差为 `ε_0`，则力矩估计误差满足 `|τ̂_ext − τ_ext| ≤ K_r·ε_0 + η_H`（`η_H` 为迟滞/摩擦建模误差）。因此**柔度越大（K_r 越小）力矩分辨越好，但扭转带宽越低**；在准静态接触（≪ 扭转共振）下，降低 `K_r` 是纯收益，故行星 QDD（若属实）对力分辨更有利，谐波则需更精细的迟滞建模。∎

**引理 L9（VoI 探针恰好作用于模糊带）** 二值接触状态、先验 `p = P(¬grasp)`，动作 {推进, 重抓}；推进在未抓住时代价 `c_FN`，重抓在已抓住时代价 `c_FP`。被动最优期望代价 `= min(p·c_FN, (1−p)·c_FP)`；完美探针后期望代价为 0，故 `VoI(p) = min(p·c_FN, (1−p)·c_FP)`，在 `p* = c_FP/(c_FN + c_FP)` 取最大值 `c_FN·c_FP/(c_FN+c_FP)`。含探针成本 `C_p` 时，探针区间为满足 `VoI(p) > C_p` 的一段区间，**必在模糊带**。当 `c_FN ≫ c_FP`（漏判灾难性）时，探针区间显著向"低失败先验"扩展——这正是第 1 轮保守策略不敢做、而可逆探针可以做的事。∎

**引理 L10（导纳稳定的工程充分条件）** 对被动力环境（刚度 `K_e`）与一阶导纳（阻尼 `b`）、环路总延迟 `T`，由无源性可得充分条件 `b ≥ K_e·T/2`（须留 2–3× 余量，实际以能量监测为准）。因此接触相位必须同时满足：短 chunk（降 `T`）与足够大的 `b`（虚拟阻尼），二者缺一都会振荡。∎

**引理 L11（信念误差 → 路由 regret 上界）** 对有限时域 `H`、奖励上界 `R_max`，任意策略 `π` 在信念 `b` 与真实 `b*` 下的价值差满足 `|V^π(b) − V^π(b*)| ≤ 2 R_max·H·E[TV(b, b*)]`。故提升接触信念（降低 `TV`）会**直接降低**相对 oracle 路由的 regret；这把第 1 轮 L2/L5 的"路由上界"与第 1 轮风险"抓握误判"接上了同一根杠杆。∎

**引理 L12（chunk 长度 = 力环带宽）** 接触环频率 `f_loop = 1/(T_a·Δt + T_infer)`。对一阶接触动力学（带宽 `f_contact`），工程稳定/性能要求 `f_loop ≥ β f_contact`（`β≈5–10`），故 `T_a ≤ (1/(β f_contact) − T_infer)/Δt`。取 `Δt = 1/30 s`、`T_infer = 50 ms`、`f_contact = 2 Hz`、`β = 5` ⇒ `T_a ≤ 1.5`，即插入相位必须 `T_a ∈ {1,2}`。**这解释了为什么第 1 轮的"自适应 chunk"从可选优化变成力控前提。** ∎

**引理 L13（共形假阳率保证）** 在校准集与测试样本可交换、非一致性分数同分布下，分裂共形阈值 `τ_α` 满足 `P(s_test > τ_α) ≤ α`（有限样本修正 `⌈(n+1)(1−α)⌉/n`）。因此"未抓住"判定的假阳率有分布无关上界；但 OOD 破坏可交换性，故须分层 + 加权重校准（只调阈值，不动模型）。∎

**引理 L14（指纹迁移误差界）** 若观测器 `Φ` 对指纹参数 `ψ` 满足 Lipschitz 常数 `L_Φ`，且 `|ψ − ψ̂| ≤ ε`，则 `|ŵ − w| ≤ L_Φ·ε`。在线辨识把 `ε` 从型号先验的跨实例散布降到后验标准差 ⇒ 跨实例力矩误差按比例下降。∎

```python
                "observation.images.cam_left_high", "observation.images.cam_right_high",
                "observation.images.cam_left_wrist", "observation.images.cam_right_wrist"]},
            "action_chunk_size": 8,
            "token": os.environ["UNIBOT_SUBMISSION_TOKEN"],
        }

    def reset(self, port=None):
        self.sessions[port] = Session()

    def get_action(self, obs, port=None):
        s = self.sessions[port]; t0 = time.perf_counter()
        # --- 感知环 ---
        tau   = self.propio.estimate(obs, s)          # U14
        w_hat = self.propio.wrench(tau, obs)          # U15
        # --- 信念环 ---
        b     = self.belief.update(obs, w_hat)        # U16/U22，滑移检测
        # --- 实验环：三区决策 ---
        plan  = self.probe.decide(b, obs, s)          # U18/U23
        if plan.kind == "probe":                      # 模糊带：先做最便宜的判别实验
            a = self.probe.render(plan.u, obs)        # 如抬升 3 mm
            self.trace.log(b, plan, w_hat, s); return self.pack(a, obs)
        if plan.kind == "regrasp":                    # 确信未抓住
            a = self.model.act(obs, skill="regrasp"); self.trace.log(b, plan, w_hat, s); return self.pack(a, obs)
        # --- 柔顺环：任务动作 + 导纳 + 短 chunk ---
        phi   = self.belief.phase(b)
        T_a   = self.chunk_len(phi)                   # U20/L12
        a_nom = self.model.act(obs, phase=phi, c=self.propio.fingerprint(obs), T_a=T_a)
        a     = self.adm.shape(a_nom, w_hat, phi)     # U19
        a     = self.stitch_and_clamp(a, s, t0)       # 复用第 1 轮 IP-03/U12
        self.trace.log(b, plan, w_hat, s)
        return self.pack(a, obs)
```

```python
# ===== IP-09：减速器观测器 + 在线辨识 =====
class ReducerObserver:
    def calibrate_free_space(self, log):
        # 自由空间：τ_ext=0 ⇒ 用逆动力学残差辨识 e0、K_r、摩擦
        for seg in log.free_space_segments():
            self.model.fit(seg)                 # 模型选择：行星 / 谐波 / 混合
            self.zero_offset = self.model.residual_at_rest(seg)

    def estimate(self, obs, s):
        if "estimated_torque" in obs:           # 通道①：直接用
            return obs["estimated_torque"] - self.zero_offset
        if "motor_pos" in obs:                  # 通道②：双编码器
            e = obs["motor_pos"] / self.N - obs["joint_pos"] - self.model.e0(obs["motor_pos"])
            return self.model.torque_from_deflection(e, obs["joint_vel"])
        r = obs["q_cmd_prev"] - obs["joint_pos"]  # 通道③：跟踪残差
        return self.model.torque_from_residual(r, obs["joint_vel"], s.history)

    def wrench(self, tau, obs):
        J = self.kin.jacobian(obs)              # 7×6（或 6×6）
        return np.linalg.pinv(J.T) @ tau        # 六维腕力
```

```python
# ===== IP-10/11：共形抓握 + VoI 三区决策 =====
class ConformalGrasp:
    def __init__(self, calib): self.thr = conformal_quantile(calib, alpha=0.02)
    def update(self, obs, w):
        feat = fuse(w, obs["gripper"], obs["wrist_img"])
        s_not = self.score_not_grasped(feat)     # 越大越像"未抓住"
        b = {"not_grasped": 1/(1+np.exp(-(s_not-self.thr))) }
        b["slip"] = self.slip_detector(w.history)
        return b

class VoIScheduler:
    def decide(self, b, obs, s):
        # 三区：确信抓住 / 确信未抓住 / 模糊带
        if b["not_grasped"] > self.p_hi: return Plan("regrasp")
        if b["not_grasped"] < self.p_lo: return Plan("task")
        best = max(self.probes, key=lambda u: self.voi(u, b) - self.cost(u))
        if self.voi(best, b) > self.cost(best) and s.probe_budget > 0:
            return Plan("probe", best)
        return Plan("regrasp")                   # 预算耗尽 → 回退保守（第 1 轮行为）
```

```python
# ===== IP-12：虚拟导纳（位置接口）=====
class AdmittanceShaper:
    def shape(self, a_nom, w_hat, phi):
        K = self.stiffness(phi)                  # 横向软 / 轴向硬 / 旋转软
        b = self.damping(phi)                    # 满足 L10：b ≥ K_e·T/2 × 余量
        dx = np.linalg.solve(K, self.w_des - w_hat)
        dq = self.J_pinv(a_nom) @ dx
        a = a_nom + dq
        if self.oscillation_detected(w_hat.history):  # 能量监测
            return a_nom                         # 立即回退纯位置
        return a
```
