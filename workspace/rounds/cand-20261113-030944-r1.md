# 第 64 轮（承接第 63 轮「LIRO 几何-技能-干扰闭环」IP-193~203；灵感循环 III 第 1 轮；本轮灵感：「机器人」×「机器人竞赛」）

> 第 63 轮把 ROSE 升级为 LIRO，用 LiDAR 几何先验压缩 WCV 球、用技能库降低遗憾、用干扰不变表征兜底。但第 63 轮自述的最大风险是一句直指要害的话：**若 E_geo 在分布外几何上产生系统性幻觉，几何先验会从「压缩不确定性」反变为「注入确定性错误」**。根因不在几何编码器本身，而在**制度设计**：
> 1. **自证循环**：ρ_rob、ρ_dir、geo_hash 全部由产生幻觉的同一套系统内部产生；J_liro 是「自己给自己发证书」，没有独立第三方核验。产生幻觉的编码器无法可靠地发现自己的幻觉。
> 2. **被动世界假设**：SSB 只对「已经发生的险情」记账，从不主动生成「最可能骗过 E_geo 的场地」；A77（几何先验良性）是一个**从未被对手压力测试过的经验假设**。
> 3. **渐近目标错配**：OGD 的 √T 遗憾界假设长期在线；而真实部署更像比赛——**有限回合、未知场地、单次机会、按规则计分**，需要的是有限预算内的得分下界，而不是 T→∞ 的渐近最优。
>
> 「机器人竞赛」恰好提供了这三个缺失的**制度**：**裁判**（独立审计，不信任自证）、**对手联盟**（主动研究并攻击你的弱点）、**规则手册与计分**（把安全/任务/时间显式化，有限预算内博弈）。因此本轮不再叠加先验，而是给系统装上**怀疑机制、对手和记分板**。

## 0. 直觉与动机

**灵感 1（机器人竞赛 → 裁判：独立审计，而非自证）**
直觉：赛场上没有队伍给自己发奖牌；裁判用**独立传感器与规则手册**核验，且裁判的失效模式必须与选手不同。第 63 轮所有证书都由内部组件生成，几何幻觉会同时污染「被认证对象」和「认证者」。**关键洞见**：引入**独立观测通道 O_indep**（外部相机、力台、场地动捕，与策略传感器不相交）与**独立几何一致性见证**，由裁判审计 J_liro 的**结论**而非采信其内部哈希。裁判的价值不是更高精度，而是**不同失效模式**：LiDAR 法向翻转在外部多视角重投影、触觉力方向、穿透一致性上会留下与内部表征不一致的痕迹。

**灵感 2（机器人竞赛 → 对手联盟：主动寻找自己的失败）**
直觉：对手会研究你的录像，专门设计让你翻车的场地。SSB 是「防守型」的场景银行，从不主动构造镜面、透明、强吸光、法向翻转这类**几何幻觉陷阱**。**关键洞见**：把场景银行升级为**对抗联盟 ALB**：生成器 g 在物理可行集 𝒫_phys 内以最大化 solver 失败为目标，演化出专门诱发 E_geo 幻觉的场地；solver 与联盟用 **PFSP + Elo** 共同进化。这把 A77「几何先验良性」从**假设**变成**可被证伪、并需持续防守的经验命题**——联盟找不到反例，才允许把 A77 作为工作假设。

**灵感 3（机器人竞赛 → 战术手册 + 有限预算计分）**
直觉：比赛不是「跑得越久越好」，而是**B 次机会内按规则拿分**；有时保守拿稳分优于激进搏高分。ROSE/LIRO 的 √T 遗憾在 B 有限时没有指导意义。**关键洞见**：把策略从「组件模式调度」提升为**战术手册 Playbook**：每个战术 =（技能序列 τ，应急分支树 Ψ_cont，中止条件），由预算化 EXP3 在 B 次内选择；目标改写为 **max E[Score] − λ·CVaR[违规]**，并给出有限样本 PAC 下界。竞赛还意味着**规则合规是硬约束**：Shield 从「技能前置条件投影」扩展为「规则手册（MTL）合规投影」。

**灵感 4（三灵感合流 → ARENA：Adversarial Referee-Enforced league Arena）**
三者咬合为闭环：**联盟主动证伪**（ALB/PFSP 生成幻觉场地并攻击 solver）→ **裁判独立证伪**（IRE/GCV 用 O_indep 审计 J_liro）→ **若证伪则降级**（RDG：关闭 GeoInit、膨胀半径、切保守战术）→ **联盟获得奖励**（找到弱点，Elo 上升）→ **手册更新应急分支**（PB/PMB）→ **有限预算得分保证**（BSG）。**第 63 轮是「给系统更强的先验」，第 64 轮是「给系统更强的怀疑机制与对手」**：先验让球变小，裁判与联盟保证球不会被幻觉缩小到错误的位置。

**灵感 5（LIRO 组件的原位升级）**
- **SSB → ALB**：被动记账变主动联盟；Mine 记录险情，Exploit 生成对抗几何，Elo 排序，PFSP 采样。
- **AIC → REF-AIC**：认证从「内部采样单签」变为「内部采样 + 裁判独立见证双签」。
- **J_liro → J_arena**：证书增加 rulebook_ver、ref_sig、witness_hash、league_ver、elo_snapshot、play_hash、geo_trust。
- **OCB-Skill → PMB**：臂从「组件模式」升为「战术 play」，奖励含规则违规惩罚与切换成本。
- **Shield-Skill → Rule-Shield**：投影目标从 pre_σ 扩展到 rulebook 的 MTL 合规域。
- **WCV-Geo → WCV-Geo+**：当裁判给出几何质疑时，半径按见证残差**膨胀**，而不是按 γ_geo **收缩**——先验只能在其被独立验证时才被信任。

## 1. 形式化定义（增量：定义 201–216）

- **定义 201（ARENA 闭环）**：ARENA = (LIRO, ℛ, IRE, GCV, ALB, PFSP, PB, PMB, BSG, RDG, J_arena)。定位：LIRO 的**制度层升级**——不改动感知/控制算法本身，而是在其外层加装「规则—裁判—联盟—手册—计分」五件套，使第 63 轮的先验在被独立验证前不具备「收缩安全球」的权限。
- **定义 202（规则手册 ℛ）**：ℛ = (Φ_rule, S, δ_ref)。Φ_rule 为一组度量时序逻辑（MTL）公式，作用于执行轨迹 σ=(s_0,…,s_T)，原子命题含 collision、force≤F_max、workspace、contact、time_limit 等，如 □(¬collision)、□(‖f‖≤F_max)、◇_{[0,T_max]}(goal)。得分 S(σ) = w_s·𝟙[Φ_task] + w_t·(1−T_used/T_max) − w_v·|Viol(σ,Φ_rule)| − w_e·E_used。δ_ref 为裁判审计容差。
- **定义 203（独立裁判引擎 IRE）**：IRE 持有**与策略传感器不相交**的独立观测通道 O_indep（外部 RGB-D、力台、场地动捕），并实现审计函数 Audit(J, O_indep) → {accept, reject, escalate}：accept ⇔ r_geo(O_indep, J) ≤ δ_geo^ref ∧ r_rule(σ_exec, Φ_rule) ≤ δ_rule^ref ∧ sig_ref 有效。裁判离线冻结、独立版本化，策略侧**无写权限**；关键 reject 触发 RDG。
- **定义 204（几何一致性见证 GCV）**：见证残差 r_geo = α_1·E_reproj + α_2·E_temporal + α_3·E_tactile + α_4·E_penetration。E_reproj：把系统声称的接触面/法向在外部多视角重投影的误差；E_temporal：相邻帧法向与拓扑的时序一致性；E_tactile：‖n_cloud − n_force‖ 与摩擦锥一致性；E_penetration：声称曲面相对外部观测的有符号穿透量。GCV 不重建几何，只检验「系统声称的几何」与「独立证据」是否矛盾。
- **定义 205（幻觉集与检测域）**：幻觉集 ℋ_δ = {O: ‖n_cloud−n_true‖ ≥ δ_n ∨ |κ_cloud−κ_true| ≥ δ_κ ∨ 拓扑错误(χ 不符)}；检测域 D = {r_geo ≥ τ_geo}。裁判在 D 上拒绝，在 D^c 上保留第 63 轮先验权限。
- **定义 206（对抗联盟 ALB）**：L = (G, Π, Elo, μ)。G={g_θ} 为参数化场地生成器（几何、材质、传感攻击），受**物理可行约束** g∈𝒫_phys（网格流形、质量>0、与真实分布 Chamfer≤ε_phys）；Π 为 solver 种群；Elo 为双方评分；μ 为 PFSP 采样分布。每轮 payoff u(π,g)=S(σ)−λ_v·Viol。
- **定义 207（Exploiter 目标）**：g* = argmax_{g∈𝒫_phys} E_{π∼Π_sel}[𝟙(u(π,g) < u_ref)] − β·d_phys(g, 𝒟_real)，即**在物理合理范围内最大化 solver 失败率**；不是随机增广，而是有目标的对抗搜索。
- **定义 208（PFSP-Elo 调度器）**：Elo 更新 R ← R + K(R̂−E[R])；主 agent 训练时按 p(g) ∝ (1−p_win(g))^α 优先采样「难场地」，exploiter 训练时按 p(g) ∝ p_win(g)^α 优先采样「主 agent 擅长的场地」以寻找其边界；保留 ε 均匀探索防止模式坍塌。
- **定义 209（战术手册 PB）**：PB={play_j}，play=(τ, Ψ_cont, abort)。τ 为 CSP 技能序列；Ψ_cont 为应急树（裁判 reject / 见证残差超阈 / 接触异常 → 修复技能序列）；abort 为中止条件（预算耗尽/违规风险超限）。
- **定义 210（战术元老虎机 PMB）**：在 |PB| 个战术上运行 EXP3，预算 B；奖励 r_t = clip(S_t,0,1) − κ_sw·𝟙[play 切换]；硬约束：不得选择经 REF-AIC 认证违规概率 > α 的战术。
- **定义 211（预算化竞赛目标 BSG）**：max_{π} 𝔼_{a∼𝒟}[S] s.t. P(Viol) ≤ α，在 B 次回合内估计；同时最小化 CVaR_ε[−S]。BSG 输出「B 次内达到的得分下界」而非 T→∞ 遗憾。
- **定义 212（联盟鲁棒得分缺口）**：Gap_league = max_π min_{g∈G} u(π,g) − u(π*, g_ε^*)，其中 g_ε^* 为 ε-exploiter；衡量联盟覆盖不足导致的「虚假鲁棒」。
- **定义 213（规则裕度 ρ_rule）**：ρ_rule(τ,σ)=min_k dist(σ, ∂Φ_rule,k)（到第 k 条规则不安全边界的距离）；Rule-Shield 在 ρ_rule ≤ 0 时拒绝提案，在 0 < ρ_rule < δ 时投影到合规域。
- **定义 214（裁判触发降级 RDG）**：Audit=reject 时执行：① 关闭 GeoInit，φ̂_0 ← φ̂_MEL；② 半径膨胀 r ← r_bias·(1+ζ·[r_geo−τ_geo]_+)；③ 放大违规惩罚；④ 切换 conservative play；⑤ 置 geo_trust=False。不变式：**RDG 后的行为不劣于第 62 轮 ROSE**（保守回退是安全下界）。
- **定义 215（J_arena 扩展证书）**：J_arena = (J_liro, rulebook_ver, ref_sig, witness_hash, league_ver, elo_snapshot, play_hash, geo_trust)。Valid ⇔ Valid(J_liro) ∧ ref_accept ∧ Φ_rule 满足 ∧ league_fresh ∧ sig_ref 有效 ∧ geo_trust 与实际审计结论一致。
- **定义 216（ARENA 闭环算子）**：语义流新增 [联盟采样 → exploiter 优化 → solver 执行 → IRE/GCV 审计 → Elo/PFSP 重排 → PB 应急更新 → REF-AIC 重认证 → BSG 记账]；实时流新增 [非阻塞裁判监控（10Hz）→ 触发 RDG 切换]。**学习/生成/审计在低频，实时流只做监控与切换**。

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 5（裁判检测下界）**：若幻觉幅度 δ_h 使见证残差满足 r_geo ≥ κ_h·δ_h，噪声残差次高斯（参数 σ），阈值 τ_geo=η_max+κ_h·δ_h/2，则检测概率 ≥ 1−2exp(−(κ_h δ_h/2)²/(2σ²))；即**幻觉不可能在独立证据下完全隐形**，除非幻觉同时骗过所有独立通道。
- **引理 6（带审计的安全球不劣于 ROSE）**：审计 accept 时先验获准收缩先验球；reject 时 RDG 令 r ≥ r_bias 并关闭 GeoInit。故 r_∞ ≤ r_∞^{LIRO}（accept）且 r_∞ ≥ r_bias（reject），**ARENA 在安全半径上弱支配 LIRO/ROSE**——先验只被允许「有条件地」压缩不确定性。
- **定理 4（联盟鲁棒性）**：若联盟含 ε-exploiter 且 𝒫_phys 覆盖真实场地支撑，PFSP 覆盖难例，则 co-evolved π* 在 𝒫_phys 上最坏得分的估计误差 ≤ Gap_league + O(√(log|G|/T))；**联盟找不到反例 ⇒ 有理由把 A77 降级为「经检验的工作假设」**，而不是公理。
- **定理 5（有限预算得分下界）**：K 个战术、B 回合，EXP3 期望遗憾 ≤ 2√(BK log K)；同时由 Hoeffding，|Ŝ−𝔼S| ≤ √(log(2/δ)/(2B))。故给定 δ、ε，取 B ≥ 2log(2/δ)/ε² 即可以 1−δ 置信度给出得分下界——**这是比赛式部署真正需要的保证**。
- **命题（裁判开销与 Goodhart 缺口）**：GCV 每 10Hz 审计 <5ms，非阻塞；但若策略优化目标逐渐贴合裁判见证而非真实任务，存在**代理-真实得分差**（Goodhart gap），其大小由裁判与真实规则的 Lipschitz 差与策略对见证的可达敏感度决定——这是本方案的核心结构性风险。

## 2. 形式化定义（完整版）

**定义 201（ARENA 闭环）** ARENA 是 LIRO 的**制度层升级**：不改动 LSF/USL/DIR/OLP/WCV 的算法内核，而在其外层挂载规则手册 RB、独立裁判 IRE/GCV、对抗联盟 ALB/PFSP、战术手册 PB/PMB、有限预算计分 BSG 与裁判触发降级 RDG，并把证书升级为 J_arena。不变式：**先验（几何、技能、干扰模型）只有在通过独立审计后才获得「收缩安全球 / 激进参数 / 认证通过」的权限**；学习、生成、审计都发生在语义流，实时流只做非阻塞监控与降级切换。

**定义 202（规则手册 ℛ）** ℛ=(Φ_rule, S, δ_ref)。Φ_rule 为 MTL 公式集，定义在轨迹 σ=(s_0,…,s_T) 上，原子命题包括 collision、force≤F_max、workspace、contact、time_limit、human_zone 等。得分 S(σ)=w_s·𝟙[Φ_task 满足]+w_t·(1−T_used/T_max)−w_v·|Viol(σ,Φ_rule)|−w_e·E_used。规则集版本化（rulebook_ver），任何改动需重跑联盟与裁判校准。计分函数是**唯一的优化目标**，但不得与安全规则冲突（Φ_rule 为硬约束，S 只在合规域内可比）。

**定义 203（独立裁判引擎 IRE）** IRE 持有独立观测通道 O_indep，与策略使用的 (V,T,P,P_cloud) **不相交**（不同物理传感器、不同安装位姿、不同失效模式）。Audit(J,O_indep) 分三支：
- accept：r_geo ≤ δ_geo^ref ∧ r_rule ≤ δ_rule^ref ∧ sig_ref 有效；
- reject：任一残差超阈或规则被硬违反；
- escalate：残差处于灰区，或独立通道自身退化（自检失败）→ 转人工/保守兜底。
裁判冻结、独立版本化、只读；策略侧无法写入，裁判代码与策略代码由不同团队维护（制度性隔离）。审计在语义流 10Hz 执行，实时流仅接收其 verdict 进行无阻塞切换。

**定义 204（几何一致性见证 GCV）** GCV 不重建几何，只检验「系统声称的几何」与「独立证据」的矛盾：
- E_reproj：把 J 中声称的接触面/法向在主视角之外的重投影误差；
- E_temporal：相邻帧法向、曲率、拓扑（欧拉特征 χ）的时序一致性；
- E_tactile：‖n_cloud − n_force‖ 及摩擦锥一致性（法向翻转会与接触力方向矛盾）；
- E_penetration：声称曲面相对外部观测的有符号穿透量。
r_geo 为四项加权和；权重 α 由离线校准确定（使干净样本残差集中在 τ_geo 以下）。

**定义 205（幻觉集与检测域）** ℋ_δ={O: ‖n_cloud−n_true‖≥δ_n ∨ |κ_cloud−κ_true|≥δ_κ ∨ χ_cloud≠χ_true}。检测域 𝒟={r_geo≥τ_geo}。裁判在 𝒟 上 reject；在 𝒟^c 上保留第 63 轮先验权限（GeoInit 收缩、WCV-Geo 剪枝、ρ_dir 认证）。**幻觉不是「一定检测到」，而是「要么被检测，要么其幅度被噪声上界限制」**（引理 5）。

**定义 206（对抗联盟 ALB）** L=(G,Π,Elo,μ)。G={g_θ} 是参数化场地生成器：几何（拓扑、法向、曲率、镜面/透明/吸光材质）、传感攻击（遮挡、欺骗点云、多径）、任务布置。约束 g∈𝒫_phys：网格为流形、质量/惯量正定、与真实分布 Chamfer≤ε_phys、接触力学可仿真。每轮 payoff u(π,g)=S(σ)−λ_v·Viol(σ,Φ_rule)。Elo 记录 (π,g) 相对实力；μ 为 PFSP 采样分布。联盟保留历史强 exploiter（防止遗忘）。

**定义 207（Exploiter 目标）** g* = argmax_{g∈𝒫_phys} 𝔼_{π∼Π_sel}[𝟙(u(π,g)<u_ref)] − β·d_phys(g,𝒟_real)。目标不是随机域随机化，而是**有方向地寻找当前 solver 的失败边界**；β 项防止生成物理上不可能、只对网络有效的对抗样本（避免「假对手」）。

**定义 208（PFSP-Elo 调度器）** Elo：R←R+K(R̂−𝔼[R])，𝔼[R]=1/(1+10^{(R_b−R_a)/400})。主 agent 训练按 p(g)∝(1−p_win(g))^α 采样（优先难场地）；exploiter 训练按 p(g)∝p_win(g)^α 采样（优先主 agent 擅长的场地，逼近其能力边界）；始终保留 ε/K 均匀探索。模式坍塌检测：若场地嵌入的有效多样性（k-means 轮廓或熵）低于阈值，强制注入均匀样本。

**定义 209（战术手册 PB）** PB={play_j}，play=(τ, Ψ_cont, abort)。τ 为 CSP 规划出的技能序列；Ψ_cont 是应急树：节点为触发事件（裁判 reject、r_geo 超阈、接触力异常、ρ_rule 过低、预算告急），边为修复技能序列（如退避→重新感知→换抓取→保守移交）；abort 为中止条件。战术库离线构建 + 在线从联盟失败案例中挖掘新应急分支（lineage 记录）。

**定义 210（战术元老虎机 PMB）** 在 |PB| 个战术上运行 EXP3，预算 B；奖励 r_t=clip(S_t,0,1)−κ_sw·𝟙[play 切换]；硬约束：不得选择 REF-AIC 认证违规概率 >α 的战术（合规下界）；硬降级规则继承第 62/63 轮。重要性加权更新 w_a←w_a·exp(η r̂_t)。

**定义 211（预算化竞赛目标 BSG）** 给定 B 回合，目标 max_π 𝔼_{a∼𝒟}[S] s.t. P(Viol)≤α，并最小化 CVaR_ε[−S]（尾部风险）。输出**得分下界** L_B(π)=Ŝ−√(log(2/δ)/(2B))，以及违规概率上界。与 OGD 的 √T 遗憾不同，BSG 回答的是「B 次机会内至少能拿多少分、最多违规多少次」。

**定义 212（联盟鲁棒得分缺口）** Gap_league = max_π min_{g∈G} u(π,g) − u(π*,g_ε^*)，其中 g_ε^* 为联盟中的 ε-exploiter。它度量「联盟覆盖不足导致的虚假鲁棒」：Gap 越大，说明还有未被联盟发现的失败模式。

**定义 213（规则裕度 ρ_rule）** ρ_rule(τ,σ)=min_k dist(σ, ∂Φ_rule,k)，即执行轨迹到最近规则不安全边界的距离。Rule-Shield：ρ_rule≤0 拒绝提案；0<ρ_rule<δ 时做合规投影（把 MTL 约束松弛为时变线性/二次约束的小规模 QP）；投影距离过大则降级 ask_clarify。

**定义 214（裁判触发降级 RDG）** Audit=reject 时执行：① 关闭 GeoInit，φ̂_0←φ̂_MEL；② 半径膨胀 r←r_bias·(1+ζ·[r_geo−τ_geo]_+)；③ 放大违规惩罚 w_v；④ 切换 conservative play（保守战术）；⑤ 置 geo_trust=False 写入证书。**不变式**：RDG 之后系统退化为第 62 轮 ROSE 的安全下界（几何先验被完全弃用），因此「先验幻觉」不会造成比 ROSE 更差的安全性。

**定义 215（J_arena 扩展证书）** J_arena=(J_liro, rulebook_ver, ref_sig, witness_hash, league_ver, elo_snapshot, play_hash, geo_trust)。Valid(J_arena) ⇔ Valid(J_liro) ∧ ref_accept ∧ Φ_rule 满足（ρ_rule>0）∧ league_fresh（league_ver≥curr−2）∧ sig_ref 有效 ∧ geo_trust 与最近一次审计结论一致。审计链：witness_hash 追溯独立证据，elo_snapshot 追溯联盟状态，play_hash 追溯实际战术。

**定义 216（ARENA 闭环算子）** 语义流：[联盟 PFSP 采样场地 → exploiter 优化 → solver 执行 → IRE/GCV 审计 → RDG 或信任先验 → Elo 更新 → PB 应急分支挖掘 → REF-AIC 重认证 → BSG 记账]；实时流：[锚点读 → LIRO 实时路径 → 非阻塞裁判监控(10Hz) → 若 verdict=reject 则 RDG 切换]。**学习/生成/审计低频，实时只监控与切换，零学习写操作（A75/A82 继承）。**

class Rulebook:
    """MTL 规则集 + 显式计分。规则是硬约束，得分只在合规域内可比。"""
    def __init__(self, formulas, weights, delta_ref):
        self.formulas = formulas          # ['G(!collision)', 'G(force <= Fmax)', 'F[0,Tmax](goal)', ...]
        self.w = weights                  # {'success': 1.0, 'time': 0.2, 'viol': 5.0, 'energy': 0.05}
        self.delta_ref = delta_ref
        self.version = hash(tuple(formulas))

    def score(self, sigma, metrics):
        viol = sum(1 for f in self.formulas if mtl_violated(f, sigma))
        return (self.w['success'] * metrics.task_success
                + self.w['time'] * (1 - metrics.t_used / metrics.t_max)
                - self.w['viol'] * viol
                - self.w['energy'] * metrics.energy_used)

    def rule_margin(self, sigma):
        return min(mtl_distance(f, sigma) for f in self.formulas)


class IndependentRefereeEngine:
    """独立观测通道审计，策略无写权限。"""
    def __init__(self, rulebook, delta_geo_ref=0.05, delta_rule_ref=0.02):
        self.R = rulebook
        self.d_geo, self.d_rule = delta_geo_ref, delta_rule_ref
        self.version = 'ref-v1.0-frozen'

    def audit(self, J, O_indep):
        if not self._self_check(O_indep):          # 独立通道自身退化
            return 'escalate', None
        r_geo = GCV.residual(J.geo_claims, O_indep)
        r_rule = self.R.rule_margin(J.exec_trace)
        if r_geo > self.d_geo or r_rule < self.d_rule:
            return 'reject', r_geo
        if r_geo > 0.5 * self.d_geo or r_rule < 1.5 * self.d_rule:
            return 'escalate', r_geo
        return 'accept', r_geo


class GCV:
    """几何一致性见证：只检验声称几何与独立证据是否矛盾。"""
    @staticmethod
    def residual(geo_claims, O_indep, alpha=(0.35, 0.2, 0.3, 0.15)):
        E_reproj = multi_view_reprojection_error(geo_claims.surface, O_indep.views)
        E_temporal = normal_topology_drift(geo_claims.history)
        E_tactile = (np.linalg.norm(geo_claims.normal - O_indep.force_normal)
                     + friction_cone_inconsistency(geo_claims, O_indep.force))
        E_penetration = signed_penetration(geo_claims.surface, O_indep.depth)
        return (alpha[0] * E_reproj + alpha[1] * E_temporal
                + alpha[2] * E_tactile + alpha[3] * E_penetration)

### IP-207/208 对抗联盟 + PFSP-Elo

```python
class AdversarialLeagueBank:
    """场景银行 → 主动联盟。exploiter 在物理可行域内找 solver 的失败边界。"""
    def __init__(self, phys_filter=PhysicallyPlausible(eps_chamfer=0.3), alpha=1.0):
        self.G, self.Pi, self.elo = [], [], Elo()
        self.phys = phys_filter
        self.alpha = alpha
        self.history = deque(maxlen=256)

    def exploit(self, solver_pop, u_ref, n_iter=64, beta=0.5):
        best, best_obj = None, -float('inf')
        for g in self._init_candidates():
            if not self.phys.admit(g):
                continue
            fail = np.mean([1.0 if self._payoff(pi, g) < u_ref else 0.0
                            for pi in solver_pop])
            obj = fail - beta * self.phys.distance_to_real(g)
            if obj > best_obj:
                best, best_obj = g, obj
        for _ in range(n_iter):
            g_c = self.phys.project(self._mutate(best))
            fail = np.mean([1.0 if self._payoff(pi, g_c) < u_ref else 0.0
                            for pi in solver_pop])
            obj = fail - beta * self.phys.distance_to_real(g_c)
            if obj > best_obj:
                best, best_obj = g_c, obj
        self.G.append(best)
        return best

    def _payoff(self, pi, g):
        sigma = rollout(pi, g)
        return self.R.score(sigma, g.metrics) - self.lambda_v * violations(sigma, self.R)

    def pfsb_sample(self, for_exploiter=False):
        p = np.array([self._win_rate(g) for g in self.G])
        if for_exploiter:
            p = p ** self.alpha            # 优先主 agent 擅长的场地（逼近能力边界）
        else:
            p = (1 - p) ** self.alpha      # 主 agent 优先难场地
        p = (1 - self.eps) * p / p.sum() + self.eps / len(self.G)
        return self.G[np.random.choice(len(self.G), p=p)]

    def elo_update(self, pi, g, u):
        self.elo.update(pi.id, g.id, outcome=u)
```

class Playbook:
    def __init__(self, plays: List[Play]):
        self.plays = plays
        self.index = {p.hash: p for p in plays}

    def repair(self, failed_play, failure_event):
        """从联盟失败案例中挖掘应急分支，而非重写战术。"""
        branch = synthesize_repair(failed_play, failure_event)
        new = failed_play.with_contingency(branch)
        self.plays.append(new)
        return new


class PlaybookMetaBandit:
    """EXP3 over plays，预算化，合规硬约束。"""
    def __init__(self, playbook, K=None, eta=0.3, alpha=0.05):
        self.PB = playbook
        self.K = K or len(playbook.plays)
        self.w = np.ones(self.K) / self.K
        self.eta, self.alpha = eta, alpha
        self.certified_viol = {p.hash: estimate_violation_prob(p) for p in playbook.plays}

    def choose(self, budget_left):
        legal = [i for i, p in enumerate(self.PB.plays)
                 if self.certified_viol[p.hash] <= self.alpha]
        if not legal:
            return self.PB.plays[0]           # conservative 兜底
        p = np.array([self.w[i] for i in legal]); p /= p.sum()
        return self.PB.plays[legal[np.random.choice(len(legal), p=p)]]

    def update(self, play, score):
        i = self.PB.plays.index(play)
        r_hat = clip(score, 0, 1) / max(self.w[i], 1e-6) / self.K
        self.w[i] *= np.exp(self.eta * r_hat / self.K)
        self.w /= self.w.sum()
```

    play = M.pmb.choose(budget_left)
    tau, theta_bind = M.csp.plan(goal, x_prime, phi_hat, M.rsc.r)
    tau, theta_bind = merge_with_play(tau, theta_bind, play)
    theta_bind[0] = rule_shield(tau[0], theta_bind[0], M.R, phi_hat, M.rsc.r)

    K_safe, EV_exec, cert_exec = realtime_step_liro(
        M, delta_f_req, tau, theta_bind, x_prime)

    # ———— 独立裁判审计 ————
    verdict, r_geo = M.ire.audit(build_j_liro_candidate(M, cert_exec), M.O_indep)
    if verdict == 'reject':
        phi_hat, r_safe, geo_trust = rdg_degrade(
            phi_hat, M.r_bias, r_geo, M.tau_geo)
        K_safe, EV_exec, cert_exec = conservative_replan(
            M, phi_hat, r_safe, delta_f_req)
    else:
        geo_trust = True

    # ———— 联盟与手册记账 ————
    u = M.R.score(EV_exec.trace, EV_exec.metrics) - M.lambda_v * EV_exec.violations
    M.alb.elo_update(M.pi, g, u)
    M.pmb.update(play, u)
    if verdict == 'reject':
        M.pb.repair(play, failure_event=EV_exec.event)

    # ———— 认证与返回 ————
    rho_rule = M.R.rule_margin(EV_exec.trace)
    J_arena = build_j_arena(
        cert_exec, build_j_liro(cert_exec, M.rho, M.rsc.r, M.hedge.Ghat, M.arm,
                                M.shield_hash, M.adapter_ver, M.rho_dir, M.eps_spec,
                                M.geo_hash, M.csp_hash, M.skill_hash),
        M.R, verdict, hash(M.witness), M.alb.version, M.alb.elo.snapshot(),
        play.hash, geo_trust)
    return M, K_safe, EV_exec, J_arena, r_geo, rho_rule


def realtime_step_liro(M, delta_f_req, tau, theta_bind, x_prime):
    # ———— 实时流：完全不新增学习/生成 ————
    anchor, fresh = M.ara.read_latest()
    K_prior = K_BASELINE if anchor is None else robust_prior(M.olp_geo, anchor, fresh)
    first_skill, first_theta = tau[0], theta_bind[0]
    K_seq = first_skill(x_prime, first_theta)
    K_safe, rho_rob, _, geo_conflict = wcv_geo_compile(
        M.olp_geo, x_prime, M.eeis,
        anchor.phi_hat if anchor else None, M.rsc.r, M.lsf.g_cache, M.lsf)
    cert_exec = M.ertc.dispatch(K_seq[0])
    EV_exec = wait_contact_and_build_evidence()
    M.usr.push_evidence(EV_exec)
    M.rho = rho_rob
    # 非阻塞裁判监控：只读 verdict，不参与实时控制
    if M.ire.latest_verdict == 'reject':
        M.pending_degrade = True
    return K_safe, EV_exec, cert_exec
```

## 4. 推导

**引理 5（裁判检测下界）** 设真实几何 θ、系统声称几何 θ̂，幻觉幅度 δ_h=‖θ̂−θ‖。GCV 残差满足 r_geo ≥ κ_h·δ_h（四类见证对几何偏差敏感，κ_h 为最小灵敏度），独立通道噪声使残差附加次高斯项 η∼subG(σ²)，即观测残差 r̃_geo ≥ κ_hδ_h−η。取阈值 τ_geo=κ_hδ_h/2，则漏检概率 P(r̃_geo<τ_geo) ≤ P(η>κ_hδ_h/2) ≤ 2exp(−(κ_hδ_h/2)²/(2σ²))。故 δ_h 越大、通道噪声越小，漏检概率指数下降；**幻觉无法在独立证据下完全隐形，除非它同时骗过所有独立通道（此时是「共盲」，见风险）**。∎

**引理 6（带审计的安全球不劣于 ROSE）** 分两支：
- accept：先验获准，r_∞ ≤ r_∞^{LIRO}（引理 3 继承）；
- reject：RDG 关闭 GeoInit（φ̂_0=φ̂_MEL）并令 r≥r_bias，系统回到 ROSE 的安全下界。
因此对任意审计结果，ARENA 的安全半径满足 r_∞^{ARENA} ≤ r_∞^{LIRO}（先验有效时）且 r_∞^{ARENA} ≥ r_bias（先验被拒时）——**先验只被允许「有条件地」压缩不确定性，最坏情况不劣于无先验的 ROSE**。∎

**定理 4（联盟鲁棒性）** 设联盟含 ε-exploiter：对任意 π∈Π，max_{g∈G} 失败率 ≥ max_{g∈𝒫_phys} 失败率 − ε；设 PFSP 覆盖难例且 Elo 估计收敛，则 co-evolved π* 的最坏得分满足
min_{g∈𝒫_phys} u(π*,g) ≥ max_π min_{g∈𝒫_phys} u(π,g) − Gap_league − O(√(log|G|/T))。
即**联盟找不到反例时，A77 可从「公理」降级为「经检验的工作假设」**；Gap_league 给出仍需补测的方向。∎（依赖：𝒫_phys 覆盖真实支撑、exploiter 近最优、Elo 无偏。）

**定理 5（有限预算得分下界）** K 个战术、B 回合，PMB 为 EXP3：期望遗憾 ≤ 2√(BK log K)，故 𝔼[S_best]−𝔼[S_PMB] ≤ 2√(BK log K)。同时 Hoeffding 给出 |Ŝ−𝔼S| ≤ √(log(2/δ)/(2B))。合并得置信度 1−δ 下的得分下界
L_B ≥ Ŝ_PMB − 2√(BK log K)/B − √(log(2/δ)/(2B))。
违规约束由 REF-AIC 认证概率 + 采样上界共同保证。取 B≥2log(2/δ)/ε² 即可以 1−δ 置信度把得分估计误差压到 ε。**这正是比赛式有限回合部署需要的保证**。∎

**命题（裁判开销与 Goodhart 缺口）** GCV+Audit 单次 <5ms，10Hz 运行占用语义流 <5% 算力；实时流只读 verdict，零新增写操作。另一方面，若策略在优化中逐渐对裁判见证函数敏感（而非对真实任务），代理得分与真实得分之差满足
|S_proxy−S_true| ≤ L_S·(r_geo^{proxy}−r_geo^{true})_+ + O(策略对见证的可达敏感度)，
该差即 **Goodhart 缺口**；联盟若与策略共享见证函数，会同时过拟合，缺口被系统性低估——这是本方案的结构性风险。∎

## 7. 已知风险

**一句话**：若策略把「通过裁判」当成目标而非「完成任务」，对抗联盟也会一起过拟合裁判的见证函数与计分公式（Goodhart 定律）——**系统可能演化出「裁判认证通过、真实世界失败」的证书游戏**，此时独立审计反被同化为新的自证闭环；这是本轮所有「裁判—联盟—计分」论证共同依赖的单点假设（A84/A89）。

**次级风险与缓解**：
1. **裁判共盲**：O_indep 与策略传感器仍共享盲区（如透明物体对所有光学传感器隐形）→ 引入**异质通道**（力/声/热/结构光）与「共盲自检」：当所有见证残差同时偏低但任务失败率偏高时，判为「裁判可疑」，强制人类复核并冻结先验。
2. **联盟模式坍塌**：exploiter 收敛到少数「万能陷阱」→ PFSP ε 探索 + 场地嵌入多样性阈值 + 历史强 exploiter 回放。
3. **假对手（不可物理实现）**：对抗样本只骗网络不骗物理 → 𝒫_phys 硬过滤（流形/质量/Chamfer/可仿真），β 惩罚偏离真实分布。
4. **裁判算力/延迟**：10Hz 审计占用语义流 → 见证分级（快见证每帧、慢见证每 N 帧），实时流只读 verdict 不阻塞。
5. **战术爆炸**：应急分支组合爆炸 → 战术哈希去重 + 仅保留经联盟验证有效的分支 + 预算化剪枝。
6. **Elo 陈旧**：solver 快速进化导致对手评分失真 → 滑动窗口 Elo + 新场地冷启动高探索。
7. **计分规格漏洞**：S 可被钻空子（如放弃任务只求不违规）→ 计分单调性约束 + 对抗性规格审查（红队专门找计分漏洞）。
