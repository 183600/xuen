# 第 56 轮（承接第 55 轮语义-接触生存核；灵感循环第 1 轮；本轮灵感：「痛点分析」×「模型蒸馏」）

> 第 55 轮把“感知标签”升级为“接触约束 + 全身生存核”，但整套安全层仍默认跑在算力充足的云端。本轮把问题从“安全层是否 sound”推进到 **“安全层能否被压缩到边端，而压缩过程本身是否 still sound”**。核心矛盾：**H24（痛点稀释）**：标准蒸馏以数据分布的平均散度为目标，而真正决定安全的是低频、高危、不可逆的尾部事件；平均意义下更小的误差会把学生拉向“常见情形正确”，系统性抹掉痛点区域的分歧，出现“跑分更好、尾部更脆”的假进步。**H25（理由不可蒸馏）**：教师的安全不只来自动作 `a_T`，还来自“为什么安全”——生存核裕度 `m_T`、核心接触集 `C_T`、以及何时应弃权 `s_T`；这些是特权信息而非动作标签，纯动作蒸馏会让学生复制安全动作却不承载安全证书，使第 55 轮的保证在蒸馏后失效。

## 0. 直觉与动机

**三句话直觉**
- **痛点分析**不是写需求文档，而是把“平均要拟合什么”换成 **“尾部绝不能错什么”**；
- **模型蒸馏**不是把大模型的输出抄给小模型，而是把教师的 **“动作 + 安全理由 + 自知之明”** 一起搬过去；
- 两者结合 = **用痛点测度分配蒸馏预算，用安全证书决定何时升级**。

**灵感 1（痛点分析 → 重尾测度，而非平均损失）**
直觉：运维者最痛的不是“模型在常见场景偶尔差一点”，而是“十次里有九次很好，第十次直接跌倒”。这类事件在数据里稀疏，在损失里却被平均掉。正确的抽象不是“换一个更鲁棒的 loss”，而是 **把痛点定义成一个加权的测度 `μ_pain`**：严重度、不可逆度、漏报倾向共同决定每个事件的分量。训练时从这个测度采样并加权，评价时在它的支撑上取最坏——这才让“痛点”从形容词变成可优化的对象。

**灵感 2（模型蒸馏 → 蒸馏“安全理由”，而非仅动作）**
直觉：第 55 轮的教师不是单个网络，而是“大模型 + 语义-接触护盾 + 生存核”的复合体。它的每个安全动作背后都附带 `(m_T, C_T, s_T)`：离不可行边界多远、踩在哪些接触上、护盾是否想介入。学生若只学 `a_T`，就像只背答案不学推理；一旦分布偏移，动作标签不再覆盖，学生没有任何内部量能触发自保。因此要用 **特权信息蒸馏**：训练期把教师的裕度、接触集与弃权分数作为额外监督，让学生学会“怎么做、有多稳、踩在哪、何时别做”。

**灵感 3（痛点分析 → 反事实归因，定向分配蒸馏预算）**
直觉：一个痛点可能来自语义边界、接触可供性、动力学核、动作规划或延迟中的任一环。把所有容量平均分给所有模块，是最昂贵的浪费。用 **反事实痛点归因** `β_m(e)`（把模块 `m` 换成 oracle 后痛点下降多少）把蒸馏预算 `b_m` 定向到真正致痛的模块；于是“痛点分析”不再是汇报材料，而是 **容量分配器**，直接决定学生每个头/每层该被压多狠。

**灵感 4（模型蒸馏 → 教师护盾的干预就是免费痛点标签）**
直觉：在线运行时，教师护盾每一次否决或修正名义动作，都是一次 **near-miss 的免费标注**；每一次“本可以过但被迫急停”都是一条痛点事件。用“影子教师”持续记录 `(x, a_nom, a_T, m_T, s_T)` 并滚动更新 `μ_pain`，可以缓解离线账本只记得历史痛点的问题，并给出一条 **痛点漂移** 的在线估计。蒸馏因此从一次性离线压缩变成 **持续痛点蒸馏**。

**灵感 5（痛点分析 × 模型蒸馏 → 痛点保持证书 + 升级路由）**
直觉：要求学生在所有痛点上与教师一致，既不可能也无必要。正确目标是：学生在“有把握的常见区”快速通过，在“痛点/低裕度”区显式升级到教师、护盾或安全制动。证书只需证明一件可检查的事：**学生的痛点动作偏差乘上约束 Lipschitz 常数后，仍被教师的最小安全裕度支配**。一旦不被支配，就必须升级。这样蒸馏不是“压完就完”，而是 **带安全开关的级联**。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（痛点账本与痛点测度）**
事件 `e=(x,u,c,ℓ)`，痛点类别 `ℓ∈F={跌倒, 接触失败, 护盾干预, 核边界触碰, 语义边界误判, 超时}`。严重度 `sev(ℓ)>0`，不可逆度 `irr(ℓ)∈[0,1]`，观测倾向 `π_obs(e)∈(0,1]`（用于修正漏报）。痛点权重与痛点测度
```
w(e) = sev(ℓ)·(1+irr(ℓ)) / π_obs(e)
μ_pain(A) = ∫_A w(e) dP(e)
```
痛点账本 `L_p = {(e_i, w_i, z_i)}`，`z_i` 为归因嵌入；热点 `H_k` 为 `μ_pain` 在 `z` 空间的高密度峰。账本覆盖率
`cov(L_p) = μ_pain(supp L_p) / μ_pain(E)`，未覆盖率 `ε_L = 1 - cov(L_p)`。

**定义 128（痛点归因与定向蒸馏预算）**
模块集 `M={sem, con, dyn, act, lat}`。对痛点事件的反事实归因
```
β_m(e) = [pain(e) - pain(e | do(m → oracle))]_+ / Σ_{m'∈M} [...]
```
即把模块 `m` 换成 oracle 后痛点下降的份额，`β(e)∈Δ(M)`。模块蒸馏预算
```
b_m = Σ_{e∈L_p} w(e)·β_m(e),     b̄_m = b_m / Σ_m b_m
```
定向蒸馏目标
```
min_θ  L_pain(θ) = Σ_m b̄_m · E_{e~μ_pain}[ β_m(e)·d_m(π_T^m, π_S^m) ]
s.t.    L_nom(θ) ≤ ε_nom
```
其中 `d_m` 按模块定义（语义=边界一致性，接触=接触集/可供性偏差，动力学=裕度误差，动作=动作散度，延迟=路由延迟），`L_nom` 为名义分布散度。约束项是本轮的“名义回归护栏”。

**定义 129（特权安全蒸馏）**
教师特权信号 `y_T(x) = (a_T, m_T, C_T, s_T)`，其中 `m_T` 为第 55 轮生存核裕度 `K_margin`、`C_T` 为核心接触集、`s_T∈[0,1]` 为护盾介入/弃权分数。学生多头 `f_S(x) = (a_S, m̂, Ĉ, ŝ)`。损失
```
L_priv = d_a(a_S, a_T)
       + α1·|m̂ - m_T| + α2·d_H(Ĉ, C_T) + α3·CE(ŝ, s_T)
       + α4·L_rank(m̂, m_feasible) + α5·L_consist(m̂, ŝ)
```
`L_rank` 要求 `m̂` 与学生自身动作的可行裕度同序；`L_consist` 强制
`m̂ < θ_m ⇒ ŝ ≥ θ_s`（低裕度必须高弃权）。这把“知道何时不知道”写进网络结构，而不是事后拍阈值。

**定义 130（痛点保持谱）**
学生相对教师的痛点最坏动作偏差
```
δ_pain(π_S) = sup_{x∈supp μ_pain} ||π_S(x) - π_T(x)||
```
对扰动 `ξ∈Ξ_pain`（语义扰动预算 `δ_s`、接触参数、传感噪声），痛点保持谱
```
ρ_pain(ε) = inf_{||ξ||≤ε} P_{x~μ_pain}( safe | π_S + Shield, ξ )
```
`ρ_pain` 与第 53 轮 `ρ`、第 55 轮 `ρ_sem` 共用证书框架，但只在痛点支撑上取最坏，因此更锐利、也更难估——这正是它必须配独立证据的原因。

**定义 131（蒸馏安全证书）**
`J_D = (δ_nom, δ_pain, m_min, L_A, s_cal, ρ_pain, evidence)`，其中 `δ_nom` 为名义散度、`m_min = min_{x∈supp μ_pain} m_T(x)`、`L_A` 为第 55 轮护盾约束对动作的 Lipschitz 常数、`s_cal` 为弃权头校准。若
```
(1) δ_nom ≤ ε_nom
(2) L_A·δ_pain + θ_shield ≤ m_min          # 安全裕度支配动作偏差
(3) ρ_pain(ε_p) ≥ ρ_min
(4) ECE(ŝ) ≤ ε_cal
```
则称学生 **痛点蒸馏可部署**。条件 (2) 是本轮的核心：先证明偏差小于裕度，再谈平均精度；顺序反过来就是拿平均指标掩盖尾部风险。

**定义 132（蒸馏-护盾升级路由）**
级联策略
```
π_C(x) = π_S(x)                       若 ŝ ≤ θ_s 且 m̂ ≥ θ_m
       = π_T(x)                       若需升级且云边延迟 τ ≤ τ_max
       = u_stop(x)                    否则
```
升级率 `η = P(ŝ > θ_s ∨ m̂ < θ_m)`，有效成本 `C_C = c_S + η·c_T + η_stop·c_stop`，实时约束 `η·τ_T + (1-η)·τ_S ≤ τ_max`。路由需带滞回，避免在阈值附近抖振式切换。这把蒸馏从“一次性压缩”变成 **带安全开关的级联**。

## 2. 关键算法 伪代码

### IP-127 PLA（Pain Ledger Analysis）

```python
def build_pain_ledger(logs, taxonomy, sev, irr, audit):
    Lp = []
    for e in logs:
        lab = taxonomy.tag(e)                 # fall / contact_fail / shield_override / ...
        p_obs = audit.observation_propensity(e)
        w = sev[lab] * (1.0 + irr[lab]) / max(p_obs, 1e-6)
        z = attribution_embedding(e)
        Lp.append(PainEvent(e, w, z, lab))
    hotspots = density_peaks([p.z for p in Lp], weights=[p.w for p in Lp])
    return PainLedger(events=Lp, hotspots=hotspots,
                      coverage=ledger_coverage(Lp, hotspots))
```

### IP-128 PAD（Pain-Aware Distillation）

```python
def pain_aware_distill(teacher, student, D_nom, ledger, budgets):
    lam = budgets.lam0
    for step in range(budgets.steps):
        x_nom = sample(D_nom, budgets.B_nom)
        x_pain = ledger.sample_by_weight(budgets.B_pain)
        yT_n = teacher.privileged(x_nom)
        yT_p = teacher.privileged(x_pain)

        L_nom = nominal_div(student(x_nom), yT_n)
        beta = ledger.attribution(x_pain)                 # [B, |M|]
        L_pain = sum(
            budgets.b_m[m] * (beta[:, m] * module_div(m, student, yT_p)).mean()
            for m in MODULES
        )
        # 名义回归护栏：只惩罚超过预算的部分（hinge），避免尾部一压就牺牲常见情形
        L = L_pain + lam * max(0.0, L_nom - budgets.eps_nom)
        update(student, L)
        lam = dual_update(lam, L_nom - budgets.eps_nom)
    return student
```

### IP-129 PSD（Privileged Safety Distillation）

```python
def privileged_safety_distill(student, teacher, D_pain, alpha):
    for x in D_pain:
        aS, m_hat, C_hat, s_hat = student.forward_multihead(x)
        aT, m_T, C_T, s_T = teacher.privileged(x)
        L = (d_action(aS, aT)
             + alpha.m * abs(m_hat - m_T)
             + alpha.c * hausdorff(C_hat, C_T)
             + alpha.s * cross_entropy(s_hat, s_T)
             + alpha.r * rank_loss(m_hat, feasible_margin(student, x))
             + alpha.k * consistency_penalty(m_hat, s_hat, theta_m, theta_s))
        update(student, L)
    return student
```

### IP-130 PCS（Pain Preservation Spectrum）

```python
def pain_preservation_spectrum(student, teacher, shield, ledger, eps_grid):
    spectrum = {}
    for eps in eps_grid:
        worst = 1.0
        for xi in pain_perturbations(ledger, eps):      # 语义/接触/噪声扰动
            ok = 0
            for x in ledger.support_sample():
                aS = student(x, xi)
                ok += int(safe(shield(aS, x, xi), x, xi))
            worst = min(worst, ok / len(ledger.support_sample()))
        spectrum[eps] = worst
    return spectrum
```

### IP-131 DSC（Distillation Safety Certificate）

```python
def distillation_certificate(student, teacher, ledger, shield, budgets):
    delta_nom = empirical_div(student, teacher, budgets.D_nom)
    delta_pain = max_div_on_support(student, teacher, ledger.support)
    m_min = min_teacher_margin(teacher, ledger.support)
    L_A = estimate_action_lipschitz(shield, ledger.support)

    if delta_nom > budgets.eps_nom:
        return ('reject', 'nominal_regression', delta_nom)
    if L_A * delta_pain + budgets.theta_shield > m_min:
        return ('reject', 'margin_dominated', L_A * delta_pain, m_min)
    if budgets.rho_pain(ledger) < budgets.rho_min:
        return ('reject', 'pain_robustness_fail')
    if not calibrated(student.abstain_head):
        return ('reject', 'abstain_miscalibrated')

    return ('ok', DistillCert(delta_nom, delta_pain, m_min, L_A,
                              student.abstain_calibration, budgets.rho_pain,
                              evidence=ledger.counterexamples))
```

### IP-132 DSR（Distillation-Shield Router）

```python
def escalation_route(x, student_out, latency_budget, hysteresis):
    aS, m_hat, s_hat = student_out
    want_up = (s_hat > theta_s) or (m_hat < theta_m)
    if not want_up and not hysteresis.sticky(x):
        hysteresis.clear(x)
        return aS, 'student'
    if latency_budget.can_call_teacher():
        hysteresis.mark(x)
        return teacher.act(x, privileged=True), 'teacher'
    return safe_brake(x), 'stop'
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PLA | O(|logs|·log|logs| + |M|·|logs|·CF) | O(|logs|) | 观测倾向校正、漏报有界 |
| PAD | O(N·(B_nom+B_pain)·(|M|+1)) | O(model) | 预算归一、名义护栏 |
| PSD | O(N·B_pain·|heads|) | O(model+|heads|) | 特权信号与动作同源 |
| PCS | O(N_adv·|support|·T) | O(|support|·T) | 扰动覆盖、最坏可复现 |
| DSC | O(|support|·(|M|+calib)) | O(|support|) | δ_pain 上界、L_A 可信 |
| DSR | O(1) + O(η·teacher) | O(1) | 滞回不抖振、延迟预算 |

**正确性定理（Pain-Preserving Distillation Soundness）**
假设第 55 轮 (A29)–(A32) 成立（语义置信校准、生存核保守包含、语义扰动预算、云边延迟有界）；本轮新增：
**(A33)** 痛点账本 `ε_L`-覆盖：真实痛点测度落在账本支撑外的质量 `≤ ε_L`；
**(A34)** 学生痛点偏差 `δ_pain`、教师痛点最小裕度 `m_min`、护盾约束 Lipschitz 常数 `L_A` 均可估且有限；
**(A35)** 弃权头已校准 `ECE ≤ ε_cal`，升级延迟 `τ_route ≤ τ_max`，路由带滞回无抖振。
则级联部署后的单步安全概率
```
P_safe ≥ 1 - ε_L
            - P(δ_pain > Θ_p)
            - P(L_A·δ_pain + θ_shield > m_min)
            - P(ŝ miscalibrated)
            - P(router timeout)
```
关键：**痛点先进入测度与预算、安全理由随动作一起蒸馏、证书要求偏差被裕度支配、越界即升级**。四层任一失守，都不允许把“平均精度高”当作“尾部安全”。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 痛点样本稀少、漏报导致账本有偏 | 高 | 观测倾向校正 + 影子教师在线标注 + 主动审计采样 |
| 尾部过拟合历史痛点、部署分布漂移 | 高 | 滚动账本 + 漂移检测 + OOD 拒绝 + 定期重蒸馏 |
| 特权信号（裕度/接触集）边端不可得 | 中 | 仅训练期使用 + 学生头自监督一致性 + 教师抽样校验 |
| 为尾部牺牲常见情形（名义回归） | 高 | 约束优化 + 名义 hinge 护栏 + 压缩-安全 Pareto 选点 |
| 升级路由频繁触发、延迟超限 | 高 | 滞回 + 升级预算 + 本地轻量护盾 + 云端配额 |
| `δ_pain` 的最坏值难估、证书虚高 | 高 | 分层置信上界 + 反例库 + 保守回退阈值 |

## 6. 本轮最大风险

**一句话**：痛点蒸馏把“平均拟合”换成“尾部保持”，但其 soundness **三重依赖痛点账本的无偏覆盖、特权安全信号在边端的可蒸馏性、以及 `δ_pain` 最坏上界的可信估计**；一旦漏报使账本系统性错过真正的痛点、或学生只学到裕度的平均趋势而未学到其尾部，证书会在“自认为已被裕度支配”的区域内放行学生动作，让一次低频高危的语义-接触误判绕过升级路由造成不可逆跌倒——因此必须以 **倾向校正账本 + 影子教师持续标注 + 反例驱动的保守证书** 三重护栏，宁可在痛点区多升级一次，绝不把“平均精度更高”当作“尾部已被证明安全”。

# 第 56 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SCG×WBV×SSF×SCC×SRS×CEB×PLA×PAD×PSD×PCS×DSC×DSR）

## 2. 关键算法 伪代码

### IP-121 SCG（Semantic-Contact Grounding）

```python
def semantic_contact_map(rgbd, seg_model, kappa, theta_k, theta_conf):
    Sigma = seg_model.predict_soft(rgbd)
    C = set()
    for p in grid(rgbd):
        l = argmax(Sigma[p])
        if confidence(Sigma[p]) < theta_conf:
            continue
        for c in CONTACT_TYPES:
            if kappa[l][c] >= theta_k:
                C.add((p, c))
    M = boundary_margin(Sigma)
    return Sigma, C, M

def conservative_contacts(C, M, kappa, theta_m):
    return {(p, c) for (p, c) in C
            if M[p] >= theta_m(kappa[argmax_at(p)][c])}
```

### IP-122 WBV（Whole-Body Viability Kernel）

```python
def viability_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for x in sample_state_space(x0, horizon):
        feas, u, lam = solve_contact_dynamics(x, C_plus, friction_cone=mu)
        if feas:
            K.add(x)
            margins.append(distance_to_infeasible(x, C_plus))
    return KernelApprox(inner_hull(K), outer_hull(K, eps),
                        margin=min(margins) if margins else 0.0)
```

### IP-123 SSF（Semantic Shield Filter）

```python
def semantic_shield(u_nom, x, Kernel, C_plus, W):
    u = qp_solve(H=W, g=-W @ u_nom,
                 constraints=[viability_constraint(x, u, Kernel.K_in),
                              contact_constraint(u, C_plus),
                              friction_cone_constraint(u, mu),
                              joint_limit_constraint(u)])
    if u is None or projection_gap(u, u_nom) > Delta_u:
        return safe_brake(x), 'shield_infeasible'
    return u, 'ok'
```

### IP-124 SCC（Semantic-Contact Certificate）

```python
def semantic_contact_certificate(traj, Sigma, kappa, rho_sem, budgets):
    Sigma_core = core_semantics(traj, Sigma)
    C_core = contacts_used(traj) & conservative_contacts(Sigma_core, M, kappa, theta_m)
    if not C_core:
        return ('reject', 'no_core_contact')
    K_margin = min(distance_to_boundary_K(x, Sigma) for x in traj)
    delta_s = semantic_perturbation(Sigma_core, calibrated_eps)
    if K_margin < budgets.theta_K or delta_s > budgets.Theta_s:
        return ('reject', 'semantic_budget_exceeded', K_margin, delta_s)
    if rho_sem(delta_s) < budgets.rho_min:
        return ('reject', 'semantic_robustness_fail')
    return ('ok', SemanticCert(Sigma_core, C_core, K_margin, rho_sem, delta_s))
```

### IP-125 SRS（Semantic Robustness Spectrum）

```python
def semantic_robustness_spectrum(Sigma_hat, eps_s, sampler):
    worst = 1.0
    for Sigma_adv in sampler.ball(Sigma_hat, eps_s, worst_case=True):
        p = empirical_viability(renormalize(Sigma_adv), sampler.states)
        worst = min(worst, p)
    return worst
```

### IP-126 CEB（Cloud-Edge Semantic Boundary）

```python
def cloud_edge_semantics(P_c, Sigma_c, kappa_c, edge):
    Sigma_e, C_e = edge.local_semantics()
    mismatch = boundary_disagreement(Sigma_c, Sigma_e)
    if mismatch.area > delta_A:
        return ('reprofile', region=mismatch.hotspots,
                evidence=edge.explain_contact_failure())
    C_shared = conservative_contacts(C_e, edge.margin, kappa_c, theta_m)
```

### IP-127 PLA（Pain Ledger Analysis）

```python
def build_pain_ledger(logs, taxonomy, sev, irr, audit):
    Lp = []
    for e in logs:
        lab = taxonomy.tag(e)
        p_obs = audit.observation_propensity(e)
        w = sev[lab] * (1.0 + irr[lab]) / max(p_obs, 1e-6)
        Lp.append(PainEvent(e, w, attribution_embedding(e), lab))
    hotspots = density_peaks([p.z for p in Lp], weights=[p.w for p in Lp])
    return PainLedger(Lp, hotspots, coverage=ledger_coverage(Lp, hotspots))
```

### IP-128 PAD（Pain-Aware Distillation）

```python
def pain_aware_distill(teacher, student, D_nom, ledger, budgets):
    lam = budgets.lam0
    for step in range(budgets.steps):
        x_nom = sample(D_nom, budgets.B_nom)
        x_pain = ledger.sample_by_weight(budgets.B_pain)
        yT_n, yT_p = teacher.privileged(x_nom), teacher.privileged(x_pain)
        L_nom = nominal_div(student(x_nom), yT_n)
        beta = ledger.attribution(x_pain)
        L_pain = sum(budgets.b_m[m] *
                     (beta[:, m] * module_div(m, student, yT_p)).mean()
                     for m in MODULES)
        L = L_pain + lam * max(0.0, L_nom - budgets.eps_nom)
        update(student, L)
        lam = dual_update(lam, L_nom - budgets.eps_nom)
    return student
```

### IP-129 PSD（Privileged Safety Distillation）

```python
def privileged_safety_distill(student, teacher, D_pain, alpha):
    for x in D_pain:
        aS, m_hat, C_hat, s_hat = student.forward_multihead(x)
        aT, m_T, C_T, s_T = teacher.privileged(x)
        L = (d_action(aS, aT) + alpha.m * abs(m_hat - m_T)
             + alpha.c * hausdorff(C_hat, C_T)
             + alpha.s * cross_entropy(s_hat, s_T)
             + alpha.r * rank_loss(m_hat, feasible_margin(student, x))
             + alpha.k * consistency_penalty(m_hat, s_hat, theta_m, theta_s))
        update(student, L)
    return student
```

### IP-130 PCS（Pain Coverage Spectrum）

```python
def pain_coverage_spectrum(student, teacher, shield, ledger, eps_grid):
    spectrum = {}
    for eps in eps_grid:
        worst = 1.0
        for xi in pain_perturbations(ledger, eps):
            ok, n = 0, 0
            for x in ledger.support_sample():
                ok += int(safe(shield(student(x, xi), x, xi), x, xi)); n += 1
            worst = min(worst, ok / n)
        spectrum[eps] = worst
    return spectrum
```

### IP-131 DSC（Distillation Safety Certificate）

```python
def distillation_certificate(student, teacher, ledger, shield, budgets):
    delta_nom = empirical_div(student, teacher, budgets.D_nom)
    delta_pain = max_div_on_support(student, teacher, ledger.support)
    m_min = min_teacher_margin(teacher, ledger.support)
    L_A = estimate_action_lipschitz(shield, ledger.support)
    if delta_nom > budgets.eps_nom:
        return ('reject', 'nominal_regression', delta_nom)
    if L_A * delta_pain + budgets.theta_shield > m_min:
        return ('reject', 'margin_dominated', L_A * delta_pain, m_min)
    if budgets.rho_pain(ledger) < budgets.rho_min:
        return ('reject', 'pain_robustness_fail')
    if not calibrated(student.abstain_head):
        return ('reject', 'abstain_miscalibrated')
    return ('ok', DistillCert(delta_nom, delta_pain, m_min, L_A,
                              student.abstain_calibration, budgets.rho_pain,
                              evidence=ledger.counterexamples))
```

### IP-132 DSR（Distillation-Shield Router）

```python
def escalation_route(x, student_out, latency_budget, hysteresis):
    aS, m_hat, s_hat = student_out
    want_up = (s_hat > theta_s) or (m_hat < theta_m)
    if not want_up and not hysteresis.sticky(x):
        hysteresis.clear(x)
        return aS, 'student'
    if latency_budget.can_call_teacher():
        hysteresis.mark(x)
        return teacher.act(x, privileged=True), 'teacher'
    return safe_brake(x), 'stop'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCG | O(|Ω|·(|L|+|C|)) | O(|Ω|·|L|) | 置信校准、可供性标定 |
| WBV | O(|X|·T·QP) | O(|X|) | 外近似 sound、接触集完备 |
| SSF | O(QP)/步 | O(|A_WB|) | 可行或安全回退、投影有界 |
| SCC | O(|traj|·|Ω|) | O(|Ω|) | `δ_s` 闭合、核心接触非空 |
| SRS | O(N_adv·|X|) | O(|X|) | 扰动球覆盖、最坏可复现 |
| CEB | O(|Ω|+τ_sem) | O(|Ω|) | 边界不一致可检测、重分割收敛 |
| PLA | O(|logs|·log|logs| + |M|·|logs|·CF) | O(|logs|) | 倾向校正、漏报有界 |
| PAD | O(N·(B_nom+B_pain)·(|M|+1)) | O(model) | 预算归一、名义护栏 |
| PSD | O(N·B_pain·|heads|) | O(model+|heads|) | 特权信号与动作同源 |
| PCS | O(N_adv·|support|·T) | O(|support|·T) | 扰动覆盖、最坏可复现 |
| DSC | O(|support|·(|M|+calib)) | O(|support|) | `δ_pain` 上界、`L_A` 可信 |
| DSR | O(1)+O(η·teacher) | O(1) | 滞回不抖振、延迟预算 |

**正确性定理（GroundEdge Semantic-Contact-Distillation Soundness）**
假设第 53 轮 (A22)–(A25) 与第 54 轮 (A26)–(A28) 成立；第 55 轮 **(A29)** 语义置信校准 `ECE ≤ ε_cal`；**(A30)** `K_in ⊆ K(Σ) ⊆ K_out` 且护盾不可行时回退 `u_stop∈𝒳_safe`；**(A31)** 真实语义扰动 `||Σ-Σ̂||_∞ ≤ ε_s`；**(A32)** 云边边界回传延迟 `≤ τ_sem` 且重分割收敛。本轮新增 **(A33)** 痛点账本 `ε_L`-覆盖；**(A34)** `δ_pain, m_min, L_A` 可估且有限；**(A35)** 弃权头校准 `ECE ≤ ε_cal`、`τ_route ≤ τ_max`、路由带滞回。则部署后单步安全概率
```
P_safe ≥ 1 - P(||Σ-Σ̂||_∞ > ε_s) - P(κ miscalibrated)
            - P(K_out \ K_in ≠ ∅) - P(shield fallback fails)
            - ε_L - P(δ_pain > Θ_p)
            - P(L_A·δ_pain + θ_shield > m_min)
            - P(ŝ miscalibrated) - P(router timeout)
```
关键：**语义不确定性进证书、生存核保守包含、护盾兜底、痛点偏差被裕度支配、越界即升级**；任何一层失守，都不允许把“分割看起来很确定”或“平均精度很高”当作“接触一定成立、尾部一定安全”。

## 7. 本轮最大风险

**一句话**：v32 用“语义-接触安全层 + 痛点驱动蒸馏 + 升级路由”把云端的高保证安全压缩到边端，但其 soundness **三重依赖痛点账本的无偏覆盖、特权安全信号在边端的可蒸馏性、以及 `δ_pain` 最坏上界的可信估计**；一旦漏报让账本系统性错过真正的痛点、或学生只学到裕度的平均趋势而未学到尾部，证书会在“自认为被裕度支配”的区域内放行学生动作，使一次低频高危的语义-接触误判绕过升级路由造成不可逆跌倒——因此必须以 **倾向校正账本 + 影子教师持续标注 + 反例驱动的保守证书** 三重护栏，宁可在痛点区多升级一次，绝不把“平均精度更高”当作“尾部已被证明安全”。
