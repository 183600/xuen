# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；灵感循环第 3 轮；本轮灵感：「知识图谱」×「并发推理」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险堪称一剑封喉：**归因依赖「故障属于有限假设集、且视觉与几何失效相互独立」两个隐藏假设（A88）；真实故障常是未知类型的组合，透明/镜面/对抗 patch 让视觉与几何共享同一个 OOD 失效源，FIR 会把未知复合故障强行塞进最近假设、只膨胀错误的球——而且系统因「已经归因」而更自信地继续执行。** 本轮不新增传感器，而是换一个**建模与计算**的提问方式：第 65 轮问「谁坏了」，CAIRN 问「**我们凭什么认为这些故障彼此独立、且只有这么几种？**」。本轮核心命题是：
>
> **把「扁平单标签假设集上的贪心归因」升级为「因果知识图谱上的并发可信集推理」：用图结构显式表达共因、掩蔽与复合故障，用并发线程同时维护一整簇假设并按可信集做安全 join，让安全与归因解耦——归因只买效率，安全由可信集兜底。**

## 0. 直觉与动机

**灵感 1（知识图谱 → 单标签 ℋ 装不下根因幂集）**
直觉：第 65 轮的 ℋ 是"一次只能选一个"的扁平单标签集，因此它在表示层面就**无法表达**"透明物体同时导致 H_vis 与 H_geo"或"F/T 偏置叠加软接触"。所谓"未知复合故障被强行归入最近假设"，根因不是 softmax 太弱，而是**假设空间错了**：真实故障空间是根因的幂集，不是 6 个互斥标签。知识图谱把根因（latent root causes）、失效模式（failure modes）、证据（evidence）分成三层节点，用有类型边连接，复合故障自然地成为**激活集 S⊆V_R**。第 65 轮 §7 自己承认"有限假设集的固有缺陷"——本轮从表示上修它，而不是继续调阈值。

**灵感 2（知识图谱 → 共因在错模型里是噪声，在对图里是证据）**
直觉：第 65 轮把"视觉与几何同时失效"视为最坏情况，因为它只允许独立归因，两个通道一起坏只能判 ambiguous。但在因果图里，透明/镜面物体是一个**共享父节点**，它同时指向 H_vis 与 H_geo。"两条通道同时坏"这个**相关性事件**恰恰是共因父节点的指纹。于是同一个现象：扁平独立模型必须说"我分不清"，因果图模型却可以说"我看到的是一个共因"。**从"检测到模糊"升级为"识别出模糊的来源"。**

**灵感 3（知识图谱 → 开放式世界：未知故障也必须是一个节点）**
直觉：闭集 FIR 最危险的动作，是把没见过的故障硬塞进最近已知假设并**当作完成了归因**。知识图谱天然是开放世界的：保留一个 `r_unknown` 根因节点，用 conformal 新奇度分数决定其质量。未知不是被忽略，而是被**显式表示**为一个可激活节点；只要它进入可信集，认证就转保守，绝不会"静默误归因"。

**灵感 4（并发推理 → 不要在证据不足时把假设压成一个 argmax）**
直觉：第 65 轮的顺序 FIR 因时延被迫 argmax + 阈值，模糊时只发一个探针。但正确的对象本应是**一整簇后验可信的假设**。并发推理把"每个假设各算一套球、一套证书、一套监控"做成并行线程，同时保活；决策用 join 而非 argmax。并发在这里的第一价值不是快，而是**顺序系统因时延被迫早下结论，并发系统可以先都留着、用安全 join 说话**。

**灵感 5（并发推理 → 推测式归因：安全与归因解耦）**
直觉：投机解码并行生成多个候选、只在一致时提交。这里同理：只提交**在所有活跃假设下都安全**的那个动作前缀，同时让归因并发地继续收集证据、只用于**放宽**前缀。这是对第 65 轮的一次反转：第 65 轮是"先归因、再安全行动"；CAIRN 是"**先对整簇假设都安全，再靠归因把前缀放宽**"。因此错误归因只能让我们更慢，不能让我们更不安全——这从结构上拆掉了"因为已归因而更自信"的引信。

**灵感 6（三灵感合流 → CAIRN 对 VISTA 的原位升级）**
- **FIR → GFI**：从扁平 softmax 改为因果图上的后验推断，输出根因边际、共因后验与**可信集 L**。
- **新增 CKG / OGN / CCC**：因果故障知识图谱、开放世界节点、共因认证。
- **APP/AFA → AFA-G**：探针目标从"故障假设互信息"升级为"**根因集合互信息 + 等价类分裂增益**"；探针被当作**工具变量**去破除共因。
- **RSC-V → RSC-G**：从固定三球升级为"根因→物理组件"的定向球分配；**不可分等价类联合膨胀**，可分组件保持紧致。
- **CSC → CSJ + SAP**：并发安全 join + 推测式认证前缀。
- **CSP-V → CSP-G**：技能绑定**子图签名**，规划必须对可信集内全部假设有效；偏向信息获取元技能。
- **AIC-V → AIC-G**：干扰集增**结构误设、共因对抗、并发时序撕裂**。
- **J_vista → J_cairn**：证书增 credible_set_hash、equiv_class_id、open_world_mass、confounder_coef、snapshot_version、thread_join_ms。

## 2. 关键算法骨架

```python
# GFI：图上后验 → 可信集 L（语义流，可并发）
marg_r = message_passing(CKG, lik, rho)            # P(r|rho)，含 COMMON 父因
sets   = credible_cover(marg_r, CKG, 1 - delta_cred)
L      = sets | CKG.equiv_classes(marg_r)          # 不可辨识等价类必须并入
if CKG.novelty(rho) > CKG.q_nov: L |= {'r_unknown'}
gamma, beta_hat, ident = CCC.identify(rho, instruments)

# CHT + CSJ：同一版本快照上并发认证
with blackboard.snapshot(version=v) as snap:
    futs = {S: scheduler.submit(certify, S, snap) for S in L}
    certs = [fut.result_or(CONSERVATIVE_DEFAULT) for fut in futs]   # 超时即保守
assert all(c.snapshot_version == v for c in certs)                  # 防撕裂
k_star = min(c.k_star for c in certs)                              # 全假设安全 join

# SAP：推测式执行，归因只放松前缀
for a in prefix[:k_star]:
    dispatch(a)
    if join_abort(a, certs): break                                 # 任一存活假设越界即停
refresh_posterior_async(rho_new)                                   # 并发收缩 L -> k*↑
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（共因可辨识性 / 工具变量）**：线性 SEM 下，无干预时只能辨识乘积 αβVar(c)；存在"只改变某通道对共因暴露"的去激活探针 z 时，loading 比 β/α 可辨识。故第 65 轮必须判 ambiguous 的共因，在 CKG+CCC 下**可被归因为共享父节点**，且 null_test/visual_probe 正是天然工具。
- **引理 10（可信集安全 / join 可靠性）**：若 P(S_true∈L)≥1−δ_cred，且对 L 中每个 S 认证的前缀安全，则 P(前缀安全)≥1−δ_cred−α_chunk−α_vis。**安全取决于可信集覆盖，而非点归因正确**——错误归因落在 L 内只会缩小 k*、增加保守，不会导致越界。这是对第 65 轮风险的形式反转。
- **引理 11（并发一致性 / anytime）**：所有线程对同一不可变版本 v 认证、join 原子读取时，并发 join 等价于顺序 join。若无版本校验，撕裂读会在过期 L 上认证并使引理 10 失效——故 snapshot_version 必须写入 J_cairn。截止期超时→保守默认线程（k*=0）仍可靠。
- **定理 9（CAIRN 端到端归因-安全）**：A94–A99 下，Valid(J_cairn) ⇒ 安全与归因解耦（全可信集前缀安全）∧ 共因被识别或按等价类联合膨胀（绝不错误拆分）∧ 未知根因或归入 r_? 或保守处置（绝不静默误归因）∧ 并发在快照一致下可靠 ∧ 第 65 轮 VISTA 是单例图/单点可信集的特殊情形。
- **定理 10（效率单调性与并发加速）**：E[progress] 随可信集收缩单调不减；k*_join(L)=min_S k*_S 对 L 单调反序，故归因越确定前缀越长。并发把语义推理时延上界压缩至 ceil(|L|/cores)，在 |L|≤cores 时可近似常数时间，从而更早达到较大 k*。
- **命题（共因：模糊→可辨识）**：扁平单标签模型在共因样本上的真实分布与模型分布的 KL 散度 D(p_true‖p_flat)=I(ρ_a;ρ_b)>0，故其似然系统性错配、只能判模糊；含共享父节点的 CKG 在该方向 D=0 并可集中后验。**"模糊"是错模型的产物，不是数据的固有属性。**
- **实时性**：CKG/GFI/AFA-G/CSP-G/CHT 调度全在语义流；实时流只增逐线程监控（O(|L|)，|L|≤4）与 join（O(|L|)），并借共享缓冲与事件触发视觉 ROI，维持 ≤2.5ms（A99）。

## 2. 形式化定义（完整版）

**定义 233（CAIRN 闭环）** CAIRN 是 VISTA 的"开放世界因果 + 并发可信集"升级：保留 VISTA 的视觉前瞻（VPG）、动作分块（ACH）、视觉接触验证（VCV）、主动探测（AFA）、长预测短执行（CSC）与 GRIP 的四层骨架，新增 CKG（因果故障知识图谱）、OGN（开放世界节点）、GFI（图故障推断）、CCC（共因认证）、CHT（并发假设线程）、CSJ（并发安全 join）、SAP（推测式归因前缀），并原位升级 AFA→AFA-G、RSC-V→RSC-G、WCV-V→WCV-G、CSP-V→CSP-G、AIC-V→AIC-G、J_vista→J_cairn。不变式：**所有图结构学习、后验推断、共因辨识、可信集维护、并发调度与证书构建只发生在语义流与低频线程；实时路径只做残差采集、逐线程监控、join 与安全前缀派发，零学习写操作。**

**定义 234（因果故障知识图谱 CKG）** CKG=(V,E,Θ)，节点分三层：
- **根因层 V_R**（latent）：`r_bias`（F/T 零偏）、`r_drift`、`r_sat`（饱和）、`r_soft`（软接触）、`r_contact_amb`（接触点歧义）、`r_transparent`、`r_mirror`、`r_lowtexture`、`r_adv_patch`、`r_stale_geom`（几何过期）、`r_policy_ood`、`r_latency`、`r_unknown`；
- **失效模式层 V_F**：`f_geo`、`f_force`、`f_model`、`f_vis`、`f_policy`（即第 65 轮 ℋ\{H0} 的"多标签版本"）；
- **证据层 V_E**：阶段残差 `ρ_p`、`e_vis`、`ℓ_contact`、`d_chunk`、`u_chunk`、`f̂_vis` 等。

有类型边：CAUSE（r→f）、MANIFEST（f→e）、MASK（`r_i→r_j`：一故障掩盖另一签名）、AMPLIFY（交互放大）、COMMON（同一父因 c 同时→多个 f）、CONTEXT（任务/物体/环境作为选择子门控某条边）。边参数 Θ 由离线故障注入 + 真机标定台估计。证据按图分解：
p(E|S)=∏_{e∈V_E} p(e | Pa(e)), S⊆V_R。
**独立性问题被显式化**：若 `r_transparent` 同时是 `f_vis` 与 `f_geo` 的父节点，则模型不会假设二者独立；第 65 轮的 A88 从"隐藏假设"变成"一条可审计、可检验的 COMMON 边"。

**定义 235（根因激活后验与开放节点 OGN）** 故障场景是根因子集 S⊆V_R。后验
q(S)=p(ρ|S)P(S)/Σ_{S'}p(ρ|S')P(S')，
P(S) 用稀疏 MRF 先验（激活根因数少、COMMON 父因有额外先验）。高维时用 mean-field q(S)=∏_{r∈V_R}q_r(s_r) 或粒子集 `{S^{(m)},w^{(m)}}`。开放世界节点 `r_?`：DP/stick-breaking 先验质量 β；conformal 新奇度 `s_nov(ρ)` 为签名到已知典型集（凸包/马氏距离）的距离，阈值 `q_nov(α_nov)` 为其 ⌈(n+1)(1−α_nov)⌉/n 分位数。**可信集**
L = CredibleCover(q, 1−δ_cred) ∪ EquivClasses(marg) ∪ ({r_?} if s_nov>q_nov else ∅)，
要求 Σ_{S∈L}q(S)≥1−δ_cred，并保证 P(S_true∈L)≥1−δ_cred（模型正确时）。**注意：L 是覆盖集，不是 argmax 的 top-k；等价的不可辨识原因必须整类保留。**

**定义 236（GFI 图故障推断）** 在 CKG 的因子图上做 loopy BP 或平均场变分，迭代至收敛或固定轮数：
m_{i→j}(s_j) ∝ Σ_{s_i} ψ_{ij}(s_i,s_j) φ_i(s_i) ∏_{k∈N(i)\j} m_{k→i}(s_i)，
输出根因边际 P(r|ρ)、失效模式边际 P(f|ρ)、共因后验 P(c|ρ)=P(∃r∈C_common active|ρ)，以及定义 235 的可信集 L。**第 65 轮 FIR 是 CKG 的退化特例**：无 COMMON 边、根因两两互斥、且只取 argmax。复合故障（多个根因同时激活）与未知故障（r_?）在 GFI 中被**原生表示**，而不是被 softmax 挤进单一标签。

**定义 237（共因签名与混淆系数 CCC）** 考虑两"名义独立"证据通道 a、b（如视觉残差与几何/力残差），线性 SEM：
ρ_a = α c + ε_a，ρ_b = β c + ε_b，ε_a⊥ε_b⊥c。
观测协方差给出 Cov(ρ_a,ρ_b)=αβVar(c)，**一个方程两个未知数**（αβ 与 Var(c) 不可分），这正是第 65 轮只能说"ambiguous"的数学根源。引入**去激活探针** z（干预只改变某通道对共因的暴露，例如 `null_test` 进入自由空间：几何/视觉误差消失、而 F/T 零偏仍在；或 `visual_probe` 主动视觉：视觉证据增强、力不变）。干预前后
Δρ_a=α c，Δρ_b=β c ⇒ β/α=Δρ_b/Δρ_a，
故 loading 比可辨识；结合 `γ=corr(ρ_a,ρ_b)` 的符号与时间签名，可区分：
- **共因**：|γ| 高、且探针响应满足 |Δρ_b/Δρ_a|≈|β/α|、两通道同时出现/消失；
- **两个独立故障**：探针只改变一个通道、另一个通道响应不随干预同步；
- **单向因果 a→b**：干预 a 后 b 同向变化，但干预 b 不影响 a（方向可辨）。
**结论：共因不是"无法归因"，而是缺少一个正确的干预。探针 = 工具变量。**

**定义 238（图谱可辨识性与等价类）** 把签名矩阵从观测推广到干预：
S_{e,r}=∂E[ρ_e | do(r=1), other causes fixed]/∂θ_r，
图 Fisher 信息 `J_graph=SᵀΣ_ρ⁻¹S`，`κ_graph=λ_min(J_graph)/λ_max(J_graph)`。**结构可辨识**由 d-分离给出：在给定证据与可执行干预集合下，若根因 r_i 与 r_j d-分离，则其效应可分别估计；否则它们属于同一**等价类 E_eq**，任何后验点估计都在 E_eq 内不可分辨。策略：
- E_eq 是单元素 → 定向膨胀（同第 65 轮）；
- |E_eq|>1 → **禁止 argmax 破平局**，整类并入 L，并对其映射到的组件**联合膨胀**；
- 若存在能 d-分离该等价类的探针（打断 backdoor/COMMON 边），优先用 AFA-G 去消除它。
这是对第 65 轮"未知复合故障被强行归类"的**结构性修正**：系统在不可辨识时的默认动作是"保留整类 + 联合保守"，而不是"选一个最近标签"。

**定义 239（AFA-G 图信息/混淆破除探针）** 探针动作带阶段模板 a=(visual_approach, light_touch, load)，探针集 A={`null_test`,`visual_probe`,`press`,`rub`,`tap`,`lift`,`confounder_cut`}。选择
a*=argmax_{a∈A} I(S_R; ρ_new(a) | ρ_old, do(a)) + λ_sep·Δ|E_eq|(a)，
s.t. 预测 f_n≤f_safe(φ̂,f̂_vis)、预测形变≤ε_strain、支持视觉早停。其中第一项是**根因集合**（而非扁平单标签）的互信息，第二项奖励"把最大等价类劈开"的探针；探针在 CCC 中充当工具变量。易损物体（f_safe<f_min_probe）禁用接触探针，只用 `null_test`/`visual_probe`/`confounder_cut`。若最大增益<δ_fi 或探针不安全，返回 None，保持 L 不变并走保守前缀。

**定义 240（并发假设线程 CHT）** 给定可信集 L 与语义快照版本 v，为每个 S∈L 派生线程
T_S=(S, p_S, B_S, Cert_S, monitor_S)，
分别计算：该激活集下的后验权重 p_S、RSC-G 球配置 B_S、认证前缀 Cert_S、实时监控阈值 monitor_S。并发模型采用**版本化黑板（MVCC）**：线程只读不可变快照 v，只写私有 workspace；完成后把结果原子发布回黑板并附 snapshot_version。调度器按风险优先级派发（高风险/高后验先算）。截止期 τ 到达时，未完成线程由保守默认线程 `S_⊥` 替代：`B_⊥` 取最大球、`k*_⊥=0`、`valid_⊥=False`。

**定义 241（并发安全 join CSJ）** 对前缀长度 k，定义
Cert_join(k)=⋀_{S∈L}Cert_S(k)，
`k*_join=min_{S∈L}k*_S`，`margin_join=min_{S∈L}margin_S`。join 门必须**在一次原子读取中取得同一 snapshot_version 的全部证书**；若任一证书版本不一致则判 `torn_read`，本次 join 无效并回退保守。`k*_join=0` ⇒ safe_idle/柔顺退避/重规划。join 的语义是：**只有对当前所有可信假设都安全的前缀才可执行**；这正是"以可信集兜底安全"的算子化。

**定义 242（推测式归因与认证前缀 SAP）** 每语义拍：
1. 用新证据更新 q(S) 与 L（并发进行 GFI/CCC/AFA-G）；
2. 取最大 k 使所有 S∈L 的 Cert_S(k) 通过，执行该前缀；
3. 归因（后验收缩）只用于**放大 k***，不参与"是否允许行动"。
单调性：若 L'⊆L，则 `k*_join(L')≥k*_join(L)`。极端情形：L=V_R 的全幂集（完全未知）时 k*=0 → 只做安全驻留与信息获取；L={S_true} 时 k* 回到第 65 轮 CSC 的激进程度。**SAP 把安全从"归因正确"这一脆弱前提上解耦下来。**

**定义 243（RSC-G 图定向球分配）** 维护物理组件不确定半径向量
b=(b_geo,b_force,b_model,b_vis,b_policy,b_latency)，
以及组件融合关系。CKG 给出根因→组件映射 M: V_R→2^{components}。对每个组件 c：
b_c ← clip( b_c0 · exp(λ·Σ_{r∈M^{-1}(c)} P(r|ρ)) , b_min, b_max )，
并施加：
- **等价类联合规则**：若 E_eq 中不同根因映射到不同组件，则这些组件**同时**膨胀（不确定的是"组合"，不能只挑一个）；
- **可分收缩规则**：一旦 CCC/AFA-G 证明某根因不存在或其 d-分离分量与当前模糊无关，对应组件按后验收缩回标定值；
- 融合半径按组件**正交合成**传入 WCV-G：`r_c = sqrt(Σ_{c'∈C}b_{c'}²)`（C 为进入搜索域的组件子集）。
相比第 65 轮 RSC-V 的固定三球，RSC-G 增加了 `b_vis/b_policy/b_latency`，并把"膨胀谁"从"最近标签"变成"**图上哪些根因被激活/哪些等价类不可分**"。

**定义 244（OGN 开放世界新奇度校准）** conformal 新奇度 `s_nov(ρ)=min_{S∈known} d(ρ, Typical(S))`，阈值 `q_nov(α_nov)`。判据：
- `s_nov ≤ q_nov`：正常模式，r_? 质量 = 先验 β；
- `s_nov > q_nov`：unknown mode，`P(r_?)↑`，强制 r_?∈L，全组件保守膨胀、k* 截断至 0 或最小、请求额外感知/人类接管。
保证（A98 下）：对真未知根因产生的证据，`P(r_?∈L)≥1−α_nov`，故**静默误归因到已知根因的概率 ≤α_nov**。这是对第 65 轮"未知故障强行归类"的直接安全界：不保证能诊断未知，只保证**不会假装已经诊断**。

**定义 245（CSP-G 图一致规划）** 在 CSP 的层级 A* 上以块为边；技能 σ 绑定子图签名 `𝒟_σ`（对哪些根因敏感、期望证据轨迹、典型块签名）。规则：
- 块边需对**所有 S∈L** 有效且 `k*_join≥1`；
- 实际块子图签名到 `𝒟_σ` 的 Mahalanobis 距离>`τ_graph` ⇒ 判 OOD、不入图；
- 规划可在图中插入 `null_test`（零力窗，识别 `r_bias/r_drift`）、`visual_probe`（识别 `r_transparent/r_mirror/r_adv_patch`）、`confounder_cut`（打断 COMMON 边）、`fi_probe`（通用 AFA-G 判别）。
代价：`J = J_task + λ_fi·H(S|ρ) + λ_risk·max_{S∈L}risk_S + λ_k·Σ hinge(k_req−k*)`；因此当 L 很大、归因熵高时，规划器会主动选信息获取元技能来收缩 L，再把任务前缀放大——**探索与执行在同一张图上竞争，而非硬编码先后。**

**定义 246（AIC-G 结构/共因/并发对抗认证）** 干扰集
ℰ_G=ℰ_V×ℰ_struct×ℰ_common×ℰ_time。
- ℰ_struct：删边/加边/边权扰动/层间错连（图谱结构误设）；
- ℰ_common：**伪装成两独立故障的相关 OOD**（骗独立假设）、**伪装成共因的单点故障**（骗图模型）、共享父因的对抗样本；
- ℰ_time：块重放、时序错位、通信延迟、**线程快照撕裂/异步发布/版本回退**；
- ℰ_unknown：真未知根因（与 OGN 联动）。
在 ℰ_G 上重算 ρ_dir（n_cert 128→160，新增 32 用于结构/共因/并发）；`ρ_force` 在最坏偏置与最坏共因遮挡下取最坏；J_dir 增 `graph_ver`、`snapshot_ver`、`common_cause_cert`、`open_world_mass`、`thread_join_ms`。**共因与结构误设下不要求归因正确，只要求安全 join 仍成立（保守或 ambiguous→safe_idle）。**

**定义 247（CAIRN 证书 J_cairn）** 
J_cairn=(J_vista, graph_posterior, credible_set_hash, equiv_class_id, open_world_mass, confounder_coef, k*_join, snapshot_version, thread_join_ms, graph_ver, aic_g_ver)。
验证规则：
Valid(J_cairn) ⇔ Valid(J_vista)
∧ P(S_true∈L)≥1−δ_cred（可信集覆盖已校准）
∧ 所有存活线程在同一 snapshot_version 上认证且 join 原子完成（无 torn read）
∧ (k*_join≥1 ∨ 显式 safe_idle)
∧ 开放世界质量已处置（r_? 在 L 中已保守化，或 s_nov≤q_nov）
∧ (存在 COMMON 边冲突 ⇒ 已识别共因 ∨ 已按等价类联合膨胀)
∧ graph_ver、aic_g_ver 为当前版本。
审计链新增：**为何相信这个可信集**（credible_set_hash/覆盖）、**为何这些根因不可分**（equiv_class_id）、**是否可能存在没见过的原因**（open_world_mass）、**是否同源失效**（confounder_coef）、**认证读的是哪一版后验**（snapshot_version）。

**定义 248（CAIRN 闭环算子）** 见 IP-233 伪代码。
语义流：[LiDAR→LSF→USR/MEL→VPG→ACH 生成块→阶段切分→VCV→**CKG 更新→GFI 图推断→CCC 共因认证→可信集 L→AFA-G→RSC-G→CSP-G→CHT 派发→CSJ join→SAP 前缀**→Shield-Skill→OCB-Skill→执行 k*_join 步→EV_exec→OLP→DIR→SSB→AIC-G]。
实时流：[锚点读→视觉/力残差采集→阶段判定→**逐线程监控（O(|L|)）→join abort 标志→WCV-G 编译→π_σ 前缀派发→J_cairn 构建**]。
并发调度：MVCC 版本化黑板；线程读 v、写私有区、原子发布；join 门单快照读取并递增版本；超时→保守默认线程。

### IP-225 GFI（图故障推断）

```python
class GraphFaultInference:
    """CKG 上的后验推断：根因边际 + 共因后验 + 可信集 L。语义流；可并发。"""
    def __init__(self, ckg, lik, delta_cred=0.05, max_sets=64, bp_iters=8):
        self.G, self.lik = ckg, lik
        self.delta_cred, self.max_sets, self.bp_iters = delta_cred, max_sets, bp_iters

    def infer(self, rho, instruments=None):
        # 1) 因子图 loopy BP（含 COMMON 父因的 factor）
        marg_r = loopy_bp(self.G, self.lik, rho, iters=self.bp_iters)
        # 2) 枚举/采样高概率激活集，凑够 1-delta_cred 的可信覆盖
        sets = enumerate_or_sample_sets(marg_r, self.G, self.max_sets)
        post = normalize({S: self.lik.joint(rho, S) * self.G.prior(S) for S in sets})
        L = credible_cover(post, 1.0 - self.delta_cred)
        # 3) 不可辨识等价类必须整类并入（禁止 argmax 破平局）
        L |= self.G.equiv_classes(marg_r)
        # 4) 开放世界节点
        s_nov = self.G.novelty(rho)
        if s_nov > self.G.q_nov:
            L |= {'r_unknown'}
        return {'marg_r': marg_r, 'post': post, 'L': L,
                'common': self.G.common_posterior(marg_r, rho),
                'novelty': s_nov}

    def equiv_classes(self, marg_r):
        # d-分离：给定证据与可用干预下仍不可分的根因对 -> 并查集等价类
        return union_find(self.G.dsep_pairs(marg_r, interventions=self.G.available_probes()))
```

### IP-226 CCC（共因认证 / 工具变量）

```python
class CommonCauseCertifier:
    """用去激活探针当工具变量，辨识共享父因的 loading 比。"""
    def __init__(self, eps_iv=1e-6, gamma_thr=0.5, ratio_tol=0.25):
        self.eps_iv, self.gamma_thr, self.ratio_tol = eps_iv, gamma_thr, ratio_tol

    def identify(self, rho_a, rho_b, probe_before, probe_after):
        gamma = pearson(rho_a, rho_b)
        da = np.mean(rho_a) - np.mean(probe_before.a)   # 干预前后通道 a 变化
        db = np.mean(rho_b) - np.mean(probe_before.b)   # 干预前后通道 b 变化
        if abs(da) < self.eps_iv:
            return {'gamma': gamma, 'status': 'no_instrument'}   # 不可辨识 -> 联合膨胀
        ratio = db / da                                  # = beta/alpha
        ratio_ok = abs(ratio) > 0 and np.isfinite(ratio)
        verdict = 'common_cause' if (abs(gamma) >= self.gamma_thr and ratio_ok) \
                  else 'independent_or_directed'
        return {'gamma': gamma, 'loading_ratio': ratio,
                'status': verdict, 'instrument': probe_after.name}

    def joint_inflate_if_unidentified(self, status, balls, components):
        if status == 'no_instrument':
            for c in components:                        # 等价类联合膨胀
                balls[c] = expand(balls[c])
        return balls
```

### IP-227 AFA-G（图信息 / 混淆破除探针）

```python
class GraphActiveAttribution:
    PROBES = ('null_test', 'visual_probe', 'confounder_cut', 'press', 'rub', 'tap', 'lift')

    def choose_probe(self, post, L, G, phi_hat, f_safe, object_fragile):
        best, best_gain = None, -np.inf
        for a in self.PROBES:
            if object_fragile and a in ('press', 'rub', 'tap', 'lift'):
                continue
            traj = predict_probe_traj(a, phi_hat)
            if np.max(traj.f) > f_safe or np.max(traj.strain) > EPS_STRAIN:
                continue
            ig = expected_mutual_info(G, post, a)          # I(S_R; rho_new | do(a))
            sep = equiv_split_gain(L, G, a)                # 打断 COMMON/backdoor 的收益
            gain = ig + LAMBDA_SEP * sep
            if gain > best_gain:
                best, best_gain = a, gain
        if best_gain < DELTA_FI:
            return None, best_gain                          # 不冒险，保持保守
        return best, best_gain
```

### IP-228/229 CHT + CSJ + SAP（并发线程、join、推测式前缀）

```python
class ConcurrentHypothesisThreads:
    """版本化黑板 + 并行认证线程 + 并发安全 join。"""
    def __init__(self, scheduler, certifier, deadline_ms=20):
        self.sched, self.certifier, self.deadline = scheduler, certifier, deadline_ms

    def advance(self, L, obs, version):
        with self.blackboard.publish_snapshot(obs, version) as snap:
            futs = {S: self.sched.submit(self._certify_one, S, snap) for S in L}
            certs = []
            for S, fut in futs.items():
                try:
                    certs.append(fut.result(timeout=self.deadline / 1000))
                except TimeoutError:
                    certs.append(CONSERVATIVE_DEFAULT)      # k*=0, 最大球, invalid
            if not all(c.snapshot_version == version for c in certs):
                return JoinCert(valid=False, k_star=0,
                                reason='torn_read', version=version)
            return JoinCert(
                valid=all(c.valid for c in certs),
                k_star=min(c.k_star for c in certs),        # 全可信集安全
                margin=min(c.margin for c in certs),
                version=version)

    def _certify_one(self, S, snap):
        balls = rsc_g.allocate(S, snap.post)                # 图定向球
        return self.certifier.certify(S, balls, snap)


def speculative_prefix(policy, obs, join_system, m, alpha_chunk):
```

### IP-230 RSC-G（图定向球分配）

```python
def rsc_g_allocate(activation_set, post, G, balls, lam=1.0):
    """根因激活 -> 组件膨胀；等价类联合、可分收缩。"""
    inflate = defaultdict(float)
    for r in activation_set:
        for c in G.component_map[r]:                       # 根因 -> 物理组件
            inflate[c] += lam * post.get(r, 0.0)
    for c, amt in inflate.items():
        balls[c] = np.clip(balls0[c] * np.exp(amt), B_MIN, B_MAX)
    # 不可辨识等价类：其映射组件必须联合膨胀（不能只挑一个）
    for eq in G.equiv_classes_of(activation_set):
        comps = set().union(*(G.component_map[r] for r in eq))
        for c in comps:
            balls[c] = np.clip(balls[c] * KAPPA_JOINT, B_MIN, B_MAX)
    return balls
```

## 4. 推导

**引理 9（共因可辨识性 / 工具变量）** 设两通道线性 SEM `ρ_a=α c+ε_a, ρ_b=β c+ε_b`，`ε_a⊥ε_b⊥c`。
(i) 无干预时，观测协方差只给出 `Cov(ρ_a,ρ_b)=αβVar(c)`，以及边缘方差 `α²Var(c)+σ_a²`、`β²Var(c)+σ_b²`。三个方程含 `α,β,Var(c),σ_a²,σ_b²` 五个未知数，loading 比 β/α 不可辨识（只说"两通道相关"）。
(ii) 设存在去激活干预 z：干预只移除通道 a 对 c 的暴露、b 的暴露保持不变（如 null_test 让几何/视觉误差窗关闭、F/T 零偏保留）。干预前后差
`Δρ_a=α c`，`Δρ_b=β c` ⇒ `β/α=Δρ_b/Δρ_a`，
在 `Δρ_a≠0`（A97 工具有效性）下可辨识。进一步，若对两通道分别施加独立去激活干预，可得 α、β 各自（up to Var(c)），从而对 `Var(c)` 做约束。
(iii) 因此 `γ=corr(ρ_a,ρ_b)` 高且探针响应符合固定 loading 比 ⇒ 判共享父因；`γ` 高但只对单通道干预响应 ⇒ 判独立/单向因果。
故第 65 轮必须判 ambiguous 的共因，在 CKG+CCC 下可被归因为一个共享父节点，**前提是存在有效去激活干预**；无工具时按定义 238 归入等价类并联合膨胀。∎

**引理 10（可信集安全 / 并发 join 可靠性）** 设可信集 L 满足 `P(S_true∈L)≥1−δ_cred`（A95）。对每个 `S∈L`，`Cert_S(k)` 表示"在假设 S 下前 k 步所有安全通道 ρ_safe≥0 且越界概率 ≤α_chunk"；视觉 conformal 以 ≥1−α_vis 覆盖。若执行 `k*_join=min_{S∈L}k*_S` 步，则由联合界
P[越界] ≤ P(S_true∉L) + P(∃S∈L: Cert_S 失效) + α_vis
≤ δ_cred + α_chunk + α_vis。
关键点：该界**不含"归因是否正确"**。若后验点估计错，只要错误假设仍落在 L 内，join 仍然覆盖它，安全不受影响；错误归因的唯一后果是 L 偏大 → k* 偏小 → 更保守。只有当 L 不覆盖真值（模型/校准失效）时安全才被破坏，而那是被 A95 显式约束的量。∎

**引理 11（并发一致性与 anytime）** 设黑板保证每个线程读取不可变快照 v，join 门在一次原子读取中取得同一 v 的全部证书。则对固定 v：
`⋀_{S∈L_v}Cert_S(k)` 与"顺序逐个认证并取 min"逐元素等价，并发不改变 join 的结果，仅改变墙钟时间。若缺少版本校验，线程 T_{S1} 可能基于 v1 的 L 认证、T_{S2} 基于 v2 的 L 认证；join 得到的"可信集"是两次快照的并/交（取决于实现），可能既不覆盖 v1 也不覆盖 v2 的真值，使引理 10 的前提失效。因此 `snapshot_version` 的一致性必须写入 J_cairn 并在 join 时断言。截止期 τ 超时：未完成线程以保守默认 `S_⊥`（k*=0、最大球、invalid）替代，join 结果 `k*_join=0`，系统进入 safe_idle——**anytime 的代价是效率而非安全**。∎

**定理 9（CAIRN 端到端归因-安全）** 在 A94–A99 下：
1. **安全与归因解耦**：执行前缀由 `k*_join=min_{S∈L}k*_S` 决定，L 至少以 1−δ_cred 覆盖真值（引理 10）；因此错误归因至多降低 k*，不能造成越界。
2. **复合故障可表示**：CKG 的激活集后验覆盖单/多根因组合；第 65 轮单标签 ℋ 是"根因两两互斥且最多激活一个"的退化图。
3. **共因可识别或安全联合**：有有效去激活探针时由引理 9 识别共享父因；无工具时由定义 238 归入等价类并联合膨胀（定义 243），**绝不错误拆分到单一球**。
4. **未知不静默误归因**：由定义 244，`P(r_?∈L)≥1−α_nov`，未知样本进入 unknown mode 并被保守化；不保证诊断未知，只保证不假装诊断。
5. **并发可靠**：由引理 11，快照一致时并发 join=顺序 join；torn read 被 J_cairn 拒绝并回退保守。
6. **降级链**：视觉失效→w_vis↓、退回 GRIP；F/T 失效→GFI 上调 r_bias 路径、视觉/几何主导；图结构可疑（结构新奇）→ r_? 或 graph_ver 失配→保守；并发超时→k*=0 safe_idle。
7. **实时性**：语义流承担图推断/共因/并发调度；实时流只加逐线程监控与 join（O(|L|)，|L|≤4），≤2.5ms（A99）。∎

**定理 10（效率单调性与并发加速）** 由定义 241，`k*_join(L)=min_{S∈L}k*_S`，故 `L'⊆L ⇒ k*_join(L')≥k*_join(L)`：后验越集中、可信集越小、可执行前缀越长。设单线程认证耗时 t_c，核心数 C，则语义拍时延 `T(L)≤ceil(|L|/C)·t_c`；当 |L|≤C 时 `T` 近似常数，且高风险高后验线程优先完成可进一步降低"达到 k* 的期望时间"。因此 CAIRN 在保持安全的同时，期望进度不低于第 65 轮（后者用 top-2 截断近似，CAIRN 用完整可信集但不放弃效率）。∎

**命题（共因：模糊 → 可辨识）** 设真实分布 p_true 含共享父因 c（故 `I(ρ_a;ρ_b)>0`），而第 65 轮扁平模型强制 `p_flat(ρ)=p(ρ_a)p(ρ_b)·p(其余)`。则
`D_KL(p_true‖p_flat)=I(ρ_a;ρ_b)>0`，
即扁平模型在共因样本上的似然**系统性错配**，其后验无法收敛到"一个正确标签"，只能表现为高熵/ambiguous。CKG 在 p_true 的图结构正确时（A94）包含该共享父因，模型族覆盖 p_true（该方向 KL=0 的下界可达），故其后验可集中到 c。**"模糊"是错误假设空间的产物，而不是数据本身的固有属性**——这正是第 65 轮"有限假设集固有缺陷"的严格表述与修复。∎

**命题（图 vs 扁平的过度保守）** 第 65 轮在无法区分 `H_geo/H_force` 时对单一球联合膨胀，几何分量体积膨胀 `κ_infl^{d_φ}`。CAIRN 在等价类 `E_eq={r_geo-side,r_force-side}` 下只对**映射组件集合**联合膨胀；d-分离的第三组件（如 `b_vis`）保持标定值。若可辨识分量维数为 d_sep，则搜索域体积相对第 65 轮缩小 `κ_infl^{d_sep}`。当 AFA-G 打断 COMMON/backdoor 后 E_eq 收缩，进一步把膨胀退回最小。∎

## 7. 已知风险

**一句话**：CAIRN 的正确性依赖「因果图谱结构近似正确（A94）」与「并发线程在同一版本快照上认证（A96）」这两个假设；一旦图谱漏掉真实共因（结构误设）或后验快照被并发撕裂，「对整簇可信假设的安全 join」就退化为「对错误可信集的安全」——第 65 轮的「归因错误」由此升级为「**认证与归因不同步**」，而且并发越快、系统越自信。

**次级风险与缓解**：
1. **结构误设（缺 COMMON 边）**：最危险，等价于退回独立假设；缓解：AIC-G 结构扰动认证、graph_ver 校验、结构新奇度并入 r_?、结构置信度低于阈值时强制联合膨胀。
2. **并发撕裂 / 版本回退**：认证读到过期可信集；缓解：MVCC + join 前 snapshot_version 断言 + 版本单调递增 + 超时保守默认；J_cairn 拒绝 torn read。
3. **可信集覆盖在分布漂移下失准**：δ_cred 名不副实；缓解：自适应 conformal（ACI）、漂移检测触发重校准、把覆盖失败计入 AIC-G。
4. **激活集组合爆炸**：可信覆盖被截断破坏；缓解：可信覆盖按质量而非 top-k 选取、变分下界、截断质量计入保守默认（S_⊥）。
5. **工具变量不可得**（易损物体不能接触、透明下 visual_probe 也失效）：无法辨识共因；缓解：退化为等价类联合膨胀（安全但保守），并显式记录 `no_instrument`。
6. **开放世界阈值误判**：r_? 过敏导致长期 safe_idle，或迟钝导致静默误归因；缓解：分层 q_nov、人类接管通道、未知样本回流扩充图谱。
7. **并发资源竞争导致截止期频繁超时**：安全但吞吐差；缓解：风险优先调度、线程池上限、把低风险假设降级为解析近似。
8. **图谱构建与维护成本 / 域漂移**：边与 Θ 过时；缓解：版本化图谱、在线边权更新只在语义流、定期注入再认证。
9. **A94–A99 一旦被违反**：定理 9 的保证失效；缓解：J_cairn 显式记录各假设的验证状态，任一失配即降级为 VISTA/GRIP 的保守模式。
