# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「实时控制」×「运动学」）

> 第 66 轮 RAS 把闭环从「被动故障响应」升级为「主动意图感知」，用 `λ_risk` 把情绪/风险压进控制指令。但 RAS 的作用点选错了轴：它用**标量 λ 缩放力矩幅值**，却在**时间维度**上仍按固定块节拍执行。实时控制的第一性事实是「安全是路径-时间耦合的」——同一条几何路径，慢速安全、快速越界。运动学的第一性事实是「约束作用在构型/速度/雅可比上，而不作用在力矩幅值上」。因此：
>
> **本轮命题：把「幅值风险缩放」升级为「时间风险膨胀」，把「块级认证前缀」升级为「带截止时间与新鲜度的运动学管（kinodynamic tube）」——KAIROS：Kinodynamic-Aware Intention-Responsive Real-time Operation Shield。**
>
> KAIROS 问的不再是「控制多少（λ）」，而是「**在什么时间窗内、沿哪条运动学同伦分支、以多快的重参数化执行，且证书是否仍然新鲜**」。它把 RAS 的「语义-安全」两件事拆成两率架构：慢语义层签发**运动学管 + 带过期时间的证书**，快实时层用 CBF-QP 盾以 1kHz 把指令投影回管内。

## 0. 直觉与动机

**灵感 1（实时控制 → 证书必须有截止时间和新鲜度）**
直觉：RAS 的 `k*RAS` 是一个「块数」，不是一个「时长」。实时系统里，一个没有 WCET、没有 jitter、没有有效期的证书等于没有证书。若语义层在 `t_issue` 签发「前 k 块安全」，而执行到第 k 块时语义层已超时 200ms，执行层仍在消费一个**过期结论**——这是实时控制的典型 stale-certificate 事故。
把证书从「块数」升级为「`(k, T_k, t_exp, WCET, jitter)` 五元组」，是实时控制视角带来的第一个结构性修正。

**灵感 2（运动学 → 风险应作用于时间轴，而非幅值轴）**
直觉：把 τ 乘 `λ` 只改了「推多用力」，没改「走多快、经过哪些构型」。而危险恰恰常来自后者：接近奇异点时速度不降，可操作度 `μ(q)` 掉到阈值以下；关节速度在高速段饱和。**时间膨胀** `ρ ≥ 1`（`ds/dt` 除以 ρ）保持路径几何与同伦类不变，只把速度、加速度裕度按 `1/ρ`、`1/ρ²` 放大——这是一个**与几何证书可交换**的操作；幅值缩放不是。

**灵感 3（运动学 → 奇异点不是「慢一点」能解决的）**
直觉：如果路径本身穿越奇异点，任何 ρ 都无法让 `σ_min(J(ξ(s))) ≥ σ_min0`。此时必须换**运动学同伦分支**（如肘上/肘下、冗余零空间重构），或在进入不可行区域前破块重规划。这让 ACH 的「动作块」获得一个新的身份：**块不仅是一条几何轨迹，还携带一个同伦类标签**。

**灵感 4（实时控制 × 运动学 → 两率架构：管道 + 盾）**
直觉：语义层再快也只有 10~30Hz，实时层必须 1kHz。二者不能强行同频。正确分工是：慢层签发**一个非空的运动学管**（状态可行域 + 不变式裕度），快层用 CBF-QP 把任意参考指令**投影**回管内；只要管非空且盾的 WCET 小于周期，约束就逐点成立。证书的职责从「证明指令安全」降为「证明盾可行」。

**灵感 5（安全单调性 → 情绪只能减速，不能加速）**
直觉：RAS 允许 `λ_risk ∈ (0.5, 1.2)`，其中 `>1` 是「放宽」。这是危险的：假笑、僵硬表情、遮挡伪造出的「安全」会把真实几何故障放行。KAIROS 强制 `ρ ∈ [1, ρ_max]`：**风险/情绪只能增加时间膨胀（减速），永远不能把速度提到名义值以上**。于是情绪欺骗的最坏后果被压缩为「该减速时没减速」，而名义速度仍被 VISTA/RAS 证书覆盖——RAS 的最大风险被**从设计上**消除，而非靠额外检测补救。

**灵感 6（实时控制 → 不可行时的确定性回退）**
直觉：任何在线优化都可能 infeasible。实时控制要求回退也是可证的：引入**可生存核** `V = {x : T_stop(x) ≤ D_react(x)}`，其中 `T_stop` 是在 `q̈ ≤ a_max` 下的最小制动时间。只要管始终位于 `V` 内，任何时刻切换为制动都可在预算内停下。这把「降级」从启发式（RAS 的降力限）变成**可生存性约束**。

## 1. 形式化定义（增量：定义 251–261）

- **定义 251（KAIROS 总览）**：`KAIROS = (KTE, KTP, VK, DCR, RTS, ESF, KHS, KCV)`。定位：RAS 的「幅值风险缩放」升级为「时间膨胀 + 运动学管 + 实时盾」。不变式：慢语义层只签发「管 + 带过期时间的证书」，不做高频控制；快实时层只做投影与制动，零学习写操作；**任何情绪信号都不能把执行速度提高到名义速度以上**。
- **定义 252（运动学状态与路径）**：构型空间 `Q ⊆ ℝⁿ`（n 自由度），`q ∈ Q`，`q̇, q̈ ∈ ℝⁿ`。路径 `ξ: [0,1] → Q` 为 C² 正则曲线（`ξ'(s) ≠ 0`）；时间参数化 `s: [t₀,t₁] → [0,1]` 严格单调、C²。`q(t)=ξ(s(t))`，`q̇=ξ'(s)ṡ`，`q̈=ξ''(s)ṡ²+ξ'(s)s̈`。
- **定义 253（运动学可行包络）**：给定路径 ξ，其可行速度剖面集合
  `K(ξ) = { ṡ : ∀s, q̇=ξ'(s)ṡ ∈ [q̇⁻,q̇⁺], q̈=ξ''(s)ṡ²+ξ'(s)s̈ ∈ [q̈⁻,q̈⁺], μ(ξ(s)) ≥ μ_min, σ_min(J(ξ(s))) ≥ σ₀, dist(ξ(s), O) ≥ d_min, |τ̇| ≤ τ̇_max }`。
  其中 `μ(q)=√det(JJᵀ)` 为可操作度，`σ_min` 为雅可比最小奇异值，`O` 为障碍集。
- **定义 254（风险时间膨胀）**：膨胀因子
  `ρ(t) = 1 + κ_R·R_emotion(t) + κ_F·(1−face_quality(t)) + κ_S·(1−μ(q)/μ_nom) + κ_D·(1−slack(t)/slack₀)`，
  约束 `ρ ∈ [1, ρ_max]`。名义调度 `s_nom(t)` 的膨胀调度满足 `ds_ρ/dt = (ds_nom/dt)/ρ`，时长 `T_ρ = ∫ρ dt`。**关键：ρ 只作用在时间轴，不改变 ξ 与力矩方向。**
- **定义 255（运动学管）**：围绕 ξ 的时变管
  `T = { (q,q̇,t) : q=ξ(s_ρ(t))+e, ‖e‖ ≤ ε_pos(s), q̇=ξ'(s_ρ(t))ṡ_ρ+e_v, ‖e_v‖ ≤ ε_vel(s), s_ρ(t)∈[0,1] }`，并要求 `T ⊆` 定义 253 的硬约束集。管的有效视界 `h = t₁−t₀`。
- **定义 256（可生存核与制动时间）**：`T_stop(x)` 为从状态 x 出发、在 `|q̈|≤a_max` 与 `|q̇|≤q̇⁺` 下到达静止的最短时间（沿最短可行制动路径）。可生存核 `V = { x : T_stop(x) ≤ D_react(x) }`，`D_react(x)` 为由障碍距离/任务时序导出的允许反应时间。要求 `T(t) ⊆ V`。
- **定义 257（截止时间认证区域 DCR）**：认证区域
  `k*_K = max { k : RAS-certified(k) ∧ ∃ρ∈[1,ρ_max], K(ξ_{[0,k]})≠∅ ∧ T_ρ(k)+WCET_sem+J_sem ≤ D_react ∧ h_k ≥ T_ρ(k) ∧ now < t_exp(k) }`。
  与 RAS 的 `k*RAS`（纯块数）不同，`k*_K` 同时认证**时长、截止时间与新鲜度**。
- **定义 258（实时盾 RTS）**：以周期 `T_r` 求解
  `u* = argmin_u ‖u−u_ref‖²` s.t. `L_f h_i(x)+L_g h_i(x)u ≥ −α_i h_i(x)`（关节/速度/加速度/奇异值/碰撞/管成员 CBF 约束）。若 QP 不可行，切换到由定义 256 保证的制动控制器 `u_stop`。
- **定义 259（陈旧性作为一阶故障）**：设证书签发时刻 `t_issue`、过期时刻 `t_exp = t_issue + T_ρ(k) + δ_jitter`。新鲜谓词 `Fresh(t) ⇔ t < t_exp ∧ semantic_loop_not_overrun(t)`。新增故障假设 `H_stale`（语义超时/证书过期），`¬Fresh ⇒` RTS 收缩到 `ρ=ρ_max` 的最保守管，并在需要时制动。**过期证书绝不允许被执行。**
- **定义 260（运动学同伦切换 KHS）**：块 A 携带同伦类标签 `[ξ] ∈ π₁(Q_free)`。若 `K(ξ)=∅` 对任意 ρ 成立（结构性不可行，如穿越奇异点），则在进入不可行区前选择同伦替代 `ξ' ∈ [ξ'] ≠ [ξ]`（同一端点约束），或触发 ACH 破块重规划；切换只允许发生在零空间可重构的安全窗口。
- **定义 261（J_KAIROS 证书）**：`J_KAIROS = (J_RAS, ρ, tube_id, μ_min^obs, σ_min^obs, WCET_sem, J_sem, t_exp, shield_feasible, homotopy_tag)`。`Valid ⇔ Valid(J_RAS) ∧ t < t_exp ∧ ρ∈[1,ρ_max] ∧ T≠∅ ∧ shield_feasible ∧ T⊆V`。

## 2. 关键算法骨架

```python
# KTE：把动作块提升为运动学管
class KinodynamicTubeEnvelope:
    def build(self, A, q0, qd0):
        xi = fit_path(A)                      # ξ: [0,1] -> Q
        S = sample_s(xi, N_s)
        mu = [manipulability(J(xi[s])) for s in S]
        smin = [min_singular_value(J(xi[s])) for s in S]
        if min(mu) < self.mu_min or min(smin) < self.sigma0:
            return None                       # 结构性不可行 -> KHS
        eps_pos, eps_vel = self._margin(S, qd0)
        return Tube(xi, S, eps_pos, eps_vel, mu, smin)


# KTP：风险只做时间膨胀，rho >= 1
class KinematicTimeParameterizer:
    def dilate(self, s_nom, R_emotion, face_quality, mu, slack):
        rho = 1 + self.kR*R_emotion + self.kF*(1-face_quality) \
                + self.kS*(1-mu/self.mu_nom) + self.kD*(1-slack/self.slack0)
        rho = max(1.0, min(self.rho_max, rho))   # 只能减速
        return lambda t: s_nom(t / rho), rho


# VK + DCR：截止时间/可生存性认证
class DeadlineCertifiedRegion:
    def certify(self, A, tube, rho, t_issue):
        T_rho = duration(tube.xi, rho)
        t_exp = t_issue + T_rho + self.jitter
        if T_rho + self.wcet_sem + self.jitter > self.D_react: return 0
        if not subset(tube, self.V): return 0
        if not (tube.h >= T_rho and now() < t_exp): return 0
        return certified_prefix_ras(A, tube, rho, t_exp)


# RTS：1kHz CBF-QP 盾
class RealTimeShield:
    def step(self, x, u_ref, tube):
        cons = cbf_constraints(x, tube)       # 关节/速度/奇异/碰撞/管成员
        u = solve_qp(u_ref, cons)             # OSQP, warm start
        if u is None:
            u = self.stop_controller(x)       # 由可生存核保证可行
        return u


# KAIROS 闭环
def KAIROS_round(M, obs):
    V, Tq, P, L, P_cloud, W, tactile, img, depth, flow = obs
    x = M.estimator.state()                                   # (q, qd)
    face = M.er.recognize(img)                                # RAS 情绪网关
    A = M.vista.ach.propose(M.lsf.fuse(M.usr.fuse(V,Tq,P,L)))

    tube = M.kte.build(A, x.q, x.qd)
    if tube is None:                                          # 结构性不可行
        branch = M.khs.switch(A, x)                           # 运动学同伦切换
        tube = M.kte.build(branch, x.q, x.qd)

    rho = M.ktp.plan(tube, face)                              # rho >= 1
    k = M.dcr.certify(A, tube, rho, t_issue=now())            # 含截止/新鲜度
    if k == 0 or not M.fresh(now()):                          # 陈旧/不可行
        return M.rts.stop(x)

    while not chunk_done(A[:k]):
        u_ref = M.pi_sigma.dispatch(A[:k], x)
        u = M.rts.step(x, u_ref, tube)                        # 1kHz 投影
        M.actuator.send(u)
        x = M.estimator.state()
        if not M.fresh(now()):                                # 事件触发重认证
            rho = M.rho_max
            if not M.rts.feasible(x, tube): return M.rts.stop(x)
    return k, rho, tube.id, M.kcv.issue(...)
```

## 3. 推导

**引理 11（膨胀-证书可交换）** 设几何证书 `C_geo(ξ)` 仅依赖构型序列（关节限位、碰撞、`μ(ξ(s))`、`σ_min(J(ξ(s)))`）。对任意 `ρ ≥ 1` 的时间膨胀 `D_ρ`，有 `C_geo(D_ρ ξ) = C_geo(ξ)`；且速度裕度按 `1/ρ` 增大、加速度裕度按 `1/ρ²` 增大。相反，幅值缩放 `A_λ: τ ↦ λτ` 下 `q̈(λ)=M⁻¹(λτ−Cq̇−g)=λq̈(1)+(λ−1)M⁻¹(Cq̇+g)`，科氏/重力项不同比例缩放，故一般 `C_geo(A_λ ξ) ≠ A_λ C_geo(ξ)`。**结论：RAS 的 λ 缩放会破坏几何证书；KAIROS 的 ρ 膨胀保持它。**

**引理 12（单边风险单调性）** 在 `ρ∈[1,ρ_max]` 下，对任意 `R_emotion∈[0,1]`、`face_quality∈[0,1]`，有 `ρ ≥ 1` 且 `ρ` 关于风险非减、关于面部质量非增。因此执行速度 `v_ρ = ṡ_nom/ρ ≤ ṡ_nom`。若情绪被欺骗为「安全」（`R_emotion→0`、`face_quality→1`），最坏只恢复到 `ρ=1` 的名义速度；而名义速度已被 VISTA/RAS 证书覆盖。**RAS 的「过度放宽」在该参数化下不可达。**

**定理 11（截止时间-动力学可靠性）** 在 (A1) 运动学模型精确、(A2) `WCET_sem` 与 jitter 上界成立、(A3) 可生存核 `V` 由 `T_stop` 精确计算 下，若 DCR 返回 `k*_K>0` 且盾的 `WCET_shield ≤ T_r`，则对 `t∈[t_issue, t_exp]`：
1. 所有硬运动学约束（关节/速度/加速度/奇异值/碰撞）逐点成立；
2. 若语义层在任意 `t` 变为陈旧，盾的制动回退在 `t + D_react` 前使系统静止；
3. 任何过期 epoch 的指令都不会被执行。
证明要点：KTE 保证 `T ⊆` 约束集；CBF-QP 是到可行输入集的正交投影，保持前向不变性；`T ⊆ V` 保证制动回退可行；ESF 的新鲜谓词在消费前拦截过期证书；三者复合即得。

**定理 12（两率跟踪界）** 若盾对管的跟踪 Lipschitz 常数为 `L`、语义刷新误差为 `δ = WCET_sem + J_sem`，则相对管中心的偏差 `≤ L·δ`。DCR 中令 `ε_pos(s) ≥ L·δ`，即可保证管跟踪。该不等式给出「语义抖动」到「管裕度」的设计换算。

## 6. 本轮最大风险

**一句话**：KAIROS 的「管 + 盾」可靠性完全建立在**运动学/动力学模型精确**与**WCET/jitter 上界成立**这两个假设上；一旦负载变化、摩擦/间隙未建模，或嵌入式计算被共享调度挤占导致盾超时，所谓「可证安全的管」会退化为「迟到的刹车」——模型失配与实时可调度性假设，是整套两率架构的单一命门。

**次级风险与缓解**：
1. **时间膨胀无法修复路径级不可行**：奇异/碰撞是几何性质，减速无效 → 必须 KHS 同伦切换或破块重规划，切换代价可能高；
2. **管的保守性损失吞吐**：为满足 `T ⊆ V` 与 `ε_pos ≥ Lδ`，管会偏窄，导致频繁重认证 → 用自适应裕度与惰性认证；
3. **QP 在极限附近 infeasible**：CBF 约束可能互斥 → 分层软化约束（硬约束优先：关节/碰撞；软约束：任务跟踪）；
4. **同伦切换的时序安全**：切换只能在零空间安全窗口发生，窗口检测本身有延迟 → 预留切换前的制动余量；
5. **情绪噪声仍在**：但已被降级为「少减速」而非「过度放宽」，影响有界。

# 第 67 轮产物 · 创新点清单 v1：KAIROS（Kinodynamic-Aware Intention-Responsive Real-time Operation Shield：实时控制 × 运动学驱动的闭环；KTE×KTP×VK×DCR×RTS×ESF×KHS×KCV）

> 承接第 66 轮 IP-224~233（RAS：情绪驱动闭环）。第 66 轮解决了「谁控制、控制多少」，但它的风险缩放 `λ_risk` 作用在**力矩幅值轴**，且认证前缀 `k*RAS` 只是一个**块数**——没有截止时间、没有 WCET、没有新鲜度。本轮从「实时控制」与「运动学」出发，把闭环修正为**时间轴上的风险膨胀 + 带过期时间的运动学管 + 1kHz 实时盾**。
>
> IP 编号：IP-234~IP-243（共 10 个），全部为 KAIROS 的核心组件。

## 2. 形式化定义（完整版）

**定义 251（KAIROS 总览）** `KAIROS = (KTE, KTP, VK, DCR, RTS, ESF, KHS, KCV)`。不变式：慢语义层只签发「管 + 带过期时间的证书」，不做高频控制；快实时层只做投影与制动，零学习写操作；任何情绪信号都不能把执行速度提高到名义速度以上。

**定义 252（运动学状态与路径）** `q(t)=ξ(s(t))`，`q̇=ξ'(s)ṡ`，`q̈=ξ''(s)ṡ²+ξ'(s)s̈`，其中 `ξ` 为 C² 正则路径，`s(t)` 为严格单调 C² 时间参数化。

**定义 253（运动学可行包络）**
```
K(ξ) = { ṡ : q̇=ξ'(s)ṡ ∈ [q̇⁻,q̇⁺],
              q̈=ξ''(s)ṡ²+ξ'(s)s̈ ∈ [q̈⁻,q̈⁺],
              μ(ξ(s)) ≥ μ_min, σ_min(J(ξ(s))) ≥ σ₀,
              dist(ξ(s), O) ≥ d_min, |τ̇| ≤ τ̇_max }
```

**定义 254（风险时间膨胀）**
```
ρ(t) = 1 + κ_R·R_emotion(t) + κ_F·(1−face_quality(t))
         + κ_S·(1−μ(q)/μ_nom) + κ_D·(1−slack(t)/slack₀),   ρ ∈ [1, ρ_max]
ds_ρ/dt = (ds_nom/dt)/ρ
```
注意：ρ 只改变时间轴，不改变路径 ξ，也不缩放力矩方向。

**定义 255（运动学管）**
```
T = { (q,q̇,t) : q=ξ(s_ρ(t))+e, ‖e‖ ≤ ε_pos(s),
                q̇=ξ'(s_ρ(t))ṡ_ρ+e_v, ‖e_v‖ ≤ ε_vel(s), s_ρ(t)∈[0,1] }
```
并要求 `T ⊆` 定义 253 的硬约束集；有效视界 `h=t₁−t₀`。

**定义 256（可生存核与制动时间）**
```
T_stop(x) = min{ t : ∃u(·), |q̈|≤a_max, |q̇|≤q̇⁺, x(t)=静止 }
V = { x : T_stop(x) ≤ D_react(x) }
```
要求 `T(t) ⊆ V`。

**定义 257（截止时间认证区域 DCR）**
```
k*_K = max { k : RAS-certified(k)
                ∧ ∃ρ∈[1,ρ_max], K(ξ_{[0,k]}) ≠ ∅
                ∧ T_ρ(k) + WCET_sem + J_sem ≤ D_react
                ∧ h_k ≥ T_ρ(k)
                ∧ now < t_exp(k) }
```

**定义 258（实时盾 RTS）**
```
u* = argmin_u ‖u−u_ref‖²
     s.t. L_f h_i(x) + L_g h_i(x)u ≥ −α_i h_i(x),  ∀i
```
约束含关节/速度/加速度/奇异值/碰撞/管成员；infeasible 时切换 `u_stop`。

**定义 259（陈旧性作为一阶故障）** `t_exp = t_issue + T_ρ(k) + δ_jitter`；
```
Fresh(t) ⇔ t < t_exp ∧ semantic_loop_not_overrun(t)
¬Fresh(t) ⇒ ρ := ρ_max ∧ 必要时 u := u_stop
```
新增故障假设 `H_stale`；过期 epoch 的指令零执行。

**定义 260（运动学同伦切换 KHS）** 块携带 `[ξ] ∈ π₁(Q_free)`。若 `∀ρ, K(ξ)=∅`，则选择 `ξ' ∉ [ξ]`（端点约束相同）或在进入不可行区前破块重规划；切换只允许发生在零空间可重构的安全窗口。

**定义 261（J_KAIROS 证书）**
```
J_KAIROS = (J_RAS, ρ, tube_id, μ_min^obs, σ_min^obs,
            WCET_sem, J_sem, t_exp, shield_feasible, homotopy_tag)
Valid ⇔ Valid(J_RAS) ∧ t < t_exp ∧ ρ∈[1,ρ_max]
        ∧ T≠∅ ∧ shield_feasible ∧ T⊆V
```

## 3. 关键算法伪代码

```python
# IP-234 KTE
class KinodynamicTubeEnvelope:
    def build(self, A, q0, qd0):
        xi = fit_path(A)
        S = sample_s(xi, self.N_s)
        mu  = [manipulability(self.J(xi[s])) for s in S]
        smin = [min_singular_value(self.J(xi[s])) for s in S]
        if min(mu) < self.mu_min or min(smin) < self.sigma0:
            return None                              # -> KHS
        eps_pos, eps_vel = self._margin(S, qd0)
        return Tube(xi, S, eps_pos, eps_vel, mu, smin)


# IP-235 KTP
class KinematicTimeParameterizer:
    def plan(self, tube, face):
        R = face['risk']; fq = face.get('face_quality', 1.0)
        mu = min(tube.mu); slack = self.slack(tube)
        rho = (1 + self.kR*R + self.kF*(1-fq)
                 + self.kS*(1-mu/self.mu_nom)
                 + self.kD*(1-slack/self.slack0))
        rho = max(1.0, min(self.rho_max, rho))       # 只能减速
        tube.set_rho(rho)
        return rho


# IP-236/237 VK + DCR
class DeadlineCertifiedRegion:
    def certify(self, A, tube, rho, t_issue):
        T_rho = duration(tube.xi, rho)
        t_exp = t_issue + T_rho + self.jitter
        if T_rho + self.wcet_sem + self.jitter > self.D_react: return 0, t_exp
        if not subset(tube, self.V): return 0, t_exp
        if tube.h < T_rho or now() >= t_exp: return 0, t_exp
        return certified_prefix_ras(A, tube, rho, t_exp), t_exp


# IP-238 RTS
class RealTimeShield:
    def step(self, x, u_ref, tube):
        cons = cbf_constraints(x, tube)
        u = solve_qp(u_ref, cons)                    # OSQP, warm start
        if u is None:
            u = self.stop_controller(x)              # 由 V 保证可行
        return u


# IP-243 KAIROS 两率闭环
def KAIROS_round(M, obs):
    V, Tq, P, L, P_cloud, W, tactile, img, depth, flow = obs
    x = M.estimator.state()
    face = M.er.recognize(img)
    A = M.vista.ach.propose(M.lsf.fuse(M.usr.fuse(V, Tq, P, L)))

    tube = M.kte.build(A, x.q, x.qd)
    if tube is None:                                 # 结构性不可行
        A = M.khs.switch(A, x)
        tube = M.kte.build(A, x.q, x.qd)

    rho = M.ktp.plan(tube, face)
    t_issue = now()
    k, t_exp = M.dcr.certify(A, tube, rho, t_issue)
    if k == 0 or not M.fresh(t_issue):
        return M.rts.stop(x)

    while not chunk_done(A[:k]):
        u_ref = M.pi_sigma.dispatch(A[:k], x)
        u = M.rts.step(x, u_ref, tube)
        M.actuator.send(u)
        x = M.estimator.state()
        if not M.fresh(now()):                       # 事件触发重认证
            rho = M.rho_max
            tube.set_rho(rho)
            if not M.rts.feasible(x, tube):
                return M.rts.stop(x)
    return k, rho, tube.id, M.kcv.issue(t_exp, tube)
```

## 4. 推导

**引理 11（膨胀-证书可交换）** 对仅依赖构型的几何证书 `C_geo(ξ)`，任意 `ρ≥1` 的时间膨胀满足 `C_geo(D_ρ ξ)=C_geo(ξ)`；速度裕度按 `1/ρ`、加速度裕度按 `1/ρ²` 放大。幅值缩放 `A_λ` 下 `q̈(λ)=λq̈(1)+(λ−1)M⁻¹(Cq̇+g)`，科氏/重力项不同比例缩放，故一般 `C_geo(A_λ ξ) ≠ A_λ C_geo(ξ)`。**RAS 的 λ 缩放破坏几何证书；KAIROS 的 ρ 膨胀保持它。**

**引理 12（单边风险单调性）** `ρ∈[1,ρ_max]` ⇒ `v_ρ=ṡ_nom/ρ ≤ ṡ_nom`；情绪欺骗（`R→0, fq→1`）最坏只恢复到 `ρ=1` 的名义速度，而该速度仍被 VISTA/RAS 证书覆盖。**「过度放宽」不可达。**

**定理 11（截止时间-动力学可靠性）** 在 (A1) 运动学模型精确、(A2) `WCET_sem`/jitter 上界成立、(A3) `V` 由 `T_stop` 精确计算 下，若 `k*_K>0` 且 `WCET_shield ≤ T_r`，则对 `t∈[t_issue,t_exp]`：硬约束逐点成立；语义陈旧时制动在 `t+D_react` 前完成；过期指令零执行。证明要点：KTE 保证 `T⊆约束集`，CBF-QP 保持前向不变性，`T⊆V` 保证制动可行，ESF 拦截过期证书。

**定理 12（两率跟踪界）** 盾跟踪 Lipschitz 常数 `L`、语义刷新误差 `δ=WCET_sem+J_sem` ⇒ 偏差 `≤ Lδ`。DCR 取 `ε_pos(s) ≥ Lδ` 即保证管跟踪，给出「语义抖动 → 管裕度」的设计换算。

## 6. 本轮最大风险

**一句话**：KAIROS 的「管 + 盾」可靠性完全建立在**运动学/动力学模型精确**与**WCET/jitter 上界成立**这两个假设上；一旦负载变化、摩擦/间隙未建模，或嵌入式计算被共享调度挤占导致盾超时，所谓「可证安全的管」会退化为「迟到的刹车」——模型失配与实时可调度性假设，是整套两率架构的单一命门。

**次级风险与缓解**：
1. **时间膨胀无法修复路径级不可行**：奇异/碰撞是几何性质，减速无效 → KHS 同伦切换或破块重规划；
2. **管的保守性损失吞吐**：`T⊆V` 与 `ε_pos ≥ Lδ` 使管偏窄 → 自适应裕度 + 惰性认证；
3. **QP 极限附近 infeasible**：CBF 约束互斥 → 分层软化（关节/碰撞为硬约束，任务跟踪为软约束）；
4. **同伦切换的时序安全**：只在零空间安全窗口切换，预留切换前制动余量；
5. **情绪噪声仍在**：已降级为「少减速」而非「过度放宽」，影响有界。
