# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；新一轮灵感循环第 1 轮；本轮灵感：「人形机器人」×「故障诊断」）

> 前 54 轮已把技能表示为动作空间剖面 α_S、鲁棒性谱 ρ、组合证书 C_comp 与云边联合证书 J。本轮引入「人形机器人」与「故障诊断」。核心矛盾：**H22：故障不是部件级标签，而是作用在动作空间与鲁棒性谱上的一个收缩算子 Φ_f；故障前后同一技能的证书会在边端静默失效。H23：人形机器人高自由度、欠驱动、接触频繁切换，故障表现为动作空间局部坍缩 + 平衡鲁棒性骤降，传统 FDI 的“换件式”诊断无法直接指导技能重组与降级决策。**

## 0. 直觉与动机

**灵感 1（故障 = 动作空间收缩算子）**
直觉：关节电机失效、编码器偏置、足端打滑，本质上都是“某些动作再也做不出来、另一些动作做出来也不可靠”。因此把故障 f 写成算子 `Φ_f = (C_f, Δρ_f)`：`C_f: A → 2^A` 把原动作空间收缩成可行子集，`Δρ_f` 沿鲁棒性维度扣分。诊断不再只输出一个故障名，而是**估计当前动作空间被谁、按什么模式收缩了多少**。这直接复用第 54 轮的 α_S 与 ρ，不需要另起一套表示。

**灵感 2（证书即观测模型：用证书失效做残差）**
直觉：第 54 轮的联合证书 J 承诺了 `A_core` 的覆盖与 `ρ ≥ ρ_min`。若机器人真实执行时出现“证书说能做、实际做不到”，这个**承诺-观测差**就是天然残差。于是故障诊断变成：持续监测证书不变量 `(cover, ρ, δ_a)`，把违反模式与故障假设的预测签名匹配。诊断器不必依赖额外黑箱分类器，而是**复用证书作为物理一致的观测模型**，诊断结论也天然可回传到解释信道。

**灵感 3（动作空间层析：安全约束下的主动隔离）**
直觉：被动残差常在故障初期不可分（多个故障都表现为“右腿有点软”）。可以在**已认证安全集**内主动施加一组探测动作，让不同故障的收缩模式在动作空间上“显影”——类似医学层析，用不同角度投影重建病灶。硬约束是每条探测动作必须先落在 `A_safe` 内，绝不能用“跳一下看看会不会摔”来诊断。这把主动故障诊断从“信息增益最大化”变成“**安全约束下的信息增益最大化**”。

**灵感 4（故障感知重组：在收缩后的动作空间上重新发证）**
直觉：故障后继续沿用故障前的组合路径是危险的，因为云端路径是在 `A` 上认证的，而边端实际只剩 `A_f = C_f(A)`。正确做法是把 `G_S` 用 `A_f` 重建：重算 α、compat、ρ，再搜路径并签发 `J_f`。若 `A_f` 已容不下任务的最小可行动作集 `A_viable`，则不是“硬做”，而是**显式进入降级模式并签发能力损失证书**。

**灵感 5（人形机器人特有的降级与跌倒绊线）**
直觉：人形机器人最贵的故障不是“任务失败”，而是“跌倒”。因此降级模式库 M（跪撑、扶墙、单臂支撑、爬行、原地稳定）要与动作空间和平衡鲁棒性联合选择，并把“跌倒风险”作为独立于任务成功率的硬约束。能力损失证书 `L_cap = (A_lost, Δtask, fall_risk)` 让“我不能做 X 了”成为可审计的承诺，而不是静默退化。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（故障假设格与故障算子）**
故障假设格 `(F, ≼)`，`f ∈ F`。每个故障 f 对应算子 `Φ_f = (C_f, Δρ_f, ε_f)`：
- `C_f: A → 2^A` 为动作收缩映射，`C_f(a) ⊆ A`，可为空；
- `Δρ_f: D → [0,1]` 为鲁棒性扣分向量，`ρ_f(d) = max(0, ρ_0(d) - Δρ_f(d))`；
- `ε_f` 为故障强度/置信参数。

复合故障满足单调性：`f ≼ g ⇒ C_g(A) ⊆ C_f(A)`，且 `Φ_{f∧g} = Φ_f ∘ Φ_g`。人形机器人的关节抱死、力矩衰减、编码器偏置、足端打滑、IMU 漂移、通信抖动都实例化为不同的 `(C_f, Δρ_f)`。

**定义 122（故障-动作签名）**
技能 S 在故障 f 下的预测签名 `ŝ_f: A → ℝ^{1+|D|}`：
```
ŝ_f(a) = ( α_S^0(a) - α_{S,f}(a),  ρ^0(d_1) - ρ_f(d_1), ..., ρ^0(d_m) - ρ_f(d_m) )
```
其中 `α_{S,f}(a) = α_S(a)·1[a ∈ C_f(A)]`。观测签名 `s(a)` 由边端在线残差给出。诊断即
```
f̂ = argmin_{f∈F} D(s, ŝ_f) + λ·complexity(f)
```
残差范数超阈时判为**开放集未知故障** `f_⊥`，不得强行归入已知类。

**定义 123（可诊断性与区分裕度）**
故障 f,g 在安全探测集 `A_safe` 上可区分，当且仅当
```
κ(f,g) = max_{a∈A_safe} ||ŝ_f(a) - ŝ_g(a)|| ≥ κ_min
```
否则 f,g 属于同一**安全不可分等价类** `[f]_κ`。对等价类，证书必须取保守包络：
```
C_[f] = ⋂_{g∈[f]_κ} C_g,   ρ_[f](d) = min_{g∈[f]_κ} ρ_g(d)
```

**定义 124（安全约束主动诊断）**
探测序列 `π = (a_1,...,a_k) ⊆ A_safe`，其中 `A_safe = {a : α(a) ≥ θ_cov ∧ ρ(a) ≥ ρ_safe}`。选择目标：
```
π* = argmax_π  I(F; R_π) - λ_s·Risk(π)
s.t.  a_t ∈ A_safe(Ĵ_{t-1}),  t = 1..k
```
`Risk(π)` 为跌倒/失稳风险估计，`Ĵ_{t-1}` 为上一拍证书。若安全预算内不存在能区分 f,g 的探测，则二者保持等价类，交给保守包络，而不是冒险加大激励。

**定义 125（故障感知联合证书）**
```
J_f = (f̂, F_plausible, ρ_f, A_cert,f, δ_a,f, mode, evidence)
```
- `F_plausible` 为未排除故障集合（含 `f_⊥`）；
- `A_cert,f = (A_core,f, A_buffer,f)`，`A_core,f = A_core ∩ ⋂_{g∈F_plausible} C_g(A)`；
- `mode ∈ {nominal, degraded, safe_stop}`；
- `evidence` 含残差轨迹、探测记录、云端重规划日志。

仅当 `min_d ρ_f(d) ≥ ρ_min` 且 `A_viable(task) ⊆ A_cert,f` 且 `fall_risk ≤ Θ_fall` 时 `mode = nominal`。

**定义 126（能力损失与降级模式选择）**
能力损失 `L_cap = (A_lost, Δtask, fall_risk)`，其中
```
A_lost = A - A_cert,f
Δtask  = 1 - |A_viable ∩ A_cert,f| / |A_viable|
```
降级模式库 `M = {m_j}`，每个 `m_j` 有认证动作集 `A_{m_j}` 与跌倒风险 `r_j`。选择
```
m* = argmax_{m_j∈M} [ vol(A_cert,f ∩ A_{m_j}) - w_f·r_j ]
     s.t. r_j ≤ Θ_fall
```
若 `m*` 为空则 `safe_stop`（原地稳定/坐地），并签发 `L_cap`。

## 2. 关键算法 伪代码

### IP-121 FAS（Fault-Action Signature）

```python
def fit_fault_signature(skill, fault, sim, A_probe, dims):
    alpha0, rho0 = skill.alpha, skill.rho
    alpha_f, rho_f = sim.inject(skill, fault)      # 结构化故障注入
    sig = {}
    for a in A_probe:
        sig[a] = (alpha0.get(a, 0.0) - alpha_f.get(a, 0.0),
                  {d: rho0[d] - rho_f[d] for d in dims})
    return FaultSignature(fault, sig, support=A_probe)
```

### IP-122 CRM（Certificate Residual Monitor）

```python
def monitor_certificate(skill, a_e, obs, J, signatures, kappa_min):
    pred_cover = J.A_cert.core_covers(a_e)
    s_obs = (pred_cover - obs.cover,
             {d: J.rho[d] - obs.rho[d] for d in J.rho})
    if norm(s_obs) <= eps_nominal:
        return ('ok', None, s_obs)
    best, best_d = None, float('inf')
    for f, sig in signatures.items():
        d = dist(s_obs, sig.at(a_e))
        if d < best_d:
            best, best_d = f, d
    if best_d > kappa_min:
        return ('open_set', UnknownFault(s_obs), s_obs)   # f_⊥
    return ('fault', best, s_obs)
```

### IP-123 AST（Action-Space Tomography）

```python
def active_diagnose(F_plausible, A_safe, signatures, budget, risk_model):
    cls = equivalence_classes(F_plausible, signatures, kappa_min)
    probes = []
    while any(len(c) > 1 for c in cls) and len(probes) < budget:
        a = argmax_{a in A_safe}(info_gain(cls, a, signatures)
                                 - lam * risk_model(a))
        if a is None or a not in A_safe:
            break                       # 安全预算内不可分，保留等价类
        probes.append(a)
        r = execute_probe(a)
        cls = refine_classes(cls, a, r, signatures)
    return cls, probes                  # 未分离的类交给保守包络
```

### IP-124 FAR（Fault-Aware Recomposition）

```python
def fault_aware_recompose(task, G, F_plausible, J_prev, M):
    A_f = intersection([contract(A, f) for f in F_plausible])  # 保守包络
    G_f = rebuild_graph(G, A_f)                                 # 重算 alpha/compat/rho
    path, cost = a_star(G_f, start=J_prev.state, goal=task.A_T,
                        heuristic=cost_align)
    if path is None or not covers(path, task.A_viable):
        return degraded_select(A_f, task, M)                    # IP-125
    J_f = issue_joint_cert(path, A_f, F_plausible)
    if min(J_f.rho.values()) < rho_min:
        return degraded_select(A_f, task, M)
    return ('nominal', J_f)
```

### IP-125 DMS（Degraded Mode Selector）

```python
def degraded_select(A_f, task, M, theta_fall):
    best, best_score = None, float('-inf')
    for m in M:
        r = m.fall_risk(A_f, task)
        if r > theta_fall:
            continue
        score = vol(A_f & m.A) - w_f * r
        if score > best_score:
            best, best_score = m, score
    if best is None:
        return ('safe_stop', L_cap(A_lost=A - A_f, task_loss=1.0))
    return ('degraded', best,
            L_cap(A_lost=A - A_f,
                  task_loss=1 - vol(A_f & task.A_viable) / vol(task.A_viable),
                  fall_risk=best.fall_risk(A_f, task)))
```

### IP-126 CFC（Cloud-Edge Fault Contract）

```python
def edge_fault_loop(J, obs, signatures, A_safe):
    status, f, s = monitor_certificate(J.skill, J.a_e, obs, J,
                                       signatures, kappa_min)
    if status == 'ok':
        return ('keep', J)
    if status == 'fault':
        cls, probes = active_diagnose([f], A_safe, signatures,
                                      budget, risk_model)
        return ('escalate', FaultReport(cls, probes, s))
    return ('escalate', FaultReport([UNKNOWN], [], s))   # 开放集

def cloud_fault_loop(report, task, G, M, J_prev):
    F_plausible = report.classes if report.is_closed else F | {UNKNOWN}
    return fault_aware_recompose(task, G, F_plausible, J_prev, M)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| FAS | O(|F|·|A_probe|·|D|) | O(|F|·|A_probe|) | 故障注入覆盖、签名可重复 |
| CRM | O(|F|·|D|) / tick | O(|D|) | 证书不变量可观测、阈值标定 |
| AST | O(k·|A_safe|·|F|) | O(|F|²) | 探测始终落在 A_safe |
| FAR | O(|S|²·|A_f| + |V|log|V|) | O(|S|²) | 收缩包络 sound、路径可判定 |
| DMS | O(|M|·|A|) | O(|M|) | 跌倒风险上界可靠 |
| CFC | O(τ_loop) 边端 + O(重规划) 云端 | — | 回传不震荡、包络保守 |

**正确性定理（Fault-Aware Safe Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** 真实故障 `f*` 要么被 `F_plausible` 覆盖，要么被开放集残差检出（`P(detect f_⊥) ≥ 1-β_o`）；**(A30)** 主动探测全程 `a_t ∈ A_safe`，诊断误差 `P(f̂ ∉ [f*]_κ) ≤ ε_d`；**(A31)** 故障算子复合单调，且收缩包络 `C_[f]` 可计算。则
```
P(safe_completion) ≥ 1 - β_o - ε_d - P(fall | m*) - Σ_d (1 - ρ_f(d))
```
其中 `m*` 为 DMS 选出的模式。关键量 `P(fall | m*)` 必须由独立绊线估计，不能被任务成功率稀释；当 `mode = safe_stop` 时把任务成功率记为 0，但把跌倒概率压到最低，这是有意的不对称。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 故障假设格不完备（未知故障） | 高 | 开放集残差 + 保守包络 + safe_stop |
| 主动探测本身诱发跌倒 | 高 | A_safe 硬约束 + 风险预算 + 物理绊线 |
| 多故障耦合被误判为单故障 | 高 | 复合算子单调性 + 等价类包络 |
| 仿真故障与真机分布差 | 高 | 域随机化故障注入 + 真机残差校准 |
| 误诊断导致过度降级 | 中 | 迟滞 + 置信度门控 + 可恢复升级 |
| 云边回传震荡 | 中 | 事件触发 + 最小驻留时间 |

## 6. 本轮最大风险

**一句话**：把故障建模为动作空间收缩算子、把证书当观测模型，能让诊断直接服务于技能重组，但其 soundness **同时依赖故障假设格的完备性、主动探测的安全约束、以及保守包络对多故障耦合的覆盖**；一旦出现“长得像已知故障”的未知复合故障，诊断器会高置信度误隔离，云端在错误的收缩动作空间上重新发证，机器人将以“已认证”的姿态执行实际不安全的动作——这是比任务失败更危险的静默失稳，故必须以 **开放集检测 + 等价类保守包络 + 跌倒独立绊线 + safe_stop 兜底** 四重护栏，宁可过度降级，绝不把“证书通过”当作“物理安全”。

## 2. 关键推导

**推导 1（收缩包络的单调性）**
设 `f ≼ g`，由定义 121 有 `C_g(A) ⊆ C_f(A)`。对任意 `S ⊆ F_plausible`，保守包络 `C_S = ⋂_{f∈S} C_f(A)`。加入新故障只会让交集更小，故 `C_{S∪{h}} ⊆ C_S`。这保证：**诊断越不确定、包络越保守、可认证动作越少**，系统在信息不足时自动向安全侧收缩，而非向任务侧扩张。这是本方案最重要的单调性保证。

**推导 2（能力损失下界）**
由 `A_cert,f ⊆ C_f(A)` 得 `A_lost = A - A_cert,f ⊇ A - C_f(A)`，故
```
vol(A_lost) ≥ vol(A) - vol(C_f(A))
```
即能力损失证书报出的 `A_lost` 不会低估真实丢失的动作体积。反之，若诊断把未知故障误判为已知轻故障，`vol(C_f(A))` 被高估，`A_lost` 被低估——这正是“静默失稳”的数学来源，因此必须有开放集项 `f_⊥` 把 `F_plausible` 撑大。

**推导 3（为什么跌倒风险不能并入成功率）**
令 `P_safe = P(task) - P(fall)`。若把跌倒折算成任务失败，优化器会用“高跌倒风险 + 高任务成功率”换取期望收益；但跌倒对人形机器人是不可逆损伤，成本非线性。故本方案把 `fall_risk ≤ Θ_fall` 作为**约束**而非**惩罚项**，在 DMS 中先过滤 `r_j > Θ_fall` 的模式，再做能力最大化。

### IP-121 FAS

```python
def fit_fault_signature(skill, fault, sim, A_probe, dims):
    alpha0, rho0 = skill.alpha, skill.rho
    alpha_f, rho_f = sim.inject(skill, fault)
    sig = {}
    for a in A_probe:
        sig[a] = (alpha0.get(a,0.0) - alpha_f.get(a,0.0),
                  {d: rho0[d] - rho_f[d] for d in dims})
    return FaultSignature(fault, sig, support=A_probe)
```

### IP-122 CRM

```python
def monitor_certificate(skill, a_e, obs, J, signatures, kappa_min):
    pred_cover = J.A_cert.core_covers(a_e)
    s_obs = (pred_cover - obs.cover,
             {d: J.rho[d] - obs.rho[d] for d in J.rho})
    if norm(s_obs) <= eps_nominal:
        return ('ok', None, s_obs)
    best, best_d = None, float('inf')
    for f, sig in signatures.items():
        d = dist(s_obs, sig.at(a_e))
        if d < best_d:
            best, best_d = f, d
    if best_d > kappa_min:
        return ('open_set', UnknownFault(s_obs), s_obs)
    return ('fault', best, s_obs)
```

### IP-123 AST

```python
def active_diagnose(F_plausible, A_safe, signatures, budget, risk_model):
    cls = equivalence_classes(F_plausible, signatures, kappa_min)
    probes = []
    while any(len(c) > 1 for c in cls) and len(probes) < budget:
        a = argmax_{a in A_safe}(info_gain(cls, a, signatures)
                                 - lam * risk_model(a))
        if a is None or a not in A_safe:
            break
        probes.append(a)
        cls = refine_classes(cls, a, execute_probe(a), signatures)
    return cls, probes
```

### IP-124 FAR

```python
def fault_aware_recompose(task, G, F_plausible, J_prev, M):
    A_f = intersection([contract(A, f) for f in F_plausible])
    G_f = rebuild_graph(G, A_f)
    path, cost = a_star(G_f, start=J_prev.state, goal=task.A_T,
                        heuristic=cost_align)
    if path is None or not covers(path, task.A_viable):
        return degraded_select(A_f, task, M)
    J_f = issue_joint_cert(path, A_f, F_plausible)
    if min(J_f.rho.values()) < rho_min:
        return degraded_select(A_f, task, M)
    return ('nominal', J_f)
```

### IP-125 DMS

```python
def degraded_select(A_f, task, M, theta_fall):
    best, best_score = None, float('-inf')
    for m in M:
        r = m.fall_risk(A_f, task)
        if r > theta_fall:
            continue
        score = vol(A_f & m.A) - w_f * r
        if score > best_score:
            best, best_score = m, score
    if best is None:
        return ('safe_stop', L_cap(A_lost=A - A_f, task_loss=1.0))
    return ('degraded', best,
            L_cap(A_lost=A - A_f,
                  task_loss=1 - vol(A_f & task.A_viable) / vol(task.A_viable),
                  fall_risk=best.fall_risk(A_f, task)))
```

### IP-126 CFC

```python
def edge_fault_loop(J, obs, signatures, A_safe):
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FAS | O(|F|·|A_probe|·|D|) | O(|F|·|A_probe|) | 故障注入覆盖、签名可重复 |
| CRM | O(|F|·|D|)/tick | O(|D|) | 证书不变量可观测、阈值标定 |
| AST | O(k·|A_safe|·|F|) | O(|F|²) | 探测落在 A_safe、区分裕度 sound |
| FAR | O(|S|²·|A_f|+|V|log|V|) | O(|S|²) | 收缩包络 sound、路径可判定 |
| DMS | O(|M|·|A|) | O(|M|) | 跌倒风险上界可靠 |
| CFC | O(τ_loop)+O(重规划) | — | 回传不震荡、包络保守 |

**正确性定理（Fault-Aware Safe Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `f*` 被 `F_plausible` 覆盖或被开放集检出（`P ≥ 1-β_o`）；**(A30)** 探测全程 `a_t∈A_safe`，`P(f̂∉[f*]_κ) ≤ ε_d`；**(A31)** 复合算子单调且包络可计算。则
```
P(safe_completion) ≥ 1 - β_o - ε_d - P(fall | m*) - Σ_d (1 - ρ_f(d))
```
**证明要点**：由 A29/A30，以概率 `1-β_o-ε_d` 有 `f* ∈ F_plausible` 且 `A_cert,f ⊆ C_{f*}(A)`；由 FAR 只在 `A_cert,f` 上发证、DMS 只在 `r_j ≤ Θ_fall` 的模式中选择，故任一执行动作同时满足收缩可行性与跌倒约束；再由第 54 轮鲁棒性链式界得 `Σ_d(1-ρ_f(d))` 项。三项风险相加，得证。

## 7. 本轮最大风险

**一句话**：把故障建模为动作空间收缩算子、把证书当观测模型，能让诊断直接服务于技能重组，但其 soundness **同时依赖故障假设格的完备性、主动探测的安全约束、以及保守包络对多故障耦合的覆盖**；一旦出现“长得像已知故障”的未知复合故障，诊断器会高置信度误隔离，云端在错误的收缩动作空间上重新发证，机器人将以“已认证”的姿态执行实际不安全的动作——这是比任务失败更危险的静默失稳，故必须以 **开放集检测 + 等价类保守包络 + 跌倒独立绊线 + safe_stop 兜底** 四重护栏，宁可过度降级，绝不把“证书通过”当作“物理安全”。
