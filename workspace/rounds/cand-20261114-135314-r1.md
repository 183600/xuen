# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；本轮灵感：「运动控制」×「轮足机器人」）

> R69 把不确定性一分为二，并给了系统一张嘴：问。流匹配生成「看—问—触—等」的信息动作，VoI 决定值不值得问，k 个正交证据源防止被单次回答骗。但它仍默认：**信息动作是任务动作之外的附加项，可以用一个独立成本去认证；探针是只读的，问了不会改变被问的世界。**
>
> 本轮两个灵感同时拆掉这个默认：
> - **运动控制**告诉我们，物理信息从来不是免费的。要知道地面刚度，必须压它；要知道摩擦，必须让它滑一点；要确认支撑，必须把重量移过去。信息动作会反作用于机器人自身，它不是外挂传感器，而是**对偶控制**中「既改变状态、又改变信念」的控制输入。
> - **轮足机器人**告诉我们，平台本身就是一台多模态实验装置：**滚动是连续询问，抬轮落点是点询问**。滚动用滑移率/电流连续估计地形，足式用离散接触确认支撑；步态不只是运动方式，它还是提问方式。
>
> 核心命题：**把运动控制建模为受安全裕度约束的物理贝叶斯实验。地形/接触是潜变量，接触时序是实验设计，全身控制器是实验装置，鲁棒 CBF 是伦理审查。信息动作只能落在认证安全探针包络内；信息增益受机械功上界约束；探针花掉当下的安全裕度，换回未来的安全裕度。R69 的 MINT 是「探针与动力学解耦、功为零」的退化情形。** 命名 **GAIT-RAS**（Grounded Active Information-seeking Traversal for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**为了知道，我必须先动多少？我的知识是用安全裕度买来的吗？**」

## 0. 直觉与动机

**灵感 1（运动控制：信息动作有反作用力）**
直觉：R69 的 `g_probe` 被当作一个可以独立认证的「力探针」；但在运动控制里，探针的反作用力会进入机器人自己的动力学。压地面测刚度，地面也把同样大的力推回来；在斜坡上探头，重心会偏；在松土上踩一脚，支撑可能先塌。于是「信息动作的安全」不是给 `g` 加一个约束就完了，而是**任务通道与探针通道共享同一个动力学预算**。R69 的 `LoI − c` 是标量经济学；R70 需要的是**动力学记账**：这一次探针从平衡裕度里借走了多少，什么时候还。

**灵感 2（轮足机器人：步态就是提问方式）**
直觉：轮足平台有一条从「连续滚动」到「离散落脚」的连续谱。滚动时，轮子持续采样地形，信息率高、单次扰动小，但对台阶、沟壑、松土这类离散事件不敏感；抬轮落点时，接触是点采样，信息密度高、能确认支撑，但会暂时缩小支撑多边形、消耗平衡裕度。**所以「用滚的还是用踩的」本身就是一个信息动作。** 更关键的是：一个步态只有在接触时序可行、摩擦锥可行、全身动力学可行时才成立。R69 用流匹配采样模态，可能采样出物理上不存在的模态；轮足平台给了我们一个天然的物理门：**接触一致性门（CMG）**。

**灵感 3（对偶控制：R69 的 VoI 是「无扰动实验」的退化情形）**
直觉：对偶控制（dual control）的经典结论是：当动作同时影响状态和信念时，确定性等价不是最优的；最优动作会主动试探。R69 的 MINT 已经有一点对偶控制的味道，但它把「试探」当成任务动作之外的附加项，且假设试探不改变被估计的对象。R70 把这一点补全：信息动作是一个**受控实验** `do(g)`，它有转移核 `P_g(x',θ'|x,θ)` 和观测核 `P_g(y|x',θ',ξ)`；观测模型依赖动作，动作又会扰动潜变量。于是 R69 恰是 `T_g = id`、`W(g)=0` 的边界。

**灵感 4（安全裕度是货币：探针花掉裕度，知识赚回裕度）**
直觉：地形越不确定，鲁棒控制屏障函数（CBF）越保守，安全裕度 `M` 越小；探针花掉一点 `M` 去降低地形方差 `σ_θ`，方差降了，`M` 又会回来。这不是比喻，可以直接写成账本：
`M_{t+1} = M_t − ΔM_now(g) + κ(σ_t − σ_{t+1}(g)) − risk`。
于是「值不值得探」变成一个可算的判据：**只有当信息带来的未来裕度增量超过当下花掉的裕度与成本时，才探**。这比 R69 的标量 VoI 更贴近运动控制：不是「不确定就问」，而是「**这块不确定性真的影响安全、且我买得起时，才去探**」。

**灵感 5（R69 最大风险：幻影模态在物理世界可被接触一致性门拦截）**
直觉：R69 最怕流模型幻觉出不存在的模态，然后系统自信地追问一个幻影。对语言问句，这只能靠校准门；对轮足运动，物理给了第二条防线：**一个模态若没有可行的接触时序，就不可能被真正执行**。于是把「模态采样」投影到「接触一致可行集」上，幻影模态的执行概率直接为零。代价是可行集为空时只能回退保守——这正是我们想要的失败方向。

**灵感 6（新威胁：探针改变被测量的世界）**
直觉：接触不是被动观测。压实地、推走松土、把轮子陷入泥里，都会改变 `θ` 本身。更糟的是，这种改变是**自利偏差**：机器人越用力探，越可能把自己脚下的地形改造成「看起来可支撑」的样子，然后在下一步踩空。所以 R70 必须把 `T_g` 写进模型，把「探针诱导的地形修改」列入威胁模型，并对重复探针设记忆与上限。否则「接触即测量」会变成「接触即自我欺骗」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（GAIT-RAS 总览）** GAIT-RAS = (HAL, TEF, DCL, PWI, NSQ, RCBF, SMV, CMG, HLC, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **探针权限层级**：安全 > 任务 > 探针；任何信息动作必须位于鲁棒 CBF 认证的安全探针包络内；若需借用任务权限，必须显式记账 `ρ_g` 并计入风险；
(iii) **信息-功诚实**：每个信息动作必须声明机械功 `W(g)` 与状态扰动算子 `T_g`；未声明或不可认证的信息动作作废；
(iv) **不可逆闸门**：踩上未知支撑、下台阶等不可逆承诺，必须后验可信集落在安全包络内，或由 `g_ask`/非语言确认补充；否则退化为 R68 保守。

**定义 311（混合运动自动机 HAL）** `HAL = (Q, X, U, Θ, f, Guard, Reset, Σ)`。`Q = {ROLL, STEP, HYBRID, STAND}` 为运动/接触模式；连续状态 `x = (p, R, v, ω, q_j, q̇_j)`；`σ_q(t)` 为模式 `q` 的接触时序（哪些轮/足在何时接触）。模式内动力学 `ẋ = f_q(x, u, θ)`，`Guard_{q→q'}` 为切换守卫，`Reset_{q→q'}` 为重置映射。**可行模式集** `Adm(b) = {q | ∃u, σ_q 满足动力学、摩擦锥、单边接触、力矩/速度约束，且在可信集 Θ_t^ε 下守卫可达}`。`q ∈ Adm(b)` 称接触一致。

**定义 312（地形/接触 epistemic 场 TEF）** 地形潜场 `θ(z) = (h(z), k(z), μ(z), c(z))`，分别为高度、刚度、摩擦、黏聚；`z` 为地面坐标。维护后验 `b_t(θ)`、可信集 `Θ_t^ε`、逐点不确定性场 `σ_θ(z)`。探针会修改地形：`θ' ~ T_g(θ)`，`T_g` 为接触诱导的压实/滑移/位移算子；`T_g = id` 表示无扰动。

**定义 313（信息动作 = 受控接触实验 DCL）** `g = (q_g, τ_g, p_g, f_g, g_ask)`：探测时采用的运动模式、轮端力矩曲线、落点/扫掠路径、接触力曲线，以及可选的语言询问。与 R69 不同，`g` 是**读写**的：`do(g)` 同时诱导转移 `P_g(x', θ' | x, θ)` 和观测 `P_g(y | x', θ', ξ)`。R69 的 `g_gaze`、`g_ask` 是只读/语义动作，`g_probe` 被默认为只读——这正是本轮要修正的假设。

**定义 314（内生观测与 Fisher 信息）** 观测模型 `y = h(x, θ, g) + ε`；`I_g(θ) = E[−∂² log p_g(y|x,θ,g)/∂θ²]` 为实验 `g` 对 `θ` 的 Fisher 信息。关键：`g` 是设计变量，观测模型依赖动作——这就是对偶控制与普通状态估计的分水岭。

**定义 315（探针-功-信息不等式 PWI）** 线性接触模型 `F = kx + ε`，`ε ~ N(0, σ²)`，探针位移 `x`。则 `I(k) = x²/σ²`，准静态功 `W = ½kx²`，故
`I(k) = 2W / (kσ²)`。
若先验 `k ~ N(μ, σ_k²)`，高斯近似下后验熵降 `ΔH = ½ log(1 + I σ_k²)`，因此
`W_min(ΔH) = kσ² / (2σ_k²) · (e^{2ΔH} − 1)`。
定义探针功预算 `W_max = η_M · M_safe`（`η_M` 为允许从安全裕度中提取的比例），对应信息上限
`ΔH_max = ½ log(1 + 2η_M M_safe σ_k² / (kσ²))`。
**任何需要 `ΔH_req > ΔH_max` 的探针都不可认证。**

**定义 316（鲁棒控制屏障与安全裕度账本 RCBF）** 安全集 `C = {x | h(x, θ) ≥ 0}`。对可信集 `Θ_t^ε` 取最坏情况：
`M_t = min_{θ∈Θ_t^ε} h(x, θ) = h(x, θ̂) − κ σ_θ`，
`κ` 为 `h` 对地形误差的 Lipschitz 常数。探针的即时裕度消耗 `ΔM_now(g) = M_t − M_t(g)`；信息使方差从 `σ_t` 降到 `σ_{t+1}`，未来裕度增量 `ΔM_future = κ(σ_t − σ_{t+1})`。账本：
`M_{t+1} ≥ M_t − ΔM_now(g) + ΔM_future(g) − risk(g)`，且任何时刻必须 `M ≥ 0`。

**定义 317（零空间探针 QP NSQ）** 分层全身 QP，优先级为：鲁棒 CBF/接触约束 > 任务跟踪 > 探针。解形式：
`u = u_safe + N_safe u_task + N_safe N_task (u_probe + ρ_g u_borrow)`，
其中 `N_*` 为动力学一致零空间投影，`ρ_g ∈ [0,1]` 为显式「借用任务权限」的比例。`ρ_g` 产生的额外风险按 `ρ_g · margin_loss` 记账；若 QP 不可行或 `W(g) > W_max`，则 `g` 作废。

**定义 318（接触一致性模式门 CMG）** 对策略采样的模式分布做投影：
`π_adm(q|o) = π_θ(q|o) · 1[q ∈ Adm(b)] / Z`；若 `Z = 0`，回退到最保守的 `q_safe`。因此任何不可行模式（幻影模态）的执行概率为零；代价是可行集为空时性能下降，但失败方向是安全侧。

**定义 319（不确定性分解扩展）** `U = (U_ale, U_epi, U_contact, U_mode, U_terrain, U_dyn, U_irrev)`：
- `U_contact`：接触建立/断开、滑移状态不确定；
- `U_mode`：当前该滚/该踩/该混合的模式不确定；
- `U_terrain`：地形高度/刚度/摩擦潜场不确定；
- `U_dyn`：质量、惯量、执行器/摩擦参数不确定；
- `U_irrev`：不可逆承诺的后悔风险；
- `U_ale, U_epi` 继承 R69。
处置映射：`U_terrain, U_contact` → 滚动/落点探针（SMV）；`U_mode` → CMG + 混合证书；`U_dyn` → 鲁棒 CBF 膨胀/有界在线辨识；`U_irrev` → `g_ask`/teach-back/保守模式；`U_epi` → R69 语义 MINT；`U_ale` → R68 λ_floor。七者语义不同，不做简单加和。

**定义 320（安全裕度信息价值 SMV / MINT-M）** 对候选信息动作 `g`：
`SMV(g) = E_b[M_{t+1} | g] − M_t − c(g) = κ(σ_t − Eσ_{t+1}(g)) − ΔM_now(g) − c(g)`。
选择 `g* = argmax SMV(g)`，约束：`q_g ∈ Adm(b)`、`W(g) ≤ η_M M_t`、`risk(g) ≤ ε_int`；`g_ask` 仅在无物理探针可认证时启用。若 `SMV(g*) ≤ 0`，不探针，退化为 R69 语义交互；若 R69 也无利可图，退化为 R68 保守。

**定义 321（混合 Lyapunov 与无抖振 HLC）** 每个模式 `q` 有 Lyapunov 函数 `V_q`：模式内 `V̇_q ≤ −αV_q + β‖u_probe‖²`；切换重置满足 `V_{q'}(Reset(x)) ≤ V_q(x) + δ`；驻留时间 `τ_dwell ≥ τ_min`；守卫带迟滞 `Δ_hys`。四者共同保证混合执行无 Zeno、无抖振。

**定义 322（威胁模型 AIC-GAIT）** `ℰ_GAIT = ℰ_FLUID × ℰ_terrain × ℰ_endogenous`。`ℰ_terrain` = {滑移注入、欺骗性柔顺（看着软其实硬）、地形欺骗（视觉/本体感觉串谋）、探针诱导塌陷、接触延迟}；`ℰ_endogenous` = {探针诱导极限环、自激振动、零空间泄漏、权限借用过量}。

**定义 323（证书 J_GAIT）** `J_GAIT = (J_FLUID, mode_admissibility, W_probe, ΔH_realized/ΔH_req, M_before/after, robust_cbf_margin, dwell_time, contact_schedule_hash, gait_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 模式接触一致 ∧ `W_probe ≤ W_max` ∧ 鲁棒 CBF 满足 ∧ 驻留时间满足 ∧ `SMV > 0`。

**定义 324（对 R69/R68 的严格退化）** 在 A99–A101 下：`T_g = id`、`W = 0`、`|Q| = 1`、`Θ = {θ}`、探针语义退化为 R69 的 `g_probe`，则 GAIT 的选择与 FLUID 逐指令相同；若进一步 `SMV ≤ 0`（等价于 R69 的 `VoI ≤ c`），则逐指令退化为 R68。R70 不是并列替代，而是把「物理探针」接入旧层后的严格泛化。

**定义 325（自适应步态保真度）** 默认 roll-first：`K=1`、连续滚动采样；仅当 `U_terrain > τ_T` 或 `U_mode > τ_M` 时升级为落点探针；安全滤波器 `f_safe = 1kHz`，epistemic 规划 `f_epi ≈ 50Hz`；`W_max` 与 `ρ_g` 随剩余裕度自适应，保证 P99 实时预算。

```python
# IP-264/265 HAL + TEF：混合模式可行性与地形场更新
class HybridLocomotion:
    MODES = [ROLL, STEP, HYBRID, STAND]
    def admissible(self, belief, x):
        # 预计算接触时序 + 摩擦锥/单边/力矩/守卫检查 + 鲁棒 CBF 可行性
        return [q for q in self.MODES
                if self.qp.feasible(q, x, belief.theta_eps)]

class TerrainEpistemicField:
    def update(self, obs, last_probe):
        # 贝叶斯更新 theta=(h,k,mu,c)，并纳入探针扰动 T_g
        return belief, sigma_theta, theta_eps

# IP-266/267 DCL + PWI：探针的功-信息交换率
def probe_work_info(theta_hat, g, sigma2):
    W = 0.5 * theta_hat.k * g.disp**2 + wheel_work(g)   # 接触功 + 轮端功
    I = g.disp**2 / sigma2                              # Fisher info about k
    dH = 0.5 * log1p(I * theta_hat.sigma_k2)             # 高斯后验熵降
    return W, I, dH

def info_ceiling(M_safe, eta_M, theta_hat, sigma2):
    W_max = eta_M * M_safe
    return 0.5 * log1p(2 * W_max * theta_hat.sigma_k2 /
                       (theta_hat.k * sigma2))

# IP-270 SMV：安全裕度信息价值（R69 MINT 的物理版）
def choose_probe(modes, b, x):
    best = None
    for g in info_action_candidates(modes, b):
        if g.q not in admissible(modes, b, x):        continue
        if not c_ras_wm.certify_info(g, x):           continue
        W, I, dH = probe_work_info(b.theta_hat, g, b.sigma2)
        if W > eta_M * robust_margin(x, b):           continue
        dM_now    = margin_cost(g, x, b)
        dM_future = kappa * (b.sigma_theta - expected_sigma(b, g))
        smv = dM_future - dM_now - social_physical_cost(g)
        if best is None or smv > best.smv: best = (g, smv)
    return best if best and best.smv > 0 else None      # 无利可图 → R69/R68

# IP-268 NSQ：零空间探针，安全 > 任务 > 探针
def safe_probe_qp(x, q, g, b):
    u_safe = qp_safety(x, b, q)                         # 鲁棒 CBF + 接触
    u_task = qp_task(x, q, u_safe)                      # 任务跟踪
    u_probe = nullspace_project(u_task, g)              # 探针进零空间
    if infeasible(u_probe, W_max=eta_M * robust_margin(x, b)):
        return None
    return u_safe + u_probe

        y = M.execute(g)
        b = M.tef.update(y, g)
        U_epi = M.cia.update_belief(modes, y)
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    if M_safe < eps_m or g is None:
        lam = max(lam, 0.8)                             # 回 R68 最保守
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    mode = select_mode(modes, U_epi, lam)
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_i.submit_async(g, U_epi, M_safe)
    return k, lam, mode, (U_ale, U_epi, M_safe)
```

## 3. 推导

**引理 19（探针-功-信息交换率）** 在线性接触模型 `F = kx + ε`、`ε~N(0,σ²)` 下，对 `k` 的 Fisher 信息为 `I(k) = x²/σ²`；准静态压缩功 `W = ½kx²`。故 `I(k) = 2W/(kσ²)`。若先验方差 `σ_k²`，则熵降 `ΔH = ½log(1 + Iσ_k²)`，最小所需功 `W_min(ΔH) = kσ²/(2σ_k²)·(e^{2ΔH}−1)`。系 19.1：**功为零则信息为零**——对接触刚度而言，不存在「完全不动却能问出结果」的探针；R69 若把安全认证收紧到 `W→0`，MINT 会被物理规律自然饿死。系 19.2：信息/功的交换率 `2/(kσ²)` 由接触刚度和传感噪声决定，不随探针幅度改变；幅度只是同时放大信息与代价。

**引理 20（安全裕度账本与探针判据）** 由定义 316 的账本，探针在一步内严格改善安全裕度当且仅当
`κ(σ_t − Eσ_{t+1}) > ΔM_now(g) + c(g)`，
即 `SMV(g) > 0`（定义 320）。系 20.1：**探针的价值取决于地形不确定性对安全的影响 `κ`，而不只是不确定性本身**。若 `κ` 很小（地形误差几乎不影响安全），即使 `σ_θ` 很大也不值得探；若 `κ` 很大（安全对地形高度敏感），很小的 `σ_θ` 也值得花裕度去降。这把 R69 的「可分性」升级为「安全相关性」。

**引理 21（接触一致性门的幻影模态界）** 若可信集覆盖 `P(θ* ∈ Θ_t^ε) ≥ 1−ε`，且可行性检查是可靠的（真模式在 `θ*` 下可行），则真实模式被错误排除的概率 `≤ ε`。对任意 `q ∉ Adm(b)`，由投影 `π_adm` 其执行概率为零。因此 **幻影模态执行率为零**；代价是 `Adm(b) = ∅` 时的回退率，其上界由 `ε` 与保守的 CBF 膨胀控制。系 21.1：R69 的「幻觉模态诱发追问」在轮足平台上被物理可行性截断，但可能转化为「可行集过窄导致过度保守」——这是本轮的新失败模式。

**定理 18（GAIT 严格包含 FLUID/R68）** 在 A99–A101（`T_g=id`、`W=0`、`|Q|=1`、`Θ={θ}`、探针语义退化为 R69 的只读 `g_probe`）下，GAIT 的 SMV 退化为 R69 的 `VoI − c`，CMG 退化为恒等，NSQ 的探针通道消失；因此 GAIT 与 FLUID 逐指令相同。进一步若 `SMV ≤ 0`（等价 `VoI ≤ c`），两者都退化为 R68。故 R70 的安全侧不做让步，效率侧只在「物理上买得起且安全相关」时获得增益。

**定理 19（混合安全与无抖振）** 假设：鲁棒 CBF 在 `Θ_t^ε` 上可行；NSQ 投影保证 `u` 满足 CBF 与接触约束；HLC 满足驻留时间 `τ_min`、重置条件 `V_{q'}(Reset(x)) ≤ V_q(x)+δ`、守卫迟滞 `Δ_hys`；探针功 `W ≤ W_max`。则安全集 `C` 前向不变，混合自动机不存在 Zeno 执行，模式切换无抖振，且探针不改变任务通道的安全包络。证明要点：CBF 保证连续段不变性；驻留时间排除无限快切换；重置条件排除 Lyapunov 跳升；投影保证探针不越权。系 19.1：**探针只能改变「选哪个可行模式」，不能改变「安全集本身」**。

**定理 20（物理不可知边界）** 若不可逆动作所需的熵降 `ΔH_req > ΔH_max(W_max)`，则由引理 19，任何满足 `W(g) ≤ W_max` 的认证探针都无法把后验可信集压到安全包络内。此时唯一安全的选择是 `g_ask`（若语义信道可用且可信）或放弃该不可逆动作、退回鲁棒保守模式。系 20.1：**不是所有不确定性都能用运动解决；安全预算给知识设了一个物理上限。** 这也解释了为什么 R69 的语言询问不能被物理探针完全替代。

## 6. 可证伪预测

1. **P1**：在在线性接触区，测得 Fisher 信息与机械功的比值应接近 `2/(kσ²)`；若系统性偏离，说明接触模型或功模型错了。
2. **P2**：`SMV > 0` 的探针应在下一步平均提升安全裕度；`SMV < 0` 的探针应平均降低它。若两者无差异，则「裕度货币」假设被证伪。
3. **P3**：CMG 应把幻影模态执行率压到 0，但会提高可行集为空时的回退率；若回退率不升，说明可行性检查过松或场景太简单。
4. **P4**：在可变形地形上，累计探针功超过阈值后，地形模型虚假自信率应上升，任务成功率应出现非单调拐点；若始终单调上升，则 `T_g` 建模不足。
5. **P5**：在 `T_g=id, W=0, |Q|=1` 的退化场景，GAIT 与 R69 的行为差应为 0；若有差，严格包含定理不成立。

## 7. 本轮最大风险

**一句话**：GAIT-RAS 把「接触即测量」当成可以记账的实验，但接触是**读写**的——探针会压实地、推走松土、扰动滑移，系统可能在稳定预算内测到一个被自己改造过的、自信而错误的地形模型，然后在下一步踩空；**最危险的不是不知道，而是用安全裕度买到了一个关于错误世界的确定答案。**

**次级风险与缓解**：
1. **PWI 只对线性/准静态接触成立**（塑性、非线性、动态接触会破坏交换率）→ 用保守上界 + 在线校验，超出模型区即禁用探针；
2. **鲁棒 CBF 过保守导致「探针瘫痪」**（`SMV` 永不为正）→ 分层放宽 `κ`、允许小 `ρ_g` 借用，但显式记账并设上限；
3. **零空间解耦把有用信号也滤掉**（探针在零空间里对地形几乎无激励）→ 引入可控的权限借用，并优先选择「高信息/低扰动」的滚动扫掠；
4. **混合可行性检查对未建模接触脆弱** → 用可信集上的鲁棒可行性 + `Adm=∅` 安全回退；
5. **探针诱导地形修改/记忆缺失** → 把 `T_g` 写入 TEF，限制重复探针，维护「被扰动地形」地图；
6. **地形欺骗/滑移注入** → 轮式与足式两条独立通道交叉验证，继承 R69 的「k 个正交证据源一致」纪律；
7. **实时预算被 QP 击穿** → 降阶模型 + 预计算接触时序 + warm start，安全滤波与 epistemic 规划分频。

**定义 311–313（HAL / TEF / DCL）** `HAL=(Q,X,U,Θ,f,Guard,Reset,Σ)`；`Adm(b)` 为接触一致可行集。地形潜场 `θ(z)=(h,k,μ,c)`，维护 `b_t, Θ_t^ε, σ_θ(z)` 与 `θ'~T_g(θ)`。信息动作 `g=(q_g,τ_g,p_g,f_g,g_ask)` 是**读写**实验：`do(g)` 同时诱导 `P_g(x',θ'|x,θ)` 与 `P_g(y|x',θ',ξ)`；R69 的只读探针是 `T_g=id, W=0` 特例。

**定义 314–315（内生观测与 PWI）** `I_g(θ)=E[−∂²log p_g(y|x,θ,g)/∂θ²]`。线性接触 `F=kx+ε, ε~N(0,σ²)` 下：`I(k)=x²/σ²`、`W=½kx²`，故 `I=2W/(kσ²)`；高斯先验下 `ΔH=½log(1+Iσ_k²)`，`W_min(ΔH)=kσ²/(2σ_k²)(e^{2ΔH}−1)`。`W_max=η_M M_safe`，`ΔH_max` 由 `W_max` 反解；`ΔH_req>ΔH_max` 的探针不可认证。

**定义 316–317（RCBF / NSQ）** `M_t=min_{θ∈Θ_t^ε}h(x,θ)=h(x,θ̂)−κσ_θ`；账本 `M_{t+1}≥M_t−ΔM_now+κ(σ_t−σ_{t+1})−risk`，且 `M≥0`。分层 QP：`u=u_safe+N_safe u_task+N_safe N_task(u_probe+ρ_g u_borrow)`；优先级安全 > 任务 > 探针，`ρ_g` 计入风险，不可行则 `g` 作废。

**定义 318–319（CMG / 不确定性分解）** `π_adm(q|o)∝π_θ(q|o)1[q∈Adm(b)]`，`Z=0` 回退 `q_safe`；幻影模态执行率为零。扩展分解 `U=(U_ale,U_epi,U_contact,U_mode,U_terrain,U_dyn,U_irrev)`；分别映射到滚动/落点探针、CMG+HLC、鲁棒 CBF/有界辨识、`g_ask`/保守、R69 语义 MINT、R68 λ_floor。

**定义 320（SMV / MINT-M）** `SMV(g)=κ(σ_t−Eσ_{t+1})−ΔM_now−c`；`g*=argmax SMV` s.t. `q_g∈Adm`、`W≤η_M M_t`、`risk≤ε_int`；`SMV≤0` 不探针，退 R69 语义交互；R69 也无利可图则退 R68。

**定义 321–325（HLC / AIC / 证书 / 退化 / 保真度）** `V̇_q≤−αV_q+β‖u_probe‖²`、`V_{q'}(Reset(x))≤V_q(x)+δ`、`τ_dwell≥τ_min`、守卫迟滞 `Δ_hys`。`ℰ_GAIT=ℰ_FLUID×ℰ_terrain×ℰ_endogenous`。`J_GAIT` 并入模式可行性、探针功、`ΔH` 实现率、裕度前后、CBF 裕度、驻留时间。A99–A101（`T_g=id, W=0, |Q|=1, Θ={θ}`）下逐指令退化为 FLUID；再 `SMV≤0` 退化为 R68。默认 roll-first，`f_safe=1kHz`、`f_epi≈50Hz`。

```python
def probe_work_info(theta_hat, g, sigma2):
    W  = 0.5 * theta_hat.k * g.disp**2 + wheel_work(g)
    I  = g.disp**2 / sigma2
    dH = 0.5 * log1p(I * theta_hat.sigma_k2)
    return W, I, dH

def info_ceiling(M_safe, eta_M, theta_hat, sigma2):
    W_max = eta_M * M_safe
    return 0.5 * log1p(2 * W_max * theta_hat.sigma_k2 /
                       (theta_hat.k * sigma2))

# IP-270 SMV：安全裕度信息价值
def choose_probe(modes, b, x):
    best = None
    for g in info_action_candidates(modes, b):
        if g.q not in admissible(modes, b, x): continue
        if not c_ras_wm.certify_info(g, x):    continue
        W, I, dH = probe_work_info(b.theta_hat, g, b.sigma2)
        if W > eta_M * robust_margin(x, b):    continue
        smv = kappa * (b.sigma_theta - expected_sigma(b, g)) \
              - margin_cost(g, x, b) - social_physical_cost(g)
        if best is None or smv > best.smv: best = (g, smv)
    return best if best and best.smv > 0 else None   # 无利可图 → R69/R68

# IP-268 NSQ：安全 > 任务 > 探针
def safe_probe_qp(x, q, g, b):
    u_safe  = qp_safety(x, b, q)                     # 鲁棒 CBF + 接触
    u_task  = qp_task(x, q, u_safe)                  # 任务跟踪
    u_probe = nullspace_project(u_task, g)           # 探针进零空间
    if infeasible(u_probe, W_max=eta_M * robust_margin(x, b)):
        return None
    return u_safe + u_probe

def GAIT_RAS_round(M, obs):
```

## 4. 推导

**引理 19（探针-功-信息交换率）** 线性接触 `F=kx+ε`、`ε~N(0,σ²)` 下，`I(k)=x²/σ²`，`W=½kx²`，故 `I(k)=2W/(kσ²)`；高斯先验下 `ΔH=½log(1+Iσ_k²)`，`W_min(ΔH)=kσ²/(2σ_k²)(e^{2ΔH}−1)`。系 19.1：功为零则信息为零——不存在完全不动却能问出接触刚度的探针；R69 若把认证收紧到 `W→0`，MINT 会被物理规律饿死。系 19.2：交换率 `2/(kσ²)` 由刚度和噪声决定，不随探针幅度改变。

**引理 20（安全裕度账本与探针判据）** 由 `M_{t+1}≥M_t−ΔM_now+κΔσ−risk`，探针严格改善裕度当且仅当 `κ(σ_t−Eσ_{t+1})>ΔM_now+c`，即 `SMV>0`。系 20.1：**探针价值取决于地形不确定性对安全的影响 `κ`，而不只是不确定性本身**；`κ` 小则再不确定也不值得探，`κ` 大则很小的 `σ_θ` 也值得花裕度。R69 的「可分性」由此升级为「安全相关性」。

**引理 21（接触一致门的幻影模态界）** 若 `P(θ*∈Θ_t^ε)≥1−ε` 且可行性检查可靠，则真实模式被错误排除的概率 `≤ε`；任意 `q∉Adm` 的执行概率为零。故幻影模态执行率为零，代价是 `Adm=∅` 时的回退率，其上界由 `ε` 与 CBF 膨胀控制。系：R69 的「幻觉模态诱发追问」被物理可行性截断，但可能转化为「可行集过窄导致过度保守」。

**定理 18（GAIT 严格包含 FLUID/R68）** A99–A101（`T_g=id, W=0, |Q|=1, Θ={θ}`，探针退化为 R69 只读 `g_probe`）下，SMV 退化为 R69 的 `VoI−c`，CMG 退化为恒等，NSQ 探针通道消失 ⇒ 与 FLUID 逐指令相同；再 `SMV≤0`（等价 `VoI≤c`）⇒ 退化为 R68。安全侧不让步，效率侧只在「物理买得起且安全相关」时获益。

**定理 19（混合安全与无抖振）** 鲁棒 CBF 在 `Θ_t^ε` 可行、NSQ 投影满足 CBF/接触、HLC 满足驻留时间/重置条件/守卫迟滞、`W≤W_max` ⇒ 安全集 `C` 前向不变、无 Zeno、无抖振，探针不改变任务通道安全包络。系：**探针只能改变「选哪个可行模式」，不能改变安全集本身**。

**定理 20（物理不可知边界）** 若 `ΔH_req>ΔH_max(W_max)`，则任何 `W≤W_max` 的认证探针都无法把可信集压进安全包络；唯一安全选择是 `g_ask`（语义信道可信时）或放弃不可逆动作、退回鲁棒保守。系：**并非所有不确定性都能用运动解决；安全预算给知识设了物理上限**，这也是 R69 语言询问不可被物理探针完全替代的原因。

## 7. 可证伪预测

1. **P1**：线性接触区测得 Fisher 信息/机械功应接近 `2/(kσ²)`；系统性偏离说明接触/功模型错。
2. **P2**：`SMV>0` 的探针应平均提升下一步安全裕度，`SMV<0` 应平均降低；若无差异，「裕度货币」假设被证伪。
3. **P3**：CMG 应把幻影模态执行率压到 0，但提高 `Adm=∅` 时的回退率；回退率不升说明可行性检查过松或场景太简单。
4. **P4**：可变形地形上，累计探针功超过阈值后，地形模型虚假自信率应上升，任务成功率出现非单调拐点；若始终单调上升，则 `T_g` 建模不足。
5. **P5**：`T_g=id, W=0, |Q|=1` 退化场景中，GAIT 与 R69 行为差应为 0；有差则严格包含定理不成立。

## 8. 本轮最大风险

**一句话**：GAIT-RAS 把「接触即测量」当成可以记账的实验，但接触是**读写**的——探针会压实地、推走松土、扰动滑移，系统可能在稳定预算内测到一个被自己改造过的、自信而错误的地形模型，然后在下一步踩空；**最危险的不是不知道，而是用安全裕度买到了一个关于错误世界的确定答案。**

**次级风险与缓解**：PWI 仅对线性/准静态接触成立（保守上界 + 在线校验，超出模型区禁用探针）；鲁棒 CBF 过保守导致探针瘫痪（分层放宽 `κ`、允许小 `ρ_g` 但记账并设上限）；零空间把有用信号滤掉（可控权限借用 + 优先高信息/低扰动滚动扫掠）；混合可行性对未建模接触脆弱（可信集鲁棒可行性 + `Adm=∅` 回退）；探针诱导地形修改/记忆缺失（`T_g` 写入 TEF、限制重复探针、维护扰动地图）；地形欺骗/滑移注入（轮式与足式两条独立通道交叉验证，继承 R69 的证据纪律）；实时预算被 QP 击穿（降阶模型 + 预计算接触时序 + warm start + 分频）。
