# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮；本轮灵感：「深度学习」×「仿真训练」）

> R72 把安全从「认知层算法」下沉到「具身实时执行」，建立了 REG 实时执行图、IRL 意图、DMEM 接触计量、EREFLEX 三层反作用、S2R-UQ 参数桥接。但它对两个东西仍采取**黑箱信任**：
> - **深度学习**：R72 把意图网络、触觉编码器、AURA 当作「已校准的密封仪器」，只查 ECE / OOD 分数。可是**这些网络本身就是用数据训练出来的测量函数 f_θ**——它没有物理量纲、没有可追溯的传递链，其「校准」是在训练分布上的平均；一旦进入操作域（ODD）之外，网络会**高置信地错**。R72 的 S2R-UQ 只桥接「参数 θ」，却没有桥接「**学习过程 T 与数据 D**」，更没有桥接「**不确定度估计器本身可不可信**」。
> - **仿真训练**：R72 把 sim2real 残差当成满足 N(0,Σ_Δ) 的随机不确定度。但**仿真是「标准器」，不是「噪声源」**：它有**有方向、随状态变化、不可由域随机化消除的系统偏差**（物理简化、接触模型错误、渲染误差、执行器延迟）。把系统偏差当零均值噪声，会让 u_real **严重低估**；而域随机化只扩大「支撑集」，既不覆盖「真实密度」，更覆盖不了「模型形式错误」。
>
> 本轮两个灵感正好补上「上游因果链」：
> - **深度学习**：把每个可学习组件升级为**学习型仪器（LIG, Learned Instrument Gauge）**，其读数必须携带 **(训练溯源链, 有效性域 ODD, 保形覆盖证书, 不确定度分解, 偏移监控)** 五元组；不确定度不再是一串数字，而是**带覆盖语义的区间 + 可检测的失效**。
> - **仿真训练**：把仿真器升级为**带模型差异的标准器（SIM-STD）**，用 Kennedy–O'Hagan 校准框架把 sim-real gap 分解为 **尺度偏差 / 结构（模型形式）偏差 δ(x) / 参数偏差 / 随机噪声**，证明**结构偏差不可由域随机化消除、在真实标定数据支撑集之外不可识别**；从而把「仿真训练」从一次性离线流程，变成**由 gap 图指导的主动真实数据采集闭环（GDA）**。
>
> 核心命题：**不再只问「部署期的测量链可信吗」，而要问「这条测量链的仪器，是在哪个数据分布上、用哪套仿真标准、经过哪条溯源链训练出来的；当它走出那个分布时，它会不会自己知道？」** 把 R72 的「部署期具身证书」向上游扩展为 **TRAIN-GAUGE-RAS**（**T**raceable, **R**eference-standard, **A**udited, **I**nstrument-learning, **N**on-exchangeability-aware GAUGE for RAS）——**训练期计量审计闭环**。

## 0. 直觉与动机

**灵感 1（深度学习 → 模型即仪器，而且是「没有量纲、没有溯源」的仪器）**
直觉：一支温度计之所以可信，是因为它能溯源到 SI 定义，且校准证书声明了量程与最大允许误差。一个意图分类器没有这些：它的「量程」是从训练数据里**统计出来**的 ODD，它的「最大允许误差」是一组**只在同分布上成立**的保形分位数。**一旦部署分布偏离训练/校准分布，整条「传递链」就断了，而模型不会报警——它只会更自信。** 所以深度学习的计量问题不是「准确率多少」，而是**「它的保证在什么条件下成立、条件被破坏时谁来喊停」**。

**灵感 2（深度学习 → 不确定度有两层：模型说自己不确定，和模型的不确定度本身可不可信）**
直觉：深度集成、MC dropout、Laplace 近似都能吐出 σ。但**σ 本身可能错**：训练不足的区域 σ 小但误差大（过度自信），训练充分的区域 σ 大但误差小（过度保守）。所以真正需要的不是一个 σ，而是**不确定度的校准性（risk–coverage 单调）+ 失效的可检出性（shift 检测）**——这是「UQ 的 UQ」（UQ-of-UQ）。R72 只 ECE 校准了**点预测**，没校准**不确定度估计器**。

**灵感 3（仿真训练 → 仿真是「标准器」，标准器也有系统误差）**
直觉：计量学里，用一把没校准的尺子去校准另一把尺子，会把这个系统误差**传播并放大**。仿真器就是那把「母尺」：它的接触模型是刚性的、它的渲染没有真实光照、它的执行器没有真实延迟。**这些是有方向的系统偏差，不是零均值噪声。** R72 用 N(0,Σ_Δ) 去拟合残差，等于强迫系统偏差「平均为零」——在**有真实数据的地方**或许近似成立，在**没有真实数据的地方**则是纯粹的幻觉。Kennedy–O'Hagan 早在 2001 年就指出：计算机模型校准必须显式建模 **model discrepancy δ(x)**，否则参数会被 δ 污染，形成「补偿性误导」。

**灵感 4（仿真训练 → 域随机化只扩「支撑集」，不补「密度」和「模型形式」）**
直觉：域随机化（DR）把参数在一个大盒子里随机撒，看起来「什么都见过」。但三件事它做不到：
- **支撑覆盖**：真实状态可能落在盒子外（真实摩擦、真实柔性、真实人）；
- **密度覆盖**：盒子里均匀撒 ≠ 真实世界在该处的概率密度；
- **结构覆盖**：如果真值不在仿真器的函数族里（例如真实接触是软接触，仿真只有刚体接触），那么**无论怎么随机化参数，都到不了真值**。
**DR 提高了鲁棒性（方差），却可能掩盖偏差（均值）**——这是「用方差冒充准确度」的典型 Goodhart。

**灵感 5（非交换性 → 保形预测的保证在仿真训练下会失效）**
直觉：split conformal 的 90% 覆盖保证，前提是「校准集与测试集可交换（exchangeable）」。**仿真训练 + 现实部署**恰恰打破交换性：校准集是仿真的（或少量实机），测试集是现实的。此时名义 90% 的覆盖可以掉到任意低。修复只有三条路：**加权保形**（估计密度比，且要求支撑重叠）、**自适应保形 ACI**（不依赖交换性，给长期平均覆盖）、**偏移检测 + 证书吊销**（放弃保证，改为安全降级）。三条必须同时有，因为它们的失效模式不同：加权保形怕「无重叠」，ACI 怕「慢漂移不如突变」，偏移检测怕「检测太慢」。

**灵感 6（Gap-directed acquisition → 把「仿真训练」变成闭环，而不是一次性）**
直觉：既然仿真便宜、实机贵，直觉是「多在仿真里训」。但真正决定安全的不是仿真数据的**数量**，而是**仿真在哪些区域最不可信、且这些区域恰好安全关键**。所以应该用**模型差异后验**画一张「仿真说谎地图」，主动到「谎最大 / 最不确定」的地方采实机数据——这是**针对模型差异的贝叶斯最优实验设计（OED）**，不是针对世界状态的主动学习。这把 R72 的 ERVOI 从「问人」扩展到「问世界（做实验）」。

## 1. 形式化定义（增量：定义 366–380）

**定义 366（TRAIN-GAUGE-RAS 总览与五不变式）** TRAIN-GAUGE-RAS = (LIG, TCHAIN-T, SIM-STD, COVER, SHIFT, GDA, GAUGE-RAS†)。
(i) **训练溯源优先**：每个可学习组件进入控制/计量环前，必须携带完整 TCHAIN-T；缺链即冻结该组件，降级为 R72 固定参数形态；
(ii) **有效性域显式**：每个学习型仪器声明 D_v（ODD）；**D_v 之外不允许输出点估计**，只能输出保守包络 + 弃权标记；
(iii) **覆盖语义可声明**：每个概率输出必须携带 (coverage_type ∈ {marginal, weighted, ACI, none}, empirical_cov, overlap_coef, cal_set_hash)；**不允许「裸概率/裸 σ」进入风险缩放**；
(iv) **仿真系统偏差不归零**：模型差异 δ(x) 的后验必须随读数传递；在真实标定数据支撑集之外，δ 取**先验上界**而非 0；
(v) **严格退化链**：溯源断 ⇒ 冻结组件；ODD 越界 ⇒ 收窄/弃权；覆盖失效 ⇒ 换 R72 保守界；偏移吊销 ⇒ E-IVG 降级；全失效 ⇒ R68。**安全侧只增不减。**

**定义 367（学习型仪器 LIG）** L = (f_θ, T, D_v, U_L, C_L)：
- f_θ：学习型测量函数（意图网络、触觉编码器、AURA、策略网络等）；
- T：训练过程（数据 D、损失、优化器、随机种子、课程）；
- D_v ⊆ 𝒮×𝒜：有效性域（operational design domain），可测集；
- U_L：不确定度分解（定义 372）；
- C_L：覆盖/校准证书（定义 371）。
测量语义：在 D_v 内，y = f_θ(x) + e，e 由 C_L 给出**带覆盖语义的区间**；在 D_v 外，**不定义读数**，只输出保守包络。**与物理仪器的根本差异：f_θ 没有量纲传递链，TRAIN-GAUGE 用 TCHAIN-T + 保形 + 差异后验「人工制造」可溯源性。**

**定义 368（训练溯源链 TCHAIN-T）** 对每个可学习组件：
TCHAIN-T = (h_data, h_label, ρ_syn, κ_annot, A_noise, C_curric, h_code, h_seed, h_env, u_train)。
- h_data：训练样本 Merkle 哈希（逐样本来源：真实/仿真/合成/增强）；
- h_label：标注协议哈希；κ_annot：标注者间一致性（Cohen/Fleiss κ）；
- ρ_syn：合成/真实混合比；
- A_noise：标签噪声估计（cleanlab / 混淆矩阵反演）；
- C_curric：课程与域随机化调度签名；
- h_code, h_seed, h_env：可复现性指纹；
- u_train：数据诱导的参数不确定性（bootstrap / 集成离散度）。
**不变式**：h_data 的支撑必须覆盖声明的 D_v；任何在 D_v 外采样的训练样本必须被标记为「域外训练样本」，其数量计入 u_train。

**定义 369（仿真标准器与模型差异 SIM-STD）** 采用 Kennedy–O'Hagan 校准框架，真实观测生成模型：
y_real(x) = ρ(x)·f_sim(x; θ) + δ(x) + ε,  ε ~ 𝒩(0, σ²),
其中 f_sim 为仿真器在状态-动作 x 的输出，θ 为标定参数，ρ 为尺度偏差，**δ(x) 为模型形式差异（systematic discrepancy，先验为 GP）**，ε 为随机噪声。sim-real gap 分解：
Δ(x) = [ρ(x)−1]·f_sim(x;θ) + δ(x) + [f_sim(x;θ) − f_sim(x;θ*)]。
三项分别对应**尺度偏差 / 结构（模型形式）偏差 / 参数偏差**。**关键**：δ 只在真实数据 {x_i, y_i} 的支撑集内可辨识；支撑集外 δ 的后验退回 GP 先验（均值 0、方差取上界），**不得当作 0**。仿真不确定度：
U_sim(x)² = Var[δ(x) | 𝒟_real] + Var[ρ(x) f_sim(x;θ*) | 𝒟_real] + σ²。

**定义 370（域随机化覆盖的三分解与结构偏差不可约性）** 设随机化分布 P_DR（参数盒 + 噪声分布），真实分布 P_real。定义三层覆盖：
- **支撑覆盖** c_sup = P_real(supp P_DR)；
- **密度覆盖** c_den = OC(P_DR, P_real) = ∫ min(p_DR, p_real)（重叠系数）；
- **结构覆盖** c_str = 1 当且仅当真值函数 g ∈ closure(ℱ_sim)，否则 0。
**命题（DR 不修复结构偏差）**：若存在 ε_str > 0 使 min_{θ∈Θ} sup_x |f_sim(x;θ) − g(x)| ≥ ε_str（模型族误设），则任意随机化分布 P_DR 都无法把 E_{P_DR}[δ(x)] 或 sup_x |E_{P_DR}[f_sim(x;θ)] − g(x)| 降到 ε_str 以下。**域随机化提高 c_sup、可能略微提高 c_den，但对 c_str 无任何作用；它甚至会用方差把均值偏差「洗白」。**

**定义 371（非交换性下的覆盖语义 COVER）** 校准集 S_cal ~ P_cal，测试 ~ P_test，**允许 P_cal ≠ P_test**。覆盖风险 R(α) = P_test(Y ∉ C_α(X)) − α。三种可声明语义（必须显式标注）：
- **Marginal（交换性成立）**：标准 split conformal，P_test(Y∈C) ≥ 1−α；
- **Weighted（协变量偏移）**：w(x) = dP_test/dP_cal，加权分位数给出 P_test 覆盖；需 (w 已知或有界估计, 重叠 OC > 0)。**界**：P_test(Y∈C) ≥ 1−α − d_TV(P_cal,P_test) ≥ 1−α − √(½·KL(P_test‖P_cal))（Pinsker），当 OC→0 时该界退化到无信息；
- **ACI（任意非交换）**：Gibbs–Candès 自适应更新 α_{t+1} = α_t + γ(α − err_t)，给**长期平均覆盖** (1/T)Σ err_t ≤ α + O(1/(γT))，不依赖交换性，但**不给单步保证**，且对突变有滞后。
输出证书 C_L = (type, empirical_cov, OC, ACI_traj_hash, cal_set_hash)。**「保形」不是标签，是一个带前提的数学命题。**

**定义 372（学习型仪器不确定度分解 U_L）** 
U_L = (U_epi^net, U_ale, U_shift, U_sim^param, U_sim^struct, U_cal)：
- U_epi^net：网络认知不确定度（集成/Laplace），**其自身需通过 risk–coverage 校准审计（UQ-of-UQ）**；
- U_ale：数据固有随机性；
- U_shift：分布偏移幅度（密度比方差 / OOD 分数）；
- U_sim^param：标定参数后验；
- U_sim^struct：模型差异后验（定义 369，支撑集外不可约）；
- U_cal：保形有限样本修正 / 集合大小。
**组合规则用区间算术（保守）而非方差相加**：各分量既非独立、也非零均值，√(Σ U_i²) 会系统性低估。默认取 U_L = max_i U_i + λ_corr·Σ_{i<j} Cov_+，且对 U_sim^struct 在支撑外取**先验上界**。

**定义 373（偏移监控与证书生命周期 SHIFT）** 偏移统计量 s_t = f_shift(x_t)（密度比 / 马氏距离 / 集成分歧 / OOD 分数）。检测延迟 τ_d，误报率 FAR。证书状态机：
**valid → suspect（s_t > τ_sus）→ revoked（s_t > τ_rev，或滑动窗覆盖违规）**。
吊销语义：该组件证据权重置 0，进入 R72 保守模式；**重新认证需要偏移区域内的新真实标定数据**，而非「重启就好」。

**定义 374（Gap-directed 主动真实数据采集 GDA）** 给定差异后验 δ|𝒟_real，选择真实实验 x*：
x* = argmax_x { MI(δ(x); (x,Y)) − λ_cost·c_real(x) − λ_risk·Risk(x) }，
s.t. 硬安全包络。MI 为对**模型差异**的互信息（不是对世界状态）。**口号：到「仿真最可能说谎、且最不确定、且安全关键」的地方去采真数据。** 与 R72 ERVOI 互补：ERVOI 问人，GDA 问世界。

**定义 375（训练-部署统一证书 J_TRAIN）** 
J_TRAIN = (J_EMB, tchain_t_hash, odd_def, scl_level, discrepancy_post_hash, coverage_type, empirical_cov, overlap_coef, shift_state, train_ver)。
Valid ⇔ Valid(J_EMB) ∧ TCHAIN-T 完整 ∧ ODD 覆盖 ≥ 阈值 ∧ 覆盖语义已声明且经验覆盖过检 ∧ shift 未吊销 ∧ 仿真可信度 ≥ 风险等级要求。

**定义 376（威胁模型 AIC-TRAIN）** ℰ_TRAIN = ℰ_data × ℰ_sim × ℰ_cal × ℰ_shift：
- ℰ_data = {标签投毒、后门触发器、溯源伪造、合成/真实比谎报、域外样本偷灌}；
- ℰ_sim = {规范博弈/奖励黑客、仿真器漏洞利用、标定参数投毒、差异标定数据伪造}；
- ℰ_cal = {校准集污染、测试期偏移攻击（专门打穿覆盖）、重叠度隐瞒};
- ℰ_shift = {渐变协变量漂移、对抗 OOD、伪同分布投毒}。

**定义 377（严格退化链）** 
- 溯源断（TCHAIN-T 缺失/哈希不符）⇒ 冻结该组件，退 R72 固定参数形态；
- ODD 覆盖 < 阈值 ⇒ 收窄到已验证子域，或输出保守包络 + 弃权；
- 覆盖失效（shift 后经验覆盖破界）⇒ 换 R72 保守固定界（按重叠缺口膨胀）；
- shift revoked ⇒ E-IVG 降级（R71 / R68）；
- 全失效 ⇒ R68（纯视觉/本体开环 + 硬安全包络）。
**逐指令等价性对每个退化分支成立；安全单调不减。**

**定义 378（选择性仪器与弃权语义）** 学习型仪器可选择**弃权（abstain）**而非硬答。设覆盖率 c（回答比例），选择性风险 R_sel(c) = E[ℓ | 已回答]。运行点在 risk–coverage 曲线上按风险预算选：c* = max{c : R_sel(c) ≤ ε_risk}。**AURC（risk-coverage 曲线下面积）是「UQ 的 UQ」的核心审计指标**；弃权触发 R72 ERVOI 求人/求实验。

**定义 379（仿真可信度分级 SCL）** 参照 V&V/UQ 与 NASA-STD-7009 精神分五级：
- L0 无 V&V；L1 仅代码验证（verification）；L2 参考任务验证（validation，有限域）；L3 跨域验证（含 shift）；L4 持续验证 + 差异模型在线维护。
**部署约束**：高风险任务（λ_floor 高、人机共融）只允许 L3+；L2 仅允许在已验证子域 + 弃权；L0/L1 禁止进入控制环。**可信度是准入条件，不是评分。**

**定义 380（训练期指标扩展 T-MIB）** 在 R72 E-MIB 上新增：
- **溯源族**：TCHAIN-T 完整率、ρ_syn、κ_annot、标签噪声估计、域外训练样本比；
- **覆盖族**：经验覆盖率 vs 名义、条件覆盖（分群最差覆盖）、集合大小、OC、ACI 轨迹偏差；
- **仿真族**：δ 后验方差、c_sup / c_den / c_str、各偏差分量、SCL 等级；
- **偏移族**：OOD AUROC、检测延迟 τ_d、FAR、吊销次数；
- **选择性族**：AURC、选择性风险、弃权率、条件风险（最差子群）。
所有指标同遵循定义 332 六元组（φ,m,u,D,τ,I⊥）与定义 333 DAG 分层。

# IP-295 LIG：学习型仪器封装（读数必须带覆盖语义与差异后验）
@dataclass
class LearnedInstrument:
    f: Callable                    # 学习型测量函数
    tchain: TrainingProvenance     # TCHAIN-T
    odd: ValidityDomain            # D_v
    conformal: ConformalCalibrator # COVER
    discrepancy: ModelDiscrepancyGP  # SIM-STD 的 δ(x)
    shift: ShiftMonitor            # SHIFT
    risk_class: str                # 决定 SCL 准入阈值

    def measure(self, x):
        if not self.odd.contains(x):
            # 域外：不返回点估计，返回保守包络 + 弃权
            return Measurement(x, point=None,
                               interval=self.conservative_envelope(x),
                               u=self.discrepancy.prior_upper(x),
                               status="OUT_OF_ODD")
        y = self.f(x)
        C, cov_type, oc = self.conformal.predict(y, x)
        u_sim = self.discrepancy.uncertainty(x)   # 支撑外自动取先验上界
        u = combine_interval_arith(self.uq_components(x), u_sim)
        st = self.shift.step(x)
        return Measurement(x, point=y, interval=C, u=u,
                           status=st, coverage=cov_type, overlap=oc)

# IP-296 TCHAIN-T：训练溯源链（训练期生成，部署期只读校验）
def build_tchain_t(dataset, labels, curriculum, code_repo, seed):

        u_train=bootstrap_param_uncertainty(dataset, labels))

# IP-297 SIM-STD：Kennedy–O'Hagan 模型差异校准
def fit_sim_standard(x_real, y_real, f_sim, theta_post):
    # y_real = rho * f_sim(x; theta) + delta(x) + eps
    rho   = fit_scale_bias(x_real, y_real, f_sim, theta_post)
    resid = y_real - rho * f_sim(x_real, theta_post.mean)
    delta_gp = fit_gp(resid, x_real, kernel="matern52")
    return ModelDiscrepancyGP(
        gp=delta_gp, support=x_real,
        outside_policy="PRIOR_UPPER_BOUND")       # 支撑外绝不取 0

# IP-298 COVER：加权保形 + ACI 双保险
class ConformalCalibrator:
    def __init__(self, cal_scores, alpha=0.1, gamma=0.01):
        self.scores, self.alpha, self.alpha0, self.gamma = cal_scores, alpha, alpha, gamma
        self.err_hist = []
    def density_ratio(self, x):                    # 域分类器估计 dP_test/dP_cal
        return self.domain_clf.ratio(x)
    def predict(self, x):
        w = self.density_ratio(x)
        q = weighted_quantile(self.scores, self.cal_weights * w, 1 - self.alpha)
        oc = self.overlap_coefficient(x)           # OC→0 时报告 "no guarantee"
        ctype = "weighted" if oc > self.oc_min else "aci_only"
        return self.make_set(x, q), ctype, oc
    def aci_update(self, err_t):
        self.err_hist.append(err_t)
        self.alpha += self.gamma * (self.alpha0 - err_t)   # 长期覆盖修正

# IP-299 SHIFT：偏移统计 + 证书生命周期
class ShiftMonitor:
    def step(self, x, y_true=None):
        s = self.score(x)                          # 密度比 / 集成分歧 / OOD
        if s > self.tau_rev or self.window_cov_violated(y_true):
            self.state = "REVOKED"                 # 证据权重 -> 0
        elif s > self.tau_sus:
            self.state = "SUSPECT"
        return self.state

# IP-300 GDA：gap-directed 真实数据采集（针对 δ 的 OED）
def gap_directed_acquisition(discrepancy_gp, candidate_xs, risk_model, budget):
    best = None
    for x in candidate_xs:
        if not budget.allow(x): continue
        ig   = mutual_info_discrepancy(discrepancy_gp, x)  # δ 的信息增益
        gain = ig - LAM_RISK * risk_model(x) - LAM_COST * real_cost(x)
        if best is None or gain > best.gain:
            best = Candidate(x, gain)
    return best if best and best.gain > 0 else None   # 无正收益 -> 不采

# IP-301 J_TRAIN：训练-部署统一证书
def J_TRAIN(M):
    return TrainCert(

        cov=(M.lig.conformal.type, M.lig.conformal.emp_cov, M.lig.conformal.oc),
        shift=M.lig.shift.state,

# IP-303 TRAIN-GAUGE 主闭环（复用 R72 三域，前置训练期门控）
def TRAIN_GAUGE_round(M, obs, audio, tac_frame):
    # 1) 训练期证书门控（部署前/在线周期检查）
    if not M.j_train.valid():
        M.mode = M.j_train.fallback          # R72 / R71 / R68，逐指令等价
    # 2) 学习型仪器读数：先 ODD/shift，再覆盖语义

    m_intent = inst.measure(extract_intent_obs(obs, audio))
    if m_intent.status == "OUT_OF_ODD":

    # 3) 用带覆盖语义的区间（而非点/裸σ）进入 R72 E-RISK
    U_sim = m_intent.u.sim_struct          # δ 后验（支撑外上界）
    lam = embodied_risk_scale(*M.risk_inputs, U_sim, params=M.risk_params)
    # 4) gap-directed 采集（低频、预算约束、事件触发）
    if M.clock.due_gda() and M.discrepancy.needs_data():
        x_star = gap_directed_acquisition(M.discrepancy, M.candidates,
                                          M.risk_model, M.budget_gda)
        if x_star: M.real_experiment_queue.push(x_star)
    # 5) 异常/吊销 -> 触发退化与重认证

        M.mode = "R71"

## 3. 推导

**引理 33（TCHAIN-T 完整 ⇒ 训练可重放、偏差可归因）** 若 (h_data, h_label, C_curric, h_code, h_seed, h_env) 全部匹配，则训练过程可逐位重放（在确定性硬件与固定并行归约下）。系：任何部署期的系统性误差都可沿 TCHAIN-T 归因到「数据 / 标签 / 课程 / 代码 / 环境」中的某一环，而不是笼统的「模型不行」。**可归因是计量的前提。**

**引理 34（交换性破坏 ⇒ 边际覆盖可任意失效）** 设 P_cal ≠ P_test。对任意 α∈(0,1) 与任意 δ_cov>0，存在 P_test（把质量集中到 C_α 以外的高分区域）使 P_test(Y∈C_α) < δ_cov，尽管 P_cal 上覆盖 ≥ 1−α。证明：保形集是校准分布中最优分位数的水平集；把测试质量搬到该水平集之外即可。系：**仿真校准 + 现实部署是「结构性非交换」，名义覆盖不是现实覆盖。**

**引理 35（加权保形的覆盖缺口由全变差/重叠控制）** 对任意保形集 C，P_test(Y∈C) ≥ 1−α − d_TV(P_cal,P_test) ≥ 1−α − √(½ KL(P_test‖P_cal))。证明：Q(A) = P(A) + (Q−P)(A) ≥ P(A) − d_TV(P,Q)。系：**当 overlap OC = 1 − d_TV 趋近 0（仿真与现实的支撑几乎不交），任何保形保证都退化为无信息的 0。** 这解释了为什么「仿真训得再好也要少量真实校准数据」不是工程妥协，而是**数学必要条件**。

**引理 36（域随机化不消除结构偏差）** 在定义 370 下，若模型族 ℱ_sim 误设（c_str=0），则 min_{θ∈Θ} sup_x |f_sim(x;θ) − g(x)| ≥ ε_str > 0，且该下界与随机化分布 P_DR 无关。证明：下界只依赖函数族与真值的距离；P_DR 只是在 Θ 上的测度，改变测度不改变函数族的值域。系：**DR 能买到鲁棒性（对 θ 的敏感性下降），买不到保真度（对 g 的系统偏差不降）；把 DR 当 sim2real 解药是一种范畴错误。**

**引理 37（模型差异在支撑集外不可辨识）** 在定义 369 下，δ 的后验只在 𝒟_real 的支撑集 S 内被数据约束；在 x ∉ S 处，p(δ(x)|𝒟_real) = p(δ(x))（先验），其方差为 GP 先验方差（上界）。证明：GP 的后验均值和方差由核在 S 上的观测决定；远离 S 时核相关性趋于 0，后验退回先验。系：**「仿真外推的偏差是 0」是一个不可检验的假设；TRAIN-GAUGE 要求在 S 外显式报告「差异未知」并取保守上界。** 这正是 R72 把 δ 塞进 N(0,Σ_Δ) 时丢掉的东西。

**引理 38（GDA 的有限停止与预算约束）** 若对 δ 的互信息随采样边际递减，且每次真实实验成本有正下界 c_real ≥ ε_c > 0，则存在有限 n* 使第 n*+1 次采集的边际净收益 ≤ 0，GDA 在 n* 停止。证明：与 R72 引理 31 同构——边际收益非增、边际成本有正下界 ⇒ 净收益终将变负。系：**「用实机数据补仿真」不会无限进行，它有一个可计算的最优停止点，不是无底洞。**

**定理 27（TRAIN-GAUGE 严格包含）** 在 A111–A116（溯源可校验、覆盖语义成立、δ 后验有界、SCL 分级有效、shift 可检出、GDA 可停止）下，TRAIN-GAUGE 在退化条件下逐指令等价于 R72 EMBODIED / R71 GAUGE-RAS / R68；且对任意有效执行，其风险界 ≤ R72 风险界。**安全单调不减，效率仅在「溯源完整、覆盖有效、差异可辨」时获益。**

**定理 28（训练期证书有效性 ⇒ 条件化风险界）** 若 J_TRAIN 有效，则物理/认知执行风险
Risk ≤ ε_emb + Gap_cov + B_δ，
其中 ε_emb 为 R72 界，Gap_cov 为覆盖缺口（引理 35 的 d_TV 项），B_δ 为支撑集内 δ 后验上界（支撑外取先验上界）。证明：风险 = R72 基础风险 + 学习型仪器引入的统计误差；后者由覆盖缺口与模型差异两部分构成，二者相加。**注意这是「条件于覆盖语义真实成立」的界——证书不能自证其前提。**

**定理 29（证书吊销的单调安全）** 对任意时刻 t，SHIFT 吊销只会把可行动作集 𝒜_allowed 缩小（或保持不变），绝不扩大：吊销后组件权重 → 0、λ_floor 抬高、模式降到 R71/R68。证明：吊销条件只触发定义 373/377 的降级映射，这些映射在构造上是「移除动作 + 增大保守性」。系：**偏移监控即便误报，也只会让系统更保守（可用性下降），不会让它更冒险——这是把「检测器不完美」纳入安全论证的关键。**

## 6. 本轮最大风险

**一句话**：TRAIN-GAUGE 把安全从「相信部署期证书」进一步转移到「相信 **TCHAIN-T 的哈希没有被伪造**、相信 **加权保形的密度比估计在无重叠时不撒谎**、相信 **KOH 的 GP 差异先验在支撑集外给出的上界真的覆盖了真值**、相信 **偏移监控在慢漂移下不会漏检**」——**如果真实标定数据本身稀少且有偏（只采了容易采的区域）、仿真器在安全关键区域恰好结构性误设（c_str=0 而无人知晓）、密度比估计在无重叠区给出虚假的低方差、或者偏移是渐变到每个单步都「未超阈」的累积漂移——那么系统会拿着一条「哈希完整、覆盖语义齐全、SCL 达标」的训练证书，在它从未真正见过的区域里高置信地执行，而所有审计数字都在有效域内。这是「**用仿真与自我标定互相作证，完成一次合法化的自证清白**」。**

次级风险与缓解：
1. **真实数据稀少/有偏** → GDA 专攻高差异区 + 分层采样审计 + 对未覆盖区强制弃权（定义 378），宁可少做不可错做。
2. **结构误设不可知** → 多仿真器交叉验证（E373/E381）+ SCL 降级 + 对差异后验做「模型族敏感性分析」，把 c_str 当作**不可消除的认知负债**显式记账。
3. **密度比/重叠估计失真** → 报告 OC 与权重方差，OC<阈值直接降级为 ACI-only；对密度比估计器本身做校准审计（UQ-of-UQ）。
4. **慢漂移累计漏检** → 除逐点阈值外加**累积和（CUSUM）/滑动窗覆盖检验**，把「每步都合规但长期漂移」变成可检测信号。
5. **证书自证前提** → J_TRAIN 显式声明「条件于覆盖语义成立」，并把前提的验证（真实标定覆盖、SCL）作为**独立可审计项**，不允许在同一证书内自洽。
6. **计算/存储膨胀** → GP 后验表 + 分块缓存；控制域只查 O(1) 保守表；TCHAIN-T 只在部署前与周期性校验。

## 2. 形式化定义（要点版）

**定义 366（TRAIN-GAUGE 总览与五不变式）** 训练溯源优先 / 有效性域显式 / 覆盖语义可声明 / 仿真系统偏差不归零 / 严格退化链。**没有覆盖语义的数字不得进入风险缩放。**

**定义 367（学习型仪器 LIG）** L=(f_θ,T,D_v,U_L,C_L)。ODD 内给出带覆盖语义的区间；ODD 外**不定义读数**，只给保守包络+弃权。**与物理仪器差异：无天然量纲链，用溯源+保形+差异后验人工制造可溯源性。**

**定义 368（训练溯源链 TCHAIN-T）** 覆盖数据/标签/合成比/一致性/噪声/课程/代码/种子/环境/参数不确定度。**不变式：训练集支撑必须覆盖声明的 D_v，域外样本显式记账。**

**定义 369（仿真标准器与模型差异 SIM-STD）** y_real=ρ f_sim+δ(x)+ε；δ 为 GP。**关键：δ 只在真实标定支撑集内可辨识；支撑外取先验上界，不得取 0。** U_sim²=Var[δ|D]+Var[参数]+σ²。

**定义 370（域随机化覆盖三分解与结构偏差不可约性）** c_sup/c_den/c_str。**命题：模型族误设时，任意 P_DR 都无法把 sup_x|E_DR[f_sim]−g| 降到 ε_str 以下；DR 买鲁棒，买不到保真。**

**定义 371（非交换覆盖语义 COVER）** marginal / weighted（界 1−α−d_TV）/ ACI（长期覆盖）。OC→0 时保证退化为无信息。**「保形」不是标签，是带前提的数学命题。**

**定义 372（不确定度分解 U_L）** 六分量：网络认知/固有/偏移/参数/结构/保形。**用区间算术而非方差相加；U_sim^struct 支撑外取上界；U_epi^net 自身需 risk–coverage 校准（UQ-of-UQ）。**

**定义 373（偏移监控与证书生命周期 SHIFT）** s_t → valid/suspect/revoked。**吊销把证据权重置 0，重认证需偏移区新真实数据。**

**定义 374（Gap-directed 采集 GDA）** 针对 δ 的互信息 − 成本 − 风险，s.t. 安全包络。**到「仿真最可能说谎、最不确定、且安全关键」处采真数据。**

**定义 375（训练-部署统一证书 J_TRAIN）** J_EMB + 溯源 + ODD + SCL + δ 后验 + 覆盖语义 + shift。**Valid 显式条件于「覆盖前提成立」，不自证。**

**定义 376（威胁模型 AIC-TRAIN）** ℰ_data×ℰ_sim×ℰ_cal×ℰ_shift：投毒/后门/溯源伪造、规范博弈/奖励黑客、校准污染/覆盖攻击、慢漂移/对抗 OOD。

**定义 377（严格退化链）** 溯源断→冻结组件；ODD 越界→收窄/弃权；覆盖失效→R72 保守界（按缺口膨胀）；shift 吊销→E-IVG 降级；全失效→R68。**逐指令等价，安全单调不减。**

**定义 378（选择性仪器与弃权）** R_sel(c)=E[ℓ|已回答]；运行点 c*=max{c:R_sel(c)≤ε_risk}；AURC 为核心审计指标。**弃权触发 ERVOI 或 GDA。**

**定义 379（仿真可信度分级 SCL）** L0 无 V&V / L1 仅验证 / L2 参考任务验证 / L3 跨域验证 / L4 持续验证+差异在线。**高风险任务仅允许 L3+；L0/L1 禁入控制环。可信度是准入条件，不是评分。**

**定义 380（训练期指标扩展 T-MIB）** 溯源族（完整率/ρ_syn/κ/噪声/域外比）、覆盖族（经验vs名义/条件覆盖/集合大小/OC/ACI 偏差）、仿真族（δ 方差/c_sup,c_den,c_str/偏差分量/SCL）、偏移族（OOD AUROC/延迟/FAR/吊销次数）、选择性族（AURC/选择性风险/弃权率/最差子群）。同遵循定义 332/333。

def fit_sim_standard(x_real, y_real, f_sim, theta_post):
    rho = fit_scale_bias(x_real, y_real, f_sim, theta_post)
    resid = y_real - rho * f_sim(x_real, theta_post.mean)
    delta_gp = fit_gp(resid, x_real, kernel="matern52")
    return ModelDiscrepancyGP(gp=delta_gp, support=x_real,
                              outside_policy="PRIOR_UPPER_BOUND")

# IP-298 COVER：加权保形 + ACI
class ConformalCalibrator:
    def __init__(self, cal_scores, alpha=0.1, gamma=0.01):
        self.scores, self.alpha, self.alpha0 = cal_scores, alpha, alpha
        self.gamma = gamma
    def density_ratio(self, x): return self.domain_clf.ratio(x)
    def predict(self, x):
        w = self.density_ratio(x)
        q = weighted_quantile(self.scores, self.cal_weights * w, 1 - self.alpha)
        oc = self.overlap_coefficient(x)
        ctype = "weighted" if oc > self.oc_min else "aci_only"
        return self.make_set(x, q), ctype, oc
    def aci_update(self, err_t):
        self.alpha += self.gamma * (self.alpha0 - err_t)

# IP-299 SHIFT：偏移监控与证书吊销
class ShiftMonitor:
    def step(self, x, y_true=None):
        s = self.score(x)
        if s > self.tau_rev or self.window_cov_violated(y_true):
            self.state = "REVOKED"
        elif s > self.tau_sus:
            self.state = "SUSPECT"
        return self.state

                - LAM_RISK * risk_model(x) - LAM_COST * real_cost(x))
        if best is None or gain > best.gain: best = Candidate(x, gain)
    return best if best and best.gain > 0 else None

## 4. 推导

**引理 33（TCHAIN-T 完整 ⇒ 可重放、可归因）** 全哈希匹配 ⇒ 训练可逐位重放（确定性硬件），任何部署误差可归因到数据/标签/课程/代码/环境之一。**可归因是计量前提。**

**引理 34（交换性破坏 ⇒ 边际覆盖任意失效）** P_cal≠P_test 时，对任意 α、δ_cov，存在 P_test 使 P_test(Y∈C_α)<δ_cov，尽管 P_cal 覆盖≥1−α。**仿真校准+现实部署是结构性非交换。**

**引理 35（加权保形缺口由全变差控制）** P_test(Y∈C) ≥ 1−α − d_TV(P_cal,P_test) ≥ 1−α − √(½ KL(P_test‖P_cal))。**OC→0 时保证退化为无信息；少量真实校准数据是数学必要条件，不是工程妥协。**

**引理 36（DR 不消除结构偏差）** 模型族误设时 min_θ sup_x|f_sim−g|≥ε_str>0，且与 P_DR 无关。**DR 买鲁棒不买保真；把 DR 当 sim2real 解药是范畴错误。**

**引理 37（模型差异支撑外不可辨识）** x∉S_real 时 p(δ(x)|D)=先验，方差为上界。**「仿真外推偏差为 0」是不可检验假设；必须显式报告「差异未知」并取保守上界。**

**引理 38（GDA 有限停止）** 边际 MI 递减 + 成本正下界 ⇒ 存在有限 n*。**补真数据有可计算的最优停止点，不是无底洞。**

**定理 27（严格包含）** 在 A111–A116 下逐指令等价 R72/R71/R68；风险界 ≤ R72。**安全单调不减。**

**定理 28（训练期证书 ⇒ 条件化风险界）** J_TRAIN 有效 ⇒ Risk ≤ ε_emb + Gap_cov + B_δ。**界条件于「覆盖语义真实成立」，证书不能自证前提。**

**定理 29（吊销单调安全）** 吊销只缩动作集不扩：权重→0、λ_floor↑、模式降级。**检测器误报只降可用性，不增冒险性。**

## 7. 本轮最大风险

**一句话**：TRAIN-GAUGE 把安全从「相信部署期证书」进一步转移到「相信 **TCHAIN-T 未被伪造**、相信 **密度比在无重叠时不撒谎**、相信 **GP 差异先验在支撑外真的覆盖了真值**、相信 **偏移监控在慢漂移下不漏检**」——**如果真实标定数据稀少且有偏、仿真器在安全关键区恰好结构性误设而无人知晓、密度比在无重叠区给出虚假低方差、或偏移是每步都不超阈的累积漂移——系统会拿着「哈希完整、覆盖语义齐全、SCL 达标」的训练证书，在从未真正见过的区域高置信执行，而所有审计数字都在有效域内。这是「用仿真与自我标定互相作证，完成一次合法化的自证清白」。**

次级风险与缓解：
1. **真实数据稀少/有偏** → GDA 专攻高差异区 + 分层审计 + 未覆盖区强制弃权。
2. **结构误设不可知** → 多仿真器交叉验证（E373/E381）+ SCL 降级 + 模型族敏感性分析，把 c_str 当**不可消除认知负债**显式记账。
3. **密度比/重叠失真** → 报告 OC 与权重方差，OC<阈值降级 ACI-only；对密度比估计器做 UQ-of-UQ。
4. **慢漂移漏检** → CUSUM/滑动窗覆盖检验，把「每步合规但长期漂移」变成可检测信号。
5. **证书自证前提** → J_TRAIN 显式声明条件，前提验证（真实覆盖/SCL）作为独立可审计项。
6. **计算/存储膨胀** → GP 后验表 + 分块缓存；控制域 O(1) 查表；TCHAIN-T 仅部署前/周期校验。
7. **弃权过多** → 选择性风险预算挂钩任务价值；用 GDA 把「弃权区」转成「已验证区」，形成正循环。
