### 第 1 轮灵感驱动研究记录

**灵感词**：三维感知、创新点

**直觉与动机**：

先给直觉。当前 KEMPC/CADVS 的证书体系（v29 十二证 + CADVS-v1 的 STCK/GCK/DAKI）已经把「常识、时序、时空域、抓取」纳入证书，但所有证书本质上仍是**离散消息 + 局部球域**。它们回答「这条规则是否通过」，却回答不了「机器人脚下的三维世界到底被看见了多少、哪些体素仍是未知、某条证书在空间中如何衰减」。这正是「三维感知」暴露出的缺口：控制决策发生在三维空间里，而证据却以扁平列表存在。

一个具体场景：机器人在货架间抓取，视觉伺服 FQC 通过、抓取 GCK 通过、时空 STCK 也通过，但目标物背后的支撑面从未被任何深度传感器观测到。三张证书全绿，系统据此规划手部轨迹，结果撞上未建模的悬空物——证书没有说谎，是证书体系缺少「三维证据覆盖度」这一维。这正是上一轮 R36「证据链断裂」在三维感知层面的具体化。

因此本轮的核心直觉是：**把证书从「消息列表」升级为「三维证书场」，把三维重建从「几何表示」升级为「可渲染的证书载体」，再用主动感知去主动填补证书亏空**。三者分别对应表征、渲染、闭环，也正好构成三个可辩护的创新点。

1. **三维感知证书场（3D-PCF）**：在稀疏体素哈希上维护每个体素的观测次数、占据概率、重建方差与证书置信度。证书的「有效」不再是一个布尔值或一个球，而是一个随空间位置与时间衰减的场 conf(c, p, t)。未知体素被显式标记为 unknown，任何落入 unknown 的控制查询一律拒绝。这把 STCK 的单球域推广为完整场，并把 R36 的「无数据支撑」变成可查询、可告警的一等状态。

2. **证书标注高斯（CA-3DGS）**：用 3D Gaussian Splatting 作为三维场景表示，每个高斯除 μ、Σ、α、SH 外，额外携带证书置信度 γ_i、证据来源与时间戳。渲染时不仅合成颜色与深度，还用同一套 α 合成权重合成证书置信度与不确定性，得到「证书渲染图」。这让证书**可微**：可以沿 ∇γ 对高斯做证书感知的致密化/剪枝，把表示能力集中到证书薄弱处。创新点在于证书第一次进入可微渲染管线，而不是渲染之后的附加检查。

3. **证书驱动主动感知（CDAP）**：定义证书亏空 D(F) = ∫ (γ_min − γ_cov(p))_+ dp，把下一最佳视角选择写成「期望亏空下降 − 运动代价 − 风险」的约束优化；可见性用高斯渲染的射线投射估计。这样 DAKI 的数据采集从「被动挖掘」变成「主动补证」，形成 三维感知 → 证书场 → 主动补证 → 更好三维感知 的闭环。

4. **（安全补丁）跨模态几何一致性证书（CMGCC）**：神经渲染会幻觉。用 LiDAR 点到渲染曲面距离、双目深度差、IMU-光流一致性三项独立度量，给 CA-3DGS 的渲染几何上「外部锚」。没有这张证书，CA-3DGS 的高置信度可能只是自我一致，而不是世界一致。

**关键洞见**：v29 的证书回答「规则是否成立」，CADVS-v1 回答「规则在何时何地成立」，本轮 CADVS-v2 要回答「规则所依赖的三维证据是否真的存在、被看见、且与其他模态一致」。三者的递进是：布尔 → 时空区间 → 三维证据场。这把「证据链」从时间维度扩展到了空间维度与模态维度。

**创新点提炼（相对 CADVS-v1）**：

- **C1 表征创新（证书场化）**：证书从「离散消息/单球域」变为「稀疏体素场 + 时空衰减 + 显式 unknown」。可证伪判据：在遮挡场景中，3D-PCF 能拒绝而 STCK 会误通过。
- **C2 渲染创新（证书可微渲染）**：证书置信度进入 3DGS 的 α 合成并可反传梯度，支持证书感知的致密化/剪枝。可证伪判据：证书渲染图与逐点真值置信度相关性 ≥ 0.8。
- **C3 闭环创新（主动补证）**：以证书亏空而非重建误差为 NBV 奖励。可证伪判据：同等步数下未知体素残留率比经典 NBV 低 ≥ 30%。
- **C4 安全创新（抗洗白）**：CMGCC 提供独立模态锚，并规定「证书不得自证」（生成源不能同时充当验证源）。可证伪判据：注入渲染幻觉后拦截率 ≥ 95%。

**形式化目标（增量）**：

1. 定义三维感知证书场 F: ℝ³ × 𝕋 → 2^{Cert} × [0,1]，F(p,t) = {(c, conf(c,p,t))}；覆盖置信度 γ_cov(p,t) = (1−e^{−λ n(p)})·e^{−(t−τ(p))/τ₀}，未知体素 γ_cov ≡ 0。
2. 定义证书标注高斯 g_i = (μ_i, Σ_i, α_i, c_i, γ_i, h_i, τ_i, src_i)，以及证书渲染算子 R_cert 与 α 合成式 γ(u) = Σ_i T_i α_i γ_i + (1−Σ_i T_i α_i)·0。
3. 定义证书亏空 D(F; V) 与 CDAP 目标 v* = argmax_{v∈V_adm} [E[ΔD(v)] − λ_m cost(v) − λ_r risk(v)]，约束 v 满足运动证书。
4. 定义跨模态一致性证书 CMGCC = (ε_lidar, ε_stereo, χ²_imu)，kc_geom_consistent = CMGCC.valid。
5. 定义 KC 规则 kc_3d_cover、kc_gs_render_valid、kc_active_perc，并证明 CADVS-v2 执行集满足 Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**本轮最大风险**：**证书洗白（certificate laundering）**——CA-3DGS 可能把神经渲染的几何幻觉以高 α 权重、高 γ_i 合成为一张「看起来很可信」的证书渲染图；若跨模态标定存在系统偏差，CMGCC 会被同一偏差骗过，于是控制回路拿到一张形式完备、实为模型臆造的证书。这比 R36 更危险，因为它不是「缺证据」，而是「假证据」。

### IP-481 3D Perception Certificate Field (3DPCF)

```python
@dataclass
class CertificateVoxel:
    center: np.ndarray
    n_obs: int = 0
    t_last: float = -np.inf
    occ: float = 0.5
    sigma2: float = np.inf
    certs: dict = field(default_factory=dict)   # cert_id -> conf ∈ [0,1]

@dataclass
class CertQuery:
    valid: bool
    certs: dict
    coverage: float
    reason: str

class PerceptionCertificateField:
    """3D-PCF：稀疏体素哈希上的三维证据场（显式建模 unknown）"""
    def __init__(self, res=0.05, gamma_min=0.6, lam=0.5, tau0=2.0,
                 sigma2_max=0.01, theta=0.5):
        self.res, self.gamma_min = res, gamma_min
        self.lam, self.tau0 = lam, tau0
        self.sigma2_max, self.theta = sigma2_max, theta
        self.voxels: dict[tuple, CertificateVoxel] = {}

    def _key(self, p):
        return tuple(np.floor(np.asarray(p) / self.res).astype(np.int64))

    def coverage(self, v, t):
        if v is None or v.n_obs == 0:
            return 0.0
        persist = np.exp(-max(0.0, t - v.t_last) / self.tau0)
        return (1.0 - np.exp(-self.lam * v.n_obs)) * persist

    def integrate(self, points, sigma2, cert_ids, t):
        """把一帧深度/点云观测写入场；points: (N,3), sigma2: (N,)"""
        for p, s2 in zip(np.asarray(points), np.asarray(sigma2)):
            k = self._key(p)
            v = self.voxels.get(k)
            if v is None:
                v = CertificateVoxel(center=(np.array(k) + 0.5) * self.res)
                self.voxels[k] = v
            v.n_obs += 1
            v.t_last = t
            v.sigma2 = min(v.sigma2, float(s2))
            v.occ = self._fuse_occ(v.occ, s2)          # 占据概率融合
            for cid in cert_ids:
                incr = np.exp(-s2 / self.sigma2_max) * 0.2
                v.certs[cid] = min(1.0, v.certs.get(cid, 0.0) + incr)

    def query(self, p, t):
        v = self.voxels.get(self._key(p))
        if v is None:
            return CertQuery(False, {}, 0.0, 'unknown')
        cov = self.coverage(v, t)
        if cov < self.gamma_min:
            return CertQuery(False, {}, cov, 'low_coverage')
        if v.sigma2 > self.sigma2_max:
            return CertQuery(False, {}, cov, 'high_variance')
        certs = {c: cf for c, cf in v.certs.items() if cf >= self.theta}
        return CertQuery(len(certs) > 0, certs, cov,
                         'ok' if certs else 'no_cert')

    def deficit(self, points, t):
        """证书亏空 D(F; V) = Σ max(0, γ_min − γ_cov(p))_+"""
        total = 0.0
        for p in points:
            v = self.voxels.get(self._key(p))
            total += max(0.0, self.gamma_min - self.coverage(v, t))
        return total

    def kc_3d_cover(self, p, t):
        q = self.query(p, t)
        return q.valid and q.reason == 'ok'
```

### IP-482 Certificate-Annotated Gaussian Splatting (CA-3DGS)

```python
@dataclass
class CertGaussian:
    mu: np.ndarray            # 中心 μ_i ∈ ℝ³
    scale: np.ndarray         # 各轴尺度
    rot: np.ndarray           # 旋转四元数
    alpha: float              # 不透明度 α_i ∈ [0,1]
    sh: np.ndarray            # 球谐颜色
    gamma: float              # 证书置信度 γ_i ∈ [0,1]
    entropy: float            # 证书不确定性 h_i ∈ [0,1]
    t_obs: float              # 证据时刻 τ_i
    src: str                  # 证据来源 src_i（禁止自证）

class CertificateGaussianSplatting:
    """CA-3DGS：证书标注高斯的可微渲染（颜色与证书共用 α 权重）"""
    def __init__(self, gamma_min=0.6, tau_T=0.2, H_max=0.35):
        self.gamma_min, self.tau_T, self.H_max = gamma_min, tau_T, H_max

    def render_cert(self, gaussians, cam):
        """返回 (γ_img, d_img, H_img, T_img)；T_img 为剩余透射率"""
        H, W = cam.height, cam.width
        g_img = np.zeros((H, W))
        d_img = np.zeros((H, W))
        h_img = np.zeros((H, W))
        T_img = np.ones((H, W))
        order = sorted(gaussians, key=lambda g: self._view_depth(g, cam))
        for g in order:
            pix, w = self._project(g, cam)          # 像素坐标与高斯核权重
            a = np.clip(g.alpha * w, 0.0, 1.0)      # 有效不透明度
            g_img += T_img * a * g.gamma
            d_img += T_img * a * self._view_depth(g, cam)
            h_img += T_img * a * g.entropy
            T_img *= (1.0 - a)
        # 背景证书置信度取 0、熵取 1：未观测即未知
        h_img += T_img * 1.0
        return g_img, d_img, h_img, T_img

    def kc_gs_render_valid(self, g_img, T_img, h_img):
        """证书渲染有效：既要求每个高斯可信，也要求表面被不透明覆盖"""
        return ((g_img >= self.gamma_min) &
                (T_img <= self.tau_T) &
                (h_img <= self.H_max))

    def cert_aware_densify(self, gaussians, d_gamma, k=0.05):
        """证书感知致密化：在 γ 低但证书梯度大的区域分裂高斯"""
        new = []
        for g in gaussians:
            if self._proj_gamma(g) < self.gamma_min and \
               np.linalg.norm(self._cert_grad(g, d_gamma)) > k:
                new.extend(self._split(g, ratio=0.5))
        return gaussians + new
```

### IP-483 Cross-Modal Geometric Consistency Certificate (CMGCC)

```python
@dataclass
class CrossModalGeometricConsistencyCertificate:
    eps_lidar: float = 0.03     # LiDAR 点到渲染曲面距离上界（m）
    eps_stereo: float = 0.05    # 双目深度差上界（m）
    chi2_thresh: float = 11.34  # 卡方阈值（df=4, p≈0.99）
    valid: bool = False
    e_lidar: float = np.inf
    e_stereo: float = np.inf
    chi2_imu: float = np.inf

    def validate(self, rendered_depth, lidar_pts, stereo_depth,
                 imu_delta, cam_pose):
        e_l = self._point_to_surface(lidar_pts, rendered_depth, cam_pose)
        e_s = float(np.mean(np.abs(rendered_depth - stereo_depth)))
        chi2 = self._imu_flow_chi2(imu_delta, rendered_depth, cam_pose)
        self.e_lidar, self.e_stereo, self.chi2_imu = e_l, e_s, chi2
        self.valid = (e_l < self.eps_lidar and
                      e_s < self.eps_stereo and
                      chi2 < self.chi2_thresh)
        return self

    def cert_payload(self):
        return {
            'cert_id': 'kc_geom_consistent',
            'payload': {'valid': self.valid, 'e_lidar': self.e_lidar,
                        'e_stereo': self.e_stereo, 'chi2': self.chi2_imu},
            't_stamp': time.time(),
            'validity_window': 0.05,
            'src_node': 'cmgcc'
        }
```

### IP-484 Certificate-Driven Active Perception (CDAP)

```python
@dataclass
class CertificateDrivenActivePerception:
    gamma_min: float = 0.6
    ig_min: float = 0.05
    lambda_cost: float = 0.1
    lambda_risk: float = 1.0
    max_views: int = 8

    def plan_nbv(self, field, candidates, target_region, motion_cert_fn, sensor):
        """在运动证书允许的视角中，最大化期望证书亏空下降"""
        best, best_score = None, -np.inf
        for v in candidates:
            cert = motion_cert_fn(v)
            if not cert.valid:                 # 安全护盾：不可达/无证书直接剔除
                continue
            gain = self._expected_gain(field, v, target_region, sensor)
            cost = self._travel_cost(v)
            risk = self._risk(v, cert)
            score = gain - self.lambda_cost * cost - self.lambda_risk * risk
            if gain >= self.ig_min and score > best_score:
                best, best_score = v, score
        return best, best_score

    def _expected_gain(self, field, view, region, sensor):
        visible = sensor.visibility(view, region)   # 射线投射/高斯渲染可见性
        return sum(max(0.0, self.gamma_min - field.coverage_at(p, view.t))
                   for p in visible)

    def kc_active_perc(self, view, gain):
        return view is not None and gain >= self.ig_min
```

### IP-485 Perception-Certificate Runtime (PCR)

```python
class PerceptionCertificateRuntime:
    """PCR：把 3D-PCF / CA-3DGS / CMGCC / CDAP 接入 CADVS-v2 控制环"""
    def __init__(self, field, gs, cmgcc, cdap):
        self.field, self.gs, self.cmgcc, self.cdap = field, gs, cmgcc, cdap

    def step(self, state, depth, lidar, t, target_region):
        # 1) 三维证据写入证书场
        pts = self._backproject(depth, state.cam_pose)
        self.field.integrate(pts, self._depth_var(depth),
                             cert_ids=['kc_3d_cover'], t=t)
        # 2) 证书渲染 + 跨模态一致性
        g_img, d_img, h_img, T_img = self.gs.render_cert(self.gs.scene, state.cam)
        cm = self.cmgcc.validate(d_img, lidar, depth,
                                 state.imu_delta, state.cam_pose)
        # 3) 四道新 KC 门控
        kc_cover = all(self.field.kc_3d_cover(p, t) for p in target_region)
        kc_render = bool(np.all(self.gs.kc_gs_render_valid(g_img, T_img, h_img)))
        kc_geom = cm.valid
        # 4) 证书不足时触发主动补证（受运动证书约束）
        if not (kc_cover and kc_render and kc_geom):
            view, gain = self.cdap.plan_nbv(
                self.field, state.candidate_views, target_region,
                motion_cert_fn=state.motion_cert, sensor=state.sensor)
            if self.cdap.kc_active_perc(view, gain):
                return Decision(action='PERCEIVE', view=view)
            return Decision(action='FALLBACK', reason='3d_cert_insufficient')
        return Decision(action='CONTROL',
                        certs=['kc_3d_cover', 'kc_gs_render_valid',
                               'kc_geom_consistent'])
```

**与既有节点图的衔接**：在 RCANG 的 `CertCheckerNode` 前插入 `PerceptionCertNode`（发布 `/cert/3dpcf`）、`GaussCertNode`（发布 `/cert/gsrender`）、`CMGCCNode`（发布 `/cert/geom`）、`CDAPNode`（发布 `/perception/nbv`）。四者与 STCK/GCK/DAKI 同容器零拷贝；证书聚合的 `required_certs` 从 12 增至 15（含本轮三张新证），DAKI 的 `kc_mining_result` 仅在 `kc_3d_cover` 覆盖的体素上允许注入，从源头阻断「无数据规则」。

## 4. 正确性论证（增量更新）

### 引理 35（证书场查询的无未知幻觉性）

**陈述**：对任意查询 (p,t)，若 F.query(p,t).valid = True 且返回证书 c，则体素 v(p) 至少有一次真实观测，且 γ_cov(v,t) ≥ γ_min、σ²(v) ≤ σ²_max、conf(c) ≥ θ。特别地，unknown 体素（n=0）永不返回 valid。

**证明**：`query` 先做哈希查找，缺失即返回 `unknown`；随后三个 guard 分别对应覆盖度、方差与证书置信度。由 γ_cov 定义，n=0 ⇒ γ_cov=0 < γ_min，故未知体素必被拒。证书只在 `integrate` 中由真实观测写入，故每个返回证书至少有一个支撑观测。∎

**工程含义**：这把 R36「无数据支撑却证书通过」从概率性风险降为结构性不可能——只要查询走 3D-PCF，unknown 就无法被认证。

### 引理 36（证书渲染的凸组合界）

**陈述**：令 w_i = T_i α_i，w_bg = 1 − Σ_i w_i，则 γ(u) = Σ_i w_i γ_i + w_bg·0，且 w_i,w_bg ≥ 0、Σ_i w_i + w_bg = 1。因此
min_i γ_i·(1−w_bg) ≤ γ(u) ≤ max_i γ_i。
若所有贡献高斯 γ_i ≥ γ_min 且累积不透明度 1−w_bg ≥ 1−ε，则 γ(u) ≥ γ_min(1−ε)。熵 H(u) 同理。

**证明**：由渲染递推 T_i = Π_{j<i}(1−α_j)、α_j ∈ [0,1]，得 T_i ≥ 0 且单调不增，故 w_i ≥ 0。颜色与证书共用同一组 w_i，故 γ(u) 是 {γ_i} ∪ {0} 的凸组合。代入下界即得。∎

**工程含义**：`kc_gs_render_valid` 同时要求 γ(u) ≥ γ_min 与 T ≤ τ_T（即 1−w_bg ≥ 1−τ_T），等价于「每个高斯都可信」且「表面确实被不透明地覆盖」，防止透射率饱和把低置信高斯掩盖成高置信像素。

### 引理 37（CDAP 的次模性与近似最优）

**陈述**：设可观测体素集合的覆盖函数 g(S) = Σ_{p∈∪_{v∈S}Vis(v)} δ(p) 为单调次模，δ(p) ≥ 0 为体素亏空。则贪心视角选择的期望亏空下降满足 g(S_greedy) ≥ (1−1/e)·g(S*)，且每步 E[D_{t+1}] ≤ D_t。

**证明**：覆盖函数是经典次模函数（新增视角对已覆盖体素的边际收益递减）；δ ≥ 0 保证单调性。贪心对单调次模最大化有 (1−1/e) 近似保证。每步仅接受 gain ≥ ig_min 的视角，期望亏空按定义下降；无可增益视角时保持不变。∎

**工程含义**：无需解 NP-hard 的最优视角集，贪心 + 探索预算即可获得有理论保证的补证效率。

### 引理 38（CMGCC 对渲染几何误差的界）

**陈述**：若 CMGCC.valid，则控制所用的渲染表面点相对度量传感器支撑曲面的几何误差 e_geo ≤ ε_lidar + ε_stereo + O(σ_render)。对 L_u-Lipschitz 的控制律，动作误差 ≤ L_u·e_geo。

**证明（概要）**：由三角不等式，渲染曲面到真实曲面 ≤ 渲染到 LiDAR 曲面 + LiDAR 到双目曲面 + 双目到真实曲面，三项分别由 ε_lidar、ε_stereo 与重建方差界定；控制律 Lipschitz 性直接给出动作误差界。∎

**工程含义**：CMGCC 把「神经渲染自洽」升级为「与独立度量模态一致」，是抗证书洗白的关键外部锚。

### 定理（CADVS-v2 执行集包含与三维证据链可靠性）

**陈述**：在以下假设下：
(A1)–(A5) CADVS-v1 既有假设（时空域、FQC、DLC、GC、γ_data）；
(A6) 三维证书场覆盖：控制相关体素 γ_cov ≥ γ_min 且非 unknown；
(A7) 证书渲染达标：kc_gs_render_valid（引理 36 成立）；
(A8) 跨模态一致：CMGCC.valid（引理 38 成立）；
(A9) 主动感知可行：CDAP 输出满足运动证书的视角，或系统进入回退；
则 Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。并且，任一依赖三维几何的控制步，要么 A6–A8 同时成立，要么系统拒绝/回退，绝不在 unknown 或跨模态矛盾几何上给出认证动作。

**证明**：
- **包含性**：CADVS-v2 的每道新 KC 门控都是合取项。任何 v2 动作必须额外满足 kc_3d_cover ∧ kc_gs_render_valid ∧ kc_geom_consistent（主动感知步还须满足运动证书）；教师/回退路径完全复用 v1，故 Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。
- **可靠性**：若任一三维门控失败，CertChecker 不通过，学生动作被拒绝并进入回退；若全部通过，由引理 35 保证非未知支撑、引理 36 给出渲染置信下界、引理 38 给出几何误差有界，故控制所依赖的几何既非未知也非跨模态矛盾。∎

**诚实声明**：A6–A9 依赖标定精度、传感器时间同步与场景准静态假设。最脆弱处是 (A8)：若 LiDAR/双目/IMU 与渲染共享同一系统性标定偏差，CMGCC 可能被「同向偏差」骗过。CADVS-v2 以「证书不得自证」（src_i 与验证源分离）、在线标定证书、随机审计采样来管理该风险，而非假设其恒真。

## 6. 本轮最大风险（最终确认）

**一句话**：**证书洗白**——CA-3DGS 可能把神经渲染的几何幻觉以高 α 权重、高 γ_i 合成为一张「看起来很可信」的证书渲染图，若跨模态标定存在系统偏差，CMGCC 会被同一偏差骗过，控制回路于是拿到一张形式完备、实为模型臆造的证书；这比 R36 更危险，因为它不是「缺证据」，而是「假证据」，也是 CADVS-v2 从「看见」走向「看懂」的生死线。
