# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 1 轮；本轮灵感：「少样本学习」×「数据规模」）

> R69 教会系统「问」，但它的每一个保证——MCG 的 ECE、信任账本的来源信誉、保形区间、流似然阈值、k 源一致的证据纪律——本质上都是一句**关于数据的话**：在某个数据集上、某种分布下、某个样本量时成立。R69 没有追问：部署时我只有**几条**新样本，这些保证还剩多少？数据从 1e3 涨到 1e6，我的证书会更可信，还是只是**看起来更紧**？
>
> 本轮两个灵感正好击中这个盲点：
> - **少样本学习**说：不要从零估计，把跨任务的元先验带来，用一个小支持集适配。但少样本**准确率**不等于少样本**校准**——m 条样本能买到的保证只有 O(1/√m)，而且必须先付分布距离的税。
> - **数据规模**说：样本量不是证据量。相关、漂移、长尾、投毒都会让有效样本量 n_eff ≪ n；把原始 n 塞进风险界，是 R69 保证静默失效的根源。
>
> 核心命题：**把「数据」提升为一等公民——每个证书都必须绑定数据快照、模型版本、有效样本量、决策相关覆盖与少样本适配预算；用元校准而非元准确率做少样本适配；用有效样本量而非原始规模写风险界；用 Value-of-Data（VoD）与 R69 的 VoI 做分层预算仲裁；异步数据飞轮只在安全点、可回滚、可遗忘地更新。** 命名 **DATUM-RAS**（Data-Aware Trusted Uncertainty Meta-calibration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭多少证据、哪几条证据，才配说我学会了？如果数据错了，我的证书还成立吗**」。

## 0. 直觉与动机

**灵感 1（少样本学习 → 每个保证都是带数据前提的条件句）**
直觉：R69 把「问到的回答」当作证据，却没有计算「要多少条证据才够」。MCG 的 ECE 是在一个标定集上量的；证据纪律的 k 源一致只在来源独立时成立；FMA 的似然阈值依赖训练分布。到了新场景，这些前提可能一条都不满足。少样本学习给出的正确姿势不是「拿新数据重训」，而是带着**跨任务的元先验**落地，再用一个小支持集只修正偏移。但这里有一个容易被忽略的陷阱：**元学习通常优化准确率，而风险自适应需要的是校准**。一个 5-shot 准确率 90% 的分类器可以同时是严重过自信的；用它去驱动 λ_floor 或 VoI，等于用一个错的置信度做安全决策。因此本轮的核心不是「少样本识别」，而是「少样本**保形校准**」：支持集同时充当适配集与校准集，产出的是带覆盖保证的预测集，而不是一个点估计。

**灵感 2（数据规模 → n 不是 n_eff，规模会撒谎）**
直觉：直觉上数据越多越可靠，但风险界里真正出现的是**有效样本量**。至少有三重折扣：其一，时序/空间相关使 1e6 帧连续视频的有效独立样本可能只有几千；其二，部署分布相对元训练分布有漂移，远处样本对当前查询的核权重趋近于零；其三，长尾中真正危险的稀有事件（行人突然横穿、玻璃门、地面湿滑）就算总样本上亿，局部 n_eff 仍可能是个位数。于是「数据规模」不是一个可以拿来炫耀的标量，而是一个**按查询、按类别、按时间衰减**的函数。把 n 直接写进证书，等于把「我有多少条日志」误当成「我对这个决策知道多少」。

**灵感 3（支持覆盖 → 保证只在数据支持内有效）**
直觉：任何统计保证都隐含「查询与校准数据来自同一分布」。若当前状态落在数据支持的边缘之外，保形区间可以形式上有 95% 覆盖，实质上是**外推的幻觉**。因此需要一个显式的支持指示器：决策相关覆盖 cov_dec（当前状态附近、且落在决策边界邻域内的样本比例）与 n_eff 同时过门，证书才有效。注意不能用「全图熵」或「全库样本量」替代 cov_dec：在无关区域堆一亿条数据，对眼前这个岔路口的决策价值仍为零。这直接继承了 R69「只建会改变动作的地图」的决策相关精神，只是把对象从地图换成了数据。

**灵感 4（VoD 对偶 VoI → 数据是投资，不是免费品）**
直觉：R69 的 VoI 是「现在做一个信息动作，能立刻减少多少动作模态的不确定性」；本轮需要一个对偶量：**现在采这一条数据，能让我未来多少决策的证书变窄/变可信**。前者是短期信息，后者是长期能力投资，二者争夺同一个交互预算。若不加仲裁，系统会陷入两种病：只做 VoI，则永远在救火、不积累；只做 VoD，则在危险歧义前还在「为了未来」慢慢采数据。正确做法是分层预算：安全相关的 VoI 有优先权，VoD 只在安全点、且剩余预算超过下限时执行，并受「不得挤占安全预算」的硬约束。

**灵感 5（少样本 = 高杠杆攻击面 → 一条毒样本能翻转整个校准）**
直觉：m 很小的时候，单个支持样本的影响函数极大。攻击者不需要污染一万条数据，只要在你唯一的那几条 few-shot 演示里塞一条「把玻璃门标成可通行」或「把停下的行人标成模特」，就可能把校准温度、模态权重或释放阈值整体推偏。R69 已经建模了「人会撒谎」，但那是**单次回答**层面；本轮的风险升级为**支持集感染**：被污染的不是一个动作，而是之后所有决策所依赖的适配器。所以证据纪律必须下沉到数据层：单源不得贡献超过 1/k 的适配权重，影响函数必须截断，少样本校准必须用抗污染聚合，并且任何「放宽安全集」的证书都不能由单源支持集签发。

**灵感 6（数据是时间对象 → 证书不能比数据活得久）**
直觉：数据会过期：环境变了、任务变了、被删除的数据还在模型里、被确认污染的数据还在证书里。R68/R69 已经给证书加了版本与日志哈希，但数据版本一直是隐式的。本轮把「证书-数据耦合」做成硬约束：每个证书钉住 `D_hash + model_ver + adaptation_ver`；数据一改、模型一更新、漂移告警一响，旧证书立即失效，必须重验证。这不是工程洁癖，而是安全语义：**证书描述的是「那张数据快照上的世界」，世界或数据任一改变，它就不再是同一句话。**

**灵感 7（严格包含 → 数据通道可以关掉，R69 必须原样活着）**
直觉：任何加层都存在「新层反而制造新故障」的风险。因此 DATUM 的理论姿态仍是**严格包含**：当 VoD=0、无适配、数据快照固定且支持条件满足时，DATUM 必须逐指令退化为 R69；当数据不可信（n_eff 小、cov 低、污染高、CDR 失败）时，逐级退到「冻结适配、只用 R69 证书」→「R69 纯保守」→ R68 最保守。数据飞轮永远在安全点异步运行，实时环只读不可变快照。这样，最坏情况下我们只是失去了数据带来的效率红利，而不会失去 R69 已有的安全保证。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DATUM-RAS 总览）** DATUM-RAS = (DPL, DSN, ESS, FCA, DSC, DRD, VoD, DPG, CDR, DFW, DSS, RAS-WM‡)。继承 R69 定义 293 的三不变式（实时零学习写操作、交互预算、证据纪律），并新增五条：
(i) **数据绑定**：任何证书 J 必须钉住 `(D_hash, model_ver, adaptation_ver, n_eff, cov_dec, m_support)`，缺一即无效；
(ii) **支持内有效**：DSC 只在查询的 `cov_dec ≥ τ_cov` 且 `n_eff ≥ n_min` 时有效，越界即退回 R69，禁止外推；
(iii) **适配原子性**：FCA 产物只有同时通过少样本保形门（定义 316）与 DSC 门（定义 317）才可换装，否则保留旧适配器（双缓冲、可回滚）；
(iv) **数据方向性**：新数据默认只允许收紧证书；要放宽（释放 resolution bonus）必须满足 k 源正交、影响函数截断、保形风险界三重条件；
(v) **遗忘即失效**：数据删除、污染确认、分布漂移都触发 CDR，旧证书立即失效，禁止「用旧证书读新世界」。

**定义 311（数据记录与出处账本 DPL）** 数据记录 `d_i = (x_i, y_i, src_i, t_i, hash_i, parent_i, ver_i, w_i, ℓ_i)`，其中 x 可为观测/交互回答/人类演示/仿真轨迹，y 为标签或监督信号，src 为来源（传感器/人/他机/仿真），ℓ_i 为影响记录（该样本对哪些证书、适配器、参数有贡献）。账本只追加，删除以 tombstone 表达；每条记录不可原地改写。`D_t = {d_i : ver_i ≤ t, alive}` 为数据快照，其内容哈希记 `D_hash`。

**定义 312（时间加权数据状态）** 每个来源 s 有漂移半衰期 `τ_s`；样本在 t 时刻的权重
`w_i(t) = w_i^0 · exp(−(t−t_i)/τ_s) · 1[alive] · rep(src_i)`。
数据规模因此不是静态计数，而是**按时间与来源衰减的证据质量**。`rep(·)` 为来源信誉，来自 VQAuditor-D 回灌。

**定义 313（有效样本量 ESS）** 对查询/区域 z，核 `κ_z(x_i) = exp(−‖φ(x_i)−φ(z)‖²/2h²)`，定义
`n_eff(D; z) = [(Σ_i κ_z(x_i) w_i(t))² / Σ_i (κ_z(x_i) w_i(t))²] · ρ_shift(z) · ρ_corr`，
其中 `ρ_shift ∈ [0,1]` 由密度比/判别器或保形非一致性估计（元训练分布 vs 部署分布），`ρ_corr ∈ [0,1]` 由时间/空间相关去冗余（有效簇数 / 样本数）估计。恒有 `n_eff ≤ n`；对长尾类或罕见危险事件，`n_eff` 可远小于全局 n。

**定义 314（决策相关支持覆盖）** 设 B 为当前决策边界（R69 的模态选择边界 / 风险缩放阈值 / 安全集边界）。定义
`cov_dec(z) = min{ ρ_local(z), E_{x~D, κ_z(x)>0}[1[dist(x,B) ≤ δ]] }`，
`support(z) = 1[cov_dec(z) ≥ τ_cov ∧ n_eff(z) ≥ n_min]`。
`ρ_local` 为局部密度比下界。全图熵、全库样本量、平均 mIoU 都不是 cov_dec 的合法替代。

**定义 315（少样本元校准适配器 FCA）** 任务族 `τ ~ p(τ)`，离线元训练得到元先验 φ。支持集 `S_m = {(x_j,y_j)}_{j=1}^m`，适配器
`θ_S = argmin_θ L_cal(θ; S_m) + (λ/2)‖θ−φ‖²`，
其中 `L_cal` 是校准损失（Brier / 可微 ECE 代理 / 保形 pinball），**不是纯准确率损失**。θ 可作用于模态权重温度、信任分阈值、λ_floor 斜率。适配预算 `m ≤ m_max`，只在安全点执行，且 `‖θ_S−φ‖` 受信任域约束，防止少样本把先验整体拽走。

**定义 316（少样本保形证书）** 以 S_m 作校准集，非一致性分 `s(x,y)`。可交换假设下，预测集 `C_α(x)` 满足 `P(y ∈ C_α(x)) ≥ 1−α−1/(m+1)`。协变量漂移下用加权保形，权重 `w(x)=dP_deploy/dP_meta`（有界），覆盖下界 `≥ 1−α−TV(P_meta,P_deploy)`。因此少样本的 resolution bonus 是一个显式的 `(α, m, TV)` 三元组，不得隐式声称「few-shot 所以自适应」。

**定义 317（数据规模缩放证书 DSC）** 对查询 z，风险上界
`ε_DSC(z) = ε_0 + A·n_eff(z)^{−β} + B·(1−cov_dec(z))_+ + C/(m+1) + D·δ̂_poison(z) + E·TV(z)`，
参数由离线保形回归给出置信上界。`ε_0` 是即使无限数据也不可约的 aleatoric/模型误差项——**数据规模不能消除它**。
`Valid_DSC(z) ⇔ support(z) ∧ ε_DSC(z) ≤ ε_budget ∧ (D_hash, model_ver) 匹配`。

**定义 318（数据规模制度 DRD）** 四类制度：
(a) 小数据/过自信（n_eff 小、margin 大）；
(b) 大数据/漂移（n 大但 TV 高、cov_dec 低）；
(c) 长尾/稀有危险（全局 n 大但类条件 n_eff 小）；
(d) 污染/高杠杆（少数样本影响函数异常大）。
DRD 输出制度标签，决定 FCA 是否可用、DSC 哪一项主导、何时必须弃权回 R69。

**定义 319（Value-of-Data 与 VoI/VoD 分层预算）** 候选数据查询 q（请人标注、主动演示、他机共享、仿真回放）：
`VoD(q) = E_{d~q}[ΔRisk_cert(D ∪ {d})] − c_data(q) − c_risk(q)`，
其中 `ΔRisk_cert` 用 DSC 的期望收窄或决策翻转价值度量。`q* = argmax VoD`，s.t. 预算与安全约束。
仲裁规则：若 `U_epi > τ_epi` 且 `VoI > c`，**先 VoI**；仅在安全点且剩余预算 `> b_min` 时执行 VoD；VoD 永远不得挤占安全交互预算。R69 的 VoI 是短期信息，本轮 VoD 是长期能力投资。

**定义 320（数据投毒防护 DPG）** 污染率 δ，单样本影响上界 `I_max`（影响函数/杠杆）。采用截断权重、median-of-means、trimmed conformal，使 breakdown point ≥ 1/2；少样本支持集要求 k 个正交来源一致，且**单源适配权重 ≤ 1/k**。证书膨胀上界由引理 21 给出。任何放宽安全集的证书，禁止由单源支持集签发。

**定义 321（证书-数据重验证 CDR）** 证书 `J` 绑定 `(D_hash, model_ver, adaptation_ver, DSC 参数版本)`。任何 data append/delete、model update、shift alarm 都使 J 失效；重验证 = 重算 `n_eff / cov_dec / DSC` + 保形覆盖 + 影响审计。失效期间控制退回「上一张有效证书」或 R69 纯保守，绝不带病换装。

**定义 322（异步数据飞轮 DFW）** 双缓冲：在线只读 snapshot_A；离线在 snapshot_B 上做 FCA/DSC。换装是原子指针切换，仅当 `Valid_DSC` 且无未决安全事件；失败回滚 A。数据删除用遗忘（精确删除 / 影响重算 / 微调）保证被删样本对参数与证书的贡献可证为零或低于 `ε_unlearn`。飞轮最大滞后 `L_max`，超时冻结换装。

**定义 323（决策支持集选择 DSS）** 选择 `S_m ⊆` 候选池，最大化决策相关价值：
`S* = argmax_{|S|=m} [cov_dec(S) − γ·redundancy(S)]`，近似用决策边界核心集、最大熵或影响函数贪心。与 VoD 的区别：VoD 决定「要采哪些数据」，DSS 决定「已采数据里留哪几条做支持集」。

**定义 324（证书 J_DATUM）** `J_DATUM = (J_FLUID, D_hash, model_ver, adaptation_ver, n_eff_p95, cov_dec_p5, m_support, ε_DSC, DRD_regime, poison_score, vod_log_hash, datum_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ Valid_DSC ∧ CDR 通过 ∧ 证据/预算纪律满足`。

**定义 325（删除与遗忘有效性）** 删除请求作用于 `d_i` 后，要求对任意证书 J：`d_i ∉ support(J)` 且 `∂J/∂d_i = 0`（或 `≤ ε_unlearn`）；否则 J 失效。防止「数据删了，模型和证书还记得」。

**定义 326（三级退避与 R69 边界）** L0 完整 DATUM（FCA 已认证 + DSC 有效）；L1 冻结适配、只用 R69 证书（数据不可信但动作层仍可信）；L2 R69 纯保守（n_eff/cov 越界或 CDR 失败）；L3 回到 R68 最保守（数据与交互都不可信）。当 `VoD=0`、无适配、D 固定且 support 满足时，DATUM 逐指令退化为 R69。

# IP-264/265 DPL + DSN：数据出处账本与不可变快照
class DataProvenanceLedger:
    def add(self, x, y, src, ts, parent=None, influence=None):
        rec = Record(x, y, src, ts, hash=H(x, y, src, ts),
                     parent=parent, ver=self.next_ver(), influence=influence)
        self._append(rec)                       # 只追加，不原地改
        return rec.hash

    def tombstone(self, rec_hash, reason):      # 删除 = 追加墓碑
        self._append(Tombstone(rec_hash, reason, self.next_ver()))

    def snapshot(self, t):                      # 不可变视图，实时环只读这个
        return Snapshot(records=self._alive_at(t), hash=self._merkle(t))

# IP-266 ESS：有效样本量 + 决策相关覆盖
def effective_sample_size(snap, z, kernel, shift_est, corr_est):
    w = [rec.w_t(now) * kernel(z, rec.x) for rec in snap.records]
    kish = sum(w) ** 2 / max(sum(wi * wi for wi in w), 1e-12)
    return kish * shift_est(z) * corr_est(z)    # 恒 <= 原始 n

def decision_support(snap, z, boundary_set, tau_cov, n_min):
    cov = min(local_density_ratio(snap, z),
              boundary_coverage(snap, z, boundary_set))
    ess = effective_sample_size(snap, z, kernel, shift_est, corr_est)
    return cov, ess, (cov >= tau_cov and ess >= n_min)

# IP-267 FCA：元校准，不是元准确率
class FewShotCalibrator:
    def __init__(self, meta_prior, lam=1.0):
        self.meta, self.lam = meta_prior, lam

    def adapt(self, support, budget):           # 仅在安全点调用
        m = min(len(support), budget.m_max)
        S = select_support(support, m)          # DSS 先选，再适配
        theta = fit_calibrated(self.meta, S, self.lam)   # 校准损失 + 信任域
        cover = weighted_conformal(S, alpha=budget.alpha,
                                   weights=density_ratio(S))
        return theta, cover, len(S)

def data_scaling_certificate(ess, cov, m, poison, tv, P):
    eps = (P.eps0 + P.A * ess ** (-P.beta)
           + P.B * max(0.0, 1.0 - cov)
           + P.C / (m + 1)
           + P.D * poison + P.E * tv)
    return eps

def cert_valid(eps, support_ok, budget, snap, model):
    return support_ok and eps <= budget.eps and snap.hash == budget.d_hash \
           and model.ver == budget.model_ver

# IP-270 VoD：数据投资，与 VoI 分层仲裁
def value_of_data(candidates, snap, cert, budget):
    best = None
    for q in candidates:
        if not budget.long_term_allow(q):       continue
        if not at_safe_point():                 continue   # 安全点才投资
        d_risk = expected_cert_shrink(snap, q, cert) - data_cost(q)
        if best is None or d_risk > best.score: best = (q, d_risk)
    return best if best and best.score > 0 else None

# IP-271/272 DPG + CDR：抗污染与重验证
def guarded_adapt(support, k_sources):
    S = trim_by_influence(support, cap=I_MAX)           # 截断高杠杆样本
    if source_weight(S) > 1.0 / k_sources: return None  # 单源不得独大
    return median_of_means_adapt(S)

def revalidate(cert, snap, model):
    if (cert.d_hash != snap.hash or cert.model_ver != model.ver):
        return None                                     # 证书随数据/模型立即失效
    return recompute_dsc(snap, cert.query, cert.params)

# IP-277 主闭环（R69 之上加「数据门」，不改 R69 动作层）
def DATUM_RAS_round(M, obs):
    snap = M.dpl.snapshot(now)                          # 不可变快照
    z, o = M.mtm.forward(obs)
    cov, ess, support_ok = M.ess.decision_support(snap, z, M.boundary)
    regime = M.drd.classify(ess, cov, snap, M.dpl.influence_stats())
    # 1) 只有认证过的适配器才允许进入控制；否则沿用 R69 的旧适配器
    theta = M.fca.certified() if (support_ok and regime.allows_adapt) else M.fca.frozen()
    # 2) R69 原闭环（FMP/AUD/MINT/CIA/FMA/认证）逐指令不变
    k, lam, mode, (U_ale, U_epi) = R69_round(M, o, theta)
    # 3) 数据侧证书：数据不够/不支持/污染高 → 不给 resolution bonus
    eps = M.dsc.compute(ess, cov, m=M.fca.m_support,
                        poison=M.dpg.score, tv=M.drd.tv)
    if not M.dsc.valid(eps, support_ok, snap, M.model):
        lam = max(lam, M.r69.lam_floor(U_ale + U_epi))  # 回 R69 保守
        k   = min(k, M.r69.k_cal_shrink(U_epi))
    # 4) 预算仲裁：安全相关 VoI 优先；VoD 只在安全点、且有余量
    if U_epi > TAU_EPI:
        g = M.mint.choose_interaction(...)               # R69 VoI
        if g is not None: U_epi = M.cia.execute_and_update(g)
    else:
        q = M.vod.select_candidates_and_choose(snap, eps, M.budget)
    # 5) 旁路：数据采集、适配、重验证全部异步，不写实时权重
    M.dfw.submit_async(support=select_support(M.recent, M.dss),
                       query=q, base_hash=snap.hash)
    M.vqa_d.submit_async(regime, eps, M.dpg.score, q)
    return k, lam, mode, (U_ale, U_epi, eps, regime)

## 3. 推导

**引理 19（少样本校准的数据税）** 设元先验 φ 在任务族上的校准误差为 `ε_meta`，任务分布与元分布的一阶 Wasserstein 距离为 `W_1`，校准假设类的复杂度常数为 M。用 m 条支持样本做元校准适配，则以概率 ≥ 1−δ：
`ECE(θ_S) ≤ ε_meta + L·W_1(P_task, P_meta) + M·√(log(1/δ)/(2m))`。
系：要达到校准预算 `ε_cal`，必须 `m ≥ M² log(1/δ) / [2(ε_cal − ε_meta − L·W_1)²]`。**少样本能买到的 resolution bonus 正比于支持集大小，反比于分布距离；「few-shot 所以自适应」是非法推论。**

**引理 20（有效样本量的规模折扣）** 由定义 313，`n_eff ≤ n·ρ_shift·ρ_corr ≤ n`。对稀有危险类 c（基准 prevalence p），局部 `n_eff^c ≈ n·p·ρ_shift·ρ_corr`。若用原始 n 代入 DSC，风险被低估至少
`Δ = A·[(n·p·ρ)^{−β} − n^{−β}]`，
当 p、ρ 很小时 Δ 可超过任何安全裕度。系：**长尾安全必须用类条件 n_eff，而不是全局数据规模；「我们有一亿帧」不是危险场景可认证的理由。**

**引理 21（支持集投毒的证书膨胀上界）** 设支持集污染率 δ，单样本影响上限 `I_max`，trimmed/median 聚合的 breakdown point 为 b。则适配参数偏移 `‖θ_S−θ_clean‖ ≤ I_max·min(δ, 1−b)·m`；证书膨胀
`Δε_poison ≤ L_θ·I_max·min(δ, 1−b)·m + D·δ`。
若采用 k 个正交来源且各源欺骗概率 δ_p、相关 ρ<1，则错误放宽概率 `≤ δ_p·ρ^{k−1}+ε_σ`。系：**少样本的高杠杆使「单源支持集」在安全上不可接受；k 源一致不是锦上添花，而是 m 小时唯一的上界来源。**

**定理 18（DATUM 严格包含 R69）** 在定义 310 的五条不变式、A99（DSC 的保形回归有效）与 A100（支持条件可判定）下：
(i) 当 `VoD=0`、无适配、D 固定且 `support(z)` 成立时，DATUM 的每个输出与 R69 **逐指令相同**；
(ii) 当 `support(z)` 不成立或 CDR 失败时，DATUM 走 L2/L3，认证动作集是 R69 的子集，故期望风险 ≤ R69；
(iii) 当 DSC 有效且适配通过双门时，DATUM 可在同一 `ε_budget` 下释放 resolution bonus（更少保守、更快完成），但证书风险 ≤ 预算。
因此 R69 是「数据通道关闭」边界上的严格退化，安全侧不做任何让步。

**定理 19（数据规模的非单调安全性）** 在平稳分布且支持固定时，`ε_DSC` 关于 `n_eff` 单调不增。但存在两个部署世界 W1、W2 与数据集合 `D1 ⊂ D2`，满足 `|D2| > |D1|`、`ε̂_DSC(D2) < ε̂_DSC(D1)`，而真实风险 `R(D2) > R(D1)`：构造方式为让 D2 的多余样本全部来自漂移后的旧分布（TV 增大但未被重估），同时 `ρ_shift` 估计器因数据变多而更自信。故 **「数据越多越安全」只在 CDR 验证平稳性后成立；否则数据规模只是让错误证书更紧**。这条定理是 R68「标定可吸收故障」在数据侧的同构风险。

**定理 20（异步适配的非干扰与可回滚）** 双缓冲快照 + 原子指针切换 + `Valid_DSC` 门 + 最大滞后 `L_max` 保证：实时控制永远只消费已认证的 `(snapshot_A, model_A, adaptation_A)`；离线飞轮的任何更新、失败、污染都不改变当前环路的动作与证书；换装失败回滚 A，控制序列连续。结合 R69 定理 17（换装不变式），系统的无突变性与安全包络在数据更新下保持。删除传播（定义 325）保证遗忘后旧证书不再可用。

## 6. 本轮最大风险

次级风险与缓解：
1. **元先验与部署任务距离过大**（`W_1` 高，少样本税吃光 bonus）→ 定义 315 信任域 + 引理 19 显式扣税 + DRD 小数据制度直接弃权；
2. **n_eff/cov 估计器本身被污染**（用错误的数据估计数据可信度）→ 双源估计 + 保形审计 + 定理 19 的漂移告警；
3. **支持集感染**（少样本高杠杆）→ 影响截断 + 单源权重 ≤ 1/k + k 源一致 + 放宽证书单源禁签；
4. **飞轮反馈偏差**（自采数据强化自身错误）→ E314 独立测试集监控 + VoD 探索下限 + 定期外部校准；
5. **遗忘不彻底**（删了数据残留影响）→ 定义 325 影响可证零 + E308 审计。

**一句话**：DATUM-RAS 的最大风险是**把「样本量」误当成「证据量」**——一旦 `n_eff`、`cov_dec` 与数据出处本身由被污染或漂移的数据估计，系统就会拿着一个看似严格的证书，为错误的少样本适配背书；数据越多，反而越自信地错。

## 2. 形式化定义（要点版）

**定义 310（总览与五不变式）** DATUM-RAS 继承 R69 的实时零学习写操作、交互预算、证据纪律，新增：数据绑定（证书钉快照/模型/适配版本）、支持内有效（越界不外推）、适配原子性（双门换装）、数据方向性（默认只收紧，放宽需 k 源 + 截断 + 保形界）、遗忘即失效（删数据/漂移 → CDR）。

**定义 311–312（DPL 与时间加权）** 数据记录只追加，删除用墓碑；`w_i(t)=w_i^0·exp(−(t−t_i)/τ_s)·1[alive]·rep(src)`。规模是时间衰减的证据质量，不是静态计数。

**定义 313–314（ESS 与决策覆盖）** `n_eff = Kish(κ_z w) · ρ_shift · ρ_corr ≤ n`；`cov_dec = min(局部密度比, 决策边界 δ-邻域覆盖)`；`support = 1[cov_dec ≥ τ_cov ∧ n_eff ≥ n_min]`。长尾危险必须用类条件 ESS。

**定义 315–316（FCA 与少样本保形）** `θ_S = argmin L_cal(θ;S_m)+(λ/2)‖θ−φ‖²`，`L_cal` 是校准损失不是准确率损失；保形覆盖 `≥1−α−1/(m+1)`，漂移下 `≥1−α−TV`。**少样本 resolution bonus 是一个 `(α,m,TV)` 三元组。**

**定义 317–318（DSC 与 DRD）** `ε_DSC = ε_0 + A n_eff^{−β}+B(1−cov)_+ + C/(m+1)+Dδ̂+E·TV`，`Valid ⇔ support ∧ ε≤ε_budget ∧ 版本匹配`；`ε_0` 是无限数据也不可约的项。DRD 分四制度：小数据过自信 / 大数据漂移 / 长尾稀有 / 污染高杠杆。

**定义 319（VoD 与预算仲裁）** `VoD(q)=E[ΔRisk_cert]−c_data−c_risk`；安全相关 VoI 优先，VoD 只在安全点、剩余预算 > b_min 时执行，永不挤占安全交互预算。

**定义 320–321（DPG 与 CDR）** 影响截断 + median-of-means + trimmed conformal，单源适配权重 ≤ 1/k；证书钉 `(D_hash, model_ver, adaptation_ver)`，数据/模型/漂移任一变化即失效并重验证。

**定义 322–323（DFW 与 DSS）** 双缓冲、安全点换装、原子切换、失败回滚、精确遗忘、最大滞后 L_max；DSS 用决策边界核心集选支持集，与 VoD 分工「采什么 / 留什么」。

**定义 324–326（证书、遗忘、退避）** `J_DATUM` 并入 J_FLUID 与数据字段；删除后要求 `∂J/∂d_i=0` 或 ≤ε_unlearn；三级退避 L0→L1→L2→L3；`VoD=0`、无适配、支持内时逐指令退化为 R69。

## 4. 推导

**引理 19（少样本校准的数据税）** `ECE(θ_S) ≤ ε_meta + L·W_1(P_task,P_meta) + M√(log(1/δ)/(2m))`。系：达到校准预算 `ε_cal` 需 `m ≥ M² log(1/δ)/[2(ε_cal−ε_meta−L·W_1)²]`。**少样本买到的 bonus 正比于 m、反比于分布距离。**

**引理 20（规模折扣）** `n_eff ≤ n·ρ_shift·ρ_corr`；稀有类 `n_eff^c ≈ n·p·ρ`。用原始 n 代入 DSC 至少低估 `A[(n p ρ)^{−β}−n^{−β}]`，可超过任何安全裕度。系：长尾安全必须用类条件 ESS。

**引理 21（支持集投毒上界）** 污染率 δ、影响上限 I_max、breakdown b 下，`Δε_poison ≤ L_θ I_max min(δ,1−b)m + Dδ`；k 源正交时错误放宽 `≤ δ_p ρ^{k−1}+ε_σ`。系：m 小时单源支持集在安全上不可接受。

**定理 18（DATUM 严格包含 R69）** 数据通道关闭（VoD=0、无适配、D 固定、support 成立）时逐指令相同；support 不成立或 CDR 失败时走 L2/L3，认证动作集是 R69 子集，风险 ≤ R69；DSC 有效且双门通过时，可在同一 `ε_budget` 下释放 resolution bonus。R69 = 「数据通道关闭」边界。

**定理 19（数据规模的非单调安全性）** 平稳且支持固定时 `ε_DSC` 关于 `n_eff` 单调不增；但存在 `D1⊂D2`、`|D2|>|D1|`，使 `ε̂_DSC(D2)<ε̂_DSC(D1)` 而真实风险 `R(D2)>R(D1)`（多余样本全来自未重估的漂移旧分布，且 `ρ_shift` 估计器因数据变多更自信）。故「数据越多越安全」只在 CDR 验证平稳性后成立；否则数据规模只是让错误证书更紧。

**定理 20（异步适配非干扰与可回滚）** 双缓冲 + 原子指针切换 + Valid_DSC 门 + 最大滞后保证实时控制只消费已认证快照；离线更新/失败/污染不改变当前动作与证书；换装失败回滚，结合 R69 定理 17 保持控制连续与安全包络。删除传播保证遗忘后旧证书不可用。

## 7. 本轮最大风险

次级风险与缓解：元先验距离过大（信任域 + 引理 19 扣税 + DRD 弃权）；n_eff/cov 估计器被污染（双源估计 + 保形审计）；支持集感染（影响截断 + 单源 ≤1/k + 放宽证书单源禁签）；飞轮反馈偏差（独立测试集 + 探索下限 + 定期外部校准）；遗忘不彻底（影响可证零 + E308 审计）。

**一句话**：DATUM-RAS 的最大风险是**把「样本量」误当成「证据量」**——一旦 `n_eff`、`cov_dec` 与数据出处本身由被污染或漂移的数据估计，系统就会拿着一个看似严格的证书，为错误的少样本适配背书；数据越多，反而越自信地错。
