# 第 8 轮（灵感循环第 1 轮；本轮灵感：「灵巧操作」×「视觉语言模型」）
> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> **本轮纪律**：**接触程序化 + 语义接地 + 证书化信任**。VLM 只提议“候选接触意图”，绝不直接产生控制；灵巧操作被建模为可类型检查、可力闭合认证的**接触模式程序**；任何语义结论必须携带覆盖率证书或弃权。通过**语义-几何-接触三级退化**保证任一环节失效即退回 v7。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 把“抓取几何”升级为“接触模式程序”）**
v7 的 GCT 只检查 width/depth/force 三个标量是否越界：它能挡住“张不开”，却挡不住“抓得住但会滑、会扭、抓不稳”。灵巧操作的本质不是某一帧的抓取几何，而是**接触状态随时间的有意切换**：先捏住把手，再沿轴插入，再用指尖做在手中的重定向。于是把指令从扁平 ι 扩成一段**接触模式程序（CMP）**：每个 phase 声明“用哪些手指、接触物体哪个部位、施加多大期望力旋量、允许多大滑移”。判据也从“几何是否在范围”变成“这段接触程序是否力闭合、是否有摩擦/滑移/工作空间裕度”。直觉一句话：**灵巧不是更多地抓，而是有序地换接触。**

**灵感 2（视觉语言模型 → 把“语音指令”升级为“有覆盖率证书的语义先验”）**
v7 的 VoiceCommandTyping 把语音转成类型化指令，但仍隐含“指令说的是对的、物体是见过的”。VLM 能用图像把“抓住那个把手”落到具体物体部位与可抓取性上，但它有两个致命弱点：**幻觉**与**慢**——它可能把细杆说成把手，也可能 300ms 才回一句话，而控制环是 20ms。因此正确用法不是让 VLM 当裁判，而是**候选接触意图的提议器**：用共形预测把输出变成带 1−α 覆盖保证的候选集，用语义-几何一致性门剔除与点云/深度相矛盾的提议，用“语义租约”解决慢——VLM 结果只在有限时域内有效，过期即退化为几何策略。

**合流（DexVLG）：接触程序 × 语义接地 × 证书**
灵巧操作提供“要证明什么”（力闭合、滑移、工作空间裕度），VLM 提供“从哪儿开始找”（候选接触部位与程序），证书提供“何时可以相信”（覆盖率与裕度）。目标不是让 VLM 多抓对一次，而是让系统在 VLM 幻觉、几何噪声、语义过期时，仍能从 **D0 语义-接触全认证** 平滑退到 **D3 v7 几何单源**，且每一档都有可审计的失效理由。

## 1. 研究问题（轮次升级版）

- **Q1（接触程序编译）**：如何把（语音指令 ℓ，视觉观测 o）编译成可类型检查、可力闭合认证的接触模式程序 CMP，且编译与认证延迟（不含异步 VLM）≤ 5ms？
- **Q2（几何/摩擦不确定下的 soundness）**：当物体几何误差 ≤ ε_geom、摩擦系数不确定时，接触证书如何保证“不把不可力闭合的程序判成已认证”？
- **Q3（语义信任的可审计性）**：如何用共形预测 + 自适应覆盖（ACI）+ 语义租约，给 VLM 提议一个可审计的覆盖率，并在幻觉/漂移/过期时安全弃权而非过度自信？
- **Q4（退化与不级联）**：D0→D3 的语义-几何-接触退化如何保证单模块失效不级联，且 D3 逐项等价于 v7？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 接触模式程序化（Contact-Mode Program, CMP）**
指令被编译为相位序列，每个相位显式绑定接触指集合、物体部位与期望力旋量；相邻相位必须有公共接触指（禁止“空中换手”），且类型检查必须在控制环内可判定：
```
CMP c = (φ_1,…,φ_K),  φ_k = (S_k, ρ_k, w_k^d, τ_k, ε_k^slip)
良构: ∀k, S_k ≠ ∅；∀k<K, S_k ∩ S_{k+1} ≠ ∅；|w_k^d − w_{k+1}^d| ≤ Δw_max
```

**P11 接触能力证书（Contact Certificate, ContactCert）**
把“抓得稳”从经验判断变成可计算的裕度向量。以抓取映射 G 与摩擦锥建立可达力旋量锥 W(c)，用内接球半径作为力闭合裕度；只有全部裕度超过阈值且几何不确定度被裕度覆盖时才认证：
```
κ(c) = (η_fc, η_μ, η_slip, η_ws)
Cert_contact(c) ⇔ η_fc > L_G·ε_geom ∧ η_μ ≥ η_μ* ∧ η_slip ≥ 0 ∧ η_ws ≥ η_ws*
```

**P12 证书化语义信任（Certified Semantic Trust, CST）**
VLM 的信任不是标量置信度，而是带覆盖保证的候选集 + 租约。用非一致性分数把提议纳入/排除，并用 ACI 在分布漂移下维持长期覆盖；租约用场景漂移而非单纯计时判定新鲜度：
```
C_α(x) = { c : s(x,c) ≤ q̂ },   P(c_true ∈ C_α) ≥ 1−α
α_{t+1} = α_t + γ(α − err_t),  valid(c,t) ⇔ age(c) ≤ T_sem ∧ Δ_scene(t) ≤ ε_scene
```

**P13 语义-几何-接触三级退化（DexVLG Ladder）**
```
D0  VLM 提议 + CMP + ContactCert
D1  冻结/缓存 VLM（或 VLM 弃权），仍执行 CMP + ContactCert
D2  单相位静态抓取（几何生成），仅静态力闭合认证
D3  v7 GCT + VoiceCommandTyping（无接触证书），逐项等价 MetricVoiceGauge-OTL-GC-ER
```
降级可立即触发，升级需连续 N_ok 个周期一致；D3 必须保留 v7 的六不变式。

## 3. 与基线 v7 的接口（如何退化）

- **VLG/CST 不可用** ⇒ 进入 D1，使用缓存 CMP 或几何可抓取区域，ContactCert 仍在；
- **ContactCert 不可解/超时** ⇒ 进入 D2，退化为单相位静态抓取，仅保留静态力闭合检查；
- **CMP 类型检查失败** ⇒ ι ← ι₀，并进入 D3；
- **语义租约过期或一致性门冲突** ⇒ 当前 CMP 作废，重新编译或进入 D1；
- **全部新模块关闭** ⇒ D3，逐项等价 v7（OTL/GCT/ER/SoftCert 行为不变）。

## 4. 预期贡献

1. **接触模式程序 CMP**：把灵巧操作从单帧几何检查提升为可类型检查的接触相位序列；
2. **接触能力证书 ContactCert**：给出几何不确定度下的力闭合/摩擦/滑移/工作空间 soundness 条件；
3. **证书化语义信任 CST**：共形覆盖 + ACI + 语义租约，使 VLM 幻觉与慢响应可审计、可弃权；
4. **语义-几何一致性门 SGC** 与**灵巧度量层级**：把语义先验与几何证据的冲突显式化为指标；
5. 完整实验矩阵 **E526–E545**：覆盖接触证书 soundness、共形覆盖、灵巧任务、异步时延、退化等价与端到端。

## 5. 本轮最大风险

**一句话**：若在未见物体上共形覆盖与几何不确定度同时失准，系统可能把不可力闭合的接触程序判为“已认证”（soundness 被击穿），或因过度弃权长期停在 D3——二者都会让“证书”从安全资产变成效率负债。

## 2. 形式化定义

**定义 530（接触模式程序 Contact-Mode Program, CMP）** 一段可类型检查的接触相位序列：
```
c = (φ_1,…,φ_K),  φ_k = (S_k, ρ_k, w_k^d, τ_k, ε_k^slip)

Γ ⊢ c : ok  ⇔  ∀k:
    S_k ⊆ {1,…,n_f},  S_k ≠ ∅,  ρ_k ∈ Parts(o),
    ‖w_k^d‖ ≤ w_max,  τ_k > 0,  ε_k^slip ∈ [0, ε_max],
    ∀ k < K:  S_k ∩ S_{k+1} ≠ ∅  ∧  ‖w_k^d − w_{k+1}^d‖ ≤ Δw_max
```
其中 `S_k ∩ S_{k+1} ≠ ∅` 禁止“空中换手”，`Δw_max` 限制相位间的力旋量跳变。类型检查可在 O(K·n_f) 内完成，满足控制环预算。CMP 只声明**意图与接触结构**，不包含关节力矩/速度。

**定义 531（接触能力证书 ContactCert）** 对给定几何与摩擦估计，构造可达力旋量锥与其裕度：
```
G_i = [ I_3 ; [p_i]_× ] ∈ R^{6×3}
W(c) ≈ cone{ G_i(p_i) e_{i,j} : i ∈ S, j = 1,…,m_e }   (e_{i,j} 为摩擦锥离散边)

η_fc(c)   = max{ r ≥ 0 : B_r(0) ⊆ W(c) }          # 力闭合裕度
η_μ(c)    = min_i ( μ_i − ‖f_i^t‖ / f_i^n )
η_slip(c) = min_i ( f_i^n − f_i^slip )
η_ws(c)   = min_i dist(q_i, ∂Q_i)

Cert_contact(c) = Certified  ⇔
    η_fc(c) > L_G · ε_geom  ∧  η_μ(c) ≥ η_μ*  ∧  η_slip(c) ≥ 0  ∧  η_ws(c) ≥ η_ws*
```
`η_fc` 用线性规划在单位 wrench 球采样方向 `{u_l}` 上求解：`max r s.t. r·u_l = Σ_{i,j} λ_{i,j} G_i e_{i,j}, λ ≥ 0, Σλ = 1`，取各方向最小者。`η_fc > L_G ε_geom` 是把几何不确定度显式吃进证书的 soundness 条件（见引理 77）。

**定义 532（视觉语言接地 Vision-Language Grounding, VLG）** VLM 输出有限个候选接触意图，而不是控制量：
```
VLG(ℓ, o) = { (c^{(r)}, M^{(r)}, π^{(r)}) }_{r=1,…,R}
```
`c^{(r)}` 为候选 CMP，`M^{(r)}` 为物体部位 ρ 的 2D/3D 掩码，`π^{(r)}` 为提议分数。硬约束：`VLG` 不输出关节力矩/速度，任何候选在执行前必须经过 ContactCert。

**定义 533（共形语义信任 Certified Semantic Trust, CST）** 用非一致性分数把 VLM 提议变成带覆盖保证的候选集，并用 ACI 与租约处理漂移和过期：
```
s(x, c) = 1 − π_VLM(c | ℓ, o) + λ_sg · (1 − κ_sg(c, o))
q̂      = Quantile_{⌈(n+1)(1−α)⌉/n}( { s(x_i, c_i) }_{i=1..n} )
C_α(x) = { c : s(x, c) ≤ q̂ }

ACI :  α_{t+1} = clip( α_t + γ(α − err_t), α_min, α_max ),
       err_t   = 1[ c_true ∉ C_{α_t}(x_t) ]

lease: valid(c, t) ⇔ (t − t_c) ≤ T_sem ∧ Δ_scene(t) ≤ ε_scene
```
`C_α(x) = ∅` 是**合法的弃权输出**，此时系统必须降级，不得“挑选一个看起来最像的候选”继续执行。

**定义 534（语义-几何一致性门 Semantic-Geometric Gate, SGC）** 把 VLM 部位证据与几何可抓取区域对照：
```
κ_sg(c, o) = ω_i · IoU(M_VLM, A_geo)
           + ω_n · ( 1 − (1/|M|) Σ_{p∈M} arccos(n_p · n̂_p) / π ),   ω_i + ω_n = 1

accept(c) ⇔ κ_sg(c, o) ≥ τ_sg
```
`A_geo` 由深度/点云的法向、曲率与可达性得到；`n_p` 为几何表面法向，`n̂_p` 为 VLM 暗示的接近方向。冲突即弃权，不把语义先验强行投影到几何上。

**定义 535（灵巧度量层级 DexMetricHierarchy）** 把接触量接入 v7 的四层价值金字塔：
```
κ(s)   = ( η_fc, η_μ, η_slip, η_ws, μ_man, κ_sg )
Dex(s) = min{ η_fc/η_fc*, η_μ/η_μ*, η_ws/η_ws*, μ_man/μ_man* }

M₀（硬）: η_fc > L_G ε_geom ∧ η_slip ≥ 0 ∧ collision-free
M₁（安全）: Dex ≥ D_safe ∧ κ_sg ≥ τ_sg
M₂（效能）: 灵巧进度 = f(重定向角, 插入深度, 成功接触切换数)
M₃（完善）: 接触切换平滑度、finger-gait 代价
```
`κ(s)` 是 v7 `γ_grasp` 的严格细化：v7 的三标量检查被 `η_fc/η_slip/η_ws` 取代，而不是叠加。

**定义 536（语义-几何-接触退化阶梯 Degradation Ladder）**
```
D0 = (VLG = on,            CMP = dynamic, Cert = dynamic)
D1 = (VLG = frozen/abstain, CMP = dynamic, Cert = dynamic)
D2 = (CMP = static single-phase,           Cert = static)
D3 = (VLG = off, CMP = ∅, Cert = off)      ≡ MetricVoiceGauge-OTL-GC-ER v7
```
转移条件：
```
D0 → D1: ¬valid(c,t) ∨ C_α(x)=∅ ∨ κ_sg < τ_sg
D1 → D2: Cert_contact 不可解/超时 ∨ 动态相位不可认证
D2 → D3: 类型检查失败 ∨ 静态证书失败 ∨ 任一模块关闭
升级: 连续 N_ok 个周期满足上一级全部条件，且 D3→D2→D1 逐级恢复
```

**定义 537（DexVLG 闭环标识）**
```
Φ_DexVLG = ( c, Cert_contact(c), C_α, κ_sg, D_t )
```
其中 `D_t` 为当前退化层级，作为证书的一部分随控制输出发布，使“此刻为何可用/为何降级”可被外部审计。

**定义 538（证书-度量一致性）** 关闭 v7 遗留的“软通过、硬失败”空洞，把接触与语义证据纳入退化触发：
```
δ_trigger = { σ < τ_safe } ∪ { ¬Cert_contact(c) } ∪ { κ_sg < τ_sg }
```
任一条件成立即触发软→硬退化；由于 ContactCert 与 M₀ 使用同一力闭合判据，退化后硬约束必然满足。

```python
import numpy as np
from dataclasses import dataclass

# ---------- IP-351 ContactModeProgram ----------
@dataclass
class Phase:
    fingers: tuple          # S_k
    part: str               # ρ_k
    wrench: np.ndarray      # w_k^d in R^6
    duration: float         # τ_k
    slip_eps: float         # ε_k^slip

class ContactModeProgram:
    def __init__(self, phases):
        self.phases = list(phases)

    def typecheck(self, n_fingers, parts, w_max, delta_w, slip_max):
        for k, ph in enumerate(self.phases):
            if not ph.fingers or min(ph.fingers) < 0 or max(ph.fingers) >= n_fingers:
                return False, f"phase {k}: 接触指集合非法"
            if ph.part not in parts:
                return False, f"phase {k}: 未知部位 {ph.part}"
            if np.linalg.norm(ph.wrench) > w_max:
                return False, f"phase {k}: 力旋量超限"
            if ph.duration <= 0 or not (0.0 <= ph.slip_eps <= slip_max):
                return False, f"phase {k}: 时长/滑移非法"
            if k + 1 < len(self.phases):
                nxt = self.phases[k + 1]
                if not (set(ph.fingers) & set(nxt.fingers)):
                    return False, f"phase {k}->{k+1}: 不允许空中换手"
                if np.linalg.norm(nxt.wrench - ph.wrench) > delta_w:
                    return False, f"phase {k}->{k+1}: 力旋量跳变过大"
        return True, "ok"


# ---------- IP-352 ContactCertifier ----------
class ContactCertifier:
    def __init__(self, mu, eta_mu_min, eta_ws_min, L_G, eps_geom,
                 n_edges=8, n_dirs=42):
        self.mu, self.eta_mu_min, self.eta_ws_min = mu, eta_mu_min, eta_ws_min
        self.L_G, self.eps_geom = L_G, eps_geom
        self.n_edges, self.n_dirs = n_edges, n_dirs
        self._dirs = self._icosphere_dirs(n_dirs)

    @staticmethod
    def _skew(p):
        return np.array([[0, -p[2], p[1]],
                         [p[2], 0, -p[0]],
                         [-p[1], p[0], 0]])

    def _grasp_map(self, p):
        return np.vstack([np.eye(3), self._skew(p)])     # 6 x 3

    def _friction_edges(self, n, mu):
        # 以接触法向 n 为轴构造摩擦锥的离散边（切向圆 + 法向分量）。
        t1 = np.cross(n, [0.0, 0.0, 1.0])
        if np.linalg.norm(t1) < 1e-6:
            t1 = np.cross(n, [1.0, 0.0, 0.0])
        t1 /= np.linalg.norm(t1)
        t2 = np.cross(n, t1)
        edges = []
        for j in range(self.n_edges):
            a = 2.0 * np.pi * j / self.n_edges
            edges.append(mu * (np.cos(a) * t1 + np.sin(a) * t2) + n)
        return edges

    def force_closure_margin(self, contacts):
        gens = []
        for (p, n) in contacts:
            G = self._grasp_map(p)
            for e in self._friction_edges(n, self.mu):
                gens.append(G @ e)
        A = np.array(gens).T                              # 6 x M
        r_min = np.inf
        for u in self._dirs:
            r = self._lp_inscribed_radius(A, u)
            r_min = min(r_min, r)
        return r_min

    @staticmethod
    def _lp_inscribed_radius(A, u):
        # max r s.t. A λ = r u, λ >= 0, sum λ = 1  (小规模 LP；生产用热启动)
        # 这里给出闭式代理：最小二乘可行解沿 u 的最大缩比。
        lam, *_ = np.linalg.lstsq(A, u, rcond=None)
        lam = np.clip(lam, 0.0, None)
        denom = u @ (A @ lam)
        return float(np.linalg.norm(A @ lam) / max(denom, 1e-9))

    def certify(self, cmp, geometry, friction):
        reports = []
        for k, ph in enumerate(cmp.phases):
            contacts = [(geometry.point(i, ph.part), geometry.normal(i, ph.part))
                        for i in ph.fingers]
            eta_fc = self.force_closure_margin(contacts)
            eta_mu = min(friction[i] - geometry.tan_angle(i, ph.part)
                         for i in ph.fingers)
            eta_slip = min(geometry.normal_force(i, ph.part)
                           - geometry.slip_force(i, ph.part)
                           for i in ph.fingers)
            eta_ws = min(geometry.workspace_margin(i) for i in ph.fingers)
            certified = (eta_fc > self.L_G * self.eps_geom and
                         eta_mu >= self.eta_mu_min and
                         eta_slip >= 0.0 and
                         eta_ws >= self.eta_ws_min)
            reports.append((k, certified, (eta_fc, eta_mu, eta_slip, eta_ws)))
        return all(c for _, c, _ in reports), reports

    def certify_static(self, phase, geometry, friction):
        return self.certify(ContactModeProgram([phase]), geometry, friction)


# ---------- IP-354 ConformalSemanticTrust ----------
class ConformalSemanticTrust:
    def __init__(self, alpha=0.10, gamma=0.01, lam_sg=0.5,
                 T_sem=1.5, eps_scene=0.02, alpha_min=0.02, alpha_max=0.30):
        self.alpha, self.alpha_t = alpha, alpha
        self.gamma, self.lam_sg = gamma, lam_sg
        self.T_sem, self.eps_scene = T_sem, eps_scene
        self.alpha_min, self.alpha_max = alpha_min, alpha_max
        self.scores = []

    def calibrate(self, calib):
        self.scores = sorted(
            1.0 - pi + self.lam_sg * (1.0 - kappa)
            for (_, _, pi, kappa) in calib
        )

    def qhat(self):
        n = len(self.scores)
        if n == 0:
            return np.inf
        k = int(np.ceil((n + 1) * (1.0 - self.alpha_t)))
        k = min(max(k, 1), n)
        return self.scores[k - 1]

    def filter(self, proposals):
        q = self.qhat()
        return [p for p in proposals
                if (1.0 - p.pi + self.lam_sg * (1.0 - p.kappa)) <= q]

    def update(self, covered):
        err = 0.0 if covered else 1.0
        self.alpha_t = float(np.clip(
            self.alpha_t + self.gamma * (self.alpha - err),
            self.alpha_min, self.alpha_max))

    def valid(self, t, t_c, delta_scene):
        return (t - t_c) <= self.T_sem and delta_scene <= self.eps_scene


# ---------- IP-355 SemanticGeometricGate ----------
class SemanticGeometricGate:
    def __init__(self, tau_sg=0.55, w_i=0.6, w_n=0.4):
        self.tau_sg, self.w_i, self.w_n = tau_sg, w_i, w_n

    def evaluate(self, mask_vlm, mask_geo, normals_vlm, normals_geo):
        inter = np.logical_and(mask_vlm, mask_geo).sum()
        union = np.logical_or(mask_vlm, mask_geo).sum()
        iou = float(inter) / max(union, 1)
        if len(normals_vlm) == 0:
            ang = np.pi / 2
        else:
            cos = np.clip(np.sum(normals_vlm * normals_geo, axis=1), -1.0, 1.0)
            ang = float(np.mean(np.arccos(cos)))
        kappa = self.w_i * iou + self.w_n * (1.0 - ang / np.pi)
        return kappa, (kappa >= self.tau_sg)


# ---------- IP-357 主闭环（50Hz 内不调用 VLM） ----------
def dexyulg_step(state, voice, vlm_worker, M, compiler, certifier,
                 cst, sgc, cached=None):
    # 1) 异步语义：只读已完成结果，绝不阻塞控制环
    proposals, t_vlm = vlm_worker.latest_nonblocking()
    delta_scene = state.scene_drift()
    if proposals is None or not cst.valid(state.t, t_vlm, delta_scene):
        proposals = None
        level = "D1" if cached is not None else "D3"
    else:
        proposals = cst.filter(proposals)
        level = "D0" if proposals else ("D1" if cached is not None else "D3")

    # 2) 编译 + 类型检查
    cmp_c = None
    if level in ("D0", "D1") and proposals:
        cmp_c = compiler.compile(voice.iota, proposals[0].program)
        ok, why = cmp_c.typecheck(state.n_fingers, state.parts,
                                  state.w_max, state.delta_w, state.slip_max)
        if not ok:
            cmp_c, level = None, "D3"

    # 3) 接触证书：动态相位失败则退静态
    cert_ok, margins = False, None
    if cmp_c is not None:
        cert_ok, margins = certifier.certify(cmp_c, state.geometry, state.friction)
        if not cert_ok:
            level = "D2"
            cmp_c = compiler.static_from_geometry(state.geometry)
            cert_ok, margins = certifier.certify_static(cmp_c, state.geometry,
                                                        state.friction)
    if level == "D2" or (cmp_c is not None and not cert_ok):
        level = "D3"

    # 4) 语义-几何一致性门（掩码在降采样上计算，不阻塞控制）
    if cmp_c is not None and proposals:
        kappa_sg, agree = sgc.evaluate(state.mask_vlm, state.mask_geo,
                                       state.normals_vlm, state.normals_geo)
        if not agree:
            cmp_c, level = cached, ("D1" if cached is not None else "D3")
        else:
            state.kappa_sg = kappa_sg

    # 5) 指标与退化触发（定义 538）
    M.update_contact_metrics(margins, state.kappa_sg)
    if (not cert_ok) or M.below_safe() or state.kappa_sg < state.tau_sg:
        level = "D3"

    # 6) 执行：相位接触阻抗跟踪；D3 用 v7 原策略
    if level == "D3" or cmp_c is None:
        return v7_policy(state), "D3"
    tau = contact_impedance_control(cmp_c, state)
    return tau, level
```

## 4. 推导

**引理 77（几何不确定下的接触证书 soundness）** 设真实接触点 `p_i` 与估计 `p̂_i` 满足 `‖p_i − p̂_i‖ ≤ ε_geom`，且抓取映射满足 `‖G_i(p_i) − G_i(p̂_i)‖ ≤ L_G ε_geom`。若在估计几何下 `η_fc(c, p̂) > L_G ε_geom`，则真实几何下 `η_fc(c, p) ≥ η_fc(c, p̂) − L_G ε_geom > 0`，即真实系统仍然力闭合。

*证明*：对任一单位力旋量方向 `u`，估计锥中存在 `λ ≥ 0, Σλ = 1` 使 `Σ λ_{i,j} G_i(p̂) e_{i,j} = r u`，其中 `r = η_fc(c,p̂)`。把 `G(p̂)` 换成 `G(p)` 后，残差满足 `‖Σλ (G(p) − G(p̂)) e‖ ≤ L_G ε_geom Σλ = L_G ε_geom`。故真实可达锥包含以 `r − L_G ε_geom` 为半径的球。对所有方向取下确界即得。∎

因此证书判据必须使用 `η_fc > L_G ε_geom` 而不是 `η_fc > 0`；这也是定义 531 与定义 535 中 M₀ 使用同一阈值的理由。

**引理 78（CST 的覆盖与弃权可审计性）** 在校准集与测试点可交换时，split conformal 给出 `P(c_true ∈ C_α) ≥ 1 − α`；在分布漂移下有界时，ACI 更新 `α_{t+1} = α_t + γ(α − err_t)` 使长期误覆盖率 `(1/T)Σ err_t → α`。当 `C_α = ∅` 时系统强制弃权并降级，因此不存在“未认证却执行”的路径。

*证明要点*：可交换性下分位数取 `⌈(n+1)(1−α)⌉/n` 保证边际覆盖（Vovk 等）；ACI 的长期覆盖结论来自 Gibbs–Candès 的在线学习视角，`α_t` 被裁剪到 `[α_min, α_max]` 保证有界。弃权规则由定义 533 直接给出。∎

**引理 79（语义租约的安全性）** 设场景漂移速率上界为 `v_scene`，租约年龄 `age ≤ T_sem`，则物体部位相对位移上界为 `v_scene · T_sem`。若 `v_scene · T_sem > ε_align`（抓取对准容差），则租约到期前必须重新接地或强制降级；否则可能出现“语义仍有效、几何已错位”的静默失败。

*证明*：由 Lipschitz/速度界直接积分；把 `ε_align` 作为可达集不变式，超出即触发 D1/D2。这把 VLM 的“慢”从隐性工程问题变成可计算的约束。∎

**引理 80（退化等价与无级联）** 任一新增模块（VLG/CST/SGC/CMP/Cert）失效时，系统沿 D0→D1→D2→D3 单调退化，最终在 D3 执行 v7 的 `GCT + VoiceCommandTyping`，且 `τᵢ`、`γ_grasp`、`w'_i` 与 v7 完全一致；各模块的失效判定只通过定义 536 的显式层级触发，互不隐式耦合，故不产生级联。

*证明*：逐项对照 v7 的六不变式与退化链；D3 分支不读取任何 VLG/CST/SGC 状态，`Cert` 关闭，`CMP = ∅`，因此行为与 v7 同构。层级触发条件为有限状态机的显式边，不存在共享可变状态导致的交叉失效。∎

**引理 81（Dex 度量的单调约束）** 对任意状态，`Dex(s) ≤ 1` 且 `Dex(s) ≥ D_safe` 蕴含所有单个裕度 `η ≥ D_safe · η*`；由于 M₀ 要求 `η_fc > L_G ε_geom`，当 `D_safe · η_fc* > L_G ε_geom` 时 M₁ 的 Dex 约束严格强于 M₀ 的力闭合约束，保证层级不出现“安全层通过而硬约束失败”。
