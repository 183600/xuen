# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；本轮灵感：「手势识别」×「SLAM」）

> R69 让闭环学会「问」：把不确定性拆成 aleatoric 与 epistemic，用流匹配策略显式呈现动作模态，再用注视/探针/问句去消解 epistemic。但它对一个前提保持沉默：**被问出来的答案是「一枚标签」，而且这枚标签与空间无关**。真实的人机交互里，最自然、最高带宽的答案往往是一根手指——「放**那儿**」「拿**这个**」「从**这里**走」。手势不是一个可以塞进 confusion matrix 的类别；它是一个**索引符号（indexical sign）**：意义由「谁在什么位姿下、指向哪张地图的哪个位置」共同决定。
>
> 本轮两个灵感正好把这个缺口撕开：
> - **手势识别**告诉我们，手势有语用类型（指示/图示/象征/演示），其含义依赖视角、骨架、时序与人的基座标架；
> - **SLAM**告诉我们，「那儿」不是一句话，而是地图上的一个概率分布——位姿漂移、回环错误、动态遮挡都会静默地改写指代。
>
> 核心命题：**把手势从「意图标签」升级为「意图 × 空间指代的联合假设」；把 SLAM 地图从背景升级为指代的索引锚；把不确定性三分（aleatoric / semantic / indexical）；用共享信息动作（问 / 移动 / 重新定位 / 主动验证）在同一预算下消解；并且，任何手势对地图的写入都必须先经过空间溯源与暂定地标账本，未验证不得升格。** 命名 **DEIXIS-RAS**（Deictic Epistemic eXchange with Indexical Spatial-grounding）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**你说的『那里』，和我说的『那里』，是同一个地方吗？**」——不确定性不仅是刹车、提问，也可以是一次回头、一次靠近、一次「你带我去看看」。

## 0. 直觉与动机

**灵感 1（手势识别 → 手势是指示，不是标签）**
直觉：R69 的证据模型把人类回答写成 `p(y | g, o)`，隐含「答案是一个与几何无关的类别」。但指向手势的似然是 `p(g | r, x, h)`：同一根手指，在机器人不同位姿 `x`、人的不同基座标架 `h`、地图不同漂移下，指向完全不同的 `r`。更麻烦的是语用：竖起大拇指可能是「同意」，也可能是「向那边走」；在空中画圈可能是「转一圈」，也可能是「这里乱了」。**手势识别若只输出类别，就把索引性丢掉了；而索引性恰恰是它最有用的部分。**
一句话：手势识别要交付的不是 label，而是 `(语用类型, 指代射线, 时间窗, 置信度)` 的四元组。

**灵感 2（SLAM → 地图是指代的索引锚，也是误差源）**
直觉：在 SLAM 里，「那儿」有一个精确定义：地图坐标系下的一个 landmark 或区域，带协方差。R68 的 λ_floor 处理的是「测量还准吗」，R69 处理的是「该问谁」，但都没有处理「**我说的那个地方，在你的地图里对应哪里**」。SLAM 的位姿漂移会把「那儿」整体平移；回环错误会把「那儿」瞬移到另一个房间；动态遮挡会让人和所指对象不在同一时刻的同一帧里。**指代误差不是语义误差，它会以米为单位直接变成行动误差。**
一句话：SLAM 既是消歧的资源（更多视角、度量约束），也是新的故障源（漂移、回环、坐标系错位）。

**灵感 3（语义-空间循环 → 手势与地图互为观测，也互为污染）**
直觉：手势既可以用来消歧意图，也可以作为一条**方位测量**去约束地图（「他指的是那面墙上的开关」→ 开关的方位约束）。这就形成了一个闭环：用手势改地图，用地图解释手势。闭环本身是好事（人是最便宜的回环检测器），但它有一个致命性质：**错误可以自洽**。如果人指错了，或手势被伪造，这条错误约束会污染地图；而污染后的地图会更坚定地把下一个手势解释成同一个错误对象。R69 的「k 个正交证据源」是静态的；这里需要的是**空间溯源**：手势约束在升格为地图事实之前，必须能被另一个视角独立复核。
一句话：手势是地图的**假设**，不是地图的**事实**；先入账本，后入地图。

**灵感 4（三分不确定性 → R69 漏掉了 indexical）**
直觉：R69 把 U 拆成 aleatoric（噪声）与 epistemic（歧义）。但手势场景里 epistemic 还要再拆：
- **U_sem（语用/意图歧义）**：手势形式本身有多个合理解释（画圈=转圈？整理？）——问一句可以解决；
- **U_idx（索引/指代歧义）**：手势形式清楚，但「它指哪个对象」因位姿/地图不确定而模糊——再问一句「你指哪个？」如果对方还是用手指，信息量为零；必须**换视角、靠近、重新定位**才能解决。
把二者混在一起，就会得出「所有歧义都能靠问解决」的错误结论。实际上，**问主要降低 U_sem，动主要降低 U_idx**——这是本轮最重要的诊断性区分。
一句话：不确定性的第三种形状，是「空间索引的不确定」。

**灵感 5（共享信息动作 → 一次移动可以同时服务三个主人）**
直觉：R69 的信息动作是注视/探针/问句，默认机器人位姿不变。但手势的可观测性、SLAM 的定位精度、指代的分辨率，三者都随**同一个移动**改变：靠近一点，手势看得更清（降低 U_ale）、位姿更准（降低 U_idx），但可能进入危险区或丢失地图特征（增加风险/漂移）。于是信息动作不能再按单通道定价，而要解一个**联合 VoI**：同一次移动对语义、索引、几何三条通道的边际增益，减去安全与预算成本。R69 的 MINT 是本轮在「位姿固定、指代射线已知」边界上的退化。
一句话：主动 SLAM 与主动消歧共享同一个动作空间，必须共享同一个预算与安全证书。

**灵感 6（指代集安全 → 不要猜一个 referent，要对所有候选都安全）**
直觉：R69 的 epistemic 处理是「消解不了就收紧 λ」。在指代场景里，收紧 λ 还不够：如果「那儿」可能是人，也可能是玻璃杯，慢一点并不能让「走过去拿」变安全。正确的做法是**指代集（referent set）**：保留后验质量 ≥ 1−α 的所有候选，要求执行的动作对集合里每个候选都安全；若不存在这样的动作，就执行一个**验证动作**（靠近/换角度/指给对方确认），而不是赌 MAP。这样，「猜错」被替换成「对所有候选都安全，且动作本身能自消歧」。
一句话：指代不明时，最优动作往往不是「选一个」，而是「做一个让选择变得不必要/更清楚的动作」。

**灵感 7（验证而非信任 → 人指的地方，机器人可以去看）**
直觉：R69 的交互是「问」，答案只能被相信或被概率加权。指代有一个独特优势：**它是可物理检验的**。人说「开关在那儿」，机器人可以走过去看——如果那里真有开关，假设被证实；如果没有，假设被证伪。这给了我们一个比「k 源一致」更强的纪律：**未验证的手势只进暂定账本（DGH），不进持久地图；只有被独立观测复核后才升格**。这让人类的高带宽先验可用，又不会被单次欺骗永久污染。
一句话：对手势，最好的证据纪律不是「多问几个人」，而是「亲自去看一眼」。

**灵感 8（威胁模型 → 指代投毒是一条新的攻击面）**
直觉：一旦手势能改地图，攻击者就有了新目标：不需要黑进传感器，只要在正确的时间指错一个地方，就能让机器人把假地标写进地图，或把真地标「回环」到错误位置。更隐蔽的是**共模欺骗**：表情、注视、手指、语音一起演，R69 的 k 源一致性会被同时攻破。因此本轮必须交付：手势认证（活体/重放/授权）、指代溯源、暂定账本、空间一致性检验，以及「单次手势不得直接改图」的铁律。否则 DEIXIS 会把 R69 的「会问的嘴」升级成「会指错路的手」。
一句话：指代是最强的交互通道，也是最直接的攻击通道。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DEIXIS-RAS 总览）** DEIXIS-RAS = (IGF, TRI, SIR, NBG, RSC, SPG, DGH, GPA, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **指代可追溯**：每个任务动作必须携带其指代证据集 `R_α`、位姿假设来源与手势时间窗；手势不得直接写入持久地图；
(iii) **先安全后消歧**：若 `R_α` 不是 action-sufficient（定义 318），只能执行 `SafeAll(R_α)` 中的动作或验证动作；不得对单个 MAP referent 行动。

**定义 311（手势观测的语用-几何因子化）** 手势观测 `g = (κ, τ, s)`：`κ` 为骨架/手部关键点轨迹，`τ ∈ {deictic, iconic, emblem, demonstrative}` 为语用类型，`s` 为时间窗。设机器人位姿 `x ∈ SE(3)`、人的基座标架 `h ∈ SE(3)`、地图 `M`、意图 `z`、指代 `r ∈ M ∪ {∅}`。则
`p(g | z, r, x, h, M) = p(τ | z) · p(κ | z, τ) · p(g_ray | r, x, h) · p(s | r, x, M)`.
其中指示性手势的指代射线 `ℓ(g; x, h) = x · h · ray(κ)`，且
`p(g_ray | r, x, h) ∝ exp(−d(ℓ, r)^2 / (2σ_g^2)) · vis(r; x, h, M)`，
`d(·)` 为射线到 landmark 的角残差，`vis` 为可见性/遮挡因子。演示性手势则用轨迹似然 `p(κ | z)`，不含 `r`。**关键：语义项与索引项在同一个似然里因子化，但进入不同通道（定义 313）。**

**定义 312（索引接地后验 IGF）**
`p(z, r, x | g, o) ∝ p(z) · p(r | z) · p(x | o) · p(g | z, r, x, h, M) · p(M | o)`.
对 `x`（位姿粒子或高斯）与 `r` 边缘化，输出 `p(z | g, o)`、`p(r | g, o)` 与联合。**核心：意图后验是对几何后验边缘化得到的**，因此几何歧义会传播为意图歧义；反过来，指代后验也携带语用先验。这是「索引耦合」。

**定义 313（三分不确定性 TRI）**
- `U_ale = E[tr Σ_sensor]`：手部抖动、时间同步抖动、(当前视角下) 不可约的观测噪声；
- `U_sem = H(Z | κ, τ, o) − E_{y_sem}[H(Z | κ, τ, o, y_sem)]`：语用/意图歧义，问一句可约；
- `U_idx = I(R; X | g, o) = H(R | g, o) − E_{x∼p(x|o)}[H(R | g, x)]`：位姿/地图不确定导致的指代歧义，换视角/重新定位可约。
三者语义不同，**不做简单加和**，分别进入不同通道（定义 315、325）。`U_sem` 与 `U_idx` 共同构成 R69 的 `U_epi`，但可约机制不同。

**定义 314（索引可分辨条件）** 设两 landmark `r_i, r_j` 在当前位姿 `x` 下的角间距为 `Δθ_ij(x)`，位姿角不确定度为 `σ_x^ang`，手势射线噪声为 `σ_g`。定义索引分离比
`ρ_ij = Δθ_ij(x) / (σ_x^ang + σ_g)`.
若 `ρ_ij < 3`（A99），称该对在当前视角下**索引不可分辨**：此时无论语义多确定，指代仍不可判；降低 `σ_x^ang`（移动/重定位）或增大 `Δθ_ij`（换视角）才有效。

**定义 315（双通道信息增益与路由 SIR）** 对话式澄清、主动移动、主动验证分别记为 `g_sem`、`u_idx`、`u_ver`。定义
`VoI_sem(g) = U_sem − E_{y}[H(Z | g, o, y)]`，
`VoI_idx(u) = U_idx − E_{y}[H(R | u, o, y)]`.
SIR 在预算与安全约束下选择通道
`c* = argmax_{c ∈ {sem, idx, ver}} (VoI_c − cost_c) / norm_c`，
并显式记录「语义回答不会自动降低 U_idx」：若回答只是又一次同视角指示，则 `VoI_idx(g_sem) ≈ 0`。`VoI ≤ 0` 时退化为 R69 的保守兜底。

**定义 316（共享信息动作与联合 VoI NBG）** 运动 `u ∈ 𝒜_motion` 同时改变位姿熵 `H(X)`、手势可观测性 `H(κ | u)` 与指代熵 `H(R)`。定义联合增益
`J(u) = α_sem·IG(Z; y | u) + α_idx·IG(R; y | u) + α_geo·IG(X; y | u) + α_ale·IG(κ; y | u) − c(u)`,
`s.t. risk(u) ≤ ε_int`，预算未超。采用**向量值增益 + 约束优化**：最大化 `min_k (gain_k / cap_k)`（各通道不被饿死），或最大化加权和并约束各通道后验熵上限。R69 的 MINT 是 `𝒜_motion = ∅`、`U_idx = 0` 的退化。

**定义 317（α-指代集 R_α）** `R_α` 为后验质量 ≥ 1−α 的最小高密度集：
`R_α = argmin_{S} |S| s.t. Σ_{r∈S} p(r | g, o) ≥ 1−α`，
并允许 `⊥`（拒绝/需验证）作为候选。若使用学习到的接地打分，则用 split conformal 给出覆盖保证 `P(r* ∈ R_α) ≥ 1−α`（交换性假设下）。

**定义 318（指代集安全证书 RSC）** 设 `a*(r)` 为指代 `r` 对应的任务动作/规划。把 referent 按「动作等价类」划分：若 `a*(r_i)` 与 `a*(r_j)` 产生相同的安全前缀或相同目标，则等价。称 `R_α` **action-sufficient** 当且仅当 `R_α` 落在同一等价类，或对所有 `r ∈ R_α` 有 `risk(a*(r)) ≤ ε`。否则定义**对所有候选都安全**的动作集
`SafeAll(R_α) = ∩_{r∈R_α} Safe(r)`，
优先执行 `a ∈ SafeAll(R_α)`；若为空，执行验证动作 `u_ver`（靠近/换视角/请求确认）。**歧义税** `τ_amb = min_{a∈SafeAll} cost(a) − min_r cost(a*(r)) ≥ 0` 度量「不猜」的代价。

**定义 319（空间溯源门 SPG）** 手势导出的约束只有在同时满足以下三条时才可进入位姿图/持久地图：
(i) **关联稳定**：从 `p(x|o)` 抽 `N` 个位姿样本，同一 `r` 被选中的比例 ≥ 1−β（不是只看 MAP）；
(ii) **独立佐证**：至少一条非手势几何观测（视觉特征、深度、LiDAR、或移动后的第二视角）支持该约束；
(iii) **有界杠杆**：约束的 Fisher 信息被截断在 `I_max`，使用鲁棒核，且卡方门 `χ² ≤ τ_g`。
不满足者只能进入 DGH 账本（定义 320），不得写入持久地图。

**定义 320（暂定地标账本 DGH）** 手势导出的地标是假设 `h_r = (μ_r, Σ_r, TTL, trust, provenance_hash)`。它可参与规划（作为软代价/候选 referent），但不参与定位与地图融合；只有被独立观测复核（SPG-ii）后才升格为持久地标。超时或与后续观测矛盾则失效。这是「可证伪的地图先验」。

**定义 321（手势语用认证 GPA）** 判别 `τ` 并认证手势发出者：身份/授权、活体与重放检测（时序一致性、深度、微动作）、跨模态一致性（注视 + 指向 + 语音 + 面部）。只有**已授权的指示性手势**可以创建 DGH 条目；未授权/象征性手势只触发社交回应，永不进入任务与地图通道。语用类型决定信息去向：`deictic → U_idx`，`iconic/demonstrative → U_sem/动作模仿`。

**定义 322（DEIXIS 干扰集 ℰ_deixis）**
`ℰ_deixis = ℰ_FLUID × { 重放/伪造手势, referent spoofing（指错/指假地标）, 手势投毒建图（假回环）, 跨模态共谋（注视+手指+语音一起演）, 基座标架伪造, 动态遮挡攻击 }`.
并入 AIC-DEIXIS；每条干扰都必须在证书 J_DEIXIS 中留下可审计痕迹。

**定义 323（参与式审计 VQAuditor-D）** 审计新增：`R_α` 是否计算、是否 action-sufficient、地图写入是否过 SPG、手势是否认证、是否单源采纳、人的基座标架是否被跟踪、验证动作是否真的执行。结论回灌 AuditBuf，成为下一轮 NBG 的成本与信任先验。

**定义 324（证书 J_DEIXIS）**
`J_DEIXIS = (J_FLUID, referent_set_mass, action_sufficiency, ambiguity_tax, indexical_ratio_p05, map_write_gate_stats, gesture_auth_score, dgh_promotion_ratio, deixis_ver)`.
`Valid ⇔ Valid(J_FLUID) ∧ coverage ≥ 1−α ∧ (action-sufficient ∨ SafeAll 非空) ∧ 无未过门的地图写入 ∧ 认证通过`。

**定义 325（三级保守退避与 R69 严格包含）**
- 若 `R_α` action-sufficient、SPG 通过、GPA 通过：`λ = λ_floor(U_ale)`（resolution bonus）；
- 若 `U_sem` 可约：走 R69 的问句通道；
- 若 `U_idx` 可约：走新的移动/重定位通道；
- 若未消解/超时/被投毒/覆盖不足：`λ = λ_floor(U_ale + U_sem^{res} + U_idx^{res})`，执行 `SafeAll` 或拒绝；**R69 是 `U_idx = 0`、指代以唯一名称给出、SPG 惰性的特例**，安全侧永不弱于 R69。

**定义 326（时序-坐标锚定 TCA）** 维护人的基座标架 `h_t` 及其协方差（视觉跟踪 + IMU/骨骼）；手势时间戳必须与 SLAM 关键帧在 `Δt_sync` 内关联；人移动时使用运动补偿射线。定义**共模坐标误差** `e_cm` 为 `h_t` 与 `x_t` 共享的系统性偏差，用独立锚（轮速、重力、静态 fiducial、第二视角）估计；`e_cm` 超过阈值时禁止任何手势写图，并强制进入 R69 兜底。

# IP-264 IGF：索引接地后验（复用 R69 MTM trunk + 骨架编码器）
class IndexicalGrounding:

        self.pose, self.map, self.Np = pose_filter, map_model, Np

# IP-265 TRI：三分不确定性
def tri_decompose(post, g, o):

    U_sem = entropy(intent_marginal(post)) - \
            exp_entropy_after_semantic_answer(post)

            mean_x(entropy_referent_given_pose(post))    # I(R;X|g,o)
    return U_ale, U_sem, U_idx

# IP-266 SIR：双通道路由（问 vs 动 vs 验）
def route(post, U, budget):
    best = None
    for g in semantic_questions(post):                  # 问：降 U_sem
        if budget.allow(g) and c_ras_wm.certify_info(g):
            score = (U.sem - expected_sem_entropy(post, g)) - cost(g)
            best = better(best, ("sem", g, score))
    for u in motion_candidates(post):                   # 动：降 U_idx
        if budget.allow(u) and c_ras_wm.certify_info(u):
            score = (U.idx - expected_idx_entropy(post, u)) - cost(u)
            best = better(best, ("idx", u, score))
    if best is None or best[2] <= 0:
        return None                                     # 退化 R69
    return best

# IP-267 NBG：共享信息动作（联合 VoI，主动 SLAM + 主动消歧）
def next_best_grounding(post, budget):
    best = None
    for u in shared_motion_candidates(post):            # 同时改变位姿/视角
        gains = {
            "sem": ig_semantic(post, u),
            "idx": ig_indexical(post, u),
            "geo": ig_pose(post, u),
            "ale": ig_observability(post, u),
        }
        if not budget.allow(u) or not c_ras_wm.certify_motion(u):
            continue
        score = min(g / cap[k] for k, g in gains.items()) - cost(u)
        best = better(best, (u, gains, score))
    return best

# IP-268 RSC：指代集安全
def referent_safe_action(post, alpha):
    R = alpha_credible_set(post, alpha)                 # 定义 317
    if action_sufficient(R):
        return map_action(R)                            # 正常任务动作
    safe_all = intersect(Safe(r) for r in R)
    if safe_all.nonempty():
        return argmin_cost(safe_all)                    # 对所有候选都安全
    return verify_action(R)                             # 不赌，去验证

# IP-269 SPG：空间溯源门（防手势投毒建图）
def spatial_provenance_gate(g, r, post, map_model):
    stable = association_stability(g, r, post) >= 1 - BETA
    corroborated = map_model.has_independent_support(r)  # 非手势几何
    bounded = fisher_info(g, r) <= I_MAX and chi2(g, r) <= TAU_G
    return stable and corroborated and bounded

# IP-272 DEIXIS 主闭环（继承 R69，仅在指代处插入新层）
def DEIXIS_RAS_round(M, obs, gesture):
    z, o = M.mtm.forward(...)
    c, U_cal, thr = M.cof.step(...)                     # R68 标定
    if gesture is None or not M.gpa.authenticate(gesture):
        return R69_round(M, obs)                        # 无手势 = R69
    post = M.igf.posterior(gesture, o)
    U_ale, U_sem, U_idx = M.tri.decompose(post, gesture, o)
    # 1) 先算指代集与安全动作；不可判则只允许 SafeAll/验证
    R = M.rsc.alpha_set(post, M.alpha)
    a_safe = M.rsc.referent_safe_action(post, M.alpha)
    # 2) 双通道路由：问降语义、动降索引；共享预算
    act = M.sir.route(post, U, M.budget)
    if act and act.kind == "sem":
        ans = M.cia.ask(act.g)                          # R69 通道

    elif act and act.kind == "idx":
        u = M.nbg.next_best_grounding(post, M.budget)
        post = M.pose.predict_after(u); post = M.igf.reobserve(gesture, post)
    # 3) 手势约束：先账本，后地图（SPG + DGH）

    unresolved = (0 if a_safe is not None else U_sem + U_idx)

    return k, lam, a_safe, (U_ale, U_sem, U_idx, R)

## 3. 推导

**引理 19（索引耦合的贝叶斯误差下界）** 两个候选 referent 的角间距为 `Δ`，位姿角误差 `σ_x`，手势射线噪声 `σ_g`。在对称先验下，任何仅利用当前视角手势射线的判决器，其指代错误率至少为
`Φ(−Δ / (2√(σ_x² + σ_g²)))`。
系：当 `σ_x ≫ Δ` 时，错误率被 `σ_x` 钉住；**同视角下反复询问（得到的仍是同一个指示）无法突破该下界**。只有三种行为能继续降低误差：降低 `σ_x`（移动/重定位）、增大 `Δ`（换视角）、或获得**非索引**答案（唯一名称/数据库检索）。这为 SIR 的「问 vs 动」路由提供了不可互换性的理论依据。

**引理 20（通道分离）** 若人类回答 `y` 在给定意图 `Z` 时与指代 `R` 条件独立（即 `y` 只命名意图，不提供新几何），则 `I(R; y | g, o) ≤ I(Z; y | g, o)`，问句对 `U_idx` 的降低只能通过 `Z` 间接发生；若 `y` 是另一视角下的新指示，则其降低 `U_idx` 的机制是「位姿变化」而非「语义」，必须计入 NBG 的运动通道。故 `VoI_sem` 与 `VoI_idx` 不可自由互换，R69 的单一 VoI 会系统性高估「问」在指代场景中的价值。

**引理 21（指代集安全）** 若 `P(r* ∈ R_α) ≥ 1−α`（conformal 覆盖或可信集），且执行的动作 `a ∈ SafeAll(R_α)`，则在模型与安全集准确的前提下，不安全结果的概率 ≤ α（确定性安全集下为 0）。系：直接执行 MAP referent 的危险率等于 `E[max_r p(r|g,o)·1{r ∈ Hazard}]`，在边界场景可远高于 α；预实验（定义见 §5）中 MAP 危险率为 0.27–0.49，而 RSC 为 0，代价是验证率上升。

**引理 22（有界地图污染）** 在 SPG 的 Fisher 信息截断 `I_max`、卡方门与 DGH 升格规则下，任意单条手势约束对位姿图的信息贡献有界；`T` 条未被独立佐证的投毒约束无法改变持久地图（只能在 DGH 中产生可撤销的软先验）。被独立佐证的真实约束则以有界步长改善地图。故手势投毒的地图误差不会无界累积；预实验中未截断 RMSE 为 1.58，截断为 1.09，截断+门为 0.22，账本为 0.10（单位为 toy 地标位置）。

**定理 18（DEIXIS 严格包含 R69）** 在 `U_idx = 0`（位姿/地图确定，或指代以唯一名称给出）、SPG 惰性、`R_α` 自动 action-sufficient 的退化域内，DEIXIS 的每一步都退化为 R69 的 FLUID 闭环（同样的模态分解、同样的 VoI 问句、同样的 λ_floor）。在一般状态下，DEIXIS 的动作集包含 R69 的问句动作集，且额外用 `SafeAll` 剔除了「赌 MAP」的动作，故期望风险 ≤ R69；当 `U_idx > 0` 且存在可用运动时，严格更优（引理 19–21）。

**定理 19（共享信息动作的支配性）** 在可行动作集嵌套、各通道信息增益次模、预算共享的条件下，NBG 的约束 max-min 目标在任意状态上的最差通道增益 ≥ 任何固定单通道策略；当只开放语义通道时，NBG 的最优解收敛到 R69 的 MINT。冲突惩罚由通道间互信息 `I(sem; idx)` 上界给出：`J_joint ≥ max_k J_k − I(sem; idx)`。这解释了「一次移动同时降 U_idx 与 U_ale」为何常常优于「先问再动」。

**定理 20（安全与无突变）** 所有任务动作仍过 C-RAS-WM 前缀认证；RSC 只**收缩**动作集（`SafeAll ⊆ Safe`），不扩张安全包络；手势约束只进入 DGH 或带截断的软约束，不能直接改变执行器的安全边界；未消解时 λ 单调不降地退化为 R69。故 R68/R69 的提交/换装不变式与连续性保持。

## 6. 本轮最大风险

**一句话**：DEIXIS-RAS 的最大风险是**共模坐标误差**——手势的人的基座标架 `h` 与 SLAM 位姿 `x` 若被同一个错误先验系统性地带偏（时间同步错、人的骨架跟踪错、标定错、或场景几何退化），那么指代、建图与主动验证会共用同一个错误并彼此自洽：机器人会以极高的置信度走向一个「所有证据都同意」的错误地点。**指错坐标，比不指更危险。**

**次级风险与缓解**：
1. **RSC 过度保守导致成功率崩塌** → 验证/移动本身是信息动作；用 conformal 校准 α、设定歧义税预算、失败时回退 R69；
2. **手势分类器的视角/人群偏差** → LOSO + 校准 + E315 人类研究；对低置信手势优先要求非索引答案；
3. **耐心攻击者用多次「验证」把假地标做成真的** → SPG 的独立佐证必须来自不同视角/不同模态，DGH 有信任衰减与全局一致性检验；
4. **DGH/地图账本膨胀** → O(1) 条目、TTL、与持久地图分离存储、全局回环时批量复核；
5. **实时预算被位姿粒子与多通道优化击穿** → 无手势直接走 R69；手势路径用廉价门控（语用置信度 + 索引分离比）决定是否启动 IGF；
6. **共模坐标误差** → 独立锚（轮速/IMU/重力/静态 fiducial）、跨视角自洽检验、`e_cm` 超阈值即禁止写图并强制 R69。

| `ℓ(g; x, h) = x·h·ray(κ)` | 世界系指代射线 |

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** DEIXIS-RAS = (IGF, TRI, SIR, NBG, RSC, SPG, DGH, GPA, RAS-WM†)；零学习写操作继承；指代可追溯（动作携带 `R_α`、位姿来源、手势时间窗；手势不得直写持久地图）；先安全后消歧（`R_α` 不 action-sufficient 时只能 `SafeAll` 或验证，不得赌 MAP）。

**定义 311–312（手势因子化与 IGF）** `p(g|z,r,x,h,M)=p(τ|z)p(κ|z,τ)p(g_ray|r,x,h)p(s|r,x,M)`；指代射线 `ℓ=x·h·ray(κ)`，`p(g_ray|r,x,h)∝exp(−d(ℓ,r)²/2σ_g²)·vis`；联合后验 `p(z,r,x|g,o)` 对 `x,r` 边缘化。意图后验由几何后验边缘化而来——几何歧义传播为意图歧义。

**定义 313–314（三分与可分辨）** `U_ale=E[trΣ_sensor]`；`U_sem=H(Z|κ,τ,o)−E[H(Z|...y_sem)]`；`U_idx=I(R;X|g,o)`。`ρ_ij=Δθ_ij/(σ_x^ang+σ_g)`；`ρ<3` ⇒ 索引不可分辨，语义问答无效。

**定义 315–316（SIR 与 NBG）** `VoI_sem(g)=U_sem−E[H(Z|g,y)]`，`VoI_idx(u)=U_idx−E[H(R|u,y)]`；路由 `c*=argmax(VoI_c−cost_c)/norm_c`。NBG：`J(u)=Σ_k α_k IG_k(u)−c(u)`，`s.t. risk(u)≤ε_int`；用向量增益的 max-min 防通道饿死。R69 的 MINT = `𝒜_motion=∅` 的退化。

**定义 317–318（指代集与安全）** `R_α` 为质量 ≥1−α 的最小高密度集（conformal 可给覆盖）。`R_α` action-sufficient ⇔ 全部候选落在同一动作等价类，或各自风险 ≤ε；否则 `SafeAll(R_α)=∩ Safe(r)`，空则验证。`τ_amb` 度量不猜的代价。

**定义 319–320（SPG 与 DGH）** 手势约束入图需（i）位姿采样下关联稳定 ≥1−β；（ii）非手势几何独立佐证；（iii）Fisher 截断 `I_max` + 卡方门。否则只进 DGH：`(μ,Σ,TTL,trust,provenance)`，参与规划不参与定位/融合，复核后升格。

**定义 321–322（GPA 与干扰集）** 语用判别 + 身份/授权 + 活体/重放 + 跨模态一致（注视/指向/语音/面部）。仅已授权指示手势可建 DGH。`ℰ_deixis = ℰ_FLUID × {重放/伪造, 指错/指假, 假回环建图, 跨模态共谋, 基座标架伪造, 动态遮挡}`。

**定义 323–324（审计与证书）** VQAuditor-D 审 `R_α`、action-sufficiency、SPG、认证、单源采纳、验证执行、共模误差；`J_DEIXIS` 增加覆盖、歧义税、`ρ_p05`、门统计、认证分、升格率。

**定义 325–326（三级退避与坐标锚定）** 消解成功 `λ=λ_floor(U_ale)`；`U_sem` 可约走问句；`U_idx` 可约走移动；未消解/被投毒/覆盖不足 `λ=λ_floor(U_ale+U_sem^res+U_idx^res)` + `SafeAll`/拒绝。R69 是 `U_idx=0` 的特例。TCA 维护 `h_t` 与 `x_t`，用独立锚估计共模误差 `e_cm`；超阈值禁止写图并回退 R69。

# IP-264 IGF：联合接地后验
class IndexicalGrounding:
    def posterior(self, g, o):
        zt = self.trunk(o)
        kappa, tau, span = self.gesture_head(g)
        xs = self.pose.sample(o, self.Np)                 # 位姿粒子
        pts = []
        for x in xs:
            ray = compose(x, self.pose.human_frame(span)) @ ray_of(kappa)
            for r in self.map.candidates_near(ray):
                pts.append((self.lik_given(kappa, tau, ray, r, x), r, x))
        return normalize(pts)

# IP-265 TRI：三分
def tri_decompose(post, g, o):
    U_ale = sensor_noise_trace(g)
    U_sem = entropy(intent_marginal(post)) - exp_entropy_after_semantic_answer(post)
    U_idx = entropy(referent_marginal(post)) - mean_x(entropy_referent_given_pose(post))
    return U_ale, U_sem, U_idx

# IP-266 SIR：双通道路由
def route(post, U, budget):
    best = None
    for g in semantic_questions(post):                    # 降 U_sem
        if budget.allow(g) and c_ras_wm.certify_info(g):
            best = better(best, ("sem", g, U.sem - expected_sem_entropy(post, g) - cost(g)))
    for u in motion_candidates(post):                     # 降 U_idx
        if budget.allow(u) and c_ras_wm.certify_info(u):
            best = better(best, ("idx", u, U.idx - expected_idx_entropy(post, u) - cost(u)))
    return best if best and best[2] > 0 else None         # 否则退化 R69

# IP-267 NBG：共享信息动作
def next_best_grounding(post, budget):
    best = None
    for u in shared_motion_candidates(post):
        if not budget.allow(u) or not c_ras_wm.certify_motion(u): continue
        gains = {"sem": ig_semantic(post, u), "idx": ig_indexical(post, u),
                 "geo": ig_pose(post, u), "ale": ig_observability(post, u)}
        score = min(gains[k] / cap[k] for k in gains) - cost(u)
        best = better(best, (u, gains, score))
    return best

# IP-268 RSC：指代集安全
def referent_safe_action(post, alpha):
    R = alpha_credible_set(post, alpha)
    if action_sufficient(R): return map_action(R)
    safe_all = intersect(Safe(r) for r in R)
    return argmin_cost(safe_all) if safe_all.nonempty() else verify_action(R)

# IP-269 SPG：空间溯源门
def spatial_provenance_gate(g, r, post, map_model):
    return (association_stability(g, r, post) >= 1 - BETA
            and map_model.has_independent_support(r)
            and fisher_info(g, r) <= I_MAX and chi2(g, r) <= TAU_G)

# IP-274 主闭环（继承 R69）
def DEIXIS_RAS_round(M, obs, gesture):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    if gesture is None or not M.gpa.authenticate(gesture):
        return R69_round(M, obs)
    post = M.igf.posterior(gesture, o)
    U_ale, U_sem, U_idx = M.tri.decompose(post, gesture, o)
    R = M.rsc.alpha_set(post, M.alpha)
    a_safe = M.rsc.referent_safe_action(post, M.alpha)
    act = M.sir.route(post, U, M.budget)
    if act and act.kind == "sem":
        post = M.cia.update(post, M.cia.ask(act.g), discipline="k_orthogonal")
    elif act and act.kind == "idx":
        u = M.nbg.next_best_grounding(post, M.budget)
        post = M.igf.reobserve(gesture, M.pose.predict_after(u))
    for r in R:
        if M.spg.gate(gesture, r, post, M.map):
            M.map.add_soft_constraint(r, cap=I_MAX)
        else:
            M.dgh.add(gesture, r)
    unresolved = 0 if a_safe is not None else U_sem + U_idx
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + unresolved))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds, referent_set=R)
    M.vqa_d.submit_async(gesture, R, a_safe, U_sem, U_idx, M.spg.stats)
    return k, lam, a_safe, (U_ale, U_sem, U_idx, R)

## 4. 推导

**引理 19（索引耦合下界）** 对称两候选、角间距 `Δ`、位姿角误差 `σ_x`、射线噪声 `σ_g` 时，仅用当前视角射线的错误率 ≥ `Φ(−Δ/(2√(σ_x²+σ_g²)))`。`σ_x≫Δ` 时被 `σ_x` 钉死；同视角重复询问无法突破。只有降 `σ_x`、换视角增大 `Δ`、或获得非索引（唯一名称）答案才能继续降误差。

**引理 20（通道分离）** 若回答 `y` 在给定 `Z` 时与 `R` 条件独立（只命名意图），则 `I(R;y|g,o)≤I(Z;y|g,o)`，问句只能间接降 `U_idx`；若 `y` 是新视角的指示，则降 `U_idx` 的机制是位姿变化，必须计入 NBG 的运动通道。R69 的单一 VoI 会高估「问」在指代场景中的价值。

**引理 21（指代集安全）** 若 `P(r*∈R_α)≥1−α` 且 `a∈SafeAll(R_α)`，则不安全概率 ≤ α（确定性安全集下为 0）。MAP referent 的危险率 `E[max_r p(r|g,o)1{r∈Hazard}]` 在边界场景可远高于 α。

**引理 22（有界地图污染）** SPG 的 Fisher 截断、卡方门与 DGH 升格规则使单条手势约束的信息贡献有界；`T` 条未独立佐证的投毒约束不能改变持久地图，只能在 DGH 产生可撤销软先验。故手势投毒误差不会无界累积。

**定理 18（DEIXIS 严格包含 R69）** 在 `U_idx=0`、指代以唯一名称给出、SPG 惰性、`R_α` 自动 action-sufficient 的退化域内，DEIXIS 逐步退化为 R69 的 FLUID 闭环；一般状态下其动作集包含 R69 的问句集，并额外用 `SafeAll` 剔除「赌 MAP」的动作，故期望风险 ≤ R69；`U_idx>0` 且有可用运动时严格更优。

**定理 19（共享信息动作支配性）** 动作集嵌套、通道增益次模、预算共享时，NBG 的 max-min 目标在最差通道上不劣于任何固定单通道策略；只开放语义通道时收敛到 R69 的 MINT。冲突惩罚由 `I(sem;idx)` 上界：`J_joint ≥ max_k J_k − I(sem;idx)`。

**定理 20（安全与无突变）** RSC 只收缩动作集；手势约束只进 DGH 或带截断软约束，不直接改执行器安全边界；未消解时 λ 单调不降地退化为 R69；R68/R69 的提交/换装不变式与连续性保持。

## 7. 本轮最大风险

**一句话**：DEIXIS-RAS 的最大风险是**共模坐标误差**——手势的人的基座标架 `h` 与 SLAM 位姿 `x` 若被同一个错误先验系统性地带偏（时间同步错、骨架跟踪错、标定错、场景几何退化），指代、建图与主动验证会共用同一个错误并彼此自洽，机器人会以极高置信度走向一个「所有证据都同意」的错误地点。**指错坐标，比不指更危险。**

**次级风险与缓解**：RSC 过度保守（验证/移动即信息动作 + conformal 校准 + 歧义税预算 + 回退 R69）；手势分类的视角/人群偏差（LOSO + 校准 + 低置信时要求非索引答案）；耐心攻击者用多次验证「做实」假地标（多视角/多模态独立佐证 + 信任衰减 + 全局一致性）；DGH 膨胀（TTL + O(1) 条目 + 与持久地图分离）；实时预算（无手势走 R69 + 廉价门控）；共模误差（轮速/IMU/重力/静态 fiducial 独立锚 + 跨视角自洽检验 + `e_cm` 超阈值禁止写图）。
