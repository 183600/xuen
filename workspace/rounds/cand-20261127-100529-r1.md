### 第 1 轮灵感驱动研究记录

**灵感词**：结构优化、力控、轻量化结构

**直觉与动机**：
现有框架（HPC-E+）已建立「感知-合规-能量」三位一体的证书链，但缺失「结构-力学」维度的形式化验证。机器人本体作为物理实体，其结构拓扑、力控策略、轻量化设计直接决定能量存储上界 E_max、力控带宽、碰撞生存包络。受「结构优化」启发，拓扑优化（SIMP/Level-set）生成的有机形态需附带应力/应变证书；受「力控」启发，阻抗/导纳控制的无源性证书可桥接 EVC 与物理接触；受「轻量化结构」启发，晶格/TPMS 结构的等效刚度张量需可机械复核。核心洞见：**结构设计即证书生成过程，力控执行即证书消费过程，轻量化约束即证书预算分配过程**。

**形式化目标**：
1. 定义结构优化证书（SOC）：拓扑优化结果 ρ(x) ∈ [0,1]^Ω 附带 von Mises 应力上界证书 σ_vm(x) ≤ σ_yield/γ_s
2. 定义力控证书（FCC）：阻抗控制 Z_d(s) = M_d s + B_d + K_d/s 的无源性证书 ∫ Fᵀv dt ≥ -E_0
3. 定义轻量化证书（LSC）：等效刚度张量 C^hom 与相对密度 ρ̄ 的可证边界 C^hom ≤ C_solid ρ̄^p
4. 构建统一结构-力学准入门（USMC）：HPC-E+ ∪ SOC ∪ FCC ∪ LSC 四证一体，Exec_v24 ⊆ Exec_v23
5. 证明单调退化链在结构损伤/力控失稳/轻量化超限下的保持性

## 本轮灵感驱动：成本控制、长期记忆、可扩展性

**直觉与动机**：

## 1. 关键算法骨架（在 IP-448–450 骨架上扩展）

```python
# ============================================================
# IP-451 Kinodynamic Feasibility Certificate (KFC)
# ============================================================
@dataclass
class KinodynamicFeasibilityCertificate:
    """动力学可行性：作动约束 + ISS 跟踪管 + 离散化缺陷"""
    f: Callable                      # ẋ = f(x,u)
    dt: float
    u_max: Tensor                    # [m] 各通道作动上限
    lam: float                       # ISS 收缩率 λ>0
    delta_dist: float                # 扰动上界 δ
    eps_int: float                   # 单步离散化缺陷
    r_max: float                     # 允许跟踪管半径（含任务余量）
    xi: Tensor = None                # [T, n] 标称状态
    u_seq: Tensor = None             # [T, m] 标称控制
    integrator: str = "rk4"

    def verify_actuator(self) -> bool:
        """|u_k| ≤ u_max，逐通道"""
        return bool(torch.all(self.u_seq.abs() <= self.u_max))

    def verify_tube(self) -> bool:
        """ISS 递推：r_{k+1} = a·r_k + (δ/λ)(1-a) + ε_int, a=e^{-λdt/2}"""
        a = math.exp(-self.lam * self.dt / 2.0)
        r = 0.0
        for _ in range(len(self.xi) - 1):
            r = a * r + (self.delta_dist / self.lam) * (1.0 - a) + self.eps_int
            if r > self.r_max:
                self._r_T = r
                return False
        self._r_T = r
        return r <= self.r_max

    def verify_discretization(self, Phi: Callable) -> bool:
        """单步积分缺陷 ‖Φ_dt(x_k,u_k) - x_{k+1}‖ ≤ ε_int"""
        for k in range(len(self.xi) - 1):
            x_pred = Phi(self.xi[k], self.u_seq[k], self.dt)
            if torch.norm(x_pred - self.xi[k + 1]) > self.eps_int:
                return False
        return True

    def verify_all(self, Phi: Callable) -> bool:
        return (self.verify_actuator()
                and self.verify_tube()
                and self.verify_discretization(Phi))


# ============================================================
# IP-452 Path Planning Certificate (PPC)
# ============================================================
@dataclass
class PathPlanningCertificate:
    """清障 + 渐近最优 + 概率完备 + 同伦类"""
    clearance_min: float = 0.02      # c_min (m)
    eps_opt: float = 0.10            # 相对最优间隙
    delta_plan: float = 0.01         # 规划失败概率上界
    homotopy_class: Optional[int] = None
    n_samples: int = 0

    def verify_clearance(self, path: Tensor, esdf_fn: Callable,
                         lip: float = 0.0) -> bool:
        """d(ξ,X_obs) ≥ c_min；用 ESDF 采样 + Lipschitz 间隙下界保守化"""
        ds = [esdf_fn(p) for p in path]
        # 相邻采样间距需扣除 Lipschitz 下界 lip·Δs
        if lip > 0 and len(path) > 1:
            ds = [d - lip * torch.norm(path[i + 1] - path[i])
                  for i, d in enumerate(ds[:-1])]
        return min(ds) >= self.clearance_min

    def verify_optimality_gap(self, cost: float, lower_bound: float) -> bool:
        """cost(ξ) ≤ (1+ε_opt)·cost*，cost* 由下界证书（如 Dubins/松弛）给出"""
        return cost <= (1.0 + self.eps_opt) * lower_bound

    def verify_probabilistic_completeness(self) -> bool:
        """RRT* 衰减率：n ≥ n_min(δ_plan, 空间体积, 连通性)"""
        n_min = math.log(1.0 / self.delta_plan) / max(self._visibility_ratio(), 1e-9)
        return self.n_samples >= n_min

    def verify_homotopy(self, path_class: int) -> bool:
        return self.homotopy_class is None or path_class == self.homotopy_class

    def verify_all(self, path, esdf_fn, cost, lower_bound,
                   path_class, lip=0.0) -> bool:
        return (self.verify_clearance(path, esdf_fn, lip)
                and self.verify_optimality_gap(cost, lower_bound)
                and self.verify_probabilistic_completeness()
                and self.verify_homotopy(path_class))

    def _visibility_ratio(self) -> float:
        # 由环境连通性离线估计（自由空间可见性比例），默认回退
        return getattr(self, "visibility_ratio", 0.3)


# ============================================================
# IP-453 Dynamic Safety Certificate (DSC)
# ============================================================
@dataclass
class DynamicSafetyCertificate:
    """鲁棒 CBF 前向不变性 + ISSf 收缩度量"""
    h: Callable                      # 安全函数 h(x)，安全集 {h≥0}
    alpha: Callable                  # 扩展类 K∞
    grad_h: Callable                 # 返回 (L_f h, L_g h, h)
    u_max: Tensor = None
    w_dist: float = 0.0              # 扰动鲁棒裕度

    def _min_over_u(self, x: Tensor) -> float:
        Lfh, Lgh, hx = self.grad_h(x)
        # min_{u∈[-u_max,u_max]} L_g h·u = -|L_g h|·u_max（逐通道）
        u_worst = -torch.sign(Lgh) * self.u_max
        return float(Lfh + (Lgh * u_worst).sum() + self.alpha(hx)
                     - torch.norm(Lgh) * self.w_dist)

    def verify_forward_invariance(self, X_closed: Tensor) -> bool:
        """∀x∈X_closed: max_{u∈U}[L_f h+L_g h u+α(h)] - ‖L_g h‖w ≥ 0"""
        return all(self._min_over_u(x) >= -1e-9 for x in X_closed)

    def verify_issf(self, V_dot_fn: Callable, X_closed: Tensor,
                    c: float, b: float) -> bool:
        """收缩度量：V̇ ≤ -cV + b，保证误差最终有界"""
        for x in X_closed:
            V, Vdot = V_dot_fn(x)
            if Vdot > -c * V + b + 1e-9:
                return False
        return True

    def verify_all(self, X_closed, V_dot_fn, c, b) -> bool:
        return (self.verify_forward_invariance(X_closed)
                and self.verify_issf(V_dot_fn, X_closed, c, b))


# ============================================================
# IP-454 PDUC 路径-动力学统一准入门
# ============================================================
@dataclass
class PathDynamicsUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    kfc: KinodynamicFeasibilityCertificate
    ppc: PathPlanningCertificate
    dsc: DynamicSafetyCertificate

    def admits(self, multi_plan, sensor_data: dict, Phi: Callable,
               esdf_fn: Callable, X_closed: Tensor, V_dot_fn: Callable,
               cost: float, lower_bound: float, path_class: int,
               **src_kwargs) -> bool:
        # 1. 上游 SRC-USC 十证（物理/结构/语义/重构/协同/成本/记忆/可扩展）
        if not self.src_usc.admits(multi_plan, sensor_data, **src_kwargs):
            return False
        path = multi_plan.reference_path
        # 2. 规划证书：清障/最优/完备/同伦
        if not self.ppc.verify_all(path, esdf_fn, cost, lower_bound, path_class):
            return False
        # 3. 动力学可行性：作动/管/离散缺陷
        if not self.kfc.verify_all(Phi):
            return False
        # 4. 动力学安全：鲁棒前向不变 + ISSf
        if not self.dsc.verify_all(X_closed, V_dot_fn, c=0.5, b=1e-3):
            return False
        return True

    def synthesize_or_verify(self, *args, **kwargs) -> tuple[bool, str]:
        """合成模式：规划器产出候选；失败则回退验证模式（保守计划）"""
        if self.admits(*args, **kwargs):
            return True, "synthesized"
        ok = self.src_usc.admits(*args[:2], **kwargs)
        return (ok, "fallback_verify" if ok else "reject")
```

## 3. 正确性论证（本轮增量）

### 引理 16（KFC 的 ISS 管-残差组合保证）
**陈述**：设单步离散化缺陷 ≤ ε_int、扰动 ‖d‖≤δ、标称闭环误差满足增量 ISS（V̇≤-λV+δ，λ>0）。则 `verify_tube ∧ verify_discretization = True` ⟹ 对 ∀k，真实轨迹 x_k 满足 ‖x_k-ξ_k‖ ≤ r_k ≤ r_max。

**证明**：令 e_k=x_k-ξ_k。由增量 ISS 与比较引理，一步误差满足 ‖e_{k+1}‖ ≤ e^{-λdt/2}‖e_k‖ + (δ/λ)(1-e^{-λdt/2})；再叠加离散化缺陷 ε_int 得递推 r_{k+1}=a r_k+(δ/λ)(1-a)+ε_int，且 ‖e_{k+1}‖≤r_{k+1}。归纳基 e_0=0≤r_0。`verify_tube` 逐步检查 r_k≤r_max，故真实轨迹始终留在以 ξ 为心的 r_max 管内。∎

### 引理 17（PPC 的完备-最优-清障-同伦四重保证）
**陈述**：`PPC.verify_all = True` ⟺ 路径同时满足几何清障 ≥ c_min、相对最优间隙 ≤ ε_opt、概率完备 ≥ 1-δ_plan、同伦类与任务指定一致。

**证明**：(1) `verify_clearance` 用 ESDF 采样并扣除 Lipschitz 下界，给出保守的 d(ξ,X_obs) 下界；(2) `verify_optimality_gap` 与下界证书 cost* 直接比较；(3) `verify_probabilistic_completeness` 用 RRT* 的采样衰减率反解 n_min，n≥n_min 即失败概率 ≤ δ_plan；(4) `verify_homotopy` 保证不跨拓扑类，避免「看似更短实则穿越不可通行通道」的解。四条件分别对应可执行性、质量、可靠性、拓扑正确性，缺一不可。∎

### 引理 18（DSC 的鲁棒前向不变性）
**陈述**：若 ∀x∈安全集存在 u∈U 使 L_f h+L_g h u+α(h)-‖L_g h‖w ≥ 0，则对任意 ‖d‖≤w，安全集 {h≥0} 前向不变。

**证明**：鲁棒 CBF 条件保证在最坏扰动下仍存在 u 使 ḣ = L_f h+L_g h u+L_g h d ≥ -α(h)。对任意 d 取该 u，由比较引理 h(t) ≥ h(0)e^{-t}（α 为类 K∞ 时更一般地 h 不会在有限时间穿越 0），故 h(t)≥0 保持。ISSf 条件 V̇≤-cV+b 进一步给出误差最终界 b/c。∎

### 引理 19（从「验证」到「合成」的单调退化）
**陈述**：`synthesize_or_verify` 遵循三级退化：合成通过 → `synthesized`；合成失败但上游 SRC-USC 通过 → `fallback_verify`（保守回退计划）；两者皆失败 → `reject`。故对任意单点/组合失效，`Exec_v27 ⊆ Exec_v26 ⊆ ... ⊆ Exec_v18` 恒成立。

**证明**：PDUC.admits 是上游 SRC-USC.admits 与 KFC/PPC/DSC 的合取，任何一项为假即整体拒证。回退分支只保留 `src_usc.admits` 的结论，恰为 Exec_v26 的准入条件，故合成集 ⊆ 验证集 ⊆ 上游集。组合失效取交集，包含关系单调保持。∎

### 定理（Path-Dynamics 统一准入门的安全-可执行-最优-完备性）
**陈述**：对任意多机计划 Π 与参考路径 ξ_Π，`PDUC.admits(Π,ξ_Π) = True` ⟺ Π 同时满足：(1)–(8) 前轮全部证书（物理/云边/少样本/专利/结构/力控/轻量化/语义/重构/协同/成本/记忆/可扩展），(9) **动力学可行性 KFC**（作动/ISS 管/离散缺陷），(10) **路径规划 PPC**（清障/最优间隙/概率完备/同伦），(11) **动力学安全 DSC**（鲁棒前向不变/ISSf）。

**证明**：由 `PDUC.admits` 的合取定义与引理 16–19 直接可得。必要性：任一条件缺失即拒证，对应该维度风险未被缓解。充分性：全条件满足时，引理 16 保证真实轨迹留在管中（可执行），引理 17 保证路径质量与可靠性（可规划），引理 18 保证安全集不外逃（可安全），引理 19 保证退化链单调，构成「规划—动力学—安全」闭环。∎

| R21 | CBF-QP 在作动饱和/不可避免碰撞时不可行 | 高 | 1) 多 CBF 优先级 + 松弛变量；2) 声明「不可避免集」并触发 fail-safe 制动；3) 与 MCC 碰撞证书交叉兜底 | 极端夹缝/突发障碍下只能最小化伤害，无法保证零碰撞 |

## 6. 本轮最大风险（最终确认）

**一句话**：**KFC 的连续时间 ISS 证书与离散执行/建模误差之间存在语义鸿沟——收缩界过保守会让激进机动永不可证（Exec_v27 趋空），过乐观则真实轨迹在 ε_int 与 δ 累积下脱离跟踪管，使 PDUC 在「证书可满足但物理不可跟踪」的间隙里错误放行；PPC 的最优下界与 DSC 的 CBF-QP 可行性在同一处耦合放大该风险，是本轮从「验证」跃迁到「合成」时最难闭合的一环。**
