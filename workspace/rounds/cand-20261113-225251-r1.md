# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；本轮灵感：「持续学习」×「需求洞察」）

> R69 给了闭环一张嘴和一个分诊台：把不确定性拆成 aleatoric / epistemic，能问的去看/问/触，不能问的收紧，并用流似然做「标定不可吸收」的第二意见。但 R69 有两个从未被触碰的隐含假设：**（a）假设空间是封闭且静止的**——它只在「已知的几个动作模态」之间消歧，从不质疑「这几个模态本身是否还成立」；**（b）它只读不写**——交互证据只改当前后验，不进入模型，于是同一个歧义明天还要再问一遍，而世界和人的需求早已漂移。
>
> 这两个假设在长期部署里同时失效。人换目标、换偏好、换耐心；任务从「把杯子递给我」变成「先把桌子收干净」；昨天的 rare case 变成今天的常态。更危险的是，**机器人自己的行为会改变人表达需求的方式**——它越会问，人越顺着它答；它越体贴，人越懒得纠正。此时若把交互证据写成学习信号，学到的可能是机器人自己的倒影，而不是世界的需求。
>
> 本轮两个灵感正好补上这两块：
> - **持续学习**说明：在安全关键系统里，学习不是「多训练一点」，而是一次**写操作**——它把一次证据的偏差放大成未来所有决策的先验。因此必须两时间尺度：快环冻结零写、慢环影子训练、晋升需证书、随时可回滚。
> - **需求洞察**说明：最大的歧义不在动作层，而在**任务层**——用户说出来的、做出来的、真正需要的往往不是同一个东西。需求洞察就是把这个潜变量显式化；但它也正是家长主义与操纵的入口，必须可测试、可审计、可撤回，且永远不能覆盖显式约束。
>
> 核心命题：**在 R69 的交互层之下再垫一层「开放需求假设 × 隔离式持续学习」；把「消解歧义」升级为「维护一个保形、可识别、可撤回的需求集合，并且只把通过无回归门、无内生性检验、无遗忘上界与自主性下限的更新晋升为活动模型」。门关闭时逐指令退化为 R69，R69 再退化为 R68。** 命名 **INSIGHT-RAS**（INcremental Safety-gated Identifiable GrowTH with need-insight for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该学什么、学到的到底是世界还是我自己、以及用户真正想要的和他说的是一回事吗**」。

## 0. 直觉与动机

**灵感 1（持续学习 → 学习是唯一会跨时间传播错误的操作）**
直觉：R68/R69 都把「实时流零学习写操作」写成不变式，原因不只是算力：一次推理错误只污染一帧，一次参数写入污染之后每一帧。R69 能让一次被投毒的回答只影响一次模态选择；一旦把同样的证据拿去做 continual update，单条投毒样本就变成永久偏置。所以本轮不是给 R69 加一个训练循环，而是给「写」加一道**司法程序**：影子模型、证据保全、晋升审判、可回滚版本。持续学习在具身安全里的头号敌人不是灾难性遗忘，而是**安静地学会错的东西**。

**灵感 2（需求洞察 → 任务层的歧义比对动作层的歧义更贵）**
直觉：R69 的模态是「绕左/绕右」「接住/避让」。但一个机器人可以 99% 确信「怎么接住」，却完全接错了东西——用户要的是「把药递给我」，它学成了「把药收进抽屉」。动作层的不确定性是局部可逆的，任务层的不确定性可能不可逆。需求洞察把潜变量从动作簇提升到 n=(目标, 硬约束, 偏好, 元需求)，并区分**说出的需求 ŝ / 行为揭示的需求 r / 潜在需求 l**。三者不一致时，最省事的做法（相信说出的）常常不是最安全的（硬约束被忽略），最聪明的做法（推断潜在的）又最像家长主义。这正是需要形式化护栏的地方。

**灵感 3（耦合 → 学习给需求以时间，需求给学习以准则）**
直觉：没有持续学习，需求洞察只是一次性问卷；没有需求洞察，持续学习只会拟合任何到来的信号，并把过拟合叫「个性化」。耦合起来才成立：**学习的目标是需求，学习的许可证是可测试性**。一个需求假设只有能产生可区分预测、能改变行动、且不与显式约束冲突时，才配被写进模型；否则它只能停留在假设集合里，交由 R69 交互或 R68 保守。

**灵感 4（确认坍缩 → 封闭集合里的 VoI 会越问越自信、越自信越错）**
直觉：R69 的 VoI 是在已知模态上降熵。若真实需求不在集合里，问得越多，后验越尖，误差地板却由「投影距离」决定——**熵趋零而错误不减**。这就是确认坍缩。需求洞察要的恰恰相反：洞察来自打破假设空间的异常，而不是确认当前最优。因此 R70 在 VoI 之外加 **DVoI（证伪价值 + 新假设增益）**，并显式保留一个非参数残差需求分量。

**灵感 5（自反陷阱 → 你学到的是你自己行为的回声）**
直觉：机器人问「您是想让我往左吗？」，人为了省事说「是」。机器人于是学到「用户偏好往左」。它没学到世界的需求，只学到自己的提问方式。更糟的是闭环：越学越问，越问越偏，越偏越确信。R69 的「k 个正交证据源一致」在这里失效，因为所有源共享同一个内生原因（机器人的行为）。所以必须做因果校正（随机微探针 / 工具变量 / 反事实回放），并且把「世界漂移 / 模型故障 / 自诱因变化」做成三分诊断——只有第一种才授权需求学习。

**灵感 6（证书 → 安全学习必须是版本化、可回滚、可审计的）**
直觉：R69 用 J_FLUID 给单次决策发证。R70 需要给**参数变更**发证：晋升前后在安全锚点与回归套件上无退化、遗忘有上界、需求集合有覆盖率、自主性下限未被突破、来源哈希与版本血缘完整。证书不是形式主义——它把「学习」从一次不可观测的漂移，变成一次可被审计、可被否决、可被回滚的变更。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（INSIGHT-RAS 总览）** INSIGHT-RAS = (NIM, CLT, OPN, DVoI, EGT, VGR, PG, DLT, CSG, APF, SCD, RAS-WM§)。四不变式：
(i) **快环零写**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **学习隔离**：所有参数更新只发生在影子模型 θ_shadow，活动模型 θ_active 在快环内只读；任何写入必须经过晋升门（定义 318）；
(iii) **严格包含与权限单调**：门关闭 ⇒ 逐指令等价 R69；R69 失效 ⇒ R68；退避只降低权限，不允许跳级扩权（定义 325）；
(iv) **自主性下限**：任何潜需求不得覆盖用户显式硬约束；推断需求必须可被用户查看、否决、撤回（定义 321）。

**定义 311（开放需求假设空间）** 需求 n=(g,c,p,μ)：g 目标，c 硬约束（不可交易），p 软偏好，μ 元需求（是否愿意被打断、隐私、解释深度）。维护后验 P(n|ℋ_t) 于开放集合 𝒩 = 𝒩_known ∪ 𝒩_residual，其中 𝒩_known 为参数化假设，𝒩_residual 为非参数残差分量（Dirichlet process / 新假设原子），允许「当前集合里没有」成为一等公民。三态证据：说出的 ŝ、行为揭示的 r、系统推断的 l；记其不一致度为 Inc(ŝ,r,l)。

**定义 312（两时间尺度持续学习 CLT）** 快环 F：感知→R69 策略→认证→执行，θ_active 冻结、零写、P99 不变；慢环 S：在影子 θ_shadow 上异步整合交互日志、锚点与回放。τ_fast ≪ τ_slow。回滚 = 丢弃 θ_shadow 或切回历史版本；影子与活动模型共享冻结主干，只允许低秩/适配器级写入（减少污染面与回滚成本）。

**定义 313（需求洞察算子）** 预测偏差 d_t = D(y_t ‖ P(·|n*,o_t))；新奇度 ν_t = 贝叶斯惊讶 / 密度比。洞察判据：当 ν_t 在 ≥ m 个不同上下文持续超阈，且新假设 n_new 在**留出**上下文上降低预测损失、并通过证伪探针时，才允许「开辟新需求假设」；否则只当作噪声/故障，不得强行并入旧需求。形式化地，Insight ⇔ (Δ held-out loss < 0) ∧ (survives disconfirmation) ∧ (consistent with c)。

**定义 314（内生性与自反陷阱）** 因果图 a→y，n→a，n→y（R70 还有表达 e→y）。朴素学习拟合 P(n|y) 混淆了机器人自身行为。定义内生性间隙 EG = D(P(n|do(a),y) ‖ P(n|y))；用随机微探针（低风险决策上的 ε-探索）、工具变量、反事实回放估计。EG > τ_eg ⇒ 禁止把该证据用于需求晋升，只保留为交互证据。

**定义 315（可晋升判据 TAG）** 需求假设 n 可晋升仅当：(a) **可识别**：在 ≥2 个上下文产生可区分预测；(b) **可行动**：存在动作使期望效用差 ≥ δ_act；(c) **守约束**：与显式硬约束 c 无冲突；(d) **抗证伪**：通过一次主动证伪探针；(e) **可撤回**：记录来源与反事实。缺一 ⇒ 留在假设集合，不写入。

**定义 316（证伪价值交互 DVoI）** 在 R69 的 VoI 上增加 DVoI(q) = E[1{best n 被证伪}] + λ_n·I(𝒩_residual; y|q)。选择 q* = argmax_q [VoI + β·DVoI − c]，β 为探索系数。目的：交互不仅降熵，还要**检验假设空间本身**；在高风险场景 β→0（不拿人做实验），在低风险场景 β>0。与 R69 的关系：β=0 且 𝒩_residual=∅ 时退化为 R69 MINT。

**定义 317（版本化门控回放 VGR）** 影子更新 L_CL = L_new + λ_a L_anchor + λ_r L_replay + λ_e L_EWC。锚点集 A 固定包含罕见但安全关键场景，永不淘汰；回放缓冲区 B 有界、按重要性采样、带来源与毒性过滤。禁止只用新数据更新（抵抗漂移攻击与遗忘）。

**定义 318（晋升门 PG）** θ_shadow 晋升为 θ_active 当且仅当：
(i) 在 A ∪ 回归套件上 ΔSafety ≤ 0（置信下界）；
(ii) ECE ≤ τ_ece（继承 R69 MCG）；
(iii) 对历史已认证行为的遗忘 ≤ ε_forget；
(iv) 无内生性旗标（定义 314）、无 SCD 告警（定义 322）；
(v) 需求集合覆盖率与来源血缘证书完整（定义 324）。
否则丢弃并回滚。晋升只发生在静止窗口，不允许机动中换模型。

**定义 319（漂移—故障—自诱因三分诊断 DLT）** 观测到性能变化时判源：
- **世界漂移**：FMA 正常、残差正常、干预后行为随之改变 ⇒ 授权需求学习；
- **模型/传感器故障**：FMA 或 r_res 异常（R68/R69 通道）⇒ 冻结学习、走 R68/R69 保守；
- **自诱因**：动作条件响应分布偏移、随机探针下效应消失 ⇒ 禁止学习、审计表达/交互策略。
三者混淆是长期部署最常见的错误归因。

**定义 320（保形需求集合安全门 CSG）** 在可交换校准上下文上构造 N_α 使 P(n* ∈ N_α) ≥ 1−α。策略必须对**所有** n ∈ N_α 满足硬约束，或显式交互/停止；若不存在对 N_α 一致安全的动作 ⇒ 强制 R69 交互，交互失败 ⇒ R68。这把「点估计上安全」升级为「需求集合上安全」。

**定义 321（自主性下限与操纵指数 APF）** 潜需求 l 只能影响**可选便利**，不能修改 c；用户可查看、否决、撤回。定义操纵指数 MI = D(b_robot ‖ b_user)·1{user 信息劣势}，其中 b 为被强加的需求信念。MI > τ_mi ⇒ 阻止晋升并审计。反家长主义判据：若一个推断会导致系统覆盖用户的显式指令，则除非触发紧急安全，否则一律视为违规。

**定义 322（自确认检测器 SCD）** 监控「后验锐化」与「留出误差」的差：若 H(𝒩) 快速下降而 held-out 误差不降或上升，或交互只选择当前最优假设的确认证据，则判为确认坍缩。处置：升高 β、强制证伪探针、必要时冻结需求学习。

**定义 323（部署学习威胁模型 ℰ_INSIGHT）** 持久投毒（一条坏示范污染未来）、渐进需求漂移攻击、谄媚利用（人说机器人想听的）、回放投毒、锚点侵蚀、回滚规避。ℰ_INSIGHT = ℰ_FLUID × ℰ_persist × ℰ_endog，并入 AIC。

**定义 324（证书 J_INSIGHT）** J_INSIGHT = (J_FLUID, need_set_coverage, forgetting_bound, endogeneity_gap, promotion_hash, version_lineage, autonomy_audit, scd_stat, insight_ver)。Valid ⇔ 各分量达标且晋升链可验证。

**定义 325（三级退避与权限单调）** L0 正常学习；L1 冻结学习、活动模型回退到上一认证版本，其余行为 = R69；L2 禁用交互，= R68；L3 安全停。状态转移只允许沿「权限不增」方向升级（如 L0→L1），恢复需重新过 PG。任何退避都不允许绕过认证直接执行未经认证的新模型。

**定义 326（异步预算与晋升时机）** 快环延迟不变（R69：K=1 < 2.6ms，K=4 < 3.4ms）。慢环在维护窗口/静止期运行；晋升是原子切换（双缓冲 + 版本指针），带健康检查与一键回滚。需求集合与 SCD 监控为 O(|𝒩|)，不进快环热路径。

# IP-267 DVoI：证伪 + 新假设增益（扩展 R69 MINT）
def choose_probe(need_set, best_n, budget, risk_level):
    beta = 0.0 if risk_level > RISK_HI else BETA_DEFAULT   # 高风险不拿人做实验
    best = None
    for q in probe_candidates(need_set):
        if not budget.allow(q) or not c_ras_wm.certify_info(q, o): continue
        voi  = entropy(need_set) - expected_entropy(need_set, q)
        dvoi = expected_falsification(best_n, q) + lam_n * novelty_gain(q)
        score = voi + beta * dvoi - cost(q)
        if best is None or score > best.score: best = (q, score)
    return best if best and best.score > 0 else None

# IP-270 PG：晋升门（无回归 + 遗忘界 + 内生性 + 校准 + 血缘）
def promotion_gate(theta_shadow, theta_active):
    if safety_delta(theta_shadow, A, regression) > 0:      return False
    if forgetting(theta_shadow, certified_history) > EPS_FORGET: return False
    if ece(theta_shadow) > TAU_ECE:                        return False
    if eg_flag(theta_shadow) or scd_alarm():               return False
    return certificate_complete(theta_shadow)

## 3. 推导

**引理 19（封闭世界 VoI 的确认坍缩）** 设真实需求 n*，封闭假设集 𝒩_c，投影 n† = argmin_{n∈𝒩_c} d(n,n*)，投影距离 ε_c > 0。R69 的熵减交互使 H(P(n|ℋ)) → 0，但贝叶斯错误率下界趋近于 P(n† ≠ n*) =: e_c > 0。即存在交互步数 T 使熵 < δ 而错误率仍 ≥ e_c/2。系：**没有残差假设与证伪探针，R69 的 VoI 在开放世界会「越问越自信地错」**；A99（封闭且良定）是 R69 有效性的隐含前提，R70 显式放宽它。

**引理 20（内生需求学习的偏差下界）** 设 y = f(n,a)+ξ，a ~ π(P(n|ℋ))，且 Cov(a,y) = χ ≠ 0（机器人行为影响人的表达）。则朴素极大似然在 n 上的偏差满足 ‖bias‖ ≥ c·χ·Var(a)/Var(y) − O(噪声)，且当策略是「越确信越问」的正反馈时 χ 随轮次增大。故**未校正的持续学习不是学习，而是自我强化**；EGT 的随机探针/IV 通过切断 a→y 路径把偏差降到 O(1/√N_probe)。

**引理 21（保形需求集合的鲁棒安全）** 若校准上下文与部署可交换、N_α 覆盖率 ≥ 1−α，且策略对所有 n ∈ N_α 满足硬约束，则单步约束违反概率 ≤ α + ε_est。若 N_α 内无一致安全动作，强制交互/停使违反概率不增。这把 R69「对最佳模态安全」升级为「对需求集合安全」。

**引理 22（自主性下限的可判定性）** 若潜需求更新导致某显式约束 c 被覆盖，则操纵指数 MI > 0 且该更新被 APF 阻断；因此系统可判定的违规集合与「家长主义覆盖」集合重合。系：自主性不是软约束，而是晋升门的硬否决项。

**定理 18（INSIGHT 严格包含 R69 与 R68）** 当 PG 关闭 / SCD 告警 / EG 超阈 / 𝒩_residual=∅ 且 β=0 时，INSIGHT-RAS 逐指令等价 R69；当 R69 的 VoI ≤ c、ECE 越界或 slow_fault 时逐指令等价 R68。门打开时，只有满足引理 21–22 与无回归条件的更新才生效，故每步期望风险不增；归纳得长期风险 ≤ R69 ≤ R68。安全侧单调，效率侧获得认证后的适应性增益。

**定理 19（晋升序列的单调安全与遗忘界）** 若每次晋升以概率 ≥ 1−δ 满足 ΔSafety ≤ 0 且 forgetting ≤ ε_forget，则 T 次晋升后以概率 ≥ 1−Tδ 活动模型的风险不升、对历史认证行为的退化 ≤ ε_forget。证明：并集界 + 双缓冲原子切换 + 回滚完备性；任何未过门的影子更新不改变活动模型，故不进入风险累积。

## 6. 本轮最大风险

5. **学习偷走实时预算** → 快环零写 + 慢环离关键路径 + 静止窗口原子晋升（定义 312、326）。

## 4. 推导

**引理 19（封闭世界 VoI 的确认坍缩）** 真实需求 n* 不在封闭集 𝒩_c 时，投影距离 ε_c>0；R69 的熵减交互使 `H→0`，但错误率地板为 `P(n†≠n*)=e_c>0`。即存在 T 使熵<δ 而错误率≥e_c/2。系：缺残差假设与证伪探针时，开放世界里的 VoI 会「越问越自信地错」；A99（封闭良定）是 R69 的隐含前提。

**引理 20（内生需求学习偏差下界）** `y=f(n,a)+ξ, a~π(P(n|ℋ)), Cov(a,y)=χ≠0`，则 `‖bias‖ ≥ c·χ·Var(a)/Var(y) − O(噪声)`；正反馈策略使 χ 随轮次增大。故未校正的持续学习是自我强化；EGT 的探针/IV 把偏差降到 `O(1/√N_probe)`。

**引理 21（保形需求集合鲁棒安全）** 校准可交换且 `P(n*∈N_α)≥1−α`，策略对 `∀n∈N_α` 守硬约束 ⇒ 单步违反概率 `≤α+ε_est`；集合内无一致安全动作时强制交互/停，违反概率不增。

**引理 22（自主性下限可判定）** 潜需求更新若覆盖显式约束 c，则 `MI>0` 且被 APF 阻断；故系统可判定的违规集合与「家长主义覆盖」集合重合。

**定理 18（严格包含 R69 与 R68）** 当 PG 关闭 / SCD 告警 / EG 超阈 / `𝒩_residual=∅ ∧ β=0` 时逐指令等价 R69；当 R69 的 `VoI≤c`、ECE 越界或 slow_fault 时逐指令等价 R68。门开时仅接受满足引理 21–22 与无回归的更新，故每步期望风险不增，归纳得长期风险 `≤R69≤R68`。

**定理 19（晋升序列单调安全与遗忘界）** 每次晋升以概率 `≥1−δ` 满足 `ΔSafety≤0` 且 `forgetting≤ε_forget`，则 T 次后以概率 `≥1−Tδ` 风险不升、历史行为退化 `≤ε_forget`（并集界 + 原子切换 + 回滚完备）。

## 7. 本轮最大风险

**一句话**：全部适应性收益都押在「晋升门的安全锚点/回归套件与保形校准能代表真实部署分布、且 EG/SCD 能识别自确认」上——**若某个罕见但安全关键的上下文不在锚点里，或漂移缓慢而对抗，门会自信地晋升一个「局部更好、全局更差」的模型；由于更新持久化，一次错误晋升会被之后所有轮次继承并复利放大**，最终系统不是不会学，而是学会了再也回不去。

**次级风险与缓解**：灾难性遗忘吃掉罕见安全行为（固定锚点 + 回放 + EWC + 遗忘上界）；部署期投毒（来源血缘 + 毒性过滤 + 可回滚版本）；确认坍缩/自我强化（残差需求 + DVoI 证伪 + SCD 冻结）；家长主义与操纵（自主性下限 + 操纵指数 + 用户否决）；学习偷走实时预算（快环零写 + 慢环离关键路径 + 静止窗口原子晋升）。
