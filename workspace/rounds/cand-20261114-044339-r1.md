# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「轮足机器人」×「意图理解」）

> R69 教会系统「不确定就去问」。但它从头到尾默认了两件在真实身体上不成立的事：**（a）信息是来得及的**——VoI 只比较熵减与查询成本，从不问「等我问完，还能不能改主意」；**（b）意图是任务空间里的一个连续模态**——它从不区分「我想做什么」与「人想让我做什么」，也从不问「我现在的身体还允许我做哪个」。
>
> 轮足机器人把这两个默认同时击穿。它的身体是**分段承诺**的：轮行（快、省、动量足、怕离散地形）与腿行（慢、贵、能上坎、接触富）之间是混合动力学切换，一旦轮子加速或抬腿离地，重置映射就改写了可达集；切换前是选项，切换后是命运。而意图理解给出真正的歧义源：人想要的（跟随/停留/搬运/护送/快慢）只能从稀疏、含噪、**且与地形和机器人构型相互耦合**的线索里推断——「快点」暗含用轮，「从碎石那边过来」暗含用腿。意图 m 与地形 τ 相关，意图又与「哪种身体模式能兑现它」相关。
>
> 于是本轮的核心命题不是再叠一层滤波器，而是把**意图推断与身体承诺合并成同一个决策**：**在不理解意图时，先问「我是否即将失去根据理解行动的能力」；在还能反悔之前消解意图；反悔窗口关闭后，就按「意图鲁棒安全集」保守执行；而推断出的意图永远只是证据，不是命令。** 命名 **HILT-RAS**（Hybrid-locomotion Intent-Latent Transition for Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**他到底想要什么，而我的身体还能否反悔**」——意图不只是要被读懂，更要在身体反悔之前读懂。

## 0. 直觉与动机

**灵感 1（轮足机器人 → 身体是分段承诺的，信息有截止日）**
直觉：把轮足机器人想成一个有「两种动词」的执行者：**滚**（高效、快速，但高动量、难急停、离散地形无能）与**踏**（灵巧、能上坎，但慢、耗能、接触不确定）。模式切换不是换档，而是**承诺**：轮子一旦高速旋转，反向或转向的重置代价骤增；腿一旦抬起，支撑多边形与可达落足点被瞬间改写。于是同一个「没读懂人想要什么」的代价，在不同时刻完全不同：在岔口犹豫几乎免费，在冲出去之后才发现方向错了则可能致命。**R69 用不确定性触发查询，HILT 用「承诺时钟」触发查询**——不是「我现在有多糊涂」，而是「我还能糊涂多久」。

**灵感 2（意图理解 → 意图是带粘性的隐变量，且与地形/模式耦合）**
直觉：人不会每 100ms 换一次目标，所以意图先验天然是**粘性**的（低跳变率、滞后、惯性）；但证据永远是稀疏、含噪、片面的（一个眼神、半句话、身体朝向、站得太近还是太远、带路的轨迹）。更关键的是：**意图只有相对身体才有意义**。「快点」在平整地面意味着轮行，「从那边绕」在碎石上意味着腿行。因此不能像 R69 那样只维护一个意图后验，再和 R68 的模式不确定性拼接——那等于假设 `p(m, τ) = p(m)p(τ)`，而这个独立假设恰好在「意图决定偏好模式」时错得最厉害。正确的对象是**联合后验 `b(m, τ, σ)`**，其中 σ 是当前/候选模式。

**灵感 3（R69 的 VoI 是「无限截止日」的退化情形）**
直觉：R69 选择信息动作时只算 `熵减 − 查询成本`。在轮足机器人上，信息动作本身就是运动：转头可能撞限位、探身可能进奇异区、靠近会改变人的行为（观察者效应）、而所有这些都消耗动量与时间，并可能**关闭**某些模式选项。于是价值函数必须改写为：**信息增益 × 能在承诺截止前兑现的概率 − 查询成本 − 选项价值损失（option-value loss）**。这带来一个反直觉推论：**在不接近承诺边界时，带着不确定性继续走往往是最优的**；不确定性本身不贵，不可逆的承诺才贵。R69 的「不确定就问」只是在截止日无穷远、反悔成本为零时的特例。

**灵感 4（意图不能被无条件服从：意图是证据，不是命令）**
直觉：R69 把「问到的答案」当作贝叶斯证据，但它没处理一个更尖锐的问题——**如果人想要的本身不安全，或人根本在骗你？** 轮足机器人有速度快、质量大、动量足的物理攻击面。若系统把高置信度推断直接当命令，就会出现「自信的错误服从」：把一个被投毒的「快点冲过去」当作已验证意图执行。因此 HILT 必须有**意图权威门**：高把握 + 低代价才静默跟随；高代价必须显式确认；确认不了就退到已认证的安全暂停。这是「理解意图」与「服从意图」之间必须切开的一刀。

**灵感 5（新层必须是旧层的边界，且要正面处理混合系统的非连续）**
直觉：前几轮反复确立的姿态——新层不是并列黑箱，而是旧层的严格泛化。HILT 在（意图点质量已知、模式固定、无混合切换、反悔成本为零、截止日无穷）时应逐指令退化为 FLUID；再叠加（无信息动作/信息无利可图）退化为 CALM。这样安全侧永不弱于 R68/R69。但必须诚实：混合系统在模式切换处**控制本身是跳变的**，不能奢谈「控制连续」。HILT 承诺的不是连续性，而是**安全裕度不下降**：切换后的状态必须同时落在守卫集与意图鲁棒安全集内，否则先投影到 safe-pause。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（HILT-RAS 总览）** HILT-RAS = (HIM, MIF, IUD, ILC, DVI, QbG, IRS, IAG, IDD, RAS-WM†)。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **承诺纪律**：任何不可逆模式切换前，必须检查承诺时钟与反悔代价；未在截止前消解的意图，不得用于选择不可逆模式；
(iii) **意图鲁棒安全**：意图未定案时，控制必须对「可信意图集」全体成立；交集为空则退到已认证 safe-pause；
(iv) **意图权威**：推断意图只是证据而非命令；高代价跟随需显式确认，确认失败默认安全侧。

**定义 311（轮足混合模型）** 状态 `x = (q, q̇, p, b)`（构型、速度、动量、轮/足接触状态）；模式 `σ ∈ Σ = {W, L, H}`（轮行、腿行、混合）。模式内 `ẋ = f_σ(x, u)`，模式间由守卫集 `G_{σ→σ'} = {x : g_{σσ'}(x) ≥ 0}` 与重置映射 `R_{σσ'}` 连接。定义**承诺代价** `κ(σ→σ') ≥ 0` 与**反悔时间** `T_rev(σ→σ')`：进入 σ' 后回到 σ 所需的最小时间/能量；`κ` 在轮子高速旋转或足端离地后单调上升。

**定义 312（意图与地形隐变量）** 联合隐变量 `ℓ = (m, τ) ∈ M × T`：意图 m（如 follow / stay / fetch / escort / speed-preference），地形 τ（flat / rough / stair / unknown）。意图动力学为粘性马尔可夫跳变：`P(m_{t+1} ≠ m_t) = λ_int·Δt`，`λ_int` 小；地形在短时窗内同样近静态。**关键：m 与 τ 不独立**，允许 `p(m, τ)` 有互信息。

**定义 313（具身耦合观测）** 人类线索 `y_t`（注视、指向、语言、人际距离、带路轨迹）与机器人自身本体感受；观测似然 `p(y_t | ℓ, σ_{1:t}, a_{1:t})` **依模式而定**：轮行时视野低、速度快、难读细手势；腿行时慢、可停、可转身细看。即**身体决定了你能看见什么**（embodiment-coupled observability）。

**定义 314（模式条件意图滤波 MIF）** 维护联合后验 `b_t(ℓ, σ) ∝ p(y_t | ℓ, σ, a_{1:t}) Σ_{ℓ',σ'} T_σ(σ|σ') T_int(ℓ|ℓ') b_{t-1}(ℓ', σ')`。当模式切换时对 σ 施加重置核（非恒等）。输出边缘 `b(m)`、`b(τ)`、`b(σ)` 与互信息 `I(m; τ | y)`、`I(m; σ | y)`。

**定义 315（意图不确定性四分）** 把 R69 的 (U_ale, U_epi) 细化为四个语义不同的量：
- `U_intra = E_{ℓ}[H(y | ℓ)]`：线索噪声（aleatoric，问不出来）；
- `U_inter = H(m | y)`：意图身份歧义（epistemic，可问）；
- `U_mode = H(σ | y)`：身体模式/地形可行性歧义（epistemic，可探测）；
- `U_couple = I(m; τ | y) + I(m; σ | y)`：**耦合项**——意图与地形/模式的相互信息。`U_couple` 大意味着「按模式分头估计再加权」会系统性低估风险。四项**不做标量相加**，分别进入不同通道（定义 320、326）。

**定义 316（不可逆性账本 ILC 与承诺时钟）** 对每个候选切换 `σ→σ'`，账本记录 `(κ, T_rev, 以及剩余可逆裕度 ρ_σ)`。承诺时钟 `τ_c(σ→σ')` 为「进入不可逆区」的预计时刻，由当前动量、地形、目标速度估计；`ρ_σ = τ_c / T_rev` 为归一化可逆性。`ρ_σ ≥ 1` 表示还能完整反悔。

**定义 317（截止日驱动的信息价值 I-VoI）** 对候选信息动作 g（完成时刻 `t_g`、物理/社交成本 `c(g)`、诱导的选项价值损失 `ΔR(g)`）：
`I-VoI(g) = P(t_g ≤ τ_c)·[H(m|y) − E_{y'~p(·|g)}H(m|y,y')] − c(g) − ΔR(g)`。
选 `g* = argmax_g I-VoI(g)`，仅当 `I-VoI(g*) > 0` 且 g 通过 C-RAS-WM 认证（定义 322）。**R69 的 VoI 是 `τ_c → ∞、ΔR ≡ 0` 的边界情形。**

**定义 318（步态即查询 QbG）** 物理信息动作库 `G = {pause_and_orient, step_in_place, slow_roll, approach_to_social_distance, retreat_to_safe_distance, point_and_wait}`。每个 `g` 是一次**受控实验**：以最小不可逆代价最大化对人类意图的判别力。与 R69 的注视/探针/问句统一在同一增广动作空间，但此处强调「用整个身体去问」。

**定义 319（意图鲁棒安全集 IRS）** 给定可信水平 δ，`M_δ = {m : b(m) ≥ 1−δ}`；每个意图对应安全集 `C_σ(m)`（由意图条件 CBF 定义）。**鲁棒安全集** `C^{robust}_σ(δ) = ⋂_{m ∈ M_δ} C_σ(m)`；空集时使用**安全暂停模式** `σ_pause`（已认证的减速/站立/保持支撑多边形），其存在性由 RAS-WM† 保证。

**定义 320（意图条件屏障与模式守卫）** 每个 `(σ, m)` 定义离散时间 CBF `h_{σ,m}(x) ≥ 0`；模式守卫带滞回：`σ→σ'` 仅当 `h_{σ',m}(x) ≥ 0` 对 `m ∈ M_δ` 全体成立且 `ρ_σ` 足够，才允许；否则延迟或拒绝切换。控制投影到 `C^{robust}_σ(δ)` 内。

**定义 321（意图权威门 IAG）** 以「把握 × 代价」二维决策：`conf = 1 − H(m|y)/log|M|`，`stakes = S(σ, x, m̂)`（跟随错误的物理/社会后果）。规则：`conf ≥ c_hi ∧ stakes ≤ s_lo` → 静默跟随；`stakes > s_lo` → 显式确认（语言/手势，需第二条正交证据源）；确认失败或 `conf` 不足 → 安全暂停/保守跟随。**任何情况下，安全集先于意图，意图先于效率。**

**定义 322（信息动作/模式切换的 C-RAS-WM 认证）** 复用 R68/R69 前缀认证；新增：g 的模式切换需过守卫与 IRS；确认请求本身是信息动作，也受交互预算（R69 定义 298）约束，不得以「确认」为名反复打扰。

**定义 323（意图漂移检测 IDD）** 双通道：`r_intent =` 人类行为相对意图模型的后验预测残差（「他做的事不像我猜的目标」）；`r_mode =` 本体/地形的模式预测残差。用联合模式 `(r_intent↑, r_mode↑/↓)` 区分「意图真变了」「地形判断错了」「模型错了」：`r_intent↑ ∧ r_mode≈0` → 意图漂移；`r_intent≈0 ∧ r_mode↑` → 地形/模式漂移；两者同上 → 联合换挡或模型失配，触发主动消歧。

**定义 324（意图投毒与冒充威胁 ℰ_HILT）** 新增：冒充指挥意图（伪造手势/语音/带路）、诱导性线索（故意引向危险模式）、社交工程式确认疲劳、以及「人类意图本身不安全」。`ℰ_HILT = ℰ_FLUID × ℰ_poison × ℰ_spoof × ℰ_intent_unsafe`。

**定义 325（模式-意图审计 VQAuditor-M 与证书 J_HILT）** 审计新增：模式切换是否有承诺依据、意图后验是否校准、确认是否被单源采纳、是否在截止后才发现意图错误。`J_HILT = (J_FLUID, intent_ece, mode_ece, commitment_violations, consent_log_hash, robust_set_volume, iv_voi_ratio, hilt_ver)`；Valid ⇔ `Valid(J_FLUID) ∧ ECE_intent ≤ τ ∧ ECE_mode ≤ τ ∧ 承诺违规=0 ∧ 权威门满足`。

**定义 326（两级退避 + 承诺红利）** 若意图在截止前消解且鲁棒集非空：`λ = λ_floor(U_intra + U_couple_resolved)`，并获得**承诺红利**（允许比 R69 更晚收紧，因为「该问的已问、该看的已看」）；若未消解 / 超时 / 确认失败 / ECE 越界 / 被冒充：`λ = λ_floor(U_intra + U_inter + U_mode + U_couple)`。⇒ R69/R68 是「永不承诺、永不混合」边界。

**定义 327（惰性推断与自适应联合）** 远离承诺边界（`ρ_σ ≫ 1`）时只跑廉价边缘滤波与 mode_head，不做全联合精确推断；仅当 `U_inter` 高、`U_couple` 高或接近截止时升至联合后验与完整 VoI 枚举，保证 P99 实时预算。

## 2. 关键算法骨架

```python
# IP-264 HILT 主闭环（在 R69 之外加：意图-模式联合滤波 + 承诺时钟 + 意图鲁棒安全 + 权威门）
def HILT_round(M, obs, human_cues):
    z = M.mtm.trunk(obs)                          # 复用 R68/R69 条件编码
    # 1) 联合后验：意图 m × 地形 τ × 当前模式 σ（R69 只有标量 U，无意图/模式）
    b = M.mif.update(z, human_cues, M.last_mode, M.last_action, M.last_b)
    U_intra, U_inter, U_mode, U_couple = M.iud.decompose(b)
    # 2) 不可逆性账本与承诺时钟：离「不能再反悔」还有多久
    clocks = M.ilc.commitment_clocks(M.last_mode, M.last_action, obs)
    # 3) 惰性/自适应：远离截止只跑边缘；临近或耦合高才升联合
    K = M.adaptive_K(U_inter, U_couple, clocks)
    xi = M.fmp.sample(obs, K)                     # R69 流策略，ξ=(a,g)
    modes = M.fmp.split_by_mode(xi)               # 按 W/L/H 切分提议
    # 4) 意图鲁棒安全集：对所有可信意图取交；空则退到已认证安全暂停
    S = M.irs.credible_intersection(b, delta=M.delta)
    if S.is_empty():
        return M.irs.safe_pause(obs)              # 减速/站立，保证支撑多边形
    # 5) 截止日驱动信息动作：只有来得及兑现的信息才值钱
    g = M.dvi.choose(xi, b, clocks, budget=M.budget)
    if g is not None:
        y = M.qbg.execute(g)                      # 看/问/靠近/后退/踏步
        b = M.mif.update(z, y, M.last_mode, M.last_action, b)
        S = M.irs.credible_intersection(b, delta=M.delta)
    # 6) 意图权威门：跟随 / 确认 / 安全暂停（意图是证据不是命令）
    verdict = M.iag.gate(b, stakes=M.stakes(M.last_mode, obs))
    if verdict == "confirm":
        y2 = M.qbg.execute(M.iag.confirmation_probe(b))
        b  = M.mif.update(z, y2, M.last_mode, M.last_action, b)
        verdict = M.iag.recheck(b)
    if verdict == "pause":
        return M.irs.safe_pause(obs)
    # 7) 模式仲裁：在鲁棒安全集内选期望代价最小、可认证、带滞回的模式
    sigma, a = M.arbitrate(xi, b, S, M.last_mode)     # 承诺账本决定是否允许切换
    # 8) 认证 + 执行（R68/R69 的 C-RAS-WM 不放松）
    k   = M.c_ras_wm.certified_prefix(a, sigma, M.wm_preds)
    lam = M.risk_scale(b, S, verdict)                 # 见定义 326
    tau = M.pi_sigma.prefix_dispatch(a[:k]) * lam
    # 9) 审计 + 证书（模式/意图决策可追溯）
    M.vqa_m.submit_async(sigma, b, g, clocks, verdict)
    return sigma, k, tau, b, (U_intra, U_inter, U_mode, U_couple)

# IP-269 截止日驱动的信息价值
def choose_I_VoI(xi, b, clocks, budget):
    best = None
    for g in gait_alphabet(xi):
        if not budget.allow(g):                        continue
        if not c_ras_wm.certify_info(g, b):            continue
        p_on_time = prob_finish_before(g, clocks.tau_c)
        gain      = H(b.m) - expected_entropy_after(b, g)
        option_loss = g.expected_reversal_increase()   # 关闭未来模式的代价
        score = p_on_time * gain - cost(g) - option_loss
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 来不及/不划算 → 不问

# IP-271 意图鲁棒安全
def credible_intersection(b, delta):
    md = [m for m in b.m_domain if b.marginal_m(m) >= 1.0 - delta]
    return Intersection([C_sigma[m] for m in md])      # 空则 safe_pause

# IP-273 意图漂移双通道
def intent_drift(res_intent, res_mode, b):
    if res_intent > TAU_I and res_mode < TAU_M: return "intent_change"
    if res_intent < TAU_I and res_mode > TAU_M: return "terrain_change"
    if res_intent > TAU_I and res_mode > TAU_M: return "joint_or_model_shift"
    return "none"
```

## 3. 推导

**引理 19（截止日主导）** 设候选信息动作 g 的完成时刻为 `t_g`，承诺截止为 `τ_c`，消歧带来的期望代价下降为 `ΔC`。则 g 优于「立即按当前信念承诺」当且仅当 `P(t_g ≤ τ_c)·ΔC ≥ c(g) + ΔR(g)`。`I-VoI` 对 `ΔR` 与 `P(t_g>τ_c)` 单调不增；当 `τ_c→∞, ΔR≡0` 时退化为 R69 的 VoI。系：存在最优**审议窗口**——查询价值集中在承诺边界附近，远离边界时「先走着、带着不确定性」占优。这解释了为何 HILT 用「承诺时钟」而非「不确定性」触发查询。

**引理 20（耦合惩罚）** 若把意图与地形/模式当独立估计（即用 `E_m E_τ[cost]` 近似 `E_{m,τ}[cost]`），则风险估计的偏差满足 `|E[cost] − E_m E_τ[cost]| ≤ L·I(m; τ | y)`，其中 L 为代价对隐变量的 Lipschitz 常数。故 `U_couple` 大时必须用联合后验；仅当 `I(m;τ|y)≈0`（地形线索与意图条件独立）时，R68×R69 的拼接才安全。系：**「模式不确定 + 意图歧义」不是两个可加的 U，而是一个不可分解的联合风险**。

**引理 21（确认的证据价值上界）** 若冒充/投毒使单次确认的错误接受率为 `δ_s`，且人类可能在确认疲劳下敷衍应答（有效欺骗率 `δ_f ≥ δ_s`），则「每次都问」的边际收益递减、成本线性上升；存在最优确认频率 `q*`，使期望损失 `q·c_confirm + (1−q)·δ_effective·S` 最小。系：意图权威门必须把「确认」当有限预算的信息动作（定义 322），不能无限追问。

**定理 18（意图鲁棒安全的 PAC 保证）** 设可信集 `M_δ` 满足 `P(m* ∈ M_δ) ≥ 1−δ`（后验校准正确时成立），控制投影到 `C^{robust}_σ(δ)` 且认证风险 ≤ `ε_int`。则对任意时刻，真实意图 `m*` 的安全集被违反的概率 ≤ `δ + ε_int + ε_est`（`ε_est` 为后验估计误差）。且 `C^{robust}_σ(δ)` 随 `δ↓` 单调扩张，当 `b → δ_{m*}` 时收敛到 `C_σ(m*)`。要点：**先安全后理解**——在意图未定时对全体可信意图保守，随着证据累积自动放开，安全性与性能无需二选一，只是分时。

**定理 19（HILT 严格包含 FLUID 与 CALM）** 在（意图后验为点质量、模式固定 `Σ={σ}`、`τ_c=∞`、`κ=ΔR=0`、无混合重置）下，HILT 的闭环决策逐指令等于 FLUID；再令信息动作库为空或其 `I-VoI ≤ 0`，则逐指令等于 CALM。故 `R68 ≺ R69 ≺ R70` 为严格嵌套：安全侧不做任何让步，效率侧获得承诺红利与更晚的收紧。

**定理 20（承诺安全与裕度不降）** 采用滞回守卫（定义 320）、意图鲁棒 CBF 与 safe-pause 回退。则任何被允许的模式切换，其重置后状态满足 `h_{σ',m}(x⁺) ≥ 0` 对 `m ∈ M_δ` 全体成立；若不存在这样的 `σ'`，系统停留在 `σ_pause`。因此沿任意轨迹安全裕度不下降，且不发生「进入不可逆模式后才发现意图错误」的切换。注：混合系统在切换处**不保证控制连续**，只保证切换前已验证、切换后仍在鲁棒安全集内——这是比「控制连续」更诚实的承诺。

**定理 21（惰性推断的实时性）** 在 `ρ_σ ≥ ρ_hi` 且 `U_couple ≤ τ_couple` 的常规区间，仅跑边缘滤波与 mode_head 的决策与全联合推断的差异 ≤ `ε_lazy`（由 KL 上界控制）；仅当接近截止或耦合超阈才升联合，故 P99 时延满足实时预算（第 4 节）。

## 6. 本轮最大风险

**一句话**：HILT 的全部安全性最终押在「意图后验是校准的、可信集大小恰当」这一前提上，而**意图在部署中根本没有 oracle**——传感器噪声可以拿真值标定，意图却不能，一旦模型过度自信，鲁棒安全集会坍缩成一个错误意图（不安全服从），一旦过度保守，交集又会永久为空（永远停在 safe-pause）；更危险的是，主动确认与意图权威门本身会引入「确认疲劳」与冒充攻击面，**把 R69 的『诚实的不知道』升级成『被流程盖章的错误服从』——读错意图并不可怕，可怕的是系统确信自己读对了。**

**次级风险与缓解**：
1. **混合系统非连续**（切换处控制跳变）→ 不承诺控制连续，改为守卫滞回 + 切换后状态校验 + safe-pause 回退（定理 20）；
2. **意图-地形耦合被误当独立** → 强制联合后验 + `U_couple` 门控 + 引理 20 的耦合惩罚（定义 315、327）；
3. **确认疲劳与冒充** → 确认预算硬约束 + 双正交证据源 + ℰ_spoof 对抗训练（定义 322–324、引理 21）；
4. **实时预算被联合推断击穿** → 惰性边缘路径 + 仅临近截止才升联合 + 自适应 K（定义 327、定理 21）；
5. **未见意图/长尾地形** → `M_δ` 加入未知意图占位 + unknown 地形强制降级 + E310/E312 长时程验证；未知不能被静默当成某一已知意图。

## 3. 关键算法伪代码

```python
# IP-264 HILT 主闭环（在 R69 之外加：联合意图滤波 + 承诺时钟 + 鲁棒安全 + 权威门）
def HILT_round(M, obs, human_cues):
    z = M.mtm.trunk(obs)
    b = M.mif.update(z, human_cues, M.last_mode, M.last_action, M.last_b)
    U_intra, U_inter, U_mode, U_couple = M.iud.decompose(b)
    clocks = M.ilc.commitment_clocks(M.last_mode, M.last_action, obs)

    K  = M.adaptive_K(U_inter, U_couple, clocks)          # 惰性：远截止跑边缘
    xi = M.fmp.sample(obs, K)                             # R69 流策略，ξ=(a,g)

    S = M.irs.credible_intersection(b, delta=M.delta)     # 意图鲁棒安全集
    if S.is_empty():
        return M.irs.safe_pause(obs)                      # 已认证减速/站立

    g = M.dvi.choose(xi, b, clocks, budget=M.budget)      # 截止日驱动 I-VoI
    if g is not None:
        y = M.qbg.execute(g)                              # 用身体去问
        b = M.mif.update(z, y, M.last_mode, M.last_action, b)
        S = M.irs.credible_intersection(b, delta=M.delta)

    verdict = M.iag.gate(b, stakes=M.stakes(M.last_mode, obs))
    if verdict == "confirm":
        b = M.mif.update(z, M.qbg.execute(M.iag.confirmation_probe(b)),
                         M.last_mode, M.last_action, b)
        verdict = M.iag.recheck(b)
    if verdict == "pause":
        return M.irs.safe_pause(obs)

    sigma, a = M.arbitrate(xi, b, S, M.last_mode)         # 含滞回与承诺账本
    k   = M.c_ras_wm.certified_prefix(a, sigma, M.wm_preds)
    lam = M.risk_scale(b, S, verdict)                     # 见定义 326
    tau = M.pi_sigma.prefix_dispatch(a[:k]) * lam
    M.vqa_m.submit_async(sigma, b, g, clocks, verdict)
    return sigma, k, tau, b, (U_intra, U_inter, U_mode, U_couple)

# IP-269 截止日驱动的信息价值
def choose_I_VoI(xi, b, clocks, budget):
    best = None
    for g in gait_alphabet(xi):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, b): continue
        score = (prob_finish_before(g, clocks.tau_c) * (H(b.m) - expected_entropy_after(b, g))
                 - cost(g) - g.expected_reversal_increase())
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 来不及/不划算 → 不问

# IP-271 意图鲁棒安全
def credible_intersection(b, delta):
    md = [m for m in b.m_domain if b.marginal_m(m) >= 1.0 - delta]
    return Intersection([C_sigma[m] for m in md])         # 空 → safe_pause

# IP-273 意图漂移双通道
def intent_drift(res_intent, res_mode, b):
    if res_intent > TAU_I and res_mode < TAU_M: return "intent_change"
    if res_intent < TAU_I and res_mode > TAU_M: return "terrain_change"
    if res_intent > TAU_I and res_mode > TAU_M: return "joint_or_model_shift"
    return "none"
```

## 4. 推导

**引理 19（截止日主导）** 信息动作 g 优于「立即承诺」当且仅当 `P(t_g ≤ τ_c)·ΔC ≥ c(g) + ΔR(g)`；I-VoI 对 `ΔR` 与 `P(t_g>τ_c)` 单调不增，`τ_c→∞, ΔR≡0` 时退化为 R69 的 VoI。系：最优审议窗口集中在承诺边界附近，远离边界时「带着不确定性继续走」占优——查询由承诺时钟而非不确定性触发。

**引理 20（耦合惩罚）** 独立近似 `E_m E_τ[cost]` 与真值 `E_{m,τ}[cost]` 的偏差 ≤ `L·I(m;τ|y)`（L 为代价对隐变量的 Lipschitz 常数）。故 `U_couple` 大时必须联合后验；仅 `I(m;τ|y)≈0` 时 R68×R69 的拼接才安全。系：模式不确定与意图歧义不是两个可加的 U，而是不可分解的联合风险。

**引理 21（确认的证据价值上界）** 单次确认错误接受率 `δ_s`，确认疲劳使有效欺骗率 `δ_f ≥ δ_s`；期望损失 `q·c_confirm + (1−q)·δ_eff·S` 存在最优确认频率 `q*`。系：确认是有限预算的信息动作，不能无限追问（定义 322）。

**定理 18（意图鲁棒安全的 PAC 保证）** 若 `P(m*∈M_δ) ≥ 1−δ`、控制投影到 `C^robust_σ(δ)`、认证风险 ≤ `ε_int`，则真实意图安全集被违反的概率 ≤ `δ+ε_int+ε_est`；且 `C^robust_σ(δ)` 随 `δ↓` 单调扩张、随证据集中收敛到 `C_σ(m*)`。要点：先安全后理解，安全性与性能按时间分配而非二选一。

**定理 19（HILT 严格包含 FLUID 与 CALM）** 意图点质量、模式固定、`τ_c=∞`、`κ=ΔR=0`、无混合重置时逐指令等于 FLUID；再令信息动作库为空或 I-VoI≤0 时逐指令等于 CALM。故 `R68 ≺ R69 ≺ R70`，安全侧不让步，效率侧获承诺红利。

**定理 20（承诺安全与裕度不降）** 滞回守卫 + 意图鲁棒 CBF + safe-pause 回退下，任何被允许的切换其重置后状态满足 `h_{σ',m}(x⁺)≥0`（对全体可信意图）；否则停留在 `σ_pause`。故沿轨迹安全裕度不下降，不发生「进入不可逆模式后才发现意图错误」。注：混合切换处不保证控制连续，只保证切换前已验证、切换后仍在鲁棒安全集内。

**定理 21（惰性推断实时性）** 在 `ρ_σ ≥ ρ_hi` 且 `U_couple ≤ τ_couple` 的常规区间，边缘滤波 + mode_head 与全联合推断的决策差异 ≤ `ε_lazy`（由 KL 上界控制）；仅临近截止或耦合超阈才升联合，P99 满足实时预算。

## 7. 本轮最大风险

**一句话**：HILT 的安全性最终押在「意图后验校准、可信集大小恰当」上，而**意图在部署中没有 oracle**——过度自信会让鲁棒安全集坍缩成一个错误意图（不安全服从），过度保守又让交集永久为空（永远 safe-pause）；主动确认与权威门还会引入确认疲劳与冒充面，**把 R69 的「诚实的不知道」升级成「被流程盖章的错误服从」——读错意图并不可怕，可怕的是系统确信自己读对了。**

**次级风险与缓解**：混合系统非连续（守卫滞回 + 切换后校验 + safe-pause，定理 20）；意图-地形误当独立（联合后验 + `U_couple` 门控 + 引理 20）；确认疲劳/冒充（预算硬约束 + 双正交源 + ℰ_spoof，定义 322–324、引理 21）；实时预算（惰性边缘 + 临近截止升联合，定义 327、定理 21）；未见意图/长尾地形（未知意图占位 + unknown 强制降级，E310/E312）。
