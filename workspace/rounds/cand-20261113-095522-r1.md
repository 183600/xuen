# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序闭环」IP-214~223；新一轮灵感循环第 1 轮；本轮灵感：「数据集构建」×「记忆检索」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险同样一针见血：**归因能力依赖「故障属于有限假设集、且视觉与几何的失效相互独立」；真实故障常是未知类型的组合，透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源，此时 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球——第 65 轮的单点故障由此升级为「归因错误的复合故障」，而且系统会因为「已经归因」而更自信地继续执行（A88）。** 第 66 轮不叠加第 6 个模态，也不靠「多加一个假设」了事，而是追问更根本的一层：**VISTA 的归因后验究竟从哪来、凭什么能迁移到当下这一刻？** 本轮核心命题是：
>
> **把「离线故障库 + 在线归因」升级为「可认证的经验记忆」：用数据集构建（FAD）保证记忆有覆盖、有血统、有反确认偏误的负空间；用记忆检索（REx/RFA）把过去的证据按可交换性条件迁移到当下；并显式引入「未知」而非强行归类——让系统知道自己「没见过这种坏法」。**

## 0. 直觉与动机

**灵感 1（数据集构建 → 数据集是证书，不是素材）**
直觉：VISTA 的 p(ρ|H) 来自一份「想到什么故障就注入什么故障」的数据集。但引理 7 的可辨识性只在数据集**覆盖到的**签名区域成立；一旦查询落进覆盖空洞，S 的对应列没有被激励，后验会「自信地错」。所以数据集构建不是工程细节，而是**证书工程**：(i) 对每个假设 H 的签名支撑做 ε-覆盖；(ii) 保证可辨识裕度 κ_fi 有下界；(iii) 记录血统（仿真/真机/合成、标定版本），禁止把不同分布的样本当同分布池化；(iv) 显式维护**负空间账本**——哪些 (H, 区域) 没被覆盖。运行期落到 unknown 格就拒绝归因，而不是外推。

**灵感 2（记忆检索 → 从全局参数后验到实例级经验证据）**
直觉：p(ρ|H) 是全局参数化的；但很多故障是实例级的（「这个透明杯、这个位姿、这枚磨损的夹爪」）。人类专家用案例推理：检索相似历史片段，比较签名，再修正判断。检索能提供全局模型给不了的**条件化、局部化证据**。但检索不是免费证据：**观测相似 ≠ 因果等价**。必须满足「检索可交换性」，否则就是「看起来像，所以就是」的谬误；而且记忆可能被污染，也可能是系统自己的旧判断。

**灵感 3（二者合流 → 写记忆与读记忆是同一个认证问题）**
直觉：数据集构建是离线**写**记忆，记忆检索是在线**读**记忆。没有覆盖感知的写策略，就无法认证读；不知道读算子，也无法设计数据集。所以必须**写读协同设计**：故障图集定义检索的度量与归一化，检索失败（off-atlas / 低有效样本量 / 交换性检验拒绝）反过来驱动主动补数据。这是一条从运行期回到数据集的闭环。

**灵感 4（反确认偏误 → 记忆最危险的敌人是它自己）**
直觉：如果记忆只存「当时归因成功」的片段，RFA 检索到的就是系统自己的旧标签，后验会自我强化——不确定性下降而真实误差不降。因此写入必须设**独立标签门**（真值注入/人工审计/物理验证），模型自产标签只能以「软标签」低权重存在；数据集构建必须保留一个**盲测分片**（不参与拟合，只用于审计），并按与当前归因模型无关的先验采样故障，防止「只补模型能解释的故障」。

**灵感 5（RECALL 闭环与组件原位升级）**
RECALL = Retrieval-Enabled Certified Attribution with Layered Ledgers，可认证经验记忆闭环：FAD（故障图集构建 + 覆盖账本）→ EMG（带血统的片段记忆图）→ REx（检索可交换性与可靠性门）→ RFA（检索增强归因，含 H_unknown）→ MQ（记忆隔离/稳健聚合）→ RSC-M（新增 r_mem 球）→ WCV-M（检索边缘化尾部）→ CSP-R（块签名记忆匹配）→ AIC-R（记忆投毒/检索对抗/时序泄漏）→ J_recall。
- **FIR → RFA**：从全局似然升级为「全局先验 × 检索局部似然」，并显式加入 H_unknown。
- **APP/AFA → AFA-R**：探针不仅降故障熵，还要产出「可写入、可独立标注」的新片段（为下一次检索补洞）。
- **RSC-V → RSC-M**：新增 r_mem（检索/覆盖不确定球），只在记忆不可靠时膨胀。
- **WCV-V → WCV-M**：尾部对检索后验与 H_unknown 做边缘化。
- **CSP-V → CSP-R**：技能不仅绑块签名分布，还绑「该技能的历史片段结果分布」。
- **AIC-V → AIC-R**：干扰集增记忆投毒、近邻错标、时序泄漏、血统伪造、自证种子。
- **J_vista → J_recall**：证书增 atlas_ver、coverage_cert、retrieval_reliability、memory_label_source、quarantine_flags、h_unknown。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（RECALL 闭环）**：RECALL = (VISTA, FAD, EMG, REx, RFA, MQ, AFA-R, RSC-M/WCV-M, CSP-R, AIC-R, J_recall)。定位：VISTA 的「经验记忆可认证化」升级。不变式：**记忆写入、图集构建、检索可靠性评估、归因与证书只在语义流；实时流只读缓存好的检索证书与 r_mem，零 ANN 检索、零记忆写。**
- **定义 234（片段与经验记忆图 EMG）**：片段 e=(x, ρ, h̃, y, prov, t, ver, hash_prev)，x 为上下文嵌入（任务/物体/位姿/传感器健康），ρ 为阶段签名，h̃ 为故障标签（可为空），y 为执行结果，prov 为血统，hash 链保证只追加。EMG 为带时间与血统的异构图；标签来源 `src(e) ∈ {injected_truth, audited, physical_verified, model_derived}`。
- **定义 235（故障图集 FAD 与覆盖账本）**：FAD D={(z_i,h_i,prov_i)}，z_i∈ℝ^{15} 为签名，h_i 为注入真值；覆盖账本 L 把签名空间按哈希/Voronoi 划格，每格标 {covered, thin, unknown}，并带版本哈希 ver(D)。
- **定义 236（覆盖半径与 ε-网）**：对假设 h，S_h 为 h 在物理可达域内的签名支撑；覆盖半径 ε_h=sup_{z∈S_h} min_{i:h_i=h}‖z−z_i‖_{Σ⁻¹}。图集 gap g(z)=min_h d_h(z)。若 g(z)>ε_0 则判 `off_atlas`。
- **定义 237（数据集充分性证书）**：Sufficient(D) ⇔ ∀h: ε_h≤ε_0 ∧ n_h≥n_min ∧ κ_fi(D)≥κ_0 ∧ 血统分层校准有效 ∧ 存在未参与拟合的盲测分片 B_D。证书带 ver(D) 与覆盖率审计报告。
- **定义 238（血统分层与加权）**：prov 分层 P={injected_truth, audited, sim_calibrated, sim_only, synthetic}；校准似然按层分别拟合再按运行期可观测的血统比例混合，**禁止跨层直接池化**；层间比例偏移触发重校准。
- **定义 239（检索算子与检索邻域）**：R(x_q)=top-m_{e∈EMG} K_h(x_q,x_e)，K_h 为上下文核（度量由图集 FAD 归一化）；权重 w_e=K_h/ΣK_h。检索集 N_q 与权重 w 一并进入归因。
- **定义 240（检索可交换性缺陷与有效样本量）**：ξ_q 为检索加权分布与查询条件分布之间的可交换性缺陷估计（MMD/两样本检验上界）；ESS_q=(Σw)²/Σw²。二者共同刻画「这段记忆能不能当证据用」。
- **定义 241（检索可靠性门）**：`memory_reliable(q)` ⇔ ESS_q≥n_min ∧ ξ_q≤ξ_max ∧ 血统多样性≥2 ∧ ver(D) 与运行期一致。不可靠时不得把检索当证据，只能当「提示」。
- **定义 242（记忆隔离 MQ 与稳健聚合）**：若片段类内 Mahalanobis>τ_mem、血统校验失败、或卷入已知误归因 → 隔离（不进检索，保留审计）。聚合用截尾/影响函数有界权重；高置信标签要求 ≥2 个独立血统来源。
- **定义 243（未知故障假设 H_unknown 与开集似然）**：ℋ⁺=ℋ∪{H_unknown}。novelty(z_q)=σ(a·g(z_q)/ε_0 + b·ξ_q + c/√ESS_q)；p(ρ|H_unknown) 由图集外样本与留出故障类标定。**H_unknown 的存在使「拒绝归因」成为一等公民，而不是被迫归入最近假设。**
- **定义 244（检索增强故障后验 RFA）**：log p(H|ρ,N_q) ∝ log p_glob(H|ρ) + β_q·log p_ret(H|ρ,N_q) + 1[H=H_unknown]·log p_unk(z_q)，其中 p_ret 为检索集上的核密度标签分布，β_q=clip(ESS_q/n_ref,0,1)·(1−ξ_q/ξ_max)_+。`memory_reliable` 为假时 β_q=0，并抬高 p_unk、膨胀 r_mem。
- **定义 245（记忆条件主动探针 AFA-R）**：a*=argmax_a [I(ℋ⁺; ρ_new(a)|ρ,N_q) + λ_w·WriteValue(a)]，s.t. 预测力/形变安全。WriteValue 衡量「该探针能产出的新片段对覆盖账本空洞与检索缺陷的填补价值」——探针同时是**下一次记忆的写入口**；易损物体仍只走 visual_probe/null_test。
- **定义 246（记忆不确定球 RSC-M 与 WCV-M）**：r_mem=c₁g(z_q)+c₂ξ_q+c₃/√ESS_q；r=√(r_geo²+r_force²+r_model²+r_mem²)。WCV-M 搜索域在原交集上再交 𝒱 与「检索支持域」，尾部对后验（含 H_unknown）做边缘化；交集为空 → `attribution_conflict=True` 并回退最保守联合球。
- **定义 247（CSP-R 块级技能规划与 AIC-R 记忆对抗认证）**：CSP-R 的技能 σ 绑定块签名分布 𝒟_σ **与该技能历史片段结果分布**；两者任一 Mahalanobis>τ_chunk 即判 OOD。AIC-R 干扰集 ℰ_R=ℰ_V×ℰ_mem，ℰ_mem 含投毒片段、近邻错标、时序泄漏、血统伪造、自证种子；**投毒下不要求归因正确，只要求可靠门关闭并安全降级。**
- **定义 248（RECALL 证书 J_recall）**：J_recall=(J_vista, atlas_ver, coverage_cert, retrieval_reliability=(ESS_q,ξ_q), memory_label_source, quarantine_flags, h_unknown_flag)。Valid ⇔ Valid(J_vista) ∧ (in_atlas ∨ 显式 H_unknown) ∧ (memory_reliable ∨ β_q=0 且 r_mem 已膨胀) ∧ 写入遵守独立标签门 ∧ 血统有效。

## 2. 关键算法骨架

```python
# FAD：覆盖感知的数据集构建（离线，语义流外）
ledger = CoverageLedger(cells=hash_grid(Z), version=VER_D)
while budget > 0:
    cell = ledger.worst_gap(strategy='anti_confirmation')  # 不用当前归因模型选点
    z, h, prov = inject_fault(cell)                        # 真值注入
    D.append((z, h, prov)); ledger.update(z, h)
assert Sufficient(D)                                       # 否则拒绝发布该版本

# REx + RFA：读记忆（在线语义流）
N_q, w, xi_q, ess_q = REx.retrieve(x_q, EMG, D)           # 图集归一化的核检索
if not memory_reliable(ess_q, xi_q, N_q):
    beta_q = 0.0; r_mem = inflate(xi_q, ess_q)             # 记忆不可信 → 只当提示
else:
    beta_q = clip(ess_q / N_REF, 0, 1) * max(0, 1 - xi_q / XI_MAX)
post = softmax({
    h: log lik_glob[h](rho) + beta_q * log lik_ret[h](rho, N_q, w)
       + (log p_unk(z_q) if h == 'H_unknown' else 0.0)
    for h in H_PLUS})
if post['H_unknown'] >= 1 - delta_fi:
    abstain_and_degrade()                                  # 拒绝归因，不强行归类

# AFA-R：探针既降熵又补记忆
a = argmax_a (mutual_info(H_PLUS, rho_new(a), post)
              + LAMBDA_W * write_value(a, ledger, N_q))
execute_probe(a)
EMG.write(episode=make_episode(a), gate='independent_label_only')
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（覆盖-可辨识）**：若图集对每个 S_h 的覆盖半径 ε_h≤ε_0 且 κ_fi(D)≥κ_0，则 in-atlas 查询的归因误差 ≤ C(ε_0 + exp(−nκ_0/2))；off-atlas 查询被确定性地标记，不得输出认证归因。**覆盖不是数据量，而是签名空间上的 ε-网。**
- **引理 10（检索可交换性-条件覆盖）**：若检索集 N_q 在权重 w 下与查询条件分布加权可交换，则加权 conformal 给出 P[误差]≤α；当可交换性缺陷为 ξ_q 时，覆盖退化为 ≥1−α−Cξ_q。ξ_q 大时**没有保证**——所以必须 fail-closed，而不是继续用。
- **引理 11（记忆投毒的稳健界）**：若检索集中被投毒片段占比 ≤γ、聚合为截尾且血统加权，则 p_ret 的偏差被 breakdown point 与独立来源数共同界定；无独立标签的片段权重为 0 时，投毒无法改变后验的认证结论。
- **定理 9（RECALL 端到端）**：在 A94–A99 下，Valid(J_recall) ⇒ 归因要么 in-atlas、要么显式 H_unknown；检索增强后验覆盖 ≥1−α−Cξ_q；投毒影响有界；VISTA 的几何/力/模型/前缀安全性质在 r_mem 加入后保持。
- **定理 10（写读对偶下界）**：任何基于记忆的归因，其最坏误差下界同时受覆盖亏空与检索缺陷控制：存在未覆盖区域 U 且查询落入 U 时，任何校准都无法在 U 内区分假设；检索缺陷 ξ 时条件覆盖至多 1−α+ξ。**数据集与检索不是两个可分别优化的模块，而是同一个瓶颈的两端。**
- **命题（反确认偏误的必要性）**：若写入门允许模型自产标签以正权重进入检索，则存在部署序列使后验置信度→1 而真实误差≥ε（自证不动点）。故独立标签门不是「更好的实践」，而是**可认证性的必要条件**。
- **实时性**：ANN 检索、REx 检验、RFA、FAD 审计全在语义流；实时流只读缓存的 retrieval_reliability 与 r_mem，目标仍 ≤2.5ms（A93 契约不变）。

## 5. 本轮最大风险

**一句话**：RECALL 把「归因错误」进一步包装成「有数据血统、可复现、可审计的经验」——如果 FAD 只补当前假设集能解释的故障（确认偏误）、EMG 只收系统自己归因成功的片段（自证循环），那么 RFA 检索到的恰恰是它自己的偏见，后验会越收越紧、证书越来越漂亮，而真实误差并不下降；**数据集构建与记忆检索不是给 VISTA 增加了证据，而是给了它一套「系统性地相信自己」的基础设施**（A94）。

# 第 66 轮产物 · 创新点清单 v1：RECALL（Retrieval-Enabled Certified Attribution with Layered Ledgers：数据集构建 × 记忆检索的「可认证经验记忆」闭环；FAD×EMG×REx×RFA×MQ×AFA-R×RSC-M×WCV-M×CSP-R×AIC-R×J_recall）

> 承接第 65 轮 IP-214~223（VISTA：VPG×ACH×FIR×VCV×VSP/AFA×CSC×RSC-V×WCV-V×CSP-V×AIC-V×J_vista）。第 65 轮把「几何可证伪」升级为「故障可归因」，但其最大风险是**有限假设集 + 视觉/几何独立失效**：未知复合故障会被强行归入最近假设，只膨胀错误的球，且系统因「已经归因」而更自信。本轮不做推倒，而是补上 VISTA 从未回答的两个前置问题——**归因后验从哪来（数据集）？凭什么迁移到此刻（检索）？** 用**数据集构建**保证记忆有覆盖、有血统、有负空间；用**记忆检索**把过去的证据按可交换性条件迁移到当下；并显式引入 **H_unknown**，让「拒绝归因」成为一等公民。实现 **「覆盖可证、检索可换、未知可拒、投毒可隔离」**。
>

## 2. 形式化定义（完整版）

**定义 233（RECALL 闭环）** RECALL 是 VISTA 的「经验记忆可认证化」升级：在 VISTA 的语义流 ∘ 实时流骨架上挂载 FAD（覆盖感知故障图集）、EMG（带血统片段记忆）、REx（检索可交换性）、RFA（检索增强归因）、MQ（记忆隔离）、AFA-R（记忆条件探针），并原位升级 RSC-V→RSC-M、WCV-V→WCV-M、CSP-V→CSP-R、AIC-V→AIC-R、J_vista→J_recall。不变式：**记忆写入、图集构建、检索可靠性评估、归因与证书构建只在语义流；实时路径只读缓存好的 retrieval_reliability 与 r_mem，零 ANN 检索、零记忆写操作。**

**定义 234（片段与经验记忆图 EMG）** 片段 e=(x, ρ, h̃, y, prov, t, ver, hash_prev)，x 为上下文嵌入（任务、物体类别/实例、位姿、传感器健康、图集版本），ρ∈ℝ^{15} 为第 65 轮阶段签名，h̃ 为故障标签（可为空），y 为执行结果（成功/滑移/力越界/损伤），prov 为血统，t 为时间。EMG 为带时间与血统的异构图，边含「同物体/同技能/同签名邻域」。写入只追加，hash 链保证不可静默篡改。标签来源 `src(e) ∈ {injected_truth, audited, physical_verified, model_derived}`，只有前三者可进入「硬标签」检索；model_derived 只能作软标签且默认权重 0。

**定义 235（故障图集 FAD 与覆盖账本）** 故障图集 D={(z_i,h_i,prov_i)}，z_i 为注入故障下的签名，h_i 为注入真值，prov_i 为血统。覆盖账本 L 把签名空间按哈希/Voronoi 划格，每格标 {covered, thin, unknown}，并记录每格的样本数、血统构成与最近样本距离。L 与 D 共同带版本哈希 ver(D)。**FAD 的产物不是「一个更大的数据集」，而是「一个可查询、可审计、带负空间的覆盖地图」。**

**定义 236（覆盖半径与 ε-网）** 对假设 h，令 S_h 为 h 在物理可达域内的签名支撑，覆盖半径
ε_h=sup_{z∈S_h} min_{i:h_i=h}‖z−z_i‖_{Σ⁻¹}。
图集 gap g(z)=min_h d_h(z)。若 g(z)>ε_0，判 `off_atlas`。注意：g 衡量「离最近的已知坏法有多远」，是开集检测的第一道信号；ε_h 衡量「每个已知坏法被覆盖得多密」，是可辨识性的第一道信号。

**定义 237（数据集充分性证书）**
Sufficient(D) ⇔ ∀h: ε_h≤ε_0 ∧ n_h≥n_min ∧ κ_fi(D)≥κ_0 ∧ 血统分层校准有效 ∧ 存在未参与拟合的盲测分片 B_D。
其中 κ_fi(D) 为在 D 上线性化得到的第 65 轮可辨识裕度。证书随 ver(D) 发布；运行期 J_recall 必须引用同一 ver(D)，版本错位即拒绝认证。

**定义 238（血统分层与加权）** 血统分层 P={injected_truth, audited, sim_calibrated, sim_only, synthetic}。各层分别拟合 p_ℓ(ρ|H)，运行期按可观测血统比例 π_ℓ 混合：p(ρ|H)=Σ_ℓ π_ℓ p_ℓ(ρ|H)，**禁止跨层直接池化**。当运行期 π_ℓ 与建库时比例偏移超过 δ_prov 时触发重校准。血统分层解决「仿真注入的故障签名与真机故障签名不是同一分布，却被当成同一份数据」这一静默错误。

**定义 239（检索算子与检索邻域）** 检索算子
R(x_q)=top-m_{e∈EMG} K_h(x_q,x_e)，
其中 K_h 为上下文核，度量由图集 FAD 归一化（同一物体/技能/签名尺度）。权重 w_e=K_h(x_q,x_e)/Σ_{e'∈N_q}K_h(x_q,x_{e'})。检索集 N_q 与权重 w 一并进入归因；**检索邻域不是「最近的 m 个」，而是「在图集归一化度量下最近的 m 个硬标签片段」。**

**定义 240（检索可交换性缺陷与有效样本量）** 令 P_q 为查询条件分布、P_w 为检索集加权经验分布。定义可交换性缺陷
ξ_q = d(P_q, P_w)，
用 MMD 或两样本检验的上界估计。有效样本量 ESS_q=(Σw)²/Σw²。二者共同回答「这段记忆能不能当证据用」：ξ_q 控制**分布对不对**，ESS_q 控制**样本够不够**。

**定义 241（检索可靠性门）**
`memory_reliable(q)` ⇔ ESS_q≥n_min ∧ ξ_q≤ξ_max ∧ 血统多样性≥2 ∧ ver(D) 与运行期一致。
门关闭时，检索结果**不得进入认证证据**，只能作为提示/先验；β_q 置 0，r_mem 膨胀，若 H_unknown 后验随之升高则拒绝归因。

**定义 242（记忆隔离 MQ 与稳健聚合）** 片段 e 被隔离 `quarantine(e)` 当且仅当：类内 Mahalanobis 距离 >τ_mem、血统校验失败、或卷入已知误归因事件。隔离片段不进检索，但保留用于审计与再标注。聚合采用截尾均值/影响函数有界权重；硬标签的高置信结论要求 ≥2 个独立血统来源。**隔离不是删除——删除会抹掉攻击证据，隔离只让它失去投票权。**

**定义 243（未知故障假设 H_unknown 与开集似然）** 令 ℋ⁺=ℋ∪{H_unknown}。未知度
novelty(z_q)=σ(a·g(z_q)/ε_0 + b·ξ_q + c/√ESS_q)。
p(ρ|H_unknown) 由图集外样本与留出故障类标定（held-out fault families）。**H_unknown 使「拒绝归因」成为一等公民**：第 65 轮把未知复合故障强行归入最近假设，本轮允许后验质量集中到 H_unknown 并触发安全降级，而不是错误膨胀某个球。

**定义 244（检索增强故障后验 RFA）**
log p(H|ρ,N_q) ∝ log p_glob(H|ρ) + β_q·log p_ret(H|ρ,N_q) + 1[H=H_unknown]·log p_unk(z_q)，
其中 p_ret(H|ρ,N_q)=Σ_{e∈N_q,h_e=H} w_e κ_ρ(ρ,ρ_e) / Σ_{e∈N_q} w_e κ_ρ(ρ,ρ_e) 为检索集上的核密度标签分布，κ_ρ 为签名核；
β_q=clip(ESS_q/n_ref,0,1)·max(0,1−ξ_q/ξ_max)。
若 `memory_reliable(q)` 为假，β_q=0，并抬高 p_unk、膨胀 r_mem。RFA 的语义是：**全局模型给先验，检索只在可交换且样本足够时才允许修正后验。**

**定义 245（记忆条件主动探针 AFA-R）** 探针动作带阶段模板，选择
a*=argmax_{a∈A} [I(ℋ⁺; ρ_new(a) | ρ, N_q) + λ_w·WriteValue(a)]，
s.t. 预测 f_n≤f_safe(φ̂,f̂_vis)、预测形变≤ε_strain、支持视觉早停。
WriteValue(a) 衡量该探针产出的新片段对覆盖账本空洞（`unknown/thin` 格）与检索缺陷（高 ξ_q 区域）的填补价值。**探针不再只服务「这次分清楚」，还服务「下次有记忆可查」；易损物体仍只走 visual_probe/null_test，WriteValue 不得覆盖安全约束。**

**定义 246（记忆不确定球 RSC-M 与 WCV-M）** 维护 r_geo、r_force、r_model、r_mem 与 w_vis。记忆球
r_mem=c₁g(z_q)+c₂ξ_q+c₃/√ESS_q，
融合半径 r=√(r_geo²+r_force²+r_model²+r_mem²)。WCV-M 搜索域
B(φ̂,r) ∩ 𝒢(g) ∩ K(μ̂) ∩ ℱ(f_lim) ∩ 𝒱 ∩ ℳ(N_q)，
其中 ℳ(N_q) 为检索支持域（仅在 memory_reliable 时非平凡）。尾部对后验（含 H_unknown）按 P(H|ρ,N_q) 加权做边缘化；交集为空则回退 B(φ̂,r)，置 `attribution_conflict=True` 写入 J_recall。

**定义 247（CSP-R 块级技能规划与 AIC-R 记忆对抗认证）** CSP-R 在块级 A* 上以块为边，每条边需 Valid(J_recall) 且 k*≥1。技能 σ 绑定两个分布：块签名分布 𝒟_σ 与历史片段结果分布 𝒴_σ；实际块签名或检索到的同技能结果分布任一 Mahalanobis>τ_chunk 即判 OOD，不入图。AIC-R 干扰集
ℰ_R=ℰ_V×ℰ_mem，
ℰ_mem 含投毒片段、近邻错标（近邻但标签翻转）、时序泄漏（未来片段可见）、血统伪造、自证种子（预置可被检索到的错误归因）。**投毒下不要求归因正确，只要求可靠性门关闭、隔离生效并安全降级。**

**定义 248（RECALL 证书 J_recall）** J_recall=(J_vista, atlas_ver, coverage_cert, retrieval_reliability=(ESS_q,ξ_q), memory_label_source, quarantine_flags, h_unknown_flag)。验证规则：
Valid(J_recall) ⇔ Valid(J_vista)
∧ (in_atlas ∨ 显式 h_unknown_flag)
∧ (memory_reliable ∨ β_q=0 且 r_mem 已膨胀)
∧ 写入遵守独立标签门
∧ 血统有效且 atlas_ver 与运行期一致。
审计链在 VISTA 之上新增：**这条归因用了哪个版本的图集（atlas_ver）、覆盖够不够（coverage_cert）、检索凭什么可信（ESS_q/ξ_q）、标签从哪来（memory_label_source）、哪些片段被隔离（quarantine_flags）、是不是未知故障（h_unknown_flag）。**

### IP-224 FAD：覆盖感知的数据集构建

```python
class FaultAtlasBuilder:
    """离线/准离线：目标不是样本量，而是覆盖证书与负空间账本。"""
    def build(self, budget, epsilon0, kappa0, blind_frac=0.1):
        D, ledger = [], CoverageLedger(hash_grid(Z))
        while budget > 0 and not self.sufficient(D, epsilon0, kappa0):
            # 反确认：用与当前归因模型无关的故障先验选点
            cell = ledger.worst_gap(strategy='anti_confirmation')
            z, h, prov = inject_fault(cell)          # 真值注入
            D.append((z, h, prov)); ledger.update(z, h)
        blind = stratified_holdout(D, blind_frac)    # 不参与拟合，只审计
        return D, ledger, blind

    def sufficient(self, D, epsilon0, kappa0):
        return (all(cover_radius(D, h) <= epsilon0 for h in HYP)
                and all(count(D, h) >= N_MIN for h in HYP)
                and identifiability_margin(D) >= kappa0)
```

### IP-225/IP-226 EMG + REx：带血统的记忆与检索可靠性

```python
class EpisodicMemory:
    def write(self, episode, gate):
        # 独立标签门：模型自产标签只能软写入且默认权重 0
        if gate == 'model_derived':
            episode.soft = True
            episode.weight = 0.0
        episode.hash = sha256(prev_hash + episode.payload)
        self.graph.add(episode)                      # 只追加

    def quarantine(self, tau_mem):
        for e in self.graph:
            if (mahalanobis_within_class(e) > tau_mem
                    or not provenance_valid(e)
                    or e in known_misattributions):
                e.quarantined = True                 # 保留审计，失去投票权


class RetrievalExchangeability:
    def retrieve(self, x_q, memory, atlas, m, n_min, xi_max):
        cand = memory.hard_labeled()                 # 排除隔离/软标签
        N, K = top_m(cand, lambda e: kernel(x_q, e.x, atlas.normalizer), m)
        w = normalize(K)
        ess = (w.sum() ** 2) / (w ** 2).sum()
        xi = mmd_upper_bound(conditional_sample(x_q), weighted_sample(N, w))
        reliable = (ess >= n_min and xi <= xi_max
                    and provenance_diversity(N) >= 2)
        return N, w, xi, ess, reliable
```

### IP-227 RFA：检索增强归因（含 H_unknown）

```python
class RetrievalAugmentedAttribution:
    def attribute(self, rho, z_q, N, w, xi, ess, reliable, glob_post):
        beta = 0.0 if not reliable else (
            min(1.0, ess / N_REF) * max(0.0, 1.0 - xi / XI_MAX))
        novelty = sigmoid(A * atlas_gap(z_q) / EPS0
                          + B * xi + C / sqrt(ess + 1e-9))
        logp = {}
        for h in H_PLUS:
            lp = log(glob_post[h] + 1e-12)
            if beta > 0:
                lp += beta * log(retrieval_likelihood(h, rho, N, w) + 1e-12)
            if h == 'H_unknown':
                lp += log(novelty + 1e-12)
            logp[h] = lp
        post = softmax(logp)
        h_star = max(post, key=post.get)
        return post, h_star, post[h_star] < 1.0 - DELTA_FI, beta
```

### IP-229 AFA-R：既降熵又补记忆的探针

```python
def choose_probe(post, phi_hat, f_safe, fragile, ledger, N_q):
    if fragile:
        return 'visual_probe' if vis_reduces_entropy(post) > DELTA_FI else 'null_test'
    best, best_score = None, -np.inf
    for a in PROBES:
        traj = predict_probe_traj(a, phi_hat)
        if np.max(traj.f) > f_safe or np.max(traj.strain) > EPS_STRAIN:
            continue
        ig = expected_mutual_info(post, a)          # I(H+; rho_new)
        wv = write_value(a, ledger, N_q)             # 补洞价值
        if ig + LAMBDA_W * wv > best_score:
            best, best_score = a, ig + LAMBDA_W * wv
    return best
```

### IP-233 RECALL 闭环算子（整合）

```python
def RECALL_round(M, obs, delta_f_req):
    V, T, P, L, P_cloud, W_meas, tactile, img, depth, flow = obs
    # ———— 语义流 ————
    x_q = M.f_vis.context(img, depth, flow, P_cloud)     # 上下文嵌入
    N, w, xi, ess, reliable = M.rex.retrieve(x_q, M.emg, M.fad, M.m, M.n_min, M.xi_max)
    # 第 65 轮 VISTA 的视觉/阶段/归因

    visual = M.vpg.verify_and_predict(x_q, A, M.mws.last_contacts)
    phases = M.stage.split(M.residual_log, visual)
    glob_post, _, _ = M.fir.attribute(phases)
    # RFA：检索增强 + H_unknown
    post, h_star, ambiguous, beta = M.rfa.attribute(
        M.fir.signature(phases), M.fad.gap_of(phases), N, w, xi, ess,
        reliable, glob_post)
    if ambiguous and h_star != 'H_unknown':
        a = M.afa_r.choose_probe(post, M.phi_hat, M.f_safe,
                                 M.object_fragile, M.fad.ledger, N)
        if a is not None:
            M.execute_probe(a)
            phases = M.stage.split(M.residual_log, visual)
            post, h_star, ambiguous, beta = M.rfa.attribute(...)
    # 记忆球 + 定向处置
    M.balls['r_mem'] = memory_ball(M.fad.gap_of(phases), xi, ess)
    if not ambiguous and h_star != 'H_unknown':
        M.balls, M.w_vis, M.H = M.fir.directed_demote(
            h_star, M.balls, M.w_vis, M.H)
    # 规划 + 认证前缀 + 实时执行（沿用 VISTA，加入 r_mem 与 H_unknown 处置）
    tau = M.csp_r.plan_chunks(M.dms.parse_goal((M.usr.U_ep, M.usr.U_al)),
                              x_q, M.phi_hat, M.balls, post, N)
    k_star = M.csc.certified_prefix(tau.A, post, M.m, M.alpha_chunk)
    K_safe, EV_exec, cert_exec = realtime_step_recall(
        M, delta_f_req, tau, k_star, x_q, visual)
    # 写记忆：独立标签门；模型自产标签只软写
    M.emg.write(make_episode(x_q, phases, y=EV_exec),
                gate=label_gate(M, EV_exec))
    M.rsc_m.update(EV_exec, W_meas, M.phi_hat, post, M.balls)
    rho_dir = M.aic_r.certify(tau, x_q, M.phi_hat, M.balls, post, N)
    return M, K_safe, EV_exec, build_j_recall(
        cert_exec, J_vista=M.j_vista, atlas_ver=M.fad.ver,
        coverage_cert=M.fad.cert, retrieval_reliability=(ess, xi),
        memory_label_source=label_gate(M, EV_exec),
        quarantine_flags=M.emg.quarantined_ids(),
        h_unknown_flag=(h_star == 'H_unknown'))
```

## 4. 推导

**引理 9（覆盖-可辨识）** 设签名似然 L_H 关于 z 为 L-Lipschitz，图集对 S_h 的覆盖半径为 ε_h≤ε_0。对 in-atlas 查询，最近图集点 z_i 满足 ‖z_q−z_i‖≤ε_0，故 |L_H(z_q)−L_H(z_i)|≤Lε_0；再用第 65 轮 Laplace 集中（速率 exp(−nκ_0/2)）即得归因误差上界 C(ε_0+exp(−nκ_0/2))。若 g(z_q)>ε_0，则最近图集点已不在任何 S_h 的覆盖球内，似然是外推而非插值，**不构成认证归因**，只能标记 off_atlas 并交由 H_unknown。∎

**引理 10（检索可交换性-条件覆盖）** 加权 conformal 的标准结论：若校准分数在权重 w 下与查询分数加权可交换，则 P[Y_q∈C]≥1−α。当真实条件分布 P_q 与加权经验分布 P_w 的缺陷为 ξ_q 时，由三角不等式与覆盖事件对分布的 Lipschitz 依赖，覆盖至少退化为 1−α−Cξ_q。ξ_q→大时该界无意义，故必须 fail-closed：**没有可交换性就没有条件覆盖，检索只是「提示」不是「证据」。** ∎

**引理 11（记忆投毒的稳健界）** 设 N_q 中投毒片段占比 γ，聚合为 breakdown point γ_b>γ 的截尾估计，且硬标签要求 ≥2 个独立血统来源。则投毒片段对 p_ret 的影响被截尾与血统权重共同限制在一个 O(γ/γ_b) 的邻域内；若 model_derived 片段权重为 0，则自证种子无法进入检索，投毒不能改变认证结论（只能改变提示）。∎

**定理 9（RECALL 端到端归因-安全）** 在 A94–A99 下，若 Valid(J_recall)：
1. **覆盖可证**：归因要么 in_atlas（由引理 9 给出误差界），要么显式 h_unknown_flag 并进入安全降级——不再出现「未知故障被强行归入最近假设」。
2. **检索可换**：memory_reliable 时后验覆盖 ≥1−α−Cξ_q（引理 10）；不可靠时 β_q=0、r_mem 膨胀，检索降级为提示。
3. **投毒可隔**：MQ 与独立标签门使投毒影响有界（引理 11）；J_recall 记录 quarantine_flags 与 memory_label_source。
4. **VISTA 性质保持**：r_mem 加入后 RSC-M 的球仍有限，WCV-M 尾部含 H_unknown 最坏情形；第 65 轮的几何/力/模型/前缀安全性质在 H_unknown 处置（safe_idle/compliant retreat）下保持。
5. **写读协同**：AFA-R 的 WriteValue 把探针产出导向覆盖空洞，下一轮 FAD/EMG 的覆盖与检索可靠性单调改善（在预算与安全约束下）。∎

**定理 10（写读对偶下界）** 对任意基于记忆的归因器：
- 若存在未覆盖区域 U（μ(U)>0）且查询落入 U，则 U 内任意两个假设的签名似然不可区分，任何校准都无法在 U 内给出正确归因——覆盖亏空直接构成误差下界；
- 若检索缺陷为 ξ，则任意加权检索器的条件覆盖至多 1−α+ξ（引理 10 的逆命题方向）。
故最坏误差 ≥ (1/2)·max{coverage_deficit, retrieval_defect}。**数据集构建与记忆检索不是两个可分别优化的模块，而是同一个瓶颈的两端：补数据能降 ξ 的可用样本上限，好的检索度量能反过来指出该补哪里。** ∎

**命题（反确认偏误的必要性）** 若写入门允许 model_derived 标签以正权重进入检索，则存在部署序列：系统在某类故障上持续误归因为 H_geo → 每次误归因片段被写入并可在未来被检索 → RFA 的 p_ret 不断强化 H_geo → 后验置信度 →1，而真实误差保持 ≥ε。这是自证不动点，且数据集构建若只补 H_geo 相关故障会进一步锁死。故**独立标签门与盲测分片不是「更好的实践」，而是可认证性的必要条件。** ∎

**命题（r_mem 的保守性）** 当 memory_reliable 为真且 g→0、ξ→0、ESS→∞ 时 r_mem→0，RECALL 退化为 VISTA；当记忆不可靠时 r_mem 单调增，WCV-M 自动回到第 65 轮的保守行为。故 RECALL 是 VISTA 的**严格扩展**，不是替代。∎

## 7. 已知风险

**一句话**：RECALL 把「归因错误」进一步包装成「有数据血统、可复现、可审计的经验」——如果 FAD 只补当前假设集能解释的故障（确认偏误）、EMG 只收系统自己归因成功的片段（自证循环），那么 RFA 检索到的恰恰是它自己的偏见，后验会越收越紧、证书越来越漂亮，而真实误差并不下降；**数据集构建与记忆检索不是给 VISTA 增加了证据，而是给了它一套「系统性地相信自己」的基础设施**（A94）。

**次级风险与缓解**：
1. **确认偏误的数据集**：故障先验被当前模型污染。缓解：反确认采样（独立故障生成器）、盲测分片、定期红队注入未见故障族。
2. **自证循环**：模型自产标签回灌检索。缓解：独立标签门（model_derived 权重 0）、硬标签需 ≥2 独立血统、E246 监控 confidence−accuracy gap。
3. **检索可交换性不可验证**：高维上下文下 MMD 检验功效低，ξ_q 估计失真。缓解：低维任务嵌入 + 分层检验 + 保守上界；ξ_q 超限即 fail-closed。
4. **记忆规模与遗忘**：EMG 无限增长，旧片段与新硬件/新标定不匹配。缓解：血统版本化、按 ver(D) 分片检索、时间衰减权重（但不删除审计副本）。
5. **投毒/血统伪造**：攻击者预置可检索的错误经验。缓解：哈希链、隔离而非删除、AIC-R 对抗认证、来源多样性要求。
6. **H_unknown 滥用**：模型把「难」当「未知」逃避归因。缓解：H_unknown 需 novelty 与 off-atlas 双证据；E244 监控未知召回与误报的权衡。
7. **实时性**：ANN 检索与可交换性检验若误入实时环会破坏 2.5ms 契约。缓解：检索与 REx 全在语义流，实时只读缓存证书；A93 契约不变。
8. **图集版本错位**：运行期与证书引用不同 ver(D)。缓解：J_recall 强制版本一致，否则拒绝认证并安全降级。
