# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「抓取规划」×「视觉伺服」）

> R69 把不确定性一分为二，并问出「我该向谁求证」。但它埋着一个更强、也更危险的前提：**凡是 epistemic 不确定，都应该在行动之前把它消解掉**。对「绕左还是绕右」这也许成立；对接触丰富的抓取，这个前提直接失效：抓取是一次**不可逆的物理承诺**，问一次很贵、会被投毒、会追到幻影，而很多几何不确定性**根本不需要被消解**——只要选一个对它不敏感的动作。R69 自陈的最大风险（流模态权重不可信 → 自信地追问幻影）恰恰说明：**用学出来的置信度来发放「执行许可」，本身就是错的**。
>
> 本轮两个灵感补上两条完全不同的解题路径：
> - **抓取规划**给出「结构吸收」——笼闭（caging）、力封闭裕度、抓取质量都可以在**高置信位姿集合**上解析地认证；选择抓取时最大化的是「它能容忍的不确定性半径」，而不是「在猜测位姿上的最优质量」。
> - **视觉伺服**给出「反馈吸收」——IBVS 直接在图像误差上闭环，位姿/标定误差不必先被消解；而且闭环本身就顺带**免费**产生信息。执行不再依赖开环规划的一次性精度。
>
> 核心命题：**不确定性有三种处置，而非两种：吸收（选对它不敏感的动作）、消解（R69 去问）、退避（R68 收紧）。R70 把「吸收」放在最前面，且执行许可由解析证书发放、不由学习置信度发放；当证书集为空、只剩语义不确定、或在线监控失效时，逐指令退化为 R69。** 命名 **CAGE-RAS**（Certified Affordance Grasping under Epistemic uncertainty with Robust Adaptive Servoing）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**哪些不确定根本不必问——因为我可以选一个对它不敏感的动作**」——不确定性不只是刹车与提问，也可以是一个笼闭的抓取和一段闭环的伺服。

## 0. 直觉与动机

**灵感 1（抓取规划 → 结构吸收：让动作对不确定性不敏感）**
直觉：人抓一个看不清位置的杯子，不会先把杯子位姿精确到毫米；人会张开手指**围住**它，让手形成一个「逃不出去」的区域，再合拢。这就是笼闭（caging）：它不要求精确接触力，只要求拓扑上把物体围在里面；即使物体在手里滑动、即使位姿估计偏了几毫米，它也跑不掉。相比之下，力封闭是「精确」的保证，但也更脆——接触点一错，扳手锥可能就不再张成整个旋量空间。这个对比正是 R69 缺的那块：R69 只会「把不确定变小」，却不会「选一个不怕不确定的动作」。抓取规划还给出一个反直觉但正确的目标函数翻转：**应当最大化「可容忍的不确定性半径」，而不是最大化标称位姿处的抓取质量。**

**灵感 2（视觉伺服 → 反馈吸收：把估计问题变成控制问题）**
直觉：开环抓取 = 先精确估计位姿，再一次性执行，误差无法挽回。视觉伺服 = 不看「绝对位姿」，只看「图像特征和目标的差」，每一帧都在纠错。经典 IBVS 的一个宝贵性质是：它闭环在图像空间，很多标定误差并不会破坏稳定性（虽然深度误差与特征选择会）；也就是说，**你可以不知道准确的位姿，只要图像误差的闭环是收缩的**。这把「估计得足够准才能动」换成「闭环足够稳就能动」。更深一层：伺服所需的图像本来就为控制而采集，所以它对几何不确定性的信息获取是**顺带的、不占 R69 交互预算的**——R69 要专门「看/问/触」才拿到的信息，闭环执行在任务必经轨迹上就免费拿到了。

**灵感 3（证书而非置信 → 正面拆掉 R69 的最大风险）**
直觉：R69 的致命处是「让学出来的模态权重决定要不要问、信不信答案」。R70 改一条根本规则：**执行许可由可检查的解析证书发放，而不是由学习到的置信度发放**。笼闭裕度、力封闭最坏质量、IBVS 正实裕度都是几何量，可以在标称值上减去「Lipschitz 常数 × 信念半径」得到一个**下界**；只要下界过阈，动作就是安全的——哪怕流模型把它的概率估得很低。反过来，一个模态即使被流模型估得再高，没有证书也不许直接执行。这把 R69 的「信模型」换成了「信证书」，而证书是可以被审计、被反证、被形式检查的。对「幻觉模态诱发追问」这个问题，最干净的解法不是把阈值调高，而是**让权限不再来自那个会幻觉的东西**。

**灵感 4（三分处置 → 吸收 / 消解 / 退避，且严格包含 R69）**
直觉：面对不确定，人类其实同时使用三种策略：能绕开就绕开（吸收）、绕不开就问（消解）、问不了就慢（退避）。R69 只实现了后两种，且把第一种错当成第二种。正确的决策不是「epistemic 就一定要问」，而是比较两条路的代价：**鲁棒性成本** C_R（为了鲁棒而放弃的标称收益）与**信息价值** VoI（去问能拿回多少收益，减去交互成本与投毒风险）。谁便宜走谁。于是 R69 不再是并列的另一套系统，而是 R70 在「没有可认证的鲁棒动作」边界上的退化情形——这是本谱系一贯的理论姿态：**新层必须是旧层的严格泛化**。

**灵感 5（不可逆性 → 新的威胁模型：假证书比没证书更危险）**
直觉：R69 的交互即使问错，最坏是「得到一个错误答案」，还可以再问、可以审计、可以降级。抓取一旦合拢、抬起，就是**不可逆的物理承诺**：掉落的杯子不会给你第二次采样。而 R70 的安全性完全押在「信念集 ℬ_α 真的包含真值」和「几何/手指模型是对的」上。若 conformal 覆盖因分布漂移失效、若物体其实是可形变的、若深度偏差让交互矩阵估错，那么证书就是**假证书**——系统会带着一张错误的证明去执行一个不可逆动作，而且因为它「已经证明过了」，反而取消了 R69 那点宝贵的怀疑。所以本轮必须同时交付：信念集覆盖率监控、证书在线反证、单调降级、以及「单张证书不得授权不可逆动作，需监控在环」的纪律。否则 R70 不是进步，而是把 R69 的「问错」升级成「证明错着去抓」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（CAGE-RAS 总览与四不变式）** CAGE-RAS = (PBA, RGC, VSC, GSX, SCE, RIE, UST, VGC, RSM, J_CAGE, VQAuditor-G, AIC-CAGE, RAS-WM†)。四不变式：
(i) **在线零学习写**（继承 R68 定义 276-i）；
(ii) **证书先于运动**：任何被宣称「对不确定性不敏感」的动作必须携带可检查证书，且证书覆盖高置信信念集 ℬ_α；无证书不得声称鲁棒，也不得据此跳过 R69 的问询；
(iii) **吸收优先、消解其次、退避兜底**：先尝试结构吸收（抓取证书）与反馈吸收（伺服证书），只有当鲁棒性成本高于信息价值时才动用 R69 的交互预算；
(iv) **严格包含**：证书集为空、仅剩语义不确定、或在线监控失效 ⇒ 逐指令等于 R69（推论与定理 18）。

**定义 311（高置信信念集 PBA）** 位姿头给出 q̂ 与非一致性分数；在可交换校准集上取 conformal 区域 Q_α，使 P(q_true ∈ Q_α) ≥ 1−α（假设 A100；这是**边际**覆盖，不是条件覆盖）。记信念半径 δ_α = sup_{q∈Q_α} d(q, q̂)（SE(3) 用位置+加权旋转的乘积度量）；形状不确定集 S_α；ℬ_α = Q_α × S_α。ℬ_α 以位姿球并集或凸松弛表示，便于后续 Lipschitz 下界。

**定义 312（证书–δ 原理，本轮数学脊椎）** 任一几何证书 c 在标称位姿处取值 M_c(g, q̂)、阈值 τ_c、对位姿的 Lipschitz 常数 L_c（假设 A101）。则对任意 q ∈ ℬ_α，
M_c(g,q) ≥ M_c(g,q̂) − L_c·δ_α。
定义**证书半径** r_c(g) = (M_c(g,q̂) − τ_c)/L_c（≤0 即不可认证）。于是「在 ℬ_α 上鲁棒认证」⇔ δ_α ≤ min_c r_c(g)。笼闭、力封闭、伺服稳定三类证书被统一成同一个形状：**标称裕度 − L·δ ≥ 阈值**。这把「概率置信」换成了「带 Lipschitz 修正的几何下界」。

**定义 313（鲁棒抓取与笼闭证书 RGC）** 抓取 g = (手位姿, 接触集 C, 预成形, 接近方向)。
- **笼闭（caging）**：cage margin ρ(q̂) = sup{r : B(q̂,r) ⊆ 𝒦(q̂)}，其中 𝒦(q̂) 是自由空间中被手指围住、且不含「逃逸集」的有界连通分量。拓扑条件只要求「围住」，不要求精确接触力方向，故对位姿误差最鲁棒。对平行爪，取「搬运平面投影笼闭 + 漏斗约束」，三维逃逸由力封闭裕度兜底（假设 A102）；对可形变物体，拓扑证书直接失效并触发退化。
- **力封闭**：Ferrari–Canny ε 质量 Q(q)（抓取旋量空间内切球半径），最坏情形 Q_min ≥ Q(g,q̂) − L_Q δ_α，要求 Q_min ≥ q_min。
- **运动学/碰撞**：路径可达、无碰撞、关节与力矩受限。
鲁棒抓取集 𝒢_R(ℬ_α) = {g : δ_α ≤ min(r_cage, r_fc, r_kin)，且标称质量 Q(g,q̂) ≥ q_min}。

**定义 314（鲁棒半径最大化 / 吸收度 GSX）** 吸收度 A(g) = min_c r_c(g)。抓取选择改为
g* = argmax_g A(g)  s.t.  Q(g,q̂) ≥ q_min。
含义：**抓取规划的目标不是「在猜测位姿上最优」，而是「最大化它能容忍的不确定性半径」**。当 δ 未知或缓慢漂移时，最大化 A 直接等价于最大化安全裕度；这是对「先估准再抓」这一默认范式的正面反驳。

**定义 315（视觉伺服证书 VSC）** 图像特征 s(q) ∈ ℝ^k，期望 s*；IBVS 控制 v = −λ L̂_s^+(s − s*)，交互矩阵 L_s(q) = (∂s/∂q)·J(q)（显含深度）。取 Lyapunov V = ½‖e‖²，e = s − s*。若在 ℬ_α 上一致正实裕度
μ(q) = λ_min(sym(L̂_s^+ L_s)) ≥ μ_req > 0，
则 V̇ ≤ −2λμ V + 扰动上界，误差指数收敛到有界球。定义 M_servo = μ(q̂)、r_servo = (μ(q̂) − μ_req)/L_μ。**证书伺服盆地** ℛ(g) = {位姿 : 在可见性/力/关节/避障约束下伺服收敛到预抓取流形}，用区间/zonotope 可达性过近似；若 ℬ_α ⊆ ℛ(g)，则「位姿不确定性对抓取成败不再致命」。

**定义 316（反馈免费信息）** 伺服沿任务必经轨迹持续采集特征，每步 Fisher 信息 I(q) = L_s^T Σ_s^{-1} L_s，位姿熵至少下降 ΔH_free(T)。定义净免费 VoI：VoI_free = ΔH_free(T) − cost_detour − cost_visibility。若轨迹无需额外绕行（假设 A103），则 VoI_free ≥ 0 且**不占 R69 的交互预算**。⇒ 对几何不确定，「闭环执行」常严格优于「专门问一次」：既省一次交互，又少一个投毒入口。

**定义 317（不确定性分层 UST）** 把 R69 的 U_epi（定义 297）细分为
U_epi = U_epi^geo + U_epi^sem，
其中 U_epi^geo 是位姿/形状/接触不确定性（可被吸收或由伺服免费消解），U_epi^sem 是任务/语义不确定性（易碎、可抓、目标、许可——几何结构无法吸收）。路由：U_epi^geo → 吸收（R70）；U_epi^sem → 消解（R69）；U_ale → λ_floor（R68）。R69 恰是「吸收不可行」时把 U_epi^geo 也送去消解的退化。

**定义 318（鲁棒性–信息仲裁 RIE）** 对每个已认证 g，定义认证下界 LCB_abs(g) = min_{q∈ℬ_α} U(g,q) − C_exec；对问询定义 LCB_ask = E[U | ask] − c_int − κ·risk_poison。判定：
- 若 max_{g∈𝒢_R} LCB_abs(g) ≥ LCB_ask 且 ≥ 退避基线 ⇒ **吸收**并执行；
- 否则若 LCB_ask > 退避基线（等价地 VoI > c_int + 风险折价）⇒ **消解**（调用 R69）；
- 否则 ⇒ **退避**（R68 λ_floor）。
用**认证下界**而非期望效用，得到分布鲁棒的 satisficing / maximin 决策；R69 的「VoI > c」是其鲁棒集为空时的边界（引理 22）。鲁棒性成本记为 C_R = U(a*, q̂) − max_{g∈𝒢_R} U(g,q̂)；仅在 C_R ≤ VoI_paid − c_int 时问询才划算。

**定义 319（认证执行 SCE）** 四阶段：(1) IBVS 伺服到预抓取，保持可见性与 CBF 安全；(2) 闭合手指进入笼闭/力封闭；(3) 接触/力签名确认（可复用 R69 探针，但仅作确认、不作主证据）；(4) 搬运全程笼闭监控。任一阶段监控失效 ⇒ 证书作废，单调降级 absorb → reduce → retreat。

**定义 320（伺服安全滤波 CBF）** 伺服指令先过 C-RAS-WM 前缀认证（继承 R68），再过控制障碍函数滤波：
v_safe = argmin_v ‖v − v_ibvs‖²  s.t.  CBF（避障、力/力矩、关节、可见性、时间窗）。
⇒ 即使名义 IBVS 指令会越界，实际下发指令不越界（定理 19 的一部分）。

**定义 321（可见性–注视耦合 VGC）** IBVS 依赖特征可见，定义可见性裕度 v_margin。R69 的 g_gaze 从「信息动作」升级为「伺服使能动作」。若可见性将失守：先重注视（R69 动作，进预算），否则降级到 PBVS + 模型（精度下降但可见性鲁棒），再否则退避。R69 的 VoI 在此被重新解释为「保持反馈通道可用的成本」。

**定义 322（残余语义问询 RSM）** 吸收之后仍无法用几何结构消解的只有 U_epi^sem。仅对语义不确定调用 R69 的 MINT/CIA；证据纪律（k 个正交源一致，R69 定义 293-iii）保持不变；交互预算只花在语义上。于是 R69 的投毒/幻影攻击面随问询次数单调收缩（推论 1）。

**定义 323（证书 J_CAGE）** J_CAGE = (J_FLUID, coverage_α, δ_α, A(g), cage_margin, fc_qmin, servo_margin, basin_containment, free_voi, monitor_violations, cage_ver)。Valid ⇔ Valid(J_FLUID) ∧ coverage ≥ 1−α ∧ δ_α ≤ A(g) ∧ ℬ_α ⊆ ℛ(g) ∧ CBF 满足 ∧ 无未处理监控违规。

**定义 324（假证书威胁模型 AIC-CAGE）** 新增干扰：分布漂移破坏 conformal 覆盖（非可交换）、几何/手指模型误差、深度/标定偏差使 L_s 估错、遮挡/特征丢失、可形变物体使拓扑证书失效、对抗纹理破坏特征跟踪。ℰ_CAGE = ℰ_FLUID × ℰ_false_cert × ℰ_irreversible。核心判据：**假证书比无证书更危险**——它取消了 R69 仅存的怀疑。

**定义 325（单调降级与严格包含）** 监控残差（特征 innovation、证书残差、力/滑移、覆盖率）超阈 ⇒ 证书作废，按 absorb → reduce → retreat 降级，且 λ 单调不降。当 𝒢_R = ∅、或 U_epi^sem 主导、或 J_CAGE 失效时，控制器逐指令等于 R69（定理 18）。

## 2. 关键算法骨架

```python
# IP-264 PBA：高置信信念集（conformal 位姿区域 + 形状集）
def belief_set(z, o):
    q_hat, scores = pose_head(z)
    Q     = conformal_region(scores, alpha=ALPHA, calib=CALIB)
    delta = radius(Q, metric=SE3_WEIGHTED)          # δ_α
    return BeliefSet(Q=Q, q_hat=q_hat, delta=delta, shape=shape_head(z))

# IP-265/266/267 证书-δ：标称裕度减去 Lipschitz × 信念半径
def cert_radius(M_nom, tau, L):
    return (M_nom - tau) / max(L, 1e-9)              # r_c = (M-τ)/L

def robust_grasp_set(B, cloud, q_min):
    out = []
    for g in geometric_grasp_candidates(cloud, B.q_hat):
        if not kinematically_reachable(g) or collides(g): continue
        r_cage  = cert_radius(cage_margin(g, B.q_hat),   TAU_CAGE, L_RHO)
        r_fc    = cert_radius(fc_quality(g, B.q_hat),    q_min,    L_Q)
        r_servo = cert_radius(servo_mu(g, B.q_hat),      MU_REQ,   L_MU)
        A = min(r_cage, r_fc, r_servo)               # 吸收度
        if A >= B.delta and fc_quality(g, B.q_hat) >= q_min:
            out.append(Grasp(g, A, utility_lcb(g, B)))   # 认证下界
    return out

# IP-268 RIE：吸收 / 消解 / 退避（用认证下界做 maximin）
def rie_arbitrate(robust, ask, baseline):
    if robust:
        g_best = max(robust, key=lambda x: x.utility_lcb)
        if g_best.utility_lcb >= ask.lcb and g_best.utility_lcb >= baseline:
            return ("absorb", g_best)
    if ask.lcb > baseline:                           # VoI > c_int + 风险折价
        return ("reduce", ask.g)                     # 只对语义不确定问
    return ("retreat", None)                         # R68 λ_floor

# IP-269 SCE：伺服 → 笼闭 → 确认 → 搬运（全程证书监控）
def servo_execute(g, B, monitor):
    while not at_pregrasp(g):
        e     = features() - g.s_star
        v     = -LAMBDA * pinv(interaction_matrix(g.q_hat)) @ e   # IBVS
```

## 3. 推导

**引理 19（笼闭裕度即鲁棒笼闭）** 若 ℬ_α ⊆ B(q̂, ρ_cage) ⊆ 𝒦(q̂)，则对每个 q ∈ ℬ_α，q 仍处于被手指围住的有界连通分量中，即 g 对 ℬ_α 一致笼闭；由定义 312 的 Lipschitz 下界，ρ(q) ≥ ρ(q̂) − L_ρ δ_α，故 δ_α ≤ (ρ(q̂) − τ_cage)/L_ρ 即充分。要点：笼闭是拓扑性质，不依赖精确接触力方向；这解释了为什么它比力封闭更抗位姿误差——**它把「精确」换成了「围住」**。

**引理 20（有界交互矩阵误差下的伺服收敛）** 设 e = s − s*，v = −λ L̂_s^+ e。若在 ℬ_α 上 μ = λ_min(sym(L̂_s^+ L_s)) ≥ μ_req > 0，则 V̇ = e^T(L_s v) ≤ −2λμ V + e^T d，故 ‖e(t)‖ ≤ ‖e(0)‖e^{−λμ t} + ‖d‖/(λμ)。因此存在证书盆地 ℛ(g)，且 ℬ_α ⊆ ℛ(g) 时收敛性对位姿/标定误差一致成立。要点：**不必先知道位姿，只要闭环在信念集上一致收缩**；这把估计问题转成了控制问题。

**引理 21（反馈免费信息主导付费消解）** 沿任务必经的伺服轨迹，第 t 步特征给出 Fisher 信息 I_t(q) = L_s^T Σ_s^{-1} L_s，位姿后验熵下降至少 ΔH_free(T) = ½ log det(I + Σ_q Σ_t I_t)。在 A103（无需额外绕行与额外注视）下，VoI_free = ΔH_free(T) ≥ 0，且 cost_free = 0 < c_int + risk_poison。于是对 U_epi^geo，若存在认证伺服，则吸收在「信息收益/成本」上弱支配 R69 的问询。系：R70 的问询次数 N_ask(R70) ≤ N_ask(R69)，而 R69 的投毒错误率上界 δ_p·ρ^{k−1}+ε_σ（引理 18）随之只在语义子空间生效。

**引理 22（RIE 的严格包含与最坏情形无 regret）** 定义 318 用认证下界比较各选项，故被选选项的 LCB 不低于任意备选，即对 ℬ_α 内的最坏情形不劣于任一备选（maximin 无 regret）。当 𝒢_R = ∅ 时 LCB_abs = −∞，判定退化为「LCB_ask > 基线」，在期望效用近似下即 R69 的「VoI > c」。故 R69 是 RIE 在「无可认证鲁棒动作」边界上的严格退化。

**定理 18（CAGE 严格包含 R69）** 在 A100–A103 下，CAGE 的两阶段策略（先吸收，后消解/退避）在任意状态上的最坏情形风险 ≤ R69；且当 𝒢_R = ∅、U_epi^sem 主导、或 J_CAGE 失效时，两者**逐指令相同**；同时在相同任务上 N_ask(CAGE) ≤ N_ask(R69)。因此 R69 是 CAGE 在「结构吸收不可行」边界上的退化：安全侧不做让步，交互侧严格更省。

**定理 19（认证承诺安全 / 无不安全承诺）** 若执行抓取携带有效 J_CAGE、伺服经 CBF 滤波（定义 320）、且在线监控在工作，则对 ℬ_α 内任意真值位姿（以 ≥ 1−α 的校准覆盖概率），接触力/力矩不越限、物体在搬运全程保持笼闭；一旦监控反证证书，系统在施加任何不安全力之前按 absorb→reduce→retreat 单调降级。故抓取承诺是**对信念集认证**的，不是对点估计认证的。注意：覆盖是边际的（A100），分布漂移下需重新校准，否则结论不成立。

**定理 20（估计–鲁棒性对偶 / Pareto 扩张）** 设任务收益随「位姿精度」边际递减、随「交互预算」线性计价。R69 的可达前沿为 {(J, b) : b ≥ c·(估计误差)}，其代价由「必须先把误差压到抓取容限」决定。R70 用两条通道放宽该约束：结构吸收把容限 δ 放大到 A(g)，反馈吸收把有效误差压到伺服稳态球 ‖d‖/(λμ)。故 R70 可达集包含 R69 可达集，且前沿拐点满足 C_R = VoI_paid − c_int：低于拐点吸收更便宜，高于拐点问询更便宜。系（推论 1）：因为吸收不产生问询，攻击面（幻影追问、投毒采纳）随前沿向左移动单调收缩。

## 6. 本轮最大风险

**一句话**：CAGE-RAS 的全部安全性押在「信念集 ℬ_α 真的包含真值、且几何/手指/物体模型足够真」这一前提上——**一旦 conformal 覆盖因分布漂移失效、或物体可形变/模型有误，证书就变成假证书，而抓取是不可逆的物理承诺；系统会带着一张错误的证明去合拢、抬起，并且因为「已经证明过了」反而取消了 R69 那点宝贵的怀疑**——**一张错的证书，比没有证书更危险**。

**次级风险与缓解**：
1. **不可逆承诺放大错误** → 定义 319 四阶段 + 在线反证 + 定义 325 单调降级；先合拢确认再抬升；
2. **信念集覆盖失效（非可交换/漂移）** → E307 覆盖监控 + 漂移触发重校准 + 覆盖不达标即禁吸收；
3. **几何/手指模型误差或可形变物体** → 拓扑证书失效即退化；对可形变只用保守力封闭 + 力反馈；
4. **IBVS 局部极小/深度偏差/特征丢失** → 证书盆地过近似 + 可见性耦合 VGC + PBVS 优雅降级 + CBF；
5. **力封闭在信念边界处被高估** → 用 Lipschitz 下界而非采样点，最坏质量 Q_min 直接进证书。

**定义 323–325（证书/威胁/降级）** J_CAGE 并入覆盖、δ_α、A(g)、各裕度、盆地包含、免费 VoI、监控违规；ℰ_CAGE = ℰ_FLUID × ℰ_false_cert × ℰ_irreversible；监控残差超阈即证书作废、λ 单调不降、逐指令退化 R69。

## 4. 推导

**引理 19（笼闭裕度即鲁棒笼闭）** `ℬ_α ⊆ B(q̂,ρ_cage) ⊆ 𝒦(q̂)` ⇒ 对每个 q∈ℬ_α，q 仍在被手指围住的有界连通分量中，故 g 对 ℬ_α 一致笼闭；由 `ρ(q) ≥ ρ(q̂) − L_ρ δ_α`，`δ_α ≤ (ρ(q̂)−τ_cage)/L_ρ` 即充分。要点：笼闭是**拓扑**保证，把「精确」换成「围住」。

**引理 20（有界交互矩阵误差下的伺服收敛）** 若 ℬ_α 上 `μ=λ_min(sym(L̂_s^+ L_s))≥μ_req>0`，则 `‖e(t)‖ ≤ ‖e(0)‖e^{−λμt} + ‖d‖/(λμ)`；故存在证书盆地 ℛ(g)，ℬ_α⊆ℛ(g) 时收敛对位姿/标定误差一致成立。要点：**不必先知道位姿，只要闭环一致收缩**。

**引理 21（反馈免费信息主导付费消解）** 伺服沿任务必经轨迹给出 Fisher 信息 `I_t=L_s^TΣ_s^{-1}L_s`，`ΔH_free(T)=½logdet(I+Σ_qΣ_t I_t)`；A103 下 `VoI_free≥0` 且 `cost_free=0 < c_int+risk_poison`。故对 U_epi^geo，认证伺服弱支配 R69 问询。系：`N_ask(CAGE) ≤ N_ask(R69)`，投毒错误率上界只在语义子空间生效。

**引理 22（RIE 严格包含与最坏情形无 regret）** 用认证下界比较 ⇒ 被选选项 LCB 不低于任意备选（maximin 无 regret）；𝒢_R=∅ 时 `LCB_abs=−∞`，退化为 R69 的 `VoI>c`。故 R69 是边界退化。

**定理 18（CAGE 严格包含 R69）** A100–A103 下 CAGE 最坏情形风险 ≤ R69；且 𝒢_R=∅、U_epi^sem 主导、或 J_CAGE 失效时**逐指令相同**；同时 `N_ask` 不增。安全不让步，交互更省。

**定理 19（认证承诺安全 / 无不安全承诺）** 有效 J_CAGE + CBF + 在线监控 ⇒ 对 ℬ_α 内任意真值（以 ≥1−α 覆盖概率）接触力/力矩不越限、搬运全程笼闭；监控反证时在任何不安全力之前单调降级。注意覆盖是边际的，分布漂移需重校准。

**定理 20（估计–鲁棒性对偶 / Pareto 扩张）** 结构吸收把抓取容限放大到 A(g)，反馈吸收把有效误差压到 `‖d‖/(λμ)`；故 R70 可达 (性能, 交互预算) 集包含 R69，前沿拐点满足 `C_R = VoI_paid − c_int`。系（推论 1）：吸收不产生问询，攻击面随前沿左移单调收缩。

## 7. 本轮最大风险

**一句话**：CAGE-RAS 的全部安全性押在「信念集 ℬ_α 真的包含真值、且几何/手指/物体模型足够真」这一前提上——**一旦 conformal 覆盖因分布漂移失效、或物体可形变/模型有误，证书就变成假证书，而抓取是不可逆的物理承诺；系统会带着一张错误的证明去合拢、抬起，并且因为「已经证明过了」反而取消了 R69 那点宝贵的怀疑**——**一张错的证书，比没有证书更危险**。

**次级风险与缓解**：不可逆承诺放大错误（四阶段 + 在线反证 + 单调降级）；信念集覆盖失效（E307 监控 + 漂移重校准 + 不达标禁吸收）；几何/手指模型误差或可形变（拓扑证书失效即退化，只保留保守力封闭 + 力反馈）；IBVS 局部极小/深度偏差/特征丢失（证书盆地过近似 + VGC + PBVS 降级 + CBF）；力封闭在信念边界被高估（用 Lipschitz 下界，最坏质量 Q_min 直接进证书）。
