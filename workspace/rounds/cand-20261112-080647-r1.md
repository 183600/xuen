# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「具身智能大模型」×「6D位姿估计」）

> 第 57 轮把承诺的赌注从"模型置信"推到"证据质量"：少样本元先验、跨模态对账、个性化信任三条腿，使"证据说可信"成为可校准、可对账、可审计的门。但它留下一个更深的裂缝：**证据的"语义"和"几何"从未被分开审问**。第 57 轮的模态 ℳ={vis,tap,prop,acou} 仍全是"同一物理场景的多种读数"；而具身智能大模型给出的恰恰是**关于场景的语义断言**（"那是杯子、手柄朝右、可抓"），6D 位姿估计给出的恰恰是**关于刚体变换的几何断言**（位置 + 姿态 + 不确定度）。两者是两类本质不同的知识：语义便宜、宽泛、却不可直接证伪；几何昂贵、狭窄、却可度量、可证伪。若无脑相信前者，系统会"流畅地胡说"；若无脑相信后者，系统会在对称/遮挡物体上"精确地错 180°"。本轮的核心不是再叠一层模态，而是把架构分成**猜想机（conjecture）与证伪机（refutation）**：具身大模型只负责生成与排序假设，6D 位姿 + 接触探针负责证伪与出具证书；不可逆承诺只能由"活过证伪"的假设获得。核心命题由"证据说可信"升级为 **"语义可猜想、几何可证伪、提议有界的接地承诺"**。

核心矛盾：
- **H29（语义流畅 vs 几何接地）**：具身大模型越强，越能用流畅语言给出高置信的"是什么/在哪里/能做什么"；但语言置信不是关于物理接触的证据。语义断言与几何事实之间没有天然的同构，模型可以自信地说出一个场景里根本不存在的"手柄"。
- **H30（位姿精确 vs 对称/遮挡歧义）**：6D 位姿给出可度量的刚体变换，但对称/无纹理/被遮挡物体的位姿是多峰或流形（商空间 SE(3)/S_o），一个"高置信单点"可能在对称群下完全等价却让接触点错到物体另一侧；位姿误差也不等于接触失败风险。
- **H31（大模型更新 vs 接地漂移）**：大模型迭代提升泛化，却会**静默改变接地行为**（对象指称、幻觉画像、affordance 边界）；没有接地回归证书的模型升级，等于对一个安全关键判定器做了未审计的换芯。

## 0. 直觉与动机

**灵感 1（具身大模型 → 猜想机，不是决策机）**
直觉：把 VLA/具身大模型当"大脑"而不是"手"。它的价值不在"直接输出动作"，而在**用万亿 token 的先验替我们把假设空间排好序**——先猜"那大概率是一个能抓的把手"，再由几何与接触去证实/证伪。若让它的 action head 直连执行器，语言置信就偷偷变成了物理承诺，第 53~57 轮辛苦建起的证据门被一条端到端通路绕过。正确姿势是：**提议必须被编译成可度量的几何谓词**（指称解析、接触点、接近方向、可达性），未接地（ungrounded）的提议只能作为探索候选，永远不能单独充当证据。大模型的置信 c 只用于排序假设、分配探索预算，**不进入任何似然/风险计算**。

**灵感 2（6D 位姿 → 证伪机与几何锚）**
直觉：语义说"手柄在右边"，几何问"物体的坐标系到底在哪、朝向如何、你的末端相对它在哪里、误差多大"。真正与接触相关的量不是绝对位姿，而是**末端—物体相对位姿** T_eo=T_e^{-1}T_o 及其传播不确定度；位姿证书把这份不确定度**前推到接触点与法向** Σ_c，若 √tr(Σ_c)>ε_c，则"说得再对也碰不得"。对称物体更狠：位姿只在商空间 SE(3)/S_o 上有定义，沿稳定子 S_o 的位姿误差对接触毫无影响，但任何"假定了一个具体朝向"的规划都可能把接触点甩到错误一侧——所以要么动作对 S_o 等变，要么必须先消歧。

**灵感 3（语义-几何对账 SGR → 幻觉下限与接地证据）**
直觉：第 57 轮用"跨模态分歧"给不确定性设下限；本轮把对账轴换成**语义 vs 几何**。大模型说"那里有个可抓把手"，位姿证书说"该区域几何上不可达/无稳定接触面"，这个分歧不是噪声，而是**幻觉的告警**——分歧越大，越应加宽或拒绝，绝不平均掉。反过来，当语义指称唯一、affordance 与几何可行域一致、且对称性不冲突时，"语义-几何一致"本身成为一类新证据 EV-ground；但它本质仍是两条软管道的共识，**只可在 L1 非不可逆层替代一次佐证，绝不进入不可逆接触的必要证据集**（与 EV-xmodal 同等待遇，理由同源：共谋风险）。

**灵感 4（对称商 + 主动消歧 → 把"看错"变成"多看"）**
直觉：位姿歧义不是靠调大网络就能消除的，它是**信息不足**。与其赌一个单点，不如显式维护可容许集 [𝒯]（协方差椭球模对称群），并在歧义大时**主动花一次视角/微动/轻触去降熵**：选使可容许集体积（或位姿熵）期望下降最大的观测动作，受安全约束、有预算 k_aps。对称物体上若消歧成本高，就退而求其次要求动作对 S_o 等变（例如绕对称轴抓取），用"不改结果"换"不必知道"。这把第 57 轮"探询"从"探物理参数"扩展到"探几何位姿"，且同样走 VOI 悲观通道。

**灵感 5（合流 → 证据门七类、提议者信任、PGVE 闭环）**
直觉：把大模型也当作第 57 轮 PTM 里的"操作者"——一个可犯错、可被审计、影响力必须靠事后证实赢得的**提议者**，只是它的"授权"只调节"提议的优先级与探索配比"，永不调节证据门本体。第 57 轮"一切判定器走隔离"本轮推广为"**一切提议者（含具身大模型）先接地、再入证伪、后方可承诺**"；证据门从五类扩到七类（新增 EV-pose、EV-ground），不可逆接触的必要条件新增"位姿证书有效 ∧ 对称性已解或动作等变"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（具身大模型接地提议 EFP）** 提议者 g（版本 u_g）输入 (视觉流 I_{1:t}, 语言目标 ℓ, 对象记忆 O) 输出类型化提议集 Π_g={(κ,ρ,a,c,u_g)}：κ∈{object_ref, affordance, contact_point, grasp_pose, subgoal}，ρ 为指称表达式，a 为参数，c 为模型自报置信（**非证据**）。接地编译器 Γ 把 Π_g 编译为几何谓词集 Φ={φ_j=(pred_j, r_j, τ_j)}，每个谓词对应可测残差 r_j 与容差 τ_j。称提议**已接地**当且仅当：①所有指称 ρ 唯一解析到姿态跟踪中的对象实例；②每个 φ_j 的全部自由量可由 T_o/机器人状态测得；③无未声明歧义。未接地提议只能进入探索候选池，**禁止进入证据门**。c 仅用于候选排序与探索配比，不参与任何似然或风险聚合。

**定义 140（6D 位姿几何证书 6DG）** 对象 o 的真实位姿 T_o∈SE(3)，估计器输出 (T̂_o, Σ∈R^{6×6}, S_o, V)：S_o⊂SE(3) 为声明的对称群（离散稳定子或连续），V 为有效性条件（遮挡率、运动状态、视野、时间戳、纹理/光照）。**可容许集** 𝒜_o(α)={T: ξ(T̂_o^{-1}T)^⊤Σ^{-1}ξ(·)≤χ²_6(1−α)}，其中 ξ=log∨ 为 SE(3) 对数映射；位姿只在商空间 [T]_o=T·S_o 上有意义。**接触相关量**为相对位姿 T_eo=T_e^{-1}T_o，其协方差 Σ_eo=J_eo Σ J_eo^⊤（J_eo 由复合与逆的雅可比给出）；再前推到接触点 x_c 与法向 n_c：Σ_c=J_c Σ_eo J_c^⊤。证书**有效**当且仅当 V 成立 ∧ age≤τ_pose ∧ 未检出对象运动 ∧ √tr(Σ_c)≤ε_c。对称语义：若动作不在 S_o 下等变，则必须先消歧至 diam(𝒜_o/S_o)≤ε_o，否则位姿歧义对不可逆接触为**硬阻断**。

**定义 141（语义-几何对账 SGR）** 对每条已接地提议 π 与区域/对象几何事实，定义三元分歧
D_sg(π)=w_id·1[ρ 指称非唯一] + w_aff·dist(接触流形(π), 几何可行接触流形(o))/scale + w_sym·1[π 假定朝向 ∉ S_o-不变类]。
规则：(R1) D_sg>θ_sg ⇒ 拒绝/加宽，并排程主动消歧或转人；(R2) **EV-ground** ⇔ 指称唯一 ∧ D_sg≤θ_sg ∧ 语义与几何管道独立声明（误差源不同，非共享同一视觉骨干）∧ 约束级 ≤L1；仅可替代一次 L1 佐证，**不得进入不可逆接触必要证据集**；(R3) 事后归因：若证实为语义幻觉 ⇒ 降提议者信任 a_g；若证实为位姿错误 ⇒ 降该对象/材质类的位姿证书置信并触发重标定，历史证据回溯标记（承第 57 轮 R3）。

**定义 142（主动位姿/对称消歧 APS）** 消歧动作集 U_aps={next-best-view, 末端微动视差, 候选点轻触, 重观测}；安全过滤后选 u\*=argmax_u E[ΔH([𝒯])−λ·cost(u)]，E[·] 用当前位姿后验，ΔH 为可容许集熵/体积的期望下降（对称情形用商体积）。终止条件：diam([𝒯])≤ε_o ∨ 对称已解 ∨ 动作可声明 S_o-等变 ∨ 预算 k_aps 耗尽；耗尽仍未解 ⇒ 保守降档/绕行/协商，**不得以单点 T̂ 承诺不可逆接触**。

**定义 143（接地证据门 GEG 与证书 J_g）** 证据类七类：EV-probe\* / EV-visit / EV-margin / EV-xmodal / **EV-pose**（有效 6DG 证书）/ **EV-ground**（定义 141 R2）/ EV-human。**不可逆接触必要证据集** = {EV-pose ∧ (EV-probe\*∨EV-margin)} ∪ 佐证，且"对称已解或动作等变"；EV-ground、EV-xmodal 均不得替代 EV-pose，也不得进入不可逆必要集。大模型提议单独永不为证据。证书 J_g=(J_p 全继承, pose_certs, symmetry_decls, grounding_traces, referent_resolutions, D_sg_log, aps_log, fm_version, grounding_regression)，其中 J_p 为第 57 轮少样本-跨模态-个性化证书。

**定义 144（提议-接地-验证-演化 PGVE）** 每任务/检查点：①提议（EFP，按 a_g 调优先级）；②接地（Γ，未接地→探索池）；③位姿证书校验（6DG，失效→重估/APS）；④SGR 对账（分歧→消歧/拒绝）；⑤风险评估与证据门（GEG）；⑥承诺⇔∃g:R≤δ_f(g) ∧ GEG 过；否则 argmax 悲观 VOI（含位姿熵项）探询、绕行、降档、L2 协商或安全停；⑦事后验证→更新 a_g、位姿置信、语义/几何归因。VOI 悲观估计把 D_sg 与 diam([𝒯]) 计入风险上界。

## 2. 关键算法伪代码（完整版见产物区）

```python
def grounded_propose(g, I, goal, M, a_g):            # IP-139: 只提议不决策
    props = g.propose(I, goal, M.objmem, version=g.v)
    out = []
    for p in props:
        phi = ground_compile(p, M)                    # 指称→对象实例，参数→几何谓词
        if phi is None or not unique_referent(p, M):
            out.append(('explore_only', p)); continue # 未接地：禁入证据门
        out.append(('grounded', p, phi))
    return rank(out, key=lambda x: a_g.priority(x))    # c 仅排序，不进似然

def pose_certificate(o, t):                           # IP-140: 几何锚
    T, S, Sig, V = o.track.at(t)
    if not valid(V, t) or object_moved(o, t) or age(o, t) > tau_pose:
        return None                                    # 过期/运动→证书失效
    Ac = admissible_quotient(T, Sig, S, alpha_pose)    # 商掉对称群
    Sc = pushforward_contact(Sig, T, robot.x)
    return Cert(T=T, sym=S, adm=Ac, contact_sig=Sc,
                ok=(sqrt(trace(Sc)) <= eps_c and diam(Ac/S) <= eps_o))

def semantic_geometric_reconcile(pi, cert, o):        # IP-141
    D = w_id * (0 if unique_referent(pi, M) else 1) \
      + w_aff * manifold_dist(pi.contact, o.feasible_manifold) / scale \
      + w_sym * (0 if is_sym_invariant(pi, cert.sym) else 1)
    if D > theta_sg: return ('widen_or_deny', D)
    return ('EV-ground?' , D)                         # 仅 L1 可入证据，不可逆禁用

def active_pose_disambiguate(o, cert, budget):        # IP-142
    while diam(cert.adm / cert.sym) > eps_o and budget.aps_left > 0:
        u = argmax(admissible_views(o, cert), key=lambda u: exp_entropy_drop(o, u) - lam*cost(u))
        execute_safe(u); o = reestimate(o); budget.spend_aps(u)
        cert = pose_certificate(o, now())
    return cert, (cert.ok or is_sym_invariant_plan(o))
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| EFP | O(\|Π_g\|·d_Γ) | O(\|Π_g\|) | 类型化提议、Γ 健全、c 不入似然 |
| 6DG | O(d_pose^3) 位姿/证书 | O(\|O\|·d_pose) 跟踪 | 协方差传播、对称声明、时效/运动检测 |
| SGR | O(\|Π_g\|·d_Φ) | O(\|Π_g\|) | 分歧保守、指称唯一、独立声明 |
| APS | O(k_aps·C_view·d_pose) | O(\|𝒜_o\|) | 熵降序、安全过滤、终止 |
| GEG | O(\|σ\|+\|O\|) | O(\|σ\|) | EV-pose 必备、EV-ground 限 L1 |
| PGVE | O(\|CP\|·(k_p+k_c+k_aps)·(C_VOI+d_pose)) | O(\|V\|+\|O\|+\|σ\|) | 悲观 VOI、三预算终止 |

**正确性定理（Semantic-Geometric Grounded Soundness, SGGS 概要）**：在 A33–A40 上加 (A41) 提议类型化 ∧ Γ 健全且对未接地提议拒识；(A42) 位姿证书校准：真值落入 𝒜_o(α) 概率 ≥1−α_pose、S_o 声明诚实、协方差传播健全、失效检测（运动/过期）无漏；(A43) 条件独立仅在 EV-ground 使用处被要求且仅限 L1；(A44) 提议者信任单向有界（同 A39）、大模型升级须过接地回归。则：(i) 不可逆承诺失效率 ≤ δ_f+ε_meta+δ_probe+ε_h+ε_pose+ε_Γ，EV-ground 仅贡献于 L1；(ii) **幻觉隔离**：g 只能改变候选排序与探索配比，任何语义错误只能浪费预算或触发保守停，无法直接升险；(iii) **对称安全**：S_o 声明且动作 S_o-等变时，沿 S_o 的位姿误差不改变接触结果；否则须 diam(𝒜_o/S_o)≤ε_o；(iv) PGVE 在 k_probes+k_cons+k_aps 内终止于 {承诺,绕行,L2,安全停}。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 位姿证书"声明性错误"（对称未列全/镜面/透明） | 高 | 对称/材质披露审计、主动消歧、证书时效、EV-ground 不进不可逆 |
| 接地编译器成为新单点 | 高 | 类型化谓词、未接地拒识、回归测试、可退回纯几何路径 |
| 大模型版本静默漂移 | 中高 | 接地回归证书（指称/幻觉/affordance 分布不劣化）后才接管 |
| SGR 语义-几何共享视觉骨干→伪独立 | 中 | 强制不同骨干声明、EV-ground 限 L1、事后归因回溯 |
| APS 增加节拍时延 | 中低 | 预算 k_aps、可等变方案替代、预取与异步 |

## 6. 本轮最大风险

**一句话**：本轮把安全的赌注从"证据质量"进一步押到"位姿证书的声明诚实"——一旦对称群/材质/遮挡的有效性条件被低估（例如把镜面或近对称物体当成一般刚体），一个**看似落在 ε_c 内、实则系统性错误**的 6D 位姿会同时骗过接地编译器和语义-几何对账，而具身大模型的流畅提议与 EV-ground 的一致性加成会让这个错误更快获得承诺；必须以"对称/材质显式披露 + 主动消歧 + 证书时效/运动检测 + EV-ground 仅限 L1 + 大模型永不单独为证"五重护栏，宁可不碰，也不拿一个未审的坐标系去碰。

### IP-139 EFP（具身大模型接地提议：猜想机）

```python
def propose_and_ground(g, I, goal, M, a_g):
    props = g.propose(I, goal, objmem=M.objmem, version=g.u)   # 类型化提议
    grounded, explore = [], []
    for p in props:                                            # p=(κ,ρ,a,c,u)
        if not unique_referent(p.rho, M, within=p.context):
            explore.append(p); continue                        # 指称不唯一→仅探索
        phi = ground_compile(p, M)                             # Γ: 编译成可测几何谓词
        if phi is None or any(not measurable(q, M, robot) for q in phi):
            explore.append(p); continue                        # 未接地→禁入证据门
        grounded.append(Proposal(p, phi, referent=resolve(p.rho, M)))
    # c 只用于排序/探索配比，绝不进入似然或风险聚合
    return sorted(grounded, key=lambda x: a_g.priority(x)) + explore

def ground_compile(p, M):                                      # 示例：contact_point
    o = resolve(p.rho, M)
    if o is None: return None
    T = M.pose[o]                                              # 仅引用证书，不在此重估
    x = T.transform(p.a.x_local); n = T.rotate(p.a.n_local)
    return [('reachable', reach_residual(x), tau_reach),
            ('collision_free', clearance(x, M), tau_clear),
            ('contact_normal', angle(n, p.a.n_local), tau_norm)]
```

### IP-140 6DG（6D 位姿几何证书：证伪机与锚）

```python
def pose_certificate(o, t, robot):
    T, S, Sig, V = o.track.at(t)
    if not conditions_hold(V, t):        # 遮挡/光照/视野
        return Cert(ok=False, why='invalid_conditions')
    if object_moved(o, t) or (t - o.track.stamp) > tau_pose:
        return Cert(ok=False, why='stale_or_motion')          # 证书必须新鲜
    adm = admissible_quotient(T, Sig, S, alpha_pose)           # SE(3)/S_o 椭球
    Teo = inv(robot.T_e) @ T                                   # 接触相关量
    Sig_eo = J_compose(Sig, robot.T_e, T) @ Sig @ J_compose(...).T
    Sig_c  = J_contact(Sig_eo, Teo, x_c)                      # 前推到接触点/法向
    ok = (sqrt(trace(Sig_c)) <= eps_c) and (diam_quotient(adm, S) <= eps_o)
    return Cert(ok=ok, T=T, sym=S, adm=adm, contact_sig=Sig_c,
                stamp=t, cond=V, version=o.estimator.u)

def is_sym_invariant_plan(plan, S):
    # 对称物体上的"等变换结果"：绕对称轴的抓取/逼近不依赖被消去的那一自由度
    return all(equivariant(step, S) for step in plan.steps)
```

def semantic_geometric_reconcile(p, cert, o):
    D_id  = 0.0 if unique_referent(p.rho, M) else 1.0
    D_aff = manifold_dist(p.contact_region, o.feasible_manifold) / scale
    D_sym = 0.0 if is_sym_invariant(p.assumed_orientation, cert.sym) else 1.0
    D = w_id * D_id + w_aff * D_aff + w_sym * D_sym
    if D > theta_sg:
        return ('deny_or_widen', D, 'schedule_aps_or_human')   # 幻觉/歧义告警
    # 一致只在 L1 且两管道独立声明时成为证据
    if constraint_level(p) <= 'L1' and independent_pipelines(p, cert):
        return ('EV-ground', D, None)
    return ('consistent_no_evidence', D, None)                 # 不可逆层不采信

def grounded_evidence_gate(c, M, persona, ood_reg, fm):
    if c.ev == 'EV-pose':
        cert = c.cert
        ok = cert and cert.ok and fresh(cert) and not object_moved(c.obj, cert.stamp)
    elif c.ev == 'EV-ground':
        ok = (c.level == 'L1' and c.indep_declared and c.D_sg <= theta_sg)
    elif c.ev == 'EV-probe*':
        ok = (c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)) or \
             (c.inf.cls == 'OOD' and c.region in ood_reg.certified)
    elif c.ev == 'EV-xmodal':
        ok = (c.level == 'L1' and c.indep_declared and D(c.region) <= theta_D)
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and c.corrob >= quarantine_exit(persona[c.op].auth)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round56_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok: return ('reject', 'evidence_insufficient', c)

    # 不可逆接触硬约束：EV-pose 必备 + 对称已解或动作等变 + 物理探针/裕度
    if c.irreversible:
        if c.ev in ('EV-ground', 'EV-xmodal'):
            return ('reject', 'soft_evidence_on_irreversible', c)
        if not (c.has_pose and c.has_probe_or_margin):
            return ('reject', 'pose_or_probe_missing', c)
        if not (c.sym_resolved or c.sym_invariant):
            return ('reject', 'pose_ambiguity', c)
    if fm.proposed_only and c.ev == 'EV-fm':
        return ('reject', 'fm_not_evidence', c)                 # 大模型永不为证
    return ('ok', c)

def map_grounding_certificate_jg(sched, log, M, pose_certs, grounding_traces, aps_log,
                                 fm_version, grounding_regression):
    for c in contacts(sched):
        if grounded_evidence_gate(c, M, persona_of(c), ood_reg, fm)[0] != 'ok':
            return ('reject', c)
    if not grounding_regression.passed(fm_version):             # 大模型升级回归
        return ('reject', 'fm_grounding_drift')
    if any(not fresh(x) for x in pose_certs): return ('reject', 'stale_pose')
    return ('ok', Jg(M.core, pose_certs, symmetry_decls, grounding_traces,
                     referent_resolutions, D_sg_log, aps_log, fm_version))

### IP-144 PGVE（提议-接地-验证-演化闭环）

```python
def propose_ground_verify_evolve(x0, M, task, budget, consent, personas, fm):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        props = propose_and_ground(fm, I=cp.obs, goal=task.goal, M=M, a_g=fm.trust)
        best = None
        for p in props:
            o = p.referent
            cert = pose_certificate(o, now(), robot)
            if cert is None or not cert.ok:
                cert = active_pose_disambiguate(o, cert or pose_certificate(o, now(), robot), budget)
            if cert is None: continue                          # 消歧失败→跳过该假设
            st, D, act = semantic_geometric_reconcile(p, cert, o)
            if st == 'deny_or_widen':
                if act == 'schedule_aps_or_human': budget.note_sgr(o)
                continue
            best = (p, cert, D); break
        if best is None:
            return reroute_or_safe_stop(cp, M, task)           # 无语义-几何一致假设→不碰
        p, cert, D = best
        sigma = foothold_schedule(x0, cp, M, contact=p.contact)
        R = schedule_risk(sigma, M, cert)                      # 风险含 Σ_c 与 D_sg
        evaluate_probe_or_commit(cp, p, cert, sigma, R, budget, consent)
        # 事后：归因语义幻觉 vs 位姿错误，单向更新
        fm.trust.update(verdict=verify(cp), attribution=attribute(cp))
        M.pose_reliability.update(cp, attribution=attribute(cp))
    return sched, log, M
```

| 组件 | 时间 | 空间 | 正确性保证 |

**正确性定理（Semantic-Geometric Grounded Soundness, SGGS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 提议类型化且接地编译器 Γ 健全：未接地提议必被拒识，已接地谓词可测且与实际几何一致；(A42)**位姿证书校准**：在声明条件 V 下真值落入 𝒜_o(α) 的概率 ≥1−α_pose，对称群 S_o 声明诚实（不漏列稳定子），协方差传播 Σ→Σ_eo→Σ_c 健全，时效与对象运动检测无漏；(A43) 语义与几何管道的误差条件独立仅在 EV-ground 使用处被要求，且 EV-ground 仅限 L1 非不可逆接触；(A44) 提议者信任 a_g 单向有界（升级需事后证实、降级实时），大模型版本升级须通过接地回归证书。则：

1. **不可逆承诺健全性**：P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + **ε_pose + ε_Γ**；EV-ground 仅在 L1 上贡献 ≤δ_sg，EV-xmodal 仅在 L1 上贡献 ≤δ_xm。
2. **幻觉隔离（无升险通路）**：具身大模型只能改变候选排序与探索配比；任何语义幻觉最多把预算浪费在不可行假设上或触发保守停/协商，不能绕过 Γ、6DG、SGR、GEG 任一环而直接提升承诺风险。即风险关于"提议者质量"单调不减。
3. **对称安全性**：若 S_o 被正确声明且规划对 S_o 等变，则沿 S_o 的位姿估计误差不改变接触点/接触结果；若规划不等变，则必须或满足 diam(𝒜_o/S_o)≤ε_o（消歧成功），或拒绝不可逆接触。
4. **终止性**：每检查点 APS ≤k_aps，PGVE 在 k_probes+k_cons+k_aps 内终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + ε_pose + ε_Γ + δ_sg·1[L1] + δ_xm·1[L1])
             − P(𝓜/对象跟踪陈旧未检出) − P(接地回归漏检) − P(护盾回退失败)
             − P(APS 超时 ∧ 未等变 ∧ 安全停失效)
```

关键：**语义给效率、几何给证明**（大模型的万亿先验只用于把假设排序，安全由 6D 位姿证书与探针证伪托底，两者解耦）；**EV-ground 用"仅限 L1"把语义-几何共谋的失败隔离在非不可逆层**；**对称商用"等变或消歧"消化位姿的多峰性**，避免"精确地错 180°"；**提议者信任把人也把模型统一成单向有界状态机**——模型可以越来越会'猜'，但永远不能更敢'赌'。

## 6. 本轮最大风险

**一句话**：本轮把安全的赌注从"证据质量"进一步押到"位姿证书的声明诚实"——一旦对称群/材质/遮挡的有效性条件被低估（如把镜面、透明或近对称物体当成一般刚体），一个**看似落在 ε_c 内、实则系统性错误**的 6D 位姿会同时骗过接地编译器与语义-几何对账，而具身大模型的流畅提议和 EV-ground 的一致性加成会让这个错误更快获得承诺；必须以"对称/材质显式披露 + 主动消歧 + 证书时效/运动检测 + EV-ground 仅限 L1 + 大模型永不单独为证"五重护栏，宁可不碰，也不拿一个未审的坐标系去碰。
