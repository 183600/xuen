# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 2 轮；本轮灵感：「材料选型」×「模型预测控制」）

> 第 57 轮把安全的赌注从"模型置信"推到"证据质量"，用元先验摊销、共形保底、跨模态对账与单向信任机层层兜住；它自陈的最大风险是"坏先验普遍"——元模型在语料盲区之外自信地错。但第 57 轮仍默认了两件从未被正面检验的事：**(i) 接触的模型类是对的**——它只估 μ、k、F_bear 这些参数，仿佛"用哪一类材料本构"这个更高层的选择不会错；可材料选型告诉我们，选错材料卡是**模型类错误**，再多参数更新也修不回来。**(ii) 每个检查点的决策是短视的、且承诺不损失未来**——它用贪婪 VOI 在当前点探到能走就承诺，却从不保证"承诺之后我还回得头、还分得清、还来得及证伪"。**材料选型**把先验变成有物理包络、有适用域、有退化律、有出处的**假设类**；**模型预测控制**把"探"与"诺"统一成同一个有限时域优化里的两种输入，并用管约束、终端安全停集与递归可行性给出"承诺之后仍可退"的保证。本轮把两个灵感合流为一个更硬的问题：**你以为你在估计参数，其实你可能选错了材料；你以为你在承诺，其实你可能已经把证伪能力用掉了。** 命题由"少样本可校准、跨模态可对账、个性化有界"升级为 **"材料可辨识、控制可对偶、承诺可递归证伪：先证模型类，再谈参数；先保退出权，再谈最优。"**

核心矛盾：
- **H29（模型类错误 vs 参数估计）**：第 57 轮的安全界里有一项 ε_meta(k)，它只覆盖"同一模型类内的参数误差"。若真实地面属于材料卡库里没有的类别，或选错了卡（把湿橡胶当干橡胶、把薄壳当实心），则后验可以又窄又错，且**任何探针都只是在错误的参数空间里做更精细的拟合**。安全的赌注再次后移：从"先验质量"后移到"假设类是否包含真相"。
- **H30（可辨识性 vs 激励）**：两种材料在**标称、温和、安全的激励**下可能给出几乎相同的观测（软垫把刚度差异低通掉、干湿在低法向力下都"看起来干"）；此时重复同一探针不增加信息。更尖锐的是：**最有区分力的激励往往最接近失效边界**（要估 F_bear 就得往 F_bear 附近压）——"能看清"与"看得起"之间存在结构性冲突。若系统把"我做过探针"误当成"我分得清"，它就会带着虚假的证伪能力进入不可逆接触。
- **H31（承诺 vs 未来可证伪性）**：第 57 轮的终止性只保证当前检查点能收场，不保证承诺之后仍存在安全停 + 继续辨识的可行计划。一次不可逆接触可能吃掉探针预算、封死回退通道、或让材料进入磨损区，使"以后再验证"永远不再可能。**短视 VOI 会为了眼前一步的收益，卖掉未来的证伪权。**
- **H32（材料退化 vs 证据寿命）**：材料不是常量：脚垫会磨、橡胶会老化、温度湿度会改 μ 与 k。第 57 轮的证据只有"空间/模态/操作者"维度，没有"磨损"维度。被验证过的材料与此刻踩着的材料可能已经不是同一种材料——**"坏证据长寿"在材料维度上变成"证据比材料活得久"。**

## 0. 直觉与动机

**灵感 1（材料选型 → 模型类是假设，先验要装物理包络）**
直觉：工程上的材料选型从来不是"查一个点值"，而是拿一张**材料卡**：性能是一个**包络**（μ∈[μ⁻,μ⁺]、k∈[k⁻,k⁺]、F_bear∈[F⁻,F⁺]），外加适用域（表面类别、湿度、温度、载荷）、失效模式（打滑、穿刺、下陷）、退化律与出处（数据表版本、测试条件）。把第 57 轮的元先验装进材料卡，先验就不再可以"任意自信"：**证据只能在包络内收窄，想越过包络必须换卡，而换卡要走隔离门。** 于是"坏先验"被降级为"坏包络"，而包络是可审计、可被真实锚实验证伪的。若一张卡都不适用，就退回**第一性原理硬包络**（库仑摩擦上界、承载力下界）并禁止不可逆接触——宁可又宽又慢，也不假装知道。

**灵感 2（材料选型 → 可辨识性是设计属性，不只是估计属性）**
直觉：软脚垫更稳、更柔顺，却把地面刚度信息低通滤掉；硬脚垫信息多，却更冲击、更易打滑。**选材同时决定了"能跑多稳"和"能看懂地面多少"。** 可辨识性不是估计器的事后性质，而是材料（脚垫）-传感-激励三者共同决定的**设计期属性**。所以选型目标里必须显式包含"可辨识性"，否则会在部署后才发现某两类材料对**永远分不开**——那时再多的探针也只是把同一个问题问很多遍。

**灵感 3（MPC → 探针是激励，承诺是另一种输入）**
直觉：对偶控制（dual control）早就指出，控制输入同时承担**调节**与**激励**两职。第 57 轮把"探"和"诺"当成两个阶段，用贪婪 VOI 在中间切换；MPC 把它们统一进一个有限时域优化：同一段输入序列里，有的步用来施加**有区分力的安全激励**以识别材料，有的步用来推进任务，约束是同一套模式鲁棒管约束。**何时探、探什么、探完走哪被联合优化**，而不是分阶段拍脑袋；并且因为只看未来 N 步、只执行第一步，它天然支持"探一步看一步"的滚动修正。

**灵感 4（MPC → 管约束把不确定性自动翻译成保守度）**
直觉：不必再手设 θ_K、θ_voi。把材料信念的支撑集经接触模型前向传播成**可达集（管）**，管的半径就是必须收紧的约束量：材料模式越多、信念越宽、磨损越不确定，管越粗，步态自动降档；探针一收窄信念，管变细，速度自动放开。**证据质量直接映射为控制激进度**，中间不需要人手调阈值——这正好补上第 57 轮"阈值全靠手设"的缺口。

**灵感 5（MPC → 递归可行性与终端安全停集：承诺必须保留退出权）**
直觉：MPC 的递归可行性说的是——若此刻存在可行计划，则在执行第一步并收到任何与模型一致的观测后，下一步仍存在可行计划。把它用到承诺上就是：**在按下不可逆接触之前，必须证明从任何可能观测出发，仍存在一条"到安全停 + 保留证伪能力"的可行计划。** 一次承诺如果把自己逼进无法再探、无法再退的窄通道，即使当下"证据够"，也不该被允许——这不是保守，而是**不拿未来的证伪权换当下的进度**。

**灵感 6（两灵感合流 → 材料-控制联合探-诺-演 PCE-M）**
直觉：材料卡给"可能的物理世界及其包络与退化"，MPC 给"在世界里如何既推进又做实验"，递归可证伪给"何时允许把实验变成承诺"。三者合流成一条新流水线：**先证卡有效 → 再证可辨识（合并不可分的等价类）→ 再证证据未随磨损过期 → 用模式鲁棒管 MPC 联合选激励与动作 → 在不可逆承诺前过递归可证伪门 → 只执行第一步并重规划。** 第 57 轮"一切判定器走隔离"在本轮推进为"**模型类也要走隔离，且承诺必须可递归证伪**"。

## 1. 形式化定义（增量：定义 139–145）

**定义 139（材料卡假设空间 MCS）** 材料库 ℒ={M_1,…,M_K}∪{M_∅}。每张卡 M=(𝒫,D,ℱ,𝒲,π)：性能包络 𝒫={μ∈[μ⁻,μ⁺],k∈[k⁻,k⁺],F_bear∈[F⁻,F⁺]}；适用域 D（表面类别/湿度/温度/载荷）；失效模式集 ℱ（滑移/穿刺/下陷）；退化律 𝒲：dθ/dt=w(M,load,slip)；出处 π（数据表/测试条件/版本/真实锚）。信念 b(m,θ)，θ∈𝒫_m。卡有效谓词 `Valid(M,s)=s∈D ∧ π 已登记 ∧ 包络覆盖 s`。M_∅ 为开集"以上都不是"，只携带第一性原理硬包络 𝒫_phys。规则：**(C1)** 证据只能在 𝒫_m 内收窄，越界必须换卡且换卡过隔离；**(C2)** 无有效卡 ⇒ 退回 𝒫_phys 且禁止不可逆接触；**(C3)** 卡准入/修订须在真实锚集上做影子验证（包络不劣化 ∧ 适用域不缩小 ∧ 失效模式不漏报）。

**定义 140（材料可辨识度与等价类 MID）** 安全激励集 `𝒰_safe(b)`（在当前管约束下允许的输入）。观测模型 p(y|m,θ,u)。成对可辨识度 `D(m,m')=max_{u∈𝒰_safe} KL(p(·|m,u)‖p(·|m',u))`（对 θ 取最坏）。若 `D(m,m')<ε_id` 称 **ε-不可分**，其等价类记 `[m]_ε`。规则：**(I1)** 安全计算在 [m]_ε 内取最坏，不取平均；**(I2)** 声称"区分了类内两卡"的证据得**零学分**（不产生 EV-ident）；**(I3)** 声称可分的必须附**可辨识证书** `J_id=(m,m',u*,D,ε_id,有效期)`；**(I4)** 若只有 `u*∉𝒰_safe` 才能区分，则标称承诺**本质不可辨识** ⇒ 只能用最坏包络或绕行；**(I5)** **伪可辨识**（声称能分而实际不能）是硬安全违规，须用留出激励审计。

**定义 141（磨损-退化与证据半衰期 WDA）** 退化状态 d(t)，性能漂移 `θ(t)=θ_0+∫w(·)dt`，漂移率界 `|dθ/dt|≤w_max`。证据 e 于 t_0 采得，其**陈旧量** `Δθ_e=w_max·(t−t_0)`。有效当且仅当 `Δθ_e≤ε_θ(M)`；**半衰期** `T_{1/2}=ε_θ/w_max`。再辨识调度：当 `age>T_{1/2}` 或累计载荷/滑移超阈或换垫/维护后触发。规则：**(W1)** 超过半衰期的证据不得支撑不可逆承诺；**(W2)** w_max 由滑移/载荷史在线更新，磨得越快半衰期越短；**(W3)** 维护重置 d 但必须重新辨识，重置不等于恢复信任。

**定义 142（模式鲁棒管与终端安全停集 MRT）** 信念支撑 `ℳ_t={m:P(m|·)>ε_m}`，逐模式可达集 `X_{k+1}^m=f_m(X_k^m,u_k)⊕W`；**模式鲁棒管** `𝒯_k=∪_{m∈ℳ_t}X_k^m`；收紧约束 `𝒳_k=𝒳_safe⊖𝒯_k`（Minkowski 腐蚀）。**终端安全停集** `𝒳_f=∩_{m∈ℳ_t}𝒳_f^m`，须对 ℳ_t 中每个 m 控制不变且 `𝒳_f⊆𝒳_stop`。**递归可行性**：若 t 时刻计划可行，则执行 u_t 并收到任何支撑内观测后，t+1 仍存在可行计划。规则：**(T1)** 承诺须在整段时域满足收紧约束；**(T2)** 终端集须模式鲁棒且在时域内可达；**(T3)** 管半径对信念宽度单调：信念越宽 ⇒ 管越粗 ⇒ 越保守（自动降档）；**(T4)** OOD/无有效卡 ⇒ 终端集退化为"只能安全停"。

**定义 143（对偶控制价值与安全相关 VOI DCV）** 时域 N、输入 u_{0:N−1}、模式信念 b。目标 `J=Σ_k[ℓ_task(x_k,u_k)+λ_risk·ρ(𝒯_k)−λ_info·I_k]`，其中 I_k 只计**决策相关**的信息：`SVOI(q)=E_o[max_{a∈A(b_o)}U(a)]−max_{a∈A(b)}U(a)`（或等价的最坏风险下降量）。若 `SVOI(q)<θ_svoi`，该探针无价值。激励预算 E_exc。规则：**(D1)** 探针是输入而非独立阶段；**(D2)** 信息只有改变可行动作集或降低最坏风险才计分，纯熵减不计；**(D3)** 信息有保质期（WDA）；**(D4)** 绝不在 𝒰_safe 之外激励；若不存在安全且有区分力的输入，则**不可辨识**，转保守。

**定义 144（递归可证伪证书 RFC）** 针对不可逆接触的计划 π（时域 H）。**证伪计划**：存在停时 τ≤H 与可行策略，使 (i) 对 ℳ_t 中每个 m，τ 前动作满足收紧约束；(ii) 在 τ 处要么模式已辨识到 ε_id，要么系统已到安全停/绕行态；(iii) **退出裕度** `E_esc=d_irrev−d_stop−d_probe≥0`；(iv) 探针预算 `B_probe≥k_min`；(v) 若需区分则存在 `u*∈𝒰_safe` 且 `J_id` 有效。`J_rfc=(π,τ,{X_k^m},E_esc,k_min,J_id,J_wear)`。规则：**无 J_rfc ⇒ 不得不可逆承诺**，只能降档/绕行/L2 协商。

**定义 145（材料-控制联合探-诺-演 PCE-M）** 每个控制周期：①**卡门**（`Valid(M,s)`？否 ⇒ 𝒫_phys + 禁不可逆）；②**辨识门**（合并 ε-等价类、算 J_id、判断是否需辨识且是否可行）；③**磨损门**（证据年龄≤T_{1/2}？否 ⇒ 再辨识）；④**对偶 MPC**（模式鲁棒管 + 任务/激励联合优化 + SVOI 过滤）；⑤不可逆前过 **RFC 门**；⑥执行第一步、观测、更新信念、重规划；⑦任何换卡/磨损事件 ⇒ 失效依赖证据并重规划。预算 `E_motion+E_probe+E_exc`，终止于 {承诺, 绕行, L2 协商, 安全停}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def material_gate(M_cards, s):                       # IP-139
    valid = [M for M in M_cards if Valid(M, s)]
    if not valid: return PHYS_ENVELOPE, 'no_card_no_irreversible'
    return merge_envelopes(valid), 'ok'

def identifiability(m1, m2, b, eps_id):              # IP-140
    D = max(KL(obs(m1,u), obs(m2,u)) for u in U_safe(b))
    return ('indistinguishable', [m1,m2]) if D < eps_id else ('ok', D)

def dual_control_mpc(b, s, H, budget):               # IP-142/143
    for m in support(b): X[m] = propagate(m, H)      # 逐模式可达集
    tube = union(X); X_safe = erode(SAFE, tube)      # 收紧约束
    if not mode_robust_terminal(b) ⊆ STOP: return 'safe_stop'
    plan = argmin over u_{0:H-1} of
           sum(task_cost + lam_risk*tube_radius - lam_info*SVOI(u_k))
           s.t. x_k in X_safe, u_k in U_safe(b)
    return plan[0]                                   # 只执行第一步

def recursive_falsifiability(plan, b, H):            # IP-144
    if escape_margin(plan) < 0: return False
    if budget.probe_left < k_min: return False
    if needs_discrimination(b) and not exists_safe_discriminating_u(b):
        return False
    return exists_stop_or_identify_within(plan, H, b)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| MCS | O(K·d_𝒫) 包络合并 | O(K) 静态 | 卡有效性诚实、包络不越界 |
| MID | O(K²·|𝒰|·T_obs) | O(K²) | 可辨识度校准、伪可分漏检≤δ_id |
| WDA | O(1)/步 | O(|E|) | 漂移率上界诚实、半衰期单调 |
| MRT | O(H·K·d_x) | O(H·K·d_x) | 管包含真实可达集、终端集不变 |
| DCV | O(H·|𝒰|·(C_task+C_SVOI)) | O(H·d_x) | SVOI 只计决策相关、激励不出安全集 |
| RFC | O(H·K·d_x) | O(H·K·d_x) | 退出裕度非负、终止态可达 |
| PCE-M | O(CP·(H·|𝒰|·(K+C_SVOI)+T_id+T_wear)) | O(|V|+K·d_x) | 卡/辨识/磨损门先行、重规划终止 |

**正确性定理（Material-Identifiable Recursively-Feasible Soundness, MIRFS 概要）**：在 A37–A40（第 57 轮）之上加 **(A41)** 材料卡健全：有效卡包络覆盖真实材料、换卡过隔离且不漏失效模式；**(A42)** 可辨识度校准：`D(m,m')` 对真实观测分布的 KL 下界成立，伪可分漏检 ≤δ_id；**(A43)** 磨损界：漂移率 `|dθ/dt|≤w_max` 诚实，半衰期调度不漏期；**(A44)** 管健全：逐模式可达集包含真实可达集，终端集对 ℳ_t 控制不变；**(A45)** RFC 健全：退出裕度与预算检查不漏项。则：(i) 不可逆承诺失效率 `≤ δ_f+δ_id+δ_wear+δ_tube`，其中模型类错误被卡门/𝒫_phys 兜住，参数误差被包络与管兜住；(ii) 递归可行性：任一被 RFC 放行的承诺，执行后仍存在"安全停或继续辨识"的可行计划；(iii) 交互单调性强化：卡门/辨识门/磨损门/管只能经"信念更宽（合并等价类、包络取最坏）"或"动作更保守（降档、绕行、只安全停）"影响系统；(iv) 终止性：PCE-M 在 `k_probes+k_exc+k_id` 内终止于 {承诺, 绕行, L2, 安全停}。

def discriminability(m1, m2, b, eps_id):
    # 只在安全激励集上取最大区分力；θ 取最坏
    D = max(KL(obs_dist(m1, u), obs_dist(m2, u))
            for u in U_safe(b))

def identifiability_gate(b, cards, need_discriminate):

    J_id = {}
    for m1, m2 in pairs(cards):
        st, D = discriminability(m1, m2, b, eps_id)

    return 'ok', classes, J_id

def mode_robust_tube(b, H, u_seq):
    support = [m for m in b.modes if b.p(m) > eps_m]
    X = {m: {b.x0[m]} for m in support}
    tube = [set(X[m]) for m in support]
    for k in range(H):

            X[m] = reach(f_m, X[m], u_seq[k]) ⊕ W
        tube.append(union(X.values()))
    return tube                                     # 逐步模式鲁棒可达集

def tightened_constraints(tube):
    return [erode(SAFE, T_k) for T_k in tube]       # 𝒳_k = 𝒳_safe ⊖ 𝒯_k

def mode_robust_terminal(b, H):
    support = [m for m in b.modes if b.p(m) > eps_m]
    Xf = intersect([terminal_set(m, H) for m in support])
    if not Xf ⊆ STOP: return None                   # 无共同安全停
    if not all(is_control_invariant(Xf, m) for m in support):
        return None
    return Xf

def recursive_feasible(plan, b, H):

    if Xf is None: return False
    return plan.reaches(Xf) and plan.within(tightened_constraints(mode_robust_tube(b,H,plan.u)))

## 3. 关键推导与定量界

### 3.1 可辨识性-安全悖论：最有区分力的激励最接近失效边界

设接触观测 `y=μ·F+ε`，`ε∼N(0,σ²)`，两材料 `μ₁,μ₂`，激励为法向力 `F`。同方差高斯的 KL 为

```
KL(N(μ₁F,σ²) ‖ N(μ₂F,σ²)) = (Δμ·F)² / (2σ²).
```

取 `Δμ=0.2, σ=1, ε_id=1 nat`，则 `F* = √(2ε_id σ²)/Δμ = 7.07`。当安全激励上界 `F_safe=5` 时，`KL=0.5<1`：**在安全激励内本质不可辨识**；要分辨就必须把 `F` 推到 `7.07` 以上，而这已经逼近未知的 `F_bear`。这就是结构性冲突：

- `F=5 → KL=0.5`（安全，但分不清）
- `F=7.07 → KL=1.0`（刚好可分）
- `F=10 → KL=2.0`；`F=20 → KL=8.0`（信息多，但可能已越过承载边界）

**结论**：可辨识性不能被当作"探针数量的函数"，它首先是**激励幅度的函数**；而激励幅度受制于我们正想估计的那个量（`F_bear`）。因此 `J_id` 必须报出"在 `𝒰_safe` 内是否可分"；若不可分，安全上只能取等价类最坏值或绕行，不能假装多探几次就能分开。

### 3.2 设计期材料选型：可辨识性与柔顺性的几何平均

把脚垫刚度 `k_p` 作为选型变量，地面刚度 `k_t`，接触刚度 `k_eff=k_t k_p/(k_t+k_p)`。对 `k_t` 的观测信号 `∂F/∂k_t=δ·k_p²/(k_t+k_p)²`，故可辨识 SNR `∝ k_p²/(k_t+k_p)²`；柔顺性收益取 `k_ref/(k_p+k_ref)`。以乘积为目标（两项都必须为正）：

```
J(k_p) = [k_p/(k_t+k_p)] · [k_ref/(k_p+k_ref)].
```

令 `d log J/dk_p=0` 得 `k_p* = √(k_t·k_ref)`。取 `k_t=1000 N/m, k_ref=200 N/m`：

```
k_p* = √(1000×200) = 447 N/m,  J* = 0.309×0.309 = 0.0955.
```

对照：`k_p=100` 时 SNR=0.091、柔顺=0.667、乘积=0.0606；`k_p=1000` 时 SNR=0.5、柔顺=0.167、乘积=0.0833。**最优点落在两端之间的几何平均，而不是"越软越稳"或"越硬越准"。** 这给出一个可写进选型报告的设计判据：**材料不只按承载/寿命选，还要按"它让地面可辨识多少"选；而可辨识性有一个由几何平均决定的甜点。**

### 3.3 模式鲁棒管：把信念宽度自动翻译成约束收紧量

设某裕度对材料参数的敏感度为 `L`（如"允许法向力"对 `μ` 的敏感度，单位 mm/参数），后验标准差 `σ_θ`，分位数 `q_{1−δ}`。则

```
r = L · q_{1−δ} · σ_θ,      m_cert = m_nominal − r.
```

取 `L=20 mm/参数, q=1.645, θ_K=5 mm`：

- 探针前 `σ_θ=0.1`：`r=3.29 mm` ⇒ 需 `m_nominal>8.29 mm` 才能承诺；
- 探针后 `σ_θ=0.03`：`r=0.99 mm` ⇒ 只需 `m_nominal>5.99 mm`。

即**一轮有效探针把可承诺裕度门槛降低了约 2.3 mm**。这正是"证据质量→控制激进度"的自动映射：不需要手调 `θ_K`，管半径随信念收窄而变细，步态随之放开；反之信念变宽（换卡、OOD、磨损）管变粗，自动降档。

### 3.4 磨损半衰期：证据不能比材料活得久

设性能漂移率上界 `w_max`，容差 `ε_θ`，则证据半衰期

```
T_{1/2} = ε_θ / w_max.
```

取 `ε_θ=5×10⁻³`（μ 的容许漂移）：

- 正常地面 `w_max=2×10⁻⁶/步` ⇒ `T_{1/2}=2500 步`；
- 磨蚀地面 `w_max=4×10⁻⁶/步` ⇒ `T_{1/2}=1250 步`。

即**磨损率翻倍，证据寿命减半**。若不在 `T_{1/2}` 内再辨识，旧证据会以"仍然有效"的名义放行一个已经改变的摩擦系数——这是"坏证据长寿"在材料维度上的精确版本。

### 3.5 安全相关 VOI：信息只有能改变决策才值钱

设两模式：安全模式概率 `p`，承诺收益 `+10`；不安全模式收益 `−100`；不承诺收益 `0`。完美探针下只在安全时承诺：

```
E[commit|无探针] = 10p − 100(1−p),
SVOI = 10p − max(10p−100(1−p), 0).
```

- `p=0.6`：`E[commit]=−34`，不承诺为 0，有探针为 `6` ⇒ **SVOI=6**；
- `p=0`（两模式都不安全）：承诺恒 `−100`，探针后仍只能不承诺 ⇒ **SVOI=0**；
- `p=1`（两模式都安全）：承诺恒 `+10`，探针不改变动作 ⇒ **SVOI=0**。

而熵减 VOI 在 `p=0` 或 `p=1` 的退化先验下仍可能因观测模型噪声而为正。**所以对偶 MPC 的信息项必须用 SVOI，而不是熵减**：否则系统会把预算花在"知道了也不改变动作"的探针上，同时把真正能改变安全决策的激励省掉。

### 3.6 递归可证伪与退出裕度

对一段到不可逆接触点距离 `d_irrev`、安全停距离 `d_stop`、探针路径长度 `d_probe` 的通道：

```
E_esc = d_irrev − d_stop − d_probe ≥ 0.
```

取 `d_stop=1.0 m, d_probe=0.5 m`：

- `d_irrev=3.0 m` ⇒ `E_esc=1.5 m`（可承诺，仍留证伪/回退空间）；
- `d_irrev=2.0 m` ⇒ `E_esc=0.5 m`（临界，仅允许短时域）；
- `d_irrev=1.2 m` ⇒ `E_esc=−0.3 m`（**拒绝承诺**，因为一旦观测到材料不对，已无空间停或再辨识）。

这把第 57 轮"当前点能终止"升级为"承诺后仍可退出、仍可辨识"；短视 VOI 看不到的正是 `E_esc<0` 这类"当下证据够、未来回不了头"的情形。

### 3.7 部署界（示意）

对检查点取界，但把模型类错误、可辨识误差与磨损项提到外层各计一次，管约束把时域内的不确定性合并为一次：

```
P_safe ≥ 1 − δ_card − δ_id − δ_wear − δ_tube
             − Σ_cp (δ_region|card + δ_f)
             − P(RFC 漏检) − P(护盾失败) − P(τ_int ∧ 安全停失效).
```

关键变化：第 57 轮的 `ε_meta(k)` 被拆成 `δ_card`（模型类）与包络内参数误差，前者不再被"更多探针"稀释；`δ_id` 专门覆盖"以为分得清"；`δ_wear` 覆盖"证据过期"；时域内约束由管一次兜住，不再逐检查点 union bound。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| MCS | O(K·d_𝒫) 合并；O(K) 门 | O(K) 静态 | 卡有效/包络不越界（A41） |
| MID | O(K²·|𝒰|·T_obs) | O(K²) | 可辨识度校准、伪可分漏检≤δ_id（A42） |
| WDA | O(1)/步；O(|E|) 校验 | O(|E|) | 漂移率上界诚实、半衰期单调（A43） |
| MRT | O(H·K·d_x) | O(H·K·d_x) | 管包含真实可达集、终端集不变（A44） |
| DCV | O(H·|𝒰|·(C_task+C_SVOI)) | O(H·d_x) | SVOI 只计决策相关、激励不出安全集 |
| RFC | O(H·K·d_x) | O(H·K·d_x) | 退出裕度非负、终止态可达（A45） |
| PCE-M | O(CP·(H·|𝒰|·(K+C_SVOI)+T_id+T_wear)) | O(|V|+K·d_x) | 三门先行、重规划终止 |

**正确性定理（Material-Identifiable Recursively-Feasible Soundness, MIRFS）**
假设 A37–A40（第 57 轮）成立；**(A41)** 材料卡健全：有效卡包络覆盖真实材料、换卡过隔离且不漏失效模式，无有效卡时 `𝒫_phys` 为真硬界；**(A42)** 可辨识度校准：`D(m,m′)` 是真实观测分布 KL 的下界，伪可分漏检 ≤δ_id，类内证据零学分；**(A43)** 磨损界：`|dθ/dt|≤w_max` 诚实，`T_{1/2}=ε_θ/w_max` 调度不漏期；**(A44)** 管健全：`X_k^m` 包含真实可达集，`𝒳_f` 对 ℳ_t 控制不变且 ⊆ 安全停集；**(A45)** RFC 健全：退出裕度、预算与可辨识检查不漏项。则：

1. **模型类健全性**：不可逆承诺失效率 `P_fail ≤ δ_card + δ_id + δ_wear + δ_tube + δ_f`；模型类错误由卡门/`𝒫_phys` 兜底，参数误差由包络与管兜底，二者不再混为一个 `ε_meta(k)`。
2. **递归可行性**：任一被 RFC 放行的承诺，执行第一步并收到支撑内任意观测后，仍存在"安全停或继续辨识"的可行计划；故不存在"承诺后回不了头"的路径。
3. **交互单调性**：卡门、辨识门、磨损门、管约束只能经 (a) 信念更宽（合并 ε-等价类、包络取最坏、磨损加宽）或 (b) 动作更保守（降档、绕行、只安全停）影响系统；不存在升险路径。
4. **信息不白花**：只有 `SVOI≥θ_svoi` 的激励进入目标；纯熵减不计，故探针预算不会被"知道了也不改变动作"的信息吞掉。
5. **终止性**：PCE-M 在 `k_probes+k_exc+k_id` 内终止于 {承诺, 绕行, L2 协商, 安全停}。

**关键**：**材料卡给模型类、包络给物理界**（先验不再任意自信）；**可辨识给诚实、等价类给保守**（"分不清"被显式承认）；**磨损给寿命、半衰期给重验**（证据不能比材料活得久）；**管给约束、终端集给退路**（承诺保留退出权）；**SVOI 给激励、对偶 MPC 给联合最优**（探与诺不再是两个拍脑袋的阶段）。

## 7. 本轮最大风险

**一句话**：本轮最大风险不是材料卡库有盲区，而是**可辨识性证书本身说谎**——系统高估了安全激励的区分力，误以为"我保留了证伪能力"，实际已进入一个 ε-不可分等价类，于是递归可证伪证书退化为形式合规的橡皮章；必须以留出激励审计、等价类保守合并、单一激励不得授权不可逆、以及把 `δ_id` 显式计入失效界四重护栏，宁可承认"分不清"并绕行，也绝不让"以为分得清"成为放行理由。
