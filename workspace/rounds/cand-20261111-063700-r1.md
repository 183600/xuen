# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「数据增强」×「双臂协调」）

> 第 54 轮把技能推进为「动作空间剖面 α_S + 动作-鲁棒性双证书 J + 云边契约 C_ce」，但整条链路仍建立在两个未被审视的假设上：(i) 证据来自真实轨迹，样本越多证书越可信；(ii) 技能是单臂的，多臂只是「多个单臂并行」。本轮用「数据增强」打破 (i)——增强既能廉价放大证据，也能批量伪造证据；用「双臂协调」打破 (ii)——双臂动作是关系型的，可执行集合是被约束流形切出来的，不是两个单臂空间的笛卡尔积。核心矛盾：**H22**：独立逐臂增强会在乘积空间里制造「单臂看合理、联合看撕裂」的样本，使 α_S 与 ρ 的覆盖被系统性高估，产生**覆盖幻觉（coverage illusion）**；**H23**：双臂失效主因是关系残差（相对位姿、内力闭合、时序同步、避碰），而 `min(ρ_L,ρ_R)` 结构上无法表达协调残差，单臂都稳 ≠ 联合任务成。

## 0. 直觉与动机

**灵感 1（双臂协调 = 关系动作，而非两条独立动作）**
直觉：双臂不是「左手技能 + 右手技能」，而是被一个约束流形 `M_c` 绑在一起的联合动作 `a=(a_L,a_R)`。`M_c` 同时编码相对位姿、力闭合/摩擦锥、时序同步与避碰。真正可部署的动作集合是 `A_L × A_R` 里一张低维子流形，而不是整个乘积空间。因此「动作覆盖」必须定义在 `M_c` 上：单臂各自 100% 覆盖，联合仍可能一步都走不了。

**灵感 2（数据增强的第一性风险 = 覆盖幻觉）**
直觉：增强通常被当成「免费样本」。可在双臂里，对左右臂独立加噪会让原本满足刚性抓取约束的样本漂到 `M_c` 之外：单臂看每条轨迹都合理，联合看两只手在撕扯物体。用这些样本估计 `α_S`、`ρ`，等于把「增强分布里的可行」误当成「物理流形上的可行」。所以关键不是「增强多少」，而是「增强是否保流形」。

**灵感 3（保流形增强：只在协调等变群里增强）**
直觉：最强的增强不是加噪声，而是利用系统对称性。物体中心重参数化（物体位姿/质量/尺度变化同时传导给双臂）、左右镜像（交换双臂并镜像几何）、同步时间扭曲（两臂共享同一时间重参数化）都精确或近似保持 `M_c`。把这类变换记作协调等变群 `G_c`；只有落在 `G_c` 内、或经认证投影后残差 `≤ η` 的增强，才有资格进入证书。逐臂独立增强一般不在 `G_c` 里——它是幻觉的主要来源。

**灵感 4（增强的双重角色：确认 vs 证伪，必须分账）**
直觉：同一台生成器既能「确认」也能「证伪」。保流形增强用于抬高覆盖（确认，改善统计项）；对抗增强主动把样本推向 `M_c` 边界与摩擦锥边缘，用于挖掘失败模式（证伪，改善模型项）。两者必须分开记账，否则「用增强证明可靠」和「用增强发现不可靠」会互相污染：证伪样本一旦被计入覆盖，证书必然虚高。

**灵感 5（增强预算：不是越多越好，存在最优增强半径 γ\*）**
直觉：增强强度 `γ` 上升时，统计误差 `~1/√n_eff(γ)` 下降，但流形投影偏差 `L_C·η(γ)` 与生成器 sim-to-real 偏差 `β_gen(γ)` 上升。总误差上界 `U(γ)` 是 U 形曲线，存在 `γ*`。把「增强强度」当成需要优化的超参数，而不是默认越大越好——这是本轮最反直觉、也最可实验证伪的一点。

**灵感 6（四层可追溯：在 𝔸/ℝ 之外补证据层 𝔻）**
直觉：第 54 轮有动作层 `𝔸` 与鲁棒性层 `ℝ`。本轮补上证据层 `𝔻`：`𝔻_0` 真实轨迹（信任 1）、`𝔻_1` 保流形增强（信任 `w(η,d_SR)`）、`𝔻_2` 越界增强（**禁止签发证书**，只可用于证伪）。证书只能由 `𝔻_0 ∪ 𝔻_1` 签发，形成「证据 𝔻 - 协调 ℂ - 动作 𝔸 - 鲁棒性 ℝ」四层可追溯体系。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（双臂联合动作空间与协调流形）**
`A² = A_L × A_R`。协调约束 `C : A² → ℝ_+^k`，`C = (r_pose, r_force, r_sync, r_col)` 分别度量相对位姿、力闭合、时序同步、避碰残差。协调流形
```
M_c = { a ∈ A² | C_j(a) ≤ ε_c,j, ∀ j }
```
协调残差 `r_c(a) = ||C(a)/ε_c||_∞`，协调裕度 `m_c(a) = 1 - r_c(a)`。技能可执行当且仅当 `a ∈ M_c`。注意 `M_c ⊊ A²`，其维数由双臂闭链/共同抓取约束决定。

**定义 122（关系鲁棒性谱）**
对扰动维度集 `D`，关系鲁棒性
```
ρ_rel(d) = P_{a ~ M_c}( r_c(a) ≤ 1 | d ),   d ∈ D
```
即在扰动 `d` 下协调残差仍在容差内的概率。联合鲁棒性谱 `ρ_J = (ρ_L, ρ_R, ρ_rel)`，**不再坍缩为 `min(·)`**；三者描述不同失效通道，必须分别通过。

**定义 123（(η,κ)-保流形增强）**
增强算子 `T_θ : A² → A²`。若对任意 `a ∈ M_c` 有 `dist(T_θ(a), M_c) ≤ η` 且 `|r_c(T_θ(a)) - r_c(a)| ≤ κη`，称 `T_θ` 为 `(η,κ)`-admissible；`η=0` 为精确保流形。协调等变群
```
G_c = { g : A²→A² | g(M_c) = M_c }
```
`g ∈ G_c` 是 `η=κ=0` 的特例。独立逐臂加噪一般 `∉ G_c`，必须被投影或降权。`d_SR(s)` 为增强样本 `s` 的合成-真实距离。

**定义 124（增强证据与有效样本量）**
样本 `s_i` 的来源权重：
```
w_i = 1                             若 s_i ∈ 𝔻_0（真实）
w_i = w0·exp(-d_SR(s_i)/λ)          若 s_i ∈ 𝔻_1（保流形增强）
w_i = 0                             若 s_i ∈ 𝔻_2（越界增强，仅证伪）
n_eff = (Σ_i w_i)² / Σ_i w_i²
```
增强证据 `E_aug = (n_eff, η, β_gen, support_cells, clusters)`，其中 `β_gen` 为生成器 sim-to-real 偏差上界，`support_cells/clusters` 用于惩罚「同源重复」造成的伪独立。

**定义 125（双臂协调证书 DACC）**
```
CC = (A_core², ρ_J, r_c^max, m_c^min, Γ_ab, E_aug)
```
- `A_core² ⊆ M_c`：认证核心流形（可部署动作集合）；
- `ρ_J = (ρ_L, ρ_R, ρ_rel)`：三通道联合谱；
- `m_c^min = min_{a∈A_core²} m_c(a) > 0`：协调裕度下界；
- `Γ_ab : A_L → A_R`：左右臂同步/耦合映射，显式表达「关系」；
- `E_aug`：增强证据（定义 124）。
签发条件：`m_c^min ≥ m_req ∧ n_eff ≥ n_min ∧ η ≤ η_max ∧ β_gen ≤ β_max`。

**定义 126（协调保持组合与残差次可加律）**
两个双臂技能 `S_i,S_j` 可组合当且仅当 `A_core²(S_i) ∩ A_core²(S_j)` 在 `M_c` 上连通，且
```
r_c(S_i⊗S_j) ≤ r_c(S_i) + r_c(S_j) + c_trans
m_c(S_i⊗S_j) ≥ m_c(S_i) + m_c(S_j) - c_trans
```
即协调残差沿技能链**次可加**、裕度沿链**被转换成本侵蚀**。这与第 54 轮「边权可加」的假设不同：组合的失败可以来自残差累积，而非单点失败。

## 2. 关键算法伪代码

### IP-121 CPA（Constraint-Preserving Augmentation）

```python
def cpa_augment(traj, M_c, G_c, eta_max):
    D1, D2 = [], []
    for g in enumerate_equivariant_group(G_c):   # object-centric / mirror / synced time-warp
        a2 = g.lift_both_arms(traj)              # 变化同时传导给左右臂，而非逐臂独立采样
        r = coordination_residual(a2, M_c)
        if r <= 1.0:
            D1.append(Sample(a2, eta=0.0))
        else:
            eta = dist_to_manifold(a2, M_c)
            if eta <= eta_max:
                D1.append(Sample(project_to_manifold(a2, M_c), eta=eta))
            else:
                D2.append(a2)                    # 越界：只进证伪集
    for _ in range(n_adv):
        D2.append(adversarial_push(traj, M_c.boundary))   # 推向摩擦锥/同步边界
    return D1, D2
```

### IP-122 CCM（Coordination Certificate Miner）

```python
def mine_coordination_cert(D0, D1, D2, dims, delta):
    E = [(s, 1.0) for s in D0] + [(s, aug_weight(s)) for s in D1]
    rho_rel = {}
    for d in dims:
        Es = [(s, w) for s, w in E if s.dim == d]
        est = sum(w for s, w in Es if r_c(s) <= 1.0) / max(sum(w for _, w in Es), EPS)
        n_eff = ess([w for _, w in Es])          # 聚类 ESS，抑制同源伪独立
        rho_rel[d] = dkw_lower_bound(est, n_eff, delta)
    m_c_min = min(m_c(s) for s, _ in E)
    failures = cluster_failures(D2 + [s for s, _ in E if r_c(s) > 1.0])
    return CoordinationCert(rho_rel, m_c_min, failures)
```

### IP-123 AUG-GUARD（增强证据护栏 + 增强预算）

```python
def aug_guard(D1, D2, kappa, L_C, beta_gen, delta, eta_max):
    if any(not in_manifold(s, M_c, tol=eta_max) for s in D1):
        return Reject('manifold_violation')      # 一旦混入越界样本，整批不可信
    eta = max((s.eta for s in D1), default=0.0)
    n_eff = ess([s.w for s in D1])
    stat = sqrt(log(2.0/delta) / (2.0*max(n_eff,1.0)))     # DKW
    bias = kappa * L_C * eta + beta_gen
    return Evidence(n_eff, eta, bias, stat, U=bias+stat)

def choose_aug_strength(gammas, n_eff_fn, eta_fn, beta_fn, L_C, delta):
    # 增强预算：U(γ) 的最小值，而不是取 γ 最大
    return min(gammas, key=lambda g:
               L_C*eta_fn(g) + beta_fn(g) + sqrt(log(2/delta)/(2*n_eff_fn(g))))
```

### IP-124 DACC（Dual-Arm Coordination Certificate）

```python
def dual_arm_certificate(skill_seq, D0, D1, D2, m_req, n_min, eta_max, delta):
    certs = []
    for S in skill_seq:
        D1ok, D2ok = cpa_augment(S.traj, S.M_c, S.G_c, eta_max)
        ev = aug_guard(D1ok, D2ok, S.kappa, S.L_C, S.beta_gen, delta, eta_max)
        if ev.is_reject or ev.n_eff < n_min or ev.bias > beta_max:
            return Reject('aug_untrusted', ev)
        rho_L, rho_R = per_arm_spectra(S, D0)
        rho_rel, m_min, fails = mine_coordination_cert(D0, D1ok, D2ok, DIMS, delta)
        if m_min < m_req:
            return Reject('coordination_margin', m_min, fails)
        certs.append(DACC(S.id, (rho_L, rho_R, rho_rel), m_min, S.Gamma_ab, ev))
    return ('ok', compose_certs(certs))
```

def rel_compose(certs, c_trans, m_req):
    A_core2 = manifold_intersection([c.A_core2 for c in certs])
    if not is_connected(A_core2, M_c):
        return Reject('disconnected_manifold')

def coordination_transfer(cert_src, robot_dst, M_c_dst, G_c_dst, budget, delta):
    Gamma = align_coupling(cert_src.Gamma_ab, robot_dst)   # 迁移「耦合」而非各自单臂策略

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CPA | O(|G_c|·|traj|·cost(C) + n_adv·cost(proj)) | O(|D1|+|D2|) | 增强群完备、投影残差 ≤ η |
| CCM | O((|D0|+|D1|)·|D| + |D2|) | O(|D0|+|D1|) | 聚类 ESS、DKW 下界 |
| AUG-GUARD | O(|D1| + |Γ|) | O(1) | 越界样本零容忍、γ\* 可复算 |
| DACC | O(|S|·((|D0|+|D1|)·|D| + |M_c|)) | O(|S|·|M_c|) | 三通道独立通过、裕度 > 0 |
| REL-COMPOSE | O(k·|M_c| + k·|D|) | O(|M_c|+|D|) | 流形连通、残差次可加 |
| CAT | O(|traj|·cost(C) + homotopy(M_c)) | O(|D1|+|M_c|) | 耦合可对齐、流形同胚 |

**正确性定理（Dual-Arm Augmented Coordination Soundness）**
在承接第 54 轮 (A26)–(A28) 的基础上追加：**(A29)** `C` 在 `M_c` 邻域内 `L_C`-Lipschitz；**(A30)** 增强算子 `(η,κ)`-admissible；**(A31)** 真实轨迹按簇可交换、簇内相关已在 `n_eff` 中计入。则对任意技能链 `π`，以概率 `≥ 1-δ`：
```
P_success(π) ≥ 1 - Σ_{d∈D}[(1-ρ_L(d)) + (1-ρ_R(d))]
                 - [ (1-ρ̂_rel) + κ·L_C·η + β_gen + sqrt(ln(2/δ)/(2·n_eff)) + β_tail ]
```
其中 `ρ̂_rel` 为认证证据上的关系鲁棒性估计，`β_tail` 为**不可由证据消化的共模/长尾事件**上界（如物体滑移同时破坏双臂），必须由独立故障注入或物理分析给出。

**推论 1（增强预算）**：记 `β_aug(γ)=κL_Cη(γ)+β_gen(γ)`，上界 `U(γ)=β_aug(γ)+√(ln(2/δ)/(2n_eff(γ)))+β_tail`，则最优增强强度 `γ* = argmin_γ U(γ)`。增强唯一能被证明有益的条件是「统计项下降 > 偏差项上升」。

**推论 2（反覆盖幻觉）**：若增强集含越界样本或 `η > η_max`，则 `β_aug` 不可控，证书必须拒绝；这给出一条可执行的硬规则——**越界增强永远不能签发证书，只能用于证伪**。

**推论 3（单臂 min 的失效）**：存在任务使 `ρ_L=ρ_R=0.99` 而 `ρ_rel=0.4`；此时 `min(ρ_L,ρ_R)` 证书预测失败率 `≤0.01`，真实失败率 `≥0.6`。故第 54 轮的 `min` 组合律在双臂场景下**结构性不 sound**，必须替换为三通道联合。

| 风险 | 等级 | 缓解 |

| `M_c` 本身建模错误（漏掉接触瞬态） | 高 | 物理标定 + 接触仿真 + 真实探针校准 `C` |

## 6. 本轮最大风险

**一句话**：本轮把「数据增强」从免费样本改造成受流形约束的证据算子、把「双臂协调」从两条独立技能改造成关系约束，但最致命的风险是**「保流形」只保住了我们写下的 `M_c`，而真实双臂的致命失效（物体滑移、共模扰动、接触瞬态）恰恰发生在 `M_c` 未建模的维度上**——此时增强越充分、`n_eff` 越大，证书越自信地错，故必须以 `M_c` 的物理标定误差界与独立故障注入的 `β_tail` 作为**不可被任何增强稀释的硬下界**，宁可承认「这段协调我证不了」，也绝不把增强出来的流形内假象当作部署依据。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim-Dual（CPA×CCM×AUG-GUARD×DACC×REL-COMPOSE×CAT）

> 承接第 54 轮产物 v31。v31 已具备「动作剖面 α_S + 组合图 G_S + 云边映射 γ_ce + 动作-鲁棒性联合证书 J」。v32 不再堆叠新的单臂能力，而是补上两个被默认掉的根基：**证据从哪来**（数据增强）与**多臂为何难**（双臂协调）。新增六个算子：
> - **CPA（Constraint-Preserving Augmentation）**：只在协调等变群内增强，越界样本只用于证伪；
> - **CCM（Coordination Certificate Miner）**：挖掘关系鲁棒性 `ρ_rel` 与协调裕度 `m_c`；
> - **AUG-GUARD（Augmentation Evidence Guard）**：来源加权、聚类 ESS、DKW 下界与增强预算 `γ*`；
> - **DACC（Dual-Arm Coordination Certificate）**：`(ρ_L,ρ_R,ρ_rel)` 三通道联合证书，取代 `min`；
> - **REL-COMPOSE（Relational Composition）**：流形连通 + 残差次可加的技能链组合；
> - **CAT（Coordination-Aware Transfer）**：迁移「耦合 `Γ_ab`」而非各自单臂策略。
>
> IP 编号：IP-121~IP-126（共 6 个新增）；升级 IP-115/116/118/120 以纳入协调流形与增强证据。
> 一句话定位：**v31 让技能「可组合」，v32 让组合「可被真实证据支撑、可解释地失败」。**

## 2. 关键算法 伪代码

### IP-121 CPA

```python
def cpa_augment(traj, M_c, G_c, eta_max):
    """保流形增强：所有变换必须同时作用于双臂（lift_both_arms），
    逐臂独立采样被显式禁止。"""
    D1, D2 = [], []
    for g in enumerate_equivariant_group(G_c):
        a2 = g.lift_both_arms(traj)          # 物体中心/镜像/同步时间扭曲
        r = coordination_residual(a2, M_c)
        if r <= 1.0:
            D1.append(Sample(a2, eta=0.0, src='equivariant'))
        else:
            eta = dist_to_manifold(a2, M_c)
            if eta <= eta_max:
                D1.append(Sample(project_to_manifold(a2, M_c), eta=eta, src='projected'))
            else:
                D2.append(Sample(a2, src='out_of_manifold'))   # 只证伪
    for _ in range(n_adv):
        D2.append(adversarial_push(traj, M_c.boundary))
    return D1, D2

# 精确保流形的三类增强（η=0）
# 1) object_centric: T_L' = T_obj'·T_obj^{-1}·T_L，T_R' 同步，刚性关系不变
# 2) mirror: (L,R,几何) 同时镜像，若任务对称则 M_c 不变
# 3) synced_time_warp: 两臂共享同一 τ(t)，同步约束不变
```

### IP-122 CCM

```python
def mine_coordination_cert(D0, D1, D2, dims, delta):
    E = [(s, 1.0) for s in D0] + [(s, s.w) for s in D1]
    rho_rel = {}
    for d in dims:
        Es = [(s, w) for s, w in E if s.dim == d]
        W  = sum(w for _, w in Es)
        est = sum(w for s, w in Es if r_c(s) <= 1.0) / max(W, EPS)
        n_eff = ess_clustered([w for _, w in Es], clusters_by_source(Es))
        rho_rel[d] = dkw_lower_bound(est, n_eff, delta)  # 保守下界，不取点估计
    m_c_min = min(m_c(s) for s, _ in E)
    failures = cluster_failures(D2 + [s for s, _ in E if r_c(s) > 1.0])
    return CoordinationCert(rho_rel, m_c_min, failures)
```

### IP-123 AUG-GUARD

```python
def aug_guard(D1, D2, kappa, L_C, beta_gen, delta, eta_max):
    if any(not in_manifold(s, M_c, tol=eta_max) for s in D1):
        return Reject('manifold_violation')      # 混入越界样本 → 整批不可信
    eta   = max((s.eta for s in D1), default=0.0)
    n_eff = ess_clustered([s.w for s in D1], clusters_by_source(D1))
    stat  = sqrt(log(2.0/delta) / (2.0*max(n_eff, 1.0)))   # DKW
    bias  = kappa * L_C * eta + beta_gen
    return Evidence(n_eff, eta, bias, stat, U=bias+stat)

def choose_aug_strength(gammas, eta_fn, beta_fn, n_eff_fn, L_C, delta):
    # 增强预算：γ* 可能远离 γ_max
    return min(gammas, key=lambda g:
               L_C*eta_fn(g) + beta_fn(g)
               + sqrt(log(2/delta)/(2*max(n_eff_fn(g), 1.0))))

def audit_gc(G_c, traj_bank, tol):
    # 群完备性审计：对每个 g∈G_c 检查 r_c(g(a)) - r_c(a) ≤ tol
    return all(abs(r_c(g.lift_both_arms(t), M_c) - r_c(t, M_c)) <= tol
               for g in G_c for t in traj_bank)
```

### IP-124 DACC

```python
def dual_arm_certificate(skill_seq, D0, D1, D2, m_req, n_min,
                         eta_max, beta_max, delta):
    certs = []
    for S in skill_seq:
        D1ok, D2ok = cpa_augment(S.traj, S.M_c, S.G_c, eta_max)
        ev = aug_guard(D1ok, D2ok, S.kappa, S.L_C, S.beta_gen, delta, eta_max)
        if ev.is_reject or ev.n_eff < n_min or ev.bias > beta_max:
            return Reject('aug_untrusted', ev)
        rho_L, rho_R = per_arm_spectra(S, D0)
        rho_rel, m_min, fails = mine_coordination_cert(
            [s for s in D0 if s.skill == S.id], D1ok, D2ok, DIMS, delta)
        if m_min < m_req:
            return Reject('coordination_margin', m_min, fails)
        certs.append(DACC(S.id, (rho_L, rho_R, rho_rel),
                          m_min, S.Gamma_ab, ev))
    return ('ok', compose_certs(certs))
```

### IP-125 REL-COMPOSE

```python
def rel_compose(certs, c_trans, m_req):
    A_core2 = manifold_intersection([c.A_core2 for c in certs])
    if not is_connected(A_core2, M_c):
        return Reject('disconnected_manifold')
    # 协调残差次可加 → 裕度被转换成本侵蚀
    m = sum(c.m_c_min for c in certs) - c_trans * (len(certs) - 1)
    if m < m_req:
        return Reject('margin_eroded', m)
    rho_J = {d: min(c.rho_J[d] for c in certs) for d in DIMS}
    rho_J['rel'] = min(c.rho_J['rel'] for c in certs)
    return ('ok', DACC_chain(
        A_core2, rho_J, m,
        compose_maps([c.Gamma_ab for c in certs]),
        merge_evidence([c.E_aug for c in certs])))
```

### IP-126 CAT

```python
def coordination_transfer(cert_src, robot_dst, M_c_dst, G_c_dst,
                          budget, delta, eta_max):
    # 迁移的是「关系」：把 Γ_ab 对齐到新臂，而不是分别重训两条单臂策略
    Gamma = align_coupling(cert_src.Gamma_ab, robot_dst)
    D1, D2 = cpa_augment(cert_src.traj, M_c_dst, G_c_dst, eta_max)
    ev = aug_guard(D1, D2, cert_src.kappa, cert_src.L_C,
                   cert_src.beta_gen, delta, eta_max)
    if ev.bias + ev.stat > budget:
        return Reject('evidence_gap', ev)
    if not manifold_homeomorphic(cert_src.A_core2, M_c_dst, tol=eta_max):
        return Reject('manifold_mismatch')
    rho_dst = coupling_correction(cert_src.rho_J, Gamma, robot_dst)
    return ('ok', DACC(Gamma, rho_dst, cert_src.m_c_min,
                       Gamma, ev))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CPA | O(\|G_c\|·\|traj\|·cost(C) + n_adv·cost(proj)) | O(\|D1\|+\|D2\|) | 增强群完备、投影残差 ≤ η |
| CCM | O((\|D0\|+\|D1\|)·\|D\| + \|D2\|) | O(\|D0\|+\|D1\|) | 聚类 ESS、DKW 下界 |
| AUG-GUARD | O(\|D1\| + \|Γ\|) | O(1) | 越界零容忍、γ\* 可复算 |
| DACC | O(\|S\|·((\|D0\|+\|D1\|)·\|D\|+\|M_c\|)) | O(\|S\|·\|M_c\|) | 三通道独立通过、裕度 > 0 |
| REL-COMPOSE | O(k·\|M_c\| + k·\|D\|) | O(\|M_c\|+\|D\|) | 流形连通、残差次可加 |
| CAT | O(\|traj\|·cost(C) + homotopy(M_c)) | O(\|D1\|+\|M_c\|) | 耦合可对齐、流形同胚 |

**正确性定理（Dual-Arm Augmented Coordination Soundness）**
在 v31 的 (A26)–(A28) 之上追加：**(A29)** `C` 在 `M_c` 邻域内 `L_C`-Lipschitz；**(A30)** 增强算子 `(η,κ)`-admissible；**(A31)** 真实轨迹按簇可交换，簇内相关已计入 `n_eff`。则对任意技能链 `π`，以概率 `≥1-δ`：
```
P_success(π) ≥ 1 - Σ_{d∈D}[(1-ρ_L(d)) + (1-ρ_R(d))]
                 - [ (1-ρ̂_rel) + κ·L_C·η + β_gen
                     + sqrt(ln(2/δ)/(2·n_eff)) + β_tail ]
```

**推论 1（增强预算）**：`U(γ)=κL_Cη(γ)+β_gen(γ)+√(ln(2/δ)/(2n_eff(γ)))+β_tail`，`γ*=argmin_γ U(γ)`；增强可证有益 iff 统计项下降 > 偏差项上升。

**推论 2（反覆盖幻觉）**：含越界样本或 `η>η_max` 的增强批次 `β_aug` 不可控，必须整批拒绝；**越界增强只能证伪，不能签发证书**。

**推论 3（`min` 失效）**：存在任务使 `ρ_L=ρ_R=0.99`、`ρ_rel=0.4`；`min` 证书预测失败率 `≤0.01`，真实失败率 `≥0.6`。故 v31 的 `min` 组合律在双臂下结构性不 sound，必须用三通道联合证书替代。

**推论 4（迁移的耦合对齐）**：若 `Γ_ab` 在 `A_core²` 上 `L_Γ`-Lipschitz 且目标流形与源流形同胚，则 CAT 的迁移误差 `≤ L_Γ·d_manifold + (1-ρ_rel)`；否则即使单臂策略迁移成功，耦合失配仍会造成联合失败。

## 5. 本轮最大风险

**一句话**：v32 用「协调等变增强 + 三通道证书」把双臂技能从「两条单臂」升级为「可解释的关系能力」，但最大风险是**「保流形」只保住了我们写下的 `M_c`，而真实双臂的致命失效（物体滑移、共模扰动、接触瞬态）恰好落在 `M_c` 未建模的维度上**——此时增强越充分、`n_eff` 越大，证书越自信地错，故必须把 `M_c` 的物理标定误差界与独立故障注入得到的 `β_tail` 作为**不可被任何数据增强稀释的硬下界**，宁可承认「这段协调证不了」，也绝不用增强出来的流形内假象冒充部署依据。
