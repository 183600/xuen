# 第 44 轮（新循环第 4 轮） · Traj-Cert × IMU-Preintegration：把「轨迹优化」与「惯性测量单元」纳入时空证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 把「用户」和「并发」纳入了证书，但它仍压着两个更底层的单点假设：**(H3) 证书是点式的、无记忆的**——系统只认证当前状态 x_t 的边际 m(x_t)，而真正被执行的对象是一条未来轨迹 ξ；点在当时管内不等于整条轨迹在安全域内，且当轨迹后段证书失效时机器人可能已经「承诺」到无法退出（证书视界 ≠ 控制视界）。**(H4) 状态新鲜度只由慢速绝对传感器 + 全局 Lipschitz 速度界给出**——租约衰减 λ = L_m·v_max 用最坏全局速度，既过度保守（可用性崩塌，正是 v20 的 E90 风险），又缺乏对真实运动的物理见证。本轮灵感词「轨迹优化」「惯性测量单元」精确命中这两个假设：**轨迹优化**迫使我们把证书从「状态上的标量」提升为「沿轨迹的时空管（tube）」；**惯性测量单元**给出高频、低延迟的运动增量，让我们能用**有界误差包络**替换最坏速度界，把租约衰减从线性最坏界收紧为数据相关的二次包络，同时把「IMU 漂移」本身变成需要被认证的对象。二者耦合处是本轮真正的新问题：**管的半径由 IMU 误差包络决定，而轨迹优化会主动利用更紧的管去规划更激进的轨迹——一旦包络非保守，优化器会把系统精确地推到真实安全边界之外。**

## 0. 直觉与动机

**灵感 1（轨迹优化 → 证书必须是一条「管」，而不是一个「点」）**：直觉上，规划器输出的是 ξ={x_t}，但 v20 的守卫只在当前点查 m_lo。这就像只检查火车此刻是否在轨道上，却不检查前方 3 秒的轨道是否塌方。因此把证书对象升级为**证书管** T(ξ,r)={(t,x): ||x−ξ(t)||≤r(t)}，要求 (i) 真实状态始终在管内（包含性），(ii) 管内每一点的边际都 ≥θ（管鲁棒性），(iii) 管内始终保留一条认证过的急停/回退轨迹（可撤销性）。轨迹优化不再「先规划、后认证」，而是**在可认证的管约束内优化**——管越紧，可用的激进动作越多；管越松，优化器被迫保守。这就把「认证」从规划后的过滤器，变成规划中的一等约束。

**灵感 2（IMU → 漂移不是噪声，而是管的半径）**：IMU 以 200–1000Hz 给出角速度与比力，两次绝对锚点（LiDAR/视觉/几何证书，约 10Hz）之间可以做**预积分**得到相对位姿。它的误差不是无界的：在给定噪声与偏置界下，预积分位置误差有一个可证明的包络 E(Δt)，大致随 Δt² 增长，远小于全局界 v_max·Δt 的线性增长。于是把 v20 的租约 ℓ=(m,τ,λ,κ) 升级为**惯性租约**：管的半径 r(t)=r_anchor+E(t−τ_k)，新鲜度判据变成 m(ξ(t)) ≥ θ + L_m·r(t)。IMU 越准、重锚越勤，管越细，轨迹越激进但仍 sound。**关键翻转**：IMU 的漂移不再只是要抑制的噪声，而是证书管半径的物理来源——我们不是在「消除漂移」，而是在「给漂移开一张可审计的欠条」。

**灵感 3（耦合 → 激励感知的 soundness 门 + 可撤销承诺）**：预积分误差包络的紧致性依赖偏置可观测，而偏置可观测依赖运动激励。机器人长时间准静态时，偏置不可观、包络会膨胀甚至失真。因此必须加一道**激励感知门**：只有当窗口内信息矩阵 λ_min(J)≥ρ 时，才允许使用紧包络；否则强制膨胀到全局 Lipschitz 界（graceful degradation：动态时激进、静止时保守）。同时，轨迹优化天然会「赌」未来，必须定义**承诺视界** H_c：只执行到仍存在认证回退的那一段，绝不把机器人推进一个「证书将失效且无法急停」的走廊。

**耦合升级**：CTO（认证轨迹优化器）在管约束下优化 ξ；ICP（惯性证书传播器）产生带严格误差包络的锚点间传播与激励门；TCV（管证书验证器）在仿真与硬件上做对抗 IMU 注入、出管检测与回退模糊测试。四层架构由 v8 的「人格 + 并发证书层」升级为 v9 的「人格 + 并发 + 时空管证书层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（轨迹证书与证书管）**：给定规划轨迹 ξ:[0,T]→X 与半径函数 r:[0,T]→R_{≥0}，证书管 T(ξ,r)={(t,x): d_X(x,ξ(t))≤r(t)}。轨迹证书是一个三元组 (ξ,r,θ)，满足：
(1) **包含性**：∀t∈[0,T]，真实状态 x(t)∈T(ξ,r)（在传感器/估计误差界下确定成立，或以 ≥1−δ 概率成立）；
(2) **管鲁棒性**：inf_{t} inf_{x∈B(ξ(t),r(t))} m(x) ≥ θ；
(3) **可撤销性**：存在回退策略 π_fb 与终端控制不变集 S_fb⊆{m≥θ}，使得从管内任一点都能在管内到达 S_fb。
只有 (1)(2)(3) 同时成立，才称 ξ 被认证。**要点**：v20 的点式证书是 r≡0、T 退化为单点时的特例。

**定义 45（鲁棒管边际与 Lipschitz 收缩）**：设边际场 m:X→R 关于状态 L_m-Lipschitz（距离类证书常取 L_m=1）。则对任意 x∈B(ξ(t),r(t))：
m(x) ≥ m(ξ(t)) − L_m·r(t)。
于是定义**管边际** M(ξ,r)=inf_t [m(ξ(t)) − L_m·r(t)]。**命题**：M(ξ,r)≥θ ⇔ 管鲁棒性（定义 44(2)）成立。这把「对整个球的鲁棒性」化归为「沿中心线的一个标量不等式」，是后续可解性的关键：管半径 r(t) 直接以 L_m·r(t) 的「边际膨胀」形式进入轨迹优化。

**定义 46（IMU 预积分误差包络）**：IMU 观测 ω_m=ω+b_g+n_g、a_m=R^⊤(a−g)+b_a+n_a。两次绝对锚点 τ_k、τ_{k+1} 之间预积分得相对位姿 Δ_{k,k+1}。给定噪声界（σ_a,σ_g）与偏置界 B_k={b:(b−b̂)^⊤Σ_b^{-1}(b−b̂)≤χ²}，定义**误差包络** E(Δt) 使得
|| (真实相对位姿) ⊖ (预积分相对位姿) || ≤ E(Δt)，∀Δt≤Δt_max，
其中 E(Δt)=κ_a(σ_a+||δb_a||)Δt² + κ_g·g(σ_g+||δb_g||)Δt² + e_model(Δt)，||δb||≤sqrt(χ²·λ_max(Σ_b))，κ_a、κ_g、e_model 由离线区间算术/最坏规格标定。**命题（紧致性）**：存在 Δt* 使 E(Δt)<v_max·Δt（∀Δt<Δt*），即短重锚间隔下惯性包络严格优于全局速度界；Δt_max 取 E(Δt_max)≤v_max·Δt_max 的最大值。**注**：管半径还须叠加跟踪误差 r_track（FaSTrack 式），即 r(t)=r_est(t)+r_track，其中 r_est(t)=r_k+E(t−τ_k)；ICP 只负责收紧 r_est。

**定义 47（激励感知门与惯性租约）**：在窗口 W_k 上计算偏置信息矩阵 J_k=Σ_{i∈W_k} H_i^⊤ R_i^{-1} H_i（H_i 为偏置对预积分残差的雅可比）。**激励门**：当 λ_min(J_k)≥ρ 时，包络 E 采用紧界（定义 46）；否则 E 膨胀为全局界 E_global(Δt)=v_max·Δt。**惯性租约** ℓ_imu=(m,τ_k,λ_imu,κ,E)，新鲜度判据：
m − L_m·(r_k+E(t−τ_k)) ≥ θ 且 lease_valid，
其中 λ_imu(t)=L_m·dE/dt 为瞬时衰减率（通常 ≪ L_m·v_max）。**命题**：若 E 是真实误差的上界，则惯性租约判据 sound；激励门保证 E 不会在偏置不可观时被错误收紧。

**定义 48（认证轨迹优化 CTO）**：在规划时域 [0,T] 上求解
min_{ξ,u} J(ξ,u)
s.t. 动力学/运动学约束；r(t)=r_anchor(t)+r_track；m(ξ(t)) ≥ θ + L_m·r(t)（∀t，管约束）；
ξ(T)∈S_fb 或存在认证回退（可撤销性）；Π_u 人格契约约束（v20 定义 38）；控制/执行器约束。
**命题（充分性）**：若上述问题可行且 E、r_track、L_m 均 sound，则输出的 ξ 满足定义 44 的轨迹证书。**实践化**：把 r(t) 视为**时变安全走廊的膨胀半径**，可直接复用走廊式轨迹优化（MINCO/安全飞行走廊），只需把走廊按 r(t) 膨胀；IMU 包络越紧，膨胀越小，可行域越大。

**定义 49（承诺视界、可撤销性与管并发组合）**：**承诺视界** H_c 为最大 H≤T，使得对 ∀t≤H，从 ξ(t) 出发存在一条满足定义 44 的回退轨迹且其管不越出当前认证域；只执行 t∈[0,H_c] 的轨迹。**管并发组合**：并发证书源 j 各自给出管 T_j 与边际场 m_j，组合约束为 ∀j：m_j(ξ(t)) ≥ θ_j + L_{m_j}·r_j(t)，即组合管边际取各源最小值。要求每个低关键任务的 guarantee 不使任一边际在已承诺视界内跌破其阈值（否则触发**管失效谓词**与重认证）。**定理（管 epoch 一致）**：若 (a) 各源管在其 epoch 内 sound，(b) 轨迹只在所有管 epoch 一致（seqlock 快照）时执行，(c) 更新使管失效时立即冻结执行并重认证，则并发下不会出现「用旧管执行新状态」的静默失效。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 CERTIFIED-TRAJECTORY-OPTIMIZER（认证轨迹优化器 CTO）
1. **时变膨胀走廊**：把安全走廊按 r(t)=r_anchor+E(t−τ)+r_track 膨胀；膨胀量由 ICP 实时提供。
2. **管约束优化**：目标函数含「管边际」软/硬约束 m(ξ(t))−L_m r(t)≥θ；求解器用 SQP/iLQR，内层用区间/Lipschitz 下界验证。
3. **可撤销承诺**：维护终端不变集 S_fb 与回退轨迹池；只发布到承诺视界 H_c 的执行片段。
4. **重规划触发**：管半径增长超阈值、激励门翻转、并发管失效、人格契约更新 → 立即重规划或急停。

### 2.2 IP-61 INERTIAL-CERTIFICATE-PROPAGATOR（惯性证书传播器 ICP）
1. **预积分 + 误差包络**：按定义 46 输出 E(Δt)，在线用 NIS/χ² 一致性检验监控包络是否被违反。
2. **激励门**：滑窗信息矩阵 λ_min(J)≥ρ 才启用紧包络，否则膨胀到全局界。
3. **锚点重同步**：绝对证书到达时把 r_k 重置为绝对不确定度，并回灌预积分残差估计偏置。
4. **硬件健康**：饱和、振动、温漂、尺度因子异常检测；异常即膨胀包络并请求提前重锚。

### 2.3 IP-62 TUBE-CERT-VALIDATOR（管证书验证器 TCV）
1. **出管检测**：仿真/实机记录真实状态与管的偏差，统计包含性违约率与保守度。
2. **对抗 IMU 注入**：振动、偏置阶跃、尺度因子误差、饱和、丢帧、时间戳抖动。
3. **回退模糊测试**：随机截断承诺视界、注入管失效，验证回退成功率与最小承诺视界。
4. **管并发一致性**：多源管更新的线性一致性/epoch 快照审计。

```
L1: TRI-FUSE(INT8) + IP-49 LIO → C_ms + B_t + m(x), L_m

    → x_est(t), r_est(t), τ_k, λ_min(J)
L2: CTC + VLM + IP-35 仲裁 → 语义约束 + 候选走廊(含 r_track)

    ← IP-58 CCR(惯性租约 + 管 epoch 快照 + 混合关键级)
    → IP-39 规划/控制(CBF margin = θ + L_m·r(t))
    → IP-45 总线(tube/envelope/excitation/anchor) → IP-53 CMC 最高关键级监控
L4: IP-57 PCE(人格 → v_max/r_track → 可承诺视界) + IP-55 CKB(激励/轨迹指纹)
    ← IP-62 TCV(出管检测 + 对抗 IMU + 回退 fuzz) + IP-54 SCV(Sim)
    → IP-44 蒸馏 + IP-50 课程 → RCA 重颁(envelope-conditioned) → 管证书热更新
运行期：IMU 传播管半径 → CTO 在膨胀走廊内优化 → 签发惯性租约 → 管 epoch 一致快照
        → 执行至承诺视界 → 重锚/激励翻转/管失效 → 重规划或急停
```

## 5. 本轮最大风险

**一句话**：IMU 误差包络 E(Δt) 是本轮唯一的新 soundness 假设，一旦振动、温漂、尺度因子、时间戳抖动等未建模误差使其非保守，证书管半径会被低估，而轨迹优化会主动利用这种「虚假紧致性」把机器人精确推到真实安全边界之外——因此 E96（包络覆盖）与 E101（对抗 IMU）必须设为红线，并默认回退到「全局 Lipschitz 界 + 点式租约」这条不依赖任何 IMU 模型的底线。

# 第 44 轮产物 · 创新点清单 v21：Traj-Cert × IMU-Preintegration（CTO × ICP × TCV）× 时空管证书闭环（四层架构 v9）

> 承接第 43 轮产物 v20。本轮**增量插入** IP-60/61/62，并升级 IP-39/45/47/49/50/51/52/54/55/56/57/58；不推倒任何既有层级。核心是把 v20 的「点式 + 并发租约」证书，升级为「沿轨迹的时空管 + 惯性误差包络」的可验证闭环：**证书从状态标量变成时空管，租约从最坏速度界变成有界误差包络，承诺从全时域变成可撤销视界。**

## 0. 核心 IP 设计

## 2. 关键算法（伪代码）

### IP-61 ICP：预积分、包络、激励门与重同步
```
def preintegrate(imu_buf, tau_k, tau_k1):
    dR, dv, dp = integrate(imu_buf)              # 预积分相对位姿
    return RelPose(dR, dv, dp)

def bias_bound(Sigma_b, chi2):
    # 最坏偏置幅度：由滤波协方差的置信椭球给出
    return sqrt(chi2 * max_eig(Sigma_b))

def envelope(dt, noise, B):
    # 定义 46：位置误差包络，短间隔下二次增长优于 v_max*dt
    ea = KAPPA_A * (noise.sigma_a + B.a) * dt**2
    eg = KAPPA_G * G     * (noise.sigma_g + B.g) * dt**2
    return ea + eg + E_MODEL(dt)

def excitation_gate(imu_buf, window, rho):
    J = sum(H_i.T @ inv(R_i) @ H_i for i in window)   # 偏置信息矩阵
    return min_eig(J) >= rho

def nis_check(residual, Sigma, chi2_thr):
    # 包络一致性：标准化残差平方和不得持续超阈
    return residual.T @ inv(Sigma) @ residual <= chi2_thr

def propagate_cert(anchor, imu_buf, t, rho):
    dt = t - anchor.tau
    rel = preintegrate(imu_buf, anchor.tau, t)
    x = compose(anchor.x, rel)
    if excitation_gate(imu_buf, anchor.window, rho):
        r = anchor.r + envelope(dt, anchor.noise, anchor.bias_bound)  # 紧界
    else:
        r = anchor.r + V_MAX * dt                                    # 全局界回退
    return x, r

def reanchor(anchor, abs_cert):
    # 绝对证书到达：重置半径并回灌残差用于偏置估计
    anchor.x, anchor.r, anchor.tau = abs_cert.x, abs_cert.r, abs_cert.tau
    update_bias(abs_cert.residual, abs_cert.Sigma)
    return anchor
```

### IP-60 CTO：时变膨胀走廊、管约束与承诺视界
```
def radius_fn(t, anchors, imu_buf, persona, rho):
    a = nearest_anchor(anchors, t)
    _, r_est = propagate_cert(a, imu_buf, t, rho)
    return r_est + track_error_bound(persona)      # r_track（FaSTrack 式）

def cto(goal, anchors, persona, m_field, L_m, T):
    corridor = build_corridor(goal, anchors)        # 语义/几何安全走廊
    def tube_constraint(xi, t):
        r = radius_fn(t, anchors, imu_buf, persona, RHO)
        return m_field(xi(t)) - L_m * r - THETA     # 必须 >= 0
    prob = OptProblem(
        cost = J(xi, u),
        constraints = [
            dyn_constraints(xi, u),
            lambda t: tube_constraint(xi, t),
            lambda: terminal_in_set(xi(T), S_FB),    # 可撤销
            persona_constraints(persona),            # v20 定义 38
        ])
    xi = solve_sqp(prob, init=corridor_centerline(corridor))
    if xi is None:
        return negotiate_or_safestop()               # 绝不静默放宽
    H_c = commitment_horizon(xi, radius_fn, S_FB)    # 最大可承诺视界
    return TrajectoryCert(xi, radius_fn, THETA, H_c)

def commitment_horizon(xi, radius_fn, S_fb):
    # 从后往前扫：找到仍能认证回退的最长前缀
    for H in reversed(range(N_SAMPLES)):
        if exists_certified_fallback(xi, H, radius_fn, S_fb):
            return H
    return 0                                          # 每步重规划/急停
```

### IP-51/58 升级：管守卫与管并发一致快照
```
def car_tube_guard(e, xi, t, m_field, L_m, lease_imu, epoch):
    r = lease_imu.radius(t)
    M = m_field(xi(t)) - L_m * r                     # 管边际，替代点式 m_lo
    return (M >= THETA[e]
            and lease_imu.valid(t)                    # 惯性租约新鲜度
            and epoch_consistent(epoch))              # 管 epoch 快照一致

def composite_margin(xi, t, sources):
    # 管并发组合：各源边际约束取最小（定义 49）
    return min(m_j(xi(t)) - L_mj * r_j(t) - theta_j
               for (m_j, L_mj, r_j, theta_j) in sources)

def monitor_snapshot_tube(tube_state):
    e1 = tube_state.epoch; snap = tube_state.value; e2 = tube_state.epoch
    if e1 != e2:
        freeze_and_recertify()                        # 撕裂/陈旧 => 冻结重认证
    return snap
```

def robust_margin(m_field, x, r, L_m):
    # 定义 45：用 Lipschitz 常数把球内最坏边际收缩为标量

## 6. 本轮最大风险

**一句话**：IMU 误差包络 E(Δt) 是本轮唯一的新 soundness 假设，一旦振动、温漂、尺度因子、时间戳抖动等未建模误差使其非保守，证书管半径会被低估，而轨迹优化会主动利用这种「虚假紧致性」把机器人精确推到真实安全边界之外——因此 E96（包络覆盖）与 E101（对抗 IMU）必须设为红线，并默认回退到「全局 Lipschitz 界 + 点式租约」这条不依赖任何 IMU 模型的底线。
