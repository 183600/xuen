# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 4 轮；本轮灵感：「热管理」×「机器人竞赛」）

> R73 把 GAUGE 从具身系统重构为「证据契约的可组合代数」（MMS/DPEM/CCA/ΣREFLEX/CPB，以及末尾的 ECG 证据因果图），并承诺：系统级安全性质在模块热替换、传感器增删、本体迁移下由组合规则自动保持。但 R73 在「本轮最大风险」里亲手写下了它无法回答的问题——**隐共享物理过程耦合**（同一光源、同一振动、**同一温度场**）会让「所有模块证书有效、所有组合校验通过」的模块图给出错误的安全界。R73 只把这条风险写进缓解措施（「环境级共因审计」），**没有把它写进代数**。
>
> 本轮两个灵感正好把这条「最大风险」逼成「第一性原理」：
> - **热管理** → 温度不是一个可以「再加一个模块」的东西。它是**共同原因（common cause）**：电机热 → 扭矩降额；算力热 → WCET 膨胀与限频；相机/IMU 热漂移 → 共享几何偏差；电池热 → 内阻与压降。R73 的 `PAR` 算子假定模块（近似）条件独立、只估一个经验相关系数 ρ̂；而热耦合是**慢变、低秩、共模**的——恰好藏在 ρ̂ 的估计窗口之下，却在安全边界上起决定作用。**共同的物理原因不能模块化为独立证据，必须提升为组合代数里的「条件化算子」。**
> - **机器人竞赛** → 竞赛把上述风险变成**对抗性、资源受限、单次成败**的认证场景：对手/裁判/环境可以把机器人推向热极限，硬实时截止时间必须在降额/限频下仍成立，评分必须抗 Goodhart。认证不能只在名义温度成立，必须在**可达热包络**上成立；而竞赛里的可达热包络是**对手可控**的。
>
> 核心命题：**模块化的边界是共同原因（The boundary of modularity is the common cause）。** 把 R73 的「计量契约代数」升级为 **THERMGAUGE-RAS**（THERMal-aware Metrology with GAUGE audits for RAS）——**热耦合计量契约 × 包络对抗认证**。它不是「再加一个温度模块」，而是给组合代数补上缺失的**共模维度**：显式热状态 θ、热响应契约 TRC、条件化/共模算子（COND/CM）、热债预算 TDB、热包络证书 J_ENV、竞赛级协议 CGP。

## 0. 直觉与动机

**灵感 1（热管理 → 热是共同原因，不是又一个传感器）**
直觉：夏天连续跑十分钟，机器人不是「某个传感器坏了」，而是**所有东西一起慢慢变差**：电机铜损让扭矩上限下降，SoC 限频让感知延迟上升，相机外壳热膨胀让外参漂移，IMU 零偏随温度缓慢爬升，电池内阻让电压在瞬时大电流下塌陷。这些变化**共享同一个慢变量**。于是会出现一类最危险的情形：相机和 IMU 同时朝**彼此相容**的方向漂移——跨模态残差 r 很小、经验相关 ρ̂ 也很小，R73 的 `PAR` 判定「一致 + 近似独立」，**允许缩窄不确定度**；但两者错得一模一样，因为它们被同一个热场推着走。R73 的审计越严格，这个错误越「合规」。

严谨地说，这是**热混淆（thermal confounding）**。设热状态 θ，模块证据 y_i 有均值 h_i(s,θ)、条件方差 Σ_i(s,θ)，且**给定 θ 后条件独立**。则边际协方差
Cov(y_i, y_j) = Cov_θ(h_i, h_j) = J_i Σ_θ J_jᵀ（i≠j），其中 J_i = ∂h_i/∂θ，
即共模分量 **CCM = J Σ_θ Jᵀ**，**秩 ≤ dim(θ)**（低秩！）。边际方差 Var(y_i) = E_θ[Σ_i] + Var_θ(h_i)（全方差律）。R73 用 Σ_i 直接融合，**系统性低估**边际方差，低估量恰为共模项；而 ρ̂ 估计的是全相关，热漂移太慢（热时间常数分钟级，ρ̂ 窗口秒级），在这个窗口里几乎不可辨。结论：**热耦合不是「噪声大一点」，而是「独立性假设在慢时间尺度上失效」。**

**灵感 2（机器人竞赛 → 包络对抗认证与抗 Goodhart 评分）**
直觉：竞赛是最诚实的认证场——它同时施加四件事：(i) **对抗**（对手故意挡路、抢气流、IR 干扰逼你多算）；(ii) **资源争用**（多机共享冷却与算力）；(iii) **硬实时**（裁判只看能否在限时内完成，限频下的 WCET 膨胀必须仍满足截止时间）；(iv) **单次成败 + 诱人的作弊**（为了得分可以牺牲安全）。这正好把「热包络认证」从静态假设变成**对抗博弈**：对手是热状态的**可控扰动**，目标是把你推到 Θ_cert 之外。于是认证必须写成「∀θ ∈ 可达热包络 Θ_reach 的安全」，而不是「θ = 名义温度时的安全」；并且**安全证书必须与竞赛得分解耦**——否则优化得分的人会学会关闭证书（Goodhart）。竞赛还提供了最硬的复现协议：预注册、密封保持集、三方复现、单机 ≤3h。

**灵感 3（综合 → 模块化的边界定理：共模即预算，共模即条件）**
直觉：R73 的宏愿是「一切皆模块」。本轮必须诚实地划出这条宏愿的**边界**。共同原因不能作为独立证据节点并入 `PAR`：把它当成「又一路证据」会**重复计入**它关于状态的信息（θ 是 s 的父，不是 s 的独立观测），得到比真实边际更小的方差——比不加还危险。正确做法只有两条：(1) **条件化**（COND(θ)：给定 θ 再融合）；(2) **保守回加**（CM：把低秩共模 CCM 加回）。这给出一个可证伪的结构性主张：**共模维度的表达力是模块化体系的天花板**；把热当成模块=可被证明的过度自信（定理 32）。与此同时，热是一种**会累积、有时滞、可被规划**的资源——这正好补上 R73 反作用预算里唯一缺失的「延迟」维度：动作既改善证据（走近看）又产生热债（更热 → 未来更差）。反作用从 L1–L4 的「即时」升级到 **L5「延迟热反作用」**，规划必须跨时间尺度权衡。

## 1. 形式化定义（增量：定义 383–398）

**定义 383（THERMGAUGE-RAS 总览与六不变式）** THERMGAUGE-RAS = (MODGAUGE-RAS†, TMM, TRC, TC-CCA, TDB, TVOP, J_ENV, CGP)。**六不变式** = R73 五条 + **(vi) 共模完备性**：模块图中任一「条件独立」组合边，必须显式声明其所条件的共同原因集合 K（至少含热状态 θ_t）；未声明 K 的 `PAR` 边一律按「最坏共模」处理（禁止缩窄），缺声明不得进入证书路径。R73 的「隐共享物理过程」从此成为**必须声明、可审计、可证伪**的图性质，而不是文档里的风险脚注。

**定义 384（热状态与热计量模块 TMM）** 热状态 θ_t ∈ Θ ⊂ ℝ^{d_θ}，d_θ ≤ 8（电机/驱动/算力/电池/环境/相机），动力学用 RC 网络（Foster/Cauer）：
θ_{t+1} = A θ_t + B u_t + E w_t + c，谱半径 ρ(A) < 1（被动散热使热状态**收缩**），
u_t =（关节力矩、算力频率、风扇、运动）为执行/散热输入，w_t 为扰动（对手气流、环境温度）。**TMM** 用 (i) 板载温度传感器（电机/驱动/SoC）、(ii) 电气代理（电流²×内阻产热、占空比）、(iii) 历史，做贝叶斯观测得 θ̂_t, Σ_θ,t。**关键区分**：R73 的 χ_R 是「我的动作如何调制我的噪声」；θ 是「一个共同隐藏状态如何**同时**调制所有模块的噪声与有效域」。前者是动作通道，后者是**共同原因**。

**定义 385（热响应契约 TRC）** 每个证据模块 i 的 EC 增加热响应字段 ρ_i: Θ → (b_i(θ), Σ_i^{infl}(θ), D_i(θ), W_i(θ))：热致偏差、方差膨胀、有效域收缩、WCET 膨胀。要求 (a) 分段 Lipschitz；(b) 在 Θ_cert 上可识别（实验 E397）；(c) WCET 膨胀进入 RTA，**热致限频不得破坏硬实时**。于是模块证书从 J(module) 变为**包络参数化** J(module; Θ_cert)。

**定义 386（热混淆组合代数 TC-CCA）** 在 R73 的 SER/PAR/VETO 上增加两个算子与一条修正：
- **COND(θ)**：条件化算子。把边 e 的证据联合分布改写为 p(y|s,θ)=∏_i p(y_i|s,θ)，即「给定 θ 后模块条件独立」。**任何 PAR 缩窄都必须在 COND(θ) 下进行。**
- **CM(J, Σ_θ)**：共模算子。给定热敏感度 J_i=∂h_i/∂θ，共模协方差 CCM = J Σ_θ Jᵀ（低秩，rank ≤ d_θ）；Σ_marg = Σ_cond + CCM。
- **PAR′（修正并联）**：缩窄允许当且仅当 (a) 跨模态 conformal 审计通过；(b) TMM 不确定性 tr(Σ_θ) < τ_θ；(c) 条件相关 |ρ̂(θ)| < ρ_max；**(d) 缩窄量不超过条件精度，且必须把 CCM 保守回加**。任一不满足 ⇒ 退到 max(u_A,u_B) + 共模上界。
- **VETO 不变**：热致否决（θ > θ_veto 或降额后超出安全包络）继承非补偿语义。

**定义 387（共模融合规则与条件覆盖）** 条件高斯融合（信息形式）：Λ_cond = Σ_A^{-1} + Σ_B^{-1}（审计通过时），融合后**必须回加共模**：Σ_out = (Λ_cond)^{-1} + CCM，或等价地用 Σ_marg 保守融合。**共模零缩窄引理**：若 J_A = J_B（两模块共享同一热致偏差方向），则该方向上的融合方差缩减为 0——**传感器融合对共模失效**。条件 conformal：覆盖率必须在 (θ, s) 联合上校准，或对 θ 的不确定性取 union bound（引理 40）。

**定义 388（热债预算 TDB）** 在 ΣREFLEX 的即时反作用预算之外，增加**延迟**热债：
D_th(t) = Σ_{k=0}^{t} γ^{t−k} (θ_k − θ_amb)ᵀ Q (θ_k − θ_amb)，γ ∈ (0,1]（或连续形式 ∫）。
预算约束 D_th(t) ≤ D_total ∀t；动作 g 的边际热债 c_heat(g) = E[θ_{t+1} − θ_t | g]（由 TMM 解析）。ΣREFLEX 升级为 **ΣREFLEX†**：在 ψ/z/c/v 之外增加 **h（热）通道**，且 h 通道**带时滞**（热时间常数 τ_th ≫ 控制周期）。稳态集 Ω_safe 增加 Θ_safe，并要求**前瞻**：E[θ_{t+H}|g] ≤ θ_cert，H 为热时滞视野。

**定义 389（热-视角规划 TVOP）** 把 R73 的 PVOP 升级为**双时间尺度**：
a* = argmax_a [ Progress(a) − λ·E[u_depth^next(a)] − Σ_i c_reflex^i(a) − μ·Ĉ_heat(a; H) ]
s.t. REG 时序契约、V_safe、C_safe、**Θ_safe 与热障条件（定义 391）**。
关键：Ĉ_heat 用 TMM 的 RC 模型**解析**给出 H 步热债（零 rollout），并在**热时间尺度（1Hz）事件触发**重规划（θ̂ 变化 > δ 或热障接近），而证据/视角规划仍在 20Hz。**时间尺度分离**使 TVOP 不侵占 PVOP 的 2ms 预算。

**定义 390（可达热包络与对抗热强制）** Θ_reach = 从 θ_0 出发、在允许动作与**对抗扰动**（对手阻挡气流、外加热源、强制急停/急加速、IR 干扰迫使更多算力）下的可达集。认证必须在 Θ_cert ⊇ Θ_reach 上成立，或证明 Θ_reach ⊆ Θ_cert（热障不变集）。竞赛级定义：**对手是热状态的可控扰动**，认证 = 对 ∀θ∈Θ_reach 的安全，而非名义 θ_0。

**定义 391（热障函数与不变集）** 构造 B: Θ → ℝ，Θ_cert = {θ : B(θ) ≤ 0}。要求存在控制策略使 B(θ_{t+1}) ≤ (1−α) B(θ_t)（离散 CBF 条件）在允许动作内可满足；若某动作使条件不可满足，触发**热反作用**（降 duty / 降扭矩 / 卸载算力 / 拒绝该动作），由 TDB 记账。热障条件进入 J_ENV（定义 393）。注：CBF 本身是已知工具，本文贡献是把它接入证据契约代数而非发明它。

**定义 392（热 stub 与保守退化）** 热观测失效 / θ̂ 不可信 / TRC 识别失效 ⇒ **热 stub**：θ̂ ← θ_max（最坏包络），CCM ← 最坏共模（J 未知 ⇒ 视作完全相关），所有 PAR 缩窄禁止，模块退化为「最坏相关」融合；安全侧只增不减。区别于 R73 的模块 stub（证据∅）：热 stub 是**共模保守化**，不是丢弃证据。

**定义 393（热包络证书 J_ENV）** J_ENV = ⊗_i J(module_i; Θ_cert) ⊗ J_comp(MReg, COND/CM) ⊗ J_th(TMM, TRC, B)。校验：∀θ∈Θ_cert，各模块 TRC 成立、WCET 膨胀满足 RTA、CCM 被正确回加、TDB 闭合、热障不变。Valid(J_ENV) ⇒ Valid(J_THERM) ⇒ 在热包络内物理风险 ≤ ε_th。R73 的 J_MOD 是 θ≡θ_0、CCM=0 的特例。

**定义 394（热增强 ECG）** 在 R73 IP-302 的 ECG 上，把 θ 作为**共同父节点**：θ → 各证据节点，边权 = J_i；残差共模 = 未被 θ 解释的低秩部分。识别条件：给定 θ 后无未观测共因（**热充分性假设 A_TH**）。违背 A_TH ⇒ 证书降级为「有未建模共因」，并禁止 PAR 缩窄——把「还有别的共因吗」变成运行时可检的否决条件。

**定义 395（竞赛级协议 CGP）** CGP =（MB4 热包络基准，MB5 对抗竞赛基准，密封保持集 SEAL-C，预注册评分）。MB4：受控热斜坡 × 负载 × 降额 × 限频 × 对手热源；MB5：对抗竞赛场景（资源争用、IR 互扰、强制热、单次评分）。硬约束：认证指标与竞赛得分**解耦**（安全证书不可被得分优化绕过），预注册 + 三方复现。每个基准 ≤ 3h 单机可复现（热时间常数用加速老化或半实物台架）。

**定义 396（抗 Goodhart 评分与主张绑定）** 竞赛得分 S = f(任务分, 安全否决, 热债)；证书**只认预注册安全指标，不认 S**。新主张（延续 R73 的 C1–C3）：
- **C4（热共模条件化）**：在 COND(θ)+CM 下的融合，比 R73 的经验 ρ̂ 融合在热极限下**条件覆盖率与碰撞率**显著更优（慢变共模不被 ρ̂ 检出）。
- **C5（热债耦合规划）**：TVOP 在同等安全下比 PVOP/热盲规划**峰值温度更低、限频/降额事件更少、完成率更高**，且有限停止与预算闭合可证。
- **C6（包络对抗认证）**：J_ENV 在对手热强制下**假接受率**显著低于名义认证，且假拒绝率可接受；认证成本随模块数而非系统规模增长（延续 R73 C3）。
工程附件（风扇控制、外壳设计、散热器选型等）不进核心认证路径，不入正文。

**定义 397（多机共享热环境）** 多机器人共享气流/环境温度 ⇒ θ 跨机耦合：θ_j 通过共享环境温度与气流相互影响。扩展 R73 定义 382：除 IR 协商外增加**热协商**（降额时间片、任务分配避开热热点）；对手恶意加热/挡风视作对抗扰动，进入 Θ_reach。

**定义 398（热复杂度结构上限）** 扩展 R73 定义 377：|Θ| ≤ 8（热状态维度）、TRC 分段数 ≤ 12、CCM 秩 ≤ d_θ、共模边数 ≤ |E_M|；热时间尺度与控制/计量时间尺度分离比 ≥ 100×（否则 TDB 与 RTA 耦合，需显式最坏情况分析）。全部为可审计的图/模型性质，而非文档纪律。

## 2. 关键算法骨架

```python
# IP-303 TMM：热状态观测（1Hz，RC 网络 + 板载温度 + 电气代理）
class ThermalMetrologyModule:
    def update(self, temps, currents, duty, ambient, dt):
        u = pack_input(currents, duty)                    # 产热输入
        theta_pred = self.A @ self.theta + self.B @ u + self.c   # RC 前向
        H = self.C                                        # 观测矩阵（温度传感器）
        K = self.P @ H.T @ inv(H @ self.P @ H.T + self.R)
        self.theta = theta_pred + K @ (temps - H @ theta_pred)
        self.P = (I - K @ H) @ self.P @ self.A.T + self.Q  # 协方差传播
        self.theta = clamp(self.theta, -40, self.theta_max)
        return ThetaHat(theta=self.theta, cov=self.P,
                        valid=self.calib.sane(self.theta, temps),
                        CCM_safe=self.theta_max - self.theta)  # 距热边界的余量

# IP-304 TRC：热响应契约（每个模块声明自己随 θ 怎么坏）
@dataclass(frozen=True)
class ThermalResponse:
    bias:    Callable[[Theta], Vector]     # b_i(θ)：热致偏差（相机外参/IMU 零偏）
    inflate: Callable[[Theta], Matrix]     # Σ_i^infl(θ)：方差膨胀
    domain:  Callable[[Theta], Predicate]  # D_i(θ)：有效域收缩（降额包络）
    wcet:    Callable[[Theta], float]      # W_i(θ)：限频导致的 WCET 膨胀
    jac:     Callable[[Theta], Matrix]     # J_i = ∂h_i/∂θ（共模载荷）
    def in_envelope(self, th): return self.domain(th) and self.wcet(th) <= self.wcet_budget

# IP-305 TC-CCA：条件化 + 共模回加的组合
def compose_thermal(a_ev, b_ev, op, theta_hat, thm, audit):
    if op == 'SER':                                    # 串联：单调，域取交（含 D_i(θ)）
        return Ev(u=a_ev.u + lipschitz(b_ev, a_ev.u),
                  D=a_ev.D & b_ev.D & a_ev.trc.domain(theta_hat) & b_ev.trc.domain(theta_hat),
                  tau=a_ev.tau.merge(b_ev.tau), veto=a_ev.veto | b_ev.veto)
    if op == 'PAR':                                    # 并联：先 COND(θ)，再决定是否缩窄
        th = theta_hat
        if th.valid and tr(th.cov) < TAU_THETA:        # 条件(b) 热观测可信
            r = cross_modal_residual(a_ev, b_ev)
            if audit.conformal_covers(r, cond=th):     # 条件(a) 条件 conformal
                if abs(audit.cond_corr(a_ev, b_ev, th)) < RHO_MAX:   # (c) 条件相关
                    cond = fuse(a_ev, b_ev, audit.cond_corr(a_ev, b_ev, th))
                    CCM  = a_ev.trc.jac(th) @ th.cov @ b_ev.trc.jac(th).T   # 低秩共模
                    return Ev(u=sqrt(cond.u**2 + lam_max(CCM)),        # (d) 保守回加
                              D=cond.D, tau=cond.tau, veto=cond.veto,
                              ccm=CCM, audit='PAR_COND_OK')
        # 任一条件不满足：最坏共模，禁止缩窄
        CCM_worst = max_common_mode(a_ev, b_ev)        # J 未知 ⇒ 完全相关上界
        return Ev(u=max(a_ev.u, b_ev.u) + sqrt(lam_max(CCM_worst)),
                  D=a_ev.D & b_ev.D, tau=a_ev.tau.merge(b_ev.tau),
                  veto=a_ev.veto | b_ev.veto | {'PAR_THERMAL_VETO'})
    if op == 'VETO':                                   # 否决：非补偿（含热否决）
        if a_ev.veto or b_ev.veto or not a_ev.trc.in_envelope(theta_hat):
            return Ev(valid=False, veto=a_ev.veto | b_ev.veto | {'THERMAL_VETO'})
        return Ev(u=min(a_ev.u, b_ev.u), D=a_ev.D & b_ev.D)

# IP-306 TDB：热债预算 + 热障（与 ΣREFLEX† 耦合）
def thermal_step(theta_hat, g, budget, barrier):
    heat = whm.predict_heat(theta_hat, g)              # 解析 H 步热债（RC 闭式）
    debt = budget.spent + heat.cumulative
    if debt > budget.D_total: return None, 'TDB_EXCEEDED'          # 预算拒绝
    if not barrier.invariant_after(theta_hat, g):                  # 热障不稳
        g = derate(g)                                  # 热反作用：降 duty/扭矩/算力
        if not barrier.invariant_after(theta_hat, g): return None, 'THERMAL_BARRIER'
    return g, 'OK'

# IP-307 TVOP：双时间尺度热-视角规划（1Hz 事件触发；不占 20Hz 预算）
def thermo_viewpoint_plan(b_t, mods, theta_hat, risk, last_plan):
    if not event_trigger(theta_hat, last_plan, delta=DELTA_TH):  # 热变化小 → 复用
        return last_plan
    def J(a):
        prog   = task_progress(b_t, a)
        u_next = sum(m.ec.chi_R(a).expected_u(state[m]) for m in depth_mods)
        reflex = sum(m.reflex_cost_estimate(state[m], m.ec.chi_R(a)) for m in mods)
        heat   = mu * whm.expected_debt(theta_hat, a, horizon=H)    # 解析、带时滞
        return prog - risk.lam * u_next - reflex - heat
    return optimize_under_reg_contract(J, horizon=0.5,
                                       extra_constraint=barrier_safe(theta_hat))

# IP-308 J_ENV：热包络证书（θ 参数化）
def J_ENV(mreg, theta_grid, thm, trc, barrier, tdb):
    return all(trc[i].in_envelope(th) for i in mreg.nodes for th in theta_grid) \
       and mreg.audit_common_mode()                    # 每条 PAR 边声明了 K
       and barrier.invariant_over(theta_grid)          # Θ_reach ⊆ Θ_cert
       and tdb.closed()

# IP-309 CGP：竞赛级协议（对抗热强制 + 抗 Goodhart）
def contest_round(policy, adversary, enforcer):
    for episode in pre_registered_episodes():          # 密封 SEAL-C，固定种子
        theta = nominal_theta
        while not done:
            theta = adversary.force_thermal(theta, policy)     # 对手推热
            action = policy.act(obs, theta)
            veto = enforcer.safety_certificate(action, theta)  # 证书与得分解耦
            if veto.unsafe: record_reject(); break
            obs, score, theta = env.step(action)
        log(score, peak_theta=theta, derates=n_derates, cert=veto)   # 预注册指标
    return sealed_report()                               # 三方复现，防 Goodhart
```

## 3. 推导

**引理 38（热混淆不等式：独立融合系统性过度自信）** 设模块给定 θ 条件独立，边际协方差 Σ_marg = Σ_cond + CCM，CCM = J Σ_θ Jᵀ ⪰ 0（rank ≤ d_θ）。则任何忽略 θ 的融合其输出协方差 Σ_naive ≺ Σ_marg（Loewner 序），低估量恰为 CCM；且 rank(CCM) ≤ d_θ 说明共模是**低秩、结构化、可由 θ 敏感度识别**的，不需要（也无法可靠地）用经验 ρ̂ 去估。系：**R73 的 ρ̂ 在慢变共模下不是「估不准」，而是「估不到」——窗口内几乎无变化。**

**引理 39（共模零缩窄：融合对共模失效）** 若两模块共享同一热致偏差方向 J_A = J_B = j，则在该方向上 Cov(y_A,y_B)=jΣ_θjᵀ=Var 分量，条件相关系数→1，融合的最优精度增量→0。⇒ 传感器数量增加**不能**降低共模方向的不确定度；抵御共模只能靠**独立物理机制**（不同原理、不同热路径）或**条件化后剩余的独立分量**。系：**多传感器 ≠ 多信息——共模是「伪多样性」。**

**引理 40（条件覆盖与 θ 不确定性的并集界）** 若对每个固定 θ 有条件 conformal 覆盖 ≥ 1−α，且 θ̂ 的可信集 Θ_hat 以概率 ≥ 1−β 包含真 θ，则对 θ 取并集的边际覆盖 ≥ 1−α−β。⇒ 条件化不是免费的：**热观测不确定性直接折损覆盖率**；这给出 τ_θ 阈值的正确刻度（定义 386(b)），而不是拍脑袋。

**引理 41（热障不变性 ⇒ 包络内认证有效）** 若 (i) 对 ∀θ∈Θ_reach 存在动作使 B(θ_{t+1}) ≤ (1−α)B(θ_t)（离散 CBF），(ii) 热反作用在该动作不可行时拒绝动作，(iii) 初始 θ_0∈Θ_cert，则 ∀t，θ_t∈Θ_cert。结合 TRC 的 Lipschitz 与引理 38 的保守回加，J_ENV 的每一项在轨迹上保持。系：**「包络内安全」可被在线强制执行，无需假设对手仁慈。**

**引理 42（时间尺度分离与延迟反作用有限停止）** 热动力学收缩（ρ(A)<1）且 τ_th ≫ 控制周期 ⇒ 在控制/计量时间尺度上 θ 视为常数，(x, θ) 构成慢-快奇异摄动系统；快子系统沿用 R73 引理 36 的有限停止，慢子系统由 TDB（γ-折扣正成本 + 收缩）保证 D_th 有界。⇒ **延迟热反作用不破坏有限停止**，TVOP 只需 1Hz 事件触发。系：**加一层「延迟」不炸预算——因为热自己会冷却。**

**定理 30（严格包含：THERMGAUGE ⊒ MODGAUGE ⊒ EMBODIED ⊒ R71/R68）** 令 θ ≡ θ_0 为常数、TMM 输出平凡、CCM = 0、TRC 恒等、TDB 不激活，则 COND 退化为恒等、CM 退化为零、TVOP 退化为 PVOP、J_ENV 退化为 J_MOD。由 R73 定理 27 与引理 35，逐指令等于 R73/R72/R71/R68。**安全侧只增不减；效率仅在热观测与共模建模有效时获益。**

**定理 31（包络对抗证书 ⇒ 对抗热强制下安全）** 在 A_TH（热充分性：给定 θ 后无未观测共因）、A_TRC（热响应可识别且分段 Lipschitz）、A_BAR（热障不变）、A_CONF（条件 conformal 校准）下：Valid(J_ENV) ⇒ 对 ∀θ∈Θ_reach（含对手强制）物理执行风险 ≤ ε_th。证明沿定理 28 的骨架，但把「契约表达力」换成「**共同原因表达力**」，并额外要求 A_TH：**未建模的共因会同时击穿所有模块证书**——这正是证明的承重点。

**定理 32（模块化边界：共模不可模块化）** 若把热共同原因当作一个独立证据节点并入 `PAR`，其融合精度为 Λ_naive = Σ_cond^{-1} + Σ_θ^{-1}；而正确边际精度满足 Λ_marg ⪯ (Σ_cond + CCM)^{-1} ⪯ Σ_cond^{-1}。因 θ 是 s 的共同父而非独立观测，Σ_θ^{-1} 贡献的是「关于 θ 的信息」被错误地当成「关于 s 的独立信息」，除非 J_i 正交且 Σ_θ 完美已知，否则 Λ_naive ≻ Λ_marg（过度自信）。⇒ **共同原因必须条件化（COND）或保守回加（CM），不能作为模块并列**。系：**R73「一切皆模块」的边界被精确定位——模块化适用于「条件独立于共同原因之后」的组件，不适用于共同原因本身。**

## 6. 本轮最大风险

**一句话**：THERMGAUGE 把 R73 的「隐共享物理过程」从一个风险脚注提升为**可审计的共模维度**，但这也正是它最危险的地方——一旦系统显式建模并条件化于 θ，它就可能**高估自己已经「处理了所有共同原因」**，从而在 COND(θ) 之后更放心地缩窄不确定度；若真实世界还存在热之外、同样慢变且同样低秩的共因（湿度、电池老化、网络抖动、地面摩擦随温升变化、对手施加的持续机械扰动），这些未被声明的共因会**借助「热已处理」的证书**重新引入 R73 警告过的同型错误，而且这次证书看起来更强、审计日志更完整。

次级风险与缓解：
1. **A_TH（热充分性）被违背** → 运行时共因残差检验（ECG 边残差是否仍低秩/是否与 θ 无关）；违背即禁用 PAR 缩窄并降级证书（定义 394）。
2. **TRC 表达力不足（热响应非分段 Lipschitz / 迟滞）** → 加入迟滞项与查表回退；有效域硬边界 + 热包络外一律热 stub。
3. **热观测延迟/稀疏（传感器少）** → RC 先验 + 电气代理；tr(Σ_θ) 超阈即禁缩窄（定义 386(b)），并用以引理 40 的并集界调覆盖率。
4. **时间尺度分离失效（急速热冲击）** → 检测 |dθ/dt| 超阈，临时升频 TMM 到控制尺度并冻结 PAR/缩窄；退化为纯保守融合。
5. **热障保守导致可用性下降（降额太狠）** → 把降额当可优化变量（TVOP 的 μ 可调），用 E401 的完成率-安全 Pareto 曲线预注册选择。
6. **对抗者操纵热观测（传感器投毒/热冲击造假）** → 热观测多源交叉（电气代理 vs 温度传感器 vs 性能代理）；单源不定案，热 stub 优先。
7. **CGP 评估过拟合/Goodhart** → 密封 SEAL-C + 预注册 + 三方复现（E404/E405）；证书与得分结构解耦，得分不作为认证输入。
8. **多机热耦合的博弈不稳定** → 热协商带优先级与公平性约束；检测到恶意加热即进入 Θ_reach 对抗包络（定义 397）。

> - **TRC**：热响应契约——每模块声明 bias/infl/有效域/WCET 随 θ 的变化，证书变为**包络参数化** J(module; Θ_cert)；
> - **TC-CCA**：组合代数补上 `COND(θ)`（条件化）与 `CM`（低秩共模回加），`PAR` 缩窄必须条件化且保守回加（共模零缩窄）；
> - **TDB**：热债预算，给 ΣREFLEX 增加带**时滞**的 h 通道（反作用 L5）；
> - **TVOP**：双时间尺度热-视角规划，热债解析、1Hz 事件触发，不侵占 20Hz 预算；
> - **J_ENV**：热包络证书，Valid ⇒ 在可达热包络（含对手热强制）内安全；
> - **CGP**：竞赛级协议——对抗热强制 + 抗 Goodhart 评分 + 密封三方复现。
>
> 核心命题：**模块化的边界是共同原因（The boundary of modularity is the common cause）——共同原因不能被模块化为独立证据，只能被条件化进组合代数。**
>
> IP 编号：IP-303~310（共 8 个）+ R73 组件的 † 化。理论姿态延续：**新维度是旧代数的严格泛化，安全侧只增不减，退化链逐指令等价（θ≡const ⇒ R73）。**

## 2. 形式化定义（要点版）

**定义 383（总览与六不变式）** R73 五不变式 + (vi) 共模完备性：条件独立边必须声明共同原因集合 K（至少含 θ）；未声明 K 的 PAR 按最坏共模处理、禁止缩窄。R73 的「隐共享物理过程」成为可审计图性质。

**定义 384（TMM）** θ 低维慢变，RC 收缩动力学；θ 是共同原因（同时调制所有模块噪声与域），不是 χ_R 动作通道。TMM 融合温度传感器 + 电气代理 + 历史，输出 θ̂、Σ_θ、热边界余量。

**定义 385（TRC）** 每模块声明 (bias, inflate, domain, wcet, jac) 随 θ 的分段 Lipschitz 函数；WCET 膨胀入 RTA；证书包络参数化。

**定义 386（TC-CCA）** SER 域取交需含 D_i(θ)；PAR′ 四条件全满足才许缩窄并回加 CCM，否则最坏共模 + `PAR_THERMAL_VETO`；VETO 含热否决。

**定义 387（共模融合）** Σ_out=(Σ_A^{-1}+Σ_B^{-1})^{-1}+CCM；共模零缩窄：J_A=J_B 时该方向融合增益为 0。条件 conformal 覆盖率按引理 40 的并集界折损。

**定义 388（TDB）** 延迟热债 + γ-折扣 + 有界；ΣREFLEX† 增 h 通道（时滞）；Ω_safe 增 Θ_safe 且前瞻 E[θ_{t+H}|g]≤θ_cert。

**定义 389（TVOP）** 热-视角联合目标，Ĉ_heat 解析（RC 闭式，零 rollout），1Hz 事件触发（θ̂ 变化>δ 或热障接近），20Hz PVOP 不变。

**定义 390（对抗热包络）** Θ_reach 含对手热强制；认证 = ∀θ∈Θ_reach 安全，而非名义 θ_0。

**定义 391（热障）** B(θ)≤0 定义 Θ_cert；离散 CBF B(θ_{t+1})≤(1−α)B(θ_t)；不可满足则热反作用降额/拒绝。CBF 是已知工具，贡献在接入证据契约代数。

**定义 392（热 stub）** 观测/TRC 失效 ⇒ θ̂←θ_max、CCM←最坏共模（完全相关）、禁缩窄；保守化而非丢证据。

**定义 393（J_ENV）** TRC(θ) ∧ WCET∧CCM∧TDB∧热障；Valid(J_ENV) ⇒ Valid(J_THERM) ⇒ 包络内风险≤ε_th；J_MOD 是 θ≡θ_0、CCM=0 特例。

**定义 394（热增强 ECG）** θ 作共同父节点，边权 J_i；残差共模=未解释低秩部分；违背 A_TH ⇒ 证书降级 + 禁 PAR 缩窄。

**定义 395（CGP）** MB4/MB5 + SEAL-C + 预注册 + 三方复现；安全证书与竞赛得分结构解耦；≤3h 单机可复现。

**定义 396（抗 Goodhart 与主张）** C4 热共模条件化 / C5 热债耦合规划 / C6 包络对抗认证；附件不进核心认证路径。

**定义 397（多机热耦合）** θ 跨机经共享环境/气流耦合；扩展定义 382 增加热协商（降额时间片、任务分配避热点）；恶意加热入 Θ_reach。

**定义 398（热复杂度上限）** |Θ|≤8、TRC 分段≤12、rank(CCM)≤d_θ、共模边≤|E_M|、热-控制时间尺度分离≥100×；均为可审计模型/图性质。

## 3. 关键算法伪代码

```python
# IP-303 TMM：热状态观测（1Hz，RC + 卡尔曼）
class ThermalMetrologyModule:
    def update(self, temps, currents, duty, ambient, dt):
        u = pack_input(currents, duty)
        theta_pred = self.A @ self.theta + self.B @ u + self.c
        H = self.C
        K = self.P @ H.T @ inv(H @ self.P @ H.T + self.R)
        self.theta = clamp(theta_pred + K @ (temps - H @ theta_pred), -40, self.theta_max)
        self.P = (I - K @ H) @ self.P @ self.A.T + self.Q
        return ThetaHat(theta=self.theta, cov=self.P,
                        valid=self.calib.sane(self.theta, temps),
                        margin=self.theta_max - self.theta)

# IP-305 TC-CCA：COND(θ) + CM 回加（PAR 四条件）
def compose_thermal(a_ev, b_ev, op, th, thm, audit):
    if op == 'SER':
        return Ev(u=a_ev.u + lipschitz(b_ev, a_ev.u),
                  D=a_ev.D & b_ev.D & a_ev.trc.domain(th) & b_ev.trc.domain(th),
                  tau=a_ev.tau.merge(b_ev.tau), veto=a_ev.veto | b_ev.veto)
    if op == 'PAR':
        if th.valid and trace(th.cov) < TAU_THETA:                 # (b)
            r = cross_modal_residual(a_ev, b_ev)
            if audit.conformal_covers(r, cond=th):                  # (a)
                rho = audit.cond_corr(a_ev, b_ev, th)
                if abs(rho) < RHO_MAX:                             # (c)
                    cond = fuse(a_ev, b_ev, rho)
                    CCM = a_ev.trc.jac(th) @ th.cov @ b_ev.trc.jac(th).T
                    return Ev(u=sqrt(cond.u**2 + lam_max(CCM)),    # (d) 保守回加
                              D=cond.D, tau=cond.tau, veto=cond.veto, ccm=CCM)
        CCM_worst = max_common_mode(a_ev, b_ev)                    # J 未知 ⇒ 完全相关
        return Ev(u=max(a_ev.u, b_ev.u) + sqrt(lam_max(CCM_worst)),
                  D=a_ev.D & b_ev.D, tau=a_ev.tau.merge(b_ev.tau),
                  veto=a_ev.veto | b_ev.veto | {'PAR_THERMAL_VETO'})
    if op == 'VETO':
        if a_ev.veto or b_ev.veto or not a_ev.trc.in_envelope(th):
            return Ev(valid=False, veto=a_ev.veto | b_ev.veto | {'THERMAL_VETO'})
        return Ev(u=min(a_ev.u, b_ev.u), D=a_ev.D & b_ev.D)

# IP-306 TDB：热债 + 热障（与 ΣREFLEX† 耦合）
def thermal_step(th, g, budget, barrier):
    heat = whm.predict_heat(th, g)                        # 解析 H 步热债
    if budget.spent + heat.cumulative > budget.D_total: return None, 'TDB_EXCEEDED'
    if not barrier.invariant_after(th, g):                 # 热障不稳
        g = derate(g)                                      # 热反作用
        if not barrier.invariant_after(th, g): return None, 'THERMAL_BARRIER'
    return g, 'OK'

# IP-307 TVOP：双时间尺度（1Hz 事件触发，不占 20Hz）
def thermo_viewpoint_plan(b_t, mods, th, risk, last_plan):
    if not event_trigger(th, last_plan, delta=DELTA_TH): return last_plan
    def J(a):
        return (task_progress(b_t, a)
                - risk.lam * sum(m.ec.chi_R(a).expected_u(state[m]) for m in depth_mods)
                - sum(m.reflex_cost_estimate(state[m], m.ec.chi_R(a)) for m in mods)
                - risk.mu * whm.expected_debt(th, a, horizon=H))      # 延迟热债
    return optimize_under_reg_contract(J, horizon=0.5, extra=barrier_safe(th))

# IP-308 J_ENV：热包络证书
def J_ENV(mreg, theta_grid, trc, barrier, tdb):
    return (all(trc[i].in_envelope(th) for i in mreg.nodes for th in theta_grid)
            and mreg.audit_common_mode()          # 每条 PAR 边声明了共同原因 K
            and barrier.invariant_over(theta_grid) # Θ_reach ⊆ Θ_cert
            and tdb.closed())

# IP-310 THERMGAUGE 主闭环（热域 1Hz + 感知/计量/控制三域）
def THERMGAUGE_round(M, obs, audio, tac_frame, depth_img):
    if M.clock.due_thermal():                              # === 热域 1Hz ===
        th = M.tmm.update(M.temps, M.currents, M.duty, M.ambient, M.dt)
        if not th.valid: th = thermal_stub(M.tmm)          # 共模保守化
        M.barrier.update(th); M.tdb.step(th, M.last_g)
        M.tvop = thermo_viewpoint_plan(M.bse.latest, M.mods, th, M.risk, M.tvop)
    d_ev = M.dpe.update(depth_img, rgb, M.cam_state, M.motion, M.peers, th)
    t_ev = M.dmem.update(tac_frame, M.last_action, th)
    fused = compose_thermal(d_ev, t_ev, 'PAR', th, M.tmm, M.audit)    # IP-305
    if M.clock.due_metric():                               # === 计量域 50Hz ===
        b_t = M.bse.step_full(..., fused=fused)
        z_dist, _, _ = M.irl.update(M.y_intent_buf, psi_hat, b_t)
        g = M.ervoi.choose(b_t, psi_hat, z_dist, fused.c_dist, M.budget, M.fmp, M.bse)
        g2, _ = thermal_step(th, g, M.tdb, M.barrier)      # IP-306 热反作用
        if g2 is not None: M.last_g = g2
        M.snapshot.write(b_t, z_dist, fused, th, M.state); M.mreg.audit()
    snap = M.snapshot.read_latest()                        # === 控制域 1kHz ===
    assert snap.th.wcet_ok(M.rtm)                          # 限频后仍满足 RTA
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.fused.u, snap.th.infl), M.risk_params)
    k = M.c_ras_wm.certified_prefix(M.ach.propose_ctrl(..., pvop_bias=snap.tvop), lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, J_ENV(M.mreg, snap.th.grid, M.trc, M.barrier, M.tdb)
```

## 4. 推导

**引理 38（热混淆不等式）** 条件独立给定 θ ⇒ Σ_marg = Σ_cond + CCM，CCM=JΣ_θJᵀ ⪰ 0、rank≤d_θ。忽略 θ 的融合 Σ_naive ≺ Σ_marg，低估量=CCM。系：**ρ̂ 在慢变共模下不是估不准，而是估不到。**

**引理 39（共模零缩窄）** J_A=J_B=j ⇒ 该方向条件相关→1，融合精度增量→0。⇒ 多传感器≠多信息，共模是「伪多样性」，只能靠独立物理机制化解。

**引理 40（条件覆盖并集界）** 条件 conformal ≥1−α 且 θ̂ 可信集以概率 ≥1−β 含真 θ ⇒ 边际覆盖 ≥1−α−β；τ_θ 阈值由此定标。

**引理 41（热障不变性）** 离散 CBF + 动作不可行即拒绝 + θ_0∈Θ_cert ⇒ ∀t θ_t∈Θ_cert；J_ENV 沿轨迹保持。系：包络内安全可在线强制，无需对手仁慈。

**引理 42（时间尺度分离与有限停止）** ρ(A)<1 + τ_th≫周期 ⇒ 慢-快奇异摄动；快子系统沿用引理 36，慢子系统由 TDB（γ-折扣正成本）有界。⇒ 延迟热反作用不破坏有限停止。

**定理 30（严格包含）** θ≡θ_0、Σ_θ=0、TRC 恒等、TDB 关闭 ⇒ COND/CM 退化、TVOP≡PVOP、J_ENV≡J_MOD，逐指令等于 R73/R72/R71/R68（沿定理 27/引理 35）。安全侧只增不减。

**定理 31（包络对抗证书 ⇒ 对抗热强制下安全）** 在 A_TH、A_TRC、A_BAR、A_CONF 下，Valid(J_ENV) ⇒ ∀θ∈Θ_reach（含对手热强制）风险 ≤ε_th。证明承重点：**共同原因表达力 A_TH**——未建模共因会同时击穿所有模块证书。

**定理 32（模块化边界：共模不可模块化）** 把 θ 当独立 PAR 节点得 Λ_naive=Σ_cond^{-1}+Σ_θ^{-1}，而正确边际 Λ_marg⪯(Σ_cond+CCM)^{-1}⪯Σ_cond^{-1}；θ 是共同父而非独立观测，Λ_naive≻Λ_marg（过度自信）。⇒ 共同原因只能 COND/CM，不能并列。系：**R73「一切皆模块」的边界被精确定位——模块化适用于「条件独立于共同原因之后」的组件，不适用于共同原因本身。**

## 7. 本轮最大风险

**一句话**：THERMGAUGE 把「隐共享物理过程」提升为可审计的共模维度，却也给系统一种「共同原因已被处理」的错觉——一旦条件化于 θ，系统会更大胆地缩窄不确定度；若真实世界还有热之外、同样慢变且低秩的共因（湿度、电池老化、网络抖动、摩擦随温升变化、对手持续机械扰动），这些未声明共因会**借着一张更强的证书**重新引入 R73 警告过的同型错误，而审计日志将证明每一步都更合规。

次级风险与缓解：1) A_TH 被违背 → 运行时共因残差检验，违背即禁 PAR 缩窄并降级证书；2) TRC 表达力不足/迟滞 → 迟滞项 + 查表回退 + 硬边界热 stub；3) 热观测稀疏/延迟 → RC 先验 + 电气代理，tr(Σ_θ) 超阈禁缩窄，按引理 40 调覆盖率；4) 时间尺度分离失效（急速热冲击）→ 检测 |dθ/dt| 超阈，临时升频并冻结缩窄；5) 热障过保守损可用性 → 降额作可优化变量，用 Pareto 曲线预注册选择；6) 热观测投毒 → 多源交叉（电气/温度/性能代理），单源不定案；7) 评估 Goodhart → SEAL-C + 预注册 + 三方复现（E404/E405），得分与证书结构解耦；8) 多机热博弈不稳 → 优先级/公平性约束 + 恶意加热入对抗包络。
