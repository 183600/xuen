# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS 具身计量审计」IP-287~294；灵感循环第 1 轮；本轮灵感：「技术路线图」×「视觉编码器」）

> R72 把 GAUGE 从「认知层」下沉到「具身层」：REG 实时执行图、IRL 意图识别、DMEM 灵巧接触计量、EREFLEX 三层反作用、S2R-UQ 桥接、RTM 运行时监控，并证明「调度可信、意图可辨、接触可计量」时才允许启用新层。但 R72 有一个贯穿全局、却从未被写进证书的隐含假设：**测量仪器是固定的**。所有标定、所有不确定度分解、所有追溯链，都默认「这次部署的视觉编码器就是 f_θ，且 θ 在整个证书有效期内不变」。
>
> 现实里，视觉编码器恰恰是全系统**换代最快**的部件：ViT-B → ViT-L → DINOv2 → SigLIP → 下一代基础模型；而换代是由一张**技术路线图**驱动的（Q1 上 v4、Q3 上 v5、明年换 backbone、后年上多模态统一编码器）。于是出现 R72 完全无法拦截的失效：
> - **换代即换测量函数**：每次换编码器都在悄悄改变 f_θ，下游 head、OOD 检测器、温度标定、不确定度模型**全部失去有效性**，却仍拿着「逐字段有效」的旧证书运行。
> - **平均指标掩盖安全分层退化**：新版本 ImageNet/CLIP/检索分数全面上涨，但「透明物体、反光、低光、遮挡、形变」这些安全关键分层可能悄悄跌 20–40%；路线图门用平均值一票通过，安全侧无人察觉。
> - **仪器谱系不可追溯**：R72 的 TCHAIN / S2R-UQ 追溯的是「参数」与「标定数据」，**没有追溯「仪器版本」**。J_EMB 里没有「编码器谱系」字段，也没有「跨版本证书」字段。
> - **路线图本身是未经审计的承诺**：「我们的路线图说 v7 会解决透明物体」这句话会让团队**推迟当下的安全投入**，把风险押在一个尚未交付、且未经验证的能力上。
>
> 本轮两个灵感正好补这一块：
> - **技术路线图**：不是甘特图，而是**证书的发行时序契约**——声明「哪个版本、在哪个时间、对哪些任务与安全分层、以什么证据被批准上线」，并把「升级」从一次随手 swap 变成一次**可审计的计量标准替换**（有门禁、有迁移窗口、有回退策略、有到期时间）。
> - **视觉编码器**：不是「传感器」，而是**学出来的、带规范自由度的计量标准**。embedding 空间存在旋转/缩放/换维等规范自由度，跨版本直接比较没有意义；它的能力是**分层**的，平均值会系统性地掩盖安全分层退化；它的不确定度里有一个**随版本迁移而累积的慢变量**，不会因为某一帧画质好而消失。
>
> 核心命题：**R72 问「我的测量链在实时调度、意图模糊、灵巧接触下还能兑现风险界吗」；R73 问「当我的测量仪器本身沿着技术路线图不断换代、且每次换代都悄悄改变测量函数时，我的证书还能跨版本兑现风险界吗？」** ——把视觉编码器从「一个可替换的前端」升级为**被路线图管理、被谱系账本追溯、被跨版本证书约束的计量标准**：**VISION-ROADMAP-GAUGE（VR-GAUGE，视觉路线图计量审计）**。

## 0. 直觉与动机

**灵感 1（技术路线图 → 换代即换测量函数，路线图即标准替换契约）**
直觉：在工厂里换一台卡尺，你要重新做计量确认（calibration & verification），否则旧证书作废。但在深度学习系统里，换一个视觉编码器通常只是改一行 `model = load("v5")`。**编码器不是软件组件，它是测量仪器**；换代不是「升级依赖」，而是「替换计量标准」。技术路线图的真正含义，不是「Q3 上线 v5」，而是「Q3 我们打算做一次计量标准替换，需要在此之前拿到覆盖全部安全分层的跨版本迁移证据」。**把路线图当项目管理工具，就会漏掉它本质上是计量学事件。**
> 严谨化预告：路线图 = 版本序列 + 发行门 + 迁移窗口 + 回退策略 + 到期时间；每个门是一次「标准替换的计量确认」；未过门即冻结在上一已认证版本。

**灵感 2（视觉编码器 → 学出来的仪器，带规范自由度）**
直觉：两个版本的 embedding 可以整体旋转、缩放、换维度（768 vs 1024），你直接算欧氏距离、直接复用旧 head，等于**在一个已经转过坐标系的房间里用旧地图**。更麻烦的是，编码器的「语义」和「度量几何」能力并不一致：新版本语义更强（分类/检索更好），但度量几何可能更差（位姿/深度更粗）——而对抓取来说，**几何才是命**。跨版本比较必须先做**表示规范对齐**，对齐后的**残余**才是不可约的迁移误差。
> 严谨化预告：表示规范对齐 RGA + 版本规范间隙 ι_ver；下游标定只有在「对齐后共同变换」时才算有效（否则引理 33）。

**灵感 3（平均指标 → 路线图层的 Goodhart）**
直觉：设安全分层（透明/反光）只占测试集 2%，新版本在这层跌 30%，但主流分层涨 3%，平均值反而上涨 2.4%，门禁一票通过。**平均值不是安全的代理，它是安全的稀释剂。** 一个只测平均值的路线图，结构上不可能安全——不是「可能漏」，而是「一定漏」。
> 严谨化预告：安全分层覆盖 SSC + 分层非退化门；定理 28 构造性地证明「仅用平均指标的门必然存在可通过却违反安全界的升级」。

**灵感 4（不确定度随版本迁移，而非随单次测量）**
直觉：R72 的 u_tac 四分量是「接触条件」的函数，接触模式一变它就变。视觉也需要自己的分解，但要多一个分量 u_ver：**版本迁移带来的表示漂移、标定失配、证书老化**。它是慢变量：不会因为单帧清晰而下降，只会随「距离上次认证的时间」和「跨版本跳变幅度」单调上升。把它漏掉，就会出现「每一帧都很自信，但整体系统性偏移」。
> 严谨化预告：u_vis² = u_sem² + u_geo² + u_calib² + u_ver² + u_ood²；u_ver 含证书年龄项与对齐残差项。

**灵感 5（路线图是一种承诺，必须被审计，且有到期日）**
直觉：「路线图说 v7 会解决透明物体」——这是**主张**，不是**事实**。主张需要证据链、需要到期时间、需要「未兑现时自动降级」。否则路线图会变成一种组织性安慰剂：用未来的能力，抵押当下的安全。**一个合格的路线图契约，必须允许被证伪，并且在被证伪时自动收紧系统。**
> 严谨化预告：CRC 可采纳性 = 每一步 CVT 齐全 + 门通过；cert age > T_cert 时 u_ver 单调上升、λ_floor 抬高、任务在超阈时被禁用。

## 1. 形式化定义（增量：定义 366–380）

**定义 366（VR-GAUGE 总览与五不变式）** VR-GAUGE = (EAI, ELL, RGA, CVT, CRC, SSC, V-RISK, VDM, EMBODIED†)。五不变式：
(i) **仪器可追溯**：每条视觉证据必须绑定当前编码器版本 v 与谱系哈希 ell.head；无法追溯到具体版本与来源的测量**不得进入 BSE**；
(ii) **跨版本证书优先**：任何版本替换必须先持有覆盖全部安全分层的 CVT；无 CVT 不得上线，系统**冻结在上一已认证版本**；
(iii) **分层非退化**：安全分层覆盖集 E_enc 不得收缩；**平均指标不得用于豁免任何分层退化**（非补偿性）；
(iv) **不确定度含版本分量**：u_vis 必含 u_ver；证书年龄超过 T_cert 后 u_ver 单调上升，V-RISK 的 λ_floor 同步抬高；
(v) **严格逐指令退化**：谱系断链 ⇒ 禁用学习编码器、退化为经典几何/深度传感器 + R68；CVT 或分层失效 ⇒ 冻结上一认证版本 + R72；仅版本漂移告警 ⇒ λ_floor 临时抬高 + 重新认证。

**定义 367（视觉编码器即计量仪器 EAI）** EAI = (f_θ, h_θ, D_enc, κ_θ, u_enc, τ_enc, v)：
- f_θ: 𝒳→ℰ 为 backbone，h_θ: ℰ→𝒴 为任务头；
- D_enc ⊆ 𝒳 为**测量有效域**（标定与评估覆盖的输入支撑集）；
- κ_θ 为标定状态（内参/外参、head 校准、温度缩放、逐 token 可靠度图）；
- u_enc 为五分量不确定度（定义 373）；
- τ_enc = (H(θ), H(prov), H(eval_strata), κ_hash) 为**仪器追溯链**；
- v 为路线图中的版本标识。
测量算子：y_vis = h_θ(f_θ(x)) + ε，x ∈ D_enc。**关键：θ 是带版本、带来源、会随时间被替换的量，不是常量。**

**定义 368（编码器谱系账本 ELL）** ELL 为只追加的哈希链，记录 r_i = (v_i, H(θ_i), prov_i, D_enc,i, κ_i, ev_i, e_i, sig_i)，h_i = H(h_{i-1} ‖ r_i)。谓词 VerifyELL(v) ⇔ 存在唯一记录使 H(θ_deployed)=H(θ_i) 且链上所有 h 自洽。**ELL 是「仪器级 TCHAIN」：R72 追溯测量参数，ELL 追溯测量仪器本身。** 单调增长、不可回改、任何版本替换都必须留下签名记录。

**定义 369（表示规范对齐 RGA 与版本规范间隙 ι_ver）** 设锚点探针集 𝒜 = {(x_j, a_j)}，a_j 为跨版本稳定的人工标注属性（语义类、关键点、几何量）。对齐映射
A_{i→j} = argmin_{A∈𝒜_adm} Σ_{x∈𝒜} ‖A f_{θ_i}(x) − f_{θ_j}(x)‖² + λ_R R(A)，
其中 𝒜_adm 为允许的规范群（正交/正交+尺度/最优传输/线性投影，按维度是否一致选择），R 为正则。**版本规范间隙**
ι_ver(i,j) = E_{x∼𝒜}[ d(A_{i→j} f_i(x), f_j(x)) ] + |ECE_transfer(i→j)|，
衡量「对齐之后仍无法消除的漂移 + 标定迁移失配」。**性质**：原始嵌入距离无意义（受规范自由度支配），只有对齐后残差可比较；ι_ver 满足三角不等式但**不保证紧**（引理 35），多跳迁移必须显式再认证。

**定义 370（跨版本迁移证书 CVT）** CVT(i→j, T, S) = (A_{i→j}, {ΔR_{t,s}^{ub}}, {ECE_{t,s}}, OOD_transfer, D_incl, epoch, expiry, sig)。对任务集 T 与安全分层集 S：
Valid(i→j) ⇔ ∀t∈T, ∀s∈S_safety：ΔR_{t,s}^{ub} ≤ 0（**逐层非退化**）∧ ECE_{t,s}(v_j) ≤ ECE_{t,s}(v_i)+δ ∧ ι_ver(i,j) ≤ τ_ι ∧ D_enc,j ⊇ D_enc,i。
**关键：CVT 是逐任务、逐分层签发的，不是全局一个「准确率」。** 一个 CVT 不能因为「平均更好」而豁免某一层的退化。

**定义 371（能力路线图契约 CRC）** CRC = (⟨v_1,…,v_n⟩, {e_i}, {claims_{i,t,s}}, {G_1..G_5}, ρ_rollback, deprecation, B_rm)：
- claims_{i,t,s}：版本 v_i 对任务 t、分层 s 的**能力主张**（含置信与到期）；
- 五道发行门：G1 分层能力保持（SSC）、G2 标定迁移（CVT）、G3 不确定度迁移（u_ver 预算）、G4 证书重签发（J_RM）、G5 回退就绪（T_rollback 有界）；
- ρ_rollback：版本回退策略与最大回退时间；
- B_rm：路线图级安全预算。
**Admissible(CRC) ⇔ 相邻版本间 CVT 链完整 + 每个 e_i 处全部门通过。** 部署版本 ∉ CRC 的已批准集合，即契约漂移，立即告警并冻结。
**附：路线图 VoI（何时升级本身是一个决策）** VoI_rm(i→i+1) = E[减少的安全风险 + 新增任务收益] − c_recert − c_migration − γ·E[等待 v_{i+2} 的机会成本]。仅当 VoI_rm > 0 且 CVT 有效时升级；否则「不升级」也是契约的一部分（**主动不换，也是一种安全决策**）。

**定义 372（安全分层覆盖 SSC 与能力包络）** 安全分层 S = {transparent, reflective, lowlight, occlusion, deformable, scale, motion_blur}。能力包络 E_enc = {s ∈ S : v 在 s 上通过认证}。**覆盖亏空** δ_cov = |S_req \ E_enc| / |S_req|。分层风险 R_s 必须给**上界**而非点估计。升级要求 E_j ⊇ E_i；若任务范围明确收缩，必须显式签核并重签发任务契约，**不得静默缩容**。

**定义 373（视觉不确定度五分量分解）** u_vis² = u_sem² + u_geo² + u_calib² + u_ver² + u_ood²：
- u_sem：语义歧义/别名/同义类混淆；
- u_geo：度量几何（位姿/深度/尺度）不确定度；
- u_calib：相机内参外参与 head 标定不确定度；
- u_ver：**版本迁移不确定度** = g(ι_ver, cert_age, ΔD_enc)，慢变量；
- u_ood：支持域外/分布漂移。
每项有独立追溯链 τ_vis_i。**与 R72 的 u_tac 四分量同构：R72 让不确定度依接触模式而变，R73 让它依仪器版本而变。**

**定义 374（版本感知风险缩放 V-RISK）**
λ = max( risk_scale(U_ale, U_epi, H[b_t(z)], u_tac, u_vis),
         λ_floor(U_ale + U_epi + H[b_t(z)] + u_tac.total() + u_vis.total()) )。
附加版本项：若证书过期、部署版本 ∈ CRC 之外的漂移、或 δ_cov > 0，则
λ ← λ · (1 + u_ver + κ_age·max(0, age−T_cert)/T_cert + κ_cov·δ_cov)；
若 λ > λ_max，**直接禁用依赖该视觉证据的任务**（非补偿性硬否决）。

**定义 375（路线图指标扩展 RM-MIB）** 新增指标族：
- **谱系族**：ι_ver、CVT 有效率、逐分层 ΔR 上界、谱系链完整度；
- **表示族**：embedding 秩、各向异性、CKA、线性探针跨版本迁移 ECE；
- **路线图族**：门通过率、证书年龄、覆盖亏空 δ_cov、部署版本漂移量；
- **供应链族**：来源完整度、签名有效性、训练数据血统哈希。
全部遵循定义 332 六元组 (φ,m,u,D,τ,I⊥) 与定义 333 DAG 分层。

**定义 376（路线图 IVG 扩展 RM-IVG）** 失效条件：CVT 无效/过期、任一分层退化、ι_ver > τ_ι、δ_cov > 0、谱系断链、证书年龄 > T_cert、部署版本 ∉ CRC、VDM 漂移告警。映射：CVT/分层失效 ⇒ 冻结上一认证版本 + R72；谱系/来源断链 ⇒ 经典几何/深度 + R68；版本漂移 ⇒ 告警 + λ_floor 抬高 + 触发重新认证。**任一失效，依赖它的视觉证据立刻退出风险分母。**

**定义 377（路线图证书 J_RM）** J_RM = (J_EMB, ell_head, cvt_chain, crc_hash, ssc_cov, rga_hash, ver, cert_age)。Valid ⇔ J_EMB 有效 ∧ 实测权重哈希 = ELL 头记录 ∧ CVT 链完整 ∧ RM-IVG 全过 ∧ SSC 覆盖 = 任务要求。**证书必须能回答「这是用哪一版编码器、在哪一天、对哪些分层、由哪条迁移证据背书的测量」。**

**定义 378（威胁模型 AIC-RM）** ℰ_RM = ℰ_EMB × ℰ_supply × ℰ_roadmap × ℰ_rep：
- ℰ_supply：预训练权重投毒、后门触发器、伪造来源、供应链替换；
- ℰ_roadmap：路线图注水（宣称能力未交付）、平均门规避、静默换版、证书年龄操纵；
- ℰ_rep：锚点集投毒、对抗性 embedding 漂移、利用规范自由度隐藏漂移。

**定义 379（路线图严格退化链）**
- 全有效 ⇒ VR-GAUGE 完整形态；
- CVT/分层失效 ⇒ 冻结上一已认证版本 + EMBODIED（R72），**禁止升级但继续运行**；
- 谱系/来源断链 ⇒ 禁用学习编码器，退化为经典几何/深度传感器 + R68；
- 未授权版本漂移 ⇒ 告警 + 冻结 + 过渡期 R68。
**安全侧只增不减：任何退化都保留 R68 硬安全包络与 R72 的 λ_floor 机制；升级不是能力开关，而是「证书 + 分层证据 + 回退」三者齐全才打开的窄门。**

**定义 380（运行时版本漂移监控器 VDM）** 最高优先级感知域节点，逐帧监控 embedding 统计量（均值、协方差、有效秩、token 熵、锚点探针响应），与部署版本的参考分布比对；同时校验实测权重哈希与 ell.head 是否一致。**漂移超阈 ⇒ u_ver 实时上升、λ_floor 抬高；哈希不符（静默换版）⇒ 硬回退。VDM 不可被路线图或任务逻辑关闭，是「仪器身份」的最后防线。**

    ell_head: bytes              # ELL 账本头哈希
    def measure(self, x):
        assert in_domain(x, self.D_enc), "out-of-domain: 证据不得进 BSE"
        z = self.backbone(x)
        y = self.head(z)
        return VisualEvidence(y=y, z=z, version=self.version,
                              ell_head=self.ell_head, tau=self.trace())

# IP-296 ELL：编码器谱系账本（只追加哈希链，部署期签名）
class EncoderLineageLedger:
    def __init__(self):
        self.records = []                      # r_i
    def append(self, version, w_hash, prov, D_enc, cap, eval_strata, epoch, sig):
        r = Record(version, w_hash, prov, D_enc, cap, eval_strata, epoch, sig)
        r.h = sha256((self.head_hash() + r.payload()).encode())
        self.records.append(r); return r.h
    def verify(self, deployed_w_hash):
        return any(r.w_hash == deployed_w_hash and self._chain_ok(r)
                   for r in self.records)

# IP-297 RGA：表示规范对齐 + 版本规范间隙
def representation_gauge_align(f_i, f_j, anchors, dim_i, dim_j):
    # 维度一致 -> 正交 Procrustes；不一致 -> 线性投影 / 最优传输
    A = procrustes(f_i(anchors.x), f_j(anchors.x)) if dim_i == dim_j \
        else ot_alignment(f_i(anchors.x), f_j(anchors.x))
    residual = mean_norm(A @ f_i(anchors.x) - f_j(anchors.x))
    ece_gap  = calibration_transfer_gap(f_i, f_j, anchors)
    return A, iota_ver(residual, ece_gap)

# IP-298 CVT：逐任务逐分层跨版本迁移证书
def issue_cvt(v_i, v_j, tasks, strata, anchors):
    A, iota = representation_gauge_align(v_i.f, v_j.f, anchors, v_i.dim, v_j.dim)
    deltas = {}
    for t in tasks:
        for s in strata:
            if s in SAFETY_STRATA:
                # 逐层上界：bootstrap / 置信上界，不是点估计
                deltas[(t, s)] = risk_delta_ub(v_i, v_j, t, s, A, conf=0.99)
    valid = (iota <= TAU_IOTA
             and all(d <= 0 for (t, s), d in deltas.items() if s in SAFETY_STRATA)
             and v_j.D_enc >= v_i.D_enc)
    return CVT(i=v_i.version, j=v_j.version, A=A, deltas=deltas,
               iota=iota, valid=valid, epoch=now(), expiry=now() + T_CERT)

# IP-299 CRC：路线图契约（部署期验证 + 运行时只读）
class RoadmapContract:
    def __init__(self, versions, epochs, claims, gates, rollback, budget):
        self.versions, self.epochs = versions, epochs
        self.claims, self.gates = claims, gates
        self.rollback, self.budget = rollback, budget
    def admissible(self, deployed):
        if deployed not in self.versions: return False          # 契约漂移
        for i in range(len(self.versions) - 1):
            cvt = self.gates.cvt(self.versions[i], self.versions[i+1])
            if not cvt.valid: return False
            if not all(g.passed(self.versions[i+1], self.epochs[i+1])
                       for g in self.gates.all()): return False
        return True
    def roadmap_voi(self, i, i1):
        return (expected_safety_gain(i, i1) + expected_capability_gain(i, i1)
                - cost_recert(i, i1) - cost_migration(i, i1)
                - GAMMA * opportunity_cost_wait(i1))

# IP-300 SSC：安全分层覆盖审计（平均指标一律不作门）
def stratified_safety_coverage(encoder, strata, task_req, n_min):
    envelope = set()
    for s in strata:
        ci = stratified_risk_ci(encoder, s, conf=0.99)          # 上层界
        if ci.high <= RISK_BOUND[s] and ci.n >= n_min:
            envelope.add(s)
    delta_cov = len(task_req - envelope) / max(1, len(task_req))
    return Envelope(envelope), delta_cov

# IP-301 V-RISK：版本感知风险缩放（控制域硬实时 <0.06ms）
def version_risk_scale(U_ale, U_epi, H_z, u_tac, u_vis, ver_state, params):
    denom = U_ale + U_epi + H_z + u_tac.total() + u_vis.total()
    lam = params.lam_base * (1 + denom / params.lam_scale)
    lam = max(lam, params.lam_floor * (1 + denom))
    if ver_state.expired or ver_state.drift or ver_state.delta_cov > 0:
        age_term = params.k_age * max(0, ver_state.age - params.T_cert) / params.T_cert
        lam *= (1 + u_vis.u_ver + age_term + params.k_cov*ver_state.delta_cov)
    return lam if lam <= params.lam_max else float('inf')   # inf = 禁用任务

# IP-302 VDM：运行时版本漂移监控（最高优先级感知域节点）
def version_drift_monitor(frame, deployed, ref_stats):
    z = deployed.backbone(frame)
    drift = distance(embedding_stats(z), ref_stats)        # 均值/协方差/秩/熵
    hash_ok = (sha256(model_bytes()) == deployed.backbone_hash)
    if not hash_ok:
        return DriftSignal(level='CRITICAL', action='hard_rollback')
    if drift > TAU_DRIFT:
        return DriftSignal(level='WARN', action='raise_u_ver', drift=drift)
    return DriftSignal(level='OK', drift=drift)

# IP-303 VR-GAUGE 主闭环（嵌入 R72 三域，控制域只读快照）
def VR_GAUGE_round(M, obs, audio, tac_frame, frame, roadmap):
    # ===== 控制域 1kHz：只读快照，λ 中显式含 u_vis =====
    snap = M.snapshot.read_latest()
    b_t  = M.bse.step_ctrl(snap.b_prev, obs, M.last_action, M.last_g, M.last_y)
    U_ale, U_epi = decompose_ctrl(b_t, M.fmp, obs)
    lam = version_risk_scale(U_ale, U_epi, snap.H_z, snap.u_tac,
                             snap.u_vis, snap.ver_state, M.risk_params)
    if math.isinf(lam):
        M.mode = 'TASK_DISABLED'; return degrade_to(M, 'VISUAL_VETO')
    A = M.ach.propose_ctrl(...); k = M.c_ras_wm.certified_prefix(A, lam, ...)
    M.ctrl_out.publish(k, lam); M.last_action = A[:k]

    # ===== 计量域 50Hz：仪器校验 + 跨版本证书 + 分层审计 =====
    if M.clock.due_metric():
        # 1) 仪器身份：实测哈希 vs ELL 头
        if not M.ell.verify(deployed_hash(M.enc)): M.mode = M.mode.degrade('PROVENANCE')
        # 2) 部署版本是否仍在 CRC 已批准集合内
        if not roadmap.admissible(M.enc.version): M.mode = M.mode.degrade('ROADMAP_DRIFT')
        # 3) 分层覆盖与证书年龄
        env, delta_cov = stratified_safety_coverage(M.enc, M.strata, M.task_req, M.n_min)
        if delta_cov > 0 or M.cert_age() > M.T_cert: M.mode = M.mode.degrade('CVT_EXPIRED')
        # 4) 视觉五分量不确定度 -> 快照
        u_vis = M.vismet.update(frame, M.enc, M.rga, M.cert)
        M.snapshot.write(b_t, M.z_dist, M.gate, u_vis, M.ver_state)

    # ===== 感知域异步：VDM + 证据产出 =====
    drift = version_drift_monitor(frame, M.enc, M.ref_stats)
    if drift.level == 'CRITICAL': M.mode = M.mode.degrade('VERSION_SWAP')
    elif drift.level == 'WARN':   M.ver_state.bump_u_ver(drift.drift)
    ev = M.enc.measure(frame)                    # 带版本号的视觉证据
    M.y_vis_buf.append(ev)
    return k, lam, J_RM(M)

## 3. 推导

**引理 33（版本替换不是规范变换，除非标定同变换）** 设旧版本 i 的标定态为 κ_i，新版本 j 的 embedding 经对齐 A_{i→j}。若继续用旧 head/旧温度标定而**不**做 A_{i→j}∘κ_i 的协同变换，则测量误差下界为 ι_ver(i,j) 的非减函数；即「朴素换版复用旧标定」的误差不能低于对齐残差。证明：测量误差 = ‖h_i(A^{-1}f_j) − h_i(f_i)‖ ≈ ‖∇h_i‖·‖A^{-1}f_j − f_i‖ ≥ λ_min(∇h_i)·d_aligned；当 A 未施加时 d = 原始规范距离，被规范自由度任意放大。系：**「换编码器不换标定」不是省事，是把可消除的对齐残差变成了不可消除的系统偏差。**

**引理 34（平均指标门必然漏掉安全分层）** 设升级在主流分层 S_main（权重 1−w）风险改善 ε，在安全分层 S_safe（权重 w）风险恶化 Δ。平均风险变化 = −(1−w)ε + wΔ。当 wΔ < (1−w)ε 时平均门通过，但安全分层已违反界。故**只要 w 可被压小、Δ 可被放大，就存在通过平均门却违反安全界的升级**。系：**平均门不是「可能漏」，而是「结构上可被系统性规避」；分层非退化门是必要而非锦上添花。**

**引理 35（CVT 非传递，多跳必须再认证）** ι_ver(i,k) ≤ ι_ver(i,j)+ι_ver(j,k) 成立，但等号不保证；且 ΔR 的上界在多跳下按加性累积、而有效域可能逐跳收缩（D_k ⊇ D_j ⊇ D_i 的验证是传递的，但 ECE 迁移与 u_ver 累积不是）。因此**不能把 CVT(i→j) 与 CVT(j→k) 直接拼成 CVT(i→k)**；路线图必须对每一跳单独签发并在关键跳（跨 backbone 家族）做显式再认证。系：**「一路升级链」在计量学上不成立，除非每一跳都有证据。**

**引理 36（覆盖亏空不可外推）** 证书给出的风险界仅在有效域 D_enc 与能力包络 E_enc 上成立。对 s ∉ E_enc，不存在有限风险界（无法用其他层的表现外推）。故 δ_cov 必须作为**独立否决项**进入 RM-IVG，而不是折算成某个平均不确定度。系：**未知分层不能被「估算」，只能被「禁用或补测」；把覆盖亏空摊进平均值是第二类 Goodhart。**

**定理 27（路线图安全单调性）** 在 CRC 可采纳（每跳 CVT 有效、五门通过）、SSC 分层非退化、V-RISK 含 u_ver 与 δ_cov 项、ELL 链完整的条件下，任意一次被批准的升级使系统对任务 T 上所有安全分层的风险上界**不高于**升级前；未通过门的升级被阻止，系统冻结在上一认证版本。**安全随路线图单调不减，能力仅在证据齐全时增加。**

**定理 28（仅平均指标的门不可能安全）** 若路线图的发行门只使用定义在整体分布上的平均指标（不含逐分层上界），则存在一个升级 v_j 使门全过、但 v_j 在某安全分层上风险上界严格大于 v_i（由引理 34 构造）。故**VR-GAUGE 的分层门不可被平均门替代**；这为「路线图层的 Goodhart」给出了不可能性刻画。

**定理 29（J_RM 有效性 ⇒ 跨版本物理安全）** 若一次执行通过 J_RM，则：(i) 部署编码器就是 ELL 记录的版本（仪器身份）；(ii) CVT 链覆盖全部任务与安全分层（跨版本迁移安全）；(iii) SSC 覆盖无亏空且证书未过期（分层与时效安全）；(iv) u_vis 含 u_ver 并已进入 λ_floor（不确定度传播）；(v) J_EMB 有效（R72 具身安全）。综上，**跨版本物理执行风险 ≤ ε_rm**。**证明重量落在「CVT 的分层上界估计在分布外仍可信」与「ELL 供应链未被投毒」上。**

## 6. 本轮最大风险

**一句话**：VR-GAUGE 把安全从「相信单次测量链可信」转移到「相信 **CVT 的分层风险上界在分布外仍成立**、相信 **ELL 供应链未被投毒**、相信 **路线图的每一次换版都能被及时、完整地重新认证**」——**如果新编码器在安全分层上的真实退化发生在锚点集与评估集之外（例如一种从未采样过的材质/光照/形变组合），而 CVT 用有限样本给出的上界因分布外推而系统性偏低；或者攻击者在预训练阶段埋入只在特定触发下激活、且绕过分层评估的后门；或者组织为了赶路线图节点，把「证书年龄」和「覆盖亏空」当作可豁免的形式项——系统就会拿着一份「谱系完整、迁移证书齐全、逐层看起来没退化、所有字段都通过」的 VR-GAUGE 证书，用一版悄悄改变了测量函数的新编码器，在真实世界的安全分层上把人撞伤、把物体捏碎，事后审计发现「仪器身份对、对齐做了、门都过了、证书也没过期」，这就是**跨版本层面的「自信地错自己的计量标准」**。**

次级风险与缓解：
1. **CVT 分层上界外推失效** → 对每个安全分层做 **conformal / 分位数回归** 上界，并设**覆盖亏空硬否决**；锚点集持续扩充，新增 OOD 分层默认「未认证」而非「默认安全」。
2. **供应链后门** → **权重哈希 + 训练数据血统 + 签名** 三链交叉；部署前在**密封对抗集（SEAL-Supply）**上做触发扫描；单源视觉证据不得定案。
3. **组织性路线图注水** → 把 **claims 到期与自动降级**写进 CRC：未交付的能力主张到期即令相关任务失效，**不允许用路线图豁免当下安全投入**。
4. **多跳迁移累积失配** → 每跳单独签发 CVT，跨 backbone 家族强制**显式再认证**；u_ver 按跳累加并进入 λ。
5. **VDM 自身被绕过** → VDM 最高优先级、静态内存、零依赖、权重哈希由硬件信任根校验；不可被任务逻辑或路线图关闭。
6. **认证成本拖慢迭代** → 门禁流水线化（CI/CD），离线并行；把「换版成本」显式纳入路线图 VoI，**该等就等，该不换就不换**。

## 2. 形式化定义（要点版）

**定义 366（VR-GAUGE 总览与五不变式）** 仪器可追溯、跨版本证书优先、分层非退化、不确定度含版本分量、严格逐指令退化。

**定义 367（编码器即计量仪器 EAI）** y_vis = h_θ(f_θ(x)) + ε，x∈D_enc；θ 带版本、带来源、会被替换。**无法追溯到版本与谱系的测量不得进 BSE。**

**定义 368（谱系账本 ELL）** 只追加哈希链，记录权重/来源/有效域/标定/分层评估/部署时戳/签名。VerifyELL ⇔ 部署权重哈希在链上且链自洽。**仪器级 TCHAIN。**

**定义 369（表示规范对齐 RGA 与 ι_ver）** A_{i→j} = argmin Σ‖A f_i(x)−f_j(x)‖² + λ_R R(A)，A∈𝒜_adm；ι_ver = 对齐残差 + 标定迁移失配。**原始嵌入距离受规范自由度支配，无意义；只有对齐后残差可比较。**

**定义 370（跨版本迁移证书 CVT）** 逐任务逐分层；Valid ⇔ 安全分层 ΔR 上界 ≤0 ∧ ECE 迁移有界 ∧ ι_ver ≤ τ_ι ∧ D_enc 不回缩。**平均更好不得豁免任何分层退化。**

**定义 371（能力路线图契约 CRC）** 版本序列 + 发行时戳 + 能力主张 + 五门（G1 分层保持/G2 标定迁移/G3 不确定度迁移/G4 证书重签发/G5 回退就绪）+ 回退策略 + 到期 + 预算。Admissible ⇔ 相邻 CVT 链完整且各门通过；部署版本 ∉ 已批准集合即契约漂移，冻结。**路线图 VoI 决定「何时该升级/该不升级」。**

**定义 372（安全分层覆盖 SSC）** 能力包络 E_enc 不得收缩；覆盖亏空 δ_cov 为硬否决项；分层风险必须给上界而非点估计。**未知分层只能禁用或补测，不能外推。**

**定义 373（视觉五分量不确定度）** u_vis² = u_sem²+u_geo²+u_calib²+u_ver²+u_ood²；每项独立追溯。**u_ver 是慢变量，不因单帧画质好而消失。** 与 R72 的 u_tac 四分量同构：R72 依接触模式而变，R73 依仪器版本而变。

**定义 374（版本感知风险缩放 V-RISK）** λ 分母加入 u_vis；证书过期/版本漂移/覆盖亏空触发乘性放大；λ>λ_max 直接禁用任务（非补偿性硬否决）。

**定义 375（路线图指标扩展 RM-MIB）** 谱系族（ι_ver/CVT 有效率/逐层 ΔR/链完整度）、表示族（秩/各向异性/CKA/迁移 ECE）、路线图族（门通过率/证书年龄/δ_cov/版本漂移）、供应链族（来源完整度/签名/血统哈希）。

**定义 376（路线图 IVG 扩展 RM-IVG）** CVT 无效/过期、分层退化、ι_ver 超阈、δ_cov>0、谱系断链、证书年龄超阈、版本漂移均失效；失效即该视觉证据退出风险分母并降级。

**定义 377（路线图证书 J_RM）** Valid ⇔ J_EMB 有效 ∧ 实测权重哈希=ELL 头 ∧ CVT 链完整 ∧ RM-IVG 全过 ∧ SSC 覆盖=任务要求。**证书必须回答「哪一版编码器、哪一天、对哪些分层、由哪条迁移证据背书」。**

**定义 378（威胁模型 AIC-RM）** ℰ_EMB × ℰ_supply（权重投毒/后门/伪造来源）× ℰ_roadmap（注水/平均门规避/静默换版/年龄操纵）× ℰ_rep（锚点投毒/对抗漂移/规范操纵）。

**定义 379（严格退化链）** 全有效→VR-GAUGE；CVT/分层失效→冻结上一认证版本+R72；谱系/来源断链→经典几何深度+R68；未授权漂移→告警+冻结+过渡 R68。**安全侧只增不减。**

**定义 380（运行时版本漂移监控 VDM）** 逐帧 embedding 统计 + 权重哈希校验；漂移抬 u_ver，哈希不符硬回退；最高优先级、静态内存、零依赖、不可被路线图关闭。**仪器身份的最后防线。**

# IP-295 EAI：视觉编码器即计量仪器（部署期注册，运行时只读版本）
@dataclass
class EncoderInstrument:
    version: str
    backbone_hash: bytes
    head_hash: bytes
    D_enc: DomainSpec          # 有效域：分辨率/光照/材质/遮挡支撑集
    calib: CalibState          # 内参/外参/head 校准/逐 token 可靠度
    ell_head: bytes            # ELL 账本头哈希
    def measure(self, x):
        if not in_domain(x, self.D_enc):
            return None                       # 域外证据不得进 BSE
        z = self.backbone(x); y = self.head(z)
        return VisualEvidence(y=y, z=z, version=self.version,
                              ell_head=self.ell_head, tau=self.trace())

# IP-296 ELL：编码器谱系账本（只追加哈希链 + 签名）
class EncoderLineageLedger:
    def __init__(self): self.records = []
    def append(self, version, w_hash, prov, D_enc, cap, ev, epoch, sig):
        r = Record(version, w_hash, prov, D_enc, cap, ev, epoch, sig)
        r.h = sha256((self.head_hash() + r.payload()).encode())
        self.records.append(r); return r.h
    def verify(self, deployed_w_hash):
        return any(r.w_hash == deployed_w_hash and self._chain_ok(r)
                   for r in self.records)

# IP-297 RGA：表示规范对齐 + 版本规范间隙
def representation_gauge_align(f_i, f_j, anchors, dim_i, dim_j):
    A = (procrustes(f_i(anchors.x), f_j(anchors.x)) if dim_i == dim_j
         else ot_alignment(f_i(anchors.x), f_j(anchors.x)))
    residual = mean_norm(A @ f_i(anchors.x) - f_j(anchors.x))
    ece_gap  = calibration_transfer_gap(f_i, f_j, anchors)
    return A, iota_ver(residual, ece_gap)

# IP-298 CVT：逐任务逐分层跨版本迁移证书
def issue_cvt(v_i, v_j, tasks, strata, anchors):
    A, iota = representation_gauge_align(v_i.f, v_j.f, anchors, v_i.dim, v_j.dim)
    deltas = {(t, s): risk_delta_ub(v_i, v_j, t, s, A, conf=0.99)
              for t in tasks for s in strata}
    valid = (iota <= TAU_IOTA and v_j.D_enc >= v_i.D_enc
             and all(d <= 0 for (t, s), d in deltas.items()
                     if s in SAFETY_STRATA))
    return CVT(i=v_i.version, j=v_j.version, A=A, deltas=deltas,
               iota=iota, valid=valid, epoch=now(), expiry=now() + T_CERT)

# IP-299 CRC：能力路线图契约（部署期验证 + 运行时只读）
class RoadmapContract:
    def admissible(self, deployed):
        if deployed not in self.versions: return False          # 契约漂移
        for i in range(len(self.versions) - 1):
            if not self.gates.cvt(self.versions[i], self.versions[i+1]).valid:
                return False
            if not all(g.passed(self.versions[i+1], self.epochs[i+1])
                       for g in self.gates.all()): return False
        return True
    def roadmap_voi(self, i, i1):
        return (expected_safety_gain(i, i1) + expected_capability_gain(i, i1)
                - cost_recert(i, i1) - cost_migration(i, i1)
                - GAMMA * opportunity_cost_wait(i1))

# IP-300 SSC：安全分层覆盖审计（平均指标一律不作门）
def stratified_safety_coverage(encoder, strata, task_req, n_min):
    envelope = set()
    for s in strata:
        ci = stratified_risk_ci(encoder, s, conf=0.99)          # 上层界
        if ci.high <= RISK_BOUND[s] and ci.n >= n_min: envelope.add(s)
    delta_cov = len(task_req - envelope) / max(1, len(task_req))
    return Envelope(envelope), delta_cov

# IP-301 V-RISK：版本感知风险缩放（控制域硬实时 <0.06ms）
def version_risk_scale(U_ale, U_epi, H_z, u_tac, u_vis, ver, params):
    denom = U_ale + U_epi + H_z + u_tac.total() + u_vis.total()
    lam = max(params.lam_base * (1 + denom / params.lam_scale),
              params.lam_floor * (1 + denom))
    if ver.expired or ver.drift or ver.delta_cov > 0:
        age = params.k_age * max(0, ver.age - params.T_cert) / params.T_cert
        lam *= (1 + u_vis.u_ver + age + params.k_cov * ver.delta_cov)
    return lam if lam <= params.lam_max else float('inf')   # inf = 禁用任务

# IP-302 VDM：运行时版本漂移监控（最高优先级感知域）
def version_drift_monitor(frame, deployed, ref_stats):
    z = deployed.backbone(frame)
    drift = distance(embedding_stats(z), ref_stats)   # 均值/协方差/秩/熵
    if sha256(model_bytes()) != deployed.backbone_hash:
        return DriftSignal('CRITICAL', 'hard_rollback')
    if drift > TAU_DRIFT:
        return DriftSignal('WARN', 'raise_u_ver', drift)
    return DriftSignal('OK', drift=drift)

# IP-303 VR-GAUGE 主闭环（嵌入 R72 三域，控制域只读快照）
def VR_GAUGE_round(M, obs, audio, tac_frame, frame, roadmap):
    # ===== 控制域 1kHz：只读快照，λ 含 u_vis =====
    snap = M.snapshot.read_latest()
    b_t  = M.bse.step_ctrl(snap.b_prev, obs, M.last_action, M.last_g, M.last_y)
    U_ale, U_epi = decompose_ctrl(b_t, M.fmp, obs)
    lam = version_risk_scale(U_ale, U_epi, snap.H_z, snap.u_tac,
                             snap.u_vis, snap.ver, M.risk_params)
    if math.isinf(lam):
        M.mode = 'TASK_DISABLED'; return degrade_to(M, 'VISUAL_VETO')
    A = M.ach.propose_ctrl(...); k = M.c_ras_wm.certified_prefix(A, lam, ...)
    M.ctrl_out.publish(k, lam); M.last_action = A[:k]

    # ===== 计量域 50Hz：仪器身份 + 跨版本证书 + 分层审计 =====
    if M.clock.due_metric():
        if not M.ell.verify(deployed_hash(M.enc)):
            M.mode = M.mode.degrade('PROVENANCE')
        if not roadmap.admissible(M.enc.version):
            M.mode = M.mode.degrade('ROADMAP_DRIFT')
        env, delta_cov = stratified_safety_coverage(
            M.enc, M.strata, M.task_req, M.n_min)
        if delta_cov > 0 or M.cert_age() > M.T_cert:
            M.mode = M.mode.degrade('CVT_EXPIRED')
        u_vis = M.vismet.update(frame, M.enc, M.rga, M.cert)
        M.snapshot.write(b_t, M.z_dist, M.gate, u_vis, M.ver)

    # ===== 感知域异步：VDM + 版本化证据 =====
    drift = version_drift_monitor(frame, M.enc, M.ref_stats)
    if drift.level == 'CRITICAL':   M.mode = M.mode.degrade('VERSION_SWAP')
    elif drift.level == 'WARN':     M.ver.bump_u_ver(drift.drift)
    ev = M.enc.measure(frame)                      # 带版本号的视觉证据
    M.y_vis_buf.append(ev)
    return k, lam, J_RM(M)

## 4. 推导

**引理 33（版本替换不是规范变换，除非标定同变换）** 不施加 A_{i→j}∘κ_i 而复用旧 head/标定，测量误差 ≥ λ_min(∇h_i)·d_aligned；未对齐时 d 被规范自由度任意放大。系：**「换编码器不换标定」把可消除的对齐残差变成不可消除的系统偏差。**

**引理 34（平均指标门必然漏掉安全分层）** 升级在主流层（权重 1−w）改善 ε、在安全层（权重 w）恶化 Δ；当 wΔ < (1−w)ε 时平均门通过但安全层已越界。系：**平均门不是「可能漏」，而是结构上可被系统性规避。**

**引理 35（CVT 非传递，多跳必须再认证）** ι_ver 满足三角不等式但不保证紧；ΔR 上界加性累积，ECE 迁移与 u_ver 不传递。故 CVT(i→j) 与 CVT(j→k) 不能直接拼成 CVT(i→k)；跨 backbone 家族必须显式再认证。

**引理 36（覆盖亏空不可外推）** 风险界仅在 D_enc 与 E_enc 上成立；对 s∉E_enc 无有限界。δ_cov 必须作为独立否决项进入 RM-IVG，不能摊进平均值。

**定理 27（路线图安全单调性）** 在 CRC 可采纳、SSC 分层非退化、V-RISK 含 u_ver 与 δ_cov、ELL 链完整下，任意被批准升级使所有安全分层风险上界不高于升级前；未过门升级被阻止，系统冻结在上一认证版本。**安全随路线图单调不减，能力仅在证据齐全时增加。**

**定理 28（仅平均指标的门不可能安全）** 若发行门只用整体平均指标，则存在升级使门全过但某安全分层风险上界严格变差（引理 34 构造）。故分层门不可被平均门替代——**路线图层 Goodhart 的不可能性刻画**。

**定理 29（J_RM 有效性 ⇒ 跨版本物理安全）** 通过 J_RM ⇒ 仪器身份正确（ELL）、跨版本迁移覆盖全任务全分层（CVT）、分层覆盖无亏空且未过期（SSC）、u_vis 含 u_ver 已入 λ_floor（V-RISK）、R72 具身安全成立（J_EMB）。综上跨版本物理风险 ≤ ε_rm。**证明重量落在「CVT 分层上界在分布外仍可信」与「ELL 供应链未投毒」上。**

## 7. 本轮最大风险

**一句话**：VR-GAUGE 把安全从「相信单次测量链可信」转移到「相信 **CVT 的分层风险上界在分布外仍成立**、相信 **ELL 供应链未被投毒**、相信 **路线图每一次换版都能被及时完整地重新认证**」——**如果新编码器在安全分层上的真实退化恰好发生在锚点集与评估集之外（一种从未采样过的材质/光照/形变组合），CVT 用有限样本给出的上界因分布外推而系统性偏低；或者攻击者在预训练阶段埋入只在特定触发下激活、且绕过分层评估的后门；或者组织为赶路线图节点把「证书年龄」与「覆盖亏空」当成可豁免的形式项——系统就会拿着一份「谱系完整、迁移证书齐全、逐层看起来没退化、所有字段都通过」的 VR-GAUGE 证书，用一版悄悄改变了测量函数的新编码器，在真实世界的安全分层上把人撞伤、把物体捏碎，事后审计发现「仪器身份对、对齐做了、门都过了、证书也没过期」，这就是**跨版本层面的「自信地错自己的计量标准」**。**

次级风险与缓解：
1. **CVT 分层上界外推失效** → 每个安全分层用 conformal / 分位数回归给上界；δ_cov 作硬否决；新增 OOD 分层默认「未认证」而非「默认安全」；锚点集持续扩充。
2. **供应链后门** → 权重哈希 + 训练数据血统 + 签名三链交叉；部署前密封对抗集（SEAL-Supply）触发扫描；单源视觉证据不得定案。
3. **组织性路线图注水** → claims 到期自动降级；未交付能力使相关任务失效；**不允许用路线图豁免当下安全投入**。
4. **多跳迁移累积失配** → 每跳单独签发 CVT；跨 backbone 家族强制显式再认证；u_ver 按跳累加进入 λ。
5. **VDM 自身被绕过** → 最高优先级、静态内存、零依赖；权重哈希由硬件信任根校验；不可被任务逻辑或路线图关闭。
6. **认证成本拖慢迭代** → 门禁流水线化（CI/CD）离线并行；换版成本显式纳入路线图 VoI：**该等就等，该不换就不换**。
7. **复杂度爆炸** → |S|≤8、|V_roadmap|≤12、锚点集 ≤2k、每门一条可复算证明；复杂度本身纳入 RM-MIB。
