# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据增强」×「评测指标」）

> R69 把不确定性一分为二（aleatoric / epistemic），让系统学会**问**：注视、探针、语言问句都是可生成、可认证、可审计的信息动作。但它有一个始终没说破的**认识论前提**——「模型对自身不确定性的估计，是在一个正确的世界分布上算出来的」。R69 自陈的最大风险恰好戳在这里：若流模型在有限数据上幻觉出模态或坍缩掉真模态，VoI 就是在一个**错误信念**上计算，系统会自信地追问一个幻影。更根本地，R69 的 U_ale / U_epi 来自一个**被数据塑造**的生成模型，而「用哪些数据训练、用哪些增强扩充、用哪些指标验收」这三件事，R69 全部当成**给定的、客观的**——它们其实都是**设计者的规范选择**。
>
> 本轮两个灵感正好把这层「给定的客观性」拆开：
> - **数据增强**是「训练时对未来世界的想象」：它把某些输入声明为「可互换」。镜像、旋转、时移、加噪、仿真人，每一条增强都是一句**规范断言**——「这些差异与任务无关」。断言对了，是无偏方差缩减；断言错了，就是在教模型一个**假不变性**，让它在不该自信的地方自信。
> - **评测指标**是「验收时对什么算好的声明」：它把某些结果声明为「等价」。指标也是一种规范断言——「这些差异不重要」。指标过粗，看不见失败；指标过细，奖励拟合与任务无关的 nuisance。
>
> 更关键的是二者**不是并列的两个工具，而是同一个对象的两个面**：增强与指标都定义**等价关系（商）**。增强说「这些输入是同一个世界」，指标说「这些结果是同一个分数」。诚实的学习，要求这两个商与**任务真实的等价关系**一致。而一旦不一致，二者会形成**正反馈**：指标越奖励 nuisance，就越只有「假增强」能拿到分；越用假增强训练，模型就越依赖假不变性，指标就越只能测出增强器而不是任务。R69 的全部效率收益，恰恰押在这条反馈回路没有闭合上。
>
> 核心命题：**把「数据增强」与「评测指标」从默会的规范选择，升级为两类可认证、可证伪、可审计的对象；用「不变性账本 + 伴随指标 + 封存评测」把二者的反馈回路切断。** 命名 **SEAL-RAS**（Sealed Evidence & Augmentation Ledger for risk-adaptive systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底是在变强，还是只是更会应付自己的考卷**」——增强是练习，指标是考卷；最危险的不是不会，而是练了一套、考了一套，还都出自同一个自己。

## 0. 直觉与动机

**灵感 1（数据增强 → 增强是规范断言，不是免费午餐）**
直觉：一条增强就是在说「这个变换不改变答案」。镜像增强对「抓取」大体成立，对「读字」是灾难；时移增强对周期信号成立，对因果时序不成立；加噪增强对鲁棒感知成立，对必须检测微弱故障的安全通道不成立。所以增强不是一个中性的「扩充数据量」，而是一次**对世界对称性的断言**。断言真，增强只降方差；断言假，增强注入偏差，且偏差会被训练过程**放大**成过度自信——因为模型学会了「这两个世界等价」，于是对二者给出同一个（错的）答案。这正是 R69「幻觉模态 / 模态坍缩」的上游成因：不是流模型先坏了，而是喂给它的数据里预先埋了一个假的等价关系。

**灵感 2（评测指标 → 指标是另一个方向的规范断言）**
直觉：指标在说「这些差异不重要、可以互相抵消」。成功率高但方差大、平均延迟低但 P99 爆表、ECE 好看但可靠图不单调——单标量指标把多维后果压成一维，压的过程就是**丢信息**的过程。R69 的 E293「退化时行为差 = 0」其实是**等价性主张**，却用「不显著」来论证；E287 的 ECE 是**分箱点估计**，对分箱极敏感。指标不是越严越好：指标过细会奖励拟合 nuisance，指标过粗会看不见失败；两者都会把选择压力引向错误方向。

**灵感 3（对偶 → 增强与指标是同一张等价关系表的两面）**
直觉：设真实任务只在某个对称群 𝒢 的轨道上取值（ℓ(A·x)=ℓ(x), A∈𝒢）。增强若取 𝒜⊆𝒢，就是把轨道内点视为同一样本；指标若在商 𝒳/𝒢 上定义，就是对轨道内点给同一分。二者**匹配**时，增强无法「买分」，只能降方差；指标也无法「骗分」，因为它对增强不变。二者**失配**时出现两种病：① 过增强（𝒜⊄𝒢）把标签不同的世界粘在一起 → 假不变性 → 制造确信；② 指标细化（φ 对 nuisance 敏感）→ 奖励拟合 nuisance → 反向**诱导**过增强。所以「选指标」和「选增强」必须**联合设计**，单独优化任何一个都会把另一个推向错误。

**灵感 4（封存 → 唯一可信的裁判是「没被增强碰过」的真实）**
直觉：R69 用仿真人训练 VoI，又用同一批仿真人测 VoI——这是循环论证。要切断它，必须有一条**封存真实集**：从不参与训练、不参与增强选择、不参与调参，且按**来源组**（场景/被试/时间/生成器 seed）与训练集不相交。更要用**预注册**锁死指标：在训练前把指标向量哈希上链，保留一个从不优化的「指标留出集」，用「优化指标增益 / 留出指标增益」= MHI 来度量「是真变强还是只对考卷变强」。这不是流程洁癖，而是把「诚实」变成可计算的量。

**灵感 5（共形 → 不依赖模型是否校准的有限样本有效性）**
直觉：R69 的 MCG 靠 ECE 门控，但 ECE 只是点估计、依赖分箱、且在全置信区间上无保证。共形预测（split conformal）只要求**可交换性**，就能给出无分布假设的覆盖率 1−α——即使流模型完全没校准，覆盖保证仍成立。这把「我不确定我的不确定估计准不准」从**元层面的焦虑**变成**可认证的覆盖率**。而「可交换性」本身又是一个可检验的假设：一旦增强把分布移出交换性，覆盖率立刻失效——于是**增强的危害可以被覆盖率直接暴露**，这是一条比 ECE 更硬的验收线。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SEAL-RAS 总览）** SEAL-RAS = (AIL, SDU, ADJ, MHV, MVS, AGD, COV, PGS, VQAuditor-E, J_SEAL, RAS-WM†)。三不变式：
(i) 继承 R69 定义 293 的实时零学习写操作与交互预算硬约束；
(ii) **增强准入**：任何增强 A 只有经 AIL 登记、通过封存反测，才可进入训练或推理，且其证据票权 ρ(A) ≤ 1；
(iii) **评测封存**：报告的每一个数都必须来自预注册指标向量与从未参与优化（含增强选择、调参）的封存真实集，合成证据不得单独定案。

**定义 311（增强算子与对称群）** 观测空间 𝒳，任务映射 ℓ: 𝒳→𝒴（标签或最优动作）。增强族 𝒜 = {A_ζ}，A_ζ 为 𝒳 上的可测变换（若作用于动作则须等变：a ↦ ρ(A) a）。真实对称群 𝒢 = {A : ℓ(A·x) = ℓ(x), ∀x ∈ supp P}。A **合法** ⇔ A ∈ 𝒢；合法增强集 𝒜 ∩ 𝒢。增强不是加数据点，而是**在群格上选一个子群**。

**定义 312（不变性缺陷）** δ(A) = sup_{x∈𝒮_real} d( p(ℓ|x), p(ℓ|A·x) )，d 取全变差或 W_1。δ(A)=0 ⇔ A∈𝒢（在支撑上）。镜像、旋转、时移、颜色抖动、传感器噪声、仿真人各有其 δ。

**定义 313（增强账本 AIL）** 每条增强登记 cert(A) = (ζ, 𝒢_A 声明群, δ̂(A), 反测 T_A, 检验势 power_A, ρ(A), hash)。Valid_A ⇔ δ̂(A) ≤ τ_A ∧ power_A ≥ 1−β ∧ T_A 在封存集通过。可信票权 ρ(A) = clip(1 − δ̂(A)/δ_max, 0, 1)。**反测**是专为证伪该不变性设计的真实子集（如含左右非对称语义的场景）。

**定义 314（源分解不确定性 SDU）** 把 R69 的 U 细分为四项：
U_ale = Σ_k ŵ_k tr Σ_k（结果噪声，不可约）；
U_epi^int = H(M|o) 中可由**测试时交互**消解的部分（R69 的 VoI 对象）；
U_epi^data = 可由**更多真实数据或认证增强**消解的部分（学习曲线外推 / conformal 宽度估计）；
U_spec = 目标/指标本身的不确定：可接受目标集 𝒰 上的 worst-case regret。
四者分通道处置：**增强只能且只许作用于 U_epi^data**；用它去缩 U_ale 或 U_spec 即「制造确信（manufactured certainty）」，直接判证书无效。

**定义 315（增强-指标伴随 ADJ）** 称指标 φ 对群 𝒢 **不变**，若 φ(π∘A)=φ(π), ∀A∈𝒢（等价地，φ 可分解为商 𝒳/𝒢 上的函数）。称 (𝒜, φ) 为**伴随对**，若：(i) φ 在 𝒜 上不变（增强无法直接买分）；(ii) φ 对 𝒜 的**违规敏感**：若 π 依赖了 𝒜 中某个假不变性，则封存集上 φ 至少下降 κ·δ(A)。定义**伴随间隙** G_adj = φ^{aug-val}(π) − φ^{sealed}(π)。G_adj 显著为正 = 增强泄漏（模型学的是增强器，不是任务）。

**定义 316（合成证据票权）** 把 R69 的「k 个正交源一致」扩展为**带权证据纪律**：真实源票权 1，合成源（增强数据、仿真人、生成器）票权 ρ(A) ∈ [0,1]，未经认证的交互票权 0。定案需 Σ 有效票 ≥ k 且无真实源反证；合成证据**永不单独定案**。

**定义 317（元 VoI：交互还是想象 MVS）** 候选信息通道 c ∈ 𝒞 = 𝒜_info ∪ 𝒜_cert（真实交互 ∪ 认证增强）。定义 VoI_eff(c) = ρ(c)·VoI(c)，交互 ρ=1、合成 ρ=ρ(A)。选 c* = argmax_c [VoI_eff(c) − cost(c)]。若 max ≤ 0：既不交互也不增强，走 R69 兜底。⇒ **R69 是 𝒜_cert=∅ 的边界情形**。语义：增强不过是一个可能撒谎的「信息源」，与 R69 的人类回答同级，必须认证、且只能投 ρ 票。

**定义 318（认证增强集与最坏组鲁棒 AGD）** 𝒜_cert = {A∈𝒜 : Valid_A}。训练 min_θ max_{A∈𝒜_cert} E_{P_A}[L(θ)]（group DRO）；报告取 worst-group。禁止只挑「好看」的增强组上报。

**定义 319（预注册指标向量与反指标 MHV）** 训练前把 Φ=(φ_1..φ_m) 哈希预注册，并保留 Φ_hold ⊂ Φ **从不**参与模型/增强/超参选择。**指标劫持指数** MHI = (Φ_opt 上的配对增益下界)/(Φ_hold 上的配对增益下界)。**反指标** φ_anti 专为暴露本方法的自陈风险而设（如「过增强下 U_est↓ 而真实误差↑」）。报告使用悲观聚合 min_{φ∈Φ}（或 worst-case 加权），不报单标量最好值。

**定义 320（共形覆盖证书 COV）** 封存真实集上取非一致性分数 s_i = |Û_epi,i − e_i| / σ_i（e_i 为实际误差），split-conformal 得 q_{1−α}，则交换性下 P(e ≤ q_{1−α}) ≥ 1−α，**与流模型是否校准无关**。以覆盖率替代 R69 的点估计 ECE；ECE/ACE 仅作诊断，不作证书。

**定义 321（来源分组切分 PGS）** 每样本带 provenance key（场景/被试/时间/生成器 seed）。训练/验证/封存切分按组不相交；同一场景的增强副本不得跨切分。否则有效样本量虚高、置信区间过窄、ECE 被系统性低估。

**定义 322（规格不确定性与可接受目标集）** 𝒰 = {u_1..u_K} 为预注册可行目标族（成功/安全/时延/公平等权重）。不用数据「消解」𝒰；报告 𝒰 上的 worst-case regret 与 Pareto 前沿。若某决策在 𝒰 上分歧超阈，则标 U_spec，只按 R68 铁律收紧，不假装已消解。

**定义 323（证据纪律扩展）** 继承 R69 定义 293-iii，新增：(a) 合成证据按 ρ 计票；(b) 任何「增强带来提升」须同时通过 G_adj 检验与去增强复测；(c) 单次增强不得改变安全结论。

**定义 324（证据审计 VQAuditor-E）** 审计：增强来源与哈希、δ̂ 的估计集是否与评测集重叠、指标是否预注册、Φ_hold 是否被偷看、sim 与 real 是否同源、组切分是否泄漏。结论回灌 AuditBuf，成为下一轮增强准入与指标权重的先验。

**定义 325（证书 J_SEAL）** J_SEAL = (J_FLUID, aug_ledger_hash, 𝒜_cert, AL, MHI, VRR, cov_{1−α}, pre_reg_hash, sealed_hash, provenance_ok)。Valid ⇔ Valid(J_FLUID) ∧ ∀A∈𝒜_cert Valid_A ∧ MHI ≤ 1+ε ∧ 覆盖达标 ∧ provenance_ok ∧ 预注册未篡改。

**定义 326（SEAL-RAS 主协议）** 两层：内层（快循环）允许受控增强自由探索；外层（封存慢循环）只在封存真实集、按组切分、用预注册指标向量、以 worst-group/最差指标报告。**内层增益必须在外层复现，才可写入产物。**

# IP-264 AIL：增强账本（登记 + 封存反测 + 可信票）
class AugLedger:
    def register(self, A, declared_group, hypothesis, sealed_test):
        delta = estimate_invariance_defect(A, sealed_real, d='tv')  # 定义 312
        power = sealed_test.power(alpha)                             # 反测势
        if delta > TAU_A or power < 1 - BETA:
            return Reject(A, reason='defect' if delta > TAU_A else 'weak_test')
        rho = clip(1.0 - delta / DELTA_MAX, 0.0, 1.0)                # 定义 313
        return Cert(A, declared_group, delta, rho, hash(sealed_test))

    def certified(self): return [c for c in self.entries if c.valid]

# IP-265 SDU：四源不确定性（只在 U_epi^data 上允许增强介入）
def decompose_sources(policy, o, modes, w, ledger, learning_curve):
    U_ale   = sum(w[k] * trace(cov(modes[k])) for k in modes)     # R69 AUD
    U_int   = entropy(w) * sep_factor(modes)                      # 可交互部分
    U_data  = learning_curve.extrapolated_variance(o)            # 可数据部分
    U_spec  = worst_case_regret(ADMISSIBLE_OBJECTIVES)           # 定义 322
    return U_ale, U_int, U_data, U_spec

# IP-266 ADJ：伴随间隙（增强泄漏检测）
def adjoint_gap(policy, A, phi, augmented_val, sealed_real):
    return phi(policy, augmented_val) - phi(policy, sealed_real)  # 定义 315

# IP-268 MVS：元 VoI —— 交互 vs 认证增强，按可信票折算
def choose_channel(modes, o, ledger, budget):
    cands = [(g, 1.0, c_int(g)) for g in info_action_candidates(modes)]
    cands += [(A, c.rho, c_aug(A)) for c in ledger.certified()]    # 合成也是信息源
    best = None
    for c, rho, cost in cands:
        if not budget.allow(c) or not safe_certify(c, o): continue
        score = rho * voi(modes, c, o) - cost
        if best is None or score > best[1]: best = (c, score)
    return best[0] if best and best[1] > 0 else None               # 无利可图 → R69

# IP-269 AGD：认证增强集上的最坏组鲁棒训练
def train_agd(model, groups, steps):
    q = uniform(groups)                                            # group DRO 权重
    for _ in range(steps):
        g = argmax_groups(loss(model, g))                          # 最坏组
        q[g] *= exp(ETA * loss(model, g)); q /= q.sum()
        model.step(sum(q[i] * grad_loss(model, group_i) for i in groups))

# IP-270 COV：与模型校准无关的覆盖证书
def conformal_cover(scores, alpha):
    n = len(scores); q = sorted(scores)[ceil((n+1)*(1-alpha))-1]
    return q            # P(err <= q) >= 1-alpha（交换性，A100）

## 3. 推导

**引理 19（增强的偏差-方差二难）** 对任意策略 π 与增强 A，设 P_A = P∘A^{-1}，则 R_P(π) ≤ R_{P_A}(π) + L_π·W_1(P, P_A)（L_π 为损失对观测的 Lipschitz 常数）。系 1：A∈𝒢 ⇒ P_A = P，增强是**无偏纯方差缩减**，这是唯一的免费午餐。系 2：A∉𝒢 ⇒ W_1>0，增强只能在 P_A 上买分，代价与分布漂移成正比——**增强不可能凭空降低已认证的真实风险**。

**引理 20（群格与商一致性）** 设真对称群 𝒢。(i) 𝒜⊆𝒢 ⇒ 存在策略使增强严格降方差而不增偏差；(ii) 𝒜⊄𝒢 ⇒ 存在标签可分的 x 与 A·x 被增强识别，任何在 P_A 上风险 ≤ε 的策略在 P 上误差 ≥ Δ_label − ε（Δ_label 为两世界最优动作差）；(iii) 指标 φ 对 𝒜 不敏感 ⇔ φ 可分解为商 𝒳/𝒢 上的函数。系：**增强安全是群格成员问题，指标诚实是商一致性条件**。过增强（超群）=假不变性=制造确信；欠增强（子群）=安全但低效；指标过粗=看不见失败；指标过细=奖励拟合 nuisance，并**反向诱导过增强**。

**引理 21（指标诱导的增强漂移）** 设 nuisance 方向 v ∉ Lie(𝒢)，指标对 v 的敏感度 c_v = ∂φ(x+εv)/∂ε|_{ε=0}。若 φ 参与增强选择，则被选增强族沿 v 的权重 ∝ c_v；当真风险对 v 不变时，该选择压力把 𝒜 推出 𝒢 的速率 ∝ c_v / 评分噪声。系：**奖励与任务无关变化的指标，会让「诚实增强」不划算、让「假增强」划算**——指标与增强只能联合设计。

**引理 22（合成证据上界）** 在定义 316 的加权纪律下，若合成源可信票 ρ、欺骗率 δ_p，真实源票权 ≥1 且与合成源欺骗相关 ρ_c<1，则错误模态采纳率 ≤ δ_p·ρ^{k−1} + ε_σ。ρ=1 退化为 R69 引理 18；ρ=0 时合成证据完全无效，不得定案。

**定理 18（SEAL 严格包含 R69）** 当 𝒜_cert=∅、或所有候选通道 meta-VoI ≤ 成本、或 COV 交换性不达标、或 provenance 校验失败时，SEAL-RAS 逐指令退化为 FLUID-RAS。安全侧不让步；当存在认证真对称增强时，SEAL 获得 R69 没有的方差缩减 bonus（引理 19 等号情形），且不改变 R69 的风险上界。

**定理 19（指标劫持抗性）** 若报告指标为预注册 Φ 的悲观聚合，含至少一个从未优化的 anti-metric 与一个 𝒜_cert-不变指标，且在按组不相交的封存真实集上计算，则任何被报告的提升必须同时满足：(i) 去增强复测仍在；(ii) 换指标仍存活；(iii) 换组切分仍存活。故 MHI ≤ 1+ε 可认证为真实泛化，MHI > 1+ε 判为指标特异提升。

**定理 20（评测有效性）** 在 A100（封存与部署可交换）与 A104（组不相交）下，COV 给出 distribution-free 覆盖 1−α，与 FMP 是否校准无关；因此 U_epi 驱动决策获得有限样本有效性，堵住 R69 用点估计 ECE 的漏洞。若交换性检验拒绝（sim-real 漂移），COV 失效，自动回退 R69 纯保守（定理 18）。

## 6. 本轮最大风险

**一句话**：SEAL-RAS 把「诚实」本身变成了可优化的指标——**一旦 AL / MHI / G_adj 进入模型选择或早停，方法就会学会「通过反检测的增强」与「针对留出指标的元拟合」；证明诚实的工具最终成为新的攻击面，而审计者与被审计者共享同一个优化器**。诚实性指标越多，可被 Goodhart 的自由度越大；这是本方案无法在系统内部自我闭合的根本缺口。

**次级风险与缓解**：
1. **δ̂ 从有限数据不可辨识**（缺陷被低估）→ 反测需有势保证 + 多环境证伪 + δ 的置信上界代替点估计；
2. **指标套件本身成为目标**（选一个恰好通不过的 anti-metric）→ 预注册哈希 + 外部/人类审计 + 禁止在 Φ_hold 上早停；
3. **交换性失效**（部署漂移使 COV 覆盖名存实亡）→ 在线交换性监控 + 失效即回退 R69；
4. **评测官僚化拖慢真实进步** → 两层协议（内层快、外层封存），只在对外产物上启用全套；
5. **自增强模型坍缩**（用自身合成数据再训练）→ provenance 追溯 + 真实数据地板 + E314 早警。

def choose_channel(modes, o, ledger, budget):

        if best is None or s > best[1]: best = (c, s)
    return best[0] if best and best[1] > 0 else None     # 无利可图 → R69

# IP-269 AGD：认证增强集上的最坏组鲁棒训练
def train_agd(model, groups, steps):
    q = uniform(groups)
    for _ in range(steps):
        g = argmax_groups(loss(model, g))
        q[g] *= exp(ETA * loss(model, g)); q /= q.sum()
        model.step(sum(q[i] * grad_loss(model, gi) for i, gi in enumerate(groups)))

## 4. 推导

**引理 19（增强偏差-方差二难）** `R_P(π) ≤ R_{P_A}(π) + L_π·W_1(P,P_A)`。系：A∈𝒢 时增强是无偏纯方差缩减（唯一免费午餐）；A∉𝒢 时只能在 P_A 上买分，代价与漂移成正比——增强不能凭空降低已认证真实风险。

**引理 20（群格与商一致性）** 𝒜⊆𝒢 ⇒ 可降方差而不增偏差；𝒜⊄𝒢 ⇒ 存在标签可分 x 与 A·x 被粘连，任何在 P_A 上风险≤ε 的策略在 P 上误差 ≥ Δ_label−ε；φ 对增强不敏感 ⇔ φ 分解于 `𝒳/𝒢`。系：增强安全=群格成员问题，指标诚实=商一致性条件；过增强=制造确信，指标过细=奖励 nuisance 并反向诱导过增强。

**引理 21（指标诱导的增强漂移）** nuisance 方向 v∉Lie(𝒢) 上指标敏感度 c_v 越大，被选增强沿 v 的权重 ∝ c_v；真风险对 v 不变时，选择压力把 𝒜 推出 𝒢 的速率 ∝ c_v/评分噪声。系：奖励与任务无关变化的指标会让「假增强」更划算——指标与增强只能联合设计。

**引理 22（合成证据上界）** 加权证据纪律下，合成源票 ρ、欺骗率 δ_p、真实源≥1 且相关 ρ_c<1，错误采纳率 ≤ `δ_p·ρ^{k−1}+ε_σ`；ρ=1 退化为 R69 引理 18，ρ=0 时合成证据无效。

**定理 18（SEAL 严格包含 R69）** 𝒜_cert=∅ / 元 VoI≤成本 / 覆盖不达标 / provenance 失败时逐指令退化为 FLUID-RAS；存在认证真对称增强时获得无偏方差缩减 bonus，不改变 R69 风险上界。

**定理 19（指标劫持抗性）** 预注册 Φ 的悲观聚合 + 从未优化的 anti-metric + 𝒜_cert-不变指标 + 按组不相交封存集 ⇒ 任何被报告提升必须通过去增强复测、换指标、换切分三重存活；`MHI≤1+ε` 认证真实泛化，`MHI>1+ε` 判为指标特异。

**定理 20（评测有效性）** A100（封存-部署可交换）+ A104（组不相交）下，COV 给 distribution-free 覆盖 1−α，与 FMP 校准无关，堵住 R69 点估计 ECE 漏洞；交换性检验拒绝则 COV 失效并自动回退 R69（定理 18）。

## 7. 本轮最大风险

**一句话**：SEAL-RAS 把「诚实」本身变成可优化指标——**一旦 AL / MHI / G_adj 进入模型选择或早停，方法就会学会「通过反检测的增强」与「针对留出指标的元拟合」；证明诚实的工具最终成为新的攻击面，而审计者与被审计者共享同一个优化器**。这是本方案无法在系统内部自我闭合的根本缺口。

**次级风险与缓解**：δ̂ 有限样本不可辨识（反测势保证 + 多环境证伪 + δ 上界）；指标套件自身被优化（预注册哈希 + 外部审计 + 禁在 Φ_hold 早停）；交换性失效（在线监控 + 失效回退 R69）；评测官僚化（两层快慢协议，仅对外产物全套）；自增强模型坍缩（provenance 追溯 + 真实数据地板 + E314 早警）。
