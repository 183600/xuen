### IP-497 CLMK：证书责任市场核（离线/慢时域，独立于策略）

```python
@dataclass
class CertificateLiabilityMarketKernel:
    """CLMK：证书=带抵押的金融合约。

    auditor_pool: Any

    q_min: float = 0.05           # 审计概率下界

    def settle(self, cert: Contract, outcome) -> tuple[bool, float]:
        """结局验证失败 → Slash(b_c; α, β)；返回 (是否有效, 净赔付)"""
```

### IP-498 DMC：数据配比控制器（固化前，离线/小时级）

```python
@dataclass
class DataMixtureController:
    """DMC：用配比 w 控制自指回路增益。
    定理 10：ρ_max·κ<1 ⇒ 门博弈偏差几何有界；相变点 ρ_max*=1/κ"""
    rho_max: float = 0.3          # 自铸证份额上限（安全关键缺省）
    w_min: float = 0.03           # 每来源覆盖下界（防遗忘）
    h_min: float = 1.5            # 配比熵下界
    kappa_est: float = 1.0        # 离线估计的博弈放大 Lipschitz 常数

    def solve_mixture(self, source_stats, risk_budget) -> np.ndarray:
        """约束优化：max_w  min_{p∈ambiguity}  E_p[loss]
           s.t. w_s ≤ rho_max, w_j ≥ w_min, H(w) ≥ h_min, Σ w_j = 1,
                Σ ε_j ≤ ε_total（DP 高级组合），审计成本 ≤ budget
           用对偶/投影梯度求解；返回 w（缺省接近均匀 + 覆盖下界）"""
        ...

    def check_gain(self, w) -> float:
        g = 1.0 - ALPHA_STEP + ALPHA_STEP * w['s'] * self.kappa_est
        assert g < 1.0, "自指回路增益 ≥1：拒绝该配比，fail-closed 回退均匀+外部真值"
        return g

    def sample_batch(self, episode_store, w, batch_size):
        """按 w 分层采样；self 源只取 CLMK 认证通过且未被罚没的片段"""
        certified = {j: [ep for ep in episode_store[j] if ep.cert_valid] for j in w}
        return stratified_sample(certified, w, batch_size)
```

### IP-499 ICE-EFA v6：在线不变 + 离线经济闭环

```python
@dataclass
class IncentiveCompatibleEFA:
    """v6：在线 select 逐字复用 v5；本类只负责离线经济闭环与预算核算"""
    v5: EvidenceForgingAssemblerV5     # 在线执行完全委托给 v5（Exec_v6=Exec_v5）
    clmk: CertificateLiabilityMarketKernel
    dmc: DataMixtureController

    def select(self, *args, **kwargs):
        # 在线谓词与 v5 完全相同：七硬门 + γ 调制 + 级联
        return self.v5.select(*args, **kwargs)

    def settle_and_learn(self, episode_store, realized_loss):
        # 1) 结局验证 + 罚没结算（外部真值回写）
        for cert in episode_store.pending:
            ok, payout = self.clmk.settle(cert, cert.outcome)
            cert.cert_valid = ok
        # 2) 风险预算核算：逼近预算 → 复用 v5 的 γ 收紧到保守预设
        if realized_loss > BUDGET_HI:
            self.v5.famk.apply_conservative_preset()   # 仍是 v5 机制，非新门
        # 3) 数据配比 + 固化（只改提议器，永不改门）
        w = self.dmc.solve_mixture(episode_store.stats(), risk_budget)
        self.dmc.check_gain(w)                         # g≥1 直接拒绝
        batch = self.dmc.sample_batch(episode_store, w, BATCH)
        self.v5.fmpp.consolidate(batch, dp_eps=DP_EPS, kl_eps=KL_EPS)
        # 4) 固化后全量回归门测试 + 红队 + 相变监控（ρ_self 实际占比）
        assert self._regression_pass() and self._redteam_pass()
```

### IP-500 扩展 CERTCALC-v6：新增定理 9~12 与引理 45

```python
# 定理 9：激励相容（博弈不获利）
def theorem_incentive_compatibility() -> str:
    """
    设审计独立随机、结局验证与审计独立，合并捕获概率 p_catch=q+η-qη；
    博弈捷径收益 Δ、捕获罚金 P（保证金外）。则当
        b_c ≥ ((1-p_catch)/p_catch)·Δ - P
    时博弈的期望净收益 (1-p_catch)·Δ - p_catch·(b_c+P) ≤ 0，
    诚实认证是弱占优策略。∎
    工程含义：保证金下限由 Δ、P、p_catch 直接算出；q→0 或 η→0 时要求 b→∞，
    即「无捕获能力不得放行」——把 fail-closed 语义延伸到经济层。
    """
    return "Proven"

# 定理 10：自指回路增益有界与相变
def theorem_self_reference_gain() -> str:
    """
    固化更新 π_{n+1}=(1-α_step)π_n+α_step[w_s·G(π_n)+(1-w_s)π_ext]，
    G 为 Lipschitz(κ) 的博弈放大映射，π_ext 为外部真值锚。令 e_n=π_n-π_ext：
        ‖e_{n+1}‖ ≤ (1-α_step+α_step·w_s·κ)‖e_n‖ + α_step·w_s·δ_G.
    若 ρ_max·κ<1（等价 g=1-α_step+α_step·ρ_max·κ<1），则
        ‖e_∞‖ ≤ w_s·δ_G/(1-w_s·κ) ≤ ρ_max·δ_G/(1-ρ_max·κ).
    相变点 ρ_max*=1/κ：超过则 g≥1，偏差无界（门博弈漂移发散）。
    证明：对上述仿射递推取极限 + 几何级数求和。∎
    可证伪预测：随 ρ_max 增大，多轮门博弈率在 1/κ 附近出现相变。
    """
    return "Proven (contraction under ρ_max·κ<1)"

# 定理 11：在线执行集不变与时间非退化
def theorem_online_invariance_temporal() -> str:
    """
    (i) v6 在线 select 逐字复用 v5 ⇒ 对所有 t，Exec_v6(t)=Exec_v5(t)（故 ⊆ 链保持）。
    (ii) 多轮后有效违例率 ≤ v5 单轮界 + 定理 10 的稳态偏差界（δ_G 项）。
    (iii) 风险预算耗尽时，复用 v5 的 γ 调制收紧到保守预设 ⇒ 执行集只缩不涨。

    (iii) 由 v5 定理 5（调制单调性，γ≥1）。∎
```

## 4. 正确性论证（增量）

### 引理 45（风险比例审计分配）

**陈述**：给定各来源风险方差 σ_j²、单位审计成本 c_j、总预算 K，最小化未捕获博弈期望损失的最优抽样率满足 q_j ∝ √(σ_j²/c_j)，并截断到 q_min。**证明**：拉格朗日一阶条件即 Neyman 分配。∎

### 定理 9（激励相容）

**陈述与证明**：见 IP-500 代码注释。博弈期望净收益 E = (1−p_catch)Δ − p_catch(b_c+P)；令 E≤0 即得保证金下限。p_catch=q+η−qη 由审计与结局验证独立可得。q→0 或 η→0 ⇒ b_c→∞，即无捕获能力时禁止放行。∎

### 定理 10（自指增益有界与相变）——本轮理论主轴

**陈述与证明**：见 IP-500。关键是把 v5 含糊的「自指回路」显式写成仿射递推，**回路增益 g 由数据配比 w_s 与博弈放大 κ 共同决定**；ρ_max·κ<1 给出几何收缩与稳态偏差闭式界，相变点 ρ_max*=1/κ 是可证伪的实验锚点。**诚实边界**：κ 需离线估计且可能随对抗演化漂移；δ_G（自铸证映射自身的系统性偏差）无法从内部消除，只能靠外部真值锚 π_ext 与 ρ_max 上限压小。

### 定理 11（在线执行集不变与时间非退化）

**陈述与证明**：见 IP-500。(i) 在线谓词逐字复用 v5 ⇒ Exec_v6(t)=Exec_v5(t)；(ii) 有效违例 ≤ 单轮界 + 漂移界（三角分解）；(iii) 预算耗尽复用 γ 收紧 ⇒ 只缩不涨。∎

### 定理 12（配比覆盖与 DP 组合）

**陈述与证明**：见 IP-500。覆盖下界保证每源每轮有样本，遗忘随 w_min 单调降；DP 高级组合给出跨来源总预算，按边际价值分配。∎

### 定理 v6（总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) 外部真值锚 π_ext 无偏、(B9) 捕获概率 p_catch>0 下：
(i) 在线安全不变：∀t，Exec_v6(t)=Exec_v5(t)⊆…⊆Exec_v29；
(ii) 时间非退化：ρ_max·κ<1 ⇒ 多轮门博弈偏差 ≤ ρ_max·δ_G/(1−ρ_max·κ)（定理 10）；
(iii) 经济不获利：b_c ≥ ((1−p_catch)/p_catch)Δ−P ⇒ 博弈期望净收益 ≤0（定理 9）；
(iv) 遗忘有界与 DP 可控（定理 12）；(v) 预算耗尽时执行集只缩不涨（定理 11(iii)）。

**证明**：分别由定理 9、10、11、12 与 v5 定理 5/6 组合。∎

**诚实声明**：(B8)(B9) 是**本轮全部结论的命门**——它们把「外部真值存在且市场诚实」当作公理。现实中审计可合谋、保险可错价、来源标签可造假、跨辖区罚没未必可执行；一旦 (B8)/(B9) 破裂，定理 10 的 π_ext 项失效，自指回路从后门回流。v6 只把 R57 从「无结构兜底」推进到「有明确前提的可证有界」，并未消除该前提本身的脆弱性。

### 第 6 轮灵感驱动研究记录

**灵感词**：商业模式、数据配比

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）把提议器从离散规则升级为条件流匹配、记忆升级为嵌入+固化、人因升级为情感调制，并用定理 6（证书不变性）把框架推广为「任意生成器 + 认证边界」。但 v5 的最大风险 R57 悬而未决：固化是「铸证→学习→再铸证」的自指闭环，门是策略可学习环境的一部分，缺乏外部真值，只能靠人工抽检与红队经验性缓解。本轮不推翻 v5 的七硬门与在线执行集，而是回答 v5 遗留的**时间维度**问题：如何让多轮固化后系统不向门边界漂移。两个灵感词合成为主题「认证的经济执行」（Incentive-Compatible Certified Execution, ICE），形成 CADVS-v6（IP-497~500）。本轮自律：**在线硬门仍为七门、在线谓词与 v5 逐字相同**；新增的只有「经济层（外部真值）」与「数据配比层（回路增益控制）」两个离线/慢时域机制，执行集在线相等 Exec_v6(t)=Exec_v5(t)，并给出多轮非退化界。

**直觉与动机**：

1. **商业模式 → 把证书变成带抵押的金融合约，用激励相容补上「外部真值」这块缺失的拼图**。v5 的根本问题不是数学问题而是**激励问题**：它让策略自己审计自己。商业世界早就有成熟的「外部真值」装置——保险、审计、抵押。引入 CLMK：每条铸证是一个合约 C=(x,E_x,b_c,π_c,q_c,A_c,T_valid)，提议者（运营方/厂商）缴纳保证金 b_c；独立保险方用**与策略解耦**的精算模型给出保费 π_c；审计员被随机独立指派、按 proper scoring rule（如对数/二次计分）领薪，因此有动机说真话；结局验证失败则罚没保证金，按 α 赔付受害方、β 进入审计/保险池。关键洞见：**博弈门从「免费收益」变成「负期望收益交易」**。这是把安全认证里缺失的 ground truth，用机制设计/保险市场的外部装置补上——商业模式不是附加物，而是外部 oracle。诚实边界：该 oracle 只在「市场本身诚实」时成立，故须叠加审计随机化、罚没下限、跨辖区可执行性等约束。

2. **数据配比 → 自指回路是有增益的，数据配比是压增益的旋钮，能把 R57 从「只能缓解」变为「条件性有界」**。设固化更新为 π_{n+1}=(1−α)π_n+α[w_self·G(π_n)+(1−w_self)π_ext]，其中 G 是策略在自铸证数据上的博弈放大映射（Lipschitz 常数 κ），π_ext 是外部真值锚。v5 事实上取 w_self≈1（只学成功铸证片段），回路接近临界稳定。DMC 给自铸证份额设上限 w_self≤ρ_max，并强制掺入外部真值（人工审计、真实结局、红队、失败回放、OOD/稀有、跨站），同时加熵/覆盖/DP 约束。**定理 10**：若 ρ_max·κ<1，则稳态门博弈偏差 ‖e_∞‖≤ρ_max·δ_G/(1−ρ_max·κ)，回路增益 g<1 ⇒ 几何收缩；**相变点 ρ_max*=1/κ** 给出可证伪预测。由此，数据配比不是「调参玄学」，而是**有明确安全语义的控制变量**：外部真值进入训练的份额直接决定自指回路的稳定性。

**关键洞见**：v5 是**空间**保证（单轮执行集嵌套 Exec_v5⊆Exec_v4）；v6 是**时间**保证（多轮固化不退化）。七硬门像「宪法」，经济层像「三权分立」（提议/审计/保险相互制衡），数据配比像「政治献金法」（限制自筹比例）。两个灵感词是一枚硬币的两面：**商业模式决定外部真值的价格与供给，数据配比决定外部真值进入训练的份额**；缺任一半，自指回路要么无真值可锚、要么锚被自筹数据稀释。

```python
        t = rand(batch.B, 1)
```

### IP-496 EFA-v5：七硬门 + 调制阈值 + 级联采样选证

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：七硬门不变（阈值可调制、只紧不松）+ 级联采样选证"""
    fmpp: FlowMatchingProposalPolicyKernel
    lmem: LongTermMemoryEmbeddingConsolidation
    famk: FacialAffectModulationKernel
    v4: EvidenceForgingAssemblerV4        # 复用 scf/msrg/hic/eek/vack/bck 全套

    def select(self, x0_state, t_now, rule_id, context) -> tuple[bool, Trajectory | None, str]:
        s_emo = self.famk.observe(context.face, t_now)
        gamma = self.famk.gamma(s_emo)                   # 全 1.0 = 精确退化 v4
        c = build_ctx(context, s_emo, self.lmem)         # 含 Top-k 记忆 token
        cands = self.fmpp.propose(c, self.fmpp.K)        # K=8，~5–20 ms，异步准入时域
        # 级联第 1 层：廉价门（coverage/physics/memory/novelty，O(1)~O(log|M|)）
        surv = [x for x in cands if self._cheap_gates(x, gamma)]
        if not surv:
            return self._fallback_rule_proposal(gamma)   # fail-closed：回退 v4 规则提议
        # 级联第 2 层：VACK 仅评估 ≤3 幸存者（~50 ms 级，异步；预筛省 ~60% 昂贵调用）
        surv.sort(key=lambda x: self._prefilter_score(x), reverse=True)
        finals = []
        for x in surv[:3]:
            vac = self.v4.vack.evaluate(x, context_with(s_emo), t_now)
            if self.v4.vack.kc_val(vac, tau=gamma['val'] * TAU_VAL4):
                finals.append(x)
        # 级联第 3 层：BCK 轨迹预览（事件触发 QP + 缓存证书内插）
        ok = [x for x in finals if self._bck_preview(x, gamma)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        best = max(ok, key=certified_margin)             # 通过者中取边际最大者
        return True, best, 'FORGED_CGE'

    def ecs_v5(self, ..., n_flow: float, s_emo: SHomo | None) -> float:
        eta_flow = sigmoid(n_flow_to_ll(n_flow) - b_flow)
        eta_emo = (1.0 - self.famk.lam_emo * s_emo.p_distress
                   if s_emo is not None and s_emo.sigma <= self.famk.sigma_max else 1.0)
        return self.v4.ecs_v4(...) * eta_flow * eta_emo
```
