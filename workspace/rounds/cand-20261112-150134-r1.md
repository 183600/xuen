# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 7 轮；本轮灵感：「数字孪生」×「开源硬件」）

> 第 60 轮把闭环升级为「认知驱动的场景-执行闭环」：SSM 场景语义建模、CIEC 认知意图约束、EPIR ROS 因果隔离、SERC 场景感知闭环、PCE++++ 四维认知预算。但**三个更深的结构性缺口**仍未触及：
> 1. **预演缺位：闭环仍以「真实接触」作为唯一裁判**。SSM 的场景先验与 CLEP 的阻抗收敛，最终都要靠物理试错（contact）来验证；一旦场景误判，代价是真实碰撞而非一次虚拟回滚。缺少一个**零成本反事实试验台**，把「先失败后回退」改造成「先预演后执行」。
> 2. **证据缺身份：EV-exec/J_exec 是「无肉身」的合规声明**。它只说明「此阻抗参数执行合规」，却未绑定「在哪一台硬件、哪一个固件版本、哪一份标定参数上产生」。在**开源硬件**语境下，机器人可被任意 fork（换减速器、刷固件、改夹爪），同一证书在分叉硬件上可能完全失效——证据链一旦脱离硬件身份，就退化为不可迁移的局部断言。
> 3. **开源硬件的双刃性未被利用也未被防御**。开源让任何团队可重建硬件、复算结论（**可复现性红利**），但分叉带来行为漂移与信任异质性（**信任负债**）。第 60 轮既没有「跨分叉先验迁移」的机制，也没有「证书失效与撤销」的机制，开源硬件因此只是「一个可变的执行环境」，而非「一个可验证的知识共同体」。

## 0. 直觉与动机

**灵感 1（数字孪生 → 数字孪生同步与保真 DTSS）**
直觉：机器人不该「先猜再撞」，而应「先演后动」。维护一个与物理体**持续同步的虚拟体 + 虚拟场景** T，在真正下发 K_safe 之前，让**同一套 EEIS/CLEP 管线在孪生里先跑一遍**，得到预测执行证据 EV̂-exec 与安全裕度 m。只有当「预测安全」且「孪生本身可信」时才下发。关键洞见：**预演即证据（rehearsal is evidence）**——执行证据可以在物理执行之前生成。但孪生不是现实，必须用一个**孪生-现实发散度 d_T** 刻画保真度，并定义**可信半径（trust radius）**：只有 d_T ≤ δ_T 的孪生才允许参与决策，否则孪生虚假的安全感本身就是新的抽象泄漏。

**灵感 2（开源硬件 → 硬件溯源清单 HPM）**
直觉：开源硬件意味着「身体可被 fork」——有人把谐波减速器换成国产型号、把驱动固件改了三个 commit、把夹爪重新打印。BUQ 在线辨识的是**结构性不确定性**，但如果你说不清「这是在哪个硬件身份上学到的」，辨识结果与证书都无法迁移、无法追责。于是给每台机器人生成**硬件溯源清单**：设计文件哈希 h_design、BOM 哈希 h_bom、固件提交哈希 h_fw、标定指纹 h_cal，四者合成不可伪造的 hw_id；fork 关系构成 **provenance DAG**。关键洞见：**证据必须被「钉」在硬件身份上**；同时，正因为开源，第三方可凭公开制品重建 hw_id 与孪生，从而**独立复算**你的结论——开源从风险变成验证基础设施。

**灵感 3（两灵感合流 → 可复现执行证书 REC）**
直觉：把「孪生预演」与「硬件溯源」焊在一起，得到一张**可复现执行证书** REC =（hw_id, twin_id, scene, K_safe, EV̂-exec, d_T, 制品哈希, 签名）。验证一条 REC 只需三步：① **溯源相符**（孪生的 hw_id 与物理机 attest 一致）；② **孪生可复算**（任何人用公开制品与固定种子重跑孪生，逐位复现 EV̂-exec）；③ **发散在界内**（d_T ≤ δ_T）。三者全过才算 VALID，否则撤销。关键洞见：**证书的可信不再依赖权威，而依赖可复现性（reproducibility as trust）**——这与科学共同体的验证方式同构。

**灵感 4（闭环 → TRACE：孪生可复现的可信执行闭环）**
直觉：把 REC 嵌入 SERC，得到 **TRACE 闭环**：场景语义 → 孪生同步 → 影子预演 → 证书签发 → 物理执行 → EV-exec → 发散更新/孪生标定 → 证书复核/撤销。执行前有「预演」把关，执行后有「溯源复算」兜底，中间用 d_T 做动态信任闸门。

**灵感 5（预算 → PCE+++++ 的孪生-溯源-复现三维）**
直觉：第 60 轮的四维认知预算之上再叠加**孪生开销 B_twin**（rollout 算力、同步频率）、**溯源开销 B_prov**（签名/校验/清单维护）、**复现开销 B_repro**（第三方复算窗口）。若 B_twin 耗尽⇒跳过预演、退回保守阻抗；若 B_prov 失败（硬件未被 attest）⇒拒绝签发证书、只允许安全模式；若 d_T 超界或 B_repro 不足以复核⇒**撤销证书并回退到无孪生闭环**。预算本质上是在买入「信任」，花光就必须降级信任。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（数字孪生同步与保真 DTSS）** 孪生 T = (S_v, S_p, Φ_sync, d_T, ρ_T)。其中：
- **虚拟状态** S_v 与**物理状态** S_p 分别为孪生与实体的可观测状态估计；
- **同步算子** Φ_sync：S_p × 遥测 → S_v，按频率 f_sync 更新虚拟体；
- **发散度** d_T(t) = √[(z_t − ẑ_t)ᵀ Σ_T⁻¹ (z_t − ẑ_t)]，其中 z_t 为实测遥测特征、ẑ_t = T.predict(z_{t−1}) 为孪生预测、Σ_T 为预测协方差；
- **可信半径** ρ_T：孪生有效当且仅当 d_T ≤ δ_T = √(χ²_{1−α, n})（对应显著性 α 的椭球边界）。
- **场景保真**：对场景 z，另设分布级发散 W_T(z) = W₁(P_obs(·|z), P_twin(·|z))（Wasserstein-1），用于场景级信任门控。

**定义 162（硬件溯源清单 HPM）** 硬件身份 H = (h_design, h_bom, h_fw, h_cal, π_fork)。其中：
- **四元哈希**：h_design = SHA256(设计文件树)、h_bom = SHA256(BOM+供应商)、h_fw = SHA256(固件 commit)、h_cal = SHA256(标定参数)；
- **硬件身份**：hw_id = SHA256(h_design ‖ h_bom ‖ h_fw ‖ h_cal)；任一行为相关组件变更即产生新 hw_id；
- **分叉结构**：π_fork 将 hw_id 组织为 provenance DAG G_H = (V, E)，边 (h₁→h₂) 表示 h₂ 由 h₁ fork 而来；
- **分叉距离**：dist_fork(h₁,h₂) = Σ_{c∈C} w_c·[c₁ ≠ c₂] + γ·|path_len|，w_c 为组件行为敏感权重，C 为行为相关组件集（电机、减速器、驱动固件、标定、传感器）。

**定义 163（影子预演 PSX）** 预演算子 PreFlight(T, K_cand, z, δ_f^req) → (EV̂-exec, m, feasible)。其中：
- 在孪生中执行与物理端**同构**的 EEIS 编译 + CLEP 探针，得到预测证据 EV̂-exec（含预测接触力、滑移、收敛步数）；
- **安全裕度** m = min_j (τ_j − max_t force_j(t)) / τ_j，即各安全阈值上的归一化最小余量；
- **可行**：feasible ⇔ m ≥ m_min ∧ EV̂-exec.K_certainty ≥ τ_K ∧ W_T(z) ≤ δ_W。
- **反事实扫描**：对候选集 K_cands 批量预演，返回按 m 降序的可行列表；物理端只从可行列表取值。

**定义 164（可复现执行证书 REC）** 证书 Cert = (hw_id, twin_id, z, K_safe, EV̂-exec, d_T, H_artifacts, σ_sig)。其中 H_artifacts 是重建孪生所需的全部公开制品哈希（设计、BOM、固件、标定、模型权重、随机种子）。**验证谓词**：
```
Verify(Cert, hw_phys, twin_repo) =
    [Cert.hw_id = hw_phys.attest()]              # 溯源相符
  ∧ [twin_repo.reproduce(Cert.twin_id, Cert.K_safe, Cert.H_artifacts)
        = Cert.EV̂-exec]                          # 逐位可复算
  ∧ [twin_repo.d_T(Cert.twin_id) ≤ δ_T]          # 发散在界内
```
三元全真 ⇒ VALID；任一为假 ⇒ 分别返回 REVOKE_PROVENANCE / REVOKE_REPRO / REVOKE_DRIFT。

**定义 165（TRACE 闭环算子）** TRACE(M, z, intent, δ_f^req)：
```
① DTSS:   d_T ← Φ_sync(M.S_v, M.telemetry);  if d_T > δ_T: goto FALLBACK
② SSM:    π_scene ← M.ssm.prior(z)                       # 承接 IP-153
③ PSX:    Cands ← EEIS.enumerate(π_scene, δ_f^req)
           Pre ← PreFlight(M.twin, Cands, z, δ_f^req)
           if Pre = ∅: goto FALLBACK
④ CIEC:   if intent: ERTC.lock_constraints(ϕ(intent))    # 承接 IP-154
⑤ CERT:   Cert ← issue_REC(M.hw, M.twin, z, Pre[0].K, Pre[0].EV̂, d_T)
⑥ EXEC:   EV-exec ← physical_execute(M, Pre[0].K)
⑦ SYNC:   M.twin.calibrate(EV-exec);  d_T ← update_divergence(EV-exec)
⑧ VERIFY: v ← Verify(Cert, M.hw, M.twin_repo)
           if v ≠ VALID: revoke(Cert); goto FALLBACK
⑨ EPIR:   M.epir.append(EV-exec)                         # 承接 IP-155
⑩ Return: (Pre[0].K, EV-exec, Cert, v, d_T)

FALLBACK: return conservative_exec(M, δ_f^req)  # 无孪生闭环 / 安全模式
```

**定义 166（孪生-溯源-复现预算 PCE+++++）** 在 B_cog 之上叠加：
- **B_twin** = (Rollout_budget, Sync_rate, Twin_memory)
- **B_prov** = (Attest_latency, Manifest_storage, Signature_ops)
- **B_repro** = (Repro_window, Seed_registry, Artifact_cache)
```
voi_trace(π) = voi_cog(π) − cost_cog(π) − cost_twin(π) − cost_prov(π) − cost_repro(π)
cost_twin  = λ_roll·Rollout_ops(π) + λ_sync·Sync_cost(π)
cost_prov  = λ_ver·Attest_ops(π) + λ_sign·Signature_cost(π)
cost_repro = λ_rep·Repro_ops(π) + λ_infra·Artifact_cost(π)
```
降级策略：B_twin 耗尽 ⇒ 跳过 PSX，用保守阻抗；B_prov 耗尽/未 attest ⇒ 拒签 REC、仅安全模式；B_repro 耗尽 ⇒ 证书标 `provisional`（仅本地有效、不可第三方复核）；d_T > δ_T ⇒ REVOKE_DRIFT 且回退无孪生闭环。

**定义 167（分叉迁移 FTM）** 给定源硬件 h_s 上学到的阻抗先验 π_s(K|z) = N(μ_s, Σ_s)，向目标硬件 h_t 迁移：
```
d_f = dist_fork(h_s, h_t)
Σ_t = Σ_s + (d_f)² · σ_fork² · I          # 分叉距离越大，先验越不确定
π_t(K|z) = N(μ_s, Σ_t)
```
**迁移合法性**：仅当 d_f ≤ d_max 且 A69（分叉 Lipschitz）成立才允许作为 PSX 候选源；否则必须以目标硬件自身标定重新生成先验。迁移后的先验必须经 PSX 预演并签发**新的** REC（hw_id = h_t），**不得复用源证书**。

**定义 168（证书撤销与安全回退 CRR）** 撤销规则（任一触发即 revoke，且吊销其下游派生证书）：
- **R1 溯源失配**：hw_id 与物理机 attest 不一致（换件、刷机未重新标定）；
- **R2 发散超界**：d_T > δ_T 或 W_T(z) > δ_W 持续 k 个周期；
- **R3 复现失败**：第三方用公开制品无法逐位复现 EV̂-exec；
- **R4 分叉未校准**：目标硬件 d_f > d_max 却引用了源证书；
- **R5 预算枯竭**：B_prov/B_repro 长期为 0，证书降级为 `provisional` 后过期。
撤销后回退顺序：`按硬件重编译 → 无孪生保守闭环 → 安全停机`。

### IP-161 DTSS（数字孪生同步与保真）

```python
class DigitalTwinSync:
    def __init__(self, twin_model, delta_T=None, alpha=0.01, window=50):
        self.T = twin_model
        self.window = deque(maxlen=window)
        self.Sigma_T = np.eye(twin_model.obs_dim) * 1e-3
        self.delta_T = delta_T or chi2.ppf(1 - alpha, twin_model.obs_dim)
        self.d_T = 0.0

    def sync(self, telemetry):
        z_hat = self.T.predict(telemetry.prev_state)
        residual = telemetry.z - z_hat
        self.Sigma_T = self._running_cov(residual)
        self.d_T = float(np.sqrt(residual.T @ np.linalg.pinv(self.Sigma_T) @ residual))
        self.T.calibrate(telemetry)          # 在线更新孪生参数
        self.window.append((z_hat, telemetry.z))
        return self.d_T

    def scene_fidelity(self, scene_id):
        obs = [o for (_, o) in self.window]
        pred = [p for (p, _) in self.window]
        return wasserstein_1(np.array(pred), np.array(obs))

    def twin_valid(self, scene_id=None, delta_W=None):
        ok = self.d_T <= self.delta_T
        if scene_id is not None and delta_W is not None:
            ok = ok and self.scene_fidelity(scene_id) <= delta_W
        return bool(ok)
```

### IP-162 HPM（开源硬件溯源清单）

```python
class HardwareProvenanceManifest:
    def __init__(self, design_dir, bom, firmware_commit, calibration, fork_parent=None):
        self.h_design = merkle_hash(design_dir)
        self.h_bom    = sha256(sorted(bom.items()))
        self.h_fw     = sha256(firmware_commit)
        self.h_cal    = sha256(calibration)
        self.hw_id    = sha256(concat(self.h_design, self.h_bom, self.h_fw, self.h_cal))
        self.fork_parent = fork_parent       # None 表示根节点

    def attest(self):
        return self.hw_id

    @staticmethod
    def fork_distance(a, b, weights, gamma=0.1):
        d = sum(weights[c] for c in BEHAVIOR_COMPONENTS if a.__dict__[c] != b.__dict__[c])
        return d + gamma * dag_path_length(a, b)

    def transfer_prior(self, src_prior, d_f, sigma_fork):
        Sigma_t = src_prior.Sigma + (d_f ** 2) * (sigma_fork ** 2) * np.eye(len(src_prior.mu))
        return NormalPrior(mu=src_prior.mu, Sigma=Sigma_t)
```

### IP-163 PSX（影子预演）

```python
def preflight_shadow_execution(twin, scene_prior, K_candidates, delta_f_req,
                               m_min=0.15, tau_K=0.6):
    feasible = []
    for K in K_candidates:
        ev_hat, forces, cert_hat = twin.rollout(K, scene_prior, delta_f_req)
        margin = min((tau - max(f)) / tau for tau, f in zip(SAFETY_TAU, forces))
        if margin >= m_min and cert_hat.K_certainty >= tau_K:
            feasible.append(PreflightResult(K=K, EV_hat=ev_hat, margin=margin,
                                            cert=cert_hat))
    return sorted(feasible, key=lambda r: r.margin, reverse=True)
```

### IP-164 REC（可复现执行证书）

```python
def issue_REC(hw, twin, scene_id, K_safe, EV_hat, d_T, artifacts):
    body = {
        'hw_id': hw.attest(), 'twin_id': twin.id, 'scene': scene_id,
        'K_safe': K_safe, 'EV_hat': EV_hat, 'd_T': d_T,
        'H_artifacts': {k: sha256(v) for k, v in artifacts.items()},
        'nonce': fresh_nonce()
    }
    return Certificate(body=body, sig=sign(body, publisher_key))

def verify_REC(cert, hw_phys, twin_repo, delta_T, delta_W):
    if cert.body['hw_id'] != hw_phys.attest():
        return Verdict.REVOKE_PROVENANCE
    reproduced = twin_repo.reproduce(cert.body['twin_id'], cert.body['K_safe'],
                                     cert.body['H_artifacts'])
    if reproduced != cert.body['EV_hat']:
        return Verdict.REVOKE_REPRO
    if twin_repo.divergence(cert.body['twin_id']) > delta_T:
        return Verdict.REVOKE_DRIFT
    return Verdict.VALID
```

### IP-165 TRACE（孪生可复现可信执行闭环）

```python
def trace_loop(M, scene_id, intent, delta_f_req):
    d_T = M.twin.sync(M.telemetry)
    if not M.twin.twin_valid(scene_id, M.delta_W):
        M.crr.revoke_all(reason='R2'); return conservative_exec(M, delta_f_req)

    scene_prior = M.ssm.prior(scene_id)
    cands = M.eeis.enumerate(scene_prior, delta_f_req)
    pre = preflight_shadow_execution(M.twin, scene_prior, cands, delta_f_req)
    if not pre:
        return conservative_exec(M, delta_f_req)

    if intent:
        M.ertc.lock_constraints(map_intent(intent))

    cert = issue_REC(M.hw, M.twin, scene_id, pre[0].K, pre[0].EV_hat,
                     d_T, M.artifacts)
    EV_exec = physical_execute(M, pre[0].K)
    M.twin.calibrate(EV_exec)
    verdict = verify_REC(cert, M.hw, M.twin_repo, M.twin.delta_T, M.delta_W)
    if verdict is not Verdict.VALID:
        M.crr.revoke(cert, reason=verdict); return conservative_exec(M, delta_f_req)

    M.epir.append(EV_exec.__dict__)
    return pre[0].K, EV_exec, cert, verdict, M.twin.d_T
```

```python
class TraceBudget:
    def __init__(self, twin_ops=200, prov_ops=50, repro_window=10, cog_budget=None):
        self.B_twin, self.B_prov, self.B_repro = twin_ops, prov_ops, repro_window
        self.B_cog = cog_budget or CognitiveBudget()
        self.used_twin = self.used_prov = self.used_repro = 0

    def preflight_allowed(self):
        return self.used_twin < self.B_twin and self.B_cog.is_scene_budget_ok()

    def cert_mode(self):
        if self.used_prov >= self.B_prov:       return 'safety_only'
        if self.used_repro >= self.B_repro:     return 'provisional'
        return 'reproducible'

def cost_trace(action):
    return (0.3 * action.rollout_ops + 0.1 * action.attest_ops
            + 0.2 * action.repro_ops)
```

### IP-168 CRR（证书撤销与回退）

```python
class CertificateRevocationRegistry:
    def check_and_revoke(self, cert, hw, twin, budget):
        reason = None
        if cert.body['hw_id'] != hw.attest():              reason = 'R1'
        elif twin.d_T > twin.delta_T:                      reason = 'R2'
        elif not twin.reproducible(cert):                  reason = 'R3'
        elif budget.cert_mode() == 'safety_only':          reason = 'R5'
        if reason:
            self.revoke(cert, reason)
            for child in self.dag.children(cert): self.revoke(child, 'R1')
            return reason
        return None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DTSS | O(rollout + d) / 周期 | O(d² + window) | 发散估计误差 ≤ 5%，twin_valid 误报 ≤ 1% |
| HPM | O(\|V\|) 哈希 / O(\|E\|) 分叉距离 | O(\|V\|+\|E\|) | 篡改检出率 ≥ 99.9%（SHA-256 + Merkle） |
| PSX | O(\|K_cands\|·rollout) | O(\|K_cands\|) | 预演安全预测准确率 ≥ 90% |
| REC | O(1) 签发 / O(1) 校验 + O(rollout) 复算 | O(\|body\|) | 第三方复现率 ≥ 99% |
| TRACE | O(sync + PSX + exec) | 复用 | 真实失败率相对第 60 轮 ↓ ≥ 40% |
| FTM | O(\|V\|+\|E\|) | O(d²) | 迁移误差 ≤ L_f·d_f（分叉 Lipschitz） |
| CRR | O(1) 校验 / O(deg) 级联撤销 | O(证书数) | 撤销延迟 ≤ 1 周期 |

**正确性定理（TRACE）**：
假设 A66–A70 成立：
- **(A66) 孪生可靠性**：若 d_T ≤ δ_T，则 |P_fail(physical|K) − P_fail(twin|K)| ≤ ε_T；
- **(A67) 溯源绑定**：hw_id 抗碰撞，且 HPM 覆盖所有行为相关组件；
- **(A68) 可复现性**：固定随机种子的孪生 rollout 确定性，H_artifacts 完备；
- **(A69) 分叉 Lipschitz**：行为差异 ≤ L_f · dist_fork；
- **(A70) 预算单调**：B_twin/B_prov/B_repro/B_cog 单调消耗，任一耗尽即触发对应降级。

则：
1. **预演安全**：若 twin_valid ∧ PreFlight.feasible，则物理执行失败概率 ≤ ε_T + m_min 裕度漏检率；
2. **证书可复现**：A67∧A68 ⇒ 任一第三方凭公开制品可逐位复现 hw_id 与 EV̂-exec，Verify 是可靠判定（无假阳性签发）；
3. **迁移有界**：A69 ⇒ 跨分叉先验迁移误差 ≤ L_f·d_f，超出 d_max 的迁移被 FTM 拒绝；
4. **撤销及时**：R1–R5 任一触发，证书在 ≤ 1 周期内被撤销，且下游派生证书级联吊销；
5. **预算安全**：任一预算耗尽 ⇒ 触发 `provisional / safety_only / 无孪生保守闭环` 之一，绝不降级为「静默信任」。

### IP-161 DTSS（数字孪生同步与保真）

```python
class DigitalTwinSync:
    def __init__(self, twin_model, delta_T=None, alpha=0.01, window=50):
        self.T = twin_model
        self.window = deque(maxlen=window)
        self.Sigma_T = np.eye(twin_model.obs_dim) * 1e-3
        self.delta_T = delta_T or chi2.ppf(1 - alpha, twin_model.obs_dim)
        self.d_T = 0.0

    def sync(self, telemetry):
        z_hat = self.T.predict(telemetry.prev_state)
        residual = telemetry.z - z_hat
        self.Sigma_T = self._running_cov(residual)
        self.d_T = float(np.sqrt(residual.T @ np.linalg.pinv(self.Sigma_T) @ residual))
        self.T.calibrate(telemetry)
        self.window.append((z_hat, telemetry.z))
        return self.d_T

    def scene_fidelity(self, scene_id):
        pred = np.array([p for (p, _) in self.window])
        obs  = np.array([o for (_, o) in self.window])
        return wasserstein_1(pred, obs)

    def twin_valid(self, scene_id=None, delta_W=None):
        ok = self.d_T <= self.delta_T
        if scene_id is not None and delta_W is not None:
            ok = ok and self.scene_fidelity(scene_id) <= delta_W
        return bool(ok)
```

```python
class HardwareProvenanceManifest:
    def __init__(self, design_dir, bom, firmware_commit, calibration, fork_parent=None):
        self.h_design = merkle_hash(design_dir)
        self.h_bom    = sha256(sorted(bom.items()))
        self.h_fw     = sha256(firmware_commit)
        self.h_cal    = sha256(calibration)
        self.hw_id    = sha256(concat(self.h_design, self.h_bom, self.h_fw, self.h_cal))
        self.fork_parent = fork_parent

    def attest(self):
        return self.hw_id

    @staticmethod
    def fork_distance(a, b, weights, gamma=0.1):
        d = sum(weights[c] for c in BEHAVIOR_COMPONENTS if a.__dict__[c] != b.__dict__[c])
        return d + gamma * dag_path_length(a, b)

    def transfer_prior(self, src_prior, d_f, sigma_fork):
        Sigma_t = src_prior.Sigma + (d_f ** 2) * (sigma_fork ** 2) * np.eye(len(src_prior.mu))
        return NormalPrior(mu=src_prior.mu, Sigma=Sigma_t)
```

### IP-163 PSX（影子预演）

```python
def preflight_shadow_execution(twin, scene_prior, K_candidates, delta_f_req,
                               m_min=0.15, tau_K=0.6):
    feasible = []
    for K in K_candidates:
        ev_hat, forces, cert_hat = twin.rollout(K, scene_prior, delta_f_req)
        margin = min((tau - max(f)) / tau for tau, f in zip(SAFETY_TAU, forces))
        if margin >= m_min and cert_hat.K_certainty >= tau_K:
            feasible.append(PreflightResult(K=K, EV_hat=ev_hat, margin=margin,
                                            cert=cert_hat))
    return sorted(feasible, key=lambda r: r.margin, reverse=True)
```

```python
def issue_REC(hw, twin, scene_id, K_safe, EV_hat, d_T, artifacts):

def verify_REC(cert, hw_phys, twin_repo, delta_T, delta_W):
    if cert.body['hw_id'] != hw_phys.attest():
        return Verdict.REVOKE_PROVENANCE
    reproduced = twin_repo.reproduce(cert.body['twin_id'], cert.body['K_safe'],
                                     cert.body['H_artifacts'])
    if reproduced != cert.body['EV_hat']:
        return Verdict.REVOKE_REPRO
    if twin_repo.divergence(cert.body['twin_id']) > delta_T:
        return Verdict.REVOKE_DRIFT
    return Verdict.VALID
```

```python
def trace_loop(M, scene_id, intent, delta_f_req):
    d_T = M.twin.sync(M.telemetry)
    if not M.twin.twin_valid(scene_id, M.delta_W):
        M.crr.revoke_all(reason='R2'); return conservative_exec(M, delta_f_req)

    scene_prior = M.ssm.prior(scene_id)
    cands = M.eeis.enumerate(scene_prior, delta_f_req)
    pre = preflight_shadow_execution(M.twin, scene_prior, cands, delta_f_req)
    if not pre:
        return conservative_exec(M, delta_f_req)

    if intent:
        M.ertc.lock_constraints(map_intent(intent))

    cert = issue_REC(M.hw, M.twin, scene_id, pre[0].K, pre[0].EV_hat,
                     d_T, M.artifacts)
    EV_exec = physical_execute(M, pre[0].K)
    M.twin.calibrate(EV_exec)
    verdict = verify_REC(cert, M.hw, M.twin_repo, M.twin.delta_T, M.delta_W)
    if verdict is not Verdict.VALID:
        M.crr.revoke(cert, reason=verdict); return conservative_exec(M, delta_f_req)

    M.epir.append(EV_exec.__dict__)
    return pre[0].K, EV_exec, cert, verdict, M.twin.d_T
```

```python
class CertificateRevocationRegistry:
    def check_and_revoke(self, cert, hw, twin, budget):
        reason = None
        if cert.body['hw_id'] != hw.attest():              reason = 'R1'
        elif twin.d_T > twin.delta_T:                      reason = 'R2'
        elif not twin.reproducible(cert):                  reason = 'R3'

        return None
```
