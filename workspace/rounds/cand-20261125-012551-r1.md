## 0. 直觉与动机

**灵感 1（知识图谱 → 证书之间的关系、联合一致性与来源独立性）**
直觉：v22 的每一张证书都很"孤独"。一张 CertBox 单独看合法（类别对、框膨胀了、conformal 误差界达标），但把它和别的证书放在一起，集合可以是**共同荒谬**的：CAC 说"覆盖区内无人"，同一帧的手势识别却识别出"伸手"；SDC 把杯子定位在桌面之上 20cm（悬浮，无支撑）；DCL 说"该区禁行"而轨迹计划恰好穿过该区。这些不是单证错误，而是**关系错误**——缺的是一张能表达"支撑/遮挡/包含/属于/禁止于"的图，以及一张能判定整组证书**联合可满足**的检查器。知识图谱恰好提供三样东西：**类型化的实体-关系结构**（物体、人、区域、规则为节点；空间/部分/分类/功能/证据/规范为边）、**来源（provenance）与版本**（每条边可追溯到传感器/模块/规则编号，可 merkle 化审计）、以及**可判定的联合一致性片段**（描述逻辑 + 区域连接演算的子集）。
关键反直觉点（本轮核心）：**知识图谱的价值不在于它"能推理出更多东西"，而在于它"能禁止更多组合"**。它是三类**单调收紧算子**的统一载体——① 关系性在场推断只会**增补障碍**（人不会凭空消失）；② 联合一致性只会**拒发证书**（UNSAT 即回退，绝不新签发）；③ 来源独立仲裁只会**减少有效票数**（相关来源不能重复计票）。三者都只缩小执行域，于是"安全继承"不再需要逐条论证，而是层本身的结构性质。

**灵感 2（场景理解 → 空间非均匀先验与可见性结构）**
直觉：v21 的缺席证书把召回率下界 κ_c 当作**全域均匀**的经验常数，这既过度保守（空走廊也要证明"没人"）又不够保守（门口/走道恰恰是最该谨慎的高先验区，却与空仓库同等待遇）。场景理解给的是**结构化先验**：区域类型（走道、门口、货架、封闭柜、墙体内部）、可通行性、支撑关系、以及遮挡/视线的几何结构。它能把 Cov_t 从"传感器视锥的并集"升级为"场景几何支撑的可见性走廊"，并把人体在场先验写成按区域变化的上界 π̄_z(x)。
关键反直觉点（一个刻意的自我约束）：**场景先验在本轮被显式禁止用于"放松"缺席要求**。原因是致命的不对称：用场景先验提高高先验区的谨慎是安全的（只收紧），但用它降低低先验区的证据要求，等价于假设"本体完备 + 场景分类永不出错"——而把躺卧者识别成沙发、把轮椅使用者漏成家具，恰恰是缺席幻觉最典型的形态。因此本轮只取场景理解的**安全半边**：**结构化遮挡剔除、高先验区守卫、以及支撑/遮挡的一致性反例**；任何"因先验低而免检"的放松都被推迟到存在"本体完备性证书"之后（明示为未来工作）。

**两者如何统一**
统一为 v22 之上的 **SSKL 层**：SKG_t 回答"世界现在被断定了什么、这些断定彼此是否相容、每条断定的来源是什么"，SGPP 回答"哪些空间结构性地不可能有人 / 哪些区域必须额外要求视线证据"，RPAC 回答"凭什么能说某覆盖区无人"，JCC 回答"这组证书联合可满足吗"，CFC+++ 回答"这些票真的相互独立吗"。共享状态扩展为 **ζ_kg = ζ_pgev ∪ (SKG_t, π̄_z, ver_kg, prov_*) **。统一准入门升级为 **HPC-K = (HPC-E, JCC = SAT, RPAC)**：只有"几何∧规范∧负信息∧能量∧差距内未证伪（v22）∧ 联合一致（JCC）∧ 缺席经关系闭包（RPAC）"才进入执行；任一缺失退回 v22 的保守收缩，再退 v21/v20/v19/v18。**全线保持 `Exec_v23 = Exec_v22 ∩ Fil_kg ⊆ Exec_v22`（引理 167）**——本轮买的是安全性，不是活性；活性回收被明确推迟。

## 2. 设计原则（在 P34–P37/P41–P42 基础上新增 P43–P46）

**P43 联合一致性收紧律（Joint-Consistency Tightening）**
一组证书 C 进入执行前必须通过联合一致性检查 `JCC(C, SKG_t) ∈ {SAT, UNSAT, UNKNOWN}`；仅 `SAT` 放行，`UNSAT`/`UNKNOWN` 一律退回 v22 保守收缩。硬约束（物理支撑、区域互斥、遮挡几何相容、在场-缺席冲突、规范冲突）不可被软证据覆盖；软约束违反只触发降级而非静默通过。故 `Fil_kg` 只做交集与过滤，`Exec_v23 = Exec_v22 ∩ Fil_kg ⊆ Exec_v22`。

**P44 关系缺席闭包律（Relational Absence Closure）**
只有 `AbsClosed(x, c, t) = ¬∃v ∈ V_t [ in(v, x) ∧ class(v) ⪯ c ] ∧ ¬∃ part_of 链蕴含 c ∧ ¬gext(t) ∧ ¬occluded_candidate(x) ∧ Ω_c` 成立时，RPAC 才签发 c-类缺席。缺失任一项即拒绝签发并触发"假设在场"的保守翻置。**关系推断只能把"无"变成"可能有（人在）"，不能把"有"变成"无"**——即在场所言只增不减。

**P45 场景先验只收紧律（Scene Prior Tightens-Only）**
区域在场上界 π̄_z(x) 作为缺席的**额外必要条件**：`P(∃person in R | no det, Cov, scene) ≤ α` 必须同时满足 v22 的检测器级界与场景级界；场景先验不得替代、不得放松检测器级要求。结构化遮挡剔除必须携带独立的**几何不可达证书**（非统计先验），否则不得从 Cov_t 扣除。任何"低先验免检"放松在缺少 `Ω_c`（本体完备性证书）时一律禁止。

**P46 来源独立仲裁律（Provenance-Independence Quorum）**
两票 `v_i, v_j` 独立当且仅当 `prov(v_i) ∩ prov(v_j) = ∅` 且二者的 provenance 子图无共享上游谱系根（同相机、同 DNN 权重、同标定链视为相关）。CFC+++ 的法定票数按**独立性等价类**计，而非原始票数；相关来源合并为单票。故 `CFC+++ 的仲裁结果 ⊆ CFC++ 的仲裁结果`（更少放行，绝不更多）。

## 3. 与基线的接口（如何退化）

- SKG 构建失败（图不完整/解析崩溃）⇒ `JCC = UNKNOWN` ⇒ 全局退回 v22 保守收缩 ⇒ 子集；
- JCC 求解超预算 ⇒ 视同 `UNKNOWN` ⇒ 拒绝执行（fail-closed），绝不超时默认放行；
- RPAC 失效（本体/闭包不可评估）⇒ 缺席证书拒发 ⇒ 退回 v22 的 AbsCert 行为（更保守一档）；
- SGPP 失效（场景分类不可信）⇒ π̄_z 取最坏上界（全域高先验）⇒ 仅收紧 ⇒ 子集；
- provenance 链断裂/不可验证 ⇒ 该票视为"不可独立"并与最相关票合并 ⇒ 票数只减不增；
- CFC+++ 无法确认独立性 ⇒ 仲裁退回 CFC++ ⇒ 等价 v22；
- SSKL 全失效 ⇒ 完全回退 v22 ⇒ `Exec_v23 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（定理 167）。
- **安全继承的结构化依据**：本层所有算子（增补在场、拒发证书、缩减票数、收紧先验）在偏序上都是**单调收紧**，因此安全继承不依赖逐模块论证，而由"单调算子之复合仍是单调收紧"直接给出。

## 4. 预期贡献

1. **证书的关系化**：首次把 v20–v22 的扁平证书集合升级为带类型、关系与来源的知识图谱，使"单证合法但集合荒谬"这一类长期被忽视的失效模式可被显式检测（JCC）；
2. **单调收紧算子代数**：把新层提炼为三类只收紧算子（关系在场增补、联合一致性拒发、来源独立减票），使 `Exec_v23 ⊆ Exec_v22` 成为结构定理而非逐条论证；
3. **缺席的关系闭包**：把"覆盖区内无人"从单点检测负信息升级为本体闭包 + 部分关系 + 手势在场的联合判定，首次显式以"本体完备性假设 Ω_c"为条件，并为该假设被证伪提供 fail-safe 翻置；
4. **场景理解的安全半边**：给出只收紧的场景先验与几何不可达剔除，并明确论证"低先验免检"在无 Ω_c 时不可用——把诱惑性的活性捷径提升为可审计的禁忌；
5. **来源独立仲裁**：用 provenance 子图独立性替代朴素的"模态数 ≥ 2"，封堵"同源多模态"伪独立的共识风险；
6. **HPC-K 六证一体**：HPC-E ∪ JCC ∪ RPAC 统一准入门，配合 merkle 化的 KG 版本审计，形成跨轮可机械复核的闭环。

## 5. 本轮最大风险

**一句话**：KG 的联合一致性只保证"内部不矛盾"，而缺席推理隐含**闭世界 + 本体完备**假设；一旦本体系统性缺类（躺卧者被归为家具、轮椅使用者无 person 节点、蹲姿者落在"货物"类），系统会得到一张**自洽、可审计、却与真实世界相反**的缺席证书——此时 JCC 不仅没能防住缺席幻觉，反而以"一致性已通过"为它背书，使 v21 的风险在更高置信度上复活。

## 2. 关键算法骨架（在 IP-431–435 骨架上扩展）

```python
# IP-436 Scene Knowledge Graph（最小可审计骨架）
from dataclasses import dataclass, field

@dataclass
class Edge:
    src: str; dst: str; etype: str          # spatial/mer/ tax/func/evi/norm
    prov: frozenset                       # 来源集合 P
    ts: float
    hard: bool = True                   # 硬约束 / 软约束

@dataclass
class SKG:
    nodes: dict                          # id -> (cls, pose, cert, prov)
    edges: list                          # Edge
    ver_kg: str = ""

    def merkle_root(self):
        # 对 (节点, 边, 类型, prov, ts) 作规范化序列化后取哈希树根
        return merkle([canon(n) for n in self.nodes.values()] +
                      [canon(e) for e in self.edges])

    def subsumed(self, c_prime, c):
        return c_prime in self.class_closure(c)      # c'  ⪯ c

    def occ_implies(self, node_cls, c):
        # 经 part_of / occupant 关系会蕴含 c 在场的类
        return node_cls in self.p_occ(c)

# IP-437 Scene-Grounded Presence Prior（conformal，只收紧）
class ScenePresencePrior:
    def __init__(self, calib, alpha_z=0.01):
        self.calib = calib                 # 按 (scene_type, zone_type) 分层校准
        self.alpha_z = alpha_z

    def upper_bound(self, x, zone):
        # 返回 π̄_z(x)：满足 P(π_true ≤ π̄_z | zone, x) ≥ 1-α_z
        return self.calib.quantile(zone.type, x, 1 - self.alpha_z)

    def absence_extra_condition(self, R, zone):
        # 只作为“额外必要条件”，永不作充分条件；检测器级界必须另行满足
        return self.upper_bound(R.center, zone) <= self.alpha_z

# IP-438 Relational Presence-Absence Certificate
class RelationalAbsenceCertificate:
    def __init__(self, skg, omega_ok, gesture_active, occl_check):
        self.skg = skg
        self.omega_ok = omega_ok           # Ω_c 是否成立（本体完备性证书）
        self.gesture_active = gesture_active
        self.occl_check = occl_check

    def abs_closed(self, region, c, t):
        if not self.omega_ok(c):                    # 开放世界：本体不完备即拒发
            return False
        # 1) 覆盖区内不存在 c 及其子类
        for nid, (cls, pose, *_ ) in self.skg.nodes.items():
            if inside(pose, region) and self.skg.subsumed(cls, c):
                return False
        # 2) 不存在经由 part_of/占用关系蕴含 c 的节点（如无主轮椅）
        for nid, (cls, pose, *_ ) in self.skg.nodes.items():
            if inside(pose, region) and self.skg.occ_implies(cls, c):
                return False
        # 3) 手势通道构造性蕴含在场（手不会凭空出现）
        if self.gesture_active(t):
            return False
        # 4) 存在被遮挡候选 → 不得签发缺席
        if self.occl_check.any(region, c):
            return False
        return True

    def issue(self, region, c, t):
        # 关系在场只增障碍：若发现任何 c 候选，翻置为“可能有 c”
        if not self.abs_closed(region, c, t):
            return ("ABSENCE_REJECTED", "ASSUME_PRESENT")
        return ("ABSENCE_CERTIFIED", None)

# IP-439 Joint Consistency Certificate（可判定片段 + fail-closed）
class JointConsistencyCertificate:
    def __init__(self, skg, budget_ms=2.0):
        self.skg = skg
        self.budget_ms = budget_ms

    def check(self, certs):
        # 将证书集合与 SKG 断言编译为 ALC + RCC-8 子集约束
        kb = self._compile(certs, self.skg)
        # 硬约束：支撑（无悬浮）、区域互斥、遮挡几何相容、在场-缺席冲突、规范冲突
        res = self._solver(kb.hard, kb.soft, timeout=self.budget_ms)
        if res is None:
            return "UNKNOWN"                          # 超预算 → fail-closed
        if not res.satisfiable:
            return "UNSAT"
        return "SAT"

    def _compile(self, certs, skg):
        hard, soft = [], []
        # 物理支撑：物体不得无支撑悬浮
        for o in certs.objects:
            if not skg.supported(o):
                hard.append(Not(Supported(o)))
        # 在场-缺席冲突：CAC 缺席 ∧ 同一区域存在 person 节点 → UNSAT
        for ab in certs.absence_certs:
            if any(skg.subsumed(n.cls, "person") and inside(n.pose, ab.region)
                   for n in skg.nodes.values()):
                hard.append(Conflict(ab, "person_in_region"))
        # 遮挡几何相容、区域互斥、规范冲突同理追加
        return Kb(hard=hard, soft=soft)

# IP-440 HPC-K 统一准入门（HPC-E 原样保留，只加门）
@dataclass
class HPCK:
    hpc_e: HPCE
    jcc: JointConsistencyCertificate
    rpac: RelationalAbsenceCertificate

    def admits(self, plan, certs, region, x, v, z, E_res, margin_req):
        if not self.hpc_e.admits(plan, x, v, z, E_res, margin_req):
            return False                                     # v22 继承
        verdict = self.jcc.check(certs)
        if verdict != "SAT":                                 # UNSAT/UNKNOWN 一律拒绝
            return False
        if certs.uses_absence and not self.rpac.abs_closed(region, "person", certs.t):
            return False                                     # 缺席必须过关系闭包
        return True

# IP-441 CFC+++ 来源独立仲裁
class CertificateFederatedConsensusPlusPlusIndep(CertificateFederatedConsensusPlusHierarchical):
    def _indep(self, a, b):
        return (a.prov.isdisjoint(b.prov) and
                a.root.isdisjoint(b.root))                   # 无共享上游谱系根

    def consensus_round(self, timeout=5.0):
        results = {}
        for key, votes in self.votes.items():
            reps = []                                        # 独立性等价类代表
            for v in votes.values():
                if all(self._indep(v, r) for r in reps):
                    reps.append(v)
                else:                                        # 相关票合并（只减不增）
                    r = next(r for r in reps if not self._indep(v, r))
                    r.merge(v)
            q_eff = len(reps)
            modalities = {r.modality for r in reps if r.independent_modality}
            layer_ok = self._check_layer_consistency(reps)
            if q_eff >= self.N - self.F and len(modalities) >= 2 and layer_ok:
                results[key] = self._majority_with_outlier_filter(reps)
            else:
                results[key] = "CI"                          # 保守仲裁
        return results
```

## 3. 关键推导（引理 163–167）

**引理 163（RPAC ⟹ v22 缺席证书）**
若 `AbsClosed(x, c, t)` 成立，则 v22 的 AbsCert 条件（覆盖 + 检测无 c + 召回界 κ_c）必成立。反之不然。
*证明*：AbsClosed 的第 (1)(2) 项直接要求覆盖区内不存在任何 c/子类/占用蕴含节点，第 (4) 项进一步排除遮挡候选；其条件是 v22 条件与额外合取项的交集，故 `Abs_v23 ⊆ Abs_v22`。∎

**引理 164（JCC 只拒不放）**
`JCC(C) ∈ {UNSAT, UNKNOWN}` 时执行集为空；`JCC(C)=SAT` 时至少不新增计划。故 `Fil_kg` 对计划集只做交与过滤。
*证明*：HPC-K 中 JCC 仅出现在合取位置，且 `SAT` 不改变 v22 判定；`UNSAT`/`UNKNOWN` 返回 False。∎

**引理 165（场景先验只收紧）**
缺席可靠性要求 `P(∃person|no det, Cov, scene) ≤ α`。由于 SGPP 仅作为**额外必要条件**（P45），所需证据为 v22 条件 ∧ 场景条件，合取只会更严；且几何不可达剔除需独立证书，不改变统计充分性。
*证明*：设 v22 可行域为 A，加入场景条件后可行域为 A ∩ B ⊆ A。∎

**引理 166（CFC+++ ⊆ CFC++）**
独立性等价类合并使有效票数 `q_eff = |{[v]_ind}| ≤ |votes|`，模态数在合并后亦不增。故 CFC+++ 的放行条件严格强于 CFC++，放行集合为其子集。
*证明*：等价类划分是原票数集合的商集，基数不增；合取条件逐项不弱。∎

**定理 167（v23 安全继承）**
`Exec_v23 = Exec_v22 ∩ Fil_kg ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。
*证明*：SSKL 的三个算子——RPAC（增补在场，引理 163）、JCC（只拒，引理 164）、CFC+++（减票，引理 166）——均为单调收紧；场景层（引理 165）亦只收紧。单调收紧算子的复合仍单调收紧，且 HPC-K 以 `HPC-E` 为前提合取。故结论成立。∎

## 4. 实验设计（falsification-first）

| 实验 | 目的 | 关键指标 | 证伪条件（若成立则该机制无效） |
|---|---|---|---|
| E1 集合荒谬注入 | 验证 JCC | UNSAT 检出率、误拒率 | 对"悬浮杯 / 缺席∧手势"等注入的检出率不显著高于 v22 的逐证检查 |
| E2 缺席幻觉对抗 | 验证 RPAC | 系统漏检人体的召回（含躺卧/轮椅/蹲姿/逆光） | RPAC 对这些形态的缺席签发率与 v22 无差异（说明闭包未捕获本体缺类） |
| E3 Ω_c 漂移 | 验证 fail-safe | 新类别引入后"拒发缺席"的及时性、翻置延迟 | 新类别出现后仍持续签发缺席超过 TTL |
| E4 场景先验校准 | 验证 P45 | 区域级 π̄_z 的经验覆盖率 ≥1-α_z | 高先验区覆盖率显著低于名义水平（先验不可靠） |
| E5 同源伪装 | 验证 CFC+++ | 同相机+同 DNN 被重复计票时的一致性判定 | 仍能凑够 2 模态从而放行 |
| E6 活性代价 | 量化安全税 | 任务完成率、平均停机时长 vs v22 | 活性下降超过预设预算（如 >15%）则需重新权衡 |

**预期结果**：E1/E2/E5 上 SSKL 应显著降低灾难性假安全；代价是 E6 的活性下降——本轮**刻意**以活性换安全，活性回收留待"Ω_c 完备性证书"落地后处理。

## 5. 本轮最大风险（产物视角）

**一句话**：SSKL 的全部收益都建立在"本体完备 + 闭世界"这一前提上，而该前提无法由系统自身验证；一旦场景本体对某类人体形态系统性缺类，JCC 会把"自洽的缺席幻觉"判定为 SAT 并为它背书——**我们把缺席幻觉从"检测漏检"升级成"经一致性审计的低置信度漏检"**。
