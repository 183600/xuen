# 第 41 轮 · 双灵感落地 v18：隐式契约平面 Ξ（力影 × 规范场）——从「交付物理学」到「交互契约学」（四层架构 v6）

> 承接第 40 轮（v17：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹，四层架构 v5）。本轮灵感词「社会规范理解 / 力控」。两个词初看分属两个社区（HRI 与运动控制），但对照官方接口现实（F60，README 只给位置目标、四路相机、静态语言，**没有力/触觉/力矩反馈**）后，它们击中 v17 的同一个盲区：**v17 的世界里没有「人」，也没有「接触」**。v17 把力控判为接口不可做而锁在参考层，把「人为干扰」仅当作普通扰动重规划；于是它优化的是「对一个静止物体交付得又多快又省」，而不是「在一个人也在场的桌面上，以可接受的力与可接受的社会行为完成交付」。v18 的主轴因此从「单位物理成本的得分效率最大化」推进到「**合规交互下的得分效率最大化**」：新增横切的 **Ξ 隐式契约平面（力影 × 规范场）**，与 v17 的 **Δ 资源平面（热/时延/步数）** 组成双平面治理。

## 0. 联网核实（先事实后推理；检索口径 2026-11-10，来源链接见产物区 §5）

- **事实 F67（CompVLA，arXiv 2609.23614，CoRL 2026）**：接触丰富操作要求机器人不仅调节运动，还要调节「如何对外力让步」；现有 VLA 只输出纯运动指令。CompVLA 从 RGB+语言**联合预测运动与刚度矩阵**，用专用 Compliance Expert 输出时变刚度与虚拟位移，经几何阻抗控制执行，在多种接触任务上平均成功率最高。
- **事实 F68（CompliantVLA-adaptor，arXiv 2601.15541）**：现有 VLA（RDT、π0.5、OpenVLA-oft）只输出位置、缺少力感知适应，接触任务不安全；该工作用 VLM 依据图像与语言调节变阻抗控制器的刚度/阻尼，并用**实时力/扭矩反馈**把交互力约束在安全阈值内；总成功率 9.86%→17.29%，力越界减少。
- **事实 F69（Imp-ACT，arXiv 2609.31225）**：把**方向相关的笛卡尔刚度调制**直接写进示教采集（沿运动方向保持足够刚度、正交方向保持柔顺）；擦拭任务接触力振动相对柔顺基线降约 29×、相对刚性基线降约 180×；插孔任务正交力相对最佳固定刚度降 43%——说明「各向异性柔顺」比全局变柔顺更关键。
- **事实 F70（ForceDelta-VLA，arXiv 2609.18242）**：把 VLA 动作显式分解为**可复用参考动作 + 力条件修正**，用冻结教师的「有力条件/无力条件」成对预测构造修正目标，并加延迟修正项；学生只用近期力历史与机器人状态，可在两次参考动作更新之间响应接触变化、**无需重生成整个 action chunk**；九个单/双臂接触任务平均成功率 82.2%（ForceVLA 基线 54.4%），峰值接触力相对 ForceVLA 降约 26%。
- **事实 F71（PaCo-VLA，arXiv 2606.00515）**：不把 VLA 输出当直接电机命令，而是当**任务级柔顺提议**（语义绑定、任务阶段、导纳调度）；高频、与提议无关的**无源盾**用能量槽记账与边界检查拦截无效/过期/未验证预测，在导纳端口提供可证明的采样无源运行时契约；在对抗性柔顺漂移下保持零无源违约。
- **事实 F72（ForceVLA2，arXiv 2603.15169，CVPR 2026）**：端到端 VLA 引入**混合力-位置控制 + 显式力感知**；力提示进入 VLM 专家，Cross-Scale MoE 在动作专家中融合实时交互力；构建 1000 条轨迹/5 类接触任务数据集；相对 π0/π0.5 提升 48.0%/35.0%，缓解机械臂过载与接触不稳。
- **事实 F73（SocialVLA，arXiv 2610.02360）**：在 **Unitree G1** 真机上，把人类观察者的自发反应（副语言音频、视觉反应、显式停手短语、机器人相关性）经**首事件融合**转成 VLA 运行时干预信号，触发 hold；15 名被试、238 个应干预 episode；检测器到融合中位 47.9 ms、VLA 门到物理 hold 中位 336 ms、反应起始到 hold 1.021 s。**这是「人的反应=免费在线失败信号」的直接先例，且本体就是本赛道的 G1。**
- **事实 F74（社会规范 HRI 系统综述，ACM THRI 14(3):56, 2025，DOI 10.1145/3722120）**：规范分为成文法与同伴非正式执行的规范；遵守影响信任、接受度与助人意愿；综述按「规范遵从/规范违反」等类别整理了 proxemics、非语言沟通等在机器人设计中的纳入方式，并指出形式化人类规范是设计「规范胜任」机器人的前提。
- **事实 F75（人意图识别用于实时人机协作，Frontiers Robotics & AI, 2025，DOI 10.3389/frobt.2025.1708987）**：用 LSTM/Transformer 从人的运动提前分类意图；在「人与机器人可访问同一组槽位」的装配场景中，预测人要把铜环放进哪个槽，从而调整机器人运动规划、**避免抢占同一槽位造成干扰**，提升安全与流畅性。
- **事实 F76（交接与表达，arXiv 2604.05320 / 2607.17839；Hand2Bot, IEEE RAS 2026-08-21）**：移动操作需在不打断功能与安全约束下表达意图；交接应**以接收者为中心**并给出抓取感知的物体朝向；RGB-D 视频生成与意图感知时序面部编码可提升人类到机器人交接的意图预测并降低误触发——社会行为在操作中的落点是「时机、朝向、可中断性」，不是寒暄。
- **推论 C1（由 F60 直接推出，本轮关键）**：官方观测含**实测双臂 EE 位姿 [6]×2**，动作又是**命令目标**（ee 或 joint）。若选 `control_space=ee`，则「命令 EE − 实测 EE」的跟踪误差是**从接口内部长出来的一条力通道**；若选 joint，则需要 FK（依赖 URDF，A17 未决）。因此 v17 认为「ee 与 joint 几乎无差别」是错的：**ee 空间的首要价值不是省一次 IK，而是让力可观测**。
- **缺口登记**：A39 官方「人为干扰」场景是否真有真人、是否可观测、评分是否含规范/安全项，公开渠道未核实（沿用 v16/v17 的五场景假设）；A40 官方控制器的位置环增益未知，力影可观测性只能在自采 G1 上标定；A41 无社会规范标注数据；A42 官方是否允许 ee 空间、评测机控制器是否一致未知；A43 柔顺参数随负载漂移。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（v17 的盲区不是「能力不够」，而是「世界建模缺两个通道」）**。读完 F60 我反复确认了一件事：官方给的是**位置目标 + 实测 EE 位姿 + 四路相机 + 一句静态语言**，没有力、没有触觉、没有力矩，也没有第二句指令。v17 由此得出结论「力控做不了，只能做参考轨迹」。但这个结论只对了一半：**力没有被传感，不等于力不可观测**——命令与实测的差、夹爪开合的变化、相机里物体的形变，都是力的影子。另一半更关键：语言指令全 episode 不变、无时间轴（F60），可真实桌面任务里**人的意图是逐帧变化的**。当一个人伸手过来，他不是在「干扰噪声」，他是在用动作说一句新指令：「这个物体我要用」「让一下」「把东西给我」。v17 把这句话当扰动丢掉，v18 要把它读出来。两个灵感词因此不是两个模块，而是**两条被接口藏起来的隐式契约通道**：物-机之间的力契约，人-机之间的规范契约。

**直觉 2（力控 → 「力影 + 柔顺投影 + 无源盾」三段式，且不碰力矩层）**。文献把我原本的犹豫打散了：CompVLA/F68/Imp-ACT 证明「运动 + 刚度」可以联合预测且收益巨大；ForceDelta-VLA 更直接——**参考动作与力修正是可分离的**，而且修正可以在 chunk 之间做、不必重生成整个 chunk，这简直是为官方 `action_chunk_size` 接口量身定做；PaCo-VLA 则回答了「没有可信力传感怎么保证安全」：把 VLA 输出降级为柔顺提议，用能量槽无源盾在导纳端口兜底。于是 v18 的力控路线是：**(i) 力影**——用 ee 空间的命令-实测差 + 辨识出的闭环柔顺模型，在线估计接触力（不是传感器，是影子）；**(ii) 柔顺投影**——把期望力/刚度经 `u_ref = x_ref + K_d^{-1}(w* − D_d ẋ)` 投影回位置参考，官方接口看到的仍是一串目标，但这条参考在接触时是「会让步」的；**(iii) 无源盾**——能量槽 + 边界检查，保证模型错、力影偏、提议过期时都不会往系统里注能。三条都不需要力矩接口，全部诚实于 F60。与 v17 的 IP-50 无缝咬合：**刚度 K_d 从常数升级为决策变量**，能量项/精度项/热项一起优化。

**直觉 3（社会规范 → 「规范场 + 人的反应=免费失败检测器」，规范是接触级约束不是礼貌）**。F74 的综述提醒我：规范不只是 proxemics 和寒暄，它影响信任与接受度；但在**桌面操作**里，规范最硬的落点是接触级的：不碰人的身体/手、不抢人正在伸手去拿的物体（所有权/claim）、人伸手时让行或递交、靠近人时降速、干扰结束后从断点续做而不是把整段任务重来。SocialVLA（F73）给了我一个极其重要的礼物：**人的声音、表情、突然停手本身就是高置信的失败/干预信号**，在 G1 上 336ms 就能触发物理 hold——这比等 VLM 判别快一个数量级，而且不花额外训练标签。意图识别（F75）则给了「提前量」：从伸手轨迹预测目标槽位，在抢占发生前就让。于是规范场不是一张静态规则表，而是**由人的状态驱动的动态约束场**：硬约束（人身安全、亲密区、所有权）+ 软代价（舒适距离、速度、交接时机/朝向），再与 v17 的步骤分做兑换——过度让行会多吃步数，所以必须找 λ*，这正是 E76。

**直觉 4（两个词共享「隐式契约」结构 → Ξ 平面与 Δ 平面并列）**。力契约约束「用多大力、多柔顺、是否无源」；规范契约约束「能靠近谁、能拿什么、什么时候该停/让/递」。它们都是**部分可观测、必须在线推断、且必须以证书形式落到动作上**的东西。v17 的 Δ-Plane 是一本「资源账本」——决定「付不付得起」；v18 的 Ξ-Plane 是一本「约束账本」——决定「允不允许做」。两者合起来才是完整的运行时治理：Δ 管热/时延/步数，Ξ 管力/人/规范；冲突时按 **人身安全 > 规范硬约束 > 任务成功 > 步数/热效率** 的字典序仲裁。时间尺度也必须分开：力影和人的急停走**快通道**（chunk/step 级，毫秒–百毫秒），规范场与意图走**慢通道**（2–5Hz），慢通道的输出只能在下一个 chunk 边界生效，绝不拖慢快通道。

**直觉 5（再次修剪：v17 的复杂度要还给「人」和「接触」）**。v17 已经压过一次复杂度，但仍留着几项在单本体、单赛道里没有得分的设计：IP-42 跨本体运动先验——官方只有 G1 一种本体，跨本体只在离线预训练有意义；IP-40 六源奖励塑形——离线、复杂、且 v18 的监督重点转向「力/规范」两类新信号；IP-46 鲁棒性证书已被热 SLO 证书取代，v18 再用「契约证书」统一；IP-38 坠落恢复与 IP-24 失败监测高度重叠。**本轮把 IP-42 → P2、IP-40 收敛为三源 → P1、IP-46 并入 IP-53 契约证书、IP-38 并入 IP-24、IP-44 → P1**，腾出的预算给 IP-51/52/53。新增 P0 核心严格控制在 3 项，并明确：v18 的胜负手不是「社会规范模型多大」，而是 **力影到底可不可观测**——所以 E73 必须最先做。

## 2. 灵感词 → 落地线（新增 + 重构 + 修剪登记）

- 「**力控**」→ **IP-52 FORCE-SHADOW-COMPLIANCE（P0 新增）**：ee 空间力影估计（命令-实测差 + 辨识闭环柔顺 + 夹爪/残差线索）→ 接触相位分类（free/contact/slip/jam）→ 时变刚度与期望力调度（沿/正交各向异性）→ 柔顺投影回位置参考 → ForceDelta 式「参考+修正」学生（部署端无力传感）→ PaCo 式能量槽无源盾 → 与 IP-50 的 TO 共用一套刚度/能量目标、与 IP-48 共享峰值力→热账本。
- 「**社会规范理解**」→ **IP-51 SOCIAL-NORM-FIELD（P0 新增）**：人的状态估计（姿态/手/注视/伸手/参与度）+ 意图与所有权预测（claim/handover/interfere）+ 规范库（proxemic 环、工作区、所有权、轮次、交接朝向与时机、近人减速、干扰后续做）+ 硬约束/软代价分解 + 人的反应快通道（SocialVLA 式 hold）+ 规范违约证书。
- 「**两词联合**」→ **IP-53 IMPLICIT-CONTRACT-ARBITRATION / Ξ-PLANE（P0 新增，横切）**：把 C_contact 与 C_social 统一为隐式契约 C_t，双时间尺度推断（快：力影/人停；慢：意图/规范场），字典序仲裁（安全 > 规范硬约束 > 任务 > 步数/热），契约证书（力界/无源/规范概率界）取代 IP-46，向 IP-49 提供约束与软代价、向 IP-50 提供柔顺/交接约束、向 IP-33 提供力/社会 CBF、向 Δ-Plane 提交让步/柔顺的步数与热预算。
- 修剪登记：**IP-42 跨本体运动 → P2 挂起**（单一 G1 本体，赛道内无得分，离线收益边际）；**IP-40 六源奖励 → P1，收敛为三源**（R_VLM/sem/prog，离线且非在线得分）；**IP-46 鲁棒性证书 → 功能并入 IP-53 契约证书**（保留低层控制器解析收缩性）；**IP-38 坠落恢复 → 并入 IP-24 统一恢复**；**IP-44 渐进蒸馏 → P1**（单轮数据/算力预算下不作为 P0 胜负手）。
- 升级：IP-50（刚度 K_d 升为决策变量 + 力影约束 + 柔顺投影 + 无源盾）、IP-49（规范场硬/软约束、社会风险项、干扰后断点续做、让行步数预算）、IP-33（力/社会 CBF：力上限、人身距离、所有权）、IP-36（语义图新增 human/agent 节点、claim 关系、可形变物体接触包络）、IP-48（峰值力→力矩尖峰→热账本；社会急停走快通道）、IP-28v2（接触相位作为进度信号）、IP-25（时延 SLO 增加「人停→物理 hold」与力影更新率）、IP-43（流式执行支持柔顺投影与 chunk 间力修正）、IP-30（人的反应作为外部验证器信号）、IP-21（旗舰模型增加柔顺/规范头）、IP-2/3/4/9/10 继承、IP-27 挂起。

## 3. 形式化直觉（严格版见产物区 §3）

**定义 29（隐式契约）**：`C_t = (C^F_t, C^S_t)`。`C^F_t = {(对象对, F_max, K_d(·), E_tank, s_min)}` 是接触契约；`C^S_t = {(人 h, 亲密区 R_h, 所有权 Claim(h), 轮次状态 τ_turn, 交接帧 H_h, 近人速度上限 v_h)}` 是规范契约。语言 `l` 静态且不含时间轴，故 `C_t` 只能由观测历史推断：`b_t(C)=p(C_t | o_{1:t}, l)`；动作必须使硬约束以 `≥1−δ` 概率成立。

**定义 30（力影）**：令 `u_cmd(t)` 为 ee 空间命令目标，`x(t)` 为实测 EE 位姿，`ẋ` 由堆叠观测差分。辨识闭环柔顺 `(K̂_c, D̂_c, τ̂, b̂)` 后，力影 `ŵ(t)=K̂_c⊙(u_cmd(t−τ̂)−x(t)) + D̂_c⊙(u̇_cmd(t−τ̂)−ẋ(t)) + b̂`（旋转分量走 SO(3) log 映射）。它是**潜观测量**，不是传感器；可观测性要求位置环足够柔顺（稳态偏转大于位姿分辨率），否则退化为接触检测器。

**定义 31（柔顺投影）**：给定期望力 `w*(t)` 与刚度 `K_d(t)`，位置参考 `u_ref(t)=x_ref(t)+K_d(t)^{-1}(w*(t)−D_d ẋ_ref(t)−M_d ẍ_ref(t))`，并做关节/EE 限幅与无源盾投影。自由空间 `w*=0` 时退化为 v17 的 TO 参考；接触时用「虚拟位移」编码力——**这就是位置-only 接口上的力控**。

**定义 32（规范场）**：`c_N(x,t)=Σ_h [α·φ(d(x,h)) + β·1{x∈W_h} + γ·1{target(x)∈Claim(h)} + η·ψ(speed,d(x,h)) + θ·1{轮次违约}]`；`φ` 在亲密区（非交接）取 +∞，`W_h` 为人的工作区。硬约束：`d(x,h)≥d_min`、不进入亲密区、不碰被 claim 的物体；软代价塑形轨迹与速度。计划的社会风险 `R_S(π)=P(∃t: 硬约束违约)`，代价 `J_S(π)=E∫c_N dt + λ_resume·T_resume`。

**定义 33（契约证书与联合期望得分）**：`Cert(π)=[P(力越界)≤δ_F]∧[P(E_tank<0)=0]∧[P(规范硬违约)≤δ_S]∧Cert_v17`；计划可行当且仅当 `Cert(π)`。联合目标 `E_score^Ξ(π)=Π_s p_s(s|σ)·g(N_π) − λ_f E[力越界] − λ_s E[规范软违约] − λ_h P(人停) s.t. Cert(π)`。注意：**规范硬约束是约束不是价格**，不允许用得分「付费绕过」；软规范才是代价。

**命题 P51（力影一致性/可观测性）**：在线性柔顺闭环 `x = u_cmd* − K_c^{-1}w + ε` 与参数误差 `(ε_K, ε_D, ε_b)` 下，`E|ŵ−w| ≤ ε_K‖u−x‖ + ε_D‖u̇−ẋ‖ + ε_b + ε_noise`；接触起始检测延迟约 `τ̂ + 采样周期`。若 `‖K_c‖` 很大（刚性位置环），稳态偏转低于分辨率，力影只剩瞬态与夹爪线索——**此时只能当接触检测器，不能当力幅传感器**。
**命题 P52（投影无源性）**：若无源盾强制能量槽 `E_tank(t)≥0` 且投影在限幅内，则对任意有界 `w*` 与任意有界模型误差，导纳端口采样无源；柔顺投影不会向系统注入能量（PaCo-VLA 同构，v18 的差异是把它落在参考层、且力影本身不可信时仍成立）。
**命题 P53（规范增益阈值）**：令 `Δp=p_s(有规范)−p_s(无规范)`，`Δg=g(N_有)−g(N_无)≤0`。规范感知策略提升 `E_score` 当且仅当 `Δp·g(N) > |Δg|·p_s + λ_s·ΔE[软违约]`；故存在 `λ_s*`，过度让行会反噬步骤分。
**命题 P54（隐式通道必要性）**：构造两个物体布局与静态 `l` 完全相同、但人的 claim 不同的世界。任何忽略社会通道的策略 `π(o_{1:t})` 在两世界中动作分布相同，必须在其中一个世界侵犯 claim、或在另一个世界过度让行；故社会通道不是可选项。
**命题 P55（力-热-步三赢区间）**：峰值力矩满足 `τ_peak≤JᵀF_max+τ_grav`；降低 `F_max` 与柔顺着陆同时降低 `∫τ²dt`（热）与滑移/重抓概率（步数），故接触任务存在一个 `K_d` 区间使成功率、热、步数同时改善；过度柔顺会拉长时间、增加步数，呈 U 形，存在最优 `K_d*`。
**命题 P56（双平面可行性）**：联合调度是旋钮 `K`（v17）与刚度 `K_d`（v18）上的约束优化，约束含 `C^F, C^S`、热、时延、步数；可行域可能为空（如必须快速让行但热已临界且模型很慢）。此时按字典序回退并吊销契约证书，触发安全 hold，而不是硬做任务。

## 4. 关键决断

1. **力可观测化**：`control_space=ee` 升为 P0 默认（除官方强制 joint），因为命令-实测差是唯一不增传感器的力通道；joint 模式需 FK 且依赖 URDF。
2. **力控不碰力矩层**：力影→柔顺投影→无源盾，全在位置参考层实现；不做「假设力矩接口」的设计，诚实于 F60。
3. **规范即约束**：硬约束（人身安全/所有权/亲密区）+ 软代价（舒适/速度/交接），并进入契约证书；硬约束不允许被得分优化付费绕过。
4. **人的反应是信号**：SocialVLA 式 hold 纳入 IP-24 快通道（<1s），与 VLM 慢判别并行；这是零额外标签的在线失败检测。
5. **双平面治理**：Δ（资源）× Ξ（契约）；仲裁字典序为 人身安全 > 规范硬约束 > 任务成功 > 步数/热效率。
6. **修剪五项**：IP-42→P2、IP-40 收敛 P1、IP-46 并入 IP-53、IP-38 并入 IP-24、IP-44→P1；新增 P0 严格三项。

## 5. 本轮最大风险（一句话）

**若官方控制器的位置环足够硬（跟踪误差≈0）则在无 F/T 观测下力影不可观测；若官方「人为干扰」并非真实人类而是脚本扰动、或社会规范无法从相机稳定推断，则 Ξ 平面会退化为两个不可证伪的先验——必须以 E73（力影辨识/标定）+ E74（柔顺投影消融）+ E75（规范推断）+ E76（规范-步数兑换）+ E77（契约证书压测）+ E78（端到端）六重守门，任一失败即按「力影→接触检测器 / 规范→被动让行」降级，双败则回退 v17。**

# 第 41 轮产物 · 创新点清单 v18：隐式契约平面 Ξ（力影 × 规范场），四层架构 v6

### 3.2 IP-51 SOCIAL-NORM-FIELD（规范场，完整设计）

**IP 卡片（六字段）**
- **动机**：官方语言指令全 episode 不变、无时间轴（F60），而真实桌面评测含人机共存/人为干扰（A39 沿用假设）；F74 证明规范影响信任与接受度，F73 证明人的自发反应可在 G1 上 336ms 转成干预信号，F75 证明可从运动提前预测人要去哪、从而避免抢占。v17 把这一切当普通扰动，浪费了「人」这条免费信号。
- **与现有方案差异**：HRI 的规范研究多在导航/proxemics/交流（F74），操作中的社会性多落在交接朝向/时机（F76）；**没人把规范写成「接触级硬约束 + 操作步数兑换」并接入任务规划与 CBF**。我们把它做成 **norm field**：既是感知（人的状态）、又是约束（硬/软）、又是失败信号（人的反应）、又是步数预算项（让行成本）。
- **技术可行性**：人姿态/手/注视可由高位相机轻量估计（<10ms/帧，2–5Hz 足够）；意图预测用小型时序模型（F75 同构）；人的反应快通道用音频/视觉/停手短语（F73 同构），无需训练标签；规范库是规则 + 少量参数，不需要大模型。
- **所需资源**：数据=自采人机共存桌面 episode（含 reach/gaze/claim/handover 标注，E75）；算力=人状态估计 + 意图小模型 <1% GPU；接口=四路相机（高位为主）+ 静态语言，零改造；隐私=端上姿态估计、不存身份、不录原始音频。
- **落地步骤**：① 定义规范库与硬/软分解（E75 前）；② 自采/标注小幅数据（200–500 episode）；③ 训练意图/claim 预测；④ 规范场接入 IP-49（软代价）与 IP-33（硬约束）；⑤ 接 SocialVLA 式人停快通道到 IP-24；⑥ E75/E76 验收。
- **风险**：误停（人的动作与任务无关）→ 相关性过滤 + 迟滞；漏停 → 硬约束 CBF 兜底；过度让行吃步数 → E76 找 λ*；无规范标注 → 弱标签 + 规则先验；文化/场景差异 → 规范库参数化、只保留通用硬约束。

**符号表**

| 符号 | 含义 | 来源 |
|---|---|---|
| `h_t=(p,q,gaze,hand,vel,engage)` | 人的状态 | 高位相机估计，2–5Hz |
| `π_H(claim=o), π_H(handover), π_H(interfere)` | 意图概率 | 时序模型（F75 同构） |
| `R_h, W_h, d_min` | 亲密区/工作区/最近距离 | 规范库（F74） |
| `Claim(h)⊆O` | 人当前主张的物体集 | 伸手方向 + 注视 + 抓握 |
| `H_h=(frame, t_window, orient)` | 交接帧/时间窗/朝向 | F76 |
| `c_N(x,t)` | 规范场代价 | 定义 32 |
| `R_S(π)` | 计划的社会硬违约概率 | 定义 32 |

**算法（双通道）**
```
慢通道（2–5Hz）:
  输入：高位相机、语言 l、语义图（含 claim/human 节点）
  1. ĥ ← estimate_human(cam_high)                 # pose/hand/gaze/velocity
  2. π_H ← intent_model(ĥ_history)                # claim/handover/interfere
  3. 更新规范场：R_h, W_h, Claim(h), turn_state, H_h
  4. 输出到 IP-49：硬约束集 + 软代价图 c_N(x)；到 IP-50：交接帧/让行 waypoints
快通道（每 step / 事件）:
  1. 若 detect_human_stop(audio, face, hand_retract) 且 relevance>τ:
       IP-24.hold(reason='human_stop')；IP-33 冻结当前 chunk
  2. 若 d(EE,h)<d_min 或 EE 轨迹将进入亲密区(非交接):
       IP-33 触发社会 CBF：投影到安全集，减速/绕行
  3. 若 target(EE) ∈ Claim(h):
       标记 claim 冲突 → 慢通道重规划（等待/换目标/让行）
中断后:
  save(checkpoint)；干扰结束且无冲突 → resume_from(checkpoint)  # 不重做已完成的步
```

**正确性论证**：P54（隐式通道必要性）证明忽略社会通道无法同时最优于「人 claim」与「人不 claim」两世界；P53（规范增益阈值）给出「规范遵守 vs 步数」的兑换条件；P57（快通道上界）——若人停检测延迟 ≤ `δ_stop`，社会 CBF 在最坏情况下把违规时间限制在 `δ_stop` 内，且物理 hold 延迟由 IP-25 的 SLO 约束（F73 的 336ms 作为可达下界参考）。

**复杂度**：人状态估计 O(1)/帧；意图模型 O(history)；规范场查询 O(|O|+|H|)；快通道事件驱动 O(1)。总开销 <1% GPU，慢通道不进入每步关键路径。

### 3.3 IP-52 FORCE-SHADOW-COMPLIANCE（力影-柔顺，完整设计）

**IP 卡片（六字段）**
- **动机**：官方动作是位置目标、观测无 F/T（F60），但接触任务（插入/擦拭/按压/双臂交接）必须调力。F67/F68/F69/F72 证明「运动+刚度」联合/变阻抗收益巨大；F70 证明「参考 + 力修正」可分离且可在 chunk 间更新；F71 证明无力传感也可用无源盾提供运行时契约。C1 进一步给出**不增传感器的力通道**：ee 空间的命令-实测差。
- **与现有方案差异**：现有力感知 VLA 假设有力/触觉输入或力矩控制（F67–F72）；**无人利用「位置接口的命令-实测误差 + 辨识闭环柔顺」构造力影并投影回位置参考**。我们不做力矩层，不新增传感器，不假设官方控制器；把力控变成「参考层的柔顺投影」，并用无源盾保证模型错时也安全。与 v17 IP-50 的差异：v17 的 TO 只做参考精修、K_d 视为常数；v18 把 K_d 升为决策变量，并让 TO 的终端目标受力约束。
- **技术可行性**：ee 位姿观测与命令目标均可得（F60）；闭环柔顺参数可在自采 G1 上用外部 F/T 标定（E73）；接触相位分类用 |ŵ|、d|ŵ|/dt、EE 速度残差、夹爪开合即可；ForceDelta 式学生可用仿真特权力/实验室 F/T 作教师；无源盾是低维能量槽，<0.1ms/step。
- **所需资源**：数据=E73 激励轨迹（40min×负载 0/0.5/1.0kg）+ 实验室 F/T 标定 + 接触任务示教；算力=力影 <0.1ms/step、刚度预测 <2ms/chunk、学生推理随 VLA；接口=ee 空间动作 + 实测 EE 位姿 + 夹爪，零改造（joint 模式需 URDF，A17）。
- **落地步骤**：① E73 辨识 `(K_c,D_c,τ,b)` 并验证力影 vs F/T；② 接触相位分类器；③ 刚度/期望力头（沿/正交）；④ 柔顺投影 + 限幅；⑤ 无源盾（PaCo 同构）+ IP-33 力 CBF；⑥ ForceDelta 式学生蒸馏（可选）；⑦ E74/E71 验收。
- **风险**：位置环过刚→力影不可观测（命题 P51，最大风险）；柔顺参数随负载/温度漂移→在线自适应 + 安全系数；过度柔顺→滑移/步数上升（P55 U 形）；学生无标签→教师只在仿真/实验室，部署用一致性损失；官方控制器与自采 G1 不一致→E77 压测 + 保守裕度。

**符号表**

| 符号 | 含义 | 来源 |
|---|---|---|
| `u_cmd(t)` | ee 空间命令目标 | 官方动作（control_space=ee） |
| `x(t), ẋ(t)` | 实测 EE 位姿/速度 | 官方 obs（EE [6]×2）+ 堆叠差分 |
| `(K̂_c,D̂_c,τ̂,b̂)` | 闭环柔顺/延迟/偏置 | E73 辨识 |
| `ŵ(t)` | 力影（估计接触力） | 定义 30 |
| `K_d(t)` | 期望刚度（沿/正交各向异性） | IP-52 策略头输出 |
| `w*(t)` | 期望力/接触力剖面 | 任务阶段 + 语义图 |
| `E_tank(t)` | 无源盾能量槽 | PaCo 同构 |
| `φ_t` | 接触相位 ∈{free,contact,slip,jam} | 分类器 |

**力影与柔顺投影（核心式）**
```
力影：      ŵ(t) = K̂_c ⊙ (u_cmd(t−τ̂) − x(t)) + D̂_c ⊙ (u̇_cmd(t−τ̂) − ẋ(t)) + b̂
柔顺投影：  u_ref(t) = x_ref(t) + K_d(t)^{-1} ( w*(t) − D_d ẋ_ref(t) − M_d ẍ_ref(t) )
限幅：      u_ref ← clip(u_ref, 关节/EE 限位)；再经无源盾与 IP-33
```
**算法（接触相位 + 刚度调度 + 无源盾）**
```
输入：obs.ee=x, 命令历史 u_cmd, 夹爪 g, 任务阶段 φ_task(来自 IP-28v2), 语义图
1. 力影：ŵ ← force_shadow(x, u_cmd, K̂_c,D̂_c,τ̂,b̂)
2. 接触相位：
   free:    |ŵ|<ε_F 且 夹爪无接触特征
   contact: |ŵ|≥ε_F 且 d|ŵ|/dt 稳定
   slip:    夹爪宽度突变 或 EE 速度残差>ε_s 且 |ŵ| 下降
   jam:     |ŵ|>F_max 或 EE 停滞而 |u_cmd−x| 持续增大
3. 刚度/力调度：
   K_d(t) ← policy_head(φ_task, φ_t, 语义图, 热账本)   # 沿运动方向↑、正交↓（F69）
   w*(t)  ← force_profile(φ_task, φ_t, F_max, 物体柔性)
   若 φ_t=jam: K_d↓, w*↓, 减速；若 slip: 夹爪力↑ 或 K_d↑ 后重抓
4. 柔顺投影：u_ref ← project(x_ref, K_d, w*)
5. 无源盾：E_tank += ΔE_in − ΔE_out；若 E_tank<0 或预测越界：
   u_ref ← hold/safe_projection；记录证书违约
6. 硬约束：IP-33 检查 ||ŵ||≤F_max、d(EE,h)≥d_min、不碰 claim 物体
7. 热联动：峰值 |ŵ| 与 τ̂ 峰值写入 IP-48 的 H_motor 账本
输出：u_ref（T_a 步目标序列）
```

**正确性论证**：P51（力影误差界与可观测条件）；P52（无源盾 ⇒ 导纳端口采样无源，模型误差不注能）；P55（力-热-步三赢区间 + U 形最优 K_d）；P58（柔顺投影退化性）——当 `K_d→∞` 时 `u_ref→x_ref`，精确退化为 v17 的位置 TO，故最坏情况下不劣于 v17（只要无源盾不误触）；当 `F_max` 极小时退化为「轻触+多次微调」，步数上升但力安全。**这把「力控失败」变成「性能下降」而不是「系统不安全」。**

**复杂度**：力影 O(1)；相位分类 O(1)；刚度头 <2ms；投影 O(1)；无源盾 O(1)；学生推理随 VLA。总增量 <3ms/chunk（不含学生），不触碰 v17 的 SLO。

### 3.4 IP-53 IMPLICIT-CONTRACT-ARBITRATION / Ξ-PLANE（隐式契约仲裁，完整设计）

**IP 卡片（六字段）**
- **动机**：力契约与规范契约都是「部分可观测、必须在线推断、必须以证书约束动作」的隐式约束；v17 的 Δ-Plane 只管资源，不管「允不允许」。没有统一仲裁，IP-51/52 会各自为政（例如社会要求急停、力控要求继续接触、热控要求降额），产生互相打架的动作。
- **与现有方案差异**：文献把安全（CBF/无源）与社会规范分开处理；**无人把「力/无源」与「人身/所有权/轮次」放进同一个契约平面，并与热/步数资源平面做字典序仲裁**。Ξ-Plane 的产出是可测试的契约证书，而不是一句「注意安全」。
- **技术可行性**：契约的每一项都可观测或可界定（力影/能量槽/人距离/claim/轮次）；仲裁是低维规则 + 约束投影，<0.1ms；证书各项可独立压测（E77）。
- **所需资源**：复用 IP-51/52 的估计器；新增仲裁器与证书监控；无额外数据。
- **落地步骤**：① 定义 `C^F,C^S` 字段与硬/软边界；② 实现字典序仲裁与约束投影；③ 接 IP-49（约束/代价）、IP-50（柔顺/交接）、IP-33（CBF）、IP-48（预算）；④ 证书监控与违约回退；⑤ E77/E78 验收。
- **风险**：可行域为空导致频繁 hold → 回退策略与最小让步；硬约束过多导致任务不可完成 → E76 校准；证书概率界估计不准 → 保守 δ + 在线统计。

**契约与仲裁**
```
C_t = (C^F_t, C^S_t)
C^F_t = { (对象对, F_max, K_d(·), E_tank≥0, s_min) }
C^S_t = { (h, R_h, Claim(h), τ_turn, H_h, v_max(h), d_min) }
硬约束（不可付费绕过）：人身距离 d_min、亲密区（非交接）、不碰 Claim、力上限 F_max、无源 E_tank≥0
软代价（可兑换步数）：舒适距离、近人速度、交接时机/朝向、轮次流畅度
仲裁序：人身安全 > 规范硬约束 > 任务成功 > 步数/热效率
双平面交换：让行/柔顺消耗 Δ 的步数与热预算 → 由 IP-49 的 E_score 统一计价
证书：Cert(π) = [P(力越界)≤δ_F] ∧ [P(E_tank<0)=0] ∧ [P(规范硬违约)≤δ_S] ∧ Cert_v17
```

**正确性论证**：P56（双平面可行性/空域回退）；P59（契约证书单调性）——增加任一硬约束只会缩小可行动作集，故 `Cert` 对约束集单调（不会因加约束而「更不安全」）；P60（仲裁一致性）——字典序仲裁在任意两契约冲突时给出唯一优先级，且与「人停快通道」不矛盾（快通道永远最高）。**注意**：契约证书不是「成功率证书」，它只保证「不做被禁止的事」；任务成功率仍由 IP-49/50 的 E_score 负责。

**复杂度**：契约推断复用 IP-51/52；仲裁 O(|硬约束|+|软项|)≈O(10)；证书检查 O(1)/step。

### 3.5 v18 四层架构 v6（双平面横切）

```
   ┌────────────── Δ-Plane（IP-48：H_gpu/Ĥ_motor/S_used/L_p99 + 旋钮 K）──────────────┐
```

### 3.6 训练/服务伪代码（v18 增量版）

```python
# ===== 离线：力影辨识 + 柔顺教师蒸馏（IP-52）=====
def identify_force_shadow(robot_if, ft_sensor):
    traj = collect_excitation(minutes=40, payloads=[0.0, 0.5, 1.0])   # 目标-实测-外力
    Kc, Dc, tau, b = fit_closed_loop_compliance(traj, ft_sensor)     # 各轴 + SO(3) log
    teacher = train_force_conditioned_policy(sim_privileged_force=True)  # 特权力教师
    student = distill(teacher, inputs=[cameras, proprio, language])      # 部署端无力输入
    return Kc, Dc, tau, b, student

# ===== 离线：社会规范标注与规范场（IP-51）=====
def build_norm_field(episodes):
    # episodes: 自采人机共存桌面操作，含 reach/gaze/claim/handover/stop 标注
    intent = train_intent_predictor(episodes)   # p(claim), p(handover), p(interfere)
    norms  = NormLibrary(proxemics, claims, turn_taking, handover_frame, speed_near_human)
    return intent, norms

# ===== 运行期：双平面 governor + 契约仲裁（IP-48/51/52/53）=====
def act_v18(obs, state):
    # 1) Δ 账本（v17）
    ledger = update_ledger(gpu=telemetry(), motor=motor_heat_proxy(state.cmd_hist),
                           steps=state.steps, latency=L_ewma)
    # 2) Ξ 契约推断（双时间尺度）
    human  = social_perception(obs.cam_high)                  # pose/hand/gaze, <10ms
    intent = state.intent.update(human)                       # 2-5Hz
    force  = force_shadow(obs.ee, state.cmd_hist, state.Kc, state.Dc, state.tau)
    phase  = contact_phase(force, obs.gripper, obs.ee_vel)    # free/contact/slip/jam
    contract = infer_contract(human, intent, phase, state.norms, obs.language)
    # 3) 双平面联合调度
    knobs  = delta_governor(ledger)                           # v17 旋钮（含 T_a/resize/branch）
    budget = xi_to_delta(contract, knobs)                     # 让行/柔顺的步数-热代价
    # 4) 规划：规范硬/软约束 + 力风险 + 让行预算并入 E_score
    if state.need_plan:
        plan = step_efficient_planner(obs.language, state.semantic_map, state.p_s,
                                      state.W, state.M_f, scenario=state.sigma,
                                      contract=contract, budget=budget)
        state.plan = plan
    # 5) 柔顺投影：TO 参考 + K_d 调度 + 无源盾
    if state.need_refine:
        task = midlevel(state.waypoints, obs, budget=budget, contract=contract)
        warm = stream_policy_head(state.plan.skill, obs)      # IP-43；含 ForceDelta 式修正
        Kd, w_star = compliance_policy(state.plan.skill, phase, state.semantic_map, ledger)
        ref = hybrid_to_compliance(task, warm, force, state.Kc, state.Dc, Kd, w_star)
        u_ref = compliance_project(ref, Kd, w_star, limits=state.limits)
        if not passivity_shield.check(u_ref, force):          # PaCo 式能量槽
            u_ref = safe_hold(state); log_cert_violation('passivity')
    else:
        u_ref = state.traj
    # 6) 快通道：人的反应 / 社会硬约束
    if detect_human_stop(obs) or contract.hard_violated:
        u_ref = hold_and_yield(state)                         # <1s（F73 可达下界参考）
    # 7) 步级安全：力/社会 CBF + v17 CBF
    chunk = u_ref.next_chunk(knobs.T_a_eff)
    if not guard.cbf_check(chunk, contract):                  # IP-33 扩展
        chunk = resample_or_fallback(state, r=2)
    # 8) 失败/契约违约 → 软重规划；干扰后断点续做
    if failure_monitor(obs) > TAU or contract.violated:
        state.checkpoint = save(state)
        state.need_plan = True
    return adapt(chunk, control_space='ee')                   # ee：让力可观测（C1）
```

**降级机制 v4（按优先序保底）**
- E73 失败（力影不可观测）→ **IP-52 降为「接触检测器 + 轻触策略」**，不做力幅控制；仍保留无源盾与力上限 CBF。

- E75 失败（规范不可推断）→ **IP-51 降为「被动让行」**：只用人体距离硬约束 + 人停快通道，不做 claim/意图预测。
- E76 失败（规范让行不划算）→ λ_s→0，只保硬约束；规范只作为安全层，不作为得分层。
- E77 失败（证书过保守/违约）→ 降低 δ 需求，退回 v17 的 CBF + 热 SLO；证书仅监控不门控。

- **全败 → 回退 v17 非 Ξ 架构**，保留「人停快通道」与「力上限 CBF」两个最小安全件。

## 6. 清单迭代规则（继承 27–51 + 本轮新增 52–54）

- 继承规则 27–51（通道诚实/映射验证/SLO/fail-safe/灵感-现实校验/单模型合规/步骤分双解释/稠密监督/方法论遗产/元数据重照亮/语言口径分离/摊销/验证器分级/灵感词落地/层级联合规划/跨本体运动/流式韵律/渐进蒸馏/服务化/证书化/组合代数/热预算/期望得分/学习-TO/修剪优先）。
- **52（新增）：隐式契约原则**——力与人-机规范是两类隐式契约，必须显式推断、显式证书化；**不得把「位置接口无力反馈」当作「无需力控」**，也不得把「语言指令静态」当作「无需理解人」。
- **53（新增）：接口投影原则**——在位置-only 接口上做力控，必须用「命令−实测」力影 + 闭环柔顺辨识 + 柔顺投影；禁止假设力矩/力传感接口；力影不可观测时降级为接触检测，而非伪造力幅。
- **54（新增）：双平面仲裁原则**——Δ（资源）与 Ξ（契约）联合调度；仲裁序为 **人身安全 > 规范硬约束 > 任务成功 > 步数/热效率**；规范硬约束不得被得分优化「付费绕过」；可行域为空时按字典序最小让步并吊销契约证书，而非硬做任务。

**本轮最大风险一句话**：若官方位置环过刚使力影不可观测、且「人为干扰」并非可观测真人，则 Ξ 平面退化为两个不可证伪的先验；以 E73–E78 六重守门，按「力影→接触检测器 / 规范→被动让行」降级，双败回退 v17。

**当前最值得押注**：**IP-52 FORCE-SHADOW-COMPLIANCE**——它是 v18 唯一同时满足「不增传感器、不改官方接口、直接攻接触精度与热峰值、可被 E73/E74 快速证实或证伪」的点；力影可观测性一旦成立，柔顺投影与无源盾就只是工程实现，且能反向喂养 IP-50（K_d 决策变量）与 IP-48（峰值力→热账本）。IP-51 是第二优先（人的反应快通道几乎零成本、但规范推断依赖 A39/A41）；IP-53 是二者的粘合剂，不应先于 IP-52 单独投入。
