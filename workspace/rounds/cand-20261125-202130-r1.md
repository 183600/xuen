灵感驱动研究循环·新灵感第 1 轮；本轮灵感：「用户测试」×「场景落地」

> **基线**：MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–439（CESC 云边同步 / FSVC 少样本 / IPAM 知识产权 / HPC-E+ 四证门），其上承 v22 的 HDL/ACSC/DCSC/CFC++、v21 的 SDC/CAC/DCL/GIC、v20 的 PCA/CTS/CFC/HPC/CFCtrl 与 v19/v17 全部模块。**v20–v23 全部保留，一律不推倒。**
> **本轮纪律**：此前十一轮都在"数学世界"里签字——`κ_c` 的召回下界、`ε_loc` 的定位误差、conformal 的 `1-α`、手势阈值、能量裕度，全部是**假设**；每张证书还默认"机器人正处在设计者想象的场景里"。本轮只补一个被所有轮次默认掉的缺口：**证书必须在真实人群、真实场景中成立，并且只在其被测试过的包络内成立**。两个灵感是同一枚硬币的两面：**用户测试 = 证据从哪里来、人如何成为证据的一部分；场景落地 = 证据在哪里有效、失效时如何退场**。二者统一为 **现实接口层 (Reality Interface Layer, RIL)**：用**经验接地证书 (EGC)** 把每个经验参数钉在可审计的现场证据上，用**运行设计域证书 (OCC)** 把认证限定在可测的包络内，用**人因证书 (HFC)** 把操作员的信任与干预变成受控变量，用**分阶部署阶梯 (DRL)** 与**证书健康监测 (CHM)** 让体系"带证据上线、越界即退"。核心命题：**证书不是对一次运行的点断言，而是对一个部署总体的、有样本、有置信度、有保质期的统计断言。**

## 0. 直觉与动机

### 灵感 1（用户测试 → 证书是对总体的统计断言，干预不是噪声而是标签）

**直觉**：v23 的 conformal 与 Hoeffding 界看起来很严谨，但它们只在"校准集与测试集可交换"时成立；而校准集常常来自工程师、实验室、成年人、好光照。用户测试真正暴露的不是"界面好不好用"，而是**一个残酷的量词问题**：我们到底测的是谁？儿童蹲着、轮椅使用者、逆光中的深色衣着、戴安全帽的工人——这些人群在测试样本里可能各只有个位数，却被部署总体的"平均覆盖率"一笔带过。更反直觉的是：**操作员的每一次干预（急停、接管、纠正）都不是要过滤掉的噪声，而是一条免费的负标签**——它标记了"证书说 SAFE，但人判断为不安全"的那个点。用户测试因此不是上线前的一道验收闸门，而是**上线后的、持续的、带结构的证据采样器**。

**严谨化**：把每个安全参数 `θ ∈ Θ_emp = (κ_c, ε_loc, α, q_low, q_high, σ_E)` 从"一个常数"升级为"带 `(1-β)` 置信下界的区间"。例如类别 `c` 在场景分层 `s` 中的召回率，用 Clopper–Pearson 下界 `κ̂^L_{c,s}`；缺席证书只在 `min_s κ̂^L_{c,s} ≥ κ_c^req` 时被允许签发。**绑定分层而不是取全样本平均**，是为了堵住辛普森悖论：总体召回 0.98、儿童分层只有 0.71 时，平均值会让"覆盖区内无人"在儿童身上系统性为假。

### 灵感 2（场景落地 → 认证一直缺一个量词：`∀ z ∈ ODD`）

**直觉**：v20–v23 的所有安全性命题都是 `∀π: Safe(π)`，但真实系统从来不是"对所有场景安全"，而是"**在这些场景下安全**"。这个被省略的量词——运行设计域 (ODD)——就是场景落地的全部难点。实验室里 99% 的覆盖率，搬到没有画线的仓库、反光地坪、雨雾装卸区，可能一夜归零。反直觉点在于：**显式写出 ODD 不会让系统更保守，反而会释放活性**——因为只有在域外才需要"假设有人/全局限速"，域内则可以用接地后的紧证据大胆行动。场景落地因此不是"把实验室策略搬出去"，而是"把定义域一起搬出去，并让定义域可在线核查"。

**严谨化**：`O = { z : g_i(z) ≤ 0, i=1..m }`，`g_i` 是可测的上下文谓词（照度、坡角、人群密度、网络时延、地面材质反射率、人距分布等）。每张证书都改写成**条件证书** `Cert(π | z_{0:T_π} ∈ O)`：一旦轨迹离开 `O`，证书立即失效并触发降级。进一步用**余量带与滞回**避免边界抖动，用**事故驱动的域收缩**把每次干预/近失事件定位到具体谓词，单调缩小 `O`。

### 灵感 3（用户测试 → 人因是安全回路的一等公民，过度信任是静默失效）

**直觉**：v21 把"人"当作感知对象（检测、手势、义务），却从未把"人"当作**控制器组件**来建模。用户测试反复揭示两类相反失效：**不信任**导致频繁干预、活性坍缩、甚至在不安全时刻抢操作；**过度信任（自动化自满）**导致人不看屏幕，恰恰在自动化出错时失去了唯一的后备。两者都让安全论证里"人类兜底"这条隐含假设失效。反直觉点：**过度信任比不信任更危险**，因为它把"人作为最后防线"的可用性悄悄降为零，而日志上一切正常。

**严谨化**：把人因做成可测指标——信任校准误差 `δ_trust = |trust_reported − reliability_actual|`、干预召回 `ρ_int = P(干预 | 真危险)`、响应时延分位 `T_int^{1-γ}`、以及**自满指数** `CI`（在静默故障注入试验中，距上次事件的时间越长，漏检率上升的斜率）。HFC 用这些现场演练指标**门控自主等级**：达不到门槛就退回有人监督/辅助模式，而不是在纸面上假装人还在回路里。

### 三者如何统一（现实接口层 RIL）

统一为 v23 四证门之上的 **RIL**：EGC 回答"这些数字凭什么可信、测的是谁"，OCC 回答"这份证书在哪个场景包络内有效"，HFC 回答"人此刻是否还真的在回路里"，DRL/CHM 回答"证据攒够了没有、现在还能不能继续跑"。共享状态扩展为 `ζ_ril = ζ_ce ∪ (D, Θ_emp, κ̂, O, occ_state, hf_metrics, ℓ, Λ, E, ttl)`。统一准入门升级为 **HPC-F = HPC-E+ ∧ EGC ∧ OCC ∧ HFC ∧ DRL ∧ CHM**，执行集 `Exec_v24 = Exec_v23 ∩ Fil_egc ∩ Fil_odd ∩ Fil_hf ∩ Fil_dep ⊆ Exec_v23`。**任何一项失效都向"证据最坏值 + 场景域外 + 自主等级最低"方向闭合**，从而延续单调退化链，且把"统计上有效"升级为"外部上有效、场景上有界、部署上可退"。

## 2. 设计原则（在既有 P 系列基础上新增 P43–P45）

**P43 经验接地律（Empirical Grounding）**
每个经验参数必须随身携带一条可审计证据记录：`Ground(θ) ≜ ∃D_θ: LB_{1-β}(θ; D_θ) ≥ θ^req`，其中下界按 ODD 分层取**最坏分层**，并用同时置信修正。**未接地或证据过期一律取最坏值**（`κ_c→0` 即禁发缺席证书，`ε_loc→∞` 即全域膨胀）：接地失败只会更保守，绝不借用实验室数字。

**P44 域内认证律（Domain-Bounded Certification）**
每张证书是条件断言 `Cert(π | z_{0:T_π} ∈ O_in)`。`OCC` 三态 `IN / MARGIN / OUT` 带滞回：`IN` 使用紧证据，`MARGIN` 收紧参数并降速，`OUT` 立即回退到安全停机/受限模式。`O` 只会因事故被**单调收缩**，从不因"想跑得快"被放宽；域外无证书。

**P45 证据时效与分阶自主律（Evidence Freshness & Staged Autonomy）**
经验证据带 `TTL_evid`，过期即视为未接地。自主等级 `ℓ ∈ {0,1,2,3}`（影子/辅助/监督/自主）是"累积且在控证据"的单调函数，晋升用序贯检验、降级用 anytime-valid 变点检测；任一控制图越界、任一严重事故、任一证据过期都触发**降级 + 回滚**，且回滚只回到此前已认证版本。`Exec` 随 `ℓ` 单调不增。

## 3. 与基线的接口（如何退化）

- EGC 失效/证据过期 ⇒ 所有经验参数取最坏值 ⇒ 禁发 AbsCert、`ε_loc` 全域膨胀 ⇒ 等价 v20/v21 最保守路径；
- OCC 失效或画不出可信 `O` ⇒ 视为全局 `OUT` ⇒ 退回共享区停机/静态人距上限 ⇒ 比 v23 更保守；
- HFC 失效（无法完成人因演练）⇒ 自主等级强制 `ℓ=0/1`（影子或辅助）⇒ 子集；
- DRL/CHM 失效 ⇒ 停止晋升并冻结在上一已认证等级，必要时回滚 `V_last_valid` ⇒ 子集；
- 所有接地证据全失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ ⋯ ⊆ Exec_v18`（引理 18）。
- **安全继承**：EGC 只收紧参数、OCC 只收缩域、HFC 只降低自主、DRL/CHM 只冻结或回滚；四者都没有"放宽"通道，故任意失效都向更保守方向退化。

## 4. 预期贡献

1. **经验接地证书**：首次把 `κ_c/ε_loc/α/q` 从假设升级为"分层同时置信下界 + 样本量功效分析 + 过期即失效"的可审计统计记录，直接封堵前几轮"合规的缺席幻觉"的根因——把经验假设本身变成可被证伪的对象；
2. **ODD 作为一等证书**：把"∀场景安全"改写为可测的条件断言，给出 `IN/MARGIN/OUT` 三态 + 滞回 + 事故驱动单调收缩，并证明显式 ODD 能在保持安全的同时释放域内活性；
3. **干预即标签**：把操作员干预同时用作**证伪下界**与（经倾向加权/随机审计的）无偏证据，给出用户测试在部署后的持续证据化协议；
4. **人因门控自主**：把信任校准误差、干预召回、响应时延、自满指数做成 HFC，直接门控自主等级，使"人类兜底"从口头假设变成被测量的门槛；
5. **带统计保证的分阶部署**：SPRT 晋升 + e-process/CUSUM 监测 + CESC 回滚，首次让"开多少、开多久、何时退"具有明确的错误概率界与活性损失界；
6. **HPC-F 接地-有界-可退门**：六证一体，形成 `Exec_v24 ⊆ ⋯ ⊆ Exec_v18` 的闭环，并把"数学可证"诚实升级为"经验可信、场景有界、部署可退"。

## 5. 本轮最大风险

**一句话**：整套经验接地把可靠性押在"用户测试样本能代表部署总体"这一**外部效度**前提上——一旦测试人群与部署人群在关键分层上系统性错位（只测成年人却在儿童区部署、只测尽责操作员却遇上长期自满的值班员），所有置信界都会**数学上无懈可击、外部上彻底失效**，系统将拿着统计上完美的证书，合规地认证一个从未被真正测试过的世界。

## 1. 关键算法骨架

```python
# ============================================================
# IP-440 EGC — 经验接地证书（分层同时置信 + 功效分析 + 过期失效）
# ============================================================
def clopper_pearson_lower(X: int, n: int, beta: float) -> float:
    """Beta^{-1}(beta; X, n-X+1)：二项分布成功率的 (1-beta) 单侧下界。"""
    if n == 0 or X == 0:
        return 0.0
    return beta_ppf(beta, X, n - X + 1)  # scipy.stats.beta.ppf

@dataclass
class Evidence:
    X: int; n: int
    t_collected: float
    protocol_hash: bytes          # 预注册现场协议的 Merkle 根
    strata: str                   # 所属 ODD 分层 s

class EmpiricalGroundingCertificate:
    def __init__(self, beta: float = 0.05, ttl_evid: float = 30 * 24 * 3600):
        self.beta = beta
        self.ttl_evid = ttl_evid
        self.D: dict[tuple[str, str], Evidence] = {}   # (class, stratum) -> Evidence
        self.O_active: 'ODDMonitor' = None
        self.planned_n_min: dict[tuple[str, str], int] = {}

    def required_samples(self, p_req: float, delta: float) -> int:
        """功效分析：使 CP 下界以 1-beta 落入 [p_req-delta, p_req+delta] 所需 n。"""
        return math.ceil(math.log(2 / self.beta) / (2 * delta ** 2))

    def add_evidence(self, cls: str, stratum: str, X: int, n: int,
                     t: float, protocol_hash: bytes):
        self.D[(cls, stratum)] = Evidence(X, n, t, protocol_hash, stratum)

    def ground(self, cls: str, now: float) -> bool:
        """Ground(θ)：所有活跃分层证据未过期，且最坏分层下界达标。"""
        strata = self.O_active.active_strata()
        if not strata:
            return False
        beta_prime = self.beta / max(1, len(strata))       # 同时置信（Bonferroni）
        lower_bounds = []
        for s in strata:
            ev = self.D.get((cls, s))
            if ev is None or now - ev.t_collected > self.ttl_evid:
                return False                               # 缺证据/过期 => 拒绝接地
            if ev.n < self.planned_n_min.get((cls, s), 0):
                return False                               # 样本量不达功效要求
            lower_bounds.append(clopper_pearson_lower(ev.X, ev.n, beta_prime))
        self.kappa_lower = min(lower_bounds)               # 绑定最坏分层
        return self.kappa_lower >= self.kappa_req[cls]

    def recovery_lower(self, cls: str) -> float:
        """供 CAC/AbsCert 调用；未接地时返回 0（禁发缺席证书）。"""
        return self.kappa_lower if self.grounded[cls] else 0.0


# ============================================================
# IP-441 OCC — 运行设计域一致性证书（三态 + 滞回 + 单调收缩）
# ============================================================
class ODDMonitor:
    def __init__(self, predicates: list[Callable[[np.ndarray], float]],
                 eps_m: float = 0.1, h: float = 0.05):
        self.g = predicates           # 每个返回 g_i(z)，<=0 表示满足
        self.eps_m = eps_m            # 紧域余量
        self.h = h                    # 滞回带宽
        self.state = "OUT"
        self.shrink_log: list[tuple[float, int, bytes]] = []  # (t, predicate_id, incident)

    def evaluate(self, z: np.ndarray) -> str:
        m = max(gi(z) for gi in self.g)          # 最紧谓词（>0 即域外）
        if m <= -self.eps_m - self.h:
            self.state = "IN"
        elif m <= 0 + self.h:
            self.state = "MARGIN"
        else:
            self.state = "OUT"
        return self.state

    def active_strata(self) -> list[str]:
        """IN 用全部已测分层；MARGIN 只用保守分层（去掉边界敏感层）。"""
        return self.strata if self.state == "IN" else self.strata_conservative

    def on_incident(self, z: np.ndarray, t: float, incident_hash: bytes):
        """事故驱动收缩：把最违反的谓词阈值单调收紧，永不放宽。"""
        i = int(np.argmax([gi(z) for gi in self.g]))
        self.g[i] = tighten(self.g[i], z)        # 例如 L_min <- max(L_min, z.illuminance)
        self.shrink_log.append((t, i, incident_hash))
        self.state = "OUT"                        # 收缩即要求重新认证


# ============================================================
# IP-442 HFC — 人因证书（现场演练测得，门控自主等级）
# ============================================================
@dataclass
class DrillResult:
    hazard_present: bool
    operator_intervened: bool
    latency_s: float
    reported_trust: float
    actual_reliability: float
    hours_since_last_event: float

class HumanFactorsCertificate:
    def __init__(self, gamma=0.05, delta_trust_max=0.2,
                 rho_int_min=0.9, tau_react=2.0, ci_max=0.1):
        self.gamma = gamma; self.delta_trust_max = delta_trust_max
        self.rho_int_min = rho_int_min; self.tau_react = tau_react
        self.ci_max = ci_max
        self.metrics = None

    def calibrate(self, drills: list[DrillResult]) -> dict:
        hazards = [d for d in drills if d.hazard_present]
        rho_int = sum(d.operator_intervened for d in hazards) / max(1, len(hazards))
        lat = np.quantile([d.latency_s for d in hazards], 1 - self.gamma) if hazards else np.inf
        d_trust = np.mean([abs(d.reported_trust - d.actual_reliability) for d in drills])
        ci = self._complacency_slope(drills)       # 漏检率对"距上次事件时长"的斜率
        self.metrics = dict(rho_int=rho_int, T_int=lat, delta_trust=d_trust, CI=ci)
        return self.metrics

    def _complacency_slope(self, drills):
        """自满指数：静默故障注入下，漏检率随时长上升的回归斜率（越大越危险）。"""
        rows = [(d.hours_since_last_event, float(d.hazard_present and not d.operator_intervened))
                for d in drills]
        return linreg_slope(rows)

    def allowed_level(self) -> int:
        m = self.metrics
        if m is None:
            return 0
        if (m['rho_int'] >= self.rho_int_min and m['T_int'] <= self.tau_react
                and m['delta_trust'] <= self.delta_trust_max and m['CI'] <= self.ci_max):
            return 3
        if m['rho_int'] >= 0.8 and m['T_int'] <= 1.5 * self.tau_react:
            return 2
        if m['rho_int'] >= 0.5:
            return 1
        return 0


# ============================================================
# IP-443 DRL — 分阶部署阶梯（SPRT 晋升）
# ============================================================
class DeploymentReadinessLadder:
    def __init__(self, p0=0.001, p1=0.01, alpha_s=0.05, beta_s=0.1):
        self.level = 0
        self.p0, self.p1 = p0, p1
        self.A = math.log((1 - beta_s) / alpha_s)
        self.B = math.log(beta_s / (1 - alpha_s))
        self.llr = 0.0

    def observe(self, event_failure: bool) -> str:
        """每单位暴露（小时/千次交互）更新一次 SPRT。"""
        p = self.p1 if event_failure else self.p0
        q = self.p0 if event_failure else self.p1
        self.llr += math.log(q / p)
        if self.llr <= self.B and self.level < 3:
            self.level += 1; self.llr = 0.0; return "PROMOTE"
        if self.llr >= self.A:
            self.level = max(0, self.level - 1); self.llr = 0.0; return "DEMOTE"
        return "HOLD"


# ============================================================
# IP-444 CHM — 证书健康监测（e-process + CUSUM，anytime-valid）
# ============================================================
class CertificateHealthMonitor:
    def __init__(self, r0=0.5, alpha_chm=0.01, cusum_k=0.5, cusum_h=5.0):
        self.r0, self.alpha_chm = r0, alpha_chm
        self.E = 1.0
        self.cusum, self.cusum_k, self.cusum_h = 0.0, cusum_k, cusum_h

    def update(self, r: float, lam: float = 0.1) -> bool:
        """r_t ∈ [0,1] 为标准化残差（覆盖缺口/干预率/近失率）。"""
        lam = min(lam, 1.0 / (1.0 - self.r0) - 1e-9)
        self.E *= 1.0 + lam * (r - self.r0)
        self.cusum = max(0.0, self.cusum + (r - self.r0 - self.cusum_k))
        if self.E >= 1.0 / self.alpha_chm:
            return False                       # Ville 保证：P(误报) <= alpha_chm（时间一致）
        if self.cusum > self.cusum_h:
            return False                       # 早警（较弱保证）
        return True

# IP-445 HPC-F — 六证一体准入门
# ============================================================
@dataclass
class HPCF:
    hpc_e_plus: 'HPCEPlus'
    egc: EmpiricalGroundingCertificate
    occ: ODDMonitor
    hfc: HumanFactorsCertificate
    drl: DeploymentReadinessLadder
    chm: CertificateHealthMonitor

    def admits(self, plan, ctx, z_hist, now) -> tuple[bool, str]:
        # 1) 基线四证
        if not self.hpc_e_plus.admits(plan, *ctx):
            return False, "HPC-E+"
        # 2) 经验接地：每个被本计划依赖的参数都必须 Ground
        for theta in plan.required_params:
            if not self.egc.ground(theta.cls, now):
                return False, f"EGC:{theta.cls}"
        # 3) ODD：整段历史必须在紧域内；MARGIN 需按收紧参数重验
        for z in z_hist:
            st = self.occ.evaluate(z)
            if st == "OUT":
                return False, "OCC:OUT"
            if st == "MARGIN" and not plan.certified_under_margin:
                return False, "OCC:MARGIN"
        # 4) 人因与自主等级
        if self.hfc.allowed_level() < plan.required_level:
            return False, "HFC"
        if self.drl.level < plan.required_level:
            return False, "DRL"
        # 5) 证书健康
        if not self.chm.in_control():
            return False, "CHM"
        return True, "OK"

# IP-446 CFC-F — 域感知共识（不跨域合并、过期证据作废）
# ============================================================
class FieldAwareConsensus(CertificateFederatedConsensusPlusPlusHierarchical):
    def consensus_round(self, now):
        out = {}
        for key, votes in self.votes.items():
            # 只保留同一 (ODD 状态区间, 自主等级, 证据版本) 的票
            groups = group_by(votes.values(), key=lambda v: (v.odd_state, v.level, v.evidence_v))
            for bucket, vs in groups.items():
                count_ok = len(vs) >= self.N - self.F
                modality_ok = len({v.modality for v in vs}) >= self.M_MIN_MODALITIES
                fresh_ok = all(now - v.t <= v.ttl_evid for v in vs)
                if count_ok and modality_ok and fresh_ok:
                    out[key] = self._majority_with_outlier_filter(vs)
                    break
            else:
                out[key] = "CI"            # 跨域/过期无法形成共识 => 保守
        return out
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| EGC.ground | `O(|S_active|)`（CP 分位可预计算） | `O(|C|·|S|)` 证据记录 | `β=0.05`, `TTL=30d` |

| HFC.calibrate | `O(|drills|)` 离线 | `O(|drills|)` | `γ=0.05`, `τ=2s` |

## 3. 正确性论证

### 引理 9（经验下界的外部有效性条件与分层同时覆盖）
**陈述**：若（i）每个 `(c,s)` 的现场样本是部署该分层分布的 i.i.d. 抽样；（ii）按 `β'=β/(|C||S|)` 构造 CP 下界并对活跃分层取最小，则 `P(∀c: κ̂^L_c ≤ κ_c) ≥ 1-β`，且 `κ̂^L_c` 不过高估计任何单一分层召回。

**证明**：对固定 `(c,s)`，CP 下界满足 `P(κ̂^L_{c,s} > κ_c,s) ≤ β'`。对 `|C|·|S|` 个事件取并集界，全事件同时成立的概率 `≥ 1-|C||S|β' = 1-β`。取 `min_s` 只会进一步降低下界，故不会高估最差分层的召回；辛普森悖论被"绑定最坏分层"结构性排除。若 (i) 不成立（协变量漂移），必须先行重要性加权或拒绝接地——这正是引理 13 的残余不可消除项。∎

### 引理 10（ODD 有界认证的单调性与抗抖动）
**陈述**：`OCC_state=IN` 时 `z∈O_in⊂O`；`OUT` 时证书失效并退到回退集，故 `Exec_v24 ⊆ Exec_v23`。带滞回 `h>0` 的三态机在边界附近不产生有限时间内的无限次切换。

**证明**：`IN` 要求 `max_i g_i ≤ -ε_m-h`，由 `O_in` 定义即 `z∈O_in`；`OUT` 要求 `max_i g_i > h`，此时由 P44 立即回退，回退集是 v23 认证集的子集，故单调。滞回：进入 `IN` 的阈值为 `-ε_m-h`，离开 `MARGIN` 到 `OUT` 的阈值为 `+h`，两阈值间隔 `ε_m+2h>0`；状态机的每次迁移都要求越过一个非零带宽，故有界扰动下有界次切换。事故收缩只调用 `tighten`（阈值单调），故 `O` 满足 `O_{t+1} ⊆ O_t`。∎

### 引理 11（人因门槛的单调降级）
**陈述**：`allowed_level` 对指标 `(δ_trust↓, ρ_int↑, T_int↓, CI↓)` 单调不减；`ℓ` 下降只会使 `Exec` 收缩。

**证明**：`allowed_level` 的判定是若干"指标优于阈值"的合取分层，阈值固定且比较方向单调，故指标改善不会降低允许等级。`plan.required_level` 固定时，`ℓ` 下降使更多计划被 `DRL/HFC` 拒绝，故 `Exec(ℓ-1) ⊆ Exec(ℓ)`。∎

### 引理 12（CHM 的时间一致误报控制与安全回滚）
**陈述**：在无漂移的零假设下，`P(∃t: E_t ≥ 1/α_chm) ≤ α_chm`（Ville 不等式）；回滚回到此前已认证版本不会增大执行集。

**证明**：`E_t` 为非负鞅（`E[r_t]=r_0` 时 `E[E_t|F_{t-1}]=E_{t-1}`），Ville 不等式给出 `P(sup_t E_t ≥ 1/α_chm) ≤ α_chm`，与检验次数无关，故支持在线连续监测。回滚目标是 `V_last_valid`，其证书集按定义已被认证，且由 P43/P44 的失效闭合，回滚后的 `Exec ⊆ 回滚前 Exec`（只可能更保守）。∎

### 引理 13（分阶晋升的统计保证与残余外部效度）
**陈述**：SPRT 在 `p_1`（不合格）下错误晋升概率 `≤ α_s`，在 `p_0`（合格）下错误降级概率 `≤ β_s`。但"样本代表性"无法由任何内部算法保证。

**证明**：SPRT 的 Wald 近似/精确界给出上述两类错误概率，阈值 `A_s,B_s` 即由其反解。外部效度依赖抽样机制而非推断机制：算法只能核验"协议已预注册、分层已覆盖、样本量达功效"，无法核验"未观测分层是否存在"。故残余项须由独立审计与部署期持续采证承担。∎

### 定理（HPC-F 的接地–有界–可退完备性）
**陈述**：`HPCF.admits(π)=True` 当且仅当 π 同时满足：(1) v23 四证安全；(2) 其依赖的每个经验参数以 `1-β` 同时置信在活跃 ODD 分层上接地且未过期；(3) 全轨迹落在 `O_in`（或按 MARGIN 收紧参数后仍成立）；(4) 人因与自主等级满足 `ℓ_req`；(5) CHM 在控。且 `Exec_v24 ⊆ Exec_v23 ⊆ ⋯ ⊆ Exec_v18`。

**证明**：充分性由 `admits` 的五个连言与引理 9–12 直接可得。必要性：任一条件缺失即对应一类未被缓解的失效（未接地→缺席幻觉；域外→外部效度失效；人因不达→兜底假设失效；CHM 越界→静默漂移），故被拒。单调链由每条过滤器只收缩不扩张、失败一律取最坏值（P43）、域只收缩（P44）、等级只降不升（P45）归纳得到。∎

### 命题（"统计有效 ≠ 外部有效"不可由内部机制消除）
**陈述**：给定任意有限的现场证据 `D`，若部署总体包含 `D` 未覆盖的某分层 `s*`，则不存在仅依赖 `D` 的算法能保证 `s*` 上的安全性；HPC-F 只能保证"在被测分层上安全"，不能保证"在部署总体上安全"。

**证明**：`s*` 上的风险泛函与 `D` 独立（`D` 中无 `s*` 样本），任何只依赖 `D` 的估计器在 `s*` 上的输出与真值可任意偏离。这是样本覆盖问题而非推断问题。故必须由外部机制（代表性抽样、部署期分层监测、拒绝进入无证据分层）承担，系统应把"无证据分层"显式标为 `OUT` 并拒绝认证。∎

## 6. 本轮最大风险（最终确认）

**一句话**：整套现实接口层把可靠性最终押在"用户测试样本对部署总体具有外部效度"这一**无法由系统内部证明**的前提上——一旦测试人群与部署人群在关键分层上系统性错位，所有置信界、ODD 与门槛都会**统计上完美、外部上失效**，系统将合规地认证一个从未被真正测试过的世界。
