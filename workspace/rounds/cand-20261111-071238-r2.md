# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「场景驱动创新」×「少样本学习」）

> 第 54 轮把技能组合推进到「动作剖面 α_S + 组合图 G_S + 云边映射 γ_ce + 联合证书 J」。但 J 仍隐含一个危险假设：**证书是无场景的**。本轮把两件事合并：**场景是证书的作用域，少样本是扩张作用域的证据预算**。核心矛盾：H24：ρ 与 α 都随场景漂移，通用基准上的高鲁棒性可能在目标场景静默失效；H25：少样本适配能在 k 条演示内「看起来学会」，却把动作占用推出已认证的 A_core，形成场景捷径与负迁移。

## 0. 直觉与动机

**灵感 1（场景是一等公民 → 证书从「勾选」变成「带半径的圆」）**
直觉：第 54 轮的联合证书 `J` 实际上只对某个隐含场景成立。真实部署里，换了桌面布局、光照、物体材质或指令分布，`ρ` 和 `α_S` 都会漂移。因此证书不应是布尔值，而应带一个**有效半径**：`J(ξ)` 只在场景邻域 `B_Ξ(ξ, ε_ξ)` 内承诺。场景驱动创新的第一性含义不是「多造几个 benchmark」，而是**主动决定证书的边界往哪里扩**。

**灵感 2（行为化场景距离 → 用技能行为差异而非文本描述度量场景）**
直觉：两个场景「看起来像」不代表对技能「做起来像」。定义场景距离时，应比较同一技能在两侧产生的**轨迹分布**：`d_Ξ(ξ,ξ') = sup_s W_1(P(τ|s,ξ), P(τ|s,ξ'))`。若 `ρ` 对该距离是 `L_Ξ`-Lipschitz 的，则「证书还剩多少余量」可直接换算成「还能容忍多远的新场景」：`ε_ξ = min_d (ρ_d(ξ)-ρ_min(d))/L_Ξ`。这把场景迁移从经验判断变成可计算的半径。

**灵感 3（少样本 = 场景条件化的快速适配，但 k 不是证据量）**
直觉：元先验 `π_meta=(θ0,g_φ)` 在场景分布上训练，新场景给 k 条演示 `D_k`，适配 `θ_k=θ0+g_φ(D_k)`。关键不是 `k`，而是**有效样本数** `k_eff = (Σw_i)²/Σw_i²`，其中 `w_i` 同时惩罚「场景太远」与「动作落在 `A_core` 之外」。10 条来自远场景、且动作越界的演示，其证据量可能不到 2 条。

**灵感 4（少样本悖论 → 少样本负责「提出」，不负责「认证」）**
直觉：若要求 `ρ_LCB ≥ 0.8`、`δ=0.05` 且全部成功，Clopper–Pearson 下界需要 `k_eff ≥ ⌈ln δ / ln ρ_min⌉ = 14` 条独立有效证据。也就是说，5–10 条演示足以**适配出一个候选**，却不足以**认证高可靠**。所以正确分工是：少样本产生候选与先验收缩，认证必须由**定向场景探针**补齐证据缺口 `Δk = k_req - k_eff`。把少样本当免费可靠性来源，是本轮最需要防的认知错误。

**灵感 5（场景驱动创新 → exploit / adapt / innovate / abstain 四动作决策）**
直觉：面对新场景 ξ，系统不是「一律微调」，而是在四动作中选：复用已认证技能（exploit）、少样本适配（adapt）、合成新技能（innovate）、弃权（abstain）。创新由价值-风险-证据成本共同决定：
`V(ξ)=P(ξ)·[U(ξ)-U_ref] - λ_r·Risk(ξ) - λ_c·Cost_evid(ξ)`。
只有当 `V_innovate` 显著超过其他动作、且场景新颖度 `ν(ξ)` 足够大时才创新，并为它生成**场景证据计划** `E_plan(ξ)`。这把「场景驱动创新」从口号变成带预算的序贯决策。

**灵感 6（场景条件化组合 → 组合图也随场景失效）**
直觉：第 54 轮的组合边 `compat(S_i,S_j)` 在 ξ 上成立，不代表在 ξ' 上成立：动力学变化会改变转换成本 `c_trans`，布局变化会改变动作交集。故组合图升级为 `G_S(ξ)`，跨场景复用组合路径必须重算 `A_overlap(ξ)` 与 `c_trans(ξ)`，否则「组合证书」只是旧场景的遗物。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（场景与场景空间）**
场景 `ξ = (μ_ξ, ν_ξ, λ_ξ, Ω_ξ)`：任务/指令分布 `μ_ξ`、动力学与摩擦等参数 `ν_ξ`、传感噪声 `λ_ξ`、布局与本体约束 `Ω_ξ`。场景空间记 `(Ξ, d_Ξ)`，技能库支持集 `supp(S_lib) = {ξ : ∃S∈S_lib, ξ∈dom J(S)}`，场景新颖度 `ν(ξ) = d_Ξ(ξ, supp(S_lib))`。

**定义 122（行为化场景距离）**
对技能/策略 `π` 与任务集 `S`，
```
d_Ξ(ξ,ξ') = sup_{s∈S} W_1( P(τ | s, ξ), P(τ | s, ξ') )
```
其中 `τ` 为轨迹（状态-动作序列），`W_1` 为一阶 Wasserstein 距离。经验估计 `d̂_Ξ` 用配对 rollout 与公共随机数（CRN）降低方差。**假设 (A29)**：对每个鲁棒性维度 `d`，`|ρ_d(ξ)-ρ_d(ξ')| ≤ L_Ξ · d_Ξ(ξ,ξ')`。

**定义 123（场景条件化证书与有效半径）**
场景条件化证书
```
J(ξ) = (ρ(·|ξ), α_{S|ξ}, A_cert(ξ), γ_ce(·|ξ), δ_a(ξ), evidence(ξ))
```
其有效域 `dom J(ξ) = B_Ξ(ξ, ε_ξ)`，其中
```
ε_ξ = min_{d∈𝔇_ρ} (ρ_d(ξ) - ρ_min(d)) / L_Ξ        (L_Ξ > 0)
```
部署条件：`d̂_Ξ(ξ_deploy, ξ) ≤ ε_ξ` 且第 54 轮联合证书条件成立。若 `ε_ξ ≤ 0`，该证书在任何邻域外都无效，必须重认证。

**定义 124（少样本适配与有效样本数）**
元先验 `π_meta = (θ0, g_φ, h)`，`h` 为场景核带宽。适配 `θ_k = θ0 + g_φ(D_k)`，`D_k={(ξ_i,a_i,r_i)}_{i=1}^k`。有效样本数取 Kish 形式：
```
w_i = exp(-d̂_Ξ(ξ_i, ξ)/h) · 1[a_i ∈ A_core(ξ)] · clip(π(ξ_i)/π0(ξ_i), 0, w_max)
k_eff = (Σ_i w_i)² / Σ_i w_i²
```
第一项惩罚远场景，第二项惩罚越界动作，第三项为重要性校正。**有效证据缺口** `Δk = max(0, k_req(ρ_min,δ) - k_eff)`。

**定义 125（少样本置信证书与弃权）**
设 `k_eff` 次独立有效试验中成功 `x` 次，成功率单侧下置信界
```
ρ_LCB = BetaInv(δ; x, k_eff - x + 1)        (Clopper–Pearson)
```
（或用 Hoeffding 保守替代 `ρ̂ - sqrt(ln(1/δ)/(2k_eff))`）。少样本可部署条件：
```
ρ_LCB(ξ) ≥ ρ_min  ∧  k_eff ≥ k_min  ∧  d̂_Ξ(ξ,ξ_c) ≤ ε_ξ  ∧  α_drift ≤ θ_drift
```
否则返回 `abstain`，并报告 `(Δk, ρ_LCB, d̂_Ξ, α_drift)`。**全成功时的样本复杂度**：`k_req = ⌈ln δ / ln ρ_min⌉`（例如 `ρ_min=0.8, δ=0.05 ⇒ k_req=14`）。

**定义 126（场景驱动创新决策）**
动作集 `𝒜_ξ = {exploit, adapt, innovate, abstain}`，价值
```
V(ξ,a) = P(ξ)·[U(ξ)-U_ref] - λ_r·Risk_a(ξ) - λ_c·Cost_evid(a,ξ)
```
其中 `Cost_evid` 含补齐 `Δk` 的探针成本。决策
```
a* = argmax_a V(ξ,a)
```
仅当 `V(ξ,innovate) > max(V(ξ,exploit), V(ξ,adapt)) + θ_v` 且 `ν(ξ) > θ_n` 时进入 innovate，并输出证据计划 `E_plan(ξ) = {(s_j, n_j) : Σ n_j ≥ Δk}`。innovate 的产物只能是**候选技能**，不得直接部署。

**定义 127（场景-少样本联合证书 SSJC 与场景条件化组合图）**
联合证书
```
J_ss = (ξ, ε_ξ, k_eff, ρ_LCB, A_core(ξ), α_drift, d̂_Ξ, mode, evidence)
```
其中 `α_drift = ||α_{S'|ξ} - α_{S|ξ0}||_1` 度量适配对动作剖面的漂移，`mode∈𝒜_ξ`。部署条件：`mode∈{exploit,adapt}` 且定义 125 全部成立。组合图升级为
```
G_S(ξ) = (V, E_ξ),  E_ξ = {(i,j) : compat(S_i,S_j|ξ) ≥ θ_a ∧ c_trans(S_i,S_j|ξ) ≤ τ_e}
```
跨场景复用组合路径 `P(ξ0) → P(ξ)` 时，必须满足 `d̂_Ξ(ξ,ξ0) ≤ min(ε_ξ, ε_ξ0)` 并重算每条边的 `A_overlap(ξ)` 与 `c_trans(ξ)`；否则整条路径降级为候选。

## 2. 关键算法 伪代码

### IP-121 SSC（Scenario-Scoped Certificate）

```python
def scenario_radius(rho, rho_min, L_xi):
    margin = min(rho[d] - rho_min[d] for d in rho)
    if L_xi <= 0:
        return float('inf') if margin >= 0 else -1.0
    return margin / L_xi

def scope_certificate(J, xi, rho_min, L_xi, d_hat, eps_meas):
    eps = scenario_radius(J.rho, rho_min, L_xi)
    if eps <= 0:
        return ('reject', 'no_scenario_margin', eps)
    if d_hat + eps_meas > eps:
        return ('reject', 'out_of_domain', d_hat, eps)
    return ('ok', ScopedCert(J, xi, eps))
```

### IP-122 BSD（Behavioral Scenario Distance）

```python
def behavioral_distance(policy, xi, xi2, probes, n_pairs=8):
    dists = []
    for s in probes:                      # 固定探针任务集
        for _ in range(n_pairs):
            seed = next_common_seed()      # 公共随机数
            tau1 = rollout(policy, s, xi,  seed=seed)
            tau2 = rollout(policy, s, xi2, seed=seed)
            dists.append(wasserstein1(tau1, tau2))
    return max(dists)                      # sup 的经验上界
```

### IP-123 FSA（Few-Shot Scenario Adapter）

```python
def effective_shots(D_k, xi, A_core, h, w_max=10.0):
    ws = []
    for (xi_i, a_i, _) in D_k:
        d = behavioral_distance_est(xi_i, xi)
        w = math.exp(-d / h) * (1.0 if a_i in A_core else 0.0)
        ws.append(min(w, w_max))
    s1 = sum(ws); s2 = sum(w*w for w in ws)
    return (s1*s1 / s2) if s2 > 0 else 0.0

def few_shot_adapt(meta, D_k, xi, A_core, rho_min, delta, k_min,
                   theta_drift, budget):
    k_eff = effective_shots(D_k, xi, A_core, meta.h)
    k_req = math.ceil(math.log(delta) / math.log(rho_min))
    if k_eff < k_min:
        return ('abstain', 'insufficient_effective_shots', k_eff, k_req)
    theta = meta.theta0 + meta.g_phi(D_k)
    x = evaluate_success(theta, xi, n=max(k_min, int(k_eff)), budget=budget)
    rho_lcb = clopper_pearson_lcb(x, int(k_eff), delta)
    alpha_new = action_profile(theta, xi)
    drift = l1(alpha_new, meta.alpha_ref)
    if rho_lcb < rho_min or drift > theta_drift:
        return ('abstain', 'certificate_fail', rho_lcb, drift, k_req - k_eff)
    return ('ok', theta, rho_lcb, drift, k_eff)
```

### IP-124 SLC（Shot-Limited Certificate / Evidence Plan）

```python
def evidence_gap(k_eff, rho_min, delta):
    k_req = math.ceil(math.log(delta) / math.log(rho_min))
    return max(0.0, k_req - k_eff)

def fill_gap(E_plan, gap, probe_pool, max_probes):
    plan, spent = [], 0
    for (s, gain) in sorted(probe_pool, key=lambda t: -t[1]):
        n = min(gain, gap - spent, max_probes - spent)
        if n <= 0: break
        plan.append((s, int(math.ceil(n)))); spent += n
    if spent < gap:
        return ('abstain', 'evidence_budget_exceeded', gap - spent)
    return ('ok', plan)
```

### IP-125 SDI（Scenario-Driven Innovation）

```python
def scenario_decision(xi, lib, meta, budget, theta_v, theta_n):
    if in_domain(lib, xi):                      # 已有证书覆盖
        return ('exploit', None)
    vals = {
        'exploit':  value_exploit(xi, lib),
        'adapt':    value_adapt(xi, lib, meta),
        'innovate': value_innovate(xi, lib, meta, budget),
        'abstain':  0.0,
    }
    a = max(vals, key=vals.get)
    if (vals['innovate'] > max(vals['exploit'], vals['adapt']) + theta_v
            and novelty(xi, lib) > theta_n):
        return ('innovate', evidence_plan(xi, budget))
    if a in ('exploit', 'adapt'):
        return (a, None)
    return ('abstain', None)
```

### IP-126 SSJC（Scenario-Shot Joint Certificate）

```python
def scenario_shot_certify(skill_seq, xi, J_xi, K, rho_min, delta,
                          theta_drift, L_xi, eps_meas):
    for s in skill_seq:
        eps = scenario_radius(J_xi[s].rho, rho_min, L_xi)
        if J_xi[s].d_hat + eps_meas > eps:
            return ('reject', 'scenario_out_of_domain', s, eps)
    rho_comp = compose_robustness_chain([J_xi[s].rho for s in skill_seq], K)
    alpha_comp = intersect([J_xi[s].alpha for s in skill_seq])
    drift = max(alpha_drift(s, xi) for s in skill_seq)
    rho_lcb = {d: clopper_pearson_lcb(rho_comp[d], J_xi[skill_seq[0]].k_eff, delta)
               for d in rho_comp}
    if min(rho_lcb.values()) < rho_min or drift > theta_drift:
        return ('reject', 'few_shot_composition_fail', rho_lcb, drift)
    return ('ok', SSJC(xi, eps, rho_lcb, alpha_comp, drift, mode='adapt'))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SSC | O(\|𝔇_ρ\|) | O(1) | `L_Ξ` 上界保守、半径可计算 |
| BSD | O(\|S\|·n_pairs·T) | O(T) | CRN 配对、`sup` 经验上界 |
| FSA | O(k·T + \|θ\|) | O(\|θ\|) | 权重有界、`k_eff` 不虚高 |
| SLC | O(\|probe\| log \|probe\|) | O(\|probe\|) | LCB 覆盖 ≥ 1-δ |
| SDI | O(\|𝒜_ξ\|·\|lib\|) | O(\|lib\|) | 价值估计无偏、弃权有界 |
| SSJC | O(\|S\|·\|A\| + \|𝔇_ρ\|) | O(\|A\|) | 场景域、LCB、漂移三重闭合 |

**正确性定理（Scenario-Shot Transfer Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `ρ` 对 `d_Ξ` 为 `L_Ξ`-Lipschitz；**(A30)** 核权重有界，`k_eff` 下界独立有效证据量，Clopper–Pearson 覆盖成立；**(A31)** 适配算子 `g_φ` 对支持集扰动 `β`-Lipschitz，`α_drift` 在 `A_core` 上度量；**(A32)** 配对探针与 CRN 使 `d̂_Ξ` 的偏差不超过 `eps_meas`。则对任意目标场景 `ξ`：
```
P_success(ξ) ≥ 1 - Σ_d (1 - ρ_LCB(d|ξ))
                 - P(d_Ξ(ξ,ξ_c) > ε_ξ - eps_meas)
                 - P(α_drift > θ_drift)
                 - β_E
                 [- P(ν(ξ) < θ_n)]        (仅 innovate 候选)
```
**推论（少样本不能替代认证）**：当 `ρ_min=0.8, δ=0.05` 时，即使全部成功也需 `k_eff ≥ 14`；若只有 `k=8` 且其中 3 条来自远场景/越界动作，则 `k_eff` 可能不足 5，`ρ_LCB` 远低于 `ρ_min`，系统必须 abstain 或补探针。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| `d̂_Ξ` 低估导致「伪同域」 | 高 | 距离上置信界 + CRN 配对 + 域外探针 |
| `k_eff` 高估导致 LCB 虚高 | 高 | 权重上限 `w_max` + 相关样本降权 + 覆盖率回归测试 |
| 少样本过拟合支持集 | 高 | 动作核心约束 + `α_drift` 绊线 + 留出场景验证 |
| 创新奖励被场景过拟合刷分 | 高 | 留出场景套件 + 预注册 `E_plan` + 新颖度阈值 |
| 部署期场景漂移使证书过期 | 中 | 在线距离监控 + 证书 TTL + 自动降级/回滚 |
| 组合图跨场景复用旧边 | 中 | `G_S(ξ)` 重算 + 场景戳 + 路径失效广播 |

## 6. 本轮最大风险

**一句话**：本轮把「场景」变成证书的作用域、把「少样本」变成扩张作用域的证据预算，理论上更诚实，但**场景距离与有效样本数都来自同一批稀缺 rollout**——一旦 `d̂_Ξ` 低估或 `k_eff` 高估，系统会用「伪同域 + 伪充分证据」给一个实际越界的技能盖章，少样本适配随后把动作剖面推出 `A_core`，形成最难察觉的静默负迁移；因此必须坚持 **距离上置信界 + LCB 下置信界 + 动作漂移硬绊线 + 证据不足即弃权**，宁可少创新，也不让「证书幻觉」进入部署。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SSC×BSD×FSA×SLC×SDI×SSJC）

> 承接第 54 轮产物 v31。本轮在动作-协同层之上增加**场景作用域层**与**少样本证据层**：
> - **SSC（Scenario-Scoped Certificate）**：证书带有效半径 `ε_ξ`，场景是证书的第一性作用域；
> - **BSD（Behavioral Scenario Distance）**：用轨迹分布差异度量场景距离，支撑 Lipschitz 迁移界；
> - **FSA（Few-Shot Scenario Adapter）**：场景条件化少样本适配 + 有效样本数 `k_eff`；
> - **SLC（Shot-Limited Certificate）**：少样本只「提出」，认证靠 LCB 与定向探针补齐证据；
> - **SDI（Scenario-Driven Innovation）**：exploit / adapt / innovate / abstain 四动作序贯决策；
> - **SSJC（Scenario-Shot Joint Certificate）**：场景-少样本-动作-鲁棒性联合证书；
> - **SCG-ξ（Scenario-Conditioned Composition Graph）**：组合图随场景重算，跨场景复用需重新认证。
>
> IP 编号：IP-121~IP-127（共 7 个新增）；升级 IP-115/116/118/120，使动作剖面、组合图、联合证书与迁移证书全部场景条件化。

## 2. 关键算法 伪代码

### IP-121 SSC

```python
def scenario_radius(rho, rho_min, L_xi):
    margin = min(rho[d] - rho_min[d] for d in rho)
    return margin / L_xi if L_xi > 0 else (float('inf') if margin >= 0 else -1.0)

def scope_certificate(J, xi, rho_min, L_xi, d_hat, eps_meas):
    eps = scenario_radius(J.rho, rho_min, L_xi)
    if eps <= 0:
        return ('reject', 'no_scenario_margin', eps)
    if d_hat + eps_meas > eps:
        return ('reject', 'out_of_domain', d_hat, eps)
    return ('ok', ScopedCert(J, xi, eps))
```

### IP-122 BSD

```python
def behavioral_distance(policy, xi, xi2, probes, n_pairs=8):
    dists = []
    for s in probes:
        for _ in range(n_pairs):
            seed = next_common_seed()          # CRN
            tau1 = rollout(policy, s, xi,  seed=seed)
            tau2 = rollout(policy, s, xi2, seed=seed)
            dists.append(wasserstein1(tau1, tau2))
    return max(dists)
```

### IP-123 FSA

```python
def effective_shots(D_k, xi, A_core, h, w_max=10.0):
    ws = []
    for (xi_i, a_i, _) in D_k:
        d = behavioral_distance_est(xi_i, xi)
        w = math.exp(-d / h) * (1.0 if a_i in A_core else 0.0)
        ws.append(min(w, w_max))
    s1, s2 = sum(ws), sum(w*w for w in ws)
    return (s1*s1 / s2) if s2 > 0 else 0.0

def few_shot_adapt(meta, D_k, xi, A_core, rho_min, delta, k_min,
                   theta_drift, budget):
    k_eff = effective_shots(D_k, xi, A_core, meta.h)
    k_req = math.ceil(math.log(delta) / math.log(rho_min))
    if k_eff < k_min:
        return ('abstain', 'insufficient_effective_shots', k_eff, k_req)
    theta = meta.theta0 + meta.g_phi(D_k)
    x = evaluate_success(theta, xi, n=max(k_min, int(k_eff)), budget=budget)
    rho_lcb = clopper_pearson_lcb(x, int(k_eff), delta)
    drift = l1(action_profile(theta, xi), meta.alpha_ref)
    if rho_lcb < rho_min or drift > theta_drift:
        return ('abstain', 'certificate_fail', rho_lcb, drift, k_req-k_eff)
    return ('ok', theta, rho_lcb, drift, k_eff)
```

### IP-124 SLC

```python
def evidence_gap(k_eff, rho_min, delta):
    k_req = math.ceil(math.log(delta) / math.log(rho_min))
    return max(0.0, k_req - k_eff)

def fill_gap(E_plan, gap, probe_pool, max_probes):
    plan, spent = [], 0.0
    for (s, gain) in sorted(probe_pool, key=lambda t: -t[1]):
        n = min(gain, gap - spent, max_probes - spent)
        if n <= 0: break
        plan.append((s, int(math.ceil(n)))); spent += n
    if spent < gap:
        return ('abstain', 'evidence_budget_exceeded', gap - spent)
    return ('ok', plan)
```

### IP-125 SDI

```python
def scenario_decision(xi, lib, meta, budget, theta_v, theta_n):
    if in_domain(lib, xi):
        return ('exploit', None)
    vals = {
        'exploit':  value_exploit(xi, lib),
        'adapt':    value_adapt(xi, lib, meta),
        'innovate': value_innovate(xi, lib, meta, budget),
        'abstain':  0.0,
    }
    a = max(vals, key=vals.get)
    if (vals['innovate'] > max(vals['exploit'], vals['adapt']) + theta_v
            and novelty(xi, lib) > theta_n):
        return ('innovate', evidence_plan(xi, budget))
    return (a, None) if a in ('exploit', 'adapt') else ('abstain', None)
```

### IP-126 SSJC

```python
def scenario_shot_certify(skill_seq, xi, J_xi, K, rho_min, delta,
                          theta_drift, L_xi, eps_meas):
    for s in skill_seq:
        eps = scenario_radius(J_xi[s].rho, rho_min, L_xi)
        if J_xi[s].d_hat + eps_meas > eps:
            return ('reject', 'scenario_out_of_domain', s, eps)
    rho_comp = compose_robustness_chain([J_xi[s].rho for s in skill_seq], K)
    alpha_comp = intersect([J_xi[s].alpha for s in skill_seq])
    drift = max(alpha_drift(s, xi) for s in skill_seq)
    k_eff = min(J_xi[s].k_eff for s in skill_seq)
    rho_lcb = {d: clopper_pearson_lcb(rho_comp[d], k_eff, delta)
               for d in rho_comp}
    if min(rho_lcb.values()) < rho_min or drift > theta_drift:
        return ('reject', 'few_shot_composition_fail', rho_lcb, drift)
    return ('ok', SSJC(xi, eps, k_eff, rho_lcb, alpha_comp, drift, mode='adapt'))
```

### IP-127 SCG-ξ

```python
def build_scenario_graph(skills, xi, theta_a, tau_e, K):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            compat = jaccard(action_profile(s1, xi), action_profile(s2, xi))
            c_trans = transition_cost(s1, s2, xi)
            if compat >= theta_a and c_trans <= tau_e:
                rho_comp = compose_robustness(s1.rho, s2.rho, K, xi)
                G.add_edge(i, j, compat=compat, cost=c_trans,
                           rho_comp=rho_comp,
                           A_overlap=intersection(s1.alpha, s2.alpha))
    return G

def reuse_path(P, xi0, xi, eps_meas):
    if d_hat(xi, xi0) + eps_meas > min(scenario_radius(P.rho, rho_min, L_xi),
                                       scenario_radius(P.rho0, rho_min, L_xi)):
        return ('reject', 'path_scenario_expired')
    return ('ok', recertify_edges(P, xi))   # 重算 A_overlap(ξ), c_trans(ξ)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SSC | O(\|𝔇_ρ\|) | O(1) | `L_Ξ` 保守上界，半径可判定 |
| BSD | O(\|S\|·n_pairs·T) | O(T) | CRN 配对，`sup` 经验上界 |
| FSA | O(k·T+\|θ\|) | O(\|θ\|) | 权重有界，`k_eff` 不虚高 |
| SLC | O(\|probe\| log\|probe\|) | O(\|probe\|) | LCB 覆盖 ≥ 1-δ |
| SDI | O(\|𝒜_ξ\|·\|lib\|) | O(\|lib\|) | 价值估计无偏，弃权有界 |
| SSJC | O(\|S\|·\|A\|+\|𝔇_ρ\|) | O(\|A\|) | 场景域 + LCB + 漂移三重闭合 |
| SCG-ξ | O(\|S\|²·\|A\|) | O(\|S\|²+\|E\|) | 边权场景重算，旧路径失效 |

**正确性定理（Scenario-Shot Transfer Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `ρ` 对 `d_Ξ` 为 `L_Ξ`-Lipschitz；**(A30)** 核权重有界，`k_eff` 下界独立有效证据量，Clopper–Pearson 覆盖成立；**(A31)** 适配算子对支持集扰动 `β`-Lipschitz，`α_drift` 在 `A_core` 上度量；**(A32)** 配对探针与 CRN 使 `d̂_Ξ` 偏差 ≤ `eps_meas`。则对目标场景 `ξ`：
```
P_success(ξ) ≥ 1 - Σ_d (1 - ρ_LCB(d|ξ))
                 - P(d_Ξ(ξ,ξ_c) > ε_ξ - eps_meas)
                 - P(α_drift > θ_drift)
                 - β_E
                 [- P(ν(ξ) < θ_n)]        (仅 innovate 候选)
```
**推论（少样本悖论 / 认证分离）**：要求 `ρ_min=0.8, δ=0.05` 时，即使全部成功也需 `k_eff ≥ ⌈ln δ/ln ρ_min⌉ = 14`。因此少样本适配只能产出**候选技能**；认证必须由定向场景探针补齐 `Δk`，或由场景先验做收缩估计并显式计入偏差项。这条推论把「少样本」从可靠性来源降级为**证据预算的来源**，是本轮最关键的工程约束。

```
deploy(J_ss) ⇔ mode∈{exploit,adapt}
             ∧ d̂_Ξ + eps_meas ≤ ε_ξ
             ∧ ρ_LCB ≥ ρ_min
             ∧ α_drift ≤ θ_drift
             ∧ k_eff ≥ k_min
```
任一不满足则降级为 `abstain` 或进入 `innovate` 的候选池，**不得直接上线**。

## 5. 本轮最大风险

**一句话**：场景作用域化与少样本证据预算让证书第一次诚实地标注「在哪里有效、凭什么有效」，但 `d̂_Ξ` 与 `k_eff` 都从同一批稀缺 rollout 估计，二者的误差正相关——一旦距离被低估、有效样本被高估，系统就会用「伪同域 + 伪充分证据」给越界技能盖章，少样本适配再把动作剖面推出 `A_core`，形成最隐蔽的静默负迁移；因此必须坚持 **距离上置信界 + LCB 下置信界 + 动作漂移硬绊线 + 证据不足即弃权**，宁可少创新，也不让「证书幻觉」进入部署。
