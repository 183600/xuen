# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「灵巧操作」×「数据集构建」）

> R69 把不确定性一分为二，并教会系统「看、问、触」：aleatoric 收紧，epistemic 去问。但它有一个从未写进证书的前提——**我要消解的那个模态，我的数据集里有过。** 在自由空间运动里，这个前提几乎总成立（同一个目标、同一条路，差的是参数不是拓扑）；一进入灵巧操作，它就大面积失效。
>
> 灵巧操作的不确定性不住在动作均值里，而住在**接触模式**里：哪几根手指、哪条接触边、接触法向、粘着还是滑移、力闭合还是形闭合、物体在遮挡下的位姿。这些是**离散/混杂、稀疏、富含相变**的对象；一次滑移、一次接触断开会把整条轨迹的动力学改写。更关键的是——**这类不确定性常常不是「我该选哪个」，而是「我根本没见过这个」。** 面对一个从未在数据里出现过的接触 regime（新的摩擦区间、新的指尖构型、新的软硬组合），再多的注视/提问也问不出答案：不是证据不够，而是**支撑为零**。
>
> 数据集构建正好是「主动交互」的**离线对偶**：R69 在运行时选择「问谁/看哪里」，R70 在离线选择「采哪种 regime/向谁采/在边界上采多少」。两者都受预算约束、都由信息增益驱动，但代价与证书不同——运行时的代价是安全与社交，离线的代价是物理磨损、人力与采集风险；运行时的证书是后验，离线的证书是**覆盖**。
>
> 核心命题：**把 R69 的 epistemic 再拆成「可问的模态歧义 U_mode」与「问不出来的支撑缺失 U_support / 参数不可辨识 U_param」；前者继续交给交互，后者必须交给一个带覆盖证书、失败边界激励、标签标定与反通胀审计的数据集构建闭环。只有在数据集证书覆盖当前 regime 时，R69 的交互消歧才被允许；否则系统必须保守退避，并把缺口写成一张可执行的采集请求。** 命名 **FORGE-RAS**（Flow-derived, Ontology-stratified, Regime-certified, Gap-driven data Engine）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我到底有没有被教过这件事**」——不知道并不可怕，可怕的是把「没学过」误当成「问一句就好」。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 不确定性住在接触里，而接触是稀疏的相变）**
直觉：抓握失败往往不是因为「手伸歪了 3 厘米」，而是因为「接触相位错了」：该粘的时候滑了、该滑的时候卡住了、指腹滚动的方向反了。接触状态是混杂系统：连续力/位形 + 离散接触拓扑（哪几对 link 接触）+ 相变（make/break/slip/stick）。这带来两个后果：(a) 流策略的多峰性主要不是「目标歧义」，而是**接触模式歧义**；(b) 接触事件在数据里极度稀疏（大多数帧是接近/保持，真正的相变只有几帧），于是「平均意义覆盖很好」的数据集，可能对最要命的相变几乎零覆盖。

**灵感 2（数据集构建 → R69 的 U_epi 藏着一个「我学过」的假设）**
直觉：R69 把 epistemic 当成「证据不足」，于是默认「再问一句就能补」。但贝叶斯后验只在**支撑**上可信：如果某接触 regime 从未出现在训练集，模型对它的后验不是「不确定」，而是**自信地错**——它会把新 regime 投影到最近的旧 regime（幻觉一个熟悉模态）或坍缩成一个模糊均值。数据集构建因此不是 R69 的前传，而是它的**上界**：数据决定哪些模态可被表示，R69 只在可表示的空间里做消歧。

**灵感 3（三分 → 问不出来的那种不知道）**
直觉：把 R69 的 U_epi 拆成三份：
- **U_mode（模态歧义）**：regime 在支撑内，只是证据不够——问/看/触可解；
- **U_support（支撑缺失）**：当前 regime 落在认证支撑之外——任何交互都不可约，只能采集数据或保守退避；
- **U_param（参数不可辨识）**：regime 见过，但关键物理量（摩擦系数、质量、柔顺）在当前激励下不可辨识——**要「激励」而不是「提问」**。
这三者的处置完全不同：U_mode 花交互预算，U_support 花数据预算，U_param 花**激励预算**（故意制造滑移/接触切换）。把它们混成一个标量，正是 R69 之后最危险的简化。

**灵感 4（失败边界 → 有信息的数据往往是「坏数据」）**
直觉：这是灵巧操作与普通视觉数据集最不一样的地方。关于摩擦锥、粘滑边界、抓取稳定裕度的信息，**几乎全部集中在失败边界附近**：严格位于摩擦锥内部、且从不动的那条成功轨迹，对 μ 的 Fisher 信息近乎为零——因为它从未「试探过」边界。而人类采集与工业数据集系统性地**只保留成功**：掉落、滑移、险胜被剪掉。结果是数据集对「哪里会坏」几乎零覆盖，却在「哪里通常没事」上高度冗余。R70 必须反过来：**在认证安全包络内，主动采集边界数据（incipient slip、near-drop、接触断开）**，这就是「安全的失败采集」。

**灵感 5（标注即测量 → 数据集的标签继承 R68 的标定债）**
直觉：接触模式标签不是天上掉下来的，它来自触觉/力/位姿传感，本身有漂移、有迟滞、有时延；而且标注者若能看到结果（成功/失败），就会产生**标注-结果混淆**（把「结果好」标成「模式对」）。一个建立在未标定标签上的数据集，会把系统性偏差**固化**成「覆盖」。因此覆盖证书必须绑定标签的标定证书：未标定的标签不算覆盖，标注泄漏必须被审计。

**灵感 6（覆盖 ≠ 能力 → 数据集是最容易 Goodhart 的对象）**
直觉：一旦「覆盖」成为 KPI，它就一定会被优化到失真：重复近乎相同的 demo 刷密度、把失败重标成成功、用物理上不可行的合成轨迹「覆盖」参数空间、用同源演示者伪装成多样本。更隐蔽的是，**覆盖率上升而 held-out 风险不降**——这正是覆盖被通胀的信号。所以数据闭环必须内建：物理可行性检查、held-out contact regime、负对照（注入已知坏数据看指标是否乱涨）、出处独立性。

**灵感 7（运行时↔离线是两条有偏的采样流）**
直觉：R69 只在「它已经疑惑」的地方提问，所以它的运行痕迹是**疑惑分布**，不是部署分布；用这些痕迹去决定采什么，会把数据越采越窄（只补自己爱问的题）。同时，当前策略采到的数据覆盖的是**当前策略的访问分布**，不是目标策略的。于是桥接必须带倾向性校正（IPW）、显式探索、以及「目标分布」的重要性权重；否则数据闭环会自我实现成一个更精致的回音室。

## 1. 形式化定义（增量：定义 310–329）

**定义 310（FORGE-RAS 总览与四不变式）** FORGE-RAS = (FMP, AUD†, CRM, CCC, SUD, DCG, SFE, LPC, DPA, RSB, RAS-WM†)。四不变式：
(i) **实时零采集写**（继承 R69 定义 293-i）：控制路径不因数据采集而改变；
(ii) **支撑门先于交互门**：仅当当前 regime 在认证覆盖内，才允许 R69 的 MINT 交互消歧（定义 314/325）；
(iii) **双通道覆盖**：数据集证书必须分别报告成功流形与失败边界 ∂F 的覆盖，二者不可互相替换；
(iv) **标签可证**：计入覆盖的每个接触模式标签都必须绑定标定证书与出处签名，未标定/未溯源的标签只作诊断、不计覆盖。

**定义 311（接触 regime 空间与本体 CRM）** 接触 regime r = (τ, φ, θ, e) ∈ ℛ：τ 为接触拓扑（接触图：哪些 link–object 对接触、法向/切向关系）；φ ∈ {approach, make, stick, slip, break} 为接触相位；θ 为物理参数（摩擦锥 μ、质量/惯量、柔顺、表面粗糙度）；e 为环境/任务上下文。度量
d_ℛ = w_τ·d_graph(τ,τ′) + w_φ·[φ≠φ′] + w_θ·‖θ−θ′‖_Σ + w_e·d_e。
CRM 是一棵分层 regime 目录（拓扑→相位→参数区间），用于分层覆盖与分层评估。

**定义 312（三分不确定性 SUD）** 给定观测 o：
U_mode = H(M | o, r ∈ supp_D)（支撑内、可问的模态熵）；
U_support = 1[ρ_D(r(o)) > ε_max]·(1 − c_D(r(o)))（认证支撑外的程度，ρ_D 见定义 313）；
U_param = H(θ | D, excitation(o))（当前激励下物理参数的后验体积/熵）。
三者语义不同、进入不同预算：U_mode→交互，U_support→采集/退避，U_param→激励/鲁棒控制。

**定义 313（数据集覆盖证书 CCC）** 数据集 D = {(o_i, ξ_i, r_i, ℓ_i, p_i)}，ℓ_i 为接触标签及其标定证书，p_i 为出处。定义：
- 覆盖半径 ρ_D(r) = min_{i: ℓ_i 已标定 ∧ 可行} d_ℛ(r, r_i)；
- 认证覆盖 C_ε(ℛ′) = μ({r ∈ ℛ′ : ρ_D(r) ≤ ε ∧ 局部密度 ≥ d_min}) / μ(ℛ′)；
- **双通道覆盖** C = (C^succ, C^∂F)，分别度量成功流形与失败边界；
- 覆盖必须按 τ/φ 分层报告，不允许「总覆盖」掩盖某个拓扑为零。
CCC 是 (C, 分层表, 采样器签名, 标定证书哈希, 出处根) 的签名对象。

**定义 314（支撑缺失与支撑门）** U_support(s) = 1 − c_D(r(s))，其中 c_D 是 CCC 给出的局部可信度。**支撑门**：若 U_support > τ_sup，或当前 τ 在 C^∂F 上为零，则禁用 MINT（问不出来），直接进入 R68 两级保守退避，并生成采集请求。这条门是 R69 与 R70 的分界线。

**定义 315（参数可辨识性与激励）** 观测模型 y = h(ξ; θ) + n，Fisher 信息 J(θ; D, excitation)。U_param = det(J)^{−1/2}（或后验熵）。关键：对摩擦 μ，若数据中无 slip 事件（切向力未达 μf_n 且相对滑动为零），则 ∂h/∂μ ≡ 0、J_μμ = 0 ⇒ U_param = ∞。**可辨识性不是数据量的函数，而是激励覆盖的函数。**

**定义 316（失败边界集与信息密度）** 失败边界 ∂F = {r : margin(r) = 0}，margin 可取摩擦锥裕度 μf_n − |f_t|、力闭合裕度、接触保持裕度。边界信息密度 ι(r) = tr(J_θ(r))，并验证其集中在 ∂F 的 ε-带内（引理 20）。采集目标因此是**风险加权 + 边界加权**的覆盖，而不是均匀覆盖。

**定义 317（缺口驱动采集 DCG）** 采集动作 c = (r_target, source, mode, n)（目标 regime、演示者/仿真/自采集、成功/边界/扰动模式、数量）。价值
V(c) = [ΔCov_weighted(c) + λ_v·ΔVoI_runtime(c) − λ_d·Redundancy(c)] / cost(c)，
s.t. 安全与预算。选 c* = argmax V，直到边际价值 ≤ 0 或预算耗尽。ΔCov 用定义 316 的风险/边界加权测度；Redundancy 惩罚与既有数据在 d_ℛ 上的近重复。

**定义 318（安全失败采集 SFE）** 边界采集必须在认证安全包络内：软质/可屈服环境、力/速度上限、可放弃（drop mat）、abort 包络（R68/R69 前缀认证 + 立即松开的反射）。形式化：采集轨迹物理风险 ≤ ε_col，且任何时刻可执行安全释放 a_release ∈ 𝒜_task 使接触力在 τ_rel 内降到 0。SFE 的目标不是制造事故，而是**可控地逼近边界**（incipient slip，不进入不可恢复的掉落）。

**定义 319（标签溯源与标定 LPC）** 标签 ℓ = (mode, confidence, calib_id, ts, sensor_hash)。标定门：ECE(ℓ) ≤ τ_lab 才计入覆盖，否则降级为「未标定」，只作诊断。标注泄漏检查：标注者可见的结果变量与标签的互信息 I(outcome; ℓ) 超过阈值 ⇒ 疑似标注-结果混淆，该批次不计覆盖。

**定义 320（数据溯源与反通胀 DPA）** 对每个数据批次 b：出处签名、独立性（同一演示者/同一仿真种子/同一上游视为相关）、物理可行性（是否满足力闭合/摩擦锥/准静态一致性）、近重复率、held-out regime 表现。**覆盖通胀**定义为：ΔCov > 0 但 ΔRisk_heldout ≥ 0。触发即冻结该来源并复审。

**定义 321（运行时↔数据桥 RSB）** 运行时的支撑缺失/未消解痕迹形成采集请求队列 Q。因 Q 来自「疑惑分布」π_q ≠ 部署分布 p_dep，桥接使用重要性权重 w = p_dep(r)/π_q(r) 并裁剪，且强制探索配额（每个 τ 至少 π_min 的采集概率），防止自我实现的窄化。桥接只改请求权重，不改变实时控制。

**定义 322（覆盖-风险界）** 在 A99–A101 下，对 regime r 的期望任务风险满足
Risk(r) ≤ Risk_D(r) + L_ℛ·ρ_D(r) + L_θ·U_param(r) + L_ℓ·ECE_lab + δ_gap·U_support(r)。
即风险 = 经验风险 + 覆盖半径外推 + 参数不可辨识 + 标签标定 + 支撑缺口；δ_gap > 0 是**不可被交互消除**的下界（引理 19 的定量形式）。

**定义 323（数据预算与边际价值）** 总预算 B_data（人力/磨损/仿真/时间）。停止条件：max_c V(c) ≤ 0，或 DPA 报告来源饱和，或 held-out 边际改进 < τ_marg。数据预算与 R69 的交互预算分开记账——**花在问上的钱不能算作为学而花的钱**。

**定义 324（证书 J_FORGE）** J_FORGE = (J_FLUID, ccc_hash, C^succ, C^∂F, U_support, U_param, label_ece, provenance_root, inflation_flag, heldout_regimes, forge_ver)。Valid ⇔ Valid(J_FLUID) ∧ 当前 regime 在认证覆盖内 ∧ 标签标定达标 ∧ 无覆盖通胀 ∧ held-out 不退化为零。

**定义 325（严格退化边界）** 当数据集对当前 regime 的覆盖为 1（U_support=0）、参数可辨识（U_param ≤ τ_p）、标签已标定（ECE=0）时，FORGE 每一步与 R69 逐指令相同。R69 = FORGE 在「支撑完备」边界上的退化；支撑缺失时只会更保守，绝不更激进。

**定义 326（接触参数的跨域迁移）** 源域 s、目标域 t 的接触参数 θ_s, θ_t。可迁移性 = 1 − d_ℛ(θ_s, θ_t)/D_cap，且仅当目标域参数落在源域认证支撑内；否则「迁移」必须降级为「保守鲁棒控制 + 目标域采集」。这把 sim-to-real 从「策略迁移」改写为「**参数支撑迁移**」——不是模型像不像，而是参数在不在。

**定义 327（负空间评估）** held-out 评估集必须按 τ/φ 分层，并**强制包含失败边界样本**（真实系统无法安全产生时，用经认证的高保真仿真 + 物理一致性检查）。禁止用训练同分布的 held-out 充当覆盖证明（定义 320 的负对照）。

**定义 328（灵巧操作干扰集 AIC-DEX）** ℰ_DEX = ℰ_FLUID × ℰ_data，ℰ_data 包含：成功偏置（只采成功）、覆盖通胀（重复/近重复）、标签投毒（失败标成功）、物理不可行合成、演示者同源伪装、边界样本被安全过滤悄悄剔除。

**定义 329（参与式数据审计 VQAuditor-D）** 审计对象从交互决策扩展到数据决策：采了什么 regime、为什么采、标签是否标定、边界覆盖是否真实、held-out 是否被污染。结论回灌 AuditBuf，成为下一轮 DCG 的成本/价值先验，并公开为数据证书的一部分。

# IP-264 CRM：接触 regime 本体与嵌入
class ContactRegimeCatalogue:
    def encode(self, obs, tactile, proprio):
        tau   = contact_graph(tactile, proprio)        # 接触拓扑
        phase = phase_classifier(tactile, proprio)     # make/stick/slip/break
        theta = param_estimator(obs, tactile)          # mu, mass, compliance + cov
        return Regime(tau, phase, theta, env=obs.env)

    def dist(self, r, r2):
        return (w_tau*ged(r.tau, r2.tau) + w_phi*(r.phase != r2.phase)
                + w_th*(r.theta - r2.theta).mahalanobis() + w_e*d_env(r, r2))

# IP-265 CCC：双通道、分层的覆盖证书
class CoverageCertificate:
    def build(self, D, catalogue, eps):
        D = [d for d in D if d.label.calibrated and feasible(d)]   # 标定门 + 可行性门
        per_tau = {}
        for tau in catalogue.topologies():
            succ = fraction(D, tau, region='success', eps=eps)
            bnd  = fraction(D, tau, region='boundary', eps=eps)     # 失败边界
            per_tau[tau] = (succ, bnd)
        return CCC(per_tau=per_tau, sampler_sig=..., label_ece=...,
                   provenance_root=merkle(D))

    def support(self, r):                 # 局部可信度 c_D(r)
        return min over tau/phase of local_density(r) normalized

    def coverage(self, region):           # 分层，不允许总覆盖掩盖零覆盖拓扑
        return {tau: per_tau[tau][region] for tau in per_tau}

# IP-266 SUD：把 R69 的 U_epi 拆成 mode / support / param
def decompose_epistemic(ccc, r, posterior, fisher):
    u_mode    = entropy(posterior) if ccc.support(r) >= 1 else 0.0
    u_support = 1.0 - ccc.support(r)
    u_param   = 1.0 / sqrt(max(det(fisher), 1e-12))
    return u_mode, u_support, u_param

# IP-267 DCG：缺口驱动的采集（子模 + 成本 + 近重复惩罚）
def select_collection(D, ccc, requests, budget):
    best = None
    for c in candidate_collections(ccc.gaps(), requests):      # 含边界采集模式
        if not budget.allow(c) or not safe_envelope(c): continue
        gain = risk_weighted_coverage_gain(D, c) + lam_v*runtime_voi_gain(requests, c)

## 3. 推导

**引理 19（支撑缺失的交互不可约性）** 设当前 regime r 满足 ρ_D(r) > ε_max（在认证支撑外）。对任意交互策略（含 R69 的 MINT/CIA，任意多次提问/注视/探针），存在一个与训练数据在 r 上一致、但在 r 的 ε-邻域内动力学不同的物理假设 θ*，使其后验不可被观测区分（训练分布对 r 邻域无约束，似然在 θ* 上不变）。因此最坏情况下 Risk(r) ≥ δ_gap > 0，且**不随交互次数下降**。系：R69 的「问」只能降低 U_mode，不能降低 U_support；把 U_support 当成 U_epi 去问，是在花安全预算买一个数学上不存在的保证。

**引理 20（失败边界的信息集中）** 在单点接触 + 库仑摩擦的局部模型下，对摩擦系数 μ 的 Fisher 信息 J_μμ ∝ (∂|f_t|/∂μ)²/σ²。当接触严格处于粘着、|f_t| < μf_n 且无相对滑动时 ∂|f_t|/∂μ = 0；当 |f_t| → μf_n 或出现 incipient slip 时，|f_t| 对 μ 的敏感度随边界接近而增大，J_μμ ≥ c·(1 − margin/ε_b)²/σ²。故 μ 的可辨识信息**集中在 ∂F 的 ε_b-带**；成功内部数据的信息随 margin 增大而二次衰减。系：只采成功的灵巧操作数据集，对摩擦锥几乎零信息。

**引理 21（风险加权覆盖的子模性与贪心界）** 设采集的边际覆盖增益 ΔCov_weighted 在集合函数意义下子模、单调，成本为基数约束，则贪心 DCG 达到 (1−1/e)·OPT 的加权覆盖。但覆盖最优 ≠ 风险最优：若权重 w(r) 漏掉 ∂F 带，子模性仍成立而风险不变——**子模性保证的是「覆盖指标」，不是「能力」**，故必须把 ∂F 权重显式写进测度（定义 316）。

**引理 22（覆盖通胀攻击的存在性与检测代价）** 在允许重复/重标/不可行合成的通道下，攻击者可用 k 份近重复成功样本使报告覆盖 C^succ 任意接近 1，而 held-out 风险不变（甚至上升）。任何仅依赖 D 内部密度的覆盖证书都可被欺骗；因此证书必须包含 (a) held-out regime 表现、(b) 物理可行性、(c) 出处独立性、(d) 负对照，四者缺一不可。检测代价至少 O(|held-out|) 的真实评估，不能仅由训练侧统计替代。

**定理 18（FORGE 严格包含 R69）** 在 A99–A101 下，FORGE 的运行时策略在任意状态上的期望风险 ≤ R69；且当 U_support=0、U_param ≤ τ_p、标签已标定时，两者**逐指令相同**（定义 325）。支撑缺失时 FORGE 仅更保守（进入 R68 退避），绝不更激进。因此 R69 = FORGE 在「支撑完备 + 参数可辨识」边界上的退化。

**定理 19（安全失败采集的风险-信息权衡）** 在定义 318 的 abort 包络与力/位上限下，边界采集的物理风险 ≤ ε_col；同时由引理 20，采集得到的 μ 后验方差满足 Var(μ | D∪D_∂F) ≤ Var(μ | D)·(1 − c·n_bnd/(n_bnd + n_0))。即存在预算-风险-信息的三方 Pareto 前沿：边界采得越多，μ 越可辨识、成功区越稳，但磨损与越界风险单调上升。**最优采集点不在「零失败」，而在「可恢复的临界」**。

**定理 20（未标定标签下的覆盖虚高）** 设标签误差为系统性偏置 b（如把 near-slip 标成 stick），则认证覆盖 C_ε 被高估至少 Ω(b·μ(∂F))（边界带是误差最敏感区），而基于该覆盖的运行时风险界（定义 322）失效：真实风险可超过证书上界 L_ℓ·ECE_lab 的线性项。故 LPC 的标定门不是工程细节，而是证书有效性的前提。

## 6. 本轮最大风险

**定义 327–329（评估、干扰、审计）** held-out 必须按 τ/φ 分层且强制含 ∂F 样本；ℰ_DEX 覆盖成功偏置/覆盖通胀/标签投毒/不可行合成/同源伪装/边界样本被过滤；VQAuditor-D 审计数据决策并回灌 DCG 先验。

## 4. 推导

**引理 19（支撑缺失的交互不可约性）** 若 `ρ_D(r)>ε_max`，则存在与训练数据一致、但在 r 邻域动力学不同的物理假设 θ*，其似然在 r 上不可区分；故 `Risk(r) ≥ δ_gap>0` 且**不随交互次数下降**。系：`U_support` 不能当 `U_epi` 去问；问了也白问，还花掉安全预算。

**引理 20（失败边界的信息集中）** 单点接触库仑摩擦下 `J_μμ ∝ (∂|f_t|/∂μ)²/σ²`；粘着且 `|f_t|<μf_n` 且无滑移时为零；越接近 `|f_t|=μf_n` 或 incipient slip，`J_μμ` 越大。故 μ 的信息集中在 `∂F` 的 ε-带，成功内部数据信息随 margin 二次衰减——**只采成功的数据集对摩擦锥近乎零信息**。

**引理 21（子模贪心界）** 风险/边界加权覆盖增益子模且单调 ⇒ 贪心 DCG 达 `(1−1/e)OPT`。但覆盖最优 ≠ 风险最优：权重漏掉 `∂F` 时子模性仍成立而风险不变，故 ∂F 权重必须显式入测度。

**引理 22（覆盖通胀）** 重复/重标/不可行合成可把 `C^succ` 刷到任意接近 1 而 held-out 风险不降。任何只看 D 内部密度的证书都可被欺骗；必须同时有 held-out、可行性、出处独立性、负对照四门，检测代价至少 `O(|held-out|)`。

**定理 18（FORGE 严格包含 R69）** A99–A101 下，FORGE 任意状态期望风险 ≤ R69；且 `U_support=0 ∧ U_param≤τ_p ∧ 标签已标定` 时逐指令相同。支撑缺失只会更保守。R69 = 「支撑完备 + 参数可辨识」边界上的退化。

**定理 19（安全失败采集权衡）** abort 包络内采集风险 ≤ ε_col；且 `Var(μ|D∪D_∂F) ≤ Var(μ|D)(1 − c·n_bnd/(n_bnd+n_0))`。存在预算-风险-信息 Pareto 前沿：**最优采集点不在零失败，而在可恢复的临界**。

**定理 20（未标定标签的覆盖虚高）** 系统性标签偏置 b（near-slip→stick）使认证覆盖至少高估 `Ω(b·μ(∂F))`，且定义 322 的风险界失效——LPC 标定门是证书有效性的前提，不是工程细节。

## 7. 本轮最大风险

**一句话**：FORGE 的全部安全性继承自「覆盖证书真的刻画了支撑」——若 `d_ℛ` 把手感相近、动力学迥异的两种接触判成邻居，或标签因标定漂移把 near-slip 记成 stick，或失败边界被「成功偏置」悄悄漏掉，证书就会**高估覆盖**，系统便带着「我学过这个」的错觉进入从未真正经历的接触 regime——**「我们有数据」比「我们没数据」更危险，因为它取消了保守退避**。

**次级风险与缓解**：覆盖通胀/Goodhart（DPA 四门 + 引理 22）；边界采集不安全（SFE abort 包络 + 定理 19）；标签不可信（LPC 标定门 + 定理 20）；疑惑分布导致窄化（RSB 的 IPW + π_min + E314）；参数不可辨识被误当噪声（激励预算 + U_param 鲁棒缩放，绝不把「没激励」当「没参数」）。
