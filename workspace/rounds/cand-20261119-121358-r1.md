# 第 2 轮（UniBot 线 · 续轮；本轮灵感：「消融实验」×「状态隔离」）

> **承接声明**：不推翻第 1 轮 UniBot-SAGE 的三层栈（接地 / 技能 / 适应）+ 工程层；本轮把研究重心从"再加机制"转为"证明哪些机制在真实预算下可被识别"。第 1 轮的 U1–U12 / L1–L7 / E601–E618 保留为**候选机制库与待检验主张**；本轮新增 U13–U22、L8–L14、E619–E640。第 1 轮那种"+1.5 / +2.5 分"的表述，本轮一律降级为**待识别假设**，不再当作已知收益。

## 0. 一句话立场

上一轮我们生产了 8 个创新点；这一轮真正的问题是：**在只有几十到几百个真机 episode、成功率是伯努利、且多端口共享后端的情况下，我们凭什么说某个模块有用？** 两个灵感词不是两个新功能，而是一对"方法 × 基础设施"：**消融实验是科学方法，状态隔离是它的效度条件。**

## 1. 直觉解释（先建立画面，再进入定义）

### 1.1 「消融实验」的直觉：不是"删掉看看"，而是"在噪声和混杂里做减法"

**调音台的类比**：一个乐队听起来好听，不代表每个效果器都有用。要判断某个效果器，不能只拔掉它再听一遍——房间混响、乐手状态、你的耳朵都在变。正确做法是：同一段录音、同一副耳机、同一组随机种子，做**配对**比较；而且拔掉一个效果器时，其他效果器的增益不能跟着变。这就是消融。

**临床试验的类比**：如果新药组比对照组多吃了维生素、多住了几天院、医生更关注，那么"新药有效"就无法归因。机器人消融有三个对应的混杂：

1. **容量混杂**：关掉一个模块后参数变少，掉点可能只是"模型变小了"；需要参数 / 算力匹配的**安慰剂臂**。
2. **交互混杂**：关掉 A 会改变 B 的触发条件；一次只关一个因子的 OFAT 设计无法估计交互，甚至在存在交互时给出错误的主效应。
3. **噪声**：终态成功是 0/1，真机时段稀缺；小效应的置信区间往往比效应本身还大。

**先建立量级感**：设基线成功率 `p=0.25`，做两臂比较，`α=0.05`、功效 `0.8`。用正态近似，每臂所需 episode 数

`n ≈ (1.96+0.8416)² · [p1(1−p1)+p0(1−p0)] / δ²`。

`δ=2.5` 个百分点 → **n≈4859/臂**；`δ=5pp` → **≈1250/臂**；`δ=8pp` → **≈500/臂**；`δ=10pp` → **≈326/臂**。若 32 个任务全测、两臂，总 episode 分别约为 **31 万、8 万、3.2 万、2.1 万**。**结论：第 1 轮里 +1.5~+2.5 分的改进，在真实机器人预算下基本不可识别。** 这不是说它们一定无效，而是说"用终态成功率做一次 A/B"永远证明不了。

**出路不是更用力地做 A/B，而是把测量点前移**：抓握相位成功率、对齐误差、插入深度、重抓次数这些**相位级连续端点**方差小得多；在 `Δ=0.2σ` 时每臂约 392 个样本，`Δ=0.5σ` 时约 63 个样本。用它们做筛选，用终态成功做最终确认。**消融的对象不是"整个策略"，而是"机制到终点的那条因果链"。**

### 1.2 「状态隔离」的直觉：不是"每端口一个字典"，而是"实验单元的防火墙"

**临床试验污染的类比**：如果对照组不小心吃到了新药，试验就废了。多端口共享后端时，"对照臂吃到处理臂的状态"就是同一件事。第 1 轮把 `sessions[port]` 当作隔离，这只覆盖了显式的 episode 状态；真正会泄漏的还有：

- 每端口共享的 RNG 流（关掉模块 A 会移动模块 B 的随机数）；
- 模型内部的 KV / cache、batch-norm / 统计量、LoRA 适配器；
- chunk 游标、相位状态机、重抓计数器、上下文缓冲；
- CUDA stream / 线程池 / 批处理队列造成的**时序耦合**（B 端口的慢请求拖慢 A 端口）；
- 日志 / 审计的交错写入与全局计时器。

**为什么把这件事提到"研究"层面**：因果推断里有一个基本假设叫 **SUTVA**（稳定单元处置值假设：单元之间无干扰、潜在结果良定义）。在多端口部署里，端口就是单元，消融臂就是处置。**状态隔离就是 SUTVA 的工程实现**。没有它，"A 臂比 B 臂好"可能只是因为 A 臂偷到了 B 臂的缓存，或者因为 A 臂跑在更空的 GPU 上。

**最隐蔽的一点：随机数也必须隔离。** 配对消融要求两个臂看到"同一个场景 + 同一串噪声"，否则比较的是"机制差异 + 噪声实现差异"。如果所有模块共用一个 RNG，关闭模块 A 会让模块 B 抽到不同的随机数，配对相关性 `ρ` 下降，方差反而变大。正确做法是 **counter-based RNG + 每模块 / 每端口 / 每 episode 独立流**（key = port, episode, module, step），这样开关一个模块不会改变其他模块的随机数。**状态隔离不是工程洁癖，它是配对消融能够成立的前提。**

## 2. 严谨定义

**定义 U13（会话可变状态）** 对端口 p、episode e，隐藏可变状态

`H_{p,e} = (sess_id, epoch, {RNG_m}_{m∈M}, chunk_cursor, chunk_history, phase_state, retry_counter, context_buffer, adapter_params, cache_slots, latency_state, audit_cursor)`。

共享模型权重 `θ` 是**只读**的，不属于 `H`。

**定义 U14（状态隔离 / 非干扰）** 对任意 `p≠q`、任意时刻 `t`，

`A_p(t) ⟂ H_{q,·}(t) | (O_p(0:t), θ)`，等价于 `I(A_p(t); H_{q,·}(t) | O_p(0:t), θ) = 0`；

且 `reset(p)` 后 `H_{p,·}=H_0`，而 `H_{q,·}` 与 `θ` 不变。时序版本：`F(L_p | load_q) = F(L_p)`（p 的延迟分布不随 q 的负载变化）。

**定义 U15（隔离级别）**

- **I0** 全局单例（不安全）；
- **I1** 每端口 session 字典；
- **I2** = I1 + 每 episode 重置全部可变状态（官方接口的最低要求）；
- **I3** = I2 + 每端口 / 每模块独立 RNG + 权重只读 + 无跨端口缓存 + 确定性算子 + 无队头阻塞；
- **I4** = I3 + 全状态快照 / 恢复 / 克隆（支持反事实分支与离线回放）。

提交需 `≥I2`；**实验数据必须来自 `≥I3`**；离线反事实需要 I4。

**定义 U16（开关向量与臂）** 开关向量 `x∈{0,1}^k`，臂 `π_x`。每个因子 j 必须定义**位精确的关闭语义**：`π_{x:x_j=0}` 走的代码路径与第 1 轮冻结基线完全一致（不是"跳过后处理"，而是调用同一条基线路径）。关闭不改变其他模块的 RNG 与状态。

**定义 U17（消融估计量）** 在 SUTVA、正性、一致性下，

`ATE_j = E[Y | do(x_j=1), x_{-j}~P] − E[Y | do(x_j=0), x_{-j}~P]`。

主效应在因子设计中对 `x_{-j}` 边缘化；交互效应报告 `ATE_j(x_{-j})`。**所有估计量在实验前预注册。**

**定义 U18（SUTVA / 无干扰）** 对臂 `a,b` 与 episode 单元 `u`，潜在结果 `Y_u(a)` 良定义，且 `Y_u(a)` 不依赖其他单元的处置分配。U14 是它在部署系统中的实现；随机数流隔离是它在配对设计中的实现。

**定义 U19（配对潜在结果）** 同一场景种子 `s` 下 `(Y_s(1), Y_s(0))`，配对差 `δ_s=Y_s(1)−Y_s(0)`；McNemar 检验基于不一致对 `(n10,n01)`。配对的前提是两臂共享场景与噪声流（见 U14 的随机数版本）。

**定义 U20（替代端点与中介）** 相位级端点 `M_j`（抓握成功、对齐误差、插入深度、恢复次数）。`M_j` 可作为有效替代端点，需同时满足：处置影响 `M_j`、`M_j` 影响终态 `Y`、且给定 `M_j` 后处置对 `Y` 的剩余效应可忽略。否则只能作为机制检查，不能作为"涨点"结论的依据。

**定义 U21（隔离证书）** `Cert_iso(p) ∈ {0,1}`，由五项测试的 AND 给出：静态状态清单完整、运行时 canary 零命中、串行 / 并行位等价、reset 不变性、跨 episode 清理。`Cert_iso=0` 的端口禁止进入任何消融实验。

**定义 U22（信息预算）** 给定机器人时段 `B`（episodes）与端点方差 `σ_e²`，实验信息量 `I(B)=Σ_e w_e (δ_e/σ_e)²`；设计目标是 `argmax I(B)`，约束为成本 `≤B`、`Cert_iso=1`、预注册固定。评价实验设计的唯一指标是**每机器人小时可识别的效应量**，不是"跑了多少组"。

## 3. 本轮研究问题

- **Q6（可识别性）**：在真实预算下，第 1 轮 8 个 IP 中哪些效应可被识别？最小可检测效应（MDE）分别是多少？哪些只能作为"机制正确性"主张、不能作为"涨点"主张？
- **Q7（干扰与泄漏）**：多端口共享后端在什么条件下违反 SUTVA？canary / 位等价测试能否给出可审计的隔离证书？泄漏率 `ε` 与效应估计偏差的定量关系是什么？
- **Q8（可消融的构造）**：怎样把每个机制设计成"可位精确旁路、可影子运行、可参数匹配"的对象？哪些机制天然不可消融（例如与相位强耦合的重抓）？
- **Q9（合规的代价）**：若禁止跨 episode 在线更新（因为它破坏隔离与 SUTVA），第 1 轮 IP-04 还剩多少收益？episode 内适配是否足够？
- **Q10（替代端点）**：哪些相位级端点可作为终态成功的有效替代 / 中介？在有限真机锚点上，替代端点的校准误差如何传播到最终结论？

## 4. 设计原则（在 P1–P6 之上新增）

- **P7 可消融性是一等公民**：每个机制必须有 bypass、no-op 等价测试、影子模式；不能旁路的机制不允许进主线。
- **P8 先预注册后实验**：估计量、样本量、停止规则、主要 / 次要端点、失败处置全部实验前写死并哈希存档。
- **P9 隔离先于优化**：未通过 I3 证书的后端不产生任何可用于结论的数据；隔离失败是熔断，不是降级。
- **P10 测量前移**：优先用方差小的相位级 / 连续端点做筛选，终态成功只做最终确认。
- **P11 因子设计而非一次一因子**：默认 `2^(k−p)` 筛选，必要时用 D-optimal 增量补点；控制族错误率。
- **P12 阴性结果与安慰剂对照**：至少一个"应当无效"的负对照臂与一个参数 / 算力匹配的安慰剂臂；阴性结果进入台账，防止重复踩坑。

## 5. 方案骨架：UniBot-SAGE-ID

保留第 1 轮三层栈作为**候选机制库**，新增两层：

```
第 1 轮：接地层（IP-02） → 技能层（IP-01） → 适应层（IP-04） → 工程层（IP-03）
本轮新增：
  识别层  ABLATE（因子设计 / 配对 / 序贯 / 层级模型 / 预注册） + MEDIATE（替代端点）
  隔离层  ISOLATE（I0–I4 / 证书 / canary / RNG 流） + SWITCHBOARD（开关格 / 旁路契约 / 影子模式）
```

顺序固定为：**先隔离 → 再开关 → 再测量 → 再归因 → 最后才提交**。任何"跳过隔离直接跑消融"的实验，其结果不进入决策。

## 6. MVP 与退化链

**MVP = ISOLATE 证书 + SWITCHBOARD（先覆盖 IP-02 / IP-03 两个最高优先级机制）+ ABLATE 的 16-run 分辨度 IV 筛选 + 配对代理评测 + 预注册模板。**

理由：第 1 轮已经把机制选出来了；本轮最小闭环不是再造机制，而是**证明这些机制里哪些值得带上真机**。ISOLATE 与 SWITCHBOARD 是"能开始测量"的前置条件；ABLATE 的 16-run 设计是"用最少的臂估计主效应"的最小设计。

**退化链（熔断优先）**：

- D0 隔离证书失败 ⇒ **熔断**，修复前禁止一切实验（不是降级）。
- D1 canary / 位等价不可用 ⇒ 退回串行单端口实验，牺牲并行度但保留效度。
- D2 配对场景不可复现 ⇒ 退回分层随机 + 增加样本量 + 只识别大效应。
- D3 替代端点不可校准 ⇒ 只保留机制检查，不做涨点结论。
- D4 真机预算不足 ⇒ 只做 ≤2 个因子的确认实验，其余全部转离线 / 代理。
- D5 全部失败 ⇒ 提交第 1 轮基线策略（安全网，永远保留）。

## 7. 预期贡献（可验收）

1. **把消融从"附录"变成"主方法"**：给出具身策略可识别性的形式化框架（SUTVA + 因子设计 + 替代端点 + 隔离证书），并给出真实预算下的 MDE 表。
2. **首次把随机数流隔离作为配对消融的必要条件**：给出"泄漏率 → 偏差上界"（L10）与 canary 探测样本量（L14）。
3. **给出可审计的状态隔离级别与认证协议**：I0–I4 + 五项测试，直接对齐官方"多端口 / 状态隔离 / 可信度"要求。
4. **给出第 1 轮 8 个 IP 的可识别性排序**：哪些能用真实预算识别，哪些只能作为机制正确性主张。
5. **给出 episode-local adaptation 的合规代价**：用"跨 episode 更新 vs 每 episode 回滚"的对照，决定 IP-04 的最终形态。

## 8. 下一轮迭代计划

- **优先**：用 ISOLATE 证书把本地评测后端跑到 I3；把 IP-02 / IP-03 做成可位精确旁路的 SWITCHBOARD 模块。
- **然后**：在代理评测上跑 16-run 筛选 + 安慰剂 / 负对照，估计主效应与交互；用序贯分析决定是否值得上真机。
- **修剪预案**：若 16-run 中某因子的 95% 区间跨 0 且其机制端点也无变化，则**冻结该因子**，不再投入真机时段；若代理端点与终态成功的相关性 `|r|<0.3`（沿用第 1 轮 E601 的门槛），则所有基于代理端点的结论降级为"机制检查"，只保留隔离层与配对终态确认。
- **保留项**：ISOLATE、SWITCHBOARD、ABLATE 的预注册与序贯分析在任何情况下不砍——它们是后续所有轮次的基础设施。

## 9. 本轮最大风险（结尾一句话）

**一句话**：把研究重心转到"可识别性"之后，最大的风险是**统计功效与代理效度的双重不足**——真实预算只够识别大效应，而真正正确的改进往往是小效应，于是严谨的消融会系统性杀掉微弱但真实的收益，最后交出一个可解释却平庸的系统；更糟的是，我们只能隔离自己的后端，无法隔离官方评测端的 chunk / reset / 端口调度语义。

# 第 2 轮产物 · 可识别性工程 v1：UniBot-SAGE-ID

> 本产物承接第 1 轮 UniBot-SAGE；不重复第 1 轮的机制细节，只给出本轮新增的"识别层 + 隔离层"完整规格。编号续用：U13–U22、L8–L14、E619–E640。榜单与接口事实沿用第 1 轮 §10 的来源清单（检索日期 2026-11-17）；本轮为方法论轮，不新增未核实的赛事数字。

## 0. 结论摘要

- 第 1 轮的 8 个 IP 是**候选机制**，不是**已证收益**。在 `p≈0.25`、`α=0.05`、`power=0.8` 下，2.5pp 的终态效应需要约 **4859 eps/臂**；真实预算下不可识别。
- 本轮把"消融"做成子系统：**ABLATE**（预注册 + 因子设计 + 配对 + 层级模型 + 序贯停止）与 **MEDIATE**（相位级替代端点）。
- 把"状态隔离"做成可认证的基础设施：**ISOLATE**（I0–I4 + 五项测试 + canary）与 **SWITCHBOARD**（位精确旁路 + 影子模式 + 参数匹配）。
- 核心因果假设：**状态隔离 = SUTVA 的工程实现**；**RNG 流隔离 = 配对消融的共同随机数**。
- 对第 1 轮的直接修正：IP-04 的跨 episode 在线更新默认**禁用**（违反 I2/I3 与 SUTVA），改为 episode-local；IP-01 的 MoE 先做单专家降级形态的可识别性检验；IP-03 的优化目标从"提分"改为"边界 jerk 与失败率"双端点。

## 1. 创新点清单（IP-09–IP-14）

| 编号 | 名称 | 优先级 | 一句话 | 依赖 | 可验收指标 |
|---|---|---|---|---|---|
| **IP-09** | **ABLATE** 预注册消融引擎 | **P0** | 把"关掉看看"升级为因子设计 + 配对 + 层级模型 + 序贯停止的可识别实验 | 无（纯软件） | 预注册可复现；16-run 主效应区间可计算；假阳性率 ≤5% |

## 3. 定义（U13–U22）

### U13 会话可变状态

`H_{p,e} = (sess_id, epoch, {RNG_m}_{m∈M}, chunk_cursor, chunk_history, phase_state, retry_counter, context_buffer, adapter_params, cache_slots, latency_state, audit_cursor)`。

`θ`（模型权重）只读，不属于 `H`。每次 `reset(p)` 后 `H_{p,e}=H_0`。

### U14 状态隔离 / 非干扰

`A_p(t) ⟂ H_{q,·}(t) | (O_p(0:t), θ)`，即 `I(A_p(t); H_{q,·}(t) | O_p(0:t), θ)=0`；`reset(p)` 不影响 `H_{q,·}` 与 `θ`。时序版本：`F(L_p | load_q)=F(L_p)`。

### U15 隔离级别

| 级别 | 内容 | 用途 |
|---|---|---|
| I0 | 全局单例 | 禁止 |
| I1 | 每端口 session | 仅能跑通 |
| I2 | I1 + 每 episode 重置 | 官方提交最低线 |
| I3 | I2 + 独立 RNG + 只读权重 + 无跨端口缓存 + 确定性算子 + 无队头阻塞 | **实验数据最低线** |
| I4 | I3 + 快照 / 恢复 / 克隆 | 离线反事实 |

### U16 开关向量与臂

`x∈{0,1}^k`，`π_x`。`x_j=0` 必须调用与冻结 v1 完全相同的代码路径；不得只跳过某段后处理。关闭不改变其他模块的 RNG / 状态。

### U17 消融估计量

`ATE_j = E[Y | do(x_j=1), x_{-j}~P] − E[Y | do(x_j=0), x_{-j}~P]`。主效应对其他因子边缘化；交互效应报告 `ATE_j(x_{-j})`。

### U18 SUTVA

单元（episode / 端口 / 臂）之间无干扰，潜在结果良定义。U14 是其工程实现。

### U19 配对潜在结果

同场景种子 `s` 下 `(Y_s(1),Y_s(0))`；McNemar 基于不一致对 `(n10,n01)`。配对要求共享场景与 RNG 流。

### U20 替代端点

`M_j` 成为有效替代端点需满足：处置影响 `M_j`、`M_j` 影响 `Y`、给定 `M_j` 后处置的剩余效应可忽略。否则只作机制检查。

### U21 隔离证书

`Cert_iso(p)` = 静态清单 ∧ canary 零命中 ∧ 串并行位等价 ∧ reset 不变性 ∧ 跨 episode 清理。

### U22 信息预算

`I(B)=Σ_e w_e(δ_e/σ_e)²`；在成本 `≤B`、`Cert_iso=1`、预注册固定下最大化。评价指标：每机器人小时可识别效应量。

## 4. 引理与命题（L8–L14）

### L8（伯努利终点的样本量下界）

两臂单任务比较，基线 `p0`、处置 `p1`、`δ=|p1−p0|`：

`n ≥ (z_{1−α/2}+z_{1−β})² · [p1(1−p1)+p0(1−p0)] / δ²`。

取 `p0=0.25, α=0.05, 1−β=0.8`：

| 终态效应 δ | n/臂 | 32 任务两臂总 episode |
|---|---|---|
| 2.5pp | 4859 | ≈31.1 万 |
| 5pp | 1248 | ≈8.0 万 |
| 8pp | 501 | ≈3.2 万 |
| 10pp | 326 | ≈2.1 万 |

连续端点（等方差、两样本）：

`n = 2(z_{1−α/2}+z_{1−β})²(σ/Δ)²`。

`Δ=0.2σ → n≈392/臂`；`Δ=0.5σ → n≈63/臂`。⇒ **相位级端点比 2.5pp 终态效应便宜 1~2 个数量级**。第 1 轮的 +1.5~+2.5 分声明在真机上应视为不可识别，除非配对 + 替代端点同时成立。

### L9（配对与共同随机数的方差缩减）

设同场景两臂结果相关系数 `ρ`，则 `Var(Y1−Y0)=2p(1−p)(1−ρ)`（等 `p` 近似），相对非配对减少因子 `(1−ρ)`。`ρ≈0.5` 时样本量约减半；`ρ≈0.8` 时约降至 1/5。但若所有模块共用一个 RNG，关闭模块 A 会移动模块 B 的随机数，`ρ` 反而下降。⇒ **RNG 流隔离是配对消融的前提，不是可选优化。**

### L10（状态泄漏对效应估计的偏差上界）

设污染矩阵 `C`（行随机）使 `μ_obs = C μ_true`，则

`|μ_obs,a − μ_true,a| = |Σ_b c_ab(μ_b−μ_a)| ≤ (1−c_aa)·max_b|μ_b−μ_a| ≤ 1−c_aa`。

要在 `δ=2.5pp` 的效应上把偏差压到 `δ/4=0.625pp`，需 `c_aa ≥ 0.99375`，即跨臂状态接触率 `ε ≤ 0.625%`。这解释了为什么"每端口一个 dict"不够：任何共享 RNG / 缓存 / adapter 都可能把 `ε` 推到 1% 量级，从而让 2.5pp 的效应完全不可信。

### L11（因子设计的别名与可识别性）

`2^{6−2}=16` run，取 `E=ABC, F=BCD`，定义关系 `I=ABCE=BCDF=ADEF`，分辨度 IV。主效应与二因子交互不混叠（主效应只与 3FI/5FI 混叠），但二因子交互彼此混叠：

`AB=CE`，`AC=BE`，`AD=EF`，`AE=BC=DF`，`BD=CF`，`BF=CD`。

**重要修正**：分辨度 IV 的设计做简单 foldover **不能**分离 2FI——因为定义词都是偶数字长，全因子反号后定义关系不变。要分离 2FI，应使用 **D-optimal 增量补点**（在 16-run 基础上加 16 个最优点），或直接跑 `2^{6−1}`（`I=ABCDEF`，分辨度 VI，32 run）。**OFAT（一次一因子）无法估计交互，在有交互时主效应也有偏。**

### L12（安慰剂 / 容量对照的必要性）

若处置臂比对照臂多 `Δparams` 参数或 `ΔFLOPs`，观测效应 = 机制效应 + 容量 / 算力效应 + 期望效应。必须加入参数 / 算力匹配的安慰剂臂（同容量、随机或冻结特征），否则"关掉模块变差"可能只是"模型变小了"。

### L13（episode-local 适配的合规代价）

若策略对适配器参数是 `L`-Lipschitz，且每 episode 适配位移 `≤ρ`，则 episode-local 每轮回到 `θ_ada^0`，位移上界为 `ρ`；跨 episode 无界更新最多累积 `T·ρ`（`T` 为 episode 数）。在线性近似下，episode-local 可获得的收益最多是跨 episode 的 `1/T`；但跨 episode 更新破坏 I3 与 SUTVA，且其收益本身无法在隔离实验中归因。**决策规则**：报告 `R_local = Δ_local / Δ_cross`；若 `R_local ≥ 0.7`，直接选择 episode-local，放弃跨 episode 更新。

### L14（隔离测试的统计判据）

若泄漏率为 `ε`，做 `m` 次独立 canary 探测，零命中概率 `(1−ε)^m`。要以 95% 置信宣称 `ε≤ε_0`，需

`m ≥ ln(0.05)/ln(1−ε_0) ≈ 3/ε_0`（`ε_0≪1`）。

L10 要求 `ε_0=0.625%` ⇒ `m≈478`。**"跑一次没炸"不等于隔离；每配置至少 500 次对抗性探测。**

### 5.1 ISOLATE：状态清单、canary、证书

```python
READONLY, PER_PORT, PER_EPISODE = "RO", "PORT", "EPI"
MODULES = ("base", "ip01", "ip02", "ip03", "ip03b", "ip04", "ip05")

class SessionState:
    def __init__(self, port, episode, seed_key):
        self.port, self.episode = port, episode
        self.epoch = 0
        self.canary = h128(f"{port}|{episode}|{seed_key}")
        self.fields = {
            # counter-based：draw 只依赖 key 与 step，不依赖全局状态
            "rng": {m: CounterRNG(key=(port, episode, m, seed_key)) for m in MODULES},
            "chunk_cursor": 0,
            "chunk_history": deque(maxlen=8),
            "phase_state": PhaseState(),
            "retry_counter": 0,
            "context_buffer": [],
            "adapter": None,              # 只允许 episode-local
            "cache": LRU(maxsize=4096),
            "latency": LatencyState(),
            "audit": AuditCursor(port, episode),
        }
        for f in self.fields.values():
            tag_canary(f, self.canary)    # 每个可变 buffer 写入本会话 canary

    def reset(self):
        for k, f in self.fields.items():
            reset_field(k, f)
            tag_canary(f, self.canary)
        self.epoch += 1
        assert self.hash() == self.initial_hash()

    def snapshot(self):
        return Snapshot(self.port, self.epoch, deepcopy(self.fields))

    def restore(self, snap):
        assert snap.port == self.port and snap.epoch == self.epoch
        self.fields = deepcopy(snap.fields)


class IsolationGuard:
    def __init__(self, policy): self.policy = policy

    def static_check(self):
        for name, f in walk_fields(self.policy):
            assert getattr(f, "scope", None) in (READONLY, PER_PORT, PER_EPISODE), name

    def canary_scan(self):
        hits = []
        for p, sp in self.policy.sessions.items():
            for q, sq in self.policy.sessions.items():
                if p != q and contains(sq.fields, sp.canary):
                    hits.append((p, q))
        return hits

    def timing_check(self, base_p99, loaded_p99):
        return (loaded_p99 - base_p99) / base_p99 <= 0.10


def certify(policy, ports, probes=500):
    guard = IsolationGuard(policy)
    guard.static_check()
    for _ in range(probes):
        interleave_adversarial(policy, ports)     # 随机延迟 / 并发 reset / 端口复用
        assert guard.canary_scan() == []
    for n in (1, 2, 4, 8, 16):
        assert bit_equal(serial_run(policy, n), parallel_run(policy, n))
    for p in ports:
        before = {q: policy.sessions[q].hash() for q in ports}
        policy.reset(p)
        assert policy.sessions[p].is_initial()
        assert all(policy.sessions[q].hash() == before[q] for q in ports if q != p)
    return Certificate(static=True, canary=True, bit_equal=True,
                       reset=True, cross_episode=True, probes=probes)
```

| 测试 | 覆盖的泄漏通道 | 通过判据 |
|---|---|---|
| 静态清单 | 未标记的可变属性 | 100% 标记为 RO / PORT / EPI |
| canary | 跨端口 buffer / 缓存 / adapter | 500 探测零命中；`ε≤0.625%` |
| 串并行位等价 | 并发、GIL、CUDA stream、批处理 | N=1..16 动作逐位一致 |
| reset 不变性 | 跨 episode 残留 | `H_p=H_0`，`H_q` 哈希不变 |
| 时序隔离 | 队头阻塞 / 批队列耦合 | 满载时 p99 变化 ≤10% |

### 5.2 SWITCHBOARD：位精确旁路、影子模式、RNG 流

```python
class SwitchBoard:
    def __init__(self, baseline, modules):
        self.baseline = baseline          # 冻结的第 1 轮策略
        self.modules = modules

    def act(self, obs, s, arm):
        if not any(arm.enabled.values()):
            # 全关：走与 v1 完全相同的路径，保证 bit-exact
            return self.baseline.act(obs, s)

        x = arm.enabled
        a = self.modules["policy"].act(
            obs, s,
            z_task   = self.maybe("ip01",  x, lambda: self.modules["ip01"].route(obs, s.rng["ip01"])),
            grasp    = self.maybe("ip02",  x, lambda: self.modules["ip02"].verify(obs, s.rng["ip02"])),
            stitch   = self.maybe("ip03",  x, lambda: self.modules["ip03"].stitch(s.chunk_history)),
            chunk    = self.maybe("ip03b", x, lambda: self.modules["ip03b"].length(s.phase_state)),
            context  = self.maybe("ip04",  x, lambda: self.modules["ip04"].encode(obs)),
            pivot    = self.maybe("ip05",  x, lambda: self.modules["ip05"].prior(obs)),
        )

        # 影子模式：计算但不执行；只记录首次干预前的结果
        for name in arm.shadow:
            s.shadow_log[name] = self.modules[name].would_intervene(obs, s)

        return a
```

**位精确旁路的验收**：对 1000 步固定观测序列（覆盖 reach / grasp / insert / release），`arm(all-off)` 与冻结 `baseline` 的 `left_arm / right_arm / gripper / pivot` 必须逐位相等。若不相等，先修 SWITCHBOARD，不允许进入消融。

**RNG 流隔离的验收**：任选一个模块关闭，其他模块在同一 `(port, episode, seed)` 下的随机数序列必须逐位不变。这把"关闭模块"从一个全局扰动变成局部干预。

### 5.4 MEDIATE：替代端点与中介

```python
def surrogate_report(df, treatment, mediators, outcome):
    out = {}
    for m in mediators:
        a = effect(treatment -> m)          # 处置对中介
        b = effect(m -> outcome)            # 中介对终点
        direct = effect(treatment -> outcome | m)
        total = effect(treatment -> outcome)
        out[m] = {
            "a": a, "b": b,
            "proportion_mediated": (total - direct) / total if total else None,
            "r_with_outcome": corr(df[m], df[outcome]),
            "e_value": e_value(total, direct),
        }
    return out
```

**使用纪律**：替代端点只用于**筛选**与**机制检查**；最终"是否提交某模块"的决策仍以终态成功（或官方榜单）为准。若 `|r|<0.5`（沿用第 1 轮 E601），该端点降级为诊断指标，不得用于主效应声明。

### 5.5 EPILOCAL：episode 内适配

```python
class EpisodeLocalAdapter:
    def __init__(self, theta0, rho=0.01, lr=1e-3):
        self.theta0, self.theta = theta0.clone(), theta0.clone()
        self.rho, self.lr = rho, lr

    def on_reset(self):
        self.theta = self.theta0.clone()   # 强制回滚，跨 episode 零状态

    def step(self, loss):
        g = grad(loss, self.theta)
        self.theta = project(self.theta - self.lr * g, self.theta0, self.rho)

    def on_episode_end(self):
        self.theta = self.theta0.clone()
```

**合规代价实验**：同一策略，`Δ_cross` = 允许跨 episode 累积适配；`Δ_local` = 每 episode 回滚。若 `R_local=Δ_local/Δ_cross ≥0.7`，选择 episode-local。若 `R_local<0.7`，仍优先 episode-local，除非组委会书面确认跨 episode 更新合规，并且隔离证书能证明适配器按端口隔离。

- 别名：`AB=CE`、`AC=BE`、`AD=EF`、`AE=BC=DF`、`BD=CF`、`BF=CD`。
- **不要 foldover**（分辨度 IV 的偶数字长定义词使 foldover 保持同一别名结构）；用 D-optimal 加 16 点，或直接跑 32-run `2^{6−1}`（`I=ABCDEF`，分辨度 VI）。
- 区组：按任务族 / 场景 / 机器人 / 日期分层；臂顺序在区组内随机化。
- 配对：同 `scene_seed` + 同 RNG key；若真机无法重置场景，则配对只在离线回放 / 代理上做，真机做非配对确认。

## 8. 功效与预算

| 阶段 | 设计 | n/臂 | 终态 MDE（p=.25） | 能识别什么 |
|---|---|---|---|---|
| 代理筛选 | 16-run × 32 任务 × 50 eps | 1600 | ≈4.3pp | 中效应主因子 |
| 代理确认 | 2 因子 × 32 任务 × 200 eps | 6400 | ≈2.1pp | 小-中效应 |
| 真机确认 | 2 因子 × 32 任务 × 10 eps | 320 | ≈9.6pp | 仅大效应 |
| 真机相位端点 | 同场景配对，`Δ=0.5σ` | ≈64 | 0.5σ（连续） | 中效应机制链 |

**预算决策规则**：先用代理 16-run 把 6 个因子筛到 ≤2 个；真机只做这 2 个因子的配对确认。若真机时段少于 600 episodes，则**不做终态主效应声明**，只做机制端点 + 隔离证书 + 代理外推。

## 11. 风险登记与剪枝

| 风险 | 概率 | 影响 | 对冲 |
|---|---|---|---|
| **元工作吞噬预算**：隔离 / 设计 / 分析吃掉真机时间 | 中高 | 高 | MVP 只覆盖 IP-02/IP-03；隔离测试自动化；16-run 上限 |
| **功效不足**：小效应不可识别 | 高 | 高 | 配对 + 相位端点 + 部分池化；提前声明"不可识别"而非硬解释 |
| **代理失真**：代理与真机 `|r|<0.3` | 中 | 高 | 第 1 轮 E601 门槛；只保留机制正确性驱动的 IP-02/IP-03 |
| **隐藏泄漏**：共享库 / CUDA / 日志 / 批队列 | 中高 | 高 | canary + 串并行位等价 + 时序 p99；静态清单强制标记 |
| **官方语义未知**：chunk 执行 / reset / 端口调度 | 中 | 高 | 先复刻官方 client；所有"利用未声明行为"进黑名单（P5） |
| **RNG 混杂**：关模块移动其他模块随机数 | 中高 | 中高 | counter-based RNG + 每模块流；E626 强制验收 |
| **容量混杂**：参数 / 算力带来假效应 | 中 | 中高 | 安慰剂臂 + 参数匹配；E629 |
| **多重比较 / p-hacking** | 中 | 高 | 预注册 + Holm + 序贯 alpha spending；阴性结果台账 |
| **替代端点误导**：相位指标与终态脱节 | 中 | 中 | `|r|≥0.5` 才用于筛选；中介敏感性分析 |
| **过度平滑 / 限幅压低成功率** | 中 | 中 | 只作用于残差；阈值由数据分布定（沿用第 1 轮） |

**剪枝预案**：

- **必保**：IP-10（隔离）、IP-11（开关格）、IP-09（预注册 + 16-run 分析）。没有它们，后续任何"涨点"都不可信。
- **优先**：IP-02、IP-03 的配对确认（机制最清晰、端点方差最小）。
- **条件推进**：IP-12（替代端点）依赖 `|r|≥0.5`；IP-13（episode-local）依赖 `R_local` 实测；IP-14 仅在 I4 可用时推进。
- **冻结**：IP-01 的完整 MoE（除非代理 + 相位端点同时显示 ≥8pp 且合规确认）；IP-04 的跨 episode 更新；IP-05、IP-07。
- **熔断**：`Cert_iso=0` 时一切实验停止；官方语义未复刻前不做 chunk / reset 相关优化。
