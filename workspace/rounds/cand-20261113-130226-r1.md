# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；本轮灵感：「研究空白」×「安全对齐」）

> 第 65 轮 VISTA 回答了「哪一层坏了」，第 66 轮 RAS 回答了「谁该控制、控制多少」。它们造出了一串越来越精致的证书 `J_VISTA → J_RAS`。但这些证书全都建立在一个从未被写进证书本身的假设之上：**故障假设集 ℋ 是封闭的**——所有可能发生的事，都已经被枚举进那 6~7 个假设里。
>
> 本轮把「研究空白」从论文里的一句套话，变成一个**可计算的集合**：`Gap = 声明操作域 \ 已覆盖域`，也就是假设集 ℋ 相对声明域 `D` 的**补集**。把「安全对齐」从一句价值口号，变成一个**可检验的不等式**：`权限 a ≤ 覆盖 κ`。
>
> 新框架 **GATE（Gap-Aware Trust Escalation：空白感知的信任升级）** 不问「故障去哪儿」，也不问「谁控制多少」，它问的是更前置的一句：
>
> **在你证明「这件事落在覆盖范围内」之前，你凭什么被授予执行它的权限？**
>
> 一句话命题：**证书不是「安全」的证明，而是「在当前覆盖下安全」的证明；对齐不是让系统更善良，而是让系统的权限诚实地落后于它的证据。**

## 0. 直觉与动机

**灵感 1（研究空白 → 假设集的补集 H_∅）**
直觉：文献里的「研究空白」通常指「还没人做过」。但对一个已经上线、正在发证书的系统，空白有一个更硬的含义：**当前假设集解释不了的东西**。VISTA/RAS 的归因是「从 ℋ 里挑一个最像的」，这是一个被归一化强行封口的操作——如果真相不在 ℋ 里，系统仍会被迫输出一个「最像」的假设，并附上一张看起来很确定的证书。**这正是研究空白在工程上的样子：不是没有答案，而是给出了一个不该被相信的答案。**
所以第一个动作，是把 `H_∅`（「以上皆非」）提升为一等公民：`ℋ⁺ = ℋ ∪ {H_∅}`。`H_∅` 不是某一种新故障，它是**补集本身**。

**灵感 2（安全对齐 → 权限不能超过覆盖）**
直觉：LLM 的「对齐」常被拆成 helpful / honest / harmless。具身系统的安全对齐可以逐条对应，而且更可量化：
- **honest（诚实）** = 覆盖估计必须校准，不能把「没测过」说成「测过且安全」；
- **harmless（无害）** = 授予的权限 `a` 不得超过认证覆盖 `κ`，即 `a ≤ φ(κ)`；
- **helpful（有用）** = 通过主动扩展把 `κ` 抬上去，而不是一味弃权。

于是「安全对齐」不再是一个形容词，而是一个**带约束的优化问题**：在 `P(权限越界) ≤ ε` 的约束下最大化任务效用。本轮最核心的形式化就是**对齐间隙**：
`Δ_align = a − φ(κ*)`，其中 `κ*` 是真实覆盖。**安全对齐 ⇔ `Δ_align` 在声明域上不取正值。**

**灵感 3（从「绝对证书」到「可废止证书」）**
直觉：前几轮都把证书当成结论。但任何「安全」结论都依赖一个前提：**当前情境落在校准与假设所覆盖的范围内**。传统证书把这个前提吞掉了，于是证书一旦发出就无法被推翻——这在开放世界里是危险的。GATE 把证书写成三元组 `(claim, premise, defeaters)`：claim 是动作安全，premise 是 `x ∈ 覆盖域`，defeaters 是任何能推翻 premise 的证据。证书因此变得**可废止（defeasible）**，由 DRM 在线监控、随时吊销。这借用了 assurance case 里「away goal / defeat」的结构，以及 runtime assurance 里「监控器可否决控制器」的结构。

**灵感 4（发现空白之后：三种合法的响应）**
直觉：发现空白之后只会「降级」是浪费。面对一个覆盖不足的区域，系统其实有三种正当响应，且各有代价：
1. **E（Epistemic，认知扩展）**：补假设、补数据、补标定——把 `ℋ` 变大；
2. **O（Operational，运行收缩）**：把声明域 `D` 缩小，明确「这里我不接单」；
3. **A（Authority，权限收紧）**：留在原地但降低权限、加人类确认、缩短认证前缀。

把这三者放进一个代价敏感的决策（EAP），比「一律急停」更接近真实的工程与伦理取舍。**「研究空白」因此不只是一个待填的坑，而是一个待定价的选项。**

**灵感 5（合流 → GATE 作为元保证层）**
直觉：GATE 不替换 VISTA/RAS/TANGO/CHAI，它**包在它们外面**。它读取它们的证书与残差，输出一个更强的前提约束：

```
a_GATE = min( a_prev , φ_γ(κ̂) ),   Valid ⇔ Δ_align ≤ 0
```

它是「证书的证书」——一个**元保证层（meta-assurance layer）**。这也解释了为什么此前每一轮都会在「最大风险」里写下同一句话：情绪不可信、标定会漂、地图会错。那些风险的共同根源不是某个模块不够好，而是**没有任何一层在为自己的「适用边界」负责**。GATE 就是那一层。

**灵感 6（组件映射）**
`GATE = (GCM, NHT, CAL, EAP, AGX, GAC, DRM, AIC-G)`：
- **GCM** Gap Coverage Map：新颖度 → 共形覆盖下界 `κ̂_conf`；
- **NHT** Null-Hypothesis Tracker：开世界后验 `p_∅` 与其上界 `UCB_δ`；
- **CAL** Calibrated Authority Law：`a ≤ φ_γ(κ̂)`，把覆盖翻译成权限；
- **EAP** Escalation/Abstention Policy：E/O/A 三选一的代价敏感决策；
- **AGX** Active Gap eXpansion：按「信息增益/风险」比主动探测，把空白变成证据；
- **GAC** Gap-Aware Certificate：可废止证书 `J_GATE`；
- **DRM** Defeasibility/Revision Monitor：CUSUM 在线吊销；
- **AIC-G**：把「覆盖漂移、对抗新颖性、静默新模式、基准过拟合」纳入干扰集。

## 1. 形式化定义（增量：定义 251–268）

- **定义 251（GATE 总览）**：`GATE = (GCM, NHT, CAL, EAP, AGX, GAC, DRM, AIC-G)`。定位：在 VISTA/RAS 之外增加一层「覆盖—权限」元保证。不变式：覆盖估计、未知后验、对齐律、证书构建只在语义流；实时流只做新颖度打分、门控查表、权限缩放、升级事件触发，**零学习写操作**。
- **定义 252（声明操作域）**：`D = (X, P_X, Θ)`，`X` 为情境空间、`P_X` 为部署分布、`Θ` 为任务集。任何证书都写作 `J | D`：**覆盖离开声明域就没有意义**。这把「研究空白」锚定为「相对于某个承诺的空白」，而不是绝对的无知。
- **定义 253（开世界假设空间与空白算子）**：`ℋ⁺ = ℋ ∪ {H_∅}`，其中 `H_∅` 的语义是「不存在 `h ∈ ℋ` 能在声明置信度下解释当前证据」，其证据密度记为背景密度 `p_bg(ρ)`（由未解释残差的留出集估计）。**空白算子**：`Gap(D, ℋ, κ_abs) = {x ∈ supp(D) : κ*(x) < κ_abs}`。
- **定义 254（新颖度与共形覆盖）**：非一致性分数 `s(x, ρ) = −log p_in(ρ | x)`。参考集 `{s_i}_{i=1}^n` 上的共形分位数给出覆盖下界 `κ̂_conf(x) = Q_α({s_i})` 对应的「不小于当前分数」的尾概率下界（等价地，把共形 p 值校准为 `1−α` 水平的覆盖证据）。直观：`κ̂_conf` 越大，样本越「在分布内」。
- **定义 255（未知后验与上界）**：密度比形式的开世界后验
  `p_∅(x) = π_∅ p_bg(ρ) / (π_∅ p_bg(ρ) + (1−π_∅) p_ℋ(ρ|x))`，
  其中 `p_ℋ = Σ_h π_h p(ρ|h)`。其 `(1−δ)` 上界 `UCB_δ[p_∅] = min(1, p_∅ + √(ln(1/δ)/(2n_eff)))`。定义假设维度的覆盖 `κ̂_hyp = 1 − UCB_δ[p_∅]`。
- **定义 256（认证覆盖）**：`κ̂(x) = min(κ̂_conf(x), κ̂_hyp(x))`。分布新颖性与假设不完备性取「与」，二者任一不足都拉低覆盖。真值记为 `κ*(x)`。
- **定义 257（权限与认证前缀）**：`a(x) = k*(x)/m(x)`，`k*` 是上一层（VISTA/RAS/C-RAS）给出的认证前缀长度，`m` 是动作块长度。**权限 = 在下次复核前被开环执行的动作比例 = 不可逆暴露量**。这把抽象的「自主性」落到已有的 `k*` 上。
- **定义 258（对齐律）**：给定断崖 `κ_abs` 与保守指数 `γ ≥ 1`，
  `φ_γ(κ) = 0`（`κ < κ_abs`）；否则 `φ_γ(κ) = ((κ − κ_abs)/(1 − κ_abs))^γ`。
  φ 单调不减，且 `φ_γ(κ) ≤ κ`（见引理 12）。
- **定义 259（对齐间隙与安全对齐）**：`Δ_align(x) = a(x) − φ_γ(κ*(x))`。**安全对齐（level ε）** ⇔ `P_{X∼D}(Δ_align > 0) ≤ ε`。注意：系统只能依据 `κ̂` 设权限，故越界等价于**高估覆盖**（`κ̂ > κ*`）。
- **定义 260（权限的物理实现）**：`k_gate = ⌊m·φ_γ(κ̂)⌋`；速度/力上限按 `a` 缩放 `v_max = a·v_0, f_max = a·f_0`；当 `a < a_check` 时强制每步人类确认；`a = 0` 时只允许 `SAFE_HOLD` 或升级。**权限不是抽象权重，它有物理单位。**
- **定义 261（升级/弃权策略 EAP）**：当 `κ̂ < κ_abs`，在 `{E 认知扩展, O 运行收缩, A 权限收紧}` 中按代价选择
  `u* = argmin_u [ λ_r·risk(u) + λ_h·human_load(u) + λ_t·task_loss(u) ]`。
- **定义 262（主动空白扩展 AGX）**：`u* = argmax_{u∈U_safe} [ IG(H_∅; y_u | x, e) − λ_r·risk(u) − λ_c·cost(u) ]`，其中 `IG = I(H_∅; y_u | e)`。探针类型：受控运动（激发未建模模态）、传感器重定向、人类查询。与 TANGO 的主动力矩探测、CHAI 的主动激励同构，只是激励对象从「几何/规范」换成了「假设覆盖」。
- **定义 263（可废止证书 GAC）**：`J_GATE = (J_prev, D, κ̂, p_∅, α_conf, a, Δ_align, premise, defeaters, review_trigger, aic_g_ver)`，其中 `premise = (x ∈ C_{κ_abs})`。`Valid ⇔ J_prev.Valid ∧ a ≤ φ_γ(κ̂) ∧ κ̂ ≥ κ_abs`（否则必须以 `escalate` 形式发证）。**证书携带自己的前提，故可被证据推翻。**
- **定义 264（空白报告与三响应）**：`R_gap = (Vol_gap, top 区域, E/O/A 代价表, 建议动作)`，`Vol_gap = P_D(Gap)`。每次部署迭代必须产出空白报告，并给出 **扩展 ℋ / 收缩 D / 收紧 a** 三条路径的定价。
- **定义 265（DRM 修订监控）**：对数似然比 `ℓ_t = log p_bg(ρ_t) − log p_ℋ(ρ_t)`；CUSUM `g_t = max(0, g_{t−1} + ℓ_t − ν)`；`g_t > h` 时**吊销** `J_GATE`，令 `a = 0` 并重开覆盖评估。
- **定义 266（AIC-G 干扰与共因）**：`E_G = E_V × E_emotion × E_contact × E_social × E_gap`，`E_gap = {覆盖漂移, 对抗新颖性, 静默新模式, 基准过拟合, 标签漂移}`。共因 `E_common_gap = {高代价 ∧ 低覆盖}`——最危险象限，必须优先升级。
- **定义 267（HHH 对齐目标）**：`min_π E[task_loss]` s.t. `P_X(Δ_align > 0) ≤ ε`（harmless）、`ECE(κ̂) ≤ η`（honest）、`E[human_load] ≤ B_h`（可用性）。三项分别可测、可审计。
- **定义 268（GATE 轮次契约）**：`GATE.round(obs) → (k_gate, a, escalate, J_GATE, R_gap)`。优先级：升级/覆盖 > 上一层证书 > 任务性能；三者冲突时，低优先级项必须让位。

## 2. 关键算法骨架

```python
class GapCoverageMap:                       # GCM
    def __init__(self, cal_scores, density_in):
        self.cal = sorted(cal_scores)       # 参考集非一致性分数
        self.p_in = density_in
    def novelty(self, x, rho):
        return -self.p_in.logpdf(rho, x)    # s(x,ρ)
    def coverage(self, x, rho):
        s = self.novelty(x, rho)
        n = len(self.cal)
        ge = n - bisect_left(self.cal, s)   # #{s_i >= s}
        return tail_lower_bound((1 + ge) / (n + 1))   # κ̂_conf


class NullHypothesisTracker:                # NHT
    def __init__(self, p_bg, p_h, pi_empty=0.5, delta=0.05):
        self.p_bg, self.p_h = p_bg, p_h
        self.pi_empty, self.delta = pi_empty, delta
    def unknown_mass(self, rho):
        a = self.pi_empty * self.p_bg.logpdf(rho)
        b = (1 - self.pi_empty) * logsumexp(self.p_h.logpdf(rho).values())
        p_empty = exp(a) / (exp(a) + exp(b))
        ucb = min(1.0, p_empty + sqrt(log(1/self.delta) / (2*self.n_eff)))
        return p_empty, ucb


class CalibratedAuthorityLaw:               # CAL
    def __init__(self, kappa_abs=0.6, gamma=1.5):
        self.kappa_abs, self.gamma = kappa_abs, gamma
    def phi(self, kappa):
        if kappa < self.kappa_abs:
            return 0.0
        return ((kappa - self.kappa_abs) / (1 - self.kappa_abs)) ** self.gamma


class EscalationPolicy:                     # EAP
    def decide(self, x, kappa, ctx):
        if kappa < self.kappa_hard:         # 断崖：只允许 SAFE_HOLD / DEFER
            return 'SAFE_HOLD'
        opts = {'E': self.cost_expand(x, ctx),
                'O': self.cost_restrict(x, ctx),
                'A': self.cost_tighten(x, ctx)}
        return min(opts, key=opts.get)


class ActiveGapExpansion:                   # AGX
    def choose(self, x, e, budget, risk_budget):
        best, best_score = None, -inf
        for u in self.safe_probes(x):       # 运动 / 重定向 / 人类查询
            ig = self.info_gain(x, e, u)    # I(H_empty; y_u | e)
            score = ig - self.lam_r*self.risk(u) - self.lam_c*self.cost(u)
            if score > best_score and self.risk(u) <= risk_budget:
                best, best_score = u, score
        return best


class DefeasibilityMonitor:                 # DRM
    def __init__(self, nu=0.2, h=8.0):
        self.g, self.nu, self.h = 0.0, nu, h
    def update(self, rho):
        ell = self.p_bg.logpdf(rho) - self.p_learned.logpdf(rho)
        self.g = max(0.0, self.g + ell - self.nu)
        return self.g > self.h               # True → 吊销证书


def GATE_round(M, obs):
    # 0) 沿用前序管线，拿到上一层证书、动作块与残差
    J_prev, A, rho, x = M.prior_round(obs)

    # 1) 覆盖：共形新颖度 + 开世界未知后验
    k_conf = M.gcm.coverage(x, rho)
    p_empty, p_empty_ucb = M.nht.unknown_mass(rho)
    kappa = min(k_conf, 1.0 - p_empty_ucb)

    # 2) 对齐律：权限只能落后于覆盖
    a_cap = M.cal.phi(kappa)
    k_gate = int(min(J_prev.k_star, floor(M.m * a_cap)))

    # 3) 断崖 / 升级：覆盖不足时，不做“带病执行”
    if kappa < M.kappa_abs or k_gate == 0:
        action = M.eap.decide(x, kappa, obs)
        J_gate = M.gac.issue(J_prev, M.D, kappa, p_empty,
                             a=0.0, escalated=True)
        return 0, 0.0, action, J_gate, M.gap_report(x, kappa)

    # 4) 主动扩展（预算内、风险有界）：把空白变成证据
    if M.kappa_abs <= kappa < M.kappa_target and M.agx.budget_ok():
        u = M.agx.choose(x, obs, M.budget, M.risk_budget)
        if u is not None:
            M.execute_probe(u)               # 语义流排程，不打断实时闭环
            return k_gate, a_cap, 'PROBE', None, M.gap_report(x, kappa)

    # 5) 正常执行：权限 = min(上一层前缀, 覆盖所允许的前缀)
    tau = M.prior_dispatch(A[:k_gate])
    tau = tau * min(M.lambda_risk, a_cap)
    J_gate = M.gac.issue(J_prev, M.D, kappa, p_empty, a=a_cap,
                         escalated=False)

    # 6) 在线可废止监控
    if M.drm.update(rho):
        M.revoke(J_gate); a_cap = 0.0
        M.gap_report(x, kappa, trigger='DRM')

    return k_gate, a_cap, tau, J_gate, M.gap_report(x, kappa)
```

## 3. 推导

**引理 11（覆盖对惊奇单调）** `κ̂_conf` 关于非一致性分数 `s` 单调不增；`1 − UCB_δ[p_∅]` 关于 `p_∅` 单调不增；故 `κ̂ = min(·,·)` 关于「新颖度 / 未知后验」单调不增。于是 `a_cap = φ_γ(κ̂)` 也单调不增：**越意外，权限越低**。

**引理 12（权限恒不高于覆盖）** 对 `γ ≥ 1`、`κ ∈ [κ_abs, 1]`，有 `φ_γ(κ) ≤ κ`。
证明：`γ = 1` 时 `(κ−κ_abs)/(1−κ_abs) ≤ κ ⇔ κ − κ_abs ≤ κ(1−κ_abs) ⇔ κ_abs(1−κ) ≥ 0`；`γ > 1` 时在 `[0,1]` 上幂函数进一步压低。故 `a ≤ κ̂`，GATE 永远不比裸覆盖更激进；`γ` 只调节保守程度。

**定理 11（对齐可靠性 / Alignment Soundness）** 假设校准集与部署在 `D` 内可交换，且 `κ̂` 是 `κ*` 的 `(1−α−δ)` 下置信界。则对 GATE 执行的任意动作，
`P_D(Δ_align > 0) ≤ α + δ`。
证明：`Δ_align > 0 ⇔ φ(κ̂) > φ(κ*) ⇔ κ̂ > κ*`（φ 单调）。该事件正是下置信界失效，其概率由共形失效（≤α）与未知后验上界失效（≤δ）的并集界控制。**推论**：把对外承诺的安全等级写成 `1−α−δ`，则实际越界概率不超过承诺缺口。注意这是**边缘（marginal）**保证；交换性被破坏时须加权/在线共形（见风险）。

**定理 12（开世界不可对齐性）** 设 `P_D(H_∅) = q > 0`。任何仅在 ℋ 上归一化的封闭世界证书都无法表示「以上皆非」，因而在空白区域输出 `κ̂ = 1`，并据此授予 `a = φ_γ(1) = 1`。设它在测度为 `q_a > 0` 的空白子集上实际执行了权限 `a_gap > 0`，则该处真实允许权限为 `φ_γ(0) = 0`，于是
`E_D[Δ_align] ≥ q_a · a_gap > 0`。
即：**只要系统在空白上哪怕执行一点点，它就已经失配**。封闭世界证书在开放世界中不可能安全对齐；`H_∅` 不是可选项，是必要条件。这也是「研究空白」的严格版本：空白不是「还没研究」，而是「已被错误地当作安全」。

**定理 13（主动扩展的次模性与贪婪保证）** 令探测集 `S`，`G(S) = I(H_∅; y_S | e)`。互信息对观测集单调且次模，故带基数/成本约束的 AGX 用贪婪选择可得 `G(S_greedy) ≥ (1−1/e)·G(S*)`；带风险约束时用拉格朗日松弛，得到 `(1−1/e)` 的双准则近似。含义：**空白可以被有原则地、按性价比地填补**，而不是碰运气。

**定理 14（可废止性的检测延迟）** 对 CUSUM，设空白期对数似然比均值 `KL(H_∅‖ℋ)`、漂移 `ν`、阈值 `h`。则近似有 `ARL_0 ≥ e^{h}`，且平均检测延迟
`E[τ] ≤ (h + 1) / (KL(H_∅‖ℋ) − ν)`。
含义：吊销延迟与「偏出假设集有多远」成反比——越离谱的新模式越快吊销；越接近 ℋ 的静默漂移越难，故需要 AGX 主动激励。

**定理 15（端到端安全对齐）** 组合上述结果：
`P(不安全动作) ≤ P(升级失败) + P(Δ_align > 0) + P(DRM 漏检) ≤ ε_esc + (α+δ) + β_drm`。
这是 GATE 的「元证书」：它把端到端安全分解成**覆盖、对齐、检测**三项可分别测量、分别审计的误差。相比前几轮把安全写成一个整体目标，这个分解本身是可证伪的。

## 6. 本轮最大风险

**一句话**：GATE 把「安全」建立在「覆盖估计是诚实的」之上，但覆盖本身是由一个校准集与一个背景密度模型估计出来的——**如果校准集恰好漏掉了部署中最危险的那块区域，GATE 会恰好在它最该闭嘴的地方给出最高的 `κ̂`**，于是「空白检测器自己有一个空白」，对齐证书在最需要它的时候最不可信。

**次级风险与缓解**：
1. **交换性失效（分布漂移）**：共形保证只是边缘的 → 采用加权共形 / 在线共形，并由 DRM 与 `E_gap` 一起监控；
2. **背景密度误设**：`p_bg` 选错会让 `p_∅` 系统性偏低 → 用多模型集成 + 对抗验证（adversarial validation）交叉检查；
3. **过度弃权导致有用性崩塌**：`κ_abs` 过高时系统「什么都不敢做」 → 用 AGX 把弃权转化为主动取证，并用 EAP 对 E/O/A 定价；
4. **权限实现错位**：`a = k*/m` 只刻画了动作块长度，未必等于真实不可逆性 → 用物理不可逆暴露（力×位移、速度×时滞）重新定义权限；
5. **指标被 Goodhart 化**：只优化 `Vol_gap` 会让系统把声明域越缩越小 → 空白报告强制同时报告 E/O/A 三条路径的代价，并接受外部红队审计。

## 2. 形式化定义（完整版）

**定义 251（GATE 总览）** GATE 是包在 VISTA/RAS 之外的元保证层：
```
GATE = (GCM, NHT, CAL, EAP, AGX, GAC, DRM, AIC-G)
```
不变式：覆盖估计、未知后验、对齐律、证书构建只在语义流；实时流只做新颖度打分、门控查表、权限缩放、升级事件触发，零学习写操作。

**定义 252（声明操作域）** `D = (X, P_X, Θ)`，`X` 为情境空间、`P_X` 为部署分布、`Θ` 为任务集。任何证书都相对于 `D` 成立（`J | D`）。覆盖离开声明域即无定义——「空白」永远是**相对于某个承诺**的空白。

**定义 253（开世界假设空间与空白算子）**
```
ℋ⁺ = ℋ ∪ {H_∅}
p(ρ | H_∅) := p_bg(ρ)        # 由未解释残差的留出集估计的背景密度
Gap(D, ℋ, κ_abs) = {x ∈ supp(D) : κ*(x) < κ_abs}
```

**定义 254（新颖度与共形覆盖）** 非一致性分数 `s(x,ρ) = −log p_in(ρ|x)`。参考集 `{s_i}_{i=1}^n` 上，覆盖下界
```
κ̂_conf(x) = Cal_{1−α}( s(x,ρ) ; {s_i} )
```
由共形尾概率校准得到（`κ̂_conf` 越大，样本越在分布内）。

**定义 255（未知后验与上界）**
```
p_∅(x) = π_∅·p_bg(ρ) / ( π_∅·p_bg(ρ) + (1−π_∅)·p_ℋ(ρ|x) )
p_ℋ(ρ|x) = Σ_{h∈ℋ} π_h·p(ρ|h)
UCB_δ[p_∅] = min(1, p_∅ + √(ln(1/δ)/(2n_eff)))
κ̂_hyp = 1 − UCB_δ[p_∅]
```

**定义 256（认证覆盖）**
```
κ̂(x) = min( κ̂_conf(x), κ̂_hyp(x) )
```
分布新颖性与假设不完备性取「与」：任一维度不足都拉低覆盖。

**定义 257（权限与认证前缀）**
```
a(x) = k*(x) / m(x)
```
`k*` 为上一层（VISTA/RAS/C-RAS）的认证前缀长度，`m` 为动作块长度。权限 = 下次复核前被开环执行的动作比例 = **不可逆暴露量**。

**定义 258（对齐律）**
```
φ_γ(κ) = 0,                                          κ < κ_abs
φ_γ(κ) = ((κ − κ_abs)/(1 − κ_abs))^γ,                κ ≥ κ_abs, γ ≥ 1
```
φ 单调不减，且 `φ_γ(κ) ≤ κ`（引理 12）。

**定义 259（对齐间隙与安全对齐）**
```
Δ_align(x) = a(x) − φ_γ(κ*(x))
安全对齐(level ε) ⇔ P_{X∼D}(Δ_align > 0) ≤ ε
```
系统只能依据 `κ̂` 设权限，故 `Δ_align > 0 ⇔ κ̂ > κ*`：**越界的本质是高估覆盖**。

**定义 260（权限的物理实现）**
```
k_gate = ⌊ m·φ_γ(κ̂) ⌋
v_max = a·v_0,   f_max = a·f_0
a < a_check  ⇒ 每步人类确认
a = 0        ⇒ 仅 SAFE_HOLD / escalate
```

**定义 261（升级/弃权策略 EAP）** 当 `κ̂ < κ_abs`：
```
u* = argmin_{u∈{E,O,A}} [ λ_r·risk(u) + λ_h·human_load(u) + λ_t·task_loss(u) ]
```
`E` = 扩展 ℋ，`O` = 收缩 `D`，`A` = 收紧 `a`。发现空白不再等价于急停，而是一次**代价敏感的路径选择**。

**定义 262（主动空白扩展 AGX）**
```
u* = argmax_{u∈U_safe} [ I(H_∅; y_u | x,e) − λ_r·risk(u) − λ_c·cost(u) ]
```
探针类型：受控运动（激发未建模模态）、传感器重定向、人类查询。与 TANGO 的主动力矩探测、CHAI 的主动激励同构，激励对象从「几何/规范」换成「假设覆盖」。

**定义 263（可废止证书 GAC）**
```
J_GATE = (J_prev, D, κ̂, p_∅, α_conf, a, Δ_align,

不满足时必须以 `escalate` 形式发证。**证书携带自己的前提，故可被证据推翻。**

**定义 264（空白报告与三响应）**

R_gap = (Vol_gap, top 区域, E/O/A 代价表, 建议动作)

ℓ_t = log p_bg(ρ_t) − log p_ℋ(ρ_t)

# IP-234 GCM
class GapCoverageMap:
    def __init__(self, cal_scores, density_in):
        self.cal = sorted(cal_scores); self.p_in = density_in
    def novelty(self, x, rho):
        return -self.p_in.logpdf(rho, x)
    def coverage(self, x, rho):
        s = self.novelty(x, rho); n = len(self.cal)
        ge = n - bisect_left(self.cal, s)
        return tail_lower_bound((1 + ge) / (n + 1))     # κ̂_conf


# IP-235 NHT
class NullHypothesisTracker:
    def unknown_mass(self, rho):
        a = self.pi_empty * self.p_bg.logpdf(rho)
        b = (1 - self.pi_empty) * logsumexp(self.p_h.logpdf(rho).values())
        p_empty = exp(a) / (exp(a) + exp(b))
        ucb = min(1.0, p_empty + sqrt(log(1/self.delta) / (2*self.n_eff)))
        return p_empty, ucb                            # p_∅, UCB_δ


# IP-236 CAL
class CalibratedAuthorityLaw:
    def phi(self, kappa):
        if kappa < self.kappa_abs:
            return 0.0
        return ((kappa - self.kappa_abs) / (1 - self.kappa_abs)) ** self.gamma


# IP-237 EAP
class EscalationPolicy:
    def decide(self, x, kappa, ctx):
        if kappa < self.kappa_hard:
            return 'SAFE_HOLD'
        opts = {'E': self.cost_expand(x, ctx),
                'O': self.cost_restrict(x, ctx),
                'A': self.cost_tighten(x, ctx)}
        return min(opts, key=opts.get)


# IP-238 AGX
class ActiveGapExpansion:
    def choose(self, x, e, budget, risk_budget):
        best, best_score = None, -inf
        for u in self.safe_probes(x):
            ig = self.info_gain(x, e, u)               # I(H_∅; y_u | e)
            score = ig - self.lam_r*self.risk(u) - self.lam_c*self.cost(u)
            if score > best_score and self.risk(u) <= risk_budget:
                best, best_score = u, score
        return best


# IP-240 DRM
class DefeasibilityMonitor:
    def update(self, rho):
        ell = self.p_bg.logpdf(rho) - self.p_learned.logpdf(rho)
        self.g = max(0.0, self.g + ell - self.nu)
        return self.g > self.h                         # True → 吊销


# IP-239/243 GATE 闭环
def GATE_round(M, obs):
    J_prev, A, rho, x = M.prior_round(obs)

    k_conf = M.gcm.coverage(x, rho)
    p_empty, p_empty_ucb = M.nht.unknown_mass(rho)
    kappa = min(k_conf, 1.0 - p_empty_ucb)

    a_cap = M.cal.phi(kappa)
    k_gate = int(min(J_prev.k_star, floor(M.m * a_cap)))

    if kappa < M.kappa_abs or k_gate == 0:
        action = M.eap.decide(x, kappa, obs)
        J_gate = M.gac.issue(J_prev, M.D, kappa, p_empty,
                             a=0.0, escalated=True)
        return 0, 0.0, action, J_gate, M.gap_report(x, kappa)

    if M.kappa_abs <= kappa < M.kappa_target and M.agx.budget_ok():
        u = M.agx.choose(x, obs, M.budget, M.risk_budget)
        if u is not None:
            M.execute_probe(u)
            return k_gate, a_cap, 'PROBE', None, M.gap_report(x, kappa)

    tau = M.prior_dispatch(A[:k_gate]) * min(M.lambda_risk, a_cap)
    J_gate = M.gac.issue(J_prev, M.D, kappa, p_empty,
                         a=a_cap, escalated=False)

    if M.drm.update(rho):
        M.revoke(J_gate); a_cap = 0.0
        M.gap_report(x, kappa, trigger='DRM')

    return k_gate, a_cap, tau, J_gate, M.gap_report(x, kappa)
```

## 4. 推导

**引理 11（覆盖对惊奇单调）** `κ̂_conf` 关于新颖度 `s` 单调不增；`1 − UCB_δ[p_∅]` 关于 `p_∅` 单调不增；故 `κ̂ = min(·,·)` 关于「新颖度 / 未知后验」单调不增。于是 `a_cap = φ_γ(κ̂)` 也单调不增：**越意外，权限越低**。

**引理 12（权限恒不高于覆盖）** 对 `γ ≥ 1`、`κ ∈ [κ_abs,1]`：`φ_γ(κ) ≤ κ`。故 `a ≤ κ̂`，GATE 永不比裸覆盖更激进；`γ` 只调节保守程度。

**定理 11（对齐可靠性）** 若校准集与部署在 `D` 内可交换，且 `κ̂` 是 `κ*` 的 `(1−α−δ)` 下置信界，则
```
P_D(Δ_align > 0) ≤ α + δ
```
因 `Δ_align > 0 ⇔ κ̂ > κ*`，即下置信界失效；由共形失效（≤α）与 UCB 失效（≤δ）的并集界控制。（注：边缘保证；交换性破坏需加权/在线共形。）

**定理 12（开世界不可对齐性）** 设 `P_D(H_∅) = q > 0`。任何只在 ℋ 上归一化的封闭世界证书无法表示「以上皆非」，在空白处输出 `κ̂ = 1` 并授予 `a = φ_γ(1) = 1`。若它在测度 `q_a > 0` 的空白子集上执行了权限 `a_gap > 0`，该处真实允许权限为 `φ_γ(0) = 0`，故
```
E_D[Δ_align] ≥ q_a · a_gap > 0
```
即：**只要在空白上执行一点点，就已经失配**。`H_∅` 是开放世界安全对齐的必要条件，不是可选项。

**定理 13（主动扩展的次模性与贪婪保证）** 令 `G(S) = I(H_∅; y_S | e)`。互信息对观测集单调且次模，故带基数/成本约束的 AGX 贪婪选择满足
```
G(S_greedy) ≥ (1 − 1/e)·G(S*)
```
带风险约束时用拉格朗日松弛得到 `(1−1/e)` 双准则近似。

**定理 14（可废止性的检测延迟）** 对 CUSUM，设空白期对数似然比均值 `KL(H_∅‖ℋ)`、漂移 `ν`、阈值 `h`，则近似 `ARL_0 ≥ e^{h}`，且
```
E[τ] ≤ (h + 1) / (KL(H_∅‖ℋ) − ν)
```
吊销延迟与「偏出假设集有多远」成反比：越离谱越快吊销，越接近 ℋ 的静默漂移越依赖 AGX 主动激励。

**定理 15（端到端安全对齐）**
```
P(不安全动作) ≤ ε_esc + (α + δ) + β_drm
```
端到端安全被分解为**覆盖、对齐、检测**三项可分别测量、分别审计的误差——这使「安全」从整体口号变成可证伪的分解式。

## 6. 本轮最大风险

**一句话**：GATE 把「安全」建立在「覆盖估计是诚实的」之上，但覆盖由校准集与背景密度模型估计——**如果校准集恰好漏掉部署中最危险的那块区域，GATE 会恰好在最该闭嘴的地方给出最高的 `κ̂`**：空白检测器自己有一个空白，对齐证书在最需要它的时候最不可信。

**次级风险与缓解**：
1. **交换性失效**：共形保证仅为边缘 → 加权/在线共形 + DRM + `E_gap` 联合监控；
2. **背景密度误设**：`p_bg` 偏差使 `p_∅` 系统性偏低 → 多模型集成 + 对抗验证交叉检查；
3. **过度弃权**：`κ_abs` 过高导致「什么都不敢做」→ AGX 把弃权转成主动取证，EAP 对 E/O/A 定价；
4. **权限实现错位**：`k*/m` 未必等于真实不可逆性 → 用物理不可逆暴露（力×位移、速度×时滞）重定义权限；
5. **指标 Goodhart 化**：只压 `Vol_gap` 会让声明域越缩越小 → 空白报告强制并列 E/O/A 三条路径的代价，接受外部红队审计；
6. **实时算力**：共形查询与密度比在嵌入式平台可能超预算 → 离线排序 + 在线二分、蒸馏小模型、门控表缓存。
