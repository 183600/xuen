# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环第 1 轮；本轮灵感：「双臂协作」×「推理延迟」）

> R69 给闭环装上了一张嘴：会看、会问、会触，用信息动作主动消解 epistemic 歧义。但 R69 的每一条定理都默默假设了两件事：
> **(A) 只有一个身体、一个时钟**——不确定性是「我的」，证据是「我的」，预算是「我的」；
> **(B) 推理与执行之间没有不可忽略的延迟**——算完就能用，用的时候世界还是算的时候那个世界。
>
> 真实的双臂系统同时打破这两条。两个身体共享同一个物体，**耦合约束（相对位姿、内力、自碰撞）恰恰定义在「两个体之间」**；两条推理流水线各有各的延迟，**相对状态的误差恰恰由「两者之间的延迟差」产生**。于是 R69 最擅长的两件事——分解不确定性、把预算花在刀刃上——都需要换一个作用对象：不再是「一个智能体的不确定性」，而是「一对耦合体的相对不确定性」。
>
> 本轮两个灵感各补一块：
> - **双臂协作**告诉我们：耦合不是两个单臂的相加，而是一个**新的安全单元**——两条各自安全的臂可以合谋出一场事故（互相碰撞、拉断物体、内力爆表）；同时它给出一个 R69 没有的自由度：**角色（谁领奏、谁伴奏）**。
> - **推理延迟**告诉我们：延迟不是一个要被消灭的标量误差，而是一个**可分配的资源**——谁能领奏，取决于谁的延迟更小、更可预测；而真正破坏协作的不是「慢」，是「不同步」（skew）。
>
> 核心命题：**把「延迟」从要消灭的误差变成要分配的资源；把「双臂」从两个独立策略变成一个带契约、可换权威、并在延迟管上认证的耦合体。** 命名 **DUET-RAS**（Dual-arm Uncertainty-aware Epistemic coordinaTion with latency-adaptive tempo）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们谁先动、谁跟谁、快慢怎么对齐**」——协作不是两个闭环并排，而是一首有人领奏、有人伴奏、必须共用一个 tempo 的二重奏。

## 0. 直觉与动机

**灵感 1（双臂 → 耦合让不确定性「相乘」）**
直觉：单臂的不确定度可以加和平均；但两只手共持一个杯子时，任一只手的 1cm 误差都可能变成整对的滑脱或内力尖峰。耦合约束 M_c 是一个**放大算子**：它把一个臂的局部不确定性映射成整对的违规风险。R69 的 U_ale/U_epi 是「我该做什么」的不确定性；R70 必须新增「**我们能否一起做**」的耦合不确定性 U_coord。更关键：双份传感**不等于**双份独立证据——两臂看的是同一个物体、受同一束光照、共享同一个标定误差，R69 的「k 个正交源一致」在这里可能被共模误差伪造。

**灵感 2（延迟 → 破坏协作的是 skew，不是慢）**
直觉：两个人一起抬桌子，如果都慢 100ms，桌子还稳；如果一个人慢 100ms、另一个不慢，桌子就歪。**同向同幅的绝对延迟可以被共同补偿；只有延迟差（skew）和抖动（jitter）才真正改变相对状态。** 这把这轮的关键量定死了：需要压的不是平均延迟，而是**skew 与关键路径**。延迟于是从敌人变成调度变量。

**灵感 3（角色不对称 → 对延迟不对称的正确利用）**
直觉：既然无法让两条流水线同时又快又深，就不要对称分配算力。让延迟更小、更可控的那条臂做**领奏（leader）**：快、浅采样、短视界、保守，并广播它的**计划**；让另一条臂做**伴奏（follower）**：可以深采样、多模态，但跟踪的不是 leader 的**滞后观测**，而是它**计划在未来执行时刻的状态**（时间扭曲跟踪）。leader 的深度采样直接进关键路径，follower 的深度采样在关键路径之外——因此**把不确定性预算往 follower 挪，在延迟上更划算**。这不是「让快的等慢的」，而是「让快的人定 tempo，慢的人预判着跟」。

**灵感 4（延迟管 → 安全必须对整个集合认证）**
直觉：由于延迟，执行时两臂的相对状态不是一个点，而是一个**集合**——相对陈旧管 R_rel。R69 的单臂证书只保证「每个臂在自己的名义轨迹上安全」；双人安全要求**在最坏的延迟实现下，相对状态仍落在耦合屏障内**。这就是组合证书问题：两个有效证书不自动组合成一对有效证书。缺的那条边，正是延迟。

**灵感 5（契约与权威 → 必须有可协商、无突变、防抖动的换手）**
直觉：谁领奏不是固定的：任务阶段会变（一方去够远物、另一方稳住），延迟画像会变（某臂推理负载升高），epistemic 歧义也会变（R69 的 AUD 报某臂看不清）。所以需要一个**契约**描述「当前谁领、耦合多紧、同步容差多少、允许多大 skew」，以及一个**带滞留时间的换权威协议**。没有它，系统会在两个角色间抖动（role flapping），或双方都让行而**死锁**。换手必须在「double-hold」状态下进行：两臂都能维持物体、相对速度近零——此时谁接管都不会产生跳变。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DUET-RAS 总览）** DUET-RAS = (DCC, LAT, TEMPO, LCC, CPC, RRA, SAI, LAC, EDC, VQAuditor-D, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **耦合证书优先**：任一执行周期，若延迟管上的耦合鲁棒证书（定义 317）不成立，则不得执行任何改变相对状态的耦合动作，只能进入 safe-hold；
(iii) **权威唯一且可审计**：任一时刻恰有一个 leader（或显式 IND 模式）；换权威只在 double-hold 状态、满足滞留时间并留痕；
(iv) **证据去相关**：跨臂证据须先按共模相关 ρ_arm 折减为有效独立源 k_eff（定义 321），未折减者按单源计。

**定义 311（双臂协调契约 DCC）** 契约 C = (M_c, κ, role, L_max, τ_sync, t_swap)。M_c ⊂ 𝒳_A×𝒳_B 是协调流形（共享物体的相对位姿/内力/自碰撞可行集）；κ ∈ [0,1] 为耦合度（0=独立，1=刚性共持）；role ∈ {A→B, B→A, IND}；L_max 为契约允许的最大延迟不对称；τ_sync 为同步容差；t_swap 为上次换权威时刻。生命周期：propose → certify → run → (renegotiate | dissolve)。

**定义 312（延迟画像与陈旧管 LAT）** 臂 i 的端到端延迟 L_i = L_perc + L_infer + L_comm + L_act，给出均值、p99 与抖动。在最后一次已提交动作 u_i^{commit} 下，从 t 到 t+L_i 的可达状态集 R_i(t) 称陈旧管。相对陈旧管定义为
R_rel(t) = { (x_A, x_B) ∈ M_c : x_A ∈ R_A(t), x_B ∈ R_B(t), 二者满足共享物体的运动学 }。
**注**：R_rel 不是 R_A×R_B 的笛卡尔积——共享物体把两者耦合在一起，这正是 R69 单臂分析漏掉的。

**定义 313（延迟诱导的相对不确定度 U_lat）** 设两臂各自以延迟 L_A、L_B 跟踪同一名义轨迹 x*(t)，一阶展开得相对误差
e_rel(t) ≈ (L_B − L_A)·ẋ*(t) + J_obj^{-1}δ_c，
其中 δ_c 为共享物体建模误差。故 U_lat 主要由 **skew ΔL = |L_A−L_B|、其抖动 dΔL/dt、以及通信延迟 L_comm** 决定，而与两臂共同的平均延迟几乎无关。这是本轮的**尺度分离**：把「慢」和「不同步」分开，预算只花在后者上。

**定义 314（协调不确定度复合 U_coord）** 在 R69 的 (U_ale, U_epi) 之外新增 U_lat、U_partner（对伙伴角色/意图的估计不确定）、U_cm（无法通过互证消除的共模感知不确定）。耦合风险不做简单加和，而定义为
U_coord = E_{(x_A,x_B)~R_rel}[ C(x_A,x_B) ]，
其中 C 为耦合代价（内力越界 / 自碰撞 / 滑移 / 同步越界）。这体现「相乘」：任一只臂的局部不确定都可能经 M_c 放大成整对违规。

**定义 315（TEMPO 联合编排器）** 在联合实时预算 B_pair 下选
(role, K_A, K_B, H_A, H_B) = argmax [ Info_gain − λ_c·C_pair ]，
s.t. L_cp(role) ≤ deadline 且 skew^{p99} ≤ L_max 且 role 与延迟/歧义一致。
硬性结构约束：**leader 必须 K 小、H 短**（它定义 tempo）；**follower 可 K 大、H 长**（它在关键路径外，用预测换深度）。这把 R69 的「自适应 K」从单臂统一升级为**跨臂非对称分配**。

**定义 316（领奏-伴奏分解与时间扭曲跟踪 LCC）** leader 提交并广播**计划** π_L(t:t+H_L)（不是观测）；follower 在自身执行时刻 t+L_F 跟踪 leader 的**预测状态** x̂_L(t+L_F) = f_pred(π_L)，即沿时间轴超前跟踪。跟踪误差 e(t) = ‖x_F(t) − x̂_L(t)‖。预测视界受约束 L_pred ≤ L_max：超过后预测误差超出同步容差，必须换契约或进 safe-hold。

**定义 317（耦合鲁棒屏障 CPC）** 定义耦合屏障 h_c(x_A,x_B|C) ≥ 0，同时编码：相对位姿 ∈ M_c、内力 ∈ [f_min,f_max]、无自碰撞、同步误差 ≤ τ_sync。延迟鲁棒版本要求
min_{(x_A,x_B) ∈ R_rel(t)} h_c(x_A,x_B|C) ≥ ε_c > 0，
即在最坏延迟实现下仍安全。与 R69 的 C-RAS-WM 不同：后者认证单臂前缀，前者认证**相对状态集合**。

**定义 318（权威再协商 RRA）** 换权威触发：skew^{p99} > θ_skew、leader 的 U_epi 高（R69 定义 297）、leader 的 FMA 报慢变故障（R69 定义 301）、或任务阶段切换。换权须处于 double-hold 状态（两臂均可维持物体且相对速度 < ε_v），并满足滞留时间 T_dwell 以抑制角色抖动。若无法进入 double-hold ⇒ 维持原角色并降速，禁止强行换手。

**定义 319（共享主动信息 SAI）** 信息动作由任一只臂执行、可能降低**伙伴**的不确定度：g = (g_exec, g_beneficiary)。团队 VoI 为
VoI_pair(g) = H(M|o) − E_{y~p(·|g,o)}[H(M|o,y)]，
其中 M 是契约双方**共同**的模态/意图变量；成本 c_pair(g) 含对整对 tempo 的占用。选 g* = argmax[VoI_pair − c_pair]，并须过契约与 CPC 认证；无利可图 ⇒ 双臂均走 R69 兜底。

**定义 320（延迟预算与关键路径 LAC）** 定义**关键路径延迟** L_cp = L_L + L_comm + L_track（不是 max，因为 follower 依赖 leader 的计划）。约束 L_cp ≤ deadline。系统维护**延迟账本**：每次推理/通信/等待都记账；超支则降 K 或降 H，绝不超 deadline 执行耦合动作。

**定义 321（跨臂证据去相关 EDC）** 两臂共享物体与场景，证据相关 ρ_arm 通常远大于 0（共模光照、同一本体标定误差、共享物体上的力传导）。R69 的 k-源一致纪律替换为**有效独立源数**
k_eff = k / (1 + (k−1)ρ_arm)，
投毒/共模上界相应变为 δ_p·ρ^{k_eff−1} + ε_σ。当 ρ_arm → 1，k_eff → 1，双份观测退化回单源——**冗余 ≠ 独立**。

**定义 322（DUET 威胁模型 ℰ_duet）** 延迟注入/抖动攻击、角色劫持（迫使错误臂领奏进入坏构型）、共模欺骗（对两臂同时施加同一物理扰动以「互证」）、回声证据（伙伴只是复述你的错误）、死锁（双方都让行）、冻结（双方都等待）。并入 AIC：ℰ_DUET = ℰ_FLUID × ℰ_duet。

**定义 323（双人审计 VQAuditor-D）** 审计：换权威是否合规、是否出现单臂搭便车（free-riding）、相对状态是否滑出延迟管、跨臂证据是否被当成独立、是否发生角色抖动/死锁。结论回灌 AuditBuf，成为下一轮 TEMPO 的延迟先验与角色滞留先验。

**定义 324（证书 J_DUET）** J_DUET = (J_FLUID, contract_id, role, L_cp^{p99}, skew^{p99}, diam(R_rel), sync_margin, coupled_barrier_margin, role_swap_log_hash, k_eff, duet_ver)。Valid ⇔ Valid(J_FLUID) ∧ 延迟管鲁棒屏障成立 ∧ 权威唯一且换权合规 ∧ k_eff 达标。

**定义 325（三级退避与契约降级）** 正常 coupled → 松耦合 loose（κ↓，双臂各自跑 R69 但共享 tempo 时钟）→ 独立 IND（两条 R69 闭环，仅保留几何互避）→ safe-hold（各自静止并保持物体）。优先级：安全 > 同步 > 效率。任一级不满足即降级，绝不升级越过未认证的屏障。R69 = DUET 在 IND、κ=0、L=0 边界的退化。

**定义 326（证书组合律）** 两臂各自证书有效**不蕴含** J_DUET 有效；组合还需额外的耦合边证据：R_rel 上的屏障裕度与同步裕度。反之，J_DUET 有效 ⇒ 两臂各自证书有效（组合严格更强）。这是「组合 ≠ 求和」的形式化，也是本轮对 R69 最直接的修正。

# IP-265 LAT：延迟画像与相对陈旧管
class LatencyProfiler:
    def profile(self, arm):
        L = arm.trace_latency()                       # perc/infer/comm/act 分位
        return LatencyField(mean=L.mean, p99=L.p99, jitter=L.std)

    def stale_tube(self, arm, t):
        # 从最后已提交动作出发的可达集（区间/椭球过近似）
        return reachable_overapprox(arm.last_commit, t, self.L.p99)

    def relative_tube(self, tubeA, tubeB, obj):
        # 共享物体运动学把两个管耦合；不能取笛卡尔积
        return coupled_reachable(tubeA, tubeB, obj.kinematics)

# IP-266 TEMPO：联合角色 / K / H 编排（关键路径 + skew 约束）
def tempo_orchestrate(modesA, modesB, lat, budget):
    best = None
    for role in (LEAD_A, LEAD_B):
        for K_L in (1, 2):                            # leader：快、浅
            for K_F in (1, 2, 4):                     # follower：可深
                L_cp = lat.critical_path(role, K_L, K_F)
                skew = lat.skew_p99(role, K_L, K_F)
                if L_cp > budget.deadline or skew > budget.max_skew:
                    continue
                info = info_gain(modesA, K_L, modesB, K_F, role)
                score = info - cost(L_cp, skew)
                if best is None or score > best.score:
                    best = (role, K_L, K_F, score)
    return best                                       # 无可行解 → 降级（定义 325）

# IP-267 LCC：领奏提交计划；伴奏时间扭曲跟踪
def leader_commit(leader, plan):
    leader.broadcast_plan(plan)                       # 广播"计划"，不是观测
    return plan

def follower_track(follower, plan, L_F):
    x_hat = predict_state(plan, t + L_F)              # 跟未来，不跟滞后观测
    return follower.track(x_hat)                      # s.t. L_pred <= L_max

# IP-268 CPC：延迟管上的耦合鲁棒屏障
def coupled_certificate(tube_rel, contract):
    h = min(barrier(xA, xB, contract) for (xA, xB) in tube_rel)
    return h >= EPS_C                                 # 最坏延迟实现下仍安全

# IP-269 RRA：换权威（double-hold + 滞留时间，防抖）
def renegotiate(contract, state, audit):
    if not trigger(state, contract):
        return contract
    if not double_hold(state, contract):              # 无法安全换手
        return contract.downgrade()                   # 维持原角色并降速
    if state.t - contract.t_swap < T_DWELL:
        return contract                               # 角色抖动抑制
    return contract.swap_role(audit_log=True)

# IP-276 DUET 主闭环（继承 R69 FLUID）
def DUET_RAS_round(M, obsA, obsB, contract):
    # 1) 两臂各跑一次 R69 前端：前向 / 标定 / 歧义分解
    zA, UA = M.fluid_frontend(obsA)
    zB, UB = M.fluid_frontend(obsB)
    # 2) 延迟画像 + 相对陈旧管（不是两个单臂管的笛卡尔积）
    latA, latB = M.lat.profile(M.armA), M.lat.profile(M.armB)
    R_rel = M.lat.relative_tube(M.lat.stale_tube(M.armA, t),
                                M.lat.stale_tube(M.armB, t), M.obj)
    # 3) 联合编排：role / K_L / K_F，受关键路径与 skew 约束
    role, K_L, K_F = M.tempo.orchestrate(UA, UB, (latA, latB), M.budget)
    # 4) 领奏提交计划；伴奏按未来时刻时间扭曲跟踪
    planL = M.leader(role).propose(K=K_L, H=H_L)
    M.lcc.leader_commit(M.leader(role), planL)
    planF = M.lcc.follower_track(M.follower(role), planL, latF=latB)
    # 5) 对整个 R_rel 认证耦合屏障，而非对两条名义轨迹分别认证
    if not M.cpc.coupled_certificate(R_rel, contract):
        return M.safe_hold(contract)                  # 单调降级，绝不越界
    # 6) 团队信息动作（可选）：谁去消歧、收益归谁
    g = M.sai.choose_pair(UA, UB, contract, M.budget)
    if g is not None and M.cpc.coupled_certificate(M.lat.relative_tube(
            M.lat.stale_tube(M.armA, t), M.lat.stale_tube(M.armB, t), M.obj),
            contract):
        M.sai.execute(g)
    # 7) 换权威：仅 double-hold + 滞留时间
    contract = M.rra.renegotiate(contract, M.state, M.audit)
    # 8) 审计 + 证书
    M.vqa_d.submit_async(role, contract, R_rel, g)
    return planL, planF, contract, M.j_duet.pack()

## 3. 推导

**引理 19（skew 分离）** 设两臂均以延迟 L_i 跟踪同一名义刚体轨迹 x*(t)。一阶展开得 e_rel(t) ≈ (L_B − L_A)ẋ*(t)。故 **L_A = L_B（无论共同多大）⇒ e_rel ≈ 0**；相对状态误差只由 skew、skew 的时间导数与物体建模误差决定。系：延迟预算应优先压低 skew 与关键路径，压低平均延迟本身对同步几乎无收益。这是定义 313 的直接推论，也是把「慢」与「不同步」解耦的依据。

**引理 20（非对称编排支配对称编排）** 在 A99（follower 预测误差在 L_pred 内不超过同步容差）与 A100（leader 计划可被低带宽可靠广播）下，对固定 pair 预算，把采样深度从 leader 移到 follower 使 L_cp = L_L + L_comm + L_track 单调不增，而团队信息量单调不减（直至 L_pred 耗尽）；因此最优分配是**非对称的**，leader 取最小可行的 K_L、H_L。系：R69 的「双臂同参数自适应 K」在延迟上被支配——它把深度采样放到了关键路径上。

**引理 21（冗余 ≠ 独立）** 设 k 个证据源两两相关 ρ_arm，则等相条件下有效独立源数 k_eff = k/(1+(k−1)ρ_arm)。采用 k_eff 源多数一致纪律时，错误采纳率上界为 δ_p·ρ^{k_eff−1} + ε_σ。系：ρ_arm → 1 时 k_eff → 1，双份观测退化为单源。故双份传感买到的是**覆盖**（遮挡、可达），不是**去相关**；R69 的证据纪律必须显式折减，否则共模欺骗可伪造「一致」。

**引理 22（换手连续性）** 若换权威仅在 double-hold 状态（两臂均可维持物体且 ‖相对速度‖ ≤ ε_v）发生，则换手前后两条可行计划在 M_c 上的距离 ≤ ε_hold；配合 CPC 的屏障裕度，换手不产生超出容差的相对状态跳变。系：滞留时间 T_dwell 以有界的最坏响应延迟为代价抑制角色抖动，代价可由 TEMPO 显式计入。

**定理 18（DUET 严格包含 R69/FLUID）** 当 κ = 0（无耦合）、role = IND、L_comm = 0 且 ΔL = 0 时，DUET 逐指令退化为两条独立的 FLUID 闭环；其安全侧不做任何让步（CPC 退化为各自的 C-RAS-WM）。因此 R69 是 DUET 在「无耦合、无 skew」边界上的严格退化，DUET 是它的泛化而非替代。

**定理 19（延迟鲁棒协作安全与单调降级）** 若 R_rel 是真实相对可达集的可靠过近似，且 CPC 在 R_rel 上成立（min h_c ≥ ε_c > 0），则整个 [t, t+L_cp] 内执行的耦合动作不会使相对状态离开 M_c（前向不变性）。若任一层失败（管线不可靠、屏障失败、换手失败、deadline 超时），系统按 coupled→loose→IND→safe-hold 单调降级，且绝不升级越过未认证的屏障，故控制连续、无突变（R69 换装不变式的双人版）。

## 6. 本轮最大风险

**次级风险与缓解**：
1. **组合证书缺口**（两条单臂证书 ≠ 一对有效证书）→ 定义 326 显式要求耦合边证据 + CPC 在 R_rel 上认证；
2. **尾延迟 / 抖动低估** → LAT 用 p99 与在线分布更新 + 定理 19 的单调降级兜底；

5. **预测视界发散** → L_pred ≤ L_max 硬约束 + 超界即降级到 loose/safe-hold，绝不让 follower「自信地跟踪一个幽灵」。

## 4. 推导

**引理 19（skew 分离）** 两臂同追名义刚体轨迹 `x*(t)`，`e_rel(t) ≈ (L_B−L_A)ẋ*(t)`。故 `L_A=L_B`（无论共同多大）⇒ `e_rel≈0`；相对误差只由 skew、其抖动与物体建模误差决定。系：预算应压 skew 与关键路径，而非平均延迟。

**引理 20（非对称编排支配对称编排）** 在 A99–A100（预测误差在 `L_pred` 内不超同步容差、计划可低带宽广播）下，同样 pair 预算中把采样深度从 leader 移向 follower 使 `L_cp` 单调不增、团队信息量单调不减；最优分配非对称，leader 取最小可行 `K_L,H_L`。系：R69 的「双臂同参数自适应 K」把深采样放上关键路径，被支配。

**引理 21（冗余 ≠ 独立）** 两两相关 `ρ_arm` 的 k 源，`k_eff=k/(1+(k−1)ρ_arm)`；错误采纳上界 `δ_p·ρ^{k_eff−1}+ε_σ`。系：`ρ_arm→1` 时 `k_eff→1`，双份观测退化为单源；双份传感买的是覆盖，不是去相关。

**引理 22（换手连续性）** 仅在 double-hold（两臂均可持物且 `‖相对速度‖≤ε_v`）换权，则换手前后计划在 `M_c` 上距离 ≤ `ε_hold`，配合屏障裕度不产生超容差跳变；滞留时间以有界响应延迟的代价抑制角色抖动。

**定理 18（DUET 严格包含 R69/FLUID）** `κ=0 ∧ role=IND ∧ L_comm=0 ∧ ΔL=0` 时，DUET 逐指令退化为两条独立 FLUID；安全侧不让步（CPC→各自 C-RAS-WM）。R69 = DUET 的「无耦合、无 skew」边界。

**定理 19（延迟鲁棒协作安全与单调降级）** 若 `R_rel` 是真实相对可达集的可靠过近似且 `min_{R_rel} h_c ≥ ε_c>0`，则 `[t,t+L_cp]` 内不离开 `M_c`（前向不变性）；任一层失败则按 coupled→loose→IND→safe-hold 单调降级，绝不升级越过未认证屏障 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：DUET-RAS 的全部安全论证都押在「`R_rel` 是可靠的过近似、且 follower 对 leader 计划的预测不会悄悄发散」这两条上——**一旦尾延迟被低估或预测视界被悄悄越过，两条臂会在各自的证书里都显示「安全」，却在物理上同步地漂离 `M_c`，最终以一双「合格的」手臂把物体拉断或相撞；certify 的是一对，出事的是一对。**

**次级风险与缓解**：组合证书缺口（定义 326 要求耦合边证据 + CPC 在 R_rel 上认证）；尾延迟/抖动低估（LAT 用 p99 + 在线更新 + 定理 19 兜底）；角色抖动与死锁（RRA 的 double-hold + 滞留时间 + VQAuditor-D）；共模与回声证据（EDC 的 k_eff 折减 + 定义 310-iv + E308）；预测视界发散（`L_pred≤L_max` 硬约束，超界即降到 loose/safe-hold，绝不让 follower 自信地跟踪一个幽灵）。
