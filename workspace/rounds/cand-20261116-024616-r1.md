# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「异常检测」×「最优控制」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**残差自适应 + 约束最优 + 单向棘轮**。两个灵感分别治理 v9 的两笔遗留债：**枚举债**（所有退化触发器都是"已命名故障"的阈值谓词，未命名故障无处安放）与**证书债**（块证书的安全性依赖长时域前向模型的准确度，而模型恰恰在域偏移时最不准）。新组件同样遵循中立元退化纪律：任一环节不可用 ⇒ 退回 v9 行为（引理 92），绝不行为漂移。

## 0. 直觉与动机

### 灵感 1（异常检测 → 把"未命名故障"变成单向收紧）

直觉：v9 的安全护栏是一张**封闭的故障清单**——DA 域偏移、SPR SLAM 风险、Cal 标定失配、块证书失效……每个都对应一个手写阈值。清单之外的真实故障（某个传感器通道以未曾设想的方式退化、或多种轻故障叠加出清单里不存在的组合）在结构上"无处安放"，只能靠运气落入某个现有谓词。异常检测的价值不是"再训练一个更好的分类器"，而是给系统一条**面向未知的保守化通道**。

关键观察：v9 已经免费生产了最好的异常信号——**块证书残差** `r(t)=实际指标−预测指标`。它不是分类器输出，而是"模型对世界的承诺"与"世界实际兑现"之间的差。这个残差的检测时延是 **1 个控制周期**，而 DA-ML 的 `Δ_dom` 是 20 帧滑窗。也就是说，v9 最大的风险（"最需要安全的时刻暴露最不可靠的证书"）恰好在残差通道里**立刻可见**。

但异常检测天性是"会误报、给不出保证"。所以核心设计不是让它去操纵执行器，而是让它只做一件事：**单向棘轮**。异常分数 `α(t)` 只能沿退化格点朝更保守方向拧紧（缩短块长、放大 β、收紧阈值、唤醒休眠模块、放大鲁棒裕度），永远不能反向放松。这样，误报的代价是"更保守"，漏报的代价是"退回 v9 已有的护栏"，都不产生新的不安全行为。这就是 **P13 异常单向棘轮律**。

### 灵感 2（最优控制 → 把"赌长时域预测"换成"逐拍前向不变"）

直觉：v9 的块生成是采样 MPC（n=64）＋事后证书＋中止点集。它的安全论证本质上在**赌**：赌信任域内前向模型误差 ≤ β 且整块都不越界。模型一错，证书就假；中止点只是在错误发生后再补救。

最优控制提供两件更硬的东西：
1. **控制屏障函数（CBF）安全滤波器**：每拍解一个最小干预 QP，把名义动作投影到由屏障 `h_j(s)≥0` 定义的安全集切空间上。它只要求**一步**屏障动力学有界误差，而不是整块的长时域准确；给出的是**连续时间前向不变性**（帧间也安全），而不是"逐拍采样点看起来安全"。
2. **带认证终止集的滚动时域 OCP**：把 v9 的评分采样升级为带终端约束的有限时域最优控制，用 LQR 不变椭球做终止集，得到**递归可行性**——每拍都能解出可行解，而不是"这次刚好采样到一个可行候选"。

更妙的是，最优控制的**代价函数**天然就是 MetricVoiceGauge 的立身之本：`J = Σ_i w_i(t)·ℓ_i`，其中 `w_i(t)` 是 5 维情感 MetaWeight。**人类偏好塑造代价，CBF 守住硬安全**——这才是"指标之声"与最优控制的正当联姻，而不是把情感当成又一个加权超参。

### 两个灵感在哪里合流

异常检测估计"模型现在有多不可信"（α），最优控制需要"扰动上界 ε_w"来做鲁棒约束。于是让 `ε_w(t)=ε0+ε1·α(t)`、管半径 `ρ(α)`、终端集 `Ω(α)` 随 α 单调收缩：**异常检测在线标定最优控制的鲁棒裕度**。这正好补上 v9 的漏洞——即便 DA-ML 的 20 帧滑窗还没反应过来，残差通道已经把 α 顶上去，CBF 约束随之收紧，安全性不再等待滑窗。

## 1. 研究问题（轮次升级版）

- **Q1（未知故障的保守化）**：如何构造异常分数 `α(t)`，使其在"未命名故障"下单调收紧安全包络、而在无误报时严格等于 v9？能否用保形（conformal）方法给出分布无关的假警率上界，并诚实刻画其在分布偏移下失效的条件？
- **Q2（帧间与延迟下的 CBF 安全）**：在 50Hz 采样、0–20ms 计算/输入延迟、有界扰动下，鲁棒离散 CBF 能否保证帧间前向不变？屏障 `h_j` 的模型误差如何被残差/异常分数在线放大成鲁棒裕度，而不陷入"用坏模型证明坏模型"的循环？
- **Q3（代价—安全的分层）**：如何用 5 维情感 MetaWeight 定义 OCP 代价，同时保证 CBF 硬约束永不被代价软化？认证终止集的存在性与异常门控收缩能否同时保住递归可行性？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 异常单向棘轮律（Monotone Anomaly Ratchet, RAD）**
异常分数 `α(t)∈[0,1]` 只能通过单调映射 `R` 收紧安全包络：α 增大 ⇒ `K_eff` 不增、`β` 不减、鲁棒裕度 `ε_w` 不减、休眠模块被唤醒、阈值 `τ` 只向保守方向移动。`R` 是"只紧不松"的偏序映射；`α=0` 时 `R` 为恒等，系统逐位等价 v9。异常检测不允许直接产生执行动作。

**P14 逐拍前向不变律（Per-Tick Forward Invariance, CSF）**
对每个硬约束 j 定义屏障 `h_j(s)≥0` 与安全集 `C_j`。每个控制拍解最小干预 QP：`a*=argmin‖a−a_nom‖²_W` s.t. 鲁棒 DCBF（含扰动界 `ε_w(α)` 与延迟余量）与执行器限幅。若名义动作已安全，则 `a*=a_nom`（恒等）；若 QP 不可行，则切最大减速度急停 `a^⊥`（与 v9 中止语义一致）。安全性以一步屏障 + 连续时间延拓保证，不依赖长时域预测。

**P15 偏好—安全分层律（Preference-Safety Stratification, ATMPC）**
OCP 代价 `J=Σ_k Σ_i w_i(t)·ℓ_i(z_k,a_k)+V_f(z_K;α)` 由 5 维 MetaWeight 加权；硬安全只以 CBF/终止集约束形式进入，代价不得以任何罚因子"买通"硬约束。终止集 `Ω(α)` 由 LQR 不变椭球构造并随 α 单调收缩；异常门控管半径 `ρ(α)` 与 `ε_w(α)` 同源。

## 3. 与基线的接口（如何退化）

- RAD 失效（残差样例不足 / 分布检验不可算）⇒ `α≡0` ⇒ 棘轮恒等 ⇒ 鲁棒裕度回到 v9 的 β，行为等价 v9；
- CSF 失效（QP 求解器超时 / 屏障模型不可用）⇒ 旁路滤波器，直接执行 `a_nom`，等价 v9 的块动作 + v9 中止点语义；
- ATMPC 失效（OCP 求解失败 / 终止集构造失败）⇒ 退回 v9 采样 MPC（IP-354 原样）；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 定义 536 注入中立元，等价 v8；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9 → v8 → v7 → v6。

## 4. 预期贡献

1. **残差驱动的未知故障保守化**：用系统自产的块证书残差做 1 拍时延的分布无关异常检测，把"未命名故障"安全地编码为单向收紧，附保形假警率保证（引理 91）；
2. **异常门控鲁棒 CBF**：把异常分数在线翻译成扰动界与管半径，给出帧间、延迟、有界扰动下的前向不变性（引理 88、90），直接封堵 v9"最需要安全时证书最不可靠"的漏洞；
3. **偏好加权约束最优**：5 维情感 MetaWeight 作为 OCP 代价、CBF 作为不可软化硬约束，实现"人类偏好塑造成本、物理安全守住底线"的分层；
4. **可验证的退化代数**：三个新模块各自关闭都逐级退回 v9（引理 92），安全论证不被新模块稀释；E571–E590 覆盖检测时延、假警校准、帧间安全、延迟鲁棒、递归可行、退化等价与端到端。

## 5. 本轮最大风险

**一句话**：异常检测只能看见它被接上的通道、CBF 只能约束屏障里写下的状态维度——若真正的危险来自一个未被观测/未被建模的维度（遮挡、未标定轴、未入屏障的约束），那么残差不会大、α 不会升、h 也不会被违背，系统会在"检测器和屏障都 unanimous 地说安全"的情况下失效，即"最危险的未知恰恰是双重盲区"。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |

| `p_t` | 残差通道保形 p 值 |

| `R(α)` | 风险棘轮：单调收紧映射，坐标为 `(K_eff, β, τ_safe, ε_w, W(α))` |
| `h_j(s), C_j` | 第 j 个屏障函数与安全集 `C_j={s:h_j(s)≥0}` |

| `L_j` | `h_j` 对扰动的 Lipschitz 常数 |

**新增定义 540（闭环残差 ResidualChannel）** 令 `m^act(t)` 为本拍实际测得的指标向量，`m^pred(t)` 为 v9 块证书 `Ĉ_t` 或前向模型 `F̂` 对同一拍的预测，则 `r(t)=m^act(t)−m^pred(t)`。检验统计量取分量标准化后的单侧最大值：
```
T(r) = max_i  r_i / σ_i        （σ_i 为校准集残差标准差，i∈M₁..M₃）
```
在信任域 `U_t` 内、`α=0` 运行期采集名义校准集 `R0 = {T(r_s)}_{s=1..n}`。残差通道的核心价值：`Δ_dom` 需要 20 帧滑窗（≈400ms@50Hz）稳定判定，而 `T(r)` **在违约发生后的第 1 拍**即可非零。

**新增定义 541（异常分数 AnomalyScore）** 两通道并行、取保守合成：
- **残差保形**：`p_t = (1 + #{T(r_s)∈R0 : T(r_s) ≥ T(r_t)}) / (n+1)`，`α_res = 1 − p_t`；
- **流形新颖度**：在 `z(t)` 上用冻结编码器 `φ` 的 kNN 距离 `d(z)`，其在名义集上的保形 p 值 `p^novel`，`α_man = 1 − p^novel`；
- **合成**：`α(t) = (1−η)·α(t−1) + η·max(α_res, α_man)`，`η=0.2`（5 拍平滑）。
两通道互补：残差抓"模型承诺违约"，流形抓"输入分布出流形"。`α` **只**进入棘轮 `R`，不产生任何执行指令。

**新增定义 542（风险棘轮 RiskRatchet）** `R:[0,1]→Θ` 为逐坐标单调映射，令 `s=1−α`：
```
K_eff ← max(1, ⌊K_eff^v9 · s⌋)          β ← β0 / (s+ε)
τ_safe ← τ_safe^v9 · s                   τ_dom ← τ_dom^v9 · s
ε_w ← ε0 + ε1·α                          W(α) = {m : α ≥ θ_m}（唤醒集，单调增）
```
单调性：`α1≤α2 ⇒ Θ(α2)` 的可行动作集 `⊆ Θ(α1)`（只紧不松）；`α=0 ⇒ R=Id`（恒等）。

**新增定义 543（屏障函数族 BarrierFamily）** 仅对**控制仿射**硬约束建屏障：
```
h_clear(s) = dist(s,O) − d_safe          （间隙）
h_eff(s)   = τ_eff − ‖u‖                 （力/能耗）
h_grasp(s) = margin_grasp(s)             （抓取稳定裕度）
C_j = {s : h_j(s) ≥ 0},  j ∈ J = {clear, eff, grasp}
```
非控制仿射风险（`Δ_dom`、`risk_SLAM`）不入屏障，仍由 v9 阈值与棘轮 `R` 处理（此边界是诚实的，见第 8 节风险）。

**新增定义 544（鲁棒离散 CBF RobustDCBF）** 对 `x_{k+1}=f(x_k)+g(x_k)a_k+w_k`、`‖w_k‖≤ε_w`，对每个 `j`：
```
h_j(x_{k+1}) ≥ (1−γ_j)·h_j(x_k) − L_j·ε_w
```
一阶展开 `h_j(f+g a) ≈ h_j(f) + L_g h_j·a` 化入 QP，二阶余项并入 `ε_w`。输入延迟 `d` 用 `d` 步预测状态代入，或把 `d·‖ḣ‖` 并入 `ε_w`（delay-aware DCBF）。

**新增定义 545（最小干预安全滤波 SafetyFilterQP）**
```
a* = argmin_{a∈A}  ½‖a − a_nom‖²_W
     s.t.  L_g h_j · a ≥ −γ_j h_j(x) − (h_j(f(x))−h_j(x)) − L_j·ε_w(α),  ∀j∈J
           a_min ≤ a ≤ a_max
```
**硬约束、无松弛**（P15）：若 `a_nom` 已满足全部约束，则 `a*=a_nom`；否则 `a*` 是 `a_nom` 在约束多面体上的 W-加权投影（偏离最小）。若 QP 不可行 ⇒ `a*=a^⊥`（最大减速度急停），与 v9 中止语义一致。

**新增定义 546（偏好加权代价 AffectWeightedCost）**
```
J(a^{1:K};s) = Σ_{k=1}^{K} Σ_{i∈M} w_i(t)·ℓ_i(z_k,a_k) + V_f(z_K;α)
```
`w_i(t)` 为 v8 定义 495 的 5 维 MetaWeight 投影到指标层；`ℓ_i` 为归一化指标偏差 + 控制代价；`V_f` 为终端代价。**安全不进入 J、只进入约束**——代价无法"买通"硬约束。

**新增定义 547（认证终端集 CertifiedTerminalSet）** 在参考点线性化得 `(A,B)`，解 LQR（DARE）得 `P`，令误差 `e=z−z_r`：
```
Ω(α) = { e : eᵀ P e ≤ c(α) },   c(α) = c0·(1−α)²
c0 = 满足全部约束的最大椭球缩放（沿各约束方向最小化）
```
`Ω(α)` 对终端控制器 `z^+=(A−BK)z` 前向不变；`α` 增大 ⇒ 缩放单调收缩，故 `Ω(α2)⊆Ω(α1)`，收缩后仍不变。

**新增定义 548（异常门控管 AnomalyGatedTube）** 管半径 `ρ(α)=ρ0+ρ1α`；名义轨迹以 `ρ(α)` 膨胀后再施加约束（tube MPC），保证真实轨迹 ∈ 名义轨迹 ⊕ `ρ(α)`。`ε_w(α)` 与 `ρ(α)` 同源（同一 α），避免"两套互不一致的鲁棒裕度"。

**新增定义 549（假警预算与驻留 FalseAlarmBudget）** 保形 e-value 构造检验鞅 `M_t`，Ville 不等式给出 `P(∃t: M_t ≥ 1/δ) ≤ δ`（可交换性下）。棘轮带驻留计数：收紧需持续 `h` 拍、放松需持续 `h'` 拍（`h'≫h`），防止收紧/放松抖振；且放松永不超过 `α=0` 的 v9 包络。

## 2. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v8/v9：`M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM)` 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v8；新增用途——作为 OCP 代价权重（定义 546）。
**定义 496（软证书，v10）** 在原五条件上增加第六条件 "`α < τ_α`"：`δ_trigger = {σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM ∧ Ĉ_t valid ∧ α<τ_α}`。因 `α` 与棘轮只收紧，第六条件只会让 δ_trigger **更易**触发 M₀ 硬检查，绝不放松。
**定义 531（软硬约束衔接，v10）** M₀ 硬检查增加三入口：`原判据 ∨ CBF违例 ∨ α≥τ_α`，保证"屏障/异常"与"硬层"之间无空洞。
**定义 539（K_eff，v10）** 被棘轮复合：`K_eff(t) = R_K(K_eff^{v9}(t), α(t))`，其中 `R_K` 单调不增。

**注（检测时延对比）** DA-ML 的 `Δ_dom` 需要 20 帧滑窗才能稳定判定；残差通道的 `α_res` 在违约后第 1 拍即可非零。这并非说 DA-ML 无用——DA 检测"输入分布变化"（先兆），残差检测"模型承诺违约"（落实），二者互补：先兆给预警，落实给证据。

# IP-357 ResidualAnomalyDetector：残差异常检测器
class ResidualAnomalyDetector:
    def __init__(self, calib_T, manifold_scorer, delta=1e-3, eta=0.2):
        self.R0 = sorted(calib_T)          # 名义残差统计量校准集
        self.phi = manifold_scorer          # 冻结编码器 + kNN + 保形校准
        self.delta, self.eta = delta, eta
        self.alpha_hat = 0.0

    def _conformal_p(self, T):
        n = len(self.R0)
        ge = sum(1 for t in self.R0 if t >= T)
        return (1 + ge) / (n + 1)

    def score(self, r, z, sigma):
        T = max(r[i] / sigma[i] for i in range(len(r)))     # 定义 540
        a_res = 1.0 - self._conformal_p(T)
        d = self.phi.knn_dist(z)
        a_man = 1.0 - self.phi.conformal_p(d)               # 定义 541
        a = max(a_res, a_man)
        self.alpha_hat = (1 - self.eta) * self.alpha_hat + self.eta * a
        return self.alpha_hat


# RiskRatchet：α 的单调收紧（只紧不松）
def ratchet(alpha, cfg):
    s = max(1e-6, 1.0 - alpha)
    return dict(
        K_eff   = max(1, int(cfg.K_eff * s)),
        beta    = cfg.beta / s,
        tau_safe= cfg.tau_safe * s,
        tau_dom = cfg.tau_dom * s,
        eps_w   = cfg.eps0 + cfg.eps1 * alpha,
        wake    = {m for m, th in cfg.wake_th.items() if alpha >= th})


# IP-358 CBFQPSafetyFilter：逐拍最小干预
class CBFQPSafetyFilter:
    def __init__(self, barriers, gamma, L, eps0, eps1):
        self.h, self.gamma, self.L = barriers, gamma, L
        self.eps0, self.eps1 = eps0, eps1

    def filter(self, s, a_nom, alpha, lb, ub):
        eps = self.eps0 + self.eps1 * alpha              # 异常门控扰动界
        rows = []
        for j, hj in enumerate(self.h):
            h0 = hj(s)
            Lf, Lg = hj.lie_derivs(s)                    # h(f(s))-h(s) 一阶, L_g h
            b = -(self.gamma[j] * h0 + Lf + self.L[j] * eps)   # 定义 544/545
            rows.append((Lg, b))                         # 约束 Lg·a >= b
        try:
            a = solve_qp_min_norm(a_nom, rows, lb, ub)   # min ||a-a_nom||_W^2
        except Infeasible:
            return self.emergency_stop(s), False         # a^⊥
        return a, True


# IP-359 AffectWeightedTubeMPC：偏好加权管 MPC
class AffectWeightedTubeMPC:
    def __init__(self, model, lqr, horizon=10):
        self.f, self.lqr, self.N = model, lqr, horizon

    def solve(self, s, weights, alpha, cfg):
        rho   = cfg.rho0 + cfg.rho1 * alpha              # 定义 548
        Omega = self.lqr.invariant_ellipsoid(scale=(1 - alpha) ** 2)  # 定义 547
        def cost(z, a):
            return sum(w * li(z, a) for w, li in zip(weights, self.ell))
        return ocp_solve(self.f, s, self.N, cost,
                         tube=rho, terminal=Omega,
                         cbf=self.hard_cbf(cfg), bounds=cfg.act_bounds)  # 定义 546

## 4. 推导

**引理 87（异常单向棘轮的安全单调性）** 设 `α1≤α2`。由定义 542，`R` 各坐标单调（`K_eff` 不增、`β` 不减、`τ_safe/τ_dom` 不增、`ε_w` 不减、`W(α)` 不减），故在 `Θ(α2)` 下可行的动作集是 `Θ(α1)` 下的子集。异常分数只经 `R` 进入系统、不直接产生动作，因此任意异常轨迹下的可达状态集 ⊆ `α=0`（v9）对应结构下的可达集；且 `α=0 ⇒ R=Id` ⇒ 逐位等价 v9。故误报只致保守、漏报退回 v9 已有护栏，二者都不会产生新的不安全行为。∎

**引理 88（鲁棒 DCBF 前向不变性与帧间安全）** 若对所有 `j,k` 满足定义 544 的鲁棒 DCBF，且真实扰动 `‖w_k‖≤ε_w`，则安全集 `C=∩_j C_j` 前向不变：`h_j(x_{k+1}) ≥ (1−γ_j)h_j(x_k) − L_jε_w + L_jε_w = (1−γ_j)h_j(x_k)` 在 `ε_w` 覆盖真实扰动时非负。结合 `h_j` 的 Lipschitz 连续性，对 `t∈[t_k,t_{k+1})` 的连续时间亦不破（帧间安全），弥补 v9 只在采样点取证的缺口。输入延迟 `d`：用 `d` 步预测状态代入，或把 `d·‖ḣ‖` 并入 `ε_w`。∎

**引理 89（最小干预恒等性）** 目标 `½‖a−a_nom‖²_W` 严格凸。若 `a_nom` 落在可行多面体内，则无约束极小即 `a*=a_nom`；若不在，则 `a*` 是 `a_nom` 在约束多面体上的 W-加权欧氏投影，即最小偏离安全修正。因此 CSF 不改变任何已安全的名义动作，在安全运行时与 v9 块动作逐位一致。∎

**引理 90（异常门控管的递归可行性与 ISSf）** 若 `ε_w(α)` 覆盖真实扰动（w.p. `1−δ`，由引理 91）、`z_K∈Ω(α)`、且 `Ω(α)` 对终端控制器前向不变，则滚动时域 OCP 每步可行（标准 MPC 递归可行性）；闭环满足 input-to-state safety：安全裕度下降被管半径 `ρ(α)` 吸收，`h_j ≥ −ρ(α)` 而非无界。`Ω(α)`、`ε_w(α)`、`ρ(α)` 关于 α 单调，故异常越大越保守且始终可行。**注**：α 骤升可能使 OCP 暂时不可行，这正是 CSF/急停兜底的场景（L-B 退化）。∎

**引理 91（分布无关假警控制）** 在可交换性下，保形 p 值满足 `P(p_t≤δ)≤δ`；由保形 e-value 构造的检验鞅 `M_t` 满足 Ville 不等式 `P(∃t: M_t≥1/δ)≤δ`，故长期假警率 ≤δ（单通道）。双通道取 max 与 EMA 平滑会抬高实际上界，由 E572 标定修正。**失效条件**：分布偏移破坏可交换性时该上界不再成立；但残差通常增大使 α 偏保守（方向性安全）；真正的危险是"偏移使残差变小而危害落在未观测维度"（见第 8 节）。∎

**引理 92（全链退化等价）** RAD 关 ⇒ `α≡0` ⇒ `R=Id` 且 `ε_w=ε0`；CSF 关/不可行 ⇒ 执行 `a_nom`（v9 块动作）或 `a^⊥`（v9 中止）；ATMPC 关 ⇒ v9 采样 MPC。三者独立可关且各自退回 v9 对应层；组合后与 v9 ACMD 逐位等价（延拓引理 83 的中立元论证：α 的中立元为 0、滤波器的中立元为恒等、OCP 的中立元为 v9 采样）。∎

## 8. 本轮最大风险

**一句话**：异常检测只能看见它被接上的通道、CBF 只能约束屏障里写下的状态维度——若真正的危险来自一个未被观测/未被建模的维度（遮挡、未标定轴、未入屏障的约束），那么残差不会大、α 不会升、h 也不会被违背，系统会在"检测器和屏障都 unanimous 地说安全"的情况下失效，即"最危险的未知恰恰是双重盲区"。
