# 第 44 轮（新循环第 4 轮） · Fleet-Cert × Iter-Val：把「多机器人协作」与「迭代验证」纳入可验证证书闭环（五层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形仅边际覆盖 + 多用户契约求交为空」的静默失效与可用性崩塌。但它仍压着两个未言明的单点假设：**(H3) 认证对象是单机**——v20 的 rely-guarantee 只在单机任务族内部成立，多机器人被默认为「多个独立证书求交」，而真实协作会产生**联合动作、共享不变式与拓扑依赖**，这些东西既不是单机证书的并集，也不是它们的交集；**(H4) 验证是一次性判决**——Sim→CKB→部署被默认为单向门，「没找到反例」被当作证书；真实验证是**迭代循环**，每轮都在改变测试分布与假设，同一批反例被反复使用会**过拟合验证器**，产生「验证通过但从未采样到联合故障」的静默盲区。本轮灵感词「多机器人协作」「迭代验证」精确命中这两个假设：协作把证书从「机器人上的集合」升级为「拓扑图上的契约」；迭代验证把「验证」从一次性门禁升级为「带 anytime-valid 证据与审计独立性的收敛过程」。二者耦合处（分布式迭代验证）是真正的新问题：反例跨机传播有因果序与拜占庭污染，拓扑切换使验证分布漂移，契约求交可空与验证过拟合可能同时发生。

## 0. 直觉与动机

**灵感 1（多机器人协作 → 证书是图上的契约，不是机器人上的集合）**：单机证书 c_i 隐含了一句没说出口的 rely：「别的机器人不会撞我」。多机时这句话必须变成显式的邻居 guarantee：C_i 只在「j 保持 G_j」的环境假设下成立。更关键的是组合有两种模式：**求交（conjunction）**——共享工作空间、互斥区、相互避让，取交集天然安全但可能过保守甚至为空；**协同（synergy）**——两台机器人共同抬长物体、交接、互相稳定，能完成单机做不到的动作，此时「各自安全」既不充分（联合动力学可能失稳），也不必要（单机不可行但联合可行）。因此不能把协作简化成求交，也不能用并集放行。正确姿势是：**求交免费，协同持证**——交集永远 sound；协同扩张必须携带联合见证（力闭合、交接不变式、共享负载动力学），并走 v20 的认证扩张三重闸门。还有一个被 v20 完全漏掉的前提：**拓扑本身是证书假设**。通信边、角色分配、相对位姿图一旦变化，依赖它的证书立刻失效，因此给拓扑发**租约**，变更即失效（fail-closed），而不是让旧证书在陈旧的图假设上继续放行。

**灵感 2（迭代验证 → 反例是证据，不是否定；同一批证据不能花两次）**：一次性验证把「在我的有限样本里没找到反例」偷换成「没有反例」。迭代验证能补样本，但有两个陷阱：**(a) 自适应复用**——每轮用同一批反例修策略，再在同一批分布上验收，验证器被逐渐「喂熟」，通过率上升而真实风险不降（Goodhart / 验证漂移）；**(b) 债务隐藏**——预算耗尽就停止，没修完的罕见反例不计入结论。因此把验证形式化为带账本的迭代算子：**探索流**可以自适应地找反例、修证书；**审计流**必须预注册、独立、用完即焚（burn-after-use），只用于验收；停止条件不是「找不到反例」，而是「审计 e-process 在可选停止下拒绝坏假设 + 验证债务低于预算 + 证书哈希稳定」。一句话：**迭代可以增加证据，但不能把同一批证据花两次**。

**灵感 3（耦合 → 分布式迭代验证的敌人不是数据少，而是相关数据被当成独立证据）**：反例在机群中传播，会带来三个新问题：**(a) 因果序**——机器人 A 的「无违例」报告可能基于 B 更新前的旧证书，必须用向量时钟判定它是否 stale；**(b) 相关过拟合**——所有机器人共用同一仿真器、同一组种子、同一批对抗场景，反例高度相关，名义样本量 n 的有效样本量远小于 n，e-process 若按独立样本计算会过度自信；**(c) 拜占庭污染**——恶意/故障机器人可以伪造「无违例」投票或投毒反例。于是机群验收必须是：按拓扑/角色分层的审计、带签名与向量时钟的新鲜反例、对所有非故障机器人的联合拒绝（Bonferroni 控 FWER），分区时 fail-closed。**协作验证不是把各机证据相加，而是先证明这些证据彼此独立。**

**耦合升级**：FCC（机群契约组合器）把单机契约编译成拓扑图上的 assume-guarantee 契约，处理求交、协同见证、拓扑租约与不可行协商；IVE（迭代验证引擎）提供双流验证、anytime-valid 证据、验证债务与不动点/振荡检测；FVM（机群验证网格）负责反例的因果有序传播、分层审计、拜占庭鲁棒聚合与相关性折扣。四层架构由 v8/v9 的「单机证书栈」升级为 v10 的「单机证书栈 + **机群契约层** + **分布式验证层**」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（机群 assume-guarantee 契约与分层组合）**：设机器人集合 V={1..n}，拓扑 τ=(V,E,role,ρ)，ρ 为相对位姿/通信图。机器人 i 的局部契约 C_i=(A_i,G_i,E_i)：A_i 为允许动作/状态约束，G_i 为 guarantee（它保证邻居可依赖的证书谓词），E_i=⋀_{j∈N_τ(i)} G_j 为环境假设。若存在策略 π_i，使在 E_i 下所有可达状态满足 G_i 且动作 ∈A_i，则 C_i 可满足。机群契约 C_F=⊗_{i∈V} C_i。**循环 assume-guarantee 没有副条件是不健全的**，因此组合只允许以下两种之一：(a) **分层**——存在 ℓ:V→{1..m}，E_i 只引用 ℓ(j)<ℓ(i) 的 G_j；(b) **公共归纳不变式**——给出 J，使所有机器人保持 J 且 J⇒⋀_i G_i。**定理 44（组合 soundness）**：若 (a) 或 (b) 成立、拓扑租约有效、消息因果有序、各局部契约可满足，则任意交错执行保持 I_F=⋀_i G_i。证明按层归纳（或对 J 归纳），每层只依赖更低层的 guarantee，避免循环论证。

**定义 45（拓扑条件证书与拓扑租约）**：证书 c=(φ,h_τ,e_τ,d_exp,sig)，h_τ=H(τ) 为拓扑哈希，e_τ 为拓扑纪元，d_exp 为过期时刻。**有效判据**：h_τ=H(τ_now) ∧ e_τ≥epoch_now ∧ now<d_exp。**拓扑租约** ℓ_τ=(h_τ,e_τ,quorum,TTL)。**Fail-closed 命题**：若所有跨机守卫在使用 c 前检查 ℓ_τ，则拓扑变更后不存在用陈旧的邻居 guarantee 放行的动作。**代价**：分区/高 churn 下租约会集体过期，可能级联停机；缓解是为每个联盟预认证**降级后备契约**（单机安全模式、预设编队、冻结步态），使失效退回「少做」而非「乱做」。

**定义 46（联合动作证书、协同见证与联盟可行性）**：联合动作 a_S∈×_{i∈S} A_i。**求交证书** Adm^∧(a_S)=⋂_{i∈S} Adm_i(a_i)，天然 sound（只是收紧）。**协同证书** Adm^⊕(a_S)=Expand(Adm^∧,w_S)，w_S 为联合见证（力闭合、交接不变式、共享负载动力学、同步误差上界），扩张只能通过 v20 的「覆盖校准 + 影子证书 + 无回归」三重闸门。联盟 S 可行当且仅当 Adm_S≠∅。若为空，计算**最小不可行核** U⊆S（极小集合使 Adm_U=∅），并在让步格 (L,⊑) 上协商。**定理 46（协商终止与无静默放宽）**：若 L 有限、每次放松单调扩大可行集、操作员接受公平，则协商终止；若无让步被接受，返回「认证不可行」并安全停机/重分配任务，绝不静默放宽。**注**：「求交免费、协同持证」是 v20「收缩免费、扩张持证」在多机上的自然对偶。

**定义 47（迭代验证算子与验证债务）**：验证状态 V_k=(H_k,CE_k,A_k,D_k,h_k)：H_k 为当前证书/策略假设，CE_k 为探索反例集，A_k 为审计证据，D_k 为验证债务，h_k=H(H_k) 为证书哈希。**单调精化**：H_{k+1}=refine(H_k,CE_k)，只允许「收缩动作域」或「增加见证」，不允许在同一审计证据上静默放松。**验证债务** D_k=Σ_{ce∈open} w(severity,rarity,topology-coverage)，其中 rarity 按逆采样概率加权、topology-coverage 按该反例所在拓扑层的未覆盖率加权。**债务单调性**：只有「修复并重新审计通过」才能减债；把反例降优先级不算。**验收条件**：(i) 证书哈希连续 m 轮稳定；(ii) 审计流无新反例；(iii) e-process 拒绝坏假设；(iv) D_k≤D_max。**振荡检测**：若哈希在历史中回跳或出现不可比精化，冻结到上一个已认证证书，不继续自适应。

**定义 48（anytime-valid 证据与审计独立性）**：坏假设 H0 为「审计分布上机群违例率 ≥ p0」（或条件覆盖率 < 1−α）。令 X_t∈{0,1} 为审计违例指示，λ_t 为可预测下注比例，**e-process** e_t=∏_{s≤t}(1+λ_s(X_s−p0))。在 H0 下 {e_t} 为非负上鞅，Ville 不等式给出 P_{H0}(sup_t e_t≥1/α)≤α；当 e_τ≥1/α 时可拒绝 H0，结论是「审计分布上违例率 < p0」，**类型 I 错误 ≤α 且对可选停止有效**。**审计独立性**：lineage(A_k)∩lineage(CE_k)=∅；任何被用于修 H 的探索反例必须在审计流中「焚毁」，否则保证作废。**分层**：按拓扑层/角色/persona 分别维护 e-process，机群验收要求所有层联合拒绝（Bonferroni 或 e-value 交集）。**诚实边界**：这不是分布无关的安全证明，只是相对于预注册审计分布与可交换性假设的统计证书；分布漂移时先用 CUSUM/密度比检测并重置校准窗。

**定义 49（分布式反例因果序与鲁棒机群验收）**：反例事件 ce=(id,reporter,VC,h_cert,h_τ,payload,severity,sig)，VC 为向量时钟。**新鲜性**：ce 对当前证书哈希 h_cert 与拓扑纪元 h_τ 有效，且其 VC 不早于证书签发点；否则标记 stale，不得用于验收。**去重**：按 (h_cert, 轨迹指纹) 去重，避免同一反例被多机重复计数。**相关折扣**：有效样本量 n_eff=n/(1+(n−1)ρ)，ρ 为反例跨机相关系数估计；e-process 用 n_eff 而非 n 计算预算。**鲁棒验收**：机群接受要求所有非故障机器人的审计 e-process 拒绝坏假设；故障集 |F|≤f<n/3 时用签名日志与法定人数排除故障报告者；网络分区或拓扑租约过期时 fail-closed。**命题**：若每条验收证据都经因果新鲜性检查、相关性折扣与签名法定人数，则「陈旧反例 / 重复反例 / 单点伪造」不能单独把机群验收从拒绝翻成接受。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 FLEET-CONTRACT-COMPOSER（机群契约组合器 FCC）
1. **契约编译与分层检查**：把单机证书编译为 C_i=(A_i,G_i,E_i)，自动提取邻居 rely；检测循环依赖，要求分层或合成公共归纳不变式 J，否则拒绝组合。
2. **求交 / 协同双轨**：默认求交（免费 sound）；协同动作必须提交联合见证 w_S 并通过三重闸门，见证缺失则退回求交或触发协商。
3. **拓扑租约**：为每个拓扑纪元签发租约，守卫前置检查 h_τ/e_τ；变更即失效，预认证降级后备契约防级联停机。
4. **不可行协商**：联盟契约为空时输出最小不可行核 U 与让步格，交操作员/任务重分配，绝不静默放宽或无限停机。

### 2.2 IP-61 ITERATIVE-VALIDATION-ENGINE（迭代验证引擎 IVE）
1. **双流验证**：探索流自适应搜索反例并修证书；审计流预注册、独立、burn-after-use，只用于验收。
2. **Anytime-valid 验收**：按拓扑/角色分层维护 e-process，支持可选停止；报告「违例率 < p0」而非「零反例」。
3. **验证债务账本**：对未修复反例按严重度、稀有度、拓扑覆盖缺口计债；只有修复并重审通过才减债。
4. **不动点 / 振荡守卫**：哈希稳定 + 债务达标 + 审计拒绝才接受；出现回跳/不可比精化则冻结到上一个认证版本。

### 2.3 IP-62 FLEET-VALIDATION-MESH（机群验证网格 FVM）
1. **因果反例总线**：向量时钟 + 证书/拓扑哈希 + 签名，传播 stale/重复抑制；反例带来源与轨迹指纹。
2. **分层审计与相关性折扣**：按拓扑层/角色/场景分桶，估计跨机相关系数 ρ，用 n_eff 修正证据预算。
3. **拜占庭鲁棒验收**：法定人数排除故障报告者，非故障机器人联合拒绝；分区 fail-closed。
4. **反例多样化**：不同种子/拓扑/机体/负载的审计流配额，防止所有机器人共用同一盲区。

## 5. 本轮最大风险

**一句话**：机群的迭代验证极可能在**相关反例分布**上自证清白——所有机器人共用同一仿真器/种子/拓扑族，审计看似 anytime-valid 却从未覆盖「拓扑 churn 下的罕见联合动作」，叠加拓扑租约 fail-closed 的级联过期，可能同时出现「验证通过但联合故障未被采样」的静默失效与「集体停机」的可用性崩塌，因此 E98/E99（审计独立性与反过拟合）和 E96/E101（拓扑失效与联盟协商）必须设为红线。

### IP-60 FCC：机群契约组合、协同见证与不可行协商

def compose_fleet(robots, tau):
    C = {i: compile_local(robots[i].cert, tau, neighbors=tau.N(i)) for i in tau.V}
    # 循环 assume-guarantee 需要副条件：分层 或 公共归纳不变式
    if not stratified(tau, C):
        J = synth_common_inductive_invariant(C)
        if J is None:
            return Reject("circular-assume-guarantee")
    else:
        J = None
    lease = topology_lease(tau)                 # (h_tau, epoch, quorum, TTL)
    if not lease.valid(monotonic_now()):
        return Fallback(precertified_safe_mode(tau))   # fail-closed，少做
    C_F = fold(otimes, C.values())
    if C_F.empty():
        U = minimal_unsat_core(C)               # 极小冲突子集
        return Negotiation(U, concession_lattice(C))
    return C_F

def joint_certificate(S, action, witness=None):
    adm = intersect([admissible(i, action[i]) for i in S])   # 求交：免费 sound
    if witness is None:
        return adm                                             # 只保留保守交集
    if not triple_gate(witness):                               # 覆盖校准+影子+无回归
        return Reject("synergy-unwitnessed")
    return expand(adm, witness)                                # 协同：持证扩张

### IP-61 IVE：双流迭代验证、债务与任意时点有效验收
```
def iter_validate(H0, alpha, p0, D_max, explore, audit, m=3):
    H, debt, e, hist = H0, 0.0, 1.0, []
    for k in range(MAX_ROUND):
        CE = explore.search(H)              # 自适应：用于修证书
        H  = refine_monotone(H, CE)         # 只允许收缩动作域或增加见证
        debt = update_debt(debt, CE)        # 未修复反例计债；降优先级不减债
        x = audit.next(H)                   # 预注册、独立、burn-after-use
        e = e * (1 + lam(k) * (x - p0))     # lam 可预测；Ville 不等式
        hist.append(hash(H))
        accepted = (e >= 1/alpha) and (debt <= D_max) and stable(hist, m)
        if accepted:
            return StatAccept(H, e, debt)   # 统计接受，不是分布无关证明
        if oscillates(hist):
            return Freeze(last_certified(hist))   # 回跳/不可比则冻结
    return Reject("validation-debt-exhausted")
```

### IP-62 FVM：因果反例传播、分层审计与鲁棒验收
```
def propagate_ce(ce, vc_now, tau_epoch):
    if ce.h_cert != current_cert_hash or ce.h_tau != tau_epoch:
        return MarkStale(ce)                    # 陈旧反例不得参与验收
    if seen((ce.h_cert, ce.fingerprint)):
        return MarkDuplicate(ce)
    vc_now = merge(vc_now, ce.VC)
    return Publish(ce, vc_now, signature=verify(ce.sig))

def fleet_accept(per_robot_e, faulty, n, f, partition):
    if partition: return FailClosed()            # CAP：安全优先
    if len(faulty) > f or f >= n / 3:
        return Reject("byzantine-quorum")
    # 只聚合非故障、审计独立的机器人；各层 Bonferroni 控 FWER
    return all(e_i.rejects() for i, e_i in per_robot_e.items() if i not in faulty)

def effective_n(ce_list, rho_hat):
    n = len(ce_list)
    return n / (1 + (n - 1) * max(0.0, min(1.0, rho_hat)))   # 相关折扣
```

### IP-51/58 升级：拓扑守卫与分布式新鲜度
```
def fleet_guard(i, x, cert, tau, lease, neighbor_leases, t):
    theta = cert.alpha * cert.theta_sim
    if not lease.valid(t) or H(tau) != lease.h_tau:
        return False                                  # 拓扑失效即停，不用旧图
    for j in tau.N(i):
        if not neighbor_leases[j].valid(t):
            return False                              # 邻居 guarantee 不新鲜
    m_min = min(cert.m_lo, lease.m - lease.lam * (t - lease.tau))
    return m_min >= theta
```
