# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 1 轮；本轮灵感：「论文发表」×「面部表情识别」）

> 第 60 轮建立了「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知闭环（SSM×CIEC×EPIR×SERC×PCE++++）。但**三个更深的局限**仍未解决：
> 1. **证据「可检查」但不可复现**：EV-exec 只是一个*声明*（claim），第 60 轮只能事后检查其数值，却无法让第三方（或未来的自己）**重放并复现**这次执行——正如一篇没有代码与数据的论文，结论无法被独立验证。
> 2. **人类反馈只有显式对话，缺失隐式表情**：CIEC 依赖「请慢点」「轻触」这类**显式语言意图**；但人在观看机器人执行时的**皱眉、微笑、回避注视、微表情**是更早、更连续、更低带宽的反馈通道——它像「同行评审」，却更嘈杂、更易伪装（社交性微笑）。
> 3. **证据无版本、无撤回**：第 60 轮的证据链是「一次性」的；当后续证据与早前「已接受」的执行相矛盾时，系统没有机制**撤回（retract）**旧结论，也没有 v1→v2→v3 的修订谱系。

## 0. 直觉与动机

**灵感 1（论文发表 → 可复现执行出版包 REB）**
直觉：论文 = 声明 + 可复现材料 + 评审 + 版本史。执行证据也应如此：把 EV-exec 从「可检查的日志」升级为「**可复现的出版包**」——打包机器人型号、控制器版本、阻抗 K、场景先验、意图约束、随机种子、标定 ID、非确定性台账，使任何审计者能**重放**并核对声明。关键洞见：**可执行性（executability）是可复现性的新载体**——不是「看起来合理」，而是「重放后仍然成立」。

**灵感 2（面部表情识别 → 表情同行评审 FPR）**
直觉：人的脸是执行过程的**连续、低带宽、带噪评审员**：皱眉=关切/拒稿，微笑=接受，回避注视=不适，微表情=犹豫。把面部动作单元（AU）映射到**评审判决分布** v ∈ {accept, minor_revision, major_revision, reject}。关键洞见：**表情不是标签而是带混淆矩阵的噪声评审**——必须在设备端只提取 AU 特征（隐私），并用校准 + 弃权（abstain）处理低置信。

**灵感 3（同行评审 → 评审-申诉-修订 RRR）**
直觉：同行评审不是一锤定音：评审给意见，作者用证据**申诉（rebuttal）**，评审可能改判。机器人被「表情拒稿」时可展示证据、做低风险诊断探针，再据评审信号**修订**下一轮参数。关键洞见：**申诉必须受安全包络约束**——探针力 F_probe ≤ κ·F_safe，绝不用「证明自己安全」的方式去冒险。

**灵感 4（arXiv 版本 → 版本化证据账本 VEL）**
直觉：论文有 v1/v2/v3 与撤稿。执行也应如此：每次修订生成新的证据版本，记录 diff 与触发它的评审意见；后续矛盾可**撤回**旧版本并使依赖它的后代失效。

**灵感 5（合流 → 同行评审驱动执行出版闭环 PREPC）**
直觉：执行→打包 REB→观察表情评审→若拒稿则 RRR→修订→再执行→VEL 追加。把第 60 轮「认知闭环」再抬升一层：**执行不仅要安全，还要「可发表、可复现、可撤回」**。

**灵感 6（PCE++++ → PCE+++++ 评审预算）**
直觉：新增 B_fer（表情推断算力/时延）、B_rep（重放/复现成本）、B_rev（评审轮次）、B_dp（隐私预算，差分隐私 ε_dp）。任一耗尽即回退：B_fer 耗尽→放弃表情评审、仅用显式意图；B_dp 耗尽→只上传聚合统计；B_rep 耗尽→降级为「仅哈希审计」；B_rev 耗尽→转人工。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（可复现执行出版包 REB）** REB = (c, μ, τ, R, h, σ)。其中：
- **声明 c**：三元断言 c = (c_safe, c_eff, c_comp)，各带容差 ε = (ε_safe, ε_eff, ε_comp)；
- **清单 μ** = (robot_model, ctrl_version, K, π_scene, C_intent, seeds, calibration_id, env_hash, **非确定性台账 N**)，其中 N = (clock_skew_bound, msg_order_seed, sensor_noise_seed) 用于捕获 ROS 时序与传感器噪声；
- **轨迹 τ**：带时间戳的遥测序列；
- **重放函数 R**：R(μ, N) → c'（确定性重放）；
- **哈希 h** = SHA256(canonical(c, μ, τ))，**签名 σ**。
- **可复现度**：ρ(REB) = (1/|c|)·Σ_i 1[ |c'_i − c_i| ≤ ε_i ]。
- **可出版判定**：Publishable(REB) ⇔ h 校验通过 ∧ ρ(REB) ≥ ρ_min（默认 0.9）。

**定义 162（表情同行评审 FPR）** 评审模型 ρ_fer = (g_AU, C_rev, H_rev, τ_abstain)。其中：
- **设备端特征器** g_AU：图像 I_t → 动作单元向量 a_t ∈ R^{|AU|}，**原始帧不出端**；
- **判决域** V = {accept(+2), minor_revision(+1), major_revision(−1), reject(−2)}；
- **混淆矩阵** C_rev[v, v'] = P(预测 v' | 真值 v)，用温度标定 + 保序回归校准；
- **时序聚合** H_rev：在窗口 w 上以 HMM 后验 P(v | a_{t−w:t}) 聚合，转移矩阵刻画表情动态；
- **弃权**：v̂ = argmax_v P(v|·)，γ_rev = P(v̂|·)；若 γ_rev < τ_abstain（默认 0.6）则 **abstain**（不把低置信表情当评审）。
- **隐私**：只允许上传 AU 统计量，并满足 ε_dp-差分隐私，计入 B_dp。

**定义 163（评审-申诉-修订协议 RRR）** 状态机 S_rrr = (Q, Σ, →, q0, F)。其中：
- 状态 Q = {submit, review, rebut, revise, accept, reject, withdraw}；
- 收到 v̂ ∈ {major_revision, reject} 且 γ_rev ≥ τ_abstain → 进入 rebut；
- **申诉动作集** B = (E_display, D_probe)：E_display 展示 REB 证据；D_probe 执行低风险诊断探针，满足 **F_probe ≤ κ·F_safe（κ=0.3）** 且不改变任务目标；
- **修订**：θ_{k+1} = argmax_θ U_rev(θ; v̂, REB_k) s.t. θ ∈ K_safe（EEIS 安全域）；
- **终止**：accept，或轮次 > R_max（默认 3）→ 安全停机 + 升级人工；不得无限申诉。

**定义 164（版本化证据账本 VEL）** VEL = (V, E_ver, Φ)。其中：
- 节点 V = {REB_k}，边 E_ver ⊆ {(v_j, v_i)}，标签 ∈ {revision_of, supersedes, retracts}；
- 节点元数据：评审判决 v̂_k、可复现度 ρ_k、参数 diff δ_k；
- **撤回传播**：若后续证据以置信 ≥ τ_retract 判定 ¬c_k，则 retract(v_k)，并递归使所有祖先含被否声明、且未独立重建的后代失效：
  valid(v_j) ⇔ ¬retracted(v_j) ∧ ∀v_i ∈ anc_claim(v_j): valid(v_i) ∨ independent_support(v_j)；
- **出版真值**：P_t = 最大向上封闭的 valid 集合。

**定义 165（同行评审驱动执行出版闭环 PREPC）** 算子 PREPC(M, task, θ)：
```
① Execute:  M, fused, D⁺, EV, cert ← SERC(M, scene, intent, δ_f_req)   # 第 60 轮闭环
② Package: REB ← REB.package(claim(EV), manifest(M, θ), trace(EV)); h,σ ← sign(REB)
③ Reproduce: c' ← R(REB.μ, REB.N); ρ ← match(c', c, ε)
④ Review:    v̂, γ ← FPR.review(facial_AU_{t−w:t})
⑤ Divergence: quadrant ← RCD(ρ, v̂)
⑥ if v̂ ∈ {accept} ∧ ρ ≥ ρ_min ∧ quadrant ≠ dangerous:
        VEL.append(REB, v̂, ρ); PGC ← publish(REB, v̂, ρ)
   else:
        RRR.run(REB); θ ← revise(θ, v̂); goto ①（≤ R_max 轮）
⑦ Return: (PGC | preprint_only, VEL.status, ρ, v̂)
```

**定义 166（评审预算 B_rev 与 PCE+++++）** B_rev = (B_fer, B_rep, B_rev, B_dp)。其中 B_fer=(FER 算力/时延上限)，B_rep=(重放次数/复现算力)，B_rev=(评审轮次)，B_dp=(隐私预算 ε_dp)。扩展 VOI：
```
voi_rev(π) = voi_cog(π) − λ_fer·FER_cost − λ_rep·Replay_cost − λ_dp·Privacy_cost
```
任一预算耗尽触发对应降级（见灵感 6），保证「评审」永不压垮「实时执行」。

**定义 167（可复现-评审分歧 RCD）** 给定 (ρ, v̂)，定义四象限：

| | v̂=accept | v̂=reject |
|---|---|---|
| ρ≥ρ_min | 可信出版 | **隐性问题**（表情捕捉到重放漏掉的主观不适，如力太大、动作生硬）→ 尊重拒稿，增加隐式约束 |
| ρ<ρ_min | **社交掩饰/假阳性接受（最高风险）** → 禁止自动出版，强制独立审计 | 一致拒绝 |

- **分歧度** D_rc = |norm(ρ) − norm(signed(v̂))|；dangerous ⇔ ρ < ρ_min ∧ v̂ = accept ∧ D_rc ≥ τ_div。
- 设计意图：**表情永远不是 ground truth**，它只能与复现证据交叉验证。

**定义 168（出版级执行证书 PGC）** PGC = (h(REB), v̂, γ_rev, ρ, path_VEL, σ_robot, audit_status)。出版条件：
```
publish ⇔ h 校验 ∧ ρ ≥ ρ_min ∧ (v̂ = accept ∨ 拒稿已由 RRR 解决) ∧ ¬dangerous(RCD) ∧ audit_status = pass
```
不满足者标记为 **preprint_only**（可作参考、不可作为下游可信证据）；这样「未复现/被掩饰接受」的执行无法污染证据链。

## 2. 关键算法伪代码

### IP-161 REB（可复现执行出版包）

```python
class ReproducibleExecutionBundle:
    def package(self, claim, manifest, trace):
        manifest['nondeterminism'] = {
            'clock_skew_bound': 5e-3,
            'msg_order_seed': manifest['seeds']['ros'],
            'sensor_noise_seed': manifest['seeds']['sensor'],
        }
        reb = {'claim': claim, 'manifest': manifest, 'trace': trace}
        reb['hash'] = hashlib.sha256(
            json.dumps(reb, sort_keys=True).encode()).hexdigest()
        reb['sig'] = self.signer.sign(reb['hash'].encode())
        return reb

    def reproduce(self, reb, sim):
        c_prime = sim.replay(reb['manifest'])       # 确定性重放
        hits = sum(abs(c_prime[k] - reb['claim'][k]) <= self.eps[k]
                   for k in reb['claim'])
        return hits / len(reb['claim'])
```

### IP-162 FPR（表情同行评审）

```python
class FacialPeerReviewer:
    VERDICTS = ['reject', 'major_revision', 'minor_revision', 'accept']

    def review(self, au_window):
        feats = self.temporal_pool(au_window)           # 时序池化
        logits = self.calibrated_clf(feats)             # 温度标定后的 logits
        post = self.hmm.smooth(softmax(logits))         # HMM 时序聚合
        v_idx = int(np.argmax(post)); conf = float(post[v_idx])
        if conf < self.tau_abstain:
            return None, conf                          # 弃权
        return self.VERDICTS[v_idx], conf
```

### IP-163 RRR（评审-申诉-修订）

```python
def run_rrr(reb, reviewer, controller, eeis, theta, R_max=3):
    for _ in range(R_max):
        v_hat, conf = reviewer.review(controller.recent_aus())
        if v_hat in (None, 'accept', 'minor_revision'):
            return 'accepted', theta
        controller.display_evidence(reb)               # 申诉：展示证据
        if conf >= 0.8:                                 # 高置信拒稿才做探针
            controller.probe(force_cap=0.3 * eeis.F_safe)  # 安全包络约束
        theta = revise(theta, v_hat, eeis.K_safe)       # 仅在安全域内修订
        reb = controller.reexecute_and_package(theta)
    return 'escalate_human', theta                      # 轮次耗尽：升级
```

### IP-164/165 VEL 与 PREPC

```python
class VersionedEvidenceLedger:
    def append(self, reb, verdict, rho, delta):
        node = {'reb': reb, 'verdict': verdict, 'rho': rho, 'delta': delta}
        self.nodes.append(node)
        self.edges.append((len(self.nodes)-1, len(self.nodes)-2, 'revision_of'))
        return len(self.nodes) - 1

    def retract(self, idx, reason):
        self.retracted.add(idx)
        if self._contradicted(idx):
            self._invalidate_descendants(idx)           # 撤回沿依赖传播

def prepc(M, task, theta):
    M, fused, Dp, EV, cert = serc(M, task.scene, task.intent, task.delta_f)
    reb = REB.package(claim(EV), manifest(M, theta), trace(EV))
    rho = REB.reproduce(reb, M.sim)
    v_hat, conf = M.fpr.review(M.au_window)
    quadrant = rcd(rho, v_hat)
    if v_hat == 'accept' and rho >= RHO_MIN and quadrant != 'dangerous':
        idx = M.vel.append(reb, v_hat, rho, delta=None)
        return publish(reb, v_hat, rho, M.vel.path(idx))
    status, theta = run_rrr(reb, M.fpr, M.ctrl, M.eeis, theta)
    return ('escalate_human' if status != 'accepted' else 'revised'), theta
```

### IP-166 B_rev（PCE+++++）

```python
class ReviewBudget:
    def __init__(self, fer_ms=50, replays=10, rounds=3, eps_dp=1.0):
        self.B_fer, self.B_rep, self.B_rev, self.B_dp = fer_ms, replays, rounds, eps_dp
        self.used = {'fer': 0.0, 'rep': 0, 'rev': 0, 'dp': 0.0}

    def degrade(self):
        if self.used['fer'] > self.B_fer: return 'no_fer'      # 仅用显式意图
        if self.used['rep'] >= self.B_rep: return 'hash_only'  # 仅哈希审计
        if self.used['rev'] >= self.B_rev: return 'escalate'   # 转人工
        if self.used['dp'] >= self.B_dp: return 'agg_only'     # 只传聚合
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| REB | O(T) 打包 / O(T) 重放 | O(T + |μ|) | ρ ≥ 0.9 ⇒ 声明可复现（误差 ≤ ε_replay） |
| FPR | O(w·|AU|) 每窗口 | O(|AU|·|V| + HMM) | 校准 ECE ≤ 0.08；低置信必弃权 |
| RRR | O(R_max) 轮 | O(1) | 每轮修订 θ ∈ K_safe；探针 F_probe ≤ 0.3·F_safe |
| VEL | O(1) 追加 / O(V+E) 撤回传播 | O(V+E) | 撤回传递；出版真值向上封闭 |
| RCD/PGC | O(1) | O(1) | dangerous 象限绝不自动出版 |

**正确性定理（PREP）**：假设 A66–A71 成立：**(A66)** 非确定性台账使重放误差 ≤ ε_replay；**(A67)** FPR 校准 ECE ≤ δ_cal 且低置信弃权；**(A68)** RRR 在 R_max 内终止且每次修订保安全包络；**(A69)** VEL 撤回沿依赖传递闭包传播；**(A70)** RCD 在阈值间隔内正确判别四象限；**(A71)** B_rev 各分量单调消耗。则：
1. **可复现性**：Publishable(REB) ⇒ 任一审计者重放可得 c' 且 |c'−c| ≤ ε；
2. **评审安全性**：dangerous 象限（ρ<ρ_min ∧ v̂=accept）**永不自动出版**，必须独立审计；
3. **版本一致性**：retract(v_k) ⇒ 依赖被否声明的后代失效，除非独立重建；
4. **预算安全性**：任一 B_rev 耗尽 ⇒ 触发对应降级，评审不阻塞实时执行。

| 实验 | 指标 | 目标 |

## 5. 本轮最大风险

**一句话**：若把「社交性微笑/礼貌性点头」误读为 accept，而重放其实显示 ρ<ρ_min（执行不可复现），系统就可能把一次不安全执行当作「已通过同行评审」发表出去——必须用 **RCD 四象限分歧门 + FPR 低置信弃权 + 危险象限强制独立审计 + PGC 的 preprint_only 隔离** 四重护栏保证「表情永远只是评审、绝不是 ground truth」。

## 2. 关键算法伪代码

### IP-161 REB（可复现执行出版包）

```python
class ReproducibleExecutionBundle:
    def package(self, claim, manifest, trace):
        manifest['nondeterminism'] = {
            'clock_skew_bound': 5e-3,
            'msg_order_seed': manifest['seeds']['ros'],
            'sensor_noise_seed': manifest['seeds']['sensor'],
        }
        reb = {'claim': claim, 'manifest': manifest, 'trace': trace}
        reb['hash'] = hashlib.sha256(
            json.dumps(reb, sort_keys=True).encode()).hexdigest()
        reb['sig'] = self.signer.sign(reb['hash'].encode())
        return reb

    def reproduce(self, reb, sim):
        c_prime = sim.replay(reb['manifest'])       # 确定性重放
        hits = sum(abs(c_prime[k] - reb['claim'][k]) <= self.eps[k]
                   for k in reb['claim'])
        return hits / len(reb['claim'])
```

### IP-162 FPR（表情同行评审，端侧 + 隐私）

```python
class FacialPeerReviewer:
    VERDICTS = ['reject', 'major_revision', 'minor_revision', 'accept']

    def __init__(self, tau_abstain=0.6, eps_dp=1.0):
        self.tau_abstain, self.eps_dp = tau_abstain, eps_dp
        self.temporal_pool = TemporalAUEncoder()
        self.calibrated_clf = TemperatureScaled(Isotonic())
        self.hmm = ExpressionHMM()

    def review(self, au_window):
        feats = self.temporal_pool(au_window)           # 端侧：只出 AU 特征
        feats = dp_noise(feats, self.eps_dp)            # 差分隐私
        logits = self.calibrated_clf(feats)
        post = self.hmm.smooth(softmax(logits))         # 时序聚合
        v_idx = int(np.argmax(post)); conf = float(post[v_idx])
        if conf < self.tau_abstain:
            return None, conf                          # 弃权：不当评审
        return self.VERDICTS[v_idx], conf
```

### IP-163 RRR（评审-申诉-修订，安全包络约束）

```python
def run_rrr(reb, reviewer, controller, eeis, theta, R_max=3):
    for _ in range(R_max):
        v_hat, conf = reviewer.review(controller.recent_aus())
        if v_hat in (None, 'accept', 'minor_revision'):
            return 'accepted', theta
        controller.display_evidence(reb)               # 申诉：展示 REB 证据
        if conf >= 0.8:
            controller.probe(force_cap=0.3 * eeis.F_safe)  # 安全包络内探针
        theta = revise(theta, v_hat, eeis.K_safe)       # 仅在安全域修订
        reb = controller.reexecute_and_package(theta)
    return 'escalate_human', theta                      # 轮次耗尽：升级人工
```

### IP-164 VEL（版本化证据账本，撤回传播）

```python
class VersionedEvidenceLedger:
    def __init__(self):
        self.nodes, self.edges, self.retracted = [], [], set()

    def append(self, reb, verdict, rho, delta):
        self.nodes.append({'reb': reb, 'verdict': verdict, 'rho': rho, 'delta': delta})
        if len(self.nodes) > 1:
            self.edges.append((len(self.nodes)-2, len(self.nodes)-1, 'revision_of'))
        return len(self.nodes) - 1

    def retract(self, idx, reason):
        self.retracted.add(idx)
        self._invalidate_descendants(idx)               # 沿依赖传递失效

    def _invalidate_descendants(self, idx):
        stack = [j for (i, j, _) in self.edges if i == idx]
        while stack:
            j = stack.pop()
            if j in self.retracted:
                continue
            self.retracted.add(j)
            stack += [k for (i, k, _) in self.edges if i == j]

    def valid(self, idx):
        return idx not in self.retracted
```

### IP-165 PREPC + IP-167 RCD + IP-168 PGC（出版闭环与安全门）

def rcd(rho, v_hat, rho_min=0.9, tau_div=0.35):
    if rho >= rho_min and v_hat == 'accept':   return 'trusted'
    if rho >= rho_min and v_hat == 'reject':   return 'latent_issue'
    if rho <  rho_min and v_hat == 'accept':   return 'dangerous'   # 社交掩饰
    return 'consistent_reject'

def prepc(M, task, theta):
    M, fused, Dp, EV, cert = serc(M, task.scene, task.intent, task.delta_f)
    reb = REB.package(claim(EV), manifest(M, theta), trace(EV))
    rho = REB.reproduce(reb, M.sim)

    quadrant = rcd(rho, v_hat)

        idx = M.vel.append(reb, v_hat, rho, delta=None)

    if v_hat == 'reject' and quadrant == 'latent_issue':

### IP-166 PCE+++++（评审预算与降级）

```python
class ReviewBudget:
    def __init__(self, fer_ms=50, replays=10, rounds=3, eps_dp=1.0):
        self.B_fer, self.B_rep, self.B_rev, self.B_dp = fer_ms, replays, rounds, eps_dp
        self.used = {'fer': 0.0, 'rep': 0, 'rev': 0, 'dp': 0.0}

    def degrade(self):
        if self.used['fer'] > self.B_fer:   return 'no_fer'       # 仅显式意图
        if self.used['rep'] >= self.B_rep:  return 'hash_only'    # 仅哈希审计
        if self.used['rev'] >= self.B_rev:  return 'escalate'     # 转人工
        if self.used['dp']  >= self.B_dp:   return 'agg_only'     # 只传统计
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| REB | O(T) 打包 / O(T) 重放 | O(T + \|μ\|) | ρ≥0.9 ⇒ 重放误差 ≤ ε_replay |
| FPR | O(w·\|AU\|) | O(\|AU\|·\|V\| + HMM) | ECE ≤ 0.08，低置信必弃权 |
| RRR | O(R_max) | O(1) | 探针 F_probe ≤ 0.3F_safe，修订 ∈ K_safe |
| VEL | O(1) 追加 / O(V+E) 撤回 | O(V+E) | 撤回传递闭包；P_t 向上封闭 |
| RCD/PGC | O(1) | O(1) | dangerous 象限永不自动出版 |

**正确性定理（PREP）**：若 A66–A71 成立，则：
1. **可复现性**：Publishable(REB) ⇒ 重放 c' 满足 |c'−c| ≤ ε；
2. **评审安全性**：ρ<ρ_min ∧ v̂=accept ⇒ 输出 preprint_only + AUDIT_REQUIRED，绝不自动 publish；
3. **版本一致性**：retract(v_k) ⇒ 所有依赖被否声明的后代失效（除非 independent_support）；
4. **预算安全性**：任一 B_rev 耗尽 ⇒ 对应降级，评审不阻塞执行。

## 5. 本轮最大风险
