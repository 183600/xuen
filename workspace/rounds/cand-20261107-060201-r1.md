# 第 1 轮（新灵感循环第 1 轮）· SIM-COMP：Isaac Sim 驱动的开源技能组合验证

## 0. 先给直觉：为什么「Isaac Sim + 开源软件 + 技能组合」是必然组合？

从第 25 轮 PRISM-NAV 最大风险出发：
> **想象模型的概念漂移导致 σ 误判，回退依赖想象即辨识在真实物理上不可靠**

Isaac Sim + 开源技能组合正是对这一根本限制的回应：
- **Isaac Sim** → 提供可复现、可批量的物理仿真验证，用地面真值替代学习世界模型的漂移
- **开源软件** → 技能以标准化接口注册、版本化、分发，形成可组合的公共技能库，降低演示依赖
- **技能组合** → 将规划从单原语 roll-out 升级为原语级符号组合，组合有效性由仿真验证而非数据覆盖保证

核心灵魂：**用仿真验证把「数据驱动的想象」变成「开源可复现的组合搜索」**。

一句话押注：
> **本轮把技能库从「经验记忆+想象」升级为「开源注册+仿真验证的组合搜索」：每个技能 z 遵循 OSS-Spec 接口注册；组合候选由符号预后置条件链生成；Isaac Sim 批量仿真评分 r_sim, s_safe；开源 registry 记录验证结果，形成可信的技能组合图。**

## 1. 研究日志：从 PRISM-NAV 到 SIM-COMP

### 1.1 第 25 轮系统的三个「信任」症状
```text
D1. 想象漂移：μ_z 的 σ 在刚度/材质微变时误判，导致过度保守或激进；
D2. 组合假设盲区：L3' 假设原语可无损拼接，未在真实接触动力学下验证；
D3. 复现成本高：世界模型训练依赖私有演示，社区无法复现技能组合。
```

### 1.2 三个新判断
1. **仿真验证是想象的不确定性的地面真值**：Isaac Sim 的物理引擎提供确定性、批量的接触动力学评估，替代 MC Dropout 的经验方差；
2. **开源接口是组合的前提**：技能必须标准化 φ, ψ, π, θ, meta，才能被符号规划器组合并被他人复现；
3. **组合搜索比分步想象更高效**：符号预后置条件链把搜索空间从 O(N^D) 动作 roll-out 压缩到 O(|Z|^K) 技能序列，Isaac Sim 并行验证使实际开销可控。

### 1.3 与第 25 轮 PRISM-NAV 的关系（增量演进）

| 层 | 第 25 轮 | 第 1 轮 SIM-COMP | 关系 |

### 1.4 灵感词贯通
> **Isaac Sim**：批量仿真验证器 SimValidator，支持并行 N=32 技能组合 roll-out；输出 r_sim, collision, contact_stability。

## 3. 正式化：SIM-COMP 算法定义

### 3.1 符号与技能接口

记号：
- 技能 z = (id, φ_z, ψ_z, π_z, θ_z, meta_z)
- φ_z ⊆ S：前置条件谓词集合
- ψ_z ⊆ S：后置条件谓词集合
- π_z : S × θ → A：在 Isaac Sim 中可执行策略
- 组合 z_i ∘ z_j 有效 iff ψ_i ∩ φ_j ≠ ∅

**OSS-Spec**：
```yaml
id: push_door
pre: [in_contact, door_unlocked]
post: [door_open_angle>0.5]
params: [force_scale]
impl: push_door.py
```

### 3.2 组合搜索

**问题**：
```
π* = argmax_{z1...zk ∈ Z}  Σ sim_score(z1...zk) s.t. ψ_{i} ⊆ φ_{i+1}
```

**算法步骤**：
1. 从 registry 加载技能图 G(Z,E)，E = {(i,j) | ψ_i ∩ φ_j ≠ ∅}
2. Beam Search：宽度 W=8，深度 K=4
3. 对每个候选序列 C，调用 Isaac Sim BatchValidator：
   - 并行仿真 T_sim=5s
   - 评分 r_sim = w1·task_success + w2·(-collision) + w3·(-energy)
4. 保留 top-W 序列，回溯最优

**复杂度**：O(W·K·|Z| + W·C_sim)；仿真并行使 C_sim 常数化

### 3.3 开源闭环

```
registry_pull → symbol_plan → sim_validate → registry_push
```
验证通过的组合自动打包为 Composition Package，包含仿真证据 log、Isaac Sim scene snapshot、可复现种子。

## 4. 性质与复杂度

### 4.1 理论性质
**命题 1（完备性）**：若技能库 Z 对任务 T 完备且 G 为全连通，则 Beam Search 在 W→∞ 时找到最优组合。
**命题 2（验证可靠性）**：Isaac Sim 仿真评分 r_sim 在 sim-real gap 有界时，与真实执行成功率单调相关。

### 4.2 计算复杂度
| 模块 | 频率 | 复杂度 | 典型延迟 |
|---|---|---|---|
| Registry 加载 | 离线 | O(|Z|) | <100 ms |
| 符号搜索 | 事件驱动 | O(W·K·|Z|) | <10 ms |
| Isaac Sim 批量验证 | 异步 | O(W·T_sim / P) | ~2 s / 批 P=32 |
| 总延迟 | — | — | **规划 <20 ms + 异步验证** |

## 5. 风险

**本轮最大风险**：Isaac Sim 仿真与真实接触动力学的 sim-real gap 可能导致验证通过的组合在真实机器人上失效，而开源分发会放大错误传播。

## 2. Python 核心实现

```python
from dataclasses import dataclass
from typing import List, Set
import yaml

@dataclass
class Skill:
    id: str
    pre: Set[str]
    post: Set[str]
    params: dict
    meta: dict

class OSSRegistry:
    def __init__(self, path="registry"):
        self.skills = {}
    
    def load(self):
        for yml in Path(path).glob("*.yaml"):
            data = yaml.safe_load(yml.read_text())
            self.skills[data['id']] = Skill(**data)
    
    def graph(self):
        edges = {}
        for s in self.skills.values():
            edges[s.id] = [t.id for t in self.skills.values() if s.post & t.pre]
        return edges

class SimValidator:
    def __init__(self, num_workers=32):
        self.num_workers = num_workers
    
    def batch_validate(self, seqs: List[List[Skill]]):
        # 伪代码：调用 Isaac Sim 批量仿真
        scores = []
        for seq in seqs:
            # sim.run(seq)
            success = 1.0  # placeholder
            collisions = 0.0
            energy = 0.5
            score = 0.6*success -0.2*collisions -0.2*energy
            scores.append(score)
        return scores

class Composer:
    def __init__(self, registry: OSSRegistry, validator: SimValidator, W=8, K=4):
        self.registry = registry
        self.validator = validator
        self.W, self.K = W, K
    
    def search(self, goal_preds: Set[str]):
        G = self.registry.graph()
        # 初始化：找到 pre ⊆ current_state 的技能
        beams = [ [s] for s in self.registry.skills.values() if s.pre <= goal_preds ]
        for depth in range(self.K-1):
            cand = []
            for seq in beams:
                last = seq[-1].id
                for nxt_id in G.get(last, []):
                    cand.append(seq + [self.registry.skills[nxt_id]])
            # 去重
            cand = list({tuple(s.id for s in seq): seq for seq in cand}.values())
            scores = self.validator.batch_validate(cand)
            top_idx = sorted(range(len(scores)), key=lambda i: scores[i], reverse=True)[:self.W]
            beams = [cand[i] for i in top_idx]
        return beams[0] if beams else None
```
