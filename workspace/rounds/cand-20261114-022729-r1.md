# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「边缘计算」×「嵌入式系统」）

> R69 把不确定性一分为二，问出「我该向谁求证、还能问什么」，并让流匹配策略把歧义显影成多个模态、让主动交互去消解。但它默默假设了两件在真实硬件上都不成立的事：**（a）消歧的计算是免费的**——K 次流采样、Hutchinson 似然回放、冻结 LLM 生成问句，都要花延迟、能量、带宽；**（b）速度场是数值精确的**——一旦把模型量化到 int8/定点、部署到 MCU/NPU，速度场被扰动，**模态结构本身会变**。也就是说，R69 最信任的那个对象（模态分布），恰恰是部署时最容易被改写、而它的 ECE 又只在 fp32 上「标定过」的那个对象。
>
> 两块灵感补的正是这两刀：
> - **嵌入式系统**：WCET、能量、定点/量化、确定性执行——把「消歧算力」从隐含假设抬成一等资源，并揭示 R69 二分之外还有**第三条不确定性通道**：只能靠算力约简、观测无效的 **U_comp**（数值/近似不确定性）。
> - **边缘计算**：分层异构算力 + 分布式证据 + 网络时断时续——一方面逼出「本地/边缘/云」的卸载调度，另一方面让**不同精度/不同层/不同节点的数值实现**成为一组「部署原生」的正交证据，用来验伪 R69 最怕的幻影模态。
>
> 核心命题：**不确定性三分 U = U_ale ⊕ U_epi ⊕ U_comp；U_epi 靠交互（R69），U_comp 靠算力（本轮），两者共用同一份预算，在「每毫秒/每焦耳」的边际收益上做套利；只有跨精度/跨层数值稳健的模态才获准驱动交互；预算不可行或确定性不可证时，整体事前退回 R68 纯保守。** 命名 **EDGE-RAS**（Energy- and Determinism-Governed Epistemic resolution）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这次求证，在这块硅和这点电量上还成立吗？我付得起、也复现得了吗？**」——不确定性不只分「能问」和「不能问」，还分「**买得起、验得过才算数**」。

## 0. 直觉与动机

**灵感 1（嵌入式 → 消歧是一笔要还的算力债，不是免费的信息动作）**
直觉：R69 的 VoI(g) = 信息增益 − 物理/社交成本，漏掉了**计算 VoI 本身**和**执行消歧本身**的代价。嵌入式系统把这件事变成硬约束：WCET 必须可证、能量必须可持续、内存/算子必须固定。于是问题退化为经典元推理（metareasoning）：不是 `argmax[VoI−c]`，而是对计算计划 π 取 `argmax[VoI(π) − c_phys − c_comp(π)]`，且 `WCET(π) ≤ T_max`、`E(π) ≤ E_max`。更微妙的是**元递归**：你还要花算力去判断「值不值得花算力去判断值不值得问」。所以需要一条**保真度阶梯**——先用 int8 粗估 VoI，只有落在决策边界附近才升精度重算；预算撑不到决策所需精度，就**不赌**，直接 R68。算力在这里既是成本，也是「更准的元判断」的购买力。

**灵感 2（嵌入式 → 部署会改写模态：R69 的二分少了第三条通道）**
直觉：R69 把 U 拆成 aleatoric（不可约）与 epistemic（靠观测可约）。但量化/定点 ODE/算子融合带来的误差，**既不是观测能消掉的，也不是物理噪声**——它只能靠**花更多算力**（更高精度、更多步、换层）来减少。这是第三类：**U_comp（计算不确定性）**。它的处置既不是「慢下来」也不是「问一句」，而是「提精度/升层/加步数，或承认这台机器给不了这个确定性、按 aleatoric 兜底」。把 U_comp 单列是 R70 相对 R69 的结构性贡献：**不确定性的可约简方式，决定了它该用哪种货币去支付**——观测的货币是「交互」，硅的货币是「算力/能量」。

**灵感 3（边缘 → 部署多样性是一组天生的正交证据，但只对数值伪影有效）**
直觉：同一模型在 fp32（云）、fp16（边缘 NPU）、int8/定点（MCU）上的模态分解会略有差异。**跨精度都稳定出现的模态**大概率是真模态；**只在某一精度冒出来**的多半是量化伪影（幻影模态）——这正是 R69 最怕、而其 ECE 却往往只在 fp32 上标定过的失败。于是 CMA（跨精度模态一致性）给了 R69 一条**部署原生**的第二意见，不需要再训练一个模型。但必须诚实划界（见 §6）：它只压制**数值伪影**，压不住**同一份权重/数据导致的系统性模态错误**——所有精度都会一致地错，一致性反而制造虚假安全感。

**灵感 4（边缘 → 分层卸载与时鲜度：远程第二意见不是免费的确定性）**
直觉：边缘是分层的：MCU → 边缘 SoC/NPU → 网关 → 云。越往上层，精度/模型越大，但延迟、带宽、能耗、隐私与**时鲜度**代价越高。网络分区或远程模型陈旧时，远程证据必须被当作「无证据 ⊥」而不是「一致证据」。这与 R69 的「投毒证据」不同：这里敌人不是撒谎的人，而是**延迟与失联**。卸载决策因此是 U_comp 与 U_epi 之外的第二类「用资源换确定性」——花带宽换一层正交校验。

**灵感 5（热与能量 → 确定性是安全论证的一部分；热债会反过来改模态）**
直觉：电池/能量采集嵌入式系统里，持续算力有限，热节流会降低可用时钟 → 可用 ODE 步数下降 → U_comp 上升 → 模态漂移变大。**能量预算与认知质量是耦合的**：R69 的「交互疲劳」在 R70 多了「算力疲劳/热疲劳」。而且不可复现的消歧（非确定定点、乱序并行）无法进入安全案例——所以确定性本身是安全论证的一部分，而非实现细节。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（EDGE-RAS 总览）** EDGE-RAS = (MRA, NDQ, DSS, CMA, HER, TDS, EDG, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **算力预算硬约束**：任何消歧计划 π 满足 `WCET(π) ≤ T_max`、`E(π) ≤ E_max`、`B(π) ≤ B_max`，越界即不可行；
(iii) **确定性可证**：消歧路径必须由定点/定步长、无动态分配的 DSS 执行，给定输入与精度 bit-exact 可复现；
(iv) **部署证据作用域**：只有 CMA 判定为「跨精度/跨层稳健」的模态可驱动交互；且退化链 R70→R69→R68 在任何边界的 λ 单调不降。

**定义 311（算力预算契约 CBC）** 计划 π = (K, N_step, precision, tier, sensor_set)。资源向量 ρ(π) = (WCET, E, B, thermal)。可行域 `𝒫_feas = {π : WCET ≤ T_max ∧ E ≤ E_max ∧ B ≤ B_max ∧ T_junction ≤ T_crit}`。预算是**实时硬约束**，不是软惩罚。

**定义 312（不确定性三分）** U = (U_ale, U_epi, U_comp)：
- U_ale：物理/感知噪声，任何手段不可约；
- U_epi：模态间歧义，靠**观测/交互**约简（R69）；
- U_comp：量化/定点/ODE 截断/近似带来的数值不确定，靠**算力**约简，**观测无效**。

三者进入不同通道：U_ale 直接进 λ floor；U_epi 进 MINT/VoI（R69）；U_comp 进 MRA（提精度/升层）或按 aleatoric 兜底。

**定义 313（数值不确定性 NDQ）** 设速度场量化误差 `‖δv‖ ≤ ε_q`、步长 h、视界 H、步数 N、Lipschitz 常数 L_v。则轨迹偏差上界（Gronwall）`‖δξ‖ ≤ (ε_t + N·ε_q)·(e^{L_v H}−1)/L_v`；定义 `U_comp = tr(Σ_num) + ‖δξ‖²`，作为该精度下的附加方差并入动作分布。**关键：U_comp 随 H 指数放大**——同一 int8 模型长视界不可信，短视界 + 查表才可信。

**定义 314（元推理目标 MRA）** 保真度阶梯 f ∈ {COARSE(int8,1步), MEDIUM(fp16,2步), FINE(fp32,多步/云)}。对每级算下置信界 `VoI_LCB(f) = VôI(f) − κ·σ(f)`（σ(f) 随算力降）。选
`π* = argmax_{π∈𝒫_feas} [VoI_LCB(π) − c_phys(π) − c_comp(π)]`，若最优 ≤ 0 则不消歧。
**跨币种最优分配**：在 U_epi（交互）与 U_comp（提精度/升层）间，最优时单位资源边际收益相等：`∂VoI/∂ms = ∂VoI/∂J`。

**定义 315（确定性定步长求解器 DSS）** 用固定 N_det、定点/整型或确定性浮点算子、预分配缓冲实现流 ODE；禁止动态分配与数据相关分支；输出对 (输入, 精度, 版本) 确定。WCET 由静态分析/实测上界给出，纳入定义 311。

**定义 316（部署条件化模态分解）** 对精度 p 与层 t，得模态集 `{m_k^{(p,t)}}`、权重、协方差。部署条件化的 `U_ale^{(p,t)}`、`U_epi^{(p,t)}`、`U_comp^{(p,t)}`。**R69 的 fp32 分解只是 p=FINE 的一个切片**。

**定义 317（跨精度/跨层模态一致性 CMA）** 用最优传输/原型匹配把各实现的模态对齐。定义
- **稳健模态** `R = {m : ∃ 匹配于所有 (p,t) ∈ Π，且匹配距离 ≤ δ_match}`；
- **幻影模态** `P_h = {m : 仅出现在部分实现，且在被消去的实现中无匹配}`；
- **坍缩模态** `C_l = {m^{(FINE)} : 在低精度中与另一模态合并}`。

一致性率 `κ_cma = |R| / |{m^{(FINE)} 对应真实支持}|`。**只有 R 进入 VoI**。

**定义 318（异构证据路由 HER）** 证据源 `e = (tier, precision, node, sensor)` 及其误差相关 `ρ(e_i,e_j)`。路由目标：在预算内选一组**误差低相关**的证据做交叉验证；相关性用跨精度/跨节点的误差协方差估计。**多样性 ≠ 数量**：同一 trunk 的十个副本只算一个证据源。

**定义 319（分层消歧调度 TDS）** 在 {MCU, EDGE_SOC, GATEWAY, CLOUD} 上按定义 311 可行性 + 时鲜度约束排程；远程证据仅在 `age ≤ τ_stale` 且链路未分区时可用，否则降级为本地证据。

**定义 320（时鲜度与分区下的证据等价类）** 远程回答 `y_remote` 若 `age > τ_stale` 或分区，则视为「无证据 ⊥」，而非「支持」。更新规则 `p(M | y_remote=⊥) = p(M)`，禁止把陈旧/缺失当一致。

**定义 321（部署-硬件威胁 ℰ_edge）** 位翻转、时钟抖动、热节流、低精度 ODE 发散、量化伪影、远程模型陈旧、网络分区、侧信道。并入 AIC：`ℰ_EDGE = ℰ_FLUID × ℰ_num × ℰ_hw × ℰ_net`。

**定义 322（能耗-热耦合）** 温度 T 升高 → 时钟降频 → 可用步数 N(T) 下降 → U_comp(T) 上升。定义热债 `Q(t)=∫(P−P_cool)dt`。可行域须含 `T_junction ≤ T_crit`；热债越界 ⇒ 计划降级或退化。

**定义 323（算力感知校准门 MCG-E）** 部署条件 ECE：`ECE^{(p,t)}` 在目标精度/层上（而非 fp32）测量。`ECE^{(p,t)} > τ_ece` ⇒ 禁用该实现的 VoI 决策，回退上一级精度或 R68。

**定义 324（稳健模态准入）** 仅当 `m ∈ R`（定义 317）且其跨实现权重方差 `≤ σ_w` 时，m 才可参与 VoI 与动作选择；`P_h`、`C_l` 一律不得驱动交互，只进审计。

**定义 325（边缘部署退化门 EDG）** 若 `𝒫_feas` 为空、或 DSS 无法给出 WCET 认证、或存在未检出的数值发散风险、或 MCG-E 越界：立即回退 R68 纯保守，且 λ 不降。退化是**事前**判定的（不是运行中赌运气）。

**定义 326（证书 J_EDGE）** `J_EDGE = (J_FLUID, precision, tier, WCET_bound, E_used, thermal_margin, κ_cma, ECE^{(p,t)}, U_comp, determinism_hash, net_state, edge_ver)`。Valid ⇔ Valid(J_FLUID) ∧ 预算未越界 ∧ 确定性可复现 ∧ 仅稳健模态驱动交互。

## 2. 关键算法骨架

```python
# IP-264 MRA：算力感知元推理（保真度阶梯 + 跨币种套利）
class MetareasoningAllocator:
    def plan(self, z, budget, world):
        best = None
        for f in [COARSE, MEDIUM, FINE]:          # int8/1步 → fp16/2步 → fp32/多步
            if not budget.feasible(f): break      # 更高质量不可能就停
            U   = estimate_uncertainty(z, f)      # (U_ale, U_epi, U_comp)
            voi = voi_lcb(U, f)                   # 下置信界，防粗估过度自信
            net = voi - c_phys(f) - c_comp(f)
            if best is None or net > best.net: best = (f, net, U)
            if net < -MARGIN and f is COARSE:     # 粗估已判"不值得"
                return None                       # 不消歧 → R68
        return best.plan if best and best.net > 0 else None

# IP-265 NDQ：数值不确定性（部署引入的第三通道）
def numerical_uncertainty(precision, N_step, H, L_v):
    e_q = rounding_eps(precision)                 # int8 / fp16 / 定点舍入
    e_t = truncation_eps(N_step, H)               # ODE 截断
    return (e_t + N_step * e_q) * (math.exp(L_v * H) - 1) / L_v

# IP-266 CMA：跨精度/跨层模态一致性（部署自带的第二意见）
def cross_tier_agreement(obs, tiers, delta_match):
    modes = {t: cluster(dss_sample(obs, t)) for t in tiers}   # MCU/EDGE/CLOUD
    R, phantoms = [], []
    for m in modes[CLOUD]:                        # 以最高保真度为参照
        if all(any(dist(m, m2) <= delta_match for m2 in modes[t]) for t in tiers):
            R.append(m)                           # 跨层稳健 → 可信
        else:
            phantoms.append(m)                    # 数值伪影 / 坍缩
    return R, phantoms

# IP-267 TDS：分层卸载（预算 + 时鲜度 + 分区）
def tiered_schedule(plan, budget, link):
    for tier in [MCU, EDGE_SOC, GATEWAY, CLOUD]:
        if not budget.feasible(plan, tier):        continue
        if not dss.wcet_certified(plan, tier):     continue
        if tier == CLOUD and (link.partitioned() or link.age() > TAU_STALE):
            continue                               # 远程不可用 → 当无证据
        return tier
    return None                                    # → EDG

# IP-268 主闭环（在 R69 的 FLUID 层外再包一层"算力预算 + 部署证据"）
def EDGE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)   # R68 标定
    # 1) 元推理：预算内决定保真度、层、以及是否值得消歧
    plan = M.mra.plan(z, M.budget, M.world)
    if plan is None:                                # 预算不可行 / 不划算
        return M.r68_conservative(o, U_cal)         # EDG → R68
    # 2) 确定性采样 + 部署条件化三分
    U_comp = M.ndq.numerical_uncertainty(plan)
    robust, phantoms = M.cma.cross_tier_agreement(o, plan.tiers, DELTA_MATCH)
    if M.mcg_e.ece(plan) > TAU_ECE or not robust:    # 部署校准不过
        return M.r68_conservative(o, U_cal)          # EDG → R68
    U_ale, U_epi, modes = M.aud.decompose(robust)    # 只对稳健模态做 R69 分解
    # 3) 交互：分层执行 + 时鲜度纪律
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    tier = M.tds.schedule(plan, M.budget, M.link) if g else None
    answer = M.cia.execute(g, tier=tier, max_age=TAU_STALE) if tier else None
    U_epi_after = U_epi if answer is None else M.cia.update_belief(modes, answer, k=2)
    # 4) 三分退避：ale + 未消解 epi + 全部 comp 一起进 floor
    U_floor = U_ale + U_comp + (U_epi_after if answer is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 5) 安全前缀 + 确定性输出
    k = M.c_ras_wm.certified_prefix(M.ach.propose(M.vista.H), ...)
    mode = select_mode(robust, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 部署审计 + 证书
    M.vqa_d.submit_async(plan, phantoms, U_comp, answer, M.link.state)
    return k, lam, mode, (U_ale, U_epi_after, U_comp)
```

## 3. 推导

**引理 19（部署诱导的模态漂移上界）** 设真实速度场 v 与部署实现 v̂ 之差 `‖v−v̂‖∞ ≤ ε_v = ε_t + N·ε_q`。轨迹误差 `e = ξ̂−ξ` 满足 `de/ds = v̂(ξ̂)−v(ξ) ≤ ε_v + L_v‖e‖`。由 Gronwall，`‖e(s)‖ ≤ (ε_v/L_v)(e^{L_v s}−1)`；在视界 H 处给出上界，模态原型漂移 `δ_proto` 不超过同量。**系**：若 `Δ_min ≤ 2δ_proto`，对齐后模态可合并（坍缩）或分裂（伪模态）——这给出「低精度 → 幻影模态」的充分条件。**要点**：δ_proto 随 H 指数放大，故嵌入式部署必须**限制视界或改用查表**；长视界 + int8 是最危险的组合。

**引理 20（跨精度一致性的伪模态压制，及其作用域）** 设 L 个实现的数值误差实现相互独立，单个实现产生伪模态的概率 `≤ p_q`。CMA 要求伪模态在所有 L 个实现中都出现且位置匹配，故保留概率 `≤ p_q^L`（独立 + 匹配巧合有界）。同时，若真模态在各实现的原型漂移 `< δ_match/2`（引理 19 保证），则真模态被 R 保留。**作用域警告**：若错误来自**共享权重/数据**而非数值，则所有实现一致地错（`ρ→1`），上界退化为 `p_q`，CMA **无法**检出——此时独立性假设失效，与 R69 引理 18 在 ρ=1 时退化为单源同构。**结论**：CMA 只认证「数值稳健」，不认证「语义正确」。

**引理 21（算力受限 VoI 的保守元推理与跨币种均衡）** 设保真度 f 下 VoI 估计 `VôI(f) = VoI + η_f`，`|η_f| ≤ σ(f)`，且 σ(f) 随算力递减（Monte Carlo 下约 `∝ c^{-1/2}`）。
(i) 停止收益 `G(f)=E[VoI_LCB(f)]−c(f)` 在边际方差收益递减时单峰，故存在最优停止保真度 f*（一阶条件：边际方差下降的价值 = 边际算力成本）。
(ii) 若在最大可负担保真度下决策裕度 `< κσ(f)`，则 LCB 的符号不可靠 ⇒ 保守规则选「不交互」的概率 `≥ 1−η`（不赌）。
(iii) **跨币种**：把资源 R 在「交互降 U_epi」与「算力降 U_comp」间分配，拉格朗日一阶条件要求 `∂VoI/∂ms = ∂VoI/∂J`；角点解给出纯交互或纯算力。**系**：消歧算力具有**双重价值**——直接降 U_comp，又因锐化 VoI 估计而在决策边界附近优先；这解释了为何「先粗估、近边界再精算」是近最优。

**引理 22（能耗-热耦合下的模态漂移放大）** 设结温升高使时钟 `f_clk(T)` 降，则在 WCET 内可执行步数 `N(T)=⌊T_max·f_clk(T)/c_step⌋` 下降，截断误差 ε_t 上升 ⇒ 由定义 313/引理 19，U_comp(T) 与 δ_proto 单调上升。若控制器不按 T 重规划，实际模态可能漂出 δ_match，使 CMA 误报不稳或催生新伪模态。**系**：热预算必须进入 `𝒫_feas`；长时程部署若不含热感知的 N(T)，会在「看起来没坏」的情况下悄悄越过数值可信边界。

**定理 18（EDGE 的部署严格包含链）** 在 A99–A101（预算可行性、DSS 确定性可证、CMA 作用域）下：
(i) 当算力充足、数值精确、部署 ECE 合格（理想部署）时，U_comp=0、R=全体、EDG 不触发，R70 与 R69 **逐指令相同**；
(ii) 当 `𝒫_feas=∅`、DSS 无法认证、或 MCG-E 越界时，EDG 触发，R70 与 R68 逐指令相同；
(iii) 任意可行计划下 `λ_EDGE = λ_floor(U_ale + U_comp + 未消解 U_epi) ≥ λ_floor(U_ale + 未消解 U_epi) = λ_FLUID`（U_comp≥0），故安全侧**逐点不弱于**把 R69 硬部署到同硬件；且因幻影模态被 CMA 剔除，R69 会执行的那些「由伪模态驱动的交互」被抑制，故期望风险 `≤` naive FLUID 部署。⇒ 链 `R70 ⊇ R69 ⊇ R68` 成立，且安全侧永不因效率而让步。

**定理 19（确定性、守时与无突变）** DSS 定步长 + 预分配 + 静态 WCET 上界 ⇒ 对 `π∈𝒫_feas`，执行时间 `≤ Σ WCET(op) ≤ T_max`，无动态分配导致的无界停顿；确定性 ⇒ 相同 (o, precision, version) 下 bit-exact 复现。EDG 由**事前**可行性谓词触发，故不会运行中超时；资源收缩（T_max↓、精度↓、热债↑）使可行集单调缩小、λ 单调不降，退化只会更保守。认证前缀在稳健模态子集内选择，安全包络不扩张；退化切换是保守切换 ⇒ 控制连续、无突变，R69 定理 17 的换装不变式保持。**系**：可复现的消歧才能进安全案例——确定性不是实现细节，而是论证前提。

## 6. 本轮最大风险

**一句话**：EDGE-RAS 把可信度押在「跨精度/跨层一致性 = 证据正交」上，但**同一份权重与训练数据会让所有精度一致地错**——CMA 给出的「一致」可能只是**共享偏差的自我确认**，而算力预算又迫使系统在廉价的粗估保真度上过早定型；于是 R70 可能以**确定性、可复现、可认证**的方式自信地犯错——**部署非但没让它更对，反而让它更可信地错**。

**次级风险与缓解**：
1. **热节流悄悄改写模态** → 定义 322 热预算入 `𝒫_feas` + 引理 22 重规划 + E307；
2. **远程证据陈旧/分区被误当一致** → 定义 320 证据等价类 + `⊥` 规则 + E309；
3. **低精度 ODE 数值发散** → DSS 定步长 + NDQ 上界 + 发散检测门 + E311；
4. **预算过紧饿死安全** → 三级保真度 + 「不赌」规则 + EDG 事前退化 + E303/E315；
5. **确定性带来虚假安全感**（可复现 ≠ 正确）→ J_EDGE 显式记录 precision/tier/κ_cma，审计不把「可复现」当「正确」；
6. **跨层误差相关（共享 trunk）** → HER 的 ρ(e_i,e_j) 估计 + 要求跨**传感器/模型族**的多样性，而非同模型多副本。

```python
# IP-264 MRA：算力感知元推理（保真度阶梯 + 跨币种套利）
class MetareasoningAllocator:
    def plan(self, z, budget, world):
        best = None
        for f in [COARSE, MEDIUM, FINE]:          # int8/1步 → fp16/2步 → fp32/多步
            if not budget.feasible(f): break
            U   = estimate_uncertainty(z, f)      # (U_ale, U_epi, U_comp)
            net = voi_lcb(U, f) - c_phys(f) - c_comp(f)
            if best is None or net > best.net: best = (f, net, U)
            if net < -MARGIN and f is COARSE: return None   # 不消歧 → R68
        return best.plan if best and best.net > 0 else None

# IP-265 NDQ：数值不确定性（部署引入的第三通道）
def numerical_uncertainty(precision, N_step, H, L_v):
    e_q, e_t = rounding_eps(precision), truncation_eps(N_step, H)
    return (e_t + N_step * e_q) * (math.exp(L_v * H) - 1) / L_v

# IP-266 CMA：跨精度/跨层模态一致性（部署自带的第二意见）
def cross_tier_agreement(obs, tiers, delta_match):
    modes = {t: cluster(dss_sample(obs, t)) for t in tiers}
    R, phantoms = [], []
    for m in modes[CLOUD]:
        if all(any(dist(m, m2) <= delta_match for m2 in modes[t]) for t in tiers):
            R.append(m)                           # 跨层稳健
        else:
            phantoms.append(m)                    # 数值伪影 / 坍缩
    return R, phantoms

# IP-267 TDS：分层卸载（预算 + 时鲜度 + 分区）
def tiered_schedule(plan, budget, link):
    for tier in [MCU, EDGE_SOC, GATEWAY, CLOUD]:
        if not budget.feasible(plan, tier):    continue
        if not dss.wcet_certified(plan, tier): continue
        if tier == CLOUD and (link.partitioned() or link.age() > TAU_STALE):
            continue                               # 远程不可用 → ⊥
        return tier
    return None                                    # → EDG

# IP-268 主闭环（在 R69 的 FLUID 层外再包一层"算力预算 + 部署证据"）
def EDGE_RAS_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(...)
    plan = M.mra.plan(z, M.budget, M.world)        # 元推理
    if plan is None: return M.r68_conservative(o, U_cal)          # EDG
    U_comp = M.ndq.numerical_uncertainty(plan)
    robust, phantoms = M.cma.cross_tier_agreement(o, plan.tiers, DELTA_MATCH)
    if M.mcg_e.ece(plan) > TAU_ECE or not robust:
        return M.r68_conservative(o, U_cal)        # 部署校准不过 → EDG
    U_ale, U_epi, modes = M.aud.decompose(robust)  # 只对稳健模态三分
    g = M.mint.choose_interaction(modes, o, M.budget) if U_epi > TAU_EPI else None
    tier = M.tds.schedule(plan, M.budget, M.link) if g else None
    answer = M.cia.execute(g, tier=tier, max_age=TAU_STALE) if tier else None
    U_epi_after = U_epi if answer is None else M.cia.update_belief(modes, answer, k=2)
    U_floor = U_ale + U_comp + (U_epi_after if answer is None else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(M.vista.H), ...)
    mode = select_mode(robust, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_d.submit_async(plan, phantoms, U_comp, answer, M.link.state)
    return k, lam, mode, (U_ale, U_epi_after, U_comp)
```

## 4. 推导

**引理 19（部署诱导的模态漂移上界）** `‖v−v̂‖∞≤ε_v=ε_t+Nε_q`，误差微分不等式经 Gronwall 得 `‖δξ‖≤(ε_v/L_v)(e^{L_vH}−1)`；模态原型漂移同阶。若 `Δ_min≤2δ_proto` 则模态并/裂（坍缩/伪模态）——低精度伪模态的充分条件。**系**：δ_proto 随 H 指数放大，故嵌入式必须限视界或查表；长视界+int8 最危险。

**引理 20（跨精度一致性的伪模态压制，及其作用域）** L 个独立数值实现、单实现伪模态概率 `≤p_q`，CMA 要求全实现匹配 ⇒ 保留概率 `≤p_q^L`；真模态在漂移 `<δ_match/2` 时被保留。**作用域**：若错误源于共享权重/数据（`ρ→1`），上界退化为 `p_q`，CMA 无法检出——只认证「数值稳健」，不认证「语义正确」。

**引理 21（算力受限 VoI 的保守元推理与跨币种均衡）** `VôI(f)=VoI+η_f`，`|η_f|≤σ(f)` 递减。(i) 停止收益 `G(f)` 单峰 ⇒ 最优停止保真度 f*（边际方差收益=边际成本）；(ii) 最大可负担保真度下决策裕度 `<κσ(f)` ⇒ 以 `≥1−η` 概率选「不交互」；(iii) 资源在交互/算力间最优分配满足 `∂VoI/∂ms=∂VoI/∂J`。**系**：算力有双重价值（直接降 U_comp + 锐化 VoI），故「先粗估、近边界再精算」近最优。

**引理 22（能耗-热耦合下的漂移放大）** `f_clk(T)↓ ⇒ N(T)↓ ⇒ ε_t↑ ⇒ U_comp↑, δ_proto↑`（定义 313/引理 19）；不按 T 重规划则可能漂出 δ_match，催生新伪模态。**系**：热预算必须入 `𝒫_feas`，否则长时程部署会悄悄越过数值可信边界。

**定理 18（EDGE 的部署严格包含链）** A99–A101 下：(i) 理想部署（算力足、数值精确、ECE 合格）⇒ U_comp=0、R=全体、EDG 不触发 ⇒ 与 R69 逐指令相同；(ii) `𝒫_feas=∅`/DSS 不可证/MCG-E 越界 ⇒ 与 R68 逐指令相同；(iii) 任意可行计划 `λ_EDGE=λ_floor(U_ale+U_comp+未消解U_epi) ≥ λ_FLUID`（U_comp≥0），且伪模态驱动的交互被抑制 ⇒ 期望风险 `≤` naive FLUID 部署。故 `R70⊇R69⊇R68`。

**定理 19（确定性、守时与无突变）** 定步长 + 预分配 + 静态 WCET ⇒ `π∈𝒫_feas` 时执行 `≤T_max`、无无界停顿，bit-exact 可复现；EDG 由事前谓词触发、资源收缩使可行集单调缩小 ⇒ λ 单调不降；稳健模态子集内选前缀保安全包络，退化是保守切换 ⇒ 控制连续、无突变，换装不变式保持。**系**：可复现的消歧才能进安全案例。

## 7. 本轮最大风险

**一句话**：EDGE-RAS 把可信度押在「跨精度/跨层一致性 = 证据正交」上，但**同一份权重与训练数据会让所有精度一致地错**——CMA 给出的「一致」可能只是**共享偏差的自我确认**，而算力预算又迫使系统在廉价的粗估保真度上过早定型；于是 R70 可能以**确定性、可复现、可认证**的方式自信地犯错——**部署非但没让它更对，反而让它更可信地错**。

**次级风险与缓解**：热节流悄悄改写模态（定义 322 热预算 + 引理 22 + E307）；远程证据陈旧/分区被误当一致（定义 320 的 ⊥ 规则 + E309）；低精度 ODE 发散（DSS 定步长 + NDQ 上界 + 检测门 + E311）；预算过紧饿死安全（三级保真度 + 不赌规则 + 事前 EDG + E303/E315）；确定性虚假安全感（J_EDGE 显式记录，审计不把可复现当正确）；跨层误差相关（HER 的 ρ 估计 + 要求跨传感器/模型族多样性，而非同模型多副本）。
