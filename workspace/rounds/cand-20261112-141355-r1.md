# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；本轮灵感：「评测指标」×「阻抗控制」）

> 第 57 轮把先验从手设换成跨区域摊销、把证据从单模态换成分账对账、把人从常量换成单向状态机，安全的赌注被推到"元先验的质量"。但它与更早各轮共享一个从未被正面处理的盲点：**我们一直在图上决定"走不走、碰不碰"，却几乎不决定"用多大的机械阻抗去碰"**。同样一条"已批准的落足"，硬若磐石地压下与柔软地探一下，是两种截然不同的物理事件：前者可能压碎薄壳、激起接触振荡、把关节力矩打进饱和，后者可能根本读不到刚度、完不成任务。更麻烦的是，**验证这些决定的"评测指标"本身从未被证明有效**——成功率、探针数、假承诺率都是单一工作点上的均值，既看不见尾部风险，也分不清"方法真的更好"还是"把机器人变软、把任务定义变窄"带来的分数。本轮两个灵感各补一块基石：**阻抗控制**把接触从抽象层级 L0/L1/L2 变成可调度、可证明稳定的机械量（力/能量/无源性）；**评测指标**把评测从"报一个分数"变成"签一份可证伪、抗操纵、按风险配平的契约"。合流命题是：**安全的可调维度不是"碰不碰"，而是"以多大阻抗碰"；方法好坏的度量不是单一工作点，而是阻抗-安全-信息前沿上的支配关系**。核心命题由"执行可跟踪、评测可复核的证据说可信"进一步落成 **"阻抗可调度、指标可证伪的证据说可信"**。

核心矛盾：
- **H29（柔顺 vs 信息/任务）**：阻抗是一个双向旋钮。变软降低接触力与能量、天然更安全，但同时降低信噪比（刚度辨识需要力/位移激励）、降低任务能力（按压、拧转、插入需要施力）。极端下"最安全"的策略是瘫软不动——安全证书可以被"什么都不做"轻易满足。
- **H30（阻抗估计 vs 耦合稳定）**：安全证书依赖环境阻抗 θ_e=(K_e,D_e) 的估计，而估计恰恰在硬表面、薄壳、含间隙/延迟的环境里最不可靠；更致命的是，机器人自身阻抗 Z_r 与环境阻抗 Z_e 耦合后可能失稳（接触颤振、极限环），这不是"力有没有超限"能捕捉的，必须有无源性/能量罐级别的保证。
- **H31（指标 vs 有效性/古德哈特）**：任何被当作优化目标的指标都会被博弈。单一成功率在固定阻抗下可被"变软"刷高，也可被选择地形/种子/停止时机刷高；均值掩盖尾部；缺少反事实归因则无法区分机制贡献与基准红利。指标若不先被证明"测的是它声称要测的东西"，前面 57 轮的所有 δ、ε、α 都只是在给自己的考卷打分。

## 0. 直觉与动机

**灵感 1（阻抗控制 → 接触不是离散层级，而是一个可调动力学契约）**
直觉：阻抗控制的核心不是"把末端推到哪"，而是"让末端对外表现为多硬、多黏、多重"。机器人对环境呈现的阻抗 Z_r=(M_d,D_d,K_d) 决定了同样的位移偏差会产生多大接触力；于是安全约束第一次有了一个**连续、可控、可证明**的旋钮：力上限可以通过降低 K_d 直接买到，能量注入可以通过阻尼与能量罐限制。但柔顺不是免费午餐：**变软=少力=少信息=少任务能力**。所以本轮把每个接触阶段都写成一个阻抗调度 z(phase)：接近段柔软（低刚度、高阻尼，先保证不撞坏）、探测段"带力帽的适度刚硬"（为了辨识环境刚度必须施一点力）、承诺段按证据与任务需要匹配阻抗、退出段再次柔软。核心增量：**阻抗既是一个安全通道，也是一个信息通道，二者的兑换率必须显式建模**。

**灵感 2（评测指标 → 指标本身必须是一份可证伪的契约）**
直觉：过去我们说"假承诺率 ↓60%""成功率 +8%"，这些数字有三个原罪：**(i)** 是均值/点估计，看不见尾部（一次不可逆压碎远比一百次轻微超调严重）；**(ii)** 是单一工作点，方法可以靠更保守的阻抗（更软、更慢、更常绕行）换来好看的安全数字，却不说明它是否还有用；**(iii)** 没有反事实，无法排除"分数来自更容易的地形/种子/停止规则"。于是本轮把指标定义成一份**预注册契约**：估计量、尾部泛函、分层、风险预算、信息预算、留出集、停止规则、显著性水平全部先冻结；比较必须在**风险配平**或**性能配平**下进行；每个"机制有效"的声明都必须通过**反事实消融**；每个指标必须报告它对合法扰动（种子/地形/停止时机/任务族内定义）的**脆弱度**。"指标不是给论文看的分数，而是一个能被攻击、能被证伪、能被审计的测量仪器。"

**灵感 3（合流 → 阻抗-评测对偶：指标是阻抗调度器的目标，阻抗是指标自变量的物理实现）**
直觉：两个灵感不是并列的两条腿，而是一个闭环。阻抗调度需要目标函数——不能只最大化安全，否则退化为瘫软；正确的目标只能是"在被认证的指标前沿上取最优"。反过来，指标若脱离阻抗工作点就没有意义——离开"用多硬的阻抗接触"谈成功率，等于离开工作电压谈器件寿命。因此本轮的中心对象是**阻抗-安全-信息-任务前沿**：对每个方法，画出它在不同风险/信息预算下能同时达到的任务表现，用**支配关系**而非单点分数比较。一个方法只有在同样的风险或同样的信息预算下仍更好，才算更好；单点刷分不算。这直接把"靠变软换分"的保守性套利暴露在前沿上。

**灵感 4（证据门再升级 → 机械见证 + 指标见证）**
直觉：第 57 轮证据门管的是"信念与标注"，本轮再加两道现实见证：**机械见证**（本次接触的实测力/位移/能量落在该区域阻抗后验与环境不确定集允许的包络内，且能量罐非负、耦合无源性成立）与**指标见证**（用于给该承诺定级的所有经验常数，都来自预注册、留出且抗扰动的评测契约）。任一见证失败，承诺不得升级到 L2。EV-impedance 成为新的证据类：它可在 L1 顶替一次到访佐证，但**永远不能单独授权不可逆接触**——因为"摸起来对"与"压下去不会坏"是两件事。

**灵感 5（PCE+++ → 双旋钮、双时钟：快环管阻抗，慢环管评测）**
直觉：阻抗检查必须在控制周期内（O(1)），评测与前沿更新可以慢。于是算子拆成：**快时钟**每步算 ρ_Z 与能量罐，越界立刻软化/降档/停（纯安全通道，不需要重新推理）；**慢时钟**做阻抗地图更新、探询规划、指标契约的序贯检验与前沿重估，其结果**只能收紧快环参数（θ_Z↑、F_max↓、K_d 上限↓、佐证数↑），永不放宽**。这样第 57 轮"元推断时延进入控制回路"的风险在结构上被消除，且"评测"不再是事后报告，而是实时收紧安全包络的输入。

## 1. 形式化定义（增量：定义 139–145）

**定义 139（阻抗动作与接触约束 ZAC）** 任务空间阻抗动作 z=(M_d,D_d,K_d,F_max,v_max,ρ_pass)，呈现动力学 M_d ẍ+D_d ẋ+K_d x=F_ext。环境阻抗 θ_e=(K_e,D_e)∈Θ_r，Θ_r 为区域 r 的**声明不确定集**（后验最高密度区或共形集，覆盖 ≥1−α_e）。定义区域安全包络 𝓔(r)={(F,E): F≤F_safe(r), E≤E_budget(r)}（F_safe 由材质/薄壳/载荷上限给，E_budget 由不可逆损伤阈值给）。阻抗裕度

ρ_Z(r,z)=min_{θ_e∈Θ_r} min{ (F_safe(r)−F_max(z,θ_e))/F_scale, (E_budget(r)−E_int(z,θ_e))/E_scale }，

其中 E_int=∫max(0,F·v)dt 为净注入能量。**阻抗健全**要求 ρ_Z≥θ_Z>0，且能量罐 E_tank≥0（无源性不变式）。F_max(z,θ_e) 与 E_int(z,θ_e) 由耦合模型在不确定集上取最坏值。

**定义 140（环境阻抗地图 ZMAP）** 每个区域维护阻抗后验 q_r(K_e,D_e) 与其不确定集 Θ_r，由历次阻抗探针的力-位移响应经贝叶斯/最小二乘更新；标注分辨率 δ_K、覆盖声明 α_e、陈旧度衰减 τ_Z。ZMAP 与第 57 轮区域信念 (μ,k,F_bear) 并列，是地图的**机械层**。新区域无后验时 Θ_r=Θ_prior（全局宽先验），只允许柔软接近与带力帽探测，禁止 L2。

**定义 141（阻抗调度与机械见证 ZSP）** 调度 z(phase)∈{approach,probe,commit,retreat}，相邻阶段阻抗切换须满足能量罐约束（只允许从罐中取用有限能量，罐按被动性补充）。机械见证 EV-impedance ⇔ 实测 (F,x) 与 q_r 在声明置信下相容 ∧ ρ_Z≥θ_Z ∧ E_tank≥0 ∧ 无滑移/颤振；可在 L1 顶替一次到访佐证，**不得单独授权 L2**。负证据 EV-zviol ⇔ 力/能量越界、滑移超限或检测到接触振荡 ⇒ 立即软化并加宽 Θ_r（威胁与证据双通道）。调度器在给定预算下求解
max_{z(·)} E[U_task+λ_I·I(z;θ_e)] s.t. ρ_Z(r,z)≥θ_Z, E_int≤E_budget, E_tank≥0,
其中 I(z;θ_e) 为接触对阻抗参数的期望信息增益（Fisher/互信息近似）。

**定义 142（阻抗感知探询 ZPC）** 探针 p=(z,excitation)（小幅正弦/阶跃/力控扫频），既估计区域语义参数也估计 θ_e；探询价值 VOI_Z(p)=E[信息增益的决策价值]−cost(p)，cost 含时间、能量、磨损与安全风险，且随已注入能量单调上升。探测遵循**带力帽的逐级增硬**：初始 K_d≤K_probe^0，仅当 ρ_Z 仍有余量才允许升硬；每区域探针预算 k_probes 与总能量预算 E_probe 同时约束，探尽→绕行→降档→L2 协商或安全停。

**定义 143（评测指标契约 EMC）** 指标 μ=(estimand, tail, strata, R_budget, I_budget, holdout, stopping, α)，预注册后冻结。有效性六要件：**(M1) 尾部敏感**：用 CVaR_α 或分层最坏值，不用裸均值；**(M2) 配平比较**：只允许"风险配平下的性能"P@R 或"性能配平下的风险"R@P，禁止跨工作点比较；**(M3) 反事实归因**：机制效应须由同种子消融的差分给出且置信区间不含 0；**(M4) 声明校准**：任何上报界/区间在留出环境上的覆盖率 ≥1−α（anytime-valid/conformal）；**(M5) 分布稳健**：须报告对抗/留出分层的最坏值与时移敏感性；**(M6) 抗操纵**：在合法扰动集 𝒫（种子、地形、截止时机、任务族内定义）下报告排序脆弱度，排序不稳定则指标降级为描述性。指标证书 J_ev=(μ,Π,留出集,序列检验,消融记录,脆弱度报告)。

**定义 144（前沿评测 PFE）** 方法 A 可实现的点集 F_A={(P,R,I,E): 存在策略达到}，P 任务表现、R 尾部风险、I 信息量、E 能耗。配平支配：A≻B ⇔ 对每个风险预算 R，P_A(R)≥P_B(R) 且 I_A(R)≥I_B(R)，且至少一处严格；或用前沿超体积 HV 比较。**非空性约束**：任何被接受的证书必须同时满足任务地板 P≥τ_task 与信息地板 I≥τ_info，否则"瘫软不动"不构成方法。报告两个核心量：同任务下的可容许风险上限 R@P，与同风险下的任务表现 P@R。

**定义 145（阻抗-评测对偶证书 ZED）** 联合证书 J_z=(J_p, z(·)/K_d 轨迹, F/E_int 日志, E_tank, q_r/Θ_r, ρ_Z, J_ev, R@P/P@R, 前沿点)。要求双闭合：**(i)** 每个安全数值声明都携带其阻抗工作点/调度与风险预算（否则不可解释）；**(ii)** 每个阻抗调度的选择都必须由某个被认证前沿上的支配点诱导（否则是拍脑袋）。为打断"按指标调阻抗、再按阻抗报指标"的循环论证，强制三条：留出环境与调参环境不相交、指标预注册、机制反事实消融；不满足则 J_z 降级为"实验性"（禁 L2、只许柔软接触）。

## 2. 关键算法伪代码（完整版见产物区）

```python
def impedance_margin(r, z, M, env_uncertainty):      # IP-139
    worst = min(env_uncertainty, key=lambda e: margin_of(z, e, r))
    return margin_of(z, worst, r)                     # 力/能量双预算的最坏裕度

def schedule_impedance(r, phase, M, task, tank):      # IP-141
    z = init_soft(phase)                              # 接近/退出永远柔软
    while needs_stiffer(phase, task) and tank.available():
        cand = stiffen(z, step=K_STEP)
        if impedance_margin(r, cand, M, M.Theta[r]) < theta_Z: break
        z = cand
    return z if tank.valid_for(z) else soften(z)

def mechanical_witness(c, M, tank):                   # IP-141/145
    if c.F > c.F_safe or c.E_int > c.E_budget: return ('soften', 'zviol')
    if c.slip > c.slip_max or oscillation(c.force): return ('soften', 'zviol')
    if impedance_margin(c.r, c.z, M, M.Theta[c.r]) < theta_Z: return ('reject', 'no_margin')
    return ('ok',) if tank.nonnegative() else ('soften', 'passivity')

def metric_contract_ok(J_ev):                         # IP-143
    return all([J_ev.preregistered, J_ev.M1_tail, J_ev.M2_matched,
                J_ev.M3_counterfactual, J_ev.M4_coverage >= 1 - J_ev.alpha,
                J_ev.M5_worst_stratum, J_ev.M6_fragility_reported])
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| ZAC | O(1)/步 | O(\|Θ_r\|) | 不确定集覆盖、最坏值保守 |
| ZMAP | O(d_K)/探针；更新 O(\|Θ\|) | O(\|V\|·d_K) | 覆盖声明诚实、陈旧衰减 |
| ZSP | O(1)/控制步；规划 O(\|phase\|·k) | O(\|phase\|) | 能量罐不变式、只软不硬 |
| ZPC | O(k·(d_K+C_VOI)) | O(\|σ\|+k) | 力帽逐级、能量预算终止 |
| EMC | O(N·S) 离线 | O(N·S) | 预注册、留出不相交 |
| PFE | O(\|Π\|·\|R\|) | O(\|Π\|·\|R\|) | 配平比较、非空地板 |
| ZED | 组合 | 组合 | 双闭合、循环论证三护栏 |

**正确性定理（Robust Impedance-Metric Soundness, RIMS 概要）**：在 A33–A40 之上加 **(A41)** 阻抗健全与能量罐不变式：ρ_Z≥θ_Z 在 Θ_r 上取最坏且 E_tank≥0，阻抗切换不注入额外能量；**(A42)** 环境阻抗不确定集覆盖 ≥1−α_e 且陈旧衰减诚实；**(A43)** 评测契约预注册、留出集与调参集不相交、声明校准且脆弱度已报告。则：(i) **鲁棒机械安全**：对任意 θ_e∈Θ_r，接触力与净注入能量落在 𝓔(r) 内，且耦合系统保持无源（不产生自激振荡）；(ii) **非空性**：被接受的方法必须同时越过任务与信息地板，排除"瘫软即安全"的空证书；(iii) **不可套利**：在配平比较下，单纯降低 K_d 所获得的安全提升无法转化为排名提升——它要么落在前沿上（如实展示任务/信息损失），要么因越过地板被拒；(iv) **指标可证伪**：任何机制效应须在反事实消融下显著，任何上报界须在留出环境上校准；(v) 部署界在前沿点 (R@P,P@R) 上联合第 57 轮给出，并把"不确定集未覆盖"与"指标失效"作为显式扣项。

```python
def margin_of(z, theta_e, r):
    F = worst_force(z, theta_e)                     # 耦合模型最坏接触力
    E = worst_energy(z, theta_e)                    # 净注入能量上界

               (E_budget(r) - E) / E_scale)

def impedance_margin(r, z, M):
    Theta = M.Theta[r]                              # 声明不确定集（覆盖>=1-alpha_e）
    return min(margin_of(z, e, r) for e in Theta)   # 最坏情形，保守

    return tank.nonnegative() and tank.valid_for(z)
```

```python
def schedule_impedance(r, phase, M, task, tank):
    z = SOFT_PRESET[phase]                          # approach/retreat 永远柔软
    if phase in ('probe', 'commit'):
        while needs_stiffer(phase, task) and tank.available():
            cand = stiffen(z, step=K_STEP)
            if impedance_margin(r, cand, M) < theta_Z: break
            if not tank.valid_for(cand): break
            z = cand
    return z if impedance_certified(r, z, M, tank) else soften(z)

def mechanical_witness(c, M, tank):
    if c.F > c.F_safe or c.E_int > c.E_budget:
        return ('soften', 'force_energy_violation')
    if c.slip > c.slip_max or oscillation(c.force):
        M.Theta[c.r] = widen(M.Theta[c.r], gamma_w)   # 威胁+证据双通道
        return ('soften', 'slip_or_chatter')
    if impedance_margin(c.r, c.z, M) < theta_Z:
        return ('reject', 'impedance_margin')
    if not tank.nonnegative():
        return ('soften', 'passivity')
    return ('ok', 'EV-impedance')                   # 仅可顶替 L1 到访佐证
```

```python
def metric_contract_ok(mu, J_ev):
    return all([
        J_ev.preregistered and J_ev.frozen,
        mu.tail in ('CVaR', 'worst_stratum'),        # M1 尾部敏感

def fragility(mu, policies, perturb_set):
    base = ranking(mu, policies)
    worst = 0.0
    for pert in perturb_set:                         # 种子/地形/截止/任务族内定义

        worst = max(worst, rank_distance(base, r))
```

```python
def frontier(policy_family, envs, budgets):
    pts = []
    for pi in policy_family:
        for R in budgets.risk:
            P = best_task_at_risk(pi, envs, R)       # P@R
            I = best_info_at_risk(pi, envs, R)
            E = energy_at(pi, R)
            pts.append(Point(P, R, I, E))
    return pareto_filter(pts, floors=(tau_task, tau_info))   # 非空地板

def dominates(F_A, F_B):
    return (all(task_at_risk(F_A, R) >= task_at_risk(F_B, R)
                for R in union_risks(F_A, F_B))
            and all(info_at_risk(F_A, R) >= info_at_risk(F_B, R)
                    for R in union_risks(F_A, F_B))
            and (exists_strict(F_A, F_B)))

def frontier_score(F_A, F_B):
    if dominates(F_A, F_B): return ('A>B',)
    if dominates(F_B, F_A): return ('B>A',)
    return ('incomparable', HV(F_A), HV(F_B))        # 报告不可比与超体积
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ZAC | O(1)/控制步 | O(\|Θ_r\|) | 最坏情形保守、能量罐不变式（A41） |
| ZMAP | O(d_K)/探针；更新 O(\|Θ\|) | O(\|V\|·d_K) | 覆盖 ≥1−α_e、负证据加宽、陈旧衰减（A42） |
| ZSP | O(1)/步，规划 O(\|phase\|·k) | O(\|phase\|) | 只从罐取能、只软不硬 |
| ZPC | O(k·(d_K+C_VOI)) | O(\|σ\|+k) | 力帽逐级、能量预算终止 |
| EMC | O(N·S) 离线 | O(N·S) | 预注册、留出不相交、校准（A43） |
| PFE | O(\|Π\|·\|R\|) | O(\|Π\|·\|R\|) | 配平比较、非空地板、脆弱度 |
| ZED | 组合 | 组合 | 双闭合、循环论证三护栏 |

**正确性定理（Robust Impedance-Metric Soundness, RIMS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 阻抗健全与无源性：ρ_Z(r,z)≥θ_Z 在声明不确定集 Θ_r 上取最坏，能量罐 E_tank≥0 且阻抗切换只从罐中取用有限能量（被动性补给）；**(A42)** 环境阻抗不确定集覆盖 ≥1−α_e，陈旧衰减与负证据加宽诚实；**(A43)** 评测契约预注册冻结、留出集与调参/校准集不相交、上报界在留出环境覆盖 ≥1−α、脆弱度已报告。则：

1. **鲁棒机械安全**：∀θ_e∈Θ_r，接触力 F≤F_safe(r)、净注入能量 E_int≤E_budget(r)；且机器人阻抗 Z_r 无源 ⇒ 对任意无源环境耦合稳定（不产生自激接触振荡）。该保证不依赖 θ_e 点估计，只依赖 Θ_r 覆盖与能量罐，故对硬表面/薄壳/延迟环境同样成立（只要落在 Θ_r）。
2. **非空性（反瘫软）**：被接受的证书必须同时满足任务地板 P≥τ_task 与信息地板 I≥τ_info；故"把 K_d 降到零、什么都不做"不能构成安全方法，也不会进入前沿。
3. **无保守性套利**：在风险配平 P@R 或性能配平 R@P 下，单纯软化阻抗带来的安全提升不改变排名——它只能如实沿前沿移动（展示任务/信息损失），或在越过地板时被拒。故"靠变软刷分"被结构性阻断。
4. **指标可证伪与抗操纵**：任何机制效应须在反事实消融下置信区间不含 0（M3）；任何排序须在合法扰动下报告脆弱度，超过 θ_frag 即降级（M6）；任何上报界须在留出环境校准（M4）。因此"通过"不再是可以由选择种子/地形/停止时机制造的仪式。
5. **双闭合与循环论证阻断**：J_z 要求每个安全数值携带其阻抗工作点与风险预算，每个阻抗调度由被认证前沿上的点诱导；且留出/调参不相交、指标预注册、机制消融三条同时成立才发给完整证书，否则降级为实验性并禁止 L2。
6. **终止性**：每区域探针 ≤k_probes、能量消耗 ≤E_probe，快环每次越界只走一次降柔，PCE+++ 在有限步内终止于 {承诺, 绕行, L2 协商, 安全停}。
7. **部署界**（对检查点与风险预算取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − P(Θ_r 未覆盖) − P(能量罐违反) − P(指标契约失效)
             − P(古德哈特/脆弱度超阈) − P(τ_int ∧ 安全停失效)
```

关键：**阻抗把安全从"离散层级"变成"连续可证明量"，且最坏裕度+能量罐使保证不依赖环境估计；指标把"更好"从"单点均值"变成"配平前沿支配"，且非空地板+配平比较+预注册+反事实把"变软刷分"和"选种子刷分"两条套利路径同时堵死。** 两个灵感构成闭环：评测契约是阻抗调度器的目标函数，阻抗调度是指标自变量的物理实现；联合证书 J_z 确保这个闭环不是自证。

## 6. 本轮最大风险

**一句话**：本轮把安全旋钮从"碰不碰"换成"以多硬碰"，最大风险是"阻抗换安全"退化为"躺平换安全"——越软越安全但越没信息、越完不成任务，而前沿评测若只在有限地形上做配平比较，方法仍可靠整体变软与窄化任务定义在基准上刷分，真正的危险（硬表面/薄壳处环境阻抗失配导致的接触失稳）恰好落在"低刚度=低风险"这一单调假设之外。
