# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「安全性」×「基准测试」）

> 第 60 轮的 SGEC 把「执行层→证据层」升级为「认知驱动的场景-执行闭环」，用 SSM×CIEC×EPIR×SERC×PCE++++ 实现场景先验、意图锁定、证据防丢失。但在「安全性×基准测试」的透镜下，**两个根本弱点**暴露：
> 1. **安全性是事后二元护栏，不是在线可审计的信用**：第 60 轮的「场景置信度<0.7 回退」「意图 2s 超时」「EPIR 序列号+哈希」「SIC 三元校验」只是四条硬阈值。它们既不刻画**风险的累积与偿还**（一次误判可被数次"看起来成功"的执行掩盖），也回答不了「凭什么说这一刻是安全的」——安全论证停留在部署前的静态文档，而 SGEC 在运行时**自己改写约束**，静态论证随场景漂移而失效。
> 2. **基准测试只测任务成功率，不测安全覆盖**：E187–E191 度量的是识别准确率、响应分位、恢复率、适应率——这些是"任务性能"而非"安全性质"。系统可能在 Z_scene×I×Φ_fault×T 的高维联合空间里**只走了容易的角落**，用 85% 的准确率掩盖 15% 的灾难性误判。没有覆盖率、没有近失（near-miss）、没有统计置信界，「≥85%」无法外推为「安全」。

## 0. 直觉与动机

**灵感 1（安全性 → 安全信用包络 SCE）**
直觉：安全不是开关，而是一块**电池**。每一次高风险动作（场景不确定、意图冲突、靠近 K_safe 边界）都在**放电**；每一条自洽证据（哈希/序列一致、XMC+ 一致、力裕度充足）都在**充电**。系统应实时维护一块「安全信用」S_credit∈[0,1]，低于 θ_nom 就退回保守，低于 θ_fallback 就安全停机。关键洞见：**把"安全"从离散断言变成连续状态变量**，让"剩余安全裕度"像电量一样可观测、可预算、可耗尽保护。

**灵感 2（安全性 → 运行时安全论证 RSC）**
直觉：静态安全案例（GSN 文档）假设「部署即定型」，但 SGEC 在运行时改写 K_safe、锁定约束、切换场景——论证的假设被系统自己不断推翻。应当把安全案例**编译成运行时图**：每个 Claim 节点挂一条 confidence，每条 Evidence 链接到 EPIR 的真实 EV-exec；一旦某条假设被违反（defeat），信心沿图传播，根 Claim 被推翻即触发安全响应。关键洞见：**安全论证必须是"活"的、可被证据实时反驳的**，且反驳记录本身进入证据链。

**灵感 3（基准测试 → 场景-安全基准 SSB）**
直觉：现有基准给的是「成功率排行榜」，安全研究需要的是「**近失地图**」。设计一个在 Z_scene × I × Φ_fault × T 联合空间上采样的基准，报告安全违约率 SVR、近失率 NMR、覆盖率 C_safe，并用 Clopper–Pearson 上界给出「在 1−δ 置信下 p_fail ≤ ε」的统计保证。关键洞见：**覆盖率不是安全，但没有覆盖率的安全结论是空话**——必须显式区分"测过的"和"没测过的"。

**灵感 4（基准测试 → 反例引导安全基准 FSB / 蜕变关系 MRS）**
直觉：随机采样在稀疏的危险角落极度低效。用**反例引导**（STL 鲁棒度 ρ 作为适应度）主动搜索最坏场景序列；同时用**蜕变关系**（如"降低噪声不应让违约率上升""把场景错判为更保守场景不应降低安全"）做无需真值的性质检验——违反蜕变关系就是一个安全 bug 的强信号。关键洞见：**安全基准的目标不是刷分，而是尽快证伪**。

**灵感 5（合流 → 安全-基准-证据闭环 SBEC）**
直觉：SSB 出题 → FSB 加难 → SGEC 执行 → SCE 记账 → RSC 判证 → EPIR 存证 → 覆盖率回灌出题。反例进入回归集，证书 Cert_safe 随证据刷新。形成「**以基准证伪、以信用守卫、以论证审计、以证据复核**」的闭环。

**灵感 6（PCE+++++ → 安全/基准双预算）**
直觉：认知预算之上再加两个：B_safe（必须保留的最小安全裕度，不可被探索挪用）、B_bench（证伪采样预算）。若 B_safe 低于保留线 ⇒ 停止探索；若 B_bench 耗尽 ⇒ 退回回归集。关键洞见：**探索预算不能透支安全预算**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（安全信用包络 SCE）** 状态变量 S_credit(t) ∈ [0,1]，动力学：
```
S_credit(t+1) = clip( S_credit(t) − Σ_i w_i·r_i(t) + Σ_j v_j·d_j(t), 0, 1 )
```
- **风险项 r**（放电）：r_scene = −log P(z_scene|o_t)（场景不确定）；r_intent = τ_response/τ_deadline（意图时延）；r_exec = D⁺_t（执行分歧，归一化）；r_bound = dist(K_t, ∂K_safe)/dist_max（越贴边界越危险）。
- **偿还项 d**（充电）：d_ev = 1[hash ∧ seq 一致]·(1−ECE)（证据自洽）；d_margin = min(1, F_margin/F_nom)（力裕度充足）。
- **阈值**：θ_nom > θ_fallback > 0。运行模式：
  - S_credit ≥ θ_nom ⇒ `NOMINAL`（允许场景先验 + 完整闭环）
  - θ_fallback ≤ S_credit < θ_nom ⇒ `CONSERVATIVE`（回退通用先验/默认约束）
  - S_credit < θ_fallback ⇒ `SAFE_STOP`（Simplex 后备控制器，撤销一切场景先验）
- **吸能不变式**：r_i 有界、d_j ≥ 0 时 S_credit ≥ 0；因 θ_fallback > 0 先于归零触发，存在非空安全吸收区，避免"归零猝死"。

**定义 162（运行时安全论证 RSC）** 安全案例图 G_rt = (C, S, E, conf, defeat)：
- **Claim 节点** c ∈ C，置信度 conf(c) ∈ [0,1]；**Strategy** 组合子 conf(s) = ⊗_children conf。
- **Evidence 链接** e ∈ E：每个叶 Claim 必须链接到 EPIR 中的真实 EV-exec（哈希锚定），无悬空义务。
- **defeat 类型**：`assumption_violation`（假设被违反）/`evidence_stale`（证据过期）/`context_shift`（场景漂移使上下文失效）。
- **传播**：defeat(c)=true 若 conf(c)<τ_claim 或任一假设被违反；沿父链上行，根 Claim defeat ⇒ 强制安全响应（映射到 SCE 模式）。
- **审计**：每次 defeat 生成 proof-obligation 事件，append-only 写入 EPIR，供 Cert_safe 复核。

**定义 163（场景-安全基准 SSB）** 联合输入空间 X_bench = Z_scene × I × Φ_fault × T，其中
Φ_fault = {sensor_dropout, ros_loss, actuator_degrade, intent_ambiguity, scene_misclass}。采样 D_n ~ P_bench。
度量：
- SR = (1/n)Σ success；SVR = (1/n)Σ 1[硬约束违约]；NMR = (1/n)Σ 1[S_credit 跌破 θ_nom 但无违约]（近失）
- C_safe = 已覆盖且达到最小密度的 (scene,intent,fault) 单元数 / 总单元数
- SCVR = Cert_safe 有效的运行占比
- **统计保证**：违约概率 p_fail 的 (1−δ) 上界 p̄ = CP_upper(k, n, δ)，声明「p_fail ≤ p̄」。表内所有安全指标必须以上界而非点估计报告。

**定义 164（反例引导安全基准 FSB + 蜕变关系 MRS）** 反例搜索：
```
max_x ρ_STL(x)   s.t. x ∈ X_bench, budget = B_bench
fitness(x) = ρ_STL(x) + λ_cov·Δcoverage(x)     # ρ<0 即违约
```
**蜕变关系** R = {R1,R2,R3,R4}（无需真值的性质检验）：
- R1 噪声单调：noise↓ ⇒ SVR 不增
- R2 保守错判单向：若 ẑ 被错判为**比真值更保守**的场景，则 SVR 不增
- R3 危险意图：追加 'danger' 意图 ⇒ SVR 不增
- R4 场景切换频率：降低切换频率 ⇒ NMR 不增
违反任一 R 记为 `metamorphic_failure`，等价于发现一个安全缺陷，直接进回归集。

**定义 165（安全-基准-证据闭环 SBEC）** 算子 SBEC(M, benchmark, budget)：
```
① SSB.sample_batch() → X_batch
② FSB.falsify(X_batch, ρ_STL) → X_hard
③ for x in X_hard: SERC(M, ...) 执行（复用第 60 轮闭环）
④ SCE.update(S_credit; r(x), d(x))
⑤ RSC.evaluate(evidence) → root_conf, defeats
⑥ EPIR.append(EV-exec, proof_obligations, Cert_safe)
⑦ coverage_feedback(X_hard) → P_bench
⑧ if violation or metamorphic_failure: regression_suite.add(counterexample)
⑨ Return (S_credit, root_conf, Cert_safe, coverage, counterexamples)
```

**定义 166（PCE+++++ 安全/基准预算）** B = (B_safe, B_bench, B_scene, B_intent, B_ros, B_exec)：
- **B_safe**：必须保留的最小安全裕度（探索不可挪用）；**B_bench**：证伪采样/变异预算。
```
voi_safe(π) = VOI_meta(π) − cost_safe(π) − cost_bench(π) − cost_cog(π) − cost_exec(π)
cost_safe  = λ_safe·max(0, θ_reserve − S_credit)
cost_bench = λ_bench·n_falsify
```
规则：B_safe < θ_reserve ⇒ 停探索、只执行保守策略；B_bench 耗尽 ⇒ 回归集模式；认知/执行预算沿用第 60 轮降级链。

**定义 167（可验证安全证书 Cert_safe）**
```
Cert_safe = (claims, evidence_digest, coverage_claim, stat_bound, horizon, signature)
Verify(Cert_safe) = soundness ∧ completeness ∧ freshness ∧ coverage
```
- **soundness**：SVR 上界 p̄ ≤ ε_max（统计保证必须存在）
- **completeness**：每个叶 Claim 有有效 Evidence 链接（无悬空义务）
- **freshness**：now ≤ horizon 且所有证据未 stale、未被 context_shift 推翻
- **coverage**：C_safe ≥ C_min
证书是 dispatch 的必要条件；验证可被第三方独立复算（哈希链 + 置信界 + 覆盖审计）。

**定义 168（安全门控决策 SGD）** dispatch(K_t) 放行条件：
```
allowed(K_t) ⟺ S_credit ≥ θ_nom ∧ root_conf ≥ τ_case ∧ Verify(Cert_safe) = ⊤
elif S_credit ≥ θ_fallback: dispatch(K_conservative)   # 保守但不停机
else: SAFE_STOP
```
即「信用 × 论证 × 证书」三重门控：三者同时满足才放行场景先验。

## 2. 关键算法伪代码

### IP-161 SCE（安全信用包络）

```python
class SafetyCreditEnvelope:
    def __init__(self, theta_nom=0.7, theta_fallback=0.3,
                 w=(0.25, 0.15, 0.25, 0.35), v=(0.4, 0.3)):
        self.s = 1.0
        self.theta_nom, self.theta_fallback = theta_nom, theta_fallback
        self.w, self.v = np.array(w), np.array(v)

    def update(self, r_scene, r_intent, r_exec, r_bound,
               d_ev, d_margin):
        r = self.w @ np.array([r_scene, r_intent, r_exec, r_bound])
        d = self.v @ np.array([d_ev, d_margin])
        self.s = float(np.clip(self.s - r + d, 0.0, 1.0))
        return self.mode()

    def mode(self):
        if self.s >= self.theta_nom:
            return 'NOMINAL'
        if self.s >= self.theta_fallback:
            return 'CONSERVATIVE'
        return 'SAFE_STOP'
```

### IP-162 RSC（运行时安全论证）

```python
class RuntimeSafetyCase:
    def __init__(self, graph, tau_claim=0.6):
        self.g = graph              # DAG: claims/strategies/evidence
        self.tau_claim = tau_claim

    def evaluate(self, evidence_bus):
        conf = {}
        for c in self.g.topo_leaves():
            e = evidence_bus.get(c.evidence_ref)
            conf[c.id] = 1.0 if (e and e.hash_ok and not e.stale) else 0.0
        for c in self.g.topo_internal():
            conf[c.id] = float(np.prod([conf[k] for k in c.children]))
        defeats = [c.id for c in self.g.claims
                   if conf[c.id] < self.tau_claim or self.g.assumption_broken(c)]
        return conf[self.g.root], defeats

    def emit_proof_obligation(self, claim_id, epir):
        epir.append({'type': 'proof_obligation', 'claim': claim_id,
                     'ts': time.time()})
```

### IP-163 SSB + IP-164 FSB（基准与反例引导）

```python
class ScenarioSafetyBenchmark:
    def __init__(self, scenes, intents, faults):
        self.units = set(itertools.product(scenes, intents, faults))

    def sample_batch(self, n, p_bench):
        batch = [p_bench.sample() for _ in range(n)]
        for x in batch:
            self.units_covered.add((x.scene, x.intent, x.fault))
        return batch

    def report(self, results, delta=0.05):
        n = len(results)
        k = sum(1 for r in results if r.hard_violation)
        p_bar = clopper_pearson_upper(k, n, 1 - delta)
        return {'SR': np.mean([r.success for r in results]),
                'SVR': p_bar, 'NMR': np.mean([r.near_miss for r in results]),
                'C_safe': len(self.units_covered) / len(self.units)}

def falsify(batch, rho_stl, budget):
    hard = []
    for _ in range(budget):
        x = mutate(argmax(batch, key=lambda z: rho_stl(z) + 0.3*novel(z)))
        hard.append(x)
    return hard
```

### IP-165 SBEC（安全-基准-证据闭环）

```python
def safety_benchmark_evidence_closure(M, benchmark, budget):
    batch = benchmark.sample_batch(256, M.p_bench)
    hard = falsify(batch, M.rho_stl, budget.B_bench)
    for x in hard:
        M, _, D_plus, ev, _ = closed_loop_exec_probe(M, x, M.budget)
        mode = M.sce.update(*risk_terms(x, D_plus), *deposit_terms(ev))
        root_conf, defeats = M.rsc.evaluate(M.evidence_bus)
        cert = M.certify(root_conf, benchmark)
        M.epir.append({'EV': ev, 'defeats': defeats,
                       'cert': cert, 'mode': mode})
        if defeats or M.metamorphic_failure(x):
            M.regression_suite.add(x)
    M.p_bench = coverage_feedback(hard, M.p_bench)
    return M, M.sce.s, root_conf, cert, benchmark.report(hard)
```

### IP-166 PCE+++++（安全/基准预算）

```python
class SafetyBenchBudget:
    def __init__(self, b_safe_reserve=0.4, b_bench=1000, cog=None, exec_b=None):
        self.theta_reserve = b_safe_reserve
        self.B_bench = b_bench
        self.cog = cog
        self.B_exec = exec_b

    def explore_allowed(self, s_credit):
        return s_credit - self.theta_reserve > 0 and self.B_bench > 0

    def mode(self, s_credit):
        if not self.explore_allowed(s_credit):
            return 'REGRESSION_ONLY' if self.s_credit_safe(s_credit) else 'STOP'
        return 'NORMAL'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCE | O(1)/更新 | O(1) | S_credit∈[0,1]，SAFE_STOP 先于归零 |
| RSC | O(\|C\|+\|E\|) 评估 | O(\|C\|+\|E\|) | 无悬空义务；defeat 传播到根 |
| SSB | O(n) 采样 | O(cells) | 覆盖率 C_safe 可审计；SVR 带上界 |
| FSB | O(B_bench·cost(ρ)) | O(batch) | 反例单调进回归集 |
| SBEC | O(闭环) | 复用 | 信用/论证/证书一致刷新 |

**正确性定理（SBC，Safety-Benchmark Closure）**：
假设 A66–A70 成立：
**(A66)** SCE：r_i 有界、d_j ≥ 0，θ_fallback > 0 ⇒ 存在非空安全吸收区，S_credit 不为负且 SAFE_STOP 先于归零。
**(A67)** RSC：叶 Claim 证据哈希锚定且未 stale，defeat 沿 DAG 单调上行，根 defeat ⇒ 强制安全响应。
**(A68)** SSB：采样独立同分布，Clopper–Pearson 上界 p̄ 在 1−δ 置信下覆盖真实 p_fail。
**(A69)** FSB：STL 鲁棒度 ρ 对违约符号正确（ρ<0 ⟺ 违约），蜕变关系在安全系统上必成立。
**(A70)** Cert_safe：soundness/completeness/freshness/coverage 四谓词同时成立才签发，验证可独立复算。

则：
1. **信用守卫性**：S_credit < θ_nom ⇒ 系统必进入 CONSERVATIVE 或 SAFE_STOP，不存在"高信用假象下的裸奔"。
2. **论证活性**：任一假设被 context_shift 推翻 ⇒ 根 Claim defeat ⇒ 安全响应，静态安全案例的"部署即定型"失效被消除。
3. **基准可信性**：安全指标以统计上界报告，覆盖率未达标时 Cert_safe 不得签发（覆盖不足的安全声明被拒绝）。
4. **证伪有效性**：metamorphic_failure 或 ρ<0 必进回归集，安全缺陷不因一次通过而被遗忘。
5. **门控完备性**：dispatch 放行 ⟺ 信用 ∧ 论证 ∧ 证书三重成立，任一不满足即降级或停机。

## 5. 本轮最大风险

**一句话**：若基准采样与运行时证据共用同一套有偏模型，S_credit 与 Cert_safe 会被「自洽但错误」的证据循环充高，产出一张"自信满满却错"的安全证书——必须用独立 oracle、OOD 留出集、对抗证伪和证据多样性打断这个自证循环，否则「基准测过」会异化为「基准替你背书」。

> 承接第 60 轮 IP-153~160（SGEC 场景感知闭环 SSM×CIEC×EPIR×SERC×PCE++++）。本轮把「场景安全」从**四条事后硬阈值**升级为 **「可审计、可证伪、可统计保证」的安全工程闭环**：安全信用包络 SCE 把安全变成连续可预算的状态变量；运行时安全论证 RSC 把静态 GSN 变成活图；场景-安全基准 SSB 把"成功率榜"升级为"近失地图 + 统计上界"；反例引导 FSB 与蜕变关系 MRS 把基准目标从刷分改成证伪；SBEC 将三者串成「出题→加难→执行→记账→判证→存证→回灌」；PCE+++++ 增设安全/基准双预算；Cert_safe 提供可独立复算的安全证书。核心口号：**「以基准证伪、以信用守卫、以论证审计、以证据复核」**。

## 2. 关键算法伪代码

### IP-161 SCE（安全信用包络）

```python
class SafetyCreditEnvelope:
    def __init__(self, theta_nom=0.7, theta_fallback=0.3,
                 w=(0.25, 0.15, 0.25, 0.35), v=(0.4, 0.3)):
        self.s = 1.0
        self.theta_nom, self.theta_fallback = theta_nom, theta_fallback
        self.w, self.v = np.array(w), np.array(v)

    def update(self, r_scene, r_intent, r_exec, r_bound,
               d_ev, d_margin):
        r = self.w @ np.array([r_scene, r_intent, r_exec, r_bound])
        d = self.v @ np.array([d_ev, d_margin])
        self.s = float(np.clip(self.s - r + d, 0.0, 1.0))
        return self.mode()

    def mode(self):
        if self.s >= self.theta_nom:
            return 'NOMINAL'
        if self.s >= self.theta_fallback:
            return 'CONSERVATIVE'
        return 'SAFE_STOP'
```

### IP-162 RSC（运行时安全论证）

```python
class RuntimeSafetyCase:
    def __init__(self, graph, tau_claim=0.6):
        self.g = graph              # DAG: claims/strategies/evidence
        self.tau_claim = tau_claim

    def evaluate(self, evidence_bus):
        conf = {}
        for c in self.g.topo_leaves():
            e = evidence_bus.get(c.evidence_ref)
            conf[c.id] = 1.0 if (e and e.hash_ok and not e.stale) else 0.0
        for c in self.g.topo_internal():
            conf[c.id] = float(np.prod([conf[k] for k in c.children]))
        defeats = [c.id for c in self.g.claims
                   if conf[c.id] < self.tau_claim or self.g.assumption_broken(c)]
        return conf[self.g.root], defeats

    def emit_proof_obligation(self, claim_id, epir):
        epir.append({'type': 'proof_obligation', 'claim': claim_id,
                     'ts': time.time()})
```

### IP-163 SSB + IP-164 FSB（基准与反例引导）

```python
class ScenarioSafetyBenchmark:
    def __init__(self, scenes, intents, faults):
        self.units = set(itertools.product(scenes, intents, faults))
        self.units_covered = set()

    def sample_batch(self, n, p_bench):
        batch = [p_bench.sample() for _ in range(n)]
        for x in batch:
            self.units_covered.add((x.scene, x.intent, x.fault))
        return batch

    def report(self, results, delta=0.05):
        n = len(results)
        k = sum(1 for r in results if r.hard_violation)
        return {'SR': np.mean([r.success for r in results]),
                'SVR': clopper_pearson_upper(k, n, 1 - delta),
                'NMR': np.mean([r.near_miss for r in results]),
                'C_safe': len(self.units_covered) / len(self.units)}

def falsify(batch, rho_stl, budget):
    hard = []
    for _ in range(budget):
        x = mutate(argmax(batch, key=lambda z: rho_stl(z) + 0.3*novel(z)))
        hard.append(x)
    return hard
```

```python
def safety_benchmark_evidence_closure(M, benchmark, budget):
    batch = benchmark.sample_batch(256, M.p_bench)
```

### IP-167 PCE+++++（安全/基准预算）

```python
class SafetyBenchBudget:
    def __init__(self, b_safe_reserve=0.4, b_bench=1000, cog=None, exec_b=None):
        self.theta_reserve = b_safe_reserve
        self.B_bench = b_bench
        self.cog = cog
        self.B_exec = exec_b

    def explore_allowed(self, s_credit):
        return s_credit - self.theta_reserve > 0 and self.B_bench > 0

    def mode(self, s_credit):
        if not self.explore_allowed(s_credit):
            return 'REGRESSION_ONLY' if s_credit > 0 else 'STOP'
        return 'NORMAL'
```

### IP-168 Cert_safe（可验证安全证书）

```python
def certify(root_conf, benchmark, svr_upper, c_min=0.8, eps_max=0.02):
    cert = Cert(
        claims=benchmark.root_claims,
        evidence_digest=hash_chain(benchmark.evidence),
        coverage_claim=benchmark.coverage,
        stat_bound=svr_upper,
        horizon=now() + 3600,
    )
    ok = (svr_upper <= eps_max and root_conf >= 0.6
          and benchmark.coverage >= c_min
          and all(has_evidence(c) for c in cert.claims))
    return cert if ok else None

def verify(cert, now):
    return (cert.stat_bound <= eps_max
            and all(has_evidence(c) and not stale(c) for c in cert.claims)
            and now <= cert.horizon
            and cert.coverage_claim >= c_min
            and recompute_digest(cert) == cert.evidence_digest)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| SCE | O(1)/更新 | O(1) | S_credit∈[0,1]，SAFE_STOP 先于归零 |
| RSC | O(\|C\|+\|E\|) | O(\|C\|+\|E\|) | 无悬空义务，defeat 传播到根 |
| SSB | O(n) 采样 | O(cells) | SVR 以 CP 上界报告 |
| FSB | O(B_bench·cost(ρ)) | O(batch) | 反例单调进回归集 |
| SBEC | O(闭环) | 复用 | 信用/论证/证书一致刷新 |

**正确性定理（SBC）**：若 A66–A70 成立，则：
1. **信用守卫性**：S_credit < θ_nom ⇒ 系统必入 CONSERVATIVE/SAFE_STOP，排除"高信用假象下的裸奔"。
2. **论证活性**：任一假设被 context_shift 推翻 ⇒ 根 Claim defeat ⇒ 安全响应，消除"部署即定型"失效。
3. **基准可信性**：安全指标以统计上界报告，覆盖率未达标时 Cert_safe 不得签发。
4. **证伪有效性**：metamorphic_failure 或 ρ<0 必进回归集，安全缺陷不被遗忘。
5. **门控完备性**：dispatch 放行 ⟺ 信用 ∧ 论证 ∧ 证书三重成立。

## 5. 本轮最大风险

**一句话**：若基准采样与运行时证据共用同一套有偏模型，S_credit 与 Cert_safe 会被「自洽但错误」的证据循环充高，产出一张"自信满满却错"的安全证书——必须用独立 oracle、OOD 留出集、对抗证伪和证据多样性打断这个自证循环，否则「基准测过」会异化为「基准替你背书」。
