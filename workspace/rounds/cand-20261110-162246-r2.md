# 第 47 轮（承接第 46 轮产物 v23；本轮灵感：多任务学习 × 传感器融合） · MTL-Fusion-Cert：多任务共享表征与多传感器融合下的联合任务证书与干扰感知调度（架构 v11）

> 承接第 45 轮 v10 Energy-Context-Depth 与第 46 轮产物 v23 Memory-Safety-Voice。v10 把感知从「模态点选择」升级为能量租约约束下的条件可观测性调度，v23 又把记忆检索、语音接地与安全绑定接进全局决策。但二者共享一个未被审查的隐含假设 **H5：各感知任务（姿态、深度补全、语义上下文、语音接地、接触预测）彼此独立，传感器融合只是把可用模态「相加」，因此每个任务/模态的共形半径 r_ω 可独立校准、独立失效**。本轮两个灵感词精确击穿 H5：**多任务学习**把 K 个任务压进共享编码器 f_θ，退化层上的任务干扰/负迁移会让一个任务头的错误经共享表征污染另一个头；**传感器融合**把 RGB/双目/深度/IMU/轮速/本体/语音在融合图 G_t 上耦合，外参漂移、时间失步、相关失效会让一组单模态证书「同时」静默失效。新的核心问题：**如何在共享表征 + 融合图下签发跨任务、跨传感器的联合覆盖证书，并在能量/时延约束下动态选择任务头子集 K_t 与传感器子集 S_t，而当干扰张量被低估或融合租约过期时，联合证书不得静默失效**。

## 0. 直觉与动机

**灵感 1（多任务学习 → 任务干扰是证书的新污染源）**
直觉：共享编码器是「带宽复用」也是「故障耦合」。在普通纹理层，深度补全头与姿态头共享的特征互不干扰；但在透明/镜面/弱纹理/深度空洞层，深度头为了补洞会学出「平滑先验」，这个先验经共享表征反向污染姿态头的特征，导致姿态半径膨胀——这就是负迁移（negative transfer）。因此证书不能按任务独立签发，必须用**任务干扰张量**把「共享表征税」显式计入半径。

**灵感 2（传感器融合 → 融合图是新的信任根，校准即租约）**
直觉：融合不是免费的一致性。深度与 RGB 的颜色-几何一致性依赖外参；双目依赖时间同步；IMU+轮速依赖零偏标定。任一环节漂移，融合结果会「看起来很平滑但整体偏移」，比单传感器失效更危险，因为它不会触发单模态的明显异常。于是融合图 G_t 必须携带一条**融合租约 ℓ_f**（外参协方差、时间同步偏差、传感器健康、租约时效），与姿态租约 ℓ_p、能量租约 ℓ_e 并列为根信任。

**灵感 3（二者耦合 → 调度对象从「模态」升为「任务头 × 传感器子集」）**
直觉：并非每个指令都需要全部 K 个任务，也并非每个任务都需要全部传感器。语音「把左边红色杯子拿给我」只需要语义接地 + 姿态 + 接触预测，不需要深度补全全身；但若场景预测进入透明层，则必须临时把深度头与深度传感器纳入。调度因此是**在干扰、能量、时延、融合代价四者间的子集选择问题**，并且必须保证任何被激活的安全关键任务仍在联合证书覆盖内。

**耦合升级**：在 v10 四层架构上新增 **多任务-融合证书层**。FMTC（Fusion-MTL Task Certifier）签发跨任务联合证书；SAFG（Sensor Alignment & Fusion Guard）维护融合图与融合租约；TIGS（Task Interference-aware Gating Scheduler）输出 (K_t, S_t)。ECPS 从输出模态 m_t 升级为输出任务-传感器子集；PSE 半径改为干扰修正半径；DCL 采集负迁移样本；CCA 红队融合失配与相关失效；CAR 用联合证书守卫；MVR 记忆键加入融合图与任务集。五层 v11：根信任层 = {ℓ_p, ℓ_e, ℓ_f}，L1 几何/任务层融合条件化，L2 上下文预测驱动，L3 CAR 联合守卫，L4 DCL 覆盖驱动采集。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（多任务融合前向）**
传感器全集 S，子集 S_t ⊆ S，观测 x_s ∈ X_s。融合算子 Φ_t: ∏_{s∈S_t} X_s → Z，共享表征 z_t = Φ_t({x_s}_{s∈S_t})。任务头 h_k: Z → Y_k，任务集 K_t ⊆ [K]，输出 y_t^k = h_k(z_t)。参数 θ = θ_enc ∪ {θ_k}，多任务损失 L = Σ_{k∈K_t} λ_k L_k。
**关键**：z_t 是 K_t 与 S_t 的联合函数，任何任务的证书都必须以 (K_t, S_t, G_t) 为条件。

**定义 60（任务干扰张量与干扰修正半径）**
设任务 k 单独训练时的共形半径 r_ω^{(k)}。联合训练任务 j 对 k 在退化层 ω 的负迁移强度
I_{jk}(ω) = max(0, r_ω^{(k)}(joint with j) − r_ω^{(k)}(k only))。
干扰修正半径
r̃_ω^{(k)}(K_t) = r_ω^{(k)} + κ · max_{j∈K_t, j≠k} I_{jk}(ω)，κ ≥ 1 为安全系数。
**单调性（共享表征税）**：K_t 越大 ⇒ r̃_ω^{(k)} 不减，即激活更多任务不保证每个任务的证书更紧。这直接改变调度目标：任务不是越多越好。

**定义 61（传感器融合图与融合租约）**
融合图 G_t = (S_t, E_t, Φ_t)，边 (s,s') 表示融合依赖，w_{s,s'} 为依赖权重。融合租约
ℓ_f = (Σ_ext, δ_sync, {h_s}_{s∈S_t}, τ_f)，
其中 Σ_ext 为外参协方差、δ_sync 为时间同步偏差、h_s∈{0,1} 为健康位、τ_f 为租约时刻。
**融合可行判据**：
tr(Σ_ext) ≤ ε_ext ∧ δ_sync ≤ δ_max ∧ (∀s∈S_t: h_s=1) ∧ |t−τ_f| ≤ τ_f。
**失效传播**：任一 s∈S_t 失效，则所有以 s 为祖先的任务 k（s∈anc(k)）证书级联失效，而非仅该传感器自己的输出失效。

**定义 62（跨任务-跨传感器联合证书）**
J_t = ({P_t^k}_{k∈K_t}, ℓ_p, ℓ_e, ℓ_f, G_t, K_t)。**联合 soundness**：
P( ∀k∈K_t: y_t^k ∈ P_t^k | ω_t, G_t, ℓ_* 均有效 ) ≥ 1 − α_joint。
**保守实现**：union bound α_joint ≤ Σ_{k∈K_t} α_k；当任务残差正相关时用 Simes/Holm 收紧，α_joint ≤ min(1, Σ_k α_k·ρ_k)，ρ_k 为相关性权重。
**半径**：rad(P_t^k) = c_k · r̃_ω^{(k)}(K_t, S_t)。

**定义 63（干扰-融合感知调度）**
策略 π(c_t, ω_t, B_t, G_t, ℓ_f) → (K_t^*, S_t^*)，求解
max_{(K,S)} U = [ Σ_{k∈K} S_φ(ω)·Δrad_k(K,S) ] / [ L(K,S) + λ_e E(K,S) + λ_I Σ_{j,k∈K} I_{jk}(ω) + λ_f C_fuse(|S|) ]
约束：联合证书 soundness ≥ 1−α_joint，E(t+Δ) ≥ E_min，L(K,S) ≤ L_max，融合租约有效。
**风险前置**：若任一安全关键任务 k*（姿态/接触）的预测覆盖 < 1−α_{k*}，则强制把 k* 所需的传感器并入 S_t 或直接 fail-closed，禁止用「省算力」的调度换取安全关键任务的覆盖下降。

## 2. 三大新增产出与既有 IP 升级

**IP-69 FMTC（Fusion-MTL Task Certifier）**
- 干扰张量在线/离线双模校准：离线按退化层 ω 估计 I_{jk}(ω)，在线用滑动残差检测负迁移漂移
- 联合证书签发：干扰修正半径 + union bound / Simes 的 α_joint 控制
- 任务间一致性检查：语义接地锚点与姿态锚点在同一融合表征下的一致性（防止「各自置信但彼此矛盾」）

**IP-70 SAFG（Sensor Alignment & Fusion Guard）**
- 外参漂移监测：基于颜色-几何一致性的在线残差，估计 Σ_ext
- 时间同步审计：硬件时间戳 + 软同步残差，估计 δ_sync
- 相关失效检测：融合图中同源故障（同一曝光/同一供电/同一驱动）识别，输出健康位 h_s
- 融合租约签发与级联失效：ℓ_f 失效 → 依赖任务证书全失效 → CAR fail-closed

**IP-71 TIGS（Task Interference-aware Gating Scheduler）**
- 任务头门控：按指令语义与上下文 c_t 选择 K_t（不是全任务常开）
- 传感器子集选择：按融合增益 / 融合代价 / 校准信心选 S_t
- 干扰感知效用：U 中含 λ_I·Σ I_{jk}，避免「多任务反而更差」
- 子集搜索：效用对 K,S 近似单调子模时用贪心，得 (1−1/e) 近似

**既有 IP 升级**
- IP-63 ECPS：输出从模态 m_t 升级为 (K_t, S_t)，求解改用定义 63 的 U
- IP-64 DEPTH-CERT：深度补全作为 MTL 任务，单列深度-姿态干扰 I_{Depth,Pose}；深度帧率失配并入 ℓ_f 的 δ_sync 项
- IP-60 PSE：半径查表 r_ω 升级为干扰修正半径 r̃_ω^{(k)}(K_t,S_t)
- IP-61 DCL：采集任务加入「负迁移样本」与「融合失配样本」，按覆盖缺口排序
- IP-62 CCA：新增融合图红队（外参注入、时间戳抖动、同源失效）、干扰张量低估测试
- IP-51 CAR：守卫改为联合证书 J_t 的 soundness + ℓ_f 有效
- IP-45 总线：新增 fusion-graph / calibration-lease / task-head-decision / interference-report 话题
- IP-66 MVR：记忆检索键加入 (G_t, K_t, S_t)，融合图不兼容的历史记忆直接屏蔽
- IP-68 SAB：绑定函数 B(v_t,P_t) 改用联合证书中最紧的任务半径，避免「姿态还行但接触预测已失效」仍执行

## 3. 算法骨架

FMTC / TIGS 每控制周期：
1. 读 c_t, ω_t, B_t, G_t, ℓ_p, ℓ_e, ℓ_f
2. SAFG 校验融合租约；失效则直接 fail-closed
3. 按上下文预测各任务将进入的退化层，查干扰张量 I_{jk}(ω)
4. 在 K,S 子集上贪心求解 U，先满足安全关键任务覆盖约束
5. 用干扰修正半径签发联合证书 J_t；α_joint 用 union bound / Simes 校验
6. 若联合 soundness 不足或任一租约失效 → fail-closed；否则把 (K_t,S_t,J_t) 交 CAR 守卫、MVR 记忆写回

## 4. 本轮最大风险

**一句话**：任务干扰张量 I_{jk}(ω) 只能在已枚举的退化层与已采集的审计样本上校准，一旦部署场景出现分布外（新材质、新光照、新外参漂移模式），负迁移会被系统性低估、干扰修正半径被压得过窄，联合证书名义上满足 1−α_joint 实际却已失效；因此必须用独立审计集分层校准每个 ω 的干扰张量、对分布外检测触发半径保守膨胀，并在干扰估计置信不足时默认激活最大安全任务集而非最小集。

## 2. 关键算法 伪代码

### IP-69 FMTC：干扰张量校准与联合证书

```
def interference_tensor(regime, audit, K, kappa=1.0):
    I = zeros((K, K))
    for k in K:
        r_single = conformal_radius(single_models[k], audit[regime])
        for j in K:
            if j == k:
                continue
            r_joint = conformal_radius(joint_models[k],
                                       audit[regime], trained_with=j)
            I[j, k] = max(0.0, r_joint - r_single)
    return I

def corrected_radius(k, K_t, omega, I, kappa=1.0):
    base = base_radius[k][omega]
    worst = max((I[j, k][omega] for j in K_t if j != k), default=0.0)
    return base + kappa * worst

def joint_certificate(K_t, S_t, omega, G_t, leases, alpha_joint, I):
    if not fusion_guard(G_t, leases.f, t):
        return None                      # 融合租约失效 -> fail-closed
    certs = {}
    for k in K_t:
        r = corrected_radius(k, K_t, omega, I)
        certs[k] = TaskCert(radius=r, alpha=alpha_table[k])
    # 先用保守 union bound，再做相关性收紧
    if sum(c.alpha for c in certs.values()) <= alpha_joint:
        return certs
    if simes_check([c.pvalue for c in certs.values()], alpha_joint):
        return certs
    return None                          # 联合覆盖不足 -> 缩小候选或 fail-closed
```

### IP-70 SAFG：融合租约与级联失效

```
def fusion_guard(G_t, lease_f, t):
    if trace(lease_f.Sigma_ext) > EPS_EXT:
        return False
    if lease_f.delta_sync > DELTA_MAX:
        return False
    if not all(lease_f.health[s] == 1 for s in G_t.S):
        return False
    if abs(t - lease_f.tau_f) > TAU_F:
        return False
    return True

def cascade_invalidate(task_certs, G_t, failed_sensors):
    # 任一祖先传感器失效，依赖它的任务证书全部失效
    for k in task_certs:
        if ancestors(k, G_t) & failed_sensors:
            task_certs[k].valid = False
    return task_certs

def update_extrinsic_lease(rgb, depth, prior):
    # 颜色-几何一致性残差 -> 外参漂移估计
    res = color_geometry_residual(rgb, depth, prior.extrinsics)
    Sigma = robust_cov(res)              # Huber/MAD 抗 outlier
    return Lease(Sigma_ext=Sigma, delta_sync=prior.delta_sync,
                 health=prior.health, tau_f=now())
```

### IP-71 TIGS：干扰-融合感知调度

```
def utility(K_t, S_t, c_t, omega, B_t, G_t, I, lat, energy):
    if not fusion_guard(G_t, leases.f, t):
        return -inf
    gain = 0.0
    for k in K_t:
        r_single = base_radius[k][omega]
        r_corr   = corrected_radius(k, K_t, omega, I)
        gain += S_phi(omega) * max(0.0, r_single - r_corr)
    interference = sum(I[j, k][omega] for j in K_t for k in K_t if j != k)
    denom = lat(K_t, S_t) + LAMBDA_E * energy(K_t, S_t) \
            + LAMBDA_I * interference + LAMBDA_F * fuse_cost(S_t)
    return gain / max(denom, 1e-6)

def gating_scheduler(c_t, omega, B_t, G_t, leases, I):
    best = None
    for K_t in greedy_task_subsets(K):          # 近似单调子模 -> 贪心
        for S_t in greedy_sensor_subsets(S, K_t):
            if not energy_ok(B_t, energy(K_t, S_t)):
                continue
            certs = joint_certificate(K_t, S_t, omega, G_t, leases,
                                      ALPHA_JOINT, I)
            if certs is None:
                continue
            u = utility(K_t, S_t, c_t, omega, B_t, G_t, I,
                        latency, energy)
            if best is None or u > best.u:
                best = Solution(K_t, S_t, certs, u)
    if best is None or not critical_tasks_covered(best, CRITICAL):
        return 'fail-closed'
    return best
```

### 全局决策（承接 v23，融入联合证书）

```
def global_decision(c_t, omega_t, B_t, v_t, M, G_t, leases, I, Q_safe):
    if Q_safe and not empty(Q_safe):
        v_t = pop(Q_safe).v
    sol = gating_scheduler(c_t, omega_t, B_t, G_t, leases, I)
    if sol == 'fail-closed':
        return 'fail-closed', 'joint-cert'
    mem = memory_lookup(v_t, c_t, B_t, key=(G_t, sol.K, sol.S))
    if mem and mem.compatible(G_t, sol.K, sol.S) and energy_ok(mem):
        return mem.m, 'memory'
    # 安全绑定使用联合证书中最紧的任务半径
    tight = min(sol.certs.values(), key=lambda c: c.radius)
    if safety_bind(v_t, tight) < THETA_SAFE:
        push(Q_safe, v_t)
        return sol, 'queued'
    return sol, 'execute'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| FMTC 干扰张量 | 离线 O(K²·n_audit)，在线 O(K²) 查表 | O(K²·|Ω|) | 每层 ω 的 I_{jk} 由独立审计集校准，半径膨胀有下界 |
| FMTC 联合证书 | O(|K_t|²) 每周期 | O(|K_t|) | union bound / Simes 控制 α_joint |
| SAFG 融合守卫 | O(1) 租约检查 + O(|E_t|) 失效传播 | O(|S_t|) | ℓ_f 失效 ⇒ 依赖任务证书级联失效 |
| TIGS 调度 | 贪心 O((|K|+|S|)·|K_t|²) | O(|K||S|) | 近似单调子模 ⇒ (1−1/e) 增益；安全关键任务覆盖为硬约束 |

**正确性定理（v11 联合证书）**：设融合租约 ℓ_f 有效、干扰张量在退化层 ω 上的估计满足 I_{jk}^{true}(ω) ≤ I_{jk}^{est}(ω)（即估计不低估负迁移），且 α_joint ≥ Σ_{k∈K_t} α_k。则 FMTC 签发的 J_t 满足 P(∀k∈K_t: y_t^k∈P_t^k | ω,G_t,ℓ_*) ≥ 1−α_joint。若 ℓ_f 失效或 α_joint 约束不可满足，则 J_t=None，TIGS 收缩 (K_t,S_t) 或输出 fail-closed，不存在「证书名义有效而实际失效」的静默路径。记忆复用仅在 (G_t,K_t,S_t) 兼容且半径未过时时允许，否则回退实时求解。

## 4. 实验设计 E115–E120

| 实验 | 指标 | 门槛 |
|---|---|---|
| E115 任务干扰测量 | 每退化层 K×K 的 I_{jk}(ω)；姿态半径膨胀 | 姿态半径膨胀 ≤ 10%；I 估计与留出集偏差 ≤ 15% |
| E116 联合证书覆盖 | 审计集上 α_joint 实际违约率 | 实际违约 ≤ 5%（α_joint=0.05）；单任务边际不劣化 |
| E117 融合对齐压力测试 | 外参注入/时间抖动下的检测率与误报 | 检测率 ≥ 95%；误报 ≤ 3% |
| E118 干扰感知调度收益 | 相对全任务常开的时延/能耗/覆盖率 | 时延 −35%；能耗 −25%；联合覆盖不降 |
| E119 相关失效红队 | 同源故障下 fail-closed 召回 | 召回 ≥ 99%；静默错误 0 起 |
| E120 100h 闭环 | 联合安全违约、任务成功率、记忆复用率 | 安全违约 0 起；成功率 ≥ 95%；记忆复用 ≥ 55% |

**回退策略**：E115 干扰估计偏差 > 25% → 关闭共享编码器、回退每任务独立小模型；E116 联合违约 > 5% → 提高 κ 与 α_joint 保守度，或强制全任务全传感器模式；E117 融合失配检测不足 → 停用融合，退化到单传感器证书；E118 调度收益为负 → 固定 K_t=CRITICAL、只调度 S_t。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 干扰张量在分布外被低估，联合半径过窄 | 高 | 独立审计集分层校准；OOD 检测触发半径保守膨胀 κ↑；置信不足默认最大安全任务集 |
| 融合租约过期未被察觉，证书集体静默失效 | 高 | ℓ_f 与 ℓ_p/ℓ_e 同级 fail-closed；外参/时间戳双通道监测；周期性强制重标定 |
| 多任务负迁移导致「任务越多越差」 | 高 | 干扰感知效用 λ_I；任务头可插拔门控；必要时切换独立模型 |
| 相关失效（同曝光/同供电/同驱动）绕过单传感器健康检查 | 中 | 融合图同源分组；组级健康位；红队注入同源故障 |
| 联合 α_joint 用 union bound 过保守，任务集被迫收缩 | 中 | 相关性感知的 Simes/Holm 收紧；按任务重要性分配 α_k |
| 记忆复用跨融合图复用旧决策 | 中 | 记忆键含 (G_t,K_t,S_t)；图/任务集不兼容直接屏蔽 |

## 6. 本轮最大风险

**一句话**：任务干扰张量 I_{jk}(ω) 与融合租约 ℓ_f 都只在已枚举退化层和已采集审计样本上校准，分布外场景（新材质、新光照、未建模的外参漂移）会同时低估负迁移并漏检融合漂移，使联合证书在名义满足 1−α_joint 的同时实际已失效；因此必须以独立审计集分层校准、对 OOD 触发半径保守膨胀与融合租约收紧，并在任一估计置信不足时默认激活最大安全任务集并 fail-closed，而不是用「省算力」的调度去赌安全关键任务的覆盖。
