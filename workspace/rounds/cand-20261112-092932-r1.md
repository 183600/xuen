# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；本轮灵感：「伦理与合规」×「点云配准」）

> 第 57 轮把承诺的依据做成"可校准、可对账、可个性化的证据"，但它有一个更深的盲点：**所有护栏都是后果主义的、且由系统自己判定**——问的是"失败概率多大""我们的证据是否过了我们的门"，从不问"这个动作是否根本被允许""外部审计者能否把'我们做了什么'与'我们承诺了什么'对齐"。证据可以被"选择测什么"制造得好看；一个足够自信的系统仍可能去做一件被禁止的事。两个灵感各补一刀：**点云配准**给了对齐两套表示并判断"何时对齐根本不可观测"的严格语言——对应关系、内点共识、退化、歧义、环一致性；**伦理与合规**给了一个概率买不到的非后果层——硬禁令、目的限定、知情同意、可问责、可删除、外部审计。本轮新增：道义不变量流形（不可收买的硬门）、策略-行为配准（合规=带弃权的稳健对齐）、配准退化可观测性（不可观测即默认拒绝）、环一致且预注册的证据谱系（反选择性报告）、同意-谱系-可删除（数据治理）、可导航合规包络（更新只能收紧，放松须外部再认证）。核心命题升级为 **"不可收买的禁区、可审计的配准、对不可观测保持沉默的证据说可信"**。

核心矛盾：
- **H29（道义 vs 后果）**：概率永远不能授权被禁止之事；但把伦理写成硬编码又带来价值锁定与"合规剧场"——禁令集由谁、按哪一辖区的规则、如何修订？过保守则机器人寸步难行，过宽松则形同虚设。
- **H30（合规 vs 可审计性）**：行为点云可以在可观测维度上与策略流形"对齐得很好"，却在未激活/不可观测维度上系统性违规；稳健配准会把系统性违规当"离群点"剪掉，内点率高并不等于合规。
- **H31（可审计 vs 隐私/可删除）**：完整谱系是审计与问责的前提，却与数据最小化、目的限定、被遗忘权直接冲突；既要"一切可回溯"，又要"该删就删"，二者必须在密码学承诺层面调和。

## 0. 直觉与动机

**灵感 1（伦理 → 禁区不可收买 + 合规是外部对齐）**
直觉：安全证据像货币，能买"更低风险"，但买不到"被允许"。伦理层应是一个**前置的、非概率的、不可被证据/同意/VOI/授权绕过的门**：无论后验多自信、操作者授权多高、跨模态多一致，只要动作落入保护值禁区（人身、隐私、第三方财产、不可逆环境损害），就拒绝；反过来，当存在救助义务时，不做也算违规。合规则是另一件事：不是系统自证"我很安全"，而是让外部审计者能把"声明义务"与"实际行为"对齐——这正是配准问题。

**灵感 2（点云配准 → 合规=带弃权的稳健配准）**
直觉：把每条部署轨迹嵌入"义务相关描述子"空间（接触力、与受保护实体的接近度、访问的数据、同意标志、能耗），得到行为点云 X_b；把政策 π 允许的轨迹集合写成策略流形 M_π。合规不是"行为=政策"的恒等，而是"存在一个**保持保护度量的合法适配** g∈G_safe 使 g·X_b 与 M_π 在容差内高内点对齐"。配准的四类失败正好对应合规的四类病：部分重叠=只审计了发生过的场景；局部极小=审计者锚在一个解释上；对称歧义=两套政策解释同样自洽；非刚性形变=悄悄改政策却假装只是适配。对策也照搬：保守平局取更严解释、要求条款级见证、非 G_safe 形变一律外部再认证、离群占比过高时**弃权而非强行对齐**。

**灵感 3（配准退化 → 不可观测即不可认证）**
直觉：ICP 在长走廊里"看起来收敛"，但沿走廊轴的特征值近零——那个方向根本没被约束。合规审计同样：如果部署轨迹里从未出现过受保护实体，那么"未违规"只是**该方向未被激活**，不是已证明安全。用配准 Hessian/Fisher 的特征谱定义退化指数 κ_deg 与退化子空间 U_deg；在 U_deg 上证书只能写"未约束（unconstrained）"，绝不能写"合规"；不可逆接触在未约束的保护方向上默认拒绝。"没有伤害的证据"不等于"没有伤害的证据"。

**灵感 4（环一致性 + 预注册 → 证据的科研伦理）**
直觉：点云配准靠多视角环闭合发现漂移；证据体系也要靠"探针-承诺-结果-政策版本"构成的有向图的环一致性发现伪造与漂移。更强的类比是**预注册**：临床与科研伦理要求试验前登记方案、报告全部结果；系统若在事后挑选"好看的探针"再对齐，就是 p-hacking 式的证据操纵。把探针计划在执行前做哈希预注册，所有探针（含失败、无效）必须入账；漏报与环残差超限都会触发**回溯隔离**并作废其后继证书。

**灵感 5（合流 → 部署证书 = J_p ∧ J_e，更新只能收紧）**
直觉：第 57 轮的 J_p 只证明"证据够好"；本轮加 J_e 证明"行为被允许且可对齐"。二者是逻辑与，不是加权——伦理门一票否决。所有自适应更新（信任授权、阈值、元模型）只能落在**可导航合规包络** G_safe 内（保持禁令不变量与硬界，等价于对保护度量的等距变换）；自主只能收紧，任何放松必须外部再认证；定期用锚点（禁令、硬界、同意规则）做环闭合，漂移超限即回滚。这样"个性化/元学习"带来的漂移被限制在合规流形内。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（道义不变量流形 DIM）** 保护值格 (V,⪯)，动作到受影响值 v(a)∈V^d；禁令集 P={a:∃v, v(a)⪰v_forbid}，采用**过近似** P̂⊇P（宁误禁、勿误放）。伦理门 E(a,π_pol)∈{pass,forbid,obligate}：a∈P̂⇒forbid；若触发救助/报告/停机义务且可执行⇒未执行即 obligate-violation。**不可收买性**：对任意证据 e、同意 c、授权 auth、VOI 值，Commit(a)⇒E(a)=pass；E 不接受概率论证。π_pol 由外部治理、带版本与签名，系统只能选择"更严"的辖区叠加，不能自降。

**定义 140（策略-行为配准 PBR）** 描述子 φ(τ)∈R^d（接触力/接近度/数据访问/同意位/能耗等）；策略流形 M_π={φ(τ):τ⊨π}；行为点云 X_b={φ(τ_i)}。合法适配群 G_safe={g: 在保护子空间上保持 d_P 等距且不改变禁令}（如站点坐标系、单位换算、任务重参数化）。合规 ⇔ ∃g∈G_safe：内点率 η_in(g)≥1−α_comp、残差分位 q_{1−α}(r)≤ε、**每条政策条款有 ≥n_w 个激活见证**、且不存在规模 ≥m_v 的残差连通簇（系统性违规）。证书 C_e=(η_in,q_{1−α},κ_deg,条款覆盖,非合规簇,歧义集,ĝ)。若多个 g 的 η_in 相差 ≤δ_eq，取**保护裕度最小**的解释；若修剪后离群占比 >α_max，输出 abstain("无法认证")，不得强行对齐；任何非 G_safe 的非刚性形变⇒须外部再认证，审计不得默认接受。

**定义 141（配准退化可观测性 RDO）** 配准 Hessian/Fisher H=Σ_i n_i n_i^T（point-to-plane）或观测信息阵；特征分解得 κ_deg=λ_min/λ_max，退化子空间 U_deg=span{λ_i<λ_0}；配准协方差 Σ_T≈σ²H^+。规则：若 κ_deg<κ_0 或某受保护方向**无激活见证**，C_e 在该子空间只能标 "unconstrained"；P_fail 取 U_deg 内最坏值；不可逆接触在未约束的保护方向上**默认拒绝**（absence of evidence ≠ evidence of absence）。

**定义 142（环一致预注册证据谱系 CPR）** 证据图 𝓖_ev=(探针/承诺/结果/政策版本/操作者, 推导边)。每个探针计划在执行前哈希预注册 preHash(π_probe)；所有探针（含失败/无效）必须入账。环残差 r_cyc=||⊕_{e∈cycle}T_e−I||；若 r_cyc>θ_cyc、或发现未预注册探针、或应报告未报告，则该节点及**全部后代证书回溯作废并隔离**，需重新推导。审计者据此检测选择性报告、伪造与漂移。

**定义 143（同意-谱系-可删除 CLD）** 每个地图/证据节点带谱系 L=(用途 p,主体 s,TTL,派生关系)。目的限定：动作必须配准到声明的用途，越用即非合规。最小化：尽可能只存承诺（哈希/草图/充分统计量）而非原始个人数据。删除证书 DelCert=(哈希链证明节点已移除且后代已失效, 保留撤销标志, 审计根完整)；当再裁决确需原始数据时，先以**防篡改承诺**替换再删除。问责：每次承诺签名归属 {机器人,操作者,云端版本}，形成可追责映射。

**定义 144（可导航合规包络 NCE 与伦理-合规门 ECG）** 所有自适应更新 u（信任 auth、阈值、元模型增量）必须满足 u∈G_safe（保持 P 不变量与全局硬界）⇒ 部署策略 π^dep=u∘π_pol 恒在合规流形内；自主只可收紧（π^dep⊑π_pol），放松需外部再认证。锚点 A_root={禁令检查,硬界,同意规则}，每个审计周期做锚点环闭合，漂移 r_anchor>θ_anchor⇒回滚。伦理-合规门：Commit(a) ⇔ E(a)=pass ∧ C_e 有效（含覆盖/见证）∧ J_p ∧ 非退化方向或已显式接受保守默认。**J_e=(π_pol 版本/哈希, P̂ 摘要, C_e, 覆盖/见证, κ_deg, 非合规簇, 歧义集, DelCert 摘要, r_anchor, 签名)**；部署证书 J_deploy=J_p∧J_e。

## 2. 关键算法伪代码

```python
def ethics_gate(a, policy, ctx):                    # IP-139: 非概率、不可收买
    if meets(a.value_impact, policy.P_hat): return 'forbid'
    if policy.duty_triggered(ctx) and not a.satisfies_duty:
        return 'obligate_violation'
    return 'pass'

def compliance_register(X_b, M_pi, G_safe, eps):    # IP-140/141
    g, inl, r = robust_register(X_b, M_pi, group=G_safe, tol=eps)
    if outlier_frac(inl) > alpha_max: return Cert('abstain')
    if tie_ambiguous(g, delta_eq): g = most_conservative(G_safe)
    if not is_rigid_on_protected(g, d_P): return Cert('recertify')
    H = reg_hessian(X_b, M_pi, g); lam = eigvals(H)
    k_deg, U_deg = degeneracy(lam)
    cover = clause_witnesses(X_b, M_pi, g)
    return Cert(eta_in=inl.ratio, q=q_alpha(r), kappa=k_deg, U=U_deg, cover=cover)

def commit_or_reject(a, ev, persona, policy, M, cert_e, cert_c):
    if ethics_gate(a, policy, ctx) != 'pass': return 'reject', J_e('forbid')
    if cert_c.abstain or cert_c.bad: return 'reject', J_e('unobservable')
    if cert_c.kappa < kappa_0 and a.irreversible:
        return 'reject', J_e('degenerate_default_deny')
    if few_shot_evidence_gate(ev, M, persona, ood_reg)[0] != 'ok':
        return 'reject', J_e('evidence')
    return 'commit', J_deploy(cert_e, cert_c)
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DIM | O(\|P̂\|) 规则匹配 | O(\|P̂\|) | 过近似、不可绕过、外部版本化 |
| PBR | O(N_b·d + RANSAC) | O(N_b·d) | 弃权优先、平局取严、G_safe 刚性与条款见证 |
| RDO | O(d³) 特征分解 | O(d²) | 退化方向只写"未约束"、默认拒绝 |
| CPR | O(\|E\|·\|cycle\|) | O(\|E\|) | 预注册+环残差、后代回溯作废 |
| CLD | O(log n) 承诺验证 | O(承诺) | 删除可证、审计根不受损 |
| ECG/NCE | O(更新数·d_P) | O(锚点) | 更新∈G_safe、只收紧、漂移回滚 |

**正确性定理（Ethical-Compliant Registration Soundness, ECRS）**：在 A33–A40 上增 (A41) 禁令过近似 P̂⊇P 且检测误差≤δ_P，伦理门实现不可绕过、π_pol 签名版本固定；(A42) PBR 残差/内点模型诚实、条款见证与弃权规则正确、G_safe 仅含保护度量等距；(A43) 预注册哈希不可否认、环残差与删除证明诚实；(A44) 一切自适应更新 u∈G_safe 且自主只收紧。则：(i) **禁令健全**：P(∃提交 a∈P_true)≤δ_P+δ_impl，且该界与证据、同意、授权、VOI **无关**，同意只能缩小可行动集；(ii) **合规健全（含弃权）**：若行为在**已激活**保护方向上系统性偏离，检出概率≥1−β_comp；若方向未激活/退化，证书只能输出"未约束"而不能输出"合规"——高内点率但缺条款见证一律拒绝；(iii) **退化安全**：P_fail 取 U_deg 最坏值，不可逆接触在未约束保护方向上的接受概率为 0（模门实现误差）；(iv) **策略不漂移**：任意可容许更新序列后 π^dep∈G_safe·π_pol，锚点残差超限即回滚；(v) 部署界在第 57 轮基础上增加 δ_P、β_comp、δ_del、δ_audit 与退化/环一致性项。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是**合规剧场**——系统学会了把自己的行为"配准"到一个可审计的分数上（高内点率、漂亮覆盖），而真正的保护值违规落在描述子空间之外或未激活的退化方向上；加之道义门若由系统自己版本化，就会变成一套不可申诉、按单一辖区冻结的道德脚本，用"零违规"的证书掩盖"根本没观测"的事实。必须以外部治理的禁令版本、条款级正见证、退化即弃权/默认拒绝、以及任何放松都需外部再认证来兜底——**没有见证的合规不是合规，只是沉默**。

# 第 58 轮产物 · 创新点清单 v34：Norm-Register（道义不变量×策略-行为配准×退化可观测×环一致谱系×同意-谱系-删除×可导航合规包络，DIM×PBR×RDO×CPR×CLD×ECG/NCE）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）与第 56 轮 IP-127~132（SMM/PCE/BVK/ISE/TAF/MEC）。本轮把"证据承诺"再推进一层：不再只问"证据能否支撑承诺"，而先问 **"这个承诺是否被允许、是否可被外部对齐"**。两个灵感各补一条腿：**点云配准**提供"对应-共识-退化-歧义-环闭合"的严格语言，使合规从自证变为可审计的稳健对齐；**伦理与合规**提供概率买不到的非后果层——硬禁令、目的限定、同意、问责、可删除。第 57 轮"一切判定器（含元模型）走隔离"在本轮推广为 **"一切判定器与政策更新都必须通过道义门、并在合规流形内被配准审计"**。
> IP 编号：IP-139~IP-144（共 6 个），升级 IP-137/138 以纳入道义门与合规证书。

def dim_gate(a, pi_pol, ctx):
    impact = value_impact(a)                 # 人身/隐私/第三方财产/不可逆环境

### IP-140 PBR（策略-行为配准，合规=带弃权的稳健对齐）

```python
def pbr_certify(X_b, M_pi, G_safe, eps, n_w, m_v):
    al = robust_register_all(X_b, M_pi, group=G_safe, tol=eps)
    if not al:
        return C_e(abstain=True, reason='no_alignment')
    g = max(al, key=lambda z: z.eta_in)
    if tie_ambiguous(al, delta_eq):
        g = min(al, key=protected_margin)     # 平局取更严解释
    if not preserves_ethic_metric(g, d_P):
        return C_e(abstain=True, reason='non_rigid_recertify')
    if outlier_frac(g) > alpha_max:
        return C_e(abstain=True, reason='too_many_outliers')
    cover = {cl: witnesses(cl, X_b, M_pi, g) for cl in clauses(M_pi)}
    clusters = residual_clusters(X_b, M_pi, g, eps)
    bad = [cl for cl, w in cover.items() if len(w) < n_w]
    if any(len(c) >= m_v for c in clusters):
        bad.append('systematic_violation')
    return C_e(g=g, eta_in=g.eta_in, q=q_alpha(g.r), cover=cover,
               bad=bad, abstain=False)
```

### IP-141 RDO（配准退化可观测性）

```python
def rdo_update(C_e, X_b, M_pi, g, sigma2):
    H = reg_hessian(X_b, M_pi, g)             # point-to-plane / Fisher
    lam, U = eigh(H)
    C_e.kappa = lam.min() / max(lam.max(), 1e-12)
    C_e.U_deg = U[:, lam < lambda_0]
    if C_e.kappa < kappa_0 or not C_e.cover_all_active:
        C_e.status = 'unconstrained'          # 绝不写 compliant
    return C_e, sigma2 * pinv(H)

def risk_with_degeneracy(P_base, C_e):
    if C_e.kappa < kappa_0:
        return max(P_base, worst_case_over(C_e.U_deg))
    return P_base
```

### IP-142 CPR（环一致预注册证据谱系）

```python
def cpr_log(node, pre_plan):
    assert pre_registered(node, pre_plan)     # 执行前哈希登记
    G_ev.add(node)                            # 失败/无效探针同样入账
    return G_ev

def cpr_audit(G_ev, theta_cyc):
    bad = set()
    for cyc in simple_cycles(G_ev):
        if cycle_residual(cyc) > theta_cyc:
            bad |= descendants(cyc)           # 回溯作废后继证书
    for n in nodes(G_ev):
        if not n.pre_registered or not n.reported:
            bad |= {n} | descendants(n)       # 检测选择性报告
    for n in bad:
        quarantine(n)
    return G_ev, bad
```

def nce_update(pi_dep, u, pi_pol):
    if not in_group(u, G_safe(pi_pol)):
        return 'reject', 'outside_envelope'

def ecg_commit(a, ev, persona, M, cert_e, cert_c, ood_reg):
    if dim_gate(a, pi_pol, ctx)[0] != 'pass':
        return 'reject', J_e(cause='deontic_forbid')
    if cert_c.abstain or cert_c.bad:

def anchor_loop_closure(pi_dep, A_root, theta_anchor):
    r = sum(residual(pi_dep, a) for a in A_root)   # 禁令/硬界/同意

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DIM | O(\|P̂\|) 规则匹配 | O(\|P̂\|) | 过近似、不可绕过、外部版本化（A41） |
| PBR | O(N_b·d + RANSAC) | O(N_b·d) | 弃权优先、平局取严、条款见证、G_safe 刚性（A42） |
| RDO | O(d³) 特征分解 | O(d²) | 退化方向只写"未约束"、默认拒绝（A42） |
| CPR | O(\|E\|·\|cycle\|) | O(\|E\|) | 预注册+环残差、后代回溯作废（A43） |
| CLD | O(log n) 承诺验证 | O(承诺+充分统计量) | 删除可证、审计根完整（A43） |
| ECG/NCE | O(更新数·d_P) | O(锚点) | 更新∈G_safe、只收紧、漂移回滚（A44） |
| PCE+ | O(\|CP\|·k_p·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | 继承第 57 轮终止性 |

**正确性定理（Ethical-Compliant Registration Soundness, ECRS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41)** 禁令过近似 P̂⊇P_true，检测误差 ≤δ_P，伦理门实现不可绕过且先于一切证据/同意/授权/VOI，π_pol 为签名固定版本；**(A42)** PBR 的残差模型、条款见证与弃权规则诚实，G_safe 仅含保护度量 d_P 的等距变换，退化指数与覆盖如实报告；**(A43)** 探针预注册哈希不可否认，所有探针（含失败/无效）入账，环残差与删除证明诚实、删除后审计根完整；**(A44)** 一切自适应更新 u∈G_safe，且自主更新只能收紧（π^dep⊑π_pol），放松必经外部再认证。则：

1. **禁令健全（不可收买）**：P(∃ 提交 a∈P_true) ≤ δ_P + δ_impl，且该界与证据质量、同意、授权、VOI **无关**；任何 consent/auth 只能收缩可行动集，不能扩张。
2. **合规健全（含弃权）**：若行为在**已激活**保护方向上系统性偏离策略，PBR 检出概率 ≥1−β_comp；若某保护方向未激活/退化，C_e 只能输出 `unconstrained` 而不能输出 `compliant`；高内点率但缺条款见证 ⇒ 拒绝，不存在"以高 η_in 掩盖系统性违规"的路径。
3. **退化安全**：P_fail 取退化子空间 U_deg 内最坏值；不可逆接触在未约束保护方向上的接受概率为 0（模伦理门实现误差）；配准协方差 Σ_T 只增不减地进入 F_bear。
4. **策略不漂移**：任意可容许更新序列后 π^dep∈G_safe·π_pol；锚点环残差 r_anchor>θ_anchor ⇒ 回滚，个性化与元学习不能把系统带出合规流形。
5. **证据健全性继承并强化**：第 57 轮的 P(fail) 界保留，另加 δ_P、β_comp、δ_del、δ_audit；环不一致或未预注册的证据及其全部后代证书作废。

**部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − δ_P − β_comp − δ_audit − δ_del
             − P(𝓜 陈旧未检出) − P(退化保护方向被误认证) − P(政策版本回滚失败)
```

关键：**道义门用"过近似 + 不可绕过"把概率与许可彻底分层**——证据只能让系统更保守，永远不能让它更敢犯禁；**合规是配准而非自证**——要求条款级正见证、对退化方向弃权、对非刚性形变强制再认证；**审计与隐私用承诺调和**——删得掉原始数据，留得住可验证的账。

## 5. 与第 57 轮的关系（继承与不变量）

- **继承**：MFSL/XMC/PTM/MXI/FSE/PCE+ 全部保留；J_p 仍是"证据够好"的证书。本轮 **不修改** 第 57 轮的证据类判定，只在最外层加 DIM 前置门、在最外层加 C_e 合取、在所有更新上加 G_safe 约束。
- **不变量**：任何新机制只能经"证据更准（含加宽）"或"动作更保守"影响系统；伦理门是唯一的**非概率否决权**，且不可被个性化/元学习/云端下发放宽。
- **证书链**：`J_deploy = J_p ∧ J_e`，其中 `J_e = (π_pol, P̂, C_e, cover, κ_deg, nonconform, ambiguity, DelCert, r_anchor, sig)`；审计只验逻辑与，不做风险加权。

## 7. 本轮最大风险

**一句话**：本轮最大的风险是**合规剧场**——系统学会了把自己的行为"配准"到一个可审计的分数上（高内点率、漂亮覆盖），而真正的保护值违规落在描述子空间之外或未激活的退化方向上；加之道义门若由系统自己版本化，就会变成一套不可申诉、按单一辖区冻结的道德脚本，用"零违规"的证书掩盖"根本没观测"的事实。必须以外部治理的禁令版本、条款级正见证、退化即弃权/默认拒绝、以及任何放松都需外部再认证来兜底——**没有见证的合规不是合规，只是沉默**。
