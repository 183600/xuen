# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC；灵感循环第 7 轮；本轮灵感：「UniBot世界挑战赛」×「痛点分析」）

> 第 60 轮把闭环从「执行层→证据层」升级为「场景→意图→约束→阻抗→执行→EV-exec→场景」的认知驱动闭环（SSM×CIEC×EPIR×SERC×PCE++++）。但把这套 60 轮累积的体系放进**UniBot 世界挑战赛**这种真实赛场，会暴露三个更根本的局限：
> 1. **能力堆叠 ≠ 赛事可用**：前 60 轮每轮都在「良性输入 + 单一能力」假设下证明改进；赛场是**长尾痛点分布 + 多能力并发 + 时间压力**。真正杀死成绩的不是某个模块不够强，而是**能力组合坍塌（composition collapse）**——A 模块把 B 模块的隐含假设破坏掉，且这种破坏在集成测试中不可见。
> 2. **优化目标错位（Goodhart 风险）**：D⁺、ECE、τ_response 等内部指标与赛事计分**不是单调同构**的。赛场计分常带**分段函数与阈值悬崖**（完成即得分、超时即 0 分），把内部指标刷到极致可能一分不涨，甚至因追求精度而超时。
> 3. **失败不可归因、不可恢复**：赛场故障会级联（感知漂移→场景误判→约束错误→执行失败→超时）。现有体系能「检测失败」，但缺乏**痛点→根因→自愈**的结构化闭环；同时裁判/评委需要一套**可解释的得分归因账本**，否则再好也说不清。

## 0. 直觉与动机

**灵感 1（UniBot世界挑战赛 → 赛场是痛点分布而非能力清单）**
直觉：世界挑战赛的胜负手不在「谁有最先进的模块」，而在「谁在最多的高权重痛点上不崩、并能拿到最多分段得分」。痛点天然重尾：未知光照、地面材质切换、裁判临时指令、硬件温漂、网络抖动、电池衰减、任务歧义、评分部分给分等。关键洞见：**把赛场抽象为一张加权痛点图（PPAG）**，节点是痛点、边是级联因果、权重 = 严重度 × 频率 × 当前覆盖缺口。优化目标从「提升单项指标」转为「最大化高权重痛点的期望覆盖」。

**灵感 2（痛点分析 → 痛点驱动的能力编排 PCO）**
直觉：给定痛点图，每个既有能力（SSM/CIEC/EPIR/…）只是「对某些痛点有部分覆盖、且要付出集成/算力/时延代价」的选项。选出子集 S 使**残余痛点风险最小且总代价不超预算**，本质是**单调次模覆盖**问题，贪心即有 (1−1/e) 保证。关键洞见：**不要平均用力**——把有限预算压到「高权 × 未覆盖」的痛点上，允许低权重痛点显式降级。

**灵感 3（赛事计分 → 计分对齐与悬崖规避 CSA）**
直觉：赛事计分 S_comp 是分段非线性函数。内部指标好不等于分数高；存在「分数悬崖」（差 0.1s 从满分掉到 0）。关键洞见：**用「每单位预算的边际期望得分」而非「VOI」排序动作**，并显式检测悬崖：宁可在阈值上方留安全裕度，也不在悬崖边上刷精度。

**灵感 4（故障自愈 → 失败归因与自愈 FASH）**
直觉：失败签名（指标偏离向量、失败模块、剩余时间、最近动作）是可观测的，根因是隐变量。用贝叶斯后验 P(根因|签名) 归因，再在 {重试、重配置、降级、急停} 中选**期望得分增益/代价**最大的自愈动作。关键洞见：**自愈本身也消耗预算**，必须防止「为修一个问题触发三个新问题」的自愈级联。

**灵感 5（组合契约 + 账本 → CCC 与 CGEL）**
直觉：能力组合坍塌的根因是**假设泄漏**：模块 i 的隐含假设 A_i 没有被组合中任何模块的保证 Post/Inv 所蕴含。把每个能力写成契约 K_c=(Pre,Post,Inv,Asm)，组合前静态检查泄漏量 λ。再用**哈希链证据账本 CGEL** 把「痛点—能力调用—得分增量—证据」串起来，支撑赛后复盘与评委可解释性。

**灵感 6（未知未知 → 对抗未知场景压力器 AUSS）**
直觉：赛前痛点分析必然漏掉「未知未知」。用生成式压力器在仿真里主动搜索**痛点覆盖空洞**：最大化「高权重但实测失败证据不足」的区域，把隐藏痛点反向补进 PPAG。

## 1. 形式化定义（增量：定义 161–169）

**定义 161（痛点图 PPAG）** 痛点图 G_p = (P, E, w, L)。其中：
- **痛点集**：P = {p₁,…,p_m}，每个痛点 p=(trigger, failure_mode, s_p, f_p, c_p)，s_p∈[0,1] 严重度、f_p 频率、c_p∈[0,1] 当前覆盖度。
- **权重**：w_p = s_p · f_p · (1 − c_p)，即「未被覆盖的期望损失」。
- **因果边**：E ⊆ P×P 为有向无环级联关系；级联损失
  L(p) = w_p + γ · Σ_{q∈succ(p)} L(q)，0<γ<1 为衰减系数（防止无限级联）。
- **更新**：赛后/运行中由 CGEL 与失败签名更新 (f_p, c_p)；AUSS 可新增 p。

**定义 162（痛点驱动能力编排 PCO）** 给定能力集 C={c₁,…,c_n}（对应 IP 模块），集成代价 κ(c)，覆盖矩阵 M∈[0,1]^{m×n}，M[p][c]=P(c 缓解 p)。编排是子集选择 S⊆C：
- **残余风险**：R(S) = Σ_p w_p · Π_{c∈S} (1 − M[p][c])
- **优化**：S* = argmin_{S⊆C} R(S)  s.t.  Σ_{c∈S} κ(c) ≤ B_comp
- **性质**：R 关于 S 单调不增且边际收益递减 ⇒ 覆盖增益 f(S)=R(∅)−R(S) 为单调次模函数，贪心解满足 f(S_greedy) ≥ (1−1/e)·f(S*)（即覆盖类近似保证）。
- **降级语义**：未被选中能力对应的痛点 c_p 保持低值，必须显式登记为「已知未覆盖风险」。

**定义 163（赛事计分对齐 CSA）** 计分模型 S_comp = Σ_k α_k · g_k(x_k)，g_k 为分段函数：g_k(x)=0（x<θ_k^low）、线性中段、饱和上段（x≥θ_k^high）。定义：
- **分数悬崖集**：Θ_cliff = {θ_k^low, θ_k^high}，在悬崖附近 ∂S/∂x 不连续。
- **计分感知优先级**：ρ(a) = E[ΔS_comp | a] / cost(a)，替代纯 VOI 排序。
- **悬崖裕度约束**：动作 a 合法仅当对每个活跃悬崖，预测指标 x_k(a) 距阈值 ≥ ε_cliff（默认 3σ 估计）。

**定义 164（失败归因与自愈 FASH）** 失败签名 σ = (Δmetrics, failing_module, t_remaining, recent_actions)。归因与自愈：
- **归因后验**：P(r|σ) ∝ P(σ|r)·P(r)，r∈根因集 R。
- **自愈动作**：H = {retry, reconfigure, degrade, abort}；每个 h 有期望恢复增益 E[ΔS|h,σ] 与代价 cost_heal(h)。
- **选择规则**：h* = argmax_h (E[ΔS|h,σ] − λ_h·cost_heal(h))，且要求 P(r*|σ) ≥ τ_attr；否则升级为 degrade/abort。
- **自愈预算**：Σ cost_heal ≤ B_heal；超预算立即进入保守降级，禁止「自愈级联」。

**定义 165（赛事鲁棒预算 CRB / PCE+++++）** B_comp = (B_time, B_energy, B_heal, B_integ)，与 B_cog 并列构成五维预算：
- B_time = 距任务/赛段截止的剩余时间；B_energy = 剩余电量折算的可执行预算；
- B_heal = 自愈预算余量；B_integ = 可接受的集成改动预算（配置冻结度）。
- **策略**：B_time 低 ⇒ 跳过探索、用最佳已知策略；B_energy 低 ⇒ 节能优先；B_heal 低 ⇒ 直接安全降级；B_integ 低 ⇒ 冻结能力编排 S*（禁止临场换模块）。

**定义 166（能力组合契约 CCC）** 每个能力 c 的契约 K_c = (Pre_c, Post_c, Inv_c, Asm_c)。组合 S 的**假设泄漏量**
λ(S) = Σ_{c∈S} |Asm_c \ (⋃_{c'∈S,c'≠c} (Post_{c'} ∪ Inv_{c'}))|
- **组合有效**：λ(S)=0；**赛场容错模式**允许 λ(S)>0，但必须把泄漏假设登记为高风险痛点（进入 PPAG，c_p 置 0）。
- 契约检查 O(|S|²·|Asm|)，是「组合坍塌」的前置静态护栏。

**定义 167（对抗未知场景压力器 AUSS）** 生成器 G(θ) 在仿真中搜索未知痛点：
- **覆盖空洞**：p_hole = argmax_p [ w_p − evid_p ]，evid_p 为实测失败证据量。
- **对抗目标**：θ* = argmax_θ Σ_p w_p·1[failure(G(θ)) 命中 p]，用进化/bandit 搜索；
- 发现的新痛点回填 PPAG，并触发 PCO 重编排。

**定义 168（赛事级证据账本 CGEL）** 只追加、哈希链式：
- 记录 rec_i = (t_i, pain_id, capability_id, action, evidence_hash, score_delta)
- 链：h_i = H(h_{i−1} ∥ rec_i)，h_0 = H(genesis)。
- **用途**：得分归因（哪个能力在哪个痛点上贡献了多少分）、裁判可解释、赛后可复现。任何篡改使 h 链断裂，故完整性可验证。

**定义 169（CPAR 赛事痛点分析-恢复闭环算子）** CPAR(M, competition_state):
```
① PPAG.update(CGEL.log, failure_signatures)        # 痛点频率/覆盖度刷新
② S* ← PCO.greedy(B_comp, PPAG)                      # 痛点驱动编排
③ CCC.check(S*) → λ；若 λ>0，登记泄漏痛点并回退相关能力
④ AUSS.probe(仿真) → 新痛点/空洞 → PPAG.add
⑤ Greedy 重算 S*；CSA 排序动作（含悬崖裕度约束）
⑥ Execute；若失败：FASH.attribute(σ) → h*
⑦ CRB.update(B_time,B_energy,B_heal,B_integ)
⑧ CGEL.append(rec)；赛后 review 更新 M[p][c] 与 w_p
⑨ Return (S*, score_attribution, uncovered_risks, ledger_hash)
```

## 2. 关键算法伪代码

### IP-161 PPAG（痛点图构建与级联加权）

```python
class PainPointGraph:
    def __init__(self):
        self.points = {}          # id -> dict(s, f, c, trigger, failure_mode)
        self.edges = {}           # id -> [succ ids]
    def weight(self, pid):
        p = self.points[pid]
        return p['s'] * p['f'] * (1.0 - p['c'])
    def cascade_loss(self, pid, gamma=0.6, memo=None):
        memo = memo or {}
        if pid in memo:
            return memo[pid]
        loss = self.weight(pid)
        for q in self.edges.get(pid, []):
            loss += gamma * self.cascade_loss(q, gamma, memo)
        memo[pid] = loss
        return loss
    def update_from_ledger(self, ledger):
        for rec in ledger:
            p = self.points[rec.pain_id]
            p['f'] = 0.9 * p['f'] + 0.1 * rec.hit
            p['c'] = min(1.0, p['c'] + 0.05 * rec.mitigated)
```

### IP-162 PCO（次模贪心编排）

```python
def orchestrate_capabilities(ppag, cost, cover, B_comp):
    S, spent = [], 0.0
    remaining = set(cover.keys())
    def residual(S):
        return sum(ppag.weight(p) * prod(1 - cover[c].get(p, 0) for c in S)
                   for p in ppag.points)
    while remaining:
        best, best_gain = None, -1.0
        for c in remaining:
            if spent + cost[c] > B_comp:
                continue
            gain = residual(S) - residual(S + [c])
            if gain > best_gain:
                best, best_gain = c, gain
        if best is None or best_gain <= 1e-9:
            break
        S.append(best); spent += cost[best]; remaining.remove(best)
    return S, residual(S), spent
```

### IP-163 CSA（计分对齐与悬崖裕度）

```python
def score_aware_priority(action, score_model, sigma=1.0, eps_cliff=3.0):
    dS = score_model.expected_delta(action)       # 分段期望增量
    if not score_model.margin_ok(action, eps_cliff * sigma):
        return -float('inf')                      # 悬崖边禁止冒险
    return dS / max(action.cost, 1e-6)
```

### IP-164 FASH（贝叶斯归因 + 自愈选择）

```python
def attribute_and_heal(sig, causes, heal_actions, B_heal, tau_attr=0.6):
    post = {r: causes[r].likelihood(sig) * causes[r].prior for r in causes}
    Z = sum(post.values()) or 1e-12
    post = {r: v / Z for r, v in post.items()}
    r_star = max(post, key=post.get)
    if post[r_star] < tau_attr:
        return 'degrade', post
    best, best_util = 'degrade', -float('inf')
    for h in heal_actions:
        if h.cost > B_heal:
            continue
        util = h.expected_score_gain(sig) - h.lambda_cost * h.cost
        if util > best_util:
            best, best_util = h, util
    return best, post
```

### IP-169 CPAR（闭环主算子）

```python
def cpar_loop(M, comp_state):
    M.ppag.update_from_ledger(M.cgel)
    S, risk, spent = orchestrate_capabilities(
        M.ppag, M.cap_cost, M.cover, M.budget.B_comp)
    leak = M.ccc.check(S)
    if leak > 0:
        M.ppag.add_leak_points(leak); S = M.pco.repair(S, leak)
    holes = M.auss.probe(M.sim, M.ppag)
    M.ppag.add_points(holes)
    action = max(comp_state.actions,
                 key=lambda a: score_aware_priority(a, M.score_model))
    result = M.executor.run(action)
    if result.failed:
        h, post = attribute_and_heal(result.sig, M.causes, M.heal_actions,
                                     M.budget.B_heal)
        result = M.executor.apply_heal(h)
    M.crb.update(result)
    M.cgel.append(comp_state.t, result)
    return M, S, score_attribution(M.cgel), M.ppag.uncovered_risks()
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PPAG | O(m+\|E\|) 更新 | O(m+\|E\|) | 级联损失有限（γ<1）且权重可解释 |
| PCO | O(n²m) 贪心 | O(nm) | 次模覆盖增益近似比 ≥ 1−1/e |
| CSA | O(1)/动作 | O(1) | 悬崖裕度约束下不越界 |
| FASH | O(\|R\|) 归因 | O(\|R\|+\|H\|) | 归因后验归一；预算内自愈 |
| CCC | O(\|S\|²·\|Asm\|) | O(\|S\|) | λ=0 时组合安全 |
| CGEL | O(1) 追加 | O(N) | 哈希链防篡改 |

**正确性定理（CPAR）**：假设 A66–A72 成立：
- **(A66)** PPAG 权重 s/f/c 由可观测统计估计，级联边无环；(A67) PCO 覆盖矩阵 M 校准（Brier<0.1）；(A68) CSA 计分模型分段函数在阈值外局部 Lipschitz；(A69) FASH 归因似然可校准；(A70) CCC 契约假设可枚举；(A71) AUSS 采样覆盖未知场景分布；(A72) CGEL 哈希函数抗碰撞。
则：
1. **覆盖近优**：R(∅)−R(S_PCO) ≥ (1−1/e)·(R(∅)−R(S*)) − ε_m（次模贪心保证）。
2. **计分不越悬崖**：满足 ε_cliff 裕度的动作不会因预测误差跨过阈值（概率 ≥ 1−δ）。
3. **自愈有界**：任一失败至多消耗 B_heal，之后强制降级，无自愈级联。
4. **组合无隐式坍塌**：λ(S)=0 ⇒ S 中任意能力的前置条件均由其他能力的后置/不变式支撑。
5. **账本可审计**：CGEL 哈希链完整 ⇒ 得分归因可复现。

## 5. 本轮最大风险

**一句话**：PPAG 与计分模型都只从「已排练过的痛点」估计，若赛场出现真正的未知未知（AUSS 也没采样到），或计分模型被误设，那么「痛点驱动编排」会把预算精准地投到错误的痛点上并诱发新的 Goodhart 行为；必须以「AUSS 主动搜洞 + 得分模型在线校准 + λ>0 强制登记未覆盖风险 + B_heal 硬上限」四重护栏，确保「赛事优化」不会牺牲「不崩」这一底线。

## 2. 关键算法伪代码

### IP-161 PPAG（痛点图）

```python
class PainPointGraph:
    def __init__(self):
        self.points = {}          # pid -> dict(s, f, c, trigger, failure_mode)
        self.edges = {}           # pid -> [succ ids]
    def weight(self, pid):
        p = self.points[pid]
        return p['s'] * p['f'] * (1.0 - p['c'])
    def cascade_loss(self, pid, gamma=0.6, memo=None):
        memo = memo or {}
        if pid in memo:
            return memo[pid]
        loss = self.weight(pid)
        for q in self.edges.get(pid, []):
            loss += gamma * self.cascade_loss(q, gamma, memo)
        memo[pid] = loss
        return loss
    def update_from_ledger(self, ledger):
        for rec in ledger:
            p = self.points[rec.pain_id]
            p['f'] = 0.9 * p['f'] + 0.1 * rec.hit
            p['c'] = min(1.0, p['c'] + 0.05 * rec.mitigated)
```

### IP-162 PCO（次模贪心编排）

```python
def orchestrate_capabilities(ppag, cost, cover, B_comp):
    S, spent = [], 0.0
    remaining = set(cover.keys())
    def residual(S):
        return sum(ppag.weight(p) * prod(1 - cover[c].get(p, 0) for c in S)
                   for p in ppag.points)
    while remaining:
        best, best_gain = None, -1.0
        for c in remaining:
            if spent + cost[c] > B_comp:
                continue
            gain = residual(S) - residual(S + [c])
            if gain > best_gain:
                best, best_gain = c, gain
        if best is None or best_gain <= 1e-9:
            break
        S.append(best); spent += cost[best]; remaining.remove(best)
    return S, residual(S), spent
```

### IP-163 CSA（计分对齐与悬崖裕度）

```python
def score_aware_priority(action, score_model, sigma=1.0, eps_cliff=3.0):
    dS = score_model.expected_delta(action)
    if not score_model.margin_ok(action, eps_cliff * sigma):
        return -float('inf')
    return dS / max(action.cost, 1e-6)
```

### IP-164 FASH（贝叶斯归因 + 自愈）

```python
def attribute_and_heal(sig, causes, heal_actions, B_heal, tau_attr=0.6):
    post = {r: causes[r].likelihood(sig) * causes[r].prior for r in causes}
    Z = sum(post.values()) or 1e-12
    post = {r: v / Z for r, v in post.items()}
    r_star = max(post, key=post.get)
    if post[r_star] < tau_attr:
        return 'degrade', post
    best, best_util = 'degrade', -float('inf')
    for h in heal_actions:
        if h.cost > B_heal:
            continue
        util = h.expected_score_gain(sig) - h.lambda_cost * h.cost
        if util > best_util:
            best, best_util = h, util
    return best, post
```

### IP-166 CCC（组合契约检查）

```python
def composition_leakage(selected, contracts):
    leak = 0
    for c in selected:
        guaranteed = set()
        for other in selected:
            if other != c:
                guaranteed |= contracts[other].post | contracts[other].inv
        leak += len(contracts[c].asm - guaranteed)
    return leak
```

### IP-169 CPAR（闭环主算子）

```python
def cpar_loop(M, comp_state):
    M.ppag.update_from_ledger(M.cgel)
    S, risk, spent = orchestrate_capabilities(
        M.ppag, M.cap_cost, M.cover, M.budget.B_comp)
    leak = M.ccc.check(S)
    if leak > 0:
        M.ppag.add_leak_points(leak); S = M.pco.repair(S, leak)
    holes = M.auss.probe(M.sim, M.ppag)
    M.ppag.add_points(holes)
    action = max(comp_state.actions,
                 key=lambda a: score_aware_priority(a, M.score_model))
    result = M.executor.run(action)
    if result.failed:
        h, post = attribute_and_heal(result.sig, M.causes, M.heal_actions,
                                     M.budget.B_heal)
        result = M.executor.apply_heal(h)
    M.crb.update(result)
    M.cgel.append(comp_state.t, result)
    return M, S, score_attribution(M.cgel), M.ppag.uncovered_risks()
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| PPAG | O(m+\|E\|) | O(m+\|E\|) | γ<1 ⇒ 级联损失有限 |
| PCO | O(n²m) | O(nm) | 次模覆盖增益近似 ≥ 1−1/e |
| CSA | O(1)/动作 | O(1) | ε_cliff 裕度下不越悬崖 |
| FASH | O(\|R\|) | O(\|R\|+\|H\|) | 后验归一；B_heal 内自愈 |
| CCC | O(\|S\|²·\|Asm\|) | O(\|S\|) | λ=0 ⇒ 组合安全 |
| CGEL | O(1) | O(N) | 哈希链防篡改 |

**正确性定理（CPAR）**：若 A66–A72 成立，则：
1. 覆盖近优：R(∅)−R(S_PCO) ≥ (1−1/e)·(R(∅)−R(S*)) − ε_m。
2. 计分不越悬崖：满足 ε_cliff 裕度的动作跨阈值概率 ≤ δ。
3. 自愈有界：任一失败至多消耗 B_heal，随后强制降级，无自愈级联。
4. 组合无隐式坍塌：λ(S)=0 ⇒ 全部前置条件由其他能力的后置/不变式支撑。
5. 账本可审计：CGEL 哈希链完整 ⇒ 得分归因可复现。

## 5. 本轮最大风险

**一句话**：PPAG 与计分模型都只从「已排练过的痛点」估计，若赛场出现真正的未知未知（AUSS 也没采样到），或计分模型被误设，那么「痛点驱动编排」会把预算精准地投到错误的痛点上并诱发新的 Goodhart 行为；必须以「AUSS 主动搜洞 + 得分模型在线校准 + λ>0 强制登记未覆盖风险 + B_heal 硬上限」四重护栏，确保「赛事优化」不会牺牲「不崩」这一底线。
