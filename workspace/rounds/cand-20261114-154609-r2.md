# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「Gazebo」×「传感器融合」）

> R69 把不确定性一分为二，并让系统学会「问」。但它有一个没说破的假设：**证据只能从现实中来，而且来得又贵、又不可逆、还只能试一次**。于是 FLUID-RAS 像一个只能做一次实验的科学家：先验错了、模态是幻觉、回答被投毒，就只能把「诚实的不知道」升级成「被证实的错误」。更隐蔽的是，R69 的 FMA 第二意见仍由策略自己给——**系统用自己的密度检验自己的动作**，在分布外会退化成自说自话。
>
> 本轮两个灵感正好提供一对「实验台」与「量具」：
> - **Gazebo** 提供可重复、可反事实、可大规模故障注入的**数字孪生预演场**：同一场景可重放一万次，可改物理参数、光照、时延、接触模型；可以先在仿真里把一次「看/问/触」演一遍，再决定是否在现实里花掉。
> - **传感器融合** 提供**不依赖仿真的现实锚点**：多模态之间的过约束物理一致性（运动学链、接触力、时间同步、多视角几何）是现实世界自己的「证人」，它不关心 Gazebo 怎么想。
>
> 但本轮的核心不是「再加一个仿真器」，而是一个反向的认识论命题：**仿真只能用来杀死假设，不能用来给假设盖章。** 数字孪生是假设生成器与证伪器，不是证据源；任何作用于现实的定案必须由「孪生一致」与「现实不变量见证」两把钥匙共同签发。于是 R69 的「问错比不问更危险」被升级为「**预演过、验证过、仍然错**」这一更深的病——而本轮的解药恰恰是：**让仿真无权单独定罪，也无权单独赦免。**
>
> 核心命题：**把交互从「现实中的一次性实验」变成「孪生中的可证伪预演 + 现实中的锚定确认」；用仿真做鲁棒 VoI 筛选与安全预筛，用传感器融合的过约束不变量做独立见证；仿真权威随 sim-real 间隙分区失效，任何单一来源都不得单独定案。** 命名 **TWIN-RAS**（Twin-grounded, Witness-anchored, Invariant-fusion, Null-first Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**在花掉一次不可逆的现实提问之前，我能不能先在孪生世界里把它杀死；如果不能，我凭什么相信孪生没有与我的错误同谋？**」

## 0. 直觉与动机

**灵感 1（Gazebo = 可反事实的排练厅，而不是真理机）**
直觉：现实交互是一次性、不可回滚、带社会成本的实验；Gazebo 则把同一场景变成可反复重放的「排练」。你可以先让机器人在孪生里「问一句」「凑近看一眼」「轻触一下」，看会发生什么、是否会越界、答案是否真的能区分假设。这天然解决了 R69 的两个痛点：交互太贵（省现实预算）与交互太险（先在孪生里撞墙）。但排练厅不是真理机：**导演（仿真器）和演员（策略）可以共享同一个错误剧本**。

**灵感 2（传感器融合 = 现实的过约束证人）**
直觉：单一传感器可以被骗，但多条相互约束的物理通道很难被同时、同向、同幅度地骗。编码器–IMU–视觉位姿必须满足同一运动学链；触觉力、物体加速度与视觉接触必须满足同一接触约束；多路相机必须满足同一极线几何；事件必须共享同一时间轴。这些约束是**过定的**（约束数多于自由误差数），因此能在不依赖仿真的情况下产生一个「不一致度」——这就是现实证人。它不是另一个模型，而是模型之间**不允许同时错误**的那部分结构。

**灵感 3（危险的对称：孪生也能自洽地骗人）**
直觉：如果系统把 Gazebo 当成主要证据源，就会形成认识论闭环：策略在仿真里采样模态 → 用仿真验模态 → 用模态选交互 → 用仿真看交互结果。每一步都「通过」，因为每一步都用同一个世界的假设。更糟的是，**sim-to-real 间隙不是随机噪声，而是相关的系统误差**：同一套 URDF、同一套外参、同一套动力学先验，会同时污染孪生和「现实见证」。所以本轮最重要的动作不是「让仿真更真」，而是**给仿真降权**：它只能证伪，不能认证。

**灵感 4（零先验：把仿真自己的伪影减掉）**
直觉：仿真里出现一个「显著现象」，可能不是世界真有，而是渲染、碰撞、时延、纹理、接触模型制造的伪影。科学上的做法是做**配对对照**：同一冻结场景，一份注入假设，一份不注入，保留同一套仿真伪影。两者相减，平稳伪影抵消，剩下的才可能是真实效应。这把「仿真可信吗」从无法回答的元问题，转成可操作的**差分审计**：伪影若在对照中同分布，就减得掉；减不掉的非平稳伪影，必须让该发现不可准入。

**灵感 5（迁移感知的 VoI：问「答案不依赖仿真参数」的问题）**
直觉：R69 选信息动作只看「期望降低多少熵」。但如果一个问题的答案高度依赖 Gazebo 的摩擦系数、纹理或接触模型，那它在现实里可能什么也说明不了。于是本轮把 VoI 乘以一个**迁移可信度**：在孪生集合里扰动物理/感知参数，答案越稳定，越值得在现实里问；答案越依赖仿真细节，越应该被降权。**不是「哪个问题信息量最大」，而是「哪个问题的信息量最扛得住 sim-real 间隙」。**

**灵感 6（双钥与钥匙独立性：两把钥匙不能由同一把锁签发）**
直觉：双钥（孪生一致 + 现实见证）听起来安全，但如果两把钥匙共享同一个上游（同一份 URDF、同一次外参标定、同一个时间戳源），它们就会一起错。此时「双钥」只是同一把钥匙盖了两次章。因此必须显式度量**钥匙独立性 ρ_K**：孪生证据与现实见证在「错误时是否同向」的相关性。ρ_K 越高，双钥的误证上界越差；超过阈值，双钥退化为单钥，必须引入真正独立的锚点（外部相机、重力/接触等与机器人模型无关的约束、人工抽检）。**安全的单位不是证据数量，而是独立自由度。**

**灵感 7（严格包含：退化成 R69/R68 而不是并列替代）**
直觉：TWIN 不推翻 FLUID，而是给 FLUID 加一个「预演前置」。当孪生不可用、不在有效区、或预算不允许时，TWIN 逐指令等于 FLUID；当 TVoI≤0 时，不交互，逐指令等于 R68。预演只会**增加拒绝**，不会**增加接受**；因此安全侧永不弱于 R69。这是本轮的理论姿态：新层必须是旧层的保守扩展，否则每加一层就多一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（TWIN-RAS 总览与五不变式）** TWIN-RAS = (DTE, CXR, SDF, TVoI, RSS, NFSA, SFIW, CCF, DAF, KIA, SAG, J_TWIN, FL, RAS-WM†)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i；孪生预演、重放、差分审计只在离线或并行预算内运行，不阻塞实时环）；
(ii) **权威非对称**：孪生证据只能剪枝、塑先验、提出假设，**不得单独签发证书**；
(iii) **双钥合签**：任何作用于现实的模式定案，须同时通过孪生一致性检查与至少一个与孪生弱相关的现实不变量见证；
(iv) **零先验优先（null-first）**：孪生发现必须先通过其配对零假设的差分审计，扣除仿真伪影；
(v) **权威分区失效**：在未获 sim-real 等价认证的状态区域，孪生权威 = 0，链路逐指令退化为 FLUID；无交互时退化为 R68。

**定义 311（数字孪生集合 DTE）** 不是单个 Gazebo 实例，而是 M 个随机化世界 {S_m}，S_m = (物理参数 θ_m, 传感器噪声/时延/量化 ψ_m, 渲染/纹理 ρ_m, 接触/摩擦 μ_m, 人类响应模型 η_m)。参数来自现实标定先验上的不确定性盒（不是任意放大）。对候选动作 g，S_m 给出结果 y_m(g) 与安全裕度 s_m(g)。

**定义 312（冻结场景反事实重放 CXR）** 给定现实记录 o_{t−T:t} 与冻结场景状态 ẑ（由 SLAM/状态估计给出），在 S_m 中以同一初始状态重放，得到配对样本 (o_real, o_sim^m)。配对使场景方差在差分中抵消，只剩孪生误差；这是后续 SDF、NFSA 的统计功效来源。

**定义 313（sim-real 间隙场 SDF 与有效区）** 对状态区域 R，d_SR(R) = sup_{配对样本} D(p_real(r|R), p_sim(r|R))，D 取 MMD/能量距离/分位数差。维护分区地图；样本不足时 d_SR = ∞（保守）。若 d_SR(R) ≤ ε_R 且样本数 ≥ n_min，则 R ∈ 𝒱（孪生有效区）。

**定义 314（鲁棒 VoI 与迁移感知 VoI）** 对候选信息动作 g：
VoI_sim^m(g) = H(M|o) − E_{y~S_m(·|g)} H(M|o,y)；
VoI_rob(g) = min_m VoI_sim^m(g) − τ_R·d_SR(R)（或置信下界）；
TVoI(g) = (1 − δ(g))·VoI_rob(g) − c(g)，其中 δ(g) ∈ [0,1] 为 g 的预演结果对孪生参数 θ_m 的敏感度（归一化极差/方差），度量「答案有多依赖仿真细节」。选 g* = argmax TVoI，并要求双钥可签。

**定义 315（预演安全筛 RSS）** 信息动作 g 在现实执行前，须在全体（或 α-分位最差）S_m 上通过 C-RAS-WM 认证且 s_m(g) ≥ 0；任一失败 ⇒ g 进入「仅仿真可做」清单，不得现实执行。RSS 同时预演社会安全：问句是否诱导危险、探针是否越力/位包络、注视是否诱发失稳。

**定义 316（零先验仿真审计 NFSA）** 对孪生发现 φ（如「模态 k 真实存在」「故障是 X」），构造配对零假设 S^0：同一冻结场景、移除 φ 的成因、保留同一套渲染/物理/传感器伪影。统计量 Δ_m = T(o_sim^m(alt)) − T(o_sim^m(null))。仅当 Δ_m 超出零分布校准的 e-value/conformal 阈值才准入。平稳伪影在差分中抵消；非平稳伪影不抵消，必须显式建模或使发现不可准入。

**定义 317（传感器融合不变量见证 SFIW）** 令潜在误差 e = (e_1,…,e_d)（各模态偏差/时延/标定误差），过约束不变量映射 H: ℝ^d → ℝ^k，见证残差 w = H e + ν。典型 H 行：运动学链闭合（编码器–IMU–视觉位姿）、接触一致性（触觉力–物体加速度–视觉接触）、时间同步（跨模态事件相关）、多视角几何（极线/深度）、能量/动量约束。见证通过 ⇔ ‖w‖ ≤ τ_w 且无主导异常方向。

**定义 318（共同因可检测性 CCF）** 设 rank(H) = k，冗余 r = d − k。误差 e 可检测 ⇔ e ∉ ker(H)。若故障/共谋误差落在 ker(H)（例如一个统一外参错误同时污染所有视觉通道），该见证族完全不可见。因此要求见证多样性：存在独立约束族 H′，使 ker(H) ∩ ker(H′) = {0}（强）或使交集维度显著下降（弱）。

**定义 319（依赖感知融合 DAF）** 不做朴素贝叶斯相乘（会重复计数相关模态），而用协方差交叉/因子图：后验 ∝ ∏_i p_i^{ω_i}，ω 由配对反事实消融估计的模态相关矩阵 Σ_modal 决定。Σ_modal 可在孪生中通过冻结场景逐模态消融估计，但 ω 的最终取值只接受现实见证校正（双钥）。这是「仿真提议、现实批准」在融合权重上的具体化。

**定义 320（钥匙独立性 KIA 与 ρ_K）** 令 A = 孪生通过，B = 现实见证通过，F = 命题为假。ρ_K 度量「在 B 成立的条件下，A 与 F 的正相关强度」：ρ_K = sup P(A|F,B) − P(A|B)。ρ_K=0 表示仿真的通过与否不偏向假命题；ρ_K→1 表示对抗孪生专挑现实见证薄弱处通过（仿真捕获）。双钥有效要求 ρ_K ≤ ρ_0。若孪生与现实共享模型/标定/时间源，ρ_K 会升高，必须用外部独立锚点补强。

**定义 321（孪生权威门 SAG）** 权威 a(R) = 1{R ∈ 𝒱}·min(1, n_R/n_min)·(1 − d_SR(R)/ε_R)_+。a=0：禁用一切孪生剪枝，退化为 FLUID；0<a<1：只允许按 a 加权的软先验，不允许硬性剪枝/定案；a=1：允许 RSS/NFSA 的完整剪枝，但仍不允许单独签发证书（定义 310-iii）。

**定义 322（双钥证书 J_TWIN）** J_TWIN = (J_FLUID, sim_margin, d_SR(R), witness, ρ_K, null_evalue, twin_hash, twin_ver)。Valid ⇔ Valid(J_FLUID) ∧ sim_margin ≥ 0 ∧ witness 通过 ∧ ρ_K ≤ ρ_0 ∧ null_evalue 达标 ∧ R69 证据纪律满足 ∧ twin_hash 未被篡改。任一缺失 ⇒ 不得把孪生证据用于定案。

**定义 323（孪生投毒威胁 ℰ_twin）** 数字孪生自身的攻击面：物理参数篡改、传感器模型后门、场景资产投毒、回放缓存污染、孪生版本回滚。并入 AIC：ℰ_TWIN = ℰ_FLUID × ℰ_twin。关键：孪生被投毒时内部一致性通常全绿，唯一防线是独立现实见证、版本哈希/签名与外部抽检。

**定义 324（预演隔离与仿真捕获度 κ）** 现实实时学习写操作仍为零；孪生产生的数据只能离线更新课程/先验，且需现实见证分层验证。定义仿真捕获度 κ = 策略在孪生分布与现实分布上的 VoI 排序一致性（Kendall τ）或 regret 差；κ 越低，越要减少对孪生先验的依赖。设「预演配额」防止过拟合孪生盲区。

**定义 325（分歧驱动场景挖掘 DDSM）** 主动选择使 d_SR 最大或双钥结论冲突最大的场景进行真实采集/校准：z* = argmax_z [d_SR(z) + λ·1{two_key_disagree(z)}]。这把「更多仿真」换成「更对的仿真」：仿真不负责变多，负责暴露自己哪里不像现实。

**定义 326（证伪账本 FL）** 记录每个假设被谁杀死：sim-kill（仿真否证）、real-kill（现实否证）、undecided。审计比例与时间趋势；若 sim-kill 占比极高而 real-kill 长期为 0，可能是仿真捕获（仿真太容易杀死假设）或现实证据不足。账本同时驱动 DDSM 与预演配额。

**定义 327（预演-交互联合预算）** 总预算 B = B_sim + B_real。单次决策分配 (b_sim, b_real)：先用低分辨率 DTE 粗筛，再用高保真/更多随机化对候选集精筛；形式化为带预算约束的序贯决策，目标 max E[TVoI] s.t. cost ≤ B，并满足 P99 实时约束（孪生结果未就绪即回退 FLUID，绝不阻塞）。

**定义 328（严格包含与退化边界）** 当 DTE 为空、a(R)=0 或时间预算不允许预演时，TWIN 的候选集与决策逐指令等于 FLUID；当 TVoI≤0（含 VoI 无利可图）时不交互，逐指令等于 R68。预演只可能增加拒绝、不可能增加接受 ⇒ 安全侧单调不弱于 R69。

## 2. 关键算法骨架

```python
# IP-264 DTE：随机化数字孪生集合（Gazebo/gz-sim + 域随机化）
class TwinEnsemble:
    def __init__(self, worlds, n_min, eps_R):
        self.worlds, self.n_min, self.eps_R = worlds, n_min, eps_R

    def rehearse(self, g, scene_hat, M):
        out = []
        for S in self.worlds[:M]:
            y, margin = S.replay(scene_hat, g)      # CXR：冻结场景重放
            out.append((y, margin, S.theta))
        return out

# IP-265 SDF：sim-real 间隙场（分区 + 配对差分）
def update_gap_map(gmap, pairs):
    for R, (real, sim) in group_by_region(pairs):
        gmap.d[R] = energy_distance(real, sim)
        gmap.n[R] += len(real)

def authority(R, gmap):
    if not gmap.certified(R): return 0.0            # 样本不足 / 未认证
    return min(1.0, gmap.n[R]/gmap.n_min) * max(0.0, 1.0 - gmap.d[R]/gmap.eps_R)

# IP-266 TVoI：鲁棒 + 迁移感知的交互选择
def choose_interaction_twin(modes, o, budget, DTE, gmap):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g): continue
        if not c_ras_wm.certify_info(g, o): continue
        sims = DTE.rehearse(g, scene_hat(o), M=budget.M)   # RSS 安全预筛
        if min(m for _, m, _ in sims) < 0: continue
        voi   = min(voi_for(modes, g, s) for s in sims)    # 最差世界
        delta = transfer_sensitivity(sims)                 # 对 theta 的敏感度
        score = (1-delta)*voi - cost(g) - tau_R*gmap.d[region(o)]
        if best is None or score > best.score: best = (g, score, sims)
    return best if best and best.score > 0 else None

# IP-267 NFSA：零先验差分，扣除仿真伪影
def null_first_admit(expt, DTE, scene_hat):
    alt  = DTE.simulate(expt, scene_hat, inject=True)
    null = DTE.simulate(expt, scene_hat, inject=False)    # 保留同套伪影
    d    = statistic(alt) - statistic(null)
    return e_value(d, DTE.null_dist(expt)) >= 1.0/alpha

# IP-268 SFIW：传感器融合不变量见证
def invariant_witness(modalities, model):
```

## 3. 推导

**引理 19（证伪非对称性与剪枝单调）** 设 A_F 为 FLUID 候选交互集，A_T 为经 RSS 与 TVoI 剪枝后的集合，则 A_T ⊆ A_F。若孪生只用于拒绝（不安全 / 鲁棒 VoI≤0 / 零假设不过），TWIN 的现实交互诱发风险不高于 FLUID；被剪掉的期望收益 ≤ Σ_{g∈A_F∖A_T} TVoI(g)。即安全单调，效率损失有界。证明：剪枝只可能减少候选；每一次现实执行都仍经 FLUID 的安全认证。

**引理 20（迁移感知 VoI 的遗憾界）** 若 g 的预演结果对孪生参数 θ 的敏感度 ≤ δ_0，且真实与孪生后验熵差 ≤ L·d_SR，则 |VoI_real(g) − VoI_sim(g)| ≤ L·d_SR + C·δ_0。故在有效区 R∈𝒱 内以 TVoI 选出的 g 相对真实最优的遗憾 ≤ 2(L·d_SR + C·δ_0)。系：**可迁移的问题不是信息量最大的问题，而是对孪生参数最不敏感的问题**；当 d_SR 很大时，应优先选 δ 小的「鲁棒问题」，而不是 δ 大的「高信息问题」。

**引理 21（共同因可检测性）** 见证残差 w = H e + ν，rank(H)=k。可检测子空间 = row(H)，不可检测子空间 = ker(H)，冗余 r = d−k。若跨模态共谋误差 e ∈ ker(H)，则该见证族完全不可见；需第二见证族 H′ 使 ker(H) ∩ ker(H′) = {0}。系：**融合鲁棒性不是模态数量，而是零空间被多样性覆盖的程度**；十路同源相机不等于十路独立证据。

**引理 22（钥匙独立性与双钥误证上界）** 设 P(F|B) ≤ α_R，A = 孪生通过，B = 现实通过。则 P(F|A∩B) ≤ α_R·(1 + ρ_K/P(A|B))。当 ρ_K=0（在 B 条件下 A 不偏向假命题）时，双钥误证率 ≤ α_R；当 ρ_K→1 时上界退化到平凡。证明：贝叶斯展开 P(F|A∩B)=P(A|F,B)P(F|B)/P(A|B)，再用 ρ_K 的定义放缩。系：**双钥的安全性不来自「有两个检查」，而来自「两个检查在错误上不同向」**。

**定理 18（双钥健全性与严格包含）** 在 A99–A101（配对重放可用、见证映射有界、二元检查校准）下，J_TWIN Valid ⇒ 现实误证率 ≤ α_R·(1+ρ_K/P(A|B))，与孪生偏差无直接关系；若 DTE 空或 a(R)=0，TWIN 逐指令等于 FLUID；若 TVoI≤0，逐指令等于 R68。故安全侧不弱于 R69/R68，且孪生只增加拒绝、不增加接受。

**定理 19（现实锚点的必要性 / 仿真捕获不可能性）** 对任何仅依赖孪生的证书程序，存在孪生 S* 与场景 z*，使所有内部一致性检查通过而真实风险 > ε。证明思路：有限现实样本无法约束孪生在未观测场景的行为；S* 可在观测点上与真实一致、在 z* 处任意偏离，且可把任何内部检查实现为恒真。故「仿真只能证伪、不能认证」不是保守口号，而是对抗模型下的必要条件。系：**越强的生成式孪生，越能自洽地为一个错误世界背书**。

**定理 20（零先验差分消除平稳伪影）** 若孪生伪影 a(z) 在配对 alt/null 中同分布（冻结场景、同参数、同版本），则 Δ = T(alt)−T(null) 的期望等于真实效应，伪影偏差为 0；若伪影非平稳（版本/缓存/时间相关），差分不消除，偏差 ≤ E|ξ|，误准入率 ≤ α + g(E|ξ|)。系：NFSA 的有效性依赖「配对可用」与「伪影平稳」，这正是定义 312/322 的工程约束。

**定理 21（权威门的安全退化）** 当 R∉𝒱 或 a(R)=0 时，SAG 强制禁用孪生剪枝与先验，TWIN 的决策分布与 FLUID 完全相同；当 0<a<1 时，软先验只改变候选排序、不改变认证前缀，故换装不变式（R68 定理 15）与无突变性保持。故孪生失效/被投毒/版本回滚时，系统单调退回 R69，不存在「孪生一坏就失控」的通道。

## 6. 本轮最大风险

**一句话**：TWIN-RAS 的致命前提是「现实锚点与孪生真的独立」——如果物理不变量与仿真共享同一套模型/外参/时间源（同一份 URDF、同一次标定、同一个时钟），那么两把钥匙其实由同一把锁签发（ρ_K→1）；此时仿真越强、预演越多，系统越能**自洽地**为一个错误世界盖章，最终把 R69 的「问错」升级为「**预演过、验证过、仍然错**」。

**次级风险与缓解**：
1. **仿真捕获 / 过预演**（策略学会讨好 Gazebo 而非现实）→ 预演隔离 + 捕获度 κ + 预演配额 + E310；
2. **双钥退化为单钥**（共享上游）→ KIA 显式估 ρ_K + 外部独立锚点（外部相机、重力/接触、人工抽检）+ E306；
3. **共同因故障不可见**（落在 ker(H)）→ 见证多样性 H′ + 冗余覆盖 + E305；
4. **非平稳仿真伪影**（NFSA 差分失效）→ 版本哈希 + 配对隔离 + 伪影漂移检测 + E303；
5. **预演预算击穿时延** → anytime rehearsal + 未就绪即回退 FLUID + P99 门控 + E312；
6. **孪生投毒/回滚** → ℰ_twin 对抗训练 + 版本签名 + 独立现实见证 + E304。

**定义 311–312（DTE 与 CXR）** M 个随机化 Gazebo 世界；冻结现实场景 ẑ 后在每个世界重放，得到配对样本。随机化来自标定先验的不确定性盒，不能任意放大。

**定义 313（SDF 与有效区）** d_SR(R) 为配对残差分布距离的上确界；样本不足取 ∞；R∈𝒱 才允许孪生权威。有效区是一张地图，不是全局开关。

**定义 314（TVoI）** `VoI_rob=min_m VoI_sim^m−τ_R d_SR`；`TVoI=(1−δ)VoI_rob−c`。δ 度量答案对孪生参数的敏感度：**先问「答案扛不扛得住 sim-real 间隙」，再问「信息量大不大」**。

**定义 315–316（RSS 与 NFSA）** RSS：任一孪生世界不安全 → 禁止现实执行；NFSA：alt−null 配对差分，扣除平稳仿真伪影，e-value 达标才准入。

**定义 317–319（SFIW / CCF / DAF）** 过约束不变量残差 w=He+ν；不可检测误差恰为 ker(H)，需多样见证 H′；融合用协方差交叉避免相关模态重复计数，ω 由现实见证批准。

**定义 320–322（KIA / SAG / J_TWIN）** ρ_K 是双钥是否真独立的核心；a(R) 分区权威，0 时逐指令退化为 FLUID；J_TWIN 要求 Valid(J_FLUID) ∧ 双钥 ∧ e-value ∧ 版本哈希。

**定义 323–324（ℰ_twin / 捕获度）** 孪生自身可被投毒/回滚；预演数据只进离线课程，不进实时学习；κ 监测「策略是否在讨好仿真」。

**定义 325–328（DDSM / FL / 预算 / 退化）** 主动采集双钥分歧场景；账本识别 sim-kill 偏置；预算 B=B_sim+B_real 序贯分配；DTE 空或 a=0 → FLUID，TVoI≤0 → R68。

```python
# IP-264/265 DTE + CXR
def rehearse(DTE, g, scene_hat, M):
    return [S.replay(scene_hat, g) for S in DTE.worlds[:M]]   # (y, margin, theta)

# IP-266/267 TVoI + RSS
def choose_interaction_twin(modes, o, budget, DTE, gmap):
    best = None
    for g in info_action_candidates(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        sims = rehearse(DTE, g, scene_hat(o), budget.M)
        if min(m for _, m, _ in sims) < 0: continue            # RSS
        voi   = min(voi_for(modes, g, s) for s in sims)        # 最差世界
        delta = transfer_sensitivity(sims)                     # 对 theta 的敏感度
        score = (1-delta)*voi - cost(g) - tau_R*gmap.d[region(o)]
        if best is None or score > best.score: best = (g, score, sims)
    return best if best and best.score > 0 else None

# IP-269 NFSA：alt - null
def null_first_admit(expt, DTE, scene_hat):
    alt  = DTE.simulate(expt, scene_hat, inject=True)
    null = DTE.simulate(expt, scene_hat, inject=False)
    return e_value(statistic(alt)-statistic(null), DTE.null_dist(expt)) >= 1/alpha

# IP-270/271/273 双钥 + 独立性
def two_key_admit(sim_claim, o_real, R):
    ok_sim  = sim_claim.margin >= 0 and sim_claim.valid
    ok_real, w = invariant_witness(o_real.modalities, o_real.model)
    rho = KIA.estimate(sim_claim, w, R)                        # 共享上游 → rho↑
    return ok_sim and ok_real and rho <= RHO0, w, rho

# IP-274 主闭环（继承 FLUID；孪生异步，未就绪即回退）
def TWIN_RAS_round(M_, obs):
    z,o = M_.mtm.forward(obs); c,U_cal,thr = M_.cof.step(...)
    K = 1 if M_.fmp.mode_head(z) < TAU_MODE else 4
    U_ale,U_epi,modes,_ = M_.aud.decompose(M_.fmp.sample(o,K), z, M_.fmp.mode_head)
    a_hat = M_.fma.flow_anomaly(M_.fmp, M_.last_action, o_obs, o_cal)
    slow  = (a_hat > TAU_FMA) and (M_.last_r_res < TAU_RES)
    g, sims = None, None
    if U_epi > TAU_EPI and not slow:
        R = region(o)
        if M_.sag.authority(R) > 0 and M_.twin_ready(R):
            r = M_.mint_twin.choose_interaction(modes, o, M_.budget, M_.dte, M_.gap)
            g, _, sims = r if r else (None, None, None)
        if g is None: g = M_.mint.choose_interaction(modes, o, M_.budget)  # FLUID
    if g is not None:
        if sims is not None and M_.sag.authority(region(o)) > 0:
            if not M_.nfsa.admit(g, M_.dte, scene_hat(o)): g = None
        if g is not None:
            U_epi_before = U_epi
            ans = M_.cia.execute(g)
            U_epi = M_.cia.update_belief(modes, ans)
            ok, w, rho = M_.two_key_admit(sim_claim(g, sims), o, region(o))
            if not ok: U_epi = max(U_epi, U_epi_before)       # 双钥不过 → 不定案
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(M_.efs.risk_scale(...), lam_floor(U_floor))
    k = M_.c_ras_wm.certified_prefix(M_.ach.propose(x_prime, M_.vista.H), ..., wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, k_cal_shrink(x_prime, U_cal))
    mode = select_mode(modes, U_epi, lam)
    tau  = M_.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M_.daf.update_with_witness(w); M_.gap.update(pair_from(o, sims))
    M_.fl.log(...); M_.vqa.submit_async(g, U_epi, a_hat, sims, rho)
    return k, lam, mode, (U_ale, U_epi)
```

## 4. 推导

**引理 19（证伪非对称 / 剪枝单调）** A_T ⊆ A_F；孪生只用于拒绝时，现实交互诱发风险不高于 FLUID，效率损失 ≤ Σ_{g∈A_F∖A_T} TVoI(g)。安全单调，效率有界损失。

**引理 20（迁移感知 VoI 遗憾界）** 若 δ(g) ≤ δ_0 且熵差 ≤ L·d_SR，则 |VoI_real−VoI_sim| ≤ L·d_SR + C·δ_0；TVoI 选择的遗憾 ≤ 2(L·d_SR + C·δ_0)。系：d_SR 大时应优先选 δ 小的鲁棒问题。

**引理 21（共同因可检测性）** w=He+ν，rank(H)=k；可检测子空间 row(H)，不可检测 ker(H)，冗余 r=d−k；需第二见证族 H′ 使 ker(H)∩ker(H′)={0}。系：鲁棒性来自零空间被多样性覆盖，而非模态数量。

**引理 22（钥匙独立性与双钥误证上界）** P(F|B) ≤ α_R 时，P(F|A∩B) ≤ α_R·(1+ρ_K/P(A|B))；ρ_K=0 时 ≤ α_R，ρ_K→1 时退化为平凡上界。系：双钥安全来自「错误不同向」，不来自检查数量。

**定理 18（双钥健全性与严格包含）** J_TWIN Valid ⇒ 现实误证率 ≤ α_R·(1+ρ_K/P(A|B))；DTE 空/a=0 → 逐指令 = FLUID；TVoI≤0 → 逐指令 = R68。安全侧不弱于 R69/R68。

**定理 19（现实锚点的必要性 / 仿真捕获不可能性）** 任何仅依赖孪生的证书程序都存在对抗孪生 S* 与场景 z*，使内部检查全绿而真实风险 > ε。故双钥是必要条件，不是可选优化。

**定理 20（零先验差分消除平稳伪影）** 配对 alt/null 中伪影同分布时，Δ 期望等于真实效应；非平稳伪影偏差 ≤ E|ξ|，误准入 ≤ α+g(E|ξ|)。系：NFSA 依赖配对可用与伪影平稳。

**定理 21（权威门安全退化）** R∉𝒱 或 a=0 时 TWIN 决策分布等于 FLUID；0<a<1 时只改候选排序、不改认证前缀，换装不变式保持。孪生失效/投毒/回滚时单调退回 R69，无突变通道。

## 8. 本轮最大风险

**一句话**：TWIN-RAS 的致命前提是「现实锚点与孪生真的独立」——如果物理不变量与仿真共享同一套模型/外参/时间源（同一份 URDF、同一次标定、同一个时钟），那么两把钥匙其实由同一把锁签发（ρ_K→1）；此时仿真越强、预演越多，系统越能**自洽地**为一个错误世界盖章，最终把 R69 的「问错」升级为「**预演过、验证过、仍然错**」。

**次级风险与缓解**：仿真捕获/过预演（隔离 + κ + 配额 + E310）；双钥退化（KIA + 外部独立锚点 + E306）；共同因故障（见证多样性 H′ + E305）；非平稳伪影（版本哈希 + 配对隔离 + E303）；预算击穿（anytime rehearsal + 回退 + E312）；孪生投毒/回滚（ℰ_twin + 签名 + E304）。
