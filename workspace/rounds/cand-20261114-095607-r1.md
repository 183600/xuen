# 第 73 轮（承接第 72 轮「EMBODIED-GAUGE-RAS」IP-287~294；灵感循环第 3 轮；本轮灵感：「惯性测量单元」×「人机交互」）

> R72 把 GAUGE 从「认知层」下沉为「具身层」：REG 实时执行图、IRL 意图隐变量、DMEM 灵巧接触计量、EREFLEX 三层反作用、S2R-UQ 仿真-实机桥接，并给出「调度可信、意图可辨、接触可计量」时的逐指令风险界。但 R72 的证据模型仍隐含两个未经审计的假设：
> - **独立同分布/马尔可夫证据假设**：每条观测都贡献「新鲜」信息，误差在时间上不相关。惯性测量单元（IMU）从根本上违反这一点：姿态/速度由积分得到，误差是**带偏置的随机游走**；100 Hz 采 1 秒，对慢变偏置而言**有效独立样本可能不足 1 个**。把 IMU 当成「又一个 y」送进 BSE，会把同一段漂移重复计数上百次，导致**信息增益虚高、协方差过窄、λ 过低**。
> - **人机分离假设**：人和机器人是两个独立证据源。但在递接、物理引导、外骨骼、拥抱式协作中，**人与机器人共享同一条机械惯性通道**：两个 IMU 都观测到「自身运动 + 对方运动 + 共同运动」的混合。把它们当独立证据，会在刚性耦合时产生**虚假一致（common-mode masking）**：两个传感器都说「稳定」，因为它们一起在动，相对运动信息却已经消失。
>
> 更关键的是，R72 的意图 z 是**自愿意图**，没有建模**不自愿的保护性反射**。人在机器人靠近时会 brace/flinch/freeze——这些信号比语言快一个数量级，且**不是可优化的偏好，而是安全否决**。把反射当意图，会让机器人对「人害怕了」做任务级推理；把意图当反射，会让机器人过度保守。
>
> 本轮两个灵感正好补三块：
> - **惯性测量单元**：把 IMU 从「普通传感器」升级为**带记忆的计量证据**（误差状态、相关时间、有效样本数、信息半衰期、激励可观测性）；把「漂移」从噪声问题升级为**计量审计问题**。
> - **人机交互**：把「人」从「证据源 + 意图源」升级为**共享惯性通道 + 反射安全源 + 物理同意主体**；引入 L0 保护性反射否决、物理同意与舒适包络、跨设备时间同步审计。
> - **惯性×交互的交点**：惯性既是**记忆**（时间相关），又是**耦合**（人机共享），还是**身体信号**（反射/同意）。三者共同构成「惯性的三重性」。
>
> 核心命题：**R72 问「我的测量链在调度、意图、接触下还能兑现风险界吗？」R73 追问：「当我的证据有记忆、我和人共享一个惯性身体时，我还能兑现风险界吗？我能不能分清人的意图和人的保护性反射？」** 这就是 **INERTIA-GAUGE-RAS**（Inertial, Non-Markovian, Embodied, Reflex-coupled, Time-synchronized, Intent/consent-Audited GAUGE for RAS）——**惯性耦合计量审计闭环**。

## 0. 直觉与动机

**灵感 1（IMU → 漂移不是噪声，漂移是记忆）**
直觉：普通传感器的一次观测错了，下一次可能就对了；IMU 的偏置错了，**接下来所有积分都错，而且错得一样**。把所有样本当独立高斯，就像把同一句话听了一百遍就以为得到了一百条证据。IMU 的误差是一个**慢变隐状态**：偏置随机游走、尺度因子、安装误差、温度与振动调制。必须把误差状态显式放进状态空间，携带**相关时间 τ_corr**、**有效独立样本数 n_eff**、**信息半衰期 τ_1/2**，并在证据过期时**非补偿性地降权或拒绝**。**IMU 的第一性原理不是「高频」，而是「高相关」。**

**灵感 2（IMU → 死 reckoning 把测量变成历史，信息预算不可再生）**
直觉：用 IMU 推位姿，本质是**用历史换现在**；走得越久，历史债务越重。更麻烦的是，**没有激励就没有可观测性**：人站着不动时，「真实加速度为零 + 偏置 b」与「真实加速度为 b + 偏置为零」在数学上不可区分。因此惯性证据的可信度不仅取决于传感器，还取决于**运动激励**与**外部锚点**（零速检测、已知标定动作、接触事件、视觉相对位姿、力/力矩）。**静止不是「信息量低」，静止是「偏置不可观」。**

**灵感 3（人机交互 → 物理耦合让两个人共享一个惯性身体）**
直觉：递杯子时，人的手腕 IMU 和机器人末端 IMU 会同时看到「一起抬、一起停」的共同运动。若把两路信号当独立证据做融合，系统会**因为两路一致而更自信**，但这两路一致可能只是**共同模态**，相对运动信息在强耦合下被抵消。极端情况下（刚性连接），差分信号趋近于零，**相对运动完全不可辨**。必须做**共同模态/相对模态分解**，用条件数判断可辨识性；耦合越强，越不能相信「两路一致」。**人机交互的本质不是「多一个传感器」，而是「多一个共享误差源」。**

**灵感 4（人机交互 → 人的身体有两套通道：自愿意图与不自愿反射）**
直觉：人说「好」不代表身体说「好」。机器人突然加速，人的手会先**僵住/后缩/护住**，然后才说「没事」。反射走的是更快、更底层的通路：startle < 100 ms、brace/flinch 100–300 ms；自愿意图（伸手、指、撤回）通常 > 300 ms。反射的规范地位不同：**它不是「人想要什么」，而是「人的身体在报警」**。因此需要在 R72 的 L1 情感、L2 意图、L3 接触之下，增加 **L0 保护性反射层**：L0 是否决，不是可交易的成本项；任何任务 VoI 都不能把它优化掉。**分不清意图与反射，是把安全信号当偏好、把偏好当安全信号。**

**灵感 5（人机交互 → 物理同意与舒适是硬约束，不是软成本）**
直觉：信任不只写在问卷里，也写在身体上：人 stiffen（僵硬）、avoid（回避）、brace（支撑）、freeze（冻结）就是「还没说出口的拒绝」。同时，机器人运动本身会通过耦合传到人身上：频率加权加速度、jerk、累积运动病剂量（MSDV）都有硬上限。**「物理同意」不是一次性的按钮，而是随机器人动作实时演化的隐状态；「舒适」不是惩罚项，而是可行域的边界。** 当舒适包络不可行时，正确动作是**交还控制/停手**，而不是「用更高收益说服自己继续」。

**灵感 6（跨设备时间 → 耦合分解的前提是亚毫秒级时间对齐）**
直觉：要比较人和机器人的加速度，必须先保证两个时钟说的是同一时刻。1 ms 的时间错位，在 10 m/s² 的快速动作上就是 1 cm/s 的速度误差；在接触瞬间，会制造出根本不存在的力。可穿戴 IMU 与机器人 IMU 各有晶振漂移，蓝牙/WiFi 时间同步还会被延迟攻击。**时间同步不是一个工程细节，而是耦合计量链上的一个可审计分量 u_sync。**

**灵感 7（非马尔可夫核算 → 同一段漂移不能反复「学习」）**
直觉：R72 的 VoI 用熵减衡量信息增益；但若误差相关，后验熵的下降会被高估。系统会以为「我又确认了一次」，其实是「我又看了一眼同一段漂移」。必须用**有效信息** J_eff 替代名义信息 J_nom：白噪声分量可按样本累加，相关分量只能按 n_eff 累加。否则**交互越多，越自信，越危险**——这是一种「信息高利贷」。**相关误差下的反复观测，不是学习，是复读。**

**灵感 8（综合 → 惯性的三重性：记忆、耦合、身体）**
直觉：IMU 同时是：
- **记忆**：误差跨时间相关 → 需要非马尔可夫核算与半衰期；
- **耦合**：人机共享机械通道 → 需要共同模态/相对模态分解与可辨识性审计；
- **身体**：反射/同意/舒适 → 需要 L0 否决与硬约束。
三者都不是「再加一层算法」能解决的，它们共同要求把**安全否决从「证据层」上移到「身体层」**。**当传感器开始测量人的身体时，安全不再是统计问题，而是伦理-物理问题。**

## 1. 形式化定义（增量：定义 366–380）

**定义 366（INERTIA-GAUGE-RAS 总览与五不变式）** INERTIA-GAUGE-RAS = (IMM, ICD, RID, PCC, TSA, NMIA, I-RISK, GAUGE-RAS†/EMBODIED†)。五不变式：
(i) **记忆诚实**：任何惯性证据必须携带 (误差状态后验 e, 协方差 P, 相关时间 τ_corr, 有效样本 n_eff, 信息半衰期 τ_1/2, 同步不确定度 u_sync, 追溯链 τ)；禁止 i.i.d. 假设；
(ii) **耦合诚实**：当人机机械耦合强度 γ > γ_0，禁止把两路 IMU 当独立证据；必须做共同模态/相对模态分解，携带耦合算子 C、条件数 κ_C、耦合不确定度 u_C；
(iii) **反射优先**：人类保护性反射 r_t ≠ calm 是 **L0 非补偿性否决**，优先于任何任务 VoI、意图 z、情感 ψ；从反射发生到机器人力/速受限的延迟必须可证 ≤ δ_L0；
(iv) **时间相干**：跨设备时钟偏差 (δ, ε) 的不确定度 (u_δ, u_ε) 必须进入耦合分解与风险缩放；同步审计失效即禁止耦合证据；
(v) **严格退化**：IMM/ICD/RID/PCC/TSA 任一失效 ⇒ 退化为 R72 或 R68 的保守形态，且风险界单调不减。**惯性层只在「记忆可审计、耦合可辨识、反射可检出、同步可信」时启用。**

**定义 367（惯性误差状态记忆 IMM）** 真实比力/角速度与观测：
y_a(t) = a(t) + b_a(t) + S_a a(t) + M_a a(t) + n_a(t)，
y_g(t) = ω(t) + b_g(t) + S_g ω(t) + M_g ω(t) + n_g(t)，
其中 b 为偏置，S 为尺度因子对角阵，M 为安装/非正交误差，n 为白噪声。偏置动力学 b_{t+1} = b_t + w_t，w_t ~ 𝒩(0, Q_b)（可推广为 Gauss-Markov）。误差状态
e_t = [b_a; b_g; vec(S_a); vec(S_g); vec(M_a); vec(M_g)]，协方差 P_t。
定义误差自相关 ρ_e(τ)，相关时间 τ_corr = ∫_0^∞ max(ρ_e(τ), 0) dτ；在 AR(1) 近似下 ρ = exp(−Δt/τ_corr)。信息半衰期 τ_1/2 = P_0 / q（一维随机游走，q 为扩散系数；首次使方差翻倍的时间）。惯性证据元组
I = (x̂, P, b̂, P_b, τ_corr, n_eff, τ_1/2, u_sync, τ_chain)。
**性质**：证据权重随年龄 Δ 按 w_age = 2^{−Δ/τ_1/2} 衰减；Δ > τ_1/2 且无外部锚点时，该证据进入 **staleness veto**（不得进入风险缩放分母的「精确项」，只能作为保守先验）。

**定义 368（非马尔可夫信息核算 NMIA）** 将误差分解为白噪声分量 e_w（样本间独立）与慢变相关分量 e_c（自相关 ρ）。名义 Fisher 信息 J_nom = J_w + J_c；有效信息
J_eff = J_w + (n_eff/N) J_c = J_w + J_c / κ_info，
其中 N 为窗口样本数，n_eff = N (1−ρ)/(1+ρ)，信息膨胀因子 κ_info = N/n_eff = (1+ρ)/(1−ρ)。**任何后验更新、VoI 计算、风险缩放必须使用 J_eff，不得使用 J_nom。** 定义后验一致性证书：归一化估计误差平方 NEES = eᵀP^{−1}e 应落在 χ²_{d,α/2} 与 χ²_{d,1−α/2} 之间；持续高于上界即**过自信**，触发 I-IVG 降级。相关时间估计必须使用**置信上界 ρ_upper**（而非点估计），以保证 n_eff 是保守下界。

**定义 369（人机惯性耦合分解 ICD）** 设 a_R, a_H 为机器人末端与人体手/腕的真实加速度。耦合观测模型
y_R = (I − C_RH) a_R + C_RH a_H + n_R，
y_H = C_HR a_R + (I − C_HR) a_H + n_H，
其中 C_RH, C_HR 为**传递/柔顺算子**（频带内用标量/矩阵近似，频带外必须声明未建模）。对称标量耦合 c 下：
共同模态 m = (y_R + y_H)/2 = (a_R + a_H)/2 + (n_R+n_H)/2，
相对模态 d = y_R − y_H = (1 − 2c)(a_R − a_H) + (n_R − n_H)。
**可辨识条件**：0 ≤ c < 1/2 − ε_margin。条件数 κ_C = cond([[I−C, C],[C, I−C]])；对称标量情形 κ_C = 1/|1 − 2c|。当 c → 1/2，κ_C → ∞，相对运动信息消失（**共同模态掩蔽**）；当 c > 1/2，相对模态反号（过耦合/坐标错误）。耦合证据元组
C_ev = (Ĉ, b_t(c), γ, κ_C, u_C, u_sync, τ_chain)。
**性质**：κ_C > κ_max 或 u_sync > u_sync_max 时，不得使用差分证据；只能使用单通道证据并**膨胀** u_C。

**定义 370（反射-意图解耦 RID 与 L0 否决）** 人体 IMU 信号分解为三个频带：
- 反射带 B_r：3–20 Hz（startle/brace/flinch），潜伏期 < 200 ms；
- 意图带 B_i：0.2–2 Hz（reach/withdraw/point），潜伏期 > 300 ms；
- 姿态带 B_p：< 0.2 Hz（sway/lean）。
反射隐状态 r_t ∈ {calm, brace, flinch, freeze, startle}；意图隐变量 z_t 沿用 R72（递交/放置/演示/指示/虚晃/其他）。观测模型
y_H = f_r(r_t) + f_i(z_t) + f_p(p_t) + n_t。
L0 否决规则：
**若 P(r_t ≠ calm | y_H, context) > τ_r，则强制进入保护模式（λ ← λ_max，力/速封顶），任何任务 VoI 不得覆盖。**
定义反射检出延迟 δ_r（反射发生到否决置位）与误否决率 FVR。**freeze 是低运动模式，单靠运动学可能漏检；必须结合力/肌电/语音/视觉/上下文，且漏检时进入「不确定保护模式」而非「正常模式」。**

**定义 371（物理同意与舒适包络 PCC）** 物理同意状态 κ_t ∈ {granted, hesitant, withdrawn}，由人体 IMU（僵硬、回避、支撑、冻结）、接触力、语音与上下文推断；转移模型 p(κ_{t+1} | κ_t, a_t^robot, comfort_t)。**withdrawn 是硬否决**；hesitant 触发降速与澄清，不触发任务级优化。
舒适包络（耦合/近身时强制）：
|a_w(t)| ≤ a_max，|j(t)| ≤ j_max，|ω(t)| ≤ ω_max，MSDV(T) = sqrt(∫_0^T a_w²(t) dt) ≤ MSDV_max，
其中 a_w 为 ISO 2631 频率加权加速度（垂向 W_k、水平 W_d），j 为 jerk。**舒适不是成本项，而是动作可行域的边界；不可行时交还控制/停手。**

**定义 372（跨设备时间相干 TSA）** 人体可穿戴 IMU 与机器人 IMU 的时钟关系 t_H = (1+ε) t_R + δ。估计 (ε̂, δ̂) 及其不确定度 (u_ε, u_δ)，并检测同步攻击。耦合分解的时间对齐误差界：
||Δa|| ≤ L_a (u_δ + T_win u_ε) + ||n_R − n_H||，
其中 L_a 为加速度的 Lipschitz 常数，T_win 为窗口长度。**同步可信条件**：u_δ ≤ u_δ_max、u_ε ≤ u_ε_max、且同步残差未触发攻击检测。**同步不确定度 u_sync 必须进入耦合不确定度与风险缩放。**

**定义 373（惯性反作用 VoI：I-VoI）**
VoI^I(g) = c(ψ)·IG_s^eff + η·IG_z^eff + ζ·IG_C^eff − c_reflex_total − γ_f·E[ΔH_future] − ρ_c·E[comfort_excess(g)]，
其中 IG^eff 使用 J_eff（定义 368），IG_C^eff 为对耦合状态 C 的信息增益（对递接/物理引导有用）。约束：
L0 未否决 ∧ κ_t = granted ∧ 舒适包络可行 ∧ IMM/ICD/TSA 审计有效。
**选择 g* = argmax VoI^I s.t. 上述约束；max VoI^I ≤ 0 或无可行 g ⇒ 停止/交还。** 停止证明需在「有效信息非增、每步反作用成本有正下界」下重做（R72 引理 31 的非马尔可夫版本）。

**定义 374（惯性风险缩放 I-RISK）** 定义
u_inertial = sqrt(tr(P_eff))，u_coupling = u_C · κ_C，u_sync = L_a(u_δ + T_win u_ε)。
λ = max( risk_scale(U_ale, U_epi, H_z, u_tac, u_inertial, u_coupling, u_sync),
         λ_floor(U_ale + U_epi + H_z + u_tac + u_inertial + u_coupling + u_sync) )。
**硬覆盖在软缩放之后施加，且不可被 VoI 抵消**：
- 若 L0 否决 ⇒ λ ← λ_max，并强制力/速封顶 S_env；
- 若 κ_t = withdrawn 或舒适不可行 ⇒ λ ← λ_max，并 hold/handback；
- 若锚点覆盖不足 ⇒ J_INERTIA 无效，降级为 R72 并膨胀 u_inertial。
**物理不确定度、意图不确定度、接触不确定度、惯性记忆不确定度、耦合不确定度、同步不确定度同权进入分母；任一维失控都抬高 λ。**

**定义 375（惯性证书 J_INERTIA）**
J_INERTIA = (J_EMB, imm_hash, n_eff_proof, nees_consistency, coupling_hash, κ_C, sync_proof, reflex_latency_proof, comfort_dose, consent_state, anchor_proof, inertial_ver)。
Valid ⇔ Valid(J_EMB) ∧ 记忆审计通过（ρ_upper、n_eff、NEES）∧ 耦合可辨识（κ_C ≤ κ_max、u_sync ≤ u_sync_max）∧ L0 延迟证明有效 ∧ 舒适/同意在包络内 ∧ **锚点覆盖 A(T) ≥ A_min**。
**锚点证明是证书的必要组件：没有外部锚点，惯性证书就是自证。**

**定义 376（惯性威胁模型 AIC-INERTIA）** ℰ_INERTIA = ℰ_EMB × ℰ_imm × ℰ_couple × ℰ_reflex × ℰ_sync：
ℰ_imm = {IMU 重放/注入、偏置漂移投毒、振动/共振注入、温度攻击、尺度因子攻击}；
ℰ_couple = {耦合矩阵投毒（伪造强耦合以抹掉相对运动）、共同模态掩蔽、接触几何误导}；
ℰ_reflex = {反射伪装（伪造 flinch 强制机器人急停）、反射抑制（真实惊跳/冻结被隐藏）、可穿戴拆除/移位、反射分类器对抗样本}；
ℰ_sync = {时钟偏移/漂移攻击、延迟攻击、PTP 欺骗}。
**核心防御原则：单源惯性不定案；耦合分解必须与至少一个独立锚点（力/接触/视觉/已知激励）交叉验证。**

**定义 377（惯性严格退化链）**
- IMM 失效 ⇒ 用最坏情况误差协方差（随机游走上界）+ R72；
- ICD 失效（κ_C 超阈/同步失效/耦合模型不可信）⇒ 禁用差分证据，单通道 + 膨胀 u_C + R72；
- RID 失效或反射不确定 ⇒ 保护模式（力/速封顶）+ R72；**不得回到「正常模式」**；
- PCC 失效（同意不可判/舒适不可行）⇒ hold/handback，保留 R68 硬安全包络；
- TSA 失效 ⇒ 禁用耦合分解 + 保守单通道 + R72；
- 锚点失效 ⇒ J_INERTIA 无效，退回 R72（带膨胀不确定度）；
- 全部失效 ⇒ R68。
**安全侧只增不减：任何退化都保留 R68 的硬安全包络；INERTIA 的风险界 ≤ R72 的风险界。**

**定义 378（惯性指标扩展 I-MIB）** 在 E-MIB 基础上新增：
- **记忆族**：Allan 方差（ARW、bias instability）、τ_corr 估计误差、n_eff/N、NEES 一致性、τ_1/2、激励可观测 Gramian；
- **耦合族**：γ、κ_C、共同模态占比、相对模态 SNR、分解误差、递接检出延迟；
- **反射族**：δ_r、AUROC、FVR、反射-意图混淆率、freeze 漏检率；
- **同步族**：u_δ、u_ε、同步残差、攻击检出率；
- **同意/舒适族**：κ_t 推断准确率、MSDV、峰值 a_w、峰值 jerk、handback 率。
所有指标遵循 R71 定义 332 六元组 (φ,m,u,D,τ,I⊥) 与定义 333 DAG 分层（V/L/G/A）。

**定义 379（惯性 IVG 扩展 I-IVG）** 新增失效条件：
- 记忆：NEES > χ²_upper、n_eff/N < ρ_min、τ_corr 置信区间过宽、激励 Gramian < G_min；
- 耦合：κ_C > κ_max、u_sync > u_sync_max、共同模态占比 > ρ_cm_max；
- 反射：δ_r > δ_L0、FVR > FVR_max、freeze 漏检率 > τ_freeze；
- 同意/舒适：κ_t = withdrawn、MSDV > MSDV_max、峰值 a_w/jerk 超限；
- 锚点：A(T) < A_min 或锚点交叉验证失败。
任一成立 ⇒ 相关证据失效，按定义 377 降级。**时序失效 ⇒ R68；记忆/耦合失效 ⇒ R72；反射失效 ⇒ 保护模式；同意失效 ⇒ hold/handback。**

**定义 380（惯性锚点与激励协议 IAEP）** 为打破「用同一段数据给自己发证书」的循环，定义外部锚点集合
𝒜 = {零速检测（ZUPT）、已知标定动作激励、接触/力-力矩事件、视觉相对位姿、关节编码器运动学约束、语音/交互确认}。
滑动窗口 T 上的锚点覆盖率 A(T) = |{a ∈ 𝒜 : a 在 T 内有效}| / |𝒜|。**证书规则：A(T) ≥ A_min 且至少一个锚点与 IMU 独立（非同一物理通道）。** 激励条件：可观测 Gramian G_exc = Σ_t Φ_tᵀΦ_t ≥ G_min I，其中 Φ_t 为偏置到观测的灵敏度；G_exc < G_min 时偏置不可观，必须保留先验并膨胀 P_b。

# IP-295 IMM：惯性计量记忆（计量域 50Hz；控制域只做 stale 快速检查）
@dataclass
class InertialEvidence:
    x_hat: np.ndarray; P: np.ndarray
    b_hat: np.ndarray; P_b: np.ndarray
    tau_corr: float; rho_upper: float
    n_eff: float; kappa_info: float
    tau_half: float; u_sync: float
    tau_chain: bytes

class InertialMetrologyMemory:
    def __init__(self, err_model, allan_calib, anchor_proto):
        self.em, self.calib, self.anchor = err_model, allan_calib, anchor_proto

    def update(self, imu_seq, anchor_obs):
        dt = imu_seq.dt
        rho, rho_up = self.calib.ar1_upper(imu_seq.residuals)   # 置信上界
        tau_corr = -dt / math.log(max(rho_up, 1e-9))
        N = len(imu_seq); n_eff = N * (1 - rho_up) / (1 + rho_up)
        kappa = N / max(n_eff, 1e-9)
        # 误差状态滤波：偏置/尺度/安装误差 + 外部锚点
        e_post, P_post = self.em.step(imu_seq, anchor_obs)
        # 激励可观测性：静止时偏置不可观 -> 保留先验、膨胀
        G_exc = self.anchor.excitation_gramian(imu_seq)
        if G_exc < self.anchor.G_min:
            P_post = self.anchor.inflate_to_prior(P_post, self.em.P_b_prior)
        tau_half = self.em.half_life(P_post)
        return InertialEvidence(
            x_hat=e_post.x, P=P_post.P, b_hat=e_post.b, P_b=P_post.P_b,
            tau_corr=tau_corr, rho_upper=rho_up, n_eff=n_eff,
            kappa_info=kappa, tau_half=tau_half,
            u_sync=anchor_obs.u_sync, tau_chain=self.calib.tchain)

# IP-296 ICD：人机惯性耦合分解（计量域 50Hz）
class InertialCouplingDecomposition:
    def __init__(self, coupling_prior, kappa_max, u_sync_max):
        self.C0, self.kmax, self.usmax = coupling_prior, kappa_max, u_sync_max

    def decompose(self, yR, yH, sync, anchor):
        if not sync.valid or sync.u_delta > self.usmax:
            return CouplingResult(valid=False, u_coupling=INFLATE,
                                  reason='sync')
        C = self._estimate_C(yR, yH, self.C0, anchor)     # 频带内算子
        T = block([[I - C, C], [C, I - C]])
        kappa = cond(T)
        if kappa > self.kmax:                            # 共同模态掩蔽
            return CouplingResult(valid=False, u_coupling=INFLATE * kappa,
                                  kappa=kappa, reason='unidentifiable')
        aR, aH = solve(T, vstack([yR, yH]))
        m = (yR + yH) / 2; d = yR - yH
        gamma = self._strength(C)
        uC = self._uncertainty(C, kappa, sync.u_delta, sync.u_eps)
        return CouplingResult(valid=True, aR=aR, aH=aH, C=C,
                              common=m, diff=d, gamma=gamma,
                              kappa=kappa, u_coupling=uC,
                              tau_chain=hash_calib(anchor))

# IP-297 RID：反射-意图解耦（控制域快速 veto + 计量域完整解耦）
class ReflexIntentDisentangler:
    def __init__(self, reflex_bank, intent_bank, context_gate, tau_r):
        self.rb, self.ib, self.ctx, self.tau = reflex_bank, intent_bank, context_gate, tau_r

    def fast_veto(self, imu_h, sync):
        # 控制域：高通 3-20Hz + 阈值，无分配、状态静态
        if not sync.valid: return True                  # 同步不可信 -> 保守否决
        r_energy = self.rb.highpass_energy(imu_h)
        return r_energy > self.rb.hard_threshold

    def update(self, imu_h, context):
        b_r = self.rb.posterior(imu_h, context)         # r_t 后验
        b_z = self.ib.posterior(imu_h, context)         # z_t 后验（含频带先验）
        veto = b_r.p_noncalm > self.tau
        return b_r, b_z, veto

# IP-298 PCC：物理同意与舒适包络（控制域标量剂量 + 计量域状态推断）
class PhysicalConsentComfort:
    def __init__(self, consent_model, iso2631, env):
        self.cm, self.w, self.env = consent_model, iso2631, env

    def step(self, kappa_prev, imu_h, imu_r, cmd, dt):
        kappa = self.cm.transition(kappa_prev, imu_h, imu_r, cmd)
        a_w = self.w.weight(cmd.acc)                    # ISO 2631 频率加权
        msdv = math.sqrt(msdv_prev**2 + a_w**2 * dt)
        feasible = (abs(a_w) <= self.env.a_max
                    and abs(cmd.jerk) <= self.env.j_max
                    and msdv <= self.env.msdv_max)
        veto = (kappa == WITHDRAWN) or (not feasible)
        return kappa, msdv, feasible, veto

# IP-299 TSA：跨设备时间同步审计（事件触发）
def sync_audit(tR, tH, contact_events):
    eps, delta, u_eps, u_delta = fit_clock(tR, tH)
    res = clock_residual(tR, tH, eps, delta)
    attack = (res > res_max) or detect_replay(tR, tH, contact_events)
    valid = (u_delta <= U_DELTA_MAX and u_eps <= U_EPS_MAX and not attack)

# IP-300 NMIA：非马尔可夫信息核算 + 后验一致性
def effective_information(J_w, J_c, n_eff, N):
    kappa = N / max(n_eff, 1e-9)
    return J_w + J_c / kappa, kappa

def nees_consistency(err, P, dof, alpha):
    nees = float(err.T @ np.linalg.solve(P, err))
    lo, hi = chi2.ppf(alpha/2, dof), chi2.ppf(1-alpha/2, dof)
    return (lo <= nees <= hi), nees

# IP-301 I-RISK：惯性风险缩放 + 硬覆盖（控制域，无分配）
def inertia_risk_scale(U_ale, U_epi, H_z, u_tac, u_inertial,
                       u_coupling, u_sync, p):
    denom = U_ale + U_epi + H_z + u_tac + u_inertial + u_coupling + u_sync
    lam = max(p.lam_base * (1 + denom / p.lam_scale),
              p.lam_floor * (1 + denom))
    return lam

def apply_hard_overrides(lam, reflex_veto, consent, comfort_ok, p):
    if reflex_veto:
        return p.lam_max, SafetyEnvelope(force=p.f_safe, speed=p.v_safe,
                                         reason='L0_reflex')
    if consent == WITHDRAWN or not comfort_ok:
        return p.lam_max, SafetyEnvelope(hold=True, reason='consent_comfort')
    return lam, SafetyEnvelope()

## 3. 推导（引理 33–38 / 定理 27–32）

**引理 33（AR(1) 惯性误差的有效样本数与信息膨胀）** 设误差慢变分量 e_t 服从 AR(1)：e_t = ρ e_{t−1} + v_t，v_t ~ (0, σ_v²)，Var(e) = σ² = σ_v²/(1−ρ²)。N 个连续样本的样本均值方差为
Var(ē_N) = (σ²/N)[1 + 2Σ_{k=1}^{N−1}(1 − k/N)ρ^k]。
当 N 较大时，Σ_{k≥1}ρ^k = ρ/(1−ρ)，故 Var(ē_N) ≈ (σ²/N)·(1+ρ)/(1−ρ)。因此有效独立样本
n_eff = N (1−ρ)/(1+ρ)，κ_info = N/n_eff = (1+ρ)/(1−ρ)。
取 ρ = exp(−Δt/τ_corr)，小 Δt 时 κ_info ≈ 2τ_corr/Δt，n_eff ≈ T/(2τ_corr)。
**例**：100 Hz、τ_corr = 10 s，则 κ_info ≈ 2000；1 秒 100 个样本对偏置的 n_eff ≈ 0.05。**把 100 个样本当 100 条独立证据，是把信息放大了 2000 倍。** 系：慢变误差的信息必须按 J_c/κ_info 计入；白噪声分量 J_w 才可按 N 累加。R72 的 VoI 与风险分母在惯性证据上必须改用 J_eff。

**引理 34（耦合分解的可辨识性与共同模态掩蔽）** 在定义 369 的对称标量耦合下，观测矩阵 T = [[1−c, c],[c, 1−c]]，特征值为 1 与 1−2c。故
κ_C = 1/|1−2c|；相对模态增益 = 1−2c。
当 c → 1/2，κ_C → ∞，差分信号 d = y_R − y_H 中相对运动项趋近于零，只剩噪声与共同模态；此时「两路一致」不是证据，而是**共同模态掩蔽**。当 c > 1/2，增益反号，说明模型/坐标/安装存在错误，必须拒绝分解。**可辨识域为 0 ≤ c < 1/2 − ε_margin；耦合越强，越不能把两路 IMU 当独立证据。** 系：R72 的「多模态独立融合」在强耦合下会把共同模态重复计数，产生虚假置信。

**引理 35（L0 反射否决的延迟-力上界）** 设机器人名义接触力 F_nom，控制器最大力变化率 \dot F_max，反射检出延迟 δ_r，执行延迟 δ_c，Δ = δ_r + δ_c。在反射发生后、机器人尚未降力前，峰值力满足
F_peak ≤ F_nom + \dot F_max · Δ。
要在人体保护性反射造成伤害前降力，必须
Δ ≤ (F_safe − F_nom)/\dot F_max。
**例**：F_safe − F_nom = 20 N，\dot F_max = 2000 N/s，则 Δ ≤ 10 ms。人类脊髓反射潜伏期约 50–100 ms，因此机器人没有「等人反应」的余量；L0 必须在**人体动作完成之前**由前馈/早期运动学特征触发。系：**L0 的延迟预算不是用户体验指标，而是接触安全定理的硬参数。**

**引理 36（跨设备时间同步误差向耦合分解的传播）** 设人体加速度在窗口内 Lipschitz 常数 L_a，时钟偏差误差 u_δ，频率误差 u_ε，窗口 T_win。则用 t_R 与 t_H 对齐产生的加速度差异误差
||Δa_sync|| ≤ L_a (u_δ + T_win u_ε)。
该误差直接进入相对模态 d，故耦合分解误差 ≥ u_sync。若 u_sync 与相对运动真值同量级，则分解不可辨识。**同步不确定度是计量链上的独立分量，不能当成「网络抖动」忽略。** 系：u_sync 必须进入 I-RISK 分母；同步攻击等价于耦合证据投毒。

**引理 37（惯性偏置的可观测性需要激励）** 线性化观测 y_t = a_t + b + n_t。若 a_t 未知且无约束，则对任意 δ，(a_t + δ, b − δ) 产生同一观测 y_t，b 不可辨识。只有当存在已知运动/零速/接触约束等激励时，才能打破该对称性。定义激励 Gramian G_exc = Σ_t Φ_tᵀΦ_t；当 G_exc < G_min I，偏置后验必须退回先验并膨胀 P_b。
**系**：人站着不动时，IMU 的偏置不可观；「静止」不是信息量低，而是**偏置与真实加速度共线**。这直接解释了为什么 HRI 中的静止场景最容易积累漂移。

**引理 38（舒适包络的向下封闭性与 λ 单调性）** 固定路径下，若将速度/加速度/力按 λ ≥ 1 缩放（更保守），则频率加权加速度 a_w、jerk、MSDV 在标准低通加权假设下非增；因此舒适可行域对「更慢/更软」动作向下封闭。若某动作 a 可行，则任何 λa（λ≥1）仍可行。**故风险缩放只会扩大舒适可行域，不会破坏它；反之，若任务在包络内无可行解，则必须 handback，而不是靠提高收益强行执行。**

**定理 27（记忆审计后验的保守一致性）** 在定义 367–368 下，若相关时间使用置信上界 ρ_upper（从而 n_eff 为保守下界），且误差模型包含偏置随机游走与激励可观测性检查，则后验协方差 P_post 不小于真实相关噪声下的 Cramér-Rao 下界（在模型类内），且 NEES 不会持续高于 χ² 上界。证明：对 AR(1) 正相关，使用 n_eff ≤ N 等价于低估相关分量的 Fisher 信息；Fisher 信息越小，CRLB 越大，故 P_post 保守。若 ρ_upper 覆盖真值，则一致性成立；若 ρ 被低估，NEES 检查会触发 I-IVG。系：**R72 的 i.i.d. 融合在惯性证据上是过自信的；记忆审计把它拉回保守侧。**

**定理 28（耦合感知的风险单调性）** 在记忆审计、耦合审计、同步审计均有效的条件下，INERTIA 的动作集 A_I ⊆ A_R72（因 L0/同意/舒适硬约束），且当耦合可辨识（κ_C ≤ κ_max）时，相对模态提供了 R72 没有的独立信息，使 U_epi 不增。风险界对动作集单调、对不确定度单调，故 R_INERTIA ≤ R_R72；当耦合处于可辨识内点且人体通道提供额外信息时严格更小。**安全单调不减，效率只在「记忆可审计、耦合可辨识、反射可检出」时获益。**

**定理 29（L0 反射优先的物理安全）** 定义策略 π_I：若 L0 否决，则在控制域选择保护动作 a_safe ∈ A_safe（力/速封顶），否则执行任务策略。由引理 35，a_safe 的峰值力超调 ≤ \dot F_max(δ_r+δ_c) ≤ F_safe − F_nom；由定义 374，硬覆盖在软缩放之后施加且不可被 VoI 抵消。因此对任意任务 VoI，π_I 的接触力不超过 F_safe。**反射安全不是优化目标，而是策略空间的投影约束。**

**定理 30（惯性严格包含与退化链）** 在定义 377 下，INERTIA 在 IMM/ICD/RID/PCC/TSA 失效时逐指令退化为 R72 或 R68：记忆失效用最坏协方差，耦合失效用单通道膨胀，反射失效进入保护模式，同意失效 hold/handback，全部失效回 R68。每次退化都以「更大不确定度 + 更小动作集」实现，故风险界单调不减。**新层只在旧层仍可信时叠加；安全侧永远只增不减。**

**定理 31（J_INERTIA 有效性 ⇒ 物理安全，含人的舒适/同意）** 若 J_INERTIA 有效，则：(i) J_EMB 有效 ⇒ R72 的具身风险界成立；(ii) 记忆审计 + NEES 一致 ⇒ 惯性误差在声明界内；(iii) 耦合可辨识 + 同步有效 ⇒ 相对模态与人体运动估计在 u_C 内；(iv) L0 延迟证明 + 硬覆盖 ⇒ 接触力 ≤ F_safe；(v) 舒适/同意包络 ⇒ 人体加速度/jerk/MSDV 与同意状态在安全域内；(vi) 锚点覆盖 A(T) ≥ A_min ⇒ 慢漂移被外部锚点约束。综上，物理执行风险（含对人的伤害、不适与未同意接触）≤ ε_inertia。**证明重量落在「相关性/耦合模型未误设」与「锚点独立且未被投毒」上。**

**定理 32（自证壁垒：无外部锚点时惯性证书不成立）** 设证书统计量 (τ_corr, n_eff, C, u_sync) 仅由同一段惯性流 y_{0:T} 估计，且不使用任何外部锚点。则存在测量误差过程与估计器，使证书的所有审计统计量通过，而真实状态误差超过声明界任意 ε > 0。证明思路：构造慢变偏置 e(t)，其在短窗口内与「真实低频运动 x(t)」不可区分；审计看到的相关性与运动学特征都合法，但长期漂移超出声明界。由于没有外部锚点，x 与 e 的分解不可辨识（引理 37 的全局版本）；对抗者还可注入与合法运动同分布的漂移。**因此 J_INERTIA 必须包含 anchor_proof；锚点覆盖率不足时证书无效。** 系：**「用惯性数据审计惯性数据」在原理上不成立；必须引入独立的物理/几何/接触锚点。**

## 6. 本轮最大风险

**一句话**：INERTIA-GAUGE-RAS 把安全押在「用同一段惯性数据估计出的相关性/耦合/同步模型来给自己发证书」上——**如果 τ_corr、耦合算子 C 与时钟偏差在真实人体/环境中非平稳，或外部锚点稀疏且可被投毒，系统就会一边用「已计入记忆与耦合」的漂亮证书自信漂移，一边把人的保护性反射误读为意图、或漏掉真实的惊跳/冻结；更阴险的是，可穿戴 IMU 成了新的攻击面：伪造反射可让机器人无故急停，抑制反射可让机器人对真实痛苦视而不见——这是「用人的身体信号给人自己发安全证书」的循环。**

次级风险与缓解：
1. **相关性/耦合模型非平稳** → 在线鲁棒估计 + ρ_upper 置信上界 + 滑窗分段 + 锚点交叉验证；模型失配即膨胀 u_inertial/u_coupling，绝不外推。
2. **自证壁垒/锚点投毒** → 强制 anchor_proof；锚点必须跨物理通道（力/视觉/编码器/已知激励）且至少一个独立；SEAL-anchor 隐藏锚点集离线评估；A(T)<A_min 直接拒绝签发 J_INERTIA。
3. **反射漏检（尤其 freeze）** → 单靠运动学不够；融合力/肌电/语音/视觉与上下文；不确定时进入「不确定保护模式」（降速/降力），而不是正常模式。
4. **误否决/过度保守** → 两级响应：低置信异常→减速与澄清；高置信反射→硬否决；加入 hysteresis 与上下文门控，但**硬否决不可被用户设置关闭**。
5. **耦合模型频变/未建模** → 只声明已认证频带；频带外不用于安全决策；用接触事件与力/力矩做频带内校验。
6. **舒适包络不完整** → 补充角速度/角加速度、视觉-前庭冲突代理指标；保留 handback 作为兜底。
7. **同步攻击/可穿戴不合规** → 硬件 PTP/双向测距 + 接触事件对齐 + 信号质量/皮肤接触检测；检测不到同步即禁用耦合证据并降级。
8. **隐私与伦理** → IMU 是行为生物特征；端侧处理、最小化上传、明确同意、可撤回；物理同意状态与数据同意状态分离审计。
9. **证书实时性** → 控制域只写最小片段 (k, λ, reflex, consent, MSDV, WCET)；完整 J_INERTIA 由计量域异步组装，不阻塞控制环。
10. **复杂度爆炸** → |𝒜|≤8、|r|≤5、|C|≤2×2、|Z|≤8；每个 veto 一条可复算证明；复杂度纳入审计指标。

## 2. 形式化定义（要点版）

**定义 366（总览与五不变式）** INERTIA 的五条铁律：记忆诚实、耦合诚实、反射优先、时间相干、严格退化。**惯性层只在「记忆可审计、耦合可辨识、反射可检出、同步可信」时启用。**

**定义 367（惯性误差状态记忆 IMM）** 观测含偏置、尺度、安装误差；偏置随机游走。证据元组 `I=(x̂,P,b̂,P_b,τ_corr,n_eff,τ_1/2,u_sync,τ_chain)`；证据权重 `w_age=2^{−Δ/τ_1/2}`；过期且无锚点 ⇒ staleness veto。**IMU 的第一性原理不是「高频」，而是「高相关」。**

**定义 368（非马尔可夫信息核算 NMIA）** `J_eff=J_w+(n_eff/N)J_c`；`n_eff=N(1−ρ)/(1+ρ)`；`κ_info=N/n_eff`。任何后验/VoI/风险缩放必须用 J_eff。NEES 持续高于 χ² 上界 ⇒ 过自信 ⇒ I-IVG 降级。**相关时间用置信上界，保证 n_eff 是保守下界。**

**定义 369（人机惯性耦合分解 ICD）** 对称标量耦合下：`d=(1−2c)(a_R−a_H)+n`，`κ_C=1/|1−2c|`。可辨识域 `0≤c<1/2−ε`；`c→1/2` 相对运动消失（共同模态掩蔽）；`c>1/2` 模型/坐标错误。`κ_C>κ_max` 或同步失效 ⇒ 禁用差分证据并膨胀 u_C。**强耦合下「两路一致」不是证据。**

**定义 370（反射-意图解耦 RID 与 L0）** 三频带分解；`r_t` 反射隐状态，`z_t` 自愿意图。**L0 规则：`P(r_t≠calm)>τ_r` ⇒ 强制保护模式（λ←λ_max，力/速封顶），任何任务 VoI 不得覆盖。** freeze 低运动、易漏检，必须多模态交叉；漏检时进入「不确定保护模式」而非正常模式。

**定义 371（物理同意与舒适包络 PCC）** `κ_t∈{granted,hesitant,withdrawn}`；withdrawn 硬否决；hesitant 触发降速/澄清。舒适包络 `|a_w|≤a_max, |j|≤j_max, |ω|≤ω_max, MSDV≤MSDV_max`。**舒适不是成本，是可行域边界；不可行即 handback。**

**定义 372（跨设备时间相干 TSA）** `t_H=(1+ε)t_R+δ`；`||Δa_sync||≤L_a(u_δ+T_win u_ε)`。同步可信条件 `u_δ≤u_δ_max ∧ u_ε≤u_ε_max ∧ 无攻击`。**同步不确定度是计量链的独立分量，必须进 λ。**

**定义 373（惯性反作用 VoI：I-VoI）** 用 J_eff 计算物理/意图/耦合信息增益，扣除三层反作用成本、远期损失、舒适超额；约束 L0 未否决、同意 granted、舒适可行、审计有效。**无正收益或无可行 g ⇒ 停止/交还。**

**定义 374（惯性风险缩放 I-RISK）** 六维不确定度 `U_ale+U_epi+H_z+u_tac+u_inertial+u_coupling+u_sync` 同权入分母。**硬覆盖在软缩放之后施加且不可被 VoI 抵消**：L0 ⇒ λ_max + 力/速封顶；withdrawn/舒适不可行 ⇒ hold/handback；锚点不足 ⇒ J_INERTIA 无效并降级。

**定义 375（惯性证书 J_INERTIA）** Valid ⇔ J_EMB 有效 ∧ 记忆审计（ρ_upper/n_eff/NEES）∧ 耦合可辨识（κ_C≤κ_max、u_sync≤u_sync_max）∧ L0 延迟证明 ∧ 舒适/同意在包络内 ∧ **锚点覆盖 A(T)≥A_min**。**没有 anchor_proof，惯性证书就是自证。**

**定义 376（惯性威胁模型 AIC-INERTIA）** `ℰ_INERTIA=ℰ_EMB×ℰ_imm×ℰ_couple×ℰ_reflex×ℰ_sync`：IMU 重放/注入/偏置投毒、振动共振、耦合矩阵投毒、共同模态掩蔽、反射伪装/抑制、可穿戴拆除/移位、时钟欺骗/延迟攻击。**防御原则：单源惯性不定案，耦合必须与独立锚点交叉验证。**

**定义 377（惯性严格退化链）** IMM 失效→最坏协方差+R72；ICD 失效→单通道+膨胀+R72；RID 失效/不确定→保护模式+R72；PCC 失效→hold/handback+R68 包络；TSA 失效→禁用耦合+R72；锚点失效→J_INERTIA 无效→R72；全失效→R68。**安全侧只增不减。**

**定义 378（惯性指标扩展 I-MIB）** 记忆族（Allan/τ_corr 误差/n_eff/NEES/τ_1/2/激励 Gramian）、耦合族（γ/κ_C/共同模态占比/相对模态 SNR/递接延迟）、反射族（δ_r/AUROC/FVR/混淆率/freeze 漏检）、同步族（u_δ/u_ε/残差/攻击检出）、同意舒适族（κ_t 准确率/MSDV/峰值 a_w/jerk/handback 率）。同遵循定义 332 六元组与定义 333 DAG。

**定义 379（惯性 IVG 扩展 I-IVG）** 新增失效：NEES 超界、n_eff/N 过低、τ_corr 区间过宽、激励 Gramian 不足、κ_C 超阈、u_sync 超阈、共同模态占比过高、δ_r 超限、FVR/freeze 漏检超限、withdrawn、MSDV/a_w/jerk 超限、A(T)<A_min。**时序失效→R68；记忆/耦合→R72；反射→保护模式；同意→hold/handback。**

**定义 380（惯性锚点与激励协议 IAEP）** 锚点集 `𝒜={ZUPT, 已知标定激励, 接触/力事件, 视觉相对位姿, 编码器约束, 语音确认}`；覆盖率 `A(T)`；激励 Gramian `G_exc=ΣΦ_tᵀΦ_t`。**证书要求 A(T)≥A_min 且至少一个锚点与 IMU 独立（非同一物理通道）。** 这是打破自证壁垒的制度性组件。

class InertialMetrologyMemory:
    def update(self, imu_seq, anchor_obs):
        dt = imu_seq.dt
        rho, rho_up = self.calib.ar1_upper(imu_seq.residuals)   # 置信上界
        tau_corr = -dt / math.log(max(rho_up, 1e-9))
        N = len(imu_seq); n_eff = N * (1 - rho_up) / (1 + rho_up)
        kappa = N / max(n_eff, 1e-9)
        e_post, P_post = self.em.step(imu_seq, anchor_obs)      # 偏置/尺度/安装
        G_exc = self.anchor.excitation_gramian(imu_seq)         # 激励可观测性
        if G_exc < self.anchor.G_min:
            P_post = self.anchor.inflate_to_prior(P_post, self.em.P_b_prior)
        return InertialEvidence(x_hat=e_post.x, P=P_post.P,
            b_hat=e_post.b, P_b=P_post.P_b, tau_corr=tau_corr,
            rho_upper=rho_up, n_eff=n_eff, kappa_info=kappa,
            tau_half=self.em.half_life(P_post),

            return CouplingResult(valid=False, u_coupling=INFLATE, reason='sync')
        C = self._estimate_C(yR, yH, self.C0, anchor)

        kappa = cond(T)
        if kappa > self.kmax:                    # 共同模态掩蔽
            return CouplingResult(valid=False, u_coupling=INFLATE*kappa,
                                  kappa=kappa, reason='unidentifiable')
        aR, aH = solve(T, vstack([yR, yH]))
        m = (yR + yH) / 2; d = yR - yH
        return CouplingResult(valid=True, aR=aR, aH=aH, C=C,
            common=m, diff=d, gamma=self._strength(C), kappa=kappa,
            u_coupling=self._uncertainty(C, kappa, sync.u_delta, sync.u_eps),
            tau_chain=hash_calib(anchor))

def nees_consistency(err, P, dof, alpha):
    nees = float(err.T @ np.linalg.solve(P, err))
    lo, hi = chi2.ppf(alpha/2, dof), chi2.ppf(1-alpha/2, dof)
    return (lo <= nees <= hi), nees

## 4. 推导（引理 33–38 / 定理 27–32）

**引理 33（AR(1) 有效样本数与信息膨胀）** 对 e_t=ρe_{t−1}+v_t，N 个样本均值的方差 `Var(ē)≈(σ²/N)(1+ρ)/(1−ρ)`，故 `n_eff=N(1−ρ)/(1+ρ)`，`κ_info=(1+ρ)/(1−ρ)`。取 `ρ=e^{−Δt/τ_corr}`，小 Δt 时 `κ_info≈2τ_corr/Δt`，`n_eff≈T/(2τ_corr)`。**例**：100 Hz、τ_corr=10 s ⇒ κ_info≈2000；1 秒 100 样本对偏置的 n_eff≈0.05。**把 100 个样本当 100 条独立证据，是把信息放大约 2000 倍。** 系：慢变分量按 J_c/κ_info 计入，白噪分量 J_w 才按 N 累加。

**引理 34（耦合可辨识性与共同模态掩蔽）** 对称标量耦合下 `T=[[1−c,c],[c,1−c]]`，特征值 1 与 1−2c，故 `κ_C=1/|1−2c|`，相对模态增益 1−2c。`c→1/2` 时 κ_C→∞，差分信号中相对运动消失，只剩共同模态与噪声；`c>1/2` 增益反号说明模型/坐标错误。**可辨识域 0≤c<1/2−ε；强耦合下两路一致不是证据，而是共同模态掩蔽。**

**引理 35（L0 延迟-力上界）** `F_peak≤F_nom+\dot F_max(δ_r+δ_c)`；要求 `δ_r+δ_c≤(F_safe−F_nom)/\dot F_max`。例：20 N 余量、2000 N/s ⇒ Δ≤10 ms。人类脊髓反射 50–100 ms，故机器人不能「等人反应」；L0 必须由前馈/早期特征触发。**L0 延迟预算是接触安全定理的硬参数，不是体验指标。**

**引理 36（同步误差传播）** `||Δa_sync||≤L_a(u_δ+T_win u_ε)`，直接进入相对模态 d；若与相对运动同量级则分解不可辨识。**u_sync 必须进入 I-RISK 分母；同步攻击等价于耦合证据投毒。**

**引理 37（偏置可观测性需要激励）** 无约束下 `(a+b)` 对 `(a+δ,b−δ)` 不变，偏置不可辨识；需 ZUPT/已知激励/接触约束打破对称。`G_exc=ΣΦ_tᵀΦ_t<G_min I` 时保留先验并膨胀 P_b。**静止不是信息量低，是偏置与真实加速度共线。**

**引理 38（舒适包络向下封闭）** 固定路径下按 λ≥1 缩放速度/加速度/力，a_w、jerk、MSDV 在标准低通加权假设下非增；故舒适可行域对更慢/更软动作向下封闭。**风险缩放只会扩大可行域；若包络内无可行解，必须 handback。**

**定理 27（记忆审计后验的保守一致性）** 若用 ρ_upper 使 n_eff 为保守下界，且误差模型含偏置随机游走与激励检查，则 P_post 不小于模型类内相关噪声的 CRLB，NEES 不持续超 χ² 上界。证明：AR(1) 正相关下低估相关分量的 Fisher 信息 ⇒ CRLB 变大 ⇒ 协方差保守；若 ρ 被低估，NEES 触发 I-IVG。**R72 的 i.i.d. 融合在惯性证据上过自信；记忆审计把它拉回保守侧。**

**定理 28（耦合感知风险单调性）** 审计有效时 `A_I⊆A_R72`（L0/同意/舒适硬约束），且耦合可辨识时相对模态提供额外独立信息 ⇒ U_epi 不增。风险对动作集与不确定度单调 ⇒ `R_INERTIA≤R_R72`，可辨识内点严格更小。**安全单调不减，效率只在记忆/耦合/反射可信时获益。**

**定理 29（L0 反射优先的物理安全）** 否决时选保护动作 `a_safe∈A_safe`；由引理 35 峰值力 ≤F_safe；硬覆盖在软缩放后施加且不可被 VoI 抵消。故任意任务 VoI 下接触力 ≤F_safe。**反射安全是策略空间的投影约束，不是优化目标。**

**定理 30（惯性严格包含与退化链）** 按定义 377，各失效逐指令退化为 R72/R68/保护模式；每次退化都以「更大不确定度 + 更小动作集」实现，风险界单调不减。**新层只在旧层仍可信时叠加。**

**定理 31（J_INERTIA 有效性 ⇒ 物理安全）** J_INERTIA 有效 ⇒ J_EMB 有效（R72 风险界）+ 记忆一致（误差在声明界内）+ 耦合/同步有效（相对运动在 u_C 内）+ L0 延迟与硬覆盖（力 ≤F_safe）+ 舒适/同意包络 + 锚点覆盖（慢漂移受约束）。故物理执行风险（含伤害、不适、未同意接触）≤ε_inertia。**证明重量在「模型未误设」与「锚点独立未投毒」。**

**定理 32（自证壁垒）** 若证书统计量仅由同一段惯性流估计且无外部锚点，则存在误差过程与估计器使所有审计通过而真实误差超界任意 ε>0。构造：慢变偏置在短窗口内与真实低频运动不可区分；审计统计合法，长期漂移超界；无锚点则 x 与 e 不可分解（引理 37 的全局版），对抗者还可注入同分布漂移。**故 J_INERTIA 必须含 anchor_proof；锚点不足即证书无效。系：用惯性数据审计惯性数据在原理上不成立。**

## 7. 本轮最大风险

**一句话**：INERTIA-GAUGE-RAS 把安全押在「用同一段惯性数据估计出的相关性/耦合/同步模型来给自己发证书」上——**如果 τ_corr、耦合算子 C 与时钟偏差在真实人体/环境中非平稳，或外部锚点稀疏且可被投毒，系统就会一边用「已计入记忆与耦合」的漂亮证书自信漂移，一边把人的保护性反射误读为意图、或漏掉真实的惊跳/冻结；更阴险的是，可穿戴 IMU 成了新的攻击面：伪造反射可让机器人无故急停，抑制反射可让机器人对真实痛苦视而不见——这是「用人的身体信号给人自己发安全证书」的循环。**

次级风险与缓解：
1. **模型非平稳** → 在线鲁棒估计 + ρ_upper 置信上界 + 滑窗分段 + 锚点交叉验证；失配即膨胀 u_inertial/u_coupling。
2. **自证壁垒/锚点投毒** → 强制 anchor_proof；锚点跨物理通道且至少一个独立；SEAL-anchor 隐藏集；A(T)<A_min 拒绝签发。
3. **反射漏检（freeze）** → 多模态（力/肌电/语音/视觉/上下文）；不确定时进入「不确定保护模式」。
4. **误否决** → 两级响应：低置信→减速/澄清；高置信→硬否决；hysteresis + 上下文门控；**硬否决不可被关闭**。
5. **耦合频变/未建模** → 只声明认证频带；频带外不用于安全决策；力/力矩与接触事件校验。
6. **舒适包络不完整** → 补角速度/角加速度与视觉-前庭冲突代理；保留 handback。
7. **同步攻击/可穿戴不合规** → 硬件 PTP/双向测距 + 接触事件对齐 + 信号质量检测；同步不可信即禁用耦合证据。
8. **隐私与伦理** → IMU 是行为生物特征；端侧处理、最小化上传、明确同意、可撤回；物理同意与数据同意分离审计。
9. **证书实时性** → 控制域只写最小片段 (k, λ, reflex, consent, MSDV, WCET)；完整 J_INERTIA 异步组装。
10. **复杂度爆炸** → |𝒜|≤8、|r|≤5、|C|≤2×2、|Z|≤8；每个 veto 一条可复算证明；复杂度纳入审计指标。
