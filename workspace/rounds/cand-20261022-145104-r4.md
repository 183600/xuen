# 想法区 · 第 4 轮（本循环）：从 X-DUB/AG* 到 X-DUB/PCB

**灵感词**：指称语义 / 回溯法 / 蚁群算法  
**起点**：v0.5「X-DUB/AG*」。它有 A* 一致的路径最大下界、focal + 贪心 guide、THRESH、DOM-GEN、证明 DAG。本轮不推翻这些定理，而是先做一次**语义审计**：v0.5 的证书到底在证什么？审计的结论把设计带到另一个方向——**瓶颈不在搜索，在原始解**。

## 一句话直觉：先把“状态指称什么”算清楚，再让回溯去拿原始解、让蚁群把原始解做小，最后用一张局部可查的证明 DAG 收尾

v0.5 把“泛化”理解成“在状态空间上划更大的证书区域”。我先问一个更基础的问题：一个状态对未来到底指称什么？答案是接口

```text
ι = (R, r, A)
R : 剩余任务（优先约束的上闭集）
r : 剩余任务的释放下界，r_i = max{ c_j : j∈pred(i)∩S }（无前驱则为 0）
A : 机器可用时间（排序后的向量）
```

任务完成时间向量 `c` 是**历史**，不是指称：只要 `c_j` 不是任何剩余任务的前驱，它就永远不会再被用到。于是 `(S,A,c)` 的树可以商成接口的 DAG，搜索对象小了一个数量级（微基准：n=7–8 无剪枝时，c-状态数是接口数的 5.0 倍）。

但真正让我改主意的不是这个商，而是实验里的一个刺眼数字：**30 个“困难”实例中，29 个的根界核在 `H=OPT-1` 上已经能证 OPT**。也就是说，只要有人把 `U` 压到 OPT，证明通常是一行的事；搜索之所以“困难”，是因为它不知道 OPT，只能靠展开去把最后一格补上。**v0.5 把力气花在证明侧，而这批实例的瓶颈在原始解侧。**

三个灵感词因此各就各位：

- **指称语义**：给出接口、指称函数 `D`、Bellman 泛函的 greatest fixed point，以及一条**冗余性定理**——在单调界核下，绝对的状态区域证书不增加任何剪枝。这解释了为什么我最初做的“证书前沿”几乎不省节点。
- **回溯法**：不是“换个展开顺序”，而是**先下潜拿可行解**。DFS 的第一条下降路径在 ≤n 步内到达一个 terminal，立刻把 `U` 压下来；强界核随后把剩下的 DAG 剪掉。best-first 先展开浅层低 f 节点，反而迟迟到不了 terminal。实测同一 primal 下 DFS 比 best-first 少 3–7 倍节点。
- **蚁群算法**：不再当 guide（v0.5 的 guide 消融只有 ~5%，本循环此前的一个候选（X-DUB/ACO-D）的 ACO guide 也失败），而是当 **primal**：在接口商上做 rank-based 构造，把 `U0` 的间隙和从贪心的 47 拉到 22，13/30 直接命中 OPT。`U0` 一进界核 `H=U0-1`，搜索立刻塌缩。

## 1. 语义审计：`c` 是历史，`r` 才是指称

取一个最小例子。`m=2`，已调度 `S={1,2}`，`c_1=3, c_2=7`，机器 `A=(7,3)`。剩余任务 3 的前驱是 1，任务 4 的前驱是 2。未来只看见 `r_3=3, r_4=7`；`c_1=3` 与 `c_2=7` 的具体分配、甚至哪台机器先空出来，都不再影响剩余问题（机器同构）。若另一条路径达到 `c_1=3,c_2=7` 但机器标签互换，接口完全相同。

这不是“近似”，是**双模拟**：两个状态只要有相同接口，它们的可行完成集合逐点相同，因此 `OPT` 相同。

**定义 1（接口与转移）**。对状态 `σ=(S,A,c)`，令 `R=V\S`，`r_i=max({c_j:j∈pred(i)∩S}∪{0})`，`ι(σ)=(R,r,sort(A))`。对就绪任务 `i`（`pred(i)∩R=∅`）和机器 `k`：

```text
t = max(A_k, r_i)
A'_k = t + p_i,  其余 A'_j = A_j,  最后 sort(A')
r'_j = max(r_j, t+p_i)  对 j∈succ(i)∩(R\{i})，其余 r'_j = r_j
R' = R\{i}
```

**命题 1（接口充分性）**：`ι(σ)=ι(τ) ⇒ OPT(σ)=OPT(τ)`，且两状态的可行完成 makespan 集合相同。证明对 `|R|` 归纳：完成的第一步必是某个就绪任务在最早可用时刻开工；转移只依赖 `(R,r,A)`，归纳假设给出剩余部分相同。

这条命题的直接后果是：**搜索状态可以只存 `(R,r,A)`**，不必存 `c`。v0.5 的状态合并键 `(S,sort(A),c)` 是这个商的一个细化；细化会丢掉本可以合并的等价状态。

## 2. 指称函数与它的三个性质

**定义 2（指称）**：`D(ι)` 是从接口 `ι` 出发完成所有剩余任务的最小绝对 makespan。

**引理 1（单调性）**：定义硬度序 `ι ⪯ ι'` 为 `R⊆R'`、`r_i≤r'_i (i∈R)`、`A≤A'`（逐分量）、且 `R'` 上的优先约束限制在 `R` 上包含原约束。则 `D(ι) ≤ D(ι')`。

证明：把 `ι'` 的任一可行完成限制到 `R`，得到 `ι` 的可行完成，makespan 不变或更小。

注意这个序与搜索深度**反相关**：越深，`R` 越小（更容易），但 `r,A` 越大（更难）。这解释了后文的一个负结果：绝对区域证书的“上集”方向与搜索树的生长方向横切，覆盖到的已访问状态极少（实测每个闭节点最多覆盖 3 个其它节点）。

**引理 2（Bellman）**：`D(ι)=max(max A, min_{a∈Act(ι)} D(ι_a))`（`R=∅` 时 `D=max A`）。

**定理 1（greatest fixed point）**：令 `T(φ)(ι)=max(max A, min_a φ(ι_a))`。`T` 在逐点序上单调；`D` 是 `T` 的最大不动点；任意 post-fixed point `φ≤T(φ)` 都是可采纳下界。

证明：对 `|R|` 良基归纳。`R=∅` 时 `φ(ι)≤T(φ)(ι)=max A=D(ι)`。否则
`φ(ι) ≤ max(max A, min_a φ(ι_a)) ≤ max(D(ι), min_a D(ι_a)) = D(ι)`。
`D` 本身满足等式，故是最大不动点。证毕。

这个定理给的是**证书代数**：可采纳下界对逐点 max 封闭（`T` 单调），所以“把多张证书取 max”永远是安全的。v0.5 的 `L_X5=max(...)` 是这个代数的一个特例。

## 3. 一个让我停下手术刀的负结果：绝对区域证书是冗余的

我最初的设计是 v0.5 的自然延续：把每条局部证书泛化成一个**状态区域**

```text
β = (ι0, h),   Reg(β) = { ι : ι ⪰ ι0 },   含义：∀ι∈Reg(β), D(ι) ≥ h
```

一张证书覆盖一个上集，理论上可以跨分支复用。我实现了它，跑了 30 个实例，结果是：**前沿命中 801 次，节点数从 2,255 变成 2,304（略差）**。命中很多，但全是“本来就会被局部界核剪掉”的节点。

**定理 2（绝对区域证书的冗余性）**：设 `λ` 是可采纳下界，且对硬度序单调。若 `h ≤ λ(ι0)`，则对任意 `ι ⪰ ι0` 有 `λ(ι) ≥ λ(ι0) ≥ h`。因此，若搜索已经用 `λ(ι) ≥ U` 剪枝，则 `β` 不能剪掉任何 `λ` 剪不掉的节点。

证明：单调性一步。

这条定理的边界很重要，它只杀**绝对的状态区域证书**：

- v0.5 的 `CERT-REGION` 与 `DOM-GEN` 的绝对值部分被覆盖；
- **THRESH 不被覆盖**：它是在*同一个状态*上对目标 `H` 做更强的求值（二分 vs 单点），不是把证书搬到别的状态；
- **相对支配不被覆盖**：`σ⪯τ` 时剪掉 `τ` 不需要 `λ(σ)≥U`，只需要 `σ` 还在前沿/已闭合。实测 best-first 加 DOM 从 58,077 降到 17,298（−70%），这是真收益；
- **路径最大 `F` 不被覆盖**：`F` 不是接口的函数，它可以严格大于 `λ(ι0)`；这也正是它无法进入接口记忆的原因。

所以本轮的结论不是“v0.5 的证书没用”，而是：**在单调界核下，把证书在状态空间上“摊大”没有边际收益；真正非冗余的泛化只有两种——相对支配，和精确子问题值的记忆化。** 前者 v0.5 已经做了；后者是接口 DAG 搜索。

## 4. 回溯法：先拿原始解，再证

DFS 的第一条下降路径在 ≤n 步内到达 terminal，立刻得到一个可行 `U`；随后每个节点先算 `λ(ι,U)`，`λ≥U` 就一行闭合。best-first 按 `f` 展开，浅层低 `f` 节点优先，反而要很久才碰到 terminal。同一 primal 下：

```text
30 个困难实例：best-first 17,298 节点；接口记忆 DFS 2,255 节点（7.7×）
```

DFS 还自带一个 v0.5 没有的东西：**记忆化**。接口是规范状态，`(R,r,A)` 只解一次；`memo` 把树变成 DAG。消融：关掉 memo 是 4,666 节点，开是 2,255（2.1×）。

证明结构也顺势变成 DAG：每个闭合节点一条 `LOCAL`（局部界核）或 `CLOSE`（动作覆盖：`D(ι)≥min_a D(ι_a)`）；terminal 存动作路径。checker 只做局部重算，30/30 通过。

## 5. 蚁群：第三次尝试，但这次换角色

前两轮的教训很清楚：guide 不是瓶颈（v0.5 的 guide 消融只有 ~5%，本循环此前的 ACO-D 候选的 guide 也失败）。本轮把 ACO 放在 **primal** 位置：

```text
在接口商上构造：状态键 (R, A)，动作 (i,k) 上的信息素 τ
rank-based 沉积 + 蒸发；返回最好路径与 U_ACO
U0 = min(U_greedy, U_ACO)
```

`U0` 直接进入界核 `H=U0-1`。在 30 个实例上，4 迭代 × 6 蚂蚁（30 实例总计约 34–40 ms）把初始间隙和从贪心的 47 降到 22（1×3 就已经到 36），13/30 直接命中 OPT；搜索节点从 2,255 降到 1,316（−42%）。预算消融（1×3 → 20×12）显示间隙 36→32→22→8→3（贪心是 47），收益递减但单调。

代价也要说清楚：ACO 不是免费的。10×8 要 113 ms，20×12 要 336 ms；在小实例上它可能比搜索本身还贵。本轮的取舍是 4×6，约 0.04 s，换来 939 个节点。

## 6. 真正的“困难”在哪：根界核诊断

30 个实例上，把 `U` 设成 OPT 再跑 best-first，只需要 **39** 个节点；把 `U` 设成贪心，需要 17,298。把 `U` 设成 ACO 的 U0，需要 3,883。也就是说：

```text
节点数 ≈ 原始解间隙的函数；搜索结构是二阶项。
```

这个诊断很重要，也很危险：它说明这批“困难实例”是**原始解困难**，不是**证明困难**。如果下一轮换到根界核本身不够紧的实例（precedence-heavy、大 n），搜索结构会重新变成一阶项。本轮不把“ACO 万能”写进结论。

## 7. 核心方案：X-DUB/PCB

**Primal-Certified Backtracking（原始解认证回溯）**，在 v0.5 上做四处增量：

1. **DENOT-IFACE**：状态改为接口 `(R,r,A)`；转移如定义 1；证明接口是双模拟商（命题 1）。
2. **IDB（接口记忆回溯）**：DFS + 精确 memo；`λ(ι,U)` 先剪，`CLOSE` 动作覆盖；证明树变 DAG。
3. **ACO-PRIMAL**：接口商上的 rank-based 蚁群，只产出 `U0` 和可行路径；guide 可选、默认关。
4. **PROOF-CHECK**：`TERMINAL/LOCAL/CLOSE` 三种局部规则；checker 重算 `λ`、动作覆盖与区域成员，不信任搜索顺序、memo、ACO。

保留 v0.5 的 `L0 + AVAIL` 界核、贪心组合、DOM（相对支配）与证明 DAG 思想；替换的是“路径最大 `F` + 区域证书”这一层。

## 8. 本轮要验证的命题

1. **接口充分**：`(R,r,A)` 是未来可行完成集合的充分统计量；接口 DAG 的节点数 ≤ c-状态 DAG。
2. **gfp**：`D` 是 Bellman 泛函的最大不动点；post-fixed point 可采纳。
3. **冗余性**：单调界核下，绝对状态区域证书不增加剪枝；实测前沿命中 801 次但节点 +2%。
4. **记忆正确**：memo 只存已完全探索节点的精确值/合法下界；终止即 `U=OPT`。
5. **原始解主导**：同一搜索下，`U0` 从贪心到 ACO 到 OPT，节点数应单调下降；根界核诊断给出上界。
6. **回溯优于 best-first**：同一 `U0` 下，接口记忆 DFS 的展开数应显著低于 best-first。
7. **checker 可靠**：30/30 证明通过；无假证书。
8. **边界**：接口商不保证比 c-key 记忆更少节点（实测反而多 ~12%）；ACO 不是万能 primal。

## 9. 初步结果（30 个 n=9–10、m=2 困难实例）

| 变体 | primal | 搜索 | 总展开 | 墙钟 |
|---|---|---|---:|---:|
| v0.5 风格 | 贪心 | best-first + DOM + inherit | 17,298 | 1.63 s |
| BF-ACO | ACO 4×6 | 同上 | 3,883 | 0.40 s（含 ACO） |
| IDB | 贪心 | 接口记忆 DFS | 2,255 | 0.32 s |
| **IDB-ACO** | ACO 4×6 | 接口记忆 DFS | **1,316** | **0.24 s** |
| BF-oracle | OPT | best-first | 39 | — |
| IDB-oracle | OPT | 接口记忆 DFS | 170 | — |

- 消融：关 DOM 58,077；关 inherit 15,734（继承在这批实例上不赚）；加区域前沿 2,304；换 c-key 2,018；关 memo 4,666。
- ACO：13/30 在 U0 命中 OPT；初始间隙和 22（贪心 47）；预算 1×3/2×4/4×6/10×8/20×12 的间隙和 36/32/22/8/3。
- anytime：25 节点时 BF 平均间隙 1.567，IDB 0.467；100 节点时 1.567 vs 0.033。
- checker：30/30 通过；证明 DAG 共 1,316 个节点，最大 141。
- 失败案例：2/30 上 IDB 比 BF 差（65→153，58→101），都是 BF 本来就很容易的实例。

## 10. 我知道的边界

- 只做了 m=2、n≤10、随机 DAG；没有 PSPLIB、没有 m>2 精确装箱、没有 n≥15 的 anytime。
- 30 个实例是按“best-first ≥40 节点”筛的，天然偏向原始解困难；根界核诊断只在这批实例上成立，不能外推。
- 接口商在理论上更粗，但实测比 c-key 记忆多 ~12% 节点；原因可能是商合并改变了 DFS 的原始解到达顺序（合并跳过了某些“先撞到好 terminal”的冗余路径）。这是一个诚实的反例，不是手误。
- ACO 的 34–40 ms 在小 n 上相对搜索并不便宜；n 大时它的相对成本才会下降。
- checker 只验证到界核层；如果 `L0/AVAIL` 实现有 bug，checker 会一起错。checker 的独立性是“相对搜索器”的，不是“相对界核数学”的。

## 本轮的一句话最大风险

**当前方案最大的风险是：本轮把 v0.5 的“困难实例”重新解释成“原始解困难”而不是“证明困难”（29/30 在已知 OPT 时根界核一步闭合），于是 ACO 的收益可能只是补上这批实例的最后一格；在根界核本身不够紧、真正需要搜索的大实例上，接口商反而比 c-key 记忆多约 12% 的节点，本轮的核心卖点（指称状态）还没有被证明是搜索效率的来源。**

# 产物区 · v0.6：X-DUB/PCB

> **Primal-Certified Backtracking**（原始解认证回溯）  
> 中文名：指称接口 + 接口记忆回溯 + 蚁群原始解 + 证明 DAG  
> 状态：完整设计稿；30 个 n=9–10、m=2 困难随机 DAG 上的 2×2 消融、ACO 预算、根界核诊断、30/30 独立 checker 已验证。m>2、PSPLIB、n≥15 留到下一轮。

## 0. 版本关系与本轮增量

v0.5（X-DUB/AG\*）已经建立：

- `P|prec|Cmax` 的 `(任务,机器)` 动作空间与最优性覆盖；
- 一致 A\* 的路径最大下界 `F`、focal search、`f=max(C,F)`；
- `L0 + AVAIL` 打包核、THRESH 阈值证书；
- 同 `S` 的 `DOM-GEN` 相对支配；
- 证明树/DAG 的局部检查思想。

v0.6 **不推翻** 这些定理，但替换其中一层，并给出一个负结果来界定它：

1. **DENOT-IFACE**：搜索状态从 `(S,A,c)` 换成**接口** `ι=(R,r,A)`；证明接口是未来可行完成集合的**双模拟商**（命题 1）。`c` 是历史，`r` 才是指称。
2. **REDUNDANCY**：证明在单调界核下，**绝对的状态区域证书**（v0.5 的 `CERT-REGION`/`DOM-GEN` 绝对值部分）不增加任何剪枝（定理 2）。这把“泛化”的努力从“划更大的区域”转到“精确记忆”。
3. **IDB**：接口上的记忆化回溯。DFS 先下潜拿原始解，再用界核剪枝；`memo` 把树变成 DAG；闭合节点用 `LOCAL` 或 `CLOSE`（动作覆盖）证明。
4. **ACO-PRIMAL**：蚁群在接口商上构造可行调度，**只当 primal**（不当 guide），把 `U0` 拉近 OPT；`U0` 进入界核 `H=U0-1`。
5. **PROOF-CHECK**：独立 checker 验证 `TERMINAL/LOCAL/CLOSE` 三种局部规则；30/30 通过。

关系：

```text
关闭 ACO、memo、IDB 顺序      → v0.5 风格的 best-first + DOM + inherit
只开接口 + memo               → 记忆化 DAG 搜索（无 primal 提升）
只开 ACO                      → 更好的 U0，搜索骨架不变
全部打开                      → X-DUB/PCB
```

组合下界与界核：

```text
λ(ι,U) = max( L0(ι), AVAIL(ι,U-1) )          # 本轮不启用对偶，隔离变量
D(ι)   = max( max A, min_{a∈Act(ι)} D(ι_a) )  # Bellman
X-DUB/PCB 用 λ 剪枝，用 ACO 给 U0，用 memo 复用精确子问题值。
```

## 1. 问题、符号与复用的旧结论

### 1.1 形式化问题

```text
P | prec | Cmax
```

给定任务集 `V={1,...,n}`、工时 `p_i∈Z_{≥1}`、优先约束 `E⊆V×V`（DAG）、同构机器数 `m`。调度由开始时间 `s_i` 与机器 `μ_i` 组成，满足：

```text
(i,j) ∈ E  ⇒  s_j ≥ s_i + p_i
μ_i = μ_j  ⇒  [s_i, s_i+p_i) 与 [s_j, s_j+p_j) 不重叠
```

目标 `Cmax=max_i(s_i+p_i)` 最小，最优值记 `OPT`。任务按拓扑序编号（边只从低到高），因此 `0..n-1` 即拓扑序。

### 1.2 符号表

### 1.3 复用的 v0.5 结论

- **动作覆盖性**：任意完成的第一步是某个就绪任务 `i` 在 `t=max(A_k,r_i)` 开工；从根出发的某条动作序列可达最优调度。
- **`L0` 可采纳**：`est_i` 是含已调度前驱与剩余前驱链的最早开始，`q_i` 是剩余 tail；`L0≤D`。
- **AVAIL 可采纳**：固定截止期 `H`，窗口 `[a,b)` 的强制集
  `X={i∈R: est_i≥a, H-q_i≤b}` 必须装进容量
  `caps_k=max(0,b-max(a,A_k))`；若 2-bin 装箱不可行，则不存在 `≤H` 的完成。
- **相对支配**：同 `R` 下，`r'≤r` 且 `A'≤A` 的状态支配更大的状态；被支配者可以剪掉，只要支配者已闭合或仍在搜索中。
- **贪心组合**：CP/LPT/MWKR 三条表调度规则给出可行上界。

v0.6 只替换“状态、记忆、原始解”三处；界核与动作空间不变。

## 2. 动机：一次语义审计与一个刺眼的诊断

### 2.1 缺口一：v0.5 的状态不是规范状态

v0.5 用 `(S,sort(A),c)` 做 transposition，用 `c` 的逐分量比较做支配。但 `c` 里的很多分量对未来没有影响：只要一个已完成任务不是任何剩余任务的前驱，它的完成时间就再也不会被读到。于是同一“剩余问题”会被拆成许多不同的 `c` 向量，重复搜索。

**例 A**：`m=2`，`S={1,2}`，`pred(3)={1}`，`pred(4)={2}`，`c=(3,7)`，`A=(7,3)`。另一条路径达到 `c=(3,7)` 但机器标签互换，`sort(A)` 相同。两条路径的剩余问题完全一样；v0.5 的键因为 `c` 相同而恰好合并，但如果 `c_1` 是 5 而不是 3（任务 1 不是任何剩余任务的前驱），未来不变，键却不同。

### 2.2 缺口二：区域证书在单调界核下是冗余的

v0.5 的 `CERT-REGION` 把一条证书推广到一个由 `lo/q/A` 不等式定义的状态区域。直觉上这能跨分支复用。但若区域是硬度序的上集、值又是由同一个单调界核算出来的，那么区域里的每个状态**自己的界核**就已经不小于这个值。证书命中的都是“本来就会被剪掉”的节点。第 4 节给出定理，第 10.3 节给出 801 次命中但 +2% 节点的实测。

### 2.3 缺口三：真正的瓶颈是原始解

30 个“困难”实例（best-first ≥40 节点）上：

```text
U = 贪心      → best-first 17,298 节点
U = ACO 4×6   → best-first  3,883 节点
U = OPT       → best-first     39 节点
```

同一批实例，**29/30 的根界核在 `H=OPT-1` 上已经证不出可行完成**，也就是根证书一步就能闭合。搜索之所以展开几千个节点，是因为它不知道 OPT，只能靠下降去找一个可行调度。**原始解每降 1，界核就多剪掉一大片。** 这直接决定了本轮的分工：指称语义负责“证明得对”，回溯负责“先拿到解”，蚁群负责“把解做小”。

### 2.4 三个灵感词的分工

- **指称语义**：接口、`D` 的 gfp、证书代数、冗余性定理。它回答“什么该被记忆、什么证书是白做的”。
- **回溯法**：primal-first DFS + 接口 memo；先下潜，后闭合；证明树变 DAG。
- **蚁群算法**：接口商上的 rank-based 构造，只做 primal；guide 明确不作为贡献。

## 3. 指称层：接口、指称函数与 greatest fixed point

### 3.1 接口与转移

**定义 1（接口）**：对状态 `σ=(S,A,c)`，

```text
R    = V \ S
r_i  = max( {c_j : j∈pred(i)∩S} ∪ {0} )      (i∈R)
ι(σ) = (R, r, sort(A))
```

**定义 2（转移）**：对 `i∈R` 且 `pred(i)∩R=∅`，机器 `k`：

```text
t     = max(A_k, r_i)
A'_k  = t + p_i,   A'_j = A_j (j≠k),   最后 sort(A')
r'_j  = max(r_j, t+p_i)   (j∈succ(i)∩(R\{i}))
r'_j  = r_j               (其它 j∈R\{i})
R'    = R \ {i}
ι_a   = (R', r', A')
```

机器同构，所以 `A` 排序不丢信息；`k` 是排序后向量里的下标，不同 `k` 可能给出同一 `A'`，在 `children` 里去重。

**命题 1（接口充分性 / 双模拟）**：若 `ι(σ)=ι(τ)`，则从 `σ` 与 `τ` 出发的可行完成 makespan 集合相同；特别地 `OPT(σ)=OPT(τ)`。

**证明**：对 `|R|` 归纳。`R=∅` 时两边都只能取 `max(A)`。否则，完成的第一步必是某个就绪任务 `i` 在某台机器上以 `t=max(A_k,r_i)` 开工（延后只会增大 makespan，可前移到最早时刻），转移只用到 `(R,r,A)`；由归纳假设，剩余部分的可行完成集合相同。对所有就绪动作取并，得到相同集合。证毕。

**推论 1**：搜索状态可以只存 `(R,r,A)`；v0.5 的 `(S,sort(A),c)` 是这个商的一个细化。

### 3.2 单调性

**定义 3（硬度序）**：`ι⪯ι'` 当且仅当

```text
R ⊆ R',   r_i ≤ r'_i (∀i∈R),   A ≤ A' (逐分量),
且 R' 上的优先约束限制在 R 上包含原约束。
```

**引理 1（D 对硬度序单调）**：`ι⪯ι' ⇒ D(ι)≤D(ι')`。

**证明**：取 `ι'` 的任一可行完成，把不在 `R` 中的任务删掉。删除任务不会破坏剩余任务的优先约束与机器不重叠；开始时间不变，makespan 不增。得到的调度对 `ι` 可行（释放下界更小、机器更早可用、约束更少）。因此 `D(ι)≤D(ι')`。证毕。

**注意（横切）**：沿搜索路径往下走，`R` 变小（更容易），但 `r,A` 变大（更难）。硬度序的上集方向与搜索树的生长方向是**横切**的。这一点是 §4 冗余性定理的几何直觉，也解释了为什么“区域复用”覆盖到的已访问状态极少（实测每个闭节点最多覆盖 3 个其它节点）。

### 3.3 Bellman 泛函与 gfp

**引理 2（Bellman）**：

```text
R=∅ :  D(ι) = max(A)
R≠∅ :  D(ι) = max( max(A), min_{a∈Act(ι)} D(ι_a) )
```

**证明**：任一完成的第一步是某个动作 `a`，之后是 `ι_a` 的完成；对 `a` 取 min。`D≥max(A)` 显然。证毕。

**引理 3（界核可采纳）**：`λ(ι,U) = max(L0(ι), AVAIL(ι,U-1)) ≤ D(ι)`。

**定理 1（最大不动点）**：令 `T(φ)(ι)=max(max A, min_a φ(ι_a))`（`R=∅` 时 `=max A`）。`T` 在逐点序上单调；`D` 是 `T` 的最大不动点；任意 post-fixed point `φ≤T(φ)` 都是可采纳下界。

**证明**：单调性显然。对 `|R|` 良基归纳证明 `φ≤D`：

```text
R=∅ :  φ(ι) ≤ T(φ)(ι) = max A = D(ι)
R≠∅ :  φ(ι) ≤ max(max A, min_a φ(ι_a))
           ≤ max(D(ι), min_a D(ι_a))        # 归纳假设
           = D(ι)                            # Bellman
```

`D` 本身满足 `D=T(D)`，故是最大不动点。证毕。

**推论 2（证书代数）**：可采纳下界对逐点 max 封闭；`max(λ1,λ2)` 仍可采纳。v0.5 的 `L_X5=max(L0,L_D,L_AV,L_TH)` 是特例。

## 4. 证书代数与冗余性定理

### 4.1 点证书与 CLOSE 规则

**定义 4（点证书）**：`β=(ι0,h)` 表示在 `ι0` 处证 `D(ι0)≥h`。它是可采纳的，若 `h≤D(ι0)`。

**定义 5（CLOSE / 动作覆盖）**：若对 `ι` 的每个动作 `a` 都有一个证书 `β_a=(ι_a,h_a)`，且 `h≤max(λ(ι), min_a h_a)`，则 `β=(ι,h)` 可采纳。

**证明**：`D(ι)≥min_a D(ι_a)≥min_a h_a`，且 `D(ι)≥λ(ι)`。证毕。

这就是“证明树变 DAG”的局部规则：一个节点的值由“局部界核”与“所有子节点值的最小值”取 max。

### 4.2 区域证书

**定义 6（区域证书）**：`β=(ι0,h)` 的**区域**是 `Reg(β)={ι:ι⪰ι0}`；语义是 `∀ι∈Reg(β): D(ι)≥h`。

由引理 1，只要 `h≤D(ι0)`，区域证书就是可采纳的。v0.5 的 `CERT-REGION`、`THRESH-CORE` 的跨状态复用都属于这个形状。

### 4.3 冗余性定理

**定理 2（绝对区域证书冗余）**：设 `λ` 可采纳且对 `⪯` 单调（实现中的有限窗口族是一个近似，见 §12 风险 13）。若 `h≤λ(ι0)`，则对任意 `ι⪰ι0` 有 `λ(ι)≥λ(ι0)≥h`。因此，若搜索已用 `λ(ι)≥U` 剪枝，则 `β` 不能剪掉任何 `λ` 剪不掉的节点。

**证明**：单调性给出 `λ(ι)≥λ(ι0)`；`h≤λ(ι0)` 给出 `λ(ι)≥h`。若 `β` 剪掉 `ι`，则 `h≥U`，于是 `λ(ι)≥U`，`λ` 本来就会剪掉 `ι`。证毕。

**边界（哪些不被覆盖）**：

1. **THRESH 不被覆盖**：它是在同一个状态上对目标 `H` 做更强的求值（二分 vs 单点），不是把证书搬到别的状态。目标维的单调性是另一条轴。
2. **相对支配不被覆盖**：`σ⪯τ` 时剪掉 `τ` 不需要 `λ(σ)≥U`，只需要 `σ` 已闭合/仍在前沿。这是“相对”的，不是绝对证书。
3. **路径最大 `F` 不被覆盖**：`F` 不是 `ι` 的函数，它可以严格大于 `λ(ι0)`。这也正是它无法进入接口记忆的原因。

**推论 3（v0.5 审计）**：`CERT-REGION` 与 `DOM-GEN` 的绝对值部分，如果值来自同一个单调界核，则没有额外剪枝；v0.5 实测的 DOM 收益来自**相对支配**（本轮关掉继承后仍在：17,298→15,734），不是区域本身。本轮消融复现了这一点：best-first 关 DOM 从 17,298 涨到 58,077；但把区域证书前沿加到接口 DFS 上，只从 2,255 变到 2,304。

### 4.4 那什么不是冗余的

只有两种：

- **相对支配**：不需要绝对 `h≥U`；它删除的是“有更好见证”的状态。
- **精确子问题值**：如果 `h=D(ι0)` 严格大于 `λ(ι0)`，那么它可能剪掉 `λ` 剪不掉的更硬状态。记忆化就是复用这种值。

本轮的接口 DAG 搜索，本质上是把“精确子问题值”的复用做到极致：每个接口只解一次。

## 5. IDB：接口记忆回溯

### 5.1 主过程

```text
算法 IDB(ι0, U0)
──────────────────────────────────────────────
1  U ← U0;  M ← ∅;  Proof ← ∅
2  h ← DFS(ι0)
3  if h ≥ U:  return (U, Proof)        # 根闭合，U=OPT
4  else:      return (U, ⊥)

DFS(ι):
1  if ι ∈ M: return M[ι]               # 规范状态，只解一次
2  if R=∅:
3      U ← min(U, max A);  return TERMINAL(path)
4  λ ← LB(ι, U)                        # L0 + AVAIL(U-1)
5  if λ ≥ U: return LOCAL(ι, λ)        # 一行证明
6  V ← []
7  for a ∈ Act(ι) in GUIDE order:
8      V.append( DFS(ι_a) )
9  h ← max(λ, min V)
10 if h ≥ U: return CLOSE(ι, λ, V)     # 动作覆盖
11 return h
```

其中 `GUIDE` 是静态 CP 序：`q_i` 降序、`max(A')` 升序、任务下标。它使第一条下降路径沿关键链走，在 ≤n 步内到达 terminal，立刻拿到一个可行 `U`。

### 5.2 为什么先下潜

在 best-first 中，`f=max(C,λ)` 最小的节点通常是浅层节点；搜索会先铺开一层，迟迟到不了 terminal。DFS 的第一条路径代价只有 `O(n)`，却立刻给出一个完整调度。对 `P|prec|Cmax`，`U` 每降 1，`AVAIL(U-1)` 就更紧，剪枝是指数放大的。**先拿到一个好 `U`，比先证明一个弱 `U` 更值。**

### 5.3 记忆的正确使用

`M[ι]` 只在 `DFS(ι)` **完整返回**（没有触发预算异常）后写入，存的是 `h`，满足 `h≤D(ι)`（terminal 取等；内部由 Bellman 与归纳）。因此：

- `M` 命中时返回 `h` 是可采纳的；
- 若 `h≥U`，剪掉 `ι` 是可靠的；
- 若 `h<U`，返回 `h`，父节点继续用 `min` 组合；不影响正确性。

不需要 reopening：`h` 只会是合法下界；`U` 只降不升。若某次 `DFS` 因为预算被截断，则不写 `M`，下次重新展开。

### 5.4 证明 DAG

每个闭合节点产生一个证明节点：

```text
TERMINAL(path, C)          重放动作路径；R=0；max A = C
LOCAL(ι0, h)               重算 λ(ι0) ≥ h
CLOSE(ι, λ, {β_a})         动作全覆盖；每个子证书覆盖对应子接口；
                           h ≤ max(λ, min_a h_a)
```

被 `LOCAL` 剪掉的子节点直接引用该 `LOCAL`；被 memo 命中的子节点引用第一次的证明；被前沿/支配剪掉的子节点引用见证的证明。证明是 DAG（`|R|` 严格下降，无环）。

## 6. ACO：只做 primal

### 6.1 构造

信息素键为 `(R, A, i, k)`（接口商上的状态 + 动作）：

```text
1  初始化 τ≡1
2  for iter in 1..I:
3      for ant in 1..A:
4          从根接口出发；每步在就绪 (i,k) 上按 p ∝ τ^α · η^β 采样
5          η = 1/(1 + t + p_i)，t=max(A_k,r_i)
6          得到完整路径与 makespan C
7      蒸发：τ ← (1-ρ)τ；删掉 τ<1e-3
8      对前 E 条路径按 rank 沉积：τ(key) += (E-rank)/max(1,C-1)
9  返回最好路径、U_ACO、τ
```

`U0 = min(U_greedy, U_ACO)`。

### 6.2 为什么不当 guide

v0.5 的 guide 消融只有 ~5%；v0.6（被拒稿的候选）的 ACO guide 也没有打过固定顺序。本轮明确把 ACO 放在 primal：`U0` 进入界核，是**可证明有效**的（`U` 越小，`λ(·,U)` 越大，剪枝单调）；而 guide 只影响顺序，没有单调性保证。

### 6.3 成本

`T_ACO = O(I·A·n·m·n)`（每只蚂蚁每步扫就绪任务与机器）。本轮取 `I=4, A=6`，30 个实例总耗时约 0.04 s；`10×8` 约 113 ms，`20×12` 约 336 ms。

──────────────────────────────────────────────

2  U0 ← min(Greedy_CP, Greedy_LPT, Greedy_MWKR)(ι0)

## 8. 正确性论证

### 8.1 接口充分性（命题 1）

已证于 §3.1。它是整个搜索的基础：`M` 只按接口索引，不按 `c`。

### 8.2 界核可采纳（引理 3）

`L0≤D` 由 v0.5 继承；`AVAIL` 由窗口-装箱不可行性继承。两者取 max 仍 `≤D`。

### 8.3 记忆化 DFS 正确（定理 3）

**定理 3**：设 `U` 是任意可行上界。若 `DFS(ι0)` 完整返回 `h≥U`，则 `U=OPT`。

**证明**：对 `|R|` 归纳证明：完整返回的 `h` 满足 `h≤D(ι)`，且若 `h≥U` 则 `D(ι)≥U`。

- terminal：`h=C=D(ι)`。
- `λ≥U`：`h=λ≤D(ι)` 且 `h≥U`。
- 内部：每个子节点返回 `h_a≤D(ι_a)`；`h=max(λ,min_a h_a)≤max(D(ι),min_a D(ι_a))=D(ι)`。若 `h≥U`，则 `D(ι)≥h≥U`。

根：`D(ι0)≥U`。又 `U` 是可行调度的 makespan，`OPT≤U`。故 `U=OPT`。证毕。

**定理 4（有限完备性）**：预算无限时，`DFS(ι0)` 必然返回 `h≥U=OPT`。证明：对 `|R|` 归纳。`U=OPT` 时 terminal 的 `C≥OPT`；内部节点的所有子节点归纳返回 `≥OPT`，故 `min≥OPT`，`h≥OPT`。根闭合。证毕。

### 8.4 CLOSE 规则可靠（引理 4）

若每个动作 `a` 的子证书满足 `D(ι_a)≥h_a`，且 `h≤max(λ(ι),min_a h_a)`，则

```text
D(ι) ≥ min_a D(ι_a) ≥ min_a h_a
D(ι) ≥ λ(ι)
⇒ D(ι) ≥ max(λ, min h_a) ≥ h
```

证毕。

### 8.5 checker 可靠（定理 5）

**定理 5**：若 `CHECK(root)` 通过，且 incumbent 路径可行、makespan 为 `U`，则 `U=OPT`。

**证明**：对证明 DAG 拓扑归纳。

- `TERMINAL`：checker 重放动作路径，验证 `R=0`、`max A=C`；故 `C` 是可行完成，`D(root)≤C`。
- `LOCAL`：checker 重算 `λ(ι0)≥h`；由引理 3，`D(ι0)≥h`。
- `CLOSE`：checker 枚举 `Act(ι)`，验证每个动作都映射到一个子证书，且子接口落在子证书区域内；由归纳，每个子证书的 `h_a≤D(ι_a)`；再由引理 4，`D(ι)≥h`。

根证书 `h≥U`，故 `D(root)≥U`。incumbent 可行给出 `OPT≤U`，于是 `U=OPT`。证毕。

### 8.6 相对支配（引理 5）

**引理 5**：同 `R` 下，若 `r'≤r` 且 `A'≤A`，则 `D(ι')≤D(ι)`。若 `ι'` 已闭合（`D(ι')≥h`）且 `h≥U`，则可剪 `ι`。

**证明**：引理 1。证毕。

**注**：这是“相对”规则：`ι'` 不必有 `h≥U` 的绝对证书；只要它在搜索中已被处理，剪掉 `ι` 不会丢更优解。这正是它与定理 2 不冲突的原因。

## 9. 复杂度分析

### 9.1 单次操作

- `est_q`：`O(n+|E|)`。
- `L0`：`O(n+|E|)`。
- `AVAIL`：两族窗口，各 `O(n)` 个；每个窗口构集合 `O(n)`，2-bin bitset 装箱 `O(|X|·C/word)`。故
  `T_λ = O(n²·C/word)`。
- `children`：`O(n·m·n)`（每个就绪任务、每台机器、更新后继）。
- memo 查询/写入：`O(n+m)` 哈希。
- ACO：`O(I·A·n²m)`。
- checker：`O(N_proof + |E_proof|)`，每个 `CLOSE` 还要重算一次 `Act(ι)` 与 `λ`。

### 9.2 总复杂度

设 `N` 为展开的接口数，`B` 为节点预算：

```text
时间: O( T_ACO + N·(T_λ + n·m·n + (n+m)) + T_check )
空间: O( N(n+m) + depth·(n+m) + N_proof )
```

最坏情况：接口数仍是 `O(2^n · T^m)`（`T` 为时间上界），问题 NP-hard，不改变最坏复杂度。

### 9.3 与 best-first 的复杂度对比

```text
best-first: Open 可能指数增长；每个接口在 Open 中可能被多条路径以不同 F 表示。
IDB:        M 存每个接口一次；栈深度 ≤ n；无 Open 堆。
```

本轮 30 个实例上，best-first 的单实例 `Open` 峰值最高 1,324；IDB 的 `M` 最高 153。两者都只展开“界核没剪掉”的接口，IDB 的 `N` 更小（§10.2）。

## 10. 实验设计

### 10.1 设置

- 随机 DAG：任务按索引拓扑排序；`i<j` 以概率 `ep` 加边；`p_i` 均匀取 `1..pmax`；`m=2`。
- 候选池：`n∈{9,10}`，`ep∈{0.2,0.3,0.4}`，`pmax∈{6,8,10}`；用 v0.5 风格 best-first 跑一遍，保留展开数 `≥40` 的实例；共 30 个。
- 独立 OPT：在接口 DAG 上做**无剪枝** DP（`exact_dp_iface`），30/30 与 best-first 返回的 U 一致；DP 节点数 3,605–345,391。
- 界核：`L0 + AVAIL(U-1)`；2-bin bitset 子集和；两族窗口（释放窗 `[a,H)`、截止窗 `[0,b)`）。
- 代码：纯 Python 3.12，单线程，单次测量；时间只作相对 sanity check。
- 复现：`exp/pcb.py`、`exp/build_pool.py`、`exp/run_final.py`、`exp/final_idb.json`、`exp/pool30.pkl`。

### 10.2 主 2×2：primal × search

| 变体 | primal | search | 总展开 | 墙钟 |
|---|---|---|---:|---:|
| v0.5 风格 BF | 贪心 | best-first + DOM + inherit | 17,298 | 1.63 s |
| BF-ACO | ACO 4×6 | 同上 | 3,883 | 0.40 s（含 ACO） |
| IDB | 贪心 | 接口记忆 DFS | 2,255 | 0.32 s |
| **IDB-ACO** | ACO 4×6 | 接口记忆 DFS | **1,316** | **0.24 s** |
| BF-oracle | OPT | best-first | 39 | — |
| IDB-oracle | OPT | 接口记忆 DFS | 170 | — |

读法：

- **primal 的作用**：同一 best-first 下，贪心 17,298 → ACO 3,883 → OPT 39。`U0` 是主导变量。
- **search 的作用**：同一贪心下，best-first 17,298 → IDB 2,255（7.7×）；同一 ACO 下，3,883 → 1,316（3.0×）。
- 两者互补：IDB-ACO 相对 v0.5 风格是 **13.1×** 节点、**6.8×** 墙钟。
- oracle 行是一个反向提示：给定 OPT 时 best-first 反而比 IDB 省（39 vs 170），因为 DFS 仍要下潜；IDB 的优势在“找 U”，不在“证已知的 U”。
- 30 个实例上 IDB 对 BF 是 **28 胜 0 平 2 负**；两个负例是 BF 本来就很容易的实例（65→153、58→101）。
- 所有变体的 `U` 都等于独立 OPT（30/30）。

### 10.3 消融

| 消融 | 总展开 | 解读 |
|---|---:|---|
| BF 完整（DOM + inherit） | 17,298 | 基线 |
| BF 关 DOM | 58,077 | 相对支配是 BF 的最大单项（−70%） |
| BF 关 inherit | 15,734 | 路径最大 F 在这批实例上不赚反亏 |
| IDB（无前沿） | 2,255 | 接口 + memo |
| IDB + 区域前沿 | 2,304 | **+2%，定理 2 的实测**：801 次命中全在界核已剪的节点上 |
| IDB 换 c-key 记忆 | 2,018 | 接口商反而多 ~12%（诚实的反例） |
| IDB 关 memo | 4,666 | memo 贡献 2.1× |

**解读**：

- **DOM 是相对的，不是绝对的**：best-first 关 DOM 涨 3.4×，说明“有见证的相对支配”有效；但把绝对区域证书加到 IDB 上无效，说明“划大区域”无效。这正是定理 2 的边界。
- **inherit 没有复现 v0.5 的 3.6% 收益**：在这批实例上关掉继承反而少 9%。我们不把它当作本轮贡献；可能的原因是接口 memo + CLOSE 已经取代了路径继承的作用。
- **接口商没有赢 c-key**：理论上接口更粗，但 DFS 的原始解到达顺序被合并改变，导致 `U` 下降更慢。需要说明的是，c-key 对照用的是 visited 集合而非值 memo，二者不是完全同构；这个数字只作为“接口商没有自动赢”的证据，不作因果结论。这是一个开放问题（§12 风险 3）。

### 10.4 ACO 预算

30 个实例，`seed=1000+k`；第一行是三条贪心规则取 min 的基线：

| 迭代 × 蚂蚁 | 初始间隙和 | 命中 OPT | 30 实例总时间 (ms) |
|---|---:|---:|---:|
| 0（贪心组合） | 47 | 0 / 30 | 0 |
| 1 × 3 | 36 | 3 / 30 | 7 |
| 2 × 4 | 32 | 6 / 30 | 13 |
| **4 × 6** | **22** | **13 / 30** | **34** |
| 10 × 8 | 8 | 22 / 30 | 113 |
| 20 × 12 | 3 | 27 / 30 | 336 |

主实验取 4×6：30 实例总计约 34–40 ms，换 939 个节点（2,255→1,316），在小 n 上墙钟仍从 0.32 s 降到 0.24 s；10×8 会多花约 80 ms 的 ACO 时间，不划算。

### 10.5 根界核诊断：瓶颈在哪

对每个实例，令 `U=OPT`，只算根节点：

```text
L0(root) + AVAIL(root, OPT-1) ≥ OPT   ?
```

结果：**29 / 30 成立**。也就是说，只要知道 OPT，根证书一行闭合；搜索的全部工作是把 `U` 从贪心/ACO 的值降到 OPT。

这个诊断解释了主表：`BF-oracle` 39 节点、`IDB-oracle` 170 节点，而 `BF-greedy` 17,298。它同时是一个警告：这批实例是“原始解困难”，不是“证明困难”；换成根界核不紧的实例，搜索结构会重新变成一阶项。

### 10.6 Anytime

固定展开预算，记录 `U_best-OPT` 的平均值（30 个实例）：

| 预算 | best-first 平均间隙 | IDB 平均间隙 |
|---:|---:|---:|
| 10 | 1.567 | 1.567 |
| 25 | 1.567 | 0.467 |
| 50 | 1.567 | 0.333 |
| 100 | 1.567 | 0.033 |

best-first 在前 100 个展开里几乎不改善 `U`（它先铺浅层）；IDB 的第一条下降在 ≤n 步内到 terminal，25 步后已经把平均间隙压到 0.467。这是“primal-first”的直接证据。

### 10.7 checker

- 30/30 通过；证明 DAG 共 1,316 个节点，最大 141。
- 检查内容：terminal 路径重放、`LOCAL` 的 `λ` 重算、`CLOSE` 的动作全覆盖与子证书区域成员、根证书 `h≥U`。
- 没有发现假证书；`U=OPT` 与独立 DP 一致。

### 10.8 规模

`n=12` 的三个非平凡实例（ACO 10×8）：

| n | ep | BF 节点 | IDB 节点 | BF 时间 | IDB 时间 | checker |
|---:|---:|---:|---:|---:|---:|---|
| 12 | 0.18 | 8,277 | 109 | 1.12 s | 0.03 s | ✓ |
| 12 | 0.18 | 2,750 | 91 | 0.29 s | 0.03 s | ✓ |
| 12 | 0.26 | 214 | 520 | 0.02 s | 0.09 s | ✓ |

两胜一负；负例仍是“BF 本来容易”的实例。其余 `n=12–13` 实例根界核一步闭合（BF 1 节点），不具区分度。规模实验只作 sanity check，不作结论。

## 11. 与 v0.5 的关系

| 维度 | v0.5 | v0.6 |
|---|---|---|
| 状态 | `(S,A,c)` | `(R,r,A)` 接口 |
| 状态合并 | `(S,sort(A),c)` 精确键 | `(R,r,A)` 双模拟商 |
| 下界 | `L0+L_D+L_AV+L_TH`，路径最大 `F` | `L0+AVAIL`，无 `F` |
| 搜索 | best-first / focal | primal-first DFS + memo |
| 支配 | 同 `S`、`c` 逐分量 | 同 `R`、`r/A` 逐分量（相对） |
| 证书泛化 | THRESH / REGION / INHERIT | 保留 THRESH 思想；证明 REGION 冗余 |
| 上界 | 贪心组合 + MCTS/bandit | ACO primal |
| 证明 | 树 | DAG + 独立 checker |

**不推翻的部分**：`L0`、AVAIL 打包核、动作覆盖、相对支配、证明 DAG 的局部检查思想、THRESH 的目标维单调性。

**替换的部分**：路径最大 `F`（破坏接口商）、绝对区域证书（定理 2 冗余）、focal/bandit guide（收益小）、`c` 作为状态。

## 12. 已知风险

1. **基准偏差**：30 个实例按“best-first ≥40”筛出，且 29/30 的根界核在已知 OPT 时一步闭合。这批实例主要测“原始解”，不测“证明”。在大规模、根界核不紧的实例上，IDB 的优势可能消失甚至反转（§10.8 已有一例 520 vs 214）。
2. **ACO 成本**：4×6 是 30 实例总计约 34–40 ms；10×8 是 113 ms；20×12 是 336 ms。小 n 上 ACO 可能比搜索还贵；本轮只在 n≤13 上验证。
3. **接口商的反例**：理论上 `(R,r,A)` 更粗，但实测比 c-key 多 ~12% 节点（2,255 vs 2,018；c-key 对照用 visited 集合而非值 memo，非完全同构）。可能原因是合并改变了 DFS 的原始解到达顺序，使 `U` 下降更慢；本轮没有证明这是唯一原因。**这是本轮最需要下一轮解释的异常。**
4. **路径继承没有复现**：关 inherit 反而略好（15,734 vs 17,298）。这与 v0.5 的 3.6% 收益不一致；可能是实现/实例差异。我们不声称继承无效，只声称“在这批实例上不赚”。
5. **checker 的独立性有限**：checker 重算 `λ`，但 `λ` 的数学（`L0`、AVAIL、2-bin 装箱）是共享的；如果界核实现有 bug，checker 会一起错。真正的独立 checker 需要另一套界核（例如对偶/穷举）对拍。
6. **m=2 限制**：2-bin bitset 是精确的；`m≥3` 只用总能量测试（弱），没有实现精确异构装箱。`m≥3` 的结论不能外推。
7. **拓扑序假设**：实验实例按索引拓扑排序；一般 DAG 需要显式拓扑排序与传递闭包，`r` 的更新要按拓扑序。
8. **机器同构**：`sort(A)` 只在同构机器上成立；unrelated machines 或带机器 release time 时，接口商与支配引理都要重写。
9. **不改善最坏复杂度**：接口 DAG 仍可能指数大；本轮是“更早的 primal + 更少的重复子问题”，不是新的最坏界。
10. **ACO 随机性**：单次运行、固定 seed；没有报告方差。`U0` 的波动会直接影响节点数。
11. **证明 DAG 的工程复杂度**：`CLOSE` 的动作覆盖需要枚举 `Act(ι)`；memo 共享会产生 DAG 而非树；checker 的环检测与区域成员检查都依赖实现细节。本轮 30/30 通过，但没有做大规模 fuzz。
12. **THRESH 未合并**：本轮为了隔离变量，界核只用 `L0+AVAIL(U-1)`，没有启用 v0.5 的 THRESH 二分。THRESH 在目标维的单调性是独立的、未被定理 2 覆盖的；把它与 ACO primal 合并可能还有收益，留到下一轮。

13. **界核窗口族的单调性**：定理 2 的前提是 `λ` 对 `⪯` 单调。`L0` 与“截止窗”族是单调的；但“释放窗”族的窗口集合随 `est_i` 移动，有限窗口族不一定闭合，严格单调性需要在实现层检查。实测前沿无收益与定理一致，但形式前提不应被当作无条件成立。

---

## 13. 一句话最大风险

**当前方案最大的风险是：本轮把 v0.5 的“困难实例”重新解释成“原始解困难”而不是“证明困难”（29/30 在已知 OPT 时根界核一步闭合），于是 ACO 的收益可能只是补上这批实例的最后一格；在根界核本身不够紧、真正需要搜索的大实例上，接口商反而比 c-key 记忆多约 12% 的节点，本轮的核心卖点（指称状态）还没有被证明是搜索效率的来源。**
