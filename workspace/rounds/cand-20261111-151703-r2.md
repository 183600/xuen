# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「机器人操作系统」×「传感器标定」）

> 第 54 轮把技能组合提升为动作空间剖面 `α_S` 与动作-鲁棒性联合证书 `J`，但其前提是「动作可被观测、且云边标定一致」。本轮把 **ROS 计算图** 作为技能的物理接口层，把 **传感器标定** 作为可观测性的度量学地基。核心矛盾：H22：`α_S` 假设动作可被可靠观测，但标定漂移会让同一动作在置信区间内不可分辨，覆盖判定出现假阳；H23：云端与边端 ROS 节点可能持有不同标定版本，同名动作映射到不同物理量，联合证书 `J` 在语义上分叉。

## 0. 直觉与动机

**灵感 1（ROS = 技能的神经系统，而不是部署细节）**
直觉：把 ROS 计算图 `G_ROS` 当成技能组合图 `G_S` 的物理实现，而不是事后适配。两个技能能否组合，不只在动作空间上 `compat`，还要在 **接口契约** 上可连接：消息类型、QoS（reliability / durability / deadline）、TF 坐标系、时间戳同步。`compat(S_i,S_j) ≥ θ_a` 只是必要条件；`I_ij = (msg, qos, frame, stamp) 可满足` 才是充分条件。第 54 轮的「动作兼容边」若接口不匹配，运行时会在话题/变换处直接断裂——这是一种组合前完全看不见的边失效。

**灵感 2（标定 = 可观测性的地基，动作空间是被「测量」出来的）**
直觉：传感器标定不是一次性工程步骤，而是一个带协方差 `Σ_cal` 与漂移率的状态。动作 `a` 造成的状态变化 `Δx`，只有显著超过标定噪声 `k·√tr(Σ_cal)` 才能被可靠区分。于是定义 **可观测锥 `O_S(a)`**：在标定不确定度下仍可被判定的状态集合。动作空间的真实边界不是「物理可达」，而是「可观测可达」。`α_S` 应从「能否执行」升级为「能否被标定精度分辨」，否则覆盖检查只是在黑箱能力上自欺。

**灵感 3（标定感知鲁棒性 → 鲁棒性谱的度量学扣除）**
直觉：第 53 轮的 `ρ_d` 是在「传感器可信」前提下测得的。若维度 `d` 的判定依赖标定很差的传感器，则鲁棒性应打折：`ρ^cal_d = clip(ρ_d - λ_d·u_d(Σ_cal), 0, 1)`，其中 `u_d` 是标定协方差在维度 `d` 上的投影不确定度。鲁棒性不再是纯控制属性，而是 **控制 × 度量学** 的联合属性。这解释了为什么仿真里 `ρ≈1` 的技能到现场会「莫名」失败：不是控制坏了，而是判定它的尺子弯了。

**灵感 4（云边标定契约 → 版本一致性先于动作一致性）**
直觉：云边映射 `γ_ce` 建立在「同一标定」的假设上。实际中云端用仿真标定、边端用现场标定，`θ_c ≠ θ_e`。应增加 **标定契约** `C_cal = (θ_c, θ_e, Σ_cal, ε_cal, τ_fresh)`，要求 `||θ_e - γ_cal(θ_c)||_{Σ_cal} ≤ ε_cal` 且标定年龄 `age(θ) ≤ τ_fresh`。同名动作必须先通过标定一致性，再谈动作对齐；否则联合证书 `J` 的「同名动作」只是字面相同、物理不同，证书 soundness 从根上失效。

**灵感 5（标定回路 → 证书总线与「标定新鲜度」作为一等失效模式）**
直觉：把证书本身作为 ROS 话题发布（QoS=reliable，带 timestamp 与 `frame_id`）。于是出现新的失效模式 **证书陈旧（stale certificate）**：云端拿到的 `J` 已过期，边端标定早已漂移。需在 `J` 上附加 `κ_stale`（新鲜度）与 `O_cert`（可观测证书），并让 Explain 回传区分根因是「动作错位」还是「标定漂移」：前者触发 `reprofile`，后者触发 `recalibrate`。形成 **标定-动作-鲁棒性** 三元闭环，而不是单环。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（ROS 计算图与接口契约）**
ROS 计算图 `G_ROS = (N, T, Φ)`：`N` 为节点（技能实例），`T` 为带类型的话题/服务，`Φ` 为 TF 坐标系树。技能 `S` 的接口契约 `I_S = (In_S, Out_S, qos_S, frames_S, stamp_S)`。两技能接口相容：
```
I_ij = 1  ⟺  Out_i ⊆ In_j ∧ types/msg 匹配 ∧ qos_compatible(q_i,q_j)
             ∧ ∀ f∈frames_j, tf_reachable(f, base_i, stamp_j)
```
第 54 轮的组合边集合应修正为 `E = {(i,j) | compat(S_i,S_j) ≥ θ_a ∧ I_ij = 1}`。

**定义 122（标定状态、协方差与漂移）**
标定状态 `θ = (θ_int, θ_ext)`（内参、外参），服从 `θ ~ N(θ̂, Σ_cal)`。漂移过程 `dθ/dt` 满足 `|dθ/dt| ≤ δ_θ`，标定年龄 `age(θ) = t_now - t_cal`。**标定新鲜度** `κ_stale = age(θ)/τ_fresh`，`κ_stale > 1` 即不可信。

**定义 123（可观测锥与可观测动作覆盖）**
动作 `a` 的可观测裕度：
```
m_S(a) = ||Δx_S(a)|| - k·√( tr(Π_S Σ_cal Π_S^T) )
```
其中 `Π_S` 为技能观测模型对状态变化的投影，`k` 为置信系数。**可观测锥** `O_S(a) = { Δx | m_S(a) > 0 }`。**可观测覆盖**：
```
cover_obs(S, A_T) = 1  ⟺  ∀a∈A_T, α_S(a) ≥ θ_cov ∧ m_S(a) > 0
```
即 `α_S` 只保留「既会做、又看得清」的动作。

**定义 124（标定感知鲁棒性谱）**
```
ρ^cal_d = clip( ρ_d - λ_d·u_d(Σ_cal), 0, 1 ),   u_d(Σ_cal) = √( e_d^T Π_d Σ_cal Π_d^T e_d )
```
其中 `λ_d ≥ 0` 为维度 `d` 对度量误差的敏感系数。第 54 轮的 `ρ` 是 `ρ^cal` 在 `Σ_cal→0` 时的特例。

**定义 125（云边标定契约）**
`C_cal = (θ_c, θ_e, Σ_cal, ε_cal, τ_fresh)`，一致性判定：
```
consistent(C_cal) ⟺ ||θ_e - γ_cal(θ_c)||_{Σ_cal} ≤ ε_cal  ∧  age(θ_e) ≤ τ_fresh
```
其中 `γ_cal` 为标定参数的云边换算（含时间/温度补偿）。`C_cal` 是第 54 轮 `C_ce = (P_c,P_e,Δ,Explain_loop)` 的**前置条件**：`C_cal` 不一致时，`Δ` 的度量本身无参照意义。

**定义 126（ROS 原生三元联合证书）**
```
𝕁 = ( J, O_cert, C_cal, I_chain, κ_stale, evidence )
```
- `J` 为第 54 轮动作-鲁棒性联合证书；
- `O_cert = (O_core, m_min, k)` 为可观测证书，`O_core = {a∈A_core | m_S(a)>0}`；
- `C_cal` 为标定契约，`I_chain` 为技能链接口契约的逐边合取；
- `κ_stale` 为证书新鲜度；
- `evidence` 至少含 ROS bag 片段、标定残差、Explain 根因标签 `{action, calibration}`。
若 `dom_𝕁(T)=in ∧ κ_stale ≤ 1 ∧ I_chain=1 ∧ consistent(C_cal)`，则三元证书可部署。

## 2. 关键算法 伪代码

### IP-121 RICC（ROS Interface Contract Check）

```python
def ros_interface_check(si, sj):
    for topic in si.outputs:
        if topic not in sj.inputs:               return False, 'topic_missing'
        if si.msg_type[topic] != sj.msg_type[topic]: return False, 'type_mismatch'
        if not qos_compatible(si.qos[topic], sj.qos[topic]):
                                                 return False, 'qos_mismatch'
    for f in sj.required_frames:
        if not tf_reachable(f, si.base_frame, sj.stamp):
                                                 return False, f'frame_unreachable:{f}'
    return True, 'ok'

def build_ros_composition_graph(skills, theta_a, tau_e):
    G = nx.DiGraph()
    for i, s1 in enumerate(skills):
        for j, s2 in enumerate(skills):
            if i == j: continue
            if s1.compat(s2) < theta_a or s1.transition_cost(s2) > tau_e: continue
            ok, why = ros_interface_check(s1, s2)
            if not ok: continue
            G.add_edge(i, j, compat=s1.compat(s2), iface=why)
    return G
```

### IP-122 OCC（Observability Cone Characterization）

```python
def observability_margin(skill, a, Sigma_cal, k=2.0):
    dx = predict_state_delta(skill, a)
    P  = skill.observation_projection
    noise = k * sqrt(trace(P @ Sigma_cal @ P.T))
    return norm(dx) - noise

def calibrated_cover(skill, A_T, Sigma_cal, theta_cov=0.8):
    for a in A_T:
        if skill.alpha.get(a, 0.0) < theta_cov: return False
        if observability_margin(skill, a, Sigma_cal) <= 0: return False
    return True
```

### IP-123 CAT（Calibration-Aware Transfer）

```python
def calibration_aware_rho(rho, Sigma_cal, obs_model, lam):
    rho_cal = {}
    for d, r in rho.items():
        u_d = project_uncertainty(Sigma_cal, obs_model, d)
        rho_cal[d] = min(1.0, max(0.0, r - lam.get(d, 1.0) * u_d))
    return rho_cal
```

### IP-124 CDH（Calibration Drift Handshake）

```python
def calibration_drift_handshake(theta_c, theta_e, Sigma_cal, eps_cal,
                                tau_fresh, age_e):
    if age_e > tau_fresh:
        return ('reject', 'stale_calibration', age_e)
    d = mahalanobis(theta_e, transform_cal(theta_c), Sigma_cal)
    if d > eps_cal:
        return ('recalibrate', 'drift_detected', d)
    return ('ok', 'consistent', d)
```

### IP-125 CBUS（Certificate Bus）

```python
def publish_certificate(cert, bus):
    cert.kappa_stale = (now() - cert.stamp) / cert.tau_fresh
    bus.publish('/xuen/certificate', cert,
                qos=dict(reliability='reliable',
                         deadline=cert.tau_fresh,
                         frame_id=cert.frame_id))
    return cert.kappa_stale

def accept_certificate(cert, tau_fresh):
    if (now() - cert.stamp) / tau_fresh > 1.0: return ('reject', 'cert_stale')
    if not cert.I_chain:                      return ('reject', 'interface_mismatch')
    if not consistent(cert.C_cal):            return ('recalibrate', 'calibration_drift')
    return ('ok', cert)
```

### IP-126 TJC（Tri-Joint Certificate）

```python
def tri_joint_certificate(skill_seq, gamma_ce, Sigma_cal, C_cal, budgets):
    ok, why = ros_chain_check(skill_seq)
    if not ok: return ('reject', 'interface_mismatch', why)

    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    if not calibrated_cover_actions(A_core, Sigma_cal, budgets.theta_cov):
        return ('reject', 'unobservable_action')

    state, tag, d = calibration_drift_handshake(*C_cal)
    if state == 'reject':      return ('reject', tag, d)
    if state == 'recalibrate': return ('recalibrate', tag, d)

    rho     = compose_robustness_chain([s.rho for s in skill_seq], K)
    rho_cal = calibration_aware_rho(rho, Sigma_cal, obs_model, lam)
    if min(rho_cal.values()) < budgets.rho_min:
        return ('reject', 'robustness_fail', rho_cal)

    O_cert = (A_core, min(observability_margin(s, a, Sigma_cal)
                          for s in skill_seq for a in A_core), budgets.k)
    return ('ok', TriJointCert(rho_cal, A_core, O_cert, C_cal, d))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RICC | O(|Out|·|In| + |frames|·log|Φ|) | O(|T|) | 类型/QoS/TF 静态可判定 |
| OCC | O(|A|·(|Δx|+|Σ|²)) | O(|A|) | Σ_cal 有界、投影线性 |
| CAT | O(|𝔇_ρ|·|Σ|²) | O(|𝔇_ρ|) | u_d 单调、λ_d 有界 |
| CDH | O(|θ|²) | O(|θ|²) | 漂移有界、γ_cal 可逆 |
| CBUS | O(1) 发布 / 校验 | O(1) | 时钟同步、QoS 可靠 |
| TJC | O(|S|·|A|·|Σ|² + |I|) | O(|A|+|I|) | 三元合取 sound、κ_stale 闭合 |

**正确性定理（Calibrated Observable Composition Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** 标定协方差 `Σ_cal` 有界且漂移率 `|dθ/dt| ≤ δ_θ`；**(A30)** ROS 接口契约可静态判定（msg/QoS/frame 类型可检查）；**(A31)** 云边通过 CDH 在 `τ_fresh` 内完成标定对齐，且 `ε_cal ≤ Θ_cal`。则部署成功概率：
```
P_success ≥ 1 - Σ_d(1-ρ^cal_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
               - P(interface_mismatch) - P(κ_stale>1) - P(ε_cal>Θ_cal)
```
关键：**接口先于动作、可观测先于覆盖、标定一致先于云边对齐**。三者任一为假，证书 `𝕁` 必须拒绝而非降级。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 标定不可自证（递归标定） | 高 | 外部锚点 + 互标定 + 残差监控，禁止自证闭环 |
| `Σ_cal` 被低估导致假可观测 | 高 | 在线残差估计 + 保守膨胀因子 + 红队注入漂移 |
| ROS QoS 组合语义复杂 | 中 | 形式化 QoS 相容表 + 运行时 QoS 事件监控 |
| TF 时间同步误差伪装成标定误差 | 中 | 硬件时间戳 + 时钟偏差单独标定与扣除 |
| 漂移模型失配（温漂/振动） | 高 | 分段漂移模型 + 变化点检测 + 触发重标定 |

## 6. 本轮最大风险

**一句话**：本轮把技能组合的合法性从「动作对齐」前移到「接口可连 + 标定可观测」，但这套判定的地基是**标定基准本身可溯源**；若基准也随温漂/振动缓慢漂移，则 `O_cert` 与 `ρ^cal` 会陷入「自己量自己」的自证循环，表现出仿真与现场都「证书有效」却系统性误判的**标定闭环幻觉**；故必须以外部物理锚点 + 互标定残差 + 保守不确定度膨胀三重护栏，把「不可自证」当作硬约束，宁可判不可观测，也不把标定的自我一致性当作世界的一致性。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim+++（RICC×OCC×CAT×CDH×CBUS×TJC）

> 承接第 54 轮产物 v31。本轮在动作空间剖面与动作-鲁棒性联合证书之上，增加 **ROS 接口契约、标定可观测性、云边标定一致性、证书总线** 四类算子：
> - **RICC（ROS Interface Contract Check）**：把技能组合的可行性从动作空间推进到 ROS 接口契约；
> - **OCC（Observability Cone Characterization）**：用标定协方差界定「可观测动作空间」；
> - **CAT（Calibration-Aware Transfer）**：鲁棒性谱的度量学折扣 `ρ → ρ^cal`；
> - **CDH（Calibration Drift Handshake）**：云边标定一致性 + 漂移触发重标定；
> - **CBUS（Certificate Bus）**：证书作为 ROS 话题发布，引入「证书陈旧」失效模式；
> - **TJC（Tri-Joint Certificate）**：动作-鲁棒性-可观测三元联合证书 `𝕁`。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/118/120 以纳入 ROS 与标定维度。

```python
        u_d = project_uncertainty(Sigma_cal, obs_model, d)
        out[d] = min(1.0, max(0.0, r - lam.get(d,1.0)*u_d))
    return out
```

```python
def calibration_drift_handshake(theta_c, theta_e, Sigma_cal, eps_cal,
                                tau_fresh, age_e):
```

```python
def tri_joint_certificate(skill_seq, gamma_ce, Sigma_cal, C_cal, budgets):
    ok, why = ros_chain_check(skill_seq)
    if not ok: return ('reject','interface_mismatch',why)

    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    if not calibrated_cover_actions(A_core, Sigma_cal, budgets.theta_cov):

    state, tag, d = calibration_drift_handshake(*C_cal)
    if state == 'reject':      return ('reject', tag, d)
    if state == 'recalibrate': return ('recalibrate', tag, d)

    rho     = compose_robustness_chain([s.rho for s in skill_seq], K)
    rho_cal = calibration_aware_rho(rho, Sigma_cal, obs_model, lam)
    if min(rho_cal.values()) < budgets.rho_min:
        return ('reject','robustness_fail',rho_cal)

    O_cert = (A_core, min(observability_margin(s,a,Sigma_cal)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RICC | O(|Out|·|In| + |frames|·log|Φ|) | O(|T|) | 类型/QoS/TF 静态可判定 |
| OCC | O(|A|·(|Δx|+|Σ|²)) | O(|A|) | `Σ_cal` 有界、投影线性 |
| CAT | O(|𝔇_ρ|·|Σ|²) | O(|𝔇_ρ|) | `u_d` 单调、`λ_d` 有界 |
| CDH | O(|θ|²) | O(|θ|²) | 漂移有界、`γ_cal` 可逆 |
| CBUS | O(1) | O(1) | 时钟同步、QoS 可靠 |
| TJC | O(|S|·|A|·|Σ|² + |I|) | O(|A|+|I|) | 三元合取 sound、`κ_stale` 闭合 |

**正确性定理（Calibrated Observable Composition Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** `Σ_cal` 有界、`|dθ/dt| ≤ δ_θ`；**(A30)** ROS 接口契约静态可判定；**(A31)** 云边在 `τ_fresh` 内完成标定对齐且 `ε_cal ≤ Θ_cal`。则：
```
P_success ≥ 1 - Σ_d(1-ρ^cal_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
               - P(interface_mismatch) - P(κ_stale>1) - P(ε_cal>Θ_cal)
```
关键：**接口先于动作、可观测先于覆盖、标定一致先于云边对齐**；任一为假则 `𝕁` 拒绝而非降级。

## 5. 本轮最大风险

**一句话**：本轮把组合合法性前移到「接口可连 + 标定可观测」，但地基是**标定基准可溯源**；若基准随温漂/振动缓慢漂移，`O_cert` 与 `ρ^cal` 会陷入「自己量自己」的自证循环，出现仿真与现场都「证书有效」却系统性误判的**标定闭环幻觉**；故必须以外部物理锚点 + 互标定残差 + 保守不确定度膨胀三重护栏，把「不可自证」当作硬约束，宁可判不可观测，也不把标定的自我一致性当作世界的一致性。
