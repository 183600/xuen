# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「状态机」×「评测指标」）

> 第 54 轮把技能组合提升为动作空间剖面 + 组合图 + 云边联合证书。但两个隐患暴露：(1) 组合图只表达**静态动作兼容**，无法表达执行顺序带来的**前置条件漂移、死锁、恢复**；(2) E157–E161 的指标是**点估计且互不可比**，"提升 12%/15%" 可能只是分母/任务集漂移的度量假象。本轮用「状态机」把组合变成**时序可验证的运行时对象**，用「评测指标」把评测变成**可组合、可校准、可比的代数对象**；两者相乘得到**轨迹级证书 + 指标护照**。核心矛盾：H22：静态兼容 ≠ 时序可达，组合图会漏掉"看似兼容、执行必死锁"的路径；H23：跨轮增益不可比，报告的性能提升可能是度量假象而非真实能力提升。

## 0. 直觉与动机

**灵感 1（组合的运行时本质是状态机，而非静态图）**
直觉：第 54 轮的 SCOM 把技能当图节点，用 `compat≥θ_a` 判边。但真机执行时，S1 执行完会改变位姿、接触、能量，S2 的前置条件可能已不成立。**技能是个带前置/后置条件的状态，组合是状态转移**。因此把技能库升级为 **守护层级状态机 GHSM**：状态 =（技能, 动作子域），转移由联合状态上的 guard 守卫。组合正确性从"路径存在"升级为时序性质：安全性 `G¬bad`、活性 `G F progress`、无死锁、可恢复性 `G(fail → F recovered)`。

**灵感 2（产品构造把环境不确定性吸收进证书）**
直觉：技能状态机 `M_S` 与任务自动机 `M_T` 做**产品构造** `M_S × M_T`，组合可行当且仅当产品中存在问题且避开坏状态的接受路径。把扰动看成对手，就出现**双人博弈**语义：鲁棒获胜域 `W_d` 是控制器在扰动 d 下能保持不变式并到达目标的状态集。于是第 54 轮的鲁棒性谱 `ρ(d)` 从"每技能标量"升级为 **ω-正则鲁棒性** `ρ_M(d)=μ(W_d)/μ(Q)`，直接由模型检验算出，而不是经验估计。

**灵感 3（评测指标必须是代数对象，否则跨轮增益不可比）**
直觉：E157–E161 报的是 MAE、发现率、+12%、+15% 这类**孤立点估计**，任务集/分布/基线一变就不可比，"提升"甚至可能只是换了分母。必须给每个指标发**护照** `Pass(m)=(dom,assum,est,ci,agg,ax)`，并用四条公理约束：
- (M1) 可分解性/单调性：组合指标是分量指标的良定义聚合，且 `A⊒B ⇒ compose(A,C)⊒compose(B,C)`；
- (M2) 校准性：概率型指标用 proper scoring rule，置信区间覆盖率 ≥ 1-α；
- (M3) 不变性：对任务重标号、仿真种子、机器人编号等 nuisance 变换不变；
- (M4) 可比性：`m1≍m2` 仅当定义域重叠且假设相容，比较前必须做**公共细化实验** R。
只有过护照的指标才能进证书；未过者标为 anecdotal。

**灵感 4（轨迹级评测指标 > 点成功率）**
直觉：状态机天然产生轨迹 τ，评测应从"最后一次成功/失败"升级为**轨迹指标向量**：`m(τ)=(succ, recov, margin_min, deadlock, lead_time, cost_align)`，其中 `margin_min=min_i(g_i-ε_i)` 是全程守卫裕度，`lead_time` 是失败前提前预警步数。这些指标共享同一轨迹分布，因而在 MPA 下**天然可比**，也更能区分"侥幸成功"与"稳健成功"。

**灵感 5（评测指标反过来守护状态机）**
直觉：指标不只离线评测，还应成为**运行时监视器**：每条转移带指标预算，监视器用 conformal 校准阈值 `θ_m` 判定漂移；超阈值则触发状态机的**保守/恢复转移**。配合第 54 轮的 hysteresis，可避免指标噪声引发来回抖动。于是闭环为：**状态机 → 轨迹指标 → 指标守护转移 → 重规划/恢复**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（守护层级状态机 GHSM）**
`M=(Q,q0,Σ,δ,Inv,G,F)`：`Q` 有限状态，`q=(S_q, A_q)` 为技能与动作子域；`δ⊆Q×Σ×Q` 为转移；`Inv:Q→Pred(X)` 为不变式；`G` 为守卫集合（联合状态 `x=(pose,contact,energy,ρ,δ_a)` 上的谓词）；`F⊆Q` 接受态。轨迹 `τ=q0→σ1 q1→…` 可行当且仅当 `∀i, Inv(q_i)∧g_i(x_i)` 成立。

**定义 122（产品博弈与鲁棒获胜域）**
给定任务自动机 `M_T`，产品 `M=M_S×M_T`。扰动等级 d 下的获胜域
```
W_d = νZ. { q | (∃σ∈Σ_ctrl, ∀ξ∈Σ_dist: q→σ,ξ q' ∧ q'∈Z) ∧ Inv(q) }
```
（最大不动点，即"无论对手怎么扰动都能保持在 Z 并最终到达 F"）。组合鲁棒性 `ρ_M(d)=μ(W_d)/μ(Q)`，其中 μ 为可达状态测度。

**定义 123（轨迹证书与轨迹指标向量）**
轨迹证书 `T=(τ, {g_i≥ε_i}_i, obligations, evidence)`。轨迹指标向量
```
m(τ)=(succ, recov, margin_min, deadlock, lead_time, cost_align)
```
其中 `margin_min=min_i(g_i(x_i)-ε_i)`；在轨迹分布 `P_τ` 上聚合为带置信区间的估计向量 `M=(μ̂,CI)`。

**定义 124（评测指标护照）**
`Pass(m)=(dom_m, assum_m, est_m, ci_m, agg_m, ax_m)`，`ax_m⊆{M1,M2,M3,M4}` 为已验证公理集。`m1≍m2` 当且仅当 `dom_{m1}∩dom_{m2}≠∅` 且 `assum` 相容；**认证比较**需公共细化 `R` 且两护照在 R 上有效。

**定义 125（指标代数与认证增益）**
代数 `(𝕄,⊗,⊑,⊤,⊥)`：`⊗` 沿 FSM 路径复合（概率型指标在条件独立下相乘，否则用 copula 给上下界），`⊑` 为细化序。认证增益
```
Δ_cert(m)=(μ̂_1-μ̂_2)-z_{1-α}·σ_pooled
```
仅当置信区间排除 0 且 `m1≍m2` 时才允许声称"提升"。

**定义 126（指标守护转移）**
`q --[m̂<θ_m^adv]--> q_recover`。阈值由 conformal 校准：在名义分布下 `P(false trigger)≤α`；采用滞回带 `[θ_lo,θ_hi]` 与驻留时间 `dwell` 防抖。

## 2. 关键算法 伪代码

### IP-121 GHSM（Guarded Hierarchical State Machine）

```python
def build_ghsm(skills, task_automaton, eps):
    M = StateMachine()
    for s in skills:
        for region in partition(s.action_domain, eps):
            M.add_state(q=(s.id, region),
                        Inv=lambda x, s=s: s.post_cond(x) and s.rho >= x.rho_min)
    for (q1, q2) in candidate_pairs(M.states):
        g = guard(q1, q2)          # pre(q2) ∧ post(q1) ∧ action_compat
        if sat(g, eps):            # 守卫裕度 ≥ ε 才加边
            M.add_transition(q1, q2, guard=g)
    M.add_recovery_states(skills)  # 每技能一个安全回退态
    return M

def guard(q1, q2, eps=0.05):
    return lambda x: q2.skill.pre(x) and q1.skill.post(x) and \
                     action_compat(q1.region, q2.region) >= eps
```

### IP-122 PMC（Product Model Checking）

```python
def product_check(M_S, M_T, d):
    M = product(M_S, M_T)
    W = greatest_fixpoint(M, lambda Z: {q for q in M.states
            if Inv(q) and exists_ctrl_forall_dist(q, Z, d)})
    dead = [q for q in M.states if no_outgoing(q) and q not in M.F]
    live = all(reachable_from(q, M.F, M) for q in W)
    safe = all(not is_bad(q) for q in W)
    if not (safe and live and not dead):
        return ('reject', T_cert(M, W, dead, live, safe))
    return ('ok', T_cert(M, W, dead, live, safe),
            rho_M=measure(W)/measure(M.states))
```

### IP-123 MPA（Metric Passport Algebra）

```python
def issue_passport(m, data, alpha):
    ax = set()
    if decomposable(m) and monotone(m): ax.add('M1')
    if is_proper(m.est) and coverage(m, data, alpha) >= 1-alpha: ax.add('M2')
    if invariant_under(m, nuisances(data)): ax.add('M3')
    return MetricPassport(dom=m.domain, assum=m.assumptions, est=m.est,
                          ci=bootstrap_ci(m, data, alpha), agg=m.agg, ax=ax)

def comparable(p1, p2):
    return domains_overlap(p1.dom, p2.dom) and assumptions_ok(p1.assum, p2.assum)

def certified_gain(m1, m2, R, alpha):
    assert comparable(m1.passport, m2.passport)
    assert validate_on(m1, R) and validate_on(m2, R)
    delta = m1.mu - m2.mu
    lo = delta - z(1-alpha)*pooled_sigma(m1, m2)
    return ('certified', delta) if lo > 0 else ('artifact_or_null', delta, lo)
```

### IP-124 TAM（Trace-Aligned Metrics）

```python
def trace_metrics(traces_ref, traces_eval, weights=None):
    out = []
    for tau_e in traces_eval:
        tau_r = align(tau_e, traces_ref, metric=dtw)
        m = dict(
            succ       = terminal(tau_e) in F,
            recov      = recovered_after_fail(tau_e),
            margin_min = min(g_i(x_i)-eps_i for (g_i,eps_i,x_i) in guards(tau_e)),
            deadlock   = has_deadlock(tau_e),
            lead_time  = steps_before_failure(tau_e),
            cost_align = path_cost(tau_e),
        )
        out.append((m, similarity(tau_e, tau_r)))
    return weighted_bootstrap(out, weights)
```

### IP-125 CMC（Certified Metric Comparison）

```python
def audit_prior_gains(claims, R, alpha):
    report = []
    for c in claims:                     # 如 E160 +12%, E161 +15%
        p1, p2 = issue_passport(c.m1, R, alpha), issue_passport(c.m2, R, alpha)
        if not comparable(p1, p2):
            report.append((c.id, 'not_comparable', p1.ax, p2.ax)); continue
        status, delta, lo = certified_gain(c.m1, c.m2, R, alpha)
        report.append((c.id, status, delta, lo))
    return report                        # 输出"度量假象占比"
```

### IP-126 MGM（Metric-Guarded Monitor）

```python
def metric_guard_transition(q, m_hat, theta_lo, theta_hi, dwell):
    if m_hat < theta_lo and dwell_elapsed(q):
        return 'recover'          # 进入保守/恢复态
    if m_hat > theta_hi:
        return 'resume'           # 滞回：只有明显回升才退出恢复
    return 'hold'

def calibrate_threshold(m_hat_nominal, alpha):
    return conformal_quantile(m_hat_nominal, 1-alpha)  # false trigger ≤ alpha
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| GHSM | O(|S|·|A_region| + |δ|) | O(|Q|) | guard 完整、Inv 忠实 |
| PMC | O(|M_S|·|M_T|·|Σ|)（最坏指数） | O(|M_S|·|M_T|) | 产品完备、W_d 为最大不动点 |
| MPA | O(|m|·n_boot) | O(n_boot) | 公理检查 sound、CI 覆盖 |
| TAM | O(|τ|²)（DTW） | O(|τ|) | 对齐良定义、权重归一 |
| MGM | O(1)/步 | O(1) | conformal 可交换性、滞回稳定 |

**正确性定理（Temporal Composition Soundness with Metric Passports）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** guard/Inv 是对真实动力学 sound 的过近似（`Inv_model ⊇ Inv_real`）；**(A30)** 扰动 d 落在产品博弈对手动作集内；**(A31)** 指标在公共细化 R 上满足 M1–M4 且轨迹满足可交换性。
则若 `product_check(M_S,M_T,d)=ok`、`m1≍m2` 且 `Δ_cert>0`，有
```
P(success ∧ claim_sound) ≥ 1 - P(¬W_d) - P(guard_violation) - α - β_shift
```
其中 `β_shift` 为分布漂移破坏可交换性的惩罚项。**关键：状态机保证时序可达，护照保证比较有效；两者缺一，证书就退化为"漂亮但空洞"的声明。**

## 6. 本轮最大风险

**一句话**：状态机与指标护照把"技能组合"升级为时序可验证、评测可比的证书体系，但其 soundness **双重依赖 guard/不变式对真实动力学的忠实过近似，以及评测指标在分布漂移下仍满足可交换性**；一旦守卫模型与实际执行错位、或任务分布漂移使 conformal 阈值失效，状态机就会在一个*虚假的获胜域*上发放"认证"，而护照反而让这种假象更难被质疑——即"证书越正式，误证越危险"。故必须以**仿真反例回灌的守卫过近似 + 漂移感知的加权 conformal + 未认证即标 unknown** 三重护栏，宁可交付"未知"，绝不发放"假认证"。

def issue_passport(m, data, alpha):
    ax = set()
    if decomposable(m) and monotone(m): ax.add('M1')
    if is_proper(m.est) and coverage(m, data, alpha) >= 1-alpha: ax.add('M2')

    return MetricPassport(dom=m.domain, assum=m.assumptions, est=m.est,
                          ci=bootstrap_ci(m, data, alpha), agg=m.agg, ax=ax)

def comparable(p1, p2):

### IP-125 CMC

```python
def certified_gain(m1, m2, R, alpha):
    assert comparable(m1.passport, m2.passport)
    assert validate_on(m1, R) and validate_on(m2, R)
    delta = m1.mu - m2.mu
    lo = delta - z(1-alpha)*pooled_sigma(m1, m2)
    return ('certified', delta) if lo > 0 else ('artifact_or_null', delta, lo)

def audit_prior_gains(claims, R, alpha):
    report = []
    for c in claims:                     # 如 E160 +12%, E161 +15%
        p1, p2 = issue_passport(c.m1, R, alpha), issue_passport(c.m2, R, alpha)
        if not comparable(p1, p2):
            report.append((c.id, 'not_comparable', p1.ax, p2.ax)); continue
        status, delta, lo = certified_gain(c.m1, c.m2, R, alpha)
        report.append((c.id, status, delta, lo))
    return report                        # 输出"度量假象占比"
```

## 5. 本轮最大风险

**一句话**：状态机与指标护照把"技能组合"升级为时序可验证、评测可比的证书体系，但其 soundness **双重依赖 guard/不变式对真实动力学的忠实过近似，以及评测指标在分布漂移下仍满足可交换性**；一旦守卫模型与实际执行错位、或任务分布漂移使 conformal 阈值失效，状态机就会在一个*虚假的获胜域*上发放"认证"，而护照反而让这种假象更难被质疑——即"证书越正式，误证越危险"。故必须以**仿真反例回灌的守卫过近似 + 漂移感知的加权 conformal + 未认证即标 unknown** 三重护栏，宁可交付"未知"，绝不发放"假认证"。
