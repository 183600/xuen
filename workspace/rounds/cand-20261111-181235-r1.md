# 第 56 轮（承接第 55 轮语义-接触生存核；灵感循环第 1 轮；本轮灵感：「VLA」×「目标检测」）

> 第 55 轮把感知从“像素标签”推进到“可执行接触约束”，但仍默认“接触对象是谁”是已知的。本轮补上最上游、也最容易被忽视的一环：**指称（reference）**。核心矛盾：**H24**：目标检测输出的是“带身份的实例集合”，其误差不是稠密像素噪声，而是漏检、误检、身份互换这类**离散事件**——错一个实例，整条动作的落点就押错；**H25**：VLA 把“语言名词短语 → 视觉实例 → 动作 token”串成一条链，真正的危险不是动作抖动，而是**在错误指称下自信地完成一个物理上成功、语义上错误的动作**；**H26**：语言先验会让 VLA 在检测缺失时“幻觉”出一个对象，因此“模型自述它抓的是杯子”不能作为指称正确的证据，必须用**外部反事实**去验证指称是否真的进入了控制。

## 0. 直觉与动机

**灵感 1（目标检测 → 实例假设集，而非又一张稠密标签图）**
直觉：语义分割回答“每个像素是什么”，目标检测回答“画面里有几个可被指称的物体、它们各是谁”。后者是 **集合值 + 带身份** 的输出：`D = {h_i}`，每个 `h_i` 有框/掩码、类别、校准分数、嵌入与跨帧 ID。它的误差形态是离散的——**漏检（miss）、误检（false positive）、身份互换（identity swap）**。对操作任务而言，“把 A 杯当成 B 杯”比“把杯沿三个像素标错”致命得多，因为动作的整个落点都绑在这个身份上。这是与第 55 轮语义分割**拓扑不同**的鲁棒性问题。

**灵感 2（VLA → 指称绑定，而不只是动作生成）**
直觉：VLA 的价值不只是“看图出动作”，而是把指令里的名词短语接到视觉实例、再接成动作 token。于是瓶颈从“动作是否平滑”移到 **“指称是否唯一且稳定”**：桌上有两个一样的杯子时，语言先验与检测分数在争夺“the cup”的解释权。VLA 真正的失效模式不是输出抖动，而是 **指称错误下的高置信执行**——机器人抓到了东西、任务“完成”了，但抓错了对象。因此**物理成功不等于任务正确**，二者必须拆成两个事件来度量。

**灵感 3（检测是集合 → 反事实身份消融，把“指称是否真被使用”变成可测量量）**
直觉：既然检测是集合，就可以做消融：把被绑定的实例 `h*` 从检测集中删掉，重跑 VLA，看动作是否剧变。若删掉后动作几乎不变，说明 VLA 根本没在用这个实例（很可能靠语言先验在幻觉）；若剧变，说明动作对身份高度敏感。这把“指称是否真的进入控制”变成一个**外部可测**的量，而不是听模型自述——这是本轮最关键的实验杠杆。

**灵感 4（指称闭合 → 三重绑定证书）**
直觉：第 55 轮把“语义标签 → 接触”接上了，但缺了“这是**谁的**接触”。一个可部署动作应同时满足：指令指称 `r`、检测实例 `h`、接触面 `c` 三者互相一致且各自带裕度。于是证书从语义-接触证书 `J_s` 升级为**三重绑定证书** `T=(r,h,c,裕度,预算,ρ_ref,证据)`，把“指称唯一性”写进可部署条件，而不是事后解释。

**灵感 5（澄清即动作 → 语言回路的主动消歧）**
直觉：VLA 能输出语言，因此“问一句‘你说的是左边那个杯子吗？’”应被视为一个合法的**安全动作**，而不是失败。把澄清/重观测纳入动作空间 `A_WB × A_ask`：护盾在指称模糊时优先选择**信息增益最高**的澄清动作，而不是在模糊里赌一把。这把第 55 轮的“保守制动”扩展为“保守提问”，把不可逆接触推迟到指称闭合之后。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（实例假设集与检测扰动）**
实例假设集 `D = {h_i = (id_i, b_i, l_i, s_i, e_i, m_i)}`，`b` 为框/掩码，`l ∈ L ∪ {⊥}`（`⊥` 为开集未知类），`s` 为校准分数，`e` 为实例嵌入，`m` 为掩码。检测扰动定义为集合编辑
`τ ∈ {del, ins, relabel, jitter, swap}`，其度量用匈牙利匹配后的编辑代价：
`d_det(D, D̂) = min_σ [ Σ_i cost_edit(h_i, ĥ_{σ(i)}) + λ·boxHausdorff(·, ·) ]`。
关键：**用集合匹配代价，而不是稠密图的 L∞ 误差**；漏检/误检/换 ID 在这一度量下是高代价事件。

**定义 128（指称解析与绑定场）**
指令 `q` 解析出指称表达式集合 `R(q)={r_j}`（名词 + 属性 + 空间关系）。接地分数 `G(r,h)∈[0,1]`。对 `r` 的候选按分数降序 `G_(1) ≥ G_(2) ≥ …`，定义
- 未解析：`G_(1)(r,D) < θ_g`；
- 指称模糊度（裕度）：`m_lang(r,D) = G_(1)(r,D) - G_(2)(r,D)`，当 `m_lang < θ_l` 判为模糊。
绑定场 `B(D,q) = {(r,h) | G(r,h) ≥ θ_g}`，即“哪些实例有资格被这个短语指称”。

**定义 129（三重绑定与裕度）**
绑定 `β = (r, h, c)`，`c` 为该实例上的接触类型与接触区域。四个裕度：
- 指称裕度 `m_ref = m_lang(r,D)`；
- 身份稳定裕度 `m_inst = min_{t∈窗口} sim(h.id_t, h.id_{t-1})`（IoU/嵌入连续性）；
- 检测置信裕度 `m_det = s_(1) - s_(2)`；
- 接触裕度 `m_contact`（承接第 55 轮定义 123 的语义边界裕度）。
可行绑定集 `B^+(D,q) = {β | 全部裕度 ≥ 对应阈值}`。**唯一性**：`|{h : (r,h) ∈ B^+}| = 1`。

**定义 130（指称护盾）**
给定 VLA 动作块 `a = π(I,q)` 及其**声明的指称** `r*`（来自语言头或解析后的计划），护盾在放行前校验 `β* = (r*, h*, c*) ∈ B^+`，并做两项外部检查：
1. **接触可行**：`c*` 在第 55 轮生存核 `K(Σ)` 内且 `m_contact ≥ θ_m`；
2. **指称因果性**：`RSR = ||a - a_{D\{h*}}|| / (||a||+ε) ≥ θ_dep`，即删掉该实例后动作必须显著改变，否则判为“指称未进入控制”。
若模糊，输出澄清动作 `a_ask = argmax_{ask∈A_ask} IG(ask)`；若未解析/接触不可行/因果性不通过，回退安全制动 `u_stop`。护盾只有三种出口：**放行、提问、制动**。

**定义 131（指称鲁棒性谱与“正确性”事件）**
在第 55 轮 `ρ_sem` 之上增加指称维：
`ρ_ref(ε_d, ε_l, ε_p) = inf_{d_det(D,D̂)≤ε_d, d_lang(q,q̂)≤ε_l, ||π-π̂||≤ε_p} P(correct_binding(a; D,q) ∧ task_success(a))`。
其中 `correct_binding` 要求动作实际作用的实例等于指令真值指称。**物理成功但抓错对象不计入成功**——这是与以往鲁棒性谱最本质的区别。

**定义 132（三重绑定证书）**
`T = (r_core, h_core, c_core, m_ref, m_inst, m_contact, δ_det, δ_lang, ρ_ref, evidence)`：
- `r_core` 指令核心指称，`h_core` 绑定实例，`c_core ⊆ C^+` 接触集；
- `δ_det = d_det(D, D̂)` 实测检测扰动，`δ_lang = d_lang(q, q̂)` 实测语言扰动；
- `evidence` 含漏检/误检日志、身份互换反例、澄清记录、`RSR` 曲线。
若指称唯一、四个裕度达标、`δ_det < Θ_d ∧ δ_lang < Θ_l` 且 `ρ_ref ≥ ρ_min`，则**指称-接触可部署**。

## 2. 关键算法 伪代码

### IP-127 ODH（Object Detection Hypothesis Set）

```python
def instance_hypotheses(rgbd, detector, tracker, calib, theta_s):
    raw = detector.predict_open_set(rgbd)      # boxes, labels incl. UNKNOWN, scores, embeds
    D = []
    for h in raw:
        h.score = calib.temperature_scale(h.score)
        h.id = tracker.match(h)                # cross-frame identity
        if h.score < theta_s:
            continue
        D.append(h)
    return dedup_by_mask_iou(D)
```

### IP-128 RBG（Referential Binding Grounder）

```python
def referential_binding(q, D, embedder, theta_g, theta_l):
    B, ambiguous, unresolved = [], [], []
    for r in parse_referents(q):               # noun + attributes + relations
        ranked = sorted(((G(r, h, embedder), h) for h in D), key=lambda x: -x[0])
        if not ranked or ranked[0][0] < theta_g:
            unresolved.append(r); continue
        margin = ranked[0][0] - (ranked[1][0] if len(ranked) > 1 else 0.0)
        if margin < theta_l:
            ambiguous.append((r, [h.id for _, h in ranked[:3]]))
        B.append((r, ranked[0][1], margin))
    return B, ambiguous, unresolved
```

### IP-129 OAR（Object-Ablation Referentiality）

```python
def referential_causality(a_nom, h_star, policy, image, q):
    a_abl = policy.act(render_without(image, h_star.id), q)   # same scene, instance removed
    return rel_change(a_nom, a_abl)                          # RSR in [0, inf)
```

### IP-130 RSF（Referential Shield Filter）

```python
def referential_shield(a_nom, image, q, D, policy, budgets):
    r_decl = policy.declared_referent(a_nom, q)
    B, ambiguous, unresolved = referential_binding(q, D, policy.embedder, budgets.theta_g, budgets.theta_l)
    beta = match(B, r_decl)

    if unresolved or beta is None:
        return safe_brake(image), 'referent_unresolved'
    if ambiguous:
        return clarify(argmax_info_gain(ambiguous, q)), 'ask_clarify'

    rsr = referential_causality(a_nom, beta[1], policy, image, q)
    if rsr < budgets.theta_dep:
        return clarify(beta[0]), 'referent_not_causal'   # VLA likely hallucinating

    if not contact_feasible(beta[1], beta[2]) or beta.m_contact < budgets.theta_m:
        return safe_brake(image), 'contact_infeasible'
    return a_nom, 'ok'
```

### IP-131 RRS（Referential Robustness Spectrum）

```python
def referential_spectrum(D_hat, q_hat, policy, eps_d, eps_l, eps_p, sampler):
    worst = 1.0
    for D_adv in sampler.set_edits(D_hat, eps_d):        # del/ins/relabel/swap
        for q_adv in sampler.paraphrase(q_hat, eps_l):   # synonyms, pronouns, word order
            p = empirical_correct_success(policy, D_adv, q_adv, eps_p)
            worst = min(worst, p)
    return worst
```

### IP-132 TBC（Tri-Binding Certificate）

```python
def tri_binding_certificate(traj, D, q, policy, rho_ref, budgets):
    binds = bindings_used(traj)
    if len(binds) != 1 or not is_unique(binds, D, q):
        return ('reject', 'ambiguous_referent', binds)
    r, h, c = binds[0]
    m_ref = m_lang(r, D)
    m_inst = min(identity_consistency(h.id, traj))
    m_contact = min(contact_margin(c, traj))
    delta_det = detection_perturbation(D, calibrated_eps_d)
    delta_lang = paraphrase_perturbation(q, calibrated_eps_l)
    if min(m_ref, m_inst, m_contact) < budgets.theta:
        return ('reject', 'margin_fail', m_ref, m_inst, m_contact)
    if delta_det > budgets.Theta_d or delta_lang > budgets.Theta_l:
        return ('reject', 'referential_budget_exceeded', delta_det, delta_lang)
    if rho_ref(delta_det, delta_lang) < budgets.rho_min:
        return ('reject', 'referential_robustness_fail')
    return ('ok', TriCert(r, h, c, m_ref, m_inst, m_contact, delta_det, delta_lang, rho_ref))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| ODH | O(N_det·d + N_det²) | O(N_det) | 分数校准、ID 关联稳定 |
| RBG | O(|R|·|D|·d) | O(|R|·|D|) | 指称解析完备、接地标定 |
| OAR | O(1) 次策略前向 | O(1) | 反事实渲染忠实、动作距离有界 |
| RSF | O(QP + 1 次前向) | O(|A|) | 三出口完备、RSR 阈值可校准 |
| RRS | O(N_edit·N_para·N_state) | O(N_state) | 集合编辑球覆盖、语言改写覆盖 |
| TBC | O(|轨迹|·(|D|+|R|)) | O(|D|+|R|) | 唯一性判定 sound、预算闭合 |

**正确性定理（Referential-Contact Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 检测分数经校准，ECE ≤ ε_cal；**(A34)** 指称真值在 `B^+` 内且裕度 `m_ref ≥ θ_l` 时才唯一；**(A35)** 护盾的外部检查（接触可行 + `RSR` 因果性）不被 VLA 自述欺骗；**(A36)** 澄清/制动回退在 `τ_ask` 内终止。则
```
P(correct referential execution)
  ≥ 1 - P(true referent missed)
      - P(false positive bound as referent)
      - P(identity swap within window)
      - P(undetected ambiguity)
      - P(VLA declared referent ≠ internal action)   # 由 OSR/RSR 外部检查捕获
      - P(contact infeasible)
```
关键：事件是**乘性链条**——漏检会让 VLA 用语言先验补位，误检会被绑定成“合法”目标，身份互换会让证书“自洽但错误”。因此护盾必须用**外部反事实**验证指称，而不是相信 VLA 的语言自述；并且**物理成功不计入正确性**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 开集检测漏检致 VLA 语言幻觉补位 | 高 | 未知类显式 `⊥` + 低分不绑定 + 主动重观测 |
| 同形物体的指称模糊 | 高 | 空间/属性关系复用 + 澄清动作 + 唯一性证书 |
| VLA 声明指称与实际动作不一致 | 高 | 对象消融 `RSR` 外部验证，不信自述 |
| 检测跟踪 ID 跳变 | 中 | 嵌入 + 运动一致性 + 窗口内 `m_inst` |
| 澄清动作拖慢任务 | 中 | 信息增益/代价权衡、批量澄清、可配置提问预算 |

## 6. 本轮最大风险

**一句话**：三重绑定把“抓的是谁”写进了可部署证书，但其 soundness 依赖检测校准、指称解析与**外部反事实**三者同时可靠；一旦 VLA 的“声明指称”只是事后语言合理化（自述与内部动作不一致），护盾就会在验证一个虚构的绑定上放行，让机器人高置信地抓错对象——因此必须以**对象消融 RSR + 感知侧独立绑定 + 模糊即澄清**三重护栏，宁可多问一句，绝不把模型的语言自述当作指称已证实。

# 第 56 轮产物 · 创新点清单 v32：GroundEdge-RefBind（ODH×RBG×OAR×RSF×RRS×TBC）

> 承接第 55 轮语义-接触接地与第 54 轮动作-鲁棒性双证书（v31）。本轮增加**指称层**：把“检测实例集合、语言指称、物理接触”闭合成一个可判定、可度量、可提问的三重绑定体系。
> - **ODH（Object Detection Hypothesis Set）**：集合值、带身份、开集感知接口；
> - **RBG（Referential Binding Grounder）**：指令指称 ↔ 检测实例的绑定场与模糊度；
> - **OAR（Object-Ablation Referentiality）**：对象消融反事实，验证指称是否真的进入控制；
> - **RSF（Referential Shield Filter）**：放行 / 提问 / 制动的三出口指称护盾；
> - **RRS（Referential Robustness Spectrum）**：检测集合扰动 × 语言改写下“正确绑定且成功”的最坏保持率；
> - **TBC（Tri-Binding Certificate）**：`(r,h,c)` 三重绑定证书，把指称唯一性写成可部署条件。
>
> IP 编号：IP-127~IP-132（共 6 个新增）；升级 IP-121/123/124/126 以接受实例级输入。

## 2. 关键算法 伪代码

### IP-127 ODH

```python
def referential_binding(q, D, embedder, theta_g, theta_l):
    B, ambiguous, unresolved = [], [], []
    for r in parse_referents(q):
        ranked = sorted(((G(r, h, embedder), h) for h in D), key=lambda x: -x[0])
        if not ranked or ranked[0][0] < theta_g:
            unresolved.append(r); continue
        margin = ranked[0][0] - (ranked[1][0] if len(ranked) > 1 else 0.0)
        if margin < theta_l:
            ambiguous.append((r, [h.id for _, h in ranked[:3]]))
        B.append((r, ranked[0][1], margin))
    return B, ambiguous, unresolved
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ODH | O(N_det·d + N_det²) | O(N_det) | 分数校准、ID 关联稳定 |
| RBG | O(|R|·|D|·d) | O(|R|·|D|) | 指称解析完备、接地标定 |
| OAR | O(1) 次策略前向 | O(1) | 反事实渲染忠实、动作距离有界 |
| RSF | O(QP + 1 次前向) | O(|A|) | 三出口完备、`RSR` 阈值可校准 |
| RRS | O(N_edit·N_para·N_state) | O(N_state) | 集合编辑球覆盖、语言改写覆盖 |
| TBC | O(|轨迹|·(|D|+|R|)) | O(|D|+|R|) | 唯一性判定 sound、预算闭合 |

**正确性定理（Referential-Contact Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 检测分数校准 ECE ≤ ε_cal；**(A34)** 真值指称在 `B^+` 内且 `m_ref ≥ θ_l` 时唯一；**(A35)** 护盾外部检查（接触可行 + `RSR` 因果性）不被 VLA 自述欺骗；**(A36)** 澄清/制动在 `τ_ask` 内终止。则
```
P(correct referential execution)
  ≥ 1 - P(true referent missed)
      - P(false positive bound as referent)
      - P(identity swap within window)
      - P(undetected ambiguity)
      - P(VLA declared referent ≠ internal action)
      - P(contact infeasible)
```
关键：**漏检 → 语言先验幻觉补位；误检 → 被绑定成“合法”目标；身份互换 → 证书自洽但错误**。因此护盾只信外部反事实，不信语言自述；且**物理成功不计入正确性**。
