# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环本轮第 2 轮；本轮灵感：「机器人操作系统」×「奖励设计」）

> R69 把不确定性做成了有形状的对象，并让系统学会「看、问、触」去消解关于**世界**的歧义。但它默认了一个从未被审计的前提：**目标是对的、唯一的、且就写在策略能看到的那一个标量里**。真实机器人不是单体：它是一张由节点、话题、QoS、生命周期与版本拼起来的运行时图——导航节点贡献一段代价，抓取节点贡献一次成功，安全节点贡献一笔罚分，人类贡献一句偏好。所谓「奖励」，其实是这张图在每一时刻**分布式地铸造**出来的量。
>
> 于是就出现一类 R69 完全无法处理的故障：**每个节点都在正确运行，传感器残差为零，动作似然很高，系统安全且自洽，但它优化的却是一个没人真正想要的目标**；或者更糟，某个节点（或某条被投毒的话题）正在偷偷铸币，而系统把它当成真理。R69 的 FMA 能测「行为在观测下是否自洽」，却测不出「这条行为**是否值得被奖励**」——行为似然与目标正确性正交。
>
> 本轮两个灵感正好补上两块缺失：
> - **机器人操作系统**告诉我们：奖励不是一个标量，而是一条**有来源、有时戳、有 QoS、有版本、有生命周期**的消息；因此它可以被溯源、契约化、审计、回放。
> - **奖励设计**告诉我们：势函数塑形（potential-based shaping）之所以不改变最优策略，是因为它在状态转移图上是一个**保守场**；一旦局部塑形不共享同一个势，闭路上的**环流**就非零——那正是「绕圈刷分却不干活」的数学形状。
>
> 核心命题：**把奖励当成一本分布式账本，而不是一个可信输入。** 每个奖励项必须携带可验证的来源与契约；塑形必须保守，或用「声明环流预算」显式记账；关于真实目标的不确定性拆成 aleatoric（偏好噪声，收紧）与 epistemic（规格歧义，去问）；而且——**奖励平面只能在一个已经通过 R69 安全认证的动作集合内重新排序，永远不能抬高安全下限、不能扩张安全集合、不能改变 λ 或认证前缀。** 命名 **LEDGER-RAS**（Ledgered Evidence-based Distributed Goal Evaluation & Reconciliation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我拿到的奖励，还是你当初想让我优化的东西吗**」——不确定性不只是刹车、提问，也可以是一次对账：这笔奖励，背后真的有活干过吗？

## 0. 直觉与动机

**灵感 1（ROS → 奖励是分布式铸币，不是标量输入）**
直觉：在 ROS 2 里，每条消息都带 `header.stamp`、QoS（reliability / deadline / lifespan / liveliness）、节点生命周期状态与参数版本。于是「一次奖励」天然是一笔**交易**：谁铸的（provenance）、什么时候铸的（freshness）、按哪版规范铸的（version）、经由哪条链路（topics）。这给出 R69 从未拥有的三个观测量。一笔通过了这三项检查的奖励才是「已承兑」的，否则只能「挂账」。具体到一台移动操作臂：nav2 的 costmap 给出「前进奖励」，MoveIt 的抓取节点给出「抓取成功奖励」，安全节点给出「危险罚分」，人类给出偏好排序——只要 costmap 话题被一个错误的时间源污染，机器人就可能在一个空货架间绕圈，一边累积「进展奖励」，一边什么都没送达。

**灵感 2（奖励设计 → 保守场与环流：Goodhart 的数学形状）**
直觉：势函数塑形 `F(s,s') = γΦ(s') − Φ(s)` 不改变最优策略，因为它沿任何轨迹**望远镜式抵消**。机器人若沿一条闭路回到同一状态，`∮F = 0`。反过来，若某个塑形项不是势差，就必然存在一条闭路使积分非零：机器人可以**绕这条环刷分而净任务进展为零**——这正是 specification gaming 的形状。妙处在于：我们不需要猜测设计者的意图，可以直接在状态转移图上**测量**环积分；再用溯源把非零环流**定位**到具体节点。一个哲学上含糊的概念（Goodhart）被降格为一个可计算、可定位的审计统计量。

**灵感 3（QoS → 陈旧奖励是「倒填日期的账」）**
直觉：用 500ms 前的世界状态算出的奖励，是对**过去**的奖励；把它用在**现在**，本质是控制延迟。而且延迟的目标往往比噪声更危险：噪声会被平均，延迟却会**自信地指向错误的方向**。ROS QoS 的 `deadline` 与 `lifespan` 恰好就是「此消息只在 Δt 内有效」的契约。于是奖励陈旧不再是悄无声息的工程细节，而是一次契约违约；它的性能代价有 Lipschitz-延迟上界可算。违约 ⇒ 奖励不再进入当拍决策，转入规格不确定性通道。

**灵感 4（规格不确定性 → aleatoric 偏好噪声 vs epistemic 规格歧义）**
直觉：R69 拆的是**测量**不确定性，本轮拆**目标**不确定性。有些目标不确定性不可约：人本身有噪声、会无所谓、答案随语境漂移——记为 `U_ale^pref`，对策是对可信集做风险敏感/极小极大后悔，而不是反复追问（问也问不出来）。有些可约：权重含糊、阶段信用不清、边界情形没定义——记为 `U_epi^spec`，对策是查溯源、核版本、问偏好。二者语义不同、通道不同，绝不做简单加和——与 R69 的姿态完全同构。

**灵感 5（查询是策略性的 → 奖励平面不能碰安全平面）**
直觉：一旦机器人会问「你更喜欢哪个」，人就变成一个**策略性输入**：他可能为了引导机器人而谎报，恶意第三方也可能代答。因此查询必须**激励相容**：成对随机、顺序反平衡、不显示会锚定答案的数值、只比较**已经认证**的行为。更关键的是，一次「是」绝不能等同于一次「允许」：**asked ≠ permitted**。安全由 R69 的证书决定，奖励只在证书之内重排序。这是 ROS 里「安全节点独立于规划器」的工程共识，被提升成一条定理（定理 19）。

**灵感 6（审计本身是新的攻击面 → 审计洗白）**
直觉：一旦我们宣称「本奖励已通过审计」，一个被攻陷的溯源链、一次时戳回拨、或一个**根本不在奖励基张成空间里的真实目标**，都会让审计签发一张漂亮但错误的健康证明。**审对了账，可能审错了世界。** 所以本轮必须同时交付：溯源真实性、可信奖励集、审计证书的「覆盖声明」，以及「审计失败即退回 R69」的硬退避——否则 LEDGER 会把「诚实的不知道」升级成「有证书的错误」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（LEDGER-RAS 总览）** LEDGER-RAS = (RPG, RQC, CCF, DEA, SUD, PRISM, RWM, RAS-WM§)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **奖励-安全隔离**：奖励信号只能作用于 `select_mode`，不得改变 λ、认证前缀 k 或安全包络；动作的安全证书与奖励值无关（定义 313）；
(iii) **奖励契约有效性**：仅当奖励项溯源完整、未过期、版本匹配、量程合法时才被承兑（定义 312）；
(iv) **保守性/记账纪律**：任一未声明环流超预算、或无背书奖励比例超阈，奖励层失效并退回 R69（定义 315–316、326）。

**定义 311（奖励溯源图 RPG）** 设 ROS 计算图 G=(V,E)，V=V_sense∪V_est∪V_ctrl∪V_reward∪V_verify。对每个奖励项 r_i，来源追溯 `prov(r_i) ⊆ V×E×ℝ` 是递归闭包（节点-边-时戳），一直回溯到传感器/人因/规范源。RPG 为 `(r_i, prov(r_i), header.stamp, ν_i, topic_i)` 组成的 DAG。要求 `prov(r_i)` 可验证（SROS2/DDS 安全签名或受信执行环境）；不可验证者状态记为 `unverifiable`，不得承兑。

**定义 312（奖励 QoS 契约 RQC）** 契约 `κ_i = (rate_i, deadline_i, τ_stale_i, ν_i^req, prov_i^req, [lo_i, hi_i])`。状态
`σ_i ∈ {valid, stale, version_skew, provenance_violation, out_of_range, unverifiable}`。
仅 `σ_i = valid` 的奖励项进入奖励平面。实时路径只做 O(|V_r|) 的契约检查；环流等重审计结论来自异步签发、带版本的证书。

**定义 313（奖励-安全平面隔离）** 安全证书 `C_safe(a)` 只依赖 `(o, U_ale, 未消解 U_epi, 标定)`（沿用 R69 定义 297、307），与任何 `r_i` 无关。奖励平面是一个选择映射
`Sel: 2^{𝒜_safe} × Θ → 𝒜_safe`，其中 `𝒜_safe = {a : C_safe(a)=True}`。
不变式：`∀θ, Sel(𝒜_safe,θ) ∈ 𝒜_safe`。因此奖励只能重排、不能放行；「问了」不等于「被允许」。

**定义 314（分布式塑形与势）** 局部奖励 `r_i` 诱导塑形 `F_i(s,s') = r_i(s,s') + γ_disc Φ_i(s') − Φ_i(s)`（可选）。全局 `F = Σ_i F_i`。称 `{F_i}` **共享势**，若 `∃Φ, ∀i: Φ_i = Φ + c_i`。称 `F` **保守**，若对状态转移图 `G_s` 上任意闭合轨迹 γ（`s_0=s_T`）环流为零。

**定义 315（奖励环流与声明预算）** `C(γ;F) = Σ_{t=0}^{T−1} F(s_t,s_{t+1})`。取环基 `{γ_j}`（由回放/转移图求得）表示全部环流。规范方声明预算 `C^decl(γ_j)`。审计量
`Undeclared(γ_j) = |C^obs(γ_j) − C^decl(γ_j)|`，`Viol ⇔ max_j Undeclared(γ_j) > τ_circ`。
超预算 ⇒ 存在「不干活也能刷分」的通道；用 RPG 定位贡献最大的节点集合（可解释的故障隔离）。

**定义 316（双分录奖励记账 DEA）** 每个奖励项必须引用一个可验证事件 `e`（如「物体位移 Δx」「目标到达」「接触建立」），事件由独立 verifier 节点写入 event ledger。背书值 `b(r_i) = min(r_i^+, v(e))`；无背书 `U_back = Σ_i max(0, r_i − b(r_i))`；比例 `ρ_back = U_back / (Σ_i r_i^+ + ε)`。`ρ_back > τ_back` ⇒ 奖励层失效。这是「铸币必须有实物背书」的对应。

**定义 317（目标不确定性二分 SUD）** 设奖励后验 `p(θ|𝒟)`（θ 含权重、势、奖励机转移、阶段信用）。定义
- `U_ale^pref = E_{θ~p}[ H(answer | θ, q) ]`：同一偏好在重复/交叉询问下的不可约分歧（偏好噪声）；
- `U_epi^spec = diam_{θ,θ'∈Θ_cred} d(a*_safe(θ), a*_safe(θ'))`：可信集内最优安全动作的**决策歧义**（不是参数熵，而是决策差）。
二者语义不同、通道不同（定义 326），不做简单加和。

**定义 318（可信奖励集 Θ_cred）** `Θ_cred = {θ : p(θ|𝒟) ≥ ε_θ ∧ 与已声明规范一致 ∧ 通过 RPG/DEA 审计}`。若真实目标不在 `Θ_cred` 的支撑内，则任何审计都无法发现——这正是本轮最大风险的正式位置（见 §6）。

**定义 319（决策论信息价值 VoI_d）** 对查询 q，结果 `y ~ p(y|q,θ)`：
`VoI_d(q) = E_y[ max_{a∈𝒜_safe} E_{θ|y} U(a,θ) ] − max_{a∈𝒜_safe} E_θ U(a,θ)`。
相较 R69 的熵型 VoI，这里只计「会改变安全集内决策」的信息；又因 `𝒜_safe` 与 θ 无关（定义 313），`VoI_d` 永远只衡量**对齐收益**，不衡量**安全收益**。

**定义 320（PRISM 偏好查询与激励相容）** 查询类型：成对偏好 `(a_i,a_j)`、权重澄清、阶段信用确认、否决/停止。许可条件：(a) 只比较两个**已认证**行为；(b) 成对随机化且顺序反平衡；(c) 不显示会锚定答案的数值奖励；(d) 单位时间 ≤ 1 次、注意力成本 ≤ c_q。激励相容：在「近视人、随机配对、机器人策略对报告单调」下，如实报告弱占优（命题 5）；非近视情形需承诺/复核，不作强假设。

**定义 321（奖励机 × 生命周期同步 RWM）** 奖励机 `𝒜_R=(Q,Σ,δ,ρ,q_0)`（Toro Icarte 式）承载阶段奖励；其守卫必须与 ROS 生命周期（configure/activate/deactivate/cleanup）和 `/clock` 对齐。阶段错配（如在 grasp 阶段用 deliver 奖励）由契约 `(phase_id, lifecycle_state)` 检测，记为 `phase_mismatch`，奖励层失效。

**定义 322（奖励滞后算子）** 观测奖励 `R^obs_t = R(s_{t−Δ}, s_{t−Δ+1})`，Δ 为时戳差。若 `Δ > τ_stale`（契约）则 `R^obs_t` 不进入当前决策，转 `U_epi^spec`。在 A100（奖励/动力学 `L_R`-Lipschitz，`γ_disc<1`）下，滞后引起的价值偏差 `≤ L_R·Δ/(1−γ_disc)`。

**定义 323（参与式审计 VQAuditor-L）** 审计对象新增：奖励溯源完整性、契约违反率、环流超预算、无背书比例、查询激励相容性、阶段错配。审计在异步平面运行（rosbag2 回放 + 环基增量更新）；实时环只读取已签名、带版本的审计证书。

**定义 324（威胁模型 ℰ_LEDGER）** `ℰ_LEDGER = ℰ_FLUID × ℰ_reward`，
`ℰ_reward = {奖励投毒/节点劫持，陈旧奖励，QoS 别名（把错误的量接到奖励话题），溯源伪造/时戳回拨，诱导性提问，策略性谎报，感知-奖励共谋，奖励机阶段混淆，奖励模型过拟合}`。

**定义 325（证书 J_LEDGER）** `J_LEDGER = (J_FLUID, audit_cert_hash, contract_violation_rate, circulation_p95, unbacked_ratio, U_spec_before/after, query_ic_score, reward_version, ledger_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ 审计证书未过期 ∧ 无环流超预算 ∧ ρ_back ≤ τ_back ∧ 契约违反率 ≤ τ_qos`。

**定义 326（两级目标退避与严格包含 R69）** 若 `U_epi^spec` 在预算内消解且审计有效：在 `𝒜_safe` 内按后验最大化期望效用（获得 **alignment bonus**）；若未消解/超时/审计失败/陈旧：目标退化为**保守目标** `U_cons`（最小化风险 + 最大化已验证进度下界，等价于忽略奖励、按 R69 的安全/证据选择）。⇒ 关闭奖励层时 LEDGER 与 R69 **逐指令相同**；安全侧不做任何让步。

```python
# IP-264 RPG：奖励溯源图（记录每条奖励的来源，构造 provenance DAG）
class RewardProvenanceGraph:
    def __init__(self, ros_graph): self.g = ros_graph      # V / topics / 时戳
    def provenance(self, r_msg):                            # 递归回溯到传感器/规范源
        return closure_over(self.g, r_msg.header.src, key='inputs')
    def localize(self, cycle):                              # 把非零环流落到具体节点
        return [v for v in self.g.nodes if v.contribution(cycle) != 0.0]

# IP-265 RQC：奖励 QoS 契约（新鲜度/版本/来源/量程），不满足即不承兑
def contract_status(r, now):
    if now - r.stamp > r.contract.tau_stale:            return 'stale'
    if r.version != r.contract.version_req:             return 'version_skew'
    if not subset(r.prov, r.contract.prov_req):         return 'provenance_violation'
    if not (r.contract.lo <= r.value <= r.contract.hi): return 'out_of_range'
    return 'valid'

# IP-266 CCF：环流审计（离线/异步，rosbag2 回放 + 环基；实时只读签名证书）
def circulation(traj_basis, F):
    return {g: sum(F(s, s2) for (s, s2) in gamma) for g, gamma in traj_basis.items()}

def conservative_ok(C_obs, C_decl, tau_circ):
    return all(abs(C_obs[g] - C_decl.get(g, 0.0)) <= tau_circ for g in C_obs)

# IP-267 DEA：双分录——每个奖励项必须引用可验证事件，无背书部分不计入
def double_entry(reward_items, event_ledger):
    unbacked = 0.0
    for r in reward_items:
        ev = event_ledger.match(r.evidence_id)
        backed = 0.0 if ev is None else min(r.value, ev.verified_value)
        unbacked += max(0.0, r.value - backed)
    return unbacked

# IP-268 SUD：目标不确定性二分（偏好噪声 vs 规格歧义）
def decompose_spec(posterior, safe_actions, answers):
    U_ale = expected_answer_entropy(answers)                 # 不可约偏好噪声
    a_star = {th: argmax_a E[U(a, th)] for th in posterior.credible()}
    U_epi = max_distance_over_values(a_star, safe_actions)   # 决策歧义，而非参数熵
    return U_ale, U_epi

# IP-269 PRISM：决策论 VoI 的偏好查询 + 激励相容 + 注意力预算
def choose_query(posterior, A_safe, budget, human):
    best = None
    for q in candidate_queries(posterior, A_safe):           # 只比较两个已认证行为
        if not budget.allow(q) or not ic_admissible(q):      continue
        voi = decision_voi(posterior, q, A_safe)             # E_y[max E[U|y]] - max E[U]
        score = voi - attention_cost(q, human)
        if best is None or score > best.score: best = (q, score)
    return best if best and best.score > 0 else None         # 无利可图 → 不问

    # --- R69 前缀：感知 / 标定 / 模态分解 / FMA / 交互消歧（逐项继承）---
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    # --- 1) 奖励通道：契约检查（实时，O(|V_r|)）---
    items  = M.rpg.collect(o.stamp)
    status = [M.rqc.check(r, o.stamp) for r in items]
    trust  = [r for r, s in zip(items, status) if s == 'valid']
    # --- 2) 审计平面（异步/离线）：环流 + 双分录 + 溯源，签发带版本证书 ---
    cert = M.audit_plane.latest_certificate()                 # 已签名、带版本，不阻塞实时
    # --- 3) 目标不确定性：可约则问；不可约/审计失败/陈旧则退保守目标 ---
    U_pref, U_spec = M.sud.decompose(trust, M.posterior, cert)
    q = (M.prism.choose_query(M.posterior, M.safe_modes, M.qbudget, M.human)
         if (U_spec > TAU_SPEC and cert.ok and not slow) else None)
    if q is not None:
        ans = M.prism.execute(q)                              # 只比较两个已认证行为
        M.posterior.update(q, ans)
        U_spec = M.sud.after(U_spec, q, ans)
    # --- 4) R69 安全平面：λ 与认证前缀完全不看奖励（定义 313）---
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if M.no_resolve else 0.0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., M.wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, M.k_cal_shrink(x_prime, U_cal))
    # --- 5) 奖励平面：仅在已认证的安全模态集合内重排序 ---
    safe_modes = M.c_ras_wm.certified_modes(modes, k, lam)
    if cert.ok and not slow and M.rqc.violation_rate() <= TAU_QOS:
        mode = M.ledger_select(safe_modes, M.posterior, U_spec, U_pref)
    else:
        mode = M.r69_select(safe_modes)                       # 退化：R69 的选择
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # --- 6) 参与式审计 + 证书（异步，不进入实时环）---
    M.vqa_l.submit_async(q, cert, U_pref, U_spec, items, status)
    return k, lam, mode, (U_ale, U_epi, U_pref, U_spec)
```

## 3. 推导

**引理 19（保守 ⇔ 势差；环流可判别）** 在 A99（episodic，`γ_disc=1`）下，`F` 保守（所有闭合轨迹环流为零）⇔ 存在 `Φ` 使 `F(s,s') = Φ(s') − Φ(s)`（连通转移图上）。证：必要性由望远镜求和；充分性沿闭合路径积分，闭合零积分保证两状态间积分与路径无关，据此定义 `Φ`。系：分布式塑形共享势 ⇔ 全局保守；任何非保守项必落在某个环基上，因而**可检测、可定位**。

**引理 20（奖励滞后上界）** A100 下，`|V*_{R^obs} − V*_R| ≤ L_R·Δ/(1−γ_disc)`。要点：把滞后奖励视为逐点 `≤ L_R·Δ` 的有界奖励扰动。系：ROS QoS 的 `deadline` 不是工程细节，而是**价值误差的预算单位**；`τ_stale` 应设为 `L_R` 与可接受价值误差之商。

**引理 21（无背书奖励与投毒上界）** 若 verifier 被攻陷概率 `δ_v`、节点与 verifier 共谋相关 `ρ<1`，则被承兑的伪造奖励比例 `≤ δ_v·ρ^{k−1} + ε_v`（k 个正交 verifier）。系：双分录把「奖励可信」从「相信奖励节点」降为「相信至少一个 verifier 的可验证事件」；单一被劫持的奖励节点无法凭空铸币。

**定理 18（奖励组合失真界）** 若局部势 `{Φ_i}` 最大不一致 `ΔΦ_max = max_{i,j}‖Φ_i−Φ_j‖_∞`，则全局塑形 `F` 与某个保守场之差逐点有界 `≤ 2 n_r ΔΦ_max`；故最优策略的真实价值失真 `≤ 2 n_r ΔΦ_max/(1−γ_disc)`（A100）。当 `ΔΦ_max=0` 时退化为 Ng 的策略不变性。⇒ 「各自设势」不是无害的工程自由，而是有量化代价的对齐漂移。

**定理 19（奖励-安全隔离与严格包含 R69）** 由定义 313，`Sel` 的值域 `⊆ 𝒜_safe`，故 LEDGER 的动作风险 `≤` R69 对同一模态的风险（λ、k 不变）；当审计有效、`U_epi^spec` 已消解、目标为名义奖励时，LEDGER 的选择在 R69 的安全/证据等价类内取最大期望效用；关闭奖励层则**逐指令等于 R69**。⇒ 新层是旧层在「奖励可信且用户可问」边界上的严格泛化。

**命题 5（PRISM 的弱激励相容）** 在近视人、随机配对、策略对报告单调的条件下，如实报告弱占优；若人非近视或能影响未来查询集合，则一般不存在无须承诺的诚实机制。系：不把查询当验证，只当似然；R69 的 `k` 源一致证据纪律继续适用。

## 6. 本轮最大风险

**一句话**：LEDGER-RAS 的全部收益押在「溯源图可信 + 真实目标落在声明奖励基的张成空间内」这两个前提上——**若溯源可伪造、时钟可回拨，或真实目标本就是奖励基之外的「规格缺口」而非「缺陷」，审计会把一本错误的账审得干干净净**；于是系统拿到一张「已对齐」的证书继续自信地优化错误目标——**审计洗白（audit laundering）比不审计更危险**，因为它把一个可被发现的分歧伪装成了已核验的共识。

**次级风险与缓解**：
1. **溯源伪造 / 时戳回拨** → SROS2/DDS 签名 + 受信时钟 + 证书覆盖声明（定义 311、325）；
2. **非保守塑形被当成合法** → 声明环流预算 + 环流超预算即退回 R69（定义 315、326）；
3. **奖励节点劫持/共谋** → 双分录 + k 个正交 verifier + 引理 21 上界；
4. **策略性谎报 / 诱导性提问** → PRISM 的随机反平衡 + 只比较已认证行为 + 命题 5 的弱 IC 边界；
5. **审计层自身成为实时负担** → 环流与回放全部放到异步审计平面，实时只读签名证书（定理 19 不依赖审计时延）；
6. **规格缺口（真实目标不在奖励基内）** → 这是原理性盲区：只能靠「不确定就退回保守目标 + 显式标注审计覆盖范围」把伤害限制在效率侧，绝不冒险扩大安全集合。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** LEDGER-RAS = (RPG, RQC, CCF, DEA, SUD, PRISM, RWM, RAS-WM§)；零学习写操作继承 R69；**奖励-安全隔离**（奖励只作用于 `select_mode`，不改 λ/k/包络）；**契约承兑**（仅 valid 奖励进入平面）；**保守/记账纪律**（未声明环流或无背书超阈即退回 R69）。

**定义 311–312（RPG 与 RQC）** 每条奖励回溯到 `(节点,话题,时戳,版本)` 的 provenance DAG，要求签名可验证；契约 `κ_i` 检查 freshness/deadline/version/provenance/量程，状态非 `valid` 即不承兑。实时只做 O(|V_r|) 检查，重审计异步。

**定义 313（奖励-安全隔离）** `C_safe(a)` 只依赖 `(o,U_ale,未消解 U_epi,标定)`，与奖励无关；`Sel` 值域 `⊆𝒜_safe`。**asked ≠ permitted**。

**定义 314–315（势、保守性与环流）** `F_i=r_i+γΦ_i(s')−Φ_i(s)`；共享势 ⇒ 全局保守；`C(γ;F)=∮F`，`Undeclared=|C^obs−C^decl|>τ_circ` ⇒ 存在「绕圈刷分」通道，用 RPG 定位故障节点。

**定义 316（双分录）** 奖励须引用可验证事件 `e`；`b=min(r^+,v(e))`，`U_back=Σmax(0,r−b)`，`ρ_back=U_back/(Σr^++ε)>τ_back` ⇒ 奖励层失效。

**定义 317–318（SUD 与可信集）** `U_ale^pref=E[H(answer|θ,q)]`（不可约）；`U_epi^spec=diam_{Θ_cred} d(a*_safe(θ),a*_safe(θ'))`（决策歧义）；`Θ_cred` 为后验+规范一致+审计通过之集。

**定义 319–320（VoI_d 与 PRISM）** `VoI_d(q)` 只计安全集内决策改变；查询只比较两个已认证行为、随机反平衡、无锚定、有注意力预算；近视+单调+随机配对下如实报告弱占优。

**定义 321–322（RWM 与滞后）** 奖励机守卫与 ROS 生命周期、`/clock` 对齐，阶段错配即失效；`R^obs_t=R(s_{t−Δ})`，`Δ>τ_stale` 即转 `U_epi^spec`，价值偏差 `≤L_RΔ/(1−γ_disc)`。

**定义 323–325（审计/威胁/证书）** VQAuditor-L 审计溯源/契约/环流/背书/IC；`ℰ_LEDGER=ℰ_FLUID×ℰ_reward`；`J_LEDGER` 并入审计证书哈希、环流 p95、无背书率、U_spec 前后、IC 分、奖励版本。

**定义 326（两级目标退避）** 消解成功 → 安全集内最大化期望效用（alignment bonus）；未消解/超时/审计失败/陈旧 → 保守目标 `U_cons`（忽略奖励，按 R69 选择）⇒ 关闭奖励层逐指令等于 R69。

```python
# IP-265 RQC：契约检查（新鲜度/版本/来源/量程）
def contract_status(r, now):
    if now - r.stamp > r.contract.tau_stale:            return 'stale'
    if r.version != r.contract.version_req:             return 'version_skew'
    if not subset(r.prov, r.contract.prov_req):         return 'provenance_violation'
    if not (r.contract.lo <= r.value <= r.contract.hi): return 'out_of_range'
    return 'valid'

# IP-266 CCF：环流审计（离线 rosbag2 回放 + 环基；实时只读签名证书）
def circulation(traj_basis, F):
    return {g: sum(F(s, s2) for (s, s2) in gamma) for g, gamma in traj_basis.items()}

def conservative_ok(C_obs, C_decl, tau):
    return all(abs(C_obs[g] - C_decl.get(g, 0.0)) <= tau for g in C_obs)

# IP-267 DEA：双分录（无背书奖励不计入）
def double_entry(items, ledger):
    return sum(max(0.0, r.value - min(r.value, (ledger.match(r.evidence_id) or E0).verified_value))
               for r in items)

# IP-268 SUD：目标不确定性二分
def decompose_spec(post, A_safe, answers):
    U_ale = expected_answer_entropy(answers)
    a_star = {th: argmax_a E_U(a, th) for th in post.credible()}
    return U_ale, max_distance_over_values(a_star, A_safe)

# IP-269 PRISM：决策论 VoI 查询 + 激励相容 + 注意力预算
def choose_query(post, A_safe, budget, human):
    best = None
    for q in candidate_queries(post, A_safe):                # 只比较两个已认证行为
        if not budget.allow(q) or not ic_admissible(q):      continue
        score = decision_voi(post, q, A_safe) - attention_cost(q, human)
        if best is None or score > best.score: best = (q, score)
    return best if best and best.score > 0 else None          # 无利可图 → 不问

# IP-274 主闭环（继承 R69；奖励只在安全集内重排序）
def LEDGER_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_action, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    items, status = M.rpg.collect(o.stamp), None
    status = [M.rqc.check(r, o.stamp) for r in items]
    trust  = [r for r, s in zip(items, status) if s == 'valid']
    cert   = M.audit_plane.latest_certificate()               # 异步签名证书
    U_pref, U_spec = M.sud.decompose(trust, M.posterior, cert)
    q = (M.prism.choose_query(M.posterior, M.safe_modes, M.qbudget, M.human)
         if (U_spec > TAU_SPEC and cert.ok and not slow) else None)
    if q is not None:
        M.posterior.update(q, M.prism.execute(q)); U_spec = M.sud.after(U_spec, q)
    lam = max(M.efs.risk_scale(...), lam_floor(U_ale + (U_epi if M.no_resolve else 0.0)))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(x_prime, M.vista.H), ..., M.wm_preds)
    if slow: lam = max(lam, 0.8); k = min(k, M.k_cal_shrink(x_prime, U_cal))
    safe_modes = M.c_ras_wm.certified_modes(modes, k, lam)
    mode = (M.ledger_select(safe_modes, M.posterior, U_spec, U_pref)
            if (cert.ok and not slow and M.rqc.violation_rate() <= TAU_QOS)
            else M.r69_select(safe_modes))                    # 退化：R69
    tau = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_l.submit_async(q, cert, U_pref, U_spec, items, status)
    return k, lam, mode, (U_ale, U_epi, U_pref, U_spec)
```

## 4. 推导

**引理 19（保守 ⇔ 势差）** A99（episodic，`γ_disc=1`）下，`F` 在所有闭合轨迹上环流为零 ⇔ `F` 是某个 `Φ` 的势差。证：望远镜求和（必要性）+ 路径无关性定义 Φ（充分性）。系：非保守项必落在环基上，可检测、可定位。

**引理 20（奖励滞后上界）** A100（`L_R`-Lipschitz，`γ_disc<1`）下，`|V*_{R^obs}−V*_R| ≤ L_R·Δ/(1−γ_disc)`。系：QoS 的 `deadline` 是价值误差的预算单位。

**引理 21（无背书与投毒上界）** verifier 被攻陷 `δ_v`、相关 `ρ<1` 时，被承兑伪造奖励比例 `≤ δ_v·ρ^{k−1}+ε_v`。系：单一被劫持奖励节点无法凭空铸币。

**定理 18（奖励组合失真界）** 局部势最大不一致 `ΔΦ_max` 时，全局塑形与某保守场逐点差 `≤ 2n_rΔΦ_max`，故真实价值失真 `≤ 2n_rΔΦ_max/(1−γ_disc)`；`ΔΦ_max=0` 退化为 Ng 策略不变性。系：各自设势有量化的对齐漂移代价。

**定理 19（奖励-安全隔离与严格包含 R69）** `Sel` 值域 `⊆𝒜_safe`，故 LEDGER 动作风险 `≤` R69 对同一模态的风险；审计有效且 `U_epi^spec` 消解时，在 R69 的安全/证据等价类内取最大期望效用；关闭奖励层逐指令等于 R69。安全不让步，效率获 alignment bonus。

**命题 5（PRISM 弱激励相容）** 近视人 + 随机配对 + 策略对报告单调 ⇒ 如实报告弱占优；非近视/可影响未来查询时一般无无须承诺的诚实机制。系：查询只当似然，证据纪律继续适用。

## 7. 本轮最大风险

**一句话**：LEDGER-RAS 的收益押在「溯源可信 + 真实目标落在声明奖励基内」上——**若溯源可伪造、时钟可回拨，或真实目标本就是奖励基之外的规格缺口，审计会把错误账本审得干干净净**；系统拿到「已对齐」证书继续优化错误目标——**审计洗白比不审计更危险**，它把可被发现的分歧伪装成已核验的共识。

**次级风险与缓解**：溯源伪造/时戳回拨（SROS2 签名 + 受信时钟 + 覆盖声明）；非保守塑形被合法化（声明环流预算 + 超阈退回 R69）；节点劫持/共谋（双分录 + k 正交 verifier + 引理 21）；策略性谎报/诱导（PRISM 随机反平衡 + 只比已认证行为 + 命题 5 弱 IC 边界）；审计拖垮实时（环流/回放全异步，实时只读证书）；规格缺口（原理性盲区：退保守目标 + 显式标注审计覆盖范围，只在效率侧让步）。
