研究循环·新灵感二元组第 1 轮；本轮灵感：「关节空间控制」×「触觉感知」

> **基线**：第 4 轮产出 MetricVoiceGauge-NCD-HUTDH-v23 + IP-436–440（FTAC/CRA/CFS/SLCR/HPC-EC），其上承 v22 物理接地-能量层（HDL/ACSC/DCSC/HPC-E/CFC++）、v21 语义-规范层（SDC/CAC/DCL/GIC/HPC+/CFC+）、v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）、v19（DCM/OGCC/CCV/DRS/OGC）与 v17 感知链（CLP/S2C/HCG/PSV/APS/AMC）。
> 本轮纪律：**关节空间控制把安全从"笛卡尔空间的几何预测"下移到"配空间的力矩/能量流"；触觉感知把"接触"从必须避免的事故，变成一张有界、可审计、可赎回的证书**。不推倒 v23：FTAC/CRA/CFS/SLCR/HPC-EC 一个都不删。本轮只做一件事：**在 v23 之上加一层"接触时"证书层，把"安全 = 永不接触"升级为"安全 = 避免接触 ∨ 有界且被动的接触"，并用本体感受（关节力矩残差）作为与视觉结构独立的在场证据，去封堵 v23 的循环认证风险**。

## 0. 直觉与动机

**灵感 1（关节空间控制 → 安全的最低层是力矩与能量，而不是位置）**
直觉：v17–v23 的安全几乎全部定义在**笛卡尔空间的位置**上：Hull、CertBox、自由空间、AbsCert——它们都在回答"这个位置会不会碰到"。但位置是**预测**出来的，一旦现实偏离预测（标定漂移、模型误差、灯变、人动了），位置证书当场失效。关节空间控制揭示了一个更深的层次：真正决定"会不会造成伤害"的不是"末端在哪个位置"，而是**关节上流过了多少力矩、系统交换了多少能量**。核心创新：**关节空间安全证书 (Joint-Space Safety Certificate, JSC)**——把安全包络从笛卡尔空间下移到配空间 `Q_safe = {q : q∈[q_min,q_max], |q̇|≤q̇_max, |τ|≤τ_max, 可操作度 μ(q) ≥ μ_min}`，用一个"安全配空间管道 (tube)"逐时刻认证 `q(t) ∈ Q_safe(t)`，并规定控制器**在关节空间**执行力矩/阻抗控制（而非笛卡尔位置控制），使接近奇异位形、接触、被推挤时仍保持可分析性。关键反直觉点：**笛卡尔空间的"安全位置"在奇异位形附近会放大成任意大的关节力矩——位置看起来安全，力矩已经危险；把安全定义在配空间，奇异位形就变成一条可显式约束的边界，而不是藏在逆运动学里的定时炸弹**。

**灵感 2（关节空间控制 → 被动性：唯一不依赖任何模型的硬保证）**
直觉：v22 的 EVC 管的是"任务能量储备够不够"（预测性、依赖模型）；但真正在"所有感知都失效"时还成立的，是**被动性 (passivity)**：一个被动控制器 + 一个被动的人体，耦合系统的总能量只减不增，于是任何接触都不会让机器人"失控地把能量灌进人身上"。核心创新：**被动性/能量槽证书 (Passivity & Energy-Tank Certificate, PPC)**：在关节空间维护能量槽 `E_tank`，控制器只允许从槽里支取能量（`τ = τ_task + τ_imp − τ_damp`，且槽的支取受 `−P_out` 记账约束），当槽见底时退化为纯阻尼（安全但保守）。关键反直觉点：**PPC 不预测任何东西，它只保证"注入耦合系统（含人）的能量有上界"——这正是 v21 AbsCert、v22 EVC、v23 FTAC 全部押在经验假设上时所缺的那条"不依赖假设"的底线。它不替代那些证书，它是它们崩掉时唯一还在的安全网**。

**灵感 3（触觉感知 → 接触不是事故，是一张可审计的证书）**
直觉：在 v23 里，任何接触都会触发 SafeStop——绝对安全，但把活性直接打到零（SLCR 记为 ∞）。可现实中的交互（交接、擦拭、人扶着机器人走、拥挤环境里的擦碰）**必然有接触**。触觉感知提供了一种全新的可能：**有界的接触是安全的**。核心创新：**接触合法性证书 (Contact Legality Certificate, CLC)**：把一次接触事件 `c=(t, p_c, F(t), J_imp, A_patch, slip)` 编译为四条可机械复核的判据——峰值力 `‖F‖≤F_safe(class)`、冲量 `J_imp=∫‖F‖dt≤J_safe`、局部压强 `‖F‖/A_patch ≤ P_safe`、接触位置 `p_c ∈ R_allow` 且滑移 `slip≤s_max`；且 `F_safe/J_safe/P_safe` 随**人群**调整（儿童/老人/骨质疏松的阈值远低于成人）。合法 ⇒ 进入柔顺模式（阻抗 + 零空间让位）继续任务；非法 ⇒ SafeStop。关键反直觉点：**把接触从"违规"改判为"合法接触 / 非法接触"两类，是把 v23 的"零活性兜底"换成了"有界活性兜底"——安全性不变（非法照样停），活性从 ∞ 成本降到有限成本，这恰恰是 v23 SLCR 想解决却没法解决的那件事**。

**灵感 4（触觉感知 → 本体感受是与视觉结构独立的在场证据，专治 v23 的循环认证）**
直觉：v23 最大的风险是"竞品和我们共享同一个视觉盲区"——所有光学检测器都可能同时漏掉一个逆光里的孩子。但**物理接触不经过视觉**：一个孩子如果碰到了机器人，关节力矩残差 `r(t)` 和皮肤信号一定会响应，无论视觉看没看见。核心创新：**接触锚定的障碍证据 + 接触增强缺席证书 (Contact-Augmented Absence, CAC-C)**：广义动量观测器给出 `r(t)`，超过阈值即估计接触点 `p_c`；`p_c` 是**被物理证明存在**的障碍点（你摸到了它，它一定在），可直接并入 `Obs_t`；并且 **AbsCert 在签发前必须查询本体感受与皮肤通道——一旦有任何接触/在场地证据，缺席证书拒绝签发并翻转为"有人"**。关键反直觉点：**视觉说"没人"可以被逆光骗过，力矩说"我撞到了东西"骗不过——接触通道不解决"从没碰到过的漏检"，但它把"缺席幻觉"的持续时间和后果从"撞上"压缩到"擦碰即停/柔顺让位"，并把"存在"从概率命题升级为物理事实**。

**如何统一（"避让-接触"二择一）**
统一为 **v23 之上的接触接地安全层 (Contact-Grounded Safety Layer, CGSL)**：JSC/PPC 管"移动与接触时力矩/能量是否在界内"，CLC 管"这次接触是否合法"，PMO/CAC-C 管"用不经过视觉的通道证明有人在"。安全谓词从 v23 的 **"永不接触"** 升级为 **`Safe_v24 = GeometricAvoid ∨ (CLC ∧ PPC)`**——**要么几何上避开，要么接触但有界且被动**。这不是放宽安全，而是把"零活性兜底"（SafeStop）替换成"有界活性兜底"：两者都保证无界伤害为零，但后者成本有限。统一准入门升级为 **`HPC-JCT = HPC-EC ∧ JSC ∧ (GeometricAvoid ∨ CLC) ∧ PPC`**（任一不可满足则退 SafeStop）。共享状态扩展为 `ζ_cgsl = ζ_accl ∪ (q, q̇, τ, E_tank, r_residual, contact_log, F_safe/人群, skin_evidence)`。**安全继承以"伤害序"而非"计划集包含"表达**（详见 §3 与引理 173）：`Exec^plan_v24 ⊆ Exec^plan_v23`（不在自由空间新增任何计划），且 `Harm_v24 ⊆ Harm_v23 = ∅`——本层只在被迫接触时把兜底从停机换成柔顺，绝不新增接触前的冒险。

## 1. 研究问题（轮次升级版）

- **Q17（配空间安全管道的紧致性）**：如何在关节限位、速度限位、力矩限位与可操作度 `μ(q) ≥ μ_min` 下认证一条 `Q_safe(t)` 管道，且其膨胀不把 JSC 变成新的活性杀手？管道如何与 v20/v21 的笛卡尔 CertBox/Hull 取交而非叠加（避免双重保守）？

- **Q18（本体感受的灵敏度地板与误报）**：广义动量观测器残差 `r(t)` 的阈值 `r_thr` 如何在摩擦力建模误差、负载变化、温漂下标定？**缓慢轻触**（儿童轻轻靠上来、力持续但 `r<r_thr`）的灵敏度地板如何量化并显式记账？模型误差引起的假接触如何保证只向保守方向退化？

- **Q19（接触合法性的阈值与人群）**：`F_safe/J_safe/P_safe` 如何从 ISO/TS 15066 的成人准静态/瞬态限值推导出**按人群下调**的阈值（儿童/老人/骨质疏松），并在在线无法确定人群时取最低阈值？接触面积 `A_patch` 未知时如何给出压强的上界（用最小可辨面积 = 最坏压强）？交接许可型接触与意外碰撞型接触为何要走**非对称阈值**？

- **Q20（被动性与能量槽的活性）**：能量槽见底触发纯阻尼后如何安全回补而不产生 Zeno/极限环（froop 振荡）？被动性只界总能量、不界局部压强，这一"充分非必要"的缺口如何由 CLC 补齐而不产生循环依赖？

- **Q21（接触锚定证据与缺席证书的耦合）**：接触点 `p_c` 如何以误差界 `ε_contact` 并入 `Obs_t` 并撤销邻域 AbsCert？假接触（模型误差）只会增障碍、不会误撤自由空间的证明是什么？接触增强究竟把 v23 循环认证风险的**持续时间/后果**压缩了多少（可量化指标）？

- **Q22（从笛卡尔证书到关节力矩的编译）**：HPC-E/HDL/PGEV 的笛卡尔与能量约束如何编译成关节空间的力矩/速度包络，既不越安全门又不额外吃掉活性？可审计性：`contact_log / E_tank 轨迹 / 阈值版本 / 人群估计` 如何入 merkle 链做确定性重放与追责？

## 2. 设计原则（在 P43–P46 基础上新增 P47–P51）

**P47 配空间安全下移律（Safety-in-Joint-Space）**
任何笛卡尔安全证书都必须与关节空间包络求交后才可执行：`Exec ⊆ {q(t) : q(t) ∈ Q_safe(t)}`，其中 `Q_safe` 同时约束关节限位、速度、力矩与可操作度 `μ(q) ≥ μ_min`。控制器在关节空间以力矩/阻抗律执行。JSC 失效（无法认证管道）⇒ 退回纯阻尼（最保守），故本律只收缩、不扩张。

**P48 被动性兜底律（Passivity as Last Resort）**
维护能量槽 `E_tank ≥ 0`，控制器支取能量须记账；`E_tank` 见底即退纯阻尼。被动性保证 `∫ F^T ẋ dt ≤ E_tank^max`，**不依赖任何感知/检测/模型**。但**被动性只界能量、不界局部压强**（明确列为充分非必要），故 PPC 必须与 CLC 联用，且 PPC 失效 ⇒ 停机。

**P49 接触合法性律（Contact Legality, Not Contact Prohibition）**
接触分两类：合法（力/冲量/压强/位置/滑移全在界内）⇒ 柔顺模式（阻抗 + 零空间让位）；非法或无法认证 ⇒ SafeStop。阈值按人群 `class∈{adult,child,elderly,fragile}` 下调，类别不确定时取最低。`R_allow`（如交接目标区）之外一律非法。合法接触的可达区域 ⊆ `GeometricCertified ∪ R_allow`，绝不越过几何证书边界。

**P50 非视觉在场证据律（Non-Optical Presence Evidence）**
本体感受残差 `r>r_thr` 或皮肤接触是**声音的在场见证**（无假缺席，只可能有假存在→保守）。任何此类证据都撤销 `AbsCert` 并禁止"缺席"声明；`p_c` 只并入 `Obs_t`、从不移除障碍。故接触通道只增障碍、只撤自由空间，安全方向不变。

**P51 有界-活性兜底律（Bounded-Liveness Fallback）**
仅在伤害有界的方向上，用 `CLC`-合法柔顺模式替换 `SafeStop`：`Harm` 界不变（两者皆无界伤害为零），活性成本严格下降（`Cost(SafeStop)=∞ > Cost(CLC)<∞`）。形式化为**伤害序细化**而非计划集包含：`Exec^plan_v24 ⊆ Exec^plan_v23` 且 `Harm_v24 ⊆ Harm_v23 = ∅`。

## 3. 与基线的接口（如何退化）

- JSC 失效（管道无法认证/配空间估计丢失）⇒ 退回纯阻尼 + 笛卡尔几何证书（v23）⇒ 更保守；
- PMO 失效（无力矩估计）⇒ 无本体感受证据 ⇒ 退化为纯视觉 v23（缺席幻觉可能延续，但不比 v23 差）；
- CLC 无法认证（无 F/T、无皮肤或接触面积不可测）⇒ 接触一律 SafeStop ⇒ 等价 v23；
- PPC 失效（能量槽监控失效）⇒ 纯阻尼/停机 ⇒ 比 v23 更保守；
- 人群分类不确定 ⇒ 取最低阈值 ⇒ 更保守；
- CAC-C 失效 ⇒ 缺席证书退回仅依赖视觉 κ_c ⇒ 等价 v21/v23；
- 全失效 ⇒ 完全回退 v23，`Harm = ∅` 仍成立。
- **安全继承（伤害序 + 避让分支计划子集）**：JSC 只收缩配空间；PPC 只减弱注入能量；CLC 只在合法时把停机换成柔顺（非法仍停）；PMO/CAC-C 只增障碍、只撤缺席。故 `Exec^plan_v24 ⊆ Exec^plan_v23`（自由空间不新增计划）且 `Harm_v24 ⊆ Harm_v23 = ∅`，接引理 170/173。DCL/GIC/APs 新鲜度阶梯原样保留，CLC/PPC 以事件方式接入，控制路径仅 O(1) 查询。

## 4. 预期贡献

1. **配空间安全证书（JSC）**：把安全包络从笛卡尔位置下移到关节限位/速度/力矩/可操作度四重约束的安全配空间管道，消除奇异位形处"位置安全、力矩致命"的落差；
2. **被动性兜底（PPC）**：给出唯一不依赖任何感知/模型/假设的硬保证——注入耦合系统能量有上界；并诚实标注其"只界能量不界压强"的充分非必要缺口；
3. **接触合法性证书（CLC）**：把接触从事故事件重构为力/冲量/压强/位置/滑移五判据 + 人群自适应阈值，首次让"有界接触"成为合法且可审计的安全态；
4. **非视觉在场证据（PMO/CAC-C）**：用广义动量残差与皮肤接触作为与视觉结构独立的在场见证，物理性封堵 v23 的"循环认证/缺席幻觉"——把其后果从"撞上"压缩到"擦碰即柔顺/停"；
5. **避让-接触二择一语义（`Safe_v24 = GeometricAvoid ∨ (CLC ∧ PPC)`）与伤害序继承**：把"安全 = 永不接触"升级为"避免或合法接触"，并以 `Harm` 序而非计划集包含给出可证明的严格继承；
6. **HPC-JCT 统一门**：`HPC-EC ∧ JSC ∧ (GeometricAvoid ∨ CLC) ∧ PPC`，实现"有界活性兜底"，在零无界伤害前提下把兜底成本从 ∞ 降到有限。

## 5. 本轮最大风险

**一句话**：被动性只约束**交换的总能量**，不约束**局部压强/峰值力**，而 `F_safe/J_safe/P_safe` 又来自成人人群的生物力学阈值——一张"被动合规、能量有界"的接触证书，仍可能在一个儿童或骨质疏松者身上造成局部挤压伤；更糟的是本体感受对**缓慢轻触**（孩子轻轻靠上来）存在灵敏度地板、触觉皮肤又有覆盖缺口，于是"接触证明存在"这条最后的物理底线也可能被"太轻而没感觉"绕过——即"被能量界掩盖的、感觉不到的局部致伤"。

## 1. 关键算法骨架（在 IP-436–440 骨架上扩展）

```python
# IP-441 关节空间安全证书：管道认证 + 关节空间阻抗/力矩控制
class JointSpaceSafetyCertificate:
    def __init__(self, robot, mobs_min=1e-3, margin=1.05):
        self.robot = robot
        self.mu_min = mobs_min
        self.margin = margin                      # 管道膨胀余量

    def in_safe_tube(self, q, qdot, tau):
        lim = self.robot.joint_limits            # [q_min, q_max]
        if not all(lim[0][i] <= q[i] <= lim[1][i] for i in range(len(q))):
            return False, "JOINT_LIMIT"
        if any(abs(qdot[i]) > self.robot.qdot_max[i] for i in range(len(q))):
            return False, "VELOCITY_LIMIT"
        if any(abs(tau[i]) > self.robot.tau_max[i] for i in range(len(tau))):
            return False, "TORQUE_LIMIT"
        if manipulability(self.robot.jacobian(q)) < self.mu_min * self.margin:
            return False, "SINGULARITY"          # 奇异位形显式约束
        return True, "OK"

    def torque_command(self, q, qdot, q_des, tau_task):
        # 关节空间阻抗 + 阻尼；所有输出先过 Q_safe 校验
        tau = tau_task + self.Kp * (q_des - q) - self.Kd * qdot
        ok, why = self.in_safe_tube(q, qdot, tau)
        if not ok:
            tau = -self.Kd * qdot                 # 退纯阻尼（最保守）
        return tau, why


# IP-442 广义动量观测器：不经过视觉的接触检测与定位
class ProprioceptiveMomentumObserver:
    def __init__(self, robot, K_O=50.0, r_thr=None):
        self.robot = robot
        self.K_O = K_O
        self.r_thr = r_thr or self._calibrate_friction_bound()

    def update(self, q, qdot, tau_cmd, dt, r_prev):
        # r(t) = K_O ( M(q)q̇ − ∫(τ_cmd + C^T q̇ − g + r) dt )
        p = self.robot.M(q) @ qdot
        p_dot_pred = tau_cmd - self.robot.C(q, qdot).T @ qdot - self.robot.g(q) + r_prev
        r = self.K_O * (p - (self._p_int + p_dot_pred * dt))
        self._p_int += p_dot_pred * dt
        return r

    def contact(self, r):
        if norm(r) <= self.r_thr:
            return None                           # 在灵敏度地板下：可能漏检轻触
        # 由外力矩反演接触点：τ_ext ≈ J(q)^T F ⇒ F ≈ (J^T)^+ τ_ext
        F = pinv(self.robot.jacobian(self._q).T) @ r
        p_c = forward_kinematics(self._q) + self.robot.jacobian(self._q) @ pinv(
            self.robot.jacobian(self._q)) @ self._tip_offset
        return ContactEvent(t=self._t, r=r, p_c=p_c, F=F,
                            eps_contact=self.eps_contact)

    def _calibrate_friction_bound(self):
        # r_thr 取空载运动中 |r| 的高分位 + 摩擦/温漂模型误差上界
        return friction_model_error_bound(self.robot) + self.robot.disturbance_q99


# IP-443 接触合法性证书：人群自适应五判据 + 柔顺/停机
class ContactLegalityCertificate:
    def __init__(self, R_allow, class_fn, min_patch_area=1e-4):
        self.R_allow = R_allow
        self.class_fn = class_fn                  # 人群估计（返回 class 或 None）
        self.A_min = min_patch_area               # 最坏压强：用最小可辨面积

    def thresholds(self, cls):
        base = ISO_TS_15066_limits(cls or "adult")
        chi = CHI_VULN.get(cls, 1.0)              # 儿童/老人/骨质疏松 χ<1
        return base.scale(chi)

    def is_legal(self, c, skin_patch=None):
        cls = self.class_fn()
        th = self.thresholds(cls)                 # 类别不确定→取最低阈值
        A = max(skin_patch.area if skin_patch else 0.0, self.A_min)
        checks = {
            "force":    norm(c.F) <= th.F_safe,
            "impulse":  c.J_imp <= th.J_safe,
            "pressure": norm(c.F) / A <= th.P_safe,   # 压强用最坏面积上界
            "location": c.p_c in self.R_allow,
            "slip":     c.slip <= th.s_max,
        }
        legal = all(checks.values())
        self._log(c, cls, th, checks, legal)
        return legal, checks

    def respond(self, c, legal, accepted, jac, qdot):
        if not legal:
            return "SAFE_STOP"
        # 合法接触：零空间让位（顺人方向屈服，任务子空间尽量保持）
        N = np.eye(len(qdot)) - pinv(jac) @ jac
        return ("COMPLIANT_YIELD", N @ c.F)        # 只在零空间让位


# IP-444 被动性 / 能量槽证书
class PassivityEnergyTankCertificate:
    def __init__(self, E_tank_init, damping_only):
        self.E = E_tank_init
        self.pure_damping = damping_only

    def step(self, tau_cmd, qdot, dt, P_out):
        # 只允许支取槽内能量：Ė = −τ_cmd·q̇ − P_out；见底退纯阻尼
        self.E += -(tau_cmd @ qdot) * dt - P_out * dt
        if self.E < 0:
            self.E = 0.0
            return self.pure_damping(qdot), False, "TANK_EMPTY_DAMPING"
        return tau_cmd, True, "OK"

    def passive_bound(self, F, xdot):
        # 审计用：累计注入耦合系统的能量不得超过 E_tank^max
        return integral_le(self.E_max, F, xdot)


# IP-445 接触增强缺席：接触即存在，撤销 AbsCert，锚定障碍
class ContactAugmentedAbsence:
    def __init__(self, abs_cert, obs_set):
        self.abs = abs_cert
        self.obs = obs_set

    def on_evidence(self, contact=None, skin=None):
        if contact is not None:
            # p_c 是物理证明存在的障碍点：并入障碍（全部标签都为 person，
            # 因为力矩只证存在不证语义），并以 ε_contact 膨胀
            self.obs.add_sphere(contact.p_c, contact.eps_contact, label="person")
            self.abs.revoke(region=ball(contact.p_c, contact.eps_contact))
        if skin is not None and skin.contact_detected:
            self.obs.add_sphere(skin.p_c, skin.eps_contact, label="person")
            self.abs.revoke(region=ball(skin.p_c, skin.eps_contact))

    def can_issue_absence(self, region, contact_channel, skin_channel):
        # 签发前必查非视觉通道：任何在场证据→拒绝
        if contact_channel.has_evidence(region) or skin_channel.has_evidence(region):
            self.abs.revoke(region)               # 翻转为"有人"
            return False
        return self.abs.valid(region)


# IP-446 HPC-JCT 统一准入门：避让或合法接触
@dataclass
class HPCJCT:
    hpc_ec: HPCEC
    jsc: JointSpaceSafetyCertificate
    pmo: ProprioceptiveMomentumObserver
    clc: ContactLegalityCertificate
    ppc: PassivityEnergyTankCertificate
    cac_c: ContactAugmentedAbsence

    def admits_motion(self, plan, state):
        # 接触前：只认 v23 的几何避让（不新增冒险计划）
        if not self.hpc_ec.admits(plan, state):
            return False, "NO_GEOMETRIC_AVOID"
        ok, why = self.jsc.in_safe_tube(state.q, state.qdot, state.tau)
        if not ok:
            return False, f"JSC:{why}"
        return True, "GEOMETRIC_AVOID"

    def admits_contact(self, contact, skin):
        # 接触后：要么 CLC 合法且 PPC 有效，要么 SafeStop
        self.cac_c.on_evidence(contact=contact, skin=skin)  # 必先撤缺席
        legal, checks = self.clc.is_legal(contact, skin)
        if legal and self.ppc.E >= 0:
            return True, ("COMPLIANT_YIELD", checks)
        return False, ("SAFE_STOP", checks)
```

## 2. 关键命题（供后续轮次继续编号）

**引理 171（接触即存在，声音性）**
若观测器残差 `‖r‖ > r_thr` 且 `r_thr` 已覆盖摩擦/模型误差上界，则存在真实物体位于以 `p_c` 为心、半径 `ε_contact` 的球内（在 FK 与标定误差界内）。故接触通道**无假缺席**（假存在只导致保守停机/让位），它是声音的在场见证。推论：任何接触证据都使该邻域的 `AbsCert` 无效。

**引理 172（被动性 ⇒ 有界交换能量，但不界压强）**
被动控制器与被动人体耦合时 `∫_0^T F^T ẋ dt ≤ E_tank^max`，与初始状态无关、不依赖任何感知/模型。**但该界只约束能量积分，不约束 `max_t‖F(t)‖` 或 `max_t‖F‖/A_patch`**——一个能量很小、面积更小的持续挤压可以造成局部致伤而全程"被动合规"。故 PPC 对接触安全是**充分非必要**，必须配 CLC 的压强判据。

**引理 173（伤害序细化：有界活性兜底仍是继承）**
`SafeStop` 与 `CLC`-合法柔顺都满足 `Harm = ∅`，故 `Harm_v24 ⊆ Harm_v23 = ∅`；但 `Cost(SafeStop) = ∞ > Cost(CLC) < ∞`。在计划语义上 `Exec^plan_v24 = Exec^plan_v23 ∩ JSC ⊆ Exec^plan_v23`（CAC-C 只增障碍、CLC 只在接触后替换兜底，均不新增接触前计划）。因此 v24 是 v23 的**伤害序细化**：安全性不变，活性在接触事件上严格提升。

**命题 174（避让-接触二择一的活性增益）**
`Safe_v24 = GeometricAvoid ∨ (CLC ∧ PPC)`。在 v23 会因任何接触而判违规并 SafeStop 的事件上，v24 若认证 `CLC ∧ PPC` 则进入柔顺让位并继续任务。故在"被迫接触"子集上 `Cost_v24 < Cost_v23`，且两者 `Harm` 同为 `∅`。这是 v23 SLCR 中"停机竞争比 ∞"的可操作解。

**定理 175（v24 复合继承）**
固定模型时 `Exec^plan_v24 ⊆ Exec^plan_v23`；跨模型 `θ→θ'` 时 FTAC 仍为前置门。JSC 失效→纯阻尼；PMO 失效→退纯视觉 v23；CLC 无法认证→接触即停；PPC 失效→停机；CAC-C 失效→等价 v21/v23。所有失效路径只使执行域收缩或使兜底更保守，无一扩大 `Harm` 或新增接触前计划。故 `Harm_v24 ⊆ Harm_v23 = ∅`，且避让分支上 `Exec^plan_v24 ⊆ Exec^plan_v23 ⊆ … ⊆ Exec^plan_v18`。

## 3. 实验设计（可执行草案）

**目的**：验证（i）CLC 能把合法交接/擦碰从 SafeStop 改为柔顺，显著降低活性成本而不增大伤害；（ii）PMO/CAC-C 能缩短并削弱 v23"缺席幻觉"；（iii）PPC 在人施加对抗推力时保持稳定；（iv）**暴露本轮风险**：轻触灵敏度地板与"被动合规但局部高压"。

**平台**：6-DoF/7-DoF 机械臂 + 腕部 F/T + 关节力矩/电流 + 全身触觉皮肤（**故意保留覆盖缺口**）；人体代理含成人、儿童假人、骨质疏松等效软体代理。

**场景**：① 交接（合法接触，`R_allow` 内）；② 意外轻靠（力 < 灵敏度地板，测试 PMO 盲区）；③ 对抗推挤（测试 PPC 稳定性）；④ 小面积夹挤（能量低但压强超阈，测试引理 172 缺口）；⑤ v23 式 SafeStop 对照。

**指标**：① 无界伤害事件（期望 0）；② 接触峰值压强与持续时间；③ 接触检测延迟与灵敏度地板（最小可检持续力）；④ 假接触率；⑤ 活性成本 / 任务时间 / 成功率 / SafeStop 率；⑥ AbsCert 假缺席的持续时长与后果（接触前后）。

**消融**：去 PMO → 盲区漏检回退 v23；去 CLC → 交接被迫停机；去 PPC → 推挤下失稳或过度停机；去人群自适应 → 儿童场景超阈；去皮肤 → 覆盖缺口处漏检。

## 4. 与 v23 及更早模块的接线要点

- **JSC ↔ ACSC/HDL**：ACSC 的臂配空间证书并入 `Q_safe`；HDL 分层过滤器在关节层落地为力矩/速度包络的交；
- **PPC ↔ EVC/PGEV**：EVC 管任务能量储备（预测性），PPC 管接触能量流（非预测性）；`E_tank` 与 `E_margin` 分开记账，PPC 见底优先级高于任务；
- **PMO ↔ CFC++**：力矩/皮肤是与视觉**结构独立**的新模态，直接满足 CFC++ 的 `模态数 ≥ 2` 且专治 v23 的"竞品同盲区"；
- **CAC-C ↔ CAC/AbsCert**：签发缺席前强制查询 PMO/皮肤；接触证据按引理 171 撤销邻域缺席；
- **CLC ↔ GIC/DCL**：交接许可（P 规则）与合法接触需 GIC 意图 + CLC 双确认；意外接触走非对称阈值（低门槛触发安全、高门槛才允许"续行"）；
- **HPC-JCT ↔ HPC-EC**：`HPC-EC` 是避让分支；JCT 在其上追加"或合法接触"分支，且两分支共享 `Harm=∅` 的伤害界。
