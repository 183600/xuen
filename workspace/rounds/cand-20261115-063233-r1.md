# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「目标检测」×「动作空间」）

> R69 把不确定性一分为二，让 epistemic 歧义第一次有了「提问」这个出口。但它有两个从未被审视的前提：
>
> 1. **歧义是一个「无名的模式」**——R69 在动作轨迹空间聚类得到模态，却从不问「这些模态到底是在对哪个**实体**做动作」。绕左/绕右看似动作空间的两种轨迹，实际是「把谁当成障碍」的实体判断分歧；接住/避让看似两种策略，实际是「那是不是人」的检测分歧。**模态是果，实体假设是因。** 因果颠倒后，聚类会把「同一实体下的两种接近方式」误当两个模态（过度交互），也会把「两种实体下的相似轨迹」并成一个（漏交互）。
> 2. **可解性没有上限**——R69 只问「值不值得交互」（VoI > 成本），从不问「**我的动作空间里到底有没有能分辨它们的动作**」。如果看、问、触都无法让两个假设产生可区分的观测，U_epi 在原理上不可解，交互只是烧预算；R69 会反复尝试、反复失败，再把失败当成「再保守一点」。
>
> 本轮两个灵感正好补上这两个前提：
> - **目标检测**给出「实体假设」的正确语言：离散 object slots、可校准的 objectness、稳定的身份分配（Hungarian/tracking）、集合级去重（NMS/DETR）；
> - **动作空间**给出「可解性」的正确语言：信息动作是带前置/效果/终止条件的、对象参照的 option；动作空间的分辨力决定认知可解性的上限；动作空间扩张本身就是安全面的扩张。
>
> 核心命题：**把 R69 的「无名模态」重写为「对象化实体假设」，把「要不要交互」重写为「交互是否可辨识」；歧义只有在（动作空间存在可辨识动作）∧（objectness 校准可信）∧（检测不是被提问诱导出来的）三者同时成立时才可解；否则按不可解直接并入 aleatoric。** 命名 **SCOPE-RAS**（Set-prediction, Certified, Object-centric, Perception-grounded Epistemic disambiguation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我要分辨的到底是哪个对象，而我的动作空间分辨得出吗**」——歧义不是一团雾，是一组可被命名、可被去重、也可能根本问不出来的实体假设。

## 0. 直觉与动机

**灵感 1（目标检测 → 歧义有指称物，不是一团无名的密度的峰）**
直觉：R69 在动作轨迹空间聚类，等价于把所有分歧都投影到「怎么动」上。但人犹豫时真正卡住的是「那是什么/那是谁/那属于谁」，一旦实体确定，动作几乎唯一。检测把这个问题拆成**离散实体假设**（哪个对象、在哪、是什么、置信多少）+ **条件动作**。objectness 可以用检测校准的标准工具（可靠图、ECE）验证，身份分配可以用 Hungarian + 轨迹关联做稳定——这比轨迹聚类稳得多，因为离散槽的错误是**可数、可校准、可审计**的，而连续密度聚类的错误是**不可观测的**。

**灵感 2（NMS/集合预测 → 模态去重与集合级监督，而不是密度阈值）**
直觉：R69 的聚类对密度阈值敏感——阈值松则一个模式被拆成两个（系统反复追问同一件事），阈值紧则两个模式被并成一个（系统漏掉真正的岔路）。检测的正解不是调阈值，而是**在假设集合层面做去重与覆盖**：NMS 处理重叠槽，DETR 用一对一 Hungarian 做无重复集合预测。于是引入**模态 NMS** 与**集合级损失**：同时惩罚幻影模态（假阳）与坍缩（假阴）。这正是 R69「模态幻觉/坍缩」的正面工具。

**灵感 3（动作空间 → 可解性有上限：动作空间的分辨力 = 认知可解性的上限）**
直觉：R69 的 VoI 是「问了以后熵会降多少」的期望，但「问了以后观测怎么变」这个模型本身是拍脑袋的。动作空间视角给出一个硬的、可算的判据：信息动作 g 对假设对 (i,j) **可辨识**，当且仅当「在 i 下观测的分布」和「在 j 下观测的分布」的 KL 散度 ≥ δ。若所有可用动作的 KL 都 < δ，那么**任何策略、问多少次，都不可能把这题做对**。这把「不值得问」（成本）与「问不出来」（动作空间不足）彻底分开：前者走 R68 保守，后者应立即并入 aleatoric，不再烧预算。**动作空间不是能力的边界，而是可解性的边界。**

**灵感 4（层级动作/选项 → 信息动作是带前置、效果、终止条件的宏动作）**
直觉：「问一句」「凑近看」不是一步原子动作，而是有前置条件（对象已被检测且跟踪稳定）、有可审计效果（哪些假设的证据分布被改变）、有终止条件（新观测到达 / 预算耗尽 / 置信饱和）的 option。把它形式化成**对象参照 option**，认证、效果建模、终止判定才都有定义。动作空间因此从 R69 的「扁平增广」升级为「对象参照的层级结构」：primitive ≺ option ≺ skill，信息动作只在认证安全子集内。

**灵感 5（开放词表检测 → 提问会制造它要找的对象：自证预言威胁）**
直觉：g_ask 通过语言先验参与检测。问「那是不是一个人」会抬高 person 的检测置信度——**问题制造了它所询问的对象**。这是 R69「问错比不问更危险」的精确机制，而不只是一句警告。防御必须是结构性的：**反事实检测**——有/无问题先验各跑一次，只在无问题先验下也成立的检测才可作为依据；纯粹由提问诱导出的槽标记为 question-induced，禁止据其行动。这把不可观测的语义风险变成可统计的检测偏移。

**灵感 6（动作空间扩张 = 安全面扩张 → 保守扩张）**
直觉：加入信息动作会扩大需要认证的动作空间，可能引入新的越界方式。要求增广是**保守扩张**：不移除任何任务动作、安全包络不变、信息动作只在认证安全子集内。这是 R69 定理 17（交互无突变）在动作空间层面的加强——不是靠经验测试，而是靠结构条件。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（SCOPE-RAS 总览与四不变式）** SCOPE-RAS = (SPD, OFP, MNA, AIG, ORV, CFD, SCA, RAS-WM‡)。继承 R69 三不变式（实时流零学习写操作、交互预算硬约束、证据纪律），新增：
(iv) **对象参照闭包**：每个 epistemic 假设必须绑定至少一个 object slot，或显式记为 `no-referent`（后者不得进入交互通道）；每个信息动作必须参照一个已认证 slot 或已稳定轨迹。

**定义 311（对象化实体假设空间 SPD）** 观测 o_t 经检测器 D 得候选槽集 𝒮_t = {(b_i, c_i, ŷ_i, id_i)}_{i=1}^N：框/掩码 b_i、objectness 与类别置信 c_i、类别 ŷ_i、身份 id_i。歧义假设不是动作轨迹簇，而是**实体假设对** h_{ij} =「当前任务动作取决于实体 i 还是实体 j」。所有假设构成超图 ℋ_t。R69 的「模态」是本定义在「只保留一个抽象槽」时的商空间投影。

**定义 312（因子化策略 OFP）** p_θ(a_{t:t+H} | o_t) ≈ Σ_k p_κ(k | 𝒮_t) · p_φ(a_{t:t+H} | k, 𝒮_t)，k ∈ {1..N} ∪ {∅}；p_κ 为离散实体选择头（经校准），p_φ 为以 slot 为条件的流匹配速度场（复用 R69 FMP，零重复训练）。k=∅ 表示「动作不依赖任何被检测实体」。**把「选哪个实体」与「对该实体怎么动」解耦**，是相对 R69 的唯一结构改动，其余接口不变。

**定义 313（objectness 校准与身份分配）** objectness 头需经可靠图校准，ECE_obj ≤ τ_obj。跨帧身份用 Hungarian 匹配 + 轨迹关联；身份切换率 ISR = 单位时间 id 变化次数，约束 ISR ≤ τ_isr（否则交互参照失效）。定义模态身份稳定性 MSS = 1 − P(id 在消歧前后改变)。

**定义 314（模态集合去重 MNA）** 对 ℋ_t，两假设 i,j 若「动作条件分布 Fréchet 距离 ≤ ε_nms 且实体框 IoU ≥ ι_nms」，合并为一个槽（NMS）。去重后集合用集合级指标评估：幻影率 FPR_mode（假阳）、坍缩率 FNR_mode（假阴）、集合 F1_mode。集合级损失 L_set = L_FM + λ_p·FP + λ_r·FN，对幻影与坍缩同时惩罚（区别于 R69 只在连续密度上聚类）。

**定义 315（对象参照信息动作 = option 宏动作）** g = (pre, β, term, eff)：前置 pre（slot 已检测、身份稳定、认证通过）、本体 β ∈ {gaze, probe, ask}（继承 R69 定义 294）、终止 term（新观测 / 预算耗尽 / 置信饱和）、效果 eff（对哪些假设的证据分布产生何种变化）。𝒜_info 是对象参照 option 集合，按层级组织 primitive ≺ option ≺ skill。

**定义 316（动作-观测可辨识性 AIG）** 对假设对 (i,j) 与信息动作 g，可辨识性 D_{ij}(g) = D_KL( p(y|g, h_i) ‖ p(y|g, h_j) )（或用 Fisher 信息 / Bretagnolle–Huber 距离）。g 对 (i,j) **可辨识** ⇔ D_{ij}(g) ≥ δ_id。可辨识矩阵 𝐃(g) ∈ ℝ^{N×N}。**关键：D 由独立的判别模型/物理前向模型估计，不依赖 R69 的模态权重——这是对「模态不可信」的第二道防线。**

**定义 317（可解性三分）** 对假设对 (i,j)：
- **可解 Resolvable**：∃ g ∈ 𝒜_info，D_{ij}(g) ≥ δ_id 且 risk(g) ≤ ε_int 且预算允许；
- **昂贵 Costly**：可辨识但 VoI_obj(g) ≤ c(g)；
- **不可解 Unresolvable**：∀ g ∈ 𝒜_info，D_{ij}(g) < δ_id（含「动作空间里根本没有这个动作」与「有动作但分辨不出」两种）。
仅 Resolvable 进入交互；Costly 走 R68；**Unresolvable 立即并入 aleatoric，不烧预算**。

**定义 318（对象化 VoI ORV）** VoI_obj(g|i,j) = H(p_κ(·|𝒮)) − E_{y~p(·|g,h_i)}[H(p_κ(·|𝒮,y))]，后验只在可辨识方向上更新，并用 D_{ij}(g) 对更新量做上界（引理 20）。R69 的 VoI 是本定义在「单槽、D 由流权重近似」时的特例。

**定义 319（保守动作空间扩张）** 增广 𝒜_+ = 𝒜_task ⊔ 𝒜_info 必须满足：(a) 不移除任何任务动作（𝒜_task ⊆ 𝒜_+）；(b) 安全包络不变（信息动作只在认证安全子集内）；(c) 信息动作物理/社交风险 ≤ ε_int 且过 C-RAS-WM‡ 前缀认证（强化 R69 定义 302）。不满足则拒绝上线——**保守扩张是上线前置条件，不是经验结论。**

**定义 320（反事实检测 CFD 与问题诱导检测 QID）** 设检测先验在「有问题 q」与「无问题 q」下分别为 p_κ(·|𝒮, q) 与 p_κ(·|𝒮)。问题诱导度 QID(k, q) = 1[ p_κ(k|𝒮,q) − p_κ(k|𝒮) ≥ τ_qid ]。**反事实检验**：若某 slot 只在含 q 的先验下成立，标记为 question-induced，禁止作为交互/决策依据，并计入 ℰ_poison 的开放词表攻击集。这是对 R69「问错比不问更危险」的精确机制化防御。

**定义 321（对象级证据纪律）** R69 的「k 个正交证据源一致」升级为**对象一致性**：定案须满足 (i) 至少两源在**同一 object id** 上一致；(ii) 该 id 无 QID 标记；(iii) 该 id 的 ISR 未越界。避免「两源各支持两个不同幻影对象」却因证据数够而被误判一致。

**定义 322（动作空间充分性审计 ASR）** 统计运行中假设对的可解/昂贵/不可解比例，以及「因 𝒜_info 缺动作而不可解」的频次，输出**动作空间缺口报告**（需新增哪类信息动作：侧面视角 / 触觉 / 延长观察窗）。这是给**系统设计者**的反馈回路，不是给策略的——策略无法通过自身改进突破动作空间的分辨力上限（定理 19）。

**定义 323（集合级校准门 SCG）** 在 R69-MCG 之上增加：objectness ECE_obj ≤ τ_obj、集合 F1_mode ≥ τ_f1、ISR ≤ τ_isr、QID 率 ≤ τ_qid。任一越界 ⇒ **禁用交互通道、退回 R68 纯保守**（与 R69-MCG 一致，但门控的是「对象」而非「模态」）。

**定义 324（三分退避）** 依定义 317：Resolvable → λ = λ_floor(U_ale)（resolution bonus）；Costly → λ = λ_floor(U_ale + U_epi)（R68）；Unresolvable → 先把 U_epi **永久并入 U_ale**（进入慢学习/表征层，不在实时环反复尝试），λ = λ_floor(U_ale + U_epi) 且**不再触发交互**（预算吸收为 0）。R69 恰是「所有假设至少 Costly」的边界。

**定义 325（证书 J_SCOPE）** J_SCOPE = (J_FLUID, objectness_ECE, mode_set_F1, ISR, QID_rate, resolvable_ratio, identifiability_margin_p05, action_space_gap_report_hash, scope_ver)。Valid ⇔ Valid(J_FLUID) ∧ SCG 未越界 ∧ 对象参照闭包成立 ∧ 反事实检验通过。

**定义 326（时序对象-模态身份继承）** 假设身份由 object id 继承；跨帧若 id 被 Hungarian 重匹配，模态后验按关联概率迁移，防止「同一对象被当成新幻影」的追问闪烁。MSS 低于阈值 ⇒ 交互结果作废（而非重问）。

# IP-264 SPD：把歧义检测成"实体假设对"，而不是轨迹簇
class SlotAmbiguityDetector:
    def __init__(self, detector, calib):
        self.det, self.calib = detector, calib          # detector: 冻结开放词表检测器
    def slots(self, o_t, prior=None):                   # prior: 提问先验（可 None）
        raw = self.det(o_t, text_prior=prior)
        s   = self.calib.objectness(raw)                # 可靠图校准 objectness
        return nms_slots(s, eps=EPS_NMS, iou=IOU_NMS)   # 定义 314

# IP-265 OFP：实体选择 × 条件流匹配（复用 R69 的 FMP trunk / v_θ）
def factorized_policy(z, slots, K_ent=8, K_flow=1):
    k_post = entity_select_head(z, slots)               # 离散实体后验 p_κ(k|𝒮)
    k      = sample_topk(k_post, K_ent)                 # 只对高概率槽生成
    acts   = {ki: flow_sample(z, slots[ki], K_flow) for ki in k}   # 复用 R69 FMP
    return k_post, acts

# IP-266 MNA：集合级去重 + 集合 F1（同时罚幻影与坍缩）
def mode_set_dedup(hyps):
    merged = []
    for h in sorted(hyps, key=lambda x: -x.conf):
        if all(frechet(h.ac, m.ac) > EPS_NMS or iou(h.box, m.box) < IOU_NMS
               for m in merged):
            merged.append(h)                            # 非极大抑制
    return merged                                       # 集合级指标见定义 314

# IP-267 AIG：动作-观测可辨识性门（独立于流权重）
def identifiability(slots, i, j, g, d_model):
    p_i = d_model.predict_obs(slots[i], g)              # p(y | g, h_i)
    p_j = d_model.predict_obs(slots[j], g)
    return kl_divergence(p_i, p_j)                      # 定义 316

def classify_pair(i, j, g_cands, d_model, budget):
    D = {g: identifiability(slots, i, j, g, d_model) for g in g_cands if budget.allow(g)}
    if not D or max(D.values()) < DELTA_ID:
        return "UNRESOLVABLE"                           # 动作空间分辨不出 → 并入 aleatoric
    best = max(D, key=D.get)
    return "RESOLVABLE" if D[best] > 0 else "COSTLY"

# IP-268 ORV：对象化 VoI（只在可辨识方向上算增益）
def object_voi(k_post, i, j, g, d_model):
    before = entropy(k_post)
    after  = expected_entropy_after(k_post, i, j, g, d_model)
    return before - after

# IP-269 ORM：对象参照 option（前置/本体/终止/效果）
class InfoOption:
    def step(self, o_t, slots, budget):
        if not self.pre(slots, budget):    return "ABORT"      # 前置不满足
        y = self.body(o_t)                                     # gaze / probe / ask
        if self.term(y, budget):           return "DONE", y
        return "RUNNING", y

# IP-270 CFD：反事实检测，隔离"提问制造对象"
def counterfactual_detect(det, o_t, q):
    s0 = det.slots(o_t, prior=None)                        # 无问题先验
    s1 = det.slots(o_t, prior=q)                           # 有问题先验
    qid = [x for x in s1 if not matches(x, s0)]            # 只在 q 下涌现的槽
    return s0, [x for x in s1 if x not in qid], qid        # 定义 320

# IP-274 SCOPE 主闭环（继承 R69 FLUID，仅在"歧义来源"与"可解性"处替换）
def SCOPE_RAS_round(M, o_t):
    z, o = M.mtm.forward(o_t); c, U_cal, thr = M.cof.step(o)      # R68 标定
    s0, s, qid = counterfactual_detect(M.spd.det, o_t, M.last_q)  # 反事实检测
    if M.scg.breach(s, qid):                                       # 定义 323
        return conservative_round(M, o, U_cal)                     # 退回 R68
    k_post, acts = factorized_policy(z, s)                         # 定义 312
    U_ale, U_epi, pairs = decompose_objectwise(k_post, acts)       # R69 AUD 的对象化版
    # 1) 逐个假设对判可解性（不做无谓交互）
    resolvable = [p for p in pairs if classify_pair(*p, M.g_cands, M.d, M.budget)
                  == "RESOLVABLE"]
    # 2) 只对可解对算对象化 VoI，选最优 option
    g = M.orm.select(resolvable, k_post, M.d, M.budget) if resolvable else None
    U_epi_after = U_epi
    if g is not None:
        ans = M.orm.execute(g, o_t)                                # 认证 + 终止条件
        U_epi_after = M.sca.update(k_post, ans, discipline="object_consistent")  # 定义 321
    # 3) 三分退避：不可解直接并入 aleatoric，不再烧预算
    unresolved = [p for p in pairs if p not in resolvable]
    U_floor = U_ale + (U_epi_after if g is None else 0.0) + sum(perma_u(p) for p in unresolved)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(o_x, M.vista.H), ..., wm_preds)
    mode = select_object_mode(acts, k_post, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 4) 证书：审计对象参照、QID、动作空间缺口
    M.asr.log(pairs, unresolved, qid); M.vqa_i.submit_async(g, ans, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 3. 推导

**引理 19（校准 objectness 下的假模态上界）** 设 objectness 校准误差 ECE_obj ≤ τ_obj，基础假阳率 FPR_0。经 MNA 去重后，幻影模态进入交互的概率 ≤ FPR_0 + τ_obj + O(ε_nms)；若真模态的 objectness 被低估超过 τ_obj，漏检率 ≤ FNR_0 + τ_obj。系：R69 的「模态幻觉」在本层被转化为**可测量的检测校准问题**，而非不可观测的流采样问题——这是本轮对 R69 最大风险的正面回应。

**引理 20（可辨识性对 VoI 的夹逼）** 对二假设 (i,j)，最优检验错误率 P_e ≤ ½·exp(−D_{ij}(g))（Chernoff–Stein），故一次观测带来的熵降 ΔH ≥ 1 − h₂(P_e)；反之，若 ∀g, D_{ij}(g) < δ_id，由 Pinsker（TV ≤ √(KL/2)）得任何策略的错误率下界 P_e ≥ ½(1 − √(δ_id/2))。系：**可解性门（定义 316–317）是 VoI > 0 的必要条件，不是启发式**；「不可辨识」意味着交互的期望信息增益被 KL 上界钉死。

**引理 21（问题诱导检测的可分离性）** 设检测在问题先验下对槽 k 的对数几率偏移 Δℓ(k|q)，反事实差 Δp = p_κ(k|𝒮,q) − p_κ(k|𝒮)。若 τ_qid 取校准噪声的 95% 分位，则真检测被误标 QID 的概率 ≤ 5%；纯由提问诱导、无真实证据的幻影被检出率 ≥ 1 − e^{−Δℓ}（Δℓ 足够大时）。系：反事实检验把「提问制造对象」从不可观测的语义风险变成可统计的检测偏移。

**引理 22（保守扩张的安全等价）** 若 𝒜_+ 满足定义 319 (a)-(c)，则任意在 𝒜_task 上安全的 π 与混入信息动作的 π' 安全包络相同：sup_s Risk(π') ≤ sup_s Risk(π)，且认证子集 𝒮_cert(𝒜_task) ⊆ 𝒮_cert(𝒜_+)。系：动作空间扩张的安全性由「保守扩张」三条件保证，而非由经验测试。

**定理 18（SCOPE 严格包含 FLUID 与 R68）** 在 A95–A99（A99：objectness 校准、身份稳定、D 估计可靠）下：
(i) 若检测退化为单槽且所有假设对 Resolvable，SCOPE 的交互选择与 FLUID 一致（VoI_obj 上界到 R69 的 VoI）；
(ii) 若所有假设对 Unresolvable 或 SCG 越界，SCOPE 逐指令等于 R68；
(iii) 一般情形，SCOPE 期望风险 ≤ FLUID ≤ R68，且交互预算消耗 ≤ FLUID（不可解不再烧预算）。
故 R68 ⊂ FLUID ⊂ SCOPE，安全侧单调不让步，效率侧获得「不烧冤枉预算」的额外收益。

**定理 19（动作空间分辨力是可解性的充要边界）** 给定假设对 (i,j) 与动作空间 𝒜_info：
(i)（充分性）若 ∃g∈𝒜_info，D_{ij}(g) ≥ δ_id，则存在满足对象级证据纪律的策略，使错误采纳率随有效交互次数指数下降（引理 20 + 引理 18）；
(ii)（必要性/极限）若 ∀g∈𝒜_info，D_{ij}(g) < δ_id，则任何策略（无论多聪明、问多少次）的错误采纳率 ≥ ½(1−√(δ_id/2)) − ε_σ。即**不可辨识的歧义不能被「更聪明的策略」解决，只能被「更大的动作空间」解决**。
系：这为「何时该扩展动作空间（加传感器/加交互模态）」提供了可计算判据——扩展动作空间是在扩展**可解性**，不只是扩展能力。

## 6. 本轮最大风险

**一句话**：SCOPE 把 epistemic 歧义**定义**成「检测槽之间的歧义」，于是凡没有对象指称的歧义——意图（想让我左还是右）、偏好（要快要稳）、规范（该不该打扰）——会被可解性判别判为 `UNRESOLVABLE` 并**永久并入 aleatoric**；系统于是永远保守、永远不提问，却仍能签发 `Valid` 证书。**它把 R69 的「问错」风险换成了「根本不问」风险，而后者更难被发现，因为它看起来就像「安全」。**

**次级风险与缓解**：
1. **检测漏掉关键实体**（最大风险的触发路径）→ 引理 19 的假阴上界 + E313 OOD 压力测试 + ASR 缺口报告；
2. **objectness 校准漂移**（R68 缓变故障的检测版）→ SCG 实时 ECE 门控 + 越界即退回 R68；
3. **问题诱导的开放词表幻觉**（自证预言）→ 反事实检测 CFD + QID 标记 + 禁止据其行动（定义 320）；
4. **动作空间扩张扩大攻击面** → 保守扩张三条件（定义 319）+ 引理 22 + C-RAS-WM‡ 认证；
5. **身份抖动导致追问闪烁** → MSS/ISR 约束 + 交互结果作废而非重问（定义 326）；
6. **表示过度承诺**（强行把非对象歧义塞进槽）→ `no-referent` 显式通道 + E314 专门量化它的代价，作为下一轮必须处理的缺口。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** SCOPE-RAS = (SPD, OFP, MNA, AIG, ORV, ORM, CFD, SCA, ASR, RAS-WM‡)；继承 R69 三不变式，新增 **(iv) 对象参照闭包**：每个 epistemic 假设须绑定 object slot 或显式 `no-referent`（后者禁入交互通道）。

**定义 311–312（对象化假设与因子化策略）** 歧义假设是实体对 `h_{ij}`，超图 `ℋ_t`；策略因子化 `p(a,k|o)=Σ_k p_κ(k|𝒮)·p_φ(a|k,𝒮)`，`k=∅` 表示不依赖任何实体。R69 的「模态」= 单抽象槽的商空间投影。

**定义 313–314（校准/身份/集合去重）** objectness 需 `ECE_obj ≤ τ_obj`；Hungarian + 轨迹关联得 `ISR ≤ τ_isr`、`MSS`；MNA 用 Fréchet+IoU 做 NMS，集合级损失 `L_set=L_FM+λ_p·FP+λ_r·FN`，同时罚幻影与坍缩。

**定义 315–316（对象参照 option 与可辨识性）** `g=(pre,β,term,eff)`，`β∈{gaze,probe,ask}`；`D_{ij}(g)≥δ_id` 才可辨识；**D 由独立判别模型估计，不依赖 R69 模态权重**——第二道防线。

**定义 317–318（可解性三分与对象化 VoI）** Resolvable（存在可辨识动作且安全且预算允许）/ Costly（可辨识但 VoI≤成本）/ Unresolvable（所有动作 D<δ）；仅 Resolvable 交互，Costly 走 R68，**Unresolvable 立即并入 aleatoric、不烧预算**。`VoI_obj` 只在可辨识方向更新。

**定义 319–320（保守扩张与反事实检测）** `𝒜_+=𝒜_task⊔𝒜_info` 须 (a) 不删任务动作 (b) 安全包络不变 (c) 信息动作过认证；CFD 用有/无提问先验两次检测，`QID=1[p_κ(k|𝒮,q)−p_κ(k|𝒮)≥τ_qid]`，QID 槽禁止据以行动。

**定义 321–323（对象级证据/审计/校准门）** 证据纪律升级为**对象一致性**（同一 id、无 QID、ISR 未越界）；ASR 输出动作空间缺口报告；SCG 四门控（ECE_obj/F1_mode/ISR/QID）任一越界即退回 R68。

**定义 324–326（三分退避/证书/身份继承）** Resolvable→`λ=λ_floor(U_ale)`；Costly→`λ=λ_floor(U_ale+U_epi)`；Unresolvable→U_epi 永久并入 U_ale 且不再交互。`J_SCOPE=J_FLUID+对象化与可辨识性字段`；身份随 object id 继承，MSS 过低则交互作废而非重问。

# IP-264 SPD：把歧义检测成"实体假设对"
def slots(det, calib, o_t, prior=None):
    s = calib.objectness(det(o_t, text_prior=prior))      # 校准 objectness
    return nms_slots(s, eps=EPS_NMS, iou=IOU_NMS)         # 定义 314

# IP-265 OFP：实体选择 × 条件流匹配（复用 R69 FMP）
def factorized_policy(z, slots, K_ent=8, K_flow=1):
    k_post = entity_select_head(z, slots)                 # p_κ(k|𝒮)
    k      = sample_topk(k_post, K_ent)
    return k_post, {ki: flow_sample(z, slots[ki], K_flow) for ki in k}

# IP-267 AIG：动作-观测可辨识性（独立判别模型）
def classify_pair(slots, i, j, g_cands, d_model, budget):
    D = {g: kl_divergence(d_model.predict_obs(slots[i], g),
                          d_model.predict_obs(slots[j], g))
         for g in g_cands if budget.allow(g)}
    if not D or max(D.values()) < DELTA_ID: return "UNRESOLVABLE"
    return "RESOLVABLE"

# IP-269 ORM：对象参照 option
class InfoOption:
    def step(self, o_t, slots, budget):
        if not self.pre(slots, budget): return "ABORT", None
        y = self.body(o_t)                                # gaze / probe / ask
        return ("DONE", y) if self.term(y, budget) else ("RUNNING", y)

# IP-270 CFD：反事实检测，隔离"提问制造对象"
def counterfactual_detect(det, o_t, q):
    s0 = det.slots(o_t, prior=None); s1 = det.slots(o_t, prior=q)
    qid = [x for x in s1 if not matches(x, s0)]           # 只在 q 下涌现的槽
    return s0, [x for x in s1 if x not in qid], qid

# IP-274 SCOPE 主闭环（继承 R69 FLUID）
def SCOPE_RAS_round(M, o_t):

    s0, s, qid = counterfactual_detect(M.spd.det, o_t, M.last_q)
    if M.scg.breach(s, qid): return conservative_round(M, o, U_cal)   # 退回 R68
    k_post, acts = factorized_policy(z, s)
    U_ale, U_epi, pairs = decompose_objectwise(k_post, acts)
    resolvable = [p for p in pairs
                  if classify_pair(s, *p, M.g_cands, M.d, M.budget) == "RESOLVABLE"]
    g = M.orm.select(resolvable, k_post, M.d, M.budget) if resolvable else None
    U_epi_after = U_epi
    if g is not None:
        ans = M.orm.execute(g, o_t)
        U_epi_after = M.sca.update(k_post, ans, discipline="object_consistent")
    unresolved = [p for p in pairs if p not in resolvable]
    U_floor = U_ale + (U_epi_after if g is None else 0.0) + sum(perma_u(p) for p in unresolved)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(o_x, M.vista.H), ..., wm_preds)
    mode = select_object_mode(acts, k_post, U_epi_after, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.asr.log(pairs, unresolved, qid); M.vqa_i.submit_async(g, ans, U_epi, U_epi_after)
    return k, lam, mode, (U_ale, U_epi_after)
```

## 4. 推导

**引理 19（校准 objectness 下的假模态上界）** `ECE_obj≤τ_obj`、基础假阳率 `FPR_0`；经 MNA 后幻影进入交互的概率 `≤ FPR_0+τ_obj+O(ε_nms)`；漏检率 `≤ FNR_0+τ_obj`。系：R69「模态幻觉」被转化为**可测量的检测校准问题**。

**引理 20（可辨识性对 VoI 的夹逼）** 二假设下最优检验 `P_e ≤ ½·exp(−D_{ij}(g))`（Chernoff–Stein），故熵降 `ΔH ≥ 1−h₂(P_e)`；若 `∀g, D<δ_id`，由 Pinsker 得 `P_e ≥ ½(1−√(δ_id/2))`。系：**可解性门是 VoI>0 的必要条件，不是启发式**。

**引理 21（问题诱导检测的可分离性）** τ_qid 取校准噪声 95% 分位时，真检测误标 QID ≤ 5%；纯提问诱导的幻影检出率 `≥ 1−e^{−Δℓ}`。系：把「提问制造对象」变成可统计的检测偏移。

**引理 22（保守扩张的安全等价）** 满足定义 319(a)-(c) 时 `sup_s Risk(π') ≤ sup_s Risk(π)` 且 `𝒮_cert(𝒜_task) ⊆ 𝒮_cert(𝒜_+)`。系：动作空间扩张的安全性由结构条件保证，而非经验测试。

**定理 18（SCOPE 严格包含 FLUID 与 R68）** A95–A99 下：(i) 单槽且全 Resolvable 时与 FLUID 一致；(ii) 全 Unresolvable 或 SCG 越界时逐指令等于 R68；(iii) 一般情形 `Risk(SCOPE) ≤ Risk(FLUID) ≤ Risk(R68)`，且交互预算消耗 ≤ FLUID。故 `R68 ⊂ FLUID ⊂ SCOPE`。

**定理 19（动作空间分辨力是可解性的充要边界）** (i) 若 `∃g, D_{ij}(g)≥δ_id`，存在对象级证据纪律策略使错误率随交互次数指数下降；(ii) 若 `∀g, D_{ij}(g)<δ_id`，任何策略错误率 `≥ ½(1−√(δ_id/2))−ε_σ`。即**不可辨识的歧义只能被更大的动作空间解决，不能被更聪明的策略解决**。系：为「何时扩展动作空间/传感器」提供可计算判据。

## 7. 本轮最大风险

**一句话**：SCOPE 把 epistemic 歧义**定义**成「检测槽之间的歧义」，于是凡没有对象指称的歧义（意图：左还是右；偏好：快还是稳；规范：该不该打扰）会被判为 `UNRESOLVABLE` 并**永久并入 aleatoric**——系统永远保守、永远不提问，却仍签发 `Valid` 证书。**它把 R69 的「问错」风险换成了「根本不问」风险，而后者更难被发现，因为它看起来就像安全。**

**次级风险与缓解**：检测漏掉关键实体 → 引理 19 假阴上界 + E313 + ASR 缺口报告；objectness 校准漂移 → SCG 实时门控 + 越界退回 R68；开放词表自证预言 → CFD 反事实检测 + QID 标记；动作空间扩张扩大攻击面 → 保守扩张三条件 + 引理 22；身份抖动导致追问闪烁 → MSS/ISR + 交互作废而非重问；表示过度承诺 → `no-referent` 显式通道 + E314 专门量化，留给下一轮处理。
