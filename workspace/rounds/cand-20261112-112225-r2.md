# 第 58 轮（承接第 57 轮「证据地图×少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「可靠性」×「VLA」）

> 第 57 轮把安全的赌注从"模型置信"移到"证据质量"，并用 MFSL/XMC/PTM 让小样本、跨模态、个性化下的证据更可校准；但它默认了两件危险的事：**(a)** 作为新策略来源的 VLA（Vision-Language-Action）模型，其失效概率在部署期内近似平稳，且可以由离线评测一次性认证；**(b)** "视觉/语言/动作"多通道一致就约等于独立佐证。可靠性工程会立刻反问：你测的是**哪个能力**、在**哪个上下文**、**置信下界多少**、**共因失效 β 多大**、**监测器自己坏了怎么办**？VLA 把感知、语言 grounding 与动作生成压进同一个大模型，能力更强，但失效也更**相关**、更**非平稳**、更**会自圆其说**。本轮把 VLA 从"会说话的策略"降格为"可靠性未知、但可被独立核验的提议者"：用可靠性契约限定它能做什么，用证明携带行动让每个动作带可检查的义务，用多样性运行时保证在它不可信时切到认证基线，用动态故障树与共因 β 给"多通道一致"打折，用可靠性中心维护决定何时证明测试、重校准、请人或退役某个能力。核心命题从"证据说可信"升级为 **"可分解、可监测、可切换的可靠性契约下的 VLA 行动"**。

核心矛盾：

- **H29（非平稳可靠性 vs 静态认证）**：VLA 经微调、换 prompt、换传感器、换场地后，失效分布会移动；离线 benchmark 的均值不能给在线部署背书。可靠性必须按 (能力, 上下文, 时间, 维护史) 分账，并显式区分"婴儿期/有效寿命/耗损期"。
- **H30（共因失效 vs 多模态一致）**：VLA 的视觉编码器、语言 grounding、动作头共享骨干与训练分布；同一个幻觉可以在三种表征里自洽出现。把 VLA 的三路输出当独立证据，是把一个单点故障穿了三件衣服。
- **H31（语义正确 vs 行动安全）**：VLA 能生成语言上合理、视觉上合理、但物理上不可执行或不安全的动作；更糟的是，它的解释也由同一个模型生成——用 VLA 的解释证明 VLA 的动作，是循环自证。
- **H32（可靠性账本 vs 幸存者偏差）**：被安全网兜住的 VLA 失败，后果被消除，但仍是失败证据；若账本只统计"任务失败"，可靠性会被系统性高估。监测器若与 VLA 共享感知，还会把共因失败记成两次独立观测。

## 0. 直觉与动机

**灵感 1（可靠性 → 把"置信"换成"有置信下界的失效能力画像"）**
直觉：可靠性工程从不问"这个零件自信吗"，而问"在什么工况下、已累计多少小时、下次失效的概率上界是多少、坏了有没有冗余、多久做一次证明测试"。把 VLA 当零件看，会得到一张浴盆曲线：新模型刚上线是**婴儿期**（分布未熟、prompt 未稳），正常部署是**有效寿命期**，传感器磨损/场景漂移/模型熵增进入**耗损期**。可靠性不是一个全局分数，而是能力画像 `r_c(x,t)`：同一模型可能"抓杯子"很可靠、"开抽屉"很不可靠。安全的第一性原理不是提高 VLA 的平均分，而是**只在有置信下界的能力包络内授权，并让包络外自动退回可认证基线**。

**灵感 2（VLA → 能力放大器，也是共因放大器）**
直觉：VLA 把"看见—理解—行动"压进一个模型，端到端很优雅，但它的多模态不是多条独立传感器，而是同一个参数化函数的不同出口。于是第 57 轮最锋利的证据形态"跨模态一致"出现了新的反例：**一致可能不是两个证人碰头，而是一个骗子换了三套说辞**。VLA 生成的 rationale 尤其危险：它看起来像证据，其实是被审查对象的自述。正确用法是把 VLA 输出当**带噪观测或提案**，而不是判决；判决必须交给独立、可检查、失效机制不同的组件。

**灵感 3（合流 → VLA 提议，可靠性治理器处置）**
直觉：经典 Simplex 用"先进控制器 + 认证安全控制器 + 决策模块"做运行时保证。本轮把它升级成**可靠性感知的切换**：是否让 VLA 接管，不看 VLA 自己说多有把握，而看三项外部事实——该能力在 x 上的失效概率下界、独立监测器是否在线、当前状态是否处于可安全切换的恢复集。VLA 可以"赢得"更大权限，但只能靠影子模式、证明测试和事后核验，不能靠自信。切换本身也要有安全条件：只在恢复集内切、有驻留时间、切换后预测状态仍在不变集内，否则宁可不切。

**灵感 4（可靠性中心维护 → 人的注意力也是稀缺可靠性资源）**
直觉：人不是免费的万能兜底。人的可靠性也有状态、会疲劳、会被橡皮章化；但人的失效机制与 VLA **不同源**，所以人是天然的多样性通道。可靠性中心维护把"何时请人"从固定阈值变成按**可靠性不确定度**分配：哪个能力的失效下界最不确定、哪个共因 β 最没被验证，就把证明测试或人工核验投到哪里。对高可靠、低风险、已有证明测试的能力，减少打扰；对低可靠、高不确定、接近包络边界的能力，增加见证。这样个性化不是"信任通胀"，而是"注意力按风险定价"。

**灵感 5（可靠性导向的主动测试 → 问一个能让系统知道自己哪里不可靠的问题）**
直觉：第 57 轮的 VOI 主要降低世界状态的不确定性；本轮还需要一种 VOI：降低**故障树顶事件概率与共因 β 的不确定性**。一次探针如果既能确认地面，又能暴露"这个 VLA 能力在边界工况下是否会错"，它的信息价值远高于重复确认已知安全。证明测试（proof test）就是可靠性工程的"主动探询"：用已知真值场景周期性激活潜在失效，防止隐藏故障长期休眠。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（VLA 可靠性契约与认证包络 VRC）** 能力集 `C={ground,parse,afford,plan,act,recover}`；上下文 `x=(o,ℓ,z_r)`（观测/指令/区域）；动作提案 `a`；结果 `y∈{success,fail,near_miss}`。可靠性状态 `r_c(x,t)=(q̂_c,q_c^L,n_c,β_c,λ_c,drift_c,τ_pt)`：`q̂_c` 为失效概率点估计，`q_c^L` 为置信下界（如 `q_c^L=Q_α(Beta(a0+n_f,b0+n_s))`，对删失/被兜底失败单列计数），`β_c` 为共因因子，`λ_c` 为风险率，`drift_c` 为漂移统计量，`τ_pt` 为最近证明测试。契约 `K_c=(Pre_c,Post_c,Fail_c,Mon_c,Fallback_c,ε_c,scope_c)`。**认证包络** `E_c(t)={x: q_c^L(x,t)≤ε_c ∧ drift_c≤δ_drift ∧ τ_pt 有效 ∧ ∀f∈Fail_c 有独立 Mon 覆盖}`。VLA 只有 `x∈E_c(t)` 且 SPAC 通过且治理器允许时才能承诺；包络外只允许"提议/询问/退回基线"。模型更新、微调、换传感器或检出变点后进入**烧机期**：`q_c` 重置到保守先验，需 `N_burn` 次影子/证明测试才可重新入包络；风险率按 `λ_c(t)=λ_infant(t-t0)+λ_useful+λ_wear(age)` 分段建模。

**定义 140（语义-物理行动证书 SPAC）** 动作提案 `a=(skill,params)` 必须附带证书 `z=(G,Pre,Eff,Unc,W,cov)`：`G` 为可判定片段内的 grounded 原子（对象、关系、可达性、支撑面），`Pre/Eff` 为前后条件公式，`Unc` 为感知/执行不确定区间，`W` 为独立见证（几何地图、物理监测器、另一模型族、人工确认），`cov` 为证书覆盖度。可信检查器 `Ch(z,𝓜,x)∈{accept,reject,unknown}`，其中 `𝓜` 为第 56 轮证据地图。**健全性**：`accept ⇒ Pre 在 𝓜 的传感器误差内成立 ∧ Eff∩HardViol=∅ ∧ cov≥γ_cov`。**反自证原则**：`W` 不得引用 VLA 的隐藏状态或自然语言 rationale；VLA 的解释不是证据。`unknown` 或 `cov<γ_cov` 的动作不得进入 L2/不可逆接触，只能走"补见证/换基线/请人"。

**定义 141（多样性运行时保证 DRA）** 先进控制器 `π_V`（VLA）与认证基线 `π_B`；认证不变集 `I`；恢复集 `R⊆I` 为两控制器都能安全接管的状態集。可靠性治理器 `G(x,r,m)`：当 `x∈E_c`、独立监测器 `m(x)>0`、能力下界满足阈值时，允许 `π_V`；否则 `π_B`。切换规则：仅当 `x∈R`、驻留时间 `≥τ_dwell`、且 `Predict(π_V,x)∈I` 时允许 V→B 之外的切换；一旦监测器报警、证明测试失败或变点检出，**立即降级**到 `π_B` 或安全停。治理器自带看门狗与独立监测器；若监测器与 VLA 共享感知/训练分布，则必须按共因 β 计入，不能当作独立防线（见定义 143）。

**定义 142（可靠性账本与动态故障树 RLL/DFT）** 账本 `L={(t,c,x,a,y,mask,witness,verdict)}`，其中 `mask=1` 表示失败被兜底捕获、后果被消除，但**仍作为失败证据保留**。动态故障树顶事件 `U`＝"不安全承诺"，基本事件 `E_V`（VLA 语义/动作失败）、`E_M`（监测器漏检）、`E_B`（基线失败）、`E_C`（契约/检查器不可靠）、`E_H`（人失败）、`E_CC`（共因）。门结构至少包含 `U=(E_V∧E_M)∨(E_V∧E_B)∨(E_C)∨(E_CC)`。共因项用 beta 因子模型：冗余通道的失效概率上界 `q_sys≤β·q+(1−β)q^r`；无独立性证据时 `β=β0`（保守）。**可靠性导向 VOI**：`VOI_rel(π)=E[ΔH(U|L) 或 ΔVar(q_U)]−cost(π)`，优先选择能降低 `q_U` 与 `β` 不确定性的测试，而不是重复确认已知安全。

**定义 143（抗共因多样性 CCRD）** 多样性集合 `D`；对任意通道 `i,j`，由故障注入与联合失败记录估计失效相关系数 `ρ_ij` 与共因因子 `β_ij=P(CCF_ij)/P(至少一个失败)`。有效冗余 `r_eff(D)=1+Σ_{i>1}(1−β_i)·1[ρ_i≤ρ_max ∧ 独立性证据有效]`；未通过独立性检验的通道贡献 0。**模态不等于通道**：同一 VLA 骨干的视觉/语言/动作出口只算一个通道；真正的多样性来自不同失效机制，例如几何感知、物理监测器、不同模型族、人工确认。第 57 轮的 `EV-xmodal` 在本轮被降级为**条件证据**：只有跨模态见证通过 CCRD 独立性检验时才可计入；若三路同源，`EV-xmodal` 立即失效。

**定义 144（可靠性中心维护与规划 RCMP）** 在 PCE+ 的检查点上，规划目标为 `max E[utility(π)]`，硬约束为 `q_U(x,π)≤ε_hard` 且所用每个能力 `q_c^L≤ε_c`；不可行时在维护动作 `m∈{proof_test,recalibrate,switch_baseline,ask_human,retire_capability}` 中选择最小代价者。维护债 `D_m` 按风险率与证明测试间隔累积；证明测试调度由 `λ_c` 与所需失效检出概率给出。可靠性中心交互把人工注意力按 `Uncertainty(q_c^L)+Uncertainty(β)` 分配，而不是平均分配；人工状态继承第 57 轮 PTM，但人工通道与 VLA 的失效机制不同源，故可作为多样性见证。

## 2. 关键算法伪代码

```python
def vla_admit(c, x, r, M):
    if not in_envelope(c, x, r):                 # q_c^L、漂移、证明测试、失效模式覆盖
        return 'propose_only'                    # 包络外：只提议，不承诺
    z = vla.propose_certificate(x)               # 动作 + grounded 证书
    verdict = spac_check(z, M, x)                # 独立检查器，不信 VLA rationale
    if verdict != 'accept':
        return 'hold' if verdict == 'unknown' else 'reject'
    return 'commit' if governor_safe(c, x, r) else 'baseline'

def reliability_governor(x, pi_V, pi_B, r, mon):
    if mon.violation(x) or r.qL > r.eps or x not in r.E:
        return pi_B                              # 外部事实优先，VLA 自信无效
    if x in r.R and dwell_ok() and predict_safe(pi_V, x):
        return pi_V
    return pi_B

def ledger_update(L, ev, c):
    L.append(ev)                                 # mask=1 的兜底失败也保留
    qL, beta = dft_lower_bound(L, ccf_prior)     # 动态故障树 + 共因下界
    if change_point(L, c): enter_burn_in(c)      # 婴儿期：重置保守先验
    return qL, beta
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| VRC | O(1) 查询 / O(\|L_c\|) 重估 | O(\|C\|·\|X\|) | 下界有效、漂移检出、证明测试未过期 |
| SPAC | O(\|z\|·d_M) 检查 | O(\|z\|) | 检查器健全、覆盖度 γ_cov、见证独立 |
| DRA | O(1)+O(1) 切换判定 | O(\|I\|) | 不变集/恢复集、驻留时间、看门狗 |
| RLL/DFT | O(\|L\|) 增量；O(\|tree\|) 求界 | O(\|L\|+\|tree\|) | 掩蔽失败保留、β 保守、删失处理 |
| CCRD | O(\|D\|²) 相关估计 | O(\|D\|²) | 独立性证据、同源通道不重复计数 |
| RCMP | O(\|CP\|·(\|m\|+C_VOI)) | O(\|V\|+\|σ\|) | 硬约束优先、维护预算有限、四态完备 |

**正确性定理（RGV，Reliability-Governed VLA Soundness 概要）**：在 A33–A40 基础上增加 **(A41)** 检查器 `Ch` 对可信地图与物理约束健全，证书覆盖度诚实；(A42) 可靠性账本满足删失/掩蔽处理，`q_c^L` 在可交换或慢漂移假设下是有效下界，变点检出后烧机期生效；(A43) CCRD 的独立性证据可审计，`β` 取保守上界，同源通道不得重复计入冗余；(A44) 治理器只在不变集 `I` 与恢复集 `R` 内切换，看门狗与独立监测器可用。则：(i) **不安全承诺界** `q_U≤β·q_cc+(1−β)(q_V q_M+q_V q_B+q_M q_B)+q_C+q_G`，且包络内 `q_c≤ε_c` 以置信度 `1−α` 成立；(ii) **反自证性**：VLA 的置信、解释或跨模态自洽不能扩大 `E_c` 或提高 `r_eff`，只有独立见证、证明测试与事后核验能改变授权；(iii) **可靠性单调性**：降级实时，升级需证据且有界；增加同源通道不能降低 `q_U` 上界；(iv) **终止性**：RCMP 在有限证明/维护预算内终止于 {承诺, 退回基线, 维护, 安全停}。

## 6. 本轮最大风险

### IP-139 VRC（VLA 可靠性契约与认证包络）

```python
def reliability_update(r, c, x, outcome, masked, witness):
    r[c].n += 1
    # 被兜底捕获的失败仍是失败证据，只是后果被消除
    if outcome in ('fail', 'near_miss'):
        r[c].n_f += 1
        if masked: r[c].masked_f += 1
    else:
        r[c].n_s += 1
    r[c].q_hat = beta_mean(r[c].n_f, r[c].n_s)
    r[c].qL = beta_lower_bound(r[c].n_f + r[c].a0,
                               r[c].n_s + r[c].b0, alpha=alpha_rel)
    if witness.independent and witness.supports_failure:
        r[c].beta = max(beta_min, r[c].beta * gamma_beta_down)
    if witness.independent and witness.supports_success:
        r[c].beta = min(beta_max, r[c].beta + gamma_beta_up)
    return r

def in_envelope(r, c, x):
    return (r[c].qL(x) <= r[c].eps
            and r[c].drift <= delta_drift
            and not expired(r[c].tau_pt)
            and all(covered(f, r[c].monitors) for f in fail_modes(c)))

def maybe_burn_in(r, c, L):
    if change_point_detected(L, c):              # 模型更新/换传感器/漂移
        r[c].qL = prior_conservative(c)          # 重置到婴儿期
        r[c].tau_pt = None
        r[c].burn_in_left = N_burn(c)
    return r
```

### IP-140 SPAC（语义-物理行动证书与独立检查）

```python
def spac_check(z, M, x, sensor_err):
    # 1) grounding：证书里的对象/关系必须在独立地图中可定位
    if not all(grounded(g, M, sensor_err) for g in z.G):
        return 'unknown'                         # 不可验证 ≠ 可通过
    # 2) 前后条件：Pre 必须在当前状态成立，Eff 不得触碰硬违规集
    if not implies(M.state, z.Pre, sensor_err):
        return 'reject'
    if intersects(z.Eff, HARD_VIOLATIONS):
        return 'reject'
    # 3) 见证独立性：VLA rationale / hidden state 不得作为见证
    if any(w.from_vla_hidden_state or w.from_vla_rationale for w in z.W):
        return 'reject'
    # 4) 覆盖度：动作语义必须有足够的可检查义务
    if z.cov < gamma_cov:
        return 'unknown'
    return 'accept'

def vla_action_with_certificate(vla, x, M):
    a = vla.propose(x)                            # 想象/提案，不是判决
    z = vla.emit_certificate(a, x)                # 只接受可判定片段
    verdict = spac_check(z, M, x, sensor_err=M.sigma)
    if verdict == 'accept':
        return ('commit_candidate', a, z)
    if verdict == 'unknown':
        return ('hold_or_ask', a, z)              # 补见证/请人/退回基线
    return ('reject', a, z)
```

def governor_step(x, r, pi_V, pi_B, mon, state):

### IP-142 RLL-DFT（可靠性账本、动态故障树与共因下界）

```python
def dft_bound(L, c_prior):
    events = fit_basic_events(L)                  # E_V,E_M,E_B,E_C,E_H
    beta = estimate_beta(L.joint_failures, c_prior)   # 无证据则取保守 beta0
    # 顶事件至少要覆盖：VLA 错且监测漏、VLA 错且基线错、契约/检查器不可靠、共因
    q_cc = beta * max(q(events['E_V']), q(events['E_M']))
    q_ind = (1 - beta) * (q(events['E_V']) * q(events['E_M'])
                          + q(events['E_V']) * q(events['E_B'])
                          + q(events['E_M']) * q(events['E_B']))
    q_U = min(1.0, q_cc + q_ind + q(events['E_C']) + q(events['E_G']))
    return q_U, beta

def reliability_voi(probe, L, r):
    # 价值不在确认世界，而在降低故障树顶事件与 beta 的不确定性
    before = entropy(q_U_posterior(L))
    after = expected_entropy(q_U_posterior(L + simulate(probe)))
    return (before - after) - cost(probe)

def proof_test(c, r, hidden_set):
    # 用已知真值/隐藏场景周期性激活潜在失效，防休眠故障
    res = run_shadow(c, hidden_set, ground_truth=True)
    r[c].tau_pt = now()
    if res.fail_rate > r[c].eps:
        r[c].qL = reconservative(r[c].qL); r[c].burn_in_left = N_burn(c)
    return r
```

def independence_test(channels, fault_injection):
    for i, j in pairs(channels):
        rho = failure_correlation(i, j, fault_injection)
        beta = ccf_beta(i, j, fault_injection)
        if rho > rho_max or beta > beta_max:
            channels[i].independent[j] = False
    return channels

def effective_redundancy(D):
    # 同源 VLA 的视觉/语言/动作出口只算一个通道
    D = merge_common_backbone(D)
    r_eff = 1
    for ch in D[1:]:
        if ch.independent and ch.rho <= rho_max and ch.beta <= beta_max:
            r_eff += (1 - ch.beta)
    return r_eff

def xmodal_evidence(b_r, D, rho, level, ccr):

### IP-144 RCMP（可靠性中心维护与可靠性导向规划）

```python
def rcmp_plan(x, task, M, r, budget, personas):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        # 先过可靠性硬约束，再做 VOI；VOI 同时看世界状态与故障树不确定性
        if not reliability_feasible(cp, r):
            m = argmin_maintenance(cp, r, {proof_test, recalibrate,
                                            switch_baseline, ask_human,
                                            retire_capability})
            if m == 'retire_capability': return safe_stop(cp)
            route = apply_maintenance(route, m); continue
        while budget.left > 0:
            p = argmax(admissible_probes(cp, M),
                       key=lambda q: voi_rel(q, r) + voi_state(q, M) - cost(q))
            if voi_rel(p, r) + voi_state(p, M) < theta_voi: break
            M, r = execute_and_learn(p, M, r)
            budget.spend(p)
        # 动作仍须 SPAC 通过，且治理器允许；否则退回基线/请人
        if spac_ok(cp, M) and governor_allows(cp, r):
            commit(cp); continue
        alt = reroute(M, cp, risk_model)
        if alt and reliability_feasible(alt, r): route = alt; continue
        return negotiate_or_stop(cp, M, r, personas,
                                 attention=uncertainty_rank(r))
    return route, r
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VRC | O(1) 查询；O(\|L_c\|) 重估 | O(\|C\|·\|X\|) | 下界有效、漂移检出、烧机期、证明测试未过期（A42） |
| SPAC | O(\|z\|·d_M) | O(\|z\|) | 检查器健全、覆盖率 γ_cov、见证独立（A41） |
| DRA | O(1)+O(1) 切换 | O(\|I\|+\|R\|) | 不变集/恢复集、驻留、看门狗、失效安全默认（A44） |
| RLL-DFT | O(\|L\|) 增量；O(\|tree\|) 求界 | O(\|L\|+\|tree\|) | 掩蔽失败保留、删失处理、β 保守（A42/A43） |
| CCRD | O(\|D\|²) | O(\|D\|²) | 独立性证据、同源去重、EV-xmodal 条件化（A43） |
| RCMP | O(\|CP\|·(\|m\|+C_VOI)) | O(\|V\|+\|σ\|) | 硬约束优先、维护预算有限、四态完备 |

**正确性定理（RGV，Reliability-Governed VLA Soundness）**
假设 A22–A40（第 53–57 轮）成立；**(A41)** 检查器 `Ch` 对可信地图与物理约束健全，证书覆盖度 `cov` 诚实，`unknown` 不被当作 `accept`；**(A42)** 可靠性账本正确处理删失与被兜底捕获的失败，`q_c^L` 在能力内可交换或慢漂移假设下是有效置信下界，变点检出后进入烧机期且旧证书失效；**(A43)** CCRD 的独立性由故障注入/联合失败证据支撑，共因因子 `β` 取保守上界，同骨干通道只计一次；**(A44)** 治理器只在认证不变集 `I` 与恢复集 `R` 内切换，驻留时间满足，看门狗与独立监测器可用，失效时默认退回 `π_B` 或安全停。则：

1. **不安全承诺界**：`q_U ≤ β·q_cc + (1−β)(q_V q_M + q_V q_B + q_M q_B) + q_C + q_G`；包络内单能力失效 `q_c ≤ ε_c` 以置信度 `1−α_rel` 成立；包络外只能提议/询问，不产生 L2/不可逆承诺。
2. **反自证性（No Self-Certification）**：VLA 的置信、自然语言解释、跨模态自洽均不能扩大 `E_c`、提高 `r_eff` 或替代 `W`；只有独立见证、证明测试、事后核验与外部监测能续期授权。
3. **多样性单调性**：`r_eff` 只统计通过独立性检验的通道；增加同源通道不降低 `q_U` 上界，不增加可用授权；`EV-xmodal` 在独立性未证时自动失效。
4. **可靠性单调性**：降级实时（监测报警/证明失败/变点即降），升级需 `n_verify`、证明测试与有界速率；可靠性状态与授权历史进入审计证书。
5. **终止性**：RCMP 在 `k_probes + k_proof` 与维护预算内终止于 {承诺, 退回基线, 维护, 安全停}。

**部署界**：

```
P_safe ≥ 1 − Σ_cp [ β·q_cc + (1−β)(q_V q_M + q_V q_B + q_M q_B)
                    + q_C + q_G + q_reliability_underestimate ]
             − P(证明测试过期未检出) − P(检查器/监测器共因失效)
             − P(治理器切换失败 ∧ 安全停失效)
```

关键：**可靠性下界给授权、证明测试给续期、独立见证给证据、治理器给兜底**；VLA 的效率与安全被解耦——VLA 可以因为表现好而获得更大包络，但不能因为"自信"而获得任何额外授权。

云边协议 CEB++ → **CEB+++**：云端可下发 VLA 权重/能力包增量，但**每次模型更新都必须先过可靠性回归门**——影子模式在边端同分布探针流上运行，要求 `q_c^L` 不劣化、包络外检出率不下降、共因 β 不上升、SPAC 覆盖率不下降，且新模型自动进入烧机期；未过门的新权重只能作为"提议者"而不能接管承诺。边端回传可靠性账本（含 mask 标志、删失信息、证明测试结果、联合失败样本），作为云端重校准与共因建模依据。第 57 轮"一切判定器走隔离"在本轮推广为"**VLA 的每次授权都要用独立失效机制来续期**"。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是"可靠性自证"——若故障账本只记录被安全网兜住后的任务失败（幸存者偏差），而监测器又与 VLA 共享感知或训练分布（共因 β 被低估），则"认证包络"会把同一个单点故障包装成多条独立证据，系统越显得有据越敢放开 VLA；必须以独立监测器、故障注入与证明测试、β 保守下界以及对掩蔽/删失数据的显式建模为护栏。
