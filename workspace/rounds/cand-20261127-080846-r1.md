### 第 1 轮灵感驱动研究记录

**灵感词**：比赛策略、状态机

**直觉与动机**：
现有证书链（Exec_v18 → … → Exec_v26）本质上是**逐帧的静态准入门**：每个控制周期对当前计划做一次合取式检查，通过则执行、否则拒证回退。它回答的是「此刻这个动作安全吗」，却回答不了三个在真实比赛中致命的问题：

1. **策略性**：在对抗性比赛（RoboCup、机器人竞速、攻防夺旗）中，安全但必败的动作也应当被拒；证书必须能对「这一步是否让我离胜利更近 / 更远」给出可证判断，而不只是「是否撞到」。
2. **时序性**：比赛是分阶段的（侦察 → 接敌 → 交锋 → 撤退 → 补给），不同阶段的证书约束不同；单帧证书无法表达「先让渡一点安全裕度换取位置优势，之后必须回到安全区」这种跨阶段的时序契约。
3. **对抗性**：对手是一个会针对我方策略做最优响应的理性（或近似理性）主体；一个「对我方模型安全」的策略可能被对手的最优反制击穿，单机 / 固定环境证书对此完全失明。

受「状态机」启发：把整个执行系统显式建模为**混合策略自动机** H = (Q, Σ, →, q0, Inv, Guard, Reset, L)——离散控制模式 Q（侦察 / 接敌 / 交锋 / 撤退 / 补给）、连续状态 x、带守卫与重置的迁移、模式不变式 Inv、以及 LTL 标签。比赛不是一串独立动作，而是自动机里的一条**受证书约束的路径**；安全性 = 所有可达状态落在安全不变式内，活性 = 最终能到达胜利 / 补给状态，无死锁 = 不存在走不出去的模式。

受「比赛策略」启发：在自动机的每条边上叠加**博弈值**——我方策略 π 与对手策略 σ 的收益 u(π,σ)、可利用度（exploitability）、遗憾（regret）、以及对手模型不确定集 Θ 下的稳健性。状态机给出「能怎么走」（结构），比赛策略给出「该往哪走」（价值）；二者是同一枚硬币的两面。

核心洞见：**证书应当从「单帧谓词」升维为「自动机上的博弈证书」——证书的载体不是某一步动作，而是整个策略自动机在对手自动机乘积下的可 winning 区域，以及在该区域内策略的 ε-可利用度。** 状态机负责把无穷多条轨迹压成有限个模式与迁移，博弈证书负责在每个模式 / 迁移上给出可复核的安全-价值双重证据。这样，「拒证」不再只是「这一步不安全」，而是「这条策略在对手最优反制下会输，且存在一条可证的、有限步的修复路径」。

**形式化目标**：
1. 定义状态机证书（STMC）：混合策略自动机 H 的安全不变式 Reach(H×M) ⊆ Safe（M 为证书监控自动机）、迁移准入（守卫可满足 ∧ 重置合法 ∧ 证书传递 pre⇒post）、无死锁与 LTL 活性 □◇goal ∨ □◇recharge、以及抽象-具体仿真的可靠性（抽象安全 ⇒ 具体安全）。
2. 定义比赛策略证书（CSC）：零和可利用度 sup_σ [u(σ,π) − u(π,σ)] ≤ ε_exp；一般和 ε-Nash 间隙 u_i(π_i,π_{-i}) ≥ max_{π_i'} u_i(π_i',π_{-i}) − ε_nash；次线性遗憾 R_T ≤ ε_regret·√T；对手模型 Wasserstein 不确定球 Θ(ρ_W) 下的稳健可利用度上界。
3. 构造乘积博弈 G = H_robot × H_adv × M，用 μ-演算吸引域算子 Attr 计算可 winning 区域 W，证明 W 上存在 ε-最优且证书保持的策略 π*，且策略合成 = 证书保持的博弈求解。
4. 构建对抗性比赛统一准入门（ACUC）：USMC ∪ SMC ∪ RMC ∪ MCC ∪ DMC ∪ XPC ∪ STMC ∪ CSC 十一证一体，Exec_v27 = Exec_v26 ∩ Fil_sm ∩ Fil_strat ⊆ Exec_v26。
5. 证明十一位一体单调退化链在模式死锁 / 策略被反制 / 对手模型失配下的保持性，并证明「W 上的策略合成 = 证书保持的博弈求解」。

**直觉层最大风险**：状态机的模式抽象可能把连续动力学中的细微危险（如边缘失稳）压成「安全模式」，使 STMC 在抽象层通过而具体系统已进入不可恢复的坏状态——即**抽象可靠性本身是整条策略证书链最脆弱的地基**。

# ============================================================
# IP-452 State Machine Certificate (STMC) — 状态机证书
# ============================================================
@dataclass
class Transition:
    q: str                      # 源模式
    q_next: str                 # 目标模式
    event: str                  # 触发事件
    guard: Callable             # Guard(x) -> bool
    reset: Callable             # Reset(x) -> x'
    cert_transfer: Callable     # (pre_certs, post_certs) -> bool

    def guard_satisfiable(self) -> bool:
        return self.guard.satisfiable()

    def reset_well_defined(self) -> bool:
        return self.reset.is_total_on(self.guard.domain())


@dataclass
class StrategyAutomaton:
    """混合策略自动机 H = (Q, Σ, →, q0, Inv, Guard, Reset, L)"""
    Q: list[str]
    Sigma: set[str]
    trans: list[Transition]
    q0: str
    Inv: dict[str, Callable]          # Inv[q](x) -> bool
    L: dict[str, set[str]]            # LTL 原子命题标签
    owner: dict[str, str]             # 每个事件由 'robot' 还是 'opp' 控制


@dataclass
class StateMachineCertificate:
    """安全不变式 + 迁移准入与证书传递 + 无死锁/活性 + 抽象仿真"""
    H: StrategyAutomaton
    monitor: 'CertificateMonitor'     # M：pass/fail/repair 监控自动机
    safe: Callable                    # Safe(q, x) -> bool（含 v26 证书）
    liveness: list['LTLFormula']      # 活性 φ_live
    abstraction: Optional['Simulation'] = None
    k_induction: int = 8              # BMC/k-归纳深度
    max_states: int = 100000          # 显式搜索上限，超出则强制抽象

    def verify_invariant(self) -> bool:
        """Reach(H × M) ⊆ Safe：所有可达模式-状态对满足安全不变式"""
        if self.abstraction is not None or self._state_bound_exceeded():
            abstract = self._build_abstraction()
            reach = self._reachable(abstract)
            return all(self._safe_abstract(s) for s in reach)
        # 具体层：先 BMC 找反例，再用 k-归纳证明不变式
        cex = self._bmc_reach_violation(self.k_induction)
        if cex is not None:
            return False
        return self._k_inductive_invariant()

    def verify_transition_admissibility(self) -> bool:
        """∀t=(q,g,e,r,q')：守卫可满足 ⇒ 重置合法 ⇒ 证书传递 pre⇒post"""
        for tr in self.H.trans:
            if not tr.guard_satisfiable():
                continue
            if not tr.reset_well_defined():
                return False
            # 复用 v25/v26 证书传递：SOC/FCC/LSC/DMC/XPC 在 q→q' 上保持
            pre = self.monitor.certificates_at(tr.q)
            post = self.monitor.certificates_at(tr.q_next)
            if not tr.cert_transfer(pre, post):
                return False
        return True

    def verify_deadlock_freedom(self) -> bool:
        """∀q∈Q：若非终止/胜利模式，则存在机器人可控事件使能"""
        for q in self.H.Q:
            if self._is_terminal_or_win(q):
                continue
            enabled = [t for t in self.H.trans if t.q == q and t.guard_satisfiable()]
            if not any(self.H.owner[t.event] == 'robot' for t in enabled):
                return False
        return True

    def verify_liveness(self) -> bool:
        """LTL 活性：在乘积自动机上做 Büchi/parity 空性检查"""
        product = self._product_with_monitor()
        return all(not self._ltl_empty(product, phi) for phi in self.liveness)

    def verify_abstraction_soundness(self) -> bool:
        """∼_sim 保持 Safe：抽象安全 ⇒ 具体安全（过近似方向）"""
        if self.abstraction is None:
            return True
        return self.abstraction.is_simulation_preserving(self.safe)

    def verify_all(self) -> bool:
        return (self.verify_invariant() and
                self.verify_transition_admissibility() and
                self.verify_deadlock_freedom() and
                self.verify_liveness() and
                self.verify_abstraction_soundness())


# ============================================================
# IP-451 Competitive Strategy Certificate (CSC) — 比赛策略证书
# ============================================================
@dataclass
class CompetitiveStrategyCertificate:
    """零和可利用度 + 一般和 ε-Nash + 次线性遗憾 + Wasserstein 稳健性"""
    game: 'GameModel'                 # u(π,σ)、策略空间、信息结构
    pi: 'Strategy'                    # 我方模式条件策略 π(a|q,x)
    opponent_model: 'OpponentModel'   # 对手模型 + 不确定集 Θ(ρ_W)
    eps_exp: float = 0.05             # 零和可利用度上界
    eps_nash: float = 0.05            # 一般和 Nash 间隙
    eps_regret: float = 0.10          # 遗憾系数（√T 归一）
    rho_W: float = 0.02               # Wasserstein 球半径
    horizon_T: int = 1000
    n_br: int = 64                    # 最优响应采样数

    def verify_exploitability(self) -> bool:
        """零和：sup_σ [u(σ,π) − u(π,σ)] ≤ ε_exp"""
        if not self.game.is_zero_sum:
            return True  # 一般和走 Nash 间隙
        sigma_br = self.game.best_response(self.pi, n=self.n_br)
        best_response_value = self.game.payoff(sigma_br, self.pi)  # 对手收益
        own_value = self.game.payoff(self.pi, sigma_br)            # 我方收益
        return (best_response_value + own_value) <= self.eps_exp

    def verify_nash_gap(self) -> bool:
        """一般和：u_i(π_i,π_-i) ≥ max_{π_i'} u_i(π_i',π_-i) − ε_nash"""
        for i in range(self.game.N):
            br_i = self.game.best_response_i(i, self.pi, n=self.n_br)
            gap = self.game.u(i, br_i, self.pi) - self.game.u(i, self.pi, self.pi)
            if gap > self.eps_nash:
                return False
        return True

    def verify_regret(self, action_values: Tensor) -> bool:
        """R_T = max_{a} Σ_t [u(a,σ_t) − u(π_t,σ_t)] ≤ ε_regret·√T"""
        cum = action_values.cumsum(dim=0)              # [T, |A|]
        realized = cum.gather(1, self.game.action_trace)  # [T, 1]
        regret = (cum.max(dim=1, keepdim=True).values - realized).sum().item()
        return regret <= self.eps_regret * math.sqrt(self.horizon_T)

    def verify_robustness(self) -> bool:
        """∀θ∈Θ(ρ_W)：exploitability(π,θ) ≤ ε_exp（分布鲁棒博弈对偶形式）"""
        worst = self.opponent_model.worst_case_exploitability(
            self.pi, radius=self.rho_W, n_samples=self.n_br)
        return worst <= self.eps_exp

    def verify_all(self, action_values: Optional[Tensor] = None) -> bool:
        ok = (self.verify_exploitability() and
              self.verify_nash_gap() and
              self.verify_robustness())
        if action_values is not None:
            ok = ok and self.verify_regret(action_values)
        return ok

@dataclass
class ProductGame:
    """G = H_robot × H_adv × M，在证书监控下求解可 winning 区域"""
    H_robot: StrategyAutomaton
    H_adv: StrategyAutomaton
    monitor: 'CertificateMonitor'
    safe: Callable

    def states(self) -> list:
        return [(q1, q2, qm) for q1 in self.H_robot.Q
                for q2 in self.H_adv.Q for qm in self.monitor.Q_M]

    def winning_region(self) -> set:
        """W = 最大可控安全不变集：
        对对手事件要求所有后继留在 W，对机器人事件要求存在后继留在 W。"""
        W = {s for s in self.states() if self.safe(s)}
        while True:
            nxt = {s for s in W
                   if self._all_opp_successors_in(s, W)
                   and self._exists_robot_successor_in(s, W)}

# ============================================================
# IP-453 ACUC — 对抗性比赛统一准入门
# ============================================================
@dataclass
class AdversarialCompetitiveUnifiedCertificate:
    xduc: 'ExplainableDexterousUnifiedCertificate'
    stmc: StateMachineCertificate
    csc: CompetitiveStrategyCertificate
    product: ProductGame

    def admits(self, plan, sensor_data, hand_model,
               action_values: Optional[Tensor] = None) -> tuple[bool, dict]:
        # 1) 先过 v26 九证（单机 + 语义 + 重构 + 协同 + 灵巧 + 可解释）
        ok, info = self.xduc.admits(plan, sensor_data, hand_model)
        if not ok:
            return False, {'stage': 'v26', **info}

        # 2) 乘积博弈：必须存在非空、证书保持的 winning 区域
        W = self.product.winning_region()
        if not W:
            return False, {'stage': 'product_game', 'reason': 'empty_winning_region'}

        # 3) 状态机证书：不变式 / 迁移 / 无死锁 / 活性 / 抽象可靠
        if not self.stmc.verify_all():
            return False, {'stage': 'STMC', 'failed': self._failed_stmc()}

        # 4) 比赛策略证书：可利用度 / Nash / 遗憾 / 稳健性
        if not self.csc.verify_all(action_values):
            return False, {'stage': 'CSC',
                           'exploitability': self.csc.verify_exploitability(),
                           'nash_gap_ok': self.csc.verify_nash_gap(),
                           'robust_ok': self.csc.verify_robustness()}

        # 5) 在 W 上合成证书保持的 ε-最优策略
        strategy = self.product.synthesize(W)
        return True, {'stage': 'admit', 'winning_region': W, 'strategy': strategy}

    def _failed_stmc(self) -> dict:
        return {
            'invariant': self.stmc.verify_invariant(),
            'transition': self.stmc.verify_transition_admissibility(),
            'deadlock_free': self.stmc.verify_deadlock_freedom(),
            'liveness': self.stmc.verify_liveness(),
            'abstraction': self.stmc.verify_abstraction_soundness(),
        }

# 端到端流水线：在 v26 之上加入策略-状态机环
# ============================================================
class AdversarialCompetitivePipeline:
    def __init__(self, config: dict):
        self.acuc = AdversarialCompetitiveUnifiedCertificate(
            xduc=config['xduc'],
            stmc=StateMachineCertificate(
                H=config['H'], monitor=config['monitor'], safe=config['safe'],
                liveness=config['liveness'], abstraction=config.get('abstraction'),
                k_induction=config['k_induction']),
            csc=CompetitiveStrategyCertificate(
                game=config['game'], pi=config['pi'],
                opponent_model=config['opponent_model'],
                eps_exp=config['eps_exp'], eps_nash=config['eps_nash'],
                eps_regret=config['eps_regret'], rho_W=config['rho_W'],
                horizon_T=config['horizon_T']),
            product=ProductGame(
                H_robot=config['H'], H_adv=config['H_adv'],
                monitor=config['monitor'], safe=config['safe']))

    def step(self, plan, sensor_data, hand_model, action_values=None):
        admitted, info = self.acuc.admits(plan, sensor_data, hand_model, action_values)
        # 拒证时输出：失败的 STMC 子项 + 当前可利用度 + 可回退模式
        info['fallback_mode'] = self._select_fallback(info) if not admitted else None
        return admitted, info

| CSC Nash 间隙 | O(N·n_br·C_payoff) | O(N·n_br) | N≤10 机 |
| CSC 遗憾 | O(T·|A|) 前缀和 | O(T·|A|) | |A|≤20 离散动作 |
| CSC Wasserstein 稳健 | O(n_br·n_samples·C_payoff) | O(n_samples) | n_samples=256 |
| 乘积 winning 区域 | O(|V|·|E|) 吸引域迭代 | O(|V|+|E|) | |V|≤|Q|³, |E|≤|V|·|Σ| |
| 策略合成 CFR | O(iter·|I|·|A|) | O(|I|·|A|) | iter≤10³, |I|≤|V| |
| ACUC 准入判定 | v26 + O(|V|·|E|) + O(iter·|I|·|A|) | +O(|V|+|I|·|A|) | 关键路径在博弈求解 |
| 端到端单步（增量） | +O(|V|·|E|)（增量吸引域）+ 低频 CFR | +O(|V|) | 5 模式 × 3 对手模式 → +4~8ms |

**实时性保证**：STMC 的不变式与 LTL 检查、CSC 的利用度/遗憾评估、以及 winning 区域求解均为**离线或事件触发**（模式切换、对手模型更新、策略重规划，≤2Hz）；控制环内只做 O(|→|) 的迁移准入查表与 O(1) 的证书状态查询。故 50Hz 控制环关键路径不增加。

## 3. 正确性论证（增量）

### 引理 17（状态机证书的不变-迁移-无死锁-活性-抽象五重保证）
**陈述**：`STMC.verify_all() = True` ⟹ 策略自动机同时满足：
(1) 安全不变式：所有可达模式-状态对 (q,x) ∈ Reach(H×M) 满足 Safe(q,x)；
(2) 迁移准入：∀t=(q,g,e,r,q')，若 g 可满足则 r 合法，且 v26 证书在 q→q' 上传递（pre⇒post）；
(3) 无死锁：每个非终止模式都存在机器人可控的使能迁移；
(4) 活性：φ_live = □◇goal ∨ □◇recharge 在乘积自动机上非空；
(5) 抽象可靠：若使用抽象，则 ∼_sim 保持 Safe（抽象安全 ⇒ 具体安全）。

**证明**：
1. `verify_invariant` 有两条路径：具体层先由 BMC 在深度 k 内搜索可达违例，再用 k-归纳证明「初始满足 ∧ 连续 k 步保持 ⇒ 不变式恒成立」；抽象层在过近似自动机上显式枚举可达集。两条路径返回 True 均意味着不存在违例，故 (1)。
2. `verify_transition_admissibility` 对每条可满足守卫的迁移检查重置全域性，并调用 v25/v26 的证书传递谓词（SOC/FCC/LSC/DMC/XPC 前后单调关系）；这与 RMC 的证书传递同构，故迁移不制造证书真空，得 (2)。
3. `verify_deadlock_freedom` 逐模式要求存在机器人事件使能；对手事件不受控，故只对机器人可控边要求存在性，正确对应「机器人总能做出选择」的死锁定义，得 (3)。
4. `verify_liveness` 把 H 与监控自动机 M 做积，在积上检查 Büchi/parity 接受条件非空；非空即存在无限运行满足 □◇goal ∨ □◇recharge，得 (4)。
5. `verify_abstraction_soundness` 验证仿真关系；仿真是过近似，抽象层的 Safe 覆盖具体层的 Safe，故抽象安全蕴含具体安全，得 (5)。
五条分别对应「不越界、换得稳、走得动、活得到、抽得对」，缺一不可。∎

### 引理 18（比赛策略证书的可利用-Nash-遗憾-稳健四重保证）
**陈述**：`CSC.verify_all() = True` ⟹ 策略 π 同时满足：
(1) 零和可利用度：sup_σ [u(σ,π) − u(π,σ)] ≤ ε_exp；
(2) 一般和 ε-Nash：∀i，u_i(π_i,π_{-i}) ≥ max_{π_i'} u_i(π_i',π_{-i}) − ε_nash；
(3) 次线性遗憾：R_T ≤ ε_regret·√T；
(4) 稳健性：∀θ∈Θ(ρ_W)，exploitability(π,θ) ≤ ε_exp。

**证明**：
1. 零和情形下最优响应值由 `best_response` 近似求得，可利用度 = 对手最优响应收益 + 我方对应收益（零和归一），≤ ε_exp 即策略不可被显著利用，得 (1)。
2. 一般和对每个参与者分别计算单边偏离增益；所有增益 ≤ ε_nash 即构成 ε-Nash 均衡，得 (2)。
3. 遗憾用动作价值的前缀和计算：max 动作累计收益与实现收益之差即外部遗憾；≤ ε_regret·√T 是次线性遗憾的定义式，保证长期平均策略收敛到粗相关均衡，得 (3)。
4. 在 Wasserstein 球 Θ(ρ_W) 内取最坏对手模型计算可利用度；分布鲁棒博弈的对偶理论保证该上界对球内所有分布成立，得 (4)。
四条分别约束「不被利用、不单边后悔、长期不亏、模型漂移不崩」。∎

### 引理 19（乘积博弈 winning 区域的可靠性与证书保持策略合成）
**陈述**：设 G = H_robot × H_adv × M，W 为 `winning_region()` 的输出。则：
(1) W 是最大可控安全不变集：W ⊆ Safe，且从任意 s∈W，对手的任意事件后继仍在 W、机器人存在事件后继留在 W；
(2) 若 W 非空，则存在策略 π* = `synthesize(W)`，使得在对手任意策略下，乘积运行始终留在 W，且 π* 的可利用度 ≤ ε_exp；
(3) 策略合成过程不破坏任何已通过的证书（证书保持）。

**证明**：
1. 吸引域迭代从 Safe 出发，每轮只保留「对手所有后继在 W」且「机器人存在后继在 W」的状态；不动点即最大可控安全不变集，得 (1)。
2. 由 (1) 的封闭性，机器人按「选择使后继留在 W 的边」即可对抗任意对手事件而永不离开 W；在该受限博弈上用 CFR 迭代，平均策略的可利用度单调下降至 ≤ ε_exp，得 (2)。
3. 每个乘积状态携带 M 的证书状态；W ⊆ Safe 已要求所有证书 pass，且迁移准入（引理 17(2)）保证转移不破坏证书，故合成策略只在证书通过的状态与迁移上取动作，得 (3)。
∎

### 引理 20（十一位一体单调退化链 v27 延伸）
**陈述**：任意单点/组合失效下，`Exec_v27 ⊆ Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：`ACUC.admits = xduc.admits ∧ (W≠∅) ∧ STMC ∧ CSC`，故 Exec_v27 是 Exec_v26 与两个新过滤器的交集。增加三种退化路径：
- 模式死锁 / 不变式违反 / 活性丧失 / 抽象不可靠 → `STMC.verify_all=false` → `ACUC` 拒证 → 退回 `Exec_v26`（冻结自动机，停留在当前已验证安全模式，放弃跨阶段策略推进）。
- 策略被反制 / 可利用度超界 / 遗憾线性增长 / 对手模型失配 → `CSC.verify_all=false` → `ACUC` 拒证 → 退回 `Exec_v26`（放弃对抗性最优，转为保守的证书保底策略，只求安全不求取胜）。
- winning 区域为空 → 拒证 → 退回 `Exec_v26`（当前对手模型下无证书保持的取胜策略，转为防守 / 撤退的 v26 安全计划）。
- 组合失效：取交集，单调性由集合交的传递性保持。
另：策略层只在对抗性 / 跨阶段任务中启用，正常单步准入不扩张执行集，故不会出现 Exec_v27 ⊄ Exec_v26。∎
