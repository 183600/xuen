# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环第 6 轮；本轮灵感：「动作分块」×「视觉-语言-动作模型」）

> 第 59 轮把「证据承诺」一路下沉到执行物理：BUQ 辨识电机结构化不确定性、ERTC 契约化嵌入式实时性、EEIS 把概率安全界编译成阻抗参数、CLEP 双向闭环、PCE+++ 四预算耦合。但它仍隐含两个更强的假设：**（i）承诺是原子的**——一个检查点对应一次探针/一次动作，执行完再收集证据；**（ii）动作是高层的符号量**——由规划器或人工规则直接给出。本轮两个灵感精准击穿这两个假设：**动作分块**（action chunking）把未来 H 步压成一次「批量承诺」，执行时开环滚动、块末重规划——承诺在证据之前、且一次失败会沿时间轴回溯污染整段前缀；**视觉-语言-动作模型**（VLA）从图像+指令直接生成动作块，其置信度是**指称不确定性、指令歧义、动作精度**的混合物——高置信度完全可能对应「抓错物体」。本轮核心命题：**「把动作块从『一串动作』升级为『带可撤销前缀与风险预算的时序契约』；把 VLA 从『策略』降格为『提议源』，其语义指称必须由独立证据接地，其动作通道才可被共形校准」**——即**时序-语义动作接地（TAGE）**。

核心矛盾：
- **H32（块级承诺·证据早于执行）**：单块执行是 `a_{1:H}` 的批量承诺。若第 j 步才发现失败，前 j−1 步已经发生，证据却在承诺之后才到达。第 59 轮的证据门假设「执行—观测—判定」是闭环原子操作，分块把它变成**开环段 + 迟到证据**。必须区分**可撤销前缀**（reversible prefix，可回滚/无接触）与**不可逆后缀**（irreversible suffix，接触/移动/消耗），并把「承诺度」显式化为契约参数。
- **H33（语义指称·VLA 置信度不是证据）**：VLA 的 log-prob / energy 同时混合了「指的是哪个物体/区域」（指称）、「指令到底是什么意思」（歧义）、「这个动作能不能执行」（动作精度）。把 VLA 置信度当证据，等价于把 59 轮刚否定的「执行自证」再犯一次。必须做**语义-动作双通道分解 SADD**：指称通道只能被视觉/触觉/探针等独立模态接地，动作通道才可用块级共形校准。
- **H34（推理时钟域·块长两难）**：VLA 推理延迟 100 ms~1 s，控制周期 5~50 ms，相差 1~2 个数量级。分块存在的**根本理由**就是摊销推理延迟：块越长，单位任务推理次数越少；但块越长，开环漂移、观测陈旧、块边界不连续越严重。块的尽头不是「更长的计划」，而是**延迟摊销收益与开环漂移成本的交点**。

## 0. 直觉与动机

**灵感 1（动作分块 → 时间抽象契约 ACC）**
直觉：动作块不是「更长的动作列表」，而是**一份带期限的批量承诺**。人类抓杯子不会每一步重算，而是在一个「动作块」内开环执行，并在关键节点（接触前、松手前）重新看世界。关键洞见：**分块把「每步验证」换成「块级承诺」，安全论证必须从「单步失败概率」升级为「前缀累积风险 + 可撤销性结构」**。定义三类结构：可撤销前缀（可回滚、无不可逆接触）、守卫点（guard points，力/碰撞/工作空间/稳定性的硬检查）、不可逆后缀（一旦执行不可撤销）。只有当证据充分性超过阈值时，才允许把承诺推进到不可逆段。于是「块」变成一个**实物期权组合**：前缀是已行权的确定动作，后缀是保留「放弃权」的或有动作。

**灵感 2（VLA → 语义-动作双通道分解 SADD）**
直觉：一个 VLA 说「抓左边红色的杯子」，其总不确定性可链式分解为 `U(a_{1:H}, r | o, ℓ) = U(r | o, ℓ) + E[U(a_{1:H} | r, o, ℓ)]`：前一项是**指称不确定性**（哪个物体/哪个区域/哪种可供性），后一项是**动作不确定性**（给定指称后的轨迹精度）。VLA 的自报置信度往往只反映后一项（甚至只是 token 似然），却被人误读为整体可靠。关键洞见：**指称通道不可由 VLA 自证，只能由独立模态接地**——视觉区域重叠、触觉探针、先验地图、人类澄清；动作通道才可用共形预测在块级校准。于是有了「**VLA 只提议、不执行、不作证**」的三不原则。

**灵感 3（VLA × 动作分块 → 推理摊销与开环漂移的取舍 LHC）**
直觉：分块是对推理延迟的**摊销**：一次前向，执行 H 步。摊销的收益是推理成本下降，利息是开环漂移。设推理延迟 `τ_inf`、控制周期 `Δt`，则块长必须至少覆盖延迟：`H_min = ceil(τ_inf^{q99}/Δt) + H_margin`，否则执行到一半就要停下来等下一次推理。但 `H` 越大，块内观测越陈旧、拼接越不连续、失败回溯代价越大。存在唯一的最优块长 `H*`，由「漂移成本 + 推理摊销成本 + 拼接风险」三项之和最小化给出。**这就是「动作分块」的严谨版本：不是超参数，而是延迟、漂移、预算三者的最优点。**

**灵感 4（三灵感合流 → 提议-验证-分块执行算子 PVCE）**
直觉：`VLA 提议 N 个块 → SADD 指称门 → 影子仿真先验筛选（EV-sim 仅作先验，不作证据）→ ACC 编译块契约 → LHC 选块长与新鲜前缀 → 执行可撤销前缀并逐步守卫 → 块边界重承诺（用新鲜观测复核）→ 产出 EV-chunk → CCC 块级共形校准`。VLA 永远不直接驱动执行器；它只往「提议池」里放候选，所有候选必须过证据门与契约编译。**块边界重承诺**是关键：不是把整块一次执行完，而是在可撤销/不可逆分界、以及证据鲜度耗尽处强制重新观测。

**灵感 5（PCE++++ → 推理预算与接地预算）**
直觉：第 59 轮已有 B_probe / B_ft / B_ux / B_exec；本轮新增 **B_inf（推理预算：加速器时延、队列长度、token/显存）** 与 **B_sem（语义接地预算：为消除指称不确定性可支付的探针/澄清/重观测次数）**。VOI 扩展为 `voi = VOI_meta_pessimistic − cost_exec − cost_inf − cost_sem`。当 B_inf 紧张 ⇒ 增大块长以摊销推理（但受 LHC 上限约束）；当 B_sem 紧张 ⇒ 拒绝高指称不确定性的提议、退向已接地区域或请求人类澄清；两者同时耗尽 ⇒ 切反应式保守策略或安全停。

## 1. 形式化定义（增量：定义 153–161）

**定义 153（动作块契约 ACC）** 动作块契约是一个七元组
`C = (H, {a_i}_{i=1..H}, {δ_i}_{i=1..H}, k_rev, 𝒢, Π_abort, Validity)`，其中 `H` 为时域，`a_i∈ℝ^{d_a}`，`δ_i` 为第 i 步归属失败概率，`k_rev∈[0,H]` 为可撤销前缀长度（前 `k_rev` 步可回滚且不含不可逆接触），`𝒢={g_i}` 为逐步守卫谓词（力上限、碰撞、工作空间、稳定性、温度），`Π_abort: 遥测前缀 → {continue, replan, rollback, stop}` 为中止策略，`Validity` 为有效期。定义：
- 块级风险 `δ_C = 1 − ∏_{i=1}^{H}(1−δ_i) ≤ Σ_i δ_i`；
- 前缀风险 `δ_prefix(k) = 1 − ∏_{i=1}^{k}(1−δ_i)`；
- 承诺度 `κ(C) = 1 − k_rev/H ∈ [0,1]`（不可逆步占比）。
安全义务：**(O1)** 任意中止点 k，已执行前缀风险 `δ_prefix(k) ≤ δ_C^req`；**(O2)** 第 j 步若 `j > k_rev`（不可逆），则必须 `E(a_{1:j}) ≥ θ_evid`（证据充分性）；**(O3)** 每步执行前守卫 `g_i` 为真，守卫违例 ⇒ 一个控制周期内进入 `Π_abort`。证书 `Cert_chunk=(H,k_rev,{δ_i},δ_C,𝒢,κ,policy_hash,vla_id,adapter_hash,t0)`，不可篡改、版本单增。

**定义 154（块内风险预算分配 CRBA）** 给定块风险预算 `δ_C^req`，分配 `{δ_i}`：
```
δ_i = δ_C^req · w_i / Σ_j w_j ,   w_i ∝ exp(λ_drift·(i−1)) ,  λ_drift ≥ 0
s.t.  δ_i ≤ δ_max,  δ_i 单调不减（漂移导致后段更不确定）
```
同时定义**后缀期权价值** `V_opt(k)`：执行到第 k 步后保留「重新观测并重规划」权利的价值。选择提交长度
```
k* = argmax_{k ≤ H} [ Progress(prefix_k) − λ_risk·δ_prefix(k) + V_opt(k) ]
```
其中 `V_opt(k)` 随 k 递减（越往后，放弃的沉没成本越高），故 `k*` 通常严格小于 H。**CRBA 的严谨含义：不是把预算平均摊到每步，而是让「后段更不确定 + 后缀更值钱」共同决定提交边界。**

**定义 155（时滞-块长耦合 LHC）** 设 VLA 推理延迟上界 `τ_inf^{q99}`、控制周期 `Δt`、证据鲜度阈值 `τ_fresh`（承接 ERTC 的 Renewal_period）。定义：
- 最小块长 `H_min = ceil(τ_inf^{q99}/Δt) + h_safe`；
- 新鲜前缀长度 `k_fresh = floor((τ_fresh − τ_inf^{q99})/Δt)`（超出此长度的步只能执行可撤销动作）；
- 开环漂移上界 `D(H) ≤ ε_0 + L·v_max·H·Δt`（Lipschitz 常数 L）；
- 拼接不连续度 `J_stitch = ||a_H^{(k)} − a_1^{(k+1)}||`；
- 任务时长 T 下推理次数 `N_inf(H) = ceil(T / max(H − k_rev, 1))`。
最优块长：
```
H* = argmin_{H ≥ H_min} [ D(H) + λ_inf·cost_inf(N_inf(H)) + λ_stitch·P(J_stitch > θ_stitch) ]
```
并强制 `k_fresh ≥ k_rev`，否则加密重观测点或拒绝不可逆段。**LHC 把「块长」从经验超参变成可证明的优化变量。**

**定义 156（VLA 语义-动作双通道分解 SADD）** 将 VLA 提议分解为
```
p(a_{1:H}, r | o, ℓ) = p(r | o, ℓ) · p(a_{1:H} | r, o, ℓ)
```
其中 `r=(object_id, region, affordance, frame)` 为指称变量，`o` 为观测，`ℓ` 为指令。定义：
- 指称不确定性 `U_sem = H(r | o, ℓ)`；
- 动作不确定性 `U_mot = E_{r~p(r|o,ℓ)}[H(a_{1:H} | r,o,ℓ)]`；
- 链式分解 `U_total = U_sem + U_mot`（互信息非负）；
- 指称一致性 `C_ref = IoU(region_VLA, region_fused)`（或标签 TV 的补）；
- 指称 OOD 判定：`C_ref < θ_ref ∨ U_sem > θ_sem ∨ (ℓ 指称的对象不在 M 中)`。
关键约束：**`U_mot` 可用块级共形校准；`U_sem` 不可由 VLA 自证，必须由独立模态（视觉/触觉/探针/人类）降低**。VLA 自报的 `logprob` 不得进入 `EV-xmodal` 或任何佐证集。

**定义 157（提议-验证-分块执行 PVCE）** 算子 `PVCE(M, ℓ, task, δ_req, budget)`：
```
① 提议:   {(C_k, r_k, s_k)}_{k=1..N} ← VLA.propose(o, ℓ, N)
② 语义门: 对每个提议做 SADD，拒绝 C_ref<θ_ref ∨ U_sem>θ_sem ∨ 指称不在 M
③ 影子仿真: EV-sim ← shadow_rollout(C_k, M)   # 仅先验，不作证据
④ 契约编译: Cert_chunk ← ACC.compile(C_k, δ_req, M.evidence)
          若不可行 → 截断到不可逆前一步 或 丢弃
⑤ 块长选择: (H*, k_fresh, k_rev) ← LHC.select(τ_inf, Δt, τ_fresh, budget_inf)
⑥ 前缀执行: 仅执行前 k_rev 步（或 k_fresh 步），每步检查守卫 g_i
⑦ 边界重承诺: 块边界/守卫触发/鲜度耗尽 ⇒ 重新观测、SADD 复核、重规划
⑧ 证据回传: EV-chunk ← build_ev_chunk(执行前缀, Cert_chunk, 遥测, 时延)
⑨ 校准:     CCC.update(EV-chunk)   # 块级共形，不更新步级
⑩ 返回: (M, 已执行轨迹, EV-chunk, Cert_chunk)
```
不变式：**VLA 只写提议池，不写执行器；任何进入执行器的动作必须携带 `Cert_chunk` 且通过守卫。**

**定义 158（块级共形校准 CCC）** 在**块层面**（而非步层面）构造校准集 `{(o_j, ℓ_j, C_j, y_j)}`，`y_j` 为前缀执行结果（成功/成本）。非一致性分数 `s_j = 1 − success_j` 或 `s_j = normalized_cost_j`。由于相邻块在时间上重叠，步级样本不满足可交换性，必须：
- 按**互不重叠块**取样，保证块级可交换性（block exchangeability）；
- 对语义分组（指令类型/物体类别）做 **group-conditional conformal**，避免「简单指令高覆盖、危险指令低覆盖」；
- 对 VLA 适配器/指令分布漂移做**加权共形**，覆盖率下界为 `1−α−δ_shift`。
输出**前缀成功率下界** `LCB_success(k) = 1−α`，作为 ACC 的 `E(a_{1:k})` 输入之一。

**定义 159（动作块证据 EV-chunk 与 XMC++）**
```
EV-chunk = (proposal_id, ref_consistency, U_sem, U_mot,
            H, k_exec, k_rev, prefix_success, J_stitch,
            latency_actual, abort_flag, cert_hash, vla_id, adapter_hash)
```
规则扩展：**(R1⁺⁺)** `EV-chunk` 只作「提议来源 + 执行一致性」证据，**不得替代 EV-xmodal / EV-exec / EV-human**；**(R2⁺⁺)** 时间一致性分歧 `D_time = J_stitch/θ_stitch + |τ_actual−τ_planned|/τ_fresh`，仅用于**加宽后验**，块间一致**不得减少**探针需求；**(R3⁺⁺)** `ref_consistency < θ_ref` ⇒ 该块的执行证据权重乘性降级，并回溯标记同源提议。

**定义 160（时序-语义动作接地证书 J_tage）**
```
J_tage = (Cert_chunk_chain, VLA_adapter_chain, CCC_calibration_set_hash,
          SADD_log, EV-chunk_log, LHC_decision_log, latency_audit,
          budget_snapshots, degradation_log, version, timestamp)
```
`verify_chain()` 检查：证书版本单增、`k_rev` 与不可逆标注一致、`CCC` 校准集哈希与实际一致、`τ_actual ≤ τ_inf^{q99}`、每个不可逆步都有证据充分性记录。

**定义 161（PCE++++ 与推理/接地预算）** 新增
`B_inf = (accelerator_latency_slack, queue_slack, mem_slack, token_slack)`；
`B_sem = (grounding_probe_budget, clarification_budget, reobserve_budget)`。
```
voi_pvce(π) = VOI_meta_pessimistic(π) − cost_exec − cost_inf − cost_sem
cost_inf = λ_lat·max(0, τ_inf(π)−τ_inf_slack) + λ_tok·max(0, tok(π)−token_slack)
cost_sem = λ_g·(探针/澄清/重观测次数 − B_sem 剩余)
```
预算耗尽策略：`B_inf` 耗尽 ⇒ 增大 H（摊销）但不超过 LHC 的 `H_max`，同时扩大可撤销段；`B_sem` 耗尽 ⇒ 拒绝高 `U_sem` 提议、只执行已接地区域、请求人类澄清；两者同时耗尽 ⇒ 切反应式策略或安全停。**五预算硬隔离、互不挪用。**

## 2. 关键算法伪代码（概要，完整版见产物区）

### IP-152 ACC（动作块契约编译）
```python
def compile_chunk_contract(chunk, delta_req, evidence, M):
    delta_i = crba_allocate(delta_req, chunk.H, lam_drift)
    delta_C = 1 - np.prod(1 - delta_i)
    if delta_C > delta_req + 1e-12:
        return None
    k_rev = reversible_prefix_len(chunk.actions)      # 可回滚、无不可逆接触
    for j in range(k_rev + 1, chunk.H + 1):
        if evidence.sufficiency(M, chunk.actions[:j]) < theta_evid:
            k_rev = j - 1                              # 截断到不可逆前
            break
    guards = compile_guards(chunk, delta_i, M)
    return CertChunk(chunk.H, k_rev, delta_i, delta_C, guards,
                     abort_policy=default_abort, kappa=1-k_rev/chunk.H)
```

### IP-154 LHC（块长选择）
```python
def select_horizon(tau_inf_q99, delta_t, tau_fresh, drift_model, budget_inf, T):
    H_min = ceil(tau_inf_q99 / delta_t) + H_margin
    best = None
    for H in range(H_min, H_max + 1):
        k_fresh = floor((tau_fresh - tau_inf_q99) / delta_t)
        drift = drift_model.expected_error(H)
        n_inf = ceil(T / max(H - k_rev, 1))
        J = drift + LAMBDA_INF * budget_inf.cost(n_inf) \
            + LAMBDA_STITCH * stitch_risk(H, drift)
        if best is None or J < best.J:
            best = (H, k_fresh, J)
    return best
```

### IP-155 SADD（语义-动作分解与指称门）
```python
def sadd_decompose(ref_dist, action_dists):
    U_sem = entropy(ref_dist)
    U_mot = sum(p * entropy(d) for p, d in zip(ref_dist.probs, action_dists))
    return U_sem, U_mot            # U_total = U_sem + U_mot

def referential_gate(ref, fused_belief, theta_ref, theta_sem):
    if entropy(ref) > theta_sem:
        return False
    if ref.object_id not in fused_belief.known_objects:
        return False
    return iou(ref.region, fused_belief.region) >= theta_ref
```

### IP-156 PVCE（提议-验证-分块执行）
```python
def propose_verify_chunk_execute(M, ell, task, delta_req, budget):
    proposals = vla.propose(M.obs, ell, N=8)
    survivors = []
    for p in proposals:
        U_sem, U_mot = sadd_decompose(p.ref_dist, p.action_dists)
        if not referential_gate(p.ref, M.fused, theta_ref, theta_sem):
            continue
        sim = shadow_rollout(p.chunk, M)              # EV-sim：仅先验
        if not sim.feasible:
            continue
        cert = compile_chunk_contract(p.chunk, delta_req, M.evidence, M)
        if cert is None:
            continue
        survivors.append((p, cert, U_sem, U_mot))
    if not survivors:
        return negotiate_or_stop(M, ell, reason="no_grounded_proposal")
    p, cert, U_sem, U_mot = max(survivors, key=voi_pvce)
    H_star, k_fresh, _ = select_horizon(...)
    k_exec = min(cert.k_rev, k_fresh, H_star)
    for i in range(1, k_exec + 1):
        if not check_guard(cert.guards[i], M.telemetry):
            return abort_replan_or_stop(M, cert, i)
        execute(p.chunk.actions[i])
    ev = build_ev_chunk(p, cert, k_exec, M.telemetry, U_sem, U_mot)
    if ev.prefix_success and reobserve(M) == "consistent":
```

```python
    """最长的『全可撤销』前缀长度"""
    k = 0
    while k < chunk.H and bool(chunk.reversibility[k]):
        k += 1
    return k
```

### IP-153 CRBA（块内风险预算与后缀期权）

```python
def crba_allocate(delta_req, H, lam_drift, delta_max=1e-3):
    """指数非均匀分配：后段更不确定；裁剪后重归一化，保证 Σδ_i ≤ delta_req"""
    i = np.arange(1, H + 1)
    w = np.exp(lam_drift * (i - 1))
    delta = delta_req * w / w.sum()
    delta = np.minimum(delta, delta_max)
    # 裁剪释放出的预算重新分给未饱和步（后段优先）
    for _ in range(8):
        remaining = delta_req - delta.sum()
        if remaining <= 1e-15:
            break
        open_mask = delta < delta_max - 1e-15
        if not open_mask.any():
            break
        w_open = w * open_mask
        delta = delta + remaining * w_open / w_open.sum()
        delta = np.minimum(delta, delta_max)
    return delta

def option_value(k, H, progress_gain, reobserve_cost, risk, gamma=0.95):
    """后缀期权：越往后，放弃的沉没成本越高，期权价值越低"""
    if k >= H:
        return -reobserve_cost
    expected_remaining = sum(gamma ** (j - k) * progress_gain
                             for j in range(k + 1, H + 1))
    expected_risk = risk * (H - k)
    return max(0.0, expected_remaining - expected_risk) - reobserve_cost

def commit_length(cert, progress_gain, reobserve_cost, lam_risk):
    best_k, best_val = cert.k_rev, -np.inf
    for k in range(0, min(cert.k_rev, cert.H) + 1):
        prefix_risk = 1.0 - np.prod(1.0 - cert.delta[:k]) if k > 0 else 0.0
        val = (k * progress_gain - lam_risk * prefix_risk
               + option_value(k, cert.H, progress_gain, reobserve_cost, lam_risk))
        if val > best_val:
            best_val, best_k = val, k
    return best_k
```

### IP-154 LHC（时滞-块长耦合）

```python
@dataclass
class HorizonDecision:
    H: int
    k_fresh: int
    k_rev: int
    drift_bound: float
    n_inference: int
    stitch_risk: float
    objective: float

def select_horizon(tau_inf_q99, delta_t, tau_fresh, drift_model,
                   budget_inf, task_duration, k_rev, H_max=64):
    H_min = int(np.ceil(tau_inf_q99 / delta_t)) + H_MARGIN
    k_fresh = int(np.floor((tau_fresh - tau_inf_q99) / delta_t))
    if k_fresh < k_rev:
        # 证据鲜度不足以覆盖不可逆段 ⇒ 拒绝该块或加密重观测
        return None

    best = None
    for H in range(H_min, H_max + 1):
        drift = drift_model.upper_bound(H)                 # D(H)
        n_inf = int(np.ceil(task_duration / max(H - k_rev, 1)))
        stitch = stitch_risk(H, drift, theta_stitch=THETA_STITCH)
        obj = (drift
               + LAMBDA_INF * budget_inf.cost(n_inf)
               + LAMBDA_STITCH * stitch)
        if best is None or obj < best.objective:
            best = HorizonDecision(H, k_fresh, k_rev, drift,
                                   n_inf, stitch, obj)
    return best

class LatencyHorizonDriftModel:
    """开环漂移上界：e_i ≤ e_0 + L·v_max·i·Δt（保守线性化）"""
    def __init__(self, L, v_max, delta_t, e0=0.0):
        self.L, self.v_max, self.dt, self.e0 = L, v_max, delta_t, e0

    def upper_bound(self, H):
        return self.e0 + self.L * self.v_max * H * self.dt

def stitch_risk(H, drift, theta_stitch):
    # 拼接不连续度随块长/漂移增大；超出阈值的概率近似
    sigma_j = STITCH_SIGMA_BASE + STITCH_SIGMA_DRIFT * drift
    return float(1.0 - norm.cdf(theta_stitch, 0.0, max(sigma_j, 1e-9)))
```

### IP-155 SADD（VLA 语义-动作双通道分解）

```python
@dataclass
class VLAProposal:
    chunk: ActionChunk
    ref_dist: "Categorical"        # over (object_id, region, affordance)
    action_dists: list             # H 个动作分布（给定 ref 的混合）
    logprob: float                 # VLA 自报置信度——禁止入佐证集

def sadd_decompose(p: VLAProposal) -> tuple[float, float]:
    U_sem = entropy(p.ref_dist)                       # H(r|o,ℓ)
    U_mot = 0.0
    for p_r, d in zip(p.ref_dist.probs, p.action_dists):
        U_mot += p_r * entropy(d)                     # E_r[H(a|r,o,ℓ)]
    # 链式分解：U(a,r) = U(r) + E[U(a|r)]，互信息非负
    return float(U_sem), float(U_mot)

def referential_gate(p: VLAProposal, fused_belief,
                     theta_ref=0.5, theta_sem=None) -> bool:
    U_sem, _ = sadd_decompose(p)
    if theta_sem is not None and U_sem > theta_sem:
        return False
    ref = p.ref_dist.argmax()
    # 指称对象必须已在融合信念中（或由探针显式引入）
    if ref.object_id not in fused_belief.known_objects:
        return False
    # 指令-场景一致性：ℓ 提到的属性需在 ref 区域可观测
    if not instruction_scene_consistent(ref, fused_belief, p.instruction):
        return False
    return iou(ref.region, fused_belief.region_for(ref.object_id)) >= theta_ref

def vla_confidence_is_not_evidence(p: VLAProposal) -> bool:
    """三不原则：VLA 只提议、不执行、不作证。自报 logprob 永不计入 D⁺ 的『一致』侧。"""
    return True
```

### IP-157 CCC（块级共形校准）

```python
class ChunkConformalCalibrator:
    """块级（非步级）共形校准。

    关键：相邻块时间重叠 ⇒ 步级样本不可交换；必须按互不重叠块取样。
    """
    def __init__(self, alpha=0.05, group_key_fn=None, weighted=False):
        self.alpha = alpha
        self.group_key_fn = group_key_fn or (lambda sample: "global")
        self.weighted = weighted
        self.calib = defaultdict(list)   # group -> nonconformity scores

    def add(self, observation, instruction, chunk, outcome):
        g = self.group_key_fn((observation, instruction, chunk))
        # 非一致性分数：前缀失败读作高分数
        s = 1.0 if not outcome.prefix_success else normalized_cost(outcome)
        self.calib[g].append(s)

    def _qhat(self, scores, weights=None, alpha=None):
        alpha = alpha or self.alpha
        n = len(scores)
        if n == 0:
            return 1.0
        if weights is None:
            k = int(np.ceil((n + 1) * (1 - alpha)))
            return float(np.sort(scores)[min(k, n) - 1])
        # 加权共形：处理 VLA 适配器/指令分布漂移
        order = np.argsort(scores)
        cw = np.cumsum(np.asarray(weights)[order])
        cw = cw / cw[-1]
        idx = int(np.searchsorted(cw, 1 - alpha))
        return float(np.sort(scores)[min(idx, n - 1)])

    def coverage_bound(self, group, n_calib, delta_shift=0.0):
        return 1.0 - self.alpha - delta_shift - 1.0 / (n_calib + 1)

    def prefix_success_lcb(self, proposal, group):
        q = self._qhat(self.calib[group])
        return max(0.0, 1.0 - q)       # 返回给 ACC 作为 E(a_{1:k}) 的下界
```

## 6. 本轮最大风险

**一句话**：本轮把「动作块」与「VLA」引入安全论证链，但**块级可交换性很可能被时间相关性与策略漂移破坏、VLA 的语义指称错误往往是系统性的（而非零均值噪声）**——一旦 CCC 在高危指令类上系统性低覆、或 SADD 的指称门被 VLA 自报置信度「循环污染」，就会出现「块级校准看似达标、实际抓错/撞上」的隐蔽失效；必须以「块级互不重叠校准 + 危险类分组条件覆盖硬门槛」「指称只能由独立模态接地、VLA 置信度绝不入佐证集」「不可逆后缀必须新鲜前缀 + 证据充分性双条件」三重护栏，宁可频繁块边界重承诺导致吞吐下降，也绝不允许「高置信度 VLA + 达标共形 = 误抓误撞」。
