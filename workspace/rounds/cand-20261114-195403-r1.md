# 第 75 轮（承接第 74 轮「SENTGAUGE-RAS 哨兵审计闭环」IP-303~309；灵感循环第 1 轮；本轮灵感：「数据集构建」×「可重构机构」）

> R74 用 anytime-valid 哨兵把「自信地组合一个错误世界」改造为「诚实地发现并退出错误世界」。但 R71–R74 的整条论证链下面，还压着一层从未被计量学处理的**共同地基**：**每一张证书都是一个数据集与一个物理构型的函数**。
> - **数据集构建**：SEAL、MBench、conformal 校准、e-process 的零假设，全部写成「给定校准集」。可数据集被当作**素材**而不是**仪器**：没有采样策略、没有覆盖见证、没有污染预算、没有构建过程的可追溯链。R74 自认最大风险是「SEAL 是否覆盖真实部署分布」，这正是数据集构建问题——**交换性（exchangeability）不是数据的性质，而是构造过程的性质**。同一堆样本，随机采、主动分层采、按构型采、被人挑过之后，conformal 覆盖率的含义完全不同。
> - **可重构机构**：R73 的热替换定理只对「同契约」成立。但可重构机构（模块对接、变拓扑、变自由度、传感器换位、灵巧手增减手指）改变的不是实现，而是**契约本身**：有效域、反作用通道、噪声结构随构型变化，旧的校准集在新构型下不再与部署分布可交换。把「同契约换实现」当成「换构型」，是 R73 热替换定理最危险的误读——它会给出一个「证书齐全、逐指令等价」的错误安全感。
>
> 两个灵感在数学上是同一件事：**交换性是连接数据集与机构构型的隐藏不变量**——重构破坏它，数据集构建负责界定/恢复它。于是本轮不问「契约内的现实是否越界」（R74），而问：
> **「我们用来定义契约的证据集，是否仍代表即将部署的现实；当机构变形时，这种代表性如何被证明、被迁移、被定价？」**
>
> 把 SENTGAUGE-RAS 升级为 **XCHANGE-GAUGE-RAS**（eXchangeability-audited, Configuration-aware evidence metrology with GAUGE audits for RAS）：**数据集构建计量 × 重构迁移审计**。核心新量只有一个：域限制交换性间隙 δ_xch。

## 0. 直觉与动机

**灵感 1（数据集构建 → 数据集是仪器，不是素材）**
直觉：在实验室用五个不透明物体采了 5000 帧校准深度误差，conformal 名义覆盖率 90%，部署时遇到透明/镜面物体，实测覆盖只有 40%。问题不是「样本不够」，而是**校准集的支持集根本没盖住部署域**。再多的同分布样本也救不了支持集缺失。反过来，如果只关心契约依赖的十个噪声驱动方向（距离、入射角、材质类别、互扰、曝光×速度……），主动分层设计往往只需几百个样本就能把每个契约域盖到指定分辨率——**有效维数远小于原始维数**。所以「构建数据集」的正确形式不是「多采」，而是在契约域上求解一个**覆盖需求优化**：每层至少多少、填充距离多大、污染上界多少、预算多少。

数据集一旦是仪器，就有仪器的全部负担：它有不确定度（采样不确定度、覆盖间隙、标签噪声、污染），会漂移（部署分布变了），会被「校准到通过」（Goodhart），也需要溯源（谁采的、怎么筛的、删了什么）。R71–R74 给传感器写了六/四/五分量，却从没给「数据集」写过一个分量。本轮补上。

形式直觉：把构建测度 μ_𝒟 与部署测度 μ_dep 在契约域 D 上的全变差称为**交换性间隙** δ_xch。标准 conformal 假设 δ_xch=0；真实系统的覆盖率按 1−α−δ_xch 衰减。于是数据集构建 = 在标签预算下最小化最坏情形 δ_xch，同时**显式声明**一个部署族 𝒫，使「δ_xch 小」这句话有可证伪的适用范围。

**灵感 2（可重构机构 → 重构是契约同态，不是热替换）**
直觉：一只四指灵巧手对接上第五指模块。软件层看，新指尖插件的契约与旧指尖完全一样，热替换定理说「实现可换、性质保持」。但物理层看：抓取接触分布变了，可达工作空间变了，相机视角与基线变了，触觉阵列的空间分辨率变了。旧数据集的「覆盖」是在旧构型下建立的；新构型下它既可能仍可交换（变化很小），也可能完全失效（新手指落在旧样本从未到过的接触区域）。**热替换定理的「同契约」前提在物理重构时恰好被打破，而系统往往不知道。**

正确的抽象是**契约同态**：物理重构 ρ 诱导一个证据输运映射 T_ρ，把旧构型的证据上下文搬到新构型；若 T_ρ 在契约相关度量下 L-Lipschitz，且构型距离为 r，则旧的 ε-稠密校准搬到新构型后是 (Lr+ε)-稠密，δ_xch 至多增加 C(Lr+ε)。这给出一个**迁移半径** R：半径内可带膨胀项复用校准，半径外必须采一个最小**见证集**（witness set）或整体重采。热替换是 T_ρ=id 的特例——旧定理被严格包含，而不是被推翻。

运行时，把所有可认证构型与可迁移边组成**认证重构图**。控制器只能沿有有效迁移证书的边走；没有边就硬互锁停机（R68），而不是「先变形再说」。这把「可重构」从无限可能的自由，收窄为**认证可达集内的自由**——安全侧的代价是明确的、可审计的。

**灵感 3（统一：交换性间隙是数据集与机构之间的共同货币）**
直觉：数据集构建问「我的证据集离部署现实多远」；重构问「变形后我的证据集离新现实多远」。两者都归结为同一个 δ_xch：前者靠采样策略压低，后者靠物理输运抬高。既然同一货币，就能**联合定价**：为覆盖目标构型流形，选择一组训练构型作 ε-网，每个训练构型建一个「认证球」；所需数据集数量由**覆盖数**决定，而不是构型总数。这是本轮的中心命题，也是 C6 可证伪的核心：认证成本应随 $(\mathrm{diam}/R)^{d_{\mathrm{eff}}}$ 增长，而不是随构型数线性增长。

**灵感 4（自证不可能 → 把「检不出」写成诚实的不可能性引理）**
直觉：一个只在实验室支持集上采样的数据集，无论多大，都无法凭自身证明「部署不会出现在支持集外」。这是支持集不匹配的平凡事实，但在 R74 的哨兵框架里它变成一条关键边界：**任何只依赖数据集本身的证书，都不能无条件给出有限部署间隙**。因此：
1. 证书必须相对于**声明的部署族 𝒫** 成立（A117）；
2. 部署期必须挂一个**数据集漂移哨兵**，其最小可检散度 δ_min 必须预注册（A119）；
3. 日志必须显式记录「本证书对 𝒫 外不可见」——这是「已知的未知」，不是假装没有。
R74 的「检不出」问题没有消失，但它从**隐式盲区**变成了**显式、有界、可审计的盲区**。这是本轮唯一诚实的处理。

**灵感 5（构型是协变量，不是背景）**
直觉：大多数机器人数据集把不同构型的数据混在一起训练，却不记录构型。在可重构机构里，构型本身就是数据生成过程的**协变量/混杂因子**：同一动作在不同构型下的接触几何、相机视角、雅可比都不同。池化数据而不标构型，等于把未观测混杂当成同分布——这正是 R74 联合哨兵最怕的「隐共享物理过程耦合」的数据版本。因此 XCHANGE 强制每条样本携带构型标签与契约版本；否则迁移不可识别，δ_xch 无法归因。

## 1. 形式化定义（增量：定义 398–414）

**定义 398（XCHANGE-GAUGE-RAS 总览）** XCHANGE-GAUGE-RAS =(DCM, XCH, CCD, RCM, XFER, RCGraph, DDS, SENTGAUGE-RAS†)。在 R74 六不变式上增加两条：
- (vii) **数据来源完备性**：每张证书引用的校准/基准必须指向一个构建记录 𝒟=(π, W_cov, W_cont, τ_𝒟, 𝒫)，而不仅是一个数据文件名；无构建记录者不得进入认证路径；
- (viii) **迁移可审计性**：任何跨构型复用必须先有迁移证书 J_XFER（含迁移半径与膨胀项），否则触发见证集重采或运行时互锁；不存在「静默跨构型复用」。

**定义 399（证据数据集 / 数据集即仪器）** 𝒟 = (𝒮, π, μ_𝒟, W_cov, W_cont, τ_𝒟, 𝒫, seal)：
- 𝒮：样本记录集合，每条携带上下文 z（含构型 c、环境 e、材质 m、视角 v、契约版本）；
- π：采样策略，即 z 上的设计分布，记录倾向得分 π(z)；
- μ_𝒟：由 𝒟 诱导的经验测度；
- W_cov：覆盖见证 {(D_i, n_i, ε_i, p_i)}，逐契约域报告样本数、填充距离、最小质量；
- W_cont：污染上界，由**独立裁判**在密封 canary 上估计，而非自报；
- τ_𝒟：构建溯源 DAG（来源、变换、标注者、拒绝/剔除原因、版本）；
- 𝒫：声明的部署族（如「构建测度 + 有界 TV 偏移」或协变量偏移族）；
- seal：密封审计集引用（SEAL-Dataset）。
数据集自身的不确定度 u_𝒟 =(u_s 采样, δ̂_xch 覆盖间隙, u_ℓ 标签噪声, u_c 污染)。

**定义 400（交换性间隙 δ_xch）** 对契约域 D：
δ_xch(μ_cal, μ_dep; D) = sup_{A⊆D 可测} |μ_cal(A) − μ_dep(A)|（域限制全变差）。
多模块时取加权最大 δ_xch = max_i δ_i / w_i。**关键**：δ_xch 是 (采样策略, 部署族) 的函数，不是样本量的函数；n→∞ 不会让 δ_xch→0，若支持集不含 D 的某部分。

**定义 401（覆盖需求契约 CDC）** 每个模块 i 声明 CDC_i =(D_i, Σ_i, ε_i, p_i, n_i^min, δ_i^max)：
- Σ_i：分层集合（材质×距离×视角×构型×互扰…）；
- ε_i：该域内允许的填充距离（空间填充分辨率）；
- p_i：每层最小概率质量；
- n_i^min：每层最小样本数；
- δ_i^max：允许的交换性间隙上界。
MReg 的全部 CDC 合成为图级覆盖需求。

**定义 402（构建算子 Construct）** Construct(CDC, B, 𝒫)→𝒟 在标签预算 B 下求解
min_{π}  max_i δ̂_xch(μ_π, 𝒫; D_i) + λ·Cost(π) + μ·Risk_cont(π)
s.t.  每层 n_i≥n_i^min、填充距离 ≤ε_i、倾向得分可记录。
构建必须输出 W_cov、W_cont、τ_𝒟；只输出数据文件者视为未构建。

**定义 403（配置流形与契约相关度量）** 构型 c ∈ 𝒞，𝒞 是带边界的 d 维流形（关节模块、对接拓扑、传感器位姿）。**契约相关度量** d_𝒞(c,c′) 由物理量定义（关节角、连杆长度、相机基线/外参、接触面法向分布的变化），**不是**由证据散度定义——否则 Lipschitz 假设会变成同义反复。证据输运的 Lipschitz 性作为独立假设 A118。

**定义 404（物理重构算子与诱导推前）** 重构 ρ: c→c′ 作用于机构物理状态，诱导证据上下文映射 T_ρ: 𝒵(c)→𝒵(c′)（视角变换、接触坐标变换、外参变换），并改变契约参数 D(c)、χ_R(c)、u(c)、I⊥(c)。ρ_* μ 表示证据测度的推前。

**定义 405（契约同态 ρ\*）** EC(c)→EC(c′) 是**保守同态**，若：
(a) D(c′) ⊆ T_ρ(D(c))（旧有效域经输运覆盖新有效域）；
(b) u_{c′}(z′) ≥ u_c(T_ρ^{-1}z′) + u_xfer（只许膨胀）；
(c) χ_R^{c′} = T_ρ ∘ χ_R^c ∘ T_ρ^{-1} 且有效域只缩不扩；
(d) I⊥_{c′} ⊇ I⊥_c（否决只增不减）；
(e) τ 合并可复算；(f) WCET/内存预算不减。
T_ρ=id 时退化为 R73 同契约热替换——**旧定理是特例**。

**定义 406（迁移半径与迁移证书 J_XFER）** 对 ρ: c→c′，迁移半径 R_ρ 与间隙上界
δ_xfer(ρ) ≤ L_ρ·d_𝒞(c,c′) + δ_samp(𝒟_c) + δ_ℓ，
其中 L_ρ 为 T_ρ 的 Lipschitz 常数（A118），δ_samp 为原数据集采样间隙，δ_ℓ 为标签/污染项。J_XFER = (ρ, 同态证明, δ̂_xfer 置信上界, 选择, u_xfer, R_ρ, 有效时域)：
- 选择 REUSE：δ̂_xfer ≤ δ_max，允许复用并加 u_xfer；
- 选择 AUGMENT(W_ρ)：采最小见证集 W_ρ 使增广后 δ̂ ≤ δ_max；
- 选择 RECOLLECT：无同态或超半径，必须重采。
**有效时域**：迁移证书会随温度/磨损过期，到期必须重认证（衔接 R74 CAS）。

**定义 407（认证重构图 RCGraph）** 𝔾=(V_𝒞, E_ℛ)：节点为已认证构型，边为 (c,c′,ρ,J_XFER)。认证可达集 ℛ(c_0)= 由有效边可达的节点集。运行时规则：仅当边 ∈ E_ℛ 且 J_XFER 未过期，才允许重构；否则**硬互锁停机**并请求认证。MReg 结构上限（R73 定义 377）在此获得物理对应：不是「模块数≤24」，而是「认证可达构型集有限且可审计」。

**定义 408（数据集-构型协同设计与有效维数）** 选训练构型 C_train⊆𝒞 与每构型数据集，使 C_target⊆∪_{c∈C_train} B_{d_𝒞}(c,R_ρ(c))。比例为**覆盖证书**。**有效维数** d_eff 为契约相关上下文流形的维数（例如十个噪声驱动方向，而非百万像素）。标签复杂度 ≈ N(R, C_target, d_𝒞)·m(δ,R)，其中 N 为覆盖数、m 为每球见证集大小。协同设计同时选 R（迁移半径，决定 δ 预算）与 C_train。

**定义 409（数据集漂移哨兵 DDS）** 对部署流 {z_t}，以构建模型密度 p_𝒟 为参照构造可预测下注的 e-process：H0: μ_dep ∈ 𝒫（或 μ_dep=μ_𝒟）。
δ_min = 在预注册功效与 canary 设计下可检出的最小散度。状态 GREEN/YELLOW/RED：
- YELLOW：所有依赖数据集的不确定度膨胀 γ_d，禁用 PAR 缩窄；
- RED：数据集判定失效，依赖模块全部 stub，触发重采/见证集。
**canary 通道**：定期注入已知参考样本（已知材质、已知构型、已知几何标定物）到独立通道，用于 (i) 估计偏移、(ii) 检查哨兵本身是否被致盲。canary 不进主训练流。

**定义 410（AIC-DATA 数据集威胁面）** 五类：
1. **覆盖赌博/Goodhart**：针对 SEAL 反复调参，使 SEAL 不再代表部署 → 密封保持集 + 独立裁判 + 预注册；
2. **投毒/标签翻转**：污染训练与校准 → 污染预算 + 溯源 + 鲁棒聚合；
3. **主动采样选择偏差**：设计策略本身把分布拉偏 → 记录倾向得分 + 设计策略审计；
4. **构型混淆**：池化不同构型而不标构型 → 强制构型标签 + 分层；
5. **迁移集泄漏/哨兵致盲**：见证集/保持集泄漏，或抑制 canary → 通道隔离 + 物理包络 + canary 存活检查。

**定义 411（来源与独立裁判）** 构建溯源 τ_𝒟 必须可重放每条样本的「来源→变换→标注→接受/拒绝」。独立裁判在密封 canary 上估计 W_cont，不能读取构建者的自评指标；任何剔除/重标注都计入污染与选择偏差。裁判与构建者共享代码视为来源不完整。

**定义 412（XCHANGE 证书 J_XCH）** J_XCH = J_SENT ⊗ (⊗_{i} J_dataset_i) ⊗ (⊗_{e∈E_ℛ} J_XFER_e) ⊗ DDS 状态 ⊗ (𝒫, δ_min, 盲区日志)。Valid 当且仅当：
(a) 每个数据集有 W_cov、W_cont、τ_𝒟、seal；
(b) 每个部署构型在认证可达集内且对应边 J_XFER 有效；
(c) δ̂_xch ≤ δ_max 且置信上界可复算；
(d) DDS 为 GREEN，或 YELLOW 已按语义降级、RED 已 stub；
(e) 声明族 𝒫 与最小可检散度 δ_min 显式写盘。
审计语义：可重放「哪份数据集、在哪个构型、以多大间隙、认证了哪个域、何时过期」。

**定义 413（新增主张 C5/C6 与 MB5/MB6）**
- **C5（交换性认证的数据集构建）**：覆盖需求驱动、交换性认证的构建，在部署覆盖间隙与安全违例上显著优于随机采样、跨构型池化、自报覆盖的构建。指标：部署 δ_xch、覆盖率偏差、每认证域标签数、下游违例率。
- **C6（重构迁移审计）**：契约同态 + 迁移证书支撑的可重构机构认证，在构型切换下保持安全，且认证成本显著低于逐构型重采。指标：认证可达构型比例、切换期违例率、每构型标签/认证成本、见证集大小。
- **MB5**（数据集构建最小基准）：受控偏移/材质/构型矩阵 + 3 个下游任务，≤3h 单卡，预注册脚本 + 固定种子 + 密封保持集 SEAL-MB5。

## 3. 推导

**引理 42（δ-鲁棒覆盖）** 设分数 s(z,y) 有界（或取秩分数），校准测度 μ_cal 与部署测度 μ_dep 在契约域 D 上满足 δ_xch ≤ δ。对任意事件 A⊆D，有 |μ_dep(A) − μ_cal(A)| ≤ δ。取 split-conformal 阈值 q̂ 使 μ_cal(s≤q̂) ≥ 1−α′−O(1/√n)，则
**P_{μ_dep}(s ≤ q̂) ≥ 1 − α′ − δ − O(1/√n) = 1 − α − δ − O(1/√n)。**
系：**覆盖率短缺的第一序项是交换性间隙，不是样本量**；把 α 调小救不了支持集缺失。这是「数据集构建必须进入安全论证」的最直接理由。

**引理 43（自证不可能）** 设数据集 𝒟 支撑集为 S，证书规则 C(𝒟) 只依赖 𝒟 的经验测度/统计量。对任意有限 δ̂，存在部署测度 μ_dep=(1−ε)μ_𝒟+ε·δ_{z*}，z*∉S，使得 δ_xch(μ_𝒟,μ_dep;D) ≥ ε，而 C(𝒟) 的取值完全相同。故不存在**无条件**的有限部署间隙证书；任何有限界必须相对于声明的部署族 𝒫（A117），并辅以在线哨兵。系：**「检不出」被写成一条不可能性引理，而不是一个待修 bug**——诚实的形式是声明 𝒫 与 δ_min，并记录盲区。

**引理 44（迁移 Lipschitz 界）** 若证据输运 T_ρ 在契约相关度量下 L-Lipschitz，且 𝒟_c 在 D(c) 中 ε-稠密，则 ρ_*𝒟_c 在 D(c′) 中 (L·d_𝒞(c,c′)+ε)-稠密；在密度有界的正则性下，
**δ_xfer(ρ) ≤ C·(L·d_𝒞(c,c′) + ε) =: C(Lr+ε)。**
系：迁移证书的膨胀项 u_xfer 可直接取 C(Lr+ε)；R_ρ = δ_max/(CL) 给出「不重采可走多远」的解析半径。

**引理 45（配置覆盖数与标签复杂度）** 若用半径 R 的球覆盖 C_target，最少球数 N(R)=覆盖数。对 d_eff 维流形，N(R)=Θ((diam/R)^{d_eff})。每球需 m(δ,R) 个样本，则协同设计总标签 ≈ N(R)·m；逐构型重采为 |C_target|·m。故当 |C_target| ≫ (diam/R)^{d_eff} 时，协同设计严格更省。**可证伪形式**：改变 R，测量认证覆盖率与标签数，检验标度指数是否接近 d_eff。

**引理 46（重构安全保持）** 若在线重构路径 c_0→c_1→…→c_k 的每条边都有有效 J_XFER（保守同态 + δ_xfer≤δ_max），则每步系统满足 R73 定理 28 / R74 定理 31，且不确定度按 u_xfer 逐边膨胀（同态合成仍为同态，Lipschitz 常数相乘）；若任一边缺失或过期，运行时互锁拒绝重构（定义 407），系统保持原构型的已验证安全。系：**热替换定理（R73 引理 35）是 T_ρ=id、δ_xfer=0 的特例**；重构安全不是新信任来源，而是带膨胀项的旧定理沿认证边的合成。

**定理 32（XCHANGE 严格包含）** 在 A117–A120 下：取固定单构型 c_0、δ_xch=0 的稠密数据集、迁移边为空，则 XCHANGE-GAUGE 逐指令等于 SENTGAUGE-RAS（R74），再依次退化为 R73→R72→R71→R68。安全单调不减，效率仅在额外预算满足时获益。

**定理 33（交换性-迁移审计有效性）** Valid(J_XCH) ⇒
(i) R74 定理 31 全部结论；
(ii) 对认证可达集内每个部署构型，域限制覆盖间隙 ≤ δ_max，且 δ-鲁棒 conformal 覆盖率 ≥ 1−α−δ_max−O(1/√n)（引理 42/44）；
(iii) 认证可达集外的重构不可执行（硬互锁，定义 407）；
(iv) 若部署偏移的逐步 KL ≥ δ ≥ δ_min，DDS 以 R74 引理 39 的速率检出并降级（引理 43 界定了它检不到的部分）。
**证明重量从「支持集假设」转移到「声明的 𝒫、迁移 Lipschitz、canary 功效与来源完整性」——四者都是可注入检验的。** 但 𝒫 外仍是不可见区，这是引理 43 的硬边界。

## 6. 本轮最大风险

**一句话**：XCHANGE 把「数据集是否代表现实」从隐式假设变成了显式、可检验、可审计的对象，但它的全部结论都只在**声明的部署族 𝒫** 内成立——若真实部署落在 𝒫 之外（全新材质、全新环境、全新构型拓扑不在构建支持集里，或偏移不是构建分布的有界扰动），数据集证书、迁移证书与漂移哨兵会**一起**失效；而由引理 43，系统没有任何内部手段能知道自己已经在 𝒫 外——它会把「从未见过的现实」静默地当作「已被覆盖的现实」来处理，且日志会证明每一步都合规。

次级风险与缓解：
1. **𝒫 声明过宽（证书看似强、实际空）** → 预注册 𝒫 + 独立裁判 + 对抗性支持集探针（E413/E426）；𝒫 宽度纳入 C5 指标。
2. **迁移 Lipschitz 常数低估（A118 在极端构型失效）** → 迁移半径硬边界 + 超出即 RECOLLECT + 局部 L 在线标定（E415）。
3. **DDS 致盲（缓慢漂移、canary 被抑制）** → 独立 canary 通道 + 第 0 层物理包络 + δ_min 预注册 + 哨兵存活检查（E420/E426）。
4. **构建过程 Goodhart** → 密封保持集 SEAL-MB5/6 + 三方复现 + 只认预注册指标（E413/E425）。
5. **构型覆盖数爆炸（d_eff 高）** → 有效维数归约（只保留契约相关驱动）+ 认证可达集上限 + 分层优先级（E418/E427）。
6. **见证集选择偏差** → 见证集由独立裁判按覆盖需求抽，不由部署性能反馈挑选；倾向得分记录（E414/E417）。
7. **重构与感知的时序竞态（新构型下旧证据仍被使用）** → 构型切换清空证据缓冲 + 快照版本号绑定构型（E419/E421）。

>
> 两灵感在数学上同一：**交换性间隙 δ_xch 是连接数据集与机构构型的隐藏不变量**。本轮把 SENTGAUGE-RAS 升级为 XCHANGE-GAUGE-RAS：
> - **DCM（数据集构建计量）**：数据集 =（采样策略、覆盖见证、污染预算、来源 DAG、声明部署族）；构建 = 在契约域上求解覆盖需求优化；数据集自身带不确定度与漂移；
> - **XCH/CCD（交换性 + 构型覆盖）**：δ-鲁棒 conformal；构型流形 ε-网协同设计，认证数据集数由**覆盖数**而非构型数决定；
> - **RCM/XFER/RCGraph（重构迁移审计）**：契约同态 + 迁移半径 + 迁移证书 J_XFER；运行时只允许走认证边，未认证重构硬互锁；
> - **DDS（数据集漂移哨兵）**：检验「现实是否仍在数据集支持内」；用引理 43（自证不可能）把 R74 的「检不出」写成显式的有界盲区 δ_min。
>
> 核心命题：**不再问「契约内的现实是否越界」，而问「用来定义契约的证据集是否仍代表部署现实；机构变形时这种代表性如何被证明、迁移、定价」。** 新层是旧层的严格泛化：同构型 = 恒等同态，热替换定理被包含而非推翻。
>
> IP 编号：IP-310~317（共 8 个）+ SENTGAUGE† 化。新增主张 C5（交换性认证的数据集构建）与 C6（重构迁移审计）。

## 2. 形式化定义（要点版）

**定义 398（总览与八不变式）** R74 六不变式 + (vii) 数据来源完备性（证书必须引用构建记录，裸数据文件不得入认证路径）+ (viii) 迁移可审计性（跨构型复用必须有 J_XFER，否则见证集重采或互锁）。

**定义 399（数据集即仪器）** 𝒟=(𝒮,π,μ_𝒟,W_cov,W_cont,τ_𝒟,𝒫,seal)；u_𝒟=(采样、覆盖间隙、标签噪声、污染)。数据集有不确定度、会漂移、可被 Goodhart、需溯源——与传感器同等待遇。

**定义 400（交换性间隙）** 域限制全变差 δ_xch；多模块取加权最大。核心事实：它是 (π, 𝒫) 的函数，不是 n 的函数。

**定义 401（覆盖需求 CDC）** 逐模块声明域、分层、填充距离、最小质量、最小样本、间隙上界；图级合成为构建目标。

**定义 402（构建算子）** 在预算 B 下最小化最坏 δ_xch + 标签成本 + 污染风险，受分层/填充/倾向约束；必须输出 W_cov、W_cont、τ_𝒟。

**定义 403（配置流形与契约度量）** c∈𝒞（带边界 d 维流形）；d_𝒞 由物理量定义，证据输运的 Lipschitz 性作为独立假设 A118。

**定义 404（重构算子与推前）** T_ρ 搬运视角/接触/外参上下文；同时改变 D(c)、χ_R(c)、u(c)、I⊥(c)。

**定义 405（保守契约同态）** 六条件（域覆盖、u 膨胀、通道共轭、否决只增、溯源可复算、预算不减）；T_ρ=id 退化为 R73 热替换。

**定义 406（迁移半径与 J_XFER）** δ_xfer ≤ L r + δ_samp + δ_ℓ；REUSE/AUGMENT/RECOLLECT 三选一；带 u_xfer、R_ρ、有效时域。

**定义 407（认证重构图）** 𝔾=(V_𝒞,E_ℛ)；运行时仅走有效边，否则硬互锁。R73「模块数≤24」的结构上限在此获得物理对应：认证可达集有限且可审计。

**定义 408（协同设计与有效维数）** C_train 的 R-球覆盖 C_target；标签复杂度 ≈ N(R)·m，N(R)=Θ((diam/R)^{d_eff})。

**定义 409（DDS）** 构建测度相对部署流的可预测下注 e-process；GREEN/YELLOW（γ_d 膨胀、禁 PAR 缩窄）/RED（数据集失效、依赖模块 stub）；canary 独立通道；δ_min 预注册。

**定义 410（AIC-DATA）** 覆盖赌博、投毒/标签翻转、主动采样选择偏差、构型混淆、迁移泄漏/哨兵致盲；逐项防线。

**定义 411（来源与独立裁判）** τ_𝒟 可重放；W_cont 由独立裁判在密封 canary 上估计，自报不算；裁判与构建者共享代码视为来源不完整。

**定义 412（J_XCH）** 数据集证书 ⊗ 迁移证书 ⊗ DDS 状态 ⊗ (𝒫,δ_min,盲区日志)；Valid 条件 (a)–(e)；审计可重放「哪份数据集、在哪个构型、以多大间隙、认证了哪个域、何时过期」。

**定义 413（C5/C6 与 MB5/MB6）** C5 ←(DCM,XCH) ← MB5 ← AB5 ←（δ_xch、覆盖率偏差、每认证域标签数、违例率）；C6 ←(RCM,XFER,RCGraph,CCD) ← MB6 ← AB6 ←（认证可达比例、切换期违例、每构型成本、见证集大小）。MB5/6 各 ≤3h 单卡、预注册、密封保持集、三方复现。

**定义 414（A117–A120）** 部署族声明 / 迁移 Lipschitz / 哨兵功效 / 来源完整性。四者都可注入检验；𝒫 外由引理 43 明确无保证。

## 4. 推导

**引理 42（δ-鲁棒覆盖）** δ_xch≤δ ⇒ 任意事件概率差 ≤δ ⇒ 若校准侧覆盖 ≥1−α′−O(1/√n)，则部署侧覆盖 ≥**1−α′−δ−O(1/√n)**。系：覆盖率短缺的第一序项是交换性间隙，不是样本量。

**引理 43（自证不可能）** 只依赖 𝒟 的证书无法区分「部署落在支持集外」的混合分布；故无条件的有限部署间隙证书不存在。任何有限界必须相对于 𝒫，并由 DDS 覆盖 𝒫 内偏移。系：R74 的「检不出」被写成不可能性引理，盲区必须显式声明 δ_min。

**引理 44（迁移 Lipschitz 界）** T_ρ 为 L-Lipschitz 且原数据 ε-稠密 ⇒ 推前 (Lr+ε)-稠密 ⇒ **δ_xfer ≤ C(Lr+ε)**；R_ρ=δ_max/(CL)。

**引理 45（配置覆盖数）** 半径 R 覆盖 C_target 的最少球数 N(R)=Θ((diam/R)^{d_eff})；协同设计标签 ≈ N(R)·m，逐构型重采为 |C_target|·m。可证伪：改变 R 拟合标度指数。

**引理 46（重构安全保持）** 认证路径上每边 J_XFER 有效 ⇒ 逐边应用 R73 定理 28/R74 定理 31，u 按 u_xfer 膨胀；同态可合成；缺边/过期 ⇒ 互锁。系：热替换 = T_ρ=id、δ_xfer=0 的特例。

**定理 32（XCHANGE 严格包含）** 单构型 + δ_xch=0 + 空迁移边 ⇒ 逐指令等于 R74，再退化为 R73→R72→R71→R68。安全单调不减。

**定理 33（交换性-迁移审计有效性）** Valid(J_XCH) ⇒ (i) R74 定理 31；(ii) 认证可达集内覆盖率 ≥1−α−δ_max−O(1/√n)；(iii) 集外重构不可执行；(iv) 偏移 ≥δ_min 时 DDS 按 R74 引理 39 速率降级。证明重量落在 A117–A120（可注入检验），𝒫 外由引理 43 明确无保证。

## 7. 本轮最大风险

**一句话**：XCHANGE 把「数据集是否代表现实」从隐式假设变成了显式、可检验、可审计的对象，但它的全部结论都只在**声明的部署族 𝒫** 内成立——若真实部署落在 𝒫 之外（全新材质、环境、构型拓扑不在构建支持集里，或偏移不是构建分布的有界扰动），数据集证书、迁移证书与漂移哨兵会**一起**失效；而由引理 43，系统没有任何内部手段能知道自己已在 𝒫 外——它会把「从未见过的现实」静默地当作「已被覆盖的现实」处理，日志还会证明每一步都合规。

次级风险与缓解：
1. **𝒫 声明过宽（证书看似强、实际空）** → 预注册 𝒫 + 独立裁判 + 对抗性支持集探针（E413/E426）；𝒫 宽度进 C5 指标。
2. **迁移 Lipschitz 常数低估** → 迁移半径硬边界 + 超界即 RECOLLECT + 局部 L 在线标定（E415）。
3. **DDS 致盲（慢漂移 / canary 抑制）** → 独立 canary + 第 0 层物理包络 + δ_min 预注册 + 哨兵存活检查（E420/E426）。
4. **构建 Goodhart** → SEAL-MB5/6 密封保持集 + 三方复现 + 只认预注册指标（E413/E425）。
5. **配置覆盖数爆炸** → 有效维数归约 + 认证可达集上限 + 分层优先级（E418/E427）。
6. **见证集选择偏差** → 独立裁判按覆盖需求抽，不由部署性能反馈挑选；倾向得分记录（E414/E417）。
7. **重构-感知时序竞态** → 构型切换清空证据缓冲 + 快照版本号绑定构型（E419/E421）。
