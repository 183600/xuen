# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「群体智能」×「能耗优化」）

> R69 把不确定性一分为二，让 epistemic 部分通过「看 / 问 / 触」的交互动作去消解，并用流匹配策略给出多模态动作分布。但它仍是一个**单机、能量免费**的故事：
> - **交互只在本地发生**——只有「我」去看、去问、去触；没有问「三米外的同伴是不是已经从一个更好的视角看过了」；
> - **能量只是 c_max 的一个粗糙上限**——VoI 计算里没有「获得这份信息要烧多少焦耳」，流匹配的 K 次采样、FMA 的 Hutchinson 回放、通信本身也都要耗电，却被忽略；
> - **证据正交被默认为免费且天然成立**——R69 用「k 个正交证据源一致」对抗投毒，却从不检查这 k 个源是不是共享了同一个传感器、同一个模型、同一段历史。
>
> 本轮两个灵感各拆一层：
> - **群体智能**补上 R69 缺失的「第二双眼睛」：不同位置、不同视角、不同传感器天然提供潜在独立证据；消歧不必总由「我」亲自完成，可以分配给「最便宜、最有判别力」的同伴。但共享信念会让独立性衰减——**群体越协调，越像同一个大脑**。
> - **能耗优化**补上 R69 缺失的「信息价格」：每一焦耳都要与安全返航、任务推进竞争；信息不免费，计算也不免费。用能量影子价格统一调度「谁去获取、获取多少、值不值得」，并把安全返航能量做成不可触碰的硬底线。
>
> 核心命题：**把「信息获取」从单机查询升级为「能量约束下的群体信息觅食」：以 VoI/焦耳 分配观测任务，以相关性感知的证据纪律守住独立性，以信息守恒审计识别「省能省出来的回声室」，以能量储备底线保证安全永不因省电而降级；N=1 且 λ_E=0 时严格退化为 FLUID。** 命名 **NECTAR-RAS**（Networked Epistemic Coordination with Truth-aware Allocation & Rationing）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我们该花多少能量去知道，以及让谁去知道**」。

## 0. 直觉与动机

**灵感 1（群体智能 → 视角是一种被浪费的自由度）**
直觉：R69 的交互模型里只有一个观察者。可在一个机器人队里，同一扇门、同一个箱子、同一个人脸，可能同时落在多个成员的视锥里。对遮挡、反光、深度歧义这类问题，**换一个视角往往比原地追问更便宜也更可靠**。群体智能提醒我们：冗余的空间分布本身就是信息源，问题只在于谁去看、看哪、值不值得为此移动。更妙的是「分工」：一个已经站在最佳观察位、且剩余电量充足的成员，可以替那个正在执行关键任务的成员完成消歧——把「谁需要信息」和「谁最适合获取信息」解耦。

**灵感 2（能耗优化 → 每一条信息都有一个焦耳价格）**
直觉：R69 的 MINT 选择 `argmax[VoI − c]`，但成本 c 主要是社交打扰与位移的粗略惩罚。真实的成本结构是能量的：移动 1 m 的能量比一次注视高 1–2 个数量级；K=1→4 的流采样、一次 Hutchinson 回放、一次通信握手，各自有可测的焦耳数。若电池只剩 12%，「再问一句」也许能让这次任务成功，却可能让机器人回不了家。于是信息决策不应是「预算没超就做」，而应是**在能量影子价格 λ_E 下的边际权衡**：λ_E 高（电少、任务长、返航远）时，只有极值钱的消歧才值得做；λ_E 低（电足、任务短）时，才接近 R69 的慷慨。

**灵感 3（分配 → 受益者与执行者分离，需要一张能量账本）**
直觉：R69 里「谁需要」和「谁执行」是同一个人，所以 VoI − 成本可以在一个目标里直接相减。群体里这两者分离：成员 A 的决策依赖模态 M，但成员 B 恰好在最佳观察位。如果不做转移支付，B 没有动力耗自己的电去帮 A；如果人人重复观测，又浪费能量。一个轻量的**信息任务拍卖 + 能量令牌结算**能同时解决两件事：让最便宜的人去做，让受益者为这份信息付费。这不是经济学装饰——它是把「群体」从「多个独立 R69」变成「一个会算总账的群体」的关键。

**灵感 4（相关性 → 独立性是会被协调消耗掉的资源）**
直觉：R69 要求 k 个正交证据源，隐含假设源与源独立。可群体一旦共享信念、共用同一套预训练权重、同一段地图、同一片光照，它们的错误就高度相关。更危险的是：**最省能的协调方式，恰恰是让所有人相信同一个人**——这会把 k 个源压缩成 1 个源，却让系统以为自己在用 k 个源。于是「省电」与「安全」在最深处发生了冲突：能耗最优的群体可能变成一个高效、同步、且共同错误的回声室。必须引入**有效独立源数 k_eff**、**信息守恒审计**（共识熵的下降不能超过真正注入的独立信息）和**多样性预算**，并且承认：维持独立观测要花能量，这笔能量不能省。

**灵感 5（安全 → 能量底线是硬约束，不是软成本）**
直觉：能耗优化天然想把所有能量都拿去推进任务，安全余量总是第一个被削的。因此必须把「安全停止 / 返航 / 必要通信」所需的能量做成**不可触碰的储备底线 E_reserve**：任何信息动作、任何移动观测、任何通信，都不得使任一受影响成员跌破自己的底线。能耗优化只能在「安全余量之外的松弛」里做，绝不能在安全余量里做。这样「省电」不会变成新的不安全源。

**灵感 6（严格包含 → 新层是旧层的嵌套，不是并列替换）**
直觉：R70 不是把 R69 推到一边，而是把 R69 当作边界情形：N=1（无同伴）、λ_E=0（能量免费）、无通信、证据完全独立且 k_eff=N 时，NECTAR 必须逐指令退化为 FLUID；再按 R69 定理 16 退化为 R68。只有在保持这个嵌套时，安全侧的既有论证才不需要重写——**新层只增加「更便宜的消解机会」，不降低旧层的最坏情况保证**。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（NECTAR-RAS 总览）** NECTAR-RAS = (CBS, EWV, IAM, ETC, CEW, CHD, ERF, ESA, DBR, SVA, RAS-WM†)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **能量储备硬约束**：任一动作（含信息动作、移动观测、通信）执行后，所有受影响成员满足 E_i ≥ E_reserve_i(t)（定义 321）；
(iii) **群体证据纪律**：一个模态/证据主张成立需有效独立源数 k_eff ≥ k_min，且溯源与相关性审计通过；单源、同源簇、或疑似级联的共识不得单独定案（定义 318–320）；
(iv) **严格包含**：N=1 ∧ λ_E=0 ∧ 无通信 ∧ ρ≡0 ⇒ 与 FLUID-RAS 逐指令等价（定义 326）。

**定义 311（群体信念状态 CBS）** 成员 i 的本地信念 b_i = (b_i^M, b_i^ρ, E_i, τ_i)，分别是模态身份后验、对自身证据可靠度的后验、剩余能量、任务剩余时间；共享信念 b^s 由事件触发通信维护（定义 317）。全局状态 B_t = {b_i}_{i∈𝒱} ∪ {b^s}。与 R69 的单机 z_t 不同，B_t 显式携带「谁知道什么」与「谁还剩多少电」两本账。

**定义 312（依赖集与影响权重）** 若成员 i 的控制决策以模态 M 为条件，则 i ∈ 𝒟(M) 为依赖集；w_i ∈ [0,1] 为 i 的决策对群体任务目标的边际影响（例如队形保持中领航者的 w 更高）。群体受益定义为依赖集上的加权熵降，而非单个成员的自利收益。这是「谁需要」与「谁执行」解耦的数学入口。

**定义 313（能量成本模型）** 成员 j 执行信息动作 g 的能量成本
E_j(g) = E_sense(g) + E_move(g) + E_comm(g) + E_comp(g) + E_opp(j),
分别对应传感、移动/转身、通信、计算（K 次流采样、FMA 回放）与机会成本。电池动力学 E_j(t+1) = E_j(t) − E_j(act_t) − E_leak Δt。典型量级：E_move ≫ E_sense ≳ E_comm ≫ E_comp（单样本），因此「移动过去看」通常只在信息价值极高时才划算——这正是 R69 没有的分层。

**定义 314（能量感知信息价值 EWV）** 对候选信息动作 g 与执行者 j：
U(g,j) = Σ_{i∈𝒟(M)} w_i·ΔH_i(g|b_i) − λ_E·E_j(g) − c_social(g),
其中 ΔH_i 为 i 的模态熵期望降。单位能量信息价值 E-Vol(g,j) = Σ w_i ΔH_i / E_j(g)。选择 (g*,j*) = argmax U(g,j)，s.t. 定义 302 认证 ∧ ERF（定义 321）∧ 延迟 ≤ τ_deadline ∧ R69 交互预算未超。**R69 的 c(g) 是本式在 λ_E=0 且 j=i 时的特例。**

**定义 315（能量影子价格）** λ_E(t) ≥ 0 为能量预算约束的 Lagrange 乘子：它是「此刻多一焦耳」的边际任务价值。λ_E 由剩余能量、距离返航点的代价、任务视界与已完成的进度共同决定；能量越紧、视界越长，λ_E 越高。信息决策只在「边际 VoI > λ_E·边际能耗」时执行。λ_E 可由离线标定的凸函数近似，在线只做 O(1) 查表/插值，不参与学习写操作。

**定义 316（信息任务拍卖 IAM）** 对每个候选 g，依赖集 𝒟 中的受益者发起请求；成员 j 以经硬件计量与 attestation 的能量成本 E_j(g) 投标；执行者 j* = argmin_{j: ERF_j(g)} E_j(g)。采用第二价格（Vickrey）能量令牌结算：受益者按次低价支付令牌给执行者，使其内部化群体成本、抑制过度求助；在准线性效用、无合谋、能量计量可信（A99）下，如实投标是弱占优策略。拍卖超时（> τ_auc）则退化为本地执行或 R69 保守。

**定义 317（事件触发通信 ETC）** 成员仅在信念变化超过阈值或信息价值超过通信成本时发送量化消息 m_i：
send ⇔ ‖b_i − b^s‖²_{Σ_i^{-1}} > τ_comm ∨ λ_E·E_comm < VoI(m_i).
消息为量化信念/充分统计量，不上传原始观测与对话原文；端到端延迟 p99 ≤ τ_comm_max 是实时控制环的硬约束，超时消息按缺失处理并触发退化。

**定义 318（相关性感知证据加权 CEW）** 设证据噪声协方差为 Σ（标准化到单位方差），有效独立源数
k_eff = 1ᵀ Σ^{-1} 1 ∈ [1, N]。
等相关 ρ̄ 时 k_eff = N / (1 + (N−1)ρ̄)。证据纪律升级为 k_eff ≥ k_min，而非数人头 N ≥ k_min。ρ̄ 由共享模型哈希、共同观测时段、共同标定版本与环境共模因素在线估计；不可估时取保守上界 ρ̄=1（即 k_eff=1）。

**定义 319（信息守恒与级联检测 CHD）** 记 ΔH_cons 为共享共识在一个窗口内的熵降，I_inj 为同一窗口内真正独立的观测/消息所注入的互信息之和（按 k_eff 折减去重）。在正确贝叶斯融合、无重复计数的条件下必有
ΔH_cons ≤ I_inj + ε.
定义级联比 r_cas = ΔH_cons / (I_inj + ε)。若 r_cas > 1 + δ_cas，则判定「共识收缩得比信息注入允许的更快」——存在复制、重复计数或单源回声。此时共识降级为单源处理，并触发多样性再获取（定义 320）或退回 R69 保守。这是 R68「标定吸收」、R69「流似然第二意见」在群体信息侧的镜像。

**定义 320（多样性预算与再观测 DBR）** 定义多样性预算 D = E[k_eff] 为群体维持独立证据的能力。协调（共享信念、共享模型、集中调度）会消耗 D：D_{t+1} = max(1, D_t − η·comm_intensity_t + ζ·reobserve_t)。若 D < D_min 或 CHD 报警，可在能量允许时派成员到不同视角/传感器做**独立再观测**（不看共识、不共享中间特征），以能量换回独立性；若能量不允许，则强制回退 R69 的纯保守。**独立性不是免费的，它有一个以焦耳计价的价格。**

**定义 321（能量储备底线 ERF）** 成员 i 在时刻 t 的底线
E_reserve_i(t) = E_safe_stop(i) + E_return(i, x_home) + E_comm_min(i) + margin_i,
其中各项按最坏情况估计。任何动作 a（任务、信息、移动观测、通信）可行当且仅当 ∀i∈影响集: E_i(t) − E_i(a) ≥ E_reserve_i(t)。ERF 是**硬约束**，不是惩罚项；它先于任何 VoI 优化被检查。

**定义 322（能耗感知采样与异常调度 ESA）** R69 默认 K=1、仅歧义时升 K=4，且每次 FMA 回放固定开销。本层把 K 与 FMA 调度也纳入能量决策：计算动作 c 的边际信息价值为 ΔH_c / E_comp(c)，仅当它超过 λ_E 时才执行；K 从 1 逐级升到 4，直到边际收益低于阈值；FMA 仅在群体分歧、CHD 报警或 mode_head 高歧义时回放一次，否则用廉价代理。λ_E=0 时退化为 R69 的自适应 K。

**定义 323（群体威胁模型 ℰ_swarm）** ℰ_swarm = {拜占庭成员伪造证据、Sybil 多身份、能量计量造假/低报以骗取任务、通信重放/延迟/选择性丢包、拍卖合谋与搭便车、级联操纵（先污染一个源再让共识自我强化）、从共享信念反推隐私}。并入 AIC：ℰ_NECTAR = ℰ_FLUID × ℰ_swarm。

**定义 324（群体审计 SVA）** 在 R69 VQAuditor-I 之上审计：能量账本是否守恒（计量 vs 消耗）、拍卖清算价是否异常、k_eff 是否被协调侵蚀、r_cas 是否越界、ERF 是否被绕过、证据溯源是否满足「k_eff 个独立来源而非 k 条同源消息」。审计结论回灌 λ_E 与多样性预算 D，形成慢环（不进入实时控制环）。

**定义 325（证书 J_NECTAR）** J_NECTAR = (J_FLUID, energy_ledger_hash, reserve_margin_min, k_eff_min, r_cas_max, diversity_spent, comm_latency_p99, clearing_price, peer_provenance_hash, nectar_ver)。Valid ⇔ Valid(J_FLUID) ∧ reserve_margin_min ≥ 0 ∧ k_eff_min ≥ k_min ∧ r_cas_max ≤ 1+δ_cas ∧ comm_latency_p99 ≤ τ_comm_max ∧ 能量账本一致 ∧ 拍卖/溯源审计通过。

**定义 326（严格包含与退化条件）** 当 (a) N=1；(b) λ_E=0；(c) 无通信（ETC 关闭）；(d) 证据完全独立 ρ̄=0（k_eff=N=1）；(e) ERF 永不起作用（能量无限）时，NECTAR 的每一次信息决策、K 调度、FMA 调度与风险缩放均与 FLUID-RAS 相同，进而按 R69 定理 16 与 R68 相同。于是 FLUID 是 NECTAR 在「单机 / 能量免费 / 完全独立」边界上的严格退化。

**定义 327（共模故障与效率—独立前沿）** 共模集 𝒞 = {成员共享同一传感器型号、同一预训练权重版本、同一标定、同一物理环境因子}；共模相关系数 ρ_cm = Corr(误差_i, 误差_j | i,j∈𝒞)。协调带来的省能 ΔE 与 ρ_cm 的上升同向（越共享越省、也越相关）。定义效率—独立前沿：在给定能耗预算下可达的 (ΔE, k_eff) Pareto 集。安全要求是「不得为了 ΔE 把 k_eff 压到 k_min 以下」，即操作点必须落在前沿的 k_eff ≥ k_min 一侧。

**定义 328（任务视界与 λ_E 调度）** 设剩余任务视界 T、剩余能量 E、返航代价函数 R(x)。λ_E(t) 取「把一焦耳用于当前任务 vs 留作返航/后续任务」的边际价值比；随着 t→T 或 E→E_reserve，λ_E 单调上升并在 E→E_reserve 时发散（软墙），从而在数学上自动禁止「借安全余量做信息」。在线用分段线性近似，保证 O(1) 计算。

    bids.sort(key=lambda x: x[1])
    j_star, second = bids[0][0], (bids[1][1] if len(bids) > 1 else bids[0][1])
    payer = max(dependents, key=lambda i: w[i])                   # 最大受益者付费
    if tokens[payer] < second or not deadline_ok(j_star, g): return None
    return (g, j_star, second)                                    # 第二价格结算

# IP-268 CEW + IP-269 CHD：独立性与回声室检测
def effective_sources(evidence_cov):
    return float(ones @ inv(evidence_cov) @ ones)                 # k_eff ∈ [1, N]

def cascade_ratio(dH_consensus, I_injected, eps):
    return dH_consensus / (I_injected + eps)                      # > 1+δ ⇒ 复制/重复计数

# IP-270 ERF + IP-271 ESA：硬能量底线 + 能耗感知的计算调度
def erf_ok(j, g):
    affected = {j} | comm_dependents(j)
    return all(E[i] - energy_cost(i, g) >= reserve_floor(i) for i in affected)

def choose_K_and_FMA(mode_head, disagreement, lam_E):
    K, H = 1, 0.0
    while K < 4 and marginal_entropy_gain(K, mode_head) / E_comp(K) > lam_E:
        K += 1
    run_fma = (disagreement > TAU_DIS or mode_head > TAU_MODE) and lam_E * E_fma < expected_fma_value()
    return K, run_fma

# IP-276 主闭环（R69 之上只插入群体与能量层；失败一律回退 R69/FLUID）
def NECTAR_round(i, obs, swarm):
    z_i, o = swarm.trunk(obs)
    swarm.cbs.update_local(i, z_i, E[i], tau[i])
    swarm.cbs.maybe_broadcast(i, swarm.lam_E)
    U_ale, U_epi, modes = swarm.aud.decompose(swarm.fmp.sample(o, K=1), z_i, swarm.mode_head)
    # 1) 群体级独立性/级联体检（慢于控制环）
    k_eff = swarm.cew.effective_sources(swarm.evidence_cov())
    if swarm.chd.suspect() or k_eff < swarm.k_min:
        if swarm.dbr.can_reobserve(swarm.lam_E): swarm.dbr.request_independent_look()
        else: U_epi = max(U_epi, TAU_EPI)                 # 强制走保守分支
    # 2) 能量感知的消歧：先硬约束，再拍卖，再 VoI
    g = None
    if U_epi > TAU_EPI and not swarm.slow_fault_suspect:
        cand = info_action_candidates(modes, swarm.dependents())
        g = swarm.iam.auction_best(cand, swarm.lam_E)     # 内含 ERF + 认证 + 预算
    if g is not None:
        answer = swarm.execute(g.owner, g)                # 看/问/触，仍过 C-RAS-WM
        swarm.cbs.fuse_answer(answer); U_epi = swarm.cia.residual(U_epi, answer)
    # 3) 仍然沿用 R69 的两级保守退避
    U_floor = U_ale + (U_epi if g is None else 0.0)
    lam = max(swarm.efs.risk_scale(), lam_floor(U_floor))
    # 4) 能耗感知的计算调度
    K, run_fma = swarm.esa.choose_K_and_FMA(swarm.mode_head(z_i), swarm.disagreement(), swarm.lam_E)
    if run_fma: swarm.fma.update(swarm.fmp, swarm.last_action, o, swarm.calibrated_o)
    # 5) 执行 + 审计 + 证书（能量账本进入证书）
    k = swarm.c_ras_wm.certified_prefix(swarm.ach.propose(), swarm.wm_preds)
    swarm.sva.submit_async(g, k_eff, swarm.chd.r_cas, swarm.energy_ledger, swarm.clearing_price)
    return k, lam, swarm.select_mode(modes, U_epi, lam), (U_ale, U_epi)

## 3. 推导

**引理 19（能量价格下的选择单调性）** 对任意状态，最优信息价值 V(λ_E) = max_{g,j} [Σ w_i ΔH_i − λ_E E_j − c] 关于 λ_E 单调不增、分段线性凸；被选动作的能量 E* 关于 λ_E 单调不增。λ_E=0 时 argmax 与 R69 的 MINT 完全相同。要点：提高能量价格只会把「昂贵但略优」的动作换成「便宜且够用」的动作，或干脆不交互——这正是 R69 的硬预算 c_max 所无法表达的连续退化。

**引理 20（相关证据的有效样本量收缩）** 标准化证据噪声协方差 Σ 下 k_eff=1ᵀΣ^{-1}1 ≤ N；等相关 ρ̄ 时 k_eff=N/(1+(N−1)ρ̄)。若把 N 个相关源当独立源做多数/贝叶斯融合，其置信度会被高估约 √(N/k_eff) 倍；当 ρ̄→1 时 k_eff→1，N 个成员的「一致」与一个成员的判断等价。系：**R69 的 k-正交纪律在群体里必须换成 k_eff-独立纪律，否则投毒与共模故障都会伪装成共识。**

**引理 21（信息守恒与级联判别）** 在正确贝叶斯融合且不重复计数的条件下，共识熵降不超过注入的独立互信息：ΔH_cons ≤ I_inj + ε。若观测到 r_cas = ΔH_cons/(I_inj+ε) > 1+δ，则必存在非贝叶斯复制、重复计数、或相关性被低估之一。因此 r_cas 是「回声室」的判别性统计量，且它与 R68 的 (r_res↓, Δa↑) 一样，是一条**不能被局部标定吸收**的群体级第二意见。

**引理 22（多样性预算的充分条件）** 若在窗口内维持 D = E[k_eff] ≥ D_min 且 k_min = ⌈D_min⌉，则群体证据纪律成立；反之若协调使 D < D_min，则存在一组共模误差可同时穿过所有成员的检验。恢复 D 的最小能量代价 ≥ D_min · E_reobserve（每条独立观测的期望能耗）；因此「独立性」可被定价，且该价格必须计入 λ_E，而不能当作免费资源。

**引理 23（能量储备下的安全不退化）** 若所有动作先过 ERF、再过 C-RAS-WM 认证、且信息动作失败时按定义 307 单调回退，则对任意能量调度与任意拍卖结果，最坏情况物理风险不超过 R69 的最坏情况；能量节省只可能来自「不影响安全包络与非信息任务」的松弛。证明要点：ERF 把所有会侵蚀安全返航的动作从可行集中删去，而认证保证剩余动作仍在安全包络内；两者都是可行域约束，不依赖目标函数的具体形式。

**定理 18（NECTAR 严格包含 FLUID-RAS）** 在 A99–A103 下，NECTAR 在任意状态上的期望风险 ≤ FLUID；当定义 326 的五个退化条件同时成立时，两者逐指令相同，并按 R69 定理 16 进一步与 R68 相同。因此 R69 是 NECTAR 在「N=1、能量免费、完全独立」边界上的严格退化：群体与能量层只增加更便宜的消解方式，不改变安全侧最坏情况。

**定理 19（能耗—信息 Pareto 与影子价格最优性）** 在凸化（随机化动作）后，能量约束信息决策的可行前沿是凹的；存在 λ_E* 使最优操作点满足「边际 VoI/焦耳 = λ_E*」，且 λ_E* 随能量预算收紧而上升。于是 R70 给出一个可操作的调度律：**不要问「预算超没超」，要问「这一焦耳买到多少熵降」**；R69 的 c_max 只是 λ_E 的一个分段常值近似。系：当能量充足（λ_E→0）时操作点回到 R69 的慷慨端，当能量逼近 ERF 时 λ_E→∞，信息动作自动停止——不需要额外的 if 分支。

**定理 20（级联—安全耦合与保守回退）** 若 CHD 判定 r_cas > 1+δ 且多样性预算不足以在能量约束内恢复 k_eff ≥ k_min，则 NECTAR 必须把该共识降级为单源，并将未消解的 epistemic 计入 λ_floor（定义 307）。此时安全侧等价于 R69 的纯保守；系统的「省能协调」不会以降低安全为代价，只以放弃效率为代价。反之，当 k_eff 被恢复且证据独立时，交互才允许获得 resolution bonus。

## 6. 本轮最大风险

**一句话**：NECTAR-RAS 的效率收益全部来自「协调」——共享信念、集中调度、让最便宜的成员代劳——而协调恰恰在消耗 R69 赖以自保的**独立性**；一旦共模故障、拜占庭成员或能量市场操纵让群体在错误的模态上高效地达成一致，系统就会用更少的焦耳、更快地、更自信地共同错下去——**省下的每一焦耳，都可能买来一个更一致的错误**。

**次级风险与缓解**：
1. **能量计量不可信 / 低报骗取任务** → 硬件计量 + attestation + 审计账本 + E309；
2. **拍卖合谋与搭便车** → 第二价格 + 受益者付费 + 令牌预算 + 定义 324 审计；
3. **k_eff 估计偏差** → 不可估时取 ρ̄=1 的保守上界 + E303；
4. **通信延迟击穿实时性** → 事件触发 + 消息超时按缺失处理 + 硬延迟门 + E306/E311；
5. **λ_E 设计不当导致过度保守或过度乐观** → 离线 DP 标定 + E314 regret 约束；
6. **群体规模扩展后的组合爆炸** → 候选动作与成员裁剪 + 分层拍卖 + E312。

**定义 317（ETC）** `send ⇔ ‖b_i−b^s‖²_{Σ⁻¹}>τ_comm ∨ λ_E E_comm < VoI(m)`；只发量化信念/充分统计量；延迟 p99 ≤ τ_comm_max，超时按缺失处理。

**定义 318（CEW）** `k_eff=1ᵀΣ⁻¹1`；等相关时 `k_eff=N/(1+(N−1)ρ̄)`；证据纪律从数人头改为数独立源；不可估时取 ρ̄=1。

**定义 319（CHD）** 贝叶斯融合下必有 `ΔH_cons ≤ I_inj+ε`；`r_cas>1+δ` ⇒ 复制/重复计数/相关性低估；共识降级为单源，触发再观测或回退 R69。它是 R68 标定吸收、R69 流似然第二意见的群体镜像。

**定义 320（DBR）** `D_{t+1}=max(1, D_t−η·comm+ζ·reobserve)`；`D<D_min` 或 CHD 报警时，用能量换回独立再观测；能量不足则回退纯保守。独立性有焦耳价格。

**定义 321（ERF）** `E_reserve_i=E_safe_stop+E_return+E_comm_min+margin`；任一动作后所有受影响成员须满足 `E_i−E_i(a) ≥ E_reserve_i`；硬约束，先于 VoI。

**定义 322（ESA）** K 从 1 逐级升到 4，直到 `ΔH/ΔE_comp < λ_E`；FMA 仅在群体分歧/CHD 报警/高歧义时回放；λ_E=0 时退化为 R69。

**定义 323–325（威胁/审计/证书）** `ℰ_NECTAR=ℰ_FLUID×ℰ_swarm`；SVA 审计能量账本、拍卖、k_eff、r_cas、ERF、溯源并回灌慢环；J_NECTAR 并入能量与独立性指标。

**定义 326（严格包含）** 五退化条件下与 FLUID 逐指令相同，再按 R69 定理 16 与 R68 相同。

**定义 327–328（共模 / 视界调度）** 共模集与 `ρ_cm` 定义「效率—独立」前沿，安全要求操作点落在 `k_eff ≥ k_min` 一侧；λ_E(t) 随 t→T 或 E→E_reserve 单调上升，软墙处发散，自动禁止借安全余量做信息。

## 3. 关键算法伪代码

```python
# IP-264/267 CBS+ETC：事件触发的群体信念（不传原始观测）
class CollectiveBelief:
    def update_local(self, i, z_i, E_i, tau_i): self.b[i] = fuse_local(self.b[i], z_i)
    def maybe_broadcast(self, i, lam_E):
        m, gain = quantize(self.b[i]), mutual_info(self.b_shared, quantize(self.b[i]))
        if norm(self.b[i]-self.b_shared) > TAU_COMM or gain > lam_E*E_comm(i, m):
            self.send(i, m)                                  # 超时按缺失处理

# IP-265 EWV：能量感知信息价值（R69: lam_E=0, j=i）
def energy_aware_value(g, j, dependents, b, lam_E):
    dH = sum(w[i]*expected_entropy_drop(b[i], g) for i in dependents)
    return dH - lam_E*energy_cost(j, g) - social_cost(g)

# IP-266 IAM：受益者付费、最省者执行的第二价格拍卖
def auction(g, dependents, candidates, lam_E, tokens):
    bids = sorted((attested_energy_cost(j, g), j) for j in candidates
                  if erf_ok(j, g) and c_ras_wm.certify_info(g, j))
    if not bids: return None
    j_star, price = bids[0][1], (bids[1][0] if len(bids) > 1 else bids[0][0])
    payer = max(dependents, key=lambda i: w[i])
    return (g, j_star, price) if tokens[payer] >= price and deadline_ok(j_star, g) else None

# IP-268/269 CEW+CHD：独立性与回声室
def effective_sources(Sigma): return float(ones @ inv(Sigma) @ ones)   # k_eff ∈ [1,N]
def cascade_ratio(dH_cons, I_inj, eps): return dH_cons/(I_inj+eps)     # >1+δ ⇒ 复制

# IP-270/271 ERF+ESA：硬能量底线与计算调度
def erf_ok(j, g):
    return all(E[i]-energy_cost(i, g) >= reserve_floor(i) for i in {j}|comm_dependents(j))
def choose_K_and_FMA(mode_head, disagreement, lam_E):
    K = 1
    while K < 4 and marginal_entropy_gain(K, mode_head)/E_comp(K) > lam_E: K += 1
    run_fma = (disagreement > TAU_DIS or mode_head > TAU_MODE) \
              and lam_E*E_fma < expected_fma_value()
    return K, run_fma

# IP-276 主闭环（R69 之上只插入群体与能量层；失败一律回退 FLUID/R68）
def NECTAR_round(i, obs, swarm):
    z_i, o = swarm.trunk(obs); swarm.cbs.update_local(i, z_i, E[i], tau[i])
    swarm.cbs.maybe_broadcast(i, swarm.lam_E)
    U_ale, U_epi, modes = swarm.aud.decompose(swarm.fmp.sample(o, K=1), z_i, swarm.mode_head)
    k_eff = swarm.cew.effective_sources(swarm.evidence_cov())
    if swarm.chd.suspect() or k_eff < swarm.k_min:
        U_epi = TAU_EPI if not swarm.dbr.can_reobserve(swarm.lam_E) \
                else (swarm.dbr.request_independent_look() or U_epi)
    g = None
    if U_epi > TAU_EPI and not swarm.slow_fault_suspect:
        g = swarm.iam.auction_best(info_action_candidates(modes, swarm.dependents()), swarm.lam_E)
    if g is not None:
        answer = swarm.execute(g.owner, g); swarm.cbs.fuse_answer(answer)
        U_epi = swarm.cia.residual(U_epi, answer)
    lam = max(swarm.efs.risk_scale(), lam_floor(U_ale + (U_epi if g is None else 0.0)))
    K, run_fma = swarm.esa.choose_K_and_FMA(swarm.mode_head(z_i), swarm.disagreement(), swarm.lam_E)
    if run_fma: swarm.fma.update(swarm.fmp, swarm.last_action, o, swarm.calibrated_o)
    k = swarm.c_ras_wm.certified_prefix(swarm.ach.propose(), swarm.wm_preds)
    swarm.sva.submit_async(g, k_eff, swarm.chd.r_cas, swarm.energy_ledger, swarm.clearing_price)
    return k, lam, swarm.select_mode(modes, U_epi, lam), (U_ale, U_epi)
```

## 4. 推导

**引理 19（能量价格下的选择单调性）** `V(λ_E)=max_{g,j}[Σw_iΔH_i−λ_E E_j−c]` 关于 λ_E 单调不增、分段线性凸；被选动作能量 `E*` 单调不增；λ_E=0 时与 R69 MINT 完全相同。系：R69 的硬预算 c_max 只是 λ_E 的分段常值近似，无法表达「电越少越只做最值钱的消歧」的连续退化。

**引理 20（相关证据的有效样本量收缩）** 标准化噪声协方差 Σ 下 `k_eff=1ᵀΣ⁻¹1 ≤ N`；等相关 `ρ̄` 时 `k_eff=N/(1+(N−1)ρ̄)`。把 N 个相关源当独立源融合会高估置信约 `√(N/k_eff)` 倍；ρ̄→1 时 N 人一致 ≡ 一人判断。系：R69 的「k 正交源」在群体里必须换成「k_eff 独立源」。

**引理 21（信息守恒与级联判别）** 正确贝叶斯融合且不重复计数时 `ΔH_cons ≤ I_inj+ε`；`r_cas>1+δ` 必存在复制、重复计数或相关性低估之一。故 r_cas 是回声室的判别统计量，且与 R68 的 `(r_res↓,Δa↑)` 同构——都是不能被局部校准吸收的第二意见。

**引理 22（多样性预算的充分条件）** `D=E[k_eff] ≥ D_min` 且 `k_min=⌈D_min⌉` 时证据纪律成立；`D<D_min` 时存在共模误差同时穿过所有成员。恢复 D 的最小能量 ≥ `D_min·E_reobserve`，故独立性可定价，且必须计入 λ_E。

**引理 23（能量储备下的安全不退化）** 动作先过 ERF、再过 C-RAS-WM，失败时按定义 307 单调回退，则任意能量调度 / 拍卖结果下最坏物理风险不超过 R69；节能只来自不影响安全包络与非信息任务的松弛。证明：ERF 与认证都只删除不可行动作，不依赖目标函数。

**定理 18（NECTAR 严格包含 FLUID-RAS）** A99–A103 下 NECTAR 任意状态期望风险 ≤ FLUID；定义 326 五条件成立时逐指令相同，并按 R69 定理 16 与 R68 相同。R69 是「N=1、能量免费、完全独立」边界；群体与能量层只增加更便宜的消解方式。

**定理 19（能耗—信息 Pareto 与影子价格最优性）** 凸化后可行前沿凹，存在 λ_E* 使操作点满足「边际 VoI/焦耳 = λ_E*」，且 λ_E* 随预算收紧上升。调度律：不问「预算超没超」，问「这一焦耳买到多少熵降」。λ_E→0 回 R69 慷慨端，λ_E→∞ 信息动作自动停止。

**定理 20（级联—安全耦合与保守回退）** 若 `r_cas>1+δ` 且能量约束内无法恢复 `k_eff≥k_min`，则共识降级为单源、未消解 epistemic 计入 λ_floor；安全侧等价 R69 纯保守。省能协调只以放弃效率为代价，不以降低安全为代价。

## 7. 本轮最大风险

**一句话**：NECTAR-RAS 的效率收益全部来自「协调」——共享信念、集中调度、让最便宜的成员代劳——而协调恰恰在消耗 R69 赖以自保的**独立性**；一旦共模故障、拜占庭成员或能量市场操纵让群体在错误的模态上高效地达成一致，系统就会用更少的焦耳、更快地、更自信地共同错下去——**省下的每一焦耳，都可能买来一个更一致的错误**。

**次级风险与缓解**：能量计量不可信/低报（硬件计量 + attestation + 审计 + E309）；拍卖合谋与搭便车（第二价格 + 受益者付费 + 令牌预算 + SVA）；k_eff 估计偏差（不可估时取 ρ̄=1 + E303）；通信延迟击穿实时性（事件触发 + 超时按缺失 + 硬延迟门 + E306/E311）；λ_E 设计不当（离线 DP 标定 + E314 regret）；规模扩展组合爆炸（候选/成员裁剪 + 分层拍卖 + E312）。
