# 第 2 轮（UniBot 线累计；本轮灵感循环第 1 轮；本轮灵感：「开源硬件」×「机器人操作系统」）

> **接续说明**：第 1 轮 UniBot-SAGE 把主问题定义为“能力栈”（抓握显式化 × 技能路由 × 推理期适应 + 工程层），编号 U1–U12 / L1–L7 / E601–E618 / IP-01–IP-08。本轮**不推翻**其领域事实与机制结论，而是往下一层问：**策略运行其上的“基座”本身可不可信**——它看到的观测有多旧、它站的那台机器与标称差多少、以及我们能在多便宜的真机上验证它。新增编号：定义 M1–M12、引理 L8–L14、实验 E619–E636、创新点 IP-09–IP-16；第 1 轮资产全部保留。

## 0. 情报核实（检索/核验日期 2026-11-17；按确定性分层）

**A. 已由第 1 轮核实、本轮直接沿用（接口事实）**
1. 提交本质是一个**远程分布式实时系统**：websockets + msgpack + numpy；N 台真机、N 个连续端口、每端口独立 `reset()`；官方采集 per-step 延迟及其波动、动作统计规律性并可能据此评估可信度。⇒ 观测与动作在时间上并不同时，这是本轮要正面处理的对象。
2. 观测是 4 路 480×640@30fps（AV1，头 stereo×2 + 左右腕）+ 1 维抓手开合 + arm/ee/lower_body 低维状态；动作 chunk 长度自定。⇒ 不同模态的采样率、编码与传输延迟不同，天然存在时间错位。
3. 官方 32 个数据集是 **LeRobot v3.0**（G1 + Dex1）。⇒ 数据格式与开源硬件生态（LeRobot）同源，这是“物理孪生”可行的接口基础。

**B. 开源生态中可直接借用（低风险；需本地核验版本与许可）**
4. **ROS 2 的时间/一致性契约可同构借用**：QoS 的 `deadline / lifespan / liveliness / reliability / history`、`message_filters` 的 `ApproximateTime` 同步、`tf2` 的带时间戳查询与缓存、`rosbag2` 的带时间戳录制/回放。关键不是“必须装 ROS”，而是这些是**已被工程验证过的一套时间语义**，可在 websocket 服务里以定义 M1–M5 同构实现。
5. **硬件抽象层的既有范式**：`ros2_control` 的 `hardware_interface`（state/command interface + lifecycle：init→configure→activate→deactivate→cleanup，配合 `read()/write()` 循环）。我们用它把“官方远程 API”和“本地孪生”做成同一策略的两个后端（IP-14）。
6. **开源硬件臂/本体**：LeRobot 生态提供 SO-100/SO-101、Koch 等低成本开源臂与夹爪；G1 提供 `unitree_ros2` / `unitree_sdk2`（DDS）。⇒ 用数百到数千元级硬件即可搭一个**共享同一 obs/act schema 的物理孪生**，而官方数据同为 LeRobot 格式，可直接读。

**C. 必须本地/真机核验的假设（标记 H，进入风险登记册）**
- **H1**：G1 侧是否提供逐帧时间戳/可控时钟？若只给“到达时刻”，时滞只能由到达时刻 + 序列号估计，误差不可忽略。
- **H2**：孪生与 G1 的保真度是否**任务相关**（而非只是平均偏置）？这是本轮最大未测量量。
- **H3**：关节零位 / 连杆尺度 / 夹爪间隙在 N 台评测机之间的实际离散度未知。
- **H4**：评测端 chunk 执行/插值语义（第 1 轮 Q5）仍未闭环；时滞条件化必须在实测语义后再决定启用方式。

## 1. 直觉（两灵感的第一性原理）

**灵感 1 ·「开源硬件」→ 真机的稀缺与差异，都是“基座”问题，不是“模型”问题**

第一性原理有两条，方向相反但互补：
- **(a) 稀缺 ⇒ 用开源硬件造“物理孪生”**。第 1 轮把代理评测做成了纯仿真（IP-06）。但仿真缺的恰是**接触物理、相机噪声、夹爪实际行程**。开源硬件把“复制物理条件”的成本从“再买一台 G1”降到“几百到几千元”，于是我们能用**真实接触**做 A/B，而不只是渲染。但要立刻钉死一句：孪生的价值不是“像”，而是**迁移保真度**——孪生上的排序能否预测真机排序（引理 L11）。
- **(b) 差异 ⇒ 每台机器都要“在线辨识”**。开源硬件意味着规格公开，但评测用的是**未知的那 N 台 G1**：连杆尺度、关节零位、夹爪间隙、相机外参都可能偏。一个按标称运动学训练的策略，在插入类任务上会遭遇系统性偏差——这正好解释第 1 轮“断点在最后一环”。可解的形态是：episode 开头用几条**标定探针**估计这台的参数，再让策略条件化在辨识结果上（引理 L12）。

**灵感 2 ·「机器人操作系统」→ 策略在时间上是“失明”的**

第一性原理：ROS 教给机器人学最重要的一课不是“消息怎么发”，而是**“系统是一个带时间的图”**——正确性取决于时间对齐与时间预算，而不只是消息内容。把这条原则搬到 UniBot：
- 当前提交把 4 路相机、EE 位姿、抓手读数各自取“最新”拼在一起 ⇒ 这是一组来自**不同时刻**的快照。头相机与腕相机可能差 1–3 帧（33–100 ms），再叠加解码与网络抖动；而动作 chunk 还要在**未来**执行。若末端以 0.15 m/s 运动，100 ms 的时滞就是 15 mm 的位置偏置——对 5 mm 级的插入容差是致命的（引理 L8，§2-A 仿真）。这与第 1 轮“最难的是插入/旋转”完全同源。
- 正确形态不是“更快地传”，而是**在正确的时刻做正确的推断**：定义共同评估时刻、把各模态对齐到该时刻、并把动作预测到执行时刻——即**时滞条件化推理**（M2–M4）。
- 同时，ROS 的 `hardware_interface` 给了“同一策略、两个后端”的工程范式，正好把灵感 1 的孪生与官方 API 缝合（IP-14）。

**合成**：开源硬件（造基座 + 辨识基座）× 机器人操作系统（对齐时间 + 抽象硬件）⇒ **UniBot-ECHO**：
**E**mbedded-time **C**ompensated **H**ardware-abstraction **O**rchestration（嵌入式时间补偿 · 硬件抽象编排）。
三层：**Twin（物理孪生）→ Time（时间对齐与时滞补偿）→ Identity（在线参数辨识）**，外面套一层 **HAL（双后端硬件抽象）**。
一句话：**SAGE 决定“策略多强”，ECHO 决定“这份强在多旧、在哪台、可不可信的世界里还剩多少”。**

## 2. 本轮量化发现（机制校验，非真机结果）

> 数据：`exp/mirror_sim.py → exp/mirror_results.json`（seed 20261117，Monte Carlo）。**只验证结构与机制**，数值不代表真机；任务级迁移需 E619/E623 实测。

| 发现 | 数值（仿真） | 策略含义 |
|---|---|---|
| 时滞 33→100 ms 的未补偿偏置 | 4.95 → 15.0 mm（v=0.15 m/s） | 一旦 `v·Δ > ε`，未补偿插入的成功率**结构性趋零**，与模型容量无关 |
| 5 mm 容差插入：未补偿 vs 一阶补偿 | 33 ms：0.48 vs 0.99；66 ms：0.00 vs 0.78；100 ms：0.00 vs 0.44 | **时滞对齐是“从不可能到可能”的开关**，不是润色 |
| 补偿的残余误差 | 1.6 → 4.6 mm（33→100 ms） | 补偿有代价：速度估计与加速度界决定上限 → 需要“启用/关闭”门 |
| 孪生选优：系统偏差 0 pp | n=1：Kendall τ=0.39，选入真机 top-3 概率 0.52；n=16：τ=0.81，0.90 | 孪生要足够多次重复才有分辨力 |
| 孪生选优：系统偏差 2 pp | n=16：τ=0.68，top-3 概率 0.78 | **任务相关偏差**会把 τ 拖到 0.6 附近 → 必须做保真度门控 |
| 系统辨识：m 条探针 | m=0 残余 12 mm（成功率 0.08）；m=5 → 3.4 mm（0.65）；m=20 → 1.8 mm（0.98） | **几条标定探针就能把最难的插入从“不可做”救到“可做”**，边际收益递减于 m |

**一句话**：**两个灵感各自都指向同一个被忽略的变量——策略与世界之间的“对齐误差”：时间上的时滞（Time）与本体上的参数偏差（Identity）；而开源孪生（Twin）是把这两者在真机之外测出来的唯一低成本手段。**

## 3. 研究问题（本轮）

- **Q6（时滞可观测性）**：在只有“到达时刻 + 序列号”、未必有逐帧硬件时间戳的条件下，能否把每个模态的观测年龄 `τ_m` 估到毫秒级，并给出置信度？
- **Q7（时滞条件化的收益与代价）**：一阶外推在接触瞬间（最需要它的插入相位）恰恰最不可靠；如何界定“何时补偿、何时退回不补偿”，并把准则写成可证伪的门？
- **Q8（孪生的可信任域）**：怎样用最少真机锚点把“孪生排序 ↔ 真机排序”的保真度标定出来，并给出“这个结论能不能用孪生下的”决策规则（MDE 门控）？
- **Q9（在线参数辨识）**：能否用 ≤10 条探针在 episode 开头识别连杆尺度/零位/夹爪间隙，使插入类任务的到达误差落进容差？探针是否会污染正常任务？
- **Q10（硬件抽象的正确性）**：官方 API 与本地孪生若 obs/act 语义有一处不等价，A/B 就变成“接口伪影”；HAL 需要强制哪些不变量（L13）？
- **Q11（时间感知的降级）**：延迟尖峰时，ROS 式 QoS 的正确动作是“丢旧帧重规划”还是“延长 chunk”？与第 1 轮 IP-03 的缝合/延迟整形如何合成而不叠加抖动？

## 4. 设计原则（D1–D6）

- **D1 对齐先于容量**：任何改动先问“它是否减小了策略与世界的对齐误差（时间/本体/接口）”，再问“是否更大”。对齐误差是乘性的，模型容量是加性的。
- **D2 时间是显式变量**：所有观测带 `(t_stamp, age, conf)`；所有动作带 `(t_target, horizon)`；策略显式条件化于 `age/horizon`，而不是隐含地猜。
- **D3 孪生只用于“可迁移的结论”**：孪生输出必须附带“可信域”（τ 与 MDE）；超出可信域一律升级到官方 debug/计分时段。
- **D4 硬件参数是一等状态**：每台机器的 `(尺度, 零位, 夹爪间隙)` 是 episode 级状态，可辨识、可回退到标称。
- **D5 接口不变量优先于性能**：HAL 先保证 twin 与 official 的 obs/act/时间语义逐项等价（L13），再谈优化。
- **D6 合规不变**：仍是单 checkpoint、单 API；时间戳/辨识量全部来自已传输观测与到达时刻，不读取评测侧私有信息。

## 5. 最小可提交闭环（MVP）与退化链

**MVP = IP-11（时滞估计+对齐） + IP-12（时滞条件化，带门控） + IP-14（HAL 双后端） + 第 1 轮冻结的 SAGE 安全基线**。
理由：IP-11/12 直击第 1 轮“断点在最后一环”的时间成因，且纯推理侧、零数据；IP-14 是把孪生结论搬回真机的前提；冻结基线保证任何情况下可交。

**严格退化链（任一不可用 ⇒ 回退行为，而非漂移）**：
- L0 时滞估计不可靠（conf 低）⇒ 退回“不补偿”的开环执行（等价第 1 轮基线）。
- L1 外推在接触相位不可信 ⇒ 该相位只对齐、不外推（降为 C0 时间对齐）。
- L2 系统辨识探针失败/超预算 ⇒ 退回标称参数。
- L3 孪生保真度出域（τ<0.3）⇒ 孪生仅用于工程联调，不用于策略选择。
- L4 HAL 不变量校验失败 ⇒ 禁用孪生后端，只保留官方 API。
- L5 整条新链路失效 ⇒ 提交冻结的 SAGE 基线。

## 6. 预期贡献（可验收）

1. **把“时滞”从工程噪声升级为一等可观测量**：给出多模态观测年龄估计器 + 置信度，并在官方 client 上实测（E619）。
2. **给出时滞条件化的“收益-风险”判据**：证明未补偿时滞在插入容差下是乘性致命项，并给出外推的启用门与残余误差界（L8/L9）。
3. **给出物理孪生的“可信任域”口径**：Kendall τ + MDE + 选优概率，明确“哪些结论能用孪生、哪些必须真机”（L11，E623/E624）。
4. **把系统辨识做成 episode 级动作**：≤10 条探针估计硬件参数，给出残余误差→成功率的映射（L12，E625/E626）。
5. **一套双后端硬件抽象**：官方 API 与开源孪生共享同一策略，附不变量校验与一致性回归（L13，E627）。
6. **对第 1 轮资产的重新排序**：IP-03（延迟/缝合）与 IP-06（代理评测）被本轮的 Time/Twin 吸收并强化，而不是并列堆叠。

## 7. 本轮最大风险

**一句话**：孪生的保真度是一个隐藏且不可直接观测的变量——如果它与真机的差不是“加性常数”而是**任务相关**的（某些任务上系统性偏乐观），那么我们在孪生上做的每一次 A/B 都会把研究引向错误方向，而且越投入越难回头；更糟的是，时滞补偿最依赖的速度/加速度估计，恰好在接触瞬间（最需要补偿的插入相位）最不可靠，可能“补偿反而不如不补偿”。

## 8. 下一轮迭代计划（深化与修剪，不推倒重来）

- **深化**：把 IP-11 的时滞估计与 IP-14 的 HAL 时间语义合并成一张“时间预算表”（每模态 age 分布 + 每相位可容忍 age）；把 IP-13 的探针与第 1 轮 IP-02 的抓握确认合并为“一次动作，两个信息”（标定探针顺带验抓）。
- **修剪预案**：若 E623 的孪生↔真机 τ < 0.3，则**砍掉一切以孪生为依据的策略选择**，孪生只保留为工程联调台；资源全部转回时间对齐（IP-11/12，机制正确、无需孪生证明）。
- **保留项**：IP-11（时间对齐）、IP-12（时滞条件化）、IP-14（HAL 不变量）在任何情况下不砍——它们不依赖孪生保真度，只依赖“时间错位客观存在”。

# 第 2 轮产物 · 创新点清单 v2（UniBot 线）：**UniBot-ECHO**

> **ECHO = Embedded-time, Compensated, Hardware-abstraction Orchestration**（嵌入式时间补偿 · 硬件抽象编排）。
> 定位：包在 UniBot-SAGE（第 1 轮能力栈）下面的**基座层**；不改主干能力，只处理“策略与世界之间的对齐误差”——时间上的时滞、本体上的参数偏差、以及验证基座（孪生）的可信度。

## 0. 本轮结论摘要

**一句话路线**：把“开源硬件 × 机器人操作系统”编译成一条**对齐栈**：

`Twin（物理孪生/保真度） → Time（时间对齐/时滞条件化） → Identity（在线参数辨识） → HAL（双后端硬件抽象）`。

**四条量化依据（仿真机制校验，详见 §2）**：

| 证据 | 数值 | 推出的设计 |
|---|---|---|
| 未补偿时滞 33→100 ms 的偏置 4.95→15.0 mm（v=0.15 m/s） | `v·Δ > ε` 时插入成功率结构性趋零 | **TimeAligner（IP-11）**：显式估计并对齐观测年龄 |
| 5 mm 容差：66 ms 未补偿 0.00 / 一阶补偿 0.78；100 ms 0.00 / 0.44 | 补偿是“从不可能到可能”的开关 | **DelayCond（IP-12）**：带门控的时滞条件化推理 |
| 孪生系统偏差 2 pp、n=16：τ=0.68，选入真机 top-3=0.78；偏差 0：τ=0.81/0.90 | 孪生有用但需可信域 | **FidelityMap（IP-10）**：τ + MDE 门控，而非“越像越好” |
| 系统辨识 m=0→20：残余 12.0→1.8 mm，插入成功 0.08→0.98 | 几条探针救回最难插入 | **SysID（IP-13）**：episode 级硬件参数辨识 |

**合规红线（沿用 D6/P5）**：单 checkpoint、单 API；时间戳与辨识量全部来自已传输观测与到达时刻；不读评测侧私有信息；不读题硬编码；不利用未声明执行语义（H4 未实测前不启用跨 chunk 外推）。

## 1. 创新点总表 IP-09–IP-16

| 编号 | 名称 | 优先级 | 一句话 | 依赖 | 可验收指标 |
|---|---|---|---|---|---|
| **IP-09** | TwinRig 低成本物理孪生 | **P0** | 用开源硬件臂 + 同规格相机搭与官方 obs/act 同构的孪生，做真实接触 A/B | 开源硬件 + 3D 打印 | 与官方 schema 逐键一致；重复性 CV ≤5% |
| **IP-10** | FidelityMap 保真度标定与可信域 | **P0** | 用真机锚点标定孪生↔真机排序一致性，给出 τ/MDE 可信域 | IP-09 + 真机锚点 | Kendall τ ≥0.6 才可用于选优；MDE 可计算 |
| **IP-11** | TimeAligner 多模态时间对齐 | **P0** | 估计每模态观测年龄，把各流对齐到“动作执行时刻” | 官方 client | age 估计误差 ≤10 ms；对齐后错位 ≤1 帧 |
| **IP-12** | DelayCond 时滞条件化推理 | **P0** | 把 `age/horizon` 变成策略显式条件，按相位门控外推 | IP-11 | 插入类相对提升 ≥25%；接触相位不劣化 |
| **IP-13** | SysID 在线硬件参数辨识 | P1 | ≤10 条标定探针估计尺度/零位/夹爪间隙并条件化 | IP-09 | 残余 ≤3 mm（m≤10）；探针不污染任务 |
| **IP-14** | HAL 双后端硬件抽象 | **P0** | 官方 API 与孪生共享同一策略，强制接口不变量 | IP-09/IP-11 | 双后端一致性回归通过；策略零改动切换 |
| **IP-15** | QosGuard 时间感知降级 | P1 | 延迟尖峰时按 deadline/lifespan 丢旧重规划或延长 chunk | IP-03/IP-12 | p99 不漂；降级 <0.5%；无异常交互模式 |
| **IP-16** | ReplayBench 时间戳级回放 | P2 | 用 LeRobot/rosbag 风格带时间戳回放做确定性复现 | IP-14 | 同输入两次回放逐位一致；可回归 |

> **P0 = 本轮 MVP**；**P1 = 机制正确、需先实测 H1/H4 或拿到探针数据**；**P2 = 有余量再做**。第 1 轮 IP-01–IP-08 保留，投资组合见 §9。

## 2. 本轮量化发现（机制校验）

> 全部来自 `exp/mirror_sim.py`。A 是延迟补偿的 2D 插入 Monte Carlo；B 是孪生选优的保真度模型；C 是参数辨识的贝叶斯/最小二乘缩放。**这些是结构性结论，不是真机结论。**

**A. 时滞 → 位置偏差 → 插入成功（2D，ε=5 mm，v=0.15 m/s，a=0.5 m/s²，σ0=1 mm）**

| 有效时滞 Δ=τ_obs+τ_exec | 未补偿偏置 | 未补偿成功 | 一阶补偿残余 | 补偿成功 |
|---:|---:|---:|---:|---:|
| 33 ms | 4.95 mm | 0.479 | 1.61 mm | 0.992 |
| 66 ms | 9.90 mm | 0.000 | 2.88 mm | 0.775 |
| 100 ms | 15.0 mm | 0.000 | 4.62 mm | 0.441 |
| 150 ms | 22.5 mm | 0.000 | 8.02 mm | 0.176 |
| 200 ms | 30.0 mm | 0.000 | 12.54 mm | 0.075 |

读法：**未补偿时，一旦 `v·Δ > ε`，成功率不是“变差”而是“结构性归零”**；补偿把它拉回可行区，但补偿本身随 Δ 变大而失效（速度估计噪声 + 加速度项）。⇒ 需要“按相位启用/关闭”的门（IP-12 的 gate），而不是全局开补偿。

**B. 孪生选优的保真度（16 个候选，潜在真值 q~U[20,35]）**

| 孪生系统偏差 σ_sys | 每榜试验数 n | Kendall τ(孪生,真机) | 孪生 argmax 落在真机 top-3 |
|---:|---:|---:|---:|
| 0 pp | 1 | 0.394 | 0.523 |
| 0 pp | 4 | 0.635 | 0.745 |
| 0 pp | 16 | 0.808 | 0.903 |
| 2 pp | 16 | 0.680 | 0.783 |
| 4 pp | 16 | 0.514 | 0.623 |

读法：孪生的价值**强依赖于重复次数 n 与系统偏差 σ_sys**；σ_sys 只要 2 pp，就能把 τ 从 0.81 拖到 0.68。⇒ **FidelityMap 必须显式测量 σ_sys，并把“可信域”写进决策规则**，不能默认孪生等于真机。

**C. 系统辨识：m 条探针后的残余与插入成功（4 参数，σ_probe=2 mm，lever=1）**

| 探针数 m | 参数残余 RMS | 5 mm 插入成功 |
|---:|---:|---:|
| 0（标称） | 12.0 mm | 0.083 |
| 3 | 4.31 mm | 0.492 |
| 5 | 3.43 mm | 0.651 |
| 10 | 2.48 mm | 0.871 |
| 20 | 1.77 mm | 0.982 |
| 50 | 1.13 mm | 1.000 |

读法：**m=5–10 就把最难的插入从“不可做”拉到“可做”**，再往上边际递减。⇒ 探针应短（≤10）、只在 episode 开头、且可跳过（退化到标称）。

## 3. 创新点详述

### IP-09 · TwinRig 低成本物理孪生（P0）

- **动机**：第 1 轮 IP-06 的代理评测是纯仿真，缺接触物理与相机噪声；官方真机时段稀缺。开源硬件（LeRobot SO-100/SO-101、Koch 等 + 同规格相机 + 3D 打印夹具）能以极低成本复制“真实接触”。
- **与现有方案的差异**：别人把“仿真→真机”当唯一迁移路径；我们插入一个**物理中间层**：真实接触 + 真实相机噪声 + 可控实验，再把结论按保真度门控迁回 G1。
- **技术可行性**：中–高。schema 同构可直接复用官方 LeRobot v3.0 键名与单位；难点是夹爪与桌面几何的机械复现、以及相机位姿的可重复安装。
- **所需资源**：硬件数百–数千元级；一台工作站；3D 打印与标定工具。
- **落地步骤**：①对齐 obs/act 键名、单位、频率（4 相机 → 孪生可降为 2–3 相机，但键语义一致）；②夹爪行程/力标定；③相机内外参与桌面对齐；④做重复性测试（同一动作 50 次，位置 CV）；⑤建立“孪生能复现哪些失败模式”的白名单/黑名单。
- **风险**：①机械保真度不足 ⇒ 只用于“机制方向”而非绝对值；②夹爪动力学差异 ⇒ 抓握类结论降级；③成本失控 ⇒ 先做最小 1 臂版本。

### IP-10 · FidelityMap 保真度标定与可信域（P0）

- **动机**：孪生的价值是**迁移保真度**，不是逼真度（§2-B）。若不标定，孪生 A/B 会把研究带偏。
- **与现有方案的差异**：常见做法是“仿真/孪生上涨点就当真”；我们维护 `(τ, MDE, σ_sys)` 的可信域，超出即升级到真机。
- **技术可行性**：中。需要少量真机锚点（官方 debug 或计分时段），但只需**排序**信息。
- **落地步骤**：①预注册一批候选策略（≥8，覆盖预期效应量）；②在孪生与真机各测 n 次；③算 Kendall τ、σ_sys 与 MDE；④拟合“孪生效应 → 真机效应”的校准曲线；⑤把可信域写进决策规则（L11/L14）。
- **风险**：①真机锚点太少 ⇒ τ 置信区间宽；②任务相关偏差 ⇒ 分任务维护 τ，不做全局一个数；③过拟合锚点 ⇒ 留出任务做验证。

### IP-11 · TimeAligner 多模态时间对齐（P0）

- **动机**：4 相机 @30fps + AV1 解码 + 网络抖动 + 低维状态不同步 ⇒ “最新拼一起”是时间上不连贯的快照。ROS 的 `message_filters`/`tf2` 早已把这类问题形式化。
- **与现有方案的差异**：别人默认“到达即当前”；我们为每个模态维护 `(t_stamp, arrival, seq)`，估计年龄并**对齐到动作执行时刻** `t_e`，而不是对齐到“现在”。
- **技术可行性**：高（纯软件）。若 H1 无逐帧时间戳，则用“到达时刻 + 序号 × 帧间隔”估计，并给置信度。
- **落地步骤**：①在 client 侧记录每模态 arrival 与 seq；②估帧间隔/抖动（EWMA）；③`t_e = now + τ_exec_est`；④低维状态线性插值/外推，图像取最近帧并标记 age；⑤输出统一时间戳的 obs 包 + age 向量；⑥审计 age 分布。
- **风险**：①无硬件时间戳 ⇒ 估计有偏；②插值在接触瞬间引入伪运动 ⇒ 图像只取最近帧，不外推；③时基漂移 ⇒ 周期重估。

### IP-12 · DelayCond 时滞条件化推理（P0）

- **动机**：§2-A 显示未补偿时滞在插入容差下是乘性致命项；一阶补偿能救回，但在接触相位最不可靠。
- **与现有方案的差异**：别人把延迟当“要压低的成本”；我们把它当**输入**：策略显式看到 `age/horizon/conf`，并据相位决定“对齐 / 一阶外推 / 不外推”。
- **技术可行性**：中–高。最小形态甚至不需要重训：把 age/horizon 作为额外条件特征（或在输入上做前向预测）即可；理想形态是训练时域随机化 age/horizon。
- **落地步骤**：①把 IP-11 的 age 向量接进策略输入；②实现前向预测器 `f_pred`（EE 速度估计 + 加速度界）；③定义门控：接触相位（grasp/align/insert）`horizon` 收短、外推权重降；④训练期随机化 age/horizon 做鲁棒化；⑤A/B 对比 raw / align-only / align+cond。
- **风险**：①接触瞬间速度估计噪声大 ⇒ 门控必须保守；②外推与评测端插值叠加 ⇒ 先复刻语义（H4）再启用；③过拟合特定时滞 ⇒ 域随机化。

### IP-13 · SysID 在线硬件参数辨识（P1）

- **动机**：评测 N 台机器，连杆尺度/零位/夹爪间隙未知；按标称训练的策略在插入上系统性偏差（§2-C）。
- **与现有方案的差异**：别人假设标称运动学；我们把硬件参数当 episode 级隐状态，用**短探针**辨识并条件化。
- **技术可行性**：中。探针设计（激发参数可观性的小动作）是关键；可用官方数据回归“参数 → 观测残差”的可观性矩阵。
- **落地步骤**：①定义参数向量 θ_hw（如 2 连杆尺度 + 2 零位 + 夹爪间隙）；②设计 ≤10 条探针（小幅多方向运动）；③最小二乘/贝叶斯估计 + 先验（标称）；④把 θ_hw 作为条件特征或用于动作补偿；⑤残差监控与回退标称。
- **风险**：①探针耗时/扰动任务 ⇒ 放 episode 开头、限步数、可跳过；②参数不可观 ⇒ 只辨识可观子空间；③不同机器差异小 ⇒ 收益为 0，先做“零成本探测”再投入。

### IP-14 · HAL 双后端硬件抽象（P0）

- **动机**：孪生结论要能搬回真机，前提是两后端**接口等价**；否则 A/B 是接口伪影。ROS 的 `hardware_interface` 正是这个范式。
- **与现有方案的差异**：别人为每个平台写一套胶水；我们用统一 HAL（state/command interface + lifecycle），策略零改动切换后端，并把不变量做成断言。
- **技术可行性**：高（工程）。核心是 schema adapter + 时间语义 + 动作语义（joint/ee、chunk 执行）的逐项对齐。
- **落地步骤**：①定义 HAL 元组（obs keys/单位/频率、act 语义、时间契约）；②实现 official backend（websocket）与 twin backend；③启动时做一致性自检（形状/单位/时间戳单调）；④跑“同一策略双后端”回归；⑤把差异记录进审计。
- **风险**：①隐蔽的单位/坐标系差异 ⇒ 断言 + 黄金样本；②时间语义不同 ⇒ 统一到 `t_e`；③HAL 抽象泄漏 ⇒ 保留后端特有能力作为可选扩展，不进主链。

### IP-15 · QosGuard 时间感知降级（P1）

- **动机**：延迟尖峰时，盲目排队会执行过期动作；ROS QoS 的 `deadline/lifespan` 给出“过期即丢、重规划”的正确动作。
- **与现有方案的差异**：第 1 轮 IP-03 只做“超预算兜底”；QosGuard 把降级做成**时间语义驱动**：丢旧帧、缩短 chunk、或重规划，三选一按相位定。
- **技术可行性**：中–高。需要 IP-11 的 age 估计与第 1 轮 IP-03 的 chunk 调度。
- **落地步骤**：①为每模态设 lifespan；②定义降级阶梯（丢帧 → 短 chunk → 安全位）；③按相位选择降级动作；④8 h 压测；⑤导出 p50/p99/降级计数。
- **风险**：①丢帧导致信息缺失 ⇒ 只丢“过期且可替代”的；②频繁切换抖动 ⇒ 最小驻留 + 死区；③与缝合叠加 ⇒ 二者互斥开关，真机 A/B 决定。

### IP-16 · ReplayBench 时间戳级回放（P2）

- **动机**：要让孪生/真机结论可复现、可回归，必须有带时间戳的确定性回放（`rosbag2` 思想 + LeRobot 数据）。
- **与现有方案的差异**：别人复现到“同一批文件”；我们复现到“同一时间轴 + 同一 age 向量”，才能复现时滞相关行为。
- **技术可行性**：高（工程）。
- **落地步骤**：①录制 `(stamp, arrival, payload)`；②按 `t_e` 重放到 HAL；③断言逐位一致；④做成回归门。
- **风险**：①非确定性算子（GPU/并行）⇒ 固定种子/单线程；②存储开销 ⇒ 采样关键片段。

## 4. 符号与定义（M1–M12）

| 符号 | 含义 |
|---|---|
| `t_e` | 动作**执行**时刻（不是决策时刻） |
| `t_m` | 模态 m 的采样时刻 |
| `τ_m` | 模态 m 的观测年龄 `= t_e − t_m` |
| `conf_m` | 年龄估计置信度 |
| `A_τ(·)` | 时间对齐算子（对齐到 `t_e`） |
| `H` | 动作块执行时域（horizon） |
| `g_t` | 第 1 轮抓握隐变量（保留） |
| `σ_sys` | 孪生相对真机的系统偏差（任务级） |
| `Θ` | 孪生可信域 `{τ ≥ τ0, MDE ≤ δ0}` |
| `θ_hw` | 硬件参数（尺度/零位/夹爪间隙） |
| `Φ` | 标定探针集合 |
| `Π_HAL` | 硬件抽象元组（obs/act/时间契约） |

**定义 M1（共同评估时刻）** 令 `t_e = t_now + τ_exec_est`，`τ_exec_est` 为“决策到动作真正被执行”的估计时延；所有观测统一对齐到 `t_e`，而非 `t_now`。

**定义 M2（观测年龄）** `τ_m = t_e − t_m`；无硬件时间戳时 `t_m = arrival_m − k_m·Δt_m`（`k_m` 为队列内序号，`Δt_m` 为估计帧间隔），并给出 `conf_m = f(抖动估计, 丢帧数)`。

**定义 M3（时间对齐算子）** `A_τ(o) = { ĝ_m(t_e) }`，其中低维状态用线性插值/外推，图像取 `argmin_m |t_m − t_e|` 的帧并附 `(τ_m, conf_m)`；不对图像做外推。

**定义 M4（时滞条件化策略）** `π(a_{1:H} | A_τ(o), ℓ, z_task, z_phase, τ_vec, H)`：策略显式条件化于年龄向量与执行时域。

**定义 M5（前向预测器）** `f_pred(x_{t}, v_t, a_max, h)` 给出 `h` 步后的状态估计；残余误差上界见引理 L9。

**定义 M6（年龄门控）** 设相位 `z_phase`，当 `z_phase ∈ {grasp, align, insert}` 或 `‖v‖` 高时，外推权重 `w_pred(z_phase, τ) = w_hi`（保守）否则 `w_lo`；`w_pred=0` 即退回“只对齐不外推”。

**定义 M7（孪生保真度）** `Fid = (τ_rank, σ_sys, MDE)`：`τ_rank` 为孪生↔真机排序的 Kendall τ；`σ_sys` 为任务级系统偏差；`MDE` 为在给定 `n` 下可检测的最小效应。

**定义 M8（可信域）** `Θ = { (π_a, π_b) : τ_rank ≥ τ0 且 MDE ≤ δ0 }`；只有落在 `Θ` 内的**结论**才允许用孪生做选择，否则升级到官方时段。

**定义 M9（硬件参数）** `θ_hw = (s_L, s_1, s_2, gap) `（连杆尺度缩放、两个关节零位、夹爪有效间隙），先验为标称 `θ_0`。

**定义 M10（标定探针）** `Φ = {φ_1..φ_k}`，`k ≤ k_max`，每条为小幅、多方向、可观性高的动作；估计 `θ̂_hw = argmin Σ ‖y_i − h(φ_i; θ)‖² + λ‖θ − θ_0‖²`。

**定义 M11（HAL 契约）** `Π_HAL = (obs_schema, act_schema, unit_spec, time_contract, act_semantics)`；后端合法当且仅当五项逐项等价（引理 L13）。

**定义 M12（QoS 降级算子）** `Q(π, τ_vec) → π'`：按模态 lifespan 丢过期帧、按相位缩短 `H`、必要时切安全位；每次降级记入审计。

## 5. 关键算法骨架

```python
# ===== IP-11 + IP-12：时间对齐 + 时滞条件化（单 checkpoint 内，不新增接口）=====
class TimeAligner:
    """把 4 相机 + 低维状态对齐到 t_e = now + tau_exec_est（ROS message_filters/tf 思想）"""
    def __init__(self, dt=1/30, tau_exec_est=0.04):
        self.dt = dt
        self.tau_exec_est = tau_exec_est

    def push(self, key, payload, arrival):
        self.buf[key].append((arrival, payload))     # arrival 替代缺失的硬件时间戳
        self.buf[key] = self.buf[key][-8:]           # 只留短历史，L1 可检索

    def age(self, key):
        arrival, _ = self.buf[key][-1]
        k = len(self.buf[key]) - 1
        t_m = arrival - k * self.dt                  # M2：无硬件时间戳时的估计
        return (self.tau_exec_est + (time.time() - t_m)), 1.0 / (1.0 + k * 0.1)

    def align(self, obs):
        out, ages = {}, {}
        for key in obs:
            if "images" in key:                      # 图像：取最近帧，不外推（避免伪运动）
                out[key] = obs[key][-1]
            else:                                     # 低维：线性插值/外推到 t_e
                out[key] = linear_extrapolate(self.buf[key], target=time.time()+self.tau_exec_est)
            ages[key] = self.age(key)
        return out, ages

class DelayCondPolicy:
    """M4：把 age/H 变成显式条件；M6：按相位门控外推权重"""
    def __init__(self, model, aligner, pred, tau_conf=0.8):
        self.m, self.al, self.pred = model, aligner, pred

    def act(self, obs, phase, H):
        o, ages = self.al.align(obs)
        w = self.gate(phase, ages)                    # M6：接触相位 w 小
        if w > 0:
            o["ee_pred"] = self.pred(o, horizon=H) * w + o["ee_now"] * (1 - w)
        feats = self.model.encode(o, age_vec=ages, H=H)   # 策略显式看到 age/H
        return self.model.act(feats)

    def gate(self, phase, ages):
        if phase in ("grasp", "align", "insert"):     # 接触相位：保守
            return 0.0 if max(np.mean(list(a[0] for a in ages.values())), 0) > 0.1 else 0.3
        return 0.7
```

class SysIDProbe:
    def __init__(self, theta0, diag, k_max=10, lam=1e-2):
        self.theta0, self.diag, self.k_max, self.lam = theta0, diag, k_max, lam

    def probe(self, hal):
        ys, phis = [], []
        for phi in self.design(self.k_max):           # M10：小幅多方向动作
            y = hal.step(phi)                          # 真实硬件响应
            ys.append(y); phis.append(phi)
        # 可辨识子空间上的岭回归；不可观方向保持先验 theta0
        theta = ridge_estimable(ys, phis, self.theta0, self.lam, self.diag)
        resid = rms_residual(ys, phis, theta)
        return theta, resid                            # 残差大 -> 回退 theta0

## 6. 推导（引理 L8–L14）

**引理 L8（时滞-偏置下界）** 设策略在时刻 `t` 以年龄 `Δ = t_e − t_m` 的端点状态做对齐式控制，末端沿运动方向的速率为 `v`。则未补偿的沿运动方向位置偏置满足 `|bias| ≥ v·Δ − σ_obs`。若插入容差为 `ε` 且 `v·Δ > ε`，则在忽略横向误差的理想情形下，未补偿插入成功率上界为 0。∎（§2-A：Δ=66 ms, v=0.15 m/s ⇒ bias 9.9 mm > 5 mm ⇒ 成功率 0。）

**引理 L9（一阶外推的残余误差与启用条件）** 若用窗口 `w` 估计速度、加速度上界 `a`，向前预测 `Δ`（到 `t_e`），残余位置误差满足 `e_res ≲ (1/2)aΔ² + σ_vel·Δ + σ_model`。因此当 `(1/2)aΔ² + σ_vel·Δ + σ_model < v·Δ` 时，外推严格优于不补偿；在接触相位 `σ_model` 与 `σ_vel` 剧增，条件可能反向，此时应把 `w_pred → 0`（M6 门控）。∎（§2-A：Δ=100 ms 时补偿仍 0.44，Δ=200 ms 降到 0.075，与 `aΔ²` 项增长一致。）

**引理 L10（时间对齐不改变合规形态）** 时间戳、年龄、前向预测均只使用已传输的观测内容与本地到达时刻，不引入评测侧私有信息，也不改变“单 checkpoint / 单 API”的对外形态。故 IP-11/12 在合规性上等价于第 1 轮基线。∎

**引理 L11（孪生选择器的信息价值）** 设候选真实差异分散度为 `Δ_q`，孪生系统偏差 sd 为 `σ_sys`，每策略每榜试验 `n`、评估噪声 sd 为 `σ_e/√n`。则孪生↔真机 Kendall τ 随 `σ_sys² + σ_e²/n` 相对 `Δ_q²` 增大而单调下降；孪生 argmax 落入真机 top-k 的概率同理下降。⇒ 存在可计算的“可信域”，超出即不可用于选择。∎（§2-B：σ_sys 0→2 pp 使 τ 0.81→0.68。）

**引理 L12（辨识误差缩放）** 对 `k` 参数、每探针噪声 sd `σ_p`、先验 sd `σ_0`，贝叶斯后验方差满足 `var_j ≥ (σ_0^{-2} + m/(kσ_p²))^{-1}`（等号在正交设计下取到）。故末端残余 `e_res = sqrt(Σ_j var_j)·ℓ`（`ℓ` 为等效力臂），插入成功 `P(succ) = 1 − exp(−ε²/(2e_res²))`。⇒ 给定 `ε` 可反解所需 `m*`。∎（§2-C：m=5 ⇒ 3.43 mm；m=20 ⇒ 1.77 mm。）

**引理 L13（硬件抽象的可迁移性）** 同一策略在孪生与官方后端上可比较，当且仅当 `Π_HAL` 五项逐项等价（obs 键/单位/频率、动作语义、时间契约）。若任一不等价，则两后端的性能差含不可分离的接口项，A/B 结论无效。∎

**引理 L14（保真度门控的决策规则）** 在 `Θ`（M8）内，用孪生做选择的期望损失不超过在真机上做选择的损失加上 `MDE` 项；在 `Θ` 外，必须把结论升级到真机时段。故正确策略是“先测 `Fid`，再决定信不信”，而非默认二选一。∎
