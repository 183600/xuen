# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 1 轮；本轮灵感：「长程任务」×「Gazebo」）

> 第 60 轮的 SGEC 把「场景→意图→约束→阻抗→执行→EV-exec→场景更新」打成了一个闭环，但这个闭环的默认尺度是**一次场景、一次接触、一次证据**。UniBot 的真实任务是**长程**的：整理桌面→抓取→搬运→上架，跨越数十个子目标、数十分钟、多种场景与多次人机对话。于是三个结构性缺口暴露出来：
> 1. **没有任务进度状态**：SSM/SIC 只回答「现在是什么场景、这次接触可不可信」，不回答「任务走到第几步、还剩多少、当前进度下的剩余成功概率是多少」。没有进度隐变量，长程只能被当成一条更长的短程轨迹，误差随阶段数 H 复利累积，且无法在不可逆动作前止损。
> 2. **Gazebo 只是离线训练工具，不是在线证据源**：第 60 轮没有把仿真纳入执行闭环。Gazebo 的价值不只是生成数据，而是能在执行前**反事实排练**候选策略；但仿真存在 sim-to-real gap，若把仿真均值当成功率，就会「在孪生里很稳、在现实里翻车」。
> 3. **证据链只有顺序，没有结构**：EPIR 用 seq_id+hash 保证「先来后到」，但长程任务的证据不是流水账，而是**与子目标义务绑定的分层结构**。线性链在 H=10³ 时无法压缩、无法局部验证，也无法回答「这个阶段凭什么算完成」。
>
> 本轮把 SGEC 升级为 **LATTICE（Long-horizon Adaptive Task Trust lattice，长程任务可信执行格）**：用阶段图刻画进度，用校准孪生排练未来，用失败预算分摊长程风险，用重接地抑制漂移，用 Merkle-DAG 分层证据保证可审计，用沉没成本防火墙保证「该停就停」。

## 0. 直觉与动机

**灵感 1（长程任务 → 任务阶段图 LTPG）**
直觉：长程任务不是一条 3000 步的动作序列，而是一张**带前置/后置条件的阶段图**。做饭的关键状态是「食材已切好」，不是「机械臂第 1742 步」。把任务进度从「时间/步数」换成「阶段后验 + 完成度」后，长程才具备三个能力：可解释（现在在哪一阶段）、可中断（阶段边界是天然的恢复点）、可恢复（从最近一个已关闭阶段重启，而不是从头重放）。关键洞见：**长程的第一性表征是阶段与条件，而不是轨迹。**

**灵感 2（长程任务 → 长程失效预算 LHEB）**
直觉：若每阶段成功率 99%，独立假设下 H=100 的联合成功率只剩 0.99¹⁰⁰≈36.6%；即便不假设独立，union bound 也给出 P(失败)≤Σ(1−p_i)。所以长程安全不是「把每一步做得更稳」的单点问题，而是一个**总失败预算的显式分配问题**：给可逆阶段多分一点失败概率，给不可逆阶段（松手、上架、越过桌沿）少分一点。由此还能得到一个硬约束：若单阶段最小可证明失败概率是 δ_min，则系统能可靠覆盖的horizon上界约为 H_max≈⌊δ_task/δ_min⌋。关键洞见：**长程能力 = 每阶段可证明性 × 预算分配，而不是策略的平均分。**

**灵感 3（Gazebo → 排练-孪生校准 GRTC）**
直觉：Gazebo 是一个**可反事实重放的物理预言机**：执行前先在数字孪生里排练若干候选阻抗策略，观察哪些会打滑、哪些会卡死；但孪生不是真值，必须用真实 EV-exec 在线校准物理参数 θ_sim（摩擦系数、接触刚度、阻尼、通信/执行延迟、传感器噪声），并只输出**校准后的下置信界（LCB）**，绝不输出仿真均值。关键洞见：**仿真只能作为「带误差棒的预言机」；排练的价值取决于校准，而不是保真度的绝对值。**

**灵感 4（Gazebo → 仿真-现实后验 S2RP）**
直觉：把 θ_sim 当成一个持续被证据更新的隐变量。每次真实执行后，用接触特征（法向力、穿透、滑移、接触时长）更新 p(θ_sim|EV-exec)；当仿真预测分布与真实证据分布的 W₁/MMD 距离超过阈值时，判定「孪生失配」，自动给排练结果降权并触发重辨识。关键洞见：**仿真保真度本身必须被监测；一个从不承认自己失配的仿真器，就是长程系统里最危险的传感器。**

**灵感 5（长程任务 → 重接地调度 RGS）**
直觉：长程中的模型漂移会累积，不能等失败才修正。应像 SLAM 的回环检测一样，在「预测漂移将要超过 ε_max」之前主动插入探针/重观测，用最小探针成本把后验拉回；阶段边界与不可逆动作是**强制接地检查点**。关键洞见：**重接地不是异常处理，而是长程执行的前置条件。**

**灵感 6（长程任务 → 分层证据证书 HEC）**
直觉：长程证据应是一棵 Merkle-DAG：叶节点是每阶段 EV-exec，中间节点是「阶段关闭证书」，根节点是「任务证书」。每个阶段带证据义务 ev_i；义务未满足就标记 unknown，禁止关闭阶段；旧证据可压缩归档，但根哈希链不可篡改。这样验证者只需 O(log n) 的 Merkle 证明就能确认某个阶段，而不必重放整条时间线。关键洞见：**长程可审计性来自分层与义务，而不是更长的时间戳序列。**

**灵感 7（长程任务 → 沉没成本防火墙 SCF）**
直觉：长程系统最容易犯的错不是算错，而是「已经做了 80%，不能停」——escalation of commitment。决策必须只看**剩余阶段的未来期望价值**，历史成本只进审计日志，不进入决策函数的定义域。关键洞见：**长程系统最大的敌人可能不是误差累积，而是不肯止损。**

**灵感 8（合流 → 长程排练-证据闭环 LHREL）**
直觉：LTPG 预测下一阶段及其义务 → GRTC 在校准孪生中排练候选 K → HSI 用校准 LCB 与失败预算判定 commit/rehearse/replan/abort → 执行 → EV-exec 追加到 HEC → 关闭阶段并更新 θ_sim 与进度 → 到达 RGS 时点则主动接地。形成「规划—排练—承诺—执行—证据—再接地」的长程闭环。关键洞见：**长程不是把短程闭环重复 H 次，而是在每次重复之间插入预算再分配、孪生校准与接地纠偏。**

## 1. 形式化定义（增量：定义 161–170）

**定义 161（长程任务阶段图 LTPG）** 长程任务 T 的阶段图
G_T = (V, E, Ψ, D, ev, w)
其中：
- **阶段集** V={v₀,…,v_n}，每个阶段 v_i=(pre_i, post_i, req_i, c_i)：pre_i 为守卫条件，post_i 为可测完成谓词，req_i 为所需场景/意图/阻抗签名，c_i∈[1,∞) 为**不可逆严重度**（松手、上架等取高值）。
- **转移** E⊆V×V，边 (i,j) 带守卫 pre_j 与转移核 A_{ij}。
- **时长模型** D_i 为阶段 i 的持续时间分布（对数正态/半马尔可夫 hazard）。
- **证据义务** ev_i 为阶段关闭必须满足的证据谓词集合（力/位姿/场景/意图/排练证书/重接地证明）。
- **完成权重** w_i∈[0,1] 为阶段 i 关闭后累计完成度，w_0=0, w_n=1。
- **阶段后验**：给定观测 o_{1:t} 与停留时间 d_t，半马尔可夫前向递推
  α_t(j) ∝ Σ_i α_{t−1}(i)·A_{ij}·S_j(d_t)·L_j(o_t)，
  其中 S_j 为阶段 j 的生存函数，L_j 为观测似然。
- **任务进度** ρ_t = Σ_i α_t(i)·w_i；**剩余 horizon** H_rem(t)=Σ_i α_t(i)·(n−i)。
- **阶段可行性** feas_i(K) = SIC_valid(v_i,K) ∧ rehearsal_LCB_i(K) ≥ 1−δ_i。

**定义 162（Gazebo 排练-孪生校准 GRTC）** 数字孪生 W(θ) 与排练算子：
- **孪生参数** θ=(μ_friction, k_contact, c_damping, τ_latency, σ_sensor, m_obj)∈Θ。
- **排练**：给定阻抗策略 K 与阶段 v_i，在 W(θ) 中做 M 次随机化 rollout，得到仿真结果
  p_sim(K;θ) = (1/M)Σ_{m=1}^M 1[success_m]。
- **校准后验**：p(θ|E_{1:t}) ∝ p(θ)·Π_{τ≤t} L(EV-exec_τ|θ)，其中 E 为真实证据集。
- **校准下界**：p_cal^−(K;v_i) = LCB_α[ ∫ p_sim(K;θ) p(θ|E_{1:t}) dθ ]，
  用 Beta/Clopper–Pearson 处理有限 rollout，用 split-conformal 或 posterior predictive 处理 θ 不确定性，保证在可交换性下覆盖率 ≥1−α。
- **孪生失配**：Δ_s2r = W₁( P_sim(EV-exec|θ*), P_obs(EV-exec) )；若 Δ_s2r>τ_g，则孪生证书置为 INVALID，排练结果不得用于 commit。
- **排练成本** c_sim·M + c_time，rollout 数 M 由信息价值决定（定义 170）。

**定义 163（仿真-现实后验 S2RP）** 孪生可信证书
V_twin = (p(θ|E_{1:t}), Δ_s2r, coverage, θ_MAP, HPD_α)
- **可信判据**：V_twin.valid ⇔ Δ_s2r≤τ_g ∧ coverage≥1−α ∧ θ_MAP∈Θ_safe。
- **更新**：每关闭一个阶段，用该阶段 EV-exec 的接触特征更新 p(θ|E)；若连续 k 次失配，冻结排练、退回「保守解析上界」。
- **降权**：排练结果按可信度 γ_twin=exp(−Δ_s2r/τ_g) 折算为有效样本数，避免失配孪生给出虚假置信。

**定义 164（长程失效预算 LHEB）** 任务失败预算 δ_task∈(0,1) 的分摊：
- **预算账本**：δ_rem(t) 初始为 δ_task，每关闭阶段 i 扣除该阶段已消耗的失败概率 δ_i。
- **分配规则**：给定严重度 c_i 与先验权重 δ_i⁰，解
  min_{δ_i≥0} Σ_i c_i δ_i + γ Σ_i δ_i log(δ_i/δ_i⁰)
  s.t. Σ_i δ_i ≤ δ_rem(t)，
  得 δ_i ∝ δ_i⁰·exp(−c_i/γ)（边界处截断归一）。严重度越高，分到的失败预算越小。
- **每阶段要求**：p_i^req = 1−δ_i。
- **长程保证（union bound）**：P(任务失败) ≤ Σ_i P(阶段 i 失败) ≤ Σ_i δ_i ≤ δ_task。该界不依赖阶段独立性。
- **horizon 上界**：若每阶段可证明的最小失败概率为 δ_min，则 H_max≈⌊δ_task/δ_min⌋；超过 H_max 必须缩短 horizon（重分解为更少、更可验证的宏动作）或提高单阶段可证明性。
- **不可逆保护**：对 c_i 超过阈值的阶段，额外要求 δ_i≤δ_irr，否则禁止执行（只允许 rehearse/replan）。

**定义 165（重接地调度 RGS）** 状态估计 x_t 与协方差 Σ_t 的主动接地：
- **预测**：Σ_{t+1}=FΣ_tFᵀ+Q+B_t，其中 B_t 为模型偏差项；预测漂移 d_t=√(tr(Σ_t))+‖bias_t‖。
- **调度**：选检查点集 C 解
  min_C Σ_{t∈C} c_probe(t) + λ Σ_t E[d_t]
  s.t. sup_t E[d_t] ≤ ε_max。
- **强制检查点**：阶段边界、不可逆动作前、孪生失配后、意图/场景切换后。
- **新鲜度**：证据权重 w(Δt)=exp(−Δt/τ_trust) 只用于**信念更新**；原始证据永不删除，供 HEC 审计。
- **触发**：若 d_t≥ε_max 而预算不足以探针，则降低自主等级（请求人类确认）而非静默漂移。

**定义 166（分层证据证书 HEC）** 任务证据的 Merkle-DAG：
- **叶节点** ℓ=(phase_id, seq_id, timestamp, hash(EV-exec), obligation_id, status∈{sat, viol, unknown})。
- **阶段节点** C_i=(path_signature, MerkleRoot(leaves_i), K_used, scene/intent, sim_cert_root, reground_proof, status)。
- **任务根** C_T=(LTPG 实际路径, MerkleRoot({C_i}), budget_ledger, exceptions, root_hash)。
- **关闭规则**：阶段 i 可关闭 ⇔ ∀e∈ev_i: status(e)=sat，或存在带权限签名的显式风险接受（accepted_risk）。
- **验证**：任何阶段/叶子的存在性与内容可用 Merkle 证明在 O(log n) 内验证；篡改或遗漏会改变根哈希（碰撞阻力下可忽略概率）。
- **压缩**：已关闭子树可替换为「检查点根 + 归档指针」；根链保持不可变，支持长程审计。
- **与 EPIR 的关系**：EPIR 的 seq_id/hash 成为叶节点不变量；HEC 在其上增加「阶段义务」与「分层聚合」。

**定义 167（沉没成本防火墙 SCF）** 决策 d∈{commit, rehearse, replan, abort}：
- **决策泛函** U(d)=E[V_future(d)] − Cost_future(d) − λ_risk·CVaR_β(Loss_future)。
- **防火墙约束**：C_past∉dom(U)；历史成本只写入 HEC 的 budget_ledger，禁止进入 U 的任何项。
- **承诺规则**：commit ⇔ U(commit)>0 ∧ HSI_LB≥1−δ_rem ∧ V_twin.valid ∧ 不可逆保护满足。
- **升级检测**：若「计划投入随 HSI 下降而上升」，标记 escalation_risk，强制 rehearse/replan/abort 三选一。

**定义 168（长程成功指数 HSI）** 剩余阶段的校准成功概率：
- **名义值**（正相关假设）：HSI=Π_{i∈remaining} p_cal,i。
- **保守下界**（分布无关）：HSI_LB=1−Σ_{i∈remaining}(1−p_cal,i^−)=1−Σ_i δ_i^post。
- **判定**：commit 使用 HSI_LB；报告同时给出名义值、下界与每阶段贡献，避免「平均值掩盖不可逆阶段」。
- **更新**：阶段关闭后，用真实结果把该阶段 δ_i 结算，并把剩余预算按定义 164 重分配。

**定义 169（长程排练-证据闭环 LHREL）** 算子 LHREL(M, T, G_T, δ_task)：
```
① LTPG:  α_t ← semi_markov_update(observations, durations); ρ_t, H_rem
② GRTC:  V_twin ← s2rp.update(EV-exec_history); if invalid → conservative_bound
③ Rehearse: for next phase i: p_cal,i^− ← gazebo_rehearse(K_candidates, θ~p(θ|E))
④ Budget: δ ← lheb.allocate(δ_rem, c, δ⁰); p_i^req ← 1−δ_i
⑤ HSI:   HSI_LB ← 1 − Σ_remaining(1−p_cal^−); d ← scf.decide(HSI_LB, δ_rem, V_twin)
⑥ switch d:
     commit   → execute(K_best); 
     rehearse → M ← voi.select_rollouts(); goto ③;
     replan   → shorten_horizon / re-decompose; goto ①;
     abort    → request_human / safe_hold; return ABORT_CERT
⑦ Evidence: EV-exec ← build_exec_evidence(telemetry); HEC.append_leaf(EV-exec)
⑧ Close: if post_i ∧ obligations_sat: HEC.close_phase(i); δ_rem ← δ_rem−δ_i
⑨ Reground: if rgs.due(): EV-probe ← probe(); HEC.attach_proof(EV-probe); update posterior
⑩ Update: p(θ|E) ← s2rp.update(EV-exec); α_{t+1} ← LTPG.transition()
⑪ Return (ρ_t, HSI_LB, HEC.root, V_twin, δ_rem)
```

**定义 170（PCE+++++ 长程可信预算）** B_lh=(B_task, B_sim, B_evidence, B_reground)：
- **B_task**：阶段推断/规划的算力与时延；耗尽 ⇒ 退化为短程 MPC（horizon=1），并显式标记「长程能力已降级」。
- **B_sim**：Gazebo rollout 数、墙钟时间、并行 world 数；耗尽 ⇒ 使用解析保守界/上次排练结果（降权），禁止伪装成新证据。
- **B_evidence**：HEC 存储、Merkle 证明计算、归档带宽；耗尽 ⇒ 先压缩已关闭子树，仍不足则降低证据粒度并标记 audit_degraded。
- **B_reground**：探针次数、人类确认次数、重观测时长；耗尽 ⇒ 扩大安全裕度 + 降低自主等级，绝不静默提高置信。
- **长程 VOI**：
```
voi_lh(π) = E[ΔHSI_LB(π)]·L_fail − c_exec(π) − c_sim·M(π) − c_probe(π) − c_evidence(π)
```
只在 voi_lh>0 时排练/探针；排练的 rollout 数 M* 由序贯停止规则给出。

## 2. 关键算法伪代码

### IP-161 LTPG（长程任务阶段图）

```python
class LongHorizonPhaseGraph:
    def __init__(self, phases, edges, duration_models):
        self.V = phases
        self.A = edges                    # A[i][j] transition kernel
        self.D = duration_models          # survival functions S_j(d)
        self.alpha = uniform(len(phases))
        self.progress = 0.0

    def update(self, observation, dwell_time):
        prior = self.alpha
        post = np.zeros(len(self.V))
        for j, vj in enumerate(self.V):
            trans = sum(prior[i] * self.A[i][j] for i in range(len(self.V)))
            post[j] = trans * self.D[j].survival(dwell_time) \
                      * vj.observation_likelihood(observation)
        self.alpha = normalize(post)
        self.progress = sum(self.alpha[i] * self.V[i].weight
                            for i in range(len(self.V)))
        return self.alpha, self.progress

    def next_phases(self, top_k=3):
        return sorted(range(len(self.V)),
                      key=lambda j: -self.alpha[j])[:top_k]

    def remaining_horizon(self):
        n = len(self.V)
        return sum(self.alpha[i] * (n - i) for i in range(n))
```

### IP-162/163 GRTC + S2RP（排练与孪生校准）

```python
class GazeboRehearsalTwin:
    def __init__(self, world_factory, theta_prior, tau_gap=0.15):
        self.world_factory = world_factory
        self.theta_post = theta_prior
        self.tau_gap = tau_gap
        self.evidence_buffer = []
        self.valid = False

    def rehearse(self, phase, K_candidates, M):
        p_sim = {}
        for K in K_candidates:
            wins = 0
            for _ in range(M):
                theta = self.theta_post.sample()
                world = self.world_factory(theta)
                wins += world.rollout(phase, K).success
            p_sim[K] = wins / M
        return p_sim

    def calibrated_lcb(self, p_sim, alpha=0.05):
        # Beta / Clopper-Pearson lower bound over finite rollouts,
        # then posterior-predictive integration over theta.
        return {K: clopper_pearson_lower(w, n, alpha)
                for K, (w, n) in p_sim.items()}

    def update_real_evidence(self, ev_exec):
        self.evidence_buffer.append(ev_exec)
        self.theta_post = bayes_update(self.theta_post, ev_exec)
        sim_feats = self.simulate_matched_features()
        real_feats = extract_contact_features(self.evidence_buffer)
        gap = wasserstein_1d(sim_feats, real_feats)
        self.valid = (gap <= self.tau_gap) and self.theta_post.coverage >= 0.95
        return gap, self.valid
```

### IP-164 LHEB（长程失效预算）

```python
class LongHorizonFailureBudget:
    def __init__(self, delta_task, gamma=1.0):
        self.delta_rem = delta_task
        self.gamma = gamma

    def allocate(self, phases, delta0=None):
        n = len(phases)
        delta0 = delta0 or [1.0 / n] * n
        w = np.array([d0 * np.exp(-p.severity / self.gamma)
                      for d0, p in zip(delta0, phases)])
        w = np.maximum(w, 1e-9)
        delta = w / w.sum() * self.delta_rem
        for i, p in enumerate(phases):
            if p.irreversible:
                delta[i] = min(delta[i], p.delta_irr)
        return delta

    def consume(self, delta_i):
        self.delta_rem = max(0.0, self.delta_rem - delta_i)
        return self.delta_rem

    def horizon_bound(self, delta_min):
        return int(np.floor(self.delta_rem / delta_min))
```

### IP-165 RGS（重接地调度）

```python
class RegroundingScheduler:
    def __init__(self, eps_max=0.05, tau_trust=600.0):
        self.eps_max = eps_max
        self.tau_trust = tau_trust
        self.cov = initial_cov()
        self.last_probe = 0.0

    def predict(self, F, Q, bias):
        self.cov = F @ self.cov @ F.T + Q + bias
        return np.sqrt(np.trace(self.cov))

    def due(self, phase_boundary=False, irreversible=False,
            twin_invalid=False, switch=False):
        drift = np.sqrt(np.trace(self.cov))
        return (drift >= self.eps_max or phase_boundary or irreversible
                or twin_invalid or switch)

    def freshness(self, age):
        return np.exp(-age / self.tau_trust)
```

### IP-166 HEC（分层证据证书）

```python
class HierarchicalEvidenceCertificate:
    def __init__(self, task_id):
        self.task_id = task_id
        self.leaves = {}          # phase_id -> [leaf]
        self.phase_roots = {}     # phase_id -> hash
        self.archived = {}

    def append_leaf(self, phase_id, ev_exec, obligations):
        leaf = {
            'phase_id': phase_id,
            'seq_id': ev_exec.seq_id,
            'timestamp': ev_exec.timestamp,
            'hash': sha256(ev_exec),
            'obligation_id': ev_exec.obligation_id,
            'status': check_obligation(ev_exec, obligations)
        }
        self.leaves.setdefault(phase_id, []).append(leaf)
        return leaf

    def close_phase(self, phase_id, obligations, accepted_risk=None):
        leaves = self.leaves[phase_id]
        sat = all(l['status'] == 'sat' for l in leaves
                  if l['obligation_id'] in obligations)
        if not sat and accepted_risk is None:
            return False
        root = merkle_root([l['hash'] for l in leaves])
        self.phase_roots[phase_id] = root
        return True

    def task_root(self):
        return merkle_root(sorted(self.phase_roots.items()))

    def verify_phase(self, phase_id, proof):
        return merkle_verify(self.phase_roots[phase_id], proof,
                             self.task_root())
```

### IP-167/168 SCF + HSI（承诺防火墙与长程成功指数）

```python
class CommitmentFirewall:
    def decide(self, hsi_lb, delta_rem, twin_valid, futures, past_cost):
        # past_cost is deliberately NOT used in the decision.
        del past_cost
        p_req = 1.0 - delta_rem
        if not twin_valid:
            return 'rehearse'
        if hsi_lb < p_req:
            return 'abort' if futures.no_safe_replan() else 'replan'
        if expected_utility(futures.commit) <= 0:
            return 'abort'
        return 'commit'

    def hsi_lower_bound(self, p_cal_lcb):
        return 1.0 - sum(1.0 - p for p in p_cal_lcb)
```

### IP-169 LHREL（长程排练-证据闭环）

```python
def long_horizon_rehearsal_evidence_loop(M, task, graph, delta_task):
    ltp = LongHorizonPhaseGraph(graph.V, graph.A, graph.D)
    lheb = LongHorizonFailureBudget(delta_task)
    rgs = RegroundingScheduler()
    hec = HierarchicalEvidenceCertificate(task.id)

    while not task.done:
        alpha, progress = ltp.update(M.observation, M.dwell_time)
        twin_valid = M.twin.update_real_evidence(M.last_ev_exec)
        phases = [graph.V[i] for i in ltp.next_phases()]
        p_sim = M.twin.rehearse(phases[0], M.K_candidates, M.rollout_budget)
        p_lcb = M.twin.calibrated_lcb(p_sim)

        if not twin_valid:
            p_lcb = conservative_analytic_bound(phases[0])

        delta = lheb.allocate(phases)
        hsi_lb = M.scf.hsi_lower_bound(p_lcb.values())
        d = M.scf.decide(hsi_lb, lheb.delta_rem, twin_valid,
                         M.futures, M.past_cost)

        if d == 'commit':
            telemetry = execute(M, phases[0].K_best)
        elif d == 'rehearse':
            M.rollout_budget = M.voi.select_rollouts()
            continue
        elif d == 'replan':
            task.replan_shorter_horizon()
            continue
        else:
            return abort_certificate(hec, reason='hsi_below_budget')

        ev = build_exec_evidence(telemetry)
        hec.append_leaf(phases[0].id, ev, phases[0].obligations)
        if phases[0].post_condition(telemetry):
            hec.close_phase(phases[0].id, phases[0].obligations)
            lheb.consume(delta[0])
            M.twin.update_real_evidence(ev)

        if rgs.due(phase_boundary=True, irreversible=phases[0].irreversible,
                   twin_invalid=not twin_valid):
            probe = active_probe(M)
            hec.attach_proof(probe)
            M.posterior = fuse(M.posterior, probe)

    return hec.task_root(), progress, lheb.delta_rem
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性/保证 |
|---|---|---|---|
| LTPG | O(|V|²) / 更新（稀疏 A 可 O(|E|)） | O(|V|+|E|) | 阶段后验归一；进度单调（w_i 单调时） |
| GRTC | O(M·|K|·T_rollout) / 排练 | O(M) | 校准 LCB 覆盖率 ≥1−α（可交换性） |
| S2RP | O(1) 更新 + O(N_ev) 距离 | O(N_ev) | 失配检测；失配即降权/冻结 |
| LHEB | O(|V|) 分配 | O(|V|) | union bound：P(fail)≤Σδ_i≤δ_task |
| RGS | O(1) 查询 + O(n) 规划 | O(n) | 漂移 sup≤ε_max 或降自主等级 |
| HEC | O(log n) 验证；O(n) 构建 | O(n) | 篡改/遗漏检测；阶段义务闭合 |
| SCF+HSI | O(|V|) | O(1) | 决策不依赖 sunk cost（按构造） |
| LHREL | O(H·(排练+执行+证据)) | 复用 | 闭环不变式见下 |

**正确性定理（LATTICE）**：在 A66–A72 下：

**(A66) LTPG 良构**：阶段图弱连通，post_i 可测，时长模型正确指定；半马尔可夫前向递推是精确后验。
**(A67) GRTC 校准**：孪生后验 p(θ|E_{1:t}) 校准，排练 LCB 满足 P(p_true ≥ p_cal^−) ≥ 1−α；失配检测功效 ≥ 1−β_g。
**(A68) LHEB 预算**：δ_i 非负且 Σδ_i≤δ_task；union bound 不依赖独立性。
**(A69) RGS 漂移界**：预测协方差上界真实误差；重接地更新使 tr(Σ) 不增。
**(A70) HEC 完整性**：哈希碰撞阻力；阶段关闭需义务满足或显式风险接受。
**(A71) SCF 防火墙**：决策泛函的定义域不含 C_past。
**(A72) PCE+++++ 单调**：四类预算单调消耗，任一耗尽触发对应安全降级。

则：
1. **长程失败界**：若每阶段校准下界满足 p_cal,i^−≥1−δ_i，则 P(任务失败)≤Σδ_i≤δ_task。
2. **horizon 可达性**：可可靠执行的 horizon 满足 H≤⌊δ_task/δ_min⌋；超过时必须缩短 horizon 或提高单阶段可证明性。
3. **排练安全性**：仅当 V_twin.valid 且 p_cal^− 过预算时 commit，因此 sim-to-real gap 不能静默转化为真实安全风险（失配时降权/冻结）。
4. **漂移有界性**：若重接地调度满足 sup d_t≤ε_max，则任意时刻任务状态误差 ≤ε_max（在 A68/A69 下）。
5. **证据可审计性**：任意阶段/叶子可 O(log n) 验证；未满足义务的阶段不能被合法关闭。
6. **止损正确性**：SCF 的决策与 C_past 无关，因此不会因沉没成本而继续不可行任务。

**数值示例（horizon barrier）**：δ_task=0.05，若每阶段最小可证明失败概率 δ_min=0.005，则 H_max≈10；若 H=50，必须把 δ_min 压到 0.001，或把任务重分解成 ≤10 个宏动作阶段。该式说明：**长程能力不是策略泛化能力的线性外推，而是证据质量与预算分配的函数。**

## 2. 关键形式化与推导

### 2.1 长程失败界（LHEB）

设阶段 i 的失败事件为 F_i，失败预算为 δ_i=P(F_i)。不假设阶段独立，直接用 union bound：

```
P(任务失败) = P(∪_i F_i) ≤ Σ_i P(F_i) = Σ_i δ_i ≤ δ_task        (1)
```

因此长程安全的关键不是「每步 p 很高」，而是**把 δ_task 分摊到阶段**。给定不可逆严重度 c_i，采用带熵正则的分配：

```
min_{δ_i≥0}  Σ_i c_i δ_i + γ Σ_i δ_i log(δ_i/δ_i^0)
s.t.         Σ_i δ_i ≤ δ_rem
```

KKT 条件给出：

```
δ_i ∝ δ_i^0 · exp(−c_i/γ)                                        (2)
```

高严重度阶段获得更小的失败预算。示例：δ_task=0.05，c=(1,1,2,4,8)，δ⁰ 均匀，γ=1 时归一化后约

| 阶段 | c_i | δ_i |
|---|---:|---:|
| 可逆搬运 | 1 | 0.0207 |
| 可逆放置 | 1 | 0.0207 |
| 接近桌沿 | 2 | 0.0076 |
| 松手 | 4 | 0.00103 |
| 上架（不可逆） | 8 | 0.0000188 |

不可逆阶段的失败预算被压缩约 1000×，这正是长程系统需要的**风险重分配**。

**horizon barrier**：若每阶段最小可证明失败概率为 δ_min，则

```
H_max ≈ ⌊δ_task / δ_min⌋                                         (3)
```

δ_task=0.05、δ_min=0.005 时 H_max≈10。要跑 H=50，必须把 δ_min 压到 0.001，或把任务重分解为 ≤10 个可验证宏动作。该式把「长程能力」从策略问题转化为**证据质量 + 预算分配**问题。

### 2.2 排练校准（GRTC/S2RP）

仿真排练给出 p_sim(K;θ)，真实参数 θ 未知。校准预测为

```
p_cal(K) = ∫_Θ p_sim(K;θ) p(θ|E_{1:t}) dθ                          (4)
```

用有限 rollout 的 Clopper–Pearson 下界与 θ 后验预测结合，得到 p_cal^−，满足（可交换性下）

```
P(p_true(K) ≥ p_cal^−(K)) ≥ 1−α                                   (5)
```

孪生失配检测：

```
Δ_s2r = W₁(P_sim(EV-exec|θ*), P_obs(EV-exec))                       (6)
V_twin.valid ⇔ Δ_s2r ≤ τ_g ∧ coverage ≥ 1−α ∧ θ_MAP ∈ Θ_safe
```

失配时排练结果按 γ_twin=exp(−Δ_s2r/τ_g) 降权；连续失配则冻结排练，退回解析保守界。**关键设计：仿真永远不能单独把 commit 置为真，它只能降低而非提高真实安全下界。**

### 2.3 重接地（RGS）

误差预测：

```
Σ_{t+1} = F Σ_t Fᵀ + Q + B_t,    d_t = √(tr(Σ_t)) + ‖bias_t‖      (7)
```

调度问题：

```
min_C  Σ_{t∈C} c_probe(t) + λ Σ_t E[d_t]
s.t.   sup_t E[d_t] ≤ ε_max                                       (8)
```

强制检查点：阶段边界、不可逆动作前、孪生失配后、场景/意图切换后。若预算不足以探针，则降低自主等级而非静默漂移。

### 2.4 分层证据（HEC）

叶节点 ℓ=(phase_id, seq_id, ts, hash(EV-exec), obligation_id, status)。阶段节点

```
C_i = (path_sig, MerkleRoot(leaves_i), K_used, scene/intent,
       sim_cert_root, reground_proof, status)                      (9)
```

任务根 C_T=MerkleRoot({C_i} ∪ budget_ledger ∪ exceptions)。阶段关闭规则：

```
close(C_i) ⇔ ∀e∈ev_i: status(e)=sat ∨ accepted_risk(signed)       (10)
```

任意叶子/阶段的成员证明与内容验证为 O(log n)；篡改或遗漏在碰撞阻力下可忽略概率被检出。长程审计从「重放整条时间线」变成「验证一条 Merkle 路径 + 检查义务状态」。

### 2.5 止损决策（SCF/HSI）

```
U(d) = E[V_future(d)] − Cost_future(d) − λ_risk·CVaR_β(Loss_future),  C_past ∉ dom(U)   (11)
HSI_LB = 1 − Σ_{i∈remaining} (1 − p_cal,i^−) = 1 − Σ_i δ_i^post                          (12)
commit ⇔ U(commit)>0 ∧ HSI_LB ≥ 1−δ_rem ∧ V_twin.valid ∧ 不可逆保护满足                 (13)
```

式 (11) 把「已投入成本」从决策定义域中移除；若「计划投入随 HSI 下降而上升」，标记 escalation 并强制 rehearse/replan/abort。

### IP-161 LTPG

```python
class LongHorizonPhaseGraph:
    def __init__(self, phases, edges, duration_models):
        self.V, self.A, self.D = phases, edges, duration_models
        self.alpha = uniform(len(phases))
        self.progress = 0.0

    def update(self, observation, dwell_time):
        post = np.zeros(len(self.V))
        for j, vj in enumerate(self.V):
            trans = sum(self.alpha[i] * self.A[i][j]
                        for i in range(len(self.V)))
            post[j] = trans * self.D[j].survival(dwell_time) \
                      * vj.observation_likelihood(observation)
        self.alpha = normalize(post)
        self.progress = sum(self.alpha[i] * self.V[i].weight
                            for i in range(len(self.V)))
        return self.alpha, self.progress

    def remaining_horizon(self):
        n = len(self.V)
        return sum(self.alpha[i] * (n - i) for i in range(n))
```

### IP-162/163 GRTC + S2RP

```python
class GazeboRehearsalTwin:
    def __init__(self, world_factory, theta_prior, tau_gap=0.15):
        self.world_factory = world_factory
        self.theta_post = theta_prior
        self.tau_gap = tau_gap
        self.evidence_buffer = []
        self.valid = False

    def rehearse(self, phase, K_candidates, M):
        p_sim = {}
        for K in K_candidates:
            wins = 0
            for _ in range(M):
                theta = self.theta_post.sample()
                world = self.world_factory(theta)
                wins += world.rollout(phase, K).success
            p_sim[K] = (wins, M)
        return p_sim

    def calibrated_lcb(self, p_sim, alpha=0.05):
        return {K: clopper_pearson_lower(w, n, alpha)
                for K, (w, n) in p_sim.items()}

    def update_real_evidence(self, ev_exec):
        self.evidence_buffer.append(ev_exec)
        self.theta_post = bayes_update(self.theta_post, ev_exec)
        gap = wasserstein_1d(self.simulate_matched_features(),
                             extract_contact_features(self.evidence_buffer))
        self.valid = (gap <= self.tau_gap) and self.theta_post.coverage >= 0.95
        return gap, self.valid
```

### IP-164 LHEB

```python
class LongHorizonFailureBudget:
    def __init__(self, delta_task, gamma=1.0):
        self.delta_rem = delta_task
        self.gamma = gamma

    def allocate(self, phases, delta0=None):
        n = len(phases)
        delta0 = delta0 or [1.0 / n] * n
        w = np.array([d0 * np.exp(-p.severity / self.gamma)
                      for d0, p in zip(delta0, phases)])
        delta = np.maximum(w, 1e-9) / np.maximum(w, 1e-9).sum() * self.delta_rem
        for i, p in enumerate(phases):
            if p.irreversible:
                delta[i] = min(delta[i], p.delta_irr)
        return delta

    def consume(self, delta_i):
        self.delta_rem = max(0.0, self.delta_rem - delta_i)
        return self.delta_rem

    def horizon_bound(self, delta_min):
        return int(np.floor(self.delta_rem / delta_min))
```

### IP-165 RGS

```python
class RegroundingScheduler:
    def __init__(self, eps_max=0.05, tau_trust=600.0):
        self.eps_max, self.tau_trust = eps_max, tau_trust
        self.cov = initial_cov()

    def predict(self, F, Q, bias):
        self.cov = F @ self.cov @ F.T + Q + bias
        return np.sqrt(np.trace(self.cov))

    def due(self, phase_boundary=False, irreversible=False,
            twin_invalid=False, switch=False):
        return (np.sqrt(np.trace(self.cov)) >= self.eps_max
                or phase_boundary or irreversible or twin_invalid or switch)

    def freshness(self, age):
        return np.exp(-age / self.tau_trust)
```

### IP-166 HEC

```python
class HierarchicalEvidenceCertificate:
    def __init__(self, task_id):
        self.task_id = task_id
        self.leaves, self.phase_roots, self.archived = {}, {}, {}

    def append_leaf(self, phase_id, ev_exec, obligations):
        leaf = {
            'phase_id': phase_id,
            'seq_id': ev_exec.seq_id,
            'timestamp': ev_exec.timestamp,
            'hash': sha256(ev_exec),
            'obligation_id': ev_exec.obligation_id,
            'status': check_obligation(ev_exec, obligations)
        }
        self.leaves.setdefault(phase_id, []).append(leaf)
        return leaf

    def close_phase(self, phase_id, obligations, accepted_risk=None):
        leaves = self.leaves[phase_id]
        sat = all(l['status'] == 'sat' for l in leaves
                  if l['obligation_id'] in obligations)
        if not sat and accepted_risk is None:
            return False
        self.phase_roots[phase_id] = merkle_root([l['hash'] for l in leaves])
        return True

    def task_root(self):
        return merkle_root(sorted(self.phase_roots.items()))

    def verify_phase(self, phase_id, proof):
        return merkle_verify(self.phase_roots[phase_id], proof, self.task_root())
```

class CommitmentFirewall:
    def decide(self, hsi_lb, delta_rem, twin_valid, futures, past_cost):
        del past_cost                      # sunk-cost firewall by construction
        if not twin_valid:
            return 'rehearse'
        if hsi_lb < 1.0 - delta_rem:
            return 'abort' if futures.no_safe_replan() else 'replan'
        if expected_utility(futures.commit) <= 0:
            return 'abort'
        return 'commit'

    def hsi_lower_bound(self, p_cal_lcb):
        return 1.0 - sum(1.0 - p for p in p_cal_lcb)

### IP-169 LHREL

```python
def long_horizon_rehearsal_evidence_loop(M, task, graph, delta_task):
    ltp = LongHorizonPhaseGraph(graph.V, graph.A, graph.D)
    lheb = LongHorizonFailureBudget(delta_task)
    rgs = RegroundingScheduler()
    hec = HierarchicalEvidenceCertificate(task.id)

    while not task.done:
        alpha, progress = ltp.update(M.observation, M.dwell_time)
        twin_valid = M.twin.update_real_evidence(M.last_ev_exec)
        phases = [graph.V[i] for i in ltp.next_phases()]
        p_sim = M.twin.rehearse(phases[0], M.K_candidates, M.rollout_budget)
        p_lcb = M.twin.calibrated_lcb(p_sim) if twin_valid \
                else conservative_analytic_bound(phases[0])

        delta = lheb.allocate(phases)
        hsi_lb = M.scf.hsi_lower_bound(p_lcb.values())
        d = M.scf.decide(hsi_lb, lheb.delta_rem, twin_valid,
                         M.futures, M.past_cost)

        if d == 'commit':
            telemetry = execute(M, phases[0].K_best)
        elif d == 'rehearse':
            M.rollout_budget = M.voi.select_rollouts()
            continue
        elif d == 'replan':
            task.replan_shorter_horizon()
            continue
        else:
            return abort_certificate(hec, reason='hsi_below_budget')

        ev = build_exec_evidence(telemetry)
        hec.append_leaf(phases[0].id, ev, phases[0].obligations)
        if phases[0].post_condition(telemetry):
            hec.close_phase(phases[0].id, phases[0].obligations)
            lheb.consume(delta[0])
            M.twin.update_real_evidence(ev)

        if rgs.due(phase_boundary=True, irreversible=phases[0].irreversible,
                   twin_invalid=not twin_valid):
            probe = active_probe(M)
            hec.attach_proof(probe)
            M.posterior = fuse(M.posterior, probe)

    return hec.task_root(), progress, lheb.delta_rem
```

### IP-170 PCE+++++ 长程预算

```python
class LongHorizonTrustBudget:
    def __init__(self, task_ops, sim_rollouts, evidence_bytes, probe_budget):
        self.B_task, self.B_sim = task_ops, sim_rollouts
        self.B_evidence, self.B_reground = evidence_bytes, probe_budget
        self.used = {'task': 0, 'sim': 0, 'evidence': 0, 'reground': 0}

    def fallback(self):
        if self.used['task'] >= self.B_task:
            return 'short_horizon_mpc'          # horizon=1, long-horizon degraded
        if self.used['sim'] >= self.B_sim:
            return 'analytic_conservative_bound'
        if self.used['evidence'] >= self.B_evidence:
            return 'compress_closed_subtrees'
        if self.used['reground'] >= self.B_reground:
            return 'widen_margin_lower_autonomy'
        return 'normal'

    def voi(self, delta_hsi, loss_fail, c_exec, c_sim, c_probe, c_ev):
        return delta_hsi * loss_fail - c_exec - c_sim - c_probe - c_ev
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LTPG | O(|V|²) / 更新，稀疏 A 为 O(|E|) | O(|V|+|E|) | 阶段后验归一；w_i 单调 ⇒ 进度单调 |
| GRTC | O(M·|K|·T_rollout) | O(M) | 校准 LCB 覆盖率 ≥1−α（可交换性） |
| S2RP | O(1) 更新 + O(N_ev) 距离 | O(N_ev) | 失配检测；失配即降权/冻结 |
| LHEB | O(|V|) | O(|V|) | P(fail)≤Σδ_i≤δ_task（union bound，无独立性假设） |
| RGS | O(1) 查询 + O(n) 规划 | O(n) | sup 漂移 ≤ε_max 或降自主等级 |
| HEC | O(log n) 验证 / O(n) 构建 | O(n) | 篡改/遗漏检测；义务闭合才可关闭阶段 |
| SCF+HSI | O(|V|) | O(1) | C_past 不进入决策（按构造） |
| LHREL | O(H·(排练+执行+证据)) | 复用 | 闭环不变式：commit 必过 LCB+预算+孪生+不可逆四闸 |

**正确性定理（LATTICE）**：在 A66–A72 下：
1. **长程失败界**：若 ∀i: p_cal,i^−≥1−δ_i，则 P(任务失败)≤Σδ_i≤δ_task。
2. **horizon 可达性**：H>⌊δ_task/δ_min⌋ 时不存在满足预算的 commit 序列，必须缩短 horizon 或提高单阶段可证明性。
3. **排练安全性**：commit 仅当 V_twin.valid 且 p_cal^− 过预算，sim-to-real gap 不能静默降低真实安全。
4. **漂移有界性**：RGS 满足 sup d_t≤ε_max ⇒ 任务状态误差 ≤ε_max。
5. **证据可审计性**：任意阶段/叶子 O(log n) 验证；未满足义务的阶段不能被合法关闭。
6. **止损正确性**：SCF 决策与 C_past 无关，因此不会因沉没成本继续不可行任务。

## 6. 本轮最大风险

**一句话**：如果 Gazebo 孪生校准被长程数据漂移带偏（排练 LCB 越来越「准」，真实 sim-to-real gap 却缓慢扩大），LATTICE 会用「经过校准的自信」把系统推向不可逆失败；必须让 S2RP 失配检测、LHEB 不可逆阶段硬预算、RGS 强制接地与 SCF 止损成为四道**互相独立**的否决闸门，任何一道都不能被另外三道「投票通过」。
