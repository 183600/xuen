**校准细节的严格处理**：对已 rectified 的左右图，`x_L = fx_L·X/Z + cx_L`，`x_R = fx_R·(X-B)/Z + cx_R`。当 `fx_L≈fx_R=fx` 时，
`d = x_L - x_R = fx·B/Z + (cx_L - cx_R)`，故
`Z = fx·B / (d - (cx_L - cx_R))`。
若忽略 `cx_L-cx_R≈-18.43px`，在 `Z=0.5m` 处会产生约 **36%** 的系统性深度偏差。工程上更稳的做法是：用标定参数构造 `Q`/rectified `P`，或在回放数据上用已知平面/已知位移拟合 `1/Z = a·d + b`，把主点差与焦距差一起吸收。

## 1. 直觉解释：为什么「深度」是真实世界泛化最便宜的杠杆

**直觉**：一个只看 RGB 的策略，很容易把「桌布是木纹、背景是白墙、杯子是红色」这些**与任务无关的表象**编码进策略；一旦评测换了背景、加了干扰物、换了没见过的杯子，表象分布一变，策略就崩。物理世界真正稳定的量是**三维几何**：物体在哪、多高、表面朝向、和夹爪的相对位姿、有没有碰撞。深度图正是把「长什么样」翻译成「在哪里、什么形状」的接口。双目深度对光照、颜色、背景纹理的变化天然更不敏感（在匹配鲁棒的前提下），因此它把泛化问题从「记住外观」改写成「估计几何」。

**严谨定义**：设一次观测为
`o = (I_L, I_R, I_WL, I_WR, q, x_ee, g, l)`，
其中 `I_L,I_R` 为头部 rectified 双目，`I_W*` 为腕部彩色图，`q` 为关节，`x_ee∈SE(3)` 为末端位姿，`g` 为夹爪开度，`l` 为语言指令。

- **立体深度算子**：`D = f_stereo(I_L, I_R) ∈ R^{H×W}_{≥0}`，由标定得 `Z = fx·B/(d-d0)`，并给出置信度 `C∈[0,1]^{H×W}`。
- **反投影点云**：`P_cam(u,v) = D(u,v)·K^{-1}[u,v,1]^T`，再经相机到基座变换 `T_{base←cam}` 得 `P_base`。
- **几何条件集**：由任务语义与点云构造可行域
  `C = {x ∈ R^3 | 支撑面以上、抓取 standoff、无碰撞、插入轴对齐、…}`。
- **几何一致算子**：`Proj_C(x) = argmin_{y∈C} ||y-x||`。
- **深度接地策略**：`a = π_θ(o, D, P)`，或对任意 RGB 策略 `π_θ^RGB` 做**外层包装**：
  `a = h(π_θ^RGB(o), D, P)`。
- **泛化间隙**：`Gap(π) = E_{e~D_test}[R(π,e)] - E_{e~D_train}[R(π,e)]`。
  若 `h` 主要依赖几何量 `(P, C)` 而对光度干扰 `g(I)`（换背景、换光照、换纹理）不敏感，则 `Gap` 中由外观漂移贡献的部分被压低。

**一个可检验的分解假设**：把策略误差拆成
`ε = ε_semantic + ε_metric`。
上一轮 UIP-01 的 VLM 验证器主要压 `ε_semantic`；本轮深度主要压 `ε_metric`（高度、插入轴、standoff、碰撞）。二者正交，可叠加。

## 2. 瓶颈假设（工作假设，待实验证伪）

- **H1（度量误差主导）**：在 `PlugInEthernet / PlugCharger / SyringeWaterTransfer / PourOutMedicine / PaperCupStacking / StackBowls` 这类任务上，RGB-VLA 的失败更多来自**毫米级三维误差**（高度、轴线、间隙），而非语义认错物体 → 几何校正的边际收益高。
- **H2（背景/干扰物是表象轴）**：背景替换、干扰物插入主要改变 RGB 分布；深度前景分离 + 物体中心化裁剪可显著降低这两条轴的掉分。
- **H3（免费信号被浪费）**：头部双目已标定，但多数队伍只喂单目 RGB；立体匹配的成本远低于 VLA 前向，且可用 chunk 隐藏延迟。
- **H4（深度并非免费午餐）**：透明/反光/无纹理物体（药瓶、注射器、金属工具、玻璃杯）上立体匹配会失败；**必须**有置信度门控 + 单目度量深度回退，否则几何校正会注入系统偏差，反而伤害原本能成的任务。
- **H5（相机-基座外参是隐含假设）**：数据集有 `state_d435` 相机位姿，但测试 obs 没有；只能离线拟合 `T_{base←head}` 并假设桌面任务中云台/腰部不动。若评测中 pivot/waist 变化，外参漂移会成为新的误差源。

## 1. 旗舰点深潜 · UIP-11 DGR（Depth-Grounded Referee）

### 1.1 深度重建：先校准，再谈几何

对已 rectified 的左右图：

```
x_L = fx_L · X/Z + cx_L
x_R = fx_R · (X - B)/Z + cx_R
d   = x_L - x_R = fx · B / Z + (cx_L - cx_R)      (取 fx_L≈fx_R=fx)
Z   = fx · B / (d - (cx_L - cx_R))
```

代入数据集标定：`fx≈282.37px`，`B≈58.25mm`，`cx_L-cx_R≈-18.43px`，故 `fx·B≈1.6449×10^4 mm·px`。

> **工程铁律**：不要用 `Z=fxB/d`。主点差在 `Z=0.5m` 处会造成约 36% 的系统偏差。正确做法是用标定构造 `Q`/rectified `P`，或在回放数据上拟合 `1/Z = a·d + b`，把主点差、焦距差、rectification 残差一起吸收。

**深度误差量级（单像素，忽略 d0 偏置）**：`σ_Z ≈ Z²/(fx·B)·σ_d`。

| 工作距离 Z | 视差 d | 单像素深度当量 | 若 σ_d=0.25px 的单点误差 | 100 像素平面拟合的理想上限 |
|---|---|---|---|---|
| 0.30 m | 54.8 px | 5.5 mm/px | 1.4 mm | ~0.14 mm |
| 0.50 m | 32.9 px | 15.2 mm/px | 3.8 mm | ~0.38 mm |
| 0.80 m | 20.6 px | 38.9 mm/px | 9.7 mm | ~0.97 mm |
| 1.00 m | 16.4 px | 60.8 mm/px | 15.2 mm | ~1.52 mm |

结论：**头部双目适合「粗到中」几何（接近、standoff、碰撞、堆叠高度、倒药角度），不适合单独承担毫米级插孔**。精细插入（网线、充电器、注射器）必须由 UIP-15 的腕部视觉伺服兜底；平面拟合能压低随机误差，但压不掉标定/压缩/匹配的系统偏差。

### 1.2 三件事：校正、验证、护栏

DGR 不替换 VLA，只在 `get_action` 内部做三件事：

1. **几何校正（只在 ee 空间）**：保留 VLA 的旋转与夹爪语义，仅修正 EE 平移 `x̂`：
   `x* = Proj_C(x̂)`，`Δ = clip(λ·(x*-x̂), Δ_max)`，再速率限制/平滑后写回 chunk。
2. **几何里程碑验证**：用点云判断子目标是否达成（杯口是否套上钩、插头尖端到插座平面的轴向距离、碗沿接触高度、瓶口是否在目标上方、毛巾折线是否对齐）。
3. **安全门控**：深度置信度 `λ` 低、目标被遮挡、或校正量超限时，**退回原始 VLA 动作**；宁可不用深度，也不让深度把好动作修坏。

**可行域 C 的构造**（逐任务配置，通用模板）：

```
C = { x |  n_s^T x + c_s ≥ h_standoff         # 支撑面上方安全高度
          dist(x, P_distractor) ≥ r_safe      # 干扰物/桌面碰撞
          (x - p_target)·a_axis ∈ [0, l_max]  # 沿插入/接近轴
          ||(x - p_target) - ((x-p_target)·a)a|| ≤ r_align }  # 横向对齐
```

`Proj_C` 可用顺序投影（alternating projection）近似，或用小 QP 精确解；单次求解应在亚毫秒级。

### 1.3 伪代码

```python
class DepthGroundedReferee:
    def __init__(self, vla, stereo, grounder, calib,
                 k=4, depth_every=4, conf_thr=0.5,
                 max_corr_m=0.02, blend=0.5):
        self.vla, self.stereo, self.grounder = vla, stereo, grounder
        self.calib = calib                    # K, B, d0, T_base_cam, control_space
        self.k, self.depth_every = k, depth_every
        self.conf_thr, self.max_corr_m, self.blend = conf_thr, max_corr_m, blend

    def reset(self):
        self.vla.reset()
        self.t = 0
        self.D = self.C = self.P = None
        self.buf = []
        self.subgoal = 0
        self.retry = 0

    def get_action(self, obs):
        self.t += 1
        if self.D is None or self.t % self.depth_every == 0:
            D, C = self.stereo(luma(obs["cam_left_high"]),
                               luma(obs["cam_right_high"]))
            self.D, self.C = D, C
            self.P = backproject(D, self.calib.K, self.calib.T_base_cam)
        if not self.buf or self._need_replan(obs):
            chunk = self.vla.get_action(obs)          # (T_a, >=6)
            if self.calib.control_space == "ee":
                chunk = self._geometry_refine(chunk, obs)
            self.buf = list(chunk[:self.k])           # 只承诺 k 步
        return self.buf.pop(0)

    def _geometry_refine(self, chunk, obs):
        x_hat = chunk[:, :3]                          # EE xyz in base frame
        g = self._current_subgoal(obs)                # target / receptacle
        pts, conf = self._crop(self.P, self.C, g)     # confident point cloud
        C_feas = build_feasible(pts, g, obs)          # support/standoff/axis/collision
        x_corr = project_to_feasible(x_hat, C_feas)
        lam = self._gate(conf, g, obs)                # 0..1 depth trust
        delta = clip_norm(lam * (x_corr - x_hat), self.max_corr_m)
        chunk[:, :3] = x_hat + rate_limit(smooth(self.blend * delta, self.k))
        return chunk

    def _need_replan(self, obs):
        done, conf = self._geometric_milestone(self.P, self.C, obs)
        if conf < self.conf_thr:
            return len(self.buf) == 0                 # 不可信 → 不重试
        if done:
            self.subgoal += 1; self.retry = 0; return True
        if self._stuck(obs) and self.retry < 2:
            self.retry += 1; return True              # 带护栏的重试
        return len(self.buf) == 0
```

### 1.4 三重护栏 + 延迟工程（直接对应可信度）

| 护栏 | 作用 | 默认值（起点） |
|---|---|---|
| `conf_thr` | 深度/里程碑不可信时禁止校正与重试 | 0.5 |
| `max_corr_m` | 单步最大几何校正量，防止「修飞」 | 20 mm |
| `blend` + `rate_limit` | 平滑校正，避免动作统计异常 | 0.5，jerk 限幅 |
| `k` | 只承诺 k 步，限制盲走 | 4 |
| `max_retry` | 限制重试发散 | 2 |
| `depth_every` | 深度不必每步算 | 4 |

**延迟设计**：立体匹配放独立线程/双缓冲，`get_action` 只读最近一帧；深度未就绪时用旧深度并降低 `λ`，绝不阻塞。SGBM 在 320×240 约 3–8ms（CPU）；学习式立体在 480×640 约 15–30ms（GPU）；grounding 1–2Hz，任务解析按 episode 缓存。目标是**新增 p99 延迟 < 20–30ms**，且不出现单步尖峰。

## 2. UIP-12 · SDC：深度置信与单目回退（DGR 的安全阀）

**问题**：药瓶、注射器、金属工具、玻璃杯是透明/反光/无纹理重灾区，立体匹配会给出错误视差；盲目校正比不校正更糟。

**置信图**（逐像素，乘性/逻辑融合）：

```
C = σ( w_lr·C_lr + w_p·C_photo + w_g·C_grad + w_s·C_speckle + w_u·C_learn )
C_lr     = 1[ |d_L(u,v) - d_R(u-d_L,v)| < τ_lr ]        # 左右一致性
C_photo  = 1[ |I_L(u,v) - I_R(u-d_L,v)| < τ_p ]         # 光度一致
C_grad   = 1[ |∇I_L(u,v)| > τ_g ]                       # 纹理足够
C_speckle= 1[ local_var(d) < τ_s ]                      # 非散斑
C_learn  = 学习式立体/不确定度头输出
```

**单目回退**：用 UniDepth / Metric3D v2 / Depth Anything V2 (metric) 得 `D_mono`，在**高置信立体像素**上用 RANSAC 拟合尺度/偏移 `(s,t)`：`D_stereo ≈ s·D_mono + t`；再融合

```
λ = C_stereo / (C_stereo + C_mono + ε)
D_fused = λ·D_stereo + (1-λ)·(s·D_mono + t)
```

**时序补洞**：用已知 EE 运动把历史点云对齐到当前基座系，仅对**静态背景/桌面**做 EMA 融合；移动物体不融合，避免拖影。

**输出**：`D_fused, C_fused, τ_D`（区域级信任）。`τ_D` 低时 DGR 只做「验证」不做「校正」，并把控制权交回 UIP-15 的腕部视觉伺服。

## 3. 其余点（结构化）

**UIP-13 OCR-3D**｜动机：背景/位置/未见物品靠关系而非坐标。机制：`l → (目标物体, 容器/支撑物, 关系 in/on/under/left-of, 动作 pour/insert/stack/fold/zip)`；GroundingDINO/SAM2 在头部 RGB 上定位，深度反投影成 3D 框/平面/法向，构图 `G=(V,E)`；把关系 token 或图嵌入条件化到策略。差异：用**形状/法向/尺寸**而非类别纹理表示未见物体；用**深度前景掩码 + 物体中心裁剪**替换背景，直接压背景轴。可行性：高。风险：2D grounding 错→3D 全错；用多帧投票与置信度门控。

**UIP-14 GDP**｜动机：未见物体抓取靠几何。机制：目标邻域点云 → 法向/曲率 → 反极抓取评分（parallel-jaw）→ 抓取中心/宽度/接近向量；宽度映射到 Dex1 命令（range 5.5→0，open→close）；加 pre-grasp standoff 与桌面碰撞检查。差异：只精修 VLA 的抓取阶段，不改整条轨迹。可行性：高。风险：Dex1 单通道开度标定误差；用数据集统计校准。

**UIP-15 CVC**｜动机：头部被机械臂遮挡时深度不可用。机制：检测目标区域深度置信骤降 + 腕部视野内出现目标 → 切换腕部局部视觉伺服（RGB 模板/光流/单目深度），头部深度只提供全局搜索区。差异：不是简单多视角拼接，而是**按遮挡状态切换控制源**。可行性：中高（需腕部相机到 EE 的外参；数据集有 ir/color 外参与 EE 位姿可离线标定）。风险：切换不平滑→动作跳变；用混合权重过渡。

**UIP-16 DID**｜动机：人为干扰轴。机制：深度时序中值背景模型 → 前景 `|D- median|>τ`；用运动学/URDF 投影剔除机器人自身；人体/外来物要求持续 N 帧且面积超阈值 → 暂停、退让到安全位、等待稳定、更新 3D 场景图后重规划。差异：用深度而非 RGB，避免背景颜色变化误报。可行性：中高。风险：误停降低效率；用迟滞与恢复超时。

**UIP-17 DSH**｜动机：真机只能预约，迭代慢。机制：为每任务定义 3–6 个**几何里程碑**（见 §1.2），在回放数据上计算步骤分代理；构建 5 轴扰动测试台（位置/背景/干扰物/未见物体/人为干扰）；输出 action 误差、里程碑通过率、碰撞率、延迟分位数。差异：不依赖官方计分点也能先迭代；官方手册开放后替换权重。可行性：高。风险：代理与真机相关性不足；用真机时段校准。

**UIP-18 DDA**｜动机：长期上限在训练侧。机制：用双目伪深度训练深度感知策略，或把「深度特权教师」蒸馏进 RGB 学生；增广注入孔洞、散斑、边缘膨胀、尺度抖动、AV1 压缩伪影、合成透明区域；随机 depth dropout 防止过依赖。差异：把推理期技巧沉淀为模型能力。可行性：中（算力/伪深度噪声）。风险：伪深度标签噪声；用置信掩码与一致性过滤。

## 4. 实验设计 E101–E108（离线代理为主，真机前不称「真机结论」）

| 实验 | 对照 | 指标 | 目标 / 证伪线 |
|---|---|---|---|
| E101 | RGB-VLA vs +DGR（回放，5 轴扰动） | EE 平移误差(mm)、里程碑成功率、步骤分代理 | 平移误差 −20~30%；若 <10% 则 DGR 无价值 |
| E102 | 无门控 vs SDC 门控（透明/反光子集） | 成功率、错误校正率 | 门控必须让透明子集不掉分；若掉 >2% 则回退 |
| E103 | 纯立体 vs 纯单目 vs 融合 | 深度 RMSE（小标注集）、平面一致性 | 融合在无纹理区最好；立体在纹理区最好 |
| E104 | 原始抓取 vs GDP（leave-one-object-out） | 抓取成功率、碰撞率 | 未见物体 +Δ；若 Dex1 开度误差大则先标定 |
| E105 | 无 CVC vs CVC（臂遮挡任务） | 插入/倒药里程碑通过率 | 遮挡场景 +Δ；切换 jerk 不超阈值 |
| E106 | 无 DID vs DID（人手入镜） | 碰撞次数、恢复成功率、误停率 | 碰撞↓且误停 <5% |
| E107 | 无深度 vs 有深度（延迟/动作统计） | p50/p95/p99 延迟、动作 jerk、离群率 | p99 增量 <30ms；无异常尖峰 |
| E108 | RHPV-V(VLM 验证) vs RHPV-V+DGR(几何验证) | 成功率、步骤分代理、验证延迟 | 几何验证更快更准；VLM 只兜底 |

**消融**：`depth_every ∈ {1,2,4,8}`、`max_corr_m ∈ {5,10,20,40}mm`、`conf_thr ∈ {0.3,0.5,0.7}`、`blend ∈ {0.25,0.5,1.0}`、`k ∈ {1,4,8}`。

**证伪优先**：先做 E101/E102/E107。若 E102 显示透明子集被伤害，或 E107 显示 p99 超预算，则 DGR 降级为「只验证不校正」，把资源转到 UIP-13/15。

## 5. 离线深度与回放 Harness（UIP-17 的底座）

1. **数据**：32 个 LeRobot v3.0 数据集；头部双目帧 → 立体匹配得伪深度；无 GT depth，故用三种弱监督校验：① 桌面/墙面平面拟合残差；② 左右重投影光度一致性；③ 小规模人工标注（几十帧）做 RMSE 校准。
2. **标定校验**：用已知基线/焦距与平面场景验证 `1/Z=a·d+b`；检查 AV1 压缩对匹配的影响（luma vs chroma）。
3. **扰动套件（对应 5 轴）**：
   - 位置：图像仿射/裁剪 + 深度重投影，模拟物体/相机平移；
   - 背景：深度前景掩码 + 随机背景合成；
   - 干扰物：深度感知的干扰物合成/粘贴；
   - 未见物体：leave-one-object-out 或纹理替换；
   - 人为干扰：人手/手臂视频或深度前景 blob 叠加。
4. **指标**：EE 平移/旋转误差、几何里程碑通过率、碰撞率、步骤分代理、延迟 p50/p95/p99、动作 jerk/离群率。
5. **门禁**：任何改动必须在扰动套件上同时满足「精度↑、透明子集不降、p99 不超预算」才允许进入真机提测。

## 6. 资源与时间线（粗排）

- 第 1 周：立体匹配 + 标定校验（`1/Z=a·d+b`）+ 回放 harness；复现 RGB 基线。
- 第 2 周：DGR 包装器（ee 空间校正 + 几何里程碑）+ E101/E107。
- 第 3 周：SDC（置信图 + 单目回退 + 透明/反光）+ E102/E103。
- 第 4 周：OCR-3D / GDP / CVC + E104/E105。
- 第 5 周：DID / DSH 扰动套件 + E106；DDA 预研。
- 第 6 周起：预约真机时段，用真实榜单/手册校准代理与计分点。

**算力**：1 张推理卡可同时跑 VLA + 小 VLM + 学习式立体；若显存紧张，立体走 CPU SGBM，grounding 降频。

## 7. 本轮最大风险（承接想法区 §5）

**一句话**：头部双目在 0.5–1m 上每像素约 15–40mm 深度误差、且对透明/反光物体系统性失效；若不做 SDC 门控、不限制单步校正、不用腕部视觉伺服兜底精细插入，DGR 会把可用的 RGB 策略修坏，并因额外深度计算抬高 p99 延迟而触发可信度质疑。
