# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化证据承诺」IP-133~138；灵感循环新一轮第 1 轮；本轮灵感：「成功率」×「MuJoCo」）

> 第 57 轮把先验、证据、人三条腿补齐，却把真正的判据留在了暗处：它只回答"证据够不够"，从未正式定义**成功**是什么、以何种置信度、在哪个条件层上成立。工程界用来判断一次部署能不能上的，恰恰是**成功率**；而它几乎总是在 **MuJoCo** 这类物理仿真器里被廉价地估计、被大规模地优化。问题不是"用不用成功率"，而是"成功率这个标量，凭什么可以为一个不可逆动作签字"。本轮两个灵感各补一刀：**成功率**被从标量升级为**分层、严重度加权、带置信下界且可事后证伪的证书**；**MuJoCo** 被从"可信度含糊的第二个世界"升级为**只用于证伪与排险、绝不用于认证的反事实引擎**，其现实差距由一个见证集共形门实时定价。二者合流还逼出第三个机制：一旦承诺规则显式依赖成功率，优化压力就立刻涌向这个数字（Goodhart），因此必须让"被优化的成功率"与"独立审计的成功率"分账，差额超阈即**冻结度量**。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"成功率可证伪、仿真可校准、度量可审计的承诺"**。

核心矛盾：
- **H29（边缘 vs 条件）**：成功率是边际统计量，安全却是条件 + 尾部的性质。聚合成功率可以很高而当前分层致命（Simpson 悖论：两类区域各自失败率都高，合并后因到访权重错配反而"好看"）；而一旦按条件分层，每层样本骤减，又给"层购物"留了后门。
- **H30（仿真保真 vs 覆盖）**：MuJoCo 便宜、可枚举反事实、能看见真实世界舍不得弄坏的东西；但它的偏差是系统性的。一个没建出来的接触模式，仿真会**自信地判安全**——而这恰好发生在真实探针最贵、最不可逆的地方。仿真能证伪的，只是它能模拟的失效。
- **H31（度量 vs 目标）**：以成功率为承诺触发器的瞬间，成功率就从"描述"变成"目标"；策略会改变它被测量的分布（内生性），并主动寻找规格漏洞。越把成功率写进规则，它越不可信。
- **H32（证据复用 vs 多重比较）**：分层证书 × 仿真 × 真实 × 审计，共享同一笔有限证据。同样的 5 次探针若不复用会计，就能靠多重比较"认证"出任意多个好看的分层。

## 0. 直觉与动机

**灵感 1（成功率 → 从标量到证书）**
直觉：把"成功率 95%"贴到系统上，就像把"平均体温 36.5℃"贴到急诊室墙上——它既不说谁的体温，也不说尾部有多烫。安全需要的不是平均成功率，而是**当前这个分层、这次这个步态、这一级接触下，成功率的下置信界**，外加**失败严重度的条件风险值**。并且这个下界必须是**可证伪的**：每次承诺都记下预测的成功概率与所属分层，事后用真实结局回算校准（Brier/可靠性图）；校准一旦掉出契约，该分层的证书立即失效。关键纪律：**聚合成功率永远不能作为不可逆层的证据**——它只能被展示，不能被签字。

**灵感 2（MuJoCo → 反事实证伪引擎，而非认证引擎）**
直觉：仿真器是一个"可以随便弄坏世界"的沙盘。它最可靠的能力不是告诉你"这样一定行"，而是告诉你"这样会以某种方式坏"——前者要求仿真把真实世界的所有物理都建对，后者只要求它建对了那一条失效路径。于是采用**非对称用法**：(U1) 仿真发现、且真实证据尚未排除的失效模式，拥有**否决权**；(U2) 仿真给出参数敏感性排序，用于把真实探针花在刀刃上；(U3) 仿真预测的"成功"**不得**直接进入不可逆层的成功率下界，只能塑形先验与探测预算。它删候选，不加证据。仿真与现实之间的差距由**见证集**（同时有仿真与真实结局的上下文）实时共形定价为 δ_sim；差距超阈或走出见证覆盖，仿真权重直接归零并隔离——和元模型一样，仿真器也是判定器，也要走隔离区。

**灵感 3（合流 → 度量影子审计）**
直觉：如果承诺规则读成功率，那么"把成功率做高"就成了新的攻击面。防御不是更努力地测成功率，而是**让测量分账**：一条是面向优化的策略 rollout 成功率，一条是策略无法控制的、预注册准随机分层审计流的成功率，再用 doubly-robust 估计出部署分布上的成功率。三者差额的上置信界超过阈值，系统不是"更谨慎地承诺"，而是**度量冻结**：停止一切由成功率驱动的承诺与优化，升级给人并重写成功定义。度量被污染时，最安全的动作是不再相信度量。

**灵感 4（三机制合流 → 成功率感知的探-诺-演）**
直觉：每检查点先定分层、建证书；用仿真先删危险候选、排序探针；真实探针只补证书缺的那一格；承诺需同时过 {成功率证书 ∧ 证据门 ∧ 影子审计} 三关。仿真能否决、能指路，但永远不能单独放行。若仿真被隔离，系统退化为"真实-only"证书——更慢、更宽，但仍可承诺。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（成功率证书 SRC）** 结果空间 O={succ}∪{(deg,κ)}∪{(fail,κ_f)}，κ∈[0,κ_max] 为归一化伤害。分层变量 c=(r,g,level,season)，预注册分层族 𝒞_pre。对每层维护真实样本 (n_c,k_c)，给出成功率下置信界
p_L(c)=BetaInv(α_s; k_c, n_c−k_c+1)（Clopper–Pearson，有限样本精确覆盖），
以及在 n_c 不足时按层次部分池化（以第 57 轮元先验 q_φ 为父分布、收缩强度 λ(n_c)）的 n_eff(c)。证书
SRC(c)=(c,n_c,n_eff(c),k_c,p_L(c),CVaR_β(κ|c),cal_state,provenance)。
承诺判据：c∈𝒞_pre ∧ cal_state=OK ∧ p_L(c)≥p_min(level) ∧ CVaR_β(κ|c)≤κ_max(level)。**聚合成功率被规则性排除**：它不得作为任何不可逆层（L2）判据，只可作展示与溯源。

**定义 140（MuJoCo 反事实引擎 MJC）** 参数集合 Θ_sim（摩擦/刚度/质量/时延/传感噪声），仿真器 S:(θ,π,x0)→轨迹。三产物：失效模式集 F_sim(c)={φ | ∃θ∈Θ_sim，rollout 以模式 φ 失败}；敏感性排序 Sens(c)=∂p̂_sim/∂θ；反事实结果分布 p̂_sim(o|c)。**非对称使用规则**：(U1) 证伪优先——若 F_sim(c) 含真实证据未排除的失效模式，则否决承诺；(U2) 分配——按 Sens 排序真实探针的信息增益；(U3) 禁止认证——p̂_sim 不得直接进入 L2 的 p_L，只可塑形 L0/L1 先验与探针预算。一句话：仿真只做"删候选"，不做"加证据"。

**定义 141（仿真-现实差距门 SRG）** 见证集 W={(z_i,o_i^sim,o_i^real)}，残差 e_i=discrep(o_i^sim,o_i^real)（成功率差 / 严重度差 / 失效模式是否漏报）。分层加权共形上界 δ_sim(z)=Quantile_{1−α_g}({e_i: sim(z,z_i)})，见证覆盖 cov(z)=1[有效邻居数≥m_min]。影响权重
w_sim(z)=clip((τ_sim−δ_sim(z))/(τ_sim−δ_0),0,1)·cov(z)。
δ_sim>τ_sim 或 cov=0 ⇒ w_sim=0（仿真隔离）。若某真实失败发生在 w_sim>0 且仿真判安全的上下文，则全局乘性降低 w_sim 并重估 δ_sim（仿真漏报的事后证伪回溯）。仿真模型本身作为判定器，须走第 57 轮隔离区（影子模式 + 校准回归）后才可影响承诺。

**定义 142（度量影子审计 MSA）** 三个成功率：SR_opt（策略 rollout、行为分布、面向优化）；SR_audit（策略不可控的预注册准随机分层审计流 + 红队上下文）；SR_dep（用 doubly-robust/IPS 估计的部署分布成功率）。影子差 G=max(|SR_opt−SR_audit|, |SR_opt−SR_dep|)，取 bootstrap 上置信界 G_hi。承诺前置 G_hi≤θ_G；否则进入**度量冻结**：暂停一切成功率驱动的承诺与优化，升级人工并重新定义成功规格。审计流的调度由固定准随机序列生成，策略无法控制其采样。

**定义 143（成功率溯源与证据会计 SRP）** 分层必须先验预注册；层次部分池化，收缩强度 λ(n_c) 随样本量自适应；同一真实探针跨预注册分层复用时施 union bound，α_family=α_s/|𝒞_pre|，并披露有效样本 n_eff(c) 与借用先验权重。只允许在"n_eff 足够的最粗分层"上承诺（层次回退），事后新增分层不得追溯认证——**禁止层购物**。

**定义 144（PCE++ 成功率感知探-诺-演，升级 IP-138）** 每检查点：①定层 c，建 SRC（元层次先验；若 w_sim>0 再用仿真塑形 L0/L1 先验）；②仿真反事实——若否决则绕行/降档，否则按其敏感性排序真实探针；③执行真实探针并更新跨模态分账（继承 XMC）；④承诺 ⇔ SRC 过 ∧ FSE+ 证据门过 ∧ MSA 过；⑤否则绕行→降档→L2 协商（τ_int(auth)）或安全停。仿真隔离时退化为真实-only 证书。物理探针 ≤k_p+k_cons，仿真 rollout ≤N_sim（只耗算力预算），每检查点四态完备。

## 2. 关键算法伪代码（完整版见产物区）

```python
def build_src(c, obs, meta, srp):
    n, k = count(obs[c]), successes(obs[c])
    pL = clopper_pearson_lcb(k, n, alpha_s) if n >= n_min \
         else hier_lcb(k, n, meta.hier_prior(c), srp.shrink(n))
    return SRC(c, n, srp.n_eff(n), pL, cvar(severity(obs[c]), beta),
               meta.cal_state, srp.provenance(c))

def sim_use(mjc, real_ev, srg, c):
    if srg.weight(c) <= 0:                       # 仿真隔离
        return {'veto': False, 'rank': None}
    return {'veto': bool(mjc.fail_modes - real_ev.excluded),  # U1 只否决
            'rank': rank_by_sensitivity(mjc.sensitivity)}      # U2 只分配

def metric_shadow_audit(opt_log, audit_log, theta_G):        # U3 度量分账
    G = max(gap(ratio(opt_log), ratio(audit_log)),
            gap(ratio(opt_log), doubly_robust(opt_log, audit_log)))
    return 'metric_freeze' if bootstrap_upper(G) > theta_G else 'ok'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SRC | O(n_c)/层 | O(\|𝒞_pre\|) | 有限样本覆盖、聚合率禁用、可证伪校准 |
| MJC | O(N_sim·T·\|θ\|)（算力） | O(\|Θ_sim\|) | 失效模式枚举完整度、只否决不认证 |
| SRG | O(\|W\|) | O(\|W\|) | 见证覆盖诚实、δ_sim 上界、失败回溯降权 |
| MSA | O(\|audit\|) | O(\|audit\|) | 审计流独立、DR 估计无偏、冻结而非放行 |
| SRP | O(\|𝒞_pre\|) | O(\|𝒞_pre\|) | 预注册、union bound、层回退 |
| PCE++ | O(\|CP\|·(k_p+k_c)·(N_sim·T+C_VOI)) | O(\|V\|+\|σ\|) | 物理探针有界、度量冻结可终止 |

**正确性定理（SCS：Stratified Certified Success）** 在 A33–A40 上加 (A41) 分层证书覆盖：每预注册层 p_L 覆盖真实成功率 ≥1−α_s，借用元先验仅在 A37 成立且披露 n_eff；(A42) 仿真非对称使用：仿真只经否决/塑形/分配通道进入，w_sim 由 SRG 诚实给出且 δ_sim 上界有效；(A43) 度量影子审计：SR_audit 独立于优化、G_hi 诚实、部署分布用 DR 估计；(A44) 证据会计：分层预注册、union bound、层次回退。则：
(i) **条件成功率健全性**：∀c∈𝒞_pre，P(p_s(c)≥p_L(c))≥1−α_s；L2 使用聚合率的概率为 0（规则拒绝）。
(ii) **证伪健全性（不对称）**：SRG 通过且仿真发现未排除失效模式 φ 时，真实失效风险以 ≥1−α_g 的覆盖成立，或仿真被隔离；仿真预测"成功"对认证概率的增益为 0。
(iii) **度量健全性**：若 G_hi>θ_G 而系统仍承诺，则 SR_opt 高估部署成功率超过 θ_G，或审计流被污染；MSA 将其转为度量冻结而非静默通过。
(iv) **部署界**：P_safe ≥ 1 − Σ_cp[δ_f+ε_meta+δ_probe+ε_h+δ_ood·α_conf+δ_xm·1[L1]+α_s·|𝒞_pre|] − P(仿真盲区) − P(审计流污染) − P(τ 超时 ∧ 安全停失效)。新增的 α_s·|𝒞_pre| 是多重比较的明码价格；P(仿真盲区) 是"无法被见证/无法被模拟的失效模式"。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"证据质量"移到"成功率的下界"，但下界只在**预注册分层**与**见证集覆盖的物理**里成立；真正的风险从"坏先验普遍"变成"**不可见证的失败模式**"——MuJoCo 只能证伪它能模拟的失效，影子审计只能发现它采样到的作弊，二者共同的盲区恰好落在最昂贵的不可逆接触上。

# 第 58 轮产物 · 创新点清单 v34：SuccessRate-MuJoCo（成功率证书×仿真反事实证伪×度量影子审计，SRC×MJC×SRG×MSA×SRP×PCE++）

> 承接第 57 轮 IP-133~138（MFSL/XMC/PTM/MXI/FSE/PCE+）、第 56 轮 IP-127~132 与第 55 轮 IP-121~126。本轮把部署前提从"少样本可校准、跨模态可对账、个性化有界的证据承诺"升级为 **"成功率可证伪、仿真可校准、度量可审计的承诺"**：成功率从标量变为分层置信证书，MuJoCo 从"含糊的第二世界"变为只做证伪与排险的反事实引擎，度量本身被分账审计以对抗 Goodhart；第 57 轮"一切判定器（含元模型）走隔离"推广为"**一切判定器（含仿真器与度量）走隔离**"。

### IP-139 SRC（分层成功率证书，可证伪）

```python
def build_src(c, real_obs, meta, srp):
    if c not in srp.PRE_REGISTERED:                  # 反层购物
        return None
    n, k = count(real_obs[c]), successes(real_obs[c])
    if n >= n_min:
        pL = clopper_pearson_lcb(k, n, alpha_s)      # 有限样本精确覆盖
    else:
        prior = meta.hier_prior(c) if meta.cal_ok else None
        pL = hier_lcb(k, n, prior, lam=srp.shrink(n))# 层次部分池化
    cvar = empirical_cvar(severity(real_obs[c]), beta)
    return SRC(c=c, n=n, n_eff=srp.n_eff(n, prior), k=k,
               pL=pL, cvar=cvar, cal=meta.cal_state,
               prov=srp.provenance(c))

def src_admissible(src, level):
    if src is None:                     return False, 'unregistered_stratum'
    if src.cal != 'OK':                 return False, 'uncalibrated'
    if src.pL < P_MIN[level]:           return False, 'success_lcb'
    if src.cvar > KAPPA_MAX[level]:     return False, 'severity_cvar'
    return True, 'ok'

def src_commit_rule(src, level):
    # 聚合成功率被规则性排除：L2 永不读 aggregate_success_rate
    assert level != 'L2' or src.stratum is not None
    return src_admissible(src, level)
```

### IP-140 MJC（MuJoCo 反事实引擎，只否决不认证）

```python
def mujoco_counterfactual(c, policy, sim, N_sim):
    fail_modes, sens = set(), defaultdict(float)
    for theta in sim.ensemble(c, n=N_sim):            # 域随机化/参数后验
        traj = sim.rollout(theta, policy, c.x0)
        if not satisfies(traj, c.spec):
            fail_modes.add(classify_failure(traj))    # 枚举"会怎么坏"
        for p in sim.params:
            sens[p] += sensitivity(traj, p)           # 哪一参数主导风险
    return MCJ(fail_modes=fail_modes, sensitivity=normalize(sens),
               phat=sim.outcome_dist(c))              # phat 仅供内部

def sim_use(mjc, real_ev, srg, c):
    if srg.weight(c) <= 0:                            # 隔离：退回真实-only
        return {'veto': False, 'rank': None, 'phat': None}
    unexcluded = mjc.fail_modes - real_ev.excluded_modes
    return {
        'veto': bool(unexcluded),                     # U1 证伪拥有否决权
        'rank': rank_by_sensitivity(mjc.sensitivity), # U2 只指导探针分配
        'phat': None,                                 # U3 禁止认证，绝不上行
    }
```

### IP-141 SRG（仿真-现实差距门，见证集共形定价）

```python
def sim_real_gap_gate(W, c, tau_sim, delta0):
    if not W.covers(c):                               # 无见证 ⇒ 不采信
        return 0.0
    e = [discrep(sim_out, real_out) for (z, sim_out, real_out) in W]
    delta = weighted_quantile(e, w=W.sim(c), q=1 - alpha_g)
    return clip((tau_sim - delta) / (tau_sim - delta0), 0.0, 1.0)

def on_real_failure(c, sim_said_safe):
    if sim_said_safe and W.weight(c) > 0:             # 仿真漏报 → 全局降权
        W.global_down(gamma_sim)
        W.reestimate_gap()                            # 重估 δ_sim
        audit.flag(('sim_miss', c))
```

### IP-142 MSA（度量影子审计，反 Goodhart）

```python
def metric_shadow_audit(opt_log, audit_log, theta_G):
    sr_opt   = ratio(opt_log)                         # 面向优化（行为分布）
    sr_audit = ratio(audit_log)                       # 独立准随机审计流
    sr_dep   = doubly_robust(opt_log, audit_log)      # 部署分布估计
    G = max(abs(sr_opt - sr_audit), abs(sr_opt - sr_dep))
    if bootstrap_upper(G) > theta_G:
        return 'metric_freeze'                        # 冻结而非放行
    return 'ok'

def audit_stream_schedule():                          # 预注册、策略不可控
    return quasirandom_stratified(seed=PRE_REG_SEED)
```

### IP-143 SRP（成功率溯源与证据会计）

```python
def evidence_accounting(strata, probes):
    if not pre_registered(strata):
        return 'reject', 'unregistered'
    alpha_family = alpha_s / max(1, len(strata))      # union bound
    n_eff = {c: effective_n(probes, c, borrow=True) for c in strata}
    if any(n_eff[c] < n_min and not has_parent(c) for c in strata):
        return 'reject', 'underpowered_stratum'
    return 'ok', alpha_family, n_eff

def hierarchical_fallback(c):                         # 只向更粗层回落
    while n_eff[c] < n_min and parent(c) is not None:
        c = parent(c)
    return c
```

```python
def success_evidence_gate(cp, M, persona, ood_reg, W):
    src = build_src(stratum(cp, M), M.obs, meta, srp)
```

### IP-144 PCE++（成功率感知探-诺-演）

```python
def probe_commit_evolve_pp(x0, M, task, budget, sim, W, audit):
    route = plan_on_map(M, task)
    sched, log = [], []
    for cp in route.checkpoints:
        c = stratum(cp, M)
        src = build_src(c, M.obs, meta, srp)
        mjc = mujoco_counterfactual(c, nominal_policy(c), sim, N_sim)
        use = sim_use(mjc, M.evidence(c), W, c)
        if use['veto']:                               # 仿真只否决
            route = reroute_or_degrade(cp, M, risk_model)
            continue
        while budget.probes_left > 0 and not src_admissible(src, cp.level)[0]:
            p = pick_probe(use['rank'], M) if use['rank'] else voi_meta(c, M)
            M, _, _ = xmodal_fuse(M, c, execute_probe(p, cap=F_abs))
            src = build_src(c, M.obs, meta, srp)
            if D(M.b[c]) > theta_D and 'consensus' not in cp.done:
                M, _, _ = xmodal_fuse(M, c,
                           execute_probe(most_disagreeing_probe(M, c), cap=F_abs))
                cp.done.add('consensus')
            mjc = mujoco_counterfactual(c, nominal_policy(c), sim, N_sim)
            use = sim_use(mjc, M.evidence(c), W, c)
            if use['veto']:
                break
        if not metric_shadow_audit(opt_log, audit.log, theta_G) == 'ok':
            return escalate_freeze(cp, 'metric_gaming')   # 度量冻结：停止优化式承诺
        st = success_evidence_gate(cp, M, personas, ood_reg, W)
        if src_admissible(src, cp.level)[0] and st[0] == 'ok':
            sched.append(commit(select_gait(R), sigma_of(cp)))
            continue
        alt = reroute(M, cp, risk_model)
        if alt: route = alt; continue
        return negotiate_or_stop(cp, M, sigma_of(cp), R_of(cp), consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SRC | O(n_c)/层 | O(\|𝒞_pre\|) | 有限样本覆盖、聚合率禁用、可证伪（A41） |
| MJC | O(N_sim·T·\|θ\|)（算力） | O(\|Θ_sim\|) | 失效模式枚举、只否决不认证（A42） |
| SRG | O(\|W\|) | O(\|W\|) | 见证覆盖诚实、δ_sim 上界、漏报回溯（A42） |
| MSA | O(\|audit\|) | O(\|audit\|) | 审计独立、DR 无偏、冻结而非放行（A43） |
| SRP | O(\|𝒞_pre\|) | O(\|𝒞_pre\|) | 预注册、union bound、层回退（A44） |
| PCE++ | O(\|CP\|·(k_p+k_c)·(N_sim·T+C_VOI)) | O(\|V\|+\|σ\|) | 物理探针有界、度量冻结可终止 |

**正确性定理（SCS：Stratified Certified Success）**
假设 A22–A40 成立；**(A41)** 分层证书：∀c∈𝒞_pre，p_L(c) 以 ≥1−α_s 覆盖真实成功率，元先验借用仅在 A37 成立时进行且披露 n_eff；**(A42)** 仿真非对称使用：仿真只经否决/塑形/分配通道进入，w_sim 由 SRG 诚实给出且 δ_sim 为有效上界；**(A43)** 度量影子审计：SR_audit 独立于优化、G_hi 诚实、SR_dep 用 DR 估计；**(A44)** 证据会计：分层预注册、union bound、层次回退。则：

1. **条件成功率健全性**：∀c∈𝒞_pre，P(p_s(c)≥p_L(c))≥1−α_s；任何 L2 承诺使用聚合成功率的概率为 0。
2. **证伪健全性（不对称）**：若 SRG 通过且仿真发现真实证据未排除的失效模式，则真实失效风险以 ≥1−α_g 覆盖存在，或仿真被隔离；仿真预测"成功"对认证概率的增益恒为 0——这是把仿真放在"证伪位"而非"认证位"的形式化收益。
3. **度量健全性**：若 G_hi>θ_G 而系统仍在承诺，则 SR_opt 对部署成功率的高估超过 θ_G，或审计流被污染；MSA 使系统进入度量冻结而非静默通过。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                  + δ_xm·1[L1] + α_s·|𝒞_pre|)
             − P(仿真盲区: 不可见证且不可模拟的失效)
             − P(审计流污染)
             − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**成功率给判据、共形给覆盖、仿真给证伪、审计给度量可信**。四者都在"更保守"或"更可证伪"的通道里起作用：仿真只能删候选、审计只能冻结、证书只能拒绝、差距门只能把 w_sim 拉向 0——没有一条升险路径。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"证据质量"移到"成功率的下界"，但下界只在**预注册分层**与**见证集覆盖的物理**里成立；真正的风险从"坏先验普遍"变为"**不可见证的失败模式**"——MuJoCo 只能证伪它能模拟的失效，影子审计只能发现它采样到的作弊，二者共同的盲区恰好落在最昂贵的不可逆接触上；必须用"仿真只否决不认证 + 见证集覆盖审计 + 真实失败全局回溯 + 度量冻结"四重护栏，宁可退回又慢又宽的真实-only 证书，绝不把"仿真里没坏"当作"现实里会好"。
