# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「状态机」×「分层规划」）

> R69 把不确定性一分为二：aleatoric 走 R68 铁律，epistemic 交给「流匹配多模态策略 + 主动多模态交互」去问、去看、去触。它把「该不该问」算成了一个漂亮的 VoI，却留下两个从未被形式化的前提：
>
> 1. **模态是每轮重新聚类出来的浮动标签**。R69 的模态来自 K 条采样轨迹的聚类，标签集随数据而变；ECE、证据纪律、审计都建立在一个会漂移的标签集上。这既是它自陈的「幻影模态」风险的根源，也意味着「承诺」没有对象——系统每一轮都可以重新打开上一轮已经决定的事。
> 2. **VoI 是瞬时、单步、无期限的**。它问「现在问这一句值不值」，却不问「来不来得及在不可逆之前得到答案」，也不问「这个答案会不会改变整条计划，而不仅是当前动作」。交互本身是有延迟、有持续时间的选项，不是瞬时信息位。
>
> 本轮两个灵感正好补上这两块缺失：
> - **状态机**把「承诺、协议、守卫、不变式」变成显式、可验证、可审计的离散结构：什么时候允许问、问到什么程度算数、什么时候必须冻结、承诺之后如何安全地反悔，全部写成状态与转移。
> - **分层规划**把「歧义」放回它诞生的抽象层：粗层（走哪条路、做哪个任务）的歧义与细层（具体轨迹怎么走）的歧义不是同一个问题；选项（option）带有前置/不变/后置契约与时长，使「非短视 VoI」与「组合式安全证书」成为可能。
>
> 核心命题：**歧义有层级，决策有承诺边界。要在歧义所属的抽象层、且在承诺边界之前解决它；一旦承诺，epistemic 问题就退化为在固定选项内的 tracking 问题，只能经可验证的中止转移重开。** 用「可验证层次状态机 + 带契约选项 + 期限感知的层次 VoI + 证据协议状态机 + 分层屏蔽 + 假设-保证证书」实现。命名 **STRATA-RAS**（State-machine, Temporal Abstraction, Risk-Aware System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这个歧义属于哪一层、我还来不来得及问、承诺之后还能不能反悔**」。

## 0. 直觉与动机

**灵感 1（状态机 → 模态从「聚类标签」变成「持久状态」）**
直觉：R69 每一轮都对采样轨迹重新聚类，得到一组当轮才存在的模态标签。这带来两个后果：一是校准对象不稳定（这一轮的 m_1 和下一轮的 m_1 可能不是同一个东西），二是系统没有「已经决定过」的概念，因而可以无限次重开同一个问题。状态机把模态变成**跨时间持久的状态**：它有身份、有历史、有进入条件、有必须维持的不变式、有退出条件。由此，校准可以固定在有限标签集上，证据可以挂在状态上，承诺可以写成「在某状态下、某守卫成立后，不再重新打开」。一句话：**状态不是这一帧的聚类结果，而是系统对自己当前所处制度（regime）的承诺**。

**灵感 2（分层规划 → 歧义有出生地，粗层先于细层）**
直觉：同一时刻的歧义常常不在同一抽象层。穿过房间时，「走哪扇门」是粗层歧义，「左脚落在哪块砖上」是细层歧义；如果粗层还没定，花一次交互去问细层是浪费——因为粗层一旦改变，细层问题会被整枝剪掉。分层规划把策略组织成「任务自动机 → 选项（option）→ 原始动作」的多层结构：每一层只处理本层的离散选择，层内连续轨迹交给 R69 的流匹配策略。于是 U_epi 不再是对一个无结构轨迹簇分布的熵，而是**对有限符号模态的信念**；粗层消歧可以先剪掉整棵不可达的子树，再决定是否值得为细层付一次交互。这正是 R69 扁平 MINT 看不见的「分辨率经济学」：**先问便宜且能剪枝的粗问题，再问昂贵且只影响局部的细问题**。

**灵感 3（承诺边界 → 状态机给 VoI 加上截止时间）**
直觉：很多决策是不可逆或高成本的——并道、抓取、开口说话、越过门槛。它们存在一个**承诺边界** t_c：过了这一刻，改主意要么不安全，要么代价超过收益。R69 的 VoI 只减去交互成本，却没有减去「来不及」：一个高信息量的问题，如果答案在 t_c 之后才到，它对当前决策的价值恰好为零，成本却照付。状态机把 t_c 写成守卫，把「交互延迟 + 安全余量 ≤ 剩余承诺时间」写成可执行的可行性条件。一句话：**不是所有信息都值得等；来不及的信息等于噪声，追问它只是把不确定性换成账单**。

**灵感 4（证据纪律 = 协议状态机 → 投毒变成非法转移）**
直觉：R69 的「k 个正交证据源一致才可定案」只是散文式的规则，既不可执行也不可审计。把它写成协议状态机后：每个证据源属于一个机械/信息独立组；同一组的第二次回答不能推进状态；确认态只能由两个不同组的一致证据进入；超时一律落到 UNRESOLVED。于是「单源重复计数」「共谋欺骗」「无限确认循环」都变成**非法转移或超时转移**，可以被拦截、被记录、被审计。协议状态机把安全纪律从「应该」变成「不可能违反」。

**灵感 5（组合式安全 → 契约、分层屏蔽与假设-保证）**
直觉：R69 只在低层对动作前缀做 C-RAS-WM 认证，但很多危险根本不来自某个动作越界，而来自**高层选错了时机或选项**：在横穿马路中途开始一段注视问询、在抓取闭合前启动一个长延迟交互。分层规划让每个选项携带契约（前置条件、必须维持的不变式、后置条件、时长与成本上界）；高层屏蔽只允许满足契约且不破坏状态机不变式的转移。安全证书因此从「一个大黑箱」变成「一组可组合、可局部替换的契约」：只要每段契约在各自假设下成立，组合起来就满足顶层规范；没有契约的选项直接不可选。**安全不是一张总证书，而是一族可组合的局部承诺。**

**灵感 6（双刃剑 → 抽象失配是新的最大风险）**
直觉：层次化最大的收益——用少量离散状态概括复杂连续世界——也正是它最大的危险：**如果状态机漏掉了一个关键状态或守卫，证书不是在保护系统，而是在保护一个错误的模型**。这比没有证书更危险，因为它把「未建模的危险」伪装成「已验证的安全」。因此本轮必须同时交付：开放集「未知模态」类、抽象覆盖审计（ACA）、守卫残差监测、契约覆盖率、抽象模糊测试，以及在覆盖率不足时**退回扁平 R69** 的降级开关。否则 R70 只是把 R69 的「问错」升级为「按错误的图纸验收」。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（STRATA-RAS 总览）** STRATA-RAS = (HSM, OCL, OPL, HVO, CBA, PSM, SPC, TAC, SLM, FMA-H, ARM, ACA, RAS-WM‡)，并继承 R69 的 FMP/AUD/CIA/FMA。四条不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i）；
(ii) **层次承诺不变式**：低层执行只允许发生在某个已承诺选项的契约内；任何不可逆/高成本转移必须先通过可验证守卫；
(iii) **期限可靠性**：任何信息动作必须满足「估计延迟 + 安全余量 ≤ 剩余承诺时间」（定义 315），否则不得执行，且 U_epi 视为未消解；
(iv) **组合证书**：全局安全 = 各选项局部契约之合取 ∧ 状态机屏蔽的模型检验结果；缺少契约或抽象覆盖不足 ⇒ 该选项不可选或整体降级。

**定义 311（层次状态机 HSM）** HSM = (S, s_0, V, δ, Inv, G, AP, L)。S = S_comp ⊎ S_prim 为复合/原始状态；V 为有界变量集；δ ⊆ S × G × S 为带守卫转移；Inv: S → Pred(V) 为状态不变式；AP 为原子命题，L: S → 2^AP。复合状态含子状态与正交区域（并发）。运行时要求：在屏蔽后每个状态至多一条转移被使能（确定性），否则按优先级裁决；任何执行轨迹必须满足 □(⋀_{s∈S} (in_s ⇒ Inv(s)))。

**定义 312（带契约选项 OCL）** 选项 o = (I_o, β_o, π_o, T_o, C_o)：I_o ⊆ S × Δ(M) 为进入集，β_o: S × V → {0,1} 为终止条件，π_o(·|o, z) 为以选项标签为条件的 R69 流策略（共享 trunk，仅条件头不同），T_o 为最大时长，C_o 为契约（定义 319）。选项是**时间扩展动作**：它的执行占用一段区间，期间可能改变信念、消耗预算、并必须维持本层不变式。

**定义 313（层次规划 OPL）** 在选项集 O 上定义半马尔可夫决策过程 (S × Δ(M), O ∪ 𝒜_info, P, R, γ_eff)。抽象状态 (s, b)，b 为符号模态信念；一次选项转移的时长为 T_o，回报按 γ_eff^{T_o} 折扣。计划 π_hi: (s,b) → o 或信息动作，允许** contingent plan**（按证据结果分支的树）。规划分三层：任务自动机选子目标 → 选项序列/树 → R69 原始动作块。值函数满足
V*(s,b) = max_{o∈O(s)} [ −c(o) + E_{s',b'}[γ_eff^{T_o} V*(s',b')] ]，
信息动作作为零时长或短时长选项进入同一 Bellman 备份。

**定义 314（符号模态与分层分解 SLM）** 有限标签集 M = ⊔_{ℓ=0}^{L} M^ℓ，附带细化映射 ρ_ℓ: M^{ℓ+1} → M^ℓ（粗标签）。信念 b ∈ Δ(M)。第 ℓ 层歧义 H_ℓ = H(b^ℓ)，其中 b^ℓ 为 b 在 M^ℓ 上的边缘。定义
U_ale = Σ_{m∈M} b(m) · E_{ξ∼π_o(m)}[tr Σ_{ξ|m}]（选项内、不可约），
U_epi = H(b)（符号模态间、可约）。
与 R69 的关键差别：模态是 HSM 的持久状态/选项标签，不是每轮轨迹聚类的产物；M 有限且闭合，另设开放集残类 m_∅（定义 321）承接「不在 M 中」的观测。

**定义 315（承诺边界 CBA）** 对每个可能改变选项的决策定义承诺时刻
t_c = max{ t : 从当前选项切换到任一可行选项的成本 ≤ c_c 且切换后仍满足低层安全包络 }。
剩余承诺时间 TTC(t) = t_c − t。交互动作 g 的可行性要求
L(g) + δ_safe ≤ TTC(t)，
其中 L(g) 为估计延迟（含感知、通信、人类响应），δ_safe 为安全余量。承诺守卫 commit 在 TTC ≤ δ_safe 时强制冻结当前选项。冻结后只允许经定义 323 的中止转移重开。

**定义 316（层次 VoI，HVO）** 用抽象层的计划值替代 R69 的单步后验熵：
VoI_hi(g) = V*(s,b) − E_{y∼p(·|g,s,b)}[V*(s^g, b^y)] − c(g)，
s.t. L(g) + δ_safe ≤ TTC(t) 且 g 过 SPC。若不可行或 VoI_hi ≤ 0，则不交互。R69 的 MINT 是本定义在 «层次深度 0、L=0、TTC=∞、计划视界 1» 时的退化：此时 V* 只依赖当前模态，VoI_hi 退化为熵差 − 成本。

**定义 317（证据协议状态机 PSM）** Q_p = {IDLE, PROVISIONAL, CONFIRMING, CONFIRMED, UNRESOLVED, POISONED}。转移标签为 (source, answer, t)。守卫：
- 同一 source 组在同一决策问题上的重复回答**不得**推进状态（禁止单源重复计数）；
- PROVISIONAL + 来自另一正交组的独立一致证据 ⇒ CONFIRMED；
- 任何超时 t − t_0 > TAU_PROTO ⇒ UNRESOLVED；
- 出现与已知源相关的共谋模式（同组多票、答案与身份异常耦合）⇒ POISONED。
只有 CONFIRMED 允许高置信度地改变符号模态；PROVISIONAL/UNRESOLVED/POISONED 一律走保守退避。PSM 的完整轨迹哈希进入证书。

**定义 318（分层屏蔽 SPC）** 高层屏蔽 H_shield(s, a↑, b) = 1 iff 转移守卫使能、Inv 保持、目标选项存在有效契约、预算与 TTC 满足。低层屏蔽沿用 R69 的 C-RAS-WM 前缀认证。最终允许动作 = H_shield ∧ C_RAS_WM；在满足安全的前提下取**最大允许集**（least restrictive shield），避免不必要的过度保守。

**定义 319（假设-保证契约 TAC）** 选项契约 C_o = (A_o, Pre_o, Inv_o, Post_o, B_o)：环境假设 A_o、前置条件 Pre_o、执行期间不变式 Inv_o、后置条件 Post_o、时长/成本上界 B_o。C_o 有效当且仅当
A_o ∧ Pre_o ⇒ □Inv_o ∧ ◇_{≤T_o} Post_o，且 cost ≤ B_o。
组合规则：顺序组合中，前一项的 Post 与顶层环境共同承担后一项的 A；缺少 A_o 的放电证据或契约缺失 ⇒ o 不可选。全局证书由对组合契约的模型检验/可达性分析产生。

**定义 320（守卫残差与层次异常 FMA-H）** 离散侧定义守卫残差
r_g = |margin_pred(guard | s, o) − margin_obs(guard | s, o)|，
以及非法转移事件（HSM 不接受但观测上发生的模式跳变）。与 R69 的连续流似然 a_score 组成二维异常通道：(a_score↑, r_g≈0) 偏传感器/世界偏移；(a_score≈0, r_g↑) 偏模式误分类或状态机守卫模型错误；(两者同时↑) 偏结构变化或抽象失配，触发 ACA。

**定义 321（符号校准门 SCG 与开放集残类）** 对有限标签 M ∪ {m_∅} 维护逐类校准：ECE_k、混淆矩阵与选择性风险。开放集残类 m_∅ 表示「当前观测不属于任何已建模模态」。门控规则：若选择性风险 > ε_sel，禁止用高置信模态做承诺，退回保守；若 b(m_∅) > τ_∅，触发抽象缺口告警（交给 ACA）。SCG 取代 R69 的 MCG：后者在数据依赖的聚类标签上估 ECE，样本复杂度不可控；前者在有限闭集上估，且用 m_∅ 把「幻影」转成「拒识 + 告警」。

**定义 322（分层退避与承诺冻结）** 三种情形：
(a) 承诺前在正确层级消解成功：λ = λ_floor(U_ale)（resolution bonus，安全侧不弱于 R68）；
(b) 到达 t_c 仍未消解：冻结到**最坏情况风险最小**的可行选项，λ = λ_floor(U_ale + U_epi)，转入固定选项内的保守 tracking（不再反复重开）；
(c) 契约缺失、m_∅ 告警或抽象覆盖不足：进入最小风险状态/停，禁止学习写操作与外部交互。
⇒ R69 是 STRATA 在 «单层、无承诺边界、无协议状态、无开放集告警» 时的边界情形。

**定义 323（中止与复活语义 ARM）** 对每个已承诺选项预计算中止集 Abort(o) = {(g_abort, fallback)}，要求 fallback 契约有效、切换成本 ≤ c_abort、且切换过程满足低层包络。引入最小驻留时间 τ_d 与滞回阈值 h：两次模式切换间隔 ≥ τ_d，且信念变化超过 h 才允许重开。没有可用中止转移时，不得以「重新规划」为名绕过承诺；只能进入最小风险状态。

**定义 324（层次证书 J_STRATA）** J_STRATA = (J_FLUID, hsm_hash, plan_id, contract_set_hash, TTC_margin, protocol_trace_hash, symbolic_ece, open_set_rate, abstraction_coverage, shield_violations, strata_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有已执行选项的契约成立 ∧ shield_violations = 0 ∧ TTC_margin ≥ 0 ∧ symbolic_ece ≤ τ_ece ∧ abstraction_coverage ≥ κ_min。

**定义 325（抽象覆盖审计 ACA）** 令 U_abs 为「触发 m_∅、守卫残差异常、非法转移、或契约未覆盖」的情形集合，E 为实际遭遇的情形集合。抽象覆盖率 κ = 1 − |U_abs ∩ E| / |E|；抽象债 D_abs = |U_abs ∩ E|。当 κ < κ_min 时，STRATA 自动降级为 R69 扁平闭环（关闭高层次收益，也关闭虚假的高层保证）。ACA 还包括离线的**抽象模糊测试**：对状态/守卫/契约注入扰动，检验证书是否会错误地保持 Valid。

```python
# IP-264 HSM：守卫 + 高层屏蔽 + 承诺冻结
def hsm_step(M, s, obs, b):
    enabled = [(g, t) for (g, t) in M.delta[s] if M.eval_guard(g, obs, b)]
    safe    = [(g, t) for (g, t) in enabled if M.spc.allow_hi(s, g, t, obs, b)]
    if not safe:
        return M.arm.minimal_risk(s, obs)          # 无安全转移 → 最小风险态
    g, t = max(safe, key=M.priority)               # 屏蔽后确定性
    if M.cba.ttc(s, obs) <= DELTA_SAFE:
        t = M.cba.freeze(s, b)                     # 承诺边界：冻结而非重开
    return t

    if M.cache.hit(s, b): return M.cache.get(s, b)
    best = max(M.options(s, b),
               key=lambda o: -M.contracts.cost(o)
                   + M.disc(o) * M.value(M.post(o, s), M.predict_b(b, o)))
    M.cache.put(s, b, best)
    return best

# IP-267 HVO：期限感知的层次 VoI（含“先去有利位置再问”）
def choose_info(M, s, b):
    V = M.opl.value(s, b)
    best = None
    for g in M.info_options(s, b):                 # gaze / probe / ask / vantage / self-probe
        if M.cba.ttc(s) < g.latency + DELTA_SAFE:  continue   # 来不及 → 直接排除
        if not M.spc.allow_hi(s, g, g.target, None, b): continue
        b_y = M.psm.expected_posterior(b, g, s)
        voi = V - M.opl.value(M.hsm.next(s, g), b_y) - g.cost
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None

# IP-269 PSM：证据协议（同源不得重复计数，超时必到 UNRESOLVED）
def psm_step(q, src, ans, t):
    if src.group in q.used_groups: return q          # 单源重复 → 不推进
    q = q.with_source(src, ans)
    if q.state == 'PROVISIONAL' and q.has_orthogonal_agreement():
        return q.to('CONFIRMED')
    if q.looks_collusive():  return q.to('POISONED')
    if t - q.t0 > TAU_PROTO: return q.to('UNRESOLVED')
    return q.to('CONFIRMING') if q.state == 'IDLE' else q

# IP-276 STRATA 主闭环（继承 R69，在“模式/计划/承诺”处插入层次层）
def STRATA_round(M, obs):
    s, b = M.hsm.current, M.belief
    b, U_ale, U_epi = M.slm.update(obs, b)            # 符号模态 + 选项内方差
    a_hat = M.fma_h.flow_score(obs, s)                # R69 连续似然通道
    r_g   = M.fma_h.guard_residual(obs, s)            # 离散守卫残差通道
    if M.aca.alarm(b, r_g, a_hat):                    # 未建模 / 抽象缺口
        b = M.slm.inject_unknown(b)                   # 提升 m_∅ 质量
    # 1) 承诺前：在正确层级做期限感知交互
    g = None
    if not M.cba.committed(s) and U_epi > TAU_EPI:
        g = M.hvo.choose_info(s, b)
    if g is not None:
        ans = M.psm.execute(g)                        # 协议 + k 源一致
        b   = M.psm.posterior(b, ans)
    # 2) 到达承诺边界：冻结最坏情况最优选项
    if M.cba.ttc(s) <= DELTA_SAFE:
        o_c = M.cba.freeze(s, b)
        U_floor = U_ale + (U_epi if not M.psm.confirmed(b) else 0.0)
    else:
        o_c = M.opl.select(s, b)
        U_floor = U_ale
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 3) 低层执行 + 分层屏蔽；契约失败即中止
    k = M.c_ras_wm.certified_prefix(M.ach.propose(o_c, M.vista.H), ..., wm_preds)
    if not M.tac.holds(o_c, s, M.vista.H) or M.aca.low_coverage():
        k, lam = M.arm.abort(o_c, s), max(lam, 0.8)   # 退回最小风险
    tau = M.pi_sigma.prefix_dispatch(o_c.a[:k]) * lam
    # 4) 审计 + 证书
    M.vqa_i.submit_async(g, b, r_g, a_hat, M.aca.coverage)
    return hsm_step(M, s, obs, b), k, lam, o_c, (U_ale, U_epi)
```

## 3. 推导

先声明本轮定理依赖的假设：
**A99（抽象包含）** M 与 HSM 覆盖任务相关模态与制度；未覆盖情形以 m_∅ 显式暴露，而不是被静默并入已建模状态。
**A100（契约可靠）** 每个被选选项的 C_o 在其环境假设 A_o 下成立。
**A101（守卫 Lipschitz）** 守卫裕度对观测的扰动满足局部 Lipschitz，残差 r_g 可检测模型偏差。
**A102（TTC 保守）** 估计的 TTC 是真实最后可安全切换时间的下界。
**A103（证据条件独立）** PSM 使用的不同源组在给定真值下条件独立，共谋相关 ρ < 1。

**引理 19（嵌套信息序：粗层先问不劣于细层先问）** 设歧义是嵌套的：细层模态 m^{ℓ+1} 的细化只在某个粗层分支 m^ℓ 内才有决策意义；粗、细两次询问都可在承诺边界前完成，且成本 c_coarse ≤ c_fine。则「先粗后细」的可行策略集合包含「先细后粗」：若粗层答案排除了细问题所在的分支，先粗者根本不必付细问题的成本；若未排除，先粗者仍可在其后问细。因此先粗的期望代价不高于先细，期望计划价值不低于先细。**系**：R69 在扁平模态集上询问，无法利用「粗层答案会剪掉整枝细问题」这一结构，因而在长程任务上会为不可达的细分支支付交互成本；这正是分层 VoI 相对 R69 的严格增益来源。反之，若粗问题来不及（L(coarse) > TTC）而细问题来得及，定义 316 会选细问题——期限约束优先于信息序。

**引理 20（期限可靠性）** 若 L(g) + δ_safe > TTC(t)，则 g 的答案在承诺边界之后才可用，不能改变任何在 t_c 前必须完成的转移。于是 E[V*(s^g,b^y)] = V*(s,b)，VoI_hi(g) = −c(g) < 0。故任何理性规划都不会执行该 g；R69 的贪婪 MINT 忽略延迟时可能选择它，造成「高信息量、零价值、正成本」的典型浪费。**系**：把 L(g) + δ_safe ≤ TTC 写成硬守卫，不是保守，而是让 VoI 的定义域正确。

**引理 21（有限符号标签消除幻影模态、并把缺口转成拒识）** 在闭集 M ∪ {m_∅} 上，任何被报出的高置信模态都属于 M；因此「不在 M 中的幻影模态被当成真实模态并据此追问」的概率为 0（在分类器校准前提下），幻影问题被转化成 m_∅ 的拒识/告警。逐类 ECE 的估计样本复杂度为 O(|M| ε^{-2} log(1/δ))，只随有限标签数增长；R69 的聚类标签是数据依赖的随机划分，要在所有可能划分上一致收敛需要额外假设，小样本下 ECE 可以任意乐观。**系**：SCG 使「模态校准」第一次成为一个适定（well-posed）的统计问题；但若 M 本身不完整，幻影会变成「缺模」，这由定义 325 的 ACA 负责，而不是由校准负责。

**引理 22（非短视 VoI 支配贪婪 VoI）** 构造两状态例子：状态 A 中「立即问」单步信息增益高，但答案在 t_c 后到达（有效价值 0）；存在一个「先移动到有利位置再问」的选项，其单步增益略低，但延迟满足 TTC 且在到达后信息增益更高。贪婪单步 VoI 选前者，HVO 选后者且获得正收益。故在存在延迟与计划耦合时，定义 316 的选项级 VoI 不低于 R69 的单步 VoI；R69 是 L=0、视界 1 的特例。

**定理 18（STRATA 严格包含 FLUID-RAS/R68）** 取退化配置 D0：单层 HSM（|S|=1）、选项库坍缩为单选项、TTC=∞、L=0、无开放集告警、PSM 采用与 R69 相同的 k 源规则、SCG 退化为 MCG。则 OPL 的选择等价于 R69 的逐轮模态选择，HVO 等价于 MINT 的单步 VoI，SPC 等价于 C-RAS-WM，分层退避等价于 R69 的两级退避。故 D0 下逐指令相同。对非退化配置，在 A99–A103 下，STRATA 的可行动作集是 R69 可行集的子集（多了承诺、契约、协议守卫），且每次交互满足期限可靠性（引理 20），因此期望风险不高于 R69；当粗层歧义存在且可剪枝时，由引理 19 获得严格更低的交互成本。**结论**：R69 是 STRATA 在「无层次、无承诺」边界上的退化；安全侧不做让步，效率侧获得「分辨率 + 期限」双重收益。

**定理 19（组合式安全）** 在 A99–A102 下，若 (i) 每个被执行的选项 o 的契约 C_o 有效，(ii) 初始状态满足顶层前置条件，(iii) 每次转移都通过 SPC 的高层与低层屏蔽，则任意执行前缀都满足顶层不变式 Inv_top。证明：对选项执行区间做归纳。基例由初始前置条件给出；归纳步中，C_o 在 A_o 下保证 □Inv_o 且终止于 Post_o，SPC 阻止任何破坏 Inv_top 的转移，下一选项的 A 由前一 Post 与顶层环境放电（假设-保证组合规则）。缺少契约或假设无法放电时，SPC 使该选项不可选，执行要么停在安全状态，要么走 ARM 的最小风险中止，故已执行前缀仍安全。**注意**：该定理是相对于 HSM/契约模型的安全，不是相对于真实世界的绝对安全——模型漏项正是本轮最大风险。

**定理 20（无抖动与协议活性）** 在最小驻留 τ_d 与滞回 h 下，任意长度 T 的区间内模式切换次数 ≤ T/τ_d，故无 Zeno 抖动。PSM 在公平源可用假设下，从 PROVISIONAL 出发，要么由正交一致证据进入 CONFIRMED，要么在 TAU_PROTO 内由超时进入 UNRESOLVED，二者必居其一；不存在只有「继续等待」出边的封闭子图，故无死锁。若所有源被污染，则进入 POISONED 并触发 ARM 的最小风险中止，活性以「有限时间内到达安全降级」而非「有限时间内成功」定义。**系**：R69 的「无限追问」在协议层被结构性排除。

## 6. 本轮最大风险

**一句话**：STRATA-RAS 的全部安全论证都建立在「HSM、选项库与契约正确覆盖了真实世界的相关制度」这一前提上——**一旦状态机漏掉一个状态、守卫或契约，分层屏蔽就会把「未建模的危险」认证成「已验证的安全」，这种抽象失配比没有状态机更危险，因为它让系统带着错误的图纸自信地承诺**。

**次级风险与缓解**：
1. **契约不可靠/环境假设未放电** → TAC 组合规则 + 无契约即不可选 + E307 覆盖率测试；
2. **符号标签集不完整（缺模）** → 开放集 m_∅ + ACA 抽象债 + 覆盖不足自动退回 R69 扁平闭环；
3. **守卫模型误差/传感器欺骗** → 守卫残差 r_g + 低层 C-RAS-WM 双通道 + E311；
4. **规划状态爆炸/重规划超时** → 选项抽象 + 缓存策略 + 半马尔可夫折扣 + 仅信念显著变化时重规划；
5. **承诺后无法安全反悔或反复抖动** → ARM 预计算中止集 + 最小驻留 τ_d + 滞回 h + 定理 20；
6. **层次化掩盖低层风险（过度抽象）** → 低层认证永不缺席 + 层次证书要求 J_FLUID 仍 Valid。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 继承 R69 的 FMP/AUD/CIA/FMA；新增 (i) 层次承诺不变式（低层只在已承诺选项契约内执行）；(ii) 期限可靠性（L(g)+δ_safe ≤ TTC，否则不得交互）；(iii) 组合证书（局部契约合取 + 状态机屏蔽）；(iv) 实时流零学习写操作。

**定义 311–313（HSM / 选项 / 规划）** HSM 含复合与正交状态、守卫、不变式，屏蔽后确定性；选项是带时长与契约的时间扩展动作，低层流策略复用 R69 trunk；OPL 在 (S×Δ(M)) 上做半马尔可夫规划，允许按证据分支的 contingent plan，分「任务自动机 → 选项树 → 原始动作」三层。

**定义 314（符号模态）** 模态是 HSM 的持久状态/选项标签，取自有限闭集 M ∪ {m_∅}，带细化映射；`U_ale` 为选项内方差，`U_epi=H(b)` 为符号模态熵。与 R69 的轨迹聚类标签相比：身份稳定、校准适定、承诺有对象。

**定义 315（承诺边界）** `t_c = max{t : 切换成本 ≤ c_c 且切换后仍安全}`；`TTC=t_c−t`；交互可行须 `L(g)+δ_safe ≤ TTC`；到界触发 commit 守卫，冻结当前选项，只能经 ARM 重开。

**定义 316（HVO）** `VoI_hi = V*(s,b) − E_y[V*(s^g,b^y)] − c(g)`，含去到有利位置再问的选项；R69 的 MINT = 层次深度 0、L=0、TTC=∞、视界 1 的退化。

**定义 317（PSM）** 证据协议状态机：同源重复不推进；确认需另一正交组独立一致；超时→UNRESOLVED；共谋→POISONED；只有 CONFIRMED 可驱动高置信承诺；轨迹哈希入证书。

**定义 318–319（SPC / TAC）** 高层屏蔽检查守卫、Inv、契约、预算、TTC；低层仍过 C-RAS-WM；允许 = 两者之交，取最大允许集。契约 (A,Pre,Inv,Post,B) 有效当 `A∧Pre ⇒ □Inv ∧ ◇_{≤T}Post` 且成本 ≤ B；顺序组合中前项 Post 放电后项 A；缺契约或假设无法放电即不可选。

**定义 320–321（FMA-H / SCG）** 连续流似然 a_score 与离散守卫残差 r_g 构成双通道：(a↑,r_g≈0) 偏传感器/世界；(a≈0,r_g↑) 偏模式误分类；(双↑) 偏结构变化/抽象失配。SCG 在 M∪{m_∅} 上做逐类 ECE 与选择性风险门控；`b(m_∅)>τ_∅` 触发抽象缺口告警。

**定义 322–323（分层退避 / 中止语义）** 承诺前消解成功 `λ=λ_floor(U_ale)`；到界未消解则冻结最坏情况最优选项、`λ=λ_floor(U_ale+U_epi)`、转保守 tracking；契约缺失/覆盖不足进最小风险态。中止集 Abort(o) 预计算，最小驻留 τ_d + 滞回 h；无可用中止则不得绕过承诺。

**定义 324–325（证书 / ACA）** J_STRATA 并入 hsm_hash、plan_id、contract_set_hash、TTC_margin、protocol_trace_hash、symbolic_ece、open_set_rate、abstraction_coverage、shield_violations。ACA 定义覆盖率 κ 与抽象债 D_abs；κ<κ_min 自动降级为 R69 扁平闭环；离线做抽象模糊测试，检验证书是否会错误保持 Valid。

## 3. 关键算法伪代码

```python
# IP-264 HSM：守卫 + 高层屏蔽 + 承诺冻结
def hsm_step(M, s, obs, b):
    enabled = [(g, t) for (g, t) in M.delta[s] if M.eval_guard(g, obs, b)]
    safe    = [(g, t) for (g, t) in enabled if M.spc.allow_hi(s, g, t, obs, b)]
    if not safe: return M.arm.minimal_risk(s, obs)
    g, t = max(safe, key=M.priority)               # 屏蔽后确定性
    if M.cba.ttc(s, obs) <= DELTA_SAFE:
        t = M.cba.freeze(s, b)                     # 到界冻结，不重开
    return t

# IP-266 OPL：半马尔可夫选项规划（缓存策略，仅显著变化时重规划）
def plan(M, s, b):
    if M.cache.hit(s, b): return M.cache.get(s, b)
    best = max(M.options(s, b),
               key=lambda o: -M.contracts.cost(o)
                   + M.disc(o) * M.value(M.post(o, s), M.predict_b(b, o)))
    M.cache.put(s, b, best)
    return best

# IP-267 HVO：期限感知层次 VoI（含“先去有利位置再问”）
def choose_info(M, s, b):
    V, best = M.opl.value(s, b), None
    for g in M.info_options(s, b):                 # gaze/probe/ask/vantage/self-probe
        if M.cba.ttc(s) < g.latency + DELTA_SAFE:  continue   # 来不及 → 排除
        if not M.spc.allow_hi(s, g, g.target, None, b): continue
        b_y = M.psm.expected_posterior(b, g, s)
        voi = V - M.opl.value(M.hsm.next(s, g), b_y) - g.cost
        if best is None or voi > best.voi: best = (g, voi)
    return best if best and best.voi > 0 else None

# IP-269 PSM：同源重复不推进；超时必到 UNRESOLVED
def psm_step(q, src, ans, t):
    if src.group in q.used_groups: return q
    q = q.with_source(src, ans)
    if q.state == 'PROVISIONAL' and q.has_orthogonal_agreement():
        return q.to('CONFIRMED')
    if q.looks_collusive():  return q.to('POISONED')
    if t - q.t0 > TAU_PROTO: return q.to('UNRESOLVED')
    return q.to('CONFIRMING') if q.state == 'IDLE' else q

# IP-276 主闭环（继承 R69，在模式/计划/承诺处插入层次层）
def STRATA_round(M, obs):
    s, b = M.hsm.current, M.belief
    b, U_ale, U_epi = M.slm.update(obs, b)
    a_hat = M.fma_h.flow_score(obs, s)             # 连续似然通道
    r_g   = M.fma_h.guard_residual(obs, s)         # 离散守卫残差通道
    if M.aca.alarm(b, r_g, a_hat):
        b = M.slm.inject_unknown(b)                # 提升 m_∅ 质量
    g = None
    if not M.cba.committed(s) and U_epi > TAU_EPI:
        g = M.hvo.choose_info(s, b)
    if g is not None:
        b = M.psm.posterior(b, M.psm.execute(g))   # 协议 + k 源一致
    if M.cba.ttc(s) <= DELTA_SAFE:
        o_c = M.cba.freeze(s, b)
        U_floor = U_ale + (U_epi if not M.psm.confirmed(b) else 0.0)
    else:
        o_c = M.opl.select(s, b); U_floor = U_ale
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(o_c, M.vista.H), ..., wm_preds)
    if not M.tac.holds(o_c, s, M.vista.H) or M.aca.low_coverage():
        k, lam = M.arm.abort(o_c, s), max(lam, 0.8)
    tau = M.pi_sigma.prefix_dispatch(o_c.a[:k]) * lam
    M.vqa_i.submit_async(g, b, r_g, a_hat, M.aca.coverage)
    return hsm_step(M, s, obs, b), k, lam, o_c, (U_ale, U_epi)
```

## 4. 推导

**假设 A99–A103**：A99 抽象包含（未覆盖情形以 m_∅ 暴露）；A100 契约可靠；A101 守卫裕度 Lipschitz；A102 TTC 保守；A103 证据源条件独立（共谋相关 ρ<1）。

**引理 19（嵌套信息序）** 当细层问题只在某个粗层分支内有意义、且两次询问都可在承诺前完成时，「先粗后细」可模拟「先细后粗」；若粗层答案剪掉了细问题所在分支，先粗者省下细问题成本，否则仍可随后再问细。故先粗的期望代价不高于先细。**系**：R69 在扁平模态集上询问，无法利用「粗层剪枝」；这是分层 VoI 的严格增益来源。若粗问题来不及而细问题来得及，由定义 316 的期限守卫改选细问题。

**引理 20（期限可靠性）** 若 `L(g)+δ_safe > TTC`，答案在承诺后到达，不能改变任何承诺前转移，故 `E[V*(s^g,b^y)] = V*(s,b)`、`VoI_hi(g) = −c(g) < 0`；理性的 HVO 必不选它，R69 的贪婪 MINT 可能选它，形成「高信息、零价值、正成本」的浪费。**系**：期限守卫是 VoI 定义域的一部分，不是额外保守。

**引理 21（有限标签消除幻影、缺口转拒识）** 在闭集 M∪{m_∅} 上，高置信报出的模态必属于 M，幻影采纳率在构造上为 0；逐类 ECE 样本复杂度 O(|M|ε^{-2}log(1/δ))；R69 的数据依赖聚类划分无法在无额外假设下一致收敛，小样本 ECE 可任意乐观。**系**：SCG 使模态校准适定；缺模问题交给 ACA，而不是交给校准。

**引理 22（非短视 VoI 支配贪婪）** 存在两状态例子：立即问的单步信息增益高但答案晚于 t_c，有效价值 0；「先到有利位置再问」单步增益略低但满足 TTC 且后续增益更高。贪婪选前者，HVO 选后者。故有延迟/计划耦合时 HVO ≥ R69 单步 VoI；R69 是 L=0、视界 1 的特例。

**定理 18（STRATA 严格包含 R69）** 退化配置 D0（单层 HSM、单选项、TTC=∞、L=0、无开放集告警、PSM 同 R69、SCG 退化为 MCG）下，OPL/HVO/SPC/退避分别等价于 R69 的模态选择/MINT/C-RAS-WM/两级退避，逐指令相同。非退化时，A99–A103 下可行动作集是 R69 可行集的子集，且交互满足期限可靠性，故期望风险不高于 R69；粗层可剪枝时由引理 19 获得更低交互成本。**R69 = 「无层次、无承诺」边界；安全不让步，效率获 resolution + deadline 双重收益。**

**定理 19（组合式安全）** 在 A99–A102 下，若每个被执行选项的契约有效、初始前置条件成立、每次转移过 SPC，则任意执行前缀满足顶层 Inv_top。证明用选项执行区间归纳：契约保证 □Inv_o 与 Post_o，SPC 阻止破坏 Inv_top 的转移，下一项 A 由前项 Post 与顶层环境放电；契约缺失/假设无法放电则选项不可选，执行停在安全态或走 ARM 中止。**注意**：安全性相对于 HSM/契约模型成立，模型漏项即本轮最大风险。

**定理 20（无抖动与协议活性）** 最小驻留 τ_d + 滞回 h ⇒ 任意 T 内切换 ≤ T/τ_d，无 Zeno 抖动。PSM 在公平源可用下，从 PROVISIONAL 要么进入 CONFIRMED，要么在 TAU_PROTO 内进入 UNRESOLVED；无「只等待」的封闭子图，故无死锁；全部源被污染则进 POISONED 并触发 ARM，活性定义为「有限时间内安全降级」。**系**：R69 的无限追问被协议结构性排除。

## 7. 本轮最大风险

**一句话**：STRATA-RAS 的全部安全论证都建立在「HSM、选项库与契约正确覆盖了真实世界的相关制度」这一前提上——**一旦状态机漏掉一个状态、守卫或契约，分层屏蔽就会把「未建模的危险」认证成「已验证的安全」，这种抽象失配比没有状态机更危险，因为它让系统带着错误的图纸自信地承诺**。

**次级风险与缓解**：契约不可靠/环境假设未放电（TAC 组合规则 + 无契约不可选 + E307）；符号标签集不完整（m_∅ + ACA 抽象债 + 覆盖不足退回 R69）；守卫模型误差/传感器欺骗（r_g + 低层 C-RAS-WM 双通道 + E311）；规划状态爆炸/重规划超时（选项抽象 + 缓存 + SMDP 折扣 + 显著变化才重规划）；承诺后无法安全反悔或抖动（ARM 预计算中止集 + τ_d + 滞回 + 定理 20）；层次化掩盖低层风险（低层认证永不缺席 + J_FLUID 仍须 Valid）。
