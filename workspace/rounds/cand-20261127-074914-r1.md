### 第 1 轮灵感驱动研究记录（数据质量 / 用户体验）

**灵感词**：数据质量、用户体验

**直觉与动机**：
现有 SRC-USC v25 的七证（USMC + SMC + RMC + MCC）都默认了两件事：其一，证书所依赖的数据是干净的——conformal 校准集无偏、语义标注正确、训练分布与部署分布可交换；其二，人会按证书的边界使用机器人——不过度信任、不绕过告警、不弃用。这两条假设是整个证书体系最脆弱的「隐根」。数据质量差，conformal 覆盖只是覆盖了错误分布；用户体验差，用户会在交互层绕过证书，使事前的物理安全形同虚设。

受「数据质量」启发：数据集不是静态资产，而是每个学习型证书的「燃料」。语义证书依赖标注质量，conformal 证书依赖校准集覆盖与交换性，策略证书依赖示范数据的分布。证书必须携带可审计的数据出处-覆盖-噪声-漂移画像，否则无法回答「这个证书凭什么成立」。受「用户体验」启发：用户体验不是满意度打分，而是人机闭环中的**人因安全边界**。过度信任（over-trust）与弃用（disuse）是两种对称的失效模式；信任必须与真实可靠性校准，交互成本必须可预算，时延必须可证上界。核心洞见：**数据质量是证书的「信任根」（ex ante），用户体验是证书的「效用验证」（ex post）；二者互为对偶，并构成一个必须证明稳定的反馈环。** 数据质量确定「证书能声称什么」，用户体验确定「证书声称的东西对人有何用」。

**三条可证伪的直觉预测**：
1. 若去掉数据出处与噪声证书，语义/conformal 证书的实测覆盖率会随标注噪声单调下降，且证书本身不会报警（「证书沉默失效」）。
2. 若只优化任务成功率而不约束信任校准，用户在某次失败后的弃用率会显著上升，系统级有效成功率反而低于「成功率略低但校准良好」的版本。
3. 若忽略用户反馈导致的内生分布漂移，静态 conformal 覆盖率会在多轮交互后跌破名义水平；引入反馈稳定性证书可把漂移限制在可证球内。

**严谨定义（本轮采用的骨架）**：

- **定义 A（数据质量画像与偏序格）**：对数据集 `D`，定义六维质量向量 `Q(D) = (q_prov, q_cov, q_noise, q_shift, q_fair, q_priv)`，各分量归一化为「越大越好」。`Q₁ ⊑ Q₂` 当且仅当六维逐项 `≤`；`⊓/⊔` 为逐项最小/最大。证书签发要求 `Q(D) ⊒ Q_req(task)`。数据质量不是一个标量，而是一个偏序格——因为「覆盖广但噪声高」与「噪声低但覆盖窄」不可互相替代。
- **定义 B（分布覆盖证书）**：给定数据点集 `D` 与用户可达分布 `P_H`，令 `s(x)=min_{d∈D}‖x−d‖`。用 split conformal 取 `r` 为校准分数的 `⌈(n+1)(1−α_data)⌉` 分位，则对可交换的 `x∼P_H` 有 `ℙ(s(x)≤r) ≥ 1−α_data`。`(r, α_data)` 即覆盖证书；`r` 小、`α_data` 小者为强。
- **定义 C（标注噪声证书）**：对多标注者用 Dawid–Skene 估计混淆矩阵与逐项后验，给出噪声上界 `η_ub`（置信度 `1−δ`）；对主观任务改用可接受标签集 `A_i`，要求歧义比例 `|{i: consensus_i∉A_i}|/N ≤ η_amb`。证书断言 `η_ub ≤ η_max`。
- **定义 D（用户体验证书）**：对人群模型 `H`，在置信度 `1−δ_ux` 下断言六元组：任务成功率 `≥1−α_ux`；交互成本均值/95 分位 `≤ B_cost`；信任校准误差 `ECE ≤ ε_trust`，过度信任率 `P(依赖 | 机器人错) ≤ γ_over`，弃用率 `P(不依赖 | 机器人对) ≤ γ_under`；端到端时延 `P99 ≤ L_p99`；解释理解度与人工接管成功率达标；跨用户群体满意度极差 `≤ ε_ux_fair`。
- **定义 E（经验-数据双向伴随）**：记数据侧断言 `C_D=(Q(D),π)`、体验侧断言 `C_U=U(π,H)`。`C_D ⊢ C_U` 表示对 `∀h∈H`，数据保证可推出体验保证；`C_U ⊣ C_D` 表示每条体验轨迹都能经归因映射回具体数据切片并更新其权重/出处。九证准入门要求两个方向都可审计，缺一即拒。
- **定义 F（反馈稳定性）**：用户策略 `μ_t` 受信任状态影响，部署分布按 `P_{t+1}=F(P_t,π_t,μ_t)` 演化。若反馈算子满足压缩条件 `W₁(P_{t+1},P_t) ≤ κ·W₁(P_t,P_{t−1})`（`κ<1`），且稳态漂移 `≤ Δ_budget`，则称反馈环稳定；此时经验调整后的覆盖可由 `1−α_data` 减去 `O(Δ_budget)` 的松弛得到。
- **定义 G（九证准入门 DEX-USC）**：`Exec_v26 = Exec_v25 ∩ Fil_data ∩ Fil_ux ∩ Fil_feedback`，即 `π` 同时通过 v25 七证、DQC、UXC、反馈稳定性与归因闭合。

**为什么这两个词必须同时出现**：只有数据质量，会得到「数据很干净但没人愿意用」的系统；只有用户体验，会得到「用户很满意但建立在不可复现数据上」的系统。二者是「来源合法性」与「消费有效性」的对偶，必须用双向伴随锁在一起，且任一侧失效都只能降级、不能被另一侧补偿。

**本轮最大风险（一句话）**：用户体验指标高度主观且可被 Goodhart，数据质量审计又只能覆盖有限切片——若二者在「用户迎合式交互 + 数据出处伪造」的联合攻击下同时被刷高，DEX-USC 可能给出一个统计上漂亮、归因上自洽、却在真实人群与真实数据上失效的「完美证书」。

## 1. 形式定义

### 1.1 数据质量偏序格

**定义 1（质量画像与格）**。六维分量分别归一化为 `[0,1]` 的「好度」：
`q_prov`：出处完整且签名可验的样本比例；
`q_cov = 1 − r/r_max`；`q_noise = 1 − η_ub/η_max`；
`q_shift = 1 − Δ_shift/Δ_max`；`q_fair = 1 − gap_fair/ε_fair_max`；
`q_priv = 1 − ε_DP/ε_DP_max`（许可谓词为 `{0,1}`）。
`Q₁ ⊑ Q₂ ⇔ ∀j, q_j(Q₁) ≤ q_j(Q₂)`；`⊓/⊔` 为逐项 min/max。`DQC` 签发条件：`Q(D) ⊒ Q_req`。**注意**：该格是偏序而非全序，因此「高质量」不可被单指标替代；用 `⊒` 而非标量加权，正是为了防止用覆盖率掩盖噪声、或用满意度掩盖隐私超限。

**定义 2（出处证书）**。`G_D` 为有向无环图：叶子 `x_i` 带内容哈希 `h_i=H(x_i)`、来源标识、同意令牌与许可标签；内部节点 `v` 带操作类型与输出哈希 `H(op_v, h_{children})`；根 `root(D)` 由采集方与数据治理方双签。`verify_prov(D)` 递归重算并校验签名与同意范围。

**定义 3（分布覆盖证书）**。给定清洗后的数据点集 `D` 与用户可达分布 `P_H`，分数 `s(x)=min_{d∈D}‖x−d‖`。在独立校准集 `X_cal∼P_H`（`|X_cal|=n`）上取
`r = Quantile_{⌈(n+1)(1−α_data)⌉/n}({s(x):x∈X_cal})`。
若部署样本与校准集可交换，则 `ℙ(s(x)≤r) ≥ 1−α_data`（split conformal 的标准有限样本保证）。证书断言 `r ≤ r_req`，并把 `D` 的 ε-net 半径与 `P_H` 的覆盖同时记录。

**定义 4（噪声证书）**。`K` 个标注者、`C` 个类别，用 Dawid–Skene EM 估计混淆矩阵 `π^{(k)}_{c,c'}` 与逐项后验 `p_i(c)`；`η̂ = (1/N)Σ_i(1−max_c p_i(c))`，用 bootstrap 取上界 `η_ub`（置信度 `1−δ`）。主观任务不强行求唯一标签，而定义可接受集 `A_i`，要求歧义比例 `η_amb ≤ η_amb_max`。证书同时记录标注指南版本与仲裁记录，防止「用多数票掩盖系统性偏差」。

**定义 5（漂移证书）**。以 MMD（或 `W₁`）估计数据分布 `D` 与用户校准分布 `U` 的差异；用随机特征近似把复杂度降到 `O(m²d)`。`Δ_shift = MMD_ub(D,U)`，证书断言 `Δ_shift ≤ Δ_max`；超界即触发重新校准或数据采集，而不是静默放行。

**定义 6（公平证书）**。对受保护群体 `g∈G`，分组覆盖 `Cov_g = ℙ_{x∼P_g}(s(x)≤r)`；`gap_fair = max_g Cov_g − min_g Cov_g ≤ ε_fair`。公平与覆盖绑定，避免「总体覆盖达标、少数群体系统性失覆盖」。

**定义 7（隐私/许可证书）**。`dp_epsilon` 为训练或校准的 DP 预算（或无 DP 时的成员推断风险上界）；`license` 为许可标签集合。`allows(purpose)` 为谓词：用途（研究/商用/再分发/微调）必须落在同意与许可交集内。许可不可满足时拒证，不用「匿名化」口头声明替代。

### 1.2 用户体验证书

**定义 8（人群模型与交互轨迹）**。`h=(expertise, goals, trust_prior, risk_pref, language, accessibility)`；`H` 为人群分布。轨迹 `τ_t` 记录目标 `g_t`、用户指令 `u_t`、机器人动作 `a_t`、反馈 `f_t`、干预 `I_t`、纠正 `N_t`、成本 `c_t`、时延 `ℓ_t`、自报信任 `b_t` 与满意度 `sat_t`。

**定义 9（UX 六元组）**。在置信度 `1−δ_ux` 下：
1. **成功**：`S_i=1[goal_i 达成 ∧ 无安全干预]`，`ℙ(S=1) ≥ 1−α_ux`（用 Clopper–Pearson 下界，而非点估计）；
2. **成本**：`E[C] ≤ B_cost_mean` 且 `P95(C) ≤ B_cost_p95`，`C = c_t·T + c_i·I + c_c·N_corr + c_m·TLX`；
3. **信任校准**：`ECE(b,ρ) ≤ ε_trust`，其中 `ρ` 为同上下文经验可靠性；`P(依赖 | 机器人错) ≤ γ_over`，`P(不依赖 | 机器人对) ≤ γ_under`；
4. **时延**：端到端 `P99(ℓ) ≤ L_p99`；
5. **解释/接管**：解释理解测验 `≥ρ_expl`，人工接管成功率 `≥ρ_override`；
6. **公平**：`max_g E[sat|g] − min_g E[sat|g] ≤ ε_ux_fair`。

**定义 10（经验调整覆盖）**。由于用户会依据信任改变输入，部署分布是内生的。把覆盖定义在用户可达集 `R(H)` 上，并用自适应 conformal 在每个反馈轮更新分位数；证书断言：在漂移预算 `Δ_budget` 内，
`ℙ_{x∼P_H}(s(x)≤r_t) ≥ 1−α_data − Lip·Δ_budget`。
这把「静态交换性」替换为「带漂移松弛的动态覆盖」，是 v26 与普通 conformal 的本质区别。

### 1.3 双向伴随与归因闭包

**定义 11（数据→体验推出 `C_D ⊢ C_U`）**。若对 `∀h∈H`，`Q(D)⊒Q_req(π,h)` 蕴含 `U(π,h)⊒U_req`，则记 `C_D ⊢ C_U`。这是**充分性**方向：数据保证必须足以支撑体验承诺；否则体验数字只是偶然相关。

**定义 12（体验→数据归因 `C_U ⊣ C_D`）**。存在映射 `α: τ ↦ (slice_j, w_j)`，把每条体验轨迹经出处 DAG 映射回具体数据切片并更新权重，且更新后的 `D'` 仍满足出处完整性。这是**必要性**方向：每个体验结果都可回溯，否则无法判断是数据问题、模型问题还是运行时问题。

**定义 13（归因矩阵与闭包）**。`Φ_attr[j,k]` 为数据维 `j` 对 UX 维 `k` 的因果效应（用分层/反事实删失估计并给出置信区间）。闭包条件：
- 前向守卫：若 `q_j(Q) < τ_j`，则要么该切片被排除/降权（`j∈Mitigated`），要么 `∃k: Φ_attr[j,k]>0` 且对应缓解措施生效；
- 反向归因：若 UX 维 `k` 未达标，则要么 `∃j: Φ_attr[j,k]>0` 并定位到切片，要么存在**运行时原因证书**（时延/算力/硬件）且该证书独立可验。
任一失败即拒证。**不允许**用「数据质量很好」去抵消一个无法归因的 UX 失败。

**定义 14（反馈稳定性证书）**。反馈算子 `P_{t+1}=F(P_t,π_t,μ_t)` 满足 `W₁(P_{t+1},P_t) ≤ κ·W₁(P_t,P_{t−1})`，`κ<1`，且稳态漂移估计 `Δ_stationary ≤ Δ_budget`。证书保证交互环不振荡、不形成「迎合式过滤泡」。

**定义 15（九证准入门 DEX-USC）**。
`DEX-USC.admits(Π,D,H) = SRC-USC.admits(Π) ∧ DQC.verify_all(D,purpose(Π)) ∧ UXC.verify_all(Π,H) ∧ Stable.verify() ∧ Attr.verify_closure(DQC,UXC)`。
`Exec_v26 = Exec_v25 ∩ Fil_data ∩ Fil_ux ∩ Fil_feedback`。

## 2. 关键算法骨架

```python
from dataclasses import dataclass, field
from typing import Optional
import torch

# ---------------- 基础统计工具 ----------------

def conformal_quantile(scores: torch.Tensor, alpha: float) -> float:
    """split conformal 的有限样本分位数（取 higher 以保证覆盖）。"""
    n = scores.numel()
    q = min(1.0, (1.0 - alpha) * (1.0 + 1.0 / n))
    return torch.quantile(scores, q, interpolation="higher").item()

def clopper_pearson_lower(k: int, n: int, alpha: float) -> float:
    """成功率的单侧 (1-alpha) 置信下界。"""
    if n == 0:
        return 0.0
    if k == 0:
        return 0.0
    from scipy.stats import beta
    return float(beta.ppf(alpha, k, n - k + 1))

def expected_calibration_error(pred: torch.Tensor, obs: torch.Tensor,
                               n_bins: int = 10) -> float:
    """ECE：预测信任 vs 观测可靠性的分箱校准误差。"""
    edges = torch.linspace(0, 1, n_bins + 1)
    ece = 0.0
    for lo, hi in zip(edges[:-1], edges[1:]):
        m = (pred >= lo) & (pred < hi)
        if m.any():
            ece += m.float().mean().item() * abs(
                pred[m].mean().item() - obs[m].mean().item())
    return ece

def conformal_quantile_upper(scores: torch.Tensor, alpha: float) -> float:
    """单侧 1-alpha 上界（用于 P99 时延）。"""
    n = scores.numel()
    idx = min(n - 1, int(torch.ceil(torch.tensor((n + 1) * (1 - alpha))).item()) - 1)
    return torch.sort(scores).values[idx].item()

@dataclass
class QualityRequirement:
    r_req: float = 0.05
    alpha_data: float = 0.05
    eta_max: float = 0.05
    eta_amb_max: float = 0.10
    delta_shift_max: float = 0.10
    eps_fair_gap: float = 0.05
    dp_epsilon_max: float = 8.0


@dataclass
class DataQualityCertificate:
    dataset_id: str
    merkle_root: str
    provenance: "ProvenanceDAG"
    data_points: torch.Tensor                 # [N_d, d]
    coverage_radius: float                    # r（由校准得到）
    noise: "NoiseCertificate"
    shift: "ShiftCertificate"
    fairness: "FairnessCertificate"
    privacy_license: "PrivacyLicenseCertificate"
    groups: torch.Tensor                      # [N_d] 群体标签
    requirement: QualityRequirement = field(default_factory=QualityRequirement)

    def verify_provenance(self) -> bool:
        if self.provenance.compute_merkle_root() != self.merkle_root:
            return False
        return all(self.provenance.verify_edge(e) for e in self.provenance.edges)

    def verify_coverage(self, user_samples: torch.Tensor) -> bool:
        scores = torch.cdist(user_samples, self.data_points).min(dim=1).values
        r_conf = conformal_quantile(scores, self.requirement.alpha_data)
        return r_conf <= self.requirement.r_req

    def verify_noise(self) -> bool:
        return (self.noise.eta_ub <= self.requirement.eta_max and
                self.noise.ambiguity_frac <= self.requirement.eta_amb_max)

    def verify_shift(self, user_samples: torch.Tensor) -> bool:
        mmd = self.shift.estimate(self.data_points, user_samples)
        return mmd <= self.requirement.delta_shift_max

    def verify_fairness(self, user_samples: torch.Tensor) -> bool:
        scores = torch.cdist(user_samples, self.data_points).min(dim=1).values
        r = conformal_quantile(scores, self.requirement.alpha_data)
        covs = []
        for g in self.groups.unique():
            m = self.groups == g
            covs.append((scores[m] <= r).float().mean().item())
        return (max(covs) - min(covs)) <= self.requirement.eps_fair_gap

    def verify_privacy_license(self, purpose: str) -> bool:
        return (self.privacy_license.allows(purpose) and
                self.privacy_license.dp_epsilon <= self.requirement.dp_epsilon_max)

    def deficits(self) -> list[str]:
        out = []
        if not self.verify_noise():
            out.append("noise")
        if not self.verify_fairness():
            out.append("fairness")
        if not self.verify_privacy_license("deploy"):
            out.append("privacy_license")
        return out

    def verify_all(self, user_samples: torch.Tensor, purpose: str) -> bool:
        ok = self.verify_provenance()
        ok = ok and self.verify_coverage(user_samples)
        ok = ok and self.verify_noise()
        ok = ok and self.verify_shift(user_samples)
        ok = ok and self.verify_fairness(user_samples)
        ok = ok and self.verify_privacy_license(purpose)
        return ok

@dataclass
class UXRequirement:
    alpha_ux: float = 0.05
    delta_ux: float = 0.05
    B_cost_mean: float = 20.0
    B_cost_p95: float = 40.0
    eps_trust: float = 0.10
    gamma_over: float = 0.05
    gamma_under: float = 0.10
    L_p99: float = 0.20
    rho_expl: float = 0.80
    rho_override: float = 0.95
    eps_ux_fair: float = 0.10


@dataclass
class UserExperienceCertificate:
    population: "HumanPopulation"
    success: torch.Tensor          # bool [n]
    costs: torch.Tensor            # [n]
    satisfaction: torch.Tensor     # [n] in [0,1]
    trust_pred: torch.Tensor       # [n] 机器人对用户信任的预测
    trust_obs: torch.Tensor        # [n] 用户自报信任
    robot_correct: torch.Tensor    # bool [n]
    human_relied: torch.Tensor     # bool [n]
    latencies: torch.Tensor        # [n]
    comprehension: torch.Tensor    # [n]
    override_success: torch.Tensor # bool [n]
    group_ids: torch.Tensor        # [n]
    requirement: UXRequirement = field(default_factory=UXRequirement)

    def verify_task_success(self) -> bool:
        k, n = int(self.success.sum()), len(self.success)
        return clopper_pearson_lower(k, n, self.requirement.delta_ux) >= \
            1.0 - self.requirement.alpha_ux

    def verify_cost(self) -> bool:
        return (self.costs.mean().item() <= self.requirement.B_cost_mean and
                torch.quantile(self.costs, 0.95).item() <= self.requirement.B_cost_p95)

    def verify_trust_calibration(self) -> bool:
        ece = expected_calibration_error(self.trust_pred, self.trust_obs)
        relied, correct = self.human_relied.bool(), self.robot_correct.bool()
        over = ((relied) & (~correct)).float().mean().item()
        under = ((~relied) & (correct)).float().mean().item()
        return (ece <= self.requirement.eps_trust and
                over <= self.requirement.gamma_over and
                under <= self.requirement.gamma_under)

    def verify_latency(self) -> bool:
        return conformal_quantile_upper(
            self.latencies, 1.0 - 0.99) <= self.requirement.L_p99

    def verify_explainability(self) -> bool:
        return (self.comprehension.mean().item() >= self.requirement.rho_expl and
                self.override_success.float().mean().item() >= self.requirement.rho_override)

    def verify_fairness(self) -> bool:
        means = torch.stack([self.satisfaction[self.group_ids == g].mean()
                             for g in self.group_ids.unique()])
        return (means.max() - means.min()).item() <= self.requirement.eps_ux_fair

    def deficits(self) -> list[str]:
        checks = {
            "success": self.verify_task_success(),
            "cost": self.verify_cost(),
            "trust": self.verify_trust_calibration(),
            "latency": self.verify_latency(),
            "explain": self.verify_explainability(),
            "fairness": self.verify_fairness(),
        }
        return [k for k, v in checks.items() if not v]

    def verify_all(self) -> bool:
        return len(self.deficits()) == 0

@dataclass
class FeedbackStabilityCertificate:
    kappa: float                      # 反馈压缩系数
    predicted_stationary_drift: float
    drift_budget: float = 0.10

    def verify(self) -> bool:
        return (0.0 <= self.kappa < 1.0 and
                self.predicted_stationary_drift <= self.drift_budget)


@dataclass
class AttributionMatrix:
    phi: torch.Tensor                 # [6, 6] 数据维 -> UX 维因果效应
    runtime_causes: dict = field(default_factory=dict)  # UX维 -> 运行时证书
    mitigated_data_dims: set = field(default_factory=set)

    def verify_closure(self, dqc: DataQualityCertificate,
                       uxc: UserExperienceCertificate) -> bool:
        # 前向：数据缺陷必须有下游守卫或已定位归因
        for j_name in dqc.deficits():
            j = data_dim_index(j_name)
            if j not in self.mitigated_data_dims and \
               float(self.phi[j].abs().max()) <= 0.0:
                return False
        # 反向：UX 缺陷必须有数据归因或独立运行时原因证书
        for k_name in uxc.deficits():
            k = ux_dim_index(k_name)
            has_data = float(self.phi[:, k].abs().max()) > 0.0
            rc = self.runtime_causes.get(k_name)
            has_runtime = rc is not None and rc.verify()
            if not (has_data or has_runtime):
                return False
        return True


@dataclass
class DataExperienceUnifiedCertificate:
    src_usc: "SemanticReconfigCoordUnifiedCertificate"
    dqc: DataQualityCertificate
    uxc: UserExperienceCertificate
    stability: FeedbackStabilityCertificate
    attribution: AttributionMatrix

    def admits(self, multi_plan, sensor_data, user_samples,
               purpose: str) -> bool:
        # 1. v25 七证
        if not self.src_usc.admits(
                multi_plan, sensor_data,
                gt_entities=sensor_data.get("gt_entities"),
                queries=sensor_data.get("queries"),
                retrieved=sensor_data.get("retrieved")):
            return False
        # 2. 数据信任根
        if not self.dqc.verify_all(user_samples, purpose):
            return False
        # 3. 用户体验
        if not self.uxc.verify_all():
            return False
        # 4. 反馈稳定
        if not self.stability.verify():
            return False
        # 5. 双向归因闭包
        if not self.attribution.verify_closure(self.dqc, self.uxc):
            return False
        return True
```

### 2.1 端到端接入（慢环 vs 快环）

```python
class HumanCenteredDataPipeline:
    """DQC/UXC 在『回合级/模型级』慢环执行；DEX-USC 在任务准入时执行；
    50Hz 控制环只消费缓存的判定结果，不重复做全量审计。"""

    def __init__(self, config, src_usc, dqc, uxc, stability, attribution):
        self.src_usc = src_usc
        self.dqc = dqc
        self.uxc = uxc
        self.stability = stability
        self.attribution = attribution
        self._cached_admission = None
        self._cache_version = -1

    def on_data_or_model_update(self, dataset, user_samples, traces):
        # 慢环：数据层重证 + 体验层重证 + 稳定性拟合
        self.dqc = rebuild_dqc(dataset)                 # 出处/覆盖/噪声/漂移/公平/隐私
        self.uxc = refit_uxc(traces)                    # 成功率/成本/信任/时延/解释/公平
        self.stability = fit_feedback_stability(traces) # κ 与稳态漂移
        self.attribution = fit_attribution(dataset, traces)

    def step(self, multi_plan, sensor_data, user_samples, purpose, version):
        if version != self._cache_version:
            self._cached_admission = self.admits(
                multi_plan, sensor_data, user_samples, purpose)
            self._cache_version = version
        if not self._cached_admission:
            return False, {"reason": "DEX-USC reject",
                           "data_deficits": self.dqc.deficits(),
                           "ux_deficits": self.uxc.deficits()}
        return self.src_usc.admits(multi_plan, sensor_data), {}
```

## 4. 正确性论证（增量）

### 引理 13（DQC 的出处-覆盖-噪声三重保证）
**陈述**：`DQC.verify_all(...) = True` 蕴含：
(1) 每个样本可回溯到签名根与同意/许可范围；
(2) 用户可达分布上的覆盖半径 `r ≤ r_req`；
(3) 标注噪声上界 `η_ub ≤ η_max` 且主观歧义 `≤ η_amb_max`（置信度 `1−δ`）。

**证明**：
1. 出处：Merkle-DAG 的抗碰撞性保证任何叶/边篡改都会改变根哈希；双签保证来源与治理方不可单方抵赖；`allows(purpose)` 与同意令牌做交集，保证用途合法。
2. 覆盖：`r` 取 split conformal 的有限样本分位，标准结论给出 `ℙ(s(x)≤r) ≥ 1−α_data`；`verify_coverage` 直接比较 `r` 与 `r_req`，故覆盖断言成立。
3. 噪声：Dawid–Skene 给出逐项后验，`η_ub` 为 bootstrap 的单侧上界；在可辨识性假设下，`η_ub` 以 `1−δ` 覆盖真实噪声。主观任务用可接受集而非唯一标签，避免把合法歧义误判为噪声。∎

### 引理 14（UXC 的成功-成本-信任三重保证）
**陈述**：`UXC.verify_all() = True` 蕴含：任务成功率下界 `≥1−α_ux`、交互成本上界、信任校准（ECE 与双侧依赖率）在容差内，且时延/解释/公平同时达标。

**证明**：
1. 成功：小样本下用 Clopper–Pearson 精确下界而非正态近似，保证名义置信度；`S_i` 同时要求目标达成与无安全干预，避免「成功了但不安全」被计入。
2. 成本：均值与 P95 双约束，防止只优化平均值而尾部体验崩溃。
3. 信任：`ECE` 控制整体校准；`γ_over` 控制「机器人错但人依赖」的 complacency，`γ_under` 控制「机器人对但人弃用」的 disuse。二者是对称风险，缺一会让系统在真实人群中出现「越成功越危险」或「越安全越没人用」。∎

### 引理 15（经验调整覆盖的反馈稳定性）
**陈述**：若反馈算子满足压缩条件 `κ<1`、信任校准成立（引理 14），且交互成本在预算内，则经验调整后的部署覆盖满足
`ℙ_{x∼P_H}(s(x)≤r_t) ≥ 1−α_data − Lip·Δ_budget`，
且 `W₁(P_t,P_cal) → Δ_stationary/(1−κ)`。

**证明（要点）**：取 Lyapunov 函数 `V_t = W₁(P_t,P_cal) + λ|b_t−ρ_t|`。压缩条件给出 `W₁` 项按 `κ` 收缩；信任校准给出 `|b_t−ρ_t| ≤ ε_trust`（引理 14），因此 `V_t` 有界。由自适应 conformal 的漂移敏感性，覆盖损失不超过 `Lip·W₁`；把稳态漂移代入即得结论。**注意**：这是条件性命题，不声称无条件成立；`κ` 与 `Lip` 必须由数据估计并作为证书字段显式给出。∎

### 引理 16（双向归因闭包）
**陈述**：`Attr.verify_closure = True` 蕴含：每个数据质量缺陷都有下游守卫或已定位的 UX 因果效应；每个 UX 缺陷都有数据归因或独立可验的运行时原因。

**证明**：前向条件逐项检查 `dqc.deficits()`：未缓解的数据维必须存在非零 `Φ_attr` 行；反向逐项检查 `uxc.deficits()`：必须存在非零 `Φ_attr` 列或通过验证的运行时证书。两者都是有限谓词合取，直接由代码路径保证。闭包的意义是**禁止跨层抵消**：数据好不能抵消不可解释的 UX 差，UX 好也不能抵消不可信数据。∎

### 引理 17（九证单调退化链）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：`DEX-USC.admits` 是 `SRC-USC.admits` 与四个新条件的合取，故 `Exec_v26 ⊆ Exec_v25`。新条件的退化路径：
- 数据出处/覆盖/噪声/漂移/公平/隐私失效 → `Fil_data` 拒绝 → 冻结学习与数据驱动组件，回退到 v25 的固定模型/固定校准集；语义可降级为纯几何规划。
- 成功/成本/信任/时延/解释/公平失效 → `Fil_ux` 拒绝 → 切换保守交互模式（降低自主级别、增加确认、改用遥操作/示教器），该模式本身是 v25 的单机安全计划。
- 反馈失稳/归因不闭合 → `Fil_feedback` 拒绝 → 冻结在线自适应、停止个性化更新，回到静态 v25 策略。
三种拒绝都只减少执行集，不新增行为，故与 v25 及其下游的单调链相容。组合失效取交集，保持单调。∎

### 定理（DEX-USC 的九证完备性）
**陈述**：对任意多机计划 `Π` 与人群 `H`，`DEX-USC.admits(Π,D,H)=True` 当且仅当 `Π` 同时满足 v25 的七类条件，以及 (8) 数据出处/覆盖/噪声/漂移/公平/隐私达标，(9) 体验成功/成本/信任/时延/解释/公平达标，(10) 反馈稳定且双向归因闭合。

**证明**：直接由 `admits` 的合取定义，以及引理 13–17。必要性：任一条件缺失即拒证；充分性：全部满足时，引理 13/14 给出数据与体验的局部保证，引理 15 把体验反馈下的覆盖接回数据保证，引理 16 保证两层不可互相抵消，引理 17 保证整体仍在单调退化链内。∎

**预注册的关键对照**：v26 与 v25 在**纯物理安全**指标上应无显著差异（因为 v26 是 v25 的子集），差异应体现在「数据失效漏检率」「用户有效成功率」「弃用/过度信任」与「长期覆盖保持」上。若 v26 在物理安全上反而更差，说明新增过滤改变了策略分布并引入了新风险，需回退。

## 6. 已知风险与缓解（增量）

| 编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R16 | 数据出处可伪造、审计只覆盖抽样切片，Merkle-DAG 无法证明「未采样数据未污染」 | 高 | 1) 硬件可信执行环境签名采集端；2) 分层抽样 + 统计审计给出污染上界；3) 出处不可验的切片默认排除而非默认信任 | 供应链级投毒（上游采集器被控）仍可能绕过，需组织与法律层配合 |
| R17 | UX 指标主观、可被 Goodhart；用户可能迎合实验者，满意度与真实效用脱节 | 高 | 1) 成功/成本/信任多指标交叉，禁止单一满意度；2) 纵向行为日志与自报分离；3) 盲测与第三方审计；4) 对「异常高满意度」触发反作弊复核 | 长期真实人群迁移与实验人群差异无法完全消除 |

## 7. 本轮最大风险（最终确认）

**一句话**：**用户体验可被 Goodhart、数据出处可被上游伪造，而双向归因又只能建立在有限切片与因果假设之上——若「迎合式交互」与「供应链投毒」联合出现，DEX-USC 可能生成一份统计漂亮、归因自洽、却同时偏离真实人群与真实数据分布的「完美证书」，使九证体系在来源层与消费层被同时架空。**
