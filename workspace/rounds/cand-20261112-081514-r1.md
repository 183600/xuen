# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「专利布局」×「数据配比」）

> 第 57 轮把承诺的赌注从"模型置信"经"证据质量"押到"元先验质量"，再用 OOD 门 + 共形保底赎回一部分；它让证据可校准（MFSL）、可对账（XMC）、可个性化（PTM）。但它留下的三层结构仍是**单张证书、单一语料、没有"未覆盖领土"概念**：**(a)** 证书 J_m/J_p 是"全有或全无"的整体断言——它只说"此处安全"，不说"在什么部署条件下安全、由哪几条彼此独立的证据线支撑、哪一条失效后还剩什么"。一条被违反的假设（坏先验、传感器故障、橡皮章操作者）就可能把整张证书一次性作废——这在专利语言里叫"只有一个超宽独立权利要求、没有任何从属权利要求"，既易被无效、又易被规避。**(b)** 语料构成（数据配比）始终是背景假设：校准是边际的，而部署分层配比一旦偏离训练配比，边际 ECE 可以在每个分层都严重失准时仍然漂亮（Simpson 悖论）；更糟的是，没有一张证书记录它是"在哪种配比上被授予的"，于是证书的适用范围不可审计。**(c)** 系统只问"这个点是否过门"，从不问"可预见的部署条件里，是否每一处都至少被一条独立证据线覆盖"。一个全新地形/攻击可以满足所有既有特征（全要件）却落在所有权利要求的作用域之外——这就是**越界/设计规避**。
>
> 本轮两个灵感各补一刀。**专利布局**说：不要把安全写成一个巨型布尔门，而要写成一个**有偏序、有作用域、有冗余的权利要求组合**——独立权利要求按安全机制分族，从属权利要求做窄域回退；真正要优化的不是"证书数量"，而是威胁空间中每个场景的**最小覆盖深度 d_P**（失效掉 d_P−1 条独立权利要求，场景仍被覆盖）。**数据配比**说：每条权利要求的"支持度"取决于它背后的数据配比；必须把配比从背景变成显式参数——分层校准（最坏分层而非边际）、带密度比截断的加权共形、目标配比模糊集上的分布鲁棒界，并把"这条 claim 在哪个配比球内可执行"写进证书本身。二者合流为 **claim–data 对偶**：每条 claim 既声明覆盖范围、又消耗证据预算；安全布局就是在探针预算下，同时选择"申请哪些权利要求"和"采集哪种配比的证据"，使最坏场景的独立覆盖深度最大，且没有不可逆承诺落在"未覆盖领土"上。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"权利要求有作用域、组合有失效冗余、支持配比可审计的证据说可信"**。

核心矛盾：
- **H29（覆盖深度 vs 证据预算，且独立难证）**：专利式冗余（多条独立证据线）能抗单点失效，但每条真正独立的线都要独立探针、独立模态、独立先验、独立操作者；覆盖深度与探针预算天然冲突，而"独立性"本身只能靠声明——若两条 claim 共享同一个元先验或同一份语料，它们只是一个失效点的两种写法，冗余是幻觉。
- **H30（配比可审计 vs 配比不可观测且可博弈）**：分层校准与 DRO 需要部署配比 π_target，但真实配比未知、漂移、且由系统自己的主动采集决定；把配比写进证书等于把"谁为配比先验负责"重新引入，而按覆盖深度选择采集配比又会制造 Goodhart——系统可以把证据堆到"能让证书好看"的分层，而不是部署真正危险的分层。
- **H31（权利要求宽 vs 支持窄）**：为覆盖更多场景，claim 的 scope 必须宽；但宽 scope 的支撑证据往往只在窄分层里。专利里这叫"说明书不支持权利要求"，安全里就是**纸面安全 / scope–support gap**——证书声称覆盖的地形，正是它几乎没有证据的地形。

## 0. 直觉与动机

**灵感 1（专利布局 → 安全证书不是门，而是权利要求组合）**
直觉：专利保护的不是"一个点"，而是"一组特征所圈定的实施空间"。侵权判定遵循**全要件原则**：一个实现落入权利要求，当且仅当它同时具备该权利要求的全部特征；多加一个特征只会收窄范围。把每条安全证据条件看成一个原子特征 f，则一张安全证书就是一个特征子集 F_c 加一个作用域谓词 S_c：`Scope(c)={t | S_c(t) 且 F_c 全部成立}`。于是"加证据 = 收窄承诺范围"变成格上的单调运算，独立/从属权利要求变成可判定的偏序。更关键的是布局观：单个权利要求再强也只是单点，真正的安全来自**组合覆盖**——对威胁空间中的每个场景 t，统计有多少条**彼此独立**的权利要求覆盖它，得到覆盖深度 d_P(t)；要求失效掉任意一条（乃至 k−1 条）后 d_P(t) 仍 ≥1。配合"权项冗余剪枝"（删掉不降低最小覆盖深度的 claim）与"失效演练"（主动找能同时作废多条 claim 的共因），把"我们有很多证据"升级为"我们的证据组合抗失效"。

**灵感 2（数据配比 → 每条权利要求都携带支持配比与作用域）**
直觉：模型在训练配比上表现好，不等于在部署配比上可信；专利里权利要求能否成立，取决于说明书是否**充分支持**它主张的范围。于是给每条 claim 附一张**配比支持证书** MSC：在分层 z 上的训练配比 π_c、每层有效样本量 ESS_z、最坏分层校准 ε_str、目标配比模糊集 ℬ(π̂,ρ_mix)、以及密度比截断常数 M。claim 只在"目标配比落在 ℬ 内 ∧ 每层 ESS 足够 ∧ 最坏分层 ECE≤ε_str"时**可执行**；这直接封死 Simpson 悖论（边际合格不能救分层不合格）与"在语料里安全、在部署里不安全"。配比的另一面是**可被选择**：主动采集应优化"最坏场景覆盖深度/预算"，而不是平均精度；同时预注册目标配比与威胁集、留出未用于采集的分层做审计，防止把配比刷成证书的样子。

**灵感 3（claim–data 对偶 → 安全布局是预算下的覆盖深度最大化）**
直觉：每条 claim 同时是"覆盖声明"和"证据消耗"：它花掉探针/模态/标注预算，换来对一片作用域的承诺。于是布局变成一个带约束的优化：在探针预算 B、独立性与配比有效性约束下，选采集分配 a，使 `min_{t∈𝒯} d_{P(a)}(t)` 最大。它是单调次模的（多一条有效 claim 不会减少覆盖），贪心可给出 (1−1/e) 近似；预算耗尽而深度未达 d_min 时，正确动作不是"凑一张纸面证书"，而是绕行或安全停。数据配比在这里第一次成为**安全决策变量**，而不是训练超参。

**灵感 4（设计规避与负权利要求 → 未覆盖领土默认不安全）**
直觉：专利最危险的不是"被无效"，而是"被规避"：对手做一个落在你所有字面特征之外、却实现同一功能的实现（等同原则的灰区）。安全系统的对应物是**越界**：某场景满足某 claim 的全部特征、却不满足（或故意绕过）其作用域谓词，而它实际上仍危险。为此引入**负权利要求** b=(S_b,F_b)：显式禁止在某类场景承诺；以及不变量 NUC：任何不可逆接触都不得发生在 `unclaimed(t)`（无任何有效 claim 覆盖）或 `design-around(t)`（字面满足但风险预测高）的领土上。未覆盖不是"默认安全"，而是"默认拒绝"。

**灵感 5（失效演练与再申请 → PCE++ 在运行期维护组合）**
直觉：专利申请不是一次性的，被现有技术击中就要修改、分案、再申请。安全组合也应如此：一次事后证伪 ν 只撤掉/降级被它触及的 claim（按特征、作用域、支持配比三重判定），旧版本 claim 立即停用；系统必须用新探针**再申请**（re-file）以恢复覆盖深度，恢复不了就绕行/降档/安全停。这样"坏证据长寿"与"坏先验普遍"都被限制在**局部 claim 失效**，而不是整张安全案一次性崩塌——只要独立性声明诚实、失效演练充分。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（安全权利要求与作用域格 SCP）** 权利要求 c=(F_c,S_c,D_c,v_c,ℓ_c)：F_c 为原子证据特征集（全要件），S_c 为部署条件作用域谓词，D_c 为配比支持证书（定义 141），v_c 为版本/优先时刻，ℓ_c∈{L0,L1,L2} 为接触级。`Scope(c)={t | S_c(t)=1 ∧ ∀f∈F_c: f(t)=1}`。偏序：`c1≼c2 ⇔ Scope(c1)⊆Scope(c2) ⇔ (F_c2⊆F_c1 ∧ S_c1⇒S_c2)`；独立权利要求为各机制族的极大元，从属权利要求 = 独立项加特征（收窄）。组合 P={c_i}，其**依赖图** G_P 的边表示"共享证据源/先验/语料/操作者"。

**定义 140（覆盖深度与 k-失效容错）** 威胁集 𝒯（可预见的地形×位姿×载荷×季节×操作者×故障模式）。对 t∈𝒯，`cov_P(t)={c∈P | c 有效 ∧ t∈Scope(c)}`；按 G_P 的共因关系做商，得独立证据族集合 ℱ_P(t)，**覆盖深度** `d_P(t)=|ℱ_P(t)|`。组合对失效事件集 𝒩 是 k-容错的，若 `∀ν∈𝒩, ∀t∈𝒯: d_{P⊖Inv(ν)}(t) ≥ k`；不可逆接触要求 k≥2。P 是**无冗余**的，若删除任一 c 都会使 `min_t d_P(t)` 下降（否则该 claim 只是"纸面堆砌"）。

**定义 141（配比支持证书 MSC）** 分层 z∈Z（地形簇/位姿桶/模态可用性/操作者授权/季节），训练配比 π_c(z)，目标配比模糊集 `ℬ(π̂,ρ_mix)={w | D_f(w‖π_c)≤ρ_mix ∧ w_z≥w_min}`，密度比截断 M，分层有效样本量 ESS_z，最坏分层校准 ε_str。`MSC(c)=(π_c,ρ_mix,M,{ESS_z},ε_str)`。claim c 在目标配比 w_t 下**可执行**当且仅当：`w_t∈ℬ ∧ min_z ESS_z≥ESS_min ∧ max_z ECE_z(c,w_t)≤ε_str`（Simpson 守卫：边际合格不能替代逐层合格）。加权共形以 `w_t(z)/π_c(z)`（截断于 M）为权重、未加权质量 ≤α 时给出 ≥1−α 覆盖；配比球外则 claim 自动失执行资格（作用域收缩而非放宽）。

**定义 142（claim–data 布局 CDL）** 采集分配 a:Z→ℕ，成本 cost(a)≤B；一次采集可产生若干候选 claim。目标：
`max_a min_{t∈𝒯} d_{P(a)}(t)` s.t. 预算、独立性、每条新 claim 的 MSC 可执行、且 `w_acq` 与预注册目标配比的偏离 ≤δ_mix。覆盖函数对"加入有效 claim"单调且次模，贪心给出 (1−1/e) 最坏情形近似；采集结束后按定义 140 做无冗余剪枝。

**定义 143（设计规避监视与负权利要求 DAM）** `unclaimed_P(t) ⇔ ∄c∈P: c 有效 ∧ t∈Scope(c)`。`design-around_P(t) ⇔ ∃c: 字面全要件成立 ∧ t∉Scope(c)（作用域被绕过）∧ 风险预测 risk(t)>θ_da`。负权利要求 b=(S_b,F_b) 显式禁止承诺。**NUC 不变量**：不可逆接触仅当 `¬unclaimed(t) ∧ ¬design-around(t) ∧ ∄b: t∈Scope(b)`。监视器以"新颖度密度 + 跨模态分歧 D(r) + 反事实失效预测"合成越界分，漏检率 ≤δ_da。

**定义 144（PCE++ 与证书再申请 RFR）** 承诺条件在 IP-138 之上追加三项：`d_P(t)≥d_min(ℓ)`（L1 取 1，L2/不可逆取 2）、`MSC(c) 在 w_t 下可执行`、`¬unclaimed ∧ ¬design-around ∧ ¬blocked`。证伪事件 ν 触发 `Inv(ν)={c | ν 违反 F_c ∨ 违反 S_c ∨ 使 D_c 失执行资格}`，撤权/降级并停用所有 v_c<v_ν 的版本；随后必须**再申请**：用剩余预算产生新 claim 把 `min_t d_P(t)` 恢复到 d_min，否则绕行→降档→L2 协商→安全停。旧 claim 可作 continuation 复用，但须以当前配比重新验证 MSC，且版本必须晚于最近一次证伪。

## 2. 关键算法伪代码（完整版见产物区）

```python
def build_claim(ev, M, persona, level):          # IP-139/140 合流
    F = required_features(ev)                    # 全要件
    S = infer_scope(ev, M)                       # 声明覆盖的部署条件
    D = support_certificate(ev, M)               # 配比支持（IP-140）
    if scope_support_gap(S, D) > eta:            # 纸面权利要求 → 拒绝
        return None
    return Claim(F=F, S=S, D=D, v=now(), level=level)

def coverage_depth(P, t, dep_graph):             # IP-139
    cov = [c for c in P if c.valid and in_scope(c, t)]
    return len(quotient_by_common_cause(cov, dep_graph))

def msc_valid(c, w_t, rho_mix):                  # IP-140
    if D_chi2(w_t, c.D.pi) > rho_mix: return False
    if min(c.D.ess[z] for z in STRATA) < ESS_MIN: return False
    return max(c.D.ece_str[z] for z in STRATA) <= EPS_STR

def layout_acquire(P, threat, budget, w_pre):    # IP-141：覆盖深度/预算
    while budget.left > 0 and min_depth(P, threat) < d_goal:
        z = argmax_z marginal_min_coverage(P, z) / cost(z)
        P = irredundant_prune(P + [build_claim(probe(z), M) for _ in range(1)])
    return P

def design_around_monitor(t, P, M):              # IP-142：越界默认拒绝
    if not any(c.valid and in_scope(c, t) for c in P): return 'unclaimed'
    for c in P:
        if literal_all_elements(t, c) and not in_scope(c, t):
            if predicted_risk(t, M) > theta_da: return 'design_around'
    return 'ok'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SCP | O(\|P\|·\|𝒯\|) 评估；O(\|P\|²) 依赖图 | O(\|P\|·\|𝒯\|) | 独立族=共因商；单故障存活 |
| MSC | O(\|Z\|·N_cal)/claim | O(\|Z\|) | 逐层校准、权重截断、球外失效 |
| CDL | O(B·\|Z\|·Δ_cov) 贪心 | O(\|P\|) | 单调次模、(1−1/e)、预算终止 |
| DAM | O(\|P\|)/检查点 | O(1) | 越界默认不承诺、δ_da |
| PCR | O(\|𝒩\|·\|P\|·\|𝒯\|) | O(\|P\|) | 演练完备、scope–support gap≤η |
| PCE++ | 第 57 轮 + O(\|CP\|·(\|P\|·\|𝒯\|+B·\|Z\|)) | O(\|P\|+\|𝒯\|) | d≥d_min、再申请有界 |

**正确性定理（Portfolio–Mixture Soundness, PMS）** 在第 57 轮 A33–A40 之上追加：**(A41)** 权利要求诚实：`Scope(c)⊆Support_{ℬ}(c)`（无纸面权利要求，scope–support gap≤η）；**(A42)** 独立性声明诚实，G_P 的共因边是真实共同失效源的上界；**(A43)** 配比模糊集 `ℬ(π̂,ρ_mix)` 以高概率包含真实目标配比，密度比截断 M<∞，加权共形覆盖 ≥1−α；**(A44)** 失效演练不完备度 ≤δ_da（未检出的设计规避/共因失效）；**(A45)** NUC 不变量成立（不可逆接触不落在未覆盖/被负权利要求禁止的领土）。则：

1. **组合承诺健全性**：对 t∈𝒯，若 d_P(t)≥1 且所有覆盖 claim 的 MSC 可执行，则
   `P(fail|t) ≤ Σ_{c∈ℱ_P(t)} (δ_f+ε_meta(k)+δ_probe+ε_h+ε_str) + ρ_mix_pen(a) + δ_da`；当 d_P(t)≥2 且独立性诚实，任一条 claim 被单次证伪后剩余覆盖仍 ≥1，失效不再升级为整案崩塌。
2. **配比单调保守性**：目标配比移出 `ℬ`、某层 ESS 不足或某层 ECE 超限，只会使 claim **失去执行资格**（scope 收缩、深度下降、动作更保守），不存在"换配比让门更松"的升险路径；边际校准不得覆盖分层失败（Simpson 守卫）。
3. **无纸面安全**：若 `scope_support_gap(c)>η`，c 在构造期被拒；因此被计入深度的每一条 claim 都有与声明作用域相称的分层支持。
4. **终止与可恢复性**：每次证伪后，再申请消耗预算严格递减；PCE++ 在 `k_probes + B` 内终止于 {承诺, 绕行, L2 协商, 安全停}，且"无深度不承诺"。

## 4. 实验设计 E177–E181

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 独立性是声明而非事实（共因失效使深度虚高） | 高 | 依赖图上界 + 共因合并的悲观商 + 定期失效演练/红队；深度按最坏共因族计 |
| scope–support gap（纸面权利要求） | 高 | η 阈值构造期拒绝 + 逐层最坏支持 + 留出分层审计 + 证书可追溯 |

| 采集配比 Goodhart（刷证书） | 中高 | 预注册目标配比与威胁集 + 留出分层 + 偏离惩罚 δ_mix + 只认最坏分层 |

## 6. 本轮最大风险

**一句话**：本轮把安全从"一张证书"升级为"一组权利要求"，但最大的风险是**专利式安全表演**——组合看起来覆盖很深，实则多条 claim 共享同一个未声明的共因（同一元先验、同一份语料、同一个橡皮章操作者）或 scope 远宽于支持，于是**一次**真正的失效事件同时作废所有"看似独立"的权利要求，覆盖深度只是纸面数字；必须以共因悲观商、失效演练、scope–support gap 阈值与"未覆盖领土默认拒绝"四道审计，把"组合的广度"始终换算成"最坏分层、最坏共因下仍存活的独立证据族数"。

### IP-139 SCP（安全权利要求组合与覆盖深度）

```python
def make_claim(ev, M, persona, level):
    F = required_features(ev)              # 全要件：全部证据条件
    S = infer_scope(ev, M)                 # 声明覆盖的部署条件
    D = support_certificate(ev, M)         # IP-140
    if scope_support_gap(S, D) > eta:      # 纸面权利要求，拒绝
        return None
    return Claim(F=F, S=S, D=D, v=now(), level=level)

def in_scope(c, t):
    return c.S(t) and all(f(t) for f in c.F)

def coverage_depth(P, t, dep_graph):
    cov = [c for c in P if c.valid and in_scope(c, t)]
    families = quotient_by_common_cause(cov, dep_graph)   # 共因商：共享先验/语料/操作者合并
    return len(families)

def portfolio_k_fault_tolerant(P, threat, events, k, dep_graph):
    for nu in events:
        Q = P - Inv(P, nu)                 # 撤权被 ν 触及的 claim
        for t in threat:
            if coverage_depth(Q, t, dep_graph) < k:
                return False
    return True

def irredundant_prune(P, threat, dep_graph):
    for c in sorted(P, key=lambda x: x.support_width()):   # 先剪支持最窄的
        Q = [x for x in P if x is not c]
        if min_depth(Q, threat, dep_graph) >= min_depth(P, threat, dep_graph):
            P = Q                          # 删除不降低最坏深度者
    return P
```

### IP-140 MSC（配比支持证书与逐层校准）

```python
def support_certificate(ev, M):
    pi_c = empirical_mix(ev)               # 该批证据的训练配比
    ess  = {z: effective_sample_size(ev, z) for z in STRATA}
    ece  = {z: stratified_ece(ev, z) for z in STRATA}
    return Cert(pi=pi_c, ess=ess, ece_str=ece,
                rho_mix=rho_mix_from_prior(), M_cap=M_CAP)

def msc_valid(c, w_t, rho_mix):
    if divergence(w_t, c.D.pi) > rho_mix:      # 目标配比在球外
        return False
    if min(c.D.ess.values()) < ESS_MIN:        # 稀有分层无支持
        return False
    return max(c.D.ece_str.values()) <= EPS_STR  # Simpson 守卫：逐层而非边际

def weighted_conformal_msc(c, w_t, scores, alpha):
    weights = [min(M_CAP, w_t[z(s)] / c.D.pi[z(s)]) for s in scores]
    mass = sum(weights); upper = weighted_quantile(scores, weights, 1 - alpha)
    if mass < len(scores) * (1 - alpha):       # 未加权质量过大 → 失执行资格
        return None
    return upper                               # 覆盖 ≥1-α（A43）
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCP | O(\|P\|·\|𝒯\|) 评估；O(\|P\|²) 依赖图 | O(\|P\|·\|𝒯\|) | 共因商、k-失效容错、无冗余 |
| MSC | O(\|Z\|·N_cal)/claim | O(\|Z\|) | 逐层校准、权重截断、球外失效（A43） |
| CDL | O(B·\|Z\|·Δ_cov) | O(\|P\|) | 单调次模、(1−1/e)、预算终止 |
| DAM | O(\|P\|)/检查点 | O(1) | 未覆盖/规避默认拒绝（A44/A45） |
| PCR | O(\|𝒩\|·\|P\|·\|𝒯\|) | O(\|P\|) | 纸面拒绝、演练完备、版本停用 |
| PCE++ | 第 57 轮 + O(\|CP\|·(\|P\|·\|𝒯\|+B·\|Z\|)) | O(\|P\|+\|𝒯\|) | d≥d_min、RFR 有界、四态完备 |

**正确性定理（Portfolio–Mixture Soundness, PMS）**
假设 A22–A40 成立；追加：**(A41)** 权利要求诚实，`Scope(c)⊆Support_ℬ(c)` 且 scope–support gap≤η；**(A42)** 独立性声明诚实，G_P 的共因边是真实共同失效源的上界；**(A43)** 配比模糊集以高概率含真实目标配比，密度比截断 M<∞，加权共形覆盖 ≥1−α；**(A44)** 失效演练/越界监视漏检 ≤δ_da；**(A45)** NUC：不可逆接触不落在 unclaimed/design-around/负权利要求领土上。则：

1. **组合健全性**：对 t∈𝒯，若 `d_P(t)≥1` 且覆盖 claim 的 MSC 均可执行，则
   `P(fail|t) ≤ Σ_{c∈ℱ_P(t)}(δ_f+ε_meta(k)+δ_probe+ε_h+ε_str) + ρ_mix_pen(a) + δ_da`；
   若 `d_P(t)≥2`，任一单 claim 因证伪被撤权后剩余覆盖仍 ≥1，失效不升级为整案崩塌。
2. **保守单调性**：配比出球、某层 ESS 不足、某层 ECE 超限、版本陈旧，只使 claim 失去执行资格并降低覆盖深度，进而使动作更保守；不存在"改配比/加冗余让门更松"的升险路径。
3. **无纸面安全**：`scope_support_gap>η` 的 claim 在构建期即被拒；计入深度的每条 claim 都有与声明作用域相称的分层支持，Simpson 守卫禁止边际校准替代分层校准。
4. **终止与可恢复**：每次证伪后再申请严格消耗预算；PCE++ 在 `k_probes+B` 内终止于 {承诺, 绕行, L2 协商, 安全停}，且无深度/无配比/越界一律不承诺。

部署界（对检查点与威胁集取联合界）：

```
P_safe ≥ 1 − Σ_t [ Σ_{c∈ℱ_P(t)} (δ_f+ε_meta+δ_probe+ε_h+ε_str)
                  + ρ_mix_pen + δ_da ]
            − P(共因未并入 G_P) − P(目标配比出球未检出)
            − P(RFR 预算耗尽 ∧ 安全停失效)
```

关键：**覆盖深度把"证据数量"换成"失效后仍存活的独立线数"**；**配比证书把"在语料上安全"收紧为"在部署配比球内安全"**；**scope–support gap 把"声称覆盖"与"实际支持"强制对齐**；**负权利要求与 NUC 把未覆盖领土从默认安全翻转为默认拒绝**。

## 6. 本轮最大风险

**一句话**：本轮把安全升级为"权利要求组合"，但最大风险是**专利式安全表演**——覆盖深度看起来很高，实则多条 claim 共享同一个未声明的共因（同一元先验/同一份语料/同一个橡皮章操作者）或作用域远宽于其支持，于是一次真实的失效事件同时作废所有"看似独立"的权利要求；必须以共因悲观商、定期失效演练、scope–support gap 阈值与"未覆盖领土默认拒绝"四道审计，始终把组合广度换算成"最坏分层、最坏共因下仍存活的独立证据族数"。
