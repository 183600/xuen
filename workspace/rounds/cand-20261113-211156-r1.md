# 第 69 轮（承接第 68 轮「CALM-RAS」IP-243~252；灵感循环下一轮；本轮灵感：「对比实验」×「碰撞避免」）

> 第 68 轮 CALM-RAS 把「标定」升级为在线潜变量，用自监督与单模型多任务为「测量可信度」建模，但它自陈的最大风险暴露了一个更深层的元问题：**整个闭环没有独立参照系，一切验证都是自指的**。COF 用残差解释残差，CFA 用标定解释故障，CAC 用金标集验证适配器——而金标集本身仍是同一套传感器的产物。当漂移与故障共享一个有规范自由度（gauge）的参数空间时，「先标定后归因」的失败不是判据不够强，而是**可辨识性根本缺失**：标定能力越强，落在标定子空间里的慢故障就越隐形。
>
> 本轮两个灵感恰好提供打破自指的两把钥匙：
> - **碰撞避免**：碰撞与近失（near-miss）是物理世界给出的、任何标定都吸不走的**绝对标签**。屏障函数 h(x) ≥ 0 是一条不依赖学习模型的独立测量通道——它测的不是「传感器读数对不对」，而是「机器人的安全裕度是不是真的还在」。屏障不只是约束，更是最好的免费标签生成器。
> - **对比实验**：科学的因果归因从来不是「观测一次然后相信」，而是「设计对照、做差、看差异能否被原假设解释」。把**差分算子**嵌入闭环：同一物理量用两条独立通道测、同一动作做镜像对照、主动施加已知微扰看响应——**加性共模漂移在差分中精确抵消，只有通道特有/乘性故障才留下印记**。
>
> 核心命题：
>
> **把「碰撞避免屏障」升格为独立物理 oracle，把「对比实验」升格为在线因果探针——COBRA-RAS（Collision-Oracle Barrier + Randomized Active-contrast RAS）：系统主动设计安全的对照实验去逼近（但不越过）安全边界，用差分信号与屏障误差共同打破 R68 的标定自指，并显式地把「不可辨识子空间」当作已计量风险而非隐形失败来对待。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**凭什么相信这个『准』？拿什么独立参照来证明？**」——当自证不足时，转向受控对照与物理锚点。

## 0. 直觉与动机

**灵感 1（碰撞避免 → 屏障是唯一不可被标定吸收的物理标签）**
直觉：R68 的所有风险都指向同一个病灶——系统的「真值」来自自己。可机器人有一个天然的外生真值：它有没有撞上东西、离撞上还有多远。碰撞是二值的、物理的、不可伪造的（除非传感器坏了，而检测它恰恰是目的）。更关键的是**近失**：不必真撞，安全裕度的实测值与预测值之差 e_B = h_realized − h_predicted 就是一条持续的、免费的、绝对尺度的残差通道；它活在任务空间，而非传感器残差空间，因此任何只在 S_cal 内部做手脚的标定漂移都动不了它。把 barrier 从「约束」升级为「oracle」：同一套物理量既是安全边界，又是监督信号。

**灵感 2（对比实验 → 差分算子是漂移的零空间，是故障的显影剂）**
直觉：经典差分测量：若 y = g + b + f，b 为加性共模漂移，则差分 D_δ y = y(x+δ) − y(x) 中 b 精确消去，只剩 D_δ g + D_δ f。也就是说**加性共模漂移落在差分算子的核里**——这恰好是 R68 的 COF 能吸收的那一类。反过来，凡是能穿过差分仍不被模型解释的部分，就是「标定无法吸收」的通道特有权重：乘性增益、单通道偏移、非线性畸变、时变耦合。这不是又一次估计，而是一次**正交投影**：把可辨识分量投影到 S_cal^⊥，让慢故障无处藏身。跨通道对照（视觉 vs 触觉 vs 独立测距）、时域镜像对照（正/反动作）、干预对照（施加已知 δu 看响应）是三种可工程化的对照。

**灵感 3（两者合流 → 从「自证」到「对照 + 锚定」，并显式记账不可辨识部分）**
直觉：差分回答「通道之间谁歪了」，屏障回答「整机是否已偏离物理真实」；两者之并覆盖了 S_cal 之外的大部分方向。但必须诚实：若所有通道共享同一物理源头（同一块 IMU、同一套标定基准），就存在**规范自由度（gauge）**——某些扰动对所有观测都不产生可区分的变化，任何算法都无法辨识。R68 的错不是没辨识出，而是假装能辨识。本轮的纪律是：**把不可辨识子空间显式算出来、量化其风险、并强制其进入最坏情况回退**。能辨识的用对照杀死，不可辨识的用证书承认。

**灵感 4（五组件 + 继承核）**
1. **CAB Collision-Avoidance Barrier oracle**：认证 CBF + 冗余物理通道（接触开关 / 电容皮 / 独立测距）+ 近失事件 → 绝对标签 e_B；
2. **CEP Comparative Experiment Protocol**：安全预算内的跨通道 / 镜像 / 干预三类配对实验 → 差分统计量 Δ；
3. **SPS Safe Probing Scheduler**：用屏障证书给探针定量预算，按信息增益最大化做最优实验设计；
4. **DCA Differential Causal Attribution**：用 (Δ, e_B) 做漂移 / 通道故障 / 乘性故障 / 环境变化的四分类，替代 R68 的两分类；
5. **GAM Gauge Accounting Module**：计算并证书化不可辨识子空间与残余风险，不可辨识即升级保守；
6. **RAS-WM†/CALM 继承核**：MTM/SSG/COF/CFA/CAC 全部保留，CAC 增加「对比关」，VQAuditor 增加屏障审计。

**灵感 5（对 R68 风险的对症下药）**
- R68「缓变故障被标定吸收」：DCA 的差分通道专检 S_cal 核外的乘性/通道分量；落在核内的由 CAB 的物理锚点兜底；两者都不覆盖的由 GAM 显式标为不可辨识并强制 λ 抬升。
- R68「标定红线悖论」：红线改由独立物理 oracle 校准，不再由同一传感器自证。
- 共同的「过度放宽」通道：任何 Unidentifiable / 探针预算耗尽 / 近失统计不足，都只导向收紧，绝不放宽。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（COBRA-RAS 总览）** COBRA-RAS = (CAB, CEP, SPS, DCA, GAM, RAS-WM†)。新增三条不变式：
(iv) **独立参照不变式**：安全相关判据必须至少有一个不经过学习标定链的物理通道支撑（接触 / 独立测距 / 屏障实测），否则视为不可辨识；
(v) **探针安全不变式**：任何主动对比实验必须满足最坏情况屏障证书 h_min ≥ ε_probe > 0，且探针预算从当前安全裕度中扣除；
(vi) **诚实记账不变式**：不可辨识子空间必须每轮显式估计并写入证书，未覆盖方向不得声称已检测。

**定义 294（屏障 oracle）** 取 CBF h: X → ℝ，安全集 S = {x : h(x) ≥ 0}，离散条件 h(x_{t+1}) ≥ (1−γ)h(x_t)。oracle 输出三元组 o_B = (h_t^real, ĥ_t, N_t)，N_t 为近失计数；屏障预测误差 e_B(t) = h_t^real − ĥ_t。**关键**：h^real 由冗余物理通道测得/触发（接触开关、电容皮、独立认证测距），与标定链解耦，因此 e_B 对标定漂移免疫。

**定义 295（差分算子与共模抵消）** 对观测 y = g(x,c) + f + ε，在对照对 (x, x+δ) 上定义差分 D_δ y = y(x+δ) − y(x)。若漂移为加性共模，b(x+δ) = b(x)，则 D_δ y = D_δ g + D_δ f + D_δ ε，b 精确消去。三类对照：跨通道 δ_ch（同一 x、不同模态）、镜像 δ_mir（互为反向的动作/视角）、干预 δ_int（施加已知微扰 u+δu）。差分向量 Δ_t = (Δ_ch, Δ_mir, Δ_int)。

**定义 296（可辨识性分解）** 由标定敏感矩阵 J_c = ∂r/∂c、差分算子 D、屏障敏感矩阵 J_B = ∂e_B/∂x 组成观测算子 O = [J_c; D; J_B]。不可辨识子空间 G = ker(O)，可辨识子空间为其正交补 G^⊥。任一扰动 f 分解为 f_∥ ∈ G^⊥（可检出）与 f_⊥ ∈ G（不可检出）。**COBRA 的目标不是消灭 G，而是把 dim G 压到最小、并对 f_⊥ 显式记账。**

**定义 297（CEP 对照实验）** 一个对照实验 e = (type, δ, R_e, n_e)，type ∈ {ch, mir, int}，在预算内重复 n_e 次，输出差分统计量 Δ̄_e 与协方差 Σ_Δ。协议须使零假设下 E[Δ̄_e | 无故障] = 0，则故障检验量 z_e = Δ̄_eᵀ Σ_Δ⁻¹ Δ̄_e ~ χ²。

**定义 298（SPS 安全探针调度）** 探针库 E，安全裕度预算 B_t = h_t − ε_probe。选 e 使单位成本信息增益最大：max_π E[I(θ; Δ)] s.t. P(h_min(e) < ε_probe) ≤ δ_s 且累积 cost ≤ B_t（约束 D-最优实验设计 / 带约束 bandit）。预算随 h 恢复按速率 ρ_B 补充；预算耗尽即转被动模式。

**定义 299（DCA 微分因果归因）** 假设集 {drift_gauge, drift_channel, fault_multiplicative, fault_additive_channel, env_change}，
P(cause | Δ, e_B) ∝ p(Δ | cause)·p(e_B | cause)·P(cause)。
判别规则：Δ≈0 ∧ e_B≈0 → 纯共模加性漂移（gauge，不可辨识）；Δ≈0 ∧ |e_B|>τ_B → 共模故障（物理锚点命中）；Δ 显著 ∧ e_B≈0 → 通道故障但任务无关；Δ 显著 ∧ e_B 显著 → 通道故障且安全相关（最高优先级）。比 R68 的 H_cal/H_sensor^trans 两分类多出「任务相关性」维度。

**定义 300（GAM 规范记账）** Ĝ_t = ker(Ô_t) 的数值估计（SVD 截断，阈值 τ_svd）。残余风险
R_gauge = sup_{f∈Ĝ, ‖f‖≤ρ_f} P(|τ_cmd − τ*| > ε; f)。
若 R_gauge > ρ_risk 或 dim Ĝ 上升，触发保守升级（λ_floor 抬升 + k 收缩）。dim Ĝ 与 R_gauge 写入证书。

**定义 301（CAC 对比关，第六关）** 适配器不得降低差分/屏障检出裕度：z_e^{θ′} ≥ (1−ε_c)·z_e^{θ} 且 e_B 的可观测性不降；否则一票否决——防「适配器把对照信号解释掉」。

**定义 302（J_COBRA 证书）** J_COBRA = (J_CALM, barrier_hash, gauge_dim, R_gauge, probe_log_hash, contrast_margin, cobra_ver)。
Valid ⇔ Valid(J_CALM) ∧ dim Ĝ ≤ d_gauge^max ∧ R_gauge ≤ ρ_risk ∧ 独立参照不变式成立（定义 293-iv）。

**定义 303（AIC-COBRA 干扰集）** ℰ_COBRA = ℰ_CALM × ℰ_CAB × ℰ_CEP × ℰ_GAM；
ℰ_CAB = {oracle 非独立、近失漏计、屏障证书失效}；ℰ_CEP = {探针越界、对照伪相关、预算饥饿}；ℰ_GAM = {gauge 低估、残余风险漏报}。

**定义 304（近失标签生成）** 近失事件 n_t = 1[0 < h_t^real < ε_near]。近失率 λ_near 是真实安全裕度的无模型估计；e_B 的漂移检验用泊松/负二项比例检验。稀有事件决定检测延迟下界（信息论约束）。

**定义 305（独立参照判据）** 通道 A、B 独立，当且仅当二者噪声源与标定基准不共享祖先节点（因果图 d-分离）；可操作化为 I(A; B | 真实物理量) < ε_ind。共享同一物理源头即判非独立，其对照不计入 S_contrast——这条防止「虚假交叉验证」。

**定义 306（探针-安全 Pareto）** 信息增益 I 与最小屏障裕度 ε_probe 的可行域边界；给定风险偏好 β，选 Pareto 前沿上的工作点，探针幅度 w* = argmax_{w} [I(w) − β·risk(w)]。

**定义 307（三通道二选二冗余）** barrier oracle 需 ≥3 条独立通道中至少 2 条一致才可判安全（2-out-of-3），否则降级为被动并触发 λ_floor。继承航空冗余理念，专门防御「独立通道被同源污染」。

**定义 308（COBRA 管线）** 离线：CAB 出厂认证 + 独立基准标定 + 初始 GAM。在线：每 T_probe 周期由 SPS 调度安全对照 → CEP 收集差分 → DCA 归因 → GAM 更新 gauge → CAC（含对比关）提交；近失事件实时触发优先归因并刷新 e_B。继承 R68 的「实时流零学习写操作」：对照与归因全部异步，实时环只额外承担屏障 QP 求解。

# IP-253 CAB：碰撞避免屏障 oracle（独立物理通道 + 2-out-of-3）
class CollisionAvoidanceBarrier:
    def __init__(self, cbf, channels, eps_probe, eps_near):
        self.cbf, self.ch, self.eps_probe, self.eps_near = cbf, channels, eps_probe, eps_near

    def step(self, x, u):
        h_pred = self.cbf.predict(x, u)                 # 模型预测裕度
        votes  = [c.read() for c in self.ch]            # 独立物理通道
        h_real = minority_override(votes, k=2)          # 三选二；冲突即降级
        e_B = h_real - h_pred
        near = 0 < h_real < self.eps_near
        return {'h_pred': h_pred, 'h_real': h_real, 'e_B': e_B,
                'near_miss': near, 'degraded': len(set(votes)) > 1}

    def certificate(self, x, u):                        # 探针安全证书
        return self.cbf.worst_case(x, u)               # h_min 的下界


# IP-254 CEP：对比实验协议（三类对照，零假设期望为 0）
class ComparativeExperimentProtocol:
    def design(self, kind, replay, pool):
        if kind == 'ch':   return self.cross_channel_pairs(replay)
        if kind == 'mir':  return self.mirror_action_pairs(replay)
        if kind == 'int':  return self.known_perturbation_pairs(replay, pool)

    def run(self, pairs):
        deltas = [self.D(pair.a, pair.b) for pair in pairs]   # D_delta y
        return {'mean': np.mean(deltas, 0), 'cov': np.cov(np.array(deltas).T),
                'z': chi2_stat(deltas)}


# IP-255 SPS：安全探针调度（信息增益/成本 带约束最大化）
class SafeProbingScheduler:
    def select(self, pool, h, B):
        feasible = [e for e in pool if self.cab.certificate(e) >= self.eps_probe
                    and e.cost <= B]
        if not feasible:
            return None                                # 预算耗尽 → 被动模式
        return max(feasible, key=lambda e: e.info_gain / max(e.cost, 1e-6))


# IP-256 DCA：微分因果归因（四分类，Δ 与 e_B 联判）
def differential_causal_attribution(delta_stats, e_B, prior):
    H = ('drift_gauge', 'drift_channel', 'fault_mult', 'fault_add_ch', 'env')
    post = {}
    for h in H:
        post[h] = likelihood_delta(h, delta_stats) * likelihood_barrier(h, e_B) * prior[h]
    return normalize(post)


# IP-257 GAM：规范记账（不可辨识子空间 + 残余风险）
class GaugeAccounting:
    def update(self, J_c, D, J_B):
        O = np.vstack([J_c, D, J_B])                   # 观测算子
        U, S, Vt = np.linalg.svd(O)
        r = int((S > self.tau_svd).sum())
        self.G = Vt[r:]                                # ker(O) 的基
        self.dim = self.G.shape[0]
        self.R_gauge = self.worst_case_risk(self.G)    # sup_{f in G} 风险
        return self.dim, self.R_gauge


# IP-262 主闭环：COBRA round
def COBRA_round(M, obs):
    x_prime = M.lsf.fuse(M.usr.fuse(*obs[:4]))
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)      # R68 前向保留

    # 1) CAB：屏障 oracle（实时）
    b = M.cab.step(M.state, M.u_prev)                          # h_real, e_B, near
    if b['degraded']:
        M.mode = 'passive'; M.lam_floor = max(M.lam_floor, 0.8)

    # 2) SPS+CEP：安全对照（异步/影子；实时只读结果）
    e = M.sps.select(M.probe_pool, b['h_real'], M.budget)
    if e is not None:
        ds = M.cep.run(M.cep.design(e.kind, M.replay, M.pool))
        M.budget -= e.cost
    else:
        ds = M.cached_delta                              # 预算耗尽沿用上次

    # 3) DCA：差分 + 屏障 四分类（替代 R68 两分类）
    cause = M.dca(ds, b['e_B'], M.prior)
    unidentifiable = (cause['drift_gauge'] > 0.5) or (M.gam.dim > M.gam.max_dim)

    # 4) GAM：显式记账，不可辨识即收紧
    dim_G, R_gauge = M.gam.update(M.J_c, M.D, M.J_B)
    if R_gauge > M.rho_risk:
        M.lam_floor = max(M.lam_floor, 0.8); M.k_shrink = True

    # 5) 归因与风险缩放（继承 R68 CFA/EFS，条件于 cause）
    joint_post = M.cfa(M.fir_signature(z, M.residual_log), o['pi'], M.cof.c, M.cof.U)
    lam = max(M.efs.risk_scale(joint_post), M.lam_floor,
              0.8 if (unidentifiable or b['near_miss']) else 0.6)

    # 6) 认证前缀（继承 C-RAS-WM，加 gauge 收缩）
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, joint_post, M.m_ras, M.alpha_chunk, M.wm_preds)
    if unidentifiable: k = min(k, k_gauge_shrink(A, dim_G))

    # 7) 控制 + 异步审计/提交（CAC 对比关）
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_b.submit_async(b, ds, cause, {'dim_G': dim_G, 'R_gauge': R_gauge})
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit, contrast_gate=ds)
    return k, lam, cause, (dim_G, R_gauge)

## 3. 推导

**引理 16（差分消漂移）** 若漂移为加性且共模，b(x+δ) = b(x)，则由线性性 D_δ b = 0，Δ 中不含 b。因此 Δ 对 S_cal 内的加性分量免疫，只对乘性/通道特有条件敏感。
系：R68 COF 能吸收的加性慢漂移恰是差分算子的零空间——差分不会把它误报为故障，也不给标定吸收乘性故障的机会。二者在频域与代数上互补。

**引理 17（可辨识秩界）** dim G = dim R − rank([J_c; D; J_B])。每增加一个独立对照方向，rank 至多 +1；屏障 oracle 每次有效近失提供至多 1 个独立约束（定义 294、305）。若传感器完全共源且无独立物理锚点，则 G 包含全部共模慢变量，慢故障不可辨识——这是 R68 原罪的严格表述。COBRA 通过 J_B 与 D 提升 rank，但**不能凭空消除 G**；这正是 GAM 必须存在的理由。

**引理 18（探针安全界）** 在证书 h_min ≥ ε_probe 与模型误差界 |ĥ − h| ≤ ρ_m 下，单次探针碰撞概率 p_probe ≤ exp(−(ε_probe − ρ_m)² / (2σ_B²))；n 次独立探针累积 ≤ 1 − (1 − p_probe)^n。故信息与安全之间存在显式 Pareto 前沿（定义 306）：探针不是免费的，安全裕度就是购买信息的货币。

**定理 16（COBRA 风险一致性）** 在 R68 的 A87–A94 与本轮 A95–A98（独立参照、加性漂移、证书有效、近失可观测）下：
1. P(|τ_cmd − τ*| > ε) ≤ α_chunk + δ_fi + α_emotion + α_wm + α_vqa + α_cal + **α_contrast + α_B + R_gauge**；
2. 对任意带宽 ω_f 的慢故障，若其分量落在 G^⊥，检测概率 ≥ 1−δ 在 T_detect 内成立——**不再要求 ω_f ≥ 3ω_cal**，R68 引理 13 的 3 倍带宽假设被移除；
3. 落在 G 内的分量由 R_gauge 显式计入，且强制 λ_risk ≥ λ_floor(U, R_gauge)——测量不可信或不可辨识，永远导向收缩；
4. 近失事件使 e_B 获得一次独立约束，dim G 单调不增（无新增共源时）。

**定理 17（主动探针安全性）** 若 CAB 证书有效、SPS 满足预算约束、且 2-out-of-3 冗余成立，则主动对比实验不增加碰撞概率上界（≤ 基线 + n·p_probe）；任一证书失效即回退被动模式（零探针）。这保证「用安全换信息」的交易始终在控制之下。

## 6. 本轮最大风险

**一句话**：COBRA 的全部安全性押在「屏障 oracle 真的独立」这一前提上——**若 barrier 也由同一套传感器计算，它与 COF 共享祖先节点，共模漂移会被 DCA 同时「解释」进测量与参照两条通道，制造出虚假的交叉验证，gauge 不降反升；更隐蔽的是，探针要消耗安全裕度去购买信息，对一个尚未被检出的缓变故障，那次「安全」探针可能正是把它从未检出推向首次碰撞的动作**——这是「用对照与锚点打破自指」范式的原罪：参照系与被测对象的独立性，无法由系统自身证明。

**次级风险与缓解**：
1. **近失稀有 → 检测延迟长**：泊松比例检验 + 主动探针补样本 + 延迟下界写入证书；
2. **探针预算饥饿**：安全裕度不足时自动转被动，用缓存 Δ 并抬升 λ_floor；
3. **对照伪相关**：δ 的选择与故障耦合 → 随机化 δ + 独立性检验（定义 305）；
4. **gauge 低估**：SVD 截断阈值 τ_svd 保守设置 + 有效秩监控 + 低估即全局降级；
5. **2-out-of-3 共谋失效**：三条通道尽量跨物理原理选型（光学/接触/惯性），并纳入 J_COBRA 版本链。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 独立参照不变式（安全判据需不经学习标定链的物理通道支撑）；探针安全不变式（h_min ≥ ε_probe，预算从安全裕度扣除）；诚实记账不变式（不可辨识子空间必须显式估计入证）。

**定义 294（屏障 oracle）** 离散 CBF `h(x_{t+1}) ≥ (1−γ)h(x_t)`；输出 `(h_real, ĥ, N)`，`e_B = h_real − ĥ`，h_real 由冗余物理通道测得，与标定链解耦。

**定义 297（CEP）** 对照实验 `e=(type, δ, R_e, n_e)`，零假设 `E[Δ̄|无故障]=0`，检验量 `z_e = Δ̄ᵀΣ_Δ⁻¹Δ̄ ~ χ²`。

**定义 298（SPS）** `max_π E[I(θ;Δ)] s.t. P(h_min < ε_probe) ≤ δ_s, cost ≤ B_t`；预算按 ρ_B 恢复。

**定义 299（DCA）** 假设集 {drift_gauge, drift_channel, fault_mult, fault_add_ch, env}；`P(cause|Δ,e_B) ∝ p(Δ|cause)p(e_B|cause)P(cause)`；Δ≈0∧e_B≈0 为 gauge 不可辨识，Δ≈0∧|e_B|>τ_B 为共模故障（锚点命中）。

**定义 300（GAM）** `Ĝ = ker(Ô)`（SVD 截断）；`R_gauge = sup_{f∈Ĝ,‖f‖≤ρ_f} P(|τ_cmd−τ*|>ε; f)`；超界即保守升级。

**定义 301（CAC 对比关）** `z_e^{θ′} ≥ (1−ε_c)z_e^{θ}` 且 e_B 可观测性不降，否则一票否决。

**定义 302–303（证书 / 干扰集）** `J_COBRA = (J_CALM, barrier_hash, gauge_dim, R_gauge, probe_log_hash, contrast_margin, cobra_ver)`；`ℰ_COBRA = ℰ_CALM × ℰ_CAB × ℰ_CEP × ℰ_GAM`。

**定义 304–305（近失标签 / 独立判据）** `n_t = 1[0 < h_real < ε_near]`；独立性用因果图 d-分离或 `I(A;B|真实量) < ε_ind` 判定，共源通道不计入 S_contrast。

**定义 306–307（Pareto / 冗余）** 信息-安全 Pareto 前沿上按风险偏好 β 选点；barrier oracle 需 ≥3 通道中 2 条独立一致（2-out-of-3），冲突即降级。

# IP-253 CAB：屏障 oracle，独立物理通道 + 2-out-of-3
class CollisionAvoidanceBarrier:
    def step(self, x, u):
        h_pred = self.cbf.predict(x, u)
        votes  = [c.read() for c in self.ch]                 # 独立通道
        h_real = minority_override(votes, k=2)               # 三选二
        return {'h_pred': h_pred, 'h_real': h_real,
                'e_B': h_real - h_pred,
                'near_miss': 0 < h_real < self.eps_near,
                'degraded': len(set(votes)) > 1}
    def certificate(self, x, u):
        return self.cbf.worst_case(x, u)                     # h_min 下界

# IP-254 CEP：三类对照，零假设期望 0
class ComparativeExperimentProtocol:
    def design(self, kind, replay, pool):
        return {'ch':  self.cross_channel_pairs,
                'mir': self.mirror_action_pairs,
                'int': lambda r: self.known_perturbation_pairs(r, pool)}[kind](replay)
    def run(self, pairs):
        deltas = [self.D(p.a, p.b) for p in pairs]           # D_delta y
        return {'mean': np.mean(deltas, 0), 'cov': np.cov(np.array(deltas).T),
                'z': chi2_stat(deltas)}

# IP-255 SPS：信息增益/成本 带安全约束最大化
class SafeProbingScheduler:
    def select(self, pool, h, B):
        feasible = [e for e in pool
                    if self.cab.certificate(e) >= self.eps_probe and e.cost <= B]
        if not feasible: return None                         # 转被动
        return max(feasible, key=lambda e: e.info_gain / max(e.cost, 1e-6))

# IP-256 DCA：Δ 与 e_B 联判的四分类
def differential_causal_attribution(ds, e_B, prior):
    H = ('drift_gauge','drift_channel','fault_mult','fault_add_ch','env')
    post = {h: likelihood_delta(h, ds)*likelihood_barrier(h, e_B)*prior[h] for h in H}
    return normalize(post)

# IP-257 GAM：不可辨识子空间 + 残余风险
class GaugeAccounting:
    def update(self, J_c, D, J_B):
        U, S, Vt = np.linalg.svd(np.vstack([J_c, D, J_B]))
        r = int((S > self.tau_svd).sum())
        self.G = Vt[r:]; self.dim = self.G.shape[0]
        self.R_gauge = self.worst_case_risk(self.G)
        return self.dim, self.R_gauge

## 4. 推导

**引理 16（差分消漂移）** 加性共模漂移 `b(x+δ)=b(x)` ⇒ `D_δ b = 0`，故 Δ 对 S_cal 内加性分量免疫，只对乘性/通道特有条件敏感。系：R68 COF 能吸收的加性慢漂移恰是差分算子的零空间——差分既不误报它，也不给标定吸收乘性故障的机会，二者代数互补。

**引理 17（可辨识秩界）** `dim G = dim R − rank([J_c; D; J_B])`。每增加一个独立对照方向 rank 至多 +1；每次有效近失提供至多 1 个独立约束。若传感器完全共源且无独立物理锚点，则 G 含全部共模慢变量，慢故障不可辨识——R68 原罪的严格表述。COBRA 提升 rank，但不能凭空消除 G；这正是 GAM 存在的理由。

**引理 18（探针安全界）** 在 `h_min ≥ ε_probe` 与 `|ĥ−h| ≤ ρ_m` 下，单次探针碰撞概率 `p_probe ≤ exp(−(ε_probe−ρ_m)²/(2σ_B²))`；n 次累积 `≤ 1−(1−p_probe)^n`。信息与安全存在显式 Pareto 前沿——探针不是免费的，安全裕度是购买信息的货币。

**定理 16（COBRA 风险一致性）** A87–A98 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_contrast+α_B+R_gauge`；
2. 对任意带宽 ω_f 的慢故障，若落在 G^⊥，检测概率 ≥ 1−δ 在 T_detect 内成立——**R68 引理 13 的 ω_f ≥ 3ω_cal 假设被移除**；
3. 落在 G 内的分量由 R_gauge 显式计入并强制 `λ_risk ≥ λ_floor`；
4. 近失事件给 e_B 增加一次独立约束，dim G 单调不增（无新增共源时）。

**定理 17（主动探针安全性）** CAB 证书有效 + SPS 预算约束 + 2-out-of-3 冗余 ⇒ 主动对照不增加碰撞概率上界（≤ 基线 + n·p_probe）；任一证书失效即回退被动（零探针）。用安全换信息的交易始终受控。

## 7. 本轮最大风险

**一句话**：COBRA 的全部安全性押在「屏障 oracle 真的独立」这一前提上——**若 barrier 也由同一套传感器计算，它与 COF 共享祖先节点，共模漂移会被 DCA 同时「解释」进测量与参照两条通道，制造出虚假的交叉验证，gauge 不降反升；更隐蔽的是，探针要消耗安全裕度去购买信息，对一个尚未被检出的缓变故障，那次「安全」探针可能正是把它从未检出推向首次碰撞的动作**——这是「用对照与锚点打破自指」范式的原罪：参照系与被测对象的独立性，无法由系统自身证明。

**次级风险与缓解**：近失稀疏导检测延迟（泊松比例检验 + 主动探针 + 延迟下界入证）；探针预算饥饿（自动被动 + 缓存 Δ + 抬升 λ_floor）；对照伪相关（随机化 δ + 独立性检验）；gauge 低估（保守 τ_svd + 有效秩监控 + 低估即全局降级）；2-out-of-3 共谋失效（跨物理原理选型：光学/接触/惯性，纳入 J_COBRA 版本链）。
