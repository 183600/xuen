### 第 1 轮灵感驱动研究记录（新循环；继承上一循环 CADVS-v4）

**灵感词**：多模态大模型、力控

**继承关系**：上一循环第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM）基础上追加价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，软评分 ECS_v4 = ECS_v3 · η_val · η_bal，执行集 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v4，而是引入「多模态大模型」作为语义—物理接地层、以「力控」作为接触富操作的可执行底座，形成 CADVS-v5（IP-493~497），执行集升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **语义鸿沟：七锚点验证「对不对」，却不验证「懂不懂」**。v4 的七锚点分别验证空间覆盖、物理可行、人因意图、末端保真、记忆可靠、价值对齐、动力学稳定，但它们都默认「任务语义与物体可供性已被正确给定」。真实场景中，同一句「轻拿鸡蛋」/「插进去」在视觉-语言-力觉上是模糊的：轻是几牛？插多深？什么朝向？MLLM 擅长把多模态上下文解析成结构化语义，但其输出是概率性的、不可直接验证的，不能原样当作安全证据。

2. **力控是语义落地的物理语言，也是 MLLM 幻觉的放大器**。语言里的「轻」「稳」「贴合」最终都体现为力/力矩/阻抗/接触时序约束。若把 MLLM 的语义解析直接编译成力指令，一次幻觉就可能变成真实世界的过力、冲击或滑脱。因此关键不是「让 MLLM 控力」，而是「让 MLLM 产出可被证明保守的力包络」。

3. **核心洞见：把不可验证的生成模型，转成可验证的证据源**。引入两个新锚点与一个快路径：
   (a) **语义—力接地锚（MFGK + CFAC）**：MLLM 把多模态上下文 o 映射为参数化力可供性包络 ξ̂（逐任务相位：接近/抓取/搬运/插入/释放）；再用共形风险控制（Conformal Risk Control, CRC）在校准集上学收缩量 λ̂，使强制包络 E_λ̂ 超出真实安全集 E* 的风险 ≤ α，且该保证**分布无关、不依赖 MLLM 本身正确**。产出接地证书 FGC。
   (b) **接触一致性锚（CCK）**：视觉/触觉/力三模态各自估计接触状态（自由/接触/滑移/冲击），用对数线性池化融合，输出接触证书 CCC = (s*, p*, κ, t)，κ 为跨模态一致性；硬门要求高置信 + 高一致，否则 fail-closed，专抓「视觉说接触、力说自由」这类跨模态冲突。
   (c) **力安全滤波器（FSF）**：把 E_λ̂ 编译为 1 kHz 的 CBF-QP 投影层，对力包络做前向不变约束，MLLM 的慢推理完全离开控制环——正面回应 v4 的最大风险（实时性）。

**关键洞见**：v4 七锚点回答「覆盖/物理/人因/末点/记忆/价值/平衡」；v5 追加「语义—力接地」回答「机器人是否把多模态指令正确理解为力约束」、追加「接触一致性」回答「三模态对接触的认知是否一致」，并用「共形风险控制 + 快速力安全滤波」把不可验证的 MLLM 变成 fail-closed 的证据源。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_ground ∧ kc_contact，fail-closed；软评分 ECS_v5 = ECS_v4 · η_ground · η_contact。

**形式化目标（增量）**：
1. 定义多模态上下文 o_t = (I_{t−T:t}, ℓ, f_{t−T:t}, q_{t−T:t}) 与参数化力可供性包络 E(ξ)，接地映射 g_θ: o ↦ ξ̂。
2. 定义 CFAC 共形风险控制：非一致性/风险分数 s_i(λ)，阈值 λ̂ = inf{λ : (Σ_i s_i(λ) + 1)/(n+1) ≤ α}；接地证书 FGC = (E_λ̂, λ̂, α, H_sem, t)，硬门 kc_ground，软因子 η_ground = 1 − λ̂/λ_max。
3. 定义接触状态融合 p_fused ∝ Π_m p_m^{w_m} 与一致性 κ = 1 − max_{m≠m'} JS(p_m‖p_m')，接触证书 CCC，硬门 kc_contact，软因子 η_contact = p*·κ。
4. 定义 FSF：力包络上的 CBF h(F) = boundary − a^T F ≥ 0，CBF-QP 投影 + 通过性约束，前向不变性；不可行时回退最保守核 E_core。
5. 定义双时标安全组合定理：在 MLLM 延迟 Δ、包络陈旧收缩 δ(Δt) 下，组合系统仍以 ≥ 1−α−O(ε_shift) 保持安全。
6. 定义接地覆盖定理（分布无关）、接触一致性可靠性界、九锚点互补完备性。
7. 定义 EFA-v5 与 Exec_CADVS-v5 ⊆ Exec_CADVS-v4：在 v4 每条路径上追加 kc_ground（准入/相位切换时）与 kc_contact（控制环内），只缩不涨。

**本轮最大风险**：**共形接地的分布无关保证依赖校准集与部署上下文可交换**；面对新物体/新任务/新接触模式，MLLM 的力包络可能「自信地错」，共形覆盖静默失效，把概率性幻觉包装成被认证的硬门——这比不加接地更危险，因为它带来虚假的安全感。

## 2. 关键算法骨架

### IP-493 MFGK：多模态语义—力接地（异步，秒级，不在控制环）

```python
@dataclass
class MultimodalForceGroundingKernel:
    """MFGK：MLLM 把多模态上下文解析为相位化力可供性包络；自一致性防幻觉"""
    mllm: Any                       # Qwen-VL / LLaVA / GPT-4V 等
    schema: ForceEnvelopeSchema
    k_samples: int = 5              # 自一致性采样数
    tau_entropy: float = 0.3        # 语义熵阈值

    def ground(self, obs: MultimodalContext, t_now: float) -> tuple[ForceEnvelope, float]:
        # 1) 结构化抽取：图像窗口 + 语言 + 力/触觉历史 -> 力包络参数
        outs = [self.mllm.parse(obs, self.schema) for _ in range(self.k_samples)]
        xi_hat = self._robust_aggregate(outs)      # 逐参数取中位数
        H_sem = self._semantic_entropy(outs)       # 采样间分歧（防幻觉）
        # 2) 语义自一致性：分歧过大 -> 拒绝接地，请求澄清（fail-closed）
        if H_sem > self.tau_entropy:
            return ForceEnvelope.reject('SEMANTIC_AMBIGUOUS'), H_sem
        # 3) 相位化：接近/抓取/搬运/插入/释放 -> 每相位独立包络
        return self._phase_envelope(xi_hat, obs), H_sem

    def _robust_aggregate(self, outs) -> dict: ...
    def _semantic_entropy(self, outs) -> float: ...
    def _phase_envelope(self, xi_hat, obs) -> ForceEnvelope: ...
```

### IP-494 CFAC：共形力可供性校准（离线校准，在线 O(d)）

```python
@dataclass
class ConformalForceAffordanceCalibrator:
    """CFAC：共形风险控制学习收缩量 λ̂，使强制包络风险 ≤ α（分布无关）"""
    alpha: float = 0.1
    lam_grid: np.ndarray = field(default_factory=lambda: np.linspace(0.0, 0.5, 51))
    lam_max: float = 0.5
    lam_hat: float | None = None

    def calibrate(self, calib: list[tuple[ForceEnvelope, ForceEnvelope]]) -> float:
        """calib: (MLLM 包络 E(ξ̂), 真值安全包络 E*(ξ*))；对 λ 单调损失做 CRC"""
        for lam in self.lam_grid:
            losses = [self._risk(shrink(E, lam), E_star) for E, E_star in calib]
            if (sum(losses) + 1.0) / (len(calib) + 1.0) <= self.alpha:  # CRC 界
                self.lam_hat = float(lam)
                return self.lam_hat
        self.lam_hat = self.lam_max       # 全网格不达标：最大收缩
        return self.lam_hat

    def certify(self, E: ForceEnvelope, H_sem: float, t_now: float) -> FGC:
        lam = self.lam_max if self.lam_hat is None else self.lam_hat
        E_c = shrink(E, lam)
        ok = E_c.well_formed() and lam <= self.lam_max and H_sem <= 0.3
        return FGC(envelope=E_c, lam=lam, alpha=self.alpha, h_sem=H_sem,
                   well_formed=ok, t=t_now)

    def kc_ground(self, fgc: FGC) -> bool:
        """引理 43：通过 ⟹ 强制包络超出真实安全集的风险 ≤ α（可交换时）"""
        return fgc.well_formed and fgc.lam <= self.lam_max

    def _risk(self, E_c: ForceEnvelope, E_star: ForceEnvelope) -> float:
        return volume(E_c.difference(E_star)) / max(volume(E_c), 1e-9)
```

### IP-495 CCK：三模态接触一致性（控制环内，视觉降采样/异步，触觉+力 1 kHz）

```python
@dataclass
class ContactConsistencyKernel:
    """CCK：视觉/触觉/力后验对数线性融合 + 跨模态一致性；kc_contact 硬门"""
    tau_conf: float = 0.7
    tau_kappa: float = 0.5
    w: dict = field(default_factory=lambda: {'vis': 1.0, 'tac': 1.0, 'ft': 1.0})

    def observe(self, vis, tac, ft, t_now: float) -> CCC:
        p_vis = self._posterior('vis', vis)      # 视觉接触状态后验
        p_tac = self._posterior('tac', tac)      # 触觉（GelSight）后验
        p_ft  = self._posterior('ft', ft)        # 力/力矩后验
        p_fused = self._log_linear_pool([p_vis, p_tac, p_ft], self.w)
        s_star = int(np.argmax(p_fused))
        p_star = float(p_fused[s_star])
        kappa = 1.0 - self._max_pairwise_js([p_vis, p_tac, p_ft])
        return CCC(s_star=s_star, p_star=p_star, kappa=kappa,
                   per_modality=(p_vis, p_tac, p_ft), t=t_now)

    def kc_contact(self, ccc: CCC) -> bool:
        """引理 45：低置信或模态冲突都 fail-closed"""
        return ccc.p_star >= self.tau_conf and ccc.kappa >= self.tau_kappa

    def _posterior(self, m, obs) -> np.ndarray: ...
    def _log_linear_pool(self, ps, w) -> np.ndarray: ...
    def _max_pairwise_js(self, ps) -> float: ...
```

### IP-496 FSF：力安全滤波（控制环内，CBF-QP，目标 < 0.3 ms）

```python
@dataclass
class ForceSafetyFilter:
    """FSF：把已认证力包络编译为 CBF-QP 投影；前向不变 + 通过性约束"""
    gamma: float = 10.0
    dt: float = 0.001
    solver: str = 'osqp'

    def filter(self, F_des, F_meas, E: ForceEnvelope, t_now: float) -> ForceCmd:
        # 力包络 CBF：h_i(F) = b_i - a_i^T F >= 0；通过性：rho_passive >= 0
        # min ||F - F_des||^2  s.t.  h_i(F) + gamma*h_i(F_meas) >= 0
        F_safe = self._cbf_qp(F_des, F_meas, E, self.gamma)
        if F_safe is None:                    # 不可行 -> fail-closed 回退
            F_safe = self._fallback(F_meas, E.core())
        return F_safe

    def _cbf_qp(self, F_des, F_meas, E, gamma): ...
    def _fallback(self, F_meas, E_core): ...
```

### IP-497 EFA-v5：九硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；ECS_v5 = ECS_v4 · η_ground · η_contact"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    cfac: ConformalForceAffordanceCalibrator
    cck: ContactConsistencyKernel
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec: EEC, bcc: BCC, fgc: FGC, ccc: CCC,
                  object_class, geo_sig, theta_domain_fp, traj, context) -> tuple[bool, str]:
        # 优先级：HIC veto > 语义歧义 > 其余八硬门（并行评估，任一失败即拒）
        if self.hic.veto_active(hic):            return False, 'HIC_STOP'
        if fgc.h_sem > 0.3:                      return False, 'SEMANTIC_AMBIGUOUS'
        if not self.scf.kc_coverage(x, t_now):   return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):              return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):             return False, 'BALANCE_UNSTABLE'
        if not self.cfac.kc_ground(fgc):         return False, 'GROUNDING_UNSAFE'
        if not self.cck.kc_contact(ccc):         return False, 'CONTACT_INCONSISTENT'
        pass_mem, eta_mem, novelty = self.ltem.query(object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                         return False, 'MEMORY_REJECT'
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):            return False, 'VALUE_MISALIGNED'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5, eta_val=0.5,
               eta_bal=0.5, eta_ground=0.5, eta_contact=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return base * eta_mem * eta_val * eta_bal * eta_ground * eta_contact
```

## 3. 双时标集成流水线（v4 → v5）

```
慢时标（MLLM 语义—力接地，异步，秒级，绝不进入 1 kHz 控制环）：
  多模态上下文 o_t (图像窗口/语言/力触觉历史/本体感知)
    ──▶ MFGK 采样解析 + 自一致性 → ξ̂（或 SEMANTIC_AMBIGUOUS → 请求澄清）
    ──▶ CFAC.certify → FGC（收缩包络 E_λ̂, λ̂, α）
```

## 5. 正确性论证（增量更新）

### 引理 43（共形接地覆盖界）

**陈述**：设校准样本 (o_i, E*_i) 与部署样本 (o, E*) 可交换，风险分数 s_i(λ) 对 λ 单调非增，λ̂ 按 CRC 规则选取。则 E[ℓ(E_λ̂)] ≤ α，其中 ℓ 为「强制包络超出真实安全集的体积比例」。该界分布无关，不依赖 MLLM 是否「理解正确」。

**证明**：CRC 的单调性定理（Angelopoulos et al.）保证在可交换性下经验风险 + 1/(n+1) 是期望风险的无偏上界；取满足该界的最小 λ̂ 即得 E[ℓ] ≤ α。∎

**工程含义**：把 MLLM 的「语义解析」降级为「包络初值」，由校准数据决定收缩量；MLLM 越不准，λ̂ 越大、包络越保守，安全性不依赖模型正确性。

### 引理 44（力包络的 CBF 前向不变性）

**陈述**：若 F(0) ∈ E 且 FSF 每步解出满足 h_i(F) + γ h_i(F_meas) ≥ 0 的可行力指令，则对任意 t ≥ 0，F(t) ∈ E。

**证明**：标准 CBF 定理（Ames et al.）：对多面体半空间约束 h_i，条件保证 h_i(F(t)) ≥ h_i(F(0))e^{−γt} ≥ 0，故 F(t) 恒在 E 内。∎

**工程含义**：即使上层策略输出越界力指令，FSF 也把实际力钳制在已认证包络内；不可行时回退 E_core，保证 fail-closed。

### 引理 45（接触一致性可靠性界）

**陈述**：设各模态后验已校准（ECE ≤ ε_cal），p_fused 为对数线性池化。则 kc_contact 通过（p* ≥ τ_c ∧ κ ≥ τ_κ）时，真实接触状态被正确识别的概率 ≥ 1 − ε_cal − exp(−2(p*−τ_c)²·M_eff) − g(κ)；且模态冲突（κ < τ_κ）是「至少一个模态错误」的必要条件。

**证明**：由校准假设，各模态错误概率 ≤ ε_cal；对数线性池化在独立近似下的错误率由 Hoeffding 型界控制（M_eff 为有效独立证据数）；κ 是两两 JS 散度的上确界，JS=0 当且仅当分布相同，故冲突必有至少一模态偏离。∎（sketch）

**工程含义**：专抓「视觉说接触、力说自由」「触觉说滑移、力说稳定」等跨模态冲突，避免单一模态盲区导致的漏检滑移/冲击。

### 定理 5（双时标安全组合，MLLM 延迟下仍安全）

**陈述**：设 (i) 接地证书在 τ_k 时刻以风险 ≤ α 给出 E_k = E_λ̂(ξ̂(o_{τ_k}))；(ii) FSF 在每周期保证 F(t) ∈ E_k(t)；(iii) 包络随陈旧时间收缩 δ(Δt)，且 δ 的收缩速率不小于真实安全集随上下文漂移的 Lipschitz 速率 L·v_max；(iv) t−τ_k > T_max 时锁存 E_core 或停机。则对任意 t，P(F(t) ∈ E*(o_t)) ≥ 1 − α − O(ε_shift)，其中 ε_shift 为校准—部署非可交换性。即 MLLM 推理延迟 Δ 不破坏安全性，只通过包络收缩牺牲性能。

**证明**：由引理 44，F(t) ∈ E_k(t)；由 (iii)，E_k(t) ⊆ E*(o_t)（陈旧收缩快于真实安全集漂移）；由引理 43，E_k(τ_k) ⊆ E* 的概率 ≥ 1−α；非可交换性额外损失 ε_shift。合并即得。∎

**工程含义**：这是对 v4「最大风险（实时性）」的结构性回答——慢模型只负责「划界」，快滤波器负责「守界」，延迟被转成保守性而非不安全。

### 定理 6（九锚点完备与严格收缩）

**陈述**：在 (B1)~(B5)（继承 v4）及 (B6) 校准—部署可交换、(B7) 模态后验校准、(B8) 力包络 CBF 可行 下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29（严格收缩）；
(ii) 接地越界风险由引理 43 界；
(iii) 接触误判风险由引理 45 界；
(iv) 双时标组合在延迟 Δ 下仍安全（定理 5）；
(v) 九锚点 {3DCF, MSRG, HICK, EEK, LTEM, VACK, BCK, MFGK/CFAC, CCK} 互补完备。

**证明**：(i) v5 在 v4 每条路径上追加 kc_ground（准入/相位切换）与 kc_contact（控制环），只缩不涨；非恒真保证严格性（可构造「语义误接地」「视觉-力冲突」反例）。(ii)(iii)(iv) 分由引理 43/45、定理 5。(v) 逐锚点反例构造：去 MFGK/CFAC 则「轻拿」被误译为过力；去 CCK 则视觉-力冲突下的滑移漏检（见 R53/R54）。∎

**诚实声明**：(B6) 可交换性是共形保证的命门——新物体/新任务会造成协变量漂移，使覆盖界失效；(B7) 模态后验校准在分布外难以保证；(B8) CBF 在极端接触（冲击/多接触）下可能不可行。缓解：自适应共形推断（ACI）在线校正 α；漂移检测触发重校准；CBF 不可行时回退 E_core。这些只能降低、不能消除风险。

## 8. 本轮最大风险（最终确认）

**一句话**：**共形接地的分布无关保证依赖校准集与部署上下文可交换**——面对新物体/新任务/新接触模式，MLLM 的力包络可能「自信地错」，共形覆盖静默失效，把概率性幻觉包装成被认证的硬门；这比不加接地更危险，因为它制造了虚假的安全感，而 FSF 只会忠实地守住一个错误的边界。
