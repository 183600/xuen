# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「语义地图」×「可解释性」）

> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**语义信任基座 + 解释即证书**。v9 把安全论证押在一个标量信任域 U_t = {Δ_dom < τ_dom ∧ risk_SLAM < τ_SLAM} 上，而它自己承认的最大风险正是"Δ_dom 的 20 帧滑窗滞后于真实跳变"。本轮用两个灵感正面拆这个债：语义地图给出**帧级**的证书相关失配信号与类别条件化风险场；可解释性把"为何退化"升级为**可机器复核的忠实见证**，并让见证成为运行期许可证（不忠实 ⇒ 保守降级）。仍须保留中立元退化链：任一新模块失效，严格退回 v9，而非行为漂移。

## 0. 直觉与动机

### 灵感 A（语义地图 → 从"占用栅格"到"语义风险场 + 帧级早期预警"）

直觉：v9 的块证书只问"几何上离障碍多远"，但机器人真正怕的东西是有**类别**的：人、玻璃门、电线、热锅。同样一米间隙对不同类别意义完全不同——玻璃的深度常常测不到，于是"几何上很远"完全可能是"语义上极近"。更致命的是：域偏移 Δ_dom 是一个 20 帧滑窗统计量，**它天生滞后**；而语义地图的失配是**当下这一帧**就看得见的——先验说这里是墙，观测却给出"可通行门"的语义，这一帧的证书前提就已经破裂。所以第一个动作：把语义地图提升为**证书的信任基座**，定义"证书相关语义残差" δ_sem^cert（只在块扫掠体积内度量，避免全局噪声），把它并入信任域与 K_eff 门控。对未知/低置信类别一律取**最坏风险天花板**：语义无知必须换算为保守，而不是乐观。

严谨地说（详见产物定义 540–543）：语义地图 S_t = (E_t, R_t, Ψ_t, u_t)，其中 Ψ_t 是逐指标层的语义风险场、u_t 是未知质量；风险密度按感知置信度与风险天花板做混合 ρ_ℓ(c,p) = p·ρ_ℓ^0(c) + (1−p)·ρ_ℓ^max；证书相关残差只在块扫掠体积 V(ζ) 上度量观测场与"冻结证书所用场"之差，并计入未知质量。于是"早期预警"不是启发式，而是一个可证明的领先时间界（引理 87）。

### 灵感 B（可解释性 → 解释即证书：让"为什么退化"成为可复核的安全证据）

直觉：可解释性在多数系统里只是"给人看的旁注"，事后生成、不承担运行期责任，因此可以随口编。本轮的叛逆点：**解释应当是一张证书**。每当一次降级/中止发生，系统必须给出一个**最小不可约的语义见证** W_t——一组具体的语义实体，使得"把它们从地图里拿掉，证书就恢复；放回其中任意一个，证书又失效"。这同时给出必要性与充分性，第三方可用同一冻结前向模型复算。运行期再配一个**忠实性审计器**：若见证不能通过复核，这次降级被判为"不可解释"，系统被迫按最保守策略（K_eff ← 1、保持当前步）运行。于是解释不再是装饰，而是**高性能运行的许可证**——它只能否决、不能提权（引理 90），因此永远不会放宽安全界。

### 为什么必须一起做（互锁）

语义地图提供三样东西：证书的类别条件、帧级的预警信号、解释的落地坐标；可解释性反过来给语义地图一个硬约束：**任何降级都要在语义地图上留下可复核的因果足迹**。两者共用同一个对象，好处是可审计面收敛为一处（一张地图、一个冻结前向模型、一套证书谓词）；代价是**共模失效**——地图若错，预警、证书、解释会一起"忠实地"错。我们把这个代价显式列为本轮最大风险，并用"未知即最坏"部分对冲。

## 1. 研究问题（Q4–Q6）

- **Q4（语义早期预警）**：在何种假设下，证书相关语义残差 δ_sem^cert 严格领先于滑窗域偏移 Δ_dom？把 δ_sem^cert 并入信任域，能否把"最危险时刻仍取大 K_eff"的暴露窗口从 O(W) 帧压缩到 O(1) 帧？
- **Q5（语义条件证书）**：当类别存在混淆集 C_e 与未知类别 ⊥ 时，如何构造类别条件化的块证书，使其在最坏类别与语义误差余量 β_sem 下仍保守？
- **Q6（解释即证书）**：什么样的忠实性定义（充分性 + 不可约性 + 坐标落地）足以让一条解释成为运行期安全证据？忠实性否决能否保证"解释永不放宽安全界"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 语义证书律（Semantic-Certificate, SMC）**
信任域升级为 U_t^sem = {Δ_dom < τ_dom ∧ risk_SLAM < τ_SLAM ∧ δ_sem^cert < τ_sem}；有效块长由 r(t) = max(Δ_dom/τ_dom, δ_sem^cert/τ_sem) 连续门控；块证书在类别混淆集 C_e 上取最坏，未知/低置信类别按风险天花板 ρ^max 计入。

**P14 解释即证书律（Explanation-as-Certificate, XW）**
每次证书失效/中止/契约降级都输出最小不可约语义见证 W_t，满足充分性 Cert(ζ; S\W) = pass 与不可约性 ∀e∈W: Cert(ζ; S\(W\{e})) = fail；见证以地图坐标落地，可被同模型复算。

**P15 忠实性否决律（Faithfulness Veto, FA）**
见证必须通过审计（同冻结模型 + 地图哈希 + 坐标落地 + 充分/不可约复算）；未通过 ⇒ 判为"不可解释降级"，强制 K_eff ← 1 并保持当前步；解释永不用于提高 K_eff。

## 3. 与基线的接口（如何退化）

- SMC 失效（语义地图不可用 / 残差不可算）⇒ δ_sem^cert ≡ 0、Ψ 退化为纯几何占用、ρ_ℓ(c) ≡ 0 ⇒ 信任域、K_eff、块证书逐位回到 v9（引理 91）；
- XW 失效 ⇒ 见证退化为 v9 的契约 ID 日志字符串，无语义落地；
- FA 失效 ⇒ 审计直通、不对解释设门控，解释回到纯观测；
- v9 的 AC/MW/ID 失效 ⇒ 走 v9 定义的中立元链（K_eff ← 1 / 手写网关 / 全模块 active）；
- 全部失效 ⇒ v9 → v8 → … → v6。

## 4. 预期贡献

1. **语义风险场 + 证书相关残差**：把域偏移检测从"滑窗统计"推进到"帧级语义反证"，在理论上给出领先时间界，直接对冲 v9 最大风险；
2. **语义条件块证书**：类别混淆集 + 未知类别风险天花板，使保守性对语义不确定性成立（引理 88）；
3. **解释即证书**：最小不可约见证 + 忠实性否决，把可解释性从旁注变成运行期安全证据与性能许可（引理 89–90）；
4. **可审计单面**：一张地图、一个冻结模型、一套谓词同时承载证书/预警/解释三职责；E571–E590 覆盖早期预警、证书保守性、见证质量、审计抗欺骗与端到端。

## 5. 本轮最大风险

**一句话**：语义地图、早期预警与解释见证共享同一个感知基座——当危险在语义上不可见（玻璃、镜面、透明薄膜、未知类别被误分为"安全"类）时，δ_sem 会偏小、见证会"忠实"地指向别处，系统得到一个自洽却错误的证明，即「可解释性把错误解释得更可信」。

**定义 540（语义地图与语义风险场）** 语义地图 S_t = (E_t, R_t, Ψ_t, u_t)。风险密度按置信度混合并对未知取天花板：
```
ρ_ℓ(c, p) = p · ρ_ℓ^0(c) + (1 − p) · ρ_ℓ^max,    ρ_ℓ(⊥) = ρ_ℓ^max
Ψ_t(x, ℓ) = max_{e: x ∈ X_e} ρ_ℓ(c_e, p_e)
```
典型表（软层）：human 0.9 / glass-transparent 1.0 / cable 0.6 / cup 0.3 / table 0.2；未知类别恒取 1.0。语义无知因此**换算为保守**而非乐观。

**定义 541（证书相关语义残差）** 设块生成时冻结果 Ψ̂_{t_c}，当前观测场 Ψ_t^obs，未知质量 u_t(V) = ∫_V (1 − max_e p_e) / |V|：
```
δ_sem^cert(t; ζ) = max_{ℓ∈L_soft, x∈V(ζ)} |Ψ_t^obs(x,ℓ) − Ψ̂_{t_c}(x,ℓ)| + λ_u · u_t(V(ζ))
```
只度量扫掠体积，避免全局噪声；λ_u>0 保证"不知道"也计入残差。

**定义 542（语义信任域与门控）**
```
U_t^sem = { Δ_dom < τ_dom ∧ risk_SLAM < τ_SLAM ∧ δ_sem^cert < τ_sem }
K_eff^sem(t) = 1                                          若 ¬U_t^sem
             = max(1, ⌊K_max · (1 − min(1, r(t)))⌋)       否则
r(t) = max( Δ_dom/τ_dom , δ_sem^cert/τ_sem )
```
这是 v9 定义 539 的严格泛化：令 δ_sem^cert ≡ 0 即逐位回到 v9。

**定义 543（语义条件块证书）** 在类别混淆集上取最坏并扣除语义误差余量 β_sem：
```
ĝ_min^sem = min_{k≤K} min_{c∈C_e, e∈B(V)} F̂_clearance(s, a^{1:k}; c) − β − β_sem
ê_max^sem = max_{k≤K} F̂_effort(s, a^{1:k}) + β
d_safe^sem = max_{c∈C_e} d_safe(c)
Ĉ_t^sem 有效 ⇔ ĝ_min^sem ≥ d_safe^sem ∧ ê_max^sem ≤ τ_eff ∧ γ̂_grasp valid ∧ δ_sem^cert < τ_sem
```

**定义 544（阻塞集与语义见证）** 阻塞集 B_t = {e ∈ E_t : X_e ∩ V(ζ_t) ≠ ∅ ∧ e 参与绑定约束}。见证 W_t ⊆ B_t 满足：
```
(i)  充分性   Cert(ζ_t ; S_t \ W_t) = pass
(ii) 不可约性  ∀e ∈ W_t : Cert(ζ_t ; S_t \ (W_t\{e})) = fail
```
若不存在满足 (i) 的子集，则输出结构型失败 status=`structural`（不可归因于实体，例如纯几何越界），并按 Level-0 保守处理。

**定义 545（解释即证书）** 降级事件 d 可采纳 ⇔ 携带 status=`faithful` 的见证 W_t（充分+不可约+落地）且通过审计；可采纳降级维持当前 K_eff 并按见证记账；不可采纳 ⇒ K_eff←1 并保持当前步。

**定义 546（忠实性审计器）** FA 用**同一冻结 F̂**与**同一地图哈希**复算：h(S) 一致、坐标落地有效、充分性成立、对每个 e 的不可约性成立。任一不成立 ⇒ 驳回。

**定义 547（语义早期预警）** 若 t0 帧扫掠体积内发生"证书失效型"语义变化（类别/占用跨越阈值），则 δ_sem^cert 在第 1 帧越阈；Δ_dom 作为窗长 W 的因果 EMA 需 j* 帧才越阈，故检测领先 Δ_lead = j*−1 帧（引理 87）。

```python
# IP-357 SemanticMapCertifier
class SemanticMapCertifier:
    def __init__(self, F, rho0, rho_max, tau_sem=0.10, lam_u=1.0, K_max=10):
        self.F, self.rho0, self.rho_max = F, rho0, rho_max
        self.tau_sem, self.lam_u, self.K_max = tau_sem, lam_u, K_max

    def risk_field(self, S):
        psi = defaultdict(lambda: 0.0)
        for e in S.entities:
            for x in e.footprint:
                for l in SOFT_LAYERS:
                    r = e.p * self.rho0[l].get(e.c, self.rho_max[l]) \
                        + (1 - e.p) * self.rho_max[l]
                    psi[(x, l)] = max(psi[(x, l)], r if e.c != UNKNOWN
                                      else self.rho_max[l])
        return psi

    def cert_residual(self, S_obs, psi_frozen, swept):
        psi = self.risk_field(S_obs)
        d = max(abs(psi[(x, l)] - psi_frozen[(x, l)])
                for x in swept for l in SOFT_LAYERS)
        return d + self.lam_u * S_obs.unknown_mass(swept)

    def semantic_certificate(self, s, cand, S):
        swept = swept_of(cand)
        pred = self.F.rollout(s, cand, semantics=S)
        g = min(self.F.clearance(s, cand[:k], c)
                for k in range(1, len(cand) + 1)
                for c in S.confusion_set(swept))          # 含 ⊥ 最坏
        g_min = g - BETA - BETA_SEM
        e_max = pred.max_effort + BETA
        d_safe = max(S.d_safe(c) for c in S.confusion_set(swept))
        ok = (g_min >= d_safe and e_max <= s.tau_eff
              and pred.grasp_valid and S.delta_sem < self.tau_sem)
        return Cert(g_min, e_max, d_safe, ok)

    def effective_K(self, dd, tau_d, rs, tau_s, ds, tau_sem):
        if dd >= tau_d or rs >= tau_s or ds >= tau_sem:
            return 1
        r = max(dd / tau_d, ds / tau_sem)
        return max(1, int(self.K_max * (1 - min(1.0, r))))


# IP-358 ExplanationWitness
class ExplanationWitness:
    def __init__(self, cert): self.cert = cert
    def blocking_set(self, chunk, S):
        return [e for e in S.entities
                if intersects(e.footprint, chunk.swept_volume) and e.binds(chunk)]
    def ok(self, chunk, S):
        return self.cert.semantic_certificate(S.state, chunk.actions, S).ok
    def witness(self, chunk, S):
        B = self.blocking_set(chunk, S)
        if self.ok(chunk, S):
            return Witness([], 'no-failure')
        W = list(B)
        if not self.ok(chunk, S.without(W)):
            return Witness([], 'structural')              # 无实体可归因
        for e in list(W):                                  # 贪心去冗余
            W2 = [x for x in W if x is not e]
            if self.ok(chunk, S.without(W2)):
                W = W2
        return Witness(W, 'faithful')


# IP-359 FaithfulnessAuditor
class FaithfulnessAuditor:
    def __init__(self, cert, D_xw=0.5):
        self.cert, self.D_xw = cert, D_xw
    def audit(self, chunk, S, w, map_hash):
        if w.status != 'faithful' or map_hash != S.hash:
            return False
        if not self.ok(chunk, S.without(w.W)):             # 充分性
            return False
        for e in w.W:
            if self.ok(chunk, S.without([x for x in w.W if x is not e])):
                return False                               # 不可约性
        return True
    def ok(self, chunk, S):
        return self.cert.semantic_certificate(S.state, chunk.actions, S).ok
```

## 4. 推导

**引理 87（语义残差的帧级领先性）** 设 A1：Δ_dom 为窗长 W 的因果 α-EMA（α=1/W，W=20）；A2：t0 帧在 V(ζ) 内发生证书失效型语义变化，δ_sem^cert 在被观测到的那一帧即 > τ_sem，而 Δ_dom(t0)=0。则 Δ_dom 首次越过 τ_dom 的时刻
```
j* ≥ ⌈ ln(1 − τ_dom/D) / ln(1 − α) ⌉      （D 为单帧偏移幅度上界）
```
故检测领先 Δ_lead = j* − 1 ∈ [0, W−1] 帧；当 D ≥ 2τ_dom 时 Δ_lead ≥ ⌈W·ln2⌉ − 1 ≈ 13 帧（W=20，约 260ms）。证明：EMA 展开 Δ(t0+j)=D(1−(1−α)^j) 单调增，解不等式得 j*；δ_sem 于第 1 帧触发，故领先 j*−1。注意该结论以 A2（语义可观测）为前提——这正是本轮最大风险所在。∎

**引理 88（语义条件证书的保守性）** 假设 A3：真实类别 c_e* ∈ C_e（含 ⊥）；A4：对每个类别赋值 ‖F̂−F‖_∞ ≤ β+β_sem；A5：ρ_ℓ(c,p) 不低于真实风险密度（置信混合 + 天花板保证）。则 ∀k：真实间隙 g_k ≥ ĝ_min^sem，且用 Ψ 计算的停车不变式不弱于真实。证明：min 在超集上取 ≤ 真实 min；统一减误差界得下界；风险场逐点支配真实密度，故停车距离估计偏保守。∎

**引理 89（见证的充分性、不可约性与复杂度）** 在证书对阻塞实体单调（加入实体只减间隙）下，若存在 W⊆B 使 Cert(S\W)=pass，则贪心去冗余在 O(|B|) 次证书复算内产出不可约见证；最小基数见证等价于最小碰集问题（NP-hard），故本方案只承诺**不可约**而不承诺**最小基数**。充分性与不可约性均由复算直接验证。∎

**引理 90（忠实性否决不降低安全界）** FA 驳回 ⇒ K_eff=1，退回 v9 逐步，安全性由 v9 引理 82 保证。FA 通过 ⇒ W 经同模型复算满足充分性与不可约性，解释是对同一证书谓词的真实反事实；但 K_eff 仍只由 P13（定义 542）决定，解释**只能否决、不能提权**。因此 XW/FA 不可能放宽安全界；前提是 FA 与证书评估共享冻结 F̂ 与地图哈希。∎

**引理 91（中立元退化与 v9 逐位等价）** 置 SMC^⊥：δ_sem^cert≡0、Ψ=纯几何占用、C_e={几何}、ρ≡0 ⇒ U^sem=U、K_eff^sem=K_eff、Ĉ^sem=Ĉ（定义 542/543 逐位退化为 539/533）。置 XW^⊥：见证=契约 ID 字符串；置 FA^⊥：审计直通。三者皆 ⊥ 时 v10 ≡ v9（定义 532–539、引理 82–86）。∎

## 9. 本轮最大风险

**一句话**：语义地图、早期预警与解释见证共享同一个感知基座——当危险在语义上不可见（玻璃、镜面、透明薄膜、未知类别被误分为"安全"类）时，δ_sem 会偏小、见证会"忠实"地指向别处，系统得到一个自洽却错误的证明，即「可解释性把错误解释得更可信」。
