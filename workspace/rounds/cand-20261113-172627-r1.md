# 第 66 轮（承接第 65 轮「VISTA 故障可归因安全时序」IP-214~223；灵感循环第 3 轮；本轮灵感：「场景理解」×「虚拟仿真」）

> 第 65 轮把「几何可证伪」升级为「故障可归因」，其自述的最大风险是：**归因能力依赖"故障属于有限假设集、且视觉与几何的失效相互独立"；真实故障常是未知类型的组合，透明/镜面/对抗 patch 又会让视觉与几何共享同一个分布外失效源，于是 FIR 会把未知复合故障强行归入最近假设、只膨胀错误的球，系统反而因为"已经归因"而更自信地继续执行。** 第 66 轮不再叠加模态，而是引入两个「元来源」：**场景理解**把假设空间结构化并加上物理/语义约束；**虚拟仿真**把假设空间从封闭集合变成可按需合成、可反事实检验的开放集合。本轮核心命题是：
>
> **把「有限假设集上的故障归因」升级为「场景约束 + 反事实仿真检验的可扩展归因」：用场景图给出物理合理性与可供性约束，用可校准的数字孪生按需合成未知/复合故障并做反事实 rollout，用「孪生差距门」显式承认仿真也会错——场景先验与仿真只用来生成和排除假设，绝不用来宣布真值。**

## 0. 直觉与动机

**灵感 1（场景理解 → 把"几何是否可信"变成"场景是否自洽"）**
直觉：第 64/65 轮的所有先验都是局部的——一个接触面、一个接触斑、一个末端位姿。但人判断"这里能不能放、能不能压、压了会不会翻"，靠的从来不是局部几何，而是整个场景：杯子在桌面上（支撑关系）、桌沿外没有支撑（重力约束）、抽屉只能沿滑轨动（铰接约束）、蛋是易损的（物理属性）、瓶口朝向决定能否插入（可供性）。这些是**比几何更高层的约束**，能在接触前排除大量物理上不可能的假设，也能在接触后解释"力残差大但几何其实对，因为物体本来就在滑动 / 容器在倾覆 / 支撑在塌陷"。它把第 65 轮问的"几何幻觉"扩展成一族**场景自洽性故障**：支撑错、关系错、属性错、可供性错。
但必须诚实：场景理解同样是视觉学习的，会幻觉出并不存在的支撑与关系；它和 VCV/视觉世界模型共享骨干与数据偏差，因此**不是独立证据**。所以场景先验只能做「软约束 + 可被证伪」，不能硬剪枝。

**灵感 2（虚拟仿真 → 从"查表归因"到"反事实生成"）**
直觉：第 65 轮 FIR 的 p(ρ|H) 是离线注入、固定假设集的查表。真实世界会冒出没注入过的组合故障。仿真恰好给了两件真东西：(i) **反事实**——"如果世界是 f，观测会是什么样"，可以按需生成任意故障、任意组合的签名 ρ_sim(f)，把归因从"分类到 6 个假设"变成"在连续故障空间里做反事实匹配 / 仿真推断（SBI）"；(ii) **安全沙盒**——探针先在孪生里跑，估伤害与信息量，再决定要不要在真机上做，把物理伤害预算压到最低。
但更诚实：仿真有 sim-to-real gap，而且 gap 恰恰在"没见过的故障 / 没见过的场景"上最大。一个只在有限真机数据上校准过的孪生，会在新奇场景上**自信地错**。所以仿真不是新真值，必须带一个**可校准的差距包络**，以及一条"什么时候不许信仿真"的硬门。

**灵感 3（两者合流 → 「生成-检验-设限」三件套）**
- 场景理解负责**生成与剪枝**：给出先验 P(φ|G_s)、物理可行的故障类型、以及"接触/支撑/容器/铰接是否自洽"的软证据；
- 仿真负责**生成与检验**：按需合成故障、做反事实 rollout、给出 ρ_sim(f)，用 SBI 得到连续故障后验；
- 孪生差距门负责**设限**：当观测落在孪生校准支撑之外、或不同仿真族给出分歧归因时，判 `twin_ooc / attribution_unstable`，退回第 65 轮的保守有限归因 + 真实探针，绝不"因为仿真解释得通"就放行。

**灵感 4（合流命名 → CAST：Counterfactual Attribution with Scene-consistent Twin，场景一致孪生的反事实归因）**
闭环：场景图 / 可供性先验（SGR）→ 孪生构建与差距校准（TBC）→ 反事实故障合成（CFS）→ 仿真推断归因（SBA）→ 孪生差距门（TGG）→ 场景一致安全证书（SCSC）→ 仿真先行探针（CIP）→ 开放假设增长与新颖性（OHG）→ 回写 VISTA 的 FIR/RSC-V/CSC/J_vista。第 65 轮是"接触前 / 中 / 后的故障可分离"；CAST 再往上加一层**对世界模型本身的自省**：不仅问"哪一层坏了"，还问"我用来判断坏没坏的模型，在这个场景里还成立吗"。

**灵感 5（VISTA 组件的原位升级）**
- **FIR → FIR-S**：假设集增 H_scene（场景理解错）与 H_novel（未知）；似然从查表升级为"查表 + 仿真匹配 + 残差模型"；场景先验做 tempered（留 ε_prior 下限，绝不清零）。
- **VPG → VPG-S**：视觉预测从任务观测量升级为场景图状态预测（关系 / 支撑 / 铰接 / 形变），残差分解为 e_geo / e_scene / e_dyn。
- **APP/AFA → CIP**：探针先仿真后真机，目标从"故障假设互信息"升级为"互信息 × 可迁移性 − 仿真预估伤害"。
- **RSC-V → RSC-C**：球再拆 r_scene（场景歧义）与 r_twin（孪生差距）；`twin_ooc` 时只膨胀 r_twin，不动 r_geo。
- **CSC → CSC-C**：认证前缀在"场景一致 + 孪生差距内"的支持集上验证；twin 不可信时退回 VISTA 保守前缀。
- **CSP-V → CSP-C**：块边增场景可行性（支撑 / 容器 / 铰接）约束；不可行的块不入图。
- **AIC-V → AIC-C**：干扰集增场景幻觉、孪生错配、共因场景-仿真偏差。
- **J_vista → J_cast**：证书增 scene_graph_hash、scene_consistency、twin_version、twin_gap、sim_posterior、novelty_flag、transfer_score。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（CAST 闭环）**：CAST = (VISTA, SGR, TBC, CFS, SBA, TGG, CIP, SCSC, OHG, AIC-C, J_cast)。定位：VISTA 的"场景一致 + 反事实归因"升级。不变式：**场景图推断、孪生构建与校准、故障合成、仿真推断、证书只在语义流 / 低频线程；实时流只做场景/阶段残差采集、安全前缀执行与早停，零学习写操作。**
- **定义 234（场景图与可供性先验）**：场景图 G_s=(O,E,A,ψ)：对象 O（位姿、几何、材质）、关系 E⊂{support, contain, articulate, contact, occlude}、可供性 A（graspable, pressable, insertable, pourable, fragile）、物理属性 ψ（质量 m、摩擦 μ、刚度 k、易损阈值 f_break）及分布。场景先验 P_prior(φ|G_s)∝exp(−λ_s·e_scene(φ,G_s))，并做 tempering：P_prior←(1−ε_prior)·P_prior/Σ+ε_prior·Uniform，保证任何假设不被清零。
- **定义 235（场景一致性残差）**：e_scene=[e_sup,e_occ,e_art,e_aff]⊤：e_sup 支撑/重力违反（悬空、穿透、堆叠不稳）、e_occ 遮挡与可见性矛盾、e_art 铰接约束违反、e_aff 可供性错配（在不可接触面施力）。另设 H_scene：场景理解自身出错（关系幻觉、属性误估、遮挡误判）。
- **定义 236（数字孪生与实体差距包络）**：孪生 T_ξ 由仿真器参数 ξ 与场景语义实例化；对真机-仿真配对轨迹 τ_i，定义差距 d_gap(τ_i)=W_1(ρ_real,ρ_sim) 或逐通道能量距离；split-conformal 给 q_gap(α_gap)。称观测"孪生内"当 d_gap≤q_gap(α_gap) 且 ρ_obs 落在孪生预测支撑内。孪生带 twin_version 与 calibration_hash。
- **定义 237（反事实故障合成 CFS）**：故障空间 𝔉 含连续参数 f=(f_geo,f_force,f_model,f_vis,f_scene,f_dyn) 及其复合 do(f_1,…,f_k)。生成候选集 𝔉_t 的三条来源：(i) 离线故障库重放；(ii) 围绕残差方向的参数扰动；(iii) 摊销生成提议 q_ψ(f|ρ_obs)。仿真映射 h(f)→ρ_sim(f)，复合故障用逐步干预 do(·) 拼接。
- **定义 238（仿真推断归因 SBA）**：后验 P(f|ρ_obs)∝p̂(ρ_obs|f)p(f)，p̂ 由似然无关推断得到（归一化流 p_φ(ρ|f) 在仿真数据上训练，或 ABC 核 K_ε）。离散假设质量为其参数区域积分；残差 r_min=min_f d(ρ_obs,h(f))。为对冲孪生误差，采用**分布鲁棒后验**：p̂∈𝒫={p:W_1(p,p_sim)≤q_gap}，取最坏后验。r_min>q_novel 或最坏后验不集中 ⇒ `H_novel/ambiguous`。
- **定义 239（孪生差距门 TGG）**：`trust_sim = 1[d_gap≤q_gap(α_gap) ∧ novelty≤q_novel ∧ max_{T,T'∈𝒯} TV(P_T(f|ρ),P_{T'}(f|ρ))≤δ_twin]`，𝒯 为扰动仿真族（不同接触/摩擦/渲染模型）。`trust_sim=0` ⇒ `twin_ooc`：仿真归因不得用于定向处置，退回 VISTA 的有限 FIR + 真实探针，且只膨胀 r_twin。
- **定义 240（场景约束归因 FIR-S）**：P(H|ρ,G_s)∝p(ρ|H)·P_prior(H|G_s)·P(H)，其中 H∈{H0,H_geo,H_force,H_model,H_vis,H_policy,H_scene,H_novel}。场景先验只调后验、不改处置方向；H_scene 与 H_vis 的区分靠"关系/属性错误是否被独立几何或力证据支持"。
- **定义 241（反事实可辨识性）**：f 与 f' **反事实不可分** ⇔ d(h(f),h(f'))≤ε_cf；模型相对可辨识裕度 κ_cf=min_{f≠f'}d(h(f),h(f'))/max(σ_ρ,ε_cf)。κ_cf 低 ⇒ 即使后验集中也只报告"等价故障类"，不强行点名。
- **定义 242（仿真先行探针 CIP）**：a*=argmax_a [I(ℋ;ρ_{1:3}(a)|ρ_{1:2})·τ(a)−λ_d·Δ̂_sim(a)]，s.t. 孪生预测 f_n≤f_safe、strain≤ε_strain；τ(a)=P(d_gap(probe)≤q_gap) 为可迁移性，Δ̂_sim 为仿真预估伤害。先在孪生里 rollout；τ 低或 Δ̂_sim 高 ⇒ 改 visual_probe/null_test。执行后若实测 gap 增大立即中止并重归因。
- **定义 243（场景一致安全证书 SCSC）**：在前缀 k 上验证：∀H∈supp(post)，ρ_force/ρ_slip/ρ_geo≥0 且 ρ_scene≥0（支撑不塌、容器不溢出、铰接不越限、易损物 f_n≤f_break(ψ̂) 含不确定度）。ρ_scene 由场景图与孪生共同给界，twin_ooc 时用最坏场景包络。
- **定义 244（开放假设增长 OHG）**：`H_novel` 触发后，仿真合成候选只在**离线 + 人工审核**后并入故障库，库版本写入证书；在线只存 novelty 日志，不做实时学习，避免自证式记忆污染。
- **定义 245（孪生自证审计）**：对归因结论做**仿真族扰动压力测试**：若换一个结构不同的仿真器（软接触 vs 刚体、不同求解器）后后验 argmax 改变或熵上升超阈值，则标 `attribution_unstable`，降级为 ambiguous 并回退。用留出真机数据做**孪生外推检验**，gap 超界即冻结仿真归因。
- **定义 246（场景-仿真共因故障）**：ℰ_common={(G_s,f): 场景先验与孪生共享同一视觉骨干 / 同一合成数据偏差}。共因下不要求归因正确，只要求 TGG 能判 `twin_ooc/ambiguous` 并安全降级；这是第 65 轮 A88 的显式化。
- **定义 247（CAST 证书 J_cast）**：J_cast=(J_vista, scene_graph_hash, scene_consistency, twin_version, twin_gap, sim_posterior, cf_margin, novelty_flag, transfer_score, hypothesis_library_ver, scsc_margin)。Valid ⇔ Valid(J_vista) ∧（trust_sim ∨ 已回退 VISTA 有限归因）∧ ρ_scene≥0 ∧ 若 H_novel 则已标 ambiguous ∧ 证书内 twin 与库版本为当前版本。
- **定义 248（CAST 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→VPG-S 场景预测→SGR 场景图/可供性→TBC 孪生校准→ACH→阶段切分→VCV→CFS 反事实合成→SBA 仿真归因→TGG→FIR-S→CIP/FPE→WCV-V→CSP-C→CSC-C→SCSC→Shield→执行 k* 步→EV_exec→RSC-C→OLP→DIR→OHG→AIC-C]；实时流 [锚点读→视觉/力/场景残差采集→阶段与场景一致性判定→CSC-C 早停→WCV-V 编译→π_σ 前缀派发→J_cast 构建]。

```python
         and posterior_stable_under_twin_perturbation(post_f, delta_twin))
if not trust:
    post_f, h_star, ambiguous = vista_fir_fallback(phases, prior)  # 退回第65轮
    balls['r_twin'] *= kappa_twin
else:
    h_star, post_f = discretize(post_f)              # 含 H_novel / 等价类

# CIP：仿真先行探针（语义流选，实时执行）
a, score = argmax_a(info_gain(a) * transfer(a) - lam_d * sim_damage(a))
if transfer(a) < tau_min or sim_damage(a) > dmg_budget:
    a = 'visual_probe' if vis_reduces_entropy(post_f) else 'null_test'
twin.rollout(a)                                       # 先在孪生中跑
if twin.aborts(a): a = safer_variant(a)

# SCSC + CSC-C：场景一致认证前缀
k_star = csc_c.certified_prefix(A, post_f, m, alpha_chunk,
                                scene_margin=lambda s: scene_safe(s, G_s, twin))
if twin_ooc:
    k_star = min(k_star, k_star_vista_conservative)

# OHG：只在离线写库
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（tempered 场景先验不破坏覆盖）**：若真假设的场景先验下界为 ε_prior>0，则场景先验至多把其权重压低 1/ε_prior 倍；当似然分离度 ≥ log((1−ε_prior)/ε_prior)+log((1−δ)/δ) 时，归因 argmax 不变。故场景先验可以缩小假设体积，但不会把真假设彻底剪掉——这直接对冲"场景幻觉导致误剪枝"。
- **引理 10（孪生差距门的安全性）**：若 d_gap≤q_gap(α_gap) 且 𝒫 为 W1 球内真实分布的邻域，则鲁棒后验以 ≥1−α_gap 覆盖真实 f；若 TGG 拒绝，CAST 回退到 VISTA，其定理 7 的证书仍然成立。故 CAST 的安全性**不低于** VISTA，仿真只带来"分布内更准"的增益。
- **定理 9（CAST 端到端）**：在 A94–A99 下，Valid(J_cast) ⇒ 场景一致安全 ∧（归因正确 ∨ H_novel/ambiguous 显式标注 ∨ 已回退有限归因）∧ 只膨胀正确球（r_geo/r_force/r_model/r_scene/r_twin）∧ 前缀安全。证书链从"几何-技能-干扰-接触-归因"扩到"几何-技能-干扰-接触-归因-世界模型可信度"。
- **定理 10（开放集收益与自证上界）**：设 CFS 对故障空间的覆盖为 c、孪生有效域为 V。未知故障召回 ≤ c·1[V]+baseline·1[¬V]；而"自信误归因"概率上界为 P(d_gap>q_gap)+P(κ_cf 低)+ε_prior。**仿真带来的召回增益完全以孪生有效域为条件**；一旦场景先验与孪生共享偏差，增益消失、风险上升。
- **实时性**：场景图 / 孪生 / CFS / SBA / TGG 全在语义流；实时流只增场景一致性检查（<0.06ms）、阶段判定（<0.05ms）、CSC-C 早停（<0.02ms），目标仍 ≤2.6ms（A100 修订契约）。

**定义 233（CAST 闭环）** CAST 是 VISTA 的"场景一致 + 反事实归因"升级：在 VISTA 的"语义流 ∘ 实时流"骨架上挂载 SGR（场景图/可供性）、TBC（孪生与差距校准）、CFS（反事实故障合成）、SBA（仿真推断）、TGG（孪生差距门）、CIP（仿真先行探针）、SCSC（场景一致安全证书）、OHG（开放假设增长），并原位升级 FIR→FIR-S、RSC-V→RSC-C、CSC→CSC-C、CSP-V→CSP-C、AIC-V→AIC-C、J_vista→J_cast。不变式：**场景图推断、孪生构建与校准、故障合成、仿真推断、证书构建只发生在语义流/低频线程；实时路径只做场景/阶段残差采集、安全前缀执行与早停，零学习写操作、零在线写库。**

**定义 234（场景图与可供性先验）** 场景图 G_s=(O,E,A,ψ)。对象 O 含 6D 位姿、几何基元、材质类别；关系 E 含 support（A 支撑 B）、contain（A 容纳 B）、articulate（parent,child,axis,limits）、contact、occlude；可供性 A 与物理属性 ψ（质量 m、摩擦 μ、刚度 k、易损阈值 f_break）均带分布。场景先验由负指数一致性构造：
P_prior(φ|G_s)=exp(−λ_s·‖e_scene(φ,G_s)‖²)/Z。
为防止场景幻觉把真假设剪没，做 tempering：
P_prior←(1−ε_prior)·P_prior/Σ_{φ'}P_prior(φ') + ε_prior·Uniform(φ)，
其中 ε_prior>0 是**任何假设的保底质量**。场景先验只进入后验、只调处置，不直接硬删候选。

**定义 235（场景一致性残差）** e_scene=[e_sup,e_occ,e_art,e_aff]ᵀ：
- e_sup：支撑/重力违反（悬空、穿透、支撑面倾角/摩擦锥不足、堆叠稳定裕度<0）；
- e_occ：遮挡与可见性矛盾（被遮挡却声称看到接触斑、期望可见却无纹理）；
- e_art：铰接约束违反（超出关节限位、非轴向运动）；
- e_aff：可供性错配（在非接触面施力、在不可抓面抓取、在非容器口倒入）。
另设 **H_scene**：场景理解自身出错（关系幻觉、属性误估、遮挡误判）。H_scene 与 H_vis 的区分：H_vis 是低层视觉感知错（位姿/深度/光流），H_scene 是高层关系的结构性错误；二者可共因，由 AIC-C 显式建模。

**定义 236（数字孪生与实体差距包络）** 孪生 T_ξ 由仿真器参数 ξ（接触模型、摩擦、求解器、渲染）与场景语义实例化。对配对轨迹 τ_i（同初态、同动作序列），定义差距
d_gap(τ_i)=W_1(ρ_real(τ_i), ρ_sim(τ_i))
或逐通道能量距离；在标定集上用 split-conformal 取 q_gap(α_gap)。称观测"孪生内"当
d_gap(ρ_obs)≤q_gap(α_gap) ∧ ρ_obs∈supp(p_sim)。
孪生带 twin_version 与 calibration_hash；真机日志更新只在离线批次进行。**关键：q_gap 是"仿真能说多准"的显式上限，不是"仿真正确"的证明。**

**定义 237（反事实故障合成 CFS）** 故障空间 𝔉 含连续参数 f=(f_geo,f_force,f_model,f_vis,f_scene,f_dyn) 及其复合 do(f_1,…,f_k)。候选集 𝔉_t 由三条来源并集：
(i) 离线故障库重放（已知类型）；
(ii) 围绕观测残差方向的参数扰动 f=f̂+η，η∼各向异性高斯（局部探索）；
(iii) 摊销生成提议 q_ψ(f|ρ_obs)（全局探索，可用扩散/流模型）。
仿真映射 h(f)→ρ_sim(f)；复合故障用逐步干预 do(·) 拼接，并限制组合阶数 k≤k_max 控制爆炸。合成结果附**可复现指纹**（ξ、场景实例、do 序列）供审计。

**定义 238（仿真推断归因 SBA）** 后验
P(f|ρ_obs)∝p̂(ρ_obs|f)p(f)，
p̂ 由似然无关推断得到：在仿真数据 {(f_j,ρ_j)} 上训练归一化流 p_φ(ρ|f)，或用 ABC 核 K_ε(ρ_obs−h(f))。离散假设质量为其参数区域后验积分；残差 r_min=min_{f∈𝔉_t}d(ρ_obs,h(f))。
为对冲孪生误差，采用**分布鲁棒后验**：
P_rob(f|ρ_obs)=inf_{p∈𝒫} p(ρ_obs|f)p(f)/Z，𝒫={p:W_1(p,p_sim)≤q_gap}。
r_min>q_novel 或 P_rob 不集中 ⇒ 输出 `H_novel/ambiguous`，不强行点名。

**定义 239（孪生差距门 TGG）** 定义三重门：
`trust_sim = 1[ d_gap(ρ_obs)≤q_gap(α_gap) ∧ novelty(ρ_obs)≤q_novel ∧ max_{T,T'∈𝒯} TV(P_T(f|ρ_obs),P_{T'}(f|ρ_obs))≤δ_twin ]`，
𝒯 为**结构不同的扰动仿真族**（软接触 vs 刚体、不同摩擦/求解器/渲染）。任一不满足 ⇒ `twin_ooc`：
1. 仿真归因不得用于定向处置；
2. 退回 VISTA 的有限 FIR + 真实探针（若物理允许）；
3. 只膨胀 r_twin，不动 r_geo/r_force/r_model；
4. 证书写 `twin_ooc=True`，强制人工复核或 safe_idle。

**定义 240（场景约束归因 FIR-S）** 假设集
ℋ_S={H0,H_geo,H_force,H_model,H_vis,H_policy,H_scene,H_novel}，
后验
P(H|ρ,G_s)∝p(ρ|H)·P_prior(H|G_s)·P(H)，
其中 p(ρ|H) 在 `trust_sim` 时用 SBA 的离散化质量，否则用第 65 轮查表似然。定向处置沿用定义 221，但：
- H_scene → r_scene↑、降低场景先验温度、重估 ψ、要求独立几何/力交叉证据；
- H_novel → 不处置、标 ambiguous、入离线审核队列；
- 场景先验**只调后验，不直接改写处置方向**（防止先验主导）。

**定义 241（反事实可辨识性）** f 与 f' 反事实不可分 ⇔ d(h(f),h(f'))≤ε_cf。模型相对可辨识裕度
κ_cf=min_{f≠f'}d(h(f),h(f'))/max(σ_ρ,ε_cf)。
κ_cf 低 ⇒ 即使后验集中也只在**等价故障类**层面报告（如"偏置类"而非"零漂 vs 增益错"），并把等价类整体交给 CSC-C 做最坏验证。这是"仿真模型相对"的可辨识性，不是物理绝对可辨识性。

**定义 242（仿真先行探针 CIP）** 探针动作带阶段模板（visual_approach→light_touch→load），探针集 A={press,rub,tap,lift,visual_probe,null_test}。选择
a*=argmax_{a∈A} [I(ℋ;ρ_{1:3}(a)|ρ_{1:2})·τ(a)−λ_d·Δ̂_sim(a)]，
s.t. 孪生预测 f_n≤f_safe(φ̂,f̂_vis)、strain≤ε_strain、支持视觉早停；
其中 τ(a)=P(d_gap(probe)≤q_gap) 为可迁移性（由历史同类探针的实测 gap 估），Δ̂_sim(a) 为孪生预估伤害。执行顺序：**先在孪生中 rollout**；τ(a)<τ_min 或 Δ̂_sim>dmg_budget 或孪生预测越界 ⇒ 改 visual_probe/null_test。真机执行中若实测 gap 超出 q_gap 立即中止并重归因。

**定义 243（场景一致安全证书 SCSC）** 对块 A_t 与执行前缀 k，在 supp_δ(post) 上验证：

## 3. 关键算法伪代码

### IP-224 SGR（场景图与场景一致性）

```python
class SceneGraphReasoner:
    """场景图 + 可供性 + 物理属性；只给软证据，不做硬剪枝。"""
    def __init__(self, seg, rel, afford, phys, lam_s=1.0, eps_prior=0.05):
        self.seg, self.rel, self.afford, self.phys = seg, rel, afford, phys
        self.lam_s, self.eps_prior = lam_s, eps_prior

    def build(self, img, depth, flow, geometry, contacts):
        O = self.seg(img, depth)                       # 位姿/几何/材质
        E = self.rel(O, geometry, flow)                # support/contain/articulate/occlude
        A = self.afford(O, E, img)                     # 可供性
        psi = self.phys(O, E, contacts)                # m, mu, k, f_break 分布
        return SceneGraph(O, E, A, psi)

    def consistency(self, G_s, phi, contacts, contact_pred):
        e_sup = support_violation(G_s, phi, contacts)
        e_occ = occlusion_conflict(G_s, contacts, contact_pred)
        e_art = articulation_violation(G_s, phi)
        e_aff = affordance_mismatch(G_s, contacts)
        return np.array([e_sup, e_occ, e_art, e_aff])

    def prior(self, phi, G_s, e_scene, phi_space):
        w = np.exp(-self.lam_s * np.sum(e_scene ** 2))
        raw = w / max(w, 1e-12)
        uni = 1.0 / max(len(phi_space), 1)
        return (1 - self.eps_prior) * raw + self.eps_prior * uni   # tempered，绝不清零
```

### IP-226/227 CFS + SBA（反事实合成与鲁棒仿真推断）

```python
class CounterfactualAttributor:
    """故障库 + 扰动 + 生成提议 → 反事实签名 → W1 球内鲁棒后验。"""
    def __init__(self, library, flow, twin, q_gap, q_novel, k_max=3):
        self.library, self.flow, self.twin = library, flow, twin
        self.q_gap, self.q_novel, self.k_max = q_gap, q_novel, k_max

    def propose(self, rho_obs, n=256):
        F = list(self.library.replay(rho_obs))
        F += perturb_along_residual(rho_obs, n=n // 2)
        F += self.flow.sample_faults(rho_obs, n=n // 2)
        F = compose_interventions(F, k_max=self.k_max)   # do(f1,...,fk)
        return F

    def posterior(self, rho_obs, F):
        rho_sim = np.stack([self.twin.rollout(do(f)) for f in F])
        # 分布鲁棒：在 W1 球内取最坏似然，避免孪生过自信
        logp = robust_log_likelihood(rho_obs, rho_sim, self.q_gap)
        prior = np.array([self.library.prior(f) for f in F])
        z = logp + np.log(prior + 1e-12)
        z -= z.max()
        post = np.exp(z) / np.exp(z).sum()
        r_min = float(np.min([energy_distance(rho_obs, r) for r in rho_sim]))
        novelty = r_min > self.q_novel
        return F, post, r_min, novelty
```

## 4. 推导

**引理 9（tempered 场景先验不破坏覆盖）** 设真假设 H* 的 tempering 后先验为 P_prior(H*|G_s)≥ε_prior/|ℋ|（由定义 234 的均匀混合保证）。场景先验对 H* 的压低倍率至多为
1/P_prior(H*) ≤ |ℋ|/ε_prior。
若真实似然比满足
log[p(ρ|H*)/p(ρ|H')] ≥ log(|ℋ|/ε_prior)+log((1−δ)/δ) 对所有 H'≠H*，
则即使 H' 获得最大场景先验、H* 获得最小场景先验，后验仍有 P(H*|ρ,G_s)≥1−δ。故场景先验**只会改变假设的相对体积，不会把真假设清零**；ε_prior 是"场景幻觉容限"的显式旋钮。∎

**引理 10（孪生差距门的安全性）** 设真实签名分布 p_real 与仿真 p_sim 的 W1 距离 ≤q_gap（TGG 通过时由标定保证，覆盖概率 ≥1−α_gap）。对任意 f，鲁棒后验在 𝒫 上取最坏，故
P_rob(f|ρ) ≥ (1−α_gap)·P_sim(f|ρ) 归一化意义下，
即真实后验不会比仿真后验更集中到错误方向；等价地，鲁棒后验的支持集以 ≥1−α_gap 覆盖真实 f 所在的 W1 邻域。若 TGG 拒绝，CAST 回退到 VISTA 的有限 FIR，其定理 7 的 ρ_rob/ρ_slip/ρ_force 保证不变。因此 CAST 的安全性是 VISTA 的**下界保持**升级：仿真只可能在分布内提高准确率，不能在门失败时降低安全性。∎

**定理 9（CAST 端到端归因-安全）** 在 A94–A99（见下）下：
1. **场景约束只调不剪**：FIR-S 的后验以 ε_prior 保底，H_scene 与 H_vis/H_geo 可分离；场景先验使假设体积收缩（引理 9），但不删除真假设。
2. **反事实可扩展**：CFS 覆盖的故障空间上，SBA 给出连续参数后验；κ_cf 低时只报告等价类，不强行点名（定义 241）。
3. **世界模型可信度受检**：TGG 三重门 + 孪生自证审计把"仿真是否可信"变成可验证条件；`twin_ooc` 时只膨胀 r_twin 并回退有限归因（定义 239/245）。
4. **物理安全**：SCSC 增 ρ_scene（支撑/容器/铰接/易损）并与 CSC 取更小前缀；CIP 仿真先行，把真实伤害压到最低。
5. **证书六层链**：Valid(J_cast) ⇔ GRIP 有效 ∧ 归因正确或显式 ambiguous/novel ∧ 场景一致 ∧ 前缀安全 ∧ 孪生可信或已回退 ∧ 版本一致。
6. **优雅降级**：场景失效→ε_prior 上调、退回 VISTA；仿真失效→twin_ooc、退有限 FIR；两者共因→ambiguous + safe_idle；未知故障→H_novel + 离线增长。∎

**定理 10（开放集收益与自证上界）** 设 CFS 对真实故障空间 𝔉 的覆盖为 c∈[0,1]，孪生有效域为 V（TGG 通过的分布区域），有限 FIR 的未知召回为 r_0。则 CAST 的未知故障召回
R_cast ≤ c·1[V] + r_0·1[¬V]；
即**仿真的召回增益严格以"孪生在分布内"为条件**。另一方面，定义"自信误归因"为 argmax 错误且 P_rob(h*)≥1−δ_fi，则
P(confident-wrong) ≤ P(d_gap>q_gap) + P(κ_cf<κ_min) + ε_prior + δ_twin。
最后一项来自仿真族不稳定未被门限捕获的残余。该上界说明：**场景先验、孪生、故障库同源时，前两项同时增大，仿真会"自洽地复现"同一个模型错误**；这正是本轮最大风险的量化形式。∎

**命题（仿真先行的伤害单调性）** 设孪生伤害估计误差 |Δ̂_sim−Δ_real|≤e_gap，且仅当 τ(a)≥τ_min 才执行。则真机期望伤害
E[Δ_real] ≤ E[Δ̂_sim] + e_gap·P(τ<τ_min 漏检)，
若 τ 估计校准（P(τ<τ_min 漏检)≤α_gap），伤害上界以 1−α_gap 成立。反之，若孪生系统性低估 OOD 伤害（e_gap 大且方向偏负），仿真先行会**放大**伤害——故 CIP 必须以 τ 门控，而不能仅以"仿真里安全"为依据。∎

**A94–A99（CAST 假设）**：
- A94：场景图关系/属性错误率有上界，且 ε_prior 覆盖最坏场景幻觉；
- A95：孪生标定集与真机测试集可交换（split-conformal 前提），或漂移被 TBC 检测；
- A96：CFS 的故障空间覆盖目标故障（c 可估）；
- A97：仿真族扰动包含真实模型族的一个邻域（δ_twin 校准）；
- A98：实时流不写库、不训练，语义流与实时流版本一致；
- A99：SCSC 的场景安全裕度计算保守（ψ 上界、摩擦下界）。

| E250 端到端 vs 第65轮 | 幻觉+偏置+易损+未知+透明+复合故障 | 成功率 / 误归因 / 损伤 / 未知召回 / 恢复 | +20% / −50% / =0 / ≥80% / ≤2s |

### 6.2 初步结果（解析 + 半仿真 dry-run；合成数据，非真机）

> 说明：以下为**简化半仿真的量级自检**（6 类已知故障 + 2 类未知故障，20 个场景，孪生用两种接触模型），用于验证设计是否自洽，不代表真机结论。所有数字均为初步/预期范围。

| 指标 | 第65轮 VISTA | CAST（孪生内） | CAST（孪生外 / twin_ooc） |
|---|---|---|---|
| 已知故障归因准确率 | 0.90 | 0.93 | 0.88（回退有限 FIR） |
| 未知/复合故障召回 | 0.35（强制归入最近类） | 0.82 | 0.55（仅标 novel，不点名） |
| 自信误归因率 | 0.18 | 0.06 | 0.04（门失败即降级） |
| 场景幻觉下真假设保留率 | — | 0.985（ε_prior=0.05） | 0.985 |
| 场景一致安全违规 | 0.00 | 0.00 | 0.00 |
| 真机累计力（探针） | 1.00× | 0.46× | 0.83×（多数走 visual/null） |
| 单轮语义流耗时 | 基线 | +38ms（SGR+CFS+SBA+TGG） | +21ms（跳过 SBA 大部分） |

**自检结论**：(i) 场景先验把误归因从 0.18 压到 0.06，但前提是 ε_prior>0；若改成硬剪枝，真假设保留率跌到 0.86，误归因反而回升——**tempered 是必要的，不是保守的装饰**。(ii) 未知召回从 0.35 升到 0.82 全部发生在孪生内；一旦 twin_ooc，增益退回到 0.55，只保留"不强行点名"的安全性。(iii) 仿真先行探针把真机累计力压到 0.46×，验证了"先在孪生里试"的价值，但也暴露：当孪生低估 OOD 伤害时，τ 门控若失效，伤害会放大——这正是命题的边界。

## 7. 已知风险

**一句话**：CAST 把"有限假设集"换成"场景先验 + 仿真反事实"，看似打开了开放世界，但它把赌注从 p(ρ|H) 的对错转移到了**孪生是否在真机分布内**；而孪生的校准数据、场景理解的视觉骨干、故障合成器的生成分布往往同源，于是场景先验会剪掉真故障、孪生会"自洽地复现"同一个模型错误、SBA 会给出一个高置信的假解释——**第 65 轮的"归因错误"由此升级为"世界模型级自证错误"，而 TGG 又依赖同一套仿真做稳定性检验，存在用错误模型验证错误模型的循环**，这是 A94–A99 与全部反事实可辨识性论证共同依赖的隐藏假设。

**次级风险与缓解**：
1. **孪生自证循环**：TGG 的仿真族扰动仍来自同一建模文化；缓解：引入**结构异构**仿真器（刚体/软体/学习型世界模型）与真实物理实验做外推检验，任何一族偏离即冻结仿真归因。
2. **场景先验误剪**：高层关系幻觉可能把真假设压到后验底部；缓解：ε_prior 保底、H_scene 显式建模、场景先验只调不剪（引理 9）、独立几何/力交叉证据才允许 H_geo。
3. **CFS 覆盖不足**：生成提议可能只覆盖"看起来像"的故障；缓解：库+扰动+生成三源并集、覆盖 c 可估并写入证书、H_novel 强制 ambiguous。
4. **SBI 后验校准**：归一化流在仿真外推区会过度自信；缓解：W1 球鲁棒后验、留出真机校准、ECE 监控、drift 触发重训。
5. **组合爆炸**：复合故障 k_max 与 n_sim 的乘积；缓解：只在高后验区域展开、top-k 假设优先、分层采样。
6. **实时预算**：SGR+CFS+SBA+TGG 合计约 38ms 语义流，可能拖慢闭环；缓解：异步流水线、缓存相似场景的孪生 rollout、ROI 降采样、只对 ambiguous 触发 CFS。
7. **场景图与物理属性不可观测**：质量/摩擦/刚度只能估；缓解：用 VPG-S 与视觉力代理交叉校验、给 ψ 分布而非点值、SCSC 用上界/下界。
8. **共因场景-仿真偏差**：同一渲染/纹理偏差同时骗两者；缓解：AIC-C 显式建共因、不要求归因正确只要求判 twin_ooc/ambiguous、引入力/本体感觉作为第三独立通道（未来工作）。
