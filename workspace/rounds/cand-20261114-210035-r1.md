# 第 2 轮（承接第 1 轮「LeanGauge」IP-310~314、定义 398–415；灵感循环第 2 轮；本轮灵感：「视觉-语言-动作模型」×「需求洞察」）

> 第 1 轮 LeanGauge 把「等待大数据」改造成「主动发现需求盲区 + 少样本局部校准」。但它保留了一个从未被写进定义的前提：**需求本身已经被正确地形式化**。D-Box 的覆盖矩阵只在 (距离 × 材质 × 互扰) 的计量坐标上打洞，却无法回答「这个洞与用户真正要的东西是否有关」。真实部署的入口是自然语言与开放词汇任务——「把杯子放到桌沿但别太靠边」「小心地递给我」「除了红的那只都收走」——而对这些话的解释权，通常被交给一个视觉-语言-动作模型（VLA）。VLA 擅长语义泛化，却没有计量学意义上的不确定度：它的语言置信度不能进证书，它对「小心」「太靠边」「除了」的落地也可能与物理契约错位。
>
> 本轮核心命题：
>
> **把 VLA 从「需求的解释者 / 执行者」降格为「接地的提议者」，把「需求洞察」升级为可计量的需求契约覆盖问题——VLA 只提出候选接地、生成语言变体、排序取证位置；一切安全量必须来自 LeanGauge 的见证样本与 MODGAUGE 的契约。系统必须能区分「理解了」与「认证了」，并在二者之间显式允许「问一句」或「保守地做」。**
>
> 设计 **NEEDGAUGE-RAS**（Natural-language nEed Elicitation and evidence-bounD metrology with GAUGE audits for RAS）：「需求接地计量」。IP-315~322；定义 416–429；实验 E426–E438。理论姿态：**NEEDGAUGE 是 LeanGauge 的语义前置层**——不改变其五不变式，只在进入计量前增加「需求契约编译 + 接地覆盖 + 澄清/退化」；当禁用 VLA 或接地集退化为单点时，严格退化为 LeanGauge。

## 0. 直觉与动机

**灵感 1（视觉-语言-动作模型 → 把「提议」与「认证」拆开）**
直觉：VLA 最危险的地方不是它会错，而是它的错误**以 fluent（流畅）的形式出现**。同一个高置信度，既能支持「放在桌沿内侧 2cm」（安全需求），也能支持「放在桌沿外 2cm」（坠落需求）；语言层面二者都「合理」。因此 VLA 的置信度不能作为概率进入安全界，只能作为**提议分布的排序**。真正的问题不是「这个解释对不对」，而是「如何在一个由 VLA 提议的*解释集合*上做认证，而不是在单个解释上做认证」。

**灵感 2（需求洞察 → 需求是一种「带覆盖义务的计量对象」）**
直觉：需求工程里最贵的错误不是实现错，而是**实现了一个错误的、却被完美验证的需求**。LeanGauge 的「需求盲区」只覆盖「计量样本稀疏」；但还有三类更隐蔽的盲区：
- **歧义盲区**：语言允许两个物理上不相容的接地（「左边」依赖观察者坐标系还是物体坐标系？）；
- **覆盖盲区**：接地引用了计量层无法见证的量（「小心」需要力/触觉证据，「太靠边」需要边缘几何证据），而该格的 u 很宽；
- **作用域盲区**：否定 / 量词 / 比较级的作用域（「除了红色的都收走」vs「红色的都不要收」）。
这三类都不是多采几个 (d,m,i) 样本就能消除的——它们是**需求语义**的盲区。

**灵感 3（需求洞察的主动性 → 语言蜕变测试 + 可辨识性二分 + 澄清）**
直觉：需求是否稳定，可以用「语言蜕变关系」来探测：改写应保持需求；否定应取补；量词换序应按已知单调性变化；视角换帧应显式暴露坐标系依赖。若系统对「把杯子放桌沿」与「把杯子放桌沿外侧」给出相同的可行动作集，它就已经发现了作用域盲区。更进一步，必须区分两类不确定度：
- **世界可判定的（world-decidable）**：物体指代、遮挡、真实几何位置——可以靠移动 / 观察 / 主动取证消解；
- **意图不可判定的（intent-underdetermined）**： 「小心」「差不多」「尽量」的规范约定——物理证据再多也无法消解，只能**问**。
如果「问一句」比「多做 20 次物理采样」更便宜，系统应选择澄清，而不是沉默地猜。这把需求洞察从「被动解析」变成「主动取证 + 主动澄清」。

## 1. 形式化定义（增量：定义 416–429）

**定义 416（VLA 接地接口）** VLA 策略 π_VLA: (I, o_{1:t}) → (Â, z_I, c_I)，其中 I 为自然语言指令，Â 为提议动作块，z_I 为语言条件嵌入，c_I 为**未校准**置信度。约定：c_I 只能用于提议排序与采样预算分配，**不得进入任何 EC、R、GC 的安全量**（引理 46）。

**定义 417（需求契约 RC）** 对指令 I 与候选接地 g，RC(I,g) = (φ_I, Π_I, O_I, D_I, α_I)：
- φ_I：可判定的成功谓词（有界时序逻辑；原子命题只允许「可计量状态」或「已认证符号」）；
- Π_I：动作原语集合，每个原语必须已有 MODGAUGE 契约；
- O_I：计量义务（净空 ≥ m、接触力 ≤ f、位置 ∈ 区域、朝向 ∈ 集合）及其容差；
- D_I：需求声明域（物体类别、场景、允许改写集）；
- α_I：风险预算。
若 φ_I 或 O_I 中出现既非可计量变量、又非已认证原语的符号，称该接地含**未接地符号**。

**定义 418（候选接地集与共形接地集）** VLA / LM 对 I 采样得到 K 个候选接地 G_K(I) = {g_1,…,g_K}。取非一致性分数 s(I,g)（如反事实动作集差异、语言蕴含分数、接地程序长度惩罚），用 split-conformal 得到
G_ε(I) = { g : s(I,g) ≤ q_{1-δ} }，
其覆盖声明 P(g* ∈ G_ε) ≥ 1-δ **只在标定指令与部署指令可交换时成立**；样本不足或交换性无法辩护时返回 ⊥（无覆盖保证）。

**定义 419（需求盲区）** 给定 G_ε(I) 与契约集 C = {RC(I,g)}，需求盲区是以下任一：
- **(A) 歧义盲区**：∃ g,g′ ∈ G_ε，其可行动作集 F_g, F_{g′} 的对称差测度 > ε_amb，且交集上不存在可认证计划；
- **(C) 覆盖盲区**：∃ g，其某义务对应的计量格 s 满足 LeanGauge 定义 399（n_verify ≤ τ_n ∧ cost_risk ≥ τ_cost），或含未接地符号；
- **(S) 作用域盲区**：存在语言蜕变 t（否定 / 量词 / 比较 / 视角），使 RC(I) 与 RC(t(I)) 的关系不符合 t 的预期语义关系。
需求盲区是定义 399 在**语义坐标**上的扩展。

**定义 420（需求覆盖矩阵与不确定度二分）** 需求覆盖矩阵
R_req[v] = (n_ground, n_witness, amb, gap, cost_risk)，
v 为语义格（物体类别 × 关系 × 修饰词 × 量词模式）。n_ground 为接地次数；n_witness 为义务被计量见证次数；amb 为接地集分歧度；gap 为未接地符号计数。语义格被**需求覆盖** ⇔ n_witness ≥ τ_n ∧ amb ≤ τ_amb ∧ gap = 0。
对需求盲区中的 g,g′，称其不确定度**世界可判定** ⇔ 存在可用观测 y 使 P(y|g) ≠ P(y|g′)；否则称**意图不可判定**。此二分决定后续走 R-PROBE 还是 ASK-MIN。

**定义 421（计量接地证书 GC）** GC(I) = (G_ε, g*, {EC_o}_{o∈O_{g*}}, Δ_amb, Δ_gap, δ)，g* 为选定接地。GC 有效 ⇔
1. g* ∈ G_ε 且覆盖 ≥ 1-δ；
2. 每个义务 o 的计量格被对应 EC 覆盖；或 g* 为 maximin 接地（定义 422）且覆盖 G_ε 的全部可行交集；
3. Δ_amb ≤ Δ_budget 且 Δ_gap = 0，或附有显式澄清 / 降额记录。
GC 无效时不得进入 MODGAUGE 执行路径。

**定义 422（maximin 接地与鲁棒可行集）** 对 G_ε 定义鲁棒可行集
F_∩ = ⋂_{g∈G_ε} F_g。
若 F_∩ 非空且其中存在一个计划使全部对应 EC 有效，则称存在 maximin 接地 g_⊥（F_{g_⊥} = F_∩），可在不澄清的情况下执行，代价是有界的行为收窄。若 F_∩ = ∅ 或其中无可认证计划，则必须取证或澄清（引理 47、48）。

**定义 423（语言蜕变关系与需求不变性证书）** 蜕变集 T = T_pres ∪ T_neg ∪ T_scope ∪ T_frame：
- T_pres：改写 / 同义替换，预期 d_φ(I,t(I)) ≤ ε_inv；
- T_neg：否定，预期 F_{t(I)} ≈ complement(F_I)；
- T_scope：量词换序 / 比较级交换，预期可行集按已知单调关系变化；
- T_frame：左 / 右、内 / 外坐标系换帧，预期显式暴露坐标系参数。
其中 d_φ(I,I′) 为两条需求诱导可行轨迹集的归一化对称差。需求不变性证书 InvCert = {d_φ(I,t(I)), 关系符合度}；InvCert 有效 ⇔ 所有 T_pres 满足 ε_inv 且其余关系残差 ≤ ε_rel。它把「需求是否稳定」变成可证伪的统计命题（引理 49）。

**定义 424（VLA 引导的主动需求取证）** 给定需求盲区集合 S 与世界可判定的接地歧义，选择探针 (t,a,s)（语言变体、动作、计量位置）最大化
EIG(t,a,s) = I(g*; y_{t,a,s} | G_ε) / cost(t,a,s)，
其中 y 为 LeanGauge 见证的观测。VLA / LM 只提供候选变体与先验排序；EIG 的后验更新只使用见证样本。若 EIG < τ_eig（尤其当歧义为意图不可判定时 EIG ≡ 0），转入澄清。

**定义 425（最小澄清算子）** 候选问题集 Q。若不存在可认证的 g_⊥，输出
q* = argmin_{q∈Q} [ cost_ask(q) + E_{y∼q}[ residual_amb(G_ε | y) ] ]，
并附带「用户不答」时的保守接地 g_⊥ 或停滞 / 遥操作。澄清是需求洞察的第一类公民，而不是失败态。

**定义 426（需求时序契约 RTC）** RTC = (T_elicit, B_req, τ_eig, recovery)：T_elicit 为歧义消解时限；B_req 为取证 + 澄清总预算；recovery 为超时 / 预算耗尽时的严格退化条件。RTC 与 LeanGauge 的 IV-Contract 组合；需求层只在事件触发域运行，硬实时主循环不受影响。

**定义 427（严格退化链）** 失效时按序单调收缩：
GC 有效（完整需求接地）→ maximin 保守接地（免澄清）→ 固定模板语法（禁用开放词汇，只执行预置需求 schema）→ 第 0 层物理包络 / 遥操作 / 停机。每一步只能减小可执行集合。

**定义 428（NEEDGAUGE 总览）** NEEDGAUGE = (MODGAUGE, LeanGauge, VLA-PROP, RC-COMP, R-BOX, G-CAL, INV-TEST, R-PROBE, ASK-MIN, Degradation)。禁用 VLA 时 VLA-PROP 退化为模板解析，G_ε 退化为单点，需求层退化为 LeanGauge 的既有契约，故 NEEDGAUGE 是 LeanGauge 的语义前置增强而非替代。

**定义 429（需求—计量联合安全主张）** 称一次执行在 (α,δ) 下需求安全，若
P( 执行轨迹违反真实需求 φ_{g*} ) ≤ α + δ + ε_rel，
前提是 g* ∈ G_ε 且 GC、全部 EC 有效。注意前提不可省：若真实接地落在 G_ε 之外，右端界失效（见 §7）。

## 2. 关键算法骨架

```python
# IP-315 VLA-PROP：只提议接地，不提供证书
class VLAGrounder:
    def propose(self, I, obs, K=8):
        z = self.vla.encode(I, obs)
        cands = self.vla.sample_groundings(I, z, K)   # 多样化采样
        return sorted(cands, key=lambda g: g.prior_score)  # c_I 仅用于排序

# IP-316 RC-COMP：把候选接地编译成可判定契约，显式标出未接地符号
class RCCompiler:
    def compile(self, I, g):
        phi, prims, obligations = g.to_logic()
        ungrounded = [s for s in phi.symbols
                      if not (self.is_metric(s) or self.is_certified_primitive(s))]
        return RequirementContract(phi, prims, obligations, ungrounded, g.domain)

# IP-317 R-BOX：语义盲区检测（歧义 / 覆盖 / 作用域）
class RBox:
    def classify(self, G_eps, contracts, R_req):
        spots = set()
        if self._ambiguous(G_eps, contracts):      # 对称差 > ε_amb 且交集不可认证
            spots.add("A")
        for g in G_eps:
            c = contracts[g]
            if c.ungrounded or any(self._metric_blind(o) for o in c.obligations):
                spots.add("C")
        spots |= self._scope_spots(G_eps, contracts)  # 预筛，交给 INV-TEST 确认
        return spots

# IP-318 G-CAL：共形接地集 + maximin 交集
class GroundingCalibrator:
    def conformal_set(self, scored, delta):
        if not self.exchangeable_ok:
            return BOTTOM                      # 无覆盖保证，禁止认证
        q = quantile([s for _, s in scored], 1 - delta)
        return [g for g, s in scored if s <= q]

    def maximin(self, G_eps, contracts):
        F = intersect_feasible([contracts[g].F for g in G_eps])
        if F.is_empty():
            return None
        for plan in order_by_conservativeness(F):
            if all(self._ec_valid(o) for o in plan.obligations):
                return plan                 # g_⊥ 的构造性见证
        return None

# IP-319 INV-TEST：语言蜕变不变性
class InvarianceTester:
    def test(self, I, transforms):
        base = compile(self.parse(I))
        cert = {}
        for t in transforms:
            phi_t = compile(self.parse(t.apply(I)))
            d = symmetric_difference(base.F, phi_t.F)
            cert[t] = self._relation_residual(t, d)   # 预期关系 vs 实测
        return InvarianceCert(cert, ok=all(r <= self.eps[t] for t, r in cert.items()))

# IP-320 R-PROBE：只用世界可判定信息做主动取证
class RequirementProber:
    def choose(self, spots, G_eps, world_decidable, budget):
        cands = [(t, a, s) for s in spots for a in self._actions(s) for t in self._variants()]
        scored = [(self._eig(t, a, s, G_eps), c) for (t, a, s), c in cands]
        best = max((x for x in scored if x[1] <= budget), key=lambda x: x[0], default=None)
        return best if best and best[0] >= self.tau_eig else None

# IP-321 ASK-MIN：意图不可判定时的最小澄清
class MinimalClarifier:
    def ask(self, G_eps, contracts):
        if not G_eps:
            return self.template_fallback()
        q = min(self.questions, key=lambda q: q.cost + self._residual_after(q, G_eps, contracts))
        return Clarification(q, fallback=self._safe_default(G_eps))

# IP-322 NEEDGAUGE 主闭环
def NEEDGAUGE_round(M, obs, I):
    G_k = VLAGrounder.propose(I, obs)                       # 提议
    C = {g: RCCompiler.compile(I, g) for g in G_k}
    G_eps = GroundingCalibrator.conformal_set(score(I, G_k), M.delta)
    if G_eps is BOTTOM:
        return M.degrade("no_grounding_coverage")           # 无覆盖保证，禁止认证
    spots = RBox.classify(G_eps, C, M.R_req)
    inv = InvarianceTester.test(I, M.transforms)
    if spots or not inv.ok:
        g_bot = GroundingCalibrator.maximin(G_eps, C)
        if g_bot is not None:
            return MODGAUGE_round(M, obs, g_bot)            # 免澄清、保守执行
        probe = RequirementProber.choose(spots, G_eps, M.world_decidable, M.B_req)
        if probe is not None:
            samples = LeanGauge.IBox.execute(probe)         # 只采见证样本
            LeanGauge.BPCal.calibrate(samples)              # 只更新计量契约
            return NEEDGAUGE_round(M, obs, I)               # 重新接地
        return MinimalClarifier.ask(G_eps, C)               # 或 RTC 超时后退化
    return MODGAUGE_round(M, obs, G_eps.selected, grounding_cert=GC(I, G_eps, inv))
```

## 3. 推导

**引理 46（提议—证书分离 / VLA 置信度不可入证）** 存在两个需求世界 W、W′ 与指令 I，使 π_VLA 在同一观测上给出相同 c_I，但真实需求分别为 φ 与 ¬φ。因此任何仅依赖 c_I 的执行规则，其需求违反概率不能被任何小于 1/2 的界控制。系：c_I 只能作为排序 / 采样启发式；安全量必须来自见证。

**引理 47（maximin 交集的充分性）** 若 g* ∈ G_ε，F_∩ = ⋂_{g∈G_ε} F_g 非空，且存在计划 π ∈ F_∩ 使其全部义务的 EC 有效，则执行 π 可保证需求满足概率 ≥ 1-α-δ，无需知道哪个 g 为真。证明：π ∈ F_∩ ⇒ 对任意 g ∈ G_ε 均满足 φ_g ⇒ 在事件 g* ∈ G_ε 上满足 φ_{g*}；再用覆盖概率 1-δ 与契约风险 α 取并集界。

**引理 48（需求不确定度的可辨识性二分）** 若对可用观测 y 与任意 g,g′ ∈ G_ε 都有 P(y|g) = P(y|g′)，则任意有限次物理取证都不能降低 G_ε 的后验熵；此时唯一合法的消解手段是澄清或取 F_∩。特别地，意图不可判定歧义（修饰词 / 规范性约定）满足该条件，故 R-PROBE 对其 EIG ≡ 0。系（澄清必要性）：若 F_∩ = ∅ 且歧义意图不可判定，则不做澄清就不可能认证任一单一解释（最坏成功概率上界 < 1）。

**引理 49（蜕变测试的检出力）** 设蜕变集 T 分离作用域 / 否定盲区：错误接地在至少一个 t 上产生 ≥ ε_rel 的关系残差。则 n 次独立蜕变观测后漏检概率 ≤ exp(-2n ε_rel² / L²)（Hoeffding 型，L 为残差有界常数）。反之，通过全部关系的接地程序，其语义误差被 ε_inv、ε_rel 与 T 的覆盖度共同界定；T 不覆盖的语义维度不受保护。

**引理 50（VLA 引导采样的样本复杂度）** 若语言先验把真实盲区格排在前 k 的概率为 p，则达到相同置信度所需见证数从 n_min 降为 O(n_min / p_eff)，p_eff ≥ p/k；当先验与真实盲区无关时 p_eff = 1/k，仅得常数因子，最坏情形不优于 LeanGauge（无免费午餐）。系：VLA 降低平均样本量，不改变最坏情形下界。

**定理 22（需求—计量端到端安全）** 若 (a) g* ∈ G_ε 以概率 ≥ 1-δ；(b) GC 有效；(c) 所有被执行的 EC 有效；(d) 蜕变关系残差 ≤ ε_rel；则需求违反概率 ≤ α+δ+ε_rel。证明：对「接地漏出、契约失效、不变性失效」三类事件取并集界；执行只使用 GC 覆盖且 EC 有效的原语，故无额外未计量项。

**引理 51（严格退化）** 若 VLA-PROP 退化为模板解析且 G_ε 为单点，则 R-BOX、R-PROBE、ASK-MIN 退化为空操作，NEEDGAUGE 精确退化为 LeanGauge；若再禁用需求层，退化为 MODGAUGE。两种退化都只减小可执行集合。

## 6. 次级风险与缓解

1. **共形覆盖依赖可交换性** → 指令分布漂移时返回 ⊥ 并退化为模板 schema；对语言变体做分层校准。
2. **蜕变集不完备** → 未覆盖的语义维度显式标注为「不受保护」；高价值维度加入预注册蜕变库。
3. **maximin 过保守导致不可用** → 主动取证优先收缩 F_∩；必要时澄清；明确报告行为收窄上界。
4. **澄清问题本身有误导性** → 问题由「区分接地」而非「引导答案」生成；双盲回放评测；提供「不确定」选项。
5. **VLA 语义幻觉 / 提示注入** → VLA 永不入证；对抗指令触发 GC 失效；第 0 层物理包络兜底。
6. **未接地符号被误当作可计量** → 符号白名单 + 传感器能力注册表；新增符号必须绑定 EC 才能认证。
7. **需求漂移（用户改主意）** → R_req 带时间戳与新鲜度；RTC 到期强制重新接地；旧证书不可跨需求复用。
8. **实时性与澄清延迟冲突** → T_elicit 超时即走 maximin 或遥操作；澄清不阻塞硬实时主循环。

## 7. 本轮最大风险

**一句话**：NEEDGAUGE 的全部安全界都建立在「真实需求接地 g* 落在共形集 G_ε 内」这一前提上，而 g* 本身不可观测、由用户 / 语言 / 文化约定决定；当指令落在开放词汇的新颖语义区、包含规范性 / 模糊修饰（「小心」「差不多」「尽量」）、或被提示注入 / 分布漂移操纵，且标定指令与部署指令不再可交换时，G_ε 可能**高置信地漏掉真实需求**——系统于是拿到一份对「错误问题」的完整计量证书：所有模块都合规、所有契约都有效，却精确地满足了用户没要的东西；这是「自信地组合错误世界」的需求工程版本，比 LeanGauge 的计量盲区更根本，因为校准只能修正答案，不能发现问错了问题。

- (C) 覆盖：义务所在计量格满足定义 399，或接地含未接地符号；
- (S) 作用域：语言蜕变后的关系不符合预期语义关系。

# IP-315 VLA-PROP：只提议，不认证
class VLAGrounder:
    def propose(self, I, obs, K=8):
        z = self.vla.encode(I, obs)
        return sorted(self.vla.sample_groundings(I, z, K),
                      key=lambda g: g.prior_score)      # c_I 仅排序

# IP-316 RC-COMP：自然语言 → 可判定契约，显式标未接地符号
class RCCompiler:
    def compile(self, I, g):
        phi, prims, obligations = g.to_logic()
        ungrounded = [s for s in phi.symbols
                      if not (self.is_metric(s) or self.is_certified_primitive(s))]
        return RequirementContract(phi, prims, obligations, ungrounded, g.domain)

# IP-317 R-BOX：歧义 / 覆盖 / 作用域三类语义盲区
class RBox:
    def classify(self, G_eps, contracts, R_req):
        spots = set()
        if self._ambiguous(G_eps, contracts):  spots.add("A")
        for g in G_eps:
            c = contracts[g]
            if c.ungrounded or any(self._metric_blind(o) for o in c.obligations):
                spots.add("C")
        spots |= self._scope_spots(G_eps, contracts)
        return spots

# IP-318 G-CAL：共形接地集 + maximin 交集
class GroundingCalibrator:
    def conformal_set(self, scored, delta):
        if not self.exchangeable_ok: return BOTTOM       # 无覆盖保证
        q = quantile([s for _, s in scored], 1 - delta)
        return [g for g, s in scored if s <= q]

    def maximin(self, G_eps, contracts):
        F = intersect_feasible([contracts[g].F for g in G_eps])
        if F.is_empty(): return None
        for plan in order_by_conservativeness(F):
            if all(self._ec_valid(o) for o in plan.obligations):
                return plan                              # g_⊥ 的构造性见证
        return None

# IP-319 INV-TEST：语言蜕变不变性
class InvarianceTester:
    def test(self, I, transforms):
        base = compile(self.parse(I))
        cert = {t: self._relation_residual(t, base, compile(self.parse(t.apply(I))))
                for t in transforms}
        return InvarianceCert(cert, ok=all(r <= self.eps[t] for t, r in cert.items()))

# IP-320 R-PROBE：只对世界可判定歧义做 EIG 选样
class RequirementProber:
    def choose(self, spots, G_eps, world_decidable, budget):
        cands = [(t, a, s) for s in spots for a in self._actions(s) for t in self._variants()]
        scored = [(self._eig(t, a, s, G_eps), c) for (t, a, s), c in cands]
        best = max((x for x in scored if x[1] <= budget), key=lambda x: x[0], default=None)
        return best if best and best[0] >= self.tau_eig else None

class MinimalClarifier:

        q = min(self.questions, key=lambda q: q.cost + self._residual_after(q, G_eps, contracts))
        return Clarification(q, fallback=self._safe_default(G_eps))

## 4. 推导

**引理 46（提议—证书分离）** 存在 W、W′ 使同一观测下 `c_I` 相同而真实需求为 φ 与 ¬φ；故任何仅依赖 `c_I` 的规则，需求违反概率不能被小于 1/2 的界控制。系：`c_I` 只能用于排序 / 采样预算。

**引理 47（maximin 交集充分性）** 若 `g*∈G_ε` 且 `F_∩` 存在全部 EC 有效的计划 π，则执行 π 的需求满足概率 ≥1−α−δ，无需知道哪个 g 为真。

**引理 48（可辨识性二分与澄清必要性）** 若对所有可用 y 有 `P(y|g)=P(y|g′)`，有限次物理取证不能降低 `G_ε` 后验熵；意图不可判定歧义满足此条件，故 R-PROBE 的 EIG≡0。若再有 `F_∩=∅`，不澄清就不可能认证任一单一解释。

**引理 49（蜕变检出力）** 若错误接地在至少一个 t 上产生 ≥ε_rel 残差，则 n 次观测漏检概率 ≤exp(−2nε_rel²/L²)；T 未覆盖的语义维度不受保护。

**引理 50（VLA 引导采样的样本复杂度）** 语言先验把真实盲区排前 k 的概率为 p 时，达到同置信度的见证数从 n_min 降为 O(n_min/p_eff)，p_eff≥p/k；先验无关时仅常数因子，最坏不优于 LeanGauge。

**定理 22（需求—计量端到端安全）** 若 (a) `g*∈G_ε` 概率 ≥1−δ；(b) GC 有效；(c) 全部 EC 有效；(d) 蜕变残差 ≤ε_rel，则需求违反概率 ≤α+δ+ε_rel。

**引理 51（严格退化）** 模板解析 + 单点 G_ε 时 NEEDGAUGE 精确退化为 LeanGauge；再禁用需求层退化为 MODGAUGE，且只减小可执行集合。

## 7. 本轮最大风险

**一句话**：NEEDGAUGE 的安全界依赖「真实需求接地 `g*` 落在共形集 `G_ε` 内」，而当开放词汇指令、规范性模糊修饰或提示注入使标定指令与部署指令不再可交换时，`G_ε` 可能高置信地漏掉真实需求，系统就会拿着一份对「错误问题」的完整计量证书，精确满足用户没要的东西——校准只能修正答案，不能发现问错了问题。
