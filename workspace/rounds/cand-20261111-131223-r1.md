# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「云端协同」×「长程任务」）

> 第 54 轮把技能组合推进到动作空间剖面与云边契约，但仍是"单步/单技能可达"的证书体系，没有正面回答长程任务的三类本质困难：(i) 风险与误差随视界**累积**；(ii) 失败根因在时间上**迟到**，即时 Explain 无法归因到很早以前的决策；(iii) 云端规划与边端执行在长时标上**陈旧、漂移、失联**。本轮将证书从"瞬时对象"升级为"**带视界的时域对象**"：预算、排名超鞅、租约、可续性、任意时有效监控与时序选项。核心矛盾：H22：长程失败往往不是单步能力不足，而是预算/租约/可续性在视界内被静默耗尽；H23：长程信用归因无法在单点完成，必须在时间窗口与反事实干预下判定，否则会把"最后一步的偶然"误判为"根因"。

## 0. 直觉与动机

**灵感 1（长程任务 = ε 预算的时域可行性，而非步数堆叠）**
直觉：短程问"这一步能不能做"，长程问"做完这些步之后还剩不剩容错"。把每一步的鲁棒裕度看成消耗品 ε：任务是一份 **ε 预算**，技能组合是预算的分配、消耗与回收。若存在正下界 ε_min 使风险潜势每步期望至少下降 ε_min，则完成时间的尾概率以 **O(1/H)** 衰减，而不是随视界线性变坏。长程真正需要的不是更多局部证书，而是一条**排名超鞅（ranking supermartingale）**：它把"每步都对"换成"整段可终止且有界"。

**灵感 2（长程失败 = 迟到的因果，需要窗口化信用归因）**
直觉：边端在第 t 步报警，根因可能在 t−W 的云端技能选择。把 Explain 从"瞬时根因"扩展为**时域信用证书**：在窗口 W 内对技能段做反事实干预 `do(seg_i → alt)`，用失败概率变化量归因；云端持有长程因果图，边端持有细粒度轨迹，用逻辑时钟把两段轨迹缝合。归因不是解释"哪一步坏了"，而是解释"哪一步的选择使后面**必然**坏"，从而把云端重规划从"救火"变成"改因"。

**灵感 3（云端协同 = 有限期租约，而非一次性规划）**
直觉：云端的长程计划在发出瞬间就开始过期。把计划写成**带 TTL 的租约** `L = (P_c, τ_lease, φ_assume, E_safe)`：边端只在"未过期 ∧ 假设仍成立 ∧ 状态在安全包络内"时执行；过期则降级到本地安全策略或申请续约。权限随时间和陈旧度**单调衰减**（authority attenuation），边端只能在安全包络内做有界本地延展，绝不能自行扩张动作集。这把分布式系统的 lease（Gray–Cheriton）思想引入具身长程任务。

**灵感 4（长程可恢复性 = 后向可达的可续集）**
直觉：长任务最危险的不是失败，而是进入"再也回不来"的状态（打翻唯一工具、耗尽唯一电量、卡进不可逆位形）。定义**可续集** `Res_k`：从这里出发，剩余 k 步内仍能完成任务且预算不超。把检查点当作**义务**：每个 checkpoint 必须落在 `Res_{H−t}` 内。云端算后向可达（viability kernel），边端做保守成员判定，并定义**不可逆裕度**，度量"还有多少步可以反悔"。

**灵感 5（非平稳视界 = 任意时有效的证书监控）**
直觉：长程中"假设置信"会漂移，固定视界的显著性检验会被"看数据看到显著为止"污染。用 **e-process** 做任意时有效（anytime-valid）监控：一旦证据超过 `1/α` 阈值就自动吊销证书并触发再认证。证书因此拥有**自适应 TTL**，而不是拍脑袋的固定过期时间；这正好补上租约"什么时候该续、该不该信"的判定缺口。

**灵感 6（分层时域抽象 = 带时序契约的选项）**
直觉：长程任务是半马尔可夫决策过程，技能应写成 option `(I, β, π, D, Inv)`：启动集、终止集、策略、时长分布、全程不变式。组合不仅要求第 54 轮的动作兼容，还要求**终止—启动相容**与**时长/截止期可合成**。这把长程组合从"动作序列"提升为"带时限与不变式的选项链"。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（长程 ε 预算账户）**
视界 H。技能/选项 S 单步风险注入 `c_S(s) ≥ 0`，安全裕度 `b_S(s) ≥ 0`，有效下降 `d_S(s) = b_S(s) − c_S(s)`。云端把总预算 `ε_req(H)` 分配给技能段 `ε_1,…,ε_k`，满足 `Σ_i ε_i ≥ ε_req(H)`。称前缀 t 可行，当且仅当账户
```
E_t = E_0 − Σ_{k<t} c_k + Σ_{k<t} b_k  ≥  V(s_t)
```
其中 V 为定义 122 的风险潜势。**要点**：预算不是"步数配额"，而是"容许风险注入的累计额度"；`d_S ≥ ε_min > 0` 是长程可终止性的根条件。

**定义 122（排名超鞅长程证书 RSM）**
风险潜势 `V : S → R_{≥0}`，成功终态 `V(s)=0`。若对每个技能段
```
E[ V(s_{t+1}) | s_t, S_t ]  ≤  V(s_t) − d_{S_t}(s_t),     d_{S_t} ≥ d_min > 0
```
则称 `(V, d_min, B=V(s_0))` 为长程证书。令 τ 为首达成功时间，由可选停时/超鞅不等式：
```
P(τ > H)  ≤  B / (d_min · H)
```
即尾概率随 H 以 **O(1/H)** 衰减，与视界无线性膨胀。组合时要求各段 `d_{S_i} ≥ ε_i` 且 `Σ ε_i ≥ ε_req(H)`；这把第 54 轮的 `compat / ρ` 从"单步门槛"变成"可分配预算"。

**定义 123（时域信用证书 TCC）**
失败发生于 t 时，取窗口 `W` 与技能段 `seg_1,…,seg_m ⊆ [t−W, t]`。在仿真/回放中对段做反事实干预：
```
A_i = E[Y | do(seg_i := alt)] − E[Y],     Y ∈ {0,1} 为失败指示
N   = { i : |A_i| ≥ δ_attr }              （必要因集合）
```
时域信用证书 `TCC = (W, {A_i}, N, trace_c, trace_e, conf)`，其中 `trace_c` 为云端规划日志、`trace_e` 为边端执行轨迹，经逻辑时钟缝合。**要点**：归因对象是"段的选择"而非"单步动作"，从而与长程决策粒度一致。

**定义 124（租约式时域契约 LTC）**
云端计划租约 `L = (P_c, t_0, τ_lease, φ_assume, E_safe, κ)`：
- `P_c` 云端计划；`t_0` 签发时刻；`τ_lease` 有效期；
- `φ_assume(t,s)` 计划成立的前提谓词（动作可用、地形、电量、通信）；
- `E_safe` 边端安全包络；`κ` 允许的本地续约次数（有界授权）。
有效性谓词：
```
valid(t,s)  ⇔  (t − t_0 ≤ τ_lease) ∧ φ_assume(t,s) ∧ (s ∈ E_safe)
```
**权限衰减**：`A_edge(t) ⊆ A_edge(t_0)` 单调不增；边端续约只能在 `E_safe` 内延展，不得扩张动作集；超出则必须回云重签。陈旧上界 `Δ(τ_lease)` 单调不减且 `Δ(0)=0`。

**定义 125（可续集与不可逆裕度 RSC）**
任务剩余视界 k、剩余预算 B_rem 的可续集：
```
Res_0 = Goal
Res_k = { s : ∃ a,  s' ∈ Res_{k−1},  c(s,a) + V(s') ≤ B_rem }
```
检查点义务：第 t 步状态必须满足 `s_t ∈ Res_{H−t}`。不可逆裕度
```
m(s) = max{ k : s ∈ Res_k }
```
`m(s)=0` 表示已进入不可续状态。云端计算后向可达，边端用**内近似**（保守）分类器判定，保证 soundness：判"可续"绝不把不可续判成可续。

**定义 126（任意时有效证书监控 AVC）**
对原假设 H0"证书假设仍成立"构造 e-process `E_t`（`E_0=1`，H0 下为非负超鞅）。由 Ville 不等式：
```
P_{H0}( ∃ t : E_t ≥ 1/α )  ≤  α
```
当 `E_t` 首次越过 `1/α` 即吊销证书并触发再认证；首次越界时间为**自适应 TTL**。与固定视界检验不同，它在任意停时都保持 I 类错误控制，抗"看数据看到显著为止"。

**定义 127（时序选项证书 TOC）**
选项 `O = (I, β, π, D, Inv, deadline)`：启动集 I、终止集 β、策略 π、时长分布 D、全程不变式 Inv、截止期 deadline。组合 `O_1 → O_2` 可判定，当且仅当
```
β_{O_1} ⊆ I_{O_2}  ∧  sup D_1 + inf D_2 ≤ deadline  ∧  Inv 在衔接边界保持
```
这把第 54 轮的动作兼容性扩展为"终止—启动 + 时长 + 不变式"三重相容。

**定义 128（长程联合证书 LH-JC）**
```
J_H = (V, d_min, B, TCC, L, {Res_{H−t}}, E_t, TOC_chain, evidence)
```
部署判决：
```
accept  ⇔  L.valid  ∧  ∀ t: s_t ∈ Res_{H−t}  ∧  E_t < 1/α
           ∧  B ≤ B_budget(H)  ∧  TCC 附证据  ∧  d_min ≥ ε_min
```
任一不满足则 `defer` 或 `abort`，不得"带病放行"。

## 2. 关键算法 伪代码

### IP-121/122 HBA-RSM（Horizon Budget + Ranking Supermartingale）

```python
def compose_horizon_budget(skill_seq, H, eps_req):
    # 云端按段分配 ε，并要求每段有正的有效下降
    eps = allocate_eps(skill_seq, H, eps_req)          # Σ eps_i ≥ eps_req
    d_min = min(segment_descent(s, eps_i) for s, eps_i in zip(skill_seq, eps))
    if d_min <= 0:
        return ('reject', 'no_positive_descent')
    V = conservative_potential(skill_seq)              # 上包络，sound
    B = V(initial_state)
    return ('ok', HorizonCert(V=V, d_min=d_min, B=B, eps=eps))

def monitor_tail(cert, H):
    # 运行中只需在线检查 V 与预算账户
    for t, s in enumerate(rollout):
        if V(s) > budget_account(t):
            return ('abort', t, 'budget_exhausted')
        if empirical_descent(t) < cert.d_min * (1 - margin):
            return ('recertify', t, 'descent_violation')
    return ('ok', 'tail_bound', cert.B / (cert.d_min * H))
```

### IP-123 TCC（Temporal Credit Certificate）

```python
def temporal_credit(trace, fail_t, W, sim, alt_policy, delta_attr):
    segs = segment_skills(trace, fail_t - W, fail_t)
    base = sim.failure_rate(trace)
    A = {}
    for i, seg in enumerate(segs):
        cf = sim.replay(trace, intervene={i: alt_policy(seg)})
        A[i] = cf.failure_rate - base
    necessary = [i for i, a in A.items() if abs(a) >= delta_attr]
    return TCC(window=(fail_t - W, fail_t), attribution=A,
               necessary=necessary, trace_c=cloud_log(trace),
               trace_e=edge_log(trace), conf=sim.confidence())
```

### IP-124 LTC（Lease-based Temporal Contract）

```python
def issue_lease(plan_c, t0, tau_lease, phi, E_safe, kappa):
    return Lease(P_c=plan_c, t0=t0, tau_lease=tau_lease,
                 phi=phi, E_safe=E_safe, kappa=kappa, renewals=0)

def edge_execute_with_lease(L, s, t, local_safe_policy):
    if not (t - L.t0 <= L.tau_lease and L.phi(t, s) and s in L.E_safe):
        if L.renewals < L.kappa and s in L.E_safe:
            L.renewals += 1
            return ('extend_local', local_safe_policy(s), L)
        return ('request_renew', 'stale_or_unsafe')
    return ('execute', L.P_c.next_action(s), L)
```

### IP-125 RSC（Resumption / Viability Certificate）

```python
def backward_resumable(goal, H, budget, gamma=1.0):
    Res = {0: set(goal)}
    for k in range(1, H + 1):
        Res[k] = {s for s in state_space
                  if exists_action(s, Res[k-1], budget, gamma)}
    return Res

def checkpoint_ok(s_t, t, H, Res, epsilon=0.0):
    # 内近似：只有确定在 Res 内才返回 True
    return inner_membership(s_t, Res[H - t]) and (H - t) > epsilon
```

### IP-126 AVC（Anytime-Valid Certificate Monitor）

```python
def e_process_update(E_prev, x_t, h0_mu, betting=0.5):
    # 以有界随机变量为例的 betting e-process
    factor = 1 + betting * (x_t - h0_mu)
    return E_prev * max(factor, 1e-12)

def monitor_certificate(stream, alpha=0.05):
    E = 1.0
    for t, x in enumerate(stream):
        E = e_process_update(E, x, h0_mu=assumed_mean())
        if E >= 1.0 / alpha:
            return ('revoke', t, E)     # 自适应 TTL 到期
    return ('valid', E)
```

### IP-127 LH-JC（Long-Horizon Joint Certificate）

```python
def long_horizon_certify(skill_seq, H, L, Res, e_trace, tcc, alpha):
    cert_h = compose_horizon_budget(skill_seq, H, eps_req(H))
    if cert_h[0] != 'ok':
        return ('reject', 'budget', cert_h)
    if not L.valid(now(), current_state):
        return ('defer', 'lease_invalid')
    if not all(checkpoint_ok(s_t, t, H, Res) for t, s_t in enumerate(trace)):
        return ('abort', 'irreversible_state')
    if e_trace[-1] >= 1.0 / alpha:
        return ('recertify', 'assumption_drift')
    if tcc is None or not tcc.necessary:
        return ('defer', 'missing_temporal_credit_evidence')
    return ('accept', LHJC(cert_h, L, Res, tcc, e_trace))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| HBA-RSM | O(|S|²·k + |S|·H) | O(|S|) | V 为上包络、每段 d≥d_min |
| TCC | O(m·|W|·T_sim) | O(|W|) | 干预可回放、逻辑时钟对齐 |
| LTC | O(1) 每次查询 | O(|P_c|) | TTL 单调、权限不扩张 |
| RSC | O(H·|S|·|A|)（可采样近似） | O(H·|S|) | 内近似 sound、边界保守 |
| AVC | O(1) 每次更新 | O(1) | H0 下 e-process 超鞅 |
| TOC | O(|O|²) | O(|O|) | 终止—启动相容、时长可合成 |

**正确性定理（Long-Horizon Cloud-Edge Certified Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
- **(A29)** 每个技能段的排名超鞅条件成立，`d_{S_i} ≥ d_min > 0`；
- **(A30)** 租约期内真实云边偏差 `||s_c − s_e|| ≤ Δ(τ_lease)`，且 `Δ` 单调、`Δ(0)=0`；
- **(A31)** AVC 的 e-process 在 H0 下有效，误吊销概率 ≤ α，漂移检测延迟 ≤ δ_det；
- **(A32)** 可续集以**内近似**计算，判"可续"是 sound 的。
则长程部署的失败概率
```
P(fail before H)  ≤  B/(d_min·H)  +  α  +  P(||s_c−s_e|| > Δ)  +  P(δ_a > Θ_a)  +  β_E
```
其中第一项是长程尾界（与 H 成反比），第二项是任意时监控的误判预算，第三项是租约陈旧越界，第四项承接第 54 轮动作对齐，第五项为仿真—现实差。关键：**长程保证来自超鞅下降率，而非步数乘积**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 潜势 V 学不准导致虚假下降率 | 高 | 上包络 + 区间证书 + 在线经验下降率下置信界 |
| 长程反事实归因不可识别 | 高 | 随机微干预 + 锚点回放 + 仅报告必要因（保守） |
| 租约续约抖动/活锁 | 中 | hysteresis + 续约次数上限 κ + 安全策略兜底 |
| 可续集近似过松/过紧 | 高 | 内近似 sound + 关键状态双向验证 + 不可逆裕度告警 |
| e-process 模型错配导致迟检 | 中 | 非参数 betting/似然比 e-process + 多监控器取最大 |
| 逻辑时钟缝合错位污染归因 | 中 | 单调逻辑时钟 + 因果序校验 + 缝合证据审计 |

## 6. 本轮最大风险

**一句话**：把长程保证建立在"每步期望下降 `d_min`"与"租约内假设不变"这两条上，本质上是在赌一个**未被证伪的潜势**和**尚未漂移的语境**；一旦 V 被高估、`d_min` 被仿真乐观化，或漂移发生在监控检测延迟窗口内，系统会以"有证书"的姿态执行一条真实失败概率随 H 增长的长任务，而且比无证书系统更危险——因为证书本身制造了过度自信。故必须以 **保守上包络潜势 + 任意时有效监控 + 内近似可续集 + 独立长程红队审计** 四重护栏，宁可频繁降级，绝不把"纸面长程证书"当作部署许可。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim⁺⁺⁺⁺（LH-CEC：长程云边契约演算）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++：ACS×SCOM×CEC×AEC×JTC）。第 54 轮解决"技能能否在动作空间里组合并云边对齐"，但仍以单步/单技能可达为证书单位，无法回答长程任务的累积风险、迟到归因与计划陈旧。本轮引入 **长程云边契约演算（Long-Horizon Cloud-Edge Contract Calculus, LH-CEC）**，把证书升级为带视界的时域对象：
> - **HBA（Horizon Budget Account）**：ε 预算的时域分配与前缀可行性；
> - **RSM（Ranking Supermartingale Certificate）**：以 `O(1/H)` 尾界替代步数乘积的鲁棒性保证；
> - **TCC（Temporal Credit Certificate）**：窗口化反事实信用归因，跨云边轨迹缝合；
> - **LTC（Lease-based Temporal Contract）**：带 TTL、权限衰减与有界续约的云边契约；
> - **RSC（Resumption / Viability Certificate）**：后向可达可续集与不可逆裕度；
> - **AVC（Anytime-Valid Certificate Monitor）**：e-process 驱动的自适应证书吊销；
> - **TOC（Temporal Option Certificate）**：带时长与不变式的选项链组合。
>
> IP 编号：IP-121~IP-127（共 7 个新增），并升级 IP-116/117/118/120 以纳入长程时域维度。

## 0. 核心 IP 设计

| 编号 | 名称 | 类型 | 关键改进 |
|---|---|---|---|
| IP-121 | HBA Horizon Budget Account | 新增 | 长程 ε 预算账户 `E_t`，前缀可行性 + 段级下降率分配 |
| IP-122 | RSM Ranking Supermartingale Certificate | 新增 | `(V,d_min,B)`，尾界 `P(τ>H) ≤ B/(d_min·H)` |
| IP-123 | TCC Temporal Credit Certificate | 新增 | 窗口 `W` 内 `do(seg_i→alt)` 反事实归因，必要因集合 N |
| IP-124 | LTC Lease-based Temporal Contract | 新增 | 租约 `(P_c,t_0,τ_lease,φ,E_safe,κ)`，权限单调衰减 |
| IP-125 | RSC Resumption Certificate | 新增 | 可续集 `Res_k` + 不可逆裕度 `m(s)` + 检查点义务 |
| IP-126 | AVC Anytime-Valid Certificate Monitor | 新增 | e-process 任意时有效，阈值 `1/α` 触发吊销/再认证 |
| IP-127 | LH-JC Long-Horizon Joint Certificate | 新增/集成 | 长程联合证书与 `accept/defer/abort` 部署判决 |

**对既有 IP 的升级**：
- IP-116 SCOM：边权从 `(compat,c_trans,ρ_comp)` 扩展为 `(compat,c_trans,ρ_comp,ε_budget,deadline)`；
- IP-117 CEC：由"一次性规划—校验"升级为"租约签发—边端有界延展—回云重签"；
- IP-118 AEC：联合证书增加 `TCC` 与 `Res` 字段，支持长程归因与可续性；
- IP-120 JTC：迁移证书增加目标侧 `d_min` 与剩余视界 `H` 的预算匹配检查。

## 2. 关键算法 伪代码

### IP-121/122 HBA-RSM

```python
def compose_horizon_budget(skill_seq, H, eps_req):
    eps = allocate_eps(skill_seq, H, eps_req)        # Σ eps_i ≥ eps_req
    d_min = min(segment_descent(s, eps_i)
                for s, eps_i in zip(skill_seq, eps))
    if d_min <= 0:
        return ('reject', 'no_positive_descent')
    V = conservative_potential(skill_seq)            # 上包络，sound
    return ('ok', HorizonCert(V=V, d_min=d_min,
                              B=V(initial_state), eps=eps))

def tail_monitor(cert, rollout):
    for t, s in enumerate(rollout):
        if cert.V(s) > budget_account(t):
            return ('abort', t, 'budget_exhausted')
        if empirical_descent(t) < cert.d_min * (1 - margin):
            return ('recertify', t, 'descent_violation')
    return ('ok', 'tail_bound', cert.B / (cert.d_min * len(rollout)))
```

### IP-123 TCC

```python
def temporal_credit(trace, fail_t, W, sim, alt_policy, delta_attr):
    segs = segment_skills(trace, fail_t - W, fail_t)
    base = sim.failure_rate(trace)
    A = {}
    for i, seg in enumerate(segs):
        cf = sim.replay(trace, intervene={i: alt_policy(seg)})
        A[i] = cf.failure_rate - base
    necessary = [i for i, a in A.items() if abs(a) >= delta_attr]
    return TCC(window=(fail_t - W, fail_t),
               attribution=A, necessary=necessary,
               trace_c=cloud_log(trace), trace_e=edge_log(trace),
               conf=sim.confidence())
```

### IP-124 LTC

```python
def issue_lease(plan_c, t0, tau_lease, phi, E_safe, kappa):
    return Lease(P_c=plan_c, t0=t0, tau_lease=tau_lease,
                 phi=phi, E_safe=E_safe, kappa=kappa, renewals=0)

def edge_execute_with_lease(L, s, t, local_safe_policy):
    if not (t - L.t0 <= L.tau_lease and L.phi(t, s) and s in L.E_safe):
        if L.renewals < L.kappa and s in L.E_safe:
            L.renewals += 1
            return ('extend_local', local_safe_policy(s), L)
        return ('request_renew', 'stale_or_unsafe')
    return ('execute', L.P_c.next_action(s), L)
```

### IP-125 RSC

```python
def backward_resumable(goal, H, budget, gamma=1.0):
    Res = {0: set(goal)}
    for k in range(1, H + 1):
        Res[k] = {s for s in state_space
                  if exists_action(s, Res[k-1], budget, gamma)}
    return Res

def checkpoint_ok(s_t, t, H, Res):
    # 内近似：只有确定属于 Res 才判可续
    return inner_membership(s_t, Res[H - t])
```

### IP-126 AVC

```python
def e_process_update(E_prev, x_t, h0_mu, betting=0.5):
    return E_prev * max(1 + betting * (x_t - h0_mu), 1e-12)

def monitor_certificate(stream, alpha=0.05):
    E = 1.0
    for t, x in enumerate(stream):
        E = e_process_update(E, x, assumed_mean())
        if E >= 1.0 / alpha:
            return ('revoke', t, E)       # 自适应 TTL 到期
    return ('valid', E)
```

### IP-127 LH-JC

```python
def long_horizon_certify(skill_seq, H, L, Res, trace, tcc, alpha):
    cert_h = compose_horizon_budget(skill_seq, H, eps_req(H))
    if cert_h[0] != 'ok':
        return ('reject', 'budget', cert_h)
    if not L.valid(now(), current_state):
        return ('defer', 'lease_invalid')
    if not all(checkpoint_ok(s_t, t, H, Res)
               for t, s_t in enumerate(trace)):
        return ('abort', 'irreversible_state')
    if e_trace[-1] >= 1.0 / alpha:
        return ('recertify', 'assumption_drift')
    if tcc is None or not tcc.necessary:
        return ('defer', 'missing_temporal_credit_evidence')
    return ('accept', LHJC(cert_h, L, Res, tcc, e_trace))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| HBA-RSM | O(|S|²·k + |S|·H) | O(|S|) | V 上包络；每段 `d ≥ d_min`；尾界 O(1/H) |
| TCC | O(m·|W|·T_sim) | O(|W|) | 干预可回放；逻辑时钟因果序 |
| LTC | O(1)/查询，续约 O(κ) | O(|P_c|) | TTL 单调；权限不扩张 |
| RSC | O(H·|S|·|A|)（可采样近似） | O(H·|S|) | 内近似 sound；边界保守 |
| AVC | O(1)/更新 | O(1) | H0 下 e-process 为非负超鞅 |
| TOC | O(|O|²) | O(|O|) | 终止—启动相容；时长可合成 |

**正确性定理（Long-Horizon Cloud-Edge Certified Soundness）**
假设第 54 轮 (A26)–(A28) 成立，并新增：
**(A29)** 每段排名超鞅条件成立且 `d_{S_i} ≥ d_min > 0`；
**(A30)** 租约期内真实云边偏差 `||s_c − s_e|| ≤ Δ(τ_lease)`，`Δ` 单调、`Δ(0)=0`；
**(A31)** AVC 的 e-process 在 H0 下有效（误吊销 ≤ α），漂移检测延迟 ≤ δ_det；
**(A32)** 可续集采用内近似，判"可续"是 sound 的。
则长程部署失败概率：
```
P(fail before H) ≤ B/(d_min·H) + α
                   + P(||s_c−s_e|| > Δ)
                   + P(δ_a > Θ_a) + β_E
```
- 第一项：长程尾界，随 H 反比衰减（关键改进：不随步数线性累积）；
- 第二项：任意时监控的误判预算；
- 第三项：租约陈旧越界（承接 v54 云边映射）；
- 第四项：动作对齐越界（承接 v54 δ_a）；
- 第五项：仿真—现实差。

**推论（长程组合的预算充分性）**：若每个技能段的 `d_{S_i} ≥ ε_i` 且 `Σ_i ε_i ≥ ε_req(H)`，则组合链满足 A29，LH-JC 的预算项通过；反之若存在 `d_{S_i} ≤ 0`，则无论 H 多大都不应签发长程证书（不可终止风险）。

## 5. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 长程尾界校准 | 实测 `P(τ>H)` vs `B/(d_min·H)` | 覆盖率 ≥ 90%，不随 H 系统性低估 |
| E163 时域信用归因 | 必要因 precision/recall | P ≥ 0.85，R ≥ 0.8 |
| E164 租约陈旧鲁棒性 | 不同延迟/TTL 成功率 | 较固定计划提升 ≥ 15% |
| E165 可续性检查点 | 失败恢复率 / 不可逆态进入率 | 恢复 ≥ 85%，进入 ≤ 2% |
| E166 任意时监控 | 误吊销率 / 漂移延迟 | 误吊销 ≤ α，延迟 ≤ 3 窗口 |
| E167 长程系统级对比 | 30min+ 多房间操作成功率 vs v54 | 提升 ≥ 12%，无安全违规 |

**预期结果形态**：长程成功率随 H 的下降应从 v54 的近似线性劣化，转为受 `B/(d_min·H)` 约束的**双曲线式缓慢下降**；同时 E163 应显示"必要因"集中在任务前 20%–40% 的技能选择上，验证长程根因的迟到性。

## 6. 本轮最大风险

**一句话**：把长程保证建立在"每步期望下降 `d_min`"与"租约内假设不变"这两条上，本质上是在赌一个**未被证伪的潜势**和**尚未漂移的语境**；一旦 V 被高估、`d_min` 被仿真乐观化，或漂移发生在监控检测延迟窗口内，系统会以"有证书"的姿态执行一条真实失败概率随 H 增长的长任务，而且比无证书系统更危险——因为证书本身制造了过度自信。故必须以 **保守上包络潜势 + 任意时有效监控 + 内近似可续集 + 独立长程红队审计** 四重护栏，宁可频繁降级，绝不把"纸面长程证书"当作部署许可。
