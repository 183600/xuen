# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「产学研合作」×「社会影响」）

> R69 给闭环装上了一张会提问的嘴：aleatoric 收紧、epistemic 去问、用「k 个正交证据」防撒谎、用 (r_res↓, Δa↑) 抓被标定吸收的缓变故障。但它仍然活在一个**单机构、单基准、单证书签发者**的温室里。R69 自陈的风险是「模态分布不可信 ⇒ 问错」，而真实部署里更根本的不信任来源往往不是模型，而是**制度**：证据由谁提供、证书由谁签发、代价由谁承担。
>
> 两个盲点：
> - **证据是分布的，不是正交的**：R69 用「k 个正交证据源」抗投毒，隐含假设源之间独立。可产学研三方（高校实验室、产业部署方、监管/社区）各有激励：产业想尽快上线、实验室想发论文、监管怕出事。它们的错误可能高度相关（同一个数据集、同一批标注、同一份有利站点），甚至共谋。**独立性不是假设，而是要花成本测量和购买的公共品。**
> - **社会影响是外部性，不在目标函数里**：R68/R69 优化的是操作者的任务风险。对工人、路人、社区、未来用户的伤害既不在奖励里，也不在证书里，且在环内不可观测。系统可以像 R68 的 COF 吸收传感器漂移一样，把社会反馈「正常化」掉——投诉被过滤、工人自行补偿、影响被平均掉。
>
> 本轮两个灵感正好补这两块：
> - **产学研合作**（Triple Helix：大学—产业—政府/社会的三螺旋）给出一个**分布式保证**的框架：证据、数据、责任、审计分散在不同机构，必须用制度设计让「说真话」成为均衡，而不是靠善意。
> - **社会影响**给出一个**外部性约束**：把风险从任务标量升级为多利益相关者的伤害向量/分布，把「谁受益、谁担险」写进证书，并把社会面的慢变量当作一条独立的、可被部署「吸收」的观测通道。
>
> 核心命题：**安全证书不是实验室产物，而是一份可审计的社会契约。** R69 的「k 个正交源」升级为「k 个制度上独立的源」；R69 的 aleatoric/epistemic 二分升级为「任务不确定性 / 影响不确定性 / 制度不确定性」三分；实验室→现场的迁移缺口（valley of death）被显式记为一种需要托管（escrow）和再认证的风险，而不是默认它不存在。命名 **HELIX-RAS**（Triple-Helix, Impact-scoped, Liability-aware eXchange for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这份『安全』是谁替我担保的、代价由谁承担、出了问题谁负责——而且，他们凭什么说真话**」。

## 0. 直觉与动机

**灵感 1（产学研合作 → 证据的制度独立性）**
直觉：R69 的 k 个证据源假设「不同传感器/不同人不会一起骗你」。但产学研合作里，最常见的不是恶意共谋，而是**利益同向导致的错误相关**：同一笔经费、同一个示范场景、同一套有利的测试集、同一份由部署方提供的运行日志。两个「独立机构」可能只是同一激励的两个签字人。于是 R69 投毒上界 δ·ρ^{k−1} 里的 ρ 不再是单纯攻击参数，而是**制度参数**：它取决于资金结构、数据来源、责任归属和审计独立性。要把 ρ 估出来、把 k 算出来，而不是拍一个常数。

**灵感 2（社会影响 → 把外部性写成约束而不是指标）**
直觉：给系统加一个「社会影响分数」是最容易的，也是最容易被 Goodhart 的。真正难的是：影响是**分布的**（谁受益、谁受伤）、**延迟的**（几年后才显现）、**不可观测的**（环内没有传感器），而且会被部署本身**吸收**（工人学会绕开、投诉渠道被 KPI 化、社区被补偿收买）。所以社会影响不能是一个标量奖励项，而应是**一组带分布的分组约束**（例如每个弱势群体的 CVaR 伤害上界），外加一条**因果审计通道**把它从被吸收的原始信号里恢复出来。

**灵感 3（合成 → 任务 / 影响 / 制度三种不确定性）**
直觉：R69 把 U 分成 aleatoric 与 epistemic。放到产学研现场，至少还要第三类：**制度不确定性 U_inst**——「我拿到的这份证据/这个证书，在多大程度上是可信的？」它既不是噪声也不是模型歧义，而是**来源可信度**的不确定性。三类不确定性的处置完全不同：U_ale 收紧、U_epi 交互、U_inst 要么购买独立证据、要么托管/降级。这给出一个三分结构，且每一维都能退化回前一轮。

**灵感 4（对偶通道 → 社会面的「缓变故障」）**
直觉：R68 用 (r_res↓, Δa↑) 抓被标定吸收的传感器慢漂。社会影响有完全同构的模式：**产业侧的运行指标（吞吐、uptime、任务成功率）平稳甚至变好，而社区侧的伤害信号（投诉、工伤、离职、可达性下降）在上升**——因为部署把摩擦「正常化」了。这就是 **impact washing**。判据同样是对偶的：(m_op 平稳/向好, Δ_impact↑) ⇒ 疑似社会影响被吸收，必须启动独立因果审计，而不是相信运营仪表盘。

**灵感 5（双刃剑 → 新的治理型失效模式）**
直觉：一旦引入「产学研联合保证」，就多了一整类**治理型攻击面**：选择性认证（只在友好站点做试点）、审计捕获（第三方审计被产业方买单）、影响洗白（用多机构背书给有害部署盖章）、数据扣留（合作方只给好看的日志）、指标博弈（把投诉定义改掉）、责任甩锅（出事后按合同把责任推给最弱的一方）。**最危险的不是系统失败了，而是系统带着一张「多方认证」的证书成功了。** 所以本轮必须同时交付：制度独立性度量、激励相容的证据上报、随机独立影响审计、受影响者申辩通道，以及责任分配的显式规则。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（HELIX-RAS 总览）** HELIX-RAS = (FLUID-RAS†, SIA, ISG, CEG, ITQ, ICE, RIA, IDC, PVA, DEC)。在 R69 三不变式上增加三条：
(iv) **影响约束优先**：多利益相关者伤害约束在效率目标之前，任何效率收益不得以突破任一弱势组的伤害上界为代价（词典序：安全 > 影响下限 > 效率）；
(v) **证据的制度来源与独立性**：证书的每个断言必须携带机构来源、数据来源、利益冲突（COI）与责任份额；所需机构多样性由度量算出，不得默认独立；
(vi) **范围限定与迁移再认证**：证书只在声明的部署范围 S 内有效；跨分布/跨人群/跨法域必须重新认证，未认证期间进入影子模式（定义 322）。

**定义 311（利益相关者伤害向量与影响剖面）** 设利益相关者组 G = {operator, worker, bystander, community, future}。对每组 g，伤害随机变量 H_g ∈ ℝ_{≥0}^{d_h}（人身安全、隐私、就业质量、可达性、自主性等）。影响剖面 Π = {(E[H_g], CVaR_α(H_g), gap_g)}_{g∈G}，其中 gap_g 为组间差（如最差组与平均之差）。**社会影响不是 E[ΣH]，而是分组分布泛函**：SI = max_g CVaR_α(H_g)（或带分布权重的加权和）。影响约束：∀g, CVaR_α(H_g) ≤ h_g^max。

**定义 312（部署范围与迁移缺口）** 部署范围 S = (P_task, E_env, Pop, Law, Ops)（任务分布、环境、人群、法域、运营模式）。设实验室分布 P_lab 与现场 P_field。迁移缺口 Δ_transfer = W_2(P_lab, P_field)（或 TV）。在 A99（风险对分布 Lipschitz，常数 L_R 有界）下，R_field ≤ R_lab + L_R·Δ_transfer。**证书必须声明 S 与 Δ_transfer 的置信上界；实验室证书在 S 之外无效。**

**定义 313（迁移托管 ISG）** 进入新范围 S' 时，证书进入托管：系统以影子模式运行（可观测、不执行高风险动作），在配对站点/配对时段上做配对比较；只有当 Δ_transfer 的置信上界 ≤ δ_S 且影响剖面满足定义 311 时，托管解除。**「死亡之谷」被显式建模为未被关闭的迁移缺口，而不是一句空话。**

**定义 314（联盟证据图 CEG）** 证据图 𝒢 = (V, E)，节点 v 是一个可核验断言（如「在 S 内 CVaR 伤害 ≤ h」「模态 ECE ≤ τ」），边 (u,v) 表示 u 支持 v。每个节点带元数据：owner(v)（签发机构）、data(v)（数据来源哈希）、coi(v)（利益冲突标记）、stake(v)（责任押金）、audit(v)（审计状态）。证书是对根节点的**证成树**；缺来源、缺 COI、缺押金的节点不可作为根的直接支持。

**定义 315（机构可信度与共谋相关）** 对机构 i 维护 θ_i = (δ_i, a_i, c_i, s_i, ρ_{ij})：δ_i 可靠性、a_i 激励对齐度（与受影响者利益的一致程度）、c_i 能力/资质、s_i 责任押金规模、ρ_{ij} 与其他机构的错误相关（共谋/同源程度）。ρ_{ij} 由数据重叠、资金同源、人员重叠、历史共同错误估计。R69 的逐人信誉是 θ_i 在 i=个人时的特例。

**定义 316（制度法定人数 ITQ）** 设需保证错误采纳率 ≤ ε。取机构错误相关上界 ρ̄ = max_{i≠j} ρ_{ij}、最差可靠性 δ_min。所需**制度上独立**的证据源数
k_inst(ε) = clip(1 + ⌈ ln(ε/(1−δ_min)) / ln ρ̄ ⌉, 2, k_max)，
且要求所选机构的成对 ρ ≤ ρ̄（否则视为同一源）。**R69 的 k_u 是「问几个人」，R70 的 k_inst 是「问几个真正独立的机构」——包括要求不同资金方、不同数据源、至少一个与部署方无财务关系的审计方。**

**定义 317（激励相容的证据上报 ICE）** 机构 i 上报伤害概率 p̂_i。采用严格适当评分 S(p̂, y)（Brier/对数），并设责任押金 escrow_i。收益 U_i = S(p̂_i, y) − λ·stake_i·1{审计发现瞒报} − c_i(上报成本)。**严格适当性 ⇒ 诚实上报是严格占优（或贝叶斯纳什）**；押金与随机审计把「瞒报的期望收益」压到负。押金在无违规且审计通过后按 Shapley 贡献返还（定义 321）。

**定义 318（随机独立影响审计 RIA）** 以固定概率 q（审计预算，不随部署方优化而降到 0）由**与产业方无财务关系**的第三方抽取站点/时段，做双重差分（DiD）或合成控制，估计对受影响组的因果影响 τ_g。用配对保留站点保证可比性。**审计的随机化是识别性的来源，也是审计捕获的防线：部署方无法预知哪个站点会被查。**

**定义 319（影响对偶通道 IDC）** 维护两条通道：运营通道 m_op（吞吐、uptime、任务成功率、事故率）与社区通道 m_soc（投诉率、工伤/离职、可达性、隐私事件、参与式上报）。定义
impact_wash 判据：`(m_op 平稳或改善) ∧ (Δ_impact 显著上升) ∧ (投诉/上报被「正常化」处理)`。
其中 Δ_impact 由 RIA 的 DiD 估计，而非原始投诉计数（原始计数会被吸收/过滤）。这是 R68 (r_res↓, Δa↑) 在社会面的镜像。

**定义 320（参与式申辩 PVA）** 受影响者（工人、路人、社区代表、未来用户代理）拥有**申辩通道**：任何受影响方可提交 claim，claim 触发一次 RIA 并**转移举证责任**（由部署方证明无伤害，而非由受害者证明有伤害）。claim 的受理与裁决记录进证书。PVA 不授予单方面否决权（避免被少数人挟持），但授予**范围扩张的暂缓权**。

**定义 321（证据/数据公地 DEC）** 跨机构数据与证据以联邦方式共享：本地差分隐私（ε_dp）、用途许可（purpose binding）、来源可追溯。用 Shapley 值分配贡献与责任：机构 i 对根断言的边际贡献 φ_i 决定押金返还与出事后的责任份额。检测数据扣留：若某机构的数据使联合证据的判别力系统性低于其声明能力，标记为 withholding。

**定义 322（影子模式与金丝雀）** 高风险范围的首批部署必须经过影子模式（只观测不行动）与金丝雀（小比例、可回滚、受影响者知情同意）。影子模式期间收集的数据用于关闭 Δ_transfer 与估计 Π；不满足定义 311 则不得扩大范围。

**定义 323（影响感知的发布门）** 模型/数据/证据的公开发布需同时满足：影响剖面 ≤ 阈值、隐私预算 ≤ ε_dp、双用途风险审查通过。**开放本身是一个受约束的决策，不是默认善。**

**定义 324（HELIX 证书 J_HELIX）** J_HELIX = (J_FLUID, impact_scope S, Π, Δ_transfer 上界, institutional_quorum, COI_digest, escrow_id, audit_seed, dp_budget, claim_log_hash)。Valid ⇔ Valid(J_FLUID) ∧ 影响约束满足 ∧ 制度法定人数达标 ∧ 迁移缺口在界内 ∧ 审计未被捕获 ∧ 隐私预算合规。

**定义 325（治理型干扰集 ℰ_HELIX）** ℰ_HELIX = ℰ_FLUID × ℰ_consortium × ℰ_impact，其中 ℰ_consortium = {共谋认证, 选择性试点, 审计捕获, 数据扣留, 责任甩锅}，ℰ_impact = {影响洗白, 指标 Goodhart, 投诉正常化, 补偿收买, 范围蔓延}。每类附检测量与缓解。

**定义 326（三分不确定性与处置）** U_task 沿用 R69 的 (U_ale, U_epi)；U_inst 为来源可信度不确定性（由 θ_i 的后验宽度与 COI 度量）；U_impact 为影响剖面的估计不确定性（由 RIA 的样本量与 DiD 方差度量）。处置：U_task → R69 原通道；U_inst → 购买独立证据/提高押金/降级到影子模式；U_impact → 扩大审计/暂缓范围扩张。三者在证书中分别记录，不合并成单一分数。

**定义 327（退化边界）** 单机构、无外部性（Π 为空）、Δ_transfer = 0、无审计（q=0）时，HELIX-RAS 逐指令等于 FLUID-RAS；再令永不交互等于 CALM-RAS。影响约束与制度约束是**单调加强**：加入它们只会缩小可行动作集，不会放宽安全侧。

## 2. 关键算法骨架

```python
# IP-264 SIA：分组影响剖面与约束（CVaR，不用均值糊掉尾部）
def impact_profile(traces, groups, alpha=0.95):
    Pi = {}
    for g in groups:
        H = harm_samples(traces, g)                 # 人身/隐私/就业/可达性...
        Pi[g] = Profile(mean=H.mean(), cvar=cvar(H, alpha),
                        gap=H.mean() - H_all.mean())
    return Pi

def impact_ok(Pi, bounds):
    return all(Pi[g].cvar <= bounds[g] for g in Pi)   # 词典序：先影响后效率

# IP-265 ISG：证书范围与迁移缺口
def scope_certificate(cert, S_new):
    dt = wasserstein(P_lab(cert.S), P_field(S_new))    # 或 TV 上界
    return Cert(scope=S_new, delta_transfer=dt,
                shadow=True) if dt > DELTA_S else cert

# IP-266 CEG：证成树 + 来源/COI/押金校验
def validate_tree(root, G):
    for v in proof_tree(root, G):
        if not (G.owner[v] and G.data[v] and G.stake[v] >= s_min): return False
        if G.coi[v] and not G.audit[v]: return False
    return True

# IP-267 ITQ：按制度独立性算法定人数（不是按人数）
def institutional_quorum(insts, eps):
    rho_bar = max(pairwise_rho(insts))                 # 资金/数据/人员重叠
    d_min   = min(i.reliability for i in insts)
    k = 1 + ceil(log(eps / max(eps, 1 - d_min)) / log(max(rho_bar, RHO_FLOOR)))
    return select_independent(insts, k, max_pair_rho=rho_bar)  # 同源机构算一个

# IP-268 ICE：严格适当评分 + 责任押金（激励相容上报）
def report_payoff(p_hat, y, stake, audited, hidden_harm):
    return proper_score(p_hat, y) - LAM * stake * int(audited and hidden_harm)

# IP-269 RIA：随机第三方 DiD 影响审计
def impact_audit(sites, q, treated_key):
    if rand() > q: return None                          # q 不随部署方优化而降
    pairs = match_holdout(sites, treated_key)           # 配对站点
    return did_estimate(pairs, outcome='stakeholder_harm')

# IP-270 IDC：影响对偶通道（抓 impact washing）
def impact_wash(m_op_hist, delta_impact_hist):
    return trend(m_op_hist) >= 0 and trend(delta_impact_hist) > 0

# IP-274 HELIX 主闭环：R69 闭环 + 影响门 + 制度门 + 范围门
def HELIX_round(M, obs, scope):
    # 1) 任务层：完全复用 R69（零重复）
    k, lam, mode, U = M.fluid.round(obs)
    # 2) 影响门：任何动作在执行前都要过分组影响约束
    Pi = M.sia.update(mode, obs, M.runtime_traces)
    if not M.sia.impact_ok(Pi, M.bounds[scope]):
        return M.escalate(scope, reason='impact_bound')    # 停/降级/转人工
    # 3) 制度门：证书必须有制度上独立的法定人数
    root = M.ceg.build_root(k, lam, Pi, scope)
    if not M.itq.quorate(root):
        return M.degrade(mode, reason='institutional_quorum')
    # 4) 范围门：跨范围先影子/金丝雀，不得直接放行
    if M.isg.needs_shadow(scope):
        return M.shadow(mode, scope)
    # 5) 审计与申辩（异步、随机、独立）
    M.ria.maybe_audit(scope, q=M.q, seed=M.audit_seed)
    M.pva.poll_claims(scope)
    # 6) 证书 + 押金/责任（Shapley 贡献）
    return M.cert.issue(root, Pi, M.dec.shapley(root), M.escrow)
```

## 3. 推导

**引理 23（制度法定人数的错误界）** 设机构 i 独立出错概率 1−δ_i，任意两机构错误相关 ρ_{ij} ≤ ρ̄。取 k_inst(ε) 个成对 ρ ≤ ρ̄ 的机构，则联合错误采纳率 ≤ (1−δ_min)·ρ̄^{k_inst−1} ≤ ε。系：**「两个机构签字」不等于「两个独立证据」**；同资金源、同数据源、同审计方的机构应先合并再计数。独立性是买来的（押金、不同数据、独立审计），不是声称的。

**引理 24（迁移缺口的风险界）** 在 A99 下，R_field ≤ R_lab + L_R·Δ_transfer。故实验室证书在 S 之外的置信上界随 Δ_transfer 线性恶化；当 L_R·Δ_transfer 超过允许风险预算时，证书**必然**无效——这正是「死亡之谷」的形式化。系：发表/认证必须携带 scope；跨范围只能用影子/金丝雀逐步关闭缺口。

**引理 25（影响洗白的可识别性）** 设部署的「正常化」把原始伤害信号以速率 α 吸收（投诉被过滤、工人补偿），使 m_soc 不可见；但在随机审计站点与配对留出站点满足平行趋势时，DiD 估计 τ_g 一致，偏差 ≤ O(1/√n_audit) + 平行趋势违背项。故 **(m_op 稳/升, τ_g 升) 是影响洗白的判别模式**，且只能由独立随机审计识别——运营仪表盘在原理上无法自证清白。

**定理 20（HELIX 严格包含 FLUID）** 在 A99–A101 下，单机构、Π 为空、Δ_transfer=0、q=0 时 HELIX 逐指令等于 FLUID；影响约束与制度约束是可行集的单调收缩，故 HELIX 的期望任务风险 ≤ FLUID，且**影响侧**（分组 CVaR）≤ FLUID。R69 是 HELIX 的「无外部性、无制度摩擦」边界。

**定理 21（激励相容与社会约束的联合）** 若评分严格适当、审计概率 q>0、押金 stake_i 足够大（使瞒报期望收益为负）、审计方与产业方无财务关系，则「诚实上报 + 不隐瞒伤害」是贝叶斯纳什均衡；在该均衡下，影响约束可行性判定与集中式全信息判定的差 ≤ 审计噪声项。**但审计捕获是此定理的唯一制度性前提**：一旦审计方被收买或由被审方选择，均衡退回「影响洗白」。

## 6. 本轮最大风险

**一句话**：HELIX-RAS 的全部合法性押在「审计独立、机构说真话」这一制度前提上——而产学研合作恰恰制造了把审计变成**共同署名**的激励：当产业方选择审计方、资助试点、提供数据，高校需要产业经费、监管需要政绩，所谓的「多方认证」可能只是**影响洗白的社会许可**；系统会带着一张看起来更可信的证书部署一个更不公平的系统——**被认证的错误，比未被认证的错误更难纠正。**

**次级风险与缓解**：选择性试点（随机独立审计 + 范围门）；审计捕获（无财务关系 + 随机化 + 审计方轮换）；数据扣留（公地 provenance + withholding 检测）；指标 Goodhart（分组 CVaR + 因果 DiD，不用单标量）；责任甩锅（Shapley 责任份额 + 押金）；隐私（DP + purpose binding + 发布门）。

## 2. 形式化定义（要点版）

**定义 310（总览与六不变式）** 在 R69 三不变式（零学习写、交互预算、证据纪律）上加：(iv) 影响约束优先（安全 > 影响下限 > 效率的词典序）；(v) 证据的制度来源与独立性（每个断言带 owner/data/COI/stake，多样性由度量算出）；(vi) 范围限定与迁移再认证（跨 S 必须影子/金丝雀 + 重新认证）。

**定义 311（影响剖面与约束）** 各组伤害向量 H_g；`Π={(E[H_g], CVaR_α(H_g), gap_g)}`；`SI=max_g CVaR_α(H_g)`；约束 `∀g, CVaR_α(H_g) ≤ h_g^max`。**社会影响是分布泛函，不是 E[ΣH]。**

**定义 312–313（范围与迁移托管）** `S=(P_task,E_env,Pop,Law,Ops)`；`R_field ≤ R_lab + L_R·Δ_transfer`（A99）；实验室证书在 S 外无效；进入 S' 先影子模式 + 配对比较，Δ_transfer 置信上界 ≤ δ_S 且 Π 达标才解除托管。

**定义 314–315（证据图与机构可信度）** 节点=可核验断言，元数据 owner/data/coi/stake/audit；证书为证成树，缺来源/COI/押金不可作根支持。机构 `θ_i=(δ_i,a_i,c_i,s_i,ρ_{ij})`，ρ 由资金/数据/人员重叠与历史共同错误估计；R69 逐人信誉是 i=个人时的特例。

**定义 316（ITQ）** `k_inst(ε)=clip(1+⌈ln(ε/(1−δ_min))/ln ρ̄⌉,2,k_max)`，且所选机构成对 ρ ≤ ρ̄（同源算一个）。**「两个机构签字」≠「两个独立证据」。**

**定义 317（ICE）** 严格适当评分 `S(p̂,y)` + 押金 escrow；`U_i=S(p̂_i,y) − λ·stake_i·1{审计发现瞒报} − c_i`；严格适当 ⇒ 诚实上报占优，押金+随机审计把瞒报期望压负；押金按 Shapley 返还。

**定义 318（RIA）** 固定概率 q 由无财务关系第三方抽站点/时段做 DiD/合成控制估计 τ_g；配对留出站点保可比；随机化既是识别来源也是审计捕获防线。

**定义 319（IDC）** 运营通道 m_op vs 社区通道 m_soc；`impact_wash := (m_op 稳/升) ∧ (Δ_impact 显著升) ∧ (投诉被正常化)`；Δ_impact 用 DiD 而非原始投诉计数。R68 (r_res↓,Δa↑) 的社会镜像。

**定义 320–321（PVA 与 DEC）** 受影响者 claim 触发 RIA 并转移举证责任、给范围扩张暂缓权（不给单方否决）；跨机构数据联邦共享，DP + purpose binding + provenance + Shapley 贡献/责任 + withholding 检测。

**定义 322–323（影子/金丝雀与发布门）** 高风险范围先影子（只观测不行动）+ 金丝雀（小比例可回滚、知情同意）；公开发布需 Π≤阈值、dp≤ε_dp、双用途审查通过——开放是受约束决策。

**定义 324–327（证书 / 干扰集 / 三分 / 退化）** J_HELIX 在 J_FLUID 上并入 S、Π、Δ_transfer、quorum、COI_digest、escrow、audit_seed、dp_budget、claim_log_hash；ℰ_HELIX=ℰ_FLUID×ℰ_consortium×ℰ_impact；U_task/U_inst/U_impact 分通道处置、不合并；单机构+无外部性+Δ=0+q=0 ⇒ HELIX 逐指令等于 FLUID，再令不交互等于 CALM。

```python
# IP-264 SIA：分组影响剖面与约束（CVaR 抓尾部，不用均值糊掉）
def impact_profile(traces, groups, alpha=0.95):
    Pi = {}
    for g in groups:
        H = harm_samples(traces, g)                 # 人身/隐私/就业/可达性...
        Pi[g] = Profile(mean=H.mean(), cvar=cvar(H, alpha), gap=H.mean()-H_all.mean())
    return Pi

def impact_ok(Pi, bounds):
    return all(Pi[g].cvar <= bounds[g] for g in Pi)   # 词典序：先影响后效率

# IP-265 ISG：证书范围与迁移缺口
def scope_certificate(cert, S_new):
    dt = wasserstein(P_lab(cert.S), P_field(S_new))
    return Cert(scope=S_new, delta_transfer=dt, shadow=True) if dt > DELTA_S else cert

# IP-266 CEG：证成树 + 来源/COI/押金校验
def validate_tree(root, G):
    for v in proof_tree(root, G):
        if not (G.owner[v] and G.data[v] and G.stake[v] >= s_min): return False
        if G.coi[v] and not G.audit[v]: return False
    return True

# IP-267 ITQ：按制度独立性算法定人数（不是按人数）
def institutional_quorum(insts, eps):
    rho_bar = max(pairwise_rho(insts))                 # 资金/数据/人员重叠
    d_min   = min(i.reliability for i in insts)
    k = 1 + ceil(log(eps / max(eps, 1-d_min)) / log(max(rho_bar, RHO_FLOOR)))
    return select_independent(insts, k, max_pair_rho=rho_bar)   # 同源机构算一个

# IP-268 ICE：严格适当评分 + 责任押金
def report_payoff(p_hat, y, stake, audited, hidden_harm):
    return proper_score(p_hat, y) - LAM*stake*int(audited and hidden_harm)

# IP-269 RIA：随机第三方 DiD 影响审计
def impact_audit(sites, q, treated_key):
    if rand() > q: return None                          # q 不随部署方优化而降
    return did_estimate(match_holdout(sites, treated_key), outcome='stakeholder_harm')

# IP-270 IDC：影响对偶通道
def impact_wash(m_op_hist, delta_impact_hist):
    return trend(m_op_hist) >= 0 and trend(delta_impact_hist) > 0

# IP-274 HELIX 主闭环：R69 + 影响门 + 制度门 + 范围门
def HELIX_round(M, obs, scope):
    k, lam, mode, U = M.fluid.round(obs)                  # 完全复用 R69
    Pi = M.sia.update(mode, obs, M.runtime_traces)
    if not M.sia.impact_ok(Pi, M.bounds[scope]):
        return M.escalate(scope, reason='impact_bound')   # 停/降级/转人工
    root = M.ceg.build_root(k, lam, Pi, scope)
    if not M.itq.quorate(root):
        return M.degrade(mode, reason='institutional_quorum')
    if M.isg.needs_shadow(scope):
        return M.shadow(mode, scope)                      # 影子/金丝雀，不直接放行
    M.ria.maybe_audit(scope, q=M.q, seed=M.audit_seed)    # 异步、随机、独立
    M.pva.poll_claims(scope)
    return M.cert.issue(root, Pi, M.dec.shapley(root), M.escrow)
```

## 4. 推导

**引理 23（制度法定人数错误界）** 机构独立出错 1−δ_i、成对错误相关 ρ_{ij} ≤ ρ̄，取 k_inst 个 ρ≤ρ̄ 机构，联合错误采纳 ≤ (1−δ_min)·ρ̄^{k_inst−1} ≤ ε。系：**同资金源/同数据源/同审计方的机构应先合并再计数**；独立性是买来的，不是声称的。

**引理 24（迁移缺口风险界）** A99 下 `R_field ≤ R_lab + L_R·Δ_transfer`；当 L_R·Δ_transfer 超预算时证书必然无效——「死亡之谷」的形式化。系：认证必须携带 scope，跨范围只能影子/金丝雀关闭缺口。

**引理 25（影响洗白的可识别性）** 部署以速率 α「正常化」吸收原始伤害信号使 m_soc 不可见；随机审计 + 配对留出站点满足平行趋势时，DiD 的 τ_g 一致，偏差 ≤ O(1/√n_audit)+平行趋势违背项。故 (m_op 稳/升, τ_g 升) 是影响洗白判别模式，且只能由独立随机审计识别。

**定理 20（HELIX 严格包含 FLUID）** 单机构、Π 空、Δ_transfer=0、q=0 时 HELIX 逐指令等于 FLUID；影响/制度约束是可行集单调收缩 ⇒ 任务风险与分组 CVaR 均不高于 FLUID。R69 是「无外部性、无制度摩擦」边界。

**定理 21（激励相容 × 社会约束）** 评分严格适当、q>0、押金足够大、审计方与产业方无财务关系 ⇒ 「诚实上报 + 不隐瞒伤害」为贝叶斯纳什均衡，且影响可行性判定与全信息判定的差 ≤ 审计噪声项。**审计捕获是该定理的唯一制度前提**：审计方被收买或由被审方选择，均衡退回影响洗白。

## 7. 本轮最大风险

**一句话**：HELIX-RAS 的全部合法性押在「审计独立、机构说真话」这一制度前提上——而产学研合作恰恰制造了把审计变成**共同署名**的激励：当产业方选择审计方、资助试点、提供数据，高校需要产业经费、监管需要政绩，所谓的「多方认证」可能只是**影响洗白的社会许可**；系统会带着一张看起来更可信的证书部署一个更不公平的系统——**被认证的错误，比未被认证的错误更难纠正。**

**次级风险与缓解**：选择性试点（随机独立审计 + 范围门）；审计捕获（无财务关系 + 随机化 + 审计方轮换）；数据扣留（公地 provenance + withholding 检测）；指标 Goodhart（分组 CVaR + 因果 DiD，不用单标量）；责任甩锅（Shapley 责任份额 + 押金）；隐私（DP + purpose binding + 发布门）；冷启动/跨域（影子 + 金丝雀 + 范围托管）。
