# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「快速原型」×「VLA」）

> R69 把不确定性一分为二：aleatoric 用 λ_floor 收紧，epistemic 用「看/问/触」主动消解。它回答的是「**我该向谁求证**」。但这个答案有一个未言明的前提——**正确动作已经在我策略的支撑集里**，交互只是帮我在已知的几个模态里挑一个。真实世界会给出第三种情况：**当前策略根本不会做**。新指令、新工具、新地形、新协作对象。此时 R69 的模态熵可能很低（它自信地选中一个错误的已知模态），问一句也问不出来（语言回答不能把「不会」变「会」），λ_floor 只能让它**更慢地做错事**。这就是「自信地不会」——比「诚实地不知道」危险得多。
>
> 本轮两个灵感正好补上这块：
> - **VLA** 提供「用语言命名缺失行为」的语义先验。语言是组合性的、可跨任务迁移的规格接口，能把「没见过的任务」编译成一个**可检验的行为假设**，而不是直接吐出一串动作。
> - **快速原型**提供「用最便宜的可丢弃实验把假设变成能力」的方法论。先造一个粗糙但可跑的版本，在沙盒里证伪、迭代、放行——原型不是缩小版产品，而是**可执行的问题**。
>
> 核心命题：在 R69 的 (U_ale, U_epi) 之外引入第三类不确定性 **U_ont（模型不充分性 / 本体不确定性）**。aleatoric 收紧、epistemic 交互、**ontological 原型**：由冻结 VLA 把语言指令编译成结构化行为草图，快速合成一个**可丢弃的残差原型**，经**保真度阶梯**与**证伪预算**取得**带域界与过期时间的原型证书**，再由 **Simplex 运行时盾**（原型 = 高级控制器，R69/R68 = 基线控制器）四阶放行。原型永不直接上硬件；证书失效即有界回退基线。命名 **FORGE-RAS**（Falsification-gated Ontology-aware Rapid Guarded Experimentation for Risk-Adaptive Safety）——锻造、试火、放行。
>
> 一句话定位：R66 问「谁控制」，R67「未来怎样」，R68「我的测量还准吗」，R69「我该向谁求证」，R70 问「**我不会做的时候，能不能快速造一个、试到敢用、用完敢扔**」——不确定性之外还有能力边界，能力边界之外还有**验证经济学**。

## 0. 直觉与动机

**灵感 1（VLA：语言是能力的索引，不是动作的许可证）**
直觉：VLA 最诱人的地方不是「它能直接出动作」，而是「它能把没见过的东西用语言接到已知语义上」。但若把 VLA 的输出直接接到执行器，就等于把一个未经认证的大黑箱塞进安全回路。本轮第一个姿态：**VLA 负责「说什么」，不负责「怎么动」**。让它只输出结构化的行为草图、成功谓词、安全谓词与低维参数化接口，语言就从「动作命令」降级为「可验证规格」；真正上硬件的，是一个小到可以被证伪、被认证、被撤销的残差原型。语言因此成为**能力的索引**：它指向一个可被快速构造和检验的假设，而不是直接授权一次动作。

**灵感 2（快速原型：原型是可执行的问题，不是缩小的产品）**
直觉：工程界做快速原型的真正收益不是「省时间」，而是**把不确定性外化成可丢弃的实物/实验**：3D 打印一个手板，仿真里跑一遍，失败就扔，沉没成本几乎为零。翻译成策略学习：不要在实时回路里微调大模型，而是**在慢回路里快速合成一个低维残差原型**，用最低必要保真度的实验去证伪它。原型的第一目标是**尽快失败**（fail fast），而不是尽快成功。这把 R69 的「信息动作」扩展成「能力动作 × 信息动作」的复合体：造原型既得到「它行不行」的信息，也直接得到「能做」的能力——**原型同时是探针和工具**。

**灵感 3（第三类不确定性：不知道 ≠ 不确定）**
直觉：R69 的 U_epi 是「我知道有哪几种可能，但不知道是哪一种」；U_ont 是「我的可能性集合里根本没有正确答案」。前者的解药是**证据**（看/问/触），后者的解药是**构造**（造/试）。把两者混同会得两种病：把 U_ont 当 U_epi → 反复追问一个语言回答不了的问题（问一个没有词汇的答案）；把 U_epi 当 U_ont → 每次都重新造轮子，浪费预算并引入新风险。所以必须**先分诊、再处置**。分诊本身是本轮的第一道理论关卡。

**灵感 4（保真度阶梯：证据价值随保真度上升，成本也随保真度上升）**
直觉：仿真里通过的原型不一定在真机上通过；但真机试验贵、慢、可能不可逆。快速原型的「快」不是无脑用最低保真度，而是**选最便宜的、仍足以支撑当前决策的保真度**。这给出一条清晰经济学：迁移上界 UB(f) 随保真度 f 下降，成本 c(f) 随 f 上升；最优保真度是满足 UB(f) ≤ ε 的最小 f。**过度原型**（用真机做仿真能做的验证）与**欠原型**（用仿真给真机发证）都违反这条原则。保真度因此不是工程细节，而是**证据的可信度参数**。

**灵感 5（盾与法庭：证书不是一次性判决，而是可撤销的保释）**
直觉：最危险的时刻不是原型失败，而是原型**曾经通过**、于是被无限信任。真实系统的安全不是「证明一次永远对」，而是**持续可撤销的运行时保证**：证书带域界（trust region）与过期时间；一旦观测越出域界或监视器报警，就在有界时间内切回基线。这就是 Simplex 架构的精髓——高级控制器可以激进，但决定权永远在「可证明安全的基线 + 能刹车的判决器」手里。快速原型因此不是给系统装了一个更猛的引擎，而是给它装了一个**可换引擎、但方向盘和刹车永远归安全层**的结构。

**灵感 6（Goodhart：越快，越容易把「通过测试」当成「学会做事」）**
直觉：快速原型压缩了每轮验证时间，于是更依赖便宜的代理指标（仿真奖励、离线成功率、少量真机试次）。候选原型越多、筛选越快，**赢家诅咒 / 选择偏差**越强：被选中的那个只是「在这批候选里最会考试」，不是「最安全」。这是本轮必须正面处理的理论风险，也是为什么 FALSIFY 必须带选择偏差校正（e-value / 独立 holdout），ODD 覆盖必须独立审计，证书域界绝不能大于测试足迹。否则「快速」会系统性放大规格游戏——**快不是错，快而没有统计纪律才是错**。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（FORGE-RAS 总览）** FORGE-RAS = (VLA-S, TRIAGE, PROTOSYN, FIDEL, FALSIFY, ODD-COVER, SHIELD, PROTLIB, PVOIE, RAS-WM††)。四不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）：原型合成、保真度实验、证书签发全部在慢回路；控制回路只做证书查表与 SHIELD 判决；
(ii) **原型永不直接上硬件**：新行为必须经沙盒→影子→受限→放行四阶（定义 321），每阶有独立可撤销证书；
(iii) **证书带域界与过期**：J_PROTO 含 trust region 𝕋_p、expiry τ_p、rollback pointer；越界/超时/监视器报警 ⇒ 有界时间回退基线（R69/R68）；
(iv) **来源可溯与隔离**：失败/不确定原型进隔离区，不得直接写入认证策略或认证库（定义 319、322）。

**定义 311（三类不确定性分诊 TRIAGE）** 继承 R69 的 U_ale = Σ_k ŵ_k tr(Σ_k)、U_epi = H_mode·g(Δ_min)，新增
U_ont(ℓ,o) = 1 − max_{k∈𝒦_cert} [ match(ℓ, ψ_k) · 1(o ∈ ODD_k) ] + λ_ont·ρ_OOD(o)，
其中 𝒦_cert 为已认证技能库，ψ_k 为技能 k 的成功谓词，match 为指令与技能规格的语义对齐度（由冻结 VLA 的跨模态相似度给出），ρ_OOD 为观测相对认证分布的新颖度（密度比）。操作判据：**U_epi 低而 U_ont 高 = 「自信地不会」**。关键性质（A99）：在语言可表达但技能库缺失时，∂U_ont/∂evidence = 0——**再多的问与看也不能降低 U_ont，只能构造**。这是第三类不确定性必须独立成通道的根本原因。

**定义 312（语言规格编译 VLA-S）** 冻结 VLA 把 (ℓ,o) 编译为结构化的行为草图
s = VLA-S(ℓ,o) = (Σ, φ_succ, φ_safe, A_sketch, Θ)，
其中 Σ 为子目标序列，φ_succ/φ_safe 为状态上的可检验谓词，A_sketch 为动作原语骨架，Θ 为低维原型参数化（供 PROTOSYN 拟合）。硬约束：VLA 不输出自由形式的执行器令牌；φ_safe 必须属于 C-RAS-WM/SHIELD 可判定的规格文法；输出经 schema 校验。schema 不合法、谓词不可判定或规格越权 ⇒ **直接拒绝**，U_ont 保持未消解，退回 R69。语言因此只是**假设的书写语言**，不是动作的许可证。

**定义 313（原型与残差合成 PROTOSYN）** 原型 p = (π_p, Θ_p, D_p, f_p)；π_p(a|o) = π_base(a|o) + r_{Θ_p}(h(o), s)，其中 π_base 为 R69/R68 基线策略，h 为冻结 VLA/MTM 特征，r 为低维残差网络，dim(Θ) ≤ d_max。拟合：
Θ* = argmin_Θ L_task(rollouts in sandbox) + β‖Θ‖²，s.t. φ_safe 硬约束。
D_p = (prompt_hash, sketch_hash, sandbox_seed_set, fit_data_hash) 为来源。**「快速」的量化**：合成预算 B_syn（如单卡 ≤ 3 分钟），且**不含**任何基础模型训练；原型参数量与训练样本量都被硬性上界约束——「小」是可认证性的前提，不是节省算力的副产品。

**定义 314（保真度阶梯与迁移界 FIDEL）** 保真度 f ∈ {f0 代数模型, f1 仿真, f2 数字孪生, f3 受限真机, f4 全真机}，成本 c(f0)<…<c(f4)。原型 p 在保真度 f 上测得风险 R_f(p)，部署风险满足（A100：风险对域偏移 Lipschitz）
R_1(p) ≤ R_f(p) + L_f·d_f(p) + η_f ≜ UB_f(p)，
其中 d_f 为域差异（特征 MMD / 物理参数偏差），L_f 为 Lipschitz 常数，η_f 为不可约差，另加置信项 conf(B) 计入有限样本。证书要求 UB_f(p) ≤ ε_transfer。

**定义 315（证伪预算与统计验收 FALSIFY）** 给定证伪预算 B_fals，证伪器 𝔽 在 ODD 内做自适应压力测试（对抗初值/扰动搜索），目标是最大化 φ_safe 的违反。接受条件三条同时成立：
(a) 未找到反例；
(b) 成功率下置信界 LCB_{1−δ}(p) = Clopper–Pearson(成功数, n) > 1 − δ_task；
(c) **多候选选择偏差校正**：对 N 个候选用 e-value（e(p) = ∏ 似然比，e ≥ 1/α 才拒绝「不安全」原假设）或 Bonferroni 校正。B_fals 固定而 N 增大时，校正必使接受门槛升高——这直接把「快速批量试原型」的统计代价写进协议。

**定义 316（ODD 覆盖与测试充分性 ODD-COVER）** 覆盖度 cov_f(𝕋_p) = 测试/证伪分布对声称运行域 𝕋_p 的测度覆盖率。测试充分性要求 cov_f ≥ τ_ODD 且对已知失效模式集 ℱ_known 有对抗覆盖。**证书域界不得大于测试足迹**：𝕋_p^cert = 𝕋_p ∩ supp(测试分布)。cov_f < τ_ODD ⇒ 拒绝发证。这是反 Goodhart 的物理闸门：**测试没踩过的区域，证书无权覆盖**。

**定义 317（原型证书 J_PROTO）**
J_PROTO = (J_FLUID, prompt_hash, sketch_hash, Θ_hash, f, UB_f, cov_f, LCB_succ, e_value, 𝕋_p^cert, expiry τ_p, rollback_ptr, protlib_lineage, poison_flag)。
Valid ⇔ Valid(J_FLUID) ∧ UB_f ≤ ε_transfer ∧ cov_f ≥ τ_ODD ∧ LCB_succ ≥ 1−δ_task ∧ ¬poison_flag ∧ 未过期。J_PROTO **可撤销**：撤销不是异常路径，而是正常生命周期的一部分。

**定义 318（运行时盾 SHIELD / Simplex）** 两个控制器：基线 π_B = R69/R68 策略（在不变集 𝕊_B 内可证安全），高级 π_A = 原型 p。判决 δ(o,cert) ∈ {A,B}。可恢复谓词 Rec(o) = 存在时域 T_rec 与恢复控制，使系统回到 𝕊_B^inv 且状态距离 ≤ ε_switch。SHIELD 仅在
cert valid ∧ o ∈ 𝕋_p^cert ∧ Rec(o) ∧ 监视器（φ_safe 残差）正常
时选择 A，否则选 B。切换成本 ≤ ε_switch 且抖动有界（定理 19）。

**定义 319（原型库与污染防护 PROTLIB）** 库 L = {(skill key, 𝕋, provenance, trust score, lineage)}。检索 retrieve(ℓ,o) 为快速合成提供热启动（复用已认证片段可让「快速」越来越快）。规则：只有认证原型进 L_cert；失败/不确定进 L_quarantine；trust 随 ODD 漂移衰减；跨 ODD 复用前必须过负迁移检验；来源为 DAG，被投毒节点可连同全部后代一次性驱逐，poison_flag 沿 lineage 向下传播。

**定义 320（保真度感知原型经济学 PVOIE）** 对实验 e = (p, f, B_fals)：
Val(e) = VoI(e) + Cap(e) − c(f,B_fals) − E[loss | accept/reject] − λ_contam·contam_risk(e)，
其中 Cap(e) 为可达认证任务测度的期望增量，VoI 为 U_ont 的期望消解量，contam_risk 为污染/负迁移风险。选择 e* = argmax Val；等价地选满足 UB_f ≤ ε_transfer 的最小 f。若 max Val ≤ 0 ⇒ **不造原型**，退回 R69（能问就问）或 R68（只能保守）。这条规则是「快而不鲁莽」的形式化：快是预算约束下的最优，不是无条件的美德。

**定义 321（四阶放行 SAND→SHADOW→BOUNDED→RELEASE）**
Stage 0 SAND：只在沙盒，零致动；
Stage 1 SHADOW：在真实流上并行计算但零致动，记录与基线分歧；若原型选择在基线世界模型下会违反 φ_safe ⇒ 拒绝；
Stage 2 BOUNDED：仅在 𝕋_p^cert 内致动，SHIELD 全程在位，监视器一报警即中止；
Stage 3 RELEASE：扩展 ODD 后仍受 SHIELD 与过期约束。
每次晋升都需要相应保真度的新 J_PROTO；**降级是立即且单调的**，永远不需要审批。

**定义 322（失败原型处置与抗遗忘）** 失败原型证据 D_fail = {(ξ, failure reason)} 留在隔离区，作为**负证据**保留（失败信息有价值），但禁止直接更新认证基线；只允许经 KL(π_new‖π_cert) ≤ ε_drift 的受限更新作用于「原型先验」，并伴随认证分布回放。目的：既从失败中学习，又不让失败/后门通过梯度污染认证策略，防止灾难性遗忘。

**定义 323（威胁模型 ℰ_FORGE）**
ℰ_FORGE = ℰ_FLUID × ℰ_prompt × ℰ_afford × ℰ_fidelity × ℰ_libpoison：
- ℰ_prompt：指令注入、场景文字注入、越权语言；
- ℰ_afford：VLA 幻觉出不存在的 affordance、错误子目标或错误成功谓词；
- ℰ_fidelity：仿真器漏洞被原型利用（sim exploit / reward hacking），影子通过而真机失败；
- ℰ_libpoison：向原型库注入后门原型，借 lineage 扩散。
关键安全论证（定理 19）：因为 VLA 只出草图、原型必须过 FALSIFY + SHIELD，**注入语言不能直接致动**；但它仍可浪费预算（prototype DoS）或把搜索导向「认证但狭窄」的 exploit。因此预算本身也需要抗 DoS 上界。

**定义 324（参与式审计 VQAuditor-P）** 审计对象：规格是否歧义、schema 是否合法、保真度阶梯是否被绕过、测试是否充分、选择偏差是否校正、隔离区是否泄漏、lineage 是否被投毒、人工接管是否合规。结论回灌 PVOIE 的成本先验与 ODD 课程；当 U_ont 高且风险高时，晋升必须人工在环。

## 2. 关键算法骨架

```python
# IP-264 FORGE-RAS：慢回路「造—试—证」，快回路「查—判—切」
class FORGE_RAS:
    def slow_loop(self, ell, o):
        # 1) 分诊：先判断是「不会」还是「不确定」
        U_ale, U_epi, U_ont = triage(self.fluid, ell, o)
        if U_ont <= TAU_ONT:
            return self.fluid.round(o)                  # 退化为 R69
        # 2) 语言规格编译：VLA 只出结构化草图，不出动作
        s = self.vla_s.compile(ell, o)                  # (Sigma, phi_succ, phi_safe, A_sketch, Theta)
        if s is None:
            return self.fluid.round(o)                  # schema/规格不合格 → R69
        # 3) 快速合成低维残差原型（冻结底座，不训练大模型）
        p = self.protosyn.fit(s, o, budget=B_SYN)
        # 4) 最便宜的、仍能发证的保真度 + 证伪 + 选择偏差校正
        f = min_fidelity_with_bound(p, eps_transfer)    # 解 UB_f <= eps
        v = self.falsify.run(p, f, B_FALS, alpha=ALPHA, n_cand=N_CAND)
        if not v.accept:                                # 失败原型：隔离，绝不入认证库
            self.protlib.quarantine(p, v)
            return self.fluid.round(o)
        cert = self.issue_cert(p, f, v)                 # 带域界/过期/回退指针
        self.protlib.add_certified(p, cert)
        return cert

    def fast_loop(self, o, cert):
        # 实时路径：证书查表 + Simplex 判决，零学习写操作
        base = self.fluid.policy(o)                     # R69 基线
        if cert is None or not cert.valid(o):
            return base
        adv = cert.prototype(o)                         # 原型动作（可能激进）
        if self.shield.safe_to_switch(o, adv, cert, base):
            return adv
        return base                                     # 有界、单调回退

# IP-269 FALSIFY：证伪预算 + ODD 覆盖 + 统计验收 + 选择偏差校正
def falsify(p, f, B, alpha, n_cand):
    viol, succ = 0, 0
    for _ in range(B):
        x0 = adversarial_sample(p, f, target=viol)      # 自适应压力测试
        traj = rollout(p, x0, f)
        if violates(traj, p.phi_safe):
            viol += 1
            break                                        # 找到反例即拒
        succ += satisfies(traj, p.phi_succ)
    cov = odd_coverage(p, f)                             # 测试足迹覆盖率
    lcb = clopper_pearson_lower(succ, B, 1 - alpha)      # 成功率下置信界
    ev  = e_value(succ, B, alpha, n_cand)                # 多候选校正
    return Verdict(accept=(viol == 0 and cov >= TAU_ODD and ev.accept),
                   cov=cov, lcb=lcb, ev=ev)

# IP-274 SHIELD：Simplex 运行时判决（可换引擎，刹车不动）
class Shield:
    def safe_to_switch(self, o, adv, cert, base):
        if not cert.in_region(o):            return False   # 出域即回退
        if not recoverable(o, base, T_rec):  return False   # 回退必须可行
        if self.wm.discrepancy(o, adv, base) > cert.max_disc:
            return False                                    # 行为偏离监视器
        return self.c_ras_wm.certified_prefix_ok(adv)       # 与 R68/R69 同源认证
```

## 3. 推导

**引理 19（保真度迁移下的风险上界）** 在 A100（R_1 对域差异 L_f-Lipschitz）下，任意原型 p 的部署风险满足 R_1(p) ≤ UB_f(p) = R_f(p) + L_f d_f(p) + η_f。故：若 UB_f ≤ ε_transfer，则 f 上的证据足以给 f4 发证。系 1：**证书域界不能大于测试足迹**（定义 316）——否则 d_f 在未测区域不可估，上界失效。系 2：当 d_f 与 η_f 不可约时，再高的测试功效也无法降低部署风险——**有些能力必须上真机才能认证**，这正是保真度阶梯不能跳级的原因。

**引理 20（快速原型的赢家诅咒）** 设 N 个候选原型，真实风险 R_i，估计 R̂_i = R_i + ε_i，ε_i 次高斯（尺度 σ/√n，n 为每候选样本数）。选择 p* = argmin_i R̂_i，则真实风险相对表观风险的系统性上偏为
E[R_{p*} − R̂_{p*}] = E[−ε_{p*}] ≥ c·σ·√(2 log N / n)。
**系（本轮的核心警告）**：快速原型同时让 N↑、n↓，偏差按 √(log N / n) 增长；越「快」越容易选出最会考试的而非最安全的。解药是定义 315(c) 的 e-value/Bonferroni 校正，或留出一份**从不参与选择**的独立 holdout；二者都以「减慢发证」为代价——**这正是速度应付的统计利息**。

**引理 21（Simplex 有界切换与无突变）** 若基线在 𝕊_B 内不变安全、原型仅在 cert 域界内被选、且 Rec 保证 T_rec 内可回 𝕊_B^inv、切换成本 ≤ ε_switch，则闭环状态始终落在 𝕊_B ∪ (T_rec-可达域) 内；回退时间 ≤ T_rec；切换引起的控制抖动有界；回退后 R69 的定理 17（交互无突变）与 R68 的提交/换装不变式继续成立。

**定理 18（FORGE 严格包含 R69）** 在 A99–A103 下，FORGE 的策略空间包含 R69；当 U_ont ≤ τ_ont、规格编译失败、或没有原型通过 J_PROTO 时，两者**逐指令相同**，安全侧不做任何让步；在可认证的意义下，FORGE 的可达任务测度单调不小于 R69。故 **R69 是 FORGE 在「永不原型」边界上的退化**；新增的只有能力与效率，不是风险。

**定理 19（端到端可信与注入不可直接致动）** 在 A99–A103 下，任何到达硬件的动作要么来自基线 π_B，要么来自满足「J_PROTO 有效 ∧ o ∈ 𝕋_p^cert ∧ SHIELD 批准 ∧ Rec 成立」的原型 p，因此物理风险 ≤ ε_phys；任一证书失效都触发有界时间单调回退；语言注入**最多**导致一个被拒/被隔离的原型或消耗预算，**永远不能**让未经验证的草图直接致动；lineage 投毒因隔离区 + KL 漂移界而无法污染认证基线。**安全性的最终仲裁者是盾，而不是语言模型。**

## 6. 本轮最大风险

**一句话**：快速原型把「验证」变成了「通过我们设计的考试」——**原型造得越快、候选越多、每轮样本越少，被选中的就越可能是最会应试（奖励黑客 / 规格游戏）而非最安全的那个；证书越漂亮，离真实安全可能越远**。快速不会凭空制造不安全，但它会**系统性地放大「测试是安全的代理」这一裂缝**；一旦裂缝大于保真度迁移界，FORGE 就会自信地批量放行「已认证的错误」。

**次级风险与缓解**：
1. **保真度迁移界不可估**（sim-to-real 非线性）→ 引理 19 系 2 强制不跳级 + 影子阶 + 真机受限阶；
2. **选择偏差 / 赢家诅咒** → e-value/Bonferroni + 独立 holdout + 引理 20 明确速度的统计代价；
3. **证书域界被偷偷放大** → 定义 316「证书域界 ≤ 测试足迹」+ 独立 ODD 审计；
4. **失败原型污染库/基线** → 隔离区 + lineage 驱逐 + KL 漂移界（定义 319/322）；
5. **VLA 幻觉与提示注入** → VLA 只出结构化草图 + 规格文法白名单 + FALSIFY + SHIELD（定理 19）；
6. **原型 DoS**（注入诱导无限试错）→ PVOIE 预算硬上界 + 单位时间原型次数上限。

```python
# IP-264 FORGE-RAS：慢回路「造—试—证」，快回路「查—判—切」
class FORGE_RAS:
    def slow_loop(self, ell, o):
        U_ale, U_epi, U_ont = triage(self.fluid, ell, o)
        if U_ont <= TAU_ONT:
            return self.fluid.round(o)                  # 退化为 R69

        v = self.falsify.run(p, f, B_FALS, ALPHA, N_CAND)
        if not v.accept:
            self.protlib.quarantine(p, v); return self.fluid.round(o)
        cert = self.issue_cert(p, f, v)                 # 域界/过期/回退指针
        self.protlib.add_certified(p, cert)
        return cert

    def fast_loop(self, o, cert):
        base = self.fluid.policy(o)                     # R69 基线
        if cert is None or not cert.valid(o):
            return base
        adv = cert.prototype(o)
        return adv if self.shield.safe_to_switch(o, adv, cert, base) else base

# IP-269 FALSIFY：证伪 + 覆盖 + 统计验收 + 选择偏差校正
def falsify(p, f, B, alpha, n_cand):
    viol = succ = 0
    for _ in range(B):
        x0 = adversarial_sample(p, f, target=viol)
        traj = rollout(p, x0, f)
        if violates(traj, p.phi_safe):
            viol += 1; break
        succ += satisfies(traj, p.phi_succ)
    cov = odd_coverage(p, f)
    lcb = clopper_pearson_lower(succ, B, 1 - alpha)
    ev  = e_value(succ, B, alpha, n_cand)
    return Verdict(accept=(viol == 0 and cov >= TAU_ODD and ev.accept),
                   cov=cov, lcb=lcb, ev=ev)

# IP-274 SHIELD：Simplex 判决（可换引擎，刹车不动）
class Shield:
    def safe_to_switch(self, o, adv, cert, base):
        if not cert.in_region(o):            return False
        if not recoverable(o, base, T_rec):  return False
        if self.wm.discrepancy(o, adv, base) > cert.max_disc: return False
        return self.c_ras_wm.certified_prefix_ok(adv)
```

## 4. 推导

**引理 19（保真度迁移风险上界）** A100 下 `R_1(p) ≤ UB_f(p)=R_f+L_f d_f+η_f`。系 1：**证书域界 ≤ 测试足迹**，否则 d_f 在未测区不可估；系 2：`d_f,η_f` 不可约时再高测试功效也无用——**有些能力必须上真机才能认证**，故保真度阶梯不能跳级。

**引理 20（快速原型的赢家诅咒）** N 个候选、每候选 n 样本、次高斯噪声，选 `p*=argmin R̂` 时
`E[R_{p*}−R̂_{p*}] ≥ c·σ·√(2 log N / n)`。
系：快速原型同时使 `N↑、n↓`，偏差按 `√(log N/n)` 增长；越「快」越容易选出最会考试而非最安全的。解药：e-value/Bonferroni 或独立 holdout——**速度应付统计利息**。

**引理 21（Simplex 有界切换与无突变）** 基线不变安全 + 原型仅在 cert 域界内 + Rec 保证 T_rec 回退 + 切换成本 ≤ ε_switch ⇒ 闭环落在 `𝕊_B ∪ (T_rec-可达域)`，回退时间 ≤ T_rec，抖动有界；回退后 R69 定理 17 与 R68 提交/换装不变式保持。

**定理 18（FORGE 严格包含 R69）** A99–A103 下 FORGE 策略空间包含 R69；当 `U_ont ≤ τ`、规格编译失败、或无原型通过 J_PROTO 时两者**逐指令相同**，安全不让步；可认证可达任务测度单调不小于 R69。**R69 = 「永不原型」边界**。

**定理 19（端到端可信与注入不可直接致动）** 到硬件的动作要么来自基线，要么来自满足「J_PROTO 有效 ∧ o∈𝕋_p^cert ∧ SHIELD 批准 ∧ Rec」的原型，故物理风险 ≤ ε_phys；证书失效 ⇒ 有界单调回退；语言注入最多造成被拒/被隔离原型或耗预算，**永不直接致动未验证草图**；lineage 投毒因隔离 + KL 漂移界无法污染认证基线。**安全仲裁者是盾，不是语言模型。**

## 7. 本轮最大风险

**一句话**：快速原型把「验证」变成了「通过我们设计的考试」——**原型造得越快、候选越多、每轮样本越少，被选中的就越可能是最会应试（奖励黑客 / 规格游戏）而非最安全的那个；证书越漂亮，离真实安全可能越远**。快速不会凭空制造不安全，但会系统性放大「测试是安全的代理」这条裂缝；一旦裂缝大于保真度迁移界，FORGE 就会自信地批量放行「已认证的错误」。

**次级风险与缓解**：保真度迁移界不可估（不跳级 + 影子阶 + 受限真机阶）；选择偏差/赢家诅咒（e-value/Bonferroni + 独立 holdout）；证书域界被偷偷放大（域界 ≤ 测试足迹 + 独立 ODD 审计）；失败原型污染库/基线（隔离区 + lineage 驱逐 + KL 漂移界）；VLA 幻觉与提示注入（结构化草图 + 规格文法白名单 + FALSIFY + SHIELD）；原型 DoS（PVOIE 预算硬上界 + 单时间窗原型次数上限）。
