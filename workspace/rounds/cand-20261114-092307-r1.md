# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「仿真到现实迁移」×「移动操作」）

> R69 把不确定性一分为二（aleatoric / epistemic），并让系统学会「问」——看、触、问句。但它有一句自陈的软肋藏在最大风险里：**FLUID-RAS 的全部效率收益押在「流模型的模态分布可信」这一前提上**。这个前提其实是一个更大假设的局部：**生成模态的那个世界模型，与真实世界是同一个**。仿真到现实迁移把这个假设整个抽掉——策略是在一个「错的物理」里学出来的，标定层能对齐传感器残差，却对齐不了接触刚度、轮地摩擦、负载质心、执行器延迟。
>
> R69 问「我该向谁求证、还能问什么」，R70 追问更狠的一层：**我凭什么相信我学到的东西在真实世界成立？我用来求证的那套模型，凭什么可信？** 更要命的是，在移动操作里，最有信息量的求证动作（把底座挪到能激发轮地摩擦/负载惯量的位形、轻触未知表面）往往同时也最贴近安全边界。
>
> 本轮两个灵感正好给出结构：
> - **仿真到现实迁移**告诉我们：差距不是标量，而是一个**低维、部分可辨识**的对象——有些旋钮你能拧准，有些你永远分不清；「分不清」不总是探索不够，而是物理上不可辨识。
> - **移动操作**告诉我们：底座不是「更大的机械臂」，而是一台**可重定位的测量装置**——把它挪到相对世界的不同位形，就是在做主动实验（optimal experimental design）。**移动即激励；走一步，就是标定一次。**
>
> 核心命题：**把 R69 的 epistemic 再拆成「可辨识的认知差距 U_epi,id」与「不可辨识的模型失配 U_epi,nid」；可辨识的部分交给「底座即探针」的主动激励去消解，不可辨识的部分用差距感知的鲁棒膨胀兜住；探针只能落在与差距无关的安全核内，证书用「后验覆盖 + 鲁棒膨胀」实现可迁移。** 命名 **STRIDE-RAS**（Sim-to-real Transfer via Reconfiguration-based Identification and Decomposition of Epistemic gap）——「跨步」既是移动操作的一步，也是从仿真跨进现实的一步。
>
> 一句话定位：R68 问「测量准吗」，R69 问「该问谁」，R70 问「**我学到的到底是不是这个世界的规律，以及我敢不敢用一步移动去验证它**」。

## 0. 直觉与动机

**灵感 1（差距是有结构的，不是一团雾）**
直觉：域随机化把差距当成一个「盒子里随便抽」的分布，然后学一个对所有盒子都稳的策略——这是对冲（hedge），不是理解。但真实世界的差距通常只错在少数几个旋钮上：轮地摩擦、负载质量、接触刚度、相机外参、控制延迟。一旦估计出这几个旋钮，策略就能从「最坏情况保守」升级为「当前情况精确」。这把 sim-to-real 从「提高鲁棒性」变成「做一个在线系统辨识问题」。关键是承认：**有些旋钮在你的当前动作分布下根本拧不动（不可辨识）**，对它们只能鲁棒兜底，对可辨识的才值得花预算去测。

**灵感 2（移动操作 → 底座是测量装置）**
直觉：固定底座的机械臂只能在一组接触/视角/负载下观察世界，它的可辨识子空间是受限的；而移动底座可以把自己挪到新的位形，主动创造「能区分不同假设」的测量条件——换接触点、换重心、换视角、换轮地滑移状态。这正是实验设计（D-optimal design）在做的事：选一组实验，使参数的后验协方差行列式最小。**把底座轨迹当实验设计变量，就得到「边走边辨识」**。这也是移动操作相对固定臂的独特价值：**移动性本身就是可辨识性**——只有整体移动才能激发轮子摩擦、负载 CoM 这类参数。

**灵感 3（辨识-安全死锁 → 最该知道的偏偏最不敢试）**
直觉：R69 的探针（看/触/问）都在「已知模型」里认证。到了 sim-to-real，认证器本身来自仿真，于是出现恶性循环：**用不可信的仿真证书，去授权真实的探索动作**。更糟的是，最有信息量的激励往往最靠近安全边界（大加速度激发轮地摩擦、硬接触激发刚度）。也就是说，**你最需要辨识的参数方向，恰恰是最不敢激励、也最可能不可辨识的方向**。这不是工程细节，是认识论上的硬约束。解决办法只能是把探针限制在一个**物理无关的安全核**（质心在支撑多边形内、力矩限、力上限、碰停）里——这些量不依赖 θ_gap，所以可用来打破循环。

**灵感 4（证书不迁移 → 让置信集而不是点估计去背锅）**
直觉：在仿真里通过的证书，到了现实一文不值，因为仿真的「真值」是错的。但如果差距估计有一个**校准过的后验置信集 Θ_α**（覆盖真实参数的概率 ≥ 1−α），并且控制器对 Θ_α 里每个 θ 都鲁棒可行，那么现实违反概率 ≤ α + 余量。也就是说：**把「点估计 + 确定性证书」换成「置信集 + 鲁棒证书」，证书就能合法地跨越现实鸿沟**。辨识越充分，Θ_α 越小，证书越不保守——这就是「跨步」带来的收益。

**灵感 5（差距会漂移 → 标定过期比不标定更危险）**
直觉：负载换了、轮子磨了、地面变了、相机被碰了，差距会非平稳漂移。一次辨识出的「已标定」会过期，而过期的标定比诚实的未知更危险——系统会自信地在错误模型上行动。R69 的 FMA 行为似然通道正好复用：它测的是「观测条件下的动作是否仍落在策略密度的高处」，差距漂移会把它顶起来。所以辨识必须由**漂移检测**触发重开，而不是按计划表重标。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（STRIDE-RAS 总览）** STRIDE-RAS = (GRD, IDX, BAP, CRI, GAP-POL, GISK, GATC, GDT, RAS-WM†)。四不变式：
(i) 实时控制流零学习写操作（继承 R68 定义 276-i）；
(ii) **探针只在差距无关安全核内**（定义 317）：任何信息动作必须先通过 GISK，且 GISK 的成立不依赖 θ_gap；
(iii) **可辨识性门控**（定义 312）：只有 U_epi,id 驱动探索，U_epi,nid 一律走鲁棒膨胀，不得用探索预算「假装」消除；
(iv) **证据与漂移纪律**：证书必须携带校准后的差距置信集；漂移检测触发重辨识前，旧的「已标定」不得降低安全裕度。

**定义 311（差距表示与三分解）** 现实差距建模为低维物理参数 θ_gap ∈ ℝ^{d_g}（轮地摩擦、负载质量/CoM、接触刚度、执行器延迟、相机外参等）与非参数残差 e_m。把 R69 的 U_epi 细分为：
- U_ale：不可约随机性（传感噪声、高频未建模）；
- U_epi,id：在当前激励下**可辨识**的认知差距（Fisher 信息超过阈值）；
- U_epi,nid：**不可辨识或不可在本任务预算内辨识**的模型失配（进入鲁棒兜底）。
三者分别进入探索 / 鲁棒 / 保守三条通道，不做简单加和。

**定义 312（可辨识性度量 IDX）** 设传感映射 y = h(q, θ_gap) + e，灵敏度 Jacobian J_t = ∂h/∂θ_gap。激励 Gramian G(ξ) = Σ_{t∈horizon} J_tᵀ Σ_e⁻¹ J_t。方向 d 可辨识 ⇔ dᵀGd ≥ τ_id（持久激励，PE）。可辨识子空间 𝒮_id = span{特征值 ≥ τ_id 的特征向量}；U_epi,id 在 𝒮_id 上取后验迹，U_epi,nid 在补空间上取最坏界。

**定义 313（全身增广动作空间）** 任务动作 a = (a_base, a_arm) ∈ 𝒜_base × 𝒜_arm（底座速度/位形 + 关节/夹爪指令）；信息动作 g 在 R69 的 (g_gaze, g_probe, g_ask) 上新增 **g_base**（底座重定位/激励轨迹）。增广动作 ξ = (a, g) ∈ 𝒜_+；g_base 与任务底座动作共享同一 C-RAS-WM 安全认证，但承担额外的辨识目的。

**定义 314（底座即探针 BAP 与 OED 激励设计）** 对候选底座轨迹/位形 β，定义期望信息增益 IG(β) = ½ log det(I + G(β)Σ_θ⁻¹) − c_safe(β)。选 β* = argmax_β [IG(β) − λ_task·task_regress(β) − c(β)]，s.t. β 全程在 GISK 内且不使任务进度回退超过 ε_prog。**底座轨迹是实验设计变量**：它同时服务任务与辨识，二者冲突时以安全核为硬约束。

**定义 315（接触机制辨识 CRI）** 移动操作的隐藏离散状态 r ∈ {free, contact, slip, grasp}；差距在机制边界处最危险。轻触探针 g_probe 用于判定 r 与边界距离：r̂ = argmax_r p(r | y_probe)。机制误判概率 p_mis 进入 U_epi,nid 的鲁棒膨胀项（定义 324）。

**定义 316（差距条件自适应策略 GAP-POL）** 策略 π_θ(ξ | o, θ̂_gap, Θ_α)：以辨识后验的均值 θ̂ 与置信集 Θ_α 为条件；对 Θ_α 做鲁棒化（min-max 或分布鲁棒）。θ̂ 只用于「提效」，Θ_α 的半径用于「保安全」；两者解耦，防止点估计过拟合造成的过度自信。

**定义 317（差距无关安全核 GISK）** 一组仅依赖物理恒等式与硬件极限、不依赖 θ_gap 的安全谓词：质心投影在支撑多边形内且留裕度、关节力矩/速度/力上限、碰停（力超阈立即停）、低速包络、自碰撞与静态稳定。GISK(ξ) = True ⇒ 该动作在最坏物理参数下也不越界。**这是打破「用仿真证书授权真实探索」循环的唯一锚点。**

**定义 318（探针认证）** 信息动作 g 必须满足：GISK(g) ∧ C-RAS-WM 认证（在 θ̂ 下）∧ 力/位移/时间预算。任一不满足 ⇒ g 作废，U_epi,id 保持未消解（走保守），不得以「为了辨识」为由放宽 GISK。

**定义 319（差距 VoI）** 对探针 g：VoI_gap(g) = ½ log det(Σ_θ) − ½ E_{y~p(·|g)} log det(Σ_θ|y)，即参数后验熵的期望下降（D-最优）。选 g* = argmax[VoI_gap − c_safety − c_time]，且 max ≤ 0 时不探、走鲁棒/保守。

**定义 320（非平稳差距追踪 GDT）** 复用 R69 的流似然异常分：Δa_t = |a_score(o_t) − a_score(o_t^{cal})|。定义漂移分 D_t = EWMA(Δa_t) / (1 + κ·confidence(θ̂))。D_t > τ_drift ⇒ 差距分布漂移，重开辨识、把 U_epi,nid 抬到漂移界。

**定义 321（差距感知可迁移证书 GATC / J_STRIDE）** J_STRIDE = (J_FLUID, θ̂_gap, Θ_α, coverage_test, U_epi,id, U_epi,nid, excitation_gramian_hash, gisk_log_hash, drift_score, stride_ver)。Valid ⇔ Valid(J_FLUID) ∧ 后验覆盖率 ≥ 1−α（可检验）∧ 控制器对 ∀θ∈Θ_α 鲁棒可行（含 GISK 膨胀）。

**定义 322（仿真到现实对抗干扰集 ℰ_s2r）** 最坏参数漂移、以辨识为诱饵的对抗激励（把你引导到不可辨识/危险区域）、传感器欺骗使 θ̂ 收敛到错值、非平稳突跳。并入 AIC：ℰ_STRIDE = ℰ_FLUID × ℰ_s2r × ℰ_drift。

**定义 323（域随机化桥接 DRB）** 当 𝒮_id 维度过低（几乎不可辨识）时，STRIDE 退化为对 DR 分布 D 的最坏情况鲁棒控制：θ̂ 弃用，Θ_α 取 support(D) 的膨胀。即 **DR 是 STRIDE 在「无可辨识方向」边界上的特例**。

**定义 324（三级退避）** 按 U_epi,id 是否消解、U_epi,nid 是否受控分三级：
- L1（辨识成功且差距受控）：λ = λ_floor(U_ale)；
- L2（可辨识但预算/安全不允许探索，或部分不可辨识）：λ = λ_floor(U_ale + U_epi,id + robust_inflate(U_epi,nid, Θ_α))；
- L3（漂移/对抗/覆盖率失败）：λ = λ_floor(U_ale + U_epi,id + U_epi,nid + drift_bound)，并缩回 R68 最保守。
λ 单调不降，安全侧永不弱于 R69（更不弱于 R68）。

**定义 325（安全-可辨识性死锁）** 若对某关键方向 d，唯一高信息激励 β_d 的 GISK 认证失败（或其安全成本 > 收益），称该方向**死锁**。死锁方向强制归入 U_epi,nid，并用最坏界兜底；同时在证书中显式记录「不可学习的危险方向」，供人类接管或重新布置环境（例如先移走负载、铺更粗糙的地面）。

**定义 326（双速率时序与预算）** 快环（控制，≤2ms）只用 θ̂ 与预计算的鲁棒界；慢环（辨识，10–100ms）跑 GRD/IDX/BAP/GDT。激励预算：单位任务内底座激励位移 ≤ ε_exc、轻触次数 ≤ n_probe、且不得使任务完成时间退化超过 δ_T。

## 2. 关键算法骨架

```python
# IP-275 STRIDE 主闭环（继承 FLUID-RAS，插入「差距辨识层」）
def STRIDE_round(M, obs):
    # 0) 快层：R69/R68 一次前向 + 标定
    z, o = M.mtm.forward(obs)
    c, U_cal, thr = M.cof.step(...)
    # 1) 差距三分解：可辨识 / 不可辨识 / 随机
    theta_hat, cov = M.grd.estimate(o)                  # 低维 θ_gap（EKF/RLS）
    S_id, U_id, U_nid = M.idx.decompose(theta_hat, cov, M.last_excitation)
    U_ale = M.grd.aleatoric(o)
    # 2) R69 的多模态策略沿用；歧义仍未消解
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale_s, U_epi, modes = M.aud.decompose(samples, z)
    U_ale += U_ale_s
    # 3) 差距-VoI：用「底座重定位 / 轻触 / 主动看」消解可辨识方向
    probe = None
    if U_id > TAU_ID:
        probe = M.bap.design(modes, theta_hat, cov, M.last_excitation, M.budget)
        # 探针候选含 g_base（OED 选出的激励位形）与 g_probe（机制辨识）
        if probe is not None and not M.gisk.certify(probe, o):
            M.vqa_s.log_deadlock(probe.direction)        # 安全-可辨识性死锁
            probe = None
    # 4) 执行探针（可与任务动作拼成同一 ξ 模态）并更新差距后验
    if probe is not None:
        y = M.cia.execute(probe)                         # 走/触/看，均在 GISK 内
        theta_hat, cov = M.grd.update(theta_hat, cov, probe, y)
        S_id, U_id, U_nid = M.idx.decompose(theta_hat, cov, M.last_excitation)
    # 5) 非平稳：复用的行为似然通道检测差距漂移
    D = M.gdt.drift_score(M.fmp, M.last_action, o, o_calibrated)
    if D > TAU_DRIFT:
        M.grd.reopen(theta_hat, cov)                     # 旧标定作废，重开辨识
        U_nid = max(U_nid, drift_bound(D))
        M.gatc.invalidate(theta_hat)                     # 证书降级 L3
    # 6) 差距感知鲁棒膨胀（不可辨识方向走最坏界）
    U_robust = robust_inflate(U_nid, cov, M.gisk.margin)
    U_id_left = 0.0 if probe is not None else U_id
    lam = max(M.efs.risk_scale(...), M.lam_floor(U_ale + U_id_left + U_robust))
    # 7) 全身动作 + 差距感知可迁移证书
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.gatc.certified_prefix(A, theta_hat, cov, U_robust, ..., wm_preds)
    mode = select_mode(modes, U_id_left, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 8) 参与式审计：探针、死锁、漂移、覆盖率
    M.vqa_s.submit_async(probe, theta_hat, cov, D)
    return k, lam, mode, (theta_hat, U_id, U_nid)
```

## 3. 推导

**引理 19（持久激励 ⇒ 可辨识；移动性扩展可辨识子空间）** 方向 d 可辨识 ⇔ 激励 Gramian 满足 dᵀGd ≥ τ_id。固定底座时，J_t 对轮地摩擦/负载 CoM 的列在整条轨迹上近似为零 ⇒ G 在这些方向奇异 ⇒ 不可辨识；底座运动引入位形变化与惯性/滑移观测，使对应列非零、G 在这些方向正定。**系：移动性是可辨识性的来源——固定臂永远学不到只有整体移动才能激发的参数；「走一步」本身就是一次系统辨识。**

**引理 20（辨识-安全权衡与死锁）** 设探针 g 使参数后验熵下降 ΔH_g，任务风险增益 ≤ L_risk·√(ΔH_g)（差距到风险的 Lipschitz 界）；探针自身安全成本 c_g ≥ ε_int，且若 GISK 失败则不可执行。则最优探针 = argmax[L_risk·√(ΔH_g) − c_g]，条件为 GISK(g)。当所有高信息探针都 GISK 失败时，ΔH_g 可得而 c_g = ∞ ⇒ 方向进入死锁、永久归入 U_epi,nid。**系：最致命的差距未必可学——数学上可辨识不等于物理上可执行。**

**引理 21（后验覆盖 + 鲁棒证书 ⇒ 可迁移安全）** 若差距后验的置信集 Θ_α 满足 P(θ_gap ∈ Θ_α) ≥ 1−α（校准），且控制器对 ∀θ∈Θ_α 满足差距感知约束（含 GISK 膨胀 e_m 界），则现实违反概率 ≤ α + P(e_m > e_m^max) =: α + ε_m。**系：把「点估计+确定性证书」换成「置信集+鲁棒证书」，证书即可跨越现实鸿沟；辨识收益体现为 Θ_α 收缩 → 保守度下降，而非直接信任点估计。**

**定理 18（STRIDE 严格包含 FLUID-RAS 与域随机化）** (i) 当 θ_gap = 0（无差距）时，U_id = U_nid = 0，STRIDE 逐指令退化为 FLUID-RAS（进而是 R68）；(ii) 当可辨识子空间维数为 0 时，θ̂ 弃用，Θ_α = support(D) 膨胀，STRIDE 退化为域随机化最坏情况鲁棒控制；(iii) 恒有 λ_STRIDE ≥ λ_FLUID（U_robust ≥ 0），故安全侧永不弱于 R69/R68。**两种边界都被严格包含，新层不是并列黑箱。**

**引理 22（非平稳与标定过期的危害）** 若 θ_gap 以速率 ρ 漂移而辨识窗口为 W，则 θ̂ 的陈旧误差 ≈ ρ·W；当漂移未被 GDT 检出而系统仍按旧 Θ_α 行动时，实际违反概率从 α 升到 α + Φ(ρW/σ_θ)。**系：过期的「已标定」比诚实的未知更危险——它把覆盖率悄悄破坏，而系统自以为安全；故重辨识必须由漂移检测触发，证书必须携带漂移分。**

**定理 19（GISK 打破自指循环）** GISK 的谓词仅由物理恒等式与硬件极限构成，不依赖 θ_gap，故其判定在真实世界与仿真中同真；因此用 GISK 授权的探针，其安全性不依赖不可信的世界模型。**系：可被信任的探索，只能发生在「即使模型全错也不会受伤」的动作集内；这既是约束，也是唯一可行的起点。**

## 3. 关键算法伪代码

```python
# IP-275 STRIDE 主闭环（继承 FLUID-RAS）
def STRIDE_round(M, obs):
    z, o = M.mtm.forward(obs); c, U_cal, thr = M.cof.step(...)
    theta_hat, cov = M.grd.estimate(o)                  # 低维 θ_gap
    S_id, U_id, U_nid = M.idx.decompose(theta_hat, cov, M.last_excitation)
    U_ale = M.grd.aleatoric(o)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale_s, U_epi, modes = M.aud.decompose(samples, z)
    U_ale += U_ale_s
    # 底座即探针：OED 选激励位形；越出 GISK 记为死锁
    probe = None
    if U_id > TAU_ID:
        probe = M.bap.design(modes, theta_hat, cov, M.last_excitation, M.budget)
        if probe is not None and not M.gisk.certify(probe, o):
            M.vqa_s.log_deadlock(probe.direction); probe = None
    if probe is not None:
        y = M.cia.execute(probe)                         # 走/触/看，均在 GISK 内
        theta_hat, cov = M.grd.update(theta_hat, cov, probe, y)
        S_id, U_id, U_nid = M.idx.decompose(theta_hat, cov, M.last_excitation)
    # 非平稳：复用 R69 行为似然通道
    D = M.gdt.drift_score(M.fmp, M.last_action, o, o_calibrated)
    if D > TAU_DRIFT:
        M.grd.reopen(theta_hat, cov); U_nid = max(U_nid, drift_bound(D))
        M.gatc.invalidate(theta_hat)                     # 降级 L3
    U_robust = robust_inflate(U_nid, cov, M.gisk.margin)
    U_id_left = 0.0 if probe is not None else U_id
    lam = max(M.efs.risk_scale(...), M.lam_floor(U_ale + U_id_left + U_robust))
    A = M.ach.propose(x_prime, H=M.vista.H)
    k = M.gatc.certified_prefix(A, theta_hat, cov, U_robust, ..., wm_preds)
    mode = select_mode(modes, U_id_left, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(probe, theta_hat, cov, D)
    return k, lam, mode, (theta_hat, U_id, U_nid)
```

## 4. 推导

**引理 19（PE ⇒ 可辨识；移动性扩展可辨识子空间）** 可辨识 ⇔ `dᵀGd ≥ τ_id`。固定底座时，轮地摩擦/负载 CoM 对应的 `J_t` 列近似为零 ⇒ G 奇异 ⇒ 不可辨识；底座运动使这些列非零、G 正定。系：**移动性是可辨识性的来源——「走一步」本身就是一次系统辨识。**

**引理 20（辨识-安全权衡与死锁）** 探针风险增益 ≤ `L_risk·√(ΔH_g)`、成本 `c_g ≥ ε_int`，最优 `argmax[L_risk√ΔH_g − c_g]`，`s.t.` GISK。所有高信息探针均 GISK 失败 ⇒ `c_g=∞` ⇒ 死锁、永久归 U_epi,nid。系：**数学上可辨识 ≠ 物理上可执行。**

**引理 21（后验覆盖 + 鲁棒证书 ⇒ 可迁移安全）** 校准置信集 `P(θ_gap∈Θ_α)≥1−α` 且控制器对 `∀θ∈Θ_α` 鲁棒可行 ⇒ 现实违反概率 ≤ `α + P(e_m>e_m^max)`。系：点估计→置信集，证书方可跨现实鸿沟；辨识收益 = `Θ_α` 收缩而非信任点估计。

**引理 22（标定过期的危害）** 差距以速率 ρ 漂移、窗口 W ⇒ 陈旧误差 ≈ `ρW`；未检出时违反概率从 α 升至 `α + Φ(ρW/σ_θ)`。系：**过期的「已标定」比诚实的未知更危险**；重辨识须由漂移检测触发。

**定理 18（STRIDE 严格包含 FLUID-RAS 与域随机化）** (i) `θ_gap=0 ⇒ U_id=U_nid=0`，逐指令退化为 FLUID-RAS（进而是 R68）；(ii) `dim 𝒮_id=0 ⇒` 取 `support(D)` 膨胀，退化为 DR 最坏情况鲁棒；(iii) 恒有 `λ_STRIDE ≥ λ_FLUID`。两边界严格包含，安全侧不让步。

**定理 19（GISK 打破自指循环）** GISK 谓词仅由物理恒等式+硬件极限构成、不依赖 θ_gap，故在真实与仿真中同真；GISK 授权的探针安全性不依赖不可信世界模型。系：可信任的探索只发生在「模型全错也不受伤」的动作集内。

## 7. 本轮最大风险

**一句话**：STRIDE 的探索合法性建立在 GISK「即使模型全错也不受伤」之上，但**最致命的差距往往恰好落在 GISK 之外**——你越需要辨识的方向，越是探针不敢激励、也越可能根本不可辨识的方向；把死锁误当成「还没探够」而强行探索，就会用一条仿真证书去授权真实世界的危险实验。其次，差距随负载/磨损漂移，**过期的「已标定」会悄悄破坏覆盖率，比诚实的未知更危险**。

**次级风险与缓解**：辨识-安全死锁（定义 325 显式记录 + 归 U_epi,nid 最坏界 + 请求人类重布置）；标定过期（GDT 漂移触发重开 + 引理 22 + L3 退避）；后验覆盖率失准（可检验覆盖率 + E309，不达标降 L3）；对抗诱饵激励（ℰ_s2r + VQA-S 审计激励来源 + E314）；底座激励扰动任务（任务回退硬约束 ε_prog + 双速率）；全身接触突变（CRI 机制辨识 + 继承 R69 定理 17 换装不变式）。
