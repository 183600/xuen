# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「多模态交互」×「低成本方案」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**歧义门控 + 冲突中立元 + 成本不降安全**。两个灵感互为约束：多模态交互天然抬高成本，"低成本"迫使多模态必须按需、可退化、可摊销。任一新模态不可用或冲突超阈 ⇒ 注入中性权重，严格等价退回 v9 语音单模态；成本优化只允许经调度/稀疏/复用的中立元等价路径；安全关键证书永不被成本门控。

## 0. 直觉与动机

**灵感 1（多模态交互 → 按需升级，而非全时全开）**
直觉：人不会对每句话都同时用眼、手、语音；只有当语音含糊时，才抬头看对方指哪里。现有多模态系统常犯"全模态全时在线"的错——成本高、标定难、共模故障集中。核心创新：**歧义门控多模态交互（Ambiguity-Gated Multimodal Interaction, AGMI）**——以语音意图后验的归一化熵 u_t 为闸门，仅当 u_t > θ_amb 或指代歧义 u_ref > θ_ref 时，才按"单位代价信息增益"贪心选择附加模态子集 S_t。多模态从"常开架构"变成"按需升级动作"。

**灵感 2（低成本方案 → 复用与摊销，新增硬件为零）**
直觉：v9 的动作分块已把决策算力利用率从 ~1.0 压到 ~0.3，这 70% 余量正是多模态升级的"免费预算"。核心创新：**能量感知交互契约（Energy-aware Interaction Contract, EIC）**——在 v9 模块契约上追加能量维度 J_m 与总功耗上界 P_max；多模态升级只在 AC/ID 释放的预算内进行；复用既有 RGB-D/麦克风阵列/IMU，零新增传感器；手势/注视用 INT8 小模型 + 事件触发。**低成本不是删功能，而是把昂贵计算挪到真正需要的时刻**。

**两条灵感的合成**：低成本给出"预算"，多模态给出"花法"，中立元退化保证"花错也能安全收回"。系统从 v9 的"按时间分块"升级为"时间分块 × 模态稀疏"双重稀疏化：时间稀疏（AC）与模态稀疏（AGMI）正交，可分别、独立地退化为 v9。

## 1. 研究问题（轮次升级版）

- **Q1（按需多模态的收益/代价判据）**：如何定义并标定歧义闸门 u_t 与信息增益-焦耳比，使按需升级在期望意义上优于语音单模态，又不因门控漏检而损失关键消歧？
- **Q2（冲突与共模故障）**：当 gaze/gesture/vision 共享相机与标定误差时，模态间"一致"可能是虚假的；冲突证书与共模检测如何设计，才能使冲突回退真正安全而非虚假安心？
- **Q3（低成本的严格边界）**：成本优化在什么代数条件下不降低安全？能量契约如何与 v9 的 EDF/WCET 契约统一，且不破坏 50Hz 主环？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 歧义门控多模态律（AGMI）**
附加模态只在歧义超阈时启用：S_t ⊆ {gz,gt,d,au} 由 u_t 门控、经"单位代价边际信息增益"贪心选出，并受交互预算 B_int(t) 约束；u_t < θ_amb 时 S_t=∅，严格等价 v9 语音单模态。

**P14 冲突中立元律（CNF）**
融合采用加权对数池，附加模态权重 w_m 的缺席/回退值为 0（融合算子中立元）。冲突证书 C_x=(x_t,c_t,ρ̂_t) 无效（x_t>τ_conf ∨ 覆盖不足 ∨ 共模相关超阈）⇒ 所有附加模态注入 w_m=0，逐位退回 v9；附加模态永不修改安全关键证书。

**P15 低成本不降安全律（CDSS）**
成本优化只允许三种中立元等价操作：时间摊销（复用 AC 余量）、模态稀疏（AGMI）、特征复用（事件缓存）；φ^elig=false 的安全模块与证书永不被成本门控；总功耗由能量契约硬约束 Σ J_m ≤ P_max·T_int。

## 3. 与基线的接口（如何退化）

- 附加模态全失效或冲突超阈 ⇒ w_m=0，退回 v9 语音单模态（引理 88）；
- 路由/门控失效 ⇒ 固定语音单模态（最保守），不猜测模态；
- 能量契约超支 ⇒ 关闭附加模态，等价 v9 算力模式；
- v9 的 AC/MW/ID 任一失效 ⇒ 按 v9 引理 82–86 逐级退回 v8；
- v8 的 DA/SPR/Cal 失效 ⇒ 中立元注入，退回 v7；全失效 ⇒ v6。

## 4. 预期贡献

1. **按需多模态路由**：以"信息增益/焦耳"为目标的模态子集选择，附条件独立下的 (1−1/e)（基数）/ (1−1/e)/2（背包）近似保证；
2. **中立元融合**：w_m=0 使"少模态"成为代数恒等而非行为漂移，模态增删不改变下游契约；
3. **共模盲区的诚实刻画**：给出冲突证书在共享传感器扰动下的可识别性负结果，配套 src 分组共模检测；
4. **时间×模态双重稀疏**：v9 分块释放的算力反哺多模态，形成"预算-消歧-安全"闭环；E571–E590 覆盖路由、冲突、能耗、共模、低算力部署与端到端。

## 5. 本轮最大风险

**一句话**：冲突证书默认模态证据条件独立，而 gaze/gesture/vision 共享同一相机与同一标定误差，低成本稀疏化恰好丢掉了能暴露这种相关性的冗余模态——系统可能以最低成本获得最高的"虚假一致"置信度，在最需要多模态的时刻把共模故障误判为高置信。

## 1. 符号体系增量（定义 540–547）

**定义 540（模态证据格与融合算子）** 附加模态证据以"权重-对数几率"对 (w_m, ℓ_m) 表示。融合算子 ⊕ 定义为加权线性池（log-opinion pool）：
```
ℓ(y) = ℓ_0(y) + Σ_{m∈S} w_m·(ℓ_m(y) − ℓ_0(y)),   w_m ≥ 0, Σ_{m∈S} w_m = 1
```
其中 ℓ_0 为先验对数几率。单位元为 w_m=0：任意 (0,ℓ_m) 与其余证据组合后结果不变（x⊕v^⊥=x）。该算子对权重可交换、可结合，中立元唯一。权重由留出集精度或逆方差标定。

**定义 541（歧义泛函）**
```
u_t = λ_y·H(p(y|m_v))/log|Y| + λ_r·H(p(r|m_v,s))/log|R|,  λ_y+λ_r=1
```
r 为空间指代对象；u_t∈[0,1]，越大越含糊。门控：u_t<θ_amb 时不启用任何附加模态。

**定义 542（信息增益-代价路由）** 期望增益 ΔH(S)=H(y|m_v)−E_{obs}[H(y|m_v,S)]；代价 C(S)=Σ_{m∈S}J_m + γΣ_{m∈S}c_m（焦耳/毫秒归一到同一量纲）。路由：
```
S_t = argmax_{S⊆{gz,gt,d,au}, C(S)≤B_int(t)}  ΔH(S)/C(S)
      s.t.  ΔH(S) ≥ θ_gain  且  u_t ≥ θ_amb
```
实现用密度贪心：每步选取边际增益/代价最大且增益≥θ_gain 的模态，直至预算耗尽。ΔH 的评估依赖一个廉价增益预测器 ĝ(m|context)（离线监督训练），其分布外失准正是 §8 风险的来源。

**定义 543（激活集与覆盖）** 当轮激活集 A_t={v}∪S_t。覆盖率 c_t 为被 S_t 覆盖的歧义分量占比（意图/指代分别计），用于判定"即便路由后仍不足以消歧"。

**定义 544（冲突证书）** 对 A_t，成对不一致度取 Bhattacharyya 距离 d_{ij}=1−Σ_y√(p_i(y)p_j(y))；冲突度 x_t=max_{i≠j}d_{ij}。共享源分组 src_m 给出共模相关估计 ρ̂_t=max_{src} corr(残差)。证书有效：
```
C_x 有效 ⇔ x_t ≤ τ_conf ∧ c_t ≥ c_min ∧ ρ̂_t ≤ ρ_max
```
任一不满足 ⇒ 附加模态全注入 w_m=0（引理 89）。

**定义 545（多模态交互契约）** κ_m^{MM}=(In,Out,D_m,Ŵ_m,v_m^⊥,π_m,φ^elig,J_m,src_m)。部署期除 v9 的 ΣŴ_m≤B_dec 外，追加 Σ_{m∈A_t}J_m ≤ P_max·T_int 与安全预留约束。

**定义 546（能量契约与交互预算）** 交互回合时长 T_int 内 B_int(t)=P_max·T_int−Σ_{s∈safety}J_s。权重 w_m=0 时该模态的 J_m 不计入（能量中立元）；超支即触发 Level-2 关闭附加模态。

**定义 547（事件驱动模态缓存）** 缓存 φ_m 与时戳。重算仅在事件 e_m（语音起始、手势起始、注视落点切换）或 age>τ_stale 或 Δ_dom>τ_dom 时发生；命中率 h 使附加模态有效代价乘 (1−h)。陈旧命中是允许的错误源，由 E584 量化并计入安全边际。

```python
# IP-357 ModalityRouter：歧义门控 + 信息增益/焦耳路由
class ModalityRouter:
    def __init__(self, mods, gain_pred, theta_amb=0.55, theta_gain=0.05,
                 lam_y=0.6, lam_r=0.4):
        self.mods, self.gain = mods, gain_pred
        self.theta_amb, self.theta_gain = theta_amb, theta_gain
        self.lam_y, self.lam_r = lam_y, lam_r

    def ambiguity(self, p_y, p_r):
        return (self.lam_y * entropy(p_y) / log(len(p_y))
                + self.lam_r * entropy(p_r) / log(len(p_r)))

    def route(self, u, budget):
        if u < self.theta_amb:
            return []                                  # 语音单模态足够（v9）
        S, rem, cand = [], budget, list(self.mods)
        while cand:
            m = max(cand, key=lambda m: self.gain.marginal(S, m) / self.mods[m].cost)
            g = self.gain.marginal(S, m)
            if g < self.theta_gain or self.mods[m].cost > rem:
                break
            S.append(m); rem -= self.mods[m].cost; cand.remove(m)
        return S


# IP-358 CrossModalFuser：加权对数池 + 冲突证书
class CrossModalFuser:
    def __init__(self, tau_conf=0.25, c_min=0.6, rho_max=0.5):
        self.tau_conf, self.c_min, self.rho_max = tau_conf, c_min, rho_max

    def certify(self, P, src):
        x = max((1.0 - sum(sqrt(P[i][y] * P[j][y]) for y in P[i])
                 for i in P for j in P if i < j), default=0.0)
        rho = max_shared_source_corr(P, src)           # 共模相关（定义 544）
        cov = coverage(P)
        return Cert(x, cov, rho,
                    x <= self.tau_conf and cov >= self.c_min and rho <= self.rho_max)

    def fuse(self, evidence, weights, cert):
        if not cert.valid:                             # 冲突/共模超阈
            weights = {m: 0.0 for m in weights if m != 'v'}   # 附加模态中立元
        num = defaultdict(float); den = 1.0
        for m, lo in evidence.items():
            w = weights.get(m, 0.0)
            if w == 0.0:
                continue                               # x ⊕ v^⊥ = x
            for y in lo: num[y] += w * lo[y]
            den += w
        return softmax({y: num[y] / den for y in num})


# IP-359 EnergyContractBroker：能量契约（复用 AC/ID 余量）
class EnergyContractBroker:
    def __init__(self, P_max=25.0, safety_reserve=6.0):
        self.P_max, self.reserve = P_max, safety_reserve

    def budget(self, T_int):
        return self.P_max * T_int - self.reserve     # B_int（定义 546）

    def admit(self, S, mods, T_int):
        return sum(mods[m].joules for m in S) <= self.budget(T_int)

    def on_overrun(self, weights):
        for m in list(weights):
            if m != 'v':
                weights[m] = 0.0                    # 能量中立元 → Level-2
        return weights

    verdict, k = chunker.midchunk_guard(current_chunk, ctx.k_exec, live_obs)
    C, spatial_cert, claims, metrics, rewards = M.inherited_v9_path(ctx, p_task)
    distiller.step(ctx.cycle_idx, ctx)
    return C, spatial_cert, claims, metrics, rewards
```

## 4. 推导

**引理 87（密度贪心的信息-代价近似）** 设附加模态证据在给定意图下条件独立（故 ΔH 单调子模）。则按边际增益/代价的贪心在基数约束 |S|≤k 下达到最优的 (1−1/e)，在背包约束 C(S)≤B 下达到 (1−1/e)/2（Khuller–Moss–Naor）。若条件独立被破坏（共模相关），子模性与近似比同时失效——这正是引理 91 的负结果入口。∎

**引理 88（中立元融合与 v9 逐位等价）** 对任意激活集 A_t，若把全部附加模态权重置 0，则融合后验 p(y|A_t)=p(y|m_v) 逐位一致。证明：定义 540 中 w_m=0 项整体消失，仅剩语音项；归一化权重与 v9 的 NLU 后验相同；指代后验同理。∎

**引理 89（冲突回退安全）** 若 C_x 无效（x_t>τ_conf ∨ c_t<c_min ∨ ρ̂_t>ρ_max），CMF 对附加模态注入 w_m=0，系统行为∈v9（引理 88）；附加模态在任何路径下都不写入 M₀/SpatialCert/FaultCert，故 v8/v9 引理 79–86 的安全结论原样传递。∎

**引理 90（低成本期望界）** 设门控触发概率 p_amb、附加模态期望代价 C_esc、语音代价 C_v、缓存命中率 h。每交互期望能量 E[J]=p_amb·(1−h)·C_esc+(1−p_amb)·C_v；当 C_esc≤B_int 且 p_amb≤(P_max·T_int−C_v)/((1−h)C_esc) 时总功耗≤P_max。v9 分块余量使 B_int 非负（E581）。∎

**引理 91（共模盲区，负结果）** 设两模态因共享相机/标定偏置在扰动 z 下输出同向错误后验 p_1=p_2=(1−ε,ε)。则 d_{12}=1−Σ_y√(p_1p_2)=1−[(1−ε)+ε]=0，x_t=0≤τ_conf，冲突证书在两者皆错时仍"通过"。故 x_t 不能对共模故障提供正确性保证；只能靠 src 分组的 ρ̂_t 部分缓解，且 ρ̂ 的估计本身需要独立参照（E574 注入实验量化漏检）。∎

**引理 92（不越权与安全传递）** 定义 540 的融合仅作用于任务后验空间；安全证书空间的附加模态权重恒 0，故多模态证据无法修改任何安全判定；所有安全结论仍由 v8/v9 的安全链给出。∎

**引理 93（交互时延界）** 单回合附加模态计算 ≤ Σ_{m∈S}Ŵ_m ≤ B_int（时间维），路由 O(|A|k)、融合 O(|Y||S|) 均 <0.2ms；交互级 p99 ≤300ms（含语音端点+路由+融合），不影响 50Hz 主环的 20ms 决策预算（能量契约只占 AC 释放的余量）。∎

## 9. 本轮最大风险

**一句话**：冲突证书默认模态证据条件独立，而 gaze/gesture/vision 共享同一相机与同一标定误差，低成本稀疏化恰好丢掉了能暴露这种相关性的冗余模态——系统可能以最低成本获得最高的"虚假一致"置信度，在最需要多模态的时刻把共模故障误判为高置信（引理 91 已给出该盲区的构造性证明）。
