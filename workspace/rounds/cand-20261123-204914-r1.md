研究循环 · 新灵感第 1 轮；本轮灵感：「运动控制」×「动力学」

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v22 + IP-431–435（HPC-E、EVC、PGEV、RGC、ACSC、DCSC、CFC++ 与三层过滤器 `Fil_hierarchical`），其上承 v21 语义-规范层（HPC+/SDC/CAC/DCL/GIC）与 v20 联邦感知证书（PCA/CTS/CFC/HPC/CFCtrl）。本轮不推倒 v22：能量账户 EVC、物理证伪 PGFO、现实差距 RGC、机械臂配空间 ACSC、深度 conformal DCSC 与 deontic 三层过滤器全部保留。
> 本轮纪律：**证书若只对名义轨迹成立、不对实际闭环成立，就只是"纸上的安全"；动力学决定"力能否被产生"，运动控制决定"误差能否被压住"，两者共同决定"名义计划能否变成实际轨迹"**。本轮只做一件事：把 v22 的"计划层 / 积分层证书"下沉为"**瞬时力可行 + 闭环误差管道包含 + 运行时不变式**"的执行层证书，并顺手封堵 v22 的最大风险（分层边界模糊导致的层级振荡与活性坍缩）。

## 0. 直觉与动机

**灵感 1（运动控制 → 从"名义轨迹"到"闭环误差管道 + 运行时安全滤子"）**

**直觉**：v20–v22 的所有证书，本质上都在回答两个问题——"这条名义轨迹安不安全"和"这笔能量够不够"。但机器人真正执行的是一个**闭环系统**：控制器、执行器饱和、时延、扰动、状态估计误差共同决定了实际轨迹 `x(t)` 与名义轨迹 `x_ref(t)` 之间的偏差。名义计划再漂亮，只要跟踪误差没有被界定，证书保护的就是一条从未真正发生过的轨迹。运动控制恰好提供了缺失的桥：**跟踪误差、带宽、饱和、扰动抑制、运行时安全滤子**。核心创新是把证书对象从"点 / 名义轨迹"升级为"**管道（tube）**"：障碍物按闭环误差管道膨胀，证书要求整条管道避开障碍；再用**控制障碍函数（CBF）**在真实状态上于控制频率强制一个认证不变式，使"计划时认证"与"运行时执行"成为两把必须同时转动的钥匙。

**严谨**：设被控对象 `ẋ = f(x) + g(x)u + d(t)`，`u = τ`，扰动 `d ∈ 𝒟`，`‖d‖ ≤ d_max`；控制器 `u = κ_ctrl(x, x_ref, t)`，误差 `e = x − x_ref`。在计算力矩 + PD 反馈且保留权威裕度 `κ` 时，误差系统满足 ISS 界 `V(e(t)) ≤ e^{−λt}V(e(0)) + (c/λ)d_max`；定义**闭环管道** `E(t;κ) = {e : V(e) ≤ ρ(t;κ)²}`，其半径由跟踪项、状态估计项（复用 v20/v21 的感知误差界）与时延项合成：`ρ = ρ_track + ρ_est + ρ_delay`。证书条件从"`dist(x_ref(t), Obs) ≥ margin_req`"收紧为"`dist(x_ref(t), Obs) ≥ margin_req + ρ(t;κ)`"。运行时，令 `h(x)` 为到认证安全集边界的带符号距离，鲁棒 CBF 条件 `sup_{u∈U}[L_f h + L_g h·u + α(h)] ≥ ‖L_d h‖·d_max` 保证安全集前向不变；若 QP 不可行或实际状态逸出管道，证书**立即失效**并升级 SafeStop。

**反直觉点**：更好的运动控制不是"让安全更容易"，而是**把控制性能直接变现为活动空间**——更小的管道半径意味着更少的障碍膨胀、更大的可行域。安全与活性在这里是同一份控制权威的两个函数。更反直觉的是：把轨迹开到扭矩极限附近，表面上是"更高效"，实际上使 ISS 管道证明的**无饱和前提失效**，误差界会在扰动到来的那一瞬不连续地爆开——最激进的计划不是"更危险"，而是**根本不可认证**。因此权威裕度不是保守，而是让证书的数学前提成立的必要条件。

**灵感 2（动力学 → 能量可行 ≠ 力可行；瞬时力是新的公共货币）**

**直觉**：v22 的 EVC 用积分 `∫P dt` 管总能量、用 `Σ|τᵢq̇ᵢ|` 估功率。但一辆车可以"总油量足够"却在某个坡道上"扭矩不够"；机器人可以总能量充足，却在某个瞬时需要超过 `τ_max` 的力矩，或在高速时撞上扭矩-转速衰减。能量是标量，便宜、可加、但对峰值盲；动力学是逐瞬时、逐关节、逐接触的可行性。二者的关系其实很干净：功率是 `⟨τ, q̇⟩`，v22 管的是它的**时间积分**，本轮管的是它的**瞬时对偶——力 / 力矩本身**。

**严谨**：刚体动力学 `M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_f(q̇) + J_cᵀ(q)F_c = τ`。执行器可行包络 `U_act(SoC, T_act)` 同时受扭矩上限、扭矩-转速曲线与热 / SoC 降额约束。**动力学可行证书（DFC）**：`∀t, ∃F_c ∈ ∏_i FC_i(μ_i⁻)`，使得 `τ(t) ∈ U_act^κ`，其中 `U_act^κ` 是保留裕度 `κ` 后的收缩包络。共享的**权威预算** `B(t) = Σ_i (τ_i/τ_max,i(T_act))² ≤ (1−κ)²`。热动力学 `C_th Ṫ_act = P_loss(τ,q̇) − h(T_act − T_amb)` 把"努力—发热—降额"闭环起来。刹车是安全上最关键的一瞬：认证最小减速度 `a_brake⁻ = min(τ_brake / 等效惯量, μ_g⁻·g)`，停车距离 `d_stop = v²/(2a_brake⁻) + v·τ_delay`，从而把 v22 的 `E_fallback` 从"能量够"升级为"**刹得住**"。

**反直觉点**：能量可行与力可行**互不蕴含**，而且两个反例都很日常。其一是"举着不动"：`q̇ ≈ 0` 使功率近乎为零、总能量很小，但需要持续的大静态力矩，很快逼近扭矩上限并持续发热——能量证书通过，力 / 热证书失败。其二是"长距离慢速巡航"：每瞬时力矩都远低于上限、力可行，但总能量被耗尽——力证书通过，能量证书失败。更麻烦的是**正反馈**：努力越大 → 发热越多 → 扭矩上限越低 → 若强行维持轨迹则更热。也就是说，证书的可行性会消耗掉保证它成立的那份资源，因此热储备必须被写进不变式，而不能当作事后告警。

**灵感 3（交叉：运动控制 × 动力学 → 权威-管道不变式）**

**直觉**：把两层叠在 v22 之上，缺的正是"名义—实际"的桥。我们构造**权威-管道不变式（Authority–Tube Invariant, ATI）**：用动力学给出**瞬时力可行集**，用运动控制给出**闭环误差管道**，把几何安全写在"管道包含"上，再用运行时 CBF-QP 在真实状态上强制不变式。三者通过同一个标量换算：权威裕度 `κ` 越大 → 管道半径 `ρ(κ)` 越小 → 障碍膨胀越少 → 活动空间越大；反过来 `κ` 越大则扰动裕度越小。这是一条**一维、单调**的换算轴，天然避免 v22 离散层级切换造成的振荡：退化是连续的（投影到安全控制），不是跳层。刹车权威则决定 `d_stop`，把"永远可停"变成可认证的不变式。

**严谨**：`ATI(π, κ)` 成立当且仅当 (a) DFC 在 `κ` 下逐瞬时可行；(b) 管道包含 `dist(x_ref(t), Obs) ≥ margin_req + ρ(t;κ)`；(c) 鲁棒 CBF 的 QP 可行性裕度 `δ_qp ≥ δ`；(d) 刹车不变式 `d_stop(x(t), v(t)) ≤ d_clear(x(t), v(t))` 沿运动方向成立。定义 `Exec_v24 = {π ∈ Exec_v22 : ∃κ, ATI(π,κ)}`。注意这里**只增加约束、不开辟新的交互模式**（不像"抓取 / 受控接触"必须用危害单调性替代集合包含），因此 `Exec_v24 ⊆ Exec_v22` 可以诚实地严格成立。运行期若实际状态逸出管道、QP 不可行或模型残差越界，则证书作废并进入 BSAC 认证急停——证书由此成为一个**带 TTL 的运行时谓词**，而不是一枚一次性的计划图章。

**两者如何统一**：统一为 v22 HPC-E 之上的**动态-执行层（Dynamics & Closed-loop Execution Layer, DCEL）**。共享状态扩展为 `ζ_dcel = ζ_pgev ∪ (x_ref, u_ref, e, E_tube, τ, F_c, T_act, κ, B, d_stop, S_cert, δ_qp)`。统一准入门 **HPC-D = HPC-E ∧ DFC ∧ CTTC ∧ RSF ∧ BSAC**，控制层由 **WBP-QP** 把 v22 的 `Fil_hierarchical` 与 F/O/P 编译成优先级 QP：安全硬约束永远在最顶层，低层只能在安全集的零空间里优化。于是"几何 ∧ 规范 ∧ 负信息 ∧ 能量 ∧ 差距"升级为"**几何 ∧ 规范 ∧ 负信息 ∧ 能量 ∧ 差距 ∧ 瞬时力 ∧ 闭环管道 ∧ 运行时可停**"。

## 1. 研究问题（轮次升级版）

- **Q18（闭环管道的有界性与松紧度）**：如何从控制器、模型不确定度、时延与 v20/v21 的感知 / 估计误差界，导出既**可靠**又不过分保守的管道 `E_tube(t;κ)`（饱和感知 ISS、非对称加减速、延迟小增益）？当追踪界过松时，如何用在线残差把"实际管壁"收紧而不破坏可靠性？

- **Q19（瞬时力可行性）**：如何在 1kHz 内认证 `∃F_c ∈ 摩擦锥` 使逆动力学 `τ(t)` 落入 `U_act^κ`？扭矩-转速曲线、关节摩擦、负载质量 / 惯量与热降额的 conformal 上下界如何组合成最坏情形？运动、接触、刹车对同一份权威预算的竞争如何做可行分配？

- **Q20（饱和与证书失效）**：饱和是 ISS 证明的边界——如何在线检测"证明前提已被违反"，并用抗饱和 / 有界超调保证证书失效时仍不越界？最小权威裕度 `κ*` 作为扰动界 `d_max` 与模型误差的函数如何选取？模型残差（尤其未建模接触）如何被结构性识别而非被吸收进拟合？

- **Q21（刹车权威与"永远可停"）**：如何在降额刹车扭矩与未知地面摩擦下定义 `d_stop`，并与 v22 `E_fallback`、v21 GIC 的 STOP 最高优先级嫁接？刹车本身发热导致 `a_brake⁻` 下降，如何用最坏热轨迹证明"停得住"而非"越刹越刹不住"？

- **Q22（运行时滤子与分层 deontic）**：如何把 `Fil_strategic ⊇ Fil_tactical ⊇ Fil_operational` 与 F/O/P 规则编译为**词典序 QP**，使安全硬约束永不被低层覆盖？当 CBF、摩擦锥、义务期限与任务目标互相冲突时，冲突消解的优先级与不可行升级（SafeStop）如何与 v22 的 HDL 对齐？

- **Q23（活性与计算的联合优化）**：如何选择 `κ` 与管壁以最大化活动（平均速度 / 任务吞吐）同时保持 `ATI`？滞回与一维单调退化如何保证不振荡、不在可行边界抖动？规划环（10–50Hz）重算 DFC / 管道、控制环（1kHz）解 QP、控制路径只做 O(1) 查询，如何分工并满足 p99 时延？

## 2. 设计原则（在 P37–P42 基础上新增 P43–P47）

**P43 闭环管道包含律（Closed-Loop Tube Containment）**
任何几何证书必须对**管道**成立而非对名义点成立：`dist(x_ref(t), Obs) ≥ margin_req + ρ_track(t;κ) + ρ_est + ρ_delay`。管道半径必须显式合成跟踪、估计与时延三项，且当控制器、模型、模式或时延估计任一变化时**强制重算**；管道不可计算即不得执行（退到驻停 / 极低速爬行）。`HPC` 的几何裕度在 v24 中一律以"膨胀后的管道"重新解释。

**P44 瞬时力可行律（Instantaneous Force Feasibility）**
`∀t, ∃F_c ∈ ∏ FC_i(μ_i⁻)` 使 `τ(t) = M q̈ + C q̇ + g + τ_f + J_cᵀF_c ∈ U_act^κ`，`κ > 0` 保留反馈与扰动抑制所需权威；权威预算 `B ≤ (1−κ)²`。**能量可行绝不替代力可行**；热轨迹取最坏散热 / 升温上包络，热降额必须在 `τ_max(T_act(t))` 中显式体现。任何使 `τ_max` 下降的事件（发热、SoC 下降、电压跌落）都只能使可行集收缩。

**P45 运行时不变式律（Runtime Invariant & Invalidation）**
控制频率上以鲁棒 CBF-QP 在实际测量状态上强制认证安全集 `S_cert` 前向不变；QP 可行性裕度 `δ_qp ≥ δ` 是证书的一部分。实际状态逸出管道、模型残差越界、时延突增、接触异常等任一事件都使证书**立即失效**（TTL 归零），并按优先级升级到 BSAC 认证急停。证书是运行时谓词，不是一次性计划图章。

**P46 刹车权威律（Braking Authority / Always-Able-to-Stop）**
每个可执行状态都必须满足 `d_stop(x,v) ≤ d_clear(x,v)`，其中 `d_stop` 用降额刹车扭矩、地面摩擦下界与时延计算，`d_clear` 沿当前运动方向到认证安全边界。不得进入任何"无认证停车策略"的状态；`E_fallback` 必须由"能量够"升级为"**扭矩 / 摩擦下刹得住**"，否则能量证书是不健全的。

**P47 分层优先级律（Priority-QP Consistency）**
把 deontic 与能量层级编译为词典序 QP：优先级 0 = CBF 安全 + 扭矩 / 摩擦硬约束 + F 规则；优先级 1 = O 型带期限义务；优先级 2 = 任务与能量目标。安全硬约束不设松弛变量；低层只能在高层可行集的零空间内优化。任何低层越界都被投影回高层边界，故"低层无权打开高层约束"由 QP 结构保证，而非事后检查。

## 3. 与基线的接口（如何退化）

- DFC 失效（模型 / 扭矩估计不可信）⇒ 收缩 `κ` 并放大管道，退回 v22 的"能量可行 + 名义几何"但加更保守膨胀；仍不可信 ⇒ 驻停；
- CTTC 失效（无法给出可靠管道）⇒ 管道置为工作空间量级（等价全域保守）或进入极低速爬行；比 v22 更保守；
- RSF 不可行（CBF-QP 无解 / 裕度不足）⇒ 证书作废 → BSAC 认证急停（不属于正常 `Exec`）；
- BSAC 失效（无认证停车策略）⇒ 禁止进入该状态；若已处于该状态，施加最大制动并告警（可审计升级）；
- WBP-QP 崩溃 ⇒ 退化为"安全约束单独求解"的零任务模式（保证安全、放弃活性）；
- DGC 失效 ⇒ 仲裁退回 CFC++ 行为 ⇒ 等价 v22；
- 全部失效 ⇒ 完全回退 v22 的 HPC-E ⇒ `Exec_v24 ⊆ Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20`。
- **安全继承**：DFC 只收缩瞬时可行集、CTTC 只放大几何膨胀、RSF 只在实际状态上投影、BSAC 只禁入、WBP-QP 只在零空间优化——全部是同一批名义轨迹上的**额外约束**，不开辟任何新交互模式，故集合包含严格成立，且任意失效都向更保守方向退化。

## 4. 预期贡献

1. **闭环管道证书**：首次把安全证书从"名义轨迹"升级为"跟踪 + 估计 + 时延合成的误差管道"，使 v20/v21 的感知误差界与 v22 的控制器真正复合，给出"证书保护的是实际轨迹"的条件；
2. **瞬时力可行证书**：把 v22 的积分能量约束补上其瞬时对偶，给出 `能量可行 ⊥ 力可行` 的两个日常反例，并以 `U_act^κ`、扭矩-转速、热降额与摩擦锥形式化；
3. **热-力正反馈的证书处理**：指出"可行性消耗其自身保证"，把热储备写入不变式，给出最坏热轨迹下的可认证条件；
4. **运行时 CBF 不变式**：把证书变成带 TTL 的运行时谓词，用鲁棒 CBF-QP 在真实状态上强制安全集，并定义失效 → SafeStop 的可审计升级，形成"计划 + 运行时"双钥匙；
5. **刹车权威 / 永远可停**：把 `E_fallback` 从能量上界升级为降额扭矩与摩擦下的停车距离约束，给出"能量证书若无刹车权威则不健全"的证明；
6. **分层 deontic ↔ 优先级 QP**：把 v22 的 `Fil_hierarchical` 与 F/O/P 编译为词典序 QP，使"安全永不被低层覆盖"由结构保证；
7. **封堵 v22 风险**：用一维 `κ`（连续、单调、带滞回）替代离散层级切换，用 QP 可行性裕度替代事后检查，用运行时管道执行减少保守膨胀——同时抑制层级振荡并挽回活性；
8. **严格安全继承**：`Exec_v24 ⊆ Exec_v22` 在不引入新交互模式的前提下成立，闭环。

## 5. 本轮最大风险

**一句话**：管道半径、力可行集与 CBF 不变式全部押在"模型 + 扰动界 + 时延界"之上，而**未建模接触、非线性摩擦与时延漂移**恰恰会在扰动最大、最需要安全滤子的那一瞬让真实管壁远大于认证管壁、让 CBF-QP 恰好不可行——于是证书仍然"有效"，执行却已"越界"，形成一张纸面闭环、物理开环的证书。

```python
# ---------- IP-436 动力学可行证书 ----------
@dataclass
class DynamicsFeasibilityCertificate:
    model: RigidBodyModel            # M, C, g, tau_f, J_c
    mu_lower: dict                   # 逐接触 conformal 摩擦下界 mu_i^-
    kappa: float = 0.20              # 权威裕度，须 >= kappa_star

    def torque_envelope(self, qdot, SoC, T):
        """>=0 的力矩上限向量：扭矩-转速曲线 x 热降额 x SoC 降额，再留 kappa。"""
        curve = self.model.torque_speed_curve(qdot)      # 高速降额
        derate = thermal_derate(T) * soc_derate(SoC)
        return (1.0 - self.kappa) * curve * derate

    def required_torque(self, q, qdot, qddot, F_c):
        return (self.model.M(q) @ qddot
                + self.model.C(q, qdot) @ qdot
                + self.model.g(q)
                + self.model.friction(qdot)
                + self.model.Jc(q).T @ F_c)

    def worst_case_thermal(self, plan, SoC0, T0):
        """沿计划积分热 ODE，取最坏散热/升温上包络 T_worst(t)。"""
        T, out = T0, []
        for s in plan.phases():
            P_loss = copper_loss(s.tau, s.qdot) + iron_loss(s.qdot)
            dT = (P_loss - self.model.h * (T - self.model.T_amb)) / self.model.C_th
            T = T + dT * s.dt
            out.append(T)
        return out

    def certify(self, plan, SoC, T):
        T_worst = self.worst_case_thermal(plan, SoC, T)
        for s, Tw in zip(plan.phases(), T_worst):
            tau_hi = self.torque_envelope(s.qdot, SoC, Tw)
            # 选 F_c ∈ 摩擦锥，使逆动力学力矩尽量落入 [-tau_hi, tau_hi]：
            # 小规模 LP/QP，变量为 F_c 与一个松弛 s>=0，最小化 s
            ok, tau, Fc, margin = solve_contact_force(
                tau_of_Fc=lambda Fc: self.required_torque(
                    s.q, s.qdot, s.qddot, Fc),
                envelope=tau_hi,
                friction_cones=self.mu_lower,
                contacts=s.contacts)
            if not ok or margin <= 0.0:
                return False, "TORQUE_INFEASIBLE", s.t
            if alpha_budget(tau, tau_hi) > 1.0:
                return False, "AUTHORITY_BUDGET_VIOLATION", s.t
        return True, "OK", None


# ---------- IP-437 闭环跟踪管道证书 ----------
class TrackingTubeCertificate:
    def __init__(self, controller, lam, c, d_max, sensor_eps, delay_gain):
        self.ctrl = controller
        self.lam, self.c, self.d_max = lam, c, d_max
        self.sensor_eps = sensor_eps     # 复用 v20/v21 感知/估计误差界
        self.delay_gain = delay_gain     # 时延小增益

    def iss_radius(self, V0, t):
        """饱和感知 ISS 界：无饱和前提由 kappa 保证，见命题 4。"""
        V = math.exp(-self.lam * t) * V0 + (self.c / self.lam) * self.d_max
        return math.sqrt(max(V / self.lam, 0.0))

    def tube_radius(self, plan, t, kappa):
        e0 = plan.initial_error
        V0 = 0.5 * e0 @ self.ctrl.P @ e0
        rho_track = self.iss_radius(V0, t)
        rho_delay = self.delay_gain * plan.speed(t) * plan.delay_est
        # kappa 越大，反馈保留越多，跟踪项越小；用比例因子刻画一维换算
        scale = (1.0 - kappa) / (1.0 - self.ctrl.kappa_ref)
        return scale * rho_track + self.sensor_eps + rho_delay

    def contains(self, plan, obstacle):
        for t in plan.sample_times():
            rho = self.tube_radius(plan, t, plan.kappa)
            if signed_distance(plan.x_ref(t), obstacle) < plan.margin_req + rho:
                return False
        return True


# ---------- IP-438 运行时安全滤子（鲁棒 CBF-QP） ----------
class RuntimeSafetyFilter:
    def __init__(self, alpha, delta=1e-6, d_max=0.0, u_max=None):
        self.alpha, self.delta = alpha, delta
        self.d_max, self.u_max = d_max, u_max

    def solve(self, x, tau_ref, Fc_ref, model, mu_lower, kappa):
        """min ||tau-tau_ref||^2 + w||Fc-Fc_ref||^2
           s.t. L_f h + L_g h tau + alpha(h) >= ||L_d h|| d_max
                tau in U_act^kappa, Fc in friction cones,
                Fil_priority 的更高层约束。"""
        prob = build_qp(
            x=x, model=model, alpha=self.alpha, d_max=self.d_max,
            tau_ref=tau_ref, Fc_ref=Fc_ref, mu_lower=mu_lower, kappa=kappa)
        tau, Fc, margin, status = prob.solve(warm_start=True)
        if status != OPTIMAL or margin < self.delta:
            return None, "QP_INFEASIBLE"
        return (tau, Fc), "OK"

    def step(self, x, *args, **kw):
        out, status = self.solve(x, *args, **kw)
        if out is None:
            return self.escalate_safestop(status)   # 证书作废 → BSAC
        return out


# ---------- IP-439 刹车与急停权威证书 ----------
class BrakingAuthorityCertificate:
    def __init__(self, model, mu_ground_lower, kappa, delay):
        self.model = model
        self.mu_g = mu_ground_lower      # conformal 地面摩擦下界
        self.kappa, self.delay = kappa, delay

    def min_brake_decel(self, SoC, T):
        tau_b = (1.0 - self.kappa) * self.model.torque_speed_curve(0.0) \
                * thermal_derate(T) * soc_derate(SoC)
        a_torque = tau_b / self.model.effective_inertia_along_motion()
        a_friction = self.mu_g * 9.81
        return min(a_torque, a_friction)

    def stopping_distance(self, x, v, SoC, T):
        a = self.min_brake_decel(SoC, T)
        return v * v / (2.0 * max(a, 1e-6)) + v * self.delay

    def certify(self, plan, SoC, T):
        T_worst = DynamicsFeasibilityCertificate.worst_case_thermal(
            plan, SoC, T)  # 刹车也在发热
        for s, Tw in zip(plan.phases(), T_worst):
            if self.stopping_distance(s.x, s.v, SoC, Tw) > \
                    clearance_along_motion(s.x, s.v, plan.obstacles):
                return False, "NO_CERTIFIED_STOP"
        return True, "OK"


# ---------- IP-440 全身优先级 QP（分层 deontic 的控制落地） ----------
class WholeBodyPriorityQP:
    # 优先级：[0] CBF 安全 + 扭矩/摩擦 + F 规则（硬，无松弛）
    #        [1] O 型带期限义务（高优先级软任务）
    #        [2] 任务 + 能量 J_E（零空间内优化）
    def solve(self, x, tasks, model, kappa, dcl):
        hard = self.hard_constraints(x, model, kappa, dcl)   # CBF, U_act, FC, F
        if not is_feasible(hard):
            return None, "HARD_INFEASIBLE"                    # → SafeStop
        u0 = solve_qp(hard, tasks["task"])                    # 任务层
        N0 = null_space(hard.jacobian_at(u0))
        u1 = u0 + N0 @ solve_qp(project(hard, N0), tasks["obligation"])
        u2 = u1 + null_space(...) @ solve_qp(..., tasks["energy"])
        return u2, "OK"


# ---------- IP-441 动力学接地共识 ----------
class DynamicsGroundedConsensus(CFCPlusPlusHierarchical):
    RESIDUAL_TOL = 0.05      # 归一化动力学残差容忍

    def consensus_round(self, timeout=5.0):
        out = super().consensus_round(timeout)
        for key, verdict in out.items():
            if verdict == "SAFE" and not self.dynamic_consistent(self.votes[key]):
                out[key] = "CI"          # 动力学不一致 → 不允许判 SAFE
        return out

    def dynamic_consistent(self, votes):
        """各模态估计的加速度/力矩/接触力必须落在同一动力学可行域，
        跨模态残差 <= 界；单模态相关故障无法伪造一致性。"""
        est = [v.dyn_estimate for v in votes.values()]
        spread = max_pairwise_residual(est)
        return spread <= self.RESIDUAL_TOL and all_in_actuator_envelope(est)
```

## 2. 关键命题与证明梗概

**命题 1（名义计划证书不充分）**：存在系统与轨迹，使计划时 `HPC-E`（几何 ∧ 能量 ∧ 规范）全部通过，但实际闭环轨迹在有限扰动下与障碍相交。

*证明梗概*：令控制器存在非零稳态跟踪误差 `e_ss = c·d/λ > 0`（如未建模恒定扰动、执行器死区或时延）。名义计划满足 `dist(x_ref, Obs) = margin_req > 0`，故计划检查通过；但实际 `x = x_ref + e_ss`，当 `‖e_ss‖ > margin_req` 时与实际障碍相交。v22 的证书只量化了 `x_ref`，未量化 `e`。CTTC 的 `E_tube` 正是补上这一量化缺口的最小对象。∎

**命题 2（能量可行与力可行互不蕴含）**：存在 (a) 能量可行但力 / 热不可行的轨迹；(b) 力可行但能量不可行的轨迹。

*证明梗概*：(a) 静态保持重载：`q̇≈0 ⇒ P=⟨τ,q̇⟩≈0`，故 `∫P dt` 很小、EVC 通过；但 `τ = g(q)` 持续接近 `τ_max`，且持续发热使 `τ_max(T)` 下降，最终 `τ ∉ U_act`。这是"举着不动烧电机"。(b) 长距离 / 高速巡航：逐瞬时 `τ ≪ τ_max`、摩擦锥可行，但 `E_res` 被耗尽。故两个谓词各自独立；`HPC-E ∧ DFC` 不能互相替代。∎

**命题 3（管道包含 + 鲁棒 CBF ⇒ 运行期安全）**：若初态 `x(0) ∈ S_cert`、管道 `E_tube` 以概率 ≥1−α 包含真实误差、且鲁棒 CBF-QP 满足 `L_f h + L_g h u + α(h) ≥ ‖L_d h‖ d_max`、`h ≥ 0` 定义 `S_cert` 且 `S_cert` 与"膨胀后的障碍"不交，则实际轨迹永不相交障碍。故 `ATI` 成立且运行期 QP 成功 ⇒ 安全；且因 v24 只增加约束，`Exec_v24 ⊆ Exec_v22`。

*证明梗概*：CBF 条件对 `∀‖d‖≤d_max` 成立 ⇒ `h(x(t))` 不递减到 0 以下（前向不变性）；`S_cert` 按 `margin_req + ρ` 膨胀后不含障碍 ⇒ 实际状态不进入障碍。管道包含由 ISS 与估计 / 时延界给出，成立概率由各分量界复合（Bonferroni / 并集界）≥1−α。若某一分量界失效，则前提破坏，`step()` 的 `QP_INFEASIBLE` 或残差检测会作废证书——这正是"失效安全"而非"失效即碰撞"。∎

**命题 4（权威裕度使 ISS 证明成立，热正反馈需重认证）**：若 `∀t, τ_ref(t) ≤ (1−κ)τ_max(T_act(t))` 且 `T_act(t) ≤ T_worst(t)`，则跟踪过程中不发生饱和，ISS 管道界有效。∃ 临界温度 `T_crit`，使 `(1−κ)τ_max(T_crit) = max_t τ_ref(t)`；只要 `T_worst(t) < T_crit` 沿计划成立，证书成立；越过前必须重规划。

*证明梗概*：无饱和时闭环误差系统为线性（含有界模型误差与扰动），ISS 界成立。热 ODE 单调升温使 `τ_max` 单调下降，故存在 `T_crit`；`T_worst` 是保守上包络，若其低于 `T_crit` 则全程无饱和。注意 `P_loss` 随 `|τ|` 增长，故"更努力"会加速逼近 `T_crit`——可行性消耗其自身保证，必须把 `T_crit` 写进不变式而非事后监测。∎ **风险**：热模型参数（`C_th, h`）误差直接移动 `T_crit`。

**命题 5（无刹车权威的能量证书不健全）**：存在状态 `(x,v)`，使 `E_res ≥ E_fallback`（能量充足），但认证最小减速度 `a_brake⁻ < v²/(2·d_clear)`，任何控制器都无法在净空内停住。

*证明梗概*：避免碰撞必须把 `v` 在距离 `d_clear` 内降到 0，所需减速度 `a_req = v²/(2 d_clear)`（含时延需更大）。若 `a_brake⁻ < a_req`，则物理上不可实现，与剩余能量多少无关。`E_fallback` 只约束可消耗能量，不约束可产生减速度，故不足以担保停车。BSAC 补上这一维度。∎

**命题 6（词典序 QP 实现分层 deontic）**：若安全 / F 规则位于优先级 0 且不设松弛，则任意低层解 `u` 都满足高层约束；故 `Fil_priority` 实现 `Fil_strategic ⊇ Fil_tactical ⊇ Fil_operational`，低层无法打开高层约束。

*证明梗概*：词典序 QP 在每一层于上一层可行集内优化；优先级 0 的可行集对低层是硬边界，低层只能在其零空间（线性化意义下）内选择。若低层目标不可达，投影到零空间后仍满足高层约束，活性仅在低层损失。∎ **风险**：非线性动力学下"零空间"仅在局部线性化成立，需 1kHz 重线性化或使用分层 CBF 的嵌套不变集。

**命题 7（DGC 拒绝相关伪造共识）**：若某子集的模态存在共同偏差、使它们的 SAFE 票相关，但各自的动力学估计残差超界，则 `DGC` 将其改判为 `CI`，不构成 SAFE 共识。

*证明梗概*：`CFC++` 的计数 / 模态 / 层级三条件只约束"票的分布"，不约束"票背后的物理量是否互相一致"。DGC 增加 `max_pairwise_residual(dyn_estimate) ≤ tol` 与执行器包络检查，使"同一错误模型驱动的多模态一致"在结构上被识破。∎ **风险**：若错误是**跨模态共同**的（如同一质量 / 摩擦参数错误），残差可能仍小——见本轮最大风险。

## 3. 实验设计（仿真优先，真机小规模验证）

**平台与任务**：差速 / 全向移动底座 + 6-DoF 机械臂（Isaac Sim / MuJoCo；真机取移动操作平台），可选手臂配重与低摩擦地垫。任务：(T1) 人体近距离横穿 + 强制急停；(T2) 共享工作空间内机械臂靠近人取放；(T3) 斜坡 / 低摩擦地面高速通过；(T4) 载荷突变（端起 / 放下重物）；(T5) 注入 50–300ms 传感器 / 执行时延与电流限幅。

**基线**：(B1) v22（EVC + 名义几何，无管道）；(B2) v22 + 固定保守膨胀（无动力学）；(B3) v24 去 DFC（只有管道 + CBF）；(B4) v24 去 RSF（只在计划时认证）；(B5) v24 但 `κ≈0`（贴着扭矩上限跑，验证饱和导致证书失效）；(B6) v24 完整。

**指标**：管道经验覆盖率（实际状态落入 `E_tube` 的频率，目标 ≥1−α）；碰撞 / 人身接触率；近失事件率；饱和事件率；`d_stop` 预测误差；QP 不可行率与安全升级次数；活性（平均速度 / 任务吞吐）；计算（QP p99、总时延、DFC/CTTC 重算周期）。

**消融**：(A1) 去掉 `ρ_est`（忽略估计误差）；(A2) 去掉时延项；(A3) 去掉热降额（用常温 `τ_max`）；(A4) 去掉 BSAC（只查能量）；(A5) 用一维离散层切换替代连续 `κ`。

**单调性 / 覆盖率检查**：在 `κ` 网格上测 `ρ(κ)` 与经验管道覆盖率、`λ*` 与活性，验证"`κ↑ ⇒ ρ↓ ⇒ 活性↑` 且覆盖率不跌破 1−α"；若出现非单调，记录反例并改用二维（速度 × 加速度）安全前沿。

**失败分类与反应**：

| 事件 | 检测证据 | 证书谓词 | 反应 |
|---|---|---|---|
| 扭矩逼近上限 / 饱和 | `τ` 对比 `U_act^κ`，跟踪误差增长 | `DFC` 裕度 ≤0 | 提高 `κ`、降速重规划 |
| 管道被击穿 | 实际状态超出 `E_tube` 预测 | `CTTC` 运行残差 | 作废证书、放大管道、升级 BSAC |
| CBF-QP 不可行 | 求解器状态 / `δ_qp<δ` | `RSF.step` | 认证急停（SafeStop 升级） |
| 刹不住 | `d_stop > d_clear` | `BSAC` false | 禁入该状态；已进入则最大制动 + 告警 |
| 热降额越过 `T_crit` | `T_act` 上升、`τ_max` 下降 | 命题 4 | 降努力、重认证、冷却 |
| 未建模接触 | 触觉 / 电流尖峰 / 模型残差 | 动力学残差检验 | 作废 DFC，切换接触感知模式或停机 |
| 时延突增 | 时间戳抖动 | `ρ_delay` 项 | 膨胀管道、降速 |

**预期结果**：(B1) 在时延 / 扰动下复现"计划有证、执行碰撞"；(B3) 在斜坡与载荷突变处出现力 / 热不可行；(B4) 在人体突然出现时暴露"运行时无滤子"的失效；(B5) 在扰动峰值处管道爆开、QP 频繁不可行；(B6) 以适度活性代价显著降低碰撞与近失，且管道覆盖率维持在 1−α；(A1)/(A2)/(A3) 分别验证估计、时延、热三项必要性。

## 4. 复杂度与实时性

- **DFC**：变量为接触力 `F_c`（接触数 `k≤4`）与小松弛，约束规模 `O(n+k)`；小规模 LP/QP，毫秒级，可缓存热启动。规划环 10–50Hz 重算，控制环只查包络。
- **CTTC**：管壁为矩阵指数与范数，`O(n²)`；按 10–50Hz 采样重算，控制环用最近管壁的保守上界做 O(1) 查询。
- **RSF / WBP-QP**：变量 `n+k`（典型 `8+4`），OSQP / 主动集在 1kHz 下亚毫秒到数毫秒；分层 QP 用嵌套零空间投影，层数 3，热启动 + 提前终止。
- **BSAC**：每规划周期沿计划采样 `d_stop`，`O(N_samples)`；热上包络在 1Hz 慢环更新。
- **DGC**：只在共识轮触发，`O(N·M)`，非控制路径。
- **控制路径**只做 O(1)：查 `κ`、`E_tube` 上界、`CP`/义务状态、最近 QP 解；重计算全部在规划环 / 慢环。

## 5. 本轮最大风险

**一句话**：管道半径、力可行集与 CBF 不变式全部押在"模型 + 扰动界 + 时延界"之上，而未建模接触、非线性摩擦与时延漂移恰恰会在扰动最大、最需要安全滤子的那一瞬让真实管壁远大于认证管壁、让 CBF-QP 恰好不可行——于是证书仍然"有效"，执行却已"越界"，形成一张纸面闭环、物理开环的证书。
