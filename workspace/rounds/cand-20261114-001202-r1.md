# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「数据集构建」×「跨任务泛化」）

> R69 把不确定性一分为二，并让系统学会「问」：aleatoric 收紧，epistemic 用流匹配多模态策略 + 主动多模态交互去消解。但它默认了三件事：**不确定性是部署时的问题、数据是给定的、任务是单一的**。本轮把这三条同时打穿：
> - R69 的 `U_epi = H_mode·g(Δ_min)` 只度量「模态之间有多不一致」，却不知道**这个状态离能裁决它的数据有多远**。一个自信的幻觉模态，与一个真正没见过的新模态，可以给出完全相同的模态熵。**不确定性有「数据地址」，而 R69 从未去看那个地址。**
> - 数据是昂贵的、任务族是共享结构的。任务 A 的一条示范可能消解任务 B 的模态歧义；也可能因为只是表面相关而**主动毒害** B（负迁移 / shortcut）。所以任务之间需要一张**证据汇率表**，而且必须由 held-out 元任务验证，不能由模型自说自话。
> - 一旦把部署日志直接拿来训练，R68/R69 辛苦建立的「认证闭环」会被悄悄重开：策略在飞行中变了，证书却还是旧的。**数据层必须是离线、版本化、可回滚、可审计的；在线只允许「标记候选」，不允许「学习写入」。**

> 核心命题：**把 epistemic 不确定性从「部署时的标量」升级为「任务族上的覆盖图」；用主动数据集构建去修补覆盖洞，用经元任务验证的跨任务迁移门控决定「一条证据值不值得换到另一个任务」；并让合成数据、投毒、模型坍缩、许可与隐私都成为一等的安全约束。** 命名 **DATUM-RAS**（Data-Acquisition-aware, Task-family Uncertainty-Minimizing Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我该从什么里学、学到的东西能不能迁移到别的任务**」——不确定性不只是一脚刹车、一句提问，也可以是明天数据集里的一条注记。

## 0. 直觉与动机

**灵感 1（数据集构建 → epistemic 不确定性有「数据地址」）**
直觉：R69 用模态熵度量歧义，这相当于只问「我有几个候选」，却没问「我凭什么在它们之间选」。若策略在训练分布内，模态分布是可信的；若状态落在分布的支撑之外，模态熵再低也可能只是**过度自信的错觉**。因此 `U_epi` 必须带一个**支撑坐标**：不仅「模态分歧多大」，还要「离能裁决这个分歧的锚点数据多远」。这个坐标只能靠数据集构建去移动。正确的一等对象不是标量，而是一张**覆盖图**：哪些任务/状态区域有真实认证锚点（real anchors），哪些只是插值或外推。R69 的 MCG 只校准了权重的可靠性，没有回答「这些权重在该区域是否被数据支持」。

**灵感 2（跨任务泛化 → 证据有「汇率」，且汇率可负）**
直觉：数据采集极贵，而任务族共享结构。任务 A 的一条示范，若共享因子 ψ 相同，可以低成本消解任务 B 的歧义；若只是表面相关（同一桌面、同一光照、同一条捷径特征），它会把 B 的错误当经验带过去——**负迁移**。所以跨任务不是「越多越好」，而是「按汇率换」。汇率必须由 **held-out 元任务** 验证（训练任务之外再留一层任务），而不能用模型自己报告的互信息当账本：那等于让借款人自己定利率。

**灵感 3（数据集构建是安全子系统，不是后勤）**
直觉：R69 自陈的最大风险是「流模型幻觉出不存在的模态」。这条风险在数据层有一个更根本的版本：**在模型自己生成的数据上继续训练，会让分布收缩、罕见模态被抹掉、模型越来越确信自己的偏见**（模型坍缩 / 回声室）。再加上标注投毒、对抗性任务变体、以及采集过程中的许可与隐私问题，数据集构建必须和控制器一样被风险治理：**来源可溯、合成证据打折、真实锚点保底、金丝雀任务常驻、异常可回滚**。把数据层当「后勤」，就是把整条认证链的地基交给一个没人审计的黑箱。

**灵感 4（闭环不能变跳跃 → 在线只标记，离线才学习）**
直觉：如果部署时看到一条高价值交互日志就立刻微调策略，那么 R68 的「提交/换装不变式」和 R69 的「证书」全部失效——因为**被认证的对象在认证之后变了**。所以本轮把数据层严格放在控制环之外：在线只做**不可变的候选标记**（append-only），离线在 epoch 边界做**版本化重训 + 证书重签发 + 原子换装**。这样 R69 仍是一个**严格边界情形**，而不是被数据层悄悄替换。

**灵感 5（理论形状：从 VoI 到 VoD，同一套子模机器）**
直觉：R69 选的是「信息动作」以最大化 value-of-information；R70 选的是「数据单元」（任务变体、场景、标签、反事实）以最大化跨任务族的 value-of-data。VoI 是本轮的一个特例：数据单元取「在任务 τ 上再问一次」。两者都可写成**后验方差/熵的下降**；当目标函数单调子模时，贪心就有 `1−1/e` 近似保证。差别只在于多了一个**迁移算子**：A 的数据如何改变 B 的后验。

**灵感 6（理论姿态：旧层是新层的边界，而不是被替代）**
直觉：若任务族只有一个任务、预算为零、合成数据禁用、迁移门关闭，那么 DATUM 必须逐指令退回 R69：`U_epi` 仍只由部署交互更新，`λ` 仍按 FLUID 两级退避。新层不得削弱旧层的安全保证——**加一层数据治理，不能顺手把 R69 已经证明过的东西弄丢**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DATUM-RAS 总览）** DATUM-RAS = (TFM, SOS, VoD, XTG, DCS, DPG, CPG, RAS-WM‡)。四不变式：
(i) **实时零学习写操作**（继承 R68 定义 276-i）：在线只可向只读的 `AcquisitionBuf` 追加候选标记，禁止任何参数写入；
(ii) **认证单调性**：控制路径上的策略权重必须属于某个已签发证书 `J_DATUM` 的版本；任何重训都必须在 epoch 边界原子换装并重签发证书，绝不混用版本；
(iii) **证据来源律**：每条训练样本带来源标签与 real/synthetic 类别，合成证据按折扣 `γ≤1` 计入，认证方差存在由真实锚点决定的下限；
(iv) **任务族可辨识性与治理**：任务身份不得由受保护属性推断；迁移决策必须经 held-out 元任务验证，禁止用不可迁移标签充当共享因子。

**定义 311（任务族与部署风险）** 任务族 𝒯 = {τ}，每个 τ = (ψ, ω_τ)，共享因子 ψ ∈ Ψ、任务特化 ω_τ ∈ Ω；任务分布 ν。策略 φ 的部署风险 `R̄(φ) = E_{τ~ν}[R_τ(φ)]`，其中 `R_τ(φ)=E_{ξ~p_τ}[ℓ(φ,ξ)]`。任务度量 `d_𝒯`（由 ψ 与 ω 的可迁移部分定义，而非原始像素距离）。

**定义 312（支撑/离支撑打分 SOS）** 对 (o,τ) 定义支撑分 `s(o,τ)`（密度比或 conformal 分），阈值 `τ_s`；离支撑集 `O_ε = {(o,τ): s>τ_s}`。**真实锚点集** `A ⊂ D_real` 为通过认证的真实样本；只有 A 能认证覆盖。

**定义 313（覆盖证书）** 若对每个 τ 存在已采集 τ' 使 `d_𝒯(τ,τ') ≤ ε`、且观测支撑距离 `≤ δ`，则称任务族被 `(ε,δ)`-覆盖。据 GP/自归一化界，以概率 `≥1−δ_c`：
`R̄(φ) ≤ R̂(φ) + L_τ·ε + L_o·δ + β(δ_c)·σ_cert(D)`，
其中 `L_τ, L_o` 为风险对任务/观测度量的 Lipschitz 常数，`σ_cert` 为认证后验标准差（定义 317）。⇒ **覆盖半径与认证方差是同一个风险上界的两个加法项**，缺一不可。

**定义 314（跨任务迁移算子与迁移门 XTG）** 证据 e 在任务 A 上对任务 B 的信息增益：
`G_{A→B}(e) = I(f_B; y_A | D) = ½·log( σ²_B / σ²_{B|A} )`（联合高斯下的精确式）。
**迁移门** 只在 held-out 元任务上实测的增益下界 `LCB[G_{A→B}^{heldout}] > 0` 时打开；门关 ⇒ 该证据对 B 无效（防负迁移）。模型自报的协方差只作提议，不作裁决。

**定义 315（数据价值 VoD）** 数据单元 d（任务变体 / 场景 / 标签 / 反事实）的价值：
`VoD(d|D,B) = E_{τ~ν}[ U_epi(τ;D) − U_epi(τ;D∪{d}) ] − c(d)`，
其中 `U_epi` 取 R69 的模态歧义度量或（更严格）后验方差；跨任务部分由 XTG 折算。采集包 `ΔD* = argmax_{|ΔD|≤B} [Σ_{d∈ΔD} VoD(d) + λ_cov·(ε(D)−ε(D∪ΔD))]`。

**定义 316（采集即 D-最优设计）** 在 GP 代理下 `U_epi(τ;D)=σ²_τ(D)`，采集目标为最大化任务族上的后验精度对数行列式 `logdet Σ_post^{-1}`；当目标单调子模时，贪心达到 `(1−1/e)` 近似（A96）。

**定义 317（合成证据折扣与认证下限）** 合成样本带有效权重 `γ∈[0,1]` 与偏差 nugget `η>0`；认证后验精度分解为 `Λ_cert = Λ_real + γ·Λ_syn`，故 `σ²_cert ≥ (Λ_real + ηI)^{-1} ⪰` 真实锚点决定的下限。**合成数据不能给自己签发认证**——它只能提高点估计，不能压低认证方差下限。

**定义 318（数据集构建合成器 DCS）** 三类构造：(a) **任务变体最大化覆盖**（对任务族做 maximin / 空间填充，填最大的覆盖洞）；(b) **反事实增强**（同一场景改变非因果的捷径因素，如背景/光照/纹理，用于打断 shortcut）；(c) **场景重采样**（对离支撑质量高的区域做定向采集）。每类都带来源标签与模拟器信任权重。

**定义 319（回放/抗坍缩守卫 RCG）** 真实锚点比例 `ρ_real ≥ ρ_min`；维护 replay buffer 与 **金丝雀任务集**（held-out 任务，用于测迁移是否退化）；记录生成深度与自训练轮数；若 `ρ_real<ρ_min` 或金丝雀失败 ⇒ 回滚到上一个已认证数据集版本。

**定义 320（来源图与投毒防御 DPG）** 每条样本记录 provenance DAG（采集者/时间/任务/传感器/标注链）；用影响函数做异常裁剪与稳健聚合；投毒预算 `δ_poison` 与 held-out 金丝雀给出错误采纳上界；可疑簇隔离而非直接删除（保留审计证据）。

**定义 321（跨任务捷径审计 CSP）** 检验候选共享特征在**环境 held-out** 下的预测力；若某特征在训练任务内强、跨任务弱却被当作 ψ 使用，则标记为 shortcut；以反事实增强与不变性正则（IRM 类）缓解。

**定义 322（数据治理 GOV）** 数据卡片/许可链、受保护属性不参与任务身份、保留与撤回机制、provenance hash；治理检查不过 ⇒ 该数据单元不得进入认证集。

**定义 323（陈旧证书与原子换装）** 三元组 `(φ_v, D_v, J_v)`；控制路径与学习路径双缓冲，只在 epoch 边界做 `atomic_swap`，换装前必须 `Valid(J_{v+1})`，换装后旧证书立即作废。继承 R68 定理 15 的「提交/换装不变式」。

**定义 324（漂移下的再采集触发器 ACQ-Trig）** 监控认证上界与离支撑质量：当 `certified_UB > τ_risk` 或 `P(O_ε) > τ_U` 或金丝雀退化时，触发离线再采集；触发本身不改在线策略。

**定义 325（证书 J_DATUM）** `J_DATUM = (J_FLUID, task_family_ver, coverage_ε, certified_risk_ub, transfer_gate_states, provenance_hash, synthetic_discount, canary_pass, dataset_ver, policy_ver, datum_ver)`。
Valid ⇔ Valid(J_FLUID) ∧ 覆盖证书成立 ∧ 金丝雀通过 ∧ 零写不变式满足 ∧ 治理检查通过。

**定义 326（对 R69 的严格包含）** 当任务族为单元素、采集预算 `B=0`、`γ=0`（禁合成）、迁移门关闭时，DATUM 的决策序列与 FLUID 逐指令相同；数据层只读不写。故 R69 是 DATUM 在「无数据可采、无任务可迁」边界上的退化。

```python
# IP-264 TFM：任务族模型（共享因子 ψ 与任务特化 ω_τ；轻量 GP / 低秩贝叶斯头）
class TaskFamilyModel:
    def __init__(self, phi, kernel_shared, kernel_task):
        self.phi = phi                       # 复用 R69 的 MTM/FMP 表示，不重复训练
        self.k_psi, self.k_om = kernel_shared, kernel_task

    def posterior(self, D):
        # 返回每个任务的均值/方差以及跨任务协方差块 K_{A,B}
        return gp_posterior(self.k_psi, self.k_om, D)

# IP-265 SOS：支撑/离支撑打分（密度比 + conformal）
def support_score(o, tau, D_real):
    return conformal_score(o, tau, D_real)     # 越大越离支撑

# IP-266 VoD：跨任务数据价值（含覆盖项）
def value_of_data(d, D, fam, nu, xtg, budget):
    gain = 0.0
    for tau, w in nu.items():
        if not xtg.allow(d.task, tau):         # 迁移门关 ⇒ 不折算
            continue
        gain += w * (post_var(fam, tau, D) - post_var(fam, tau, D | {d}))
    return gain - cost(d)

# IP-267 XTG：迁移门（held-out 元任务验证，非模型自报）
def transfer_allowed(src, dst, fam, meta_tasks):
    lcb = lower_confidence_bound(
        empirical_gain(fam, src, dst, meta_tasks))   # 只在 held-out 元任务上测
    return lcb > 0.0

# IP-268 DCS：数据集构建（覆盖洞 + 反事实 + 定向重采样），带来源标签
def construct_dataset(D, holes, shortcuts, budget):
    variants = maximin_task_variants(holes, budget.frac(0.4))   # 填覆盖洞
    counterf = counterfactual_augment(shortcuts, budget.frac(0.4))
    resample = resample_off_support(D, budget.frac(0.2))
    return tag_provenance(variants + counterf + resample)

# IP-274 离线轮：采集→构造→重训→认证→原子换装（全程离线）
def DATUM_offline_round(M, fam, D, budget):
    holes     = coverage_holes(fam, D, eps_target)
    shortcuts = audit_shortcuts(M.phi, fam)
    cand      = construct_dataset(D, holes, shortcuts, budget)
    chosen    = greedy_submodular(cand, lambda d: value_of_data(
                    d, D, fam, M.nu, M.xtg, budget), budget)      # (1-1/e)
    D_new     = D + chosen
    if real_anchor_ratio(D_new) < RHO_MIN or not canary_pass(fam, D_new):
        return D, M.j_v                                       # RCG：回滚，不换装
    phi_new   = retrain_offline(M.phi, D_new)
    j_new     = certify(phi_new, D_new, fam)                  # 覆盖+风险上界+迁移门
    if not Valid(j_new):
        return D, M.j_v
    M.atomic_swap(phi_new, D_new, j_new)                      # epoch 边界，双缓冲
    return D_new, j_new

# IP-274 在线钩子：只追加候选标记，绝不学习写入
def DATUM_online_hook(M, o, tau, u_epi, support):
    if support > TAU_S or u_epi > TAU_EPI:                    # 高信息 or 离支撑
        M.acq_buf.append_immutable({
            'o': o, 'tau': tau, 'u_epi': u_epi,
            'support': support, 't': now(), 'hash': content_hash(o)})
    # 注意：此处无 grad、无 optimizer、无参数更新
    return M.fluid_ras_round(o)                                # 在线仍是 R69 闭环
```

## 3. 推导

**引理 19（跨任务信息增益的闭式与正迁移条件）** 设 `(f_A,f_B)` 联合高斯，先验方差 `σ²_A,σ²_B`，跨协方差 `k_{AB}`，观测噪声 `σ²_n`。观测 A 后 B 的后验方差 `σ²_{B|A}=σ²_B − k_{AB}²/(σ²_A+σ²_n)`，故
`G_{A→B}=½log(1 + k_{AB}²/((σ²_A+σ²_n)(σ²_B−k_{AB}²/(σ²_A+σ²_n)))) ≥ 0`。
系 1：**只要 `k_{AB}≠0`，模型就认为有正增益；但真实风险是否下降，取决于 `k_{AB}` 是否被验证过**——这正是迁移门要 held-out 元任务的原因。系 2：`k_{AB}` 若来自捷径特征，held-out 上会塌到 0 甚至负，门自动关闭。

**引理 20（合成证据不能自我认证）** 认证后验精度 `Λ_cert = Λ_real + γΛ_syn`（`γ≤1`），故 `σ²_cert = (Λ_real+γΛ_syn)^{-1} ⪰ (Λ_real+Λ_syn)^{-1}`；当 `Λ_real→0`（无真实锚点）时 `σ²_cert` 不小于 `(γΛ_syn+ηI)^{-1}` 的下限，**不随合成样本数无界下降**。⇒ 定义 317 的认证下限成立；这直接封堵「在自生成数据上反复训练 → 越来越自信 → 幻觉模态被当成真模态」的回声室。

**引理 21（覆盖到风险的界）** 若任务族被 `(ε,δ)`-覆盖且 `R_τ` 对 `d_𝒯` 与观测度量分别 `L_τ,L_o`-Lipschitz，则对任意 τ，取最近邻 τ' 有
`R_τ(φ) ≤ R_{τ'}(φ) + L_τ·d_𝒯(τ,τ') + L_o·δ ≤ R̂ + L_τ ε + L_o δ + βσ_cert(τ')`。
⇒ 覆盖半径 `ε` 与认证方差 `σ_cert` 是**可分别采购**的两种风险削减：前者买「邻近任务」，后者买「同类样本」。

**引理 22（VoD 的贪心近似）** 若 `U_epi(τ;·)` 为后验方差、采集目标为单调子模（A96：log-det 型目标在 PSD 核下子模），则贪心采集包满足 `VoD(ΔD_greedy) ≥ (1−1/e)·VoD(ΔD*)`。系：VoD 与 R69 的 VoI 共享同一套子模机器；R69 只是 `d=(τ 上再问一次)` 的特例。

**定理 18（跨任务认证风险上界）** 在 A96–A99（任务族 GP 先验、风险 Lipschitz、合成折扣、held-out 迁移门）下，以概率 `≥1−δ_c`，已认证策略 φ 的部署风险满足定义 313 的上界；且该上界对**每个** τ（而非仅平均）成立。数据采集通过同时压低 `ε`、`δ`、`σ_cert` 单调收紧上界。

**定理 19（DATUM 严格包含 R69）** 在定义 326 的边界（单任务、零预算、`γ=0`、迁移门关）下，DATUM 的数据层不发生任何写操作，在线决策与 FLUID 逐指令相同；`U_epi` 仍只由部署交互更新，`λ` 仍按 FLUID 两级退避。故安全侧不弱于 R69，效率侧只在有数据预算且门开时获益。

**定理 20（数据/策略换装无突变）** 由于在线零写 + 双缓冲 + epoch 边界 `atomic_swap` + 换装前 `Valid(J_{v+1})`，控制路径在任意时刻只看到一个已认证版本；换装瞬间的指令连续性由 R68 定理 15 的提交/换装不变式保证，迁移门与覆盖证书只影响**下一次**换装，不影响当前控制包络 ⇒ 无突变、无证书失效窗口。

## 6. 本轮最大风险

**一句话**：DATUM-RAS 的整套认证都建立在「任务族与任务度量 `d_𝒯` 被正确指定」这一前提上——**若部署任务落在建模的任务族之外，或某个捷径特征伪装成共享因子 ψ，覆盖证书会为一个从未被表示的分布盖上「已泛化」的章，而主动数据构建会以比纯部署快得多的速度把这个错误放大、固化进下一版策略**——证书于是从「安全许可」变成了「错误分布的通行证」。

**次级风险与缓解**：
1. **负迁移**（A 的证据害 B）→ XTG 迁移门只在 held-out 元任务上以增益下界裁决 + 引理 19；
2. **合成数据回声室/模型坍缩** → 合成折扣 `γ` + 认证方差下限（引理 20）+ 真实锚点比例 `ρ_min` + 金丝雀任务 + RCG 回滚；
3. **数据投毒** → 来源 DAG + 影响函数裁剪 + 稳健聚合 + 投毒预算；
4. **在线偷偷学习导致证书陈旧** → 在线只追加标记 + epoch 边界原子换装 + 定理 20；
5. **覆盖证书过度乐观**（任务族外推）→ 离支撑打分 + 覆盖证书显式含 `L_τ ε` 项 + 漂移触发器；**绝不把「平均泛化」当作「逐任务泛化」**。

## 4. 推导

**引理 19（跨任务信息增益闭式）** `σ²_{B|A}=σ²_B−k_{AB}²/(σ²_A+σ²_n)`，
`G_{A→B}=½log(σ²_B/σ²_{B|A})≥0`；`k_{AB}≠0` 只是模型认为可迁移，**真实正迁移必须 held-out 验证**；捷径特征的 `k_{AB}` 在 held-out 上会塌到 0，门自动关闭。

**引理 20（合成不能自我认证）** `Λ_cert=Λ_real+γΛ_syn`，`γ≤1` ⇒ `σ²_cert ⪰ (Λ_real+Λ_syn)^{-1}`；`Λ_real→0` 时不随合成样本数无界下降（偏差 nugget 保底）。封堵「自训练→更自信→幻觉模态真化」的回声室。

**引理 21（覆盖到风险）** `(ε,δ)`-覆盖 + Lipschitz ⇒ `R_τ ≤ R̂ + L_τ ε + L_o δ + βσ_cert`。覆盖与认证方差是可分别采购的两种风险削减。

**引理 22（VoD 贪心近似）** GP 代理下采集目标是单调子模（A96），贪心 `VoD ≥ (1−1/e)VoD*`；R69 的 VoI 是 `d=(τ 上再问一次)` 的特例。

**定理 18（跨任务认证风险上界）** A96–A99 下以概率 `≥1−δ_c`，定义 313 的上界对**每个** τ 成立，采集通过同时压低 `ε,δ,σ_cert` 单调收紧上界。

**定理 19（DATUM 严格包含 R69）** 单任务、`B=0`、`γ=0`、门关 ⇒ 数据层零写，在线决策与 FLUID 逐指令相同，安全侧不弱于 R69。

**定理 20（换装无突变）** 在线零写 + 双缓冲 + epoch 边界 `atomic_swap` + 换装前 `Valid(J_new)` ⇒ 控制路径任一时刻只见一个已认证版本；迁移门/覆盖证书只影响下一次换装，不改当前安全包络。

## 7. 本轮最大风险

**一句话**：DATUM-RAS 的整套认证都建立在「任务族与任务度量 `d_𝒯` 被正确指定」这一前提上——**若部署任务落在建模的任务族之外，或某个捷径特征伪装成共享因子 ψ，覆盖证书会为一个从未被表示的分布盖上「已泛化」的章，而主动数据构建会以比纯部署快得多的速度把这个错误放大、固化进下一版策略**——证书于是从「安全许可」变成「错误分布的通行证」。

**次级风险与缓解**：负迁移（XTG held-out 增益下界 + 引理 19）；合成回声室/模型坍缩（γ 折扣 + 认证下限引理 20 + `ρ_min` + 金丝雀 + RCG 回滚）；数据投毒（provenance DAG + 影响函数裁剪 + 稳健聚合 + 投毒预算）；在线偷学致证书陈旧（零写在线 + epoch 原子换装 + 定理 20）；覆盖证书过度乐观（离支撑打分 + `L_τ ε` 显式项 + 漂移触发器；绝不把「平均泛化」当「逐任务泛化」）。
