# 第 58 轮（承接第 57 轮「少样本元推断×跨模态对账×个性化有界信任」IP-133~138；灵感循环第 1 轮；本轮灵感：「异常检测」×「遥操作」）

> 第 57 轮把安全从"模型置信"推进到"少样本可校准、跨模态可对账、个性化有界的证据承诺"：MFSL 用元先验换效率、共形带保底，XMC 以分歧下限拆穿单模态共谋，PTM 把操作者从常量变成单向有界状态机。但它始终把两个"例外处理器"当成两条互不相干的旁路：**(a) OOD 门只回答"这一看不像训练集"，给出一个更宽的区间后就地绕行，却无法回答"这个新奇到底是什么、什么时候可以解除警报"**——异常被检出却没有"结案"流程，系统要么长期瘫痪，要么在警报疲劳中把新奇当正常；**(b) 人被建模为"在场且与机器人看同一世界"的裁判**（cal/vig/auth 只测他判得准不准），可一旦进入遥操作，人看到的是延迟 τ_d、压缩、窄视场世界的一个旧副本——他"判得准"不等于"看得见"，PTM 的授权把"能力"与"可观测"混为一谈。本轮两个灵感正好补上这两块：**异常检测**把异常从"一个宽区间触发器"升级为**只能升杠、不能授权的负证据通道**（基率感知、任意时 FDR、发现即托管、结案须独立见证）；**遥操作**把人从"在场裁判"升级为**带宽/延迟/视场受限的远程信道**，授权 = 权限 ∧ 校准 ∧ 可观测三者之合取。最尖锐的合流点是：**遥操作本来就是异常触发的响应，而这两个例外处理器共享同一条退化信道——把异常交给一个只看到同一盲区旧副本的人，制造的不是冗余，而是相关失效。** 因此本轮核心命题升级为 **"异常不授权、接管须可观测、否决权不外包的证据说可信"**。

核心矛盾：
- **H29（发现 vs 结案）**：异常检测天然是"无正例"学习——它擅长说"这里不对"，却不擅长说"这里对"。可部署必须能结案：永远挂着等于隐性停摆，草率结案等于隐性放行；而判 benign 与判 hazard 的错误代价是不对称的，基率又低到"告警大多是假"。
- **H30（在场 vs 可观测）**：第 57 轮的信任是"人判得准吗"，遥操作真正缺的是"人看得见吗"。一个校准极好的专家，若延迟 600ms、视场被机械臂挡住，其对不可逆接触的确认在信息论上不比随机好；把"授权"建立在他过去的准确率上，会把"能力"当成"可观测"。
- **H31（冗余 vs 共谋）**：异常告警与人工接管本应互为冗余；但若两者共用同一路相机/同一段网络/同一个机器人自模型，它们会以同一个错误相互背书——"检测到异常 ⇒ 快叫人 ⇒ 人也说没问题 ⇒ 结案"可以完全发生在同一个盲区里。

## 0. 直觉与动机

**灵感 1（异常检测 → 负证据、基率与可结案的注销簿）**
直觉：异常检测在安全体系里最容易被误用成"第二个分类器"——告警了就当作危险证据。这是方向性错误：由于异常罕见、检测器又不完美，一个告警的**后验危害概率** = 基率乘检出率、除以基率乘检出率加假阳率，往往远低于直觉。正确的定位是给它**负权限**：告警只能"提高门槛、把动作变可逆、把人叫来"，永不能"证明安全"。于是异常检测的价值不是"多一条支持证据"，而是"多一道不会把风险往下拉的闸"。同时必须给它一本**注销簿**：每条告警登记成待结案条目，结案（benign/hazard）需要独立见证，且判 benign 的证据门槛严格高于判 hazard——因为放行比拦截更危险。

**灵感 2（遥操作 → 授权三角与延迟补偿的指令溯源）**
直觉：遥操作不是"人比机器聪明所以交给人"，而是"人通过一条有损、有延迟的信道去感知和决策"。所以授权应当是一个合取式：**权限（你是谁）∧ 校准（你判得准不准）∧ 可观测（你对这个决策的关键变量看得见吗）**。三者缺一，授权不成立。进一步，操作者此刻按下的键，是他 τ_d 秒前看到的世界的函数；机器人却活在现在。于是不能只看"这条指令在操作者脑内是否合理"，而要看它是否同时落在**真实状态的可行集**与**操作者感知状态的可行集**的交叠里——交叠之外一律限幅，并标记为"陈旧指令风险"。遥控数据本身也值得做异常检测：高频抖动、与状态相悖、权限来回切换、疲劳性退化，都是可检的遥操作异常。

**灵感 3（异常检测 × 遥操作 → 两个例外处理器都在分布外）**
直觉：这是本轮最锋利的一刀。异常检测器是在"正常"上训练、面向"没见过"的；遥操作则恰恰在系统最没把握时才启用。**两个本该兜底的机制，本身都工作在训练分布之外**。所以不能给它们正权限：异常检测只能给负权限（升杠/托管），遥操作只能给条件权限（可观测三角内），而**不可逆动作的最终否决权必须留在机器人手里、不可外包**。把例外处理器当"最后裁判"，等于把两个分布外的组件串成一个分布外的安全论证。

**灵感 4（合流 → 证据门从五类到七类：EV-anom-clear 与 EV-teleop）**
直觉：第 57 轮证据门五类各得一个新维度：**EV-anom-clear**（区域已结案为 benign，须 2 个独立见证 ∧ FDR 达标 ∧ 未过期）只能把门槛**恢复到常态**，本身不得授权不可逆；**EV-teleop**（遥操作确认/指令）须通过溯源 ∧ 可观测三角 ∧ 非托管，可替代一次 L1 佐证，但**不得进入不可逆必要证据集**。击穿安全现在需要：异常漏检 ∧ 共形带失效 ∧ 遥操作可观测性高估 ∧ 陈旧指令未被检出 ∧ 否决被绕过 ∧ 人也错——纵深从五层到七层，且新增两层都在"例外处理器"这一侧。

**灵感 5（PCE+ → PCE++：异常引导探询 + 可观测性增强 + 有界保护性否决）**
直觉：探-诺-演从"检查点循环"变成"异常-授权循环"：先扫异常并归因（哪个模态/探针贡献最大），告警则登记托管并按关键变量估可观测性；可观测不足先**增强信道**（解释/触觉/加视角/降延迟）再谈接管；授权按子空间局部化，并设"授权抖动预算"防止人机抢方向盘；执行中用交叠包络与命令流异常监测兜底。异常归因还顺带把第 57 轮 VOI 变便宜：异常告诉你去问"哪一维"，而不是把所有模态再问一遍。全部机制仍只经两个安全通道：**信念更保守（加宽/托管）** 或 **动作更保守（降档/限幅/否决/缩短授权）**。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（异常负证据与基率感知阈值 ANE）** 异常检测器 D 输出分数 s(x) 与任意时有效的在线共形 p 值 p_t(x)。告警 A_t={p_t≤α_fa}。**负权限公理**：告警只可用于 (i) 提高受影响区域/动作的证据门槛、(ii) 触发可逆探询、托管、降档或接管，**永不作为任何承诺的支持证据**。基率校正：记先验危害率 π_h、检出功效 1−β，则告警后危害后验 P(h|A)=π_h(1−β)/[π_h(1−β)+(1−π_h)α_fa]；系统只用它决定"需要的独立见证数" n_wit(A)，而非直接判危。**告警预算**：每时间窗允许触发升级的告警数 ≤B_anom；超出即进入保守模式（限幅/降档/安全停），**宁可降可用性，不降安全性**。异常归因 c_m 给出各模态/探针贡献，用于指导下一步探询。分段可交换被变化点破坏时即时重置共形状态，重置延迟 ≤L_cp。

**定义 140（新颖性注册与托管 NRE）** 告警登记条目 u=(r,sig,t,status∈{unclassified,benign,hazard,retired},witnesses)。未结案期间，受影响支持集 supp(u)（由地图相似度/材质簇传播，防打地鼠）进入**托管**：禁止不可逆承诺，仅允许 {可逆探针, 带否决的遥操作, 安全停}。**非对称结案**：判 hazard 需 1 个独立见证；判 benign 需 2 个独立见证（跨模态同侧 ∧ 物理探针，或可观测性达标的遥操作确认），用 SPRT 型序贯检验，阈值按放行/拦截代价非对称。**只增不减**：已确认 hazard 的区域在其支持集内永久保留一条监测谓词；benign 会随漂移过期而需再证。托管有硬上限 τ_escrow：超时未结案 ⇒ 升级为保守模式或交人显式处置，禁止"无限期挂着"变相放行。

**定义 141（遥操作可观测性与命令溯源 TOP）** 信道 o=(τ_d,B_w,FOV,res,compression)。对决策 c 的关键状态变量集 V_c，
O(c,o)=min_{v∈V_c} vis_v(o)，vis_v=1[v 在操作者视场/量程内 ∧ 分辨率足以分辨临界差 ∧ τ_d≤τ_max(v)]，τ_max(v) 为变量 v 的动力学时间尺度对应的最大可容忍延迟。
**授权三角**：auth_eff(c,o)=auth ∧ cal ∧ O（三者之合取，任一为 0 则授权为空）。**命令溯源**：操作者 t 时刻命令 u_h 基于 t−τ_d 的观测；用真实状态 x_t 与预测的操作者感知状态 x̂_t^o 做双状态校验，可执行指令集 U_safe=U(x_t)∩U(x̂_t^o)（交叠包络）；u_h∉U_safe ⇒ 标记 stale-command hazard 并限幅进交叠集。**遥操作异常监测**：对命令流做异常检测（高频抖动、与状态相悖、权限抖动、疲劳性退化），检出即降 auth_eff 并提示，不代替操作者决策。

**定义 142（授权仲裁与保护性否决 HAA）** 授权按控制子空间 S（导航/机械臂/夹爪/接触）局部化，a_S∈{AUTO,SHARED,TELEOP,SAFE_STOP,PROTECT_OVERRIDE}。授予 TELEOP(S) ⇔ (i) auth_eff(S,o)≥θ_auth(S)；(ii) 无影响 S 的未结案托管；(iii) 不可逆动作上保留机器人独立否决 LIC。**保护性否决有界**：异常在遥操作中触发时可瞬时覆盖为安全动作，但覆盖时长 ≤N_ovr 帧、必须给出解释并记录，且操作者可凭"接管 + 可观测自证"夺回；否决只作用于不可逆子空间，不接管全部控制。**授权抖动预算**：单位时间授权切换数 ≤B_churn，超限即锁存到 SAFE_STOP/保守模式。**否决权不外包**：遥操作不得禁用异常否决、最后一层安全与托管；不可逆动作的最终证据必须是独立于遥操作的物理证据。

**定义 143（异常-遥操作证据门 ATG 与证书 J_t）** 在 FSE 五类上新增：EV-anom-clear（支持集已结案 benign，须 2 独立见证 ∧ FDR≤α_fa ∧ 未过期）；EV-teleop（遥操作确认/指令，须 provenance 校验 ∧ O≥θ_O ∧ staleness≤τ_max ∧ auth_eff≥θ_auth ∧ 非托管）。规则：(T1) EV-anom-clear **只能恢复**到常态证据需求，本身不得授权不可逆承诺；(T2) EV-teleop 仅可替代一次 L1 佐证，不得进入不可逆必要证据集；(T3) 不可逆必要证据集 = {EV-probe\*∨EV-margin} ∧ 独立物理佐证，且排除 EV-teleop 与 EV-anom-clear；(T4) 存在未结案托管 ⇒ 硬拒一切不可逆承诺，任何 auth 不得覆盖。J_t=(J_p,anomaly_log,escrow_state,observability_log,command_provenance,authority_log,override_log)。

**定义 144（异常-遥操作算子 ATO / PCE++）** 每检查点：①异常扫描（多尺度/任意时 FDR + 归因）；②若告警 ⇒ 登记托管、按 V_c 估 O、选择信道增强（解释/触觉/加视角/降延迟）或请求遥操作；③授权仲裁（子空间 × 三角条件 × 抖动预算）；④若遥操作 ⇒ provenance 校验 + 交叠包络 + 命令流异常监测；⑤证据门：承诺 ⇔ 常规证据门过 ∧ 无未结案托管 ∧（若涉及遥操作）授权三角成立；否则异常引导探询 → 增强可观测 → 再授权 → 绕行/降档/L2 协商/安全停。

## 2. 关键算法伪代码（完整版见产物区）

```python
def anomaly_gate(M, r, obs, det):                  # IP-139/140
    a = det.score(obs); p = det.pvalue(a)          # 任意时有效共形
    if p > alpha_fa: return M, None
    u = registry.open(r, det.attribute(obs), t_now)
    M = escrow(M, support_set(M, r), u)            # 托管：只可逆/带否决/停
    return M, u                                    # 负证据：只升杠，不授权

def teleop_authorize(c, o, persona, escrow, M):    # IP-141/142
    O = min(vis(v, o) for v in critical_vars(c))   # 可观测三角
    auth_eff = persona.auth and persona.cal and O
    if auth_eff < theta_auth(c.S) or escrow.affects(c.S):
        return 'AUTO'                              # 失败关闭
    return 'TELEOP' if veto_retained(c) else 'SAFE_STOP'

def provenance_filter(u_h, x_t, guess_perceived, o): # IP-141
    U = admissible(x_t) & admissible(guess_perceived)
    if u_h not in U:
        log('stale_command_hazard'); return clamp(u_h, U)
    return u_h
```

**正确性定理（AATS 概要）**：在 A33–A40 上加 (A41) 异常检测任意时 FDR≤α_fa、漏检≤δ_anom、变化点重置延迟≤L_cp；(A42) 可观测性审计诚实（vis 由可验证几何/延迟算出，不夸大 O，信道漂移在 L_o 内检出）；(A43) 否决不外包（遥操作不能禁用异常否决/最后一层安全/托管，保护性否决≤N_ovr，抖动预算生效）；(A44) 负/条件权限（告警永不作为支持证据，EV-teleop 排除出不可逆必要证据，基率校正生效）。则：(i) 不可逆失效率 ≤ 第 57 轮界 + δ_anom·α_res + δ_stale·1[用了遥操作]；(ii) **遥操作不降低安全性**：除非 O 被高估（违 A42）、否决被绕过（违 A43）或陈旧指令未被检出，否则交叠包络使遥操作失效界不劣于自主基线；(iii) **安全性-可用性解耦**：假警只损可用性、不增安全事故（进入保守模式而非忽略）；(iv) 交互单调性延续：异常/托管/可观测/抖动预算只收紧不放宽；(v) 托管在 k_esc 次探询或 τ_escrow 内结案或升级，授权仲裁有限步。

## 6. 本轮最大风险

**一句话**：本轮把"人能不能接管"的判据押在一个机器人**无法从自身侧观测**的量上——"操作者到底看到了什么"（O）；一旦可观测性估计被高估，系统就会把一个延迟、压缩、被遮挡的旧副本当成合格裁判，让异常告警与人的确认沿同一条退化信道相互背书，形成"检测到 ⇒ 交给人 ⇒ 人也没看出 ⇒ 结案"的相关闭环；因此必须以失败关闭的低 O 默认、独立见证、物理隔离信道与不可外包的否决权四重护栏，宁可频繁降可用性，也绝不把例外处理器当最后裁判。

def anomaly_scan(M, r, obs, det, alpha_fa, B_anom, window):
    a = det.score(obs)                       # 多尺度异常分数
    p = det.pvalue_anytime(a)                # 在线共形/e-process，任意时有效
    det.maybe_reset_on_changepoint(obs)      # 分段可交换，重置延迟<=L_cp
    if p > alpha_fa:
        return ('clear', None)
    if det.alarms_in(window) >= B_anom:      # 告警预算耗尽的处理
        return ('conservative_mode', det.attribute(obs))  # 降可用性，不丢告警
    post = prior_hazard * det.power / (prior_hazard * det.power
                                       + (1 - prior_hazard) * alpha_fa)
    n_wit = witness_count_for(post)          # 后验越高，独立见证要求越少但>=1
    attrib = det.attribute(obs)              # {modality/probe: contribution}
    return ('alarm', dict(post=post, n_wit=n_wit, attrib=attrib, p=p))

# 负权限公理（类型层面强制）：scan 的返回值只有 clear/alarm/conservative_mode，

def resolve(u, witness, registry):

    if witness.independent and witness.supports('hazard'):

### IP-141 TOP（可观测性、延迟补偿与命令流异常）

def observability(c, o, x):
    Vc = critical_vars(c)                    # 决策 c 的关键状态变量
    vals = []
    for v in Vc:
        tau_max = dynamics_timescale(v) / safety_margin(v)
        seen = (in_fov(v, o.FOV) and in_range(v, o.res)
                and o.tau_d <= tau_max and channel_healthy(o))
        vals.append(1.0 if seen else 0.0)
    return min(vals) if vals else 0.0        # 失败关闭：未知即不可见

def predict_perceived_state(x, o, tracker):
    return tracker.backproject(x, delay=o.tau_d)   # 估计操作者在 t-τ_d 看到的世界

def command_provenance(u_h, x_t, o, tracker):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| ANE | O(d_D)/帧 + O(1) 共形更新 | O(N_cal) 滑窗 | 任意时 FDR≤α_fa、漏检≤δ_anom（A41） |
| NRE | O(\|supp(u)\|) 登记/结案 | O(\|U_esc\|) | 非对称结案、τ_escrow 硬上限 |
| TOP | O(\|V_c\|)/决策 | O(1) | vis 可验证、失败关闭（A42） |
| HAA | O(\|S\|)+O(1) | O(\|S\|) | 三角合取、否决不外包、抖动≤B_churn（A43） |
| ATG | O(\|σ\|) | O(\|σ\|) | 托管硬拒、EV-teleop/anom-clear 禁入不可逆（A44） |
| ATO | O(\|CP\|·(\|V_c\|+k_p+k_c)+A\*) | O(\|V\|+\|U_esc\|) | 托管结案有限步、四态完备 |

**正确性定理（Anomaly-Aware Teleoperated Soundness, AATS）**
假设 A22–A32（第 53–55 轮）、A33–A40（第 56–57 轮）成立；**(A41) 异常检测**：在分段可交换下任意时 FDR≤α_fa，漏检率 ≤δ_anom，变化点重置延迟 ≤L_cp；**(A42) 可观测性审计诚实**：vis_v 由可验证的视场/分辨率/时延几何算出，不夸大 O，信道漂移在 L_o 内检出；**(A43) 否决不外包**：遥操作不能禁用异常否决、最后一层安全与托管，保护性否决 ≤N_ovr 帧，授权抖动 ≤B_churn；**(A44) 负/条件权限**：告警永不作支持证据，EV-teleop 排除出不可逆必要证据，基率校正生效。则：

1. **不可逆承诺健全性**：P(fail) ≤ [第 57 轮 CCPS 界] + δ_anom·α_res + δ_stale·1[teleop]，其中 δ_stale≤δ_O+δ_lat；**假警不进入安全项**，只进入可用性项。
2. **遥操作不劣化安全**：若 O 未被高估（A42）、否决未被绕过（A43）且陈旧指令在 τ_max 内被检出，则交叠包络 U_safe⊆U(x_t) 保证遥操作授权的每一次不可逆动作都仍落在真实状态可行集内，其失效界不高于自主基线。
3. **安全性-可用性解耦**：告警预算耗尽进入保守模式而非丢弃告警；误结案只可能发生在"2 独立见证 + FDR 达标 + 未过期"，因此异常路径交易的是**可用性**，不是安全性。
4. **交互单调性延续**：异常、托管、可观测、抖动预算、保护性否决只经 (a) 门槛提高/信念加宽 或 (b) 动作更保守 两条通道影响系统；不存在"异常/遥操作直接把风险往下拉"的路径。
5. **终止与可结案**：每个托管在 k_esc 次异常引导探询或 τ_escrow 内结案或升级（保守模式/显式处置）；授权仲裁在有限状态机内完成。

**部署界**（对检查点取联合界；遥操作与异常项分离记账）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1])
             − δ_anom·α_res
             − 1[teleop]·(δ_O + δ_lat)
             − P(托管超时未升级) − P(可观测性审计失效) − P(否决被绕过)

Availability ≥ 1 − [α_fa·B_anom·L_cp + 托管误封时长 + 保护性否决时长]
```

关键：**异常给负权限**（只升杠、只托管，永不授权——把"多一个检测器"从潜在风险变成纯约束）；**遥操作给条件权限**（三角合取 + 交叠包络，把"人说了算"降为"在看得见的子空间里、且不越过否决"）；**否决权不外包**（不可逆动作的最终证据仍是独立物理证据）；**安全与可用性解耦**（假警只损可用性）；三个结论都由"负/条件权限 + 单调性"统一保证。

云边协议 CEB++ → **CEB+++**：异常检测器同样**走隔离区**（第 57 轮"一切判定器走隔离"的延伸）——云端下发的异常模型先在边端影子运行，须满足"FDR 不劣化 ∧ 漏检不升 ∧ 告警预算内可用性不降"才接管；边端回传**误结案样本、陈旧指令样本、可观测性失效事件**作为三张独立的补盲集。**遥操作信道健康**作为一等公民上报（延迟/丢包/视场/分辨率），任一指标越界即自动把对应子空间的授权三角置零（失败关闭），而不是等事故证据。

## 6. 本轮最大风险

**一句话**：本轮把"人能不能接管"的判据押在一个机器人**无法从自身侧观测**的量上——"操作者到底看到了什么"（O）；一旦可观测性估计被高估，系统就会把一个延迟、压缩、被遮挡的旧副本当成合格裁判，让异常告警与人的确认沿同一条退化信道相互背书，形成"检测到 ⇒ 交给人 ⇒ 人也没看出 ⇒ 结案"的相关闭环；因此必须以失败关闭的低 O 默认、独立见证、物理隔离信道与不可外包的否决权四重护栏，宁可频繁降可用性，也绝不把例外处理器当最后裁判。
