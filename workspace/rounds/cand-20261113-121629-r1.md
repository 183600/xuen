# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 4 轮；本轮灵感：「动作分块」×「动力学」）

> 第 66 轮 RAS 把「安全」抽成了一个可缩放的风险预算 `λ_risk`，并把故障归因扩展到情绪维度。但它仍默默假设了两件从未被检验的事：
>
> 1. **动作块是一串静态姿态**——块只承诺「做什么」，不承诺「做完这段时我还会在哪里」；
> 2. **块长是超参数**——`m_ras`、`k*RAS` 的上界来自手调，而不是来自系统本身的物理约束。
>
> 一旦把块放进真实动力学里，这两个假设都会崩：块是一段**会漂移的有限时域承诺**，它能开环执行多久，取决于系统对初态误差是**放大**还是**收缩**。本轮的核心命题是：
>
> **把「动作块」升级为「带动力学证书的有限时域承诺」：用局部收缩度量预测漂移管，用风险预算设定安全阈值，让块长 `k*` 成为「漂移管何时耗尽预算」的解，而不是超参数。**
>
> 该方案命名为 **CHORD（Certified HORizon from Online Risk-budget & Dynamics）**。它不取代 RAS，而是嵌在 RAS 与执行器之间：RAS 给出预算 `b`，动力学给出「燃烧率」`ε(k)`，CHORD 解出 `k* = max{k : ε(k) ≤ b}`。

## 0. 直觉与动机

**灵感 1（动作分块 → 有限时域承诺）**
直觉：一个动作块本质上是一张**带到期时间的承诺**，而不是一串姿态。人把杯子推向桌沿时，手臂并不「每帧重新决策」，而是发出一段肌肉协同，并**估计这段协同在多长时间内仍然有效**。当前策略（ACT / Diffusion Policy）只输出动作序列，把「有效期」交给固定的 `chunk_size`；这相当于签发一张不知道何时失效的支票。CHORD 要显式签发「有效期」：`k*` 就是这张承诺在安全预算内可兑现的步数。

**灵感 2（动力学 → 块的「保质期」由漂移管决定）**
直觉：执行块时是开环的，模型误差会沿时间累积。若局部动力学是**收缩的**（扰动被系统自身吸收），漂移管会饱和在 `δ_w/(1-L)`，块可以很长；若是**扩张的**（`L>1`），漂移按 `L^s` 指数放大，块必然很短。于是「块长」第一次有了物理含义：**它是动力学收缩率的函数**，而不是调参旋钮。更妙的是，这里存在一个相变：`L<1` 时认证时域可以到无穷（在块内），`L≥1` 时必然有限。

**灵感 3（两灵感合流 → 风险预算 × 漂移燃烧率）**
直觉：RAS 的 `λ_risk` 已经把「允许多大的偏差」压成了一个标量预算；动力学则给出「偏差以多快速度增长」。把二者相乘除：
```
k* = max{ k : ε(k) ≤ b_k },   ε(k) ≈ δ_w·(L^k − 1)/(L − 1),   b_k = λ_risk·m_safe
```
当人紧张（`λ_risk` 下降）→ 预算缩小 → 块自动变短、重规划变密；当动力学收缩（`L<1`）→ 漂移饱和 → 块可以变长。这不是两个模块的拼接，而是**预算-燃烧率的对偶**：风险决定「允许花多少」，动力学决定「每秒花多少」，块长就是「多久花完」。

**灵感 4（拼接 → 块缝是混合系统切换，不是插值）**
直觉：现有 chunk stitching 用线性插值或重叠平均糊住块缝，这在收缩系统里通常没事，在扩张系统里会注入能量、诱发抖振。正确的做法是把块缝当作**混合系统的切换事件**：要求前后块的终端/初始漂移管**相交**（不变集重叠），并要求拼接能量 `ΔE = ½‖u⁺ − u⁻‖²` 不超过耗散预算，再加**驻留时间** `τ_d` 防止 Zeno 式抖动。这样「拼接」从工艺问题变成稳定性条件。

**灵感 5（故障归因 → 漂移残差的两个新假设）**
直觉：块的执行残差 `r_t = x_t − x̂_t` 本身就是信息。它在块内缓慢偏置 → `H_dyn`（动力学模型失配）；它在块缝处突跳 → `H_chunk`（拼接/边界故障）；它白噪声化 → `H_sensor`。于是 RAS 的故障假设集自然长出两个动力学维度，而 CHORD 的证书 `J_chord` 与 `J_RAS` 可以逐字段合并。

## 1. 形式化定义（增量：定义 251–266）

- **定义 251（CHORD 总览）**：`CHORD = (ACP, DBB, TBE, CIU, DRA, ARC, CDC)`，即仿射块策略、动力学预算界、时间-预算耗尽求解器、块不变/拼接单元、漂移残差归因、自适应重分块控制器、CHORD 证书。定位：夹在 RAS 的风险缩放与底层执行器之间的「块有效性认证层」。不变式：漂移管、收缩估计、拼接检验只在语义流计算；实时流只做 `O(1)` 的管半径递推与越界早停，零学习写操作。
- **定义 252（仿射动作块）**：块 `C_t = (U_t, f̂_t, M_t, Σ_t, H)`，其中 `U_t = (u_t,…,u_{t+H−1})` 为动作序列，`f̂_t` 为局部仿射动力学 `x⁺ = A_t x + B_t u + c_t`，`M_t ≻ 0` 为度量矩阵，`Σ_t` 为残差协方差/界。块的语义从「动作序列」变为「动作序列 + 它自己的动力学模型」。
- **定义 253（收缩度量与收缩率）**：在度量 `M_t` 下定义 `L_t = ‖A_t‖_{M_t} = ‖M_t^{1/2} A_t M_t^{−1/2}‖₂`。`L_t < 1` 称块是 M-收缩的，`L_t ≥ 1` 称 M-扩张的。真实动力学 `x⁺ = f(x,u) + w`，`‖w‖_{M} ≤ δ_w`。
- **定义 254（漂移管）**：设名义开环轨迹 `x̂_{t+s}` 由 `(f̂_t, U_t)` 递推得到，初态误差 `e_0 = ‖x_t − x̂_t‖_M`。漂移管半径
  ```
  ε_0 = e_0
  ε_s = L_t^s·e_0 + δ_w·(L_t^s − 1)/(L_t − 1)   (L_t ≠ 1)
  ε_s = e_0 + s·δ_w                              (L_t = 1)
  ```
  并记真实误差 `e_s = ‖x_{t+s} − x̂_{t+s}‖_M ≤ ε_s`（在模型误差被 `δ_w` 吸收时成立）。
- **定义 255（风险预算）**：沿块的预算 `b_s = λ_risk(t+s) · m_safe(t+s)`，其中 `λ_risk` 取定义 238，`m_safe(s) = min_{i≤s} margin(x̂_{t+i}, u_{t+i})` 为 C-RAS 的带符号最小安全裕度。预算单调化 `b̄_s = min_{i≤s} b_i`。
- **定义 256（时间-预算耗尽时域 TBE）**：CHORD 的动力学认证前缀
  ```
  k*_dyn = max{ k ≤ min(H, m_ras, k_max) : ∀s≤k, ε_s ≤ b̄_s }
  ```
  最终认证前缀 `k*_CHORD = min(k*_RAS, k*_dyn)`。直觉：`k*_dyn` 是漂移管第一次刺穿风险预算的时刻。
- **定义 257（块不变集与拼接条件）**：终端管 `Ω_t⁺ = {x̂_{t+k} + e : ‖e‖_M ≤ ε_k}`，下一块初始管 `Ω_{t+k}⁻ = {x̂'_{t+k} + e : ‖e‖_M ≤ ε'_0}`。拼接可行当且仅当
  ```
  ‖x̂_{t+k} − x̂'_{t+k}‖_M ≤ ε_k + ε'_0    （管相交）
  ```
  且下一块在 `Ω_t⁺ ∩ Ω_{t+k}⁻` 上是前向不变的。
- **定义 258（拼接能量与驻留时间）**：拼接能量 `ΔE = ½‖u⁺ − u⁻‖²_R`（`u⁺` 为上一块在缝处的动作，`u⁻` 为下一块首动作）。CHORD 要求 `ΔE ≤ κ_d` 且两次重分块之间至少驻留 `τ_d` 步（安全越界可覆盖驻留）。
- **定义 259（在线收缩估计）**：在窗口 `W` 上用残差比值 `ρ_s = e_{s+1}/(e_s + ϵ)` 估计 `L_t`，取单侧上置信界
  ```
  L̂_t = min{ 1, Quantile_{1−α_dyn}({ρ_s : s∈W}) + β_t }
  ```
  其中 `β_t` 为自归一化浓度项。认证时一律使用 `L̂_t` 而非点估计，保证「高估收缩率」只会更保守、不会更危险。
- **定义 260（动力学残差签名）**：`r_t = x_t − x̂_t`，签名
  ```
  φ(r) = (‖mean_W r‖,   |r_{t+1} − r_t| 在块缝处的尖峰,   autocorr_1(r),   ‖r_∥‖/‖r‖)
  ```
  分别对应「持续偏置、边界突跳、低频漂移、沿预测方向性」。
- **定义 261（CHORD 故障假设扩展）**：在 RAS 的 `ℋ_RAS` 上新增 `H_dyn`（动力学失配）与 `H_chunk`（拼接/边界故障），`ℋ_CHORD = ℋ_RAS × {H_dyn, H_chunk}`，后验用 `φ(r)` 作为观测：`P(H | φ(r)) ∝ p(φ(r) | H)·P(H)`。
- **定义 262（自适应重分块控制器 ARC）**：ARC 是带驻留时间的切换自动机。状态 `EXECUTE`、`REPLAN`。触发条件：`e_s > ε_s`（越界，立即），或 `s ≥ k*`（到期），或 `L̂` 跳变超阈值，或预算 `b̄_s` 跌破 `ε_s`（风险突变）；若距上次切换 `< τ_d` 且非越界，则抑制切换（滞回）。
- **定义 263（CHORD 证书）**：
  ```
  J_chord = (J_RAS, L̂_t, δ_w, M_t, {ε_s}, k*_CHORD,
             stitch_margin, ΔE, φ(r), chord_ver)
  ```
  `Valid ⇔ Valid(J_RAS) ∧ ε_{k*} ≤ b̄_{k*} ∧ stitch_margin ≥ 0 ∧ ΔE ≤ κ_d ∧ (L̂_t < 1 ∨ k* ≤ k_max)`。
- **定义 264（闭环不变式）**：每个被执行的前缀 `k*_CHORD` 都满足「管子 ⊆ 预算」，且块缝处管子相交、拼接能量耗散。任何违反不变式的块都不得进入执行前缀。
- **定义 265（风险-动力学对偶）**：块长由对偶方程决定
  ```
  k* = ȷ max{ k : δ_w·(L^k − 1)/(L − 1) ≤ λ_risk·m_safe }
  ```
  `λ_risk` 下降 10% 与 `L` 上升（收缩变弱）对 `k*` 的一阶影响同号；但前者可在任务层补偿（换更保守的接触策略），后者只能靠模型/控制改善。
- **定义 266（流分层）**：语义流：仿射块拟合、`L̂` 估计、`φ(r)` 归因、`J_chord` 构建；实时流：`O(1)` 递推 `ε_s`、比较 `ε_s ≤ b̄_s`、越界早停、驻留计时。两层通过证书交换，不共享可写状态。

## 2. 关键算法骨架

```python
# ACP：仿射块策略（在原有 chunk policy 上挂一个局部动力学头）
class AffineChunkPolicy:
    def __init__(self, base_policy, dyn_head, horizon=16):
        self.policy, self.dyn_head, self.H = base_policy, dyn_head, horizon

    def propose(self, x, obs):
        U = self.policy(x, obs)[:self.H]            # 动作序列
        A, B, c, Sigma = self.dyn_head(x, obs)      # 局部仿射 + 残差
        M = metric_from(Sigma)                      # 选 M ≻ 0
        L = spectral_norm(M @ A @ inv(M))           # ‖A‖_M
        return Chunk(U=U, A=A, B=B, c=c, M=M, L=L,
                     Sigma=Sigma, H=self.H)


# DBB + TBE：漂移管递推与预算耗尽
def tube_radius(e0, L, dw, k):
    if abs(L - 1.0) < 1e-9:
        return [e0 + s*dw for s in range(k + 1)]
    return [L**s * e0 + dw*(L**s - 1)/(L - 1) for s in range(k + 1)]


def certified_horizon(chunk, budget, k_ras, k_max=64):
    eps = tube_radius(init_error(chunk), chunk.L, delta_w(chunk),
                      min(chunk.H, k_max))
    bbar, run = [], float('inf')
    for s, b in enumerate(budget[:len(eps)]):
        run = min(run, b)
        bbar.append(run)
    k = 0
    for s in range(len(eps)):
        if eps[s] <= bbar[s]:
            k = s
        else:
            break
    return min(k, k_ras), eps, bbar


# CIU：块缝检验（管相交 + 拼接能量 + 驻留）
def stitch_ok(prev_chunk, next_chunk, eps_prev_k, eps_next_0,
              u_plus, u_minus, R, kappa_d):
    gap = norm(prev_chunk.x_end - next_chunk.x_start, prev_chunk.M)
    intersect = gap <= eps_prev_k + eps_next_0
    splice_E = 0.5 * (u_plus - u_minus) @ R @ (u_plus - u_minus)
    return intersect and splice_E <= kappa_d, gap, splice_E


# DRA：漂移残差归因
class DriftResidualAttributor:
    def signature(self, residuals, boundary_idx):
        mean_bias = norm(mean(residuals))
        boundary_spike = norm(residuals[boundary_idx+1] - residuals[boundary_idx])
        ac1 = autocorr(residuals, lag=1)
        align = directional_alignment(residuals)
        return (mean_bias, boundary_spike, ac1, align)

    def attribute(self, phi, L_hat, L_true):
        eps = 1e-6
        if phi[1] > self.tau_boundary:
            return 'H_chunk'          # 边界突跳
        if phi[0] > self.tau_bias and abs(L_hat - L_true) > self.tau_L:
            return 'H_dyn'            # 持续偏置 + 收缩率失配
        if phi[2] < self.tau_white:
            return 'H_sensor'         # 白噪声
        return 'H0'


# ARC + CDC：CHORD 主循环
def CHORD_round(M, obs):
    x, x_meas = M.estimator.state(), M.estimator.measured()
    lam_risk, k_ras = M.ras.risk_scale_and_prefix(obs)   # 来自 RAS
    chunk = M.acp.propose(x, obs)

    M.dbb.update_residual(x_meas - x)
    chunk.L = M.dbb.estimate_contraction_ucb()           # 定义 259
    budget = M.ras.budget_along(chunk, lam_risk)         # 定义 255
    k_dyn, eps, bbar = certified_horizon(chunk, budget, k_ras)
    k_star = min(k_dyn, k_ras)

    phi = M.dra.signature(M.dbb.window(), boundary_idx=M.dbb.boundary())
    hyp = M.dra.attribute(phi, chunk.L, M.dbb.L_true_est)

    if M.arc.in_dwell() and not M.dbb.breached(eps[0]):
        k_exec = 0                                       # 保持，不切换
    else:
        ok, gap, dE = stitch_ok(M.last_chunk, chunk,
                                M.last_eps_k, eps[0],
                                M.last_u_end, chunk.U[0], M.R, M.kappa_d)
        k_exec = k_star if ok else 0
    M.arc.commit(k_exec)
    return J_chord(M.jras, chunk.L, eps, k_exec, phi, hyp), chunk.U[:k_exec]
```

## 3. 推导

**引理 11（漂移管增长界）** 在定义 253–254 下，对任意 `s≤H`，
```
e_s ≤ L^s e_0 + δ_w·(L^s − 1)/(L − 1)（L≠1），  e_s ≤ e_0 + sδ_w（L=1）。
```
证明：对误差递推 `e_{s+1} ≤ L e_s + δ_w` 展开求和；`L<1` 时级数收敛，`ε_∞ = e_0 + δ_w/(1−L)`。注意 `ε_s` 对 `s` 单调不减，故预算耗尽点唯一。

**引理 12（相变）** 若 `L<1` 且 `e_0 + δ_w/(1−L) ≤ inf_s b̄_s`，则 `k*_dyn = H`（块内时域不受限）；若 `L≥1`，则对任意正预算 `b>0` 有
```
k*_dyn ≤ ⌈ log(1 + (L−1)·b/δ_w) / log L ⌉。
```
证明：`L<1` 时 `ε_s → ε_∞ ≤ b̄`；`L>1` 时令 `ε_s ≤ b` 解出 `L^s ≤ 1 + (L−1)b/δ_w`。这说明「块长」存在由动力学决定的**硬上界或消失的上界**，而不是平滑可调的旋钮——这正是固定 `chunk_size` 无法表达的结构。

**引理 13（拼接耗散）** 若相邻块共享度量 `M` 且 `ΔE = ½‖u⁺−u⁻‖²_R ≤ κ_d`，则切换瞬间 Lyapunov 函数 `V_s = e_s^T M e_s` 满足
```
V⁺ ≤ (√V⁻ + √(2ΔE))² + O(δ_w)。
```
即拼接注入的能量被 `κ_d` 显式记账，不会在扩张系统里被无声放大。

**定理 11（CHORD 端到端安全性）** 在 RAS 的 A87–A91、定义 253–263 与引理 11–13 下，以概率至少 `1 − α_dyn − α_chunk − α_emotion`，执行 `k*_CHORD` 前缀期间真实状态始终落在风险预算内，即
```
P(∃s ≤ k*: margin(x_{t+s}) < 0) ≤ α_RAS + α_dyn + α_chunk。
```
证明：用 `ε_s` 的置信上界与 `b̄_s` 的单调化，对每个 `s` 做并集界；`L̂` 取单侧 UCB 保证 `L_true ≤ L̂` 的高概率成立；再与 RAS 定理 9 的 `α_RAS` 合并。

**定理 12（切换稳定性）** 若所有块共享同一收缩度量 `M`、`κ_d` 有界、且驻留时间 `τ_d ≥ 1`，则 CHORD 的切换闭环对扰动 `δ_w` 是 ISS 的；若进一步 `L̂ < 1` 且 `δ_w = 0`，则 `e_s → 0`（渐近稳定）。证明：块内 `V_{s+1} ≤ L²V_s + δ_w²`，块缝由引理 13 控制；多个 Lyapunov 函数在驻留时间下满足平均下降条件。

**推论 1（风险-动力学对偶的线性化）** 在 `L≈1` 附近，`k* ≈ b/δ_w`：块长与风险预算成正比、与扰动强度成反比；在 `L>1` 时退化为对数增长，表征「指数不稳定系统再多预算也买不到长时域」。

## 6. 本轮最大风险

**一句话**：CHORD 的全部安全性建立在「局部仿射 + 单一收缩度量在整块内有效」这一假设上；在接触丰富、摩擦锥切换、碰撞等**非光滑动力学**里，`L̂` 会剧烈跳变甚至无界，此时漂移管要么保守到 `k*→0`（系统陷入不断重分块的「认证瘫痪」与抖振），要么因低估 `L` 而给出过长的块，把 CHORD 变成「用一张过期的动力学证书为危险块背书」——这正是分块原本想避免的复合误差，只是换了一身更形式化的外衣。

**次级风险与缓解**：
1. **非光滑接触**：按接触模式分片，只在同一接触模式内认证；模式切换时强制重分块并重置管；
2. **收缩度量不一致**：若无法找到公共 `M`，退化为逐块度量 + 更保守的驻留时间，并标记 `J_chord` 的 `metric_shared=False`；
3. **`L` 估计滞后**：UCB 窗口过短会低估、过长会反应慢 → 用变遗忘因子 + 突变检测（CUSUM）；
4. **块缝切换开销**：`τ_d` 太大牺牲响应性，太小引发 Zeno → 用滞回带 `(1−γ)b` 自适应；
5. **与 RAS 预算单位不一致**：`m_safe` 是几何/力裕度，`ε_s` 是状态距离 → 用统一的任务空间度量 `M` 做量纲对齐，证书里记录换算矩阵。

## 2. 形式化定义（完整版）

**定义 251（CHORD 总览）** CHORD 是夹在 RAS 风险缩放与底层执行器之间的「块有效性认证层」：
```
CHORD = (ACP, DBB, TBE, CIU, DRA, ARC, CDC)
```

**定义 252（仿射动作块）**
```
C_t = (U_t, f̂_t, M_t, Σ_t, H),  U_t = (u_t,…,u_{t+H−1})
```
块从「动作序列」升级为「动作序列 + 自身动力学模型」。`f̂_t` 可由动力学头、模型 Jacobian 或集成模型局部线性化得到。

**定义 253（收缩度量与收缩率）** 真实动力学 `x⁺ = f(x,u)+w`，`‖w‖_M ≤ δ_w`。块内 `L_t = ‖M_t^{1/2}A_t M_t^{−1/2}‖₂`。`L_t<1` 为 M-收缩，`L_t≥1` 为 M-扩张。

**定义 254（漂移管）**
```
ε_0 = e_0
ε_s = L_t^s e_0 + δ_w (L_t^s − 1)/(L_t − 1)   (L_t ≠ 1)
ε_s = e_0 + s δ_w                              (L_t = 1)
```
且 `e_s = ‖x_{t+s} − x̂_{t+s}‖_M ≤ ε_s`。

**定义 255（风险预算）** 沿块预算
```
b_s = λ_risk(t+s) · m_safe(t+s),   b̄_s = min_{i≤s} b_i

`λ_risk` 由定义 238 给出，`m_safe` 为 C-RAS 的带符号最小安全裕度。预算把「风险」与「几何/力裕度」换算到同一度量。

**定义 256（TBE 时域）**

k*_dyn = max{ k ≤ min(H, m_ras, k_max) : ∀s≤k, ε_s ≤ b̄_s }
k*_CHORD = min(k*_RAS, k*_dyn)
```

**定义 257（块不变集与拼接）** `Ω_t⁺ = {x̂_{t+k} + e : ‖e‖_M ≤ ε_k}`，`Ω_{t+k}⁻ = {x̂'_{t+k} + e : ‖e‖_M ≤ ε'_0}`。拼接可行 ⇔
```
‖x̂_{t+k} − x̂'_{t+k}‖_M ≤ ε_k + ε'_0
```
且交叠集在下一块作用下前向不变。

**定义 258（拼接能量与驻留时间）** `ΔE = ½‖u⁺−u⁻‖²_R ≤ κ_d`；两次切换间隔 `≥ τ_d`（安全越界可覆盖驻留）。

认证恒用 `L̂_t`，因此低估 `L` 的概率被显式控制。

**定义 262（ARC 自动机）** 状态 `EXECUTE/REPLAN`；触发：越界 `e_s>ε_s`（立即）、到期 `s≥k*`、`L̂` 跳变、预算跌破；非越界且 `t−t_last < τ_d` 时抑制切换（滞回阈值 `ε_s ≥ (1−γ)b̄_s`）。

# IP-234 ACP：仿射块
class AffineChunkPolicy:
    def propose(self, x, obs):
        U = self.policy(x, obs)[:self.H]
        A, B, c, Sigma = self.dyn_head(x, obs)
        M = metric_from(Sigma)
        L = spectral_norm(M @ A @ inv(M))
        return Chunk(U=U, A=A, B=B, c=c, M=M, L=L, Sigma=Sigma, H=self.H)


# IP-235/236 DBB + TBE：漂移管与预算耗尽
def tube_radius(e0, L, dw, k):
    if abs(L - 1.0) < 1e-9:
        return [e0 + s*dw for s in range(k + 1)]
    return [L**s * e0 + dw*(L**s - 1)/(L - 1) for s in range(k + 1)]


def certified_horizon(chunk, budget, k_ras, k_max=64):
    eps = tube_radius(init_error(chunk), chunk.L, delta_w(chunk),
                      min(chunk.H, k_max))
    bbar, run = [], float('inf')
    for s, b in enumerate(budget[:len(eps)]):
        run = min(run, b); bbar.append(run)
    k = 0
    for s in range(len(eps)):
        if eps[s] <= bbar[s]: k = s
        else: break
    return min(k, k_ras), eps, bbar


# IP-237 CIU：块缝检验
def stitch_ok(prev, nxt, eps_k, eps_0, u_plus, u_minus, R, kappa_d):
    gap = norm(prev.x_end - nxt.x_start, prev.M)
    intersect = gap <= eps_k + eps_0
    dE = 0.5 * (u_plus - u_minus) @ R @ (u_plus - u_minus)
    return (intersect and dE <= kappa_d), gap, dE


# IP-238 DRA：漂移残差归因
class DriftResidualAttributor:
    def signature(self, r, boundary_idx):
        return (norm(mean(r)),
                norm(r[boundary_idx+1] - r[boundary_idx]),
                autocorr(r, lag=1),
                directional_alignment(r))

    def attribute(self, phi, L_hat, L_true):
        if phi[1] > self.tau_boundary: return 'H_chunk'
        if phi[0] > self.tau_bias and abs(L_hat - L_true) > self.tau_L:
            return 'H_dyn'
        if phi[2] < self.tau_white: return 'H_sensor'
        return 'H0'


# IP-239/240 ARC + CDC：CHORD 主循环
def CHORD_round(M, obs):
    x, x_meas = M.estimator.state(), M.estimator.measured()
    lam_risk, k_ras = M.ras.risk_scale_and_prefix(obs)
    chunk = M.acp.propose(x, obs)

    M.dbb.update_residual(x_meas - x)
    chunk.L = M.dbb.estimate_contraction_ucb()
    budget = M.ras.budget_along(chunk, lam_risk)
    k_dyn, eps, bbar = certified_horizon(chunk, budget, k_ras)
    k_star = min(k_dyn, k_ras)

    phi = M.dra.signature(M.dbb.window(), M.dbb.boundary())
    hyp = M.dra.attribute(phi, chunk.L, M.dbb.L_true_est)

    if M.arc.in_dwell() and not M.dbb.breached(eps[0]):
        k_exec = 0
    else:
        ok, gap, dE = stitch_ok(M.last_chunk, chunk, M.last_eps_k, eps[0],
                                M.last_u_end, chunk.U[0], M.R, M.kappa_d)
        k_exec = k_star if ok else 0
    M.arc.commit(k_exec)

    J = J_chord(J_RAS=M.jras, L_hat=chunk.L, eps=eps, k=k_exec,
                gap=gap, dE=dE, phi=phi, hyp=hyp, ver='CHORD-1')
    return J, chunk.U[:k_exec]

## 4. 推导

**引理 11（漂移管增长界）** 对误差递推 `e_{s+1} ≤ L e_s + δ_w` 展开：
```
e_s ≤ L^s e_0 + δ_w (L^s−1)/(L−1)  (L≠1)，  e_s ≤ e_0 + sδ_w  (L=1)。
```
`ε_s` 对 `s` 单调不减；`L<1` 时 `ε_∞ = e_0 + δ_w/(1−L)` 有限，`L≥1` 时无界增长。

**引理 12（相变）** `L<1` 且 `e_0 + δ_w/(1−L) ≤ inf b̄` ⇒ `k*_dyn = H`。`L≥1` 时
```
k*_dyn ≤ ⌈ log(1 + (L−1)b/δ_w) / log L ⌉。
```
块长因此在收缩系统中「免费延长」，在扩张系统中受对数硬上界约束。

**引理 13（拼接耗散）** 共享度量 `M` 且 `ΔE ≤ κ_d` 时，`V_s = e_s^T M e_s` 满足
```
V⁺ ≤ (√V⁻ + √(2ΔE))² + O(δ_w)，
```
拼接注入能量被 `κ_d` 显式记账。

**定理 11（CHORD 端到端安全性）** 在 A87–A91 与定义 253–263 下，以概率 `≥ 1−α_dyn−α_chunk−α_emotion`，
```
P(∃s≤k*: margin(x_{t+s}) < 0) ≤ α_RAS + α_dyn + α_chunk。
```
证明：`L̂` 单侧 UCB 控制低估风险；对每个 `s` 用 `ε_s ≤ b̄_s` 与并集界；再与 RAS 定理 9 合并。

**定理 12（切换稳定性）** 公共度量 `M`、`κ_d` 有界、驻留 `τ_d≥1` ⇒ 切换闭环对 `δ_w` ISS；若 `L̂<1, δ_w=0` ⇒ `e_s→0`。证明：块内 `V_{s+1} ≤ L²V_s + δ_w²`，缝处用引理 13，多 Lyapunov 函数在驻留下满足平均下降。

**推论 1（对偶线性化）** `L≈1` 时 `k* ≈ b/δ_w`；`L>1` 时退化为对数增长，说明指数不稳定系统「加预算买不到长时域」。
