# 第 69 轮（承接第 68 轮「CALM-RAS：自标定 · 自监督 · 单模型多任务的风险自适应闭环」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「末端位姿」×「分层规划」）

> 第 68 轮 CALM-RAS 用「在线标定 + 自监督 + 单模型多任务」回答了「**我的测量还准吗**」，把贯穿 R65–R67 的「测量可信度」缺失补成了一等公民。但它自陈的最大风险恰好暴露了这套范式的新盲点：**标定能力越强，落在标定带宽内的缓变故障越隐形**——COF 把慢故障当漂移「标好」，CFA 把 H_cal 后验推高，系统在「测量越来越准」的假象里失去检出能力。更根本的是，R65–R68 四轮的动作侧始终是一个「标量刹车」：ACH 出动作块、k 决定执行多少步、λ 缩放幅度。**系统从未显式回答「我到底要去哪、这一趟值不值得、失败了退到哪」**——它只有「做多少」，没有「做什么」与「退到哪」。
>
> 本轮两个灵感恰好补齐动作侧的两块拼图，核心命题：
>
> **把「末端位姿 ξ ∈ SE(3)」升格为任务层与运动层之间的「可验证契约」，把「分层规划」升格为「风险决定在哪一层重规划」的单调降级机制——HPC-RAS（Hierarchical Pose-Contract Risk-Adaptive System）。**
>
> 关键新增：末端位姿给出一条**标定无关的命令-响应残差通道** r_pose = ξ_ach − ξ_cmd，用它作「第二意见」，直接拆穿 R68 的原罪——传感器偏置能被标定吸收（r_pose ≈ 0），而执行器慢退化会被标定「吃掉」却仍在 r_pose 上现形（r_pose ≈ δ_a，且与标定修正正相关）。一句话定位：R68 问「测量准吗」，R69 问「**我按测量做的动作，真的发生了吗；若没发生，我该退到哪一层**」。

## 0. 直觉与动机

**灵感 1（末端位姿 → 任务与执行之间的「契约变量」）**
直觉：前四轮的动作是不透明的——ACH 吐动作块，k 说执行几步，λ 缩放幅度，但没有任何一个「语义变量」同时被任务层与运动层理解、又能被独立测量。末端位姿 ξ=(p,R)∈SE(3) 恰好是：任务层只关心「手该在哪」（抓取位姿、接触位姿、撤退位姿），运动层只关心「怎么过去」（关节轨迹、IK、阻抗）；而 ξ_ach 可由关节编码器经正运动学直接测出。于是 ξ 成为一个**低维、可测、可指令**的契约面：它同时支撑（a）组合式验证、（b）一条与测量标定结构独立的残差通道、（c）一个天然的安全集几何（位姿空间比全身/关节空间低维得多）。

**灵感 2（分层规划 → 风险应决定「在哪一层重规划」，而非「执行多少步」）**
直觉：R68 的认证前缀 k 是对固定计划的**标量刹车**。但真出问题时，正确反应常常是**质变而非量变**：不是「把同一件事少做一点」，而是「换目标」——放弃当前插入、把末端退到安全位姿、换个方向重新接近。这是分层规划的决策：在哪个抽象层重规划。核心洞察：**风险的类型与严重度 → 抽象层级，且单调**。局部瞬态 → 运动层重规划；持续性任务不可行 → 任务层重规划；计量层不确定 → 冻结任务层并放大位姿裕度。**风险永远只能把你推向更抽象/更保守的层级，绝不反向**。

**灵感 3（末端位姿 × 分层规划 合流 → 用位姿跟踪残差解决 R68 原罪）**
直觉：R68 的原罪是标定把慢故障「解释掉」。但标定比较的是**同一世界量的两次测量**（视觉几何 vs 触觉几何）；执行器故障不是测量分歧，而是**命令-响应分歧**：我命令 ξ_cmd，物理手却到了 ξ_ach。这条残差住在标定结构上无法吸收的通道里——因为没有什么可「标定」，手臂确实没到指令位置。再交叉验证：若 COF 标定修正 Δc 在涨、且 r_pose 同向在涨，则所谓「标定」其实在吃一个执行器故障（应升级 H_sensor^trans，禁止吸收）；若 Δc 涨而 r_pose ≈ 0，才是真正的传感器偏置（可安全吸收）。**命令-响应独立性，就是 R68 缺失的那个「第二意见」**。

**灵感 4（分层规划 → 组合式安全证书与优雅降级）**
直觉：任务层的安全可在位姿空间（6-DOF）认证，比全身/关节空间可 tractable 得多。定义位姿安全集 𝒮_pose 与位姿空间 CBF h(ξ)；任务层签发的每个契约位姿必须在 𝒮_pose 内且留裕度；运动层须认证可达性与 CBF 可行性。两层证书独立可查 → **组合即安全**。这还带来优雅降级：运动层认证不过，任务层回退到上一个已认证的安全位姿 ξ_home（「认证过的家」）。这正是「安全位姿契约」，是 R68 的 J_CALM 在规划层的对偶。

**灵感 5（对 R68 风险的对症下药）**
- R68「慢故障藏在标定带宽内」→ PDR + CFD：位姿残差标定无关，相关性检验判别传感器偏置 vs 执行器退化；
- R68「标定不确定 → 保守」→ 现在还把位姿容差 ε 放大、速度上限压低、并强制任务层冻结；
- R68「过度放宽」→ 风险→层级单调映射 + λ_pose 下限 + 契约只在 PCC 通过后下发，风险只收不放；
- R66/R67 遗留：情绪/前瞻风险现在能触发「任务层撤退」，不再只会缩短 k。

## 1. 形式化定义（增量：定义 293–308）

**定义 293（HPC-RAS 总览）** HPC-RAS = (TPL, MPL, PCC, RAL, PDR, CFD, RAS-C†)。三条不变式：
(i) **位姿契约不变式**：任何下发到运动层的指令都必须携带任务层签发的契约 κ=(ξ*, ε, h_min, id)，无契约不下发；
(ii) **抽象层级单调性**：风险只能导致向更抽象/更保守层级重规划（ℓ: motion(0) → task(1) → safe-pose(2)），未取得「风险清除证书」不得下降；
(iii) **零学习写操作 + 契约冻结**：继承 R68 影子学习纪律；CAC 提交窗口内所有契约只读冻结，换装完成前旧契约继续有效。

**定义 294（末端位姿与位姿契约）** ξ_t=(p_t,R_t)∈SE(3)，压缩表示 ξ=(p, φ)∈ℝ⁶（φ 为轴角）。契约 κ_t=(ξ*_t, ε_t, h_min_t, id_t)：目标位姿、任务容差球 ‖ξ−ξ*‖≤ε、最小安全裕度、单调递增 id。任务层输出契约序列 Ξ={κ_1,…,κ_N}。

**定义 295（任务层规划器 TPL）** TPL:(g, ctx, ρ_t)→Ξ。抽象动作集 𝒜_task={approach, grasp, insert, retreat, hold, handover, safe_retreat}。风险降级时 TPL 只能输出「同目标更保守」或「回退到已认证安全位姿 ξ_home」；禁止在风险未清除时输出更激进的契约。

**定义 296（运动层规划器 MPL）** MPL:(κ, q, env)→(τ_q, PCC_motion) 或 ⊥。约束：IK 可达、关节限位、位姿空间 CBF h(ξ(t))≥h_min、速度/加速度界、终端落在 ε 球内。MPL 不改变任务目标，只改变「怎么到」。

**定义 297（位姿跟踪残差 PDR）** r_pose,t = ξ_ach,t − ξ_cmd,t，其中 ξ_ach 由关节编码器经 FK 得到（冗余时由外部动捕二次校验），ξ_cmd 为运动层实际下发位姿。分解 r_pose=(r_pos, r_rot, r_wrench)。**标定无关性**：在 A95（编码器/FK 准确、基座系固定、标定 c 只参数化传感测量模型）下，∂r_pose/∂c=0（引理 16）。

**定义 298（慢漂移统计量）** 滑动窗 W 上：累积跟踪误差 E_t=‖∫_{t−W}^{t} r_pose,s ds‖，慢趋势斜率 ġ_pose=d/dt‖r_pose‖。执行器慢退化（摩擦增大、背隙、慢泄漏、渐进松动）表现为 ġ_pose 持续为正且与负载相关；纯测量噪声下 E[ġ_pose]≈0。

**定义 299（标定-故障判别器 CFD）** 设标定修正增量 Δc_t=ĉ_t−ĉ_{t−1}，位姿残差 r_pose,t。统计量：
C_cp = corr_W(‖Δc_t‖, ‖r_pose,t‖)（窗 W 内相关系数）。
判据（模型见引理 17）：
- C_cp < θ_c 且 ‖Δc‖ 增长 → 真实**传感器偏置**（可被标定吸收，归 H_cal）；
- C_cp ≥ θ_c 且二者同向增长 → **执行器退化被误当标定**（升级 H_sensor^trans，禁止吸收，强制 COF 修正回退）；
- 二者皆低 → 无异常。

**定义 300（风险→抽象层级映射 RAL）** 层级 ℓ∈{0=motion, 1=task, 2=safe-pose}：
ℓ*(ρ_t)=0 若风险局部瞬态（r_pose 短时小、单模态异常、U<τ_cal）；
ℓ*(ρ_t)=1 若持续性任务不可行（契约不可达、r_pose 持续超阈、归因 H_sensor^trans 或 E 高风险）；
ℓ*(ρ_t)=2 若计量层不确定（U≥τ_cal）或安全违反迫近（h(ξ)<h_min）。
单调性 + 滞回：升级即时生效；降级需「风险清除证书」且驻留时间 ≥ T_dwell。

**定义 301（位姿安全集与 CBF）** 𝒮_pose={ξ: d(ξ,𝒪_human)≥d_safe, ξ∈𝒲, ‖force(ξ)‖≤F_max}。位姿空间 CBF h(ξ)≥0 满足 ḣ+α·h≥0。契约要求 h(ξ*)≥h_min+ε_margin。

**定义 302（位姿契约证书 PCC）** PCC=(feasible, cbf_ok, tol_ok, risk_ok, ver)。运动层对每契约返回：feasible（IK+动力学可达）、cbf_ok（沿轨迹 h≥h_min）、tol_ok（终端在 ε 球内）、risk_ok（预测 r_pose 与风险预算相容）。任务层仅在 PCC=valid 后下发；PCC 带时效 ver，过期即作废（定义 306 契约过期）。

**定义 303（组合安全结构）** 安全 ⟸ 任务层契约落在 𝒮_pose 内且留裕度（TPL 保证）∧ 运动层轨迹满足 CBF 与终端容差（MPL 保证）∧ PCC 双向验证通过。任一层失败 → 沿 RAL 上卷降级（引理 18、定理 17）。

**定义 304（契约感知风险缩放 CAR-P）** λ_pose(ρ)=max(λ_floor(U), f(r_pose, ρ))；容差与速度随风险收紧：ε(ρ)=ε⁰/(1+κ_ε·risk)，v_max(ρ)=v⁰·(1−κ_v·risk)。撤退位姿 ξ_home 必须是预先认证的安全位姿，且每次使用前做一次快速 𝒮_pose 成员复核（防「安全的陷阱」）。

**定义 305（意图-执行契约一致性）** 契约违背率 V_contract=P(‖ξ_ach(T_i)−ξ*_i‖>ε_i)（逐契约 i）。分层规划须使 V_contract≤α_contract；若运动层**预测**将违背，须在违背发生前上卷到任务层重规划（前置而非事后）。

**定义 306（HPC 干扰集）** ℰ_HPC=ℰ_CALM×ℰ_pose×ℰ_hier。ℰ_pose={位姿估计漂移、FK 误差、CBF 近似误差、外部追踪失效、基座系漂移}；ℰ_hier={层级震荡、契约过期、任务/运动不一致、降级死锁、安全位姿失效}。

**定义 307（J_HPC 证书）** J_HPC=(J_CALM, pose_contract_hash, ℓ*, PCC_verdict, r_pose_stat, cfd_verdict, hpc_ver)。Valid ⇔ Valid(J_CALM) ∧ PCC=PASS ∧ ℓ* 单调一致 ∧ 契约未过期 ∧ 标定红线未越界 ∧ ξ_home 复核通过。

**定义 308（管线）** 任务层（异步 ~10 Hz）→ 契约 → 运动层（~1 kHz，CBF-QP）→ 执行；PDR/CFD 在实时流（标定无关）持续打分；每层认证失败沿 RAL 上卷。RAS-C† 继承 CALM-RAS 的 ACH/EFS/C-RAS-WM/ERS-WM/COF/CFA/CAC，只把「k 标量刹车」替换为「分层契约 + 层级映射」。

```python
# IP-254 TPL：任务层，输出带容差与安全裕度的位姿契约序列
class TaskLevelPlanner:
    def plan(self, goal, ctx, rho):
        subs = self.decompose(goal, ctx)               # approach/grasp/insert/...
        Xi = []
        for s in subs:
            xi_star = self.task_pose(s, ctx)
            h = pose_cbf.h(xi_star)
            if h < H_MIN + EPS_MARGIN:                 # 任务层安全前置
                return [Contract(self.safe_home(ctx), eps=EPS_HOME,
                                 h_min=H_MIN, id=self.next_id())]
            Xi.append(Contract(xi_star, eps=self.eps(rho),
                               h_min=H_MIN, id=self.next_id()))
        return Xi

    def replan_on_risk(self, rho, level):
        if level >= 2: return [Contract(self.safe_home(ctx), ...)]
        if level == 1: return self.plan_retreat_or_reapproach(rho)
        return self.current_Xi                          # level 0：不动任务层


# IP-255 MPL：运动层，位姿 CBF-QP，返回可行性证书
class MotionLevelPlanner:
    def solve(self, kappa, q, env):
        traj = self.ik_traj(kappa.xi_star, q, kappa.eps)
        if traj is None: return None, PCC(feasible=False, ...)
        cbf_ok = all(pose_cbf.h(xi(t)) >= kappa.h_min for t in traj)
        tol_ok = norm(xi_end(traj) - kappa.xi_star) <= kappa.eps
        risk_ok = self.predicted_pose_residual(traj) <= self.risk_budget
        return traj, PCC(feasible=True, cbf_ok=cbf_ok, tol_ok=tol_ok,
                         risk_ok=risk_ok, ver=now())

    def cbf_qp(self, q, qdot_nom):                     # 安全滤波器
        return solve_qp(cost=||qdot-qdot_nom||,
                        constraints=[hdot(xi(q)) + ALPHA*h(xi(q)) >= 0,
                                     joint_limits, vel_limits])


# IP-258 PDR + IP-259 CFD：标定无关的第二意见
class PoseDriftMonitor:
    def update(self, xi_ach, xi_cmd, dcal, window=W):
        r = xi_ach - xi_cmd
        self.buf_r.append(r); self.buf_dc.append(norm(dcal))
        g_dot = slope(self.buf_r[-window:])            # 慢趋势斜率
        E = norm(trapezoid(self.buf_r[-window:]))      # 累积误差
        C_cp = corr(self.buf_dc[-window:], [norm(x) for x in self.buf_r[-window:]])
        return r, g_dot, E, C_cp

    def verdict(self, C_cp, g_dot, E, U):
        if C_cp >= THETA_C and g_dot > 0 and E > TAU_POSE:
            return 'ACTUATOR_FAULT_ABSORBED'           # 禁止标定吸收 → H_sensor^trans
        if C_cp < THETA_C and U < TAU_CAL:
            return 'SENSOR_BIAS_OK'                    # 可安全标定 → H_cal
        return 'NOMINAL'


# IP-257 RAL：风险→抽象层级（单调 + 滞回 + 风险清除证书）
class RiskAbstractionMapper:
    def map(self, rho, U, pdr, joint_post):
        if U >= TAU_CAL or pdr.imminent_safety_violation():   return 2
        if pdr.g_dot > 0 and pdr.E > TAU_POSE:                return 1
        if joint_post.has('H_sensor^trans') or joint_post.E_high(): return 1
        return 0
    def commit_level(self, level):
        if level > self.level:  self.level = level; self.dwell = 0     # 即时升级
        elif level < self.level:
            if self.clearance_cert() and self.dwell >= T_DWELL:        # 需清证
                self.level = level
        else: self.dwell += 1


# IP-256 PCC 门控 + IP-262 主闭环
def HPC_RAS_round(M, obs):
    z, o = M.mtm.forward(obs_pack, M.a_prev, M.scene_ctx)          # R68 一次前向
    c, U, thr = M.cof.step(o['cal'], residuals(...), sigma_stat(M)) # R68 标定

    # 1) 标定无关第二意见
    r, g_dot, E, C_cp = M.pdr.update(xi_ach(M), xi_cmd(M), c - M.c_prev)
    cfd = M.pdr.verdict(C_cp, g_dot, E, U)

    # 2) 先标定后归因（R68 CFA），CFD 否决吸收
    joint_post = M.cfa(rho=M.fir_signature(z, M.residual_log), face=o['pi'], c=c, U=U)
    if cfd == 'ACTUATOR_FAULT_ABSORBED':
        joint_post = M.cfa.force_sensor_trans(joint_post)          # 禁止 H_cal 兜底

    # 3) 风险→层级
    level = M.ral.map(rho=(r, U, joint_post), U=U,
                      pdr=M.pdr, joint_post=joint_post)
    M.ral.commit_level(level)

    # 4) 分层重规划：任务层（按需）→ 契约 → 运动层认证
    if level >= 1: M.tpl.replan_on_risk(joint_post, level)
    Xi = M.tpl.current_Xi
    for kappa in Xi:
        traj, pcc = M.mpl.solve(kappa, M.q, M.env)
        if not pcc.valid():                                         # 契约上卷
            M.ral.escalate(); continue
        M.mpl.cbf_qp(M.q, traj[0])                                  # 安全滤波执行
        break

    # 5) 风险缩放（继承 EFS + 契约感知）
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'],
              M.car_p.lam_pose(joint_post, U, r))

    # 6) 异步审计 + CAC 提交（契约冻结）
    M.vqa_h.submit_async(r, (c, U), joint_post, pcc, cfd)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)          # 窗口内契约冻结
    return M.ral.level, Xi, lam, joint_post, (c, U, cfd)
```

## 3. 推导

**引理 16（PDR 的标定无关性）** 在 A95（编码器与 FK 准确、位姿残差在机器人基座系内计算、标定 c 只参数化传感测量模型）下，r_pose=ξ_ach−ξ_cmd 只依赖「指令→驱动→机构→编码器」链路，∂r_pose/∂c=0。故 COF 的任何标定修正都不能降低 r_pose：**执行器慢故障在 PDR 上始终可见**，与 U(ĉ) 无关。对照：传感器偏置 b_s 在测量空间产生残差，可被 COF 吸收，且不出现在 r_pose 中。

**引理 17（CFD 判别一致性）** 设期望任务位姿 ξ*。模型 A（传感器偏置 b）：标定估 b̂→b，指令 ξ_cmd=ξ*−b̂，物理响应 ξ_ach=ξ_cmd ⇒ r_pose≈0，Δc≈b 增长 ⇒ C_cp≈0。模型 B（执行器偏移 δ_a）：物理响应 ξ_ach=ξ_cmd+δ_a；COF 若把 δ_a 当标定 δ̂→δ_a，则 ξ_cmd=ξ*−δ̂，ξ_ach=ξ*−δ_a+δ_a=ξ*，任务目标跟踪反而「完美」，但 r_pose=ξ_ach−ξ_cmd=δ_a，且 Δc≈δ_a ⇒ C_cp≈+1。因此阈值 θ_c 可分离两模型；当 ‖δ_a‖ 超过噪声底（SNR 条件）时，判别错误概率 ≤ δ_fi+δ_cfd。系：**任务成功率高 ≠ 无故障**——模型 B 正是 R68 的盲区，PDR 是唯一暴露它的通道。

**引理 18（分层组合安全）** 若 (a) TPL 契约满足 h(ξ*)≥h_min+ε_margin 且 ξ*∈𝒮_pose；(b) MPL 轨迹满足 h(ξ(t))≥h_min 且终端在 ε 球内；(c) PCC 双向验证二者；则由 CBF-QP 的离散执行（重规划周期内保持约束）得 ξ(t) 保持在 𝒮_pose 的前向不变集内。安全由此分解为两个**独立可查**的证书，任一层失败即上卷降级。

**定理 16（HPC-RAS 端到端风险一致性）** 在 A87–A94 与 A95–A97 下：
1. P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+**α_contract+α_pose**（α_contract 由定义 305、α_pose 由引理 18）；
2. **风险→层级单调**：风险存在期间 ℓ* 非降，λ_pose≥λ_floor，ε 与 v_max 随风险收紧；不存在「不确定却放宽」的通道；
3. **R68 盲点闭合**：对执行器类慢故障，只要 ‖δ_a‖>τ_pose 持续 W，检出概率 ≥ 1−δ_fi−δ_cfd，且**与 U(ĉ) 无关**（引理 16/17）；传感器类慢偏置仍按 H_cal 正常吸收（本就安全）；
4. 组合安全：引理 18 成立时，ξ(t) 前向不变于 𝒮_pose。

**定理 17（分层降级完备性 / 无死锁）** RAL 为单调升 + 有限层级 {0,1,2} + ℓ=2 恒可行（ξ_home 已认证）。降级需风险清除证书且驻留 ≥ T_dwell，故不存在无限层级震荡；每个风险事件要么被清除证书解除（允许降级），要么在 ≤ 2·T_replan 内升至 ℓ=2（安全位姿保持）。系：**最坏情况下系统总在有限时间内到达已认证安全状态**，不会卡在「反复升降」或「等待一个永不到来的认证」。

## 6. 本轮最大风险

**一句话**：HPC-RAS 的整个「第二意见」承重在一句假设上——**r_pose 与标定结构无关（A95）**；一旦测量与执行共享同源漂移（移动底盘基座缓慢漂移、关节编码器自身慢偏置、或标定链与 FK 共用同一被污染的基座系），r_pose 会被同一污染源腐蚀，CFD 的相关性检验随之失效，R68 的「慢故障隐形」盲点便换一扇门重开——而且此时分层规划还会把系统优雅地退到一个「认证过、但世界已变」的安全位姿上，形成「安全外观下的陷阱」。

**次级风险与缓解**：
1. **安全位姿陷阱**：ξ_home 认证后环境可能改变（人移动、工件移位）→ 每次使用前做 𝒮_pose 快速成员复核 + 定期重认证（定义 304）；
2. **层级震荡/死锁**：单调 + 滞回 + 风险清除证书 + T_dwell（定理 17）；
3. **契约过期与竞态**：契约带 id 与时效 ver，CAC 窗口内冻结、双缓冲原子换装（定义 293/302/306）；
4. **CBF 近似误差**：位姿 CBF 的保守化 + 组合证书 + E290 压测；
5. **PDR 单源失效**：FK 与外部动捕冗余校验，单源失效降级为「仅保守运动」（E295）。

```python
        M.mpl.cbf_qp(M.q, traj[0]); break
    lam = max(M.efs.risk_scale(joint_post), thr['lam_floor'],
              M.car_p.lam_pose(joint_post, U, r))
    M.vqa_h.submit_async(r, (c, U), joint_post, pcc, cfd)
    M.cac.maybe_commit(M.shadow, M.time_since_last_commit)          # 窗口内契约冻结
    return M.ral.level, M.tpl.current_Xi, lam, joint_post, (c, U, cfd)
```

## 4. 推导

**引理 16（PDR 标定无关性）** A95 下 r_pose=ξ_ach−ξ_cmd 只依赖指令→驱动→机构→编码器链路，∂r_pose/∂c=0；COF 修正不能降低 r_pose，执行器慢故障在 PDR 上始终可见且与 U(ĉ) 无关；传感器偏置则只出现在测量空间、可被吸收且不入 r_pose。

**引理 17（CFD 判别一致性）** 传感器偏置 b：ξ_cmd=ξ*−b̂，ξ_ach=ξ_cmd ⇒ r_pose≈0、Δc≈b 增长 ⇒ C_cp≈0。执行器偏移 δ_a：ξ_ach=ξ_cmd+δ_a，COF 误吸收 δ̂→δ_a 后 ξ_ach=ξ*（目标跟踪反而「完美」），但 r_pose=δ_a、Δc≈δ_a ⇒ C_cp≈+1。故 θ_c 可分离两模型；SNR 足够时误判 ≤ δ_fi+δ_cfd。**系：任务成功率高 ≠ 无故障**——正是 R68 盲区，PDR 是唯一暴露通道。

**引理 18（分层组合安全）** 若 TPL 契约在 𝒮_pose 留裕度、MPL 轨迹满足 CBF 与终端容差、PCC 双向验证，则 CBF-QP 离散执行下 ξ(t) 前向不变于 𝒮_pose；安全分解为两个独立可查证书，任一层失败即上卷。

**定理 16（端到端风险一致性）** A87–A97 下：
1. `P(|τ_cmd−τ*|>ε) ≤ α_chunk+δ_fi+α_emotion+α_wm+α_vqa+α_cal+α_contract+α_pose`；
2. 风险→层级单调：风险存在期间 ℓ* 非降、λ_pose≥λ_floor、ε 与 v_max 收紧，无「不确定却放宽」通道；
3. **R68 盲点闭合**：执行器类慢故障 ‖δ_a‖>τ_pose 持续 W 时检出 ≥ 1−δ_fi−δ_cfd，且与 U(ĉ) 无关；传感器类慢偏置仍按 H_cal 安全吸收；
4. 引理 18 成立时 ξ(t) 前向不变于 𝒮_pose。

**定理 17（分层降级完备性 / 无死锁）** RAL 单调升 + 有限层级 {0,1,2} + ℓ=2 恒可行（ξ_home 已认证）；降级需清除证书且驻留 ≥ T_dwell ⇒ 无无限震荡；每事件要么被清除证书解除，要么 ≤ 2·T_replan 升至 ℓ=2。系：**最坏情况有限时间到达已认证安全态**。

## 7. 本轮最大风险

**一句话**：HPC-RAS 的整个「第二意见」承重在一句假设上——**r_pose 与标定结构无关（A95）**；一旦测量与执行共享同源漂移（移动底盘基座缓慢漂移、关节编码器自身慢偏置、或标定链与 FK 共用同一被污染基座系），r_pose 被同一污染源腐蚀，CFD 相关性检验随之失效，R68「慢故障隐形」盲点换门重开——且此时分层规划会优雅地把系统退到一个「认证过、但世界已变」的安全位姿，形成「安全外观下的陷阱」。

**次级风险与缓解**：安全位姿陷阱（每次使用前 𝒮_pose 复核 + 定期重认证）；层级震荡/死锁（单调 + 滞回 + 清除证书 + T_dwell）；契约过期/竞态（id + ver + 窗口冻结 + 双缓冲原子换装）；CBF 近似误差（保守化 + 组合证书 + E290）；PDR 单源失效（FK 与外部动捕冗余，单源失效降级为仅保守运动）。
