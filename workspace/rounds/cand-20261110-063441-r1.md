# 第 41 轮 · 二灵感落地 v18：上下文信念 × 任务导向抓取场 × 接触契约（「接触语义」横切层，四层架构 v6）

> 承接第 40 轮（v17：热预算治理 × 步数感知规划 × 学习-TO 混合轨迹）。本轮灵感词「上下文理解 / 抓取位姿估计」。联网核实（2026-11-10）后，两件事改写了问题设定：① 官方数据集已公开为 32 个逐任务 LeRobot 数据集（约 3.2 万 episodes / 169 h；头部双目 + 双腕四相机；含 EE base/torso、state_d435、state_torso 等训练期状态），32 个任务名把「接触语义」暴露无遗——ZipUp / Unlock / PlugInEthernet / PlugCharger / SyringeWaterTransfer / FoldTowel / RemovePinnedNote 等都不是通用 pick-and-place；② 提交接口仍只给静态单句语言 + 4 路 RGB + 本体，**无深度、无触觉/力、语言无时间轴，且测试观测比数据集少 state_torso/state_d435/EE_torso 等键**。v17 的盲区因此被精确定位：它把抓取当成「语义图里的一个 SE(3) 路点」，把上下文当成「静态语言 + 在线语义图」；而官方任务真正考的是**任务相关的功能部位抓取**与**从可部署观测推断隐上下文**。v18 主轴从「交付物理学」推进到「接触语义」：上下文信念（IP-51）→ 任务导向抓取场（IP-52）→ 接触契约（IP-53），把「抓哪里、为什么这样抓、抓不稳怎么办」变成可估计、可校准、可预算的显式对象。

## 1. 研究者直觉（先直觉与动机，后形式化）

**直觉 1（上下文理解 → 「官方把语言的时间轴拿走了」）**。F60 最刺眼的一条不是 4 相机，而是 language **单 str、全 episode 不变、无时间轴**。这意味着两件事：语言只配当**先验**，不能当每步条件；真正的上下文必须从观测历史与动作历史里推。32 个任务名（F59/F61）又告诉我们上下文不是抽象对话，而是**任务本体 + 相位 + 对象/功能部位 + 目标区域 + 干扰状态**的联合体。F72/F73 给出正确形态：固定大小潜记忆 + 动作历史自监督；F74/F75 给出正确目标：把上下文当 POMDP 潜变量，主动降不确定性。我的结论是：**上下文理解在本赛道 = 在只有可部署观测的条件下维护任务状态后验 b_t，而不是把静态语言喂给更大的 LLM**。并且 F61 暴露一个极关键的训练-测试错位：数据集含 state_torso/state_d435/EE_torso 等「特权状态」，提交接口没有——上下文模型必须做**特权状态蒸馏**，否则离线指标会系统性高估。

**直觉 2（抓取位姿估计 → 「32 个任务名就是 32 张抓取语义考卷」）**。粗看 Grab 类任务像通用抓取，细看任务名全是功能部位：ZipUp 拉拉链头、Unlock 转钥匙、PlugInEthernet 捏插头体插入、DisconnectEthernet 捏插头体拔出、PlugCharger 对准充电口、SyringeWaterTransfer 握针筒、RemovePinnedNote 捏图钉帽、FoldTowel 抓布角。同一个杯子在 HangCup / StackBowls / StoreCups 里抓法也不同。F67 的「切面包握刀柄 vs 递刀留手柄」把这层讲透了：**抓取位姿不是物体 6D 位姿的附赠品，而是任务、相位、下游目标共同条件的分布**。F68/F69 进一步说明开放词汇与双臂臂分配也要进这个分布。Dex1 平行夹爪只有开度 5.5→0.0（F61），所以可执行抓取还应显式含**宽度与接近方向**，而不是只回归一个 6D 末端位姿。

**直觉 3（不确定性是两词的接缝）**。上下文不确定时，正确动作往往不是硬猜，而是**多看一眼**；但「看一眼」要花步数、时延、热预算（v17 的 Δ-Plane）。F71 的校准能量模型与 F70 的 affordance 信息增益正好拼成可执行方案：抓取场给校准分布，主动视角按「单位预算的信息增益」选。这样「上下文理解」与「抓取位姿估计」不是两个模块，而是**同一个信念-信息回路**：信念决定抓取分布，抓取分布的不确定性决定是否主动感知，观测再回写信念。

**直觉 4（接触契约 → 不要再加一个大模型，而是加一个接口）**。v17 已经把热/时延/步数做成资源平面，v18 若再加一个端到端大模型，复杂度必爆。正确做法是加一个**薄契约层**：把「上下文信念 + 抓取场」压成 `(g*, Σ_g, q*, m*, κ, fallback)`，分别喂给 IP-49 的成功率先验、IP-50 的终端/预抓取约束、IP-24 的失败签名与 IP-48 的预算。契约三查——**可执行（IK/碰撞）、稳定（力闭合/对跖余量）、任务一致（功能部位不被破坏）**——任何一查不过就按固定顺序降级。它既是精度抓手，也是安全兜底，还是不增加核心模型数的架构胶水。

**直觉 5（修剪 → 数据公开不是让你多训，而是让你少建）**。v17 仍背着跨本体运动（IP-42）、物理增广（IP-26）、三阶段蒸馏（IP-44）、独立 SLO（IP-25）、独立立体定位（IP-31）、独立 CTC 进度（IP-28v2）。现在官方只有单一人形 G1/Dex1、32 任务数据公开（F61），这些「能力展示型」设计的边际得分很低：跨本体无测试价值；物理增广依赖未核实的 URDF；三阶段蒸馏的数据瓶颈因 169 h 公开数据而缓解；SLO/立体/CTC 已分别被 Δ-Plane、抓取场、上下文信念吸收。**本轮把其中四项降级/合并，把复杂度预算让给接触语义三件套。**

## 3. 形式化直觉（严格版见产物区 §3）

**定义 29（任务上下文信念）**：令任务本体 `T={τ_1..τ_32}`，隐上下文 `c_t=(τ, φ_t, {o_i, part_i, p_i}, γ, ξ_t)`，其中 φ 为相位（approach/grasp/transport/insert/release…），o_i 为物体实例，part_i 为功能部位，p_i 为 6D 位姿，γ 为目标区域，ξ 为干扰/人状态。信念 `b_t(c)=P(c_t=c | o_{1:t}, a_{1:t-1}, l)`，更新为
`b_t(c) ∝ O(o_t|c) · Σ_{c'} T(c|c', a_{t-1}) · b_{t-1}(c')`，
语言只进先验：`b_0(c) ∝ φ_0(c; l) · p(o_0|c) · p(γ|τ,l)`。**关键性质**：因 l 无时间轴，`t>0` 不再有语言似然项，所有时序信息来自视觉/本体/动作历史；因此「上下文理解」必须由记忆与信念更新承担，而非每步重读语言。漂移检测用预测惊奇 `D_t = -log p(o_t|o_{1:t-1},l)` 或信念熵 `H(b_t)`；超过自适应阈值即触发重锚定/主动感知。

**定义 30（任务导向抓取场）**：抓取 `g=(R,t,w,ν) ∈ SE(3) × [0,w_max] × A`，w 为夹爪开度，ν 为接近方向。任务/上下文条件能量 `E_θ(g | b_t) = E_geo(g; scene) + E_task(g; b_t, τ, γ) + E_part(g; part)`，抓取分布 `p(g|b_t)=exp(-E_θ(g|b_t))/Z(b_t)`。**任务一致约束**：若抓取接触/遮挡功能部位 `part` 或破坏下游 γ，则 `E_task=∞`（硬拒绝）；校准要求 `P(success | g,b_t) = σ(-E_θ(g|b_t))` 在留出集上 ECE≤ε。该分布既替代「物体 6D 位姿 + 对跖采样」，也输出不确定性给主动感知。

**定义 31（接触契约）**：`C=(g*, Σ_g, q*, m*, κ, fallback)`，其中 `g*=argmax_{g∈top-k} q_θ(g|b_t)`，`q*=q_θ(g*|b_t)`，`Σ_g` 为校准抓取协方差，`m*` 为含位姿/深度不确定性的鲁棒间隙（`m*=min_{δ∈E_{Σ_g}} clearance(g*⊕δ, scene)`），`κ∈{0,1}` 为任务一致标志。**三查**：可执行（存在无碰撞 IK 到预抓取/抓取）、稳定（Dex1 平行夹爪对跖 + 摩擦锥余量）、任务一致（功能部位未被抓取面遮挡/挤压）。任一不过 → 按 `fallback` 降级：top-k 重采样 → 主动视角 → 换功能部位 → 双臂换手 → v17 通用抓取。契约是 IP-51/52 与 IP-49/50/24/48 之间唯一的数据接口，保证新增两模块不穿透旧架构。

**定义 32（预算化主动感知）**：感知动作 `a∈A_sense`（腕相机小幅移动/躯干微调/换视角）。信息增益 `IG(a)=H[p(g|b_t)] − E_{o'~p(o'|a,b_t)} H[p(g|b_{t+1})]`；选择
`a* = argmax_a IG(a) / (c_s·N_steps(a) + c_l·L(a) + c_h·H_thermal(a))`，
仅当 `IG(a*)/cost > θ_IG` 且 Δ-Plane 剩余预算允许时执行。如此「多看一眼」严格是**投资决策**，不是无条件多视图。

**定义 33（上下文-抓取联合得分）**：v17 的期望得分推广为
`E_score(π) = Π_{s∈π} p_s(s | b_t, C_s) · g(N_steps) − λ·P(fail | π)`，
其中 `p_s(s|b_t,C_s)` 以契约成功率 q* 与任务一致 κ 为先验，`P(fail)` 由上下文漂移率与抓取校准误差上调。规划器在 `E_score` 的**下置信界**（扣校准误差 ε 与信念熵）上优化，避免用虚高 q* 赌单点。

## 4. 关键决断

1. **上下文即信念**：静态语言只做先验；上下文 = 可部署观测下的任务状态后验 b_t；记忆（固定大小）与漂移检测是必需件，不是附加件。
2. **抓取即任务分布**：不做「物体 6D + 对跖采样」，做「任务/相位/功能部位条件的 SE(3)×开度×接近向分布」，并把校准与臂分配纳入。
3. **契约即接口**：用薄契约层连接感知与规划/TO/监控/预算；三查 + 固定降级链，保证新增能力不穿透旧架构、最坏不劣于 v17。
4. **感知即投资**：主动视角按单位预算信息增益决策，开销入 Δ-Plane；拒绝「先重建整个场景再说」。
5. **修剪四项**：跨本体、物理增广、三阶段蒸馏、双 SLO/双立体/双 CTC 合并——把复杂度预算兑给接触语义三件套。

## 5. 本轮最大风险（一句话）

**若功能部位在测试分布外无法从 RGB/双目稳定定位、若抓取场在 Dex1 平行夹爪上的校准（尤其开度 5.5→0.0 的量化与摩擦）失效、若提交相机与数据集头部双目并非同一标定——上下文-抓取-契约三段会退化为三个互不校准的置信度；必须以 E73（上下文/相位与漂移检测）+ E74（任务导向抓取离线/真机）+ E75（契约与预算化主动感知）+ E76（特权状态蒸馏）+ E77（抓取-TO 精度）+ E78（v17 vs v18 端到端）六重守门，任一失败即回退到 v17 的通用抓取/TO 路径（契约降级为纯几何可行性检查）。**

### 5.1 IP-51 CONTEXT-BELIEF（上下文信念，完整设计）

**IP 卡片（六字段）**
- **动机**：F60 语言静态无时间轴；F59/F61 的任务集是 32 类接触语义；F61 暴露训练-测试特权状态错位（数据有 state_torso/state_d435/EE_torso，测试无）。F72/F73 证明固定潜记忆与动作历史是长时程上下文的有效载体；F74/F75 证明上下文应作为 POMDP 潜变量主动推断。
- **与现有方案差异**：不是「长上下文 LLM」也不是「每步重读语言」；是**任务本体约束下的可部署观测信念**，显式含相位、功能部位、目标区域、干扰状态，并做特权状态蒸馏。与 Mem4Act/CAMP 的差异：它们不区分训练特权状态，也不把 32 任务本体作为结构先验。
- **技术可行性**：固定大小潜记忆（256–512 slots）在 30 Hz 控制下更新 <5 ms；32 任务本体是有限集合；相位弱标签来自演示时间/夹爪开合/CTC（IP-28v2 合并）；特权状态在训练时可用，学生只吃可部署键。
- **所需资源**：32 个公开数据集（F61）；冻结 VLM/视觉编码器特征；一个轻量时序记忆模块；无额外人工标注（功能部位用 VLM 弱标签 + 演示接触段）。
- **落地步骤**：① 建 32 任务本体与相位模式（每任务 4–8 相位）；② 训练潜记忆（语义 QA + 关键帧重建 + 动作历史重建三头）；③ 训练相位头与预测惊奇/熵头；④ 特权状态教师 → 可部署学生蒸馏；⑤ 漂移触发接入 IP-49/IP-52。
- **风险**：任务 ID 过拟合（→ 留出任务/物体切分，禁止把 τ 当 one-hot 直接喂策略）；语言捷径（→ 训练时随机遮蔽语言，强制视觉/动作历史贡献）；相位标签噪声（→ CTC 软对齐 + 多任务平滑）；特权蒸馏不彻底（→ E76 专测）。

**算法（信念更新 + 漂移触发）**
```
输入：可部署观测 o_t=(4 RGB, 双臂/夹爪/lower_body/EE base), 动作历史 a_{1:t-1}, 静态语言 l
1. 特征：z_t = FrozenVLM(o_t) ⊕ proprio(o_t) ⊕ GripperSignal(o_t)
2. 记忆：m_t = MemoryUpdate(m_{t-1}, z_t, a_{t-1})        # 固定 512 slots
3. 先验（仅 t=0 用语言）：b_0 ∝ TaskPrior(l) · ObjectPrior(o_0);  t>0 无语言项
4. 预测：ĉ_t, Σ_t = Transition(m_{t-1}, a_{t-1});  o_t 的预测分布 p(·|m_{t-1},a_{t-1})
5. 更新：b_t ∝ O(o_t | c) · N(c; ĉ_t, Σ_t) · b_{t-1}
6. 漂移：D_t = -log p(o_t|m_{t-1},a_{t-1}); H_t = H(b_t)
   若 D_t > δ_adapt 或 H_t > h_max：置 re_ground=True，通知 IP-49 软重规划 + IP-52 重算抓取场
7. 输出：τ̂, φ̂_t, {part_i}, γ̂, ξ̂_t, D_t, H_t, m_t
```
**正确性论证**
- **P51（静态语言零时序信息）**：因 `I(l; c_t | c_0, o_{1:t}, a_{1:t-1}) = 0`，任何依赖 `l` 的每步时序推断都不增加上下文信息；故 b_t 必须由观测/动作历史更新。这解释了为什么 v18 把语言降为先验是**信息论上正确**而非工程偷懒。
- **P52（贝叶斯更新最优性）**：若 T、O 与初始先验正确，定义 29 的递归即贝叶斯滤波，b_t 是 `P(c_t|o_{1:t},a_{1:t-1},l)` 的精确后验；近似误差只来自记忆压缩与模型误差。
- **P53（漂移检测受控）**：若预测分布校准（ECE≤ε），则阈值 δ 下误报率 ≤ α；漂移触发只会增加感知/重规划预算，不直接改动作，故最坏情况由 IP-48 预算与 IP-33 守护兜底。
- **复杂度**：记忆 O(1)（固定 slots），相位头 O(|T|)，整体 <5 ms/步；仅在漂移/相位切换时触发重计算。

### 5.2 IP-52 TASK-GRASP-FIELD（任务导向抓取场，完整设计）

**IP 卡片（六字段）**
- **动机**：32 任务名（F59/F61）显示功能部位抓取是主线；F67 证明同一物体因任务不同抓点不同；F68/F69 证明开放词汇与双臂臂分配应进抓取生成；F70/F71 证明 affordance 信息增益与校准能量可实现预算化主动感知；F60 测试无深度、无触觉，Dex1 开度 5.5→0.0（F61）。
- **与现有方案差异**：不是「物体 6D 位姿 + 对跖采样」，也不是 2D 平面抓取；是**任务/相位/功能部位条件的 SE(3)×开度×接近向分布**，含校准、臂分配、预算化视角；与 TGrasp6D 的差异：我们把抓取分布直接接入规划得分与 TO 契约，形成闭环，而非只输出单次抓取。
- **技术可行性**：头部双目已校正（F61）可做伪深度/点云；双腕相机补近距遮挡；32 任务各 ~1k 演示可提取抓取接触段；能量场/条件流模型在 SE(3) 上采样 32–64 候选，top-k 精修毫秒–十毫秒级；校准用温度缩放/等渗回归。
- **所需资源**：公开数据 + 双目 + 腕相机；Dex1 几何（夹爪指宽/开度）；无触觉/力 → 稳定性代理用几何对跖 + 夹爪开度 + 视觉接触；功能部位弱标签用 VLM（F67 形态）+ 演示接触段。
- **落地步骤**：① 从演示提取抓取段（夹爪闭合起始/接触前后）与 EE 相对物体位姿；② 训练条件能量场（任务/相位/part 条件）；③ top-k 采样 + 碰撞/可达精修；④ 校准到成功率；⑤ 双臂臂分配头（F69 形态）；⑥ 主动视角策略（F70/F71 形态）；⑦ E74/E75 验收。
- **风险**：演示抓取标签噪声（→ 多假设 + 置信过滤）；测试相机与数据集标定不一致（A39 → E73 标定/退化单目）；Dex1 开度量化/摩擦未知（→ E74 真机辨识 + 保守开度）；功能部位 OOD（→ 开放词汇 + 多假设 top-k + 主动视角）。

**符号表**

| 符号 | 含义 | 来源 |
|---|---|---|
| g=(R,t,w,ν) | 抓取位姿、开度、接近方向 | 定义 30 |
| part | 功能部位/affordance | IP-36 + VLM |
| E_geo, E_task, E_part | 几何/任务/部位能量 | 定义 30 |
| q_θ(g|b_t) | 校准抓取成功率 | 定义 30 |
| Σ_g | 抓取后验协方差 | 能量场/集成 |
| A_arm | 左/右/双臂分配 | F69 |
| IG(a) | 感知动作信息增益 | 定义 32 |

**算法（抓取场 → 契约）**
```
输入：b_t=(τ̂,φ̂,{o_i,part_i,p_i},γ̂), 双目/腕 RGB, 语义图, 预算 knobs
1. 几何：D_stereo = StereoDepth(head_left, head_right);  P = fuse(D_stereo, wrist RGB, p_i)
2. 条件：cond = (τ̂, φ̂, part_i, γ̂, 下游技能 s_next)
3. 能量场：在 SE(3)×[0,w_max]×A 采样/去噪 top-k 候选 {g_j}
   E_θ(g_j)=E_geo(g_j;P)+E_task(g_j;cond)+E_part(g_j;part_i)
   硬拒绝：接触功能表面/遮挡 γ/与场景碰撞
4. 精修：对 top-k 做 IK、自碰撞、URDF/包络（IP-35/36）精修
5. 校准：q_j = σ(-E_θ(g_j))，按留出集温度/等渗校准
6. 臂分配：a_j = ArmAlloc(g_j, 双臂可达性, 协同约束)    # F69
7. 若 max_j q_j < q_min 或 margin < m_min：
      a_sense = argmax IG(a)/cost(a)（定义 32）；若预算允许 → 返回感知动作
8. 输出 top-k (g_j, Σ_j, q_j, κ_j, a_j) → IP-53 契约
```
**正确性论证**
- **P54（校准 top-1 增益）**：若 q_θ 在留出集 ECE≤ε，则 `E[success(g*)] ≥ max_g P(success|g) − ε`；抓取场把「选哪个抓取」变成可校准排序，而非不可解释的回归。
- **P55（任务一致性）**：硬拒绝 `E_task=∞` 保证输出抓取不接触功能表面、不遮挡目标区域；因此契约 κ=1 时抓取与下游任务兼容（在几何模型准确的前提下）。
- **P56（规划增益）**：把 q* 作为 IP-49 的 p_s 先验，使 E_score 对抓取失败风险敏感；若 q* 校准，E_score 是期望得分的无偏估计（扣 ε 下界）。
- **复杂度**：采样 32–64 + top-k 精修 O(k·d²)，<10 ms/次；仅在相位切换/漂移/失败时重算，非每步。

### 5.3 IP-53 CONTACT-CONTRACT（接触契约，完整设计）

**IP 卡片（六字段）**
- **动机**：IP-51/52 输出的是分布，而 IP-49/50/24/48 需要的是可消费的确定性接口；没有契约层，三个模块会互相穿透，复杂度回潮。契约也是「抓取失败可诊断」的关键：失败签名要能区分抓点错、宽度错、接近向错、上下文漂移。
- **与现有方案差异**：文献多输出单个抓取或策略动作；我们把抓取分布压成**三查证书 + 校准成功率 + 鲁棒间隙 + 固定降级链**，并作为跨层唯一数据接口。
- **技术可行性**：三查都是轻量几何/运动学检查（IK、碰撞、对跖/摩擦锥、功能部位遮挡），O(k)；校准与协方差来自 IP-52；降级链复用 v17 通用抓取/TO，无需新模型。
- **所需资源**：URDF/几何（A17 未决 → 缺失时用软限位 + 包围盒包络）；Dex1 开度范围；URDF 自碰撞或 MuJoCo（IP-35）；无触觉 → 稳定性用几何代理，契约只作先验不作保证。
- **落地步骤**：① 定义契约结构与三查；② 接 IP-52 top-k；③ 接 IP-49 p_s 与 IP-50 终端约束；④ 接 IP-24 失败签名；⑤ 固定降级链与预算申报；⑥ E75/E77 验收。
- **风险**：URDF 缺失使自碰撞/稳定性检查退化（→ 包围盒 + 保守间隙 + 小增益）；校准误差使 q* 虚高（→ 下置信界 + E74 校准门）；降级链过长导致步数浪费（→ 每级最多一次，失败即上报 IP-24）。

**契约定义**
```
C = (g*, Σ_g, q*, m*, κ, a_arm, fallback)
g*  : 选中的抓取 (R,t,w,ν)
Σ_g : 抓取后验协方差（含深度/位姿不确定性）
q*  : 校准成功率 q_θ(g*|b_t)
m*  : 鲁棒间隙 = min_{δ∈E_{Σ_g}} clearance(g*⊕δ, scene)
κ   : 任务一致标志（功能部位未被接触/遮挡、目标区域可达）
a_arm: 左/右/双臂
fallback: [top-k 重采样, 主动视角, 换功能部位, 双臂换手, v17 通用抓取]
```
**三查**
1. **可执行**：∃ 无碰撞 IK 到预抓取与抓取；关节/速度/力矩限位；pivot/躯干可达。
2. **稳定**：Dex1 平行夹爪对跖条件 + 摩擦锥余量；开度 w 在 [w_min+ε, w_max−ε]；接近向 ν 与表面法向夹角 ≤ θ_max。
3. **任务一致**：抓取接触区域 ∩ 功能表面 = ∅；抓取后位形不遮挡 γ；下游插入/放置方向可行。

**降级链（固定顺序，保证不劣化）**
```
if 三查全过 and q*≥q_min and m*≥m_min: 返回 C
else:
  1. top-k 中下一个通过三查的 g → 重发契约
  2. 若 top-k 全败但预算允许 → 主动视角（定义 32）→ 回 IP-52
  3. 换功能部位（part 的次优假设）→ 回 IP-52
  4. 双臂换手（另一臂可达且协同约束允许）→ 回 IP-52
  5. v17 通用抓取/TO 路径（仅几何可行性检查）→ 保底
```
**正确性论证**
- **P57（契约可靠性）**：若三查的几何/运动学模型准确，则通过契约的抓取可执行且稳定；任务一致检查保证不破坏功能部位。模型误差由 m* 的鲁棒间隙与 CBF/MuJoCo 兜底吸收。
- **P58（不劣化）**：降级链末位是 v17 通用抓取/TO，故 v18 的最坏情况不劣于 v17；额外收益来自前三级的任务一致抓取与主动感知。
- **P59（可诊断）**：失败签名四类（抓点/宽度/接近向/上下文漂移）与契约字段一一对应，IP-24 可直接定位并写失败记忆库，避免 v17「抓取失败=笼统失败」。
- **复杂度**：三查 O(k)；降级最多 4 次；总开销 <5 ms（不含主动视角运动）。

### 5.5 训练/服务伪代码（v18 增量版）

```python
# ===== 离线：32 任务本体 + 相位模式 =====
TASKS = load_task_ontology("unibot_v1_32")          # F59/F61 任务名
PHASES = {t: load_phase_schema(t) for t in TASKS}   # approach/grasp/.../release

# ===== 离线：特权状态教师 → 可部署学生（IP-51）=====

    model = calibrate(model, heldout=split_by_object(datasets))

# ===== 运行期：上下文-抓取-契约主循环 =====
def act_v18(obs, state):
    # 1. 上下文信念（只用可部署观测）
    b = state.context.update(obs.images, obs.proprio, obs.language, state.actions)
    if b.surprise > DELTA or b.entropy > H_MAX:
        b = state.context.re_ground(obs)          # 重锚定对象/部位/目标
        state.need_plan = True
    # 2. 相位与预算
    knobs = governor(state.ledger, sense_budget=b.expected_sense_cost)
    # 3. 抓取场（相位切换/漂移/失败时重算）
    if state.need_grasp or state.phase_changed:
        gf = task_grasp_field(b, state.semantic_map, stereo=stereo_depth(obs), budget=knobs)
        contract = make_contract(gf, b, K=8)
    # 4. 低置信 → 预算化主动感知
    if contract.q < Q_MIN or contract.margin < M_MIN or b.entropy > H_SENSE:
        a_sense = choose_sense(contract, b, budget=knobs)
        if a_sense is not None:
            return sense_action(a_sense)          # 动作即小幅移动腕/躯干
        contract = contract.fallback_first()      # 预算不足 → 降级
    # 5. 规划 + TO（契约条件）
    if state.need_plan:
        state.plan = step_efficient_planner(b, contract, state.semantic_map,
                                            state.failure_memory, budget=knobs)
    task = midlevel(state.plan, contract, budget=knobs)
    warm = stream_policy_head(state.plan.skill, obs)
    refined = hybrid_to(task, warm, contact=contract, envelopes=state.semantic_map.objects,
                        f_track=state.f_track)
    if refined is None:
        refined = warm
    # 6. 执行 + 守护
    chunk = refined.next_chunk(knobs.T_a)
    if not guard.cbf_check(chunk):
        chunk = resample_or_fallback(state, r=2)
    q_cmd = adapt(chunk, control_space=state.control_space)
    # 7. 失败 → 契约诊断 + 记忆
    if failure_monitor(obs) > TAU_FAIL:
        state.failure_memory.log(contract, b, sig=classify_failure(obs, contract))
        state.need_plan = True
        state.need_grasp = True
    return q_cmd
```

## 8. 清单迭代规则（继承 27–51 + 本轮新增 52–56）

- 继承规则 27–51（通道诚实/映射验证/SLO/fail-safe/灵感-现实校验/单模型合规/步骤分双解释/稠密监督/方法论遗产/元数据重照亮/语言口径分离/摊销/验证器分级/灵感词落地/层级联合规划/跨本体运动/流式韵律/渐进蒸馏/服务化/证书化/组合代数/热预算/期望得分/学习-TO/修剪优先）。
- **52（新增）：上下文即信念原则**——静态语言只作先验；上下文必须由可部署观测/动作历史维护为 POMDP 信念；训练-测试特权状态差必须显式蒸馏；漂移检测触发重锚定而非每步重读语言。
- **53（新增）：任务导向抓取原则**——抓取输出是任务/相位/功能部位条件的 SE(3)×开度×接近向分布，不是物体 6D 位姿的附赠品；必须校准、含臂分配、可被契约消费。
- **54（新增）：接触契约原则**——感知与规划/TO/监控/预算之间只通过 `(g*,Σ_g,q*,m*,κ,fallback)` 契约连接；三查（可执行/稳定/任务一致）+ 固定降级链 + 末位 v17 保底。
- **55（新增）：不确定即投资原则**——主动感知按单位预算信息增益决策，开销入 Δ-Plane；禁止无条件多视图/全场景重建；每次 episode 感知次数有硬上限。
- **56（新增）：数据公开=少建原则**——公开数据用于减少模块与标注依赖（合并重复 SLO/立体/CTC，挂起跨本体/物理增广），不得以「数据多了」为由扩张模型数；P0 核心 ≤6。

**本轮最大风险一句话**：功能部位定位、Dex1 抓取校准、相机标定三者只要有一个在测试分布外失效，「上下文-抓取-契约」就会退化为三个互不校准的置信度——E73–E78 六重守门任一失败，即按「契约→抓取→上下文」的倒序回退，最终保底 v17 通用抓取/TO。

**当前最值得押注**：**IP-52 TASK-GRASP-FIELD（任务导向抓取场）**——它同时被官方 32 任务名单、F67–F71 四条外部证据和 v17 的 TO 精度瓶颈三方指向，且可被 E74 一个实验快速证实/证伪：先在公开 32 数据集上把「功能部位抓取成功率」与「q* 校准 ECE」打出来，再接 IP-53 契约与 IP-50 的插入/堆叠精度。上下文（IP-51）与契约（IP-53）都围绕它的输出做条件与兜底；若只允许保留一条新线，就保留它。
