### 第 1 轮灵感驱动研究记录

**灵感词**：流匹配策略、隐私保护

**直觉与动机**：
前几轮已经把「安全」做成了证书体系：KEMPC 保证动力学可行，KC/DCC 保证常识与动态一致性，KACG 把安全准入变成可验证的合取门。但这套体系默认「策略本身」是可信的——而策略往往从大量机器人轨迹中学习，轨迹里含有敏感信息：工厂布局、人类工位位置、操作员习惯，甚至可由动作序列反推的摄像头视野。于是出现一条被忽视的裂缝：**证书越强，越要求把策略与轨迹交给验证器，隐私泄漏面反而越大**。

一个具体的直觉例子：某仓储机器人在夜班学会了一条绕开「只有夜班才出现的清洁工」的路线。流匹配策略会把这条稀有轨迹记进速度场；攻击者只需查询若干状态下的动作，就能用成员推断判断「该清洁工是否在训练集中」，甚至重建其常驻区域。传统 DP-SGD 只保证参数层面的样本级隐私，却无法直接回答「生成出来的这条动作轨迹到底泄漏了多少」。

流匹配策略（Flow Matching Policy, FMP）给出了一条新路径：学习速度场 v_θ(x,t,s)，把高斯噪声沿 ODE 从 t=0 输运到 t=1 的动作分布。相比扩散策略，FMP 采样是确定性 ODE、步数少、轨迹平滑，且整条生成路径**可微、可逆、可做精确似然**。这三个性质恰好是隐私保护需要的：
1) 可微 ⟹ 可沿流时间反传并分配隐私噪声；
2) ODE 的 Lipschitz 稳定性 ⟹ 训练样本的微小影响在输出轨迹上有可计算的放大界（Grönwall 界），得到「轨迹级敏感度」而非黑箱参数敏感度；
3) 可逆/精确似然 ⟹ 可用连续归一化流密度做更紧的 Rényi DP 记账，并支持「可证明遗忘」（certified unlearning）。

**关键洞见**：把隐私预算当作与力矩、能量同级的「资源约束」，沿流时间 t∈[0,1] 做最优分配——在流映射放大系数大的方向/时段注入噪声，能以更小的采样扰动换取同样的隐私；再用「流敏感度证书」把隐私噪声对动作分布的影响（Wasserstein 距离）与既有安全证书连接起来。这样隐私不再是训练后的补丁，而是与 KEMPC/KC/DCC 并列的第九类证书。

**威胁模型（必须先说清）**：
- **T1 训练集隐私**：成员推断、稀有轨迹重建。对策：DP-SGD 训练速度场 + 流敏感度证书；
- **T2 部署期状态隐私**：其他机器人或窃听者由发布动作反推本机敏感状态（如人类位置、工位布局）。对策：沿流时间的局部 DP（local DP）噪声调度；
- **T3 联邦梯度泄漏**：多机协同训练时梯度可被反演。对策：安全聚合 + 本地 DP。

**与既有框架的关系**：
- **在流匹配策略上**：定义带时变噪声的随机速度场 ṽ_θ(x,t,s)=v_θ(x,t,s)+σ(t)ξ(t)，σ(t) 为隐私噪声调度；
- **在隐私保护上**：T1 用 RDP 沿训练步复合，T2 用 RDP 沿流时间复合，T3 用安全聚合把原始轨迹留在本地；三者在同一人同时出现在训练集与部署场景时按基本复合合并；
- **在证书体系上**：新增 FSC（流敏感度证书）、PC（隐私证书）、FMPC（策略保真证书），并把 PUCG 作为 KACG 的隐私扩展，保持 Exec_v28 ⊆ Exec_v27。

**形式化目标**：
1. 定义流匹配策略 π_θ(a|s)：a(1)=Φ_θ(a(0),s)，其中 da/dt=v_θ(a,t,s)，a(0)~𝒩(0,I)；
2. 定义邻接数据集 D≃D'（恰好一条轨迹不同）与轨迹级敏感度 Δ_traj = sup_{D≃D'} W_1(π_θ(·|D), π_θ(·|D'))；
3. 定义流敏感度证书 FSC：若 v_θ 对状态 L-Lipschitz、对参数/数据扰动上界 Δ_v，则 Δ_traj ≤ ((e^L−1)/L)·Δ_v，并给出 Euler 离散积分下的紧化版本；
4. 定义时变噪声调度 σ(t) 与线性化基本解矩阵 Φ(1,t)，把输出扰动写成 ∫₀¹ Φ(1,s)Σ(s)Φ(1,s)ᵀ ds，并将调度化为半定规划（SDP）或水填充问题；
5. 定义隐私证书 PC：PC_train 的 DP-SGD RDP 记账、PC_local 的流时间 RDP 记账，复合后转换到 (ε,δ)-DP；
6. 定义策略保真证书 FMPC：W_1(π_θ,π_expert) ≤ η，且生成动作满足 KEMPC 的动力学/几何约束；
7. 构造隐私-效用证书门 PUCG：KACG ∧ PC(ε≤ε_max) ∧ FMPC(η≤η_max)，证明 Exec_v28 ⊆ Exec_v27，并给出预算耗尽/敏感度超界时回退到非学习型 KEMPC 保守控制的降级路径；
8. 设计联邦流匹配：各机器人本地训练 v_θ^i，用安全聚合求均值，本地加 DP 噪声，给出跨机器人复合隐私界。

**本轮最大风险**：FSC 的紧致性完全依赖 Lipschitz 常数 L 与敏感度上界 Δ_v 的估计，在高维动作空间中这两者都极易被低估，导致隐私证书「形式成立、实际泄漏」；同时沿流时间注噪可能抹平多模态动作分布的长尾模式，使策略在罕见但关键的场景退化，与既有安全证书产生冲突。

### IP-465 Flow Matching Policy (FMP)

```python
@dataclass
class FlowMatchingPolicy:
    """π_θ(a|s): da/dt = v_θ(a,t,s), a(0)~N(0,I), a(1)~π_θ(·|s)"""
    velocity: nn.Module
    K: int = 8
    noise_schedule: Callable = None   # σ(t)，None 表示无隐私噪声

    def sample(self, state: Tensor, generator: torch.Generator = None) -> Tensor:
        x = torch.randn(self._action_dim(state), generator=generator)
        h = 1.0 / self.K
        for k in range(self.K):
            t = k * h
            v = self.velocity(x, t, state)
            if self.noise_schedule is not None:
                sigma = self.noise_schedule(t)
                v = v + sigma * torch.randn_like(v, generator=generator)
            x = x + h * v
        return x

    def log_prob(self, action: Tensor, state: Tensor) -> Tensor:
        """连续归一化流精确似然：log p(a(1)) = log p(a(0)) − ∫ div v dt"""
        x, logdet = action, 0.0
        h = 1.0 / self.K
        for k in reversed(range(self.K)):
            t = k * h
            with torch.enable_grad():
                x = x.detach().requires_grad_(True)
                v = self.velocity(x, t, state)
                div = torch.autograd.grad(v.sum(), x, create_graph=False)[0].sum(-1)
            x = x - h * v.detach()
            logdet = logdet + h * div
        return self._base_log_prob(x) + logdet
```

### IP-466 Flow Sensitivity Certificate (FSC)

```python
@dataclass
class FlowSensitivityCertificate:
    """把参数/数据敏感度翻译为轨迹敏感度；连续与离散两种界"""
    L: float                 # v_θ 对 x 的 Lipschitz 常数（谱范数估计）
    delta_v: float           # 速度场敏感度上界
    K: int = 8
    margin: float = 1.10     # 保守放大，抵消 Lipschitz 估计误差

    def continuous_bound(self) -> float:
        if abs(self.L) < 1e-9:
            return self.delta_v
        return (math.exp(self.L) - 1.0) / self.L * self.delta_v

    def discrete_bound(self) -> float:
        if abs(self.L) < 1e-9:
            return self.delta_v
        growth = (1.0 + self.L / self.K) ** self.K
        return (growth - 1.0) / self.L * self.delta_v

    def verify(self, measured_delta_traj: float) -> bool:
        return measured_delta_traj <= self.margin * self.discrete_bound()
```

### IP-467 Privacy Certificate (PC)

```python
@dataclass
class PrivacyCertificate:
    """PC = compose(PC_train, PC_local)；两条链路分别对应 T1 与 T2"""
    alpha_orders: list = field(default_factory=lambda: [2,4,8,16,32,64])
    train_rdp: dict = field(default_factory=dict)   # 训练步 RDP
    local_rdp: dict = field(default_factory=dict)   # 流时间 RDP
    delta: float = 1e-5

    def total_rdp(self, alpha: float) -> float:
        return self.train_rdp.get(alpha, 0.0) + self.local_rdp.get(alpha, 0.0)

    def epsilon(self) -> float:
        best = float('inf')
        for a in self.alpha_orders:
            eps = self.total_rdp(a) + math.log(1.0 / self.delta) / (a - 1.0)
            best = min(best, eps)
        return best

    def verify(self, eps_max: float) -> bool:
        return self.epsilon() <= eps_max and self.delta <= self.delta_max


def dp_sgd_rdp(steps: int, clip: float, batch: int, sigma: float,
               alphas: list) -> dict:
    """T1：每个训练步的 Gaussian 机制 RDP 上界，按步复合"""
    out = {}
    for a in alphas:
        per_step = a * (clip / batch) ** 2 / (2.0 * sigma ** 2)
        out[a] = steps * per_step
    return out


def flow_time_rdp(g: list, sigma_t: list, delta_s: float, alphas: list) -> dict:
    """T2：沿流时间 K 个注入点复合；g_k 为第 k 步噪声到输出的放大系数"""
    out = {}
    for a in alphas:
        cost = 0.0
        for gk, sk in zip(g, sigma_t):
            if sk <= 0:
                return {aa: float('inf') for aa in alphas}
            # 每个注入点的等效输出敏感度 ~ gk * delta_s
            cost += a * (gk * delta_s) ** 2 / (2.0 * sk ** 2)
        out[a] = cost
    return out
```

### IP-468 Privacy-Aware Flow Matching Trainer (PAFMT)

```python
class PrivacyAwareFlowMatchingTrainer:
    """DP-SGD 训练 + 流时间噪声调度优化"""

    def __init__(self, policy, cfg):
        self.policy = policy
        self.cfg = cfg  # clip C, batch B, sigma_train, eps_max, eta_max, K

    def train(self, dataloader):
        for x0, x1, state in dataloader:
            t = torch.rand(x0.size(0))
            xt = (1 - t) * x0 + t * x1
            target = x1 - x0
            per_sample = ((self.policy.velocity(xt, t, state) - target) ** 2).mean(-1)
            # 逐样本裁剪 + 高斯噪声（DP-SGD）
            clipped = per_sample.clamp(max=self.cfg.clip)
            grad = torch.autograd.grad(clipped.mean(), self._params())
            for p, g in zip(self._params(), grad):
                p.grad = g + torch.randn_like(g) * self.cfg.sigma_train * self.cfg.clip
            self._optimizer.step()
        return dp_sgd_rdp(self.cfg.steps, self.cfg.clip, self.cfg.batch,
                          self.cfg.sigma_train, self.cfg.alphas)

    def optimize_noise_schedule(self, linearized_flow: list, delta_s: float):
        """min  Σ tr(Σ_k)  s.t.  Σ Φ_k Σ_k Φ_kᵀ = Σ_out(ε), Σ_k ⪰ 0
        其中 Φ_k = Φ(1,t_k)·h 为第 k 步噪声到输出的线性化放大；
        当只约束总输出噪声时退化为水填充，闭式解 σ_k ∝ ||Φ_k||_F。"""
        import cvxpy as cp
        K, d = len(linearized_flow), linearized_flow[0].shape[0]
        Sig = [cp.Variable((d, d), PSD=True) for _ in range(K)]
        target = cp.Variable((d, d), PSD=True)
        # 隐私要求给出输出协方差下界：Σ_out ⪰ (Δ_traj²/(2ε_local)) I
        eps_local = self.cfg.eps_max / 2.0
        lower = (self.cfg.delta_traj ** 2) / (2.0 * eps_local)
        cons = [target >> lower * np.eye(d),
                sum(Ph @ Sk @ Ph.T for Ph, Sk in zip(linearized_flow, Sig)) == target]
        prob = cp.Problem(cp.Minimize(sum(cp.trace(Sk) for Sk in Sig)), cons)
        prob.solve(solver='SCS')
        return [np.linalg.eigvalsh(Sk.value)[-1] ** 0.5 for Sk in Sig]
```

class FederatedFlowMatchingAggregator:
    """本地训练 + 本地 DP + 安全聚合；原始轨迹不出域"""
    def __init__(self, n, threshold, clip, sigma_local):
        self.n, self.t, self.C, self.sigma = n, threshold, clip, sigma_local

    def aggregate(self, masked_updates: list) -> dict:
        # 各机上传 mask(θ_i + DP 噪声)，服务器只能看到和
        if len(masked_updates) < self.t:

        summed = sum_masked(masked_updates)          # 安全聚合

        # 本地 DP 噪声 + 阈值聚合的复合隐私界（保守：按客户端数线性复合）

                for a in alphas}

## 3. 关键推导

### 引理 23（连续流敏感度的 Grönwall 界）

**陈述**：设 ẋ=v_θ(x,t)、ẋ'=v_θ'(x',t)，v 对 x 为 L-Lipschitz，且 sup_t‖v_θ−v_θ'‖≤Δ_v，则
‖x(1)−x'(1)‖ ≤ ((e^L−1)/L)·Δ_v。

**证明**：令 e(t)=‖x(t)−x'(t)‖。则
e(t) ≤ ∫₀ᵗ (L·e(s)+Δ_v) ds。由 Grönwall 不等式，
e(t) ≤ (Δ_v/L)(e^{Lt}−1)，取 t=1 即得。∎

### 引理 24（Euler 离散化的紧化界）

**陈述**：K 步 Euler 下，若单步速度扰动 ≤Δ_v，则
Δ_traj ≤ ((1+L/K)^K−1)/L·Δ_v。

**证明**：e_{k+1} ≤ (1+Lh)e_k + hΔ_v，h=1/K。展开得
e_K ≤ hΔ_v·Σ_{i=0}^{K−1}(1+Lh)^i = ((1+Lh)^K−1)/L·Δ_v。∎
注意 (1+L/K)^K ↑ e^L，故离散界更紧且始终 ≥ 连续界的有限步近似。

### 引理 25（流时间注噪的效用界）

**陈述**：在 t_k 注入协方差 Σ_k 的零均值噪声，线性化后输出协方差为
Σ_out = Σ_k Φ(1,t_k)Σ_kΦ(1,t_k)ᵀ·h²。于是
W_2(π_θ,π_θ^noisy) ≤ √tr(Σ_out)。

**证明**：噪声经线性化流映射传播，输出分布为原分布与零均值高斯的卷积；
两分布 W_2 的上界由噪声协方差的迹给出。∎

### 引理 26（RDP 双链路复合）

**陈述**：若 T1 训练链路满足 (α,ε_train(α))-RDP，T2 流时间链路满足
(α,ε_local(α))-RDP，且同一用户同时参与两者，则总体满足
(α,ε_train(α)+ε_local(α))-RDP，再经标准转换得到 (ε,δ)-DP。

**证明**：Rényi 散度的链式法则/基本复合。∎

### 定理（PUCG 的可靠性与单调收缩）

**陈述**：对任意计划 Π，`PUCG.admits(Π)=True` ⟹ Π 同时满足：
1) KACG 的八项安全约束；2) 轨迹敏感度不超过 FSC 保守界；
3) 隐私预算 ε≤ε_max；4) 生成分布 W_1≤η 且动作动力学可行。
并且 Exec_v28 = Exec_v27 ∩ Fil_privacy ∩ Fil_flow ⊆ Exec_v27。

**证明**：PUCG.admits 为四项合取，逐项调用对应 verify；集合包含关系由
交集定义直接得到。∎

### 命题（隐私预算耗尽时的安全降级）

**陈述**：若 PC.verify 失败或 FSC 超界，PUCG 拒绝学习型策略，回退到
非学习型 KEMPC 保守控制；该回退不消耗训练隐私预算，且保持 KACG 安全性。

**证明**：回退策略不查询训练数据、不释放梯度，故 T1 隐私成本为 0；
其安全性已由 KACG 的 USMC/KEMPC 证书保证。∎

## 4. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| FMP 采样 | O(K·C_v) | O(d) | K=8, d=动作维 |
| FMP 精确似然 | O(K·C_v·d)（含 Jacobian） | O(K·d) | 反向积分 |
| FSC 界计算 | O(1) | O(1) | 仅 L, Δ_v, K |
| PC RDP 记账 | O(|α|·(T+K)) | O(|α|) | T 训练步, K 流步 |
| σ(t) SDP | O(K·d³)（小规模） | O(K·d²) | 水填充可降到 O(K·d) |
| FMPC W1 | O(n²·iters) | O(n²) | n=64, iters=50 |
| PUCG 总体 | O(K·C_v + n²·iters + T|α|) | O(K·d²+n²) | 关键路径：采样+W1 |

**实时性**：采样 8 步 × 轻量速度网络约 2–5ms；FSC/PC 查表 <0.5ms；
FMPC 的 Sinkhorn 仅离线/低频审计，在线走缓存；PUCG 单步可在 10ms 内完成，
仍满足 50Hz。隐私调度 SDP 只在训练/换岗时求解，不在控制回路内。

## 5. 实验设计（增量）

**平台**：MuJoCo 双足（10-DoF 简化）与 Isaac Gym 四足/双足混合编队；
策略输入为本体感知 + 语义地图局部栅格。

**基线**：① 非隐私流匹配；② DP-SGD 流匹配（无流时间调度）；
③ DP 扩散策略；④ DP-SGD MLP 策略；⑤ KEMPC 保守控制器（安全下界）。

**指标**：
- 效用：任务成功率、回报、与专家动作的 W1、长尾场景（滑移/突障）成功率；
- 隐私：δ=1e-5 下 ε、成员推断 AUC、轨迹重建误差、梯度反演 PSNR；
- 安全：KEMPC 约束违反率、KC 违规率、回退触发率；
- 效率：采样延迟、证书生成延迟、训练通信量（联邦）。

**消融**：均匀 σ(t) vs. 水填充/SDP 调度；各向同性 vs. 敏感子空间定向注噪；
集中式 vs. 联邦安全聚合；FSC margin 1.0 vs. 1.1；有无 PUCG 回退。

**预期**：在相同 ε 下，流时间调度比均匀注噪把 W1 降低 20%–35%；
联邦版通信量降低一个量级而 ε 仅增加约 10%；长尾成功率是主要退化项，
需要模式感知调度来缓解。

## 6. 已知风险与缓解（增量）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R22 | Lipschitz 常数 L 与 Δ_v 被低估，隐私证书形式成立但实际泄漏 | 高 | 1) 谱范数正则 + 对抗采样估计 L；2) 保守 margin；3) 定期用影子模型做经验审计 | 高维动作空间仍可能低估，审计本身也有隐私成本 |
| R23 | 流时间注噪抹平多模态/长尾动作模式 | 高 | 1) 模式感知的噪声分配；2) 混合流（mixture-of-flows）；3) 长尾重加权 | 稀有但关键场景仍可能退化 |
| R24 | RDP 双链路复合在自适应查询下记账不紧或失效 | 中 | 1) 隐私过滤器（privacy filter）替代事后记账；2) 独立噪声源；3) GDP 近似校验 | 自适应攻击下实际 ε 可能高于名义值 |
| R25 | 联邦聚合的异质性与合谋 | 中 | 1) 阈值安全聚合；2) 本地 DP + 鲁棒聚合；3) 客户端抽样 | 低于阈值的合谋仍可能推断本地分布 |
| R26 | 隐私/保真约束与 KEMPC 安全约束冲突 | 中 | 1) 字典序优化：安全 > 隐私 > 效用；2) 冲突时回退 KEMPC；3) 联合约束求解 | 回退过频会显著降低任务能力 |
| R27 | 精确似然/可逆性在数值离散下不成立，影响 unlearning 证书 | 低 | 1) 高精度积分 + 误差界；2) 只用离散可逆耦合层 | 离散化误差破坏严格保证 |

## 7. 本轮最大风险（最终确认）

**一句话**：**FSC 的紧致性依赖高维空间中极难可靠估计的 Lipschitz 常数与敏感度上界，一旦低估，隐私证书就会「形式成立、实际泄漏」；同时沿流时间的隐私噪声可能抹平长尾多模态动作，使策略在罕见突发场景退化并与既有安全证书冲突，这是本方案最需要优先证伪的风险。**
