# 第 3 轮迭代（灵感循环 v3：「语音识别」×「小样本学习」）—— 把「进度判定」做成一次受限解码，把「未见」做成一次词典扩展

> 承接 v2（UIP-01′~15）。v2 的旗舰 UIP-01′ 把 `human_*` 读成「反向撤回」，给出「`done/ongoing/fail/regressed` 四态 + 每 k 步阈值验证 + 重做」。它自己已经点出了最大的软肋：**`regressed` 是逐帧阈值判出来的**，误判就会「反复重做」。本轮两个灵感词正好各补一刀：
>
> - **语音识别**不是让我们加麦克风（接口里根本没有音频），而是把「在噪声观测中追踪一个基本只准前进的符号序列」这件**被解决过很多次的问题**借过来：声学模型 → 发射器，发音词典 → 步骤/技能符号表，语言模型/WFST → 计分步文法，beam search → 在线进度解码，VAD/端点检测 → 人机接管端点，热词偏置 → 语言里的物体名，CTC blank → 「无进展」符号，说话人自适应 → 少样本适配。
> - **小样本学习**不是学术装饰：`unseen_object_*` 与「公开数据零干扰」意味着测试时必然出现**词汇表外（OOV）**的物体/情境；正确动作是**扩展词典**（原型 + 轻量适配器），而不是重训整个策略。
>
> **一句话直觉**：把策略的「我在第几步、有没有被人退回去」从**分类问题**重写成**解码问题**；把「没见过的东西」从**泛化问题**重写成**词典扩展问题**。

## 1. v2 清单诊断：哪一块必须换掉，哪一块只是升级

- **必须换掉（核心）**：UIP-01′ 的「每 k 步阈值判 `regressed`」。四态 FSM 本质是一个**退化的文法**：没有时间先验、没有校准置信度、没有「人正在操作」的隐状态。它把「一次谓词抖动」直接升级成「重做一个计分步」，正是 v2 自己写下的最大风险。
- **顺势升级**：UIP-13 ACS 的「按阶段查表选 k」→ **由解码器后验熵/改写概率驱动 k**（同一套机制，去掉了手工表）；UIP-14 MSGR 的「技能图」→ 解码器的**词典/文法结构**（不是另起一套模块）。
- **合并**：UIP-05 LCAG（语言→可供性）→ 并入**上下文偏置 + 少样本词典扩展**；语言的正确用法是给「词」加先验，而不是直接回归动作。
- **保留并重新定位**：UIP-11 GSO 从「离线判分」升级为**发射器/文法的校准集**；UIP-12 DRF 从「造恢复数据」升级为**少样本 support set 工厂**；UIP-02′（步骤分账本）、UIP-08′（多端口工程）、UIP-15 CSG（护栏）继续保留。
- **封存**：以「每帧分类器 + 阈值」为中心的旧验证器；固定阶段→k 的手工调度表。

## 2. 两个灵感词：先直觉，再定义

### 2.1 直觉解释

**语音识别**的核心不是「听」，而是**在模糊、连续、带噪声的观测流里，找到一个受语言约束的离散符号序列**。它从不逐帧独立下结论：声学模型给出每帧对音素的后验，语言模型/WFST 规定「哪些音素序列是合法的词」，beam search 在两者之间找最可能的整句，VAD/端点检测决定「人什么时候开始说、什么时候说完」，CTC 的 blank 允许「这一帧什么都不说」。

把摄像头帧想成「音频帧」，把每个计分步想成「一个词」，把计分点的固定顺序想成「语法」，把人为撤回想成「说话人改口/自我纠正」，整个问题就和 ASR 同构了。v2 的做法相当于「每一帧都独立判断当前是哪个词，听到一点噪声就改口」；v3 要做的，是把整段观测当成一句话去解码。

**小样本学习**的核心也不是「数据少也能训大模型」，而是**在不改动主干的前提下，用极少量样例把一个新类别接进现有的表示/词典**。这正是 ASR 的「词典扩展 / 热词偏置」：来了一个没见过的物体名，不需要重训声学模型，只需要在解码图里加一个「新词」的原型与先验。对 UniBot 来说，`unseen_object_*` 就是 OOV 词；DRF/GSO 生成的少量合成样例就是 support set。

### 2.2 语音识别 → 进度解码：严谨定义

把任务 `T` 的计分点记作有序符号序列 `σ_1, …, σ_K`，分值 `w_1, …, w_K`（`Σw=100`），并为每个计分步绑定一个可观测谓词 `φ_i`（几何/接触/视觉，见 v2 的 GSO）。定义：

- **任务文法** `G_T = (Q, Σ, δ, q_0, F, c)`：加权有限状态转换器；`Q = {0..K} × {R, H}`，第二维表示「控制权在机器人 R / 在人 H」。
  - 前进弧：`(i,R) --σ_{i+1}--> (i+1,R)`，代价 `log π_i`（先验允许按演示统计的步进速率来定）；
  - 停驻弧：`(i,R) --ε--> (i,R)`，代价 `0`，对应 CTC 的 blank；
  - 接管弧：`(i,R) --ε--> (i,H)`、`(i,H) --ε--> (i,R)`，代价 `log π_start / log π_end`；
  - **撤回弧**：`(i+1,H) --υ_i--> (i,H)`，代价 `λ_i`；`λ_i` 是「相信被撤回」的门槛，按分值设为 `λ_i = λ_0 − γ·w_i`——**分越高的步，越愿意先怀疑被撤回**（因为丢分更痛）；
  - 未知弧：每个状态一条低权重自环，防止文法与隐藏评分器不一致时「硬错」。
- **发射器** `E_θ(o_t) ∈ Δ(Σ ∪ {ε})`：由 4 路 RGB + 本体状态给出「当前帧像哪个计分步/停驻」的后验。`E_θ` 用 **CTC** 在公开演示上训练：演示天然是干净、单调、无干扰的，标签是任务目录给出的有序计分步，**不需要逐帧标注**。这是本轮最便宜、最实在的一步：32k 条干净演示正好是 CTC 的完美语料。
- **解码**：给定观测 `o_{1:T}`，求
  `ŝ_{1:T} = argmax_{s_{1:T} ∈ L(G_T)} Σ_t [ log E_θ(s_t | o_t) + log P(s_t | s_{t-1}) ]`。
  离线用 Viterbi，在线用 **prefix beam search / 前向滤波**，得到 `p(g_t | o_{1:t})`（当前进行到第几步）与 `p(υ_t | o_{1:t})`（刚刚被撤回的概率），同时单独维护 `m_t = max_{τ≤t} g_τ` 的**历史最高进度账本**。
- **端点检测（IAD）**：把「人是否正在操纵」建成隐变量 `a_t ∈ {R, H}`（半马尔可夫，带持续时长先验），观测是「指令预测的 EE 运动 vs 实际 EE 运动」的残差、手部出现/遮挡、物体状态的意外变化。**接管开始/结束**定义为
  `τ_on = min{t : P(a_t=H | o_{1:t}) > θ_on}`，`τ_off` 同理并用驻留时间/滞回抑制抖动。关键：**「人活动」不等于「人撤回」**——`a_t` 与 `υ_t` 必须是两个量，这是第 6 节合成实验给出的硬教训。
- **重做决策（决策论）**：不要「看到 `regressed` 就重做」。设当前步为 `j`，重做恢复概率 `ρ`，重做成本 `c`（延迟 + 动作风险 + 可信度），则
  `重做 ⟺ ρ·w_j + (1−ρ)·(预期保留分) − c > 继续的预期分`。
  末步分更高（`w_j` 大）时自然更愿意重做；低分前置步则优先「保住已有分、继续推进」。这条规则把 v2 的硬阈值变成了**可解释的收益计算**。
- **块长（UIP-13′）**：`k_t = clip(k_0 − α·H(p(g_t|o_{1:t})) − β·p(υ_t), k_min, k_max)`；接触密集/高不确定/疑似被撤回时自动缩短块，长距离搬运时放大块。

### 2.3 小样本学习 → 词典扩展：严谨定义

- **少样本 episode**：任务分布 `p(T)` 覆盖「物体 × 背景 × 位置 × 指令措辞」。support `S = {(x_i, y_i)}_{i=1..k}` 来自 DRF/GSO 的合成样例（或同任务前几帧 + 指令弱标签），query `Q` 是留出样例。目标是学一个**适配器** `ψ`，使 `E_{T∼p(T)}[ L(Q; ψ(S)) ]` 最小。
- **单模型合规下的两种实例化**：
  1. **原型分类（NCM）**：`p_c = mean_{i:y_i=c} φ(x_i)`，`ŷ = argmin_c ||φ(x) − p_c||²`；`φ` 是冻结主干，原型是**非参数记忆**，不引入第二个模型；
  2. **轻量头（PEFT/ridge）**：在 support 特征上闭式解一个线性/低秩头，用于校准发射器的每类温度或做谓词打分。
- **恢复元学习（FSR-M）**：DRF 生成的 `(撤回前 → 撤回 → 恢复)` 三元组在 32 任务间共享同一个「撤回算子」结构；元训练目标是**学会撤回/恢复的共性**，使新任务只需 `k` 个（甚至 0 个）恢复样例。这是把「零干扰数据」变成「少样本恢复能力」的直接路径。
- **上下文偏置**：指令 `l` 只用来给词典里的「物体/步骤词」加先验（`log P(σ_i | l)` 的偏置项），不直接回归动作；当指令过于泛化（示例里只有 `"move the block..."`）时，退化为纯视觉原型。语言在公开数据里缺失这一事实，决定了它只能是**辅助先验**。

### 2.4 为什么两个词必须一起用

解码器需要一个**发射器**来给每个计分步打分；而发射器的「词汇表」在 `unseen_object_*` 上会失效。小样本学习负责**在不重训主干的前提下扩展这个词汇表**；CTC 负责用干净演示把「帧 → 步骤词」的发射器训出来；WFST 负责把「步骤词的合法顺序 + 撤回」编码成先验。四者缺一不可：没有 CTC，发射器没有逐帧标签；没有 WFST，解码器退化为逐帧分类；没有 FSL，遇到没见过的物体就整段失效；没有语言/任务目录，连「有哪些词」都不知道。

## 3. 瓶颈假设（v3）

- **H1（最高杠杆）**：进度/撤回的正确抽象是**序列解码**而非逐帧分类。若成立，误报撤回导致的「反复重做」应大幅下降，而真撤回的检出延迟基本不变。第 6 节的合成实验给出初步支持（重做触发 56.5 → 2.85 次/episode）。
- **H2**：公开演示的「干净单调性」是资产而不是缺陷——它让 CTC 对齐几乎无歧义；撤回是**测试期才出现**的非单调事件，正好由 WFST 的撤回弧处理，而不该污染发射器的训练。
- **H3**：`unseen_object_*` 的正确解法是**词典扩展**（k≈5–10 的原型/轻量头），不是全量微调；合成实验显示 k=5 已能拿到大部分收益，k>10 饱和。
- **H4**：「人活动」与「人撤回」必须解耦。把 IAD 当成撤回检测器会过度触发（第 6 节：简单门控反而更差）；IAD 的正确职责是**让行/暂停**，撤回的判定交给文法+发射器。
- **H5**：计分点文法是一个**强先验**，但它只是我们对隐藏评分器的**猜测**；必须保留 unknown 弧与「不硬失败」的兜底，否则「更自信的解码」会变成「更自信地错」。
- **H6**：CTC/WFST/原型都是 CPU 级轻量计算，可与 `T_a`、延迟预算、单模型合规共存；真正的成本在**校准**（用 GSO/DRF 标注）和**真机锚点**，不在推理。

## 4. 候选与合并 → v3 清单（详见产物区）

围绕两词发散 12 个草案，合并/修剪后得到：

- **升级为旗舰**：UIP-16 **FLIP-D**（Few-shot Lattice Inference for Progress Decoding）——把 UIP-01′ 的四态阈值状态机换成「CTC 发射器 + 计分步 WFST + 在线束解码 + 决策论重做」。
- **新增**：UIP-17 **CTC-SA**（用干净演示做 CTC 步骤对齐/发射器）、UIP-18 **TGC**（把 `scoring_points` 自动编译成 WFST）、UIP-19 **IAD**（接管端点检测/让行）、UIP-20 **META-LEX**（少样本词典扩展）、UIP-21 **FSR-M**（撤回-恢复的元学习）。
- **升级**：UIP-13′ **ACS-E**（熵驱动块长）、UIP-14′ **MSGR-L**（技能图=词典/文法，不再是并列模块）。
- **保留**：UIP-02′（步骤分账本）、UIP-08′（多端口延迟工程）、UIP-11（GSO 校准）、UIP-12（DRF support 工厂）、UIP-15（CSG 护栏）。
- **合并/封存**：UIP-05 → UIP-20/上下文偏置；UIP-01′ 的「阈值验证器」→ 被 UIP-16 取代；固定阶段→k 表 → 被 UIP-13′ 取代。

## 5. 本轮最大风险

**一句话**：本轮最大的风险是「文法幻觉」——我们把从 `scoring_points` 猜出来的计分步序列当成隐藏评分器的真值，而语言在公开数据里根本不存在；一旦文法或词义猜错，概率解码只会**更自信地做错**，所以必须保留 unknown 弧、真机锚点和「不硬失败」的兜底。

**→ 本轮最值得押注**：**UIP-17 CTC-SA + UIP-18 TGC + UIP-16 FLIP-D** 组成的「干净演示学词、文法约束解码、决策论重做」闭环；它把 v2 最脆的 `regressed` 阈值替换成有校准、有先验、可解释的后验决策，且完全落在单模型与选手 API 权限内。**UIP-20 META-LEX 是第二优先**：它用 k≈5–10 的合成/首帧原型堵住 `unseen_object_*` 这个数据空白。

## 2. 形式定义

### 2.1 计分步与任务文法

任务 `T` 的计分点为有序符号 `σ_1..σ_K`，分值 `w_1..w_K`，`Σ w_i = 100`。每个 `σ_i` 绑定谓词 `φ_i(o) ∈ {0,1}` 与（可选）子阶段 `approach/contact/retreat`。

定义加权自动机
`G_T = (Q, Σ, δ, q_0, F, c)`，其中
- `Q = {0..K} × {R, H}`；`R`=机器人控制，`H`=人接管；
- 前进：`(i,R) --σ_{i+1}--> (i+1,R)`，代价 `c = −log π_prog`；
- 停驻：`(i,R) --ε--> (i,R)`，`c=0`；
- 接管/归还：`(i,R)<->(i,H)`，代价 `−log π_start / −log π_end`；
- 撤回：`(i+1,H) --υ_i--> (i,H)`，代价 `λ_i = λ_0 − γ·w_i`；
- 未知：每个状态一条 `ε` 自环，`c = λ_unk`（大但有限），保证文法错了也不硬失败。

语言 `L(G_T)` = 所有「按序前进 + 在接管期最多 Δ 次撤回」的符号串。**注意**：撤回只允许在 `H` 状态发生——这是把一个先验写进文法：没有人动，进度不应倒退。

### 2.2 发射器与 CTC 对齐

给定干净演示 `x_{1:T}` 与任务的有序标签 `l = (σ_1..σ_K)`（来自任务目录，**无逐帧标注**），最小化 CTC 负对数似然：
`L_CTC = −log Σ_{π: B(π)=l} Π_t E_θ(π_t | x_t)`，
其中 `B` 合并重复符号并删 blank。训练后：
- `E_θ(σ | o_t)` 直接作为解码发射分数；
- 对 `argmax` 对齐路径做 `B^{-1}`，得到每个 `σ_i` 的**伪时间戳** `[t_i^start, t_i^end]`，用于：① 校准 `π_prog`/驻留时长；② 给 UIP-20 的原型/轻量头提供弱标签；③ 训练 UIP-19 的「活动/撤回」弱标签。

> 为什么 CTC 可行：公开 32 个数据集是**零干扰、单调完成**的演示，正好满足 CTC 的单调对齐假设；撤回只发生在测试期，交给文法弧处理。这把「数据没有逐帧步骤标签」从障碍变成了「用 CTC 免费获得弱标签」。

### 2.3 在线解码

在每个评测调用点（每 `T_a` 步一个观测）维护前向消息 `α_t(q)`：
`α_t(q) ∝ Σ_{q'} α_{t-1}(q') · A(q'→q) · E_θ(s(q'→q) | o_t)`。
输出：
- `p(g_t | o_{1:t}) = Σ_{a∈{R,H}} α_t(g_t,a)`；
- `p(υ_t | o_{1:t}) = Σ_{i} α_t(i+1,H)·A_undo`（归一化后）；
- 历史最高进度 `m_t = max_{τ≤t} g_τ`（独立账本，用于步骤分审计）。

在线用 beam（宽度 `B`）近似；离线 GSO 用 Viterbi 得最优路径。

### 2.4 接管检测（IAD）

隐状态 `a_t ∈ {R,H}` 为半马尔可夫链：`P(a_t=H | a_{t-1}=R)=π_start`，`P(a_t=R | a_{t-1}=H)` 由持续时长分布 `D_H` 决定。发射特征：
`z_t = [ ||ẋ_t^cmd − ẋ_t^obs||, hand_mask_t, Δobject_t, grip_force_proxy_t ]`。
`τ_on = min{t: P(a_t=H|o_{1:t})>θ_on}`，`τ_off` 用滞回 + 最小驻留。**`a_t` 与 `υ_t` 解耦**：人可能只是在移动干扰物/扶着物体，不等于撤回。

### 2.5 少样本词典扩展

- support `S={(x_i,y_i)}_{i=1..k}`，query `Q`；
- 冻结主干 `φ`，原型 `p_c = mean_{i:y_i=c} φ(x_i)`，`ŷ = argmin_c ||φ(x) − p_c||²`；
- 或 ridge 头 `W = (Φ_S^T Φ_S + μI)^{-1} Φ_S^T Y_S`（闭式、无梯度、适合在线）；
- 元目标 `min_ψ E_{T∼p(T)} [ L(Q; ψ(S)) ]`，`ψ` 为 PEFT（LoRA/prefix）或上述闭式头；
- **合规**：`φ` 是唯一骨干，`ψ` 是同一模型的一部分，原型是同一模型的特征记忆；推理期不调用任何外部模型/API。

### 2.6 决策论重做

设当前步 `j`，继续的预期保留分 `S_cont`，重做恢复概率 `ρ`，成本 `c`：
`重做 ⟺ ρ·(Σ_{i≤j} w_i) + (1−ρ)·S_cont − c > S_cont`。
等价于 `ρ·W_j > c`，其中 `W_j = Σ_{i≤j} w_i`（或只看 `w_j` 的增量）。末步 `w_j` 更大 ⇒ 更愿意重做；低分前置步优先「保分推进」。

## 3. 关键算法（伪代码）

### 3.1 TGC：计分点 → WFST

```python
def compile_task_grammar(task):
    # task.scoring_points: [{"desc", "weight", "predicate"}...]
    K = len(task.scoring_points)
    arcs = []
    for i in range(K + 1):
        for a in ("R", "H"):
            arcs.append(((i, a), (i, a), "eps", 0.0))          # stay / blank
            arcs.append(((i, a), (i, a), "unk", LAMBDA_UNK))   # unknown fallback
        if i < K:
            arcs.append(((i, "R"), (i + 1, "R"), f"sig{i+1}", -log(PI_PROG)))
        if i > 0:
            # 撤回只发生在 H 状态；高分步更容易被判撤回（λ 更小）
            lam = LAMBDA0 - GAMMA * task.scoring_points[i - 1]["weight"]
            arcs.append(((i, "H"), (i - 1, "H"), "undo", max(lam, LAMBDA_MIN)))
    for i in range(K + 1):
        arcs.append(((i, "R"), (i, "H"), "eps", -log(PI_START)))
        arcs.append(((i, "H"), (i, "R"), "eps", -log(PI_END)))
    return WFST(states, sigma, arcs, q0=(0, "R"), F={(K, a) for a in ("R", "H")})
```

### 3.3 FLIP-D 在线解码 + 让行 + 重做

```python
class FLIPD_Policy:
    def __init__(self, policy, emitter, grammar, iad, csg, T_A=8):
        self.policy, self.E, self.G, self.IAD, self.CSG = policy, emitter, grammar, iad, csg
        self.T_A = T_A

    def reset(self):
        self.alpha = self.G.initial()      # forward message
        self.m = 0                         # max progress ledger
        self.pending = None                # pending redo target
        self.buf = []

    def get_action(self, obs):
        # 1) 发射器 + 前向更新
        e = self.E(obs)                                   # p(symbol | o_t)
        self.alpha = self.G.forward(self.alpha, e)        # O(B * |delta|)
        pg = self.G.step_posterior(self.alpha)            # p(g_t | o)
        pu = self.G.undo_posterior(self.alpha)            # p(upsilon_t | o)
        ph = self.IAD.human_posterior(obs, self.alpha)    # p(a_t = H | o)

        # 2) 让行优先：人在动就先别对抗
        if ph > THETA_H:
            return self.policy.hold(obs, self.T_A)

        # 3) 决策论重做：只在证据足够且收益为正时
        g = int(pg.argmax())
        self.m = max(self.m, g)
        if pu > THETA_U and self.CSG.allow_redo():
            j = max(0, self.m - 1)
            if self.G.expected_gain(j, rho=pu, cost=self.CSG.redo_cost) > 0:
                self.pending = j

        # 4) 生成动作：重做目标优先，否则正常策略
        target = self.pending if self.pending is not None else g
        chunk = self.policy.act(obs, target, horizon=self.T_A)
        self.pending = None
        return chunk
```

> **块长红线（对 v2 的修正）**：README §3 要求每个动作数组形状为 `(T_a, ...)`，且 `T_a` 在握手时固定。因此「每次返回 ≤k 步」在没有明确许可前**不可假定合法**。默认实现：**固定全局 `T_a`**，自适应只体现在「按任务/片段离线选 `T_a`」与「块内动作的保守化」；若要在线逐段变块，必须先跑 `example_env/run_client` 探明评测端是否接受变长块（见 E205）。

## 5. 推导

### 5.1 为什么逐帧阈值会「反复重做」

设每个评测点的谓词误报率 `ε`，共 `N` 个评测点。至少一次误报的概率
`P(≥1 false redo) = 1 − (1−ε)^N ≈ Nε`。
v2 在每个块边界独立判 `regressed`，一旦误报就重做已完成步；在长 episode 中，重做次数随 `N` 线性增长。合成实验（§6）里，朴素前缀法每 episode 触发 **56.5** 次重做，其中 **93.9%** 是误报——这正是 v2 自己写下的「反复重做」风险。

### 5.2 概率解码的对数几率边界

把「进度 vs 被撤回」局部化为两状态比较。设发射似然 `p(o|g)`、`p(o|g−1)`，先验 `π_undo`，撤回代价 `λ`。则
`log [P(undo|o) / P(stay|o)] = log [p(o|g−1)/p(o|g)] + log[π_undo/(1−π_undo)] − λ`。
**重做当且仅当该式 > 0**。因此：
- `λ` 直接控制误报/漏报的权衡，可按目标误报率用 GSO/DRF 的 conformal 分位数校准；
- 逐帧阈值等价于 `λ=0` 且忽略时序先验；这解释了它为什么对谓词抖动没有免疫力；
- 高分步令 `λ_i` 更小（§2.1），使 `w_j` 大的步更容易被怀疑——与「末步分值更大」的赛制一致。

### 5.3 步骤分账本与重做收益

若最终按「结束时的状态」计分，设当前进度 `j`、已完成分 `Σ_{i≤j} w_i`。疑似撤回时：
- 继续：以 `1−ρ` 保留 `Σ_{i≤j} w_i`，以 `ρ` 丢掉 `w_j`；
- 重做：花成本 `c`，以 `ρ` 恢复 `Σ_{i≤j} w_i`。
重做优于继续当 `ρ·w_j > c`。末步 `w_j` 大 ⇒ 重做阈值更低；前置步 `w_j` 小 ⇒ 优先保分推进。这把「保前置、搏末步」从口号变成了可计算的规则。

### 5.4 CTC 对齐的复杂度与标签成本

CTC 对长度 `T`、标签 `K` 的 DP 复杂度 `O(TK)`；32k 演示 × ~1–2k 帧 × K≤5 完全可离线。它把「逐帧步骤标签」的成本降为 0，代价是只利用**单调干净**演示（正好是公开数据的性质）。撤回样本不参与 CTC，避免把非单调事件学进发射器。

### 5.5 少样本原型的误差尺度

设类均值 `μ_c`，特征噪声 `σ`，维度 `d`，k-shot 原型 `p_c = μ_c + (σ/√k)ξ`。原型估计误差 `O(σ√(d/k))`；分类间隔 `Δ=||μ_c−μ_{c'}||` 时，误分类随 `k` 增大而下降，但当**查询样本自身噪声**成为主导时会饱和。合成实验（§6）显示：σ=1.0 时 k=5 已达 92.2%、k=10 94.7%、k=20 95.6%（饱和）；σ=0.6 时 k=1 就 95.8%。**结论**：为 META-LEX 预算 k≈5–10，且优先提升嵌入质量而非堆更多 shot。

### 5.6 延迟与复杂度

解码 `O(T·B·|δ|)`，`K≤5`、`B≤16`、`|δ|≈O(K)`，单次前向 <1 ms（CPU）；真正的延迟在视觉主干（与主策略共享，不另起模型）。原型检索是 `O(kC d)` 的向量距离，可缓存。CTC 仅离线。故本方案不显著增加逐步延迟，符合 README §6 的可信度要求。

## 6. 本轮合成实验（机制验证，非真机结论）

> 目的：验证「时序文法解码 vs 逐帧阈值」与「少样本原型 k 曲线」两个核心命题；用可控 HMM 生成器，**不是** UniBot 真机/仿真结果，不能当作成败证据。

### 6.1 设置

- 5 个计分步；episode 长 180 个评测点；1500 episodes；seed=0。
- 真实进度：每点以 `0.08` 概率前进一步。
- 人为接管：每点 hazard `0.012` 启动，持续 4–8 点；在接管中点以 `0.75` 概率撤回一步。
- 发射：已完成步的谓词真阳性 `0.85`，未完成步假阳性 `0.08`，各步独立。
- 接管提示：真接管时 `0.70` 检出，非接管时 `0.05` 假阳性（模拟一个不完美的 IAD 头）。
- 对比：① 朴素前缀法（v2 风格逐帧阈值）；② HMM 前向解码（纯时序先验，不用 IAD）；③ HMM + 逐帧 IAD 门控；④ 联合 (进度 × 接管) HMM。
- 指标：状态准确率、MAE、误报占所有告警比例、每 episode 重做触发数、撤回检出率（±5 点内）。

### 6.2 结果

| 方法 | 状态准确率 | MAE | 误报占告警 | 重做触发/ep | 撤回检出率 |
|---|---:|---:|---:|---:|---:|
| 朴素前缀（v2 风格） | 0.543 | 1.306 | 0.939 | 56.46 | 0.731 |
| HMM 前向（纯时序先验） | **0.929** | 0.072 | 0.516 | **2.85** | 0.725 |
| HMM + 逐帧 IAD 门控 | 0.929 | 0.073 | 0.612 | 4.98 | 0.711 |
| 联合 (进度 × 接管) HMM | 0.940 | **0.061** | 0.761 | 7.50 | **0.742** |

**少样本原型（NCM）准确率 vs k**：

| 特征噪声 | k=1 | k=2 | k=3 | k=5 | k=10 | k=20 |
|---|---:|---:|---:|---:|---:|---:|
| σ=1.0（难） | 0.688 | 0.832 | 0.883 | 0.922 | 0.947 | 0.956 |
| σ=0.6（易） | 0.958 | 0.992 | 0.996 | 0.998 | 0.999 | 0.999 |

### 6.3 读法（含一个负面结果）

1. **时序解码是主收益**：重做触发从 56.5 降到 2.85（−95%），状态准确率 +39pp；但**撤回检出率几乎不变**（0.731 → 0.725）。也就是说，解码器不是让你「看得更清」，而是让你**不再把噪声当成撤回**。这正对 v2 的最大风险。
2. **「人活动」≠「人撤回」**：简单的逐帧 IAD 门控和联合 HMM 都提高了检出率，却显著增加了误报/重做（联合模型 7.5 次/ep）。原因是「接管期」里大部分帧并没有发生撤回。**教训**：IAD 应只负责让行/暂停（安全），撤回判定必须由「接管 + 发射证据 + 撤回弧代价」共同决定，且要校准 `P(undo|activity)`。
3. **少样本在 k≈5–10 饱和**：难特征 k=5 已 92.2%，k=10 94.7%，k=20 仅 +0.9pp。**预算应给嵌入质量与 support 多样性，而不是堆 shot**。
4. **合成实验的局限**：谓词独立同分布、无遮挡相关性、无真实接触动力学；真实 GSO 上误报会相关且更难。因此第 7 节把 GSO/真机校准列为必做。

## 8. 合规与风险（本轮重点）

- **单模型合规**：发射器、IAD 头、META-LEX 适配器全部挂在一个骨干上；原型是同一模型的特征记忆；**推理期不调用任何外部 ASR/VLM/API**。GSO/DRF 只在离线用。
- **文法幻觉**：`scoring_points` 是我们对隐藏评分器的解读，不是真值。必须保留 unknown 弧、限制最大重做次数、设收益阈值；用真机/GSO 做校准锚点。
- **语言缺失**：公开数据没有 `observation.language`，只有 `task_index`；语言只能从任务目录弱构造，且测试措辞可能不同。**不做纯语言条件化**，视觉原型为主、语言偏置为辅。
- **无音频红线**：接口无音频；本方案不含任何音频输入/输出，只迁移算法。
- **IAD 安全**：漏检会导致机器人与人对抗。让行策略必须保守（高召回、低误伤），宁可暂停也不硬做；这是安全优先于分数的少数场景。
- **变长块红线**：README 只承诺 `(T_a,...)` 形状；在线变块长未经证实，默认固定 `T_a`，E205 先探明再启用。
- **仿真过拟合**：合成/GSO 的收益不等于真机；E210 必须留真机时段。

## 10. 本轮最大风险 & 押注

**一句话**：若把 `scoring_points` 猜出来的文法当成真值，FLIP-D 会用更高的置信度做错事；必须先证明「CTC 发射器 + 文法」在 GSO/真机上校准可靠，再放大自动化，否则只是把 v2 的阈值错误换成了更精致的概率错误。

**→ 押注**：**UIP-17 CTC-SA → UIP-18 TGC → UIP-16 FLIP-D** 的「干净演示学词、文法约束解码、决策论重做」主链；**UIP-20 META-LEX** 作为第二优先，用 k≈5–10 的原型扩展堵 `unseen_object_*`。这两个方向都精确对住「公开数据有干净演示但无逐帧标签、有语言接口但无语言标注、有人为撤回但零干扰演示」的三个空白，且完全落在选手的单模型与 API 权限内。
