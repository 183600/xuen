# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「力控」×「三维感知」）

> R69 给了闭环一张嘴：把不确定性拆成 aleatoric / epistemic，能问的去看、去问、去触，不能问的收紧；并用流似然做「标定不可吸收」的第二意见。但 R69 的 `g_probe`（定义 294）只是一个没有接触动力学、不会改变世界状态的占位向量——「触」被降级成了「另一种看」。真实具身系统最贵的不确定性恰恰发生在**接触的那一毫秒**：抓住了没有、表面到底在哪、这物体是软是硬、会不会滑、会不会一碰就倒、对面是不是人。语言回答不了这些问题，只能靠力去试；而「试」会改变世界，可能捏碎、推倒、划伤、甚至伤人。**接触是最硬的信息，也是最不可逆的信息。**
>
> 本轮两个灵感正好补上两块缺失：
> - **三维感知**给出接触发生前的几何先验：点云、TSDF、表面法向、物体位姿、接触流形。但视觉的可观测性是**各向异性**的：沿视线方向的深度、透明/反光/暗表面、遮挡后的接触片，恰恰是安全最关键、视觉最不靠谱的地方。三维感知能给出一个自信但可能错误的几何假设。
> - **力控**给出一种真正可施加的测量：阻抗/导纳不是「读一个力」，而是设计一次**机械实验**——压、擦、点、转、松，力与位移的响应就是答案。但力控同时是承诺：探询力只能由关节产生，接触一旦发生就可能不可撤回。
>
> 核心命题：**把接触当作一次「带不可逆预算的主动物理实验」：三维感知提出接触几何信念；力控在「视觉不可观测子空间」里设计并执行阻抗探询；接触因子反过来修正三维地图；每一次探询都必须通过接触 CBF、无源性能量罐、激发充分性与可恢复撤退证书；没有合格探针时逐指令退回 R69，R69 再退回 R68。** 命名 **FORGE-RAS**（Force–geometry Observability Resolution with Guarded Exploration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我看到的形状是真的吗？摸一下能知道什么、会不会摸坏、摸完还能不能退回来**」——「摸一下」不是一次接收，而是一次有账单的实验。

## 0. 直觉与动机

**灵感 1（三维感知 → 接触流形是假设，不是事实）**
直觉：三维感知擅长回答「物体大概在哪、朝向如何、前面有没有障碍」，但它回答不了「这个接触片的法向、摩擦、柔顺度、局部曲率」。更麻烦的是视觉的误差结构不是各向同性的：深度相机沿视线方向的噪声最大；透明、反光、暗表面会给出缺失或错误深度；遮挡会让接触片根本不可见；单目/低基线系统对沿视线方向的平移几乎无分辨力。也就是说，**视觉最不确定的方向，往往正是接触最先发生、也最需要精确的方向**。FORGE 不把点云当几何真值，而是把它当接触假设的先验：`H = {h_k}`，每个 `h_k` 包含位姿、局部曲面、摩擦锥、柔顺张量与接触状态。

**灵感 2（力控 → 阻抗是提问的语法，接触是不可逆的实验）**
直觉：R69 的「看/问」几乎不改变世界，成本主要是时间和社交；力探询不同，它必须由关节施加法向力与切向运动，必然改变接触状态。阻抗控制把「问什么」变成一个可设计的动作：法向力斜坡问「表面在哪、有多硬」，切向微振问「摩擦锥多大」，轻点问「惯量/连接是否牢固」，小旋转问「接触质心在哪」，释放问「是否粘连」。这把 R69 的标量 `g_probe` 升级为一条**探询协议** `u = (x_d(t), K_d(t), D_d(t), f_max, T)`。但代价是：探询可能捏碎、推倒、划伤、让人疼痛，而且一旦滑脱就回不到「没摸过」的状态。因此信息增益必须用**不可逆风险**来定价，而不是用社交成本来定价。

**灵感 3（对偶与规范 → 力单独测不出绝对几何，视觉单独测不出柔顺）**
直觉：一个容易忽略的事实是，在固定阻抗下，力觉数据存在**规范歧义（gauge ambiguity）**：接触模型 `w = K(x − x_s) + d` 中，把表面位置平移 `x_s → x_s + K^{-1}δ`、同时把外部扰动平移 `d → d + δ`，所有力读数完全不变。也就是说，**力单独无法区分「表面在这里且有人推我」与「表面在别处且没人推我」**。力不是全局几何锚点，它测的是相对柔顺。要打破这个规范，必须么改变阻抗 `K`（让同一位移在不同刚度下产生不同力），要么用三维感知给 `x_s` 一个独立锚点。反过来，三维感知能定几何规范，却测不出摩擦与柔顺；力控能测柔顺，却需要视觉来定规范。**两者不是冗余，而是互补的对偶通道；变阻抗不是安全旋钮，而是识别工具。**

**灵感 4（安全 → 先算清这一摸能不能收回）**
直觉：R69 的交互预算可以「问错一次，下次再问」；接触不能。FORGE 因此引入三层硬约束：接触控制屏障函数（力、摩擦锥、支撑多边形、穿透深度）、无源性能量罐（未知刚度下保持稳定）、以及**可恢复撤退证书**（对信念支撑集内的每个可信假设，都存在一条回到安全自由空间的退路）。再加上按 CVaR 定义的不可逆预算：压碎、滑落、倾倒、划伤、人体疼痛、关节过载，各有代价，尾部风险不得超过 `ε_irr`。如果找不到既安全又有信息量的探针，正确动作不是「轻一点摸」，而是**不摸**。

**灵感 5（证据 → 力也会撒谎，轻触不等于验证）**
直觉：力觉并不是「物理真值」。外物推挤、负载、线缆张力、自接触、量程饱和、迟滞、未建模摩擦都会伪造力读数。更隐蔽的是**假确认**：一次太轻、太短、方向不对的探针什么也没测到，却被系统记成「已验证」。FORGE 要求每条力证据同时满足：与 efference copy（指令力/运动的感觉副本）一致、激发功率超过阈值、至少一个独立源（视觉或另一组不同阻抗的探针）一致；否则只能作为建议证据，不能单独定案。接触因子只有在探针通过证书后才允许写回三维地图，防止一次被污染的接触把整张地图带偏。

**灵感 6（与 R69 的关系 → 只替换接触空白，不推翻交互层）**
直觉：FORGE 不重写 R69 的流匹配策略、aleatoric/epistemic 二分、gaze/ask 交互和安全包络；它只把 R69 的 `g_probe` 从占位向量替换为**经认证的接触探询集合**。若接触信念没有力可观测的 epistemic 分量、或没有合格探针、或探针 VoI 不抵成本、或激发不足，FORGE 逐指令退化为 R69；R69 在没有交互时再退化为 R68。于是得到严格退化链 `R68 ⊂ FLUID-RAS ⊂ FORGE-RAS`：接触层只在能证明「值得且能收回」时才打开。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（FORGE-RAS 总览）** `FORGE-RAS = (CGB, OSD, PAD, CCF, IRB, CFG, FCR, EPC, VQAuditor-G, RAS-WM†)`。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **接触预算硬约束**：法向力 `≤ f_max`、接触能量 `≤ E_max`、单次接触时长 `≤ T_max`、不可逆风险 `≤ ε_irr`，且每次探询必须持有可恢复撤退证书（定义 317）；
(iii) **证据纪律**：单次力读数不得单独确立几何事实；确认性力证据需同时满足 efference copy 一致、激发充分（定义 320）与至少一个独立源一致（定义 322）；
(iv) **单调退化**：无合格探针 / VoI 不抵成本 / 激发不足 / 安全证书失败时，关闭接触层并逐指令退回 R69；R69 再按自身边界退回 R68（定义 325）。

**定义 311（接触几何信念 CGB）** 接触参数 `θ = (T_o, S, μ, k, σ) ∈ Θ`，其中 `T_o ∈ SE(3)` 为物体/接触方位，`S` 为局部曲面片（如二次曲面系数），`μ` 为摩擦系数（或摩擦锥参数），`k` 为局部柔顺张量，`σ ∈ {free, contact, stick, slip}` 为接触状态。三维感知给出信念 `b(θ)` 与离散假设集 `H = {h_k}`，权重 `ŵ_k`，模态内协方差 `Σ_k`。定义 `U_ale^c = Σ_k ŵ_k tr(Σ_k)`（传感器/接触噪声，不可约），`U_epi^c = H(H) · g(Δ_min^c)`（假设间歧义，可约；`Δ_min^c` 为任务风险度量下假设间最小可分距离）。R69 的动作模态不确定性记为 `U_epi^a`；二者通过流策略的条件编码耦合，分别送入各自的消解通道。

**定义 312（三维接触流形与视觉信息）** 从点云/TSDF 提取接触流形 `M = {(p_i, n_i, Σ_i)}`，`p_i` 为表面点，`n_i` 为法向，`Σ_i` 为各向异性深度/法向协方差。视觉观测 `y_v = h_v(θ) + ε_v`，`ε_v ~ 𝒩(0, Σ_v)`；视觉雅可比 `J_v = ∂h_v/∂θ`，视觉信息矩阵 `Ω_v = J_v^T Σ_v^{-1} J_v`。`Σ_v` 显式编码沿视线方向的深度退化、透明/反光/暗表面的缺失与多路径误差。

**定义 313（力控探询动作空间）** 探询协议 `u = (x_d(t), K_d(t), D_d(t), f_max, T) ∈ 𝒰`：期望位姿轨迹、阻抗刚度、阻尼、力上限与持续时间。执行律采用阻抗控制
`τ = J^T [K_d(x_d − x) + D_d(ẋ_d − ẋ) + f_ff] + g(q)`，
并允许在接触相内切换刚度档位（用于规范识别，定义 319）。测得接触力旋量 `w = (f, m)`；力观测 `y_f = h_f(θ, u) + d + ε_f`，外部扰动 `d`、噪声 `ε_f ~ 𝒩(0, Σ_f)`；力雅可比 `J_f(u) = ∂h_f/∂θ`，力信息矩阵 `Ω_f(u) = J_f^T Σ_f^{-1} J_f`。注意：`u` 是一个机械实验协议，而不是一个标量力。

**定义 314（可观测子空间与规范分解 OSD）** 给定任务风险度量 `M ⪰ 0`，令 `J̃_v = M^{1/2} J_v`、`J̃_f(u) = M^{1/2} J_f(u)`。按行空间的主角度分解参数空间：
- `V`：视觉可观测、力弱可观测（vision-only）；
- `F`：力可观测、视觉弱可观测（force-only）；
- `R`：两者都强可观测（redundant，用于交叉验证）；
- `B`：两者都弱可观测（blind，任何探询都不可约）。
记投影算子 `P_V, P_F, P_R, P_B` 与 `U_B = tr(M^{1/2} P_B Σ_post P_B M^{1/2})`。若安全关键参数在 `B` 上仍有非零不确定性，则**禁止接触**：这类不确定性只能靠机械设计、任务改写或新增传感模态消除，不能靠「多摸几下」消除。力模型还存在一类**规范轨道** `G = {(x_s + K^{-1}δ, d + δ) : δ ∈ ℝ^n}`（定义 319）：固定 `K` 下整条轨道给出相同力读数，OSD 必须显式标记该不可辨识方向。

**定义 315（力-几何信息增益 PAD）** 探询的信息增益
`VoI(u) = H(θ|o) − E_{y_f}[H(θ|o, y_f(u))]`。
高斯近似下
`VoI(u) ≈ ½ log det(I + Σ_post^{1/2} Ω_f(u) Σ_post^{1/2})`，
并只在任务风险度量 `M` 下的 `F ∪ R` 子空间计分。选择
`u* = argmax_{u ∈ 𝒰_adm} [VoI(u) − c(u)]`，
其中 `𝒰_adm` 由定义 316–317 的接触安全与撤退证书给出。若 `VoI(u*) ≤ c(u*)`，或 `F ∪ R` 上没有显著 epistemic 分量，则不接触；R69 的 gaze/ask 候选与接触候选在共同任务风险度量下比较，不可比时优先非接触动作。

**定义 316（接触安全滤波 CCF）** 安全集
`C = { f_n ≤ f_max, |f_t| ≤ μ_s f_n − δ_μ, |m| ≤ m_max, δ_pen ≤ δ_max, E_tank ≥ 0 }`。
对每个约束定义控制屏障函数 `h_i(x)`，在 QP 中强制 `ḣ_i + α_i h_i ≥ 0`；用无源性能量罐限制接触能量注入/抽取；接近速度满足 `v_n ≤ v_contact` 以避免冲击。任一约束不可行 ⇒ 该探询不可采纳。

**定义 317（可恢复性证书）** 给定信念的可信集 `B_δ(b)`（后验质量 `≥ 1−δ`），探询 `u` 持有撤退证书，当且仅当存在撤退策略 `π_ret`，使得对任意前缀 `τ ≤ u` 与任意 `θ ∈ B_δ(b)`，执行 `π_ret` 都能在有限时间内回到安全自由空间，且全程力/能量不超过安全界。若不存在这样的 `π_ret`，则 `u` 不可采纳——哪怕它的 VoI 很高。

**定义 318（接触因子图 CFG）** 维护物体位姿与局部曲面的联合后验，因子包括：
视觉点-面残差、物体位姿先验、语义关键点；接触点-在-曲面上、法向对齐、摩擦锥不等式、准静态力旋量平衡、柔顺先验。
接触因子只有在探针通过定义 320 的激发证书与定义 322 的证据纪律后才允许加入；更新结果回写三维地图（物体位姿、被遮挡表面、局部曲率）。在线性高斯近似下，接触因子只会降低协方差，不会增加（定义 322 的不一致因子除外）。

**定义 319（力一致性残差 FCR 与规范检验）** 采用局部线性接触模型 `w = K(x − x_s) + d + ε_f`。预测力旋量 `ŵ(θ, u)`，残差 `r_f = w − ŵ`，归一化异常分 `a_c = ||r_f||_{Σ_f}^{-1}`。规范检验：固定 `K` 时，`(x_s, d)` 只能辨识到轨道 `G`；改变阻抗档位 `K_i` 后，若反推的表面位置 `x_s` 随 `K_i` 发生系统性平移，则存在未建模外部扰动或接触模型误差；若 `x_s` 对 `K_i` 不变，则几何与模型自洽。残差分类：
- 几何误差：随法向力/探询方向变化，且与视觉残差同向；
- 外部扰动：在短时窗内近似加性、与阻抗档位无关；
- 接触模型误差：随力幅/刚度非线性变化，常伴随迟滞或饱和。

**定义 320（激发充分性证书 EPC）** 探针 `u` 被称为信息性探针，当且仅当：
(a) 期望 `VoI(u) ≥ τ_info`；
(b) 测得响应信噪比 `SNR ≥ τ_snr`，统计功效 `≥ 1−β`；
(c) 至少激发一个任务相关的 `F ∪ R` 方向。
否则结论为 **inconclusive**：不得把「没有测到差异」写成「已确认一致」，只能以「无信息」因子更新，或直接退回 R69。该证书专门阻断「轻触一下就算验证」的假确认。

**定义 321（不可逆预算 IRB）** 对探询 `u` 与信念 `b`，定义不可逆风险
`R_irr(u) = CVaR_α[ C(e) | u, b ]`，
事件 `e ∈ {crush, slip/drop, topple, scratch, human_pain, joint_overload}`，`C(e)` 为非对称代价。硬约束 `R_irr(u) ≤ ε_irr`，并按物体类别/人体在场状态维护分项预算。若无探针能满足该约束，接触被禁止，退回 R69/R68 的保守策略。

**定义 322（接触信任与证据纪律 FTP）** 力证据的信任分
`T_f = g(efference_copy_consistency, excitation_power, cross_modal_agreement, independence)`。
只有 `T_f ≥ τ_trust` 且至少一个独立源（视觉几何，或另一组不同阻抗的探针）一致时，力证据才是**确认性**的；否则只是建议性证据。单次力读数永远不能单独定案。该纪律把 R69 的「k 个正交证据源一致」从语言/视觉扩展到物理接触，并显式承认力通道也会被伪造。

**定义 323（接触模式流策略 FMP-C）** 在 R69 的流匹配策略上把动作块扩展为 `x_1 = (a, u)`：任务动作 `a` 与接触探询 `u` 联合生成。速度场 `v_θ(x_s, s | o, b)` 以接触信念 `b` 为条件；目标
`L_FM-C = E_{s,x_0,x_1} || v_θ(x_s, s | o, b) − (x_1 − x_0) ||²`。
采样后按轨迹聚类得接触模式 `{m_k^c}`；`mode_head^c(z)` 廉价预测接触歧义，决定是否升采样数 `K`。R69 的 `g_probe` 是本定义中「零接触、零力」的退化成员。

## 3. 推导

假设 A99–A103：A99 接触模型在可信集内可局部线性化，视觉/力噪声高斯且雅可比可估；A100 外部力旋量在一次探询对内近似常值、加性；A101 接触安全集非空、CBF-QP 可行、能量罐与未知刚度界可用；A102 三维接触流形误差有界且已标定；A103 不可逆代价与撤退策略可估，CVaR 估计已校准。

**引理 19（双空间互补性）** 在 A99 下，联合 Fisher 信息为 `F = Ω_v + Ω_f(u)`。若方向 `v ∈ null(J_v)`，则视觉数据对 `v` 不提供任何曲率；只有 `J_f(u)v ≠ 0` 时力探询才能降低 `v` 方向方差；若 `v ∈ null(J_v) ∩ null(J_f(u))`，则任何探针都无法降低该方向方差（Cramér–Rao 下界）。系：沿视线方向的深度在遮挡/透明表面常落入 `null(J_v)` 却可被力激发；遮挡物背后的自由空间常同时落入两者（盲区），必须按未知处理而不能由接触「脑补」。

**引理 20（力觉的规范歧义）** 在固定阻抗的线性接触模型 `w = K(x − x_s) + d` 中，对任意 `δ`，变换 `x_s' = x_s + K^{-1}δ`、`d' = d + δ` 使所有 `x` 下的 `w` 完全不变。因此仅凭固定阻抗的力数据，`(x_s, d)` 只能辨识到轨道 `G`；力通道无法单独给出绝对几何，也无法单独区分「表面偏移」与「外部推挤」。这正是力不能替代三维感知的根本原因。

**引理 21（变阻抗打破规范；规范检验）** 令探针 `i` 使用不同刚度 `K_i`、位置 `x_i`，观测 `w_i = K_i(x_i − x_s) + d`。若 `{K_i}` 中至少两档不可交换/不相似，则 `(x_s, d)` 在该探针组下的可辨识性矩阵满秩，规范轨道被打破；若 `K_i` 恒定，则秩亏恰为定义 314 的轨道维数。系：**阻抗调度是一个识别仪器**——若反推的 `x_s` 随 `K_i` 系统性平移，说明存在未建模 `d` 或接触模型误差；若不变，则几何与模型自洽。该检验构成 FCR 的分类依据。

**引理 22（接触因子收缩）** 在线性高斯信息滤波中，加入接触因子后的后验精度 `Ω_post = Ω_prior + Ω_v + Ω_c`，协方差 `Σ_post = Ω_post^{-1} ⪯ (Ω_prior + Ω_v)^{-1}`；在任意方向 `v` 上，若 `J_c v ≠ 0`，则收缩严格为正。系：接触点/法向因子主要收缩沿接触法向的深度不确定性，而这恰是深度相机最弱的方向；接触因子因此是对三维感知的定向校正，而不是全局重测。

**引理 23（激发充分性与假确认上界）** 设两个接触假设在探针 `u` 下的期望对数似然比为 `τ`。由贝叶斯因子定义，后验几率至多放大 `e^τ` 倍。因此当 `τ < τ_info` 时，任何「确认」都只能是弱证据；EPC 要求 `τ ≥ τ_info` 与统计功效 `≥ 1−β`，从而把「轻触=已验证」的假确认概率压到 `≤ β` 量级。系：不充分探询的正确结论是 inconclusive，而不是 confirmation。

**定理 18（FORGE 对 R69 的安全包含）** 在 A99–A103 下，FORGE 的任一决策要么逐指令等于 R69（无合格探针、VoI 不抵成本、EPC 失败或盲区越界），要么增加一次满足 `R_irr ≤ ε_irr` 且持有撤退证书的接触探询。因此新增风险有硬上界 `ε_irr + R_retreat`，安全侧不做无界让步；当接触层关闭时行为与 R69 完全一致。结合 R69 对 R68 的退化，得到严格层级 `R68 ⊂ FLUID-RAS ⊂ FORGE-RAS`：接触层只在能证明「值得且能收回」时打开。

**定理 19（接触安全与无突变）** 在 A101 下，CCF 的 CBF-QP、无源性能量罐、接近速度界与撤退证书共同保证：探询全程法向力/力矩/能量有界，接触过渡的冲击冲量有界，且对可信集内每个假设都存在回到安全自由空间的撤退轨迹；探询失败/超时/滑移/饱和时，控制器单调退回 R69 的保守包络。故接触层不改变 R69 的安全不变式，只在其边界内增加一个可撤回的物理查询。

## 6. 本轮最大风险

**一句话**：FORGE-RAS 把「不可逆的物理接触」当成可反复查询的传感器——**一旦接触模型、三维几何或规范分解出错，系统会在「以为在求真」时把物体捏坏、推倒、划伤，或让人受伤；R69 的问句可以撤回，接触不能。**

**次级风险与缓解**：
1. **接触模型线性化失效**（软物体、间隙、迟滞、非线性摩擦）→ 只在可信集内声明可观测性；FCR 检测模型误差；EPC 不通过即不写地图；必要时退回 R69。
2. **盲区被误当可测** → OSD 显式标记 `B`；安全关键参数在 `B` 上非零则禁止接触，靠机械设计/任务改写消除，而不是多摸。
3. **不可逆预算估计偏乐观** → CVaR + 物体类别分项预算 + 人体在场硬阈值；任何超预算探针直接作废。
4. **假确认与力证据污染** → EPC + 变阻抗规范检验 + 至少一个独立源一致；单次力读数永不单独定案；接触因子需证书后才写回地图。
5. **实时预算被接触层击穿** → 接触相计算异步化；无接触路径与 R69 同延迟；物理探询时长与计算预算分离核算。

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** `FORGE-RAS=(CGB,OSD,PAD,CCF,IRB,CFG,FCR,EPC,VQAuditor-G,RAS-WM†)`；零学习写操作继承；接触预算硬约束（力/能量/时长/不可逆风险/撤退证书）；证据纪律（单次力读数不得定案）；单调退化（无合格探针即回 R69）。

**定义 311–312（CGB 与三维接触流形）** `θ=(T_o,S,μ,k,σ)`；`U_ale^c=Σŵ trΣ`，`U_epi^c=H(H)·g(Δ_min^c)`；视觉 `y_v=h_v(θ)+ε_v`，`Ω_v=J_v^TΣ_v^{-1}J_v`；`Σ_v` 编码深度沿视线退化、透明/反光/遮挡误差。

**定义 313（阻抗探询）** `u=(x_d(t),K_d(t),D_d(t),f_max,T)`；阻抗律 `τ=J^T[K_d(x_d−x)+D_d(ẋ_d−ẋ)+f_ff]+g(q)`；测力旋量 `w=(f,m)`；`y_f=h_f(θ,u)+d+ε_f`，`Ω_f(u)=J_f^TΣ_f^{-1}J_f`。

**定义 314（OSD 与规范）** 在风险度量 `M` 下按 `J̃_v=M^{1/2}J_v`、`J̃_f=M^{1/2}J_f` 分解 `V/F/R/B`；`U_B=tr(M^{1/2}P_BΣ_post P_B M^{1/2})`；安全关键参数若在 `B` 上非零则禁止接触；固定 `K` 下存在规范轨道 `G`，必须显式标记。

**定义 315（PAD）** `VoI(u)=H(θ|o)−E[H(θ|o,y_f(u))]`；高斯近似 `≈½logdet(I+Σ_post^{1/2}Ω_f(u)Σ_post^{1/2})`；`u*=argmax[VoI−c]`，s.t. 可采纳；`VoI≤c` 或不显著则回 R69。

**定义 316–317（CCF 与撤退证书）** 安全集 `C={f_n≤f_max, |f_t|≤μ_s f_n−δ_μ, |m|≤m_max, δ_pen≤δ_max, E_tank≥0}`；CBF 约束 `ḣ_i+α_i h_i≥0`；接近速度 `v_n≤v_contact`；探询需对可信集 `B_δ(b)` 中每个假设存在安全撤退策略 `π_ret`。

**定义 318（CFG）** 因子：视觉点-面/位姿/关键点；接触点-在-曲面/法向对齐/摩擦锥/力旋量平衡/柔顺先验。接触因子仅在 EPC 与证据纪律通过后加入，更新回写三维地图。

**定义 319（FCR 与规范检验）** `w=K(x−x_s)+d+ε_f`；`r_f=w−ŵ`，`a_c=||r_f||_{Σ_f}^{-1}`；固定 `K` 时 `(x_s,d)` 只辨识到轨道 `G`；改变 `K_i` 后若反推 `x_s` 随 `K_i` 平移 ⇒ 外部扰动/模型误差；若不变 ⇒ 几何自洽。残差三分类：几何误差/外部扰动/接触模型误差。

**定义 320（EPC）** 信息性探针：期望 `VoI≥τ_info`、`SNR≥τ_snr` 且功效 `≥1−β`、至少激发一个任务相关 `F∪R` 方向；否则结论为 inconclusive，禁止写成「已确认」。

**定义 321（IRB）** `R_irr(u)=CVaR_α[C(e)|u,b]`，事件含压碎、滑落、倾倒、划伤、人体疼痛、关节过载；硬约束 `R_irr≤ε_irr`，按物体类别/人体在场维护分项预算；无合格探针则禁止接触。

**定义 322（FTP）** `T_f=g(efference_copy_consistency, excitation_power, cross_modal_agreement, independence)`；`T_f≥τ_trust` 且至少一个独立源一致才可确认；单次力读数只作建议证据。

**定义 323（FMP-C）** 动作块 `x_1=(a,u)`；`v_θ(x_s,s|o,b)`；`L_FM-C=E||v_θ−(x_1−x_0)||²`；聚类得接触模式；`mode_head^c` 廉价预测接触歧义；R69 的零力探询是其退化成员。

**定义 324–326（证书/退化/审计）** `J_FORGE=(J_FLUID, contact_belief_hash, obs_split, probe_log_hash, excitation_power, force_consistency, irreversibility_risk, retreat_certificate_hash, map_update_hash, forge_ver)`；无合格探针时逐指令等于 R69，盲区越界或风险不可控时回 R68；VQAuditor-G 审计探针依据、激发、撤退、力证据加权与地图污染。

# IP-264 CGB：三维感知 → 接触几何信念
def contact_belief(obs3d, prior):
    M = extract_contact_manifold(obs3d.pointcloud, obs3d.tsdf)
    H = sample_contact_hypotheses(M, prior, K=8)
    return ContactBelief(H, weights(H), covs(H), M)

# IP-265 OSD：可观测子空间 + 规范轨道
def observability_split(belief, risk_metric):
    Jv, Jf = belief.visual_jacobian(), belief.force_jacobian()
    V, F, R, B = subspace_decompose(sqrtm(risk_metric) @ Jv,
                                    sqrtm(risk_metric) @ Jf)
    gauge = contact_gauge_orbit(belief)          # x_s, d 的不可辨识轨道
    return ObsSplit(V, F, R, B, gauge, P_B=projector(B))

# IP-266 PAD：安全且可恢复的阻抗探询
def design_probe(belief, split, budget):
    best = None
    for u in probe_candidates(belief, split):      # 压/擦/点/转/松
        if not ccf.admissible(u, belief): continue # CBF + 能量罐
        if not retreat.certify(u, belief): continue
        risk = irb.cvar(u, belief)
        if risk > budget.eps_irr: continue
        voi = gaussian_voi(belief.cov, belief.force_info(u), split.task_metric)
        score = voi - cost(u) - risk_penalty(risk)
        if best is None or score > best.score: best = (u, voi, risk)
    return best if best and best.voi >= TAU_INFO else None   # 无利可图 → R69

# IP-270：变阻抗规范检验 + FCR
def probe_and_check(robot, u, belief):
    w1 = robot.impedance_probe(u)
    u2 = impedance_schedule(u)                     # 改变 K_d 的第二档
    w2 = robot.impedance_probe(u2)
    r_f, gauge_shift = force_consistency(w1, w2, belief, u, u2)
    epc = excitation_certificate(u.voi, snr(w1, w2))
    return w1, w2, r_f, gauge_shift, epc

# IP-276 FORGE 主闭环：只在接触空白处插入，失败即回 R69
def FORGE_RAS_round(M, obs):
    b     = M.cgb.contact_belief(obs)
    split = M.osd.split(b, M.risk_metric)
    modes = M.fmp_c.sample(obs, b, K=4 if M.mode_head_c.maybe_ambiguous(b) else 1)
    U_ale, U_epi_a, U_epi_c = M.aud.decompose(modes, b)
    needs = (split.has_force_epistemic(U_epi_c)
             and not M.mcg.blocked() and split.blind_ok())
    u = M.pad.design_probe(b, split, M.irb.budget) if needs else None
    if u is None:
        return M.fluid_round(obs)                  # 精确 R69 边界
    w1, w2, r_f, gauge_shift, epc = M.probe_and_check(u, b)
    if not epc.passed:
        return M.fluid_round(obs)                  # inconclusive ≠ confirmed
    b_post = M.cfg.update(b, w1, w2, r_f, M.map)  # 证书通过才写地图
    M.vqa_g.submit(u, epc, r_f, gauge_shift, b, b_post)
    return M.fluid_round(obs, contact_belief=b_post)

## 4. 推导

假设 A99–A103：局部接触可线性化、噪声高斯、雅可比可估；外部力旋量在一次探针对内近似常值加性；接触安全集/CBF/能量罐可用；三维接触流形误差有界；不可逆代价与撤退策略可估且 CVaR 已校准。

**引理 19（双空间互补）** `F=Ω_v+Ω_f(u)`；方向 `v∈null(J_v)` 只能由 `J_f(u)v≠0` 的力探询降低方差；若 `v∈null(J_v)∩null(J_f(u))`，任何探针都不可约（Cramér–Rao）。系：沿视线深度/遮挡接触片是力可补的视觉盲区，但遮挡背后的自由空间是双盲区，不能由接触脑补。

**引理 20（力觉规范歧义）** `w=K(x−x_s)+d` 在变换 `x_s'=x_s+K^{-1}δ, d'=d+δ` 下不变；固定阻抗的力数据只能辨识到轨道 `G`，无法单独区分表面偏移与外部推挤。力不能替代三维感知，必须由视觉定规范。

**引理 21（变阻抗打破规范）** 不同刚度 `K_i`、位置 `x_i` 的探针 `w_i=K_i(x_i−x_s)+d`；若 `{K_i}` 至少两档不相似，则可辨识性矩阵满秩，规范轨道被打破；若 `K_i` 恒定，则秩亏等于轨道维数。系：阻抗调度是识别仪器；反推 `x_s` 随 `K_i` 系统性平移 ⇒ 外部扰动/模型误差；不变 ⇒ 几何自洽。

**引理 22（接触因子收缩）** 信息滤波中 `Ω_post=Ω_prior+Ω_v+Ω_c`，`Σ_post⪯(Ω_prior+Ω_v)^{-1}`；若 `J_c v≠0` 则沿 `v` 严格收缩。系：接触点/法向因子定向收缩沿接触法向的深度不确定性，恰是深度相机最弱方向。

**引理 23（激发充分性与假确认上界）** 两假设在探针下的期望对数似然比为 `τ`，则后验几率至多放大 `e^τ`；`τ<τ_info` 时任何「确认」只能是弱证据。EPC 要求 `τ≥τ_info` 且功效 `≥1−β`，把假确认压到 `≤β` 量级；不充分探询只能记 inconclusive。

**定理 18（FORGE 对 R69 的安全包含）** A99–A103 下，FORGE 决策要么逐指令等于 R69（无合格探针、VoI 不抵成本、EPC 失败、盲区越界），要么增加一次 `R_irr≤ε_irr` 且持有撤退证书的接触探询；新增风险硬上界 `ε_irr+R_retreat`。故安全侧不做无界让步，接触层关闭时与 R69 完全一致；结合 R69⊂R68 的退化得 `R68⊂FLUID-RAS⊂FORGE-RAS`。

**定理 19（接触安全与无突变）** CCF 的 CBF-QP、无源性能量罐、接近速度界与撤退证书共同保证探询全程力/力矩/能量有界、接触冲击冲量有界、可信集内每个假设都有安全撤退轨迹；失败/超时/滑移/饱和时单调退回 R69 保守包络，不改变 R69 的提交/换装安全不变式。

## 7. 本轮最大风险

**一句话**：FORGE-RAS 把「不可逆的物理接触」当成可反复查询的传感器——**一旦接触模型、三维几何或规范分解出错，系统会在「以为在求真」时把物体捏坏、推倒、划伤，或让人受伤；R69 的问句可以撤回，接触不能。**

**次级风险与缓解**：
1. **接触模型线性化失效**（软物体、间隙、迟滞、非线性摩擦）→ 只在可信集内声明可观测性；FCR 检测模型误差；EPC 不通过即不写地图，必要时退回 R69。
2. **盲区被误当可测** → OSD 显式标记 `B`；安全关键参数在 `B` 上非零则禁止接触，靠机械设计/任务改写消除，而不是多摸。
3. **不可逆预算估计偏乐观** → CVaR + 物体类别分项预算 + 人体在场硬阈值；任何超预算探针直接作废。
4. **假确认与力证据污染** → EPC + 变阻抗规范检验 + 至少一个独立源一致；单次力读数永不单独定案；接触因子需证书后才写回地图。
5. **实时预算被接触层击穿** → 接触相计算异步化；无接触路径与 R69 同延迟；物理探询时长与计算预算分离核算。
