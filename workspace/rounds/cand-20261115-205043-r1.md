## 1. 三个灵感的合成逻辑（直觉与动机）

**灵感 1「Isaac Sim」→ 数据是当前唯一可控的杠杆。**
每任务 ~1000 条、每条仅 ~6 秒的干净短示教（F5），而评测按五类泛化轴计分（F3）——位置变化、干扰物、背景、未见物品、人为干扰恰好都是 32k 演示里覆盖最薄的方向，「人为干扰」轴在官方数据里甚至没有任何恢复片段。结论：**泛化轴就是数据需求说明书**。Isaac Sim/Isaac Lab 把评测协议反变成数据生成协议：把五类场景显式编码为五个随机化轴（GA-DR），对每条真机 demo 做任务级场景重建后定向扩增。这是与「32k demo 直接微调 VLA」的社区主流路线最大的差异点。

**灵感 2「通用机器人」→ 瓶颈大概率不在「会不会做」，而在「换了也不慌」。**
32 任务各有 1k demos，任务内技能可学；把 <30%（待核实，F8）的失败按五轴分解，失分应集中在未见物品/人为干扰/背景三轴。架构主线因此是「物体中心 + 双系统 + 世界模型前瞻」的混合通才策略，而非更大的端到端 Transformer：像素级端到端对背景脆弱；单次前向选 chunk 对干扰是盲打。更关键的是，本评测的接口形态（F6：chunk 间有网络间隙、允许每步重规划、观测/动作 chunk 化）天然给「想一想再动」留了算力窗口——这是本赛事特有、连续控制场景里没有的可乘之机；官方 WMA-0 世界模型（F7）同平台同格式，微调成本低。

**灵感 3「专利布局」→ 用专利性当创新点的筛选器与护栏。**
参赛产出不止名次：GA-DR、干扰算子合成、动作块级 WM 前瞻选择、干扰证据二分触发器、稳态尾动作块，都是「方法+系统」可写权利要求的组件。同时必须 FTO：Physical Intelligence、NVIDIA（GR00T）、字节等在 VLA/世界模型方向已有大量申请，创新点须落在「组合差异」上（新触发条件、新损失、新接口语义）。本轮先立专利候选清单与公开时序纪律（先申请、后开源/发论文，防自毁新颖性），专利检索留待下轮。

## 4. 与现有方案差异（一览）

- vs 社区主流「32k demo 直接微调 VLA」：加五轴定向合成数据 + 干扰恢复对，攻的正是计分面。
- vs 盲目域随机化：GA-DR 以评测协议为蓝本、以真机 demo 为校准锚，随机化有方向。
- vs 纯端到端：物体中心表征 + 检索增强 + 双系统，专治背景/未见物品/人为干扰三轴。
- vs 单次前向出 chunk：动作块级 WM 前瞻 + 置信门控，评测接口的独有红利。
- vs 只管模型：可信度工程与接口参数最优化是无人区。

## 5. 资源与实时预算（估算）

- 合成数据引擎：Isaac Lab 开源免费；8×RTX4090 约 2 周产 ~10 万条合成 episode（每任务 3–5k 估）；人力：场景重建 3–4 人周，Dex1 夹爪近似为最大不确定项。
- 训练：底座微调 8×H100 × 3–7 天量级（按 π0/GR00T 公开微调配置外推）；OCRA 蒸馏 4×4090 × 2 天。

## 7. 本轮最大风险

**一句话**：五类泛化场景目前只有官方的定性描述（规则手册抓不到、任务页需登录，F3/F9），**数据引擎可能在为「想象中的评测」造数据**——干扰物是什么、人手怎么干扰、位置扰动多大、未见物品池多广全靠猜；猜错方向，合成数据越多毒性越大。
**缓解**：(1) 用官方 demo 的场景/物体元数据反推真实分布；(2) 立即申请账号与 Submit Test 档期，把每次真实评测设计成「分布探测实验」；(3) GA-DR 各轴强度参数化，一次探测后整体重标定。

# 第 70 轮产物 · 创新点清单 v1：PARALLAX-RAS（Placement Ambiguity Resolution via Active muLti-view eXamination：多视角几何见证 × 任务等价商 × 不可逆承诺屏障的放置消歧闭环；MVW×TEQ×PAD×ANV×WIT×FMA-V×PCB×MVC×PVG×PSE×RAS-WM§）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 把不确定性分成 aleatoric / epistemic，并让 epistemic 通过「问/探/看」消解。但它把**「策略不知道」与「我看不见」混为一谈**（观测是已融合的单一 `o_t`），也没有区分**可逆探询**与**不可逆释放**（松手不能反放置）。对放置任务，这两点恰好是主要矛盾：大量歧义来自遮挡/单目深度/透明反光/未知支撑面；而释放一旦发生就无法撤回。
>
> 本轮用两个灵感补齐：
> - **多视角视觉**给出与流策略密度正交的**世界见证**通道：真放置假设必须在独立视角下可重投影、可见支撑面、深度一致；视差能溶解单视角伪影。
> - **放置**给出任务结构：目标常是区域/关系（**多解不是歧义**，需任务等价商），成功是确定性谓词（可算），释放不可逆（需随不可逆度收紧的承诺屏障）。
>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**换个视角歧义还在吗；放手前谁能为它作证**」。
>
> IP 编号：IP-264~IP-275（共 12 个）。理论姿态：**R69 是 PARALLAX 在「单视角 + 可逆 + 几何通道静默」边界上的严格退化；对不可逆放置只会更严，不会更松。**

## 2. 形式化定义（要点版）

**定义 310（总览与四不变式）** 零学习写操作继承；视角预算与安全（≤B_v、位移≤ε_v、换视角过 C-RAS-WM）；见证纪律（不可逆释放需 `n_eff≥2` 且 MVC 有效）；不可逆单调性（证据门槛随 `irr` 不降）。

**定义 311–312（多视角观测与放置谓词）** `y_i = h_i(p,S)+b+ε_i`，`b` 为共模偏置；`Succ(p,S)` 编码支撑/稳定/无碰撞/语义。重投影-深度残差 `r_i`。

**定义 313（任务等价商 TEQ）** `p ~ p' ⇔ Pr[Succ(p,S)≠Succ(p',S)] ≤ δ_eq`；只在商空间算 `U_epi^quot = H([M]|o)`。**多解不是歧义。**

**定义 314（三分）** `U_ale`（模态内噪声）→ λ floor；`U_epi^pol`（商空间策略歧义）→ MINT 问/探；`U_epi^geo`（给定视角的几何后验熵）→ ANV 换视角。三者不简单相加。

**定义 315–316（见证与视差）** `W(c)={i: visible ∧ r_i≤τ_geo ∧ support_observed ∧ depth_consistent}`；`n_eff≥2` 才算见证。`S_v(c,c')=δ_v/σ_pix`；若所有可用视角 `max S_v < z_{1−α}` 则几何不可分，换视角无益。

**定义 317（ANV）** `v* = argmax_v [VoI_view(v) − c_motion(v) − c_risk(v)]`，s.t. 认证与预算。R69 的注视是零基线退化情形。

**定义 318（WIT）** 由残差相关 `ρ̄` 得 `n_eff=|W|/(1+(|W|−1)ρ̄)`；`ρ̄→1` 时 `n_eff→1`，任意多视角「一致」只等于一次观测。

**定义 319（FMA-V）** 每视角 `a_score^{(i)}`；`ā=median`，`D_a=MAD`。真模态跨视角稳定；幻影/单视角伪影 `D_a` 大。与 R69 `Δa` 组成二维第二意见。

**定义 320（PCB）** 释放当且仅当：后验 `≥1−δ_irr(irr)`、`n_eff≥2`、MVC 有效、PSE 最坏情形通过、hover 不翻转；否则重抓/撤离/交接。

**定义 321–323（MVC/PVG/PSE）** 保形覆盖 + `ECE_mv`，越界禁用释放；无见证且 ANV 无法改善的类不得承诺；最坏情形支撑多边形/间隙/语义检查，`Pr_fail^{worst}≤ε_place`。

**定义 324–327（审计/退避/调度/溯源）** `J_PARALLAX` 并入见证与承诺字段；两级退避 + 几何 resolution bonus，失败走安全回退；视角预算按 reach→transport→hover→release 分配，hover 信息量最大；证据 DAG 让单相机篡改无法凑出 `n_eff≥2`。

## 3. 关键算法伪代码

```python
# IP-264 MVW：多视角见证
class MultiViewWitness:
    def witness(self, cand, views, calib):
        W = []
        for i, v in enumerate(views):
            if not visible(cand, v): continue
            if reproj_depth_residual(cand, v) <= TAU_GEO \
               and support_observed(cand, v):
                W.append(Witness(i, v.calib_provenance))
        return WitnessSet(W, n_eff=independence_test(W, calib))

# IP-265 TEQ：任务等价商（多解合并）
def task_quotient(modes, succ_probe, delta_eq=1e-2):
    classes = []
    for m in modes:
        for c in classes:
            if outcome_diff(m, c, succ_probe) <= delta_eq:
                c.add(m); break
        else: classes.append(EquivClass([m]))
    return classes

# IP-266 PAD：三分
def decompose3(samples, z, views):
    modes = cluster_trajectories(samples)
    cls   = task_quotient(modes, succ_probe)
    U_ale = sum(w[k]*trace(cov(modes[k])) for k in modes)
    U_pol = entropy(class_weights(cls))
    U_geo = geometric_posterior_entropy(views, cls)
    return U_ale, U_pol, U_geo, cls

# IP-267 ANV：主动下一视角
def choose_view(cls, views, budget, c_ras_wm):
    best = None
    for v in candidate_views(cls):                  # 腕转 / 基座平移 / 变焦
        if not budget.allow(v) or not c_ras_wm.certify_view(v): continue
        score = (entropy(class_weights(cls)) - expected_entropy(cls, v)
                 - motion_cost(v) - risk_cost(v))
        if best is None or score > best.score: best = (v, score)
    return best if best and best.score > 0 else None

# IP-268 WIT：有效独立见证数
def independence_test(W, calib):
    rho = mean_pairwise_residual_corr(W, calib)
    return len(W) / (1.0 + (len(W)-1.0)*rho)        # ρ→1 ⇒ n_eff→1

# IP-269 FMA-V：视角条件流似然
def flow_anomaly_mv(policy, xi, views):
    a = [-policy.log_likelihood(xi, v) for v in views]
    return median(a), mad(a)                        # 幻影：单视角尖峰

# IP-270 PCB：承诺门
def may_commit(cls, W, irr, mvc, pse, hover):
    c = argmax(class_probs(cls))
    return (class_prob(cls, c) >= 1 - delta_irr(irr)
            and W.n_eff >= 2 and mvc.valid()
            and pse.worst_case_ok(c, W) and hover.stable(c))

# IP-275 主闭环
def PARALLAX_round(M, obs):
    z = M.mtm.forward(obs)
    U_ale, U_pol, U_geo, cls = M.pad.decompose3(
        M.fmp.sample(obs, K=4), z, obs.views)
    g = M.mint.choose_interaction(cls, obs, M.budget) if U_pol > TAU_POL else None
    v = M.anv.choose_view(cls, obs.views, M.budget, M.c_ras_wm) if U_geo > TAU_GEO else None
    if v is not None: obs = M.mvw.acquire(v)
    W = M.mvw.witness(best_class(cls), obs.views, M.calib)
    a_hat, D_a = M.fmav.flow_anomaly_mv(M.fmp, M.last_action, obs.views)
    phantom = M.pvg.check(best_class(cls), W, a_hat, D_a)
    if (not phantom) and M.pcb.may_commit(cls, W, irr(M), M.mvc, M.pse, M.hover):
        tau = commit_control(cls)
    else:
        tau = M.pi_sigma.prefix_dispatch(safe_fallback(cls),
                                         lam_floor(U_ale + U_pol + U_geo))
    M.vqav.submit_async(v, W, phantom, a_hat, D_a, irr(M))
    return tau, cls, W, (U_ale, U_pol, U_geo)
```

## 4. 推导

**引理 19（任务等价商只减冗余）** 只在类内区分的信息动作满足 `Pr(Succ|o,y)=Pr(Succ|o)`，任务 VoI 为零；商空间保留全部非零任务 VoI。系：放置的「桌面上哪个点」大多同类，TEQ 把预算集中到「桌沿内/外」等后果不同的类。前提是等价关系必须经多视角见证，否则单视角误并会造成反效果。

**引理 20（视差可分性与几何不可约）** 深度 `z`、横向间隔 `Δx_⊥` 下 `δ≈fΔx_⊥/z`，引入基线 `b` 后 `S≈f(b/z²)Δx_⊥/σ_pix`（一阶）。若所有可用视角 `max_v S_v < z_{1−α}`，贝叶斯误分率有下界，**几何不可分**：此时应保守/重抓/交人，而非继续换视角或追问。

**引理 21（见证独立性与共模上界）** `Var(y_i)=ρσ²+(1−ρ)σ²` 的共模模型下，均值估计方差 `σ²[ρ+(1−ρ)/n]`，故 `n_eff=n/(1+(n−1)ρ)`。`ρ→1` 时 `n_eff→1`，任意多视角一致只等于一次观测；朴素「两视角一致」规则失效，且系统更自信。系：必须显式估计 `ρ` 并用 `n_eff` 写进承诺门。

**定理 18（PARALLAX 严格包含 FLUID/R68）** `V=1`、`U_epi^geo≤τ_geo`、`irr=0` 且见证门失效时，ANV 不触发、TEQ 不改模态集合、PCB 恒真 ⇒ 逐指令等于 FLUID；再在 FLUID 退化边界上等于 R68。MVC 有效时，几何见证只删除无见证类、不新增候选，故承诺门内期望风险 ≤ R69；MVC 越界或 `n_eff<2` 时强制回退。**R69 = 单视角 + 可逆 + 几何静默边界。**

**定理 19（不可逆承诺的安全门）** PCB 满足四条件时，提交类真实失败概率 `≤ α_conf + ε_place + δ_irr(irr)`；去掉独立性（`n_eff=1`）则退化为数据先验失败率，共模下无保证。`δ_irr(irr)` 单调不增 ⇒ 可提交集合随不可逆度单调收缩（安全单调性）。系：不可逆释放必须是「两个独立见证 + 保形覆盖 + 最坏稳定 + hover 不翻转」，缺一不放。

**定理 20（视角预算边际收益递减）** 增加视角使方差按 `σ²(1−ρ)/n²` 下降，但共模下界 `ρσ²` 不可消除；`VoI_view` 在 `n_eff` 饱和后迅速归零。系：最优预算通常在 `n_eff≈2` 或 `VoI−成本≤0` 处停止。

## 7. 本轮最大风险

**一句话**：PARALLAX 的全部安全收益押在「多视角见证是独立的」这一前提上——**若多个视角被同一物理共模（透明/反光/重复纹理/共享标定漂移）一起骗过，而 `ρ` 估计失效，系统会把「同一个错误的 n 次复制」当成 `n_eff≥2` 的独立证据，并在不可逆释放上比 R69 更自信；此时「多视角一致」不是解药，而是把「诚实的不知道」升级成「集体背书的自杀式放手」——共同的错，比单独的错更危险。**

**次级风险与缓解**：视角运动本身碰撞/遮挡（C-RAS-WM 认证 + 定义 317 风险项）；TEQ 误并后果不同的类（多视角见证前提 + 保守 `δ_eq`）；ANV 在几何不可分处空转（引理 20 早停）；保形校准在分布外失效（MVC 越界即禁用释放）；hover 验证拖长节拍（定义 326 分阶段预算 + hover 窗上限）。
