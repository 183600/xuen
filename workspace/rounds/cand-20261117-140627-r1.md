# 第 12 轮（本次会话第 1 轮；研究线累计 v12；本轮灵感：「自然语言指令」×「单模型多任务」）

> **基线**：第 11 轮 MetricVoiceGauge-NCD-H（定义 554–561；引理 96–103；实验 E589–E606；IP-363–366）。
> **本轮纪律**：**语言只编译契约，多任务只共享已认证特征，证书只收缩执行集**。不推倒 v11：HAS/HCC/HATD/HDT 与 MetricVoiceGauge 九不变式、NGE/DSL/CC/CWM/CAE/NCP、AC/MW/ID、DA/SPR/Cal 全部保留；新增组件以互不相交的端口接入，失效即注入中立元，严格退回 v11（引理 108 升级版），再沿 v11 十三级链退回 v10/v9/v8/v7/v6。

## 0. 直觉与动机

### 0.1 先看 v11 真正遗留的两个缺口

v11 已经把规范、接触、因果、谐波四类约束接进同一个块级决策闭环，但它默认两件在真实“单模型多任务”测评里并不成立的事：

1. **任务从哪来是给定的。** G_task 由上游直接给出，系统没有回答“一句自然语言指令如何变成一个可检查、可拒绝、可退化的任务契约”。而自然语言天然带歧义、否定、指代、时序与未见过组合；把它当作不可验证的输入，等于把最大的不确定源放在证书链之外。
2. **每个任务各有一套策略与证书。** v11 没有回答“当策略是一个共享参数骨干、多任务联合训练时，一个任务的梯度或数据捷径会不会污染另一个任务的安全头”。单模型多任务的收益是样本效率与跨任务泛化，代价是**参数干扰与同源失效**。

在单模型多任务真机测评（如 UniBot-V1：32 项桌面任务、32000 条演示、169 小时数据；观测含自然语言指令、多视角相机、双臂本体状态；动作为带时间轴的动作块）里，这两个缺口其实是同一个耦合：**语言是任务的选择器，共享骨干是任务的执行器；语言选错 + 多任务污染 = 用一个错误的任务非常一致地执行下去。**

### 0.2 灵感 1（自然语言指令 → 指令契约，而不是自由动作）

直觉：最诱人的叙事是“让 VLM 读懂指令直接产出动作”。但在 v11 这种四重证书系统里，这会把不可验证的语义置信度提升为执行权威：同义改写会改变输出、否定句会被忽略、指代会在长块内漂移、未见过组合会被强行映射到最像的已见任务。语言应当只做两件事——(i) 在**已注册技能、谓词与约束的有限词表**上做选择与参数化；(ii) 表达目标、偏序、否定、预算与证据义务。

核心创新：**指令契约编译器（InstructionContractCompiler, ICC）+ 指令合规证书（InstructionComplianceCertifier, ICert）**。ICC 输出一个**带权候选契约集**而不是单一解析；ICert 检查可接地性、能力闭包（不新增动作）、指代持续性、歧义质量与对 v11 证书的可满足性。语言只提议契约，证书决定能否执行。

### 0.3 灵感 2（单模型多任务 → 共享骨干 + 类型化头 + 干扰预算）

直觉：单模型多任务的价值在于共享表征带来的样本效率与跨任务泛化；危险在于共享参数把“一个任务的数据捷径”变成“所有任务的先验”。尤其当安全关键头（接触/谐波/规范）与任务头共享底层特征时，一次负迁移可能让安全头在别的任务上系统性失准，而任务头仍然高置信。

核心创新：**共享骨干治理器（SharedTrunkGovernor, STG）+ 任务干扰证书（TaskInterferenceCertifier, TIC）**。把参数显式分成**共享特征 θ_sh 与任务私有头 θ_priv^t**；只有当任务对 (t,u) 在安全头上的梯度冲突、表征漂移与共形覆盖差都低于预算时，才允许共享；否则 STG 冻结共享层或切到私有头。**“一个模型”是优化选择，不是安全主张**；TIC 负责把这句话变成可检查的合取项。

### 0.4 灵感 3（两者耦合 → 指令-任务覆盖账本与一致性监控）

直觉：最危险的失败不是“听不懂”，也不是“互相干扰”，而是两者的**同源耦合**：指令说 A，模型执行 B，而指令证书与干扰证书都因为依赖同一个数据集捷径而同时通过。隐藏任务恰恰会改变指令模板、槽位组合与对象/场景，使公开集里稀疏的“任务×指令组合”成为盲区。

核心创新：**指令-任务覆盖账本（InstructionTaskCoverageLedger, ITCL）+ 语言-任务一致性监控（LanguageTaskConsistencyMonitor, LTCM）**。ITCL 按（任务族×指令模板×槽位组合）分层记账，输出**覆盖债**；LTCM 把“活跃任务后验”与“指令契约允许的动作支撑”做一致性检验，漂移超阈就降块长、重接地或追问。覆盖债与一致性分数只允许收紧执行，不允许放宽。

### 0.5 三者如何统一

把决策写成**契约提议、骨干隔离、覆盖校准三层只收缩的闭环**：

```
ℓ, obs ──ICC──> K_ℓ = {κ_i, w_i}（候选契约 + 歧义权重）
          │
          └─ICert─> 删除不可接地/越权/不可满足契约；歧义高 → a_ask / hold
                      │
STG：按活跃任务 t 路由 shared / private / frozen <── TIC（干扰预算）
                      │
        v11 的 HATD/NCP + 物理/接触/谐波/规范四重证书（语义不变）
                      │
              chunk 执行 + LTCM（语言-任务一致性）
                      │
              ITCL 记账 → 覆盖债 → 保守模式 / 块长收紧
```

**ICC 只能加“已注册且可接地”的候选，ICert 只能删，STG/TIC 只能隔离或冻结，LTCM/ITCL 只能收紧许可**——四者都不能扩大 v11 的可执行集。用一句话概括：**语言把任务说清楚，共享骨干把任务分开，覆盖账本把“没见过的组合”显式化。**

### 0.6 为什么不是这些“显然的解法”

| 显然解法 | 为什么不够 |
|---|---|
| 让 VLM 端到端输出动作或技能序列 | 语义置信度不可证书化；同义改写下不稳；失效时无法逐位退回 v11 |
| 对指令只做一次最佳解析 | 歧义被隐藏而非被管理；错误解析会被“自信”放大成整块错误 |
| 用语言模型自带的犹豫/置信度当安全门 | 似然 ≠ 可接地性/可满足性；与训练数据同源，无法自证 |
| 一个共享大模型 + 每任务只换提示词 | 参数与安全头完全共享，负迁移无预算、无证书、无隔离 |
| 多任务统一训练以“互相正则” | 正则收益是平均意义；安全关键头需要最坏情形界 |
| 隐藏任务靠更多公开数据覆盖 | 隐藏分布改的是组合结构，不是样本量；覆盖债必须显式预算 |
| 用同一个校准集同时校准语言与任务 | 同源误差正反馈；需要分层校准与独立证据通道 |

## 1. 研究问题（本轮要回答什么）

- **Q1（可编译性）**：如何把自然语言指令编译成只引用已注册技能/谓词/约束的类型化契约，并证明它不扩张 v11 的能力集？指代、否定、时序与未见过组合如何进入证书？
- **Q2（歧义安全）**：当指令存在多个候选解释时，如何用交集语义保证“未消歧前不越过任何解释的权限”，并把追问/保持作为一等动作？歧义的保守代价如何度量？
- **Q3（干扰可证）**：单模型多任务的共享参数在什么条件下不损害安全关键头？如何用可测的梯度冲突、表征漂移与共形覆盖给出任务隔离证书，并在违反时安全降级为私有头？
- **Q4（隐藏组合与退化）**：如何在隐藏指令模板/槽位/对象组合下给出覆盖债与性能下界？ICC/ICert/STG/TIC/ITCL/LTCM 任一失效时，能否逐位等价退回 v11？

## 2. 设计原则（在 P16–P18 基础上新增 P19–P23）

**P19 语言可编译但不可授权律（Language Compiles, Certificates Authorize）**
语言只产生候选契约，不产生可执行动作；任何契约必须通过 ICert 与 v11 四重证书。语言模型的置信度、注意力或生成概率不得成为任何证书的合取项。ICC/ICert 不可用或语义不可接地时，退回 v11 给定的 G_task 与 NGE 规范信念。**语言只能改变“试什么”，不能改变“什么算安全”。**

**P20 能力闭包律（Capability Closure / Non-Regress）**
指令契约只能引用 Skill_reg、Pred_reg、Constraint_reg 中的已注册项；Act_κ ⊆ A_reg ⊆ A_v11，𝔅_κ 只能增加禁止谓词、不能删除 v11 的禁止谓词。任何“语言造出新动作/新约束语义”的输出一律判为不可编译。语言层的合法任务集必须是 v11 可执行任务集的子集。

**P21 歧义交集律（Ambiguity Intersection）**
未消歧前，可执行动作集为所有候选契约可采纳集的交集：A(K_ℓ) = ⋂_i (Act_{κ_i} \ 𝔅_{κ_i})。若交集为空、或最大解释权重低于阈值、或证据不足以区分候选，则执行 a_ask/hold，而不是猜一个。消歧只能由独立证据（视觉/触觉/力/音频/主动探测）触发，不能由语言模型自我复述触发。

**P22 干扰预算与任务隔离律（Interference Budget & Task Isolation）**
共享骨干只在 TIC 有效时启用：对每个安全关键头 h 与在册任务 u，干扰量 I_h(t,u) 必须低于预算 B_int，且任务间不可逆动作集不得交叉泄漏。违反时 STG 必须冻结共享层或切到私有头；不允许“先共享、出问题再事后补偿”。**共享是许可，不是默认。**

**P23 覆盖债与语言-任务一致律（Coverage Debt & Instruction-Task Consistency）**
ITCL 必须记录任务族×指令模板×槽位组合的分层覆盖与覆盖债 Debt(t,c)；LTCM 必须给出语言-任务语义漂移 D_lt。Debt 超预算或 D_lt 超阈时，只允许降低块长、进入交集/保守模式、追问或退回 v11，不允许提高置信度或放宽证书。覆盖债只能收紧许可。

## 3. 与基线的接口（如何退化）

- **ICC/ICert 失效** ⇒ 注入语言中立元：忽略 ℓ 的编译结果，直接使用 v11 的 G_task 与 NGE 规范信念，任务输入等价 v11；**等价 v11 任务输入路径**；
- **STG/TIC 失效** ⇒ 注入单任务中立元：每个任务 t 使用私有头 θ_priv^t（或独立单任务模型），禁用跨任务共享与切换；**等价 v11 的单任务策略路径**；
- **ITCL/LTCM 失效** ⇒ 关闭覆盖债与一致性监控，退回 v11 的全局共形/域门控；**等价 v11 校准路径**；
- **三者全失效** ⇒ 严格等价 v11 MetricVoiceGauge-NCD-H，再沿 v11 十三级链退回 v10/v9/v8/v7/v6；
- **安全继承**：物理/接触/谐波/规范四重证书始终是合取项。ICC 只能加已注册候选，ICert 只能删候选，STG/TIC 只能隔离/冻结，ITCL/LTCM 只能收紧。ICert 的合法契约集 ⊆ v11 可执行任务集；TIC 的共享模型在安全头上的行为被约束在私有模型邻域内（引理 107）；因此 v11 引理 101 的安全继承在本轮继续成立。

## 4. 预期贡献

1. **指令契约编译器 ICC 与指令合规证书 ICert**：把自然语言从“不可验证的命令”变成“带接地、偏序、否定、预算与证据义务的类型化契约”，并证明其能力闭包；覆盖 v11 完全未建模的语言歧义、指代漂移与未见过组合安全性；
2. **歧义交集语义与追问/保持机制**：让未消歧指令不靠猜测也能保持权限安全，量化“保守 vs 猜错”的代价，并给出消歧证据的一等接口；
3. **共享骨干治理器 STG 与任务干扰证书 TIC**：把“单模型多任务”从架构口号变成带干扰预算、任务隔离与安全头邻域约束的可证对象；覆盖 v11 未建模的跨任务负迁移与同源污染；
4. **指令-任务覆盖账本 ITCL 与语言-任务一致性监控 LTCM**：把隐藏任务上的“指令×任务组合未覆盖”风险显式化、可预算、可退化；
5. **完整可证伪链路 E607–E626**：覆盖语言接地、歧义交集、释义不变性、干扰预算、任务隔离、覆盖债、隐藏组合、WCET 与端到端长跑。

## 5. 本轮最大风险

**一句话**：最危险的不是“听不懂”或“互相干扰”，而是**语言与共享骨干共享同一个数据捷径**——模型对错误任务的指令同样给出高置信度、单模型跨任务一致地执行，而指令合规证书与干扰证书因同源证据同时失效，形成“语言正确、证书齐全、任务稳定做错”。

前三级作用于**互不相交的端口**（语言编译端口、语言证书端口、共享骨干端口、覆盖/一致性端口）；任意子集失效都落在 v11 的一个明确退化点上。Level-3 是“语言与多任务增强全部关闭”的锚点，此后逐级复现 v11 十三级链，不存在“半失效”的灰色行为。

## 1. 符号体系增量（定义 571–590）

| 符号 | 含义 |

**定义 571（指令契约 Instruction Contract）** 指令契约是一个类型化、可检查的任务对象：

```
κ = ( g,                # 可接地的目标谓词（对象 track、关系、数量、区域）
      τ,                # 已注册任务族/技能族
      Act ⊆ Skill_reg,  # 可采纳技能/动作模式
      Φ_pre, Φ_post,    # 前后置状态约束（一阶可检查谓词）
      ≺,                # 子目标偏序（不是全序）
      𝔅,                # 禁止谓词（否定、不可逆屏障、禁入区）
      Ev,               # 证据义务（视觉/触觉/力/音频/主动探测）
      Term,             # 终止谓词
      B,                # 步数/时间/能量/热预算
      a_amb )           # 歧义标注（同义、指代、省略、量词）
```

前置条件必须能映射到 v11 的 M₀ 可检查谓词；目标 g 必须绑定到当前场景的 track 或关系，不能是自由文本嵌入。**契约是语言与证书之间的唯一接口**：语言不能直接产生动作，只能产生契约。

**定义 572（指令歧义集与解释权重 Ambiguity Set）** ICC 对 ℓ 输出至多 m 个候选契约及其归一化权重：

```
K_ℓ = { (κ_i, w_i) }_{i=1..m},   w_i ≥ 0,  Σ_i w_i = 1
```

候选必须来自有限的**语义模板文法**（指令模板×槽位×修饰词），而不是自由生成。权重由接地证据、语言先验与反事实释义一致性共同决定；语言模型的自回归概率只作为先验之一，不单独决定权重。

**定义 573（歧义保护交集 Guarded Intersection Semantics）** 未消歧前，可执行动作集定义为：

```
A(K_ℓ) = ⋂_{i: w_i ≥ w_min} ( Act_{κ_i} \ 𝔅_{κ_i} )
```

只有当 K_ℓ 被独立证据收缩到单元素（或剩余解释在 Act/𝔅 上等价）时才允许执行该解释的目标进度动作；否则只允许 A(K_ℓ) 的交集动作（通常是运输/观察/保持/主动探测），或触发追问 a_ask。若 A(K_ℓ)=∅ 或 max_i w_i < w_min，则 hold。**歧义不靠猜，靠交集与追问。**

**定义 574（能力闭包与非回归 Capability Closure）** 契约 κ 合法，当且仅当：

```
Act_κ ⊆ Skill_reg ⊆ A_v11
𝔅_κ ⊇ 𝔅_v11(τ)
所有 g、Φ_pre、Φ_post、≺、Ev、Term 的原子谓词 ∈ Pred_reg
不存在语言新造的技能、控制模式、夹爪语义或安全谓词
```

其中 𝔅_v11(τ) 是 v11 对任务族 τ 的最低禁止集。能力闭包排除了“语言越权”——语言不能通过命名一个不存在的技能来扩张执行集，也不能通过省略否定来删除安全约束。

**定义 575（指令合规证书 Instruction Compliance Certificate）** 由 ICC 的解析证据与场景/证书状态计算：

```
Ĉ_ℓ = ( g_ok,      # 所有指代接地到存在的 track/关系，置信 ≥ τ_g，且无悬空引用
        c_ok,      # 能力闭包成立（定义 574）
        r_ok,      # 指代持续性：chunk 内 track 身份不变；重接地只发生在声明端口
        s_ok,      # 存在满足 κ 的 v11 可行技能序列（四重证书非空）
        α_mass,    # 歧义质量 1-max_i w_i
        ν_novel )  # 未接地词/未注册组合比例
```

有效 ⇔

```
g_ok ∧ c_ok ∧ r_ok ∧ s_ok
∧ α_mass ≤ δ_amb        （歧义未超阈，或已消歧）
∧ ν_novel ≤ δ_novel     （未见过组合未超阈，或已通过主动探测接地）
```

**定义 576（指令中止/追问点 Instruction Abort/Ask Points）** 对契约 κ，定义

```
P^ℓ(κ) = { p : 在 p 处可安全保持或追问，
           且从 p 开始的 hold/ask 序列不违反 v11 的 I_c/I_h/I_norm }
```

与 v11 的三语义中止点合并为 P_t^{all} = P_t^{nav} ∪ P_t^c ∪ P_t^h ∪ P^ℓ。块可执行必要条件升级为：**当前模式对应的 v11 中止点集非空，且若契约尚未消歧/接地不完整，则 P^ℓ 非空**。

**定义 577（任务签名与共享-私有分解 Task Signature & Factorization）** 单模型多任务策略写为

```
π_θ(a | s, t, κ),   θ = θ_sh ∪ { θ_priv^t }_{t=1..T}
```

任务签名 σ_t 由 (任务族 τ、契约模板 c、槽位类型、安全关键头集合 H_t、支持集、证据通道需求) 组成。**只有签名相近且通过 TIC 的任务对才允许共享 θ_sh**；其余任务使用私有头。任务切换必须经过 STG 的显式路由，不能在 chunk 中途隐式切换。

**定义 578（跨任务干扰度量 Interference Measure）** 对任务对 (t,u) 与安全关键头 h：

```
I_h(t,u) = λ_g · G_h(t,u) + λ_r · R_h(t,u) + λ_c · C_h(t,u)
G_h(t,u) = ‖ ∇_{θ_sh} L_t^h − ∇_{θ_sh} L_u^h ‖₂          （梯度冲突）
R_h(t,u) = 1 − CKA( φ_t^h(X), φ_u^h(X) )                  （表征漂移）
C_h(t,u) = | Cov_t^h − Cov_u^h |                          （共形覆盖差）
```

其中 G 度量共享层上两任务对安全头的更新方向冲突，R 度量共享表征在两任务输入分布上的漂移，C 度量校准后的覆盖差。三者都在校准集上可测；λ 为预注册权重。

**定义 579（任务干扰/隔离证书 Task Interference Certificate）** 任务 t 在共享骨干上可执行，当且仅当

```
TIC_t 有效 ⇔ ∀ h ∈ H_t, ∀ u ∈ Task_reg \ {t}:
    I_h(t,u) ≤ B_int
    ∧ G_h(t,u) ≤ B_g ∧ R_h(t,u) ≤ ε_drift ∧ C_h(t,u) ≤ ε_cov
    ∧ Leak(t,u) = 0
```

其中 Leak(t,u) 表示 t 与 u 的不可逆动作集相交，或 u 的私有头能触发 t 的不可逆动作。无效时 STG 必须选择 frozen（冻结共享层，执行保守原语）或 private（切到 θ_priv^t），并把该次切换记入审计日志。

**定义 580（共享骨干执行模式 Shared-Trunk Execution Mode）** STG 的输出是三种模式之一：

```
mode(t) = shared   若 TIC_t 有效且 t 的签名在共享集中
        | private  若 TIC_t 无效但 θ_priv^t 可用
        | frozen   若两者都不可用（退回 v11 单任务/保守原语）
```

模式只能在 chunk 边界或声明的切换端口改变；不可逆动作执行期间强制 private/frozen，且 K=1。

**定义 581（语言-任务一致性 Language-Task Consistency）** 活跃任务后验 p(t | s, ℓ) 与策略动作分布 π_θ(·|s,t,κ) 的一致性定义为：

```
D_lt(s) = d_H( Supp_κ(Act) , Supp_π(s) )
        + λ_kl · KL( p(·|s,ℓ) ‖ q_π(·|s,κ) )
        + λ_ref · 1[目标 track 在策略关注/动作中被替换]
```

其中 d_H 为动作支撑的 Hausdorff/集合距离，Supp_κ(Act) 是契约允许的技能/对象集合，Supp_π(s) 是策略当前高概率动作支撑，q_π 是策略隐含的任务后验。D_lt > δ_lt 时触发重接地、追问、降低块长或退回私有/保守模式。

**定义 582（指令-任务覆盖账本 Coverage Ledger & Debt）** 对每个分层单元 (t,c)（任务族 t×指令模板 c×槽位组合），记录 n_{t,c}、失败数 f_{t,c}、覆盖来源（真实/仿真/增广）与最近一次校准时间。覆盖债定义为

```
Debt(t,c) = max(0, n_min − n_{t,c}) / n_min
          + λ_o · max(0, d_TV(P_pub(t,c), P_hidden(t,c)) − δ_TV)
```

其中 n_min 为预注册最小样本数，d_TV 为公开-隐藏组合分布的可估 TV 距离（隐藏不可见时用最坏情形上界/专家先验）。Debt 高于预算时进入保守模式：降低块长、优先交集动作、增加追问、禁用共享骨干。

**定义 583（分层共形集 Stratified Conformal Set）** 对每个分层单元 (t,c)，用可交换校准样本计算阈值 q_{t,c}^α，使

```
P( 风险(τ) ≤ q_{t,c}^α ) ≥ 1 − α
```

样本不足时逐级回退到父层（任务族→全局），并把回退标记为“未认证覆盖”，不得伪装成已认证。隐藏任务上报告的是**分层覆盖率**，不是全局平均覆盖率。

**定义 584（v12 中立元表）**

| 新组件 | v^⊥ | 等价退化点 |
|---|---|---|
| ICC 编译器 | 不解析 ℓ，输出 ⊥；任务来自 v11 G_task | Level-3（v11） |
| ICert 证书 | Ĉ_ℓ 恒真；不做语言约束筛选 | Level-3（v11） |
| STG 治理器 | θ_sh≡∅，每任务独立私有头/单任务模型 | Level-2（v11） |
| TIC 证书 | TIC_t 恒真，但 STG 已退化为私有头，故无共享风险 | Level-2（v11） |
| ITCL 账本 | Debt≡0，使用 v11 全局共形/域门控 | Level-1（v11） |
| LTCM 监控 | D_lt≡0，不做语言-任务一致性检查 | Level-1（v11） |

**定义 585（v12 联合可执行条件 Joint Admissibility）** 一个块 C 在 v12 可执行，当且仅当：

```
Ĉ_ℓ(C) 有效
∧ Ĉ_joint^{v11}(C) = Ĉ_contact ∧ Ĉ_h ∧ Ĉ_safety ∧ Ĉ_norm 有效
∧ TIC_{t(C)} 有效（或 mode(t)=private/frozen 且私有头可用）
∧ P_t^{all} ≠ ∅（对应模式的中止点集非空）
∧ Debt(t(C), c(C)) ≤ B_debt
∧ D_lt(C) ≤ δ_lt
```

v12 的联合条件是对 v11 条件的**合取加强**：所有 v11 项原样保留，新项只能删除块、不能宽恕块。因此 v12 可执行集 ⊆ v11 可执行集。

## 2. 形式化定义（要点与升级）

**升级定义 531（软硬约束衔接，v12）** M₀ 硬检查增加两个入口：(i) **语言硬违规**——执行了 Ĉ_ℓ 未授权或明确禁止的动作/对象/区域；(ii) **跨任务硬违规**——在私有/冻结模式下触发了其他任务的不可逆动作，或共享模式下 TIC 已失效仍继续共享执行。两者与 v11 的物理/接触/谐波/规范硬违规同级，直接中止，不因语言或多任务模块存在而放宽。

**升级定义 534'（中止点，v12）** 块可执行必要条件升级为

```
P_t^{all} = P_t^{nav} ∪ P_t^c ∪ P_t^h ∪ P^ℓ ≠ ∅
```

按模式检查：导航模式查 P^{nav}∪P^ℓ；接触模式查 P^c∩P^h∪P^ℓ；自由模式查 P^{nav}∪P^h∪P^ℓ。若契约未消歧且 P^ℓ=∅，该块不可执行，ICC 必须追问或 ICert 必须拒绝。

**升级定义 546（灵巧技能，v12）** 技能 π_h 增加两个只读字段：`contract_id` 与 `task_signature`。技能执行时必须声明当前活跃契约与任务签名；STG 据此路由；若执行期活跃任务与技能声明的签名不一致，视为跨任务泄漏，立即中止。

**升级定义 547（接触/联合证书，v12）** 证书合取升级为

```
Ĉ_joint^{v12} = Ĉ_contact ∧ Ĉ_h ∧ Ĉ_ℓ ∧ TIC_t
```

其中 Ĉ_ℓ 由 ICert 给出，TIC_t 由 TIC 给出。任一项无效则该块不可执行；ICert 或 TIC 只能删除块，不能放宽 Ĉ_contact/Ĉ_h。

**升级定义 548（安全中止，v12）** 接触中止点 p∈P^c 仍要求 p∈P^h；若当前契约未消歧，p 还必须 ∈P^ℓ 或在 p 处可执行 hold/ask。若 P^c∩P^h∩P^ℓ=∅，HATD 必须重新切分或 ICC 必须消歧。

**升级定义 557（任务分解，v12）** HATD 的输入增加 (κ, σ_t, mode(t))。分解约束增加：

```
每段的技能 ∈ Act_κ，且 ∈ θ_priv^t 或 TIC_t 认证的共享支撑
每段的动作支撑与 Supp_κ(Act) 交集非空
每段携带 Ĉ_ℓ、TIC_t 与 v11 四重证书
若 mode(t)=frozen，则仅允许保守原语与 K=1
```

分解目标在 v11 的段数/带宽/共振/热约束上，增加“语言授权约束”和“任务签名一致约束”。

**升级定义 559（因果世界模型，v12）** CWM 的输入增加 (κ, σ_t)；不变父集 S* 必须排除语言捷径特征（数据集来源、模板 id、对象命名风格、机器人 id）与任务 id 的泄漏编码。CWM 的分任务预测误差必须按分层报告，不能用全局平均掩盖某个任务对的负迁移。

# IP-367 InstructionContractCompiler
class InstructionContractCompiler:
    def __init__(self, lexicon, template_grammar, grounder, max_contracts=8):
        self.lexicon = lexicon              # Skill_reg, Pred_reg, Constraint_reg
        self.grammar = template_grammar     # 有限语义模板文法
        self.grounder = grounder            # 对象/关系/区域接地
        self.max_contracts = max_contracts

    def compile(self, utterance, obs, task_graph):
        parses = self.grammar.parse(utterance, max_n=self.max_contracts)
        contracts = []
        for parse in parses:
            if not self._is_registered(parse):
                continue                     # 能力闭包：未注册项直接丢弃
            grounding = self.grounder.bind(parse, obs)
            if grounding is None:
                continue                     # 悬空引用 → 不可编译
            kappa = InstructionContract(
                g=grounding.goal, tau=parse.task_family,
                Act=parse.actions & self.lexicon.skills,
                Phi_pre=parse.pre, Phi_post=parse.post,
                order=parse.partial_order, forbid=parse.forbidden,
                evidence=parse.evidence_obligations, term=parse.termination,
                budget=parse.budget, ambiguity=parse.ambiguity)
            w = self._weight(parse, grounding, obs)
            contracts.append((kappa, w))
        if not contracts:
            return Bottom                    # 语言中立元：退回 v11 G_task
        return self._normalize(contracts)

    def _is_registered(self, parse):
        return (parse.actions <= self.lexicon.skills and
                parse.predicates <= self.lexicon.predicates and
                parse.constraints <= self.lexicon.constraints)


# IP-368 InstructionComplianceCertifier
class InstructionComplianceCertifier:
    def __init__(self, delta_amb, delta_novel, tau_g,
                 v11_certifier, registered_forbidden):
        self.delta_amb, self.delta_novel, self.tau_g = delta_amb, delta_novel, tau_g
        self.v11 = v11_certifier
        self.base_forbidden = registered_forbidden

    def certify(self, contract_set, state, scene):
        if contract_set is Bottom:
            return NeutralCert()             # 等价 v11
        kept = []
        for kappa, w in contract_set:
            g_ok = self._grounded(kappa, scene)
            c_ok = (kappa.Act <= self.v11.skill_set and
                    kappa.forbid >= self.base_forbidden[kappa.tau])
            r_ok = self._reference_persistent(kappa, state)
            s_ok = self.v11.has_feasible_sequence(kappa, state)
            if g_ok and c_ok and r_ok and s_ok:
                kept.append((kappa, w))
        if not kept:
            return None
        alpha = 1.0 - max(w for _, w in kept)
        novel = self._novel_ratio(kept, scene)
        if alpha > self.delta_amb or novel > self.delta_novel:
            return AskCert(kept, alpha, novel)   # 触发追问/交集，而非执行
        return Certificate(kept, alpha, novel,
                           abort_points=self._ask_abort_points(kept, state))

    def guarded_intersection(self, cert):
        acts = None
        for kappa, w in cert.contracts:
            if w < self.w_min:
                continue
            allowed = kappa.Act - kappa.forbid
            acts = allowed if acts is None else (acts & allowed)
        return acts


# IP-369 SharedTrunkGovernor
class SharedTrunkGovernor:
    def __init__(self, shared_params, private_heads, tic, freeze_policy):
        self.theta_sh = shared_params
        self.heads = private_heads           # task -> θ_priv^t
        self.tic = tic
        self.freeze_policy = freeze_policy

    def route(self, task, state):
        cert = self.tic.certify(task, self.theta_sh, self.heads)
        if cert.valid and self._signature_in_shared_set(task):
            return Mode('shared', self.theta_sh, cert)
        if task in self.heads:
            return Mode('private', self.heads[task], cert)
        return Mode('frozen', self.freeze_policy, cert)

    def _signature_in_shared_set(self, task):
        return task in self.tic.certified_shared_tasks


# IP-370 TaskInterferenceCertifier
class TaskInterferenceCertifier:
    def __init__(self, safety_heads, B_int, B_g, eps_drift, eps_cov,
                 calibration_set):
        self.H = safety_heads
        self.B_int, self.B_g = B_int, B_g
        self.eps_drift, self.eps_cov = eps_drift, eps_cov
        self.calib = calibration_set

    def certify(self, task, shared_params, private_heads):
        worst, drift, cov, leak = 0.0, 0.0, 0.0, 0
        for u in self.calib.tasks:
            if u == task:
                continue
            for h in self.H[task]:
                G = self._grad_conflict(shared_params, task, u, h)
                R = self._repr_drift(shared_params, task, u, h)
                C = self._coverage_gap(task, u, h)
                worst = max(worst, G, R, C)
                drift, cov = max(drift, R), max(cov, C)
                if self._irreversible_overlap(task, u):
                    leak = 1
        valid = (worst <= self.B_int and drift <= self.eps_drift
                 and cov <= self.eps_cov and leak == 0)
        return TaskInterferenceCert(worst, drift, cov, leak, valid)


# IP-371 InstructionTaskCoverageLedger
class InstructionTaskCoverageLedger:
    def __init__(self, n_min, debt_budget, tv_delta, strata):
        self.n_min, self.budget, self.delta_tv = n_min, debt_budget, tv_delta
        self.counts = {s: 0 for s in strata}

    def update(self, task, template, slots, success, source):
        key = (task, template, frozenset(slots.items()))
        self.counts[key] = self.counts.get(key, 0) + 1
        self._record_failure(key, success, source)

    def debt(self, task, template, slots):
        key = (task, template, frozenset(slots.items()))
        n = self.counts.get(key, 0)
        return max(0.0, (self.n_min - n) / self.n_min) + \
            max(0.0, self._tv_distance(key) - self.delta_tv)

    def conservative_mode(self, task, template, slots):
        return self.debt(task, template, slots) > self.budget


# IP-372 LanguageTaskConsistencyMonitor
class LanguageTaskConsistencyMonitor:
    def __init__(self, p_task, delta_lt, kl_weight=0.5):
        self.p_task = p_task
        self.delta_lt = delta_lt
        self.kl_weight = kl_weight

    def drift(self, state, contract, policy_dist, policy_task_post):
        supp_k = contract.act_support()
        supp_pi = policy_dist.high_prob_support()
        d_h = set_distance(supp_k, supp_pi)
        kl = kl_divergence(self.p_task(state), policy_task_post)
        ref = 1.0 if self._target_track_replaced(state, contract) else 0.0
        return d_h + self.kl_weight * kl + ref

    def should_intervene(self, d_lt):
        return d_lt > self.delta_lt

## 4. 推导

**引理 104（指令契约能力闭包）** 若 ICert 判定 κ 有效，则 κ 的可执行动作集满足 `Act_κ \ 𝔅_κ ⊆ A_v11(τ) \ 𝔅_v11(τ)`，即语言层不扩张 v11 的能力集。证明：由定义 574，Act_κ ⊆ Skill_reg ⊆ A_v11 且 𝔅_κ ⊇ 𝔅_v11(τ)，集合差对子集与超集单调，故结论成立；ICert 的 c_ok 正是该条件的可检查形式。∎

**引理 105（歧义交集安全性）** 设真实解释 κ* ∈ K_ℓ，且执行动作 a_t ∈ A(K_ℓ)。则对每个候选解释 i（含 κ*），a_t ∈ Act_{κ_i} \ 𝔅_{κ_i}；因此 a_t 不违反真实解释的禁止集，也不会调用真实解释未授权的技能。证明：A(K_ℓ) 是各候选可采纳集的交集，交集元素属于每个集合；取 i=* 即得。∎

推论：在未消歧前，任何执行都不越过任何候选解释的权限；代价是交集可能为空或过于保守，因此需要 P^ℓ 与追问。

**引理 106（指令合规证书可靠性）** 设接地误差、指代跟踪误差与解析误差均在证书余量内（E607/E608 标定），且 Ĉ_ℓ 有效。则执行中：
(i) 所有被操作对象都可追溯到存在的 track；
(ii) 不存在未注册技能或未注册约束被调用；
(iii) 指代在 chunk 内保持不变，除非在声明端口重接地；
(iv) 存在 v11 可行的契约满足序列。
证明：g_ok 保证 (i)；c_ok 与定义 574 保证 (ii)；r_ok 保证 (iii)；s_ok 直接给出 (iv)。证书用保守余量检查，故真实量不超界。∎

**引理 107（任务干扰预算 → 安全头邻域界）** 设对任务 t 的每个安全头 h，共享模型的安全损失 L_h^sh 对共享表征 φ 满足 L-Lipschitz，且 TIC_t 有效（I_h(t,u) ≤ B_int）。则共享模型在任务 t 的安全头输出与私有模型输出的差满足

```
‖ L_h^sh(φ_t) − L_h^priv(φ_t) ‖ ≤ L · ( B_int + ε_est )
```

其中 ε_est 为校准/估计误差。证明：由 Lipschitz 性，损失差 ≤ L·‖φ_sh − φ_priv‖；TIC 的干扰度量上界 B_int 给出两表征在任务 t 数据上的漂移上界（R 项）与梯度冲突上界（G 项），共形覆盖差 C 项给出校准误差上界；合并即得。∎

**引理 108（中立元退化等价 v11）** 将定义 584 的六个中立元分别注入 ICC/ICert/STG/TIC/ITCL/LTCM 端口，则主闭环的候选集、排序与执行序列逐位退化为 v11：
- ICC 输出 ⊥，ICert 恒真 ⇒ 任务输入回到 v11 的 G_task 与 NGE；
- STG 的 θ_sh=∅ ⇒ 每任务私有头，等价 v11 单任务策略；
- ITCL 的 Debt≡0、LTCM 的 D_lt≡0 ⇒ 校准回 v11 全局共形/域门控。
六端口互不相交，逐端口代入即得 v11 程序；再由 v11 引理 102 继续退回 v10/v9/v8/v7/v6。∎

**引理 109（覆盖债 → 隐藏组合风险界）** 设在分层单元 (t,c) 内校准样本与隐藏样本可交换，且 ITCL 的分层共形阈值 q_{t,c}^α 由 n_{t,c} 个样本估计。则对隐藏指令模板/槽位组合，任务失败率满足

```
P(fail | t,c) ≤ α + O( √( log(1/δ) / n_{t,c} ) ) + Debt(t,c) · L_debt
```

其中 L_debt 为覆盖债到风险的经验映射常数。证明：标准分裂共形覆盖界给出 α + 有限样本项；当隐藏分布与公开分布在同一分层内可交换时，Debt=0；当组合分布发生 TV 偏移时，额外的风险由 Debt 的 TV 项与样本不足项加性上界（用 TV 距离的标准风险差界）。∎

**引理 110（语言-任务一致性监控的检测界）** 若策略实际执行的任务 u ≠ 契约任务 t，且 u 的动作支撑与契约允许支撑的 Hausdorff 距离 ≥ δ_lt，或策略任务后验与 p(t|s,ℓ) 的 KL 超过阈值，则 LTCM 在有限步内触发干预。反之，若 D_lt ≤ δ_lt，则不能保证无错误，只能保证“错误未表现为可观测的支撑/后验漂移”——这正是需要 ICert 与 TIC 独立证据的原因。∎

**引理 111（无跨任务泄漏）** 若 TIC_t 有效（Leak=0），且 STG 在不可逆动作期间强制 private/frozen 与 K=1，则任务 t 的执行不会触发任何其他任务 u 的不可逆动作，也不会使用 u 的私有头产生 t 的动作。证明：Leak(t,u)=0 排除不可逆动作集相交；STG 的 mode 路由把私有头隔离在任务 t；K=1 保证不可逆动作前有独立验证。∎

**引理 112（预算守恒 v12）** 新增在线成本上界：ICC 编译 ≤0.8ms（5Hz 摊销，模板文法剪枝）；ICert 证书 ≤0.4ms；STG 路由 ≤0.2ms；TIC 证书按任务对缓存、5Hz 摊销 ≤0.5ms；ITCL/LTCM ≤0.1ms。v11 继承路径 ≤9ms，谐波辨识/分解/预测不变。总决策 p99 仍 ≤22ms（50Hz 保持，v11 留 2ms 余量）。证明：逐项代入复杂度表并做静态 EDF 校验 ΣŴ_m ≤ B_dec 即得。∎

## 8. 已知风险与失效模式

1. **交集语义过度保守**：歧义候选多、w_min 高时，A(K_ℓ) 可能为空或只剩保持动作，使任务无法推进。缓解：分层消歧（先消指代再消动词）、主动探测、把“追问”计入预算、对已消歧子目标放行。
2. **语言捷径与释义不稳**：VLM 依赖模板 id、对象命名风格、数据集来源等虚假特征，导致同义改写输出不一致。缓解：反事实释义增广、去除捷径特征、释义一致性作为 ICert 的一等项、独立视觉/触觉接地。
3. **任务 id 由语言错误决定**：指令歧义或多语言混用导致 π 选错任务，且错误任务执行得很“顺畅”。缓解：LTCM 监控支撑/后验漂移、多假设交集、错任务也会被 v11 四重证书拦截一部分、必要时追问。
4. **共享骨干的隐式干扰不可测**：定义 578 的梯度/表征/覆盖度量只在有限校准集上测，可能漏掉隐藏组合上的干扰。缓解：分层测量、最坏情形任务对、Leak 硬约束、私有头兜底。
5. **覆盖债与隐藏风险不相关**：隐藏分布可能是结构性偏移而非分层内可交换，Debt 可能低估。缓解：使用最坏情形 TV 上界、专家先验、报告“未认证覆盖”、保守模式默认开启。
6. **同源误差正反馈**：语言模型、共享骨干与校准器共用同一训练/仿真数据，ICC→ICert→STG→LTCM 可能同时失效。缓解：独立证据通道（视觉/触觉/力/音频/主动探测）、显式不确定性传播、必要时 a_ask 打破环。
7. **证书过度保守导致无可行任务**：语言证书 + 干扰证书 + v11 四重证书的合取可能清空候选集。缓解：证书裕度分层（hard/soft）、HATD 自动细化粒度、任务级松弛、追问与重接地作为兜底。
8. **分层样本稀缺**：细粒度 (t,c) 单元样本不足，共形阈值不稳定。缓解：逐级回退父层并标记未认证、跨任务共享校准先验、主动采集隐藏组合样本。

## 9. 本轮最大风险

**一句话**：最危险的不是“听不懂”或“互相干扰”，而是**语言与共享骨干共享同一个数据捷径**——模型对错误任务的指令同样给出高置信度、单模型跨任务一致地执行，而指令合规证书与干扰证书因同源证据同时失效，形成“语言正确、证书齐全、任务稳定做错”。
