# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「多模态大模型」×「状态隔离」）

> 第 54 轮把技能组合提升为动作-鲁棒性双证书 `(α_S, A_cert, γ_ce, δ_a)`。本轮引入 **多模态大模型（MLLM）作为不可信语义编译器** 与 **状态胶囊化的强隔离**。核心矛盾：**H22**：MLLM 的上下文、记忆与 KV 缓存是跨任务共享的隐性总线，任务 A 的指令/记忆/感知会污染任务 B 的计划，产生“语义幻觉迁移”，而该污染在 `ρ` 与 `α_S` 中完全不可见（两者都默认输入状态与任务对齐）。**H23**：云边状态投影缺少隔离契约，云端越权读取边端原始上下文、或边端读取陈旧全局状态，都会使“隔离”退化为口头承诺而非可判定证书。

## 0. 直觉与动机

**灵感 1（MLLM 从决策者降级为语义编译器 → propose-verify）**
直觉：不要指望 MLLM 的规划“正确”，而应把它当编译器：把多模态指令 `x=(I,L,D)` 编译成符号化技能计划 `P̂=(pre,eff,atoms)`，在**沙箱**里只读隔离状态、只写影子状态，绝不直接写真实状态。是否可信由**符号验证器 `V`** 判定：`V(P̂, SCOM, α_S)` 通过才算数。这样 MLLM 的幻觉只降低“可行计划发现率（completeness）”，不破坏部署正确性（soundness）——这是本轮与“纯 MLLM 规划”最本质的区别。

**灵感 2（状态胶囊 + 能力作用域隔离 → 把隔离变成非干扰）**
直觉：状态不是一块黑箱，而是带 `(task,node,modality,timestamp,version-vector,dep)` 标签的**状态胶囊** `χ`。访问由根信任层已有的**能力格（capability lattice）**授权：任务 `T` 只能读本任务作用域内的胶囊，共享胶囊必须持有带 TTL 的 lease。隔离的严格含义是**有界无干扰（bounded non-interference）**：任务 A 的可观测输出对任务 B 的写入不变（泄漏 ≤ ε_max），而不是“我猜它们没串”。

**灵感 3（隔离谱 ι 与跨模态一致性 cons → 污染可被探针发现）**
直觉：第 53 轮用鲁棒性谱 `ρ(d)` 描述每个扰动维；本轮对称地定义**隔离谱 `ι(d)`**，维度 `d∈{task, embodiment, modality, temporal, tenant, version}`，并度量泄漏 `ε_iso(d)`。MLLM 的污染很难直接观测，但**多模态视图是一组交叉校验**：视觉、语言、本体感知、记忆对同一状态给出不同投影 `V_m(χ)`，若视图互相打架（`cons` 低），即为陈旧视图、错误检索或跨任务污染的信号。

**灵感 4（隔离-鲁棒性耦合 → 泄漏单调腐蚀证书）**
直觉：隔离与鲁棒性不是正交的。上下文被污染时，即便单技能 `ρ` 很高，组合后的实际鲁棒性也会下降。定义耦合 `ρ'(d) = ρ(d)·(1 - λ·ε_iso(d))`（对 `ε_iso` 单调不增）。这把“状态泄漏”从运维事故变成**证书中可计算、可预算、可拒批**的量：`SIC` 不过，则联合证书 `J` 一律判 out。

**灵感 5（云边状态契约 + 状态谱系 → 只传有界投影）**
直觉：云端 MLLM 需要全局视野，边端需要实时性，二者都不能直接吞对方的原始状态。用**只读有界投影** `σ_ce: Ξ_e → Ξ_c`（带投影损失 `Δ_state`）跨越边界，配合 lease/TTL/revoke 与**状态谱系 lineage**（记录每条结论依赖了哪些胶囊）。这样边端 Explain 回传时能精确指认“是哪颗胶囊/哪个版本被污染”，云端据此重投影而不是盲目重规划。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（多模态状态胶囊 State Capsule）**
状态胶囊 `χ = (id, task, node, modality, payload, t, ver, dep)`：
- `modality ∈ {vis, lang, prop, mem, kv}`（视觉/语言/本体感知/记忆/KV 缓存）；
- `t` 逻辑时间戳，`ver` 版本向量 `ver: Node → ℕ`，`dep ⊆ CapsuleId` 为依赖集；
- `payload` 为 token/tensor/结构化记忆。状态库 `Ξ = {χ}`，分区函数 `π(χ)=(task,node,modality)`。

**定义 122（状态隔离与隔离谱）**
任务 `T` 在节点 `n` 的读集 `R(T,n)` 满足隔离 `iso(T,n)=1` 当且仅当：
```
(1) ∀χ∈R(T,n): χ.task = T ∨ χ ∈ Lease(T)          # 任务隔离/显式共享
(2) ∀χ∈R(T,n): χ.node = n ∨ χ 经 σ_ce 合法投影      # 边界隔离
(3) R(T,n) ∩ W(T',n') = ∅, ∀T'≠T                   # 写隔离（无干扰）
(4) cons(R(T,n)) ≥ θ_cons                          # 跨模态一致
(5) ver_read ≥ ver_dep（逐项）                      # 读后写因果
```
泄漏 `ε_iso(T,n) = |R(T,n) ∩ ⋃_{T'≠T} W(T',·)| / |R(T,n)|`；隔离谱 `ι: D_iso → [0,1]`，`D_iso={task,embodiment,modality,temporal,tenant,version}`，`ι(d)=1-ε_iso(d)`。有界无干扰：`∀w1,w2: d_TV(O(T|W(T')=w1), O(T|W(T')=w2)) ≤ ε_max`。

**定义 123（MLLM 语义编译器，沙箱化）**
`M` 将多模态指令 `x=(I,L,D)` 编译为类型化技能计划 `P̂=(pre,eff,atoms)`，`atoms ⊆ A`。沙箱条件：`M` 仅读 `R_iso(x) ⊆ R(T,n)`，仅写影子库 `Ξ_shadow`，输出经受限文法解码（只允许技能 DSL）。语义证书 `C_sem=(P̂,pre,eff,ctx(P̂),ε_iso,conf)`，其中 `ctx(P̂) ⊆ R_iso(x)` 为通过污点追踪估计的影响胶囊闭包。**关键约定：`M` 是不可信提议者，soundness 由验证器 `V` 承担。**

**定义 124（跨模态状态一致性）**
对状态 `s` 与模态对 `(m,m')`，投影 `V_m(s), V_{m'}(s)`，归一化分歧 `δ_mm' ∈ [0,1]`，`cons(s)=1 - max_{m≠m'} δ_mm'`。`cons < θ_cons` 判为陈旧/污染/检索错误。

**定义 125（状态隔离证书 SIC）**
`SIC = (T, n, R(T,n), ε_iso, ι, cons, ver, ctx(P̂), lease, evidence)`。`dom_SIC(T)=in` 当且仅当：`ε_iso ≤ ε_max`、`cons ≥ θ_cons`、版本向量因果一致（`ver_read ≥ ver_dep`）、`ctx(P̂) ⊆ R_iso(x)`、`lease` 未过期。`evidence` 至少含胶囊谱系与一次红队注入记录。

**定义 126（云边状态契约与谱系）**
`C_state = (σ_ce, Δ_state, Lease, Revoke, lineage)`：
- `σ_ce: Ξ_e → Ξ_c` 只读有界投影，`Δ_state = sup_s d(σ_ce^{-1}(σ_ce(s)), s)`；
- `Lease(T,χ,τ)` 带 TTL 的共享授权，`Revoke` 在任务结束/失败/泄漏告警时立即回收；
- `lineage(o) = {χ | χ 影响了输出 o}`，用于反向解释精确回溯。
`C_state` 与第 54 轮 `γ_ce` 正交复合：动作走 `γ_ce`，状态走 `σ_ce`，任一侧越界即否决联合证书 `J`。

## 2. 关键算法 伪代码

### IP-121 SCE（State Capsule Engine）

```python
def put_capsule(store, task, node, modality, payload, dep, ver):
    chi = Capsule(id=uuid(), task=task, node=node, modality=modality,
                  payload=payload, t=now(), ver=ver, dep=set(dep))
    store.vector_clock.merge(ver); store.insert(chi)
    return chi

def read_scope(store, task, node, lease):
    out = []
    for chi in store.iter(task=task, node=node):
        if chi.ver_satisfies(store.vector_clock) and not lease.expired(chi.id):
            out.append(chi)
    return out

def check_write_isolation(store, task, node, reads):
    read_ids = {c.id for c in reads}
    for chi in store.writes_by_others(task):
        if chi.id in read_ids:          # 读到了他任务写过/正写的胶囊
            return False, chi
    return True, None
```

### IP-122 ISB（Isolated Semantic Bridge，propose-verify）

```python
def compile_isolated(M, x, store, task, node, lease, grammar):
    reads = read_scope(store, task, node, lease)
    shadow = Store()                     # 只写影子，不触真实状态
    P_hat = M.generate(x, context=reads, grammar=grammar,
                       sink=shadow)      # 受限文法解码 -> pre/eff/atoms
    ctx = taint_trace(M.last_attention, reads)   # 估计影响闭包
    if not ctx.issubset({c.id for c in reads}):
        return ('reject', 'context_escape', ctx)
    C_sem = SemCert(P_hat, ctx, epsilon_iso=store.leakage(task, node, reads))
    return ('ok', C_sem)

def verify_plan(V, C_sem, G_S, alpha, rho_min):
    if not V.pre_eff_sound(C_sem.P_hat):            # 前置/效果可满足
        return ('reject', 'semantics_unsound')
    if not all(alpha_covers(a) for a in C_sem.P_hat.atoms):  # 动作覆盖
        return ('reject', 'action_uncovered')
    if not V.path_exists(G_S, C_sem.P_hat.atoms):   # 组合图可达
        return ('reject', 'no_composition_path')
    return ('ok', C_sem, V.robustness(C_sem.P_hat))
```

### IP-123 SIC（State Isolation Certifier）

```python
def state_isolation_cert(T, n, reads, writes_others, ctx, lease, cons, ver):
    inter = set(c.id for c in reads) & set(c.id for c in writes_others)
    eps = len(inter) / max(1, len(reads))
    if eps > EPS_MAX:                     return ('reject', 'leakage', eps)
    if cons < THETA_CONS:                 return ('reject', 'stale_or_contam', cons)
    if not ctx.issubset({c.id for c in reads}):
        return ('reject', 'ctx_escape', ctx)
    if not all(c.ver_read >= c.ver_dep for c in reads):
        return ('reject', 'causal_violation')
    if any(lease.expired(c.id) for c in reads if c.task != T):
        return ('reject', 'lease_expired')
    return ('ok', SIC(T, n, reads, eps, cons, ver, ctx, lease, evidence=chain(reads)))
```

### IP-124 CSE（Cross-modal State Estimator）

```python
def cross_modal_consistency(state_views):
    pairs = [(m, m2) for m in state_views for m2 in state_views if m < m2]
    deltas = [normalized_disagreement(V_m(s), V_m2(s)) for m, m2 in pairs]
    return 1.0 - max(deltas) if deltas else 1.0

def contamination_probe(store, T, n, window):
    views = {m: project(store, T, n, m, window) for m in MODALITIES}
    cons = cross_modal_consistency(views)
    suspects = [m for m in MODALITIES if view_is_stale(views[m], store.vector_clock)]
    return cons, suspects
```

### IP-125 SRC（State-Robustness Coupling）

```python
def couple_state_robustness(rho, eps_iso, lam=1.0):
    # 对 eps_iso 单调不增；eps=0 时退化为第 53/54 轮证书
    return {d: rho[d] * (1.0 - lam * eps_iso[d]) for d in rho}
```

### IP-126 STX（State Transfer Certificate，云边）

```python
def transfer_state(store_e, T, target, sigma_ce, lease, delta_state_budget):
    proxy = sigma_ce(store_e.scope(T))       # 只读有界投影
    delta_state = projection_loss(sigma_ce, store_e.scope(T))
    if delta_state > delta_state_budget:
        return ('reject', 'projection_loss', delta_state)
    if not proxy.all_labels_carry(lease):    # 标签必须随投影携带
        return ('reject', 'label_stripping')
    lineage = {o: store_e.lineage(o) for o in proxy.outputs}
    return ('ok', StateContract(proxy, sigma_ce, delta_state, lease, lineage))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SCE | O(log |Ξ| + |R|) 读；O(1) 写 | O(|Ξ|) | 标签完整、版本向量因果 |
| ISB | O(Tokens²·d)（MLLM）+ O(|atoms|·|A|) 验证 | O(ctx) | 沙箱只读、文法受限、验证器 sound |
| SIC | O(|R| + |D_iso|) | O(|R|) | 无干扰、lease 有效、ctx 闭包 |
| CSE | O(|M|²·|V|) | O(|M|·|V|) | 投影可比较、阈值校准 |
| SRC | O(|D_ρ|) | O(|D_ρ|) | 单调性、λ 可辨识 |
| STX | O(|scope| + |lineage|) | O(|σ|) | 投影有界、标签不剥离 |

**正确性定理（Isolation-Aware Propose-Verify Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** 验证器 `V` 对技能 DSL 计划 sound（拒绝任何违反 pre/eff/动作覆盖/组合可达的计划）；**(A30)** 能力作用域不可伪造、胶囊标签完整（无标签剥离）；**(A31)** 版本向量在时钟偏差上界 `δ_clk` 下因果一致；**(A32)** 跨模态探针误报/漏报有界。
**不假设 MLLM `M` 正确**。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
              - P(ε_iso>ε_max) - P(cons<θ_cons) - P(ver_inconsistent)
```
**含义**：MLLM 只影响可行计划发现率（completeness），其幻觉被验证器拦截；部署 soundness 由“**验证器 sound + 状态隔离 + 版本因果**”三者承担。若 `SIC` 判 out 或任一耦合项越界，联合证书 `J` 一律拒批——**隔离是联合证书的前置门，而非并列加分项**。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 状态隔离泄漏 | 并发多任务下 `ε_iso` 分布 | P95 ≤ 0.01，最大值 ≤ 0.05 |
| E163 MLLM 计划可采纳率 | `V` 通过的 MLLM 计划占比 / 误接收率 | 采纳率 ≥ 70%，误接收 ≤ 3% |
| E164 跨模态污染探针 | 污染检测 AUROC / 误报 | AUROC ≥ 0.95，FPR ≤ 5% |
| E165 隔离感知鲁棒性 | 有 SIC vs 无 SIC 的部署成功率（跨任务干扰下） | Δ ≥ 10% |
| E166 云边状态移交 | `Δ_state` 与任务成功率、P95 延迟 | `Δ_state` ≤ 0.1，P95 ≤ 60ms |

**消融**：(a) 去掉能力作用域 → 预期 `ε_iso` 爆炸；(b) 去掉版本向量 → 预期陈旧视图导致的间歇性失败上升；(c) 去掉跨模态探针 → 预期污染漏检率显著上升；(d) 换成“信任 MLLM 不验证”基线 → 预期 soundness 崩溃。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| MLLM 沙箱逃逸 / 提示注入 | 高 | 受限文法 + 只读投影 + 工具白名单 + 红队注入回归 |
| 隐信道泄漏（时序/缓存/输出统计） | 高 | KV 缓存分区 + 独立实例 + 统计泄漏预算 + 物理隔离兜底 |
| 胶囊爆炸与存储压力 | 中 | TTL 淘汰 + 语义去重 + 冷热分层 |
| 版本向量时钟偏差 | 中 | 时钟偏差上界 + 保守因果 + 冲突显式拒批 |
| 跨模态一致性阈值漂移 | 中 | 在线校准 + 人类锚点 + 拒绝域 hysteresis |
| lease 回收风暴 | 中 | 批量 revoke + 任务级租约 + 幂等回收 |

## 6. 本轮最大风险

**一句话**：本轮把 MLLM 降级为不可信提议者、把状态隔离证书化，soundness 从“相信模型”转移到“验证器 sound + 能力作用域 + 版本因果 + 跨模态探针”，但其 **隔离性本身可能被隐信道（时序、共享 KV 缓存、输出统计）击穿**——一旦 `ctx(P̂)` 实际越界而 `SIC` 仍判 in，就会产出“隔离假象”下的跨任务污染，比显式不隔离更危险；故必须以 **KV 缓存分区与统计泄漏预算 + 污点追踪 + lease 到期强回收 + 红队注入回归** 作为硬护栏，宁可在隔离证据不足时拒批联合证书。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（SCE×ISB×SIC×CSE×SRC×STX）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书体系之上，增加 **MLLM 语义编译（不可信提议者）、状态胶囊化强隔离、隔离-鲁棒性耦合、云边状态契约** 四条主线：
> - **SCE（State Capsule Engine）**：多模态状态胶囊与能力作用域读写；
> - **ISB（Isolated Semantic Bridge）**：MLLM 在沙箱中把多模态指令编译成可验证技能计划；
> - **SIC（State Isolation Certifier）**：状态隔离证书 `SIC`，有界无干扰 + 版本因果；
> - **CSE（Cross-modal State Estimator）**：跨模态一致性探针，检测陈旧与污染；
> - **SRC（State-Robustness Coupling）**：泄漏对鲁棒性的单调耦合 `ρ'=ρ·(1-λ·ε_iso)`；
> - **STX（State Transfer Certificate）**：云边只读有界投影 + 状态谱系 + lease/revoke。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-116（SCOM 接入语义 pre/eff）、IP-117（CEC 接入 `C_state`）、IP-118（AEC 前置 `SIC`）。

| `R(T,n)` / `W(T,n)` | 任务 T 在节点 n 的读集 / 写集 |
| `iso(T,n)` / `ε_iso` | 状态隔离判定 / 泄漏率 |
| `ι: D_iso→[0,1]` | 隔离谱，`D_iso={task,embodiment,modality,temporal,tenant,version}` |
| `P̂=(pre,eff,atoms)` | MLLM 编译出的类型化技能计划 |
| `ctx(P̂)` | 影响胶囊闭包（污点追踪） |
| `C_sem=(P̂,pre,eff,ctx,ε_iso,conf)` | 语义编译证书 |
| `V` | 符号验证器（pre/eff/动作覆盖/组合可达） |
| `cons(s)` | 跨模态状态一致性 |
| `SIC=(T,n,R,ε_iso,ι,cons,ver,ctx,lease,evidence)` | 状态隔离证书 |
| `σ_ce: Ξ_e→Ξ_c` / `Δ_state` | 云边只读投影 / 投影损失 |
| `lineage(o)` | 输出 o 依赖的胶囊谱系 |

> 注：JCPS 原输出中的 `κ` 已被占用，本轮状态胶囊统一记作 `χ`、状态库记作 `Ξ`，避免符号冲突。

### IP-121 SCE

```python
def put_capsule(store, task, node, modality, payload, dep, ver):
    chi = Capsule(id=uuid(), task=task, node=node, modality=modality,
                  payload=payload, t=now(), ver=ver, dep=set(dep))
    store.vector_clock.merge(ver); store.insert(chi)
    return chi

def read_scope(store, task, node, lease):
    return [chi for chi in store.iter(task=task, node=node)
            if chi.ver_satisfies(store.vector_clock) and not lease.expired(chi.id)]

def check_write_isolation(store, task, node, reads):
    read_ids = {c.id for c in reads}
    for chi in store.writes_by_others(task):
        if chi.id in read_ids:
            return False, chi
    return True, None
```

### IP-122 ISB（propose-verify）

```python
def compile_isolated(M, x, store, task, node, lease, grammar):
    reads = read_scope(store, task, node, lease)
    shadow = Store()
    P_hat = M.generate(x, context=reads, grammar=grammar, sink=shadow)
    ctx = taint_trace(M.last_attention, reads)
    if not ctx.issubset({c.id for c in reads}):
        return ('reject', 'context_escape', ctx)
    return ('ok', SemCert(P_hat, ctx, store.leakage(task, node, reads)))

def verify_plan(V, C_sem, G_S, alpha):
    if not V.pre_eff_sound(C_sem.P_hat):            return ('reject','semantics_unsound')
    if not all(alpha_covers(a) for a in C_sem.P_hat.atoms): return ('reject','action_uncovered')
    if not V.path_exists(G_S, C_sem.P_hat.atoms):   return ('reject','no_composition_path')
    return ('ok', C_sem)
```

### IP-123 SIC

```python
def state_isolation_cert(T, n, reads, writes_others, ctx, lease, cons, ver):
    inter = {c.id for c in reads} & {c.id for c in writes_others}
    eps = len(inter) / max(1, len(reads))
    if eps > EPS_MAX:                 return ('reject','leakage',eps)
    if cons < THETA_CONS:             return ('reject','stale_or_contam',cons)
    if not ctx.issubset({c.id for c in reads}): return ('reject','ctx_escape',ctx)
    if not all(c.ver_read >= c.ver_dep for c in reads): return ('reject','causal_violation')
    if any(lease.expired(c.id) for c in reads if c.task != T): return ('reject','lease_expired')
    return ('ok', SIC(T, n, reads, eps, cons, ver, ctx, lease, evidence=chain(reads)))
```

### IP-124 CSE

```python
def cross_modal_consistency(views):
    pairs = [(m, m2) for m in views for m2 in views if m < m2]
    deltas = [normalized_disagreement(views[m], views[m2]) for m, m2 in pairs]
    return 1.0 - max(deltas) if deltas else 1.0

def contamination_probe(store, T, n, window):
    views = {m: project(store, T, n, m, window) for m in MODALITIES}
    return cross_modal_consistency(views), \
           [m for m in MODALITIES if view_is_stale(views[m], store.vector_clock)]
```

### IP-125 SRC

```python
def couple_state_robustness(rho, eps_iso, lam=1.0):
    return {d: rho[d] * (1.0 - lam * eps_iso[d]) for d in rho}
```

### IP-126 STX

```python
def transfer_state(store_e, T, target, sigma_ce, lease, delta_state_budget):
    scope = store_e.scope(T)
    proxy = sigma_ce(scope)
    delta_state = projection_loss(sigma_ce, scope)
    if delta_state > delta_state_budget:      return ('reject','projection_loss',delta_state)
    if not proxy.all_labels_carry(lease):     return ('reject','label_stripping')
    lineage = {o: store_e.lineage(o) for o in proxy.outputs}
    return ('ok', StateContract(proxy, sigma_ce, delta_state, lease, lineage))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SCE | O(log |Ξ| + |R|) 读，O(1) 写 | O(|Ξ|) | 标签完整，版本向量因果 |
| ISB | O(Tokens²·d) + O(|atoms|·|A|) | O(ctx) | 沙箱只读、文法受限、验证器 sound |
| SIC | O(|R| + |D_iso|) | O(|R|) | 有界无干扰、lease 有效、ctx 闭包 |
| CSE | O(|M|²·|V|) | O(|M|·|V|) | 投影可比较、阈值可校准 |
| SRC | O(|D_ρ|) | O(|D_ρ|) | 对 `ε_iso` 单调不增，`ε=0` 退化 |
| STX | O(|scope| + |lineage|) | O(|σ|) | 投影有界、标签不剥离 |

**正确性定理（Isolation-Aware Propose-Verify Soundness）**
假设第 53/54 轮 (A22)–(A28) 成立；**(A29)** 验证器 `V` 对技能 DSL 计划 sound；**(A30)** 能力作用域不可伪造、胶囊标签完整；**(A31)** 版本向量在时钟偏差上界 `δ_clk` 下因果一致；**(A32)** 跨模态探针误报/漏报有界。**不假设 MLLM 正确**。则：
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
              - P(ε_iso>ε_max) - P(cons<θ_cons) - P(ver_inconsistent)
```
**核心主张**：MLLM 只影响 completeness；soundness 由 **验证器 sound + 状态隔离 + 版本因果** 承担。`SIC` 是联合证书 `J` 的前置门：`dom_SIC(T)≠in ⇒ dom_J(T)=out`。

## 6. 本轮最大风险

**一句话**：本轮把 MLLM 降级为不可信提议者、把状态隔离证书化，soundness 从“相信模型”转移到“验证器 sound + 能力作用域 + 版本因果 + 跨模态探针”，但其 **隔离性本身可能被隐信道（时序、共享 KV 缓存、输出统计）击穿**——一旦 `ctx(P̂)` 实际越界而 `SIC` 仍判 in，就会产出“隔离假象”下的跨任务污染，比显式不隔离更危险；故必须以 **KV 缓存分区与统计泄漏预算 + 污点追踪 + lease 到期强回收 + 红队注入回归** 作为硬护栏，宁可在隔离证据不足时拒批联合证书。
