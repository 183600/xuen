# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感驱动研究循环第 2 轮；本轮灵感：「竞赛策略」×「放置」）

> 第 60 轮把「执行→证据」升级为「场景→意图→执行→证据」的认知闭环：SSM 把场景变成阻抗先验、CIEC 把意图锁成实时约束、EPIR 保证 EV-exec 不丢包、SERC 统一闭环。但它仍隐含三个"实验室假设"，而 UniBot 是**有限时间、有限尝试、按评分规则定输赢**的竞赛：
> 1. **无赛局**：SERC 只优化"安全与适应"，不优化"分数与胜负"。它可能做到 100% 合规却**完美地输掉比赛**（超时、过度保守、把尝试次数浪费在低分任务上）。
> 2. **无终局**：几乎所有任务都以「放置」结算，而松爪是**不可逆**的。第 60 轮的 SIC/RPC 类证书全部是"接触期间"的可逆保证，没有任何东西证明"放手之后仍然成立"。
> 3. **无策略取证**：EPIR 只证明 EV-exec 的顺序与完整，却不证明"这次尝试是否值得、是否遵守竞赛规则、输赢是否可解释"。策略层是一个黑箱。

## 0. 直觉与动机

**灵感 1（竞赛策略 → 赛局感知竞价 CSB）**
直觉：竞赛不是"把每个动作做对"，而是**在评分规则下把有限的「尝试次数 × 时间 × 能量」押到期望收益最高的任务上**。它本质是带预算的序贯下注：领先时应当"落袋为安"，落后且有余量时才该提高风险偏好去搏高分。关键洞见：**安全证书不应是独立的硬闸门，而应作为"下注赔率"进入决策**——用证书给出的成功率下界 p_lb 去算期望得分增量，由"分差"而不是"保守程度"决定是否冒险。

**灵感 2（放置 → 松爪点证书 RPC）**
直觉：放置是"从可逆接触切换到不可逆承诺"的一瞬。松爪前必须证明的不是"现在接触合规"，而是**"松爪后的世界仍安全"**：重力投影落在支撑多边形内、释放后滑移概率低、位姿误差有界、物体与目标语义一致。关键洞见：**放置证书是对"未来"的预测性不变量（post-release invariant）**——这是它与第 60 轮所有"当下合规"证书的本质区别。

**灵感 3（竞赛策略 × 放置 → 竞赛感知分阶段放置 CSRP）**
直觉：把放置拆成「预放置（可逆逼近）→ 稳定（可逆微调）→ 终局承诺（松爪）」三段，前两段都是**可放弃的检查点**，只有第三段不可逆。是否越过最后检查点，交给赛局策略决定：时间充裕、分差允许时多微调换成功率；时间紧迫时接受较低成功率直接松爪。关键洞见：**不可逆动作前必须设置"最后的可逆检查点"，并把越线权显式交给竞赛策略**。

**灵感 4（证据链 → 策略取证与规则编译 CPC）**
直觉：EPIR 证明了"执行合规"，还缺"尝试合规、得分合规、时间合规"。把竞赛规则编译成可检查的 Rules-as-Code，每次尝试生成 `AttemptReceipt = (task_id, start/end, score_delta, rules_checked, evidence_ref, decision_trace)`。关键洞见：**把"输赢"变成可复盘的证据**——赛后申诉、反事实重放、策略调参都基于同一份收据。

**灵感 5（预算 → 五维混合预算 PCE+++++）**
直觉：第 60 轮的 B_scene/B_intent/B_ros/B_exec 是"能力预算"，而竞赛真正稀缺的是**B_comp =（B_score 保底分额度、B_release 松爪前验证次数、B_attempt 剩余尝试次数）**。B_attempt 耗尽⇒只能收尾；B_release 耗尽⇒强制最保守可放置姿态；B_score 跌破保底线⇒禁止高风险任务。关键洞见：**能力预算决定"能不能做对"，竞赛预算决定"值不值得做"**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（竞赛策略状态 CSS）** 赛局状态 X_comp = (t_rem, n_rem, ΔS, E_rem, R_active, S_bank)。其中 t_rem 剩余时间、n_rem 剩余尝试次数、ΔS = S_now − S_ref 分差（S_ref 为晋级线/对手分/保底目标）、E_rem 剩余能量、R_active 当前生效的规则集、S_bank 保底分。任务 τ 的得分模型为 r_τ: {success, partial, fail} → ℝ，罚分 −C_fail(τ) 显式进入模型（超时、碰撞、越界）。

**定义 162（风险-得分竞价 CSB）** 对候选尝试 a（任务 τ 上的一种策略），设证书给出的成功率下界 p_lb(a) = 1 − δ_cert(a)（δ_cert 由 SIC 置信度与 EV-exec 偏离导出），则：
- **期望得分增量**：EV(a) = p_lb·r_succ(τ) + (1−p_lb)·r_fail(τ) − λ_t·E[t_a] − λ_e·E[e_a]
- **竞价指数**：g(a) = EV(a) / max(E[t_a], ε)，即"单位时间期望得分"（Gittins 型索引）
- **风险偏好**：α(ΔS) = σ(β·(−ΔS)) ∈ (0,1)，落后越多越敢冒险
- **保底约束**：Vent(a) = CVaR_{α(ΔS)}(score_a)，仅当 S_now + Vent_worst(a) ≥ S_bank 才允许下注
- **决策**：a* = argmax_a g(a) s.t. g(a) ≥ θ(ΔS) ∧ S_now + worst_case(a) ≥ S_bank。
**性质**：当 ΔS 充足（领先）时 α→0、θ 抬高，策略自动"收手保分"；当 ΔS 为负且 n_rem/t_rem 仍充裕时 α→1，策略自动"搏高分"。

**定义 163（松爪点证书 RPC）** 放置状态 s = (pose, obj, support_polygon, contact)。定义释放后不变量：
```
Φ_post(s) = [σ_spt(s) ≥ σ_min] ∧ [P_slip(s) ≤ ε_slip]
          ∧ [‖e_pose(s)‖ ≤ ε_pose] ∧ [M_sem(obj, target) ≥ τ_place]
```
其中 σ_spt 为重心在支撑多边形内的裕度、P_slip 为释放后滑移概率、e_pose 为落点误差界、M_sem 为物体-目标语义匹配度。**松爪谓词**：
```
ReleaseOK(s) ⟺ Pr[ Φ_post(s) holds after release | EV-exec, z_scene, I_intent ] ≥ 1 − α_rel
```
与第 60 轮证书的区别：SIC 保证"执行时可行"，RPC 保证"放手后仍成立"。

**定义 164（放置的最优停止形式化）** 设放置分 k = 0..K 个微调阶段，状态 s_k = (e_k, σ_k, p_k^slip, t_k)，每阶段可 CONTINUE（一次微调，代价 c，转移到 s_{k+1}）或 RELEASE（吸收态）。单次放置回报：
```
R_place(s_k) = S_place·P_settle(s_k) − C_fall·(1 − P_settle(s_k))
```
值函数满足 Bellman 最优停止：
```
V(s_k) = max{ R_place(s_k),  −c + E[V(s_{k+1})] },   V(s_K) = R_place(s_K)
```
**松爪阈值面** s* = {s : R_place(s) ≥ −c + E[V(s')]}。竞赛时间压力通过 inflate c(t_rem) = c₀·(1 + η/t_rem) 进入：越到最后，继续微调的"机会成本"越高，阈值面越早触发松爪。

**定义 165（竞赛感知分阶段放置 CSRP）** 放置策略 π_place 在三个阶段间转移：
- **PRE_PLACE**：从自由空间逼近，全程可逆，可 abandon，代价 c_ab；
- **STABILIZE**：接触后微调（对位、压紧、找支撑），全程可逆，可 abandon；
- **COMMIT**：执行 `gripper.open()`，不可逆。
越线规则：`STABILIZE → COMMIT` 仅当 `ReleaseOK(s) ∧ (time_pressure ∨ marginal_gain(s) < c_micro)`。time_pressure ⟺ t_rem ≤ τ_commit；marginal_gain 为再做一次微调对 P_settle 的边际提升。**不可逆边界（irreversibility frontier）** F_irr 定义为 COMMIT 前的最后可放弃检查点集合。

**定义 166（竞赛取证与规则编译 CPC）** 把规则编译为可检查约束集 R_active = {r₁,...,r_m}（时间上界、碰撞罚分、禁用动作、有效放置判定）。每次尝试产出：
```
AttemptReceipt = (task_id, t_start, t_end, score_delta, R_checked, evidence_ref, decision_trace)
```
其中 decision_trace 记录 CSB 的候选集、p_lb、EV、α、g 与最终选择；evidence_ref 指向 EPIR 的 EV-exec 序列区间。**可复盘性**：给定 receipt + edvidence，可离线重放并做反事实（"若当时不松爪会怎样"）。

**定义 167（竞赛感知放置闭环 CAPS）** 算符 CAPS(M, tasks, X_comp)：
```
① CSS: 读取 t_rem, n_rem, ΔS, E_rem, R_active
② CSB: candidates ← plan_candidates(tasks); a* ← bid(candidates, X_comp)
③ 若 a*=∅：bank_and_finish()；否则 SERC(a*.scene, a*.intent) 逼近
④ CSRP: PRE_PLACE → STABILIZE →（ReleaseOK ∧ commit_condition）→ COMMIT
⑤ 失败：若在 F_irr 前，abandon 并退回安全态；若在 COMMIT 后，记录 settle 结果
⑥ CPC: receipt ← record(a*, outcome, cert, EV-exec)
⑦ CSS.update(outcome, receipt)；若 B_score 跌破保底 ⇒ 禁用高风险任务
⑧ Return (X_comp', receipt, outcome)
```

**定义 168（五维混合预算 PCE+++++）** B = (B_scene, B_intent, B_ros, B_exec, B_comp)，其中
- B_comp = (B_score, B_release, B_attempt)；
- B_attempt 耗尽 ⇒ 只允许"收尾/保底"动作；
- B_release 耗尽 ⇒ 强制 `ReleaseOK_conservative`（最大化 σ_spt 的保守姿态）后松爪；
- B_score < 0（跌破保底）⇒ 禁止 g(a) 依赖高方差的动作，退化为纯保底策略。
PCE+++++ 的 VOI 增加 `cost_comp = λ_att·Attempt_cost + λ_rel·Release_check_cost + λ_risk·Risk_cost`，四维能力预算与一维竞赛预算联合约束。

## 2. 关键算法伪代码

### IP-161/162 CSS + CSB（竞赛策略竞价）

```python
class CompetitionStrategyEngine:
    def __init__(self, bank_target, theta=0.0):
        self.S_bank = bank_target
        self.theta = theta
        self.trace = []

    def risk_appetite(self, delta_S):
        return 1.0 / (1.0 + math.exp(0.5 * delta_S))  # 落后(delta<0)→接近1

    def bid(self, candidates, state):
        ranked = []
        for a in candidates:
            p_lb = a.cert.success_lower_bound()      # 证书→赔率
            ev = (p_lb * a.r_succ + (1 - p_lb) * a.r_fail
                  - state.lam_t * a.t_expected - state.lam_e * a.e_expected)
            idx = ev / max(a.t_expected, 1e-6)        # 单位时间期望得分
            cvar = a.score_cvar(alpha=self.risk_appetite(state.delta_S))
            ranked.append((idx, ev, cvar, a))
        ranked.sort(key=lambda x: -x[0])
        for idx, ev, cvar, a in ranked:
            if idx < self.theta:
                continue
            if state.score + cvar < self.S_bank:      # 保底约束
                continue
            self.trace.append(dict(task=a.task, p_lb=p_lb, ev=ev,
                                   idx=idx, alpha=self.risk_appetite(state.delta_S)))
            return a
        return None
```

```python
def release_ok(s, alpha_rel=0.01):
    sigma = support_margin(s.pose, s.obj, s.support_polygon)
    p_slip = SlipModel.predict(s)
```

### IP-164/165 CSRP（最优停止 + 分阶段放置）

```python
def staged_place(M, task, state):
    reach_pose(task.target)                      # PRE_PLACE（可逆）
    while True:
        s = observe_placement_state()
        if not reversible_safe(s):
            return ABANDON_TO_SAFE               # 未越过 F_irr，可全身而退
        if release_ok(s) and commit_condition(s, M.css, state):
            gripper.open()                        # COMMIT（不可逆）
            return verify_settle(s)
        if release_ok(s) and (time_pressure(state, TAU_COMMIT)
                              or marginal_gain(s) < C_MICRO):
            gripper.open()                        # 竞赛压力下更早承诺
            return verify_settle(s)
        if M.budget.B_release <= 0:
            conservative_pose(s); gripper.open()
            return verify_settle(s)
        micro_adjust(s)                           # STABILIZE（可逆）
        M.budget.B_release -= 1

def commit_condition(s, css, state):
    # 越线权交给赛局：给 g_release 一个由分差调制的门槛
    return css.risk_appetite(state.delta_S) >= RELEASE_ALPHA_MIN
```

### IP-166/167 CAPS（竞赛感知放置闭环）

```python
def caps_loop(M, tasks, state):
    while state.t_rem > 0 and state.n_rem > 0 and state.score < state.S_goal:
        cands = plan_candidates(tasks, M.scene, M.intent)
        a = M.css.bid(cands, state)
        if a is None:
            return bank_and_finish(M, state)
        M, fused, D, ev, cert = scenario_perception_evolution_loop(
            M, a.scene, a.intent, a.delta_f)
        outcome = staged_place(M, a.task, state)
        receipt = M.cpc.record(a, outcome, cert, ev, M.css.trace)
        state = state.update(outcome, a, receipt)
        if outcome.drop_detected:
            M.css.penalize(a.task)
        if state.score - state.S_bank < 0:
            state.forbid_high_variance = True
    return M, state, M.cpc.receipts
```

### IP-168 PCE+++++ （五维预算）

```python
class PCE5Budget:
    def __init__(self, scene_ops, intent_ops, ros_retry, exec_budget,
                 bank_target, release_checks, attempts):
        self.B_scene, self.B_intent, self.B_ros = scene_ops, intent_ops, ros_retry
        self.B_exec = exec_budget
        self.B_score, self.B_release, self.B_attempt = bank_target, release_checks, attempts

    def can_attempt(self, action):
        if self.B_attempt <= 0:
            return False
        if self.B_score < 0 and action.high_variance:
            return False
        return True

    def on_release_check(self):
        self.B_release -= 1
        return self.B_release > 0

    def on_attempt(self, outcome):
        self.B_attempt -= 1
        self.B_score += outcome.score_delta
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CSS/CSB | O(\|A\| log\|A\|) / 决策 | O(\|A\|) | 保底约束 + 竞价索引最优（同质任务下 Gittins 最优） |
| RPC | O(1)（预计算支撑裕度） | O(1) | 释放后不变量置信度 ≥ 1−α_rel |
| CSRP | O(K) 阶段 | O(1) | 越过 F_irr 前任意时刻可 abandon；松爪后不变量成立 |
| CPC | O(1)/尝试 | O(#attempt) | 收据可离线重放，规则检查完备 |
| CAPS | O(闭环 × 尝试数) | 复用 | 分数单调改善或安全收尾 |

**正确性定理（CAPS）**：假设 A66–A72 成立——(A66) 证书成功率下界 p_lb 可靠；(A67) 得分模型 r_τ 与规则集 R_active 正确；(A68) ReleaseOK 的释放后预测器在置信水平 1−α_rel 下可靠；(A69) 保底约束 `S_now + worst_case ≥ S_bank` 始终被检查；(A70) 分阶段放置的 PRE_PLACE/STABILIZE 均可逆且可 abandon；(A71) CPC 收据包含决策与证据引用；(A72) PCE+++++ 各预算单调消耗。则：
1. **保底性**：只要存在可达成 S_bank 的动作序列，策略最终分数 ≥ S_bank（保底约束是硬约束）。
2. **终局安全性**：每次松爪都满足 ReleaseOK ⇒ 释放后不变量以概率 ≥ 1−α_rel 成立，掉落率被 α_rel 上界。
3. **策略竞争性**：在 K 个任务、T 次尝试的有限预算下，相较最优固定分配，竞价策略的期望得分后悔 ≤ O(√(KT log K))（预算化 bandit 的标准界）。
4. **可复盘性**：任一次尝试可由 AttemptReceipt + EPIR 证据完整重放，规则违规在重放中可判。

## 5. 本轮最大风险

**一句话**：若竞赛规则被误读、或证书给出的 p_lb 因场景/迁移误差而系统性高估，赛局竞价会把"错误的高赔率"放大成"更早、更狠、不可逆的松爪"，使第 60 轮费尽力气建立的执行安全被一次错误的终局承诺清零；必须以"规则即代码校验 + 保底分硬约束 + p_lb 保守下界 + 释放后不变量 + 越过 F_irr 前可 abandon"五重护栏，保证"敢冒险"永远不等于"赌上不可逆动作"。

| 符号 | 含义 |

## 2. 关键算法伪代码

### IP-161/162 CSS + CSB（竞赛策略竞价）

```python
class CompetitionStrategyEngine:
    def __init__(self, bank_target, theta=0.0):
        self.S_bank = bank_target
        self.theta = theta
        self.trace = []

    def risk_appetite(self, delta_S):
        return 1.0 / (1.0 + math.exp(0.5 * delta_S))   # 落后→接近1

    def bid(self, candidates, state):
        ranked = []
        for a in candidates:
            p_lb = a.cert.success_lower_bound()         # 证书→赔率
            ev = (p_lb * a.r_succ + (1 - p_lb) * a.r_fail
                  - state.lam_t * a.t_expected - state.lam_e * a.e_expected)
            idx = ev / max(a.t_expected, 1e-6)           # 单位时间期望得分
            cvar = a.score_cvar(alpha=self.risk_appetite(state.delta_S))
            ranked.append((idx, ev, cvar, a))
        ranked.sort(key=lambda x: -x[0])
        for idx, ev, cvar, a in ranked:
            if idx < self.theta:
                continue
            if state.score + cvar < self.S_bank:         # 保底硬约束
                continue
            self.trace.append(dict(task=a.task, ev=ev, idx=idx))
            return a
        return None
```

### IP-163 RPC（松爪点证书）

```python
def release_ok(s, alpha_rel=0.01):
    sigma = support_margin(s.pose, s.obj, s.support_polygon)
    p_slip = SlipModel.predict(s)
    e_pose = pose_error_bound(s)
    m_sem = semantic_match(s.obj, s.target)
    post_holds = (sigma >= SIGMA_MIN and p_slip <= EPS_SLIP
                  and e_pose <= EPS_POSE and m_sem >= TAU_PLACE)
    conf = post_release_confidence(s, sigma, p_slip, e_pose, m_sem)
    return post_holds and conf >= 1.0 - alpha_rel
```

### IP-164/165 CSRP（最优停止 + 分阶段放置）

```python
def staged_place(M, task, state):
    reach_pose(task.target)                       # PRE_PLACE（可逆）
    while True:
        s = observe_placement_state()
        if not reversible_safe(s):
            return ABANDON_TO_SAFE                # 未越过 F_irr
        if release_ok(s) and (
                M.css.risk_appetite(state.delta_S) >= RELEASE_ALPHA_MIN
                or time_pressure(state, TAU_COMMIT)
                or marginal_gain(s) < C_MICRO):
            gripper.open()                         # COMMIT（不可逆）
            return verify_settle(s)
        if M.budget.B_release <= 0:
            conservative_pose(s)
            gripper.open()
            return verify_settle(s)
        micro_adjust(s)                            # STABILIZE（可逆）
        M.budget.on_release_check()
```

```python
def caps_loop(M, tasks, state):
    while state.t_rem > 0 and state.n_rem > 0 and state.score < state.S_goal:
        cands = plan_candidates(tasks, M.scene, M.intent)
        a = M.css.bid(cands, state)
        if a is None:
            return bank_and_finish(M, state)
        M, fused, D, ev, cert = scenario_perception_evolution_loop(
            M, a.scene, a.intent, a.delta_f)
        outcome = staged_place(M, a.task, state)
        receipt = M.cpc.record(a, outcome, cert, ev, M.css.trace)
        state = state.update(outcome, a, receipt)
        if outcome.drop_detected:
            M.css.penalize(a.task)
        if state.score < state.S_bank:
            state.forbid_high_variance = True
    return M, state, M.cpc.receipts
```

### IP-168 PCE+++++（五维预算）

```python
class PCE5Budget:
    def __init__(self, scene_ops, intent_ops, ros_retry, exec_budget,
                 bank_target, release_checks, attempts):
        self.B_scene, self.B_intent, self.B_ros = scene_ops, intent_ops, ros_retry
        self.B_exec = exec_budget
        self.B_score, self.B_release, self.B_attempt = bank_target, release_checks, attempts

    def can_attempt(self, action):
        if self.B_attempt <= 0:
            return False
        if self.B_score < 0 and action.high_variance:
            return False
        return True

    def on_release_check(self):
        self.B_release -= 1
        return self.B_release > 0

    def on_attempt(self, outcome):
        self.B_attempt -= 1
        self.B_score += outcome.score_delta
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性 |
|---|---|---|---|
| CSS/CSB | O(\|A\| log\|A\|) / 决策 | O(\|A\|) | 保底约束 + 同质任务下竞价索引最优 |
| RPC | O(1) | O(1) | 释放后不变量置信度 ≥ 1−α_rel |
| CSRP | O(K) 阶段 | O(1) | 越过 F_irr 前任意时刻可 abandon |
| CPC | O(1)/尝试 | O(#attempt) | 收据可重放、规则检查完备 |
| CAPS | O(闭环 × 尝试数) | 复用 | 分数单调改善或安全收尾 |

**正确性定理（CAPS）**：若 A66–A72 成立（证书 p_lb 可靠、得分与规则模型正确、释放后预测器可靠、保底约束始终检查、可逆阶段可 abandon、收据完整、预算单调消耗），则：
1. 只要存在可达成 S_bank 的序列，最终分数 ≥ S_bank（保底硬约束）；
2. 每次松爪满足 ReleaseOK ⇒ 掉落概率 ≤ α_rel；
3. 有限 K 任务、T 次尝试下，相对最优固定分配的期望得分后悔 ≤ O(√(KT log K))；
4. 任一次尝试可由 AttemptReceipt + EPIR 证据完整重放，规则违规可判。

## 5. 本轮最大风险

**一句话**：若竞赛规则被误读、或证书给出的 p_lb 因场景/迁移误差而系统性高估，赛局竞价会把"错误的高赔率"放大成"更早、更狠、不可逆的松爪"，使第 60 轮费尽力气建立的执行安全被一次错误的终局承诺清零；必须以"规则即代码校验 + 保底分硬约束 + p_lb 保守下界 + 释放后不变量 + 越过 F_irr 前可 abandon"五重护栏，保证"敢冒险"永远不等于"赌上不可逆动作"。
