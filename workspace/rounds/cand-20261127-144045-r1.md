## 1. 直觉与动机

### 1.1 灵感 1：视觉伺服——眼睛是唯一的高频闭环传感器，但接口给的是低频开环 chunk

直觉：没有力/触觉、没有深度，接触瞬间唯一可用的反馈是图像。视觉伺服的本能方案是「每步检测关键点 → 算误差 → 修正 ee 位姿」。但 F22 揭示了一个反直觉事实：策略返回的是 T_a 步的开环 chunk，chunk 内不保证有新观测。也就是说，**视觉伺服的真正瓶颈不是检测精度，而是固定 chunk 造成的「盲窗」**。若 T_a=8、控制 15Hz，盲窗约 533ms；在这段时间里，杯子可能已经被碰倒、插头可能已经顶偏。因此本轮把视觉伺服重新定义为两件事：

(a) **chunk 边界的残差校正**：每次 get_action 用当前腕部图像算一个带权限上限的 SE(3) 残差，按衰减权重叠加到整段 chunk；
(b) **盲窗安全的 chunk 设计**：让 chunk 末端停在「可观测、低风险」的位姿（例如接触前 1–2cm 的预对齐位姿），或者用双频推理把 T_a 压到 1–2。

核心反直觉点：**在固定 chunk 接口下，「把动作做慢、把末端停在能看见的地方」比「把检测器做准」更能提升接触任务成功率。**

严谨定义（本轮采用的最小形式）：

- 控制周期 Δt = 1/f_ctrl（按官方 15Hz 参照，Δt≈66.7ms），盲窗 W = T_a·Δt。
- 关键点观测 s_t ∈ R^{2K}，目标 s*；图像误差 e_t = s_t − s*。
- 由多视图三角化/物体模型得到目标位姿 T*，当前 ee 位姿 T_t；位姿误差 ξ_t = log(T_t^{-1}T*) ∈ se(3)。
- 有界残差：ΔT_t = exp(clamp(α_t·ξ_t, δ_max))，输出 T'_t = T_t ⊕ ΔT_t。
- 权限门控：α_t = α_max·1[phase∈precision]·1[conf≥τ]·1[‖e_t‖≥ε]·1[reproj≤ρ]；δ_max 是单 chunk 的位置/角度上限。
- chunk 内衰减：第 i 步残差权重 β_i = exp(−i/κ)，避免用旧图像过度修正后段动作。

### 1.2 灵感 2：碰撞避免——碰撞不是随机误差，是几何约束违反

直觉：碰撞与「抓取失败」不同，它是「机器人/携带物体扫过的体积与场景障碍相交」的几何事件。接口没有碰撞信号，但有 4 路 RGB、关节状态、ee pose；桌面场景还有强先验（桌平面、物体大致高度、任务语义）。因此可以构造保守的 2.5D 障碍图 + 扫掠体积，做「风险分级」的安全壳：绿区直接执行，黄区减速/重定时，红区投影到可行位姿或回退重观测。

核心反直觉点：**碰撞避免的关键不是「更准的深度」，而是「风险分级 + 语义排除目标物体」——把目标物体从障碍集里排除，否则策略会被自己的抓取目标挡住，安全壳会误停。**

严谨定义：

- 动作 chunk A = {(T_i, g_i)}_{i=1..T_a}；扫掠体积 S(A) 由 ee 轨迹、夹爪开度、携带物体包围盒膨胀得到。
- 障碍集 O_t 由 RGB 重建/分割得到，显式排除机器人自身、目标物体的「预期接触面」、桌面的「可放置面」。
- 间隙 c(A) = min_{x∈S(A), y∈O_t} ‖x−y‖；风险 R(A) = max(0, m − c(A))，m 为安全裕度。
- 安全壳算子 Π：R=0 时恒等；0<R<m_y 时时间缩放/重定时；R≥m_y 时投影到可行位姿或回退到上一安全位姿并请求重观测。
- 语义排除：目标物体掩码 M_target 从 O_t 中扣除，但仅限预期接触面；其他物体仍是障碍。

### 1.3 灵感 3（统一）：双环架构——慢语义环 + 快几何环

直觉：第 2 轮结论是「中期胜负手在数据引擎」；本轮补上它的边界——数据引擎解决「会做」，但解决不了「最后一厘米」和「最后一次碰撞」。这两类失败都是几何约束违反，适合用推理期几何闭环处理，不需要再训练一个大模型。统一架构：

- **慢环（VLA 策略）**：I1/I2/I5/I9 提供动作 chunk + 进度/相位估计；
- **快环（几何 guard）**：I10 视觉伺服残差把动作投影到「目标流形」（精度）；I11 碰撞安全壳把动作投影到「自由空间」（安全）；
- **调度**：I5 进度头做相位门控，I6 双频推理做 66ms 预算分配，I8 做盲窗压力测试与消融。

核心反直觉点：**视觉伺服和碰撞避免不是两个新模块，而是同一个「几何可行性投影」的两个面——一个投影到目标流形，一个投影到自由空间。**

## 2. 对前两轮痛点的增量修订

- P5（时间压力）修正：固定 T_a 使「运行时自适应 chunk」在接口层不可行；改为「声明小 T_a + 双频推理 + chunk 末端安全位姿」。
- P6（延迟）细化：几何层必须与策略共享 66ms 预算；I6 给出预算表，I7 推理路径裁撤以腾出预算。
- P8（示教质量）补充：质量不仅是平滑/进度，还包括「间隙质量」——长期贴着障碍走的示教不应被当成高质量示教。
- 新增 P9（碰撞/几何不可行）：无碰撞信号、clutter 任务多；一次碰撞可能直接失败或损坏物体，且步骤分归零。
- 新增 P10（精度天花板/盲窗）：固定 chunk 的开环盲窗导致接触段误差累积；视觉伺服只能在 chunk 边界校正，且校正会随 chunk 内步数衰减。
- 新增 P11（几何感知可靠性）：RGB-only 的深度/关键点在遮挡、反光、透明物体（杯子/试管/注射器）上不可靠；几何层可能误停或漏停。

## 3. 研究问题（本轮立项 Q9–Q11）

- **Q9（盲窗下的视觉伺服）**：在 T_a 固定的接口下，视觉伺服应该「校正 chunk」还是「设计 chunk」？最小充分表示是什么（2D 关键点/6D 位姿/图像矩）？权限上限、衰减系数与相位门控如何设？
- **Q10（RGB-only 碰撞几何）**：如何用 4 路 RGB + 本体感知构建足够可靠的 2.5D 障碍图与扫掠体积？如何做语义排除（目标物体、可接触表面）与不确定性传播？风险阈值如何与步骤分/时间预算联合优化？
- **Q11（几何层的消融与合规）**：I10/I11 作为推理期组件是否触碰「单模型」边界？如何用 L0 盲窗压力测试 + L2 真机建立「几何代理指标→真机增益」的相关性？

## 4. 设计原则（新增 PR6–PR7）

- **PR6 盲窗-闭环律**：任何闭环几何层必须先申报其盲窗 W=T_a/f_ctrl；若 W 内可能发生不可逆事件（碰撞、打翻、插入失败），则必须缩小 T_a、或在 chunk 末端设置安全/可观测位姿，否则该闭环层不得上计分通道。
- **PR7 硬约束-软进度律**：碰撞是硬约束，进度是软目标；但硬约束的执行要风险分级，避免「安全壳过度保守→超时/步骤分损失」。默认：绿区放行、黄区减速、红区投影/回退。
- PR1–PR5 保留（第 1/2 轮）。

# UniBot-V1 参赛创新点清单（第 3 轮 v1.2）

> 检索日期：2026-11-26（第 1 轮）、2026-11-27（第 2/3 轮）；来源见 §7。承接 v1.1：新增 I10/I11，深化 I1/I3/I4/I5/I6/I8/I9，裁撤 I7 推理路径。清单只增改不重置。

## 0. 创新点清单（每点：动机 / 与现有方案差异 / 技术可行性 / 所需资源 / 落地步骤 / 风险）

### I10 多视图视觉伺服残差层（新） ★★★★★

- **动机**：32k 示教训练出的策略给出的是「平均正确」的轨迹；接触/插入/堆叠阶段需要亚厘米级对齐，误差会随固定 chunk 的开环盲窗累积。接口没有力/触觉、没有深度，唯一的高频反馈是图像。第 2 轮 I3 只覆盖「接触段脚本回退」，没有覆盖全任务的精度闭环，也没有处理 T_a 固定带来的盲窗问题。
- **与现有方案差异**：
  1. 不是替换策略，而是在策略输出上叠加**有界 SE(3) 残差**：策略负责大范围语义运动，伺服负责最后一厘米；
  2. 不是「每步闭环」的幻想，而是**chunk 边界闭环 + 盲窗安全 chunk 设计**：残差按 β_i=exp(−i/κ) 在 chunk 内衰减，末端停在可观测/低风险位姿；
  3. 不是单目深度硬猜，而是**多视图几何**：左右高位相机做固定基线三角化，腕部相机做近距校验，重投影误差门控；
  4. 与 I5 进度头联动：只在 `phase∈precision/contact` 时开启，避免运输段被伺服拖慢。
- **技术可行性**：中-高。推荐 `control_space="ee"`；若基线是 joint，则加一层 IK/雅可比把残差转成关节目标并过限位。关键点用开放词汇检测 + SAM/CoTracker 跟踪；目标位姿由多视图三角化 + 物体 CAD/检索先验（I9）得到。伺服本身零训练；可选训练一个轻量关键点热图头做加速。
- **所需资源**：1×24GB GPU 做检测/跟踪/三角化；相机标定 1 人日（棋盘格 + 机器人位姿）；工程 1–2 人周；不需要重训大模型。
- **落地步骤**：①为 5 个任务族定义关键点 schema（见 §2）；②标定 4 路相机与 ee/基座外参；③实现检测+跟踪+多视图三角化；④实现有界残差与衰减；⑤L0 盲窗压力测试（§4）；⑥在 PlugCharger/StackBowls/ZipUp 做 L2 真机 A/B。
- **风险**：透明/反光物体（杯子、试管、注射器）关键点检测不稳；标定漂移；伺服与策略「打架」导致振荡；66ms 预算不够；单模型边界合规。缓解：置信/重投影门控、权限上限、死区、相位门控；合规降级见 §6。

### I11 视觉几何碰撞安全壳（新） ★★★★

- **动机**：碰撞是硬约束，但接口没有任何碰撞/力信号；clutter 任务（StackBowls、ArrangeTestTubes、ToolboxStorage、ConveyorSorting 等）中一次碰撞可能直接失败、损坏物体，甚至让步骤分归零。第 2 轮 I4 只处理人手，没有处理物体/桌面/自碰撞。
- **与现有方案差异**：
  1. 不用碰撞传感器，用**几何可判定性**：4 路 RGB + 桌平面先验 + 物体掩码构建 2.5D 障碍图；ee 轨迹 + 夹爪 + 携带物体包围盒构建扫掠体积；
  2. **风险分级**而不是一刀切急停：绿区放行、黄区减速/重定时、红区投影到可行位姿或回退重观测；
  3. **语义排除**：把目标物体的预期接触面从障碍集里扣除，避免「安全壳挡住自己的抓取目标」；
  4. **动态障碍**：人手（I4）与传送带上的运动物体用更大的裕度和更高的风险等级。
- **技术可行性**：中。桌面场景可用「桌平面 + 物体掩码 + 高度先验」做 2.5D，避免每步跑重型深度网络；高位相机低频更新全局障碍图，腕部相机高频更新近场。自碰撞用 URDF + 关节状态做胶囊近似；ee 模式下用 IK 估计关节构型。可选：用 Isaac Lab（F14）生成碰撞/近失数据训练轻量间隙头。

## 1. 核心定义（盲窗、视觉伺服残差、碰撞风险）

### 1.1 盲窗

控制周期 Δt = 1/f_ctrl；盲窗 W = T_a·Δt。按官方 15Hz 参照，T_a=8 → W≈533ms，T_a=1 → W≈66.7ms。**W 是几何闭环层真正的时间分辨率。**

### 1.2 视觉伺服残差

- 关键点观测 s_t ∈ R^{2K}，目标 s*；图像误差 e_t = s_t − s*。
- 目标位姿 T* 由多视图三角化/物体模型给出；当前 ee 位姿 T_t；位姿误差 ξ_t = log(T_t^{-1}T*) ∈ R^6。
- 权限：α_t = α_max·1[phase∈P_precision]·1[conf≥τ]·1[‖e_t‖≥ε]·1[reproj≤ρ]。
- 有界残差：ΔT_t = exp(clamp(α_t·ξ_t, −δ_max, δ_max))；δ_max 按位置/角度分量裁剪。
- chunk 内衰减：T'_i = T_i ⊕ (β_i·ΔT_t)，β_i = exp(−i/κ)，i=0..T_a−1。
- 死区 ε 与滞回：误差小于 ε 不修正，避免抖动；连续两帧同向误差才升级修正。

### 1.3 碰撞风险

- 扫掠体积 S(A)：由 ee 轨迹、夹爪开度、携带物体包围盒（I9 先验）膨胀 m_obj 得到。
- 障碍集 O_t：RGB 分割/2.5D 重建得到；排除机器人自身、目标物体预期接触面、桌面支撑面。
- 间隙 c(A) = min_{x∈S(A), y∈O_t} ‖x−y‖；风险 R(A) = max(0, m − c(A))。
- 风险分级：绿 R=0；黄 0<R<m_y；红 R≥m_y。
- 安全壳 Π(A)：绿=恒等；黄=时间缩放 τ∈[0.5,1] 或重定时；红=投影到最近可行位姿/回退到上一安全位姿/请求重观测。
- 动态障碍：人手与运动物体用更大的 m_y 和更早的减速触发。

### 1.4 相位门控

进度头输出 p_t∈[0,1]；`phase=precision` 当 p_t∈[p1,p2] 或 ee 到目标距离 < d；否则 `phase=transport`。I10 只在 precision/contact 开启；I11 全程开启但运输段可用更小裕度。

### 3.1 视觉伺服残差层（I10）

```python
class VisualServoResidual:
    def __init__(self, calib, keypoint_schema, alpha_max=0.4,
                 delta_p=0.005, delta_theta=0.02, tau=0.6, eps=2.0):
        self.calib, self.schema = calib, keypoint_schema
        self.alpha_max, self.dp, self.dth = alpha_max, delta_p, delta_theta
        self.tau, self.eps = tau, eps

    def __call__(self, obs, chunk, phase, progress):
        if phase not in ("precision", "contact"):
            return chunk
        s, conf, reproj = detect_and_track(obs, self.schema)   # 腕部+高位多视图
        if conf < self.tau or reproj > RHO:
            return chunk
        e = s - self.schema.target_keypoints(obs)
        if np.linalg.norm(e) < self.eps:
            return chunk
        xi = pose_error_from_keypoints(e, obs, self.calib)      # se(3)
        alpha = self.alpha_max * gate(progress)
        dT = exp_se3(clamp(alpha * xi, self.dp, self.dth))
        # chunk 内衰减：越靠后越信任原策略
        out = []
        for i, T in enumerate(chunk):
            beta = np.exp(-i / KAPPA)
            out.append(compose(T, scale_se3(dT, beta)))
        return np.stack(out)
```

### 3.2 碰撞安全壳（I11）

```python
class CollisionShield:
    def __init__(self, urdf, calib, margin=0.02, m_yellow=0.01):
        self.urdf, self.calib = urdf, calib
        self.m, self.m_y = margin, m_yellow

    def reset(self, obs, instruction):
        self.obstacles = build_2p5d_obstacles(obs, self.calib)
        self.target_mask = segment_target(obs, instruction)
        self.prev_safe = obs["observation.state.left_ee_pose_gripper_base"]

    def __call__(self, chunk, target_mask, dynamic_obstacles):
        S = swept_volume(chunk, self.urdf, target_mask, inflate=self.m)
        O = self.obstacles.exclude(robot=True, target_contact=target_mask)
        O = O.union(dynamic_obstacles)                    # 人手/运动物体
        c = min_clearance(S, O)
        R = max(0.0, self.m - c)
        if R == 0.0:
            return chunk                                  # 绿区
        if R < self.m_y:
            return time_scale(chunk, factor=0.5)          # 黄区
        feasible = project_to_free_space(chunk, O, self.m)  # 红区
        return feasible if feasible is not None else retreat(self.prev_safe)
```

class DualFreqPolicy:
    VLM_PERIOD = 4          # 每 4 步刷一次 VLM 特征

**L1 分数因子**：伺服 on/off × 安全壳 on/off × T_a∈{1,2,4} × 相位门控 on/off 的 2^(4-1) 部分析因；主效应优先。

**L2 真机排队**：①I10 在 PlugCharger/StackBowls/ZipUp；②I11 在 ConveyorSorting/ToolboxStorage/ArrangeTestTubes；③I6 双频延迟回归；④I4 人手干扰 + I11 动态障碍联合测试。

**注册表字段**：run_id、T_a、α_max、m/m_y、离线 Δkp/Δservo/Δclear、真机成功率/步骤分/碰撞率；滚动计算分层 Spearman。

## 8. 本轮最值得押注（一句话）

**押「几何闭环双保险」：I10（多视图视觉伺服残差）× I11（视觉几何碰撞安全壳）× I6（双频推理/盲窗调度）——用固定接口内的 4 路 RGB + 本体感知，把「最后一厘米」和「最后一次碰撞」变成可判定、可回退的几何问题；数据引擎负责「会做」，几何闭环负责「做准、不做坏」。**

## 9. 本轮最大风险

**一句话**：I10/I11 把宝押在 RGB-only 几何估计的可靠性上，而固定 T_a 的盲窗会让一次漏检直接变成碰撞或精度失败——几何层必须先通过「盲窗压力测试」，否则只能降级为训练期辅助监督，不能上计分通道。
