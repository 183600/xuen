# 第 1 轮（新循环 v20） · 时空证书演算 STCC：用「固定迭代连续碰撞检测」把实时推理钉进 Sim-Cert-RAG 飞轮的第四根轴（四层架构 v8）

> 承接第 42 轮 v19（Sim-Cert-RAG 飞轮）。v19 的证书是**空间 × 统计**对象：在离散控制拍上 margin ≥ θ，再用 sim-to-real 界迁移。它缺第三根轴——**时间**。一来证书只在采样点成立，快速薄障碍可在两拍之间被「隧穿」；二来证书逻辑 sound 却可能**迟到**，实时推理一旦 deadline miss，控制端拿到的就是过期证书。本轮灵感词「实时推理」「碰撞检测」正好补上：**碰撞检测**给出连续时间图元（扫掠体 + 保守推进 TOI + 距离场 Lipschitz 界），**实时推理**给出时限契约（anytime 分层 + 固定迭代 WCET + 感知陈旧度记账）。二者合成 **时空证书演算（Spatio-Temporal Certificate Calculus, STCC）**：证书 = (空间安全管, 连续时间区间, 截止时刻 D)，三者同时成立才签发。飞轮因此多转一圈：Sim 注入薄/快/瞬移障碍挖隧穿反例 → CKB 存 TOI 与速度包络 → ECR 跑固定迭代定点 CCD → 实机按时返回 → 回灌 Sim。

## 0. 直觉与动机

**灵感 1（碰撞检测 → 证书从「点」变成「管」）**：v19 的守卫在每个控制拍 `t_k` 检查 `margin(x(t_k)) ≥ θ`，这在几何上只证明了「采样点安全」，两拍之间机器人仍可能扫过一根细柱子——经典**离散碰撞检测隧穿**。碰撞检测的直觉是把「点校验」换成「扫掠体校验」：用带符号距离场 `d(x, O)` 加运动的 Lipschitz 速度上界 `v_max`，就有 `d(t+δ) ≥ d(t) − v_max·δ`；于是每步可安全推进 `δ = (d(t)−θ)/v_max` 而不可能在此之前接触——这就是**保守推进（conservative advancement）**，它给出的不是快照，而是一段**时空安全管**。证书从此是「管」，不是「点」。

**灵感 2（实时推理 → 证书的时限契约与 anytime）**：把 CCD 的迭代循环直接搬上边缘端是危险的——GJK/EPA 的迭代次数数据依赖，WCET 不可界。实时推理的直觉有两条：其一，**固定迭代预算** `K_max`，超过预算就返回 `INCONCLUSIVE` 且**语义上等同 UNSAFE**（fail-safe），于是 WCET = K_max·单步代价，是常数；其二，**anytime 分层**：最粗的保守层保证按时、更细的层只在剩余预算足够时把「保守 UNSAFE」精化为「SAFE」。关键工程律是「**迟到的证书等于不安全证书**」——任何超过 deadline 的结果一律丢弃，绝不降级复用。实时推理的延迟还以**感知陈旧度**进入几何：状态估计时间戳 `t_s` 与使用时刻 `t` 之差必须用 `v_max·(t−t_s)` 膨胀障碍，否则「推理很快但状态很旧」仍是隧穿。

**灵感 3（二者耦合 → 时空证书演算与「接触瞬间」的元风险）**：空间管 × 时间区间一旦相乘，就暴露一个致命的耦合点：保守推进的 soundness 依赖 `v_max` 是真实速度上界；而**碰撞瞬间速度会跳变**（恢复系数 e>0），执行器冲击、接触反弹都会让 `‖ẋ‖` 越过名义界，于是保守推进恰恰在它最该报警的那一刻失效。STCC 的应对是**冲击感知重同步**：检测力/力矩尖峰 → 撤销当前证书 → 用冲击后速度重新播种 `v_max`，并禁止任何证书跨接触瞬间复用。再叠加**时空组合**：把相邻区间的证书段按「缝隙 + 抖动」膨胀后拼接，长时程才可组合。

**耦合升级**：v19 的飞轮是 `Sim→RAG→Edge→Sim`；STCC 给它加上时间维度，变成 `Sim(隧穿反例)→CKB(TOI+速度包络)→Edge(固定迭代 CCD+anytime 调度)→实机(时限内返回/冲击撤销)→Sim`。碰撞检测提供几何刚性，实时推理提供时间刚性，二者缺一，证书都会在「看起来对」的地方静默失效。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（连续时间安全管与时空证书）**：设障碍时变集合 `O(t)`，带符号距离 `d(x,t) = dist(x, O(t)) − r_robot`，标称轨迹 `x:[t0, t0+H]→X`。安全管 `Tube(θ,H) = {(t,x) : t∈[t0,t0+H], d(x(t),O(t)) ≥ θ}`。**时空证书** `C_st = (θ, H, t0, D, K_max, v_max)` 当且仅当三条同时成立：(i) **连续性** `∀t∈[t0,t0+H], d ≥ θ`；(ii) **时限性** 结果返回时刻 `τ ≤ D`；(iii) **预算性** 迭代数 `≤ K_max`。任一条不成立则不签发。

**定义 39（保守推进 TOI 下界）**：设 `d_k = d(x(t_k), O(t_k)) − θ ≥ 0`，且在 `[t_k, t_k+δ]` 上 `‖ẋ(t)‖ ≤ v_max`。则 `d(x(t_k+δ)) ≥ d_k − v_max·δ`。取 `δ_k = d_k / v_max`，得**首次接触时间下界** `TOI ≥ t_k + δ_k`；取 `x_{k+1} = x(t_k+δ_k; u_k)`，`t_{k+1} = t_k+δ_k`，迭代推进。**命题**：在 `[t_0, t_k+δ_k]` 上不存在碰撞。

**定义 40（固定迭代 CCD 证书 `CCD_K`）**：给定迭代上限 `K_max`，`CCD_K(x_0, H)` 返回三种标签之一：`SAFE`（在 `[t0,t0+H]` 内全程 `d ≥ θ`，附最小距离 `d_min`）、`UNSAFE`（给出 `TOI_lo`）、`INCONCLUSIVE`（预算耗尽未覆盖 `H`）。语义规定 `INCONCLUSIVE ≡ UNSAFE`。**命题（soundness）**：若 `v_max` 是 `‖ẋ‖` 的真上界，则 `CCD_K` 的 `SAFE` 结论 sound；`INCONCLUSIVE` 只增保守性，绝不漏报。`WCET ≤ K_max·(T_sdf + T_adv) + c`，为常数。

**定义 41（时限感知证书与单调 anytime）**：证书阶梯 `Tier_0 ⊏ Tier_1 ⊏ … ⊏ Tier_m`，代价递增、保守性递减，且**单调保守**：`SAFE_{j-1} ⊆ SAFE_j`。对截止时刻 `D`，调度器先跑能保证完成的**最粗层**；若其判 `UNSAFE` 且仍有剩余预算，再用更细层尝试把「保守 UNSAFE」精化为 `SAFE`。**定理（时限 soundness）**：任何在 `τ ≤ D` 返回的 `SAFE` 都是 sound；细层精化只会把 `UNSAFE` 升级为 `SAFE`，不会反向；预算耗尽返回 `UNSAFE/SafeStop`，因此**不存在「迟到的 SAFE」**。

**定义 42（感知陈旧度、速度包络与接触失效条件）**：设状态估计时间戳 `t_s`、使用时刻 `t`，定义**陈旧膨胀** `ε_stale = v_max·(t − t_s) + σ_sens`，几何校验一律用膨胀后的机器人与障碍。设名义速度包络 `v_max^nom` 由执行器与动力学给出；接触瞬间速度跳变 `Δv = (1+e)·v_n`，定义**冲击感知包络** `v_max^c = max(v_max^nom, ‖v_post‖ + a_max·Δt)`。**soundness 前提**：`v_max ≥ sup_t‖ẋ(t)‖`（含接触）。若该前提被击穿，保守推进在接触瞬间失效——必须以力/力矩尖峰触发**冲击感知重同步**：撤销证书、重估 `v_post`、重新签发。

**定义 43（时空证书合成与实时调度）**：证书段 `C_i` 覆盖 `[t_{i-1}, t_i]`。合成 `C = C_1 ⊕ … ⊕ C_m` 在接缝处要求 `d(t_i^-) ≥ θ + v_max·(jitter_max + Δ_replan)` 且 `d(t_i^+)` 同式，否则拒绝拼接。调度层：`N` 个证书子目标各带截止 `D_i`，EDF 可行性 `Σ (WCET_i / D_i) ≤ 1`，证书松弛 `s_i = D_i − WCET_i`；实时推理在每拍选择「在剩余预算内能完成的最高精化层」，目标是在 deadline 约束下最大化被证明的安全时域。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级 IP-49/51/52/53/54/55/56/45/47）

### 2.1 IP-57 RT-CCD-CERT（实时连续碰撞证书器）
1. **时空图元**：带符号距离场 + GJK/EPA 退化情形；用 `v_max` 做保守推进，输出 `TOI_lo`、`d_min`、实际迭代数、`cert_hash`。
2. **反隧穿协议**：测试集强制包含「薄障碍（厚度 < v_max·ΔT_ctrl）」「高速动态障碍」「瞬移障碍」；相对速度用 `v_rel = v_robot + v_obs_max` 而非仅机器人速度。
3. **固定迭代 + fail-safe**：`K_max` 硬上限，`INCONCLUSIVE→UNSAFE`；所有迭代用整数次数上界记账，保证 WCET 可静态核算。
4. **证书载荷**：`(θ, [t0,t0+H], D, v_max, K_used, d_min, TOI_lo)` 直接写入总线，供 CAR 做**时序守卫**。

### 2.2 IP-58 DACS（时限感知证书调度器）
1. **证书阶梯**：`T-1` 解析包络（最保守、O(1)）、`T0` L0 查表 + 固定迭代 CCD、`T1` 全量区间/CEGAR。每层带 `(WCET, 保守度)` 双标签。
2. **EDF + 松弛选层**：按 `D_i` 排序，选「`WCET ≤ 剩余预算` 的最高层」；利用率 `>1` 时按优先级逐级降层（单调保守降级）。
3. **迟到即丢弃**：结果回读时间戳，`τ > D` 一律丢弃并报 `STALE`，绝不进入控制回路；`STALE` 触发 `SafeStop` 而非复用旧证书。
4. **anytime 精化**：剩余预算用于收紧 `θ`/缩小 `Tube`，把「保守 UNSAFE」尽可能救回 `SAFE`，直接对抗 v19 的可用性崩塌。

### 2.3 IP-59 STTC（时空管合成器）
1. **接缝膨胀**：拼接按 `jitter_max + Δ_replan` 膨胀；接缝两侧 `d ≥ θ + v_max·(缝隙)`。
2. **掉拍不变量**：证书频率 `f_cert` 可低于控制频率 `f_ctrl`，但要求 `f_ctrl · ΔT_cert ≤ 安全余量/v_max`；该不等式写入证书对象。
3. **接触撤销 + 环形缓冲**：力尖峰沿总线广播即撤销所有未过期证书，禁止跨接触复用。
4. **时序守卫编译**：把 CAR 的不变式编译成 `□_{[t,t+T]} (margin ≥ θ)` 形式的时序谓词，由 STTC 提供见证。

## 3. 四层架构 v8（在 v7 上加入时间轴）

```
L1: TRI-FUSE(INT8/Q16) + IP-49 LIO(关键帧) → C_ms + B_t + v_max^nom + 感知陈旧度 ε_stale
L2: CTC + VLM + IP-35 仲裁 → R_φ(w) + 几何残差 → CKB 指纹 (φ, ψ)；所有状态带时间戳
L3: IP-51 CAR(时序守卫 □margin≥θ) ← IP-56 ECR(L0查表 + L1 INT8 + IP-57 CCD_K 固定迭代内核)
    → IP-58 DACS(EDF 选层/迟到丢弃/SafeStop) → IP-59 STTC(接缝膨胀+掉拍不变量+接触撤销)
    → IP-39 规划(margin=Tube) → IP-45 总线(新鲜度戳+ImpactEpoch) → IP-53 CMC(时限看门狗)
L4: IP-55 CKB(TOI/速度包络/恢复系数) ← IP-54 SCV(隧穿注入 + 冲击谱 + 反例归因)
    → IP-44 蒸馏(QAT→INT8) + IP-50 课程 → RCA 重颁证书(含时间区间+deadline+版本) → 热更新
运行期：L0查表(5μs) + CCD_K(≤K_max·单步) + anytime 精化 → 按时签发/接触撤销 → 飞轮回灌 Sim
```

## 5. 本轮最大风险

**一句话**：把「安全」从空间命题升级成「时限内的连续时间命题」后，最大风险是**速度界与时限同时被击穿**——接触/冲击让速度不连续、保守推进的 `v_max` 在碰撞瞬间失效，而 WCET 抖动又让证书迟到，于是系统会在「按时返回、看起来 sound」的假象下从碰撞体身上穿过去，且失效点恰好是最危险的接触瞬间，比 v19 的显式降级更难发现、更难回滚。

| 符号 | 含义 | 定义 |
|---|---|---|
| `d(x,t) = dist(x,O(t)) − r_robot` | 时变带符号距离 | 障碍距离减去机器人半径，≥0 为无碰 |
| `Tube(θ,H) = {(t,x): d(x(t),O(t)) ≥ θ, t∈[t0,t0+H]}` | 连续时间安全管 | 证书的时空有效域 |
| `C_st = (θ,H,t0,D,K_max,v_max)` | 时空证书 | 连续性 + 时限性 + 预算性三条件 |
| `δ_k = (d_k − θ)/v_max` | 保守推进步长 | 该步内不可能发生接触 |
| `CCD_K ∈ {SAFE, UNSAFE, INCONCLUSIVE}` | 固定迭代 CCD 标签 | `INCONCLUSIVE≡UNSAFE`（fail-safe） |
| `Tier_0 ⊏ … ⊏ Tier_m` | 单调 anytime 证书阶梯 | 代价递增、保守性递减、`SAFE_{j-1}⊆SAFE_j` |
| `ε_stale = v_max·(t−t_s) + σ_sens` | 感知陈旧膨胀 | 实时推理延迟进入几何的记账项 |
| `v_max^c = max(v_max^nom, ‖v_post‖ + a_max·Δt)` | 冲击感知速度包络 | 接触后重估的速度上界 |
| `C_i ⊕ C_j` | 时空证书合成 | 接缝 `d ≥ θ + v_max·(jitter_max+Δ_replan)` |
| `s_i = D_i − WCET_i` | 证书松弛 | EDF 选层与可行性判据 |

## 2. 关键算法（伪代码）

### IP-57 RT-CCD-CERT：固定迭代连续碰撞证书
```
def ccd_cert_K(x0, traj_fn, O_fn, theta, H, v_max, K_max, v_obs_max):
    # 输出 (label, t_covered, d_min, TOI_lo, k_used)
    t, x, d_min, k_used = 0.0, x0, +inf, 0
    for k in range(K_max):
        k_used = k + 1
        d = signed_distance(x, O_fn(t)) - theta      # SDF / GJK
        d_min = min(d_min, d)
        if d < 0.0:
            return ('UNSAFE', t, d_min, t, k_used)   # 已接触
        v_rel = v_max + v_obs_max(O_fn, t)           # 相对速度，防高速障碍
        if v_rel <= 1e-9:
            return ('SAFE', H, d_min, +inf, k_used)  # 静止，全时域安全
        delta = d / v_rel
        if t + delta >= H:
            return ('SAFE', H, d_min, +inf, k_used)  # 覆盖整个时域
        x = traj_fn(t + delta)                       # 沿预测轨迹推进
        t = t + delta
    # 预算耗尽：语义等同 UNSAFE，但保守只会更安全
    return ('INCONCLUSIVE', t, d_min, t, K_max)

def ccd_sound(verdict):
    # 调用方一律把 INCONCLUSIVE 当 UNSAFE，根除漏报
    return verdict if verdict[0] != 'INCONCLUSIVE' else ('UNSAFE',) + verdict[1:]
```

### IP-58 DACS：时限感知 anytime 调度
```
def certify_by_deadline(x, D, tiers, v_max):
    t0 = now()
    # 1) 最粗层：保证按时完成，先给出 sound 保守结论
    coarse = tiers[0].run(x)                    # Tier_0：解析/Minkowski 包络
    if coarse.label == 'SAFE':
        return coarse, 'SAFE', now()
    if coarse.label == 'UNSAFE' and not spare(t0, D, tiers[1]):
        return coarse, 'UNSAFE', now()
    # 2) 剩余预算内做单调精化：只允许 UNSAFE -> SAFE，绝不反向
    for tier in tiers[1:]:
        if tier.wcet > D - now():
            break
        v = tier.run(x)
        if now() > D:                           # 迟到即丢弃
            return coarse, 'STALE_DROP', now()
        if v.label == 'SAFE':
            return v, 'SAFE', now()
        if v.label == 'UNSAFE' and tier.is_final:
            break
    # 3) 预算耗尽仍不确定 -> fail-safe
    return coarse, 'SAFE_STOP', now()

def edf_select(tasks, now):
    order = sorted(tasks, key=lambda q: q.deadline)      # EDF
    plan = []
    for q in order:
        budget = q.deadline - now
        tier = next((t for t in reversed(q.tiers)
                     if t.wcet <= budget), None)          # 最高精化层
        if tier is None:
            return ('SAFE_STOP', q)                       # 来不及 -> 停
        plan.append((q, tier))
    if utilization(plan) > 1.0:                           # Sum(WCET/D) > 1
        plan = degrade_lowest_priority(plan)              # 单调保守降级
    return ('RUN', plan)
```

### IP-59 STTC：时空管合成、掉拍不变量与接触撤销
```
def compose_tubes(segments, theta, v_max, jitter_max, delta_replan):
    # 相邻证书段接缝必须留出速度可覆盖的余量
    need = theta + v_max * (jitter_max + delta_replan)
    for a, b in zip(segments[:-1], segments[1:]):
        if a.end_t != b.start_t:
            return ('REJECT', 'time_gap')
        if a.margin_end < need or b.margin_start < need:
            return ('REJECT', 'seam_margin')
        if a.v_max != b.v_max:                            # 接触后包络变更
            return ('REJECT', 'envelope_mismatch')
    return ('OK', Tube.merge(segments))

def check_drop_frame(cert, f_ctrl, f_cert, v_max, theta):
    # 证书频率可低于控制频率，但相邻证书间必须仍被管覆盖
    dt_cert = 1.0 / f_cert
    return f_ctrl * dt_cert <= (cert.d_min - theta) / max(v_max, 1e-9)

def on_impact(force_spike, x, v_pre, e, m, dt):
    # 接触瞬间：撤销所有未过期证书，禁止跨 ImpactEpoch 复用
    broadcast('ImpactEpoch', epoch=next_epoch())
    invalidate_all_certificates()
    v_post = (1.0 + e) * project_normal(v_pre, force_spike.normal)
    v_max_c = max(v_max_nominal, norm(v_post) + max_accel(m) * dt)
    return cert_new = ccd_cert_K(x, traj_fn, O_fn, theta, H, v_max_c, K_max, v_obs_max)
```

### IP-56 ECR：定点固定迭代 CCD 内核
```
def ccd_fixed_point(x_q16, O_q16, theta_q16, K_max_q16):
    # 所有运算 Q16.16 整数：SDF 查表 + 三线性插值，GJK 用整数分离轴
    # 迭代次数恰为 K_max -> WCET 常量可静态核算
    t, d_min = 0, INT32_MAX
    for k in range(K_max_int):
        d = sdf_lookup_q16(O_q16, x_q16) - theta_q16
        d_min = min_q16(d_min, d)
        if d < 0:
            return ('UNSAFE', d_min, k)
        delta = div_q16(d, v_rel_q16)
        if t + delta >= H_q16:
            return ('SAFE', d_min, k)
        x_q16 = traj_q16(t + delta)
        t += delta
    return ('INCONCLUSIVE', d_min, K_max_int)
```

### IP-51/53 升级：时序守卫与时限看门狗
```
# CAR：时序守卫 —— 要求整个 [t, t+T] 上 margin >= theta
def temporal_guard(e, cert, T, theta, f_ctrl, v_max):
    if cert is None or not cert.temporal_valid: return False
    if cert.impact_epoch != current_epoch(): return False   # 跨接触拒绝
    return check_drop_frame(cert, f_ctrl, cert.f_cert, v_max, theta) \
           and cert.d_min >= theta + v_max * T

# CMC 时限看门狗：迟到或时序失效即 trip，绝不复用旧证书
def cdf_watchdog(cert, now, D):
    if cert is None: return 'TRIP'
    if now - cert.tau > 0: return 'TRIP'          # 迟到
    if now > cert.D: return 'TRIP'                # 过期
    if not cert.temporal_valid: return 'TRIP'
    return 'OK'
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性保证 |
|---|---|---|---|
| IP-57 `CCD_K` | `O(K_max)` 固定迭代 | `O(1)` 状态 | `v_max` 为真上界 ⟹ `SAFE` sound；`INCONCLUSIVE≡UNSAFE` ⟹ 无漏报 |
| IP-57 反隧穿 | 每步 SDF/GJK `O(1)` | 同 | 相对速度 `v_rel` 与连续推进 ⟹ 消除离散采样隧穿 |
| IP-58 EDF 选层 | `O(N log N)` | `O(N)` | `Σ(WCET/D)≤1` ⟹ EDF 可行；迟到的 `SAFE` 被丢弃 ⟹ 不存在迟到 sound 假象 |
| IP-58 单调精化 | 每层至多一次 | `O(m)` | `SAFE_{j-1}⊆SAFE_j` ⟹ 精化只提升可用性、不破坏 soundness |
| IP-59 管合成 | `O(|segments|)` | `O(|segments|)` | 接缝余量 `≥v_max·(jitter+Δreplan)` ⟹ 组合后仍连续 sound |
| IP-59 掉拍不变量 | `O(1)` | `O(1)` | `f_ctrl·ΔT_cert ≤ (d_min−θ)/v_max` ⟹ 掉拍期间仍被管覆盖 |
| IP-56 定点 CCD | `O(K_max)` 整数运算 | `< 8KB`（SDF 表另计） | 定点误差 ≤ 量化步长；部署前 vs 浮点零反转才放行 |
| IP-49 扫掠体证书 | `O(1)`/查询 | `Tube` 环形缓冲 | 保守推进 TOI 下界 ⟹ 连续时间无碰 |
| IP-51 时序守卫 | `O(1)` 查表+比较 | 同证书 | `ImpactEpoch` 一致 + 掉拍不变量 ⟹ 跨接触不复用 |
| IP-42 陈旧记账 | `O(1)` | `O(1)` | `ε_stale` 膨胀 ⟹ 感知延迟不引入新的隧穿 |

|---|---|---|

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 接触/冲击使 `v_max` 失效，保守推进恰在碰撞瞬间漏报 | 高 | 力尖峰触发 `ImpactEpoch` 撤销与重同步；`v_max^c` 冲击包络；E91 红线实测 |
| WCET 抖动/缓存效应导致迟到，控制端复用旧证书 | 高 | 固定迭代 + 整数运算 + 内存锁定；迟到即丢弃 + 时限看门狗；E88/E89 红线 |
| 感知陈旧（推理快但状态旧）引入隧穿 | 高 | `ε_stale` 膨胀几何；证书新鲜度戳 `(t_s,τ,D)`；超时即降级 |
| 掉拍期间证书管覆盖不足 | 中 | 掉拍不变量 `f_ctrl·ΔT ≤ (d_min−θ)/v_max` 写入证书；违反即停 |
| 时空组合接缝处余量不足 | 中 | `jitter_max+Δ_replan` 膨胀；接缝双重校验；E90 |
| 定点 CCD 舍入导致 `d_min` 偏乐观 | 中 | 保守舍入方向（向下取整距离）、部署前浮点对拍零反转；E92 |
| SDF 建模误差导致「假安全」 | 中 | 认证 SDF 上界 + 保守膨胀；对未建模障碍回退包围盒 |
| anytime 细层仍不足把 UNSAFE 救回，可用性回落 | 低-中 | 提高证书频率/预算；E89 监控 SafeStop 占比并自适应降层 |

## 6. 本轮最大风险

**一句话**：把「安全」从空间命题升级成「时限内的连续时间命题」后，最大风险是**速度界与时限同时被击穿**——接触/冲击让速度不连续、保守推进的 `v_max` 在碰撞瞬间失效，而 WCET 抖动又让证书迟到，于是系统会在「按时返回、看起来 sound」的假象下从碰撞体身上穿过去，且失效点恰好是最危险的接触瞬间，比 v19 的显式降级更难发现、更难回滚。
