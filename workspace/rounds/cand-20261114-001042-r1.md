# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「安全性」×「机械臂抓取」）

> R69 把不确定性拆成 aleatoric/epistemic，用「信息动作」（看/问/触）去消解 epistemic，并声明这些动作与任务动作一样过 C-RAS-WM 认证、故安全（定理 17）。这套推理在屏幕与对话里大致成立，因为「看一眼」「问一句」几乎不改变世界。但**机械臂抓取把最后一个前提击穿**：在接触丰富的操作里，**获取信息的唯一方式是物理接触，而物理接触本身就是一次操作**——摸一下判断质量会把物体推离原姿态，探一下刚度会扰动已建立的力闭合，凑近看可能要求先松开唯一的稳定抓取。R69 的 VoI 假设 p(y|g,o) 不改变状态分布；抓取里这个假设是错的。
>
> 更根本的裂缝在「安全性」本身。R69 的安全是**一个**标量风险经 λ 缩放 + 前缀认证；但抓取的安全是**条件于接触模态的约束系统**——同一条轨迹在 power grasp 下安全，在 pinch grasp 下会压碎；且抓取充满**不可逆失败**（滑落、压碎、卡死），而 λ_floor 这个「慢一点」算子对不可逆失败根本无效——物体已经在滑，慢放不会把它接回来。最后，前缀认证依赖世界模型，而**新物体恰恰是 WM 最不可信的地方**，于是「认证安全」在最需要它的分布外区域变成一句空话。
>
> 本轮两个灵感正好补上两块缺失：
> - **安全性** → 从「标量风险」升级为「**接触模态条件的、含不可逆性的、带世界模型不确定度的安全契约**」——安全不是可缩放的标量，而是可行性核上的硬约束；
> - **机械臂抓取** → 提供「度量即扰动、扰动即不可逆风险」的真实物理约束，把 R69 的信息动作重新定义为**有代价的物理探询**。
>
> 核心命题：**信息不是免费的，探询会改变世界；安全不是可缩放的标量，而是条件于接触模态的可行性核。R70 只在「探询净信息增益扣除扰动与选项代价后仍为正、探询后状态仍在可行性核内、且安全证书在世界模型不确定度下仍成立」时才允许探询；否则执行保持可行性的最保守抓取或撤退。** 当扰动=0、不可逆风险=0、WM 确定时，GRIP 逐指令退化为 FLUID（R69）。
>
> 命名 **GRIP-RAS**（Grasp-aware, Risk-bounded, Irreversibility-aware Probing；RAS = Risk-Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**求证这件事本身会不会把我唯一的好抓取弄丢**」——在接触的世界里，「知道得更多」通常意味着先动一下手，而动一下手可能就回不来了。

## 0. 直觉与动机

**灵感 1（抓取 → 信息动作即操作动作）**
直觉：R69 的 RaDAR 式信息动作（注视、探针、问句）被默认为「只观测、不施力」。抓取里不存在这种免费午餐：要判断纸杯里有没有水，就得托一下、听一下、感受反力——托的这一下本身可能把杯子捏瘪或碰倒。于是信息与行动不再可分离，探询是一个**带扰动的受控转移**。这把 R69 的「先看清再做」改写成「**在做的过程中、以不破坏后路的方式小心地看**」：探询必须是状态转移方程里的一项，而不是观测方程旁的白名单。

**灵感 2（安全性 → 从标量风险到接触模态条件契约）**
直觉：R69/68 的安全是一个标量 risk ≥ R 然后 λ 缩放。但抓取的安全在语义上是**条件于接触模态**的：同一个力在「已力闭合的 power grasp」下安全，在「仅两指捏取的 pinch」下会超过局部压强上限。真正要认证的不是「这条轨迹」，而是「这条轨迹 × 每种可能的接触模态」。而接触模态（滑动/滚动/固定/脱离、软指/硬指、点/面接触）本身是不确定的，正是 R69 留下的 epistemic 对象——R69 只把它当作选动作的歧义，R70 要把它当作**安全认证的定义域**：对可行模态集里的每个模态都安全，才叫安全。

**灵感 3（不可逆性 → λ_floor 的盲区）**
直觉：R68/R69 的核心安全算子是「慢下来」（时间缩放 λ）。但它只对**动态**安全有效（惯性、反应时间、冲量）；抓取最致命的失败是**准静态不可逆**的：静摩擦锥边界只取决于切/法向力比，与速度无关；压碎只取决于压强，与速度无关；卡死只取决于几何与柔顺，与速度无关。把速度降到 0 也不能让一个已经超出摩擦锥的抓取「变安全」。所以 λ 缩放对不可逆失败不是一个完备的安全算子——**必须有一个硬的可容许性谓词（可行性核）与之并列，而不能拿 λ 当万能刹车**。

**灵感 4（选项价值 → 安全 = 保住后路）**
直觉：人在抓易碎品时不会「为了看清而把它举高」，因为举高会消耗掉「能稳稳放回桌面」这个选项。抓取的安全感与其说来自「当前这一步多安全」，不如说来自「**任何时刻都还有一条安全退路**」。这就是 viability（可行性核）：安全状态 = 存在一条留在安全集内的策略。探询的价值必须扣除它对**未来选项**的侵蚀——越靠近可行性核边界，探询越不该做。R69 的 VoI 是短视的（myopic），它会把系统一步步骗到「信息很充分、但已经无路可退」的墙角。

**灵感 5（新物体 → 安全认证恰好在最不可信处最自信）**
直觉：抓取的分布外（新物体、新材质、湿滑、形变）正是世界模型预测最差的地方，而 R69 的 certification 直接拿 WM 预测当安全真值。结果是一个危险的错配：**系统在最需要保守的时候最不保守**，因为它对「自己不认识这个物体」没有计入安全认证。补法是对 WM 的安全裕度做**共形校准**：输出的是带置信下界的安全裕度（lower confidence bound），WM 越不确定，认证越难通过；当安全裕度的 LCB 跌破阈值，唯一被认证的动作是「保持/撤退」。这是「不知道自己不知道就不能动」的抓取版。

**灵感 6（安全是双刃剑 → 过度保守也会失败）**
直觉：若把安全做成纯硬约束，系统会陷入「永远不敢碰」的瘫痪；而抓取任务的价值恰恰在接触。所以本轮不能只交付「更保守」，必须同时交付一个**安全地获取信息**的机制：在可行性核内部、以受控力探询，把 resolution bonus（R69 的效率来源）**裁剪**到不可逆预算之内。目标不是「更慢」，而是「**在不丢掉后路的前提下，敢碰**」。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GRIP-RAS 总览）** GRIP-RAS = (CMS, WSU, DVOI, IVK, SPC, SMG, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **模态全称安全**：动作必须在可行接触模态集 Ĉ(o) 内**对每个模态**满足安全契约，且认证使用世界模型安全裕度的共形下界，而非点估计；
(iii) **探询可容许性与不可逆预算**：信息动作必须在安全探询集内、其扰动后的状态必须仍在可行性核内，且每次探询消耗不可逆预算 B_irr；预算耗尽即禁止探询，resolution bonus 不得在预算为负时计入。

**定义 311（抓取阶段与接触模态集）** 阶段 p ∈ P = {approach, touch, force_closure, lift, transport, place, release}。接触模态 c = (contact_type, slip_state, finger_mode)，contact_type ∈ {point, line, area}，slip_state ∈ {sticking, sliding, rolling, separated}，finger_mode ∈ {hard, soft, underactuated}。可行模态集 Ĉ(o) = {(c, w_c)} 由感知 + 物理先验给出，Σ_c w_c = 1，w_c ≥ w_min 的模态称为「可行成员」。

**定义 312（模态条件安全包络）** 对每个模态 c，存在安全集 S_c ⊆ 𝒮 × 𝒜（由摩擦锥、压强上限、关节/几何极限、自碰撞、奇异位形定义）。模态安全谓词 safe_c(a, s) ⇔ 在 c 下执行 a 的全过程 s(·) ∈ S_c。**鲁棒安全**：safe^rob(a, s) ⇔ ∀c ∈ Ĉ(o), w_c ≥ w_min : safe_c(a, s)。区分「真安全」与「模态混淆下的伪安全」：若仅对 argmax_c w_c 成立而对某一可行模态失败，则记 mode_confusion(a) = 1。

**定义 313（世界模型安全不确定性 WSU / 共形安全批判者）** RAS-WM‡ 输出安全裕度 m̂(s, a, c)（到最近约束边界的带符号距离）与其集成/后验标准差 σ_wm(s, a, c)。在标定集上定义非一致性分数 r_i = |m_i − m̂_i|，取 (1−α) 分位数 q̂_α，则安全下界 LCB(s,a,c) = m̂ − β σ_wm − q̂_α。**认证成立**：cert(a,s,c) ⇔ LCB ≥ 0。共形覆盖：在标定与测试可交换（exchangeable）时，P(m < LCB) ≤ α，与 WM 结构无关（定理 20）。

**定义 314（度量-扰动对偶 / 接触观察者效应）** 待估参数 θ（质量 m、质心、摩擦系数 μ、刚度 k、内部状态如液体/空腔）。探询 g 施力 f、接触时长 τ、位姿偏移 δ。观测 y = h(θ, s) + ε，ε ~ 𝒩(0, σ²(f,τ))，σ² 随 f 递减（信噪比上升）。但状态被扰动：Δs(g, θ) = C(θ) f + G(θ) δ + O(‖f‖²)，柔顺矩阵 C 越大（越软越易推走）扰动越大。扰动对任务与安全的代价 d(s, Δs) 在接近不可逆边界时≥ κ‖Δs‖ 且不连续放大。

**定义 315（扰动感知 VoI，d-VoI）** d-VoI(g) = I(θ; y | g, o) − λ_d·E[d(s, Δs(g,θ))] − ρ·ΔΩ(s → s')。其中 I 为 Fisher/互信息增益，第二项是物理扰动代价，第三项是选项代价（定义 318，ΔΩ = Ω(s) − E[Ω(s')]）。**关键区别**：R69 的 VoI = H(M|o) − E[H(M|o,y)] 隐含 s'=s；d-VoI 在 s' 上评估后验，并显式扣除改变世界与侵蚀选项的代价。

**定义 316（安全探询集 STS 与最优探针力）** safe-to-probe 集 STS(s) = {g : g ∈ 𝒜_info, safe^rob(g,s), cert(g,s,c) ∀c, s' = s + Δs(g) ∈ K}。探针力上界 f_probe ≤ min(f_max^{mech}, f_crush(θ̂), f_slip(μ̂, N))。净信息-力曲线 net(f) = I(f) − λ_d·κ‖C f‖ 在 (0, f_max] 内有内点最优 f*（引理 19）。

**定义 317（不可逆失败类与吸收态）** 失败按可恢复性分类：R-类（可恢复：轻微滑移被矫正、临时失稳被回摆）、I-类（不可逆：脱手坠落、压碎/破裂、卡死、不可恢复的位姿突变）。吸收失败集 F_abs ⊂ 𝒮。不可逆事件赋吸收代价（视为 +∞ 或远超任务收益的罚），**不参与有限风险的凸组合**。

**定义 318（可行性核 IVK 与选项价值）** K = {s : ∃ 策略 π 使 s 经 T_rec 步内以概率 ≥ 1−δ 回到已知安全驻留集，且全程 s ∉ F_abs}。选项价值 Ω(s) = 从 s 可达的最大期望安全任务成功。动作可容许 ⇔ 其后继 s' ∈ K。K 由 RAS-WM‡ 离线/在线松弛计算，边界用可达集近似。

**定义 319（三级安全裁决 SMG）** 执行时按优先级三选一：
(1) **可容许过滤（硬）**：若 a 不可容许（∃c: ¬safe_c，或 s'∉K，或 cert 失败）→ 拒绝，转 (3)；
(2) **风险缩放（软）**：在可容许集内按 λ = max(λ_task, λ_floor(U_ale + 未消解 U_epi)) 缩放，继承 R69；
(3) **撤退/保持（兜底）**：a_retreat = argmin_{a: s'∈K, ¬irr} risk(a)，可为「维持当前力闭合」「停止接近」「释放到最近支撑面」。决策单调：越不确定 → 越靠 (3)。

**定义 320（不可逆预算 B_irr 与 resolution bonus 裁剪）** 每次探询 g 扣减 B_irr ← B_irr − irr_cost(g)，irr_cost = 进入 ∂K 的 margin 消耗 + 探询本身对吸收集的暴露。只有当 irr_cost(g) ≤ B_irr 且 s'∈K 时才允许。R69 的 resolution bonus（消歧后用 λ_floor(U_ale)）仅在 B_irr 未被消耗（irr_spent = 0）时全额计入；否则 bonus 被裁到 λ_floor(U_ale + U_epi)（即不提供额外效率）。**含义**：探询换来的效率不得由安全预算补贴。

**定义 321（安全证书 J_GRIP）** J_GRIP = (J_FLUID, contact_mode_margin, wm_safety_lcb, viability_margin, dvoi_net, irreversibility_budget, probe_force, split_mode, grip_ver)。Valid ⇔ Valid(J_FLUID) ∧ safe^rob ∧ (s'∈K) ∧ probe∈STS ∧ B_irr ≥ 0 ∧ LCB ≥ 0。

**定义 322（接触模态切换守卫 CSG）** 模态切换（如 sticking→sliding 或 soft→hard 接触）由守卫条件触发；切换需满足：切换后仍在 S_{c'}、切换过程不停留于边界、切换有最小 dwell-time（防抖）。模态集按一次探询/一次新兴观测做贝叶斯更新 Ĉ ← Ĉ ⊕ y（非学习写操作，仅滤波器更新）。

**定义 323（对抗抓取干扰集 ℰ_grip）** 力/力矩传感器偏置与欺骗、接触模态误分类、对抗材质（超滑/超脆/隐藏空腔）、滑移起始检测延迟、视觉位姿欺骗、他人对抓取的物理干扰。并入 AIC：ℰ_GRIP = ℰ_FLUID × ℰ_grip × ℰ_irrev（不可逆诱骗：伪装稳定的抓取）。

**定义 324（安全审计 VQAuditor-S）** 审计新增：认证是否使用了点估计而非 LCB、探询是否真的未被扰动模型吸收、是否在 ∂K 附近过度探询、撤退是否被过早/过晚触发、不可逆预算是否被正确记账。结论回灌 AuditBuf 成为下一轮 λ_d、B_irr、w_min 的先验。

**定义 325（对 R69 的退化条件）** 当 (a) 扰动模型 Δs ≡ 0（无接触/非接触任务），(b) 支撑中不含 I-类失败（F_abs = ∅），(c) WM 确定（σ_wm → 0、q̂_α → 0）时，K = 𝒮、STS = 𝒜_info、B_irr 不受限，GRIP 的每次判决与 FLUID 逐指令相同。故 FLUID（因而 R68/R67）是 GRIP 在「无扰动-无不可逆-确定世界」边界上的退化。

**定义 326（时序与自适应模态集扩张）** 默认 |Ĉ| = argmax 一个模态 + 一个备选（K_c = 2）；当 CSG 报边界驻留或 WSU 报高 σ_wm 时临时扩张到 K_c = 4（滑动/滚动/脱离/软接触）。扩张是预算与鲁棒性的折中；扩张只在接触阶段开启，approach/place 等低接触阶段保持 K_c = 1 以守 P99。

## 2. 关键算法骨架

```python
# IP-264 CMS：接触模态集与鲁棒安全包络（全称认证，不做 argmax 简化）
class ContactModeSafety:
    def plausible_modes(self, o):                 # 感知 + 物理先验 → {c: w_c}
        return normalize(self.prior(o) * self.wm.contact_likelihood(o))

    def robust_envelope(self, o, C_hat, w_min):
        # 只对 w_c >= w_min 的可行成员做全称认证
        return {c: self.constraints(c) for c, w in C_hat.items() if w >= w_min}

    def safe_c(self, a, s, c):                    # 摩擦锥 / 压强 / 关节 / 自碰撞
        return self.envelope[c].contains(s, a)

# IP-265 WSU：共形安全批判者（输出带置信下界的安全裕度）
class SafetyCritic:
    def lcb(self, s, a, C_hat, alpha):
        lcb = +inf
        for c in C_hat:
            m, sig = self.wm.safety_margin(s, a, c)
            lcb = min(lcb, m - self.beta * sig - self.conformal_q[alpha])
        return lcb                                # 取下界，非平均

# IP-266/267：扰动感知 VoI + 可行性核（探询前先算“后路还剩多少”）
def d_voi(g, s, theta, ivk, lam_d):
    ds       = disturbance(g, theta)              # 度量即扰动
    info     = fisher_gain(g, theta)             # 力越大信噪比越高
    opt_cost = ivk.option_value(s) - ivk.expected_option_value(s + ds)
    return info - lam_d * disturbance_cost(s, ds) - opt_cost

def choose_probe(modes, s, C_hat, ivk, budget):
    best = None
    for g in info_candidates(modes):
        if g not in ivk.safe_to_probe(s):  continue        # STS + 全称安全
        if not budget.allow(g):            continue
        s2 = s + disturbance(g, theta_hat)
        if not ivk.contains(s2):           continue        # 探询后必须仍在核内
        if ivk.irr_cost(g) > budget.irr:   continue        # 不可逆预算
        score = d_voi(g, s, theta_hat, ivk, LAM_D)
        if best is None or score > best.score: best = (g, score, s2)
    return best if best and best.score > 0 else None        # 净收益<=0 → 不探询

# IP-268/269：安全探询执行 + 不可逆记账
def execute_probe(M, g, s):
    f = clamp(g.force, 0, M.spc.f_star(g))                 # 内点最优力（引理19）
    y = M.spc.contact_sense(g, f)                          # 力/触觉观测
    M.ivk.spend(g, M.ivk.irr_cost(g))                      # B_irr -= cost
    return y

# IP-276 主闭环：继承 R69 FLUID_RAS_round，在“不确定性处置”处插入安全裁决
def GRIP_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c_cal, U_cal, _ = M.cof.step(...)
    K = 4 if M.fmp.mode_head(z) >= TAU_MODE else 1
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)

    # 1) 接触模态集 → 鲁棒安全包络；WSU 给带置信的安全下界
    C_hat  = M.cms.plausible_modes(o)
    safe_r = M.cms.robust_envelope(o, C_hat, W_MIN)
    lcb    = M.wsu.lcb(M.world.state, M.world.last_a, C_hat, ALPHA_S)

    # 2) 可行性核：动之前先确认“还有退路”
    s   = M.world.state
    inK = M.ivk.contains(s)
    nadir = (not safe_r) or (lcb < 0.0) or (not inK)

    # 3) 仅在安全、可行、可容许时探询；探询会扰动 → 再验一次可达性
    g = None
    if (U_epi > TAU_EPI) and not nadir:
        g = M.spc.choose_probe(modes, s, C_hat, M.ivk, M.budget)
        if g is not None:
            s2 = s + M.spc.disturbance(g, M.world.theta_hat)
            if not M.ivk.contains(s2) or not M.cms.safe_rob(g, s2, C_hat):
                g = None                                   # 扰动会越界 → 禁止探询
    if g is not None:
        y = M.spc.execute_probe(g, s)                      # 见 IP-268
        U_epi = M.cia.update_belief(modes, y, discipline='k_orthogonal_agree')
        C_hat = M.csg.bayes_update(C_hat, y)               # 定义 322

    # 4) 三级安全裁决：硬可容许 > 软 λ 缩放 > 撤退
    if nadir:
        a_exec, lam, mode = M.smg.retreat_action(s, C_hat), 1.0, RETREAT
    else:
        U_floor = U_ale + (U_epi if g is None else 0.0)
        lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
        if M.ivk.irr_spent > 0:                            # resolution bonus 不得由安全预算补贴
            lam = max(lam, lam_floor(U_ale + U_epi))
        mode   = select_mode(modes, U_epi, lam)
        a_exec = mode.a

    # 5) 硬可容许性投影 + 前缀认证（λ 不是万能的，先投影到核内）
    A = M.ach.propose(a_exec, H=M.vista.H)
    if not M.ivk.path_admissible(A):                       # 滑移/压碎/卡死前验
        A, _ = M.ivk.project_to_K(A, C_hat)
    k  = M.c_ras_wm.certified_prefix(A, ..., C_hat, wm_preds)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam

    # 6) 安全审计 + 证书
    M.vqa_s.submit_async(g, C_hat, lcb, M.ivk.margin, M.ivk.irr_spent)
    return k, lam, A, (U_ale, U_epi), J_grip(M)
```

## 3. 推导

**引理 19（度量-扰动的内点最优）** 设探针观测 y = h(θ,s)+ε，ε ~ 𝒩(0,σ²(f))，σ²(f) 单调递减且下有正下界 σ²_floor（信噪比饱和）；Fisher 信息 J(f) = HᵀΣ(f)⁻¹H 随 f 凹增，扰动代价 λ_d·d(s,Δs) ≥ λ_d·κ‖C(θ)f‖ 随 f 至少线性增长。则净信息 net(f) = tr J(f) − λ_d κ‖C f‖ 在 [0, f_max] 上连续、f→0 时 net→0、f→∞ 时 net→−∞，故存在内点最优 f* > 0；且「零扰动」与「零信息」同义（不接触就测不到接触属性）。系：**探询的成本-信息曲线永远非单调递增；R69 把信息当免费量，等价于把 f* 推到 ∞ 的错误极值**。

**引理 20（不可逆失败使 λ 缩放不完备）** 静摩擦滑移条件为 ‖f_t‖ > μ‖f_n‖，压碎条件为局部压强 p > p_max，卡死取决于几何/柔顺——三者均与执行速度无关。设一条几何路径在 f 不变时穿越这些静态边界，则对任意时间缩放 λ>0，路径仍穿越同一力/几何边界，故 sup_{λ>0} P(safe(a_λ)) < 1 当路径违反静态约束时。**因此不存在仅靠 λ_floor 提供的安全保证**；R68/R69 的 λ 只覆盖动态裕度（惯性、冲量、反应时），隐含假设了准静态可行性。必须并列一个不依赖时间的可容许性谓词。

**引理 21（选项价值与探询陷阱）** 设 K 为可行性核，Ω 为其上选项价值。探询把状态从 s 移到 s'，若 s' 更靠近 ∂K，则 E[Ω(s')] < Ω(s)（严格，除非探询保持 K 的内点）。故 d-VoI 中选项代价 ΔΩ ≥ 0，且当 s→∂K 时 ΔΩ 与 d(s,Δs) 同时增大。系：R69 的短视 VoI 在 ∂K 附近系统性过探询；其在边界带内的期望任务损失下界为 P(∂K 邻域)·ΔΩ，即使探询带来的模态熵下降完全正确。**信息越多≠越安全，若代价是未来选项。**

**定理 18（GRIP 对 FLUID 的严格安全包含）** 在 A99–A101（可行模态集覆盖真实模态；共形覆盖成立；扰动非负）下，GRIP 的可容许动作集 Admissible_GRIP(s) ⊆ Admissible_FLUID(s)，且 P(进入 F_abs) ≤ α + P(c* ∉ Ĉ) + δ_num。当 Δs≡0、F_abs=∅、σ_wm→0 时，Admissible_GRIP = Admissible_FLUID 且判决逐指令相同（定义 325）。故 R69 是 GRIP 的「无扰动-无不可逆-确定世界」边界：**安全侧严格更强，效率侧只获得被不可逆预算裁剪后的安全 resolution bonus**。

**定理 19（安全探询的净收益与探询陷阱界）** 若 d-VoI(g*) ≤ 0，则探询严格降低期望任务成功，GRIP 拒绝探询而 R69 会执行；GRIP 相对 oracle 的期望后悔 ≤ Σ_{被拒探询}(扰动代价 + 选项代价)。反之若 d-VoI(g*) > 0 且 g 可容许，期望成功增益 ≥ c·Δ_min·(1−e^{−ΔH}) − (扰动代价 + 选项代价)（把 R69 引理 16 的增益减去本轮两代价）。系：**存在一个区域，R69 因 VoI>0 而探询、GRIP 因 d-VoI≤0 而拒绝——这不是保守化，而是修正短视**。

**定理 20（分布无关的安全证书）** 以安全裕度为非一致性分数的共形校准，在标定与测试可交换下，P(m(s,a,c) < LCB) ≤ α，与 WM 结构、容量无关。因此 Valid(J_GRIP) ⇒ 单模态不可逆失败概率 ≤ α；全体模态失败概率 ≤ α + P(c* ∉ Ĉ) + δ_num。**诚实注记**：共形覆盖的前提是「可交换」，新物体/新材质恰恰破坏它——这正是本轮最大风险，不能被公式掩盖。

**定理 21（三级裁决的单调安全与无突变）** 定义 319 的优先级裁决满足：纳迪尔条件（不安全/不可行/LCB 失败）触发时执行撤退动作 a_retreat，其风险 ≤ 任一被拒动作；且从 (2) 到 (3) 的切换只减少可执行集，故安全概率单调不降。撤退为预设的 K-内动作，满足 R68 换装不变式（定理 15）⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：GRIP-RAS 的全部安全保证押在「可行接触模态集 Ĉ 与共形安全批判者都已校准」之上——**一旦新物体诱发了未建模的接触模态、或标定数据与测试不再可交换（共形覆盖失效），『对所有模态安全』就退化为空保证，而系统仍会自信地把一个不可逆动作认证为安全、并撤退进一个错误的可行性核**，于是它在最需要安全的分布外抓取里给出虚假的安全感；更隐蔽的是，错误的 K 会把「有退路」误判为「无退路」，让系统要么无谓瘫痪、要么在假边界内放心冒险。

**次级风险与缓解**：
1. **模态集漏掉真实模态**（新接触类型）→ 开放集接触检测 + OOD 触发「一律撤退」；E301/E311 专测；
2. **共形可交换性失效**（新物体/新材质）→ 按物体族分层标定 + 漂移监控，覆盖失效即降级为纯几何最坏情形认证；
3. **可行性核在错误 WM 上被算错** → 用可达集区间包络而非点估计，核外一律视为危险（保守侧）；
4. **过度保守致任务瘫痪**（永远不敢碰）→ 安全探询集 + 力-信息 Pareto（E315）显式给出「敢碰」的边界；
5. **不可逆预算记账错误/被审计绕过** → VQAuditor-S 独立核算 + J_GRIP 硬校验 B_irr ≥ 0，证书不通过即拒绝执行。

**定义 317–318（不可逆与可行性核）** 失败分 R-类/I-类；`F_abs` 赋吸收代价；`K={s: ∃π 在 T_rec 内以 ≥1−δ 回到安全驻留且不触 F_abs}`；选项价值 `Ω`；可容许 ⇔ `s'∈K`。

**定义 319（三级裁决 SMG）** 硬可容许过滤 → 软 `λ_floor` 缩放 → 撤退/保持；纳迪尔条件 = 不安全/不可行/LCB 失败；越不确定越靠撤退。

**定义 320（不可逆预算与 bonus 裁剪）** `B_irr ← B_irr − irr_cost(g)`；仅 `irr_spent=0` 时全给 resolution bonus，否则裁到 `λ_floor(U_ale+U_epi)`。

**定义 321（证书 J_GRIP）** `Valid ⇔ Valid(J_FLUID) ∧ safe^rob ∧ s'∈K ∧ probe∈STS ∧ B_irr≥0 ∧ LCB≥0`。

**定义 322（模态切换守卫 CSG）** 切换需在 `S_{c'}` 内、不驻留边界、满足 dwell-time；`Ĉ` 用贝叶斯滤波更新（非学习写操作）。

**定义 323–324（干扰与审计）** `ℰ_GRIP=ℰ_FLUID×ℰ_grip×ℰ_irrev`；VQAuditor-S 审 LCB 真实性、∂K 过度探询、撤退时机、B_irr 记账。

**定义 325–326（退化与时序）** 当 `Δs≡0、F_abs=∅、σ_wm→0` 时 GRIP≡FLUID 逐指令；`K_c=2` 常规、边界/高 σ_wm 时 `K_c=4`，低接触阶段 `K_c=1`。

## 3. 关键算法伪代码

```python
# IP-264 CMS：接触模态集与全称安全包络
class ContactModeSafety:
    def plausible_modes(self, o):
        return normalize(self.prior(o) * self.wm.contact_likelihood(o))
    def robust_envelope(self, o, C_hat, w_min):
        return {c: self.constraints(c) for c, w in C_hat.items() if w >= w_min}
    def safe_c(self, a, s, c):
        return self.envelope[c].contains(s, a)             # 摩擦锥/压强/关节/自碰撞

# IP-265 WSU：共形安全批判者（取所有可行模态的最坏下界）
class SafetyCritic:
    def lcb(self, s, a, C_hat, alpha):
        return min(self.wm.safety_margin(s, a, c)[0]
                   - self.beta * self.wm.safety_margin(s, a, c)[1]
                   - self.conformal_q[alpha] for c in C_hat)

# IP-266/267：扰动感知 VoI + 可行性核
def d_voi(g, s, theta, ivk, lam_d):
    ds = disturbance(g, theta);  info = fisher_gain(g, theta)
    opt_cost = ivk.option_value(s) - ivk.expected_option_value(s + ds)
    return info - lam_d * disturbance_cost(s, ds) - opt_cost

def choose_probe(modes, s, C_hat, ivk, budget):
    best = None
    for g in info_candidates(modes):
        if g not in ivk.safe_to_probe(s):   continue       # STS
        if not budget.allow(g):             continue
        s2 = s + disturbance(g, theta_hat)
        if not ivk.contains(s2):            continue       # 探询后仍须在核内
        if ivk.irr_cost(g) > budget.irr:    continue       # 不可逆预算
        score = d_voi(g, s, theta_hat, ivk, LAM_D)
        if best is None or score > best.score: best = (g, score, s2)
    return best if best and best.score > 0 else None       # 净收益<=0 → 不探询

# IP-268/269：安全探询执行 + 不可逆记账
def execute_probe(M, g, s):
    f = clamp(g.force, 0, M.spc.f_star(g))                 # 内点最优力（引理19）
    y = M.spc.contact_sense(g, f)
    M.ivk.spend(g, M.ivk.irr_cost(g))                      # B_irr -= cost
    return y

# IP-276 主闭环（继承 R69 FLUID_RAS_round）
def GRIP_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c_cal, U_cal, _ = M.cof.step(...)
    K = 4 if M.fmp.mode_head(z) >= TAU_MODE else 1
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    C_hat = M.cms.plausible_modes(o)
    safe_r = M.cms.robust_envelope(o, C_hat, W_MIN)
    lcb = M.wsu.lcb(M.world.state, M.world.last_a, C_hat, ALPHA_S)
    s, inK = M.world.state, M.ivk.contains(M.world.state)
    nadir = (not safe_r) or (lcb < 0.0) or (not inK)
    g = None
    if (U_epi > TAU_EPI) and not nadir:
        g = M.spc.choose_probe(modes, s, C_hat, M.ivk, M.budget)
        if g is not None:
            s2 = s + M.spc.disturbance(g, M.world.theta_hat)
            if not M.ivk.contains(s2) or not M.cms.safe_rob(g, s2, C_hat):
                g = None                                   # 扰动越界 → 禁止探询
    if g is not None:
        y = M.spc.execute_probe(g, s)
        U_epi = M.cia.update_belief(modes, y, discipline='k_orthogonal_agree')
        C_hat = M.csg.bayes_update(C_hat, y)
    if nadir:
        a_exec, lam, mode = M.smg.retreat_action(s, C_hat), 1.0, RETREAT
    else:
        U_floor = U_ale + (U_epi if g is None else 0.0)
        lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
        if M.ivk.irr_spent > 0:                            # bonus 不得由安全预算补贴
            lam = max(lam, lam_floor(U_ale + U_epi))
        mode = select_mode(modes, U_epi, lam); a_exec = mode.a
    A = M.ach.propose(a_exec, H=M.vista.H)
    if not M.ivk.path_admissible(A):                       # 滑移/压碎/卡死前验
        A, _ = M.ivk.project_to_K(A, C_hat)
    k = M.c_ras_wm.certified_prefix(A, ..., C_hat, wm_preds)
    tau = M.pi_sigma.prefix_dispatch(A[:k]) * lam
    M.vqa_s.submit_async(g, C_hat, lcb, M.ivk.margin, M.ivk.irr_spent)
    return k, lam, A, (U_ale, U_epi), J_grip(M)
```

## 4. 推导

**引理 19（度量-扰动的内点最优）** `σ²(f)` 饱和、Fisher 信息凹增、扰动代价随 f 至少线性；故 `net(f)=trJ(f)−λ_dκ‖Cf‖` 在 `(0,f_max]` 有内点最优 `f*`，且「零扰动 ⟺ 零接触信息」。系：R69 把信息当免费量等价于把 `f*→∞` 的错误极值。

**引理 20（不可逆失败使 λ 缩放不完备）** 滑移 `‖f_t‖>μ‖f_n‖`、压碎 `p>p_max`、卡死均由力/几何决定、与速度无关；故对任意时间缩放 λ>0 仍穿越同一静态边界，`sup_λ P(safe(a_λ))<1`。R68/R69 的 λ 只覆盖动态裕度，隐含准静态可行假设 ⇒ 必须并列硬可容许谓词。

**引理 21（选项价值与探询陷阱）** 探询使 `s→s'` 靠近 ∂K 时 `E[Ω(s')]<Ω(s)`，故 `ΔΩ≥0` 且随边界邻近增大；R69 短视 VoI 在 ∂K 邻域系统性过探询，损失下界 `P(∂K邻域)·ΔΩ`。

**定理 18（GRIP 严格包含 FLUID）** A99–A101 下 `Admissible_GRIP ⊆ Admissible_FLUID`，`P(F_abs) ≤ α + P(c*∉Ĉ) + δ_num`；当 `Δs≡0、F_abs=∅、σ_wm→0` 时逐指令相同。R69 = 「无扰动-无不可逆-确定世界」边界；安全严格更强，效率仅得被裁剪的安全 bonus。

**定理 19（安全探询净收益与陷阱界）** `d-VoI≤0` 时探询严格降成功、GRIP 拒绝而 R69 会执行；后悔 ≤ Σ(扰动代价+选项代价)。`d-VoI>0` 且可容许时增益 ≥ `c·Δ_min(1−e^{−ΔH}) − (扰动+选项代价)`。系：存在「R69 会探、GRIP 拒绝」的区域——这是修正短视而非保守化。

**定理 20（分布无关安全证书）** 安全裕度作非一致性分数共形校准，可交换下 `P(m<LCB)≤α`，与 WM 结构无关；故 `Valid(J_GRIP) ⇒` 单模态不可逆失败 `≤α`、全体 `≤α+P(c*∉Ĉ)+δ_num`。**诚注**：可交换性是命门，新物体恰破坏之（见最大风险）。

**定理 21（三级裁决单调安全与无突变）** 纳迪尔条件触发撤退，其风险 ≤ 任一被拒动作；从 (2)→(3) 只减少可执行集 ⇒ 安全概率单调不降；撤退为预设 K-内动作，满足 R68 换装不变式（定理 15）⇒ 连续、无突变。

## 7. 本轮最大风险

**一句话**：GRIP-RAS 的全部安全保证押在「可行接触模态集 Ĉ 与共形安全批判者都已校准」之上——**一旦新物体诱发了未建模的接触模态、或标定数据与测试不再可交换（共形覆盖失效），『对所有模态安全』就退化为空保证，而系统仍会自信地把一个不可逆动作认证为安全、并撤退进一个错误的可行性核**，于是在最需要安全的分布外抓取里给出虚假的安全感；更隐蔽的是，错误的 K 会把「有退路」误判为「无退路」，让系统要么无谓瘫痪、要么在假边界内放心冒险。

**次级风险与缓解**：模态集漏真实模态（开放集接触检测 + OOD 一律撤退，E301/E311）；共形可交换性失效（按物体族分层标定 + 漂移监控，失效即降级为几何最坏情形）；K 在错误 WM 上算错（可达集区间包络而非点估计，核外一律危险）；过度保守致瘫痪（STS + 力-信息 Pareto，E315）；B_irr 记账被绕过（VQAuditor-S 独立核算 + J_GRIP 硬校验）。
