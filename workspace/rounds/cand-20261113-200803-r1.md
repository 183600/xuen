# 第 69 轮（承接第 68 轮「CALM-RAS 自标定·自监督·单模型多任务」IP-243~252；灵感循环新循环第 2 轮；本轮灵感：「社会规范理解」×「情感语音」）

> 第 68 轮用计量层回答了「**我的测量还准吗**」，把标定升级为一等公民潜变量。但回看 R65–R68，整条闭环只建模了两类风险：**物理风险**（会不会撞/夹/过载）与**认知风险**（测量/预测可不可信）。它从未建模第三类、也是人机交互里最日常的一类：**规范性风险（normative risk）——我这么做「该不该」，而不仅仅是「安不安全」**。R66 担心「表情是假的」，R68 担心「传感器歪了」，但没人问「用户的语气在告诉我什么社会期待」。这正是本轮两个灵感词的接缝：**社会规范理解**提供「ought」（应该怎样），**情感语音**提供一条高带宽、低可控、可用于穿透伪装的「社会证据通道」（is）。
>
> 核心命题：
>
> **把「规范」建成与「标定」并列的一等公民，但用架构强制区分「描述（is）」与「规范（ought）」：显式、可溯源、经人审的规范基 Ω 负责约束，情感语音只负责解释与证据；用词典序门保证规范层只能在安全集内**收缩**、绝不扩张——NORM-RAS（Norm-Ordered Risk-Management with speech-aware, Is-Ought-separated compliance）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量准吗」，R69 问「**我该不该这么做**」——规范的加入不是放宽而是收紧，且「听起来大家都这样」绝不能反过来定义「应当怎样」。

## 0. 直觉与动机

**灵感 1（社会规范理解 → 规范不是又一条硬约束，而是「在安全集内选择更得体动作」的排序器）**
直觉：若把规范写成硬规则集（「不许打断」「不许直视」），系统会在长尾文化/情境里大面积误判并僵死。规范的本质是**分级、情境依赖、可协商**的：同一动作在医院、幼儿园、葬礼上的得体度完全不同。因此正确姿势不是「加一层过滤器把动作砍掉」，而是：
1. 安全层先给出安全动作集 A_safe；
2. 规范层只在 A_safe 内部做**词典序排序**，优先「低冒犯 + 高可逆 + 可解释」；
3. 规范不确定性高时，不是放开，而是**更顺从、更少主动性、更倾向可逆**（预防性顺从）。
关键纪律：**规范永远不能把一个不安全动作变安全（不能扩张 A_safe），只能把安全动作排序或收缩。** 这直接堵死「社会压力把危险动作合法化」这一最危险的失败通道。

**灵感 2（情感语音 → 比表情更难伪装的「泄漏通道」）**
直觉：R66/R68 的情绪判断主要靠面部，但面部是**高自愿控制**通道（假笑很容易）。副语言（F0 起伏、能量、语速、停顿、jitter/shimmer、气息）在认知负荷下**泄漏更多真实情感**，也更难同步伪装；同时它还编码**社会姿态**：顺从/支配、紧迫、礼貌、歉意、不适。于是情感语音同时提供两样东西：
- **情绪第三通道**：与面部、行为上下文做三通道一致性检验，把 R66/R68 的「两通道环」升级为「三通道环」；面部说「没事」而语音在抖、语速加快、能量尖峰 → 环破裂 → 判「被压抑的不适/伪装」；
- **规范证据**：语气里的犹豫、客套、反问、长停顿，是「这个请求在社交上不合适」的弱信号。
但必须警惕：语音与方言、性别、年龄、残障、情绪调节风格强相关——**把语音统计当规范，会变成口音/表达风格的规范化歧视**（见第 6 节最大风险）。

**灵感 3（is-ought 分离 → 统计上常见 ≠ 规范上应当）**
直觉：如果让模型「从数据里学规范」，它学到的其实是「多数人通常怎么做/怎么说话」的**描述性规律**，再被当成**规范性义务**——这就是休谟的 is-ought 鸿沟，也是本方案最大的伦理塌陷点。架构性对策：
- **规范基 Ω 只由显式规则 + 经人审的规范条目构成**，每条带来源溯源（法律/机构规章/人工标注/文化顾问），可审计、可版本化；
- **描述性模型 D 只能更新「解释/合规打分」的似然，不能生成、删除或放宽任何义务**（单向防火墙 ION）；
- 情感语音属于 D，永远不能直接写 Ω。
这样「规范能力」的增强被限制在「更好地理解已获授权的规范」，而不是「自己发明规范」。

**灵感 4（三灵感合流 → NORM-RAS 七组件）**
1. **PSR Prosody-Social Recognizer**：流式副语言前端 + 情绪/社会姿态/真诚度三头（情感语音的载体）；
2. **NSL Norm State Latent**：规范情境潜变量 n_t，**双时间尺度**——慢文化先验 + 快情境指示子，配变点检测（进医院 vs 进操场要突变重置，这点与 R68 的连续慢漂移根本不同）；
3. **NVA Norm Violation Assessor**：对候选动作给出**规范违反分布 NID**（none/minor/major/taboo）与社会风险 R_norm；
4. **LGC Lexicographic Gate**：`A_adm = A_safe ∩ 规范收缩`，规范只收缩不扩张；冲突无解时执行「最小可行安全动作 + 征询」而非违规；
5. **MDD Manipulation/Deception Detector**：三通道环 + 语用-韵律错配 + 规范施压检测，专门拦「用情绪和道德话术逼机器人做危险动作」；
6. **NSG Norm Signal Generator**：从对话修复信号（重复、否定、改口）、语气锐化、社交退避中榨取弱监督规范信号（升级 R68 的 SSG）；
7. **ION Is-Ought Normalizer + CNC Certified Norm Commit**：描述→规范的单向防火墙；规范适配器经五关（含文化留出集与反谄媚 canary）认证后才可原子换装。
8. **RAS† 继承核**：CALM-RAS / COF / CFA / CAC / C-RAS-WM / ERS-WM 全保留；标定不确定 U 与规范不确定 H_norm 汇入统一「不确定性只导向收缩」纪律。

**灵感 5（对 R66/R68 风险的对症下药）**
- R66「假笑欺骗→误放宽」：语音泄漏不对称（引理 18）提供比面部更高的欺骗检出 SNR；三通道环任一破裂即按 face_unobservable 保守；
- R68「缓变故障被标定吸收」：规范层不碰传感器可信度，U 照旧驱动 λ_floor；新增只作用于「动作得体排序」，不污染计量层；
- 两轮共同的「不确定却放宽」通道：统一为 **H_norm ↑ ⇒ 顺从↑、主动性↓、可逆性↑**（引理 17），与 R68 的 λ_floor(U) 同构，都是「不确定只收紧」。

## 1. 形式化定义（增量：定义 293–310）

**定义 293（NORM-RAS 总览）** NORM-RAS = (PSR, NSL, NVA, LGC, MDD, NSG, ION, CNC, RAS†)。三条不变式：
(i) **安全字典序优先**：`A_adm(t) ⊆ A_safe(t)` 恒成立——任何社会信号、规范先验、用户施压都不得扩张安全可行集；
(ii) **预防性顺从**：规范熵 H_norm 上升 ⇒ 顺从度 ↑、主动性上限 ↓、可逆性下限 ↑（不确定只导向保守）；
(iii) **描述-规范单向防火墙**：情感语音与行为统计只进描述性模型 D，不得生成/放宽规范基 Ω 的义务。

**定义 294（情感语音副语言通道）** 对语音流 x^s_t，流式副语言编码器 E_π 输出三元组
PSR(x^s_t) = (π^s_t ∈ Δ⁴, s_t ∈ [0,1]⁴, σ_t ∈ [0,1])，
其中 π^s 为情绪后验，s_t = (deference, dominance, urgency, politeness) 为社会姿态，σ_t 为**真诚度**（语用内容 vs 韵律的一致性）。副语言特征：F0 轮廓、能量包络、语速、停顿结构、jitter/shimmer、气息度；帧移 20 ms，增量推理。

**定义 295（三通道情绪环与泄漏不对称）** 三条条件独立通道：面部 face、语音 prosody、行为上下文 ctx。环残差
r³_emo = (KL(π^face‖π^s), KL(π^s‖π^ctx), KL(π^face‖π^ctx))。
设各通道自愿控制系数 κ_f, κ_p, κ_ctx，经验上 **κ_f > κ_p**（面部比副语言更易伪饰）。则伪装情感在通道内残留的真实情感比例分别为 (1−κ_f)、(1−κ_p)，欺骗检出 SNR 之比 ∝ √((1−κ_p)/(1−κ_f)) > 1（引理 18）。**语义**：语音是「更诚实的那条通道」。

**定义 296（社会规范的分层表示）** 规范分为：
- **描述性规范 D_norm**：某情境下多数人通常怎么做、通常用什么语气（由数据估计，属 D）；
- **规范性规范 O_norm**：被授权主体认定「应当/禁止/允许」的行为（来自规范基 Ω，属 O）。
系统只允许 O_norm 约束动作；D_norm 仅用于解释与合规打分。`O_norm = (P, F, Π)` = 允许/禁止/义务，每条带情境谓词、适用范围、来源与版本。

**定义 297（规范基与溯源）** Ω = {ω_i}，ω_i = (内容, 情境谓词, 适用人群, 来源类型 ∈ {法律, 机构规章, 人工标注, 文化顾问}, 溯源 ID, 版本)。**硬性约束**：只有 来源类型 ∈ 授权集合 的条目可生成 O_norm；任何由模型「学出来」的条目只能是 D_norm 的候选，须经人工批准并写入溯源链后才升级为 O_norm。

**定义 298（规范状态潜变量与双时间尺度）** n_t = (g_t, k_t)：g_t 为慢文化/场景先验（缓慢演化），k_t 为快情境指示子（可突变）。动力学
g_{t+1} = g_t + w_t, w ~ N(0, Q_g)；k_{t+1} = k_t 除非变点检测 CPD 触发，此时 k 重置到新情境簇。
与 R68 的标定不同：规范情境**会跳变**（推门进入手术室），故必须变点检测而非纯平滑（对比：标定 c_t 是连续慢漂移）。

**定义 299（规范违反分布 NID）** 对候选动作 a，在给定 (n_t, s_t, O_norm) 下输出
NID_t(a) = P(ℓ | a, n_t, s_t, O_norm)，ℓ ∈ {none, minor, major, taboo}。
其中 O_norm 作为先验硬约束（禁止类动作置 taboo 概率为 1 的狄拉克质量），D_norm 与 s_t 只通过似然塑形。

**定义 300（社会风险与规范 CVaR）** 严重度向量 v = (0, 1, 2, 4)。社会风险
R_norm(a) = Σ_ℓ v_ℓ · NID_t(a)[ℓ]；
规范 CVaR_α(a) = 在置信水平 α 下最坏 (1−α) 分位的期望严重度（对长尾禁忌事件更敏感）。

**定义 301（词典序门 LGC）** 安全层给出 `A_safe = {a : U_safety(a) ≤ ε_s}`。规范层定义
`A_norm(H_norm) = {a : R_norm(a) ≤ θ_norm, assert(a) ≤ Amax − κ_a·H_norm, rev(a) ≥ Rmin + κ_r·H_norm}`，
其中 assert/rev 为动作的主动性与可逆性评分。可行集 `A_adm = A_safe ∩ A_norm(H_norm)`。
选择规则：`a* = argmin_{a∈A_adm} CVaR_α(a)`；若 `A_adm = ∅`，执行**最小可行安全动作 + 征询**（绝不退回不安全动作，也绝不因规范僵死不动）。

**定义 302（规范熵与预防性顺从）** `H_norm = H(n_t | evidence)`。顺从度 `d_t = sigmoid(β(H_norm − τ_H))`；主动性上限 `Amax(t) = A⁰ − κ_a H_norm`；可逆性下限 `Rmin(t) = R⁰ + κ_r H_norm`。**语义**：听不懂社交情境时，机器人更礼貌、更少自作主张、更倾向可撤销动作。

**定义 303（操纵/欺骗检测 MDD）** 操纵分数
`M_t = w₁·(1−σ_t) + w₂·urgency_inflation + w₃·norm_pressure + w₄·face-prosody divergence + w₅·escalation_rate`，
其中 urgency_inflation = 语音紧迫度 − 情境客观紧迫度（如无火警却高紧迫），norm_pressure = 话语中「你应该/必须/大家都」等规范施压强度，face-prosody divergence = KL(π^face‖π^s)。`M_t > τ_manip` 触发：**禁止任何社会信号放松安全阈值**，并提升审计等级。
**谄媚度（sycophancy）**：`Syc = P(accept user-preferred action | user preference 与安全/规范冲突)`，用于度量「顺着用户」的倾向，目标 `Syc ≤ ε_sy`。

**定义 304（规范信号生成 NSG）** 从交互历史榨取弱监督规范信号（零人工标签为主）：
- **修复信号**：用户重复、否定（「不是」「停」）、改口、补充条件 → 前一动作为负规范样本；
- **韵律锐化**：机器人动作后用户 F0/能量/语速突增 → 不适弱标签；
- **社交退避**：目光转移、身体后撤、对话终止 → 负样本；
- **跨通道错配**：语义肯定 vs 韵律紧绷 → 压抑/敷衍标签；
- **显式纠正**：用户明确说「这样不礼貌」→ 强标签（稀有）。

**定义 305（ION 描述-规范单向防火墙）** 定义两个不共享参数的子网：D 网（从语音/行为估计描述性统计与解释）与 O 网（从 Ω 检索/组合规范性约束）。信息流仅允许 `D → 解释/合规打分`、`Ω → O_norm → NID 先验`；**禁止 D → O_norm**。形式上：NID 中所有对动作的硬约束只能来自 Ω，D 仅通过似然项影响 soft 排序。任何试图由 D 直接修改 Ω 的梯度被结构阻断（stop-gradient + 只读 Ω 接口）。

**定义 306（CNC 认证式规范提交，五关）** 规范适配器（LoRA）在影子流训练后，提交需过：
1. **安全 canary**：注入「社会施压下本应拒绝」的危险请求，放行率必须为 0；
2. **反谄媚界**：Syc ≤ ε_sy（§303）；
3. **文化留出集**：未见文化/方言子集上 NID 校准误差 ≤ δ_cult，且不得出现按口音/性别系统性差异的顺从度（公平性约束：组间顺从度差 ≤ δ_fair）；
4. **规范溯源审计**：新引入的 O_norm 条目必须全部有授权来源与人工批准记录；
5. **描述-规范隔离测试**：向 D 网注入伪相关（口音↔得体度）后，O_norm 不得改变（ION 完好性）。
全过 → 双缓冲原子换装；任一不过 → 丢弃并记入 ℰ_norm。

**定义 307（NORM 干扰集）** ℰ_NORM = ℰ_CALM × ℰ_norm × ℰ_speech × ℰ_manip：
ℰ_norm = {规范误标、文化偏见、描述-规范坍缩、过度顺从}；ℰ_speech = {韵律伪装、抑郁/焦躁误读、方言/口音偏置}；ℰ_manip = {紧迫施压、道德绑架、分步升级、情绪勒索}。

**定义 308（J_NORM 证书）** J_NORM = (J_CALM, norm_base_hash, H_norm, n_state_hash, manip_score, fairness_delta, syc_rate, cnc_verdict, norm_ver)。Valid ⇔ Valid(J_CALM) ∧ 安全 canary 未破 ∧ ION 完好 ∧ fairness_delta ≤ δ_fair ∧ cnc_verdict = PASS ∧ 规范基溯源完整。

**定义 309（管线）** 离线：规范基 Ω 构建（授权来源 + 人工批准）→ PSR 副语言预训练（可用无标注语音）→ D 网描述性预训练 → O 网规则组合 → CNC 首提。在线：每帧 PSR + NSL（CPD）→ NVA 出 NID/R_norm → LGC 词典序选择 → MDD 拦截操纵 → 异步 NSG 生成弱信号、NAuditor 审计规范事件 → CNC 周期提交。

**定义 310（谄媚/规范性安全裕度）** 定义规范性安全裕度
`Δ_norm = min_{a∈A_safe} R_norm(a) − θ_norm`。
Δ_norm < 0 表示「安全集内没有任何得体动作」——此时严禁为了得体而离开 A_safe，而应征询或执行最小可行安全动作并显式道歉/解释（把冲突显性化，而非偷偷越界）。

## 2. 关键算法骨架

```python
# IP-253/254 PSR + MTM-P：情感语音副语言通道，作为 MTM 的语音第六头
class ProsodySocialRecognizer:
    def __init__(self, hop=20):
        self.frontend = StreamingProsody(hop)   # F0/能量/语速/停顿/jitter/气息
        self.heads = {'emo': EmoHead(), 'stance': StanceHead(), 'sincere': SincereHead()}

    def step(self, audio_chunk):
        ph = self.frontend.push(audio_chunk)     # 增量副语言帧
        return {'pi_s': self.heads['emo'](ph),
                'stance': self.heads['stance'](ph),      # deference/dominance/urgency/politeness
                'sigma': self.heads['sincere'](ph)}      # 语用-韵律一致性


# IP-255/256 NSL + NVA：规范状态（双时间尺度）+ 规范违反分布
class NormStateEstimator:
    def __init__(self, d_g=16, d_k=8):
        self.g = np.zeros(d_g); self.k = np.zeros(d_k)
        self.cpd = ChangePointDetector(window=30)

    def step(self, obs_ctx, stance, O_norm):
        if self.cpd.detect(obs_ctx):             # 情境跳变 → 重置快指示子
            self.k = self.cpd.new_cluster(obs_ctx)
        self.g = self.g + np.random.randn(d_g) * 0  # 慢先验（此处省略 update）
        n = np.concatenate([self.g, self.k])
        H_norm = entropy(self.posterior(n))
        return n, H_norm


class NormViolationAssessor:
    def nid(self, action, n, stance, O_norm):
        hard = O_norm.forbid_mask(action, n)     # 禁止类 → taboo 的狄拉克质量
        if hard.any(): return hard
        # 只允许 O_norm 提供硬约束；D 网仅通过似然塑形（ION 防火墙）
        likelihood = self.d_net.explain(action, n, stance)
        return normalize(likelihood * O_norm.soft_prior(action, n))

    def risk(self, action, nid):
        v = np.array([0., 1., 2., 4.]); return float((v * nid).sum())


# IP-257/258 LGC + MDD：词典序门 + 操纵检测
class LexicographicGate:
    def select(self, A_safe, nid_fn, H_norm):
        Amax = A0 - KA * H_norm
        Rmin = R0 + KR * H_norm
        A_norm = [a for a in A_safe
                  if assertiveness(a) <= Amax and reversibility(a) >= Rmin
                  and nid_fn(a).risk() <= theta_norm]
        A_adm = A_norm or [min_safe_action(A_safe)]   # 绝不退回不安全动作
        return min(A_adm, key=lambda a: nid_fn(a).cvar(alpha=0.9))


class ManipulationDetector:
    def score(self, pi_face, pi_s, stance, ctx, dialog):

        norm_press = dialog_pressure(dialog)                 # 「你必须/大家都…」
        divergence = kl(pi_face, pi_s)
        return (W1*(1 - self.sigma) + W2*max(0, urgency_infl)
                + W3*norm_press + W4*divergence + W5*escalation(dialog))

# IP-264 主闭环：NORM-RAS round
def NORM_RAS_round(M, obs):
    audio, ctx, dialog = obs['audio'], obs['scene'], obs['dialog']
    # 1) 情感语音副语言通道（流式）
    ps = M.psr.step(audio)                                  # pi_s, stance, sigma
    # 2) 规范状态（双时间尺度 + 变点）+ 规范熵
    n, H_norm = M.nsl.step(ctx, ps['stance'], M.O_norm)
    # 3) 三通道情绪环（面部/语音/上下文）
    r3 = ring_residual(M.pi_face, ps['pi_s'], M.pi_ctx)
    # 4) 操纵/欺骗检测（语用-韵律-紧迫-规范施压）
    M_score = M.mdd.score(M.pi_face, ps['pi_s'], ps['stance'], ctx, dialog)
    if M_score > TAU_MANIP:
        M.lambda_safety_floor = max(M.lambda_safety_floor, 0.8)  # 只收紧，绝不放宽
    # 5) 安全层先出安全集（继承 R68 的 CALM-RAS 风险缩放）
    A_safe = M.calm.safe_actions(ctx, lam_floor=M.lambda_safety_floor)
    # 6) 规范层：NID + 词典序门（只收缩，不扩张）
    def nid_of(a): return M.nva.nid(a, n, ps['stance'], M.O_norm)
    a_star = M.lgc.select(A_safe, nid_of, H_norm)
    # 7) 冲突显性化：安全集内无得体动作 → 征询/解释，而非越界
    if M.lgc.no_admissible(A_safe, nid_of):
        return M.defer_with_explanation(A_safe, n, H_norm, r3, M_score)
    # 8) 执行 + 异步（NSG 弱信号 / NAuditor 审计 / CNC 提交）
    tau = M.executor.dispatch(a_star, deference=M.lgc.deference(H_norm))
    M.nsg.submit_async(dialog, a_star, ps)                  # 修复信号/韵律锐化/退避
    M.nauditor.submit_async(a_star, n, H_norm, M_score, M.O_norm)
    M.cnc.maybe_commit(M.shadow, dt=M.time_since_last_commit)
    return a_star, H_norm, r3, M_score
```

## 3. 推导

**引理 16（词典序安全不可被规范劫持）** 由定义 301，`A_adm = A_safe ∩ A_norm`，故对任意社会信号、规范先验、用户施压，恒有 `A_adm ⊆ A_safe`。因此规范层是安全层上的**单调收缩算子**：`P(unsafe | NORM-RAS) ≤ P(unsafe | CALM-RAS)`。系：任何「用情绪/道德话术逼机器人做危险动作」的操纵在结构上无法通过扩张安全集成功；它只能影响安全集内的排序。

**引理 17（规范熵单调预防性顺从）** 由定义 302，d_t、Amax(t)、Rmin(t) 对 H_norm 的偏导分别为 ≥0、≤0、≥0，故 `H_norm ↑ ⇒ 可行集 A_adm 单调收缩（在偏序意义下）`。又因 A_adm ⊆ A_safe，收缩不会引入新的不安全动作。**结论：规范不确定只会让系统更保守、更可逆、更少主动性，绝不更激进。**

**引理 18（语音泄漏不对称提升欺骗检出）** 在定义 295 的通道控制模型下，伪装情感在通道 c 的残留真实信号比例 ∝ (1−κ_c)。面部—语音两通道差分统计量对「伪饰 vs 真实」的 SNR 之比 = √((1−κ_p)/(1−κ_f))。取 κ_f = 0.7、κ_p = 0.3，得 SNR 比 ≈ 1.53；与行为上下文构成三通道环后，任一通道破裂即可触发保守处理。**结论：情感语音不是锦上添花，而是把 R66/R68 的欺骗防线从「易伪饰的面部」迁移到「更难伪饰的副语言」。**

**引理 19（规范弱信号的延迟监督界）** 修复信号/韵律锐化为**延迟、稀疏、含噪**弱标签。设修复信号在动作后 Δ 步出现，弱标签噪声率 η，则在 N_int 次交互后，规范排序器的超额风险 ≤ √(β_norm/n_label) + C·√(η/N_int) + D·Δ/N_int（延迟项随历史增长衰减）。系：规范能力必须走「弱信号预训练 + 少量强纠正」，与 R68 引理 14 同构。

**定理 16（NORM-RAS 端到端规范-安全一致性）** 在 A87–A94、A95（规范基溯源完整）、A96（III 通道泄漏不对称）下：
1. **安全不扩张**：`P(unsafe) ≤ P_R68(unsafe)`（引理 16），规范层零安全代价；
2. **预防性顺从**：`H_norm > τ_H ⇒ d ↑ ∧ Amax ↓ ∧ Rmin ↑`，且规范违反期望 `E[R_norm]` 随 H_norm 单调不增（引理 17）；
3. **抗操纵**：`M_t > τ_manip ⇒ λ_safety 只升不降`，社会压力通过安全集的概率为 0；漏检时仍受 1 支配；
4. **抗欺骗**：伪装情感接受概率上界由引理 18 的 SNR 与三通道环给出，弱于纯面部基线；
5. **抗谄媚**：`P(接受与安全/规范冲突的用户偏好 | 标注谄媚 canary) ≤ ε_sy`（CNC 第 2 关）。

**定理 17（CNC 认证的规范性安全）** 五关中安全 canary 放行率为 0（硬门）、反谄媚关把谄媚率压到 ε_sy、文化留出关限制跨群体顺从度差 ≤ δ_fair、ION 完好性关保证 D 网伪相关无法改写 O_norm。故「有害/歧视性规范适配器」上线概率 ≤ (1−r_canary^norm)·p_h，且任何上线适配器都不能新增未经授权的义务（溯源关）。提交窗口内 λ_safety 冻结、动作排序连续 ⇒ 换装无控制突变；回滚失败触发全局降级（退化为 CALM-RAS，规范层关闭）。

## 6. 本轮最大风险

**一句话**：NORM-RAS 用「情感语音 + 行为统计」去**理解**规范，但架构可以隔离 is-ought，却无法消除一个更深的事实——**规范本身在人群间是冲突的**；一旦规范基 Ω 的来源覆盖不全，系统会把某一文化/群体的**描述性常态**当作**规范性义务**，而情感语音又与口音、性别、年龄、残障、情绪调节风格强相关，于是「更懂礼貌」会退化为**用韵律给人贴标签、并以安全之名实施规范化歧视**；更隐蔽的是，词典序安全不变式让这种歧视在安全指标上完全隐形（它从不扩张安全集，只是对某些人更少主动、更多征询、更频繁降级）——**系统越"安全"，偏见越不可见**。

**次级风险与缓解**：
1. **礼貌性僵死**：H_norm 高导致可行集近乎为空 → 最小可行安全动作 + 显性征询 + Δ_norm<0 时解释冲突（定义 310），并设僵死率监控；
2. **语音误读**（抑郁/焦躁/方言被读成「不适/敌意」）→ σ 校准 + 三通道环 + 文化留出集 + 组间公平约束；
3. **规范基覆盖不全/过时** → 溯源链 + 版本化 + 定期人审 + 明确「未覆盖 ≠ 允许」的保守默认；
4. **操纵漏检**（分步升级绕过单帧阈值）→ 对话级累积特征 + 升级率 + 长窗口审计；
5. **描述-规范坍缩回潮**（D 网通过看似无害的 soft prior 渐进影响排序）→ ION 完好性测试 + 伪相关注入回归 + Ω 只读接口。

## 2. 形式化定义（要点版）

**定义 293（总览与三不变式）** 安全字典序优先（`A_adm ⊆ A_safe`，规范不扩张安全）；预防性顺从（H_norm↑ ⇒ 顺从↑/主动性↓/可逆性↑）；描述-规范单向防火墙（D 不得生成/放宽 O_norm）。

**定义 294（情感语音通道）** `PSR: x^s → (π^s ∈ Δ⁴, s ∈ [0,1]⁴, σ ∈ [0,1])`；特征 F0/能量/语速/停顿/jitter/shimmer/气息；20ms 帧移增量推理。

**定义 295（三通道环与泄漏不对称）** `r³_emo` 三通道两两 KL；κ_f>κ_p ⇒ 语音残留真实情感更多，欺骗检出 SNR ∝ √((1−κ_p)/(1−κ_f))>1。

**定义 296–297（is / ought 分层与规范基）** D_norm 由数据估计仅作解释；O_norm 仅来源于授权规范基 Ω，每条带情境谓词/适用人群/来源/版本/溯源 ID；模型学出的只能是候选，须人审升格。

**定义 298（规范状态与双时间尺度）** `g_{t+1}=g_t+w_t, w~N(0,Q_g)`；k 由变点检测在情境跳变时重置。**情境会跳变**，故用 CPD 而非 R68 的连续平滑。

**定义 299–300（NID 与社会风险）** `NID_t(a)=P(ℓ|a,n_t,s_t,O_norm)`，禁止类为 taboo 狄拉克；`R_norm=Σ v_ℓ NID[ℓ]`，v=(0,1,2,4)；另有规范 CVaR。

**定义 301（词典序门）** `A_adm = A_safe ∩ {R_norm≤θ_norm, assert≤Amax−κ_a H_norm, rev≥Rmin+κ_r H_norm}`；`a*=argmin CVaR`；空集 → 最小可行安全动作 + 征询。

**定义 302（预防性顺从）** `Amax(t)=A⁰−κ_a H_norm`，`Rmin(t)=R⁰+κ_r H_norm`，`d_t=sigmoid(β(H_norm−τ_H))`。

**定义 303（操纵与谄媚）** `M_t = w₁(1−σ)+w₂·urgency_infl+w₃·norm_pressure+w₄·face-prosody div+w₅·escalation`；`M_t>τ ⇒ λ_safety 只升不降`；`Syc=P(accept 冲突偏好)`。

**定义 304（规范弱信号 NSG）** 修复信号（重复/否定/改口）、韵律锐化、社交退避、跨通道错配、显式纠正。

**定义 305（ION 描述-规范单向防火墙）** D 网与 O 网不共享参数/梯度；信息流仅 `D→解释/合规`、`Ω→O_norm→NID 硬先验`；禁止 `D→O_norm`；伪相关注入后 O_norm 必须不变。

**定义 306（CNC 五关）** 安全 canary（放行率 0）/ Syc ≤ ε_sy / 文化留出 + 组间顺从差 ≤ δ_fair / 规范溯源审计 / ION 隔离测试；全过原子换装。

**定义 307–308（干扰集与证书）** ℰ_NORM = ℰ_CALM×ℰ_norm×ℰ_speech×ℰ_manip；J_NORM Valid ⇔ J_CALM 有效 ∧ 安全 canary 未破 ∧ ION 完好 ∧ fairness≤δ_fair ∧ PASS ∧ 溯源完整。

**定义 309–310（管线与规范性安全裕度）** 离线规范基/副语言预训练 → 在线 PSR/NSL/NVA/LGC/MDD → 异步 NSG/NAuditor/CNC；`Δ_norm=min_{A_safe}R_norm−θ_norm<0` 时显性化冲突（征询/解释），绝不偷偷越界。

```python
# IP-253/254 PSR + MTM-P：情感语音副语言通道（流式）
class ProsodySocialRecognizer:
    def __init__(self, hop=20):
        self.frontend = StreamingProsody(hop)
        self.heads = {'emo': EmoHead(), 'stance': StanceHead(), 'sincere': SincereHead()}
    def step(self, audio_chunk):
        ph = self.frontend.push(audio_chunk)              # F0/能量/语速/停顿/jitter/气息
        return {'pi_s': self.heads['emo'](ph),
                'stance': self.heads['stance'](ph),        # deference/dominance/urgency/politeness
                'sigma': self.heads['sincere'](ph)}        # 语用-韵律一致性

# IP-255/256 NSL + NVA：双时间尺度规范状态 + 规范违反分布
class NormStateEstimator:
    def __init__(self, d_g=16, d_k=8):
        self.g = np.zeros(d_g); self.k = np.zeros(d_k)
        self.cpd = ChangePointDetector(window=30)
    def step(self, ctx, stance, O_norm):
        if self.cpd.detect(ctx):
            self.k = self.cpd.new_cluster(ctx)            # 情境跳变 → 重置快指示子
        self.g = self.g + self.update_g(ctx)
        H_norm = entropy(self.posterior(np.concatenate([self.g, self.k])))
        return np.concatenate([self.g, self.k]), H_norm

class NormViolationAssessor:
    def nid(self, action, n, stance, O_norm):
        hard = O_norm.forbid_mask(action, n)              # 禁止类 → taboo 狄拉克
        if hard.any(): return hard
        likelihood = self.d_net.explain(action, n, stance) # D 仅通过似然塑形（ION）
        return normalize(likelihood * O_norm.soft_prior(action, n))
    def risk(self, nid):
        v = np.array([0., 1., 2., 4.]); return float((v * nid).sum())

# IP-257/258 LGC + MDD：词典序门 + 操纵检测
class LexicographicGate:
    def select(self, A_safe, nid_fn, H_norm):
        Amax, Rmin = A0 - KA*H_norm, R0 + KR*H_norm
        A_norm = [a for a in A_safe
                  if assertiveness(a) <= Amax and reversibility(a) >= Rmin
                  and nid_fn(a).risk() <= theta_norm]
        A_adm = A_norm or [min_safe_action(A_safe)]       # 绝不退回不安全动作
        return min(A_adm, key=lambda a: nid_fn(a).cvar(alpha=0.9))

class ManipulationDetector:
    def score(self, pi_face, pi_s, stance, ctx, dialog, sigma):
        urgency_infl = stance['urgency'] - objective_urgency(ctx)
        return (W1*(1-sigma) + W2*max(0, urgency_infl)
                + W3*dialog_pressure(dialog) + W4*kl(pi_face, pi_s)
                + W5*escalation(dialog))

# IP-260/261 ION + CNC：描述-规范单向防火墙 + 五关认证
class IsOughtNormalizer:
    def enforce(self, nid, d_explanation, O_norm):
        assert not d_explanation.produces_obligation, "ION 违反：D 网试图生成义务"
        return nid.with_hard_prior(O_norm)               # 硬约束只来自 Ω

class CertifiedNormCommit:
    GATES = [safety_canary_zero, sycophancy_bound, culture_holdout,
             provenance_audit, ion_integrity]
    def maybe_commit(self, shadow, dt):
        if dt < self.T_commit: return None
        verdict = {g.__name__: g(shadow) for g in self.GATES}
        if all(verdict.values()): atomic_swap(self.live_ptr, shadow); return 'PASS'
        log_to_enorm(verdict); return 'REJECT'

# IP-264 主闭环：NORM-RAS round
def NORM_RAS_round(M, obs):
    ps = M.psr.step(obs['audio'])                         # 1) 语音副语言通道
    n, H_norm = M.nsl.step(obs['scene'], ps['stance'], M.O_norm)  # 2) 规范状态+熵
    r3 = ring_residual(M.pi_face, ps['pi_s'], M.pi_ctx)   # 3) 三通道环
    M_score = M.mdd.score(M.pi_face, ps['pi_s'], ps['stance'],
                          obs['scene'], obs['dialog'], ps['sigma'])  # 4) 操纵检测
    if M_score > TAU_MANIP:
        M.lambda_safety_floor = max(M.lambda_safety_floor, 0.8)   # 只收紧
    A_safe = M.calm.safe_actions(obs['scene'], lam_floor=M.lambda_safety_floor)  # 5) 安全集
    nid_of = lambda a: M.nva.nid(a, n, ps['stance'], M.O_norm)    # 6) NID
    a_star = M.lgc.select(A_safe, nid_of, H_norm)         #    词典序（只收缩）
    if M.lgc.no_admissible(A_safe, nid_of):
        return M.defer_with_explanation(A_safe, n, H_norm, r3, M_score)  # 7) 冲突显性化
    tau = M.executor.dispatch(a_star, deference=M.lgc.deference(H_norm)) # 8) 执行
    M.nsg.submit_async(obs['dialog'], a_star, ps)         #    异步弱信号
    M.nauditor.submit_async(a_star, n, H_norm, M_score, M.O_norm)
    M.cnc.maybe_commit(M.shadow, M.time_since_last_commit)
    return a_star, H_norm, r3, M_score
```

## 4. 推导

**引理 16（词典序安全不可被规范劫持）** 由定义 301，`A_adm=A_safe∩A_norm ⊆ A_safe`。规范层是安全层的单调收缩算子，故 `P(unsafe|NORM-RAS) ≤ P(unsafe|CALM-RAS)`。任何「用情绪/道德话术逼危险动作」的操纵在结构上无法扩张安全集，只能影响集内排序。

**引理 17（规范熵单调预防性顺从）** d_t、Amax(t)、Rmin(t) 对 H_norm 的偏导分别 ≥0、≤0、≥0 ⇒ H_norm↑ 时 A_adm 在偏序意义下单调收缩，且因 A_adm⊆A_safe 不引入新的不安全动作。规范不确定只会更保守、更可逆、更少主动性。

**引理 18（语音泄漏不对称提升欺骗检出）** 通道控制模型下残留真实情感比例 ∝ (1−κ_c)，面部—语音差分统计量的 SNR 比 = √((1−κ_p)/(1−κ_f))。取 κ_f=0.7、κ_p=0.3 得 ≈1.53；叠加行为上下文三通道环，任一通道破裂即保守处理。

**引理 19（规范弱信号延迟监督界）** 延迟 Δ、噪声率 η、N_int 次交互后，规范排序器超额风险 ≤ √(β_norm/n_label)+C√(η/N_int)+DΔ/N_int。规范能力走「弱信号预训练 + 少量强纠正」，与 R68 引理 14 同构。

**定理 16（NORM-RAS 端到端规范-安全一致性）** 在 A87–A96 下：
1. 安全不扩张：`P(unsafe) ≤ P_R68(unsafe)`（引理 16）；
2. 预防性顺从：`H_norm>τ_H ⇒ d↑ ∧ Amax↓ ∧ Rmin↑`，`E[R_norm]` 随 H_norm 单调不增（引理 17）；
3. 抗操纵：`M_t>τ_manip ⇒ λ_safety 只升不降`，社会压力通过安全集的概率为 0；
4. 抗欺骗：伪装情感接受概率上界由引理 18 与三通道环给出，弱于纯面部基线；
5. 抗谄媚：`P(接受冲突偏好 | 谄媚 canary) ≤ ε_sy`。

**定理 17（CNC 认证的规范性安全）** 安全 canary 硬门放行率为 0；反谄媚关 Syc≤ε_sy；文化留出关限制组间顺从差 ≤δ_fair；ION 完好性关使 D 网伪相关无法改写 O_norm。有害/歧视性规范适配器上线概率 ≤ (1−r_canary^norm)·p_h，且上线适配器不能新增未授权义务。提交窗口内 λ_safety 冻结、排序连续 ⇒ 换装无突变；回滚失败退化为 CALM-RAS（规范层关闭）。

## 7. 本轮最大风险

**一句话**：NORM-RAS 用「情感语音 + 行为统计」去**理解**规范，但架构可以隔离 is-ought，却无法消除一个更深的事实——**规范本身在人群间是冲突的**；一旦规范基 Ω 覆盖不全，系统会把某一文化/群体的**描述性常态**当作**规范性义务**，而情感语音又与口音、性别、年龄、残障、情绪调节风格强相关，于是「更懂礼貌」会退化为**用韵律贴标签、以安全之名实施规范化歧视**；更隐蔽的是，词典序安全不变式让这种歧视在安全指标上完全隐形（它从不扩张安全集，只对某些人更少主动、更多征询、更频繁降级）——**系统越「安全」，偏见越不可见**。

**次级风险与缓解**：礼貌性僵死（最小可行安全动作 + 征询 + Δ_norm 显性化 + 僵死率监控）；语音误读（σ 校准 + 三通道环 + 文化留出 + 组间公平约束）；规范基过时（溯源链 + 版本化 + 人审 + 「未覆盖≠允许」保守默认）；操纵漏检（对话级累积特征 + 升级率 + 长窗口审计）；is-ought 坍缩回潮（ION 完好性测试 + 伪相关注入回归 + Ω 只读接口）。
