# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「事件相机」×「原型验证」）

> R69 把不确定性从标量拆成「有形状的对象」（多模态动作 + 权重 + 可分性），并让系统第一次学会「问」。但它有两个从未被审视的前提：**（a）「什么时候该算、该问」由固定帧时钟决定；（b）「这些结论在真实硬件上是否成立」由仿真实验担保。** 前者把连续的物理时间拍扁成离散帧，于是「我何时会知道」这个最有价值的问题被丢掉了；后者让整条 R66→R69 的证明链悬在 sim-to-real 的空中。
>
> 本轮两个灵感正好各补一刀：
> - **事件相机**不产生帧，而是逐像素、微秒级地报告「变化」。它把「证据何时到达」变成可观测量，也给 CIA 提供了一个物理上真正正交的证据源（对数亮度导数、高动态范围、无运动模糊、微秒时间戳）。
> - **原型验证**把「理论承诺」变成「分级证伪的工程门」：廉价代理先预筛、硬件在环再确认、闭环样机再晋级；每一级只为它能回答的声明负责，并显式度量现实差距。
>
> 核心命题：**不确定性的完整描述不止「形状」，还有「时间戳」与「硬件化身」。R70 把 R69 的静态 VoI 升级为事件驱动的 time-to-resolve（我何时会知道），把 R69 的「事后审问」升级为「先廉价原型预验证、再真实交互」；只有在无事件、无原型证据或现实差距越界时，才退回 R69。** 命名 **PROVE-RAS**（Prototype-validated, Event-triggered uncertainty Resolution and Verification for Adaptive Safety）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我什么时候会知道，而且这个答案在真实原型上还站得住吗**」——不确定性不只有形状，还有时钟和肉身。

## 0. 直觉与动机

**灵感 1（事件相机 → 不确定性有时间戳）**
直觉：R69 的 VoI 是一个「期望熵减」，它默认信息一到位就立即被用上。但真实系统里，证据是**随时间逐点到达**的：两个动作模态可能在第 3ms 就因为一条遮挡边缘的移动而分开，也可能要等到第 80ms 目标转过脸。事件相机逐像素上报带微秒时间戳的极性变化，等于直接吐出「证据到达曲线」。于是可以定义一个新量 **TTR（time-to-resolve）**：在当前信念下，还需多少毫秒、看到多少事件，两个模态才变得可分。这把 R69 的问句「值不值得问」补全为「**值不值得等、等到什么时候**」。

**灵感 2（事件相机 → 一个物理上真正正交的证据源）**
直觉：R69 的证据纪律要求「k 个正交证据源一致」，可它的证据全都来自帧式传感器——同一套光学、同一个曝光、同一类运动模糊。它们会在强光、逆光、高速运动下**一起坏掉**，所谓「正交」只是统计上的，不是物理上的。事件相机测的是对数亮度的**时间导数**：高动态范围（>120dB）、无运动模糊、微秒延迟、低冗余。它与帧通道的失效模式几乎不重叠。这正是 CIA 一直缺的那第 k 个源——不是「再问一遍」，而是「换一种物理去测」。

**灵感 3（事件触发 → 把「该算了」从超参数变成物理信号）**
直觉：R69 用 mode_head 廉价预测歧义来决定升 K，这仍是「每个控制周期都问一次模型」。事件相机的输出本身稀疏、由场景变化驱动：没有变化就没有事件，没有事件就不必重算。于是「何时计算、何时升 K、何时发起交互」可以由**可触发事件（admissible event）**驱动，而不是由固定帧率驱动。这把实时预算从「每周期都要付」变成「只在信息真的到来时付」，也让 R69 的 3.4ms 歧义路径第一次有了物理依据。

**灵感 4（原型验证 → 现实差距是新的一类不确定性）**
直觉：R66–R69 的所有定理都写在「模型即世界」的假设里。但机器人研究里最贵、最痛、最常被跳过的一步是：**这东西在样机上真的成立吗？** 原型验证给出一个可操作的答案——分级阶梯（仿真 → 硬件在环 → 台架样机 → 闭环机器人 → 长时现场），每一级只回答它能回答的问题，并用显式统计检验去**证伪**具体声明。更关键的是，它引入了一个 R69 没有的量：**现实差距 RG**。当代理模型与真实统计量偏离过大时，策略的模态分布、甚至 FMA 的动作似然都会系统性偏移——这本身就是一种必须被度量、被膨胀、被退回保守的不确定性。

**灵感 5（原型验证 → 用「廉价原型」给交互动作做预验证）**
直觉：R69 最大的风险是「追问一个幻影模态」。人类不会这么干：在真的开口问之前，会先在脑子里低成本地「演一遍」——如果我问这句，对方会怎么答？答了之后我还分得清吗？这在工程上就是**代理原型预验证（surrogate pre-validation）**：在真正消耗交互预算之前，把候选信息动作 g 放进一个廉价的低保真代理（事件回放缓冲 / 低精度仿真 / 缓存世界模型）里跑一遍，看这个模态是否**持续存在**（不是幻觉）、看 VoI 是否仍然为正。幻影模态在最廉价的代理里就会消失，于是根本轮不到它去污染真实交互。**把 R69 的「事后审计」前移成「事前预验证」**——这是本轮对 R69 头号风险的正面回应。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（PROVE-RAS 总览）** PROVE-RAS = (ESU, TTR, EES, SPV, PVL, RG, RAS-WM††)。继承 R68/R69 的实时零学习写与交互预算，并新增四条不变式：
(i) **事件因果性**：任何触发、计算、交互只能使用时间戳 ≤ t 的事件（无未来泄漏）；
(ii) **事件可触发门**：只在可触发事件集 𝒯 上更新决策，其余时刻复用上一份已认证轨迹；
(iii) **原型门**：任何进入部署的声明必须达到所需 PVL 等级，否则标记 provisional 并强制 R68 保守兜底；
(iv) **严格包含**：帧化 + 代理=真实 + PVL 旁路时，逐指令退化为 R69（定理 19）。

**定义 311（事件观测）** 事件流 E = {(t_i, e_i, p_i)}_i，t_i 单调递增、微秒分辨率，e_i ∈ Ω 为像素，p_i ∈ {−1,+1} 为极性。窗口 W 内聚合为体素网格或时间曲面 o_t^ev = Agg(E ∩ W_t)。事件密度 ρ_E(t) = |E ∩ [t−δ,t]| / (|Ω|·δ)；时间对比度由局部时间曲面的斜率给出。

**定义 312（可触发事件与因果调度）** 惊奇度 S(t) = −log p_ψ(ΔE_t | ℋ_{<t})。触发集 𝒯 = {t : S(t) ≥ τ_trig ∧ 去抖(t) ∧ 因果(t)}。控制与推理只在 𝒯 ∪ 安全节拍上更新；安全节拍（截止 D）保证即使长期无事件也有心跳。触发延迟 + 推理 ≤ D（定义 322）。

**定义 313（证据时延 TTR）** 对模态对 (m_i, m_j) 与信息动作 g，TTR_{ij}(g) = inf{ t ≥ 0 : I(m_i; m_j | E_{≤t}, g) ≥ 1−ε }；其期望 Ê[TTR] 由事件到达模型（定义 314）给出。若在预算窗内不可达则记为 ∞。

**定义 314（事件到达模型与静默语义）** 对每个判别特征 φ_{ij}，建模其可观测变化率 λ_{ij}(g, o)。若无预期变化（λ→0），则**静默不提供任何关于 (m_i,m_j) 的信息**：p(∅ | m_i) = p(∅ | m_j) = e^{−λT}。这条定义专门阻断「把没事件误读成没歧义」。

**定义 315（事件驱动 VoI）** eVoI(g) = [H(M|o) − E_{E_{≤TTR}} H(M|o, E_{≤TTR})] / (c_int(g) + c_time·Ê[TTR](g) + c_E·Ê[|E|])，单位是「每焦耳·毫秒的信息」。选择 g* = argmax eVoI，s.t. 安全与预算（定义 323）。当 c_time = c_E = 0 且 TTR 量化为单帧时，退化为 R69 的 VoI − c。

**定义 316（事件证据源 EES）** r_ev ∈ ℰ 为新增证据通道：由事件的时间对比度、极性一致性与 TTR 残差构造。其噪声（热像素、散粒、读出噪声）与帧通道近似独立；HDR 与无运动模糊使其在帧通道饱和/拖影时仍可用。CIA 的候选对扩展为 (r_ev, r_x)。

**定义 317（A/E 的事件侧分离）** 事件噪声零模型的极性对称、时间白、空间稀疏；定义事件相干度 C_E = 邻域极性场的时空相关 / 白噪零分布分位。U_ale^ev 由噪声底估计；U_epi^ev ∝ C_E·(1 − I(M; E_{≤t}))。事件侧 (U_ale^ev, U_epi^ev) 与 R69 流侧 (U_ale, U_epi) 独立；二者一致性是新的交叉检验，不一致即触发保守。

**定义 318（代理原型 SPV）** 代理 π̂_ℓ 为保真度 ℓ 的可执行代理（事件回放 / 低精度仿真 / 缓存世界模型），输入 (g, o)，输出 (V̂oI, persist, Ĉ)。预验证通过 ⇔ persist ≥ τ_persist ∧ V̂oI > c(g)。SPV 在线程外异步执行，不占控制关键路径。

**定义 319（幻影模态判据）** 模态 m_k 为幻影 ⇔ 在代理扰动集（事件丢包 / 极性翻转 / 时间抖动 / 回放截断）下 persist < τ_ph，或其支持事件低于噪声底、或仅由热像素簇构成。幻影模态不得进入交互（把 R69 E300 的拦截前移）。

**定义 320（原型验证阶梯 PVL）** 等级 L0 仿真 → L1 硬件在环（真事件相机 + 仿真被控对象）→ L2 台架样机 → L3 闭环机器人 → L4 长时现场。每级有保真度 f_ℓ、成本与**证伪测试套件**。声明 C 的验证等级 ℓ(C) 必须 ≥ 部署所需等级；不足即 provisional，只能驱动 R68 保守。

**定义 321（现实差距 RG 与膨胀）** RG_ℓ = D(P̂_ℓ(统计量), P_real(统计量))，统计量取 (U_ale, U_epi, Δa, TTR, r_res) 的联合，D 用 Wasserstein / 风险校准差。RG_ℓ > τ_rg ⇒ 按 RG 膨胀 U 并收紧 λ（不信任代理给出的 resolution bonus），极端时退 R68。

**定义 322（事件触发安全截止）** 触发到执行的端到端时延 ≤ D；若某次触发会越界，则丢弃该次更新，沿用上一份经 C-RAS-WM 认证的轨迹（R68 定理 15 换装不变式保持）。事件触发不得改变安全包络。

**定义 323（能量-事件预算）** B(t) 为漏桶：信息动作消耗 c_int、事件计算消耗 c_E|E|、等待消耗 c_time·TTR；容量 B_max、回充率 β。R69 的「单位时间 ≤1 次」是本预算在 c_time = 0、仅计 c_int 时的特例。

**定义 324（AIC-PROVE 干扰集）** ℰ_PROVE = ℰ_FLUID × ℰ_event × ℰ_gap，其中 ℰ_event = {热像素注入, 时间戳伪造, 事件流对抗贴片, 反折射/致盲, 重放攻击}，ℰ_gap = {sim-to-real 分布漂移, 代理过拟合, 原型过窄}。

**定义 325（证书 J_PROVE）** J_PROVE = (J_FLUID, trigger_causal, ttr_p95, evoi_ratio, rg_p95, pvl_level, phantom_veto_precision, event_noise_floor, prove_ver)。Valid ⇔ Valid(J_FLUID) ∧ 因果 ∧ RG ≤ τ_rg ∧ PVL 等级足够 ∧ 无幻影被采纳。

## 2. 关键算法骨架

```python
# IP-264 ESU：事件前端（去噪 + 时间曲面 + 惊奇度触发）
class EventSensingUnit:
    def __init__(self, net, tau_trig, D):
        self.net, self.tau_trig, self.D = net, tau_trig, D
        self.ring, self.noise_floor = EventRingBuffer(), None

    def push(self, events, t):
        causal = [e for e in events if e.t <= t]          # 定义 310-i：因果过滤
        self.ring.extend(causal)
        self.noise_floor = estimate_hot_pixel_floor(self.ring)

    def trigger(self, t):
        return self.surprise(t) >= self.tau_trig and self.debounced(t)

# IP-265 TTR：证据到达时间估计（解析 + 回放双路）
def time_to_resolve(modes, g, event_model):
    return min(analytic_hitting_time(event_model.change_rate(i, j, g), EPS)
               for (i, j) in pairs(modes))              # 定义 313–314

# IP-266 eVoI：每焦耳·毫秒的信息
def event_voi(modes, g, ttr, budget):
    gain = entropy(modes.w) - expected_entropy_after_events(modes, g, ttr)
    cost = budget.c_int(g) + budget.c_time * ttr + budget.c_E * expected_events(g, ttr)
    return gain / max(cost, EPS)                         # 定义 315

# IP-267 SPV：代理原型预验证（异步，关键路径外）
def surrogate_prevalidate(g, o, surrogate, perturb_set):
    voi, persist = surrogate.rollout(g, o)
    for pert in perturb_set:                             # 丢包/抖/截断/翻转
        persist = min(persist, surrogate.persistence(g, o, pert))
    return voi, persist, (persist < TAU_PH)              # 定义 318–319

# IP-273 主闭环：事件触发 + 预验证 + 原型门（继承 R68/R69）
def PROVE_RAS_round(M, obs, t):
    if not M.esu.trigger(t):                             # 定义 312：不触发则沿用
        return M.last_certified
    z, o, o_ev = M.mtm.forward(obs), M.esu.aggregate(t)
    c, U_cal, thr = M.cof.step(...)                      # R68 标定
    # 1) 流侧与事件侧独立分解；不一致即保守
    samples = M.fmp.sample(o, K=M.k_for(z, o_ev))
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z)
    U_ale_ev, U_epi_ev = M.aud.event_decompose(o_ev)     # 定义 317
    disagree = cross_check(U_epi, U_epi_ev) > TAU_X
    # 2) 候选交互：eVoI 排序 → 代理预验证 → 幻影否决
    cands = rank_by_event_voi(modes, M.esu, M.budget)    # 定义 315
    g = next((h for h in cands
              if not M.spv.prevalidate(h, o_ev, M.surrogate).phantom  # 定义 318-319
              and M.c_ras_wm.certify_info(h, o)), None)
    # 3) 现实差距门：代理不可信就不给 resolution bonus
    rg = M.rg.estimate(M.pvl.current_level)
    trust = (rg <= TAU_RG) and (M.pvl.level >= M.pvl.required())
    # 4) 风险缩放：与 R69 一致，bonus 受 trust 门控
    if g is not None and trust and not disagree:
        ans = M.cia.execute(g)
        U_epi = M.cia.update_belief(modes, ans)
        U_floor = U_ale
    else:
        U_floor = U_ale + U_epi
        if not trust:
            U_floor *= (1.0 + kappa_rg * rg)             # 定义 321 膨胀
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(...)
    M.vqa_p.submit_async(g, U_ale, U_epi, ttr, rg, trust)  # 定义 325
    return cache_and_return(k, lam, select_mode(modes, U_epi, lam), t)
```

## 3. 推导

**引理 19（TTR 的信息下界）** 设判别特征 φ 的可观测变化率为 λ，事件到达近似泊松，则达到置信 1−ε 的期望时间 Ê[TTR] ≥ ((1−ε)/λ)·ln(1/ε)。系：eVoI 随 λ 单调增、随 c_time 单调减——只有当「证据来得足够快」时，等待才优于直接保守。这给 R69 的 VoI 补上了缺失的时间维度。

**引理 20（事件侧与帧侧的失效互补）** 在 A99（事件噪声与帧噪声条件独立、事件通道在帧饱和区仍保信息）下，联合证据的互信息满足 I(M; r_ev, r_frame) ≥ max(I(M;r_ev), I(M;r_frame)) + δ_c，且 δ_c > 0 当且仅当存在帧通道退化的状态。系：**k-正交一致纪律在事件源加入后严格变强**，且强在「帧一起坏」的场景——正是 R69 的盲区。

**引理 21（幻影模态的预验证拦截率）** 设幻影模态在代理扰动下的持续度分布为 F_ph、真模态为 F_true；若二者在 τ_ph 处可分（A100），则 SPV 单次拦截率 ≥ 1 − F_ph(τ_ph)，真模态误杀率 ≤ F_true(τ_ph)。系：R69 的「追问幻影」从**事后审计**降为**事前否决**，把 E300 的 ≤5% 提前到交互预算消耗之前。

**引理 22（静默的信息守恒）** 在定义 314 的事件模型下，若 λ_{ij} = 0，则任意时长静默对 (m_i,m_j) 的后验不做改变：I(m_i; ∅ | m_j) = 0。系：**「没有事件」只能作为「没有变化」的证据，不能作为「没有歧义」的证据**；系统在静默时必须保持 U_epi，或主动激发变化（探针/注视），不得把静默当作消解。

**定理 18（事件触发的实时性与无突变）** 若端到端触发延迟 ≤ D（定义 322），则事件驱动调度与固定帧调度在安全节拍上生成相同或更晚的认证轨迹，且任何被丢弃的触发不改变已认证前缀；换装不变式保持 ⇒ 控制连续、无突变，安全侧不弱于 R69。

**定理 19（PROVE 严格包含 R69）** 当 (a) 事件流以步长 Δ 积分为帧观测、(b) 𝒯 取每个帧边界、(c) TTR 量化为 Δ 且 c_time = c_E = 0、(d) 代理保真度 ℓ = ∞ 且 RG = 0、(e) PVL 门旁路时，PROVE-RAS 的每一步（分解、VoI、交互、λ、认证、审计）与 R69 逐指令相同。因此 R69 是 PROVE 在「帧化 + 无现实差距」边界上的退化；安全侧不让步，效率侧获得时间维度与预验证。

**定理 20（原型门的安全性）** 若某声明未达所需 PVL 等级或 RG > τ_rg，则 PROVE 强制 λ ≥ λ_floor(U_ale + U_epi)（不给 resolution bonus）并沿用 R69 兜底；故未验证的代理永远不能使系统比 R69 更激进。

## 6. 本轮最大风险

1. **静默被误读为消解** → 定义 314 静默语义 + 引理 22 + 主动激发（探针/注视）+ E309；

class EventSensingUnit:
    def push(self, events, t):

        self.noise_floor = estimate_hot_pixel_floor(self.ring)
    def trigger(self, t):

# IP-265 TTR：我何时会知道
def time_to_resolve(modes, g, event_model):
    return min(analytic_hitting_time(event_model.change_rate(i, j, g), EPS)
               for (i, j) in pairs(modes))                    # 定义 313–314

# IP-266 eVoI：每焦耳·毫秒的信息
def event_voi(modes, g, ttr, budget):
    gain = entropy(modes.w) - expected_entropy_after_events(modes, g, ttr)
    cost = budget.c_int(g) + budget.c_time*ttr + budget.c_E*expected_events(g, ttr)
    return gain / max(cost, EPS)                              # 定义 315

# IP-269 SPV：代理原型预验证（异步，关键路径外）
def surrogate_prevalidate(g, o, surrogate, perturb_set):
    voi, persist = surrogate.rollout(g, o)
    for pert in perturb_set:                                  # 丢包/抖动/截断/翻转
        persist = min(persist, surrogate.persistence(g, o, pert))
    return voi, persist, (persist < TAU_PH)                   # 定义 318–319

# IP-274 主闭环（继承 R68/R69，仅在触发与交互前插两道门）
def PROVE_RAS_round(M, obs, t):

        return M.last_certified
    z, o, o_ev = M.mtm.forward(obs), M.esu.aggregate(t)
    c, U_cal, thr = M.cof.step(...)

## 4. 推导

**引理 19（TTR 信息下界）** 泊松事件到达下，达到置信 1−ε 的期望时间 `Ê[TTR] ≥ ((1−ε)/λ)·ln(1/ε)`。系：eVoI 随 λ 增、随 c_time 减——只有证据来得够快，等待才优于直接保守；这给 R69 的 VoI 补上时间维度。

**引理 20（失效互补）** A99 下 `I(M;r_ev,r_frame) ≥ max(I(M;r_ev),I(M;r_frame)) + δ_c`，`δ_c>0` 当且仅当帧通道退化。系：k-正交纪律在事件源加入后严格变强，强在「帧一起坏」的场景。

**引理 21（幻影拦截）** 幻影持续度 `F_ph`、真模态 `F_true` 在 τ_ph 可分（A100）时，SPV 拦截率 `≥1−F_ph(τ_ph)`、误杀率 `≤F_true(τ_ph)`。系：把 R69 E300 的 ≤5% 从「事后」前移到「预算消耗之前」。

**引理 22（静默守恒）** λ_{ij}=0 时 `I(m_i;∅|m_j)=0`。系：「没有事件」只能证明「没有变化」，不能证明「没有歧义」；静默时必须保持 U_epi 或主动激发变化。

**定理 18（触发实时性与无突变）** 端到端延迟 ≤ D 时，事件驱动与固定帧在安全节拍上给出相同或更晚的认证轨迹；丢弃越界触发不改变已认证前缀；换装不变式保持 ⇒ 控制连续、无突变。

**定理 19（严格包含 R69）** 帧化 (Δ)、𝒯=每帧边界、TTR 量化且 c_time=c_E=0、代理 ℓ=∞ 且 RG=0、PVL 旁路时，PROVE 每步与 R69 逐指令相同。R69 = 「帧化 + 无现实差距」边界；安全不让步，效率获时间维度与预验证。

**定理 20（原型门安全性）** 声明未达 PVL 等级或 RG>τ_rg 时，PROVE 强制 `λ ≥ λ_floor(U_ale+U_epi)`（无 bonus）并走 R69 兜底；未验证的代理永不能使系统比 R69 更激进。

## 7. 本轮最大风险

**一句话**：事件相机只报告「变化」——**当世界（以及歧义本身）静止时它保持沉默，系统会把「没有事件」误读成「没有歧义」，TTR 变成 ∞；而「原型验证」又可能退化为验证剧场：在一台与仿真共享盲区的窄样机上全绿通过，把仿真里的错误盖上「已上真机」的章**——**用沉默当证据、用样板当现实，比不知道更危险。**

**次级风险与缓解**：静默被误读为消解（定义 314 + 引理 22 + 主动激发 + E309）；事件侧与帧侧「一致地错」（定义 317 交叉检验 + 不一致即保守 + E304）；代理过拟合使预验证虚高（PVL 分级 + RG 膨胀 + 代理扰动集 + 引理 21）；事件流攻击（ℰ_event 对抗训练 + 时间戳单调性校验 + E310）；触发抖动击穿预算（去抖 + 心跳节拍 + 丢弃越界触发 + 定理 18）。
