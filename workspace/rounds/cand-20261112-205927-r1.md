# 第 1 轮（灵感循环 v2：「专利布局」×「联邦学习」）—— 从「单点旗舰」转向「联邦式个性化 + 组合式布局」

> **本轮不是再换赛道，而是在 v1（UIP-01~10）上做两件事：加固旗舰、给整个方案上「组合保险」。** 两个灵感词当作**变异算子**使用：
> 1. **联邦学习**——为「32 个高度异构任务 + N 台真机 N 端口的服务拓扑」提供一套现成的**异构治理 / 个性化 / 掉队者调度 / 稳健聚合**工具；它的真价值不在「隐私」，而在**广播的模型结构恰好同构于本赛事的 server–client 评测拓扑**。
> 2. **专利布局**——为研究本身提供**设计空间覆盖 + 先验检索(FTO) + 核心/从属权利要求树 + 风险对冲**的元方法，专门纠正 v1「把一切押在 UIP-01 单点上」的脆弱性。

## 1. 对 v1 清单的诊断

- **保留但改承重墙**：UIP-01（进度验证滚动时域）仍是最高杠杆，但它缺一个「训练侧为何能同时服务 32 个异构任务」的解释——**FedProx 个性化**正好补上这块地基。
- **升级**：UIP-03（MoE-Router）是**临时凑合**的路由；改为 **FedPer 式共享骨干 + 每任务 LoRA 本地适配器**，把「路由」变成「个性化」，从推理期硬切换改为训练期解耦，跨任务污染风险显著下降。
- **重获新解**：UIP-08（延迟工程）从「压测调参」升级为**掉队者感知的有界异步 + 稳健聚合**，直接对齐 §6 可信度口径。
- **作废**：UIP-10（双控制空间仲裁）单次提交不可行（事实 A）。
- **保留为组合成员**：UIP-04（世界模型预演）、UIP-05（语言→可供性）、UIP-06（泛化轴数据配方）、UIP-07（回放 harness）、UIP-09（人为干扰恢复）——作为「从属权利要求」级别的**替代资产**，而非核心。

## 2. 两个灵感词的严谨解读

### 2.1 联邦学习：从「比喻」到「同构」

- **直觉**：多客户端、数据不出本地、共享一个模型；难点是 non-IID、个性化、掉队者、通信。
- **严格的训练侧定义（离线「拟联邦」）**：客户端集合 K={1..32} 对应 32 个任务数据集，样本量 n_k；共享骨干参数 w，本地个性化参数 φ_k（LoRA）。第 t 轮：
  - 本地目标：`F_k(w, φ_k) + (μ/2)·||w − w^t||²`（FedProx 近端项，抑制客户端漂移）；
  - 仅聚合骨干：`w^{t+1} = Σ_k (n_k/n)·w_k`，**φ_k 永不上传**（FedPer 式个性化）。
  - 近端项等价于 EWC 的连续学习正则，因此它天然抑制「顺序微调 32 任务」的灾难性遗忘——这才是它在**算力有限、必须串行训任务**场景下的真实卖点。
- **严格的服务侧定义（在线联邦拓扑）**：端口 i 持有私有状态 s_i（满足事实 C 的强制隔离），共享后端 B；每端口一个请求队列，调度为**有界异步**（限制在飞请求数与等待上限，避免一个慢机器人阻塞其余）。任何需要跨端口共享的在线统计（若启用）一律用 `median / trimmed-mean` 做稳健聚合，禁止裸均值。
  - 注：straggler 在**训练期**用有界异步/陈旧度加权处理；在**纯推理服务期**主要体现为排队与并发隔离——两者要分开讲，避免概念混用。

### 2.2 专利布局：从「好点子」到「组合资产」

- **直觉**：不是押一个发明，而是围绕核心圈一圈从属权利要求，先查先验，再留对冲。
- **严格定义**：
  - 权利要求图 `G=(C,E)`：一个**独立权利要求**（核心机制的整体组合）+ 若干**从属权利要求**（可替换/可加强的子机制）。
  - 覆盖矩阵 `A ∈ {0,1}^{资产 × 设计轴选项}`，设计轴 = {个性化方式, 聚合方式, 验证信号, 控制空间, 时延调度, 数据配方}；**白空间** = 全 0 的列（无人覆盖、可能是空档也可能是陷阱）。
  - **组合风险** = 对每个资产 a，若 a 失效，是否存在替代资产 a′ 能顶上（fallback 覆盖率）。
- **元方法输出**：① 先验/自由实施(FTO)检索表；② 独立+从属权利要求树；③ 设计空间覆盖矩阵；④ 资产失效→替代资产的风险对冲表。

## 3. 瓶颈假设（本轮更新）

- **H1（异构遗忘）**：32 任务差异极大且算力受限，必须串行训练 → 顺序微调会灾难性遗忘；FedProx 近端 + 每任务 LoRA 是**低成本、可验证**的对症药。
- **H2（掉队者/可信度）**：若共享后端用朴素同步，N 台真机里最慢者决定整体节奏 → 延迟方差升高，撞 §6 可信度；有界异步 + 端口隔离可直接解耦。
- **H3（单点脆弱）**：v1 全押 UIP-01，一旦验证器误判或延迟超标就全线失守；需**组合保险**（进度验证失败 → 退回步骤分安全网 → 再退回纯策略保底）。
- **H4（控制空间是战略变量）**：既然 joint/ee 互斥，选哪个本身是「组合决策」——ee 抗位置泛化但可能 IK 抖动，joint 平滑但绝对精度受标定影响；应以回放代理对每任务分组决策。

## 4. 候选创新点（收敛）

发散出 11 个草案，按「设计空间覆盖」收敛为 8 个（FPL-01~08，见产物区）。**旗舰 FPL-01 = FedPer-VLA**：
`联邦近端个性化训练（32 任务）` + `进度验证滚动时域（RHPV）` + `掉队者感知的联邦式 N 端口服务`。

它是唯一同时踩中：联邦（异构个性化）、迭代验证（滚动重试）、排行榜（成功率+步骤分+可信度）、且**完全在选手 API/服务进程权限内**的组合。其余点作为从属权利要求/替代资产，构成「核心 + 保险」。

## 5. 本轮最大风险

**一句话**：把「联邦」当成纯叙事包装是最大陷阱——32 个数据集并不存在真实的数据持有方与隐私约束，若 `FedProx + 每任务 LoRA` 相对「标准多任务/顺序微调」没有可复现的**抗遗忘增益**，整个旗舰就退化为改名换姓的 MoE，投入即沉没；因此必须先以回放代理跑「FedProx vs 顺序微调」的遗忘曲线消融，确认增益后再把资源押上去。

## 1. 旗舰深潜 · FPL-01（FedPer-VLA）

### 1.1 机制
- **训练期（拟联邦）**：32 任务 = 32 个客户端；共享骨干 `w`（视觉-语言-动作主干），每任务本地适配器 `φ_k`（LoRA）。每轮抽样客户端子集，本地最小化
  `F_k(w, φ_k) + (μ/2)·||w − w^t||²`，**只上传 w 的增量**，服务器做 `w^{t+1}=Σ_k (n_k/n) w_k`；`φ_k` 永不上传（FedPer 式个性化）。近端项 = EWC 式抗遗忘正则，缓解串行训练 32 任务的灾难性遗忘。
- **推理期（进度验证）**：沿用 v1 的 RHPV——输出动作块，执行 `k<T_a` 步后由**常识进度验证器** `V(o_t, l, g)` 判定子目标 done/fail/ongoing，据此继续/重规划/重试/提前结束；适配器由 `observation.language` + 轻量门控选择。
- **服务期（联邦拓扑）**：N 端口 = N 客户端，每端口私有 state `s_i`（强制隔离，事实 C），共享后端 `B`；有界异步调度 + 每端口队列，防掉队者拖垮延迟（事实 D）。

### 1.2 与现有方案差异
- 相对 pi0 / ACT 式开环 chunk：把验证器作为 chunk 间**一等公民**。
- 相对 v1 UIP-03 硬路由：把「路由」换成「共享干 + 个性化适配器」，跨任务污染从**推理期不可控**降为**训练期可正则**。
- 相对朴素多端口：把 §6 的延迟方差当作**一级目标**而非副作用。

### 1.3 可行性 / 资源
- 可行性：高。难点在「抗遗忘增益是否真实」，可用回放代理先验证（见 E101）。
- 资源：单卡可做 LoRA 个性化 + 小 VLM 验证器；数据用公开 32 数据集；接口零额外要求。

### 1.4 落地步骤
1. 冻结骨干，做 32 个 LoRA 适配器的 FedProx 训练（先 8 任务小规模验证增益）；
2. 每任务写 3–6 个可观测子目标 + 判据，训练/规则化小 VLM 进度分类器；
3. 策略 loop 接入 `k` 步验证与切换（三重护栏：`k`、`conf_thr`、`max_retry` + 延迟预算）；
4. `example_env.py` 桩 + 数据集回放联调；5. 多端口并发压测 → 提测。

### 1.5 风险
验证器误判/延迟 → 置信度门限 + 异步降频；联邦增益不成立 → 用 E101 消融**先证伪再投入**。

## 2. 训练侧：FedProx + 每任务 LoRA（FPL-02）

目标（客户端 k，第 t 轮）：

```
min_{w, φ_k}  F_k(w, φ_k) + (μ/2)·||w − w^t||²
aggregate:    w^{t+1} = Σ_k (n_k / n) · w_k        (φ_k 不上传)
```

- `μ` 控制「对全局骨干的黏性」：`μ→0` 退化为纯本地微调（遗忘重）；`μ→∞` 退化为全体共享（个性化弱）。建议对 μ 做小网格。
- 与 EWC 关系：近端项是「参数级」而非「Fisher 加权级」的廉价近似；在算力受限时优先 FedProx，EWC 作对照。
- 与 FedAvg 关系：FedAvg 是 `μ=0 且 φ=∅` 的特例，作为**下界对照**。

## 3. 服务侧：有界异步 + 端口隔离（FPL-03）

```python
class FedServingBackend:
    def __init__(self, model, n_ports, max_inflight=4, wait_cap_ms=150):
        self.model = model
        self.q = {p: deque() for p in range(n_ports)}   # 每端口独立队列
        self.inflight = 0
        self.max_inflight, self.wait_cap = max_inflight, wait_cap_ms

    def submit(self, port, obs):
        self.q[port].append(obs)                        # 端口状态天然隔离

    def step(self, deadline_ms):
        # 有界异步：只取「已就绪」端口，快端口不等慢端口（防 straggler）
        ready = [p for p in self.q if self.q[p] and self.inflight < self.max_inflight]
        for p in ready:
            obs = self.q[p].popleft()                   # 不跨端口共享 state
            self._dispatch_async(p, obs)                # 回包写回 q[p] 的应答槽
        # 等待上限：超过 wait_cap 未回则记录 stale 事件（不阻塞其余端口）
```

- **合规点**：每端口 `reset()`/历史状态独立（事实 C）；并发不互相阻塞（事实 C）。
- **可信度点**：`wait_cap` 防止个别慢请求无限拉长尾延迟；对 stale 事件计数上报，避免「异常交互模式」（事实 D）。

## 4. 服务期稳健聚合（FPL-04，条件启用）

仅当启用 **FPL-07 在线 F-TTA** 时才需要跨端口聚合共享统计/校正量。此时**禁止裸均值**：

```
g_robust = trimmed_mean({g_i}, trim=0.2)     或   median({g_i})
```

动机：N 个端口中若某台机器人/端口退化（漂移、遮挡、标定异常），均值会被单点污染，稳健聚合可隔离之。**若 FPL-07 封存，则 FPL-04 一并封存**——不引入无收益的复杂度。

## 5. 先验 / 自由实施(FTO)检索表（FPL-05）

> 目的：确认「新颖性来自组合，而非任一单件」。以下为公开方法的代表性出处（作者-年份级，未逐篇核对正文，标注为**待精读**）。

| 设计轴 | 已知方法（先验） | 与我们的关系 | 结论 |
|---|---|---|---|
| 动作分块 | ACT (Zhao et al. 2023)、π0 (Black et al. 2024)、OpenVLA (Kim et al. 2024)、RDT-1B (Liu et al. 2024) | 单块开环执行 | 我们改「块间验证」——组合新颖 |
| 滚动时域/重规划 | MPC 经典；receding-horizon 模仿 | 无 VLM 语义子目标核验 | 语义验证器是差异点 |
| 进度/成功核验 | VIP (Ma 2023)、LIV (Ma 2022)、RoboCLIP (Sontakke 2023) | 多为奖励/表征学习 | 我们用作**chunk 间切换判据** |
| 联邦训练 | FedAvg (McMahan 2017)、FedProx (Li 2020)、FedPer (Arivazhagan 2019)、Per-FedAvg (Fallah 2020) | 通用 FL 算法 | 我们用其**抗遗忘 + 个性化**性质 |
| 参数高效个性化 | LoRA (Hu 2021) | 通用 PEFT | 与 FedPer 组合，非新 |
| 抗遗忘 | EWC (Kirkpatrick 2017) | 连续学习正则 | 近端项是其廉价近似（对照） |
| 测试时自适应 | TENT (Wang 2021)、CoTTA (Wang 2022) | 单客户端自适应 | 在线联邦 TTA 为差异点（高风险） |
| 机器人 FL | 已有「federated robot learning」工作 | 多聚焦隐私/协作采集 | 我们聚焦**评测拓扑 + 可信度** |
| 厂商先验 | UnifoLM-VLA-0 / WMA-0 / WLA-1.0 | Unitree 自有 VLA/WM | 需确认是否已含 chunk+验证（待精读） |

**白空间陈述**：尚未见「共享骨干 + 每任务 LoRA（FedProx 个性化） + 进度验证滚动时域 + N 端口有界异步服务」作为**单一可提交系统**的公开组合。新颖性主张应写成**组合权利要求**，并把每一子件列为从属权利要求。

## 6. 权利要求树（专利式布局）

- **C1（独立）**：一种机器人操作策略方法，包含：共享骨干 + 每任务本地适配器（近端约束仅聚合骨干）；在动作块之间以语义进度验证器决定继续/重规划；以 N 端口有界异步 + 每端口状态隔离对外服务。`[FPL-01]`
- **C2（从属）**：C1 中本地适配器为 LoRA，近端项为 FedProx 型平方范数。`[FPL-02]`
- **C3（从属）**：C1 中服务调度以在飞请求上界 + 等待上限抑制掉队者。`[FPL-03]`
- **C4（从属，条件）**：跨端口共享统计用稳健聚合（trimmed mean / median）。`[FPL-04]`
- **C5（从属）**：验证器为小 VLM，且带置信度门限 + 最大重试 + 延迟预算三重护栏。`[UIP-01 护栏]`
- **C6（从属）**：失效降级链 验证器→步骤分安全网→纯策略保底。`[UIP-02]`
- **C7（从属）**：按泛化轴分组的数据增广与重加权配方。`[UIP-06/07]`
- **C8（从属，条件）**：跨端口在线稳健自适应校正。`[FPL-07]`
- **C9（从属）**：按任务分组在赛前选定 joint 或 ee 的**分册提交**策略。`[FPL-08]`

> 布局要点：C1 越宽越容易被先验「单件」拆掉，故把可辩护的窄点放在 C2/C3/C5；C6 提供「即使核心失效仍拿分」的保险，C8/C9 为可选延伸。

## 8. 实验设计（回放代理优先，E101–E107）

| 实验 | 对照 | 指标 | 判据（先证伪） |
|---|---|---|---|
| E101 | FedProx+LoRA vs FedAvg vs 顺序微调 | 32 任务成功率、遗忘 Δ（首/末任务差） | **无显著抗遗忘增益则否决 FPL-01 的联邦叙事** |
| E102 | 每任务适配器 vs 共享单模型 vs v1 路由 | 平均成功率 + 任务间方差 | 个性化须降方差且不损均值 |
| E103 | 有/无进度验证器（固定 chunk） | 成功率、步骤分、episode 超时率 | 验证器收益须大于其延迟代价 |
| E104 | 同步共享后端 vs 有界异步 vs N 份独立 | 逐步延迟均值/方差、stale 事件数、动作异常率 | 方差须下降且不增动作异常（§6） |
| E105 | 泛化轴逐轴压力（背景/干扰物/未见物/人为扰动） | 每轴成功率 | 每轴不劣化，至少一轴提升 |
| E106 | 稳健聚合 on/off（仅当启用 FPL-07） | 单端口污染下的整体成功率 | 无收益则封存 FPL-04/07 |
| E107 | 端到端组合（01+02+03+06） | 综合=成功率+步骤分，代理 | 相对基线显著提升 |

> 所有真机结论在提测前一律标注为 **RRV 代理指标（UIP-07）**，不得当作真机结论。

## 11. 本轮最大风险

**一句话**：若 E101 无法证明 FedProx+每任务 LoRA 相对标准多任务/顺序微调有可复现的抗遗忘增益，则 FPL-01 的「联邦」只是叙事外壳、整套旗舰退化为改名的 MoE，故必须**先证伪、后投入**，并把 C6 降级链（步骤分安全网→纯策略保底）作为无论旗舰成败都必须先落地的保底资产。
