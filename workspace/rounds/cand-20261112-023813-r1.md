# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 4 轮；本轮灵感：「长程任务」×「状态估计」）

> 第 57 轮把"证据承诺"做成少样本可校准、跨模态可对账、个性化有界的三层机制，它的安全账本里却埋着两笔长程债务。**第一笔是担保稀释**：CCPS 的部署界是对检查点取联合界 `P_safe ≥ 1 − Σ_cp(δ_f+ε_meta+δ_probe+ε_h+δ_ood·α_conf+δ_xm)`，每多走一个检查点就多减一项。短程演示里 Σ 很小、看不出问题；一旦任务是"数小时、上千检查点"的长程任务，这个下界会线性趋零——**不是系统变危险了，而是我们证明它安全的方式在大 N 下失效了**。更隐蔽的是第 57 轮的共形保底与 ECE 声明都以"残差可交换"为前提，而长程部署恰恰非平稳（季节、磨损、传感器漂移），可交换性一旦被破坏，覆盖率会**静默下降**且报警不响。**第二笔是估计漂移**：第 57 轮把区域信念 {b_r} 当成静态要估计的量，却几乎没认真对待"估计器本身会漂"——机器人自身的位姿/打滑估计、地形隐状态的滤波、乃至每一层元模型，都在长程里累积误差；估计在两次观测之间无声发散，而共形/ECE 不会告诉你它发散了。本轮两个灵感正好各还一笔债：**长程任务**要求把风险从"逐步否决"改成"全程预算 + 任一时刻有效（anytime-valid）的信用账本"——用 e-process/Ville 不等式取代联合界，使担保对**所有时域 T 一致成立**而不再随 T 稀释；**状态估计**要求把信念当作滤波问题：显式区分机器人快变状态与地形慢变隐状态、用 NIS/NEES 监控滤波器一致性（不一致本身就是警报）、用可观测性谓词把"测不准的区域"挡在不可逆接触之外、并用闭环/定点平滑在重访时**回溯校正**地图与证据（这是第 57 轮"事后证伪回溯"的自动化版本）。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"任一时刻可担保、漂移可监控、可观测才可承诺、重访可回溯的长程证据说可信"**。

核心矛盾：
- **H29（担保稀释 vs 长程可用性）**：检查点联合界在长程下趋零；但换成"任一时刻有效"的担保又要求系统**在所有时刻按最坏情况付费**，一个永远按最坏情况安全的机器人可能干脆不敢动。安全账本与长程可用性之间存在真实张力——必须给风险一个预算/影子价格，而不是一个每步都一样的硬阈值。
- **H30（估计漂移 vs 证据有效）**：滤波器只在被观测时才被纠正；两次观测之间漂移不可见，而"陈旧"与"漂移"在拿到残差前不可区分。更隐蔽的是：基于可交换性的共形/校准在非平稳下静默失效——你以为还有 1−α 覆盖，其实早没了。
- **H31（回溯校正 vs 已承诺动作）**：闭环平滑能纠正地图与未来信念，**却无法撤销已经发生的不可逆接触**。所以状态估计的价值被可逆性上界死死卡住：对已经压碎的冰面，再准的回溯也只是为下一次服务。

## 0. 直觉与动机

**灵感 1（长程任务 → 风险信用账本 + anytime-valid 担保 + 视界感知探询）**
直觉：短程安全像"每一次过马路都左右看"，长程安全像"一整天的出行保险"。第 57 轮每次过马路都独立买一份保险再做联合界，走的路越多，总保额越不够用。两个改法：**(a) 账本化**——给整个时域一个总风险预算 B_H，每步只允许花一份 allowance，花完就只能绕行/降档/停，从构造上杜绝"稀释"；**(b) anytime-valid**——用 e-process（非负测试超鞅）监控"声明风险是否失真"，由 Ville 不等式给出 `P(∃t: E_t≥1/α)≤α`，这对**所有 T 同时成立**，不需要预先知道要走多少步。长程还白送两件礼物：重复到访让漂移可学（见灵感 2）、时间足够摊销探针成本（视界感知 VOI：早探还是晚探，取决于还剩多少决策能受益）。代价是两件诅咒：联合界稀释与误差复利。

**灵感 2（状态估计 → 信念即滤波、一致性即警报、可观测才可承诺、重访即闭环）**
直觉：把第 57 轮的静态信念 {b_r} 换成滤波状态 s_t=(x_t, h_r)：x_t 是机器人快变的位姿/打滑/载荷，h_r 是地形慢变的隐危险状态（干/湿/冰/颗粒/空洞及其承载参数）。滤波器预测-校正，残差新息 ν_t 的 NIS/NEES 若越出 χ² 带，说明**模型与观测不一致**——这本身是最灵敏的警报，比"证据门"更早发现"我开始自欺"。第二把钥匙是**可观测性**：若沿计划轨迹的可用模态在信息论上无法区分两个会导致不同接触后果的隐状态（只有视觉、没有触探的"看起来干"），那么这块区域的 h_r 就是不可观测的——**不是"证据不足"，而是"再攒证据也没用"**，必须直接禁止不可逆接触。第三把钥匙是**闭环/定点平滑**：重访时用新观测对过去 W 个区域做向后平滑，用累积和（CUSUM/e-detector）检测地形是否变了；一旦检出变化，刷新局部信念、把旧证据按半衰期降权、并回溯审计过去依赖它的承诺。这把第 57 轮的"人工证伪回溯"自动化了。但必须诚实：平滑只救未来，救不了已发生的不可逆接触（H31）。

**灵感 3（两灵感合流 → 安全性质从"每步局部"升级为"全程一致"）**
直觉：把证据门升级成"长程证据门"：不可逆承诺必须同时过六关——(i) anytime-valid 信用账本允许、(ii) 滤波器一致且不在变化检测窗口内、(iii) 信念新鲜（未超陈旧半衰期，否则先重探）、(iv) 隐状态可观测、(v) 第 57 轮五类证据齐、(vi) 不可逆预算已预留。任一关不过就只走保守出口。纵深从"五类证据"扩到"证据 × 估计 × 时间 × 可观测性"四维。

**灵感 4（视界感知 → 探询本身是一个跨时域的调度问题）**
直觉：第 57 轮的 VOI 是"这一步探不探"；长程下真正的问题是"这点探针预算花在旅程的哪个位置最值"。给风险预算一个影子价格 λ：只有当边际 VOI 超过"边际风险占用×λ"时才探。早探能保护更多后续决策但可能被后续漂移作废；晚探更贴近当前状态但可能来不及绕行。于是探针调度变成带影子价格的动态规划，而非逐步贪心。

**灵感 5（诚实边界 → 状态估计不是免费的护身符）**
直觉：本轮所有新机制都必须走"信念更宽 / 动作更保守 / 拒绝 / 重探"四个安全通道，绝不允许"因为估计更准所以更敢赌"。同时明确标出估计的**能力边界**：它能把不可观测变成"拒绝"，把漂移变成"更宽的带"，把变化变成"回溯降权"，但它无法撤销过去。这个诚实边界本身应当成为设计约束，而不是事后免责声明。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（长程风险信用与 anytime-valid 担保 LHC）** 时域 H 上的总风险预算 B_H=1−α。检查点 t 的声明风险 r_t（继承第 57 轮上界），累计已承诺风险 C_t=Σ_{s≤t} committed r_s；承诺允许 ⇔ C_t+r_t≤B_H（预算不破，从构造上消除联合界稀释）。同时维护 e-process：`E_0=1, E_t=E_{t−1}·(1+λ_t(z_t−r_t))`，z_t∈{0,1} 为实际失效指示，λ_t∈[0,1/r_t) 为下注比例；在"声明风险校准"零假设下 E_t 是测试超鞅，Ville 给出 `P(∃t: E_t≥1/α_e)≤α_e`（对所有 T 一致，无需预设时域）。E_t 越界 ⇒ 判定声明风险失真 ⇒ 不可逆地膨胀 r_·、进保守模式并重校准（**只许向保守方向**）。可交换性被违反时，共形/ECE 改用 anytime-valid 共形或 e-value 版本。信用可"赚息"：当经验失效率持续低于声明，只放宽探针成本参数（可以少探），**绝不放宽安全阈值**（保持单调性）。

**定义 140（漂移感知状态估计 DSE）** 状态 s_t=(x_t,h_r)，x_t 快变（位姿/速度/打滑/载荷），h_r 慢变（地形隐危险类及其承载参数）；信念 b_t=Filter(b_{t−1},u_t,o_t)，预测/校正分离。新息 ν_t=o_t−ĥ(o_t|F_{t−1})，NIS_t=ν_tᵀS_t^{−1}ν_t；一致性谓词 Cons(t)⇔ NIS_t∈[χ²_lo,χ²_hi]（状态误差用 NEES）。不一致 ⇒ 协方差膨胀 Cov↑ ⇒ 信念加宽 ⇒ 更保守（单调安全通道）。可观测性谓词 `Obs(h_r | ℳ_avail, trajectory)`：若沿计划轨迹的可用模态的 Fisher 信息矩阵在"导致不同接触后果的隐状态对"上秩亏（不可区分），则判不可观测；不可观测 ⇒ 禁止不可逆接触（不是"证据不足"，而是"再探也无用"）。

**定义 141（闭环回溯校正与漂移检测 LSC）** 重访区域 r 时新息 ν_r^loop=o_revisit−predict(M,r)。用 CUSUM/e-detector 对 ν_r^loop 检测变化：统计量越过 θ_chg ⇒ 判环境非平稳 ⇒ (a) 局部信念重初始化、(b) 旧证据按变化后重估的半衰期降权、(c) 回溯审计并标记过去依赖该证据的承诺、(d) 连续 k 次检出则升级该区域危险类并重规划。定点平滑：用新观测对最近 W 个区域做向后平滑更新 b（只改善未来决策）。**价值界**：平滑对 t 之前已执行的不可逆接触收益恒为 0（H31）。

**定义 142（非平稳与非交换性处理 NSH）** 可交换性假设在长程被破坏，故：共形/ECE 采用时间衰减权重 `w(t)=2^{−(t−t_obs)/τ_{1/2}(r)}` 或 e-value 版 anytime-valid 共形；半衰期 τ_{1/2}(r) 由 LSC 检出的变化率驱动（变化越快半衰期越短）。新鲜度谓词 `Fresh(r,t)` ⇔ 衰减后有效后验仍满足覆盖界、且未超最大陈旧窗口 τ_stale；不新鲜 ⇒ 不可逆承诺前必须先重探。此外，OOD 门与元模型（第 57 轮）也须按漂移定期回归测试，防止"坏先验普遍"随时间恶化。

**定义 143（长程证据门 LHE 与证书 J_h）** 不可逆承诺的必要条件（同时满足）：(1) LHC 预算允许且 E_t<1/α_e；(2) Cons(t) 且 t 不在任何变化检测窗口内；(3) Fresh(r,t) 或已完成重探；(4) Obs(h_r|·)=真；(5) 第 57 轮证据门（EV-probe*/visit/margin/xmodal/human）通过；(6) 不可逆预算已预留。可逆/L1 承诺可放宽 (3)(4)，但必须记录。`J_h=(M_core,C_core,K_margin,ρ_sem,δ_s,probe_log,consent_log,evidence,meta_cal_log,xmodal_log,auth_log,ood_registry,risk_ledger,e_process_log,consistency_log,observability_cert,change_log,smoothing_log)`，继承 J_p 全检。

**定义 144（长程探-诺-演 LPCX）** 每检查点：①预测 s_t；②一致性与变化检测（NIS/NEES、CUSUM）；③视界感知 VOI 选探针——`π*=argmax_π [VOI_H(π) − cost(π) − λ·Δrisk(π)]`，其中 VOI_H 按**剩余时域可受益的决策数**折算、λ 为风险预算影子价格；④承诺 ⇔ LHE 六关全过；否则绕行/降档/L2 协商/安全停；⑤重访触发 LSC 平滑 + 回溯审计；⑥记账（C_t、E_t、τ_{1/2} 更新）。终止于 {承诺, 绕行, L2, 安全停}。

## 2. 关键算法伪代码（完整版见产物区）

```python
def long_horizon_commit(cp, M, ledger, filt, budget):
    s = filt.predict(cp)                                    # ①状态预测
    if not filt.consistent(s) or filt.in_change_window(cp):  # ②一致性警报
        M = filt.inflate(cp); return 'conservative'
    if budget.irreversible(cp) and not observable(cp, M):    # ④不可观测禁不可逆
        return 'refuse'
    if budget.irreversible(cp) and not fresh(cp, M):         # ③不新鲜先重探
        cp = force_probe(cp, M)
    r = declared_risk(cp, M)
    if not ledger.allows(r): return 'reroute'               # ①预算不破
    if not lh_evidence_gate(cp, M, ledger)[0] == 'ok':       # ⑤六关
        return 'conservative'
    ledger.commit(r); return commit(cp, s)                   # ⑥记账

def probe_schedule_voi(cands, M, cp, lam):
    return argmax(cands, key=lambda q: voi_horizon(q, M, cp)
                  - cost(q) - lam * delta_risk(q))            # H29/H44 影子价格
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| LHC | O(1)/检查点 | O(H) 账本 | Ville 一致界、预算从不越界 |
| DSE | O(d_s³) 滤波 / O(d_s²) NIS | O(d_s²) | 一致性带诚实、可观测判据保守 |
| LSC | O(W·d_b)/重访 | O(W·d_b) | 变化检出延迟≤D_chg、回溯完整 |
| NSH | O(1)/更新 | O(\|𝒟_meta\|) | 半衰期随漂移缩短、共形 anytime 有效 |
| LHE | O(1) | O(\|J_h\|) | 六关全过才承诺、可逆可放宽但记账 |
| LPCX | O(\|CP\|·(k_p·(C_VOI+d_s)+W·d_b)+A*) | O(\|V\|+\|σ\|) | 影子价格收敛、预算单调、终止 |

**正确性定理（Long-Horizon Drift-aware Soundness, LHDS 概要）**：在 A37–A40 上加 **(A41)** 滤波器一致且漂移有界（Cons 判据诚实、不一致时协方差膨胀）；**(A42)** 变化检测延迟 ≤D_chg 且不新鲜区域在不可逆前必重探；**(A43)** 可观测谓词保守（判不可观测时确实不可区分）；**(A44)** e-process 与风险账本诚实（λ_t 合法、C_t≤B_H 恒成立）。则对**任意时域 T**（一致地）：(i) `P(∃t≤T: commit_t∧fail_t) ≤ α_e + δ_drift·D_chg + δ_probe`，不再随 T 稀释；(ii) 可观测性把"不可区分区域"的不可逆失效率压到 0；(iii) 单调性保持：所有新机制只经"加宽/降档/拒绝/重探"影响系统；(iv) 平滑对过去不可逆接触的收益恒为 0（价值被可逆性上界）。

## 6. 本轮最大风险

**一句话**：本轮用"任一时刻有效 + 漂移一致 + 可观测"把长程安全从联合界稀释里救出来，但代价是系统可能被这套担保"锁死"——在恰恰最需要长程探索的新鲜、变化中的地形里，它要么因预算/可观测性/新鲜度而拒绝不可逆接触、要么因保守模式而不敢前进；而三把钥匙（变化检测、一致性模型、可观测判据）本身正是在这些新地形里最不可信，安全链条的最弱环从"证据质量"悄悄换成了"估计与检测模型的质量"。

### IP-139 LHC（风险信用账本 + e-process anytime-valid 担保）

```python
def ledger_allow_and_commit(ledger, r_t, z_t=None):
    # (a) 预算：构造上杜绝联合界稀释
    if ledger.C + r_t > ledger.B_H:
        return False, 'budget_exhausted'
    # (b) e-process：监控声明风险是否失真（Ville 对所有 T 一致）
    lam = ledger.lambda_t(r_t)                     # lam in [0, 1/r_t)
    if z_t is not None:                            # 事后拿到失效指示才更新
        ledger.E *= (1.0 + lam * (z_t - r_t))
    if ledger.E >= 1.0 / ledger.alpha_e:           # 声明失真 -> 只向保守方向
        ledger.inflate_all(mult=ledger.rho_up)     # 不可逆地膨胀风险
        ledger.enter_conservative()
        return False, 'risk_model_miscCalibrated'
    ledger.C += r_t
    return True, 'ok'

def earn_dividend(ledger):                         # 只降成本，不降安全阈值
    if ledger.empirical_fail_rate() < ledger.declared_rate * ledger.margin:
        ledger.probe_cost_mult *= ledger.dividend_decay   # 可以少探
        # 注意：B_H / r_t / 证据门阈值不变（单调性）
    return ledger
```

### IP-140 DSE（漂移感知状态估计 + 一致性 + 可观测性）

```python
def dse_predict(s_prev, u):
    x, h = motion_model(s_prev.x, u), slow_drift_model(s_prev.h)
    P = F @ s_prev.P @ F.T + Q
    return State(x, h, P)

def dse_update(s, o):
    nu = o - obs_model(s)                          # 新息
    S  = H @ s.P @ H.T + R
    K  = s.P @ H.T @ inv(S)
    s.x, s.h = s.x + K @ nu, s.h + K @ nu
    s.P = (I - K @ H) @ s.P
    nis = nu.T @ inv(S) @ nu
    s.consistent = chi2_lo <= nis <= chi2_hi       # Cons(t)
    if not s.consistent:
        s.P = inflate(s.P, factor=kappa)           # 加宽：单调安全通道
    return s, nis

def observable(region, modalities, trajectory):
    F = fisher_information(region, modalities, trajectory)
    return rank_on_distinguishable(F) == full_rank   # 保守：秩亏即不可观测
```

### IP-142 NSH（非平稳与非交换性处理 + 新鲜度）

```python
def freshness_and_half_life(M, r, t):
    tau = tau0 / (1.0 + M.change_rate[r])          # 漂移越快，半衰期越短
    age = t - M.t_obs[r]
    w   = 0.5 ** (age / tau)                        # 时间衰减证据权重
    fresh = (w >= w_min) and (age <= tau_stale)
    return fresh, tau, w

def anytime_conformal(residuals, times, t, alpha, tau_half):
    w = [0.5 ** ((t - tj) / tau_half) for tj in times]
    return weighted_quantile(residuals, w, 1 - alpha)   # 覆盖不依赖固定 N
```

```python
def voi_horizon(p, M, cp, lam):
    remaining = decisions_benefiting(p.region, cp, horizon_left)   # 受益决策数
    dH = expected_entropy_reduction(p, M) * remaining
    return dH - cost(p) - lam * delta_risk(p)                       # 视界折算

def probe_commit_evolve_long(x0, M, task, ledger, personas, filt):
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        s = filt.predict(cp); M = attach_state(M, cp, s)
        if not filt.consistent(s) or filt.in_change_window(cp):
            M = filt.inflate(cp)                    # 保守：不承诺

        while select_gait(schedule_risk(cp, M)) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, M, F_abs)         # 非破坏性过滤（继承）
            p = argmax(cands, key=lambda q: voi_horizon(q, M, cp, lam))
            if voi_horizon(p, M, cp, lam) < 0:  break
            M = xmodal_update(M, cp, execute_probe(p, cap=F_abs))  # 第 57 轮
            budget.spend(p)
        if long_horizon_evidence_gate(core_contact(cp), M, filt, ledger, budget)[0] == 'ok':

                commit(cp, s); continue
        alt = reroute(M, cp, risk_model)            # 出口：绕行/降档/L2/安全停
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, s, consent,
                                 tau_int=tau_int(personas.active.auth))
    return route, M, ledger
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| LHC | O(1)/检查点 | O(H) 账本 | 预算从不越界；Ville 一致界（A44） |
| DSE | O(d_s³) 滤波 / O(d_s²) NIS | O(d_s²) | 一致性带诚实、可观测判据保守（A41/A43） |
| LSC | O(W·d_b)/重访 | O(W·d_b) | 变化检出延迟≤D_chg、回溯完整（A42） |
| NSH | O(1)/更新 | O(\|𝒟_meta\|) | 半衰期随漂移缩短、共形 anytime 有效 |
| LHE | O(1) | O(\|J_h\|) | 六关全过才承诺；可逆可放宽但记账 |
| LPCX | O(\|CP\|·(k_p·(C_VOI+d_s)+W·d_b)+A*) | O(\|V\|+\|σ\|) | 影子价格收敛、预算单调、四态完备 |

**正确性定理（Long-Horizon Drift-aware Soundness, LHDS）**
假设 A22–A40（第 53–57 轮）成立，并加：**(A41)** 滤波器一致且漂移有界——Cons 判据诚实，不一致时协方差单调膨胀；**(A42)** 变化检测延迟 ≤D_chg，且不新鲜区域在不可逆承诺前必被重探；**(A43)** 可观测谓词保守——判"不可观测"时隐状态确实不可区分；**(A44)** e-process 与风险账本诚实——λ_t 合法、`C_t≤B_H` 恒成立、E_t 在零假设下为测试超鞅。则：

1. **任一时刻担保（消除稀释）**：对**任意时域 T 一致地**，
   `P(∃t≤T: commit_t ∧ fail_t) ≤ α_e + δ_drift·D_chg + δ_probe`，
   不再含 `N·δ_f` 形式的线性稀释项；长程失效率被风险预算从构造上封顶。
2. **可观测性硬边界**：在 `¬Obs` 区域上，不可逆承诺的失效率为 0（被 LHE 硬拒绝），与探针数量、元先验质量无关。
3. **估计单调性**：DSE/LSC/NSH 只能经 (a) 加宽信念、(b) 降档/拒绝/重探 影响系统；不一致、变化检测、不新鲜都使 LHE 更严，绝无升险通道。第 57 轮"信念更准或动作更保守"两通道被扩展为"信念更准/更宽或动作更保守或拒绝/重探"。
4. **回溯价值界（H31）**：对 t0 之前已执行的不可逆接触，平滑与回溯的期望收益 ≤0（不能撤销）；其唯一可证明价值是保护 t>t0 的决策并防止同错复发。因此状态估计的安全贡献被可逆性上界，透明披露。
5. **终止性**：LPCX 每检查点探针 ≤k_p，预算 B_H 单调消耗且有限，必在有限步终止于 {承诺, 绕行, L2 协商, 安全停}。

**部署界（anytime，对所有 T）**：

```
∀T: P_safe(T) ≥ 1 − α_e − δ_drift·D_chg
                   − P(变化漏报导致新鲜度失效)
                   − P(可观测判据漏判)
```

关键：**第 57 轮"元先验给效率、共形给保底"**在本轮补上长程维度——**风险预算给长程不稀释、滤波一致性给实时监控、可观测性给硬边界、闭环回溯给纠错**；但回溯只能救未来，估计的价值被可逆性上界。

## 6. 本轮最大风险

**一句话**：本轮用"任一时刻有效 + 漂移一致 + 可观测"把长程安全从联合界稀释里救出来，但代价是系统可能被这套担保"锁死"——在恰恰最需要长程探索的新鲜、变化中的地形里，它要么因预算/可观测性/新鲜度而拒绝不可逆接触、要么因保守模式而不敢前进；而三把钥匙（变化检测、一致性模型、可观测判据）本身正是在这些新地形里最不可信，安全链条的最弱环从"证据质量"悄悄换成了"估计与检测模型的质量"。
