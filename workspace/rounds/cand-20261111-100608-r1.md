# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「课程学习」×「避障控制」）

> 第 54 轮把技能组合提升为「动作空间剖面 α_S + 云边协同 + 动作-鲁棒性联合证书 J」，但留下三个硬伤：α_S 靠均匀采样、γ_ce 在极限动作处未必单调、联合证书只在训练分布均值上成立。本轮用 **课程学习** 把「均匀剖面采样 / 均匀验证」改造成「按难度推进的主动取证」，用 **避障控制** 为「难度」提供物理轴、为「安全」提供可判定的包络。核心矛盾：H22：均匀采样把「未测到」误当「安全或不安全」，产生虚假兼容；H23：云端与边端共享一个难度序，但边端在真实难度上出现「课程断层」，离线证书在难例上失效；H24：课程推进带来灾难性遗忘，安全前沿证书只对当前课程阶段成立。

## 0. 直觉与动机

**灵感 1（把动作剖面采样变成课程）**
直觉：第 54 轮的 ACS 在 `A_c × A_e` 上均匀采样，既浪费预算又系统性漏掉「边界动作」。给每个动作 `a` 一个难度 `d(a)`，从低难度开始采样，只在 **最近发展区 ZPD**（胜任度落在 `[c_lo, c_hi]`）内加密；采样停止条件不再是「采满固定网格」，而是「难度前沿 `d*_S` 不再上升」。这像人学骑车：先宽路后窄路，窄路不再进步时，才知道自己的安全极限在哪。

**灵感 2（避障为难度轴提供物理定义，也为安全提供可判定包络）**
直觉：避障任务天然有难度轴——障碍密度、最小间隙、动态障碍速度、感知噪声。更关键，避障提供 **控制障碍函数（CBF）** 这一硬约束：安全动作集 `Safe_S(x) = {a : h(x,a) ≥ 0 ∧ CBF 条件}`。这把第 54 轮抽象的「动作占用」落到「安全包络 `E_S`」上——组合不仅要动作有交集，还要包络在前向不变意义下能接力。

**灵感 3（要前沿证书，不要均值证书）**
直觉：课程学到的不是「平均成功率」，而是「我在多难的任务上仍能保证 `c ≥ 1-ε`」。定义 **课程覆盖证书 `CC_S = (d*_S, ε, retention, n_cert)`**，任何鲁棒性谱 `ρ` 只在难度带 `[0, d*_S]` 内被承认。这直接回应第 54 轮「α_S 欠采样导致虚假兼容」：兼容性必须在路径最大难度 `d_path` 上重新判定，而不是在训练分布均值上判定。

**灵感 4（运行时安全滤波是证书之外的第二道门）**
直觉：离线课程前沿再保守，也可能被分布外难例击穿。CBF-QP 安全滤波器可在执行瞬间把标称动作投影回 `Safe_S(x)`，干预量 `β = ||a* - a_nom||` 是「证书正被现实修正」的实时证据。若 `β` 持续超预算，回传边端并触发云端重新排课。这把第 54 轮的 Explain 回传升级为「干预量触发的课程回传」。

**灵感 5（课程分级组合 + 难度对齐的云边协同）**
直觉：技能图 `G_S` 的边不应只有 `compat` 阈值，还要有「难度上限 `d*_{ij}`」。云端按全局难度地图排课与组合，边端按本地胜任度回传 `ĉ_e(d)` 与 `β`；云端只能在 `d ≤ min d*_edge - margin` 的难度带上发计划。云边契约于是从「动作对齐」扩展为「难度对齐」，并加入保留复测以防课程遗忘。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（任务难度与课程）**
任务空间 `𝒯`，难度函数 `d : 𝒯 → [0,1]`。避障任务的具体化：
```
d(τ) = σ( w_o·ρ_obs + w_g·(1 - m_min/m_0) + w_v·v_dyn/v_0 + w_n·η_perc )
```
其中 `ρ_obs` 为障碍密度，`m_min` 为最小间隙，`v_dyn` 为动态障碍速度，`η_perc` 为感知噪声，`σ` 为单调压缩函数。课程 `𝒞 = {(𝒯_k, p_k)}`，`p_k` 为非降进程函数，`𝒯_k` 支撑在 `{d ≤ p_k}` 上。

**定义 122（胜任度、最近发展区、学习进步）**
技能 S 的胜任度 `c_S(d) = P_{τ~𝒯_d}[success(S,τ)]`；最近发展区 `ZPD_S(δ) = {d : c_lo ≤ c_S(d) ≤ c_hi}`；学习进步 `LP_S(d,t) = ∂c_S(d,t)/∂t`。课程策略取 `argmax_{d∈ZPD} E[LP_S(d,t)]`，并用 PAC 置信带在线更新 `ĉ_S(d)`。

**定义 123（课程覆盖证书与安全前沿）**
对容差 `ε`，认证前沿 `d*_S(ε) = max{d : ∀ d' ≤ d, c_S(d') ≥ 1-ε}`（取包含 0 的最大连续带，以容忍非单调）。课程覆盖证书 `CC_S = (d*_S, ε, retention_S, n_cert, evidence)`，其中 `retention_S = min_{k'≤k} c_S(d_{k'})` 为对早期课程的保留下界。`ρ_S` 只在 `d ≤ d*_S` 上被承认；避障语义下最小认证间隙 `m*_S = m_0·(1 - d*_S)`。

**定义 124（避障安全包络）**
障碍集 `O`，安全函数 `h(x) = min_{o∈O} dist(x,o) - r_safe`。技能 S 的安全动作集 `Safe_S(x) = {a∈A_S : h(x,a) ≥ 0 ∧ L_f h + L_g h·a + α h ≥ 0}`。安全包络 `E_S` 为 `{h ≥ 0}` 在 S 下的最大前向不变子集。组合可接力条件：`E_{S_i} ∩ E_{S_j}` 在转换动作下前向不变，即 `ΔA_{ij} ⊆ E_i ∩ E_j`。

**定义 125（课程分级组合证书）**
边 `(i,j)` 在难度 `d` 上的证书 `C_comp(d) = (A_overlap(d), ρ_comp(d), E_i∩E_j, d)`；难度上限 `d*_{ij} = min(d*_i, d*_j, d*_trans)`，`d*_trans` 为转换动作的认证前沿。路径 P 在任务难度 `d` 上有效，当且仅当 `d ≤ min_{(i,j)∈P} d*_{ij}`。

**定义 126（运行时安全滤波与干预量）**
`π_safe(x, a_nom) = argmin_{a∈Safe_S(x)} ||a - a_nom||²`；干预量 `β = ||π_safe(x,a_nom) - a_nom||`。若 `β ≤ β_max` 且 CBF 模型有效，则执行动作安全，其概率下界独立于离线动作剖面的准确度。

**定义 127（课程-云边协同契约）**
`C_ce^cur = (P_c, P_e, Δ, Explain_loop, Curriculum_state)`，其中 `Curriculum_state = (D_c, p, {ĉ_e(d), LP_e(d), β_e, violations})`：`D_c` 为全局难度地图，`p` 为进程函数。契约约束：云端发出的计划难度必须满足 `d ≤ D_c^{-1}(p) ∧ d ≤ min d*_edge - margin`；边端 `β` 或违规超阈时触发 `reprofile(frontier)`（只重采前沿邻域），而非全域重采。

## 2. 关键算法 伪代码

### IP-121 DAC（Difficulty-Aware Curriculum）

```python
def estimate_difficulty(task_stats, w):
    d = w['o']*task_stats.obs_density + w['g']*(1 - task_stats.min_gap/M0) \
      + w['v']*task_stats.dyn_speed/V0 + w['n']*task_stats.perc_noise
    return sigmoid(d)

def pace(stage, d_star, last_lp, lp_min=0.02, step=0.05, backoff=0.1):
    # 进程函数：ZPD 内推进；前沿停滞则回撤，避免课程跳变
    if last_lp < lp_min:
        return max(0.0, d_star - backoff)
    return min(1.0, d_star + step)
```

### IP-122 ZPD-APS（课程驱动的主动剖面采样，升级 IP-115）

```python
def curriculum_profile(skill, tasks, budget, eps=0.05):
    alpha, d_star, n, last_lp = {}, 0.0, 0, 1.0
    while budget > 0:
        d = pace(n, d_star, last_lp)
        # 只在 ZPD 与前沿邻域做主动采样 + 贝叶斯优化
        a = active_query(skill, tasks, d, zpd=(c_lo, c_hi))
        s = simulate(skill, a, tasks)
        alpha[a] = running_mean(alpha.get(a, 0.5), s.success)
        budget -= 1
        last_lp = c_s_estimate(alpha, d) - c_s_estimate(alpha, max(0.0, d-0.05))
        if c_s_estimate(alpha, d) >= 1 - eps:
            d_star = max(d_star, d)
        if n % retention_every == 0 and not retention_ok(skill, alpha, d_star):
            d_star = max(0.0, d_star - backoff)   # 遗忘则主动回撤前沿
        n += 1
    return alpha, CurriculumCert(d_star, eps, retention_ok, n)
```

### IP-123 CSF（前沿证书）与 IP-126 SFC（CBF 安全滤波）

```python
def safety_frontier(cert, rho, d_path, d_task):
    if d_task > d_path or d_task > cert.d_star:
        return ('reject', 'beyond_certified_frontier', cert.d_star)
    return ('ok', min(rho_band(cert, rho, d_task)))

def barrier_filter(x, a_nom, h, alpha_cbf):
    # CBF-QP: min ||a-a_nom||^2  s.t. h>=0, h_dot + alpha*h >= 0
    a_safe, beta = solve_cbf_qp(x, a_nom, h, alpha_cbf)
    return a_safe, beta
```

### IP-124 AEC+（避障包络组合，升级 IP-118）

```python
def compose_envelope(S_i, S_j, transition):
    E = invariant_subset(intersect(S_i.E, S_j.E))
    if not subset(transition.actions, E):
        return ('reject', 'envelope_not_forward_invariant')
    return ('ok', E)

def joint_certificate_cur(skill_seq, gamma_ce, d_path, rho_min, beta_budget):
    A_core = reduce(intersection, [s.alpha for s in skill_seq])
    E = reduce(intersect, [s.E for s in skill_seq])
    delta_a = max_alignment_error(gamma_ce, A_core)
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    if delta_a > delta_a_budget or min(rho_comp.values()) < rho_min:
        return ('reject', 'action_or_robustness_fail', delta_a)
    return ('ok', JointCertCur(rho_comp, A_core, E, gamma_ce, delta_a, d_path))
```

### IP-125 CEC+（课程-云边闭环，升级 IP-117）

```python
def cloud_curriculum_plan(T_desc, G, D_c, pacing, edge_reports, margin):
    d_cap = min(D_c_inv(pacing), min_d_star(edge_reports) - margin)
    path = search_path(G, goal=T_desc, difficulty_cap=d_cap)   # A* on cost_align

def edge_curriculum_check(P_c, gamma_ce, sim, beta_max):
    reports = []
    for sid, a_c, d in P_c:
        s = skill_lib[sid]
        a_e = gamma_ce(a_c)
        a_safe, beta = barrier_filter(sim.x, a_e, sim.h, alpha_cbf)
        if beta > beta_max or not cover_check(s.alpha, a_e):
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| DAC | O(\|𝒯\|) | O(1) | 难度单调、标定误差有界 |
| ZPD-APS | O(B·\|A\|) | O(\|A\|) | ZPD 全支撑、前沿 PAC 覆盖 |
| CSF | O(\|P\|) | O(1) | 前沿带内 sound、保留复测 |
| AEC+ | O(\|S\|²·\|A\| + \|∂E\|) | O(\|E_i\|) | 包络前向不变、δ_a 预算闭合 |
| CEC+ | O(\|V\|log\|V\| + \|E\| + \|P\|·\|π\|) | O(\|V\|+\|E\|) | 难度对齐、回传收敛 |

**正确性定理（Curriculum-Frontier Safety Composition Soundness）**
在第 54 轮 (A22)–(A28) 之上补充：**(A29)** 难度序对安全单调（或取保守包络，允许非单调但以前沿连续带计）；**(A30)** CBF `h` 对真实动力学有效，且 `Safe_S(x) ≠ ∅` 于认证带；**(A31)** 胜任度估计 PAC：`|ĉ_S(d) - c_S(d)| ≤ γ` 以概率 `1-δ` 成立，且前沿邻域采样满支撑；**(A32)** 安全滤波 QP 在 `τ_filt` 内可解。则对任务难度 `d ≤ d*_path`：
```
P_success ≥ 1 - Σ_dim(1-ρ_min) - β_E - P(δ_a>Θ_a) - P(compat<θ_a) - k·γ
P_safety  ≥ 1 - P(β>β_max) - P(CBF_model_error) - P(retention_fail) - ε_frontier
```
关键：**离线前沿证书**与**在线 CBF 滤波**是两条统计独立的失效路径；部署必须同时满足 `d_task ≤ d*_path`、`retention_ok`、`β ≤ β_max`，任一条不满足即降级为安全停或重新排课。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 难度度量 `d` 与真实安全关键性错位 | 高 | 多维难度矢量 + Pareto 前沿 + 用干预量/违规在线标定 `d` |
| 前沿估计非单调、方差大 | 高 | PAC 置信带 + 保守包络 + 前沿回撤 |
| 课程遗忘/灾难性遗忘 | 高 | 保留复测 + 经验回放 + 混合课程 replay |
| CBF 模型与真实动力学失配 | 高 | 鲁棒/自适应 CBF + 保守 `α` + 学习残差上界 |
| 课程被 teacher/adversary 投毒 | 中 | held-out 最难测试 + 随机化课程 + 红队 |
| 云边难度地图不一致 | 中 | 报告滞后补偿 + margin + 版本化难度地图 |

## 6. 本轮最大风险

**一句话**：课程学习把剖面采样与验证从「均匀枚举」变成「按难度推进」，避障包络把安全从离线证书变成在线兜底；但其 soundness 双重依赖 **难度度量 `d` 与真实安全关键性的一致性** 与 **课程推进中的保留（防遗忘）**，一旦 `d` 误设或前沿只在训练均值上成立，系统会在「看似已掌握」的难度带上系统性失守，故必须以 **多维难度标定 + 前沿保留复测 + 鲁棒 CBF 运行时兜底** 三重护栏，宁可把安全前沿报低，也绝不把课程进步曲线当作安全证书。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim-CurrSafe（DAC×ZPD-APS×CSF×AEC+×SFC×CEC+×CGC）

> 承接第 54 轮产物 v31（GroundEdge-GenSim+++）。本轮在「动作剖面 + 云边协同 + 联合证书」之上，引入 **课程学习驱动的主动取证** 与 **避障安全包络** 两条主线：
> - **DAC（Difficulty-Aware Curriculum）**：可标定的任务难度函数与进程函数；
> - **ZPD-APS（ZPD Active Profile Sampling）**：只在最近发展区加密的主动剖面采样，升级 ACS；

> - **SFC（Safety Filter Controller）**：CBF-QP 运行时兜底与干预量 `β` 证据；
> - **CEC+（Curriculum-Aware Cloud-Edge Coordination）**：难度地图 + 干预量回传的云边排课闭环，升级 CEC；
> - **CGC（Curriculum-Graded Composition）**：带难度上限 `d*_{ij}` 的技能组合图，升级 SCOM。

| `β` | 安全滤波干预量 `\|\|π_safe - a_nom\|\|` |
| `d*_{ij}` | 组合边难度上限 `min(d*_i, d*_j, d*_trans)` |
| `C_ce^cur` | 课程-云边协同契约（含难度地图与回传状态） |

## 2. 关键算法 伪代码

### IP-121 DAC：难度标定与进程

```python
def estimate_difficulty(task_stats, w, calibrator):
    raw = (w['o']*task_stats.obs_density
           + w['g']*(1 - task_stats.min_gap/M0)
           + w['v']*task_stats.dyn_speed/V0
           + w['n']*task_stats.perc_noise)
    d = sigmoid(raw)
    # 在线标定：用真实失败率/干预量修正难度序，防止 d 只是代理
    return calibrator.correct(d, task_stats.failure_rate, task_stats.beta_p95)

def pace(stage, d_star, last_lp, lp_min=0.02, step=0.05, backoff=0.10):
    return min(1.0, d_star + step) if last_lp >= lp_min \
           else max(0.0, d_star - backoff)
```

### IP-122 ZPD-APS：课程驱动的主动剖面

```python
def curriculum_profile(skill, tasks, budget, eps=0.05):
    alpha, d_star, n, last_lp = {}, 0.0, 0, 1.0
    while budget > 0:
        d = pace(n, d_star, last_lp)
        a = active_query(skill, tasks, d, zpd=(c_lo, c_hi))  # BO/红队混合
        s = simulate(skill, a, tasks)
        alpha[a] = running_mean(alpha.get(a, 0.5), s.success)
        budget -= 1
        last_lp = c_s_estimate(alpha, d) - c_s_estimate(alpha, max(0.0, d-0.05))
        if c_s_estimate(alpha, d) >= 1 - eps:
            d_star = max(d_star, d)
        if n % retention_every == 0 and not retention_ok(skill, alpha, d_star):
            d_star = max(0.0, d_star - backoff)
        n += 1
    return alpha, CurriculumCert(d_star, eps, retention_ok(skill, alpha, d_star), n)
```

### IP-123 CSF：前沿证书（把 ρ 关进难度带）

```python
def certify_frontier(alpha, tasks, rho, eps=0.05, gamma=0.03):
    # PAC 下界：只有置信下界仍 >= 1-eps 的难度才计入前沿
    d_star = 0.0
    for d in sorted_difficulty_grid():
        if c_lower_bound(alpha, d, gamma) >= 1 - eps:
            d_star = d
        else:
            break                      # 取连续带，非单调处截断
    return CurriculumCert(d_star, eps, retention_ok(alpha), n_cert=len(alpha))

def admit(rho, cert, d_task):
    if d_task > cert.d_star:
        return ('reject', 'beyond_frontier', cert.d_star)
    return ('ok', rho_band(rho, d_task))   # 只承认带内谱
```

### IP-124 AEC+ / IP-125 SFC：包络组合 + 运行时兜底

```python
def compose_envelope(S_i, S_j, transition):
    E = invariant_subset(intersect(S_i.E, S_j.E))
    if not subset(transition.actions, E):
        return ('reject', 'envelope_not_forward_invariant', E)
    return ('ok', E)

def barrier_filter(x, a_nom, h, alpha_cbf):
    a_safe, beta = solve_cbf_qp(x, a_nom, h, alpha_cbf)  # min ||a-a_nom||^2
    return a_safe, beta

def deploy_gate(J, cert, d_task, beta, beta_max):
    ok = (d_task <= min(J.d_path, cert.d_star)
          and cert.retention_ok and beta <= beta_max)
    return 'deploy' if ok else ('safe_stop' if beta > beta_max else 'reprofile')
```

```python
def cloud_curriculum_plan(T_desc, G, D_c, pacing, edge_reports, margin):

def edge_curriculum_check(P_c, gamma_ce, sim, beta_max):
```

### IP-127 CGC：课程分级组合图

```python
def build_graded_graph(skills, theta_a, tau_e, d_grid):
    G = nx.DiGraph()
    for i, s1 in skills:
        for j, s2 in skills:
            if i == j: continue
            for d in d_grid:
                if (jaccard(s1.alpha[d], s2.alpha[d]) >= theta_a
                        and transition_cost(s1, s2, d) <= tau_e
                        and subset(transition(s1, s2).actions, s1.E & s2.E)):
                    G.add_edge(i, j, d=d,
                               d_star=min(s1.d_star, s2.d_star, d_trans(s1, s2)),
                               rho=compose_robustness(s1.rho, s2.rho, K))
                    break       # 取该边最高可行难度，形成分层边
    return G

def path_valid(path, d_task):
    return d_task <= min(G[u][v]['d_star'] for u, v in path_edges(path))
```

## 3. 关键推导：双重门 soundness

把失效拆成两条互不依赖的路径：

1. **离线门**：课程前沿证书只覆盖 `d ≤ d*`。若难度估计 `ĉ` 有 PAC 误差 `γ`、路径含 `k` 条边，则由并集界，
   `P(带内失败) ≤ k·γ + Σ_dim(1-ρ_min) + P(compat<θ_a) + P(δ_a>Θ_a)`。
2. **在线门**：CBF-QP 将任何标称动作投影到 `Safe_S(x)`。若 QP 可解且 CBF 模型有效，则
   `P(碰撞 | β ≤ β_max) ≤ P(CBF_model_error) + ε_filt`，且该界不依赖 `α_S` 的准确度。

联合部署条件：
```
deploy ⇔ d_task ≤ d*_path ∧ retention_ok ∧ β ≤ β_max
```
于是 `P(safe ∧ success) ≥ 1 - k·γ - Σ_dim(1-ρ_min) - β_E - P(δ_a>Θ_a) - P(β>β_max) - P(CBF_error) - ε_frontier`。

**可证伪点**：若在认证带内有碰撞，必是 `γ` 低估 / CBF 模型失配 / retention 失效之一；三者都能由实验单独注入（E165、E167）。这正是本轮相对第 54 轮的可检验增量——把「证书 sound」拆成可独立否证的三个假设。

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DAC | O(\|𝒯\|) | O(1) | 难度序可标定，标定误差计入 `γ` |
| ZPD-APS | O(B·\|A\|) | O(\|A\|) | ZPD 全支撑，前沿 PAC 覆盖 |
| CSF | O(\|P\| + \|𝒯\|) | O(1) | 连续带前沿、保留下界 |
| AEC+ | O(\|S\|²·\|A\| + \|∂E\|) | O(\|E_i\|) | 包络前向不变，组合可接力 |
| SFC | O(poly(\|A\|)) / QP | O(\|A\|) | 若 QP 可解则安全性独立于 α 精度 |
| CEC+ | O(\|V\|log\|V\| + \|E\| + \|P\|·\|π\|) | O(\|V\|+\|E\|) | 难度对齐 + 回传单调收敛 |
| CGC | O(\|S\|²·\|A\|·\|d_grid\|) | O(\|S\|²) | 分层边 sound，路径按 `d*` 校验 |

**正确性定理（Curriculum-Frontier Safety Composition Soundness）**
在第 54 轮 (A22)–(A28) 成立的前提下，补充 (A29) 难度序对安全单调或取保守包络；(A30) CBF `h` 对真实动力学有效且认证带内 `Safe_S ≠ ∅`；(A31) 胜任度估计 PAC、前沿邻域满支撑；(A32) 安全 QP 在 `τ_filt` 内可解。则对 `d_task ≤ d*_path` 的部署：
```
P_success ≥ 1 - k·γ - Σ_dim(1-ρ_min) - β_E - P(δ_a>Θ_a) - P(compat<θ_a)
P_safety  ≥ 1 - P(β>β_max) - P(CBF_model_error) - P(retention_fail) - ε_frontier
```
关键：**课程前沿负责「不该去的地方不去」，CBF 滤波负责「去了也撞不上」**，二者共同构成双门证书；任一门的假设都要能被实验单独击穿。

## 6. 本轮最大风险

**一句话**：课程学习把剖面采样与验证从「均匀枚举」变成「按难度推进」，避障包络把安全从离线证书变成在线兜底；但其 soundness 双重依赖 **难度度量 `d` 与真实安全关键性的一致性** 与 **课程推进中的保留（防遗忘）**，一旦 `d` 误设或前沿只在训练均值上成立，系统会在「看似已掌握」的难度带上系统性失守，故必须以 **多维难度标定 + 前沿保留复测 + 鲁棒 CBF 运行时兜底** 三重护栏，宁可把安全前沿报低，也绝不把课程进步曲线当作安全证书。
