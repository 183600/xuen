## 1. 两个灵感的第一性原理

### 灵感 1 ·「抓取」→ 零样本泛化的认知瓶颈，以及一条可辨识性边界

**直觉**：位置、干扰物、外观、指令这些泛化轴，都能在「感知—重规划」层解决而不必接触物体；唯独未见物体的**质量、摩擦、质心、刚性**无法靠看获得，只能靠**碰**获得。所以抓取不是「末端执行器的动作」，而是策略**向物体提出的第一个物理问题**——它是零样本泛化里唯一的信息闸门。

**严谨**：在无接触力/触觉、观测仅为头/腕相机 + EE 位姿 + 夹爪标量的条件下，平行夹爪准静态无滑移条件为

- 平动：`2μN ≥ m·a_eff`
- 转动：`μN·w ≥ m·a_eff·d`

（N=单指法向力，w=指宽，d=质心到夹持轴偏心，`a_eff=‖g−a_ee‖`）。两式相除得「转动先于平动滑移 ⇔ `d/w > 1/2`」；统一写成 `N*(κ,g) = κ·a_eff·max(1/2, d/w)`，`κ = m/μ`。**结论（L14）：m 与 μ 只以比值 κ 与几何量 d/w 进入动力学，各自不可辨识；控制相关的可辨识量是 κ（等价于临界夹持力 N\*），不是质量或摩擦系数。** 因此「估质量/估摩擦」的模块在设计上就不可辨识；正确目标是估计并调节**滑移裕度 s = N − N\***。

**三个直接推论**：
1. **抓取即假设检验（P13）**：每个抓取假设都带一个可证伪的成功判据与一个验证动作（预升力微滑移 / 运输期滑移监测），没有验证计划的抓取不许上线。
2. **稳健优先（P14 / L15）**：在 κ 先验下，最优抓取是最大化「可容忍 κ 上界」`κ_max(g)` 的抓取，或**笼式（caging）抓取**——用几何包容替代力闭合，从而不依赖 κ；排序键从「名义对跖分数」改为「稳健裕度 / 笼式包容性」。
3. **探测记账（L16，接 L13）**：预升力探测的盈亏平衡由「先验宽度 × 抓取激进度 × 运输失败代价」决定；只对「新物体 + 激进抓取 + 高失败代价」探测。

### 灵感 2 ·「零样本泛化」→ 不是「见过更多」，而是「不变量学到极致 + 在线补差」

**直觉**：零样本泛化常被误解为「更大的训练集/更多物体」。但新语料（F4）增长的是**任务与外观多样性**，并不自动带来**物体身份级**的零样本。真正可迁移的是三类不变量：①几何/拓扑（对跖、笼式、可达）；②物理（重力、力平衡、滑移）；③任务语义（要做什么）。不可迁移的是外观、纹理、精确质量。零样本的正解是把未见物体**路由到不变量**，而不是路由到外观检索。

**严谨**：把未见分布上的缺口按信息 oracle 链分解（L17）。取 `O_0`=仅外观、`O_1`=几何、`O_2`=几何+探测、`O_3`=几何+探测+裕度调节，则「可被信息闭合的缺口」`G_closed = R(O_3) − R(O_0) = Σ_k [R(O_k) − R(O_{k−1})]` 可望远镜分解，每项归因到**不变性缺口 G_inv / 辨识缺口 G_id / 动作缺口 G_act**；`R_in − R(O_3)` 为**覆盖缺口 G_cov**（先验支撑之外，不可约，只能靠探索/生成）。⇒ 「泛化差」从口号变成可分配预算；本轮把预算押在 G_id + G_act（抓取辨识与裕度调节），并用仿真生成物体压缩 G_cov（IP-17）。

**数据含义**：F4/F5 说明官方语料与仿真资产都在扩张，但挑战评测的「未见物品」轴仍要求**按物体身份留出**；因此新语料的价值取决于切分方式与物理随机化，而非下载量。这是第 3 轮「数据护城河为零」的正确修订版：**数据不再稀缺，稀缺的是物体级零样本的方法与评测纪律**。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（零样本缺口归因）**：未见物体抓取失败中，不变性/辨识/动作/覆盖四类缺口各占多少？用 L17 的 oracle 链能否稳定归因？（E637）
- **Q14（κ 的可辨识性与探测精度）**：视觉-only 预升力探测能否在 2–3 步内把 κ̂ 估到可决策精度（Spearman ≥0.7、相对误差 ≤30%）？其精度如何随遮挡/运动模糊退化？（E635）
- **Q15（生成物体的 sim-to-real）**：用 `unitree_sim_isaaclab_usds` + 物理域随机化生成的新形状，其零样本抓取收益能否迁移到真实未见物体，还是被接触物理的 sim-to-real 差距吞掉？（E638）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（抓取即假设检验）**：每个抓取假设必须携带可证伪成功判据与验证动作；无验证计划的抓取不得进入运输相位。
- **P14（估可辨识量，不估不可辨识量）**：只在线估计 κ / 滑移裕度等控制相关充分统计量；不得把「质量估计」「摩擦估计」当作可学习目标；未见物体一律路由到几何/物理不变量，而非外观检索。
- **P15（最坏情况优先 + 兜底）**：物理未知时选「可容忍 κ 上界最大」或笼式抓取；任何高精度对跖抓取都必须配一个「换笼式 / 重抓更深」的兜底介入。

## 5. 本轮最大风险

**把「抓取 = 可在线辨识的假设检验」当作地基，前提是滑移裕度能被视觉探测到；一旦接触物理的 sim-to-real 差距让 κ̂ 估计系统性失真，整个零样本抓取方案会退化为「要么捏碎、要么滑落」的两难，稳健选择反而变成保守误时。** 次要风险：过度收紧压碎易碎物、探测吃步骤分、生成物体只在仿真纹理上过拟合。

### IP-16 · GraspHypothesis 抓取假设 + 稳健选择 + 探测 + 裕度调节（P0，新）

- **动机**：抓取是零样本泛化唯一「必须接触未知」的信息闸门（§1 灵感 1）。IP-14 的候选按几何供抓性排序，但未处理物理不确定性；SlipGuard 只报警不调节；两者之间缺一个「选择—验证—调节」的闭环。

## 7. 推导（新增引理 L14–L17；L1–L13 沿用第 1–3 轮）

**引理 L14（抓取物理的可辨识性边界）** 在无力/触觉传感、仅头/腕相机 + EE 位姿 + 夹爪标量的观测集下，平行夹爪准静态无滑移条件为平动 `2μN ≥ m·a_eff`、转动 `μN·w ≥ m·a_eff·d`。两式相除得「转动先于平动滑移 ⇔ d/w > 1/2」；统一写成 `N* = κ·a_eff·max(1/2, d/w)`，`κ = m/μ`。故 `m` 与 `μ` 只以比值 κ 与几何量 d/w 进入动力学，**各自不可辨识**；可辨识且控制相关的是 κ（等价于 N\*）。⇒ 任何「估质量/估摩擦」模块在设计上不可辨识；正确目标是在线估计并调节滑移裕度 `s = N − N*`。∎

**引理 L15（稳健抓取选择）** 设 κ 的先验支撑为 K，抓取候选 g 的几何决定 `κ_max(g) = N_max/(a_eff·max(1/2, d_g/w_g))`，则 g 不滑移 ⇔ `κ ≤ κ_max(g)`。零样本最坏情况最优抓取 `g* = argmax_g min_{κ∈K} 1[κ ≤ κ_max(g)] = argmax_g κ_max(g)`（最大化可容忍 κ 上界）。若存在笼式抓取 `g_c`，其成功判据为几何包容、不依赖 κ 在扰动界内，则 `g_c` 对 K 的任意值鲁棒，应优先于高精度对跖抓取。⇒ 零样本抓取的排序键是稳健裕度 `κ_max` 或笼式包容性，而非外观/名义几何。∎

**引理 L16（抓取探测的盈亏平衡，接 L13）** 设预升力探测耗 `s_p` 步，得到 κ 的噪声估计 `κ̂`（方差 σ²）；若 `κ̂ > κ_max(g)` 则在运输前换到更稳健抓取 `g'`（切换代价 `s_sw`），否则直接运输。探测净收益 `Δ = P(κ>κ_max(g)|κ̂)·(C_fail − s_sw) − s_p`，盈亏平衡概率 `P* = s_p/(C_fail − s_sw)`。⇒ 仅当「先验宽（新物体）+ 抓取激进（κ_max 低）+ 运输失败代价高」时探测划算；熟悉物体或保守抓取跳过探测（P12 白名单的特化）。∎

**引理 L17（零样本缺口望远镜分解）** 取信息 oracle 链 `O_0 ⊂ O_1 ⊂ O_2 ⊂ O_3`（外观→几何→几何+探测→几何+探测+裕度调节），记 `R(O)` 为未见分布成功率。则可被信息闭合的缺口严格望远镜分解：`G_closed = R(O_3) − R(O_0) = Σ_{k=1}^{3} [R(O_k) − R(O_{k−1})]`，每项归因到不变性/辨识/动作；剩余 `R_in − R(O_3)` 为覆盖缺口 G_cov（先验支撑外，不可约）。⇒ 零样本缺口可被逐项归因（E637），「泛化差」变成可分配预算。∎
