# 第 44 轮（新一轮灵感循环首轮） · Transfer-Cert × Agent-Cert：迁移的是「骨架」不是「有效性」，智能体是「持证决策者」（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形条件覆盖 + 多用户契约空集」，但它仍压着两个未言明的假设：**(H3) 每个域/机器人/任务都从零独立认证**——CKB 只是检索索引，知识无法降低新域的认证成本；**(H4) 智能体只是证书的被动守卫对象**——它从不决定「何时取证、向谁借、何时撤销」。本轮灵感词「迁移学习」「智能体」精准命中这两个假设：迁移学习迫使我们回答**什么能跨域复用、什么绝不能复用**；智能体迫使我们把**认证本身升级为智能体的一个可决策动作**。一句话：**迁移的是证书骨架、认证先验与搜索起点；绝不迁移证书的有效性——有效性永远在目标域重签。**

## 0. 直觉与动机

**灵感 1（迁移学习 → 迁移「骨架」，不迁移「有效性」）**：传统迁移学习搬的是权重/表示，默认源域知识在目标域仍有统计效力。证书不同：证书是**带 soundness 承诺的断言**，源域的承诺对目标域没有任何逻辑约束。若直接把源证书搬到目标域，域差异会静默吃掉 margin，制造「看起来有证、实际失效」的最坏故障。于是本轮把迁移拆成三层：**骨架（守卫结构/不变式模板/搜索树摘要）可迁移；先验（margin 热启动、采样分布）可迁移；有效性（证书本身）不可迁移**。目标域证书必须用目标域数据重签；迁移的收益体现为**重签所需样本复杂度下降**，而非「免于重签」。这把迁移学习从「赌域相关」降级为「只借结构、不借承诺」。

**灵感 2（智能体 → 认证是动作，不是背景流程）**：现有系统里认证是运行时后台，智能体只被告知「能不能做」。真实智能体应主动推理：「当前证书覆盖这个边缘场景吗？值不值得花 20ms 补证？能否向同伴借一个骨架少走弯路？」于是把认证建模为**带信息价值的决策动作**：act / acquire / verify / degrade / ask-for-help，按 VoI 与信任预算选择。这同时把智能体从「证书消费者」升级为「证书生产者」——它产出的骨架与反例回流 CKB，形成真正的迁移飞轮。

**灵感 3（耦合 → 多智能体共享骨架 = 污染高速公路）**：骨架可迁移，因此天然会被多智能体共享；共享越快，错误先验传播越快。负迁移最隐蔽的形态不是「借来的证书错了」，而是「借来的先验让验证者只盯着错误区域，留下先验自认为安全的验证盲区」。因此必须引入**溯源 DAG + 信任半环 + 有效性级联撤销**，并明确区分 validity 依赖与 skeleton 依赖：撤销源证书时，前者必须级联撤销，后者只需标记建议重验。

**耦合升级**：TCE（迁移证书引擎）负责域代数、骨架抽取、目标域重签与负迁移闸门；ACP（智能体证书协议）把认证变成智能体的可规划动作，并管理请求/授予/撤销与信任账本；CPV（证书溯源验证器）在仿真里注入 Byzantine 节点与域漂移，验证污染传播与级联撤销。四层架构由 v8 的「仿真-检索-边缘飞轮 + 人格 + 并发」升级为 v9 的「+ 迁移证书层 + 智能体证书协议层」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（证书域与边际函数）**：证书 c = (φ, D(c), m_c, prov)。D(c) ⊆ Θ 为有效域（环境/任务/本体/硬件参数）；m_c: D(c) → R≥0 为边际函数；c 在 θ∈D(c) 上 sound 当且仅当 m_c(θ) ≥ θ_safe。证书强弱由 (D 的大小, min_{θ∈D} m_c) 偏序刻画：**域越大、margin 越薄，证书越弱**，且弱证书不能推出强证书。

**定义 45（证书骨架与重签算子）**：骨架 S(c) = (φ, 不变式模板, 守卫结构, 搜索树摘要, 反例集)，只保留与域无关的结构。迁移算子 T_{s→t}: c_s ↦ (S(c_s), D_t)，随后**必须** c_t = ReSign(S(c_s), D_t, Data_t)。**重签定理**：若 D_t 覆盖目标域，且重签在目标域数据上满足校准/覆盖条件，则 c_t 的 soundness 与 c_s 无关——源证书的错误不传递。**命题（样本复杂度收益）**：以骨架为先验的主动认证，达到 margin ε 所需目标样本数满足 N_t ≤ N_0/(1+ρ(S))，ρ(S) 为骨架带来的信息增益；ρ(S)≤0 时迁移无收益，必须退回独立认证。

**定义 46（负迁移风险证书）**：设迁移假设 H_{s→t} 断言 P_t 与 P_s 的差异被 δ 界定。风险证书 r(H) 给出上界 P(m_t < θ_safe | H) ≤ ε 的置信度；用重要性加权、两样本检验与共形校准共同估计。**负迁移闸门**：若 r 的置信上界 > ε_neg，则拒绝迁移。**关键性质**：负迁移一旦以「未重签的源证书」形式进入行动即属 unsound，任何事后证书都无法补救——因此闸门必须在行动前。

**定义 47（智能体认证决策与信息价值）**：智能体状态 s，动作集 A = A_act ∪ A_cert ∪ {degrade, ask}。认证动作 a 有成本 κ(a) 与信息增益 IG(a)。**信息价值** VoI(a) = E[风险下降 | a] − λ·κ(a)，在信任预算 τ 约束下取 argmax。**安全约束**：任何 a∈A_act 必须携带有效租约（定义 41）且 m≥θ；否则只能 degrade/verify/ask。**定理（决策不破坏 soundness）**：若 act 仅在持证时可选，且认证只增加信息、不改阈值，则任意策略执行保持证书不变式 I。

**定义 48（证书溯源 DAG 与信任半环）**：溯源图 G=(V,E)，节点为证书/骨架/反例，边带类型 dep∈{validity, skeleton} 与衰减。信任在半环 (⊕=max, ⊗=min) 上传播：trust(v)=min(直接证据(v), max_{u→v} trust(u)⊗decay(e))。**污染界**：若 f 个 Byzantine 节点、信任阈值 β，则错误**有效性**被采纳必须存在一条 trust≥β 的路径且终点跳过重签；由于定义 45 强制重签，错误有效性无法沿 skeleton 边传播（**骨架可污染，有效性不可污染**，除非接收方违约）。

**定义 49（级联撤销的完备性与最小性）**：撤销 c_s 时，validity 依赖的后代必须做可达闭包撤销；skeleton 依赖的后代只需标记 `reverify-suggested`，不得误撤。**撤销声性**：撤销闭包覆盖所有 validity 后代；**撤销最小性**：不触碰任何 skeleton-only 后代。**命题**：若依赖类型声明正确，则级联撤销在 O(|V|+|E|) 内同时满足完备性与最小性。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 TRANSFER-CERT-ENGINE（迁移证书引擎 TCE）
1. **证书域代数**：域表示（参数盒 + 分布约束）、包含/交判定、域差 δ 估计（域分类器 + 重要性权重 + MMD 上界），域差始终取**置信上界**而非点估计。
2. **骨架抽取与检索**：从 CKB 取最近骨架，估计信息增益 ρ；ρ≤0 直接拒绝迁移，杜绝「为迁移而迁移」。
3. **目标域主动重签**：以骨架先验初始化采样，按 margin 不确定性选点，迭代至覆盖/校准达标，产出 c_t 并重算域与 margin；**有效性从头重签**。
4. **负迁移闸门**：风险证书上界 ≤ ε_neg 才允许把骨架作为先验；否则独立认证。域差不可证时默认关闭迁移。

### 2.2 IP-61 AGENTIC-CERT-PROTOCOL（智能体证书协议 ACP）
1. **认证动作空间与 VoI 规划器**：act/acquire/verify/degrade/ask 与 IP-39 规划器共享代价模型，VoI 同时计入风险下降与信任预算消耗。
2. **请求/授予/撤销协议**：request(skeleton|evidence|lease) → provenance 检查 → 域差估计 → grant（附 provenance 与信任扣减）；授予方不得替接收方担保有效性。
3. **信任账本**：agent trust 与 persona trust 分离；不可自授信；只能单调降级；跨智能体租约带域差衰减项。
4. **协作认证分工**：多智能体按集合覆盖/子模最大化分配待验区域，避免重复采样，把「多智能体」从算力叠加变成认证加速。

### 2.3 IP-62 CERT-PROVENANCE-VALIDATOR（证书溯源验证器 CPV）
1. **溯源 DAG 构造与审计**：每次 grant/revoke 写入带类型的审计边，支持事后重放。
2. **污染仿真**：注入伪造 δ、投毒骨架、Byzantine 证书，测传播深度、覆盖面与恢复率。
3. **级联撤销验证**：完备性（validity 后代零遗漏）+ 最小性（skeleton-only 零误撤）+ 传播时延。
4. **负迁移对抗**：非平稳漂移、标签投毒、域分类器规避，检验闸门在对抗下的假阴性。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

| 实验 | 指标 | 门槛 |

| E95 重签 soundness | 目标域实机违例；重签证书与独立认证一致率 | 0 起；≥99% |

回退：E95/E97 不达标 → 关闭证书骨架迁移，仅迁移超参与结构，证书全量独立认证；E96 无收益 → 不迁移；E98 污染 → 关闭 peer 共享，只允许中心 CKB 且强制重签；E99 撤销不达标 → 缩短租约并保守全撤销；E100 无 VoI 收益 → 固定认证策略；任何红线失败 → 熔断回退 v20。

## 5. 本轮最大风险

**一句话**：迁移的样本效率恰恰来自「不处处验证」，而骨架先验会把主动认证的采样集中在预测低 margin 区域，一旦域差上界被低估，就会留下「先验自认安全、实际未覆盖」的验证盲区，再叠加多智能体骨架共享把错误先验高速扩散——因此 E95（重签 soundness）、E97（负迁移闸门）、E98（污染）必须设为红线，默认回退到「只迁移超参与结构、证书全量独立重签、禁止 peer 共享」这条永远不赌域相关的底线。

| S(c) | 证书骨架 | φ、不变式模板、守卫结构、搜索树摘要、反例集 |
| T_{s→t} | 迁移算子 | 只映射骨架与目标域，随后强制 ReSign |
| ρ(S) | 骨架信息增益 | 决定迁移是否有样本收益；ρ≤0 不迁移 |
| r(H) | 负迁移风险证书 | P(m_t<θ_safe) 的置信上界 |
| VoI(a) | 认证信息价值 | E[风险下降] − λ·κ(a) |
| dep∈{validity,skeleton} | 依赖类型 | 决定撤销是否级联 |
| trust(v) | 溯源信任 | 半环 (⊕=max, ⊗=min) 传播 |
| λ_D·δ | 域差衰减 | 跨域租约中与时间衰减并列的保守项 |

## 2. 关键算法（伪代码）

### IP-60 TCE：骨架迁移、负迁移闸门与目标域重签
```
def transfer_certificate(c_s, target_domain, data_t, eps_neg):
    S = extract_skeleton(c_s)                  # 只抽结构，不含有效性
    rho = info_gain(S, target_domain)          # 估计骨架先验的样本收益
    if rho <= 0:
        return independent_certify(target_domain, data_t)   # 无收益 => 不迁移
    r = negative_transfer_bound(S, c_s.domain, target_domain)
    if r.upper() > eps_neg:                    # 负迁移闸门：域差取置信上界
        return independent_certify(target_domain, data_t)
    samples = active_certify_campaign(S, target_domain, data_t)  # margin 不确定处采样
    c_t = re_sign(S, target_domain, samples)   # 目标域重签：有效性从头来
    c_t.prov = Provenance(parents=[c_s.id], dep='skeleton')  # 骨架依赖，非 validity
    return c_t
```

### IP-61 ACP：VoI 认证决策、信任传播与级联撤销
```
def agent_cert_decision(state, cert, trust_budget):
    if cert is None or not lease_valid(cert.lease, theta, now()):
        acts = {verify, acquire, degrade, ask}
    else:
        acts = {act, verify, acquire, degrade, ask}
    best = max(acts, key=lambda a: voi(a, state, cert) - cost(a))
    if best is act and holds_valid_cert(cert, state):
        return act(best.plan)
    return execute_cert_action(best)           # 认证只增信息，绝不放宽阈值

def propagate_trust(G, beta):
    for v in topo_order(G):
        direct = evidence(v)
        inherited = max((trust(u) * decay(u, v) for u in pred(v)), default=0)
        trust[v] = min(direct, inherited)
        admissible[v] = trust[v] >= beta and has_re_sign_path(v)
    return admissible

def cascade_revoke(G, c_s):
    validity_desc = reachable(G, c_s, edge='validity')   # 可达闭包
    for v in validity_desc:
        revoke(v)
    for v in reachable(G, c_s, edge='skeleton'):
        if v not in validity_desc:
            mark_reverify(v)                     # 仅建议，不误撤 skeleton-only
```

### IP-58/51 升级：跨域租约与双衰减守卫
```
def cross_domain_lease_guard(lease, domain_gap, t):
    m_eff = lease.m - lease.lam * (t - lease.tau) - lease.lam_D * domain_gap
    return m_eff >= theta

def acquire_transfer_lease(S, target_domain, theta, kappa):
    delta = domain_gap_upper_bound(S, target_domain)   # 置信上界，非常数点估计
    lam_D = L_m * delta                                 # 域差衰减率
    return Lease(m=S.m_prior, tau=monotonic_now(), lam=0.0, lam_D=lam_D,
                 kappa=kappa, domain=target_domain)     # margin 由重签写入
```

## 5. 风险与缓解（增量）

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 域差 δ 上界被低估，骨架先验制造「验证盲区」，负迁移静默失效 | 高 | E95/E97 红线；δ 取置信上界；对抗漂移测试；盲区区域强制均匀补采 |
| 多智能体骨架共享成为污染高速公路，错误先验快速扩散 | 高 | E98 红线；骨架可污染但有效性强制重签；溯源 DAG + 信任半环；限 1 跳扩散 |
| 撤销语义混淆，valitidy/skeleton 依赖标注错误导致漏撤或误撤 | 高 | 依赖类型由工具生成；E99 完备性+最小性双门槛；审计重放 |
| 主动重签的先验采样集中在低 margin 区，高 margin 边缘反而欠采样 | 中-高 | 保留固定比例均匀采样；覆盖/校准双检；未覆盖即拒绝签发 |

| 骨架蒸馏剥离了必要域约束，导致骨架过强、重签被误导 | 中 | 骨架只作先验不作约束；重签数据独立；蒸馏前后回归 |

## 6. 本轮最大风险

**一句话**：迁移的样本效率恰恰来自「不处处验证」，而骨架先验会把主动认证的采样集中在预测低 margin 区域，一旦域差上界被低估，就会留下「先验自认安全、实际未覆盖」的验证盲区；再叠加多智能体共享骨架把错误先验高速扩散，可能同时造成「静默负迁移」与「污染级联」——因此 E95（重签 soundness）、E97（负迁移闸门）、E98（污染）必须设为红线，默认回退到「只迁移超参与结构、证书全量独立重签、禁止 peer 共享」这条永远不赌域相关的底线。
