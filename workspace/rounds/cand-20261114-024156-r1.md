# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「少样本学习」×「机械臂」）

> R69 把不确定性分成 aleatoric / epistemic，并让机器人学会「问」：看、触、提问。但它仍有一个隐含的封闭世界假设——**所有可能的模态都已在流策略的假设空间里**；交互只能在这些模态之间做选择，不能发现「根本没有这个模态」。
>
> R69 自陈的最大风险正来自这里：模态权重未校准，系统会自信地追问一个幻影。换句话说，**R69 能问「是 A 还是 B」，却问不出「是不是还有 C」**。
>
> 本轮两个灵感补上这个缺口：
> - **少样本学习**给出扩展假设空间的机制：从 K 个带标签的样本构造新技能/新模态，而不必重训大模型；
> - **机械臂**给出一个被忽视的事实：具身系统可以**自己生产标签**——试抓一次就知道成功/失败，接触一次就知道刚度/滑移，推一下就知道质量分布。机械臂不只是执行器，它还是一台「物理实验机」。
>
> 核心命题：把不确定性再拆出一类 **U_ont（结构性不确定性：现有模态集合无法解释当前观测）**；U_ale 走 R68 保守、U_epi 走 R69 交互、U_ont 走**有界少样本物理试错 + 上下文适配 + 保形验收**；只有验收通过的新技能才允许进入技能库，否则回退到 R69/R68。命名 **TRIAL-RAS**（Test-time Rapid In-context Adaptation & Learning for Risk-adaptive systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个模态根本不存在时，我能不能安全地试出来、并且敢不敢用**」——R69 向人求证，R70 向物理求证。

## 0. 直觉与动机

**灵感 1（少样本学习 → 假设空间必须能被打开）**
直觉：R69 的 VoI 交互是在一个固定的模态集合 M 上做贝叶斯更新；如果真实世界出现一个从未见过的物体/接触模式/任务阶段，M 里根本没有正确项，那么再多的「看/问/触」也只能在错误候选里挑一个最不差的。少样本学习提醒我们：人类遇到全新物体时不会重新训练大脑，而是拿两三次示范就临时拼出一个新类别。R70 要把这种「临时开一个新模态」的能力放进闭环，而不是把封闭集合当作世界本身。

**灵感 2（机械臂 → 试错本身就是测量，标签是免费的）**
直觉：语言模型要从人类反馈里拿标签，代价高且可能被骗；机械臂不同——它推一下积木，积木倒没倒就是标签；它抓一次杯子，滑没滑就是标签；它压一下表面，力-位移曲线就是标签。**一次设计良好的物理 trial 同时是动作、探询和自标注**。这把少样本从「被动接收 K 个样本」升级为「主动设计 K 个最有信息量的物理实验」。但每次 trial 也可能打翻、撞坏、卡死，所以「会试」必须和「试得起」一起设计。

**灵感 3（上下文适配 → 保持实时零学习写操作）**
直觉：R68/R69 的一条硬不变式是控制回路里不做学习写操作。若 R70 在环内跑梯度下降，就会破坏可预测性与实时性。少样本学习里的 in-context / prototype / closed-form head 给出一条出路：**冻结主干，只在前向时用 K 个支持样本做非参数比较**；真正的技能提交发生在 episode 边界，事务化、可回滚。于是「学」不进入 2.6ms 的控制回路，只进入秒级的「课间」。

**灵感 4（保形预测 → 用有限样本覆盖保证替代不可信的 ECE）**
直觉：R69 的最大风险是模态权重未校准。小样本下 ECE 本身估计方差极大，越修越不可信。保形预测（conformal prediction）换一个承诺：不要求模型概率准，只要求**在可交换性下，预测集以 ≥1−α 的概率覆盖真值**，且这是有限样本、分布无关的。对 R70 来说这正好：新技能被接受前，必须在留出的 query 上通过覆盖/集大小检验；否则宁可 abstain。这把「我觉得学会了」变成「在统计上敢用」。

**灵感 5（试错是双刃剑 → 不可逆性与支持集投毒）**
直觉：R69 的交互最多是「问错」，R70 的 trial 可能「做坏」——不可逆动作（打碎、跌落、过力）是新的风险面。同时，支持集可能被污染：人类示范可能故意教错，自标注可能被传感器故障带偏。因此必须同时交付：安全 trial 护盾（最坏情况风险 + 不可逆动作禁令）、支持集来源追踪、鲁棒聚合、以及「验收失败即回滚」的事务纪律。否则少样本不是在扩展能力，而是在给错误发证书。

**为什么不是简单的 meta-RL**：meta-RL 通常优化「多试几次后的回报」，它默认试错成本可接受；真实机械臂上，前几次 trial 恰恰是最危险的。R70 的目标函数不是「学得快」，而是「**在不可逆约束下，用最少的 trial 学到可被统计验收的技能；验收不过就不学**」。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（TRIAL-RAS 总览）** TRIAL-RAS = (TUS, ESS, ICA, TSS, ASS, CAG, SKL, FSP, EPW, VQAuditor-F)。四条不变式：
(i) **实时零梯度写操作**：控制回路内只读冻结主干与已提交技能；任何适配/提交只发生在 episode 边界，事务化且可回滚；
(ii) **trial 预算与不可逆约束**：单 episode 的物理 trial 次数 ≤ K_max、累计风险预算 ≤ ε_trial、不可逆动作集 𝒜_irr 内动作一律禁止；
(iii) **保形验收**：新技能进入技能库前必须通过 CAG 的有限样本覆盖检验，验收失败即 abstain，不得「先用了再说」；
(iv) **来源与回滚**：每个技能携带支持集哈希、来源标签与 undo 计划；任何时刻可原子回滚到上一版本。

**定义 311（三重不确定性）** 在 R69 的 (U_ale, U_epi) 之外引入结构性不确定性：
- U_ale = Σ_k ŵ_k tr(Σ_k)：模态内噪声，不可约，走 R68 λ floor；
- U_epi = H_mode·g(Δ_min)：已知模态间的歧义，可约，走 R69 交互；
- **U_ont = 1 − p_nov(o)**，其中 p_nov 为观测 o 相对已知模态支持集的保形新颖性 p 值：
  p_nov(o) = (1 + Σ_{i=1}^{n} 1[s(o) ≥ s(o_i)]) / (n+1)，s(o) = min_k d(o, supp(m_k)) / √(trΣ_max)。
  p_nov 小 ⇒ 观测落在已知模态支持之外 ⇒ 不是「选哪个」，而是「没有哪个」。
三者语义不同、通道不同：U_ale→收紧，U_epi→问/看/触，U_ont→有界试错或拒答。

**定义 312（自标注支持集）** 一次物理 trial 产生四元组 (s_i, a_i, y_i, ρ_i) ∈ D_sup：s_i 为 trial 初始状态，a_i 为执行的短时动作，y_i 为结果标签（抓取成功/滑移/力超限/位姿误差等，由本体感觉、力觉、任务谓词自动判定），ρ_i 为来源标签（self / human / sim）。只有 ρ_i ∈ {self, human-verified} 且通过来源校验的样本可进入验收集；sim 样本只用于 meta-training，不得单独支撑验收。

**定义 313（上下文少样本适配器 ICA）** 冻结编码器 φ（复用 R68 MTM trunk），对每个候选技能 c 构造原型 μ_c = (1/|D_c|)Σ_{(s,a)∈D_c} φ(s,a)。K-shot 预测：
p(y=c | o) = softmax_c( −d(φ(o), μ_c)/T )，
或用闭式 ridge head W = (ΦᵀΦ+λI)^{-1}ΦᵀY（只在 episode 边界计算，不在控制回路内）。
**不做 SGD、不更新 φ、不产生环内写操作**；适配器是 episode-local 的只读对象。

**定义 314（trial 动作与微 episode）** 信息动作扩展为 g_trial = (a_probe, τ_trial, y_oracle) ∈ 𝒜_trial，其中 a_probe 是一段受约束的短时探测动作，τ_trial 为其时长，y_oracle 为该 trial 的自动标注谓词。一次 trial 是「动作 + 测量 + 标签」的最小单元；trial 序列构成一个微 episode。trial 与 R69 的 g_gaze/g_probe/g_ask 并列，但**会改变世界状态**，因此风险等级更高。

**定义 315（安全 trial 护盾 TSS）** 给定保守动力学集合 ℳ_con（参数区间 + 未建模动态界 + 接触刚度界），trial 的最坏情况风险：
R_wc(g) = max_{M∈ℳ_con} E[ℓ(x_{t+τ}, a_{t:t+τ}) | M, g]。
允许 trial 当且仅当 R_wc(g) ≤ ε_trial、g ∩ 𝒜_irr = ∅、且存在可执行的回退/人接管路径；否则该 trial 作废，转「请求人类示范」或「不学，按 R69 保守执行」。用控制屏障函数（CBF）把 R_wc 约束落实为对 a_probe 的逐时刻硬约束。

**定义 316（主动支持集选择 ASS）** 候选 trial 集合 G，选子集 S（|S|≤K_max）最大化期望保形覆盖增益与任务信息增益，同时惩罚风险与成本：
S* = argmax_{S⊆G, |S|≤K_max} E[ΔCov(S) + β·IG(M;y|S) − λ_r Σ_{g∈S} R_wc(g) − λ_c Σ c(g)]。
在可交换性近似下 ΔCov 关于 S 单调次模，故贪心达到 (1−1/e) 近似（引理 21）。

**定义 317（保形验收门 CAG）** 把 D_sup 划分为校准集 D_cal 与查询集 D_q。非一致性分数 s(x,y)（如 −log p(y|x) 或原型距离）。取
q = Quantile( {s(x_i,y_i)}_{i∈D_cal}, ⌈(n+1)(1−α)⌉/n )，
预测集 C(x) = { y : s(x,y) ≤ q }。验收条件：
(a) 在 D_q 上经验覆盖率 ≥ 1−α−δ；
(b) 单标签查询比例 ≥ 1−γ（集合不能总是模棱两可）；
(c) 风险受控版本 CRC：E[ℓ·1{accept}] ≤ ε_conf；
(d) R_wc(使用新技能) ≤ R69 保守策略的风险上界。
任一不满足 ⇒ **ABSTAIN**，U_ont 保持未消解，回退 R69/R68。CAG 给出的是分布无关、有限样本的覆盖承诺；它不承诺新技能「因果正确」，只承诺「在支持集同分布假设下不轻易骗自己」——这个边界必须写进证书。

**定义 318（新技能证书 J_NEW）** J_NEW = (K, α, coverage_emp, mean_set_size, risk_bound_wc, reversibility, provenance_hash, source_mix, trial_cost, cag_ver)。Valid ⇔ K ≥ K_min ∧ coverage_emp ≥ 1−α−δ ∧ mean_set_size ≤ m_max ∧ risk_bound_wc ≤ ε_trial ∧ reversibility = true ∧ provenance_hash 可核验。

**定义 319（技能库与版本化 SKL）** 技能库为带版本的有限集合：SKL = {(skill_id, prototype, J_NEW, parent_version, undo_snapshot)}。新技能只能 append，不能覆盖旧技能；技能选择按「已认证 + 当前观测的保形预测集唯一」进行。回滚是原子的：恢复 parent_version 与对应安全包络。

**定义 320（支持集投毒与鲁棒聚合 FSP）** 污染模型：支持集中比例 δ_p 的样本标签被恶意翻转，或人类示范故意教错，或自标注被传感器缓变故障带偏。鲁棒聚合采用：来源分层（self/human/sim 不混池）、trimmed/median 原型、leave-one-out 影响函数筛除高杠杆样本、标签翻转检测（双向预测一致性）。ℰ_TRIAL = ℰ_FLUID × ℰ_poison × ℰ_irreversible × ℰ_self_label。

**定义 321（episode 边界写协议 EPW）** 所有适配与提交走两阶段事务：prepare（在影子副本上构造新技能与证书）→ verify（CAG + 安全包络检查）→ commit（原子替换技能库版本）或 abort（丢弃影子副本）。控制回路只读 committed 版本；提交期间旧版本持续可用。实时不变式因此保持。

**定义 322（三级退避）** U_ale > τ_ale ⇒ R68 收紧；U_epi > τ_epi 且 U_ont ≤ τ_ont ⇒ R69 交互消歧；U_ont > τ_ont 且预算/安全允许 ⇒ TRIAL 少样本试错；若 trial 被 TSS 否决、CAG abstain、或 K 不足 ⇒ 视 U_ont 为不可约，走 R68 最保守（λ = λ_floor(U_ale + U_epi + U_ont)）。安全侧逐级单调不降。

**定义 323（trial 策略的元训练）** 在任务分布 p(T) 上做 episodic 元训练：内循环用 K 个支持样本做 in-context 适配，外循环优化「适配后风险 + trial 风险/成本」。目标：
min_ψ E_{T~p}[ E_{D_sup~π_ψ(T)} ( R_adapt(D_sup) + λ_r R_wc(trials) + λ_c |D_sup| ) ]。
元训练只发生在离线/仿真；部署时 π_ψ 只输出候选 trial，仍须逐个过 TSS。元训练学到的是「怎样用最少的物理实验问出最多信息」，而不是「跳过安全」。

**定义 324（参与式审计 VQAuditor-F 与 J_TRIAL）** 审计对象新增：支持集来源是否真实、trial 是否越界、CAG 是否被重复使用同一批数据「刷」覆盖、技能库是否可回滚、错误技能是否被及时冻结。J_TRIAL = (J_FLUID, J_NEW, trial_log_hash, rollback_ready, cag_reuse_count, library_version)。Valid ⇔ Valid(J_FLUID) ∧ Valid(J_NEW) ∧ rollback_ready ∧ cag_reuse_count ≤ 1。

## 2. 关键算法骨架

```python
# IP-264 TUS：结构性新颖性检测（在 R69 的模态集合之外判断「没有哪个」）
def structural_novelty(o, known_modes, cal_scores):
    s_o = min(distance(o, m.support) for m in known_modes) / sqrt(max_trace(known_modes))
    p_nov = (1 + sum(s_i >= s_o for s_i in cal_scores)) / (len(cal_scores) + 1)
    return 1.0 - p_nov                      # U_ont：越小越「已知」，越大越「没学过」

# IP-265/268 ESS+ASS：安全地选 trial 并自标注
def collect_support(M, o, K, budget):
    candidates = M.ass.propose_probes(o)                 # 推/抓/压/抬，短时微动作
    selected = []
    for g in candidates:
        if len(selected) >= K or not budget.allow(g): break
        if not M.tss.certify(g, o):                      # 最坏风险 + 不可逆禁令 + CBF
            continue
        y = M.ess.execute(g, o)                          # 动作 + 本体/力觉自动标注
        selected.append((o, g, y, provenance='self'))
    return selected

# IP-266 ICA：冻结主干上的 K-shot 上下文适配（环内只读，无梯度）
class InContextFewShot:
    def fit(self, support):
        self.mu = {c: mean(phi(s, a) for (s, a, y, _) in support if y == c)
                   for c in labels(support)}
        return self
    def predict(self, o):
        d = {c: norm(phi(o) - self.mu[c]) for c in self.mu}
        return softmax({c: -v / self.T for c, v in d.items()})

# IP-269 CAG：保形验收（有限样本覆盖，失败即 abstain）
def conformal_accept(support, query, alpha, delta, risk_budget):
    cal, val = split_by_provenance(support)              # self/human 分层
    scores = [nonconformity(x, y) for (x, y, _, _) in cal]
    q = quantile(scores, ceil((len(cal) + 1) * (1 - alpha)) / len(cal))
    sets = [{c: s(x, c) <= q for c in classes} for (x, _, _, _) in val]
    coverage = mean(true_label(x) in C for x, C in zip(val, sets))
    single = mean(len(C) == 1 for C in sets)
    risky = risk_upper_bound(M, support)                 # CRC：风险上界
    ok = (coverage >= 1 - alpha - delta and single >= 1 - gamma
          and risky <= risk_budget)
    return ok, J_NEW(...) if ok else None

# IP-271 EPW+SKL：事务化提交/回滚（只在 episode 边界写）
def commit_skill(M, adapter, cert):
    shadow = M.skl.fork()                                # prepare
    shadow.add(adapter, cert)                            # 影子副本
    if not M.cag.reverify(shadow, cert):                 # verify
        shadow.abort(); return None
    return M.skl.atomic_commit(shadow)                   # commit（旧版本保留）

# IP-275 主闭环：在 R69 的三级处置上再加一层「结构性未知」
def TRIAL_RAS_round(M, o):
    z, o_cal = M.mtm.forward(o)                          # 复用 R68/R69
    U_ale, U_epi, modes = M.r69.estimate_uncertainty(o)
    U_ont = M.tus.structural_novelty(o, modes, M.cal_scores)
    # 1) 已知世界：完全走 R69
    if U_ont <= TAU_ONT:
        return M.r69.step(o, U_ale, U_epi, modes)
    # 2) 结构未知但试不起：不学，按最保守处理
    if not M.budget.allow_trial() or M.tss.irreversible_risk(o) > EPS_TRIAL:
        return M.r69.conservative(o, lam_floor(U_ale + U_epi + U_ont))
    # 3) 选 trial → 自标注 → 上下文适配
    D_sup = collect_support(M, o, K=M.ass.K_star(o), budget=M.budget)
    if len(set(y for (_, _, y, _) in D_sup)) < 2:
        return M.r69.conservative(o, lam_floor(U_ale + U_epi + U_ont))
    adapter = InContextFewShot().fit(D_sup)
    # 4) 保形验收：不过就 abstain，不写库
    ok, cert = M.cag.evaluate(adapter, D_sup, query=M.query(o), alpha=M.alpha)
    if not ok:
        M.skl.freeze_suspect(o)                          # 记录幻影/污染，供审计
        return M.r69.conservative(o, lam_floor(U_ale + U_epi + U_ont))
    skill = commit_skill(M, adapter, cert)               # 仅在边界提交
    # 5) 用新技能执行，但风险上界不得高于 R69 保守
    lam = max(M.r69.floor(U_ale + U_epi), M.cag.risk_bound(cert))
    return M.r69.step_with_skill(o, skill, lam, U_ont_after=0.0)
```

## 3. 推导

**引理 19（少样本可辨识性的下界）** 设新模态与最近已知模态的分离度为 Δ，单样本噪声 σ-次高斯。任意基于 K 个自标注 trial 的判别器，在两模态等先验下的最坏错误率满足
err_K ≥ (1/4)·exp(−KΔ²/(8σ²))。
故要在置信 1−δ 下可靠区分，需要 K = Ω((σ²/Δ²)·log(1/δ))。系：**当 Δ ≲ σ 时，增加 K 的边际收益指数衰减，正确做法不是「再试一次」，而是 abstain 或改变探针让 Δ 变大**——这与 R69 引理 16「只有可分的歧义才值得交互」同构，但作用于假设空间而非模态身份。

**引理 20（污染支持集下的保形覆盖）** 若支持集污染率为 δ_p 且污染破坏可交换性，则标准 CAG 的覆盖率下界退化为 1−α−δ_p；采用来源分层 + trimmed 非一致性分数后，覆盖下界为 1−α−δ_p·ρ_trim + o(1/√n)，其中 ρ_trim 为被修剪污染样本比例。系：**保形门必须分层，不能把人类示范与自标注混池**；否则一个恶意示范可以按比例稀释覆盖保证。

**引理 21（主动 trial 选择的次模性）** 在可交换性近似下，期望覆盖增益 ΔCov(S) 关于 S 单调次模；风险与成本为模函数。故带预算的贪心选择达到 (1−1/e)·OPT。系：trial 不值得「平均撒」，而值得「先选最能改变预测集大小的那几个」——这为 ASS 的亚毫秒贪心提供依据。

**定理 18（TRIAL 严格包含 R69/R68）** 在定义 317 的验收条件与定义 322 的三级退避下，任意状态 s 上 TRIAL 的期望风险 ≤ R69；当 U_ont ≤ τ_ont、CAG abstain、TSS 否决或 K < K_min 时，TRIAL **逐指令等价**于 R69（再在 U_epi 消失时退化为 R68）。因此 R68/R69 是 TRIAL 在「不打开假设空间」边界上的退化，安全侧不做让步，能力侧只在「持证」后扩张。

**定理 19（试错安全、可回滚与实时不变式）** 若每个 trial 过 TSS（R_wc ≤ ε_trial、无 𝒜_irr、CBF 可行），每次提交走 EPW 两阶段事务，且控制回路只读 committed 版本，则：(i) 不存在不可逆违规；(ii) 任意失败/超时/污染可在 O(1) 次版本切换内回滚；(iii) 控制回路最坏执行时间与 R69 相同（适配与提交在边界，不在环内）。故「学习」不破坏 R68 的实时性与 R69 的无突变性。

## 3. 关键算法伪代码

```python
# IP-264 TUS：结构性新颖性（封闭集合之外）
def structural_novelty(o, known_modes, cal_scores):
    s_o = min(distance(o, m.support) for m in known_modes) / sqrt(max_trace(known_modes))
    p_nov = (1 + sum(s_i >= s_o for s_i in cal_scores)) / (len(cal_scores) + 1)
    return 1.0 - p_nov

# IP-265/268 ESS+ASS：安全地设计并执行 trial，自动标注
def collect_support(M, o, K, budget):
    selected = []
    for g in M.ass.propose_probes(o):                    # 抓/推/压/抬微动作
        if len(selected) >= K or not budget.allow(g): break
        if not M.tss.certify(g, o):                      # R_wc + CBF + 不可逆禁令
            continue
        y = M.ess.execute(g, o)                          # 本体/力觉/任务谓词自标注
        selected.append((o, g, y, 'self'))
    return selected

# IP-266 ICA：冻结主干上的 K-shot 上下文适配
class InContextFewShot:
    def fit(self, support):
        self.mu = {c: mean(phi(s, a) for (s, a, y, _) in support if y == c)
                   for c in set(y for (_, _, y, _) in support)}
        return self
    def predict(self, o):
        return softmax({c: -norm(phi(o) - self.mu[c]) / self.T for c in self.mu})

# IP-269 CAG：保形验收（失败即 abstain）
def conformal_accept(support, query, alpha, delta, gamma, risk_budget):
    cal, val = split_by_provenance(support)              # self / human 分层
    scores = [nonconformity(x, y) for (x, y, _, _) in cal]
    q = quantile(scores, ceil((len(cal) + 1) * (1 - alpha)) / len(cal))
    sets = [{c for c in classes if s(x, c) <= q} for (x, _, _, _) in val]
    coverage = mean(true_y(x) in C for x, C in zip(val, sets))
    single   = mean(len(C) == 1 for C in sets)
    ok = (coverage >= 1 - alpha - delta and single >= 1 - gamma
          and risk_upper_bound(M, support) <= risk_budget)
    return ok, (J_NEW(...) if ok else None)

# IP-272/270 EPW+SKL：事务化提交，失败即回滚
def commit_skill(M, adapter, cert):
    shadow = M.skl.fork()                                # prepare
    shadow.add(adapter, cert)
    if not M.cag.reverify(shadow, cert):                 # verify
        shadow.abort(); return None
    return M.skl.atomic_commit(shadow)                   # commit，旧版本保留

# IP-275 主闭环（继承 R69，插入「结构性未知」通道）
def TRIAL_RAS_round(M, o):
    z, o_cal = M.mtm.forward(o)
    U_ale, U_epi, modes = M.r69.estimate_uncertainty(o)
    U_ont = structural_novelty(o, modes, M.cal_scores)
    if U_ont <= TAU_ONT:                                  # 已知世界：完全走 R69
        return M.r69.step(o, U_ale, U_epi, modes)
    if not M.budget.allow_trial() or M.tss.irreversible_risk(o) > EPS_TRIAL:
        return M.r69.conservative(o, lam_floor(U_ale + U_epi + U_ont))
    D_sup = collect_support(M, o, K=M.ass.K_star(o), budget=M.budget)
    if len(set(y for (_, _, y, _) in D_sup)) < 2:         # 标签退化，学不出东西
        return M.r69.conservative(o, lam_floor(U_ale + U_epi + U_ont))
    adapter = InContextFewShot().fit(D_sup)
    ok, cert = conformal_accept(D_sup, M.query(o), M.alpha, M.delta, M.gamma, EPS_TRIAL)
    if not ok:                                            # 验收不过：不写库
        M.skl.freeze_suspect(o)
        return M.r69.conservative(o, lam_floor(U_ale + U_epi + U_ont))
    skill = commit_skill(M, adapter, cert)
    lam = max(M.r69.floor(U_ale + U_epi), M.cag.risk_bound(cert))
    return M.r69.step_with_skill(o, skill, lam, U_ont_after=0.0)
```

## 4. 推导

**引理 19（少样本可辨识下界）** 分离度 Δ、σ-次高斯噪声下，任意 K-trial 判别器的最坏错误率 `err_K ≥ (1/4)exp(−KΔ²/(8σ²))`，故可靠区分需 `K=Ω((σ²/Δ²)log(1/δ))`。系：`Δ≲σ` 时再加 trial 的边际收益指数衰减，正确动作是 abstain 或改变探针增大 Δ，而不是「再试一次」。

**引理 20（污染支持集的保形覆盖）** 污染率 δ_p 破坏可交换性时，标准 CAG 覆盖下界退化为 `1−α−δ_p`；来源分层 + trimmed 分数后为 `1−α−δ_p·ρ_trim+o(1/√n)`。系：人类示范与自标注不能混池，否则恶意样本按比例稀释覆盖保证。

**引理 21（主动 trial 选择的次模性）** 可交换性近似下 `ΔCov(S)` 单调次模，风险/成本为模函数；带预算贪心达 `(1−1/e)OPT`。系：trial 应优先选「能改变预测集大小」的样本，而非平均撒点。

**定理 18（严格包含 R69/R68）** 在 CAG 验收与三级退避下，任意状态期望风险 `≤ R69`；当 `U_ont≤τ_ont`、CAG abstain、TSS 否决或 `K<K_min` 时逐指令等价于 R69，再在 U_epi 消失时退化为 R68。安全侧不让步，能力侧仅对持证技能开放。

**定理 19（试错安全、可回滚、实时不变）** 每个 trial 过 TSS（`R_wc≤ε_trial`、无 `𝒜_irr`、CBF 可行），每次提交走 EPW，控制回路只读 committed 版本 ⇒ (i) 无不可逆违规；(ii) 失败/超时/污染可在 O(1) 次版本切换内回滚；(iii) 环内 WCET 与 R69 相同。学习不破坏 R68 实时性与 R69 无突变性。

## 7. 预期结果与判定（非实测，供下一轮核验）

- **门控顺序**：E301（能识别未知）→ E303（验收可信）→ E304（试错安全）必须依次通过；任一失败则不得开启 TRIAL 通道，系统仍可用 R69。
- **增益归因**：E306 的增益应集中在「真实新模态」子集；若主要来自已知模态，判定 U_ont 泄漏，回退重标定。
- **负结果约定**：若 E302 显示 K=5 仍达不到 85%，本轮结论应为「接触丰富任务上少样本试错不成立」，不得靠调大 K 掩盖——K 增大会同时放大不可逆风险与污染面。

## 8. 本轮最大风险

**一句话**：TRIAL-RAS 的最大风险是：K 个自标注 trial 的分布覆盖不了真实任务分布，保形门只保证「在这些 trial 上不骗人」，**并不保证学到的技能因果正确**——一旦一个由支持集偏差/传感器缓变故障/投毒造成的错误技能通过验收并写入技能库，系统会把一次性的少样本偏差**版本化、复用化、长期化**，此时「学错」比 R69 的「不问」更危险，因为错误获得了证书。

**次级风险与缓解**：不可逆 trial（TSS + CBF + `𝒜_irr` 禁令 + 人接管）；支持集投毒（分层 + trimmed + LOO + `ℰ_poison` 对抗）；保形可交换性被破坏（可交换性检验 + 漂移监测 + 拒绝验收）；技能库膨胀/负迁移（版本化 + 冻结/回滚 + 兼容性门）；元训练过拟合仿真（sim-to-real 差距纳入 `R_wc`，E310 单列）。
