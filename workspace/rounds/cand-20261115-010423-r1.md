# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「动作分块」×「语义建图」）

> R69 教会系统「看、问、触」，把 epistemic 歧义交给主动交互。但它有两个从未被审视的隐含假设：**(a) 动作可以一次只决定一步、下一步再看**；**(b) 脚下的世界语义是即时可读的，不需要记忆**。真实系统恰恰相反：动作总是**成块**生成并执行（action chunking），而语义理解必须**建图**——十分钟后那只杯子还在不在，取决于地图，而不是当下一帧。
>
> 本轮两个灵感把这两个隐含假设变成一等设计变量：
> - **动作分块**把「决定多久不重新看」变成一个可定价的决策：块越长，推理越省、动作越连贯，但对世界变化的赌注越大；
> - **语义建图**把「世界此刻是什么」升级为「关于每个地点的一组带出处、带易变率、可被反驳的断言」。地图不是真值，而是账本。
>
> 核心命题：**一段动作块，本质上是对语义地图一组断言的赌注**。块的支持集 S(ξ) 是它依赖的地图断言；承诺时长 H 由这些断言的失效率决定；语义地图同时充当动作块的**检索先验**与**边界证据**。命名 **MOSAIC-RAS**（Map-Organized Semantic Action-chunking with Interactive Commitment）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我可以闭眼走多远，又该相信哪一段记忆**」。

## 0. 直觉与动机

**灵感 1（动作分块 → H 是「多久不看」的赌注）**
直觉：ACT / diffusion policy / VQ-BeT 之所以强，是因为它们一次生成 H 步动作块，只执行前 k 步（receding horizon），从而减少复合误差与推理次数，并用 temporal ensembling 抹平块缝。R69 其实已经在采样 H 步轨迹，却把 H 当成常数、把「块」只当作多模态聚类的载体——它从未为**承诺**定价。分块的第二层含义是：每执行一个块，系统就主动放弃 H 步的反馈。这不是免费的加速，而是一笔**对世界保持不变的赌注**。本轮把 H 从超参数变成决策变量，与 R69 的自适应 K 形成对偶：**K 是「想象多少个未来」，H 是「在多远的未来之前不再想象」**。

**灵感 2（语义建图 → 地图是可错的断言账本，而不是真值）**
直觉：语义标签是**推断**，不是测量；它依赖视角、光照、遮挡、训练分布和标注偏差，会过期、会冲突、会被别人改写。传统语义地图把每个栅格压成一个 argmax 标签，等于把「断言」伪装成「事实」。更合理的表征是**语义地点图**：节点是地点，节点上挂着类别/affordance 的**假设分布**、每条断言的出处与时间戳、以及该地点的**易变率**（语义/占据变化的风险率）。这直接接上 R69：R69 把动作拆成多个模态；这里把「我在哪、这里能做什么」也拆成多个**地点模态**——感知别名（两条一模一样的走廊）本身就是一种 epistemic 歧义。

**灵感 3（块 × 图 的耦合 → 支持集与承诺风险）**
直觉：一段块不是凭空执行的，它必然「依赖」地图上的一串断言：这扇门是开的、这块地可通行、这个杯子是目标而不是倒影、这段楼梯的高度是标准值。把这些依赖记为块的**支持集 S(ξ)**。只要 S(ξ) 中任一断言在 H 内失效，块就可能在语义上错位（撞上刚关的门、抓错刚被移走的物体）。于是承诺时长的自然定义不是拍脑袋的 H，而是「让支持集存活概率 ≥ 1−ε 的最大 H」。**H 是对地图稳定性的下注，语义建图负责报出赔率（hazard）**。

**灵感 4（记忆是双刃剑 → 检索先验、自我确认闭环与投毒）**
直觉：语义地图与动作块库还能反向帮助 R69。R69 最大的风险是流模型模态分布不可信（幻觉模态 / 坍缩真模态）；而「这个地点过去被认证过的成功动作块」是一份**经验校准集**，可以抑制幻觉、补回被坍缩的模态。但记忆同时制造两个新危险：(i) **自我确认闭环**——错误标签导致块执行，执行没出事就被记为「该地点已验证的成功块」，反过来强化错误标签；(ii) **语义 spoof / 块库投毒**——让危险地点看起来像熟悉的Safe地点，或伪造一条「已认证」块。因此本轮必须把记忆严格限制为**提议**，绝不允许它独自授权执行或扩大安全集。

**灵感 5（边界即探针 → 第三条证据通道）**
直觉：R69 用 (r_res, Δa) 两条通道分离传感器故障与行为异常。动作分块免费送来第三条：每个块的边界都是一次**隐含的假设检验**——执行前根据地图预测「到 t+H 时应该看到什么语义状态」，执行后比对真实观测。残差 r_sem 高而传感器残差低、动作似然正常，指向的不是传感器，而是**地图陈旧 / 地点别名 / 地图投毒**。**每一个块边界，都是一次不用额外花钱的实验**。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (SPM, CEL, RAC, ACH, SBR, CHA, REG, SCG, MST, RAS-WM†)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）；
(ii) **语义不扩张安全集**：语义断言只能缩小候选动作集或缩短承诺时长；物理安全集 Safe_t 恒由几何最坏情况与 C-RAS-WM 认证给出，**任何在线语义都不能扩大它**（扩张必须走离线认证的释放流程，不在实时环内）；
(iii) **记忆只做提议**：检索到的动作块与地图断言只能进入先验/证据/候选，**不得单独授权执行、不得单独认证安全、不得单独定案**。

**定义 311（语义地点图 SPM）** M_t = (V, E, G, Φ, Γ, ν, L)。节点 v ∈ V 表示地点，携带：空间原型与地标签名；假设分布 h_v（类别 / affordance / 动态性，保留多个假设而非 argmax）；易变率 ν_v（单位时间断言失效的风险率）；年龄与版本；出处账本 L_v（谁、何时、凭何证据写入）；引用到的块库条目。E 为邻接/可通行关系；G 为几何占据层（只服务安全，不参与语义扩张）；全局版本号 ver(M_t)。

**定义 312（地点信念与别名模态）** 观测 o_t 下地点后验 b_t(v) ∝ p(o_t | v)·prior(v)。感知别名使 b_t 可能**多峰**：用与 R69 相同的轨迹/特征聚类得地点模态 {v_j}、权重、熵 H_place 与最小间距 Δ_place。地点歧义是一种 epistemic 不确定，可由 R69 的信息动作（环视、读标识、询问他机、查询地图邻域）消解——R69 消解「做什么」，这里消解「我在哪、这里能做什么」。

**定义 313（动作块样本库 CEL）** 对每个地点 v，C_v = {(ξ_i, y_i, S_i, prov_i, cert_i)}：ξ_i 为历史动作块，y_i 为结果，S_i 为其支持集（它依赖的地图断言集合），prov_i 为签名出处，cert_i 为认证。检索后验 q(ξ | v) = Σ_i w_i K(ξ; ξ_i)，w_i ∝ exp(−α·age_i)·trust_i·1[y_i 成功]。**入籍条件**：结果经过验证、支持集在当时被独立核验（不是只凭「没出事」）、出处可验签。

**定义 314（检索增强块策略 RAC）** p(ξ | o_t, b_t) ∝ p_flow(ξ | o_t, ψ_t) · q(ξ | b_t)^{β_t}，其中 ψ_t 为地点上下文嵌入，β_t ∈ [0, β_max] 为 SCG 门控（定义 321）。β_t = 0 时**精确退化为 R69** 的纯流策略。采样用重要性重采样 / 温度化 product-of-experts 实现。注意：q 只是提议先验，其后验可信度由 β_t 显式标出，不得被当作已校准概率。

**定义 315（语义条件流策略）** 在 R69 FMP 上加地点条件：v_θ(x_s, s | o_t, ψ_t)，x_1 = ξ_{t:t+H}。训练时对 ψ_t 做 place-dropout（随机置空），保证 β=0 路径在分布内；块长度 H 作为条件输入，使同一网络支持多尺度块。

**定义 316（自适应承诺时长 ACH）** 对块 ξ 的支持集 S(ξ)，断言失效风险率 λ_S = Σ_{a∈S(ξ)} ν_a。支持集存活概率 P_surv(H) = exp(−λ_S H)。给定边界失效预算 ε_B：
H_surv = −ln(1−ε_B) / λ_S。
再与推理成本权衡：C(H) = c_inf/H + c_err·λ_S·H（推理越频繁越贵，承诺越久错位风险越大），得
H* = clip( min( H_surv, sqrt(c_inf / (c_err·λ_S)) ), H_min, H_max )，
λ_S = 0 时取 H_max。λ_S 越大 H* 越短；**H* ∝ 1/√ν**——地图越易变，闭眼越短。

**定义 317（语义边界残差与地标锚定拼接 SBR）** 在边界 t+H：由 M_t 与 ξ 预测语义状态 ŝ = f_map(ξ, M_t)，与实测语义 s′ = Sem(o_{t+H}) 比较，r_sem = D(ŝ, s′) + r_lm。r_lm 为**地标锚定拼接残差**：重叠块不按时间硬拼，而按语义地标（门框、桌角、标识）对齐后再拼接；对齐失败即计入 r_sem。块缝应由地标缝合，而不是由时间戳缝合。

**定义 318（三通道故障分诊 CHA）** 证据向量 (r_res, Δa, r_sem, b_{t+H})。在 A102（三通道条件独立、各自对对应故障单调）下：
- r_res ↑ ⇒ 传感器/标定通道故障；
- Δa ↑ ∧ r_sem ↑ ∧ b 集中 ⇒ 世界模型/策略条件错位；
- r_sem ↑ ∧ b 集中 ∧ 动作似然正常 ⇒ 地图陈旧（良性语义变化）或断言被改写；
- r_sem ↑ ∧ b 弥散 ⇒ 里程计漂移 / 感知别名；
- r_sem ↑ ∧ 出处异常 / 支持集断言的签名与版本不符 ⇒ 地图投毒 / 重放。
分诊结论进入 R69 的 MINT 与 R68 的保守退避。

**定义 319（检索证据纪律 REG）** 检索块要进入候选，必须：(i) 与流块过**同一套** C-RAS-WM 认证；(ii) 至少 k 个正交证据一致（当前语义观测、几何一致性、已认证结果出处）；(iii) 支持集断言的年龄 ≤ τ_age 或易变率 ≤ τ_ν；(iv) 出处签名、地图版本与当前一致。任一不满足 ⇒ 该块被丢弃或 β 下调；**检索永不覆盖认证**。

**定义 320（语义 spoof 与块库投毒 ℰ_map）** 篡改标签、伪造块、重放旧地标签名、对抗性 affordance、跨机 Byzantine 写入、别名攻击（把危险地点伪装成已知 Safe 地点）。并入 AIC：ℰ_MOSAIC = ℰ_FLUID × ℰ_map。

**定义 321（语义一致性门 SCG）** β_t = β_max · 1[place 置信 ≥ τ_p] · 1[age(M_t) ≤ τ_age] · 1[ver 一致] · 1[无出处异常]。任一不满足 ⇒ β_t = 0，且 H 收缩到 H_min 或 R69 的固定 H，**逐指令退回 R69**；地图不可信时，宁可不记忆。

**定义 322（承诺安全与滚动截断）** 物理安全集 Safe_t = Safe_geo ∩ Certified(C-RAS-WM)，与语义无关。执行块时若边界残差、支持集失效或新观测与预测冲突，立即**截断剩余块**（receding horizon），重新规划并调用 R69/R68 兜底。承诺是**可抢占的软契约**，不是不可撤销的命令。

**定义 323（地图存储与版本纪律 MST）** 地图与块库的写入全部异步、离环；每条写入带来源、时间、证据链、签名与版本号；入籍需验证结果与支持集；实时控制环**只读**。更新用 compare-and-swap 版本推进；版本落后或不可验签即触发 SCG 关闭。

**定义 324（证书 J_MOSAIC）** J_MOSAIC = (J_FLUID, place_id, H_place, map_ver, H, λ_S, r_sem, triage_class, retrieval_hash, exemplar_provenance, scg_beta)。Valid ⇔ Valid(J_FLUID) ∧ SCG 条件成立 ∧ REG 满足 ∧ 截断日志一致。

**定义 325（层级块组合 HCH）** 块分多尺度：任务块（语义子目标序列）→ 子目标块（区域间移动）→ 原语块（局部动作）。粗块只在语义子目标图（SPM 上的地标节点序列）上承诺，细块在执行时按边界证据重规划；跨尺度共享同一支持集与 λ_S 记账，粗块的风险是细块风险的上界。

```python
# IP-264/265 SPM + CEL：语义地点图与动作块样本库（只读快照进实时环）
class SemanticPlaceMap:
    def localize(self, o_t):                      # 多峰地点信念
        return self.place_filter.update(o_t)      # b_t(v), modes, H_place

    def assertions(self, chunk):                  # 块的支持集 S(ξ)
        return {a for v in chunk.visited_places for a in self.M[v].assertions}

    def hazard(self, support):                    # λ_S = Σ ν_a
        return sum(self.M[a.place].nu[a.id] for a in support)

class ChunkExemplarLibrary:
    def retrieve(self, b_t, k=8):                 # 只取已认证、未过期条目
        return ann_search(self.index, b_t, k,
                          filter=lambda e: e.cert and self.fresh(e))

# IP-266 RAC：检索增强块策略（β=0 即 R69）
class RetrievalAugmentedChunkPolicy:
    def sample(self, o_t, b_t, H, K, beta):
        z   = self.trunk(o_t)
        psi = self.place_encoder(o_t, self.spm.M)
        chunks = self.flow.sample(o_t, psi, H, K)          # R69 流采样
        if beta == 0:
            return chunks                                  # 严格退化 R69
        q = self.cel.retrieve(b_t)                          # 认证样本先验
        return self.poe_resample(chunks, q, beta)           # 温度化 PoE

# IP-267 ACH：承诺时长 = 支持集存活 × 成本最优
def choose_horizon(chunk, spm, eps_B=0.05):
    lam = spm.hazard(spm.assertions(chunk)) + 1e-9
    H_surv = -math.log(1 - eps_B) / lam
    H_cost = math.sqrt(C_INF / (C_ERR * lam))
    return clip(min(H_surv, H_cost), H_MIN, H_MAX)

# IP-268/269 SBR + CHA：边界即探针
def boundary_probe(chunk, o_next, spm):
    s_hat = spm.predict_semantics(chunk)                 # 地图预测
    s_obs = sem_encoder(o_next)
    r_sem = divergence(s_hat, s_obs) + landmark_stitch_residual(chunk, o_next)
    b_next = spm.localize(o_next)
    return r_sem, b_next

def triage(r_res, da, r_sem, b_next):
    if r_res > T_RES:                          return "sensor"
    if da > T_DA and r_sem > T_SEM:            return "world_model"
    if r_sem > T_SEM and entropy(b_next) < T_E:return "map_stale_or_tampered"
    if r_sem > T_SEM:                          return "odometry_or_alias"
    return "ok"

# IP-270/272 REG + SCG：记忆只做提议，地图不可信即退回 R69
def governing_gate(b_t, spm, chunk, exemplars):
    if spm.stale() or not spm.signatures_ok():      return 0.0, H_MIN
    if entropy(b_t) > T_PLACE:                       return 0.0, H_MIN
    if not k_orthogonal_agree(exemplars, chunk, b_t): return 0.0, H_MIN
    return BETA_MAX, None                            # None: 用 ACH 正常选 H

# IP-276 主闭环（继承 R69；在策略前后插入地点层与承诺层）
def MOSAIC_round(M, o_t):
    z = M.trunk(o_t)
    b_t = M.spm.localize(o_t)
    # 0) 地点歧义本身也是 epistemic：先按 R69 的方式消解「我在哪」
    if entropy(b_t) > T_PLACE:
        g = M.mint.choose_place_probe(b_t, M.budget)      # 环视 / 读标识 / 问
        if g is not None and M.c_ras_wm.certify_info(g, o_t):
            b_t = M.spm.update(b_t, M.cia.execute(g))
    beta, H_force = M.scg.gate(b_t, M.spm)
    # 1) 先用廉价流块估计支持集，再定价 H（必要时按 H 重采样）
    seed    = M.rac.sample(o_t, b_t, H_MIN, K=1, beta=beta)[0]
    H       = H_force or M.ach.choose_horizon(seed, M.spm)
    samples = M.rac.sample(o_t, b_t, H, K=4 if M.aud.ambiguous(seed) else 1, beta=beta)
    U_ale, U_epi, modes = M.aud.decompose(samples)
    # 2) 选块：只在几何认证安全集内选；语义只加约束/排序，不扩安全集
    a_hat = M.fma.flow_anomaly(M.fmp, M.last_chunk, o_obs, o_calibrated)
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    chosen = M.select_mode(modes, U_epi, lam=M.efs.risk_scale(...))
    if not M.reg.govern(chosen, b_t, M.spm, M.cel):
        chosen = M.flow.sample(o_t, None, H, K=1)[0]       # 记忆不可信 → 纯流
    A = chosen.actions
    k = M.c_ras_wm.certified_prefix(A, ..., safe_set=M.safe_geo)   # 语义不参与扩张
    if slow:
        k = min(k, k_cal_shrink(A, U_cal)); H = min(H, H_MIN)
    # 3) 执行前 k 步，登记边界探针，异步审计
    M.sbr.register(chosen, o_t, M.spm, H)
    M.vqa_i.submit_async(chosen, b_t, H, beta, M.spm.last_version)
    return k, H, chosen, (U_ale, U_epi)

# IP-268 下一轮入口：边界探针 → 分诊 → 截断/重规划/写回
def on_chunk_boundary(M, o_next):
    r_sem, b_next = M.sbr.boundary_probe(M.last_chunk, o_next, M.spm)
    cls = triage(M.last_r_res, M.last_da, r_sem, b_next)
    if cls != "ok":
        M.truncate_and_replan(cls)                  # 承诺可抢占（定义 322）
    if cls == "map_stale_or_tampered":
        M.scg.quarantine(M.spm.last_version)        # 冻结该版本，转审计
    M.mst.async_write(M.last_chunk, cls, b_next)    # 离环、带出处写回
```

## 3. 推导

**引理 19（检索的校准修复与校准投毒）** 设地点匹配正确的概率为 1−δ，块库有 n 个已认证且条件无偏的样本，地点流形直径为 D_place。则 RAC（定义 314）后验的模态权重 ECE ≤ ECE_flow + O(δ + 1/√n)；当 δ→0 时检索**严格改善** R69 的模态校准，直接缓解 R69 自陈的最大风险（幻觉/坍缩模态）。反之，若地点匹配错误（概率 δ），选中模态的期望偏差 ≤ δ·D_place——检索从「校准修复」变成「校准投毒」。系：**β 必须由地点置信与地图可信度门控**（SCG），不可由检索本身决定。

**引理 20（承诺时长的存活-成本最优）** 若支持集断言按独立风险率 ν_a 失效，则块在 H 内语义错位的概率 ≤ 1−exp(−λ_S H)（λ_S=Σν_a）。满足预算 ε_B 的最大 H 为 H_surv；在成本 C(H)=c_inf/H+c_err λ_S H 下，最优点 H* = sqrt(c_inf/(c_err λ_S))。故 **H* ∝ 1/√ν**：地图越易变，承诺越短；且 H 的选择把「推理频率」与「语义错位」显式对立，而不是拍脑袋。系：块的支持集越大、越旧，λ_S 越大，H 自动收缩——**长块只属于新鲜、稳定、支持集小的地点**。

**引理 21（三通道分诊的可辨识性）** 在 A102 下，(r_res, Δa, r_sem) 对传感器、世界模型、地图、里程计四类故障的灵敏度矩阵非奇异，则四类故障的期望残差方向两两可分；特别地 (r_sem↑, H_place↓, Δa 正常) 指向地图语义层，(r_sem↑, H_place↑) 指向别名/漂移。系：块边界把「地图错误」从「传感器错误」中分离出来，这是 R69 两通道做不到的。

**引理 22（自我确认记忆的不动点）** 若块入籍只以「执行未出事」为判据、不支持集独立核验，则一个错误语义断言导致的「安全但语义错误」的块会以概率 P_success 被反复入籍；于是地图错误形成一个稳定不动点：错误的标签持续生产「成功证据」，成功证据持续强化错误标签，系统永不触发 R69 的交互（因为它「有先例」）。要点：**必须把「结果成功」与「语义正确」分开核验**，否则记忆会用自己的结论给自己作证。这是 CEL 入籍条件（定义 313）与 REG（定义 319）的理论依据。

**定理 18（物理安全严格包含，任务风险有界）** 语义永不扩大 Safe_t（定义 310-ii、322），检索块与流块过同一认证，截断只会缩小执行集合，故对任意状态 P(碰撞) ≤ P_R69(碰撞)。任务层：若地点错配概率为 δ_map、任务损失对语义偏差 Lipschitz 常数为 L_bias，则期望任务风险 ≤ R69 + δ_map·L_bias；当 SCG 关闭（δ_map 视为 1 但 β=0）时，**逐指令退化为 R69**。即：**安全是无条件包含，任务收益是有条件包含**——不把「没撞」偷换成「做对了」。

**定理 19（自适应承诺的稳定性与严格包含）** 在地标锚定拼接（定义 317）与滚动截断（定义 322）下，块缝的状态不连续度被地标对齐误差界住，故执行轨迹连续、无突变；当 β=0 且 H=H_R69 时，MOSAIC 与 R69 逐指令相同。承诺越久，认证前缀与截断检查越保守，故 H 的延长不降低物理安全裕度。R69 恰是 MOSAIC 在「不检索、固定 H、无边界证据」边界上的退化。

## 6. 本轮最大风险

**一句话**：MOSAIC 把「记忆」引进了安全回路，而记忆会**自我背书**——错误语义标签生产动作块，块执行没出事就被记为「该地点已验证的成功块」，反过来强化错误标签；**当「成功」被当作「语义正确」的证据时，地图就在用自己的结论给自己作证**，R69 的 VoI 会在这个闭环里越来越自信地问错问题——**会背书的记忆，比没有记忆更危险**。

**次级风险与缓解**：
1. **地点别名 / 语义 spoof**（危险地点伪装成熟悉 Safe 地点）→ 多峰地点信念 + 地标签名 + SCG 门控 + E301/E306；
2. **地图/块库投毒** → 语义不扩张安全集（定理 18）+ 提案制 + k 正交证据 + 版本/签名纪律 + E306/E315；
3. **自我确认闭环** → 入籍必须独立核验支持集，而非只看结果（引理 22、定义 313）+ E307；
4. **H 对易变率估计过敏**（ν 低估 → 块过长）→ 保守先验 + 存活预算硬约束 + 滚动截断，H 只缩不长 + E303/E311；
5. **检索偏置破坏对 R69 的包含**（地图错时反而更差）→ SCG 关闭即 β=0、H 回退，任务层偏差被 δ_map·L_bias 界住（引理 19、定理 18）+ E308/E314。

```python
    slow  = (a_hat > TAU_FMA) and (M.last_r_res < TAU_RES)
    chosen = M.select_mode(modes, U_epi, lam=M.efs.risk_scale(...))
    if not M.reg.govern(chosen, b_t, M.spm, M.cel):
        chosen = M.flow.sample(o_t, None, H, 1)[0]         # 记忆不可信 → 纯流
    k = M.c_ras_wm.certified_prefix(chosen.actions, ..., safe_set=M.safe_geo)
    if slow: k = min(k, k_cal_shrink(chosen.actions, U_cal)); H = min(H, H_MIN)
    M.sbr.register(chosen, o_t, M.spm, H)
    M.vqa_i.submit_async(chosen, b_t, H, beta, M.spm.last_version)
    return k, H, chosen, (U_ale, U_epi)
```

## 4. 推导

**引理 19（检索的校准修复与校准投毒）** 地点匹配正确率 1−δ、块库 n 个认证无偏样本时，RAC 后验模态权重 `ECE ≤ ECE_flow + O(δ + 1/√n)`：δ→0 时检索修复 R69 的模态幻觉/坍缩；地点错配时选中模态偏差 `≤ δ·D_place`，检索变成校准投毒。故 β 必须由 SCG 门控。

**引理 20（承诺时长的存活-成本最优）** 支持集独立风险率下，块在 H 内语义错位概率 `≤ 1−exp(−λ_S H)`；满足预算 ε_B 的 `H_surv=−ln(1−ε_B)/λ_S`；成本 `C(H)=c_inf/H+c_err λ_S H` 的最优点 `H*=sqrt(c_inf/(c_err λ_S))`。故 H∝1/√ν：长块只属于新鲜、稳定、支持集小的地点。

**引理 21（三通道可辨识）** A102 下灵敏度矩阵非奇异，四类故障期望残差方向两两可分；`(r_sem↑, H_place↓)` 指向地图语义层，`(r_sem↑, H_place↑)` 指向别名/漂移。块边界把「地图错误」从「传感器错误」中分离。

**引理 22（自我确认记忆的不动点）** 若入籍只以「执行未出事」为准，不独立核验支持集，则错误语义断言会稳定地生产「成功证据」，成功证据又强化错误标签，系统因「有先例」而永不触发交互。必须把「结果成功」与「语义正确」分开核验。

**定理 18（物理安全严格包含，任务风险有界）** 语义不扩 Safe_t、检索块过同一认证、截断只缩执行集 ⇒ `P(碰撞) ≤ P_R69(碰撞)` 对任意状态成立；任务风险 `≤ R69 + δ_map·L_bias`；SCG 关闭时逐指令退化为 R69。安全无条件包含，任务收益有条件包含。

**定理 19（自适应承诺稳定性与严格包含）** 地标锚定拼接 + 滚动截断 ⇒ 块缝状态不连续度被地标误差界住，轨迹连续无突变；β=0 且 H=H_R69 时与 R69 逐指令相同。R69 是 MOSAIC 在「不检索、固定 H、无边界证据」边界上的退化。

## 7. 本轮最大风险

**一句话**：MOSAIC 把「记忆」引进了安全回路，而记忆会**自我背书**——错误语义标签生产动作块，块执行没出事就被记为「该地点已验证的成功块」，反过来强化错误标签；**当「成功」被当作「语义正确」的证据时，地图就在用自己的结论给自己作证**，R69 的 VoI 会在这个闭环里越来越自信地问错问题——**会背书的记忆，比没有记忆更危险**。

**次级风险与缓解**：地点别名/语义 spoof（多峰地点信念 + 地标签名 + SCG，E301/E306）；地图/块库投毒（语义不扩安全集 + 提案制 + k 正交证据 + 版本签名，E306/E315）；自我确认闭环（入籍独立核验支持集，引理 22，E307）；H 对 ν 低估过敏（保守先验 + 存活硬约束 + 只缩不长，E303/E311）；检索偏置破坏包含性（SCG 关闭即 β=0，任务偏差被 δ_map·L_bias 界住，E308/E314）。
