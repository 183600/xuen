## 0. 直觉与动机

**灵感 1（多端口部署 → 证书的可移植性而非可复制性）**

直觉：v23 的 CESC 把同一套 (model, calib, proto, rule, patent) 原子同步到**一个**边端。但真实部署是把同一套证书复制到几十个"端口"（场地/租户/机型/接入点——"端口"此处兼含网络端口与部署站点双重语义）。直觉上"同一份证书"应该处处成立；但 conformal 覆盖是**相对某个校准分布**的承诺，换一个端口，传感器内参、光照、人群身高分布、地面材质全都变了，交换性 (exchangeability) 假设随之破裂。**证书可以复制，但保证不能复制**。于是核心问题从"如何同步版本"变成"如何判定一份证书在新端口仍然有效"。我们把这叫**部署可移植性 (deployment portability)**：它不是二值的"能用/不能用"，而是"在付出多大的覆盖折损 Δ_transport 后仍可用"。

严谨定义：端口指纹 `π_p = (ρ_sensor, h_calib, v_rule, D_pop_p, τ_twin)`（传感器构型、标定哈希、规则版本、人群/环境分布描述子、孪生标识）。部署实例 `I_p = (C, π_p)`。设源端口校准分布 `P_p`、目标端口 `P_q`，证书 C 的目标覆盖 `1-α`。若以总变差距离 `d_TV(P_q, P_p) ≤ Δ_budget` 且有效样本量 `n_eff = (Σw)²/Σw² ≥ n_min`（w 为密度比 dP_q/dP_p）为**可移植见证 (portability witness)**，则加权 conformal 保证目标端口覆盖 `≥ 1-α - d_TV(P_q, P_p)`。因此源端必须按 `α_p = α - Δ_budget` 校准（预留迁移裕度），才能让目标端口"落地即 1-α"。无见证 ⇒ 不许继承，只能在 v23 包络内本地重校准（与包络**求交**，绝不扩张）或按 `Δ_budget` 收缩运行包络。关键反直觉点：**跨端口继承证书的正确方向不是"把证书送过去"，而是"把 α 的预算按迁移距离预先花掉"**。

**灵感 2（数字孪生 → 单侧否决器与缺席审计器，而非第二真相）**

直觉：数字孪生是物理世界的实时镜像。最自然的用法是"先在孪生里跑一遍，孪生说安全才执行"——但这立刻把 sim2real 保真度变成了新的安全前提，而这恰是最不可验证的东西。反向思考：**孪生的价值不在于它能"放行"，而在于它能"否决"和"证伪"**。一个只会说"不"的孪生，无论多不准，都不会让系统比 v23 更危险——它最多让系统更保守（活性下降）。这就是**单侧过滤 (one-sided filtration)**：`Exec_v24 = Exec_v23 ∩ Fil_twin ⊆ Exec_v23`，孪生误差只侵蚀活性，不侵蚀安全。

更强的用途是**审计负信息**：v23 最大的风险是"覆盖区内无人"的缺席证书 (AbsCert) 建立在检测器召回下界 κ_c 这个经验假设上。孪生可以合成对抗性人体（儿童、轮椅、蹲姿、逆光、非常规衣着），把它们塞进 AbsCert 声称"无人"的覆盖区，渲染后喂给真实检测器；**只要有一个合成人未被检出，该区域的 AbsCert 立即被撤销**。注意这也是单侧的：审计只能撤销、永不签发。于是孪生把 v23 的"合规的缺席幻觉"从"无法检验的假设"变成"可主动证伪的测试"。

严谨定义：孪生 `T_p` 在状态估计 `ŝ` 上的演练 `Rehearse(T_p, π, ŝ) → {SAFE, UNSAFE, UNKNOWN}`；过滤器 `Fil_twin = {π : Rehearse(π,ŝ) ≠ UNSAFE}`（UNKNOWN 放行，因为安全已由 v23 证书兜底）。缺席审计 `AuditAbs(T_p, AbsCert) = AbsCert` 若覆盖区注入的对抗虚拟人全部被检出，否则撤销被漏检虚拟人所在的子区。关键反直觉点：**孪生越不准，系统只会越保守而不会越危险——前提是它被严格限制为"只能否决/撤销"，任何"用孪生放行 AbsCert 或放宽能量裕度"的用法都会瞬间把安全重新押回不可验证的 sim2real 保真度上**。

**两者如何统一：部署即证书的再实例化**

多端口是"同一证书的许多实例"，孪生是"每个实例的本地影子审计器"。统一为 **v23 之上的部署层 (Deployment Layer)**：端口清单与可移植证书 (PMPC) 回答"这份证书凭什么在这个端口成立"，孪生演练证书 (DTRC) 回答"这个计划在这个端口执行前有没有被影子世界否决"，孪生缺席审计 (TAA) 回答"覆盖区无人的断言有没有被对抗虚拟人证伪"，跨端口审计链 (CPFAC) 回答"几十个端口的证书历史是否可对账、无抵赖、无静默漂移"。共享状态扩展为 `ζ_dep = ζ_ce ∪ (π_p, Δ_transport, n_eff, TwinCert, AbsAuditLog, PortLedger)`。统一准入门 **HPC-P = HPC-E+ ∧ Portable ∧ TwinPass ∧ PortAudited**：只有"v23 四证 ∧ 可移植见证 ∧ 孪生未否决 ∧ 端口审计一致"才进入执行；任一缺失退回 v23，再退 v22…v18。跨端口继承只在有见证时发生，孪生只做减法，故 `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。

## 1. 研究问题

- **Q13（孪生单侧保证与活性）**：在孪生保真度任意差的前提下，如何证明 `Exec_v24 ⊆ Exec_v23`（安全）并把"误否决率"（活性损失）用 sim2real 差距显式界定？何时应主动降低孪生否决权（换活性）而不破坏安全？UNKNOWN 的放行策略与 v23 的保守退化如何衔接？

## 2. 设计原则（在 P41–P42 基础上新增 P43–P46）

**P43 部署可移植律（Deployment Portability）**
证书 C 与端口指纹 `π_p` 绑定；跨端口 p→q 继承当且仅当存在可移植见证 `Portable(C,p→q) ≜ d_TV(P_q,P_p) ≤ Δ_budget ∧ n_eff ≥ n_min`。有见证时目标覆盖 `≥ 1-α`（源端按 `α_p = α - Δ_budget` 预留）；无见证时**禁止继承**，仅允许在 v23 包络内本地重校准（与包络求交，绝不扩张）或按 `Δ_budget` 收缩运行包络（更慢/更远/更小工作区）。故跨端口执行集 `Exec_q ⊆ Exec_p`，且可移植性是**传递但会累积折损**的。

**P44 孪生单侧过滤律（Twin One-Sided Filtration）**
孪生只可否决，不可授权：`Exec_v24 = Exec_v23 ∩ Fil_twin`，`Fil_twin = {π : Rehearse(π,ŝ) ≠ UNSAFE}`。孪生保真度只影响误否决率（活性），**不影响**执行集上界（安全）；任何"以孪生预测放行 AbsCert / 放宽能量裕度 / 扩大可达集"的用法均被架构禁止（类型系统层面：孪生只能返回 `VETO` 或 `NO_OPINION`，不提供 `GRANT`）。

**P45 孪生缺席审计律（Twin Absence Auditing）**
AbsCert 签发前必须通过对抗虚拟人审计：`AuditAbs(T_p, AbsCert) = AbsCert` 当且仅当注入覆盖区 `Cov_t` 的全部对抗虚拟人均被检测器检出；任一漏检 ⇒ 撤销该子区 AbsCert，并把该形态计入 κ_c 的保守下修。审计**只能撤销、永不签发**，故 `AbsCert_v24 ⊆ AbsCert_v23`，是对 v23 缺席幻觉的单调改进。

**P46 多端口审计不可抵赖律（Cross-Port Non-repudiation）**
每个端口对 (证书, 计划, 结果, 版本五元组, 孪生判决) 签名并链入本地 merkle 链，周期性上卷到全局账本根 `R_global`。任意端口结论与全局分布显著分歧 ⇒ 标记该端口 `UNVERIFIED` ⇒ 该端口仅可用本地重校准包络。审计链单调追加、不可改写；离线端口以签名批次补链，保持可对账。

## 3. 与基线的接口（如何退化）

- PMPC 失效（无可移植见证/指纹缺失）⇒ 禁止跨端口继承，逐端口本地重校准（与 v23 包络求交）⇒ 比 v23 更保守（覆盖需重新证明）；
- DTRC 失效（孪生不可用/超时）⇒ `Fil_twin = 全集`（不否决）⇒ 等价 v23（安全不依赖孪生）；
- TAA 失效（审计器不可用）⇒ 退回 v23 的 AbsCert（仍依赖 κ_c）⇒ 等价 v23，不更差；
- CPFAC 失效（账本不可达）⇒ 端口降级为本地签名链，跨端口分歧检测暂停 ⇒ 仍可用本地包络，`Exec_v24 ⊆ Exec_v23` 保持；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`。
- **安全继承**：PMPC 只在有见证时"允许继承"（不新增自由空间）；DTRC 只减；TAA 只撤；CPFAC 只审计/降级。任意失效都向更保守方向退化。孪生与审计状态机以事件方式接入 v23 的 CESC 双轨窗口与 v17 APS 新鲜度阶梯：判决携带时间戳，TTL 过期回落"无意见"，控制路径仅 O(1) 查询。

## 4. 预期贡献

1. **可移植证书理论**：首次把"部署实例"作为一等公民，给出端口指纹、可移植见证与覆盖折损界，把"复制证书"升级为"带迁移预算的再认证"；
2. **孪生单侧安全定理**：证明孪生保真度任意差时 `Exec_v24 ⊆ Exec_v23` 仍成立，把数字孪生从"不可验证的第二真相"改造为"只减不增的安全否决器"；
3. **缺席幻觉的主动证伪**：用对抗虚拟人审计把 v23 的 κ_c 经验假设从"不可检验"变为"可证伪、可下修"，并保持 AbsCert 单调收缩；
4. **多端口可对账审计**：签名 merkle 端口链 + 全局账本根，使跨端口证书历史不可抵赖、漂移可检测、隐私可保留；
5. **HPC-P 五证一体**：HPC-E+ ∧ Portable ∧ TwinPass ∧ PortAudited 统一准入门，`Exec_v24 ⊆ Exec_v23` 闭环；
6. **部署层与云边层的正交分解**：CESC 管"版本是否同步"，PMPC 管"证书是否可移植"，DTRC/TAA 管"本地影子是否否决"，三者失效互不放大。

## 5. 本轮最大风险

**一句话**：孪生只有在被严格限制为"只否决/只撤销"时才是安全的；而多端口扩张下逐端口重认证成本高，工程上极易把孪生悄悄升级为"授权器"（用孪生放行 AbsCert、放宽能量裕度或扩大可达集），一旦如此，安全就重新押在无法验证的 sim2real 保真度上，`Exec_v24 ⊆ Exec_v23` 的单调链会在无人察觉处断裂——即"把否决器误用为授权器"的静默越权。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440/441 Port Manifest & Port-Portable Weighted Conformal
# ============================================================
@dataclass
class PortManifest:
    port_id: str
    sensor_hash: str
    calib_hash: str
    rule_version: int
    pop_descriptor: Tensor       # 人群/环境分布描述子
    twin_id: str

    def fingerprint(self) -> str:
        return sha256((self.port_id, self.sensor_hash, self.calib_hash,
                       self.rule_version, self.twin_id)).hexdigest()


@dataclass
class PortabilityWitness:
    d_tv: float
    n_eff: float
    alpha_source: float          # α_p = α − Δ_budget
    def valid(self, delta_budget: float, n_min: int) -> bool:
        return self.d_tv <= delta_budget and self.n_eff >= n_min


class PortabilityCertificate:
    """证书可移植性：有见证才允许跨端口继承，否则只在 v23 包络内求交。"""
    def __init__(self, alpha: float, delta_budget: float, n_min: int):
        self.alpha, self.delta_budget, self.n_min = alpha, delta_budget, n_min

    def certify(self, C_source, p: PortManifest, q: PortManifest,
                src_scores: Tensor, tgt_scores: Tensor) -> Optional[PortabilityWitness]:
        # 密度比估计（kNN / 二分类器两样本法）
        w = estimate_density_ratio(src_scores, tgt_scores)   # w(x) ≈ dP_q/dP_p
        d_tv = 0.5 * torch.mean(torch.abs(w - 1.0)).item()    # ≤ ½E_p|w−1|
        n_eff = (w.sum() ** 2 / (w ** 2).sum()).item()
        witness = PortabilityWitness(d_tv, n_eff,
                                     alpha_source=self.alpha - self.delta_budget)
        return witness if witness.valid(self.delta_budget, self.n_min) else None

    def local_fallback(self, C_source, p: PortManifest, local_envelope):
        """无见证：本地重校准只能与 v23 包络求交，绝不扩张。"""
        return intersect(C_source.envelope, local_envelope)


class WeightedConformal:
    """密度比加权 conformal：给出目标端口覆盖下界。"""
    def __init__(self, alpha_source: float):
        self.alpha = alpha_source

    def quantile(self, calib_scores: Tensor, calib_w: Tensor, test_w: float) -> float:
        p = calib_w / (calib_w.sum() + test_w)
        order = torch.argsort(calib_scores)
        cdf = torch.cumsum(p[order], dim=0)
        idx = torch.searchsorted(cdf, 1.0 - self.alpha)
        return calib_scores[order][min(idx, len(order) - 1)].item()

    def coverage_lower_bound(self, d_tv: float) -> float:
        # 标准加权 conformal 界：coverage ≥ 1 − α_source − d_TV
        return max(0.0, 1.0 - self.alpha - d_tv)

# IP-442 Digital Twin Rehearsal Certificate (DTRC) — 单侧否决

from typing import Literal
TwinVerdict = Literal["VETO", "NO_OPINION"]   # 类型系统层面不存在 GRANT


class TwinRehearsalCertificate:
    def __init__(self, twin, timeout_ms: float = 50.0):
        self.twin, self.timeout_ms = twin, timeout_ms

    def filter(self, plan, state_hat) -> TwinVerdict:
        try:
            v = self.twin.rehearse(plan, state_hat, deadline_ms=self.timeout_ms)
        except (TimeoutError, TwinUnavailable):
            return "NO_OPINION"            # 超时/不可用绝不阻塞
        if v == "UNSAFE":
            return "VETO"
        return "NO_OPINION"                # SAFE / UNKNOWN 都不授权

    def admits(self, plan, state_hat) -> bool:
        return self.filter(plan, state_hat) != "VETO"

# IP-443 Twin Absence Auditor (TAA) — 只撤销缺席证书
# ============================================================
class TwinAbsenceAuditor:
    def __init__(self, twin, detector, avatar_sampler, n_avatars: int = 256):
        self.twin, self.detector = twin, detector
        self.avatar_sampler = avatar_sampler
        self.n_avatars = n_avatars

    def audit(self, abs_cert, cov_t) -> "AbsenceCertificate":
        revoked = []
        for _ in range(self.n_avatars):
            av = self.avatar_sampler.sample(cov_t)   # 形态/姿态/材质/光照/遮挡
            img = self.twin.render(av)
            if not self.detector.detect(img, cls="human"):
                revoked.append(av.region)            # 漏检 ⇒ 撤销该子区
        out = abs_cert
        for region in revoked:
            out = out.restrict_excluding(region)     # 只能收缩
        return out

    def update_recall_bound(self, kappa_c: float, miss_rate: float) -> float:
        return max(0.0, kappa_c - miss_rate)          # κ_c 只降不升

# IP-444 Twin Fidelity Divergence Monitor (TFDM)
# ============================================================
class TwinFidelityMonitor:
    """估计 sim2real 差距 → 只用于调节否决权（活性），不参与授权。"""
    def __init__(self, delta_twin_max: float = 0.05):
        self.delta_twin_max = delta_twin_max

    def update(self, twin_preds, real_outcomes) -> float:
        self.gap = torch.mean(torch.abs(twin_preds - real_outcomes)).item()
        return self.gap

    def veto_authority(self) -> bool:
        # 差距过大时放弃否决权（换活性）；安全上界不受影响
        return getattr(self, "gap", 0.0) <= self.delta_twin_max


# ============================================================
# IP-445 Cross-Port Federated Audit Chain (CPFAC)
# ============================================================
@dataclass
class PortRecord:
    port_id: str
    cert_h: bytes
    plan_h: bytes
    outcome: str
    V: "VersionTuple"
    twin_v: str
    ts: float
    prev_h: bytes
    sig: bytes
    def digest(self) -> bytes:
        return sha256((self.port_id, self.cert_h, self.plan_h, self.outcome,
                       self.V.payload_hash, self.twin_v, self.ts, self.prev_h)).digest()


class CrossPortAuditChain:
    def __init__(self, pk_ports: dict, alpha: float = 0.01):
        self.pk_ports, self.alpha = pk_ports, alpha
        self.heads: dict[str, bytes] = {}
        self.records: dict[str, list[PortRecord]] = defaultdict(list)

    def append(self, rec: PortRecord) -> bytes:
        rec.prev_h = self.heads.get(rec.port_id, b"\x00" * 32)
        rec.sig = sign(self.pk_ports[rec.port_id], rec.digest())
        self.records[rec.port_id].append(rec)
        self.heads[rec.port_id] = rec.digest()
        return self.heads[rec.port_id]

    def verify_chain(self, port_id: str) -> bool:
        prev = b"\x00" * 32
        for rec in self.records[port_id]:
            if rec.prev_h != prev or not verify(self.pk_ports[port_id], rec.digest(), rec.sig):
                return False
            prev = rec.digest()
        return True

    def detect_drift(self, scenario_class: str) -> list[str]:
        """同场景类别在端口间结论分歧 → 标记 UNVERIFIED（保守降级）。"""
        by_port = {p: [r.outcome for r in rs if r.scenario_class == scenario_class]
                   for p, rs in self.records.items()}
        return two_sample_divergence(by_port, self.alpha)   # 返回需降级端口

    def global_root(self) -> bytes:
        return sha256(b"".join(sorted(self.heads.values()))).digest()


# ============================================================
# IP-446 HPC-P 统一五证准入门
# ============================================================
@dataclass
class HPCP:
    hpc_e_plus: "HPCEPlus"
    pmpc: PortabilityCertificate
    dtrc: TwinRehearsalCertificate
    taa: TwinAbsenceAuditor
    cpfac: CrossPortAuditChain

    def admits(self, plan, port: PortManifest, state_hat, src_scores, tgt_scores,
               local_envelope, base_args) -> bool:
        # 1) v23 四证（几何∧规范∧负信息∧能量∧云边∧少样本∧IP）
        if not self.hpc_e_plus.admits(*base_args):
            return False
        # 2) 可移植：有见证，或退回包络求交（只会更小）
        witness = self.pmpc.certify(None, None, port, src_scores, tgt_scores)
        if witness is None and not self.pmpc.local_fallback(None, port, local_envelope):
            return False
        # 3) 孪生单侧否决（NO_OPINION 放行，VETO 拒绝）
        if not self.dtrc.admits(plan, state_hat):
            return False
        # 4) 端口审计一致（分歧端口降级为本地包络，此处拒绝跨端口授权）
        if not self.cpfac.verify_chain(port.port_id):
            return False
        return True
```

## 2. 复杂度分析

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| PMPC 可移植见证 | O(n log n)（kNN/两样本分类）离线 | O(n) | n≤10⁵/端口对，n_min=200 |
| PPWC 加权分位数 | O(n log n) 建表 / O(1) 查询 | O(n) | n≤5000/端口 |
| DTRC 孪生演练 | O(H)（仿真时域）/ 计划，可并行 | O(H) 轨迹缓冲 | deadline=50ms，H≈100 步 |
| TAA 缺席审计 | O(n_av·(render+detect)) 后台 | O(n_av) | n_av=256，秒级、非控制路径 |
| TFDM 保真度监测 | O(1)/样本增量 | O(1) | 滑窗 1000 |
| CPFAC 追加/验证 | O(1) 追加 / O(log n) 包含证明 | O(n) | 每端口链长 n≤10⁶ |
| HPC-P 准入 | O(1) + 委托（无阻塞 I/O） | O(1) 增量 | 50Hz 关键路径 <20ms |

**实时性保证**：控制路径只做 `sync_predicate`（v23 O(1)）+ `Portable` 查表（见证预计算）+ `DTRC.filter`（带 50ms deadline，超时即 NO_OPINION）+ `CPFAC` 本地链验证（O(1) 头部校验）。PMPC/PPWC/TAA/TFDM 全部离线或后台异步，不进入 50Hz 环。

## 3. 正确性论证

### 引理 5（可移植覆盖界）
**陈述**：若 `Portable(C,p→q)` 成立且源端以 `α_p = α − Δ_budget` 校准，则目标端口覆盖 `P_{q}(Y∈C) ≥ 1−α`。

**证明**：
1. 加权 conformal 在协变量偏移下的标准界：`P_q(Y∈C) ≥ 1 − α_p − d_TV(P_q,P_p)`（Tibshirani et al. 2019；`d_TV = ½E_p|w−1|`）。
2. 由见证 `d_TV(P_q,P_p) ≤ Δ_budget`，代入得 `≥ 1 − (α−Δ_budget) − Δ_budget = 1−α`。
3. 有限样本修正：`n_eff ≥ n_min` 保证加权经验分位数的集中不等式成立（有效样本量控制方差）。
4. 多跳 p→q→r：`d_TV(P_r,P_p) ≤ d_TV(P_r,P_q)+d_TV(P_q,P_p)`（三角不等式），故 α 预算须按累计距离预留；`n_eff` 随重加权乘积衰减，限制链长。
∎

### 引理 6（孪生单侧安全定理）
**陈述**：对**任意**孪生 `T_p`（包括对抗性错误孪生），`Exec_v24 = Exec_v23 ∩ Fil_twin ⊆ Exec_v23`；孪生保真度只影响 `|Exec_v24|`（活性），不影响安全上界。

**证明**：
1. `Exec_v24` 按定义等于 `Exec_v23` 与 `Fil_twin` 的交，故集合包含关系与孪生输出无关，恒有 `⊆ Exec_v23`。
2. v23 的安全性由 HPC-E+ 保证：`π ∈ Exec_v23 ⇒ Safety(π)`。
3. 因此 `π ∈ Exec_v24 ⇒ π ∈ Exec_v23 ⇒ Safety(π)`，与孪生是否正确无关。
4. 孪生"假 UNSAFE"只会缩小 `Fil_twin`（活性下降）；"假 SAFE"不能使 `π` 绕过 `Exec_v23`（架构上无 `GRANT` 返回值）。
∎

**推论**：孪生越不准，系统只会越保守；把孪生用于放行 AbsCert/放宽能量即等价于引入无证明的 `GRANT`，引理 6 不再适用——这正是本轮最大风险的来源。

### 引理 7（缺席审计单调收缩）
**陈述**：`AbsCert_v24 = AuditAbs(T_p, AbsCert_v23) ⊆ AbsCert_v23`，且审计后召回下界 `κ_c^audit ≤ κ_c`。

**证明**：
1. `audit` 对每个漏检虚拟人所在子区调用 `restrict_excluding`，只做集合差，故结果必为原证书子集。
2. 全部检出时不做任何修改（返回原证书）；任一漏检时严格收缩。
3. `update_recall_bound` 取 `max(0, κ_c − miss_rate)`，单调不增。
4. 审计器永不调用签发接口，故不存在"审计扩大 AbsCert"的路径。
∎

### 引理 8（多端口审计不可抵赖与漂移可检测）
**陈述**：任何对历史记录的改写都会破坏 `prev_h` 链并被 `verify_chain` 检出；端口间系统性分歧会被 `detect_drift` 以显著性水平 α 标记为 `UNVERIFIED`，从而降级为本地包络（保守）。

**证明**：
1. 每条记录 `digest` 含 `prev_h` 且签名，篡改任一字段需同时伪造后续所有 `prev_h` 与签名（哈希抗碰撞 + 签名不可伪造）。
2. `verify_chain` 逐条校验 `prev_h` 连续性与签名，任一断裂即返回 False。
3. `detect_drift` 对同场景类别的结果分布做两样本检验；拒绝同分布假设即以概率 ≥1−α 触发降级。降级仅收紧执行集。
∎

### 定理（HPC-P 五证一体的安全-可移植-可审计完备性）
**陈述**：对任意计划 π，`HPCP.admits(π)=True` ⟺ π 同时满足：
(1) v23 四证（几何∧规范∧负信息∧能量∧云边∧少样本∧IP）；
(2) 存在可移植见证或已退回包络求交；
(3) 孪生未否决；
(4) 端口审计链完整且该端口未被标记 `UNVERIFIED`。
且任意失效下 `Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18`。

**证明**：由 `HPCP.admits` 的四个连言条件直接得充要性。每个条件对应一个过滤器：`Fil_ce∩Fil_fs∩Fil_ip`（v23）、`Fil_port`（见证或求交，只收缩）、`Fil_twin`（只否决）、`Fil_audit`（只降级），四者皆为集合收缩，故 `Exec_v24 = Exec_v23 ∩ Fil_port ∩ Fil_twin ∩ Fil_audit ⊆ Exec_v23`；再由 v23 的单调链传递得全链。失效分析：PMPC/DTRC/TAA/CPFAC 任一失效均使对应过滤器退化为全集或更严子集（见 §3 退化表），方向始终向保守，故链条保持。
∎

## 6. 本轮最大风险（最终确认）

**一句话**：孪生只有在被严格限制为"只否决/只撤销"时才是安全的；而多端口扩张下逐端口重认证成本高，工程上极易把孪生悄悄升级为"授权器"（用孪生放行 AbsCert、放宽能量裕度或扩大可达集），一旦如此，安全就重新押在无法验证的 sim2real 保真度上，`Exec_v24 ⊆ Exec_v23` 的单调链会在无人察觉处断裂——即"把否决器误用为授权器"的静默越权。
