# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；本轮灵感：「主动交互」×「模型蒸馏」）

> R69 已经让系统学会「问」：把不确定性拆成 (U_ale, U_epi)，用流匹配策略显式表示多模态，用 MINT 按 VoI 选择看/问/触，并自陈其最大风险——**若模态权重不可信，VoI 就是在错误的信念上计算，系统会自信地追问幻影**。R69 给出的答案是「模态校准门 MCG：ECE 越界就退回纯保守」。
>
> 但这里藏着一个更深、更尴尬的问题：**那个用来判断「该不该问」的不确定性估计器，本身很可能是从更大的教师模型里蒸馏出来的。** 部署在真实机器人上的学生必须实时；实时只能靠蒸馏；而蒸馏恰恰是「制造自信」的操作——它把多峰教师压成单峰学生（模式坍缩），把软标签压成硬标签（过度自信），还会把 R69 赖以做第二意见的流似然一起改写。于是 R69 的安全机制可能不是被攻击关掉的，而是**在自己的压缩过程中被静悄悄地关掉的**：学生不再问，不是因为没有歧义，而是因为它忘了自己曾经会犹豫。
>
> 本轮两个灵感正好接成一个闭环：
> - **模型蒸馏**不是「把教师变小」这么简单，而是**教师策略的有损压缩**；压缩的失真不是动作误差，而是**被抹掉的模态结构**——我们叫它 epistemic debt（认知债务）。
> - **主动交互**不只是「问世界」，它同时是**压缩信道的反馈**：每一次提问既消除当前任务歧义，又产生一个最靠近学生盲区的「硬样本」，喂回慢环去修学生的债务。
>
> 核心命题：**蒸馏决定学生有多快，认证债务决定学生有多诚实，主动交互决定债务在哪里被偿还；三者焊成一个快-慢双环。学生永远不能比「认证债务」允许的更自信；任何交互证据在进入权重之前，必须先过比 R69 更严的隔离、正交与溯源纪律——因为一次错误的提问在 R69 里只错一集，在 R70 里会被固化进权重、从此再也想不起来要问。** 命名 **ECHO-RAS**（Epistemic-debt Certified Honest-Oracle distillation & active interaction）：学生是教师的回声；回声的问题不在于不响，而在于**它不知道自己丢了哪些频率**。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我用来决定该不该问的那把尺子，本身是不是蒸馏出来的赝品；如果是，我怎么知道自己量错了多少**」。

## 0. 直觉与动机

**灵感 1（蒸馏是压缩，不是复制 → 失真就是被抹掉的多模态）**
直觉：教师是一个又大又慢、可以采很多次样的多模态策略；学生要实时，只能小、只能少采样。这本质是一次**有损压缩**。压缩会丢东西，但丢的不是像素，而是**概率质量在模态之间的分配**。两峰教师压成单峰学生，学生在「绕左/绕右」中间生成「直行」——两个安全动作的平均值恰好是那个不安全的动作。R69 的 AUD 把这种结构当作安全信号；蒸馏却在训练时把它当成噪声压掉。第一个新量因此不是「学生多准」，而是**学生保留了多少教师的模态结构**。

**灵感 2（epistemic debt → 学生必须知道自己忘了什么）**
直觉：R69 假设学生能诚实报告 H_mode 与 U_epi。但「诚实报告不确定性」这件事本身也是学出来的；一个被蒸馏过的学生完全可能**在真实歧义处输出低 H_mode**。于是需要一个独立于学生自报的量：教师与学生模态后验的差异 D_epi。它不能在线算（教师不在场），所以用代理头 + **split conformal** 给出上界 D̂_hi，并把 U_epi 保守地抬高。核心姿态：**宁可多问，不可静默自信**；只有当债务上界很紧时，才允许拿 R69 的 resolution bonus。

**灵感 3（主动交互是反馈信道 → 提问同时是采样）**
直觉：在有反馈的信道里，接收端可以请求重传。R69 的 MINT 只在「当前该选哪个模态」上算 VoI，是**短视**的；R70 要算两种货币：当前任务的信息增益 ΔH_task，以及这次交互对**未来学生债务**的削减 DVoI。一次提问如果恰好落在学生坍缩掉的模态上，它的教学价值远大于它的任务价值。用主动学习语言：惊讶度 × 代表性 ÷ 冗余度。交互预算就是信道速率，按**反注水**分配给边际失真最大的区域。

**灵感 4（教师不是学生的正交证人 → 证据纪律要升级）**
直觉：R69 的证据纪律说「k 个正交源一致」。但 R70 里多了一个微妙陷阱：**教师和学生共享盲区**（学生就是从教师蒸馏来的）。所以「教师也同意」不能算作独立第二意见；对「学生的债务估计对不对」，教师是基准；但对「人类回答有没有投毒」，教师-学生是同一支证人。正交性必须显式建模，否则 k-一致会退化成「自己给自己作证」。

**灵感 5（固化谎言 → 慢环比快环更需要证据纪律）**
直觉：R69 的引理 18 只保证「单次交互不单独定案」，错也只错一集。R70 把交互结果喂进蒸馏集，一次投毒就可能**变成永久的权重**——这不是「被证实的错误」，而是「被制度化的错误」。而且重复提问可能得到同一个共谋谎言；只有**事后世界**（任务成功/失败、后续观测）能真正裁决。所以隔离区必须在「未来」上验证，而不只在「当下的一致」上验证；同时保留按溯源回滚的能力。

**灵感 6（双过程理论 → 快系统需要被蒸馏出来的元认知）**
直觉：人类专家把慢速刻意的推理（System 2）练成快速直觉（System 1），但保留了「我觉得这里不对劲」的元认知。R70 就是给 System 1 学生蒸馏一个来自 System 2 教师的**校准元认知**：不是把教师的答案抄下来，而是把教师的「犹豫的形状」和「何时该停下来想」一起抄下来。没有元认知的自动化，是最危险的自动化。

## 1. 形式化定义（增量：定义 310–325）

**定义 310（ECHO-RAS 总览与四不变式）** ECHO-RAS = (MKD, EDE, FCA, AQD, DPQ, RDI, RAS-WM†)，其上仍运行 R69 的 (FMP, AUD, MINT, CIA, FMA)。四个不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i；快环只写隔离区与日志，不改权重）；
(ii) **不可静默自信**：学生对外使用的有效 epistemic 不确定性必须 ≥ 其自报值，且 w.p. ≥ 1−α 覆盖教师-学生债务（定义 315）；
(iii) **入权重证据的门槛高于入决策证据**：任何进入蒸馏集的样本必须带溯源并过正交/事后验证（定义 319），k 个证据源中**教师-学生不得互相作证**；
(iv) **可回滚有界**：任一被判定为投毒的样本，可在 ≤ T_rollback 内按分片回滚，残留影响 ≤ ε_rb（定义 320）。

**定义 311（教师-学生通道与速率）** 教师 T = (FMP_T, AUD_T) 为大容量、多采样（K_T≫K_S）、可多模态的慢策略；学生 S = (FMP_S, AUD_S) 为实时策略。蒸馏数据 D_distill 由教师 rollout 与**已晋升**的交互日志构成。把蒸馏视为速率 R_S（学生容量/采样预算）下的有损压缩，其失真由 epistemic debt 度量（定义 314）。

**定义 312（模态保持蒸馏 MKD）** 学生目标
L_MKD = L_flow + α·L_mass + β·L_sep + γ·max(0, δ_m − (H_mode^S − H_mode^T))，
其中 L_flow 为速度场/轨迹匹配（保行为保真）；L_mass = Σ_k [ ŵ_k^T·max(0, ε_m − ŵ_k^S) ] + KL(ŵ^T ‖ ŵ^S) 为**模态质量匹配 + 防丢模态铰链**（通过 Sinkhorn 软指派对齐教师原型）；L_sep = Σ_{i≠j} |W_2(ξ̄_i^S, ξ̄_j^S) − W_2(ξ̄_i^T, ξ̄_j^T)| 保模态几何；最后一项为**熵不塌缩约束**（拉格朗日形式）。前提 A99：学生容量 R_S 至少能表示 K_T 个模态，否则失真存在不可约下界，必须如实计入债务而不是假装 MF=1。

**定义 313（模态保真度 MF）** 在标定集上比较 (K̂, ŵ, ξ̄, Δ_min, Σ)：mode recall = 教师模态中被学生覆盖（ŵ_k^S≥ε_m）的比例；mode precision = 学生模态中能匹配教师原型的比例；weight-ECE = 模态权重的校准误差；geometry error = 原型两两 W_2 的相对误差。MF 为这四项的加权几何平均，MF∈[0,1]。

**定义 314（Epistemic debt）** 对观测 o，D_epi(o) = TV(p_T(M|o) ‖ p_S(M|o)) + D_halluc(o)，其中 D_halluc 为学生落在教师支撑外的模态质量（幻觉模态）。它可分解为**丢模态 / 生幻影 / 权重错位**三项。关键：教师在线不可见，故 D_epi 只能离线在标定集上算，并在线用代理上界替代（定义 315）。

**定义 315（认证债务 EDE 与 OOD 守卫）** 代理头 φ(z_S) → D̂。用 split conformal：在标定集上取非一致性分数 s_i = D_epi(o_i) − D̂(o_i)，取 q̂ = Quantile_{1−α}(s)，得在线上界 D̂_hi(o) = D̂(o) + q̂，满足 P(D_epi ≤ D̂_hi) ≥ 1−α（可交换性下）。**OOD 守卫**：若 o 落在标定分布之外（特征密度低或 FMA 异常），可交换性破裂，强制 D̂_hi = D_max。安全侧有效不确定性
U_epi^safe = min(H_max, H_mode^S + ln K̂·D̂_hi + ln 2)，
（丢弃 g(Δ_min) 的折扣，偏保守；理由见引理 20）。只有当 MF ≥ τ_MF 且 D̂_hi ≤ τ_debt 时，才允许用回 U_epi^S = H_mode^S·g(Δ_min) 并领取 resolution bonus。

**定义 316（双货币 VoI 与反馈信道分配）** 信息动作 g 的总价值
V(g) = VoI_task(g) + η·DVoI(g) − c(g) − λ_r·risk(g)，
VoI_task 继承 R69 定义 298；DVoI(g) = E[Δ D_epi^{future}] 为对未来学生债务的期望削减，用**惊讶度 × 代表性 ÷ 冗余度**做代理（惊讶度 = 学生在该样本上的负对数似然或与教师的分歧；代表性 = 特征空间密度；冗余度 = 与 D_distill 的最大相似度）。交互预算视为速率约束；当各区域增益凹时，最优分配为**反注水**（给边际失真削减最大的区域更多交互位）。

**定义 317（信息源正交性 Ω）** 源集合 𝒮 = {人, 教师, 额外采样, 跨模态, 事后观测}。定义正交矩阵 Ω_{ij} ∈ [0,1] 为两源错误的可交换/相关程度。**关键约束**：Ω_{教师,学生} ≈ 1（共享盲区），故教师不得作为「学生债务估计」之外任何投毒判定的第二证人；k-一致纪律要求所选 k 源两两 Ω < τ_Ω。

**定义 318（主动查询蒸馏 AQD）** 交互结果 e（人类回答 / 教师输出 / 探针观测）成为候选蒸馏样本，权重
w(e) ∝ surprisal(e | S, o) · representativeness(o) · reliability(source) / redundancy(e, D_distill)。
即「学生越没想到、越有代表性、越不重复」的样本，教学价值越高。同一句话既用于当前后验更新（R69 CIA），也进入隔离区等待晋升（定义 319）——**问与学共用一次交互**。

**定义 319（蒸馏隔离区 DPQ）** 候选样本先入隔离区 Q，不碰权重。晋升到 D_distill 需满足：
(a) **正交验证**：除教师-学生对外的 k 源一致（定义 317）；或
(b) **事后验证**：在窗口 T_hind 内，后续观测/任务结局与该样本一致（世界裁决优先于重复证词）。
隔离区有 TTL、毒样本检测器与容量上限；未晋升样本定期丢弃。

**定义 320（溯源与分片回滚 RDI）** 每个样本带溯源哈希链（来源、时间、证据源、师生版本、晋升理由）。D_distill 分片训练。发现投毒后，定位最小分片并回滚重训；保证恢复时间 ≤ T_rollback、残留影响 ≤ ε_rb。诚实声明：这是**分片级**回滚，不是精确 unlearning；代价是可能连带丢弃同分片的好样本。

**定义 321（校准继承与双钥匙门）** 若教师 ECE ≤ ε_T 且 MF ≥ 1−δ，则学生 ECE ≤ ε_T + g(δ)（校准继承界）。R69 的 MCG 升级为**双钥匙**：ECE 与 MF 同时达标才允许 VoI 决策与 resolution bonus；任一越界即用 U_epi^safe 退避，绝不让学生自报的低熵驱动交互。

**定义 322（固化风险）** R_cons = δ_p · ρ_promote · (1 − p_detect) · T_retention，其中 δ_p 为投毒率、ρ_promote 为毒样本通过隔离区的概率、p_detect 为审计检出率、T_retention 为错误在权重中的存活时长。目标 R_cons ≤ ε_cons。DPQ + RDI + 事后验证共同压低后三项。

**定义 323（蒸馏证书 J_ECHO）** J_ECHO = (J_FLUID, teacher_ver, student_ver, MF, D̂_hi_coverage, ECE_S, provenance_root, quarantine_stats, rollback_manifest, echo_ver)。Valid ⇔ Valid(J_FLUID) ∧ MF ≥ τ_MF ∧ coverage ≥ 1−α ∧ DPQ/RDI 不变量成立。

**定义 324（两键退避与 R69 边界）** 三档：
(A) **教师在场**：直接跑 R69（教师 = FMP），蒸馏只做旁路 → R70 严格包含 R69，逐指令可退化；
(B) **教师缺席 + 证书有效 + 债务小**：U_epi^safe 收紧到接近 H_mode^S，允许认证 resolution bonus；
(C) **证书失效/债务大/OOD**：D̂_hi = D_max，U_epi^safe 吞掉全部 epistemic，λ = λ_floor(U_ale + U_epi^safe)，即 R69 纯保守的等价物。
因此 R70 在「无教师」时也**不会比证书允许的更乐观**；保守侧单调不弱于 R69。

**定义 325（快-慢双环与写入边界）** 快环：推理 + 交互决策 + 写隔离区/日志（零权重写）。慢环：MKD 蒸馏、conformal 重标定、DPQ 晋升、RDI 回滚；只在安全停顿（充电/驻停/离线）执行，绝不在任务中改权重。两环通过 J_ECHO 与版本号握手；快环发现证书过期立即退到 (C) 档。

# IP-264 MKD：模态保持蒸馏（教师离线采样，学生实时；防模式坍缩）
def distill_mode_preserving(T, S, D_distill, calib):
    for o, _ in D_distill:
        teacher_modes = cluster(T.sample(o, K_T))       # 教师模态/权重/原型
        L  = flow_loss(S, T, o)                         # 行为保真
        L += alpha * mass_loss(S, teacher_modes, o)     # Sinkhorn + 防丢模态铰链
        L += beta  * geometry_loss(S, teacher_modes, o) # 原型两两 W2
        L += gamma * entropy_floor_loss(S, teacher_modes, o)  # H_S >= H_T - delta
        S.update(L)
    return S

# IP-265 EDE：认证 epistemic 债务（split conformal + OOD 守卫）
def certify_debt(S, T, calib, alpha):
    scores = [tv(T.mode_posterior(o), S.mode_posterior(o)) - S.debt_head(o)
              for o in calib]
    q_hat = quantile(scores, 1 - alpha)
    def D_hi(o):
        if ood(o): return D_MAX                      # 可交换性破裂 → 最悲观
        return clip(S.debt_head(o) + q_hat, 0, D_MAX)
    return D_hi, q_hat

# IP-266 FCA：双货币 VoI + 反注水预算分配
def choose_info_action(S, modes, o, budget, D_hi):
    best = None
    for g in sources_and_info_actions(modes):        # 人/教师/探针/多看
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        voi  = entropy(modes) - expected_entropy(modes, g, o)        # 当前任务
        dvoi = surprisal_proxy(modes, g, o) * representativeness(o) \
               / redundancy(g, D_distill)                            # 未来债务
        score = voi + eta * dvoi - cost(g) - lam_r * risk(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 无利可图 → R69 退避

# IP-267/319 AQD+DPQ：交互结果先隔离、后晋升
def ingest_interaction(e, o, provenance):
    if not provenance.complete(): return
    q = quarantine.put(e, o, provenance,
                       weight=surprisal(e) * repr(o) / redundancy(e))
    # 晋升：正交 k-源一致（排除教师-学生）或事后世界裁决
    if orthogonal_agree(e, k=2, exclude={('teacher','student')}) or hindsight_ok(e):
        D_distill.promote(q); provenance.link(q, 'promoted')

# IP-270/321 MFE：双钥匙门 + 安全膨胀
def gate_and_inflate(S, modes, o, D_hi):
    MF, ECE = mode_fidelity(S), student_ece(S)
    trusted = (MF >= TAU_MF) and (ECE <= TAU_ECE)
    U_safe  = min(H_MAX, entropy(modes) + log(K) * D_hi(o) + LOG2)
    return (U_safe, trusted)

# IP-276 ECHO 主闭环（继承 R69 + 教师可选）
def ECHO_ROUND(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    if M.teacher_available:                          # (A) 教师在场：跑 R69
        k, lam, mode, U = M.fluid_round(o)           # 旁路记录蒸馏样本
        M.dpq.observe_passive(...); return k, lam, mode, U
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    modes, w = M.aud.decompose(M.fmp.sample(o, K), z)
    D_hi = M.ede.D_hi(o)
    U_safe, trusted = M.mfe.gate_and_inflate(M.student, modes, o, D_hi)
    g = (M.fca.choose_info_action(modes, o, M.budget, D_hi)
         if (U_safe > TAU_EPI) else None)
    if g is not None:
        e = M.cia.execute(g)                         # 看/问/触/问教师
        U_safe = M.cia.update_belief(modes, e)
        M.dpq.ingest(e, o, M.log.provenance(g))      # 只进隔离区，不碰权重
    if not trusted:                                  # (C) 证书失效 → 纯保守
        U_safe = max(U_safe, U_ale + H_MAX)
    lam = max(M.efs.risk_scale(...), lam_floor(U_safe))
    k = M.c_ras_wm.certified_prefix(...)
    M.vqa_d.submit_async(g, D_hi, trusted, M.dpq.stats())
    return k, lam, select_mode(modes, U_safe), U_safe
```

## 3. 推导

**引理 19（均值蒸馏的双峰坍缩下界）** 设教师 p_T(ξ|o)=½δ(ξ−a₁)+½δ(ξ−a₂) 且 ‖a₁−a₂‖=Δ。任何以 ‖f(o)−ξ‖² 为目标的均值型蒸馏，其最优学生输出为 f*=(a₁+a₂)/2；在「a₁,a₂ 安全、中间不安全」的任务中，其期望风险比教师高 ≥ c·Δ − ε_flow。系：**动作误差最小不等于安全**；没有模态质量项，L2/KL 蒸馏会系统性制造「两个安全动作的平均 = 一个不安全动作」。这正是 R69 的 AUD 被蒸馏悄悄关掉的地方。

**引理 20（债务-熵桥与安全膨胀）** 对 K̂ 个共享模态上的教师/学生后验 p_T,p_S，令 δ=TV(p_T,p_S)≤D_epi。熵的连续性给出 |H(p_T)−H(p_S)| ≤ δ·ln(K̂−1)+h_b(δ) ≤ δ·ln K̂ + ln 2。由于 g(Δ_min)≤1，有 U_epi^T=H_T·g_T ≤ H_T ≤ H_S+δlnK̂+ln2。故取 U_epi^safe = H_mode^S + lnK̂·D̂_hi + ln2，当 D̂_hi ≥ D_epi（定义 315 的 conformal 覆盖）时**恒有 U_epi^safe ≥ U_epi^T**。系：学生永远不会因为蒸馏而比教师更少触发交互——它在债务上界内是保守的，而不是自信的。

**引理 21（双货币分配的自适应最优性）** 设每个区域 r 的边际失真削减 Δ_r(b) 随交互预算 b 单调递减（凹/次模）。则反注水分配（持续向 Δ_r'(b) 最大处投预算）给出连续松弛下的最优；离散次模贪心达到 (1−1/e) 近似。系：交互预算不应按状态均匀花，而应按「学生债务 × 歧义 × 代表性」密度花；R69 的逐步贪心 VoI 是 η=0、无预算跨期耦合的特例。

**引理 22（固化谎言上界）** 单源投毒率 δ_p、隔离区晋升需 k 个两两正交（Ω<τ_Ω）证据一致，且事后验证窗口 T_hind 内世界以概率 p_w 揭穿错误，则错误进入权重的概率 ≤ δ_p·(ρ^{k−1}+ε_σ) + (1−p_w)·1[T_hind 内未观测]，再经分片回滚使残留 ≤ ε_rb。系：**慢环的证据门槛必须严格高于快环**——快环错一次只损失一集，慢环错一次改写未来所有集。

**定理 18（教师在场时严格包含 R69）** 当教师在线可用时，ECHO 取 (A) 档，控制回路与 R69 逐指令相同，蒸馏仅旁路写日志；因此期望风险 ≤ R69，且所有 R69 的不变式（定义 293）保持。R70 是 R69 在「有教师」方向的严格扩展，而不是替代。

**定理 19（教师缺席时的保守安全）** 在 A99（学生容量足够）与定义 315 的 conformal 覆盖下，w.p. ≥ 1−α 有 U_epi^safe ≥ U_epi^T，故交互触发率不低于教师策略；当证书失效/OOD/MF 越界时 D̂_hi=D_max，退化为 R69 纯保守。所有信息动作仍过 C-RAS-WM 认证（定义 302），故物理风险 ≤ ε_int；认证 resolution bonus 只在「债务已被证明很小」时发放，故安全侧相对 R69 没有新增让步。

**定理 20（双环无突变与回滚安全）** 快环权重冻结 + 慢环仅在安全停顿执行 ⇒ 控制连续、无参数突变；回滚只使 J_ECHO 失效并把快环切到 (C) 档，不改变安全包络；继承 R68/R69 的提交/换装不变式。系：**可回滚性本身是安全属性，不是运维细节**——没有溯源与回滚，慢环的每一次学习都是一次不可撤销的承诺。

## 6. 本轮最大风险

**一句话**：ECHO-RAS 把安全押在「认证债务估计器能诚实报告学生丢失了什么」上，但估计器本身也是蒸馏出来的、其 conformal 覆盖依赖可交换性——**一旦它在分布漂移下系统性低估债务，学生就会比教师更自信、更少求证，而 R69 的「问错」在这里升级为「把错误固化进权重、并且再也想不起来要问」**——这比不问更危险，因为它把一次性的错误变成了永久的性格。

**次级风险与缓解**：学生容量不足导致不可约债务（A99 + 容量审计 + 债务如实计入）；交互结果投毒→固化（DPQ 事后验证 + 正交矩阵 + RDI 分片回滚 + 引理 22）；教师-学生共享盲区被当成双重确认（定义 317 显式禁止）；慢环学习影响实时安全（双环 + 证书握手 + 安全停顿）；OOD 下 conformal 失效（OOD 守卫强制 D_max）。

# IP-264 MKD：模态保持蒸馏（防「两个安全动作的平均」）
def distill_mode_preserving(T, S, D_distill):
    for o, _ in D_distill:
        tm = cluster(T.sample(o, K_T))                 # 教师模态/权重/原型
        L  = flow_loss(S, T, o)                        # 行为保真
        L += alpha * mass_loss(S, tm, o)               # Sinkhorn + 防丢模态铰链
        L += beta  * geometry_loss(S, tm, o)           # 原型两两 W2
        L += gamma * entropy_floor_loss(S, tm, o)      # H_S >= H_T - delta
        S.update(L)

# IP-265 EDE：split conformal 认证债务 + OOD 守卫
def certify_debt(S, T, calib, alpha):
    s = [tv(T.mode_posterior(o), S.mode_posterior(o)) - S.debt_head(o)
         for o in calib]
    q = quantile(s, 1 - alpha)
    return (lambda o: D_MAX if ood(o)
            else clip(S.debt_head(o) + q, 0, D_MAX)), q

# IP-266 FCA：双货币 VoI（当前任务 + 未来债务）
def choose_info_action(S, modes, o, budget, D_hi):
    best = None
    for g in sources_and_info_actions(modes):
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o): continue
        score = (entropy(modes) - expected_entropy(modes, g, o)) \
              + eta * surprisal(g, o) * repr(o) / redundancy(g, D_distill) \
              - cost(g) - lam_r * risk(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None   # 无利可图 → R69 退避

# IP-267/319 AQD+DPQ：先隔离、后晋升（师生不得互证）
def ingest(e, o, prov):

    q = quarantine.put(e, o, prov,
                       weight=surprisal(e) * repr(o) / redundancy(e))
    if orthogonal_agree(e, k=2, exclude={('teacher','student')}) or hindsight_ok(e):
        D_distill.promote(q); prov.link(q, 'promoted')

# IP-270/321 MFE：安全膨胀 + 双钥匙

    trusted = (MF >= TAU_MF) and (ECE <= TAU_ECE)
    U_safe  = min(H_MAX, entropy(modes) + log(K) * D_hi(o) + LOG2)
    return U_safe, trusted

        e = M.cia.execute(g)
        U_safe = M.cia.update_belief(modes, e)
        M.dpq.ingest(e, o, M.log.provenance(g)) # 只进隔离区
    if not trusted: U_safe = max(U_safe, U_ale + H_MAX)   # (C) 纯保守
    lam = max(M.efs.risk_scale(...), lam_floor(U_safe))
    k = M.c_ras_wm.certified_prefix(...)
    M.vqa_d.submit_async(g, D_hi, trusted, M.dpq.stats())
    return k, lam, select_mode(modes, U_safe), U_safe
```

## 4. 推导

**引理 19（均值蒸馏的双峰坍缩下界）** 教师 ½δ(a₁)+½δ(a₂)，‖a₁−a₂‖=Δ；均值型蒸馏最优输出 `(a₁+a₂)/2`。在「两端安全、中间不安全」任务中，风险比教师高 ≥ `c·Δ−ε_flow`。系：L2/KL 蒸馏没有模态质量项时会系统制造「两个安全动作的平均=一个不安全动作」——R69 的 AUD 在蒸馏中被悄悄关掉。

**引理 20（债务-熵桥与安全膨胀）** `|H(p_T)−H(p_S)| ≤ δln(K̂−1)+h_b(δ) ≤ δlnK̂+ln2`，δ=TV≤D_epi。又 g≤1，故 `U_epi^T=H_T·g_T ≤ H_T ≤ H_S+δlnK̂+ln2`。取 `U_epi^safe=H_S+lnK̂·D̂_hi+ln2` 且 `D̂_hi≥D_epi`，则恒有 `U_epi^safe ≥ U_epi^T`。系：学生不会因蒸馏而比教师更少触发交互——在债务上界内它保守，而非自信。

**引理 21（双货币分配的自适应最优性）** 各区域边际失真削减随预算递减（凹/次模）时，反注水为连续松弛最优；离散次模贪心达 `(1−1/e)`。系：预算应按「债务×歧义×代表性」密度花；R69 的逐步贪心 VoI 是 η=0 且无跨期耦合的特例。

**引理 22（固化谎言上界）** 晋升需 k 个两两正交源一致、事后窗口以概率 p_w 揭穿，则错误进入权重概率 ≤ `δ_p(ρ^{k−1}+ε_σ)+(1−p_w)·1[未观测]`，再经分片回滚残留 ≤ ε_rb。系：慢环证据门槛必须高于快环——快环错一次损失一集，慢环错一次改写未来所有集。

**定理 18（教师在场严格包含 R69）** 教师在线时取 (A) 档，控制回路逐指令同 R69，蒸馏仅旁路；期望风险 ≤ R69，R69 全部不变式保持。

**定理 19（教师缺席时的保守安全）** A99 + conformal 覆盖下，w.p. ≥ 1−α 有 `U_epi^safe ≥ U_epi^T`，交互触发率不低于教师策略；证书失效/OOD/MF 越界时 `D̂_hi=D_max`，退化为 R69 纯保守；信息动作仍过 C-RAS-WM 认证，物理风险 ≤ ε_int；认证 bonus 只在债务已证很小时发放。

**定理 20（双环无突变与回滚安全）** 快环权重冻结 + 慢环安全停顿执行 ⇒ 控制连续；回滚只令 J_ECHO 失效并切 (C) 档，不改安全包络；继承 R68/R69 提交/换装不变式。系：可回滚性是安全属性，不是运维细节。

## 7. 本轮最大风险

**一句话**：ECHO-RAS 把安全押在「认证债务估计器能诚实报告学生丢失了什么」上，但估计器本身也是蒸馏出来的、其 conformal 覆盖依赖可交换性——**一旦它在分布漂移下系统性低估债务，学生就会比教师更自信、更少求证，而 R69 的「问错」在这里升级为「把错误固化进权重、并且再也想不起来要问」**——这比不问更危险，因为它把一次性的错误变成了永久的性格。

**次级风险与缓解**：容量不足→不可约债务（A99 + 容量审计 + 如实计入）；投毒→固化（DPQ 事后验证 + 正交矩阵 + 分片回滚 + 引理 22）；师生共享盲区被当双重确认（正交矩阵显式禁止）；慢环影响实时安全（快慢双环 + 证书握手 + 安全停顿）；OOD 下 conformal 失效（强制 D_max）。
