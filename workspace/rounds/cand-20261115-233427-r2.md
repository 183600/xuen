# 第 11 轮（新灵感循环第 2 轮；本轮灵感：「模型量化」×「机械臂抓取」）
> **基线**：第 10 轮 MetricVoiceGauge-STF-NRB-LS（定义 540–548；引理 87–91；实验 E571–E590）。
> 本轮纪律：**量化须认证、安全须解析、抓取须条件化**。两个灵感分别治理 v10 的两种债：**量化债**——β_q 仍是一个标量，用它对整个 K 步 rollout 的量化误差"一刀切"覆盖，忽略了误差的层间各向异性、状态依赖与视界累积，这是 v10 最隐蔽的前提；**操作债**——γ_grasp 仍是学习模型的布尔输出，而抓取恰是接触丰富、非光滑、且在语义新颖与模型量化叠加处最不可信的过程。必须保住 v10 铁律：任一新模块失效 ⇒ 声明中立元，行为严格**等价**（量化/感知）或**支配**（抓取）于 v10，不得行为漂移。

## 0. 直觉与动机

**灵感 1（模型量化 → 从"标量 β_q"到"传播误差椭球 + 证书感知比特分配"）**
直觉：v10 刚把全局标量信任 β 换成空间局部化的 β_STF，却在量化处又退回一个全局标量 β_q——同一个错误换了层皮。量化误差不是可以"重标定掉"的噪声，而是一个**资源分配问题**：比特是预算、证书余量是约束、证书对某层激活的敏感度是价格。更关键的是误差会**沿 rollout 累积**：单步量化误差在 K 步 MPC 里被闭环雅可比反复放大/衰减，v10 的 sup‖F̂_q−F‖≤β_q 只在单步、且隐含"误差可被等价吸收"时才成立。核心创新：**认证量化（Certificate-Aware Quantization, CAQ）** 把 β_q 升级为**与视界 K 相关的传播误差椭球 E_q(K)**：由逐层/逐通道量化误差界经闭环线性化传播得到半径 R_q(K)=ε_max(1−ρ^K)/(1−ρ)（ρ<1 收缩）或 ε_max·K（ρ≥1 时按线性最坏），证书用**区间最坏值** m(x̂)−L_m R_q(K) 而非点预测；比特分配解一个**证书敏感度加权的水填充/背包**：min Σ_l s_l c_l 2^{−b_l} s.t. Σ b_l≤B，把比特花在"证书感觉得到"的层（clearance/effort 头、接触瞬间的状态通道），安全头保留 FP16。这把 v10"量化误差被证书吸收"从口号变成可算、可证、可调预算的机制。

**灵感 2（机械臂抓取 → 从"学习式 γ_grasp"到"解析力闭合/笼闭证书"）**
直觉：把安全关键判定交给一个（还被量化的）神经网络，是在最需要确定性的地方引入最不可解释的误差。机械抓取理论恰好提供**不依赖学习模型**的证书：力闭合（接触力能否抵抗任意外扰）、笼闭（物体在几何上能否逃逸）。核心创新：**稳健力闭合证书（RFC）** 与 **笼闭证书（Cage）**——前者在接触位姿不确定 δ_obj、摩擦系数区间 [μ_min,μ_max] 下计算 ε-稳健力闭合裕量 ε*，后者用接触约束下的位形空间拓扑给出**摩擦无关**的逃逸不可达证明；网络只负责**提名候选抓取**（可 INT4），**验证与安全一律走解析路径**（ASG，永不被量化）。再叠加**抓取条件化信任**：物体地标语义新颖度 ν̄_ℓ 单调放大其位姿不确定 δ_obj=δ_0+κν̄_ℓ，于是 ν↑ ⇒ 可行抓取集 A(ν) 单调收缩；ν>τ_grasp 时只许笼闭/大力抓取/请求人——新颖物体不是"更自信地抓"，而是"更保守地抓或求人"。

**灵感 3（耦合 → 安全与性能的误差预算分离）**
直觉：v10 把量化、感知、语义分割三种误差混在一个 β 里，无法判断"哪笔简化花掉了多少安全余量"。v11 立**误差预算账（EBL）**：β_total = L_m R_q(K)（量化）+ ε_p（感知）+ ε_s（语义分割）+ ε_g（抓取不确定性），各项独立校准、按并集界合并；量化只准动"提名侧"预算，安全侧余量由解析证书独占。由此得到本轮的核心命题：**量化只应降低抓取成功率，不应降低安全覆盖率**（引理 96）——这正面回应了 v10 自认的最大风险"INT8 压缩了显著/非显著分割面的安全边际"：v11 不再让量化去决定分割面，而是让区间界与解析几何接管安全。

## 1. 研究问题（轮次升级版）

- **Q1（认证量化）**：如何把标量 β_q 升级为视界相关、各向异性的传播误差椭球 E_q(K)，并用证书敏感度做比特分配，使 K 步 rollout 在 INT4/INT8 混合精度下证书覆盖率 ≥99.9%、且误差不随 K 发散（给出 ρ 的可验证条件）？
- **Q2（解析抓取）**：如何在位姿/摩擦不确定与语义新颖下计算 ε-稳健力闭合与笼闭证书，使抓取安全不依赖量化网络，且"换抓型/请求人"修复可证不扩权（支配 v10）？
- **Q3（预算分离）**：如何把总误差预算在量化/感知/语义/抓取间可证分配，使"INT4 提名 + FP16 证书/安全头 + 解析验证"在 ≤25W、50Hz、决策 p99≤20ms 下同时满足物理安全与抓取成功率？

## 2. 设计原则（在 P13–P15 基础上新增 P16–P18）

**P16 认证量化律（Certificate-Aware Quantization, CAQ）**
量化误差必须以**传播后、按层/按通道分解、随视界 K 增长**的误差集进入证书；禁止用单一标量覆盖整个 rollout。比特分配以证书敏感度为价格（敏感层多比特），安全关键头（clearance/effort）不低于 FP16。

**P17 安全解析律（Analytical Safety, RFC/Cage/ASG）**
一切安全关键判定（力闭合、笼闭、净空、停车不变式）必须由解析/几何证书或**带误差集的区间**给出；学习模型（尤含量化模型）只许提名候选与打分，禁止单独放行安全。ASG 路径永不被量化、蒸馏或消融。

**P18 抓取条件化信任律（Grasp-Conditioned Trust）**
语义新颖度 ν̄ 必须单调放大物体位姿/摩擦不确定并单调**收缩**抓取可行集；ν↑ 只许更保守的抓取（笼闭/大力）或请求人，不得因"模型自信"放松。

## 3. 与基线的接口（如何退化）

- CAQ/REP 失效（敏感度不可算或 ρ 校准未过）⇒ 回退 v10 的 FP 前向模型 F̂ + β_base（放弃内存收益，安全不降）；若 FP 亦不可用 ⇒ K=1 + β_base；
- ρ 校准失败（接触区非光滑、局部扩张）⇒ 用线性最坏界 ε_max·K，并以 K_eff 反解使 L_m ε_max K ≤ 余量；仍不可行 ⇒ K=1 且禁高速接触接近；
- RFC 失效 ⇒ γ_grasp:=false（禁止抓取），任务退化为搬运/观察，等价 v10 的最保守 γ_grasp；
- Cage 失效 ⇒ 仅 RFC；RFC+Cage 全失效 ⇒ 请求人 + 语音披露（并入 Π_r）；
- 量化提名器失效 ⇒ 回退 v10 FP 提名器；预算账越界 ⇒ 先降为均匀 INT8，再回退 FP；
- 其余（STF/NRB/AC/MW/ID/v8）沿 v10 退化链：Level-1 STF ⇒ K=1；Level-2 NRB ⇒ Π_r；… ⇒ v6。

## 4. 预期贡献

1. **认证量化与误差传播**：把 β_q 升级为 E_q(K) 椭球 + 证书敏感度比特分配，INT4 提名使模型内存 ↓≥87.5% 而证书覆盖率 ≥99.9%（引理 92–93、96）；
2. **解析抓取证书**：稳健力闭合 ε*-FC 与摩擦无关笼闭，安全不依赖学习模型；抓取条件化信任使新颖物体可行抓取集单调收缩（引理 94–95、97）；
3. **安全-性能误差预算分离**：量化只影响成功率、不影响安全覆盖率；EBL 使每笔简化可审计（引理 96）；
4. **E591–E610** 覆盖误差传播、收缩失效、比特分配、混合精度、分布偏移、力闭合标定、笼闭验证、新颖物体、修复算子、分离律、预算、功耗、长跑与竞赛。

## 5. 本轮最大风险

**一句话**：误差椭球 E_q(K) 的有效性依赖"闭环收缩率 ρ"与"证书函数 Lipschitz 常数 L_m"的估计，而抓取的接触瞬间恰是**非光滑、强非线性、局部扩张（ρ≳1）** 的时刻——用平滑线性化的 ρ̂ 去界定接触动力学，会在最需要它的时刻给出**过紧的界**；同时稳健力闭合假设刚性接触与已知几何/摩擦锥，对可变形、易滑、未知质量的物体系统性失效，两套证书在同一处（接触）共享被违反的刚性假设。

**新增定义 549（量化误差与传播椭球）** 对层 l、通道 c 的仿射量化误差界 ε_{l,c}=γ_c·range_{l,c}/(2^{b_l}−1)（非对称取 max(|min|,|max|)）。闭环 rollout e_{k+1}=A_k e_k+δ_k，‖δ_k‖≤ε_max。定义 E_q(K)={e:e^TΣ_q(K)^{-1}e≤χ²_{d,1−α}}，Σ_q(K)=Σ_{i=0}^{K−1}Φ(K,i)Q_iΦ(K,i)^T，Q_i=diag(ε_i²/12)；确定性模式下用半径 R_q(K)。ρ<1 时 R_q(K)=ε_max(1−ρ^K)/(1−ρ)，ρ≥1 时 R_q(K)=ε_max·K。

**新增定义 550（证书敏感度与比特分配）** 层敏感度 s_l=E_{x∼D_cal}‖∂m/∂a_l(x)‖·range(a_l)，m 为当前最紧证书泛函。比特分配 B*=argmin_{b_l∈{4,8,16}, Σb_l≤B} Σ_l s_l c_l 2^{−b_l}；贪心按边际收益 s_l c_l 2^{−b_l}ln2 逐比特投放（可分凸，贪心最优，引理 93）。安全头（clearance/effort/接触状态通道）锁定 b_l≥16。

**新增定义 551（认证量化前向模型）** F̂_caq 按 B* 量化；证书用区间最坏值：ĝ_min=min_k[F̂_caq.clearance_k−L_g R_q(K)]−β_STF，ê_max=max_k[F̂_caq.effort_k+L_e R_q(K)]+β_STF。Ĉ_t⁺ 的 valid 条件同 v10 定义 543，但以区间最坏值替换点预测。ρ 校准：ρ̂ 由 rollout 雅可比谱范数经验估计，取 ρ=ρ̂+δ_ρ（验证分位）；若 ρ̂≥1 或校准未过 ⇒ R_q(K)=ε_max·K，并以 K_cert 反解。

**新增定义 552（抓取接触与力闭合）** 接触位姿 p_i、法向 n_i、摩擦 μ∈[μ_min,μ_max]。抓取映射 G(C,δ) 把接触力映为物体合旋量。力闭合 ⇔ ∀w_ext ∃f_i∈FC_i 使 G f=−w_ext（等价原点在接触原始旋量凸包内部）。

**新增定义 553（ε-稳健力闭合证书）** W_ε={w:‖w−w_0‖≤ε}。ε*(C,μ_min,δ_obj)=sup{ε:∀pose∈δ_obj,∀w∈W_ε,∃f∈ΠFC_i(μ_min),G(pose)f=−w}。γ_grasp^{RFC}=true ⇔ ε*≥ε_req（ε_req 经 E598 标定）。

**新增定义 554（笼闭证书）** 位形空间 C_obj 中，接触约束把自由位形困在有界连通单元（不能连续逃逸）⇒ 笼闭。Cage(C) 由位形空间障碍判定（2D 多边形精确 / 3D 预计算笼闭库查表）。笼闭条件不含 μ ⇒ 摩擦无关（引理 95）。γ_grasp^{Cage}=true ⇒ 即使力闭合失败物体亦不逃逸。

**新增定义 556（抓取修复算子）** 扩 R：r₄ 换抓型（pinch→power/caging，取满足 ε*/Cage 的最大可行型），r₅ 请求人确认/claim（语音+等待）。修复后重验 RFC/Cage 与定义 551 证书；验不过退单步 fallback。

**新增定义 557（误差预算账）** β_total=L_m R_q(K)+ε_p+ε_s+ε_g；各项独立校准覆盖 ≥1−α_i，合并覆盖率 ≥1−Σα_i（并集界）。EBL 记录分配/实耗，越界即按退化链收缩。

class CertificateAwareQuantizer:
    def __init__(self, bits_choices=(4, 8, 16), B=..., locked=frozenset()):
        self.choices, self.B, self.locked = bits_choices, B, locked

    def allocate_bits(self, sens, costs, calib):
        # 定义 550：敏感度加权可分凸 → 贪心最优（引理 93）
        b = {l: min(self.choices) for l in sens}
        for l in self.locked:                      # 安全头锁 FP16
            b[l] = 16
        while sum(b.values()) < self.B:
            cand = max((l for l in sens if b[l] < 16 and l not in self.locked),
                       key=lambda l: sens[l]*costs[l]*2**(-b[l])*math.log(2),
                       default=None)
            if cand is None: break
            b[cand] = self.choices[self.choices.index(b[cand]) + 1]
        return b

    def quantize(self, model, bits):
        q = model.copy()
        for l, bl in bits.items():
            q.layer[l] = affine_quant(model.layer[l], bl,
                                      per_channel=True, asym=True)

class RolloutErrorPropagator:
    def __init__(self, eps_max, rho, delta_rho, L_m, alpha=1e-3):
        self.eps_max, self.L_m = eps_max, L_m
        self.rho = rho + delta_rho                # 校准后更保守
        self.alpha = alpha

    def radius(self, K):
        if self.rho >= 1.0:                       # 线性最坏界（保守回退）
            return self.eps_max * K
        return self.eps_max * (1 - self.rho**K) / (1 - self.rho)

    def k_cert(self, margin):
        K = 1
        while self.L_m * self.radius(K + 1) <= margin:
            K += 1
        return K

class GraspConditionedTrust:
    def __init__(self, stf, kappa=0.05, tau_grasp=0.5, delta0=0.005):
        self.stf, self.kappa, self.tau_grasp = stf, kappa, tau_grasp
        self.delta0 = delta0

    def object_uncertainty(self, ell):
        return self.delta0 + self.kappa * self.stf.nu_bar(ell)

    def admissible(self, ell, grasp_set):
        d = self.object_uncertainty(ell)
        A = [g for g in grasp_set
             if RFC.certify(g, d) or Cage.certify(g, ell.cls)]
        if self.stf.nu_bar(ell) > self.tau_grasp:
            A = [g for g in A if Cage.certify(g, ell.cls) or g.is_power]
            if not A:
                return ('request_human', None)     # r₅
        return ('ok', A)

## 4. 推导

**引理 92（量化误差的传播界与收缩判据）** 设单步量化扰动 ‖δ_k‖≤ε_max，闭环线性化 e_{k+1}=A_k e_k+δ_k 且 ‖A_k‖≤ρ。则 (i) ρ<1 时 ‖e_K‖≤ε_max(1−ρ^K)/(1−ρ)≤ε_max/(1−ρ)，与 K 无关（有界）；(ii) ρ≥1 时 ‖e_K‖≤ε_max·K（线性最坏）；(iii) v10 的标量 β_q 等价于"ρ=0 且 K=1"，故 E_q(K) 对一切 K 均不弱于 β_q（更保守）。证明：e_K=Σ_i Φ(K,i)δ_i，取范数用次乘性与三角不等式；ρ<1 时几何级数求和。∎ 推论：当 ρ̂ 校准失败或 Γ（接触区）局部扩张时，强制走 (ii) 并反解 K_cert，杜绝"用平滑 ρ̂ 低估接触瞬间误差"。

**引理 93（敏感度加权比特分配的最优性）** 目标 Σ_l a_l 2^{−b_l}（a_l=s_l c_l，可分凸），约束 Σb_l≤B、b_l∈{4,8,16}。按边际收益 a_l 2^{−b_l}ln2 的贪心逐比特分配到当前损失下降最大者，得全局最优。证明：对数凸、边际收益单调递减 ⇒ 贪心等价于离散水填充；离散域上用交换论证（若两层次序反了，交换一比特严格降损）。∎ 意义：有限的比特花在"证书对之敏感"的层，而非均匀量化；安全头锁 FP16。

**引理 94（稳健力闭合对不确定性的单调性）** ε*(C,μ_min,δ_obj) 对 μ_min 单调不增、对 δ_obj 单调不增（不确定集变大 ⇒ 可行接触力集变小、需抵抗的外扰集变大）。证明：FC(μ) 随 μ↓ 单调收缩；W_ε 的 ε 上确界在扩张的位姿集上取 min，故 ε* 只降不升。∎ 推论：抓取条件化信任 δ_obj=δ_0+κν̄ 使 ν↑ ⇒ ε*↓ ⇒ A(ν) 收缩，且收缩是单调、可证的。

**引理 95（笼闭的摩擦无关性）** 笼闭条件由接触几何约束下的位形空间连通性定义，显式不含摩擦系数 μ ⇒ 对任意 μ≥0 成立。故在 μ 未知/极小的最坏情形，笼闭仍提供"物体不逃逸"的保证；力闭合可能失效而笼闭不失效。证明：C_obj 的接触障碍只依赖 p_i,n_i 与物体几何，不依赖切向力上限；连通单元被几何障碍围住即不能逃逸。∎

**引理 96（安全-性能分离：量化只降成功率不降安全）** 设 (A1) 真实 rollout 误差以概率 ≥1−α 落在 E_q(K) 内（E591 校准）；(A2) 安全判定全部走 Ω_safe（净空用区间最坏值、抓取用 RFC/Cage）；(A3) 量化提名器只影响候选集与打分。则任一中块危险事件的物理安全覆盖率 ≥1−α−ε_p−ε_s，**且与量化比特数 b 无关**；量化只改变可行候选数量/任务成功率。证明：净空证书用 ĝ_min 的下界（含 L_g R_q(K)），真实净空 ≥ 界当且仅当误差 ∈E_q(K)（概率 ≥1−α）；抓取证书完全不含量化模型；提名器仅从候选集里删/排，不改变任何通过安全门的候选的物理可执行性。故 b 只影响"有多少候选能过"（性能），不影响"过了的候选是否安全"（安全）。∎ 这是对 v10 风险"INT8 压缩分割面安全边际"的正面拆除：安全不再由量化网络的分割/置信决定。

**引理 97（抓取条件化信任的支配性）** 对 ν1≤ν2，A(ν1)⊇A(ν2)（引理 94）。v10 允许的任何满足 γ_grasp valid 的抓取，若不在 A(ν) 内则 v11 拒绝；v11 不引入 v10 之外的新物理抓取（r₄ 的 power/caging 是 v10 抓取型的子集，r₅ 为请求人、非新动作）。故 v11 可执行抓取集 ⊆ v10，安全支配、无行为漂移；ν>τ_grasp 时进一步收缩至笼闭/大力/求人。证明：集合包含 + 定义 555 的直接展开。∎

## 8. 本轮最大风险

**一句话**：误差椭球 E_q(K) 的有效性依赖"闭环收缩率 ρ"与"证书函数 Lipschitz 常数 L_m"的估计，而抓取的接触瞬间恰是**非光滑、强非线性、局部扩张（ρ≳1）** 的时刻——用平滑线性化的 ρ̂ 去界定接触动力学，会在最需要它的时刻给出**过紧的界**；同时稳健力闭合假设刚性接触与已知几何/摩擦锥，对可变形、易滑、未知质量的物体系统性失效，两套证书在同一处（接触）共享被违反的刚性假设。
