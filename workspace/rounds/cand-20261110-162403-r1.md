# 第 47 轮（承接第 46 轮 v23；本轮灵感：成功率 × 语音识别） · SR-Cert：语音识别不确定性与任务成功率证书的双层风险控制（架构 v11）

> 承接第 46 轮 v23 Memory-Safety-Voice（MVR × VAD × SAB）。v23 让语音指令可被记忆复用、用需求分布驱动模态激活，并以安全队列兜底姿态绑定；但隐含假设 H5 是：**ASR 的槽位置信 σ_s 是校准的，且"单次置信高"等价于"任务成功率高"**。UniBot 实机里，语音在厨房噪声、口音、领域术语和同音词上会让 top-1 过度自信；历史记忆只保留成功样本（幸存者偏差），使 MVR 命中率与真实成功率脱钩；而 θ_safe 是一个静态阈值，无法随识别质量漂移。两个灵感词精确命中 H5：**语音识别**要求把识别不确定性从单一置信度升级为 n-best 槽位后验与可校准的识别成功率；**成功率**要求把"这次大概能成"升级为"在统计意义下以 1−δ 保证成功率不低于 S_req"的 anytime-valid 证书。耦合出的新问题是：**如何在识别成功率证书与任务成功率证书同时受控的前提下，自适应地在执行/复述/确认/弃权之间路由，且不让记忆复用与阈值调参污染成功率估计**。

## 0. 直觉与动机

**灵感 1（成功率 → 证书，而不是点估计）**
直觉：一个 0.92 的置信度既不知道样本量，也不知道置信水平，更无法阻止"看多了数据再决定"的选择偏差。真正的"成功率"应是带样本量 n、失败预算 δ、并且允许随时查看的**下置信界**（LCB）。只有 LCB ≥ S_req 才允许执行。这样"成功率"从评价指标变成在线运行时的安全谓词。对多阶段链路（识别→绑定→执行），端到端成功率不是三个点估计的乘积，而是联合事件概率；必须用联合估计或 Fréchet 下界，而不是朴素相乘。

**灵感 2（语音识别 → n-best 槽位后验，而非 top-1 置信）**
直觉：ASR 的错误高度相关：同音词、数字、否定词、领域专名会成簇出错。单个 σ_s 无法表达"识别器其实在三个候选间摇摆"。正确做法是保留 n-best / lattice，把每个候选映射到意图与关键槽位，得到槽位后验 q(s|a)；并区分**识别成功**（意图正确且关键槽位全对）与**语义成功**（下游能正确执行）。语音识别的"成功率"应分层：字符级 WER、槽位级 SER、意图级 exact-match，各自独立校准，不能互相替代。

**灵感 3（耦合 → 双层证书 + 自适应澄清 + 去偏记忆）**
直觉：当识别 LCB 偏低而任务 LCB 尚可时，最优动作不是硬执行也不是直接失败，而是花一点延迟去"复述/确认"以换取成功率的边际提升；当两者都低时，确认也无用，应弃权。记忆复用则像"只采访活下来的人"：只在成功样本上训练会系统性高估成功率。需要用记录策略的倾向得分做逆概率加权（IPS/SNIPS），并用有效样本量约束记忆命中的可信度。

**耦合升级**：在 v10 能量-上下文-深度与 v23 记忆-语音-安全之上新增 **成功率治理层 SRG（Success-Rate Governor）**。SRG 维护识别成功率证书与任务成功率证书，输出澄清动作 a_t∈{execute, repeat, confirm, abstain} 与自适应绑定阈值 θ_safe(t)；VAD 改为消费 lattice 后验而非 top-1 置信；MVR 的记忆命中必须附带去偏成功率与样本量；SAB 的阈值由证书动态抬升；CCA/DCL 增加分布漂移红队与识别困难样本采集。四层 v11：根信任层增加"成功率证书"这一时间受限的可信根，L1 几何层不变，L2 上下文层增加识别可靠性上下文，L3 安全层由双层证书门控，L4 采集层按成功事件分层采样。

## 1. 形式化定义（增量：定义 59–63）

**定义 59（n-best 槽位后验与识别成功事件）**
设第 t 条语音 a_t 的识别 lattice 产生候选集 H_t={h_1,…,h_N} 及声学-语言得分。映射 φ(h) 给出意图与槽位填充。定义槽位后验
q(s|a_t)=Σ_{h: φ(h) 在槽位 s 上取值} softmax_j(score(h_j)/T)。
识别成功事件
Y_rec=1[意图(a_t)=意图(h*) ∧ ∀s∈S_crit: φ(h*)_s=真值_s]，
其中 S_crit 为关键槽位（物体、目标、否定、数量）。未观测真值时用审计集的共形校准上界估计其期望。

**定义 60（任务成功事件与链路分解）**
Y_task=Y_rec ∧ Y_bind ∧ Y_exec，其中 Y_bind=1[B(v_t,P_t)≥θ_safe(t)]，Y_exec 为执行后未触发安全召回。联合成功率 S_task=P(Y_task=1)。为避免朴素相乘高估，采用两个下界：
- 直接联合估计：S_task 用同一 episode 的 Y_task 经验均值 + anytime-valid LCB；
- Fréchet 分解下界：S_task ≥ max(0, Σ_i S_i − (k−1))，k=3，仅用于诊断与归因。

**定义 61（Anytime-valid 成功率下界）**
对伯努利成功指示 Y_i∈{0,1}，固定候选成功率 p，构造 e-process
E_n(p)=Π_{i=1}^n (1+λ_i(p)(Y_i−p))，λ_i(p)∈[0,1/(1−p))。
在任意停止时刻，下置信界
\underline S_n(δ)=inf{ p∈[0,1] : E_n(p) < 1/δ }。
性质：P(∀n: S_true ≥ \underline S_n(δ)) ≥ 1−δ（无需固定样本量，允许在线查看）。执行准入：\underline S_n^{task}(δ) ≥ S_req 且 \underline S_n^{rec}(δ) ≥ S_req^{rec}。

**定义 62（成功率感知的记忆重加权）**
记忆库记录采集策略倾向 e_i=P(i∈M | c_i)，e_i>0。IPS 成功率
Ŝ_IPS=(1/n)Σ_{i=1}^n Y_i/e_i，SNIPS=Σ(Y_i/e_i)/Σ(1/e_i)。
有效样本量 ESS=(Σ w_i)^2/Σ w_i^2，w_i=1/e_i。仅当 ESS ≥ ESS_min 且 Ŝ_IPS 的 LCB ≥ S_req 时，记忆命中才可用于执行；否则降级为"建议"并转实时求解。

**定义 63（双层证书门控与澄清路由）**
状态 z_t=(\underline S_n^{rec},\underline S_n^{task},q(s|a_t),B_t)。澄清动作
a_t=argmax_{a∈{exec,repeat,confirm,abstain}} E[Y_task | a,z_t] − λ_lat·latency(a) − λ_r·Risk(a)
s.t. 若 a=exec 则 \underline S_n^{task}(δ)≥S_req。
自适应绑定阈值 θ_safe(t)=θ_0+γ·(1−\underline S_n^{rec}(δ))，识别证书越弱，绑定要求越严。若 repeat/confirm 后 LCB 仍不升，则 abstain（fail-closed）。

## 2. 新增产出与既有 IP 升级

**IP-69 SRC（Success-Rate Certifier）**
- 识别/任务两级 e-process 证书，按成功事件分层维护
- 支持随时停止与在线查看，自动处理非平稳（变点重启）
- 输出执行准入布尔量与证书年龄

**IP-70 ASR-LATTICE UNCERTAINIZER**
- n-best/lattice → 槽位后验 q(s|a)，保留同音/否定/数字候选
- WER/SER/意图 exact-match 三通道共形校准
- 低后验关键槽位触发澄清请求

**IP-71 ACR（Adaptive Clarification Router）**
- 代价敏感路由：执行 / 复述 / 确认 / 弃权
- 复述与确认的预期成功率增益建模（含用户疲劳惩罚）
- 与 Q_safe 队列联动：确认超时自动 abstain

**既有 IP 升级**
IP-66 MVR：命中必须携带 IPS 去偏成功率与 ESS，否则只作建议。
IP-67 VAD：需求分布改用 q(s|a) 的期望，而非 top-1 置信平方。
IP-68 SAB：θ_safe 由 θ_0 升为 θ_safe(t)，绑定检查消费识别证书。
IP-62 CCA：新增 ASR 分布漂移红队、成功率证书覆盖测试。
IP-61 DCL：按识别成功/失败分层采集，主动补困难同音与否定样本。
IP-51 CAR：双层证书任一失效即 fail-closed。
IP-45 总线：新增 success-cert / asr-posterior / clarification 话题。

## 3. 算法骨架

每处理一条语音指令：
1. ASR 产生 n-best，构造槽位后验 q(s|a_t) 与关键槽位置信。
2. SRC 读取当前 \underline S_n^{rec}、\underline S_n^{task} 与证书年龄。
3. ACR 在 {exec,repeat,confirm,abstain} 上做代价敏感选择。
4. 若 exec：VAD 用 q(s|a) 生成 R(v)，MVR 检索（带 IPS/ESS 门控），SAB 用 θ_safe(t) 绑定。
5. 执行后回填 Y_rec/Y_bind/Y_exec 与 Y_task，更新 e-process；检测分布漂移则重启证书并提高 θ_safe。
6. 任一证书 LCB < S_req 且澄清无增益 → abstain 并 fail-closed。

## 4. 本轮最大风险

**一句话**：成功率证书与 ASR 后验都建立在"评估分布与运行分布一致"的隐含假设上，一旦厨房噪声、口音或领域术语造成分布漂移，e-process 的历史样本会让 LCB 变得过度乐观，系统会自信地执行错误的语音指令；因此必须内置变点检测、按漂移重启证书，并在证书年龄过大或漂移告警时默认 abstain 或强制确认。

## 2. 关键算法 伪代码

### IP-70 ASR-Lattice Uncertainizer
```
def slot_posterior(lattice, T=1.0, crit=['object','target','neg','count']):
    q = {s: defaultdict(float) for s in crit}
    Z = 0.0
    for h in lattice.hypotheses:
        w = exp(h.score / T)
        Z += w
        intent = h.intent
        for s in crit:
            val = h.slots.get(s, MISSING)
            q[s][val] += w
    for s in crit:
        for v in q[s]:
            q[s][v] /= Z
    return q, intent_posterior(lattice)

def rec_success_lower_bound(q, crit, delta_rec, calib):
    # 关键槽位后验均超过校准阈值才算"可判定的识别成功"
    min_conf = min(max(q[s].values()) for s in crit)
    return conformal_lower(min_conf, calib.rec_success, delta_rec)
```

### IP-69 SRC Success-Rate Certifier
```
class EProcess:
    def __init__(self, delta):
        self.logE = {p: 0.0 for p in GRID}   # 候选 p 的对数 e-process
        self.n = 0
        self.delta = delta

    def update(self, y):
        self.n += 1
        for p in GRID:
            lam = self._lam(p, self.n)        # lam in [0, 1/(1-p))
            self.logE[p] += log(1 + lam * (y - p))

    def lcb(self):
        # 下界 = 使 E_n(p) 仍未被 1/delta 否决的最小 p
        valid = [p for p in GRID if self.logE[p] < log(1 / self.delta)]
        return min(valid) if valid else 1.0

def update_certificates(y_rec, y_task, buf_rec, buf_task, change_detector):
    buf_rec.update(y_rec); buf_task.update(y_task)
    if change_detector.alarm(buf_rec, buf_task):   # 分布漂移
        buf_rec.restart(); buf_task.restart()
        return 'drift_restart'
    return buf_task.lcb(), buf_rec.lcb()

def admit(lcb_task, lcb_rec, S_req, S_req_rec, age, age_max):
    if age > age_max:
        return False
    return lcb_task >= S_req and lcb_rec >= S_req_rec
```

### IP-66 MVR 去偏升级
```
def memory_hit(mem, B_t, c_t, delta_mem, ESS_min=30):
    w = 1.0 / max(mem.propensity, 1e-6)
    snips = mem.success_mass / mem.weight_mass
    ess = mem.weight_mass**2 / mem.weight_sq_mass
    lcb = snips - sqrt(log(1/delta_mem) / (2*ess))
    if ess < ESS_min or lcb < mem.S_req:
        return None, 'memory_untrusted'   # 仅作建议，不直接执行
    return mem.decision, 'memory'
```

### IP-71 ACR Adaptive Clarification Router
```
def clarification_route(z, q, budget, costs):
    actions = ['exec', 'repeat', 'confirm', 'abstain']
    best_a, best_u = 'abstain', -inf
    for a in actions:
        p_succ = predict_success(a, z, q, costs)
        lat = costs.latency[a]
        fatigue = costs.fatigue[a] * z.user_load
        risk = costs.risk[a] * (1 - z.lcb_task)
        u = p_succ - costs.lambda_lat * lat - costs.lambda_f * fatigue - costs.lambda_r * risk
        if a == 'exec' and not admit(z.lcb_task, z.lcb_rec, z.S_req, z.S_req_rec, z.age, z.age_max):
            continue
        if lat > budget.remaining:
            continue
        if u > best_u:
            best_a, best_u = a, u
    if best_a in ('repeat', 'confirm'):
        return best_a, clarify_prompt(best_a, q)
    return best_a, None
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| Lattice 槽位后验 | O(\|H\|·\|S_crit\|) | O(\|S_crit\|·\|V_slot\|) | 关键槽位后验为真实后验的离散近似 |
| SRC e-process | O(\|GRID\|) 每样本 | O(\|GRID\|) | P(∀n: S_true≥LCB_n(δ))≥1−δ |
| IPS 记忆门控 | O(1) 每命中 | O(\|M\|) | ESS 足够时 SNIPS 一致估计去偏成功率 |
| ACR 路由 | O(\|A\|) | O(1) | 仅在证书准入且预算内选择执行 |
| 全局闭环 Π⁺ | O(\|H\|·\|S_crit\|+\|M\|) | O(\|M\|) | 双层证书 + 安全绑定 + 队列 ⇒ fail-closed |

**定理（成功准入的边际保证）**：设识别与任务 e-process 各自以 δ/2 失效，ACR 仅在 exec 分支要求两证书均达标。若两证书均未失效且数据来自与审计集同分布，则被执行的指令满足 P(Y_task=1) ≥ S_req。记忆路径额外要求 ESS≥ESS_min，其去偏估计的偏差不超过 O(1/√ESS)。分布漂移时定理前提被破坏，必须由变点检测重启证书（见风险）。

**命题（澄清的增益条件）**：只有当复述/确认后 q(s|a) 的关键槽位最大后验提升带来的 ∂E[Y_task]/∂LCB 超过延迟与疲劳代价时，ACR 才选择澄清；否则放弃澄清直接 abstain，避免"越问越糟"。

| E116 成功率证书覆盖率 | 实际成功率 vs LCB 覆盖率 | 100h 内覆盖率 ≥ 1−δ（δ=0.05） |
| E117 记忆去偏效果 | IPS/SNIPS 与真实成功率偏差、ESS | 偏差 ≤ 3%；ESS ≥ 30 |
| E118 澄清路由收益 | 成功率提升 / 平均延迟 | 成功率 +8pp；延迟 ≤ 1.2s |
| E119 漂移鲁棒性 | 噪声/口音切换后误执行率 | 切换后 10 条内误执行 ≤ 1% |
| E120 100h 语音闭环 | 任务成功率、abstain 率、安全召回 | 成功率 ≥ 96%；误执行召回 ≤ 0.5% |

回退策略：E116 覆盖率跌破 1−δ → 证书失效，回退为固定保守阈值并强制确认；E117 ESS < 20 → 关闭记忆直接执行路径；E119 漂移告警频繁 → 缩短证书窗口、提高 θ_0，并暂停自主执行转人工确认。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| ASR 分布漂移使 LCB 过期乐观 | 高 | 变点检测 + 证书重启 + 证书年龄上限 |
| 澄清循环被噪声触发，延迟爆炸 | 中 | 澄清增益门控、每指令最多一次复述、超时 abstain |
| IPS 倾向得分缺失或过小导致方差爆炸 | 高 | 权重截断、ESS 门槛、缺失倾向的样本不进入执行路径 |
| 关键槽位集合定义遗漏否定/数量 | 高 | 用审计集做槽位敏感性分析，S_crit 定期复核 |
| 用户在反复确认后改变说法造成反馈漂移 | 中 | 将澄清后样本单独分层，不与自然分布混算证书 |
| 联合成功率直接估计样本稀疏 | 中 | 分层采样 + Fréchet 下界作诊断，主判据用直接联合 LCB |

## 6. 本轮最大风险

**一句话**：双层成功率证书把"语音识别这次大概率对"变成了可执行的安全谓词，但其有效性完全依赖评估分布与运行分布一致；一旦噪声、口音、领域术语或用户被澄清提示后的行为改变造成漂移，历史 e-process 会给出过度乐观的 LCB，系统将以统计保证的名义执行错误指令——因此必须把变点检测、证书年龄和漂移重启作为与证书同等优先级的运行时约束，漂移时默认 abstain 而非继续相信旧证书。
