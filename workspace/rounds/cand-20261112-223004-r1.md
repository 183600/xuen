# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 8 轮；本轮灵感：「实例分割」×「数据配比」）

> 第 61 轮构建了 ESEC：USR 统一语义表征、MEL 多模态具身大模型、DMS 多轮对话、SRT-Dual 语义-实时双流、PCE+++++ 六元预算。但**四个新暴露的局限**待突破：
> 1. **全局语义糊化（semantic smearing）**：USR 把整个场景压成一个 `scene_emb`、一个 `intent_emb`、一个 `K_prior`。在杂乱堆叠、多物体、双手/多指接触时，`fused = scene_emb + intent_emb` 是**多个实例语义的平均**——对物体 A 安全的阻抗对脆性物体 B 可能致命，折中先验对谁都不最优。
> 2. **单实例控制假设**：EEIS 只编译一组 `K_safe`，无法表达「指尖 A 压住物体 1、指尖 B 推开物体 2」的**实例级阻抗与力分配**；滑移发生在哪个接触面也无法定位。
> 3. **数据配比盲区**：MEL 的训练数据（仿真/真实、各材质、各任务）与运行时证据缓冲是**隐式等权混合**的。长尾实例（罕见材质、小零件、遮挡物体）的数据支撑 `n_i` 极低，却被全局平均淹没——这正是第 61 轮零样本失败的根因之一，但「配比」从未被当作一等设计变量优化。
> 4. **无实例归因的闭环**：`EV-exec` 进入 USR 证据缓冲后只剩一个 `evidence_emb`，**无法把失败归因到具体实例**，因此 DMS 说不出「哪个物体滑了」，数据采集/微调也无法定向补数据——闭环是「无靶心的」。

## 0. 直觉与动机

**灵感 1（实例分割 → 实例索引的语义空间 ISU）**
直觉：实例分割的本质是「给每个像素分配一个物体身份 + 掩码」，而不是把图像压成一个全局描述子。第 61 轮的 USR 恰恰犯了「全局池化」的错误。把 USR 从「一个锚点」升级为「实例索引的锚点集合」：每个实例 `i` 拥有独立的 `scene_emb_i`、`phys_prior_i`、`contact_state_i` 与 `mask_i`；全局量退化为实例量的**加权聚合**（而非平均）。类比 panoptic segmentation：物体（thing，有身份、可数）与支撑面（stuff，无固定身份）分开建模——前者逐实例绑定阻抗，后者提供公共约束（如桌面法向、摩擦下限）。

**灵感 2（实例分割 → 接触实例分割 CIS）**
直觉：触觉阵列/力场本身就是一张「图像」，接触斑块就是图像里的「实例」。对力/力矩时空图做实例分割，可把合力旋量分解为**逐接触实例的 `wrench_k`**；对接触时序做「时间实例分割」（approach / contact / slip / release 相位即时间实例）。关键洞见：滑移、振动、力超限这些第 61 轮只有全局标量的证据，在 CIS 下变成「**绑定了实例身份的局部证据**」，直接为 IP-179 的 EFGP 提供「哪个物体、哪个接触点、哪个相位」的精细归因。

**灵感 3（数据配比 → 实例数据配比 IDM）**
直觉：大模型的能力由训练数据的**配比**塑造；同理，具身系统的能力由「各实例簇的数据支撑」塑造。把数据配比形式化为**实例簇上的概率测度** `w = (w_1..w_M)`：`w_c` 决定该实例簇在训练/蒸馏/回放/在线采集中占多少采样预算。朴素等权会 starving 长尾；全按困难度加权又会灾难性遗忘常见实例。关键洞见：配比应按「**每实例风险的最坏情况 + 数据支撑 + 覆盖约束**」求解（组 DRO / minimax），而不是拍脑袋。更进一步：配比不只用于**训练**，也用于**运行时**——MoE 路由门控、证据融合权重、预算分配，都是「配比」的不同投影，应共享同一个 `w`。

**灵感 4（实例分割 × 数据配比 → 实例混合路由 IMR）**
直觉：不同实例需要不同「专家」（不同阻抗律、不同物理先验头）。用**混合专家（MoE）**承载，门控输入是实例嵌入，门控权重由该实例的配比后验 `w_{c(i)}` 调制：数据支撑高的实例更信任其专属专家，支撑低的实例更依赖共享/保守专家。这样既防负迁移（稀有实例不被常见实例的梯度淹没），又能在数据不足时自动退回安全默认。

**灵感 5（合流 → 实例级数据配比再平衡闭环 AMR / I-ESEC）**
直觉：把执行证据按实例归因（IEA）→ 更新每实例的难度 `d_c` 与支撑 `n_c` → 重新求解配比 `w` → 触发定向数据采集/仿真重采样/蒸馏/回放 → 重训或在线更新专家 → 再次执行。这是一个**以实例为靶心的主动学习闭环**：哪里弱，就往哪里加数据；哪里数据够，就少采。它与第 61 轮的语义闭环正交叠加：语义闭环管「当前怎么控」，配比闭环管「长期怎么变强」。

**灵感 6（预算 → PCE++++++ 七维）**
直觉：新增第七维 `B_mix`（数据配比-实例联合预算），内含真实采集、仿真重采样、标注、蒸馏 token、回放缓冲与实例追踪开销。当 `B_inst` 耗尽 ⇒ 实例合并/退休（ILM）；当数据预算耗尽 ⇒ 冻结配比 `w`，仅用缓存专家。

## 1. 形式化定义（增量：定义 173–184）

**定义 173（实例索引语义空间 ISU）** `ISU = (I_t, E_inst, Π_inst, Λ, d_us)`。
- **实例集**：`I_t = {1..N_t}`，由视觉实例分割与 CIS（定义 174）联合产生；实例 `i` 携带 `(mask_i, id_i, type_i ∈ {thing, stuff}, emb_i ∈ ℝ^{d_us}, φ_phys_i, conf_i, ttl_i)`。
- **实例编码器**：`E_inst: (crop_i, tactile_patch_i, L) → emb_i ∈ ℝ^{d_us}`，与第 61 轮共享 `d_us = 256`，保证与旧锚点可比。
- **逐实例投影**：`Π_inst: ℝ^{d_us} → K_i`（2 层 MLP，~0.1ms/实例）。
- **聚合算子**：`Λ: {K_i} → (K_cmd, F_alloc)`，**不是平均**，而是带约束的可行域交（见定义 174 与 IP-188）；`Λ` 必须保证 `K_cmd` 落在所有安全区间的交内，交为空时回退最保守单实例。
- **全局视图**：`scene_emb = Σ_i α_i emb_i`，`α = softmax(attend(emb_i))`，仅供 MEL 的粗粒度先验使用，**不再直接投影**为控制量。

**定义 174（接触实例分割 CIS）** 设触觉/力场为时空图 `W(x,t)`。分割算子
`S_cis: W → {(mask_k, wrench_k, phase_k, conf_k)}_{k=1..K}`，
满足**旋量守恒** `Σ_k wrench_k = wrench_total + ε_res`，`‖ε_res‖ ≤ ε_cons`。每个接触实例提供局部证据 `slip_k`、`vib_k`、`f_k^max` 及相位标签 `phase_k`。视觉侧实例分割 `S_vis: V → {(mask_j, id_j, class_j)}`；两者通过 `mask_k ∩ mask_j` 与本体运动残差做数据关联，得到 `I_t`。

**定义 175（实例数据配比 IDM）** 设实例簇（cohort）集合 `C`，`c = (材质, 几何, 任务)` 的离散组合。数据池 `D = ⊔_{c∈C} D_c`。**配比** `w ∈ Δ^{|C|-1}`（`Σ_c w_c = 1`），定义为采样预算占比：从 `P_w = Σ_c w_c P_c` 采样训练/蒸馏/回放。每簇维护 `(n_c, κ_c, d_c, σ_c², U_c)`：数据支撑量、覆盖度、难度 EMA、损失方差、认知不确定性。约束 `w_min ≤ w_c ≤ w_max`（安全下限防 long-tail 灭绝，上限防常见簇过拟合与遗忘）。

**定义 176（实例最坏情况风险与 Minimax 配比）** 每簇风险 `R_c(θ) = E_{P_c}[ℓ(θ)]`。目标
```
min_θ  max_c R_c(θ)
s.t.   θ 由配比 w 采样训练，n_c = w_c · N，Σ_c w_c = 1，w_min ≤ w_c ≤ w_max
```
在标准 VC/Rademacher 意义下，以概率 `1-δ`：`R_c(θ) ≤ R̂_c(θ) + sqrt(A_c / n_c)`，`A_c = σ_c² log(2|C|/δ)/2 + Lip²·complexity`。代入 `n_c = w_c N`，忽略 `R̂_c` 的常数项，配比子问题化为
```
min_w  max_c sqrt(A_c / (w_c N))     ⇔     max_c A_c / w_c 最小化
```
内点最优解为 **`w_c* ∝ sqrt(A_c) ∝ σ_c`**（water-filling）；有 `w_min/w_max` 时用带上下界的投影 water-filling（IP-185）。直观：方差大/数据稀缺的簇应获得更多配额，但不得挤占安全下限。

**定义 177（实例混合路由 IMR）** 专家集合 `E = {e_1..e_E}`（共享保守专家 `e_0` 必选）。门控
```
g_i = softmax( W_g · emb_i + log(w_{c(i)} + ε) / τ )
```
`g_{i,0} ≥ g_min`（保守专家地板权，安全硬约束）。实例阻抗 `K_i = Σ_e g_{i,e} · K_i^{(e)}`。配比 `w` 既训练专家容量，又调制运行时门控，使「数据支撑」与「信任度」一致。

**定义 178（实例级自适应再配比 AMR）** 状态 `(d_c, n_c, U_c, w_c)`，每闭环周期：
```
d_c ← (1-β)·d_c + β·ℓ̂_c                         # 难度 EMA（来自 IEA 归因后的损失）
n_c ← n_c + Δn_c                                 # 新增样本/证据计数
A_c ← σ_c² + λ_U·U_c + λ_d·exp(γ·d_c)            # 风险代理
w*  ← water_filling({A_c}, w_min, w_max)         # 定义 176
w   ← (1-η)·w + η·w*                             # 平滑，防抖动
if n_c < n_min or (d_c > τ_d and w_c > w_min):   # 触发定向补数据
    allocate_data(c, ρ·B_mix·w_c)
```
非平稳场景用 EXP3/UCB 变体：把「簇选择」视为带反馈的臂，防止对早期偶然困难的簇过度加权。

**定义 179（实例-配比认知预算 B_cog7 / PCE++++++）** 在第 61 轮六元预算上新增第七维：
```
B_cog7 = (B_scene, B_intent, B_ros, B_exec, B_mel, B_usr, B_mix)
B_mix   = (B_real, B_sim, B_label, B_distill, B_replay, B_inst, w)
```
- `B_real/B_sim/B_label`：真实采集、仿真重采样、标注预算；`B_distill`：蒸馏 token；`B_replay`：DMS-RL 回放缓冲配额；`B_inst`：实例追踪（掩码计算、逐实例锚点内存、`N_t ≤ N_max`）；`w`：当前配比（可冻结）。
- **降级链**：`B_inst` 耗尽 ⇒ ILM 合并/退休低置信实例；`B_real` 耗尽 ⇒ 配比转为纯 sim + 高保真仿真重采样；`B_distill` 耗尽 ⇒ 冻结专家，仅 IMR 保守专家在线。

**定义 180（实例级联合证书 J_inst）**
```
J_inst = (J_sem_exec,
          {mask_hash_i}, mask_quality_iou,
          attribution_conf, attribution_entropy,
          coverage_hat = min_c (n_c / n_min),
          worst_risk_hat = max_c R̂_c,
          w_hash, instance_count N_t)
验证：Valid(J_inst) ⇔ Valid(J_sem_exec)
        ∧ mask_quality_iou ≥ τ_iou
        ∧ attribution_conf ≥ τ_attr
        ∧ min_c w_c ≥ w_min
        ∧ worst_risk_hat ≤ R_max
        ∧ N_t ≤ N_max
```

**定义 181（实例证据归因 IEA）** 证据 `EV-exec` 到实例的归因分布
```
A_i = softmax( λ_s·IoU(mask_i, contact_region)
             + λ_t·temporal_alignment_i
             + λ_f·|wrench_i| / Σ_j |wrench_j| )
```
失败归因置信 `conf_attr = 1 - H(A)/log N_t`；每实例证据 `ev_i = Σ_t A_i(t)·ev(t)`。`conf_attr < τ_attr` 时不更新配比（防止把噪声当靶心）。

**定义 182（实例生命周期管理 ILM）** 操作 `{spawn, merge, split, retire, revive}`：
- `spawn`：新接触/新掩码出现且 `conf > τ_new`；
- `merge`：`IoU(mask_i, mask_j) > τ_merge` 或物理上同一刚体；
- `split`：遮挡解除/接触分离且运动残差 > 阈值；
- `retire`：离开工作空间或遮挡 `> T_occ`；`revive`：以 id 先验重识别。
生命周期保证 `N_t ≤ B_inst`，并将 `id_switch_rate` 作为证书指标（定义 180）。

**定义 183（实例感知语义-实时双流 ISRT-Dual）** 第 61 轮 SRT-Dual 的实例化：
- **语义流**：CIS + `S_vis` → `I_t`；MEL 逐实例推理 → `emb_i, φ_phys_i`；AMR 更新 `w`；逐实例写入 `Anchor_i = (emb_i, φ_i, version_i, ts_i, mask_hash_i)`。
- **实时流**：读取活跃实例 top-k（按 `conf_i·w_{c(i)}` 排序），逐实例 `K_i = Π_inst(emb_i)`（若 `version` 更新），`Λ` 聚合为 `(K_cmd, F_alloc)`；实例集变化时执行**安全交接**（新旧 `K` 线性 ramp ≥ `T_hand`，且旧实例保留至新实例确认）。
- **一致性**：逐实例新鲜度检查 `now - ts_i < τ_fresh`；单实例过期触发该实例保守扩展，不影响其他实例。

**定义 184（实例级语义进化闭环 I-ESEC）** 整体算子
```
I-ESEC = AMR ∘ IEA ∘ ISRT-Dual ∘ IMR ∘ ISU ∘ CIS
```
即 `分割 → 实例锚点 → 专家路由 → 逐实例控制 → 归因 → 配比再平衡 → 定向补数据/重训 → 再分割`。其不动点条件：`‖w_{t+1} - w_t‖ ≤ ε_w` 且 `max_c R̂_c ≤ R_max` 且 `mask_quality_iou ≥ τ_iou`。

### IP-183 ISU（实例索引语义空间）

```python
class InstanceIndexedUSR:
    def __init__(self, d_us=256, n_max=16, anchor_ttl=0.2):
        self.d_us, self.n_max, self.anchor_ttl = d_us, n_max, anchor_ttl
        self.enc = InstanceEncoder(d_us)          # E_inst
        self.proj = InstanceProjector(d_us)       # Π_inst
        self.anchors = {}                         # id -> InstanceAnchor
        self.attn = nn.Linear(d_us, 1)            # 全局视图注意力

    def update(self, instances, language):
        # instances: [(id, mask, crop, tactile_patch, conf)]
        live = set()
        for iid, mask, crop, tpatch, conf in instances:
            emb = self.enc(crop, tpatch, language)
            old = self.anchors.get(iid)
            ver = (old.version + 1) if old else 0
            self.anchors[iid] = InstanceAnchor(
                id=iid, mask=mask, emb=emb, version=ver,
                ts=time.time(), mask_hash=hash_mask(mask), conf=conf)
            live.add(iid)
        # ILM：退休失活实例（不立即删除，保留 T_occ 供 revive）
        for iid in list(self.anchors):
            if iid not in live:
                self.anchors[iid].ttl -= 1
                if self.anchors[iid].ttl <= 0:
                    del self.anchors[iid]
        if len(self.anchors) > self.n_max:            # B_inst 兜底
            self._retire_lowest_confidence()

    def project(self, iid):
        a = self.anchors[iid]
        K_i = self.proj(a.emb)
        return K_i, a

    def aggregate(self, K_list):
        # Λ：可行域交，而非平均
        K_cmd = intersect_feasible(K_list)
        if K_cmd is None:                             # 交为空 ⇒ 最保守
            K_cmd = most_conservative(K_list)
        return K_cmd

    def global_scene_emb(self):
        embs = torch.stack([a.emb for a in self.anchors.values()])
        alpha = torch.softmax(self.attn(embs).squeeze(-1), dim=0)
        return (alpha.unsqueeze(-1) * embs).sum(0)    # 仅给 MEL 粗先验
```

### IP-184 CIS（接触实例分割）

```python
def contact_instance_segmentation(W_map, V, proprio):
    # 视觉侧实例
    vis = visual_instance_seg(V)                     # [(mask_j, id_j, class_j)]
    # 触觉侧：力场时空图上的斑块分割（可微分水岭 / Mask2Former 触觉版）
    contact_masks = tactile_patch_seg(W_map)         # [(mask_k, phase_k)]
    out = []
    for mask_k, phase in contact_masks:
        wr = integrate_wrench(W_map, mask_k)          # wrench_k
        j = argmax_j IoU(mask_k, vis[j].mask)
        iid = associate(vis[j].id, proprio, mask_k)   # 数据关联
        out.append(dict(id=iid, mask=mask_k, wrench=wr,
                        slip=detect_slip(W_map, mask_k),
                        vib=band_power(W_map, mask_k, 20, 200),
                        phase=phase, conf=mask_conf(mask_k)))
```

### IP-185 IDM（实例数据配比：minimax water-filling）

```python
def solve_mixture(sigma2, U, d, w_min, w_max, gamma=1.0):
    """最小化 max_c A_c / w_c，A_c = sigma2 + λ_U·U + λ_d·exp(γ d)。"""
    A = sigma2 + LAMBDA_U * U + LAMBDA_D * np.exp(gamma * d)
    # 内点解 w_c ∝ sqrt(A_c)，再投影到 [w_min, w_max] 的单纯形（water-filling）
    w = np.sqrt(A)
    w = w / w.sum()
    w = project_bounded_simplex(w, w_min, w_max)
    return w

def project_bounded_simplex(w, lo, hi, iters=50):
    """二分 λ：w_i = clip(v_i - λ, lo, hi)，使 Σ w_i = 1。"""
    v = w  # 初值
    a, b = v.min() - 1.0, v.max() + 1.0
    for _ in range(iters):
        lam = (a + b) / 2
        ww = np.clip(v - lam, lo, hi)
        if ww.sum() > 1.0: a = lam
        else: b = lam
    return np.clip(v - (a + b) / 2, lo, hi)
```

### IP-186 IMR（实例混合路由）

```python
class InstanceMixtureRouter(nn.Module):
    def __init__(self, d_us, n_experts=4):
        super().__init__()
        self.gate = nn.Linear(d_us, n_experts)
        self.experts = nn.ModuleList([ImpedanceExpert(d_us) for _ in range(n_experts)])
        self.conservative = ConservativeExpert(d_us)   # e_0
        self.g_min = 0.2

    def forward(self, emb, log_w):
        logits = self.gate(emb) + log_w / TEMP           # 配比先验注入门控
        g = torch.softmax(logits, dim=-1)
        K = sum(gi * ex(emb) for gi, ex in zip(g, self.experts))
        # 保守专家地板权，安全硬约束
        g0 = self.g_min
        K = (1 - g0) * K + g0 * self.conservative(emb)
        return K, g
```

### IP-187 AMR（实例级再配比）

```python
class AdaptiveMixtureRebalancer:
    def __init__(self, cohorts, w_min=0.02, w_max=0.5, beta=0.1, eta=0.2):
        self.w = np.ones(len(cohorts)) / len(cohorts)
        self.n = np.zeros(len(cohorts))
        self.d = np.zeros(len(cohorts))
        self.U = np.zeros(len(cohorts))
        self.sigma2 = np.ones(len(cohorts))
        self.w_min, self.w_max, self.beta, self.eta = w_min, w_max, beta, eta

    def update(self, cohort_ids, losses, uncertainties, new_counts):
        for c, l, u, dn in zip(cohort_ids, losses, uncertainties, new_counts):
            self.d[c] = (1 - self.beta) * self.d[c] + self.beta * l
            self.U[c] = u
            self.n[c] += dn
            self.sigma2[c] = (1 - self.beta) * self.sigma2[c] + self.beta * l ** 2
        w_star = solve_mixture(self.sigma2, self.U, self.d,
                               self.w_min, self.w_max)
        self.w = (1 - self.eta) * self.w + self.eta * w_star
        # 触发定向数据采集
        triggers = [(c, rho * B_mix * self.w[c])
                    for c in range(len(self.w))
                    if self.n[c] < N_MIN or self.d[c] > TAU_D]
        return self.w, triggers
```

### IP-185 IDM（minimax water-filling 配比）

```python
def solve_mixture(sigma2, U, d, w_min, w_max, gamma=1.0):
    A = sigma2 + LAMBDA_U * U + LAMBDA_D * np.exp(gamma * d)
    w = np.sqrt(A); w = w / w.sum()               # 内点解 w_c ∝ sqrt(A_c)
    return project_bounded_simplex(w, w_min, w_max)

def project_bounded_simplex(w, lo, hi, iters=50):
    v = w
    a, b = v.min() - 1.0, v.max() + 1.0
    for _ in range(iters):
        lam = (a + b) / 2
        ww = np.clip(v - lam, lo, hi)
        if ww.sum() > 1.0: a = lam
        else: b = lam
    return np.clip(v - (a + b) / 2, lo, hi)
```

```python
class InstanceMixtureRouter(nn.Module):
    def __init__(self, d_us, n_experts=4):
        super().__init__()
        self.gate = nn.Linear(d_us, n_experts)
        self.experts = nn.ModuleList([ImpedanceExpert(d_us) for _ in range(n_experts)])
        self.conservative = ConservativeExpert(d_us)
        self.g_min = 0.2

    def forward(self, emb, log_w):
        logits = self.gate(emb) + log_w / TEMP
        g = torch.softmax(logits, dim=-1)
        K = sum(gi * ex(emb) for gi, ex in zip(g, self.experts))
        g0 = self.g_min                          # 安全地板权
        K = (1 - g0) * K + g0 * self.conservative(emb)
        return K, g
```

### IP-187 AMR（实例级再配比）

```python
class AdaptiveMixtureRebalancer:
    def __init__(self, cohorts, w_min=0.02, w_max=0.5, beta=0.1, eta=0.2):
        self.w = np.ones(len(cohorts)) / len(cohorts)
        self.n = np.zeros(len(cohorts)); self.d = np.zeros(len(cohorts))
        self.U = np.zeros(len(cohorts)); self.sigma2 = np.ones(len(cohorts))
        self.w_min, self.w_max, self.beta, self.eta = w_min, w_max, beta, eta

    def update(self, cohort_ids, losses, uncertainties, new_counts):
        for c, l, u, dn in zip(cohort_ids, losses, uncertainties, new_counts):
            self.d[c] = (1 - self.beta) * self.d[c] + self.beta * l
            self.U[c] = u
            self.n[c] += dn
            self.sigma2[c] = (1 - self.beta) * self.sigma2[c] + self.beta * l ** 2
        w_star = solve_mixture(self.sigma2, self.U, self.d,
                               self.w_min, self.w_max)
        self.w = (1 - self.eta) * self.w + self.eta * w_star

                    for c in range(len(self.w))
                    if self.n[c] < N_MIN or self.d[c] > TAU_D]
```

```python
def attribute_evidence(ev, instances):
    scores = []
    for a in instances:
        s = (L_S * IoU(a.mask, ev.contact_region)
             + L_T * temporal_alignment(a, ev)
             + L_F * norm(a.wrench) / (sum(norm(b.wrench) for b in instances) + 1e-9))
        scores.append(s)
    A = softmax(np.array(scores))
    conf_attr = 1 - entropy(A) / np.log(len(instances) + 1e-9)
    return A, conf_attr

def build_J_inst(J_sem_exec, instances, A, conf_attr, w, R_hat):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CIS | O(P·K)+O(K·N_vis) | O(P) | 旋量残差 ≤ ε_cons；接触 IoU ≥ 0.7 |
| ISU | O(N_t·d_us) | O(N_t·d_us) | 逐实例投影误差 ≤ ε_proj；N_t ≤ N_max |
| IDM | O(|C| log |C|) | O(|C|) | 最坏界单调不增；Σw=1、w∈[w_min,w_max] |
| IMR | O(N_t·E·d_us) | O(E·d_us) | 保守专家 ≥ g_min；输出经安全裁剪 |
| AMR | O(|C|)/周期 | O(|C|) | w 平滑收敛；补数据仅在触发条件 |
| ISRT-Dual | 实时 O(K_top·d_us) ≤ 0.3ms | O(N_t·d_us) | 逐实例不阻塞；交接 ramp ≥ T_hand |
| PCE++++++ | O(1) | O(1) | 任一预算耗尽触发降级，安全不降级 |

**正确性定理（I-ESEC-Complete）**：设 A61–A70 成立，且 **(A71)** CIS 接触分割 `IoU≥τ_iou`、旋量守恒残差 `≤ε_cons`；**(A72)** 数据关联 ID 切换率 `≤ρ_switch` 且被 ILM 检出；**(A73)** `w` 由带界 water-filling 给出；**(A74)** IMR 保守专家地板权 `g_min>0` 且逐实例安全裁剪；**(A75)** `conf_attr≥τ_attr` 时归因错误率 `≤ε_attr`；**(A76)** 逐实例锚点读写原子、版本单调。则：
1. **实例级语义分离**：`IoU(mask_i,mask_j)<τ_merge` 时 `K_i,K_j` 独立投影，多物体力违规率 ≤ 单实例的 `1+ε_cons` 倍。
2. **配比最优性**：`w*` 使定义 176 的最坏实例泛化上界最小，且 `min_c w_c ≥ w_min` 保证长尾不灭绝。
3. **长尾单调改善**：`R_c` 上界随 `w_c·N` 单调下降 ⇒ AMR 在有限数据预算下定向补数据是单调改进。
4. **安全不退化**：`Λ` 取可行域交，空集回退最保守；交接 ramp 与保守专家地板权保证控制可执行。
5. **实例可归因**：`conf_attr≥τ_attr` 时失败可定位到实例簇（错误率 `≤ε_attr`），使配比更新有靶心而非噪声。

## 5. 本轮最大风险

**一句话**：实例分割与数据关联一旦出现持续性身份切换或掩码漂移，就会把高刚度阻抗错误绑定到脆性实例、同时把数据配比错误地导向错误的实例簇（「靶心打歪 + 补错数据」），造成比全局平均更危险、且会自我强化的长尾恶化——必须以「mask 质量与溯源的硬门控 + 配比更新仅在归因置信达标时生效 + 可行域交/保守专家地板权的安全兜底 + 配比熵与 w_min 覆盖约束」构建实例级安全护栏，确保实例分割的误差永远不会直接变成控制与配比的错误。
