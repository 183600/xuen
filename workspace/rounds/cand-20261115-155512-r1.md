# 第 8 轮（新灵感循环第 1 轮；本轮灵感：「大语言模型」×「力矩传感」）

> **基线**：第 7 轮 MetricVoiceGauge-OTL-GC-ER（定义 493–529；引理 73–76；实验 E513–E525）。
> 本轮纪律：**提议 ≠ 授权；物理力矩 = 独立见证；慢语义层与快控制层分离**。LLM 只产生类型化、可证伪的提案，永不直接签发证书或写入阈值；力矩提供高频物理见证并对语义主张行使否决权；任一新增模块失效 ⇒ 严格退回 v7。

## 0. 直觉与动机

**灵感 1（大语言模型 → 可审计的语义提案器，而非控制器）**
直觉：v7 的 VoiceCommandTyping 只做浅层 ASR 置信门 + NLI 类型检查，面对“先把左边那个反光件夹稳，再抬起来，如果打滑就换侧”这类复合指令时，既不能分解，也不能在失败后提出恢复方案。LLM 正好补这一层：它能做指代消解、任务分解、异常解释与候选计划生成。但 LLM 有三个不适合进控制回路的性质：**幻觉**（会陈述未被观测到的物理事实）、**非确定性**（同一输入不同采样）、**高延迟**（百毫秒到秒级）。若把 LLM 放进 50Hz 回路或让它直接写证书，系统就退化为“会编造物理事实的控制器”。因此它的正确位置是**慢速语义层（1–5Hz）**：输出类型化、可证伪的提案 π，异步刷新、带版本与 TTL；控制层只消费已通过物理见证的缓存提案。LLM 负责“提出更好的假设/计划”，不负责“决定什么是真的”。

**灵感 2（力矩传感 → 高频、可证伪的物理见证者）**
直觉：语言与视觉都可以被误读，力矩很难。关节力矩/腕部六维力以 1kHz 提供接触、滑移、卡死、碰撞与负载变化的直接物理证据。v7 的 GCT 是一个**开环几何规则**（宽度/深度/最小接触力阈值）：物体质量未知、表面摩擦变化、抓取姿态偏移时，规则会自信地错。力矩残差 `r_τ = τ_meas − τ̂_model` 能在毫秒级回答“抓稳了吗”：法向力是否建立、切向力是否越过摩擦锥、无运动时力矩是否持续异常（卡死）、低频分量是否对应负载突变。于是力矩成为把 LLM 的语义主张升级为证书的**独立见证通道**：语义说“已抓稳”，力矩说“不，你在滑”——后者有最终否决权。

**灵感 3（二者耦合 → 语义-物理双向接地，而非单向命令）**
直觉：单向“LLM 下计划 → 力矩碰巧验证”还不够，因为模糊语义与物理量之间没有可复现的编译关系。真正有价值的是双向：(a) **Γ↑（语言→谓词）**把“夹稳一点”编译成可测的力矩谓词（法向力下界、滑移率上界、持续窗口、允许的负载变化率），使模糊语义变成可证伪的物理测试；(b) **Γ↓（证据→语言）**把力矩证据编译回**每条都绑定 evidence id 的自然语言诊断**（“第 3 指在 t=1.23s 出现滑移，因为法向力 6.8N 低于下界 8N”），供人类审计。两个方向都必须类型化、携带 provenance；Γ↓ 的自由措辞只是表层，任何未被见证支持的断言在序列化时被剥离，防止“事后编故事”。

## 1. 研究问题（本轮要回答什么）

- **Q1（LLM 的安全位置）**：如何让 LLM 提升语义理解、任务分解与恢复能力，同时从**架构与证据结构**上保证幻觉永远不能直接产生安全证书、修改阈值或突破 M₀ 硬约束？
- **Q2（力矩见证的可用性）**：在惯性/重力/摩擦建模误差、负载未知、温度漂移与传感器偏置下，如何构造足够灵敏又低误报的力矩残差与滑移/接触谓词，并给出可校准的漏报/误报界？
- **Q3（双向接地的保真性）**：如何保证“语言→谓词”可测且可执行、“证据→语言”可审计且不越出证据，使两个方向在同一个证据 DAG 上闭环，而不是各说各话？

## 2. 设计原则（在 P7–P9 基础上升级为 P10–P13）

**P10 提议-见证分离（Proposal–Witness Separation）**
LLM 的输出只能是沙箱中的类型化提案 π；证书、阈值、硬约束只能由物理证据链签发。形式化目标：任一安全证书的证据 DAG 中，LLM 只能作为“提议来源”节点，不能作为叶子证据；凡以 LLM 为叶子的证书一律判为污点并拒绝（TaintCert）。

**P11 力矩见证（Torque Witness, TW）**
把接触/滑移/卡死/负载变化编译成带窗口、持续性与不确定度的力矩谓词；见证证书 W 取 `support / refute / unknown` 三值并携带新鲜度。`unknown` 必须**保守地当作不支持**，而不是当作通过。

**P12 双向接地（Bidirectional Grounding, BG）**
Γ↑ 只接受能落到可测统计量上的主张；Γ↓ 只允许输出被见证逻辑蕴含的主张，并逐条绑定 evidence id。不可编译的主张直接拒绝，不可绑定的解释直接剥离——两者都是纯投影，不改变数值行为。

**P13 慢-快分离与陈旧性预算（Slow-Fast Scheduling）**
LLM 以 `f_L ≤ 5Hz` 异步运行、latest-wins、绝不阻塞；控制以 50Hz 只读缓存提案，且只执行 `age ≤ TTL_L` 的提案。LLM 的延迟与抖动被完全隔离在控制 WCET 之外；过期语义等价于“没有提案”，退回 v7。

## 3. 与基线的接口（如何退化）

- LLM 超时 / 不可用 / 输出非法或不可编译 ⇒ 使用 π₀（v7 VoiceCommandTyping+GCT 的结果），等价于 v7；
- 力矩见证不可用 / 标定过期 / 信号饱和 ⇒ 所有依赖 φ_τ 的原子判 `unknown`，准入失败，退回 v7 固定几何检查与阈值；
- 双向接地失败（谓词不可测 / 解释无法绑定证据）⇒ 该主张被剥离或丢弃，数值路径不变；
- v7 的 OTL/GCT/ER 任一失效 ⇒ 继续按 v7 自身退化链退回 v6。

## 4. 预期贡献

1. 一个“LLM 只提议、物理才授权”的架构口径，以及可机检的证书污点规则，从结构上排除幻觉直达安全证书；
2. 一个可证伪、可校准的力矩见证层：残差模型 + 滑移/接触/卡死/负载签名 + 三值证书 + 新鲜度；
3. 一个双向接地编译/解释链，把自然语言主张与物理证据绑定成同一棵可审计证据 DAG；
4. 慢-快调度与严格退化，使新增语义能力不进入 50Hz WCET；
5. 一条完整可证伪路径：E526–E540 覆盖提案类型化、见证灵敏度、对抗幻觉、陈旧性、退化等价、跨本体迁移与端到端任务。

## 5. 本轮最大风险

**一句话**：LLM 的流畅解释会让人误以为语义已被物理验证，而力矩残差模型在摩擦/负载突变下仍有系统误差——真正的残余风险是“见证本身被过度信任”，即把模型化的 `r_τ` 当成比它实际更强的物理真理，从而在漏报时给出高置信的错误安全证书。

## 2. 形式化定义（要点）

**定义 530（LLM 类型化提案 π 与能力闭包）**
`π = (g, ρ, Φ_τ, Π_sketch, conf, prov, t_emit)`。`π ∈ Π_typed` 当且仅当所有槽位通过类型/本体检查、`tools(Π_sketch) ⊆ T₀`、`mag(Π_sketch) ⊆ M_phys`，且不存在自由文本直达执行器的通道。`LLM(ℓ, ctx) → π ∪ {⊥}`；`conf ∈ [0,1]`，`prov = (model_id, prompt_hash, seed, decoding)`。不合法输出一律 ⊥，不进入后续环节。

**定义 531（力矩残差模型 r_τ）**
```
τ̂(t) = M(q)q̈ + C(q,q̇)q̇ + g(q) + τ_f(q̇,z) + Ĵᵀ(q) F̂_ext
r_τ(t) = τ_meas(t) − τ̂(t)
```
`τ_f` 采用 LuGre 摩擦（内部状态 `z` 在线估计）；`F̂_ext` 为已声明负载/环境的期望外力（未知时取 0 并增大不确定度）。残差不是“真实外力”，而是“模型未解释的力矩”——这一点决定了引理 79 的保守界，禁止把 `r_τ` 当作接触力真值。

**定义 532（力矩签名 Ψ）**
```
Ψ(r_τ, W) = (c_on, v_slip, j, Δm, q_s)
```
`c_on`：`|r_τ|` 连续 `k` 拍超过 `ε_τ` 的接触建立指示；`v_slip`：切向残差导数/法向残差（或 `|f_t|/f_n` 越过摩擦锥）的滑移代理；`j`：`|r_τ|` 持续大且 `‖q̇‖≈0` 的卡死指示；`Δm`：`Ĵ^{-T} r_τ` 的低频分量；`q_s ∈ [0,1]`：饱和、丢帧、标定有效期与温漂共同决定的信号质量。

**定义 533（力矩谓词 φ_τ 与编译 Γ↑）**
```
φ_τ = (W, stat, cmp, θ, k, ε),   stat ∈ {c_on, v_slip, j, Δm}
Γ↑: L_NL × Context → Φ_τ ∪ {⊥}
```
原子要求 `stat` 属于可测集合、`θ ∈ M_phys`、`W` 与持续性 `k` 有界、且 `q_s ≥ q_min`；否则 ⊥（“不可见证的主张”）。复合主张可取合取/析取，但**安全关键原子只允许合取**——增加约束只会收紧，不会放宽。

**定义 534（三值见证证书 W）**
```
W = (π_id, φ_τ, evid, verdict, conf, t_eval, TTL)
verdict ∈ {support, refute, unknown}
fresh(W,t) = (t − t_eval ≤ TTL) ∧ (q_s ≥ q_min)
```
`verdict = unknown` 当信号质量不足、标定过期、饱和或证据窗不足；`support/refute` 由 `φ_τ` 在 `r_τ` 上求值。**`unknown` 与 stale 在准入中等价于 not-support**，绝不当作通过。

**定义 535（见证准入 Admit）**
```
Admit(π,{W}) = 1  ⇔  π ∈ Π_typed
  ∧ (∀ a ∈ Φ_τ^crit : ∃ fresh W, verdict(W) = support)
  ∧ (∀ a ∈ Φ_τ      : ¬∃ fresh W, verdict(W) = refute)
  ∧ (∏_a conf(W_a) ≥ τ_admit)
  ∧ compatible(π, π₀)
```
`compatible(π,π₀)` 要求 π 不扩大 v7 的物理可行域、不放宽 M₀/M₁、不改变 δ 触发条件。满足时 `Admit` 只可能**收紧**行为（引理 78）。任一条件失败返回 π₀。

**定义 536（双向接地 Γ↓ 与证据绑定解释）**
```
Γ↓: (W, ctx) → E = {(claim_i, evid_i)}
grounded(E) = 1  ⇔  ∀ i: evid_i ≠ ∅ ∧ evid_i ⊆ W.evid ∧ (W ⊨ claim_i)
```
LLM 只负责表层措辞；机器检查器逐条核对主张-证据对，未绑定或不被见证蕴含的主张被**剥离**（纯投影）。剥离不改变数值路径。

**定义 537（慢-快调度与陈旧性预算）**
```
v_k = (π_k, t_emit,k),  k = 1,2,...
π(t) = π_k  iff  t − t_emit,k ≤ TTL_L  ∧  k = argmax{j : t_emit,j ≤ t}
```
LLM 以 `f_L ≤ 5Hz` 运行、有界超时 `T_out < 1/f_L`、latest-wins；控制回路从不等待 LLM。语义抖动 `J_s = max_k |t_emit,k+1 − t_emit,k|` 只影响提案新鲜度，不影响控制周期。

**定义 538（证据 DAG 与污点规则 TaintCert）**
证书 `C` 携带 `D_C = (V,E)`，叶子 `V_leaf ⊆ PhysicalReceipts`（力矩、本体感觉、空间证书、回执等）。污点规则：
```
taint(v) = LLM                       if v ∈ V_LLM
taint(v) = ⊔_{u→v} taint(u)          otherwise
ValidCert(C) ⇔ ∀ v ∈ V_leaf : taint(v) ≠ LLM
```
LLM 节点可作为“提议来源”被引用，但**不能位于任何叶子**；`Witness` 节点把物理叶子与提案连接，构成唯一授权通道。

**定义 539（条件共形见证阈值 ε_τ(s)）**
按工况 `s = (payload_bin, speed_bin, temperature_bin, tool)` 分层，在标定集上取残差范数的共形分位：
```
ε_τ(s) = Quantile_{1−α}( {‖r_τ‖ : regime = s} )
```
样本不足的层回退父层/全局阈值 `ε_τ^global`，并按层样本量收缩。该阈值只用于“残差是否异常”的见证，不直接当作接触力真值。

**定义 540（退化链标识）**
```
Φ_v8 = {π typed, W fresh-3-valued, Admit witness-gated, Γ↑/Γ↓ evidence-bound, slow-fast}
Φ_v7 = {fixed τ, geometry-only GCT, risk-only weights, no LLM, no torque witness}
```
任一新增组件不可用 ⇒ `Φ_v8` 对应维度取 `Φ_v7` 值；组合退化按组件逐一映射，不产生级联（引理 83）。

## 3. 关键算法骨架

```python
# IP-358 LLMProposer：1-5Hz 异步提案；对证书与阈值无写权限
class LLMProposer:
    def __init__(self, llm, compiler, f_llm=2.0, ttl=0.5, timeout=0.25):
        self.llm, self.compiler = llm, compiler
        self.ttl, self.timeout = ttl, timeout
        self.latest = None            # (version, pi, t_emit)
        self._v = 0

    def tick(self, ell, scene):
        raw = self.llm.generate(ell, scene, timeout=self.timeout)
        if raw is None:
            return                    # 超时：保留旧提案直到 TTL 过期
        pi = parse_typed(raw)         # 只接受白名单槽位，否则 None
        if pi is None or not capability_closed(pi, T0, M_PHYS):
            return                    # ⊥：不产生提案
        atoms = self.compiler.up(pi.claims, scene)   # Γ↑：语言 -> 力矩谓词
        if atoms is None:
            return                    # 不可测主张 => 拒绝
        self._v += 1
        self.latest = (self._v, pi.bind(atoms), now())

    def current(self, t):
        if self.latest is None:
            return None
        _, pi, t_emit = self.latest
        return pi if t - t_emit <= self.ttl else None


# IP-359 TorqueWitness：1kHz 残差 + 签名 + 三值见证
class TorqueWitness:
    def __init__(self, model, conformal, f_tau=1000, win=0.2):
        self.model, self.cal = model, conformal
        self.buf = deque(maxlen=int(win * f_tau))

    def update(self, q, dq, ddq, tau_meas, regime):
        tau_hat = self.model.predict(q, dq, ddq)     # 含摩擦/重力/负载
        r = tau_meas - tau_hat
        eps = self.cal.threshold(regime)             # 条件共形阈值
        qs = signal_quality(regime)                  # 饱和/丢帧/标定有效期
        self.buf.append(Sample(r, eps, qs, t=now()))

    def evaluate(self, phi):
        win = [s for s in self.buf if now() - s.t <= phi.window]
        if len(win) < phi.min_samples or min(s.qs for s in win) < Q_MIN:
            return Witness(phi, verdict="unknown", conf=0.0, t_eval=now())
        sig = extract_signature(win)                 # Ψ
        if not phi.measurable(sig):
            return Witness(phi, verdict="unknown", conf=0.0, t_eval=now())
        verdict = "support" if phi.holds(sig) else "refute"
        return Witness(phi, verdict=verdict,
                       evid=[s.id for s in win], t_eval=now())


# IP-360 WitnessGovernor：见证门；失败一律退回 pi0
class WitnessGovernor:
    def __init__(self, tw, tau_admit=0.8):
        self.tw, self.tau_admit = tw, tau_admit

    def admit(self, pi, pi0, t):
        if pi is None or not typed(pi):
            return pi0
        Ws = {a: self.tw.evaluate(a) for a in pi.atoms}
        for a in pi.critical_atoms:                  # 关键原子必须 support
            w = Ws[a]
            if not fresh(w, t) or w.verdict != "support":
                return pi0
        if any(fresh(w, t) and w.verdict == "refute" for w in Ws.values()):
            return pi0                               # 任何新鲜反驳 => 拒绝
        if prod(w.conf for w in Ws.values()) < self.tau_admit:
            return pi0
        if not compatible_with_v7(pi, pi0):
            return pi0                               # 只准收紧，不准扩权
        return Admitted(pi, Ws, EvidenceDAG(pi, Ws))


# IP-361 双向接地：Gamma_up 可测编译；Gamma_down 证据绑定解释
class BidirectionalGrounding:
    def up(self, claims, scene):
        atoms = [compile_atom(c, scene) for c in claims]
        if any(a is None or not measurable(a) for a in atoms):
            return None                              # 不可见证 => 拒答
        return atoms

    def down(self, W, draft_prose):
        claims = extract_claims(draft_prose)         # 机器可解析断言
        keep, stripped = [], 0
        for c in claims:
            if c.evidence and c.evidence <= W.evid and entailed(c, W):
                keep.append(c)
            else:
                stripped += 1                        # 未绑定/不被蕴含 => 剥离
        return Explanation(keep, stripped)


# IP-363 证据 DAG 污点检查：LLM 永不作为叶子
def valid_cert(cert):
    return all(leaf.source != "LLM" for leaf in cert.evidence_dag.leaves())


# IP-364 TWG-LLM 主闭环：慢语义层 + 50Hz 快控制层
def twg_llm_round(M, s, obs, ell=None):
    t = now()
    pi0 = M.voice_typing.process(ell)                # v7 路径（含 GCT/OTL/ER）
    pi = M.llm_proposer.current(t) if M.llm_proposer else None
    admitted = (M.governor.admit(pi, pi0, t)
                if (pi is not None and M.governor is not None) else pi0)

    # --- 50Hz 热路径：只读缓存，绝不调用 LLM ---
    iota = admitted.pi
    for atom in iota.atoms:                          # 见证在 1kHz 线程更新
        M.torque_witness.evaluate(atom)
    C, spatial_cert, claims, metrics, rewards = M.v7_core(s, obs, iota)
    return C, spatial_cert, claims, metrics, rewards, admitted.evidence
```

## 4. 推导

**引理 77（无 LLM 单独授权 / TaintCert 可靠性）** 若证书按定义 538 构造并通过 `ValidCert`，则其每条证据路径的叶子均为物理回执，LLM 节点只能出现在“提议来源”位置。因此 LLM 幻觉无法在没有任何物理见证的情况下使 `ValidCert(C)=1`。*证明*：对证据 DAG 结构归纳。叶子情形由定义 538 直接排除 LLM 叶子；内点情形，证书的 discharge 边必经过一个 `Witness` 节点，而 `Witness` 的 verdict 由定义 534 在 `r_τ` 上求值，其叶子是力矩/本体回执。故证书的物理支撑不依赖 LLM 的真值性。

**引理 78（准入的保守性 / 不扩权）** 若 `Admit(π,{W})=1`，则 `Act(π) ⊆ Act(v7)`，且 π 不会使任何 M₀/M₁ 约束变松。*证明*：`Admit` 要求 `compatible(π,π₀)`，而 `compatible` 逐条要求不扩物理包线、不放宽硬约束；力矩原子只增加合取约束（关键原子仅允许合取），合取只会缩小可行集。故准入是“收紧或保持”，绝不扩权。推论：LLM 再“聪明”，也不能越过 v7 的安全包线。

**引理 79（滑移见证的检测延迟与漏报界）** 设在窗口 `W` 内真实滑移使 `|r_τ| ≥ Δ_s`，传感器噪声与模型误差满足 `‖noise‖ ≤ ε_τ`，且 `Δ_s > ε_τ`。则签名在 `W` 内被检出，检测延迟 `≤ W`；漏报只能在 `Δ_s ≤ ε_τ` 时发生，其概率被条件共形覆盖率约束为 `≤ α + η_model`（`η_model` 为层间漂移项）。*证明*：由三角不等式 `|r_τ| ≥ Δ_s − ε_τ > 0` 超过阈值；覆盖由定义 539 的分层共形保证，漂移由 `TV_s` 修正。注意这是**相对模型残差**的界，不是对外力真值的界——故本引理不声称“力矩=真值”。

**引理 80（条件共形覆盖与低样本回退）** 在层 `s` 内可交换假设下 `P(‖r_τ‖ ≤ ε_τ(s) | s) ≥ 1−α`；当 `|C_cal^s| < n_min` 回退父层时，覆盖按 `1−α−η_parent` 优雅降级。*证明*：标准 split-conformal；分层只改变分位集合，不改变层内可交换性；回退相当于用更大的混合分布，覆盖率损失由父层与子层的 TV 距离界定。

**引理 81（慢-快隔离与陈旧性安全）** 若控制只消费 `current(t)` 返回且 `age ≤ TTL_L` 的提案，且 LLM 调用在独立线程且有界超时，则 50Hz 主路径 WCET 与 LLM 延迟无关；任何提案在执行时的陈旧度 `≤ TTL_L`。*证明*：`current` 是 O(1) 读；LLM 从不被主路径调用；`Admit` 对见证做 `fresh` 检查，过期见证判 not-support。故不存在“用旧语义执行新动作”的路径超过 `TTL_L`。

**引理 82（双向接地保真）** 若 `grounded(Γ↓(W,draft))=1`，则保留的每条主张 `c` 都有 `∅≠evid(c) ⊆ W.evid` 且 `W ⊨ c`；被剥离的主张不进入序列化。故解释层不能引入未被证据支持的新事实，审计可沿 `claim→evidence` 回指到物理回执。*证明*：`down` 的 keep 条件即定义 536；剥离是纯投影，不改变数值。对 Γ↑，`measurable(a)` 失败即返回 ⊥，保证不存在“不可测却被当作已测”的原子。

**引理 83（联合退化等价）** 关闭 LLM ⇒ `current=None` ⇒ `Admit` 返回 π₀；关闭力矩见证 ⇒ 所有力矩原子 `unknown` ⇒ 关键原子非 support ⇒ π₀；两者皆关 ⇒ π₀ = v7 输出。且 v7 内部 OTL/GCT/ER 退化链不受影响。故任意子集失效都等价于 v7 或其自身退化，不产生级联。*证明*：逐组件检查定义 535/540 的映射；`Admit` 是单调保守门，组件缺失只会使更多原子 not-support，不会使更多提案通过。

## 8. 本轮最大风险

**一句话**：LLM 的流畅解释会让人误以为语义已被物理验证，而力矩残差模型在摩擦/负载突变下仍有系统误差——真正的残余风险是“见证本身被过度信任”，即把模型化的 `r_τ` 当成比它实际更强的物理真理，从而在漏报时给出高置信的错误安全证书；缓解只能依赖证伪式结构（LLM 不可为证据叶子、见证三值保守、条件共形覆盖、关键原子 support-only、严格退化 v7），并用 E528/E531/E533/E536/E539 主动攻击这一信任假设。
