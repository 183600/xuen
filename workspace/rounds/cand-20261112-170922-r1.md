# 第 61 轮（承接第 60 轮「场景感知闭环」IP-153~160；灵感循环第 7 轮；本轮灵感：「机器人操作系统」×「专利布局」）

> 第 60 轮把闭环推进到「场景→意图→约束→阻抗→执行→EV-exec→场景更新」，并用 EPIR 处理 ROS 消息丢失与乱序。但**三个更深层的局限**仍未解决：
> 1. **EPIR 假设了不存在的「全局单调 seq_id」**：ROS 2 是去中心化 DDS 系统，节点重启、namespace 重映射、launch 重拉会使序列号回退或复用；第 60 轮的 `last_received+1` 在节点级重启后会与旧证据「撞号」，导致**证据冒名顶替（provenance laundering）**——旧场景的合规证据可被新节点继承，证据链看似连续、实则换了一个主体。
> 2. **ROS 的失败不只是「丢包」**：更隐蔽的是 QoS 不兼容导致的**静默不连接**（reliable 发布者遇到 best-effort 订阅者）、`transient_local` 与 `volatile` 的持久化差异、lifecycle 节点在 inactive 状态下不产生证据、executor 回调组造成的**优先级反转**。这些失败没有「丢包异常」，只有「证据永远不来」，第 60 轮的序号缺口检测无法区分「消息丢了」和「压根没连上」。
> 3. **研究自身缺少「权项边界」**：IP-145~160 已形成密集技术簇，但各 IP 之间是**平铺的清单**，没有独立权项/从属权项、优先权日、依赖关系、自由实施（FTO）分析。换言之，研究已经进入「自己与自己的权项重叠」阶段：EPIR 的因果恢复与 EPIR-Protocol 的序号预测实质是同一发明，SSM 与 SIC 也存在交叉。没有专利式布局，技术贡献会被自己的公开顺序和权项宽窄所稀释。

## 0. 直觉与动机

**灵感 1（ROS → 计算图即权项图）**
直觉：ROS 2 的一张运行图（graph）不是「节点+话题」的管道，而是一群**彼此主张资源主权的主体**。一个节点发布 `/cmd_impedance`、占用 `actuator_authority=(right_arm, 0~40N)`、声明 QoS `reliable+transient_local`，本质是在说：「这块执行能力归我，且我的证据必须可靠送达」。这与专利权利要求（claim）的结构同构：
- 节点/能力 ≈ 申请人；
- 话题/参数/QoS/执行器权限 ≈ **权项范围（claim scope）**；
- lifecycle 状态 ≈ 权项状态（pending / active / lapsed / invalidated）；
- 证据 EV-exec ≈ **优先权文件与实施证明**；
- executor 调度器 ≈ 审查/授权机构。

关键洞见：**把「执行资源竞争」升级为「权项边界裁决」**——不是谁先抢到锁谁执行，而是谁的主张「更新（priority）且更具体（specificity）且更安全（safety）」。

**灵感 2（专利布局 → 运行时自由实施 FTO）**
直觉：专利布局的核心不是「写很多专利」，而是三件事：**圈地（claim fencing）、优先权（priority）、自由实施（freedom-to-operate）**。机器人执行层同样需要：在执行一个动作前，先问「我是否落入了某个更高优先级的**安全权项**范围？」若落入，则要么获得授权（时间片资源租约），要么**设计绕行（design-around）**到另一组安全的阻抗参数，而不是硬执行后失败。

**灵感 3（续案/族谱 → 跨重启的证据血统 ELE）**
直觉：公司重组不会让专利失效，只会在**同一专利族（family）**下新增**续案（continuation）**并保留**优先权日**。节点重启也应如此：重启不是「新主体从零开始」，而是同一 `lineage_id` 下的新 `epoch`，`(lineage, epoch, counter)` 三元组保证唯一性，`parent_hash` 把新旧 epoch 连成哈希链。这样即使 seq 计数器归零，证据也不会撞号，更不会冒名。

**灵感 4（QoS → 权项使能性 enablement）**
直觉：专利里「公开不充分 ⇒ 权项不可实施」；ROS 里「QoS 不足 ⇒ 证据不可获得」。若一个证据权项要求 `reliable + transient_local`，实际端点却是 `best_effort + volatile`，那么该证据在法律意义上是**非使能的（non-enabling）**——不是数值错了，而是传输契约根本不支持它被完整观察。把 QoS 的偏序关系接入证据有效性，是第 60 轮缺失的一层。

**灵感 5（专利丛林 → 权项冲突与运行时无效宣告）**
直觉：专利丛林（patent thicket）是大量重叠权项导致的「谁都不敢实施」。ROS 执行层也有 thicket：多个行为树节点、安全监视器、遥操作节点同时主张同一执行器权限，形成**权项冲突环**，表现为死锁或优先级反转。解法不是简单加锁，而是**冲突环检测 + 时间片授权租约 + 运行时无效宣告（opposition/invalidation）**：当执行证据证伪某个场景先验时，直接「无效」旧权项并回滚到上一个有效配置（prior art）。

**灵感 6（合流 → CAGE：权项图治理与证据闭环）**
直觉：把上述五点合为 **CAGE（Claim-grAph Governance & Evidence）**：
`权项注册 → FTO 裁决 → 授权租约 → QoS 使能校验 → 执行 → 族谱化证据 → 权项图更新 / 无效宣告`。
它把第 60 轮的「证据链」从「消息顺序」升级为「**主体血统 + 权项边界 + 使能条件**」的三重连续性。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（ROS 能力权项图 RCG）** 权项图 G_C = (C, E_dep, E_conf)。其中：
- **权项** c = (id, owner, scope, priority, state, deps)。`owner` 为 ROS 节点/进程的 `lineage_id`；`state ∈ {pending, active, lapsed, invalidated}`。
- **权项范围** scope(c) = (T, P, Q, A)：T 为话题/服务/动作集合，P 为参数命名空间与参数区间，Q 为 QoS 需求，A 为执行器权限（关节集合 × 力/速度包络）。
- **冲突边** E_conf = {(c_i,c_j) | scope(c_i).A ∩ scope(c_j).A ≠ ∅}；**依赖边** E_dep 表示 c_j 的使能以 c_i 的证据为前提。
- **具体度** spec(c) = (|T|, |P|, |Q|, |A|) 的归一化逆宽度：范围越窄，具体度越高。
- **优先序** ≺：c_i ≺ c_j 当且仅当 `(priority_time_i, safety_level_i, spec_i)` 字典序更小；安全权项永远优先于性能权项。
- **重叠度** overlap(c_i,c_j) = |A_i∩A_j| / |A_i∪A_j| ∈ [0,1]，并叠加 QoS 兼容性惩罚。

**定义 162（运行时自由实施 FTO 裁决）** 给定新权项 c_new 与图 G_C，裁决算子
`FTO(c_new,G_C) → {GRANT_EXCLUSIVE, LICENSE(τ_lease), DESIGN_AROUND(K'), BLOCK}`：
- **新颖性检查**：若存在 c 与 c_new 的 scope 完全相同且 priority_time 更早，则 c_new 无新颖性，必须改为从属权项或拒绝。
- **重叠检查**：N = {c ∈ C_active | overlap(c,c_new) > θ_overlap}。
- **裁决规则**：
```
if N = ∅: GRANT_EXCLUSIVE
elif ∀c∈N: c.priority_time < c_new.priority_time and c.safety_level ≤ c_new.safety_level:
     GRANT_EXCLUSIVE            # 新权项更新且不降安全
elif ∃c∈N: c.safety_level > c_new.safety_level:
     if 存在可行 K' ∈ K_safe 且 overlap(c,c_new|K') ≤ θ_overlap:
          DESIGN_AROUND(K')    # 安全优先，设计绕行
     else: BLOCK               # 不得以性能动作侵犯安全权项
else:
     LICENSE(τ_lease)          # 平级或更旧权项：时间片租约
```
- 租约 `τ_lease` 由执行预算 B_exec 与冲突数动态给出，到期自动收回，避免饥饿。

**定义 163（族谱化证据账本 ELE）** 证据 e 的地址为三元组 `addr(e) = (lineage_id, epoch, counter)`，并携带 `parent_hash, priority_time, content, hash`。其中：
- `lineage_id` 在一次 ROS 进程「血统」创建时生成，跨重启保持不变；
- `epoch` 在每次节点重启/重新配置/重映射时 +1，`counter` 在每个 epoch 内从 0 单调递增；
- `hash_e = H(parent_hash_e || lineage_id || epoch || counter || canon(content))`；
- **续案语义**：重启只增加 epoch，不改变 lineage 与 priority_time；旧 epoch 的最后一个 hash 成为新 epoch 的 parent_hash。
- **冒名检测**：若同一 `owner_name` 出现不同 `lineage_id`，或同一 `(lineage, epoch)` 内 counter 回退，则判定为「证据主体异常」，拒绝合并。

**定义 164（QoS-权项使能性 QCH）** 对每个证据权项 c 定义必需 QoS 下界 `q_req(c)`，对每个端点定义实际 QoS `q_act`。QoS 偏序 `⊒`：
- reliability: `reliable ⊒ best_effort`；
- durability: `transient_local ⊒ volatile`；
- deadline: 数值越小越强（`d_act ≤ d_req` 才使能）；
- liveliness: lease 越短越强（`l_act ≤ l_req`），且 `automatic ⊒ manual_by_node`。
**使能判定**：`enabled(c) = (q_act ⊒ q_req(c))`。若 `enabled(c)=false`，则证据状态为 `NON_ENABLING`，即使内容完整也不得计入合规链。对非使能证据触发 `QOS_REPAIR`（升级为 reliable/transient_local）或 `EVIDENCE_DOWNGRADE`（降级为弱证据，不参与安全判定）。

**定义 165（权项-证据对照表 CCES）** 权项 c 的对照元素 `E_c = {e_1,...,e_m}`，每个元素带权重 w_i 与是否关键 `crit_i`。证据向量 v(ε) ∈ {0,1}^m 表示该元素是否被证据支持。**充分度**：
```
σ(ε,c) = Σ_i w_i·v_i(ε) / Σ_i w_i
enabled_evidence(ε,c) = (σ(ε,c) ≥ τ_suff) ∧ (∀i: crit_i ⇒ v_i(ε)=1)
```
关键元素通常包括：`timestamp, lineage, epoch, seq, force_bound, scene_id, intent_lock_id`。缺失任一关键元素 ⇒ 证据「不可实施」，不得用于无效宣告或安全放行。

**定义 166（专利丛林仲裁 PTA）** 在冲突图 G_conf = (C, E_conf) 上：
- **冲突环**：若存在 c_1 → c_2 → ... → c_1，则判定为**权项互锁（deadlock thicket）**；
- **优先级反转**：若存在依赖路径 c_i → ... → c_j，而 priority(c_i) > priority(c_j) 却被 c_j 阻塞，则判定为反转；
- **仲裁算子** `Arbitrate(cycle)`：按 `(safety_level ↓, priority_time ↑, spec ↓)` 选择「锚权项」；其余权项获得 `τ_lease` 时间片；若锚权项无法满足依赖，则沿 E_dep 反向释放低优先权项；
- **可终止性条件**：所有租约有限且到期强制回收，故仲裁不会无限等待。

**定义 167（运行时无效宣告 IOL）** 给定权项 c、反证证据 ε_o 与先验有效性 `prior_valid(c)`，似然比 `LR = P(ε_o | c 为假)/P(ε_o | c 为真)`。后验：
```
valid'(c) = sigmoid( logit(prior_valid(c)) + log LR )
```
若 `valid'(c) < τ_valid`，则 `state(c) ← invalidated`，并回滚到 `prior_art(c)`（最近一个通过 SIC 的有效配置 K*），同时把 ε_o 写入 ELE 作为「无效宣告证据」。关键区分：**证据不足（σ 低）只挂起，不无效；证据矛盾（LR 高）才无效**。

**定义 168（权项预算 B_claim 与 PCE+++++）** `B_claim = (B_graph, B_fto, B_lineage, B_qos)`：
- `B_graph`：权项图更新/冲突检测算力；
- `B_fto`：FTO 裁决时延预算；
- `B_lineage`：epoch 迁移与哈希链存储；
- `B_qos`：QoS 探测与修复开销。
备用策略：`B_graph` 耗尽 ⇒ 冻结图、只读裁决；`B_fto` 耗尽 ⇒ 默认 `BLOCK` 高风险动作（fail-safe）；`B_lineage` 耗尽 ⇒ 压缩旧 epoch、保留链尾与优先权证明；`B_qos` 耗尽 ⇒ 只接受已使能端点，禁止临时升级。
```
voi_claim(π) = VOI_cog(π) - cost_cog(π) - cost_exec(π) - cost_claim(π)
cost_claim = λ_g·Graph_update + λ_f·FTO_latency + λ_l·Lineage_store + λ_q·QoS_probe
```

### IP-161 RCG（ROS 能力权项图）

```python
from dataclasses import dataclass, field

@dataclass(frozen=True)
class Scope:
    topics: frozenset
    params: frozenset
    qos: tuple          # (reliability, durability, deadline, liveliness)
    authority: frozenset  # {(joint, force_lo, force_hi, vel_max)}

@dataclass
class Claim:
    cid: str
    owner: str            # lineage_id
    scope: Scope
    priority_time: float
    safety_level: int     # 0=performance, 1=monitor, 2=safety
    state: str = "pending"
    prior_art: object = None

class ROSClaimGraph:
    def __init__(self, theta_overlap=0.3):
        self.claims = {}
        self.by_authority = {}       # joint -> set[cid] (倒排索引)
        self.theta = theta_overlap

    def register(self, c: Claim):
        for (joint, *_ ) in c.scope.authority:
            self.by_authority.setdefault(joint, set()).add(c.cid)
        self.claims[c.cid] = c

    def overlap(self, a: Claim, b: Claim) -> float:
        A, B = a.scope.authority, b.scope.authority
        if not (A & B):
            return 0.0
        jac = len(A & B) / len(A | B)
        qos_pen = 0.0 if qos_compatible(a.scope.qos, b.scope.qos) else 0.2
        return min(1.0, jac + qos_pen)

    def candidates(self, c: Claim):
        out = set()
        for (joint, *_ ) in c.scope.authority:
            out |= self.by_authority.get(joint, set())
        return [self.claims[i] for i in out if i != c.cid]
```

### IP-162 FTO（运行时自由实施）

```python
def fto(c_new, G, K_safe, theta_overlap=0.3):
    dup = [c for c in G.claims.values()
           if c.state == "active" and c.scope == c_new.scope]
    if dup and min(c.priority_time for c in dup) < c_new.priority_time:
        return ("BLOCK", "no_novelty")

    N = [c for c in G.claims.values()
         if c.state == "active" and G.overlap(c, c_new) > theta_overlap]
    if not N:
        return ("GRANT_EXCLUSIVE", None)

    safety = [c for c in N if c.safety_level > c_new.safety_level]
    if safety:
        for Kp in design_around_candidates(K_safe):
            if all(G.overlap(c, project(c_new, Kp)) <= theta_overlap for c in safety):
                return ("DESIGN_AROUND", Kp)
        return ("BLOCK", "safety_claim")

    if all(c.priority_time < c_new.priority_time for c in N):
        return ("GRANT_EXCLUSIVE", None)
    return ("LICENSE", lease_from_budget(G, N))
```

### IP-163 ELE（族谱化证据账本）

```python
class LineageLedger:
    GENESIS = "0" * 64

    def __init__(self, lineage_id, priority_time):
        self.lineage = lineage_id
        self.priority_time = priority_time
        self.epoch = 0
        self.counter = 0
        self.head = self.GENESIS
        self.chain = []

    def restart(self, reason):
        self.epoch += 1
        self.counter = 0          # counter 归零，但 lineage/priority/head 不变
        self._restart_reason = reason

    def append(self, content):
        self.counter += 1
        body = {"lineage": self.lineage, "epoch": self.epoch,
                "seq": self.counter, "priority_time": self.priority_time,
                "parent": self.head, "content": content}
        body["hash"] = sha256(canonical(body))
        self.head = body["hash"]
        self.chain.append(body)
        return body

def verify_lineage(chain, expected_owner):
    prev = LineageLedger.GENESIS
    last_epoch = -1
    for e in chain:
        if e["parent"] != prev:
            return "HASH_BREAK"
        if e["lineage"] != expected_owner:
            return "IMPERSONATION"          # 同名不同血统
        if (e["epoch"], e["seq"]) <= (last_epoch, -1):
            return "REPLAY_OR_ROLLBACK"
        if e["epoch"] != last_epoch and e["seq"] != 1:
            return "EPOCH_NOT_FIRST"
        prev, last_epoch = e["hash"], e["epoch"]
    return "OK"
```

### IP-164 QCH（QoS-权项使能性）

```python
REL = {"best_effort": 0, "reliable": 1}
DUR = {"volatile": 0, "transient_local": 1}
LIVE = {"manual_by_node": 0, "automatic": 1}

def qos_enabled(q_act, q_req):
    ok = (REL[q_act.reliability] >= REL[q_req.reliability]
          and DUR[q_act.durability] >= DUR[q_req.durability]
          and q_act.deadline <= q_req.deadline
          and q_act.liveliness_lease <= q_req.liveliness_lease
          and LIVE[q_act.liveliness] >= LIVE[q_req.liveliness])
    return ok

def evidence_state(ev, claim):
    if not qos_enabled(ev.endpoint.qos, claim.scope.qos):
        return "NON_ENABLING"
    if not cces_enabled(ev, claim):
        return "INSUFFICIENT"
    return "ENABLED"
```

### IP-165 CCES（权项-证据对照）

```python
def cces_enabled(ev, claim, tau=0.85):
    elems = claim.chart          # {name: (weight, critical)}
    num = sum(w for name, (w, _) in elems.items() if ev.supports(name))
    den = sum(w for (w, _) in elems.values())
    sigma = num / den if den else 0.0
    critical_ok = all(ev.supports(name)
                      for name, (_, crit) in elems.items() if crit)
    return sigma >= tau and critical_ok
```

def arbitrate_conflicts(G):
    cycles = find_cycles(G.conflict)
    for cyc in cycles:
        anchor = min(cyc, key=lambda c: (-c.safety_level,
                                         c.priority_time,
                                         -specificity(c)))
        for c in cyc:
            if c is not anchor:
                c.lease = min(lease_from_budget(G, cyc), TAU_LEASE_MAX)
        if not deps_satisfied(anchor, G):
            for c in reversed(dependency_path(anchor, G)):
                if c.priority_time > anchor.priority_time:
                    release(c)
        log_arbitration(cyc, anchor)
    return G

def opposition(c, ev_o, prior_art):
    if evidence_state(ev_o, c) != "ENABLED":
        suspend(c); return "SUSPENDED"      # 证据不足 ≠ 权项为假
    lr = likelihood_ratio(ev_o, c)

class ClaimBudget:
    def __init__(self, graph_ops, fto_ms, lineage_mb, qos_probes):
        self.B = dict(graph=graph_ops, fto=fto_ms, lineage=lineage_mb, qos=qos_probes)

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RCG 注册 | O(\|scope\|) | O(\|C\|·\|A\|) | 倒排索引不漏冲突候选 |
| FTO 裁决 | O(k log k)，k=冲突候选数 | O(k) | 安全权项不被性能权项侵犯 |
| ELE 追加/校验 | O(1) / O(N) | O(N) | 三元组唯一 + 哈希链连续 |
| QCH | O(1) | O(1) | QoS 偏序使能判定 |
| CCES | O(\|E_c\|) | O(1) | 关键元素全覆盖才使能 |
| PTA | O(V+E) | O(V+E) | 冲突环可检测、租约有界 |
| IOL | O(1) | O(1) | 证据不足只挂起，矛盾才无效 |

**正确性定理（CAGE）**：假设 A66–A72 成立：
- **(A66)** 权项范围有限、冲突图可构造；**(A67)** 哈希函数抗第二原像；**(A68)** QoS 偏序为良基偏序且 `q_req` 可满足；**(A69)** 对照表覆盖全部关键元素；**(A70)** 租约有限、调度器公平；**(A71)** IOL 似然比校准；**(A72)** B_claim 单调消耗。
则：
1. **证据血统唯一性**：任意两条证据 `addr(e_i) ≠ addr(e_j)`；节点重启只增加 epoch，`parent_hash` 链保证「新 epoch 是旧 epoch 的续案」而非新主体，同名不同 lineage 必被拒绝。
2. **FTO 安全性**：若存在更高安全级权项且无可行 design-around，则 `FTO=BLOCK`，执行器不会被更低安全级的动作占用。
3. **使能性可靠**：若证据通过 QCH+CCES，则不存在「因 QoS 静默丢弃或关键元素缺失而导致的假合规」。
4. **仲裁活性**：冲突环在有限租约内被打破，不会出现永久死锁；优先级反转沿依赖路径被显式修复。
5. **无效宣告可靠性**：仅当反证证据本身通过使能校验且后验有效性低于阈值时，旧权项才被无效并回滚到 prior art。
6. **预算安全性**：任一 `B_claim` 耗尽都触发对应的 fail-safe 降级，不会用「更少的证据」冒充「更强的结论」。

**一句话**：若权项图把安全边界画得过宽、或 QoS/族谱探测本身失真，CAGE 会从「防止证据冒名」退化为「自我专利丛林」——FTO 把所有动作都判为侵权而 BLOCK，系统陷入「为了证明安全而拒绝执行」的僵局；因此必须用「FTO 失败默认最小可行动作 + 租约强制回收 + prior art 回滚 + B_claim 预算」四重机制，确保治理层永远不成为执行层的单点故障。

### IP-161/162 RCG + FTO

```python
def fto(c_new, G, K_safe, theta=0.3):
    dup = [c for c in G.active() if c.scope == c_new.scope]
    if dup and min(c.priority_time for c in dup) < c_new.priority_time:
        return ("BLOCK", "no_novelty")

    N = [c for c in G.active() if G.overlap(c, c_new) > theta]
    if not N:
        return ("GRANT_EXCLUSIVE", None)

    safety = [c for c in N if c.safety_level > c_new.safety_level]
    if safety:
        for Kp in design_around_candidates(K_safe):
            if all(G.overlap(c, project(c_new, Kp)) <= theta for c in safety):
                return ("DESIGN_AROUND", Kp)
        return ("BLOCK", "safety_claim")

    if all(c.priority_time < c_new.priority_time for c in N):
        return ("GRANT_EXCLUSIVE", None)
    return ("LICENSE", lease_from_budget(G, N))
```

### IP-163 ELE（族谱化证据，解决重启撞号）

```python
class LineageLedger:
    GENESIS = "0" * 64

    def __init__(self, lineage_id, priority_time):
        self.lineage, self.priority_time = lineage_id, priority_time
        self.epoch, self.counter, self.head = 0, 0, self.GENESIS

    def restart(self):
        self.epoch += 1
        self.counter = 0            # 关键：counter 归零，但 lineage/priority/head 不变

    def append(self, content):
        self.counter += 1
        body = {"lineage": self.lineage, "epoch": self.epoch, "seq": self.counter,
                "priority_time": self.priority_time, "parent": self.head,
                "content": content}
        body["hash"] = sha256(canonical(body))
        self.head = body["hash"]
        return body

def verify_lineage(chain, expected_owner):
    prev, last_epoch = LineageLedger.GENESIS, -1
    for e in chain:
        if e["parent"] != prev:                 return "HASH_BREAK"
        if e["lineage"] != expected_owner:      return "IMPERSONATION"
        if (e["epoch"], e["seq"]) <= (last_epoch, -1): return "REPLAY_OR_ROLLBACK"
        if e["epoch"] != last_epoch and e["seq"] != 1: return "EPOCH_NOT_FIRST"
        prev, last_epoch = e["hash"], e["epoch"]
    return "OK"
```

### IP-164/165 QCH + CCES（QoS 使能 + 对照表充分度）

```python
REL  = {"best_effort": 0, "reliable": 1}
DUR  = {"volatile": 0, "transient_local": 1}
LIVE = {"manual_by_node": 0, "automatic": 1}

def qos_enabled(q_act, q_req):
    return (REL[q_act.reliability] >= REL[q_req.reliability]
            and DUR[q_act.durability] >= DUR[q_req.durability]
            and q_act.deadline <= q_req.deadline
            and q_act.liveliness_lease <= q_req.liveliness_lease
            and LIVE[q_act.liveliness] >= LIVE[q_req.liveliness])

def evidence_state(ev, claim, tau=0.85):
    if not qos_enabled(ev.endpoint.qos, claim.scope.qos):
        return "NON_ENABLING"                 # 静默不连接/降级，内容对也不可用
    elems = claim.chart
    num = sum(w for name, (w, _) in elems.items() if ev.supports(name))
    den = sum(w for (w, _) in elems.values())
    sigma = num / den if den else 0.0
    critical_ok = all(ev.supports(n) for n, (_, crit) in elems.items() if crit)
    return "ENABLED" if sigma >= tau and critical_ok else "INSUFFICIENT"
```

def opposition(c, ev_o, prior_art):

- 去 ELE：重启/重映射场景证据连续性由 ≥99.99% 降至 <90%，冒名无法检出；
- 去 QCH：`best_effort+volatile` 端点上「内容完整但不可使能」的假合规显著上升；
- 去 FTO：安全监视权项与性能动作重叠时，安全侵犯次数 >0；
- 去 IOL：错误场景先验无法被反证清除，K_safe 长期污染。

## 6. 本轮最大风险

**一句话**：若权项图过宽或 QoS/族谱探测失真，CAGE 会从「防证据冒名」退化为「自我专利丛林」——FTO 把一切动作判为侵权而 BLOCK，系统陷入「为证明安全而拒绝执行」的僵局；必须以「FTO 失败默认最小可行动作 + 租约强制回收 + prior-art 回滚 + B_claim 预算」四重护栏，确保治理层永远不是执行层的单点故障。
