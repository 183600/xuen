# 第 67 轮（承接第 66 轮「RAS 情绪驱动闭环」IP-224~233；灵感循环第 1 轮；本轮灵感：「在线学习」×「全身控制」）

> 第 66 轮 RAS 用面部表情捕获风险态度，用 `λ_risk` 把控制量整体缩放。它回答的是「该多保守」，却没有回答「模型错了以后怎么办」：VISTA/RAS 整条谱系的动力学模型是**冻结的**。闭环能检出故障、归因故障、降级控制，却不能从故障里学到任何东西。
>
> 这在**全身控制（whole-body control, WBC）**中是结构性缺陷：负载、接触模式、摩擦、磨损、地形都在变，固定模型会持续漂移；而 WBC 的每一次求解都同时被浮基动力学、接触约束、摩擦锥、力矩限位绑死，模型一错，安全约束就可能当场失效。
>
> 本轮命题：
>
> **把「故障归因闭环」升级为「归因门控的在线学习闭环」：用 VISTA/RAS 的后验决定「学哪里」，用认证前缀与可微 QP 敏感度决定「学多少、学多久」，让学习只发生在安全约束的零空间里。**
>
> 命名为 **SOMA（Safe Online Model Adaptation；soma 亦为「身体」）**。它的口号不是「学得更快」，而是「**只在证书允许的零空间里学**」。

## 0. 直觉与动机

**灵感 1（在线学习 → 全身控制：稳定-可塑性困境就是任务优先级困境）**
直觉：WBC 已经用一个分层 QP 回答「哪些任务不能动」：平衡与接触最高，末端跟踪次之，姿态/冗余最低。在线学习面对的是同一个结构——**哪些参数不能动**。当前一步的安全约束由哪些参数决定，那些参数就必须被「冻结」；只有落在零空间与低优先级方向的参数才允许可塑。于是 stability-plasticity 不必靠一个全局学习率来折中，而可以由任务优先级逐方向地裁剪。**可塑性应当像任务一样被排序，而不是像噪声一样被平均。**

**灵感 2（全身控制 → 在线学习：身体就是实验设计器）**
直觉：动力学学习通常在离线数据集上做，数据分布由别人给定；而全身机器人会通过接触切换**自己制造非平稳数据**。这既是灾难（分布漂移），也是礼物（对偶控制）：控制器可以在安全集内主动选择小幅激励，使当前最不确定的参数方向获得最大 Fisher 信息。**「动一下再学」不是探索的浪漫，而是受约束的最优实验设计。**

**灵感 3（故障归因 → 信用分配：学哪里）**
直觉：VISTA/RAS 的联合后验本来就在回答「几何、传感器、模型、意图哪一层坏了」。这正是在线学习最缺的 credit assignment。若后验把故障归给 `H_model_payload`，就没有理由去动摩擦参数；若归给 `H_contact_friction`，就不该让惯性参数一起漂。**只学被归因为坏掉的那一维，是最高效的正则化。**

**灵感 4（认证前缀 → 信赖域：学多少、学多久）**
直觉：RAS 的 `k*` 前缀是一个不可逆视界：只承诺前 k 步。在线更新也必须这样：不是「先改，坏了再回滚」，而是「先证明在参数球 `B_ρ` 与预测时域 `k` 内所有安全约束仍然成立，才允许这次更新进入实时控制器」。**学习率不该由调参决定，而应由证书能覆盖多大半径决定。**

**灵感 5（零空间 → 安全可塑性）**
直觉：一个参数更新对任务性能可能有益，却可能悄悄吃掉摩擦裕度。对 WBC-Q 的 KKT 条件做隐函数微分，可以得到安全约束对参数的敏感度 `A_h`；把学习梯度投影到 `ker(A_h)`，就能在一阶意义上**不降低任何活跃约束的裕度**。而那些确实要改约束敏感方向的更新，不能丢，只能进「临时区」——只做前馈补偿、不参与安全判定，等证书复核通过后再固化。

**灵感 6（合流 → SOMA 的分层结构）**
SOMA 在 VISTA/RAS 的时序骨架上换装为：
1. **WBC-Q**：可微的分层全身控制 QP，输出 `ξ*=(q̈,τ,f_c)` 及其对模型参数的敏感度；
2. **CAG Credit Assignment Gate**：用 RAS/VISTA 后验给每个模型分量分配可学习权重 `α_k`；
3. **NSP Null-Space Safety Projector**：把学习方向投影到活跃安全约束的零空间；
4. **MCR Mode-Conditional Replay**：按接触/负载模式分层的 Fisher 与回放，约束遗忘；
5. **CCR Certified Consolidation Regulator**：双时间尺度（provisional / consolidated）+ 鲁棒管 + 回滚；
6. **DES Dual Excitation Scheduler**：在认证集内选择信息增益最大的激励动作；
7. **J-SOMA**：把学习增量、信赖半径、模式覆盖、遗忘界写入证书。

## 1. 形式化定义（增量：定义 245–259）

- **定义 245（SOMA 总览）**：`SOMA = (WBC-Q, CAG, NSP, MCR, CCR, DES, J-SOMA)`。三层结构：语义流做归因、Fisher、证书；实时流只做 QP 求解、投影与回滚；证书层裁决「哪次更新可以进入实时控制器」。不变式：(i) 实时控制器只使用保守参数 `z_safe`，从不直接使用临时参数 `z_p`；(ii) 所有学习写操作只在语义流；(iii) 证书失效时下一周期回滚到上一个 `Valid(z_c)`；(iv) 用于更新安全约束的证据必须来自执行前缀内产生的 on-policy 数据。
- **定义 246（全身控制 QP，WBC-Q）**：设 `q∈ℝ^n`，任务 `{T_i}_{i=1..N}` 带优先级 `≻`，控制变量 `ξ=(q̈,τ,f_c)`。WBC-Q 解
  `ξ* = argmin_ξ Σ_i w_i ||J_i ξ − a_i*||² + λ_u||ξ||²`
  s.t. 浮基动力学 `M(q)q̈ + h(q,q̇) = Sᵀτ + J_cᵀ f_c`，接触约束 `J_c q̈ + J̇_c q̇ = a_c*`，摩擦锥 `f_c ∈ K_μ`，执行器限位 `τ∈[τ⁻,τ⁺]`，加速度可行集。将其视为参数化映射 `Π_θ: (q,q̇,任务) ↦ ξ*`，`θ∈Θ` 为模型参数（惯性、质心、摩擦、执行器延迟）。
- **定义 247（残差字典与在线学习变量）**：真实模型 `θ = θ₀ + Δθ`。在线学习不直接改 `θ`，而是在低维残差字典 `B∈ℝ^{d×r}`（`r≪d`，基为「质心偏移 / 负载 / 接触摩擦 / 执行器延迟」等物理残差模态）上更新 `z∈ℝ^r`：`Δθ = Bz`。因此「在线学习」被压缩为 `r` 维的在线辨识。
- **定义 248（可微 WBC 敏感度）**：对 WBC-Q 的 KKT 系统做隐函数微分，得到解对学习变量的敏感度
  `S_z = ∂ξ*/∂z = −K⁻¹ ∂F/∂z`，其中 `K` 为 KKT 矩阵，`F` 为 KKT 残差。
  对安全函数 `h(ξ*(z))` 有 `A_h = ∂h/∂z = (∂h/∂ξ) S_z`。只在当前活跃约束集上计算；`K` 的分解可在语义流缓存复用。
- **定义 249（安全函数与认证集）**：`h(z)=[h_1,…,h_m] ≥ 0` 汇合 ZMP/CoP 支撑、摩擦裕度、力矩限位、关节限位。认证参数集
  `Z_cert(ρ) = { z : ||z−z_c||_{Σ⁻¹} ≤ ρ, 且 ∀s≤k, h(z; mode_s) ≥ ε_h }`，
  其中 `ρ` 为信赖半径，`k` 为认证时域，`mode_s` 为第 `s` 步预测接触模式。
- **定义 250（零空间安全投影，NSP）**：给定数据梯度 `g_t`，令 `P = A_h⁺A_h` 为活跃安全约束行空间投影，
  `d_safe = (I − P) g_t + P g_t⁺`，
  其中 `g_t⁺` 为在行空间内**提升裕度**的分量（`A_h g_t⁺ ≥ 0`）。一阶保证 `A_h d_safe ≥ 0`，即活跃约束不退化。
- **定义 251（归因信用分配，CAG）**：由 RAS 联合后验 `P(H,E|ρ,face)`（无面部通道时退化为 VISTA 的 `P(H|ρ)`）计算分量权重
  `α_k ∝ P(H=H_k|obs)·(1−P(H=H₀|obs))`，归一化后 `Σ_k α_k = 1`。
  学习目标 `L(z)=Σ_k α_k L_k(z) + λ_c||z−z_c||²`；`α_k` 同时门控学习率与 Fisher 累积。直觉：只学被归因为坏掉的分量。
- **定义 252（模式条件 Fisher 与覆盖）**：接触/负载模式 `m∈M`（双支撑、单支撑、飞行、不同负载区间）。`F = Σ_m p(m) F_m`，`F_m = E_{data_m}[∇_z log p(y|z,m) ∇_z log p(y|z,m)ᵀ]`。模式覆盖率 `c_m = N_m/Σ N`。低覆盖模式的 `F_m` 只增不减，防止非平稳数据流把旧模式冲掉。
- **定义 253（SOMA 在线更新律）**：
  `z_{t+1} = Π_{Z_cert(ρ)}( z_t − η_t (I − A_h⁺A_h)( ∇L(z_t) + λ_f F(z_t − z*) ) )`
  `Π` 为联合投影：先投影到参数椭球，再对活跃约束做半空间回退（交替投影，收敛到 `Z_cert` 的交）。
- **定义 254（认证前缀与鲁棒管）**：对候选更新 `δz`，要求存在鲁棒管：`∀z'∈B_ρ(z+δz), ∀s≤k: min_{mode∈M_s} h(z';mode) ≥ ε_h`。令
  `k_SOMA = max{ k : 上式成立且 k ≤ k_RAS }`。
  实时执行使用 `z_safe = z_c + δz − ρ·u_worst`（`u_worst` 为鲁棒管最坏方向），而非点估计 `z_c+δz`。
- **定义 255（双时间尺度 provisional / consolidated）**：`z = z_c + z_p`。`z_c`（已固化）受证书保护并参与安全约束；`z_p`（临时）只做前馈补偿与探索，绝不进入安全判定。`z_p` 连续 `T_cert` 个周期通过证书后并入 `z_c`，否则回滚并上调 `ρ`。
- **定义 256（对偶激励，DES）**：当 `α_k` 高且 `F` 在对应方向的 `λ_min` 低于阈值时，选择激励
  `u_ex = argmax_u log det(F(z) + I(δz;y|u)) − β·risk(u)` s.t. `z+δz(u)∈Z_cert(ρ), u∈U_safe`。
  这就是「身体作为实验设计器」：用受证的小幅运动把不可辨识参数变成可辨识的。
- **定义 257（遗忘界）**：对旧模式 `m`，更新后的性能下降
  `ΔJ_m ≤ (1/(2λ_f λ_min(F_m))) ||δz||²_{Σ} + O(||δz||³)`。
  因此若 `||δz|| ≤ sqrt(2λ_f λ_min(F_m) ε_J)`，则 `ΔJ_m ≤ ε_J`。
- **定义 258（J-SOMA 证书）**：`J_SOMA = (J_RAS, z_c, ρ, {c_m}, k_SOMA, λ_min(F), ΔJ_bound, sim_version)`。
  `Valid ⇔ Valid(J_RAS) ∧ ρ>0 ∧ min_m c_m ≥ c_min ∧ k_SOMA ≥ 1 ∧ ΔJ_bound ≤ ε_J`。
- **定义 259（闭合不变式）**：任一执行周期满足：(i) 实时控制器只用 `z_safe`；(ii) 学习写操作只在语义流；(iii) 证书失效立刻回滚；(iv) 不得用未认证的离线数据去「改进」安全约束——安全约束的更新与性能参数的更新必须走不同的证据通道。

## 2. 关键算法骨架

```python
class SOMA:
    def __init__(self, wbc_q, cag, nsp, mcr, ccr, des):
        self.wbc, self.cag, self.nsp = wbc_q, cag, nsp
        self.mcr, self.ccr, self.des = mcr, ccr, des
        self.z_c = np.zeros(R)      # consolidated
        self.z_p = np.zeros(R)      # provisional
        self.rho = 0.05

    def tick(self, q, qd, task, mode):
        # 实时流：不学习、不写入，只用保守参数
        z_safe = self.ccr.safe_point(self.z_c, self.rho)
        xi = self.wbc.solve(q, qd, task, z_safe)
        return xi

    def learn(self, batch, obs):
        # 语义流
        post = self.ras.posterior(obs)                 # 故障归因
        alpha = self.cag.weights(post)                 # 学哪里
        g = self.grad(batch, self.z_c + self.z_p, alpha)   # 数据梯度
        g = self.nsp.project(g, self.z_c)              # 一阶安全投影
        g = g + self.mcr.ewc_grad(self.z_c)            # 模式条件回放
        z_new = self.z_c - self.eta * g
        if self.ccr.verify(z_new, self.rho, self.k):
            self.z_c = self.ccr.consolidate(z_new)
            self.z_p *= 0.5                            # 临时量衰减
        else:
            self.rho = max(self.rho * 0.5, self.rho_min)
            self.z_p = self.ccr.push_provisional(z_new)
        if self.des.needed(self.z_c, alpha):
            self.queue_excitation(self.des.choose(self.z_c))
```

闭环每一轮只做三件事：**归因 → 投影 → 认证**。归因决定方向，投影保证一阶可行，认证决定这次更新是否允许被身体执行。

## 3. 推导

**引理 11（NSP 的一阶可行性）** 设活跃约束集 `A` 与 `A_h` 在更新邻域内不变，`d_safe=(I−P)g+Pg⁺`。则对任意 `η>0`，
`h(z+η d_safe) = h(z) + η A_h d_safe + O(η²||d_safe||²) ≥ h(z) + O(η²)`。
即一阶上不降低任何活跃约束的裕度；非活跃约束由连续性在小 `η` 下保持正裕度。
*证明*：`(I−P)` 的像落在 `ker(A_h)`，`Pg⁺` 满足 `A_h Pg⁺ = A_h g⁺ ≥ 0`，故 `A_h d_safe ≥ 0`，代入一阶展开即得。

**引理 12（模式条件 Fisher 的遗忘界）** 在二次近似下，对旧模式 `m` 的期望性能下降满足定义 257 的界。若回放覆盖 `c_m ≥ c_min`，则 `λ_min(F_m) ≥ c_min λ_min(F_m^{local}) > 0`，遗忘界不随总数据量无限增大。
*证明*：对 `J_m(z)` 在 `z*_m` 处展开并代入带 EWC 正则的更新，标准二次型放缩即得。

**引理 13（信用分配降低错分量梯度方差）** 设真实故障分量为 `k*`，后验权重 `α`。则施加在错分量 `k≠k*` 上的有效学习率为 `ηα_k`。若后验校准且 `α_{k*} ≥ 1−ε`，则错分量累计更新的方差降为原来的 `O(ε²)`，而正确分量的有效更新量保持不变。故在同样的遗忘预算下，CAG 允许更大的 `||δz||` 落在正确分量上。

**定理 11（SOMA 端到端安全性）** 在 A1（`A_h` 在活跃集上精确）、A2（CCR 的鲁棒管覆盖参数不确定性）、A3（`z_safe` 保守）、A4（失效即回滚）下，对任意执行时刻 `t`：
1. `h(q_t) ≥ ε_h − O(ρ²)`，即认证安全约束不被在线学习破坏；
2. 若 `k_SOMA=0`，控制器退化为「只执行、不学习」，安全性与 VISTA/RAS 相同；
3. 学习带来的参数变化只在 `Valid(J_SOMA)` 为真时生效。
*证明*：对执行周期做归纳。基例：初始 `Valid(J_SOMA)`。归纳步：若更新被接受，定义 254 保证鲁棒管内所有参数满足安全约束；实时使用管内的 `z_safe`，故约束成立。若被拒绝，`z_c` 不变且 `z_p` 不进入安全判定，约束由上一周期保持；失效时回滚恢复上一 `Valid` 状态。∎

**定理 12（可塑性-遗忘 Pareto）** 在引理 11–13 与 A1–A4 下，给定遗忘预算 `ε_J`，允许的更新范数满足
`||δz||² ≤ 2λ_f ε_J / λ_min(F_{k*})`（集中到真实故障分量时）；
而均匀更新需对全部分量满足同一界，故
`||δz_uniform||² / ||δz_CAG||² ≤ λ_min(F_{k*}) / max_{k≠k*} λ_min(F_k) ≤ 1`。
因此 CAG 把同样的遗忘预算换成了更大的有效适应步长：**归因越准，能安全学到的越多**。

**推论 12.1（向后兼容）** 当 `α≡0` 或 `k_SOMA=0` 时，SOMA 不含任何参数更新，退化为 VISTA/RAS 的证书闭环。因此 SOMA 是 VISTA/RAS 的严格保守扩展，而非替换。

| E258 对抗噪声/投毒 | 学习数据被污染时证书是否守住 | 回滚触发率 100%，安全违规 = 0 |
| E259 实时性 | 敏感度与认证是否拖垮 1 kHz 环路 | 实时路径 < 2 ms |
| E260 sim-to-real | 迁移后在线适应与遗忘 | 30 min 连续运行，`ΔJ_bound` 不超预算 |

**初步合成结果（40 seeds，非完整 WBC 基准）**：

1. **安全在线质量自适应**（1-D CoM + 足力抽象，100 Hz，8 s，负载 1.0→2.2→1.0→2.2 kg）：naive 点估计平均有 74.2/800 步跌破 3 cm 高度阈值，最大跌落 5.1 cm；SOMA 证书包络为 0 步违规、从不跌落，但保守过推使高度上冲 9.6 cm、RMS 由 1.8 cm 升至 4.7 cm。结论：SOMA 把不安全的「跌落」换成了安全的「过推」——这正是设计目标。
2. **顺序接触模式残差学习**（4 模式 × 250 步，40 seeds）：朴素 SGD 旧模式 MSE 3.87、新模式 0.003（严重遗忘）；EWC(λ=8) 旧模式 1.34、新模式 2.07（学不动新模式）；SOMA（模式条件回放 0.7）旧模式 1.59、新模式 1.22。SOMA 在「旧模式遗忘」与「新模式适应」之间取得更低的总代价（1.59+1.22=2.81 vs 3.41 vs 3.87）。

## 6. 本轮最大风险

**一句话**：SOMA 的全部安全保证都建立在「安全函数 `h` 与可微 QP 敏感度 `A_h` 正确」之上，而全身控制的接触模式切换会让活跃约束集在一个更新间隔内跳变；一旦活跃集误判或接触模型本身错误，NSP 就会把更新投影进**错误的零空间**，认证器反而对真实约束视而不见——这是「在错误的安全模型里安全地学习」的根本风险。

**次级风险与缓解**：
1. **活跃集非光滑**：可微 QP 在活跃集边界不可导 → 用平滑 max/多面体鲁棒化 + 多活跃集束（active-set bundle）验证；
2. **认证过保守导致学习停滞**：`ρ→0`、`k_SOMA→0` → 用 DES 主动激励换取信息，并对不同分量设分层 `ρ`；
3. **非平稳流的 Fisher 过时**：用滑动窗口 + 变化检测重置 `F_m`，但保留旧模式的「只增不减」下界；
4. **归因错误导致学错分量**：后验温度缩放 + 低置信拒识（`α` 熵高时不更新）；
5. **实时算力**：敏感度只在语义流、低维 `r`、缓存 KKT 分解；实时路径只做查表与投影。

## 2. 形式化定义（完整版，245–259）

**定义 245（SOMA 总览）**
```
SOMA = (WBC-Q, CAG, NSP, MCR, CCR, DES, J-SOMA)
```
三层：语义流（归因 / Fisher / 证书）、实时流（QP / 投影 / 回滚）、证书层。不变式：(i) 实时控制器只用保守参数 `z_safe`；(ii) 学习写操作只在语义流；(iii) 证书失效下一周期回滚到上一 `Valid(z_c)`；(iv) 安全约束的证据必须来自执行前缀内的 on-policy 数据，不得用未认证离线数据「改写」安全边界。

**定义 246（全身控制 QP）** 控制变量 `ξ=(q̈,τ,f_c)`：
```
ξ* = argmin_ξ Σ_i w_i ||J_i ξ − a_i*||² + λ_u||ξ||²
s.t.  M(q)q̈ + h(q,q̇) = Sᵀτ + J_cᵀ f_c
      J_c q̈ + J̇_c q̇ = a_c*
      f_c ∈ K_μ,  τ∈[τ⁻,τ⁺]
```
参数化映射 `Π_θ:(q,q̇,任务)↦ξ*`。高层任务（平衡、CoM）优先于低层任务（末端、姿态），这是「控制优先级」；SOMA 把它镜像为「学习优先级」。

**定义 247（残差字典与在线学习变量）** `θ=θ₀+Bz`，`B∈ℝ^{d×r}`，`r≪d`。基向量取物理模态：质心偏移、负载质量、接触摩擦、执行器延迟、关节柔顺。在线学习只更新 `z`。

**定义 248（可微 WBC 敏感度）** 令 KKT 残差 `F(ξ,z)=0`，则
```
S_z = ∂ξ*/∂z = −K⁻¹ (∂F/∂z),   K = ∂F/∂ξ
A_h = (∂h/∂ξ) S_z
```
只在活跃约束集上计算；`K` 的分解可缓存、跨周期复用。

**定义 249（安全函数与认证集）**
```
h(z) = [h_zmp, h_friction, h_torque, h_joint] ≥ 0
Z_cert(ρ) = { z : ||z−z_c||_{Σ⁻¹} ≤ ρ  ∧  ∀s≤k, h(z;mode_s) ≥ ε_h }
```

**定义 250（零空间安全投影 NSP）** `P = A_h⁺A_h`，
```
d_safe = (I − P) g_t + P g_t⁺,   A_h g_t⁺ ≥ 0
```
一阶上 `A_h d_safe ≥ 0`：活跃约束不退化，且能提升的方向仍被利用。

**定义 251（归因信用分配 CAG）**
```
α_k ∝ P(H=H_k | obs) · (1 − P(H=H₀ | obs))
L(z) = Σ_k α_k L_k(z) + λ_c ||z−z_c||²
```
`α_k` 同时门控学习率与 Fisher 累积。含面部通道时用 RAS 的 `P(H,E|ρ,face)`，否则退化为 VISTA 的 `P(H|ρ)`。

**定义 252（模式条件 Fisher）**
```
F = Σ_m p(m) F_m,   F_m = E_{data_m}[∇_z log p(y|z,m) ∇_z log p(y|z,m)ᵀ]
c_m = N_m / Σ_m N_m
```
`F_m` 对低覆盖模式只增不减，形成「模式记忆下界」。

**定义 253（SOMA 更新律）**
```
z_{t+1} = Π_{Z_cert(ρ)}( z_t − η_t (I − A_h⁺A_h)( ∇L(z_t) + λ_f F(z_t − z*) ) )
```
`Π` 为椭球投影与半空间回退的交替投影。

**定义 254（认证前缀与鲁棒管）**
```
k_SOMA = max{ k : ∀z'∈B_ρ(z+δz), ∀s≤k, min_{mode∈M_s} h(z';mode) ≥ ε_h  ∧  k ≤ k_RAS }
z_safe = z_c + δz − ρ·u_worst
```

**定义 255（双时间尺度）** `z = z_c + z_p`。`z_c` 参与安全约束，`z_p` 只做前馈/探索；`z_p` 连续 `T_cert` 周期过证后并入 `z_c`，否则回滚并 `ρ←ρ/2`（下限 `ρ_min`）。

**定义 256（对偶激励 DES）**
```
u_ex = argmax_u log det(F(z) + I(δz;y|u)) − β·risk(u)
s.t.  z+δz(u) ∈ Z_cert(ρ),  u ∈ U_safe
```

**定义 257（遗忘界）**
```
ΔJ_m ≤ (1/(2 λ_f λ_min(F_m))) ||δz||²_{Σ} + O(||δz||³)
```
故 `||δz|| ≤ sqrt(2 λ_f λ_min(F_m) ε_J) ⇒ ΔJ_m ≤ ε_J`。

**定义 258（J-SOMA 证书）**
```
J_SOMA = (J_RAS, z_c, ρ, {c_m}, k_SOMA, λ_min(F), ΔJ_bound, sim_version)
Valid ⇔ Valid(J_RAS) ∧ ρ>0 ∧ min_m c_m ≥ c_min ∧ k_SOMA ≥ 1 ∧ ΔJ_bound ≤ ε_J
```

**定义 259（闭合不变式）** 任一执行周期：(i) 实时只用 `z_safe`；(ii) 学习只在语义流；(iii) 失效即回滚；(iv) 安全约束与性能参数走不同证据通道。

# IP-234 可微全身控制 QP
class DifferentiableWBC:
    def solve(self, q, qd, task, z):
        theta = self.theta0 + self.B @ z
        # hierarchical QP: balance > contact > end-effector > posture
        xi, K, active = self.qp_solve(q, qd, task, theta)
        return xi, K, active

    def sensitivity(self, q, qd, task, z, active, h):
        # implicit differentiation of the KKT system on active set
        dFdz = self.kkt_residual_jac_z(q, qd, task, z, active)
        S_z = -np.linalg.solve(self.K_cache, dFdz)
        A_h = self.dh_dxi(active) @ S_z          # ∂h/∂z
        return S_z, A_h


# IP-235 零空间安全投影
class NullSpaceSafetyProjector:
    def project(self, g, A_h):
        P = A_h.T @ np.linalg.pinv(A_h @ A_h.T) @ A_h
        g_null = (np.eye(len(g)) - P) @ g
        g_up = P @ g
        g_up = np.where(A_h @ g_up >= 0, g_up, 0.0)   # keep only margin-improving
        return g_null + g_up


# IP-236 归因信用分配
class CreditAssignmentGate:
    def weights(self, posterior, temp=1.0):
        p = softmax(posterior / temp)
        p0 = p.get('H0', 0.0)
        alpha = {k: v * (1.0 - p0) for k, v in p.items() if k != 'H0'}
        s = sum(alpha.values()) or 1.0
        return {k: v / s for k, v in alpha.items()}


# IP-237 模式条件回放 / Fisher
class ModeConditionalReplay:
    def ewc_grad(self, z, z_star):
        return self.lam_f * (self.F @ (z - z_star))

    def update_fisher(self, mode, grad_logp):
        Fm = np.outer(grad_logp, grad_logp)
        self.F_m[mode] = self.beta * self.F_m.get(mode, 0) + Fm
        self.F = sum(self.p[m] * self.F_m[m] for m in self.F_m)

    def replay(self, batch_by_mode, k=4):
        out = []
        for m, (X, Y) in batch_by_mode.items():
            idx = np.random.choice(len(X), min(k, len(X)), replace=False)
            out.append((X[idx], Y[idx], m))
        return out


# IP-238 证书化整合调节器
class CertifiedConsolidationRegulator:
    def verify(self, z_new, rho, k):
        z_worst = self.worst_case_ball(z_new, rho)
        for s in range(k):
            mode = self.mode_predictor(s)
            if self.h(z_worst, mode) < self.eps_h:
                return False
        return True

    def safe_point(self, z_c, rho):
        return z_c - rho * self.worst_direction(z_c)   # conservative, never z_p

    def consolidate(self, z_new):
        return z_new

    def push_provisional(self, z_new):
        return z_new - self.z_c                     # only feed-forward


# IP-239 对偶激励
class DualExcitationScheduler:
    def needed(self, z, alpha):
        return min(self.eigvals(self.F, alpha)) < self.f_min

    def choose(self, z):
        cands = self.safe_motions(z)                # u in U_safe
        return max(cands, key=lambda u: self.info_gain(z, u)
                   - self.beta * self.risk(z, u))


# IP-241/243 闭环
def SOMA_round(M, obs, q, qd, task, mode):
    # --- real-time path (no learning writes) ---
    z_safe = M.ccr.safe_point(M.z_c, M.rho)
    xi, K, active = M.wbc.solve(q, qd, task, z_safe)
    M.wbc.cache(K, active)

    # --- semantic path ---
    post = M.ras.posterior(obs)
    alpha = M.cag.weights(post)
    g = M.grad(obs, M.z_c + M.z_p, alpha)
    S_z, A_h = M.wbc.sensitivity(q, qd, task, M.z_c + M.z_p, active, M.h)
    g = M.nsp.project(g, A_h)
    g = g + M.mcr.ewc_grad(M.z_c, M.z_star)
    z_new = M.z_c - M.eta * g

    if M.ccr.verify(z_new, M.rho, M.k):
        M.z_c = M.ccr.consolidate(z_new)
        M.z_p *= 0.5
        M.j_soma = M.cert.build(M.z_c, M.rho, M.mcr.coverage,
                                M.cert.prefix(M.z_c, M.rho))
    else:
        M.rho = max(M.rho * 0.5, M.rho_min)
        M.z_p = M.ccr.push_provisional(z_new)
        M.rollback_if_invalid()

    if M.des.needed(M.z_c, alpha):
        M.queue_excitation(M.des.choose(M.z_c))

    return xi, M.j_soma

## 4. 推导

**引理 11（NSP 一阶可行性）** 在活跃集不变的前提下，`h(z+ηd_safe) ≥ h(z) + O(η²||d_safe||²)`。见想法区证明。

**引理 12（模式条件 Fisher 遗忘界）** `ΔJ_m ≤ ||δz||²_Σ / (2 λ_f λ_min(F_m)) + O(||δz||³)`；覆盖 `c_m≥c_min` 给出与总数据量无关的正下界。

**引理 13（CAG 降低错分量更新方差）** 校准后验下，错分量累计更新方差为 `O(ε²)`，正确分量有效步长不变。

**定理 11（端到端安全性）** 在 A1–A4 下，`∀t: h(q_t) ≥ ε_h − O(ρ²)`；`k_SOMA=0` 时退化为 VISTA/RAS 的只执行模式；参数变化只在 `Valid(J_SOMA)` 时生效。归纳证明见想法区。

**定理 12（可塑性-遗忘 Pareto）** 给定遗忘预算 `ε_J`，CAG 允许的更新范数满足
```
||δz_CAG||² / ||δz_uniform||² ≥ max_{k≠k*} λ_min(F_k) / λ_min(F_{k*})
```
即归因越准，同样的遗忘预算能换取越大的有效适应步长。

**推论 12.1（向后兼容）** `α≡0 ∨ k_SOMA=0 ⇒ SOMA ≡ VISTA/RAS` 证书闭环，SOMA 是严格保守扩展。

解释：SOMA 用非对称证书包络（向上误差立即吸收、向下误差需复核）把「跌落」这一不安全失效，转化为「过推」这一可被反馈调节的安全低效。

**E254 顺序接触模式残差学习（4 模式 × 250 步，40 seeds）**

| 方法 | 旧模式 MSE（遗忘） | 新模式 MSE（适应） | 合计 |
|---|---|---|---|
| 朴素 SGD | 3.868 | 0.003 | 3.871 |
| EWC (λ=8) | **1.339** | 2.070 | 3.409 |
| SOMA（模式回放 0.7） | 1.585 | 1.218 | **2.803** |

解释：朴素 SGD 完全遗忘旧模式；EWC 守住旧模式却学不动新模式；SOMA 的模式条件回放给出更优的折中点。该结果只验证机制方向，不代表完整 WBC 基准。

## 7. 本轮最大风险

**一句话**：SOMA 的全部安全保证都建立在「安全函数 `h` 与可微 QP 敏感度 `A_h` 正确」之上，而全身控制的接触模式切换会让活跃约束集在一个更新间隔内跳变；一旦活跃集误判或接触模型本身错误，NSP 就会把更新投影进**错误的零空间**，认证器反而对真实约束视而不见——这是「在错误的安全模型里安全地学习」的根本风险。

**次级风险与缓解**：
1. **活跃集非光滑** → 平滑 max / 多面体鲁棒化 + active-set bundle 验证；
2. **认证过保守**（`ρ→0`）→ DES 主动激励 + 分层 `ρ`；
3. **Fisher 过时** → 滑窗 + 变化检测，但保留旧模式下界；
4. **归因错误** → 后验温度 + 低置信拒识；
5. **实时算力** → 敏感度只在语义流，`r` 维、缓存 KKT 分解。
