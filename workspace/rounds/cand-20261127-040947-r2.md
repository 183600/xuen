# 第 2 轮 · 想法区（灵感词：语义建图 / 差异化定位）

## 0. 直觉先行：两个词其实是同一件事的两面

- **语义建图**不是"画一张更漂亮的地图"，而是把地图从"点云/栅格"升级为**带语义标签与不确定性的对象账本**：每个门、柱子、货架、消防栓都是带 ID、类别、位姿误差半径、稳定等级的可复用锚点。
- **差异化定位**我先按字面读成两层：
  1. **差分定位（differential localization）**——像差分 GPS / 相对定位那样，把两个观测**相减**，让共模误差（时钟偏差、星历偏差、地图全局漂移、标定尺度误差）在减法里自然抵消；
  2. **差异化（differentiated）锚点角色**——不是所有地标都配当"锚"：建筑结构（S 级）可做全局基准，家具/货架（Q 级）只做局部约束，行人/车辆（D 级）根本不配做锚。

这两个词一旦合起来，逻辑非常顺：**语义对象提供了"可复用的对应关系"，差分运算提供了"共模误差消除器"**。语义建图负责"找对同一个东西"，差异化定位负责"用同一个东西把误差减掉"。

## 1. 一个具体场景

仓库机器人 A 与 B 同时作业。两者的 GNSS/时钟/地图帧都带一个**共同的**缓慢漂移 b（例如同一批卫星、同一张云端地图、同一套标定）。单独看，A、B 的绝对定位误差都可能到 30cm，谁都不敢贴着货架走。但只要它们同时看到同一个语义锚点（同一根编号柱），把两边的观测相减，b 就被抵消，**相对位姿误差可能只有 3cm**——于是"A 贴着 B 走 / A 从 B 身边过"这类高风险动作反而更安全。

关键洞察：**绝对精度差，不代表相对精度差；安全往往只依赖相对量。** 而"安全只依赖相对量"这件事，恰好可以被证书化。

## 2. 从直觉到严谨定义（简版，完整版在产物区）

- 语义地标 `o = (oid, c, μ, ε_o, h, tier, τ)`：ID、类别、地图系位置、conformal 位置误差半径、语义描述子、稳定等级、最后观测时刻。
- 语义地图证书 `SMC(M_t)`：每个地标位置覆盖 ≥1-α、类别后验合格、且满足**语义互斥**（互斥类别不能占据同一栅格）。
- 共模有效谓词 `CM(a,b)`：同一星座/时钟源、时间戳差 ≤Δt_max、同一地图版本、同一标定版本——**只有共模假设成立，差分才真的抵消偏差**。
- 差分约束 `δ_ab = { z_{a→i} − z_{b→i} }_{i∈I_ab}`，解出 `T_ab`，带 conformal 相对误差界 `ε_ab`。
- 锚点图 `G=(V,E)`：节点是智能体/时刻，边是差分约束；全局误差由**生成树上的边误差之和 + 锚点误差**界定。
- 回环残差 `r(cycle)`：绕一圈复合回来与单位变换的偏差，用来抓"语义混叠/错误关联"。
- 差分定位谓词 `DiffLoc(π)`：存在连通锚点子图，只用 S/Q 级锚、所有边共模有效、回环残差 ≤τ_res、全局界 ≤预算。

## 3. 本轮真正想验证的三个猜想

- **猜想 A（共模不变性）**：若偏差 b 对 A、B 完全相同，则差分估计的误差分布**与 b 无关**。→ 这给了"绝对定位很差但相对定位可信"的证书基础。
- **猜想 B（要么被抓、要么无害）**：一次错误的语义关联若对应真实位移 δ，则回环残差 ≥ δ − ε_noise；所以 **δ 大就被残差检验抓住，δ 小则即使漏检，造成的全局误差也被 δ 界住**。这条命题把"感知混叠"从"灾难"降级为"可界定的误差"——**前提是回环里至少有一个未被混叠的锚点**。
- **猜想 C（语义互斥压制假自由）**：若某栅格被宣称"空"，而其中确实有物体，则该物体必须被所有模态同时漏检；在 m 个近独立模态下，假自由概率 ≤ α^m。→ 这正好接上上一轮的 CAC 缺席证书与 CFC+++ 多模态仲裁。

## 4. 设计跃迁（相对 v23）

- **IP-440 语义地图证书 SMC**：对象级地标 + conformal 位置/类别证书 + 语义互斥一致性 + 版本挂到 CESC。
- **IP-441 差分定位证书 DLC**：共模有效性判定 + 差分相对位姿 + conformal 相对误差界。
- **IP-442 锚点图一致性证书 AGCC**：生成树全局界 + 回环残差 + 语义混叠检测。
- **IP-443 差异化锚点角色 DAR**：S/Q/D 三级角色分类与选择，决定哪些锚能进全局差分。
- **IP-444 HPC-E++ 统一门**：在 HPC-E+ 之上再叠 SMC/DLC/AGCC/DAR 四证，`Exec_v24 = Exec_v23 ∩ Fil_sm ∩ Fil_dl ∩ Fil_ag`。

## 5. 开放问题

1. 共模假设一旦被打破（例如 A 用 GPS、B 用 UWB），差分不但不抵消，还可能**放大**偏差——需要显式的"共模违约"检测，而不是默认成立。
2. 语义描述子的**感知混叠**（两条一模一样的走廊、镜面反射的假门、对抗贴纸）是本方案最脆弱处；回环残差只能抓"局部不一致"，抓不到"整体自洽的错"。
3. 语义互斥约束需要类别本体（ontology）支撑，类别越多、互斥表越难维护。
4. 生成树全局界会随节点数线性膨胀，长时任务下 `ε_global` 可能迅速超预算——需要周期性绝对锚定或地图重锚。

## 6. 本轮最大风险（一句话）

**当环境在语义与几何上都高度自相似（或遭对抗性语义伪造）时，错误的数据关联会同时骗过语义建图证书与差分定位证书，使"要么被抓、要么无害"的界失效，系统以极高置信度给出错误定位。**

```python
# ============================================================
# IP-440 Semantic Map Certificate (SMC) — 语义地图证书
# ============================================================
@dataclass
class SemanticLandmark:
    oid: str
    cls: str
    mu: np.ndarray            # 地图系位置 (3,)
    eps_pos: float            # conformal 位置误差半径
    desc_hash: bytes          # 语义描述子（用于回环/对应）
    tier: str                 # 'S' | 'Q' | 'D'
    last_seen: float
    map_version: int

class SemanticMapCertificate:
    def __init__(self, alpha: float = 0.01, eps_max: float = 0.15):
        self.alpha = alpha
        self.eps_max = eps_max
        self.O: dict[str, SemanticLandmark] = {}
        self.X: set[tuple[str, str]] = set()   # 互斥类别对
        self.V_M: int = 0
        self.D_calib: list[float] = []         # 位置残差校准集

    def add_landmark(self, o: SemanticLandmark) -> bool:
        if not self._exclusion_ok(o):
            return False
        self.O[o.oid] = o
        return True

    def _exclusion_ok(self, o_new: SemanticLandmark) -> bool:
        # 同格冲突：若同格已有互斥类别地标，拒绝写入
        for o in self.O.values():
            if _same_cell(o.mu, o_new.mu) and (o.cls, o_new.cls) in self.X:
                return False
        return True

    def calibrate(self, residuals: list[float]):
        self.D_calib.extend(residuals)
        if len(self.D_calib) > 5000:
            self.D_calib = self.D_calib[-5000:]

    def eps_quantile(self) -> float:
        # conformal (1-alpha) 分位数，附 Hoeffding 下界修正
        return np.quantile(self.D_calib, 1 - self.alpha)

    def certify(self) -> bool:
        if not self.O:
            return False
        eps_q = self.eps_quantile()
        for o in self.O.values():
            if o.eps_pos > min(eps_q, self.eps_max):
                return False
            if o.tier == 'D' and o.eps_pos > self.eps_max * 0.5:
                return False
            if not self._class_certified(o):
                return False
        return self._global_exclusion_ok()

    def _class_certified(self, o) -> bool:
        return o.cls != "unknown"   # 类别后验已由 DCSC 覆盖约束保证

    def _global_exclusion_ok(self) -> bool:
        cells = defaultdict(list)
        for o in self.O.values():
            cells[_cell_key(o.mu)].append(o.cls)
        for clss in cells.values():
            for i in range(len(clss)):
                for j in range(i + 1, len(clss)):
                    if (clss[i], clss[j]) in self.X:
                        return False
        return True

    def version(self) -> int:
        return self.V_M

# IP-441 Differential Localization Certificate (DLC) — 差分定位证书
# ============================================================
class DifferentialLocalizationCertificate:
    def __init__(self, alpha: float = 0.01, dt_max: float = 0.02,
                 n_min: int = 3, eps_max: float = 0.05):
        self.alpha = alpha
        self.dt_max = dt_max
        self.n_min = n_min
        self.eps_max = eps_max
        self.D_calib: list[float] = []

    def common_mode_valid(self, a: 'AgentState', b: 'AgentState') -> bool:
        return (
            a.constellation == b.constellation
            and abs(a.t - b.t) <= self.dt_max
            and a.v_map == b.v_map
            and a.v_calib == b.v_calib
        )

    def differential_pose(self, a: 'AgentState', b: 'AgentState',
                          shared: dict[str, tuple[np.ndarray, np.ndarray]]
                          ) -> tuple[np.ndarray, int]:
        # shared[i] = (z_a_i, z_b_i)；共模偏差在相减中抵消
        deltas = []
        for oid, (za, zb) in shared.items():
            deltas.append(_pose_delta(za, zb))
        if len(deltas) < self.n_min:
            return None, len(deltas)
        T_ab = _robust_se3_average(deltas)   # 中位数/IRLS，抗离群
        return T_ab, len(deltas)

    def calibrate(self, residuals: list[float]):
        self.D_calib.extend(residuals)
        if len(self.D_calib) > 5000:
            self.D_calib = self.D_calib[-5000:]

    def eps_bound(self) -> float:
        if len(self.D_calib) < 30:
            return float("inf")
        return np.quantile(self.D_calib, 1 - self.alpha)

    def certify(self, a, b, shared) -> tuple[bool, float]:
        if not self.common_mode_valid(a, b):
            return False, float("inf")       # 共模违约：拒绝，绝不放大偏差
        T_ab, n = self.differential_pose(a, b, shared)
        if T_ab is None:
            return False, float("inf")
        eps = self.eps_bound()
        ok = (n >= self.n_min) and (eps <= self.eps_max)
        return ok, eps

# IP-442 Anchor Graph Consistency Certificate (AGCC) — 锚点图一致性
# ============================================================
class AnchorGraphConsistencyCertificate:
    def __init__(self, tau_res: float = 0.10, eps_budget: float = 0.20):
        self.tau_res = tau_res
        self.eps_budget = eps_budget

    def build(self, nodes, edges):
        # edges: list[(u, v, T_uv, eps_uv)]
        self.G = nx.Graph()
        self.G.add_nodes_from(nodes)
        for u, v, T_uv, eps in edges:
            self.G.add_edge(u, v, T=T_uv, eps=eps)

    def global_bound(self) -> tuple[float, float]:
        if not nx.is_connected(self.G):
            return float("inf"), float("inf")
        T = nx.minimum_spanning_tree(self.G, weight="eps")
        eps_anchor = self.G.nodes[next(iter(self.G))].get("eps_anchor", 0.0)
        eps_global = eps_anchor + sum(d["eps"] for _, _, d in T.edges(data=True))
        diam = nx.diameter(T, weight="eps")
        return eps_global, diam

    def loop_residual(self, cycle_nodes) -> float:
        prod = np.eye(4)
        for u, v in zip(cycle_nodes, cycle_nodes[1:] + cycle_nodes[:1]):
            T_uv = self.G[u][v]["T"] if self.G.has_edge(u, v) else self.G[v][u]["T"].inv()
            prod = prod @ T_uv
        return _se3_log_norm(prod)

    def certify(self) -> tuple[bool, dict]:
        if self.G is None or not nx.is_connected(self.G):
            return False, {"reason": "disconnected"}
        eps_global, diam = self.global_bound()
        worst = 0.0
        for cyc in nx.cycle_basis(self.G):
            worst = max(worst, self.loop_residual(cyc))
        ok = (worst <= self.tau_res) and (eps_global <= self.eps_budget)
        return ok, {"eps_global": eps_global, "diam": diam, "worst_residual": worst}

# IP-443 Differentiated Anchor Role (DAR) — 差异化锚点角色
# ============================================================
class DifferentiatedAnchorRole:
    TIER_WEIGHT = {"S": 1.0, "Q": 0.5, "D": 0.0}

    def classify(self, o: SemanticLandmark, dynamics: float) -> str:
        if o.cls in STRUCTURAL_CLASSES:          # 墙/柱/门框/固定设备
            return "S"
        if o.cls in DYNAMIC_CLASSES:             # 人/车/移动机器人
            return "D"
        if dynamics <= 0.02:                     # 准静态
            return "Q"
        return "D"

    def select_anchors(self, M: SemanticMapCertificate,
                       min_tier: str = "Q") -> list[SemanticLandmark]:
        allowed = {"S", "Q"} if min_tier == "Q" else {"S"}
        return [o for o in M.O.values() if o.tier in allowed]

    def has_global_anchor(self, M: SemanticMapCertificate) -> bool:
        # 至少 1 个 S 级锚点，才能把局部差分图钉到全局
        return any(o.tier == "S" for o in M.O.values())

    def certifiable(self, M: SemanticMapCertificate) -> bool:
        return self.has_global_anchor(M) and len(self.select_anchors(M)) >= 3

@dataclass
class HPCEDoublePlus:
    hpc_e_plus: 'HPCEPlus'
    smc: SemanticMapCertificate
    dlc: DifferentialLocalizationCertificate
    agcc: AnchorGraphConsistencyCertificate
    dar: DifferentiatedAnchorRole

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               a: 'AgentState', b: 'AgentState',
               shared_anchors: dict) -> bool:
        # 1. v23 物理接地四证
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2. 语义地图完整性
        if not self.smc.certify():
            return False
        # 3. 差异化锚点可用（至少一个 S 级 + ≥3 个可锚地标）
        if not self.dar.certifiable(self.smc):
            return False
        # 4. 差分定位（含共模有效性）
        dl_ok, _ = self.dlc.certify(a, b, shared_anchors)
        if not dl_ok:
            return False
        # 5. 锚点图一致性（全局界 + 回环残差）
        ag_ok, _ = self.agcc.certify()
        if not ag_ok:
            return False
        return True

            dlc=self.dlc, agcc=self.agcc, dar=self.dar,
        )

    def step(self, sensor_data: dict, cloud_update=None) -> tuple[bool, dict]:
        # 1) 语义建图：把检测结果写入对象级地图，按角色分级
        for det in sensor_data.get("detections", []):
            o = SemanticLandmark(
                oid=det.id, cls=det.cls,
                mu=det.map_position,
                eps_pos=det.conformal_radius,
                desc_hash=det.desc_hash,
                tier=self.dar.classify(det, det.dynamics),
                last_seen=sensor_data["t"],
                map_version=self.cesc.current_version().v_model,
            )
            self.smc.add_landmark(o)

        # 2) 差分定位：A/B 共视锚点 → 相对位姿 + conformal 界
        a, b = sensor_data["agent_a"], sensor_data["agent_b"]
        shared = self._shared_anchors(a, b, self.smc)
        dl_ok, eps_ab = self.dlc.certify(a, b, shared)

        # 3) 锚点图：边=差分约束，做全局界与回环检验
        self.agcc.build(self._nodes(a, b), self._edges(a, b, shared, eps_ab))
        ag_ok, ag_info = self.agcc.certify()

        # 4) 五证准入
        plan = self._plan_from_consensus(self.cfc.consensus_round())
        admitted = self.hpc_e_dp.admits(
            plan, sensor_data["x"], sensor_data["v"], sensor_data["z"],
            sensor_data["E_res"], sensor_data["margin_req"],
            self._modules_in_plan(plan), a, b, shared,
        )
        return admitted, {
            "plan": plan if admitted else None,
            "eps_ab": eps_ab,
            "anchor_graph": ag_info,
            "smc_ok": self.smc.certify(),
            "version": self.cesc.current_version(),
        }

    def _shared_anchors(self, a, b, smc):
        seen_a, seen_b = set(a.visible_ids), set(b.visible_ids)
        common = seen_a & seen_b
        return {oid: (a.obs[oid], b.obs[oid]) for oid in common
                if smc.O[oid].tier in ("S", "Q")}

    def _nodes(self, a, b):
        return [("A", a.t), ("B", b.t)]

    def _edges(self, a, b, shared, eps_ab):
        return [(("A", a.t), ("B", b.t), self.dlc.differential_pose(a, b, shared)[0], eps_ab)]
```

## 3. 正确性论证

### 引理 1（共模抵消：差分精度与绝对偏差无关）
**陈述**：设观测模型 `z_{a→i} = h(T_a, m_i) + b_a + η_{a,i}`。若 `CM(a,b)` 成立使 `b_a = b_b = b`，则
`δ_{ab,i} = z_{a→i} ⊖ z_{b→i} = h(T_a,m_i) ⊖ h(T_b,m_i) + (η_{a,i} ⊖ η_{b,i})`，
与 `b` 无关。因此差分估计 `T̂_ab` 的误差分布对任意 `|b|≤B_max` 不变，`ε_ab` 的 conformal 保证对全部 `b` 成立。

**证明**：直接在观测方程两侧相减，`b` 作为同加项被消去；`⊖` 对共同平移分量线性。噪声项仅剩差分噪声，故误差界不依赖 `B_max`。若 `CM` 不成立（`b_a≠b_b`），残差为 `b_a⊖b_b`，不会被抵消——因此 `CM` 是**必要前置条件**，DLC 在 `CM=false` 时直接拒证。∎

### 引理 2（锚点图全局误差界）
**陈述**：若 `G_t` 连通且含至少一个绝对锚点（误差 `ε_anchor`），边误差为 `ε_e`，则任两节点间位姿误差
`‖T̂_ij ⊖ T*_ij‖ ≤ ε_anchor + Σ_{e∈T_ij} ε_e`，
其中 `T_ij` 为连接 i,j 的生成树路径；取最小生成树可最小化该上界。

**证明**：沿生成树路径三角不等式逐边累加；绝对锚点提供初始误差预算。由于路径唯一，误差不随圈数放大，只随路径长度增长。∎

### 引理 3（感知混叠的"要么被抓、要么无害"）
**陈述**：设一次错误语义关联把真实位姿 `x` 关联到别名位姿 `x'`，`δ=‖x−x'‖`。若回环中**至少存在一个未被混叠的锚点**，则回环残差满足 `r(cycle) ≥ δ − ε_noise`。于是：
- 若 `δ > τ_res + ε_noise`，则 `r > τ_res`，被 AGCC 拒绝；
- 若 `δ ≤ τ_res + ε_noise`，即使漏检，造成的全局误差也被 `δ ≤ τ_res + ε_noise` 界住。

**证明**：未被混叠的锚点给出与真实 `x` 一致的约束；混叠锚点给出与 `x'` 一致的约束。绕环复合时两者不一致量至少为 `δ` 减去噪声项，故残差下界成立。两种情形分别对应"被检测"与"误差被界住"。∎

> 关键限定：若回环内**所有**锚点被整体一致地混叠（完美自相似环境 / 对抗伪造），则不存在未混叠锚点，引理 3 的前提失效——这是本方案的信息论边界。

### 引理 4（语义互斥压制假自由）
**陈述**：若 `Exclusion(M_t)` 成立且每个地标漏检概率 ≤ α，则某实际被物体占据的栅格被签为"空"的概率 ≤ α^m（m 个近独立模态同时漏检）。

**证明**：要签"空"，必须该栅格内所有互斥类别地标均未被任何模态检出；在近独立假设下概率相乘。语义互斥保证不会出现"两个互斥类同时被当作同一物体"的抵消错误。∎

### 引理 5（五证单调退化链）
**陈述**：`Exec_v24 ⊆ Exec_v23 ⊆ Exec_v22 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：
- 共模违约（`CM=false`）→ DLC 拒证 → 回退到 v23 的绝对定位证书；
- 无 S 级锚点 → DAR 失败 → 差分仅局部可用，`Exec_v24` 收缩为局部子集；
- 回环残差超阈 → AGCC 拒证 → 触发重定位/重锚，`Exec_v24` 收缩；
- 语义地图失效 → SMC 拒证 → 退回 v23；
- 组合失效取交集，单调性保持。∎

### 定理（HPC-E++ 语义-差分五证准入门）
**陈述**：对任意计划 π，`HPCEDoublePlus.admits(π)=True` ⟺ π 同时满足
(1) 物理接地安全（v23 四证），(2) 语义地图完整且互斥一致，(3) 差异化锚点可全局锚定，
(4) 差分定位在共模有效下相对误差 ≤ε_max，(5) 锚点图连通、回环残差 ≤τ_res、全局界 ≤ε_budget。

**证明**：由 `admits` 的五个连言与引理 1–5 直接得到。必要性：任一条件缺失即拒证，对应一类未被缓解的定位/建图风险。充分性：五条件全满足时，差分相对误差与全局界均有界，且单调退化链保证任何降级都不会扩大执行集。∎

## 4. 已知风险与缓解

| 编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R1 | 完美自相似环境/对抗语义伪造：全部锚点被整体一致混叠，引理 3 前提失效 | 最高 | 1) 强制至少一个异质模态锚点（LiDAR 几何 + 视觉语义 + 反光板）；2) 语义描述子加密码学 nonce/水印；3) 引入运动视差/IMU 死推作为独立约束 | 信息论上无法区分两个完全相同的环境，只能靠外部先验或主动探测 |
