### 第 1 轮灵感驱动研究记录（承接 KEMPC / v27）

**灵感词**：扩散策略（Diffusion Policy）、模型预测控制（MPC）

**直觉与动机**：
上一轮的 KEMPC 把常识作为软约束塞进 MPC 的代价函数，用 KC/DCC 证书兜底。它的软肋是「常识闭塞」：软约束是单峰的，优化器会把整个解空间压向同一个保守盆地，一旦真实环境出现常识库没覆盖的突发情形，机器人可能「越安全越无能」。

扩散策略提供了相反的偏置。它不求解单个最优动作，而是学习条件动作分布 p_θ(A | O)，通过 T 步去噪从噪声中采样出一族动作块；其多模态性天然能表达「左绕 / 右绕 / 停下 / 后退」这类离散意图，对多解任务不会塌缩到单峰。直觉上：**让扩散负责「想得多、想得野」，让 MPC 负责「做得稳、做得对」**。扩散给 MPC 提供多模态提议与热启动，MPC 给扩散的野提议做硬约束投影与证书；二者不是替代关系，而是「生成—投影」的双通道。

**关键洞见**：
把扩散策略当作 MPC 的「多模态提议分布 + 热启动生成器」，把 MPC 当作扩散策略的「可验证安全投影算子」。提出「扩散驱动证书 MPC」（Diffusion-Propelled Certified MPC, DP-CMP）：

- **生成侧**：条件扩散提议器采样 K 条候选动作块，覆盖多个意图模态；
- **投影侧**：对每条候选求解约束投影 QP，Π_C(A) = argmin_{A'∈C} ‖A'−A‖²_W，其中 C 为动力学/几何/常识可行集；
- **认证侧**：生成可行性证书 GFC 界定「提议离可行集多远」，模态覆盖证书 MCC 界定「K 个样本以多大概率覆盖关键模态」；
- **执行侧**：选投影后代价最小、且覆盖关键模态的一条，滚动时域执行首控量。

这样，「多样性」与「安全性」被解耦：多样性由扩散采样与 MCC 认证，安全性由投影与 GFC 认证。上一轮的常识闭塞风险，正是被「多模态提议」对冲的；而扩散的无约束缺陷，正是被「投影 + 证书」补上的。

**形式化目标**：
1. 条件扩散提议器 D_θ: O → P(A^{1:H})，A^{1:H} 为 H 步动作块；
2. 约束投影算子 Π_C: A → A*，C 为硬约束集（动力学、状态/控制界、地形），常识以软罚进入投影代价；
3. 生成可行性证书 GFC：d_k = ‖Π_C(A^(k)) − A^(k)‖_W ≤ ε_k；
4. 模态覆盖证书 MCC：对关键模态集 M，K ≥ ⌈ln(δ/|M|) / ln(1−p_min)⌉ ⟹ P(覆盖所有 p_m ≥ p_min 的模态) ≥ 1−δ；
5. DP-CMP 闭环：采样 → 投影 → GFC/MCC 过滤 → 选优 → 执行 u_0，滚动重规划；
6. 与 KACG 融合为 GKACG（十证一体），Exec_v28 = Exec_v27 ∩ Fil_gen ∩ Fil_proj ⊆ Exec_v27；
7. 给出退化路径：投影不可行 → KEMPC 回退；扩散 OOD（d 过大）→ GFC 拒绝 → KEMPC；MCC 失败 → 增采样或回退。

**本轮最大风险**：投影是多对一的凸算子，它可能把扩散精心采出的多个模态压成同一条可行轨迹——「投影坍缩」；此时 GFC 只约束单条提议到其投影的距离，MCC 只度量投影前的几何覆盖，二者都检测不到投影后的语义模态丢失，系统可能「证书齐全地」重新陷入常识闭塞。

## 2. 关键算法骨架（在 IP-455~464 骨架上扩展）

### IP-465 Conditional Diffusion Proposal (CDP)

```python
@dataclass
class ConditionalDiffusionProposal:
    """条件扩散提议器：一次采样 K 条多模态动作块"""
    denoiser: Callable          # ε_θ(a_t, t, O)
    T: int = 50                 # 去噪步数
    H: int = 16                 # 动作块长度
    n_u: int = 12               # 动作维度
    K: int = 8                  # 候选数
    eta: float = 0.0            # DDIM 随机性（0=确定性）

    @torch.no_grad()
    def sample(self, obs: Tensor, K: int = None) -> Tensor:
        K = K or self.K
        a = torch.randn(K, self.H, self.n_u, device=obs.device)
        for t in reversed(range(self.T)):
            eps = self.denoiser(a, t, obs)
            a = self._ddim_step(a, eps, t)
        return a                # (K, H, n_u)

    def _ddim_step(self, a, eps, t):
        # 标准 DDIM 更新；省略 alpha_bar 调度细节
        a0 = (a - (1 - self._alpha[t]).sqrt() * eps) / self._alpha[t].sqrt()
        return self._alpha[t - 1].sqrt() * a0 + (1 - self._alpha[t - 1]).sqrt() * eps
```

### IP-466 Certified Projection Operator (CPO)

```python
@dataclass
class CertifiedProjectionOperator:
    """约束投影 Π_C(A) = argmin ‖A'-A‖²_W，常识以软罚进入投影代价"""
    dynamics: Callable
    x_bounds: Tensor
    u_bounds: Tensor
    W: np.ndarray               # 动作维度权重
    kc_list: list = field(default_factory=list)
    lam_kc: float = 10.0
    eps: float = 0.15

    def project(self, a_ref: np.ndarray, x0: np.ndarray):
        import cvxpy as cp
        H, n_u = a_ref.shape
        n_x = len(x0)
        X = cp.Variable((H + 1, n_x))
        U = cp.Variable((H, n_u))
        cost = cp.sum_squares(cp.multiply(self.W, U - a_ref))
        cons = [X[0] == x0]
        for k in range(H):
            cons += [X[k + 1] == self.dynamics(X[k], U[k])]
            cons += [U[k] >= self.u_bounds[0], U[k] <= self.u_bounds[1]]
            cons += [X[k + 1] >= self.x_bounds[0], X[k + 1] <= self.x_bounds[1]]
            cost += self.lam_kc * self._knowledge_penalty(X[k + 1])
        prob = cp.Problem(cp.Minimize(cost), cons)
        prob.solve(solver="OSQP", warm_start=True)
        if prob.status != "optimal":
            return None, float("inf")
        a_proj = np.asarray(U.value)
        d = float(np.linalg.norm((a_proj - a_ref) * self.W))
        return a_proj, d

    def _knowledge_penalty(self, x):
        # 复用 v27 的常识权重场 W_kc(x)；这里返回标量表达式
        return sum((1 - kc.activation(x)) for kc in self.kc_list)
```

### IP-467 Generative Feasibility Certificate (GFC)

```python
@dataclass
class GenerativeFeasibilityCertificate:
    """d_k ≤ ε_k 认证提议可被安全投影"""
    eps_base: float = 0.15
    scale: float = 1.0

    def threshold(self, a_ref: np.ndarray, context: dict) -> float:
        # 自适应阈值：扩散置信低时收紧，高动态时略放宽
        conf = context.get("diffusion_confidence", 1.0)
        return self.eps_base * self.scale / max(conf, 1e-3)

    def verify(self, d_k: float, eps_k: float) -> bool:
        return d_k <= eps_k
```

### IP-468 Multimodal Coverage Certificate (MCC)

```python
@dataclass
class MultimodalCoverageCertificate:
    """模态覆盖概率下界（iid 采样 + 模态可枚举假设）"""
    modes: list                 # 关键模态标签集 M
    delta: float = 0.05
    p_min: float = 0.1

    def required_K(self) -> int:
        import math
        M = max(len(self.modes), 1)
        if not (0 < self.p_min < 1):
            return M
        return max(M, math.ceil(math.log(self.delta / M) / math.log(1 - self.p_min)))

    def verify(self, cluster_labels: set, K: int) -> bool:
        if K < self.required_K():
            return False
        return set(self.modes).issubset(cluster_labels)
```

### IP-470 Adaptive Mode-Coverage Sampler (AMCS)

```python
@dataclass
class AdaptiveModeCoverageSampler:
    """按 MCC 反解 K，受实时预算约束"""
    k_min: int = 8
    k_max: int = 64
    budget_ms: float = 15.0
    _last_K: int = 8

    def next_K(self, mcc: MultimodalCoverageCertificate) -> int:
        need = mcc.required_K()
        self._last_K = int(min(self.k_max, max(self.k_min, need)))
        return self._last_K

    def can_escalate(self) -> bool:
        if self._last_K >= self.k_max:
            return False
        self._last_K = min(self.k_max, self._last_K * 2)
        return True
```

### IP-471 Projection-Collapse Detector (PCD)

```python
@dataclass
class ProjectionCollapseDetector:
    """投影坍缩比 ρ = 投影后有效簇数 / 投影前有效簇数"""
    rho_min: float = 0.5
    eps_pair: float = 0.05

    def collapse_ratio(self, pre: np.ndarray, post: np.ndarray) -> float:
        return self._n_clusters(post) / max(self._n_clusters(pre), 1)

    def is_collapsed(self, pre, post) -> bool:
        return self.collapse_ratio(pre, post) < self.rho_min

    def _n_clusters(self, batch: np.ndarray) -> int:
        # 单链聚类，避免依赖 sklearn
        flat = batch.reshape(len(batch), -1)
        n = len(flat)
        parent = list(range(n))

        def find(i):
            while parent[i] != i:
                parent[i] = parent[parent[i]]
                i = parent[i]
            return i

        for i in range(n):
            for j in range(i + 1, n):
                if np.linalg.norm(flat[i] - flat[j]) < self.eps_pair:
                    parent[find(i)] = find(j)
        return len({find(i) for i in range(n)})
```

### IP-469 Diffusion-Propelled Certified MPC (DP-CMP)

```python
@dataclass
class DiffusionPropelledCertifiedMPC:
    """采样 → 投影 → GFC/MCC → 选优 → 执行"""
    proposer: ConditionalDiffusionProposal
    projector: CertifiedProjectionOperator
    gfc: GenerativeFeasibilityCertificate
    mcc: MultimodalCoverageCertificate
    pcd: ProjectionCollapseDetector
    kempc_fallback: 'KnowledgeEmbracingMPC'
    amcs: AdaptiveModeCoverageSampler = None

    def solve(self, obs: Tensor, x0: np.ndarray):
        K = self.amcs.next_K(self.mcc) if self.amcs else self.mcc.required_K()
        cands = self.proposer.sample(obs, K=K).cpu().numpy()

        projected, dists, kept = [], [], []
        for a in cands:
            a_p, d = self.projector.project(a, x0)
            if a_p is None:
                continue
            eps_k = self.gfc.threshold(a, {"diffusion_confidence": 1.0})
            if self.gfc.verify(d, eps_k):
                projected.append(a_p)
                dists.append(d)
                kept.append(a)
        if not projected:
            return self._fallback(x0, reason="all_proposals_rejected")

        clusters = self._cluster_labels(projected)
        mcc_ok = self.mcc.verify(set(clusters), K)
        if not mcc_ok:
            if self.amcs is not None and self.amcs.can_escalate():
                return self.solve(obs, x0)          # 增采样后重试
            return self._fallback(x0, reason="coverage_failed")

        rho = self.pcd.collapse_ratio(np.array(kept), np.array(projected))
        if rho < self.pcd.rho_min:
            return self._fallback(x0, reason="projection_collapse")

        idx = min(range(len(projected)), key=lambda i: self._task_cost(projected[i]))
        u0 = projected[idx][0]
        return u0, {
            "gfc": dists[idx],
            "mcc_ok": mcc_ok,
            "collapse_ratio": rho,
            "K": K,
        }

    def _fallback(self, x0, reason: str):
        u0, kc, dcc = self.kempc_fallback.solve(x0)
        return u0, {"fallback": reason, "kc": kc, "dcc": dcc}

    def _task_cost(self, a: np.ndarray) -> float:
        return float(np.sum(a ** 2) + 0.5 * np.sum(np.diff(a, axis=0) ** 2))

    def _cluster_labels(self, plans: list) -> list:
        flat = np.array([p.reshape(-1) for p in plans])
        labels = []
        for i in range(len(flat)):
            lab = 0
            for j in range(i):
                if np.linalg.norm(flat[i] - flat[j]) < self.pcd.eps_pair:
                    lab = labels[j]
                    break
            labels.append(lab)
        return labels
```

### IP-472 Generative Knowledge-Aware Cert Gate (GKACG)

```python
@dataclass
class GenerativeKnowledgeAwareCertGate:
    """十证一体准入门（KACG ∪ GFC ∪ MCC ∪ PCD）"""
    kacg: 'KnowledgeAwareCertificationGate'
    dp_cmp: DiffusionPropelledCertifiedMPC

    def admits(self, robot_plan, sensor_data: dict) -> bool:
        # 1. 先过 v27 的八证（保证 Exec_v28 ⊆ Exec_v27）
        if not self.kacg.admits(robot_plan, sensor_data):
            return False
        # 2. DP-CMP 生成 + 投影
        u0, cert = self.dp_cmp.solve(sensor_data["obs"], robot_plan.init_state)
        if "fallback" in cert:
            return self.kacg.admits(robot_plan, sensor_data)
        # 3. GFC / MCC / 坍缩 三证
        if not cert["mcc_ok"]:
            return False
        if cert["collapse_ratio"] < self.dp_cmp.pcd.rho_min:
            return False
        if not self.dp_cmp.gfc.verify(cert["gfc"], self.dp_cmp.gfc.eps_base):
            return False
        return True
```

## 3. 复杂度分析（增量）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| CDP 采样 | O(K·T·H·d_θ) | O(K·H·n_u) | K≤64, T≤50, H≤16 |
| CPO 投影 | O(K·(H·n_x³ + H·n_u²·m)) | O(H·n_x) | 每候选一个 QP |
| GFC 验证 | O(K·H·n_u) | O(1) | 逐候选范数 |
| MCC 验证 | O(K²·H·n_u) | O(K) | 聚类为 O(K²) |
| PCD 检测 | O(K²·H·n_u) | O(K) | 成对距离 |
| DP-CMP 单步 | O(K·(T·H·d_θ + H·n_x³) + K²·H·n_u) | O(K·H·n_u + H·n_x) | 瓶颈为 K 个 QP |

**实时性**：K=8, T=20, H=12 时，GPU 上扩散采样约 2–5ms；8 个 QP 若串行约 8×2ms=16ms，总计 20–30ms，勉强满足 50Hz。AMCS 把 K 限制在预算内并对 QP 做并行/热启动；当 K 被迫升到 64 或 QP 超时时，直接降级到 KEMPC（v27 路径），保证控制周期不破。

## 4. 正确性论证（增量）

### 引理 23（投影可行性）

**陈述**：若 CPO 返回 `optimal`，则 A* = Π_C(A) ∈ C，即投影轨迹在 H 步内满足动力学、状态/控制界与地形约束。

**证明**：投影 QP 的约束集即 C 的离散化；`prob.status == "optimal"` 表明存在满足全部约束的可行解，而求解器返回的 U.value 必在约束集内。∎

### 引理 24（GFC 的意图偏离界）

**陈述**：设动力学 f 对控制 u 是 L_u-Lipschitz，且 ‖A*−A‖_W ≤ ε_k。则投影轨迹相对扩散提议诱导的标称轨迹，在 H 步内的状态偏离 ≤ L_u·H·ε_k。

**证明**：逐步展开 x_{t+1}=f(x_t,u_t)，对控制差取 Lipschitz 上界并累加，得 ‖x_t−x_t^ref‖ ≤ L_u·Σ_{s<t}‖u_s−u_s^ref‖ ≤ L_u·t·ε_k ≤ L_u·H·ε_k。∎

### 引理 25（MCC 的覆盖下界）

**陈述**：若 K 条候选 iid 采样自 p_θ，且每个关键模态质量 p_m ≥ p_min，则当 K ≥ ⌈ln(δ/|M|)/ln(1−p_min)⌉ 时，P(覆盖 M 中所有模态) ≥ 1−δ。

**证明**：单个模态被漏掉的概率为 (1−p_m)^K ≤ (1−p_min)^K。对 |M| 个模态做 union bound：P(漏任一) ≤ |M|(1−p_min)^K ≤ δ，即得。∎

### 定理（DP-CMP 的条件安全-覆盖性）

**陈述**：在（i）投影精确、（ii）C 凸、（iii）扩散采样 iid 且关键模态质量 ≥ p_min、（iv）PCD 判定未坍缩（ρ ≥ ρ_min）的条件下，GKACG 准入的每条执行计划都满足硬约束 C，且以概率 ≥ 1−δ 覆盖全部关键模态；因此闭环既安全、又不退化为单模态保守解。

**证明**：安全性由引理 23 直接给出（每步执行的是投影解）。覆盖性由引理 25 给出。非单模态由 PCD 的 ρ ≥ ρ_min 运行时约束保证。三者合取即得。∎

**诚实边界**：定理的（iii）（iv）是**假设而非结论**——模态集是否可枚举、扩散样本是否真 iid、投影是否真的保模态，都不由证书本身保证。这正是下一节风险 R22 的核心。

### 退化路径（保证 Exec_v28 ⊆ Exec_v27）

1. 全部候选被 GFC 拒绝 → 回退 KEMPC（v27，仍过 KACG）；
2. MCC 不满足 → AMCS 增采样至 K_max，仍不满足 → 回退 KEMPC；
3. PCD 检测到投影坍缩 → 回退 KEMPC 或加模态保持约束重投影；
4. QP 超时/不可行 → 回退 KEMPC。
因 GKACG 第一步就要求 `kacg.admits == True`，故任何被 v28 准入的计划必先被 v27 准入，`Exec_v28 ⊆ Exec_v27` 成立。

## 5. 已知风险与缓解（增量）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R22 | 投影坍缩：凸投影多对一，把多模态压成同一可行轨迹 | 高 | 1) PCD 在线监测 ρ；2) 模态保持约束（每模态单独投影并保留代表点）；3) 语义散度惩罚 | 无形式保证；ρ 阈值本身是启发式 |
| R23 | 扩散模型分布外/训练偏差，提议整体不可行 | 高 | 1) GFC 距离拒绝；2) 在线置信估计；3) 回退 KEMPC | 突发未见场景可能全部拒绝→过度保守 |
| R24 | K 个 QP 实时超时 | 中 | 1) AMCS 预算封顶；2) QP 并行 + 热启动；3) 超时即降级 KEMPC | 高动态高 K 时控制抖动 |
| R25 | MCC 的 iid/模态可枚举假设不成立 | 中 | 1) 在线聚类估计模态质量；2) 放宽 δ；3) 与人工规则库联动 | 未知模态集时下界失效 |

## 6. 本轮最大风险（最终确认）

**一句话**：**投影是多对一的凸算子，GFC 只看单条提议到其投影的距离、MCC 只看投影前的几何覆盖，二者都无法察觉投影后的语义模态丢失——系统可能「十证齐全」却因投影坍缩重新陷入常识闭塞，这是当前方案最隐蔽、也最难在线证伪的风险。**
