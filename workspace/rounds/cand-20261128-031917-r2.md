### 第 2 轮灵感驱动研究记录（新循环 · 继承 CADVS-v4 / IP-489~492）

**灵感词**：创新点挖掘、成本控制

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点之上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3·η_val·η_bal；执行集嵌套 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。v4 的最大遗留问题是「安全锚点越多，算力/能量/维护成本越高，最终撞上 1 kHz 控制环预算」（R49）。本轮不推翻 v4，而是把「成本」提升为一等安全约束、把「创新点」当作有限预算下要主动开采的资源，形成 CADVS-v5（IP-493~496），执行集嵌套升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **成本控制：成本不应是优化目标，而应是硬约束**。若把「便宜」乘进证据得分，规则会学会少取证、少检查来刷分（奖励黑客，R47 的近亲）。所以 v5 的关键设计是把成本放进 fail-closed 一侧：引入时间证据门 kc_temporal（端到端认证延迟 ≤ 截止期 D）与新鲜度门 kc_fresh（证书年龄 ≤ τ_fresh 且输入指纹未变），并显式规定 ECS_v5 = ECS_v4（不把成本并入质量分）。直觉：过期证据等同于没有证据；算不完的证明等同于证伪。

2. **成本感知调度（CAES）**：七个锚点不是同等昂贵。kc_coverage/kc_mem/kc_ee 等是 O(1)，VACK ~10–50 ms，BCK ~1–5 ms。把证据铸造看成一个「带截止期的任意时（anytime）子模收益背包」：每个锚点 i 有成本向量 c_i=(延迟, 能量, 带宽, 人工注意力, 金钱) 与边际风险削减 v_i(S)。按 v_i/c_i 排序，先用廉价门快速否决大部分坏规则，昂贵锚点只在廉价门通过且风险后验高时才调用；预算耗尽则保守拒绝，绝不「凑合通过」。

3. **创新点挖掘：从「堆锚点」转向「提炼可发表核心」**。v1~v4 已积累十余模块，但真正的理论贡献只有少数几条。本轮定义「贡献图 + 新颖性-可验证性-成本」三维排序，识别最小可发表核心（MPC）与杀手实验（killer experiment），并把「创新点挖掘」本身形式化为预算约束下的帕累托选择问题。v5 挖出的核心创新不是又一个锚点，而是三条元命题：(a) **成本-安全对偶**（成本超限即安全失效）；(b) **任意时证据铸造的预算单调性与 fail-closed 健全性**；(c) **调度只扩大可达执行集、不越安全边界**。

**关键洞见**：v4 回答「证据够不够强」；v5 回答「在给定时间/能量/维护预算内，证据是否足够强且来得及」。成本第一次成为安全语义的一部分，而不是工程附录；创新点第一次被当作有限资源来开采，而不是事后包装。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_temporal ∧ kc_fresh，fail-closed；ECS_v5 = ECS_v4（刻意不引入成本乘子，避免奖励黑客）。

**形式化目标（增量）**：
1. 定义成本向量 c_i=(ℓ_i,e_i,b_i,h_i,m_i) 与预算 B=(D,E,...)，定义锚点边际安全价值 v_i(S)（关于已评估集合 S 子模）。
2. 定义时间证据门 kc_temporal = (ℓ_end2end ≤ D) ∧ (WCET_upper ≤ D) 与新鲜度门 kc_fresh = (t_now − t_cert ≤ τ_fresh) ∧ (fingerprint(input)=cached_fp)。
3. 定义成本证书 CCC=(ℓ,e,cache_hit,budget_slack,t)，仅作遥测与调度，不进入 ECS。
4. 定义 CAES：在预算约束下最大化期望风险削减，预算耗尽即 fail-closed；给出精确 DP（n≤9）与贪心 (1−1/e) 近似。
5. 定义 ACCC 摊销证书编译器：按输入指纹缓存与增量重算，缓存条目带新鲜度，保证「缓存等价于重算」。
6. 定义 EFA-v5 九硬门与执行集 Exec_v5 = {x∈Exec_v4 : 可于 D 内认证 ∧ 证据新鲜}，证明严格收缩。
7. 定义贡献图与最小可发表核心 MPC：在 (新颖性, 可验证性, 成本) 上取帕累托前沿，MPC 为覆盖全部核心定理的最小贡献集（集合覆盖，贪心 log 近似）。
8. 证明任意时健全性、预算单调性、调度不越界、缓存可靠性、成本-安全对偶五条命题。

**本轮最大风险**：成本感知调度依赖「风险后验」来跳过昂贵证据，一旦风险被低估（分布漂移/对抗场景），省下的算力会直接变成漏检的安全违例，且缓存过期或指纹碰撞会让旧证据被误当成新证据。

## 2. 关键算法骨架

### IP-493 CAES：成本感知证据调度（准入 + 控制环共用，决策本身 O(n log n)，n≤9）

```python
@dataclass
class CostAwareEvidenceScheduler:
    """CAES：带截止期的 anytime 子模收益背包；预算耗尽即 fail-closed"""
    budget: Budget = Budget(D=0.001, E=0.02, B_w=1e6, H=0.0, M=0.0)
    tau_fresh: float = 0.010
    cheap_first: bool = True

    def schedule(self, anchors: list[Anchor], risk_prior: float,
                 S0: frozenset = frozenset()) -> list[Anchor]:
        # 1) 估计每锚点成本 c_i（用 LTEM.cost_hist 的分位数 + WCET 上界）
        # 2) 估计边际安全价值 v_i(S) = risk_prior * info_gain_i(S)
        #    info_gain 关于 S 子模（新增锚点的信息增益随已评估证据递减）
        # 3) 按 v_i / cost_scalar(c_i) 降序；廉价 O(1) 门强制前置
        # 4) 精确解：n<=9 时用预算离散化 DP；否则贪心 (1-1/e)
        ranked = sorted(anchors, key=lambda a: self._ratio(a, S0), reverse=True)
        if self.cheap_first:
            ranked = self._hoist_o1_gates(ranked)
        return self._knapsack_dp(ranked, self.budget) if len(ranked) <= 9 else ranked

    def run(self, anchors, evaluate_fn, risk_prior, t_now):
        """anytime 执行：每个门完成即更新剩余预算；预算不足立即拒绝"""
        remaining = self.budget
        S = set()
        for a in self.schedule(anchors, risk_prior):
            if remaining.latency <= a.wcet_upper:
                return Decision.reject("BUDGET_EXHAUSTED", partial=S)  # fail-closed
            t0 = clock()
            ok, cert = evaluate_fn(a)          # 昂贵门可被早停/降级
            remaining.latency -= clock() - t0
            remaining.energy  -= a.energy_used
            if not ok:
                return Decision.reject(a.reason, partial=S)
            S.add(a.id)
        return Decision.accept(S, budget_slack=remaining)

    def _ratio(self, a, S): ...
    def _hoist_o1_gates(self, ranked): ...
    def _knapsack_dp(self, ranked, budget): ...
```

### IP-494 ACCC：摊销证书编译器（离线编译 + 在线查表，O(1) 命中）

```python
@dataclass
class AmortizedCertificateCompiler:
    """ACCC：把九门编译成 DAG，公共子表达式消除；按指纹缓存 + 新鲜度绑定"""
    tau_fresh: float = 0.010
    cache: dict = field(default_factory=dict)   # key -> (cert, produced_at, fp, anchor_version)

    def compile(self, gates: list[Gate]) -> DAG:
        # 提取公共输入（q/q̇/context/sensor_digest），合并重复子表达式
        # 例如 kc_ee 与 kc_bal 共享 f_ext 预处理；kc_val 与 kc_mem 共享 context 指纹
        return build_dag_with_cse(gates)

    def lookup_or_compute(self, key, inputs, compute_fn, t_now):
        entry = self.cache.get(key)
        if entry is not None:
            cert, produced_at, fp, ver = entry
            fresh = (t_now - produced_at <= self.tau_fresh
                     and fp == fingerprint(inputs)
                     and ver == ANCHOR_VERSION)
            if fresh:
                return cert, CCC(latency=0.0, energy=0.0,
                                 cache_hit=True, budget_slack=None, t=t_now)
            del self.cache[key]                       # 过期即失效，绝不复用
        t0 = clock()
        cert = compute_fn(inputs)
        dt = clock() - t0
        self.cache[key] = (cert, t_now, fingerprint(inputs), ANCHOR_VERSION)
        return cert, CCC(latency=dt, energy=cost_model(key, dt),
                         cache_hit=False, budget_slack=None, t=t_now)

    def incremental(self, prev_inputs, new_inputs, anchor):
        """仅当 anchor 的输入依赖集发生变化时重算；否则返回缓存证书"""
        changed = {k for k in anchor.deps if prev_inputs.get(k) != new_inputs.get(k)}
        return changed
```

### IP-496 EFA-v5：九硬门 + 成本遥测（ECS_v5 = ECS_v4，成本不进评分）

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；ECS_v5 刻意等于 ECS_v4"""
    efa_v4: EvidenceForgingAssemblerV4
    caes: CostAwareEvidenceScheduler
    accc: AmortizedCertificateCompiler
    deadline_D: float = 0.001
    tau_fresh: float = 0.010

    def hard_gate(self, x, t_now, rule_id, hic, eec, bcc,
                  object_class, geo_sig, theta_domain_fp,
                  traj, context, t_trigger: float) -> tuple[bool, str]:
        # 0) 时间门：证明来得及（WCET 上界 + 当前排队）
        if not (t_now - t_trigger + self._wcet_upper(rule_id) <= self.deadline_D):
            return False, 'DEADLINE_MISS'
        # 1) 新鲜度门：证据不能过期，输入指纹不能变
        fp_now = fingerprint(x, context, rule_id)
        if not self.efa_v4.cert_is_fresh(rule_id, fp_now, t_now, self.tau_fresh):
            return False, 'EVIDENCE_STALE'
        # 2) v4 七硬门（顺序由 CAES 决定，HIC veto 永远最先）
        ok, reason = self.efa_v4.hard_gate(
            x, t_now, rule_id, hic, eec, bcc, object_class,
            geo_sig, theta_domain_fp, traj, context)
        if not ok:
            return False, reason
        return True, 'FORGED_V5'

    def ecs_v5(self, *args, **kwargs) -> float:
        return self.efa_v4.ecs_v4(*args, **kwargs)   # 语义不变，无 η_cost

    def _wcet_upper(self, rule_id) -> float: ...
```

### 集成流水线（v4 → v5）

```
离线/慢时域：
  FFA + 成本画像学习：各站 Δ_i 追加每锚点延迟/能量分位数 → Φ_global 下发成本先验
  ACCC 编译：九门 DAG + 公共子表达式消除 + 版本号锚定

在线准入（异步，< 2 s/规则）：
  DAKI → MSRG.sprt_gate → CAES.schedule(risk_prior) → 逐门评估
       ├─ 廉价门先否决 → 早停（省下 VACK/BCK）
       └─ 预算耗尽 → BUDGET_EXHAUSTED（保守拒绝，不降级通过）

在线控制环（目标 < 1 ms，anytime）：
  每周期：
    t_trigger ← now
    kc_temporal 检查（WCET_upper + 排队 ≤ D）      ← O(1)
    kc_fresh 检查（age ≤ τ_fresh ∧ 指纹一致）        ← O(1)，ACCC 命中则 ~0
    v4 七门（CAES 排序；BCK 8 面锥/查表，VACK 读缓存）
    EFA-v5.hard_gate → 证书消费
       ├─ DEADLINE_MISS   → 回退安全控制器 + 教师（不消费证书）
       ├─ EVIDENCE_STALE  → 强制重认证 / 保守回退
       └─ 其余 v4 分支原样继承
```

## 3. 复杂度与成本分析（增量）

| 模块 | 时间复杂度 | 空间 | 关键参数 | 成本/实时性 |
|---|---|---|---|---|
| kc_temporal | **O(1)** | O(1) | WCET 查表 | < 0.005 ms |
| kc_fresh | **O(1)**（指纹增量哈希） | O(1) | τ_fresh | < 0.01 ms |
| CAES.schedule | O(n² log n) 精确 DP / O(n log n) 贪心 | O(n·B_discrete) | n≤9 | 调度本身 < 0.02 ms |
| ACCC 命中 | **O(1)** | O(|cache|) | 指纹/版本 | ~0 ms |
| ACCC 未命中 | 等于被缓存锚点原成本 | — | — | 摊销后期望 = Σ p_hit·0 + (1−p_hit)·c_i |
| EFA-v5 硬门（不含昂贵观测） | **O(1)** | O(1) | — | < 0.04 ms |
| 端到端（CAES + ACCC + 九门） | 期望大幅下降，最坏 ≤ v4 | — | — | **P99 目标 < 1 ms（见 §6）** |

**成本口径**：以「每决策延迟 × 能量 + 人工注意力 + 维护工时」计。v5 的收益来源不是删证据，而是 (a) 廉价门早停、(b) 缓存/增量重算、(c) 昂贵锚点按风险后验按需触发。**最坏情况仍可能超预算，此时 fail-closed，而非降级通过。**

## 4. 正确性论证（增量）

### 引理 43（成本-安全对偶）

**陈述**：设证书只有在 ℓ_end2end ≤ D 时才被消费。则任何 ℓ_end2end > D 的认证等价于「无证书」，系统必须进入安全回退；因此成本超限是安全失效，而非性能退化。

**证明**：证书消费要求 kc_temporal；kc_temporal 失败 ⇒ hard_gate 返回 ⊥ ⇒ 执行集不含该动作 ⇒ 只能走 S_stop/教师。∎

**工程含义**：把「算力不足」从工程隐患升级为可审计的安全事件（DEADLINE_MISS）。

### 引理 44（任意时健全性）

**陈述**：对任意预算 B 与任意截断点，CAES.run 若未评估完全部硬门，则输出必为拒绝（或安全回退），绝不接受。故 A(B) ⊆ Exec_v5 对所有 B 成立。

**证明**：accept 仅在循环完整执行且所有门返回真时产生；预算不足分支直接返回 reject（fail-closed，⊥ 吸收）。∎

### 定理 5（成本-安全对偶与严格收缩）

**陈述**：定义 Exec_v5 = {x∈Exec_v4 : 可于 D 内认证 ∧ 证据新鲜}。则 Exec_v5 ⊆ Exec_v4，且因 kc_temporal/kc_fresh 非恒真，严格 ⊂。

**证明**：Exec_v5 在 v4 七门之外追加两门合取，路径集只缩不涨；构造 x*：v4 七门通过但 BCK 在该接触构型下 WCET_upper > D（或缓存已过期），则 x*∈Exec_v4 而 x*∉Exec_v5。∎

### 定理 6（预算单调性与调度不越界）

**陈述**：(i) 预算 B₁ ≤ B₂（逐分量）⇒ A(B₁) ⊆ A(B₂)；(ii) 存在 B* 使 A(B*)=Exec_v5；(iii) 对任意调度顺序 π，A_π(B) ⊆ Exec_v5，即调度只改变「可达」不改变「安全边界」。

**证明**：(i) 预算更大只会多评估、不少评估，拒绝单调减少（信息增益非负）。(ii) 取 B* = 全锚点 WCET 上界之和 + 排队上界。(iii) 由引理 44，任何调度都受九门合取约束。∎

**推论**：CAES 相对固定顺序只可能扩大可达执行集（Exec_v5^naive ⊆ Exec_v5^CAES ⊆ Exec_v4），这是纯效率收益，不构成安全削弱。

### 定理 7（调度近似比）

**陈述**：在预算约束下最大化子模安全价值 v(S) 是 NP-hard；贪心按 v_i/c_i 得 (1−1/e) 近似；n≤9 时预算离散化 DP 给出精确最优。

**证明**：子模最大化 + 背包约束的经典结果（Nemhauser–Wolsey–Fisher 的 (1−1/e) 界在背包下需按密度贪心并取最优前缀）；n≤9 时状态数可控，DP 精确。∎

### 定理 8（缓存/摊销可靠性）

**陈述**：ACCC 缓存条目仅在 (指纹一致 ∧ 版本一致 ∧ age ≤ τ_fresh) 时复用；此时缓存返回与重算返回的证书语义等价。故缓存不改变接受集，只降低期望成本：E[cost] = Σ_i (1−p_hit,i)·c_i。

**证明**：证书的语义只依赖 (输入, 锚点版本, 时刻)；指纹与版本一致保证输入与实现一致，新鲜度保证时刻有效。任何不一致都删除缓存并重算。∎

### 定理 9（创新点挖掘：MPC 的近似最优性）

**陈述**：给定贡献图 G=(贡献, 定理依赖边)，每个贡献 m 有 (N,V,C)。最小可发表核心 MPC = 覆盖全部核心定理且总成本 ≤ C_pub 的最小贡献集，是带权集合覆盖，NP-hard；贪心给出 H(d)=O(log d) 近似（d 为最大覆盖度）。新颖性-可验证性-成本前沿上的非支配集即「值得开采的创新点」。

**证明**：把每条核心定理看作需被至少一个贡献覆盖的元素，贡献覆盖其支撑的定理；带权集合覆盖的标准贪心界。∎

**诚实声明**：定理 9 只是「选择框架」，不能替代同行评审判断；N/V/C 的量化本身有主观性（见 R55）。真正可发表的仍是定理 5/6/8 这类可证伪的命题，MPC 只是帮助在预算内排序。

## 5. 创新点挖掘：贡献图、MPC 与排序

### 5.1 贡献图（节选）

| 贡献 | 支撑的核心命题 | 新颖性 N | 可验证性 V | 成本 C | 备注 |
|---|---|---|---|---|---|
| 七锚点证据铸造（v4） | 互补完备性 | 高 | 中 | 高 | 已有 R52 维护负债 |
| 成本-安全对偶（v5, 引理 43/定理 5） | 时间即安全 | **高** | **高** | 低 | 一句话可证伪：超时是否导致回退 |

### 5.2 最小可发表核心（MPC）

- **核心命题**：成本是安全约束（引理 43）；任意时铸造 fail-closed 且预算单调（引理 44、定理 6）；调度只扩大可达集不越界（定理 6 推论）。
- **最小贡献集**：{kc_temporal/kc_fresh 两门} + {CAES anytime} + {定理 5/6/8}。v4 七锚点作为被继承的实验平台，不重复主张新颖性。
- **Killer experiment**：在同一截止期下，对比「v4 固定顺序」与「v5 CAES」——展示 v5 的 P99 延迟显著下降、而非法通过率**不升高**；再用「成本进 ECS」的消融展示非法通过率反而升高（奖励黑客），从而证明「成本只能作约束、不能作目标」。

## 7. 已知风险与缓解（增量）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| R19–R52 | v1~v4 全部既有风险 | — | 原样继承；R49 由 CAES/ACCC 部分缓解 | 见既有表 |
| R53 | **风险后验低估导致跳过昂贵证据**（省算力变成漏安全） | **极高** | 廉价门永不可跳；昂贵门仅在风险上界 < τ_skip 时跳过；HIC veto 最高优先级；周期性强制全门校准；A4 对抗测试 | 分布外仍可能低估 |

## 8. 本轮最大风险（最终确认）

**一句话**：成本感知调度依赖「风险后验」来跳过昂贵证据，一旦风险被低估（分布漂移/对抗场景），省下的算力会直接变成漏检的安全违例，且缓存过期或指纹碰撞会让旧证据被误当成新证据。
