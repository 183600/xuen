# 第 44 轮（新循环第 4 轮） · Twin-Cert × Demo-Cert：把「数字孪生」与「演示数据」纳入可验证证书闭环（四层架构 v9）

> 承接第 43 轮 v20（Persona-Cert × Concurrent-Cert）。v20 自陈最大风险是「共形只保边际覆盖 + 多用户契约求交可空」，但它压着两个更深的未言明假设：**(H3) 证书的证据基是均质的、仿真-现实被当作二元 gap**——证书只有「仿真/实机」标签，缺少「证据从哪来、能否连续跨孪生与现实验证」的来源（provenance）语义；**(H4) 演示数据只是训练数据**——人类示教被当作单向的模仿学习燃料，而非可验证、可审计、可反证的一等证据。本轮灵感词「数字孪生」「演示数据」精确命中：**数字孪生**把离线仿真升级为在线、双向、持续同步的镜像，它能在需要证书之前就预先算出证书（新鲜度工厂），但孪生-现实偏差必须自身被认证；**演示数据**把示教从训练燃料升级为「见证/反例」——安全示教是存在性可达见证，近失/违例示教是收缩安全域的反例。二者耦合处是本轮真正的新问题：**孪生生成演示、演示校准孪生**，形成自指证据闭环，可能「自信地错」（对自身模型 sound、对现实 unsound）。

## 0. 直觉与动机

**灵感 1（数字孪生 → 「孪生不是更快的仿真，而是会预支信任的证书预言机」）**：直觉上，数字孪生最诱人的不是「离线多跑几遍」，而是**在真实世界还没到达那个状态之前，就把那时的证书算好**。这把第 43 轮租约的瓶颈（证书必须现取，故必然陈旧）变成预计算：孪生比现实快 s 倍，就能在 t 时刻预支 t+Δ 的证书，真到 t+Δ 时租约「零龄」。但预支信任必须有代价——孪生与现实存在偏差 δ。于是把 δ 提升为**一等证书量**：证书可用当且仅当 m − λΔt − L_m·δ_H ≥ θ，即**时间陈旧 + 模型陈旧**双借记。数字孪生由此从「又一个仿真器」升级为「新鲜度工厂」，而它的偏差与租约衰减用同一套 soundness 算术管理。

**灵感 2（演示数据 → 「示教是见证，不是标签」）**：直觉上，一段人类示教「我这样走过去了、没撞」本身就是一条存在性证明：**存在**一条安全到达的轨迹，这与证书的**全称**安全保证恰好对偶。更妙的是，近失/失败示教是反例，能直接收缩安全域、堵住第 43 轮「空可行集」——因为空集不只可以靠协商解决，还可以靠**展示一条可行见证**解决。但演示数据有致命陷阱：**为了让系统「看起来安全」而精心挑选的演示**（cherry-picking）恰恰是攻击。故演示数据必须带 **provenance（来源证书）** 与**覆盖完备性**审计，且证据必须**主动找反例**（demo fuzzing）而非被动收集。

**灵感 3（耦合 → 反共谋共校准：别让孪生和演示彼此作证）**：孪生合成演示去填补稀疏人格的校准空洞，演示又反过来校准孪生。若只追求两者一致，就会收敛到一个「彼此自洽、共同偏离现实」的不动点——这是比第 43 轮「边际覆盖被欺骗」更强的欺骗：连覆盖估计器及其数据都被共同生成。解法是引入**永不参与共校准的独立现实锚集 S_anchor**，并要求共校准使锚残差**不增**（向现实收缩），一旦上升立即冻结回滚。

**耦合升级**：DTCO 把孪生编译成前瞻证书预言机与偏差监视器；DPL 把演示编译成带来源的见证/反例行与证据账本；TDCL 在二者之间做带**迁移税**的共校准并设**反共谋闸门**。四层架构由 v8 的「个性化并发证书」升级为 v9 的「个性化并发证书 + 孪生-演示证据面（Twin-Demo Plane）」。

## 1. 形式化定义（增量：定义 44–49）

**定义 44（带证演示数据与见证/反例对偶）**：演示 d=(Σ_d, u_d, ctx_d, prov_d, lab_d)，Σ_d 为状态-动作轨迹，ctx_d=(persona, 环境, 传感器配置, 时间)，prov_d 为防篡改来源证书，lab_d∈{safe, near-miss, violation, unknown}。校准可采纳谓词 A(d,c) := (prov_d ⊨ c) ∧ (lab_d≠violation) ∧ ¬Flag_adv(d)。**见证语义**：安全演示是存在性见证——存在策略在 S_safe 内到达目标；**反例语义**：near-miss/violation 演示排除邻域 N(d)，C_global ← C_global \ N(d)。**推论**：演示为「全称安全证书」补齐了「存在可达见证」，可直接缓解第 43 轮 E93 的空可行集——空集先找见证，找不到才协商。

**定义 45（孪生偏差证书与统一信任借记）**：孪生 M_T 近似现实 M_R。一步偏差 δ_1 = sup ρ(M_T(x,a), M_R(x,a))，在独立现实锚集 S_anchor 上用共形上界给出有限样本高概率界 δ̂_1；视界 H 的轨迹偏差由动力学 Lipschitz 常数 L_f 传播：δ_H ≤ ((L_f^H−1)/(L_f−1))·δ̂_1（L_f>1 时）。**统一信任借记**：租约 ℓ=(m, τ, λ, κ, δ_H, H) 可用当且仅当 m − λ(t−τ) − L_m·δ_H ≥ θ。即在定义 41 的时间陈旧之外新增**模型陈旧**借记；两条借记同构、可加、可静态审计。

**定义 46（孪生前瞻证书与新鲜度工厂）**：孪生相对现实有加速比 s=T_real/T_twin>1。在墙钟 t 预计算 t+Δ（Δ≤H）状态的证书；使用时证书已就绪，有效获取延迟→孪生查询延迟 ε_T≪T_cert，租约龄≈0。**命题**：若 δ_H 满足 m_T − L_m·δ_H ≥ θ，则前瞻证书的可用性不低于反应式租约，且 p99 决策延迟严格下降；数字孪生由此成为**新鲜度工厂**而非单纯风险源。

**定义 47（带证反事实演示与迁移税）**：孪生在真实数据稀疏区（如被低估人格）合成演示 d_syn，打 synthetic 戳并携带该区偏差 δ_R。**共形迁移引理**：若非一致性分数 s(x) 对状态 L_s-Lipschitz，且该区孪生偏差高概率 ≤δ_R，则用合成演示校准得到的真实覆盖 ≥ 1−α − L_s·δ_R（**覆盖税**）。仅当覆盖税 ≤ 预算 α_tax 才采纳。**推论**：合成演示可在**孪生理解**的区域内合法扩张条件覆盖（直接补救 E88），但无法在孪生不理解的区域凭空制造覆盖。

**定义 48（反共谋共校准）**：共校准是双向映射 F:孪生→演示（合成）与 G:演示→孪生（校准），可收敛到自洽对 (M_T*, D*) 而背离现实。独立现实锚集 A 的 provenance 与 F、G 均不相交，按周期 T_anchor 刷新。**锚残差** r_A = sup_{d∈A} ρ(M_T(d), d)。**反共谋谓词** E(A) := [r_A 每轮不增] ∧ [D* 覆盖 A 的上下文分布] ∧ [漂移检测器为负]。仅当 E(A) ∧ 独立(A) 才允许继续共校准；r_A 上升即冻结、回滚、强制真实数据重校准。

**定义 49（演示即证据的安全案例）**：证据秩偏序 proof ≻ exhaustive-twin ≻ divergence-certified-twin ≻ calibrated-sim ≻ real-demo-witness ≻ anecdote。安全声明必须引用秩 ≥ρ(claim) 的证据；demo-witness 证据须满足**覆盖完备性**（演示上下文分布覆盖声明的运行域，防 cherry-picking）。**对抗演示选择（demo fuzzing）**：主动搜索能证伪声明的真实演示，只有预算 B_fuzz 内无证伪时才给予统计鲁棒下界。**Goodhart 防御**：为「演示安全」而挑选的演示数据是攻击本身，证据必须**寻求证伪**而非寻求确认。

## 2. 三大新增产出与既有 IP 升级

### 2.1 IP-60 DIGITAL-TWIN-CERT-ORACLE（孪生证书预言机 DTCO）
1. **偏差证书编译**：在 S_anchor 上共形估计 δ_1，按 L_f 传播到 δ_H，输出带视界的偏差证书。
2. **前瞻证书预计算**：超前 Δ 预测状态并预取/预合成证书，签零龄租约，喂给 L3。
3. **统一信任借记**：把 λΔt 与 L_m·δ_H 合并为可用性判据，超阈即单调降级。
4. **偏差漂移监视**：锚残差、区域偏差热图，超阈触发冻结与重校准。

### 2.2 IP-61 DEMO-PROVENANCE-LEDGER（演示来源账本 DPL）
1. **provenance 编译与校验**：上下文绑定、采集链签名、篡改检测；A(d,c) 可采纳判定。
2. **见证/反例双语义**：安全演示产出可达见证（喂可行性求解）；near-miss/violation 产出反例邻域（收缩 C_global）。
3. **cherry-pick 审计**：演示上下文分布 vs 声明运行域的覆盖完备性检验。
4. **对抗演示选择**：demo fuzzing 主动找证伪，输出鲁棒下界与反例回流。

### 2.3 IP-62 TWIN-DEMO-CALIBRATION-LOOP（孪生-演示共校准环 TDCL）
1. **合成演示增广**：在稀疏人格区合成演示，按定义 47 计覆盖税，仅税内采纳。
2. **反共谋闸门**：独立锚集 + 锚残差非增 + 漂移检测，违则冻结回滚。
3. **证据编译**：把证书声明映射到证据秩，生成可审计安全案例。
4. **共校准账本**：记录每轮 F/G 的输入、偏差、锚残差、采纳/拒绝，支持事后线性追溯。

## 4. 实验设计（E95–E102 硬门槛，承接 E87–E94）

回退：E95 provenance 不可靠 → 演示只作立方校验不参与校准；E96 偏差界失真 → 关闭前瞻预取，退回反应式租约；E98 覆盖税不准 → 禁用合成演示，仅用真实数据；E99 共谋检出失败 → 冻结共校准，孪生降级为只读仿真；E97 无收益 → 取消前瞻；任何红线失败 → 熔断回退 v20。

## 5. 本轮最大风险

**一句话**：孪生与演示的共校准是**自指证据环**——孪生生成校准自己的演示、演示又校准孪生，唯一外部锚是有限且可能过期的现实集，系统可变得「自信地错」（对自身模型 sound、对现实 unsound），而精心挑选的「演示数据」恰是让这种错误**看起来安全**的攻击；故 E96（偏差 soundness）与 E99（反共谋）必须设为红线，独立且持续刷新的现实锚集是不可谈判的唯一外部系绳。

## 2. 关键算法（伪代码）

### IP-60 DTCO：偏差证书与前瞻新鲜度
```
def conformal_divergence(twin, anchor, alpha_div, Lf):
    # 在独立锚集上估计一步偏差，取共形上界（有限样本高概率）
    resid = [rho(twin.step(x, a), real_step(x, a)) for (x, a) in anchor.samples]
    delta1 = quantile(resid, 1 - alpha_div)              # 共形上界
    deltaH = delta1 * ((Lf**H - 1) / (Lf - 1)) if Lf > 1 else H * delta1
    return DivergenceCert(delta1=delta1, deltaH=deltaH,
                          anchor_ver=anchor.version)     # 绑定锚版本

def issue_lookahead_lease(twin, x, H, theta, kappa, dcert):
    x_pred = twin.rollout(x, H)                          # 比现实快 s 倍
    c = twin.certify(x_pred)                             # 预取证书
    lam = L_m * v_max_bound(x)                           # 时间衰减率（定义 41）
    usable = (c.m_lo - L_m * dcert.deltaH) >= theta      # 模型借记后仍可用
    return Lease(m=c.m_lo, tau=monotonic_now(), lam=lam,
                 delta=dcert.deltaH, H=H, kappa=kappa, usable=usable)

def lease_valid(lease, theta, t):
    debit = lease.lam * (t - lease.tau) + L_m * lease.delta   # 双借记
    return (lease.m - debit) >= theta
```

### IP-61 DPL：可采纳、见证/反例与 cherry-pick 审计
```
def demo_admissible(d, ctx):
    return covers(d.prov, ctx) and d.label != VIOLATION and not d.adv_flag

def demo_evidence(d):
    if d.label == SAFE:
        return Witness(region=d.traj, policy=d.policy)        # 存在性可达
    else:  # near-miss / violation
        return Counterexample(exclude=N(d.traj, r_safe))      # 收缩安全域

def coverage_completeness(demo_set, claim_domain, eps_cov):
    # 防 cherry-picking：演示上下文分布必须覆盖声明运行域
    return wasserstein_upper(demo_set.ctx_dist, claim_domain) <= eps_cov

def demo_fuzz(claim, real_demo_pool, budget):
    # 对抗选择：主动找能证伪 claim 的演示，而非收集支持证据
    for d in sample_until(real_demo_pool, budget):
        if falsifies(claim, d):
            return Counterexample(found=d)          # 证伪成功
    return RobustBound(B=budget)                    # 统计鲁棒下界
```

### IP-62 TDCL：覆盖税增广与反共谋闸门
```
def certified_synthetic_augment(twin, persona, region, alpha, dcert):
    d_syn = twin.synthesize_demo(persona, region)
    d_syn.synthetic, d_syn.delta_R = True, dcert.delta_on(region)
    tax = L_s * d_syn.delta_R                       # 覆盖税（定义 47）
    if tax > alpha_tax_budget:
        return None                                 # 税超预算 => 拒绝，不扩张
    return d_syn, coverage_floor=1 - alpha - tax    # 合法但打折的覆盖

def anti_echo_gate(twin, anchor, prev_residual, eps_mono):
    assert not anchor.used_in_cocalib                 # 独立现实锚（硬断言）
    r_now = max(rho(twin.predict(d), d) for d in anchor.samples)
    drift = drift_detector(anchor.residual_history + [r_now])
    ok = (r_now <= prev_residual + eps_mono) and not drift   # 向现实收缩
    if not ok:
        freeze_cocalibration()                        # 冻结
        rollback_to_real_only()                       # 回滚，仅真实数据
    return ok, r_now
```

### IP-57/58/51 升级：见证优先补空集 + 双借记守卫
```
def resolve_empty_contract(C_global, personae, demo_pool):
    # 先用真实见证尝试恢复可行性，找不到再协商（缓解 E93）
    for witness in witnesses_for(personae, demo_pool):
        if feasible_with(C_global, witness):
            return feasible_plan(C_global, witness)
    return negotiation(minimal_relaxation(C_global, personae))

def car_transition_guard(e, x, cert_obj, persona, lease, dcert, t):
    theta = cert_obj.alpha_e[e] * cert_obj.theta_sim[e]
    m_lookup = cert_lookup_L0(x).m_lo[e]
    m_lease  = lease.m - lease.lam * (t - lease.tau) - L_m * lease.delta
    m_cap    = persona_cap[e](persona)
    return min(m_lookup, m_lease, m_cap) >= theta and lease_valid(lease, theta, t)
```

## 6. 本轮最大风险

**一句话**：孪生与演示的共校准是**自指证据环**——孪生生成校准自己的演示、演示又校准孪生，唯一外部锚是有限且可能过期的现实集，系统可变得「自信地错」（对自身模型 sound、对现实 unsound），而精心挑选的「演示数据」恰是让这种错误**看起来安全**的攻击；故 E96（偏差 soundness）与 E99（反共谋）必须设为红线，独立且持续刷新的现实锚集是不可谈判的唯一外部系绳。
