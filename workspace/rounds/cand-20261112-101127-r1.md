# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；新灵感循环第 1 轮；本轮灵感：「决策规划」×「商业模式」）

> 第 59 轮已经把「执行层」纳入安全论证链：BUQ 在线辨识电机结构性不确定性，ERTC 把嵌入式时序不确定性契约化，EEIS 把高层 δ_f 编译成阻抗参数与证书，CLEP 让执行实测作为第 5 个模态回传证据层。但它仍留下两个未回答的问题：**「这些承诺为什么值得做、由谁买单」**（价值/成本/责任）与**「在多个承诺、多个检查点、多个客户之间，风险预算应该如何分配」**（决策/规划）。本轮两个灵感正好补上这两个缺口：**「决策规划」**提示把承诺从「固定阈值的单步动作」升级为**证书感知的约束部分可观测决策过程**；**「商业模式」**提示把机器人理解为**持续交付可信服务的经营体**——订单、SLA、单位经济、营运资本、保险、责任、声誉共同构成业务状态。核心命题：**「把安全证书变成可定价、可审计、可承保的服务承诺；把决策规划变成在安全底线与偿付能力约束下的风险调整收益最大化；但安全本身永不进入价格，商业层只能经营安全底线之上的可靠性档位与安全盈余。」**

核心矛盾：

- **H32（规划与证书脱节·风险预算错配）**：第 59 轮之后，每个检查点都能拿到 `K_safe` 与 `Cert_eeis`，但上层规划仍用统一的 `δ_f` 阈值、固定的 `B_probe/B_ft/B_ux/B_exec` 预算。结果是：高风险检查点可能拿到与低风险检查点相同的风险预算，低风险检查点又被迫过度探测。**没有边际风险价格，就没有正确的风险预算分配**——系统要么「 evidence 军备竞赛」，要么在关键处「省证据冒险」。
- **H33（经济闭环缺失·无法判断值不值得）**：现有 VOI 只计算认知价值，不计算「订单价值 − 证据成本 − 执行成本 − 期望责任 − 风险资本占用」。因此系统无法回答：这个订单该不该接？探针买到什么时候停？失败赔偿准备多少？是否该买保险或转包？缺乏经济闭环，证据策略无法与真实服务目标对齐。
- **H34（激励错位·商业模式腐蚀安全）**：一旦引入收入、毛利、交付压力，组织就有动机接受高风险订单、压缩证据、选择性报告、把尾部风险转嫁给保单或客户。**商业模式若直接给安全定价，必然产生「卖安全」的套利**；必须用「安全底线不可交易 + 双账本防火墙 + 职责分离 + 外部审计」把商业失败与安全失败隔离。

## 0. 直觉与动机

**灵感 1（决策规划 → 证书感知的约束 POMDP）**
直觉：机器人不是在「已知地图上走最短路径」，而是在「部分可观测环境 + 不确定执行 + 有限证据预算 + 客户 SLA」下做**序贯决策**。经典决策规划给出的正确对象不是一条轨迹，而是一个**策略**：在每个信念状态、每个证书结果、每个预算状态下，决定「继续探测、承诺、绕行、重新谈判、投保、转包还是停」。第 59 轮的 CLEP 已经提供了单检查点的「执行—证据」闭环；本轮把它嵌入一个三层决策架构：**战略层**做订单准入与组合选择，**战术层**做风险预算分配与路线/合同选择，**操作层**做探针/承诺的实物期权决策。关键不是再写一个规划器，而是让规划器的动作可行性由证书 oracle 决定，让目标函数包含经济价值与尾部责任。

**灵感 2（商业模式 → 机器人即服务，证书即质量保证）**
直觉：卖硬件是一次性生意，卖「可信任务完成」是复利生意。客户真正购买的不是「机械臂动了 37 次」，而是**一份可审计的服务承诺**：在什么力限、什么时限、什么成功率下完成任务；失败如何赔付；证据如何追溯。于是商业模式画布的每个格子都能映射成运行时变量：

| 商业画布 | 机器人服务化含义 | 形式化变量 |
|---|---|---|
| 价值主张 | 带安全证书的任务完成与可靠性档位 | `v(o, δ_sla)`，`Cert_eeis`，`J_exec` |
| 客户细分 | 高价值/不可逆任务 vs 常规任务 | `irr(o)`，`L(o)`，`d(o)` |
| 收入来源 | 任务费 + 可靠性溢价 + 订阅/运维 | `v`，`δ_sla` 的单调定价 |
| 成本结构 | 证据成本、执行成本、人工监督、保险、风险资本 | `C_probe+C_exec+C_ft+C_ux+π_ins+λ_C·K` |
| 核心资源 | 证据管线、证书链、风险资本、声誉 | `M_evidence`，`J_safety`，`R_ring`，`rep` |
| 关键活动 | 订单准入、风险预算、证书规划、结算 | 本轮 `SLA-POMDP` 算子 |
| 关键伙伴 | 云、保险公司、人类操作员、硬件供应商 | `CEB+++++` 协议、再保险、人工接管 |

关键洞见：**证书是质量保证的计量单位，但不是安全底线的售卖单位**。客户可以购买更高的可靠性档位（更小的 `δ_sla`），但不能购买低于 `δ_floor` 的「更危险但更便宜」的服务。安全底线是**非交易权利**；商业层只能经营底线之上的可靠性溢价与安全盈余。

**灵感 3（双账本 → 商业可以破产，安全不可以）**
直觉：把系统账本拆成两本。**安全账本**记录 `δ_f`、`Cert_eeis`、`EV-exec`、`J_exec`、`R_ring`、硬约束；**商业账本**记录订单价值、成本、责任、保险、现金、毛利、声誉。两本账之间有一道**防火墙**：商业层不能修改 `δ_floor`、`F_abs`、`ε_traj`、不可逆禁令；不能把 `R_ring` 拿去做运营或利润分配；不能因为「这单很值钱」而放宽安全约束。反过来，商业账本可以破产（拒绝订单、赔付、重组），但安全账本必须始终偿付。这样，商业模式的风险被限制在财务层，不会穿透为物理伤害。

**灵感 4（风险价格 → 影子价格，而不是安全价格）**
直觉：当风险资本/证据预算/截止期成为稀缺资源时，它们自然有**影子价格** `λ_R, λ_E, λ_T, λ_C`。这些价格用于内部资源分配：高价值、低风险贡献的订单优先；高不确定性、低边际收益的探针被推迟；高风险检查点获得更多风险预算。**但 `λ_R` 是「安全盈余的影子价格」，不是「降低安全底线的报价」**。底线约束的拉格朗日乘子趋于无穷，任何有限报价都不能购买它。这个区分是本轮伦理与工程上的核心。

**灵感 5（内部证据市场 → 让稀缺暴露，而不是让部门抢预算）**
直觉：视觉、触觉、本体、声学、执行五个模态都能提供证据，但成本、延迟、质量不同；探针、微调、解释、执行四类预算又互相竞争。与其让各模块「先到先得」，不如建立一个**内部影子市场**：每个模块提交「我能在什么延迟内、以什么成本、把风险降低多少」的报价，规划器在预算与截止期约束下选择组合；对偶价格告诉每个模块「你的证据在当下值多少钱」。这不是把机器人变成交易所，而是用市场机制做**稀缺注意力与预算的分布式发现**；支付用内部记账单位，外部仍是服务合同。

**灵感 6（组合与再保险 → 不要用一个不可逆承诺赌全部资本）**
直觉：单笔不可逆任务可能一次性击穿风险资本。商业上不会用全部资本承保一个巨灾风险，而是**分散、分层、再保险、设置免赔额与止损**。机器人服务同样：把长任务拆成多个可停止的「最小可行承诺」，用独立证据源分散相关性，用人工接管/远程操作作为再保险，用 `δ_ruin` 与 CVaR 约束防止「一次失败毁掉整个服务」。这就是「决策规划」与「商业模式」真正的交叉点：**规划的不是动作序列，而是风险与期权的组合**。

## 1. 形式化定义（增量：定义 153–160）

**定义 153（服务订单与业务状态）** 订单 `o=(g, v, d, SLA, L(·), irr)`，其中 `g` 为任务目标，`v` 为净收入（已扣除直接变动成本前的合同价值），`d` 为截止期，`SLA=(δ_sla, F_max, ε_traj, T_max)` 为服务等级协议，`L(·)` 为责任随机变量/赔付函数，`irr∈{0,1}` 为不可逆标志。业务状态 `β=(R_free, R_ring, I_cov, D_ded, backlog, rep, λ_R, λ_C, λ_E, λ_T)`：`R_free` 为可运营/可赔付现金，`R_ring` 为**安全隔离金**（只能用于安全整改、停机、召回，不得用于运营或分配），`I_cov` 为保险覆盖上限，`D_ded` 为免赔额，`backlog` 为在途订单，`rep∈[0,1]` 为声誉/信任资产，`λ_R, λ_C, λ_E, λ_T` 分别为风险资本、资金、证据预算、截止期的影子价格。硬性不变量：`R_ring ≥ R_ring_min`。

**定义 154（SLA-POMDP：证书感知的约束部分可观测决策过程）** 
`M_SLA = (S, A, T, O, Z, r, C, γ, δ_floor, δ_ruin)`。
- 状态 `s=(x_env, ξ_exec, b_evidence, β_biz, τ_evidence)∈S`：环境、执行不确定性状态、证据信念、业务状态、证据年龄。
- 动作 `A = A_probe ∪ A_commit ∪ A_reroute ∪ A_renegotiate ∪ A_reinsure ∪ A_subcontract ∪ A_stop`；每个 `commit` 动作必须携带 `Cert_eeis` 且通过 CLEP 的 `K_safe` 可行性检查。
- 转移 `T = T_env × T_exec × T_biz`：物理演化、执行降级/失效、业务现金与责任演化。
- 观测 `O = O_sensor × O_exec × O_cert × O_cost`：多模态观测、`EV-exec`、证书审计结果、实际成本。
- 奖励 `r = v(o,δ_sla)·1[success] − C_total − L_paid + ΔV_rep + ΔV_option`。
- 约束 `C = {C_safety, C_SLA, C_solvency, C_budget}`，且采用**字典序偏好**：`C_safety ≻ (C_SLA, C_solvency, C_budget) ≻ r`。
- 策略 `π: (b_evidence, β_biz) → a`，动作集先经硬掩码 `A_safe(b,β)` 过滤；`δ_floor` 为全局安全底线，`δ_ruin` 为破产概率容忍度。
- 目标：`max_π E[Σ_t γ^t r_t] s.t. C_safety 恒成立，C_SLA/C_solvency/C_budget 以概率/期望约束满足`。

**定义 155（双账本与风险定价账本 RPL）** 安全账本 `L_safe=(δ_f, Cert_eeis, EV-exec, J_exec, R_ring, floor)`；商业账本 `L_biz=(v, C_total, L, R_free, I_cov, margin, SLA_outcome, rep)`。防火墙规则：(F1) 商业层不得写 `δ_floor, F_abs, ε_traj, irr`；(F2) `R_ring` 不得用于运营、投资、分红，只能用于安全整改/召回/停机；(F3) 商业损失不得减少 `R_ring`，安全支出不得被商业目标否决；(F4) 任何承诺必须先在 `L_safe` 通过，再进入 `L_biz` 计价。计划 `π` 的风险定价：
```
C_total(π) = C_probe(π) + C_exec(π) + C_ft(π) + C_ux(π)
           + E[L(π)] + λ_R · CVaR_α(L(π)) + λ_C · K(π)
K(π) = max(0, CVaR_α(L(π)) − R_ring_order)
RAP(π) = v(o, δ_sla) + ΔV_rep(π) + ΔV_option(π) − C_total(π)
```
其中 `CVaR_α` 为尾部条件期望，`λ_R` 为风险资本影子价格，`λ_C` 为风险资本占用成本。单位经济指标：贡献毛利 `CM=v−C_variable`；赔付率 `loss_ratio=E[L]/v`；证据 ROI `ROI_ev=(realized_VOI−C_probe)/C_probe`；风险调整收益 `RAP`。**安全底线约束的乘子不参与定价**：`δ<δ_floor` 的动作无论 `RAP` 多高都不可行。

**定义 156（风险预算与 SLA 分解 RBA）** 给定订单 `o` 的 `δ_sla` 与检查点集合 `CP`，为每个检查点分配风险预算 `δ_i`。用相干风险度量的欧拉风险贡献：
```
RC_i = δ_i · ∂ρ(L)/∂δ_i,   Σ_i RC_i = ρ(L)（ρ 一次齐次时）
δ_i* = clip( δ_sla · RC_i / Σ_j RC_j , δ_min_i, δ_max_i )
```
不可逆检查点默认 `δ_i=0`（必须人工批准或绕行）；若 `Σδ_i* > δ_sla`，解约束分配问题：
```
max_{δ_i} Σ_i U_i(δ_i)
s.t. Σ_i δ_i ≤ δ_sla, δ_i∈[δ_min_i,δ_max_i], δ_i=0 (irr 且未批准)
```
KKT 条件：内点 `U_i'(δ_i)=μ`（等边际效用），边界取 clip。`U_i` 为「该检查点多获得一点风险预算带来的期望续行价值」。在线每完成一个检查点，用剩余预算 `δ_remaining=δ_sla−Σ_{j<i}δ_j` 与更新后的 `RC_i` 重解，实现**风险再平衡**。

**定义 157（偿付能力约束的订单准入 SAC）** 令 `L_total=L_open+L(o)`。准入必须同时满足：
```
(C1) 安全：存在 Cert_eeis 使 δ_f ≤ δ_floor ∧ F ≤ F_abs ∧ (irr ⇒ 人工批准)
(C2) 偿付：CVaR_α(L_total − I_cov) ≤ R_free − R_buffer
(C3) 破产：Pr(R_free + I_cov − L_total < 0) ≤ δ_ruin
(C4) 经济：RAP(o) ≥ 0
(C5) 隔离：R_ring ≥ R_ring_min
```
任一不满足时，按序尝试：**重新谈判** `(v,δ_sla,d)` → **再保险/分层承保** → **带保修的转包/人工接管** → **拒绝**。保险定价（示意）：
```
π_ins = (1+η)·E[(L−D_ded)^+] + λ_C·CVaR_α((L−D_ded)^+)
```
保险只转移金钱，不转移安全责任：保单生效不豁免 `C1`，且免赔额/审计抑制道德风险。

**定义 158（实物期权探针调度 OVPS）** 在检查点，定义 `V_commit(b), V_defer(b), V_abandon(b)` 为承诺、推迟、放弃的续行价值。探针 `p` 的期权价值：
```
OV(p) = E_{o∼p}[ max(V_commit(b'), V_defer(b'), V_abandon(b')) ]
        − max(V_commit(b), V_defer(b), V_abandon(b))
        − C_probe(p) − λ_R·Δρ(p) − λ_E·C_probe(p)
```
决策规则：`OV(p)>0` 且预算/截止期可行才探测；承诺当且仅当 `V_commit(b)−C_commit(b) ≥ max_p OV(p)` 或截止期强制；若 `max(V_commit,V_defer,V_abandon) < C_stop` 则安全停。该定义把「先做最小可行承诺，证据充分后再扩大」形式化为**买期权—持有—行权**：探测是买入继续决策的权利，承诺是行权，放弃是止损。

**定义 159（内部证据市场 IEM）** 证据模块 `m∈{vis,tap,prop,acou,exec}` 提交报价 `(q_m, l_m, c_m, Δρ_m, ΔV_m)`：质量、延迟、成本、风险降低、价值增量。清算问题：
```
max_{x} Σ_m x_m (ΔV_m − λ_R·Δρ_m)
s.t. Σ_m x_m c_m ≤ B_evidence,  Σ_m x_m l_m ≤ d_remaining,
     Σ_m x_m q_m ≥ q_min,      x_m∈{0,1}
```
对偶变量 `λ_E` 为证据预算影子价格，`λ_T` 为截止期影子价格。支付可用 VCG 外部性定价；预算约束破坏 VCG 的严格激励相容时，用第二价格 + 预算节奏 + 审计 + 声誉来约束。内部市场只用于计算资源分配，不对应真实货币交易，避免把安全责任外部化。

**定义 160（业务证书 J_biz 与结算）** 
`J_biz=(order_id, SLA, v, cost_breakdown, λ_R, λ_C, reserve_charge, insurance, J_safety_ref, J_exec_ref, realized_outcome, liability_paid, margin, reputation_delta, audit_status, timestamp)`。结算更新：
```
R_free' = R_free + v − C_total − L_paid + claim − π_ins
R_ring' = R_ring − safety_remediation_cost   （仅安全用途）
rep'    = clip(rep + α_s·1[success] − α_f·1[fail] − α_v·1[SLA violation], 0, 1)
```
失败率用信誉/经验费率更新（Bühlmann 信度）：
```
μ_post = z·μ_obs + (1−z)·μ_prior,   z = n/(n+k)
```
其中 `n` 为同类订单经验数，`k` 为先验强度。`J_biz` 追加到不可篡改账本，供内部审计、保险理赔与客户追溯；它只引用 `J_safety/J_exec`，不得修改其内容。

## 2. 关键算法伪代码（本轮方案骨架）

```python
def sla_pomdp_plan(M, order, beta, budget, deadline):
    """SLA-POMDP 三层规划：战略准入 → 战术风险预算 → 操作期权执行"""
    # 战略层：安全底线 + 偿付能力 + 经济性
    if not sac_admit(order, M, beta):
        return sac_negotiate_or_reject(order, M, beta)

    # 战术层：把订单 SLA 分解成检查点风险预算
    delta_cp = rba_allocate(order.SLA.delta_sla, M.route(order), M, beta)
    route = hierarchical_plan(M, order, delta_cp, beta)

    # 操作层：证书感知的 contingent execution
    policy = build_contingent_policy(M, order, route, delta_cp, beta)
    log = []
    while not deadline.expired() and budget.is_viable():
        cp = policy.next_checkpoint()
        result = clep_execute(M, cp, delta_cp[cp], budget)  # 复用第 59 轮 CLEP
        if result.degraded or result.cert is None:
            route, delta_cp = replan_conservative(M, order, cp, budget)
            policy = build_contingent_policy(M, order, route, delta_cp, beta)
            continue
        if evidence_gate_ppp(result.evidence, M, M.operators, M.ood, result.EV_exec)[0] == 'ok':
            budget, entry = rpl_settle(M, order, result, beta)
            beta = beta.update(entry)
            log.append(entry)
        else:
            # 期权续行：探测 / 推迟 / 承诺 / 放弃
            action = ovps_decide(M, cp, result, budget, deadline)
            if action == 'probe':
                M, result = clep_execute(M, cp, delta_cp[cp], budget)
            elif action == 'abandon':
                return sac_negotiate_or_reject(order, M, beta, reason='option_stop')
            elif action == 'commit':
                budget, entry = rpl_settle(M, order, result, beta)
                beta = beta.update(entry)
                log.append(entry)
    return log, beta
```

```python
def rba_allocate(delta_sla, checkpoints, M, beta):
    """欧拉风险贡献 + 等边际效用 + 不可逆硬零预算"""
    for cp in checkpoints:
        cp.rc = euler_risk_contribution(cp, M)  # δ_i * ∂ρ/∂δ_i
    total_rc = sum(cp.rc for cp in checkpoints if not cp.irreversible)
    for cp in checkpoints:
        if cp.irreversible and not cp.human_approved:
            cp.delta = 0.0
        else:
            cp.delta = clip(delta_sla * cp.rc / total_rc, cp.delta_min, cp.delta_max)
    if sum(cp.delta for cp in checkpoints) > delta_sla:
        cp.delta = solve_kkt_waterfilling(checkpoints, delta_sla)  # U_i'(δ_i)=μ
    return {cp: cp.delta for cp in checkpoints}

def sac_admit(order, M, beta):
    if not safety_floor_feasible(order, M):
        return False
    L_total = beta.L_open + M.liability_model.sample(order)
    if cvar(L_total - beta.I_cov, alpha=0.99) > beta.R_free - beta.R_buffer:
        if not reinsurance_can_fix(order, M, beta):
            return False
    if beta.R_ring < beta.R_ring_min:
        return False
    return risk_adjusted_profit(order, M, beta) >= 0

def ovps_decide(M, cp, result, budget, deadline):
    v_now = max(value_commit(M, cp), value_defer(M, cp), value_abandon(M, cp))
    best_ov = -inf
    for p in admissible_probes(cp, M, budget):
        ov = option_value(p, M, cp) - probe_cost(p, M) - budget.shadow_price(p)
        best_ov = max(best_ov, ov)
    if best_ov <= 0 or deadline.forces_commit():
        return 'commit' if value_commit(M, cp) >= value_abandon(M, cp) else 'abandon'
    if value_commit(M, cp) - commit_cost(cp, M) >= best_ov:
        return 'commit'
    return 'probe'
```

```python
def rpl_settle(M, order, result, beta):
    """风险定价账本：结算一次承诺/订单"""
    c_probe = result.cost_probe
    c_exec = result.cost_exec
    c_ft, c_ux = result.cost_ft, result.cost_ux
    L = result.liability_distribution
    k_cap = max(0, cvar(L, alpha=ALPHA) - beta.R_ring_order)
    c_total = c_probe + c_exec + c_ft + c_ux + mean(L) + \
              beta.lambda_R * cvar(L, ALPHA) + beta.lambda_C * k_cap
    rap = order.value + result.reputation_delta + result.option_value - c_total
    entry = BusinessEntry(order=order, cost=c_total, rap=rap, L=L,
                          safety_ref=result.cert, exec_ref=result.EV_exec,
                          audit=audit_ledger(result))
    return beta, entry
```

def clear_evidence_market(bids, budget, deadline, M):

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SLA-POMDP | 在线分层：战略 O(1)，战术 O(\|CP\|·k_rba)，操作 O(H·(\|A\|+CLEP))；离线可用 POMCP/ rollout 近似 | O(\|B\|·d_b + \|β\|) | 安全动作掩码、字典序约束、终止性 |
| RPL | O(\|CP\|·d_L) / 结算；CVaR 用样本 O(N log N) 或增量 | O(N_tail + \|β\|) | 双账本防火墙、风险定价不触碰底线 |
| RBA | O(\|CP\|^2 log(1/ε))（欧拉+水填充） | O(\|CP\|) | `Σδ_i≤δ_sla`、不可逆零预算、欧拉可加性 |
| SAC | O(N_L) 采样 + CVaR；O(1) 查表准入 | O(N_L) | 偿付/破产约束、保险/转包保守回退 |
| OVPS | O(\|A_probe\|·(C_VOI+CLEP)) / 检查点 | O(\|B\|) | 期权价值单调、预算/截止期终止 |
| IEM | O(2^{\|M\|}) 精确；O(\|M\| log\|M\|) 贪心/对偶近似 | O(\|M\|) | 预算/延迟/质量约束、对偶价格解释 |
| J_biz | O(1)/订单追加；审计 O(log n) | O(订单数) | 追加不可篡改、引用不修改 J_safety/J_exec |

**正确性定理（Business-Grounded Safety Soundness, BGSS）**
假设 A51–A55（第 59 轮执行接地层）成立；并新增：
- **(A56) 订单真实性**：`v, d, SLA, L(·), irr` 由可审计合约给出，误报收益有界；关键字段需客户/第三方确认。
- **(A57) 安全底线不变量**：`δ_floor, F_abs, ε_traj, irr` 由安全治理层设定，商业层无写权限；不可逆动作必须人工批准。
- **(A58) 风险模型校准**：失败概率与 CVaR 估计有有限样本上界，估计误差 ≤ `δ_est`；用共形/信度/经验贝叶斯校准。
- **(A59) 账本完整性**：双账本追加写、职责分离、外部审计；欺诈被检出概率 ≥ `1−δ_audit`。
- **(A60) 市场诚实性**：内部证据市场采用 VCG/第二价格，或审计+声誉机制使真实报价为 `ε_IC`-最优；无合谋。
- **(A61) 执行证书健全**：第 59 轮 `Cert_eeis, EV-exec, J_exec` 音完备且未被篡改。
- **(A62) 流动性**：`R_free` 与保险赔付可及时兑现；压力场景覆盖相关失效；否则触发停业/安全停。

则：

1. **安全底线不变量**：对任何被接受的订单/动作，`C_safety` 以至少 `1−δ_floor` 成立，且与 `v, RAP, λ_R` 无关。证明：动作先经 `A_safe` 硬掩码，`C_safety` 在字典序中优先于经济目标；商业层无写权限（A57）。
2. **偿付能力**：在 A58/A62 下，任意滚动窗口内 `Pr(ruin) ≤ δ_ruin + δ_est + δ_audit`，且 `CVaR_α(L_total−I_cov) ≤ R_free−R_buffer`。证明：SAC 的准入约束 + CVaR 上界 + 审计修正。
3. **SLA 风险预算健全性**：若每个检查点按 `δ_i` 执行且证书健全，则 `Pr(SLA violation) ≤ Σ_i δ_i + δ_est ≤ δ_sla + δ_est`。证明：联合界 + A61；不可逆点 `δ_i=0` 消除该类风险。
4. **激励相容与不压制证据**：在 A59/A60 下，真实报告证据与真实报价的长期收益不低于偏差策略，偏差收益 ≤ `ε_IC`，且审计/声誉惩罚 ≥ 偏差收益；`J_biz` 的赔付与信度更新使「省证据」在未来保费/准入中显性化。
5. **终止性**：订单/检查点/预算/截止期有限；每个探针消耗 `B_evidence` 或降低不确定性；`OV(p)≤0` 或预算耗尽即停止，故在 `O(k_probe+k_commit+k_renegotiate)` 内终止于 {承诺(带证书), 绕行, 重新谈判, 转包, 安全停, 拒绝}。
6. **部署界（业务扩展）**：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD] + δ_ertc·1[契约违例]
                   + δ_eeis·1[μ分析漏报])
         − δ_est − δ_audit − δ_liquidity
```
且对任何被接受订单，安全账本另行保证 `P_safe ≥ 1−δ_floor`；商业账本破产不降低该下界。

关键：**RBA 把风险预算从「平均主义」变成「边际风险贡献定价」**；**SAC 把订单准入从「拍脑袋接单」变成「偿付能力约束下的风险调整收益」**；**OVPS 把探测/承诺从「固定规则」变成「实物期权」**；**IEM 把预算竞争从「部门抢占」变成「影子价格发现」**；**双账本把商业失败与安全失败隔离**。商业层可以更聪明地经营，但不能更便宜地不安全。

| `CVaR_α(L)=min_ν{ν+(1/(1−α))E[(L−ν)^+]}` | 尾部条件期望（Rockafellar–Uryasev） |
| `OV(p)` | 探针 p 的实物期权价值 |
| `IEM` 清算 `(x,λ_E,λ_T,pay)` | 内部证据市场的选择、对偶价格、支付 |
| `J_biz=(order,SLA,v,cost,λ,reserve,insurance,J_safety,J_exec,outcome,liability,margin,rep_delta,audit)` | 业务证书 |
| `JCPS+++` | 在 `JCPS++` 上增加业务层字段的联合证书 |

**定义 153（服务订单与业务状态）** 见想法区。补充：`R_ring` 是**安全隔离金**，只能用于安全整改、停机、召回、责任赔付中的安全部分；`R_free` 才是运营与商业赔付资金。硬不变量 `R_ring≥R_ring_min`，商业层无写权限。

**定义 154（SLA-POMDP）** 状态、动作、转移、观测、奖励、约束如想法区所述。信念更新：
```
b'(s') ∝ Z(o|s',a) · Σ_s T(s'|s,a) b(s)
Q(b,a) = R(b,a) + γ Σ_o Pr(o|b,a) V(b')
V(b) = max_{a∈A_safe(b,β)} Q(b,a)   （安全动作硬掩码）
```
约束用拉格朗日松弛（安全约束不松弛）：
```
L(π;λ_SLA,λ_solv,λ_budget) = E[Return(π)] 
  − λ_SLA·(Σ_i δ_i − δ_sla)
  − λ_solv·(CVaR_α(L_total−I_cov) − (R_free−R_buffer))
  − λ_budget·(Σ B_used − B_total)
```
`safety constraint` 作为硬掩码，`λ` 只对 SLA/偿付/预算生效。

**定义 155（双账本与 RPL）** 见想法区。补充三点：
1. `λ_R` 是「安全盈余/风险资本的影子价格」，不是「安全底线的价格」；`δ<δ_floor` 的拉格朗日乘子视为 `+∞`。
2. `K(π)=max(0,CVaR_α(L(π))−R_ring_order)` 表示超出订单安全隔离金的风险资本占用。
3. 定价单调性：`v(o,δ_sla)` 对 `δ_sla` 单调不增（更高可靠性收费更高），但定义域 `δ_sla∈(0,δ_floor]`，禁止购买 `δ>δ_floor` 的「低可靠性折扣」。

**定义 156（RBA）** 欧拉分配 + KKT 水填充。相关失效时用条件风险贡献：
```
RC_i = E[δ_i(ω)·∂ρ/∂δ_i] 或 Copula 条件期望
```
不可逆点 `δ_i=0` 除非 `human_approved=true`；若 `Σδ_i` 下界仍超过 `δ_sla`，则订单不可行（拒绝/谈判/转包/人工接管）。

**定义 157（SAC）** 准入约束 `(C1)~(C5)` 如想法区。再保险/分层承保：
```
π_ins = (1+η)·E[(L−D_ded)^+] + λ_C·CVaR_α((L−D_ded)^+)
```
若保险后仍不满足 `C2/C3`，则转包/人工接管/拒绝。**保险不豁免 `C1`**。

**定义 158（OVPS）** 期权价值如想法区。补充：当 `OV(p)` 因不确定性而增大时，系统更愿意探测；当截止期逼近、`λ_T` 升高时，行权（承诺）阈值下降；当 `V_abandon` 最优点出现时立即止损。该规则天然避免「沉没成本谬误」。

**定义 159（IEM）** 清算问题如想法区。LP 松弛的对偶给出 `λ_E,λ_T`；若预算约束紧，`λ_E>0`，只有「单位预算风险降低」高于价格的证据被采购。VCG 支付在预算约束下不再严格激励相容，故加审计与声誉：虚报被检出后扣减 `rep` 并提高未来报价门槛。

**定义 160（J_biz）** 业务证书与结算如想法区。补充哈希链：
```
h_t = H(h_{t-1} || J_biz_t || J_safety_ref_t || J_exec_ref_t)
```
`J_biz` 只引用安全/执行证书，不修改它们；审计可重放整条链。失败率信度更新：
```
μ_post = z·μ_obs + (1−z)·μ_prior,  z=n/(n+k)
```

### IP-152 SLA-POMDP（三层证书感知规划）

```python
def sla_pomdp_plan(M, order, beta, budget, deadline):
    # ===== 战略层：订单准入 =====
    if not sac_admit(order, M, beta):
        return sac_negotiate_or_reject(order, M, beta)

    # ===== 战术层：SLA 风险预算 + 证书感知路线 =====
    delta_cp = rba_allocate(order.SLA.delta_sla, M.route(order), M, beta)
    route = hierarchical_plan(M, order, delta_cp, beta)

    # ===== 操作层：contingent policy =====
    policy = build_contingent_policy(M, order, route, delta_cp, beta)
    log, beta = [], beta
    while not deadline.expired() and budget.is_viable():
        cp = policy.next_checkpoint()
        res = clep_execute(M, cp, delta_cp[cp], budget)  # 第 59 轮 CLEP
        if res.degraded or res.cert is None:
            route, delta_cp = replan_conservative(M, order, cp, budget)
            policy = build_contingent_policy(M, order, route, delta_cp, beta)
            continue
        gate = evidence_gate_ppp(res.evidence, M, M.operators, M.ood, res.EV_exec)
        if gate[0] == 'ok':
            beta, entry = rpl_settle(M, order, res, beta)
            log.append(entry)
            continue
        # 期权决策：探测 / 推迟 / 承诺 / 放弃
        act = ovps_decide(M, cp, res, budget, deadline)
        if act == 'probe':
            M, res = clep_execute(M, cp, delta_cp[cp], budget)
        elif act == 'abandon':
            return sac_negotiate_or_reject(order, M, beta, reason='option_stop')
        elif act == 'commit':
            beta, entry = rpl_settle(M, order, res, beta)
            log.append(entry)
    return log, beta

def build_contingent_policy(M, order, route, delta_cp, beta):
    """为每个检查点建立分支：commit / probe / reroute / stop"""
    policy = {}
    for cp in route.checkpoints:
        branches = ['commit', 'probe', 'reroute', 'stop']
        if cp.irreversible and not cp.human_approved:
            branches.remove('commit')
        # rollout 用 CLEP + EEIS 证书 oracle 估计每个分支的续行价值
        policy[cp] = max(branches, key=lambda a: rollout_value(M, cp, a, delta_cp[cp]))
    return ContingentPolicy(policy)
```

def rpl_price(plan, order, M, beta):
    c_probe = plan.cost_probe
    c_exec = plan.cost_exec
    c_ft = plan.cost_ft
    c_ux = plan.cost_ux
    L = plan.liability_distribution
    tail = cvar(L, alpha=ALPHA)
    k_cap = max(0.0, tail - beta.R_ring_order)
    c_total = (c_probe + c_exec + c_ft + c_ux
               + mean(L) + beta.lam_R * tail + beta.lam_C * k_cap)

    rap = value - c_total
    return Pricing(c_total, rap, tail, k_cap, value)

### IP-154 RBA（风险预算分配）

```python
def rba_allocate(delta_sla, checkpoints, M, beta):
    """欧拉风险贡献 + 硬零预算 + KKT 等边际效用"""
    active = []
    for cp in checkpoints:
        if cp.irreversible and not cp.human_approved:
            cp.delta = 0.0
        else:
            cp.rc = euler_risk_contribution(cp, M)  # δ_i * ∂ρ/∂δ_i
            active.append(cp)
    total_rc = sum(cp.rc for cp in active) + 1e-12
    for cp in active:
        cp.delta = clip(delta_sla * cp.rc / total_rc,
                        cp.delta_min, cp.delta_max)
    if sum(cp.delta for cp in active) > delta_sla:
        solve_kkt_waterfilling(active, delta_sla)  # U_i'(δ_i) = μ
    if sum(cp.delta_min for cp in active) > delta_sla:
        return None  # 订单风险预算不可行 → 拒绝/谈判/转包
    return {cp: cp.delta for cp in checkpoints}

def solve_kkt_waterfilling(checkpoints, budget):
    """max Σ U_i(δ_i) s.t. Σδ_i≤budget, 边界 clip; 二分 μ"""
    lo, hi = 0.0, max(cp.delta_max for cp in checkpoints)
    for _ in range(60):
        mu = 0.5 * (lo + hi)
        for cp in checkpoints:
            cp.delta = clip(inv_marginal_utility(cp, mu),
                            cp.delta_min, cp.delta_max)
        if sum(cp.delta for cp in checkpoints) > budget:
            lo = mu
        else:
            hi = mu
    scale = budget / max(sum(cp.delta for cp in checkpoints), 1e-12)
    for cp in checkpoints:
        cp.delta = clip(cp.delta * scale, cp.delta_min, cp.delta_max)
```

### IP-155 SAC（偿付能力订单准入）

```python
def sac_admit(order, M, beta):
    # C1 安全底线：证书 oracle
    if not safety_floor_feasible(order, M):
        return False
    # C2/C3 偿付与破产
    L_total = beta.L_open + M.liability_model.sample(order, n=N_MC)
    net = L_total - beta.I_cov
    if cvar(net, ALPHA) > beta.R_free - beta.R_buffer:
        plan = reinsurance_plan(order, M, beta)
        if plan is None:
            return False
        beta = beta.with_insurance(plan)
    if ruin_prob(L_total, beta.R_free, beta.I_cov) > beta.delta_ruin:
        return False
    # C4 经济性
    if risk_adjusted_profit(order, M, beta) < 0:
        return False
    # C5 隔离金
    if beta.R_ring < beta.R_ring_min:
        return False
    return True

def sac_negotiate_or_reject(order, M, beta, reason=None):
    """按优先级尝试：重谈 SLA/价格/期限 → 再保险 → 带保修转包 → 拒绝"""
    for proposal in negotiate_space(order):
        if sac_admit(proposal, M, beta):
            return accept(proposal)
    if subcontract_with_warranty_available(order, M):
        return subcontract(order, warranty=True)
    return reject(order, reason=reason)
```

### IP-156 OVPS（实物期权探针调度）

```python
def option_value(probe, M, cp):
    b = M.belief[cp.region]
    v0 = max(value_commit(M, cp), value_defer(M, cp), value_abandon(M, cp))
    # 采样探针观测，计算续行价值
    vals = []
    for o in sample_probe_outcomes(probe, b, n=N_OPT):
        b2 = belief_update(b, o, probe)
        vals.append(max(value_commit(M, cp, b2),
                        value_defer(M, cp, b2),
                        value_abandon(M, cp, b2)))
    return mean(vals) - v0

def ovps_decide(M, cp, result, budget, deadline):
    best, best_p = -inf, None
    for p in admissible_probes(cp, M, budget):
        ov = (option_value(p, M, cp)
              - probe_cost(p, M)
              - budget.lam_E * probe_cost(p, M)
              - budget.lam_R * risk_delta(p, M))
        if ov > best:
            best, best_p = ov, p
    if deadline.forces_commit():
        return 'commit' if value_commit(M, cp) >= value_abandon(M, cp) else 'abandon'
    if best <= 0:
        return 'commit' if value_commit(M, cp) >= value_abandon(M, cp) else 'abandon'
    if value_commit(M, cp) - commit_cost(cp, M) >= best:
        return 'commit'
    return 'probe'
```

### IP-157 IEM（内部证据市场）

```python
def clear_evidence_market(bids, budget, deadline, M):
    # 0/1 背包（预算、延迟、质量）→ LP 松弛取对偶价格
    x = solve_budgeted_knapsack(bids, budget.evidence_left,
                                deadline.remaining, M.quality_floor)
    lam_E, lam_T = recover_dual_prices(bids, x, budget, deadline)
    if budget.is_unconstrained():
        pay = vcg_payments(bids, x)  # 外部性定价
    else:
        pay = second_price_with_pacing(bids, x)
    return MarketResult(x, lam_E, lam_T, pay)

def vcg_payments(bids, x):
    """p_m = 其他投标人在包含 m 时的最优值 − 不包含 m 时的最优值"""
    total = sum(x[m] * bids[m].value for m in bids)
    payments = {}
    for m in bids:
        without = solve_budgeted_knapsack(
            {k: v for k, v in bids.items() if k != m}, INF, INF, 0)
        payments[m] = total - x[m] * bids[m].value - without.value
    return payments
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SLA-POMDP | 在线分层：战略 O(1)，战术 O(\|CP\|·k_rba)，操作 O(H·(\|A\|+CLEP))；离线 POMCP/rollout | O(\|B\|·d_b+\|β\|) | 安全硬掩码、字典序约束、有限预算终止 |
| RPL | O(\|CP\|·d_L)+CVaR O(N log N) | O(N_tail+\|β\|) | 双账本防火墙、风险定价不触碰底线 |
| RBA | O(\|CP\|^2 log(1/ε)) | O(\|CP\|) | `Σδ_i≤δ_sla`、不可逆零预算、欧拉可加性 |
| SAC | O(N_MC)+O(1) 准入 | O(N_MC) | 偿付/破产约束、保险/转包保守回退 |
| OVPS | O(\|A_probe\|·(C_VOI+CLEP)) | O(\|B\|) | 期权价值单调、预算/截止期终止 |
| IEM | 精确 O(2^{\|M\|})；贪心 O(\|M\|log\|M\|) | O(\|M\|) | 预算/延迟/质量约束、对偶价格解释 |
| J_biz | O(1)/订单；审计 O(log n) | O(订单数) | 哈希链追加、引用不修改 J_safety/J_exec |

**正确性定理（Business-Grounded Safety Soundness, BGSS）**
假设 A51–A55（第 59 轮执行接地层）成立，并新增 A56–A62（订单真实性、安全底线不变量、风险模型校准、账本完整性、市场诚实性、执行证书健全、流动性）。则：

1. **安全底线不变量（Safety Floor Invariance）**：对任何被接受的订单/动作，`C_safety` 以至少 `1−δ_floor` 成立，且与 `v, RAP, λ_R, rep` 无关。证明：动作先经 `A_safe` 硬掩码，`C_safety` 在字典序中先于经济目标；商业层无写权限（A57）。
2. **偿付能力（Solvency Soundness）**：在 A58/A62 下，任意滚动窗口内 `Pr(ruin)≤δ_ruin+δ_est+δ_audit`，且 `CVaR_α(L_total−I_cov)≤R_free−R_buffer`。证明：SAC 准入约束 + CVaR 上界 + 审计修正 + 流动性压力测试。
3. **SLA 风险预算健全性（SLA Budget Soundness）**：若每个检查点按 `δ_i` 执行且证书健全，则 `Pr(SLA violation)≤Σ_i δ_i+δ_est≤δ_sla+δ_est`。证明：联合界 + A61；不可逆点 `δ_i=0`。
4. **激励相容与不压制证据（Incentive Soundness）**：在 A59/A60 下，真实报告证据与真实报价的长期收益不低于偏差策略，偏差收益 ≤`ε_IC`，审计/声誉/保费惩罚 ≥偏差收益；`J_biz` 的赔付与信度更新使「省证据」在未来准入与保费中显性化。
5. **终止性（Termination）**：订单/检查点/预算/截止期有限；每个探针消耗 `B_evidence` 或降低不确定性；`OV(p)≤0` 或预算耗尽即停止；故在 `O(k_probe+k_commit+k_renegotiate)` 内终止于 {承诺(带证书), 绕行, 重新谈判, 转包, 安全停, 拒绝}。
6. **部署界（Deployment Bound）**：
```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_xm·1[L1]
                   + δ_ft·1[回滚窗口] + δ_kg·1[检索失败] + δ_ux·1[μ_mis>θ_mis]
                   + δ_exec·1[ξ_exec漂移] + δ_ξ_ood·1[执行OOD] + δ_ertc·1[契约违例]
                   + δ_eeis·1[μ分析漏报])
         − δ_est − δ_audit − δ_liquidity
```
且对任何被接受订单，安全账本另行保证 `P_safe≥1−δ_floor`；商业账本破产不降低该下界。**商业失败可以破产，安全失败不允许。**

**关键推导（风险预算）**：对一次齐次相干风险度量 `ρ`，欧拉分配满足 `Σ_i δ_i ∂ρ/∂δ_i=ρ(L)`；独立失效且用联合界时 `ρ≈Σδ_i`，故按 `RC_i` 比例分配在局部最优；`U_i'(δ_i)=μ` 的水填充是约束优化的 KKT 条件。对相关失效，用条件风险贡献替代边际贡献，避免「把相关性当成独立」的低估。

**关键推导（偿付）**：CVaR 的 Rockafellar–Uryasev 表示给出可计算的凸上界；SAC 用蒙特卡洛/共形上界 `CVaR_α^{UB}` 替代真值，`CVaR_α^{UB}≤R_free−R_buffer` 保证保守性。破产概率用经验分布 + 保守尾部模型估计，并与 CVaR 约束同时使用，防止单点分布估计失效。

**关键推导（期权）**：`OV(p)=E[max(V_c,V_d,V_a)]−max(...)−cost`；由 `E[max]≥max(E)`，不确定性越大、灵活性越有价值，`OV` 越大。当 `OV≤0` 或截止期迫使行权时停止探测，避免无限信息收集。

**消融实验**：
- `−RBA`（均匀预算）：预期 SLA 违例显著上升或证据成本上升。
- `−SAC`（只看经济性）：预期破产概率/尾部赔付超限；安全底线仍由 `C_safety` 保住（验证防火墙）。
- `−OVPS`（固定阈值）：预期探针过多或过少，后悔值上升。
- `−IEM`（均分预算）：预期高价值模态饥饿、分配效率下降。
- `−Firewall`（允许商业层写风险参数）：**必须出现安全违例**——这是反例测试，用于证明防火墙必要性，不作为系统运行模式。

**对抗与压力测试**：
1. **高价值不可逆订单**：`v` 极大、`irr=1`，检查系统是否仍要求人工批准/拒绝，而不是「价格覆盖风险」。
2. **证据压制**：某一模态故意低报失败率，检查 `J_biz` 审计、保费更新与声誉惩罚是否使长期收益下降。
3. **虚报报价**：证据市场投标虚报，检查 `ε_IC` 与审计惩罚。
4. **相关失效**：多个订单共享同一硬件/环境故障，检查 CVaR 组合约束与再保险。
5. **流动性冲击**：`R_free` 骤降、保险延迟赔付，检查 `R_ring` 隔离与停业策略。
6. **截止期挤压**：`λ_T` 升高，检查系统是否用「更少证据 + 更保守动作」而不是「跳过安全门」。

**构造性数值算例（说明用，不是实测）**：
- 风险预算：`δ_sla=10⁻³`，5 点 `RC=[0.40,0.30,0.20,0.10,0]`，第 5 点不可逆未批准。均匀分配每点 `2×10⁻⁴`；RBA 给 `[4,3,2,1,0]×10⁻⁴`，第 5 点必须人工接管/绕行/拒绝。若第 5 点实际风险贡献被低估（相关性），则用条件风险贡献重算，宁可拒绝。
- 偿付：`R_free=100`，`I_cov=500`，`CVaR_99(L)=800`，则 `CVaR(L−I_cov)=300>R_free`；再保险覆盖 `300`、免赔 `50`、保费 `40` 后，净值尾部降到 `≤100`，且 `RAP>0` 才接单；若保费使 `RAP<0`，则谈判或拒绝。
- 期权：探针成本 `10`，承诺失败损失 `500`，探测后避免失败的概率 `0.1`，则 `OV≈0.1×500−10=40>0`，值得探测；若只剩 `1` 秒且 `λ_T=100/秒`，则 `OV≈40−100<0`，直接行权或放弃。

## 6. 本轮最大风险

**一句话**：本轮最大的风险是**制度性套利**——一旦商业激励能够影响风险参数、证据生产或证书定价，组织就会把「安全盈余」逐步做成「安全赤字」，用更松的证书换更高毛利，直到尾部事件一次性清算；双账本、职责分离、硬底线与外部审计是必要防线，但它们本身也可能被权力或流程绕过。
