# 第 66 轮（承接第 65 轮「VISTA 视觉知情故障归因」IP-214~223；本轮灵感：「机器人竞赛」×「通用操作」）

> 第 65 轮用视觉与动作分块把「几何可证伪」升级为「故障可归因」，其自述的最大风险一针见血：**归因依赖「故障属于有限假设集、视觉与几何失效相互独立」；真实故障是未知类型的组合，透明/镜面/对抗会让视觉与几何共享同一个分布外失效源，于是 FIR 把未知复合故障强行塞进最近假设、只膨胀错误的球——系统反而因为「已经归因」而更自信地继续执行。** 本轮不再往「更细的故障分类」里加假设，而是承认这条风险的本质：**如果故障本就不可枚举，那么「归因」不该是终局问题。** 竞赛与通用操作恰好把实验室长期隐藏的三个变量摆到台面上：
>
> **时钟（时间/分数预算）、裁判（稀疏、延迟、可能带偏的外部真值）、开放任务分布（对象与任务无法穷举）。**
>
> 本轮核心命题是：
>
> **把「故障可归因」升级为「能力可审计、风险可预算」：不再问「哪个已知部件坏了」，而问「我此刻在哪个区域有资格做、这次尝试值不值得、什么时候该收手保分」；用竞赛的裁判信号给证书做外部校准，用能力组合替代单一通才。**

## 0. 直觉与动机

**灵感 1（机器人竞赛 → 被实验室隐藏的三件事）**
直觉：比赛不是「更难一点的测试集」，而是一种**制度**。它同时给了三样实验室里没有的东西：(i) **时钟**——固定时长、按成功得分、按违规罚分，于是「多试一次」和「稳一点」有了明确的机会成本；(ii) **裁判**——一个独立于机载传感器的外部判定者，它的成功/失败/罚分是稀疏、延迟、低频但**语义上真**的信号；(iii) **隐藏任务与对手**——赛题公开但具体实例与评测权重不公开，且其他队伍/环境会改变分布。严格地说，竞赛把一个「安全控制问题」变成了「**带外部审计与时间预算的风险决策问题**」：目标函数从「不越界」变成「在罚分约束下最大化期望得分」，而信息结构里多了一条**低频外部标签通道**。

**灵感 2（通用操作 → 单一通才不是答案，能力是有边界的）**
直觉：一个「通用操作大模型」在开放对象上必然有大量它**没见过**的角落；继续堆参数只能把边界推远，不能消除边界。真正可部署的通用性不是「什么都会」，而是「**知道自己会在哪、不会在哪，不会时能安全地退**」。严格地说，通用操作 = 能力库的**运行时组合**：每个能力有一块被验证过的操作设计域（ODD），组合的合法性取决于这些区域的交与并；「新异」不是故障，而是「落在所有已验证区域之外」。所以第 65 轮的闭集归因（几何/力/模型/视觉/策略）必须前置一个**开集问题**：这到底是不是我认识的世界？

**灵感 3（竞赛 × 通用 → 教练，而不是球员）**
直觉：面对开放世界和计时赛制，我们最缺的不是更强的球员，而是一个**教练**。教练不亲自上场造球，他做四件事：**排兵**（谁上）、**换人**（回退/组合）、**看表**（时间与比分）、**听哨**（裁判）。这四件事恰好对应四个被 VISTA 忽略的决策层：
- 排兵 = 能力路由：给定任务嵌入，选哪个能力；
- 换人 = 组合与回退：能力失效/超域时切到哪一层；
- 看表 = 风险预算与最优停止：这一杆打不打、何时保分；
- 听哨 = 外部审计：用裁判结果校准每个能力的「战绩」。

严格地说，COACH 不是一个新策略，而是一个**元决策层**：它的输入是「任务嵌入 + 能力证书 + 比赛状态 + 裁判历史」，输出是「路由 + 尝试/放弃 + 时间分配 + 证书修正」。

**灵感 4（反直觉主张 → 证书必须能被裁判打脸）**
直觉：第 65 轮的证书链全是**内部一致性**：只要各层验证通过，就输出 Valid。但一张从没被外部检验过的证书，和免责声明没有区别。竞赛提供了一个廉价的外部校准器：证书说「这个区域成功率 ≥0.9」，就用裁判在该区域的实测成功率检验它。严格地说，把证书当作**可证伪预测**而不是**通过/不通过的布尔**：定义校准误差 ECE_i = |预测成功率 − 裁判实测成功率|，并把它写进证书。**一张不可被校准的证书是空洞的（vacuous）**；这比再多加一层内部验证更能对冲 VISTA 的「归因自信」风险。

**灵感 5（合流 → COACH：Competition-aware Open-set Adaptive Competence Hierarchy，竞赛感知的开集自适应能力层级）**
闭环：任务/物体嵌入 z → 开集新异检测 OSN（先问「认不认识」）→ 能力区域估计 CRE（每个能力被验证过的 ODD）→ 组合路由 SUB（排兵）→ 计时尝试证书 TCA（这一杆打不打、打几步、何时停）→ 比赛级规划 PPL（时间怎么分、何时保分）→ 执行 → 裁判审计 EAC（听哨）→ 慢速校准能力证书与先验 → 对抗认证 AIC-C。VISTA 是「已知世界里哪一环坏了」；COACH 在它前面加「这是不是已知世界」，在它后面加「值不值得继续、这张证书可不可信」。

**灵感 6（VISTA 组件的原位升级）**
- **FIR → OSN/OSFIR**：先做开集新异检测；只有落在已知区域内才调用 VISTA 的闭集归因，否则进入「未知」分支与能力回退阶梯。
- **CSC → TCA**：承诺单位从「步」提升到「一次尝试」；证书含时长、成功下界、罚分风险、机会成本与截止时间。
- **AFA → SCP**：探针目标从「降低故障假设熵」升级为「扩张/确认能力区域 + 降低比分方差」；时钟紧时从「侦察」切回「利用」。
- **RSC-V → RSC-C**：不确定半径增加「能力区域外」分量 r_comp；新异只膨胀 r_comp，不误伤几何。
- **WCV-V → WCV-C**：鲁棒编译的搜索域增加「能力 ODD 约束」与「比赛状态约束」。
- **CSP-V → PPL**：从块级技能规划升级为「技能选择 + 时间分配 + 保分」的随机调度/背包问题。
- **AIC-V → AIC-C**：干扰集增隐藏任务分布、裁判噪声/偏置、对手挤占与时间抖动。
- **J_vista → J_coach**：证书增 competence_id、odd_hash、novelty_pvalue、match_state、attempt_schedule、referee_audit_ver、calib_error。

## 1. 形式化定义（增量：定义 233–248）

- **定义 233（COACH 闭环）**：COACH = (GRIP, VISTA, CL, CRE, OSN, SUB, TCA, PPL, SCP, RSC-C, EAC, AIC-C, J_coach)。定位：VISTA 的「开放世界 + 时间预算 + 外部审计」升级。不变式：**新异校准、能力学习、裁判审计、组合规划只在语义流；实时流只做路由查表、认证尝试执行、截止/早停与比分时钟更新，零学习写操作。**
- **定义 234（任务嵌入与能力库）**：任务嵌入 z = φ_task(o, g) ∈ ℝ^{d_z}（物体/场景/指令）。能力库 CL = {c_i = (π_i, ODD_i, cert_i)}，含一个通才 π_0 与若干专才；每个能力 i 有被验证的操作设计域 ODD_i ⊆ ℝ^{d_z}，以及证书 cert_i。
- **定义 235（能力区域与能力证书）**：用 conformal 由标定集估计能力 i 的能力区域 R_i = {z : s_i(z) ≤ q_i(α_comp)}（s_i 为「在该 z 上能否成功」的非一致性分数），并按区域给出成功率下界 p_i^-、代价 c_i、风险 (罚分) L_i、版本 ver。R_i 是 ODD_i 的**可证伪代理**：只有落在 R_i 内才允许以证书宣称成功率。
- **定义 236（开集新异检测 OSN）**：给定 z 与全部 R_i，定义新异分数 s_nov(z) = min_i dist(z, R_i) 与 conformal p 值 p_nov(z)。三态判定：**in-domain**（∃i，p_nov 足够大且 z∈R_i）、**near-domain**（在边界 ε 带内，可探测）、**out-of-domain**（p_nov < α_nov，判未知）。显式声明：conformal 只在可交换性下给覆盖；隐藏任务分布可破坏可交换性，此时 OSN 的保证降级为**经验风险**而非分布无关界。
- **定义 237（裁判审计通道 EAC）**：裁判在事件 k 输出稀疏延迟标签 r_k ∈ {success, fail, penalty, invalid}，延迟 d_k，观测噪声/偏置用混淆矩阵 C_ref 建模。EAC 只做三件事：(i) **慢校准**能力证书的 p_i^-；(ii) 用 bandit/off-policy 给能力选择做信用分配；(iii) 维护证书的外部校准误差 ECE。**裁判信号绝不进入实时控制环**，避免高频误用低频标签。
- **定义 238（比赛状态与风险预算）**：比赛状态 m_t = (剩余时间 τ, 当前得分 s, 分差 Δ, 得分不确定度 σ_s, 阶段 phase)。风险预算 B_t 为允许的期望罚分。目标从「安全」改为「罚分约束下的期望得分」：Score = Σ 成功分 − λ_pen·罚分 − λ_time·超时损失。
- **定义 239（计时尝试证书 TCA）**：把 CSC 的「前缀 k 步」提升为「一次尝试」a，携带时长 T_a、成功下界 p_a^-（来自 cert 与 TCA 的 conformal 复合）、罚分风险 L_a、机会成本 c_time。TCA 验证：对归因后验支持集与能力区域约束，尝试全程 ρ_safe ≥ 0，且截止时间内可中止；输出**尝试计划** (a, deadline, abort_cond) 而非仅 k*。执行到 deadline 或 abort 即强制重规划与重审计。
- **定义 240（最优停止与保分）**：设尝试成功收益 G、失败罚分 L、继续价值 V_cont(m_t)。在风险中性下，尝试的充要条件为 p̂_a ≥ p*(m_t) = (V_cont + c_time + L)/(G + L)。p* 随 τ 减小、随分差 |Δ| 增大而下降（落后且时间少时必须赌），随领先优势增大而上升（此时应保分）。这是「看表」的严格形式：**保分不是保守，而是当继续价值低于尝试的失败成本时的最优动作。**
- **定义 241（能力组合路由 SUB）**：c* = argmax_{c_i} [ p_i(z, m)·G_i − (1−p_i)L_i + β·OptionValue_i ]，s.t. z ∈ ODD_i（或显式探索预算）、c_i ≤ B_t、且 TCA 可行。若没有可行能力，进入**回退阶梯** (safe_idle → 降级能力 → 求助人 → 放弃并保分)，阶梯本身也带证书。
- **定义 242（能力区域定向校准 RSC-C）**：不确定半径增为 r = √(r_geo² + r_force² + r_model² + r_comp²)，其中 r_comp 刻画「能力区域外」的不确定。新异 → 只膨胀 r_comp；某能力被判罚 → 只膨胀该能力（及其近邻）的 r_comp；几何/力/模型故障仍按 VISTA 定向膨胀。避免把「我不认识这个任务」误记成「几何坏了」。
- **定义 243（侦察式能力探测 SCP）**：探针目标从「故障假设熵」升级为「能力区域信息 + 比分方差」：
  a* = argmax_a [ I(能力区域; ρ(a)) + λ·ΔV(m_t, a) ]，s.t. 预测力/形变/时长安全且不超时。时钟紧或分差大时 λ 主导（利用），时钟松且新异高时信息项主导（侦察）。易损物体仍禁用接触探针。
- **定义 244（比赛级组合规划 PPL）**：在任务图/尝试图上做随机调度：在总时长约束下选择尝试子集与顺序、分配时间、决定保分点，最大化期望总分（含截止期与罚分）。这是带截止期的随机背包/调度问题；用滚动时域重规划，保分（停止）是一个显式动作。
- **定义 245（AIC-C 竞赛对抗认证）**：干扰集 ℰ_C = ℰ_V × ℰ_hidden × ℰ_ref × ℰ_opp，ℰ_hidden 为隐藏任务分布漂移，ℰ_ref 为裁判噪声/偏置/延迟，ℰ_opp 为对手挤占、遮挡与时间竞争。认证对象从「安全」扩为「**证书校准**」：在最坏干扰下要求 ECE ≤ ε_cal，且覆盖率不被高估。
- **定义 246（证书的外部校准性）**：对能力 i，令预测成功率 p_i^- 与裁判实测成功率 p̂_i^ref 在共同区域上的差为 ECE_i。定义 **Valid_external(cert_i) ⇔ ECE_i ≤ ε_cal 且区域覆盖计数 n_i ≥ n_min**。未校准（n_i < n_min）的证书标为 `vacuous`，不得单独用于高风险路由。证书由此成为可被裁判打脸的预测。
- **定义 247（J_coach 证书）**：J_coach = (J_vista, competence_id, odd_hash, novelty_pvalue, match_state, attempt_schedule, referee_audit_ver, calib_error, fallback_ladder)。Valid ⇔ Valid(J_vista) ∧ (z ∈ ODD_{c*} ∨ 显式声明探索) ∧ TCA 认证尝试可行 ∧ 回退阶梯逐级可用 ∧ (可获裁判信号时 ECE ≤ ε_cal，否则标 `uncalibrated`)。
- **定义 248（COACH 闭环算子）**：语义流 [LiDAR→LSF→USR/MEL→任务嵌入 φ_task→OSN 开集判定→CRE 能力区域→SUB 路由→TCA 尝试证书→PPL 比赛级调度→VISTA 执行尝试→EAC 裁判事件→能力证书慢校准→SCP 侦察→RSC-C→AIC-C]；实时流 [路由查表→执行认证尝试→deadline/abort 早停→比分与时钟更新→回退阶梯→J_coach 构建]。

## 3. 保证概要与推导要点（完整推导见产物区）

- **命题 9（开集不可约风险）**：任何仅依赖有限标定集的新异检测，对**可被对抗选择的隐藏任务分布**都不存在非平凡的分布无关漏检界。故 COACH 不宣称「保证认识所有任务」，只宣称 (i) 在可交换性下 OSN 的边际覆盖 ≥1−α_nov；(ii) **一旦判 out 必走带证书的回退阶梯**。这把 VISTA 的「未知被强行归因」替换为「未知被显式承认并降级」。
- **定理 9（尝试级最优停止的阈值最优性）**：在风险中性、尝试收益/罚分有界、剩余选项价值随 τ 单调的假设下，最优策略为阈值策略：当且仅当 p̂ ≥ p*(m_t) 时尝试；p* 关于 τ 单调不增、关于领先分差单调增。故「保分/梭哈」不是启发式，而是动态规划的解。
- **定理 10（组合相对通才的占优）**：若路由误差 ≤ ε、各专才在其 ODD 内相对通才的成功率增益 ≥ Δ_i，且失败代价一致，则组合的期望得分 ≥ 通才 − ε·L_max，且当 Σ_i P(z∈ODD_i)·Δ_i > ε·L_max 时严格占优。故「通用」的正确实现是**带边界的能力组合**，而非单一模型。
- **定理 11（证书校准的必要性）**：只做内部一致性验证的证书，其宣称成功率与真实成功率之差可被隐藏任务分布任意放大；故任何「Valid 即安全」的论证在开放世界不成立。必须报告**覆盖率与校准误差**，否则证书是空洞的。

## 5. 本轮最大风险

## 2. 形式化定义（完整版）

**定义 233（COACH 闭环）** COACH 是 VISTA 的「开放世界 + 时间预算 + 外部审计」升级：在 VISTA 的语义流/实时流骨架上**前置** OSN（开集新异）与 CRE（能力区域），**横切** SUB（路由）、TCA（尝试证书）、PPL（比赛级调度）、SCP（侦察探针）、EAC（裁判审计），并原位升级 RSC-V→RSC-C、WCV-V→WCV-C、AIC-V→AIC-C、J_vista→J_coach。不变式：**新异校准、能力学习、裁判审计、组合规划只在语义流与低频线程；实时路径只做路由查表、认证尝试执行、截止/早停、比分时钟更新与回退阶梯，零学习写操作。**

**定义 234（任务嵌入与能力库）** 任务嵌入 z = φ_task(o, g) ∈ ℝ^{d_z} 由物体、场景与指令编码得到。能力库 CL = {c_i = (π_i, ODD_i, cert_i)}_{i=0}^{N}，其中 π_0 为通才策略（覆盖广、单项平庸），π_{i>0} 为专才（在窄域内更强）。每个能力附带操作设计域 ODD_i（设计者声明 + 数据覆盖共同给出）与证书 cert_i。**能力库不是技能树，而是「有战绩的球员名册」。**

**定义 235（能力区域与能力证书）** 对能力 i，用标定集 D_i 定义非一致性分数 s_i(z)（例如「在 z 邻域内执行 π_i 的失败预测残差」或「z 到最近成功样本的度量距离」）。取 q_i(α_comp) 为 s_i 的 ⌈(n+1)(1−α_comp)⌉/n 分位数，能力区域
R_i = {z : s_i(z) ≤ q_i(α_comp)}。
在可交换性下，P[z ∈ R_i] ≥ 1−α_comp（边际覆盖）。证书
cert_i = (p_i^-, R_i, c_i, L_i, n_i, ver_i)，
其中 p_i^- 为成功率下界（Wilson/Clopper-Pearson 或 conformal 风险控制），n_i 为区域覆盖计数，L_i 为该能力失败的罚分风险。R_i 是 ODD_i 的**可证伪代理**：只有 z∈R_i 才允许以证书宣称 p_i^-。

**定义 236（开集新异检测 OSN）** 给定 z 与 {R_i}，新异分数 s_nov(z)=min_i dist(z,R_i)，并用标定集构造 conformal p 值 p_nov(z)。三态判定：
- **in-domain**：∃i 使 z∈R_i 且 p_nov(z) ≥ α_nov，且该区域证书未标 `vacuous`；
- **near-domain**：min_i dist(z,R_i) ≤ ε_nov 但 p_nov 未过阈，或能力区域冲突；
- **out-of-domain**：p_nov(z) < α_nov，判未知。
**显式声明**：conformal 覆盖只在可交换性下成立；隐藏任务分布可破坏可交换性，故 OSN 的 out-of-domain 保证降级为**经验风险控制**，不得宣称分布无关漏检界（命题 9）。OSN 的职责不是「保证认识一切」，而是「**在不确定时把决定权交给回退阶梯**」。

**定义 237（裁判审计通道 EAC）** 裁判在事件 k 给出稀疏延迟标签 r_k∈{success, fail, penalty, invalid}，延迟 d_k，并用混淆矩阵 C_ref 建模噪声与偏置（例如人工裁判对「勉强成功」的宽严不一）。EAC 只做三件事，且全部在低频：
1. **慢校准**：用 r_k 更新 cert_i 的 p_i^- 与覆盖计数 n_i（贝叶斯/滑动窗口）；
2. **信用分配**：把 r_k 归到当时的 (c_i, z) 上，做 contextual bandit / off-policy 更新路由先验；
3. **外部校准审计**：维护 ECE_i 与可靠度曲线，写进 J_coach。
**裁判信号绝不进入实时控制环**：低频、延迟、可能带偏的标签若进入高频闭环，会引入比 VISTA 的 F/T 偏置更隐蔽的「制度偏置」。

**定义 238（比赛状态与风险预算）** 比赛状态 m_t=(τ, s, Δ, σ_s, phase)，τ 为剩余时间，s 为当前得分，Δ 为与目标/对手的分差，σ_s 为得分不确定度，phase 为准备/主赛/加时。风险预算 B_t 为允许的期望罚分。目标：
max E[Σ 成功分 − λ_pen·罚分 − λ_time·超时损失]，s.t. E[罚分] ≤ B_t。
这把第 65 轮的「安全约束满足」变成「**安全作为预算、得分作为目标**」。

**定义 239（计时尝试证书 TCA）** 一次尝试 a = (π_c, T_a, p_a^-, L_a, deadline, abort)：
- π_c 为被路由能力的策略；
- T_a 为预计时长；
- p_a^- 为成功下界，由 cert_c 的区域成功率与 TCA 的 conformal 复合给出；
- L_a 为失败/罚分风险上界；
- deadline 为最晚可中止时刻；
- abort 为实时中止谓词（力/滑移/超时/裁判提前判负）。
TCA 的验证沿用 CSC 的 ρ_safe，但把「逐步前缀」替换为「**尝试全程 + 截止期**」：∀H∈supp_δ(post)、∀t≤T_a，ρ_safe(t)≥0，且 deadline ≤ 不可逆视界 m。输出尝试计划而非仅 k*。执行到 deadline 或 abort，强制重规划、重归因、重校准。

**定义 240（最优停止与保分）** 设尝试成功收益 G、失败罚分 L、耗时成本 c_time、继续价值 V_cont(m_t)（若不打这一杆，用剩余时间做别的事的期望得分）。风险中性下尝试的期望净收益
EU(a) = p_a G − (1−p_a)L − c_time − V_cont。
EU(a) ≥ 0 ⇔ p_a ≥ p*(m_t) = (V_cont + c_time + L)/(G + L)。
性质：p* 关于 τ 单调不增（时间越少，机会成本越低，越该赌）；关于领先分差 Δ 单调增（领先时应保分）；关于 σ_s 单调（不确定高时更依赖期望）。**保分（bank）不是保守，而是当 EU<0 时的最优动作**；落后且 τ→0 时 p*→(L)/(G+L)，即「只要成功率高于失败代价比就值得梭哈」。

**定义 241（能力组合路由 SUB）** 给定 z、m_t、post（若走 VISTA），
c* = argmax_{c_i} [ p_i(z, m_t)·G_i − (1−p_i(z,m_t))·L_i + β·OptionValue_i ]，
s.t. z ∈ ODD_i（或显式探索预算 ε_explore）、c_i ≤ B_t、TCA 可行、回退阶梯可用。
OptionValue 表示「用这次尝试换取能力区域信息的价值」，β 随 τ 减小而减小（时钟紧时不为信息付溢价）。**可行性优先于最优性**：若 argmax 不可行，按**回退阶梯**逐级下降：
`safe_idle`（不动作、保分）→ 降级能力（更保守参数）→ 求助人（语言/遥操作）→ 放弃并保分。
阶梯每一级都带自己的证书与耗时上界，且阶梯本身在语义流预编译。

**定义 242（能力区域定向校准 RSC-C）** 维护 r_geo、r_force、r_model（VISTA）与新增 r_comp（能力区域不确定），以及 w_vis。新异或跨域失败 → **只膨胀 r_comp**，不动 r_geo/r_force/r_model；VISTA 已归因的几何/力/模型故障仍按原规则定向膨胀。融合半径
r = √(r_geo² + r_force² + r_model² + r_comp²)。
这避免把「我不认识这个任务」误记成「几何坏了」，也避免第 65 轮「任何异常都怀疑接触层」的过度保守。

**定义 243（侦察式能力探测 SCP）** 探针集 A={visual_probe, null_test, micro_press, reorient, ask_human}。选择
a* = argmax_{a∈A} [ I(能力区域; ρ(a)) + λ·ΔV(m_t, a) ]，
s.t. 预测力/形变/时长安全、不超时、不触发罚分。第一项是「这次探测能把 R_i 的边界收窄多少」，第二项是「它能多快把比分不确定性降下来」。时钟紧或分差大时 λ 增大（**侦察→利用**）；新异高且领先时信息项主导（**利用→侦察**）。易损物体仍禁用接触探针；裁判不可探测（不能主动问裁判要答案）。

**定义 244（比赛级组合规划 PPL）** 在尝试图/任务图上做随机调度：选择尝试子集 S 与顺序 σ，分配时间 {T_a}，选择保分点，最大化
E[Σ_{a∈S} (p_a G_a − (1−p_a)L_a) − λ_time·超时]，
s.t. Σ T_a + 缓冲 ≤ τ，且每条边 Valid(J_coach)。这是带截止期的随机背包/调度问题；用滚动时域重规划（receding horizon），**保分（停止）是图中的显式边**，不是隐式的超时。

**定义 245（AIC-C 竞赛对抗认证）** 干扰集
ℰ_C = ℰ_V × ℰ_hidden × ℰ_ref × ℰ_opp，
ℰ_hidden 为隐藏任务分布漂移（实例、权重、初始条件），ℰ_ref 为裁判噪声/偏置/延迟，ℰ_opp 为对手挤占、遮挡与时间竞争。认证对象从「安全」扩展为「**证书校准**」：在最坏干扰下要求 ECE ≤ ε_cal，且覆盖率不被高估。ρ_dir 在 ℰ_C 上重算，n_cert 由 128 增至 160（其中 32 给隐藏任务/裁判/对手）。**共因与盲区下不要求归因正确，只要求被显式标为 vacuous 并安全降级。**

**定义 246（证书的外部校准性）** 对能力 i，令 p_i^- 为证书宣称的区域成功率，p̂_i^ref 为裁判在共同区域（z∈R_i 且被实际执行过）的实测成功率，则
ECE_i = |p_i^- − p̂_i^ref|。
定义
Valid_external(cert_i) ⇔ ECE_i ≤ ε_cal ∧ n_i^ref ≥ n_min。
未达 n_min 的证书标 `vacuous`，**不得单独用于高风险路由**（只能用于低风险/探索）。证书由此从「内部通过的布尔」变成「可被裁判打脸的预测」；一张永远不被执行的证书自动暴露为 vacuous——这是对 VISTA「归因自信」的制度性对冲。

**定义 247（J_coach 证书）** 
J_coach = (J_vista, competence_id, odd_hash, novelty_pvalue, match_state, attempt_schedule, referee_audit_ver, calib_error, fallback_ladder)。
Valid(J_coach) ⇔ Valid(J_vista)
∧ (z ∈ ODD_{c*} ∨ 显式声明探索预算)
∧ TCA 认证尝试可行（∀ 支持集假设，尝试全程 ρ_safe≥0，deadline≤m）
∧ 回退阶梯逐级可用且各自证书有效
∧ (可获裁判信号 ⇒ ECE ≤ ε_cal；否则显式标 `uncalibrated` 并降级)
∧ aic_c_ver 为当前版本。
审计链新增：**为什么选这个能力（ODD/novelty）、为什么现在打（m_t/p*）、为什么敢承诺（TCA）、这张证书被裁判校准过吗（ECE/vacuous）、退路是什么（fallback_ladder）。**

**定义 248（COACH 闭环算子）** 语义流：[LiDAR→LSF→USR/MEL→φ_task 任务嵌入→OSN 开集判定→CRE 能力区域→SUB 路由→TCA 尝试证书→PPL 比赛级调度→VISTA 执行尝试（含 VPG/VCV/FIR/CSC）→EAC 裁判事件→能力证书慢校准→SCP 侦察→RSC-C→AIC-C]。实时流：[路由查表→执行认证尝试→deadline/abort 早停→比分与时钟更新→回退阶梯→J_coach 构建]。定位：VISTA 是「已知世界内部的故障归因」，COACH 在其前后各加一层——**前加开集承认，后加价值判断与外部校准**。

### IP-224/225 CIL/CRE + OSN（能力区域与新异）

```python
class CompetenceInventory:
    """每个能力一块 conformal 能力区域；R_i 是 ODD 的可证伪代理。"""
    def __init__(self, alpha_comp=0.1):
        self.certs = {}                     # i -> dict(p_minus, R, cost, L, n, ver, vacuous)
        self.alpha_comp = alpha_comp

    def fit_region(self, i, calib_scores):
        q = conformal_quantile(calib_scores, self.alpha_comp)
        self.certs[i]['R'] = lambda z: score_i(z, i) <= q
        self.certs[i]['q'] = q

    def update_from_referee(self, i, z, r_k, C_ref):

        self.certs[i]['n'] += 1

            self.certs[i].get('successes', 0) + ref_success(r_k, C_ref),
```

```python
def route(cl, z, m_t, post, beta, eps_explore=0.05):
    nov = osn.classify(z, cl)
    if nov == 'out':
        return cl.fallback_ladder(z, m_t)          # 不归因、不硬执行
    cands = []
    for i, c in cl.certs.items():
        if not (z in c['R']):
            if nov != 'near' or random() > eps_explore:
                continue
        p = c['p_minus'] if not c['vacuous'] else c['p_minus'] * 0.5
        ev = p * G(c) - (1 - p) * c['L'] + beta * option_value(c, z)
        cands.append((ev, i))
    if not cands:
        return cl.fallback_ladder(z, m_t)
    return max(cands)[1]


def match_plan(cl, m_t, tasks, alpha):
    """滚动时域：尝试子集 + 顺序 + 时间分配；保分是显式动作。"""
    plan, tau_left = [], m_t.tau
    for z in rank_by_expected_value(tasks, m_t):
        c = route(cl, z, m_t, post=None, beta=beta(m_t))
        a = tca.certify_attempt(c, z, post=default_post(), deadline_cap=tau_left)
        if a is None:
            continue
        p = a.p_minus
        if p < tca.threshold(m_t, G(c), c['L'], c['cost'], V_cont(tasks, tau_left)):
            break                                  # 保分
        plan.append(a); tau_left -= a.T_a
        if tau_left <= reserve(tasks):
            break
    return plan
```

```python
class RefereeAuditChannel:
```

## 4. 推导

**命题 9（开集不可约风险）** 设标定集来自分布 P_0，隐藏任务来自 P_hidden。任何仅依赖 P_0 有限样本的新异检测器，对可被对抗选择的 P_hidden，都不存在非平凡的分布无关漏检界：对任意 ε>0，存在 P_hidden 使漏检率 >1−ε 而检测器输出不变。**证明要点**：把 P_hidden 的质量集中到标定集支撑的 ε-邻域内但在 R_i 之外；任何基于 P_0 的经验分数在该处取值与域内几乎相同（连续性），故检测器不可分。因此 COACH **不宣称**「保证认识所有任务」，只宣称：(i) 可交换性下 OSN 边际覆盖 ≥1−α_nov；(ii) 一旦判 out，**必走带证书的回退阶梯**（定义 241），把「未知被强行归因」替换为「未知被显式承认并降级」。∎

**定理 9（尝试级最优停止的阈值最优性）** 设尝试成功率 p 已知、成功收益 G、失败罚分 L、耗时成本 c_time、继续价值 V_cont；假设 p 的后验与 m_t 满足单调似然比（MLR），且 V_cont 关于 τ 有界。则动态规划的最优策略是阈值策略：尝试 ⇔ p ≥ p*(m_t)=(V_cont+c_time+L)/(G+L)，且 p* 关于 τ 单调不增、关于领先分差Δ单调增。
**证明要点**：尝试的净收益 EU=pG−(1−p)L−c_time−V_cont 关于 p 线性递增，故对每个 m_t 存在唯一阈值；保分使收益固定为 V_cont，二者比较即得阈值。τ 减小降低 V_cont（可用于其他尝试的机会变少），故 p* 下降；领先Δ增大提高保分的相对价值（保住领先的效用增加），故 p* 上升。MLR 保证阈值集合是区间，策略不会抖动。∎

**定理 10（组合相对通才的占优）** 设路由把 z 分给能力 r(z)，专才 i 在 z∈ODD_i 内相对通才的成功率增益 Δ_i ≥ 0、失败罚分相同、路由误差 P(r(z)∉ODD_{r(z)}) ≤ ε。则组合的期望得分
E[S_comb] ≥ E[S_gen] + Σ_i P(z∈ODD_i)Δ_i − ε·L_max。
当 Σ_i P(z∈ODD_i)Δ_i > ε·L_max 时组合严格占优。
**证明要点**：对域内样本按增益累加；对路由出错样本，最坏损失不超过 L_max，按 ε 折算。∎ 这给出「通用操作 = 带边界的能力组合」的定量理由：**只要边界估计（ODD/R_i）比随机猜测好，组合就能赢过单一通才**；反之若路由误差大到 εL_max 吞掉全部增益，则退回通才/保守回退。

**定理 11（证书校准的必要性）** 只做内部一致性验证的证书，其宣称成功率 p^- 与真实成功率 p^true 之差可被隐藏任务分布任意放大；因此「Valid ⇒ 安全/成功」在开放世界不成立。
**证明要点**：内部验证只约束证书各层之间的一致性（J_grip/J_vista 的合取），不约束 z 的分布。取 P_hidden 把质量移到内部验证不检查的 FailureMode 上，p^true 可任意低而所有内部检查仍通过。故必须报告**覆盖率 n_i** 与**校准误差 ECE_i**（定义 246）；未校准证书标 vacuous。∎

**命题 10（保分与梭哈的相变）** 在定理 9 的阈值 p*(m_t) 下，令 τ→0 且 Δ<0（落后），则 p*→L/(G+L)：**只要成功率高于「失败代价占总赌注的比例」就应梭哈**；令 Δ>0 且 τ 充足，则 V_cont 高、p*→1：**领先且时间足够时应保分**。二者之间的切换由 (τ, Δ) 的符号结构决定，而非固定保守系数。∎

## 8. 已知风险

**一句话**：COACH 的全部「可审计」承诺最终都落在开集新异检测与裁判信号上，而**未知-未知没有分布无关的界，竞赛的隐藏任务分布又可以恰好落在新异检测与能力区域的共同盲区里**——此时系统会「看起来被审计过」（有 ODD、有 ECE、有证书）却恰恰在执行最危险的超域动作，形成**证书剧场（certificate theater）**；这是本轮所有路由、尝试证书与外部校准论证共同依赖的隐藏假设。

**次级风险与缓解**：
1. **未知-未知不可界**：命题 9 已显式承认；缓解：不宣称覆盖，只宣称「out 必降级」；用多通道新异（视觉/语言/本体）降低单通道盲区；持续扩充能力库。
2. **裁判噪声/偏置/延迟**：低频标签进入校准会引入制度偏置；缓解：C_ref 去偏、延迟对齐、ECE 监控、裁判信号绝不进实时环；裁判不可主动探测。
3. **近域误判（near→in）**：边界样本被误路由；缓解：near 一律先侦察/低风险执行，探索预算 ε_explore 有上限，失败即回退。
4. **ODD 过窄→过度保守**：排名受损；缓解：α_comp 按赛制调优，允许低风险域外探索，用 OptionValue 显式定价。
5. **保分/梭哈策略抖动**：阈值随 m_t 抖动；缓解：MLR 条件 + 滞回带，避免在阈值附近反复横跳。
6. **能力库组合爆炸**：路由候选过多；缓解：按嵌入聚类预筛 top-k，ONNX/量化加速，实时只查表。
