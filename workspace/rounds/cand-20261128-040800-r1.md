### 第 5 轮灵感驱动研究记录

**灵感词**：基准测试、示教学习

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点（3DCF/MSRG/HICK/EEK/LTEM/FFA）之上追加价值锚 VACK 与平衡锚 BCK，形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，软评分 ECS_v4 = ECS_v3·η_val·η_bal，执行集嵌套 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ … ⊆ Exec_v29。本轮不推翻 v4，而是补上它未回答的两个「元证据」问题：**(i) 我们用来铸造规则的测量协议本身是否有效？(ii) 规则背后的行为先验是否有示教数据的因果支撑？** 由此形成 CADVS-v5（IP-493~496），新增基准有效性锚 BVK 与示教支撑锚 DPK，并在 EFA-v5 中增加一个交叉校准元门 kc_cross；执行集继续收缩为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。关键结构决策：两道新锚只作用于**规则准入/慢时域**，不进入 1 kHz 控制环，从结构上回避 v4 的最大风险（实时性）。

**直觉与动机**：

1. **基准测试：从「分数」回到「测量仪器」**。v4 的七锚点都在问「证据够不够」，却没有问「产生证据的测量协议本身是否有效」。一个基准分数至少受五种偏差污染：(a) **代表性偏差**——基准分层没有覆盖部署分布（新物体、新位姿、新接触模式）；(b) **污染/泄漏**——训练集与测试集重复、答案泄漏、排行榜过拟合；(c) **统计功效不足**——样本量小、任务间相关导致有效样本 n_eff 远小于名义 n，置信区间宽到无法区分好坏规则；(d) **构念效度失配**——基准指标（如抓取成功率）与真实部署目标（安全、长期可用、人类价值）相关性低；(e) **对抗脆弱**——标准划分上很好，对抗/held-out 划分上崩溃。引入**基准有效性证书 BVC**，把「基准分数」升级为「带校准误差的测量」；硬门 kc_bench 要求基准在代表性、无污染、统计功效、构念效度、对抗鲁棒五个维度同时达标，否则 fail-closed。让「证书通过」多问一句：**这个分数，是用一把校准过的尺子量出来的吗？**

2. **示教学习：从「轨迹复制」回到「行为先验的因果溯源」**。示教数据不是中性的样本，它带有来源、质量、覆盖与因果结构。行为克隆可以在演示集上损失极低，却学到**因果混淆**（copycat）：把与动作无关的 nuisance 特征（背景纹理、操作者手速、光照）当成动作原因，一旦部署时这些特征变化就失效；稀疏示教还会让策略在未见状态上无支撑地外推；次优/多模态示教则把错误偏好写进规则。引入**示教支撑证书 DSC**，显式记录演示来源链、状态-动作支撑覆盖、示教质量、因果充分性与示教-部署漂移；硬门 kc_demo 要求五者同时达标。让「证书通过」再问一句：**这条规则的行为依据，真的来自可迁移的因果结构吗？**

3. **双锚对偶与交叉校准**。基准锚是**评价侧**证据：规则在一个测量协议下是否表现良好；示教锚是**生成侧**证据：规则所依赖的行为先验是否有数据支撑与因果根据。二者对偶，类似因果推断中的「测量效度」与「处理效度」。仅有基准锚会奖励「会考试」的规则；仅有示教锚会奖励「会模仿」的规则。EFA-v5 因此增加一个**交叉校准元门 kc_cross**：在一组双方都有独立信号的 canary 任务上，若基准通过/拒绝与示教通过/拒绝的符号不一致率超过阈值，则拒绝并转人工复核。交叉门不是新锚点，而是对两个锚点「是否在测量同一件事」的元检查。

4. **为什么与泛化锚不重复**。泛化锚（若后续引入）回答「经验风险到部署风险的上界」；基准锚回答「经验风险本身是否被正确测量」；示教锚回答「规则的行为先验是否被正确归因」。三者分别对应**测量、推断、外推**：测量错了，泛化界再紧也只是「精确地错误」；归因错了，示教损失再低也只是「高效地模仿错误」。

**关键洞见**：v4 的七锚点回答「证据是否充分（sufficient）」；v5 的基准锚回答「证据是否被正确测量（valid measurement）」，示教锚回答「证据是否被正确归因（causal attribution）」。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_bench ∧ kc_demo，外加交叉校准元门 kc_cross；软评分 ECS_v5 = ECS_v4·η_bench·η_demo·η_cross。新门全部位于准入/慢时域，控制环逻辑与 v4 完全一致，因此 v5 的实时性预算**严格不劣于 v4**。

**形式化目标（增量）**：

1. 定义基准有效性证书 BVC = (ρ_cov, κ_contam, π_power, γ_construct, Δ_adv, n_eff, t)，及硬门 kc_bench = (ρ_cov ≥ ρ_min) ∧ (κ_contam ≤ ε_c) ∧ (π_power ≥ 1−β_min) ∧ (γ_construct ≥ γ_min) ∧ (Δ_adv ≤ Δ_max)，软因子 η_bench = clamp(ρ_cov·γ_construct·(1−Δ_adv)·(1−κ_contam), 0, 1)。
2. 定义示教支撑证书 DSC = (σ_support, q_demo, c_causal, prov_valid, δ_shift, t)，及硬门 kc_demo = (σ_support ≥ σ_min) ∧ (q_demo ≥ q_min) ∧ (c_causal ≥ c_min) ∧ prov_valid ∧ (δ_shift ≤ δ_max)，软因子 η_demo = clamp(q_demo·σ_support·c_causal·(1−δ_shift), 0, 1)。
3. 定义交叉校准元门 kc_cross：在 canary 集 K 上计算符号不一致率 d_cross 及其 Hoeffding 上界 d_cross^+；kc_cross = (d_cross^+ ≤ d_max)，软因子 η_cross = clamp(1−d_cross/d_max, 0, 1)。
4. 定义基准测量迁移定理：在损失 L-Lipschitz、W_1(P_B,P_D) ≤ ρ、污染率 κ、构念偏差 b_c 下，R_D(π) ≤ R̂_B(π) + Lρ + κ/(1−κ) + b_c + √(log(1/δ)/(2n_eff))。
5. 定义示教性能差定理：在演示覆盖 σ_support、次优性 ε_sub、因果混淆界 c_conf、漂移 δ_shift 下，J(π*) − J(π_BC) ≤ (1/(1−γ))[C_1(1−σ_support) + C_2 ε_sub + C_3 c_conf + C_4 δ_shift]。
6. 定义交叉校准定理：若 canary 在零假设下独立同分布，则 P(d_cross > α + √(log(1/δ)/(2|K|))) ≤ δ；若 canary 间存在共模相关 ρ_cc，则有效样本 |K|_eff = |K|/(1+(|K|−1)ρ_cc)，可检测阈值被放大 √(1+(|K|−1)ρ_cc) 倍。
7. 定义 EFA-v5 九硬门 + 交叉元门 + 软评分 ECS_v5 = ECS_v4·η_bench·η_demo·η_cross；定义 Exec_CADVS-v5 = Exec_CADVS-v4 ∩ {kc_bench} ∩ {kc_demo} ∩ {kc_cross}。
8. 实时性不变式：kc_bench/kc_demo/kc_cross 仅在规则准入时评估，控制环只读取缓存的 BVC/DSC 与 v4 的 EEC/BCC，控制周期计算量与 v4 相同。

**本轮最大风险**：**基准与示教共享同一实验室分布时会发生「共模盲区」**——两个锚点一起错，交叉校准也因 canary 同源而失效，九硬门给出「共识幻觉」，系统把「在同一个窄分布上自洽」误当成「在部署分布上可信」。

### 0.3 与 v4 的边界和设计约束

1. **不替换 v4**：v5 只是在 v4 的准入路径上追加「测量有效性」与「行为归因」两把锁；七硬门、ECS_v4、EEC/BCC 语义不变。

## 2. 关键算法骨架

### IP-493 BVK：基准有效性核（准入/慢时域，异步 ~0.1–2 s/基准审计）

```python
@dataclass
class BenchmarkValidityKernel:
    """BVK：把基准分数变成带校准误差的测量；kc_bench 硬门"""
    rho_min: float = 0.70          # 最坏分层覆盖阈值
    eps_c: float = 0.01            # 污染率容差
    beta_min: float = 0.20         # II 类错误上限，要求功效 >= 0.8
    gamma_min: float = 0.70        # 构念效度阈值
    delta_max: float = 0.10        # 对抗间隙阈值
    alpha: float = 0.05            # 功效计算的显著性水平
    delta_min_effect: float = 0.05 # 最小可检测效应

    def certify(self, benchmark: Benchmark, deploy_proxy: ProxySet,
                rule: Rule, t_now: float) -> BVC:
        # 1) 最坏分层覆盖：基准必须在每个部署分层上有足够比例
        rho_cov = self._worst_stratum_coverage(benchmark, deploy_proxy)
        # 2) 污染/泄漏审计：重复、近重复、答案泄漏、排行榜过拟合
        kappa_contam = self._contamination_rate(benchmark)
        # 3) 有效样本与统计功效
        n_eff = self._effective_sample_size(benchmark)
        pi_power = self._power(n_eff, self.delta_min_effect, self.alpha)
        # 4) 构念效度：基准损失 vs 部署代理损失
        gamma_construct = self._construct_correlation(benchmark, deploy_proxy, rule)
        # 5) 对抗/held-out 间隙
        delta_adv = max(0.0, self._adversarial_loss(benchmark, rule)
                        - self._standard_loss(benchmark, rule))
        return BVC(rho_cov=rho_cov, kappa_contam=kappa_contam,
                   pi_power=pi_power, gamma_construct=gamma_construct,
                   delta_adv=delta_adv, n_eff=n_eff, t=t_now)

    def kc_bench(self, bvc: BVC) -> bool:
        """引理 43：通过 ⟹ 基准测量误差、污染、功效、构念、对抗间隙均达标"""
        return (bvc.rho_cov >= self.rho_min
                and bvc.kappa_contam <= self.eps_c
                and bvc.pi_power >= 1.0 - self.beta_min
                and bvc.gamma_construct >= self.gamma_min
                and bvc.delta_adv <= self.delta_max)

    def eta_bench(self, bvc: BVC) -> float:
        return float(np.clip(bvc.rho_cov * bvc.gamma_construct
                             * (1.0 - bvc.delta_adv) * (1.0 - bvc.kappa_contam),
                             0.0, 1.0))

    def _worst_stratum_coverage(self, bench, proxy) -> float: ...
    def _contamination_rate(self, bench) -> float: ...
    def _effective_sample_size(self, bench) -> float: ...
    def _power(self, n_eff, delta_min, alpha) -> float: ...
    def _construct_correlation(self, bench, proxy, rule) -> float: ...
    def _standard_loss(self, bench, rule) -> float: ...
    def _adversarial_loss(self, bench, rule) -> float: ...
```

### IP-494 DPK：示教支撑核（准入/慢时域，异步 ~0.1–1 s/示教集）

```python
@dataclass
class DemonstrationProvenanceKernel:
    """DPK：把示教变成可归因的行为证据；kc_demo 硬门"""
    sigma_min: float = 0.70        # 支撑覆盖阈值
    q_min: float = 0.60            # 示教质量阈值
    c_min: float = 0.70            # 因果充分性阈值
    delta_shift_max: float = 0.20  # 示教-部署漂移阈值
    eps_s: float = 0.10            # 支撑邻域半径

    def certify(self, demos: DemoSet, deploy_proxy: ProxySet,
                rule: Rule, t_now: float) -> DSC:
        # 1) 来源链：同意/许可/链式保管/无泄漏/无毒化
        prov_valid = self._provenance_valid(demos)
        # 2) 支撑覆盖：部署状态上所需动作是否落在演示支撑邻域
        sigma_support = self._support_coverage(demos, deploy_proxy, rule)
        # 3) 示教质量：相对专家/随机的归一化回报
        q_demo = self._demo_quality(demos)
        # 4) 因果充分性：控制 s 后动作与 nuisance z 的条件互信息
        c_causal = self._causal_sufficiency(demos)
        # 5) 示教-部署漂移
        delta_shift = self._distribution_shift(demos, deploy_proxy)
        return DSC(sigma_support=sigma_support, q_demo=q_demo,
                   c_causal=c_causal, prov_valid=prov_valid,
                   delta_shift=delta_shift, t=t_now)

    def kc_demo(self, dsc: DSC) -> bool:
        """引理 44：通过 ⟹ 示教有覆盖、有质量、有因果根据、有来源、无大漂移"""
        return (dsc.sigma_support >= self.sigma_min
                and dsc.q_demo >= self.q_min
                and dsc.c_causal >= self.c_min
                and dsc.prov_valid
                and dsc.delta_shift <= self.delta_shift_max)

    def eta_demo(self, dsc: DSC) -> float:
        if not dsc.prov_valid:
            return 0.0
        return float(np.clip(dsc.q_demo * dsc.sigma_support * dsc.c_causal
                             * (1.0 - dsc.delta_shift), 0.0, 1.0))

    def _provenance_valid(self, demos) -> bool: ...
    def _support_coverage(self, demos, proxy, rule) -> float: ...
    def _demo_quality(self, demos) -> float: ...
    def _causal_sufficiency(self, demos) -> float: ...
    def _distribution_shift(self, demos, proxy) -> float: ...
```

### IP-495 CERTCALC-v5：测量-推断对偶与核心定理（离线理论，不在控制环）

```python
class CertCalcV5:
    """在 v4 证书演算上追加测量有效性、示教归因与交叉校准定理"""

    @staticmethod
    def benchmark_transport_bound(r_hat_b, L, W1, kappa, b_construct, n_eff, delta):
        """
        引理 43（基准测量迁移）：
        R_D <= r_hat_b + L*W1 + kappa/(1-kappa) + b_construct
               + sqrt(log(1/delta)/(2*n_eff)).
        """
        return (r_hat_b + L * W1 + kappa / max(1.0 - kappa, 1e-9)
                + b_construct + math.sqrt(math.log(1.0 / delta) / (2.0 * n_eff)))

    @staticmethod
    def demo_performance_gap(sigma, eps_sub, c_conf, delta_shift, gamma, C):
        """
        引理 44（示教性能差）：
        J(pi*) - J(pi_BC) <= 1/(1-gamma) * [C1*(1-sigma) + C2*eps_sub
                                            + C3*c_conf + C4*delta_shift].
        """
        return (C[0] * (1.0 - sigma) + C[1] * eps_sub
                + C[2] * c_conf + C[3] * delta_shift) / max(1.0 - gamma, 1e-9)

    @staticmethod
    def cross_calibration_upper(d_cross, K, delta):
        """引理 45（交叉校准）：Hoeffding 上界 d_cross^+"""
        return d_cross + math.sqrt(math.log(1.0 / delta) / (2.0 * K))

    @staticmethod
    def common_mode_power(rho_cc, K):
        """定理 6：共模相关下交叉门对共享偏差的有效样本与可检测性"""
        K_eff = K / (1.0 + (K - 1.0) * rho_cc)
        inflation = math.sqrt(1.0 + (K - 1.0) * rho_cc)
        return K_eff, inflation
```

#### 定理 5（基准测量迁移）

**陈述**：设基准分布 P_B 与部署分布 P_D 满足 W_1(P_B,P_D) ≤ ρ，损失 ℓ ∈ [0,1] 且 L-Lipschitz，污染率为 κ，构念偏差 |E_D ℓ − E_B ℓ| ≤ b_c，有效样本量为 n_eff。则对任意规则 π，以概率 ≥ 1−δ：
R_D(π) ≤ R̂_B(π) + Lρ + κ/(1−κ) + b_c + √(log(1/δ)/(2n_eff))。

**证明**：W_1 对偶给出 |E_D ℓ − E_B ℓ| ≤ Lρ（Kantorovich-Rubinstein）；污染样本最多贡献 κ/(1−κ) 的偏差；构念偏差由 b_c 吸收；经验均值由 Hoeffding 不等式集中。合并即得。∎

**工程含义**：kc_bench 的五个分量正好对应五项误差来源：ρ_cov 控制 ρ，κ_contam 控制 κ，π_power/n_eff 控制集中项，γ_construct 控制 b_c，Δ_adv 控制「标准划分→对抗划分」的额外漂移。基准分数不是真值，而是一个带误差条的测量。

#### 定理 6（示教性能差与因果混淆）

**陈述**：设 π_BC 为从示教集 D 行为克隆的策略，π* 为专家策略，回报折扣 γ。令 σ_support 为演示支撑覆盖，ε_sub 为演示策略次优性，c_conf 为因果混淆界（动作对 nuisance 特征的条件依赖），δ_shift 为示教-部署漂移。则存在常数 C_1…C_4 使得：
J(π*) − J(π_BC) ≤ (1/(1−γ))[C_1(1−σ_support) + C_2 ε_sub + C_3 c_conf + C_4 δ_shift]。

**证明**：由性能差引理，J(π*)−J(π_BC) 可写成折扣状态分布下的优势加权；支撑外状态用 (1−σ_support) 的覆盖缺口界定；演示次优性由 ε_sub 进入；因果混淆使策略在 nuisance 变化时产生额外动作偏差，由 c_conf 界定；示教-部署漂移由 δ_shift 进入。∎

**工程含义**：kc_demo 的五个分量对应五类失效：无覆盖、次优示教、因果混淆、来源非法、分布漂移。示教损失低不等于策略对，必须把「为什么动作会发生」纳入证书。

#### 定理 7（交叉校准与共模盲区）

**陈述**：在 canary 集 K 上，若零假设下两锚误差独立同分布且不一致率期望 ≤ α，则 P(d_cross > α + √(log(1/δ)/(2|K|))) ≤ δ（Hoeffding）。若 canary 间存在共模相关 ρ_cc，则有效样本 |K|_eff = |K|/(1+(|K|−1)ρ_cc)，可检测阈值被放大 √(1+(|K|−1)ρ_cc) 倍。特别地，当 ρ_cc = 1 时，d_cross 在零假设下恒为 0，交叉门对共模偏差的检测功效为 0。

**证明**：Hoeffding 不等式直接给出第一项；共模相关下，canary 的有效独立样本由设计效应公式收缩；ρ_cc=1 时所有 canary 的锚点判决由同一个隐变量决定，符号不一致率恒为 0，故任何仅依赖两锚一致性的检验都无法拒绝「两锚同时错」。∎

**工程含义**：交叉门只能检测「两锚各自独立地犯错」，不能检测「两锚共享同一个盲区」。这是 v5 的结构性盲区，必须靠外部锚（真实部署探针、独立基准、人类审计）打破。

#### 定理 8（执行集严格收缩与双锚误差控制）

**陈述**：在 v4 的 (B1)~(B6) 以及新增假设 (B7) 基准分层已知、(B8) 示教因果状态充分、(B9) canary 可独立采样 下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4；若 kc_bench、kc_demo、kc_cross 均非恒真，则严格 ⊂。
(ii) 对部署风险 R_D > τ_risk 的坏规则，P(pass kc_bench) ≤ δ_B（由定理 5）。
(iii) 对部署风险 R_D ≤ τ_risk 且示教有支撑的好规则，P(fail kc_demo) ≤ δ_D（由定理 6 与集中不等式）。
(iv) 若两锚误差独立，P(pass 全部 | bad) ≤ min(δ_B, δ_D)；若共模相关 ρ_cc → 1，该上界退化为 max(δ_B, δ_D)，交叉门失效（定理 7）。

**证明**：(i) v5 在 v4 的每条准入路径上追加 kc_bench、kc_demo、kc_cross 三个合取项，故路径集只缩不涨；非恒真保证存在至少一条 v4 通过而 v5 拒绝的路径。(ii)(iii) 分别由定理 5、6 的误差界取阈值得到。(iv) 独立性下合取概率不超过任一分量；共模相关下两锚判决同源，合取不再提供额外证据。∎

**推论（执行集规模-证据质量权衡）**：设 v4 通过率为 p_4，新增三门通过率分别为 p_B、p_D、p_C，则 |Exec_v5|/|Exec_v4| ≈ p_B·p_D·p_C（在近似独立时）。证据越严格，执行集越小；当三门过严导致 |Exec_v5| 过小时，系统会退化为「几乎不执行」，这是 v5 需要监控的「门膨胀」风险。

### IP-496 EFA-v5：九硬门 + 交叉元门 + 软评分

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：v4 七硬门 + kc_bench + kc_demo + kc_cross；软评分 ECS_v5"""
    v4: EvidenceForgingAssemblerV4
    bvk: BenchmarkValidityKernel
    dpk: DemonstrationProvenanceKernel
    d_max: float = 0.15

    def hard_gate_admission(self, x, t_now, rule_id, hic, eec, bcc,
                            object_class, geo_sig, theta_domain_fp,
                            traj, context, benchmark, demos,
                            deploy_proxy, canary: CanarySet) -> tuple[bool, str]:
        # 0) v4 七硬门（HIC veto 优先级最高）
        ok_v4, why_v4 = self.v4.hard_gate(
            x, t_now, rule_id, hic, eec, bcc, object_class, geo_sig,
            theta_domain_fp, traj, context)
        if not ok_v4:
            return False, why_v4

        # 1) 基准有效性（测量侧）
        bvc = self.bvk.certify(benchmark, deploy_proxy, rule_id, t_now)
        if not self.bvk.kc_bench(bvc):
            return False, 'BENCHMARK_INVALID'

        # 2) 示教支撑（生成侧）
        dsc = self.dpk.certify(demos, deploy_proxy, rule_id, t_now)
        if not self.dpk.kc_demo(dsc):
            return False, 'DEMO_UNSUPPORTED'

        # 3) 交叉校准（元门）：两锚是否在测量同一件事
        d_cross = self._cross_disagreement(canary, benchmark, demos, rule_id)
        d_plus = d_cross + math.sqrt(math.log(1.0 / 0.05) / (2.0 * len(canary)))
        if d_plus > self.d_max:
            return False, 'ANCHOR_DISAGREE'

        return True, 'FORGED_V5'

    def ecs_v5(self, x, t_now, rule_id, bvc, dsc, d_cross,
               A_att=0.0, eta_mem=0.5, eta_val=0.5, eta_bal=0.5) -> float:
        base = self.v4.ecs_v4(x, t_now, rule_id, A_att, eta_mem, eta_val, eta_bal)
        return (base * self.bvk.eta_bench(bvc)
                * self.dpk.eta_demo(dsc)
                * float(np.clip(1.0 - d_cross / self.d_max, 0.0, 1.0)))

    def hard_gate_control(self, *args, **kwargs) -> tuple[bool, str]:
        """控制环不变式：与 v4 完全一致，不新增 BVK/DPK 计算"""
        return self.v4.hard_gate(*args, **kwargs)

    def _cross_disagreement(self, canary, benchmark, demos, rule_id) -> float: ...
```

## 4. 正确性论证（增量更新）

### 引理 43（基准测量迁移界）

见定理 5。核心是把基准分数拆成「经验值 + 分布漂移 + 污染 + 构念偏差 + 有限样本集中」五项，并由 kc_bench 的五分量分别控制。

### 引理 44（示教性能差界）

见定理 6。核心是把示教策略的失败拆成「支撑缺口 + 次优性 + 因果混淆 + 分布漂移」四项，并由 kc_demo 的五分量分别控制。

### 引理 45（交叉校准上界）

对任意 δ ∈ (0,1)，d_cross^+ = d_cross + √(log(1/δ)/(2|K|)) 以概率 ≥ 1−δ 上界真实不一致率；kc_cross 使用 d_cross^+ 而非点估计，避免小 canary 集上的乐观偏差。

### 定理 v5（执行集严格收缩与双锚误差控制）

见定理 8。要点：v5 在 v4 的每条准入路径上追加三个合取项，故执行集只缩不涨；基准门控制「坏规则被测量偏差误接纳」，示教门控制「好规则因行为证据不足被误拒」；交叉门控制「两锚是否在测量同一件事」。严格性由三个新门的非恒真性保证。

### 定理 v6（共模盲区的不可检测性）

见定理 7。要点：当 canary 上两锚误差完全同源（ρ_cc=1）时，d_cross 恒为 0，交叉门对共享偏差的检测功效为 0。这不是工程缺陷，而是「仅靠两个相关证据源无法识别共同偏差」的信息论限制。推论：v5 必须保留**外部锚**——真实部署探针、独立第三方基准、人类抽检——否则「九硬门全过」不能排除「两锚共享盲区」。

### 定理 v7（测量-推断对偶）

**陈述**：v4 的七锚点提供「证据充分性」证书；v5 的基准锚提供「测量有效性」证书，示教锚提供「行为归因有效性」证书。三者正交：存在规则在 v4 下通过但基准测量无效（污染/构念失配）、在 v4 下通过但示教归因错误（因果混淆）、在 v4 下通过但两者同时失效（共模盲区）。因此 v5 的三类新门不能被 v4 的任一旧门替代。

**证明**：逐类构造反例：(a) 规则在泄漏测试集上高分，但部署失败——v4 的覆盖率/物理/末点/记忆/价值/平衡均可通过，kc_bench 因 κ_contam 失败；(b) 规则在演示分布内完美，但 nuisance 特征一变就失败——v4 七门均可通过，kc_demo 因 c_causal 失败；(c) 基准与示教同源于实验室窄分布，两锚同时通过而部署失败——v5 交叉门也失效，需外部锚。∎

**诚实声明**：(B7) 基准分层已知且部署分布可采样代理——在开放世界中分层本身可能遗漏未知未知；(B8) 示教因果状态充分——真实机器人中「状态」是否包含所有因果因素难以验证；(B9) canary 可独立采样——实际 canary 往往与训练/基准同源，独立性是强假设。v5 的证书是「在给定审计协议下的可辩护证据」，不是「绝对安全证明」。

## 5. 实验设计与初步结果（计划中，第 5~6 轮实机）

### 5.1 实验设计

- **平台**：MuJoCo 3.x + MJX（仿真）+ N 台实机 Panda（舰队，N=3~5，不同末端/摩擦/载荷）+ 人类示教采集与偏好标注平台。
- **基准有效性实验**：
  (a) 污染注入：训练/测试重复率 0%、5%、20%、50%；答案泄漏；近重复任务；
  (b) 分层缺失：故意移除某些物体/位姿/接触模式分层，测 ρ_cov 与部署失败率；
  (c) 统计功效：不同 n_eff 下坏规则的假接纳率；
  (d) 构念失配：用「抓取成功率」作为唯一指标，但部署目标是「安全+长期可用」；
  (e) 排行榜过拟合：对超参数做大量搜索，测标准划分 vs 对抗划分间隙 Δ_adv。
- **示教学习实验**：
  (a) 示教质量分层：专家、混合、次优、多模态、含噪；
  (b) 因果混淆：让 nuisance 特征（背景、光照、操作者手速）与动作强相关，部署时替换 nuisance；
  (c) 支撑稀疏：只覆盖部分状态-动作区域，测 OOD 失效率；
  (d) 来源链：模拟无同意/无许可/训练测试泄漏的示教数据；
  (e) DAgger 交互修正：测示教门失败后的主动补采效果。
- **交叉校准实验**：
  (a) 独立 canary：基准与示教误差独立时，测 d_cross 检出率；
  (b) 共模 canary：两锚共享同一偏差源时，测交叉门失效（预期检测功效≈0）；
  (c) 外部锚注入：加入真实部署探针/人类抽检，测共模盲区检出率。
- **对照**：v4-full、v5-full、消融 A1（去 BVK）、A2（去 DPK）、A3（去 BVK+DPK，纯 v4）、A4（BVK 替换为原始基准分数）、A5（DPK 替换为纯 BC 损失）、A6（去 kc_cross）。
- **指标**：污染基准假接纳率、基准-部署构念偏差、示教因果混淆失效率、稀疏示教 OOD 失效率、共模盲区检出率、交叉不一致率、任务成功率、安全违例率、执行集规模 |Exec_v5|/|Exec_v4|、准入延迟 P99、控制环延迟 P99/丢帧率。

### 5.3 效度威胁

1. **基准效度威胁**：仿真基准与真实部署的构念效度可能天然偏低；γ_construct 的校准集本身可能不独立。
2. **示教效度威胁**：人类示教的操作者偏差、多模态性和隐性策略可能无法被单一 q_demo/c_causal 捕捉。
3. **交叉效度威胁**：canary 若与训练/基准同源，d_cross 会系统性低估共模偏差。
4. **外部效度威胁**：实验主要在桌面操作与有限物体集上，结论向开放世界外推需谨慎。

## 7. 本轮最大风险（最终确认）

**一句话**：**基准与示教共享同一实验室分布时会发生「共模盲区」**——两个锚点一起错，交叉校准也因 canary 同源而失效，九硬门给出「共识幻觉」，系统把「在同一个窄分布上自洽」误当成「在部署分布上可信」。
