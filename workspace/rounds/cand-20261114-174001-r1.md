# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~302；灵感循环第 4 轮；本轮灵感：「UniBot」×「最小可行产品」）

> R73 把证据计量做成可组合的契约代数，并把系统安全的证明从「全系统审计」转移到「**契约表达力**」。但 R73 有两个尚未被正面攻击的假设：
> - **白盒假设**：每个证据模块都能声明自己的物理不确定度分解（DPEM 六分量、DMEM 四分量）。可现实中最可能被部署的机器人形态，恰恰是一个**跨本体、黑箱的通用策略**（UniBot：单一 foundation policy 控制多种身体）。它既不能声明六分量，其内部也无可审计的分解——R73 的契约完整性（定义 366(i)）对它直接失效。
> - **可建构性假设**：R71–R73 累计 382 个定义、302 个 IP、395 个实验。理论塔越高，越可能**从未被端到端建造、也从未被一次性证伪**。这是研究项目的**存在性风险**，不是理论风险。
>
> 本轮两个灵感正面攻击这两个假设：
> - **UniBot** → 承认黑箱是常态而非例外：**把策略从「系统模块」降级为「环境 E_π」**，用**黑箱证据契约 BEC** 从外部包住它（行为校准，不声明内部），并用**策略无关安全核 PASK** 让硬安全不依赖策略。这是 R73 白盒假设的**补集**：并非所有东西都要白盒，安全只需要一个白盒核。
> - **最小可行产品** → **MVP 账本**：找出能**一次性证伪整个 74 轮纲领**的最小端到端切片——一个本体 × 一个黑箱策略 × 一个传感器 × 一条安全性质 × 一条主张。其余全部记为**研究债**（带触发器的延期，而非删除）。`|V_M|` 从 24 降到 3（策略 / 身体 / 安全核）。
>
> 核心命题：**安全的可证明性不需要理解策略，只需要一个策略无关的安全核；模块化的最小可行形态不是 24 个模块，而是「黑箱策略 + 白盒身体 + 策略无关盾」三方分解。**

## 0. 直觉与动机

**灵感 1（UniBot → 黑箱是模块化架构的最强反例，也是它的验收标准）**
直觉：R73 的模块化在「我能把系统切开」时很美；但通用机器人策略（RT-X / OpenVLA / Octo / UniBot 这类跨本体 policy）恰恰是**不可切开的**。反应分两种：
- 坏反应：要求 UniBot 声明六分量 → 做不到，于是把它当「不可信模块」排除；结果架构只能用于玩具白盒，失去现实意义。
- 好反应：**把策略移到系统边界之外**。策略不是被审计的对象，而是**动作提议的来源**；就像环境会给机器人扰动一样，策略会给机器人提议。计量层审计的不是「策略为什么这么动」，而是「这个动作在身体上会不会越界、证据是否足以支撑这个判断」。

关键转念：**安全命题的对象从「策略」换成「身体 + 盾」**。一旦安全不依赖策略，UniBot 就可以被热替换、升级、甚至被对抗性污染，而安全证书的证明无需改动一行。这与 R73 的热替换定理（引理 35）正交：R73 说「换实现不换契约则性质保持」，R74 说「**连契约都不需要对策略持有，因为安全根本没用到它**」。

**灵感 2（最小可行产品 → 反理论塔：单一主张 + 杀死实验 + 研究债）**
直觉：一个 382 定义、395 实验的纲领，最大的敌人不是同行评审，而是**自己太重以至于永远无法被证伪**。MVP 的正确用法不是「做个 demo」，而是**找出纲领的承重墙，用最便宜的方式把它敲一下**：
- 中央赌注是什么？——「外部证据契约能在黑箱通用策略上保持安全，且成本与策略规模无关。」
- 如果它错了，整个 R71–R73 还有意义吗？——没有；因为现实世界的策略几乎都是黑箱。
- 所以 MVP = 一个能让这个赌注**失败**的实验，其余全部是**研究债**。

研究债不是删除，是**带触发器的延期**：每个 R73 组件都写明「什么 MVP 结果会迫使你把它请回核心」。这让 MVP 同时是**调度器**：理论不是一次性证明的，而是按证据触发逐层加载的。这也顺便回应「论文创新点」：论文只写 MVP 那一条主张，其余放附录/未来工作，而不是把 7 个 IP 全塞进正文。

**灵感 3（策略无关安全核 → 安全与性能的彻底分家）**
直觉：R73 的 E-RISK + λ_floor + certified prefix 已经隐含「安全下界」，但仍把策略输出当作风险缩放的输入之一。R74 把它推到极致：
- **性能/意图**是策略的事（黑箱，可能很聪明，也可能被攻击）；
- **安全**是盾的事（白盒，只依赖身体的运动学/动力学与一个**无证据安全集 S_min**）；
- **证据**是桥（决定盾能「合法地」把 S_min 扩大到多大，而不决定安全与否）。

于是得到一个非常强的性质：**∀π，包括一个故意作恶的 π，只要盾正确，系统不越出 S_safe**。证据失效时，S_safe 塌缩到 S_min，而不是「信任策略」。这就是「安全侧只增不减」在**最坏策略**下的兑现。代价是 S_min 必须非空且可达——这是本轮最大风险的种子。

**灵感 4（UniBot 的闭环自适应 → 可交换性失效；conformal 只能管性能，不能管硬安全）**
直觉：R73 用 conformal 一致性审计给 PAR 缩窄背书；但 conformal 的覆盖率依赖校准集与部署集**可交换**。黑箱策略是**自适应的**：它在闭环里选择动作，从而选择自己未来会遇到的输入分布——它可以主动把系统带到校准集覆盖不到的地方（哪怕非恶意，泛化偏差也会这样）。于是标准 conformal 在闭环下**没有逐点保证**。R74 的对策不是硬修 conformal，而是**分清它管什么**：
- **硬安全**交给盾 + S_min（不依赖可交换性）；
- **软性能/能力监控**交给 **ACI（自适应 conformal 推断）**：在漂移下维持**长程**误覆盖率 ≤ α + o(1)，用来决定「何时把控制权交回人 / 何时降级到保守控制器」。

这是把 R73 的「审计」拆成两层：**逐指令安全审计（确定性，盾）** 与 **长程能力审计（统计性，ACI）**。混在一起的审计既不够硬也不够灵活。

**灵感 5（三党最小分解 → |V_M| 从 24 降到 3，理论按需加载）**
直觉：R73 用 `|V_M|≤24`、深度 ≤4 的结构上限控制复杂度；但 MVP 揭示一个更狠的上限：**任何具身系统的可证安全，最小只需三方**——(P) 黑箱策略、(B) 白盒身体证据、(S) 策略无关盾。其余 21 个模块都是「在 B 内部做更细的分解」或「在 P 外部做更好的监控」，它们是**分辨率**，不是**承重墙**。于是复杂度上限获得一个解释：`|V_M|≤24` 不是「最多 24 个」，而是「3 个承重 + 至多 21 个分辨率增强」；MVP 只验证承重墙，分辨率按研究债触发器加载。

## 1. 形式化定义（增量：定义 383–395）

**定义 383（MODGAUGE-MVC 总览与三党分解）** MODGAUGE-MVC = (UniBot, MW, PASK, BEC, MVP-Ledger, MODGAUGE†)。四不变式：
(i) **策略外在性**：UniBot ∉ V_M；它属于环境 E_π，只能被查询、不可被分解、不可被信任；
(ii) **安全策略无关性**：硬安全命题的证明只引用 PASK 与 body EC，不引用 π_θ 的任何内部量；
(iii) **证据有条件扩张**：`S_min ⊆ S_safe(e) ⊆ S_phys`；证据只能扩张 S_safe，且扩张受 EC 有效域 D 约束；证据失效 ⇒ `S_safe := S_min`；
(iv) **MVP 单一主张**：本轮只认证一条可证伪主张 MVC-C（定义 390）；其余全部进入研究债账本（定义 389）并带触发器。

**定义 384（黑箱证据契约 BEC）** BEC = (T_in, T_out, π_ref, 𝒫_cal, A_α, D_beh, τ_beh, W_q)：
- π_ref：被包装的黑箱策略引用（只提供 query）；
- 𝒫_cal：行为校准集（SEAL-BEH），元素为（context, instruction, proposed action, observed outcome）；
- A_α：能力集预测器——给定 context 输出 conformal/ACI 能力集（「策略在此 context 下大概率能胜任的动作/结果集合」），α 为名义误覆盖率；
- D_beh：行为有效域（指令族、任务阶段、本体构型、输入分布的可表征包络）；
- τ_beh：校准来源与版本追溯；
- W_q：单次查询延迟/算力预算。
**与 EC 的本质差异**：BEC **不包含**物理不确定度分解 𝒰、不包含 χ_R 的物理噪声调制；它只做**行为声明**，不做**结构声明**。BEC 可视为 EC 的「外部观测对偶」。

**定义 385（计量包装器 MW / Contract Shell）** MW = (EC_body, BEC_policy, ⊕_wrap)。每步：读身体证据 e_t（DPEM† 的 EC）→ 读策略提议 `a_t = π_ref(o_t, ℓ)` → 组装联合证据包 `(e_t, a_t, c_t)`，其中 c_t ∈ A_α 的隶属/距离。MW 对 π_θ 内部零假设。**包装引理**：若 EC_body 有效且 BEC 在 D_beh 内有效，则 MW 输出一个合法 EC 证据包（可参与 R73 的 CCA 组合），且 MW 证书不含 `|θ|` 任何项。

**定义 386（策略无关安全核 PASK）** PASK = (S_min, S_phys, S_safe(·), Shield, Gate)：
- S_min：**无证据安全集**——只由身体运动学/静力学定义（静止、回撤、柔顺、受控制动），可由身体证书独立认证，不含任何感知量；
- S_phys：物理可达集；
- `S_safe(e) = S_min ∪ EvidenceMargin(e)`，单调满足 `S_min ⊆ S_safe(e) ⊆ S_phys`；
- Shield：`(s_t, a_t, e_t) ↦ a'_t`，使 `s_{t+1} ∈ S_safe(e_t)`（对提议动作做最小侵入投影）；
- Gate：`e_t` 有效性判定（DPEM 有效 ∧ 落在 D_beh ∧ ACI 漂移未越界）。
**关键**：Shield 只使用 `s_t, a_t, e_t`，不使用 π_θ 的任何隐藏状态。

**定义 387（证据门 Gate 与安全集的塌缩）** Gate 输出三态：VALID（S_safe 扩张）、DEGRADED（仅用 S_min 与部分证据，S_safe 收窄）、INVALID（`S_safe := S_min`）。塌缩是**单调的**：证据只增不减安全性（S_min 恒在）。DEGRADED 不是故障，而是「用更少证据换更保守的安全集」。

**定义 388（闭环可交换性失效与 ACI 能力审计）** 设校准点与部署点在同 context cell 内可交换为 H_ex。闭环自适应 π_θ 使 H_ex 一般不成立（策略选择自己的输入分布）。R74 不假设 H_ex 对硬安全成立，而只假设：
(a) **硬安全**由 PASK 保证，不依赖 H_ex；
(b) **软能力**由 ACI 维持长程误覆盖率 ≤ α + o(1)（对任意有界漂移），用于触发 DEGRADED / 人类接管；逐点保证被显式放弃，并在证书中标注为「统计性、非逐指令」。
**系**：把 R73 的「一致性审计」拆为「确定性逐指令盾审计」与「统计性长程能力审计」；混用二者会同时失去硬度与灵活性。

**定义 389（MVP 账本与研究债触发器）** MVP-Ledger = (M_core, Debt, MVC-C, KillTest)：
- `M_core = {MW, PASK, BEC, MB-MVP}`，`|M_core| = 4`，≤12 定义，单卡 ≤2 周；
- `Debt = {(module_i, trigger_i)}`：每个 R71–R73 组件配一个**触发条件**——某个 MVP 观测若越过阈值，则把 module_i 从债转为 core；
- MVC-C：唯一主张（定义 390）；
- KillTest：若 MVC-C 失败则整个纲领降级（不是修参数，而是重估承重墙）。

**定义 390（MVP 单一可证伪主张 MVC-C）** 对任意黑箱通用策略 π_θ（含对抗性微调），存在策略无关盾 PASK 与外部证据包装 MW，使：
(i) **安全**：灾难性不安全动作率 ≤ ε_cat（相对裸 π_θ 显著下降）；
(ii) **性能**：任务成功率 ≥ ρ·baseline（ρ 预注册，例如 0.8）；
(iii) **可移植**：热替换 π_θ（换 checkpoint / 换本体接口）后，安全核代码改动 = 0 行、证书重认证成本与 `|θ|` 无关。
**证伪条件**：不存在同时满足 (i)(ii) 的配置——即盾要么不安全、要么使系统瘫痪。若证伪，则「外部契约可扩展到黑箱通用策略」不成立，R73 的模块化只在白盒域有效。

**定义 391（UniBot 语义漂移与软故障）** π_θ 升级/微调导致行为漂移。R74 规定：漂移只影响 BEC 的能力集与 Gate 的 DEGRADED 判定（**软故障**），不影响 PASK 的安全证明（**硬安全**）。因此策略漂移的爆炸半径被限制在「性能/接管频率」，不触及安全证书。

**定义 392（最小基准 MB-MVP）** 一个本体（单臂 + 深度相机 + 力/力矩 + 急停）、一个策略（UniBot checkpoint，允许替换）、三个任务（透明物体抓取、人近距伸手、可形变倾倒），每个 ≤30 分钟可复跑；三个基线（裸 UniBot、UniBot + 速度限幅、UniBot + R73 全栈）；预注册脚本 + 固定种子 + SEAL-MVP 密封集。

**定义 393（MVC 认证成本）** `CertCost_MVP = CertCost(PASK) + CertCost(EC_body) + CertCost(BEC)`；断言其与 `|θ|`、与策略替换次数**无关**；弱化的可证伪形式：`CertCost_MVP / CertCost(全 R73 栈) < κ`（κ 预注册）。

**定义 394（研究债触发器的语义）** `trigger_i = (metric, threshold, direction, action)`。例：若透明物体任务失败率比不透明高 ≥2×，则 DMEM† 由债转 core；若 ACI 长程覆盖率偏离 α > δ，则 ΣREFLEX† 由债转 core；若人近距任务中 S_min 触发率 > 50%，则 S_min 需扩张（引入接触证据），否则「安全但无用」风险成立。触发器集合是**纲领的路线图**，由实验自动评估。

**定义 395（R73 的退化特例与覆盖关系）** 当 π_θ 本身是一个白盒 EC 模块时，R74 不抽取策略到环境，PASK 退化为 R73 的 certified prefix + λ_floor，MW 退化为恒等包装，BEC 退化为 EC；此时 MODGAUGE-MVC 逐指令等于 MODGAUGE（R73）。**覆盖关系不是包含关系**：R74 用「缩小可证安全面（只证 PASK）」换取「覆盖黑箱策略」；R73 用「要求全白盒」换取「更细的安全归因」。二者是同一纲领在不同可观测性假设下的两个实例。

## 2. 关键算法骨架

```python
# IP-303 BEC：黑箱证据契约（外部行为校准，不声明内部）
@dataclass(frozen=True)
class BlackBoxEvidenceContract:
    pi_ref: object                      # 只可 query 的黑箱策略
    calib: CalibSet                     # SEAL-BEH：(ctx, instruction, action, outcome)
    alpha: float                        # 名义误覆盖率
    d_beh: Predicate                    # 行为有效域（指令族/阶段/构型/输入包络）
    aci: ACIState                       # 自适应 conformal 状态（长程软审计）
    w_q_us: float                       # 查询延迟预算
    def competence(self, ctx) -> CompetenceSet:   # A_α
        return self.aci.predict(ctx)              # 只做行为声明

# IP-304 MW：计量包装器（策略当环境，证据只来自身体）
class MetrologicalWrapper:
    def __init__(self, body_ec, bec): self.body_ec, self.bec = body_ec, bec
    def wrap(self, obs, instruction, body_state):
        e = self.body_ec.update(obs, body_state)      # DPEM† 白盒证据
        a = self.bec.pi_ref.query(obs, instruction)    # 黑箱提议（不审计内部）
        c = self.bec.competence(ctx(body_state, instruction))
        gate = self.body_ec.gate(e) and self.bec.d_beh(body_state) and c.in_range
        return EvidencePacket(e=e, a=a, c=c, gate=gate,
                              tau=e.tau.merge(self.bec.calib.tau))

# IP-305 PASK：策略无关安全核（安全不引用 pi 内部）
class PolicyAgnosticSafetyKernel:
    def __init__(self, s_min, s_phys, body_cert): ...
    def safe_set(self, e, gate):
        if gate == 'INVALID':  return self.s_min          # 证据失效 → 无证据安全集
        if gate == 'DEGRADED': return self.s_min | self.evidence_margin(e, 'conservative')
        return self.s_min | self.evidence_margin(e, 'nominal')   # S_min ⊆ S_safe ⊆ S_phys
    def shield(self, s, a, e, gate):
        target = self.safe_set(e, gate)
        if self.predict(s, a) in target: return a                 # 提议合法
        return self.minimal_intrusion_project(s, a, target)       # 最小侵入投影

# IP-306 Gate + ACI：把审计拆成确定性与统计性两层
def evidence_gate(e, bec, body_state, aci):
    if not e.valid or not bec.d_beh(body_state): return 'INVALID'
    aci.update(e, bec)                                 # 更新长程误覆盖
    if aci.miscoverage() > bec.alpha + DELTA: return 'DEGRADED'   # 漂移 → 保守
    return 'VALID'

# IP-307 MVP 账本：承重墙与带触发器的研究债
MVP_CORE = ['MW', 'PASK', 'BEC', 'MB_MVP']
RESEARCH_DEBT = {
 'DMEM':        dict(trigger=('transparent_vs_opaque_fail_ratio', 2.0, '>', 'promote')),
 'SIGMAREFLEX': dict(trigger=('aci_coverage_drift', DELTA, '>', 'promote')),
 'ECG':         dict(trigger=('causal_chain_break_rate', 0.3, '>', 'promote')),
 'CCA_PAR':     dict(trigger=('cross_modal_conflict_rate', 0.05, '>', 'promote')),
 'PER_BODY_MIC':dict(trigger=('swap_requires_core_edit', 0, '>', 'promote')),
}
def load_core(results):                            # 触发器自动把债转 core
    return MVP_CORE + [m for m, t in RESEARCH_DEBT.items()
                       if t['trigger'][0] in results
                       and breach(results[t['trigger'][0]], *t['trigger'][1:3])]

# IP-308 MVC 主循环：黑箱策略 + 白盒身体 + 策略无关盾
def MVC_round(S, obs, instruction):
    body = S.body_state()
    pkt  = S.mw.wrap(obs, instruction, body)            # IP-304
    gate = evidence_gate(pkt.e, S.bec, body, S.bec.aci) # IP-306
    a    = pkt.a
    a_safe = S.pask.shield(body, a, pkt.e, gate)        # IP-305（不读 pi 内部）
    S.ctrl.execute(a_safe)
    S.log.write(pkt, gate, a, a_safe, cert=S.pask.cert) # 证书只引用 PASK+EC
    return a_safe, S.pask.invariant_ok()
```

## 3. 推导

**引理 38（包装合法性）** 若 EC_body 有效（R73 定义 367–369）且 BEC 在 D_beh 内有效（校准集对 context cell 可交换，或 ACI 长程覆盖），则 MW 的输出证据包满足 R73 的 EC 类型契约（T_in/T_out/𝒰/τ_merge/I⊥/W/seal_ref 逐项可映射），且参与 CCA 组合不破坏引理 34 的单调性。**系**：黑箱策略不破坏 R73 的组合代数——它只是「多了一个只能并联、不能被分解的证据源」。

**引理 39（PASK 的前向不变性，对任意策略）** 设 Shield 的 `minimal_intrusion_project` 在 `S_safe(e)` 上完备（对任意 a 均存在 a′ 使 `s_{t+1} ∈ S_safe(e)`）；则对任意 π（含对抗 π），若 `s_t ∈ S_safe(e_t)` 且 Gate 在 `[t, t+1]` 内不降级，则 `s_{t+1} ∈ S_safe(e_t)`；若 Gate 降级，则 `s_{t+1} ∈ S_safe = S_min`。证明只用身体动力学与 Shield 定义，不引用 π。**系**：安全证明与策略正交。

**引理 40（无证据安全集的可达性裕度）** 定义 `μ(S_min)` 为「在身体加速度/制动力约束下从 `S_phys` 内任意状态到达 `S_min` 所需最短时间上界」的倒数（即可控收缩率）。若 `μ(S_min)` 有限，则 Gate 从 VALID 塌缩到 INVALID 时存在有限制动时间 `T_b` 使状态进入 S_min；若 `μ(S_min) = ∞`（S_min 不可从某些 s 到达），则策略无关定理在该区域**空洞**。**系**：MVP 必须显式测量 `μ(S_min)`，否则「安全」可能只是「没跑到危险区」。

**引理 41（闭环 ACI 的长程覆盖）** 在任意有界漂移下，ACI 更新 `α_{t+1} = α_t + γ(α − err_t)` 使长程误覆盖率满足 `|(1/T)Σ err_t − α| ≤ O(1/(γT)) + O(γ)`，不要求可交换性；但该保证是**长程平均**，不是逐点。**系**：ACI 可用于「何时降级」的调度，不能作为硬安全证明；这正是 R74 把硬/软审计分家的理由。

**引理 42（MVP 分辨率的可加性）** 论文档 M_core 与真实系统的差 = 被推迟的研究债的分辨率增益之和；每个债项带触发条件，故 MVP 不是「简化近似」，而是「按证据触发的惰性展开」。若某债项触发而在 MVP 中缺失，则该场景的安全性退回 S_min（保守但安全），故**惰性展开不破坏安全单调性**，只损失性能。

**定理 30（策略无关安全 ⇒ 黑箱可热替换）** 在引理 38–40 下：对任意策略 π_θ 与 π_θ′，若二者经同一 MW/BEC 接口接入同一 PASK，则安全不变量与证书逐项相同，仅 BEC 的能力集 c_t 更新。⇒ 策略热替换 0 行安全代码改动，认证成本与 `|θ|` 无关。**这是 R73 热替换定理对「未知实现」的极限推广：不是同契约替换，而是「对策略无契约替换」。**

**定理 31（MVC 的覆盖-面权衡）** R74 的**可证安全面** = Safety(PASK) 是 R73 可证安全面的子集（因 R73 还证每个模块内部一致性），但 R74 的**适用范围**严格更大（包含任意黑箱 π）。⇒ 这是一个**偏序权衡**：`R73 ≺_cover R74`，`R74 ≺_surface R73`；当 π 为白盒 EC 时二者重合（定义 395）。**系**：不存在「既更细归因又覆盖黑箱」的免费午餐——必须显式选择。

**定理 32（MVP 的证伪充分性）** 若 MVC-C 在 MB-MVP 上被证伪（不存在同时满足安全 (i) 与性能 (ii) 的 PASK），则在「策略只能外部观测」这一现实约束下，任何以证据契约为承重墙的架构（含 R73 及其全部细化）都无法同时保证安全与可用。⇒ MB-MVP 是纲领的**最小杀死实验**。证明要点：只需构造一个使 S_min 触发率与任务成功率此消彼长的任务族（人近距 + 高精度），即可让 (i)(ii) 不可兼得，而该任务族属于任何具身部署的必要子集。

## 6. 本轮最大风险

**一句话**：R74 用「安全必须策略无关」换来了对黑箱的覆盖，但代价是把安全命题压缩到**无证据安全集 S_min**——如果 S_min 太小，系统会「安全地瘫痪」（MVC-C 的 (i) 靠什么都不做通过、(ii) 惨败）；如果 S_min 太大或不可从危险状态到达（引理 40 的 μ=∞），策略无关定理对真实危险区就是**空洞的**，系统会在「证书齐全、盾每次都合规」的情况下以 S_min 为名行使危险动作；而 MVP 若只测 (i) 不测 (ii)，就会把这种「安全但无用」或「空洞安全」误判为成功——即 MVP 纪律本身可能被 Goodhart 化，成为掩盖承重墙裂缝的工具。

次级风险与缓解：
1. **S_min 过保守导致瘫痪** → E401/E402 强制同时报告 (i)(ii) 与帕累托前沿；ρ 预注册不可事后调。
2. **μ(S_min)=∞ 的空洞安全** → E398 显式标出不可达危险区，并把「不可达」作为**硬失败**而非通过。
3. **MVP 只证安全不证可用（Goodhart）** → MVC-C 的 (i)(ii) 必须**联合**成立才算通过；KillTest 绑定联合条件。
4. **ACI 被误当硬安全** → 定义 388 显式把 ACI 标注为「统计性、非逐指令」；硬安全只引用 PASK。
5. **BEC 校准集被策略主动污染（闭环选择偏差）** → SEAL-BEH 由外部随机化采样的 context 生成，策略无法选择校准输入；周期性重校准。
6. **盾的最小侵入投影破坏任务语义** → 投影只改「越界分量」，并与策略的 action chunk 对齐；E402 监测投影频率。
7. **研究债触发器校准失败（误报/漏报）** → E404 显式评估触发器；触发器亦带版本与证伪记录。
8. **把 UniBot 当单一实体会掩盖其内部失效** → 明确：R74 不为 π 内部失效背书；π 的任何能力缺陷只通过 c_t 与 Gate 反映为性能下降/接管，不进入安全证书。

```python
# IP-303 BEC：黑箱证据契约（外部行为校准，不声明内部）
@dataclass(frozen=True)
class BlackBoxEvidenceContract:
    pi_ref: object                      # 只可 query 的黑箱策略
    calib: CalibSet                     # SEAL-BEH：(ctx, instruction, action, outcome)
    alpha: float                        # 名义误覆盖率
    d_beh: Predicate                    # 行为有效域（指令族/阶段/构型/输入包络）
    aci: ACIState                       # 自适应 conformal 状态（长程软审计）
    w_q_us: float                       # 查询延迟预算
    def competence(self, ctx) -> CompetenceSet:   # A_α
        return self.aci.predict(ctx)              # 只做行为声明

# IP-304 MW：计量包装器（策略当环境，证据只来自身体）
class MetrologicalWrapper:
    def __init__(self, body_ec, bec): self.body_ec, self.bec = body_ec, bec
    def wrap(self, obs, instruction, body_state):
        e = self.body_ec.update(obs, body_state)      # DPEM† 白盒证据
        a = self.bec.pi_ref.query(obs, instruction)    # 黑箱提议（不审计内部）
        c = self.bec.competence(ctx(body_state, instruction))
        gate = self.body_ec.gate(e) and self.bec.d_beh(body_state) and c.in_range
        return EvidencePacket(e=e, a=a, c=c, gate=gate,
                              tau=e.tau.merge(self.bec.calib.tau))

# IP-305 PASK：策略无关安全核（安全不引用 pi 内部）
class PolicyAgnosticSafetyKernel:
    def __init__(self, s_min, s_phys, body_cert): ...
    def safe_set(self, e, gate):
        if gate == 'INVALID':  return self.s_min          # 证据失效 → 无证据安全集
        if gate == 'DEGRADED': return self.s_min | self.evidence_margin(e, 'conservative')
        return self.s_min | self.evidence_margin(e, 'nominal')   # S_min ⊆ S_safe ⊆ S_phys
    def shield(self, s, a, e, gate):
        target = self.safe_set(e, gate)
        if self.predict(s, a) in target: return a                 # 提议合法
        return self.minimal_intrusion_project(s, a, target)       # 最小侵入投影

# IP-306 Gate + ACI：把审计拆成确定性与统计性两层
def evidence_gate(e, bec, body_state, aci):
    if not e.valid or not bec.d_beh(body_state): return 'INVALID'
    aci.update(e, bec)                                 # 更新长程误覆盖
    if aci.miscoverage() > bec.alpha + DELTA: return 'DEGRADED'   # 漂移 → 保守
    return 'VALID'

# IP-307 MVP 账本：承重墙与带触发器的研究债
MVP_CORE = ['MW', 'PASK', 'BEC', 'MB_MVP']
RESEARCH_DEBT = {
 'DMEM':        dict(trigger=('transparent_vs_opaque_fail_ratio', 2.0, '>', 'promote')),
 'SIGMAREFLEX': dict(trigger=('aci_coverage_drift', DELTA, '>', 'promote')),
 'ECG':         dict(trigger=('causal_chain_break_rate', 0.3, '>', 'promote')),
 'CCA_PAR':     dict(trigger=('cross_modal_conflict_rate', 0.05, '>', 'promote')),
 'PER_BODY_MIC':dict(trigger=('swap_requires_core_edit', 0, '>', 'promote')),
}
def load_core(results):                            # 触发器自动把债转 core
    return MVP_CORE + [m for m, t in RESEARCH_DEBT.items()
                       if t['trigger'][0] in results
                       and breach(results[t['trigger'][0]], *t['trigger'][1:3])]

# IP-308 MVC 主循环：黑箱策略 + 白盒身体 + 策略无关盾
def MVC_round(S, obs, instruction):
    body = S.body_state()
    pkt  = S.mw.wrap(obs, instruction, body)            # IP-304
    gate = evidence_gate(pkt.e, S.bec, body, S.bec.aci) # IP-306
    a    = pkt.a
    a_safe = S.pask.shield(body, a, pkt.e, gate)        # IP-305（不读 pi 内部）
    S.ctrl.execute(a_safe)
    S.log.write(pkt, gate, a, a_safe, cert=S.pask.cert) # 证书只引用 PASK+EC
    return a_safe, S.pask.invariant_ok()
```

## 4. 推导

**引理 38（包装合法性）** EC_body 有效 ∧ BEC 在 D_beh 内有效 ⇒ MW 输出满足 R73 的 EC 类型契约，参与 CCA 不破坏引理 34 单调性。黑箱策略只是「多了一个只能并联、不可分解的证据源」。

**引理 39（PASK 前向不变性，对任意策略）** Shield 投影在 `S_safe(e)` 上完备 ⇒ 对任意 π（含对抗 π），Gate 不降级时 `s_{t+1} ∈ S_safe(e_t)`；降级时 `s_{t+1} ∈ S_min`。证明只用身体动力学与 Shield 定义。**安全证明与策略正交。**

**引理 40（S_min 可达性裕度）** 若 `μ(S_min)` 有限，则 Gate 塌缩后存在有限制动时间 `T_b` 进入 S_min；若 `μ(S_min)=∞`，策略无关定理在该区域**空洞**。MVP 必须显式测量 μ。

**引理 41（闭环 ACI 长程覆盖）** `α_{t+1}=α_t+γ(α−err_t)` 使 `|(1/T)Σerr_t − α| ≤ O(1/(γT))+O(γ)`（任意有界漂移，无需可交换）；但仅长程平均，非逐点。⇒ ACI 只做降级调度。

**引理 42（MVP 分辨率的可加性）** M_core 与真实系统的差 = 被推迟债项的分辨率增益之和；债项触发而缺失时安全性退回 S_min（保守但安全）。**惰性展开不破坏安全单调性，只损失性能。**

**定理 30（策略无关安全 ⇒ 黑箱可热替换）** 引理 38–40 ⇒ 任意 π_θ 与 π_θ′ 经同一 MW/BEC 接入同一 PASK，则安全不变量与证书逐项相同，仅 c_t 更新。⇒ 热替换 0 行安全代码，认证成本与 \|θ\| 无关。**R73 热替换定理对「未知实现」的极限推广。**

**定理 31（MVC 覆盖-面权衡）** `Safety(PASK)` ⊆ R73 可证安全面，但 R74 适用范围严格更大（含任意黑箱 π）。偏序：`R73 ≺_cover R74`、`R74 ≺_surface R73`；白盒域重合（定义 395）。**无免费午餐：必须显式选择。**

**定理 32（MVP 证伪充分性）** 若 MVC-C 在 MB-MVP 上被证伪，则在「策略只能外部观测」约束下，任何以证据契约为承重墙的架构（含 R73 及全部细化）都无法同时保证安全与可用。**MB-MVP 是最小杀死实验。**

## 7. 本轮最大风险

**一句话**：R74 用「安全必须策略无关」换来了对黑箱的覆盖，但代价是把安全命题压缩到**无证据安全集 S_min**——如果 S_min 太小，系统会「安全地瘫痪」（MVC-C 的 (i) 靠什么都不做通过、(ii) 惨败）；如果 S_min 太大或不可从危险状态到达（引理 40 的 μ=∞），策略无关定理对真实危险区就是**空洞的**，系统会在「证书齐全、盾每次都合规」的情况下以 S_min 为名行使危险动作；而 MVP 若只测 (i) 不测 (ii)，就会把这种「安全但无用」或「空洞安全」误判为成功——即 MVP 纪律本身可能被 Goodhart 化，成为掩盖承重墙裂缝的工具。

次级风险与缓解：
1. **S_min 过保守导致瘫痪** → E401/E402 强制同时报告 (i)(ii) 与帕累托前沿；ρ 预注册不可事后调。
2. **μ(S_min)=∞ 的空洞安全** → E398 显式标出不可达危险区，并把「不可达」作为**硬失败**而非通过。
3. **MVP 只证安全不证可用（Goodhart）** → MVC-C 的 (i)(ii) 必须**联合**成立才算通过；KillTest 绑定联合条件。
4. **ACI 被误当硬安全** → 定义 388 显式标注为「统计性、非逐指令」；硬安全只引用 PASK。
5. **BEC 校准集被策略主动污染（闭环选择偏差）** → SEAL-BEH 由外部随机化采样的 context 生成，策略无法选择校准输入；周期性重校准。
6. **盾的最小侵入投影破坏任务语义** → 投影只改「越界分量」并与 action chunk 对齐；E402 监测投影频率。
7. **研究债触发器校准失败** → E404 显式评估触发器；触发器带版本与证伪记录。
8. **把 UniBot 当单一实体会掩盖其内部失效** → 明确 R74 不为 π 内部失效背书；π 缺陷只经 c_t 与 Gate 反映为性能下降/接管，不进入安全证书。
