# 第 60 轮（承接第 59 轮「执行接地层」IP-145~151；灵感循环重启第 1 轮；本轮灵感：「人机交互」×「无刷电机」）

> 第 59 轮把证据层一路接到底层执行：BUQ 用 UKF 辨识电机结构不确定性、ERTC 把实时性契约化、EEIS 把 δ_f 编译成阻抗证书、CLEP 把执行实测作为第 5 模态回传。但它把「人」放错了位置：要么把人体塞进环境阻抗集 Z_env 当作**被动阻抗**，要么把人的介入压缩成**离散的外部监督事件 EV-human**。这忽略了 HCI 的两个硬事实：**(1) 人是闭环里会主动注入能量、会因机器人行为而改变自身阻抗的共适应子系统；(2) 人与机器人之间唯一的物理通道就是执行器本身**——同一根 BLDC 既在「作用于世界」，也在「作用于人」。本轮两个灵感在此合流：**无刷电机不只是力源，它同时是力传感器与触觉显示器；人机交互不只是界面，它是控制回路里的非线性、时变、带延迟、会学习的环节**。核心命题：**「同一根执行通道，必须同时对世界诚实、对人诚实」——触觉诚实性（Haptic Honesty）**：机器人向人呈现的刚度、力与柔顺感，必须与证据层的真实置信一致，不得「过度自信地硬」，也不得「虚假地软」。

核心矛盾：
- **H32（共适应稳定性·被动性假设崩塌）**：第 59 轮的 Z_env 默认是无源（passive）的，于是 μ 分析 / 小增益定理成立。但人体阻抗 Z_h(s) 含**主动分量**（某些频段 Re[Z_h]<0，向系统注入能量）、神经与肌肉延迟 τ_h≈150–250 ms，且会随机器人刚度**共适应**。两个各自稳定的系统耦合后仍可能失稳（人机「抖」「打摆」）；更麻烦的是，共适应让闭环辨识产生混淆——观测到的 Z_h 已经是机器人行为的函数，不是人的固有属性。
- **H33（通信即扰动·触觉信道容量）**：把置信度 δ_f 渲染成触觉线索（微振动、刚度微调、阻尼脉冲）不是免费的：它本身就是叠加在**共享任务通道**上的力扰动，受 Weber 分数（刚度可辨阈约 10%）、延迟 τ_h、注意力带宽 B_hap 限制。存在**率失真 + 物理代价**权衡：披露越频繁、越精细，任务越差、人越烦。
- **H34（干预即证据·内生性与循环）**：人抓取、推挡、急停是强信号，但它由机器人自身行为与披露触发（内生），又可能携带机器人没有的私有信息（外生）。朴素融合会**双重计数**：机器人越表现得不自信 → 人越介入 → 被当成「环境危险」的证据 → 机器人更不自信，形成正反馈振荡。必须做因果拆解。
- **H35（触觉诚实性·物理等价≠感知等价）**：诚实不是物理量，而是**人感知量**：齿槽脉动、电流环饱和、PWM 死区、齿轮摩擦残差都会被人「摸到」；能渲染的刚度又受 Colgate 条件 B>K·T_s/2、电流环带宽与端到端延迟约束。需要**感知加权的诚实性证书**与**可渲染阻抗集**，而不是只报一个物理刚度值。
- **H36（信任校准·披露的双向耦合）**：过度披露 → 认知过载、反而怀疑「它到底行不行」；过度自信 → 一次失败就信任崩塌。披露策略影响信任，信任影响依赖与干预，干预又作为证据回流——闭环可振荡。披露策略本身需要可认证的稳定条件。

## 0. 直觉与动机

**灵感 1（人机交互 → 人的共适应阻抗与耦合稳定 CHI）**
直觉：人握住机器人末端时，不是一个弹簧阻尼器接上来，而是**一个带延迟、会调增益、会学习的控制器**接上来。人感到机器人太硬，会主动放松/顺从；感到太软，会主动收紧/接管。设交互端口力为 F、速度为 v，机器人呈现导纳 Y_r(s)：v=Y_r(s)F；人的阻抗 Z_h(s)：F=Z_h(s)(v_h^des−v)。闭环特征方程 1+Y_r(s)Z_h(s)=0。若 Z_h 与 Y_r 都无源，互联稳定；可人的主动分量让 Re[Z_h(jω)] 在低频甚至中频为负——**人是一个会向系统灌能量的「负阻尼」源**。于是 μ 分析和被动性论证必须升级为**含延迟的耦合稳定证书**：用能量罐（energy tank）实时记账，人体注入能量超过预算就由虚拟阻尼耗散；用 Padé 近似把 e^{−sτ_h} 展开成乘性不确定性，把「延迟抖动」并入 μ 的 Δ 块。更深一层：共适应意味着 φ_h(t+1)=φ_h(t)+η·g(Z_r(t))，辨识必须在**闭环**里做——用机器人自身已知的微抖动 z 作工具变量（z 对机器人是已知外生输入，对人体私有意图近似外生），或利用「人接管」时段做**干预式辨识**。

**灵感 2（无刷电机 → 无传感器触觉致动 SHA）**
直觉：第 59 轮把齿槽/脉动/饱和/摩擦当作要「消除的证据噪声」；在 HCI 里，它们是**人摸得到的触觉伪影**。反过来看，只要把这些项精确建模并从电磁转矩中减掉，剩下的残差就是**外部（人/环境）施加的力矩**——BLDC 立刻变成一台**无传感器力矩传感器**：
τ̂_ext = k̂_t·i_q − Ĵ·ω̇ − B̂·ω − τ̂_ripple(θ_e;ξ_exec) − τ̂_cog(θ_e;ξ_exec) − τ̂_fric(sign ω;ξ_exec)。
不需要额外六维力传感器，就用同一根电机实现「力源 + 力感知」。但渲染能力有硬边界：采样周期 T_s 下，要渲染虚拟刚度 K、阻尼 B，需满足 Colgate 被动性条件 B > K·T_s/2；电流环带宽与端到端延迟进一步压低可渲染刚度上限；齿轮摩擦残差决定**力分辨率地板 ΔF_min**——小于它的交互力人摸不到、机器人也测不准。于是「触觉诚实」的第一层含义：**只在可渲染集 R_set 内许诺刚度，绝不渲染超出带宽/被动性边界的「假硬」。**

**灵感 3（人机交互 × 无刷电机 → 触觉诚实性编译 HHC）**
直觉：证据层此刻的信念不是一个数，而是一个分布（融合后验 + 共形带 + 证据年龄 + OOD 标志）。诚实渲染应满足：**渲染出的阻抗必须落在信念的可行集里**。若信念说环境刚度可能是 [200, 2000] N/m，机器人把刚度渲染成 3000 N/m 就是「假装确定」；若信念很强但机器人故意渲染成极软，是「假装无知」。定义感知加权诚实误差 e_hap=‖W_perc(s)·(Z_r(s)−Z*(s))‖ + 脉动残差的可感知谱能量；Z* 由融合信念与不确定性共同决定。当证据陈旧/OOD 时，Z* 自动向柔顺端平移——**让不确定性「摸得出来」**，人便能及时接管。这把第 59 轮的「安全编译 EEIS」从「对机器安全」扩展为「对机器安全 ∧ 对人诚实」。

**灵感 4（人机交互 → 触觉披露信道 THC）**
直觉：既然执行器是唯一物理通道，机器人「告诉人它有多不确定」也只能靠这条通道——微振动编码、刚度微调、阻尼脉冲。这是一个**低带宽、有噪声、有延迟、带物理副作用**的信道：人耳/人手对刚度变化的可辨阈约 10%（Weber），触觉事件率与注意力有限。于是披露是一个**率失真 + 物理代价**问题：给定内部置信状态 c=(δ_f, τ_evidence, D⁺, OOD)，选编码 u_hap，使人的置信估计 ĉ 失真最小、任务扰动与不适最小，且互信息 I(c;ũ) ≤ C_hap、占空比 ≤ ρ_hap。关键判据是 **VOI_human**：只有当「披露后人的决策熵下降」大于「披露造成的任务/舒适代价」时才说。不是把所有不确定都倒给人。

**灵感 5（人机交互 → 干预即证据的因果门 HECG）**
直觉：人拉一把，可能因为「机器人要撞了」（机器人自己的行为诱发，内生），也可能因为「人看到了机器人没看到的东西」（私有信息，外生）。把干预直接当证据会形成正反馈：不自信 → 人介入 → 更不自信。正确做法是因果拆解：控制住机器人动作 A 与披露 U，只看 I 的**条件变异**；用 e-value / Rosenbaum 敏感性界约束「人类私有信息确实对应危险」这一假设的可信度。规则与第 59 轮 EV-exec 同构但更强：**人因证据只能「加宽后验 / 触发降级 / 请求确认」，永远不能单独满足佐证门、不能减少探针需求**；只有在独立模态确认后才允许转为正向证据。这正是「干预即证据，但干预是内生变量」的工程化。

**灵感 6（合流 → 三向契约 HCLP）**
直觉：第 59 轮是「证据层 ↔ 执行层」双向契约；本轮加入人，成为**三向契约**：证据层给执行层带证书的阻抗包，执行层给证据层带审计的执行证据，而**人通过物理通道接收「可感知的置信」，也通过物理通道回传「带因果标注的干预」**。闭环算子 HCLP 把 CHI→HCSC→EEIS+→SHA→HHC→THC→Execute→HECG→Update 串起来。安全不再是单一的 P_safe，而是**三向福利编译**：机器安全 δ_robot、人体伤害风险 δ_human（按身体部位力/压强限，参照协作机器人 PFL 思想）、触觉诚实性 δ_comm，三者在总预算 δ_f 下用 Boole 不等式分配，并做保守度最小化。

## 2. 关键算法伪代码

### IP-152 CHI（人机共适应阻抗辨识）

```python
class CoupledHumanIdentifier:
    def __init__(self, prior_phi, prior_cov, T_ctrl):
        self.phi = prior_phi      # m_h,b_h,k_h,tau_h,gamma_a
        self.P = prior_cov
        self.T = T_ctrl
        self.dither = []          # 机器人已知微抖动历史
        self.id_epochs = []       # 人接管时段

    def identify(self, port_hist, dither_hist, takeover_mask):
        # 工具变量：dither 为机器人已知外生输入，与人体私有意图条件独立
        # 回归 F_h = Z_h(s)(v_des - v) + e，用 dither 作 v 的工具变量
        Z = np.array(dither_hist)
        v = np.array([h.v for h in port_hist])
        F = np.array([h.F for h in port_hist])
        # 两阶段最小二乘（离散 ARX 近似 Z_h）
        phi_iv = self._tsls(Z, v, F)
        # 人接管时段：可直接激励，补充辨识（消除共适应混淆）
        if takeover_mask.any():
            phi_take = self._direct_fit(port_hist[takeover_mask])
            phi_iv = self._fuse(phi_iv, phi_take)
        self.phi = self._ekf_update(self.phi, phi_iv, self.P)
        # 共适应检测：phi 与 Z_r 的相关性显著 ⇒ 标记 co_adapting
        self.co_adapting = self._detect_co_adaptation(self.phi, port_hist)
        return self.phi, self.P

    def is_human_ood(self, alpha_h=0.01):
        d = self.phi - self.prior_phi
```

```python
import numpy as np
from scipy.stats import chi2

class CoupledHumanIdentifier:
    """工具变量（机器人已知微抖动）+ 接管激励双通道辨识人体阻抗。
    共适应：phi_h 是 Z_r 的函数，必须在闭环中用外生抖动做 IV。"""
    def __init__(self, prior_phi, prior_cov):
        self.prior_phi = np.asarray(prior_phi, float)   # [m,b,k,tau,gamma_a]
        self.phi = self.prior_phi.copy()
        self.P = np.asarray(prior_cov, float)
        self.co_adapting = False

    def _tsls(self, Z_dither, v, F, lags=2):
        # ARX 近似：F[t] = sum_i a_i F[t-i] + sum_j b_j v[t-j] + e
        # 用 dither 作 v 的工具变量，消除闭环共适应偏置
        X = build_arx(v, F, lags)
        Zinst = build_arx(Z_dither, F, lags)
        # 两阶段：先回归 v~dither 得 v_hat，再用 v_hat 回归
        v_hat = lstsq(Zinst, X[:, :lags])
        phi_arx = lstsq(np.column_stack([X[:, :lags], v_hat]), F)
        return arx_to_impedance(phi_arx)

    def _direct_fit(self, takeover_hist):
        # 人接管时段：机器人让权，v 不被 Y_r 主导，可直接辨识 Z_h
        return fit_impedance(takeover_hist)

    def identify(self, port_hist, dither_hist, takeover_mask):
        v = np.array([h.v for h in port_hist])
        F = np.array([h.F for h in port_hist])
        phi_iv = self._tsls(np.array(dither_hist), v, F)
        if takeover_mask.any():
            phi_iv = fuse_estimates(phi_iv, self._direct_fit(port_hist[takeover_mask]))
        # 慢变 EKF
        K = self.P @ np.linalg.inv(self.P + R_PHI)
        self.phi = self.phi + K @ (phi_iv - self.phi)
        self.P = (np.eye(len(self.phi)) - K) @ self.P
        # 共适应：phi 的慢分量与 robot 刚度历史相关
        self.co_adapting = abs(spearmanr(self.phi[2], history_Kp())) > 0.6
        return self.phi, self.P

    def is_human_ood(self, alpha_h=0.01):
        d = self.phi - self.prior_phi
        return float(d @ np.linalg.inv(self.P + np.eye(len(d))*1e-9) @ d) \
               > chi2.ppf(1-alpha_h, len(d))
```

### IP-153 HCSC（耦合稳定 + 能量罐）

```python
ETANK_INIT, EPS_E, E_ACT_MAX = 1.0, 0.02, 0.6

class CoupledStabilityCertifier:
    def __init__(self, robot_admittance, T_s):
        self.Yr = robot_admittance
        self.Ts = T_s
        self.E_tank = ETANK_INIT
        self.pc_enabled = False
        self.version = 0

    def delay_uncertainty(self, tau_lo, tau_hi):
        tau_mid = 0.5*(tau_lo+tau_hi)
        w = (tau_hi-tau_lo)/(2+tau_hi+tau_lo)
        return tau_mid, w

    def certify(self, phi_hat, Sigma_h, tau_lo, tau_hi, gamma_max):
        tau_mid, w_d = self.delay_uncertainty(tau_lo, tau_hi)
        mu_max = 0.0
        for phi in ellipsoid_boundary(phi_hat, Sigma_h, alpha=0.01, n=16):
            for ga in (0.0, gamma_max):
                Zh = human_impedance(phi, active_gain=ga, delay=tau_mid)
                mu_max = max(mu_max, mu_analysis_delay(self.Yr, Zh, w_d))
        ok = (mu_max < 1.0) and (self.E_tank > EPS_E)
        self.version += 1
        return ok, CertHCSC(mu_max, gamma_max, E_ACT_MAX, tau_mid,
                            phi_hat.copy(), self.version)

    def step_energy_tank(self, F, v, dt):
        P_in  = float(np.dot(F, v))                 # 人注入功率
        P_dis = self._damping_power(v) if self.pc_enabled else 0.0
        self.E_tank += (P_in - P_dis) * dt
        # 硬记账：能量罐不许被"预支"
        if self.E_tank < EPS_E:
            self.pc_enabled = True
        if self.E_tank < 0.0:                        # 记账泄漏 ⇒ 硬降级
            return False, "energy_tank_underflow"
        return True, "ok"

    def _damping_power(self, v):
        return float(np.sum(self.b_pass * np.asarray(v)**2))
```

### IP-154 SHA（无传感器触觉致动）

```python
class SensorlessHapticActuator:
    def __init__(self, buq, motor, T_s, kappa=3.0):
        self.buq, self.motor, self.Ts, self.kappa = buq, motor, T_s, kappa
        self.last_Sigma = np.eye(3)

    def observe_external_torque(self, t):
        xi = self.buq.ukf.x
        tau_em  = xi.k_t * t.i_q
        tau_dyn = xi.J * t.alpha + xi.B * t.omega
        tau_rip = self.buq.ripple_torque(t.theta_e, xi)
        tau_cog = self.buq.cogging_torque(t.theta_e, xi)
        tau_fri = xi.c_fric * np.sign(t.omega)
        tau_ext = tau_em - tau_dyn - tau_rip - tau_cog - tau_fri
        J = self.buq.jacobian_ext_torque(xi, t)
        self.last_Sigma = J @ self.buq.ukf.P @ J.T + self.buq.R_torque
        return tau_ext, self.last_Sigma

    def renderable_set(self, omega_c, loop_latency):
        K_max = stiffness_limit(omega_c, self.Ts, loop_latency)  # 带宽/延迟上界
        dF = self.kappa * np.sqrt(np.trace(self.last_Sigma))
        return RenderSet(K_p_max=K_max,
                         colgate_slope=self.Ts/2.0,   # B > K*Ts/2
                         delta_F_min=dF, omega_c=omega_c)

    def is_renderable(self, K, R):
        return (K.K_p <= R.K_p_max and
                K.K_d > K.K_p*R.colgate_slope and
                K.K_p * EPS_TRAJ > R.delta_F_min)
```

### IP-155 HHC（触觉诚实性编译）

```python
class HapticHonestyCompiler:
    def __init__(self, perception):
        self.W = perception.frequency_weight()
        self.weber = perception.weber_stiffness()   # ~0.1
        self.version = 0

    def target(self, fused, U):
        # 不确定/陈旧/OOD ⇒ 目标向可行集下分位（更软，可被感知）
        if U.ood or U.tau_evidence > U.tau_max or U.delta_f > U.delta_f_hi:
            return fused.stiffness_quantile(0.25)
        return fused.stiffness_mean

    def error(self, K, Z_star, xi):
        e_phys = np.linalg.norm(self.W * (impedance_of(K) - Z_star))
        ripple = self._perceptual_ripple(xi)      # 齿槽/脉动残差可感知谱
        return e_phys + LAMBDA_R * ripple

    def project(self, K_safe, R_set, fused, U, xi):
        Z_star = self.target(fused, U)
        cand = [K for K in K_safe if K.K_p <= R_set.K_p_max
                and K.K_d > K.K_p*R_set.colgate_slope]
        if not cand:
            return None, None
        best = min(cand, key=lambda K: self.error(K, Z_star, xi))
        e = self.error(best, Z_star, xi)
        soft_shift = 0.0
        # 单侧柔顺回退：只许更软更稳，绝不为"诚实"而变硬
        while e > EPS_HAP and best.K_p > K_P_MIN:
            best = soften(best, 0.9)
            soft_shift += 0.1
            e = self.error(best, Z_star, xi)
        self.version += 1
        cert = CertHap(best, Z_star, e, EPS_HAP, DELTA_HAP,
                       soft_shift, self.version)
        return best, cert
```

```python
class TactileDisclosure:
    """事件触发 + 率失真 + 物理代价。披露本身就是扰动，不能白说。"""
    def __init__(self, C_hap, rho_hap, human):
        self.C_hap, self.rho_hap, self.human = C_hap, rho_hap, human
        self.duty_acc = 0.0

    def decide(self, c, budget, dt):
        c_hat = self.human.estimate_confidence()
        if abs(c.score - c_hat) < THETA_HAP:
            return None
        best_u, best_v = None, -1e9
        for u in encode_book(c, levels=3):
            if not perceptible(u, self.human.weber):       continue
            if not within_capacity(u, self.C_hap, self.human): continue
            if self.duty_acc + dt*u.duration > self.rho_hap:   continue
            if not preserves_honesty(u):                    continue
            voi = self.human.decision_entropy(c_hat) \
                  - self.human.decision_entropy(self.human.predict(c_hat, u)) \
                  - LAMBDA_U*physical_cost(u)
            if voi > best_v:
                best_u, best_v = u, voi
        if best_v <= THETA_VOI:
            return None
        self.duty_acc += dt*best_u.duration
        return best_u
```

```python
def haptic_closed_loop(M, cp, delta_f_req, budget):
    budget.dt = M.dt_control
    # ① CHI
    phi_h, Sigma_h = M.chi.identify(M.port_hist, M.dither_hist, M.takeover_mask)
    if M.chi.is_human_ood():
        return degrade_human(M, cp, "human_ood")
    # ② HCSC
    ok, cert_hcsc = M.hcsc.certify(phi_h, Sigma_h, TAU_MIN, TAU_MAX, GAMMA_MAX)
    if not ok:
        return degrade_human(M, cp, "coupled_instability")
    # ③ EEIS+（把人体不确定性并入环境集，并加入人体伤害约束）
    Z_env = M.eeis.build_env_model(M.buq.ukf.x, M.fused[cp.region], M.b_r[cp.region])

    alloc = allocate_risk(delta_f_req, cp.human_region, Z_env)
    K_safe, cert_eeis = M.eeis.compile(alloc, M.fused[cp.region],
                                       M.buq.ukf.x, Z_env)
    if K_safe is None:
        return degrade_human(M, cp, "eeis_infeasible")
    # ④ SHA
    tau_ext, Sigma_ext = M.sha.observe_external_torque(M.telemetry)
    R_set = M.sha.renderable_set(M.control_bandwidth, M.loop_latency)
    # ⑤ HHC

    if K_honest is None:
        return degrade_human(M, cp, "honesty_infeasible")
    # ⑥ THC
    c = confidence_state(M, delta_f_req)
    u_hap = M.thc.decide(c, budget, M.dt_control)
    if u_hap is not None:
        render_haptic_cue(u_hap)
    # ⑦ Dispatch & Execute
    dispatch(K_honest, cert_hap, cert_hcsc, cert_eeis)
    tel = execute_contact(cp, K_honest, M.contact_timeout, record_port=True)
    M.port_hist.append(tel.port)
    # ⑧ HECG

    # ⑨ Trust

                              ev_h, u_hap, M.hcsc.E_tank, M.trust))

def allocate_risk(delta_f_req, region, env):
    # 三向 Boole 分配，保守度最小化
    d = proj_simplex([delta_f_req/3]*3, delta_f_req)
    lam = minimize(lambda w: conservatism(w, region, env),
                   x0=d, bounds=[(0, delta_f_req)]*3,
                   constraints=[sum(x) <= delta_f_req])
    return RiskAlloc(robot=lam[0], human=lam[1], comm=lam[2])
```

## 6. 本轮最大风险

**一句话**：本轮把「人」与「触觉」纳入安全论证，但人的模型（阻抗主动性、延迟、感知 Weber、信任动力学、私有信息）本质上不可完全辨识且会随机器人改变；一旦 CHI 共适应辨识有偏、HCSC 能量罐记账泄漏、HHC 的 W_perc 失配、或 HECG 因果图遗漏混杂，就会出现「系统自证人机和谐、实际却在正反馈振荡或过度披露」的隐蔽失效——尤其「干预即证据」若被实现成双向，会制造越帮越忙的焦虑回路。必须以「耦合 μ 证书 + 能量罐硬记账」「可渲染集封死假硬」「诚实误差可审计回退」「人因证据单向加宽 + 因果敏感性界」「披露 VOI 事件触发 + 占空比硬限」五重护栏，宁可显得谨慎啰嗦，也不允许把人当作可随意建模的被动环境。
