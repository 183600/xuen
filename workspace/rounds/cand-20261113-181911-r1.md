# 第 67 轮（新灵感驱动研究循环 第 2 轮；本轮灵感词：「本体感知」×「迭代验证」）

> 承接第 66 轮 UniBot 主线。本轮不重开清单，只做一个「换主信号 + 换验证范式」的深挖：把数字孪生验收从**视觉位姿的一次校验**升级为**本体感知残差驱动的迭代系统辨识**。产物区 v2 深化 IP-C02→C02′、IP-C08→C08′，新增 C11（接触相标注）与 C12（验证阶梯/主动重放）。

## 0. 本轮检索核实（检索日期 2026-11-13）

1. **提交接口观测全表**（github.com/unitreerobotics/unibot_submission README，本轮已取到正文）：图像 4 路（`cam_left_high`/`cam_right_high`/`cam_left_wrist`/`cam_right_wrist`）；状态为 `left_arm[7]`、`right_arm[7]`、左右 `ee_pose_gripper_base[6]`、左右 `gripper[1]`、`lower_body[15]`；语言 `observation.language`。**没有关节力矩/电流/触觉通道**。动作在 `joint` 模式下是目标关节位置、在 `ee` 模式下是目标末端位姿，二者互斥；`action_chunk_size`、`obs_delta_indices`、N 连续端口、逐步延迟与动作规律计入可信度——均与上轮一致。
   → 直接推论：**任何依赖 τ/触觉的方案在评测时都拿不到输入**；能用的本体信号只有「命令 vs 达成」的差。
2. **同类 G1 公开数据集**（如 g1-inspire-* / TWIST2 系列）常带 `observation.effort`（电机力矩估计）与触觉；但那是**数据侧**字段，不等于**评测接口**字段。若官方 32k 数据也含 effort，可作离线标定辅助；**部署策略不得依赖**，以接口为准。
3. **跟踪误差 ↔ 接触**：NoContactNoWorries（arXiv 2606.24450，本轮检索）报告了 `||q_cmd − q||` 与接触事件的统计相关（Spearman）；Blind Dexterity（arXiv 2608.29487）用纯本体感知的「接触诱导跟踪偏差」做操作，并明确其局限（关节级残差低维、多解、难定位）；Im2Contact（Kim et al., CoRL 2023, PMLR v229）把本体与视觉结合做接触定位。→ **跟踪残差是有物理依据的接触代理，但低维多解**。
4. **迭代系统辨识**：iterative simulation calibration（Tan et al., simulationBasedDesign）用「仿真标定↔轨迹优化」交替闭环；Beyond Binary（arXiv 2605.28812）用贝叶斯优化匹配 sim/real 轨迹以标定执行器动力学；交互式接触自标定（arXiv 2403.13144）在 Gazebo 中用粒子滤波做接触式自标定。→ 迭代验证有成熟方法论可借。
5. **待核实（下轮首件事）**：官方 32k 数据集的 `action` 到底是关节目标还是末端目标、`observation` 是否含速度；以及接口 `cam_*_high` 是否与数据集 `head_stereo_left/right` 同为**已矫正**立体对（接口未承诺 rectified）。这决定 C06 与重放空间的选择。

## 1. 直觉（先讲人话）

**灵感 1：本体感知 = 从「看起来像」到「推起来像」。**
上一轮用视觉重放物体位姿来验收仿真。可视觉恰在三个最难处最不可靠：手挡住操作点、柔性物没有形变模型、渲染有域差。本体感知换了个问法：**同一段命令下，机器人「感觉到的阻力」是否一样？** 自由空间里命令与达成几乎重合；一旦接触/被推，达成滞后于命令，残差的时序形状就是摩擦、接触刚度、柔顺性、负载的直接指纹。对接触任务，真正要迁移的不是像素，而是「命令下去后世界如何反推机器人」。

**灵感 2：迭代验证 = 从「打一个分」到「知道改哪个旋钮」。**
一次验收只给 trust 一个标量，无法归因。迭代验证把它做成三层闭环：内环对每个任务做**接触参数系统辨识**（目标 = 跟踪残差剖面）；中环让仿真数据生成/课程随 trust 更新；外环用稀缺真机槽更新 trust 与预算。再加一条停止原则：**残差降到平台（不再随参数改善）即为该任务的信任边界**——但平台高低本身还不够，必须同时通过「可辨识性」检查（残差对参数是否敏感），否则残差小可能只是参数无关，而不是仿真对。

**合流 → 本轮核心命题：**
> 把孪生验收从「视觉一次校验」升级为「命令-达成跟踪残差驱动的迭代系统辨识」：以跟踪残差为主信号、视觉只做几何/资产对齐；用主动重放把 32k 演示压成每任务的「接触可信域 + 可辨识性」二元标签；由验证阶梯（L0 运动学→L1 接触残差→L2 DryRun→L3 真机槽）决定仿真数据能花在哪、真机槽该花在哪。

## 2. 严谨定义

**定义 1（本体感知轨迹）** ξ_{1:T}={(q_t,q̇_t,p_t,R_t,g_t)}_{t=1}^T，q∈R^14（双臂关节）、(p,R)∈SE(3) 为末端位姿、g∈R^2 为夹爪；q̇ 可由差分得到。全部可由接口观测构造，**不含 τ**。
**定义 2（命令-达成跟踪残差）** joint 模式：ρ_t = a_t − q_{t+1}（目标减达成），按关节尺度标准化 ρ̃_t=ρ_t/σ_j；ee 模式：ρ_t=[p^tar_t−p_t; log(R_t^T R^tar_t)]。自由空间 ρ≈0；接触或外扰使其增大。
**定义 3（重放与残差目标）** 重放算子 ξ̂_{1:T}(θ)=Sim(a_{1:T};θ)，θ 为物理参数（关节/接触摩擦、接触刚度与阻尼、负载质量、控制增益与延迟）。目标 D(θ)=Σ_t w_t‖ρ̃_t−ρ̃̂_t(θ)‖² + λ·D_kin(q,q̂) + μ·D_ik，w_t 在接触相放大；D_ik 只在跨控制空间重放时出现。
**定义 4（接触相自动标注）** 用 ρ̃_t 的变点/阈值把每条演示分为 φ_t∈{approach,contact,grasp,transport,release,slip}；无需人工标签，可在 32k 上批量生成。
**定义 5（迭代信任度）** 设 θ*_τ 为迭代辨识收敛点、D*_τ=D(θ*_τ)、D0 为噪声底，trust_τ = σ((D0+m−D*_τ)/s) × 1[I_τ(θ*_τ)≻εI]，其中 I_τ 为 Fisher 信息、第二因子是**可辨识性门**。用**收敛残差**而非初始残差，避免把「没调好」误判为「不可信」。
**定义 6（验证阶梯）** L0 运动学一致（q 重放误差）→L1 接触残差匹配（ρ 剖面）→L2 仿真 DryRun 成功率→L3 真机槽。晋级逐级；失败回退到该层重新标定；L3 结果回写更新 trust。
**定义 7（主动重放）** 在预算 B 段内选段集 S 最大化 logdet(I+Σ_{t∈S}g_tg_tᵀ/σ²)（D-最优），即用最少重放换最小参数椭球体积；强制覆盖各接触相以防退化。

## 3. 为什么这次可能真的赢

- **免费激励**：32k 演示天然提供「命令-达成」成对数据，等于对每台真机、每个任务做了一次免费的系统辨识激励；不需要额外采数。
- **对症下药**：上一轮最大风险是「柔性/插拔任务孪生对齐不下来」。本轮不要求把柔性物建对，只要求**机器人感受到的阻力剖面对**——这把「物体精确建模」问题弱化为「交互响应匹配」问题。
- **可迭代**：trust 从静态判决变成可改进量，且给出「何时停/何时该采真机」的原则，直接服务 A0 下的预算分配。
- **复用**：C01 SceneSpec、C10 DryRun、C09 PortFleet 全部复用，增量集中在 C02′ 的标定管线。

## 4. 可证伪预测（下轮先做 E-C09/E-C10 来打脸）

- **P1**：在 ≥8 个混合任务上，「跟踪残差 trust」与真机迁移损失的 Spearman ≥0.5，且优于上一轮「视觉位姿 trust」。
- **P2**：接触/柔性任务的收敛残差平台高于刚体任务，但只要通过可辨识性门，其 trust 仍能预测迁移；未过门者一律判「不可辨识」而非「可信」。
- **P3**：D-最优主动重放用 ≤60% 的重放预算达到与随机重放相同的收敛残差。

## 5. 本轮最大风险（一句话）

最大风险：跟踪残差是**低维、多解**的接触代理——不同接触构型可产生相似关节残差，若真机成功还依赖残差不可观测的物体状态（柔性物拓扑、插头位姿），迭代验证可能「残差收敛 + 可辨识」却仍给出**虚假通过**，把仿真数据教向错误的接触策略，这比一次验收的直接拒绝更危险。

## 1. IP-C02′ TwinCal-Proprio（★ 本轮押注，深化 v1-C02）

**动机**：32k 演示是免费的本体「体检数据」。视觉重放在接触任务上受遮挡/柔性/域差三重污染；跟踪残差直接反映命令-达成关系，正对接触参数敏感。

**差异**：v1 用物体位姿重放误差做 trust；v2 用**三段式**标定：
- S1 运动学对齐（关节零位/连杆/相机外参 → 视觉与 q 重放，D_kin）；
- S2 自由空间对齐（approach 段：标定控制增益、延迟、关节阻尼，使 ρ≈噪声底）；
- S3 接触对齐（在 S2 基础上，用接触相残差辨识 μ,k,c、负载质量；BO/CMA-ES 最小化 D）。

并用**残差分解**把控制器滞后与接触贡献分开：ρ^contact ≈ ρ − ρ^free（ρ^free 由 S2 模型预测）。

**可行性**：高。重放只需观测+动作；无扭矩也能做。风险在动作空间与重放一致性。

**资源**：1–2 人月；单卡仿真（MuJoCo 主、Gazebo 交叉验证）；无需真机。

**步骤**：①抽每任务 ~50 条演示（含成功/失败若有）②S1 几何/运动学对齐 ③S2 自由空间标定 ④C11 接触相标注 ⑤S3 迭代 BO 辨识，记录 D_k 曲线 ⑥计算 D*、可辨识性 I_τ ⑦输出 trust 与「可信/不可辨识/禁用」三态 ⑧供 C01/C03/C10 使用。

**风险**：残差低维多解（见想法区最大风险）；动作空间不一致导致 D_ik 主导。缓解见 §9。

## 2. IP-C08′ ProprioGate（深化 v1-C08）

**动机**：扰动与接触丢失在「达成 vs 命令」空间即时可见，比视觉快且不受遮挡；这是接口内唯一的低延迟外扰通道。

**可行性**：高。**资源**：复用 C02′/C05。

**风险**：残差把「控制滞后」误判为接触（S2 未标定好时）。缓解：门限用 S2 自由空间残差上分位 + 每任务自适应。

## 3. IP-C11 ContactPhase-32k（新增）

**动机**：32k 演示无接触相标签，但 ρ̃ 的时序天然编码接触相；自动标注是几乎零成本的监督信号与恢复触发器。

**可行性**：中高（无监督分段成熟）；**资源**：单卡数天。

**步骤**：①ρ̃ 特征化（幅值/方差/微分/末端速度）②变点检测+平滑 ③与动作段对齐 ④人工抽检 20 条算边界 F1 ⑤全量生成。

**风险**：多解使相位边界模糊（如慢速接近 vs 轻接触）。

## 4. IP-C12 IterVal：验证阶梯 + 主动重放 + 真机槽分配（新增）

**动机**：把「提交即评测」变成「提交前已知能学到什么」，并给迭代一个停止/分配原则。

**差异**：定义 L0–L3 阶梯与晋级门；用 D-最优主动重放省预算；用「信息增益/边际 trust 提升」决定真机槽分配，而不是均匀撒。

**阶梯与门**：

| 层 | 内容 | 通过条件（初值） | 失败动作 |
|---|---|---|---|
| L0 | 运动学重放（q） | 关节 RMS ≤ 2°，末端 ≤ 2cm | 修几何/零位/外参 |
| L1 | 接触残差匹配（ρ 剖面） | 接触段残差 ≤ 噪声底×k，且过可辨识性门 | 回 S3 重辨识或判「不可辨识」 |
| L2 | 仿真 DryRun 成功率 | 每任务 ≥ 目标成功率区间 | 回 C03 课程/数据配比 |
| L3 | 真机槽 | 记录 success/steps | 回写 trust，更新预算 |

**主动重放**：候选段按相位分层，贪心选 D-最优段（定义 7）；预算 B=20/50 两档。

**真机槽分配**：优先给「L2 预测分数方差大 + 边际信息增益高」的任务（既是验证也是学习）。

**可行性**：高；**资源**：复用现有管线 + 评测槽。

```python
# ===== C02' TwinCal-Proprio：三段式 + 迭代 BO + 可辨识性门 =====
def rho(cmd, obs_next, mode):                 # 命令-达成残差（接口可得，无 torque）
    if mode == "joint":
        return (cmd["arm"] - obs_next["arm"]) / SIGMA_J
    return concat(cmd["ee"][:3] - obs_next["ee"][:3],
                  log_rot(rot(obs_next["ee"][3:]).T @ rot(cmd["ee"][3:])))

def replay_residual(twin, ep, theta, mode):
    obs_hat = twin.rollout(ep.actions, theta)     # 同控制空间重放
    rho_hat = [rho(a, o, mode) for a, o in zip(ep.actions, obs_hat[1:])]
    rho_real = [rho(a, o, mode) for a, o in zip(ep.actions, ep.obs[1:])]
    w = contact_weights(ep.phase)                # 接触相放大
    return sqrt(sum(w * ||r - rh||**2)) + LAM * kin_error(ep, obs_hat)

def twincal_proprio(task, demos, budget=50):
    twin = align_kinematics(demos)                # S1: 零位/外参/连杆
    twin = fit_free_space(twin, phase="approach") # S2: 增益/延迟/阻尼
    demo_phase = contact_phase(demos)             # C11
    theta, history = DEFAULT_PHYS, []
    for seg in active_replay_select(demos, demo_phase, budget):   # D-optimal
        theta = bo_step(theta, replay_residual(twin, seg, theta, MODE))
        history.append(current_loss)
    D_star = plateau(history)                      # 收敛残差（非初始！）
    identifiable = fisher_info(twin, theta) > EPS_I # 可辨识性门
    if not identifiable:
        return twin, Trust.UNIDENTIFIABLE
    trust = sigmoid((NOISE_FLOOR + M - D_star) / SCALE)
    return twin, (Trust.TRUSTED if trust > 0.5 else Trust.DISABLED)
```

```python
# ===== C08'：本体残差门 + 接触相状态机（块内不可中断，只能在调用时刻决策）=====
class ProprioGate:
    K_LONG, K_SHORT, HYST = 24, 6, 8
    def __init__(self, twin, phase_machine):
        self.q_hi = twin.free_space_residual_quantile(0.99)
        self.phase = phase_machine; self.mode_steps = 0
    def get_action(self, obs):
        ph = self.phase.update(obs)                       # C11 在线/离线状态机
        r = norm(rho(self.last_cmd, obs, MODE))
        perturbed = (r > self.q_hi) or (ph == "slip") or phase_jump(ph)
        if perturbed:
            k, A = self.K_SHORT, self.recovery.match(ph)
        else:
            k, A = self.K_LONG, self.policy.propose(obs, self.K_LONG)
        self.mode_steps = self.mode_steps + 1 if perturbed else 0
        if 0 < self.mode_steps < self.HYST: k = min(k, self.last_k)  # 迟滞
        self.last_k, self.last_cmd = k, A[0]
        return format_actions(A[:k])
```

## 7. 小命题（推导要点）

**命题 3（残差分解与接触主导）**：设跟踪误差 ρ_t = ρ_t^ctrl + ρ_t^contact。S2 在自由空间标定后 ρ_t^ctrl 可由控制模型预测，故接触相中可观测的是 ρ_t^contact。若把末端看作线性柔顺 e ≈ K^{-1}J^T w（w 为外部旋量），则匹配 ρ^contact 剖面等价于在 J 的行空间上匹配接触旋量 w。由于成功与否由 w 的**时序剖面**驱动（而非物体的完整视觉状态），在接触任务上以 ρ 为标定信号比以物体位姿为信号更贴近可迁移量；但 J 非满秩 + 柔顺模型线性化 ⇒ 映射低维、多解（呼应最大风险）。

**命题 4（信任度必须取收敛残差）**：设 D(θ) 连续、L-Lipschitz，θ∈紧集，BO 取 best-so-far D_k。则 D_k 单调不增并收敛到局部最优 D_∞。若用 D_0 定义 trust，则存在两类误判：(i) 初值差但可拟合好 → 假阴性（错误禁用仿真）；(ii) 初值巧合小但对 θ 不敏感 → 假阳性。故 trust 应取 D_∞，并叠加可辨识性门 I_τ≻εI。停止准则：连续 m 轮 |D_k−D_{k−1}|<ε，或预算耗尽。

**命题 5（主动重放的 D-最优性）**：在局部二次近似下，重放段 S 的 Fisher 信息 J_S=Σ_{t∈S}g_tg_tᵀ/σ²，后验协方差 Σ_S=(J_0+J_S)^{-1}。D-最优 max logdet(J_0+J_S) 最小化置信椭球体积；logdet 作为集合函数单调且子模，贪心选段具 (1−1/e) 近似保证。约束：S 必须覆盖各接触相，否则 J_S 秩亏、可辨识性门误杀。
