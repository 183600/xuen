# 第 56 轮（承接第 55 轮 v31 GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「双臂协调」×「痛点分析」）

> 第 55 轮把单肢接触语义升级为全身语义-接触生存核。本轮把场景从“一条动作链 + 一张语义图”推进到 **“两条动作链 + 一个闭链约束”**：双臂抓持同一物体时构成闭环运动学链，单臂各自的可行集不再可组合；同时把 **痛点分析** 从工程习惯提升为研究方法——不从“算子能做什么”出发，而从“真实双臂任务在哪里坏”出发，用痛点台账反向挑选、约束与验收算子。核心矛盾：**H24**：闭链把两臂的位姿误差与内力耦合，单臂证书的笛卡尔积在闭链上系统性乐观；**H25**：痛点分析若不建立可测残差，就会退化为事后解释，无法在部署前否决任务。

## 0. 直觉与动机

**灵感 1（痛点分析 → 先建失败台账，再谈算子）**
直觉：做双臂最容易犯的错是“把单臂的东西乘以二”。痛点分析要求先收集失败：相对位姿漂移、两臂力对抗、角色摇摆、时序错配、闭链组合失效、自碰撞。把它们写成 **痛点台账** `π=(症状, 机理, 可测残差, 对应算子, 残余风险)`。台账不是日志分类，而是 **验收清单**：每个高严重度痛点必须有算子且残差可测、可设阈值，否则该任务直接判“尚不可部署”。

**灵感 2（双臂协调 → 闭链约束流形，而非两臂笛卡尔积）**
直觉：抓同一物体时两臂不独立，`Φ(q_L,q_R)=0` 把两臂自由度压到一个约束流形上。因此可行集是 `K₂` 而不是 `K_L×K_R`；单臂各自 90% 可行，闭链上可能只有 60%。这把“协调”从调度问题变成 **约束流形上的可行性问题**，并给出可量化的 **耦合损失** `g_comp`。

**灵感 3（双臂协调 → 内力是一等公民）**
直觉：两臂夹住物体的力可分解为“抵抗外载”与“内部对抗”两部分。内力太小会滑，太大则力对抗、电机饱和、物体损伤。因此必须显式给内力一个 **安全带** `𝒲_int^safe`，而不是让两个独立控制器在零空间里互相较劲。

**灵感 4（双臂协调 → 角色是任务级自由度）**
直觉：多数双臂任务其实是“一手固定/托举、一手操作”。角色分错，负载与精度会同时恶化。角色应有 **稳定裕度** 与迟滞，避免中途反复切换——角色摇摆本身就是一个高发痛点。

**灵感 5（痛点分析 → 可证伪的研究闭环）**
直觉：把每个痛点映射到一个可直接测的残差，就得到“提出算子 → 预测残差下降 → 实验证伪”的闭环。若某算子在台账上没有降低对应残差，就应删除该算子，而不是继续叠加模块。这把研究从“堆能力”改成“消痛点”。

## 1. 形式化定义（增量：定义 127–132）

**定义 127（双臂状态与闭链约束流形）**
双臂状态 `x=(x_L,x_R)`、关节 `q=(q_L,q_R)`。两臂各持同一刚体时，末端相对位姿 `T_L(q_L)`、`T_R(q_R)` 与期望相对位姿 `T_{LR}^{des}` 的闭链残差
`Φ(q)=log(T_L^{-1} T_R · (T_{LR}^{des})^{-1}) ∈ ℝ^6`，
约束流形 `𝒞_cl = {q | ||Φ(q)||_W ≤ ε_cl}`。抓持映射 `G(q)` 把接触力映到物体合力旋量，外部旋量需满足 `w_ext ∈ WC(G)`（抓持闭合）。

**定义 128（双臂协调生存核）**
`K₂(Σ) = {(x_L,x_R) | ∃u,λ : ẋ=f(x,u,λ) ∧ q∈𝒞_cl ∧ w_int∈𝒲_int^safe ∧ supp(λ)⊆C⁺(Σ) ∧ τ∈𝒯 ∧ 无自碰撞}`。
一般 `K₂ ⊆ K_L×K_R` 且常为真子集。定义 **闭链耦合损失**
`g_comp = 1 - P(viable₂(x_L,x_R) | viable_L(x_L) ∧ viable_R(x_R))`，
即“两臂各自可行却合起来不可行”的比例，作为“乘以二”式乐观的直接度量。

**定义 129（痛点台账）**
台账 `Π={π_1,…,π_K}`，每条 `π_k=(s_k, μ_k, r_k, o_k, θ_k, σ_k)`：症状 `s`、机理 `μ`（可追溯到闭链/内力/时序/角色/自碰撞）、可测残差 `r_k(x)`、对应算子 `o_k`、阈值 `θ_k`、严重度 `σ_k`。
**台账覆盖** `cov(Π)=1 ⇔ ∀k, σ_k≥σ_min ⟹ (o_k≠⊥ ∧ r_k 可测)`。
**部署前置条件**：`cov(Π)=1 ∧ ∀k, r_k ≤ θ_k`；覆盖不全的任务不得用“已有算子很强”来豁免。

**定义 130（角色分配与稳定裕度）**
角色 `ρ∈{F(固定/托举), M(操作)}²`。角色成本
`cost(ρ)=w_l·L(ρ)+w_p·P(ρ)+w_e·E(ρ)`（负载/精度/能耗）。稳定裕度
`stab(ρ)=min_{ρ'≠ρ} cost(ρ') - cost(ρ)`。
仅当 `stab(ρ) ≤ -θ_stab` 且持续 `T_dwell` 时才允许切换（迟滞），使“角色摇摆”成为可测残差 `r_role`。

**定义 131（内力安全带）**
物体旋量分解 `w = w_ext + w_int`，`w_int ∈ ker(G)`（内力子空间）。安全带
`𝒲_int^safe = {w_int | ||w_int|| ∈ [f_min, f_max], dir(w_int) ∈ 𝒩}`，
`f_min` 由滑移裕度给定、`f_max` 由力矩/接触应力上限给定。内力残差 `r_force = dist(w_int, 𝒲_int^safe)`。

**定义 132（双臂协调证书）**
`J₂ = (Π, K₂^{in}, K₂^{out}, C_core, ρ, stab, δ_drift, w_int_band, sync_window, evidence)`：
- `K₂^{in} ⊆ K₂ ⊆ K₂^{out}` 生存核内/外近似；`C_core` 核心接触集（承接第 55 轮）；
- `δ_drift = max_t ||Φ(q(t))||_W` 闭链漂移实测；
- `w_int_band = min_t dist(w_int(t), ∂𝒲_int^safe)` 内力带裕度；
- `sync_window = max_t |t_L - t_R|` 双臂事件时差；
- `evidence` 含痛点反例、力反馈与角色切换日志。
若 `cov(Π)=1`、`K₂^{in}` 非空且核裕度达标、`δ_drift < Θ_d`、`w_int_band > 0`、`stab>θ_stab`、`sync_window<Θ_t`，则双臂协调可部署。

## 2. 关键算法 伪代码

### IP-127 PPL（Pain-Point Ledger，痛点台账）

```python
PAIN_OPERATORS = {'drift': 'CCK', 'force': 'IFR', 'role': 'BRA',
                  'timing': 'STS', 'coupling': 'CCK', 'collision': 'CCK'}

def build_pain_ledger(failures, sigma_min):
    ledger = []
    for cluster in cluster_failures(failures):       # 按症状聚类
        symptom   = observable(cluster)              # 可观测失败签名
        mechanism = trace_cause(cluster)             # 追溯到闭链/内力/时序/角色
        metric    = measurable_residual(mechanism)   # 必须可在线测
        operator  = PAIN_OPERATORS.get(mechanism, None)
        severity  = freq(cluster) * cost(cluster)
        ledger.append(PainPoint(symptom, mechanism, metric,
                                operator, severity))
    return sorted(ledger, key=lambda p: p.severity, reverse=True)

def ledger_gate(ledger, sigma_min):
    uncovered = [p for p in ledger
                 if p.severity >= sigma_min and p.operator is None]
    if uncovered:                                    # 台账不全 → 直接否决
        return ('not_deployable', uncovered)
    return ('ok', [p.residual_budget for p in ledger])

def operator_ablation(ledger, results):
    # 若某算子未降低其对应痛点残差，则删除它，而非叠加新模块
    return [op for op in set(p.operator for p in ledger if p.operator)
            if mean_residual_drop(op, results) < delta_min]
```

### IP-128 CCK（Closed-Chain Kernel，闭链协调核）

```python
def bimanual_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for (xL, xR) in sample_joint_state_space(x0, horizon):
        if self_collision(xL, xR): continue
        feas, u, lam, w_int = solve_bimanual_dynamics(
            xL, xR, C_plus, friction_cone=mu,
            closed_chain=(T_L, T_R, T_LR_des))
        if not feas: continue
        if not in_safe_band(w_int): continue        # 内力先验硬约束
        K.add((xL, xR))
        margins.append(min(dist_to_boundary(xL, xR), closure_margin(T_L, T_R)))
    return KernelApprox(K_in=inner_hull(K), K_out=outer_hull(K, eps),
                        margin=min(margins) if margins else 0.0)

def coupling_loss(K_L, K_R, K2, sampler):
    prod = {x for x in sampler if x in K_L and x in K_R}
    joint = {x for x in prod if x in K2}
    return 1.0 - len(joint) / max(len(prod), 1)      # g_comp
```

### IP-129 BRA（Bimanual Role Assignment，角色分配）

```python
def assign_roles(task, arms, W):
    best, best_cost = None, float('inf')
    for rho in product(['F','M'], repeat=2):
        if not role_feasible(task, rho, arms): continue
        c = W.l*load(rho) + W.p*precision(rho) + W.e*energy(rho)
        if c < best_cost: best, best_cost = rho, c
    alt = min(cost(rho) for rho in product(['F','M'], 2)
              if rho != best)
    return best, alt - best_cost                      # 返回 stab 裕度

def role_update(current, new, stab, dwell, theta_stab):
    if stab <= -theta_stab and dwell >= T_dwell:      # 迟滞切换
        return new
    return current                                     # 否则保持，防角色摇摆
```

### IP-130 IFR（Internal Force Regulation，内力调节）

```python
def regulate_internal_force(w_ext, G, band, limits):
    # 分解：外载分量固定，内力在零空间内投影到安全带
    w_int_des = project_to_band(project_ker(G, w_ext), band)  # [f_min,f_max]
    tau = G.T @ (w_ext + w_int_des)
    if not within_limits(tau, limits):
        w_int_des = clutch_safe(w_ext, G, band, limits)       # 降内力不超限
    return tau, w_int_des, dist(w_int_des, band)
```

### IP-131 STS（Spatio-Temporal Synchronization，时空同步）

```python
def sync_schedule(P_L, P_R, window):
    tL, tR = time_param(P_L), time_param(P_R)
    skew = max(abs(tL(t) - tR(t)) for t in key_events(P_L, P_R))
    if skew > window:                                 # 时序错配 → 重参数化
        tL, tR = retime(tL, tR, window)
        skew = max(abs(tL(t) - tR(t)) for t in key_events(P_L, P_R))
    return tL, tR, skew

def drift_budget_check(Phi_traj, Theta_d):
    delta = max(norm_W(Phi(q)) for q in Phi_traj)
    return ('ok' if delta < Theta_d else 'retime_or_regrasp', delta)
```

### IP-132 BCC（Bimanual Coordination Certificate，双臂协调证书）

```python
def bimanual_certificate(traj, Sigma, ledger, budgets):
    status, uncovered = ledger_gate(ledger, budgets.sigma_min)
    if status != 'ok':
        return ('reject', 'ledger_incomplete', uncovered)
    K2 = bimanual_kernel(Sigma, conservative_contacts(Sigma), traj.x0,
                         budgets.horizon, budgets.eps)
    if not K2.K_in:
        return ('reject', 'empty_kernel')
    K_margin = min(K2.distance(x) for x in traj)
    delta_d = max(norm_W(Phi(q)) for q in traj.q)
    r = {p.mechanism: p.residual(traj) for p in ledger}
    if K_margin < budgets.theta_K or delta_d > budgets.Theta_d:
        return ('reject', 'kernel_or_drift', K_margin, delta_d)
    if any(r[k] > budgets.theta[k] for k in r):
        return ('reject', 'pain_residual', r)
    if r['force'] > 0 or r['role'] > budgets.theta_role or r['timing'] > budgets.Theta_t:
        return ('reject', 'coordination_residual', r)
    return ('ok', BimanualCert(ledger, K2, K_margin, delta_d, r))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| PPL | O(N_fail·log N_fail) | O(N_fail) | 痛点残差可在线测、覆盖门控不豁免 |
| CCK | O(|X₂|·T·QP) | O(|X₂|) | 闭链约束 sound、内力安全带先验、核外近似 |
| BRA | O(2²·|task|) | O(1) | 成本函数标定、迟滞防摇摆 |
| IFR | O(QP_ker) 每次 | O(6) | 内力子空间投影、带内不饱和 |
| STS | O(|P|·|events|) | O(|P|) | 时间重参数化、漂移预算闭合 |
| BCC | O(|traj|·(|X₂|+|Π|)) | O(|X₂|) | 六类残差同时闭合、台账覆盖=1 |

**正确性定理（Bimanual Pain-Point-Aware Coordination Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 真实闭链残差 `||Φ||_W ≤ ε_cl`；**(A34)** 内力 `w_int` 全程位于 `𝒲_int^safe` 内且带裕度；**(A35)** 角色在 `T_dwell` 内不发生非计划切换，事件时差 ≤ `Θ_t`；**(A36)** 痛点台账 `cov(Π)=1` 且不存在未登记的严重痛点。则双臂部署后单步安全概率：
```
P_safe ≥ 1 - P(||Φ||_W > ε_cl) - P(w_int ∉ 𝒲_int^safe)
            - P(role switch unstable) - P(sync miss)
            - P(K₂^{out} \ K₂^{in} ≠ ∅) - P(shield fallback fails)
```
关键：**痛点台账先否决任务**、**闭链核保守包含**、**内力安全带兜底**、**角色/时序有迟滞与窗口**；任一失守都不允许把“单臂都能做”当作“双臂合起来能做”。

## 6. 本轮最大风险

**一句话**：把双臂从“两条单臂链”推进到“闭链生存核 + 痛点台账”是一次必要的收紧，但其 soundness **四重依赖痛点台账的完备性、闭链核外近似的紧致性、内力安全带的可辨识性、以及角色/时序迟滞的正确标定**；一旦有严重痛点未被登记，部署门控就会放行一个“自认为已验证”的任务，而闭链会把这个盲区放大成两臂互顶、物体滑落或自碰撞——因此必须以 **红队式痛点注入 + 保守闭链核 + 在线内力辨识 + 角色/时序硬窗口** 四重护栏，宁可判“尚不可部署”，绝不把台账的“没写”当作“没问题”。

## 2. 痛点台账模板（本轮核心交付物）

| ID | 症状（可观测） | 机理 | 可测残差 | 对应算子 | 默认阈值 |
|---|---|---|---|---|---|
| P1 | 物体被拧歪/滑脱 | 两臂独立估计误差经闭链累加 | `r_drift = max_t \|\|Φ\|\|_W` | CCK / STS | ≤ 2 mm / 1° |
| P2 | 电机发热、力矩饱和、物体被夹坏 | 两臂零空间力互相对抗 | `r_force = dist(w_int, 𝒲_int^safe)` | IFR | = 0（带内） |
| P3 | 中途反复换手、动作迟滞 | 角色成本噪声、无迟滞 | `r_role = 非计划切换数` | BRA | ≤ 1 次/任务 |
| P4 | 抓空、提前闭合、松手不同步 | 双臂事件时差 | `r_time = max_t \|t_L - t_R\|` | STS | ≤ 50 ms |
| P5 | 单臂都能做、合起来失败 | 笛卡尔积乐观、闭链耦合 | `g_comp` | CCK | ≤ 10% |
| P6 | 臂-臂 / 臂-躯干碰撞 | 共享工作空间、包络遗漏 | `r_self = min_t d_self` | CCK | ≥ 5 cm |

**使用规则**：严重度 `σ ≥ σ_min` 的痛点若 `o=⊥` 或 `r` 不可在线测，则 `cov(Π)<1`，任务直接判 `not_deployable`——不允许用“已有算子性能好”豁免。

PAIN_OPERATORS = {'drift':'CCK','force':'IFR','role':'BRA',
                  'timing':'STS','coupling':'CCK','collision':'CCK'}

def build_pain_ledger(failures, sigma_min):
    ledger = []
    for cluster in cluster_failures(failures):
        symptom   = observable(cluster)
        mechanism = trace_cause(cluster)          # 闭链/内力/时序/角色/碰撞
        metric    = measurable_residual(mechanism)
        operator  = PAIN_OPERATORS.get(mechanism)
        severity  = freq(cluster) * cost(cluster)
        ledger.append(PainPoint(symptom, mechanism, metric, operator, severity))
    return sorted(ledger, key=lambda p: p.severity, reverse=True)

def ledger_gate(ledger, sigma_min):
    uncovered = [p for p in ledger if p.severity >= sigma_min and p.operator is None]
    return ('ok', [p.budget for p in ledger]) if not uncovered \
           else ('not_deployable', uncovered)

def prune_useless_operators(ledger, results, delta_min):
    # 痛点分析的可证伪性：不降残差的算子应删除，而不是继续叠加
    return [op for op in {p.operator for p in ledger if p.operator}
            if mean_residual_drop(op, results) < delta_min]

### IP-128 CCK

```python
def bimanual_kernel(Sigma, C_plus, x0, horizon, eps):
    K, margins = set(), []
    for (xL, xR) in sample_joint_state_space(x0, horizon):
        if self_collision(xL, xR):
            continue
        feas, u, lam, w_int = solve_bimanual_dynamics(
            xL, xR, C_plus, friction_cone=mu,
            closed_chain=(T_L, T_R, T_LR_des))
        if not feas or not in_safe_band(w_int):
            continue
        K.add((xL, xR))
        margins.append(min(dist_to_boundary(xL, xR), closure_margin(T_L, T_R)))
    return KernelApprox(K_in=inner_hull(K), K_out=outer_hull(K, eps),
                        margin=min(margins) if margins else 0.0)

def coupling_loss(K_L, K_R, K2, sampler):
    prod  = {x for x in sampler if x in K_L and x in K_R}
    joint = {x for x in prod if x in K2}
    return 1.0 - len(joint) / max(len(prod), 1)   # g_comp
```

### IP-129 BRA

```python
def assign_roles(task, arms, W):
    costs = {}
    for rho in product(['F','M'], repeat=2):
        if role_feasible(task, rho, arms):
            costs[rho] = W.l*load(rho)+W.p*precision(rho)+W.e*energy(rho)
    best = min(costs, key=costs.get)
    alt  = min(c for r, c in costs.items() if r != best)
    return best, alt - costs[best]                # (role, stab)

def role_update(current, new, stab, dwell, theta_stab):
    if stab <= -theta_stab and dwell >= T_dwell:
        return new                                # 迟滞切换，防角色摇摆
    return current
```

### IP-132 BCC

```python
def bimanual_certificate(traj, Sigma, ledger, budgets):
    status, uncovered = ledger_gate(ledger, budgets.sigma_min)
    if status != 'ok':
        return ('reject', 'ledger_incomplete', uncovered)
    K2 = bimanual_kernel(Sigma, conservative_contacts(Sigma), traj.x0,
                         budgets.horizon, budgets.eps)
    if not K2.K_in:
        return ('reject', 'empty_kernel')
    K_margin = min(K2.distance(x) for x in traj)
    delta_d  = max(norm_W(Phi(q)) for q in traj.q)
    r = {p.mechanism: p.residual(traj) for p in ledger}
    if K_margin < budgets.theta_K or delta_d > budgets.Theta_d:
        return ('reject', 'kernel_or_drift', K_margin, delta_d)
    if any(r[k] > budgets.theta[k] for k in r):
        return ('reject', 'pain_residual', r)
    return ('ok', BimanualCert(ledger, K2, K_margin, delta_d, r))
```

## 4. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| PPL | O(N_fail·log N_fail) | O(N_fail) | 残差可在线测、覆盖门控不豁免 |
| CCK | O(|X₂|·T·QP) | O(|X₂|) | 闭链约束 sound、内力先验硬约束、核外近似 |
| BRA | O(4·|task|) | O(1) | 成本标定、迟滞防摇摆 |
| IFR | O(QP_ker) 每次 | O(6) | 内力子空间投影、带内不饱和 |
| STS | O(|P|·|events|) | O(|P|) | 时间重参数化、漂移预算闭合 |
| BCC | O(|traj|·(|X₂|+|Π|)) | O(|X₂|) | 六类残差同时闭合、`cov(Π)=1` |

**正确性定理（Bimanual Pain-Point-Aware Coordination Soundness）**
假设第 55 轮 (A29)–(A32) 成立；**(A33)** 真实闭链残差 `||Φ||_W ≤ ε_cl`；**(A34)** `w_int` 全程在 `𝒲_int^safe` 内且带裕度；**(A35)** 角色在 `T_dwell` 内无非计划切换、事件时差 ≤ `Θ_t`；**(A36)** `cov(Π)=1` 且无未登记严重痛点。则：
```
P_safe ≥ 1 - P(||Φ||_W > ε_cl) - P(w_int ∉ 𝒲_int^safe)
            - P(role switch unstable) - P(sync miss)
            - P(K₂^{out} \ K₂^{in} ≠ ∅) - P(shield fallback fails)
```
关键：**台账先否决、闭链核保守、内力兜底、角色/时序有迟滞与窗口**，四者缺一不可。

## 6. 本轮最大风险

**一句话**：双臂闭链生存核与痛点台账把“单臂可行”收紧为“合起来可部署”，但其 soundness **四重依赖痛点台账的完备性、闭链核外近似的紧致性、内力安全带的可辨识性、以及角色/时序迟滞的正确标定**；一旦有严重痛点未被登记，门控就会放行一个“自认为已验证”的任务，闭链随即把盲区放大成两臂互顶、物体滑落或自碰撞——故必须以 **红队式痛点注入 + 保守闭链核 + 在线内力辨识 + 角色/时序硬窗口** 四重护栏，宁可判“尚不可部署”，绝不把台账的“没写”当作“没问题”。
