### 第 4 轮灵感驱动研究记录

**灵感词**：对比实验、因果推理

**直觉与动机**：

前三轮把 KEMPC 堆叠为九证一体的 KTCG，每增加一证都在收缩可行执行集 Exec。但这里存在一个根本的认识论缺口：我们只能观测到「某规则激活时事故更少」，却无法由此断言「是这条规则**导致**了事故更少」。地形难度、任务模式、操作员干预会同时影响规则的激活与事故率，构成典型的混杂（confounding）。例如「支撑面积 > 200cm²」在平地频繁激活且事故率低，但真正降低事故的可能只是「平地」这个共同原因；规则本身也许毫无贡献。若把相关性误当因果，就会保留无用甚至有害的规则——这正是 R22 负迁移的统计根源。

因果推理带来的关键转变：把每条常识规则/每个证书视为一个**可干预的处理**（treatment），用 `do(A_i=1)` 与 `do(A_i=0)` 下潜在结果之差来定义其真实贡献，而不是用「激活状态」与「事故率」的相关系数。

对比实验提供识别手段：机器人在线运行无法在同一初始状态同时观测「开规则」与「关规则」两个世界，因此需要**配对比较**（同一初始状态、同一扰动序列，common random numbers）和**消融实验**来构造反事实。又因为规则由前置条件确定性触发，直接观测的数据没有重叠（positivity 失败），必须引入**证书随机丢弃**（certificate dropout）作为干预，才满足 do-calculus 的可识别条件。

关键洞见：因果推断不是给 KEMPC 再加一个并列模块，而是把「九证」从**相关性堆叠**升级为**因果归因**——每个证书必须携带「移除它会使期望违规上升多少」的因果效应及其置信区间；负迁移检测从「相似度阈值」升级为「目标域因果效应为负则禁用」。R22 由此从启发式缓解变为可检验的统计判决。

**形式化目标（增量）**：
1. 定义因果知识证书 CKC = (KC, τ_i, CI_i, id_status, intervention_log)，其中 τ_i 为平均处理效应 ATE。
2. 定义配对比较协议 CAP：对每个规则 i，在匹配初始状态与共同随机数下执行 `do(A_i=1)`/`do(A_i=0)` 配对试验，输出比较证据证书 CEC。
3. 定义因果迁移因子 μ_i^c = clip(Φ(τ_i^{s→t}/SE_i), 0, 1)，替代 `sim·ρ·κ` 的相关性乘积；当 τ_i^{s→t} 的置信上界 < 0 时令 μ_i^c = 0。
4. 定义因果门 CCG：仅准入 LCB_α(τ_i) ≥ -ε 的规则，并将 τ_i < 0 的规则隔离（quarantine）。
5. 证明在无未测混杂、SUTVA、正性成立时配对估计量无偏；设计「伪规则」负对照实验，验证因果门拒绝相关性虚假规则而保留真实有益规则。

**本轮最大风险**：因果识别假设（无未测混杂、SUTVA、正性）在真实闭环机器人数据中很可能被违反——证书随机丢弃会改变控制分布、规则间交互会破坏 SUTVA——此时 ATE 估计有偏，因果门可能误杀有益规则或放行有害规则，且比相关性门更危险，因为它披着「已被因果验证」的外衣。

### IP-467 Causal Knowledge Certificate (CKC)

```python
@dataclass
class CausalKnowledgeCertificate:
    """CKC：为每条 IEKC 规则附加因果效应与可识别性元数据"""
    kc: 'InterpretabilityEnhancedKnowledgeCertificate'
    tau: float = 0.0                 # ATE 点估计 E[Y(1)-Y(0)]
    se: float = float('inf')         # 标准误
    ci_low: float = -float('inf')    # 置信下界 L_i
    ci_high: float = float('inf')    # 置信上界 U_i
    n_pairs: int = 0                 # 配对样本量
    id_status: str = "unidentified"  # identified / confounded / positivity_fail
    intervention_log: list = field(default_factory=list)  # 每次干预记录
    interactions: dict = field(default_factory=dict)      # {other_name: I_ij}

    def lcb(self) -> float:
        return self.ci_low

    def ucb(self) -> float:
        return self.ci_high

    def is_harmful(self) -> bool:
        """因果显著有害：置信上界仍小于 0"""
        return self.id_status == "identified" and self.ci_high < 0.0

    def is_causally_admissible(self, eps: float = 0.0) -> bool:
        """仅当因果效应下界不低于 -eps 时准入；不可识别一律不准入"""
        return (self.id_status == "identified"
                and self.ci_low >= -eps
                and not self.is_harmful())

    def record_pair(self, pair_id: int, z: dict, y1: float, y0: float,
                    seed: int) -> None:
        self.intervention_log.append({
            "pair_id": pair_id, "z": z, "y1": y1, "y0": y0,
            "ite": y1 - y0, "seed": seed,
        })
```

### IP-468 Comparative Ablation Protocol (CAP)

```python
class ComparativeAblationProtocol:
    """CAP：配对消融 + 因子设计 + 随时有效检验"""

    def __init__(self, dynamics: Callable, horizon: int = 20,
                 n_pairs: int = 200, alpha: float = 0.05,
                 p_drop: float = 0.2, seed: int = 0):
        self.dyn = dynamics
        self.H = horizon
        self.n_pairs = n_pairs
        self.alpha = alpha
        self.p_drop = p_drop            # 证书丢弃率，保证 0 < P(A=1|Z) < 1
        self.rng = np.random.default_rng(seed)

    # ---------- 配对主实验 ----------
    def paired_ate(self, kc: 'InterpretabilityEnhancedKnowledgeCertificate',
                   z_sampler: Callable,
                   outcome_fn: Callable) -> CausalKnowledgeCertificate:
        """对单条规则做 do(A=1)/do(A=0) 配对比较。
        z_sampler: 分层采样 (terrain, mode, x0)
        outcome_fn: (x0, disturbance, enable) -> y ∈ [0,1]
        """
        diffs, zs, seeds = [], [], []
        for j in range(self.n_pairs):
            z = z_sampler()                       # 同一 Z 用于两个世界
            x0 = z["x0"]
            seed_j = int(self.rng.integers(0, 2**31 - 1))
            # 共同随机数：两次回放使用完全相同的扰动序列
            dist = self._common_random_numbers(seed_j)
            y1 = outcome_fn(x0, dist, True)       # do(A=1)
            y0 = outcome_fn(x0, dist, False)      # do(A=0)
            diffs.append(y1 - y0)
            zs.append(z)
            seeds.append(seed_j)

        diffs = np.asarray(diffs, dtype=float)
        n = len(diffs)
        tau = float(diffs.mean())
        se = float(diffs.std(ddof=1) / math.sqrt(n)) if n > 1 else float('inf')
        # 配对 t 区间（n 大时与 bootstrap 一致）
        tcrit = float(stats.t.ppf(1 - self.alpha / 2, df=max(n - 1, 1)))
        lo, hi = tau - tcrit * se, tau + tcrit * se

        ckc = CausalKnowledgeCertificate(
            kc=kc, tau=tau, se=se, ci_low=lo, ci_high=hi,
            n_pairs=n, id_status="identified",
        )
        for j, (d, z, s) in enumerate(zip(diffs, zs, seeds)):
            ckc.record_pair(j, z, y1=float(d), y0=0.0, seed=s)
        return ckc

    def _common_random_numbers(self, seed: int) -> np.ndarray:
        """固定种子生成与策略无关的扰动序列（CRN 的核心）"""
        rng = np.random.default_rng(seed)
        return rng.normal(size=(self.H, self.dyn.n_disturbance))

    # ---------- 因子设计：估计交互 ----------
    def factorial_interaction(self, rules: list, z_sampler: Callable,
                              outcome_fn: Callable, q: int = 0) -> dict:
        """2^k 全因子或 2^(k-q) 部分因子，估计主效应与二阶交互 I_ij。
        规则间若交互显著，边际 ATE 会误导，必须用联合准入。"""
        k = len(rules)
        levels = self._fractional_factorial(k, q)
        effects = {}
        for combo in levels:
            # combo: {rule_name: 0/1}
            ys = []
            for j in range(self.n_pairs):
                z = z_sampler()
                dist = self._common_random_numbers(int(self.rng.integers(0, 2**31 - 1)))
                ys.append(outcome_fn(z["x0"], dist, combo))
            effects[tuple(sorted(combo.items()))] = float(np.mean(ys))

        main, inter = {}, {}
        for r in rules:
            y1 = np.mean([v for c, v in effects.items() if dict(c)[r] == 1])
            y0 = np.mean([v for c, v in effects.items() if dict(c)[r] == 0])
            main[r] = float(y1 - y0)
        for a in range(k):
            for b in range(a + 1, k):
                ra, rb = rules[a], rules[b]
                inter[(ra, rb)] = float(
                    effects[(tuple(sorted({ra: 1, rb: 1}.items())))]
                    - effects[(tuple(sorted({ra: 1, rb: 0}.items())))]
                    - effects[(tuple(sorted({ra: 0, rb: 1}.items())))]
                    + effects[(tuple(sorted({ra: 0, rb: 0}.items())))]
                )
        return {"main": main, "interaction": inter}

    def _fractional_factorial(self, k: int, q: int) -> list:
        """返回 2^(k-q) 个 {rule_name: 0/1} 组合（简化：全因子 q=0）"""
        from itertools import product
        names = [f"r{i}" for i in range(k)]
        return [dict(zip(names, bits)) for bits in product([0, 1], repeat=k)]

    # ---------- 随时有效检验 ----------
    def e_value(self, diffs: list, mu0: float = 0.0) -> float:
        """H0: τ ≤ mu0 的任意时间有效 e-value（简化： betting 形式）"""
        e = 1.0
        for d in diffs:
            # 以 mu0 为原假设的似然比下界（有界随机变量）
            e *= (1.0 + max(0.0, d - mu0) / max(1e-9, abs(mu0) + 1.0))
        return float(e)
```

### IP-469 Causal Transfer Factor (CTF)

```python
class CausalTransferFactor:
    """CTF：用目标域因果效应替代 sim·ρ·κ 的相关性乘积"""

    def __init__(self, target_cap: ComparativeAblationProtocol):
        self.cap = target_cap

    def compute(self, ckc_source: CausalKnowledgeCertificate,
                z_sampler: Callable, outcome_fn: Callable) -> tuple[float, CausalKnowledgeCertificate]:
        """在目标任务上重新做配对消融，得到 τ_i^{s→t}"""
        ckc_t = self.cap.paired_ate(ckc_source.kc, z_sampler, outcome_fn)

        # 1) 目标域因果显著有害 → 禁止迁移
        if ckc_t.ci_high < 0.0:
            return 0.0, ckc_t

        # 2) 因果效应不可识别 → 保守禁用
        if ckc_t.id_status != "identified":
            return 0.0, ckc_t

        # 3) 效应量映射到 [0,1]：τ/SE 越大越可迁移
        z_score = ckc_t.tau / max(ckc_t.se, 1e-9)
        mu = 0.5 * (1.0 + math.erf(z_score / math.sqrt(2.0)))
        mu = max(0.0, min(1.0, mu))
        return float(mu), ckc_t

    def update_registry(self, registry: dict, ckc_source: CausalKnowledgeCertificate,
                        z_sampler: Callable, outcome_fn: Callable) -> dict:
        mu, ckc_t = self.compute(ckc_source, z_sampler, outcome_fn)
        registry[ckc_source.kc.name] = {
            "mu_causal": mu,
            "target_ckc": ckc_t,
            "enabled": mu > 0.0,
        }
        return registry
```

### IP-470 Causal-Transilient MPC / Causal Cert Gate (CCG)

```python
@dataclass
class CausalCertificateGate:
    """CCG：KTCG 九证 + 因果过滤器 Fil_causal"""
    base_gate: 'KnowledgeTransilientCertificationGate'
    ckc_registry: dict                    # {rule_name: CausalKnowledgeCertificate}
    cap: ComparativeAblationProtocol
    eps: float = 0.0                      # 因果容差
    quarantine: set = field(default_factory=set)

    def admits(self, robot_plan: 'RobotPlan', sensor_data: dict) -> bool:
        # 0) 先过原九证门（结构与动力学安全）
        if not self.base_gate.admits(robot_plan, sensor_data):
            return False

        # 1) 因果过滤器：活跃规则必须因果可准入
        active = self.base_gate.wlkb.get_active_rules(
            robot_plan.mode, sensor_data['terrain'])
        for kc_rule in active:
            name = kc_rule.name
            ckc = self.ckc_registry.get(name)

            # 未建立因果证书的规则：默认不准入（保守）
            if ckc is None:
                return False

            # 显著有害：隔离并拒绝
            if ckc.is_harmful():
                self.quarantine.add(name)
                return False

            # 不可识别 / 下界低于容差：拒绝
            if not ckc.is_causally_admissible(self.eps):
                return False

            # 交互显著：必须联合检查配对规则
            for other, I_ij in ckc.interactions.items():
                if abs(I_ij) > self._interaction_threshold():
                    other_ckc = self.ckc_registry.get(other)
                    if other_ckc is None or not other_ckc.is_causally_admissible(self.eps):
                        return False

        return True

    def _interaction_threshold(self) -> float:
        # 交互超过主效应中位数的 20% 视为不可忽略（可配置）
        effects = [abs(c.tau) for c in self.ckc_registry.values()]
        return 0.2 * float(np.median(effects)) if effects else float('inf')

    def causal_mpc_penalty(self, x: Tensor, kc_list: list) -> float:
        """把因果效应折算成惩罚：只有 LCB>0 的规则获得正权重"""
        penalty = 0.0
        for kc in kc_list:
            ckc = self.ckc_registry.get(kc.name)
            if ckc is None or ckc.is_harmful():
                continue
            # 因果效应越大，规则越应被强约束（权重与 LCB 成正比）
            penalty += max(0.0, ckc.lcb()) * (1.0 - float(kc.is_active))
        return penalty
```

### IP-471 Counterfactual Safety Auditor (CSA)

```python
class CounterfactualSafetyAuditor:
    """CSA：影子模式下估计当前计划中每条规则的 ITE，检测虚假包容"""

    def __init__(self, dynamics: Callable, horizon: int = 20, n_shadow: int = 50):
        self.dyn = dynamics
        self.H = horizon
        self.n_shadow = n_shadow

    def audit_plan(self, x0: Tensor, plan_u: Tensor,
                   kc_list: list, z: dict) -> list:
        """对同一计划做反事实回放：启用/禁用单条规则，其余不变"""
        findings = []
        for kc in kc_list:
            ites = []
            for s in range(self.n_shadow):
                dist = np.random.default_rng(s).normal(
                    size=(self.H, self.dyn.n_disturbance))
                y1 = self._shadow_outcome(x0, plan_u, dist, kc, enable=True)
                y0 = self._shadow_outcome(x0, plan_u, dist, kc, enable=False)
                ites.append(y1 - y0)
            ites = np.asarray(ites)
            mean_ite = float(ites.mean())
            se = float(ites.std(ddof=1) / math.sqrt(len(ites))) if len(ites) > 1 else 0.0
            findings.append({
                "rule": kc.name,
                "ite": mean_ite,
                "ci": (mean_ite - 1.96 * se, mean_ite + 1.96 * se),
                # ITE>0 表示启用该规则反而增加风险 → 疑似虚假包容
                "spurious_flag": mean_ite - 1.96 * se > 0.0,
            })
        return findings

    def _shadow_outcome(self, x0, u_seq, dist, kc, enable: bool) -> float:
        x = x0.clone()
        risk = 0.0
        for k in range(self.H):
            x = self.dyn.step(x, u_seq[k], dist[k])
            if enable and not kc.postcond(x):
                risk = max(risk, 1.0)
        return risk
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| CKC 存储与查询 | O(1) per rule | O(N_rule · T_log) | N_rule ≤ 50，T_log 为干预日志长度 |
| CAP 配对实验 | O(n_pairs · H · C_sim) per rule | O(n_pairs) | n_pairs=200, H=20 |
| CAP 因子设计 | O(2^{k-q} · n_pairs · H · C_sim) | O(2^{k-q}) | k≤5 主规则，q 为部分因子阶数 |
| CTF 目标域消融 | O(n_pairs · H · C_sim) per rule | O(N_kc) | 目标域重估，离线/影子执行 |
| CCG 准入 | O(N_active · (1 + N_inter)) | O(N_rule) | 仅查表与阈值比较，微秒级 |
| CSA 影子审计 | O(N_rule · n_shadow · H · C_step) | O(n_shadow) | 异步执行，不占实时控制路径 |

**实时性**：CAP/CTF/CSA 全部在离线仿真或影子模式运行，不进入 50Hz 控制回路；CCG 在线只做 O(N_rule) 的查表与因果区间比较，单步开销 <0.1ms。因果证据按「新规则入库 / 每 N 小时 / 检测到负迁移」三类事件触发重估。

## 4. 正确性论证（增量更新）

### 引理 26（CRN 配对估计量的无偏性与方差缩减）

**陈述**：在 SUTVA、一致性、处理随机化（或可忽略性）成立时，对任意分层 Z=z，配对差分 D_j = Y_j(1) − Y_j(0) 满足 E[D_j | Z_j=z] = τ(z)；样本均值 τ̂ 是 ATE 的无偏估计。且若 Cov(Y(1), Y(0)) > 0，则 Var(D) < Var(Y(1)) + Var(Y(0))。

**证明**：由一致性 Y_j = Y_j(A_j)，且两世界共享同一随机数 U_j（CRN），故 D_j = Y_j(1;U_j) − Y_j(0;U_j) 是同一个体在同一扰动下的处理效应，条件期望为 CATE(z)。对 z 取期望得 E[D]=E[τ(Z)]=τ。方差展开 Var(D)=Var(Y(1))+Var(Y(0))−2Cov(Y(1),Y(0))，CRN 使两个潜在结果同向变化，Cov>0，故方差缩减。∎

### 引理 27（证书随机丢弃恢复正性）

**陈述**：设规则由前置条件确定性触发，即 P(A_i=1|Z=z) ∈ {0,1}。引入丢弃概率 p_drop ∈ (0,1) 后，对任意可触发状态 z 有 p_drop ≤ P(A_i=1|Z=z) ≤ 1 − p_drop，从而后门可识别性条件（positivity）成立。

**证明**：干预后的处理分配为 A_i = Bernoulli(1 − p_drop) 与前置条件的合成；在可触发状态上 P(A_i=1)=1−p_drop，在不可触发状态上 P(A_i=1)=0。对可触发状态，1−p_drop 与 p_drop 均严格位于 (0,1)，故每个协变量层内两种处理均有正概率，positivity 成立；配合后门调整即可识别 τ_i。∎

### 引理 28（因果负迁移判决的可靠性）

**陈述**：在无未测混杂与 SUTVA 下，若目标域估计满足 UCB_α(τ_i^{s→t}) < 0，则以至少 1−α 的置信度，启用规则 i 会提高目标域期望风险；令 μ_i^c=0 可避免该因果危害。

**证明**：UCB<0 意味着 τ_i^{s→t} 的 (1−α) 置信区间整体位于负半轴，故以 1−α 置信度 τ_i^{s→t}<0，即 E[Y(1)−Y(0)]<0 的反面——启用处理使风险上升。CTF 在 `ci_high<0` 时返回 μ=0，等价于禁用迁移，故不会把有害规则引入目标域。∎

### 定理（CCG 的因果准入安全性）

**陈述**：在无未测混杂、SUTVA、正性成立，且规则间无显著交互（或交互已通过因子设计联合准入）时，对任意计划 Π，若 `CCG.admits(Π)=True`，则 Π 中被启用的每条规则 i 均满足 LCB_α(τ_i) ≥ -ε；且任何因果显著有害的规则不会被执行。因此期望风险满足 E[Y(CCG)] ≤ E[Y(KTCG)] + ε·N_active。

**证明**：`CCG.admits` 逐条检查活跃规则，`is_causally_admissible` 要求 `id_status=identified` 且 `ci_low ≥ -ε`，`is_harmful` 拦截 `ci_high<0`。在可加性（无交互）下，被拒规则对期望风险的贡献非负地移除，故总期望风险下降至多 ε·N_active；存在显著交互时，`factorial_interaction` 已把配对规则纳入联合检查，定理在联合可加性下同样成立。∎

## 5. 对比实验设计（本轮核心产物）

### 5.1 实验目的

1. 验证「因果门」相对「相关性门」是否真的减少违规，而不是仅仅改变保守度；
2. 用**伪规则负对照**证明因果推断能识别相关性虚假规则；
3. 用**已知有益规则正对照**证明因果门不会误杀真规则；
4. 验证因果迁移因子在跨地形负迁移上的判决优于 `sim·ρ·κ`。

### 5.2 实验分组（对照臂）

| 臂 | 名称 | 规则门控方式 | 用途 |
|---|---|---|---|
| A0 | No-KC | 不使用任何常识规则 | 下界基线 |
| A1 | KTCG-v28 | 相关性/相似度门（上一轮） | 主对照 |
| A2 | CCG-v29 | 因果门（LCB≥-ε） | 实验组 |
| A3 | CCG-no-dropout | 因果门但 p_drop=0 | 验证正性失败导致的有偏 |
| A4 | CCG-oracle | 用仿真真值 τ* 替代估计 τ̂ | 性能上界 |
| A5 | CCG-spurious | A2 + 注入伪规则「电池>80% ⇒ 安全」 | 负对照 |

伪规则「电池>80% ⇒ 安全」与「平地/轻载」强相关（电池高时多在平地），但因果上对安全无贡献；A1 应保留它，A2 应拒绝它。这是本轮最关键的判别性实验。

### 5.3 场景与配对

- 地形 5 类：平地、斜坡、湿滑、碎石、楼梯；
- 模式 3 类：walking / standing / transition；
- 每层 200 个匹配初始状态，固定共同随机数种子；
- 结果指标 Y 同时记录二元违规指示与归一化代价，主分析用违规指示（可解释、可直接算 ATE）。

### 5.4 评价指标

| 指标 | 定义 | 期望方向 |
|---|---|---|
| 违规率 | 每 1000 步违规次数 | A2 < A1 |
| 任务成功率 | 完成指定位移/站立的比例 | A2 ≥ A1 |
| 过度保守度 | 完成时间 / 能耗相对 A0 的增幅 | A2 < A1（更少无用约束） |
| 因果估计偏差 | \|τ̂ − τ*\| / \|τ*\|（仿真可算真值） | 报告 RMSE 与 CI 覆盖率 |
| 伪规则保留率 | 伪规则仍被门控启用的比例 | A2 ≈ 0，A1 高 |
| 真规则误杀率 | 已知有益规则被禁用的比例 | A2 ≈ 0 |
| 负迁移违规率 | 源平地→目标湿滑的违规率 | CTF < 启发式 μ |
| 告警延迟 | 从负迁移发生到隔离的步数 | 越小越好 |

### 5.5 统计方法

- 配对差分做 paired t-test，非正态时用 Wilcoxon signed-rank；
- 多重比较用 Holm–Bonferroni；
- 置信区间用配对 bootstrap（10⁴ 次）；
- 连续监控用 e-value，阈值 1/α，报告任意停止下的假阳性率；
- 先做功效分析：α=0.05、power=0.8、预期效应量 d=0.3 时 n_pairs≈90，取 200 留余量。

### 5.6 预期结果（可证伪预测）

1. A2 的违规率相对 A1 下降 ≥20%，且过度保守度不升（否则说明因果门只是更保守）；
2. A5 中伪规则保留率：A1 > 60%，A2 < 10%；
3. A3（无丢弃）的 τ̂ 偏差显著大于 A2，CI 覆盖率 < 80%，验证正性必要性；
4. CTF 在「平地→湿滑」上的违规率低于启发式 μ，且能在一个评估窗口内把负迁移规则 μ 置 0。

## 6. 已知风险与缓解（增量更新）

| 风险编号 | 描述 | 严重度 | 缓解措施 | 剩余风险 |
|---|---|---|---|---|
| **R25** | **未测混杂导致 ATE 有偏** | **高** | 1) 证书随机丢弃 + 分层配对；2) E-value 敏感性分析；3) 影子模式与仿真真值校准；4) 伪规则负对照持续监控 | 摩擦真值、人为干预等不可测因素仍可能残留偏差 |
| **R26** | **规则交互破坏 SUTVA** | **高** | 1) 2^{k-q} 因子设计估计 I_ij；2) 交互显著时联合准入；3) 按地形/模式分层估计 CATE | 高阶交互与组合爆炸使部分因子设计漏检 |
| **R27** | **证书随机丢弃本身引入风险** | **中** | 1) 仅在仿真/影子/低风险 standing 阶段丢弃；2) 丢弃率上限与安全包络；3) 丢弃期间强制 USMC 兜底 | 低风险阶段仍可能遇到突发扰动 |
| R28 | 因果估计计算开销大 | 低 | 离线/异步执行，事件触发重估 | 新规则冷启动期只能保守禁用 |

## 7. 本轮最大风险（最终确认）

**一句话**：**因果识别假设在真实闭环机器人数据中被违反**——未测混杂、证书随机丢弃改变控制分布、规则交互破坏 SUTVA，三者任一成立都会使 ATE 有偏，导致因果门误杀有益规则或放行有害规则；而它比相关性门更危险，因为它披着「已被因果验证」的外衣，让操作员放松了本应保留的怀疑。
