# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「状态估计」×「抓取规划」）

> R69 教会闭环「问」：把不确定性拆成 (U_ale, U_epi)，用流匹配策略显式表示动作多模态，用 MINT 按 VoI 选择「看 / 问 / 触」，并自己指出最大风险——模态分布不可信时，系统会自信地追问一个幻影。这个风险其实暴露了三个更深的病灶：
> - **空间错位**：R69 的不确定性定义在**动作轨迹的聚类**上，而不是**隐状态的信念**上。动作多峰 ≠ 世界歧义：任务冗余会让同一世界产生许多动作（假歧义），策略收缩又会让不同世界产生同一动作（真歧义被抹平）。
> - **信息浪费**：R69 把任务动作 a 与信息动作 g 分开（ξ=(a,g)），但**抓取/接触本身就是传感**——最值钱的信息常常藏在本来就要执行的任务动作里。
> - **处置二元**：R69 只有「问」或「刹车（λ_floor）」。它漏掉了第三种、也是人类最常用的办法：**不去消除不确定性，而是选一个对残余不确定性鲁棒的动作**（兜住、顺应、笼式抓取）。
>
> 本轮两个灵感正好补上：
> - **状态估计**把不确定性放回它该在的位置——隐状态上的信念 b_t(x)，并给出两把尺子：**可观测性**（不是所有歧义都能被任何动作消解）与**一致性**（声称的置信不能超过信息论许可）。
> - **抓取规划**给出「对不确定性鲁棒的动作」的严格语言——力闭合裕度、鲁棒抓取质量 Q_δ、笼式抓取，以及「接触即观测通道」。
>
> 核心命题：**把 epistemic 从「动作空间熵」重写为「信念空间里、可观测且决策相关的那一部分」；对这部分做三值处置——能估则估（Estimate）、不必估则兜（Absorb）、估不了也兜不住才弃权（Abstain）；把抓取接触当作任务与传感的双角色动作；用状态估计一致性（NIS/NEES）与可观测性下界拦截幻影。新框架必须在「吸收容量=0、无接触信息、全可观测」时逐指令退化为 R69，再退化为 R68。** 命名 **GRASP-RAS**（Grasp-mediated Robust-Absorption State-estimation Policy for Risk-Adaptive Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「**我到底不知道什么、它可不可知、它值不值得知道，以及我能不能干脆抓得稳到它不重要**」——不确定性可以被估计掉、被设计绕过、或被告知在哪儿。

## 0. 直觉与动机

**灵感 1（状态估计 → 不确定性有「位置」和「结构」）**
直觉：R69 拿 K 条采样轨迹做聚类，把簇当模态。但簇是**动作**的簇，不是**世界**的簇。两个完全不同的物体位姿可能因为夹爪对称而生成同一条轨迹（真歧义被抹平），同一个位姿也可能因为任务有多条等价路径而裂成两个簇（假歧义被放大）。状态估计的教训是：先有信念 b_t(x)，再由任务读出 φ(x) 定义「决策相关等价类」；模态应当在 φ 上定义，而不在动作上定义。

更要紧的是，状态估计问的不是「我有多不确定」，而是「在哪个方向上不确定、这个方向可不可观测」。一个方向如果对任何信息动作的 Fisher 信息都接近 0，再问也问不出来（VoI≡0）；一个方向如果对任务读出 φ 没有影响，知道了也没用（VoI≡0）。R69 把这些方向全塞进一个标量 U_epi，再按熵去问——于是既会追问不可知的幻影，也会被任务冗余骗着问。

**灵感 2（花费地图 → 四种不确定性，四种处置）**
直觉：把信念切空间按两把尺子分成 2×2：**可观测吗？决策相关吗？**
- 可观测 ∧ 相关 → **估计**（唯一值得花交互预算的格子）；
- 可观测 ∧ 无关 → **忽略**（看见了也别分心，最多免费记录）；
- 不可观测 ∧ 相关 → **吸收或弃权**（问不出来，只能把动作设计得对这块不确定性鲁棒，或降低权限）；
- 不可观测 ∧ 无关 → **边缘化**（纯 nuisance，不该进入任何风险项）。
这张「花费地图」是本轮的核心。R69 的错误是把四个格子都当成「可以问」，把预算花在 2、3、4 格，还在 3 格里无限追问。抓取规划恰好给出 3 号格子的唯一正确出口：吸收。

**灵感 3（抓取规划 → 鲁棒裕度就是「吸收容量」）**
直觉：抓取从来不是「知道精确位姿才敢抓」。给定信念 b 的 (1−δ) 可信域 C_δ(b)，只要存在一组接触力在**域内所有位姿**上都能满足摩擦锥与力矩平衡（鲁棒力闭合），这个抓取就能吸收这段不确定性。定义吸收容量 κ(a,b) 为「仍保持力闭合裕度 ≥ q_min 的最大残余不确定度」。若不可解但相关的 U_abs ≤ κ(a,b)，就**不需要消除它**——直接抓，且安全性由鲁棒裕度**构造性**保证。这是 R69 没有的第三条路：不是「更慢」，而是「更稳」。笼式（caging）抓取尤其如此：它允许大得多的位姿误差。

**灵感 4（接触即传感 → 抓取是双角色动作）**
直觉：R69 的「探针 g_probe」是专门的信息动作，代价单独计算。但真实操作里，**抓取本身就是最强的传感器**：接触位置约束位姿，接触力约束质量与摩擦，滑移约束外力。也就是说，任务动作 a 天然携带信息增益 I_c(a,b)。R69 的 ξ=(a,g) 是「任务与信息不相交」的特例；GRASP 允许同一个动作既完成任务又消解歧义，于是 VoI 不该只算 g 的，也要算 a 的「免费信息」。这既补上 R69 的 VoI 低估，也省掉不必要的问句。

**灵感 5（一致性 → 拦截「被证实的错误」）**
直觉：R69 的最大风险是幻影模态与误导回答被盖章「已验证」。状态估计给出一把独立的尺子：**新息一致性**。任何声称把协方差压到某个水平的更新，都不能违反 Fisher 信息给出的 Cramér–Rao 下界；若声称的后验比下界还自信，NIS/NEES 会以高概率报警。于是「回答听起来很确定」不再重要——**声称的置信度若超出信息论许可，就判为不一致并拒绝**。这把 R69 的「k 源一致」从投票升级为带信息下界的可证伪检验。

**灵感 6（分辨率的保质期 → 已解决会过期）**
直觉：R69 默认「消解」是永久的。但状态估计告诉我们：过程噪声会累积，可观测性会衰减（遮挡、接触丢失、摩擦变化），今天看清的方向明天可能又糊了。所以「已消解」应带一个由可观测性指数与过程噪声决定的保质期；到期必须重开（re-open），否则一次早期消解会变成长期盲信。这与 R68 的「标定吸收」是同一类病（盲信旧结论），只是发生在信念层。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（GRASP-RAS 总览）** GRASP-RAS = (BSE, BEAM, DRQ, OGC, GRA, DAI, BCG, RDL, RAS-WM‡)。四条不变式：
(i) 实时流零学习写操作（继承 R69 定义 293-i / R68 定义 276-i）；
(ii) **信念优先**：一切不确定性量必须由隐状态信念 b_t 导出；动作聚类只能作为信念读出的近似，不得单独定义模态；
(iii) **三值处置**：每个决策属于 {Estimate, Absorb, Abstain}，三者都通过与任务动作相同的 C-RAS-WM 认证；
(iv) **可观测性门控**：只有「可观测 ∧ 决策相关」方向的信息增益可计入 VoI。

**定义 311（隐状态与混合信念）** 隐状态 x_t = (T_obj ∈ SE(3), m, μ, c_mode, ι, w_ext)（物体位姿、质量、摩擦、接触模式、人类意图、外力）。信念 b_t = p(x_t | o_{1:t}, a_{1:t−1})，用混合表示：连续部分（位姿/质量/摩擦）高斯或 IMM，离散部分（接触模式/意图）类别分布。预测 b_t^- = ∫ T(x_t|x_{t−1}) b_{t−1} dx；更新 b_t ∝ p(o_t|x_t) b_t^-。

**定义 312（任务读出与决策相关商）** 任务读出 φ: 𝒳 → ℝ^{d_φ}（如任务扳手可行性、碰撞间隙、成功概率、后续轨迹代价）。定义决策相关等价：x ~φ x' 当且仅当 φ(x)=φ(x') 且对任意候选动作的最优值相同。模态定义在 φ 的等价类上。决策相关不确定度 U_rel = tr(Cov(φ(x)|b))。

**定义 313（可观测性 Gramian 与可分辨方向）** 对信息动作（含任务动作的接触）g，观测模型 p(y|x,g)，局部 Fisher 信息 O_g(x) = E_{y}[∇_x log p(y|x,g) ∇_x log p(y|x,g)^T]。方向 v 的主动可观测性 o_g(v) = v^T O_g v。称 v 在 g 下**可分辨**若 o_g(v) ≥ o_min。Cramér–Rao：Cov(x|y,g) ⪰ (P_prior^{-1} + O_g)^{-1}，故任何更新都无法把相关方向方差压到下界以下。

**定义 314（花费地图 BEAM）** 信念切空间按 H_rel（φ 的值域切空间）与 H_obs（Σ_g O_g 的值域）分解，得到「可观测 ∧ 相关」子空间 S_E 及四格子 {E 估计, I 忽略, A 吸收/弃权, M 边缘化}。定义可解不确定度 U_res = tr(Π_E Σ_b Π_E) 与不可解相关不确定度 U_abs = tr(Π_A Σ_b Π_A)。只有 U_res 可进入估计预算；U_abs 只能由吸收或弃权处理；其余边缘化，不计入风险。

**定义 315（鲁棒抓取质量与吸收容量）** 给定抓取动作 a（接触集与扳手）与可信域 C_δ(b)，鲁棒质量 Q_δ(a,b) = min_{x∈C_δ(b)} q(a,x)，q 为力闭合裕度/最大内接扳手球半径。吸收容量 κ(a,b) = sup{ε : Q_δ(a,b) ≥ q_min，∀ 相关方向直径 ≤ ε}。称 a **可吸收** b 当 U_abs ≤ κ(a,b) 且任务价值 V_task(a,b) ≥ v_min。

**定义 316（双角色动作与信息影子价）** 动作 a 的总价值 J(a|b) = V_task(a,b) + γ·I_c(a,b)，其中 I_c(a,b) = H(φ|b) − E_{y~p(y|a,b)} H(φ|b,y) 为接触信息增益，γ 为信息影子价（由预算对偶给出）。R69 的 ξ=(a,g) 是「任务动作 I_c=0、信息动作 V_task=0」的受限动作集特例（引理 22）。

**定义 317（三值决策 DAI）** 对信念 b 与候选动作集：
- **Absorb**：若 ∃a 可吸收且任务价值达标 → 直接执行，不消解；
- **Estimate**：若 ∃ 信息分量 g（独立或附着于 a）满足 o_g^rel ≥ o_min 且 VoI_eff(g) − c(g) > 0 → 执行并更新；
- **Abstain**：否则从安全回退集 𝒜_safe（含减速、顺应保持、撤回安全位、笼式保持）选认证动作，λ=λ_floor。
三者按 J − 成本 × 风险约束取最优；并列时 Absorb 优先（省预算）。**Abstain 不是「刹车」的同义词，刹车只是 𝒜_safe 的一个元素。**

**定义 318（可观测性门控的 VoI）** VoI_eff(g) = VoI(g) · 1[o_g^rel ≥ o_min]，其中 VoI(g) = H(φ|b) − E_{y~p(·|g,b)} H(φ|b,y)。若相关方向的观测 Fisher 信息不足以达到任务所需精度，则 VoI_eff ≡ 0（幻觉信息）。另要求回答对隐状态敏感：I(x_rel; y|g) 集中于 S_E，否则视为与决策无关。

**定义 319（信念一致性门 BCG）** 对任意更新（交互回答、接触观测、标定回灌），计算 NIS = ν^T S^{-1} ν（ν 为新息，S 为新息协方差）与 NEES = e^T P^{-1} e。若 NIS > χ²_{d,1−α_N} 则拒绝该更新；若声称后验协方差在 PSD 序下低于 Cramér–Rao 下界 (P_prior^{-1}+O_g)^{-1}，判为**过度自信**，强制回退到 prior 或协方差膨胀。BCG 是「被证实的错误」的直接拦截器。

**定义 320（吸收证书）** 吸收动作签发证书 C_abs = (Q_δ, δ, C_δ 来源, q_min, NIS, BCG 状态, 认证前缀)。有效 ⇔ Q_δ ≥ q_min ∧ BCG 一致 ∧ 任务价值达标。证书进入审计账本，与 R69 的「已消解」并列但**语义不同**：消解是「我知道」，吸收是「我不必知道，且风险被构造性界住」。

**定义 321（分辨率衰减 RDL）** 定义可观测性指数 ρ_obs(t) = λ_min(Σ_{s≤t} γ^{t−s} O_{g_s})。相关方向方差随时序增长 σ²(t+1) = σ²(t) + q_v，并在观测时按下界收缩。若 σ²(t) > σ_reopen² 或 ρ_obs < ρ_min，则此前「已消解」的方向 re-open，U_epi 回填。保质期 T_reopen ≈ (σ_reopen² − σ²)/q_v。

**定义 322（信息动作的物理可达性）** 可观测性不是免费的：某些方向只有在特定 vantage/抓取姿态下才可观测。定义可达可观测性 o_g^reach(a,b) = max over 可达且认证的姿态；信息动作的 VoI 必须扣除到达该姿态的运动/时间成本，受限预算（继承 R69 定义 293-ii）。

**定义 323（干扰集 ℰ_GRASP）** ℰ_GRASP = ℰ_FLUID × ℰ_contact × ℰ_obsdecay × ℰ_alias。ℰ_contact：滑移、摩擦锥越界、接触模型误差、力饱和；ℰ_obsdecay：遮挡、传感器掉线、对抗性观测；ℰ_alias：共谋欺骗使动作保持自洽但信念错误（专门攻击「动作聚类」）。

**定义 324（证书 J_GRASP）** J_GRASP = (J_FLUID, U_res_before/after, U_abs, absorb_margin, Q_δ, NIS_p95, NEES_p95, ρ_obs, decision∈{E,A,Abstain}, grasp_ver)。

**定义 325（严格包含 R69 / R68）** 当 κ≡0（无吸收容量）、I_c≡0（任务动作无信息）、所有相关方向可观测且 VoI_eff≡VoI 时，GRASP 的三值决策逐指令退化为 R69 的「问或刹车」；再当 VoI≤成本时退化为 R68。安全侧不变或更强。

**定义 326（φ-模态分解 DRQ）** 模态 m_k 为 φ_# b 在阈值以上的连通分量，权重 ŵ_k 为其概率质量，原型为条件均值，模态内协方差为 Σ_k^φ。与 R69 的动作聚类模态 {m_k^ξ} 的关系由引理 19 给出：既非加细也非粗化。

```python
# IP-264 BSE：混合信念估计（连续 IMM/EKF + 离散类别），在线零学习写
class BeliefSpaceEstimator:
    def predict(self, b, a_prev):
        return self.T(b, a_prev)                      # 过程模型 + 过程噪声 Q
    def update(self, b_pred, o, bc_gate):
        b_post, nu, S = self.bayes(b_pred, o)         # 新息 nu / 新息协方差 S
        if not bc_gate.accept(nu, S):                 # NIS 一致性
            return bc_gate.inflate(b_pred), None
        return b_post, (nu, S)

# IP-265 BEAM+DRQ：信念空间花费地图，取代动作聚类
def beam_decompose(b, phi, obs_gramians):
    S_E = relevant(phi) & observable(obs_gramians)    # 可观测 ∧ 相关
    U_res = trace(proj(S_E) @ cov(b) @ proj(S_E))     # 可解
    U_abs = trace(proj(relevant(phi) - S_E) @ cov(b) @ proj(relevant(phi) - S_E))
    modes = phi_modes(b, phi)                          # 在 φ 上聚类，非动作上
    return U_res, U_abs, modes, U_nuisance(cov(b), S_E)

# IP-266 OGC：可观测性门控的 VoI（拦截幻觉信息）
def voi_eff(g, b, phi, o_min):
    Og = fisher_info(g, b)
    if projected_min_eig(Og, relevant(phi)) < o_min:
        return 0.0                                     # 问也问不出来
    return entropy(phi, b) - expected_entropy(phi, b, g)

# IP-267 GRA：鲁棒抓取质量 / 吸收容量
def absorb_capacity(a, b, delta, q_min):
    C = credible_region(b, delta)                      # (1-δ) 可信域
    Q = min(grasp_quality(a, x) for x in sample(C))    # 域内最差质量
    if Q < q_min:
        return 0.0, Q
    return max_spread_with_quality(a, b, q_min), Q     # κ

# IP-268 DAI：三值决策（估计 / 吸收 / 弃权）
def dai_decide(b, candidates, budget, c_ras_wm, bc_gate):
    best = None
    for a in candidates:
        if not c_ras_wm.certify(a, b):
            continue                                   # 物理安全前缀
        kappa, Q = absorb_capacity(a, b, DELTA, Q_MIN)
        if U_abs(b) <= kappa and task_value(a, b) >= V_MIN:
            best = better(best, ("absorb", a, Q))      # 不必知道，抓得稳即可
            continue
        for g in info_components(a):
            v = voi_eff(g, b, a.phi, O_MIN) - cost(g) - reach_cost(g)
            if v > 0 and budget.allow(g):
                best = better(best, ("estimate", (a, g), v))
    return best or ("abstain", safe_fallback(b), None) # 刹车只是回退集一员

# IP-269 BCG：新息一致性 + 过度自信拦截
class BeliefConsistencyGate:
    def accept(self, nu, S):
        return nu.T @ inv(S) @ nu <= chi2_threshold(len(nu))
    def inflate(self, b):
        return b.inflate(SIGMA_INFLATE)                # 拒绝更新，保持诚实

# IP-270 RDL：分辨率衰减与重开
def resolution_decay(b, resolved, O_hist, q_v):
    rho = min_eig(discounted_sum(O_hist))
    reopened = {v for v in resolved
                if var(b, v) > SIGMA_REOPEN**2 or rho < RHO_MIN}
    return reopened                                    # 回到 U_epi 预算

# IP-274 主闭环（继承 R69，替换不确定性来源与处置）
def GRASP_RAS_round(M, obs):
    b_pred = M.bse.predict(M.b, M.last_a)
    b, inn = M.bse.update(b_pred, obs, M.bcg)          # 一致性门
    U_res, U_abs, modes, U_nui = M.beam.decompose(b, M.phi, M.o_hist)
    reopened = M.rdl.step(b, M.resolved, M.o_hist)     # 已解决会过期
    U_res += sum_var(b, reopened)
    decision, act, aux = M.dai.decide(
        b, M.fmp.sample(obs, K=M.k_for(U_res + U_abs)),
        M.budget, M.c_ras_wm, M.bcg)
    if decision == "estimate":
        y = M.cia.execute(act[1])                      # 看/问/触/抓取接触
        b, inn = M.bse.update(b, y, M.bcg)
        M.o_hist.append(fisher_info(act[1], b))
    if decision == "absorb":
        M.ledger.certify_absorb(aux)                   # 吸收证书，非消解
    # 风险：只有 aleatoric + 不可解相关 + 未消解部分进入 λ floor
    U_floor = U_ale(b) + U_abs + (U_res if decision != "estimate" else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(act, ..., wm_preds)
    M.vqa_i.submit_async(decision, U_res, U_abs, aux)
    return k, lam, act, (U_res, U_abs)
```

## 3. 推导

**引理 19（动作模态 ≠ 信念模态）** 对任意策略 π 与信念 b，动作熵 H(ξ|b) 与决策相关信念熵 H(φ|b) 之间一般不存在序关系。反例一（任务冗余/多重性）：b 退化（φ 确定），但策略在等价动作间随机 → H(ξ|b)>0、H(φ|b)=0；反例二（别名/aliasing）：b 有两个 φ-不同但 π 给出同一动作分布的模态 → H(ξ|b)=0、H(φ|b)>0。故 R69 的 H_mode 既可能高估也可能低估真实的决策相关歧义；用动作簇算 VoI 会追错目标。

**引理 20（可观测性给出信息增益的硬上界）** 对相关方向 v，后验方差下界 σ²_post(v) ≥ 1/(σ_prior^{-2}(v) + o_g(v))（Cramér–Rao）。故可达熵降 ΔH(v) ≤ ½ log(1 + o_g(v) σ_prior²(v))。当 o_g(v) < o_min（任务所需精度对应的 Fisher 阈值）时，任何交互都无法把 v 压到目标精度，VoI_eff=0。系：**不可观测的歧义不是「还没问」，而是「问不出来」**——R69 对它计算 VoI 是在为一个不存在的信息付钱。

**引理 21（吸收支配刹车）** 设风险由鲁棒质量下界刻画：Q_δ ≥ q_min ⇒ 在可信域内失败概率 ≤ δ、且风险 ≤ ε（A99）。若 a 可吸收且 V_task ≥ v_min，则在同等风险约束 ε 下，执行 a 的期望任务价值 ≥ 任一 abstain 动作；当 V_task 严格大于回退集最优值时严格更优。故 R69 的「未消解 → 一律减速」在吸收可行的状态上被支配。系：**保守不是唯一的安全出口，鲁棒是更高效的出口。**

**引理 22（双角色动作的效率优势）** 对含接触的任务动作 a，I_c(a,b) ≥ 0 且其信息获取的边际成本为 0（反正要执行）。设预算为单独信息动作的有限配额，则考虑双角色动作的策略期望成本 ≤ R69 的「任务/信息分离」策略；当 I_c>0 且 R69 会额外消耗一次 g 时严格更优。R69 的 ξ=(a,g) 是本引理中 I_c≡0、V_task(g)≡0 的边界。

**引理 23（一致性门拦截过度自信的幻影）** 若一次更新声称后验 Σ_post 在 PSD 序下低于 Cramér–Rao 下界 Σ_CR = (Σ_prior^{-1} + O_g)^{-1}，则其标准化新息 NIS 的期望超过 χ² 上界的概率随样本数 → 1（A100：观测模型正确）。故幻影模态、投毒回答若以「高置信」形式进入，BCG 以高概率拒绝；错误率由 α_N 控制。系：R69 的「k 源一致」被升级为「k 源一致 ∧ 信息论许可」。

**引理 24（分辨率的保质期）** 在过程噪声 q_v>0、可观测性指数 ρ_obs 下，已消解方向方差满足 σ²(t) ≥ σ²(0) + q_v t（无新观测时），重新越过 σ_reopen 的时间 T_reopen ≈ (σ_reopen² − σ²(0))/q_v。故「已消解」不是终态；不重开会导致长时程盲信（与 R68 的标定吸收同构）。

**定理 18（GRASP 严格包含 R69 / R68）** 在 A99–A103 下，任意状态上 GRASP 的期望风险 ≤ R69 ≤ R68，且期望任务价值 ≥；当 κ≡0 ∧ I_c≡0 ∧ S_E=H_rel ∧ VoI_eff=VoI ∧ VoI≤成本时三者逐指令相同。安全侧不让步；效率侧由吸收区与双角色动作扩展 Pareto 前沿。

**定理 19（三值处置的安全-效率支配）** 设估计、吸收、弃权三支都持有有效证书（定义 320、R69 定义 305）。则三值策略可达的 (风险, 任务价值) 区域包含 R69 的两值区域；当存在可吸收状态时严格扩张。且分支切换在同一证书失效/恢复边界上连续（换装不变式），无控制突变。

## 6. 本轮最大风险

**一句话**：GRASP-RAS 把「安全」押在**鲁棒抓取质量 Q_δ 是真实失败概率的下界**这一前提上；而 Q_δ 又完全依赖信念 b 的可信域 C_δ——**若信念过度自信（协方差被低估）或接触/摩擦模型有偏，可信域根本不包含真实状态，κ 被高估，系统就会自信地执行一个它以为鲁棒、实际已越出力闭合的抓取。吸收不是消除了不确定性，而是把不确定性抵押给了一个模型；当模型低估不确定性时，「鲁棒」恰恰是最危险的自信。**

**次级风险与缓解**：
1. **吸收区误判**（Q_δ 校准偏差）→ E312 可靠图 + BCG 协方差膨胀 + δ 保守化；
2. **接触信息被滑移/摩擦欺骗** → ℰ_contact 对抗训练 + 多源交叉 + 力矩通道否决；
3. **BEAM 子空间估计错误**（可观测性/相关性投影偏）→ 投影保守化：宁可把 E 判成 A（吸收/弃权），绝不反向；
4. **分辨率衰减导致长时程盲信** → RDL 强制重开 + E309；
5. **计算预算被混合信念与 Fisher 投影击穿** → 廉价 IMM + 低秩 Fisher + 自适应 K；
6. **与 R69 的退化边界不一致** → E308 逐指令差分测试。

**定义 317–318（三值决策与门控 VoI）** Absorb 优先；Estimate 需 `o_g^rel ≥ o_min ∧ VoI_eff−c>0`；Abstain 从安全回退集 `𝒜_safe`（刹车只是其一）选认证动作。`VoI_eff = VoI·1[o_g^rel ≥ o_min]`。

```python
class BeliefSpaceEstimator:
    def predict(self, b, a_prev): return self.T(b, a_prev)
    def update(self, b_pred, o, bcg):
        b_post, nu, S = self.bayes(b_pred, o)
        return (bcg.inflate(b_pred), None) if not bcg.accept(nu, S) else (b_post, (nu, S))

# IP-265/266 BEAM+DRQ：花费地图与 φ-模态
def beam_decompose(b, phi, gramians):
    S_E = relevant(phi) & observable(gramians)
    U_res = trace(proj(S_E) @ cov(b) @ proj(S_E))
    U_abs = trace(proj(relevant(phi) - S_E) @ cov(b) @ proj(relevant(phi) - S_E))
    return U_res, U_abs, phi_modes(b, phi)

    if projected_min_eig(fisher_info(g, b), relevant(phi)) < o_min: return 0.0
    return entropy(phi, b) - expected_entropy(phi, b, g)

    for a in cands:

        kappa, Q = absorb_capacity(a, b, DELTA, Q_MIN)

    return best or ("abstain", safe_fallback(b), None)

# IP-270 BCG：一致性 + 过度自信拦截
class BeliefConsistencyGate:
    def accept(self, nu, S): return nu.T @ inv(S) @ nu <= chi2_threshold(len(nu))
    def inflate(self, b): return b.inflate(SIGMA_INFLATE)

# IP-271 RDL：分辨率衰减
def resolution_decay(b, resolved, O_hist):
    rho = min_eig(discounted_sum(O_hist))
    return {v for v in resolved if var(b, v) > SIGMA_REOPEN**2 or rho < RHO_MIN}

# IP-274 主闭环（继承 R69）
def GRASP_RAS_round(M, obs):
    b = M.bse.update(M.bse.predict(M.b, M.last_a), obs, M.bcg)[0]
    U_res, U_abs, modes = M.beam.decompose(b, M.phi, M.o_hist)
    U_res += sum_var(b, M.rdl.step(b, M.resolved, M.o_hist))
    decision, act, aux = M.dai.decide(b, M.fmp.sample(obs, K=M.k_for(U_res + U_abs)),
                                      M.budget, M.c_ras_wm)
    if decision == "estimate":
        y = M.cia.execute(act[1]); b = M.bse.update(b, y, M.bcg)[0]
        M.o_hist.append(fisher_info(act[1], b))
    if decision == "absorb": M.ledger.certify_absorb(aux)
    U_floor = U_ale(b) + U_abs + (U_res if decision != "estimate" else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k = M.c_ras_wm.certified_prefix(act, ..., wm_preds)
    M.vqa_i.submit_async(decision, U_res, U_abs, aux)
    return k, lam, act, (U_res, U_abs)
```

## 4. 推导

**引理 19（动作模态 ≠ 信念模态）** `H(ξ|b)` 与 `H(φ|b)` 无序关系。任务冗余（φ 确定但动作多样）使动作熵高估歧义；别名（φ 不同但动作相同）使动作熵低估歧义。故 R69 的 `H_mode` 既非上界也非下界，用动作簇算 VoI 会追错目标。

**引理 20（可观测性硬上界）** `σ²_post(v) ≥ 1/(σ_prior⁻²(v)+o_g(v))`，故 `ΔH(v) ≤ ½log(1+o_g σ_prior²)`。当 `o_g < o_min` 时任何交互都达不到目标精度，`VoI_eff=0`：**不可观测的歧义不是「还没问」，而是「问不出来」**。

**引理 21（吸收支配刹车）** 若 `Q_δ ≥ q_min` 则在可信域内失败概率 ≤ δ、风险 ≤ ε；可吸收动作的任务价值 ≥ 任一 `𝒜_safe` 动作，故「未消解 → 一律减速」在吸收可行处被支配。**保守不是唯一安全出口，鲁棒是更高效的出口。**

**引理 22（双角色动作效率优势）** 含接触任务动作 `I_c ≥ 0` 且边际信息成本为 0（反正要执行），故 GRASP 期望成本 ≤ R69 的任务/信息分离策略；`ξ=(a,g)` 是 `I_c≡0, V_task(g)≡0` 边界。

**引理 23（一致性拦截幻影）** 若声称 `Σ_post` 在 PSD 序低于 `Σ_CR = (Σ_prior⁻¹+O_g)⁻¹`，则 NIS 超 χ² 上界的概率随样本数 → 1。幻影模态/投毒回答以「高置信」进入时被 BCG 高概率拒绝；R69 的「k 源一致」升级为「k 源一致 ∧ 信息论许可」。

**引理 24（分辨率保质期）** 无新观测时 `σ²(t) ≥ σ²(0)+q_v t`，`T_reopen ≈ (σ_reopen²−σ²(0))/q_v`。「已消解」不是终态，不重开会造成长时程盲信。

**定理 18（严格包含 R69/R68）** A99–A103 下，任意状态 `risk(GRASP) ≤ risk(R69) ≤ risk(R68)`，`value(GRASP) ≥ value(R69)`；当 `κ≡0 ∧ I_c≡0 ∧ S_E=H_rel ∧ VoI_eff=VoI ∧ VoI≤成本` 时逐指令相同。安全不让步，效率由吸收区与双角色动作扩展 Pareto 前沿。

**定理 19（三值安全-效率支配）** 三支都持有效证书时，三值可达 (风险, 价值) 区域包含 R69 两值区域；存在可吸收状态时严格扩张；分支切换在证书失效/恢复边界连续（换装不变式），无控制突变。

## 7. 本轮最大风险

**一句话**：GRASP-RAS 把「安全」押在**鲁棒抓取质量 Q_δ 是真实失败概率的下界**这一前提上；而 Q_δ 又完全依赖信念 b 的可信域 C_δ——**若信念过度自信（协方差被低估）或接触/摩擦模型有偏，可信域根本不包含真实状态，κ 被高估，系统就会自信地执行一个它以为鲁棒、实际已越出力闭合的抓取。吸收不是消除了不确定性，而是把不确定性抵押给了一个模型；当模型低估不确定性时，「鲁棒」恰恰是最危险的自信。**

**次级风险与缓解**：吸收区误判（E312 可靠图 + BCG 膨胀 + δ 保守化）；接触信息被滑移/摩擦欺骗（ℰ_contact 对抗训练 + 多源交叉 + 力矩否决）；BEAM 投影偏（宁可把 E 判成 A，绝不反向）；分辨率衰减致盲信（RDL 强制重开 + E309）；计算预算被混合信念与 Fisher 投影击穿（廉价 IMM + 低秩 Fisher + 自适应 K）；与 R69 退化边界不一致（E308 逐指令差分）。
