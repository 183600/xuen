# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「失败恢复」×「目标检测」）

> 第 54 轮解决的是"组合前能不能做"（动作-鲁棒性双证书 `α_S, ρ, γ_ce, δ_a`）。本轮追问"做失败之后怎么活"。核心矛盾：**H22**：现有 ρ/Explain 能报告"失败了"，却不能回答失败是否被"看见"、根因绑定到哪个物体、恢复动作本身是否安全；**H23**：目标检测是物体级前置条件的唯一锚点，但检测器的"自信错检"会制造**静默失败（silent failure）**，使恢复门控根本不被触发——恢复层可能把名义失败转化为更隐蔽的系统性失败。

## 0. 直觉与动机

**灵感 1（目标检测 = 前置条件的可证伪锚点）**
直觉：机器人失败极少是"动作解算错"，更多是"对象判断错"——抓错物体、目标被遮挡、类别漂移。检测器输出一个单点标签 `(box, cls, score)`，本质上**不可证伪**：它不会说"我可能错了"。用 conformal prediction 把它升级为带覆盖保证的**集合** `B(o)`，前置条件 `pre(o)` 在 `B(o)` 上做全称可满足性检查：只有集合中所有候选都满足前置条件，任务才被认证可执行；否则就是**检测驱动的不确定性失败**。这样，目标检测从"感知输入"变成"失败可判定性的锚点"。

**灵感 2（失败恢复 = 门控 + 诊断 + 恢复策略 + 证书，而非补丁）**
直觉：恢复不是 try/except，而是一条有自己动作空间占用的策略。定义失败签名 `φ = (u_d, v_pre, δ_exec, τ_since)`：`u_d` 检测不确定度、`v_pre` 前置条件违背、`δ_exec` 执行偏差、`τ_since` 距上次恢复的时间。门控 `G(φ)` 决定是否进入恢复；诊断把 `φ` 映射到失败类 `F` 与恢复模式（重感知 / 重绑定物体 / 重抓 / 重规划 / 安全停机 / 人接管）；恢复策略 `R` 必须在预算 `β` 内**终止（liveness）**且**不破坏安全不变式（non-regression）**。恢复策略也有动作剖面 `α_R`，其恢复包络可能与名义动作冲突。

**灵感 3（静默失败是恢复的真正敌人）**
直觉：恢复的收益是 `rec(F)`，代价是把"被检测到的失败"变成必须正确处理的状态。若检测器自信错检，门控不触发，名义计划继续在**错误物体**上执行——这是静默失败，恢复层毫无作用，甚至因占用资源/改写状态而放大损失。因此必须显式建模 `p_silent` 并给它上界，而不是默认"失败总能被发现"。

**灵感 4（净收益不等式 → 恢复不是越多越好）**
直觉：带恢复的成功率下界形如 `1 - p_f(1-rec_lo) - p_silent - ...`。恢复只在 `(p_f - p_silent)·(rec_lo - h_rec) > 0` 时净收益为正，其中 `h_rec` 为恢复动作自身的条件伤害率。这给出一个可判定的**恢复开关**：当静默失败质量超过可挽回质量、或恢复伤害率高于恢复成功率时，宁可不恢复（退回最保守的安全停机或人接管），也不要盲目重试。这把"要不要恢复"从经验直觉变成可验证判据。

**灵感 5（云边恢复协同 → 恢复证书必须可迁移）**
直觉：云端在丰富仿真里训练恢复策略，边端在真实分布执行；恢复策略对失败类分布高度过拟合，域漂移后恢复包络失效。需要**恢复迁移证书**：绑定失败类覆盖率、检测器域覆盖、逐类恢复成功率下界与预算，并把第 54 轮的 `JTC` 从"动作-鲁棒性迁移"升级为"动作-鲁棒性-恢复迁移"。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（检测信念集，Conformal Detection Belief）**
检测器 `D` 配合非一致性分数 `s(o)` 与校准集阈值 `q_{1-ε}`，输出集合值检测
`B(o) = { o' : s(o') ≥ q_{1-ε} }`。在可交换性假设下 `P(o* ∈ B(o)) ≥ 1-ε`。检测不确定度
`u_d(B) = 1 - max_{o'∈B} conf(o')`（或集合类熵）。`B(o)=∅` 即"无可靠检测"，按门控触发处理。

**定义 122（失败签名）**
`φ = (u_d, v_pre, δ_exec, τ_since)`，其中 `v_pre = 1[∃ o'∈B(o), ¬pre(o')]`，`δ_exec = ||a_exec - a_plan||`，`τ_since` 为距上次恢复的时间。失败签名是门控与诊断的唯一输入，避免"看视频猜失败"的不可复现性。

**定义 123（检测驱动失败门控）**
`G(φ) = 1` 当且仅当
```
v_pre = 1  ∨  u_d > u_max  ∨  δ_exec > δ_max  ∨  B(o) = ∅
```
**静默失败集** `S = { failure : G(φ)=0 }`，其质量 `p_silent = P(failure ∧ G=0)`。

**定义 124（恢复策略与恢复包络）**
恢复策略 `R : Φ → A_R`，其动作剖面 `α_R : A → [0,1]`，恢复包络
`E_R = { a∈A : α_R(a) ≥ θ_r }`。恢复可行条件：
```
E_R ≠ ∅  ∧  compat(E_R, A_core) ≤ θ_conflict  ∧  cost_align(E_R, A_core) ≤ τ_e
```
即恢复动作不得与名义核心动作 `A_core` 产生超阈冲突，否则恢复会破坏正在执行的任务。

**定义 125（恢复提交证书）**
`C_R = (F, R, β, rec_lo, h_rec, Inv)`，其中 `F` 为失败类、`β` 为预算、`rec_lo` 为成功恢复率下界、`h_rec` 为恢复伤害率上界、`Inv` 为安全不变式。`C_R` **sound** 当且仅当对任意 `failure∈F` 且 `G=1`：
```
R 在 β 内终止 ∧ 恢复到 pre 可满足状态 ∧ 保持 Inv
```
分别以概率 `≥ rec_lo`（成功）与 `≤ h_rec`（伤害）成立。

**定义 126（静默失败上界与恢复净收益开关）**
静默失败上界
```
p_silent ≤ p_f · (ε + p_shift + p_unmodeled)
```
其中 `ε` 为 conformal 名义失效率、`p_shift` 为域漂移导致的覆盖退化、`p_unmodeled` 为未建模失败类质量。恢复净收益
```
Δ_rec = (p_f - p_silent)·(rec_lo - h_rec)
```
恢复开关 `switch = 1[Δ_rec > margin]`。`Δ_rec ≤ 0` 时必须退回安全停机/人接管。

## 2. 关键算法 伪代码

### IP-121 CDB（Conformal Detection Belief）

```python
def conformal_detection_belief(img, detector, calib_scores, eps):
    q = quantile(calib_scores, min(1.0, (1-eps)*(1+1/len(calib_scores))))
    raw = detector.predict(img)                 # [(box, cls, score)]
    B = [d for d in raw if d.score >= q]        # 集合值输出，非单点标签
    u_d = 1.0 - max([d.score for d in B], default=0.0)
    return B, u_d, q
```

### IP-122 DGF（Detection-Grounded Failure Gate）

```python
def failure_gate(B, pre, exec_state, theta_u, theta_d):
    v_pre = any(not pre(o, b) for b in B)        # 前置条件须在整个集合上成立
    u_d = uncertainty(B)
    d_exec = action_divergence(exec_state)
    phi = FailureSignature(u_d, v_pre, d_exec, exec_state.t)
    gate = v_pre or u_d > theta_u or d_exec > theta_d or len(B) == 0
    return gate, phi
```

### IP-123 RDR（Recovery Diagnosis & Response）

```python
def recovery_diagnose(phi, F_lib, history):
    F = classify_failure(phi, F_lib, history)     # 失败类
    mode = select_mode(F)                         # re_perceive/re_bind/re_grasp/re_plan/safe_stop/human
    return F, mode

def recovery_policy(F, mode, B, a_core, beta):
    if mode == 're_perceive':
        return RePerceive(target=B, budget=beta)
    if mode == 're_bind':
        return ReBindObject(candidates=B, budget=beta)
    if mode == 're_grasp':
        return ReGrasp(avoid=a_core, budget=beta)
    if mode == 're_plan':
        return RePlan(from_state=current, budget=beta)
    if mode == 'human':
        return HumanHandoff(evidence=phi)
    return SafeStop(invariant=Inv)                # 默认最保守
```

### IP-124 RAP（Recovery Action Profile / Envelope）

```python
def recovery_envelope(R, A_core, theta_r, theta_conflict):
    E_R = {a for a in A_grid if R.alpha(a) >= theta_r}
    conflict = jaccard(E_R, A_core)
    feasible = len(E_R) > 0 and conflict <= theta_conflict
    return E_R, conflict, feasible
```

### IP-125 RCC（Recovery Commit Certificate）

```python
def recovery_commit_certificate(F, R, beta, Inv, trials):
    term = all(t.terminates_within(beta) for t in trials)
    nonreg = all(preserves(t, Inv) for t in trials)
    rec_lo = clopper_pearson_lower(n_success, n, alpha=0.05)
    h_rec  = clopper_pearson_upper(n_harm, n, alpha=0.05)
    if not (term and nonreg):
        return ('reject', 'liveness_or_invariant')
    if rec_lo <= h_rec:
        return ('reject', 'not_net_positive', rec_lo, h_rec)
    return ('ok', RecoveryCert(F, R, beta, rec_lo, h_rec, Inv))
```

### IP-126 SFC（Silent-Failure Certificate & Switch）

```python
def silent_failure_bound(p_f, eps, p_shift, p_unmodeled):
    return p_f * min(1.0, eps + p_shift + p_unmodeled)

def recovery_switch(p_f, p_silent_ub, rec_lo, h_rec, margin=0.0):
    net_gain = (p_f - p_silent_ub) * (rec_lo - h_rec)
    return net_gain > margin, net_gain
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| CDB | O(N_calib + D log D) | O(|B|) | conformal 覆盖 ≥ 1-ε（可交换） |
| DGF | O(|B|·|pre| + |A|) | O(|B|) | 前置条件全称检查、门控 sound |
| RDR | O(|F|·|φ|) | O(|F|) | 失败类可辨识、诊断可复现 |
| RAP | O(|A|) | O(|A|) | 包络非空、冲突阈值 sound |
| RCC | O(n_trials·β) | O(|A|) | liveness + non-regression + rec_lo>h_rec |
| SFC | O(1) | O(1) | 静默失败上界 sound、开关符号正确 |

**正确性定理（Detection-Grounded Recovery Soundness）**
承接第 54 轮 (A22)–(A28)，新增：**(A29)** 检测信念集在目标分布上覆盖 `≥ 1-ε-p_shift`，未建模失败类质量为 `p_unmodeled`；**(A30)** 恢复提交证书 `C_R` sound 且 `rec_lo > h_rec`；**(A31)** 门控延迟 `≤ τ_g`。
则带恢复的任务成功率：
```
P_success ≥ 1 - p_f(1-rec_lo) - p_silent_ub - (p_f-p_silent_ub)·h_rec - β_E - P(δ_a>Θ_a)
p_silent_ub = p_f·(ε + p_shift + p_unmodeled)
```
恢复相对无恢复的净增益 `Δ_rec = (p_f-p_silent_ub)(rec_lo-h_rec)`；**恢复有益当且仅当 `Δ_rec>0`**。门控漏检只可能来自 conformal 覆盖失效、域漂移覆盖退化、或未建模失败类，故护栏必须分别针对这三项加，而不能笼统地说"恢复有效"。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 检测信念集覆盖 | 名义/漂移下的经验覆盖率 | 名义 gap ≤ 1%，漂移 gap ≤ 5% |
| E163 门控性能 | 失败召回 / 误触发 / `p_silent` | 召回 ≥ 92%，误触发 ≤ 5% |
| E164 恢复成功率与伤害率 | 逐失败类 `rec_lo`、`h_rec` | `rec_lo ≥ 0.7`，`h_rec ≤ 0.1` |
| E165 净收益扫描 | 随物体漂移强度变化的 `Δ_rec` 符号翻转 | 找到恢复启用/禁用边界 |
| E166 云边恢复迁移 | 仿真→真实边端 `rec` 降幅、FRX 拒绝率 | 降幅 ≤ 10%，拒绝率 ≥ 85% 时避免负迁移 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 静默检测失败（自信错检） | 高 | conformal 覆盖 + OOD 分数 + 时序一致性 + 高 `u_d` 直接人接管 |
| 恢复策略过拟合失败类分布 | 高 | 失败类分层测试 + 恢复包络冲突检查 + 恢复迁移证书 |
| 恢复引入伤害/负迁移 | 高 | non-regression 不变式 + `h_rec` 上界 + `Δ_rec ≤ 0` 时安全停机 |
| 重试活锁/震荡 | 中 | 预算 β + 尝试计数单调 + hysteresis + 冷却窗口 |
| 门控与诊断延迟 | 中 | 边端轻量门控、云端只做离线诊断、门控分级降级 |

## 6. 本轮最大风险

**一句话**：失败恢复层的 soundness 完全依赖"失败可见性"，而目标检测的自信错检与域漂移会让静默失败绕过门控；一旦 `p_silent` 超过可挽回质量或恢复伤害率高于恢复成功率，恢复就从"救命"变成"净损失"，故必须以 **conformal 覆盖 + OOD 监控 + 净收益开关 `Δ_rec`** 三重护栏，宁可安全停机/人接管，也绝不把"检测器看起来对"当作"失败一定能被救"的前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（CDB×DGF×RDR×RAP×RCC×SFC×FRX）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性双证书之上，增加 **检测驱动失败恢复** 层，解决"失败是否被看见、能不能救、救了是否更糟"：
> - **CDB（Conformal Detection Belief）**：把单点检测升级为带覆盖保证的集合 `B(o)`；
> - **DGF（Detection-Grounded Failure Gate）**：失败签名 `φ` + 前置条件全称检查的恢复门控；
> - **RDR（Recovery Diagnosis & Response）**：失败类诊断到恢复模式的映射；
> - **RAP（Recovery Action Profile）**：恢复策略的动作剖面与恢复包络 `E_R`；
> - **RCC（Recovery Commit Certificate）**：恢复的 liveness + non-regression + 成功率下界证书；
> - **SFC（Silent-Failure Certificate）**：静默失败上界与恢复净收益开关。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-120 JTC → FRX 以纳入恢复迁移。

```python
    return ('ok', RecoveryCert(F, R, beta, rec_lo, h_rec, Inv))
```

```python
def recovery_switch(p_f, p_silent_ub, rec_lo, h_rec, margin=0.0):
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| CDB | O(N_calib + D log D) | O(|B|) | conformal 覆盖 ≥1-ε（可交换） |
| DGF | O(|B|·|pre| + |A|) | O(|B|) | 前置条件全称 sound，门控不漏物体类失败 |
| RDR | O(|F|·|φ| + |A|) | O(|F|) | 失败类可辨识、诊断可复现 |
| RAP | O(|A|) | O(|A|) | 包络非空、冲突阈值 sound |
| RCC | O(n_trials·β) | O(|A|) | liveness + non-regression + `rec_lo>h_rec` |
| SFC | O(1) | O(1) | 静默失败上界 sound、开关符号正确 |
| FRX | O(|F|·n_eval) | O(|F|) | 域覆盖与逐类恢复率下界 |

**正确性定理（Detection-Grounded Recovery Soundness）**
假设第 54 轮 (A22)–(A28) 成立；新增 **(A29)** 检测信念集在目标分布覆盖 `≥1-ε-p_shift`，未建模失败类质量 `p_unmodeled`；**(A30)** `C_R` sound 且 `rec_lo>h_rec`；**(A31)** 门控延迟 `≤τ_g`。则：
```
P_success ≥ 1 - p_f(1-rec_lo) - p_silent_ub - (p_f-p_silent_ub)·h_rec - β_E - P(δ_a>Θ_a)
p_silent_ub = p_f·(ε + p_shift + p_unmodeled)
Δ_rec = (p_f - p_silent_ub)·(rec_lo - h_rec)
```
**恢复有益当且仅当 `Δ_rec>0`**；否则触发安全停机/人接管。门控漏检的三条来源（`ε, p_shift, p_unmodeled`）分别对应三种护栏，缺一不可。

## 5. 本轮最大风险

**一句话**：失败恢复层的 soundness 完全依赖"失败可见性"，而目标检测的自信错检与域漂移会让静默失败绕过门控；一旦 `p_silent` 超过可挽回质量或恢复伤害率高于恢复成功率，恢复就从"救命"变成"净损失"，故必须以 **conformal 覆盖 + OOD 监控 + 净收益开关 `Δ_rec`** 三重护栏，宁可安全停机/人接管，也绝不把"检测器看起来对"当作"失败一定能被救"的前提。
