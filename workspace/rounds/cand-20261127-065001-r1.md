### 第 2 轮灵感驱动研究记录

**灵感词**：人机交互、机械臂抓取

**直觉与动机**：
前序 SRC-USC v25 已把「结构-力控-轻量-语义-重构-协同」七证串联成群体级准入门，但它默认了两件事：(a) 决策权威完全属于机器；(b) 末端与世界的接触被抽象为「无源力控证书」的黑箱。人机交互（HRI）与机械臂抓取恰好击穿这两个默认：HRI 的核心是**在人类意图不可观测时如何分配控制权威**，抓取的核心是**在物体位姿/摩擦不可精确已知时如何保证接触稳定**。二者共享同一数学结构——**对一个「不可直接观测的对手」做 conformal 不确定性量化，并在其可信集上要求安全不变性**：HRI 的对手是人类意图 h，抓取的对手是接触/物体状态 ξ。由此提出核心洞见：**抓取是人机共享权威下的「意图条件化接触」；安全滤波器是最小干预的权威仲裁器**。因此把「权威预算」作为一等公民引入证书链：机器不能既要求人类保留最终否决权，又在人类否决落入危险时把责任推给人类——权威必须与可证安全集共同分配，且权威的让渡量可被证书度量。

**形式化目标**：
1. 定义人类意图-权威证书（HIAC）：conformal 意图集 C_α(o_{1:t}) 满足 ℙ(h*∈C_α)≥1-α；权威混合 u=(1-α_t)u_r+α_t u_h 经 CBF 安全滤波投影 u*=Proj_K(u)；权威保真度 ‖u*-u‖≤δ_auth；信任校准 |τ_t-r_t|≤ε_trust。
2. 定义抓取稳定证书（GSC）：抓取映射 G(ξ,C) 与摩擦锥 FC(μ)；鲁棒 ε-力封闭 margin ε_robust=min_{ξ∈Δ}ε_fc(G(ξ),C)≥ε_min；滑移 margin ρ_i=1-‖f_t‖/(μ_i f_n)≥ρ_min；接触力/压力上限。
3. 定义人本安全证书（HASC）：ISO/TS 15066 保护性分离距离 S_p(t)=S_h+S_r+S_s+C+Z_d+Z_r；人类占据 conformal 管 ℙ(x_h(t)∈H_t)≥1-β；∀x_h∈H_t: dist(R_t,x_h)≥S_p(t)；不可避接触时 PFL 力/压上限。
4. 构建人-抓-安统一准入门（HGI-USC v26）：SRC-USC ∪ HIAC ∪ GSC ∪ HASC = 十证一体，Exec_v26 ⊆ Exec_v25。
5. 证明「意图歧义 / 抓取滑移 / 人类逼近」三重退化路径下单调退化链的保持性，并给出权威-安全-可用性三者张力的可证边界。

```python
# ============================================================
# IP-448 Human Intent & Authority Certificate (HIAC) — 人机交互证书
# ============================================================
@dataclass
class HumanIntentAuthorityCertificate:
    """conformal 意图覆盖 + CBF 权威仲裁 + 信任校准 + 最小干预保真度"""
    intent_model: 'ConformalIntentModel'   # 输出意图可信集 C_alpha
    cbf: 'ControlBarrierFunction'          # 安全滤波器（最小范数投影）
    safe_set: 'InvariantSet' = None        # K：来自 USMC 的控制不变集
    alpha: float = 0.05                    # 意图覆盖风险
    alpha_auth_min: float = 0.0            # 人类权威下限（可全自主）
    alpha_auth_max: float = 0.6            # 机器自主上限（协作标准约束）
    delta_auth: float = 0.02               # 权威保真度容差
    eps_trust: float = 0.10                # 信任校准容差

    def verify_intent_coverage(self, obs_hist: Tensor, human_label: int) -> bool:
        """ℙ(h* ∈ C_α(o_{1:t})) ≥ 1-α"""
        C = self.intent_model.predict_set(obs_hist, self.alpha)
        return human_label in C

    def compute_authority(self, uncertainty: float, trust: float,
                          risk: float) -> float:
        """α_t = clamp(sigmoid(w·[uncertainty, trust, risk]), min, max)
        不确定性↑ ⇒ 倾向人类；风险↑ ⇒ 倾向安全停止（α 不直接升到 1）"""
        z = self.intent_model.authority_logit(uncertainty, trust, risk)
        a = 1.0 / (1.0 + math.exp(-z))
        return float(min(max(a, self.alpha_auth_min), self.alpha_auth_max))

    def verify_authority_fidelity(self, u_robot: Tensor, u_human: Tensor,
                                  state: Tensor, alpha_t: float
                                  ) -> tuple[bool, Tensor]:
        """u_blend=(1-α)u_r+α u_h；u*=Proj_K(u_blend)；‖u*-u_blend‖≤δ_auth"""
        u_blend = (1.0 - alpha_t) * u_robot + alpha_t * u_human
        u_safe = self.cbf.min_norm_project(u_blend, state, self.safe_set)
        return torch.norm(u_safe - u_blend).item() <= self.delta_auth, u_safe

    def verify_trust_calibration(self, trust_est: float, reliability: float) -> bool:
        """避免过信/欠信：|τ_t - r_t| ≤ ε_trust"""
        return abs(trust_est - reliability) <= self.eps_trust

    def verify_safety_override(self, intent_set: list[int], state: Tensor) -> bool:
        """若可信集中存在使 CBF 不变性失败的人类意图，安全滤波必须可接管
        并进入最小风险状态（MRS），而非把危险执行归责于人类。"""
        for h in intent_set:
            u_h = self.intent_model.control_for(h, state)
            if not self.cbf.invariant_safe(state, u_h):
                if not self.cbf.can_reach_mrs(state):
                    return False
        return True

    def verify_all(self, obs_hist, human_label, trust_est, reliability,
                   u_robot, u_human, state) -> tuple[bool, dict]:
        coverage_ok = self.verify_intent_coverage(obs_hist, human_label)
        trust_ok = self.verify_trust_calibration(trust_est, reliability)
        C = self.intent_model.predict_set(obs_hist, self.alpha)
        override_ok = self.verify_safety_override(C, state)
        unc = self.intent_model.uncertainty(obs_hist)
        alpha_t = self.compute_authority(unc, trust_est, self.cbf.risk(state))
        fidelity_ok, u_safe = self.verify_authority_fidelity(
            u_robot, u_human, state, alpha_t)
        return (coverage_ok and trust_ok and override_ok and fidelity_ok), {
            'coverage_ok': coverage_ok, 'trust_ok': trust_ok,
            'override_ok': override_ok, 'fidelity_ok': fidelity_ok,
            'alpha_t': alpha_t, 'u_safe': u_safe,
        }


# ============================================================
# IP-449 Grasp Stability Certificate (GSC) — 抓取稳定证书
# ============================================================
@dataclass
class GraspStabilityCertificate:
    """鲁棒 ε-力封闭 + 逐接触滑移 margin + 接触力/压上限"""
    grasp_map: 'GraspMap'                 # G(ξ,C)
    contacts: list['Contact']             # (p_i, n_i)
    mu: Tensor                            # 每接触摩擦系数 [n_c]
    pose_uncertainty: 'PoseUncertainty'   # Δ：3σ 椭球/采样
    eps_min: float = 0.05                 # Ferrari-Canny margin 下界
    rho_min: float = 0.20                 # 滑移 margin 下界
    F_max: float = 50.0                   # 单接触法向力上限 (N)
    p_max: float = 100.0                  # 接触压强上限 (kPa)

    def friction_cone_polytope(self) -> Tensor:
        """FC(μ) 的线性化多面体（n_facet 面）"""
        return self.grasp_map.linearize_cone(self.mu)

    def epsilon_metric(self, G: Tensor, FC: Tensor) -> float:
        """Ferrari-Canny ε：max ε s.t. ∀单位旋量 w, ∃f∈FC, Gf=-ε w
        等价于求解一组线性规划，取最坏方向的最小支撑距离。"""
        return self.grasp_map.ferrari_canny_lp(G, FC)

    def verify_robust_force_closure(self) -> bool:
        """ε_robust = min_{ξ∈Δ} ε_fc(G(ξ),C) ≥ ε_min"""
        for xi in self.pose_uncertainty.worst_case_samples(self.grasp_map):
            G = self.grasp_map.at(xi)
            if self.epsilon_metric(G, self.friction_cone_polytope()) < self.eps_min:
                return False
        return True

    def verify_slip_margin(self, contact_forces: Tensor) -> bool:
        """ρ_i = 1 - ‖f_t‖/(μ_i f_n) ≥ ρ_min（接触坐标系，f_z 为法向）"""
        for i, f in enumerate(contact_forces):
            fn = torch.clamp(f[2], min=1e-6)
            ft = torch.norm(f[:2])
            rho = 1.0 - ft / (self.mu[i] * fn)
            if rho.item() < self.rho_min:
                return False
        return True

    def verify_contact_limits(self, contact_forces: Tensor,
                              contact_areas: Tensor) -> bool:
        for i, f in enumerate(contact_forces):
            if torch.norm(f).item() > self.F_max:
                return False
            pressure = torch.norm(f).item() / max(contact_areas[i].item(), 1e-6)
            if pressure > self.p_max:
                return False
        return True

    def verify_all(self, contact_forces: Tensor,
                   contact_areas: Tensor) -> tuple[bool, dict]:
        fc_ok = self.verify_robust_force_closure()
        slip_ok = self.verify_slip_margin(contact_forces)
        limit_ok = self.verify_contact_limits(contact_forces, contact_areas)
        return (fc_ok and slip_ok and limit_ok), {
            'force_closure_ok': fc_ok, 'slip_ok': slip_ok,
            'contact_limit_ok': limit_ok,
            'eps_robust': self.grasp_map.min_epsilon_over(self.pose_uncertainty),
        }


# ============================================================
# IP-450 Human-Aware Safety Certificate (HASC) — 人本安全证书
# ============================================================
@dataclass
class HumanAwareSafetyCertificate:
    """ISO/TS 15066 SSM 分离距离 + conformal 人类占据管 + PFL 上限"""
    human_predictor: 'ConformalHumanPredictor'
    beta: float = 0.01
    t_reaction: float = 0.30          # S_h：人类反应时间
    t_stop: float = 0.20              # S_r：机器人停止时间
    a_max: float = 5.0                # 最大减速度
    C: float = 0.02                   # 传感器/控制系统不确定性
    Z_d: float = 0.01                 # 侵入距离
    Z_r: float = 0.01                 # 机器人位置不确定性
    force_limits: 'BodyRegionForceLimit' = None

    def protective_separation(self, v_h: float, v_r: float) -> float:
        """S_p = S_h + S_r + S_s + C + Z_d + Z_r（ISO/TS 15066 4.5）"""
        S_h = self.t_reaction * v_h
        S_r = v_r * self.t_stop
        S_s = (v_r ** 2) / (2.0 * self.a_max)
        return S_h + S_r + S_s + self.C + self.Z_d + self.Z_r

    def verify_ssm(self, robot_traj: Tensor,
                   human_mean: Tensor) -> bool:
        """∀t, ∀x_h∈H_t: dist(R_t, x_h) ≥ S_p(t)"""
        for t in range(len(robot_traj)):
            H_t = self.human_predictor.conformal_tube(t, self.beta)
            v_r = torch.norm(robot_traj[t, 3:6]).item()
            R_t = robot_traj[t, :3]
            for x_h in H_t:
                v_h = self.human_predictor.velocity_at(t, x_h)
                S_p = self.protective_separation(v_h, v_r)
                if torch.norm(R_t - x_h).item() < S_p:
                    return False
        return True

    def verify_pfl(self, contact_force: float, contact_pressure: float,
                   body_region: str) -> bool:
        """不可避接触时：F ≤ F_lim(b) ∧ p ≤ p_lim(b)"""
        F_lim, p_lim = self.force_limits(body_region)
        return contact_force <= F_lim and contact_pressure <= p_lim

    def verify_all(self, robot_traj: Tensor, human_mean: Tensor,
                   contact_force: float = 0.0, contact_pressure: float = 0.0,
                   body_region: str = 'hand') -> tuple[bool, dict]:
        ssm_ok = self.verify_ssm(robot_traj, human_mean)
        pfl_ok = (contact_force <= 0.0 or
                  self.verify_pfl(contact_force, contact_pressure, body_region))
        return (ssm_ok and pfl_ok), {
            'ssm_ok': ssm_ok, 'pfl_ok': pfl_ok,
            'human_tube_coverage': 1.0 - self.beta,
        }

# IP-451 HGI-USC 人-抓-安统一准入门 v26
# ============================================================
@dataclass
class HumanGraspInteractiveUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'
    hiac: HumanIntentAuthorityCertificate
    gsc: GraspStabilityCertificate
    hasc: HumanAwareSafetyCertificate

    def admits(self, plan: 'HumanGraspPlan', sensor_data: dict) -> tuple[bool, dict]:
        # 1. v25 七证（单机 USMC + 语义 + 重构 + 协同）
        if not self.src_usc.admits(plan.multi_plan, sensor_data)[0]:
            return False, {'stage': 'src_usc'}

        # 2. 人类意图-权威证书
        hiac_ok, hiac_info = self.hiac.verify_all(
            sensor_data['obs_hist'], sensor_data['human_label'],
            sensor_data['trust_est'], sensor_data['reliability'],
            plan.u_robot, sensor_data['u_human'], sensor_data['state'])
        if not hiac_ok:
            return False, {'stage': 'hiac', **hiac_info}

        # 3. 抓取稳定证书（仅抓取阶段）
        if plan.is_grasping:
            gsc_ok, gsc_info = self.gsc.verify_all(
                plan.contact_forces, plan.contact_areas)
            if not gsc_ok:
                return False, {'stage': 'gsc', **gsc_info}

        # 4. 人本安全证书（全程）
        hasc_ok, hasc_info = self.hasc.verify_all(
            plan.robot_traj, sensor_data['human_mean'],
            plan.contact_force, plan.contact_pressure,
            sensor_data.get('body_region', 'hand'))
        if not hasc_ok:
            return False, {'stage': 'hasc', **hasc_info}

        return True, {'hiac': hiac_info, 'hasc': hasc_info,
                      'u_safe': hiac_info['u_safe']}
```

## 3. 正确性论证（增量）

### 引理 13（人类意图-权威证书的覆盖-保真-校准三重保证）
**陈述**：`HIAC.verify_all(...) = True` ⟹ 同时满足：
(1) 意图覆盖：ℙ(h*∈C_α(o_{1:t}))≥1-α，
(2) 权威保真：‖Proj_K(u_blend)-u_blend‖≤δ_auth，且投影后状态仍满足 CBF 不变性，
(3) 信任校准：|τ_t-r_t|≤ε_trust，且危险意图存在时可进入 MRS。

**证明**：
1. 由 split-conformal 的边际覆盖定理，C_α 以 ≥1-α 概率包含真实意图；α 由离线校准集的经验分位数确定。
2. `min_norm_project` 求 min‖u-u_blend‖ s.t. CBF 约束，故投影是最小干预的；若存在可行解，CBF 条件成立即状态保持在 K 内。权威保真度直接度量「安全滤波改写人类/机器混合指令的幅度」。
3. 信任校准约束排除过信（τ≫r，人类误以为机器可靠而放松监督）与欠信（τ≪r，人类过度接管降低效率）；`verify_safety_override` 保证危险意图下存在到 MRS 的可行路径，因此责任由安全滤波承担而非转嫁人类。
∎

### 引理 14（抓取稳定证书的力封闭-滑移-接触三重保证）
**陈述**：`GSC.verify_all(...) = True` ⟹ 对任意 ξ∈Δ 存在接触力分布 f∈FC(μ) 使物体平衡，且每接触 ρ_i≥ρ_min、接触力/压不超限。

**证明**：
1. Ferrari-Canny ε 度量定义为 max{ε: ∀单位旋量 w, ∃f∈FC, Gf=-εw}；ε_robust=min_{ξ∈Δ}ε_fc≥ε_min>0 蕴含 0 位于接触旋量凸包内部，即对 Δ 内所有位姿鲁棒力封闭。
2. 滑移 margin ρ_i≥ρ_min>0 等价于 ‖f_t‖≤(1-ρ_min)μ_i f_n < μ_i f_n，即严格位于摩擦锥内部，留出 (1-ρ_min) 的相对安全余量。
3. 接触力/压上限与 FCC 的无源性证书串联：FCC 保证执行器输出无源，GSC 保证该输出落在物体可承受的接触集内，二者缺一不可。
∎

### 引理 15（人本安全证书的分离-预测-限力三重保证）
**陈述**：`HASC.verify_all(...) = True` ⟹ 全程满足 ISO/TS 15066 SSM，且不可避接触满足 PFL。

**证明**：
1. `protective_separation` 逐项对应标准：S_h=t_reaction·v_h（人类接近）、S_r=v_r·t_stop（机器人反应）、S_s=v_r²/(2a_max)（停止距离）、C（传感器不确定）、Z_d（侵入）、Z_r（位置不确定）。距离≥S_p 即 SSM 合规。

3. 当间距无法保持（不可避接触）时，PFL 以身体部位相关的 F_lim/p_lim 约束接触，将风险从「碰撞」降级为「受控接触」。
∎
