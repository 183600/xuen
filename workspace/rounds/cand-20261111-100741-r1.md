# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim++；灵感循环第 6 轮；本轮灵感：「用户体验」×「多传感器融合」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S` 与云边动作-鲁棒性联合证书 `J`。本轮转向一个此前被当作“后处理”的问题：**用户体验（UX）**，并用 **多传感器融合** 作为统一建模语言。核心观察：机器人在内部对异构传感器做融合，人类在外部对机器人的行为通道（运动、语音、解释、时序）做融合；二者共享同一类失效——**相关/共模误差造成高置信度的“共识幻觉”**。核心矛盾：H22：内部多传感器融合一致，不代表外部用户感知一致（robust but incomprehensible）；H23：UX 预算（时延、抖动、认知负荷、可恢复性）不是事后美化，而是反向约束感知融合深度与动作/解释调度的第一性约束。

## 0. 直觉与动机

**灵感 1（双环融合：内感知融合 ↔ 外行为融合）**
直觉：多传感器融合解决“机器怎么看世界”，用户体验则是“人怎么看机器”。把机器人输出视为一组 **行为通道** `U={运动, 语音, 解释, 时序}`，用户对这组通道做一次“人类侧融合”，得到对意图、置信与安全的感知。于是系统存在两个融合环：内环 `fusion_sensor: X^M → S`，外环 `fusion_user: U^k → 用户心智状态`。两个环的失效同构：冗余通道在**共模扰动**下同时出错，仍给出高一致度，形成“共识幻觉”——传感器侧表现为“大家都说没障碍”，用户侧表现为“机器人语气自信、动作却犹豫/相反”。这把“鲁棒”与“好用”从两个工程模块，提升为**同一个融合一致性问题的两个尺度**。

**灵感 2（UX 契约 → 把体验变成可编译的预算约束）**
直觉：UX 不该是“跑完再调”，而应类似实时调度中的 **可调度性契约** `B_ux=(τ_resp, σ_jitter, κ_legib, ε_recover)`，分别约束响应时延、抖动、解释可读性、失败可恢复性。融合越深越准但越慢；解释越多越透明但认知负荷越高。UX 契约把“融合深度—解释频率—动作激进程度”纳入同一个可行域，系统在预算内优化，而不是用平均满意度做不可证伪的调参。

**灵感 3（共模感知的可证融合 → 从“证据投票”到“相关性证明”）**
直觉：标准贝叶斯/投票融合隐含“传感器条件独立”，而真实机器人最常见的失败恰是共模失效（同光照、同遮挡、同网络分区、同标定漂移）。因此融合证书必须显式携带 **共模相关上界 `Σ_cm`** 与 **冗余度**：`F_cert=(M, ρ_fuse, Σ_cm, D, fallback)`。当可证明的相关性上界使融合置信不再可信时，系统必须**降级到单传感器或主动感知**，而不是继续加权平均。

**灵感 4（分歧即解释 → 多模态不一致是 UX 的可用信号）**
直觉：多传感器分歧通常被当作噪声丢弃，但它恰恰是“系统为什么犹豫”的根因证据。把分歧 `D_set` 映射为 **用户可读解释** `E_cert=(D_set, root_cause, legible_text, confidence)`，让用户在机器人不确定时获得“可校准的信任”，而不是面对一个黑箱的自信或沉默。解释的目标不是让人相信系统，而是让人**正确校准**对系统的信任。

**灵感 5（UX-融合-鲁棒性的联合金字塔）**
直觉：在第 54 轮动作层 `𝔸` 之上再加 **交互层 `𝕌`**：`𝕌0` 物理/传感极限，`𝕌1` 单传感器证据，`𝕌2` 可证融合，`𝕌3` 动作与行为通道，`𝕌4` 用户感知与信任。跨层证书同时携带 `ρ`、`A_cert`、`F_cert`、`ρ_ux`、`E_cert`，形成 **“动作-鲁棒-感知-体验”四元证书**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（UX 契约）**
用户体验契约 `B_ux = (τ_resp, σ_jitter, κ_legib, ε_recover)`：`τ_resp` 为端到端响应时延上界，`σ_jitter` 为时延抖动上界，`κ_legib` 为解释可读性下界（见定义 126），`ε_recover` 为失败后恢复成功率下界。交互合法性谓词：
```
UX_ok(π) ⇔ P95(τ(π)) ≤ τ_resp
          ∧ Var[τ(π)] ≤ σ_jitter²
          ∧ κ_legib(E_π) ≥ κ_min
          ∧ P(recover | fail) ≥ ε_recover
```
注意：UX_ok 是**硬约束**，不是加权项；任何融合/动作策略在 `¬UX_ok` 时即判不可部署。

**定义 122（行为通道空间与行为剖面）**
行为通道空间 `U = {u_m, u_s, u_e, u_t}`（运动 motion、语音 speech、解释 explanation、时序 timing）。策略 `π` 的行为剖面 `β_π : U → Δ(Φ_u)`，把每个通道映射到该通道的可观测符号分布。用户侧融合算子 `Ψ_u` 产出用户对意图的估计 `Î = Ψ_u(β_π)`。**行为一致性**定义为
```
cons(π) = 1 - D_JS( Ψ_u(β_π) , Ψ_u(β_{π_ref}) )
```
其中 `π_ref` 为同一意图的参考渲染，`D_JS` 为 Jensen–Shannon 散度；`cons(π) ≥ θ_ch` 表示用户看到的“运动/语音/解释/时序”讲同一个故事。

**定义 123（传感器证据剖面与共模相关）**
传感器集合 `M`，每个传感器 `m` 的证据映射 `e_m : X → [0,1]`、可靠性 `r_m`、故障率 `f_m`。**共模相关矩阵** `Σ_cm ∈ [0,1]^{|M|×|M|}`，`Σ_cm[i,j]` 为传感器 `i,j` 在扰动分布 `P_ε` 下同时失效的相关系数上界（对角为 1）。单传感器证据剖面 `EP_m = (e_m, r_m, f_m, Σ_cm[·,m])`。

**定义 124（可证多传感器融合）**
融合算子 `⊕_cert` 及其证书
```
F_cert = (M, ρ_fuse, Σ_cm, D, fallback)
```
- `ρ_fuse` 为融合后在各任务维度上的鲁棒性谱（承接第 53 轮 ρ）；
- `Σ_cm` 为可证明的共模相关上界；
- `D = max_{i,j} |e_i(x)-e_j(x)|` 为当前观测上的模态分歧；
- `fallback` 为当 `D > θ_d` 或 `Σ_cm` 使独立性假设失效时启用的降级策略（单传感器 / 主动探测 / 停机）。
**融合可信条件**：`F_cert` 有效当且仅当在任意至多 `k_cm` 个 `Σ_cm`-相关传感器同时失效时，融合置信下界
```
conf_fuse ≥ 1 - (1/(1-‖Σ_cm‖_2)) · Π_m (1 - r_m·(1-f_m))
```
仍不低于 `θ_conf`；否则必须触发 `fallback`，禁止“投票掩盖共模失效”。

**定义 125（交互鲁棒性谱）**
在 ρ 的维度集 `𝔇_ρ` 上增加交互维度 `𝔇_ux = {τ_resp, σ_jitter, κ_legib, ε_recover}`，得到用户侧鲁棒性谱 `ρ_ux`。联合谱 `ρ^+ = ρ ⊗ ρ_ux`，维度为 `𝔇_ρ ∪ 𝔇_ux`，并定义
```
ρ^+_min = min_{d ∈ 𝔇_ρ ∪ 𝔇_ux} ρ^+(d)
```
只有 `ρ^+_min ≥ ρ_min` 且 `UX_ok(π)` 同时成立，系统才算“既鲁棒又好用”。

**定义 126（分歧解释证书与可读性）**
对一次融合分歧 `D_set = {(i,j,δ_ij)}`，解释证书
```
E_cert = (D_set, root_cause, legible_text, conf_text, trust_calib)
```
`root_cause` 为归因（遮挡 / 标定漂移 / 网络 / 语义歧义），`legible_text` 为面向用户的自然语言解释，`conf_text` 为解释的置信。**可读性** `κ_legib` 由三项构成：
```
κ_legib = α·COMP + β·(1-HALL) + γ·CAL
```
`COMP` 为用户理解率（受控用户研究），`HALL` 为解释幻觉率（解释内容与实际根因不符比例），`CAL` 为信任校准度（用户置信与系统真实可靠性的对齐）。解释的**目标**是最大化 `CAL`，而非最大化用户满意度。

**定义 127（UX-融合联合证书，作为证书复合算子）**
```
J_ux = (F_cert, ρ^+, A_cert, E_cert, B_ux, evidence)
```
可部署谓词：
```
deploy(J_ux) ⇔ F_cert.valid ∧ ρ^+_min ≥ ρ_min
              ∧ UX_ok(π) ∧ cons(π) ≥ θ_ch
              ∧ A_cert.δ_a ≤ Θ_a
```
`evidence` 至少含：共模注入实验记录、用户理解率与信任校准数据、端到端时延分布、以及第 54 轮云边规划日志。

## 2. 关键算法 伪代码

### IP-121 UXC（UX Contract Compiler）

```python
def compile_ux_contract(profile, task):
    B = UXBudget(
        tau_resp = task.deadline_p95,
        sigma_jitter = task.jitter_bound,
        kappa_legib = task.readability_min,
        eps_recover = task.recover_min,
    )
    # 将 UX 预算编译为对融合深度/解释频率的上界
    B.max_fusion_depth = invert_latency_budget(B.tau_resp, profile.fusion_cost)
    B.max_explain_rate = invert_cognitive_budget(B.kappa_legib, profile.explain_cost)
    return B

def ux_ok(trace, B):
    return (p95(trace.tau) <= B.tau_resp
            and var(trace.tau) <= B.sigma_jitter**2
            and kappa_legib(trace.explain) >= B.kappa_legib
            and recover_rate(trace) >= B.eps_recover)
```

### IP-122 SEP（Sensor Evidence Profiling）

```python
def profile_sensors(M, dataset, perturb):
    profiles, cm = {}, zeros((len(M), len(M)))
    for m in M:
        e = calibrate_evidence(m, dataset)          # 保形/等渗校准
        r = reliability(m, dataset)
        f = failure_rate(m, perturb)
        profiles[m] = EP(m, e, r, f)
    # 对抗式共模注入：同时扰动相关传感器组
    for group in correlated_groups(M, perturb):
        fail = inject_common_mode(group, perturb)
        for i in group:
            for j in group:
                cm[i,j] = max(cm[i,j], empirical_corr(fail, i, j))
    return profiles, cm
```

### IP-123 CMF（Certified Multi-sensor Fusion）

```python
def certified_fusion(obs, profiles, Sigma_cm, theta_conf, theta_d, k_cm):
    D = max_pairwise_disagreement(obs, profiles)     # 模态分歧
    conf = independence_bound(profiles, Sigma_cm, k_cm)
    if D > theta_d or conf < theta_conf:
        mode = choose_fallback(obs, profiles, Sigma_cm)   # 单传感器/主动探测/停机
        return FusionResult(mode, conf=conf, D=D, cert=F_cert(profiles, conf, Sigma_cm, D, mode))
    estimate = weighted_fuse(obs, profiles, Sigma_cm)     # 共模白化后再融合
    return FusionResult(estimate, conf=conf, D=D,
                        cert=F_cert(profiles, conf, Sigma_cm, D, fallback=None))
```

### IP-124 UXS（UX-constrained Fusion Scheduling）

```python
def schedule_fusion(task, profiles, B, Sigma_cm):
    # 在 UX 预算内做受限优化：max 感知精度 s.t. UX_ok
    frontier = pareto_frontier(configs=all_fusion_configs(profiles),
                               objectives=[neg_accuracy, latency, energy])
    for cfg in sorted(frontier, key=lambda c: -c.accuracy):
        trace = simulate_trace(cfg, task)
        if ux_ok(trace, B) and certified_fusion_valid(cfg, Sigma_cm):
            return cfg, trace
    return conservative_config(profiles), simulate_trace(conservative_config(profiles), task)
```

### IP-125 BCC（Behavior-Channel Consistency + Disagreement Explanation）

```python
def behavior_consistency(pi, pi_ref, user_model):
    beta  = render_channels(pi)      # motion/speech/explanation/timing
    beta0 = render_channels(pi_ref)
    cons  = 1 - js_divergence(user_model.fuse(beta), user_model.fuse(beta0))
    return cons

def explain_disagreement(fusion_res, sim_model, user_model):
    if fusion_res.D <= theta_d:
        return None
    D_set = trace_disagreement(fusion_res)
    cause = attribute_root_cause(D_set, sim_model)   # 遮挡/标定/网络/语义
    text  = render_explanation(cause, user_model)    # 面向用户的措辞
    e = E_cert(D_set, cause, text, conf_text=cause_conf(cause), trust_calib=None)
    e.trust_calib = calibrate_trust(e, user_model)   # 在线校准项
    return e
```

### IP-126 UJC（UX-Fusion Joint Certificate）

```python
def ux_joint_certificate(pi, fusion_res, A_cert, B, user_model, rho_min, theta_ch):
    rho_plus = merge_spectra(compose_robustness_chain(pi.skills),
                             interaction_spectrum(pi, B))
    e_cert = explain_disagreement(fusion_res, pi.sim_model, user_model)
    cons = behavior_consistency(pi, pi.reference, user_model)
    checks = {
        'fusion_valid': fusion_res.cert.valid,
        'robust':       min(rho_plus.values()) >= rho_min,
        'ux_ok':        ux_ok(pi.trace, B),
        'consistent':   cons >= theta_ch,
        'action_ok':    A_cert.delta_a <= A_cert.theta_a,
    }
    if not all(checks.values()):
        return ('reject', checks, e_cert)
    return ('ok', J_ux(fusion_res.cert, rho_plus, A_cert, e_cert, B, evidence=collect()))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| UXC | O(|task|·|profile|) | O(1) | 预算可逆、硬约束一致 |
| SEP | O(|M|²·|P_ε|) | O(|M|²) | 共模注入覆盖、相关上界 sound |
| CMF | O(|M|·|X| + |M|³) | O(|M|²) | 独立性界 sound、fallback 确定 |
| UXS | O(|C|·|T|) | O(|C|) | Pareto 前沿完备、预算保守 |
| BCC | O(|U|·|Φ|) | O(|U|) | 通道渲染可复现、用户模型代表 |
| UJC | O(|S|·|A| + |M|²) | O(|A|+|M|²) | 复合证书 sound、证据可审计 |

**正确性定理（UX-Fusion Joint Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `e_m` 在 `P_ε` 上保形校准，共模上界 `Σ_cm` 为真上界；**(A30)** 行为通道渲染 `β_π` 对同一策略可复现，用户模型 `Ψ_u` 代表目标人群；**(A31)** 解释归因 `root_cause` 的幻觉率上界为 `HALL_max`；**(A32)** 融合调度在 `UX_ok` 可行域内可终止。
则联合部署成功（既任务成功又被用户正确校准）概率满足
```
P_joint ≥ 1 - Σ_d (1-ρ_min(d)) - P(common-mode > Σ_cm) - β_E
          - P(cons < θ_ch) - P(UX_ok violated) - HALL_max
```
关键：**内环融合的可靠性由共模上界担保，外环体验的一致性由行为通道证书担保，两者不能互相替代**。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 共模相关上界被低估 | 高 | 对抗式共模注入 + 相关上界置信区间 + 保守 k_cm |
| UX 指标被 Goodhart 化 | 高 | 理解率/校准/幻觉三指标交叉 + 反指标（解释冗余度） |
| 用户模型不具代表性 | 高 | 分层用户研究 + 在线校准 + 冷启动保守策略 |
| 融合调度在预算边界震荡 | 中 | hysteresis + 最小驻留时间 + 回滚锚点 |
| 解释时延反过来破坏 UX | 中 | 解释预算编译 + 预生成模板 + 异步补解释 |
| 行为通道语义不一致（说左做右） | 高 | 通道共享本体 + 渲染前一致性检查 + 硬否决 |

## 6. 本轮最大风险

**一句话**：本轮把“鲁棒”与“好用”统一为内外双环融合，并用共模相关上界与 UX 契约给出可证边界；但整个 soundness 依赖 **共模相关上界 `Σ_cm` 的真实性、用户模型 `Ψ_u` 的代表性、以及解释归因的低幻觉率**——一旦共模相关被低估，内部会出现“传感器共识幻觉”，一旦用户模型失真或解释被优化成“讨好式话术”，外部会出现“体验共识幻觉”，两种幻觉都不触发任何单环告警，故必须以 **对抗式共模注入 + 三指标信任校准 + 解释幻觉硬上限** 三重护栏，宁可降级到单传感器与沉默，也不拿“高置信共识”冒充可靠性。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（UXC×SEP×CMF×UXS×BCC×UJC）

> 承接第 54 轮产物 v31。本轮在第 54 轮“动作-鲁棒性双证书”之上，引入 **用户体验** 与 **多传感器融合** 的统一算子：
> - **UXC（UX Contract Compiler）**：把响应时延/抖动/可读性/可恢复性编译为硬预算；
> - **SEP（Sensor Evidence Profiling）**：传感器证据剖面 + 对抗式共模相关上界 `Σ_cm`；
> - **CMF（Certified Multi-sensor Fusion）**：共模感知的可证融合与确定性降级；
> - **UXS（UX-constrained Fusion Scheduling）**：UX 预算内的融合深度/频率受限优化；
> - **BCC（Behavior-Channel Consistency）**：内外双环一致性 + 分歧→可读解释；
> - **UJC（UX-Fusion Joint Certificate）**：动作-鲁棒-感知-体验四元联合证书。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118/120 以纳入 UX 与共模维度。

```python
def compile_ux_contract(profile, task):
    B = UXBudget(
        tau_resp     = task.deadline_p95,
        sigma_jitter = task.jitter_bound,
        kappa_legib  = task.readability_min,
        eps_recover  = task.recover_min,
    )
    B.max_fusion_depth  = invert_latency_budget(B.tau_resp, profile.fusion_cost)
    B.max_explain_rate  = invert_cognitive_budget(B.kappa_legib, profile.explain_cost)
    return B

def ux_ok(trace, B):
    return (p95(trace.tau) <= B.tau_resp
            and var(trace.tau) <= B.sigma_jitter**2
            and kappa_legib(trace.explain) >= B.kappa_legib
            and recover_rate(trace) >= B.eps_recover)
```

### IP-122 SEP

```python
def profile_sensors(M, dataset, perturb):
    profiles, cm = {}, zeros((len(M), len(M)))
    for m in M:
        e = calibrate_evidence(m, dataset)       # 保形/等渗校准
        r = reliability(m, dataset)
        f = failure_rate(m, perturb)
        profiles[m] = EP(m, e, r, f)
    for group in correlated_groups(M, perturb):  # 对抗式共模注入
        fail = inject_common_mode(group, perturb)
        for i in group:
            for j in group:
                cm[i, j] = max(cm[i, j], empirical_corr(fail, i, j))
    # 用 Hoeffding/Bootstrap 给 Σ_cm 加上置信上界，取保守值
    return profiles, upper_confidence_bound(cm, alpha=0.05)
```

### IP-123 CMF

```python
def certified_fusion(obs, profiles, Sigma_cm, theta_conf, theta_d, k_cm):
    D    = max_pairwise_disagreement(obs, profiles)
    conf = independence_bound(profiles, Sigma_cm, k_cm)
    if D > theta_d or conf < theta_conf:
        mode = choose_fallback(obs, profiles, Sigma_cm)   # 单传感器/主动探测/停机
        return FusionResult(mode, conf=conf, D=D,
                            cert=F_cert(profiles, conf, Sigma_cm, D, fallback=mode))
    estimate = weighted_fuse(obs, profiles, Sigma_cm)     # 共模白化后融合
    return FusionResult(estimate, conf=conf, D=D,
                        cert=F_cert(profiles, conf, Sigma_cm, D, fallback=None))

def independence_bound(profiles, Sigma_cm, k_cm):
    # 在“至多 k_cm 个 Σ_cm-相关传感器同时失效”的最坏情形下的融合置信下界
    rho = spectral_norm(Sigma_cm)
    base = prod(1 - profiles[m].r * (1 - profiles[m].f) for m in profiles)
    worst = 1 - (1 / (1 - rho)) * base
    return min(base, worst)
```

```python
def behavior_consistency(pi, pi_ref, user_model):

def explain_disagreement(fusion_res, sim_model, user_model, theta_d):
```

### IP-126 UJC

```python
def ux_joint_certificate(pi, fusion_res, A_cert, B, user_model, rho_min, theta_ch):
    rho_plus = merge_spectra(compose_robustness_chain(pi.skills),
                             interaction_spectrum(pi, B))
    e_cert   = explain_disagreement(fusion_res, pi.sim_model, user_model, theta_d)
    cons     = behavior_consistency(pi, pi.reference, user_model)
    checks = {
        'fusion_valid': fusion_res.cert.valid,
        'robust':       min(rho_plus.values()) >= rho_min,
        'ux_ok':        ux_ok(pi.trace, B),
        'consistent':   cons >= theta_ch,
        'action_ok':    A_cert.delta_a <= A_cert.theta_a,
    }
    if not all(checks.values()):
        return ('reject', checks, e_cert)
    return ('ok', J_ux(fusion_res.cert, rho_plus, A_cert, e_cert, B, evidence=collect()))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| UXC | O(|task|·|profile|) | O(1) | 预算可逆，硬约束一致 |
| SEP | O(|M|²·|P_ε|) | O(|M|²) | 共模注入覆盖，`Σ_cm` sound |
| CMF | O(|M|·|X|+|M|³) | O(|M|²) | 独立性界 sound，fallback 确定 |
| UXS | O(|C|·|T|) | O(|C|) | Pareto 前沿完备，预算保守 |
| BCC | O(|U|·|Φ|) | O(|U|) | 渲染可复现，用户模型代表 |
| UJC | O(|S|·|A|+|M|²) | O(|A|+|M|²) | 复合证书 sound，证据可审计 |

**正确性定理（UX-Fusion Joint Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `e_m` 在扰动分布 `P_ε` 上保形校准，`Σ_cm` 为真上界；**(A30)** 行为通道渲染 `β_π` 可复现，用户模型 `Ψ_u` 代表目标人群；**(A31)** 解释归因幻觉率 ≤ `HALL_max`；**(A32)** 融合调度在 `UX_ok` 可行域内可终止。
则联合部署（任务成功且用户信任被正确校准）概率：
```
P_joint ≥ 1 - Σ_d (1-ρ_min(d)) - P(common-mode > Σ_cm) - β_E
          - P(cons < θ_ch) - P(UX_ok violated) - HALL_max
```

**证明思路（骨架）**
1. 由 (A29)，CMF 的独立性下界在至多 `k_cm` 个共模相关失效下仍成立；`conf_fuse < θ_conf` 时 fallback 保证不产生假共识，故内环误差不超过 `P(common-mode > Σ_cm)`。
2. 由 (A30)，`cons(π)` 是用户侧融合结果与参考渲染的 JS 距离，`cons ≥ θ_ch` 时外部意图估计的误判概率被 `1-cons` 上界控制，即 `P(cons < θ_ch)`。
3. 由 UXC 把体验预算变为硬约束，`UX_ok` 违反事件被显式计入；由 (A31)，解释幻觉贡献不超过 `HALL_max`。
4. 第 54 轮动作-鲁棒性项 `Σ_d(1-ρ_min(d))+β_E` 由证书复合保持，且 `A_cert` 在 UJC 中作为独立合取项。四项并集界给出一式。

**关键**：**内环可靠性由 `Σ_cm` 担保，外环一致性由 `cons(π)` 担保，二者不可互相替代**；这正是“robust but incomprehensible”的形式化来源。

## 6. 本轮最大风险

**一句话**：本轮把“鲁棒”与“好用”统一为内外双环融合，并用共模相关上界与 UX 契约给出可证边界；但整个 soundness 依赖 **共模相关上界 `Σ_cm` 的真实性、用户模型 `Ψ_u` 的代表性、以及解释归因的低幻觉率**——一旦共模相关被低估，内部会出现“传感器共识幻觉”，一旦用户模型失真或解释被优化成“讨好式话术”，外部会出现“体验共识幻觉”，两种幻觉都不触发任何单环告警，故必须以 **对抗式共模注入 + 三指标信任校准 + 解释幻觉硬上限** 三重护栏，宁可降级到单传感器与沉默，也不拿“高置信共识”冒充可靠性。
