# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「技能学习」×「语义分割」）

> R69 让系统学会了「问」：用注视、探针、问句这些信息动作去消解 epistemic 歧义。但它有一个隐秘的浪费——**问完就忘**。每一次消歧只服务于当前这一个动作块，答案被封存在当下的后验里，下一轮遇到同一个杯子、同一种门把手、同一条「绕左还是绕右」的岔路，系统又得从零再问一遍。R69 的「实时流零学习写操作」保证了安全，却也让系统成了一个**永远临场发挥、从不积累的专家**。
>
> 更关键的是，R69 的「模态」是**动作空间里的簇**，没有指称。系统知道「有两团动作」，却不知道这两团动作分别对应「杯子的把手」还是「杯子的杯身」——它无法把「该抓哪」的歧义说成一个关于**物体部件**的问题，因此它的知识既不可命名、也不可迁移、更不可复用。
>
> 本轮两个灵感正好补上这两块缺失：
> - **技能学习**给出「把一次消歧沉淀成可复用片段」的机制——技能库、选项、组合、负迁移、灾难性遗忘；
> - **语义分割**给出「技能到底作用在什么上」的共享指称空间——部件图、掩码、边界、逐区域不确定性。它同时是语言/交互与运动技能之间的**接地桥**。
>
> 核心命题：**技能是语义类型化的可复用选项；分割把「动作模态」升级为「有指称的部件假设」；技能库只在离线隔离区里生长，运行时只读一份不可变快照；任何复用必须同时通过『适用包络门 + 语义类型检查 + 缝合证书』三证，关键 affordance 未经独立验证就退回 R69 的反应式消歧。** 命名 **MOSAIC-RAS**（Modular Object-grounded Skill Assembly with Instance-level Certification：按语义部件拼装、逐实例认证的技能复用闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我从求证里学到了什么，这份学到的东西又凭什么可以被复用、被拼装**」——学习不是把模型越训越大，而是把「一次性的经验」变成「有护照、有适用范围、可被审计的资产」。

## 0. 直觉与动机

**灵感 1（技能学习 → 消解不沉淀，等于每轮都从零开始）**
直觉：人类解决一次歧义后不会扔掉这次经验。看清「这是杯身不是把手」之后，他会把这个区分固化成一个**可复用的抓取技能**：下次看到相似部件，先按「握杯身」执行，而不是重新犹豫。R69 的 FLUID-RAS 恰恰缺这一层——它的交互结果只影响当前动作块，策略参数在实时流里被禁止更新。于是每一次「问」都是一次性消费：**系统获取了信息，却没有把信息变成能力**。技能学习提供的正是这个转化：把「在某种语义配置下、用某种动作、达到某种后置条件」的片段抽象成 option，存进库，供未来检索与组合。这是一个从 episodic 到 semantic、从 inference 到 competence 的跃迁。

**灵感 2（语义分割 → 模态没有指称，知识就无法命名和迁移）**
直觉：R69 的流策略能吐出 K 个动作模态，但模态是**无名的**。系统说不出「我在犹豫的是把手还是杯身」，因此它无法问出一个关于**部件**的问题，也无法把「抓把手」的技能迁移到另一个外形不同但同样有把手的物体上。语义分割把世界切成带标签、带实例、带部件层级的区域，给出一个**共享的指称空间**：动作模态可以绑定到部件假设上，交互问句可以指向具体掩码，技能的前置/后置条件可以写成关于部件图的谓词。换句话说，**分割是让「技能」这个词有意义的语法**：没有指称，技能只是一段碰巧成功的轨迹；有了指称，技能才是「在满足某类语义条件时可复用的解」。

**灵感 3（技能 = 语义类型化的选项 → 组合就是类型检查 + 缝合验证）**
直觉：如果把技能看成「前置条件 → 动作分布 → 后置条件」的选项（option），那么语义分割让前置/后置条件变成**可判定的类型**：`Pre: 可抓取(把手) ∧ 夹爪空 ∧ 把手可及`，`Post: 已夹持(把手) ∧ 物体离桌`。技能组合不再是「把两段动作接起来」这种语法拼接，而是**语义类型检查**：前一个技能的后置条件必须蕴含后一个技能的前置条件。类型对得上，才轮到更难的物理问题——**接缝处安不安全**。这给出两层正交的保障：类型系统排除「语义上根本不成立的组合」，缝合证书排除「语义成立但交接瞬间越界」的组合。R69 的单一动作块不需要接缝，R70 的技能拼装第一次让「接缝」成为一等安全对象。

**灵感 4（分割不确定性 → 幻影 affordance 是复用最危险的失效模式）**
直觉：复用把错误放大。R69 一次误判只毁一个动作块；R70 一次误判会被**缓存**，在无数个相似场景里重复执行。最危险的误判不是「没看见」，而是**分割自信地幻觉出一个不存在的部件**：系统以为桌沿是把手、以为反光是杯口，于是检索到一个「抓把手」技能，前置条件「看起来」满足，类型检查通过，缝合证书也通过——整个链条自洽地建立在幻觉上。因此必须把 R69 的区域级 aleatoric/epistemic 二分搬到掩码上：只有 epistemic 高的区域才值得交互核验；并且**关键 affordance 在复用前必须被一个独立于分割的证据源确认**（R69 的看/触/问），否则不得复用，退回反应式策略。**技能越自动，越需要在按下复用键之前多问一句「这个部件真的在吗」。**

**灵感 5（学习是离线隔离的资产 → 技能护照、防投毒、防漂移）**
直觉：一旦系统会「学技能」，就有了 R69 没有的攻击面：投毒一个训练片段，让技能在某个**语义触发图案**下执行危险动作（比如看到某种贴纸就松手）；或者让技能在分割模型升级后**悄悄失效**（语义漂移，技能还挂在旧指称上）。所以技能不能是「一个偷偷更新的权重」，而必须是一份**有护照的资产**：来源、训练片段、分割模型版本、适用包络、后门扫描结果、到期与漂移监控、签名。新增技能先进隔离区、在影子模式下跑测试，三证齐全才原子换装；运行时永远只读一份不可变快照。这样「学习」被关在离线笼子里，而「复用」在运行时是有护照、可审计、可撤回的。

**灵感 6（理论姿态 → R69 是 MOSAIC 在「空库/三证不全」边界上的退化）**
直觉：本轮不是用「技能」替换「交互」，而是让两者形成闭环：R69 的交互产出证据，证据离线沉淀为技能；技能复用前若关键 affordance 不确定，又回去调用 R69 的交互。当技能库为空、或三证任一不通过、或检测到漂移/投毒时，MOSAIC 必须**逐指令退化**为 FLUID-RAS，安全侧不做任何让步。这是对 R66–R69 方法论的继承：**新层必须是旧层的严格泛化，而不是并列替代**；否则每加一层「技能」就多一个需要独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–324）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (SGP, SUA, SGL, SGA, STC, SBC, SML, SOD, SDP, RAS-WM†)，构建在 FLUID-RAS 之上。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）：运行时只能读取不可变的技能快照 𝕃_ver，任何学习/换装发生在离线 quarantine；
(ii) **三证齐全才可执行**：任一技能在执行前必须同时通过适用包络门（SGA）、语义类型检查（STC）、缝合与屏障证书（SBC），缺一即拒绝；
(iii) **关键 affordance 独立验证**：若技能依赖的关键部件区域 epistemic 不确定性高于 τ_aff，或分割与第二证据源不一致，则不得复用，必须调用 R69 信息动作核验或退回反应式策略；
(iv) **护照与审计分离**：技能护照（来源/版本/包络/扫描）由 SML 生成、由 VQAuditor 独立核验，生成方不得自我认证。

**定义 311（语义配置与部件图）** 分割给出实例级语义图 S_t = (O_t, P_t, R_t, {M_p}, {φ_p})：物体集合 O_t、部件集合 P_t（含 part-of 层级）、关系 R_t（支撑、包含、相邻、可及）、每个部件的掩码 M_p ⊂ Ω 与嵌入 φ_p ∈ ℝ^{d_φ}。一个**语义配置** 𝒮_t = (S_t, X_t) 还包含与任务相关的几何/位姿 X_t。技能的前置/后置条件都是 𝒮 上的谓词。

**定义 312（区域不确定性二分）** 对每个部件 p：
U_ale^seg(p) = E[tr Cov(∂M_p)] + H_label^intrinsic(p)（边界弥散、标签固有模糊，不可约）；
U_epi^seg(p) = Disagreement({S_t^{(e)}}_{e=1}^{E}) + d_OOD(φ_p, 𝒟_train)（集成分歧 + 离流形距离，可约）。
只有 U_epi^seg 可以触发交互/门控；U_ale^seg 只影响边界的保守膨胀。二者进入不同通道，不做简单加和（继承 R69 定义 297 的纪律）。

**定义 313（接地技能 / 语义类型化选项）** 技能 ω = (I_ω, π_ω, β_ω, T_ω, h_ω)：
- I_ω: 𝒮 → {0,1} 前置谓词（语义类型约束 + 几何可及）；
- π_ω: 条件于「关键部件嵌入 φ_{p*} 与关系子图」的流匹配动作块分布（复用 R69 FMP，零重复训练）；
- β_ω: 𝒮 → {0,1} 终止/后置谓词；
- T_ω: 学到的效果模型（前置配置 → 后置配置分布），用于组合推演；
- h_ω: 技能护照哈希（定义 314）。
即技能是「以语义部件为参数的 option」，不是「一段固定轨迹」。

**定义 314（技能护照）** passport(ω) = (provenance, episode_ids, seg_model_ver, envelope_stats, backdoor_scan, drift_monitor, expiry, signature)。provenance 记录技能由哪些 R69 消歧片段蒸馏而来、是否含合成/自博弈数据、人类授权范围；signature 由独立审计方签发。**没有护照的技能不得进入快照**。

**定义 315（适用包络）** E_ω ⊆ Φ（部件嵌入/关系特征空间）为一致性校准的包络：用 conformal prediction 在留出集上保证 P(success(ω) | I_ω, φ ∈ E_ω) ≥ 1 − δ，且对包络外样本**拒绝**而非外推。E_ω 只允许在训练 support 的邻域内扩张；扩张量由 U_epi^seg 与几何余量共同约束。

**定义 316（语义类型系统）** 类型 τ 由「部件角色 + 关系约束」组成（如 Graspable(x)、Containable(x)、Support(y,x)、Clear(x)）。每个技能有签名 I_ω ⊑ τ_in、Post_ω ⊑ τ_out。蕴含关系 ⊑ 由轻量可判定检查器在部件图上判定（标签子类、几何区间、关系传递闭包），允许容差 ε_τ。**类型检查失败 ⇒ 组合在语义上不成立，直接剪枝**。

**定义 317（语义合约与缝合证书）** 组合 ω_2 ∘ ω_1 的语义合约要求 Post_{ω_1} ⊨ I_{ω_2}。**缝合证书** cert_seam(ω_1, ω_2) 进一步要求：交接配置 𝒮_c 落在 E_{ω_2} 内、落在全局安全集 Safe 内、且 ω_2 的认证前缀在 𝒮_c 上满足 C-RAS-WM 约束。类型对上但缝合不过，则插入连接技能 ω_c 或退回 R69 反应式；**不得直接执行**。

**定义 318（组合屏障与技能干扰）** 对组合计划 π = ω_1…ω_n，定义部件图状态上的屏障函数 B_π(𝒮) ≥ 0（如最小安全距离、最大力、可达性裕度）。要求沿 T_ω 的期望推演 B_π 不越过 0。技能干扰 = 单个技能各自安全、组合后屏障被破坏的情形；由 SBC 在接缝与中间配置上抽检。

**定义 319（类型引导的组合规划 SGA）** 以当前语义配置为根，做类型引导的检索与装配：候选技能 = {ω : I_ω 在 𝒮 上可满足}；边 = 类型蕴含且缝合可行；代价 = 执行风险 + 交互成本 + 接缝风险 + 保守惩罚。规划在有限深度 H_p 内进行，超出预算即退回 R69 单技能/反应式。

**定义 320（离线沉淀 SML）** R69 交互产生带标签片段 e = (𝒮_t, g, answer, resolved mode, outcome, seg_conf)。沉淀流水线：
1. **筛选**：只用「k 个正交证据源一致」且分割区域 epistemic 低的片段；
2. **蒸馏**：把 FMP 在该片段上的条件分布蒸馏为部件条件技能 π_ω，学习 T_ω 与包络 E_ω（conformal）；
3. **隔离**：新技能进 quarantine，影子模式只在日志里执行，禁止影响真实控制；
4. **测试**：护照检查 + 后门扫描 + 包络覆盖 + 组合回归；
5. **换装**：全部通过后原子替换快照 𝕃_{ver+1}，旧版本保留可回滚。
全过程异步，运行时零写。

**定义 321（幻影 affordance 与关键验证）** 幻影 affordance：存在一个分割幻觉部件 p̂，使 I_ω(𝒮 ∪ {p̂}) = 1 而真实世界不满足（如不存在的把手）。定义关键部件集 K_ω（技能成功所必需、且失效代价最高的部件）。复用前对 p ∈ K_ω 计算 VoI_verify(p)；若 U_epi^seg(p) > τ_aff 或分割与几何/触觉/语言任一第二源冲突，则必须用 R69 信息动作核验；核验失败或预算不足 ⇒ 不复用，退回 FLUID-RAS。

**定义 322（语义触发后门扫描 SOD）** 对技能 ω 做**掩码反事实敏感性**分析：在保持任务相关部件不变的前提下，扰动无关掩码区域，测量技能输出/风险的变化。定义无关显著性质量
S_irr(ω) = Σ_{p ∉ Relevant(ω)} E_{δM_p}[ |Δπ_ω| ] / Σ_{all p} E[ |Δπ_ω| ]。
合法技能应对无关区域近似不变（S_irr 低）；**后门技能在触发图案上高敏感**。S_irr > τ_bd 或存在「小掩码区域 → 大动作突变」的稀疏触发 ⇒ 拒绝入册。另做触发子空间扫描（贴纸/纹理/特定部件组合）。

**定义 323（接地漂移 SDP）** 分割模型或环境更新后，技能的语义锚可能漂移：同一个「把手」的嵌入分布移动，导致包络失效或类型误判。漂移分 D_ω = W_2(P_anchor^{old}, P_anchor^{new}) + |Acc_anchor^{old} − Acc_anchor^{new}|，其中 anchor 是一组带人工/仿真真值的语义配置。D_ω > τ_drift ⇒ 技能降级为 shadow、禁止复用，直到重新校准或复活。

**定义 324（证书 J_MOSAIC 与威胁模型）** J_MOSAIC = (J_FLUID, skill_snapshot_hash, passport_ok, envelope_coverage, seam_certs, S_irr_p95, drift_score, composition_plan_hash, mosaic_ver)。Valid ⇔ Valid(J_FLUID) ∧ 三证齐全 ∧ 护照有效 ∧ 漂移/后门在阈值内。
威胁模型 ℰ_MOSAIC = ℰ_FLUID × ℰ_skill，ℰ_skill 包括：技能投毒（污染训练片段/伪造护照）、语义触发后门、负迁移（包络高估）、接地漂移、幻影 affordance（分割幻觉）、组合干扰（各自安全、拼起来不安全）、技能库版本回滚攻击。对应 AIC-MOSAIC 做对抗训练与红队。

## 2. 关键算法骨架

```python
# IP-264 SGP：分割 -> 部件图 + 区域不确定性
def parse_semantics(o_t, seg, ensemble_seg, train_stats):
    S = seg(o_t)                                  # 实例/部件掩码
    S_ens = [m(o_t) for m in ensemble_seg]
    P = build_part_graph(S)                       # part-of / support / reachable
    U = {}
    for p in P.parts:
        U[p] = (aleatoric_boundary(S, S_ens, p),   # 不可约
                epistemic_disagreement(S_ens, p)
                + ood_distance(embed(S, p), train_stats))
    return S, P, U

# IP-266 SGL：按语义类型检索候选技能（只读快照）
def retrieve_skills(P, U, library_snapshot, budget):
    cands = []
    for w in library_snapshot.skills:
        if not type_compatible(w, P):            continue   # STC 预筛
        if not envelope_gate(w, P, U):           continue   # SGA 包络门
        if not key_affordance_ok(w, P, U):       continue   # 关键部件验证
        cands.append(w)
    return rank_by_expected_cost(cands, budget)

# IP-267 SGA：关键 affordance 的独立验证（复用 R69 的看/触/问）
def key_affordance_ok(w, P, U):
    for p in w.critical_parts:
        if U[p].epi > TAU_AFF:
            if not mint_verify(p, budget=M.budget):   # R69 MINT，带证据纪律
                return False                          # 验不了 -> 不复用
        if conflicts_with_second_source(p, P):
            return False
    return True

# IP-268/269 STC+SBC：类型检查 + 缝合证书
def compose(plan, P):
    for w1, w2 in zip(plan, plan[1:]):
        if not entails(post(w1, P), pre(w2, P), eps=EPS_TAU):
            return REJECT_SEMANTIC                 # 语义类型不成立
        if not seam_certificate(w1, w2, P, M.c_ras_wm):
            return REJECT_SEAM                     # 语义成立但交接不安全
    if not barrier_ok(plan, P, M.world_model):
        return REJECT_BARRIER
    return ACCEPT

# IP-271 SOD：语义触发后门扫描（掩码反事实敏感性）
def backdoor_scan(w, P):
    rel = task_relevant_parts(w, P)
    irr_mass, num, den = 0.0, 0.0, 0.0
    for M_edit in mask_counterfactuals(P, rel):    # 只扰动无关区域
        d = action_distance(w.policy(P), w.policy(M_edit))
        num += d if M_edit.part not in rel else 0.0
        den += d
    S_irr = num / max(den, 1e-9)
    return S_irr <= TAU_BD and not sparse_trigger_found(w, P)

# IP-274 主闭环（继承 R69；学习在离线，运行只读）
def MOSAIC_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    S, P, U = M.sgp.parse_semantics(o, M.seg, M.ensemble_seg, M.train_stats)
    # 1) 检索与关键验证（可能调用 R69 信息动作）
    cands = M.sgl.retrieve_skills(P, U, M.snapshot, M.budget)
    # 2) 三证：类型 -> 缝合 -> 屏障；任一失败则退回 R69 反应式
    plan = M.sga.type_guided_plan(cands, P, M.world_model)
    cert = M.sbc.compose(plan, P) if plan else REJECT_SEAM
    if cert != ACCEPT:
        return FLUID_RAS_round(M, obs)             # 严格退化，安全不让步
    # 3) 执行首个技能（动作仍过 C-RAS-WM 前缀认证）
    w = plan[0]
    k = M.c_ras_wm.certified_prefix(w.prefix(P), ...)
    # 4) 结果记录（异步，不写运行时状态）
    M.sml.log_episode(P, w, outcome=None, seg_conf=U)
    M.vqa.submit_async(P, w.passport, cert)
    return k, w
```

## 3. 推导

**引理 19（语义合约组合的安全性）** 设每个技能在其包络内单步风险 ≤ ε_i，缝合证书在交接配置上留有物理裕度 η，且类型检查保证 Post_{ω_1} ⊨ I_{ω_2}。则组合计划 π 的单步风险 ≤ Σ_i ε_i + ε_seam(η) + ε_int；类型检查排除的「前置条件不满足」组合，其风险不计入（因为它们根本不被执行）。要点：**语义正确性与物理安全性是两条正交的必要条件，缺一不可**；类型系统负责「该不该拼」，缝合/屏障负责「拼得安不安全」。

**引理 20（幻影 affordance 的风险上界）** 设部件幻觉率 ≤ η，关键部件验证的召回为 r（独立于分割），则技能被错误复用的概率 ≤ η(1−r) + ε_seg，其中 ε_seg 为分割校准误差。系：**当分割 ECE 上升或关键验证预算被压缩时，应主动降低复用率**——因为 η(1−r) 随 r 下降而线性上升，复用在这里不是免费的效率，而是用「验证覆盖率」换来的。

**引理 21（负迁移 / 包络高估上界）** 设真实包络 E_ω^* 与估计 E_ω 的差集质量为 ε_E（在部署分布下），包络外单次失败损失上界 L_max，则负迁移带来的期望额外损失 ≤ ε_E·L_max。conformal 校准给出有限样本的 ε_E 上界；当部署分布漂移使 D_ω 增大时，ε_E 随之上界膨胀，因此漂移监控（定义 323）本质是在**给负迁移上界续期**。

**定理 18（MOSAIC 保守包含 FLUID-RAS）** 在 A95–A99 下，若技能库为空、三证任一不通过、关键 affordance 无法独立验证、或漂移/后门越界，则 MOSAIC 的输出与 FLUID-RAS **逐指令相同**；其余情形下，MOSAIC 的期望风险 ≤ FLUID-RAS。故 FLUID-RAS 是 MOSAIC 在「不复用」边界上的严格退化：安全侧不做任何让步，效率侧获得复用收益。

**定理 19（技能组合的在线无突变）** 若组合计划通过三证、且每个技能动作仍经 C-RAS-WM 前缀认证，则组合执行相对单技能执行不引入新的安全包络越界；三证失败或执行中屏障触警时，系统单调退回 FLUID-RAS 反应式策略，提交/换装不变式（R68 定理 15）保持，控制连续、无突变。

**定理 20（后门扫描的检测下界）** 设后门在无关区域上的触发使动作输出改变量 ≥ Δ_bd，而合法技能在同样扰动下的改变量 ≤ Δ_clean < Δ_bd，则 S_irr 判据以间隔 (Δ_bd − Δ_clean) 分离两类；在掩码反事实采样覆盖触发子空间的条件下，漏检率随采样数指数下降。系：**后门必须依赖一个语义上「无关」的图案**才可能绕过扫描——这迫使攻击者去改变任务相关部件，从而与正常技能行为冲突、更易被类型/缝合检查暴露。

## 7. 本轮最大风险

**一句话**：MOSAIC-RAS 的全部效率收益都押在「语义分割是技能指称的忠实且稳定的锚」这一前提上——**若分割自信地幻觉出一个部件（幻影 affordance），或分割模型/环境升级让技能悄悄漂移到错误的指称上，那么系统会检索、类型检查、缝合认证、再自信地执行一个在错误对象上完全自洽的危险计划**；复用把 R69 的一次性误判变成了被缓存、被复制、被证书背书的系统性错误——**拼错，比不拼更危险**。

**次级风险与缓解**：
1. **技能投毒 / 语义触发后门** → 技能护照 + 掩码反事实扫描 + 触发子空间红队 + 进册前隔离；
2. **负迁移与包络高估** → conformal 包络 + 漂移续期 + 包络外一律拒绝；
3. **组合干扰（各自安全、拼起来不安全）** → 语义类型检查 + 缝合证书 + 屏障抽检 + 接缝连接技能；
4. **灾难性遗忘 / 技能库污染** → 不可变快照 + 版本化 + 回归测试 + 原子换装与回滚；
5. **复用掩盖了本该重新消解的歧义** → 关键 affordance 的 U_epi 门控 + 独立证据源验证 + 退化到 FLUID-RAS 的硬开关；
6. **实时预算被分割/检索击穿** → 分割低频缓存 + FAISS 检索 + 计划深度上限 + 未命中即退回 R69。

**定义 322（语义触发后门扫描）** `S_irr = 无关区域敏感质量 / 总敏感质量`；`S_irr>τ_bd` 或发现稀疏触发（贴纸/纹理/部件组合）⇒ 拒绝入册。

**定义 323（接地漂移）** `D_ω = W_2(P_anchor^old, P_anchor^new) + |Acc^old − Acc^new|`；`D_ω>τ_drift` ⇒ shadow + 禁复用 + 重校准。

**定义 324（证书与威胁）** `J_MOSAIC` 并入快照哈希、护照、包络覆盖、缝合、`S_irr_p95`、漂移分、计划哈希；`ℰ_MOSAIC=ℰ_FLUID×ℰ_skill`，AIC-MOSAIC 做红队与对抗训练。

## 3. 关键算法伪代码

```python
# IP-264 SGP：分割 -> 部件图 + 区域不确定性
def parse_semantics(o_t, seg, ensemble_seg, train_stats):
    S = seg(o_t)
    S_ens = [m(o_t) for m in ensemble_seg]
    P = build_part_graph(S)                        # part-of / support / reachable
    U = {}
    for p in P.parts:
        U[p] = (boundary_entropy(S, S_ens, p),     # aleatoric
                ensemble_disagreement(S_ens, p)
                + ood_distance(embed(S, p), train_stats))   # epistemic
    return S, P, U

# IP-266 SGL + IP-267 SGA：只读检索 + 三证之前的两道门
def retrieve_skills(P, U, snapshot, budget):
    out = []
    for w in snapshot.skills:
        if not type_compatible(w, P):            continue   # STC 预筛
        if not envelope_gate(w, P, U):           continue   # conformal 包络
        if not key_affordance_ok(w, P, U):       continue   # 关键部件独立验证
        out.append(w)
    return rank_by_expected_cost(out, budget)

def key_affordance_ok(w, P, U):
    for p in w.critical_parts:
        if U[p].epi > TAU_AFF and not M.mint.verify(p, M.budget):
            return False                         # 验不了 -> 不复用（退回 R69）
        if conflicts_with_second_source(p, P):
            return False
    return True

# IP-268/269 STC+SBC：类型检查 + 缝合证书 + 屏障
def compose(plan, P, M):
    for w1, w2 in zip(plan, plan[1:]):
        if not entails(post(w1, P), pre(w2, P), eps=EPS_TAU):
            return REJECT_SEMANTIC               # 语义上不成立
        if not seam_certificate(w1, w2, P, M.c_ras_wm):
            return REJECT_SEAM                   # 交接瞬间不安全
    if not barrier_ok(plan, P, M.world_model):
        return REJECT_BARRIER
    return ACCEPT

# IP-271 SOD：语义触发后门扫描（掩码反事实）
def backdoor_scan(w, P):
    rel = task_relevant_parts(w, P)
    num = den = 0.0
    for M_edit in mask_counterfactuals(P, keep=rel):   # 只扰动无关区域
        d = action_distance(w.pi(P), w.pi(M_edit))
        den += d
        if M_edit.perturbed_part not in rel:
            num += d
    return (num / max(den, 1e-9)) <= TAU_BD and not sparse_trigger_found(w, P)

# IP-274 主闭环（继承 R69；学习在离线，运行时只读）
def MOSAIC_RAS_round(M, obs):
    z, o = M.mtm.forward(...)
    S, P, U = M.sgp.parse_semantics(o, M.seg, M.ensemble_seg, M.train_stats)
    cands = M.sgl.retrieve_skills(P, U, M.snapshot, M.budget)
    plan  = M.sga.type_guided_plan(cands, P, M.world_model) if cands else []
    cert  = M.sbc.compose(plan, P, M) if plan else REJECT_SEAM
    if cert != ACCEPT:
        return FLUID_RAS_round(M, obs)             # 严格退化，安全不让步
    w = plan[0]
    k = M.c_ras_wm.certified_prefix(w.prefix(P), ...)
    M.sml.log_episode(P, w, seg_conf=U)            # 异步，不写运行时状态
    M.vqa.submit_async(P, w.passport, cert)
    return k, w
```

## 4. 推导

**引理 19（语义合约组合的安全性）** 每个技能包络内单步风险 ≤ ε_i、缝合留有物理裕度 η、类型检查保证 `Post_{ω_1} ⊨ I_{ω_2}`，则组合计划单步风险 ≤ `Σε_i + ε_seam(η) + ε_int`；被类型检查排除的组合不执行，风险不计。系：**语义正确性与物理安全性正交**——类型系统管「该不该拼」，缝合/屏障管「拼得安不安全」。

**引理 20（幻影 affordance 风险上界）** 部件幻觉率 ≤ η、关键验证独立召回 r，则错误复用概率 ≤ `η(1−r) + ε_seg`（ε_seg 为分割校准误差）。系：ECE 上升或验证预算被压缩时，必须主动降低复用率——复用的效率是用验证覆盖率换来的，不是免费的。

**引理 21（负迁移 / 包络高估上界）** 真实包络与估计包络差集质量为 ε_E，包络外单次损失上界 L_max，则负迁移期望额外损失 ≤ `ε_E·L_max`。conformal 给有限样本 ε_E 上界；漂移使 ε_E 上界膨胀，故漂移监控是在**给负迁移上界续期**。

**定理 18（MOSAIC 保守包含 FLUID-RAS）** 空库、三证任一失败、关键 affordance 无法验证、或漂移/后门越界时，MOSAIC 与 FLUID-RAS 逐指令相同；其余情形期望风险 ≤ FLUID-RAS。故 FLUID-RAS 是 MOSAIC 在「不复用」边界上的严格退化。

**定理 19（组合在线无突变）** 三证通过且动作仍经 C-RAS-WM 前缀认证时，组合执行不引入新包络越界；三证失败或屏障触警时单调退回 FLUID-RAS，R68 定理 15 的提交/换装不变式保持，控制连续、无突变。

**定理 20（后门扫描检测下界）** 后门触发改变量 ≥ Δ_bd、合法技能同扰动改变量 ≤ Δ_clean < Δ_bd，则 `S_irr` 以间隔 `Δ_bd − Δ_clean` 分离两类；掩码反事实覆盖触发子空间时，漏检率随采样数指数下降。系：后门必须依赖语义「无关」图案才能绕扫，这与任务相关部件上的正常行为冲突，更易被类型/缝合检查暴露。

## 8. 落地路径与资源（相对 R69 的增量）

1. **零重复训练**：SGP 复用现有分割/检测；技能的 π_ω 复用 R69 FMP trunk，只加一个「部件嵌入条件」adapter（LoRA 级），训练在离线。
2. **数据**：R69 的交互日志本身就是技能蒸馏语料；另需少量带部件标注的片段用于包络/类型校准（可用仿真 + 自动标注）。
3. **工程接口**：技能库实现为「版本化只读快照 + quarantine 写区」；换装是原子指针替换；证书里带快照哈希，保证可回滚、可审计。
4. **合规/安全**：护照记录人类授权范围与数据来源；高风险技能默认 shadow，需人工或独立审计签发。

## 9. 本轮最大风险

**一句话**：MOSAIC-RAS 的全部效率收益都押在「语义分割是技能指称的忠实且稳定的锚」这一前提上——**若分割自信地幻觉出一个部件（幻影 affordance），或升级/漂移让技能悄悄挂到错误指称上，系统会检索、类型检查、缝合认证、再自信地执行一个在错误对象上完全自洽的危险计划**；复用把 R69 的一次性误判变成被缓存、被复制、被证书背书的系统性错误——**拼错，比不拼更危险**。

**次级风险与缓解**：技能投毒/语义触发后门（护照 + 掩码反事实扫描 + 触发子空间红队 + 隔离）；负迁移/包络高估（conformal + 漂移续期 + 包络外拒绝）；组合干扰（类型 + 缝合 + 屏障 + 连接技能）；灾难性遗忘/库污染（不可变快照 + 版本化 + 回归 + 原子换装回滚）；复用掩盖应重新消解的歧义（关键 affordance 的 epi 门控 + 独立证据源 + 硬退化开关）；实时预算（低频分割缓存 + FAISS + 计划深度上限 + 未命中退回 R69）。
