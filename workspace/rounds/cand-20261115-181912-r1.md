# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「SLAM」×「MuJoCo」）

> R69 把不确定性一分为二，并给系统装上了「嘴巴」：aleatoric 收紧，epistemic 去问、去看、去触。但它有一个未被言明的隐含假设——**证据是无记忆、无坐标、无物理的**：观测 `o_t` 被当成一袋特征，标定是逐帧的局部校正，动作似然只问「策略是否自洽」，却从不问「这些观测在同一个世界里是否可能同时成立」。于是 R69 最脆弱处仍在：一个自洽的偏置世界可以让感知、策略、标定三者一起漂移而互相背书；而它的「问」也只能问人，问不到几何与物理。
>
> 本轮两个灵感正好补上两根本体论意义上的锚：
> - **SLAM** 给出**长程几何一致性**：轨迹与地图被联合估计，回环把「逐帧可吸收的小漂移」放大成一条无法被局部标定解释的长杠杆残差。回环不是「建图」，而是**对整段历史的审计**。
> - **MuJoCo** 给出**可证伪的物理预言**：给定质量、摩擦、接触模式等假设，仿真能生成「探针之后应当发生什么」；真实接触一旦越出仿真-现实信任半径，就构成对假设的物理反驳。物理答案不会撒谎，但模型会。
>
> 核心命题：**把 R69 的「观测级歧义」升级为「世界级一致性」——在动作多模态之外，显式维护一个带开关变量的世界一致性图（位姿/地图/物体/物理参数），用回环残差与接触残差两条非社交证据通道，检测并归因「地图漂移、几何别名、物理失配、共享感知偏差」；只有通过锚点独立性审计与仿真-证据防火墙的残差，才允许参与 R69 的证据纪律与风险退避。** 命名 **ANCHOR-RAS**（Active Navigation–Contact Hypothesis Optimization & Reconciliation）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我凭什么相信自己的地图与身体模型**」——真正的保守不是把 λ 压低，而是先把世界钉在两枚彼此独立的锚上。

## 0. 直觉与动机

**灵感 1（SLAM → 长程约束是局部标定的审计员）**
直觉：R69 的标定像一位只检查相邻两帧是否衔接的编辑，任何一步的小误差都能被下一步「解释掉」。SLAM 的本质不是生成一张漂亮地图，而是把位姿与地图放进**同一个联合后验**：一旦绕回原点，回环约束会把整圈累积的误差一次性摆到桌面上。杠杆臂越长，同样的角误差在端点造成的位移越大；局部标定能吸收的每边误差有上界 `δ_cal`，但绕圈 `n` 步后未被模型类覆盖的漂移按 `n^α` 增长，必然在某个 `n*` 之后突破任何固定阈值。**回环是局部标定的天敌**，因为它检验的是「历史整体是否闭合」，而非「这一帧是否合理」。此外，主动 SLAM 把「去哪里」变成信息动作：重访是向世界提问「这里还是那里吗」，其 VoI 与 R69 的「问人」同构，但答案不可被社交操控。

**灵感 2（MuJoCo → 物理是可证伪的预言机）**
直觉：R69 的 FMA 问的是「这个动作在我的策略密度下是否高概率」，但感知与策略共享同一个编码器；只要偏置是**连贯的**，策略就会觉得「在这个错世界里这样做很合理」，似然通道被一起骗过。MuJoCo 提供的是**另一类生成模型**：不是「动作像不像我生成的」，而是「给定物理假设，探针之后世界应当怎样演化」。这两类预言来自不同机制，错误模式也不同。更关键的是，仿真允许**反事实重放与归因**：固定几何、只改物理参数，若残差仍在，则问题在物理；固定物理、只改位姿图，若残差消失，则问题在几何。归因把「出错了」升级为「错在哪一层」，这正是 R69 缺失的。

**灵感 3（两锚 → 统一为带开关的世界一致性图）**
直觉：回环与接触看似两件事，实则是同一张图上的两类边：位姿图边检验「空间是否闭合」，接触边检验「动力学是否闭合」。两者都可以写成残差 `r_e`、信息矩阵 `Ω_e` 与开关变量 `s_e`；也都可能被离群边（错误回环 / 欺骗性接触）拖垮。R69 的「k 个正交证据源一致」在图上就是**可开关约束 + 佐证门**：一条回环边不能被外观单独认证，必须外观、几何内点率、（有接触时）物理一致性同时支持；一条人类回答也不能单独定案。**别名攻击是回环版的投毒，物理欺骗是接触版的投毒**——同一个鲁棒图优化框架同时防它们，这是本轮最省的理论统一。

**灵感 4（包含关系 → R69 是「无图无物理」的退化）**
直觉：若世界一致性图没有长程边（不回环、不建模地图），且物理模型退化为恒等（无接触、仿真-现实间隙无穷大），则 ANCHOR 层完全不激活，逐指令退化为 R69；若再令交互预算为零，则退化为 R68。这个三级链 `R68 ⊆ R69 ⊆ R70` 不是修辞，而是可检验的退化条件：每一级只在**额外证据通过认证**时才获得效率收益，任何认证失败都单调退回上一级。**新层绝不与旧层并列，而是旧层在更强证据下的严格扩展**——否则每加一层就多一个必须独立信任的黑箱。

**灵感 5（双锚也会共谋 → 新威胁模型）**
直觉：最危险的错误不是「一个锚坏了」，而是「两个锚以同样的方式坏」。SLAM 与 MuJoCo 消费同一批传感器、共享同一个学习编码器、甚至共享同一份训练数据偏置；它们的误差可以高度相关。此时「两个独立证据源一致」是幻觉，有效独立源数 `n_eff` 可能只有 1。更糟的是，接触丰富环境里的主动激励本身可能把系统推入不可逆的物理状态。因此本轮必须同时交付：**锚点独立性审计**（把名义 k 折成有效 n_eff）、**仿真-证据防火墙**（仿真只提议、不定案，且必须超过信任半径）、**探索下限**（防止系统只重访熟悉区域而陷入认知惰化）、以及**别名/绑架/物理欺骗/仿真投毒**的联合干扰集。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ANCHOR-RAS 总览）** ANCHOR-RAS = (WCG, LCR, PCR, ASP, AXP, SEF, RCA, RAS-WM‡)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **锚点独立性审计**：任何把多个证据源当作「正交」的决策，必须先报告有效独立源数 `n_eff`；`n_eff < 2` 时不得以「多源一致」定案；
(iii) **仿真-证据防火墙**：MuJoCo 只能产生候选探针、排序假设、剪除物理不可能的动作模态；**仿真输出永远不能单独作为证据**，且仅当假设间可分离度超过 `2ε̂_sim` 时才有判别力；
(iv) **鲁棒可开关一致性**：世界图的长程边必须带开关变量与佐证门；单条回环/单次接触/单个人类回答均不得单独改变全局后验。

**定义 311（世界一致性图 WCG）** 图 `𝒢_W = (𝒦, ℰ)`。节点 `k_i = (T_i ∈ SE(3), o_i ∈ 𝒪, θ_i ∈ Θ)` 表示关键帧的位姿、局部物体状态与局部物理参数。边 `e = (i, j, τ) ∈ ℰ`，`τ ∈ {odom, loop, contact}`，带残差 `r_e(x)`、信息矩阵 `Ω_e`、开关变量 `s_e ∈ [0,1]` 与类型先验。世界能量
`E_W(x, s) = Σ_e s_e r_e(x)ᵀ Ω_e r_e(x) + Σ_e Ψ(s_e)`，
其中 `Ψ(s) = −μ log s + (1−s)²/(2σ_s²)`（开关先验）。后验 `p(x, s | z) ∝ exp(−½ E_W)`。`x` 含轨迹、地图与物理参数。

**定义 312（回环残差 LCR 与几何不确定性）** 对候选回环 `(i, j)`，相对位姿残差 `e_ij = Log(T_i⁻¹ T_j ⊖ T̂_ij)`，归一化回环统计量 `χ²_loop(i,j) = e_ijᵀ Ω_ij e_ij`。几何不确定性取图边缘化后的位姿/地图熵 `U_geo = H(x_map, T | D)`（工程上用拉普拉斯近似的协方差迹或回环 χ² 的尾概率代理）。回环长度 `n_ij` 定义为两关键帧间最短里程边数。

**定义 313（空间标定不可吸收性）** 设局部标定模型类可吸收的每条边系统误差上界为 `δ_cal`；未被该模型类覆盖的累积漂移满足 `‖(I − P_cal) D(n)‖ ≥ c n^α`，`α ∈ [1/2, 1]`（随机游走到偏置漂移）。则长度 `n` 的回环归一化残差满足
`χ_loop(n) ≥ [c n^α − n δ_cal]₊ / σ_loop`。
因此存在 `n* = (c/δ_cal)^{1/(1−α)}`，当 `n > n*` 时任何不扩大标定模型类的吸收策略都无法把回环残差压回阈值内。**局部标定可以骗过相邻帧，骗不过足够长的闭环。**

**定义 314（物理一致性残差 PCR 与物理不确定性）** 物理假设 `θ ∈ Θ`（质量、惯量、摩擦系数、恢复系数、关节柔顺、接触模式）。给定探针动作 `a` 与状态估计 `x`，MuJoCo 前向模型给出 `ŷ = Sim_θ(x, a)`。真实接触观测为 `y`。定义
`e_phys(θ) = (y − ŷ)ᵀ Σ_sim⁻¹ (y − ŷ) + λ_mode·1[接触模式不一致]`，
其中模式不一致包括穿透、摩擦锥违背、冲量符号错误。参数后验用无似然推断（ABC / 集成）近似：`p(θ | y) ∝ p(θ) exp(−½ e_phys(θ))`。物理不确定性 `U_phys = H(θ | y) + H(mode | y)`。

**定义 315（主动空间探询 ASP）** 导航信息动作 `g_nav ∈ 𝒢_nav`（重访目标、路径、观察位姿）。空间信息增益
`VoI_nav(g) = H(x_map, T | D) − E_{loop(g)}[H(x_map, T | D, loop)]`。
选择 `g* = argmax_g [VoI_nav(g) − c_nav(g)]`，受路径长度、时间窗与 C-RAS-WM 认证约束。**探索下限**：在滑动窗口内，至少 `ρ_expl` 比例的动作必须指向未充分建图的区域，防止只靠熟悉区域降低熵而造成认知惰化。

**定义 316（主动激励探询 AXP）** 接触丰富场景下的物理信息动作 `g_exc ∈ 𝒢_exc`（探针方向、力幅、接触时序）。假设集 `H = {h}` 覆盖 `θ` 与接触模式。物理信息增益 `VoI_phys(g) = I(H; y | g, x)`。选择 `g* = argmax_g [VoI_phys(g) − c_exc(g)]`，s.t. 力 ≤ `f_max`、位移 ≤ `ε_exc`、且通过 C-RAS-WM 前缀认证。**仿真只负责提议候选与预筛**，真实执行才产生证据（定义 317）。

**定义 317（仿真-证据防火墙 SEF）** 在线估计仿真-现实间隙 `ε̂_sim`（在同一残差度量下，用已知真值探针或集成离散度校准）。对假设 `h ≠ h'`，可分离度 `Δ_sep(h,h') = E‖y_h − y_h'‖`。仿真证据可用当且仅当
`min_{h≠h'} Δ_sep(h,h') > 2 ε̂_sim`；
否则该探针被判为「无判别力」，既不能确认也不能否定。仿真对动作模态的剪除必须保留 `ε̂_sim` 的保守裕度；仿真与真实冲突时，若冲突在信任半径内，以真实为准并上调 `U_phys`，不得反过来用仿真改写真实观测。

**定义 318（四通道残差归因 RCA）** 证据向量 `c = (r_res, Δa, χ_loop, e_phys)`，其中前三项继承/扩展 R69（传感器残差、动作似然差）与本轮回环残差。归因标签
`ℓ ∈ {真漂移, 标定吸收, 几何别名, 物理失配, 共享感知偏差, 混合}`。
典型签名：真漂移 `(↑, ↑, ↑, →)`；标定吸收 `(↓, ↑, ↑, →)`；几何别名 `(→, ↑, ↑, →)` 且回环开关被拒；物理失配 `(→, →, →, ↑)` 且发生在接触事件；共享感知偏差 `(↑, ↑, ↑, ↑)` 且锚点独立性 `κ` 高。`ℓ̂ = argmax_ℓ P(ℓ | c)`，仅在签名间距离大于噪声时声明可辨识（定理 20）。

**定义 319（锚点独立性审计 AIA）** 设几何锚、物理锚、感知/语义锚的误差变量为 `(E_geo, E_phys, E_sem)`。定义归一化误差耦合
`κ = max_{a≠b} I(E_a; E_b | z) / min(H(E_a), H(E_b))`。
有效独立证据源数 `n_eff = 1 + (k − 1)(1 − κ)`。仅当 `κ ≤ τ_ind` 时允许把名义 `k` 个源当作正交；否则以 `n_eff` 代入证据纪律（R69 定义 293-iii / 引理 18）。**共享同一编码器与同一传感器的两个锚，在 κ→1 时等价于一个锚。**

**定义 320（鲁棒可开关一致性 SwC）** 长程边 `e` 的开关先验 `s_e ~ Beta(a_s, b_s)`；佐证门：回环边被接受需至少两个**有效独立**来源一致（外观匹配、几何内点率、有接触时的物理一致性）；人类回答需与几何/物理通道至少一个独立来源一致。使用 max-mixture / 动态协方差鲁棒核
`ρ(r) = min(r², c̄²)` 或 `p(r) ∝ max(𝒩(0,Ω⁻¹), ε_out)`，使单条错误长程边不能拖拽整张图。**这就是 R69「k-正交一致」在图上的严格推广。**

**定义 321（锚点预算与探索下限 ABEF）** 预算向量 `B = (n_ask, n_revisit, n_excite, L_path, c_social)`，逐项硬约束。探索下限 `ρ_expl > 0` 与重访上限 `ρ_revisit < 1` 同时生效；当预算耗尽或探索比例不足时，未消解的 `U_geo/U_phys` 一律视为不可约，进入保守退避（定义 324）。

**定义 322（证书 J_ANCHOR）** `J_ANCHOR = (J_FLUID, χ²_loop_p95, e_phys_p95, U_geo_before/after, U_phys_before/after, ε̂_sim, ℓ̂, n_eff, κ, exploration_ratio, anchor_ver)`。
`Valid ⇔ Valid(J_FLUID) ∧ SEF 满足 ∧ ABEF 满足 ∧ AIA 已报告 ∧ SwC 收敛`。

**定义 323（锚点干扰集 AIC-ANCHOR）** `ℰ_ANCHOR = ℰ_FLUID × ℰ_alias × ℰ_physspoof × ℰ_simpoison × ℰ_corranchor × ℰ_complacency`：感知别名/绑架、对抗性表面导致的接触模型失配、仿真器/训练数据投毒、锚点相关失效、以及「只重访熟悉区域」的探索惰化。并入 AIC 的统一对抗评估。

**定义 324（三级单调退避）** 令 `λ` 为风险缩放系数，`U_all = U_ale + U_epi + U_geo + U_phys`。三级策略：
- **R70 可信态**：锚点通过 AIA 与 SEF，且残差已归因/消解 ⇒ `λ = λ_floor(U_ale + 残余不可约项)`，获得 anchor bonus；
- **R69 退化态**：世界图不可用、锚点不可信、或 `κ > τ_ind` ⇒ 丢弃长程边与物理边，逐指令等价 R69；
- **R68 退化态**：交互/VoI 不可用或被污染 ⇒ 只收紧，逐指令等价 R68。
不变式：`λ_R70(可信) ≤ λ_R70(不可信) = λ_R69 ≤ λ_R69(不可信) = λ_R68`，且退化条件可离线审计（E311）。

**定义 325（实时因子图调度）** 滑动窗口位姿图 + 边缘化；回环候选由外观/几何粗筛触发，增量优化（iSAM2 类）以低频运行（5–10 Hz）；MuJoCo 重放仅在接触事件、回环冲突或 FMA 异常时触发；常规路径不改变 R69 的 P99 预算。

**定义 326（锚点数据关联与联合认证）** 回环/接触关联变量 `d_e` 与开关变量联合估计；关联必须同时满足语义、几何、（可选）物理三类证据的佐证门。语义相似但几何不闭合 ⇒ 疑似别名；几何闭合但物理残差大 ⇒ 疑似物理失配；三者皆闭合但彼此矛盾 ⇒ 上报共享感知偏差，禁止单独定案。

# IP-264 WCG：增量世界一致性图（位姿 + 物体 + 物理参数 + 开关）
class WorldConsistencyGraph:
    def add_keyframe(self, T, objects, theta, cov):
        self.nodes.append((T, objects, theta, cov))
    def candidate_loops(self, k_i, topk=3):
        return appearance_and_geometry_recall(k_i, self.nodes, topk)
    def optimize(self):                       # iSAM2 式增量；低频
        return robust_switchable_optimize(self.nodes, self.edges)

# IP-265 LCR：长程回环残差（局部标定吸收不掉的那部分）
def loop_closure_residual(wcg, i, j, T_odom):
    e = log_se3(inv(wcg.T[i]) @ wcg.T[j] @ inv(T_odom))
    return float(e.T @ wcg.info_ij @ e), loop_length(i, j)

# IP-266 PCR：MuJoCo 反事实重放 + 参数后验（仿真只算残差，不定案）
def physics_residual(mujoco_model, x, a_probe, y_real, theta_particles):
    ys = [mujoco_model.rollout(x, a_probe, theta) for theta in theta_particles]
    e  = [mahalanobis(y_real, y_hat) + mode_penalty(y_real, y_hat) for y_hat in ys]
    post = softmax(-0.5 * np.asarray(e))
    return float(np.dot(post, e)), entropy(post), post

# IP-269 SEF：仿真-证据防火墙（分离度不足则判无判别力）
def sim_evidence_gate(theta_particles, y_preds, eps_sim):

## 3. 推导

**引理 19（长回环的非吸收性）** 在定义 313 的漂移模型下，若 `α > 0` 且 `c > δ_cal`，则 `χ_loop(n) → ∞`（在归一化意义下）当 `n → ∞`，且检测阈值 `τ_loop` 对应的最小可检测回环长度
`n* ≥ ((τ_loop σ_loop + n* δ_cal)/c)^{1/α}` 存在有限解。系：**回环越长，标定越无法「解释掉」漂移**；这正是 R69 定义 301 的 FMA 在空间侧的镜像，但杠杆臂随路径长度增长，而 FMA 的杠杆臂只有单步。推论：把 LCR 与 FMA 联合，`(χ_loop↑, Δa↑, r_res↓)` 把「标定吸收」与「真漂移」分开（定义 318）。

**引理 20（仿真间隙下的探针可判别性）** 设真实与仿真的输出差异有界 `‖y − ŷ‖ ≤ ε_sim`（以定义 317 的度量），假设 `h, h'` 的预测可分离度为 `Δ_sep(h,h')`。则任何基于仿真的检验在 `Δ_sep ≤ 2 ε_sim` 时，两类错误率之和 ≥ `1 − Δ_sep/(2ε_sim)`；反之若 `Δ_sep > 2ε_sim`，存在阈值检验使两类错误率为 0。故最优探针是在安全约束下最大化 `I(H; y | g)` 且满足分离条件的探针。系：**仿真不能把「不可分辨」变成「已确认」；它只能提议去哪里分辨。**

**引理 21（有效独立性与证据通胀）** 设名义 `k` 个证据源，两两误差条件耦合上界为 `κ`。则联合证据的 Fisher 信息不超过单源信息的 `n_eff = 1 + (k−1)(1−κ)` 倍；当 `κ→1`，`n_eff→1`。因此把 R69 引理 18 的 `k` 直接代入会高估证据、低估投毒上界；正确做法是用 `n_eff`。系：**共享同一感知的几何锚与物理锚，在审计意义上可能只是同一个锚**——这是本轮最重要的自我限制。

**定理 18（三级严格包含）** 在 A95–A99（R69 假设 + 锚点独立性 + 仿真间隙有界）下：
(a) 当世界图无长程边、物理模型退化为恒等（`ε_sim = ∞`）时，ANCHOR 逐指令等价 R69；
(b) 当交互预算为零时，R69 逐指令等价 R68；
(c) 在任意状态，ANCHOR 的期望风险 ≤ R69 ≤ R68，且仅在锚点通过 AIA/SEF/SwC 认证时获得严格更优的效率项；
(d) 任一认证失败时，`λ` 单调不降地退回上一级，控制连续、无突变（继承 R69 定理 17）。
**证明要点**：(a)(b) 由构造与退化条件直接得；(c) 由引理 19–21：新增证据只用于降低后验熵，且 SEF 保证不引入超出 `ε_sim` 的伪证据；(d) 由定义 324 的单调退避与 C-RAS-WM 前缀认证的封闭性。

**定理 19（别名/共谋下的鲁棒认证上界）** 设单条长程边为离群（别名/投毒）的先验概率为 `δ_e`，佐证源间欺骗相关为 `ρ < 1`，有效独立源数为 `n_eff`，关联错误率为 `ε_assoc`。采用定义 320 的开关先验与 max-mixture 鲁棒核后，错误接受一条离群长程边的后验概率
`P(false accept) ≤ δ_e · ρ^{n_eff−1} + ε_assoc`。
且该边对全局状态估计的影响被开关后验 `s_e` 与鲁棒核截断 `c̄` 双重限制，最优估计的偏差 ≤ `c̄ · s_e / λ_min(Ω)`。系：**几何/物理锚不是「更可信的人」，而是「不同的骗子」；只有独立性审计通过，`n_eff` 才真实增长。**

**定理 20（四通道故障可辨识性）** 若四类故障的签名向量在噪声尺度下两两可分（`‖μ_ℓ − μ_ℓ'‖ > 2σ_c`），且锚点独立性 `κ ≤ τ_ind`，则定义 318 的归因器以概率 ≥ `1 − exp(−Δ²/8σ_c²)` 正确识别故障类别；当 `κ > τ_ind` 时，「几何/物理/共享感知」三类不可辨识，只能输出混合集合并强制退 R69。**归因不是诊断装饰，而是退避层级的开关。**

**定义 310（总览与四不变式）** ANCHOR-RAS = (WCG, LCR, PCR, ASP, AXP, SEF, RCA, RAS-WM‡)。四不变式：实时流零学习写操作（继承 R69）；**锚点独立性审计**（先报 `n_eff`，`n_eff<2` 不得以多源一致定案）；**仿真-证据防火墙**（仿真只提议、不定案，`Δ_sep>2ε̂_sim` 才有判别力）；**鲁棒可开关一致性**（单条回环/单次接触/单个人类回答不得单独改变全局后验）。

**定义 311（WCG）** 节点 `k_i=(T_i∈SE(3), o_i∈𝒪, θ_i∈Θ)`；边 `e=(i,j,τ)`，`τ∈{odom,loop,contact}`，带 `r_e,Ω_e,s_e`。`E_W(x,s)=Σ_e s_e r_eᵀΩ_e r_e + Σ_e Ψ(s_e)`，`Ψ(s)=−μ log s+(1−s)²/(2σ_s²)`；后验 `∝exp(−½E_W)`。

**定义 312–313（LCR 与空间不可吸收性）** `e_ij=Log(T_i⁻¹T_j⊖T̂_ij)`，`χ²_loop=e_ijᵀΩ_ij e_ij`；`U_geo=H(x_map,T|D)`。设局部标定每边可吸收 `δ_cal`，未建模漂移 `‖(I−P_cal)D(n)‖≥c n^α`（`α∈[1/2,1]`），则 `χ_loop(n)≥[c n^α−nδ_cal]₊/σ_loop`，存在有限 `n*` 使更长回环不可被吸收。**局部标定骗不过长闭环。**

**定义 314（PCR）** `θ∈Θ`（质量/惯量/摩擦/恢复/柔顺/接触模式）；`ŷ=Sim_θ(x,a)`；`e_phys=(y−ŷ)ᵀΣ_sim⁻¹(y−ŷ)+λ_mode·1[mode 不一致]`；`p(θ|y)∝p(θ)exp(−½e_phys)`；`U_phys=H(θ|y)+H(mode|y)`。可用反事实重放做几何/物理解耦。

**定义 315–316（ASP/AXP）** `VoI_nav(g)=H(x_map,T|D)−E_loop[H(...)]`，`g*=argmax[VoI_nav−c_nav]`，含探索下限 `ρ_expl`；`VoI_phys(g)=I(H;y|g,x)`，`g*=argmax[VoI_phys−c_exc]`，s.t. `force≤f_max, disp≤ε_exc` 且过 C-RAS-WM。仿真只提议候选，真实执行才产生证据。

**定义 317（SEF）** 在线估 `ε̂_sim`；仅当 `min_{h≠h'}Δ_sep(h,h')>2ε̂_sim` 时仿真证据可用；否则判「无判别力」，既不能确认也不能否定。仿真不得改写真实观测；冲突在信任半径内以真实为准并上调 `U_phys`。

**定义 318（RCA）** `c=(r_res,Δa,χ_loop,e_phys)`；签名：真漂移 `(↑,↑,↑,→)`；标定吸收 `(↓,↑,↑,→)`；几何别名 `(→,↑,↑,→)` 且开关被拒；物理失配 `(→,→,→,↑)` 且发生于接触；共享感知 `(↑,↑,↑,↑)` 且 `κ` 高。仅在签名可分时声明可辨识（定理 20）。

**定义 319（AIA）** `κ=max_{a≠b} I(E_a;E_b|z)/min(H(E_a),H(E_b))`，`n_eff=1+(k−1)(1−κ)`；`κ≤τ_ind` 才允许名义正交。**共享编码器/传感器的两个锚，`κ→1` 时等价一个锚。**

**定义 320（SwC）** 开关先验 `s_e~Beta(a_s,b_s)`；佐证门：回环需外观+几何内点率+（有接触时）物理一致中至少两个有效独立源；人类回答需与几何/物理至少一个独立源一致。max-mixture/动态协方差鲁棒核 `ρ(r)=min(r²,c̄²)`；单条错误长程边不得拖拽整图。

**定义 321（ABEF）** 预算 `B=(n_ask,n_revisit,n_excite,L_path,c_social)` 逐项硬约束；`ρ_expl>0` 与 `ρ_revisit<1` 同时生效；预算耗尽或探索不足时，未消解 `U_geo/U_phys` 视为不可约。

**定义 322–323（证书与干扰集）** `J_ANCHOR=(J_FLUID, χ²_loop_p95, e_phys_p95, U_geo/U_phys 前/后, ε̂_sim, ℓ̂, n_eff, κ, exploration_ratio, anchor_ver)`；`Valid ⇔ J_FLUID valid ∧ SEF ∧ ABEF ∧ AIA 已报告 ∧ SwC 收敛`。`ℰ_ANCHOR=ℰ_FLUID×ℰ_alias×ℰ_physspoof×ℰ_simpoison×ℰ_corranchor×ℰ_complacency`。

**定义 324（三级退避）** `U_all=U_ale+U_epi+U_geo+U_phys`。可信态 `λ=λ_floor(U_ale+残余不可约项)`（anchor bonus）；锚不可用/不可信/`κ>τ_ind` ⇒ 逐指令 R69；VoI 不可用/被污染 ⇒ 逐指令 R68。不变式 `λ_R70(可信)≤λ_R70(不可信)=λ_R69≤λ_R69(不可信)=λ_R68`。

**定义 325–326（调度与关联）** 滑动窗口位姿图 + 边缘化；回环低频增量优化（5–10Hz）；MuJoCo 重放仅在接触/回环冲突/FMA 异常时触发；常规 P99 不变。回环/接触关联变量 `d_e` 与开关联合估计，须过语义+几何+物理佐证门：语义似而几何不闭 ⇒ 别名；几何闭而物理残差大 ⇒ 物理失配；三者互斥 ⇒ 共享感知偏差，禁止单独定案。

## 4. 推导

**引理 19（长回环的非吸收性）** 在定义 313 的漂移模型下，若 `c>δ_cal`，则 `χ_loop(n)` 随 `n` 发散，最小可检测长度 `n*` 存在有限解 `n* ≥ ((τ_loop σ_loop + n*δ_cal)/c)^{1/α}`。系：回环越长，标定越无法解释漂移；与 R69 的 FMA 构成空间/行为对偶。`(χ_loop↑, Δa↑, r_res↓)` 可把「标定吸收」与「真漂移」分开。

**引理 20（仿真间隙下的可判别性）** 若 `‖y−ŷ‖≤ε_sim`，则 `Δ_sep≤2ε_sim` 时任何仿真检验的两类错误率之和 `≥1−Δ_sep/(2ε_sim)`；反之 `Δ_sep>2ε_sim` 时存在零错误阈值检验。故最优探针是安全约束下最大化 `I(H;y|g)` 且满足分离条件者。系：仿真只能提议去哪里分辨，不能把不可分辨变成已确认。

**引理 21（有效独立性与证据通胀）** 名义 `k` 源、两两误差条件耦合上界 `κ`，联合 Fisher 信息至多放大 `n_eff=1+(k−1)(1−κ)` 倍；`κ→1 ⇒ n_eff→1`。直接代入 R69 引理 18 的 `k` 会高估证据、低估投毒上界；须用 `n_eff`。系：共享感知的几何锚与物理锚可能只是同一个锚。

**定理 18（三级严格包含）** 在 A95–A99 下：(a) 无长程边且 `ε_sim=∞` ⇒ ANCHOR 逐指令等价 R69；(b) 交互预算为零 ⇒ R69 逐指令等价 R68；(c) 任意状态 `Risk(ANCHOR)≤Risk(R69)≤Risk(R68)`，效率优势仅在 AIA/SEF/SwC 通过时兑现；(d) 任一认证失败则 `λ` 单调不降退回上一级，控制连续无突变。

**定理 19（别名/共谋鲁棒认证上界）** 单条长程边为离群先验 `δ_e`、佐证相关 `ρ<1`、有效独立源 `n_eff`、关联错误 `ε_assoc`；采用开关先验 + max-mixture 后，错误接受概率 `≤δ_e·ρ^{n_eff−1}+ε_assoc`；该边对全局估计的偏差 `≤c̄·s_e/λ_min(Ω)`。系：几何/物理锚不是「更可信的人」，而是「不同的骗子」；只有独立性审计通过，`n_eff` 才真实增长。

**定理 20（四通道故障可辨识性）** 若四类故障签名在噪声下两两可分（`‖μ_ℓ−μ_ℓ'‖>2σ_c`）且 `κ≤τ_ind`，归因正确率 `≥1−exp(−Δ²/8σ_c²)`；`κ>τ_ind` 时几何/物理/共享感知不可辨识，只能输出混合集合并强制退 R69。归因不是诊断装饰，而是退避层级的开关。

## 7. 本轮最大风险

**一句话**：ANCHOR-RAS 把安全性押在「两枚锚彼此独立且仿真-现实间隙可估」上——但 SLAM 与 MuJoCo 共享同一批传感器、同一个学习编码器和同一份数据偏置，**它们完全可能以同一个方向、同一种连贯性一起出错**；此时 `κ→1`、`n_eff→1`，系统会把「一个锚的偏见」误读成「两个锚的共识」，用一条错误回环把地图锁死、再用被投毒的物理模型为它背书，越优化越自信——**共谋的双锚，比没有锚更危险**。

**次级风险与缓解**：
1. **仿真-现实间隙被低估**（`ε̂_sim` 在分布外失效）→ SEF 强制保守裕度 + 在线校准 + 越界探针零误用（E304）；
2. **错误回环/绑架**（感知别名）→ 开关先验 + 三通道佐证门 + max-mixture 鲁棒核（定义 320、定理 19）；
3. **物理欺骗/对抗表面** → `ℰ_physspoof` 对抗训练 + 接触模式惩罚 + 力/位包络（定义 314、316）；
4. **锚点相关失效被误判为独立** → AIA 以 `n_eff` 取代名义 `k`，`κ>τ_ind` 即整层退 R69（定义 319、324）；
5. **探索惰化/舒适区锁定** → 探索下限 `ρ_expl` + 重访上限 + 长期熵监测（定义 321、E308）；
6. **接触激励本身不可逆** → 力/位/时序硬约束 + C-RAS-WM 前缀认证 + 不可逆动作黑名单（定义 316、E309）。
