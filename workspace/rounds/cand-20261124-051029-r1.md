## 1. 两个灵感的第一性原理

### 灵感 1 ·「UniBot世界挑战赛」→ 一场「固定观测函数下的信息提取竞赛」

把挑战赛写成 POMDP：`(S, A, O, T, R)`，状态 `S` 不可见，选手只能经观测 `O(s)` 行动；而 `O` 的实现就是**视觉编码器 + 本体感受**。三件事随之确定：

- **任务面已冻结**（F3：32 项、评分口径不变）⇒ 提分不来自「再换一个更大的策略头」，而来自「同一批像素里，谁保留的任务相关信息更多」。编码器决定了 `O` 的信息瓶颈，策略只能在瓶颈内工作。
- **五条泛化轴就是 `P(O|S)` 的五种分布漂移**。新语料恰好补上最伤语义编码器的两种：`Fold Clothes` 是可变形物体（无固定位姿、自遮挡、状态本质是时序的）；`Assemble Stool` 是精密装配（要求度量几何与最后一厘米精度）。语义预训练编码器在这两类上属于系统性短板，而非随机误差。
- **「world challenge」也是「world model」**：IP-10 的世界模型 latent 由编码器给出。编码器丢掉的维度（接触、位移、可变形进度），世界模型再大也无法重建——所以编码器审计天然是 WMA-0 选型的前置条件。
- **评分把时延也计入**（成功率×步骤分）⇒ 感知算力是受约束资源，全帧高保真在预算上不可行（这正是 L14/L15 要解决的分配问题）。

### 灵感 2 ·「视觉编码器」→ 系统的传感器，不是固定前端

端到端 VLA 普遍把视觉编码器当冻结黑盒（CLIP/SigLIP/DINOv2 一类），它们优化图文对齐或实例区分，而非度量几何、细纹理、跨帧微位移。由此有三类信息损失，且一一对应到失败面：

1. **空间量化损失**：ViT patch 下采样 + 提交模板的图像缩放 ⇒ 目标区的有效分辨率远低于最后一厘米所需 → 精密装配/插入失败。
2. **单帧语义损失**：滑移、接触起始、可变形进度都是**关系量**（跨时间定义），单帧图像按构造不含其充分统计量（L16）→ 抓取瞬间"看起来成功"、运输中滑落，失败点远离根因。
3. **均匀分配损失**：全帧同分辨率把算力浪费在背景与静止区域，挤压每步时延预算（F1 评分口径）。

**对策**：把编码器从"固定全帧前向"升级为**可查询的多保真传感器**——下游显式声明 `(区域 R, 保真级 ℓ, 时间窗 τ)`，由状态层（IP-13）的不确定性驱动路由，并在每步延迟预算内分配（U19–U21）。同时把"哪个编码器在哪条泛化轴上退化"变成可测矩阵（U22 / IP-06 扩展），使编码器选型从玄学变成审计。

**与第 3 轮的关系**：第 3 轮在感知**之上**加了状态层；本轮补齐状态层**之下**的感知基底。IP-13 的 `Σ` 必须由真实编码器精度传播而来，IP-14 的 SlipGuard 必须走时序通道（L16），IP-09 的最后一厘米必须能请求高清 crop——三者共用同一个 IP-16，而不是各自重复造视觉模块。

## 2. 研究问题（新增 Q13–Q15，接第 1–3 轮 Q1–Q12）

- **Q13（保真度-精度-延迟帕累托）**：在 32 项任务与新增 Dex1 任务上，维持「最后一厘米」精度所需的最小视觉保真度配置是什么？哪些路标需要 crop、哪些需要时序、哪些只需全局语义？（E634/E635）
- **Q14（时序充分性与可变形状态）**：单帧语义特征能在多大程度上预测滑移与可变形任务状态？加入时序通道后 AUROC / 进度误差改善多少？L16 的"静态不可充分"在真实数据上是否可复核？（E636）
- **Q15（五轴编码器退化谱）**：冻结编码器在哪条泛化轴上退化最严重，零再训练的注视/查询策略能否定向挽回？（E637）

## 3. 设计原则（新增 P13–P15，接第 1–3 轮 P1–P12）

- **P13（编码器即可查询传感器）**：下游必须显式声明所需保真度与感兴趣区域；保真度是接口参数而非实现细节。禁止静默全帧均匀降采样。
- **P14（保真度按不确定性×失败代价分配）**：感知算力按「状态不确定度 × 下游失败代价」分配（L14/L15）；全帧高保真是预算违规，不是稳妥选择。
- **P15（关系量必须走时序通道）**：任何跨时间的量（滑移、接触起始、可变形状态、重抓成功）必须由时序编码通道给出；单帧特征按构造不足以判定（L16）。

## 4. 清单处置（深化 / 修剪 / 新增）

- **新增**：**IP-16 FoveaEncoder（P1）**——多保真查询式视觉前端。零训练/轻量 adapter，复用现成冻结编码器 + 区域光流/单目几何；真正新意在「查询协议 + 预算分配 + 审计口径」。
- **深化**：
  - IP-13：`Σ` 由编码器精度按 U19 查询传播进 EKF；E628 的校准须在「实际使用的保真度」上验证；新增「状态层→感知层」查询反馈环（Σ 大 → 请求 crop/重估）。
  - IP-14：SlipGuard 检测器正式复用 IP-16 的 `E_tmp`；L16 给出静态检测不可行的证明；三段响应逻辑保留在 IP-14。
  - IP-09：接近/插入相位请求 `E_crop`（小注视比 f），远距用 `E_sem`；U17 卡方门限自适应于随保真度变化的 `Σ`（同一个 α，不同 Σ）。
  - IP-06：失败矩阵增加一层「编码器退化谱 A[5 轴 × 特征族]」；新增 Dex1 可变形/装配两任务作为**外样本轴**（holdout，不当 32 项直接用）。
  - IP-10：世界模型 latent 须过「控制相关探针」（位姿/接触/进度），非仅重建；IP-16 的审计为 WMA-0 选型提供依据。
  - IP-04：上下文向量可增补编码器健康统计（当前保真级、时序可用性、退化谱命中项）。
  - IP-12：课程新增「Dex1 可变形（Fold Clothes）+ 精密装配（Assemble Stool）」段，与物体多样性段并列。
- **修剪**：IP-14 的检测器实现合并进 IP-16（不再单独维护视觉模块）；本轮不归档任何 IP。
- **MVP 不变**：IP-06 + IP-02 + IP-09 + IP-03 + 通用基线；扩展顺序为 **IP-13（第 3 轮）→ IP-16（本轮，因零训练排在其后但可并行验证）**。
- **退化链更新**：新增 **Level-1.7：查询式编码失败（crop 越界/时序不可用/预算超限）→ 退回固定全帧编码（第 3 轮默认），精度下降但系统可运行**。

## 5. 本轮最大风险

**注意力隧道（注视盲区）**：状态层驱动的注视只会去看「状态层以为重要」的地方；在分布外场景（新可变形/装配任务）里，失败证据可能落在查询区之外——系统会「自信地漏看」，比全帧均匀编码更脆弱。对冲：①低频全帧巡检（周期性不受路由控制的全局扫描）；②腕部通道**永不**做裁剪注视（抓住物体的手边永远是高保真全景）；③OOD/异常触发强制全帧；④查询区带不确定性下限，防 Σ 塌缩导致的视而不见。次要风险：crop 丢全局参考（始终保留低分辨 `E_sem` 全局上下文）、时序通道运动模糊（保守窗长 + 多帧中值）、冻结编码器可能已接近最优（预注册 null result，见 §9）。

## 6. 下一轮迭代计划（深化与修剪，不推倒重来）

- **深化**：IP-16 的保真度需求表与预算求解（E634/E638）；IP-13 的编码器→协方差传播（E628 修订）；IP-14 的时序滑移检测（E636，复用第 3 轮 E630 协议）。
- **修剪预案**：E634 最后一厘米误差降幅 <10% → IP-16 收缩为「仅时序通道」（由 L16 保底，放弃多保真注视）；E635 端到端不升 → foveation 只留离线分析、不入闭环；E636 时序 AUROC 提升 <0.05 → 冻结时序特征不足，SlipGuard 退回日志器（与第 3 轮 E630 判据一致）；E637 退化谱不可复现 → 审计降级为报告，不用于选型。

## 3. 新增 IP 详述

### IP-16 · FoveaEncoder 多保真查询式视觉前端（P1，新）

- **动机**：32 项任务面冻结（F3）⇒ 提分靠信息提取效率；新 Dex1 语料恰好压测语义编码器两大短板——可变形时序状态（Fold Clothes）与度量精度（Assemble Stool）；提交模板已内建图像缩放，前端本就是手调关键；评分含步骤分，感知时延进预算。现有 VLA 把编码器当固定全帧前向、均匀分辨率，系统性浪费算力并丢失目标区细节。

## 5. 符号与定义（新增 U19–U22；U1–U18 沿用第 1–3 轮）

- **定义 U19（视觉查询）**：`q = (R, ℓ, τ)`；`R` 为（多相机）区域，`ℓ ∈ {0,1,2,3}` 为保真级，`τ` 为时间窗帧数（τ=1 为静态）；编码输出 `z_q = E_ℓ(obs[t-τ+1:t], R)`。查询是显式接口对象，可被记录、审计与预算。
- **定义 U20（多保真编码器组）**：`E = {E_sem, E_crop, E_tmp, E_geo}`，每一成员带时延 `c_ℓ(R)` 与任务量测的协方差剖面；`E_sem` 为低频全局语义（常开），`E_crop` 为目标区高保真，`E_tmp` 为时序差分/光流，`E_geo` 为单目深度/相对位姿代理。
- **定义 U21（感知预算分配）**：每控制步延迟预算 `B`；策略 `π_enc: (Σ, phase, task) ↦ Q`，满足 `Σ_{q∈Q} c(q) ≤ B`；目标 `max E[success]`（等价 `min E[failure cost]`）。注视比 `f = area(R)/area(frame)`。
- **定义 U22（编码器退化谱）**：矩阵 `A[a, e]`，行 `a ∈ 五泛化轴`，列 `e ∈ 特征族`；元素为任务探针（位姿/身份/时序/几何）相对基线的退化量；用于定位「哪条轴打穿哪种特征」。

## 6. 关键算法骨架（新增片段；主体沿第 1–3 轮 `UniBotSAGEPolicy`）

```python
# ===== IP-16: 多保真查询式视觉前端 =====
class FoveaEncoder:
    def __init__(self):
        self.bank = {"sem": E_sem, "crop": E_crop, "tmp": E_tmp, "geo": E_geo}
        self.tick = 0

    def query(self, obs, q):                     # U19: q=(R, l, tau)
        R, l, tau = q
        frames = obs.window(tau)                 # 时间窗
        return self.bank[l].encode(frames, R)    # z_q + 观测协方差

    def route(self, state, phase, budget):       # U21: π_enc
        Q = [("sem", None, 1)]                   # 全局语义常开（防隧道）
        if state.sigma_trace() > SIGMA_HI or phase in ("insert", "release"):
            Q.append(("crop", state.target.roi, 1))
        if phase in ("transport", "grasp"):
            Q.append(("tmp", state.wrist_roi, TAU_TMP))
        if phase == "assemble":
            Q.append(("geo", state.target.roi, 1))
        return self.fit_budget(Q, budget)        # 超预算→按收益/成本排序裁剪

    def sweep(self, obs):                        # 周期全帧巡检（不受路由控制）
        if self.tick % N_SWEEP == 0:
            return self.bank["sem"].encode(obs.window(1), FULL)
        return None
```

## 7. 推导（新增引理 L14–L16；L1–L13 沿用第 1–3 轮）

**引理 L14（固定像素预算下的注视效率）** 设线性分辨率 `ρ` 对应像素数 `∝ ρ²`，目标区面积占比 `f`；量化误差 `ε ∝ 1/ρ`。均匀编码用预算 `C` 给全帧：`ε_u ∝ C^{-1/2}`。若给目标区 `ρ_R`、背景最低可接受 `ρ_min`，则 `f ρ_R² + (1−f) ρ_min² = C`，故 `ε_R ∝ √( f / (C − (1−f) ρ_min²) )`。当背景项可忽略时 `ε_R/ε_u ≈ √f`。⇒ 例：`f=0.05` 时目标区量化误差约为均匀编码的 0.22 倍（≈4.5× 更细采样），且总像素预算不变。**前提**：`R` 必须确实包含病因区；若目标落在 `R` 外，则 `ε_R = ∞`——该前提正是「注意力隧道」风险的数学形式。∎

**引理 L15（查询价值与何时再看一眼）** 设下游期望失败代价 `Risk(Σ)` 随信息增加（`Σ` 变小）而下降；一次查询成本 `c(q)`（步数/时延折算为分数）。查询的期望收益为 `Risk(Σ) − E[Risk(Σ')]`，仅当大于 `c(q)` 才值得。若局部 `Risk ≈ λ·log det Σ`（`λ>0` 为风险敏感度），则信息增益 `g = ½ log(det Σ / det Σ')`，盈亏平衡 `g* = 2c(q)/λ`。⇒ 与 L13（探测的步数经济学）同构：高不确定度×高失败代价的相位（insert/release/运输）才配高清查询；低风险相位只保留 `E_sem`。∎

**引理 L16（关系量的时序充分性 / 静态编码器不足）** 令滑移标签 `y = 1` 当且仅当物体相对夹爪在时间窗 `Δt` 内位移超阈。腕部相机刚性固定在夹爪上，则在任一时刻 `t`，「物体被夹稳」与「物体刚发生滑移但当前相对位姿恰好相同」这两条轨迹可在 `t` 产生**完全相同的单帧图像**（相同相对位姿 + 相同背景），而 `y` 不同。故任何单帧函数 `f(O_t)` 对两条轨迹输出相同，不可能同时对两个标签正确 ⇒ 单帧编码器不构成滑移的充分统计量；至少需要跨 ≥2 帧的时序通道。可变形进度（Fold Clothes 的折叠状态）同理：其状态由形变历史决定，单帧只给瞬时快照。∎（注：若用头部世界相机，物体运动与相机运动混淆，单帧仍不足以分离，故时序+参考系仍必要。）
