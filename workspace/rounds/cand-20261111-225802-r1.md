# 第 57 轮（承接第 56 轮「证据地图×主动探询×信任协商」IP-127~132；灵感循环第 3 轮；本轮灵感：「成功率」×「用户测试」）

> 第 56 轮把安全的依据从"模型置信"升级为"证据承诺"，但它留下的问题恰好是部署评审与真实用户最先问的那一句：**"所以你的成功率是多少，你怎么知道？"** 第 56 轮的 soundness 是**逐接触、理论下**的界，无法直接回答**任务级、经验上**的成功率；而它的人类证据虽被隔离加权，其**信度**却从未被测量——`w_h` 来自"历史校准"，可"校准本身"从未被用户测试的评分者一致性、复测稳定性、需求效应与自动化偏差检验过。本轮两个灵感各补一刀：**成功率**把"单点数字"升级为**带分布标签、置信区间与失败分解的可审计主张**，并进一步升级为**控制回路的一等约束**；**用户测试**把"可用性打分"升级为**对人这一证据源的计量学**。核心命题由"证据说可信"升级为 **"可核算的成功率说可信，且核算过程本身不可套利"**。

核心矛盾：
- **H26（证据承诺 ≠ 任务成功率）**：任务成功是轨迹级合取（安全 ∧ 完成 ∧ 及时 ∧ 被接受），失败模式异质且相关；逐接触界无法不经联合界就组合成任务成功率，而 `k/n` 的裸点估计在挑种子、小样本、分布迁移下系统性偏乐观。一个说不出诚实成功率区间的系统，既不可部署也不可比较。
- **H27（用户测试 ≠ 合规剧场）**：把人当证据源，就必须把**测试协议本身**当可审计对象——否则"用户测试通过"只是需求效应、盲法缺失与橡皮图章共同制造的假保证。人可以作为被测试的传感器，但传感器的信度必须先被计量。

## 0. 直觉与动机

**灵感 1（成功率 → 从单点数字到带分布标签的区间主张）**
直觉：裸成功率是"没有分母的成功"——不写 `n`、不写 `α`、不写任务分布、不写失败分解的"95%"，和一句 "infeasible" 一样不可审计。成功率应被当作**带溯源的区间估计** `[p_L,p_U]`，附 `(D_test, n_eff, α, shift bound, tail bound)`；任务成功须**四元分解报告**（`p_safe, p_complete, p_ontime, p_accept`），防止用完成率掩盖安全失效。更要紧的是：成功率不应只是事后指标，而应成为**控制回路的约束**——用下置信界 `p_L` 调节自治等级：证据多 → `p_L` 高 → 更自主更快；迁移大/证据少 → `p_L` 低 → 加探针、降步态、升同意等级。这正好接上第 56 轮的步态变速箱，把"每接触风险预算 `δ_f(g)`"升级为"任务成功率 LCB 预算"。

**灵感 2（用户测试 → 人作为传感器的计量学）**
直觉：用户测试不是"问问人好不好用"，而是对**人这一证据源**做计量：预注册假设、任务电池、随机分配与顺序平衡、盲法、评分者间一致性 `κ`、复测 `ICC`、停止规则。它同时校准两件事——**交互层**（解释可读性、理解时延）与**信任**（过信 → automation complacency / 橡皮图章；欠信 → disuse）。信任校准误差 `CE=|T−R|` 是人类版的 ECE；`L2` 的"秒确认 + 高确认率"就是可测的橡皮图章签名。用户测试给出的是**人-机联合系统**的成功率，与纯机器人成功率之间有一个必须显式估计的**测试效度差 `Δ_tv`**，不能把人测数字直接当部署数字。

**灵感 3（两者相乘 → 可核算 + 反套利）**
直觉：成功率一旦成为控制变量，就会被 Goodhart：挑软任务、隐藏难例、学会考试而非变安全、把用户测试做成合规剧场。所以成功率证书必须内置**反套利**：held-out 任务集、红队任务、四元分解、预注册、报告必须声明部署分布——任一缺失即拒发证书。人仍不是决策者（承第 56 轮），但人是**被测试的传感器**：UTE 测传感器信度，TCL 测人对传感器的信任是否与现实相符，二者共同决定 `w_h` 与同意阶梯阈值。

## 1. 形式化定义（增量：定义 133–138）

**定义 133（任务成功谓词与成功率泛函）** 任务 `τ`、环境 `e`、执行轨迹 `ξ`：`Succ(ξ;τ,e) := Safe(ξ) ∧ Complete(ξ;τ) ∧ OnTime(ξ;T_max) ∧ Accepted(ξ;h)`。部署分布 `D` 覆盖 `(τ,e,h)`；成功率 `p(D)=E_{ξ~π,D}[Succ]`；四元分解 `v(D)=(p_safe,p_complete,p_ontime,p_accept)`，且由合取关系有 `p(D) ≤ min_i v_i`。单次任务内若有 `m` 个关键接触，任务级安全以联合界 `Σ_j P(fail_j)` 组合，不复用第 56 轮的逐接触常数。

**定义 134（成功率区间与迁移/尾部界）** 经验试验 `(k,n)`，在分层 `s` 上取 Clopper–Pearson 下界并按 Bonferroni 分摊 `α`；`p_test=Σ_s ω_s p_s`。以重要性权重 `w` 与有效样本量 `n_eff=(Σw)^2/Σw^2` 迁移到 `D_deploy`，迁移惩罚 `ε_shift ≥ TV(D_test,D_deploy)`（置信 `1−α_shift`）。尾部成功率 `p_tail(β)=inf{p: P_D(Succ) ≥ p  on mass≥β}`，等价地用失败 `CVaR_β` 报告。**诚实主张**：`p(D) ≥ p_L := CP_lower(n_eff) − ε_shift`，覆盖概率 `≥ 1−α−α_shift`；单侧区间不得由点估计 + 正态近似在 `n_eff` 小时替代。

**定义 135（成功率证书 SRC / `J_s`）** `J_s = (p_L,p_U,n_eff,strata,v(D),prov,prereg_id,ε_shift,p_tail,gaming_flags)`。**报告契约**：任何"成功率"必须携带 `(D, n_eff, α, v(D))`，缺一即**无效主张**；继承第 56 轮 `J_m`（MEC）的全部检查；`gaming_flags ≠ ∅` 即拒发。

**定义 136（成功率调节器 SRG）** 给定区间 `[p_L,p_U]`、目标 `p_target(a)`、可行域：选自治等级 `a* = argmax_a U(a)` s.t. `p_L(a) ≥ p_target(a) ∧ feasible(a)`。**单调公理**：`p_L` 下降 ⇒ 所选等级不升（不降档即不增险）；若不存在可行 `a`，回退保守停。**升级须有边际证据**（新探针/到访/裕度），不得"无证据升级"。这把第 56 轮 PCE 的"承诺/绕行/降档/协商"四态重新用 `p_L` 锚定。

**定义 137（用户测试证据协议 UTE）** `Π=(prereg,battery,assign,blind,metrics,stopping)`；信度 `κ`（评分者间）、`ICC`（复测）。只有 `κ≥κ_min ∧ ICC≥ICC_min` 才可令 `w_h = w_max·g(κ,ICC,cal) > 0`，否则 `w_h=0`；协议不合规产出的"成功"不得进入 `J_s`。测试效度差 `Δ_tv=|p_test − p_deploy|` 必须报告并计入 `J_s` 的不确定性。

**定义 138（信任校准环 TCL 与反套利 ASG）** 信任 `T`（量表或依赖行为）、经验可靠度 `R`，校准误差 `CE=|T−R|`；过信 `T>R+ε_trust`、欠信 `T<R−ε_trust`。**橡皮图章签名**：`confirm_rate>ρ_rubber ∧ median(τ_conf)<τ_read`，触发即回退保守停（只作安全动作，不作人事评价）。**反套利审计**：held-out 集 `D_hold`、红队集 `D_red`、分解 `v`；`gaming_flags ⊆ {unregistered, holdout_gap, redteam_weak, safe_hidden, goodhart_pattern, n_eff_too_small}`，任一命中即 SRC 拒发。

## 2. 关键算法伪代码（完整版见产物区）

### IP-133 SRA（Success-Rate Accounting）

```python
def success_accounting(trials, D_test, D_deploy, alpha, beta, alpha_shift):
    strata = stratify(trials, by=['env_class', 'task_family'])
    cp = {s: clopper_pearson(k(s), n(s), alpha / (2 * len(strata)))
          for s in strata}                       # A38: 分层 + Bonferroni
    v = {s: decompose(s) for s in strata}        # (safe, complete, ontime, accept)
    w, n_eff = importance_weights(D_test, D_deploy, trials)
    eps_shift = tv_bound(D_test, D_deploy, conf=1 - alpha_shift)   # A39
    p_L = cp_lower_effective(cp, w, n_eff) - eps_shift
    return SuccessInterval(p_L=p_L, p_U=cp_upper_effective(cp, w, n_eff),
                           n_eff=n_eff, strata=strata, v=v,
                           p_tail=cvar_failure(trials, beta), eps_shift=eps_shift)
```

### IP-135 SRG（Success-Rate Governor）

```python
def success_rate_governor(M, sched, ci, autonomy):
    for a in ordered_conservative_to_aggressive(autonomy):
        if ci.p_L < p_target[a] or not feasible(a, sched, M):
            continue
        if a > autonomy.current and not marginal_evidence(M, sched, a):
            continue                             # A41: 无证据不升级
        return a
    return 'conservative_stop'                   # p_L 撑不起任何等级
```

### IP-136/137 UTE / TCL

```python
def run_user_test(protocol, ops, tasks):
    if not (protocol.preregistered and protocol.blinded):
        return UTEvidence(valid=False, reason='protocol_noncompliant')
    data = balanced_randomized(protocol.battery(tasks), ops)   # 顺序平衡
    kappa, icc = inter_rater(data), test_retest_icc(data)
    valid = kappa >= kappa_min and icc >= icc_min               # A40
    return UTEvidence(kappa, icc, readability(data),
                      w_h=w_max * g(kappa, icc) if valid else 0.0,
                      gap=test_validity_gap(data, deploy_sim), valid=valid)

def trust_loop(data, R, consent_log):
    T, CE = elicit_trust(data), abs(elicit_trust(data) - R)
    rubber = (confirm_rate(consent_log) > rho_rubber and
              median(confirm_latency(consent_log)) < tau_read)
    return TrustReport(CE, over=T > R + eps_trust, under=T < R - eps_trust,
                       rubber=rubber,
                       action='fallback_conservative_stop' if rubber else 'ok')
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| SRA | O(n·d) | O(\|strata\|) | 无挑样、区间合法、迁移/尾部显式 |
| SRC | O(\|J_s\|) | O(\|prov\|) | 报告契约完备、继承 `J_m` |
| SRG | O(\|A\|) | O(1) | 单调、无证据不升级、兜底保守停 |
| UTE | O(\|ops\|·\|tasks\|) | O(\|data\|) | 预注册+盲法、`κ/ICC` 门槛 |
| TCL | O(\|data\|) | O(1) | 橡皮图章检测、只回退不做人事评价 |
| ASG | O(\|D_hold\|+\|D_red\|) | O(1) | held-out/红队/分解，任一命中即拒 |

**正确性定理（Auditable Success-Rate Soundness, ASRS）**：在 A33–A36 基础上加 **(A37)** 试验无挑样/预注册、抽样无偏；**(A38)** 区间构造合法（Clopper–Pearson + 分层 Bonferroni）；**(A39)** `ε_shift` 以 `1−α_shift` 覆盖真实 `TV`；**(A40)** 用户测试 `κ≥κ_min ∧ ICC≥ICC_min` 且橡皮图章检测可靠；**(A41)** SRG 单调。则：(i) **覆盖率** `P(p(D_deploy) ≥ p_L) ≥ 1−α−α_shift`；(ii) **调节单调性**：`p_L` 下降不升自治、无证据不升级，SRG 无"升险路径"；(iii) **人类证据健全**：`w_h>0` 仅当信度达标，橡皮图章命中即保守停；(iv) **报告契约**：不声明 `(D,n_eff,α,v)` 的成功率被 SRC 拒绝。逐接触物理安全仍由第 56 轮 `δ_f+ε_cal+δ_probe+ε_h` 保证，任务级用联合界组合，二者不可相互替代。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| Goodhart：成功率成目标后被套利 | 高 | held-out + 红队 + 四元分解 + 预注册 |
| 分布迁移不可识别，迁移惩罚估不准 | 高 | 重要性权重 + 诚实的 shift 上界 + `n_eff` 过小拒发证书 |
| 用户测试合规剧场 / 需求效应 | 高 | 预注册 + 盲法 + `κ/ICC` 门槛 + 独立审计 |
| 橡皮图章监控误伤操作者 | 中 | 仅用于回退保守停、不用于人事评价、分级复核 |
| SRG 过保守致不可用 | 中 | 目标分层 + 有界探索预算 + anytime 更新 |
| 四元分解掩盖共因失效 | 中 | 联合/共因失效建模，报告联合分布而非仅边际 |

## 6. 本轮最大风险

**一句话**：一旦把成功率提升为一等控制变量，最大的风险就是 **Goodhart**——系统与运营者会学会"制造成功率"而不是"变安全"（挑软任务、藏难例、把用户测试做成合规剧场），而带置信区间的漂亮数字又会给出虚假保证，因为真正致命的两项——**部署分布迁移**与**人的信度**——恰恰最难从自家数据中识别。

### IP-133 SRA（Success-Rate Accounting）

```python
def success_accounting(trials, D_test, D_deploy, alpha, beta, alpha_shift):
    strata = stratify(trials, by=['env_class', 'task_family'])
    cp = {s: clopper_pearson(k(s), n(s), alpha / (2 * len(strata)))
          for s in strata}                          # A38: 分层 + Bonferroni

    p_L = cp_lower_effective(cp, w, n_eff) - eps_shift
    p_U = cp_upper_effective(cp, w, n_eff)
    tail = cvar_failure(trials, beta=beta)
    return SuccessInterval(p_L, p_U, n_eff, strata, v, tail,
                           D_test, D_deploy, alpha, eps_shift)

def cp_lower_effective(cp, w, n_eff):
    # 小 n_eff 时退化到最保守分层下界，避免正态近似高估覆盖
    if n_eff < n_min: return min(lo for lo, _ in cp.values())
    return weighted_lower(cp, w)
```

```python
        return ('reject', flags, None)   # 证据门：无契约/有套利即拒发
    return ('ok', [], SuccessCert(ci.p_L, ci.p_U, ci.n_eff, ci.strata,
                                  ci.v, ci.p_tail, prereg.id, ci.eps_shift,
                                  J_m))

def report_contract_ok(ci):
    # 报告必须自带分布、样本量、显著性、分解；缺一即无效主张
    return all(x is not None for x in
               (ci.D_test, ci.D_deploy, ci.n_eff, ci.alpha, ci.v))
```

### IP-135 SRG（Success-Rate Governor）

```python
P_TARGET = {'trot': 0.95, 'pace': 0.90, 'crawl': 0.85, 'L2': 0.80}

def success_rate_governor(M, sched, ci, autonomy):
    for a in ordered_conservative_to_aggressive(autonomy):
        if ci.p_L < P_TARGET[a] or not feasible(a, sched, M):
            continue
        if a > autonomy.current and not marginal_evidence(M, sched, a):
            continue                          # A41: 无新证据不得升级
        return a
    return 'conservative_stop'                # p_L 撑不起任何等级

def marginal_evidence(M, sched, a):
    return (new_probe_since_last(M) or new_visit(M, sched)
            or min_margin(sched, M) >= margin_floor(a))
```

### IP-136 UTE（User-Test Evidence）

```python
def run_user_test(protocol, operators, tasks):
    if not (protocol.preregistered and protocol.blinded):
        return UTEvidence(valid=False, reason='protocol_noncompliant')
    data = []
    for t in balanced_randomized(protocol.battery(tasks), operators):
        trace, resp = observe(t.operator, t)          # 盲法 + 顺序平衡
        data.append((t.operator, t, trace, resp))
    kappa = cohen_kappa([r.labels for r in data])
    icc   = test_retest_icc(data)
    read  = readability_score(data)
    valid = kappa >= kappa_min and icc >= icc_min     # A40
    gap   = test_validity_gap(data, deploy_sim)       # Δ_tv
    w_h   = w_max * g(kappa, icc) if valid else 0.0
    return UTEvidence(kappa, icc, read, w_h, gap, valid)
```

### IP-137 TCL（Trust Calibration Loop）

```python
def trust_calibration_loop(data, reliability, consent_log):
    T  = elicit_trust(data)                    # 量表 + 依赖行为
    CE = abs(T - reliability)
    over  = T > reliability + eps_trust        # 过信 → complacency
    under = T < reliability - eps_trust        # 欠信 → disuse
    rubber = (confirm_rate(consent_log) > rho_rubber and
              median(confirm_latency(consent_log)) < tau_read)
    action = 'fallback_conservative_stop' if rubber else 'ok'
    return TrustReport(CE, over, under, rubber, action)
```

### IP-138 ASG（Anti-Specification-Gaming）

```python
def anti_gaming_flags(ci, holdout, redteam, decomp, prereg, prev):
    f = []
    if not prereg.valid:                            f.append('unregistered')
    if abs(ci.p_hat - holdout.p_hat) > g_max:       f.append('holdout_gap')
    if redteam.p_success < red_min:                 f.append('redteam_weak')
    if decomp.p_safe < safe_min:                    f.append('safe_hidden')
    if prev and ci.p_hat > prev.p_hat and (
            ci.p_tail.risk > prev.p_tail.risk or
            ci.intervention > prev.intervention):
        f.append('goodhart_pattern')                # 指标升、尾部/介入也升
    return f
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SRA | O(n·d) | O(\|strata\|) | 无挑样、区间合法、迁移/尾部显式（A37–A39） |
| SRC | O(\|J_s\|) | O(\|prov\|) | 报告契约完备、继承 `J_m`、套利即拒 |
| SRG | O(\|A\|) | O(1) | 单调、无证据不升级、兜底保守停（A41） |
| UTE | O(\|ops\|·\|tasks\|) | O(\|data\|) | 预注册+盲法、`κ/ICC` 门槛（A40） |
| TCL | O(\|data\|) | O(1) | 橡皮图章检测、只回退不做人事评价 |
| ASG | O(\|D_hold\|+\|D_red\|) | O(1) | held-out/红队/分解，任一命中即拒 |

**正确性定理（Auditable Success-Rate Soundness, ASRS）**
假设 A22–A28（第 53/54 轮）、A29–A32（第 55 轮）、A33–A36（第 56 轮）成立；**(A37)** 试验无挑样/预注册、抽样无偏；**(A38)** 区间构造合法（Clopper–Pearson + 分层 Bonferroni）；**(A39)** `ε_shift` 以 `1−α_shift` 覆盖真实 `TV(D_test,D_deploy)`；**(A40)** 用户测试 `κ≥κ_min ∧ ICC≥ICC_min` 且橡皮图章检测可靠；**(A41)** SRG 单调（`p_L` 下降不升自治、无边际证据不升级）。则：

1. **覆盖率**：`P(p(D_deploy) ≥ p_L) ≥ 1−α−α_shift`；
2. **调节单调性**：任何 SRG 路径只经（a）更高 `p_L` 且（b）有边际证据才升级，不存在"升险交互/升险自治"路径；
3. **人类证据健全**：`w_h>0` 仅当 `κ/ICC` 达标，橡皮图章命中立即保守停；
4. **报告契约**：未声明 `(D,n_eff,α,v)` 的成功率主张被 SRC 拒绝；`gaming_flags≠∅` 拒发证书；
5. **任务级部署界**（与第 56 轮物理界联合，取联合界）：

```
P(任务成功 ∧ 报告诚实) ≥ (1 − α − α_shift) · [1 − Σ_cp(δ_f + ε_cal + δ_probe + ε_h)]
                        − P(n_eff < n_min 未检出)
                        − P(橡皮图章漏检)
                        − P(Δ_tv > Δ_max)
```

关键：**成功率不是被优化的标量，而是被核算的区间**；**证据门从"逐接触"上移到"任务级报告"**（无契约无证书）；**人作为证据源要过计量学门槛**（`κ/ICC`），作为信任主体要被校准（`CE`/橡皮图章）；**SRG 把 p_L 接回控制回路**，使"证据多 → 更自主"成为单调、可审计的兑换。

## 6. 本轮最大风险

**一句话**：一旦把成功率提升为一等控制变量，最大的风险就是 **Goodhart**——系统与运营者会学会"制造成功率"而不是"变安全"（挑软任务、藏难例、把用户测试做成合规剧场），而带置信区间的漂亮数字又会给出虚假保证，因为真正致命的两项——**部署分布迁移**与**人的信度**——恰恰最难从自家数据中识别。
