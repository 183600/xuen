# 第 70 轮（承接第 69 轮「FLUID-RAS 交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「痛点分析」×「群体智能」）

> R69 让系统学会「看、问、触」，并用 VoI 给每一次提问定价。但它有三条从未被检验的隐含假设：
> **(i) 不确定性的单位是熵（nats），而刹车、通信、社交的成本单位是焦耳 / 毫秒 / 信誉**——用熵做跨智能体的预算分配，等于用体温计给油箱计价；
> **(ii)「k 个正交证据源」真的正交**——单机器人身上的视觉与触觉共享同一个相机、同一个世界模型、同一份训练数据，它们的错误高度相关，R69 的独立性假设在单体内是**假的**；
> **(iii) 信息动作只发生在「单个智能体 ↔ 单个被问者」之间**——没有考虑「多个智能体同时想探同一处」「我的探询会改变你的信念与行为」这类群体效应。
>
> 两个灵感各补一刀：
> - **痛点分析**给出正确的计量单位：不是「熵降了多少」，而是「**期望损失降了多少、花了多少预算**」。把 R69 的 U 映射到 Bayes 风险 ρ，得到 `Π_epi = ρ(当前信息) − ρ(预算内最优信息)`。只有这部分「可约的痛」值得治；aleatoric 是「死痛」，治了也不降；高频低危是「虚荣痛」，治它只是刷指标。
> - **群体智能**给出真正的多样性来源，也同时暴露它的病：异质机器人、不同视角、不同传感器能提供**真**正交证据；但信息素式广播会让误差相关 ρ→1、有效独立数 k_eff→1，群体从「智慧」退化为「回音室」。所以 R69 的「k 个正交源」必须升级为「**k_eff ≥ 2**」，并用「先承诺后揭示」的封存证据协议保护多样性。
>
> 再加两条承重结构：
> - **疼痛场是共享信念，共享信念是新的攻击面**。谁都能往场上沉积「这里很痛」，于是有人可以把群体引向陷阱（疼痛膨胀），也可以把真痛点投票掉（疼痛压制）。所以场必须带签名、衰减、有限影响与鲁棒聚合；安全通道取上分位（宁可信其有），预算通道取中位数（宁可信其无）。
> - **治疗了才算数**。痛点分析最容易骗自己：把噪声当痛点、把无效干预继续执行。故引入**反事实诊断**：干预前后与匹配对照做 difference-in-differences，痛没真降就撤掉干预、降权热点、回灌成本模型。这把「痛点分析」从一次性报表变成在线因果闭环。
>
> 核心命题：**把 R69 的「单智能体 + 熵 + 被动被问者」升级为「异质群体 + 期望损失 + 可被投毒的共享疼痛场」；用痛点分析决定「治哪里、值不值得治」，用群体智能决定「谁来治、证据够不够独立」；共享疼痛场负责无中心协调，但必须被鲁棒聚合、有限影响、封存证据与反事实诊断四重约束，否则群体只是把单体偏差放大成集体偏差。** 命名 **STING-RAS**（Stigmergic Threshold-indexed Information & Networked Guidance for Risk-Adaptive Swarms）——蛰刺：疼痛不是叫喊，是留在环境里、会衰减、会被别的个体读到的一枚信息素。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这一群智能体一起，最该去止哪一处痛、谁去止、凭什么相信彼此的证据**」。

## 0. 直觉与动机

**灵感 1（痛点分析 → 把「不确定性」换成「代价」）**
直觉：R69 的 U_epi 是熵，单位是 nats；但提问要花毫秒、探针要耗电、注视要占社交信用。跨智能体比较「哪一处更值得探」时，用熵等于拿体积去比重量。痛点分析的正确单位是**期望损失**：把当前信息下的 Bayes 风险 ρ(I) 与预算内最优信息下的风险 ρ(I*) 相减，得到可约的痛。副产品是三个判据变得干净：不痛不问（Π_epi 小）、死痛不问（进 Π_ale）、虚荣痛不问（高频但低危）。这把 R69 的「不确定就问」纠偏为「**只有可约的痛才问，且算清治好它的成本**」。

**灵感 2（群体智能 → 单体的「正交证据」是伪造的）**
直觉：R69 要求「k 个正交证据源一致才定案」，但在一个机器人内部，两个模态共享同一次标定、同一次前向、同一套数据偏置；它们的一致只证明「自洽」，不证明「正确」。群体智能给出真多样性：不同位置、不同传感器、不同故障模式。但群体也带来新病：**herding**——大家都读同一份广播，于是 ρ→1，名义上 N 个证据，等价于 1 个。所以「几个源」这个计数是错的，正确的是**有效独立数 k_eff**。

**灵感 3（stigmergy → 疼痛是写在环境里的）**
直觉：蚁群不靠中央调度，靠信息素在环境里做间接协调。疼痛点也应该能被「写下来」：谁在哪儿差点出事、哪儿的歧义最贵，就留下一枚带签名、带证据哈希、带衰减的痛觉信息素；别的智能体路过就读、就加权、就决定要不要去探。好处是无中心、可异步、能容忍断连；坏处是信息素可被伪造、可被压制，且**广播本身制造相关性**。这三者决定了后面必须同时有鲁棒聚合、有限影响、封存证据三件套。

**灵感 4（群体智能的另一面 → 共识不是投票，是最小化期望痛）**
直觉：多数票隐含「一人一票等权」和「错误独立」。异构群体里，一个视野被挡住的智能体和一只鹰眼不该等权；更根本的是，**共识的产物不该是「哪个模态赢」，而是「选哪个动作让期望痛最小」**。所以聚合是贝叶斯后验 + 标定可靠度 + 损失决策，而不是数票。群体智能的「智慧」来自三件套——**多样性、独立性、校准**——缺一即群体迷思。

**灵感 5（痛点分析的方法论 → 治疗后才算数）**
直觉：痛点分析最容易被自己的指标骗：把高频噪声标成痛点、把无效干预继续执行、把「看起来降了」当成「真的降了」。所以要闭环：对已治痛点与其匹配对照做反事实对比（difference-in-differences），痛没真降就撤干预、降热点先验。这把痛点从「观测到的异常」升级为「被验证可被消除的损失」，也顺便防止把疼痛指标本身当成优化目标（Goodhart）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（STING-RAS 总览）** STING-RAS = (SPF, PAD, SAA, SEI, PWC, QSG, SBA, PCD, VQAuditor-S, RAS-WM†)。四条不变式：
(i) **安全包络不扩张**：每个智能体的物理动作仍由各自的 C-RAS-WM 前缀认证；群体层只能改「选哪个信息动作 / 哪个模态」，不得扩大任何单体的安全包络（继承并强化 R69 定理 17）；
(ii) **证据纪律的独立性版**：单枚疼痛沉积、单个智能体、单次交互都不得独立定案；集体消歧要求 `k_eff ≥ 2` 且加权法定人数 `q ≥ q_quorum`；
(iii) **决策纪元对齐**：群体消息只在下一个决策纪元生效，当前已认证前缀不受影响，通信延迟不得击穿实时预算；
(iv) **疼痛预算**：单位时间信息总成本 ≤ B；只对 Π_epi 分配预算，Π_ale 不治。

**定义 311（疼痛泛函与可约 / 不可约分解）** 设 `I` 为当前信息集，`I*` 为预算内最优可获取信息集。定义 Bayes 风险 `ρ(I) = E_{s~μ}[ min_a E_{a~π(·|I)} ℓ(s,a) ]`（或对固定策略的期望损失）。则
`Π_ale = ρ(I*)`，`Π_epi = ρ(I) − ρ(I*)`，且恒有 `Π = ρ(I) = Π_ale + Π_epi`。
语义：Π_ale 是「把预算内能拿到的信息都拿到后仍要付的痛」，近似不可约；Π_epi 是「再拿一点信息就能省下的痛」，可约、可治、值得分配预算。注意这是**损失空间**的分割；R69 的 (U_ale, U_epi) 是**熵空间**的近似。在条件 A100（损失取 −log 后验的单调代理）下二者单调对应。

**定义 312（痛点 / 热点）** 状态空间区域 B 是「痛点」，当且仅当同时满足：
(a) **可约性**：`E[Π_epi | B]` 的 (1−α) 下置信界 > θ_pain；
(b) **密度**：`μ(B)·E[Π_epi|B] ≥ θ_flow`（高频低危不算痛；低频高危另设稀有事件通道）；
(c) **可及性**：存在预算内信息动作 g 使 `E[VoI_loss(g)|B] ≥ c(g)`；
(d) **可达性**：时间窗内至少一个智能体可到达或经通信覆盖。
一句话：**痛点是可约疼痛的密度峰，不是不确定性的密度峰**。

**定义 313（痛觉信息素与疼痛场 SPF）** 沉积 `d = (x, t, π̂, e_hash, sig_i, stake_i)`，其中 π̂ 为该处 Π_epi 的估计，e_hash 为支撑证据哈希。场
`Π̂(x,t) = Agg_robust { e^{−λ_p(t−t_d)} · K(‖x−x_d‖) · π̂_d }`，
K 为紧支撑核，λ_p 为遗忘率（疼痛会过期，旧图会误导）。`Agg_robust` **非对称**：安全相关通道取上分位（宁可信其有，recall 优先），预算相关通道取中位数 / 截尾均值（宁可信其无，precision 优先）。单枚沉积影响被权重上限截断：`|∂Π̂/∂π̂_d| ≤ w_max`。

**定义 314（有效独立数与相关估计）** 各智能体误差 ε_i 的相关矩阵 `R=[ρ_ij]`，权重 w。有效独立数
`k_eff = (Σ_i w_i)² / Σ_{i,j} w_i w_j ρ_ij`。
等权、两两相关 ρ 时 `k_eff = N / (1 + (N−1)ρ)`：ρ→1 则 k_eff→1（回音室），ρ→0 则 k_eff→N。ρ_ij 由标定探针上的成对一致率估计并取保守上置信界；**不得使用「自称独立」**。

**定义 315（封存证据协议 SEI）** 一个决策纪元内：(1) 各智能体先独立观测并生成证据；(2) 提交承诺 `c_i = H(e_i, nonce_i, salt_i)`；(3) 收齐或超时后再揭示 e_i；(4) 校验承诺；(5) 才允许聚合。目的：切断「看到别人证据后再调整自己」的策略性从众，保住**条件**独立性。注意：它**不能**修复共享传感器 / 共享模型造成的统计相关，后者必须由 k_eff 显式建模——这是本轮最容易被混淆的一点。

**定义 316（疼痛加权共识 PWC）** 模态后验 `p(m|E) ∝ p(m) Π_i L_i(m)^{τ_i}`，τ_i 为标定可靠度。决策不是选「票最多的模态」，而是
`a* = argmin_a E_{m~p(·|E)}[ ℓ(m,a) ]`。
即共识的产物是一个**最小化期望痛的动作**，而不是一个赢家标签。异构群体里「一人一票」错在把可靠度当常数。

**定义 317（群体注意力分配 SAA）** 候选集 `C = {(i, g, B)}`（智能体 i 用信息动作 g 探痛点 B），边际疼痛下降 `Δ(i,g,B) = ρ_before(B) − E[ρ_after(B)]`。预算 B 下最大化 `Σ_{c∈S} Δ(c)`，s.t. `Σ cost(c) ≤ B`。在 A99（边际收益递减）下目标单调子模，贪心 + 惰性评估达 `(1−1/e)` 近似。

**定义 318（群体感应门 QSG）** 智能体 i 的局部可约疼痛 `Π_epi(s_i)` 连续 h 拍超过 θ_q 才升级为集体决议；低于 `θ_q^low < θ_q` 才降级为个体探询。迟滞避免集体 / 个体之间来回抖动的通信风暴。

**定义 319（拜占庭护甲 SBA）** 聚合前对沉积与证据做截尾均值 / 中位数；法定人数 `q ≥ q_quorum` 且揭示者数 `≥ 2f+1`（身份 / 证明绑定防女巫）；低信誉或被证伪的沉积降权或罚没 stake。安全通道的上分位与预算通道的中位数**分别**聚合，避免「为省预算而压低警报」。

**定义 320（群体干扰集 ℰ_swarm）** 疼痛膨胀（伪造高危点把群体引向陷阱 / 耗尽预算）、疼痛压制（把真痛点投票 / 衰减掉）、女巫与共谋（多身份刷票、协同伪造一致）、重放与陈旧毒化（复用过期沉积）、回音室（互相复制导致 k_eff→1）。并入 AIC：`ℰ_STING = ℰ_FLUID × ℰ_swarm × ℰ_field`。

**定义 321（疼痛反事实诊断 PCD）** 对已干预痛点 B 与其匹配对照 B'（相似状态、未干预），治疗效应 `τ = E[ΔΠ(B)] − E[ΔΠ(B')]`（difference-in-differences）。若 τ ≤ 0 或成本超预算，则下调 B 的先验、降权对应信息动作类型，并回灌 SAA 成本模型。**痛点必须被「治好」验证，不能只被「看到」验证**。

**定义 322（参与式审计 VQAuditor-S）** 审计对象新增群体决策：谁被加权 / 排除、k_eff 是否达标、场是否被单点操纵、法定人数是否真实独立、治疗是否有效。结论回灌 AuditBuf，作为下一轮 SAA 的成本与可靠性先验。

**定义 323（证书 J_STING）** `J_STING = (J_FLUID, pain_calibration_ece, hotspot_precision, k_eff_min, byzantine_bound, field_deviation_max, DiD_effect, sting_ver)`。Valid ⇔ Valid(J_FLUID) ∧ pain_ece ≤ τ_pain ∧ k_eff ≥ 2 ∧ field_dev ≤ δ_max ∧ 治疗通过 DiD 门。

**定义 324（对 R69 的严格包含）** 当 N=1、无沉积、无群体法定人数、且损失取 −log 后验的单调代理（A100）时，STING 的逐纪元决策与 FLUID-RAS 逐指令相同；R69 是「单智能体、无共享场、熵计量」的边缘情形。

**定义 325（能力-独立路由）** 用能力矩阵 `C_{i,g}`（智能体 i 执行信息动作 g 的期望信息增益）路由；但不得总是路由给同一个最强智能体——那会把 k_eff 压回 1。路由目标为最大化期望疼痛下降，约束 `k_eff ≥ 2`，即「能力强 + 来源散」。

**定义 326（共识延迟与纪元预算）** 一个决策纪元内允许一次承诺轮 + 一次揭示轮；若超时，使用上一纪元的场快照与本地证据，且消歧标记为「未完成」，按 R69 走保守退避。延迟不得导致已认证前缀过期。

```python
# IP-264 SPF：痛觉信息素与鲁棒疼痛场（签名 + 衰减 + 有限影响 + 非对称聚合）
class StigmergicPainField:
    def deposit(self, x, pi_hat, evidence, agent):
        d = dict(x=x, t=now(), pi=pi_hat, e_hash=sha(evidence),
                 sig=sign(agent, evidence), stake=agent.stake)
        self.ledger.append(d)                      # 只追加，不原地改

    def read(self, x, channel):                    # channel ∈ {safety, budget}
        ds = [d for d in self.ledger if self._verify(d)]
        vals = [exp(-LAM_P*(now()-d.t)) * K(norm(x-d.x)) * d.pi for d in ds]
        q = 0.9 if channel == 'safety' else 0.5    # 安全取上分位，预算取中位
        return cap_influence(quantile(vals, q), w_max)   # 单枚沉积影响有界

# IP-265 PAD：熵 -> 损失空间，得到可治的 Π_epi
def pain_decompose(agent, o, modes):
    rho_now  = bayes_risk(agent, o)                 # ρ(I)
    rho_star = bayes_risk(agent, agent.best_info_within_budget(o))  # ρ(I*)
    Pi_ale, Pi_epi = rho_star, rho_now - rho_star
    return Pi_ale, Pi_epi                           # 恒等分解

# IP-266 SAA：子模贪心分配（惰性评估），把预算投向最可治的痛点
def allocate(agents, hotspots, budget):
    C = [(i, g, b) for i in agents for g in info_actions(i) for b in hotspots
         if reachable(i, b) and cost(i, g, b) <= budget]
    S, spent, gain = [], 0.0, {}
    while True:
        c = argmax_lazy(C, key=lambda c: marginal(c, S))   # Δ 边际递减
        if c is None or spent + cost(*c) > budget or marginal(c, S) <= 0: break
        S.append(c); spent += cost(*c)
    return S                                        # A99 下 ≥ (1-1/e)·OPT

# IP-267 SEI：先承诺后揭示，再用 k_eff 量化“到底有几个独立证据”
class SealedEvidence:
    def commit(self, e):   return sha256(e + rand_nonce())
    def reveal(self, e, c): assert sha256(e + nonce_of(c)) == c; return e
    def k_eff(self, weights, probes):
        R = pairwise_corr_upper_bound(probes)       # 自证独立无效
        return sum(weights)**2 / quad_form(weights, R)

# IP-268 PWC：共识 = 后验 + 可靠度 + 最小期望痛，而不是多数票
def pain_weighted_consensus(E, reliability, loss):
    post = bayes_post(E, reliability)               # p(m|E) ∝ p(m) Π L_i(m)^τ_i
    return argmin_a(expected_pain(post, a, loss))   # 产物是动作，不是标签

# IP-269 QSG：群体感应门（迟滞，防抖）
def quorum_gate(pi_epi, state):
    if pi_epi > THETA_Q:      state.high += 1
    elif pi_epi < THETA_Q_LOW: state.high = 0
    return state.high >= H_ESCALATE                  # 连续 h 拍才升级集体

    # 2) 读共享疼痛场：安全通道宁可信其有
    hot_safety = field.hotspots(channel='safety')
    # 3) 封存证据：先承诺，后揭示，再量化有效独立数
    commits = {i: swarm.sei.commit(local[i].evidence) for i in swarm.agents}
    reveals = swarm.sei.reveal_all(commits)          # 超时者记为缺席
    k_eff   = swarm.sei.k_eff(swarm.weights, reveals)
    # 4) 子模分配：把有限预算投向最可治的痛点
    plan = allocate(swarm.agents, merge(hot_safety, local_hotspots(local)), B)
    # 5) 群体感应门 + 执行信息动作（每个 g 仍过 C-RAS-WM 认证）
    for (i, g, b) in plan:
        if quorum_gate(local[i].Pi_epi, swarm.gate[i]) and i.c_ras_wm.certify_info(g):
            swarm.execute(i, g, b)
    # 6) 疼痛加权共识；独立性或法定人数不足则不消解
    if k_eff < 2 or not swarm.sba.quorum(reveals, f):
        resolved = False
    else:
        resolved, m_star = True, pain_weighted_consensus(reveals, swarm.reliability, LOSS)
    # 7) 沉积疼痛（签名 + 证据哈希 + stake），供他人间接协调
    for i in swarm.agents:
        field.deposit(x=env.pose(i), pi_hat=local[i].Pi_epi,
                      evidence=reveals[i], agent=i)
    # 8) 逐智能体 R69 两级退避 + 各自认证前缀（安全包络不扩张）
    for i in swarm.agents:
        lam_i = r69_two_level_retreat(resolved, local[i].Pi_ale, local[i].Pi_epi)
        k_i   = i.c_ras_wm.certified_prefix(i.ach.propose(...), wm_preds)
        i.dispatch(k_i, lam_i)
    # 9) 反事实诊断：治疗窗口结束后核对“痛是否真的降了”
    swarm.pcd.update(plan, delta_pain_observed=env.measure_pain_delta(plan))
    swarm.vqa_s.submit_async(plan, k_eff, resolved, swarm.pcd.last_effect)
    return resolved, k_eff, plan
```

## 3. 推导

**引理 19（疼痛分解的恒等性与可治性）** 由定义 311，`Π = Π_ale + Π_epi` 恒成立。在 `I*` 已由预算内最优信息取得的前提下，对 Π_ale 追加信息预算的边际风险下降 ≤ 0；故正预算应全部投向 Π_epi。系：把 aleatoric 当可治，单位预算的期望收益 ≤ 0；把高频低危的虚荣痛当痛点，则不改善总风险、只推高成本——**痛点分析的第一原则是「先证明可约」**。

**引理 20（注意力分配的子模性与近似保证）** 在 A99（不同候选的信息有重叠，边际收益递减）下，集合函数 `F(S)=Σ_{c∈S}Δ(c)` 单调子模。带预算的贪心分配达到 `F(S_greedy) ≥ (1−1/e)·OPT`。若边际估计有误差 ε（标定误差、通信丢失），则 `F(S_greedy) ≥ (1−1/e)·OPT − ε·B`。系：群体注意力的收益不是「人多」，而是「**把预算投到边际痛最大的地方**」。

**引理 21（有效独立数与回音室）** 等权、两两相关 ρ 时
`k_eff = N / (1 + (N−1)ρ)`。
若广播 / 复制使 ρ ≥ 1/2，则对任意 N 有 `k_eff ≤ 1/ρ ≤ 2`，即**再加多少智能体也凑不出两个有效独立证据**。系：封存证据只切断策略性从众，切不断共享传感 / 共享模型的统计相关；因此必须显式估计 ρ_ij，并把 `k_eff ≥ 2` 作为硬门。推论：一个「永远一致」的群体在证据意义上等价于一个智能体。

**引理 22（拜占庭鲁棒聚合的偏差界）** 设诚实估计落在 [l,u]，N 个智能体中 f 个拜占庭。取中位数聚合时，若 `f < N/2`，中位数仍落在 [l,u]；截尾均值在 `f < N/3` 时同理。叠加单枚沉积上限 δ_max，则场偏差 ≤ `(u−l) + δ_max`。系：鲁棒聚合把「无界投毒」压成「有界偏移」，剩余风险交给 k_eff 门与反事实诊断。

**引理 23（疼痛场投毒的有限影响与共谋识别）** 由定义 313，`|ΔΠ̂| ≤ w_max·δ_max`；新增一个被认证的痛点至少需要 2 个证据哈希不同、签名的独立沉积。若这些沉积来自完全共谋的拜占庭（彼此 ρ=1），则其 `k_eff = 1 < 2`，被独立性门直接拒绝；若它们伪装成独立来源（伪造多样性），则由标定探针的一致率估计与 PCD 的治疗效应揭穿。系：**独立性门同时是反共谋门**——这解释了为什么 R69 的证据纪律必须升级为 k_eff。

**定理 18（STING 严格包含 R69 / FLUID-RAS）** 当 N=1、无沉积、无群体法定人数、损失取 −log 后验的单调代理（A100）时，Π_epi 与 U_epi 单调对应，SAA 退化为 R69 的单体 VoI 选择，PWC 退化为 R69 的模态选择，PCD 无对照则关闭。故 STING 的逐纪元决策与 FLUID-RAS **逐指令相同**；R69 是「单智能体、无共享场、熵计量」的边缘情形。安全侧不做任何让步。

**定理 19（安全包络不扩张与无突变）** 群体层只改变「选哪个信息动作、选哪个模态」；每个物理动作仍由各自的 C-RAS-WM 前缀认证（定义 310-i），故群体层不能扩大任何单体的安全包络。共识失败、通信超时、k_eff 不足、被投毒时，消歧标记为未完成，`λ` 单调不降地退化为 R69 的保守退避；决策纪元对齐（定义 310-iii、326）保证已认证前缀不被中途改写 ⇒ 控制连续、无突变。

**定理 20（群体注意力的端到端性能界）** 结合引理 20–23：在 A99、鲁棒聚合与 `k_eff ≥ 2` 门控下，STING 的期望疼痛下降 ≥ `(1−1/e)·OPT − ε·B − (u−l) − δ_max`，且该下界在 N=1 时退化为 R69 的 VoI 收益。系：群体的增益来自**独立性与注意力分配**，而不是单纯的成员数量；当 ρ→1 时增益归零（引理 21）。

## 6. 本轮最大风险

**一句话**：STING-RAS 把「相信自己的标定」升级成「**相信整群共享的疼痛图**」——而共享图是单点故障：一旦某处 Π̂ 被系统性偏差或投毒污染，封存证据只能证明「大家确实各自看到了」，不能证明「大家看到的是真的」，而广播又会把 ρ 推向 1、把 k_eff 压回 1，于是**独立性与纠错机制同时失效**：群体不是变聪明，而是集体自信地痛错了地方，或对真正的痛视而不见——**治错，比不治更危险**。

**次级风险与缓解**：
1. **疼痛指标 Goodhart**（只优化 Π̂ 而不优化真实损失）→ PCD 反事实门 + 对照热点 + 证书里的 pain_ece / DiD_effect；
2. **回音室 / 独立性塌缩**（k_eff→1）→ SEI 封存证据 + k_eff 硬门 + 能力-独立路由（定义 325）；
3. **场投毒（膨胀 / 压制）** → 签名 + 衰减 + 单点影响上限 + 鲁棒分位 + 独立证据哈希 + stake 罚没；
4. **共识延迟击穿实时** → 决策纪元对齐 + 超时用旧快照 + 未完成即走 R69 保守退避；
5. **治疗无效却持续消耗预算**（虚荣痛 / 无效干预）→ DiD 撤除 + 成本回灌 + 稀有事件单独通道，避免高频低危淹没低频高危。

**定义 321–323（反事实诊断、审计、证书）** DiD 治疗效应，痛没真降即撤干预；VQAuditor-S 审群体决策；J_STING 并入疼痛标定、热点精度、k_eff、拜占庭界、场偏差、治疗效应。

**定义 324–326（包含、路由、延迟）** N=1、无场、无群体法定人数、损失取熵代理时逐指令退化为 R69；能力-独立路由约束 k_eff ≥ 2；一纪元一次承诺 + 一次揭示，超时用旧快照并走 R69 保守。

## 3. 关键算法伪代码

```python
# IP-264 SPF：痛觉信息素场（签名 + 衰减 + 有限影响 + 非对称分位）
class StigmergicPainField:
    def deposit(self, x, pi_hat, evidence, agent):
        self.ledger.append(dict(x=x, t=now(), pi=pi_hat, e_hash=sha(evidence),
                                sig=sign(agent, evidence), stake=agent.stake))

    def read(self, x, channel):                     # safety / budget
        ds = [d for d in self.ledger if self._verify(d)]
        vals = [exp(-LAM_P*(now()-d.t)) * K(norm(x-d.x)) * d.pi for d in ds]
        q = 0.9 if channel == 'safety' else 0.5     # 宁可信其有 / 宁可信其无
        return cap_influence(quantile(vals, q), w_max)

# IP-265 PAD：熵 -> 损失空间，得到可治的 Π_epi
def pain_decompose(agent, o):
    rho_now  = bayes_risk(agent, o)
    rho_star = bayes_risk(agent, agent.best_info_within_budget(o))
    return rho_star, rho_now - rho_star              # Π_ale, Π_epi

# IP-266 SAA：子模贪心分配（惰性评估）
def allocate(agents, hotspots, budget):
    C = [(i, g, b) for i in agents for g in info_actions(i) for b in hotspots
         if reachable(i, b) and cost(i, g, b) <= budget]
    S, spent = [], 0.0
    while True:
        c = argmax_lazy(C, key=lambda c: marginal(c, S))   # 边际递减
        if c is None or spent + cost(*c) > budget or marginal(c, S) <= 0: break
        S.append(c); spent += cost(*c)
    return S                                          # A99 下 ≥ (1-1/e)·OPT

# IP-267 SEI：先承诺后揭示 + 有效独立数
class SealedEvidence:
    def commit(self, e):   return sha256(e + rand_nonce())
    def reveal(self, e, c): assert sha256(e + nonce_of(c)) == c; return e
    def k_eff(self, weights, probes):
        R = pairwise_corr_upper_bound(probes)        # 自证独立无效
        return sum(weights)**2 / quad_form(weights, R)

# IP-268 PWC：共识 = 后验 + 可靠度 + 最小期望痛
def pain_weighted_consensus(E, reliability, loss):
    post = bayes_post(E, reliability)                # ∝ p(m) Π L_i(m)^{τ_i}
    return argmin_a(expected_pain(post, a, loss))

# IP-269 QSG：群体感应门（迟滞防抖）
def quorum_gate(pi_epi, state):
    if pi_epi > THETA_Q:       state.high += 1
    elif pi_epi < THETA_Q_LOW: state.high = 0
    return state.high >= H_ESCALATE

# IP-274 STING-RAS 主闭环（在 R69 之上插入群体层；单体认证不变）
def STING_round(swarm, env, field):
    local = {}
    for i in swarm.agents:                           # 1) R69 前端 + 损失换算
        z_i, o_i = i.mtm.forward(...)
        U_ale, U_epi, modes = i.fluid_front(o_i)
        Pi_ale, Pi_epi = pain_decompose(i, o_i)
        local[i] = (z_i, o_i, modes, Pi_ale, Pi_epi)
    hot_safety = field.hotspots(channel='safety')    # 2) 读场：安全优先
    commits = {i: swarm.sei.commit(local[i].evidence) for i in swarm.agents}
    reveals = swarm.sei.reveal_all(commits)          # 3) 承诺-揭示
    k_eff   = swarm.sei.k_eff(swarm.weights, reveals)
    plan = allocate(swarm.agents,                       # 4) 子模注意力分配
                    merge(hot_safety, local_hotspots(local)), B)
    for (i, g, b) in plan:                           # 5) 感应门 + 认证执行
        if quorum_gate(local[i].Pi_epi, swarm.gate[i]) and i.c_ras_wm.certify_info(g):
            swarm.execute(i, g, b)
    if k_eff < 2 or not swarm.sba.quorum(reveals, f):   # 6) 独立性/法定人数门
        resolved = False
    else:
        resolved, m_star = True, pain_weighted_consensus(reveals, swarm.reliability, LOSS)
    for i in swarm.agents:                           # 7) 沉积疼痛供他人协调
        field.deposit(env.pose(i), local[i].Pi_epi, reveals[i], i)
    for i in swarm.agents:                           # 8) 逐体 R69 退避 + 认证前缀
        lam_i = r69_two_level_retreat(resolved, local[i].Pi_ale, local[i].Pi_epi)
        k_i   = i.c_ras_wm.certified_prefix(i.ach.propose(...), wm_preds)
        i.dispatch(k_i, lam_i)
    swarm.pcd.update(plan, env.measure_pain_delta(plan))  # 9) 反事实诊断
    swarm.vqa_s.submit_async(plan, k_eff, resolved, swarm.pcd.last_effect)
    return resolved, k_eff, plan
```

## 4. 推导

**引理 19（疼痛分解恒等性与可治性）** `Π = Π_ale + Π_epi` 恒成立。在 I* 已取得的前提下，对 Π_ale 追加信息的边际风险下降 ≤ 0，故正预算应全部投向 Π_epi。系：把 aleatoric 当可治，单位预算收益 ≤ 0；高频低危是虚荣痛——**先证明可约，再谈治疗**。

**引理 20（分配子模性与近似界）** A99（信息重叠 → 边际递减）下目标单调子模，带预算贪心达 `(1−1/e)·OPT`；边际估计误差 ε 时下界为 `(1−1/e)·OPT − εB`。系：群体注意力收益来自**把预算投到边际痛最大处**，不是「人多」。

**引理 21（有效独立数与回音室）** 等权两两相关 ρ 时 `k_eff = N/(1+(N−1)ρ)`；ρ ≥ 1/2 ⇒ 任意 N 都有 `k_eff ≤ 1/ρ ≤ 2`，即**再加人也凑不出两个有效独立证据**。系：一个「永远一致」的群体在证据意义上等价于一个智能体。

**引理 22（拜占庭聚合偏差界）** 诚实估计落在 [l,u]，f < N/2 时中位数仍在 [l,u]；f < N/3 时截尾均值同理。叠加单枚上限 δ_max，场偏差 ≤ `(u−l)+δ_max`。系：鲁棒聚合把无界投毒压成有界偏移。

**引理 23（投毒有限影响与共谋识别）** 单枚沉积 `|ΔΠ̂| ≤ w_max·δ_max`；新热点至少需 2 个独立签名的证据哈希。完全共谋者 ρ=1 ⇒ k_eff=1，被独立性门拒绝；伪装多样者由标定探针与 PCD 揭穿。系：**独立性门同时是反共谋门**。

**定理 18（严格包含 R69/FLUID）** N=1、无沉积、无群体法定人数、损失取 −log 后验单调代理（A100）时，Π_epi 与 U_epi 单调对应，SAA 退化为单体 VoI，PWC 退化为模态选择，PCD 关闭 ⇒ 逐指令相同。R69 是「单智能体、无共享场、熵计量」边缘情形。

**定理 19（安全包络不扩张与无突变）** 群体层只改信息动作 / 模态，物理动作仍由各自 C-RAS-WM 认证；共识失败 / 超时 / k_eff 不足 / 被投毒时 `λ` 单调不降地退化为 R69；纪元对齐保证已认证前缀不被中途改写 ⇒ 控制连续、无突变。

**定理 20（端到端性能界）** 在 A99 + 鲁棒聚合 + `k_eff ≥ 2` 门控下，期望疼痛下降 ≥ `(1−1/e)OPT − εB − (u−l) − δ_max`，N=1 时退化为 R69 的 VoI 收益。系：群体增益来自**独立性与分配**，ρ→1 时归零。

## 7. 本轮最大风险

**一句话**：STING-RAS 把「相信自己的标定」升级成「**相信整群共享的疼痛图**」——共享图是单点故障：一旦某处 Π̂ 被系统性偏差或投毒污染，封存证据只能证明「大家确实各自看到了」，不能证明「大家看到的是真的」，而广播又会把 ρ 推向 1、把 k_eff 压回 1，于是**独立性与纠错机制同时失效**——群体不是变聪明，而是集体自信地痛错了地方，或对真正的痛视而不见；**治错，比不治更危险**。

**次级风险与缓解**：疼痛指标 Goodhart（PCD 反事实门 + 证书 pain_ece / DiD）；回音室与独立性塌缩（SEI + k_eff 硬门 + 能力-独立路由）；场投毒膨胀 / 压制（签名 + 衰减 + 单点影响上限 + 鲁棒分位 + 独立证据哈希 + stake 罚没）；共识延迟击穿实时（纪元对齐 + 旧快照 + 未完成即走 R69 保守）；虚荣痛 / 无效干预（DiD 撤除 + 成本回灌 + 稀有事件单独通道）。
