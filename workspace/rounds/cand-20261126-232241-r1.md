（第 3 轮 · 灵感驱动研究循环；本轮灵感：「末端执行器控制」×「放置」）

> **基线**：第 2 轮产出 v23（HPC-E+ / CESC / FSVC / IPAM / CFC+++；上承 v22 分层能量 PGEV/ACSC/DCSC/HPC-E，v21 语义-规范层 SDC/CAC/DCL/GIC/HPC+，v20 联邦感知 PCA/CTS/CFC/HPC/CFCtrl 及 v19/v17 各模块）。
> 本轮纪律：**末端执行器是证书兑现的唯一物理出口，放置是世界模型的唯一写操作**。不推倒 v23：全部模块保留。本轮只做一件事：**在 v23 四证准入门之上加一层"具身接触-放置"层，把计划空间的集合包含兑现为末端的力/位约束（EERC），用接触力作感知无关的缺席证书证伪器（CFCC），并把"放置"这一唯一不可逆写操作建成带后置条件与空间账本的原子事务（PLC/SL/OLC）**。

## 0. 直觉与动机

**灵感 1（末端执行器控制 → 证书的"兑现"与物理回环）**
直觉：v20–v23 的证书都活在计划空间，证明某个计划集合安全/合规/能量可行，却从未回答"这些抽象保证如何在物理末端兑现"。末端执行器是唯一把 (位姿, 力) 命令施加到世界、也是碰撞真正发生的点。末端控制补上三件事：**（a）兑现映射 ρ**：把计划 π 编译为末端轨迹 (p_ee(t), f_ee(t))，安全须沿 ρ 保持（"证书保持编译"）；**（b）误差链**：末端位姿误差 ε_ee 是基座定位、关节编码器、运动学标定、工具偏置、跟踪误差经雅可比传播之和，给"工具球"一个可标定的膨胀半径；**（c）力/阻抗回环**：末端力传感器是一个**不依赖感知的接触 oracle**——直接测"有没有碰到"，恰好绕开视觉/点云"没检测到"的缺席幻觉。核心创新：**末端兑现证书 (EERC)** 与 **接触证伪证书 (CFCC)**。关键反直觉点：**证书链最脆弱的一环不在感知，而在"抽象集合包含→物理力/位"的编译；只要 ρ 不是证书保持的，v23 的全部证明都可能在末端失效**。

**灵感 2（放置 → 世界模型的唯一写操作与空间复式记账）**
直觉：v21 的 CAC 把自由空间当作只能被缺席证书赎回、障碍只能增补的**单调读**模型。但"放置"是第一个**写**操作：把物体放进某处，把"已认证自由空间"变成"占用"。这与单调律正面冲突，必须显式处理。放置还引入两类新证书：**前置条件**（目标区 AbsCert ∧ 抓取稳定 ∧ 释放轨迹清空）与**后置条件**（释放后稳定、不滚落、不进入人共享区）——后者是 v20–v23 从未有的"效果证书"。核心创新：**放置证书 (PLC)** 与 **空间账本 (SL)**：放置是**原子事务**——借（debit）目标自由格、贷（credit）一个障碍，且**物理释放与账本提交必须原子**（先提交-后释放-再核验）。关键反直觉点：**放置不创造自由空间，只搬移占用——"认证自由 + 占用 + 不确定"是守恒量；任何失败/未核验的放置只能把格子标记为"不确定"，绝不能标记为"自由"**。

**灵感 3（物体生命周期 → 抓取/携带/放置状态机与附着几何）**
直觉：物体抓取前后"障碍身份"改变：**Free（环境障碍）→ Grasped（附着于机器人，成为扫掠体积的一部分，原位置被释放）→ Placed（新环境障碍）**。抓取时原位置"释放"须被认证（伸手抓取本身要安全）；携带时物体进入机器人碰撞几何；放置时目标区须被认证为空。核心创新：**物体生命周期证书 (OLC)**。关键反直觉点：**"抓住"不是安全性的敌人而是盟友——物体一旦附着，就不再需要独立缺席证书，而成为机器人本体的一部分，只需管好扫掠体积；反之，释放是风险最大的瞬间，因为它把责任从"可控的附着"交还给"不可控的环境"**。

**三者如何统一**
统一为 **v23 之上的"具身接触-放置"层**：EERC 把计划兑现为末端轨迹并膨胀工具球；CFCC 用接触力做感知无关的证伪与阻抗限力（物理兜底）；PLC/SL/OLC 把放置变成带后置条件与空间账本的可审计写事务。共享状态 ζ_emb = ζ_ce ∪ (ρ, ε_ee, f_ee, L, s_obj, release_pred)。统一准入门：**HPC-EC = (HPC-E+, EERC, CFCC, PLC) 四证一体**——只有"抽象证书成立 ∧ 末端兑现保持 ∧ 接触回环无异常 ∧ 放置事务可提交"才允许执行/释放；任一缺失退回 v23，再退 v22…v18。接触证伪与账本原子性直接封堵 v21 以来最大的"合规缺席幻觉"。

## 2. 设计原则（在 P42 基础上新增 P43–P46）

**P43 证书兑现保持律（Certificate Realization Preservation）**
定义兑现映射 `ρ: Plan → Traj_ee`。EERC 要求 `∀π ∈ Exec_v23: ρ(π) ⊆ EEC_domain`，其中 EEC_domain 是"膨胀工具球 `B_ee(p_ee, r_tool + ε_ee) ⊆ 已认证自由空间"且"力剖面落在阻抗包络内"的末端轨迹集合。工具球膨胀与 CertBox/CertBox_arm 相加时取并（障碍只增）。证书保持编译：`Exec_v24 = {π ∈ Exec_v23 : ρ(π) ⊆ EEC_domain} ⊆ Exec_v23`。

**P44 接触即证伪律（Contact-as-Falsifier）**
末端力/力矩是独立 oracle。令期望力 `f_expected`（重力+惯性+计划接触），残差 `r_f = ‖f_meas - f_expected‖`。若 `r_f > τ_f` 且该接触位置/时刻未被计划预测为接触，则该处 AbsCert 被**证伪**：立即进入柔顺（阻抗刚度降至下限）并沿安全方向回撤，**与感知判断无关**。证伪是单调的：被证伪的 AbsCert 不得在无新证据（重新感知 + 观测窗/人工确认）下重新签发。故即使感知全错，接触后果也被 `f_max` 与响应时延上界约束。

**P45 放置即记账律（Placement-as-Ledger）**
放置是对空间账本 L 的原子事务：`debit(T)`（T 原属认证自由）+ `credit(T, obj)`（T 变为占用）。原子性 = 提交（pending）→ 执行释放 → 核验释放后占用（含滚动包络 R(T)）→ 终结（清 pending）或升级（核验失败则 T 与 R(T) 记为 Uncertain）。守恒不变量：`|Free_certified| + |Occupied| + |Uncertain| = |Domain|`；放置永不增加 `Free_certified`。任何不可核验结果 → `Uncertain`，绝不 `Free`。`Exec_v24` 只含放置事务可提交（O1–O5 可清偿）的计划。

**P46 物体生命周期律（Object Lifecycle）**
物体状态 `s_o ∈ {Free, Grasped, Placed, Uncertain}`，迁移受证书门控。Grasped：物体并入机器人碰撞几何 `V_robot ∪ V_obj`，原格释放仅在抓取接近本身 EERC 认证通过时允许；Placed：贷记账本且须满足后置稳定；Uncertain：任一失败迁移（滑落/抓空/未核验释放）→ 保守占用。迁移记入 merkle 审计链。

## 3. 与基线的接口（如何退化）

- EERC 失效（ε_ee 不可靠 / 近奇异）⇒ 冻结末端快速运动，仅静态位姿 ⇒ 子集；
- CFCC 失效（力传感器故障）⇒ 失去物理兜底，禁用接触型放置（仅自由空间释放）并退回 v23 感知 ⇒ 子集；
- PLC 失效（目标区/后置不可核验）⇒ 禁止放置（保持抓取或回巢）⇒ 子集；
- SL 失效 ⇒ 所有目标格视为 Uncertain ⇒ 禁止放置 ⇒ 子集；
- OLC 失效 ⇒ 禁止抓取（物体保持 Free 障碍）⇒ 子集；
- 全部失效 ⇒ 完全回退 v23 ⇒ `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18`（引理 162）。
- **安全继承**：EERC 只膨胀工具球（障碍只增）、CFCC 只减许可并加回撤、PLC 只借自由/贷占用（从不创造自由）、OLC 只加保守占用；任意失效都向更保守方向退化。状态机以事件方式接入 v17 APS 新鲜度阶梯，控制路径仅 O(1) 查询。

## 4. 预期贡献

1. **证书保持兑现**：首次给出从计划空间到末端力/位的证书保持编译 ρ，以及基座-关节-标定-工具-跟踪误差链的可标定上界，使 v23 的抽象证明在物理末端可兑现；
2. **接触证伪**：首次把末端力传感作为缺席证书的**感知无关物理证伪器**，给出有界后果（非零碰撞）的显式保证，直接封堵贯穿 v21–v23 的"合规缺席幻觉"；
3. **放置账本与原子提交**：首次把放置形式化为世界模型的唯一非单调写操作，给出"认证自由 + 占用 + 不确定"守恒律与"提交-释放-核验-升级"原子协议；
4. **物体生命周期证书**：给出 Free/Grasped/Placed/Uncertain 状态机与附着物体碰撞几何，明确"抓取是盟友、释放是风险"；
5. **效果证书**：从"前置安全"扩展到"后置效果"（放置后稳定、不滚落、不进入共享区），补上"动作是否达成意图效果"的验证维度；

## 5. 本轮最大风险

**一句话**：放置账本是基于**部分可观测下的预测后置状态**提交的，若释放动力学（滑移/滚动/倾覆）超出 conformal 界、物体滚出目标区 T 且落入核验未覆盖的相邻自由格，账本会留下一片**幽灵自由空间**——把"本该让世界模型诚实的机制"变成静默、可审计的世界模型污染源。

## 1. 关键算法骨架（在 IP-436–439 骨架上扩展）

```python
# ============================================================
# IP-440 End-Effector Realization Certificate (EERC)
# ============================================================
@dataclass
class EEState:
    q: np.ndarray            # 关节配置
    p_ee: np.ndarray         # 末端位姿（命令值）
    f_meas: np.ndarray       # 实测 wrench (6,)
    f_expected: np.ndarray   # 由计划导出的期望 wrench
    t: float

class EndEffectorRealizationCertificate:
    def __init__(self, r_tool, eps_base, eps_joint, eps_kin,
                 eps_tool, eps_ctrl, kappa_max=50.0):
        self.r_tool = r_tool
        self.eps_base, self.eps_joint = eps_base, eps_joint
        self.eps_kin, self.eps_tool, self.eps_ctrl = eps_kin, eps_tool, eps_ctrl
        self.kappa_max = kappa_max

    def jacobian(self, q): ...

    def condition_number(self, q):
        return float(np.linalg.cond(self.jacobian(q)))

    def eps_ee(self, q) -> float:
        """末端误差上界：一阶雅可比传播 + 固定项"""
        J = self.jacobian(q)
        return (self.eps_base + np.linalg.norm(J, 2) * self.eps_joint
                + self.eps_kin + self.eps_tool + self.eps_ctrl)

    def realize(self, plan) -> list[EEState]:
        """ρ: 把计划离散化为末端轨迹"""
        return [EEState(q=..., p_ee=..., f_meas=..., f_expected=..., t=...)
                for ... in plan.discretize()]

    def is_certificate_preserving(self, plan, free_space) -> bool:
        """EERC(ρ(π))：近奇异拒绝 + 膨胀工具球全含于认证自由空间"""
        if self.condition_number(plan.q0) > self.kappa_max:
            return False                       # 近奇异：冻结证书
        for st in self.realize(plan):
            r = self.r_tool + self.eps_ee(st.q)
            if not free_space.contains_ball(st.p_ee, r):
                return False
        return True


# ============================================================
# IP-441 Contact Falsification & Compliance Certificate (CFCC)
# ============================================================
class ContactFalsificationCertificate:
    def __init__(self, tau_f=5.0, f_max=40.0, T_sense=0.02,
                 retreat_dir_fn=None):
        self.tau_f, self.f_max, self.T_sense = tau_f, f_max, T_sense
        self.retreat_dir_fn = retreat_dir_fn
        self.falsified_cells: set = set()      # 单调证伪集合

    def residual(self, st: EEState) -> float:
        return float(np.linalg.norm(st.f_meas - st.f_expected))

    def _predicted(self, st, planned_contacts) -> bool:
        return any(contact.contains(st.p_ee, st.t) for contact in planned_contacts)

    def _localize_contact(self, st) -> str:
        """把接触定位到被证伪的覆盖格（用于作废 AbsCert）"""
        return self._cell_of(st.p_ee)

    def step(self, st: EEState, planned_contacts) -> tuple[str, dict | None]:
        if self.residual(st) > self.tau_f and not self._predicted(st, planned_contacts):
            cell = self._localize_contact(st)
            self.falsified_cells.add(cell)     # 证伪单调不可撤销
            return "FALSIFIED", self._compliance_retreat(st, cell)
        return "OK", None

    def _compliance_retreat(self, st, cell):
        """阻抗刚度降至下限 + 沿安全方向回撤，力上限 f_max（物理兜底）"""
        return {"stiffness": "min", "force_cap": self.f_max,
                "retreat": self.retreat_dir_fn(st.p_ee, cell),
                "bounded_displacement": self._v_max * self.T_sense}

    def can_reissue(self, cell, new_evidence) -> bool:
        """证伪后重新签发 AbsCert 需新证据（重新感知 + 观测窗/人工确认）"""
        return cell in self.falsified_cells and new_evidence.window_ok


# ============================================================
# IP-443 Space Ledger (SL) — 空间复式记账
# ============================================================
class SpaceLedger:
    def __init__(self, domain_cells):
        self.domain = set(domain_cells)
        self.Free = set(domain_cells)          # 认证自由
        self.Occ: dict = {}                    # 占用: cell -> object_id
        self.Unc: set = set()                  # 不确定

    def invariant(self) -> bool:
        """守恒：认证自由 + 占用 + 不确定 = 全域"""
        return len(self.Free) + len(self.Occ) + len(self.Unc) == len(self.domain)

    def begin_debit(self, T):
        if not set(T).issubset(self.Free):
            raise PlacementRejected("target not certified free")
        return {"debit": set(T), "pending": True}

    def commit_credit(self, T, obj_id):
        self.Free -= set(T)
        for c in T:
            self.Occ[c] = obj_id

    def mark_uncertain(self, cells):
        self.Free -= set(cells)
        self.Unc |= set(cells)


# ============================================================
# IP-442 Placement Certificate (PLC) — 前置+后置义务与原子提交
# ============================================================
class PlacementCertificate:
    def __init__(self, ledger: SpaceLedger, eerc, cfcc, stability_checker,
                 tau_verify=0.5):
        self.ledger, self.eerc, self.cfcc = ledger, eerc, cfcc
        self.stability = stability_checker
        self.tau_verify = tau_verify

    def obligations(self, plan, T, obj) -> dict:
        return {
            "O1_target_free": set(T).issubset(self.ledger.Free),
            "O2_grasp_stable": plan.grasp_margin > 0,
            "O3_release_clear": self.eerc.is_certificate_preserving(
                plan.release, plan.free_space),
            "O4_post_stable": self.stability.predict(obj, T).stable,
            "O5_ledger_atomic": True,        # 由 commit-verify-escalate 保证
        }

    def committable(self, plan) -> bool:
        return all(self.obligations(plan, plan.T, plan.obj).values())

    def execute(self, plan) -> str:
        T, obj = plan.T, plan.obj
        ob = self.obligations(plan, T, obj)
        if not all(ob.values()):
            return self._fallback(plan, ob)        # 不放置（保持抓取/回巢）
        self.ledger.begin_debit(T)                 # 1. 账本预提交(pending)
        self._actuate_release(plan)                # 2. 物理释放
        if self._verify_post(T, obj):              # 3. 核验后置占用（含 R(T)）
            self.ledger.commit_credit(T, obj.id)   # 4. 终结：贷记占用
            return "PLACED"
        # 核验失败：目标区与滚动包络一律不确定，绝不自由
        self.ledger.mark_uncertain(set(T) | self._rollout_envelope(T, obj))
        self._escalate(plan)                       # 可审计升级（非静默死锁）
        return "UNCERTAIN"

    def _verify_post(self, T, obj) -> bool:
        """核验释放后物体确实落在 T（否则触发升级）"""
        return self._perceive_occupancy(T) == obj.id

    def _rollout_envelope(self, T, obj):
        """R(T)：按释放动力学预测的滚动/滑移可达包络"""
        return self.stability.rollout_reachable(T, obj)


# ============================================================
# IP-444 Object Lifecycle Certificate (OLC)
# ============================================================
class ObjectLifecycle:
    def __init__(self):
        self.state: dict = {}                  # obj_id -> s_o
        self.vol: dict = {}                    # obj_id -> V_obj
        self.audit: list = []                  # merkle 迁移链

    def transition(self, obj, src, dst, cert_ok: bool):
        if self.state.get(obj, "Free") != src:
            return "ILLEGAL"
        new = dst if cert_ok else "Uncertain"
        self.state[obj] = new
        self.audit.append((obj, src, new))
        return new

    def attached_volume(self, robot_volume):
        """Grasped 物体并入机器人碰撞几何；Free/Placed/Uncertain 不入"""
        return union(robot_volume,
                     [v for o, v in self.vol.items()
                      if self.state.get(o) == "Grasped"])

# IP-446 Place-and-Handoff Intent Bridge (PHIB)
# ============================================================
class PlaceAndHandoffIntentBridge:
    def __init__(self, gic, ledger):
        self.gic, self.ledger = gic, ledger

    def handoff_allowed(self, plan, human_zone) -> bool:
        """交接放置：高门槛许可 + 目标区 AbsCert + ≥2 模态佐证"""
        return (self.gic.permission_high(plan.intent)          # Γ ⊆ {交接}, 1-α
                and set(plan.T).issubset(self.ledger.Free)      # 目标区缺席证书
                and self.gic.modality_count(plan.intent) >= 2)


# ============================================================
# IP-445 HPC-EC 统一四证准入门
# ============================================================
@dataclass
class HPCECGate:
    hpc_e_plus: 'HPCEPlus'
    eerc: EndEffectorRealizationCertificate
    cfcc: ContactFalsificationCertificate
    plc: PlacementCertificate

    def admits(self, plan, x, v, z, E_res, margin_req, modules,
               free_space) -> bool:
        # 1. v23 四证：几何∧规范∧负信息∧能量∧差距∧云边∧少样本∧IP
        if not self.hpc_e_plus.admits(plan, x, v, z, E_res, margin_req, modules):
            return False
        # 2. 末端兑现保持（含近奇异冻结）
        if not self.eerc.is_certificate_preserving(plan, free_space):
            return False
        # 3. 接触回环无异常（有异常即拒绝并触发柔顺回撤）
        status, _ = self.cfcc.step(plan.current_state, plan.planned_contacts)
        if status == "FALSIFIED":
            return False
        # 4. 放置事务可提交
        if plan.is_placement and not self.plc.committable(plan):
            return False
        return True

            return False, info

        st = sensor["ee_state"]

        return ok, {"plan": plan if ok else None, **info}
```

## 3. 正确性论证

### 引理 5（兑现保持单调性）
**陈述**：`Exec_v24 ⊆ Exec_v23`。

**证明**：`HPCECGate.admits` 首先要求 `hpc_e_plus.admits`（即 π ∈ Exec_v23），随后追加 EERC/CFCC/PLC 三个连言条件；任一不满足即拒。故 `Exec_v24 = Exec_v23 ∩ {EERC ∧ CFCC ∧ PLC} ⊆ Exec_v23`。工具球膨胀只增大障碍、CFCC 只拒绝或回撤、PLC 只借自由/贷占用，均不扩大执行域。∎

### 引理 6（接触证伪的有界后果，而非零碰撞）
**陈述**：若力传感器功能正常且发生未被计划预测的接触，则在 `T_sense` 内控制器进入柔顺并施加力上限 `f_max`；接触冲量满足 `∫ f dt ≤ f_max·T_sense + Δp·k_min`，且回撤位移 `≤ v_max·T_sense`。

**证明**：CFCC 在 `r_f > τ_f` 且非计划接触时立即触发（P44），阻抗刚度降至下限使接触力饱和于 `f_max`；响应延迟上界为 `T_sense`，期间最大位移由接近速度 `v_max` 界定；柔顺段附加能量由最小刚度 `k_min` 与压缩量 `Δp` 界定。故后果有界，但**不保证零碰撞**——这是物理兜底与逻辑证书的本质区别。∎

### 引理 7（账本守恒与无幽灵自由，条件性）
**陈述**：若每次放置都核验目标区 `T` 且把滚动包络 `R(T)` 一并核验或标记为 `Uncertain`，则 `Free_certified` 在任意放置序列下单调不增，且不会出现"被放置物占据却仍标记为 Free"的格子。

**证明**：`commit_credit` 只从 `Free` 移除 `T` 并写入 `Occ`；`mark_uncertain` 只从 `Free` 移除并写入 `Unc`；两者都不向 `Free` 增加任何格子。守恒式 `|Free|+|Occ|+|Unc|=|Domain|` 在每次事务后保持。若 `R(T)` 未覆盖（物体滚出核验区），则 `R(T)\Coverage` 中的格子可能仍为 `Free` 而实际被占——这正是本引理的**前提被违反**时的剩余风险（见第 6 节）。∎

### 引理 8（生命周期障碍单调）
**陈述**：跨 Free→Grasped→Placed→Uncertain 迁移，与碰撞相关的障碍集合单调不减（在把附着物体并入机器人扫掠体积的意义下）。

**证明**：Grasped 时 `V_robot ← V_robot ∪ V_obj`，扫掠体积只增；原格释放仅在抓取接近经 EERC 认证时发生，且释放的是机器人已确认可安全进入的区域。Placed 时目标区由 `Free` 转为 `Occ`（障碍只增）。Uncertain 一律按占用处理。故障碍集合不会因生命周期迁移而减小。∎

### 定理（HPC-EC 四证一体的安全-兑现-物理兜底-可写完备性）
**陈述**：对任意计划 π，`HPCECGate.admits(π) = True` ⟺ π 同时满足：
(1) v23 全部条件（几何∧规范∧负信息∧能量∧差距∧云边∧少样本∧IP），
(2) 末端兑现保持（`ρ(π) ⊆ EEC_domain`，含近奇异冻结），
(3) 接触回环无未预测异常（否则被证伪并回撤），
(4) 若为放置，则 O1–O5 可清偿且账本事务可原子提交。

**证明**：由 `admits` 的四个连言条件与引理 5–8 直接可得；单调退化链 `Exec_v24 ⊆ Exec_v23 ⊆ … ⊆ Exec_v18` 由引理 5 与各层只收缩性质归纳成立。∎

| R1 | 释放后物体滚出核验区，相邻自由格成"幽灵自由" | 最高 | 1) 核验 `R(T)` 滚动包络；2) `R(T)` 超出覆盖即整片标 `Uncertain`；3) 释放后强制二次观测窗 | 包络预测本身可能低估极端弹跳/滚动 |
