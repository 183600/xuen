# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配歧义消解闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「双臂协调」×「创新点提炼」×「结构优化」）

> R69 把不确定性一分为二：aleatoric 交给 λ_floor 收紧，epistemic 交给「流匹配 + 主动交互」消解，并用两条通道（残差 r_res、似然 Δa）互为第二意见。但整套机器仍是**单臂的**：不确定性是一个标量 U，交互是「一方向另一方提问」，安全包络是单个 λ。真实操作常常是**双臂/人机共握**：两条手臂共享一个物体、一个工作空间、一次交接——「我的不确定」会通过物体**传染**给对方，最大的歧义不再是「绕左还是绕右」，而是「**谁主谁从、谁持谁操作、何时交接**」。R69 的交互词汇表（看/问/触）在共握场景下还缺最锋利的一条：**通过共同握持的物体进行触觉协商**——对方是顺从还是抵抗，就是回答本身。
>
> 另一个灵感是内向的：五轮叠层（R66 权威、R67 预测、R68 标定、R69 消歧）已到必须**提炼**的时点。把五轮创新点排开看，它们是同一模式的五个实例：**每个不确定性来源 → 一个信念对象 → 一组可预算的查询动作 → 一个退化为上一轮的兜底**。提炼出该模式（QBF 四元组），本轮就能做真正的**结构优化**：把串行塔改成「统一接口 + 退化链」，让组合正确性由链式归纳保证，而不是每层重新证明——双臂协调恰好是检验该接口的第一个新领域。
>
> 核心命题：**把 FLUID-RAS 从单臂标量不确定性升级为双臂耦合不确定性图；角色格（role lattice）是双臂特有的 epistemic 对象，触觉协商是双臂特有的查询动作，交接窗是双臂特有的危险时刻（λ 同步收紧）；并用 QBF 四元组把 R66–R70 提炼成一个可组合、可归纳证明的统一结构。** 命名 **DUET-RAS**（Dual-arm Uncertainty-coupled Epistemic Tightening）。
>
> 一句话定位：R69 问「我该向谁求证、还能问什么」，R70 问「**我们俩该怎么商量着做**」——协调不是两条轨迹的避让，而是两个不确定性预算的谈判；谈判的产物是一个被双方证据共同锚定的角色。

## 0. 直觉与动机

**灵感 1（双臂协调 → 不确定性从标量变成图）**
直觉：单臂时 λ 是标量，收紧就是全部。双臂共持一个物体时，A 臂对「往哪边倒水」的歧义会立刻变成 B 臂必须承受的力学扰动；A 臂的慢变故障会伪装成 B 臂眼里的「对方手抖」。所以双臂系统的不确定性不是数，而是**一张带耦合边的图**：节点是各臂的 (U_ale, U_epi, λ)，边是 shared-object / shared-workspace / handoff。耦合的处置原则是 R68 铁律的图版本：**耦合只收紧，不放松**——λ_i ← max(λ_i, W_ij·λ_j)。协调的本质不是避让，是预算的传染与同步。

**灵感 2（角色格 → 双臂特有的 epistemic 对象）**
直觉：R69 在动作轨迹上聚类得到的模态是「绕左/绕右」；在**联合**动作空间聚类，模态有了社会学结构：**角色**。共握倒水要么 A 持 B 倾、要么 B 持 A 倾、要么共运；主从关系决定谁的 λ 应该大、谁该执行 R69 的交互。角色歧义是双臂任务里占主导的 epistemic 不确定性，而它**离散、可枚举、可校准**——比通用动作模态更容易做 ECE。R69 的 mode_head 升级为 role_head。

**灵感 3（触觉协商 → 共握给出的独有信息通道）**
直觉：R69 的信息动作是看、问、轻触环境。人机共握时有一条物理上更近的通道：A 臂经物体施加预算内小扰动（ε_n，几十毫秒），对方响应——顺从（跟随位移）或抵抗（反力）——直接区分「跟随者」与「主导者」。其独特性：(a) 人在发力/专注时常不看、不答，但力响应总在；(b) SNR 可由刚度对比显式推导：k_lead 与 k_follow 差多少，协商就有多可信，而软物体/软人手会摧毁该假设——所以必须带门控（引理 20）。双臂协调由此不只是「多一只手」，而是**给 R69 的交互词汇表增加一个物理对话回合**。

**灵感 4（创新点提炼 → 五轮叠层是同一模式的五个实例）**
直觉：把 R66–R70 的创新点排成表，会看到重复结构——**QBF 四元组**：Believe（信念对象：权威分布 / 未来轨迹 / 标定残差 / 动作模态 / 角色后验）+ Query（预算内查询动作：仲裁信号 / WM rollout / 跨模态残差 / 看·问·触 / 触觉协商）+ Budget（时延 / 视野 / 重标定窗 / 交互预算 / 协商预算）+ Fallback（查询全禁用时输出逐指令等于上一轮）。R68 的 λ_floor 铁律是该结构的**不动点**（Chain_0）。提炼四元组后，「信任一个新层」不再需要审计一个新黑箱，只需审计一条义务：**fallback dominance（禁用查询 ⇒ 行为 = 上一层）**。

**灵感 5（结构优化 → 从串行塔到退化链，及双臂新攻击面）**
直觉：串行塔的结构性缺陷 R69 自己承认过——「每加一层就多一个需要独立信任的黑箱」。QBF 化后，正确性论证从「逐层独立证明」变为「链式归纳 + 单一义务」，此为本轮的结构优化。同时双臂带来新攻击面：角色幻觉（一臂 role_head 幻觉出「对方在跟随」）、不对称漂移（一臂慢变故障被对方误读为意图——R69 的 Δa 在双臂下需要第三条通道：**耦合残差**）、握持欺骗（grip deception：故意放松/僵直伪造「我已放手」或「我在跟随」）。证据纪律随之扩展：触觉协商**不得单独定案角色**，需 haptic+gaze 或 haptic+ask 两个正交源一致——否则 R69 的「单次交互不定案」纪律在双臂下会被握持欺骗击穿。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（DUET-RAS 总览）** DUET-RAS = (JFP, RLC, CPL, HNG, HWM, QBF†, RAS-WM†)。五不变式：
(i) 实时流零学习写操作（继承 R68–R69）；
(ii) 交互与协商预算硬约束（继承 R69 定义 293-ii，新增协商力预算 ε_n、时长 τ_n）；
(iii) 证据纪律（继承，扩展：触觉协商不得单独定案角色，需 ≥2 正交源）；
(iv) **耦合只收紧**：∀i, λ_i ≥ W_ij·λ_j（W 来自耦合图辨识，定义 314）；
(v) **交接窗同步**：handoff 窗口内 λ_L = λ_R = max(λ_L, λ_R)，双包络联合认证。

**定义 311（联合动作空间与耦合图）** ξ = (ξ_L, ξ_R) ∈ 𝒜_+^L × 𝒜_+^R（每臂含任务动作 + R69 信息动作）。耦合图 G_c = ({L,R}, E)，边带类型与强度：shared-object（W_so(t) 由接触状态估计）、shared-workspace（碰撞约束进 C-RAS-WM 认证）、handoff（W=1 全同步）。

**定义 312（角色格 RLC）** 双臂角色分配 ρ ∈ {HH(共持静止), HO_L, HO_R(单持单操作), CT(共运), LF_L, LF_R(主从)}，|ρ|=6 起步、任务级可扩展。角色后验 w(ρ|o_t) 由联合流模态聚类得到（定义 313）。角色歧义 H_ρ = −Σ_ρ w_ρ log w_ρ 是双臂主导 epistemic 量。

**定义 313（联合流策略 JFP）** 联合速度场 v_θ(x_s, s | o_t, ŵ_ρ^{t−1})（条件含上一帧角色后验，保证角色时间平滑）；采样 K 个**联合**轨迹块，Fréchet/DTW 聚类得联合模态，映射到角色格得 w_ρ。role_head(z_t) 廉价预测 H_ρ 决定是否升 K（继承 R69 定义 308）。

**定义 314（耦合收紧传播 CPL）** λ_i ← max( λ_floor(U_ale^i + 未消解 U_epi^i), max_j W_ij(t)·λ_j, λ_floor(couple-carry(U_j→i)) )，其中 couple-carry 把 j 臂歧义经物体动力学传函折算为 i 臂必须承受的扰动上界。W 辨识误差 ‖Ŵ−W‖ ≤ δ_W（A101），δ_W 以保守方向（上界）进入。

**定义 315（触觉协商 HNG）** g_neg = (d̂ ∈ S², f ≤ ε_n, τ ≤ τ_n)：经物体施加小扰动。响应特征 y = (位移跟随率, 反力积分, 恢复速度)。角色似然 p(y|ρ) 由刚度对比参数化（A100：主导刚度 k_lead 与跟随刚度 k_follow 之差 ≥ κ_min 时可辨识）。协商收益 VoI_neg = H_ρ − E_y[H_ρ|y, g_neg]；k 差不足 ⇒ VoI_neg 置信区间含 0 ⇒ 不协商、走保守（引理 20）。

**定义 316（交接窗监视 HWM）** 交接事件 = 接触状态切换（单持↔双持↔移交）。HWM 用 WM 预测交接窗 [t0,t1]（A102：检测召回/精度 ≥ 1−η）；窗内：λ 同步（定义 310-v）、双臂包络联合认证、禁止发起其他信息动作（预算让路给交接）、交接前后速度连续性检查（定理 19）。

**定义 317（QBF 四元组接口，创新点提炼产物）** UQ = (Believe, Query, Budget, Fallback)：Believe 输出信念对象与不确定性度量；Query 在 Budget 内执行查询并贝叶斯更新；Fallback 是「Query 全禁用」的实现，必须**逐指令等于链上上一层**（fallback dominance 义务）。五层实例化：
| 链 | Believe | Query | Budget | Fallback |
|---|---|---|---|---|
| Chain_0 = R68 | 标定残差 U_cal | 无（不动点：铁律） | — | λ_floor |
| Chain_1 = R69 | 动作模态 (U_ale,U_epi) | 看/问/触 | 交互预算 | Chain_0 |
| Chain_2 = R70 | 角色后验 w_ρ | 触觉协商（+R69 全部） | 协商预算 | Chain_1（单臂独立 W≡0） |

**定义 318（退化链与信任义务）** Chain_d 的正确性证明义务只有一条：禁用全部 Query ⇒ 输出 = Chain_{d−1}（逐指令）。组合安全性由归纳：Chain_0 铁律 + 链式 fallback dominance ⇒ 全链安全侧永不弱于 R68（定理 18）。**结构优化**：审计与证书机制（AuditBuf、J_*、AIC）在链上共享一份，不再逐层复制。

**定义 319（双臂干扰集）** ℰ_DUET = ℰ_FLUID × ℰ_bi，ℰ_bi = {role hallucination（role_head 幻觉角色）, asymmetric drift（单臂慢变故障被误读为对方意图）, grip deception（故意放松/僵直伪造跟随/主导）, negotiation spoofing（对协商扰动注入假响应）, handoff mistiming（交接时机误判）}。

**定义 320（双臂证书 J_DUET）** J_DUET = (J_FLUID, role_ece, W_id_error, handoff_log_hash, negotiation_p95, chain_ver)。Valid ⇔ Valid(J_FLUID) ∧ role_ece ≤ τ_rce ∧ W 误差 ≤ δ_W ∧ 交接窗预算未越界。

**定义 321（角色校准门 RCG + 耦合辨识门）** role ECE > τ_rce ⇒ 禁用协商与角色驱动决策，退化为「两个独立 FLUID」（W≡0）；W 辨识误差 > δ_W ⇒ 耦合退化为保守上界 W=1（全同步、最紧）——**耦合不确定时，宁可全同步也不放任**。

**定义 322（双臂预算）** 单位时间信息动作总数 ≤ 2（两臂合计），其中协商 ≤ 1；ε_n、τ_n 硬上限；交接窗内只允许交接本身消耗预算。所有信息动作过 C-RAS-WM 认证（继承 R69 定义 302）。

**定义 323（证据纪律扩展）** 角色定案需 ≥2 正交源一致：(haptic, gaze)、(haptic, ask) 或 (gaze, ask)；haptic 单源只提供似然。与 R69 引理 18 同构：k 源欺骗相关 ρ<1 时错误采纳率 ≤ δ_p·ρ^{k−1}+ε_σ。

**定义 324（联合模态校准）** role 权重可靠图与 ECE；校准集来自标注的交接/协商 episode，**离线积累、在线只读**——保持零学习写操作不变式。

**定义 325（时序与自适应 K）** K=1 常规（role_head 门控），联合空间歧义时 K=4（两臂同步采样）；协商触发允许一次性预算超支（与 R69 同策略）；交接窗内禁升 K（交接优先守时）。

**定义 326（三通道对偶，双臂版）** 每臂保留 (r_res^i, Δa^i)（R69 定义 301/309）；新增**耦合残差** r_cpl = ‖预期接触闭合差 − 实测‖：若故障只在一臂，r_res^i 不动但 r_cpl 失衡、且 Δa 在**另一臂**上升（故障被对方当作「世界变了」）。三通道联合模式 (r_res^i↓, Δa^j↑, r_cpl↑) 判别「单臂缓变故障伪装成协调意图」——R69 对偶引理（定义 309）在图上的推广。

# IP-264 JFP：联合流策略（两臂共享速度场，条件含上一帧角色后验）
class JointFlowPolicy:
    def __init__(self, trunk2, velocity_net, role_head, N_step=2):
        self.trunk, self.v = trunk2, velocity_net      # 双臂联合编码 z_t
        self.role_head = role_head                     # z -> H_ρ 廉价预测

    def sample(self, o_t, w_prev, K, N_step=2):
        z  = self.trunk(o_t, w_prev)
        xs = randn(K, D2)                              # D2 = 2*D1 联合动作块
        for i in range(N_step):                        # Heun，rectified
            s  = i / N_step
            xs = xs + (1.0/N_step) * self.v(xs, s, z)
        return [self.decode(x) for x in xs]            # ξ = (ξ_L, ξ_R)

# IP-265 RLC：联合模态 → 角色格
def role_decompose(samples):
    modes = cluster_joint(samples)                     # Fréchet / DTW
    w_rho = map_to_role_lattice(modes)                 # 模态映射到 6 角色格
    return w_rho, entropy(w_rho), modes

# IP-266 CPL：耦合只收紧的不动点传播
def coupled_lambda(lam_L, lam_R, U_L, U_R, What, delta_W):
    W_up = What + delta_W                              # 辨识误差保守向上
    lam_L = max(lam_floor(U_L), W_up[RL]*lam_R, lam_L)
    lam_R = max(lam_floor(U_R), W_up[LR]*lam_L, lam_R)
    return lam_L, lam_R                                 # 2 臂 1 轮收敛（引理 19）

# IP-267 HNG：触觉协商（力预算内的物理提问）
def haptic_negotiate(w_rho, obj_dyn, budget):
    d_hat = argmax_dir(voi_neg(d, w_rho, obj_dyn))     # 最能区分主/从的方向
    if snr(d_hat, obj_dyn) < KAPPA_MIN: return None    # 刚度差不足→不问（引理 20）
    if not budget.allow_neg() or not c_ras_wm.certify_info(d_hat, EPS_N): return None
    return execute_perturb(d_hat, f=EPS_N, tau=TAU_N)  # 跟随率/反力/恢复速度；只作似然

# IP-268 HWM：交接窗监视
def handoff_monitor(wm_preds, contact_state):
    return wm_predict_handoff_window(wm_preds, contact_state)   # [t0,t1]

# IP-269 QBF：统一四元组接口 + 退化链（创新点提炼的结构产物）
class UQNode:
    def __init__(self, believe, query, budget, fallback): ...
    def step(self, obs):
        b = self.believe(obs)
        if self.budget.ok() and self.gate_ok(b):
            b = self.update(b, self.query(b))          # 证据纪律在 update 内
        return self.fallback.step(obs) if self.disabled(b) else self.act(b)
    # 信任义务：disabled(b) 为真时，本节点输出必须逐指令等于 fallback.step(obs)

# IP-274 主闭环（继承 FLUID_RAS_round，插入耦合/协商/交接）
def DUET_RAS_round(M, obs):
    z, o = M.trunk2.forward(obs)                       # 双臂联合一次前向
    c, U_cal, thr = M.cof.step(...)                    # R68 标定照常
    K = 1 if M.jfp.role_head(z) < TAU_ROLE else 4      # 廉价角色歧义门控
    w_rho, H_rho, modes = M.rlc.role_decompose(M.jfp.sample(o, M.w_prev, K))
    # 三通道故障判别（定义 326）
    slow_bi = M.fma.three_channel(M.last_r_res, M.last_da, r_couple(obs))
    t0, t1 = M.hwm.window(M.wm_preds, M.contact)
    in_handoff = (t0 <= M.t <= t1)
    # 查询决策：角色歧义 + 非故障 + 不在交接窗；协商优先，退看/问
    g = None
    if H_rho > TAU_RHO and not slow_bi and not in_handoff:
        g = M.hng.haptic_negotiate(w_rho, M.obj_dyn, M.budget) \
            or M.mint.choose_interaction(modes, o, M.budget)
    if g is not None:
        w_rho = M.cia.update_belief(w_rho, M.cia.execute(g), discipline='k>=2')
    # λ：本臂地板 + 耦合传染 + 交接同步

    if in_handoff: lam_L = lam_R = max(lam_L, lam_R)   # 定义 310-v
    ks = [M.c_ras_wm.certified_prefix(M.ach.propose(m.a_i, M.vista.H), M.wm_preds)
          for m in select_roles(modes, w_rho)]

## 3. 推导

**引理 19（耦合收紧的不动点与单调性）** 两节点 max-更新 λ_i ← max(λ_i, W_ij λ_j)，W ∈ [0,1]^{2×2}，任意初值 1 轮内收敛到各臂 λ ≥ 解耦值的定点，且对 W 单调（W 增大只会更紧）。要点：max-半环上迭代幂等、2 节点无环——**协调在结构上不可能放松安全**（定义 310-iv 的证明）。

**引理 20（触觉协商的 SNR 下界与门控）** 设主导者等效刚度 k_lead、跟随者 k_follow，协商力幅 f ≤ ε_n，力噪 σ_F。以「位移跟随率」判别主从的检测 SNR ≥ (k_lead − k_follow)·f / (σ_F·√τ_n)（A100）。故存在阈值 κ_min：k 差 < κ_min 时 VoI_neg 置信区间与 0 相交，协商被门控关闭——**模糊不可辨时不问，直接保守**（R69 引理 16 的双臂版）。

**引理 21（QBF 链式退化）** 对 Chain_d，若 fallback dominance 义务成立，则「禁用全部 Query」时 Chain_d 输出与 Chain_{d−1} 逐指令相同。归纳于 d：Chain_1=R69 的「永不交互」边界已证（R69 定理 16）；Chain_2 在 W≡0 且协商禁用时逐指令退化为两个独立 Chain_1。系：全链禁查询 = R68。

**定理 18（DUET ⊇ FLUID ⊇ CALM，期望风险单调）** A99–A102 下，若各节点 Query 的 VoI 估计在预算内无偏、门控（RCG/耦合辨识门/协商 SNR 门）有效，则 Chain_2 任意状态期望风险 ≤ Chain_1 ≤ Chain_0；且当（协商 SNR < κ_min）∨（role ECE > τ_rce）∨（W 误差越界）∨（slow_bi）∨（非交接窗预算耗尽）时，逐指令退化为下链。安全侧不让步，效率侧来自「角色歧义被真实消解」的 resolution bonus。

**定理 19（交接安全与无突变）** 交接窗内 λ 同步 + 双包络联合认证 + 前后速度连续性检查 ⇒ (a) 双臂互不越包络（无碰撞）；(b) 物体受力闭合差 ≤ ε_cpl（不掉落）；(c) 窗界处控制信号连续（λ 在窗界只取 max，无跳变）。与 R68 定理 15 换装不变式同构，由 max-更新的连续性直接得到。

## 8. 本轮最大风险

**一句话**：DUET-RAS 押在三前提上——「双臂交互可压缩为小角色格（A99）」「刚度对比可辨识（A100）」「耦合图 W 可辨识（A101）」——任一被真实共握破坏（连续角色混合、软物体/软人手、故障臂伪装意图），系统就会在错误的耦合模型上做一次自信的物理协商：把噪声读成回答、把故障读成意图；双臂把 R69 的「被证实的错误」升级为「**被施加的错误**」——协商的手比问错的嘴更难收回。

**次级风险与缓解**：耦合放松（引理 19 + 定义 310-iv）；握持欺骗（定义 323 + E306）；交接守时（窗内禁升 K + E310）；角色幻觉（RCG + E308）；W 误辨（δ_W 保守 + 越界退 W=1 + E312）。
