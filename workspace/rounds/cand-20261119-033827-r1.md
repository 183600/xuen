# 第 1 轮（UniBot 线 · 本轮灵感：「阻抗控制」×「论文创新点」）

> **连续性声明**：本线沿用上一版 UniBot-SAGE 的四条硬结论，不推倒重来：①终态成功是唯一计分货币（teaser 上 step≈1.337·succ+0.09，R²=0.9955）；②跨任务专长准正交，单 checkpoint 内技能路由有 +4.26 的 oracle 上界；③断点在最后的对齐/插入/释放；④"做得快"没有红利（任务内 corr(dur,succ)≈−0.011）。
> 本轮把两个新透镜装到同一骨架上：
> - **「阻抗控制」**把上一版"抓握确认"之后的**接触阶段**，从开环位置执行升级为**可控的视在柔顺**：不再只问"抓住没有"，而是问"接触之后，机器人以多大的视在刚度去迎合几何约束"。
> - **「论文创新点」**是一次元认知校准：先问"这篇论文的 claim 是什么、prior art 是什么、什么实验能杀死它"，再决定做什么。它逼我们把"阻抗控制"这个老概念从"照搬"改写成"受限接口下的可部署机制 + 可观测性 + 无害包络"。
>
> 编号继续累加：定义 **U13–U22**、引理 **L8–L13**、实验 **E619–E632**；上一版 U1–U12 / L1–L7 / E601–E618 保留引用，不重复展开。情报基线沿用 2026-11-17 的核实结果，**本轮不新增对外事实断言**。

## 0. 先给直觉：三个画面

**画面 1 · "抓稳"解决的是手里有没有东西，"柔顺"解决的是东西能不能进去。**
上一版把抓取从开环赌注变成带置信度的隐变量，这是对的；但 teaser 榜最难的六个任务（Plug In Ethernet 17.7、Unlock 20.1、Spell robot 21.8、Organize Stationery 22.5、Open Pill Bottle 22.7、Pick Out Battery 23.3）里，有一半根本不是"没抓住"，而是"抓住了、对准了、最后一厘米进不去"。位置控制越硬，几毫米的对准误差就被放大成几十牛的侧向力，插头/瓶盖/电池就被顶住、卡死、弹开。人手的做法相反：接触瞬间变软，让倒角/孔沿把零件"导"进去。

**画面 2 · 接口只给位置，但"柔顺"不一定要力矩指令。**
官方 `control_space ∈ {joint, ee}`，动作是位置目标；没有力矩/力控字段，观测里也没有触觉。这意味着我们不能直接下发 `τ = JᵀF`。但阻抗控制的本质不是"发力矩"，而是**控制位移与力的关系**。在位置接口上，这可以拆成两条可实现的路径：
- **参考级柔顺**：不改底层控制器，只改我们下发的参考轨迹——接触时让参考"让路"（retreat / 减速 / 侧向搜索），用运动本身模拟低刚度；
- **视在刚度整形**：把策略的期望位姿 `x_d` 经过一个各向异性柔顺算子，输出 `x_r`；横向软、轴向硬（软件 RCC），但**不假设**能直接读力。
两条路径都只需要位置指令 + 对"接触是否发生"的估计。于是问题从"能不能力控"变成"能不能无传感器地看见接触"。

**画面 3 · 论文创新点不是"我用了阻抗控制"，而是"我在一个不允许力控的接口上恢复了柔顺，并且能证明它何时安全"。**
阻抗控制（Hogan 1985）、RCC（Whitney 1982）、螺旋搜索都是几十年前的东西。审稿人一定会说"这不是新控制律"。所以本轮必须把创新点钉在三件更窄、更可证伪的事情上：
1. **接口层的机制**：在 position-only、无触觉、chunked、黑盒 VLA 的约束下，用**参考级视在柔顺**恢复接触鲁棒性；
2. **可观测性**：把"指令-观测残差"标定成接触概率，给出 AUROC 与"高精度工作点"（FPR≤2% 时的 TPR），而不是假设有触觉；
3. **无害包络**：用门控 + 被动性 + 回退，证明柔顺层在检测不到接触时退化为基线，不会把"能成功的任务"改坏。
如果这三点立不住，"阻抗控制"就只是工程；如果立住了，它才是一个可发表的、跨策略可复用的贡献。

**合成的一句话直觉**：上一版把**抓握**变成隐变量；本轮把**接触**变成隐变量，并把"接触之后有多软"变成可调、可观测、可回退的控制变量。抓握决定"有没有"，柔顺决定"进不进得去"。

## 1. 为什么是现在：上一版留下的五处接缝

| 上一版的结论/组件 | 留下的接缝 | 本轮补丁 |
|---|---|---|
| IP-02 抓握确认：`g_t` 只判"抓住/没抓住" | 抓住了但插不进，`g_t` 仍是高置信 | 引入接触相 `z_phase=contact` 与视在刚度 `K(t)`；抓握成功 ≠ 任务成功 |
| IP-03 chunk 缝合：保证 C0 连续 | 缝合只处理"继续往前走"，不处理"接触后该退/该搜" | 缝合器增加 `compliance` 状态：退让/搜索动作也必须在 chunk 边界连续 |
| IP-06 六因子：reach/grasp/transport/align/insert/release | align/insert 被当成一个因子，无法区分"对不准"与"对不准但太硬" | 把 insert 条件化在 `K` 上：`P(insert \| contact, K)`；柔顺是因子间的调节器 |
| IP-01 技能路由：任务 × 阶段 token | 阶段 token 没有"接触"这个相位 | `z_phase` 增加 contact 子状态；专家可选择"接触专家" |
| L1 时长与成功无关 | 这条被当成"不要提速"的约束 | 反过来用：**时间不是货币** ⇒ 柔顺层可以用更慢的插入/搜索换成功率，不付分数代价（L11） |

## 2. 本轮自建的机制实验（先说清楚：不是基准证据）

真机时段稀缺，不能拿"插不进"这种假设直接上真机烧时段。我先写了一个**声明式**的二维倒角孔插入模拟（`exp/impedance_rcc_sim.py`），只回答四个机制问题：柔顺有没有用、最优刚度是不是内点、接触能不能无传感器看见、各向异性是否必要。模型是显式声明的（刚性倒角壁、过阻尼轴向、常数侧向偏置、法向力上限卡死），**没有拟合任何榜单数字**，所以下表只用于**生成假设**，不作为基准证据。

关键结果（N=20,000 episodes/条件，完整表见产物区 §7）：

| 侧向误差 σ_e | 最优 k_lat | 最优成功率 | 刚性 k=1e4 成功率 | 增益 | 接触检测 AUROC |
|---|---|---|---|---|---|
| 0.04 | 100 | 1.000 | 0.728 | **+0.272** | 0.972 |
| 0.07 | 180 | 0.992 | 0.464 | **+0.528** | 0.975 |
| 0.10 | 180 | 0.943 | 0.340 | **+0.603** | 0.983 |

三条读法：
- **刚性是系统性劣势**：误差越大，刚性越差；这与 teaser 榜"插入/旋转类最差"同向，但**这是模型内的同向，不是因果证据**。
- **存在内点最优**：太软会被侧向偏置推出倒角捕获区（miss），太硬会力超限卡死（jam）；最优在 `k* ≈ N_jam/w` 附近。
- **接触可见**：只用"指令深度 vs 观测深度"的偏置校正残差，AUROC 0.97–0.98；在 FPR≤2% 的工作点上，σ_m=2mm 时 TPR=0.927，σ_m=4mm 时 0.858。

还有一个**负面结果**，对"论文创新点"很重要：**各向异性（横向软、轴向硬）相对均匀软化没有可测增益**（匹配横向刚度时，成功率差 ≤0.005）。这直接否掉了我原本想写的"软件 RCC 的轴向各向异性是关键"这一子 claim。论文只能主张"横向柔顺"，不能主张"RCC 各向异性"。这是本轮元认知透镜的第一个产出：**先杀死一个漂亮但站不住的子 claim**。

## 3. 从直觉到严格命题

### 3.1 接口与视在柔顺的严格定义

**定义 U13（位置型动作接口）**：策略输出 `a_t = (q^ref_{t+1:t+T}, w^ref)`；底层控制器是未知的稳定映射 `C: q^ref → q`，跟踪误差有界：`‖q − q^ref‖ ≤ ε`。没有力矩/力字段。

**定义 U14（参考级视在柔顺）**：设策略期望位姿为 `x_d`，接触概率估计为 `ĉ`，参考生成器输出
`x_r = x_d + K(ĉ)⁻¹ f̂_ext`，
其中 `f̂_ext` 是外部力估计（有力矩观测时用动量观测器；没有时置零，改用运动策略 `R_motion`：退让 / 减速 / 搜索）。在无力的退化形态下，U14 变成"用运动模拟柔顺"的规则库。

**定义 U15（各向异性视在刚度）**：在任务坐标系（插入轴由语言 + 目标物体估计）中 `K = diag(k_lat, k_lat, k_ax)`，通常 `k_lat ≪ k_ax`。但本轮模拟显示：**收益主要来自 `k_lat` 的降低，而不是 `k_ax` 的保持**；所以 `K` 的各向异性是工程选择，不是论文 claim。

**定义 U16（接触可观测量）**：`r_t = ‖W(q_t − q^ref_t)‖`，`W` 归一化不同量纲；用前 `m` 步（假设无接触）估计偏置 `b̂`，检测分数 `s_t = |r_t − b̂|`；`P(contact|s_t)` 由可校准的分类器给出（可靠性图）。

**定义 U17（接触相位）**：`z_phase=contact` 当 `P(contact|s_t) > τ_c` 连续 `n_h` 步；带迟滞，避免抖动。

**定义 U18（柔顺调度）**：`K(t) = K_free`（自由空间，高刚度）→ `K_contact`（接触，低横向刚度）；切换只在 chunk 边界，带最小驻留时间。

**定义 U19（搜索原语）**：接触后若 `n_stall` 步无进展，执行螺旋/侧向抖动 `x_d(t) = x_c + A(t)[cos ωt, sin ωt]`，`A(t)` 衰减，法向速度设上限；搜索半径/幅度有上限。

**定义 U20（被动性与无害包络）**：参考生成器不得向系统注入净能量（或注入量有界），`k_lat ≥ k_min`、搜索幅度 `≤ a_max`、退让距离 `≤ d_max`；任一条件不满足 → 回退基线。

**定义 U21（抓握-柔顺联合签名）**：`s_t = f(g_t, r_t, Δgrip_t)`；滑移表现为 `g_t` 下降 + 残差振荡，作为 IP-02 的"随臂运动"信号的补充。

**定义 U22（贡献台账）**：一个把"claim → prior art → falsifier → 实验 → 最小证据"逐行对齐的研究对象；没有对应 falsifier 的 claim 不得进论文。

### 3.2 三个可证伪的 claim

- **C1（机制）**：在 position-only 接口上，横向参考柔顺能把倒角插入的成功率从刚性基线的 `p0` 提到 `p1 > p0`，且最优刚度是内点。
  - **falsifier**：E620/E621 在 6 个最难插入任务上 `p1 − p0 ≤ 0`，或曲线单调（无内点）。
- **C2（可观测性）**：接触可由"指令-观测残差"在 FPR≤2% 下以 TPR≥0.8 检出（σ_m≤4mm）。
  - **falsifier**：E619 的 TPR@FPR2% <0.6，或可靠性图非单调。
- **C3（与容量正交）**：柔顺增益不依赖于基座策略更强；弱策略的增益 ≥ 强策略的增益。
  - **falsifier**：E629 中强策略增益 ≥ 弱策略，或柔顺增益与"换更大模型"的增益不可区分。

**不主张的（negative claims）**：
- N1：不主张"各向异性 RCC 是关键"（本轮模拟已否掉）。
- N2：不主张"这是新的控制律"（它是 wrapper）。
- N3：不主张"适用于所有接触任务"（只主张倒角插入/旋转类；自由形态灵巧操作不在范围内）。

## 4. 研究问题（本轮）

- **Q1（接触可观测性）**：在没有力矩/触觉的位置接口上，跟踪残差能不能把接触估成带校准的隐变量？其精度在什么噪声/控制增益下失效？
- **Q2（柔顺的兑现）**：横向柔顺在 6 个最难插入任务上能兑现多少？是"只在接触相位生效"还是"全程软化"？搜索原语的边际收益是多少？
- **Q3（无危害）**：高精度接触门控（FPR≤2%）能不能保证"检测不到就不干预"，从而 26 个非接触任务不回归？
- **Q4（与容量正交）**：把同一个 wrapper 套在强/弱两个基座策略上，增益是否随基座变强而消失？这决定论文的"机制 vs 容量"claim。
- **Q5（论文边界）**：哪些子 claim 必须砍掉（如各向异性），哪些必须保留（横向柔顺、可观测性、无害包络）？最小可发表单元是什么？

## 5. 设计原则（在 P1–P6 上增补）

- **P7 接触优先于抓握**：抓握确认只回答"有没有"，接触相回答"进不进得去"；两者共用残差通道，但门控分开。
- **P8 软在横向，硬在轴向，但只为工程服务**：各向异性是默认配置，不是论文 claim；消融必须报告"均匀软化 vs 各向异性"的差。
- **P9 论文 claim 必须带 falsifier**：每个 claim 先写"什么结果会杀死它"，再写实验；没有 falsifier 的 claim 不进产物区。
- **P10 时间是可花的预算**：既然时长与成功无关（L1），柔顺/搜索可以更慢；但必须监控 180s episode 上限与超时率。

## 6. 最小可提交闭环（MVP v2）

MVP = 上一版 MVP（IP-06 代理评测 + IP-02 抓握确认 + IP-03 chunk 缝合 + 通用 VLA 基线）+ **IP-09 接触观测** + **IP-10 柔顺整形**，且默认 **compliance off**（只有检测到接触且置信度足够才开）。

退化链（在上一版 Level-0..4 上增加）：
- Level-5 接触检测不可用 ⇒ 柔顺层彻底关闭，退回刚性基线；
- Level-6 搜索原语不可用 ⇒ 只保留"减速 + 退让"，不搜索；
- Level-7 柔顺导致回归（A/B 变差）⇒ 按任务簇关闭，保留审计记录。

**一个合规要点**：搜索/退让必须由**接触事件**触发，不能由**任务名**触发；否则会被视为"读题硬编码"，撞上 P5 红线与"动作规律性"审核。

## 7. 论文创新点：把"做了什么"翻译成"新在哪里"

### 7.1 贡献分层

| 层 | 内容 | 是否新颖 | 证据 |
|---|---|---|---|
| 机制 | 位置接口上的参考级横向柔顺 | 组合新颖（阻抗控制老，接口约束新） | 模拟 + 真机 A/B |
| 观测 | 指令-观测残差 → 校准接触概率 | 较新（该接口下没人系统做过） | 可靠性图 / AUROC / TPR@FPR |
| 系统 | 门控 + 被动性 + 回退 + 审计 | 工程贡献 | 无害性 A/B |
| 实证 | 柔顺增益与基座容量正交 | 有条件的实证贡献 | 跨策略实验 |

### 7.2 审稿人最可能的两句话，以及我们的回应

- **"这不就是阻抗控制 + 螺旋搜索吗？"**
  - 回应：不主张新控制律；主张的是**在 position-only、无触觉、黑盒 VLA 接口下的可部署形态**，以及**接触可观测性**和**无害包络**这两件该接口特有的技术问题。经典 RCC 需要专用柔顺腕；我们没有，只能用参考级柔顺 + 残差观测去逼近。
- **"收益是不是只是换了个更强的模型？"**
  - 回应：E629 跨策略；如果增益随基座变强而消失，就承认是容量问题，并砍掉 C3。

### 7.3 最小可发表单元（MPU）

一张机制图（成功率 vs 横向刚度，三条误差曲线，显示内点最优）+ 一张真机表（6 个最难任务 on/off + 26 个任务无害性）+ 一张校准图（AUROC / TPR@FPR）+ 一张跨策略图。**负面结果（各向异性无增益）作为附录/讨论**，不单独成文。

## 8. 本轮最大风险（一句话）

**若位置接口的"指令-观测残差"主要反映底层控制器自身动态而非接触，接触检测就会退化为随机开关，柔顺层既拿不到物理收益、也撑不起"可观测性"这一创新点。**

- **深化**：把接触检测从"单通道残差"升级为"残差 + 视觉穿透 + 夹爪开合"的三通道校准融合；把搜索原语从固定螺旋升级为按倒角几何估计的定向搜索。

## 0. 本轮结论摘要

**一句话路线**：上一版把"抓握"变成隐变量；本轮把"接触"变成隐变量，并给接触相配一个**可在 position-only 接口上部署的视在柔顺层**：
**接触观测（IP-09）→ 柔顺调度 + 搜索（IP-10）→ 被动性/门控/回退（U20）→ 审计（承接 IP-08）**。

**三条量化依据（本轮自建机制模拟，非基准）**：

| 证据 | 数值 | 推出的设计 |

## 2. 创新点详述

### IP-09 · ContactSense 无传感器接触观测（P0）

- **动机**：官方接口只给位置型动作（`joint` 或 `ee`），观测里没有力矩、没有触觉；而 teaser 榜的断点在插入/旋转的最后一厘米（Plug In Ethernet 17.7、Unlock 20.1、Open Pill Bottle 22.7）。如果看不见"接触发生没有"，任何柔顺/搜索都无从触发。
- **与现有方案的差异**：现有 VLA 提交把动作块开环执行，接触是隐式的；我们把它显式化为一个**可校准的观测问题**：用"我们下发的参考"与"评测端回传的观测"之间的残差作为接触信号，先用前 `m` 步估计自由空间偏置 `b̂`，再用偏置校正残差 `s_t=|r_t−b̂|` 做分类。它不是一个新的端到端网络，而是**零训练/轻训练的可观测性层**。
- **技术可行性**：高。`q^ref` 是我们自己发的，`q` 在 `observation.state.*` 里；两者时间对齐后即可算残差。已有的官方 `run_client.py` 可复刻评测端的执行/插值语义（承接上一版 IP-03 步骤①），先确认"参考→实际"的延迟与插值，再做校准。
- **所需资源**：数据 = 官方数据回放 + 少量真机日志；算力 = 单 CPU / 单卡分钟级（logistic 或 isotonic 校准）；接口 = 纯策略内部逻辑，不新增字段。
- **落地步骤**：
  1. 在官方 client 上记录每一步的 `q^ref`、`observation.state.*`、时间戳、chunk 边界；
  2. 特征 = {横向残差、轴向滞后、残差一阶差分、夹爪开合速率、chunk 边界标志}；
  3. 用前 `m` 步（默认 25）估计偏置 `b̂`，之后用偏置校正残差；
  4. 校准：isotonic/Platt 回归 + 可靠性图；阈值取"非接触样本的 98 分位"，即 FPR≤2%；
  5. 迟滞：连续 `n_h=3` 步超阈值才置 `contact`，连续 `n_h` 步低于下阈值才退出；
  6. 跨任务/跨端口验证：每端口独立偏置，防止串扰；
  7. 导出可靠性图与 TPR@FPR2% 作为审计产物。
- **风险**：①残差被底层控制器动态主导（最大风险，见 §11）；②观测延迟/插值导致时间对齐错位；③偏置在"一开始就接触"的 episode 上估不准。缓解：多通道融合（视觉穿透 + 夹爪）、延迟估计、偏置估计失败时退回"不触发柔顺"（保守）。

### IP-10 · ComplianceShaper 参考级横向柔顺 + 搜索（P0）

- **动机**：位置控制越硬，对准误差→侧向力放大越厉害，插入越容易卡死；而上一版已证明"时长与成功无关"（L1），所以用更慢的插入/搜索换成功率**不付分数代价**（L11）。这是把"时间预算"变成"成功率预算"的最直接方式。
- **与现有方案的差异**：现有做法是"把动作块开环执行到底"；我们在参考级插入两层：
  1. **柔顺调度**：自由空间用 `K_free`（高横向刚度，保证跟踪/抗扰），检测到接触后切到 `K_contact`（低横向刚度，让倒角把零件导进去）；切换只在 chunk 边界，带最小驻留时间；
  2. **搜索原语**：接触后若 `n_stall` 步无进展，执行衰减螺旋/侧向抖动，法向速度设上限；搜索半径/幅度有上限。
  两者都不需要力矩指令，只改我们下发的位置参考，因此**可在任意基座策略上外挂**。
- **技术可行性**：高（纯动作后处理 + 状态机）；难点不在算法，而在**确认底层控制器语义**与**无害性**。
- **所需资源**：算力 = <1 ms/步；数据 = 无（用回放做连续性自检）；接口 = `control_space` 声明 + 动作后处理；合规 = 需在 README/metadata 声明"接触触发的柔顺/搜索"，但仍是单 checkpoint、单 API。
- **落地步骤**：
  1. 复刻评测端语义（承接 IP-03 步骤①）：确认 chunk 如何执行、是否插值、是否重置控制器；
  2. 实现准静态参考柔顺：`x_r = x_d + K⁻¹ f̂_ext`；无 `f̂_ext` 时用运动策略（减速/退让/搜索）；
  3. 实现接触相位调度 + 迟滞（U17/U18）；
  4. 实现搜索原语（U19）与被动性包络（U20）；
  5. 在 6 个最难任务做 on/off A/B；在 26 个其余任务做无害性 A/B；
  6. 与 IP-03 缝合器统一状态机：退让/搜索动作也必须 C0 连续；
  7. 导出审计看板：接触概率、刚度调度、搜索幅度、超时/降级次数。
- **风险**：①横向太软会被未建模的侧向力（线缆/重力/摩擦）推离倒角捕获区（模拟已显示 miss）；缓解：`k_min` 下限 + 偏置估计 + A/B 定标；②搜索可能碰倒其它物体；缓解：单物体场景才搜索、幅度上限、禁区；③与缝合器冲突；缓解：统一状态机 + 边界连续性断言；④超时；缓解：搜索步数/幅度上限 + 超时监控；⑤被判"脚本化/非通才"；缓解：接触事件触发、任务无关、保留"全程低横向刚度"的保守形态。

### IP-02′ · GraspVerify 的滑移签名扩展（P1）

- **动机**：滑移（抓住了但没抓稳）是插入失败的另一个来源；纯视觉/夹爪标量在快速运动时不够早。
- **增量**：在 IP-02 的三信号（腕部几何 / EE 随动 / 夹爪开合）之外，加一路**柔顺残差振荡**：当 `K_contact` 生效时，滑移表现为残差的高频振荡 + `g_t` 下降 + 夹爪开合漂移。用 `s_t=f(g_t, r_t, Δgrip_t)`（U21）做联合判定。
- **验收**：滑移检测 AUROC ≥0.85；比纯视觉早 ≥0.2s；不增加误报（FPR≤2%）。
- **风险**：柔顺会改变残差分布，可能把"正常接触"误判为"滑移"；用接触相位做条件，只在 `contact` 且 `K_contact` 生效时启用。

### IP-03′ · ChunkStitch 的柔顺状态连续性（P1）

- **动机**：上一版缝合器只保证"继续往前走"的 C0 连续；退让/搜索是反向/侧向动作，缝合规则不同。
- **增量**：在缝合器里增加 `mode ∈ {advance, retreat, search, hold}`；不同 mode 用不同的末端速度估计与外推；切换只在块边界，带最小驻留时间；搜索动作的边界用位置连续 + 速度上限，而不是一阶外推。
- **验收**：边界 jerk 不劣于上一版；0 次 ACTION REJECTED；退让→前进的切换不产生尖峰。
- **风险**：mode 切换抖动；用迟滞 + 最小驻留时间。

### IP-06′ · 六因子的条件化分解（P1）

- **动机**：上一版把 align/insert 合成一个因子，无法回答"是对不准，还是对不准但太硬"。
- **增量**：把 `P(insert)` 写成 `P(insert | contact, K)`；在代理评测里对同一批 episode 做 on/off 柔顺的反事实标注（或用接触相位 + 刚度调度做条件分层）；报告"align 失败"与"contact 后失败"的分离。
- **验收**：分解在 3 个种子下稳定；因子排序一致率 ≥0.8；能稳定地区分"pre-contact 失败"与"post-contact 失败"。
- **风险**：阶段标签噪声；用双标注器一致性检查（承接 IP-06）。

## 3. 符号与定义（U13–U22）

| 符号 | 含义 |
|---|---|
| `q^ref_t` | 第 t 步下发的参考位姿/关节目标 |
| `q_t` | 评测端回传的实际位姿/关节状态 |
| `x_d` | 策略期望的任务空间位姿 |
| `x_r` | 柔顺层输出的参考位姿 |
| `K(ĉ)` | 视在刚度矩阵（任务坐标系） |
| `ĉ_t` | 接触概率估计 |
| `r_t` | 指令-观测残差范数 |
| `b̂` | 自由空间残差偏置估计 |
| `s_t` | 偏置校正后的接触检测分数 |
| `τ_c` | 接触判定阈值（取 FPR≤2%） |
| `z_phase` | 相位 token，新增 `contact` 子状态 |
| `K_free / K_contact` | 自由空间 / 接触相的视在刚度 |
| `R_motion` | 无力估计时的运动柔顺策略（减速/退让/搜索） |
| `A(t), ω` | 搜索螺旋的幅度/角频率 |
| `k_min, a_max, d_max` | 被动性包络的下限/上限 |
| `C1–C3 / N1–N3` | 论文的正面 claim / 不主张的 negative claims |

**定义 U13（位置型动作接口）**：`a_t = (q^ref_{t+1:t+T}, w^ref)`；底层控制器 `C: q^ref → q` 未知但稳定，`‖q − q^ref‖ ≤ ε`；无扭矩/力字段。

**定义 U14（参考级视在柔顺）**：`x_r = x_d + K(ĉ)⁻¹ f̂_ext`；`f̂_ext` 不可得时置零，改用 `R_motion`。这是"用参考轨迹模拟柔顺"的一般形式。

**定义 U15（各向异性视在刚度）**：任务坐标系中 `K = diag(k_lat, k_lat, k_ax)`；默认 `k_lat ≪ k_ax`，但**各向异性不是论文 claim**（见 N1）。

**定义 U16（接触可观测量）**：`r_t = ‖W(q_t − q^ref_t)‖`；`b̂ = mean_{t≤m}(r_t)`（假设前 m 步无接触）；`s_t = |r_t − b̂|`；`P(contact|s_t)` 由校准器给出。

**定义 U17（接触相位）**：`z_phase=contact` 当 `P(contact|s_t) > τ_c` 连续 `n_h` 步；退出用下阈值 `τ_c' < τ_c`，带迟滞。

**定义 U18（柔顺调度）**：`K(t) = K_free` 若 `z_phase≠contact`，否则 `K_contact`；切换只在 chunk 边界且满足最小驻留时间 `n_dwell`。

**定义 U19（搜索原语）**：若 `contact` 且连续 `n_stall` 步 `Δs_t < ε_s`，令 `x_d(t) = x_c + A(t)[cos ωt, sin ωt]`，`A(t)=A_0 e^{−λt}`，`A_0 ≤ a_max`；法向速度 `≤ v_max`。

**定义 U20（被动性与无害包络）**：参考生成器满足 `∫ f_r·ẋ_r dt ≤ E_max`（或离散形式的能量增量有界）；`k_lat ≥ k_min`、`A_0 ≤ a_max`、退让距离 `≤ d_max`；任一条件不满足 → 回退基线。

**定义 U21（抓握-柔顺联合签名）**：`s^{slip}_t = f(g_t, r_t, Δgrip_t)`；滑移 = `g_t` 下降 ∧ `r_t` 出现高频振荡 ∧ `Δgrip` 漂移。

**定义 U22（贡献台账）**：`L = {(claim, prior_art, falsifier, experiment, minimal_evidence)}`；没有 `falsifier` 的 claim 不得进论文；没有 `minimal_evidence` 的 claim 不得进摘要。

```python
# ===== IP-09 + IP-10：接触观测 + 柔顺层（外挂在任意基座策略上）=====
class ContactSense:
    def __init__(self, m=25, tau_c=None, n_h=3):
        self.m = m
        self.tau_c = tau_c          # 由校准集按 FPR<=2% 取
        self.n_h = n_h
        self.b_hat = None
        self.hist = []

    def score(self, q_ref, q_obs):
        r = residual_norm(q_ref, q_obs)      # U16
        if self.b_hat is None:
            self.hist.append(r)
            if len(self.hist) >= self.m:
                self.b_hat = float(np.mean(self.hist))
            return 0.0, 0.0
        s = abs(r - self.b_hat)              # U16
        return s, self.calibrate(s)          # P(contact|s)

    def update(self, q_ref, q_obs):
        s, p = self.score(q_ref, q_obs)
        self.count = getattr(self, "count", 0)
        self.count = self.count + 1 if p > self.tau_c else 0
        contact = self.count >= self.n_h       # U17 迟滞
        return contact, p


class ComplianceShaper:
    def __init__(self, K_free, K_contact, k_min, a_max, d_max,
                 n_stall=6, n_dwell=8):
        self.K_free = K_free
        self.K_contact = np.maximum(K_contact, k_min)   # U20
        self.a_max = a_max
        self.d_max = d_max
        self.n_stall = n_stall
        self.n_dwell = n_dwell
        self.mode = "advance"
        self.dwell = 0

    def shape(self, x_d, contact, progress, t):
        # 1) 视在柔顺：接触相降低横向刚度（准静态形式）
        K = self.K_contact if contact else self.K_free          # U18
        x_r = x_d                                              # f_ext=0 的退化形态
        # 2) 搜索/退让（无力估计时的 R_motion）
        if contact and progress < 1e-3:
            self.stall = getattr(self, "stall", 0) + 1
        else:
            self.stall = 0
        if self.stall >= self.n_stall:
            self.mode = "search"
        if self.mode == "search":
            A = self.a_max * np.exp(-0.5 * t)                    # U19
            x_r = x_r + A * np.array([np.cos(4*t), np.sin(4*t), 0.0])
            x_r = clamp_search(x_r, self.a_max, self.d_max)      # U20
        # 3) 状态切换只在块边界（由外部 chunk 调度保证）
        return x_r, K, self.mode


class UniBotSAGEv2Policy:
    """metadata / get_action / reset 三件套不变；内部多一层柔顺。"""
    def __init__(self, base, cfg):
        self.base = base
        self.cs = ContactSense(cfg.m, cfg.tau_c)
        self.shape = ComplianceShaper(**cfg.shape)
        self.sessions = {}                 # 每端口独立状态（隔离）

    @property
    def metadata(self):
        md = dict(self.base.metadata)
        md["compliance"] = {               # 主动声明，便于审计
            "mode": "contact_triggered",
            "k_free": self.shape.K_free.tolist(),
            "k_contact": self.shape.K_contact.tolist(),
            "search": "spiral_decay",
        }
        return md

    def reset(self, port=None):
        self.sessions.setdefault(port, Session()).reset()
        self.cs = ContactSense(self.cs.m, self.cs.tau_c, self.cs.n_h)

    def get_action(self, obs, port=None):
        s = self.sessions[port]
        q_ref_prev = s.last_ref
        q_obs_prev = extract_state(obs)
        contact, p = self.cs.update(q_ref_prev, q_obs_prev)
        x_d = self.base.act(obs)                       # 基座策略
        progress = s.progress(obs)
        x_r, K, mode = self.shape.shape(x_d, contact, progress, s.t)
        x_r = s.stitch(x_r, mode)                      # IP-03'：按 mode 缝合
        s.last_ref, s.t = x_r, s.t + 1
        return pack(x_r, obs)
```

```python
# ===== IP-09：校准（离线，一次性）=====
def calibrate_contact(logs, fpr_target=0.02):
    """logs: [(q_ref, q_obs, contact_label)]，contact_label 由几何/人工/仿真给。"""
    feats = [bias_corrected_residual(qr, qo) for qr, qo, _ in logs]
    labels = np.array([c for _, _, c in logs])
    iso = IsotonicRegression(out_of_bounds="clip").fit(feats, labels)
    p = iso.predict(feats)
    thr = np.quantile(p[~labels], 1 - fpr_target)      # FPR<=2%
    return iso, thr
```

```python
# ===== IP-06'：条件化六因子 =====
def conditional_factors(episode):
    """P(success) ≈ P(reach)·P(grasp|reach)·P(transport)·P(align)
                    ·P(contact)·P(insert|contact,K)·P(release)"""
    f = {}
    f["reach"] = phase_ok(episode, "reach")
    f["grasp"] = phase_ok(episode, "grasp") if f["reach"] else 0.0
    f["transport"] = phase_ok(episode, "transport") if f["grasp"] else 0.0
    f["align"] = phase_ok(episode, "align") if f["transport"] else 0.0
    f["contact"] = phase_ok(episode, "contact") if f["align"] else 0.0
    f["insert"] = (phase_ok(episode, "insert")
                   if f["contact"] else 0.0)
    f["release"] = phase_ok(episode, "release") if f["insert"] else 0.0
    return f
```

## 5. 推导（引理 L8–L13）

**引理 L8（刚度-卡死的内点最优，模型内）**
在声明的刚性倒角模型下，有效横向偏移 `|y_eff| = |e| + f_b/k_l`（取最坏符号）。捕获条件 `|y_eff| ≤ c+w`；倒角末端的峰值法向力 `N_peak = k_l (|y_eff| − c)₊ cosθ`，`cosθ = 1/√(1+(w/h)²)`；卡死条件 `N_peak > N_jam`。因此成功集合为
`|e| ≤ min( c + w − f_b/k_l,  c + (N_jam/cosθ − f_b)/k_l )`。
第一项随 `k_l` 递增（软→miss），第二项随 `k_l` 递减（硬→jam），故存在内点最优，近似在
`k_l* ≈ (N_jam/cosθ)/w`。
代入本轮参数（`N_jam=40, cosθ≈0.987, w=0.16`）得 `k*≈253`；模拟观测最优在 100–180，差异来自误差平均与轴向动力学。**这是模型内的结论，不是真机定律**。∎

**引理 L9（接触可检测性）**
设自由空间残差偏置为 `b`、接触残差增量为 `Δ`、测量噪声 `σ_m`，用前 `m` 步估计 `b̂`。则偏置校正分数 `s_t=|r_t−b̂|` 在水平 `α`（FPR）与功效 `1−β` 下可分离，当
`Δ > z_{1−α} σ_m √(1+1/m) + z_{1−β} σ_m`。
模拟（m=25，k=180）给出：σ_m=2mm 时 AUROC 0.976、TPR@FPR2%=0.927；σ_m=4mm 时 0.951/0.858；σ_m=8mm 时 0.905/0.724。∎

**引理 L10（门控的无害性）**
若仅在 `P(contact|s_t) > τ_c` 时启用柔顺/搜索，且检测器在非接触子集上的假阳性率为 `α`、接触子集上的召回为 `r`，则期望的性能变化为
`Δ = r·TPR·Δ_gain − α·FPR·Δ_loss − overhead`。
取 `τ_c` 使 `α ≤ 0.02`；若柔顺在自由空间只是降低横向跟踪刚度、不产生搜索动作，则 `Δ_loss ≈ 0`（搜索另设门控）；于是 `Δ > 0` 只需 `TPR·Δ_gain > overhead`。这与上一版 L3（保守介入）同构。∎

**引理 L11（时间是可花的预算）**
上一版已证 `step = 1.337·succ + 0.09`（R²=0.9955），计分货币近似为 `U ≈ succ`；时长不进入 U，只通过 180s episode 上限约束。因此若一个策略以更长时长换取更高 `succ` 且不超时，它在排序上占优。这为"减速插入 + 搜索"提供了计分依据。∎

**引理 L12（单模型合规）**
COMPLY 层是确定性的动作后处理器：不新增 checkpoint、不改变 `metadata/get_action/reset` 契约、不读取评测侧信息。因此它不触发"单模型 vs 多专家"的合规问题（Q3）。但它**改变动作分布**（退让/搜索），必须在 `metadata`/README 主动声明，并接受"动作规律性"审计；否则可能被误判为脚本化。∎

**引理 L13（claim 可分离性）**
一个 claim 是"机制性"的，仅当在**固定容量**下移除该机制会改变终点：
`Δ_mech = E[Y | mech=on, capacity=c] − E[Y | mech=off, capacity=c]`。
若 `Δ_mech ≈ 0`，则观察到的增益来自容量/工程，不应写成机制 claim。本轮据此保留 C1/C2，砍掉 N1（各向异性）。∎
