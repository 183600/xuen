# 第 4 轮（灵感驱动研究循环·本轮灵感：「基准测试」×「强化学习训练」）

> **基线**：第 3 轮产出 MetricVoiceGauge-NCD-HUTDH-v21+IP-425–430（SDC/CAC/DCL/GIC/HPC+/CFC+；其上承 v20 的 PCA/CTS/CFC/HPC/CFCtrl 与 v19/v17 证书体系）。
> 本轮纪律：**"测得出"不等于"真安全"，"学得会"不等于"可以学"；基准是带有效性域的条件断言，强化学习只能在证书围栏内学性能**。不推倒 v21：SDC/CAC/DCL/GIC/HPC+/CFC+ 全部保留。本轮只做一件事：**在 v21 的语义-规范层之上加一层"评估-训练闭环层"（Evaluation-Training Loop, ETL），把"我声称安全"升级为"可被对抗基准证伪地测出来、且策略只能在硬盾内学出来"，并顺手把 v21 最大风险（召回率 κ_c 的经验假设）变成可证伪、可下界、可在线监控的量**。

## 0. 直觉与动机

**灵感 1（基准测试 → 基准不是"分数"，而是一张带有效性域的条件证书）**
直觉：v21 的每个模块都说自己好，但"好"从来没有统一的尺子；更糟的是，实验表 E771–E800 只是零散验收，不是可比较、可复现、可被攻击的度量仪器。基准测试的严谨内核不是"跑个分"，而是**把一句断言绑定到它成立的那个分布上**：一个 benchmark 结果 `φ @ (B, D_B, estimator, 1-γ)` 只在采样分布 `D_B` 上成立；把它外推到部署分布 `D_real` 是一个**显式的可迁移性假设**，不是免费的推理。三个反直觉点：第一，**基准本身是证书**——它有自己的覆盖域、污染审计、置信区间和失效条件；第二，**古德哈特定律是安全属性**——一旦某个指标成为训练目标，它就不再是好的度量，所以安全指标绝不能进奖励；第三，**最重要的基准不是平均成功率，而是尾部与"假安全率"**：一个系统在 99% 场景安全、却在系统性漏检的人体形态上 100% 撞人，平均分毫无意义。核心创新：**基准有效性证书（Benchmark Validity Certificate, BVC）+ 抗污染评估协议（Contamination-Resistant Evaluation Protocol, CREP）**。关键反直觉点：**"没测到失败"不是"没有失败"，正如 v21 的"没看见人"不是"没有人"**——未被基准覆盖的场景空间必须像 `Cov_t` 之外一样被保守对待。

**灵感 2（强化学习训练 → 学习只能在证书围栏内学性能，安全是硬盾而非奖励项）**
直觉：v21/v20 的参数（margin、q_low/q_high、κ_c）大量是手调的，直觉上应该用 RL 学一个更好的策略。但 RL 引入奖励黑客、危险探索、分布漂移与非平稳性。核心反直觉点：**安全不能被"学掉"，只能被"围住"**。把安全写进奖励，等价于允许策略用"少撞几次"去换"多跑几步"；正确做法是 **constrained MDP + 硬盾（shield）**：策略 π 自由探索，但每一步执行的都是 `Shield(a_π)`，而 Shield 的像集恰是 v21 的 `Exec_v21`。于是**无论 π 被训练成什么、甚至被对抗性篡改，实际执行轨迹永远落在 v21 的安全集内**——安全性从"策略是否正确"解耦为"盾是否正确"。第二个反直觉点：**RL 最有价值的用途不是学控制，而是学"出题"**——用对抗课程生成器（Adversarial Curriculum Generator）专门搜 v21 证书的薄弱点（罕见人体形态、强逆光、传感器退化），把"评估"变成主动证伪。第三个反直觉点：**仿真里安全不等于现实里安全**，除非你能证明仿真的扰动集**包含**现实的扰动集；否则 sim-to-real 是一次没有证书的外推。核心创新：**硬盾策略优化（Shielded Policy Optimization, SPO）+ 虚实迁移证书（Sim-to-Real Transfer Certificate, SRTC）+ 对抗课程生成器（ACG）**。

**两者如何统一：一个只会让方案更保守的"测量-学习"闭环**
统一为 **v21 语义-规范层之上的评估-训练闭环层（ETL）**：BVC/CREP 回答"这句安全断言在哪个分布上、以多高置信度成立、有没有被污染"；ACG 回答"能不能主动构造反例把它推翻"；SPO 回答"策略能否只在围栏内学得更好"；SRTC 回答"围栏能不能从仿真搬到现实"；反古德哈特活动-尾险契约（AGTC）回答"策略会不会靠站着不动或贴边来刷分"。共享状态扩展为 `ζ_etl = ζ_sem ∪ (B, D_B, Π_cert, π, σ_shield, transfer_cert, activity, tail_stats)`。统一准入门：**HPC‡ = (HPC+, PolicyCert)**，其中 `PolicyCert = (BVC, SRTC, ShieldActive, ActivityFloor)`——几何/规范/负信息（HPC+）∧ 断言有效（BVC）∧ 可迁移（SRTC）∧ 硬盾在环（SPO）∧ 非退化（AGTC）才允许部署学到的策略。安全继承的关键：**BVC/CREP/ACG 只测量不执行；SPO 的盾只把动作投影进 `Exec_v21`；SRTC 只在包含成立时放行、失效即回退 v21；AGTC 只加活动下界（进一步收缩）**；且**安全关键参数在训练期冻结，基准只能让它更保守（κ_c 只许取置信下界），绝不允许为过基准而放宽**——故 `Exec_v22 ⊆ Exec_v21`。

## 1. 研究问题（轮次升级版）

- **Q1（基准的有效性域与可迁移性）**：如何把"在 `D_B` 上以 1-γ 成立"的 BVC 外推为"在 `D_real` 上成立"？需要什么可迁移性假设（覆盖 `D_real ⊆ supp(D_B)`、分布距离 `d(D_B,D_real) ≤ Δ`、或协变量偏移的密度比界）？如何在线检测部署已滑出有效性域？

- **Q2（抗污染与反古德哈特）**：如何用密封/轮换/水印/canary + 预注册 + 多重比较校正，保证基准分数不被训练污染？当基准同时是训练目标时，如何证明"测得的提升"不是对基准的过拟合？安全指标如何做到永不进奖励？

- **Q3（硬盾与安全参数冻结）**：如何让 `Shield(a_π)` 在 50Hz 控制路径 O(1) 完成并严格等于 v21 的 HPC+/CFC+/DCL 可行域？如何形式化"安全关键参数只许保守化"（κ_c 只取 LCB、margin 只许增），并防止 RL 通过间接变量（观测编码、动作平滑、奖励塑形）绕过冻结？

- **Q4（虚实迁移与对抗课程）**：如何证明 `W_sim ⊇ W_real` 从而 SRTC 成立？当包含不成立（未建模扰动）时如何 fail-safe 回退？ACG 生成的对抗场景如何避免"只对课程过拟合"，并持续把新反例回灌到 κ_c 的下界估计与 v21 的 CAC？

- **Q5（实时与训练成本）**：基准评估、conformal 校准、对抗生成都是离线/低频的，如何与 10Hz 证书更新、50Hz 控制、12ms 预算解耦？训练侧如何避免"用真实机器人做危险探索"？

## 2. 设计原则（在 P34–P36 基础上新增 P37–P40）

**P37 基准即条件断言律（Benchmark-as-Conditional-Claim）**
任何基准结果必须写成 `EvalCert = (claim, B_ver, hash(D_B), estimator, CI_{1-γ}, validity_domain, contamination_audit)`；它只断言 claim 在 `D_B` 上以 ≥1-γ 成立。外推到 `D_real` 必须另附可迁移性证据（覆盖或距离界），否则断言降级为"仅基准内"。未被基准覆盖的场景一律按 v21 的"覆盖外=保守"处理。

**P38 安全即硬盾律（Safety-as-Hard-Shield）**
安全不进入奖励。执行动作恒为 `a = Shield(a_π)`，`Shield` 的像集 ⊆ `Exec_v21(t)`（由 HPC+/CFC+ 与 DCL 定义），且对任意 π（含被对抗篡改的 π）成立。策略只能在围栏内选"更好"，不能选"更自由"。安全指标永不作为优化目标。

**P39 反古德哈特律（Anti-Goodhart）**
安全关键证书参数（κ_c、margin_col_fed、q_high 等）在训练期**冻结**；基准与对抗课程只能把它们**推向更保守**（κ_c 取置信下界 `κ_c^LCB`、margin 只增），任何放宽必须由独立审计/形式验证另行认证。基准密封、轮换、预注册，报告尾部指标（CVaR、最坏情形、假安全率）而非仅均值；设活动下界防"站着不动刷安全分"。

**P40 可迁移性显式律（Transferability-Explicit）**
sim-to-real 与 benchmark-to-deployment 迁移都必须出示包含性证据（`W_sim ⊇ W_real` 或 `D_real ⊆ supp(D_B)`）；包含不成立即迁移无效，回退 v21 硬盾或 SafeStop。有效性域是证书的组成部分，不是脚注。

## 3. 与基线的接口（如何退化）

- BVC 失效（基准过期/污染审计失败/有效性域未知）⇒ 所有"仅基准内"的断言作废，策略退回 v21 手调参数 + HPC+ 硬盾（更保守）；
- CREP 失效（无法密封/轮换）⇒ 基准分数只作参考，不得用于部署决策，等价 v21；
- ACG 失效（生成器崩溃）⇒ 无对抗课程，κ_c 只能维持旧 LCB、不得升高（更保守）；
- SPO 失效（盾不可用/超时）⇒ 立即执行 v21 SafeStop 或 π_safe，绝不裸跑 π；
- SRTC 失效（包含无法证明/域差超界）⇒ 学到的策略不得上真机，回退 v21 手调策略；
- AGTC 失效（活动下界无法度量）⇒ 视作退化，禁用该策略（防止"安全但无用"被误判为成功）；
- 安全参数冻结被破坏（检测到间接放宽）⇒ 冻结该策略、回滚参数、触发审计；
- 全失效 ⇒ 完全回退 v21 ⇒ `Exec_v22 ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`（引理 169）。
- **安全继承**：测量类模块（BVC/CREP/ACG）不进入控制路径；盾只投影；SRTC 只做部署门；AGTC 只加任务约束；参数更新只许保守化。任意失效都向更保守方向退化。

## 4. 预期贡献

1. **基准即证书**：首次把"实验验收"升级为带有效性域、置信区间、污染审计与可迁移性条件的 EvalCert，使"测得出"本身可审计、可证伪；
2. **可证伪的召回下界**：用 ACG 主动构造罕见人体形态/退化场景去攻击 κ_c，并以置信下界 `κ_c^LCB` 驱动 v21 的 AbsCert，把 v21 最大风险从"经验假设"变成"可持续证伪、只降不升"的保守量；
3. **硬盾强化学习**：把 safety 从奖励中剥离，`Shield(a_π) ⊆ Exec_v21` 使安全性对策略正确性免疫（对抗篡改的 π 仍安全），给出奖励黑客只能"在安全集内挑动作"的结构性界；
4. **反古德哈特机制**：安全参数冻结 + 只许保守化 + 密封轮换基准 + 尾部/假安全率 + 活动下界，给出"刷分即失效"的契约；
5. **显式可迁移性**：SRTC 用扰动集包含性证书化 sim-to-real，包含失败即回退，杜绝"仿真里安全"冒充"现实安全"；
6. **HPC‡ 部署门**：`HPC+ ∧ PolicyCert` 统一准入，`Exec_v22 ⊆ Exec_v21 ⊆ ...` 闭环。

## 5. 本轮最大风险

**一句话**：ETL 把"安全"寄托在"能被基准测出来、且能在盾内学出来"，但基准只能证伪不能证明——RL 会主动把策略推向基准覆盖的边缘甚至之外，一旦部署分布滑出 BVC 的有效性域，系统会**在基准上完美、在现实里失效**，即"基准即世界"的幻觉。

```python
# IP-431 Benchmark Validity Certificate（基准=带有效性域的条件断言）
@dataclass
class EvalCert:
    claim: str
    b_ver: str
    data_hash: str
    estimator: str
    ci_lo: float
    ci_hi: float
    validity_domain: str      # "on_benchmark" | "transportable(Δ=...)"
    contamination_audit: str  # "PASS" | "FAIL"

class BenchmarkValidityCertificate:
    def __init__(self, gamma=0.05, delta_max=0.1):
        self.gamma = gamma
        self.delta_max = delta_max

    def issue(self, claim, data, estimator, dom="on_benchmark"):
        lo, hi = bootstrap_ci(estimator, data, level=1 - self.gamma)
        audit = contamination_audit(data)      # canary/水印/近重复检测
        if audit != "PASS":
            dom = "on_benchmark"               # 污染→不许外推
        return EvalCert(claim, data.version, data.hash, estimator.name,
                        lo, hi, dom, audit)

    def transport_ok(self, cert, deploy_stats):
        """外推必须显式：覆盖或密度比界，否则拒绝（P37）"""
        if cert.validity_domain.startswith("transportable"):
            return density_ratio_bound(cert, deploy_stats) <= self.delta_max
        return coverage_ok(deploy_stats, cert)  # D_real ⊆ supp(D_B)?
```

```python
# IP-432 Contamination-Resistant Evaluation Protocol（密封+预注册+选择偏差界）
class ContaminationResistantEvaluator:
    def __init__(self, sealed_suites, refresh_period, n_candidates):
        self.sealed = sealed_suites       # 训练侧无句柄；仅评估时打开
        self.refresh = refresh_period     # 定期轮换，抗饱和/记忆
        self.m = n_candidates

    def score(self, policy, suite_id):
        data = self.sealed[suite_id]
        raw = evaluate(policy, data)
        # 多重比较校正 + 选择偏差界（引理 164）
        return corrected_score(raw, m=self.m, gamma=0.05)

    def canary_leak(self, model):
        return detect_memorization(model, self.sealed)   # 水印/canary

    def pre_registered(self, hypothesis):
        return hypothesis.hash in self.registry          # 预注册，防事后挑指标

    def rotate(self):
        self.sealed = refresh_from_escrow(self.sealed)    # 抗过拟合到固定集
```

```python
# IP-433 Adversarial Curriculum Generator（RL 用来"出题"而非"控制"）
class AdversarialCurriculumGenerator:
    def __init__(self, scenario_space, realism_filter, seed_suite):
        self.S = scenario_space
        self.realistic = realism_filter    # 物理可实现性过滤，防生成荒谬场景
        self.cur = seed_suite

    def propose(self, certifier):
        # 目标：最大化证书失效（如人体漏检 / AbsCert 误发）
        s = argmax(self.S, key=lambda z: failure_score(certifier, z)
                   if self.realistic(z) else -inf)
        return s if self.realistic(s) else None

    def update_recall_lcb(self, nominal, adversarial_sealed, level=0.95):
        """对抗反例只许把 κ_c 往下拉（P39）；用 Clopper-Pearson 下界"""
        data = nominal + adversarial_sealed
        return clopper_pearson_lower(successes(data), n=len(data), level=level)

    def on_failure(self):
        return KeepOldLCB()   # 生成器失效→κ_c 不得升高（更保守）
```

```python
        self.pi = policy
        self.shield = shield       # = v21 HPC+/CFC+/DCL 可行域投影
        self.cmdp = cmdp

    def train_step(self, batch):
        # 硬约束：只在盾内最大化任务回报；安全项绝不入 r_task

            loss = -logprob(self.pi, a, x) * r_task
            update(self.pi, loss)

        # 防经观测编码/动作平滑间接放宽安全参数（Q3）
```

## 3. 推导

**引理 163（基准的条件有效性与外推的显式代价）**
BVC 把断言 φ 绑定到 `(B, D_B, est, CI_{1-γ})`，故 `P_{D_B}(φ) ≥ 1-γ`。对部署分布 `D_real`，仅当 `D_real ⊆ supp(D_B)`（覆盖）或 `TV(D_B,D_real) ≤ Δ` 且 φ 关于分布的敏感度为 `L` 时，才有 `P_{D_real}(φ) ≥ 1-γ-ΔL`；否则**不存在任何界**。因此"基准内安全 ⇒ 部署安全"不是推理，而是必须另行出示的可迁移性假设（P37/P40）；无法出示时断言降级为"仅基准内"，并按覆盖外保守处理。∎

**引理 164（选择偏差与污染的可界定性）**
若在**同一有限样本**上评估 M 个候选策略并只报告最优者，则报告值的乐观偏差以 `σ√(2 ln M)` 为上界（高斯极值 + 联合界）。CREP 用**密封且与选择样本独立**的评估集消除选择效应；预注册固定指标防止事后挑选；训练/评估重叠（污染）会进一步抬高偏差，由 canary/水印/记忆检测给出 `FAIL` 并禁止外推。故 CREP 把"测得的提升"与"真实的提升"之差界住。∎

**引理 165（硬盾的安全免疫）**
定义逐点安全动作集 `A_safe(t) = {a : ∃ 经 a 的 H 步计划被 HPC+ ∧ DCL(σ) 许可}`，`Shield_t(·)` 为到 `A_safe(t)` 的投影，且 `A_safe(t) ⊆ Exec_v21(t)`。执行动作恒为 `a_t = Shield_t(a_π(x_t)) ∈ A_safe(t)`，对任意 π（含被对抗篡改、未训练或奖励黑客化的 π）成立。于是任何执行轨迹都是可行动作的拼接，`∈ Exec_v21`。**RL 只改变在 `A_safe` 上的分布，不改变集合本身**；安全性从"π 是否正确"解耦为"盾是否正确"（P38）。∎

**引理 166（安全参数冻结的保守单调）**
令 `κ_c^LCB` 为 κ_c 的单侧置信下界，则 `κ_c^LCB ≤ κ_c^point`，故 `δ_abs = 1-κ_c^LCB ≥ 1-κ_c^point`，AbsCert 的可靠度 `1-δ_abs = κ_c^LCB` 只降不升——缺席被信任得更少，方案更保守。训练期冻结 `FROZEN_SAFETY_KEYS`，基准与对抗课程只许把 κ_c 推向 LCB、margin 只许增，任何放宽须独立审计/形式验证另行认证。故 v21 最大风险（κ_c 经验假设）被改造成**可证伪且只降不升**的保守量（P39）。∎

**引理 167（虚实迁移的包含性）**
鲁棒约束关于扰动集单调：`W_real ⊆ W_sim ⇒ Inv(W_sim) ⊆ Inv(W_real)`（更大扰动给出更小的鲁棒不变集）。故若在 `W_sim` 下算得非空不变集 `Inv(W_sim)` 且策略在其上被认证，则同一策略在 `W_real` 下仍安全。反之 `W_real ⊄ W_sim` 时，未建模扰动可击穿证书，迁移无效。因此 SRTC 以包含性为放行条件，并以 `gap_monitor` 在线检测域差、超界即回退 v21 盾或 SafeStop（P40）。∎

**引理 168（反古德哈特与活动下界的收缩性）**
仅最大化安全裕度会收敛到"不动"的退化策略（activity→0）——安全但无用；仅最大化基准分则会被过拟合。AGTC 叠加活动下界 `activity ≥ A_min`、尾部 `CVaR_α` 与假安全率 `FSR` 约束，并以"任务进展 vs 代理裕度"检测证书刷分；这些**都是额外任务约束**，只会进一步收缩可行集，不放松任何安全约束。故 AGTC 不能扩大 `Exec`。∎

**引理 169（v22 整体安全继承）**
同一几何快照、同一规则库与机器人集合下：BVC/CREP/ACG 只测量、只把 κ_c 向下拉（163/164/166）；SPO 的盾只把动作投影进 `Exec_v21`（165）；SRTC 只在包含成立时放行、失效回退（167）；AGTC 只加任务约束（168）；安全参数训练期冻结且只许保守化（166）。故 `Exec_v22 = Exec_v21 ∩ Fil_shield ∩ Fil_activity ⊆ Exec_v21 ⊆ Exec_v20 ⊆ Exec_v19 ⊆ Exec_v18`。∎

## 7. 已知风险与失效模式

1. **有效性域滑出 / "基准即世界"**（最大风险，见第 8 节）：基准只覆盖 D_B，RL 会把策略推向覆盖边缘甚至之外；`D_real ⊄ supp(D_B)` 时外推无界。缓解：BVC 显式有效性域 + 域差监控 + 覆盖外保守 + 定期轮换基准（E802/E817）。
2. **污染与古德哈特**：基准成为训练目标后被过拟合，报告分虚高。缓解：密封/轮换/预注册/多重比较校正 + 安全指标永不入奖励（E804–E806/E813）。
3. **奖励黑客与间接放宽**：策略经观测编码/动作平滑绕过冻结参数，或优化代理裕度而非任务。缓解：冻结作用域+编码审计+证书刷分检测（E814/E815/E822）。
4. **虚实迁移的未建模扰动**：`W_real ⊄ W_sim`（接触摩擦、通信延迟、人体异常行为）。缓解：保守上界+包含性证书+运行时域差回退（E816–E818）。
5. **"安全但无用"退化**：只追安全裕度→不动。缓解：活动下界 + 尾险指标 + 任务进展监控（E819/E820）。
6. **ACG 过保守 / 生成不真实场景**：把不可实现的反例当作召回失败，导致 κ_c 被压得过低、活性坍缩。缓解：物理可实现性过滤 + 对抗集与密封评估集分离（E808/E810）。
7. **隐私与基准数据**：基准含人体图像/生物特征。缓解：原始数据零出域、只传证书与统计、最小化（E833）。
8. **训练成本与实时解耦**：评估/训练若侵入控制路径会破坏 12ms。缓解：全离线/低频，在线仅 O(1) 查盾（E831/E832）。
9. **参数冻结的旁路**：安全参数虽冻结，但其**输入特征**可被策略间接操纵（如平滑掉危险观测）。缓解：特征级审计 + 对抗课程覆盖 + 独立监控通道（E815）。

## 8. 本轮最大风险

**一句话**：ETL 把"安全"寄托在"能被基准测出来、且能在盾内学出来"，但基准只能证伪不能证明——RL 会主动把策略推向基准覆盖的边缘甚至之外，一旦部署分布滑出 BVC 的有效性域，系统会**在基准上完美、在现实里失效**，即"基准即世界"的幻觉。
