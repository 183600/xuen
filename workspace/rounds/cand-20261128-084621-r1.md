### 第 8 轮灵感驱动研究记录

**灵感词**：虚实迁移、强化学习训练

**继承关系**：第 7 轮 CADVS-v7（IP-501~IP-504）建立「需求-意图-一致性三角桥」：DIM 从历史推断 ρ_demand、DRC 用 LLM 推理链量化 η_demand、DAC 从表情捕获 desire_affect、EFA-v7 把 η_demand/η_affect 接入软因子链。但 v7 留下两个结构性缺口：(i) 提议策略 FMPP 仍是**逐实例现场锻造**，没有跨任务的学习与改进；(ii) 软因子链的符号不一致——η_affect 可低至 2/3，却写成「η_j≥1 ⇒ 阈值上升」，实际会让执行集**扩张**，破坏 fail-closed。本轮以「虚实迁移 + 强化学习训练」为轴，把 v7 升级为「**迁移可证、训练有盾**」的 CADVS-v8：引入虚实鸿沟回归器（SGR）给出可校准的迁移证书，引入带硬门盾牌的约束强化学习训练器（RLS）让策略可迭代改进，引入自适应域随机化（DDA）主动压缩鸿沟，并用 EFA-v8 把「置信收缩」统一到全部软因子。

**直觉与动机**：

1. **虚实迁移 → 从「仿真调参」到「可校准的迁移证书」**。仿真里七硬门全过，不等于真机安全；v7 对这一点只有一句风险声明。关键洞见是：**鸿沟本身可以被测量并证书化**——用成对 sim/real 轨迹拟合残差模型，再用分裂共形预测给出功能级 gap 上界 δ̂_α，把「能不能上真机」变成一个带覆盖保证的判定，而不是工程经验。

2. **强化学习训练 → 从「一次性锻造」到「带盾的约束改进」**。v7 的 FMPP 每次从零提议，无法从失败中积累。关键洞见是：**探索必须被七硬门盾牌包住**——把硬门介入定义为成本 c，用拉格朗日 PPO 在 CMDP 上做「收益↑、违规↓」的对偶优化；策略只能在仿真中被盾牌过滤后的动作上学习，从训练阶段就杜绝「用违规换奖励」。

3. **虚实迁移 × RL 的耦合 → 自适应域随机化**。固定域随机化要么过窄（过拟合）要么过宽（策略保守）。关键洞见是：**用 gap 反馈驱动随机化分布**——δ̂ 大的参数维度加宽、δ̂ 小的收窄，形成「测量鸿沟 → 调整随机化 → 再测量」的闭环，把迁移从一次性校准变成持续课程。

4. **对 v7 的诚实修正 → 置信收缩**。v7 的 η_j∈[1,1.3] 与 η_affect∈[2/3,4/3] 自相矛盾。v8 统一为：所有软因子 η_j∈(0,1] 表示**置信度**，阈值 τ_i^v8 = τ_i^v7 / Π_j η_j，并设 Γ_max=1.3 截断。置信越低 → 阈值越高 → 执行集越窄，结构上保证 Exec_v8 ⊆ Exec_v7，这才是真正的 fail-closed。

**关键洞见**：v7 回答「如何从需求推导行为」；v8 回答「**仿真里学到的行为凭什么可信地迁移到真机，以及如何安全地持续训练**」。七硬门 kc_evidence_forged_v5 记号原样复用；新增部署级硬门 kc_transfer（只在部署/上线时判定，不进控制环，因而不破坏控制环时序不变量）。本轮新增：
- IP-505 SGR（Sim-to-Real Gap Regressor，虚实鸿沟回归器 + 共形证书），
- IP-506 RLS（Shielded RL Trainer，带七硬门盾牌的约束 RL 训练器），
- IP-507 DDA（Domain Randomization Adapter，gap 反馈驱动的自适应域随机化），
- IP-508 EFA-v8（置信收缩软因子链 + 部署级 kc_transfer 硬门）

**形式化目标（增量）**：

1. **SGR（虚实鸿沟回归器）**：<br>
   - 残差模型 g_φ: (s,a) ⟼ Δŝ，拟合成对 sim/real 转移 (s,a,s_sim,s_real)<br>
   - 功能级 gap：δ_f = |E_real[f] − E_sim[f]|，f 取成功指示、门裕度、能耗等可测泛函<br>
   - 分裂共形上界：δ̂_α = Quantile_{1−α}({δ_f^(i)}_{i∈calib})，覆盖保证 P(δ_f ≤ δ̂_α) ≥ 1−α<br>
   - 迁移置信：η_transfer = clamp(exp(−λ·δ̂_α/δ_budget), η_min, 1)，η_min = 1/Γ_max<br>
   - 部署门 kc_transfer：δ̂_α ≤ δ_budget ∧ η_transfer ≥ τ_transfer

2. **RLS（带盾约束训练）**：<br>
   - CMDP：(S, A, P, r, c, γ)，成本 c = 1[盾牌介入] + 1[任一门裕度 < 0]<br>
   - 拉格朗日目标：max_θ min_{β_c≥0} E_πθ[r] − β_c·(E_πθ[c] − d)<br>
   - 对偶更新：β_c ← max(0, β_c + α_dual·(ĉ − d))<br>
   - 改进置信：η_rl = clamp(0.5 + 0.5·tanh(LCB(ΔJ)/σ_J), η_min, 1)，LCB 为 bootstrap 下界

3. **DDA（自适应域随机化）**：<br>
   - 随机化分布 p_φ(ξ)，ξ 为物理参数（摩擦、质量、延迟、传感噪声）<br>
   - 灵敏度 s_k = |∂δ̂/∂φ_k|，按 s_k 分配随机化宽度：φ_k ← φ_k · (1 + ρ·s_k)<br>
   - 鲁棒目标：max_θ min_{ξ∼p_φ} E[r(θ,ξ)] − β_c·E[c(θ,ξ)]

4. **EFA-v8（置信收缩 + 部署门）**：<br>
   - 八软因子链：Π = η_g·η_topo·η_interp·η_cmd·η_demand·η_affect·η_transfer·η_rl，全部 ∈ (0,1]<br>
   - 阈值：τ_i^v8 = min(τ_i^v7 / Π, Γ_max·τ_i^v7)，Γ_max = 1.3<br>
   - 若 Π < 1/Γ_max：直接回退 v7 保守流程（不允许任何放宽）<br>
   - ECS_v8 = ECS_v7 · Π（只减不增）

5. **形式化定义**：给定指令 L、目标 ρ_target、记忆 M、成对校准集 C：<br>
   - (ok_transfer, δ̂_α, η_transfer) = SGR.certify(C)；若 ¬ok_transfer → 拒绝部署<br>
   - η_rl = RLS.improvement_factor()；Π = ∏_{j=1}^8 η_j<br>
   - 若 Π < 1/Γ_max：返回 v7.select(L)（保守回退）<br>
   - 否则：以 τ_i^v8 替换 v7 阈值执行 EFA-v7 流程，并记录 (δ̂_α, Π, β_c) 入审计日志

**本轮最大风险**：**虚实鸿沟证书的可交换性假设**：共形 gap 上界 δ̂_α 依赖 sim/real 成对样本可交换且真实分布平稳；一旦真机工况非平稳漂移（磨损、光照、载荷变化），证书会在七硬门全部「仿真通过」的表象下静默失效，而系统仍以为自己处于 δ_budget 之内。

## 2. 关键算法骨架

### IP-505 SGR：虚实鸿沟回归器与共形证书

```python
@dataclass
class SimRealGapRegressor:
    """SGR：把「仿真-真机鸿沟」量化为带覆盖保证的证书。
    输入：成对轨迹 C；输出：δ̂_α, η_transfer, kc_transfer 判定"""
    residual: nn.Module            # g_phi: (s,a) -> delta_s
    delta_budget: float = 0.05
    alpha: float = 0.10            # 共形误覆盖
    lam: float = 4.0
    eta_min: float = 0.77

    def fit(self, paired: list[TransitionPair]) -> None:
        """在成对 (s,a,s_sim,s_real) 上回归残差，冻结后进入校准"""
        xs = [(p.s, p.a) for p in paired]
        ys = [p.s_real - p.s_sim for p in paired]
        self.residual.fit(xs, ys)

    def functional_gap(self, traj_sim, traj_real, f) -> float:
        """可测泛函 f 的 gap：成功指示 / 门裕度 / 能耗"""
        return abs(f(traj_real) - f(traj_sim))

    def conformal_bound(self, calib: list[float]) -> float:
        """分裂共形 1-alpha 上界（校准集与拟合集必须不相交）"""
        n = len(calib)
        q = math.ceil((n + 1) * (1 - self.alpha)) / n
        return float(np.quantile(calib, min(1.0, q)))

    def transfer_factor(self, delta_hat: float) -> float:
        eta = math.exp(-self.lam * delta_hat / self.delta_budget)
        return max(self.eta_min, min(1.0, eta))

    def certify(self, delta_hat: float, tau_transfer: float) -> tuple[bool, float]:
        eta = self.transfer_factor(delta_hat)
        return (delta_hat <= self.delta_budget and eta >= tau_transfer), eta
```

### IP-506 RLS：带七硬门盾牌的约束强化学习

```python
@dataclass
class ShieldedRLTrainer:
    """RLS：在 CMDP 上训练 FMPP 提议策略，七硬门作为运行时盾牌。
    目标 max_theta min_{beta>=0} E[r] - beta*(E[c]-d)"""
    policy: FlowMatchingProposalPolicyKernel
    shield: EvidenceForgingAssemblerV7   # 七硬门复用
    gamma: float = 0.99
    cost_limit: float = 0.02
    beta_cost: float = 1.0
    lr_dual: float = 0.05

    def rollout(self, sim_env, dda: "DomainRandomizationAdapter") -> Buffer:
        buf = Buffer()
        for episode in range(self.sim_env.n_episodes):
            xi = dda.sample()                 # 随机化物理参数
            obs = sim_env.reset(domain=xi)
            while not done:
                a, logp = self.policy.sample(obs)
                a_safe, intervened = self.shield.project(a, obs)  # 硬门盾牌
                r, done = sim_env.step(a_safe)
                margin_ok = self.shield.all_margins_positive(obs, a_safe)
                cost = float(intervened) + float(not margin_ok)
                buf.add(obs, a_safe, logp, r, cost, done)
                obs = sim_env.obs
        return buf

    def update(self, buf: Buffer) -> None:
        # PPO clipped surrogate + 拉格朗日成本惩罚
        adv = self._gae(buf)
        cost_adv = self._gae_cost(buf)
        for _ in range(self.epochs):
            ratio = self.policy.ratio(buf, self.policy.logp)
            loss = -(torch.min(
                ratio * adv,
                torch.clamp(ratio, 1 - 0.2, 1 + 0.2) * adv,
            ).mean() - self.beta_cost * cost_adv.mean())
            self.policy.optimize(loss)
        mean_cost = buf.cost.mean().item()
        self.beta_cost = max(0.0, self.beta_cost + self.lr_dual * (mean_cost - self.cost_limit))

    def improvement_lcb(self, buf: Buffer, n_boot: int = 200) -> float:
        """bootstrap 回报差下界 LCB(Delta J)"""
        deltas = [self._bootstrap_delta(buf) for _ in range(n_boot)]
        return float(np.quantile(deltas, 0.05))

    def improvement_factor(self, lcb: float, sigma: float = 1.0) -> float:
        eta = 0.5 + 0.5 * math.tanh(lcb / max(sigma, 1e-6))
        return max(self.eta_min, min(1.0, eta))
```

### IP-507 DDA：gap 反馈驱动的自适应域随机化

```python
@dataclass
class DomainRandomizationAdapter:
    """DDA：用 SGR 的 gap 灵敏度调整随机化宽度，形成迁移课程"""
    params: dict                  # friction/mass/latency/noise 的基准值
    widths: dict                  # 每个参数的随机化半宽
    rho: float = 0.2
    width_max: dict = field(default_factory=dict)

    def sample(self) -> dict:
        return {k: self.params[k] + np.random.uniform(-self.widths[k], self.widths[k])
                for k in self.params}

    def adapt(self, delta_hat: float, sensitivity: dict[str, float]) -> None:
        """gap 大且某参数灵敏度高 -> 加宽该参数随机化；反之收窄"""
        for k, s_k in sensitivity.items():
            target = self.widths[k] * (1.0 + self.rho * s_k * (delta_hat / 0.05))
            self.widths[k] = min(target, self.width_max.get(k, self.widths[k] * 3))

    def curriculum_done(self, delta_hat: float) -> bool:
        return delta_hat <= 0.5 * 0.05   # gap 降到预算一半即收敛
```

### IP-508 EFA-v8：置信收缩软因子链 + 部署门

```python
@dataclass
class EvidenceForgingAssemblerV8:
    """EFA-v8：v7 的七硬门不变；软因子统一为 (0,1] 置信收缩。
    tau_i^v8 = min(tau_i^v7 / prod(eta), Gamma_max * tau_i^v7)"""
    v7: EvidenceForgingAssemblerV7
    sgr: SimRealGapRegressor
    rls: ShieldedRLTrainer
    dda: DomainRandomizationAdapter
    tau_transfer: float = 0.85
    gamma_max: float = 1.3
    eta_min: float = 0.77

    def deploy_certificate(self, calib_gaps: list[float]) -> tuple[bool, float, float]:
        """离线/上线时的部署门（不进控制环）"""
        delta_hat = self.sgr.conformal_bound(calib_gaps)
        ok, eta_transfer = self.sgr.certify(delta_hat, self.tau_transfer)
        return ok, delta_hat, eta_transfer

    def select(self, L, t_now, context,
               delta_hat: float, eta_transfer: float, buf: Buffer) -> tuple[bool, Trajectory | None, str]:
        # 0. 部署门 kc_transfer：证书不过则拒绝执行（fail-closed）
        if delta_hat > self.sgr.delta_budget or eta_transfer < self.tau_transfer:
            return False, None, 'TRANSFER_GATE_BLOCKED'

        # 1. 收集 v7 各软因子并截断到 (0,1]
        eta_g, eta_topo, eta_interp, eta_cmd, eta_demand, eta_affect = self.v7.soft_factors(L, context)
        eta_rl = self.rls.improvement_factor(self.rls.improvement_lcb(buf))
        factors = {k: float(np.clip(v, self.eta_min, 1.0)) for k, v in {
            'g': eta_g, 'topo': eta_topo, 'interp': eta_interp,
            'cmd': eta_cmd, 'demand': eta_demand, 'affect': eta_affect,
            'transfer': eta_transfer, 'rl': eta_rl,
        }.items()}

        # 2. 置信收缩：乘积过低则不允许任何放宽，直接保守回退 v7
        prod = float(np.prod(list(factors.values())))
        if prod < 1.0 / self.gamma_max:
            ok, x, tag = self.v7.select(L, t_now, context)
            return ok, x, f'{tag}_CONSERVATIVE_FALLBACK'

        # 3. 阈值上抬（除 prod），带上限 Gamma_max
        tau_v8 = {k: min(v / prod, self.gamma_max * v) for k, v in self.v7.tau_v7.items()}

        # 4. 执行 v7 流程，但使用 v8 阈值与收缩后的软评分
        ok, x, tag = self.v7.select_with_thresholds(L, t_now, context, tau_v8)
        return ok, x, f'{tag}_V8' if ok else tag

    def ecs_v8(self, x, n_flow, s_emo, factors: dict) -> float:
        return self.v7.ecs_v7(x, n_flow, s_emo, factors) * float(np.prod(list(factors.values())))
```

### 集成流水线（v7 → v8）

```
离线/慢时域（小时~天级）：
  1. 域随机化仿真采样 → RLS.rollout(shield=v7) → 约束 PPO 训练
  2. 成对 sim/real 校准集 → SGR.fit → 冻结残差 → SGR.conformal_bound → δ̂_α
  3. DDA.adapt(δ̂_α, 灵敏度) → 更新 p_φ → 回到 1（迁移课程）
  4. 部署门：kc_transfer 通过才签发策略与 τ_transfer/δ_budget 证书

在线准入（亚秒级）：
  SGR 证书缓存（δ̂_α, η_transfer）──▶ 若 kc_transfer 失败 → TRANSFER_GATE_BLOCKED
  RLS 改进置信 η_rl（bootstrap LCB，离线预算缓存）
  v7 软因子 ──▶ clamp(·, η_min, 1) ──▶ 八因子乘积 Π
  若 Π < 1/Γ_max → v7 保守回退（禁止放宽）
  否则 τ_i^v8 = min(τ_i^v7/Π, Γ_max·τ_i^v7) → 执行 v7 流程

在线控制环（目标 < 0.9 ms）：
  kc_transfer 与 η_rl 均为预计算缓存，控制环只做 O(1) 乘除与比较
  七硬门调用链路与 v6/v7 完全一致（缓存复用）
```

## 4. 正确性论证（增量更新）

### 定理 13（置信收缩单调性 / 修正 v7 符号漏洞）

**陈述**：设所有软因子 η_j ∈ [η_min, 1]，η_min = 1/Γ_max，Π = ∏_{j=1}^8 η_j，τ_i^v8 = min(τ_i^v7/Π, Γ_max·τ_i^v7)。则 τ_i^v8 ≥ τ_i^v7，且 Exec_CADVS-v8 ⊆ Exec_CADVS-v7；当 Π < 1/Γ_max 时系统直接走 v7 保守流程，不产生任何放宽。

**证明**：η_j ≤ 1 ⇒ Π ≤ 1 ⇒ 1/Π ≥ 1 ⇒ τ_i^v7/Π ≥ τ_i^v7；再由 min 与 Γ_max ≥ 1 得 τ_i^v8 ≥ τ_i^v7。硬门判定 1[s_i ≥ τ] 关于 τ 单调不增，故执行集只缩不扩。Π < 1/Γ_max 时分支显式返回 v7.select，等价于 τ^v8 = τ^v7，仍不扩。∎

**与 v7 的差异**：v7 的 η_affect∈[2/3,4/3] 且阈值乘 Π，当 η_affect>1 时放宽；v8 统一 clamp 到 ≤1 并改为除 Π，从结构上消除该漏洞。

### 定理 14（带盾训练的真机执行安全）

**陈述**：若盾牌 S 在仿真中对每个执行动作强制七硬门（仿真违规率 = 0），且 SGR 的共形上界满足 P(δ_gate ≤ δ̂_α) ≥ 1−α，则当真机与校准集可交换、δ̂_α ≤ δ_budget ≤ ε_safe 时，真机硬门违规概率 P_real(violation) ≤ ε_safe，覆盖概率 ≥ 1−α。

**证明**：设 f 为门违规指示泛函。盾牌给出 E_sim[f]=0；由 gap 定义 |E_real[f]−E_sim[f]| = δ_gate ≤ δ̂_α（以概率 ≥1−α）。故 E_real[f] ≤ δ̂_α ≤ ε_safe。∎

### 定理 15（迁移预算内的策略改进）

**陈述**：设 RLS 的 bootstrap 下界 LCB(ΔJ) > 0，且部署门 kc_transfer 通过。则在置信水平 1−α−β 下，真机期望回报 J_real(π_new) ≥ J_real(π_old)，其中 α 为共形误覆盖、β 为 bootstrap 失败率。

**证明**：分解 J_real(π) = J_sim(π) + Δ_gap(π)，|Δ_gap(π)| ≤ δ̂_α。由 LCB(ΔJ)>0 得 J_sim(π_new) − J_sim(π_old) ≥ LCB > 0（置信 1−β）。两侧 gap 之差 ≤ 2δ̂_α，故 J_real 差 ≥ LCB − 2δ̂_α；kc_transfer 保证 δ̂_α 在预算内，当 LCB > 2δ̂_α 时结论成立。∎

### 诚实声明

- **共形证书的交换性假设**是真机安全的核心前提；工况非平稳时 δ̂_α 会低估，证书静默失效；
- **SGR 只覆盖被测量的泛函 f**，未测维度（如长期磨损、罕见接触）不在证书内；
- **盾牌保真度**取决于仿真中七硬门的实现，sim 门本身有建模误差，盾牌不是真机物理保证；
- **RL 奖励劫持**：策略可能利用仿真器数值漏洞获得高奖励而绕过真实约束，需红队与 held-out 场景审计；
- **DDA 的灵敏度估计**本身有噪声，过宽随机化会导致策略过度保守、样本效率下降。

## 5. 实验设计与验证计划（仿真 → 实机）

### 5.1 实验设计（Isaac Lab + MuJoCo MJX → 真机）

- **平台**：UR10e（6DOF）+ 移动底盘（2DOF）+ 语音指令 + RGB-D 相机；仿真侧 Isaac Lab / MJX 双后端交叉验证
- **任务**：抓取放置、抽屉开合、移动操作、需求模糊指令下的回退执行
- **数据集**：
  - 成对校准集 C：每个任务 200 条 sim/real 配对轨迹（含成功与近失效样本）
  - RLS 训练：每任务 1e6 仿真步，域随机化参数 12 维
  - 校准/拟合严格不相交（split conformal）
- **对照**：v7-full、v8-full、消融 A21（无 SGR 证书，固定 δ_budget=∞）、A22（无盾牌 RL）、A23（无 DDA，固定随机化）、A24（η_transfer≡1）、A25（η_rl≡1）、A26（去掉拉格朗日成本，仅奖励）
- **场景**：
  - (a) 迁移成功：sim 训练策略直接部署，测真机成功率与门违规率
  - (b) 非平稳漂移：注入摩擦/载荷渐变，测证书失效检测时延
  - (c) 奖励劫持红队：构造仿真器可利用漏洞，测策略是否学会违规
  - (d) 需求模糊 + 迁移：η_demand 触发回退时，回退轨迹仍受 kc_transfer 约束
- **指标**：
  - 迁移：真机成功率、δ̂_α 与实际 gap 的覆盖率、证书失效检测时延
  - 训练：样本效率、约束成本 ĉ、β_c 收敛、奖励劫持检出率
  - 安全：真机硬门违规率、盾牌介入率、执行集规模变化
  - 性能：控制环 P99、部署门拒绝率

## 7. 本轮最大风险（最终确认）

**一句话**：**虚实鸿沟证书的可交换性假设**：共形 gap 上界 δ̂_α 依赖 sim/real 成对样本可交换且真实分布平稳；一旦真机工况非平稳漂移（磨损、光照、载荷变化），证书会在七硬门全部「仿真通过」的表象下静默失效，而系统仍以为自己处于 δ_budget 之内。
