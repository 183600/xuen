# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「差异化定位」×「灵巧操作」）

> R69 把不确定性一分为二、把「问」变成一个可认证的动作，但它有两个从未被检验的隐含前提：**（i）歧义发生在连续动作空间，聚类 K 条轨迹即可得到「模态」；（ii）定位是一个统一的全局位姿，所有证据都在同一个坐标系里比较。**
>
> 灵巧操作同时击穿这两点：真正决定成败的多峰性是**离散接触模式**（抓/放、贴/离、粘/滑、单指/多指），接触建立与断开是冲量式、非光滑的——用一个光滑速度场去拟合，流模型必然在切换处「抹平」，而抹平出来的伪峰恰好就是 R69 自陈的最大风险：**幻影模态**。与此同时，「我到底在哪、需不需要那么准」是**任务相关**的：把杯子放到架沿要毫米级**相对**位姿，握着杯子走过去只要分米级；全局地图误差对前者致命、对后者无关。R69 在错误的空间里聚类、又在错误的精度上定位。
>
> 本轮两个灵感各补一刀：
> - **灵巧操作**把 epistemic 的载体从「连续动作模态」上移到**离散接触模式自动机**：模式内用流匹配（光滑），模式间用守卫切换（离散）；接触力/触觉/本体感觉给出一个**非学习、物理接地**的证据通道，可让被流模型高估的幻影模式在 n 次探测后后验任意小。
> - **差异化定位**把「位姿」从单一全局量变成**任务-帧-保真度的帧格**：每个接触模式只激活它真正需要的相对帧与精度；并由此得到一条**差分一致性**检查（同一相对位姿由两条路径估计后比较），它消共模、但盲于共模——诚实划出它能证明什么。
>
> 核心命题：**把 R69 的「连续多峰 + 单一全局定位」升级为「离散接触模式 × 任务差异化帧格」；接触证据做幻影模式证伪、帧差分做相对几何自检；安全包络按模式分段，切换处只承诺有界冲击而非光滑。R69 是本轮在「单模式 + 单帧 + 接触证据关闭」处的严格退化。** 命名 **GRIP-RAS**（Grounded Relative-frame, In-hand contact-mode, Positioning-differentiated Risk-Adaptive System）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我此刻处在哪个接触模式、需要多准的哪一帧、这一下碰上去到底碰对了没有**」——不确定性不只是一句提问，也可能是**一次接触、一个参考系、一个需要多准的问题**。

## 0. 直觉与动机

**灵感 1（灵巧操作 → 多峰性住在离散接触模式里，不在连续动作里）**
直觉：人手犹豫「抓还是推」时，不是在两条连续轨迹之间插值，而是在两个**接触假设**之间切换：抓住则力闭合，推则点接触。接触建立/断开是状态空间的**不连续事件**，连续性假设在冲量处失效。R69 用单一光滑速度场覆盖所有情形，等于要求模型在「还没碰到」和「已经抓住」之间画一条不存在的平滑桥——桥被抹平的地方就是伪峰。把接触模式显式化为离散潜变量 c，模式内用 v_θ(·|o,c) 生成光滑动作，模式间由守卫 G 跳转，才是对的结构。**这不是给 R69 打补丁，而是把它聚类的对象从「动作的几何」换成「接触的拓扑」。**

**灵感 2（差异化定位 → 「在哪里」是一个任务相关的向量，不是一个全局标量）**
直觉：同一个机器人，对「放杯子」需要毫米级的物体-机器人相对帧，对「走过去」只需要分米级的世界帧。用一个全局位姿 + 一个全局协方差去统摄所有任务，会同时犯两种错：对精细任务**欠定位**（真实误差被平均掉），对粗任务**过定位**（把算力浪费在与决策无关的精度上）。把定位拆成帧格 F={F_i}、每个帧有各自协方差，再由任务-模式映射 ρ(c)=(F_c, δ_c) 决定「本模式只需要哪一帧、多准」，风险与 VoI 就只对**当前模式真正需要的那一帧**计算。过定位与欠定位都成了可审计的预算违规。

**灵感 3（接触证据 → 一条不会被策略同源偏差污染的通道）**
直觉：R69 的「第二意见」FMA 仍是学习模型——流密度是学的、模态权重是学的，策略与观测被同一偏差污染时它们会一起错。接触是**物理**的：守卫说「该接触了」，力/触觉/本体闭合却测不到，则这个模式根本没有物理支撑；反之，力特征与滑移能验证接触是否按物理规律演化。接触似然来自刚体接触与库仑摩擦锥，不来自策略训练分布。**幻影模式 = 守卫永不触发的模式**，接触证据是一个能把它按贝叶斯证据压下去的似然比（引理 19）。这把 R69「模态权重不可信」的致命性从「幻影」这一类上拿掉了。

**灵感 4（帧差分 → 一条非学习的几何自检，但它只证明相对、不证明绝对）**
直觉：同一个相对位姿 T_ij 可以由两种独立路径得到：直接传感器估计，或经机器人运动学把两个帧的估计复合。两者之差就是差分残差 r_ij。它对所有帧同时施加的**共模变换**完全不敏感（T_i→G T_i 时 T_i^{-1}T_j 不变），所以它能免于全局漂移的影响，给出**相对几何**的证书；但同样因为消共模，它对「所有人都一致地错」完全失明。**诚实写清楚：CFR 是一个相对证书，永远不是绝对证书。** 这正是本轮必须承认的边界，也直接指向最大风险。

**灵感 5（接触是双刃剑 → 切换处只承诺有界，不承诺正确）**
直觉：灵巧操作最危险的瞬间是接触建立/断开。此时谈「控制连续、无突变」是自欺——冲量本来就不可避免。能做的是**有界冲击**：预接触速度上限、阻抗上限、力上限、时窗约束，保证 J ≤ J_max 且切换后仍在安全集内。但和 R69 的伺服证书一样，**有界冲击证明稳定，不证明身份**：系统可以以完美受控的冲击抓住一个诱饵物体。新的攻击面随之而来：纹理相同刚度相同的诱饵、对抗触觉纹理、滑移/力信号注入、接触信号重放、以及让所有帧一致地错的共模地图偏置。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（GRIP-RAS 总览）** GRIP-RAS = (HCM, DFL, CFR, TCG, MID, PHM, HVC, CSE, MRD, RAS-WM§)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **接触模式显式**：任何动作块必须条件在某个接触模式 c 上；禁止跨越接触不连续点的无条件连续 rollout（模式切换只能由守卫触发，定义 312）；
(iii) **保真度差异化**：定位算力必须由当前模式的所需保真度 δ_c 辩护；过定位与欠定位同样算预算违规（定义 315）；
(iv) **物理接地优先但有限**：接触证据用于**证伪**模式，优先于学习得到的模态权重；但明确不保证语义身份正确（定理 19 显式排除）。

**定义 311（混合接触模式系统 HCM）** 混合自动机 H = (C, X, E, G, R, {f_c})：C 为离散接触模式集（自由接近、单指接触、多指抓取、指内重定位、滑移恢复、释放等）；X 为连续状态（关节 + 物体位姿）；E ⊆ C×C 为允许切换；G = {G_{c→c'}} 为守卫；R 为切换重置映射；模式内向量场 f_c 光滑。

**定义 312（模式潜变量与守卫）** 接触观测量 y^con_t = (e_t, f^n_t, f^t_t, s_t, τ_t, κ_t)：接触事件、法向/切向力、滑移指示、触觉图、本体运动学闭合。守卫 G_{c→c'}(y)=1 当且仅当观测与「从 c 切到 c'」一致。**模式不变式**：若无守卫触发，则 c_t=c_{t−1}——不允许出现未经守卫见证的接触切换。

**定义 313（模式内流匹配 MID）** 对每个模式 c，速度场 v_θ(x_s,s|o,c)，线性路径 x_s=(1−s)x_0+s x_1，损失 L_FM(c)=E‖v_θ(x_s,s|o,c)−(x_1−x_0)‖²。模式**间**不做 ODE 插值，而由 R 做离散步进。对照 R69：单一 v_θ 会把不连续面抹平成伪峰。

**定义 314（差异化定位帧格 DFL）** 帧格 F={F_1,…,F_n}，各有估计 T_i∈SE(3) 与协方差 Σ_i；任务-模式映射 ρ: C→F×ℝ_+，给出模式 c 所需帧 F_c 与保真度 δ_c（如米级/毫米级）。帧格边 (i,j) 携带由机器人模型给出的已知运动学关系 T_ij，以及由传感器得到的直接估计 T̂_ij。

**定义 315（所需/达成保真度与过定位）** 达成保真度 ε(F)=√(tr Σ_F)（或 95% 半径）。模式 c **可采纳**当且仅当 ε(F_c) ≤ δ_c。定位算力预算 B_loc；若把算力花在 δ 不紧的帧上，称**过定位**；若 ε(F_c)>δ_c 仍执行，称**欠定位**。二者都记为预算违规。

**定义 316（帧一致性残差 CFR）** r_ij = ‖ log(T_i^{-1}T_j) − log(T̂_ij) ‖_{Σ_ij}。差分性质：若所有帧被同一共模变换 G 左乘（T_i→G T_i），则 T_i^{-1}T_j 不变，故 r_ij 不变。因此 r_ij ≤ r_tol 只认证**相对几何**一致；对共模偏置完全不敏感。

**定义 317（接触接地证据 TCG）** 接触似然 p(y^con|c) 由刚体接触与库仑摩擦锥等接触物理先验构造，**不来自策略训练分布**。接触事件检测的假阴性率 ε_fn、假阳性率 ε_fp 为通道固有参数（A99）。

**定义 318（模式后验与幻影证伪 PHM）** 模式后验 w_c ∝ π_c·∏_k p(y_k|c)，π_c 为流模型给出的先验模态权重。**幻影模式** c*：π_{c*} 高，但守卫触发概率 = ε_fn（近 0）。经 n 次独立接触/差分探测，w_{c*}(n) ≤ π_{c*}ε_fn^n / (π_{c*}ε_fn^n + (1−π_{c*})(1−ε_fp)^n) → 0。证伪算子 Φ 把它压出支撑集。

**定义 319（模式级不确定性三分）** U_ale = Σ_c w_c tr Σ_c（模式内噪声）；U_epi = H(w)（接触模式歧义）；U_frame = Σ_c w_c u(F_c;δ_c)（与任务相关的帧不确定性，u 为超出 δ_c 的部分）。三者语义不同、不简单相加，分别进入不同通道（定义 327）。

**定义 320（混合 VoI 交互控制器 HVC）** 信息动作 g ∈ {接触探针（以受限力轻触候选接触点）、差分探针（小位移制造视差/多视角以分离共模）、注视、语言}。VoI(g)=H(w)−E_{y|g}[H(w|y)]；成本 c(g) 含力/时间/帧变更/社交。g*=argmax[VoI−c]，s.t. 探针认证通过（定义 323）且预算未超。若 max[VoI−c]≤0：不交互，走 R69 兜底。要点：对接触模式歧义，接触探针因**便宜且物理接地**通常压倒语言问句。

**定义 321（接触模式安全包络与切换守卫 CSE）** 每个模式有包络：接近速度 ≤ v_max(c)、接触力 ≤ f_max(c)、阻抗在 [K_min,K_max]、时间窗内完成。守卫切换时冲量 J=∫f dt ≤ J_max，且切换后状态仍在安全集。任一不满足 ⇒ 中止并回到安全保持模式。**平滑性被替换为有界冲击性**。

**定义 322（模式风险分解 MRD）** 期望风险 R=Σ_c w_c R_c，但增加**硬支撑约束**：模式 c 可被选中当且仅当 sup R_c ≤ ε_c（最坏情况预算），与 w_c 无关。这防止一个低概率但灾难性的模式被期望平均掉——R69 的模式期望可能正会掩盖它。

**定义 323（接触探针认证）** 探针 g 必须过力/位/时窗认证：力 ≤ f_probe、位移 ≤ ε_probe、可逆、不使当前安全模式失效。不过 ⇒ g 作废，模式保持未消解并走 R69 兜底。

**定义 324（接触欺骗干扰集 ℰ_contact）** 纹理/刚度相同的诱饵物体；对抗触觉纹理；滑移/力信号注入；接触信号重放；使所有帧一致地错的共模地图偏置。并入 AIC：ℰ_GRIP = ℰ_FLUID × ℰ_contact。

**定义 325（证书 J_GRIP）** J_GRIP = (J_FLUID, mode_posterior_ece, frame_residual_stats, contact_evidence_hash, guard_log_hash, impulse_p99, grip_ver)。Valid ⇔ Valid(J_FLUID) ∧ 模式后验校准通过 ∧ 帧一致性在容差内 ∧ 切换冲击包络满足。

**定义 326（模式校准门 MCG-c）** 模式后验需校准（可靠图 + ECE）。ECE>τ_mode 或帧残差越界 ⇒ 禁用接触-VoI，退化为 R69 纯保守——不让不可信的接触后验驱动探针。

**定义 327（三级退避与严格包含）** 若接触证据可用、校准通过、帧一致：用模式条件风险；若模式未消解/探针被拒/被欺骗：把 U_epi 并入保守项（同 R69 定义 307）；若帧不一致或接触通道不可用：整体退化为 FLUID-RAS（单模式、单帧）。⇒ R69 恰为「单模式 + 单帧 + 接触关闭」边界，安全侧不弱于 R69。

**定义 328（时序耦合与自适应）** mode_head(z_t) 廉价预测模式歧义；仅当歧义或滑移疑似时升 K 或触发接触探针；滑移检测触发模式重估；每模式自适应预测时域。保证 P99 实时预算。

```python
# IP-264/268 HCM + MID：离散接触模式 + 模式内流匹配
class HybridContactPolicy:
    def __init__(self, trunk, v_nets, guards, mode_head):
        self.trunk, self.v, self.guards = trunk, v_nets, guards
        self.mode_head = mode_head                       # z -> 模式歧义

    def sample(self, o, c, K, N_step=2):
        z  = self.trunk(o)
        xs = randn(K, D)
        for i in range(N_step):
            xs = xs + (1.0/N_step) * self.v[c](xs, i/N_step, z)   # 模式内光滑
        return [self.decode(x) for x in xs]

    def transition(self, c, y):                          # 模式间离散跳转
        for c2, guard in self.guards[c].items():
            if guard(y): return c2
        return c                                          # 无守卫 -> 不切换

# IP-265/266 DFL + CFR：任务差异化帧格 + 差分一致性
class FrameLattice:
    def required(self, c):      return self.rho[c]        # (F_c, delta_c)
    def admissible(self, c):
        F, delta = self.required(c)
        return self.eps(F) <= delta
    def consistency(self, i, j):                         # 消共模、不证绝对
        return norm(log(self.T[i].inv() @ self.T[j])
                    - log(self.That[i][j]))

# IP-267/269 TCG + PHM：接触后验与幻影证伪
def contact_posterior(prior, evidence, guards):
    w = prior.copy()
    for y in evidence:
        for c in w:
            w[c] *= guards.likelihood(c, y)               # 物理似然，非学习
    return normalize(w)

def phantom_bound(w_cstar, n, eps_fn, eps_fp=0.0):
    a = w_cstar * eps_fn**n
    return a / (a + (1 - w_cstar) * (1 - eps_fp)**n)

# IP-270 HVC：混合 VoI（接触 / 差分 / 注视 / 语言）
def hybrid_voi(w, modes, frames, budget):
    best = None
    for g in candidates(modes, frames):
        if not budget.allow(g):            continue
        if not certify_probe(g):           continue       # 定义 323
        score = entropy(w) - expected_entropy(w, g) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None      # 无利可图 -> R69

# IP-276 主闭环：在 R69 的不确定性处置处插入「模式 / 帧 / 接触」层
def GRIP_RAS_round(M, obs):
    z, o = M.mtm.forward(...)                             # R69 一次前向
    c0 = M.hcm.mode_head(z)
    # 1) 接触证据更新模式后验；歧义则发受限探针
    w = M.tcg.posterior(M.hcm.prior(c0), M.contact_evidence(o))
    if M.tcg.ambiguous(w) and not M.slow_fault_suspect:
        g = M.hvc.hybrid_voi(w, M.hcm.modes, M.frames, M.budget)
        if g is not None:
            y = M.tcg.execute(g)                          # 认证接触/差分探针
            w = M.tcg.update(w, y)
    c_hat = argmax(w)
    # 2) 帧可采纳性 + 差分一致性（相对证书）
    frame_ok = M.frames.admissible(c_hat) and M.frames.consistent()
    # 3) 模式级风险：硬支撑 + 三分不确定性
    if not M.mrd.hard_support_ok(c_hat):                  # sup R_c > eps_c
        c_hat = M.mrd.safe_alternative(w)
    U_ale, U_epi, U_frame = M.mrd.decompose(w, M.hcm)
    U_floor = U_ale + (U_epi + U_frame if not frame_ok else U_epi)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    # 4) 模式内流匹配 + 认证切换
    samples = M.hcm.sample(o, c_hat, K=1 if not M.tcg.ambiguous(w) else 4)
    A = M.ach.propose(samples, x_prime, H=M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not M.cse.envelope_ok(c_hat, A):
        return M.fluid_round(obs)                         # 退化 R69
    # 5) 若接触通道不可信/帧不一致 -> 整体退 R69
    if M.slow_fault_suspect or not frame_ok:
        return M.fluid_round(obs)
    # 6) 审计 + 证书
    M.vqa_x.submit(g, w, frame_ok, c_hat)
    return k, lam, c_hat, (U_ale, U_epi, U_frame)
```

## 3. 推导

**引理 19（接触证据的幻影证伪）** 设 A99：守卫对幻影模式的假阴性率为 ε_fn、对真实模式的假阳性率为 ε_fp，且各次探测条件独立。则对先验 π_{c*} 的幻影模式，经 n 次接触/差分探测后 w_{c*}(n) ≤ π_{c*}ε_fn^n/(π_{c*}ε_fn^n+(1−π_{c*})(1−ε_fp)^n)，当 ε_fn<1 时随 n 指数趋 0。系：**R69 的模态权重未校准对「幻影」不再致命**——物理似然比会压过先验；但对「诱饵」（真实接触、错误身份）仍致命，因为接触似然对它不降（见定义 324 与最大风险）。

**引理 20（帧差分的共模盲区）** 设所有帧估计被同一共模变换 G 左乘：T_i→G T_i。则 T_i^{-1}T_j 不变，故 r_ij 不变。因此：(i) 若 r_ij≤r_tol，则任意两帧的**相对**位姿误差 ≤ r_tol（三角不等式）；(ii) 存在非零共模偏置使 r_ij 仍为 0。系：**CFR 只能签发相对证书，永远不能签发绝对证书**——这是本轮诚实边界，也是安全论证不能越过的红线。

**引理 21（接触切换的有界冲击）** 在 A100（预接触速度 ≤ v_max、阻抗 ≤ K_max、力 ≤ f_max）下，接触建立时的冲量 J=∫f dt ≤ J_max，且切换后状态仍留在该模式安全集内；因此不需要也不可能要求切换处轨迹光滑，只需有界冲击。系：**有界冲击证明受控，不证明接触身份正确**（与 R69「伺服证书证明收敛不证明正确」同构）。

**定理 18（GRIP 严格包含 FLUID-RAS）** 当 |C|=1（无接触切换）、F={全局帧}、接触证据关闭时，GRIP 逐指令等于 FLUID-RAS。一般情形下：(a) 接触模式只**增加**硬支撑约束（定义 322），不放松任何既有安全约束；(b) 差异化定位只在 ε(F_c)≤δ_c 时采纳该模式，从不降低实际保真度；(c) 任何接触通道不可用/帧不一致/校准越界都退化为 FLUID。故安全侧不弱于 R69，效率侧获得「按需定位 + 廉价接触探针」的收益。

**定理 19（接触接地的安全与可证伪性，及其边界）** 在 A99–A100、模式后验校准（定义 326）下：(i) 幻影模式后验指数衰减（引理 19）；(ii) 所有守卫切换满足冲量与力包络（引理 21）；(iii) 接触证据不可用/被欺骗/帧不一致时严格退化为 R69，故安全不降。**显式排除**：本定理不证明「被接触/被操作的物体身份正确」；诱饵、对抗触觉纹理、共模地图偏置可同时通过幻影证伪、帧差分与冲击包络（引理 20、定义 324）。

**定理 20（差异化定位的效率界）** 设模式集 C 的所需保真度为 {δ_c}，全局统一保真度需 max_c δ_c。则差异化定位的期望算力 E[L_diff] ≤ L_global，等号当且仅当所有模式都需要全局最高保真度。系：当接触模式歧义是主导熵时，接触探针的 VoI/成本比优于语言问句，因为 c(contact)≪c(ask)。

## 6. 本轮最大风险

**一句话**：GRIP-RAS 的安全与证伪都押在「接触证据能区分**哪一个**模式/物体」上，但接触是一个局部、低维、易伪造的通道——**一个物理上一致但语义上错误的接触（纹理与刚度相同的诱饵物体、被对抗纹理欺骗的触觉、共模地图偏置下所有帧一致地错）会让幻影证伪、帧差分、冲击包络全部通过，系统于是以完备的证书自信地抓住并操作了错误的东西**——接触一致性证明「碰到了什么」，永远不证明「碰对的是谁」；这正是 R69「问错比不问更危险」在物理世界的镜像：**碰错，比不碰更危险。**

**次级风险与缓解**：
1. **共模几何偏置**（所有帧一致地错，CFR 全盲）→ 引理 20 明确只发相对证书；外部绝对锚（R70 之外的定位源）必须常开，否则退回 R69 纯保守；
2. **接触信号投毒/重放**（力/滑移/触觉注入）→ ℰ_contact 对抗训练 + 证据哈希 + 跨模态一致性（力与视觉接近事件须同步）；
3. **模式后验未校准**（模式权重幻觉）→ MCG-c 校准门，ECE 越界即禁用接触-VoI；
4. **切换抖动/极限环**（守卫在边界反复触发）→ 滞回 + 最短驻留时间 + 冲量预算；
5. **过定位诱发的实时击穿**（帧格逐帧优化）→ 保真度预算 + 只在 δ_c 收紧的帧上升级，其余降采样。

```python
    samples = M.hcm.sample(o, c_hat, K=1 if not M.tcg.ambiguous(w) else 4)
    A = M.ach.propose(samples, x_prime, M.vista.H)
    k = M.c_ras_wm.certified_prefix(A, ..., wm_preds)
    if not M.cse.envelope_ok(c_hat, A): return M.fluid_round(obs)
    if M.slow_fault or not frame_ok:    return M.fluid_round(obs)  # 退 R69
    M.vqa_x.submit(g, w, frame_ok, c_hat)
    return k, lam, c_hat, (U_ale, U_epi, U_frame)
```

## 4. 推导

**引理 19（接触证据的幻影证伪）** A99（守卫幻影假阴性 ε_fn、真实假阳性 ε_fp，探测条件独立）下，幻影 c* 经 n 次探测后 `w_c*(n) ≤ π ε_fn^n / (π ε_fn^n + (1−π)(1−ε_fp)^n)` → 0。系：R69 的模态权重未校准对「幻影」不再致命；对「诱饵」（真实接触、错误身份）仍致命。

**引理 20（帧差分的共模盲区）** 共模左乘 T_i→G T_i 不改变 T_i^{-1}T_j，故 r_ij 不变。于是 r_ij≤r_tol 只给出相对位姿误差上界，存在非零共模偏置使 r_ij 仍为 0。系：**CFR 只发相对证书，绝不发绝对证书**。

**引理 21（接触切换的有界冲击）** A100（v≤v_max、K≤K_max、f≤f_max）下 J=∫f dt ≤ J_max，切换后仍在安全集。系：有界冲击证明受控，不证明接触身份正确（与 R69 伺服证书同构）。

**定理 18（GRIP 严格包含 FLUID-RAS）** |C|=1、F={全局帧}、接触关闭时逐指令等于 FLUID。一般情形：接触模式只加硬支撑约束、差异化定位只在 ε≤δ 时采纳、任何通道失效即退 FLUID ⇒ 安全侧不弱于 R69，效率侧获得按需定位与廉价接触探针收益。

**定理 19（接触接地的安全与可证伪性，及其边界）** 在 A99–A100 与模式校准下：(i) 幻影后验指数衰减；(ii) 切换满足冲击/力包络；(iii) 接触不可用/被欺骗/帧不一致严格退 R69，安全不降。**显式排除**：不证明被操作物体身份正确——诱饵、对抗触觉、共模偏置可同时通过全部证书。

**定理 20（差异化定位效率界）** E[L_diff] ≤ L_global，等号当且仅当所有模式都需要全局最高保真度。系：接触模式歧义主导时，接触探针的 VoI/成本比优于语言问句（c(contact)≪c(ask)）。

## 7. 本轮最大风险

**一句话**：GRIP-RAS 的安全与证伪都押在「接触证据能区分**哪一个**模式/物体」上，但接触是局部、低维、易伪造的通道——**一个物理上一致但语义上错误的接触（纹理刚度相同的诱饵、被对抗纹理欺骗的触觉、共模地图偏置下所有帧一致地错）会让幻影证伪、帧差分、冲击包络全部通过，系统于是以完备的证书自信地抓住并操作了错误的东西**——接触一致性证明「碰到了什么」，永远不证明「碰对的是谁」；这正是 R69「问错比不问更危险」的物理镜像：**碰错，比不碰更危险。**

**次级风险与缓解**：共模几何偏置（CFR 全盲，须外部绝对锚常开，否则退 R69）；接触信号投毒/重放（ℰ_contact 对抗训练 + 证据哈希 + 力-视觉同步）；模式后验未校准（MCG-c，越界即禁用接触-VoI）；切换抖动/极限环（滞回 + 最短驻留 + 冲量预算）；过定位击穿实时（保真度预算，只对 δ_c 收紧的帧升级）。
