# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC/IP-153~160；灵感循环第 2 轮；本轮灵感：「协同控制」×「通用操作」）

> 第 60 轮 SGEC 把「场景」升级为可预测的阻抗先验 π_scene(K|z)，用 SSM×CIEC×EPIR×SERC 实现了「场景先验提前收敛 K_safe、意图即时锁定约束、证据链防消息丢失」。但它仍隐含两个未经检验的假设：
> 1. **通用操作 = 封闭场景词表**：SSM 的 Z_scene 只有 10 个手工标签，π_scene(K|z) 只在标签内部统计、标签之间不可组合。UniBot 的 32 项桌面任务恰恰在换物体、换摆放、换背景、换高度上考泛化；一旦遇到没见过的接触模式，SSM 大概率落入 `unknown`——在最需要先验时退化成「无信息先验」。**「通用」不是「标签更多」，而是「能把没见过的操作拆成见过的基元并组合」**。
> 2. **协同控制 = 单一权威**：CIEC 的意图锁与 SERC 的场景信念都默认只有一个执行体。双臂/多机/人机共享同一物体时，每个执行体有自己的观测 o_i 与先验 π_i：各自锁约束会在共享接触点上产生内力对抗与约束冲突；等待一致性共识则让安全「等共识」（第 57 轮已论证安全不能等共识）。更隐蔽的是，多体观测往往**同源相关**（同相机、同场景先验、同底座模型），朴素融合把相关证据当独立证据，置信度虚高。
> 3. **交叉盲区**：把「通用化的组合先验」交给「协同的分布式融合」，会产生**相关泛化先验的重复计数**——两个执行体用同一个闭集先验解释未见场景，会同时「自信地错」，融合后更自信，直接击穿第 60 轮「场景置信度 < 0.7 回退通用先验」的护栏（融合后变成 0.95）。这正是本轮要正面解决的核心危险。

## 0. 直觉与动机

**灵感 1（通用操作 → 接触模式文法 GMCG）**
直觉：人做没见过的操作，不是先认出「这是什么场景」，而是把它拆成**接触动作的小词**：靠近、压上、沿面滑、翻、抓、抬、放、插、松。桌面→斜面的迁移，本质是把 `press; slide` 换成 `press; slide(θ)`，而不是重新认识一个叫「斜面」的标签。关键洞见：把场景先验从「标签上的分布」改为**基元程序上的分布** π_scene(K|P)，任何新场景先被**文法解析**成基元程序，再由已验证基元的证书**组合出** K_safe。泛化因此不依赖「见过整个场景」，只依赖「每个基元都带证书」。

**灵感 2（通用操作 → 组合安全单调性）**
直觉：组合应当**只会更保守，不会更激进**。多一个基元，就多一组接触约束，安全集只会收缩：`K_safe(P₁;P₂) ⊆ K_safe(P₁) ∩ K_safe(P₂)`。这样「没见过的场景」只要能被拆成已验证基元，就自动落在安全侧；模型对整体的判断可以错，但组合的**方向**不能错。这条单调性是本轮所有泛化声明的地基。

**灵感 3（协同控制 → 物体中心共享场景 + 相关感知融合 CABF）**
直觉：多体协同真正共享的不是「消息」，而是**同一个物体和同一个接触状态**。用物体坐标系作为公共锚点，把各体局部先验对齐到共享隐状态 s_o；再用协方差交叉 + 证据来源去重 + 相关系数折扣，保证「相关证据只降置信、不升置信」。协同不是投票求平均，而是**求交集、取最坏、去重相关**。

**灵感 4（协同控制 → 假设-保证契约 CAGC）**
直觉：团队安全不该等共识。每个执行体只对邻居做一个**有界假设**（你的接触力在 λ^max 内、你的场景估计偏差在 δ 内、你的消息迟到不超过 τ_comm），然后**单方面保证**自己在所有满足该假设的实现下都安全。只要契约图无环、假设被邻居的保证覆盖，团队安全就能**局部推出**。共识只用来优化力分配，不用来判安全。

**灵感 5（多方意图调和 + 跨体因果证据）**
直觉：多人/多臂的意图会冲突：一个说「快」，一个说「轻」；一个说「抬」，一个说「放」。规则必须是：**安全否决一票生效、偏好取交集、冲突显式暴露、过期自动释放**。证据链也要升级：第 60 轮的 EPIR 只保证单体内 seq 连续；多体要保证 **contact-before-lift 的因果顺序**，用向量时钟而不是全局总序（跨机总序不可得，也不需要）。

**灵感 6（PCE+++++ → 协同认知预算）**
直觉：新增 B_grammar（文法解析/组合外推）、B_align（跨体场景对齐）、B_comm（跨体通信）、B_causal（因果合并）；任一耗尽即降级到「单体 SGEC + 最保守基元程序」，绝不让协同/泛化越权。协同和泛化都是**放大器**，放大器必须先有独立的限幅器。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（通用操作接触文法 GMCG）** 𝔊 = (P, Ω, R, π_P)：
- 基元集合 P = {approach, press, slide, roll, grasp, lift, place, insert, release}；
- 组合算子 Ω = {;, ∥, ?, *}（顺序、并发、条件、重复）；
- 产生式 R：S → p | S;S | S∥S | S?S | S*；
- 基元程序 P ∈ L(𝔊)，基元先验 π_P(p) 与组合先验 π_op(ω)。

场景不再等于标签：给定观测 O，文法解析
`P* = argmax_{P∈L(𝔊)} P(P|O)·π_P(P)`（Chart/Viterbi 解析）。
场景先验改写为 π_scene(K|P*)。若后验 `P(P*|O) < τ_grammar`，不进入 `unknown`，而是回退到**最小证书程序** `P_min = approach;press`（只贴、只压，不滑不抬），并标记 `grammar_low_coverage`。
- **组合安全单调性**：对任意 P₁,P₂，`K_safe(P₁;P₂) ⊆ K_safe(P₁) ∩ K_safe(P₂)`；
- **通用覆盖度**：`cov(P) = Σ_{p∈P} π_P(p)·1[cert(p)] / |P|`，只有 `cov(P) ≥ τ_cov` 才允许组合证书；
- **交互残差**：`r_int(P) = ||K_safe(P₁∥P₂) − (K_safe(P₁)∩K_safe(P₂))||`，要求 `r_int ≤ ε_int`，否则拒绝并发、退化为顺序执行。

**定义 162（物体中心共享场景状态 OCSS）** 对共享物体 o：隐场景状态 s_o ∈ S_o；执行体 i 的观测 `o_i = h_i(s_o, ξ_i)`。对齐算子
`A_i: π_i(K|z_i) → π_i^o(K|s_o) = π_i(K|z_i)·J_i(z_i→s_o)`
其中 J_i 为把局部场景坐标/朝向/尺度变换到物体坐标系的雅可比。共享场景是因子图
`B = (s_o, {π_i^o}, Ψ_align)`，Ψ_align 惩罚跨体锚点不一致。对齐后的公共接触点集 `C_shared = ∩_i C_i` 才允许并发执行；对齐不可信时逐级扩大 `δ_align`，而不是强行合并。

**定义 163（相关感知信念融合 CABF）** 给定各体后验 `{π_i(K)=N(μ_i,Σ_i)}`、证据来源映射 `source(·)`、相关上界 `ρ̂_ij ∈ [0,1]`：
- **来源去重**：同源证据组 `G_s` 只保留一份，log-odds 只计一次；
- **有效样本量（直觉）**：`n_eff = n / (1 + (n−1)·ρ̂)`，相关越强，独立证据越少；
- **相关折扣**：`γ_ij = sqrt(1−ρ̂_ij)`，证据按 γ 折减；
- **协方差交叉（严格实现）**：`Σ_fused = (Σ_i ω_i Σ_i^{-1})^{-1}`，`ω_i≥0, Σω_i=1` 且最小化 `det(Σ_fused)`；
- **过度自信护栏**：令 `c_i` 为单体最高置信、`c_f` 为融合置信，若 `c_f − max_i c_i > Δ_max`，判定「相关伪独立」，冻结融合、退回 `max_i c_i` 并标记 `fusion_correlated`。
一致性要求：`Σ_fused ⪰ Σ_true`（PSD），从而 `c_fused ≤ c_true` 的置信上界。数值直觉：两体各 0.75 置信、ρ̂=0.8 时，朴素独立融合得到 0.90，而有效样本量只剩 1.11 份证据，CABF 给出约 0.77；相关系数不是修辞，是把 0.90 拉回 0.77 的那只手。

**定义 164（假设-保证场景契约 CAGC）** 执行体 i 的契约 `C_i = (A_i, G_i)`：
- 假设 A_i：对每个邻居 j，`||λ_j|| ≤ λ_j^max`、`||s_o − ŝ_j|| ≤ δ_j`、`τ_comm ≤ τ_max`；
- 保证 G_i：`K_i ∈ K_safe_i(A_i)`、`||λ_int||_W ≤ β_int`、`x_{t+1} ∈ K_rob(Σ_i; B(λ_{−i},Δ_{−i}))`；
- **组合规则**：若契约图 𝒢_C 无环、且对每条边 (i→j) 有 `A_i ⊆ G_j`（i 的假设被 j 的保证覆盖），则 `∧_i G_i` 成立；
- **不等共识**：安全判定只用 (A_i,G_i)；一致性协议只用于最小化内力/优化力分配。通信失效时 i 单方面取邻居最坏界并收缩 K_i。

**定义 165（多方意图调和 MAIR）** 多方意图 {I_1,...,I_k}，各映射为闭凸约束集 `C_i = ϕ(I_i)`：
- **安全否决**：`∃i: I_i ∈ {danger, stop} ⇒ C_team = STOP`，无需多数；
- **保守交集**：否则 `C_team = ∩_i C_i`（「快」∩「轻」= 又快又轻，但都不越硬安全集 K_hard）；
- **冲突暴露**：若 `∩ C_i = ∅`，取风险最高意图的约束并置 `intent_conflict=True`，禁止静默平均；
- **时序**：I_i 有效期 `[t_i, t_i+τ_i]`，过期即释放；硬安全集 K_hard 永不释放；
- **权限**：人类意图 ≥ 机器自主意图，但任何意图不得扩张 K_hard。

**定义 166（通用协同操作闭环 GCML）** 算子 `GCML({M_i}, o, {I_i}, δ_f_req)`：
```
① GMCG: P* ← parse(O); π_scene(K|P*) ← compose(P*)
② OCSS: π_i^o ← A_i(π_i); 对齐 s_o、公共接触点 C_shared
③ CABF: π_fused ← corr_fuse({π_i^o}, ρ̂); 触发过度自信护栏
④ CAGC: 各体构造 (A_i,G_i)，局部求 K_safe_i
⑤ MAIR: C_team ← reconcile({C_i}); 冲突→保守回退
⑥ Compile: K_safe_i^+ ← EEIS.compile(δ_f_req, π_fused, C_team, K_safe_i)
⑦ Allocate: λ ← cooperative_force_alloc(K_safe_i^+, β_int, price_max)
⑧ Execute: 并发执行，采集 EV-exec_i
⑨ CEC: causal_merge({EV-exec_i}, VC_i)
⑩ Update: 文法后验/场景信念/相关矩阵 ρ̂ 更新
⑪ Return (P*, π_fused, {K_safe_i^+}, C_team, Cert_team, CEC.status)
```

**定义 167（协同认知预算 PCE+++++）** `B_cog+ = (B_grammar, B_align, B_comm, B_causal, B_scene, B_intent, B_exec)`。降级：
- B_grammar 耗尽 ⇒ 最小证书程序 P_min（只 approach;press）；
- B_align 耗尽 ⇒ 各体自坐标系 + δ_align 放大，公共接触点取更小集；
- B_comm 耗尽 ⇒ 只跑 CAGC 的单边最坏假设，不跑共识优化；
- B_causal 异常 ⇒ 退回各体 EPIR，证据标 `local_only`；
- B_scene/B_intent/B_exec 沿用第 60 轮。

VOI 扩展：`voi_cog+(π) = VOI_meta_pessimistic(π) − cost_cog(π) − cost_coop(π) − cost_exec(π)`，其中
`cost_coop = λ_gram·Parse_cost + λ_align·Align_cost + λ_comm·Comm_cost + λ_causal·Merge_cost`。

**定义 168（跨体因果证据链 CEC）** 每个执行体维护向量时钟 `VC_i ∈ ℕ^k`，事件 e 携带 `VC(e)`：
- **happens-before**：`e → f` 当且仅当 `VC(e) ≤ VC(f)` 逐分量且存在严格分量；
- **合并**：`VC_new = VC_i ⊔ VC_j = max(VC_i, VC_j)`；
- **因果屏障**：对关键谓词（contact-before-lift、press-before-slide），若收到的 f 存在未到达的前驱 e（`VC(e) ≰ VC(f)` 且 e 不在影子区），则挂起到 e 到达；
- **不追总序**：跨机全局总序不可得也不需要；只保证**因果一致**与关键谓词顺序。
正确性：在最终重传 + 影子区窗口内，所有关键谓词的前驱均被投递。

### IP-161 GMCG（接触文法）

```python
class ContactGrammar:
    def __init__(self):
        self.primitives = ['approach', 'press', 'slide', 'roll', 'grasp',
                           'lift', 'place', 'insert', 'release']
        self.prior = {p: 1.0 / len(self.primitives) for p in self.primitives}
        self.safe_cert = {}          # p -> K_safe(p), 每个基元独立验证
        self.tau_grammar = 0.6
        self.tau_cov = 0.8

    def parse(self, obs):
        programs = self._derive_candidates(obs, max_depth=4)
        best = max(programs, key=lambda P: self._logprob(P, obs))
        if self._posterior(best, obs) < self.tau_grammar:
            return ['approach', 'press'], 'low_coverage'   # 最小证书程序，不是 unknown
        return best, 'ok'

    def compose_safe_set(self, P):
        K = None
        for p in P:
            if p not in self.safe_cert:
                return None                                # 缺证书 ⇒ 不组合
            K = self.safe_cert[p] if K is None else (K & self.safe_cert[p])
        return K                                           # 交集单调：只会收缩
```

```python
def align_to_object(pi_local, T_obj_from_local, Q_align):
    mu_o = T_obj_from_local @ pi_local.mu
    Sigma_o = T_obj_from_local @ pi_local.Sigma @ T_obj_from_local.T + Q_align
    return Gaussian(mu_o, Sigma_o)

def shared_contact_set(agents):
    # 各体接触集视作点集/凸集，取交集；空集则不并发
    return reduce(set.intersection, [a.local_contact_set for a in agents])
```

### IP-163 CABF（相关感知融合）

```python
def correlation_aware_fuse(posteriors, source_ids, rho_hat, delta_max=0.1):
    groups = dedup_by_source(posteriors, source_ids)      # 同源只算一次
    weights = covariance_intersection_weights(groups)     # min det(Sigma_f)
    Sigma_f = inv(sum(w * inv(g.Sigma) for w, g in zip(weights, groups)))
    mu_f = Sigma_f @ sum(w * inv(g.Sigma) @ g.mu
                         for w, g in zip(weights, groups))
    c_single = max(g.confidence * sqrt(1 - max_corr(g, rho_hat))
                   for g in groups)
    c_fused = gaussian_confidence(mu_f, Sigma_f)
    if c_fused - c_single > delta_max:
        return max(groups, key=lambda g: g.confidence), 'fusion_correlated'
    return Gaussian(mu_f, Sigma_f), 'ok'
```

### IP-164 CAGC（假设-保证契约）

```python
class AssumeGuaranteeContract:
    def __init__(self, assumptions, guarantee_builder):
        self.A = assumptions                 # 邻居力/场景偏差/时延的界
        self.build_G = guarantee_builder

    def local_guarantee(self, state, worst_neighbors):
        if not self.A.covers(worst_neighbors):
            return None                      # 假设被违反 ⇒ 单边保守回退
        K = self.build_G(state, worst_neighbors)
        return K if K.nonempty and K.margin > self.theta else None

def team_safe(contracts, edges):
    if has_cycle(edges):
        return False                         # 有环则不组合，退化为单体
    return all(contracts[i].A.subset_of(contracts[j].G_bound)
               for (i, j) in edges)          # A_i ⊆ G_j
```

### IP-165 MAIR（多方意图调和）

```python
def reconcile_intents(intents, now, K_hard, tau_default=2.0):
    active = [I for I in intents if I.t_expire > now]
    if any(I.kind in ('danger', 'stop') for I in active):
        return ConstraintSet.stop(), {'veto': True}      # 一票否决，无需多数
    sets = [phi(I) for I in active]
    C = intersect_all(sets)
    if C.is_empty():
        I_max = max(active, key=lambda I: risk(I))
        return phi(I_max) & K_hard, {'conflict': True}   # 显式冲突，不静默平均
    return C & K_hard, {'conflict': False}               # 偏好交集，硬安全集不可越
```

### IP-166 GCML（通用协同操作闭环）

```python
def general_cooperative_manipulation_loop(agents, obj, intents, delta_f_req):
    grammar = agents[0].grammar
    P_star, status = grammar.parse(collect_observations(agents))
    pi_scene = grammar.compose_safe_set(P_star)

    aligned = [align_to_object(a.pi, a.T_obj, a.Q_align) for a in agents]
    C_shared = shared_contact_set(agents)

    pi_fused, fuse_status = correlation_aware_fuse(
        aligned, [a.source_id for a in agents], estimate_corr(agents))

    contracts = [a.make_contract() for a in agents]
    K_local = [c.local_guarantee(a.state, worst_case(agents, a))
               for c, a in zip(contracts, agents)]
    C_team, intent_status = reconcile_intents(intents, now(), HARD_SAFE)

    K_final = [eeis.compile(delta_f_req, pi_fused, C_team, K, pi_scene)
               for K in K_local]
    lam = cooperative_force_alloc(K_final, beta_int=0.2, price_max=0.5)

    ev = execute_concurrently(agents, lam)
    cec = [a.cec.local_event(a.id, e) for a, e in zip(agents, ev)]
    merged = causal_merge(cec)

    return {
        'program': P_star, 'grammar_status': status,
        'pi_fused': pi_fused, 'fusion_status': fuse_status,
        'K_final': K_final, 'C_team': C_team,
        'intent_status': intent_status, 'cec': merged,
    }
```

```python
class CooperativeCognitiveBudget:
    def __init__(self, grammar=100, align=50, comm=20, causal=100, base=None):
        self.B = {'grammar': grammar, 'align': align, 'comm': comm, 'causal': causal}
        self.used = {k: 0 for k in self.B}
        self.base = base or CognitiveBudget()

    def degrade_mode(self):
        if self.used['grammar'] >= self.B['grammar']:
            return 'minimum_program', ['approach', 'press']
        if self.used['align'] >= self.B['align']:
            return 'local_frames', None
        if self.used['comm'] >= self.B['comm']:
            return 'no_consensus', None
        if self.used['causal'] >= self.B['causal']:
            return 'local_evidence', None
        return 'normal', None
```

### IP-168 CEC（跨体因果证据链）

```python
class CausalEvidenceChain:
    def __init__(self, k):
        self.vc = [0] * k
        self.delivered = {}
        self.pending = {}
        self.shadow = {}

    def local_event(self, i, payload):
        self.vc[i] += 1
        e = Event(vc=tuple(self.vc), payload=payload)
        self.shadow[e.id] = e
        return e

    def receive(self, e):
        if any(p not in self.delivered and p not in self.shadow
               for p in e.predecessors()):
            self.pending[e.id] = e
            return 'buffered'                 # 因果屏障：等前驱
        self.delivered[e.id] = e
        self.vc = [max(a, b) for a, b in zip(self.vc, e.vc)]
        for pid in list(self.pending):
            if self.pending[pid].predecessors() <= set(self.delivered):
                self.receive(self.pending.pop(pid))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| GMCG | O(\|P\|³·\|O\|) Chart 解析；组合 O(\|P\|) | O(\|L(𝔊)\|≤D) | 组合安全单调，缺证书即拒绝 |
| OCSS | O(k·d²) 坐标变换 | O(k·d²) | 对齐雅可比可逆/有界，公共接触点取交 |
| CABF | O(k³) 权重优化 / O(k·d³) CI | O(k·d²) | Σ_fused ⪰ Σ_true，置信不虚高 |
| CAGC | O(k·QP) 局部求解 | O(k) | 无环 + A_i⊆G_j ⇒ 团队安全；不等共识 |
| MAIR | O(k) | O(k) | 安全否决、交集、冲突显式 |
| CEC | O(k·\|buffer\|) 合并 | O(k·N_shadow) | 因果一致，关键谓词前驱必达 |

**正确性定理（CGEM：组合安全 + 协同不虚高）** 假设 A66–A70 成立：
- **(A66)** GMCG：每个基元 p 有已验证安全集 `K_safe(p)`，且组合交互残差 `r_int ≤ ε_int`；
- **(A67)** OCSS：对齐变换可逆且有界，`δ_align` 覆盖真实坐标偏差；
- **(A68)** CABF：相关上界估计满足 `ρ̂_ij ≥ ρ_ij`，来源去重正确；
- **(A69)** CAGC：契约图无环，且每个 `A_i` 被邻居的 `G_j` 覆盖；
- **(A70)** CEC：最终重传可达，影子区窗口覆盖关键谓词前驱。

则：
1. **组合安全**：若 P* 的每个基元带证书且交互残差 ≤ ε_int，则 `K_safe(P*) ⊆ ∩_{p∈P*} K_safe(p)` 在 ε_int 扰动下仍安全（组合不扩张安全集）。
2. **泛化安全**：对未见场景，若存在解析 P* 且 `cov(P*) ≥ τ_cov`，则无需见过该场景即可给出带证书的 K_safe；否则回退 P_min，安全集最保守。
3. **融合不虚高**：若 A68 成立，则 `Σ_fused ⪰ Σ_true`、`c_fused ≤ c_true`，过度自信护栏不漏报「相关伪独立」。
4. **协同安全不等共识**：若 A69 成立，则 `∧_i G_i` 可局部推出；通信延迟/丢包只降低性能，不破坏安全性。
5. **因果完整**：若 A70 成立，则关键谓词（contact-before-lift）在跨体证据链中因果一致、可重建。

**与第 60 轮 / 第 57 轮的边界**：第 60 轮解决「单体场景先验→约束」，第 57 轮解决「力矩层安全不能等共识」；本轮把「不被场景词表限制」与「不被相关证据虚高」同时下沉到**场景-泛化层**。三者是正交的：组合证书管泛化方向，CAGC 管多体安全，CABF 管置信标定。

### IP-161 GMCG（接触文法）

```python
class ContactGrammar:
    def __init__(self):
        self.primitives = ['approach', 'press', 'slide', 'roll', 'grasp',
                           'lift', 'place', 'insert', 'release']
        self.prior = {p: 1.0 / len(self.primitives) for p in self.primitives}
        self.safe_cert = {}          # p -> K_safe(p)，每个基元独立验证
        self.tau_grammar, self.tau_cov = 0.6, 0.8

    def parse(self, obs):
        programs = self._derive_candidates(obs, max_depth=4)
        best = max(programs, key=lambda P: self._logprob(P, obs))
        if self._posterior(best, obs) < self.tau_grammar:
            return ['approach', 'press'], 'low_coverage'   # 最小证书程序，不是 unknown
        return best, 'ok'

    def compose_safe_set(self, P):
        K = None
        for p in P:
            if p not in self.safe_cert:
                return None                                # 缺证书 ⇒ 拒绝组合
            K = self.safe_cert[p] if K is None else (K & self.safe_cert[p])
        return K                                           # 交集单调：只收缩，不扩张
```

### IP-163 CABF（相关感知融合）

```python
def correlation_aware_fuse(posteriors, source_ids, rho_hat, delta_max=0.1):
    groups = dedup_by_source(posteriors, source_ids)      # 同源证据只计一次
    weights = covariance_intersection_weights(groups)     # min det(Sigma_f)
    Sigma_f = inv(sum(w * inv(g.Sigma) for w, g in zip(weights, groups)))
    mu_f = Sigma_f @ sum(w * inv(g.Sigma) @ g.mu
                         for w, g in zip(weights, groups))
    c_single = max(g.confidence * sqrt(1 - max_corr(g, rho_hat)) for g in groups)
    c_fused = gaussian_confidence(mu_f, Sigma_f)
    if c_fused - c_single > delta_max:
        return max(groups, key=lambda g: g.confidence), 'fusion_correlated'
    return Gaussian(mu_f, Sigma_f), 'ok'
```

**数值例子**：两体各 0.75 置信、`ρ̂=0.8`。朴素独立融合 log-odds 相加 ⇒ 0.90；有效样本量 `n_eff=2/(1+0.8)=1.11` ⇒ 约 0.77；CABF 取二者中不高于单体的保守值，护栏不触发但虚高被消除。

```python
class AssumeGuaranteeContract:
    def __init__(self, assumptions, guarantee_builder, theta=0.1):
        self.A = assumptions                 # 邻居力/场景偏差/时延的界
        self.build_G = guarantee_builder
        self.theta = theta

    def local_guarantee(self, state, worst_neighbors):

            return None                      # 假设被违反 ⇒ 单边最坏界回退
        K = self.build_G(state, worst_neighbors)
        return K if K.nonempty and K.margin > self.theta else None

def team_safe(contracts, edges):

        return False                         # 有环则不组合，退化单体
    return all(contracts[i].A.subset_of(contracts[j].G_bound) for (i, j) in edges)
```

### IP-168 CEC（跨体因果证据链）

```python
class CausalEvidenceChain:
    def __init__(self, k):
        self.vc = [0] * k
        self.delivered, self.pending, self.shadow = {}, {}, {}

    def local_event(self, i, payload):
        self.vc[i] += 1
        e = Event(vc=tuple(self.vc), payload=payload)
        self.shadow[e.id] = e
        return e

    def receive(self, e):
        if any(p not in self.delivered and p not in self.shadow
               for p in e.predecessors()):
            self.pending[e.id] = e
            return 'buffered'                 # 因果屏障：等前驱，不追总序
        self.delivered[e.id] = e
        self.vc = [max(a, b) for a, b in zip(self.vc, e.vc)]
        for pid in list(self.pending):
            if self.pending[pid].predecessors() <= set(self.delivered):
                self.receive(self.pending.pop(pid))
        return 'delivered'
```
