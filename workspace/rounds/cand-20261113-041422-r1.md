# 第 65 轮（承接第 64 轮「GRIP 接触接地四层闭环」IP-204~213；灵感循环 II 第 4 轮；本轮灵感：「决策规划」×「状态机」）

> 第 64 轮用接触接地（CGG）把几何先验变成可证伪假设，但它自述的最大风险一针见血：**当 F/T 偏置、漂移、饱和或接触模型错误时，CGG 会把「传感器/模型错误」误判为「几何幻觉」——在正确几何上主动降级、在错误几何上放行，而 APP 的主动探测还可能对未知易损物体施加超限力。** 根因不在力觉本身，而在判决结构：**`标量残差 → 单阈值 → 二值 demote/promote` 是一个没有「归因能力」的反应式结构**，一个残差同时混叠了五种故障源。本轮引入两个正交的离散层来改造它：
>
> **用「决策规划」把二值判决升级为多假设主动诊断（该不该测、测什么最能分清故障、信息值多少），用「状态机」把分散的数值裕度升级为可验证、可监控、带滞回的安全模式自动机（危险模式不可达、失败必可退）。安全不再只是「算出来 ≥0」，而是「离散状态与转移被证明过，且运行时守得住」。**

## 0. 直觉与动机

**灵感 1（决策规划 → 从「反应式判决」到「主动信息决策」）**
直觉：第 64 轮的 CGG 看到残差超阈就 demote 几何，但这等于「体温高就切掉某个器官」。大残差至少有五种解释：几何幻觉、F/T 常值偏置、接触模型错误（软接触/未建模动力学）、传感器饱和、微滑移。**决策规划最有价值的不是「把任务做完」，而是「在信息不足时先做一个最能消除不确定性的动作」**。把故障源 `h` 当隐变量、维护诊断信念 `b(h)`，用主动信息收集（AA-POMDP）选动作最大化 `I(H; O | a, b)`——自由空间扫动暴露常值偏置、已知刚度标定块暴露模型误差、轻触疑似表面暴露幻觉几何。**这把「猜谁错了」变成「设计一个实验分清谁错了」**，从根上避免第 64 轮的误归因。

**灵感 2（状态机 → 从「数值裕度」到「可验证离散不变式」）**
直觉：第 64 轮的安全是一个连续量 `ρ_safe = min(ρ_rob, ρ_dir, ρ_slip, ρ_force) ≥ 0`。但真正决定安全的很多是**离散问题**：什么时候允许探针？探针失败后往哪退？几何主导和力觉主导怎么切换才不抖动？这些用连续裕度表达不了。有限状态自动机恰好能做三件连续量做不到的事：① 用不变式（invariant）表达「处于探针模式 ⇒ 力 ≤ 易损阈值且退避边存在」；② 用模型检验证明「危险模式不可达、无死锁」；③ 用模式滞回（hysteresis）消除 `geo_degraded` 在阈值附近的来回抖动。**安全从「每拍算一个数」变成「证明一条离散轨迹永远合法」。**

**灵感 3（两灵感合流 → 条件规划 over 三层自动机）**
直觉：任务规划不应再是固定技能序列 `τ = [σ1, σ2, …]`，而应是**条件计划 / 策略树**：先做诊断，按诊断结果分叉到不同技能子树。技能本身也建模为自动机（approach → contact → execute → release → recover），任务自动机、技能自动机、模式自动机做同步乘积。CSP-F 升级为 CCSP-F，搜的是策略树而非线性序列，从而在第 64 轮「诊断不确定」的场景下不再一错到底。

**灵感 4（合流 → DAMS：Decision-planned Automaton Mode Supervision 决策规划驱动的可验证安全状态机）**
DAMS 在第 64 轮 GRIP 上挂三层新结构：
- **诊断层 FHA**：多假设故障诊断，输出 `b(h)`，不再输出二值判决；
- **监督层 SAM**：安全模式自动机 + 守卫证书 + 运行时监控 + 失效安全回退；
- **决策层 BCP**：信念空间约束 POMDP / 条件规划，同时决定「做任务」还是「先做判别实验」及其分支。

闭环：LiDAR 几何 + 力觉取证 → FHA 更新信念 → SAM 决定当前模式（nominal / geo / force / disc / probe / calib / recover / safe_idle）→ 若信念不足则 BCP 选判别动作 → CCSP-F 生成策略树 → 守卫证书逐边校验 → 实时路径执行并监控不变式 → 证据回灌信念与证书。**第 64 轮是「几何-技能-干扰-接触」四层连续闭环，DAMS 在其上加「诊断-模式-决策」离散层，使安全具备可证明的离散骨架。**

**灵感 5（GRIP 组件的原位升级）**
- **CGG → DGG（Diagnosis-Grounded Geometry）**：只输出证据 `o_t = (T_t, e_t^struct, ρ_force, ρ_slip, sat_t)` 与假设似然，把 demote/promote 交给 SAM，CGG 不再单独裁决。
- **USL/TSL → TSA（Tactile Skill Automaton）**：每个技能建模为一个小自动机，前后置与不变式用可检验的离散谓词 + 时序逻辑表达，并显式带 recover 边。
- **CSP → CCSP-F**：条件规划，输出 AND-OR 策略树（诊断结果作 AND 分支），叶子为任务目标或 safe_idle。
- **OLP-F → OLP-M**：投影输入增模式 one-hot 与诊断信念摘要（熵、top-2 优势比）；遗憾界加模式切换项。
- **AIC-F → AIC-D**：干扰集增「故障类漏检 / 似然误配 / 诊断延迟」，认证对象从「单次判决」变成「诊断-守卫-回退」闭环。
- **J_grip → J_dams**：证书增 `mode_trace_hash, guard_cert_hash, belief_hash, plan_tree_hash, automaton_verify_ver, liveness_witness`。
- **新增 FHA / SAM / BCP / GCM**：故障假设诊断器、安全模式自动机、信念空间条件规划器、守卫证书监控器。

## 1. 形式化定义（增量：定义 217–230）

- **定义 217（DAMS 闭环）**：DAMS = (GRIP, H, b, A, Π, G, V, J_dams)。GRIP 为第 64 轮底座；H 故障假设集；b 诊断信念；A 为任务/技能/模式三层自动机的同步乘积；Π 为条件计划策略树；G 为守卫证书集合；V 为模型检验结论；J_dams 为扩展证书。不变式：**诊断、条件规划、证书重证都在语义流；模式监控与不变式检查在实时流且只读；实时流零学习写操作。**
- **定义 218（三层自动机与乘积）**：任务自动机 `A_task=(Q_t,q_t0,Σ_t,→_t,F_t)`，字母表 Σ_t 含技能名、诊断结果、探针结果、故障事件；技能自动机族 `{A_σ}`，状态含 approach/contact/execute/release/recover；模式自动机 `A_mode`（定义 221）。系统 `A = A_task ∥ A_skill ∥ A_mode`，在「派发 / 完成 / 故障 / 诊断更新」事件上同步。**规划与安全证明都在 A 上做，连续控制仍由 GRIP 实时流承担。**
- **定义 219（故障假设集与诊断信念）**：H = {h0 标称, h_geo 几何幻觉, h_fb 力觉偏置/漂移, h_cm 接触模型错误, h_sat 传感器饱和, h_slip 微滑移}。证据 `o_t = (T_t, e_t^struct, ρ_force,t, ρ_slip,t, sat_t, contact_t)`，其中 `e_t^struct` 为残差的结构特征（自由空间是否仍残差、残差是否随载荷线性增长、方向是否恒定）。各假设给生成似然 `L(o_t | h, a)`；信念 `b_t(h) = η·L(o_t|h,a_{t-1})·b_{t-1}(h)`。**诊断阈值**：仅当 `max_h b(h) ≥ θ_diag` 且优势比 `b(h_1)/b(h_2) ≥ θ_odds` 才允许据此切换模式，否则进入 `q_disc`。
- **定义 220（判别性信息增益与安全约束）**：动作 a 的期望信息增益 `EIG(a) = I(H; O_a | b) = H(b) − E_{o∼p(o|b,a)}H(b'|o)`。动作可选当且仅当 `ρ_safe^wc(a) ≥ 0`（对 `φ∈B(φ̂,r)`、`h` 在 `b(h)≥θ_diag`、偏置在 ℰ_F 内取最坏）且存在已认证退避边。选 `a* = argmax_a EIG(a)` s.t. 安全与预算约束。**无安全判别动作时不降级、不冒险，直接进 `q_safe_idle`。**
- **定义 221（安全模式自动机）**：`Q_m = {q_nom, q_geo, q_force, q_disc, q_probe, q_calib, q_recover, q_safe_idle}`。不变式示例：
  - `Inv(q_probe)：f_cmd ≤ f_safe(class) ∧ ρ_safe ≥ 0 ∧ RetreatEdge(q_probe) 已认证`；
  - `Inv(q_disc)：驻留时间 ≤ T_disc ∧ 不执行不可逆任务动作`；
  - `Inv(q_safe_idle)：K = K_compliant_retreat ∧ 仅允许人类接管/重新标定`。
  边守卫由 `b`、`ρ_safe`、证书 `Cert_e` 共同构成；进入 `q_disc` 的阈值 `θ_in` 与退出阈值 `θ_out = θ_in − δ_hys` 构成**信念滞回**，消除模式抖动。
- **定义 222（守卫证书）**：对边 `e=(q,a,q')`，`Cert_e=(I_q, I_q', R_e, method, margin)`，要求 `∀s∈R_e`（含 `φ∈B(φ̂,r)`、`h` 满足 `b(h)≥θ_diag`、传感器扰动在 ℰ_F 内）执行 a 后仍满足 `I_q'`。`method ∈ {interval, SoS, scenario+concentration}`。证书失败 ⇒ 该边不可用；恒可用的失效安全边 `e0=(q, retreat, q_safe_idle)` 是硬兜底。**关键：证书不是「再算一个裕度」，而是「对离散转移的全称量化证明」。**
- **定义 223（信念空间约束 POMDP）**：`P=(S,A,O,T,Z,R,γ,ξ)`，`S = (φ, h, C, q_mode, skill_state, …)`；`A = 任务技能 ∪ 探针 ∪ 标定 ∪ 退避 ∪ 请求人类`；`R = task_progress − λ_r·risk − λ_c·cost − λ_i·info_cost`；约束 `CVaR_α(risk) ≤ ξ`。用 point-based / option-based 求解，选项即 TSA 技能自动机。
- **定义 224（条件计划 / 策略树）**：`π: B → A` 表示为一棵 AND-OR 树：OR 节点选择动作，AND 节点按诊断结果 `o` 分支。CCSP-F 在 A 上搜索这样的树，叶子是任务目标或 `q_safe_idle`。**这取代第 64 轮的线性技能序列 τ。**
- **定义 225（TSA 触觉技能自动机）**：`σ = (A_σ, pre, eff, inv, force_spec, θ_σ, recover_edge)`；`pre/eff/inv` 用可检验的离散谓词 + 时序逻辑表达；`recover_edge` 指向技能内部的安全退出态。技能组合 = 自动机乘积。
- **定义 226（OLP-M 模式感知在线投影）**：`x''' = [x''; onehot(q_mode); b_summary]`，`b_summary` 含 `H(b)`、top-2 优势比、`geo_degraded`、`contact_unobservable`。遗憾界 `G̃_mode = G̃_force + L_mode·N_switch`，`N_switch` 为模式切换次数；滞回直接降低该项。
- **定义 227（AIC-D 故障觉知认证）**：`ℰ_D = ℰ_F × ℰ_H`，`ℰ_H = {h∉H 的漏检故障类, 似然误配 δ_L, 诊断延迟 τ_diag}`。`ρ_dams` 在 ℰ_D 上重算；认证对象是「诊断 → 守卫 → 回退」闭环，而非单次 residual 判决。
- **定义 228（J_dams 扩展证书）**：`J_dams = (J_grip, mode_trace_hash, guard_cert_hash, belief_hash, plan_tree_hash, automaton_verify_ver, liveness_witness)`。`Valid(J_dams) ⇔ Valid(J_grip) ∧ 模式轨迹 ∈ L(A_mode) ∧ 每条跨越边有有效 Cert_e ∧ 活性见证存在 ∧ (q_probe 期间 f ≤ f_safe)`。
- **定义 229（运行时模式监控与失效安全）**：监控器每拍检查当前模式不变式与即将跨越边的 guard；若不变式违反风险 `> δ_mon` 或出现未建模事件（证据不在 H 的支撑内、期望似然低于阈值）→ **强制 `q_safe_idle` + compliant retreat**，并写 `mode_trace`。监控器零学习、纯只读，保证最低延迟。
- **定义 230（DAMS 算子）**：三层循环——语义流 `[几何/力觉取证 → FHA 信念更新 → SAM 选模式]`；决策流 `[q_disc 则 BCP 选判别动作 → CCSP-F 生成策略树 → 逐边守卫证书校验 → 派发首技能]`；实时流 `[锚读 → GRIP 实时组件 → 模式监控/不变式检查 → 派发 → J_dams 构建]`；慢速流 `[模型检验、证书重证、信念校准、假设集扩充]`。

## 2. 关键算法骨架

```python
# FHA：证据回灌，只更新信念，不做二值判决
b = fha.update(o_t, a_prev, b)                      # 各假设生成似然
if max(b.values()) < theta_diag or odds(top2) < theta_odds:
    mode = 'q_disc'                                 # 不确定 → 先诊断
# BCP：选择最能分清假设、且安全的判别动作
a_star = bcp.argmax_eig(b, A_safe, rho_safe_wc)     # s.t. rho_safe^wc >= 0
# SAM：守卫证书 + 滞回，失败必退
if not cert.check(edge, Ball(phi_hat, r), b, Sigma_w):
    edge = retreat_edge(q)                          # 恒可证的失效安全边
mode = automaton.step(mode, a_star, b, certs, theta_in, delta_hys)
# CCSP-F：输出策略树而非线性序列
tree = ccsp_f.plan(goal, A, b, phi_hat, r)          # 叶子 = goal | q_safe_idle
# 实时监控：不变式违反或未建模事件 → 强制安全态
if monitor.violated(mode, f_cmd, d_sensor) or monitor.unmodeled(o_t):
    force(mode='q_safe_idle'); K = K_COMPLIANT_RETREAT
J_dams = build_j_dams(J_grip, mode_trace, cert_hash, b, tree, verify_ver)
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 7（诊断可分离性）**：若任意两假设 `h_i,h_j` 在判别动作 a 下 `KL(p(o|h_i,a)‖p(o|h_j,a)) ≥ δ`，则 N 次观测后误诊概率 `≤ exp(−Nδ)`。这把第 64 轮「单阈值二值判决」换成**可指数收敛的多假设诊断**，误降几何的概率从常数降为指数小量。
- **引理 8（守卫证书的归纳安全）**：若初态满足安全不变式、每条被采用的边都有有效 Cert_e、且失效安全边恒保 `I_safe`，则对任意可达运行，连续安全不变式 `ρ_safe ≥ 0` 在离散模式轨迹上按归纳成立（概率版本由 WCV 球与证书置信度给出）。
- **定理 7（DAMS 端到端安全 + 活性）**：在 A83–A87 及新增 **A88（守卫证书相对抽象可靠、信念已校准）** 下，`Valid(J_dams)` ⇒ GRIP 四层安全 ∧ 模式轨迹合法 ∧ 无未守卫跨越 ∧ 从任意非汇模式以概率 `≥1−β` 在有限期望步内到达目标或 `q_safe_idle`（无死锁）。
- **定理 8（条件规划的信息-风险最优性）**：AA-POMDP 在信念近似误差 `ε_b` 下价值损失 `≤ O(ε_b·γ/(1−γ))`；CVaR 约束使安全违反概率 `≤ α + 证书置信误差`。**信息收集与任务推进在同一目标下显式权衡，而非第 64 轮「先探针后任务」的硬编码顺序。**
- **命题（相对 GRIP 的误降级率下降）**：GRIP 在 `h_fb` 下误降几何的概率约为 α_geo；DAMS 需 `h_geo` 后验优势比超过 `θ_odds`，若 `h_geo/h_fb` δ-可分离，则误降级概率 `≤ exp(−Nδ)/(1+exp(−Nδ))` 量级——**误归因从「阈值事件」变成「证据不足事件」，且证据不足时默认保守而非放行。**
- **实时性**：模式监控 + 不变式检查 `<0.05ms`、诊断证据抽取 `<0.1ms`、守卫边检查用预编译区间表 `<0.05ms`，叠加 GRIP 实时路径仍在 **≤2ms** 契约内（继承 A87，新增 A88）。

## 5. 本轮最大风险

**一句话**：守卫证书与模型检验给出的只是「相对于所建故障假设集 H 与抽象模型」的安全性——一旦 H 漏掉一整类真实故障（如未建模的接触动力学、执行器迟滞），或离散抽象把连续不变式的违反藏进等价类内部，系统就会**带着「已被证明安全」的证书自信地走入未认证的危险模式**；此时状态机不是安全网，而是把错误固化成形式化背书的放大器。

## 2. 形式化定义（完整版）

**定义 217（DAMS 闭环）** DAMS 是 GRIP 的离散决策层升级：`DAMS = (GRIP, H, b, A, Π, G, V, J_dams)`。其中 GRIP 提供连续估计、控制与接触安全；H 与 b 提供故障归因；A 提供可验证的离散骨架；Π 提供条件规划；G 提供边级证书；V 为模型检验结论；J_dams 为最终证书。**不变式**：诊断、条件规划、证书重证、模型检验只在语义流/慢速流；实时流只做证据抽取、模式监控、不变式检查、GRIP 前向与首技能派发，零学习写操作。

**定义 218（三层自动机与同步乘积）**
- 任务自动机 `A_task = (Q_t, q_t0, Σ_t, →_t, F_t)`，`Σ_t = Skills ∪ Diagnoses ∪ ProbeResults ∪ FaultEvents`；
- 技能自动机族 `{A_σ}`，`Q_σ ⊇ {approach, contact, execute, release, recover, abort}`，转移由力/位置守卫；
- 模式自动机 `A_mode`（定义 221）。
系统 `A = A_task ∥ A_skill ∥ A_mode`，在事件 `dispatch(σ), done(σ), fault(h), update(b)` 上同步。可达状态是三元组 `(q_t, q_σ, q_m)`。**规划与安全证明都在 A 的抽象上做，连续执行仍归 GRIP。**

**定义 219（故障假设集与诊断信念）** 故障假设 `H = {h0, h_geo, h_fb, h_cm, h_sat, h_slip}`，各自给出证据生成模型：

| 假设 | 证据签名 |
|---|---|
| h0 标称 | `T_t ~ χ²_6`，自由空间无残差，ρ_force/ρ_slip 正常 |
| h_geo 几何幻觉 | `T_t` 非中心，仅接触段异常；残差方向与「声称表面法向」一致；自由空间正常 |
| h_fb 力偏置/漂移 | 自由空间即存在常值旋量偏置；残差方向恒定、与载荷无关 |
| h_cm 接触模型错误 | 残差随接触力/速度**系统性增长**；自由空间正常；软接触有迟滞 |
| h_sat 饱和 | 残差仅当 `‖W‖` 接近量程；出现平台/削顶特征 |
| h_slip 微滑移 | `T_t` 中等、`ρ_slip` 下降、触觉高频剪切能量上升、μ̂ 漂移 |

信念更新 `b_t(h) = η·L(o_t | h, a_{t-1})·b_{t-1}(h)`。**诊断规则**：仅当 `max_h b(h) ≥ θ_diag` 且 `b(h_1)/b(h_2) ≥ θ_odds`（后验优势比）才允许据此切换模式；否则进入 `q_disc`。**这从机制上阻止「单个大残差即判定几何幻觉」。**

**定义 220（判别性信息增益与安全约束）** 动作 a 在信念 b 下的期望信息增益
`EIG(a) = I(H; O_a | b) = H(b) − E_{o∼p(o|b,a)} H(b'|o)`。
可选动作集 `A_safe(b) = {a : ρ_safe^wc(a) ≥ 0 ∧ 存在已认证退避边 ∧ cost(a) ≤ budget}`。选 `a* = argmax_{a∈A_safe} EIG(a)`。若 `A_safe = ∅` 或 `max EIG(a) < δ_info`，**不冒险、不降级**，直接进 `q_safe_idle`。判别动作例：自由空间扫动（分离 h_fb）、已知刚度标定块轻压（分离 h_cm）、疑似表面轻触（分离 h_geo）、已知量程内往复（分离 h_sat）。

**定义 221（安全模式自动机）** `A_mode = (Q_m, q_m0, E_m, Inv, Guard, Reset, T_disc)`。
- `Inv(q_nom)：ρ_rob ≥ 0 ∧ ρ_force ≥ 0 ∧ ρ_slip ≥ 0`；
- `Inv(q_geo)：geo_degraded = False ∧ r ≤ r_geo_max`；
- `Inv(q_force)：contact_established ∧ β ≥ β_min`；
- `Inv(q_disc)：驻留 ≤ T_disc ∧ 禁止不可逆任务动作`；
- `Inv(q_probe)：f_cmd ≤ f_safe(class) ∧ ρ_safe ≥ 0 ∧ RetreatEdge(q_probe) 已认证`；
- `Inv(q_calib)：仅允许标定轨迹，接触力 ≤ f_calib`；
- `Inv(q_recover)：K = compliant_blend(K, K_retreat)`；
- `Inv(q_safe_idle)：K = K_compliant_retreat ∧ 仅允许人类接管/重新标定`。
`Guard(e)` 由 `b`、`ρ_safe`、`Cert_e` 三者合取。**信念滞回**：进入 `q_disc` 的阈值 `θ_in`，退出 `θ_out = θ_in − δ_hys`，避免在阈值附近抖动。

**定义 222（守卫证书）** 对每条边 `e=(q,a,q')`，证书
`Cert_e = (I_q, I_q', R_e, method, margin)`，
要求 `∀s ∈ R_e`，执行 a 后仍满足 `I_q'`，其中
`R_e = {φ ∈ B(φ̂,r)} × {h : b(h) ≥ θ_diag} × ℰ_F × {初始技能态}`。
`method ∈ {interval arithmetic, sum-of-squares, scenario + concentration}`；`margin` 为保守裕度。证书失败 ⇒ 边不可用。**恒可用失效安全边** `e0 = (q, retreat, q_safe_idle)` 对一切 q 均预认证（compliant retreat 的 `Inv` 与任何前置状态兼容）。**证书的对象不是数值裕度，而是离散转移的全称量化安全性。**

**定义 223（信念空间约束 POMDP）** `P = (S, A, O, T, Z, R, γ, ξ)`：
- `S = (φ, h, C, q_mode, q_skill, x)`；
- `A = Skills ∪ {probe_press, probe_rub, probe_tap, probe_lift, calibrate, retreat, ask_human}`；
- `Z(o|s,a)` 由定义 219 的证据模型给出；
- `R(s,a) = task_progress(s,a) − λ_r·risk(s,a) − λ_c·cost(a) − λ_i·info_cost(a)`；
- 约束 `CVaR_α(risk) ≤ ξ`。
用 point-based value iteration / option-based (options = TSA 技能自动机) 在信念点上求解。**与第 64 轮 APP 的区别**：APP 无条件在接触后探针；BCP 把「探针」和「做任务」放在同一目标下竞争，且探针必须安全、可退。

**定义 224（条件计划 / 策略树）** 条件计划 `π: B → A` 表示为一棵 AND-OR 树：OR 节点为动作选择（任务技能/判别动作/退避），AND 节点为诊断结果分支 `o ∈ {h_geo 支持, h_fb 支持, …}`。CCSP-F 在 `A = A_task ∥ A_skill ∥ A_mode` 上搜索策略树，代价
`J(π) = E[Σ_t γ^t (cost_task + λ_r risk + λ_i info_cost)]`，
约束为叶子安全（goal 或 q_safe_idle）。叶子不可达时返回 `q_safe_idle` 子树。

**定义 225（TSA 触觉技能自动机）** `σ = (A_σ, pre, eff, inv, force_spec, θ_σ, recover_edge)`：
- `A_σ` 状态 `{approach, contact, execute, release, recover, abort}`；
- `pre/eff` 在 USL/TSL 基础上用离散谓词 + 时序算子表达，例：`G(contact → F[0,T](grasp_stable))`；
- `inv`：接触段力/滑移不变式；
- `recover_edge`：任何状态在守卫失败时指向 `recover`，再回 `release/abort`。
技能组合即自动机乘积；`π_σ` 只输出关键帧（阻抗/约束/力），不改变自动机结构。

**定义 226（OLP-M 模式感知在线投影）** `x''' = [x''; onehot(q_mode); b_summary]`，`b_summary = (H(b), b_1−b_2 优势差, geo_degraded, contact_unobservable)`。投影头 `K_W(x''') = Π₀(x''') + h(x''')ᵀW`。梯度上界
`G̃_mode = G̃_force + L_mode·N_switch`，
其中 `N_switch` 为模式切换次数；信念滞回与守卫证书直接降低 `N_switch`，从而收紧遗憾常数。

**定义 227（AIC-D 故障觉知认证）** `ℰ_D = ℰ_F × ℰ_H`，`ℰ_H = {h_out ∉ H} × {δ_L : 似然误配} × {τ_diag : 诊断延迟}`。`ρ_dams` 在 `ℰ_D` 上取最坏重算，采样数从 96 增到 128（32 用于故障类漏检的场景生成：加入一个「影子假设」`h_unknown`，其似然取 H 中未覆盖的残差模式）。J_dir 增 `fault_model_ver`。**认证对象从「单次判决」变为「诊断-守卫-回退」闭环。**

**定义 228（J_dams 扩展证书）**
`J_dams = (J_grip, mode_trace_hash, guard_cert_hash, belief_hash, plan_tree_hash, automaton_verify_ver, liveness_witness)`。
`Valid(J_dams) ⇔ Valid(J_grip) ∧ mode_trace ∈ L(A_mode) ∧ 每条跨越边 e 有有效 Cert_e ∧ liveness_witness 存在 ∧ (q_probe 期间 f ≤ f_safe) ∧ automaton_verify_ver 与当前抽象模型一致`。审计链：`mode_trace` 追溯离散决策，`guard_cert_hash` 追溯每条转移的证明，`belief_hash` 追溯归因依据，`plan_tree_hash` 追溯条件分支，`liveness_witness` 追溯无死锁。

**定义 229（运行时模式监控与失效安全）** 监控器每拍：
1. 检查当前模式 `Inv(q_mode)` 在实测证据下的满足性；
2. 检查即将跨越边 `e` 的 `Cert_e` 在当前 `B(φ̂,r)` 与 `b` 下仍有效；
3. 检查证据是否落在 H 的支撑内（`max_h L(o|h) ≥ L_min`）。
任一失败或出现未建模事件 → 强制 `q_safe_idle` + compliant retreat，写 `mode_trace`。**监控器零学习、只读、预编译查表，保证 `<0.05ms`。**

**定义 230（DAMS 算子）** 四条流：
- 语义流（10–100Hz）：`[LiDAR/力觉取证 → FHA 更新 b → SAM 选 q_mode]`；
- 决策流（1–10Hz）：`[q_disc ⇒ BCP 选判别动作 / 否则任务动作 → CCSP-F 生成策略树 → GCM 逐边证书校验 → 派发首技能]`；
- 实时流（≥1kHz）：`[锚读 → GRIP 实时组件 → 模式监控/不变式检查 → 首技能派发 → J_dams 构建]`；
- 慢速流（离线/秒级）：`[概率模型检验、证书重证、信念校准、假设集扩充、策略树缓存]`。

### IP-214/215 DGG + FHA（取证与归因）

```python
class FaultHypothesisDiagnoser:
    """六假设贝叶斯诊断。只更新信念，不做二值判决。"""
    def __init__(self, H=('h0','h_geo','h_fb','h_cm','h_sat','h_slip'),
                 theta_diag=0.8, theta_odds=8.0):
        self.H = H
        self.b = {h: 1.0/len(H) for h in H}
        self.theta_diag, self.theta_odds = theta_diag, theta_odds

    def evidence(self, T_t, W_meas, contact_set, tactile, rho_force, rho_slip):
        free_space = len(contact_set) == 0
        e_struct = {
            'free_space_resid': free_space and T_t > CHI2_95,
            'load_linearity': correlate(T_t, norm_load(contact_set)),
            'dir_constancy': direction_variance(W_meas),
            'sat_fraction': sat_fraction(W_meas),
            'tactile_hf': high_freq_energy(tactile),
        }
        return (T_t, e_struct, rho_force, rho_slip,
                e_struct['sat_fraction'], not free_space)

    def likelihood(self, o, h, a):
        # 由各假设的生成模型给出（表 219）；未建模模式给低似然
        return HYPOTHESIS_MODELS[h].loglik(o, a)

    def update(self, o, a_prev):
        logp = {h: np.log(self.b[h] + 1e-12) + self.likelihood(o, h, a_prev)
                for h in self.H}
        m = max(logp.values())
        z = sum(np.exp(v - m) for v in logp.values())
        self.b = {h: np.exp(logp[h] - m) / z for h in self.H}
        return self.b

    def diagnose(self):
        ranked = sorted(self.b.items(), key=lambda kv: kv[1], reverse=True)
        (h1, p1), (h2, p2) = ranked[0], ranked[1]
        return {
            'confident': p1 >= self.theta_diag and p1 / max(p2, 1e-12) >= self.theta_odds,
            'top': h1, 'odds': p1 / max(p2, 1e-12), 'belief': self.b,
        }

    def unmodeled(self, o):
        return max(self.likelihood(o, h, None) for h in self.H) < LOGLIK_FLOOR
```

### IP-218 BCP（判别性动作选择）

```python
class BeliefContingentPlanner:
    def safe_actions(self, b, r, Sigma_w):
        out = []
        for a in ACTIONS:
            rho_wc = worst_case_margin(a, b, r, Sigma_w)   # φ∈B, h∈H, ℰ_F
            if rho_wc >= 0 and self.has_certified_retreat(a):
                out.append((a, rho_wc))
        return out

    def eig(self, a, b, n_mc=128):
        H_b = entropy(b.values())
        exp_post = 0.0
        for _ in range(n_mc):
            h = sample(b)
            o = sample_evidence(h, a)                       # 假设生成模型
            b2 = bayes_update(b, o, a)
            exp_post += entropy(b2.values()) / n_mc
        return H_b - exp_post

    def choose(self, b, r, Sigma_w, budget):
        diag = self.fha.diagnose()
        if diag['confident']:
            return self.task_policy(diag['top'], b), 0.0
        cands = self.safe_actions(b, r, Sigma_w)
        if not cands:
            return ('ask_human',), 0.0                      # 无安全判别 → 不冒险
        best, best_ig = None, -np.inf
        for a, _ in cands:
            ig = self.eig(a, b)
            if ig > best_ig and budget >= action_cost(a):
                best, best_ig = a, ig
        if best is None or best_ig < DELTA_INFO:
            return ('retreat',), best_ig
        return best, best_ig
```

### IP-216/217/220 SAM + GCM + TSA（模式与证书）

```python
class GuardCertificate:
    def __init__(self, method='interval'):
        self.method = method

    def check(self, edge, Ball, belief, Sigma_w, eps_F):
        q, a, q2 = edge
        R = product(Ball.phi_set(), belief_support(belief),
                    SensorBall(Sigma_w, eps_F))
        if self.method == 'interval':
            lo, hi = interval_post(R, a)                    # 区间传播
            return hi.satisfies(INVARIANTS[q2])
        if self.method == 'sos':
            return sos_prove(R, a, INVARIANTS[q2])          # 平方和证书
        return scenario_concentration(R, a, INVARIANTS[q2], delta=DELTA_CERT)


class SafetyAutomaton:
    def __init__(self, theta_in=0.8, delta_hys=0.2):
        self.theta_in, self.delta_hys = theta_in, delta_hys
        self.mode = 'q_nom'

    def step(self, a, b, rho_safe, certs, o):
        if self.mode == 'q_disc' and max(b.values()) < self.theta_in - self.delta_hys:
            self.mode = 'q_nom'                             # 滞回退出
        if max(b.values()) < self.theta_in and self.mode == 'q_nom':
            self.mode = 'q_disc'                            # 进入诊断
        target = TRANSITION[self.mode].get(a, 'q_nom')
        e = (self.mode, a, target)
        if not certs.check(e, Ball, b, Sigma_w, EPS_F):
            e = (self.mode, 'retreat', 'q_safe_idle')       # 恒可证失效安全边
        if not INVARIANTS[e[2]].holds(measured_state()):
            e = (self.mode, 'retreat', 'q_safe_idle')
        self.mode = e[2]
        return self.mode, e


class TactileSkillAutomaton:
    """技能 = 小自动机；recover 边保证任何失败可退。"""
    STATES = ('approach', 'contact', 'execute', 'release', 'recover', 'abort')

    def step(self, skill, state, x, phi_hat, r, force_meas):
        guard_fail = not skill.inv(state, x, phi_hat, r, force_meas)
        if guard_fail and state not in ('recover', 'abort'):
            return 'recover'
        return skill.transition(state, x)
```

```python
def contingent_csp_f(goal, A, b, phi_hat, r, depth=0):
    if goal.satisfied(A.state):
        return Leaf('goal')
    if depth > D_MAX or b.entropy() > H_MAX:
        return Leaf('q_safe_idle')
    diag = fha.diagnose()
    if not diag['confident']:
        a = bcp.choose(b, r, Sigma_w, budget_left)[0]
        children = {h: contingent_csp_f(goal, A.after(a, h), b_after(b, h),
                                        phi_hat, r, depth + 1)
                    for h in plausible_hypotheses(b)}
        return ANDNode(action=a, branches=children, fallback=Leaf('q_safe_idle'))
    skills = admissible_skills(goal, A, b, phi_hat, r)
    if not skills:
        return Leaf('q_safe_idle')
    return ORNode(choices=[
        SeqNode([skill, contingent_csp_f(goal.after(skill),
                                         A.after(skill), b, phi_hat, r, depth + 1)])
        for skill in skills])
```

## 4. 推导

**引理 7（诊断可分离性与误诊率）** 设两故障假设 `h_i, h_j` 在判别动作 a 下的观测分布为 `p_i, p_j`，若 `KL(p_i‖p_j) + KL(p_j‖p_i) ≥ 2δ`（或 `KL(p_i‖p_j) ≥ δ`），由 Chernoff–Stein 界，N 次独立观测后误诊概率
`P_err ≤ exp(−N·C(p_i,p_j)) ≤ exp(−Nδ)`。
若 H 中任意两假设在某个安全判别动作下 δ-可分离，则 `P(误判) ≤ exp(−Nδ)`。代入第 64 轮场景：`h_geo` 与 `h_fb` 由「自由空间是否仍有残差」这一判别特征分离，`h_geo` 与 `h_cm` 由「残差是否随载荷线性增长」分离。故**误降几何先验的概率从 GRIP 的常数 α_geo 降为指数小量**。∎

**引理 8（守卫证书的归纳安全）** 设初始模式 `q_0` 满足 `I_{q_0}`。归纳假设：到达 `q_k` 的运行时不变式成立。对下一转移边 `e_k=(q_k,a,q_{k+1})`：
- 若 `Cert_{e_k}` 有效，由定义 222，`∀s ∈ R_{e_k}` 执行 a 后 `I_{q_{k+1}}` 成立；实测状态在 `R_{e_k}` 内（由 WCV 球与 ℰ_F 定义），故 `I_{q_{k+1}}` 成立；
- 若 `Cert_{e_k}` 无效，SAM 改走失效安全边 `e0`，其预认证保证 `I_{q_safe_idle}` 成立；
- 若监控器检测到不变式违反或未建模事件，强制 `e0`，同理。
由归纳，任意可达运行的所有模式满足各自不变式；特别地 `ρ_safe ≥ 0` 在全部非 safe_idle 模式成立，safe_idle 为 compliant retreat 且不施加任务力。∎

**定理 7（DAMS 端到端安全与活性）** 在 A83–A87 与新增
- **(A88)** 守卫证书相对抽象模型可靠（`Cert_e` 的 method 与其置信参数匹配）；诊断信念已校准（ECE ≤ ε_cal）；H 覆盖部署时出现的故障类（或 `h_unknown` 触发 safe_idle）。
下：
1. **连续安全**：由引理 8，任意可达模式满足 `ρ_safe ≥ 0`；`q_probe` 期间 `f ≤ f_safe`（`Inv(q_probe)` + 证书）。
2. **离散合法性**：模式轨迹 `∈ L(A_mode)`（SAM 转移 + 监控器强制）；每条跨越边有有效证书（GCM）。
3. **活性**：CCSP-F 的策略树在每个 AND 分支要么到达 goal、要么到 safe_idle；`q_disc` 驻留有上界 `T_disc`，超时强制 `q_safe_idle`，故无死锁；由 POMDP 的 proper policy 假设，从任意非汇模式以概率 `≥1−β` 在有限期望步内到达 goal 或 safe_idle。
4. **证书链**：`Valid(J_dams)` ⇒ 上述 1–3 且 `Valid(J_grip)`。∎

**定理 8（条件规划的信息-风险最优性）** 约束 POMDP 的最优策略 `π*` 满足
`J(π*) = min_π E[Σ γ^t r] s.t. CVaR_α(risk) ≤ ξ`。
在信念近似 `‖b−b̂‖₁ ≤ ε_b` 下，点基/选项法的价值损失满足 `|J(π̂) − J(π*)| ≤ O(ε_b·γ/(1−γ)·L_R)`（Lipschitz 常数 `L_R`）；CVaR 约束的违反概率由 Rockafellar–Uryasev 对偶给出 `≤ α + O(ε_b)`。**因此「先做判别实验还是先做任务」由价值函数统一决定，而非第 64 轮的固定顺序。** ∎

**命题（相对 GRIP 的误降级率下降）** GRIP 在 `h_fb` 下按单残差阈值误降几何的概率约 α_geo。DAMS 需 `h_geo` 后验优势比 `≥ θ_odds`，且 `h_fb` 可由自由空间判别特征排除。若 `h_geo/h_fb` δ-可分离，经 N 次判别观测，
`P(误降级) ≤ exp(−Nδ) / (1 + exp(−Nδ))`，
且当证据不足时进入 `q_disc` 或 `q_safe_idle` 而非直接裁决。**误归因从「阈值事件」变成「证据不足事件」，且证据不足默认保守。** ∎

**命题（模式滞回抑制抖动）** 设两模式切换的信念阈值差为 `δ_hys`，证据噪声标准差 `σ_b`。无滞回时单位时间期望切换数 `≈ σ_b·φ(0)/δ_hys²·T`；有滞回时需跨越宽度 `δ_hys` 才反向切换，期望切换数下降约 `O(δ_hys/σ_b)` 倍。取 `δ_hys = 4σ_b` 可抑制 >95% 的抖动（对应 E236 目标）。∎

## 7. 已知风险

**一句话**：守卫证书与模型检验给出的只是「相对于所建故障假设集 H 与抽象模型」的安全性——一旦 H 漏掉一整类真实故障（未建模接触动力学、执行器迟滞、标定漂移的非高斯尾部），或离散抽象把连续不变式的违反藏进等价类内部，系统就会**带着「已被证明安全」的证书自信地走入未认证的危险模式**；此时状态机不是安全网，而是把错误固化成形式化背书的放大器。

**次级风险与缓解**：
1. **假设集不完备（H 漏类）**：`h_unknown` 影子假设 + 似然下限触发 safe_idle；在线从残差聚类中提议新假设，人工确认后加入 H；AIC-D 显式认证漏检类。
2. **抽象-连续差距**：证书用「区间 + 场景 + 集中不等式」在 `B(φ̂,r)` 上做保守外包；抽象粒度作为认证参数（A88）；E239 专门测粒度安全性；关键不变式保留连续兜底监控器。
3. **状态爆炸**：三层乘积理论规模大；用技能等价类、模式抽象、策略树缓存与 CSS（component substitution）压缩；慢速离线求解，实时只查缓存。
4. **POMDP 求解成本与信念误配**：只在语义流求解，限制树深 `D_MAX` 与信念熵阈值；信念校准（ECE）纳入 J_dams；退回基于规则的条件计划作为 fallback。
5. **诊断延迟导致危险窗口**：`q_disc`/`q_calib` 期间限制为不可逆动作禁区；监控器快速触发 safe_idle；`T_disc` 上界硬约束。
6. **模型检验与实现不一致（refinement gap）**：生成代码与抽象模型同源（同一 DSL 生成 monitors/guards）；运行时监控器独立实现并交叉校验；`automaton_verify_ver` 校验版本一致。
7. **过度保守导致任务不可用**：safe_idle 频繁触发会牺牲可用性；用「风险预算」在 POMDP 中显式权衡，报告成功率-安全前沿而非单点；区分「可恢复保守」与「终止性保守」。
8. **人类接管依赖**：safe_idle 在无人场景需自治恢复；加入 `q_calib → q_nom` 的自动重标定路径与有界探索，失败再请求人类。
