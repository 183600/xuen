# 第 58 轮（承接第 57 轮「少样本×多模态×个性化」IP-133~138 与元认知-信任层；灵感循环新一轮；本轮灵感：「数据集」×「价值对齐」）

> 第 57 轮把安全从"单点置信"推进到"分层证据"，却把最后一道判定权交给了元推断器；其自陈的最大风险是"坏先验普遍"。本轮追问一个更根的问题：**这个元先验是从哪个数据集摊销出来的，而那个数据集凭什么代表"我们想要的"？** 数据集不是中立的现实镜像，而是一份**价值化石**——采集谁、标注谁、省略谁、用谁的代价换什么标签，全部被冻结进标签与先验里；"数据驱动"因此可能把价值选择洗白成客观事实。同时，前 57 轮整座大厦都是**认识论**的（证据是否可信、后验是否校准），却从未显式回答**价值论**问题（即使证据为真，这个动作是否应当被允许、被谁允许、以什么代价）。本轮引入与"证据门"正交的"**价值门**"：硬约束（不可交易、独立于数据、可否决）＋词典序分层（安全≻同意≻任务≻效率，层级不可标量化）＋仅在最软层学习偏好；把数据集升级为**带来源图、价值指纹、同意级、可撤销**的价值账本；把分布外检测从"没见过这种材质"推广到"**没见过这种价值处境**"。核心命题升级为 **"证据可溯、价值可辩、数据可撤的双门可信"**。

核心矛盾：
- **H29（数据集 vs 价值中立幻觉）**：数据集是价值化石，元先验继承其盲区与偏见；在它上面做校准只能保证"对采集者的世界校准"，不能保证"对应当的世界对齐"。覆盖审计能披露盲区，但披露不等于消解；同意撤销更要求整条派生链可追溯。
- **H30（价值对齐 vs 可证伪性）**：用学到的奖励模型做对齐，只是把一个不可验证的判定器换成另一个不可验证的判定器——谁来对齐对齐器？价值全可学则策略优化代理指标（reward hacking）；价值全硬编码则无法适应真实处境。可证伪的对齐必须让偏好产生可被现实反驳的预测（价值遗憾），并保留争辩通道。
- **H31（多主体 vs 单一标量）**：安全员、操作者、业主、社会各有偏好；压成单一标量会隐藏分配冲突，且多数可暴政少数（尤其可压倒安全否决）。聚合必须词典序、硬约束取交集、记录异议、允许争辩，而非求平均。

## 0. 直觉与动机

**灵感 1（数据集 → 价值账本，而非数据仓库）**
直觉：把数据集当"石油"是错的，它更像"**族谱**"——每一行数据都有祖先（谁在什么处境、以什么同意级、被谁的偏好筛出来的），也有后代（哪些摘要、哪些模型参数继承了它）。于是数据集从静态语料升级为**价值账本 VLD**：每条记录挂来源元组 π、价值指纹 v（该标签体现了谁的价值、在哪个维度、置信多少）、同意级 c；派生图 G_der 记录"哪条人类输入生成了哪条元训练样本/模型"；一旦有人行使撤销权（GDPR 式的"被遗忘"或站点撤回同意），撤销沿 G_der **传播**，其全部后代被标记 stale 并触发受影响区域的重新校准。价值卡 VC(𝒟) 像数据卡的"价值版"：披露覆盖矩阵、来源分布、同意级分布、**已知省略集**，以及被编码的价值谱——任何元先验必须发布"我继承的是谁的世界"。

**灵感 2（价值对齐 → 约束-词典序，而非标量奖励）**
直觉：把"安全、进度、公平、省事"加权求和成一个数，是在说"可以用 3 点进度买 1 点人身风险"——这正是不该被允许的交易。价值的正确结构是**先否决、再排序、最后才优化**：硬约束 C_hard（不可逆人身伤害、未获同意的数据使用、法规红线）是**绝对否决**且**不从数据学习**（deontic，规范给定），任何证据强度都不能"买通"它；词典序 ≻_lex 定义层间不可折衷的优先（安全 ≻ 同意/隐私 ≻ 任务 ≻ 效率）；只有最软层 U_soft 允许从数据/询问中学习。并且价值本身有不确定性：我们持有的是价值画像的**信念集 𝒫**（credal set），决策对 𝒫 取**最坏情形**（鲁棒），绝不偷偷点估计成一个画像。

**灵感 3（价值分布外 → "这里该不该"的 OOD）**
直觉：第 57 轮的 OOD 问"这个地面像不像我见过的"，本轮补一个平行问题"**这个处境像不像我处理过的**"——新出现的利益相关者（未建模的第三方）、突变的紧迫度（赶工期要求跳过协商）、新的法规域。价值密度模型判 V-OOD 后，系统不进入"价值保守带"之外的任何软偏好推断，而是**退到硬约束交集＋最保守词典序层**，并强制协商；若连协商都不可行，只做能被硬约束完全判定为安全的动作，否则停。安全在这里表现为"**宁可无用，不可越权**"。

**灵感 4（合流 → 双门承诺：证据决定"能不能"，价值决定"该不该"）**
直觉：前 57 轮把"证据门"焊成了唯一的承诺前置条件，隐含假设是"只要证据足够就该做"。本轮把承诺拆成两道**正交**的门：认识论门（第 57 轮 FSE，问是否为真/已知）与价值门（问是否被允许/被谁允许/以什么代价）。证据只能把动作放进**可选集**；价值门决定可选集里**哪些真的可做**。硬约束违反是绝对否决，与证据多强无关——这堵死了"证据足够所以可以为所欲为"的后门。

**灵感 5（可证伪的对齐 → 价值遗憾 + 可争辩审计）**
直觉：对齐若不可证伪，就退化成信仰。让价值画像产生可被现实反驳的预测：事后用更新后的画像算**价值遗憾** VR——"若当时完全知情且对齐，会不会选得更好？"若 VR 长期同向为正，说明画像或数据错了，回填价值指纹、重校准；同时开放**争辩窗口**：被压倒的少数可指认被违反的软偏好或被遗漏的硬约束，争辩成功则更新未来画像。但**已发生的动作不能靠价值遗憾"事后正当化"**——防止用结果倒推洗白。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（价值账本数据集 VLD）** 𝒟={(x_i,y_i,π_i,v_i,c_i)}：π_i 来源元组（采集者/时间/选择规则/主动或被动采集）；v_i∈Δ(V) 价值指纹＝该标签所体现的利益相关者与价值维度分布（例："仅为效率最优、未征询安全员"）；c_i∈{C0 匿名遥测,C1 告知,C2 明示同意,C3 可撤回}。派生图 G_der：每条元训练样本、摘要、模型参数记录其祖先人类输入集合。撤销算子 Revoke(s)：沿 G_der 标记含 s（c≤C2）输入的全部后代为 stale，重算受影响区域的 ε_meta、ρ 与共形残差；无法追溯者（unlinkable）整体降权并审计。价值卡 VC(𝒟)=(覆盖矩阵 材质×季节×坡度×价值处境, 来源分布, 同意级分布, 已知省略集 Omit, 编码价值谱分布)。契约：任何元先验须发布其继承的 v 分布；部署处境 z_dep 与 VC 价值谱不匹配 ⇒ 触发定义 140。

**定义 140（价值分布外 V-OOD 与价值保守带）** 价值处境 z_val=(任务紧迫度, 在场利益相关者集 S_dep, 可接受代价声明, 法规域)。价值密度模型 p̂_V(z_val|𝒟)，n_V=−log p̂_V(z_val)>θ_V ⇒ 价值分布外。回退**价值保守带** B_val=⋂_{s∈S_dep} C_hard(s) 与 ≻_lex 最保守层；V-OOD 下**禁止使用任何数据学来的软偏好**，承诺前必须协商（定义 142/143），或仅执行可被硬约束完全判定为安全的动作。与认识论 OOD 并列：一个说"我不知道这里的地面"，一个说"我不知道这里该不该"。

**定义 141（约束-词典序价值对齐 CLVA）** 价值画像 P=(C_hard, ≻_lex, U_soft)，部署持有信念集 𝒫（不可约成单点）。C_hard 由规范/法规/在场者否决显式给定，**不得从数据学习**；≻_lex 为层全序（人身不可逆伤害 ≻ 同意/隐私 ≻ 任务完成 ≻ 效率），层间禁止标量折衷；U_soft 仅定义在层内可行域 𝒜_feas(P)。决策 a\*=argmax_{a∈⋂_{P∈𝒫}𝒜_feas(P)} min_{P∈𝒫} U_soft^P(a)（对价值不确定性取最坏）。多主体硬约束取交集（任一主体的硬否决即否决）；软偏好仅按可争辩权重聚合且必须记录被压倒者与理由（异议台账 D）。若交集为空 ⇒ 无可行动作 ⇒ 协商/停。

**定义 142（价值主动探询 AVE）** 与地形探针（问世界）对偶，价值探询问人"在此具体处境你更接受 a 还是 b"。触发：价值不确定性决策相关 ⇔ ∃P,P'∈𝒫: a\*_P≠a\*_{P'}，且 VVOI=E[U(a\*_{P'})−U(a\*_P)]−cost(q)−λ_fatigue·fatigue>θ_VVOI。查询只以**具体、可执行、带后果的真实选项**呈现（拒绝抽象偏好题），受 k_val 预算与会话疲劳（继承第 57 轮 vig）约束；答案作为 v_i 记账，**不得直接改写 C_hard**。

**定义 143（价值遗憾与可争辩审计 CAA）** VR(a)=max_{a'∈𝒜_feas(P̂)}U_soft^{P̂}(a')−U_soft^{P̂}(a)。若 VR>θ_VR 且同向累计≥m 次系统性出现，则：(a) 回填价值指纹并触发重校准；(b) 开放争辩窗口 τ_cont，利益相关者可指认被违反的软偏好或遗漏的硬约束；(c) 争辩成功 ⇒ 更新未来 𝒫，但**已发生动作不可用价值遗憾事后正当化**（禁止结果倒推洗白）。审计项含异议台账 D 与每次被压倒的少数。

**定义 144（双门承诺 VAG 与 V 证书）** 承诺 ⇔ 认识论门（第 57 轮 FSE，问是否为真/已知）∧ 价值门（问是否被允许/被谁允许）。价值门检查：C_hard 全满足 ∧ 动作∈⋂_{P∈𝒫}𝒜_feas(P) ∧ V-OOD 已处理（协商或硬化）∧ 价值不确定度≤θ_𝒫 ∧ 异议台账完整 ∧ 数据来源/同意与当前法规域一致。产出 V 证书 J_v=(𝒫, C_hard 引用, D, 价值询问日志, VC 摘要, revocation_state, contest_log)。硬约束违反是**绝对否决**，与证据强度无关。

def revoke_and_recalibrate(D, subject, vcard, M):     # IP-139: 撤销沿派生图传播

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| VLD | 撤销 O(\|G_der\|)；查询 O(1) | O(\|𝒟\|+\|G_der\|) | 派生链完整、stale 可检出（A41） |
| V-OOD | O(d_V) | O(\|𝒟\|) 静态 | 密度模型诚实、回退硬化（A42） |
| CLVA | O(\|𝒫\|·\|𝒜\|·\|S\|) | O(\|𝒫\|+\|S\|) | 硬约束不学、层间不标量（A43） |
| AVE | O(1)/查询 | O(\|日志\|) | 具体选项、记账诚实、疲劳生效（A44） |
| CAA | O(\|𝒜\|)/事后 | O(\|日志\|) | 遗憾不可事后正当化 |
| VAG | O(\|S\|·\|𝒫\|) | O(\|σ\|) | 双门正交、硬否决绝对 |

**正确性定理（Constraint-verified Value-Aligned Soundness, CVAS 概要）**：继承 A22–A40，新增 (A41) 来源与同意诚实、撤销可传播且 stale 未检出比例 ≤δ_stale；(A42) 硬约束独立于数据给定且覆盖在场利益相关者（遗漏率 ≤δ_S）；(A43) 价值不确定性以信念集 𝒫 表示、决策对 𝒫 取最坏、不隐式标量化；(A44) 价值询问只给具体选项、答案记账诚实、疲劳约束生效。则：(i) 硬约束健全性——任何承诺动作满足 ∀s∈S_dep C_hard(s)，以 A42 覆盖为前提，未建模主体贡献 ≤δ_S；(ii) 认识论-价值正交——承诺错误 ≤ 第 57 轮 P_fail + P(价值门漏判)，且价值门不因证据增强而放宽（证据不能买通硬约束）；(iii) 交互单调性保持——价值层只能交入更多硬约束、缩小 𝒫、增加否决/协商/停，不存在靠"更好的价值推断"提高可承诺风险的路径；(iv) 终止性——每决策点价值询问 ≤k_val，PCE++ 有限步终止。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 硬约束漏主体/错条款 → 绝对否决变绝对幻觉 | 高 | 主体清单显式审计 + 遗漏登记 Omit + 争辩窗口 + 法规域核对 |
| 价值 OOD 回退"安全但无用" → 制度压力放宽硬约束 | 高 | 把"无用"与"越权"分账；只允许经争辩与显式修订改 C_hard，禁止为可用性临时降级 |
| 数据集撤销传播不全 → stale 证据继续支撑承诺 | 高 | G_der 强制登记 + unlinkable 整体降权 + 定期回放审计 |
| 价值询问疲劳/诱导 → 偏好被"问"出来而非"真"存在 | 中 | 具体选项 + 疲劳预算 k_val + 询问答案记账与事后 VR 校验 |
| 软偏好仍被 reward hacking | 中 | 软层只定义在硬约束可行域内 + 价值遗憾监控 + 争辩通道 |

## 6. 本轮最大风险

**一句话**：本轮把"绝对否决"的正当性交给一份**由人给定、无法由数据兜底**的硬约束清单——漏掉一个利益相关者或写错一条硬约束，价值门就会从"绝对否决"退化为"绝对幻觉"，而价值 OOD 下"安全但无用"的回退又会制造放宽硬约束以恢复可用性的制度性压力；因此必须以主体清单审计、遗漏登记、争辩窗口与"改条款只能经显式修订、不得为可用性临时降级"两道闸门，宁可停滞，不越权。

# 第 58 轮产物 · 创新点清单 v34：OODGen-LangGround（结构化分布外泛化×语言接地假设×指令权威，SOG×LGH×LCG×IAD×OGE×PCE++）

### IP-139 SOG（结构化 OOD 泛化 + 分级撤退）

```python
def classify_shift(obs, M, H):
    if H and any(claim.names_mechanism() for claim in H): return 'mech'
    if invariant_subspace_explains(obs, M):               return 'cov'
    if decompose_into_primitives(obs, M.P):               return 'comp'
    return 'mech'

def structured_generalize(M, r, obs, H):
    shift = classify_shift(obs, M, H)
    if shift == 'mech':
        return flat_belt(M, r), shift, None               # 不可约 → 平坦带
    I = invariance_set(r, M)                              # 声明跨上下文不变特征
    if shift == 'cov':
        b = recalibrate_within(M, r, I)                   # 仅权重再标定
        G = (I, 1.0, 0.0, delta_cov)
        return narrow_if_certified(b, G, M, r), shift, G
    Pr = primitive_cover(r, M)
    b = compose(Pr, obs)                                  # ⊕ 组合响应
    G = (I, cover(Pr), interaction_residual(b), delta_gen_hat(Pr))
    return narrow_if_certified(b, G, M, r), shift, G

def narrow_if_certified(b, G, M, r):                      # 铁律：无证书不变窄
    ok = G.cover >= 1-alpha_comp and G.eta <= eta_max and G.delta <= delta_max
    return b if ok else flat_belt(M, r)                   # 平坦带是带宽下界
```

### IP-140 LGH（语言接地为可证伪假设）

```python
def parse_language(lang, schema, channel):
    H = []
    for c in nl_to_claims(lang):
        v, pred, w = type_claim(c, schema)                # 映射到 class/μ/k/F_bear/constraint
        if not falsifiable(v, pred, probes=admissible_probes()):
            audit.log(('unfalsifiable', channel, c)); continue   # 波普尔过滤
        H.append((v, pred, w * lambda_ch[channel]))
    return H

def update_language_reliability(ch, claim, verdict):
    if verdict == 'confirmed': lambda_ch[ch] = min(1.0, lambda_ch[ch] + eta_up)
    elif verdict == 'falsified': lambda_ch[ch] = max(lambda_min, lambda_ch[ch] * eta_down)
    audit.log(('lang_reliability', ch, lambda_ch[ch])); return lambda_ch[ch]

def falsifiable(v, pred, probes):                         # 存在可判别探针才算“有内容”
    return any(kl_divergence(pi, pred, neg(pred)) >= eps_disc for pi in probes)
```

### IP-141 LCG（语言条件泛化：语言缩搜索、探针裁决、证书定带宽）

```python
def language_conditioned_generalize(M, r, H):
    if not H:
        return structured_generalize(M, r, M.obs[r], H)   # 无语言 → 退 IP-139
    shift_guess = infer_shift_type(H)
    pi = argmax(admissible_probes(M, r), key=lambda p: voi_disc(p, H))
    if voi_disc(pi, H) < theta_disc:
        return flat_belt(M, r)                            # 假设不可判别 → 不硬泛化
    obs = execute_probe(pi, cap=F_abs); M = update_belief(M, r, obs)
    L = lang_evidence_conflict(H, M.b[r])                 # R1: 冲突检查
    if L > theta_L:
        audit.flag(('lang_conflict', r, L)); return flat_belt(M, r)
    if verify(H, obs):
        M = mark_ev_lang(M, r, H, bound=delta_lang)       # R2: 有界证据，不作接触证据
        return structured_generalize(M, r, obs, H)        # 核实后走证书收窄
    update_language_reliability(channel_of(H), H, 'falsified')
    return flat_belt(M, r)
```

def ood_generalization_gate(c, M, H, lam, G, shift, persona):
    if c.ev == 'EV-lang':
        ok = c.verified and lam >= lam_0 and c.bound <= delta_lang
        if c.irreversible: return ('reject', 'lang_alone_irreversible', c)
    elif c.ev == 'EV-compose':
        ok = (G is not None and G.cover >= 1-alpha_comp and G.eta <= eta_max)
        if c.irreversible: return ('reject', 'compose_not_contact_evidence', c)
    else:
        ok = few_shot_evidence_gate(c, M, persona, ood_reg)[0] == 'ok'  # 继承 FSE
    if not ok: return ('reject', 'evidence_insufficient', c)
    return ('ok', c)

def map_evidence_certificate_g(sched, log, M, H, lambda_ch, G, shift,
                               consent_log, auth_log, directive_log, adapt_log):
    for c in contacts(sched):
        st = ood_generalization_gate(c, M, H, lambda_ch[channel_of(H)], G, shift, persona_of(c))

### IP-144 PCE++（探-诺-演++：泛化 VOI × 冲突检查 × 有界适配 × 指令路由）

```python
def probe_commit_evolve_plus_plus(x0, M, task, budget, consent, personas, lang):
    H = parse_language(lang, schema, channel=lang.channel)   # IP-140
    route = plan_on_map(M, task, risk_model)
    for cp in route.checkpoints:
        shift = classify_shift(M.obs[cp.region], M, H)       # IP-139
        theta = max(theta_ood_min, cond_threshold(shift, H)) # R3: 条件阈值有硬底
        b, shift, G = structured_generalize(M, cp.region, M.obs[cp.region], H)
        sigma = foothold_schedule(x0, cp, b); R = schedule_risk(sigma, b)
        while select_gait(R) == 'halt' and budget.probes_left > 0:
            cands = admissible_probes(cp, b, F_abs)
            if not cands: break
            p = argmax(cands, key=lambda q: voi_disc(q, H) + voi_meta_pessimistic(q, b) - cost(q))
            if voi_disc(p, H) + voi_meta_pessimistic(p, b) < theta_voi: break
            obs = execute_probe(p, cap=F_abs); M = update_belief(M, cp.region, obs)
            if lang_evidence_conflict(H, M.b[cp.region]) > theta_L:   # 冲突检查点
                M = flat_belt_region(M, cp.region); update_language_reliability(
                    lang.channel, H, 'falsified')
            b, _, G = structured_generalize(M, cp.region, obs, H)
            sigma = reselect_footholds(x0, cp, b); R = schedule_risk(sigma, b)
            budget.spend(p)
        g = select_gait(R)
        if g != 'halt' and ood_generalization_gate(core_contact(cp), M, H,
                                                   lambda_ch, G, shift, personas)[0] == 'ok':
            sched.append(commit(sigma, g)); continue
        alt = reroute(M, cp, risk_model)                       # IP-139: 平坦带优先绕行
        if alt and select_gait(schedule_risk(alt, b)) != 'halt': route = alt; continue
        d = dispatch_directive(active_directive(lang), M, personas.active, risk=R, ev=tag_evidence(sigma))
        if d in ('suggestion', 'reject', 'conservative_default'):
            return negotiate_or_stop(cp, M, sigma, R, consent,
                                     tau_int=tau_int(personas.active.auth))
        return negotiate_or_stop(cp, M, sigma, R, consent,
                                 tau_int=tau_int(personas.active.auth))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SOG | O((\|P\|·d_p+\|I\|)/区域) | O(\|P\|+\|I\|) | 证书诚实、平坦带为底（A41/A44） |
| LGH | O(L_nl·d_parse+\|Π\|) | O(\|H\|) | 不可证伪权重 0、λ_ch 诚实（A42） |
| LCG | O(\|Π_adm\|·C_disc)/检查点 | O(\|H\|) | 冲突→平坦带、θ_ood≥硬底（A41/A42） |
| IAD | O(\|Ω\|)/指令 | O(1) | propose-not-dispose、硬禁令（A43） |
| OGE | O(\|σ\|) | O(\|σ\|) | EV-lang/compose 不作接触证据 |
| PCE++ | O(\|CP\|·(k_p+k_c+k_l)·(C_VOI+d_φ)) | O(\|V\|+\|σ\|) | 有界适配、可回滚、终止 |

**正确性定理（Out-of-distribution Generalized Calibrated Soundness, OGCS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** shift 分类在声明谱系内可靠、泛化证书诚实：cover≥1−α_comp、η_int≤η_max、δ_gen≤δ_max；**(A42)** 语言假设经可证伪过滤、λ_ch 跟踪诚实、不可证伪权重为 0、EV-lang 须核实且不作接触证据；**(A43)** 指令权威格强制、无指令可修改 auth/corrob\*/w_h/θ/必要证据集、propose-not-dispose、谄媚上限生效；**(A44)** test-time 适配仅限不变性认证子空间且可回滚，**平坦共形带是带宽下界**（无证书不得更窄）。则：

1. **泛化承诺健全性**：P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf + δ_gen·1[证书收窄] + δ_lang·1[EV-lang]；证书条件任一失守即回退平坦带，故所有收窄风险由 δ_gen 统一兜底。
2. **单调性保持**：语言只以"提议假设/选探针"进入，不写似然；指令只能经"偏好/建议"进入且不得改授权与证据；泛化只在证书通过时收窄。三条均无升险路径；冲突/歧义/高风险低证据一律落保守默认。
3. **终止性**：每检查点探针 ≤ k_probes+k_cons+k_lang，PCE++ 终止于 {承诺, 绕行, L2 协商, 安全停}。
4. **部署界**（对检查点取联合界）：

```
P_safe ≥ 1 − Σ_cp (δ_f + ε_meta(k) + δ_probe + ε_h + δ_ood·α_conf
                   + δ_gen·1[证书收窄] + δ_lang·1[EV-lang] + δ_xm·1[L1])
             − P(𝓜 陈旧未检出) − P(护盾回退失败)
             − P(语言模型被注入/λ_ch 失真) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)
```

关键：**结构给效率、证书给保底**（组合泛化只在覆盖内收窄，平坦带兜底）；**语言给方向、探针给证据**（语言缩搜索空间，EV-lang 仍须探针核实）；**指令只提议不裁决**（propose-not-dispose + 谄媚上限 + 硬禁令）。三个新机制全部经"已验证收窄或更保守动作"两个安全通道起作用。

## 6. 本轮最大风险

**一句话**：本轮把"该相信哪种泛化"的方向盘交给了自然语言，风险从"坏先验普遍"变为"语言介导的先验注入"——一句听上去极权威的"这块冰很结实，直接走"可能被当作泛化证书的骨架，进而影响 shift 分类、基元选择与探针选择，使自信但错误的人（或精心构造的对抗指令）诱导机器人过度泛化；必须以"语言只提议可证伪假设并指挥探针、证书不过即退平坦带、指令不可放松授权与证据且受盾否决、λ_ch 事后审计"四重护栏，宁可退回又宽又慢但诚实的平坦带，绝不把语法流畅当作物理真值。
