# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「夹爪控制」×「持续学习」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**接触相位证书 + 证书守门持续学习**。两个灵感分别治理 v9 的两种债：**接触债**（γ_grasp 只是视觉二值判决，闭合后的摩擦/滑移/力限未进证书，块证书仅覆盖自由空间间隙）与**经验债**（F̂ 冻结、β 一次性标定，长期部署中分布漂移使模型与证书一起腐烂）。必须沿用**中立元退化链**：任一新增模块失效即注入中立元、严格退回 v9，而非行为漂移。

## 0. 直觉与动机

**灵感 1（夹爪控制 → 接触相位证书与滑移安全停驻）**
直觉：v9 把"抓得住"当成一个视觉二值谓词 γ_grasp，但真实失败几乎都发生在闭合之后——摩擦锥边界、扭转力矩、重心偏移、指面磨损、力上限压碎易碎物。夹爪控制的本质是**接触闭环**：力/触觉反馈 + 阻抗控制 + 滑移检测。核心创新：**接触证书器（ContactCertifier, CC）**——把抓取建模为"接触相位自动机"（接近→闭合→提离自检→搬运→放置），每个相位有独立不变量与中止动作；证书不再是布尔量，而是四元组 (m_μ, m_w, m_s, b_f)，用抓取矩阵 G 与摩擦锥把"外部扰动扳手是否仍落在可实现扳手集内"变成可计算的裕度。关键安全设计：**滑移触发有界时间内的"放回/重抓/松开"复合中止**，把 v9 的中止点集从自由空间的"停车"扩展到接触空间的"安全脱手"。

**灵感 2（持续学习 → 证书守门的双时间尺度适应）**
直觉：世界会变（新物体、新摩擦、指面磨损、温湿度），而 v9 的 F̂ 冻结、β 只标定一次。但朴素在线学习有两个致命问题：(a) 灾难性遗忘毁掉旧技能；(b) 更隐蔽的是，学到的模型可能**悄悄让证书失效**——证书仍按旧误差包络签发，物理真实误差却已越界。核心创新：**证书守门持续学习器（Certificate-Gated Continual Learner, CGCL）**——参数二分：**证书内核 θ_core** 冻结且独占安全路径，**自适应残差 Δθ** 只影响性能路径；残差要进入在线决策，必须通过**证书回归门 G_gate**（重放集上 conformal 覆盖率不退化 + 安全不变式回放全通过 + 影子部署 T_shadow 无违背 + 旧任务遗忘在预算内），失败即常数时间回滚。学习因此不是"更新证书"，而是"在证书约束下更新模型"——**证书是学习的不动点与守门人**。

**两者的耦合点**：抓取接触正是最需要适应、也最能产生高质量学习信号的环节（滑移事件、力曲线、成败标签）；接触证书又为持续学习提供"哪些参数可动、动多少不算越界"的安全包络。二者合起来把操纵从静态抓取判决升级为**可适应、可回滚、可证明的接触闭环**。

## 1. 研究问题（轮次升级版）

- **Q1（接触证书可靠性）**：在摩擦系数、物体位姿、触觉力均有界不确定时，抓取矩阵 + 摩擦锥能否给出保守可计算的证书？滑移检测延迟与"有界时间安全脱手"如何折中才不破坏安全？
- **Q2（学习的安全边界）**：参数二分能否真正隔离灾难性遗忘与证书失效？"通过回归门 ⇒ 认证风险不升"需要多强的分布假设？影子部署能否把非平稳带来的假阳性压到可接受？
- **Q3（共演稳定性）**：接触模型持续更新与证书周期性重标定，会不会形成"学到更乐观的 μ → 证书更松 → 接受更危险样本 → 学到更乐观 μ"的正反馈？如何用风险单调性切断？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 接触证书律（Contact-Certificate Grasping, CCG）**
抓取不是谓词，而是相位化证书。每个相位 ϕ ∈ {approach, close, lift_test, transport, release} 有独立不变量 I_ϕ；抓取证书 C_g = (m_μ, m_w, m_s, b_f) 分别为摩擦锥裕度、扳手空间裕度、滑移裕度、力预算余量，全部 ≥0 且 I_ϕ 成立才可执行。滑移裕度低于 τ_slip 必须在一个有界时间 Δ_abort 内进入接触中止动作 a^⊥_c ∈ {place_down, re_grasp, open}，且该动作本身满足 v9 定义的停车不变式。

**P14 证书守门持续学习律（Certificate-Gated Continual Learning, CGCL）**
参数划分为冻结的证书内核 θ_core 与可更新的自适应残差 Δθ；在线只更新 Δθ（低秩/末层 + EWC + 分层重放），且更新跑在非关键线程。Δθ 进入决策前必须通过证书回归门：重放集经验误差包络不升、安全不变式回放全通过、影子部署无证书失效、旧任务遗忘 ≤ B_forget。门失败即回滚到最近检查点，回滚为常数时间。

**P15 学习-证书共演律（Co-Evolution with Risk Monotonicity）**
证书重标定只能由**可交换性检验失败**触发，且重标定后的认证风险上界必须满足 R̂_new ≤ R̂_old + δ_recal；不允许"学习降低经验误差"直接换取"证书放松"。摩擦系数估计二分：学习用后验均值 μ_mean，证书用置信下界 μ_LCB，从结构上切断乐观自反馈。

## 3. 与基线的接口（如何退化）

- CC 失效（触觉不可用 / 力传感超差 / QP 无解）⇒ 退回视觉二值 γ_grasp 与 v9 块证书，接触相位坍缩为单步"闭合后即搬运"，等价 v9 操纵语义；
- CGCL 失效 ⇒ Δθ≡0、θ_core 冻结、不重标定 β，等价 v9 的冻结 F̂ 与一次性 β；
- 证书回归门失效 ⇒ 禁止任何在线晋升（fail-closed），等价 CGCL 失效；
- 可交换性监测失效 ⇒ 不触发重标定，沿用旧 β（保守方向），等价 v9；
- v9 的 AC/MW/ID 失效 ⇒ 按 v9 五级退化链注入中立元，退回 v8；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8，再退回 v7。

## 4. 预期贡献

1. **接触相位证书**：把抓取从视觉二值判决升级为摩擦锥/扳手空间的相位化安全证书，并把中止点集从自由空间扩展到接触空间（放回/重抓/松开复合中止）；
2. **证书守门持续学习**：参数二分 + 回归门 + 影子部署 + 常数时间回滚，使在线适应不侵蚀安全论证；
3. **风险单调共演**：用保守下界与重标定预算切断"学习→证书放松→更危险数据→更乐观学习"的正反馈，给出可累积的风险账本；
4. **操纵-学习双闭环**：接触数据反哺重放、分块释放的算力反哺后台适应；E571–E590 覆盖接触标定、滑移注入、遗忘、门控、共演与端到端。

## 5. 本轮最大风险

**一句话**：接触证书的滑移裕度依赖摩擦系数 μ 的估计，而 μ 恰恰是持续学习要更新的量——若重放缓冲偏向旧物体、可交换性检验又滞后于新接触体制，回归门会在"没见过新世界"的数据上批准一个"对新世界过于乐观"的残差，证书于是在最滑的那一刻最自信。

**新增定义 540（抓取相位自动机 GraspPhaseFSM）**
Φ = {app, clo, lif, tra, rel}，转移 δ_ϕ: Φ × S × C_g → Φ × (A ∪ A^⊥_c)。各相位不变量：
```
I_app: clearance ≥ d_safe ∧ ‖e_align‖ ≤ e_align_max
I_clo: 0 ≤ ḟ_n ≤ ṙ_max ∧ f_n ≤ f_max ∧ 无接触力尖峰
I_lif: 提离 Δh_test 后物体位移跟踪误差 ≤ δ_track ∧ m_s ≥ τ_s
I_tra: C_g valid ∧ v9 块证书 Ĉ_t valid
I_rel: 检测到支撑面 ∧ h ≤ h_safe ∧ 力斜坡下降 ≤ ṙ_max
```
任一不变量破坏或非法转移 ⇒ 立即选择 a^⊥_c；相位内块长独立受限（定义 539′）。

**新增定义 541（抓取扳手与摩擦锥 GraspWrench & FrictionCone）**
物体受外部扳手 w_ext（重力 + 惯性 + 扰动）。抓取可行 ⇔ ∃f ∈ FC(μ)，使 G(q) f = −w_ext。摩擦锥取逐接触约束：
```
FC(μ) = { f : f_{n,i} ≥ 0, ‖f_{t,i}‖ ≤ μ_i f_{n,i}, i = 1..n_c }
```
接触力由带约束 QP 求解：min_f ‖f‖² s.t. G f = −w_ext, 0 ≤ f_n ≤ f_max, ‖f_t‖ ≤ μ^L f_n（用摩擦下界，保守）。

**新增定义 542（接触证书 ContactCertificate）**
```
m_μ = min_i (μ_i^L f_{n,i} − ‖f_{t,i}‖) / (μ_i^L f_{n,i} + ε)      # 归一化摩擦锥裕度
m_w = max{ α ≥ 0 : α·w_ext ∈ W(μ^L) } − 1                        # 扳手空间裕度
m_s = 1 − ‖f_t‖/(μ^L f_n) − s_tac                                # 滑移裕度（含触觉高频滑移指标）
b_f = (f_max − max_i f_{n,i}) / f_max                            # 力预算余量
C_g valid ⇔ m_μ ≥ 0 ∧ m_w ≥ 0 ∧ m_s ≥ 0 ∧ b_f ≥ 0 ∧ I_ϕ
```
μ^L 为摩擦系数置信下界；s_tac 为触觉微振动/切向柔顺位移的归一化滑移指标；β_contact 的标定见 E571。

**新增定义 543（滑移与有界安全脱手 Bounded Place-Down）**
滑移在 t_d 被检测，脱手预算 Δ_abort = Δ_det + Δ_react + Δ_place。安全脱手不变式：
```
h(t_d) ≤ h_safe  ∨  h(t_d) ≤ ½ a_max Δ_abort²
```
满足则落点冲击速度 v ≤ sqrt(2 a_max h) ≤ a_max Δ_abort ≤ v_safe。若 h > h_safe，只允许 place_down / re_grasp；若 h ≤ h_safe，允许 open。a^⊥_c 在满足 v9 定义 534 停车不变式的候选中按风险最小选取。

**新增定义 544（接触中止动作集 ContactAbortSet）**
```
A^⊥_c = { place_down, re_grasp, open }
```
- place_down：以向下加速度 ≤ a_max 移到最近支撑面后张开；
- re_grasp：张开→退到预抓取位→按更新后的位姿/力重新闭合；
- open：仅在 h ≤ h_safe 时可取。
每个动作带预认证轨迹，且并入 v9 的中止点集 P_t：P_t′ = P_t ∪ A^⊥_c，使"接触中止"与"自由空间停车"共用同一可验证语义。

**新增定义 545（参数二分与自适应残差 ParameterPartition & AdaptiveResidual）**
```
θ = (θ_core, Δθ)
θ_core: 感知安全头、M₀ 硬检查、SpatialCert、FaultCert、MW 自身、AC 证书检查、C_g 计算
Δθ:    前向模型残差、抓取位姿评分、摩擦/位姿先验
F_adapt(x) = F_core(x) + Δθ·φ(x),  ‖Δθ‖_F ≤ B_θ
```
在线更新只发生在 ≤1Hz 的非关键线程，且只写 Δθ 的非活动缓冲；θ_core 对安全路径只读。

**新增定义 546（证书回归门 CertificateRegressionGate）**
```
G_gate(Δθ; B_replay) = G1 ∧ G2 ∧ G3 ∧ G4
G1 覆盖率:  重放/验证集经验误差 q̂_α ≤ β 且覆盖 ≥ 1−α
G2 安全回放: N_safe 个安全场景回放，六层指标 + C_g 零违背
G3 影子:    影子部署 T_shadow 周期，无因 Δθ 导致的证书失效
G4 遗忘:    旧任务成功率下降 ≤ B_forget
```
通过 ⇒ 原子切换指针（O(1)）；失败 ⇒ 回滚到最近检查点（O(1)）。门是 fail-closed：任何 G_i 无法评估即视为不通过。

**新增定义 547（可交换性监测与重标定预算 ExchangeabilityMonitor）**
对非一致性分数 s_t 维护 CUSUM 与共形鞅 M_t = Π(1 + λ(s_t − α))；M_t ≥ 1/δ 或 CUSUM 越阈即告警。告警后在最近窗口 W_recal 上重估 q_new，仅当
```
R̂_new ≤ R̂_old + δ_recal
```
才接受；否则保留旧 q（保守方向）。重标定频率 ≤ 1/T_recal，小时预算 N_recal ≤ B_recal，避免追逐噪声。

**新增定义 548（认证风险单调性 RiskMonotonicity）**
```
R̂(t) = P(误差 > β) ≤ α + gap(calibration)
要求: 每次接受重标定 ⇒ R̂_new ≤ R̂_old + δ_recal
⇒ R̂(t) ≤ R̂(0) + N_recal·δ_recal + gap(non-exchangeability)
```
若 N_recal 有界，则累计认证风险有界；这使"学习→放松证书"的路径不可达。

**新增定义 549（分层重放-遗忘预算 ReplayForgettingBudget）**
重放缓冲按接触体制（干/湿/油污/柔性）与物体类分层蓄水池采样。定义遗忘预算 B_forget 为旧任务累计成功率下降上限；超出即冻结 Δθ 或提高旧样本权重。样本价值 v(x) ≈ 滑移裕度不确定度 × 接触丰富度，优先重放高价值接触样本。

**升级定义 496（软证书，v10）**
```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ C_g valid
              ∧ Δ_dom < τ_dom ∧ risk_SLAM < τ_SLAM ∧ Ĉ_t valid }
```
六条件同尺度设计；接触证书失效与块证书失效一样立即触发 M₀ 硬检查，不存在"接触软通过而硬失效"的空洞。

**升级定义 532（动作块，v10）** 块分两种：自由空间块（v9 原义）与**接触块** ζ^c_t = (a^{1:K_c}, Ĉ_t, C_g,t, P_t′)，其中 K_c ≤ K_contact_max = 3（60ms），因接触动力学时间常数远小于自由空间；相变点强制截断块。

**升级定义 533（块证书，v10）** 接触相位内证书附加 C_g，且 ĝ_min 的余量 β 在接触期替换为 β_contact（由 E571 标定，含触觉/摩擦不确定度）。

# IP-357 ContactCertifier：接触证书器
class ContactCertifier:
    def __init__(self, f_max=40.0, tau_slip=0.05, h_safe=0.03,
                 a_max=4.0, v_safe=0.2, k_contact_max=3,
                 mu_lower_fn=None, slip_detector=None):
        self.f_max, self.tau_slip = f_max, tau_slip
        self.h_safe, self.a_max, self.v_safe = h_safe, a_max, v_safe
        self.k_contact_max = k_contact_max
        self.mu_lower = mu_lower_fn or (lambda ctx: ctx.mu_lcb)   # 保守下界
        self.slip = slip_detector or (lambda: 0.0)

    def certificate(self, state, w_ext):
        G  = self._grasp_matrix(state)                            # 定义 541
        mu = self.mu_lower(state.ctx)
        f  = self._solve_contact_qp(G, w_ext, mu)                 # min‖f‖² s.t. 摩擦锥
        fn, ft = f.normal, f.tangential
        m_mu = min((mu[i]*fn[i] - norm(ft[i])) / (mu[i]*fn[i] + 1e-9)
                   for i in range(len(fn)))
        m_w  = self._wrench_margin(G, w_ext, mu) - 1.0
        m_s  = 1.0 - norm_sum(ft) / max(mu * sum(fn), 1e-9) - self.slip()
        b_f  = (self.f_max - max(fn)) / self.f_max
        return ContactCert(m_mu, m_w, m_s, b_f)

    def phase_step(self, phase, state, C_g):
        """返回 (next_phase, abort_action|None)；不变量破坏即中止"""
        k = phase
        if k == 'app':
            if not self._I_app(state): return k, 're_grasp'
            return ('clo', None) if state.at_pregrasp else (k, None)
        if k == 'clo':
            if not self._I_clo(state): return k, 're_grasp'
            return ('lif', None)
        if k == 'lif':
            if not self._lift_ok(state, C_g): return k, 'place_down'
            return ('tra', None)
        if k == 'tra':
            if not (C_g.valid() and self._I_tra(state)):
                return k, self.abort_action(state, C_g)
            return (k, None)
        if k == 'rel':
            if not self._I_rel(state): return k, 'place_down'
            return ('app', None)

    def abort_action(self, state, C_g):
        """定义 543/544：有界时间安全脱手，按风险最小选"""
        h, t_budget = state.height, state.abort_budget
        feasible = []
        if h <= self.h_safe:
            feasible.append(('open', 0.0))
        if self._can_place_down(state): feasible.append(('place_down', self._t_place(state)))
        if self._can_regrasp(state):    feasible.append(('re_grasp', self._t_regrasp(state)))
        feasible = [a for a in feasible if a[1] <= t_budget]
        assert feasible, "必须至少有一个满足定义的接触中止动作"
        return min(feasible, key=lambda a: self._risk(a[0], state, C_g))[0]

    def midchunk_contact_guard(self, C_g, state, k_exec):
        if not C_g.valid() or C_g.m_s < self.tau_slip:
            return ('abort', self.abort_action(state, C_g))
        return ('continue', k_exec + 1)


# IP-358 CertificateGatedContinualLearner：证书守门持续学习器
class CertificateGatedContinualLearner:
    def __init__(self, core, adaptor, replay, beta, alpha=0.1,
                 B_theta=0.05, T_shadow=200, B_forget=0.05,
                 ewc_lambda=100.0, update_period=50):
        self.core, self.adaptor = core, adaptor            # θ_core 只读，Δθ 可写
        self.replay, self.beta, self.alpha = replay, beta, alpha
        self.B_theta, self.T_shadow = B_theta, T_shadow
        self.B_forget, self.ewc_lambda = B_forget, ewc_lambda
        self.update_period = update_period
        self.shadow_stats = ShadowStats()
        self.checkpoint = adaptor.snapshot()               # 不可变检查点

    def predict(self, x, use_adapt=True):
        y = self.core(x)
        if use_adapt and self.adaptor.promoted:
            y = y + self.adaptor.residual(x)               # F_core + Δθ·φ(x)
        return y

    def shadow_step(self, x, y):
        if self.adaptor.promoted:
            return
        y_shadow = self.adaptor.residual(x)                # 影子只读，不进决策
        self.shadow_stats.record(x, y, y_shadow)

    def gate(self, val_data, safety_suite):
        g1 = self._conformal_coverage(val_data) >= 1 - self.alpha \
             and self._conformal_quantile(val_data) <= self.beta
        g2 = safety_suite.run(self.core, self.adaptor) == 0
        g3 = (len(self.shadow_stats) >= self.T_shadow
              and self.shadow_stats.cert_invalidations == 0)
        g4 = self._old_task_drop() <= self.B_forget
        return g1 and g2 and g3 and g4

    def update_offcritical(self, batch):
        """≤1Hz，非关键线程；只更新 Δθ，EWC + 重放"""
        loss = self._task_loss(batch) + self.ewc_lambda * self._ewc(batch)
        self.adaptor.step(loss)
        self.adaptor.project_(self.B_theta)                # 信赖域投影

    def try_promote(self, val_data, safety_suite):
        if not self.gate(val_data, safety_suite):
            self.adaptor.restore(self.checkpoint)          # fail-closed 回滚
            return False
        if not self.adaptor.promoted:
            self.checkpoint = self.adaptor.snapshot()
        self.adaptor.promote_atomic()                      # O(1) 指针切换
        return True


# IP-359 RiskMonotoneRecalibrator：风险单调重标定器
class RiskMonotoneRecalibrator:
    def __init__(self, alpha=0.1, delta=1e-3, lam=0.01,
                 delta_recal=0.002, T_recal=1000, B_recal=6):
        self.alpha, self.delta, self.lam = alpha, delta, lam
        self.delta_recal, self.T_recal, self.B_recal = delta_recal, T_recal, B_recal
        self.M, self.cusum, self.n_recal = 1.0, 0.0, 0
        self.q, self.R_hat = None, None

    def observe(self, score):
        self.M *= (1.0 + self.lam * (score - self.alpha))
        self.cusum = max(0.0, self.cusum + score - self.alpha)
        if self.M >= 1.0 / self.delta or self.cusum > self._cusum_h():
            return self._try_recalibrate()

    def _try_recalibrate(self, recent_scores):
        if self.n_recal >= self.B_recal:
            return False
        q_new = conformal_quantile(recent_scores, self.alpha)
        R_new = estimate_risk(q_new)
        if R_new <= self.R_hat + self.delta_recal:         # 风险单调
            self.q, self.R_hat = q_new, R_new
            self.n_recal += 1
            self.M, self.cusum = 1.0, 0.0
            return True
        return False                                       # 保留旧 q（保守）

## 4. 推导

**引理 87（接触证书可靠性）** 设真实摩擦 μ_i^true ≥ μ_i^L，位姿误差 ‖Δq‖ ≤ e_p，触觉力误差 ‖Δf‖ ≤ e_f，且扳手映射对 q 为 L_G-Lipschitz。若 C_g 用 μ^L 与最坏位姿/力计算且 valid，则实际抓取满足 G f = −w_ext 且摩擦锥裕度 ≥ m_μ − L_G e_p − e_f（归一化后）。若该值 ≥0，则抓取为力封闭。证明：FC 对 μ 单调（μ^true ≥ μ^L ⇒ FC(μ^L) ⊆ FC(μ^true)），位姿误差经 Lipschitz 传入 G，力误差经三角不等式传入 f；三项相加得裕度下界。∎

**引理 88（滑移有界响应与接触中止安全）** 若滑移在 Δ_det 内检出，所选 a^⊥_c 的认证脱手时间 ≤ Δ_abort，且检测时高度满足 h ≤ h_safe 或 h ≤ ½ a_max Δ_abort²，则滑移事件不产生超过 v_safe 的冲击速度；又因 a^⊥_c 携带满足 v9 定义 534 的预认证轨迹，自由空间停车安全性保持。证明：落体运动学 h = ½ a t² ⇒ 落地速度 ≤ sqrt(2 a_max h) ≤ a_max Δ_abort ≤ v_safe；a^⊥_c ∈ P_t′ 且 P_t′ 的元素逐条满足停车不变式。∎

**引理 89（证书内核隔离）** 若安全决策函数 h_safe(·; θ_core) 与证书计算 C_g(·; θ_core) 的依赖闭包不含 Δθ，则对任意 Δθ，安全路径输出与证书逐位不变；故 v9 引理 80–86 原样成立。证明：只读分区 + 依赖闭包不相交；安全路径的每次读取都只索引 θ_core，组合后输出不变。注意：若任一安全路径读取了适应后的分数则引理失效——这由静态依赖检查（E584）强制。∎

**引理 90（回归门可靠性）** 若重放/验证样本与下一部署窗口可交换，且门要求 conformal 分位数 q̂_α ≤ β（覆盖 ≥1−α）并通过 N_safe 个安全场景，则部署误差超 β 的概率 ≤ α + 1/(N_safe+1)。若无（可）交换性，则门不提供任何保证——这是显式暴露的假设，也是本轮最大风险。证明：conformal 覆盖定理给出第一项；N_safe 个独立安全场景零违背的 Clopper–Pearson 上界给出第二项。∎

**引理 91（常数时间回滚与主环隔离）** 双缓冲参数指针 + 不可变 θ_core + 版本化重放，使回滚为 O(1) 原子操作；更新只写非活动缓冲，故不存在部分更新状态；适应与门评估在非关键线程，50Hz 主环 WCET 不受影响。证明：标准 RCU/双缓冲论证 + 线程预算隔离（复杂度表）。∎

**引理 92（风险单调共演）** 若证书使用 μ^L = LCB_δ(μ) ≤ μ_mean，且每次重标定仅当 R̂_new ≤ R̂_old + δ_recal 才被接受，则经 N_recal 次重标定有 R̂(t) ≤ R̂(0) + N_recal·δ_recal；且 μ_mean 单独上升不能放松 m_μ，因为 m_μ 用 μ^L 计算，而 μ^L 仅在数据/覆盖增加时上升。故"乐观学习→放松证书→更危险样本"的正反馈被切断。证明：对重标定事件归纳，配合 LCB 的单调性与定义 548。∎

**引理 93（v9 逐位等价退化）** 注入 CC→视觉二值 γ_grasp 且相位坍缩为 clo→tra、CGCL→Δθ≡0 且 θ_core 冻结、RMR→不重标定，则日志与 v9 对应退化级逐位一致（表 536 映射）；三个模块均为可选增强。∎
