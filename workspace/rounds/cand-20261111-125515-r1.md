# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 1 轮；本轮灵感：「安全性」×「面部表情识别」）

> 第 54 轮把技能组合提升为「动作-鲁棒性双证书」`J=(ρ,A_cert,γ_ce,δ_a)`，但它默认系统面对的是「无情绪、无恶意、可物理隔离」的世界。本轮把 **面部表情识别（FER）** 作为一条真实存在、却极不可靠的人机侧信道引入，并把 **安全性** 同时理解为物理/心理安全（safety）与对抗/隐私安全（security）。核心矛盾：**H22**：FER 输出不是「人的情绪读数」，而是受文化、个体、遮挡、姿态与对抗扰动影响的**证据**；把它当标签使用，会在最需要保守的时刻系统性地**放松**安全约束（fail-dangerous）。**H23**：第 54 轮的证书只证明「在标称感知下任务可行」，既不证明「对人无害」，也不证明「情感通道未被欺骗」；安全必须是动作空间上的一等约束，而不是事后的过滤器。

## 0. 直觉与动机

**灵感 1（表情不是仪表读数，而是一条不可信证据）**
直觉：人脸到情绪的映射是**多对多**的——同一张笑脸可能是礼貌、紧张、疼痛掩饰或社交面具；FER 数据集里的「愤怒/恐惧」标签本身带有标注者文化与情境先验。因此正确的接口不是 `emotion = argmax f(x)`，而是 `(校准后验 q(e|x), 保形集 E_α(x), 完整性 trust)`。**先验直觉**：把 FER 当温度计，温控器会在探头坏掉时把房间烧了；把 FER 当「带误差棒的证人」，系统才会在证人含糊时选择保守。

**灵感 2（安全是动作空间上的约束，不是输出后的补丁）**
直觉：安全强化学习里的 shielding / control barrier function 告诉我们，安全应写成「允许动作集」而不是「拒绝某些输出」。不同情感状态对应不同的**伤害风险预算** `b(e)`：检测到痛苦/恐惧时，力、速度、接近距离的上限都应更低。关键在于对**保形集取交集**而不是对点估计取值：`A_safe(E_α)=∩_{e∈E_α} A_safe(e)`，语义是「只要还有一种合理解读禁止该动作，就禁止」。这把「不确定性」从一句免责声明变成**可执行的全称量化**。

**灵感 3（安全包含 security：表情通道是攻击面）**
直觉：一个打印的「微笑」贴片、一段回放视频、一次化妆或墨镜遮挡，就可能让机器人误以为人类放松，从而解除力/速度限制。于是 `trusted` 不能由分类置信度决定，而应由**可证明的扰动半径**（randomized smoothing）与**活体/反欺骗分数**共同决定。安全工程的第一原则是 fail-safe：通道不可信时，情感信号只能**收紧**约束，绝不能**放松**约束；必要时回到显式确认或最小动作集。

**灵感 4（安全包含隐私：人脸是生物特征，不是普通输入）**
直觉：把原始人脸图像上传云端做「全局情感理解」既违反数据最小化，也制造了重识别与链接攻击面。正确做法是端侧编码 + 差分隐私（DP）统计量上传，云端只接收「情感充分统计量 + 保形集摘要 + 完整性分数」。但 DP 噪声本质上是一次**分布平移**，会破坏保形预测的可交换性假设——因此隐私机制必须与校准机制**同分布**，否则覆盖率保证会在部署时悄悄失效。

**灵感 5（伤害常发生在技能切换处，而非单个技能内部）**
直觉：第 54 轮的动作空间图 `G_S` 把组合看成路径搜索，但真正的危险在**转换区** `ΔA`：机器人从「递杯子」切到「松手」的瞬间，若把人类的退缩表情误读为「准备好了」，伤害就发生。因此组合边权必须加入**伤害裕度**与**信任损失**，且转换区需要单独的安全护栏，而不是只检查两端技能各自的安全集。

**灵感 6（纵深防御：情感永远不能越过硬物理上限）**
直觉：把安全做成层级：`L0` 硬物理限幅（与情感无关，不可被任何模型放松）→ `L1` 情感门控安全包络（只能在 L0 内收紧）→ `L2` 任务计划 → `L3` 情感建议。形式化地要求 `A_safe(e) ⊆ A_hard` 对所有 `e` 成立，且 `A_safe` 对不确定性**单调收缩**。这样即使 FER 完全错误，系统最多变得「笨」，不会变得「危险」。

## 1. 形式化定义（增量：定义 121–128）

**定义 121（情感证据与保形情感集）**
设 `x` 为人脸观测（图像/视频片段），情感状态空间 `E`（离散情绪类别，或离散化的 valence–arousal 网格）。FER 模型 `f_θ` 经温度缩放校准得到 `q_θ(e|x)`。取非一致性分数
```
s(x,e) = 1 - q_θ(e|x)
```
在留出校准集 `{(x_i,e_i*)}` 上取 `q̂_{1-α}` 为 `s(x_i,e_i*)` 的 `⌈(n+1)(1-α)⌉/n` 分位数，定义
```
E_α(x) = { e ∈ E : s(x,e) ≤ q̂_{1-α} }
```
在可交换性下满足 `P(e* ∈ E_α(x)) ≥ 1-α`。**空集协议**：`E_α(x)=∅` 表示「无可用情感证据」，必须触发 `ABSTAIN`（回到最小安全集），而**不是**逻辑上空集使交集为全集所带来的「无约束」——这是本框架与朴素保形分类最容易被误用的地方。

**定义 122（伤害风险泛函与情感条件风险预算）**
伤害风险 `R_h : A × E → R_{≥0}` 度量动作 `a` 在情感状态 `e` 下对人造成的物理/心理伤害（力超限、突进、噪声、非预期接触等）。风险预算 `b : E → R_{≥0}` 对痛苦/恐惧/高唤醒**单调不增**。情感条件安全集
```
A_safe(e) = { a ∈ A : R_h(a,e) ≤ b(e) } ∩ A_hard
```
其中 `A_hard` 为与情感无关的硬物理上限（力矩、速度、工作空间），满足 `A_safe(e) ⊆ A_hard, ∀e`。定义伤害裕度 `m(a,e) = b(e) - R_h(a,e)`。

**定义 123（情感门控安全包络）**
对保形集 `E_α(x)`，定义
```
A_safe(E_α) = ⋂_{e ∈ E_α} A_safe(e)
```
并对空集规定 `A_safe(∅) = A_min`（全局最小动作集，例如零速/零力/保持距离）。性质：
```
E_α ⊆ E_α'  ⟹  A_safe(E_α') ⊆ A_safe(E_α)
```
即**不确定性只收紧、不放松**。若 `e* ∈ E_α`，则任意 `a ∈ A_safe(E_α)` 对真实情感状态安全。

**定义 124（情感通道完整性与可证明扰动半径）**
对分类器 `f` 的随机平滑版本 `g(x)=E_{δ∼N(0,σ²I)}[f(x+δ)]`，令 `p_(1),p_(2)` 为平滑后验最高与次高概率，则 L2 意义下的可证明半径为
```
r(x) = (σ/2)·( Φ^{-1}(p_(1)) - Φ^{-1}(p_(2)) )
```
联合反欺骗分数 `s_sp(x)`（活体、纹理、时序一致性），定义信任格
```
T(x) ∈ { trusted, degraded, rejected }
trusted  ⟺ r(x) ≥ ε_patch ∧ s_sp(x) ≤ τ_s
```
- `trusted`：情感可用于正常门控；
- `degraded`：情感只能**收紧**约束，预算替换为 `b_min = min_e b(e)`；
- `rejected`：情感信号被忽略，回到 `A_hard ∩ A_min`，并要求显式人类确认后才执行有风险动作。

**定义 125（fail-safe 保守序与最小干预护盾）**
在动作集上定义保守偏序 `⊑`（更慢、更轻、更远者为更保守），并假设 `A_safe(E_α)` 对 `⊑` 向下封闭。对任意提议动作 `a_prop`，护盾
```
Shield(a_prop) = max_⊑ { a' ∈ A_safe(E_α) : a' ⊑ a_prop }
```
若集合为空，取 `a_min = min_⊑ A_min`。护盾保证「输出必安全」，同时「在安全前提下尽量保留能力」，避免安全过滤器造成的死锁与能力悬崖。

**定义 126（隐私-安全契约）**
端侧编码器 `φ`，差分隐私机制 `M`（高斯或拉普拉斯），云端仅接收 `z = M(φ(x))` 与保形摘要。对相邻人脸数据集 `D,D'`（至多一条记录不同）要求
```
P(M(φ(D)) ∈ S) ≤ e^ε · P(M(φ(D')) ∈ S) + δ
```
隐私-安全契约 `C_ps = (ε, δ, γ_ce^priv, F(ε))`，其中 `γ_ce^priv` 是第 54 轮云边映射的隐私化版本，`F(ε)` 为在隐私预算 `ε` 下可达的安全裕度前沿。**关键约束**：保形校准必须在与部署相同的 `M` 下完成（noise-aware conformal），否则覆盖率保证不成立。

**定义 127（伤害感知的技能组合）**
扩展第 54 轮组合图边权：
```
cost_safe(S_i,S_j) = w_a(1-compat) + w_ρ(1-ρ_comp)
                   + w_h(1 - Hm(S_i,S_j)) + w_t(1 - Trust) + w_p·ε
```
其中转换区 `ΔA(S_i,S_j)` 上的伤害裕度
```
Hm(S_i,S_j) = min_{a∈ΔA, e∈E_α} m(a,e)
```
路径可行性除第 54 轮 `J` 外，还要求每个转移 `a ∈ A_core ∩ A_safe(E_α)`。这使「松手/交接/接触」等高风险转移成为显式约束，而非被两端技能的平均安全性掩盖。

**定义 128（情感-安全联合证书）**
```
J_safe = ( J, E_α, S_cert, T, P_cert )
S_cert = (A_safe(E_α), b, margin, empty_flag)
P_cert = (ε, δ, coverage_noisy)
```
可部署当且仅当：
```
J 可部署  ∧  A_core ∩ A_safe(E_α) ≠ ∅  ∧  empty_flag = false
∧ (T = trusted  ∨  (T = degraded ∧ b 取 b_min)  ∨  (T = rejected ∧ 显式确认))
∧ ε ≤ ε_max  ∧  coverage_noisy ≥ 1 - α - ε_cov
```
**语义声明**：`J_safe` 证明的是「在情感标签语义与可交换性假设下，伤害概率有界」，**不**证明「系统读懂了人的情绪」。前者是可工程化的，后者不是。

## 2. 关键算法 伪代码

### IP-121 AQ（Affect Quantification）

```python
def affect_quantify(x, f, T, calib_scores, alpha):
    q = temperature_softmax(f(x), T)
    qhat = conformal_quantile(calib_scores, alpha)
    S = {e for e in E if 1 - q[e] <= qhat}
    if not S:
        return ('abstain', S, q)     # 空集 = 无证据，不是无约束
    return ('ok', S, q)
```

### IP-122 SEG（Safety Envelope Gate）

```python
def safety_envelope(E_alpha, risk, budget, A_hard, A_min):
    if not E_alpha:
        return A_min & A_hard, 'abstain'
    A = A_hard
    for e in E_alpha:
        A &= {a for a in A if risk(a, e) <= budget(e)}
    if not A:
        return A_min & A_hard, 'fallback'
    margin = min(budget(e) - risk(a, e) for e in E_alpha for a in A)
    return A, margin
```

### IP-123 ACI（Affect Channel Integrity）

```python
def channel_integrity(x, smooth_g, spoof_detector, eps_patch, tau_s):
    p = monte_carlo_smooth(smooth_g, x, n=1000, sigma=SIGMA)
    top1, top2 = sorted(p, reverse=True)[:2]
    r = (SIGMA / 2) * (norm_ppf(top1) - norm_ppf(top2))
    s_sp = spoof_detector(x)
    if r >= eps_patch and s_sp <= tau_s:
        return 'trusted', r, s_sp
    if s_sp > tau_s or r <= 0:
        return 'rejected', r, s_sp
    return 'degraded', r, s_sp
```

### IP-124 GShield（Grade Shield）

```python
def grade_shield(a_prop, A_safe, leq):
    feasible = [a for a in A_safe if leq(a, a_prop)]
    if not feasible:
        return min_by(A_safe, leq), 'strict'
    return max_by(feasible, leq), 'ok'
```

### IP-125 PSC（Privacy-Safety Contract）

```python
def dp_affect_channel(x, encoder_phi, dp_mech, eps):
    u = encoder_phi(x)                 # 端侧，不上传原图
    z = dp_mech(u, eps)                # (eps, delta)-DP 充分统计量
    return z

def calibrate_noise_aware(calib_faces, dp_mech, eps, alpha):
    scores = []
    for x, e_star in calib_faces:
        z = dp_affect_channel(x, phi, dp_mech, eps)
        q = affect_head(z)
        scores.append(1 - q[e_star])
    return conformal_quantile(scores, alpha)
```

### IP-126 SAC（Safety-Aware Composition）

```python
def safe_compose(task, G, E_alpha, trust, A_core):
    if trust == 'rejected':
        A_safe = A_hard & A_min
    else:
        A_safe, _ = safety_envelope(
            E_alpha, risk, budget if trust == 'trusted' else min_budget, A_hard, A_min)
    if not (A_core & A_safe):
        return ('reject', 'no_safe_action', A_core, A_safe)
    path = a_star(G, task, edge_cost=cost_safe,
                  prune=lambda e: transition_safe(e, A_safe, E_alpha))
    return ('ok', path, A_safe)
```

### IP-127 AJC（Affect Joint Certificate）

```python
def affect_joint_certificate(J, E_alpha, r, s_sp, eps, delta, alpha):
    trust = trust_from(r, s_sp)
    A_safe, flag = safety_envelope(E_alpha, risk, budget_for(trust), A_hard, A_min)
    if flag == 'abstain' or not (J.A_core & A_safe):
        return ('reject', 'affect_unsafe_or_empty', flag)
    cov = noisy_coverage(eps)
    if cov < 1 - alpha - EPS_COV or eps > EPS_MAX:
        return ('reject', 'privacy_coverage_fail', cov, eps)
    return ('ok', JSafe(J, E_alpha, A_safe, trust,
                        P_cert=(eps, delta, cov)))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| AQ | O(\|E\| + n log n) | O(n) | 温度校准、可交换性、空集协议 |
| SEG | O(\|E_α\|·\|A\|) | O(\|A\|) | 交集语义、预算单调、A_hard 包含 |
| ACI | O(N_smooth·C) | O(C) | 平滑半径 sound、反欺骗阈值 |
| GShield | O(\|A\|) | O(\|A\|) | 向下封闭、最小干预 |
| PSC | O(\|calib\|·C) | O(\|calib\|) | DP 组合、噪声同分布校准 |
| SAC | O(\|V\| log \|V\| + \|E\|·\|A\|) | O(\|V\|+\|E\|) | 转移区安全、伤害裕度 |
| AJC | O(\|S\|·\|A\| + \|E\|) | O(\|A\|+\|E\|) | 联合约束闭合 |

**假设（承接第 54 轮 A22–A28）**
- **(A29)** 校准集与部署分布可交换，故 `P(e*∈E_α) ≥ 1-α`；
- **(A30)** `R_h(a,e)` 关于 `e` 是 `L`-Lipschitz（在情感度量 `d_E` 下）；
- **(A31)** 完整性检查对扰动预算 `ε_patch` sound：`P(trusted | r<ε_patch 或欺骗) ≤ β_s`；
- **(A32)** 保形校准在与部署相同的 DP 机制 `M` 下完成，故 `coverage_noisy ≥ 1-α-ε_cov`；
- **(A33)** `A_safe(E_α)` 对保守序 `⊑` 向下封闭，且 `A_hard` 永不被情感放松。

**定理 1（情感门控安全可靠性，Affect-Gated Safety Soundness）**
若 `e*∈E_α`、`T=trusted` 或 `degraded`（预算取 `b_min`）、且 `a=Shield(a_prop)` 有定义，则
```
R_h(a, e*) ≤ b(e*)
```
从而
```
P(harm) ≤ α + β_s + ε_cov + P(empty_flag) · 0
```
其中空集回退到 `A_min ⊆ A_hard` 不增加伤害概率。**证明要点**：`Shield` 输出属于 `A_safe(E_α)=∩_{e∈E_α}A_safe(e)`；由 `e*∈E_α` 得 `a∈A_safe(e*)`，即 `R_h(a,e*)≤b(e*)`；再对三个失配事件取并集界。若仅知 `e*` 距 `E_α` 不超过 `δ`，则由 (A30) 得 `R_h(a,e*) ≤ max_{e∈E_α} b(e) + Lδ`，给出**分布外**的软界。

**定理 2（最小干预与无死锁，Least-Restrictive Safety）**
若 `A_safe` 对 `⊑` 向下封闭且 `{a'∈A_safe : a'⊑a_prop}` 非空，则 `Shield(a_prop)` 是该集合的最大元；因此它 (i) 必安全，(ii) 在所有安全动作中保留最多能力，(iii) 当 `a_prop∈A_safe` 时原样通过。若集合为空则回退 `a_min`，输出始终有定义，避免「安全即停机」的能力悬崖。

**定理 3（隐私噪声下的覆盖退化）**
若校准用 `M_0`、部署用 `M_1`，则
```
| coverage(M_1) - (1-α) | ≤ TV(P_{M_0}, P_{M_1}) + O(1/√n)
```
因此当 `M_1` 的噪声尺度增大时，覆盖率单调退化，必须噪声感知校准或在端侧以相同机制在线重校准。

## 4. 实验设计 E162–E167（含合成 sanity check）

| E163 安全包络 vs 点估计 | 伤害率、伤害幅度、任务效用、误保守率 | 伤害率相对下降 ≥50%，效用损失 ≤15% |
| E164 对抗/欺骗攻击 | 可证明半径、攻击成功率、**fail-dangerous 率** | 开启完整性后 fail-dangerous ≤ α |
| E165 隐私-安全-效用前沿 | FER macro-F1、覆盖率、安全裕度、重识别 AUC | `ε≤2` 时重识别 AUC ≤0.55，裕度损失 ≤10% |
| E166 转换区安全 | `ΔA` 上的伤害率、护盾干预率、任务完成率 | 转换区伤害率降至单技能内伤害率同量级 |

**合成算例（非真实人脸数据，仅验证机制；固定随机种子 2026）**
设置：二类情感 `e∈{calm, distress}`，`P(distress)=0.30`；FER 证据 `z_true∼N(μ,1)`、`z_other∼N(0,1)`，`softmax` 后验；风险预算 `b(calm)=10N`、`b(distress)=3N`；动作为连续力值 `a∈[0,10]`；伤害事件为 `a>b(e*)`，效用取 `a/10`。

### IP-121 AQ + IP-122 SEG

```python
def affect_quantify(x, f, T, calib_scores, alpha):
    q = temperature_softmax(f(x), T)
    qhat = conformal_quantile(calib_scores, alpha)
    S = {e for e in E if 1 - q[e] <= qhat}
    return ('abstain' if not S else 'ok', S, q)

def safety_envelope(E_alpha, risk, budget, A_hard, A_min, trust):
    if not E_alpha:
        return A_min & A_hard, 'abstain'
    if trust == 'rejected':
        return A_hard & A_min, 'rejected'
    b = budget if trust == 'trusted' else (lambda e: min_budget)
    A = A_hard
    for e in E_alpha:
        A &= {a for a in A if risk(a, e) <= b(e)}
    if not A:
        return A_min & A_hard, 'fallback'
    margin = min(b(e) - risk(a, e) for e in E_alpha for a in A)
    return A, ('ok', margin)
```

### IP-123 ACI

```python
def channel_integrity(x, smooth_g, spoof_detector, eps_patch, tau_s):
    p = sorted(monte_carlo_smooth(smooth_g, x, n=1000, sigma=SIGMA), reverse=True)
    r = (SIGMA / 2) * (norm_ppf(p[0]) - norm_ppf(p[1]))
    s_sp = spoof_detector(x)
    if r >= eps_patch and s_sp <= tau_s: return 'trusted',  r, s_sp
    if r <= 0 or s_sp > tau_s:           return 'rejected', r, s_sp
    return 'degraded', r, s_sp
```

### IP-124 GShield + IP-126 HAC

def grade_shield(a_prop, A_safe, leq):
    feasible = [a for a in A_safe if leq(a, a_prop)]
    return (max_by(feasible, leq), 'ok') if feasible else (min_by(A_safe, leq), 'strict')

def harm_margin(S_i, S_j, E_alpha, risk, budget):
    return min(budget(e) - risk(a, e)
               for a in transition_region(S_i, S_j) for e in E_alpha)

def safe_compose(task, G, E_alpha, trust, A_core):
    A_safe, flag = safety_envelope(E_alpha, risk, budget, A_hard, A_min, trust)
    if flag in ('abstain', 'rejected', 'fallback') or not (A_core & A_safe):
        return ('reject', flag, A_safe)
    path = a_star(G, task, edge_cost=lambda i, j: cost_safe(i, j, E_alpha),
                  prune=lambda i, j: transition_safe(i, j, A_safe, E_alpha))

| AJC/AAC | O(\|S\|·\|A\| + \|E\|) | O(\|A\|+\|E\|) | 联合约束闭合、可审计 |

**定理（Affect-Gated Safety Soundness）**
在 (A22)–(A33) 下，若 `e*∈E_α`、信任格非 `rejected`、护盾输出有定义，则
```
R_h(Shield(a_prop), e*) ≤ b(e*)     （降级时 ≤ b_min ≤ b(e*)）
P(harm) ≤ α + β_s + ε_cov
```
**证明要点**：护盾输出属于 `∩_{e∈E_α}A_safe(e)`；由 `e*∈E_α` 直接得单点安全；对「未覆盖 / 完整性误判 / DP 覆盖损失」三个事件取并集界。空集回退到 `A_min⊆A_hard` 不增加伤害项。

**最小干预定理**：若 `A_safe` 对 `⊑` 向下封闭且存在可行下界，`Shield` 返回最大可行安全动作，故安全过滤不会无谓停机；当提议动作本身安全时原样通过。这把「安全」从二元拒绝升级为**可解释的降级**。

**隐私-安全权衡**：`F(ε)` 随 `ε` 减小而收紧；DP 噪声作为分布平移会使覆盖率下降 `≈TV(P_clean,P_noisy)`，必须在同一 `M` 下校准。

与 UniBot 的契合：服务/协作机器人天然面对人类情绪与近距离接触；本方案不追求「情绪识别 SOTA」，而是把 FER 变成**可证伪、可回退、可审计的安全约束源**，与已有的动作-鲁棒性证书体系正交叠加。

## 7. 本轮最大风险

**一句话**：整个 GEAS 的安全声明都**条件于 FER 标签语义有效与保形/完整性/DP 假设成立**——文化性误读、分布外人群或物理欺骗会让情感通道「自信地错」，而情感门控的语义恰好在「看起来平静」时**放松**约束，形成最危险的 fail-dangerous；因此情感必须永远只是「只能收紧、不能放松」的建议信号，并以硬物理上限、显式同意、完整性回退与可审计安全案例四重兜底，绝不把「读懂了情绪」当作安全证书。
