### 第 1 轮灵感驱动研究记录（v29，承接 v28）

**灵感词**：开源生态、预训练

**直觉与动机**：

前几轮把双足机器人的「常识包容」做成了证书驱动的 KEMPC/KT-MPC：规则要过证书、证书要过准入闸门。但知识本身仍是**单机、闭门、离线**积累的。本轮的两个灵感词恰好指向知识生产与流通方式的重构：

1. **开源生态**：常识规则应当像开源软件一样被社区贡献、评审、分叉、合并、版本化。一条常识不再只是谓词对 `(P, Q)`，而是一个**知识包** `K`：带作者、许可证、依赖集、代码提交、签名、验证证据、来源链。好处是知识可以复用、可被独立审计、可并行演进；代价是引入了软件供应链的经典威胁——恶意投毒、过期 fork、许可证不兼容、依赖环，以及所有机器人从同一个上游分叉导致的「生态单cultivar」（相关性故障）。

2. **预训练**：可以在异构机器人日志与仿真语料上预训练一个**常识基础模型（Knowledge Foundation Model, KFM）**，学习「在什么状态/任务上下文下，哪些规则模板可能适用、参数大致取多少」的先验。机器人只需少量本地证据即可适配新任务。好处是冷启动快、覆盖面广；代价是**先验锁定**（先验压过本地证据）与**语料污染**（预训练语料混入了目标部署数据，使验证退化为自证）。

**关键洞见**：把两者合起来，证书的对象必须再升一层。v28 的证书证明「规则在当前轨迹上成立」；v29 还要证明「规则**从何而来**、经过谁的验证、依赖什么、其先验是否被本地证据支持」。于是形成三段式知识流水线：

> **预训练提供先验产能 → 开源生态提供知识流通 → 来源/先验证书提供准入闸门**

预训练先验不是权威，而是一个**可被本地证据否决的假设**（`β(n_eff)` 随本地样本衰减）；社区知识包不是默认可信，而是一个**必须通过来源级证书（PLC）的候选**。这把 KEMPC 从「单机知识自适应」推进为「联邦式、可审计、可证伪的知识共同体」。

**形式化目标（增量）**：

1. 定义 KFM 先验 `p_θ(φ, θ_rule | x, τ)`，其中 `φ` 为规则模板、`θ_rule` 为阈值/权重等连续参数。
2. 定义知识包 `K = (φ, θ, E_val, prov, ℓ, Dep, v)` 与来源 DAG `G_prov = (K, E_parent)`；要求 `G_prov` 无环。
3. 定义信任 `T(K)` 与来源准入谓词 `A(K)`：签名有效 ∧ 许可证兼容 ∧ 依赖闭包 ∧ 污染分低于阈值 ∧ `T(K) ≥ τ_min` ∧ 来源根多样性达标。
4. 定义先验-证据校准：`β(n_eff) = 1 / (1 + n_eff/κ)`，后验 `p_r ∝ p_θ · exp(-λ·loss_local)`，并要求先验-证据散度 `Δ_pe` 与污染分 `C_contam` 均低于阈值，否则弃用先验、退化为纯本地 KC。
5. 定义 KC-MPC 与 Open-Commons Cert Gate（OCG），使 `Exec_v29 = Exec_v28 ∩ Fil_provenance ∩ Fil_prior ⊆ Exec_v28`。
6. 实验验证：在注入投毒/过期/许可证不兼容包的开源供应链下，OCG 的误纳率显著低于仅签名校验与 v28 的 KTCG；在分布偏移下，`β(n_eff)` 校准比固定 β 更快摆脱先验锁定；在语料污染率 `ε` 上升时，`C_contam` 能检出验证率虚高，避免「自证循环」。

**本轮最大风险**：**预训练语料与开源验证证据的共谋性污染（自证循环）**——若 KFM 的预训练语料已含目标部署数据，而社区知识包的验证证据又来自同一数据源，那么表面验证率会异常漂亮地通过所有证书；系统把「记忆/泄漏」误当「泛化」，直到真正的新场景才崩溃，且崩溃前几乎无法从证书层面看出异常。

### IP-467 Knowledge Foundation Model (KFM)

```python
@dataclass
class RulePrior:
    logits: Tensor            # [N_tpl] 规则模板打分
    params: Tensor            # [N_tpl, d_theta] 阈值/权重等参数
    template_ids: list[str]
    corpus_fingerprint: str   # 语料清单的哈希，用于污染比对

@dataclass
class KnowledgeFoundationModel:
    """KFM：在异构语料上预训练的常识先验；只产出候选，不直接控制"""
    encoder: Callable          # (x, task_ctx) -> z
    rule_head: Callable        # z -> logits[N_tpl]
    param_head: Callable       # z -> params[N_tpl, d_theta]
    templates: list[str]
    corpus_manifest: dict      # {source_id: sha256}
    theta_version: str = "kfm-v1"

    def prior(self, x: Tensor, task_ctx: dict) -> RulePrior:
        z = self.encoder(x, task_ctx)
        return RulePrior(
            logits=self.rule_head(z),
            params=self.param_head(z),
            template_ids=self.templates,
            corpus_fingerprint=self._fingerprint(),
        )

    def candidate_kcs(self, x: Tensor, task_ctx: dict,
                      top_k: int = 8, temp: float = 1.0) -> list['CandidateKC']:
        pr = self.prior(x, task_ctx)
        p = softmax(pr.logits / temp, dim=-1)
        idx = torch.topk(p, k=min(top_k, len(p))).indices
        return [CandidateKC(template=self.templates[i],
                            theta=pr.params[i],
                            prior_prob=float(p[i])) for i in idx]

    def finetune(self, local_loader, beta_schedule, base_model,
                 epochs: int = 10, lr: float = 1e-4):
        """L = L_task + β(n_eff) · KL(p_θ_current ‖ p_θ_base)"""
        opt = torch.optim.Adam(self.parameters(), lr=lr)
        for _ in range(epochs):
            for x, y, n_eff in local_loader:
                prior = self.prior(x, y.task_ctx)
                base = base_model.prior(x, y.task_ctx)  # 冻结副本
                loss = self.task_loss(prior, y) \
                    + beta_schedule(n_eff) * kl_div(prior, base)
                opt.zero_grad(); loss.backward(); opt.step()

    def _fingerprint(self) -> str:
        return sha256(json.dumps(self.corpus_manifest, sort_keys=True).encode()).hexdigest()
```

### IP-468 Open Knowledge Ecosystem Protocol (OKEP)

```python
@dataclass
class ProvenanceRecord:
    author: str
    parent_kids: list[str]
    corpus_hashes: list[str]
    code_commit: str
    reviewers: list[str]
    timestamp: float

@dataclass
class ValidationEvidence:
    n_trials: int
    success_rate: float          # 拟合集上的验证率
    heldout_success_rate: float  # 与拟合集来源独立的留出验证率
    audit_corpus_hash: str

@dataclass
class KnowledgePackage:
    kid: str
    phi: str
    theta: dict
    precond_src: str
    postcond_src: str
    evidence: ValidationEvidence
    prov: ProvenanceRecord
    license: str
    deps: list[str]
    version: str
    signature: bytes

class OpenKnowledgeEcosystem:
    """OKEP：知识包的贡献、分叉、合并、依赖解析与来源准入"""
    def __init__(self, repo: dict[str, KnowledgePackage],
                 reputation: dict[str, float], license_policy,
                 trust_weights: dict, t_min: float = 0.6,
                 diversity_min: float = 0.3, contamination_max: float = 0.2):
        self.repo = repo
        self.reputation = reputation
        self.license_policy = license_policy
        self.w = trust_weights
        self.t_min = t_min
        self.diversity_min = diversity_min
        self.contamination_max = contamination_max
        self.half_life = 90 * 24 * 3600.0

    def resolve_dependencies(self, kid: str) -> list[str]:
        """DFS 拓扑排序；检测缺失依赖与依赖环"""
        order, state = [], {}
        def visit(k: str):
            if state.get(k) == 1:
                raise ValueError(f"dependency cycle at {k}")
            if state.get(k) == 2:
                return
            if k not in self.repo:
                raise KeyError(f"missing dependency {k}")
            state[k] = 1
            for d in self.repo[k].deps:
                visit(d)
            state[k] = 2
            order.append(k)
        visit(kid)
        return order

    def provenance_acyclic(self, kid: str) -> bool:
        try:
            self.resolve_dependencies(kid)
            return True
        except (ValueError, KeyError):
            return False

    def license_compatible(self, pkg: KnowledgePackage) -> bool:
        dep_licenses = [self.repo[d].license for d in pkg.deps if d in self.repo]
        return self.license_policy.check(pkg.license, dep_licenses)

    def contamination(self, pkg: KnowledgePackage,
                      deployment_fp: 'DeploymentFingerprint') -> float:
        """C_contam = max(语料重叠, 留出验证虚高, canary 泄漏率)"""
        overlap = len(set(pkg.prov.corpus_hashes)
                      & set(deployment_fp.corpus_hashes))
        overlap /= max(1, len(pkg.prov.corpus_hashes))
        audit_gap = max(0.0, pkg.evidence.success_rate
                        - pkg.evidence.heldout_success_rate)
        canary = deployment_fp.canary_leak_rate(pkg.theta)
        return max(overlap, audit_gap, canary)

    def trust(self, pkg: KnowledgePackage,
              deployment_fp: 'DeploymentFingerprint') -> float:
        a = self.reputation.get(pkg.prov.author, 0.0)
        age = max(0.0, time.time() - pkg.prov.timestamp)
        fresh = math.exp(-age / self.half_life)
        contam = self.contamination(pkg, deployment_fp)
        raw = (self.w['author'] * a
               + self.w['val'] * pkg.evidence.success_rate
               + self.w['heldout'] * pkg.evidence.heldout_success_rate
               + self.w['fresh'] * fresh
               - self.w['contam'] * contam)
        return max(0.0, min(1.0, raw))

    def root_diversity(self, kid: str) -> float:
        """来源根多样性：单根=0，双根=0.5，根越多越接近 1"""
        roots, seen = set(), set()
        def walk(k: str):
            if k in seen or k not in self.repo:
                return
            seen.add(k)
            parents = self.repo[k].prov.parent_kids
            if not parents:
                roots.add(k)
            for p in parents:
                walk(p)
        walk(kid)
        n = len(roots)
        return 0.0 if n <= 1 else 1.0 - 1.0 / n

    def admit(self, pkg: KnowledgePackage,
              deployment_fp: 'DeploymentFingerprint') -> 'AdmissionDecision':
        sig_ok = verify_signature(pkg.prov.author, pkg)
        lic_ok = self.license_compatible(pkg)
        dep_ok = self.provenance_acyclic(pkg.kid)
        contam = self.contamination(pkg, deployment_fp)
        trust = self.trust(pkg, deployment_fp)
        div = self.root_diversity(pkg.kid)
        ok = (sig_ok and lic_ok and dep_ok
              and contam <= self.contamination_max
              and trust >= self.t_min
              and div >= self.diversity_min)
        return AdmissionDecision(ok, sig_ok, lic_ok, dep_ok,
                                 contam, trust, div)

    def fork(self, kid: str, new_author: str, delta: dict) -> KnowledgePackage:
        parent = self.repo[kid]
        child = replace(parent, kid=f"{kid}@{new_author}-fork",
                        prov=replace(parent.prov, author=new_author,
                                     parent_kids=[kid],
                                     timestamp=time.time()),
                        theta={**parent.theta, **delta},
                        version=bump(parent.version))
        return child

    def merge(self, kids: list[str], strategy: str) -> KnowledgePackage:
        for k in kids:
            self.resolve_dependencies(k)   # 合并前保证各自闭包
        return merge_packages([self.repo[k] for k in kids], strategy)
```

### IP-469 Provenance & License Certificate (PLC)

@dataclass
class ProvenanceLicenseCertificate:
    kid: str
    prov_digest: str
    signature_ok: bool
    license_ok: bool
    deps_ok: bool
    contamination: float
    trust: float

    @classmethod

            kid=pkg.kid,
            prov_digest=sha256(json.dumps(asdict(pkg.prov), sort_keys=True).encode()).hexdigest(),
            signature_ok=d.signature_ok,
            license_ok=d.license_ok,
            deps_ok=d.deps_ok,
            contamination=d.contamination,
            trust=d.trust,
            root_diversity=d.root_diversity,
        )

    def verify(self, repo: OpenKnowledgeEcosystem,
               deployment_fp: 'DeploymentFingerprint',
               policy, t_min: float, contam_max: float, div_min: float) -> bool:
        pkg = repo.repo[self.kid]
        d = repo.admit(pkg, deployment_fp)
        self.signature_ok, self.license_ok = d.signature_ok, d.license_ok
        self.deps_ok = d.deps_ok
        self.contamination, self.trust, self.root_diversity = \
            d.contamination, d.trust, d.root_diversity
        return (d.ok and d.trust >= t_min
                and d.contamination <= contam_max
                and d.root_diversity >= div_min)

### IP-470 Prior-Evidence Calibration (PEC)

```python
@dataclass
class PriorEvidenceCalibration:
    """PEC：让先验随本地证据衰减，并在散度/污染过大时否决先验"""
    kappa: float = 50.0
    lam: float = 1.0
    divergence_max: float = 0.5
    contamination_max: float = 0.2
    beta_floor: float = 0.0

    def beta(self, n_eff: int) -> float:
        return max(self.beta_floor, 1.0 / (1.0 + n_eff / self.kappa))

    def posterior(self, prior: RulePrior, local_loss: Tensor,
                  n_eff: int) -> 'RulePosterior':
        beta = self.beta(n_eff)
        logp = log_softmax(prior.logits, dim=-1) - self.lam * local_loss
        post = softmax(logp, dim=-1)
        return RulePosterior(probs=post, beta=beta, n_eff=n_eff)

    def divergence(self, post: 'RulePosterior', prior: RulePrior) -> float:
        q = post.probs.clamp_min(1e-9)
        p = softmax(prior.logits, dim=-1).clamp_min(1e-9)
        return float((q * (q.log() - p.log())).sum())

    def accept_prior(self, post: 'RulePosterior', prior: RulePrior,
                     contam: float) -> tuple[bool, float]:
        div = self.divergence(post, prior)
        ok = (div <= self.divergence_max
              and contam <= self.contamination_max)
        return ok, div
```

### IP-471 Knowledge Commons MPC (KC-MPC)

```python
@dataclass
class KnowledgeCommonsMPC:
    """KC-MPC：预训练先验 → 来源准入 → 后验加权 → v28 控制器"""
    base: 'KnowledgeTransilientMPC'          # v28 控制器
    kfm: KnowledgeFoundationModel
    ecosystem: OpenKnowledgeEcosystem
    pec: PriorEvidenceCalibration
    deployment_fp: 'DeploymentFingerprint'
    n_local: int = 0

    def propose(self, x: Tensor, task_ctx: dict) -> tuple[list, list]:
        admitted, rejected = [], []
        for c in self.kfm.candidate_kcs(x, task_ctx):
            pkg = self._materialize(c)
            d = self.ecosystem.admit(pkg, self.deployment_fp)
            (admitted if d.ok else rejected).append((pkg, d))
        return admitted, rejected

    def solve(self, x0: Tensor, task_ctx: dict) -> tuple:
        admitted, rejected = self.propose(x0, task_ctx)
        prior = self.kfm.prior(x0, task_ctx)
        local_loss = self._local_rule_loss(x0, admitted)
        post = self.pec.posterior(prior, local_loss, self.n_local)
        contam = max((d.contamination for _, d in admitted), default=0.0)
        prior_ok, div = self.pec.accept_prior(post, prior, contam)
        if not prior_ok:
            admitted = []          # 先验不可信：退化为纯本地 KC
        self.base.kc_list = [self._to_iekc(pkg, w)
                             for pkg, w in self._weight_by_posterior(admitted, post)]
        u, kc, dcc, exp = self.base.solve(x0)
        report = ProposalReport(admitted, rejected, post, div, prior_ok)
        return u, kc, dcc, exp, report

    def _local_rule_loss(self, x: Tensor, admitted: list) -> Tensor:
        """每条候选规则的本地证据损失；无证据时返回中性值"""
        losses = []
        for pkg, _ in admitted:
            trials = self._query_local_trials(pkg)
            losses.append(trials.violation_rate if trials.n > 0 else 0.5)
        return torch.tensor(losses) if losses else torch.zeros(1)

    def _weight_by_posterior(self, admitted: list, post: 'RulePosterior') -> list:
        return [(pkg, float(post.probs[i]))
                for i, (pkg, _) in enumerate(admitted)]

    def _materialize(self, c: 'CandidateKC') -> KnowledgePackage:
        return KnowledgePackage(kid=f"kfm-{c.template}-{short_hash(c.theta)}",
                                phi=c.template, theta=c.theta,
                                precond_src="...", postcond_src="...",
                                evidence=self._empty_evidence(),
                                prov=self._kfm_provenance(),
                                license="Apache-2.0", deps=[], version="0.1.0",
                                signature=sign(self.kfm.theta_version))
```

### IP-472 Open-Commons Cert Gate (OCG)

```python
@dataclass
class OpenCommonsCertificationGate:
    """OCG：KTCG ∪ PLC ∪ PEC 十二证一体"""
    ktcg: 'KnowledgeTransilientCertificationGate'   # v28 九证
    kcmcp: KnowledgeCommonsMPC
    ecosystem: OpenKnowledgeEcosystem
    pec: PriorEvidenceCalibration
    deployment_fp: 'DeploymentFingerprint'
    t_min: float = 0.6
    contam_max: float = 0.2
    div_min: float = 0.3

    def admits(self, plan: 'RobotPlan', sensor_data: dict) -> bool:
        # 1. v28 的九证准入
        if not self.ktcg.admits(plan, sensor_data):
            return False

        # 2. 来源准入：每个进入控制的包必须有有效 PLC
        admitted, _ = self.kcmcp.propose(plan.init_state, plan.task_ctx)
        for pkg, d in admitted:
            plc = ProvenanceLicenseCertificate.issue(pkg, d)
            if not plc.verify(self.ecosystem, self.deployment_fp,
                              self.ecosystem.license_policy,
                              self.t_min, self.contam_max, self.div_min):
                return False

        # 3. 先验准入：散度与污染都必须可控，否则否决先验
        prior = self.kcmcp.kfm.prior(plan.init_state, plan.task_ctx)
        local_loss = self.kcmcp._local_rule_loss(plan.init_state, admitted)
        post = self.pec.posterior(prior, local_loss, self.kcmcp.n_local)
        contam = max((d.contamination for _, d in admitted), default=0.0)
        prior_ok, _ = self.pec.accept_prior(post, prior, contam)
        if not prior_ok:
            return False

        # 4. 来源根多样性：拒绝生态单cultivar
        for pkg, _ in admitted:
            if self.ecosystem.root_diversity(pkg.kid) < self.div_min:
                return False

        return True
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 |
|---|---|---|---|
| KFM 先验推理 | `O(E + N_tpl·d_θ)` | `O(N_tpl·d_θ)` | `N_tpl≤200`, `d_θ≤32` |
| OKEP 依赖解析 | `O(|V|+|E_dep|)` | `O(|V|)` | 包数 `|V|≤10⁴` |
| OKEP 来源/污染评估 | `O(|Dep| + N_hash + N_canary)` | `O(N_hash)` | `N_hash≤10³` |
| PEC 后验与散度 | `O(N_tpl)` | `O(N_tpl)` | `N_tpl≤200` |
| KC-MPC 单步 | `O(KTCG + N_cand·OKEP + N_tpl)` | `O(N_cand + N_tpl)` | `N_cand≤8` |
| OCG 总体 | `O(KTCG + N_cand·(|V|+|E_dep|) + N_tpl)` | `O(|V|+N_tpl)` | 关键路径仍是 KEMPC 求解 |

**实时性**：KFM 先验前向在边缘端（蒸馏后 `N_tpl=200, d_θ=32`）约 1–3ms；依赖解析与污染比对可缓存在包版本变更时增量更新，摊销 `O(1)`；PEC 为 `O(200)` 的向量运算 `<0.5ms`。整体在 v28 的 20ms 预算上增加约 3–5ms，仍满足 50Hz；预训练与全量来源审计放在离线/非实时周期。

## 4. 正确性论证（增量更新）

### 引理 26（先验权重随本地证据单调衰减）

**陈述**：`β(n_eff)=1/(1+n_eff/κ)` 在 `n_eff≥0` 上严格单调递减，`β(0)=1`，且 `lim_{n_eff→∞}β(n_eff)=0`。

**证明**：对 `n_eff` 求导得 `dβ/dn_eff = -1/(κ(1+n_eff/κ)²) < 0`；代入端点即得 `β(0)=1` 与极限为 0。故本地有效样本越多，先验权重越小，本地证据最终占优。∎

**推论**：当 `n_eff ≥ κ(1/β_floor - 1)` 时，`β(n_eff) ≤ β_floor`，先验对控制的影响被压到预设下界以下。

### 引理 27（来源依赖解析的闭包性与无环性）

**陈述**：若 `resolve_dependencies(kid)` 正常返回序列 `order`，则 `order` 恰为 `kid` 的全部祖先闭包的一个拓扑序；若存在依赖环或缺失依赖，则抛出异常而不返回序列。

**证明**：DFS 中状态 1 表示「在栈上」、状态 2 表示「已完成」。访问到状态 1 的节点即构成回边，必存在环，故抛 `ValueError`；访问到不在 `repo` 的依赖抛 `KeyError`。每个节点仅在状态 2 时入 `order`，且所有依赖先于其入列，故 `order` 为拓扑序；递归覆盖的节点集合正是从 `kid` 可达的祖先闭包。∎

### 引理 28（污染分的可检测性）

**陈述**：若 `corpus_overlap, audit_gap, canary_leak_rate ∈ [0,1]`，则 `C_contam ∈ [0,1]`；特别地，当留出验证与拟合集来源独立时，`C_contam ≥ audit_gap` 且 `audit_gap` 直接量化了「表面验证率虚高」的下界。

**证明**：`C_contam` 取三个 `[0,1]` 量的最大值，故仍在 `[0,1]`。`audit_gap = max(0, success_rate - heldout_success_rate)`，当留出集与拟合集独立时，`heldout_success_rate` 是真实泛化率的无偏估计，故差值即表面验证率相对真实泛化率的高估量，`C_contam` 不小于该高估量。∎

### 定理（OCG 的来源-先验联合可靠性）

**陈述**：对任意机器人计划 `Π`，若 `OCG.admits(Π)=True`，则每一个影响控制的 KC 要么是本地证书认证的规则，要么是满足以下全部条件的来源包：签名有效、许可证兼容、依赖闭包且无环、`C_contam ≤ ε`、`T(K) ≥ τ_min`、来源根多样性 `≥ d_min`；同时所用先验满足 `Δ_pe ≤ δ` 且污染 `≤ ε`。

**证明**：`OCG.admits` 首先要求 `KTCG.admits=True`，由 v28 定理保证所有规则满足结构/语义/动力学/可解释性/迁移/自适应/知识库一致性。随后对每个 `admitted` 包签发并验证 PLC，PLC 的 `verify` 以 `OKEP.admit` 的六项合取为返回条件，故签名、许可证、依赖、污染、信任五项均成立；OCG 又单独检查 `root_diversity ≥ d_min`。最后 PEC 的 `accept_prior` 要求散度与污染均不超阈值。以上均为合取，任一失败即返回 `False`，故结论成立。∎

### 命题（生态单cultivar 的准入阻断）

**陈述**：若所有候选包共享同一个来源根，则对任意 `kid` 有 `root_diversity(kid)=0 < d_min`（`d_min>0`），OCG 必拒绝。

**证明**：`root_diversity` 在根集合大小 `n≤1` 时返回 0；`d_min>0` 时 `0<d_min`，OCG 的根多样性检查失败并返回 `False`。∎

## 5. 实验设计（预期结果标注为待验证）

### E1 开源供应链攻击下的准入

- 构建 `|V|=500` 的 KC 仓库；注入 10% 投毒包（`postcond` 过于宽松）、5% 过期 fork、5% 许可证不兼容包、5% 依赖环包。
- 对比：无闸门 / 仅签名校验 / v28 KTCG / OCG。
- 指标：投毒包误纳率、正常包误拒率、单步准入延迟。

| 方案 | 误纳率（预期） | 误拒率（预期） | 延迟（预期） |
|---|---|---|---|
| 仅签名 | ~10% | ~0% | <1ms |
| v28 KTCG | ~6% | ~2% | 20ms |
| OCG（本轮） | **<1%** | **<3%** | 23–25ms |

### E2 预训练先验锁定 vs 校准

- 在仿真语料 A/B/C 上预训练 KFM，目标机器人为 D（分布偏移）。
- 对比固定 `β∈{0.1,0.5,1.0}` 与 `β(n_eff)` 校准；指标：成功率、违规率、达到 90% 成功率所需本地样本数、ECE。
- 预期：固定大 β 在前期快但后期卡在次优；`β(n_eff)` 在 `n_eff` 增大后更快摆脱先验锁定，最终违规率降低 30% 以上。

### E3 语料污染的自证循环检测

- 将目标部署数据以比例 `ε∈{0,0.01,0.05,0.1}` 注入预训练语料；同时让验证证据来自同一数据源。
- 测量表面验证率虚高 `audit_gap`、`C_contam` 的检测 AUC，以及 OCG 的拒绝率。
- 预期：`ε` 上升时表面验证率趋近 1 而留出验证率下降；`C_contam` 随之上升，OCG 在 `ε≥0.05` 时拒绝率显著上升，从而阻断自证循环。

### E4 消融与多样性

- 逐项移除 PLC / PEC / 根多样性检查，观察误纳率与相关性故障率。
- 预期：移除根多样性检查后，在「上游共同祖先被投毒」场景下相关性故障率显著上升，验证 `d_min` 的必要性。

## 7. 本轮最大风险（最终确认）

**一句话**：**预训练语料与开源验证证据的共谋性污染（自证循环）**——当 KFM 的预训练语料已混入目标部署数据、而社区知识包的验证证据又来自同一数据源时，表面验证率会异常漂亮地通过 PLC 与 PEC 的全部检查；系统把「记忆/泄漏」误当「泛化」，在真正的新场景到来前证书层面几乎无异常，是比供应链投毒与先验锁定更隐蔽、更致命的系统性风险。
