### 第 6 轮灵感驱动研究记录

**灵感词**：人机协作、可用性评估

**继承关系**：第 5 轮 CADVS-v5（IP-493~496, CGE）把提议升级为条件流匹配、记忆升级为固化闭环、人因升级为面部情感调制，并用定理 5–8 守住「提议可换、门不可换」。但 v5 把人类降格为两个窄角色：情感传感器（FAMK）与离线抽检员（LMEM 固化的标签来源）。这留下两个结构性空洞：(a) 人类从未进入**在线授权回路**——机器独自决定执行，人类只能事后审计；(b) v5 最大风险 R57（固化自指博弈）唯一的外部真值正是「人工抽检」，而抽检质量本身从未被建模、测量或约束。两个灵感词恰好是同一个空洞的两面：**人机协作**要求把人类提升为证书的共同签发者与不确定性仲裁者；**可用性评估**要求把「人类能否有效监督」从 UX 事后问卷变成安全论证的一等输入。本轮不新增物理硬门（延续 R52 自律），而是在七门之上加一个**协作监督层**（Oversight Layer, OVL），形成 CADVS-v6 / UACC（Usability-Aware Collaborative Certification，可用性感知的协作认证），执行集继续收缩 Exec_v6 ⊆ Exec_v5 ⊆ …。

**直觉（先讲人话）**：

把 v5 想成一辆「自我认证」的自动驾驶：它能证明自己不会撞墙（七门），但它做决定时从不问乘客，只在月底抽查行车记录。问题有二：(1) 遇到它自己也没把握的岔路，最该问人的时候它不问；(2) 它把「人抽查过的片段」拿去学习，可人若在疲劳、信息过载或被漂亮的「已认证」绿灯麻痹时乱点，学到的就是噪声甚至错误的自信。

v6 的直觉只有两条：

- **人类是「收紧器 + 仲裁器」，不是「豁免器」**：人只能在机器已认证的候选里挑、能否决、能补充**消歧信息**，但永远不能按一个按钮让不合物理硬门的轨迹执行。于是「人类介入」在结构上只会让系统更保守，不会制造 v5 没有的新物理风险。这条设计等价于把 v5 定理 5 的「情感只紧不松」推广为「**人类只紧不松**」。
- **可用性是安全的一部分，不是装饰**：如果人因为界面太糟、太忙或太信任机器而实际抓不住错误，那么「有人在环」就是一句空话。因此 v6 把「监督捕获率」当成与 ξ_wrench、ZMP 同级的**可测量量**，并且**只在可用性证书有效时才允许把人类监督折算成安全信用**；证书失效就诚实地退回全自主保守模式，而不是继续假装有人兜底。

**严谨定义（后讲形式）**：

1. **人类动作空间** A_h = {select(i) : i ∈ Certified, veto, supply_context(c′)}。其中 select/veto 只在认证集内操作，不改变物理可行性；supply_context 被限制在「已审计的传感器假设消歧」闭集内，不得改写质量/摩擦/几何等被七门消费的真值。故人类是**单调收紧算子**：Authorized_v6 ⊆ Certified_v5。
2. **决策临界度** κ_crit(x*,C) 复合三件事：top-1/top-2 证书边际间隙、绑定门的边界邻近度、流新颖度 n_flow。κ_crit > κ_h 触发交接（handoff）——这是「该问人的时候问人」的形式化。
3. **监督带宽**：交接到达率 λ_h、人类服务率 μ_h、利用率 ρ = λ_h/μ_h，监督带宽 B_h = ρ_max·μ_h。λ_h > μ_h 时队列发散、T_dec 超时概率 → 1（定理 11），故必须设带宽调节器，过载即降级。
4. **监督捕获率** R_h = P(veto | machine wrong)，用信号检测论（SDT）的灵敏度 d′ 与判据 c_sdt 估计；负载升高 ⇒ d′↓、c_sdt↑（更宽松）⇒ R_h↓（引理 45）。这把「疲劳导致橡皮图章」写成了可计算的关系。
5. **可用性证书** UC = (L_cog, d′, c_sdt, T_dec^{P99}, 解释保真度 f_exp, 覆盖度 cov, 有效期 TTL, 来源 prov, DP-ε)。仅在全部达标时有效；UC 是**对安全信用的元证书**，不是对轨迹的物理硬门。
6. **安全信用核算**：Realized_violation ≤ p_m·(1 − R_h·1[UC valid])；UC 失效则强制把 R_h 记为 0（定理 10）。Claimed 与 Realized 的差必须由影子红队定期校准，禁止「账本自我背书」。
7. **三种授权模式**：AUTO（高边际、低临界度、UC 有效 → 不打扰人）/ CO-SIGN（交接，人在认证集内选或否决）/ CONSERVATIVE（带宽耗尽或 UC 失效 → γ_fb ≥ 1 收紧阈值、降速、延后交接并记账）。

**关键洞见**：v4 回答「规则提议下七门够不够」；v5 回答「任意生成器下证书边界能否不变」；v6 回答「当人类是回路一员、且其监督能力本身会失效时，安全论证如何保持诚实」。v6 的理论主轴不是「再加一个门」，而是**把安全边界（七门，物理可行性）与安全信用（人类监督折算，认知可行性）分离**：前者是轨迹上的固定谓词，后者是可测量、可失效、可审计的证书。这个分离让我们既能利用人类监督，又不会在监督失效时凭空产生虚假安全。

**形式化目标（增量）**：

1. **COPK（协作监督核）**：临界度评估、交接调度、认证集内选择/否决、上下文消歧（审计闭集）、保守退化。
2. **UCORE（可用性证书与监督可靠性估计）**：SDT 在线捕获率、负载–判据曲线、带宽调节器、UC 有效期与来源、有限样本置信界。
3. **CABI（反自动化偏差界面）**：最小充分解释、绑定门高亮、反事实展示、解释保真度校验、认知强制（偶发要求说明理由）。
4. **审计置信加权固化**：样本权重 w_i = R̂_h(load_i)·1[UC valid_i]；加权 LMEM-v2 固化损失，KL 上界按 mean(w) 缩放；w̄ < w_min 则冻结固化（正面偿还 R57）。
5. **定理 9（协作不扩张/人类不可豁免）、定理 10（安全信用核算与可用性依赖）、定理 11（监督带宽守恒与过载退化）、定理 12（可用性不可自证/独立评估）**；引理 45（SDT 负载单调）、引理 46（捕获率有限样本界）、引理 47（解释保真度与上下文投毒界）。
6. **上下文索引的执行集嵌套**：∀c，Exec_v6(c) ⊆ Exec_v5(c) ⊆ …；任何实际执行的轨迹都必须在其**实际生效上下文**下通过冻结七门。

**本轮最大风险**：**监督剧场（oversight theater）**——系统按「有人监督」折算安全信用，但在过载、自动化偏差、解释失真下人的真实捕获率趋近于零，于是声称的安全是虚构的；又因人类只能收紧不能豁免，它不会制造 v5 之外的新物理伤害，却会污染安全账本与固化标签，让系统「自洽地高估自己更安全」。

### IP-497 COPK：协作监督核（授权时域，异步；不进入 1 kHz 环）

```python
@dataclass
class CollaborativeOversightProtocolKernel:
    """COPK：人类只能在认证集内选择/否决/消歧。
    定理 9：人类是不可豁免硬门的单调收紧算子。"""
    kappa_h: float = 0.6
    margin_ref: float = 0.25

    def criticality(self, cands: list[Trajectory], diag: list[Diagnostic]) -> float:
        # 复合：top1/top2 边际间隙 + 绑定门边界邻近 + 流新颖度
        m = sorted((d.certified_margin for d in diag), reverse=True)
        gap = (m[0] - m[1]) / self.margin_ref if len(m) > 1 else 1.0
        boundary = max(d.boundary_proximity for d in diag)   # ∈[0,1]
        novelty = max(d.n_flow / TAU_NOVEL for d in diag)
        return clip(1.0 - 0.5 * gap + 0.3 * boundary + 0.2 * novelty, 0.0, 1.0)

    def request_handoff(self, cands, uc, budget) -> Handoff | None:
        # 带宽调节器：拿不到令牌就返回 None → 上层进入 CONSERVATIVE
        if not budget.try_acquire():
            return None
        return Handoff(candidates=cands,
                       explanation=cabi.explain(cands),   # 最小充分解释
                       deadline_s=T_MAX)

    def apply_human_action(self, act: HumanAction, certified) -> list[Trajectory]:
        # 关键红线：任何分支都只在 certified 内取子集，绝不新增轨迹
        if act.kind == "veto":
            return [x for x in certified if x.id != act.target]
        if act.kind == "select":
            return [x for x in certified if x.id == act.target]
        if act.kind == "supply_context":
            # 仅允许消歧已审计传感器假设；需独立传感器佐证，否则只影响排序
            return self._recertify_by_disambiguation(certified, act.ctx)
        return list(certified)
```

### IP-498 UCORE：可用性证书与监督可靠性估计（在线流式 + 周期出证）

```python
@dataclass
class UsabilityOversightReliabilityEstimator:
    """UCORE：把「人到底能不能抓住错误」变成可测量、可失效的证书。
    定理 10：UC 失效 ⇒ 人类安全信用强制置零；定理 12：不可自证。"""
    d_min: float = 2.0
    f_min: float = 0.95
    rho_max: float = 0.7
    ttl_s: float = 1800.0
    n_min: int = 30

    def update_from_episode(self, tel: Telemetry) -> None:
        # 记录 T_dec、交互轨迹、注入错误的命中/虚警（影子模式，操作员不知注入点）
        self._sdt.update(hit=tel.vetoed_injected_bad, fa=tel.vetoed_good)
        self._load.update(tel.tlx, tel.dual_task_err, tel.face_proxy)  # face 仅作代理

    def catch_rate(self, load: float) -> tuple[float, float]:
        # R̂_h 与有限样本半宽（引理 46：Hoeffding/Clopper–Pearson）
        r = self._sdt.hit_rate_conditioned(load)
        half = sqrt(log(2.0 / self.delta) / (2.0 * max(self._sdt.n(load), 1)))
        return r, half

    def certificate(self, load: float) -> UsabilityCertificate | None:
        dprime, c_sdt = self._sdt.estimate()
        t_p99 = self._dec.p99()
        if (dprime >= self.d_min and self._fid >= self.f_min
                and t_p99 <= T_MAX and self._cov >= COV_MIN
                and self._n >= self.n_min and load <= LOAD_MAX):
            return UsabilityCertificate(load, dprime, c_sdt, t_p99,
                                        self._fid, self._cov, self._now + self.ttl_s,
                                        prov="independent_shadow_redteam", dp_eps=DP_EPS)
        return None                       # 不达标 = 不出证 = 不折算人类信用

    def governor(self, lam_h: float, mu_h: float, uc) -> Mode:
        if uc is None:
            return Mode.CONSERVATIVE
        return Mode.CONSERVATIVE if lam_h > self.rho_max * mu_h else Mode.AUTO

    def safety_credit(self, uc, load) -> float:
        # 定理 10：只有 UC 有效且未过期才计入；否则为 0
        if uc is None or self._now > uc.ttl_s:
            return 0.0
        r_hat, half = self.catch_rate(load)
        return max(0.0, r_hat - half)     # 保守下界，防止过claim
```

### IP-499 CABI：反自动化偏差界面（解释与认知强制）

```python
@dataclass
class CounterAutomationBiasInterface:
    """CABI：降低自动化偏差与橡皮图章。
    原则：最小充分解释 + 反事实 + 偶发认知强制；解释保真度可审计。"""
    f_min: float = 0.95

    def explain(self, cands: list[Trajectory]) -> Explanation:
        # 只展示「绑定门 + 关键边际 + 一个反事实」，避免信息过载
        binding = argmin_over_gates(cands)          # 最紧的硬门
        cf = counterfactual(cands[0], binding)       # 「若 X 再差 ε 就会失败」
        return Explanation(binding_gate=binding.name,
                           margin=cands[0].certified_margin,
                           alternatives=[(c.id, c.certified_margin) for c in cands],
                           counterfactual=cf)

    def fidelity_check(self, shown: Explanation, internal: Diagnostic) -> float:
        # 显示的绑定门/边际是否与内部真值一致（R63 的守门）
        return float(shown.binding_gate == internal.binding_gate
                     and abs(shown.margin - internal.margin) <= MARGIN_TOL)

    def force_justification(self, act: HumanAction, rng) -> bool:
        # 认知强制：以概率 p_force 要求说明理由，打断「看到绿灯就点」
        return rng.random() < self.p_force
    # 无障碍与跨文化：解释文案多语言/低识字版本；不做人脸情绪推断以外的主体建模
```

### IP-500 EFA-v6：七门冻结 + 协作授权 + 审计置信加权固化

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：物理认证沿用 v5（冻结），协作层只收紧不扩张。"""
    v5: EvidenceForgingAssemblerV5
    copk: CollaborativeOversightProtocolKernel
    ucore: UsabilityOversightReliabilityEstimator
    cabi: CounterAutomationBiasInterface
    budget: HandoffBudget

    def select(self, x0_state, t_now, rule_id, context) -> Decision:
        certified = self.v5.select_certified(x0_state, t_now, rule_id, context)
        if not certified:                                   # Exec_v5 已空
            return Decision.reject("NO_CERTIFIED")

        load = self.ucore.estimate_load(context)
        uc = self.ucore.certificate(load)
        kappa = self.copk.criticality(certified.cands, certified.diag)
        mode = self.ucore.governor(self.budget.arrival_rate, self.budget.mu, uc)

        if mode == Mode.AUTO and kappa <= self.copk.kappa_h and uc is not None:
            return Decision.execute(max(certified.cands, key=certified_margin),
                                    mode="AUTO", credit=self.ucore.safety_credit(uc, load))

        if mode != Mode.CONSERVATIVE:
            h = self.copk.request_handoff(certified.cands, uc, self.budget)
            if h is not None:
                act = self.human.respond(h)             # 人只能 select/veto/消歧
                allowed = self.copk.apply_human_action(act, certified.cands)
                if allowed:
                    return Decision.execute(max(allowed, key=certified_margin),
                                            mode="CO-SIGN",
                                            credit=self.ucore.safety_credit(uc, load))

        # CONSERVATIVE：带宽耗尽 / UC 失效 / 交接超时 → 收紧 + 降速 + 延后记账
        gamma_fb = self._fallback_gamma(load)               # ≥ 1，只紧不松
        tightened = self.v5.recertify_with(certified, gamma_fb)
        if not tightened:
            return Decision.reject("CONSERVATIVE_NO_SAFE")
        self.budget.defer_review(certified)                 # 延后人工复核，不丢弃
        return Decision.execute(max(tightened, key=certified_margin),
                                mode="CONSERVATIVE", credit=0.0)

    def _fallback_gamma(self, load: float) -> float:
        # 负载越高越保守；有界，保证执行集不塌缩为真空
        return 1.0 + KAPPA_FB * clip(load / LOAD_MAX, 0.0, 1.0)
```

```python
def consolidate_audit_weighted(lmem, episodes, uc_history, w_min=0.3):
    """只有「铸证 ∧ 结局验证成功 ∧ 人工抽检」片段可入池；再乘监督置信权重。
    w_i = R̂_h(load_i) * 1[UC_i valid]；w̄ < w_min 直接冻结，避免噪声自证。"""
    certified = [ep for ep in episodes if ep.forged and ep.outcome_ok and ep.human_audit]
    w = [uc_history.catch_lower(ep.t) * uc_history.valid(ep.t) for ep in certified]
    if not w or mean(w) < w_min:
        return "FROZEN_LOW_OVERSIGHT_CONFIDENCE"      # 不学习，而非学错
    loss = sum(wi * ep.loss for wi, ep in zip(w, certified)) / sum(w)
    loss += KL_EPS * mean(w) * KL(pi_new, pi_old)      # KL 上界随置信缩放
    lmem.fmpp.update_dp_sgd(loss, dp_eps=DP_EPS)        # 门与 τ^4 冻结只读
    return "CONSOLIDATED"
```
