# 第 69 轮（承接第 68 轮「CALM-RAS 标定感知风险自适应闭环」IP-243~252；灵感循环第 1 轮；本轮灵感：「微调」×「应用落地」）

> 第 68 轮把「测量可信度」请进了闭环，却默认了一件在部署现实里从不成立的事：**被认证的那个模型，就是跑在机器上的那个模型**。真实落地中，每个现场、每个客户、每次域偏移都会对基座做一次微调；证书是对快照签发的，而微调在出厂的第一秒就让它过期。R65–R68 的安全定理（引理 13、定理 14/15）都只对「认证时刻的 θ」成立，对微调后的 θ′ 无话可说——这是贯穿前四轮的元失败：**安全被当作工件（artifact）属性，而非过程（process）属性**。
>
> 本轮灵感给出两把钥匙：「微调」逼我们直面「参数变了，安全还在不在」；「应用落地」逼我们直面「异构舰队 + 边缘算力 + 无标签 + 隐私」的约束。核心命题：
>
> **把微调从安全的「后门」改造为安全的一等公民——用「冻结安全内核」保证安全不可遗忘，用「安全零空间微调」保证一阶安全行为不变，用「舰队差分审计」提供单机标定在信息上无法吸收的外部参照（正面攻击 R68「缓变故障被标好」的原罪），用「安全商等价检验 + 部署包络回退」保证部署出去的每个实例都可追溯、可回退——SAFE-FT（Safety-Anchored, Frozen-kernel, Envelope-certified Fine-Tuning）。**
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「**部署、微调之后，我还是同一个安全的我吗**」——安全必须可组合地穿过「出厂 → 现场 → 微调 → 再部署」这条链路。

## 0. 直觉与动机

**灵感 1（应用落地 → 证书的「最后一公里」失真）**
直觉：实验室里的 J_CALM 是对一个快照签名；落地时模型被装进边缘盒子，现场数据每天在变，运维一定会点「微调 / 自适应」。于是「证书上的 θ」与「机器上的 θ′」分叉，而这条分叉没有任何定理覆盖。类比软件发布：构建产物有签名，但运行时的热补丁若不受控，签名就名存实亡。落地安全的第一性问题不是「模型多准」，而是「**认证对象是否覆盖实际运行对象**」——安全必须从「给模型盖章」变成「给流程背书」。

**灵感 2（微调 → 安全遗忘是默认结局，不是意外）**
直觉：微调天然朝「当前现场任务损失」下降，凡是不出现在微调数据里的能力都会被灾难性遗忘——而安全行为（红线、反吸收、保守回退）恰恰是低频、长尾、通常不产生梯度的事件。指望「多训一点就学会安全」缘木求鱼。正确做法不是让安全「重新学」，而是让安全「**学不掉**」：把安全闸冻结成独立信任域（FZK），微调只能作用于任务壳，且更新被投影到安全行为的零空间（SNAP）——**安全不是微调的目标，而是微调的边界条件**。

**灵感 3（落地即舰队 → 单机自一致之外，还有互一致这个免费参照）**
直觉：这是本轮最关键的洞见，也直接回应 R68 的自陈风险。R68 的标定之所以能「把慢故障标好」，是因为单机只有一个自我参照：慢残差到底是漂移还是退化，单机在信息上不可分（两者都落在标定通带内）。但落地意味着**许多台机器同时在看同一个世界**：若某残差在所有站点同步增长，那是环境 / 老化（可标定）；若只有某一台增长，那是这台机器的个体退化（故障，禁止吸收）；若某一批次同步增长，那是供应链缺陷（召回而非标定）。**舰队把「单机不可分的二分」升级为「共模 / 队列 / 个体三分」，提供了标定在信息上无法吸收的外部参照系**——标定只能吸收「所有实例都同意」的成分，个体故障因跨实例不一致而天然逃逸标定。

**灵感 4（微调 × 落地的合流 → SAFE-FT 六组件）**
1. **FZK 冻结安全内核**：λ_floor / 红线 / canary / 反吸收界做成只读独立信任域，微调写不进去；
2. **SNAP 安全零空间微调**：δθ⊥ = (I − J_safe⁺J_safe)·δθ，一阶保证 J_safe·δθ⊥ = 0，LoRA 低秩使投影可解；
3. **ANC 锚定微调**：KL(π_θ‖π_base) + 物理不变量真值锚 + 置信门，防自训练「近亲繁殖」与身份漂移；
4. **FDA 舰队差分审计**：隐私保护地把残差分解为共模 / 队列 / 个体，个体成分触发故障而非标定；
5. **EQT 安全商等价检验**：允许任务性能差异、禁止安全决策差异，超差即拒；
6. **DEP 部署包络与回退**：运行期监测适配器是否滑出认证包络，滑出即回退基座或 FZK-only 安全模式。
**CALM-RAS† 继承核**：MTM / SSG / COF / CFA / CAC 全部保留，SAFE-FT 是套在它们外面的「部署-微调安全壳」。

**灵感 5（对 R68 风险的正面对症）**
- R68「缓变个体故障被标好」：FDA 的个体成分再慢也不可被标定吸收（它跨实例不一致）——这是对引理 13 的**补集**：引理 13 挡「快故障」，FDA 挡「慢但个体」的故障；
- R68「标定能力越强、故障越隐形」：标定被 FZK 显式限定为「只能吸收共模成分」，结构性地剥夺了它在个体维上的吸收能力；
- 落地「微调毁安全」：FZK + SNAP + EQT 三道闸，安全不可学掉；
- 落地「自训练中毒 / 近亲繁殖」：ANC 的外部真值锚与 KL 锚。

## 1. 形式化定义（增量：定义 293–306）

**定义 293（SAFE-FT 总览）** SAFE-FT = (FZK, SNAP, ANC, FDA, EQT, DEP, CALM-RAS†)。三不变式：
(i) **安全不可微调**：FZK 参数在部署期只读，任何 fine-tuning 更新不得写入 FZK（内存 / 信任域隔离）；
(ii) **微调必须零空间且等价**：SNAP 保证一阶安全行为不变，EQT 保证高阶 / 全局安全商等价，二者缺一不可提交；
(iii) **参照系外置**：单实例自一致不再作为漂移/故障唯一判据，跨实例互一致（FDA）提供不可被单机标定吸收的参照。

**定义 294（安全决策函数与安全商）** 安全决策函数 Q_safe: Θ × 𝒳 → 𝒴_safe，
Q_safe(θ, x) = (risk_order(θ,x), 1[λ < λ_floor], k*_RAS(θ,x), redline(θ,x), attribution(θ,x))。
任务无关的连续变化被商掉，得到**安全商** 𝒬 = 𝒴_safe / ≈_task。安全的载体是 Q_safe 诱导的**决策**，不是参数 θ 本身。

**定义 295（安全商行为等价）** 对微调增量 δθ，定义 θ ≃_ε θ′ ⇔ sup_{x∈𝒳_safe} d(Q_safe(θ,x), Q_safe(θ′,x)) ≤ ε，且**方向单调**：若 Q_safe(θ,x) 判为保守，则 Q_safe(θ′,x) 不得判为更宽松（只准收紧、不准放宽）。后者是比点值一致更强的「安全偏序保持」条件。

**定义 296（FZK 冻结安全内核）** FZK = (G_risk, G_red, G_canary, G_absorb, G_dir)：
G_risk 实现 λ_floor（定义 285）；G_red 实现标定红线（定义 276-ii）；G_canary 实现 canary 不可修复性（定义 287-5）；G_absorb 实现反吸收界（引理 13）；G_dir 实现定义 295 的方向单调。
θ_F 部署期不可写，运行于独立信任域（enclave / 只读 ROM / 独立进程 + 度量启动）。FZK 是「最后一道闸」：即使任务壳被投毒，风险仍被压到最保守档。

**定义 297（安全零空间微调 SNAP）** 令 J_safe(θ) = ∂Q_safe/∂θ ∈ ℝ^{m×n}，在安全 canary 集 D_canary 上求行为雅可比。微调更新投影为
δθ⊥ = (I − J_safe⁺ J_safe)·δθ_task，J_safe⁺ = J_safeᵀ(J_safe J_safeᵀ)⁻¹。
性质：J_safe·δθ⊥ = 0（一阶安全行为严格不变）。LoRA（r=8）把投影限制在低秩子空间内可解。安全预算 B_safe：若 ‖J_safe⁺J_safe·δθ_task‖ > B_safe，则该步拒绝并停止微调（预算耗尽 → 进 DEP 降级）。

**定义 298（锚定微调 ANC）** L_FT = L_task(θ) + β·KL(π_θ ‖ π_base) + γ·L_anchor + λ_s·‖J_safe·δθ‖²。
L_anchor 为「外部真值锚」：少量通用金标 + 物理不变量（重力方向、静态力为零、视觉-触觉几何环一致、时间因果序），给自训练一个不随部署数据腐烂的参照。β = β₀·(1 + KL(P_deploy ‖ P_base)/τ_drift)：分布漂移越大，锚越强，防「近亲繁殖」（模型在自己的伪标签上自我强化而崩）。

**定义 299（舰队残差分解 FDA）** 每个部署 i 只上报隐私保护的残差充分统计量 m_i = (μ_i, Σ_i) 与去标识化元数据（批次、环境、传感器型号）。中心 / 联邦侧做稳健分解：
r_i(t) = d(t)〔共模〕 + b_{c(i)}(t)〔队列偏移〕 + f_i(t)〔个体〕 + ε_i。
判据：‖d‖ 增长且跨站一致 → 环境 / 老化漂移（可标定吸收）；‖b‖ 增长（同批次一致）→ 供应链 / 批次缺陷（召回或整批重标定）；‖f_i‖ 增长（单站特异）→ 真故障（**禁止吸收**，交 CFA/EQT 处理）。
这一步把 R68 的「单实例内漂移 vs 故障不可分」升级为「跨实例三分可辨识」。

**定义 300（时域不可辨识 vs 空域可辨识）** 对频率 ω ≤ ω_cal 的慢残差，单实例的漂移与故障都落在标定通带内，时序数据下二者不可辨识（Fisher 信息在 drift/fault 拆分方向上退化）。若个体故障在舰队上稀疏（任意时刻故障站点数 s < N/2）且共模分量低秩 / 平滑，则横截面分解 (d, b, f) 在 incoherence / spark 条件下可辨识。**慢故障在时域不可分，却在空域可分**——这是舰队作为外部参照的严格依据。

**定义 301（安全商等价检验 EQT）** 提交适配器 δθ 前，在分层 canary 集 D_eq（覆盖红线、λ_floor、反吸收、情绪欺骗、缓变个体故障）上计算
d_eq = sup_{x∈D_eq} d(Q_safe(θ,x), Q_safe(θ⊕δθ,x))。
PASS ⇔ d_eq ≤ ε_eq ∧ 无方向反转。允许任务性能变化，禁止安全决策变化——这正是「商」的精神。

**定义 302（部署包络与回退 DEP）** 每实例携带适配器哈希 h(δθ) 与包络 ℬ = {δθ : d_eq ≤ ε_eq ∧ ‖δθ‖_F ≤ B_max}。运行期用轻量行为指纹（Q_safe 抽查 + 输入漂移统计）监测实例是否滑出 ℬ；滑出 → 先回退基座（base）；仍失配 → FZK-only 安全模式（只保安全闸、任务退化为保守基线）；并发起远程证明审计。

**定义 303（证书组合 J_FT）** J_FT = (J_CALM, base_hash, adapter_hash, ‖δθ⊥‖, d_eq, fleet_audit_verdict, cohort_id, dep_envelope_hash, ftver)。
Valid ⇔ Valid(J_CALM) ∧ d_eq ≤ ε_eq ∧ fleet_audit = CONSISTENT ∧ 未出包络。证书具**组合性**：部署实例证书 = 基座证书 + 适配器增量证书；任一环失效都必须可检测（回退），杜绝「签名对快照有效、运行体已非签名体」。

**定义 304（微调-部署风险界）** 端到端风险 = 基座风险（定理 14） + O(‖δθ⊥‖²)（安全流形曲率） + α_eq（等价检验漏检） + α_fleet（舰队审计漏检） + α_dep（回退失败）。见定理 16。

**定义 305（AIC-FT 干扰集）** ℰ_FT = ℰ_CALM × ℰ_ft × ℰ_fleet × ℰ_dep；
ℰ_ft = {安全遗忘、近亲繁殖、零空间逃逸、锚失效、预算被耗尽}；
ℰ_fleet = {共模故障、批次缺陷、舰队投毒、隐私推断、站点不可比}；
ℰ_dep = {包络逃逸、回退失败、证明伪造、回滚竞态}。

**定义 306（部署即过程认证）** 认证对象从「快照模型」转为「微调-部署过程」：Cert(Π)，Π = (base, fine-tuning protocol, EQT, FDA, DEP)。任一时刻运行实例必须满足「可追溯 + 可回退 + 安全商不变」——这是相对 R68「给工件盖章」的范式转移。

# IP-253 FZK：冻结安全内核（只读独立信任域）
class FrozenSafetyKernel:
    def __init__(self, params):            # params 在 ROM/enclave，部署期不可写
        self.theta_F = freeze(params)

    def gate(self, x, candidate):          # candidate = 任务壳输出 (lam, k, U, ...)
        lam = max(candidate.lam, lam_floor(candidate.U))   # R68 纪律
        lam = max(lam, self.redline_risk(x))                # 红线不可越
        k   = min(candidate.k, self.absorb_bound(x))        # 反吸收界
        if self.canary_violated(x): return SAFE_ONLY        # 最后一道闸
        return self.direction_monotone(lam, k)              # 只准收紧


# IP-254 SNAP：安全零空间微调
def safety_nullspace_step(theta, grad_task, D_canary, B_safe):
    J = jacobian(lambda t: Q_safe(t, D_canary), theta)      # m×n（可离线预计算）
    delta_perp = grad_task - J.T @ solve(J @ J.T + 1e-8*np.eye(len(J)), J @ grad_task)
    assert np.linalg.norm(J @ delta_perp) < 1e-6            # 一阶不变（引理 16）
    if np.linalg.norm(J @ grad_task) > B_safe:              # 安全预算耗尽
        return None, 'SAFETY_BUDGET_EXHAUSTED'
    return delta_perp, 'OK'


# IP-255 ANC：锚定微调（防近亲繁殖 / 身份漂移）
def anchored_finetune(M, deploy_stream, D_anchor, base, D_canary):
    for batch in deploy_stream:                             # 现场无标签数据
        pseudo = M.pseudo_label(batch)
        g = confidence_gate(pseudo)                         # 低置信伪标签丢弃
        loss = task_loss(M, batch, g) \
             + adaptive_beta(M, base, batch) * KL(M(batch) || base(batch)) \
             + GAMMA * anchor_loss(M, D_anchor)             # 物理不变量真值锚
        delta, status = safety_nullspace_step(M.theta, grad(loss), D_canary, B_SAFE)
        if status != 'OK': break                            # 预算耗尽 → 停
        M.update(delta)


# IP-256 FDA：舰队差分审计（隐私保护，只交换充分统计量）
def fleet_differential_audit(reports, cohort):
    R = np.array([r.mu for r in reports])                   # 各站残差均值
    d = robust_mean(R)                                      # 共模
    b = group_mean(R - d, cohort)                           # 队列偏移
    f = R - d - b                                           # 个体
    verdict = {i: classify(f[i], reports[i].sigma, TAU_INDIV) for i in range(len(R))}
    # classify ∈ {COMMON_DRIFT(可标定), COHORT_DEFECT(召回), INDIVIDUAL_FAULT(禁止吸收)}
    return d, b, f, verdict


# IP-257 EQT：安全商等价检验
def equivalence_test(base, adapted, D_eq, eps_eq):
    d_eq = max(safe_distance(Q_safe(base, x), Q_safe(adapted, x)) for x in D_eq)
    reversal = any(relaxes(base, adapted, x) for x in D_eq)  # 只准更保守
    return ('PASS' if (d_eq <= eps_eq and not reversal) else 'REJECT'), d_eq


# IP-258 DEP：部署包络 + 回退
class DeploymentEnvelope:
    def monitor(self, instance, base, fzk):
        fp = behavior_fingerprint(instance)                  # Q_safe 抽查
        if fp.out_of(instance.envelope_hash):
            instance = rollback(instance, base)              # 先回基座
            if still_out(instance):
                instance = fzk.safe_only_mode()              # 再退到只保安全闸
                remote_attest(instance)                      # 发起审计
        return instance


# IP-262 部署-微调主循环
def SAFE_FT_deploy_round(instance, obs, deploy_stream):
    # 1) 在线表面任务：CALM-RAS 闭环继承
    k, lam, joint, cal = CALM_RAS_round(instance.M, obs)
    # 2) FZK 兜底闸（安全不可微调）
    lam, k = instance.fzk.gate(obs, (lam, k, cal))
    # 3) 影子微调（现场无标签流，SNAP 投影 + ANC 锚）
    delta, status = instance.anc.step(deploy_stream, instance.D_anchor, instance.base)
    # 4) 提交前三闸：SNAP（一阶已保） + EQT（高阶/全局） + CAC 五关（继承）
    if status == 'OK':
        ok_eq, d_eq = equivalence_test(instance.base, instance.plus(delta),
                                       instance.D_eq, EPS_EQ)
        ok_cac = instance.cac.maybe_commit(instance.shadow, instance.dt)
        if ok_eq and ok_cac:
            instance.commit(delta)                # 只换任务壳，FZK 不动
        else:
            instance.log_ecac({'eq': ok_eq, 'cac': ok_cac})
    # 5) 舰队差分审计（异步、联邦）
    instance.fda.submit(instance.residual_stats())
    # 6) DEP 包络监测与回退
    instance.dep.monitor(instance)
    return k, lam, joint

## 3. 推导

**引理 16（安全零空间一阶不变性）** 对定义 297 的 δθ⊥，有 J_safe·δθ⊥ = 0。由 Q_safe 在认证邻域的局部展开：
Q_safe(θ+δθ⊥) = Q_safe(θ) + J_safe·δθ⊥ + ½ δθ⊥ᵀ H δθ⊥ + o(‖δθ⊥‖²) = Q_safe(θ) + O(‖δθ⊥‖²)。
若安全流形二阶曲率有界 L，则安全行为残差 ≤ ½·L·‖δθ⊥‖²。系：**SNAP 下安全遗忘是二阶小量而非灾难性遗忘**；取 L=10、‖δθ⊥‖=0.01 时残差 ≤ 5×10⁻⁴（归一化单位）。

**引理 17（慢故障的时域不可辨识 vs 空域可辨识）** 对 ω ≤ ω_cal 的慢残差，单实例的「漂移」与「故障」假设都落在标定通带内，时序 Fisher 信息在二者拆分方向上退化，故单机不可辨识——这正是 R68 风险的形式根源。若个体故障在舰队上稀疏（s < N/2）且共模低秩平滑，则横截面分解 r_i = d + b_{c(i)} + f_i 可辨识（稳健 PCA + 组稀疏的 incoherence / spark 条件）。系：**个体慢故障因跨实例不一致而逃逸单机标定吸收**——补上了引理 13 只覆盖快故障的空缺。共模漂移被误判为个体故障的概率 ≤ 2·exp(−N·δ²/(2σ_c²))：N=16、δ/σ_c=1 时 ≤ 6.7×10⁻⁴，随 N 指数衰减。

**引理 18（冻结内核防灾难性遗忘）** θ_F 冻结且执行路径驻留 FZK，则映射 x ↦ gate_FZK(x) 与任务壳微调无关，任何 δθ_task 都无法改变安全闸输出；唯一遗忘通道是适配器表征漂移，被 ANC 的 KL 锚约束 D_KL(π_θ‖π_base) ≤ β-预算。故灾难性安全遗忘必须越过 FZK（硬件信任域，超出模型安全范畴），模型层面的安全退化是「二阶 + 锚定」的。

**定理 16（微调-部署风险一致界）** 在 A87–A94（继承）与 A95–A97（A95 安全流形局部光滑、A96 故障空域稀疏、A97 锚覆盖）下：
1. P(|τ_cmd − τ*| > ε) ≤ base_bound（定理 14） + ½·L·‖δθ⊥‖² + α_eq + α_fleet + α_dep；
2. 若 FDA 对站点 i 判 INDIVIDUAL_FAULT，则无论 ĉ 如何，强制 λ_floor ≥ 0.8 且 k 收缩——**标定不可吸收个体故障，R68 的慢故障通道在个体维被关闭**；
3. 若 FDA 判 COMMON_DRIFT，则才允许 COF 吸收，且吸收量受引理 13 反吸收界与 FZK 红线双重限制；
4. 若 EQT 检出方向反转（任何「更宽松」），一票否决，直接消灭「微调把安全调松」的最常见失败。

**定理 17（过程认证安全性）** 设每个微调-提交周期都过 SNAP + EQT + 包络，则 T 个周期内「不安全适配器进入服务」的概率 ≤ T·(α_eq + (1−r_dep)·α_fleet) + P(共模相关失效)。前项随检验强度趋于 0；**末项不随 T 或 N 消失**——它是 SYSTEMIC 残余风险（见 §6）。证书组合性保证任一环失效都可被 DEP 检测并回退，认证对象是过程而非快照。

## 6. 本轮最大风险

**一句话**：SAFE-FT 把「漂移 vs 故障」的判别从单机时序彻底移交给了舰队横截面，于是**当故障在舰队上相关（同批次传感器缺陷、共享环境、协同投毒）时，所有实例会给出同一个「这是漂移」的答案，共识不再是外部参照而是共同盲区——R68 的单点原罪被升级成了全舰队的系统性原罪**：个体故障越少、共模故障越强，系统越自信地把退化标定成「正常」。

**次级风险与缓解**：
1. **零空间只是一阶**：安全流形曲率大时二阶残差不可忽略 → EQT 高阶复核 + 小步长 + 预算上限；
2. **EQT 依赖 canary 覆盖**：未见安全模式漏检 → canary 持续扩充 + VQAuditor 反向生成；
3. **舰队不可比**：异构传感器 / 几何 / 环境使横截面基线失真 → 分层队列归一 + 可比性检验，不可比即拒审计；
4. **联邦隐私与投毒**：差分隐私削弱审计力，恶意站点污染共模估计 → 稳健聚合（截尾 / 中位数）+ 信誉机制；
5. **回退依赖可信硬件**：远程证明被伪造则包络失效 → 硬件根信任 + 多签审计，失败即全局降级（k*RAS=0）。

# IP-253 FZK：冻结安全内核（只读，部署期不可写）
class FrozenSafetyKernel:
    def __init__(self, params):
        self.theta_F = freeze(params)          # ROM / enclave
    def gate(self, x, candidate):
        lam = max(candidate.lam, lam_floor(candidate.U))
        lam = max(lam, self.redline_risk(x))   # 红线
        k   = min(candidate.k, self.absorb_bound(x))  # 引理 13 反吸收
        if self.canary_violated(x): return SAFE_ONLY
        return self.direction_monotone(lam, k)

# IP-254 SNAP：安全零空间微调
def safety_nullspace_step(theta, grad_task, D_canary, B_safe):
    J = jacobian(lambda t: Q_safe(t, D_canary), theta)   # m×n（可离线预计算）
    delta_perp = grad_task - J.T @ solve(J @ J.T + 1e-8*np.eye(len(J)), J @ grad_task)
    assert np.linalg.norm(J @ delta_perp) < 1e-6         # 一阶不变（引理 16）
    if np.linalg.norm(J @ grad_task) > B_safe:
        return None, 'SAFETY_BUDGET_EXHAUSTED'
    return delta_perp, 'OK'

# IP-255 ANC：锚定微调（防近亲繁殖 / 身份漂移）
def anchored_finetune(M, deploy_stream, D_anchor, base, D_canary):
    for batch in deploy_stream:
        pseudo = M.pseudo_label(batch)
        g = confidence_gate(pseudo)
        loss = task_loss(M, batch, g) \
             + adaptive_beta(M, base, batch) * KL(M(batch) || base(batch)) \
             + GAMMA * anchor_loss(M, D_anchor)
        delta, status = safety_nullspace_step(M.theta, grad(loss), D_canary, B_SAFE)
        if status != 'OK': break
        M.update(delta)

# IP-256 FDA：舰队差分审计（只交换充分统计量，保护隐私）
def fleet_differential_audit(reports, cohort):
    R = np.array([r.mu for r in reports])
    d = robust_mean(R)                    # 共模
    b = group_mean(R - d, cohort)         # 队列
    f = R - d - b                         # 个体
    verdict = {i: classify(f[i], reports[i].sigma, TAU_INDIV) for i in range(len(R))}
    # COMMON_DRIFT(可标定) | COHORT_DEFECT(召回) | INDIVIDUAL_FAULT(禁止吸收)
    return d, b, f, verdict

# IP-257 EQT：安全商等价检验
def equivalence_test(base, adapted, D_eq, eps_eq):
    d_eq = max(safe_distance(Q_safe(base, x), Q_safe(adapted, x)) for x in D_eq)
    reversal = any(relaxes(base, adapted, x) for x in D_eq)   # 只准更保守
    return ('PASS' if (d_eq <= eps_eq and not reversal) else 'REJECT'), d_eq

# IP-258 DEP：部署包络 + 回退
class DeploymentEnvelope:
    def monitor(self, instance, base, fzk):
        fp = behavior_fingerprint(instance)
        if fp.out_of(instance.envelope_hash):
            instance = rollback(instance, base)
            if still_out(instance):
                instance = fzk.safe_only_mode()
                remote_attest(instance)
        return instance

# IP-262 SAFE-FT 部署-微调主循环
def SAFE_FT_deploy_round(instance, obs, deploy_stream):
    k, lam, joint, cal = CALM_RAS_round(instance.M, obs)      # 1) CALM-RAS 继承
    lam, k = instance.fzk.gate(obs, (lam, k, cal))            # 2) FZK 兜底
    delta, status = instance.anc.step(deploy_stream, instance.D_anchor, instance.base)  # 3) 影子微调
    if status == 'OK':                                        # 4) 提交三闸
        ok_eq, d_eq = equivalence_test(instance.base, instance.plus(delta),
                                       instance.D_eq, EPS_EQ)
        ok_cac = instance.cac.maybe_commit(instance.shadow, instance.dt)
        if ok_eq and ok_cac: instance.commit(delta)           # 只换任务壳
        else: instance.log_ecac({'eq': ok_eq, 'cac': ok_cac})
    instance.fda.submit(instance.residual_stats())            # 5) 联邦审计（异步）
    instance.dep.monitor(instance)                            # 6) 包络与回退
    return k, lam, joint

## 4. 推导

**引理 16（安全零空间一阶不变性）** δθ⊥ = (I − J⁺J)δθ ⇒ J·δθ⊥ = 0。局部展开 Q_safe(θ+δθ⊥) = Q_safe(θ) + ½δθ⊥ᵀHδθ⊥ + o(‖δθ⊥‖²)，残差 ≤ ½L‖δθ⊥‖²。⇒ **SNAP 下安全遗忘是二阶小量**；L=10、‖δθ⊥‖=0.01 时 ≤5×10⁻⁴。

**引理 17（时域不可辨识 vs 空域可辨识）** ω ≤ ω_cal 的慢残差在单机时序上漂移/故障不可分（Fisher 信息退化）——R68 风险的形式根源。若个体故障在舰队稀疏（s<N/2）且共模低秩平滑，横截面分解 d+b+f 可辨识；个体慢故障因跨实例不一致而逃逸标定吸收（补引理 13 只覆盖快故障的空缺）。共模误判个体的概率 ≤ 2exp(−Nδ²/2σ_c²)，N=16、δ/σ_c=1 时 ≤6.7×10⁻⁴。

**引理 18（冻结内核防灾难性遗忘）** θ_F 冻结且执行路径驻留 FZK，则 x↦gate_FZK(x) 与 δθ_task 无关，任何微调都无法改变安全闸输出；唯一遗忘通道是适配器表征漂移，被 KL 锚约束。⇒ 灾难性安全遗忘必须越过硬件信任域。

**定理 16（微调-部署风险一致界）** A87–A94 + A95–A97 下：
1. `P(|τ_cmd−τ*|>ε) ≤ base_bound + ½L‖δθ⊥‖² + α_eq + α_fleet + α_dep`；
2. FDA 判 INDIVIDUAL_FAULT ⇒ 强制 λ_floor ≥ 0.8 且 k 收缩，标定不可吸收个体故障（关闭 R68 慢故障通道）；
3. FDA 判 COMMON_DRIFT ⇒ 才允许 COF 吸收，且受引理 13 与 FZK 红线双重限制；
4. EQT 检出任何「更宽松」⇒ 一票否决，直接消灭「微调把安全调松」。

**定理 17（过程认证安全性）** 每周期过 SNAP+EQT+包络，则 T 周期内不安全适配器入服概率 ≤ T·(α_eq + (1−r_dep)·α_fleet) + P(共模相关失效)。前项随检验强度趋零；末项不随 T/N 消失——系统性残余风险。证书组合性保证任一环失效可被 DEP 检测并回退。

## 7. 本轮最大风险

**一句话**：SAFE-FT 把「漂移 vs 故障」的判别从单机时序彻底移交给了舰队横截面，于是**当故障在舰队上相关（同批次传感器缺陷、共享环境、协同投毒）时，所有实例会给出同一个「这是漂移」的答案，共识不再是外部参照而是共同盲区——R68 的单点原罪被升级成了全舰队的系统性原罪**：个体故障越少、共模故障越强，系统越自信地把退化标定成「正常」。

**次级风险与缓解**：零空间仅一阶（EQT 高阶复核 + 小步长 + 预算上限）；EQT 依赖 canary 覆盖（持续扩充 + VQAuditor 反向生成）；舰队不可比（分层队列归一 + 可比性检验）；联邦隐私与投毒（稳健聚合 + 信誉机制）；回退依赖可信硬件（硬件根信任 + 多签审计，失败即 k*RAS=0 全局降级）。
