# 第 10 轮（新灵感循环第 1 轮；本轮灵感：「群体智能」×「多传感器融合」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**证据融合代数化 + 单轮证书共识 + 群体退化等价**。两个灵感分别治理 v9 的两种债：感知债（Calib-FI 只给标量权重，无法表达证据冲突、共模相关、"失效=从未发言"）与协同债（多机仍是外挂调度，没有安全级协议）。所有新模块都必须能以中立元注入严格退回 v9；邻居只允许增加保守性，不允许增加激进性。

## 0. 直觉与动机

**灵感 1（多传感器融合 → 融合代数的中立元化）**
直觉：v9 的 Calib-FI 用一族标量权重 `sensor_weight` 处理传感器可信度。它能对付"某个传感器变差"，却表达不了三件更要命的事：(a) 两源给出互相矛盾的证据（冲突质量 K 上升）；(b) 两源误差高度相关（把相关当独立会过度自信）；(c) 某源失效本该等价于"它从未发言"，而不是"它投了一个坏票"。一个严谨的融合层应当是**代数**，不是权重表。
严谨定义（预告定义 540–542）：**证据融合总线（EvidentialFusionBus, EFB）** 把每个源（物理传感器或邻居机器人）抽象为融合单元 `u=(Ω_ind, P_com, m)`：`Ω_ind` 为独立信息矩阵（0 表示无信息），`P_com` 为共模协方差（0 表示无共模误差），`m` 为断言框架 Θ 上的质量函数。融合算子 `⊕` 逐分量定义——独立信息相加、共模协方差取保守上界、质量用去归一化合取（Smets 合取）组合。其中立项为 `⊥=(0, 0, m_Θ)`：`u⊕⊥=u`。于是"多传感器融合"和"传感器失效"统一成同一幺半群里的两种元素，退化不再需要 if-else。

**灵感 2（群体智能 → 邻居是"带契约的传感器"，共识只发生在证书层）**
直觉：群体智能最容易犯的错是让机器人对"动作"做投票——这会把单机安全保证稀释成平均意见，且在通信延迟下产生最坏的安全空洞。反过来，如果只对"安全证书"做**单轮最坏情形共识**，邻居就退化成"另一类证据源"：它只能让系统更保守，不能让它更激进。任务协调则交给类信息素的共享标量场——它只影响非安全的任务选择。
严谨定义（预告定义 543–548）：**群体共识证书器（SwarmConsensusCertifier, SCC）** 每机广播 `(epoch, 本地证书 margin_i, conflict_i, sig)`，单轮聚合 `margin_agg = min_{q∈Q} margin_q`（最坏情形，而非平均）；法定人数 `|Q| < q_min` 即**弃权**（注入 ⊥），本机单独运行 v9。**共识场（StigmergicTaskField, STF）** 为任务空间上的标量场 `F(x,t+1)=λF(x,t)+deposits`，只进入任务评分，安全滤器永远在其后运行；`F≡0` 即均匀场，精确复现 v9 的任务选择。

**综合：两个灵感是同一件事的两个尺度。** 邻居不是新的"智能体类别"，而是共享同一环境的传感器，其误差与本机高度**共模相关**。因此真正的科学问题不是"怎么融合"，而是"在共模相关未知时，如何保证融合永不比单机更自信"。**共模哨兵（CommonModeSentinel, CMS）** 因此是本轮枢纽：在线估计相关界 `ρ̄`，并对任意融合协方差施以保守膨胀因子 `C(ρ̄,n)=1+(n−1)ρ̄`，相关估计失灵时令 `ρ̄←1`（禁止跨源融合，退回本机）。

## 1. 研究问题（轮次升级版）

- **Q1（保守融合）**：在仅知两两相关界 `ρ_ij ≤ ρ̄` 时，分裂信息融合 + 膨胀因子能否给出"融合后验方差 ≥ 真实后验方差"的分布无关保证？共模哨兵的在线 `ρ̄` 估计误差如何量化，低估相关时能否熔断？
- **Q2（证书级共识的容错与实时性）**：单轮最坏情形共识在至多 f 个拜占庭邻居（含谎报"安全"）下，能否保证"任一诚实机不安全 ⇒ 群体判不安全"？法定人数丢失、分区、时钟偏移时是否严格等价退回 v9？最坏情形共识只保安全不保活性（恶意低报可触发保守停车）是否是正确取舍？
- **Q3（群体协调不触碰安全）**：共识场与证书融合在什么门控下保证群体协调只改变非安全的任务选择、且不削弱单机九不变式？跨机蒸馏（把 ID 的消融归因推广到"邻居贡献"）能否在不引入新攻击面的前提下做贡献归因？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 证据融合幺半群律（Evidential Fusion Monoid, EFB）**
每源声明契约 `κ_j=(In,Out,D_j,Ŵ_j,w_j,⊥_j,φ_j)`；融合单元构成交换幺半群 `(𝔉,⊕,⊥)`：独立信息 `Ω_ind` 相加、共模协方差 `P_com` 取 PSD 上界、断言质量 `m` 去归一化合取，`⊥=(0,0,m_Θ)`。源失效/超时/契约破坏 ⇒ 注入 `⊥`，等价于该源从未发言。

**P14 单轮证书共识律（Certificate-Level Consensus, SCC）**
共识对象仅为**安全证书**，绝不为动作。每轮 `epoch` 一次广播、一次聚合；`margin_agg = min`（最坏情形），法定人数 `|Q|≥q_min` 才有效；不满足即弃权 `⊥`。至多 f 个恶意源时要求 `n ≥ q_min+f`。共识只保安全不保活性：恶意低报导致保守停车是被接受的可用性代价。

**P15 共模保守律（Common-Mode Conservatism, CMS）**
对 n 个两两相关 `ρ_ij≤ρ̄` 的源，融合协方差至少膨胀 `C(ρ̄,n)=1+(n−1)ρ̄`；相关界未知时取 `ρ̄=1`（禁止收益）。冲突质量 `K>K_max` 或新息白化检验拒绝 ⇒ 熔断，退回本机 v9。融合的默认方向是"更不确定"，而非"更确定"。

**P16 群体退化等价律（Swarm-Neutral Degradation, SWD）**
任一群体模块失效 ⇒ 注入其 `⊥`，逐机行为逐位等价 v9：EFB 失效⇒仅 Calib-FI 标量权重；SCC 失效/失步⇒本机证书；STF 失效⇒零场；CMS 失效⇒`ρ̄=1`。全部群体模块失效 ⇒ 逐机完整退回 MetricVoiceGauge-ACMD v9，再沿 v9 链退回 v8→v7→v6。

## 3. 与基线的接口（如何退化）

- EFB 失效（超时/冲突爆炸/契约破坏）⇒ 每源注入 `⊥`，仅保留本机 Calib-FI 标量权重，等价 v9；
- SCC 失效（法定人数不足/网络分区/epoch 失步）⇒ 弃权，仅用本机证书，等价 v9；
- STF 失效 ⇒ 零场，任务分配回退本机默认评分，等价 v9；
- CMS 失效（相关估计不可信/白化检验失败）⇒ `ρ̄←1`，禁止跨源融合收益，等价本机 v9；
- v9 ACMD 的 AC/MW/ID 任一失效 ⇒ 按 v9 五级链退回 v8；
- 全部失效 ⇒ 完整退回 MetricVoiceGauge-ACMD v9 → v8 → MetricVoiceGauge-OTL-GC-ER v7 → v6。

## 4. 预期贡献

1. **分裂信息融合 + 共模膨胀界**：给出"融合永不比单机更自信"的分布无关保守保证（引理 89），把群体/多源融合从"调权重"变成"可证明的保守代数"；
2. **单轮证书级共识**：邻居只增加保守性、不增加激进性；`n≥q_min+f` 下最坏情形安全等价（引理 90），法定人数丢失精确退回 v9；
3. **共识场**：非安全任务协调与安全解耦，安全滤器后置保证零安全面增量（引理 91）；
4. **群体退化格**：所有群体模块以中立元注入退回 v9，实验 E571–E590 覆盖融合保守性、共模过自信、拜占庭邻居、分区、时钟偏移、规模扩展与端到端多机任务。

## 5. 本轮最大风险

**一句话**：整个方案的安全性押在相关界 `ρ̄` 的保守性上，而机器人恰恰在人群密集、共享同一批传感器/地图/盲区的场景中共模相关最高——若 CMS 用有限样本低估了 `ρ_ij`，膨胀因子就会失效，群体融合会在"所有机器人同时看错同一处"时给出比任何单机都高的虚假确定性，并由最坏情形共识把这个错误证书盖成群体结论。

**新增定义 540（证据源与融合契约 EvidenceSource）** 每个源 `j∈S` 声明 `κ_j`。可信度 `w_j(t)` 由源的历史新息一致性在线更新（EMA），并受 CMS 相关界约束。物理传感器与邻居机器人在本层**完全同构**——这是"邻居即传感器"的形式化。

**新增定义 541（融合单元 FusionUnit）** `u=(Ω_ind∈𝕊^d_+, P_com∈𝕊^d_+, m:2^Θ→[0,1])`，其中 `m(∅)=0`、`Σ_A m(A)≤1`（允许亚归一，Smets 开放世界）。状态估计取 `x̂ = (Ω_ind)^{-1}ξ`（`ξ` 为信息向量；`Ω_ind=0` 时无估计）。中立元 `⊥=(0,0,m_Θ)`，`m_Θ(Θ)=1` 为 vacuous BBA（完全无知）。

**新增定义 542（证据融合算子 EvidenceFusion ⊕）**
```
Ω_ind^{1⊕2} = Ω_ind^1 + Ω_ind^2
P_com^{1⊕2} = max_PSD(P_com^1, P_com^2)          # 保守上界，逐特征值取大
m^{1⊕2}(C)  = Σ_{A∩B=C} m^1(A)·m^2(B)            # 去归一化合取（Smets）
```
则 `(𝔉,⊕,⊥)` 为交换幺半群：结合、交换、`u⊕⊥=u`（引理 87）。**注意**：语义只在需要决策时才归一化，冲突质量 `K=1−Σ_C m^{1⊕2}(C)` 保留为诊断量，而非丢弃。

**新增定义 543（可信度折扣 CredibilityDiscount）** `m^w(A)=w·m(A)`（`A≠Θ`），`m^w(Θ)=1−w+w·m(Θ)`。折扣只增加无知、不增加已承诺信念（引理 88）。

**新增定义 544（共模膨胀与熔断 CommonModeInflation）** 设 n 源两两相关 `ρ_ij≤ρ̄`，对任意融合方差 `P_fused` 施加
```
P_guard = C(ρ̄, n) · P_fused,    C(ρ̄,n) = 1 + (n−1)·ρ̄
```
若 `K > K_max` 或新息白化检验 p 值 `< α` ⇒ 熔断，令 `ρ̄←1`（`C=n`，等价仅用本机）。`ρ̄` 在线更新：`ρ̄ ← min(1, max(ρ̄, 1.2·ρ̂_max))`（对估计值加 20% 安全系数）。

**新增定义 545（群体图与时变邻居 SwarmGraph）** 每周期由通信可见性得到 `G_t`；仅 1-hop 邻居作为源，避免多跳环路导致的相关性累积。丢包/超时的边视为不存在，其源注入 ⊥。

**新增定义 546（群体共识证书 SwarmCertificate）** 每机在 `epoch` 广播本地证书 `c_i=(epoch, margin_i, conflict_i, sig_i)`，`margin_i` 取该机 v9 块证书的最坏安全余量 `ĝ_min−d_safe`（定义 533）。聚合
```
margin_agg = min_{i∈Q} margin_i,   K_agg = max_{i∈Q} conflict_i
```
有效当且仅当 `|Q|≥q_min`、`epoch` 在 `T_c` 内、签名验证通过；否则 `C_t^sw=⊥`（弃权）。

**新增定义 547（法定人数与弃权 QuorumAbstention）** `q_min=n−f`，要求 `n≥3f+1`（保证 `q_min≥2f+1`）。弃权不是失败，而是**中立项**：本机以自身证书运行，群体层不贡献任何约束。恶意低报只会触发保守停车（可用性代价），不会造成不安全（引理 90）。

**新增定义 548（共识场 StigmergicTaskField）** 任务空间网格上的标量场
```
F(x,t+1) = λ·F(x,t) + Σ_i deposit_i(x,t),   0<λ<1
```
机器人完成/推进任务时沉积，未访问处挥发。任务评分 `score(task)=base(task)+μ·F(x_task)`。`F≡0`（零场）为中立元，等价 v9 默认评分。**关键门控**：`F` 只进入安全滤器**之前**的候选评分，任何被选动作仍须通过 v9 的 `M₀/SpatialCert/AC 守卫`（引理 91）。

## 2. 形式化定义（要点与升级）

**升级定义 533（块证书，v10）** 本地块证书的间隙下界再与群体证书取最坏：
```
ĝ_min^v10 = min(ĝ_min^local, d_safe + margin_agg)      # margin_agg 为定义 546 的下界
```
证书有效还需 `C_t^sw≠⊥`；`C_t^sw=⊥` 时退化为本地证书（≡ v9）。
**升级定义 496（软证书，v10）** 触发集合在 v9 五条件上增加两项：`K_agg < K_max` 与 `C_t^sw valid`。冲突质量与群体证书与单步条件同尺度，杜绝"块内软通过、群体硬失"的空洞。
**升级定义 537/538（ID，v10 可选）** 消融归因可扩展到"移除某个邻居源"的跨机贡献 `c_j`，但 `φ_j^elig=false` 的安全源（本机 M₀、SpatialCert、FaultCert、MW、AC 守卫、SCC 自身）永不参与；跨机归因仅影响调度，不影响可达性（P12 不变）。

import numpy as np
from dataclasses import dataclass, field

THETA = frozenset({"SAFE", "MARGINAL", "UNSAFE"})
VACUOUS = {THETA: 1.0}

@dataclass
class FusionUnit:
    Omega_ind: np.ndarray          # 独立信息矩阵，0=无信息（中立）
    P_com: np.ndarray              # 共模协方差，0=无共模误差
    bba: dict                      # 质量函数，THETA:1.0 为 vacuous
    xi: np.ndarray = None          # 信息向量（可选）

NEUTRAL = FusionUnit(np.zeros((6, 6)), np.zeros((6, 6)), VACUOUS, np.zeros(6))

def max_psd(A, B):
    """逐特征值取大（PSD 上界，保守）。"""
    w, V = np.linalg.eigh(A); u, U = np.linalg.eigh(B)
    return V @ np.diag(np.maximum(w, np.diag(V.T @ B @ V))) @ V.T

def conjunctive_unnorm(m1, m2):
    out = {}
    for A, pa in m1.items():
        for B, pb in m2.items():
            C = A & B
            if not C:                     # 冲突质量不丢弃，单独记录
                continue
            out[C] = out.get(C, 0.0) + pa * pb
    return out

def conflict(m1, m2):
    return sum(pa * pb for A, pa in m1.items() for B, pb in m2.items()
               if not (A & B))

def fuse(u, v):
    """交换幺半群运算：u ⊕ ⊥ = u。"""
    return FusionUnit(
        Omega_ind=u.Omega_ind + v.Omega_ind,
        P_com=max_psd(u.P_com, v.P_com),
        bba=conjunctive_unnorm(u.bba, v.bba),
        xi=None if u.xi is None else u.xi + v.xi,
    )


class CommonModeSentinel:
    """IP-360：共模相关界估计 + 保守膨胀 + 过自信熔断。"""
    def __init__(self, rho_bar=0.3, K_max=0.7, alpha=0.05):
        self.rho_bar, self.K_max, self.alpha = rho_bar, K_max, alpha

    def update(self, residuals):
        """residuals: {source: innovation_vector}；估计两两相关。"""
        rho_hat = max_pairwise_corr(residuals) if len(residuals) > 1 else 0.0
        self.rho_bar = min(1.0, max(self.rho_bar, 1.2 * rho_hat))

    def inflate(self, P, n):
        C = 1.0 + (n - 1) * self.rho_bar      # 定义 544
        return C * P

    def trip(self, K, whiteness_p):
        return (K >= self.K_max) or (whiteness_p < self.alpha)


class EvidentialFusionBus:
    """IP-357：多源融合；失效源注入 ⊥，等价"从未发言"。"""
    def __init__(self, cms: CommonModeSentinel):
        self.cms = cms

    def fuse_sources(self, sources, units, healthy):
        fused, n = NEUTRAL, 0
        for j, u in zip(sources, units):
            if healthy(j):
                fused = fuse(fused, u); n += 1
            else:
                fused = fuse(fused, NEUTRAL)      # 显式中立元注入
        P = np.linalg.pinv(fused.Omega_ind) if n else np.inf
        return fused, self.cms.inflate(P, max(n, 1)), n


class SwarmConsensusCertifier:
    """IP-358：单轮最坏情形证书共识；法定人数不足 ⇒ 弃权 ⊥。"""
    def __init__(self, q_min, T_c_ms=10.0):
        self.q_min, self.T_c_ms = q_min, T_c_ms

    def aggregate(self, epoch, certs, now):
        Q = [c for c in certs
             if c.epoch == epoch and verify(c.sig)
             and now - c.t <= self.T_c_ms]
        if len(Q) < self.q_min:
            return None                             # 弃权 ≡ ⊥ ⇒ 本机 v9
        return SwarmCert(epoch=epoch,
                         margin_agg=min(c.margin for c in Q),
                         K_agg=max(c.conflict for c in Q),
                         quorum=len(Q))

    def local_cert(self, block_cert, local_conflict, epoch):
        return Cert(epoch=epoch,
                    margin=block_cert.g_min - block_cert.d_safe,
                    conflict=local_conflict, sig=sign(...))


class StigmergicTaskField:
    """IP-359：非安全任务协调；零场 ≡ v9。"""
    def __init__(self, shape, lam=0.98, mu=0.3):
        self.F, self.lam, self.mu = np.zeros(shape), lam, mu

    def deposit(self, x, amount=1.0):
        self.F[x] += amount

    def decay(self):
        self.F *= self.lam

    def score(self, task, base):
        return base(task) + self.mu * self.F[task.cell]   # 仅进入候选评分


# 主闭环集成：MetricVoiceGauge-SwarmFuse
def metricvoicegauge_round_10(M, s, obs, neighbors, cycle_idx, ...):
    # ---- 1) 收集证据：物理传感器与邻居同构 ----

    fused, P_guard, n = fusion_bus.fuse_sources(srcs, units, healthy)
    cms.update(innovation_residuals(srcs, obs))
    K = conflict_mass(fused.bba)
    if cms.trip(K, whiteness_p(obs)):
        fused = local_only(M)                        # ≡ v9（Level-S3）

    # ---- 3) v9 ACMD 主路径（用融合状态）----
    C, block_cert, claims, metrics, rewards = v9_path(M, fused, obs)

    # ---- 4) 单轮群体证书（最坏情形，绝不平均）----
    local = scc.local_cert(block_cert, K, epoch=cycle_idx)

    if swarm is None:                                # 弃权 ⇒ 本机 v9

    else:
        cert_eff = block_cert.with_margin(
            min(block_cert.g_min, block_cert.d_safe + swarm.margin_agg))

    # ---- 5) 共识场：只影响非安全任务评分，安全滤器后置 ----
    field.decay()
    task = select_task(field.score, base_score=cert_eff)   # 候选评分

## 4. 推导

**引理 87（融合幺半群与中立元退化）** `(𝔉,⊕,⊥)` 是交换幺半群，且对任意源集合 `J`，若 `j∉J` 被注入 ⊥，则聚合结果等于只融合 `J`；`J` 为空时结果为 ⊥。证明：逐分量——`Ω_ind` 加法以 0 为单位、`P_com` 的 PSD 逐特征值取大以 0 为单位、去归一化合取以 vacuous `m_Θ` 为单位（`m_Θ` 与任意 BBA 的合取还原原 BBA）。故失效源等价"从未发言"，全失效等价无信息（本机 v9 不使用跨源信息）。∎

**引理 88（折扣的保守性）** 对 `w∈[0,1]`，`Bel_{m^w}(A)=w·Bel_m(A)` 且 `Pl_{m^w}(A)=1−w(1−Pl_m(A)) ≥ Pl_m(A)`。即折扣只增加无知、从不增加已承诺信念。证明：按定义 543 展开，非 Θ 焦元质量乘 w，Θ 质量补足 `1−w+w·m(Θ)`；代入 Bel/Pl 求和即得。∎ 推论：任何邻居/传感器的可信度加权都不能把"不确定"变成"确定"。

**引理 89（共模过自信界 / 融合永不比单机更自信）** 设 n 个估计各方差 `≤σ²`、两两相关 `ρ_ij≤ρ̄`，且融合按独立性假设给出方差 `P_ind`。则真实融合方差 `P_true ≤ C(ρ̄,n)·P_ind`。因此施加定义 544 的膨胀后 `P_guard ≥ P_true`，融合后验不会低估不确定性。证明：等方差等相关时 `Var(x̄)=σ²(1+(n−1)ρ)/n = C·σ²/n`；`P_ind=σ²/n`。由 `ρ≤ρ̄` 得 `Var(x̄) ≤ C(ρ̄,n)σ²/n = C·P_ind`。不等方差情形由 PSD 逐特征值比较与 Gershgorin 界逐通道成立。∎ 有效样本量 `n_eff=n/C`：相关越强，群体越"像一个传感器"。

**引理 90（单轮最坏情形共识的安全性）** 设至多 f 个恶意源、`n≥q_min+f`、`q_min=n−f`，诚实源报告真实 `margin_i`。群体聚合 `margin_agg=min_{i∈Q} margin_i` 满足 `margin_agg ≤ min_{i∈H} margin_i`（`H` 为诚实源集合）。故若任一诚实机判定 `margin_i<0`（不安全），则 `margin_agg<0`，群体判不安全。法定人数不足 ⇒ 弃权 ⇒ 本机 v9。证明：诚实集 `H⊆Q`（法定人数保证），`min_{Q} ≤ min_{H}`；单调性得安全蕴含。恶意低报仅使 `min` 更小、触发保守停车，不破坏安全。∎

**引理 91（共识场不触碰安全）** STF 只改变定义 548 的候选评分 `score(task)`，其输出进入安全滤器 `Φ_safe`（v9 的 `M₀∧SpatialCert∧AC 守卫∧cert_eff`）。对任意 `F`，`Φ_safe` 的输出动作集是 v9 可行集的子集；`F≡0` 时评分还原 v9，输出逐位一致。证明：安全滤器对候选集单调收缩，且不读取 `F`；`F≡0` 时 `score=base`。∎

**引理 92（群体退化等价）** 将 IP-357–360 全部替换为各自 ⊥（EFB: 每源 ⊥；SCC: 弃权；STF: 零场；CMS: `ρ̄=1`），则单机每周期计算与 MetricVoiceGauge-ACMD v9 逐位一致。证明：引理 87 给融合退化；引理 90 给证书退化；引理 91 给任务退化；`ρ̄=1` 时 `C=n` 使跨源融合无收益、仅剩本机 Calib-FI（v9 定义 496）。各中立元不改变 v9 的 `τᵢ(t)`、块证书与状态机取值。∎

## 8. 本轮最大风险

**一句话**：整个方案的安全性押在相关界 `ρ̄` 的保守性上，而机器人恰恰在人群密集、共享同一批传感器/地图/盲区的场景中共模相关最高——若 CMS 用有限样本低估了 `ρ_ij`，膨胀因子就会失效，群体融合会在"所有机器人同时看错同一处"时给出比任何单机都高的虚假确定性，并由最坏情形共识把这个错误证书盖成群体结论。
