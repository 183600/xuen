# 第 58 轮（承接第 57 轮「FewShot-XModal-Persona」IP-133~138；新灵感循环第 1 轮；本轮灵感：「力矩控制」×「知识图谱」）

> 第 57 轮把承诺的赌注从"模型置信"换成"证据质量"：元少样本先验、跨模态对账、单向有界信任三层纵深，使单点过度自信不再足以产生承诺。但它自己留下的三处结构性缺口在本轮暴露：**(a) 证据仍然太贵**——显式探针受节拍与不可逆性约束，每区域 k≤5，而关节力矩在每一个支撑相里本来就在源源不断地"称重地球"，却被当成控制噪声丢掉了；**(b) 先验仍然不可审**——摊销元模型 q_φ 是一个黑箱，它的错只能由共形带"兜底"，却无法被人逐条检查、无法被单条证据精准修正，一处语料盲区就污染整片区域；**(c) 承诺仍然只是软件拒绝**——证据门说"不承诺"，但从不说"即使承诺了，力矩也不会越过摩擦锥"；安全停在决策层，没有下沉到执行层。本轮两个灵感各补一条腿：**力矩控制**把执行器变成常开的触觉探针与物理安全壳——观测与执法同源；**知识图谱**把地形知识变成带区间、出处、版本、可证伪边的因果图——先验可审、错误可最小修正、未知即未知。于是核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"力矩接地、图谱可溯、包络可执的承诺"**（torque-grounded, graph-traceable, envelope-enforceable）。

核心矛盾：
- **H29（相关采样 vs 证据计数）**：力矩以 1 kHz 采样，但一个支撑相内的样本高度自相关；把 1000 个读数当 1000 条独立证据，就是把同一个问题问一千遍还假装得到了新答案——证据量必须按有效样本量 N_eff 折算，否则"常开探针"会制造虚假的确定感。
- **H30（符号接地 vs 开放世界）**：图谱越结构化越可审计，但边从哪来？未接地的符号关系只是"自信的胡说"；而一旦严格采用开放世界（缺失边=未知），系统可能对新地形永远不敢承诺——结构化先验在"可审"与"可用"之间走钢丝。
- **H31（观测-执行共模）**：力矩模型既当证人（推断地形）又当执法者（生成包络）。若力矩标定因负载、温漂、摩擦老化而偏移，信念与安全壳会朝同一个错误方向移动——系统会得到一个自洽却虚假的证书。这是比"坏先验普遍"更隐蔽的失效：不是不知道，而是"证据与执法一起错了"。

## 0. 直觉与动机

**灵感 1（力矩控制 → 常开探针 + 阻抗安全壳）**
直觉：腿式机器人每一次落脚，关节力矩都在回答两个物理问题——"地面有多硬？"（法向力-位移斜率）和"能给我多大切向力？"（滑移起始的切向/法向比）。这不是额外动作，是行走的副产品。于是探针经济学被改写：显式探针是"花钱采样"，力矩残差是"免费监听"。更进一步，力矩是唯一同时属于**观测通道**和**动作通道**的量：一次受控阻抗脉冲（do-操作）能主动把地形参数"问"出来，而一个力矩盒子（τ_min≤τ≤τ_max、摩擦锥、热预算）能在执行层物理地保证"即使判断错了力也不会越界"。前者给证据，后者给安全——但这恰是 H31 共模风险的来源。

**灵感 2（知识图谱 → 可审先验 + 最小修正）**
直觉：把地形知识写成一张图，而不是一袋标量：`区域 —hasSurface→ 湿钢板 —hasMaterial→ 钢 —frictionIn→ [0.10,0.18]（出处：干预 e17@t，版本 v3）—supportsGait→ trot@0.3`。每条边带区间、单位、出处、有效期；查询就是走一条可解释的路径。这样获得三种前几轮没有的能力：**可审**（人能逐边检查"为什么敢走"）、**可证伪**（一次反例只撤回相关子图，不推倒全图）、**开放世界**（走不通的路径返回"未知"，系统默认保守，而不是脑补一个最可能值）。第 57 轮的黑箱元先验在这里被替换成"带出处的先验 + 介入式接地"：没有干预或人工核验支持的边，不许单独为不可逆接触背书。

**灵感 3（合流 → 介入式接地与理由子图）**
直觉：图谱的边是因果断言，而力矩脉冲是干预实验——这正是 do-calculus 的物理版本。于是定义"边强度"：`prior < observation < intervention < human`。力矩触诊把一条 prior 边升级为 intervention 边；证伪则触发 AGM 式最小修正（只撤回极小冲突集，保留无关信念）。承诺时不再只报一个 σ，而是附一张**理由子图** J_t：从区域走到步态的每一条关键边、每一次力矩证据、包络推导链。安全从"一个数"变成"一条可被人审阅的论证"。

**灵感 4（力矩预算 → 探针不是免费的）**
直觉：触诊消耗热裕度、电池与执行器寿命，力矩预算 B_τ 是跨检查点共享的稀缺资源。VOI 必须除以力矩成本：`argmax [VOI_τ(p) − λ_τ·cost_τ(p)]`。这让"常开监听（近乎免费）+ 主动触诊（昂贵、精准）"形成自然的两级证据经济学：先用免费力矩残差把不确定性压到某个平台，只有当包络仍不稳健或图谱仍有冲突时，才花力矩去"敲一下"。

**灵感 5（合流算子 → 不确定性也走物理通道）**
直觉：第 57 轮的单调性说"机制只能让信念更准或动作更保守"。本轮加入第三条合法通道：**动作更顺应（compliant）**——图谱不确定时降低刚度、提高阻尼，即使信念完全错误，接触力也被物理地限制住。这不是"更准"，也不是"更敢/更不敢"，而是"更软"：一种不依赖信念正确性的安全兜底。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（力矩接地探针 TGP）** 关节力矩 τ_meas∈R^n，名义逆动力学 τ_rbd=M(q)q̈+C(q,q̇)q̇+g(q)，摩擦前馈 τ_f。残差 r_τ=τ_meas−τ_rbd−τ_f=J^T F_c+τ_u，接触力估计 F̂_c=(J^T)^† r_τ。地形签名 σ_τ=(k̂_s,μ̂,ĉ,v̂_slip)：k̂_s 由支撑相法向力-位移斜率估计，μ̂ 由滑移起始时 ||F_t||/F_n 估计，ĉ 由卸载段阻尼估计。**去相关校准**：N_eff=N/(1+2Σ_{k=1}^{K}ρ_k)，ρ_k 为残差自相关，K 覆盖一个支撑相；证据权重 w_τ=w_0·N_eff/(N_eff+n_0)。校准契约：以外部力台/负载辨识为独立通道，ECE_τ(N_eff)≤ε_τ。常开性：每个支撑相自动产出一条 σ_τ，无需额外动作；触诊（定义 144）只是把 N_eff 从"被动若干"抬到"主动一批"。

**定义 140（地形知识图谱 TKG）** G=(E,R,A,Π)。E={Region,Surface,Material,Gait,ContactLevel,Constraint,Modality,Operator,TorqueSig,Evidence}；R={hasSurface,hasMaterial,frictionIn,stiffnessIn,hasTorqueSig,supportsGait,requiresEvidence,contradicts,derivedFrom,supersedes}；A 为带单位的区间属性 [lo,hi] 与置信下界；Π 为出处 π(e)=(source∈{prior,observation,intervention,human}, evidence_id, t, version, trust)。语义为**开放世界**：缺失边=未知（非假）。点查询 q(r,g) 返回可满足区间 θ 与路径 P（跳数≤d_G）。冲突集 C(r)={同一 (实体,属性,有效期) 上区间不相交的边}。保守投影 Γ(G,r)：未知或冲突未决时取物理下界 (μ_lo,F_bear_lo,k_lo)，并禁止不可逆接触。

**定义 141（力矩-阻抗安全壳 TIS）** 给定 θ̂、步态 g、速度 v，包络 ℰ(g,r)={τ : τ∈[τ_min,τ_max], J^{-T}τ∈𝒲(g,v), ||F_t||≤μ_lo F_n, ∫τ²dt≤B_τ}，其中 𝒲 为维持步态所需的接触旋量集合。**稳健可行** ⇔ 对 θ̂ 的整个区间取最坏情形仍可行且裕度≥Δ_robust。执行层：τ*=Proj_ℰ(τ_des)=argmin_{τ∈ℰ}||τ−τ_des||²_W（QP/CBF）。**顺应性下限**：当图谱不确定时强制 k_p↓、k_d↑，使接触力上界不依赖 θ̂ 的正确性；这是一条与信念解耦的安全通道。

**定义 142（力矩接地信念修正 TBR）** 边的证据强度 ι(e)∈{prior<observation<intervention<human}。仅当 ι=intervention 且在同类区域复现≥n_int 次，边才可进入不可逆承诺必要集。证伪事件 f 触发**最小修正**：E'=(E∖R_min(C))∪E_new，R_min 为按可信序（intervention>human>observation>prior）与时间序求得的极小撤回集（AGM 收缩），无关边保留；所有撤回写入审计并回写负证据到历史探针。禁止"整图重置"，以抑制信念震荡。

**定义 143（力矩理由证据门 TJE 与证书 J_t）** 在第 57 轮证据类上新增 **EV-torque**：N_eff≥N_min(θ) ∧ ECE_τ≤ε_τ ∧ 区域无未决冲突 ∧ 签名与图谱预测不矛盾。承诺须附**理由子图** J_t(r,a)=最小连通子图 {r→surface→material→(friction/stiffness)→gait→constraint→evidence} ∪ 力矩证据节点 ∪ 包络推导链。不可逆接触要求：J_t 每条关键边 ι∈{intervention,human} 且 ℰ 稳健可行；否则即使 σ 很小也拒。证书 J_t 与第 57 轮 J_p 合并为 J_t=(J_p_runtime, J_t_graph, torque_log, envelope_trace, revision_log)。

**定义 144（探-控-诺-演 TCE 算子）** 每检查点：①常开力矩探针（支撑相即采样，N_eff 去相关）；②图谱查询→θ 区间→包络；③若未知/冲突/包络不稳健：冲突驱动触诊，法向脉冲默认允许，切向脉冲仅限 L1 且有包络裕度；在预算 B_τ 内选 argmax_p[VOI_τ(p)−λ_τ·cost_τ(p)]≥θ_voi；④承诺 ⇔ ℰ 稳健 ∧ TJE 过；⑤否则图重路由→顺应降档→L2 协商（沿用第 57 轮 τ_int(auth)）→安全停；⑥证伪→TBR 最小修正。终止：每次触诊 cost_τ≥c_min>0 且 B_τ 有限，故有限步终止。

## 2. 关键算法伪代码（完整版见产物区）

```python
def torque_grounded_step(x, M, G, cp):             # IP-139/140/141 合流
    pr = torque_probe(x, M, cp.region)             # 常开：stance 即采样
    M.b[cp.region] = fuse(M.b[cp.region], pr, w=pr.n_eff)   # N_eff 去相关
    q  = G.query(cp.region, cp.gait)
    th = G.conservative(cp.region) if q.unknown_or_conflict else q.theta
    env = torque_envelope(th, cp.gait, cp.v, x.limits)
    while (not env.robust or q.conflict) and budget.torque > 0:
        p   = argmax(palpation_candidates(cp, G, env),
                     key=lambda p: voi_tau(p) - lam * p.cost)
        if voi_tau(p) < theta_voi: break
        sig = torque_palpation(x, p, F_max=env.Fn)        # do-干预
        M.b[cp.region] = fuse(M.b[cp.region], sig, w=sig.n_eff)
        G.attach_intervention(cp.region, sig, p)          # 边：prior→intervention
        q, th, env = requery_and_envelope(G, cp, M)
        budget.spend(p.cost)
    return M, G, q, env
```

def revise(G, edge, ev):                            # IP-142
    if ev.type == 'intervention' and ev.replicated >= n_int:
        G.promote(edge, source='intervention')
    elif ev.falsifies(edge):
        G.revise_minimal(edge, ev)                  # AGM 极小撤回

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TGP | O(n²)+O(H_stance)/检查点 | O(H_stance) 滑窗 | N_eff 保守、ECE_τ 声明诚实 |
| TKG | O(d_G·deg) 查询；O(\|C\|log\|E\|) 修正 | O(\|E\|) | 开放世界保守、修正极小 |
| TIS | 稀疏 QP O(nnz)~O((n+m)³) 最坏 | O(n+m) | 摩擦锥/力矩盒/热预算不可越 |
| TBR | O(\|C\|·log\|E\|) | O(\|E\|) | 撤回极小、审计完备 |
| TJE | O(\|J_t\|) | O(\|J_t\|) | 无关键边即拒、理由子图连通 |
| TCE | O(\|CP\|·(H+k_p·(d_G+C_VOI))+B_τ/c_min) | O(\|V\|+\|E\|) | 预算有限 ⇒ 终止 |

**正确性定理（Torque-Grounded Soundness, TGS 概要）** 在 A22–A40 之上加：**(A41) 接地性**：力矩模型偏置 |β_τ|≤β_max，且由独立通道（力台/负载辨识/关节力矩传感器）周期性审计，β_max≤Δ_robust/2；**(A42) 采样性**：N_eff 为自相关的保守上界，证据独立性仅对干预样本声明；**(A43) 图谱性**：开放世界缺省保守，修正最小且按出处序，不可逆接触的关键边必须 intervention/human 支持；**(A44) 控制性**：CBF/QP 投影对力矩盒与摩擦锥可靠。则：(i) 力矩路径承诺失效率 ≤ δ_f+δ_τ(β_τ,N_eff)+δ_graph(C)+ε_h+δ_ood·α_conf；(ii) **共模不可辨识命题**——若不借助独立通道，任何"信念正确 ∧ 包络安全"的联合保证都无法在 β_τ 无界时成立，因为两者是同一偏置的函数，错误自洽到无法被内部残差看见；(iii) 单调性扩展为三通道：新机制只能经"信念更准""动作更保守""动作更顺应"影响系统；(iv) 在 B_τ 有限下 TCE 终止。

部署界：

```
P_safe ≥ 1 − Σ_cp(δ_f + δ_τ + δ_graph + δ_probe + ε_h + δ_ood·α_conf)
             − P(漂移未检出：β_τ>Δ_robust) − P(CBF 数值失败) − P(修正震荡)
```

关键：**力矩给密度与执法，图谱给可审与可修**；免费监听压不确定、付费触诊升级边、开放世界守住"未知不许走"；而共模风险被单独列成一条不可被内部证据消解的命题——它必须由外部校准通道负责。

## 6. 本轮最大风险

**一句话**：本轮把"证据"与"执法"压进同一个力矩模型——最大的风险不是坏先验普遍，而是**共模接地失效**：当负载、温漂或摩擦老化让力矩标定悄悄偏移，知识图谱的物理事实与阻抗包络会朝同一错误方向移动，系统得到一个自洽却虚假的证书；必须以独立校准通道、残差看门狗与"不确定即退顺应限幅"三重护栏，把安全的一部分押在"不依赖信念正确性"的物理顺应性上。

## 2. 关键算法伪代码

### IP-139 TGP（常开力矩探针）

```python
def torque_probe(x, M, r):
    tau_hat = inverse_dynamics(x.q, x.qd, x.qdd) + friction_ff(x.qd, x.T)
    r_tau   = x.tau_meas - tau_hat                 # 含接触力 + 未建模扰动
    F       = pinv(jacobian(x.q).T) @ r_tau        # 接触力估计
    if not in_stance(x):                            # 摆动相无接触
        return TorqueProbe(sig=None, residual=r_tau, n_eff=0.0)
    sig = estimate_signature(x, F)                 # k_s=ΔF_n/Δz; mu≈|F_t|/F_n at slip
    n   = effective_sample_size(x.tau_hist, K=stance_len(x))
    return TorqueProbe(sig=sig, F=F, residual=r_tau, n_eff=n,
                       cal=ece_torque(x.calib))    # 外部力台校准

def effective_sample_size(series, K):
    rho = [autocorr(series, k) for k in range(1, K + 1)]
    return max(1.0, len(series) / (1.0 + 2.0 * sum(rho)))   # 保守折算
```

### IP-140 TKG（地形知识图谱）

```python
class TerrainKG:
    def query(self, r, gait):                      # 点查询：区域→步态
        path = self.grounded_path(r, gait, max_hop=self.d_G)
        if path is None or any(self.edge(e) is None for e in path):
            return QueryResult(unknown=True)        # 开放世界：缺失=未知
        return QueryResult(theta=project_intervals(path),
                           path=path, conflicts=self.conflicts(r))

    def conflicts(self, r):
        # 同一 (实体,属性,有效期) 上区间不相交的边
        return self.index.disjoint_interval_groups(r)

    def conservative(self, r):                      # 未知/冲突未决 → 物理下界
        return Theta(mu=self.mu_lo, F_bear=self.F_lo, k=self.k_lo)

    def attach_intervention(self, r, sig, probe):
        e = Edge(head=self.surface(r), rel='torqueSig', val=sig,
                 prov=Prov('intervention', probe.id, t_now, version=self.ver),
                 valid=probe.validity)
        self.add(e)
```

### IP-141 TIS（力矩-阻抗安全壳）

```python
def torque_envelope(theta, gait, v, limits):
    Fn   = min(theta.F_bear.lo, actuator_normal_limit(gait))
    Ft   = theta.mu.lo * Fn                         # 最坏摩擦锥
    wreq = required_wrench(gait, v)                 # 维持该步态所需旋量
    box  = torque_box(limits)                       # [tau_min, tau_max] + 热预算
    tau_set = polytope_intersect(box, cone_preimage(Fn, Ft), thermal(theta))
    robust  = (wreq.n <= Fn - delta) and \
              (wreq.t <= Ft - delta) and nonempty(tau_set)
    return Envelope(Fn, Ft, tau_set, robust)

def cbf_project(tau_des, env, x):
    if feasible(tau_des, env, x):
        return tau_des
    # 最小修正：min ||tau - tau_des||^2_W  s.t. tau∈box, J^{-T}tau∈cone
    return solve_qp(H=W, f=-W @ tau_des,
                    A=env.constraints(x), b=env.bounds(x), warm_start=x.tau_prev)

def compliance_floor(env, theta_uncertain):
    # 不确定性大 → 降低刚度、提高阻尼；接触力上界不依赖 theta_hat 正确
    return Impedance(kp=lerp(kp_min, kp_max, 1 - theta_uncertain),
                     kd=lerp(kd_max, kd_min, 1 - theta_uncertain))
```

### IP-142 TBR（力矩接地信念修正）

```python
def grounding_revise(G, edge, ev):
    if ev.type == 'intervention' and ev.replicated >= n_int:
        G.promote(edge, source='intervention')      # prior → intervention
    elif ev.falsifies(edge):
        C = G.conflicts(edge.head)
        # AGM 收缩：按出处可信序 + 时间序，撤回极小冲突集
        R = agm_minimal_retract(C, order=lambda e: (-trust_rank(e.src), -e.t))
        G.remove(R)
        G.attach(ev.negative_evidence)              # 负证据回写历史探针
        G.audit(drop=R, trigger=ev, version=G.ver.bump())
    else:
        G.attach(ev)
    return G

def trust_rank(src):
    return {'prior': 0, 'observation': 1, 'intervention': 2, 'human': 3}[src]
```

### IP-143 TJE（力矩理由证据门 + J_t）

```python
def torque_evidence_gate(c, M, G, persona, env):
    if c.ev == 'EV-torque':
        q = G.query(c.r, c.gait)
        ok = (c.probe.n_eff >= N_min(c.theta)) and \
             (c.probe.cal <= eps_tau) and \
             (not q.unknown) and (not q.conflicts) and \
             (not contradicts(q.theta, c.probe.sig))
    elif c.ev == 'EV-probe*':
        ok = round57_probe_check(c) and not unresolved_conflict(G, c.r)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and round57_xmodal_check(c)
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth >= 'A1' and round57_human_check(c)
    elif c.ev in ('EV-visit', 'EV-margin'):
        ok = round57_checks(c, M)
    else:
        return ('reject', 'no_evidence_class', c)
    if not ok:
        return ('reject', 'evidence_insufficient', c)

    Jt = justification_subgraph(G, c.r, c.action)   # 最小连通理由子图
    if not Jt.connected or Jt.has_unresolved_conflict:
        return ('reject', 'justification_gap', Jt)
    if c.irreversible:
        # 不可逆接触：关键边必须由 intervention/human 支持和包络稳健
        if not all(trust_rank(G.edge(e).src) >= 2 for e in Jt.critical):
            return ('reject', 'prior_only_on_irreversible', Jt)
        if not env.robust:
            return ('reject', 'envelope_not_robust', Jt)
    return ('ok', Jt)

def justification_subgraph(G, r, action):
    # r → surface → material → (friction/stiffness) → gait → constraint → evidence
    return G.minimal_connected_subgraph(
        terminals=[r, action.gait, *action.constraints],
        include_types={'frictionIn', 'stiffnessIn', 'supportsGait',
                       'requiresEvidence', 'torqueSig'},
        max_hop=G.d_G)
```

### IP-144 TCE（探-控-诺-演）

```python
def probe_control_commit_evolve(x0, M, G, task, budget, personas):
    route = plan_on_graph(G, task)
    for cp in route.checkpoints:
        pr = torque_probe(x0, M, cp.region)                 # ①常开探针
        M.b[cp.region] = fuse(M.b[cp.region], pr, w=pr.n_eff)
        q   = G.query(cp.region, cp.gait)                   # ②图谱查询
        th  = G.conservative(cp.region) if q.unknown_or_conflict else q.theta
        env = torque_envelope(th, cp.gait, cp.v, x0.limits)

        while (not env.robust or q.conflict) and budget.torque > 0:   # ③触诊
            cands = palpation_candidates(cp, G, env)        # 法向默认；切向仅 L1+裕度
            p = argmax(cands, key=lambda p: voi_tau(p) - lam * p.cost)
            if voi_tau(p) < theta_voi or p.cost > budget.torque:
                break
            sig = torque_palpation(x0, p, F_max=env.Fn)     # do-干预
            M.b[cp.region] = fuse(M.b[cp.region], sig, w=sig.n_eff)
            G.attach_intervention(cp.region, sig, p)
            q   = G.query(cp.region, cp.gait)
            th  = G.conservative(cp.region) if q.unknown_or_conflict else q.theta
            env = torque_envelope(th, cp.gait, cp.v, x0.limits)
            budget.spend(p.cost)

        lv = contact_level(cp)
        if env.robust and torque_evidence_gate(
                core_contact(cp), M, G, personas, env)[0] == 'ok':
            commit_with_cbf(cp.gait, env, compliance_floor(env, th.width))  # ④承诺
            continue

        alt = reroute_on_graph(G, cp)                       # ⑤重路由/降档/协商
        if alt and envelope_ok(alt, G):
            route = alt; continue
        return negotiate_or_stop(cp, G, env, tau_int(personas.active.auth))
    return route, M, G

def palpation_candidates(cp, G, env):
    out = [NormalPulse(region=cp.region, amplitude=min(env.Fn, F_palp))]
    if cp.level == 'L1' and env.margin > delta_slip:
        out.append(TangentialPulse(region=cp.region, amplitude=env.Ft * 0.8))
    return out
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TGP | O(n²)+O(H_stance)/检查点 | O(H_stance) | N_eff 保守上界、ECE_τ 声明诚实（A42） |
| TKG | O(d_G·deg) 查询；O(\|C\|log\|E\|) 修正 | O(\|E\|) | 开放世界缺省保守、修正极小（A43） |
| TIS | 稀疏 QP；最坏 O((n+m)³) | O(n+m) | 摩擦锥/力矩盒/热预算不可越（A44） |
| TBR | O(\|C\|·log\|E\|) | O(\|E\|) | AGM 收缩、审计完备 |
| TJE | O(\|J_t\|) | O(\|J_t\|) | 无关键边即拒、理由子图连通 |
| TCE | O(\|CP\|·(H + k_p·(d_G+C_VOI)) + B_τ/c_min) | O(\|V\|+\|E\|) | 预算有限 ⇒ 终止、四态完备 |

**正确性定理（Torque-Grounded Soundness, TGS）**
假设 A22–A40 成立，并加：**(A41) 接地性**：力矩模型偏置 |β_τ|≤β_max，且由独立通道（外部力台、负载辨识、关节力矩传感器）周期性审计，β_max≤Δ_robust/2；**(A42) 采样性**：N_eff 为自相关保守上界，证据独立性仅对干预样本声明；**(A43) 图谱性**：开放世界缺省保守，修正最小且按出处序，不可逆接触关键边必须 intervention/human 支持；**(A44) 控制性**：CBF/QP 投影对力矩盒与摩擦锥可靠。则：

1. **力矩路径承诺健全性**：
   `P(fail) ≤ δ_f + δ_τ(β_τ, N_eff) + δ_graph(C) + δ_probe + ε_h + δ_ood·α_conf`
   其中 δ_τ 随 N_eff 增大单调不增，δ_graph 由冲突未决率与开放世界覆盖率刻画。
2. **共模不可辨识命题**：若 β_τ 无界且无独立通道，则不存在仅用力矩残差构造的检验能同时保证"信念正确"与"包络安全"——因为推断 θ̂=θ+β_θ 与包络 ℰ(θ̂) 共享同一偏置，未检出的不安全集 {θ∉Θ_safe : θ+β∈Θ_safe} 在内部不可观测。故 A41 的独立校准是**充分性前提而非装饰**。
3. **三通道单调性**：TGP/TKG/TIS 只能经 (a) 校准信念更新（含加宽/未知保守）、(b) 更保守的动作参数（步态降档、禁不可逆、触诊限制）、(c) 更顺应的阻抗（k_p↓k_d↑，接触力上界与信念解耦）影响系统；不存在升险路径。
4. **终止性**：每次触诊 cost_τ≥c_min>0 且 B_τ 有限 ⇒ 每检查点触诊步数 ≤ B_τ/c_min；共识探针沿用第 57 轮 k_cons；TCE 终止于 {承诺, 图重路由, L2 协商, 安全停}。
5. **部署界**：

```
P_safe ≥ 1 − Σ_cp (δ_f + δ_τ + δ_graph + δ_probe + ε_h + δ_ood·α_conf)
             − P(β_τ > Δ_robust，漂移未检出)
             − P(CBF 数值失败) − P(修正震荡)
```

关键：**常开力矩给密度、付费触诊给精度、知识图谱给可审与可修、阻抗包络给物理执法**；四者职责分离，唯一的强耦合——观测与执行共用同一力矩模型——被显式列为共模命题，交由独立校准通道兜底。

## 6. 本轮最大风险

**一句话**：本轮把"证据"与"执法"压进同一个力矩模型——最大风险不是坏先验普遍，而是**共模接地失效**：负载、温漂或摩擦老化使力矩标定悄悄偏移时，知识图谱的物理事实与阻抗包络会朝同一错误方向移动，系统得到一个自洽却虚假的证书；必须以独立校准通道、残差看门狗与"不确定即退顺应限幅"三重护栏，把一部分安全押在"不依赖信念正确性"的物理顺应性上。
