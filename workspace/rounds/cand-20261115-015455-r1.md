# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；本轮灵感：「运动规划」×「深度相机」）

> R69 把不确定性一分为二：aleatoric 收紧、epistemic 去问，并用 k-正交证据纪律约束「问」。但它仍藏着两个未言明的前提：
> **(P1) 决策的差异可以用轨迹距离度量**——它用 DTW/Fréchet 聚类流采样，把「两条轨迹离得多近」当作「是不是同一个决定」；
> **(P2) 几何世界是背景板**——深度只是又一路残差，空间是连续的、可微的、不参与决策结构。
>
> 本轮两个灵感正好拆掉这两个前提：
> - **运动规划**告诉我们：机器人真正的决定不是「关节走哪条曲线」，而是「**绕过障碍的哪一侧**」——决策的度量是**拓扑**，不是距离。薄墙两侧的两条轨迹可以任意接近，却是完全不同的决定；同一个同伦类里的两条轨迹可以差得很远，却是同一个决定。
> - **深度相机**告诉我们：自由空间不是给定的，而是**测出来的**。而且它的误差有确定的几何——三角化深度误差 \(\sigma_z \approx z^2\sigma_{disp}/(fb)\)，基线 \(b\) 越大越准；更关键的是，它会在玻璃、镜面、细线、强吸收表面**结构性地失明**。
>
> 核心命题：**把 epistemic 再拆成「拓扑决策歧义 U_epi^topo」与「执行抖动 U_ale^exec」，用相对深度障碍场的同伦类取代 DTW 聚类；再单列第三类「结构失明 U_struct」，其算子既不是收紧也不是提问，而是换视点/换模态或弃权。并把「运动」升级为最重要的信息动作：为看清决定性门而规划一条视差路径（parallax），在认证观测前沿内「先看后走」。** 命名 **PARALLAX-RAS**（Parallax-Active Resolution of Ambiguity via Lookahead And eXploration）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「该向谁求证」，R70 问「**世界在哪一侧、我走过去能否看清**」——不确定性不只是一句提问，也可以是一条为了看清而走的路线。

## 0. 直觉与动机

**灵感 1（运动规划 → 决定住在同伦类里，不住在距离里）**
直觉：人走到岔口犹豫「绕左还是绕右」，不是两条关节轨迹的欧氏距离大，而是它们属于**不同的同伦类**。反过来，同一条绕左的路，这次走得快、那次走得慢、肩膀抖了一下，轨迹距离可以很大，但决定没变。R69 用 DTW 聚类，等于用一把「形状尺」去量「决定」：薄墙两侧会被合并（距离小），同一侧的抖动会被拆开（距离大）。这把 U_epi 与 U_ale 的边界画错了——它会把执行抖动误报成需要求证的歧义，也会把真正的拓扑分歧藏进「同一个模态」。运动规划提供的正确对象是**配置空间 + 障碍 + 同伦类**：同伦标签对重参数化、时间缩放、执行抖动不变，只对「走哪一侧」敏感。

**灵感 2（深度相机 → 误差有几何，所以歧义可以被预测）**
直觉：R69 的 FMA 是**事后**看动作似然高不高；深度相机给出的是**事前**的物理先验。三角化深度噪声 \(\sigma_z(z,b)\approx \alpha z^2/(fb)+\beta\) 随距离平方增长、随基线平方下降。于是「在这个视点、这个距离上，几何本来就该有多模糊」是可以算出来的。若观测到的同伦歧义约等于这个预测值，那它是**几何/噪声的必然**，再问也问不出来，应当收紧；若远超预测值，那才是 epistemic——新几何、标定残差或故障。这把 R69 的「模态权重是否可信」从纯统计校准（ECE）升级为**有物理锚点的校准**，正面回应 R69 自陈的最大风险：幻影模态没有对应的几何门，深度可以先验地否决它。

**灵感 3（深度相机 → 结构性失明是第三类不确定性）**
直觉：玻璃让深度返回「前面什么都没有」，镜面把障碍折叠到假位置，黑色海绵和细线直接丢返回。这不是零均值噪声（不是 aleatoric），也不是「问一句就能解决」的歧义（不是普通 epistemic）——是**传感器的模型形式错了**。R69 的二分账本没有格子放它，于是会把它误当噪声而收紧（没用），或误当歧义去提问（危险）。本轮单列 U_struct：它的消解算子是**换视点（避开镜面反射角）、换模态（主动照明/偏振/事件/触探）或明确弃权**。更重要的是：一旦决定性门落在结构性失明区，整个「深度物理先验」失效——这是本轮必须诚实写下的边界。

**灵感 4（运动即探询 → 视差是最便宜的信息动作）**
直觉：R69 的信息动作（注视、探针、问句）都是局部的、瞬时的。但改变视点能同时获得三样东西：**基线**（深度变准，\(\sigma_z\propto 1/b\)）、**遮挡揭示**（绕到侧面看见门后）、**同伦消歧**（看见薄墙到底连不连）。这是决策驱动的 next-best-view：不是为了重建整个三维世界，而是为了**降低同伦后验熵**。于是 VoI 从「选一个信息动作」变成「选一条信息路线」，其收益可以按几何精确估计，其成本是路程、时间与风险。

**灵感 5（先看后走 → 信息运动必须被安全认证，且要能退化）**
直觉：为了看清而靠近未知区域，本身就是风险。运动规划给出一条硬纪律：**绝不把「未知」当「自由」规划过去**。要穿过当前未知或遮挡的同伦类，必须先从认证观测前沿（COF）把它看清，或由第二正交模态确认；否则改选已认证的类，或退回 R69。这样「移动去看」不会把系统从保守变成冒险；失败、超时、结构失明时，它逐指令退化为 R69。

**灵感 6（对 R69 最大风险的正面回应，及其边界）**
R69 怕的是「在错误的模态分布上自信地追问幻影」。本轮给两把新尺子：**(i) 几何可行性**——幻影模态在深度障碍场里没有可通行路径，直接否决；**(ii) 预测歧义差 \(A_{exc}=A_{obs}-A_{geo}^{pred}\)**——歧义若不能由深度噪声解释，才值得动作。但这两把尺子都以「深度是对的」为前提。玻璃正好让这个前提失效，所以本轮的最大风险也随之换位：**不是问错，而是把盲目当成确信**。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（深度几何世界模型 DGM）** 深度观测 \(D_t=\{(u,z(u),\mathrm{valid}(u),\sigma_z(u))\}\)，反投影得点云 \(P_t\)；体素占据后验 \(O:\mathbb{R}^3\to[0,1]\)，三态空间：自由 \(F=\{x:O<\varepsilon_f\}\)、障碍 \(X_{obs}=\{x:O>1-\varepsilon_o\}\)、未知 \(X_{unk}\) 为其余。轴向噪声模型 \(\sigma_z(z,\theta)=\alpha z^2/(fb)+\beta\)，横向 \(\sigma_{xy}\approx z\sigma_{pix}/f\)。膨胀半径 \(\rho(z)=k_\sigma\sigma_z(z,\theta)+\rho_{robot}\)。配置空间障碍 \(C_{obs}=\{q:\mathrm{FK}(q)\cap(X_{obs}\oplus\rho)\neq\varnothing\}\)，\(C_{unk}\) 同理。

**定义 311（同伦类标定 HCL）** 固定起终点，路径 \(\xi\subset C_{free}\) 的同伦类 \(h(\xi)\) 由与一组「门/割」的交叉签名定义（2D 用绕障碍物的绕数向量；3D 用 \(H_1\) 的 h-signature，或实用版的**门序列表**）。\(h\) 对重参数化、时间缩放、执行抖动不变，只对「走哪一侧」敏感。

**定义 312（同伦感知动作分解 HAD）** 对 \(K\) 个流采样 \(\{\xi^{(j)}\}\) 按 \(h_j\) 分组，得同伦类权重 \(\hat w_h\)、类内原型与协方差 \(\Sigma_h\)：
\[
U_{ale}^{exec}=\sum_h \hat w_h\,\mathrm{tr}(\Sigma_h)\quad(\text{类内执行抖动，不可约})
\]
\[
U_{epi}^{topo}=H(h)\cdot g(\Delta_h),\qquad H(h)=-\sum_h\hat w_h\log\hat w_h\quad(\text{类间决策歧义，可约})
\]
其中 \(\Delta_h\) 为决策距离（定义 313）。**R69 的 \((U_{ale},U_{epi})\) 是本定义在「所有样本同属一个同伦类」时的退化**：此时 \(U_{epi}^{topo}=0\)，\(U_{ale}^{exec}\) 对应其类内方差；DTW/Fréchet 聚类被同伦标定替代。

**定义 313（决策距离与同伦稳定裕度）** \(D_{decision}(h_i,h_j)=\min\) 两类之间切换路径的（路程 + 风险 + 间隙亏欠），或用门的最小间隙与绕行代价近似。稳定裕度 \(\mu_h=\min_{\xi\in h}\mathrm{clearance}(\xi,C_{obs}\oplus\rho)\)。若执行跟踪误差上界 \(e_{max}<\mu_h\)，执行不改变 \(h\)（引理 22）。

**定义 314（深度预测歧义先验 DAP）** 给定视点 \(v\) 与 DGM，按深度噪声模型做蒙特卡洛/解析传播，得同伦后验熵的**期望下界** \(A_{geo}^{pred}(v)\)（「仅由传感器噪声就该有的歧义」）。观测歧义 \(A_{obs}=H(h\mid o_t)\)，超出量
\[
A_{exc}=\max(0,\;A_{obs}-A_{geo}^{pred}(v)).
\]
判据：\(A_{exc}\approx 0\Rightarrow\) 歧义可由几何/噪声解释，按 aleatoric 收紧；\(A_{exc}\gg 0\Rightarrow\) epistemic（新几何/标定/故障）。**幻影模态判据**：若某流模态在 \(C_{free}\)（含 \(\rho\) 膨胀）中无可行路径且不被深度支撑，判为 phantom，禁止据此交互。

**定义 315（视差信息增益 PIG / 运动 VoI）** 候选信息运动 \(\xi_g\)（到视点 \(v'\)，基线 \(b\)，路径在 \(C_{free}\)）：
\[
VoI_m(\xi_g)=H(h\mid o_t)-\mathbb{E}_{D'\sim p(\cdot\mid\xi_g)}\big[H(h\mid o_t,D')\big],
\]
选 \(g^*=\arg\max[VoI_m(\xi_g)-c_{move}(\xi_g)]\)，s.t. \(P(\text{collision})\le\delta\) 且终点 \(\in\) COF。几何标度：\(\sigma_z\propto z^2/(fb)\)，故增大 \(b\) 使深度不确定度按 \(b^{-2}\) 下降（引理 20）。

**定义 316（认证观测前沿 COF）** \(COF_t=\{q\in C_{free}:\exists\) 认证路径 \(q_t\to q\)，且从 \(q\) 对目标未知区满足可视与基线 \(b\ge b_{min}\}\)。信息运动只允许终点落在 COF；任务运动不得进入 \(C_{unk}\)（除非另有正交模态确认）。

**定义 317（先看后走 / 认知刹车）** 对任何要穿过当前 \(C_{unk}\) 或遮挡区的任务同伦类 \(h\)，必须先执行信息运动使其**决定性门**被观测到且可通行（自由概率 \(\ge 1-\delta_o\)），或由第二正交模态确认；否则不得提交该 \(h\)，改选已认证的 \(h'\)，或退化为 R69。记拓扑提交规则 \(\mathrm{commit}(h)\) 仅在 \(\mathrm{evidence}(\text{decisive\_gate}(h))\) 满足定义 319 时成立。

**定义 318（结构性深度失效 U_struct）** 透明/镜面/强吸收/细线/超量程使深度似然非单峰或有偏（无效返回、multipath、错误平面）。定义失效掩码 \(M_{bad}(u)\) 与区域级「几何不可判」标记。\(U_{struct}\) 既非 aleatoric（不是零均值噪声），也非可由「问人」解决的 epistemic；其消解算子是**换视点/换模态（主动照明、偏振、事件、触探）或明确弃权**。凡决定同伦类的那道门落在 \(M_{bad}\)，该 \(h\) 视为未认证。

**定义 319（决定性门证据纪律 DEA）** 只对「决定性门」（改变 \(\arg\max h\) 或使后验熵下降 \(\ge\tau_{dec}\) 的门）要求证据：至少两个正交视角（基线差 \(\ge b_{orth}\)）或两个正交模态一致；单次观测/单视角不得定案。把 R69 的 k-正交证据纪律从「人/语言」推广到「几何/视角」。

**定义 320（三元不确定性账本 TUL）** 三类：\(U_{ale}^{exec}\)（收紧）、\(U_{epi}^{topo}\)（移动去看/交互）、\(U_{struct}\)（换模态或弃权）。算子不同，不做标量相加；任一类越界都走 R69 兜底。R69 是 \(U_{epi}^{topo}=0\wedge U_{struct}=0\) 的边界。

**定义 321（随时规划与路图复用）** 复用上一帧的 PRM/RRT* 路图并增量更新；同伦标定与 VoI 评估有硬预算 \(B_{plan}\)；超时返回当前最优可行解，或退化为「不移动」（R69）。

**定义 322（拓扑证书 J_PAR）** \(J_{PAR}=(J_{FLUID},h_{labels},\Delta_h,A_{geo}^{pred},A_{exc},b_{parallax},\rho_{inflation},COF_{ok},U_{struct}^{mask},decision\_log\_hash,parallax\_ver)\)。Valid \(\Leftrightarrow\) Valid\((J_{FLUID})\wedge A_{exc}\le\tau_{exc}\)（或已按 \(U_{struct}\) 弃权）\(\wedge\) 决定性门证据纪律满足 \(\wedge\) 安全约束满足。

**定义 323（对 R69 的退化规则）** 若所有采样同属一个同伦类、深度结构有效、且无正 VoI 的认证信息运动，则 PARALLAX 逐指令执行 R69（FLUID），不引入任何新动作。

**定义 324（对抗深度模型 \(\mathcal{E}_{depth}\)）** 玻璃/镜面/强反光、深度欺骗（投影假图案）、遮挡共谋、动态场景破坏同伦不变性、边缘 flying pixels。并入 AIC：\(\mathcal{E}_{PAR}=\mathcal{E}_{FLUID}\times\mathcal{E}_{depth}\)。

**定义 325（拓扑审计 VQAuditor-T）** 审计：同伦标签是否正确、决定性门是否被真正观测、\(A_{exc}\) 是否被误用、是否在 \(M_{bad}\) 上「自信地自由」、信息运动是否越界；结论回灌路图先验与 MCG。

**定义 326（时序耦合）** 默认 \(K=1\)；mode_head 报歧义或 \(A_{exc}\uparrow\) 时升 \(K=4\) 并触发拓扑分解；规划器后台 anytime，主环只在预算内取用（复杂度见表）。

```python
class DepthGeometricWorld:
    def update(self, depth, pose):
        P = backproject(depth, pose, self.K)
        self.occ.integrate(P, sigma_z=self.sigma_z(depth, self.baseline))
        self.label()                          # free / obs / unknown
        self.C_obs = inflate(fk_obstacles(self.occ.obs), rho(depth))
        return self.C_obs, self.C_unk

    def sigma_z(self, z, b):                  # 三角化/ToF 近似
        return ALPHA * z * z / (self.f * max(b, B_MIN)) + BETA
```

```python
def homotopy_decompose(samples, world, roadmap):
    H = [roadmap.homotopy_label(clear_path(xi, world.C_free)) for xi in samples]
    groups = group_by(H)
    w = {h: len(g) / len(samples) for h, g in groups.items()}
    U_ale = sum(w[h] * trace(cov_within(groups[h])) for h in groups)
    U_epi = entropy(w) * g_sep(min_decision_distance(groups, world))
    stable = {h: clearance_margin(groups[h], world.C_obs) for h in groups}
    return U_ale, U_epi, w, groups, stable
```

```python
# IP-267/268：视差信息运动规划（决策驱动 NBV + 认证观测前沿）
def plan_parallax(world, h_post, budget, c_ras_wm):
    best = None
    for q in cof_samples(world, h_post, b_min=B_MIN):      # 认证观测前沿
        if not budget.allow_motion(q):
            continue
        path = world.roadmap.plan(current_q, q)             # anytime，复用路图
        if path is None or not in_free(path, world.C_free):
            continue
        voi  = H(h_post) - expected_homotopy_entropy(h_post, q, world)
        risk = occupancy_risk(path, world)
        if risk > EPS_INT:
            continue
        score = voi - c_move(path) - LAMBDA_RISK * risk
        if best is None or score > best.score:
            best = (path, q, score)
    return best if best and best.score > 0 else None       # 无利可图 → R69
```

## 3. 推导

**引理 19（同伦分解严格优于度量聚类）** 存在场景使类内 DTW 距离任意大（同一同伦类的大幅执行抖动），也可使类间距离任意小（薄障碍两侧、间隙 \(\epsilon\)）。故以 DTW/Fréchet 聚类估计决策后验不一致：\(U_{epi}\) 可高估（把执行抖动当决策分歧）或低估（把薄墙两侧合并），误差无界。同伦类对重参数化与抖动不变，只在「走哪侧」改变时改变 \(\Rightarrow\) HAD 在深度几何正确的条件下一致估计决策后验。系：R69 的 VoI 可能在错误后验上计算——去追问一个只是执行抖动的问题，却忽略真正的拓扑分歧。

**引理 20（视差—深度不确定度标度律）** 三角化深度误差一阶为 \(\sigma_z\approx z^2\sigma_{disp}/(fb)\)。故增大基线 \(b\)、降低距离 \(z\) 均使 \(\sigma_z\) 下降；对固定门，VoI 随 \(b\) 单调增（可见性不变前），边际收益 \(\propto 1/b^2\)。系：**信息运动的最优方向垂直于视线—门平面以最大化基线**——「该往哪走」有了几何答案，不必枚举。

**引理 21（深度先验作为流模态的物理校准）** 在噪声模型正确且无结构失效时，仅由深度噪声引起的同伦后验熵 \(\le A_{geo}^{pred}+\varepsilon_{model}\)。若 \(A_{obs}-A_{geo}^{pred}>\tau_{exc}\)，则在模型正确假设下该歧义不能由传感器噪声解释 \(\Rightarrow\) 存在 epistemic/故障/新几何。故 \(A_{exc}\) 是 R69 幻影模态的**低成本物理否决**（不需要人回答）。注意结论以模型正确为前提——这正引出引理 23。

**引理 22（同伦稳定性）** 若类内轨迹到 \(C_{obs}\oplus\rho\) 的最小间隙 \(\mu_h>e_{max}\)（执行跟踪误差上界），则执行不改变 \(h\)，同伦标签在闭环下稳定；否则应在类边界处降速/增大间隙，或将该类判为不稳定、不提交。

**引理 23（结构失效下物理先验失效——反例）** 玻璃/镜面/强吸收可令深度返回「空旷」或错误平面，使 \(C_{free}\) 错误地包含真实障碍。此时 \(A_{geo}^{pred}\) 与 \(h\) 标签都可被系统性欺骗：系统可能「自信地」选择穿过玻璃的 \(h\)，或把真实开口判为障碍。因此深度先验**不是**无条件第二意见；必须与 \(U_{struct}\) 掩码、第二模态（事件/触/主动照明/偏振）和 R69 的 k-正交纪律联用。**这是本轮最大风险的来源。**

**定理 18（PARALLAX 严格包含 R69）** 在 A99–A102 下，当 (i) 所有采样同属一个同伦类 \(h\)、(ii) 深度结构有效、(iii) 无正 VoI 的认证信息运动时，定义 323 使每一指令与 R69 相同；其余情形在 chance-constrained 安全与「先看后走」提交规则下，期望风险 \(\le\) R69。安全侧不让步，效率侧获得「移动即可消歧」的收益。

**定理 19（先看后走的未知障碍界）** 若信息运动终点 \(\in COF\) 且任务运动只提交已认证同伦类，则在深度有效时进入未观测障碍的概率 \(\le\delta\)；若深度结构失效且未被 \(M_{bad}\) 捕获，该界不成立——这是必须用第二模态兜底的假设。交互/运动失败或超时，系统按定义 323 单调退化为 R69，控制连续。

```python
# IP-264 DGM：三态世界 + 深度噪声几何
class DepthGeometricWorld:
    def update(self, depth, pose):
        P = backproject(depth, pose, self.K)
        self.occ.integrate(P, sigma_z=self.sigma_z(depth, self.baseline))
        self.label()                                    # free / obs / unknown
        self.C_obs = inflate(fk_obstacles(self.occ.obs), rho(depth))
        return self.C_obs, self.C_unk

    def sigma_z(self, z, b):
        return ALPHA * z * z / (self.f * max(b, B_MIN)) + BETA
```

```python
# IP-265 HAD：同伦类分解（替代 DTW）
def homotopy_decompose(samples, world, roadmap):
    H = [roadmap.homotopy_label(clear_path(xi, world.C_free)) for xi in samples]
    groups = group_by(H)
    w = {h: len(g) / len(samples) for h, g in groups.items()}
    U_ale = sum(w[h] * trace(cov_within(groups[h])) for h in groups)
    U_epi = entropy(w) * g_sep(min_decision_distance(groups, world))
    stable = {h: clearance_margin(groups[h], world.C_obs) for h in groups}
    return U_ale, U_epi, w, groups, stable
```

```python
    need_geo = (A_exc > TAU_EXC) or M.ustruct.hits_decisive(groups, bad)
    g = (M.mint.choose_interaction(groups, o, M.budget) if need_geo
         else M.pig.plan_parallax(M.dgm, w, M.budget, M.c_ras_wm))
    if g is not None and g.type == 'motion':
        w = M.dea.update_topological_belief(w, M.cof.certify_and_execute(g))
    elif g is not None:
        w = M.cia.update_belief(groups, M.cia.execute(g))
    slow = (M.fma.flow_anomaly(...) > TAU_FMA) and (M.last_r_res < TAU_RES)
    U_floor = U_ale + (U_epi if (need_geo and g is None) else 0.0)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    h = argmax_h(w)
    if not M.dea.commit_certified(h, groups, bad):        # 先看后走
        h = M.nea.safest_seen_class(groups)              # 只走已认证类
    k = M.c_ras_wm.certified_prefix(
        M.ach.propose(h, M.vista.H), ..., C_obs, C_unk)
    if slow:
        lam = max(lam, 0.8); k = min(k, k_cal_shrink(...))
    M.vqa_t.submit_async(w, A_exc, bad, g)
    return k, lam, h, (U_ale, U_epi, A_exc)
```

## 4. 推导

**引理 19（同伦分解优于度量聚类）** 类内 DTW 可任意大、类间可任意小（薄墙/窄隙），故 DTW 聚类对决策后验不一致、\(U_{epi}\) 误差无界；同伦类对重参数化与执行抖动不变 ⇒ HAD 一致（深度正确时）。系：R69 的 VoI 可能把执行抖动当歧义去问，却漏掉真拓扑分歧。

**引理 20（视差—深度标度律）** \(\sigma_z\approx z^2\sigma_{disp}/(fb)\)，增大基线 \(b\) 或减小距离 \(z\) 降低深度误差；对固定门，VoI 随 \(b\) 单调增（可见性不变前），边际收益 \(\propto1/b^2\)。系：最优信息运动方向垂直于视线—门平面。

**引理 21（深度先验作流模态物理校准）** 噪声模型正确且无结构失效时，纯噪声诱导的同伦熵 \(\le A_{geo}^{pred}+\varepsilon_{model}\)；若 \(A_{exc}>\tau_{exc}\)，则该歧义不能由噪声解释 ⇒ epistemic/故障/新几何。故 \(A_{exc}\) 是幻影模态的低成本物理否决。前提是模型正确（见引理 23）。

**引理 22（同伦稳定性）** 若 \(\mu_h>e_{max}\)，执行跟踪不改变同伦类，标签闭环稳定；否则降速/增间隙或判为不稳定不提交。

**引理 23（结构失效下物理先验失效——反例）** 玻璃/镜面/强吸收可使 \(C_{free}\) 错误包含真实障碍，\(A_{geo}^{pred}\) 与 \(h\) 同时被系统性欺骗。深度先验不是无条件第二意见，必须与 \(U_{struct}\)、第二模态、R69 的 k-正交纪律联用——这是最大风险来源。

**定理 18（PARALLAX 严格包含 R69）** 单一同伦类 + 深度有效 + 无正 VoI 认证运动时，定义 323 使每指令与 R69 相同；其余情形在 chance-constrained 安全与先看后走规则下期望风险 \(\le\) R69。安全不让步，效率获「移动即消歧」收益。

**定理 19（先看后走安全界）** 信息运动终点 \(\in COF\)、任务只提交已认证同伦类时，进入未观测障碍概率 \(\le\delta\)（深度有效）；深度结构失效且未被 \(M_{bad}\) 捕获时该界不成立——必须第二模态兜底。失败/超时按定义 323 单调退化 R69，控制连续。

## 7. 本轮最大风险

**一句话**：全部拓扑收益押在「深度给出的自由空间是真的」上——**当玻璃、镜面、细线让深度在决定性门上系统性失明时，\(A_{geo}^{pred}\) 与同伦标签会一起错，系统会以「物理先验」的名义自信地穿过看不见的障碍，或否掉真实开口；把盲目误当确信，比 R69 的问错更危险。**

**次级风险与缓解**：规划延迟（后台 anytime + 路图复用）；sim2real 噪声偏差（在线辨识 + E309）；同伦组合爆炸（只保留决定性门）；动态障碍破坏同伦不变性（短时冻结 + 速度障碍补丁）；信息运动越界（COF + chance-constrained + 单调退化）；\(A_{exc}\) 阈值误用（与 ECE/FMA/\(M_{bad}\) 联合判定，单信号不定案）。
