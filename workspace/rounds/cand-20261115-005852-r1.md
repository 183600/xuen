# 第 3 轮（灵感循环第 3 轮；本轮灵感：「MuJoCo」×「运动控制」）

> **基线继承**：第 2 轮 **ToolGauge**（IP-315–320；定义 416–431；引理 46–50；实验 E426–E440），
> 其下依次为 LeanGauge、MODGAUGE。本轮纪律仍是"在前人基础上改进，而不是推倒重来"。
> 但这一轮要动的是更底层的东西：ToolGauge 把探测变成了契约化工具调用，却仍把探测当成**准静态观测**——
> `Pre_t` 是"某一时刻的快照"，回执是"一次读数的 (μ,σ)"，校准把同一回合的回执当独立样本。
> 在接触丰富（contact-rich）的计量场景里，这三点同时失效：探测是**运动**，运动**改变世界**，
> 而 MuJoCo 与运动控制恰好提供了处理"运动—接触—世界变更"这三件事的成熟语言。

**一句话版本**：探测不是读数，是接触干预；MuJoCo 只能**否决**、不能**担保**；
运动控制负责让干预**可辨识、可逆、可抢占**。

## 双灵感映射（两个词，三条升级轴）

| 灵感 | ToolGauge 的隐含假设 | 升级为 | 动机 |
|---|---|---|---|
| MuJoCo | `Pre_t` 是解析/启发式物理包络，"差不多就行" | **S-Box 排练箱**：在共形接触参数集 Δ̂ 上做鲁棒排练；模拟只作**证伪器**，不作真值 | 接触模型必然错；错误模型不能"证明安全"，只能"找出不安全" |
| 运动控制 | 探测 = 离散工具调用 (t,a)，开环、无动力学 | **M-Box 信息 MPC**：探测是带反馈的轨迹，用信息增益 + 接触持续激励（CPE）合成激励 | 有些参数只在特定接触模态下可辨识：不滑动就测不出摩擦，不加卸载不测出刚度 |
| 运动控制 × MuJoCo | 观测不改变状态；回执可交换 | **W-Box 世界变更账本**：接触即干预，观测算子非交换；引入不可逆预算与可逆性证书 | 探测会压、刮、推倒物体；"局部修复"必须建立在"世界没有被改坏"之上 |

**核心命题**：把 ToolGauge 的「准静态工具调用」升级为
「**可排练的接触激励回合**（rehearsable contact-excitation episode）」：
MuJoCo 只在共形接触不确定性下**否决**不安全/不可辨识的回合，
运动控制只在硬安全约束与主任务优先级下**合成并执行**激励，
数值真值仍由计量层独占；每一次物理交互都留下"世界变更账本"，
热替换只有在"可逆性证书"通过时才被允许。

**为什么这不是又一次模块堆叠**：三条升级轴被同一个新的观测模型耦合在一起——
`y = O(x,u,θ,c)`，其中动作 `u` 同时产生信息并改变 `x`。这不是三个工程补丁，
而是把第 2 轮默认的"可交换、状态无关、无副作用观测"替换为"顺序相关、状态耦合、可能不可逆的干预"。
由此，第 2 轮的两条核心论证（独立样本校准、局部热替换）必须被**条件化**而不是被丢弃。

**不变式处置表**（本轮最需要诚实的地方）：

| 不变式 | 处置 | 理由 |
|---|---|---|
| 契约完整性 | **保持并扩展**（定义 442：回执增加 δx、∫w、接触模态） | 字段变多，但校验仍可判定 |
| 组合单调性 | **条件化**：仅可逆/非干扰子图保持；一般情形升级为"顺序感知组合"（定义 440、引理 54） | 接触观测算子非交换，朴素单调性可被反例击穿 |
| 反作用通道完备 | **加强**：从"机器人受力反作用"扩展到"物体世界状态变更"（定义 435） | 探测的副作用第一次被显式记账 |
| 主张绑定 | **保持**（定义 442；证书增加轨迹与账本） | 语言仍不进入数值通道 |
| 严格退化链 | **延长**：MoCoGauge → ToolGauge → LeanGauge → MODGAUGE（定义 446） | 仿真与运动控制是增强项，不是依赖项 |

## 0. 直觉与动机

### 0.1 直觉一：探测是运动，不是读数

在接触丰富场景里，"测量"本身就要施加力：测刚度要加载—卸载，测摩擦要滑动，测质量分布要敲击或抖动，
测表面形貌要刮擦或滚动。信息不在某个瞬时读数里，而在**整条轨迹对激励的响应**里。
开环工具调用（第 2 轮的 `Π_s = ((t₁,a₁),…)`）有两个致命问题：
(a) 它无法维持"充分激励"——接触一旦丢失或提前粘着，参数就不可辨识；
(b) 它无法在接触状态变化时反馈补偿——同一个 `illum.sweep` 在自由空间与接触面上是完全不同的实验。
运动控制的语言恰好对症：**持续激励（persistent excitation）**回答"这条轨迹能否辨识参数"，
**滚动时域控制（MPC）**回答"下一步施加什么激励最有信息"，**阻抗/导纳切换**回答"接触时如何既稳住又不僵死"。

### 0.2 直觉二：MuJoCo 是证伪器，不是神谕

MuJoCo 的接触模型（库仑锥、恢复系数、软约束、执行器延迟）在真实世界里必然有偏差。
把 MuJoCo 当"真值"会重演第 1 轮最怕的错误：在一个自信但错误的世界里做组合。
但逻辑上有一个**单边**的用法是可靠的：如果某个探测回合在**所有**校准过的接触参数下都不安全、
或都不可辨识，那么它在真实世界里大概率也不安全/不可辨识——于是可以**否决**它。
反过来，"在仿真里安全且有信息"推不出"在真实里安全且有信息"。
所以 S-Box 是一个**拒绝器（rejector）**，不是**许可器（licenser）**。
第 2 轮的共形校准（定义 422）正好可以复用来构造接触参数集 Δ̂：给"仿真—真实"配对 rollout 打分，
取 1−β 分位，得到有覆盖保证的 Δ̂。这把"sim-to-real gap"从一句免责声明变成一个可测量的集合。

### 0.3 直觉三：接触即干预，世界会被改坏

准静态观测的世界观是"看了但不碰"。接触探测的世界观是"碰了就会留下痕迹"：
塑性变形、磨损、材料转移、翻倒、失稳。更要命的是**非交换性**：
先压再滑，与先滑再压，得到的是不同的回执，也会把物体带到不同的状态。
第 1 轮"局部修复、误差局部化"的安全论证，隐含前提是"修复过程不改变被修复对象所在的状态"。
一旦探测改变状态，这个前提就破了：一个正确的局部修复可能因为物体已被压凹而变成全局错误。
所以必须引入**世界变更账本**（每条回执附带 δx 与 ∫w dt）、**不可逆预算**（把"改坏多少"变成硬约束）、
**可逆性证书**（能否在 ε_rest 内复位），以及**状态一致的回撤**（状态变了，就撤销依赖旧状态的热替换）。
同时，探测动作与主任务共享执行器和 workspace——用**任务优先级 QP**把探测压到最低优先级、可随时抢占，
才谈得上"不破坏 50Hz 主线"。

## 1. 形式化定义（增量：定义 432–447）

**定义 432（探测回合 PE）** 回合 `e = (x₀, κ, H, Φ_term, b, Δ̂, B_irr)`：
- `x₀ ∈ 𝒳`：机器人—物体—接触联合状态（位姿、抓取、接触流形、估计的物体参数）；
- `κ: 𝒳×ℬ → 𝒰`：**反馈**策略（不是开环动作序列），ℬ 为信念空间；
- `H`：回合步数；`Φ_term`：测量完成/中止判定；`b`：待辨识目标（R 格子语义 + 参数子集 θ_S）；
- `Δ̂`：共形接触参数集（定义 439）；`B_irr`：不可逆预算（定义 435）。
执行产出轨迹 `τ = (x_{0:H}, u_{0:H-1}, w_{0:H-1})`、回执流 `ρ` 与世界变更账本 `L`。
ToolGauge 的 `Π_s` 是本定义在 `H=1、κ 常值、δx≡0、c≡stick` 下的退化特例。

**定义 433（接触耦合观测算子 CCO 与非交换缺陷）**
`y_t = O(x_t, u_t, θ, c_t) + ε_t`，`x_{t+1} = F(x_t, u_t, θ, c_t)`，
其中 `c_t ∈ 𝒞 = {stick, slip, impact, loss}` 为接触模态，`θ = (θ_S, θ_c)`，`θ_c = (μ, e, k, τ_a)`（摩擦、恢复、柔顺、执行器延迟）。
对两个激励 `a,b` 定义归一化非交换缺陷
`δ_ab(x) = ‖O_b(F_a(x)) − O_a(F_b(x))‖ / (‖O_b(F_a(x))‖ + ‖O_a(F_b(x))‖) ∈ [0,1]`，
并令 `δ(e) = max_{t,s} δ_{u_t u_s}(x_t)`。
`δ > 0` ⇒ 同一组回执的**顺序**携带信息；把它们当可交换样本会引入系统性偏差（引理 51）。
`δ = 0` 当且仅当观测与状态解耦、且接触可逆——这正是第 2 轮隐式假设成立的世界。

**定义 434（接触持续激励 CPE）**
设 `I_S(τ) = E[∇_{θ_S} log p(y_{0:H} | τ, θ) ∇^T_{θ_S} log p(·)]` 为 Fisher 信息。
称轨迹 `τ` 对 `θ_S` 是 `λ_exc`-CPE 的，若 `λ_min(I_S(τ)) ≥ λ_exc`。
例：`μ` 只有在 `slip` 模态且滑移速度非零时可辨识；`k` 只有在法向载荷有变化时可辨识。
CPE 是信息增益的**可辨识性前提**：不满足 CPE 的回合，即使贝叶斯增益预测很大也不得执行——
否则就是"在不可辨识方向上自信地收缩"，与第 1 轮"自信地组合错误世界"同构。

**定义 435（世界变更账本与不可逆预算 WCL/WCB）**
`Δx = x_H − x₀` 分解为可逆部分 `Δx_rev`（弹性、可复位）与不可逆部分 `Δx_irr`（塑性变形、磨损、材料转移、翻倒、失稳）。
不可逆度 `Irr(e) = ‖W_irr ⊙ Δx_irr‖₁ + α·1[¬settleable]`；
风险调整预算：`E[Irr(e)] ≤ B_irr` 且 `CVaR_β[Irr(e)] ≤ B_irr^max`。
WCL 记录每条回执的 `(δx_t, ∫w_t dt, c_t)`，并作为回执有效性的一部分（定义 442）。
这是对"反作用通道完备"的加强：不仅记录机器人受到的力，还记录物体被改变的状态。

**定义 436（可逆性证书 RC 与污染标签）**
`RC(e)` 成立 ⇔ 存在复位策略 `κ_rest`，使在 `τ_settle` 内到达 `x̂` 且
`‖x̂ − x₀‖_G ≤ ε_rest`（`G` 为任务相关度量），且复位过程满足同一安全包络。
`RC` 失败 ⇒ 回合标记 `CONTAMINATED`：其回执**可以**用于"当前状态"的校准，
但不得用于宣称"原状态"的性质；所有依赖原状态的热替换必须回撤（定义 444）。

**定义 437（信息 MPC / I-MPC）**
在每个规划步（滚动 H 步）求解
`max_{u_{0:H-1}} Î(θ_S; y_{0:H} | b, Δ̂) − λ_r CVaR_β(R_phys) − λ_w E[Irr] − λ_e Σ‖u_t‖²`
`s.t. x_{t+1} = F̂(x_t, u_t; θ̂, δ), δ ∈ Δ̂`（鲁棒或采样），
`u_t ∈ 𝒰, w_t ∈ 𝒲(μ̂)`（摩擦锥 + 法向力上界），
`λ_min(I_S(τ)) ≥ λ_exc`（CPE），
`Φ_term(x_H) ∧ RC 可行`。
`Î` 用 MuJoCo 可微 rollout 的 Fisher 信息/后验熵近似；接触不连续处用直通估计或有限差分。
注意：I-MPC 只在**候选集**内优化，它不能把 `RSA = 假` 的回合变成真的（定义 439、引理 52）。

**定义 438（安全滤波与任务优先级 QP / CBF-TP）**
分层 QP（每控制拍，约 1kHz）：
- 优先级 0：硬安全 `h_i(x) ≥ 0`（关节/力矩/力/工作空间/自碰撞），CBF 约束
  `L_f h_i + L_g h_i u + α_i(h_i) ≥ 0`；
- 优先级 1：主任务（50Hz 计量路径的动作）；
- 优先级 2：探测激励 `u_probe`，仅在优先级 0/1 的零空间内生效。
探测可在任意拍被主任务抢占；"工作空间租约"（workspace lease）保证同一时刻只有一个接触回合占用给定物体区域。
这把第 2 轮的 `PROBING` 显式态（定义 430）从"限幅 + 记录"升级为"可证明的任务优先级隔离"。

**定义 439（鲁棒排练与共形接触参数集 / RSA、Δ̂）**
预注册校准集 `{(仿真 rollout, 真实 rollout)}`，分数
`s(δ) = max_t ‖w_t^sim − w_t^real‖ / w_scale`（或参数后验残差），取 `1−β` 分位得到 `Δ̂`，
可交换性下 `P(δ* ∈ Δ̂) ≥ 1−β`；漂移下用加权共形（继承引理 48）。
`RSA(e) = 真` ⇔ 对 `Δ̂` 的角点 + 自适应采样 rollout，均满足：
wrench 包络、CPE、`Irr ≤ B_irr`、`RC` 可行。
**单向性**：`RSA(e) = 假 ⇒ 拒绝`（可靠）；`RSA(e) = 真 ⇒ 仅"可试"`，
**不**蕴含"物理上一定安全/有信息"（引理 52）。

**定义 440（顺序感知组合与交换缺陷；组合单调性的条件化）**
对子图 `G` 与回合序列 `σ = (e₁,…,e_m)`，组合算子 `⊙_σ` 的结果依赖顺序。定义交换缺陷
`Δ_σ(G) = max_{π ∈ Perm(σ)} ‖M_{⊙σ}(G) − M_{⊙π}(G)‖`。
若 `Δ_σ(G) = 0`（可逆、非干扰、`δ=0`），第 2 轮组合单调性原样成立；
否则使用顺序感知组合：每个 episode 作为不可分割块，块间按依赖 DAG 排序，块内不重排。
**单调性弱化为**：沿 DAG 增加一个不干扰的块，不减少已验证集合（引理 54）。

**定义 441（有效样本量与相关回执记账，修正定义 426）**
回合内回执相关（共享状态轨迹）。块自相关 `ρ_k` 下
`n_eff = n / (1 + 2 Σ_{k=1}^{K} (1 − k/n) ρ_k)`（Bartlett 窗），
或用 Fisher 特征值比 `n_eff = λ_min(I_S(τ)) / λ_min(I_S^{(1)})`。
定义 426 的独立观测下界替换为 `n_eff ≥ n_min(ε, σ_0, σ_obs)`；
后验协方差必须用 `n_eff` 代入，禁止用名义 `n`。
这是对第 2 轮"独立高斯观测"假设的审计与修复。

**定义 442（扩展回执 ER）**
`r = (t, τ_id, obs=(μ, σ_decl), sig, ts, seq, δx, ∫w dt, c, rc_flag)`。
`valid(r) ⇔ Schema ∧ Pre(回合级) ∧ Post(回合级) ∧ Verify(sig) ∧ seq 单调 ∧ (rc_flag ∨ 仅用于当前状态校准)`。
无效/污染回执的样本用途受限，但**永不**被静默当作原状态证据。
第 2 轮定义 417 是本定义在 `δx = 0, ∫w dt = 0, rc_flag = 真` 下的特例。

**定义 443（动力学残差隔离 D-Quarantine，扩展定义 428）**
按接触模态 `c` 维护最近 `K` 个回合的（预测接触结果, 实测接触结果）残差；
连续 `≥ q` 次同向且超出 `ε_dyn` ⇒ 判定 `Δ̂` 系统性失配：
先收缩 `Δ̂`（把当前模态标记为 OOD），再暂停 S-Box/M-Box 的接触丰富路径，退回 ToolGauge 准静态探测。
与 P-Quarantine 的分工：P-Quarantine 管"先验偏差"，D-Quarantine 管"接触模型偏差"。

**定义 444（状态一致局部修复与回撤）**
热替换 `new_ec` 仅当 `RC(e) = 真` 且 `‖x_H − x₀‖_G ≤ ε_rest` 时允许。
否则执行回撤：① 撤销对该子图的热替换；② 对所有"有效性依赖被改变状态"的 R 格子放大 `σ_conf`
（由 `δx` 的依赖闭包给出）；③ 入队重验。
这把第 1 轮"局部修复、误差局部化"从**无条件**改为**有条件**：局部性以"世界未被改坏"为前提。

**定义 445（接触模态条件化先验）**
`MP-Φ` 的上下文扩展为 `(h, c, Δ̂, receipts)`：`q_θ(u_s | c, Δ̂, ·)`。
风险：`θ_c` 跨格子共享 ⇒ 跨盲区相关偏差比第 2 轮更强，必须由 D-Quarantine + 分模态校准兜底。

**定义 446（准入门与退化链）**
进入 MoCoGauge 需同时满足：仿真可用、`Δ̂` 已校准（覆盖 ≥ 1−β）、目标参数 CPE 可达、工作空间租约可得。
任一失败 ⇒ ToolGauge（准静态、非接触）⇒ 再失败 ⇒ LeanGauge ⇒ MODGAUGE。
**MuJoCo 与运动控制是增强项，不是依赖项。**

**定义 447（继承与编号约定）**
未重定义记号沿用定义 398–431；本轮以 ToolGauge 为退化特例
（`H=1, Δ̂=∅, c≡stick, WCB=0, n_eff=n`）。

## 2. 关键算法骨架

```python
# IP-321 S-Box：MuJoCo 只做证伪（RSA），Δ̂ 由共形校准给出
class SBox:
    def rehearse(self, H, e) -> "RSAReport":
        # 角点 + 自适应采样覆盖 Δ̂；任一 δ 失败即拒绝（sound-reject）
        for delta in self.delta_set.corners_and_samples():
            tau = self.mj.rollout(e.policy, e.horizon, delta)
            if not wrench_ok(tau, e.envelope):        return RSAReport(False, "wrench", delta)
            if not cpe_ok(tau, e.cpe):                return RSAReport(False, "not_exciting", delta)
            if irreversibility(tau) > e.wcb:          return RSAReport(False, "irreversible", delta)
```

## 3. 推导

**引理 51（非交换偏差界）** 设 `O, F` 关于状态为 `L`-Lipschitz，单步非交换缺陷 `≤ δ`。
若把一条 `H` 步回合的回执当作可交换独立样本（第 2 轮做法），则参数估计偏差
`‖E θ̂_exch − θ*‖ ≤ (L_O L_F H² / 2)·δ + o(δ)`；
且后验方差被低估，低估因子 `≥ 1 + 2 Σ_k ρ_k`（即 `n / n_eff`）。
证明思路：对复合映射做二阶 Taylor，交叉项即 `δ`；方差由正相关样本的 Fisher 可加性给出。
**推论 51.1** `δ = 0 ⇒` 偏差为 0，ToolGauge 的独立样本假设精确成立——ToolGauge 是本轮 `δ=0` 的特例。

**引理 52（证伪器的单边可靠性）** 若 `Δ̂` 的覆盖为 `1−β`，MuJoCo 数值误差 `≤ ε_sim`，
且 RSA 在 `Δ̂` 上做鲁棒检查，则
`P(物理回合违反 wrench/Irr 包络) ≤ β + ε_sim + TV(校准分布, 部署分布)`。
反之，"RSA = 真 ⇒ 物理上有信息"**没有**同阶保证：构造反例——仿真中 `slip` 充分激励、真实中粘着，
使 RSA = 真但 `I_S` 在真实中降秩。故 S-Box 只能否决，不能担保。

**引理 53（可逆区的最优性，与不可逆区的不可能性）**
(a) 可逆、非干扰区（`δ=0`、WCB 不紧）内，若信息增益对回合集合自适应次模，H 步滚动 I-MPC 达到
`(1−1/e)·OPT − O(√(H/T))`（`T` 为规划迭代数）。
(b) 存在不可逆实例（两回合互斥：先做者毁掉后者所需的接触模态），使其等价于随机背包；
除非 WCB 作为硬约束，否则任何在线策略的竞争比无常数下界。
结论：不是 I-MPC 不够好，而是不可逆性使问题本质变难——这正是 WCB 必须硬约束的理由。

**引理 54（世界变更预算 ⇒ 误差局部性）** 若每个回合 `Irr(e) ≤ B_irr` 且 `RC` 残差 `≤ ε_rest`，
则被无效化的 R 格子集合包含于被探格子依赖闭包的 `ε_rest`-邻域；组合单调性在该邻域外成立。
若预算耗尽，停止探测并 stub + RED，退化链不破坏。
**推论 54.1** 回撤（定义 444）是完备的：任何因状态改变而失效的热替换都在 `σ_conf` 放大集合内被撤销。

**引理 55（时序与任务优先级保持）** CBF-TP QP 中探测位于最低优先级且可抢占，
优先级 0/1 的可行性不依赖探测；50Hz 计量路径的最坏时延与第 2 轮引理 50 相同。
代价：共享执行器带宽使探测吞吐随主任务负载下降，**不保证活性**（repair 可能长期排队），
需由预算/调度单独给出（实验 E449）。这是本轮必须接受的、无法用定理消除的工程事实。

## 6. 本轮最大风险（一句话）

**一句话**：本轮把安全论证从"预注册物理包络"升级为"共形接触参数集上的鲁棒排练"，
但共形覆盖只对**校准分布**成立；一旦真实接触物理落在分布外（粘附、非库仑摩擦、颗粒/软体、执行器迟滞），
MuJoCo 会以 `1−β` 的"形式可信度"**认证一个既不安全也不可辨识的回合**，
而接触探测又是不可逆的——于是错误不再是局部的，也不再可回撤；
这是"用错误的接触模型获得正确外观的证书"的失败模式。

**次级风险与缓解**：
1. **OOD 接触**：D-Quarantine（定义 443）+ 分布外检测（能量/残差）+ 强制退回准静态 ToolGauge；
2. **排练过度保守**：RSA 假阴性浪费修复机会——用 `Δ̂` 的自适应收缩与"最小可行激励"降低保守性（E444）；
3. **不可逆损伤**：WCB 硬预算 + RC 证书 + 力矩/力 CBF；预算耗尽即停机排队人工，不赌；
4. **非交换性污染校准**：episode 分块 + `n_eff` + 独立回合交叉验证（定义 441/444）；
5. **任务干扰/活性**：优先级 2 零空间 + 工作空间租约；显式承认活性不可证（引理 55 的代价）；
6. **仿真计算不可承受**：排练预算与 `Δ̂` 采样数挂钩，超预算即降级而非超时（E453）；
7. **证书可信度放大**：语言修复证书（继承定义 427）必须逐字引用含 `δx/∫w` 的回执，禁止"仿真里通过"作为主张依据。

## 2. 形式化定义（要点）

**定义 433（CCO）** `y_t=O(x_t,u_t,θ,c_t)+ε_t`、`x_{t+1}=F(·)`；归一化非交换缺陷 `δ_ab`；`δ>0` ⇒ 顺序携带信息，可交换样本假设失效。
**定义 434（CPE）** `λ_min(I_S(τ)) ≥ λ_exc` 才可辨识；摩擦需 slip、刚度需变载；不满足 CPE 的回合禁止执行。
**定义 435（WCL/WCB）** `Δx=Δx_rev+Δx_irr`；`Irr(e)=‖W_irr⊙Δx_irr‖₁+α·1[¬settleable]`；`E[Irr]≤B_irr` 且 `CVaR_β[Irr]≤B_irr^max`；每条回执记 `(δx_t,∫w_t dt,c_t)`。
**定义 436（RC）** 存在 `κ_rest` 在 `τ_settle` 内回到 `‖x̂−x₀‖_G≤ε_rest` 且满足安全包络；失败标 `CONTAMINATED`，限制回执用途并触发回撤。

**定义 438（CBF-TP）** 优先级 0 硬安全 CBF、1 主任务、2 探测；探测仅在零空间生效且任意拍可抢占；工作空间租约互斥。

**定义 444（状态一致局部修复）** 仅 `RC=真` 且残差 `≤ε_rest` 才热替换；否则撤销替换、按 `δx` 依赖闭包放大 `σ_conf`、入队重验。

```python
class SBox:
    def rehearse(self, H, e):
        for delta in self.delta_set.corners_and_samples():
            tau = self.mj.rollout(e.policy, e.horizon, delta)
            if not wrench_ok(tau, e.envelope):     return RSA(False, "wrench", delta)
            if not cpe_ok(tau, e.cpe):             return RSA(False, "not_exciting", delta)
            if irreversibility(tau) > e.wcb:       return RSA(False, "irreversible", delta)
            if not self.restorable(tau, delta, e): return RSA(False, "unrestorable", delta)
        return RSA(True, "candidate")              # 不是许可证

# IP-322/324 M-Box + A-Box：信息 MPC + 任务优先级安全滤波
class MBox:
    def synthesize(self, H, e, belief):
        u = info_mpc.solve(H, belief, e.delta_set, e.wcb)   # Î - λ_r CVaR - λ_w Irr - λ_e ||u||²
        return SafetyFilter(e).project(u)

class SafetyFilter:
    def project(self, u_probe):
        u0 = cbf_qp(priority=0).solve()
        u1 = task_qp(priority=1, nullspace_of=u0).solve()
        return probe_qp(priority=2, nullspace_of=(u0, u1), u_ref=u_probe).solve()

# IP-323 W-Box：执行 + 账本 + 可逆性证书
class EpisodeRunner:
    def run(self, e):
        enter(PROBING); ckpt = checkpoint(state); L = WorldChangeLedger(); R = []
        for t in range(e.horizon):
            if preempted_by_task(): return Result(preempted=True)
            u = MBox.next(belief); y, dx, w = env.step(u)
            L.add(dx, w, env.mode()); R.append(make_receipt(y, dx, w, t, env.mode()))
        return Result(R, L, restore_or_settle(ckpt, e))

# IP-325 MoCo-8C
def mocogauge_8C(M, s):
    H, b = M.lbox.hypothesize(s, M.dbox.R[s])                   # H
    prog = M.tbox.compile(H, M.tools)                           # C
    if not M.tcv.verify(prog, M.budget(s))[0]: return M.fallback_quasistatic(s, "tcv")
    e = M.mbox.build_episode(prog, H, s)
    if not M.sbox.rehearse(H, e).ok:             return M.fallback_quasistatic(s, "rsa")  # R
    res = M.runner.run(e)                                       # M + E

    if not res.rc.ok:                            return retract_and_stub(s, "contaminated")  # V
    mu, Sig, ne = calibrate_correlated(res.receipts, H, s, res.mode)   # C（含 n_eff）
    if mu is None:                               return stub_and_red(s, "insufficient_eff_n")
    if not M.apcal.cross_validate(mu, Sig, M.independent_episode(s)):  # V
        return stub_and_red(s, "cross_failed")
    new_ec = M.apcal.update_contract(M.dpe, mu, Sig, s, contact_mode=res.mode)
    if not contract_regression(new_ec):          return stub_and_red(s, "regression")
    M.mreg.hot_replace(M.dpe, new_ec)                           # U
    M.dbox.update_from_posterior(s, mu, Sig, ne)
    M.dquar.record(res); bind_claims(new_ec, H, e, res.receipts, res.ledger)
```

## 4. 推导

**引理 51（非交换偏差界）** `O,F` 为 `L`-Lipschitz、单步缺陷 `≤δ` 时，把 H 步回合回执当可交换独立样本的偏差
`≤ (L_O L_F H²/2)δ + o(δ)`，后验方差低估因子 `≥ 1+2Σρ_k`。**推论 51.1** `δ=0` ⇒ 偏差为 0，ToolGauge 精确成立。
**引理 52（证伪器单边可靠性）** `P(物理违反包络) ≤ β + ε_sim + TV(校准,部署)`；反向"仿真有信息⇒真实有信息"无同阶保证（构造粘着反例）。
**引理 53（可逆最优 / 不可逆不可能）** (a) `δ=0` 且信息增益自适应次模时，滚动 I-MPC 达 `(1−1/e)OPT − O(√(H/T))`；
(b) 存在互斥接触模态的不可逆实例等价随机背包，无 WCB 时在线策略无常数竞争比。
**引理 54（预算⇒局部性）** `Irr≤B_irr` 且 `RC 残差≤ε_rest` ⇒ 无效化格子含于依赖闭包的 `ε_rest`-邻域，邻域外组合单调性成立；预算耗尽即 stub+RED。**推论 54.1** 回撤完备。
**引理 55（时序/优先级保持）** 探测处于优先级 2 且可抢占，优先级 0/1 可行性不依赖探测；50Hz 时延同引理 50。代价：吞吐随主任务负载下降，**活性不可证**。

## 6. 实验设计 E441–E456（RAS-Baselines v4 协议）

|---|---|---|

**三条可证伪的总假设**（任一失败即退回 ToolGauge）：
1. `CPE` 比贝叶斯信息增益更能预测"真实可辨识性"（E441）；
2. `RSA` 的拒绝是可靠的、且假阴性在可接受范围（E443/E444）；
3. `n_eff` 修正能把相关回执的校准覆盖恢复到名义水平（E446）。

## 8. 本轮最大风险

**一句话**：共形接触集 `Δ̂` 的覆盖只对校准分布成立；一旦真实接触物理 OOD（粘附、非库仑、颗粒/软体、迟滞），
MuJoCo 会以 `1−β` 的形式可信度**认证一个既不安全也不可辨识的回合**，而接触探测不可逆——
错误由此既不局部也不可回撤，形成"用错误接触模型获得正确外观证书"的失败模式。
**三重兜底**：E443/E456 证伪 + D-Quarantine（443）在线断路 + WCB/回撤（435/444）物理止损。
