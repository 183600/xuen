# 第 62 轮（承接第 61 轮「具身语义进化闭环」IP-173~182；灵感循环第 8 轮；本轮灵感：「视觉问答」×「开源生态」）

> 第 61 轮的 ESEC 已把场景、意图、阻抗、证据统一进 USR，并用 MEL/DMS/SRT-Dual 打通「语义→控制」。但仍有四个结构性缺口：
> 1. **语义只可投影，不可提问**：USR 是高维嵌入空间，缺少「问—答」接口。工程师无法直接问「这个杯子能推吗」「往左 5cm 会碰碗吗」，只能被动接受一个向量。
> 2. **答案没有证据与弃答**：MEL 输出物理属性和策略分布，却没有「答案级」的校准、证据引用与弃答准则；嵌入相似 ≠ 回答为真，容易产生「自信的错误」。
> 3. **生态封闭、不可复现**：MEL/USR 是一体化单体栈，替换任一编码器都要重训；语义锚点与证书只存在本地，第三方无法重放与审计。
> 4. **异构开源组件语义不可互操作**：CLIP/SigLIP/DINOv2/SAM/LLaVA/OpenVLA 的维度、范数、语义坐标各不相同，直接拼接会产生「语义坐标错位」与静默漂移。

## 0. 直觉与动机

### 灵感 1（视觉问答 → 具身视觉问答 EVQA：把「问答」升级为「探-证-答」）

直觉：传统 VQA 是「给图—出答案」的单向映射；而机器人面对的世界是**可交互、可验证**的。真正有用的不是「图里有什么」，而是「如果我把杯子往左推 5cm，会不会碰到碗？」这类**组合式、反事实、可操作**的问题。于是把 VQA 重构为**具身视觉问答 EVQA**：问题先被编译成「语义探针程序」，探针可以是再看一眼（look）、摸一下（touch）、轻推测试（actuate）、问人（ask）或查账本（retrieve）；答案必须带**证据引用 Ev\***、**校准置信 c**、**可执行提示 act**，证据不足时**弃答 ⊥**。关键洞见：**问答不是感知的终点，而是主动获取信息的起点**。

### 灵感 2（开源生态 → 开放语义互操作 OEMI：把 USR 变成「语义 USB 接口」）

直觉：第 61 轮把场景/意图/阻抗/证据都映射到 ℝ^d_us，但这是一条**私有总线**。开源生态的真正力量不是「又一个更大的模型」，而是**可插拔、可替换、可验证**。于是把 USR 从「一个模型内部层」降级为**一个协议**：任何开源编码器只要通过轻量**语义适配器 SA**、满足**语义互操作契约 SIC**（类型、维度、范数、校准、许可证、哈希），就能接入；适配器的**兼容度 χ**必须被度量与认证，低兼容度模型被拒绝。关键洞见：**生态的关键不是模型数量，而是接口的可信度**。

### 灵感 3（合流 → 提问驱动的开放语义获取 QDSA）

直觉：EVQA 提供「问什么」，OME 提供「用谁的模型来答」。二者合流产生更本质的机制：**问题决定探针，探针调用生态中最合适的插件，答案回写 USR 并进入账本**。问题成为**资源分配器**：高价值问题获得更多探针预算与更强模型，低价值问题快速弃答。这把第 61 轮静态预算 PCE+++++ 升级为**问题级 VOI 预算**。

### 灵感 4（合流 → 联邦语义锚点账本 FSAL：让「语义」可复现、可审计）

直觉：开源生态要成立，必须解决「我凭什么信你的答案」。答案不能只活在本机内存里，而应写入**只追加的 Merkle 账本**：每条记录含锚点、证书、模型清单哈希、Q/A 轨迹、证据引用与签名。任何第三方都能用相同观测**重放**问答并校验证书；无法重放或重放不一致的记录被标记。这把「信任某个模型」变成「验证某条记录」。

### 灵感 5（统一 → EOS-VQA：具身开放语义问答闭环）

直觉：把 EVQA（问）、QPC（探）、OME/SIC/SA（选模型与接口）、AEA（证据归因）、HAC（校准弃答）、FSAL（记账）、ESD（防漂移）、OSEC（出证书）串成一个环：**问 → 探 → 证 → 答 → 行 → 记 → 审 → 再问**。它不是第 61 轮 ESEC 的替代，而是给它加一层**「可提问、可替换、可复现」的开放语义外壳**。

一句话押注：**第 61 轮让语义能驱动控制；本轮让语义能被提问、被替换、被审计——把「会做」升级为「说得清、换得动、查得到」。**

## 1. 形式化定义（增量：定义 173–184）

**定义 173（具身视觉问答接口 EVQA）** 具身视觉问答是一个七元组 EVQA = (Q, A, U, Op, G, κ, Act)。其中：
- **问题语言** Q：由带类型原子构成的可组合查询，覆盖对象/属性/关系/计数/比较/反事实/可操作性七类。
- **答案空间** A = A_val ∪ {⊥}：A_val 包括布尔值、区间 [l,u]、集合、离散分布与计数；⊥ 表示弃答。
- **语义状态** U：第 61 轮 USR 在时刻 t 的锚点，含 scene_emb、intent_emb、phys_prior 与类型化槽位（slot）。
- **查询算子** Op = {lookup, filter, relate, count, compare, would_if, afford}。
- **接地映射** G: Q × U × Ledger → (Ev, ν)，给出证据集合 Ev ⊆ Ledger 与证据冲突度 ν ∈ [0,1]。
- **校准器** κ: A × Ev → [0,1]，输出答案置信。
- **可执行性映射** Act: A × U → {constraint_proposal, probe_request, null}。
- **答案对象** Ans = (a, p(a), Ev\*, c, act, prov)，其中 p(a) 为答案分布，Ev\* 为最小充分证据集（定义 179），prov 为账本溯源（定义 178/182）。

**定义 173.1（语义查询代数 SQA）** 设基类型 τ ∈ {Scene, Obj, Rel, Phys, Aff, Ev, Bool, Int, Real, Dist}。原子为三元组 atom = (s:τ_s, p:τ_s→τ_o, o:τ_o)，其求值 ⟦atom⟧_U ∈ [0,1] 表示在 U 上成立的真值；复合查询按如下代数求值：
```
⟦q1 ∧ q2⟧_U = ⟦q1⟧_U ⊗ ⟦q2⟧_U      # ⊗ 为 Gödel t-范数 min(·,·)
⟦¬q⟧_U      = 1 - ⟦q⟧_U
⟦∃x. q(x)⟧_U = max_x ⟦q(x)⟧_U
⟦count(x:q)⟧_U = 关于基数的分布（由槽位后验诱导）
⟦would_if(a, q)⟧_U = ⟦q⟧_{U ⊕ do(a)}   # 在 USR 上施加干预 a 后的反事实求值
⟦afford(o,a)⟧_U = 1[ K_safe(a,o) ∈ Feasible(U) ] ⊙ conf(o)
```
类型系统要求每个谓词的签名与槽位类型匹配，否则拒绝编译（禁止「维度对但语义错」的静默拼接）。

**定义 174（提问-探针编译器 QPC 与主动语义获取）** 给定问题 q 与语义状态 U，编译器输出探针程序 P_q = ((p_1, σ_1), …, (p_k, σ_k), stop)。探针空间 P = P_look ∪ P_touch ∪ P_actuate ∪ P_ask ∪ P_retrieve。每个探针 p 有：
- **信息增益** IG(p | U) = H(A | U) − 𝔼_{o∼P(·|U,p)}[H(A | U ⊕ o)]；
- **成本** cost(p) = λ_t·time(p) + λ_e·energy(p) + λ_r·risk(p)；
- **安全约束** risk(p) ≤ B_safe（试探动作必须落在 ERTC 可行域内）。
探针选择为贪心比值最优：
```
p* = argmax_{p ∈ P, risk(p) ≤ B_safe}  IG(p|U) / cost(p)
s.t. IG(p|U) ≥ ε_ig
```
停止准则：H(A|U) < ε_H，或不存在可行探针，或问题级预算耗尽；此时若置信不足则输出 ⊥，否则输出答案。QPC 是一个有限时域信息获取 POMDP。

**定义 175（语义适配器 SA）** 对第 i 个开源编码器 E_i: X_i → ℝ^{d_i}，语义适配器 A_i: ℝ^{d_i} → ℝ^{d_us} 由残差 MLP、LayerNorm 与温度校准器 κ_i 组成。定义兼容度：
```
χ_i = σ( χ_0 − (λ_1·L_align,i + λ_2·ECE_i + λ_3·MMD_i + λ_4·L_cov,i) )
L_align,i = 𝔼_{x∼D_pair} ‖A_i(E_i(x)) − z_ref(x)‖²
```
其中 D_pair 是账本中公开的「语义锚点配对集」，z_ref 为参考语义坐标。接入判据：χ_i ≥ χ_min、契约类型检查通过、许可证兼容。替换测试：用规范 Q/A 探针集 D_qa 比较替换前后答案漂移 ΔQA ≤ δ_swap。

**定义 176（语义互操作契约 SIC 与类型系统）** 契约 C = (τ, d_us, norm, calib, ops, lic, hash, ttl, deps)。其中：
- **类型模式** τ：声明该插件可提供/消费的基类型与谓词签名；
- **范数与维度**：d_us 必须等于 USR 维度，输出范数落入 [1−δ_n, 1+δ_n]；
- **校准**：随附校准曲线与 ECE 上界；
- **算子支持** ops ⊆ Op；**许可证** lic 为 SPDX 表达式；**哈希** hash 为权重与配置的 Merkle 根；**TTL** 为语义有效期。
契约兼容关系 C_1 ⊑ C_2 当且仅当类型可被子类型化、算子被覆盖、许可证策略允许、且在 D_qa 上的行为差 ≤ δ_swap。只有 C ⊑ C_req 的插件才能被解析器选中。

**定义 177（开放具身模型生态 OME）** 注册表 R = (P, D, V, T)。P 为插件集合，D 为依赖 DAG，V 为版本解析器，T 为信任评分。每个插件带模型卡 M = (intended_use, limitations, license, eval_suite, contact)。信任评分：
```
T_i = σ( w_1·audit_i + w_2·sig_i + w_3·(1 − drift_i) + w_4·reputation_i )
```
版本解析：在 semver 与契约兼容约束下，最大化 T_i − λ_cost·latency_i，返回唯一解析结果或显式失败（禁止静默降级到不兼容版本）。

**定义 178（联邦语义锚点账本 FSAL）** 只追加 Merkle-DAG 账本 L，第 t 个区块：
```
B_t = ( h_{t−1}, root(anchors_t), root(certs_t), manifest_root_t, sig_t, ts_t )
```
支持 Merkle 包含证明与跨站重放。**语义重放**：给定区块中记录的观测 O_t 与模型清单 manifest_t，独立站点重跑问答流水线，检查 `dist(Ans_replay, Ans_log) ≤ ε_rep`。账本把「信任模型」转化为「验证记录」。

**定义 179（答案证据归因 AEA）** 对答案 a 与观测证据池 Ev_pool，最小充分证据集定义为：
```
Ev* = argmin_{Ev ⊆ Ev_pool} |Ev|
      s.t. Ans(U | Ev) = a  且  ∀ Ev' ⊊ Ev: Ans(U | Ev') ≠ a
```
即「删去任一元素答案就会改变」的最小理由集。工程上用贪心删除 + 反事实重算近似，并报告归因完备率/最小率。定义**接地正确率** = 答案正确 ∧ Ev\* 真实支持答案的比例。

**定义 180（幻觉抑制与共形弃答 HAC）** 在独立校准集上计算非一致性分数 s(q,a)，取分位数 q̂ = Quantile(s, 1−α)，构造预测集 C_α(q) = {a : s(q,a) ≤ q̂}。在可交换性假设下有覆盖率 P(a\* ∈ C_α(q)) ≥ 1−α。弃答准则：
```
abstain  ⇔  |C_α(q)| > 1  或  ν(q) > τ_ν  或  R_selective(τ) > ε_risk
R_selective(τ) = 𝔼[ℓ(q,a)·1{c ≥ τ}] / P(c ≥ τ)
```
其中 c 为校准置信，τ 由「选择性风险 ≤ ε_risk」反解。该准则给出分布无关的覆盖率与选择性风险保证。

**定义 181（跨生态语义漂移监测 ESD）** 固定探针集 D_probe。插件从版本 v 升级到 v′ 时，定义漂移
```
Δ_t = MMD²( A_i(E_i(D_probe)), A_{i'}(E_{i'}(D_probe)) )
    + 𝔼_{x∼D_probe} ‖A_i(E_i(x)) − A_{i'}(E_{i'}(x))‖²
```
用 CUSUM 累积：S_t = max(0, S_{t−1} + Δ_t − ν)；当 S_t > h 或 Δ_t > δ_drift 时隔离该插件（quarantine），触发重校准或回滚。检测延迟与平均运行长度（ARL）由 (h, ν) 控制。

**定义 182（开放语义-执行证书 OSEC）** 在第 61 轮 J_sem_exec 基础上扩展：
```
OSEC = ( J_sem_exec,
         manifest_root,                 # 模型清单 Merkle 根
         adapter_ids_and_hashes,        # 语义适配器及其哈希
         qa_trace_root,                 # Q/A 轨迹 Merkle 根
         evidence_citations,            # 证据引用（含账本区块 ID）
         conformal_set_Cα,              # 共形预测集
         license_expr,                  # SPDX 许可证表达式
         ledger_block_id,               # 账本区块
         osr_score )                    # 开放语义复现度
Valid(OSEC) ⇔ Valid(J_sem_exec) ∧ coverage(Cα) ≥ 1−α ∧ VerifyProvenance(·)
            ∧ adapter_compat ≥ χ_min ∧ license_compatible
```

**定义 183（EOS-VQA 闭环算子）** 定义一次完整循环：
```
EOS-VQA(q, U, L):
  1  P_q ← QPC.compile(q, U)                        # 问 → 探
  2  for (p,σ) ∈ P_q until stop:
        o ← Execute(p); U ← USR.update(U, o)
  3  (a, p(a)) ← SQA.eval(q, U)                     # 证 → 答
  4  Ev* ← AEA.minimal(q, a, U, L)
  5  if HAC.abstain(q,a,U,Ev*): return ⊥ with Ev*
  6  act ← Act(a, U)
  7  if act = propose_constraint: ERTC.lock_pending(act) → SRT-Dual 执行
  8  OSEC ← build_cert(a, Ev*, U, manifest, L)
  9  L.append(anchor=U, cert=OSEC, qa_trace=(q,a,Ev*))
 10  return Ans(a, p(a), Ev*, c, act, L.block_id)
```

**定义 184（开放语义复现度 OSR）** 给定开放基准 Q_bench，OSR 定义为
```
OSR = |{ q ∈ Q_bench : ∃ ≥ m 个独立站点按账本重放且 dist(Ans_replay, Ans_log) ≤ ε_rep }| / |Q_bench|
```
它度量「同一问题在开放生态中能否被独立复现」，是比单点评测更接近开源生态真实健康度的指标。

## 2. 直觉层面的三个「为什么」

1. **为什么是「探针」而不是「更多参数」？** 因为机器人真正的瓶颈不是「看懂」，而是「不确定时该做什么」。VQA 若只输出答案，无法区分「看见」与「猜对」；探针把「不确定性」显式转化为「动作」，用执行证据消除它。
2. **为什么是「适配器 + 契约」而不是「统一大模型」？** 因为开源生态注定异构且持续演化。统一大模型是把多样性压平；适配器 + 契约是把多样性**约束在可验证的接口**上，既能用社区最好的组件，又能拒绝语义错位的组件。
3. **为什么是「账本 + 复现度」而不是「排行榜」？** 排行榜奖励「刷分」，账本奖励「可重放」。只有可重放的答案才能进入安全关键的具身闭环。

## 3. 本轮最大风险

**一句话**：若开源适配器在分布外系统性失准、或账本被少数节点与恶意插件联合污染（语义投毒 + 共谋重放），系统就可能产出「有证书、可复现、但物理上错误」的答案，并据此提出看似安全实则危险的约束；因此必须以「共形弃答硬门 + 契约类型检查 + 独立多站审计 + 试探动作的 ERTC 硬安全域」构成不可绕过的语义安全底座，且**任何证书都不能替代实时安全兜底**。

### IP-183 EVQA（具身视觉问答引擎）

```python
class EmbodiedVQAEngine:
    def __init__(self, usr, ledger, compiler, attributor, calibrator, budget):
        self.usr = usr
        self.ledger = ledger
        self.compiler = compiler        # IP-184 QPC
        self.attributor = attributor    # IP-189 AEA
        self.calibrator = calibrator    # IP-190 HAC
        self.budget = budget

    def answer(self, q, ctx):
        U = self.usr.read_latest_anchor()
        plan = self.compiler.compile(q, U)          # 问 -> 探
        observations = []
        for p in plan:
            if not self.budget.allow(p):
                break
            if p.risk > self.budget.B_safe:         # ERTC 硬安全域
                break
            o = self.execute_probe(p, ctx)           # look/touch/actuate/ask/retrieve
            observations.append((p, o))
            U = self.usr.update(U, o)
            if self.compiler.should_stop(q, U, observations):
                break

        qdag = parse_typed_query(q)                  # SQA 类型检查
        dist = self.eval_sqa(qdag, U)                # 证 -> 答
        a = argmax(dist)
        Ev = self.attributor.minimal_sufficient(q, a, U, observations, self.ledger)

        # 共形预测集 + 冲突 + 选择性风险
        C_alpha = self.calibrator.prediction_set(q, a, U)
        c = self.calibrator.confidence(dist, Ev, observations)
        if (len(C_alpha) > 1
                or self.calibrator.evidence_conflict(Ev) > self.calibrator.tau_conflict
                or self.calibrator.selective_risk(c) > self.calibrator.eps_risk):
            return Answer.abstain(Ev=Ev, confidence=c, provenance=self.ledger.head_id())

        act = self.actionability(a, U)               # constraint / probe / null
        prov = self.ledger.anchor(q, a, Ev, U.version, observations)
        return Answer(a, dist, Ev, c, act, prov)

    def eval_sqa(self, node, U):
        if node.op == 'lookup':
            return self.usr.slot_distribution(node.slot, U)
        if node.op == 'would_if':
            return self.eval_sqa(node.body, self.usr.do(U, node.intervention))
        if node.op == 'count':
            return self.usr.cardinality_distribution(node.pred, U)
        if node.op == 'compare':
            return self.compare_intervals(self.eval_sqa(node.lhs, U),
                                          self.eval_sqa(node.rhs, U))
        if node.op == 'afford':
            return self.usr.affordance_distribution(node.obj, node.action, U)
        return self.eval_atom(node, U)               # Gödel t-范数合成
```

### IP-184 QPC（提问-探针编译器）

```python
class QuestionProbeCompiler:
    def __init__(self, usr, eps_ig=1e-3, eps_H=0.1):
        self.usr = usr
        self.eps_ig = eps_ig
        self.eps_H = eps_H

    def compile(self, q, U):
        atoms = parse_typed_atoms(q)
        unresolved = [a for a in atoms if self.usr.entropy(a, U) > self.eps_H]
        plan = []
        while unresolved:
            cands = [p for p in self.admissible_probes(unresolved, U)
                     if p.risk <= self.B_safe]
            scored = [(p, self.info_gain(p, U) / max(p.cost, 1e-6)) for p in cands]
            if not scored:
                break
            p, ratio = max(scored, key=lambda x: x[1])
            if self.info_gain(p, U) < self.eps_ig:
                break
            plan.append(p)
            U = self.preview_posterior(U, p)
            unresolved = [a for a in unresolved if self.usr.entropy(a, U) > self.eps_H]
        return plan

    def info_gain(self, p, U):
        H0 = self.usr.answer_entropy(U)
        expected_H = 0.0
        for o, prob in self.usr.outcome_distribution(p, U):
            expected_H += prob * self.usr.answer_entropy(self.usr.update(U, o))
        return H0 - expected_H

    def should_stop(self, q, U, observations):
        return (self.usr.answer_entropy(U) < self.eps_H
                or len(observations) >= self.max_probes)

    def admissible_probes(self, atoms, U):
        return [p for p in self.usr.probes_for(atoms)
                if self.usr.probe_schema_compatible(p, U)]
```

```python
class SemanticAdapter(nn.Module):
    def __init__(self, d_in, d_us, d_hid=512, delta_n=0.05):
        super().__init__()
        self.res_proj = nn.Linear(d_in, d_us)
        self.net = nn.Sequential(
            nn.Linear(d_in, d_hid), nn.GELU(),
            nn.Linear(d_hid, d_us))
        self.norm = nn.LayerNorm(d_us)
        self.calibrator = TemperatureCalibrator()
        self.delta_n = delta_n

    def forward(self, z_native):
        z = self.norm(self.net(z_native) + self.res_proj(z_native))
        z = F.normalize(z, dim=-1)
        assert 1 - self.delta_n <= z.norm(dim=-1).mean() <= 1 + self.delta_n
        return z

    def compatibility(self, D_pair, y, logits):
        L_align = F.mse_loss(self(D_pair.x), D_pair.z_ref)
        ece = expected_calibration_error(y, self.calibrator(logits))
        mmd = self.mmd(self(D_pair.x), D_pair.z_ref)
        L_cov = self.coverage_gap(D_pair)
        chi = torch.sigmoid(self.chi0 - (0.3*L_align + 0.3*ece + 0.2*mmd + 0.2*L_cov))
        return chi.item()
```

### IP-187 OME（开放具身模型生态注册表）

```python
class OpenModelEcosystem:
    def __init__(self, chi_min=0.8):
        self.plugins = []
        self.dep_graph = DependencyDAG()
        self.chi_min = chi_min

    def admit(self, plugin):
        assert typecheck(plugin.contract)            # SIC 类型检查
        assert self.verify_hash_and_signature(plugin)
        assert plugin.compatibility >= self.chi_min
        assert self.dep_graph.acyclic_with(plugin)
        self.plugins.append(plugin)
        self.dep_graph.add(plugin)

    def resolve(self, req, license_policy, latency_weight=0.1):
        cands = [p for p in self.plugins
                 if contract_compatible(p.contract, req)
                 and license_compatible(p.contract.lic, license_policy)
                 and p.compatibility >= self.chi_min]
        if not cands:
            return None                              # 显式失败，禁止静默降级
        return max(cands, key=lambda p:
                   p.trust - latency_weight * p.latency)

    def trust(self, p):
        return sigmoid(0.3*p.audit + 0.3*p.sig + 0.2*(1-p.drift)
                       + 0.2*p.reputation)
```

```python
class FederatedSemanticLedger:
    def __init__(self):
        self.blocks = []

    def append(self, anchor, cert, manifest, qa_trace, signature):
        prev = self.blocks[-1].hash if self.blocks else ZERO_HASH
        payload = MerkleTree([anchor, cert, manifest, qa_trace]).root
        block = Block(prev=prev, payload_root=payload,
                      signature=signature, ts=time.time())
        self.blocks.append(block)
        return block.id

    def verify_inclusion(self, item, proof, root):
        return merkle_verify(item, proof, root)

    def replay(self, block, observations, pipeline):
        ans_log = block.qa_trace.answer
        ans_replay = pipeline.run(observations, manifest=block.manifest)
        ok_cert = verify_cert(block.cert, block.manifest)
        return ok_cert and distance(ans_replay, ans_log) <= EPS_REP

    def open_semantic_reproducibility(self, bench, sites):
        ok = 0
        for q in bench:
            hits = sum(self.replay_of(q, s) for s in sites)
            if hits >= self.m_required:
                ok += 1
        return ok / len(bench)                       # OSR
```

```python
class AnswerEvidenceAttributor:
    def minimal_sufficient(self, q, a, U, observations, ledger):
        evidence = self.collect(observations, ledger)
        # 贪心删除：删去后答案改变则该证据不可删
        essential = []
        current = list(evidence)
        for e in sorted(evidence, key=self.utility, reverse=True):
            trial = [x for x in current if x is not e]
            if self.answer_with(q, U, trial) != a:
                essential.append(e)
            else:
                current = trial
        return essential

    def answer_with(self, q, U, evidence):
        return self.sqa.eval(q, self.usr.fuse(U, evidence)).argmax()


class ConformalAbstainer:
    def __init__(self, alpha=0.1, tau_conflict=0.3, eps_risk=0.05):
        self.alpha = alpha
        self.tau_conflict = tau_conflict
        self.eps_risk = eps_risk
        self.scores = []

    def calibrate(self, calib_loader, model):
        self.scores = sorted(model.nonconformity(q, a) for q, a in calib_loader)

    def prediction_set(self, q, a, U):
        qhat = quantile(self.scores, 1 - self.alpha)
        cands = self.model.candidates(q, U)
        return {c for c in cands if self.model.nonconformity(q, c, U) <= qhat}

    def evidence_conflict(self, evidence):
        return self.pairwise_conflict(evidence)

    def selective_risk(self, confidence):
        # 由校准集经验估计；此处用保守上界
        return 1.0 - confidence
```

### IP-191 ESD（跨生态语义漂移监测）

```python
class SemanticDriftMonitor:
    def __init__(self, delta_drift=0.15, nu=0.02, h=0.5):
        self.delta_drift = delta_drift
        self.nu = nu
        self.h = h
        self.S = 0.0

    def update(self, old_plugin, new_plugin, D_probe):
        z_old = old_plugin.adapter(old_plugin.encoder(D_probe))
        z_new = new_plugin.adapter(new_plugin.encoder(D_probe))
        delta = mmd(z_old, z_new) + torch.mean((z_old - z_new) ** 2).item()
        self.S = max(0.0, self.S + delta - self.nu)
        if delta > self.delta_drift or self.S > self.h:
            new_plugin.quarantine(reason='semantic_drift')
            return 'QUARANTINE'
        return 'OK'
```

### IP-192 EOS-VQA 闭环

```python
def eos_vqa(q, U, ledger, engine, registry, ertc):
    # 1. 解析模型：问题需要的算子 -> 契约需求 -> 生态选型
    req = QueryContract.from_query(q)
    plugin = registry.resolve(req, license_policy=SPDX_ALLOWLIST)
    if plugin is None:
        return Answer.abstain(reason='no_compatible_plugin')

    # 2. 问 -> 探 -> 证 -> 答
    ans = engine.answer(q, ctx=plugin.context())
    if ans.is_abstain:
        ledger.append_abstention(q, ans.evidence, ans.provenance)
        return ans

    # 3. 答 -> 行（仅提出候选约束，绝不绕过 ERTC）
    if ans.act is not None and ans.act.type == 'constraint_proposal':
        if ertc.feasible(ans.act.constraint):
            ertc.lock_pending(ans.act.constraint)
        else:
            ans = ans.downgrade(reason='infeasible_constraint')

    # 4. 记 -> 审（证书 + 账本）
    osec = build_osec(ans, U, plugin.manifest, ledger)
    block_id = ledger.append(U, osec, plugin.manifest, ans.trace)
    return ans.with_provenance(block_id)
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| EVQA | O(|q|·d_us + k·T_probe) | O(|Ev|) | 类型检查通过；覆盖率 ≥1−α；证据不足必弃答 |

**正确性定理（EOS-VQA-Complete）**：
假设 A61–A70 以及
**(A71)** EVQA：语义查询代数 SQA 对类型化槽位可靠（soundness）；探针观测模型经校准；`would_if` 干预在 USR 上满足 do-演算一致性。
**(A72)** QPC：信息增益对探针集合自适应子模；风险估计保守（risk̂ ≥ risk）；预算单调消耗。
**(A73)** SA：账本配对集 D_pair 无偏且覆盖目标分布；适配器 Lipschitz 连续；d_us 对下游任务充分。
**(A74)** SIC：类型系统可靠；许可证兼容性可由 SPDX 表达式判定；行为差在 D_qa 上可估。
**(A75)** FSAL：签名不可伪造、哈希抗碰撞；独立诚实站点数 ≥ m 且占多数。
**(A76)** AEA：最小充分证据集存在；贪心近似的近似比有界。
**(A77)** HAC：校准集与测试集可交换；共形分数有界；选择性风险单调可控。
**(A78)** ESD：漂移度量一致；CUSUM 参数 (h,ν) 使误报率 ≤η。

则：
1. **接地回答可靠性**：若 HAC 返回非弃答答案 a，则真实答案落入 C_α(q) 的概率 ≥1−α；若 |C_α|=1 且 Ev\* 支持 a，则接地错误率 ≤ α + ε_ground。
2. **探针效率**：在自适应子模与预算约束下，QPC 的贪心探针序列取得的最优信息增益 ≥ (1−1/e)·OPT_adaptive − ε_budget。
3. **互操作边界**：若所有接入插件满足 χ≥χ_min 且契约兼容，则任意两插件在 D_qa 上的答案差 ≤ δ_swap；替换引起的 USR 语义漂移被 ESD 在延迟 ≤ h/(δ−ν) 内捕获。
4. **可复现性**：在 ≥m 个诚实独立站点重放下，若重放确定性成立且账本完整，则 OSR ≥ 1−ε 以高概率成立。
5. **执行安全**：EVQA 只能「提出约束」而不能直接下发控制；约束必须经 ERTC 可行性与实时安全兜底，因此弃答与契约检查共同保证「语义错误不转化为执行危险」。
6. **漂移遏制**：若插件升级导致 Δ_t > δ_drift，ESD 在误报率 ≤η 下隔离插件，阻止漂移语义进入实时闭环。

**消融设计**：A1 去掉 QPC（直接答）→ 验证主动探测增益；A2 去掉 HAC（不弃答）→ 验证幻觉-风险权衡；A3 去掉 SIC（直接拼接异构编码器）→ 验证语义错位；A4 去掉 FSAL（本地证书）→ 验证可复现性来源；A5 去掉 ESD（不监测漂移）→ 验证漂移风险。**开源生态基准**统一采用公开模型卡 + 公开探针集 + 公开账本重放脚本，所有结果带 OSEC 证书。

## 5. 本轮最大风险

**一句话**：若开源适配器在分布外系统性失准、或联邦账本被少数节点与恶意插件联合污染（语义投毒 + 共谋重放），系统就可能产出「有证书、可复现、但物理上错误」的答案，并据此提出看似安全实则危险的约束；因此必须以「共形弃答硬门 + SIC 类型检查 + 独立多站审计 + 试探动作的 ERTC 硬安全域」构成不可绕过的语义安全底座，且**任何证书都不能替代实时安全兜底**。
