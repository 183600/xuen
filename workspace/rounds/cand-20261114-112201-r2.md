# 第 74 轮（承接第 73 轮「MODGAUGE-RAS 计量契约代数」IP-295~301；本轮灵感：「指令泛化」×「创新点挖掘」）

> R73 把「证据」做成了可组合的契约：深度六分量、接触四分量、串联/并联/否决代数、热替换定理、主张-证明绑定。它解决的是**感知证据如何进入安全闭环**。但 R73 仍留下三个更深的**结构性**问题：
> - **语义缺口**：契约约束的是「证据」，不是「意义」。自然语言指令 → 技能程序的映射（接地模块）从未被审计：它被当成一个黑箱规划器，泛化能力用基准成功率衡量，而不是用一个**可声明的覆盖域**衡量。换一种说法、换一个指代、换一个量词作用域、换一个未见的技能组合，系统没有任何结构性的「我知道我不知道」。
> - **覆盖缺口**：R73 的每张证书都**隐含**假设「我的校准集覆盖了部署分布」。SEAL 的 conformal 覆盖率、组合定理、热替换定理，全部建立在交换性/覆盖性之上，但「覆盖」从未被类型化、从未被组合、从未被审计。这是整个契约代数背后**最大的未声明假设**。
> - **元缺口**：CPB 是手工蒸馏的三条主张。没有程序去**挖掘**哪些差异真正构成创新、哪些只是工程堆叠；没有机制区分「新能力」与「已知方法的闭包」；也没有防御审稿人最常用的那句话——「这不就是 A+B 吗？」
>
> 本轮两个灵感正好各补一刀，并逼出一个统一抽象：
> - **指令泛化** → **IGM（Instruction Generalization Metrology）**：指令不再是字符串→策略的映射，而是**带类型的接地项（grounded term）**；其不确定度分解为语义六分量（词汇/指代/作用域/可供性/参数/意图）；泛化不再是「成功率」，而是「指令意义是否落在已校准的组合闭包内」；每条指令输出**泛化证书 GC**，覆盖外必须澄清或拒绝，而非猜测。
> - **创新点挖掘** → **NPM（Novelty-Point Miner）**：新颖性不是引用断言，而是对**密封基线面板 SEAL-NOVELTY** 的**可证伪检验**；能力被建模为能力-主张格，贡献用消融+Shapley 归因识别；「已知方法 A+B」被显式建模为**基线闭包**——落在闭包内的能力不算创新。NPM 自动产出并裁剪主张集，本轮正是它「挖」出了第四条主张 C4。
> - **统一抽象** → **CVM（Coverage-Verified Metrology）**：泛化与创新在数学上是同一件事——**闭包覆盖问题**。语义泛化 = 意义空间对「已认证原子/算子闭包」的覆盖；创新 = 能力空间对「基线闭包」的覆盖。于是把 **覆盖证书 COV** 提升为一等公民：所有 R73 证书都变为**覆盖相对**的；覆盖之外必须走显式回退（澄清/拒绝/降级/撤回主张）。
>
> 核心命题：**证书不是绝对的，而是覆盖相对的。** 可信系统的边界不是它的错误率，而是**它是否知道自己在哪里没有覆盖，并在此处结构性地停止**。把 R73 的计量契约代数扩展为 **GENGAUGE-RAS**（GENeralization-aware, Coverage-audited evidence metrology with GAUGE audits for RAS）——**覆盖审计计量学**。

## 0. 直觉与动机

**灵感 1（指令泛化 → 指令是一个需要被计量的「语义证据源」）**
直觉：人类说「把杯子放到盘子左边一点」，系统真正收到的不是一个任务，而是一组**约束不足的语义证据**：哪个杯子（指代）、「左边」以谁为参照（作用域/参照系）、「一点」是多少（参数）、盘子是否可放（可供性）、人是否其实想让你先擦桌子（意图）。R73 把所有证据源都契约化了，唯独把最关键的一个证据源——**「人到底在要求什么」**——留在了契约之外。这和 R70 之前把深度当「又一个观测」是同型错误：**把语义不确定度误读为策略不确定度**。

若把指令当作证据，则 R73 的全部机器可以直接复用：指令接地模块也是一个模块，有输入输出类型、不确定度预算、有效域、否决指示、反作用通道。区别只在**域的形状**：深度证据的域是连续的（距离/入射角），语义证据的域是**组合的**（原子×算子×深度×指代配置）。组合域带来的新问题是：校准集只能覆盖有限个组合签名，**未见组合没有统计保证**。因此泛化的正确形式不是「更大模型」，而是：**在组合闭包内给出证书，在闭包外给出可执行的回退**。

**灵感 2（创新点挖掘 → 新颖性是一个可证伪的统计命题，不是一个文献姿态）**
直觉：研究者说「我们首次实现了 X」时，通常只做了两件事：引用几篇最像的论文，然后声称不同。这在方法论上是**不可证伪**的，而且系统性低估「已知方法的组合」——审稿人指出 A+B，往往不是恶意，而是因为**基线闭包**没有被建模。正确的做法与安全审计同构：把「已知工作」做成一个**可运行的密封基线面板**，把「能力」做成可测的探针，把「新颖」定义成「能力落在基线闭包之外，且存在一个消融能单独把它拿掉」。新颖性于是有了覆盖率、置信区间和反例。

更进一步：把「主张」本身作为被审计对象。CPB 保证「主张有证明」，NPM 保证「主张值得被提出」。两者合起来才是完整的蒸馏纪律：**没有被消融证明的主张不提，被基线闭包覆盖的主张不提，没有覆盖证书的主张不提。**

**灵感 3（综合 → 泛化与创新是同构的：都是闭包覆盖）**
直觉：语义泛化问「这个新指令是否在我校准过的意义闭包内」；创新挖掘问「这个新能力是否在已知方法的闭包外」。一个是**向内**的覆盖（我的证书覆盖了多大的意义空间），一个是**向外**的覆盖（我的贡献超出了多大的基线空间）。两者共享同一个数据结构——**覆盖证书 COV =（域，度量，半径，有效样本数，回退策略）**——和同一条定理——**闭包外无保证，覆盖外必回退**。

这一步把 R73 的隐含假设显式化，也让整栋理论更诚实：R73 的安全性其实一直是「有条件的安全性」，条件就是覆盖。GENGAUGE 不再假装无条件，而是把条件本身变成可审计、可组合、可拒绝的一等公民。

## 1. 形式化定义（增量：定义 383–402）

**定义 383（GENGAUGE-RAS 总览与六不变式）** GENGAUGE-RAS = (CVM, IGM, GCA, SRTA, CERVOI, NPM, CPB v2, MODGAUGE-RAS†)。六不变式：
(i) **契约完整性**（继承 R73）：模块图中每个节点实例化完整契约，缺一不可入图；
(ii) **组合单调性**（继承并扩展到语义）：任何组合路径不得凭空降低风险/不确定度；语义组合同样「无免费泛化」；
(iii) **反作用通道完备**（继承并扩展）：每个证据模块声明 χ_R，人类澄清动作作为**人类通道 χ_h** 纳入 ΣREFLEX；
(iv) **主张可识别性**（新增）：进入正文的每条主张必须有消融见证、基线闭包间隙与覆盖证书；三者缺一即为工程附件；
(v) **严格退化链扩展**（继承）：语义失效 → 语义 stub；覆盖缺失 → 显式回退；安全侧只增不减；
(vi) **覆盖显式性**（新增，本轮核心）：每张证书携带 COV；有效性是**覆盖相对**的；部署点落在覆盖外时必须触发契约声明的回退，禁止静默外推。

**定义 384（覆盖证书 COV 与覆盖相对有效性）** COV = (Γ, d_Γ, δ, n_eff, α, fallback)：
- Γ ⊆ 𝒳：覆盖域（部署条件/组合签名/能力探针的集合）；d_Γ 为其上的度量；δ 为覆盖半径；n_eff 为有效校准样本量（按组合签名分层后的最小类样本量，而非原始样本总数）；
- α：conformal 风险水平；fallback ∈ {CLARIFY, REFUSE, DEGRADE, WITHHOLD_CLAIM}。
**覆盖相对有效性**：记 Valid_Γ(J) 表示证书 J 仅在 Γ 上成立；对 x ∉ Γ，系统必须执行 fallback，且 fallback 的安全性不得依赖 J。定义**覆盖缺陷** defect(Γ) = Pr(x ∉ Γ)（若可估）；不可估时记为 UNKNOWN，并按最坏情况处理。系：**R73 的 Valid(J) 是 Valid_Γ(J) 在 Γ = 全集时的特例——而这个「全集」从来不该被默认。**

**定义 385（覆盖组合代数）** 三种组合下的覆盖传播：
- **SER**：Γ_out = Γ_A ∩ Γ_B；n_eff,out ≤ min(n_eff,A, n_eff,B)；组合深度每 +1，有效样本按签名类折减（n_eff ← n_eff/(1+depth)），因为新签名类上的校准样本更稀疏；
- **PAR**：仅当两者在 Γ_A ∩ Γ_B 上同时覆盖且一致性审计通过，才允许缩窄；否则取保守上界；Γ_out = Γ_A ∩ Γ_B；
- **VETO**：Γ_out = Γ_A ∩ Γ_B，任一否决即整体否决。
**覆盖衰减原理**：n_eff,out ≤ min(n_eff,A, n_eff,B)，且 Γ_out ⊆ Γ_A ∩ Γ_B；组合只会缩小覆盖、只会减少有效样本——**覆盖也不能凭空变好**（与引理 34 同构）。

**定义 386（语义指令项与接地指令代数 GIA）** 指令语言 L 的解析产生带类型项：
t ::= a | t₁ ; t₂ | t₁ ∧ t₂ | t₁ ⊕ t₂ | if φ then t₁ else t₂ | ∀/∃ x∈R. t | rel(t₁,t₂)
其中原子 a ∈ A 是带技能契约与语义类型 τ_a 的接地谓词/技能；R 为场景指代域。类型判定 Γ ⊢ t : τ 保证「放」不会接到「导航」的槽位。**接地程序** = 所有指代已绑定到场景实体、所有连续参数落入认证区间、所有原子属于认证原子集 A_π 的项。认证算子集 O_π ⊆ {; , ∧, ⊕, if, ∀, ∃, rel}。

**定义 387（释义后验与释义集）** p(prog | x, s, b_t) ∝ p(x | prog) · p(prog | s, b_t) · p(prog)，其中 s 为场景、b_t 为 R73 的 BSE 状态。**释义集** I_ε(x) = { prog : p(prog|x,s,b_t) ≥ ε }（或 top-k，k≤8）。歧义度 H_I = H[prog|x]。**关键立场**：系统从不对单一解析负责，只对**释义集**负责——这是「单源不定案」（E356/E357）在语义层的直接继承。

**定义 388（语义不确定度六分量）** 
u_instr² = u_lex² + u_ref² + u_scope² + u_aff² + u_param² + u_intent²
- u_lex：词义/谓词映射不确定度（「拿/取/抓」是否同义）；
- u_ref：指代不确定度（哪个杯子、哪个盘子、是否包含背景同类物）；
- u_scope：组合作用域/附着不确定度（「左边」修饰盘子还是杯子；量词辖域）；
- u_aff：可供性不确定度（当前位姿/深度/接触证据下该技能是否物理可行，复用 R73 的 d_ev/t_ev）；
- u_param：连续参数不确定度（「一点」「快」「轻」映射到阈值）；
- u_intent：字面意义之外的意图/偏好不确定度（人真正想达成什么）。
每分量有独立追溯链 τ_i，并在 SEAL-INSTR 上分层校准。系：**语义六分量与深度六分量、接触四分量共享同一套计量语法——只是物理机制换成了语言/指代/可供性机制。**

**定义 389（泛化域 G_π 与组合签名）** 组合签名 sig(prog) = (原子多重集, 算子多重集, 组合深度, 参数分箱, 指代类别)。**泛化域** G_π = { prog : sig(prog) ∈ Σ_π }，Σ_π 为接地模块 π 在校准集中实际覆盖的签名集合（按 d_sig 的 δ-邻域封闭）。**覆盖假设 A114（组合交换性）**：在同一签名 δ-邻域内，校准样本与部署样本条件可交换；跨出 δ-邻域则无有效保证，必须回退。

**定义 390（指令泛化证书 GC）** GC(x) = (F, sig, COV_sem, I_ε(x), u 向量, R̂_α(x), decision, seal_ref)：
- F：解析森林；sig：组合签名；COV_sem：语义覆盖证书；
- I_ε(x)：释义集；u 向量：六分量；R̂_α(x)：任务级风险的 conformal 上界（按签名分层）；
- decision ∈ {EXECUTE(p), CLARIFY(q), REFUSE}。
**有效性条件**：(a) I_ε(x) 中至少一个程序完全认证（原子 ⊆ A_π、深度 ≤ d_max、sig ∈ Σ_π）；(b) R̂_α(x) ≤ ε_task；(c) 所选 p 的解释在 I_ε 内且可追溯。任一不满足 ⇒ decision 不得为 EXECUTE。

**定义 391（语义组合算子与「无免费泛化」）** 
- **SEM-SEQ**（t₁;t₂）：类型链 A→B；风险上界相加，覆盖取交，深度 +1，无缩窄；
- **SEM-CONJ**（t₁∧t₂）：只有当约束彼此一致、且与物理证据/已认证交叉检查一致时，才允许**缩小**释义集（与 CCA 的 PAR 同构）；否则保守取并；
- **SEM-ALT**（t₁⊕t₂）：释义集为并，风险取 max；除非有证据排除一支，否则不得缩窄；
- **SEM-CLAR**：澄清是**证据获取算子**，不是语义组合算子；它消耗人类预算，产生新的证据，从而合法地缩小 I_ε。
**核心纪律**：语义组合本身从不缩小释义集；唯一合法的缩小来自**新证据**（物理观测或人类回答）。这就是「无免费泛化」——模型再大，也不能凭先验把歧义变确定性。

**定义 392（语义 stub）** I(x) = 𝒰（全体可执行程序），R̂ = ∞，COV = ∅，decision = REFUSE/CLARIFY，χ_h 平凡；仍参与 MReg 连通性校验；**不参与 SEM-CONJ/ALT 的任何缩窄**，因此不污染其他模块的审计（与定义 381 同构）。

**定义 393（澄清动作与人类信息模型）** 澄清动作 q ∈ Q，答案 y ∈ Y_q，人类回答模型 p(y | intent, q, human_state) 带可靠度 ρ_h；成本 c_h(q)（时间 + 认知负担）；合法问题集受安全/隐私约束（|Q| ≤ 6）。**威胁**：人类可能策略性回答、误解问题、或给出对抗性答案（见定义 402）。

**定义 394（CERVOI：澄清感知的统一信息价值）** 
a* = argmax_{a ∈ A_phys ∪ Q} [ E[ΔR | a] − λ_h · c_h(a) − Σ_i c_reflex^i(a) ]
s.t. REG 时序契约、ΣREFLEX 总预算、澄清轮数 ≤ 3、V_safe。
物理探索与人类提问被放进**同一个价值函数**：两者都是「花成本买信息」。这是 R72 ERVOI 的严格扩展——当 Q = ∅ 时退化为 ERVOI†。有限停止见引理 40。

**定义 395（SRTA：语义运行时保证）** 监控谓词（计量域 20Hz + 控制域只读快照）：
(1) **解释合规**：已执行前缀 ∈ I_ε(x)；
(2) **原子认证**：执行中出现的每个原子 ∈ A_π 且深度 ≤ d_max；
(3) **覆盖在域**：sig(执行路径) ∈ Σ_π；
(4) **风险在界**：R̂_α(x) ≤ ε_task；
(5) **预算闭合**：澄清轮数与 ΣREFLEX 未超。
任一违例 ⇒ **语义断路器**：暂停 → 澄清 → 拒绝，绝不「继续执行但打个日志」。

**定义 396（能力-主张格）** 能力探针 K = {k₁..k_K}，每个 k 有见证基准、通过谓词与预注册指标 μ_k。主张 c = (k, M_c, 基线对照, μ_k, 预测方向, 覆盖 COV_claim)。偏序：c₁ ⊑ c₂ 当且仅当 c₂ 的能力集包含 c₁ 且 c₂ 的消融见证包含 c₁ 的消融见证。主张格用于去重、合并与挑选极大元。

**定义 397（主张可识别性与新颖度证书）** 消融族 Abl(M)（|a| ≤ 3 的子集）。效应 α(m,k) 为移除 m 后 μ_k 的变化。**可识别**：∃a∈Abl(M) 使 |μ(S) − μ(S\a)| > δ_noise 且置信区间排除 0。基线覆盖率 cov(b,k) ∈ {0, 0.5, 1}（1=已复现匹配，0.5=文献声称但未复现）。**新颖度下界** N(k) = (1 − max_b cov(b,k)) · 1[identifiable] · L(k)，L(k) 为「承重性」（是否改变安全/保证性质，而非仅刷分）。新颖度证书 = (主张, 消融见证, 基线面板结果, 预注册指标, 置信区间, COV_claim)。**新颖性永远相对于 SEAL-NOVELTY，不声称绝对首次。**

**定义 398（SEAL-NOVELTY 与反炒作滤波）** 密封、可运行的基线面板（含 A+B 组合基线），在保持集上评估。**新颖 = 能力落在基线闭包 B* 之外且可识别**，其中 B* 是基线在允许组合规则下的闭包（显式建模「这不就是 A+B」）。反炒作五规则：无消融 ⇒ 拒；无机制 ⇒ 拒；无可运行基线 ⇒ 弱证据；无预注册 ⇒ 拒；效应在噪声内 ⇒ 拒。

**定义 399（主张归因与主张簇）** 对每个能力 k，模块贡献用 Shapley 值 φ_m(k) 在消融族上估计（|M|≤24，用蒙特卡洛子集，误差 ≤ ε_shapley）。**主张簇** = 两两交互效应显著（|φ_{m,m'} − φ_m − φ_{m'}| > δ）的模块等价类；簇内必须联合消融，禁止重复计数。φ_m 的 CI 含 0 ⇒ 非承重，降级为工程附件。

**定义 400（CPB v2 与 C4）** 继承 C1（物理感知证据计量）、C2（反作用预算组合）、C3（契约式模块化）；新增 **C4（覆盖审计的指令泛化）**：语义六分量 + 泛化证书 + 澄清预算，在组合 OOD 指令上降低**不安全执行率**且不增加（或降低）人类负担，显著优于（a）阈值化 LLM 规划器、（b）未按组合签名分层的 conformal 规划器、（c）逢疑必问。**每条主张必须携带 COV_claim；无覆盖证书的主张不得进正文。** NPM 作为方法论服务于主张集的挖掘与裁剪。

**定义 401（复杂度结构上限与语义退化链）** |A_π| ≤ 32、组合深度 ≤ 4、|I_ε| ≤ 8、|Q| ≤ 6、澄清轮数 ≤ 3、|K| ≤ 24、|a| ≤ 3、|𝓜| ≤ 5——全部为 MReg/主张格的**可审计图性质**。退化链：IGM 失效（覆盖空/奇异签名/风险超界）⇒ 语义 stub；GCA 失效 ⇒ 保守组合（不缩窄）；SRTA 失效 ⇒ 语义断路器；CERVOI 失效 ⇒ 禁用提问、只允许认证执行或拒绝；NPM 为离线方法，无运行时降级。安全侧只增不减。

**定义 402（指令威胁面 AIC-INSTR）** ℰ_instr = {歧义陷阱（故意使用未定义指代）、作用域攻击（「不是左边而是右边」类否定嵌套）、不可能指令（物理不可行但语义合理）、语言注入（指令中夹带越权命令）、策略性澄清回答（人类/对手故意误导）、指代投毒（场景中放置对抗性同名物）}。防线：释义集 + 单解析不定案 + SRTA + 人类回答可靠度建模 + 安全否决（VETO 不被语言置信度补偿）。

```python
# IP-302 CVM：覆盖证书与覆盖相对有效性
@dataclass(frozen=True)
class Coverage:
    domain: Domain                      # Γ：部署条件/签名/能力探针子集
    metric: Callable                    # d_Γ
    radius: float                       # δ
    n_eff: int                          # 分层后的最小类样本量（非原始 n）
    alpha: float
    fallback: str                       # CLARIFY/REFUSE/DEGRADE/WITHHOLD_CLAIM
    def covers(self, x): return self.metric(x, self.domain) <= self.radius
    def compose(self, other):           # 覆盖组合（定义 385）
        return Coverage(self.domain & other.domain, self.metric,
                        min(self.radius, other.radius),
                        min(self.n_eff, other.n_eff), max(self.alpha, other.alpha),
                        strongest(self.fallback, other.fallback))

# IP-303 IGM：指令泛化计量（计量域 20Hz；解析/接地在感知域预计算）
class InstructionGeneralizationMetrology:
    def certify(self, x, scene, b_t):
        forest = self.parser.parse(x, scene)             # 解析森林 F（带类型的项）
        I_eps  = topk_posterior(forest, scene, b_t, k=8) # 释义集（定义 387）
        u = dict(lex=self.u_lex(forest), ref=self.u_ref(forest, scene),
                 scope=self.u_scope(forest), aff=self.u_aff(I_eps, b_t, d_ev, t_ev),
                 param=self.u_param(forest, scene), intent=self.u_intent(x, b_t))
        sigs = [signature(p) for p in I_eps]             # 组合签名（定义 389）
        cov  = self.seal_instr.coverage(sigs)            # 按签名分层的 COV
        covered = [p for p, s in zip(I_eps, sigs) if cov.covers(s)]
        R_hat = self.seal_instr.conformal_risk(covered, alpha) if covered else INF
        if not covered or R_hat > EPS_TASK:
            q = self.cervoi.best_question(I_eps, u)       # 覆盖外：先问，再拒
            return GC(forest, sigs, cov, I_eps, u, R_hat,
                      decision=CLARIFY if q else REFUSE)
        p = argmin_expected_cost(covered, R_hat)          # 只在已覆盖集内选执行
        return GC(forest, sigs, cov, I_eps, u, R_hat, decision=EXECUTE(p))

# IP-304 GCA：语义组合代数（无免费泛化）
def sem_compose(a, b, op):
    if op == 'SEQ':   # 风险相加、覆盖取交、深度+1、不缩窄
        return GTerm(risk=a.risk + lipschitz(b, a.risk), cov=a.cov.compose(b.cov),
                     depth=a.depth + 1, I=a.I & b.I)
    if op == 'CONJ':  # 只有证据一致才允许缩窄（与 CCA-PAR 同构）
        if consistent(a, b) and audit.conformal_covers(cross_residual(a, b)):
            return GTerm(risk=fuse(a.risk, b.risk), cov=a.cov.compose(b.cov),
                         depth=max(a.depth, b.depth), I=a.I & b.I)
        return GTerm(risk=max(a.risk, b.risk), cov=a.cov.compose(b.cov),
                     depth=max(a.depth, b.depth), I=a.I | b.I, veto={'CONJ_AUDIT_FAIL'})
    if op == 'ALT':   # 并集、max、不缩窄
        return GTerm(risk=max(a.risk, b.risk), cov=a.cov.compose(b.cov),
                     depth=max(a.depth, b.depth), I=a.I | b.I)
    if op == 'STUB':  # 语义 stub（定义 392）
        return GTerm(risk=INF, cov=Coverage.empty(), depth=INF, I=UNIVERSE, decision=REFUSE)

# IP-305 SRTA：语义运行时保证（监控，非控制）
def srta_monitor(prefix, gc, budget):
    return (prefix in gc.I_epsilon and
            all(atom in gc.atoms and depth <= D_MAX for atom in prefix) and
            gc.cov.covers(signature(prefix)) and
            gc.R_hat <= EPS_TASK and budget.clarify_turns <= 3)

# IP-306 CERVOI：物理探索 + 人类提问的统一信息价值（定义 394）
def cervoi_step(gc, physical_actions, questions, state, budget, lam_h):
    best, best_val = None, -INF
    for a in list(physical_actions) + list(questions):
        dR = expected_risk_reduction(gc, a)                 # 物理用 χ_v/χ_R；提问用人类模型
        cH = lam_h * human_cost(a) if a in questions else 0.0
        cR = sum(m.reflex_cost(state[m], m.ec.chi_R(a)) for m in state)
        val = dR - cH - cR
        if val > best_val and budget.allows(a): best, best_val = a, val
    return best

# IP-307 NPM：新颖点挖掘（离线，密封基线面板）
def mine_claims(modules, capabilities, seal_novelty, ablations):
    B_star = seal_novelty.closure()                          # 已知方法的组合闭包 B*
    frontier = []
    for k in capabilities:                                   # 能力探针
        cov = max(seal_novelty.match(b, k) for b in B_star)  # 基线覆盖（0/0.5/1）
        for m in modules:
            if cov >= 1: continue                            # 落在基线闭包内：不新颖
            phi = shapley(modules, k, ablations)             # 贡献归因（定义 399）
            if not significant(phi[m]): continue             # 非承重：不是创新点
            if not identifiable(modules, m, k, ablations): continue
            frontier.append(Claim(k=k, module=m, contrast=B_star, phi=phi[m],
                                  cov=seal_novelty.coverage_of(k), load_bearing=True))
    return pareto(frontier, keys=('novelty', 'cost', 'refutability'))
```

## 3. 推导

**引理 38（语义六分量的条件正交性）** 给定解析森林、指代配置、场景、可供性上下文与人类模型，六分量分别由词汇知识、视觉指代、句法作用域、物理可行性、参数标定、偏好建模这六种独立机制产生，条件近似不相关；遗漏任一分量 ⇒ 系统性低估（与引理 33 同型，条件集从「视角/材质」换为「解析/指代/场景」）。系：**语义不确定度不是「给规划器加个置信度」，而是与深度/接触同构的物理-语义计量。**

**引理 39（无免费泛化：语义组合单调性 + 覆盖衰减）** SEM-SEQ 的风险上界相加、SEM-ALT 取 max、SEM-CONJ 只有在证据一致时才允许缩窄；同时 Γ_out ⊆ Γ_A ∩ Γ_B 且 n_eff,out ≤ min(n_eff,A,n_eff,B)。⇒ 任何组合路径都不可能同时做到「风险低于所有输入」且「覆盖不缩小」；对未见签名，A114 不成立 ⇒ 无有效上界。系：**泛化的极限不是模型容量，而是校准覆盖；组合越深，覆盖越薄。**

**引理 40（澄清的有限停止与预算吸收）** 每个澄清动作有正的人类成本下界 ε_h，且其期望信息增益随已获取信息递减（在定义 393 的回答模型下边际增益非增）；由引理 36 的 Σ 层推广与 CERVOI 的预算约束 ⇒ 存在有限澄清轮数 n* ≤ 3，且不耗尽物理反作用预算。系：**提问不是无限权利，而是有限预算下的信息投资。**

**引理 41（语义 stub 的零级联）** 语义 stub 的 I = 𝒰、R̂ = ∞、COV = ∅，且不参与 SEM-CONJ/ALT 的缩窄；任何与 stub 的组合都取保守分支（并集/max/否决）⇒ stub 只删除该指令路径的可用性，不污染其他模块的审计（与引理 35/定理 29 同构）。系：**语义失效的传染路径唯一：该指令不可执行，而不是整个系统不可信。**

**引理 42（可识别性 ⇔ 消融见证）** 若主张 c 在 Abl(M) 上可识别，则存在非空消融 a 使效应显著；反之，若不存在这样的 a，则 c 与「无该模块」及基线不可区分。⇒ NPM 的「无消融不主张」不是写作纪律，而是**可识别性的必要条件**。系：**主张不是叙事，而是可被消融推翻的因果命题。**

**引理 43（Shapley 归因的正确性与主张簇）** 在消融族上，Shapley 值是满足有效性/对称性/零贡献/可加性的唯一归因；当模块间存在显著交互时，成对交互项非零，必须按主张簇联合消融，否则朴素逐模块消融会重复计数。系：**「A+B 创新」的争议可以用交互项量化，而不是靠争论。**

**引理 44（覆盖相对可靠性）** 若 Valid_Γ(J) 且部署点 x ∈ Γ，则 J 的保证成立；若 x ∉ Γ 且 fallback 被执行，则系统安全性不依赖 J，只依赖 fallback 的保守性。⇒ R73 的定理 28 是 Γ = 𝒳 的特例；GENGAUGE 的定理 31 是它在任意 Γ 上的推广。系：**把所有「无条件安全」改写成「覆盖相对安全」，理论不会变弱，只会变诚实。**

**定理 30（GENGAUGE 严格包含 MODGAUGE）** 令指令为单原子、I_ε 为单元素、u_instr = 0、Q = ∅、COV = 全集、NPM 关闭，则 GENGAUGE 逐指令退化为 MODGAUGE（R73），再退化为 R72/R71/R68。由定义 383(v) 与引理 41，退化条件下语义层不引入额外风险。**安全单调不减，泛化能力只在覆盖内获益。**系：**新增语义层不是替换旧理论，而是把旧理论的隐含覆盖假设显式化。**

**定理 31（语义安全 + 泛化界）** 在 A114（组合交换性）、A115（语义本体对齐：真实意图以概率 ≥ 1−β 落在释义集内）、A116（SEAL-NOVELTY 覆盖相关能力空间）下：Valid(J_GEN) ⇒ 任务级风险 ≤ ε_mod + ε_sem + ε_gen + β·C_max，其中 ε_sem 来自语义六分量、ε_gen 来自组合签名覆盖缺陷、β 为语义模型失配概率。**证明重量落在 A115 与 A114：前者保证「我们讨论的是同一个意义」，后者保证「未见组合有统计基础」。** 系：**泛化保证不是「模型更强」，而是「覆盖更清楚 + 失配被定价」。**

**定理 32（语义降级的零级联）** 任一语义模块失效 ⇒ 语义 stub 或保守组合 ⇒ 由引理 41 与定义 401，系统逐指令退化为「该指令不可执行/需澄清」的少能力版本；其他模态与既有 R73 证书不受污染。系：**语义失效不会让系统变得更危险，只会让它更保守。**

**定理 33（NPM 前沿的可靠性与相对完备性）** 对给定的能力探针集 K 与密封基线面板 B：NPM 输出的每个主张都有消融见证、基线闭包间隙与覆盖证书（可靠性）；且任何不在输出中的「能力」要么被 B* 覆盖、要么不可识别、要么非承重（相对于 K 与 B 的完备性）。**绝对完备性不可得**——K 与 B 的覆盖本身是 A116；NPM 只能保证「在面板覆盖内不遗漏」。系：**创新点挖掘的诚实边界，就是基线面板的覆盖边界。**

**定理 34（CERVOI 的有限停止与统一最优性）** 在正人类成本、非增边际信息增益与 ΣREFLEX 预算闭合下，CERVOI 的联合策略（物理 + 人类）存在有限停止，且当 Q = ∅ 时逐点等于 ERVOI†；当物理动作集为空时退化为纯澄清策略。**统一价值函数不破坏各退化的最优性**（因为退化时另一项为空）。系：**「问人」与「自己看」不是两个系统，而是同一个信息预算下的两种动作。**

## 6. 本轮最大风险

**一句话**：GENGAUGE 把泛化安全的证明负担从「执行」转移到「**释义集、语义本体与覆盖假设**」——如果真实人类意图落在系统释义集的补集（语义模型失配），或组合覆盖假设 A114 在真实 OOD 分布下失效，那么系统会在**所有 GC 都有效、所有澄清都合规、所有主张都可识别**的情况下，对一个它从未正确理解的指令做出有证书的错误执行；审计日志会证明每一步都合规，却证明不了它理解了任务。

次级风险与缓解：
1. **语义本体失配（A115 被违反）** → 释义集显式包含「其他/无法归类」选项；低置信即澄清；跨语言/跨文化校准集；SEAL-INSTR 定期红队刷新；把 β 作为可报告的一等指标而非隐藏假设。
2. **覆盖半径 δ 无物理意义** → 组合签名度量需经 E393/E410 验证其预测力；δ 由数据驱动（覆盖内/外失败率差异）而非拍脑袋；覆盖外一律回退。
3. **NPM 的基线闭包不完整（未知未知）** → 只声称「相对 SEAL-NOVELTY 的新颖」；面板版本化 + 外部复现；对未复现文献标 0.5 而非 1；结论附覆盖敏感性（E411）。
4. **澄清疲劳与策略性回答** → 人类成本入预算、轮数硬上限 3、提问信息量阈值；对人类答案做鲁棒性/信任建模；关键安全命题不得由单一人类回答裁定。
5. **释义集爆炸导致过度澄清** → |I_ε| ≤ 8、按风险而非熵选问；CERVOI 的价值函数保证只在「信息价值 > 人类成本」时提问；E395/E408 监控负担。
6. **Shapley 在 |M|≤24 上仍昂贵** → 蒙特卡洛子集 + 主张簇降维；只对候选承重模块做精确归因；离线预算与运行时解耦。
7. **语义层拖慢计量域** → 解析/接地在感知域预计算；计量域只做覆盖判定 + 风险查表 + 组合；SRTA 控制在 20µs 级。
8. **C4 与 C2 的主张重叠（澄清也是信息动作）** → 用 E403 的交互项与主张簇显式归因；若交互项显著，C2/C4 合并为一条「信息动作预算」主张，而不是重复计数。

## 3. 关键算法伪代码

```python
# IP-302 CVM：覆盖证书与覆盖相对有效性
@dataclass(frozen=True)
class Coverage:
    domain: Domain                      # Γ：部署条件/签名/能力探针子集
    metric: Callable                    # d_Γ
    radius: float                       # δ
    n_eff: int                          # 分层后的最小类样本量
    alpha: float
    fallback: str                       # CLARIFY/REFUSE/DEGRADE/WITHHOLD_CLAIM
    def covers(self, x): return self.metric(x, self.domain) <= self.radius
    def compose(self, other):           # 定义 385：覆盖只缩不增
        return Coverage(self.domain & other.domain, self.metric,
                        min(self.radius, other.radius),
                        min(self.n_eff, other.n_eff), max(self.alpha, other.alpha),
                        strongest(self.fallback, other.fallback))

# IP-303 IGM：指令泛化计量（解析/接地在感知域预计算）
class InstructionGeneralizationMetrology:
    def certify(self, x, scene, b_t):
        forest = self.parser.parse(x, scene)              # 带类型项的解析森林
        I_eps  = topk_posterior(forest, scene, b_t, k=8)  # 释义集（定义 387）
        u = dict(lex=self.u_lex(forest), ref=self.u_ref(forest, scene),
                 scope=self.u_scope(forest), aff=self.u_aff(I_eps, b_t, d_ev, t_ev),
                 param=self.u_param(forest, scene), intent=self.u_intent(x, b_t))
        sigs = [signature(p) for p in I_eps]              # 组合签名
        cov  = self.seal_instr.coverage(sigs)             # 分层 COV
        covered = [p for p, s in zip(I_eps, sigs) if cov.covers(s)]
        R_hat = self.seal_instr.conformal_risk(covered, alpha) if covered else INF
        if not covered or R_hat > EPS_TASK:               # 覆盖外：问，或拒
            q = self.cervoi.best_question(I_eps, u)
            return GC(forest, sigs, cov, I_eps, u, R_hat,
                      decision=CLARIFY if q else REFUSE)
        p = argmin_expected_cost(covered, R_hat)           # 只在已覆盖集内执行
        return GC(forest, sigs, cov, I_eps, u, R_hat, decision=EXECUTE(p))

# IP-304 GCA：语义组合（无免费泛化）
def sem_compose(a, b, op):
    if op == 'SEQ':
        return GTerm(risk=a.risk + lipschitz(b, a.risk), cov=a.cov.compose(b.cov),
                     depth=a.depth + 1, I=a.I & b.I)
    if op == 'CONJ':
        if consistent(a, b) and audit.conformal_covers(cross_residual(a, b)):
            return GTerm(risk=fuse(a.risk, b.risk), cov=a.cov.compose(b.cov),
                         depth=max(a.depth, b.depth), I=a.I & b.I)
        return GTerm(risk=max(a.risk, b.risk), cov=a.cov.compose(b.cov),
                     depth=max(a.depth, b.depth), I=a.I | b.I, veto={'CONJ_AUDIT_FAIL'})
    if op == 'ALT':
        return GTerm(risk=max(a.risk, b.risk), cov=a.cov.compose(b.cov),
                     depth=max(a.depth, b.depth), I=a.I | b.I)
    if op == 'STUB':
        return GTerm(risk=INF, cov=Coverage.empty(), depth=INF, I=UNIVERSE, decision=REFUSE)

# IP-305 SRTA：语义运行时保证（只读监控）
def srta_monitor(prefix, gc, budget):
    return (prefix in gc.I_epsilon and
            all(atom in gc.atoms and depth <= D_MAX for atom in prefix) and
            gc.cov.covers(signature(prefix)) and
            gc.R_hat <= EPS_TASK and budget.clarify_turns <= 3)

# IP-306 CERVOI：物理探索 + 人类提问的统一信息价值
def cervoi_step(gc, physical_actions, questions, state, budget, lam_h):
    best, best_val = None, -INF
    for a in list(physical_actions) + list(questions):
        dR = expected_risk_reduction(gc, a)                # 物理用 χ_v/χ_R；提问用人类模型
        cH = lam_h * human_cost(a) if a in questions else 0.0
        cR = sum(m.reflex_cost(state[m], m.ec.chi_R(a)) for m in state)
        val = dR - cH - cR
        if val > best_val and budget.allows(a): best, best_val = a, val
    return best

# IP-307 NPM：新颖点挖掘（离线，密封基线面板）
def mine_claims(modules, capabilities, seal_novelty, ablations):
    B_star = seal_novelty.closure()                       # 已知方法的组合闭包
    frontier = []
    for k in capabilities:
        cov = max(seal_novelty.match(b, k) for b in B_star)
        if cov >= 1: continue                             # 落在基线闭包内：不新颖
        phi = shapley(modules, k, ablations)              # 贡献归因
        for m in modules:
            if not significant(phi[m]): continue          # 非承重
            if not identifiable(modules, m, k, ablations): continue
            frontier.append(Claim(k=k, module=m, contrast=B_star, phi=phi[m],
                                  cov=seal_novelty.coverage_of(k), load_bearing=True))
    return pareto(frontier, keys=('novelty', 'cost', 'refutability'))

# IP-309 GENGAUGE 主闭环（复用 R73 三域，新增语义覆盖门）
def GENGAUGE_round(M, obs, audio, tac_frame, depth_img, instruction):
    # === 感知域（100Hz）===
    d_ev = M.dpem.update(depth_img, rgb, M.cam_state, M.motion, M.peers)
    t_ev = M.dmem.update(tac_frame, M.last_action)
    gc   = M.igm.certify(instruction, M.scene, M.bse.state)
    # === 计量域（50Hz）===
    if M.clock.due_metric():
        if gc.decision is CLARIFY:
            q = M.cervoi.best_question(gc.I_epsilon, gc.u)
            M.last_q = q; return CLARIFY(q)                 # 只花人类预算
        if gc.decision is REFUSE:
            return REFUSE(gc)                               # 覆盖外：结构性停止

            s2, cost = M.cervoi.commit(g, M.state, M.budget)  # 统一物理+人类预算
            if s2 is not None: M.last_g, M.state = g, s2
        M.mreg.audit()
    # === 控制域（1kHz，只读快照）===
    snap = M.snapshot.read_latest()
    if not srta_monitor(snap.executed_prefix, snap.gc, snap.budget):
        return M.breaker.trip(REASON='SEMANTIC_COVERAGE')    # 语义断路器
    lam = embodied_risk_scale(snap.U_ale, snap.U_epi, snap.H_z,
                              max(snap.t_ev.u, snap.d_ev.u, snap.gc.u_instr), M.risk_params)
    A = M.ach.propose_ctrl(..., pvop_bias=snap.pvop)
    k = M.c_ras_wm.certified_prefix(A, lam)
    M.ctrl_out.publish(k, lam)
    return k, lam, J_GEN(M.mreg, snap.gc)                    # J_MOD ⊗ GC
```

## 4. 推导

**引理 38（语义六分量条件正交性）** 六分量由词汇知识、视觉指代、句法作用域、物理可行性、参数标定、偏好建模六种独立机制产生，条件近似不相关；遗漏任一分量 ⇒ 系统性低估。系：**语义计量与深度/接触计量同构。**

**引理 39（无免费泛化）** SEM-SEQ 风险相加、SEM-ALT 取 max、SEM-CONJ 仅在证据一致时缩窄；Γ_out⊆Γ_A∩Γ_B 且 n_eff,out≤min；未见签名下 A114 不成立 ⇒ 无有效上界。系：**泛化的极限是覆盖，不是容量；组合越深，覆盖越薄。**

**引理 40（澄清有限停止）** 人类成本有正下界 ε_h、边际信息增益非增，结合 ΣREFLEX 预算闭合 ⇒ 有限轮数 n*≤3，且不耗尽物理反作用预算。系：**提问是有限预算下的信息投资，不是无限权利。**

**引理 41（语义 stub 零级联）** stub 的 I=𝒰、R̂=∞、COV=∅，且不参与缩窄；与任何模块组合都取保守分支 ⇒ 只删除该指令路径，不污染其他审计。系：**语义失效让系统更保守，而不是更危险。**

**引理 42（可识别性 ⇔ 消融见证）** 可识别 ⇒ 存在显著消融；不存在 ⇒ 与「无该模块」及基线不可区分。系：**主张是可被消融推翻的因果命题，不是叙事。**

**引理 43（Shapley 归因与主张簇）** Shapley 是满足四公理的唯一归因；显著交互 ⇒ 必须联合消融，否则朴素逐模块消融重复计数。系：**「A+B」争议可用交互项量化。**

**引理 44（覆盖相对可靠性）** x∈Γ 时 Valid_Γ(J) 成立；x∉Γ 且 fallback 执行时安全性只依赖 fallback 的保守性。⇒ R73 定理 28 是 Γ=𝒳 特例。系：**把「无条件安全」改成「覆盖相对安全」，理论更诚实而非更弱。**

**定理 30（GENGAUGE 严格包含 MODGAUGE）** 单原子、单释义、u_instr=0、Q=∅、COV=全集、NPM 关闭 ⇒ 逐指令退化为 R73，再退化 R72/R71/R68；由定义 383(v) 与引理 41，语义层不引入额外风险。**安全单调不减。**

**定理 31（语义安全 + 泛化界）** 在 A114/A115/A116 下：Valid(J_GEN) ⇒ 任务风险 ≤ ε_mod + ε_sem + ε_gen + β·C_max。证明重量落在 A115（语义本体对齐）与 A114（组合交换性）。系：**泛化保证 = 更清楚的覆盖 + 被定价的失配。**

**定理 32（语义降级零级联）** 语义模块失效 ⇒ stub/保守组合 ⇒ 逐指令退化为少能力版本；其他模态与 R73 证书不受污染。系：**语义失效不会级联成系统级危险。**

**定理 33（NPM 前沿可靠性与相对完备性）** 对给定 K 与 B，输出主张均有消融见证、基线闭包间隙、覆盖证书；未输出的能力要么被 B* 覆盖、要么不可识别、要么非承重（相对 K、B 完备）。绝对完备不可得（A116）。系：**创新挖掘的诚实边界 = 基线面板的覆盖边界。**

**定理 34（CERVOI 有限停止与统一最优性）** 正人类成本 + 非增边际增益 + 预算闭合 ⇒ 有限停止；Q=∅ 时逐点等于 ERVOI†；物理动作集为空时退化为纯澄清。系：**「问人」与「自己看」是同一预算下的两种动作。**

## 7. 本轮最大风险

**一句话**：GENGAUGE 把泛化安全的证明负担从「执行」转移到「**释义集、语义本体与覆盖假设**」——如果真实人类意图落在释义集补集（语义模型失配），或 A114 在真实 OOD 下失效，那么系统会在所有 GC 有效、所有澄清合规、所有主张可识别的情况下，对一个它从未正确理解的指令做出有证书的错误执行；审计日志证明每一步合规，却证明不了它理解了任务。

次级风险与缓解：
1. **语义本体失配（A115）** → 释义集含「其他/无法归类」；低置信即澄清；跨语言/文化校准；SEAL-INSTR 红队刷新；β 作为一等可报告指标。
2. **δ 无物理意义** → 由 E393/E410 数据驱动标定；覆盖内/外失败率差异作为 δ 的校准依据；覆盖外一律回退。
3. **基线闭包不完整** → 只声称相对 SEAL-NOVELTY 的新颖；面板版本化 + 外部复现；未复现文献标 0.5；附覆盖敏感性（E411）。
4. **澄清疲劳/策略性回答** → 人类成本入预算、轮数硬上限 3、信息量阈值；人类答案鲁棒性建模；关键安全命题不由单一回答裁定。
5. **释义集爆炸/过度澄清** → \|I_ε\|≤8、按风险而非熵提问、价值函数门控；E395/E408 监控负担。
6. **Shapley 昂贵** → 蒙特卡洛 + 主张簇降维 + 只对候选承重模块精确归因；离线与运行时解耦。
7. **语义层拖慢计量域** → 解析/接地感知域预计算；计量域只做覆盖判定 + 查表 + 组合；SRTA <20µs。
8. **C4 与 C2 重叠** → E403 交互项显式归因；若显著则合并为「信息动作预算」单条主张，避免重复计数。
