# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「奖励设计」×「模仿学习」）

> 第 54 轮把技能组合从“能力匹配”升级为“动作空间剖面 α_S + 鲁棒性谱 ρ + 云边联合证书 J”。但该体系有一个结构性盲点：**α_S 与 ρ 都是“被给定/被校准”的量，技能从何学来、优化目标是否正确，从未被审计**。本轮用「奖励设计」×「模仿学习」两条灵感直击该盲点：奖励不是一个标量，而是一个与示范一致的**可行奖励集 𝓡_D**（携带模糊度 ε_R 与最坏情形 regret）；示范也不给出全域能力，而只给出**信任动作域 A_trust**。核心矛盾：H22：模仿策略在示范分布内动作剖面覆盖良好，一旦 covariate shift 进入外推区，α_S 与组合证书出现**虚假兼容**，组合误差沿 horizon 复合；H23：奖励误设被优化器放大为 reward hacking，表现为策略把动作概率质量**外溢到示范零测集**，而现有证书对此完全不可见。

## 0. 直觉与动机

**灵感 1（奖励设计 → 奖励是可辨识集合，而非一个标量）**
直觉：人工 hand-tune 的奖励 `r` 只是一个点估计，没有误差棒；一旦策略在错误 `r` 上优化，优化器会把误设放大成 reward hacking。正确做法是把奖励建模为**与示范一致的可行奖励集** `𝓡_D`（MaxEnt IRL / 贝叶斯 IRL 的后验置信集），证书直接携带 **奖励模糊度 `ε_R`** 与在该集合上的**最坏情形 regret**。于是“奖励设计”从调参变成可审计的集合估计：**先证奖励可辨识，再谈策略最优**。

**灵感 2（模仿学习 → 示范只给出“信任动作域”）**
直觉：BC 的核心病是 covariate shift——策略一旦偏离专家分布，误差沿 horizon 复合（经典 `O(εT²)`）。因此第 54 轮的动作剖面 `α_S` 必须**劈成两半**：由示范支撑的 `A_trust`（可信）与靠外推的 `A_buffer`（假设）。只有落在 `A_trust` 内的组合证书才可信；`A_buffer` 里的“兼容”只是插值幻觉，必须降级处理。

**灵感 3（把两者接起来 → reward hacking 的动作空间签名）**
直觉：reward hacking 在动作空间上表现为**策略把概率质量扩张到示范零测集**，即 `π̂(a)>0` 却 `μ_D(a)≈0`。于是 `α_S` 剖面 + 示范密度 `μ_D` 天然构成一个**可检测的 hacking 签名** `E_hack`——“奖励外溢 = 动作剖面越过示范支撑”。这样，奖励设计问题被翻译成一个**动作支持集审计问题**，与前两轮的动作空间体系无缝咬合。

**灵感 4（云边协同 → DAgger 的天然对应）**
直觉：云端 = 专家/奖励设计者，边端 = 模仿学习者。第 54 轮已有 `Explain_loop` 反向信道，本轮把它扩展为 `Label_loop` 与 `Reward_loop`：边端把高不确定性状态回传，云端在**干预预算 `τ_q`** 内给出专家动作或偏好，边端聚合再训练并回传漂移 `δ_IL`。闭环 = **云标注 - 边模仿 - 漂移回传 - 重校准**，与第 54 轮的“云规划 - 边校验”形成双闭环。

**灵感 5（组合的复合误差 → 模仿感知兼容性）**
直觉：多技能串联时，每个技能的模仿漂移会在剩余 horizon 上递归放大。因此“动作兼容”之外须加一条**模仿感知兼容性**：`A_trust` 交集足够大 **且** 复合漂移 `Δ_IL` 在预算内。否则两个单独可靠的模仿技能，组合起来会因为切换点处的分布漂移而系统性失败。

**灵感 6（金字塔加两层 → 学习层 𝕀 与奖励层 ℝ）**
直觉：在第 54 轮动作协同层 `𝔸` 之上叠加 **学习层 `𝕀`**（示范支撑、信任域、漂移）与 **奖励层 `ℝ`**（奖励集、模糊度、外溢探针）。跨层证书需同时携带 `ρ`、`A_cert`、`ε_R`、`A_trust`、`Δ_IL`，形成 **动作-鲁棒性-奖励-模仿四元证书体系**。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（示范数据集与行为占据测度）**
示范数据 `D = {(s_i,a_i)}_{i=1}^N ∼ d_{π_E} × π_E(·|s)`。在规范动作网格 `A` 上定义**行为占据测度**
```
μ_D(a) = ∫_S μ_D(s,a) ds,   μ_D(s,a) = KDE_D(s,a)
```
其支撑 `supp(D) = {a : μ_D(a) > 0}`。`μ_D` 是对专家动作分布的**非参数估计**，用于判定“某动作是否被示范支持”。

**定义 122（信任动作域）**
给定阈值 `θ_d` 与显著性 `δ`，**信任动作域**
```
A_trust(S; θ_d, δ) = { a ∈ A : μ_D(a) ≥ θ_d }
```
经 split-conformal 校准，使在可交换校准集上 `P(a ∈ Ĉ_trust) ≥ 1 - δ`。语义：`A_trust` 内 `α_S` 由示范支撑，可信；`A_buffer = A_core \ A_trust` 内的 `α_S` 只是外推假设，必须签发“假设级”而非“证据级”证书。

**定义 123（可辨识奖励集与奖励模糊度）**
以线性特征 `r_θ(s,a) = θᵀφ(s,a)` 为例，MaxEnt IRL 后验
```
P(θ|D) ∝ exp( Σ_i log π_θ(a_i|s_i) - λ‖θ‖² )
```
**可行奖励集** `𝓡_D = { r_θ : θ ∈ Θ_{1-α_R} }`（后验 `1-α_R` 置信椭球）。**奖励模糊度**
```
ε_R = sup_{r,r'∈𝓡_D} ‖r - r'‖_∞ / R_scale
```
衡量“在示范一致的前提下，奖励还能有多不确定”。`ε_R` 越大，任何策略最优性声明越弱。

**定义 124（模仿-奖励证书）**
```
C_IL = ( 𝓡_D, A_trust, ε_R, Δ_IL, E_hack, evidence )
```
- `𝓡_D` 可辨识奖励集；
- `A_trust` 信任动作域；
- `ε_R` 奖励模糊度；
- `Δ_IL` 模仿复合漂移界（定义 125）；
- `E_hack` 奖励外溢度量（定义 126）；
- `evidence` 至少含示范清单、IRL 超参与置信校准日志、DAgger 干预记录、conformal 覆盖率记录。**仅当 `ε_R ≤ Θ_R`、`Δ_IL ≤ Θ_IL`、`E_hack ≤ Θ_h` 且 `dom(T)=in` 时，证书标记为“证据级”**，否则为“假设级”。

**定义 125（模仿复合漂移界）**
单技能 BC 的误差满足 `J(π_E) - J(π) ≤ C·ε·H²`（`ε` 为单步模仿误差，`H` 为 horizon）。对技能序列 `⟨S_1,...,S_k⟩`，定义
```
Δ_IL(⟨S_1..S_k⟩) = Σ_{j=1}^{k} δ_IL(S_j) · ( H_j + L·H_{>j} )
```
其中 `δ_IL(S_j) = sup_{s∈d_{π}} d(a_π(s), a_{π_E}(s))` 为动作漂移，`H_{>j}` 为切换点之后的剩余 horizon，`L` 为技能边界误差放大 Lipschitz 常数。该项刻画“**前期漂移会在后期 horizon 上利滚利**”。

**定义 126（奖励外溢 / reward hacking 签名）**
对策略 `π` 与示范占据测度 `μ_D`，
```
E_hack(π) = vol({ a ∈ A_support : π̂(a) ≥ θ_π 且 μ_D(a) < θ_d }) / vol(A_support)
```
即“策略高概率动作中、**示范几乎不支持**的比例”。**reward hacking 判定**：`E_hack(π) > Θ_h`。语义：奖励设计一旦误设，优化器就会把动作概率推向 `supp(D)` 之外的“奖励高但无人示范”的区域——这正是动作剖面越过示范支撑，故可由第 54 轮的 `α_S` 与 `μ_D` 直接审计。

## 2. 关键算法 伪代码

### IP-121 RIC（Reward Identification Certificate）

```python
def reward_identification(demos, feature_map, lam, alpha_R=0.05, n_ens=32):
    # MaxEnt IRL + bootstrap 集成，得到后验置信集
    Rs = []
    for b in bootstrap(demos, n_ens):
        theta = maxent_irl(feature_map, b, lam)
        Rs.append(lambda s, a: theta @ feature_map(s, a))
    R_hat = mean(Rs)
    R_lo = quantile(Rs, 0.025)
    R_hi = quantile(Rs, 0.975)
    eps_R = max_total_variation(R_lo, R_hi) / reward_scale(R_hat)
    if eps_R > Theta_R:
        return ('weak', RewardCert(R_hat, (R_lo, R_hi), eps_R),
                'need_more_demos_or_preferences')
    return ('ok', RewardCert(R_hat, (R_lo, R_hi), eps_R))
```

### IP-122 TAD（Trusted Action Domain, conformal）

```python
def trusted_action_domain(demos, action_grid, theta_d=0.05, alpha_c=0.1):
    mu_D = kde_density(demos, action_grid)
    calib, holdout = split(demos, 0.5)
    scores = [mu_D(a) for (s, a) in calib]
    q = conformal_quantile(scores, alpha_c)          # 单侧分位
    def A_trust(s):
        return {a for a in action_grid if mu_D(a) >= max(theta_d, q)}
    cover = empirical_coverage(A_trust, holdout)     # 应在 1-alpha_c 附近
    return A_trust, mu_D, q, cover
```

### IP-123 DAL（DAgger 式云边主动模仿）

```python
def dagger_cloud_edge(pi, cloud_expert, edge_env, budget_q, rounds, delta_budget):
    D = init_demos
    drift = estimate_drift(pi, D)
    for t in range(rounds):
        states = rollouts(pi, edge_env)               # 边端执行，暴露新状态
        k = budget_q // rounds
        queries = select_by_disagreement(states, pi, cloud_expert, k)  # 不确定性优先
        D += [(s, cloud_expert.act(s)) for s in queries]              # 云端标注
        pi = train_bc(D)
        drift = estimate_drift(pi, D)
        if drift <= delta_budget:
            break
    return pi, D, drift, {'queries': budget_q, 'rounds': t + 1}
```

### IP-124 RHP（Reward Hacking Probe）

```python
def reward_hacking_probe(pi, R_cert, mu_D, action_grid, theta_pi, theta_d, Theta_h):
    # (a) 动作支持集审计：策略高概率动作中示范不支持的比例
    high_prob = {a for a in action_grid if pi.act_prob(a) >= theta_pi}
    hack_set = {a for a in high_prob if mu_D(a) < theta_d}
    E_hack = vol(hack_set) / max(vol(high_prob), 1e-9)
    # (b) 奖励集内对抗扰动：在 𝓡_D 内寻找放大该区域收益的奖励
    worst_gain = 0.0
    for r in R_cert.sample_set(m=64):
        gain = expected_return(pi, r) - expected_return(pi_E, r)
        worst_gain = max(worst_gain, gain)
    if E_hack > Theta_h or worst_gain > Theta_gain:
        return ('flag', 'reward_hacking', E_hack, worst_gain, hack_set)
    return ('ok', E_hack, worst_gain)
```

### IP-125 ICC（Imitation-aware Composition Certificate）

```python
def imitation_aware_compose(skill_seq, theta_d, delta_IL_budget, theta_trust, rho_min, K):
    A_core = intersection([s.alpha for s in skill_seq])
    A_trust = intersection([s.trusted_domain for s in skill_seq])
    overlap = vol(A_core & A_trust) / max(vol(A_core), 1e-9)
    delta_IL = imitation_drift(skill_seq, L=skill_boundary_lipschitz)
    if overlap < theta_trust:
        return ('reject', 'trust_gap', overlap)          # 外推区过大
    if delta_IL > delta_IL_budget:
        return ('reject', 'imitation_drift', delta_IL)   # 复合漂移超预算
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    if min(rho_comp.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_comp)
    return ('ok', ILCert(A_core, A_trust, overlap, delta_IL, rho_comp))
```

### IP-126 IRC（Imitation-Reward Joint Certificate）

```python
def imitation_reward_certificate(skill_seq, R_cert, TAD, ICC, horizon, Theta_regret):
    eps_R = R_cert.eps_R
    delta_IL = ICC.delta_IL
    regret_bound = eps_R * horizon + delta_IL * reward_lipschitz(R_cert.R_hat)
    verdict, E_hack, worst_gain, _ = reward_hacking_probe(
        ICC.pi, R_cert, TAD.mu_D, TAD.action_grid, ...)
    if regret_bound > Theta_regret:
        return ('reject', 'reward_ambiguity', regret_bound)
    if verdict == 'flag':
        return ('reject', 'reward_hacking', E_hack, worst_gain)
    level = 'evidence' if (ICC.overlap >= theta_trust and delta_IL <= delta_IL_budget) else 'hypothesis'
    return ('ok', JointILCert(R_cert, TAD.A_trust, eps_R, delta_IL, E_hack, regret_bound, level))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RIC | O(N·d·n_ens + n_ens·|S||A|) | O(d·n_ens + |S||A|) | 特征线性可辨识、后验覆盖 |
| TAD | O(N·|A| + |A| log |A|) | O(|A|) | conformal 可交换性、密度估计一致 |
| DAL | O(rounds·(H·|A| + budget_q·|A|)) | O(|D|) | 干预预算闭合、漂移单调下降 |
| RHP | O(|A| + 64·H·|A|) | O(|A|) | 外溢度量精确、对抗扰动覆盖 |
| ICC | O(k·|A| + |𝔇_ρ|) | O(k·|A|) | trust 交集 sound、漂移界递归成立 |
| IRC | O(IRC 子过程) | O(|A|+|𝔇_ρ|) | 各失败通道独立可审计 |

**正确性定理（Imitation-Reward Certified Policy Transfer, IRCPT）**
假设第 54 轮 (A22)–(A28) 成立，并新增：**(A29)** DAgger 纠偏后部署分布与示范在信任域内满足（加权）conformal 可交换性，覆盖率下界 `1-δ_conf`；**(A30)** 奖励集 `𝓡_D` 以概率 `1-α_R` 覆盖真奖励，且 `ε_R` 有界；**(A31)** 模仿漂移满足定义 125 的递归界，技能边界 Lipschitz 常数 `L` 可估；**(A32)** 外溢度量 `E_hack` 可在 `|A_grid|` 上精确估计、对抗奖励采样覆盖 `𝓡_D`。
则部署成功概率满足
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - ε_R·H - Δ_IL - P(E_hack>Θ_h) - δ_conf
```
关键：**每一项对应一条可独立审计的失败通道**——鲁棒性(`ρ`)、环境(`β_E`)、动作对齐(`δ_a`)、奖励歧义(`ε_R·H`)、模仿漂移(`Δ_IL`)、奖励外溢(`E_hack`)、信任域外覆盖(`δ_conf`)。任一通道可单独收紧，不必牺牲其余通道的保守性。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 奖励可辨识度 | `𝓡_D` 对真奖励的覆盖率 / 归一化 regret | 覆盖 ≥ 95%，regret ≤ 0.08 |
| E163 信任域有效性 | conformal 经验覆盖率 / `A_trust` 体积比 | 覆盖率 ≥ 1-δ，体积比 ≥ 60% |
| E164 DAgger 干预效率 | `Δ_IL` 随 query budget 的下降曲线 | 预算内 `Δ_IL` 达预算阈值，干预数 ≤ τ_q |
| E165 reward hacking 检出 | 检出率 / 误报率（3 类误设：稀疏、偏移、代理奖励） | 检出 ≥ 90%，误报 ≤ 5% |
| E166 模仿感知组合 | 组合部署成功率 vs v31（仅 α+ρ） | 提升 ≥ 15%，负迁移率下降 ≥ 40% |

E165 的三类奖励误设**必须显式构造**：(i) 稀疏奖励导致的探索性外溢；(ii) 偏移奖励导致的常量行为偏移；(iii) 代理奖励导致的“高奖励但无人示范”动作。三者都应在动作支持集上留下不同形态的 `E_hack` 签名，用于检验探针不是只对单一模式敏感。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 奖励集覆盖不足（模型误设） | 高 | 奖励集成 + 主动偏好询问 + 对抗特征池 |
| conformal 可交换性在 shift 下失效 | 高 | 加权 conformal + 在线覆盖率监测 + DAgger 纠偏前置 |
| DAgger 查询预算与实时性冲突 | 中 | 云端异步批标注 + 不确定性优先采样 + 缓存复用 |
| reward hacking 探针漏检（新型外溢） | 高 | 多目标对抗扰动 + `α_S`/`μ_D` 外推审计 + 红队动作生成 |
| 示范数据偏置/长尾缺失 | 高 | 主动示范请求 + 安全回退到已验证技能 + 拒绝采样 |
| 组合跨技能误差放大 | 中 | 边界 Lipschitz 约束 + 切换点重校准 + 漂移预算动态分配 |
| 证书降级不被上游尊重 | 中 | `evidence`/`hypothesis` 双级证书 + 部署门禁强制校验 |

## 6. 本轮最大风险

**一句话**：把「奖励设计」形式化为可辨识集合 `𝓡_D`、把「模仿学习」形式化为信任动作域 `A_trust` 与复合漂移 `Δ_IL`，让证书首次能同时审计“目标对不对”与“技能学得像不像”，但其 soundness **三重依赖 conformal 可交换性在分布漂移下仍成立、奖励集真正覆盖真奖励、以及外溢探针能捕获未见过的新型 hacking 模式**；一旦部署分布系统性越出示范支撑，`A_trust` 会给出**虚假的信任证书**、`ε_R` 与 `Δ_IL` 同时低估，组合策略会在“看似有证据、实为外推”的区域自信地失效，故必须以 **加权 conformal + 奖励集对抗扩张 + 外溢绊线** 三重护栏，并坚持“证据级证书只在信任域内签发”，宁可把外推区标成假设级，也绝不把奖励可辨识的假象当作策略最优的前提。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（RIC×TAD×DAL×RHP×ICC×IRC）

> 承接第 54 轮产物 v31。本轮在层级化鲁棒性 + 动作空间协同体系之上，增加 **奖励可辨识、信任动作域、云边主动模仿、奖励外溢探针、模仿感知组合、模仿-奖励联合证书** 六大算子：
> - **RIC（Reward Identification Certificate）**：把奖励从标量升级为可行集 `𝓡_D`，签发模糊度 `ε_R` 与 regret 界；
> - **TAD（Trusted Action Domain）**：用 conformal 把 `α_S` 劈成由示范支撑的 `A_trust` 与外推的 `A_buffer`；
> - **DAL（DAgger Cloud-Edge Active Imitation）**：云端专家标注 ↔ 边端模仿学习的干预闭环；
> - **RHP（Reward Hacking Probe）**：以“动作剖面越过示范支撑”作为 hacking 的动作空间签名；
> - **ICC（Imitation-aware Composition Certificate）**：组合时同时约束 `A_trust` 交集与复合漂移 `Δ_IL`；
> - **IRC（Imitation-Reward Joint Certificate）**：把奖励歧义与外溢并入统一证书，输出证据级/假设级两级判定。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/117/118 以纳入奖励与模仿维度。

## 2. 关键算法 伪代码

### IP-121 RIC

```python
def reward_identification(demos, feature_map, lam, alpha_R=0.05, n_ens=32):
    Rs = []
    for b in bootstrap(demos, n_ens):
        theta = maxent_irl(feature_map, b, lam)
        Rs.append(lambda s, a: theta @ feature_map(s, a))
    R_hat = mean(Rs)
    R_lo, R_hi = quantile(Rs, 0.025), quantile(Rs, 0.975)
    eps_R = max_total_variation(R_lo, R_hi) / reward_scale(R_hat)
    level = 'evidence' if eps_R <= Theta_R else 'hypothesis'
    return RewardCert(R_hat, (R_lo, R_hi), eps_R, level)
```

### IP-122 TAD

```python
def trusted_action_domain(demos, action_grid, theta_d=0.05, alpha_c=0.1):
    mu_D = kde_density(demos, action_grid)
    calib, holdout = split(demos, 0.5)
    scores = [mu_D(a) for (s, a) in calib]
    q = conformal_quantile(scores, alpha_c)
    def A_trust(s):
        return {a for a in action_grid if mu_D(a) >= max(theta_d, q)}
    cover = empirical_coverage(A_trust, holdout)
    return A_trust, mu_D, q, cover     # cover 应接近 1-alpha_c
```

### IP-123 DAL

```python
def dagger_cloud_edge(pi, cloud_expert, edge_env, budget_q, rounds, delta_budget):
    D = init_demos
    drift = estimate_drift(pi, D)
    for t in range(rounds):
        states = rollouts(pi, edge_env)
        k = budget_q // rounds
        queries = select_by_disagreement(states, pi, cloud_expert, k)
        D += [(s, cloud_expert.act(s)) for s in queries]
        pi = train_bc(D)
        drift = estimate_drift(pi, D)
        if drift <= delta_budget:
            break
    return pi, D, drift, {'queries_used': (t + 1) * k, 'rounds': t + 1}
```

### IP-124 RHP

```python
def reward_hacking_probe(pi, R_cert, mu_D, action_grid, theta_pi, theta_d, Theta_h):
    high_prob = {a for a in action_grid if pi.act_prob(a) >= theta_pi}
    hack_set = {a for a in high_prob if mu_D(a) < theta_d}
    E_hack = vol(hack_set) / max(vol(high_prob), 1e-9)
    worst_gain = 0.0
    for r in R_cert.sample_set(m=64):        # 在 𝓡_D 内对抗搜索
        worst_gain = max(worst_gain,
                         expected_return(pi, r) - expected_return(pi_E, r))
    if E_hack > Theta_h or worst_gain > Theta_gain:
        return ('flag', E_hack, worst_gain, hack_set)
    return ('ok', E_hack, worst_gain)
```

### IP-125 ICC

```python
def imitation_aware_compose(skill_seq, theta_d, delta_IL_budget, theta_trust, rho_min, K):
    A_core = intersection([s.alpha for s in skill_seq])
    A_trust = intersection([s.trusted_domain for s in skill_seq])
    overlap = vol(A_core & A_trust) / max(vol(A_core), 1e-9)
    delta_IL = imitation_drift(skill_seq, L=skill_boundary_lipschitz)
    if overlap < theta_trust:
        return ('reject', 'trust_gap', overlap)
    if delta_IL > delta_IL_budget:
        return ('reject', 'imitation_drift', delta_IL)
    rho_comp = compose_robustness_chain([s.rho for s in skill_seq], K)
    if min(rho_comp.values()) < rho_min:
        return ('reject', 'robustness_fail', rho_comp)
    return ('ok', ILCert(A_core, A_trust, overlap, delta_IL, rho_comp))
```

### IP-126 IRC

```python
def imitation_reward_certificate(skill_seq, R_cert, TAD, ICC, horizon, Theta_regret):
    eps_R, delta_IL = R_cert.eps_R, ICC.delta_IL
    regret_bound = eps_R * horizon + delta_IL * reward_lipschitz(R_cert.R_hat)
    verdict, E_hack, worst_gain = reward_hacking_probe(
        ICC.pi, R_cert, TAD.mu_D, TAD.action_grid,
        theta_pi=.1, theta_d=.05, Theta_h=.1)
    if regret_bound > Theta_regret:
        return ('reject', 'reward_ambiguity', regret_bound)
    if verdict == 'flag':
        return ('reject', 'reward_hacking', E_hack, worst_gain)
    level = 'evidence' if (ICC.overlap >= .8 and delta_IL <= budget_IL) \
            else 'hypothesis'
    return ('ok', JointILCert(R_cert, TAD.A_trust, eps_R,
                              delta_IL, E_hack, regret_bound, level))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RIC | O(N·d·n_ens + n_ens·|S||A|) | O(d·n_ens + |S||A|) | 特征可辨识、后验覆盖 ≥ 1-α_R |
| TAD | O(N·|A| + |A| log |A|) | O(|A|) | conformal 覆盖 ≥ 1-δ |
| DAL | O(rounds·(H·|A| + τ_q·|A|)) | O(|D|) | 干预 ≤ τ_q，漂移单调下降 |
| RHP | O(|A| + 64·H·|A|) | O(|A|) | 外溢度量精确、对抗覆盖 𝓡_D |
| ICC | O(k·|A| + |𝔇_ρ|) | O(k·|A|) | trust 交集 sound、漂移界递归 |
| IRC | O(各子过程之和) | O(|A|+|𝔇_ρ|) | 失败通道独立可审计 |

**正确性定理（Imitation-Reward Certified Policy Transfer, IRCPT）**
假设第 54 轮 (A22)–(A28) 成立；**(A29)** DAgger 纠偏后信任域内满足（加权）conformal 可交换性，覆盖率 ≥ `1-δ_conf`；**(A30)** `𝓡_D` 以概率 `1-α_R` 覆盖真奖励，`ε_R` 有界；**(A31)** 漂移满足定义 125 递归界，边界 Lipschitz `L` 可估；**(A32)** `E_hack` 在 `|A_grid|` 上精确、对抗采样覆盖 `𝓡_D`。
则
```
P_success ≥ 1 - Σ_d(1-ρ_min(d)) - β_E - P(δ_a>Θ_a)
             - ε_R·H - Δ_IL - P(E_hack>Θ_h) - δ_conf
```
**七通道可审计性**：鲁棒性、环境、动作对齐、奖励歧义、模仿漂移、奖励外溢、信任域外覆盖。每条通道可独立收紧，避免“为压一个项而全局保守”的浪费。

## 6. 本轮最大风险

**一句话**：奖励可辨识集 `𝓡_D` 与信任动作域 `A_trust` 首次让证书能审计“目标对不对”与“技能学得像不像”，但其 soundness **三重依赖 conformal 可交换性在分布漂移下仍成立、奖励集真正覆盖真奖励、外溢探针能捕获未见过的新型 hacking 模式**；一旦部署分布系统性越出示范支撑，`A_trust` 会签发虚假信任、`ε_R` 与 `Δ_IL` 同时低估，组合策略将在“看似有证据、实为外推”的区域自信失效，故必须以 **加权 conformal + 奖励集对抗扩张 + 外溢绊线** 三重护栏，并坚持证据级证书只在信任域内签发。
