# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「真机评测」×「用户体验」）

> 第 54 轮把技能组合推进到动作空间剖面 `α_S`、组合图 `G_S` 与云边联合证书 `J`。本轮引入两个此前被当作"验收阶段"的变量：**真机评测**（证据获取通道）与**用户体验**（主观目标）。核心矛盾：H24：真机评测是稀缺、昂贵、非平稳的测量通道，仿真/云端建立的 `ρ`、`α`、`J` 在真机上会因磨损、环境差异、人体差异产生**证据漂移**——"证书在仿真里成立、在真机上失效"；H25：用户体验是多维、异质、主观的，且常与能力/鲁棒性冲突，把 UX 当成事后评分或被平均成单一标量，会诱发**评测过拟合**与 Goodhart 效应。

## 0. 直觉与动机

**灵感 1（真机评测是预算约束下的实验设计，而非最后一道验收）**
直觉：真机试次是稀缺资源：每次试次有成本 `c`、有磨损、有非平稳漂移。因此不该"训练完再上真机打分"，而应在整个开发闭环里把真机试次当作**可分配的证据预算** `B_real`：在哪些风险区域、哪些用户分群、哪些工况上花掉这一次试次，才能最大化对"能否部署"的信息量。这把评测从 checklist 变成 **active experimentation**。

**灵感 2（仿真到真机的差距是"证书差距"，不是"策略差距"）**
直觉：第 53–54 轮的证书建立在仿真与标称工况上；真机上的偏差不止是策略性能下降，而是被认证的量本身（`ρ`、`α`、`δ_a`、`J`）发生系统性偏移。于是需要一个**证据迁移算子** `T_sim→real`，把仿真风险与真机残差合成一个带统计覆盖保证的现场界。关键不是"仿真准不准"，而是"仿真预测的残差在多大范围内可控"。

**灵感 3（用户体验是可分解、可测信度的剖面，而非一个五星好评）**
直觉：用户体验不是单标量，而是若干可分别测量的维度：响应延迟、运动平滑、意图可读性/可预测性、安全感与信任、认知负荷、失败恢复体验。每个维度都有测量噪声与评分者差异；必须先估计**信度**（重测信度、评分者间一致性），再把低信度维度的结论降权甚至拒绝。否则 UX 就是"用噪声给系统背书"。

**灵感 4（主动体验 elicitation → 用最少的人类交互换取最大偏好信息）**
直觉：用户在真实使用中不愿被频繁打断；每次询问都有"交互税"。因此 UX 也应主动采样：在偏好模型不确定性最大、且对部署决策最关键的对比对上提问，用 Bradley–Terry / 高斯过程偏好模型做后验更新。把"跑真机"与"问用户"统一为两类**证据获取动作**，共享同一预算调度器。

**灵感 5（体验-能力契约 → 冲突显式化而非偷偷折中）**
直觉：更鲁棒/更快的策略可能更"机械"、更不可读；更讨喜的策略可能牺牲成功率。健康做法不是加权求和掩盖冲突，而是定义**体验-能力契约**：用户/场景给出各维最低可接受阈值 `u_min` 与硬约束，系统输出可行域上的 Pareto 前沿并显式披露权衡。不可行时给出"哪一维差多少"的反向解释，而不是给一个虚高总分。

**灵感 6（现场联合证书 → 把证据、能力、体验放进同一种可审计对象）**
直觉：最终部署判据应是**现场联合证书** FJC：它同时携带 (a) 统计意义上的真实风险上界，(b) UX 剖面的信度加权下界，(c) 证据来源与预算消耗，(d) 迁移误差与失效模式。这样"我们跑了几次真机、问了哪些用户、覆盖了什么风险区"都成为证书的一部分，使结论可复现、可反驳、可审计。

## 1. 形式化定义（增量：定义 121–127）

**定义 121（评测预算与真机试次）**
真机评测预算 `B_real = (n_max, c_budget, t_cal)`。一次真机试次 `e = (s, ω, ξ, y)`：风险分层 `s`、用户分群 `ω`、工况 `ξ`、观测 `y`（成功、鲁棒性指标、UX 维度、失效模式）。评测策略 `π_eval` 在预算内选择试次序列；其成本 `cost(e) = c_sim·1[sim] + c_real·1[real] + c_human·1[human]`。

**定义 122（主动评测信息增益）**
给定证据历史 `H`，下一次评测动作 `a` 的信息增益 `IG(a|H) = I(θ; Y_a | H)`，`θ` 为待判定的部署参数（风险、UX 可接受性等）。主动评测策略：
```
a* = argmax_a IG(a|H) / cost(a),   s.t. Σ_{a∈π_eval} cost(a) ≤ B_real
```

**定义 123（证据迁移算子与证书差距）**
证据迁移算子 `T_sim→real : (R̂_sim, D_sim) → (R̂_real, Δ, q_{1-α})`。证书差距
```
Δ = sup_{x∈supp(D_real)} |ℓ_real(π,x) - ℓ_sim(π,x)|
```
其校准残差用非一致性分数 `r = ℓ_real - ℓ_sim` 的经验分位数给出。若真机与仿真分布加权比有界 `w(x) = dD_real/dD_sim ≤ W_max`，则用加权 conformal 校正，否则迁移声明不成立。

**定义 124（现场证书）**
现场证书 `F = (R̂_real, R_upper, α, n_real, Δ, β_evid)`，满足覆盖声明
```
P(R_real(π) ≤ R_upper) ≥ 1 - α - β_evid
```
其中 `R_upper` 由仿真风险 + 迁移残差分位数合成，`β_evid` 为迁移假设（交换性/加权有界）失败概率。`F` 可部署当且仅当 `R_upper ≤ R_budget`。

**定义 125（用户体验剖面与信度）**
用户体验剖面 `u = (u_lat, u_smooth, u_leg, u_trust, u_load, u_rec) ∈ [0,1]^6`：延迟、平滑、可读、信任、认知负荷、恢复。信度 `κ = (ICC_test-retest, Krippendorff_α, n_users)`。聚合只允许在信度合格时进行：若 `ICC < κ0` 则该维度标记 `unreliable`，不得进入部署结论。用户加权体验 `U(u; w_ω) = Σ_k w_{ω,k}·u_k`，`w_ω` 来自用户分群 `ω` 的偏好分布。

**定义 126（用户偏好模型与体验契约）**
用户偏好模型 `P(y | q, ω)`（`q` 为对比对）用 Bradley–Terry / 高斯过程学习。体验契约 `C_ux = (u_min, w_ω, κ0, τ_ux)`：要求
```
P(U(u;w_ω) ≥ u_min(ω)) ≥ 1 - β_u  ∧  ∀ 关键维度 κ ≥ κ0
```
体验-能力可行域 `Adm = {π | F(π) 可部署 ∧ C_ux(π) 满足}`。若 `Adm = ∅`，返回各维违约量 `d_k = max(0, u_min,k - u_k)` 作为反向解释。

**定义 127（现场联合证书 FJC）**
`FJC = (F, u, κ, ω, tradeoff, evidence_log)`：
- `F` 为现场证书（定义 124）；
- `u, κ` 为信度加权的 UX 剖面；
- `ω` 为用户分群与偏好模型版本；
- `tradeoff` 为能力-体验 Pareto 坐标；
- `evidence_log` 为真机/人类试次账本（可复现）。

若 `F 可部署 ∧ C_ux 满足 ∧ κ ≥ κ0`，则 `dom_FJC = in`；否则返回根因（风险超界 / 体验违约 / 信度不足 / 数据不足）。联合判据的意义是：**任何一维都不能被其它维的高分"补偿"通过**。

## 2. 关键算法 伪代码

### IP-121 RME（预算化分层真机评测）

```python
def real_machine_evaluate(policy, B_real, strata, risk_surrogate):
    log, spent = [], 0.0
    while spent < B_real:
        s = argmax_stratum(strata, risk_surrogate, log)   # 风险 × 不确定性
        e = run_trial(policy, sample(s))
        log.append(e); spent += e.cost
        risk_surrogate.update(e)
    return EvidenceLog(log, spent)
```

### IP-122 AET（主动评测调度）

```python
def active_schedule(theta_post, actions, B_real):
    plan, spent = [], 0.0
    while spent < B_real:
        a = max(actions, key=lambda a: expected_info_gain(theta_post, a) / a.cost)
        plan.append(a); spent += a.cost
        theta_post = posterior_update(theta_post, a)   # 代理模型期望更新
    return plan
```

### IP-123 ETS（Sim→Real 证据迁移校准）

```python
def calibrate_transfer(real_pairs, alpha, W_max=1.0):
    # real_pairs: (sim_loss, real_loss, weight)
    scores = [w * (lr - ls) for ls, lr, w in real_pairs]
    q = weighted_quantile(scores, 1 - alpha, weights=[w for *_, w in real_pairs])
    return TransferModel(delta=max(0.0, q), n=len(real_pairs), W_max=W_max)
```

### IP-124 FCR（现场证书）

```python
def field_certificate(r_hat_sim, transfer, r_budget, alpha):
    r_upper = r_hat_sim + transfer.delta
    return FieldCert(r_hat_sim, r_upper, alpha=alpha, n_real=transfer.n,
                     delta=transfer.delta, ok=(r_upper <= r_budget))
```

### IP-125 UXP（体验剖面与信度）

```python
def ux_profile(trials, users, dims=('lat','smooth','leg','trust','load','rec')):
    u = {d: robust_mean([t.ux[d] for t in trials]) for d in dims}
    icc = intraclass_corr(trials, users)
    kri = krippendorff_alpha(trials)
    return UXProfile(u, kappa=(icc, kri, len(users)),
                     reliable=[d for d in dims if icc[d] >= K0])
```

### IP-126 HIL（主动偏好 elicitation + 体验契约）

```python
def ux_contract(pref_model, user_cluster, u_min, beta_u, budget):
    while budget > 0:
        q = argmax_pair(pref_model, acquisition='info_gain')
        y = ask_user(q, user_cluster)
        pref_model.update(q, y); budget -= 1
    w = pref_model.weights(user_cluster)
    p_ok = mean([U(sample_u, w) >= u_min
                 for sample_u in pref_model.posterior_samples(2000)])
    if p_ok < 1 - beta_u:
        return ('reject', per_dim_deficit(pref_model, u_min))
    return ('ok', w, p_ok)
```

### IP-127 FJC（现场联合证书）

```python
def field_joint_certificate(policy, B_real, contract, alpha):
    log = real_machine_evaluate(policy, B_real, contract.strata, RiskSurrogate())
    T   = calibrate_transfer(log.real_pairs, alpha)
    F   = field_certificate(log.sim_risk(policy), T, contract.r_budget, alpha)
    UX  = ux_profile(log.trials, log.users)
    if not UX.all_reliable(contract.kappa0):
        return ('reject', 'low_ux_reliability', UX.kappa)
    status, w, p_ok = ux_contract(contract.pref_model, contract.user_cluster,
                                  contract.u_min, contract.beta_u, contract.hil_budget)
    if not F.ok:
        return ('reject', 'risk_exceeds', F)
    if status != 'ok':
        return ('reject', 'ux_violation', w)
    return ('ok', FJC(F, UX.u, UX.kappa, w, pareto_point(F, UX), log))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| RME | O(n_max·(|S|+|Ω|)) | O(n_max) | 分层覆盖、预算闭合 |
| AET | O(B·|A|·T_post) | O(|A|·T_post) | 信息增益单调、代理校准 |
| ETS | O(n_real log n_real) | O(n_real) | 加权 conformal 覆盖 |
| FCR | O(1) 合成 | O(n_real) | 上界 sound、交换性/加权有界 |
| UXP | O(n_trials·d + n_users²) | O(n_trials·d) | 信度先于聚合 |
| HIL | O(budget·|Q|·T_pref) | O(|Q|) | 后验校准、elicitation 无偏 |
| FJC | O(RME + ETS + UXP) | 同左 | 联合判据不被单点侥幸通过 |

**正确性定理（Field-Evidence Composition Soundness, FECS）**
假设：(A29) 各风险分层内真机损失对给定策略条件交换，或加权比 `≤ W_max`（允许加权 conformal）；(A30) 迁移算子残差上确界偏差 `≤ Δ`，迁移假设失败概率 `≤ β_evid`；(A31) UX 关键维度信度 `κ ≥ κ0`，且偏好模型后验校准（PIT 均匀）。则现场联合证书满足
```
P( R_real ≤ R_upper ∧ U(u;w_ω) ≥ u_min ) ≥ 1 - α - β_evid - β_u - P(κ < κ0)
```
即 FJC 判 `in` 的假阳性率被上述并界控制；判 `out` 时必须能定位到风险/体验/信度/数据四类根因之一。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 真机非平稳/磨损导致证书漂移 | 高 | 分层 + 漂移检测 + 滑动窗口重校准 |
| 小样本 conformal 失效 | 高 | 加权 conformal + e-process + 保守先验 |
| UX 低信度维度污染结论 | 高 | 信度门槛 + 剔除/降权 + 多评分者 |
| Goodhart：优化指标≠真实体验 | 高 | 预注册指标 + 留出评测集 + 优化/汇报分离 |
| 人类交互税造成样本偏置 | 中 | 主动 elicitation + 分群平衡 + 交互成本建模 |
| 评测预算分配次优 | 中 | 贝叶斯实验设计 + 代理模型在线校准 |

## 6. 本轮最大风险

**一句话**：真机评测与用户体验把证书从"仿真成立"推进到"现场可审计"，但其 soundness 同时依赖**真机损失的（加权）可交换性、迁移残差上界的可校准性、以及 UX 信度门槛的被满足**；一旦真机分布非平稳漂移、或小样本 conformal 在分布外失效、或优化指标与真实体验脱钩（Goodhart），现场证书会给出统计上"合法"、体验上"灾难"的部署许可，故必须以**预注册留出评测 + 分层加权 conformal + 信度门槛与优化/汇报分离**三重护栏，宁可判"数据不足"，绝不把一次漂亮的真机演示当成部署证据。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-FieldUX（RME×AET×ETS×FCR×UXP×HIL×FJC）

> 承接第 54 轮产物 v31。本轮在动作-鲁棒性联合证书 `J` 之上，增加**真机证据**与**用户体验**两个一等公民：
> - **RME（Real-Machine Evaluation）**：预算化、分层化的真机评测与证据账本；
> - **AET（Active Evaluation Scheduler）**：以信息增益/成本调度真机试次与人类交互；
> - **ETS（Evidence Transfer Sim→Real）**：加权 conformal 迁移校准，显式度量证书差距 `Δ`；
> - **FCR（Field Certificate）**：带覆盖声明的现场风险上界 `R_upper`；
> - **UXP（User Experience Profile）**：六维体验剖面与信度 `κ`；
> - **HIL（Human-in-the-Loop Contract）**：主动偏好 elicitation + 体验-能力契约；
> - **FJC（Field Joint Certificate）**：风险 + UX + 证据账本的联合部署判据。
>
> IP 编号：IP-121~IP-127（共 7 个新增），升级 IP-118/120 以纳入现场证据与体验维度。

```python
    # real_pairs: (sim_loss, real_loss, weight)
    scores = [w * (lr - ls) for ls, lr, w in real_pairs]
    q = weighted_quantile(scores, 1 - alpha, weights=[w for *_, w in real_pairs])
    return TransferModel(delta=max(0.0, q), n=len(real_pairs), W_max=W_max)
```

### IP-126 HIL（主动偏好 + 体验契约）

```python
def ux_contract(pref_model, user_cluster, u_min, beta_u, budget):
    while budget > 0:
        q = argmax_pair(pref_model, acquisition='info_gain')
        y = ask_user(q, user_cluster)
        pref_model.update(q, y); budget -= 1
    w = pref_model.weights(user_cluster)
    p_ok = mean([U(sample_u, w) >= u_min
                 for sample_u in pref_model.posterior_samples(2000)])
    if p_ok < 1 - beta_u:
        return ('reject', per_dim_deficit(pref_model, u_min))
    return ('ok', w, p_ok)
```

```python
def field_joint_certificate(policy, B_real, contract, alpha):
    log = real_machine_evaluate(policy, B_real, contract.strata, RiskSurrogate())
    T   = calibrate_transfer(log.real_pairs, alpha)
    F   = field_certificate(log.sim_risk(policy), T, contract.r_budget, alpha)
    UX  = ux_profile(log.trials, log.users)
    if not UX.all_reliable(contract.kappa0):
        return ('reject', 'low_ux_reliability', UX.kappa)
    status, w, p_ok = ux_contract(contract.pref_model, contract.user_cluster,
                                  contract.u_min, contract.beta_u, contract.hil_budget)
    if not F.ok:
        return ('reject', 'risk_exceeds', F)
    if status != 'ok':

    return ('ok', FJC(F, UX.u, UX.kappa, w, pareto_point(F, UX), log))
```

## 3. 复杂度与推导

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| RME | O(n_max·(|S|+|Ω|)) | O(n_max) | 分层覆盖、预算闭合 |
| AET | O(B·|A|·T_post) | O(|A|·T_post) | 信息增益单调、代理校准 |
| ETS | O(n_real log n_real) | O(n_real) | 加权 conformal 覆盖 |
| FCR | O(1) 合成 | O(n_real) | 上界 sound、交换性/加权有界 |
| UXP | O(n_trials·d + n_users²) | O(n_trials·d) | 信度先于聚合 |
| HIL | O(budget·|Q|·T_pref) | O(|Q|) | 后验校准、elicitation 无偏 |
| FJC | O(RME + ETS + UXP) | 同左 | 联合判据不可补偿 |

**覆盖推导（Split/Weighted Conformal）**
设校准分数 `r_i = ℓ_real,i - ℓ_sim,i` 在分层内可交换，取经验分位数
```
q̂ = Quantile( {r_i}_{i=1..n}, (1-α)(1+1/n) )
```
则对新的真机样本有 `P(r_new ≤ q̂) ≥ 1-α`，从而 `R_real ≤ R̂_sim + q̂` 以 `1-α` 成立。若分布漂移使 `w(x)=dD_real/dD_sim ≤ W_max`，改用加权分位数并付出 `TV(D_real,D_sim)` 的覆盖折损，故 `F` 的覆盖声明扣除 `β_evid`。**这条推导把"真机演示看起来不错"替换成"在声明的分布假设下，风险以给定概率有界"。**

**Goodhart 防线**
优化阶段可最小化 `U`，但部署判据必须在**预注册的留出真机集与留出用户群**上重算 `FJC`；优化指标与汇报指标分离，否则 `U` 会被策略过拟合，`κ` 也会因选择性采样虚高。

**正确性定理（Field-Evidence Composition Soundness, FECS）**
假设第 54 轮 (A26)-(A28) 成立；本轮补充 **(A29)** 分层内真机损失条件可交换或加权比 `≤ W_max`；**(A30)** 迁移残差上确界 `≤ Δ`，迁移假设失败概率 `≤ β_evid`；**(A31)** UX 关键维度 `κ ≥ κ0` 且偏好模型后验校准。则
```
P( R_real ≤ R_upper ∧ U(u;w_ω) ≥ u_min ) ≥ 1 - α - β_evid - β_u - P(κ < κ0)
```
FJC 判 `in` 的假阳性被并界控制；判 `out` 必须定位到风险超界 / 体验违约 / 信度不足 / 数据不足之一。

## 6. 本轮最大风险

**一句话**：真机评测与用户体验把证书从"仿真成立"推进到"现场可审计"，但其 soundness 同时依赖**真机损失的（加权）可交换性、迁移残差上界的可校准性、以及 UX 信度门槛的被满足**；一旦真机分布非平稳漂移、或小样本 conformal 在分布外失效、或优化指标与真实体验脱钩（Goodhart），现场证书会给出统计上"合法"、体验上"灾难"的部署许可，故必须以**预注册留出评测 + 分层加权 conformal + 信度门槛与优化/汇报分离**三重护栏，宁可判"数据不足"，绝不把一次漂亮的真机演示当成部署证据。
