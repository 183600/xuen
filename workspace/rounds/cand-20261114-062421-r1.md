# 第 70 轮（承接第 69 轮「FLUID-RAS」IP-253~263；灵感循环第 3 轮；本轮灵感：「多语言支持」×「工具调用」）

> R69 打通了「问」这条通道：把不确定性拆成 aleatoric / epistemic，用流匹配多模态策略给出有形状的歧义，再用注视、探针、问句等**信息动作**按 VoI 去消解。但它把「收敛后验」的宝押在一句**自然语言回答**上——这句话由冻结 LLM 从 `g_ask` 解码，单语言、无类型、不可独立复核。R69 自己也承认，`g_ask` 的 `k 个正交证据源` 更像一句口号：那些"源"大多还是**同一个 LLM 的不同说法**，而它的最大风险恰恰是「模态后验不可信 → 追问幻影 / 给投毒回答盖已验证的章」。
>
> 本轮两个灵感正好补上两块：
> - **多语言支持**让"同一问题"以 m 种语言被重新表述——语言由此从**输出装饰**升级为**m 个部分独立的证据视图**；跨语言语义不变性成为幻影模态的天然筛子，逐语言校准则暴露"哪种语言的回答可以定案"。
> - **工具调用**把"问一个人"升级为"调一个**有类型契约、可证伪、可重放**的外部测量"——工具结果不是一段可信文本，而是一个必须过 schema / 前置 / 后置 / 语义校验的可采纳比特。
>
> 核心命题：**epistemic 不确定性的消解，不是"问一句更聪明的话"，而是"取得一个能被独立复核的测量"。** 每条用于坍缩模态的证据必须满足三件事：**类型化**（有可验证契约）、**跨视图一致**（语言无关身份 + 非语言源佐证）、**可溯源重放**（谁给的、能否复算）。无法被任何外部证据证伪/证实的模态，一律作为**幻影隔离**，退回 R69/R68 保守。命名 **HERMES-RAS**（Heterogeneous Evidence through Redundant Multilingual Elicitation and Sandboxed tools）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么相信这个回答，又是谁在检查检查者**」——验证优先，而非提问优先。

## 0. 直觉与动机

**灵感 1（多语言支持 → 语言是证据视图，不是输出装饰）**
直觉：如果系统只会用中文问，那么它得到的回答既是"内容"也是"这一个人的一次性说法"，无法区分"概念本身"与"中文这种说法"。换成多语言后，一个**真实、接地的概念**在不同语言里应保持稳定的语义身份（可回译到公共轴）；而一个**幻影模态**（流模型在有限数据上幻觉出来的伪动作）往往只在某种语言/某种表述里"讲得通"，一换语言就散架。于是"跨语言一致性"变成幻影模态的免费筛子——不需要额外标注，只需要把同一问题多问几种语言。进一步，语言之间还存在**翻译不对称**：一个撒谎的人很难在 m 种语言里维持同一个谎言而不露馅，这给了投毒一个语言学不变量。

**灵感 2（工具调用 → 工具是可证伪的测量）**
直觉：R69 的"问"只是让对方**再描述一次**；而工具调用是让对方（或环境）**报一个可核对的数**。一个模态若要被采纳，就应能预测某个工具的输出；预测不中即被**证伪**。这比"对方说 A 我更信一点"强得多：语言给的是似然，工具给的是判决。工具的代价是延迟、成本、副作用与新的攻击面（假工具、过期结果、共谋），所以它必须被类型契约和沙箱约束，且**单次工具结果永不单独定案**。

**灵感 3（"k 个正交源"是口号 → 用 k_eff 把正交性变成可估计量）**
直觉：R69 的证据纪律假设"k 个正交证据源"，可 `q_中文、q_英文、q_日文` 若都由**同一个冻结 LLM** 生成，它们只是**一个源穿了 k 件外套**；一族的工具若共享同一后端模型/数据，同理。真正的独立不是结构声明，而是**历史共错率**：两个源多久一起错一次。于是定义**有效独立源数 k_eff**，并用它替代名义 k 进入证据纪律——k_eff < 2 时，再多"一致"也不准定案。这是本轮最关键的方法论修正：**收益来自异构，不来自数量。**

**灵感 4（闭源工具幻觉 = 幻影模态的工具版）**
直觉：R69 担心流模型幻觉出不存在的动作模态；工具世界有完全同构的病：模型会"调用一个不存在的工具"、编造一个看似合理的 schema、或把参数塞进错误的槽。若允许"试一下"，系统就会用一个幻影工具去验证一个幻影模态，双重幻觉自洽。正确做法是**封闭注册表 + 签名 schema + 硬拒绝**：区分"工具不存在"（不可调用）与"工具存在但失败"（可降级），前者永不进入证据账本。

**灵感 5（验证优先是异步的，安全必须单调）**
直觉：调工具要几十到几百毫秒，机器人不能站着等。因此验证必须**异步**：在结果回来之前，按 R69/R68 的保守路径执行；验证结果只在**下一次 replan** 生效并发放 resolution bonus；一旦超时/不可采纳/被投毒/被隔离，模态集合**单调收缩**回保守路径，λ 单调不降。这样"会查证"不会以牺牲实时性和安全性为代价——它只购买"更敢执行"的资格，且这笔资格可以随时被撤回。

**对 R69 两个致命问题的正面回应**
- 幻影模态 → CLIC（跨语言身份一致性）+ 工具证伪 + 幻影隔离；
- 投毒回答被盖章 → 类型化可采纳性 + 非语言源强制 + k_eff 证据纪律。
- 但本轮也引入了**新的、更隐蔽的**风险：**伪正交**——见第 6 节。

## 1. 形式化定义（增量：定义 310–323）

**定义 310（HERMES-RAS 总览）** HERMES-RAS = (FMP, AUD, MINT†, EIL, LCG, CLIC, TVL, TRT, TSB, VMC, FMA, RAS-WM‡)。四条不变式：
(i) **实时流零学习写操作**（继承定义 276-i）；
(ii) **交互与工具预算硬约束**：单位时间信息动作 ≤ 1、工具调用 ≤ n_tool、总延迟/成本 ≤ c_max、所有工具动作过 C-RAS-WM 前缀认证并受沙箱能力限制（定义 323）；
(iii) **验证优先证据纪律**：单源（含单语言、单工具）不得定案；定案需 **k_eff ≥ 2** 个相互一致的可采纳证据，且至少一个为**非语言**源（物理探针 / 工具测量），或跨语言一致性 κ ≥ τ_κ 且 LCG 通过（定义 313–319）；
(iv) **幻影隔离**：预算内无法被任何外部证据证实或证伪的模态进入 Quarantined，按未消解 U_epi 走 R69/R68 保守（定义 318）。

**定义 311（增广动作空间与工具动作）** 信息动作 g = (g_sense, g_ask^L, g_tool)；g_sense ∈ 𝒜_sense（注视/探针/等待，继承定义 294）；g_ask^L 为语言集 L 上的多语言询问；g_tool = (tool_id, args) ∈ 𝒯_registry，携带输入/输出类型。增广动作 ξ = (a, g) ∈ 𝒜_+。工具动作本身有前置条件 P_t、后置条件 Q_t、超时与副作用上界。

**定义 312（多语言启发性询问 EIL）** 语言集 L = {ℓ_1, …, ℓ_m}；问句 q_ℓ = Decode_LLM(g_ask, ℓ)，应答分布 p_ℓ(y | g_ask, o)。语言不是输出装饰，而是 m 个（仅**部分**独立的）证据视图；m 与语言选择本身受预算约束。

**定义 313（跨语言身份一致性 CLIC）** 取公共枢轴语言 π。把模态 m 在各语言下的描述 c_ℓ(m) 经回译映射到枢轴表示 φ(c_ℓ(m))，定义 κ(m) = 1 − mean_{i<j} d(φ(c_i(m)), φ(c_j(m)))，d 为归一化语义散度。接地模态 κ 高、幻影模态 κ 低。**注意**：κ 度量的是语义不变性，不是源独立性；同一 LLM 的 m 语言版本仍可能共错（定义 319）。

**定义 314（语言条件校准门 LCG）** 每种语言维护 ECE_ℓ。信任权重 τ_ℓ = σ(a − b·ECE_ℓ − c·lowres_ℓ)。ECE_ℓ > τ_ece ⇒ 该语言**只作旁证、不作定案源**；且以 ℓ 计算的 VoI 相对真值的偏差 ≤ L_V·ECE_ℓ（引理 22）。

**定义 315（工具契约与可采纳性 TVL）** 工具 t = (schema, P_t, Q_t, V_t, freshness, provenance)。结果 y_t **可采纳** ⇔ schema 合法 ∧ 前/后条件满足 ∧ 语义校验 V_t 通过 ∧ 未过期 ∧ 来源签名可信。不可采纳 ⇒ 本次证据无效，**不改变后验**，但计入审计。

**定义 316（工具注册表与幻觉防护 TRT）** 只允许调用已签名注册表 𝒯_registry 中的工具；未注册/伪造/参数类型不符 → **硬拒绝**（不是"试一下"），不进入证据账本。严格区分"工具不存在"（TRT 拒绝）与"工具存在但失败"（可降级）。

**定义 317（工具信息增益 TVoI）** VoI(t) = H(M|o) − E_{y~p(·|t,o)}[H(M|o, y) · 1_{y admissible}]。净收益 = VoI(t) − c_lat(t) − c_money(t) − c_risk(t) − c_verify(t)。选择 (g*, t*) = argmax 净收益，s.t. 安全与预算；若最优净收益 ≤ 0 或无任何可采纳验证器 → 退化为 R69（只问不查）。

**定义 318（验证优先模态闭合 VMC）** 给定证据集 ℰ 后，模态三分：
- **Verified**：被 k_eff ≥ 2 个一致的可采纳源确认，且含至少一个非语言源（或 κ 与工具双重一致）；
- **Quarantined**：被某源声称但无法独立确认，或跨语言不一致，或实验证器证伪失败；
- **Unresolved**：证据不足，维持 R69 未消解态。
只有 Verified 可获 resolution bonus（λ = λ_floor(U_ale)）；Quarantined 与 Unresolved 一律 λ = λ_floor(U_ale + U_epi)。执行只能在 Verified 中选，否则回到 R69/R68 保守模态。

**定义 319（证据正交性的操作定义与"验证剧场"告警）** 源 i、j 的正交度 ρ_ij 由**历史共错率**估计（同批次一起判错的频率），而非结构声明。有效独立源数 k_eff = 1 + Σ_{i>1}(1 − ρ_{1i})（或共错矩阵的谱有效秩）。若 m 种语言由同一冻结 LLM 生成、或工具族共享后端模型/数据，则 ρ 高、k_eff ≈ 1。**证据纪律一律使用 k_eff 而非名义 k**；k_eff < 2 时不得定案、不得发放 resolution bonus。

**定义 320（工具投毒、共谋与语言侧干扰 ℰ_HERMES）** ℰ_HERMES = ℰ_FLUID × ℰ_tool × ℰ_lang。ℰ_tool：恶意但"看起来合理"的结果、过期缓存、schema 合法但语义错、同后端多工具共谋、工具返回分布漂移；ℰ_lang：翻译不对称、低资源语言语义漂移、同一 LLM 多语言同错。

**定义 321（证据账本与可重放 ELR）** 每条证据记录 (source, provenance, hash, timestamp, contract_version, admissible, k_eff 贡献)；工具调用支持**确定性重放**（固定输入/版本/随机种子），供 VQAuditor-T 与事后审计。

**定义 322（证书 J_HERMES）** J_HERMES = (J_FLUID, ECE_vec, κ_min, tool_admissible_rate, provenance_hashes, k_eff_min, verified_ratio, quarantine_count, hermes_ver)。Valid ⇔ Valid(J_FLUID) ∧ LCG 通过 ∧ 定案证据 k_eff ≥ 2 ∧ 工具全部可采纳且可重放 ∧ 预算未越界。

**定义 323（工具沙箱与安全 TSB）** 工具在沙箱内执行，能力受限（网络/文件/执行/机械接口白名单）；任何工具的物理副作用 ≤ ε_int 并过 C-RAS-WM；超时或异常不产生部分副作用；不可信工具不得直接驱动执行器。工具安全继承 R68 的提交/换装不变式。

```python
# IP-276 HERMES 主闭环：FLUID 层 + 多语言证据视图 + 工具验证闭合
class HERMES_RAS:
    def round(self, obs):
        # --- R69 FLUID 层（原样保留，作为退化边界）---
        z, o = self.mtm.forward(obs)
        K = 1 if self.fmp.mode_head(z) < TAU_MODE else 4
        modes = self.aud.decompose(self.fmp.sample(o, K))
        if not worth_resolving(modes):                 # VoI<=成本 → 逐指令同 R69
            return self.fluid_fallback(modes)

        # --- 1) 多语言证据视图（并行、可异步）+ CLIC 幻影筛 ---
        asks = {l: self.eil.ask(o, modes, l)           # q_l = LLM(g_ask, l)
                for l in self.L if self.lcg.decisive(l)} # 低校准语言只作旁证
        kappa = self.clic.consistency(modes, asks)     # 跨语言身份一致性
        modes.quarantine(kappa < TAU_KAPPA)            # 幻影 → Quarantined

        # --- 2) 工具验证：类型化、闭注册表、沙箱、按 TVoI 选择 ---
        while self.budget.tool_left():
            t = self.tvoi.argmax(modes, o)             # 含验证成本
            if t is None or t.net_gain <= 0: break
            if not self.registry.contains(t.id):       # IP-267 幻觉防护：硬拒绝
                self.vqa_t.reject(t); continue
            if not self.tsb.certify(t, o):             # IP-270 沙箱 + C-RAS-WM
                continue
            y = self.tsb.execute(t)                    # 可重放、能力受限
            if not self.tvl.admissible(t, y):          # schema/P_t/Q_t/V_t/fresh
                self.ledger.log(t, y, admissible=False); continue
            self.ledger.log(t, y)
            modes.update(y)                            # 仅可采纳结果入后验

        # --- 3) 验证优先闭合：只有 Verified 才有 resolution bonus ---
        verified, quarantined, unresolved = self.vmc.close(modes, self.ledger)
        if self.ledger.k_eff() < 2 or not verified:    # 伪正交 / 无独立复核
            return self.fluid_fallback(modes)          # 严格退回 R69/R68

        # --- 4) 保守执行：λ 只对 aleatoric+未消解 epistemic 收紧 ---
        mode = self.select_verified(verified, modes)
        U_floor = modes.U_ale                          # Verified 才有 bonus
        lam = max(self.efs.risk_scale(...), lam_floor(U_floor))
        A = self.ach.propose(x_prime, H=self.vista.H)
        k = self.c_ras_wm.certified_prefix(A, ..., wm_preds)
        tau = self.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
        self.vqa_t.submit_async(asks, self.ledger, kappa, quarantined)
        return k, lam, mode, (modes.U_ale, modes.U_epi)
```

```python
# IP-268 TRT：闭注册表幻觉防护（工具版「幻影隔离」）
def guarded_call(registry, tool_id, args, tsb, tvl):
    if not registry.contains(tool_id):          # 不存在 → 硬拒绝，不重试
        return REJECT_NOT_REGISTERED
    t = registry.get(tool_id)                   # 签名 schema
    if not schema_typecheck(t.schema, args):    # 参数类型/槽位校验
        return REJECT_BAD_ARGS
    if not tsb.certify(t, args):                # 能力/副作用/超时
        return REJECT_UNSAFE
    y = tsb.execute(t, args)                     # 沙箱内，可重放
    return ACCEPT if tvl.admissible(t, y) else REJECT_INADMISSIBLE

# IP-269 TVoI：把「查什么」当成带验证成本的 VoI 决策
def choose_tool(modes, o, registry, budget):
    best = None
    for t in registry.candidates(modes):         # 仅注册表内
        if not budget.allow(t): continue
        voi = entropy(modes.w) - expected_post_entropy(modes, t, o)
        gain = voi - (t.latency + t.money + t.risk + t.verify)
        if best is None or gain > best.gain: best = ToolChoice(t, gain)
    return best if best and best.gain > 0 else None   # 无利可图 → 退 R69

# IP-272 k_eff：用历史共错率估有效独立源，而非数「源」的个数
def effective_sources(ledger, window=512):
    R = co_failure_matrix(ledger, window)        # rho[i,j] = P(both wrong)
    return 1.0 + sum(1.0 - R[0, i] for i in range(1, len(R)))
```

## 3. 推导

**引理 19（跨语言幻影分离）** 设接地模态的跨语言语义方差上界 σ_g²，幻影模态（由单一语言 artifact 诱发）的跨语言方差下界 σ_p² > σ_g²；取阈值 τ_κ 介于两者之间，用 m 个近似独立的语言视图，则幻影被误判为接地（κ ≥ τ_κ）的概率 ≤ exp(−m·(τ_κ − σ_g²)²/(8σ_p²))，接地被误隔离 ≤ exp(−m·(σ_p² − τ_κ)²/(8σ_p²))。系：语言越多，幻影过滤越强——**但前提是这 m 个视图近似独立；若同一 LLM 生成，共享方差使有效 m 下降（定义 319），这是本轮风险的伏笔。**

**引理 20（工具可采纳性的判别增益）** 设工具 t 在模态间所测量的统计量分离为 Δ_t、噪声 σ_t，则一次**可采纳**调用使后验熵期望下降 ≥ ½·log(1 + Δ_t²/(4σ_t²))（高斯情形），正确识别概率 ≥ 1 − exp(−Δ_t²/(8σ_t²))。系：工具排序应按 Fisher 判别率 Δ_t/σ_t，这与 TVoI 的排序同序；"看起来相关"不等于"能判决"。

**引理 21（投毒上界与有效正交性）** 沿用 R69 引理 18：名义 k 源、单源欺骗率 δ、共错相关 ρ 时，错误定案率 ≤ δ·ρ^{k−1} + ε_σ；但把 k 换成 k_eff = 1 + Σ_{i>1}(1 − ρ_{1i})。由于**非语言工具源与语言源的共错相关** ρ_tool,lang 通常严格小于**同 LLM 多语言之间的共错** ρ_lang,lang，加入一个可采纳工具源**严格降低**上界。系：多语言与工具调用的真正收益来自**异构**，不是**数量**；十个同源"一致"不如一个异构"对得上"。

**引理 22（语言条件 VoI 偏差）** 若在语言 ℓ 上估计的模态后验满足 ECE_ℓ = ε，则其 VoI 与真实 VoI 之差 ≤ L_V·ε（L_V 为熵的 Lipschitz 常数）。低资源语言 ε 大，VoI 可能被系统性高估（导致无谓追问）或低估（导致漏问）。系：LCG 把 ECE_ℓ 直接变成 VoI 的**可信半径**；越界语言只能旁证。

**定理 18（HERMES 严格包含 FLUID-RAS 与 R68）** 当工具注册表为空、|L| = 1、验证关闭时，HERMES 与 FLUID-RAS **逐指令相同**；一般情形下，因任何证据仅在"可采纳 ∧ k_eff ≥ 2 ∧ 无矛盾"时才改变决策，HERMES 的期望风险 ≤ FLUID-RAS ≤ R68，安全侧（λ 下界、认证、预算）不做任何让步。故得到严格包含链 **R68 ⊂ FLUID-RAS ⊂ HERMES-RAS**。

**定理 19（验证优先的交互安全与无突变）** 工具调用在沙箱内且过 C-RAS-WM（定义 323）；证据获取不改变安全包络；当工具不可采纳/超时/被投毒/幻影被隔离时，模态集合单调收缩回 R69/R68 路径，λ 单调不降；提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

**命题 1（验证剧场的必要性条件）** 若全部证据由同一生成器 g 产生（同 LLM 多语言、同后端工具族），则其共错矩阵秩为 1、k_eff = 1；此时任何"多源一致"带来的置信增益恒为 0。故 HERMES 的 resolution bonus **必须**以 k_eff ≥ 2 的证书为前提，否则不予发放——这是把 R69 的空洞"正交"假设变成可执行条件。

## 6. 本轮最大风险

**一句话**：HERMES-RAS 的全部收益押在「证据源是异构的」这一前提上——**但 m 种语言可能只是同一个冻结 LLM 的 m 件外套，一族工具可能只是同一个后端模型的 m 个接口；若它们的共错相关 ρ 被低估，k_eff 就被高估，系统会把"一个源说了 k 遍"当成"k 个源相互印证"，于是用验证剧场给一个错误模态盖上 Verified 的章——这比 R68 的"诚实的不知道"更危险，因为它把不确定变成了自信的错误。**

**次级风险与缓解**：
1. **伪正交 / 共错相关被低估** → k_eff 用在线共错估计而非结构声明（定义 319）+ 非语言源强制 + 命题 1 的发放前提；
2. **工具幻觉（调用不存在的工具）** → 闭注册表 + 签名 schema + 硬拒绝（定义 316，工具版幻影隔离）；
3. **工具投毒/过期/共谋** → TVL 可采纳性 + 引理 21 上界 + ℰ_tool 对抗训练；
4. **低资源语言校准崩塌** → LCG 逐语言 ECE 门控，越界只作旁证（引理 22）；
5. **工具延迟击穿实时性 / 沙箱越权** → 验证全异步、结果下一 replan 生效 + TSB 能力白名单 + 定理 19 无突变。

```python
# IP-276 HERMES 主闭环：FLUID 层 + 多语言证据视图 + 工具验证闭合
class HERMES_RAS:
    def round(self, obs):
        z, o = self.mtm.forward(obs)
        K = 1 if self.fmp.mode_head(z) < TAU_MODE else 4
        modes = self.aud.decompose(self.fmp.sample(o, K))
        if not worth_resolving(modes):                 # VoI<=成本 → 逐指令同 R69
            return self.fluid_fallback(modes)

        # 1) 多语言证据视图 + CLIC 幻影筛
        asks = {l: self.eil.ask(o, modes, l)
                for l in self.L if self.lcg.decisive(l)}   # 低校准语言仅旁证
        kappa = self.clic.consistency(modes, asks)
        modes.quarantine(kappa < TAU_KAPPA)                # 幻影 → Quarantined

        # 2) 工具验证：闭注册表 / 沙箱 / 可采纳性 / TVoI
        while self.budget.tool_left():
            t = self.tvoi.argmax(modes, o)                 # 含验证成本
            if t is None or t.net_gain <= 0: break
            if not self.registry.contains(t.id):           # IP-268 硬拒绝
                self.vqa_t.reject(t); continue
            if not self.tsb.certify(t, o): continue        # IP-270
            y = self.tsb.execute(t)                        # 可重放
            ok = self.tvl.admissible(t, y)                 # IP-267
            self.ledger.log(t, y, admissible=ok)
            if ok: modes.update(y)                         # 仅可采纳入后验

        # 3) 验证优先闭合：伪正交或无 Verified → 严格退回 R69/R68
        verified, quarantined, _ = self.vmc.close(modes, self.ledger)
        if self.ledger.k_eff() < 2 or not verified:
            return self.fluid_fallback(modes)

        # 4) 保守执行：只有 Verified 才发 resolution bonus
        mode = self.select_verified(verified, modes)
        lam = max(self.efs.risk_scale(...), lam_floor(modes.U_ale))
        k = self.c_ras_wm.certified_prefix(
                self.ach.propose(x_prime, H=self.vista.H), ..., wm_preds)
        tau = self.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
        self.vqa_t.submit_async(asks, self.ledger, kappa, quarantined)
        return k, lam, mode, (modes.U_ale, modes.U_epi)

def effective_sources(ledger, window=512):
    R = co_failure_matrix(ledger, window)              # rho[i,j]=P(both wrong)
    return 1.0 + sum(1.0 - R[0, i] for i in range(1, len(R)))

# IP-268 TRT：闭注册表幻觉防护（工具版幻影隔离）
def guarded_call(registry, tool_id, args, tsb, tvl):

    t = registry.get(tool_id)
    if not schema_typecheck(t.schema, args): return REJECT_BAD_ARGS
```

## 4. 推导

**引理 19（跨语言幻影分离）** 接地模态跨语言语义方差 ≤ σ_g²、幻影下界 σ_p² > σ_g²，阈值 τ_κ 介于两者，m 个近似独立语言视图：幻影误判接地概率 ≤ `exp(−m(τ_κ−σ_g²)²/(8σ_p²))`，接地误隔离 ≤ `exp(−m(σ_p²−τ_κ)²/(8σ_p²))`。系：语言越多幻影筛越强——**但前提是视图近似独立；同 LLM 生成时共享方差使有效 m 下降（定义 319）**。

**引理 20（工具可采纳性的判别增益）** 工具在模态间分离 Δ_t、噪声 σ_t，一次**可采纳**调用使后验熵期望下降 ≥ `½log(1+Δ_t²/(4σ_t²))`，正确识别概率 ≥ `1−exp(−Δ_t²/(8σ_t²))`。系：工具按 Fisher 率 Δ_t/σ_t 排序，与 TVoI 同序；"看起来相关"≠"能判决"。

**引理 21（投毒上界与有效正交性）** 名义 k、欺骗率 δ、共错相关 ρ 时错误定案率 ≤ `δ·ρ^{k−1}+ε_σ`，但以 `k_eff=1+Σ(1−ρ_{1i})` 取代 k；因 `ρ_tool,lang < ρ_lang,lang`，加入可采纳工具源**严格降低**上界。系：收益来自**异构**，不是**数量**——十个同源"一致"不如一个异构"对得上"。

**引理 22（语言条件 VoI 偏差）** 在 ℓ 上估计后验若 `ECE_ℓ=ε`，则 VoI 与真值之差 ≤ `L_V·ε`。低资源语言 ε 大 ⇒ VoI 被系统性高/低估。系：LCG 把 ECE_ℓ 变为 VoI 的可信半径。

**定理 18（HERMES 严格包含 FLUID-RAS 与 R68）** 空工具注册表、|L|=1、验证关闭时逐指令同 FLUID-RAS；一般情形下证据仅在"可采纳 ∧ k_eff≥2 ∧ 无矛盾"时改变决策，故期望风险 ≤ FLUID-RAS ≤ R68，安全侧不让步。严格包含链 **R68 ⊂ FLUID-RAS ⊂ HERMES-RAS**。

**定理 19（验证优先的交互安全与无突变）** 工具沙箱化且过 C-RAS-WM；证据获取不改安全包络；不可采纳/超时/投毒/幻影隔离时模态集合单调收缩回 R69/R68，λ 单调不降；换装不变式保持 ⇒ 控制连续、无突变。

**命题 1（验证剧场的必要性条件）** 若全部证据由同一生成器产生（同 LLM 多语言、同后端工具族），共错矩阵秩为 1、`k_eff=1`；此时任意"多源一致"的置信增益恒为 0。故 resolution bonus **必须**以 `k_eff≥2` 证书为前提。

## 7. 本轮最大风险

**一句话**：HERMES-RAS 的全部收益押在「证据源是异构的」这一前提上——**但 m 种语言可能只是同一个冻结 LLM 的 m 件外套、一族工具可能只是同一个后端模型的 m 个接口；若共错相关 ρ 被低估，k_eff 就被高估，系统会把"一个源说了 k 遍"当成"k 个源相互印证"，用验证剧场给错误模态盖上 Verified 的章——这比 R68 的"诚实的不知道"更危险，因为它把不确定变成了自信的错误。**

**次级风险与缓解**：伪正交/ρ 低估（在线共错估计 k_eff + 非语言源强制 + 命题 1 发放前提）；工具幻觉（闭注册表 + 签名 schema + 硬拒绝，定义 316）；工具投毒/过期/共谋（TVL 可采纳性 + 引理 21 + ℰ_tool 对抗训练）；低资源语言校准崩塌（LCG 逐语言门控，越界仅旁证）；工具延迟/沙箱越权（验证全异步、下一 replan 生效 + TSB 白名单 + 定理 19 无突变）。
