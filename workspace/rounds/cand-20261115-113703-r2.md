# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「运动规划」×「遥操作」）

> R69 给闭环装上了嘴和眼睛：看不清就看、拿不准就问、质感不明就触；并把不确定性拆成 aleatoric 与 epistemic。但 R69 的交互有两条未经审视的隐含假设：
> - **它是无时间性的**：VoI(g)=H(M|o)−E[H(M|o,y)] 默认答案在行动之前到达。真实系统里，人会迟疑、网络会抖、接管有反应时间。若答案在「必须承诺」之后才到，它非但无用，还会诱发中途换模态。
> - **它只会「问完再选模态」**：R69 面对歧义只有两个动作——花代价问，或收紧 λ 慢下来。它没有第三个选项：**先执行一条对所有模态都安全的共享前缀，把承诺本身往后推**。
>
> 本轮两个灵感正好补上这两块：
> - **运动规划**告诉我们歧义有几何、承诺有截止时刻：绕左还是绕右、现在进窄道还是等一等，本质是**同伦类**问题；在走廊交集非空之前，存在一条对两种走法都安全的共享前缀（contingent plan）。真正该算的不是「选哪个模态」，而是「**我还能拖多久就必须选**」。
> - **遥操作**告诉我们人不是即时神谕，而是**带延迟、带工作量、带权威的控制器**：他的连续修正是一个免费的、一直在线的隐模态观测；他的一次接管能救命，也能因为「谁在控」的混淆而致命。
>
> 核心命题：**epistemic 不确定性是易腐的——它的价值在「承诺截止时刻 T\*」归零。** 把 R69 的「查询—选择」重写为「**带信息截止的应急规划**」：在可行性核内延迟承诺；按延迟/成本/侵入性组成升级阶梯去买信息；若截止先到，就把权威交给操作员（受安全契约约束）或承诺 minimax 模态。**遥操作不是另一个并列模块，而是信息阶梯的最后一级与权威兜底。** 命名 **CoPILOT-RAS**（Contingent Planning with Information-deadline, Latency-aware Operator Takeover）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我还能等多久，等不到时谁该握住方向盘**」——不确定性不只会过期，它还有一个由几何决定的最后兑现时刻。

## 0. 直觉与动机

**灵感 1（运动规划 → 歧义有几何，承诺有截止时刻）**
直觉：运动规划里最难的从来不是「生成一条无碰撞轨迹」，而是「**什么时候必须放弃另一条路**」。绕柱子走左还是走右，在进入窄道之前存在一段共享前缀：两条候选轨迹在这段上是重合的，走它不会损失任何选项。一旦走廊交集变空（进入只能容纳一种同伦类的通道），你就必须已经选好。于是歧义有两种坐标：R69 的**形状**（几个模态、各自权重）与本轮补上的**时钟**（T\* = 交集还能撑多久）。R69 的 λ 收缩其实是「原地慢下来」这一种最笨的等待；运动规划允许「**沿着所有候选都安全的交集前进着等**」——既不死等，也不早选。

**灵感 2（遥操作 → 人是带延迟的控制器，不是即时神谕）**
直觉：R69 把交互成本写成一个静态标量 c(g)，把回答当成即时的、无条件可信的观测。遥操作纠正这一点：人有反应延迟 τ_h、有注意力/工作量瓶颈，他的回答质量随疲劳与时间压力下降；更重要的是，他的**连续修正输入**（摇杆、力反馈、方向盘的微小动作）本身就是一个免费的、一直在线的隐模态观测——他往左带一点，你就知道「左」的先验该涨。于是通道不该被摊平成一个 argmax，而应组织成**升级阶梯**：先读被动意图（零成本、连续、有噪）→ 再做廉价的注视/探针 → 再显式提问（贵、慢）→ 最后才是完整接管（最贵、最危险）。

**灵感 3（合流 → 延迟把 VoI 变成会过期的食品）**
直觉：VoI 的隐含单位是「在行动之前」。一旦引入延迟 τ_g，答案只有在 τ_g ≤ T\*−t 时才有价值；过了截止，答案不仅价值为零，还会**有害**——它可能翻转后验、让控制器在运动中切换模态，产生抖振与「模式混淆」。所以本轮的核心量不是 VoI，而是**延迟贴现信息价值 DVoT**：按「能否赶上截止」给 VoI 打折，迟到答案一律进隔离区（定义 318）。一句话：**不是所有信息都值得等，有些信息等到了也已经太晚。**

**灵感 4（对偶 → R69/R68 都是「没有时间」的退化）**
直觉：令所有通道延迟为零、令 T\*≡0（没有可延迟的共享前缀）、禁止接管，CoPILOT 就逐指令退化为 R69；再关掉所有信息通道，退化为 R68。也就是说，本轮没有引入一个需要独立信任的新黑箱，而是给旧层补上「**时间**」这个缺失坐标。R69 的「严格包含」纪律被继承：新层必须在边界上等于旧层。

**灵感 5（共享控制 → 权威是最危险的旋钮）**
直觉：遥操作真正的事故源往往不是延迟本身，而是**权威歧义**：机器人和人同时以为自己说了算，或权威切换太快造成指令跳变，或人在毫无情境意识时被塞回控制权。于是「把方向盘交出去」必须是一个**经过认证的动作**：单一权威不变量（或显式定义的混合）、权威变化率上限、接管前的通知时间、切换处的无突变（bumpless transfer）与滞回。人既是信息源，也是安全关键执行器，两种身份都需要契约。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（CoPILOT-RAS 总览）** CoPILOT-RAS = (HCP, VDK, DVoT, ELS, TSA, OIC, LAQ, AIC-C, RAS-WM‡)。五不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **延迟纪律**：任何被采纳的信息动作必须携带 (τ̂, 置信上界)，且 τ̂_ub ≤ T\*_safe − t；超时答案进入隔离（定义 318）；
(iii) **权威纪律**：任一时刻至多一个权威源，或显式混合且仲裁可审计；权威切换满足速率/通知/滞回（定义 315）；
(iv) **延迟安全**：共享前缀必须位于所有候选模态安全走廊的交集内（定义 312），否则不得延迟承诺；
(v) **严格包含**：τ≡0 ∧ T\*≡0 ∧ 禁止延迟与接管时逐指令退化为 R69；再关闭全部信息通道退化为 R68。

**定义 311（同伦模态与应急计划）** 将 R69 的轨迹聚类升级为**同伦类**：m_k 为在障碍/约束空间中不可连续形变的轨迹族。应急计划（contingent plan）是树 π=(a_0, {g_j}, {a_k})：a_0 为共享前缀，g_j 为在前缀末端可执行的信息动作，a_k 为各分支的任务动作。前缀约束：a_0 对 ∀k 可行且落在安全包络内。

**定义 312（安全走廊、可行性核与承诺截止）** 模态 k 在时刻 t 的安全走廊 C_k(t)={x | 存在从 x 到目标的轨迹且风险 ≤ ε}。可行性核 K(t)=∩_k C_k(t)。承诺截止 T\*=sup{t≥0 : K(t)≠∅}。物理含义：T\* 之前存在对所有模态都安全的共享前缀，可以「延迟承诺」；T\* 之后任何动作都至少对一个模态不安全，必须已选定模态。为留出制动与分支准备，实际使用 **T\*_safe = T\* − τ_brake − max_k τ_prep(k)**。

**定义 313（延迟贴现信息价值 DVoT）** 通道 g 的到达延迟为 τ_g（已知分布或带置信上界），当前时刻 t。定义
DVoT(g)=P(τ_g ≤ T\*_safe−t)·E[H(M|o)−H(M|o,y) | on-time] − c(g) − c_late(g)·P(τ_g > T\*_safe−t)，
其中 c_late 是「迟到答案诱发切换」的期望代价。性质：若 τ_g ≥ T\*_safe−t 几乎必然，则 DVoT ≤ 0。特例：τ=0 且 T\*_safe→∞ 时 DVoT=VoI（R69）。

**定义 314（交互通道与升级阶梯 ELS）** 通道集合 𝒞={被动意图, 注视, 探针, 提问, 接管}，每通道带 (τ_g, c_g, 侵入性, 可靠性)。ELS 规则：按 (成本/可靠性) 升序排列，只有当「当前通道处理后的后验」仍未达到「截止前所需置信」时才升到下一级。R69 的 argmax VoI 是「所有通道同延迟、同成本」的退化特例。

**定义 315（遥操作权威场与交接契约）** 权威 α(t)∈[0,1]（0=全自主，1=全人工），混合指令 u=α·u_h+(1−α)·u_r（或在安全子空间内切换）。契约：|α̇| ≤ α̇_max；接管前通知时间 ≥ τ_notice；切换处指令连续（bumpless）；单一权威不变量；仲裁器状态可审计。α 的调度本身是一个带安全约束的行动。

**定义 316（操作员意图观测通道 OIC）** 操作员输入 u_h = y(m, workload w, latency τ_h, noise)。把 u_h 视为隐模态 m 的噪声观测 p(u_h|m)：则「被动意图推断」是零成本证据；「权威探测」（在安全子空间短暂让权并观察修正方向）是一个主动信息动作，其信息量 ≤ I(m;u_h)。操作员不是神谕，而是**相关噪声通道**：w↑、τ_h↑ ⇒ 互信息↓。

**定义 317（应急风险缩放与延迟红利）** 若 t < T\*_safe 且共享前缀 a_0∈K(t) 存在：λ = λ_floor(U_ale)（**deferral bonus**——共享前缀对所有模态安全，不必为模态歧义支付保守罚）。若 t ≥ T\*_safe（已承诺）且 U_epi 未消解：λ = λ_floor(U_ale + U_epi)（R69 兜底）。⇒ R69 恰为 T\*≡0 的特例。

**定义 318（迟到答案隔离 LAQ）** 若答案在承诺后到达，默认不采纳（quarantine）。仅当 (i) 通过高置信重规划门（后验翻转概率 > 1−δ 且新计划落在安全包络内），且 (ii) 切换代价 ≤ 预算时，才允许**至多一次**有界重规划；否则记为审计事件。目的：杜绝「迟到答案诱发振荡」。

**定义 319（截止感知调度 EDF-DP）** 信息动作带截止 d_g = t + T\*_safe − τ_g 与成本 c_g。在「单位时间至多一次、总预算 B」下最大化按期信息增益：单成本用 EDF 最优；变成本用带 deadline 的背包/DP，给出 (1+ε) 近似。超期动作被丢弃而非排队。

**定义 320（应急证书 J_COPILOT）** J_COPILOT = (J_FLUID, T\*_safe, τ̂_ub 分布, DVoT_ratio, authority_log_hash, late_answer_count, deferral_ratio, copilot_ver)。Valid ⇔ Valid(J_FLUID) ∧ 所有被采纳通道满足 τ̂_ub ≤ T\*_safe ∧ 权威契约满足 ∧ 无未审计的迟到切换。

**定义 321（威胁模型 AIC-COPILOT）** ℰ_COPILOT = ℰ_FLUID × ℰ_latency × ℰ_authority × ℰ_corridor：延迟攻击（故意延迟/丢弃答案使系统错过 T\*）、权威欺骗（伪造接管/劫持 α 通道）、走廊投毒（污染障碍/动力学模型使 K(t) 虚高，制造「假安全」延迟）、模式混淆注入（让操作员与机器人对「谁在控」产生分歧）。

**定义 322（严格包含）** 当 τ≡0、T\*≡0、α 固定、禁用延迟与接管时，CoPILOT 逐指令等于 R69（定义 306–309）；再令无信息通道，等于 R68。安全侧不弱于二者。

**定义 323（透明性显示 TUD）** 机器人把 (U_epi, T\*_safe, 候选模态) 以可理解形式显示给操作员，作为「反向信息动作」：降低操作员意图推断的噪声、缩短接管通知时间。显示有注意成本，纳入预算；不得显示会诱发危险动作的误导信息。

**定义 324（同伦合并/分裂与模态生灭）** 动态环境中同伦类可合并（障碍移开）或分裂（新障碍插入）。定义模态生灭事件与重规划触发：K(t) 变化率超阈值或 Δ_min 突变即重算应急计划树，避免在旧拓扑上继续延迟。

**定义 325（拖延风险监视器 PRM）** 延迟不是免费的：共享前缀可能绕远、耗时、增加暴露。定义拖延指数 Proc=(绕行代价 + 暴露风险)/(已获信息价值)；Proc 过高说明「为了等答案而等」，应提前承诺或升级通道。防止把「延迟承诺」变成「无限拖延」。

**定义 326（延迟估计与截止置信）** τ̂_g 用在线分位数估计（P90/P95），T\*_safe 用可达集保守外扩。二者都带置信区间；当区间重叠（τ̂_ub 可能 > T\*_safe）时不得依赖该通道，降级到更快通道或接管。这是把 R69 的「保守铁律」从风险域搬到时间域。

# IP-264/265 HCP+VDK：同伦感知的应急计划树与可行性核
class ContingentPlanner:
    def plan(self, modes, o, wm):
        classes   = homotopy_classes(modes)                 # 同伦聚类，非普通 DTW
        corridors = {k: safe_corridor(m, o, wm) for k, m in classes.items()}
        K         = intersect(corridors)                    # 可行性核（定义 312）
        T_safe    = commitment_deadline(K, wm) - brake_margin(corridors)
        a0        = shared_prefix(K, T_safe)                # 对全部模态安全的共享前缀
        return ContingentPlan(a0, T_safe, classes, corridors)

# IP-266/267 DVoT+ELS：截止贴现信息价值与升级阶梯
def choose_channel(modes, plan, t, channels, budget):
    conf_now = max_mode_posterior(modes)
    need     = confidence_needed_at(plan.T_safe)            # 截止前所需置信
    for g in sorted(channels, key=lambda c: c.cost / c.reliability):
        if conf_now >= need:            return None         # 已够确定，不必交互
        if t + latency_p95(g) > plan.T_safe: continue       # 赶不上截止（定义 326）
        dvot = (p_on_time(g, plan.T_safe - t) * info_gain(g)
                - g.cost - late_penalty(g, plan.T_safe - t)) # 定义 313
        if dvot > 0 and budget.allow(g):
            return g
    return None                                              # 赶不上 → 接管/承诺

# IP-268 TSA：权威仲裁与无突变交接
class AuthorityArbiter:
    def step(self, alpha_prev, request, human, robot, dt):
        target = self.arbitrate(request, human.situation_awareness, robot.confidence)
        alpha  = rate_limit(target, ALPHA_DOT_MAX, dt)       # 定义 315
        if target > alpha_prev + EPS:
            assert dt >= NOTICE_TIME * (target - alpha_prev) # 接管通知时间
        u = alpha * human.u + (1 - alpha) * robot.u
        return safe_filter(u, self.envelope), alpha

# IP-270 LAQ：迟到答案隔离与有界重规划
def on_answer(answer, t, plan):
    if t <= plan.T_safe:
        return update_belief(answer)                         # 按期到达 → 正常并入
    if posterior_flip_prob(answer) > 1 - DELTA and safe_and_cheap_replan(answer):
        return bounded_replan(answer)                        # 至多一次
    audit.late_answer(answer)
    return None                                              # 丢弃，不切换

# IP-275 主闭环（继承 R69，在不确定性处置处插入时间/权威层）
def COPILOT_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, thr = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, K), z, M.fmp.mode_head)
    # 1) 同伦化 + 可行性核 + 承诺截止
    plan  = M.hcp.plan(modes, o, M.wm)
    # 2) 免费证据：操作员连续修正
    modes = M.oic.assimilate(modes, M.human.u)
    # 3) 截止贴现 VoI：只在赶得上时买信息
    g = M.els.choose(modes, plan, M.t, M.channels, M.budget)
    if g is not None:
        U_epi = M.cia.update_belief(modes, g.execute())
    # 4) 截止前仍歧义：升级到接管；否则承诺 minimax 模态
    need_takeover = (M.t + M.els.min_latency() > plan.T_safe) and (U_epi > TAU_EPI)
    lam = deferral_lambda(plan, U_ale, U_epi, M.t)           # 定义 317
    a0  = plan.shared_prefix if M.t < plan.T_safe else M.select_minimax(modes)
    k   = M.c_ras_wm.certified_prefix(a0, ..., wm_preds)
    u, alpha = M.tsa.step(M.alpha, need_takeover, M.human, M.robot, M.dt)
    M.prm.check(plan, g, U_epi)                              # 拖延风险（定义 325）
    M.vqa_i.submit(g, alpha, plan.T_safe, U_epi)             # 审计
    return k, lam, a0, alpha, (U_ale, U_epi)

## 3. 推导

**假设** A100：同伦分解保守，走廊交集是真实安全集的子集（宁可低估 K）；A101：延迟分布可在线估计，T\* 可测且用制动余量外扩；A102：操作员意图通道与隐模态互信息非零但有界，且随工作量/延迟衰减；A103：K 非空期间共享前缀在延迟速度下对所有模态安全；A104：权威混合对状态 Lipschitz，安全包络控制不变。

**引理 19（延迟承诺占优）** 在 A100–A103 下，若 K(t) 在 [t,T\*] 非空，则采用应急计划、在 T\* 前只执行共享前缀的策略，其期望风险不高于任何立即承诺策略；当模态可分（Δ_min 大）且存在按期信息时，期望成本严格更低。要点：立即承诺必须以正概率选错模态（后验质量），而延迟承诺保留全部选项；共享前缀对所有模态安全，因此延迟不引入额外风险，只是把「选择」推迟到信息更充分时。

**引理 20（epistemic 的易腐性）** DVoT(g) 关于 τ_g 与 t/T\*_safe 单调不增，且仅在 τ=0、T\*_safe=∞ 时等于 VoI；当 τ_g ≥ T\*_safe−t 时 DVoT ≤ 0。系：R69 的 VoI 是「瞬时、无限期」极限下的上界，因此只要延迟不可忽略，R69 就**系统性过问**——它愿意为一个到不了的答案付成本。

**引理 21（迟到答案的危害）** 设承诺后到达的答案以后验翻转概率 p_flip 改变模态判断，切换代价为 c_sw。则采纳该答案的期望代价 ≥ p_flip·c_sw − (1−p_flip)·gain。存在参数使该值 > 0，而此刻「按期价值」已为 0（截止已过），故迟到答案严格有害。这为 LAQ（定义 318）提供依据：不是「保守起见不用」，而是「用了期望更差」。

**引理 22（操作员通道的互信息上界）** I(m;u_h) 随工作量 w 与延迟 τ_h 单调不增，且 I(m;u_h) ≤ I(m;u_h|w)。系：遥操作意图推断只能把后验抬到一个有界水平，**不能替代** R69 的 k-正交证据纪律；把人的连续输入当作「免费真值」是对相关噪声的误读。

**定理 18（严格包含 R69/R68）** 在 A100–A104 下，CoPILOT 的任意状态期望风险不高于 R69；当 τ≡0、T\*≡0、α 固定时两者逐指令相同；再关闭全部信息通道时退化为 R68。故 R70 不是并列替代，而是给 R69 补上「时间」坐标的严格泛化；安全侧不让步，效率侧获得 **deferral bonus**。

**定理 19（权威安全与无突变）** 在单一权威不变量 + |α̇|≤α̇_max + 通知时间 τ_notice + bumpless 条件下，混合指令始终位于 C-RAS-WM 认证包络内，权威切换的指令跳变有界；接管风险 ≤ g(α̇_max, τ_notice)，模式混淆概率 ≤ h(滞回宽度, TUD 透明性)。证明要点：包络对凸混合封闭（A104），速率限制保证切换轨迹连续，滞回保证不抖动。

**定理 20（截止感知调度）** 对单位成本、单资源的信息动作集，EDF 最大化按期完成数；对可变成本与总预算 B，带 deadline 的 DP 在离散网格上给出 (1+ε) 近似。系：把「问什么」与「来不来得及问」解耦后，R69 的 argmax VoI 只是 EDF 在「所有截止为 ∞」时的特例。

## 6. 本轮最大风险

**一句话**：CoPILOT-RAS 的全部「延迟承诺」都押在**可行性核 K(t) 与同伦分解是保守且正确的**这一前提上——一旦模型误差、动态障碍或走廊投毒把安全走廊的交集**高估**，「延迟承诺」就变成「在悬崖边拖延」；再叠加遥操作里那个延迟与权威都不确定的人，**当初允许你等的那条截止线，可能正是杀死你的那一条**——等得越久，错过的可能不只是答案，而是唯一的刹车点。

**次级风险与缓解**：
1. **延迟被低估**（P95 抖动、排队、人反应慢）→ 定义 326 的置信上界 + DVoT 的 on-time 概率 + 赶不上就接管，绝不「赌它来得及」；
2. **权威模式混淆**（双方都以为在控/切换跳变）→ 单一权威不变量 + 速率限制 + 通知时间 + 滞回 + TUD 透明显示（定义 315/323，定理 19）；
3. **操作员是相关噪声而非真值**（疲劳、误导、共谋）→ 引理 22 上界 + R69 的 k-正交证据纪律 + OIC 不单独定案；
4. **迟到答案诱发振荡** → LAQ 隔离 + 至多一次有界重规划 + 审计（定义 318、引理 21）；
5. **拖延本身有代价**（绕远、暴露、错过时间窗）→ PRM 拖延指数 + 提前承诺/升级通道（定义 325）；
6. **动态拓扑变化**（同伦类合并/分裂）→ 模态生灭监测 + 重算应急树（定义 324）。

class ContingentPlanner:
    def plan(self, modes, o, wm):

def choose_channel(modes, plan, t, channels, budget):
    conf_now, need = max_mode_posterior(modes), confidence_needed_at(plan.T_safe)

## 4. 推导

**引理 19（延迟承诺占优）** A100–A103 下，若 `K(t)` 在 `[t,T*]` 非空，应急计划（只走共享前缀、到 T\* 再选）的期望风险 ≤ 任何立即承诺策略；模态可分且有按期信息时期望成本严格更低。要点：立即承诺以正概率选错，延迟保留全部选项且前缀对所有模态安全。

**引理 20（epistemic 易腐性）** `DVoT` 关于 `τ_g`、`t/T*_safe` 单调不增；仅 `τ=0,T*=∞` 时等于 VoI；`τ_g≥T*_safe−t ⇒ DVoT≤0`。系：R69 的 VoI 是瞬时无限期上界，延迟不可忽略时 R69 **系统性过问**。

**引理 21（迟到答案的危害）** 承诺后答案以后验翻转概率 `p_flip`、切换代价 `c_sw` 被采纳，期望代价 ≥ `p_flip·c_sw−(1−p_flip)·gain`；可 >0，而此刻按期价值已为 0。故 LAQ 是「用了更差」，不是「保守起见」。

**引理 22（操作员通道上界）** `I(m;u_h)` 随工作量与延迟单调不增且 `≤I(m;u_h|w)`。系：遥操作意图推断只能抬到有界后验，不能替代 R69 的 k-正交证据纪律。

**定理 18（严格包含 R69/R68）** A100–A104 下 CoPILOT 任意状态期望风险 ≤ R69；`τ=0,T*=0,α` 固定时逐指令相同；关闭信息通道退化为 R68。安全不让步，效率获 deferral bonus。

**定理 19（权威安全与无突变）** 单一权威 + `|α̇|≤α̇_max` + 通知 + bumpless 下，混合指令始终在认证包络内，切换跳变有界；接管风险 ≤ `g(α̇_max,τ_notice)`，模式混淆概率 ≤ `h(滞回宽度,TUD)`。

**定理 20（截止感知调度）** 单位成本单资源下 EDF 最大化按期完成数；变成本 + 预算 B 时带 deadline 的 DP 给 `(1+ε)` 近似。R69 的 argmax VoI 是「全部截止为 ∞」的特例。

## 7. 本轮最大风险

**一句话**：CoPILOT-RAS 的全部「延迟承诺」都押在**可行性核 K(t) 与同伦分解保守且正确**这一前提上——一旦模型误差、动态障碍或走廊投毒把安全走廊交集**高估**，「延迟承诺」就成了「在悬崖边拖延」；再叠加遥操作里延迟与权威都不确定的人，**当初允许你等的那条截止线，可能正是杀死你的那一条**——等得越久，错过的可能不只是答案，而是唯一的刹车点。

**次级风险与缓解**：延迟低估（τ̂ 上界 + on-time 概率 + 赶不上即接管）；权威模式混淆（单一权威 + 速率 + 通知 + 滞回 + TUD）；操作员相关噪声（引理 22 + k-正交证据 + OIC 不单独定案）；迟到答案振荡（LAQ + 至多一次有界重规划）；拖延代价（PRM + 提前承诺/升级）；动态拓扑（模态生灭 + 重算应急树）。
