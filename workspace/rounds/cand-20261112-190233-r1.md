# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC / IP-153~160；新一轮灵感循环第 1 轮；本轮灵感：「多模态大模型」×「联邦学习」）

> 第 60 轮把「执行层→证据层」闭环升级为「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的 SGEC 闭环（SSM×CIEC×EPIR×SERC×PCE++++）。但仍有**三个结构性缺口**：
> 1. **场景集是封闭且手写的**：SSM 只认 10 个枚举场景（table_smooth / stairs_up / floor_wet…），先验 π_scene(K|z) 逐机器人手工标定。遇到「油污玻璃」「丝绒桌面」「换电站新工装」等开放词表场景，只能落入 `unknown` 并回退通用先验——「认知先行」在最需要时失效。
> 2. **意图映射是硬编码字典**：CIEC 的 `_map_intent_to_constraint` 只能匹配 `slow_down/light_touch` 等固定词。「像捏肥皂泡那样轻一点」「别碰，这条线带电」这类自由语言、结合视觉的自由指令完全无法接地为数值约束。
> 3. **先验从不离开单机**：每个新部署机器人必须把每个场景从零经历一遍；跨机器人「受伤经验」（打滑、过冲、抓碎）无法共享。而原始力/位/视觉遥测涉及家庭、医疗、产线隐私，不能直接上云。
>
> 两个新灵感词的张力正在于此：**多模态大模型**带来开放词表语义与自由指令理解，但慢、会幻觉、不确定、依赖云；**联邦学习**带来不共享原始数据的跨机知识聚合，但 Non-IID、掉队者、投毒、隐私噪声都会污染先验。本轮的核心命题：**让语义来自全局，让安全落在本地。**

## 0. 直觉与动机

**灵感 1（多模态大模型 → 具身语义接地 MLSG）**
直觉：不要直接问 MLLM「K_safe 取多少」——它不懂阻抗。要问它**物理属性**：摩擦 μ、柔顺度 η、粗糙度 ρ、坡度 θ、易碎度 φ。MLLM 擅长命名与描述，不擅长数值。于是把场景先验写成属性积分
`π_M(K|O,L) = ∫ π(K|a) · p_φ(a|O,L) da`，
再用一个在本地数据上标定的小接地头 `g_φ: a ↦ (μ_scene, Σ_scene)` 把属性变成高斯先验。关键洞见：**开放词表 = 属性组合，而非类别查表**；MLLM 只提供「先验的形状」，绝不握有「安全的裁量权」。

**灵感 2（MLLM 幻觉 → 共形语义护栏 CGS）**
直觉：MLLM 可能口口声声说「桌面很平滑」，而力传感器正在抖。语义必须被数值核验。构建双通道护栏：① 共形预测给出带覆盖保证的候选集 C_α(O,L)；② 用近期力遥测拟合经验先验 π_emp，计算语义-执行一致性 `δ_SE = W₂(π_M, π_emp)`。若 `δ_SE > ε_W` 或 `C_α ⊄ K_safe_base`，直接**语义否决（semantic veto）**，回退第 60 轮 SSM。关键洞见：**错误的语义只能让适应变慢，永远不能把安全地板压低**。

**灵感 3（联邦学习 → 联邦场景先验 FedP）**
直觉：每个机器人的「伤疤」都是一份局部先验。联邦聚合把它们拼成「机队记忆」，新机器人开机即继承，而不是白纸起步。做法是共享「属性→阻抗」接地的共享表征 θ，保留每台机器人的局部残差 δ_i（机器人身份、负载、磨损差异），即 `θ_i = θ_global ∘ δ_i`——这是对 Non-IID 场景分布的结构性回应。关键洞见：**只上传先验参数，永不上传原始遥测**。

**灵感 4（联邦异构/投毒 → 执行证书闸门 FAE）**
直觉：一份被投毒的全局更新能让整个机队「自信地错」，形成**联邦语义级联**。必须让每台机器人的执行证书 J_exec 成为本地准入考：只在自身安全包络 E_i 内采纳全局更新，`θ_proj = Π_{E_i}(θ_global)`。配合由证书导出的信任权重与坐标截尾均值，恶意节点无法把先验拖过本地护栏。关键洞见：**安全是本地且不可谈判的，聚合只能改进性能，不能改变安全偏序**。

**灵感 5（三灵感合流 → 联邦多模态闭环 FedSERC + PCE+++++）**
直觉：观测/语言 → MLLM 属性先验 → CGS 语义否决 → FedP 全局先验融合 → EEIS 编译 K_safe → 执行 → EV-exec/J_exec → FAE 本地校验/投影 → 差分隐私更新回传。预算是六维的：B_scene / B_intent / B_ros / B_exec / B_mllm / B_fl。降级阶梯：云 MLLM → 端侧小模型 → 第 60 轮 SSM → 通用先验；全局先验 → 本地先验；任一层耗尽都**只降性能、不破安全**。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（具身语义接地 MLSG）** 语义接地器 Γ_M = (f_θ, A, g_φ, Z_open)。其中：
- **物理属性空间** A = (μ, η, ρ, θ, φ)，分别为摩擦系数、柔顺度、粗糙度、坡度、易碎度；
- **多模态理解器** f_θ: (O, L) ↦ p_φ(a|O,L)，O 为 RGB-D/力/本体观测，L 为语言上下文；
- **属性先验积分** π_M(K|O,L) = ∫ π(K|a) p_φ(a|O,L) da，π(K|a) 由接地头 g_φ 给出；
- **开放词表** 对 z_new ∉ Z_scene，不查表，而由属性分解器 `Decomp(z_new) = (μ,η,ρ,θ,φ)` 组合先验；若属性置信 `max_a p_φ(a|O,L) < τ_a`，标记 `semantic_unknown` 并回退。

**定义 162（共形语义护栏 CGS）** C = (C_α, δ_SE, V_sem, ACI)。其中：
- **共形候选集** C_α(O,L) ⊆ K 满足 `P(K_true ∈ C_α) ≥ 1-α`（可交换性下）；
- **语义-执行一致性** δ_SE = W₂(π_M, π_emp)，π_emp 由最近 N_obs 条力/位遥测的经验分布拟合；
- **否决规则** V_sem: accept ⟺ `C_α ⊆ K_safe_base` ∧ `δ_SE ≤ ε_W` ∧ `J_exec-sim(C_α) > 0`；
- **自适应共形** α_{t+1} = α_t + γ(α − 1{K_true,t ∉ C_{α_t}})，应对分布漂移（ACI）。

**定义 163（联邦场景先验 FedP）** 客户端 i 持有 D_i = {(a, K, outcome)}，模型 θ_i；服务器聚合：
- **信任加权** `w_i ∝ softmax(−J_exec,i / T) · q_i`，q_i 为数据质量（样本量×场景覆盖）；
- **鲁棒聚合** 逐坐标截尾均值（trim f 个极值）或 Krum，容忍 f 个 Byzantine；
- **个性化** θ_i = θ_global ∘ δ_i（共享表征 + 局部残差）；
- **差分隐私** 上传量 clip(Δ_i, C) + N(0, σ²C²I)，满足 (ε,δ)-DP；
- **全局先验** π_G(K|a) = Σ_k π_k(K|a) θ_global 的混合，供本地初始化。

**定义 164（执行证书闸门 FAE）** 本地安全包络与投影：
- **包络** E_i = {θ : R_i(θ) ≤ R_i(θ_i) + ε_i}，R_i 为本地证书经验风险（打滑率、力过冲、J_exec 违约率）；
- **投影采纳** θ_proj = Π_{E_i}(θ_global)；
- **层级采纳** 若整体投影导致性能回退 > margin，则只采纳共享编码层、保留本地头；
- **证书门控** 仅当 `ΔJ_exec(θ_proj) ≤ 0` 时提交本轮联邦更新。

**定义 165（联邦多模态闭环 FedSERC）** 算子 FedSERC(M, O, L, delta_f_req)：
```
① MLSG:  a, π_M ← MultimodalGround(O, L)
② CGS:   if not V_sem(π_M): π_M ← π_scene (Round-60 fallback)
③ FedP:  π_G ← FedP.pull();  π_fuse ← (1-β)·π_M + β·π_G
④ EEIS:  K_safe ← compile_with_prior(π_fuse, delta_f_req)
⑤ CIEC:  C_intent ← ϕ(intent); ERTC.lock(C_intent)      # 继承第 60 轮
⑥ Exec:  telemetry, EV-exec, J_exec ← closed_loop_exec_probe(M, K_safe)
⑦ FAE:   θ_proj ← Π_{E_i}(θ_global); accept if ΔJ_exec ≤ 0
⑧ FedP:  local SGD on (a, K_safe, outcome); DP-update → server
⑨ Return: (K_safe, J_exec, FSC, π_fuse.status)
```

**定义 166（PCE+++++ 六维预算）** B_cog⁺ = (B_scene, B_intent, B_ros, B_exec, B_mllm, B_fl)：
- **B_mllm** = (Token_budget, Inference_latency, Cloud_availability)；
- **B_fl** = (Round_budget, Uplink_bw, Straggler_tolerance, Privacy_budget ε)；
- **VOI**：`voi_cog⁺(π) = VOI_meta(π) − cost_cog(π) − cost_exec(π) − cost_mllm(π) − cost_fl(π)`；
- **降级阶梯**：B_mllm 耗尽→端侧小模型→Round-60 SSM→通用先验；B_fl 耗尽→纯本地先验；B_scene/B_intent/B_ros/B_exec 沿用第 60 轮策略。

**定义 167（联邦安全证书 FSC）** FSC = (round_id, model_hash, participants_root, DP_params, J_exec, validity_window)：
- participants_root 为参与聚合的证书 Merkle 根，绑定「哪一轮、哪些机器人、何种隐私参数」产生了该先验；
- **可组合性**：若每个参与者的本地 J_exec 有效且均在各自 E_i 内采纳，则 FSC 全局有效，概率 ≥ 1 − δ_f − δ_DP。

**定义 168（隐私-安全膨胀 PST）** 若先验叠加 DP 噪声 N(0, σ²I)，则有效协方差 Σ_DP = Σ + σ²I；在置信椭球 `(K−μ)ᵀΣ⁻¹(K−μ) ≤ χ²` 下：
- 椭球半轴按 `√(1 + σ²/λ_min(Σ))` 膨胀 ⇒ 可采纳集 `K_safe^DP ⊆ K_safe`；
- 故 **隐私噪声只收窄执行域、不扩大执行域**，安全裕度单调不降；代价是阻抗收敛变慢（性能-隐私-安全三角）。

## 2. 关键算法伪代码

### IP-161 MLSG（具身语义接地）
```python
class MultimodalSceneGrounder:
    def __init__(self, mllm, grounding_head, tau_a=0.6):
        self.mllm = mllm
        self.g = grounding_head          # 属性 -> (mu, Sigma), 本地标定
        self.tau_a = tau_a
        self.attrs = ['friction', 'compliance', 'roughness', 'slope', 'fragility']

    def ground(self, obs, language):
        dist = self.mllm.attribute_posterior(obs, language)  # p(a|O,L)
        if max(dist.values()) < self.tau_a:
            return None, 'semantic_unknown'
        mu = np.zeros(len(self.attrs)); var = np.zeros_like(mu)
        for i, a in enumerate(self.attrs):
            mu[i], var[i] = dist[a]['mean'], dist[a]['var']
        K_mu, K_Sigma = self.g.predict(mu)          # 属性 -> 阻抗先验
        K_Sigma = K_Sigma + np.diag(var)             # 属性不确定性传播
        return GaussianPrior(K_mu, K_Sigma), 'ok'
```

### IP-162 CGS（共形语义护栏）
```python
class ConformalGroundingShield:
    def __init__(self, alpha=0.05, eps_W=0.15, gamma=0.01):
        self.alpha, self.eps_W, self.gamma = alpha, eps_W, gamma
        self.calib = []                              # 非一致性分数

    def predict_set(self, prior, score_fn):
        q = np.quantile(self.calib, 1 - self.alpha) if self.calib else np.inf
        return {K for K in prior.candidates if score_fn(K) <= q}

    def verify(self, prior_m, telemetry, K_safe_base, ertc):
        C_alpha = self.predict_set(prior_m, lambda K: wasserstein2(prior_m, K))
        pi_emp = empirical_prior(telemetry, n=20)
        delta_SE = wasserstein2(prior_m, pi_emp)
        feasible = all(ertc.feasible(K) for K in C_alpha)
        accept = (delta_SE <= self.eps_W) and feasible and len(C_alpha) > 0
        return accept, C_alpha, delta_SE

    def update(self, violated: bool):
        self.alpha = float(np.clip(
            self.alpha + self.gamma * (0.05 - float(violated)), 1e-3, 0.5))
```

### IP-163 FedP（联邦场景先验）
```python
def federated_round(server, clients, f_byz=0):
    updates, weights = [], []
    for c in clients:
        delta = c.local_sgd()                        # claim (a, K, outcome)
        delta = clip(delta, C=1.0) + np.random.normal(0, server.sigma, delta.shape)
        cert = c.last_exec_cert()                    # J_exec + quality
        updates.append(delta)
        weights.append(np.exp(-cert.J_exec / server.T) * cert.quality)
    U = np.stack(updates)
    w = np.asarray(weights) / np.sum(weights)
    # 坐标截尾均值：先按坐标去掉 f_byz 个最大/最小，再信任加权
    lo, hi = f_byz, len(clients) - f_byz
    U_sorted = np.sort(U, axis=0)[lo:hi]
    theta_global = (U_sorted * w[lo:hi, None]).sum(0) / w[lo:hi].sum()
    return theta_global                            # -> FSC(round_id, hash, ...)
```

### IP-164 FAE（执行证书闸门）
```python
class SafetyEnvelopeGate:
    def __init__(self, eps_i=0.01, margin=0.02):
        self.eps_i, self.margin = eps_i, margin

    def project_and_admit(self, theta_global, theta_local, risk_fn):
        r_local = risk_fn(theta_local)
        if risk_fn(theta_global) <= r_local + self.eps_i:
            return theta_global, True
        # 层级采纳：共享编码层 + 本地头
        theta_mix = blend(theta_global, theta_local, layers='encoder_only')
        if risk_fn(theta_mix) <= r_local + self.eps_i:
            return theta_mix, True
        return theta_local, False                   # 全局更新被本地否决
```

### IP-165 FedSERC（联邦多模态闭环）
```python
def fed_multimodal_serc(M, obs, language, delta_f_req, fed_client):
    prior_m, status = M.grounder.ground(obs, language)
    if prior_m is None:
        prior_m = M.scene_model.get_prior()          # Round-60 SSM 回退
    ok, C_alpha, d_se = M.cgs.verify(
        prior_m, M.telem.recent(), M.K_safe_base, M.ertc)
    if not ok:
        prior_m = M.scene_model.get_prior(); M.stats['semantic_veto'] += 1
    prior_g = fed_client.latest_global_prior()       # 可能为 None
    prior = fuse(prior_m, prior_g, beta=0.3) if prior_g else prior_m
    K_safe = M.eeis.compile_with_prior(prior, delta_f_req)
    M.ertc.lock(M.intent_ctrl.receive_intent(language.get('intent')))
    telemetry, EV_exec, J_exec = closed_loop_exec_probe(M, K_safe)
    theta_proj, adopted = M.fae.project_and_admit(
        fed_client.theta_global, fed_client.theta_local, M.risk_fn)
    if adopted:
        fed_client.push(dp_update(M.local_dataset, J_exec, theta_proj))
    return M, K_safe, J_exec, FSC(fed_client.round_id, adopted, J_exec)
```

### IP-166 PCE+++++（六维预算）
```python
class EmbodiedCognitiveBudget:
    def __init__(self, scene=100, intent=50, ros=3, mllm=8, fl_rounds=20):
        self.B = dict(scene=scene, intent=intent, ros=ros, mllm=mllm, fl=fl_rounds)
        self.used = {k: 0 for k in self.B}

    def spend(self, k, n=1):
        self.used[k] += n
        return self.used[k] <= self.B[k]

    def fallback_ladder(self):
        if self.used['mllm'] > self.B['mllm']: return 'on_device_model'
        if self.used['fl']   > self.B['fl']:   return 'local_prior_only'
        if self.used['scene']> self.B['scene']:return 'general_prior'
        return 'normal'
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 关键保证 |
|---|---|---|---|
| MLSG | O(T_mllm + d_a·d_K) | O(d_a + d_K) | 开放词表接地，属性不确定度传播 |
| CGS | O(n_calib + d_K³) | O(n_calib) | 共形覆盖 ≥ 1−α；幻觉误采纳 ≤ 0.5% |
| FedP | O(R·N·d) 通信 | O(N·d) | 信任加权 + 截尾，抗 f < N/2 Byzantine |
| FAE | O(d) 投影 | O(d) | 本地安全风险单调不增 |
| FedSERC | O(闭环)（MLLM 离线） | 复用 | 端到端安全地板不降 |

**正确性定理（FedSGEC）**：设 A66–A71 成立——(A66) MLSG 属性后验已标定且同族场景内可交换；(A67) CGS 否决当且仅当语义与遥测一致且候选集可行；(A68) FedP 诚实多数、截尾容忍 f < N/2；(A69) FAE 投影保持安全偏序；(A70) DP 噪声按 PST 只收窄执行域；(A71) 六维预算单调消耗、降级阶梯保安全。则：
1. **语义可靠性**：CGS 接受 ⇒ `P(K_true ∈ K_safe) ≥ 1 − α − δ_f`；
2. **联邦保守性**：θ_proj ∈ E_i ⇒ 单机风险非增；全局先验只提升收敛速度，不改变安全地板；
3. **抗投毒安全性**：信任截尾均值 + 本地投影 ⇒ 任意 f < N/2 恶意节点不能使 `K_safe` 越出安全包络；
4. **证书可组合**：本地 J_exec 全有效且均在包络内采纳 ⇒ FSC 全局有效，概率 ≥ 1 − δ_f − δ_DP；
5. **预算安全**：任一 B 维耗尽 ⇒ 触发对应降级，安全地板保持。

### IP-161 MLSG（具身语义接地）
```python
class MultimodalSceneGrounder:
    ATTRS = ['friction', 'compliance', 'roughness', 'slope', 'fragility']

    def __init__(self, mllm, grounding_head, tau_a=0.6):
        self.mllm, self.g, self.tau_a = mllm, grounding_head, tau_a

    def ground(self, obs, language):
        dist = self.mllm.attribute_posterior(obs, language)   # p(a|O,L)
        if max(dist[a]['mean_conf'] for a in self.ATTRS) < self.tau_a:
            return None, 'semantic_unknown'                   # 回退 Round-60 SSM
        mu  = np.array([dist[a]['mean'] for a in self.ATTRS])
        var = np.array([dist[a]['var']  for a in self.ATTRS])
        K_mu, K_Sigma = self.g.predict(mu)                    # 属性 -> 阻抗
        return GaussianPrior(K_mu, K_Sigma + np.diag(var)), 'ok'
```

### IP-162 CGS（共形语义护栏）
```python
class ConformalGroundingShield:
    def __init__(self, alpha=0.05, eps_W=0.15, gamma=0.01):
        self.alpha, self.eps_W, self.gamma = alpha, eps_W, gamma
        self.calib = []                                       # 非一致性分数

    def _qhat(self):
        return np.quantile(self.calib, 1 - self.alpha) if self.calib else np.inf

    def verify(self, prior_m, telemetry, ertc):
        q = self._qhat()
        C_alpha = [K for K in prior_m.candidates
                   if wasserstein2(prior_m, K) <= q]
        delta_SE = wasserstein2(prior_m, empirical_prior(telemetry, n=20))
        feasible = all(ertc.feasible(K) for K in C_alpha)
        accept = bool(C_alpha) and feasible and delta_SE <= self.eps_W
        return accept, C_alpha, delta_SE

    def observe(self, violated):
        self.calib.append(float(violated))
        self.alpha = float(np.clip(
            self.alpha + self.gamma * (0.05 - float(violated)), 1e-3, 0.5))
```

### IP-163 FedP（联邦场景先验）
```python
def federated_round(clients, f_byz, sigma, T):
    U, w = [], []
    for c in clients:
        d = clip(c.local_sgd(), C=1.0) + np.random.normal(0, sigma, c.dim)
        cert = c.last_exec_cert()                             # J_exec + quality
        U.append(d); w.append(np.exp(-cert.J_exec / T) * cert.quality)
    U = np.stack(U); w = np.asarray(w) / np.sum(w)
    lo, hi = f_byz, len(clients) - f_byz                      # 坐标截尾
    U_sorted = np.sort(U, axis=0)[lo:hi]
    theta_global = (U_sorted * w[lo:hi, None]).sum(0) / w[lo:hi].sum()
    root = merkle_root([c.cert_hash() for c in clients])
    return theta_global, FSC(round_id=next_round(), model_hash=hash(theta_global),
                             participants_root=root, dp_params=(sigma,))
```

### IP-166 PCE+++++（六维预算 + 降级阶梯）
```python
class EmbodiedCognitiveBudget:
    def __init__(self, scene=100, intent=50, ros=3, mllm=8, fl=20, eps_dp=1.0):
        self.B = dict(scene=scene, intent=intent, ros=ros, mllm=mllm, fl=fl)
        self.used = {k: 0 for k in self.B}
        self.eps_dp = eps_dp

    def spend(self, k, n=1):
        self.used[k] += n
        return self.used[k] <= self.B[k]

    def fallback_ladder(self):
        if self.used['mllm'] > self.B['mllm']: return 'on_device_model'
        if self.used['fl']   > self.B['fl']:   return 'local_prior_only'
        if self.used['scene']> self.B['scene']:return 'general_prior'
        return 'normal'                                       # 只降性能，不破安全

def voi_cog_plus(meta, cost_cog, cost_exec, cost_mllm, cost_fl):
    return meta - cost_cog - cost_exec - cost_mllm - cost_fl
```

```python
def pst_inflate(Sigma, sigma):
    # DP 噪声只膨胀协方差 => 置信椭球只扩大 => 可采纳集只收窄
    Sigma_dp = Sigma + sigma ** 2 * np.eye(Sigma.shape[0])
```
