# 第 3 轮迭代（灵感循环 v4：「Isaac Sim」×「桌面操作」）——从「仿真裁判」到「桌面可逆状态机」

> 承接 v2（UIP-01′~15：RHPV-D + Gazebo 计分神谕 + 扰动-恢复数据工厂 + 实时/模块化）。本轮两个词看似是"换个更高级的仿真器 + 继续做桌面任务"，但核实官方资料后得到三个反直觉结论：
>
> 1. **「桌面操作」不是"小号的人形任务"，而是一个可枚举、可逆的对象状态机。** 32 个任务都发生在固定底座的桌面上：有限物体、支撑平面、重力稳定、对象持久。进度由少量对象谓词组成，人为干扰的主体是"把已完成谓词反向撤回"。因此我们不需要通用世界模型，而需要**带见证的桌面状态账本 + 撤回算子库 + 最小重做后缀规划**。
> 2. **API 的头部相机是立体对，且官方给出了完整标定。** `cam_left_high`/`cam_right_high` 是 640×480 的双目（基线 60.11 mm，fx≈271–273 px），不是两路无关视图。这给出一条被前几轮忽略的**公制深度**通道：在 0.5 m 桌面距离上，0.25 px 视差误差≈3.8 mm，1 px≈15.3 mm。几何谓词因此可以脱离外部 VLM，且天然对背景/光照变化更稳。
> 3. **Isaac Sim 的真正杠杆不是"更真的裁判"，而是"几何/接触实验室 + 桌面场景生成器 + 回放/步骤奖励 + policy 动作源"。** 同时必须修正 v2 的一处前提：Unitree 官方仿真栈是 Isaac Lab（`unitree_sim_isaaclab`），而 `unitree_ros` 明确只有 laikago/aliengo/a1/b1/b2/go1/go2 具备完整 Gazebo 控制器配置，G1 不在其中。把 Gazebo 当 G1 神谕的工程风险被高估了。
>
> 因此本轮不是"把 Gazebo 换成 Isaac"，而是把仿真降级为**受约束的几何/接触顾问**，把"桌面操作"升级为**可逆状态机**，并用立体度量记忆把它接到真实观测上。

**两条直接推论**：

- **D1（立体是免费的度量）**：API 已经把公制深度的原料送上门，只是没人用。只要离线标定一次（或用官方 calibration），就能把桌面重建为 2.5D 高度图；这比"用 RGB-VLM 猜完成度"更便宜、更稳、且不触"单模型"红线。
- **D2（桌面是可逆的）**：`human_*` 的撤回不是随机破坏，而是对某个已完成谓词施加逆操作。把它编译成**带前置/效果/可逆类的算子**，就能把"恢复"从"重跑整条任务"降为"重做最小后缀"。

## 1. v2 清单诊断与三处硬伤修正

### 1.1 必须先承认的三处接口硬伤

1. **`action_chunk_size` 不能在运行期自适应。** v2 的 UIP-13 说"按阶段选 k、全局最大 k、每次返回 ≤k 步"。但 README §3 要求每次返回 `(T_a, …)`，`T_a` 握手后固定。**验证的时间分辨率被量化成 `T_a`**：策略只能在块边界看到新观测。UIP-13 必须改写为"**块内安全设计 + 计算调度**"，不是"变长块"。
2. **`get_action` 返回整块，不是单步。** v2 旗舰伪代码 `return self.buf.pop(0)` 返回单步动作，形状不符。正确做法：内部维护 `T_a` 长度计划，一次返回整块；**块尾动作必须是"安全保持/回撤"形态**，使下一个块边界发现 `regressed` 时机器人仍在可恢复姿态。
3. **`control_space`、`obs_delta_indices`、`image_resize` 也在握手期固定。** 这再次确认 v2 封存 UIP-10 的判断：运行期不能切 joint/ee、不能按任务换观测键。**单模型、单接口、单块长**是硬约束，所有模块化必须收敛到共享骨干 + 条件化。

### 1.2 升级 / 修剪 / 封存

- **升级为旗舰**：UIP-01′ → **UIP-01‴ TRSM-V**（桌面可逆状态机验证）：验证从"单验证器打分"变为"对象谓词账本 + 反向迁移 + 最小后缀重做"。
- **升级**：UIP-11 GSO → **UIP-11″ TGO**（Isaac 桌面几何/接触顾问，取代 Gazebo 前提）；UIP-12 DRF → **UIP-12′ UOF**（撤回算子工厂）；UIP-13 ACS → **UIP-13′ ACS-2**（块内安全 + 计算调度，修正 T_a 误解）。
- **新增（命中两词）**：**UIP-16 TMM**（立体桌面度量记忆）、**UIP-17 RSM**（可逆状态机 + 最小重做后缀）、**UIP-18 TSF**（桌面场景模糊测试器，攻位置/干扰物/背景/未见物品四轴）、**UIP-19 SDC**（立体深度置信与降级）。
- **保留**：UIP-02′（计分步安全网）、UIP-05（语言→可供性）、UIP-08′（多端口隔离）、UIP-14 MSGR（技能图，节点与撤回算子对齐）、UIP-15 CSG（可信度护栏）。
- **封存**：UIP-04（学习式世界模型 MPC）、UIP-07′（视频回放代理）、UIP-10（运行期 joint/ee 切换）。

## 2. 两个灵感词：先直觉，再严谨定义

### 2.1 Isaac Sim：不是"更真的裁判"，而是"几何/接触实验室"

**直觉**：G1 桌面任务的成败大量取决于接触——插入、拧盖、拉拉链、折叠、叠碗。接触恰恰是 sim-to-real gap 最大的地方。把 Isaac 当"更高保真的成败裁判"，只会把 v2 的"仿真自欺"放大。Isaac 的稀缺价值在于它**知道精确几何、精确物体位姿、精确相机标定，并且能把任意动作源接进来回放**。因此它适合做四件真机很贵、纯数据又做不到的事：

1. **标定/验证感知**：用仿真真值检查"立体→深度→2.5D 高度图→谓词"这条链的误差；
2. **生成桌面布局**：程序化改变物体位置、干扰物、背景、未见物体，给状态估计器做**带标签的不变性测试**；
3. **检验恢复可行性**：把撤回算子与候选恢复计划送进物理仿真，判断"这个恢复是否物理可行"，而不是判断"像素像不像成功"；
4. **读官方步骤奖励**：`get_step_reward_value` + 回放，给计分步一个离线锚点。

**严谨定义（TGO，Tabletop Geometry Oracle）**：一个查询系统 `O = (S, A, C, R, U)`：

- `S`：桌面场景集合（支撑平面、物体位姿、材质、光照）；
- `A`：物体/机器人资产（G1 29-DoF 固定底座 + Dex1 + 桌面物体）；
- `C`：相机标定（内参、畸变、双目外参、腕部手眼）；
- `R`：步骤奖励函数 `R: rollout → {0,1}^n`（回放时读 `get_step_reward_value`）；
- `U`：撤回算子集合（见 2.2）。

可用查询：`label(s)` 返回对象谓词真值；`render(s, δ)` 在视觉扰动 δ 下重渲染；`replay(τ)` 用真实关节/物体状态回放；`feasible(u, s)` 返回撤回/恢复的物理可行性；`step_reward(τ)` 返回离散步骤奖励。**信任约束**：`O` 只能作为"结构/顺序/可行性"顾问，不能作为绝对成败裁判；其信任权重在真机锚点上按 `w_O = max(0, (ρ_struct − ρ_0)/(1 − ρ_0))` 估计，只有 `w_O > τ` 的结论才允许进入排序。

### 2.2 桌面操作：一个可枚举、可逆的对象状态机

**直觉**：桌面是一个"小闭世界"。物体数量有限、都在一个支撑平面上、受重力约束、不会凭空消失；任务进度是少数对象谓词的序列；人为干扰不是任意破坏，而是"把某个已完成谓词反向撤回"（开→合、插→拔、叠→拿、拉上→拉开、放好→挪走）。因此，**验证**可以是对谓词的核验，**恢复**可以是对逆操作的再执行，**规划**可以是在小状态空间里找最小重做后缀。

**定义 1（桌面状态）**：`s = (X, P, W, H)`，其中

- `X = {x_1..x_m}`：对象槽，`x_i = (class, pose, shape, support, graspable)`；
- `P`：谓词集合，如 `on(o, support)`、`in(o, c)`、`stacked(a, b)`、`open(c, θ)`、`inserted(p, port, d)`、`zipped(z, f)`、`folded(t, f)`、`sorted(o, bin)`、`upright(o)`、`clear(region)`；
- `W`：见证集合，`w = (predicate, t, value, confidence, source)`，`source ∈ {stereo, wrist, proprio, isaac, human}`；
- `H`：桌面 2.5D 高度图（见 2.3）。

**定义 2（正向计分链）**：任务规格给出有序计分步 `G = (g_1..g_n)` 与权重 `(w_1..w_n)`，`Σ w_i = 100`。每个 `g_i` 对应一个目标谓词（或谓词合取）。策略的合法推进是 `g_1 → g_2 → … → g_n`；乱序探索会丢前置分。

**定义 3（撤回算子）**：`u = (pre, eff, cls, witness)`，`u: S ⇀ S` 是部分映射：

- `pre`：可施加撤回的前置谓词（如 `done(g_i) ∧ ¬holding`）；
- `eff`：把某个已完成谓词改回未完成（可附带位置/姿态改变）；
- `cls ∈ {R0, R1, R2, R3}`：可逆类——`R0` 同抓取可逆（开/合盖、拉链）；`R1` 需重新定位/重抓（拿走、挪底座、拔插头）；`R2` 不可逆（倒出液体、剪断）；`R3` 形变/歧义（折叠、毛巾）；
- `witness`：检测该撤回所需的见证类型（立体几何、腕部近景、本体夹爪/关节、时间差分）。

**定义 4（最小重做后缀）**：给定当前真实状态 `s` 与目标链 `G`，求

```text
j* = min { j : s ⊨ pre(g_j) 且 从 g_j 正向执行可到达 G }
```

策略只重做 `g_{j*}..g_n`，而不是整条任务。若不存在这样的 `j`（例如物体被移出可达域），则先执行 `R1` 的再定位/再抓取，再重算 `j*`。

**定义 5（谓词置信）**：`c(p) = f(σ_Z, occlusion, seg_margin, temporal_consistency)`。只有 `c(p) ≥ τ_p` 的谓词才允许写入真实账本；低于阈值时降级到腕部/本体见证，或增加核验频率。**Isaac 的谓词只能作为咨询意见，永远不能写真实账本。**

### 2.3 立体桌面度量记忆（TMM）：把"桌面"变成可算的几何

**直觉**：头部双目是"免费的深度传感器"。桌面任务不需要毫米级全场景重建，只需要**支撑平面上的 2.5D 高度图 + 对象槽**：物体在不在、在哪个格、堆了几层、盖子开了多少。深度误差随距离平方增长，所以近距离（0.3–0.6 m）做粗谓词，细接触（插入深度、拉链齿合）交给腕部近景 + 本体感觉。

**严谨定义**：给定校正后的双目 `(I_L, I_R)`、内参 `K`、基线 `B`、视差 `d`，深度 `Z = f B / d`，误差传播

```text
σ_Z = Z² / (f B) · σ_d
```

把点云变换到桌面坐标系（由支撑平面拟合 + 重力方向确定），栅格化为高度图 `H(x, y)`；对 `H` 做连通域/聚类得到对象槽 `X`；用时间一致性维护 `P` 与 `W`。官方标定给出 `B = 60.11 mm`、`f ≈ 272 px`：0.5 m 处 `σ_d = 0.25 px` → `σ_Z ≈ 3.8 mm`；`σ_d = 1 px` → `σ_Z ≈ 15.3 mm`。这足以支撑 `on/in/stacked/open/clear` 等粗谓词，但不足以支撑 `inserted(d)` 的毫米级深度。

### 2.4 桌面场景模糊测试（TSF）：把"泛化轴"变成可证伪的不变性

**直觉**：v2 只知道 `unseen_object_*` 与 `human_*` 两个字段；位置/干扰物/背景三轴未文本化。Isaac 可以程序化生成这三轴的带标签布局，但**不要用它训策略**（会 sim-to-real 过拟合），而要用它**测状态估计器的不变性**：同一个真实轨迹，换背景/光照/相机位/干扰物，谓词预测应当不变。

**严谨定义（不变性分数）**：对状态估计器 `V` 与场景扰动分布 `D`，

```text
I(V) = 1 − E_{δ~D} [ TV( V(render(s, δ)), label(s) ) ]
```

只有当 `I(V) ≥ τ_I` 时，才允许把 `V` 用于在线验证；否则先修感知，不要放大自动化。

## 3. 证据驱动的假设

- **H1（立体 > RGB-VLM，且合规）**：在背景/光照变化与撤回干扰下，TMM 的几何谓词比 RGB-VLM 验证更稳；且因不依赖外部大模型，天然满足"单模型"合规。
- **H2（最小后缀 > 整任务重跑）**：检测到撤回后，只重做最小后缀比整任务重跑更省时间、更少超时、更少"二次撤回"暴露。但**检测是低检出率下的瓶颈**：`p_detect=0.5` 时两者差距很小；只有 `p_detect` 足够高，后缀重做的优势才完全释放。因此投资顺序是"先验证、后恢复粒度"。
- **H3（Isaac 的正确用法是感知/可行性，不是策略/成败）**：把 Isaac 用于标定、场景生成、恢复可行性，收益高于用它训策略或当成败裁判；后者只会放大接触 sim-to-real gap。
- **H4（细接触必须降级）**：立体深度在薄物体（网线）、透明/反光物体（药瓶）、遮挡（容器内）上会系统性失效；`inserted/zipped/folded` 必须由腕部近景 + 本体夹爪/关节见证兜底。
- **H5（步骤分最优是"保前置、搏末步"）**：撤回任务末步权重均值 40、总和 520；TRSM 的恢复预算应优先保护前置链，再在高权重末步上冒险。

## 5. 本轮最大风险

**一句话**：把 Isaac 当成"更真的成败裁判"、把立体深度当成"万能真值"，会在薄/透明/遮挡物体上系统性误判，让可逆状态机自信地重做错误步骤；必须把 Isaac 限定为几何/接触顾问、把立体深度限定为粗谓词，并为细接触谓词保留腕部+本体感觉的降级见证。

**→ 本轮最值得押注：UIP-16 TMM（立体桌面度量记忆）× UIP-17 RSM（可逆状态机 + 最小后缀）× UIP-12′ UOF（撤回算子库）组成的"桌面可逆恢复闭环"**——它把 v2 的"检测撤回"从语义猜测变成几何可证，把"恢复"从整任务重跑变成最小后缀，且完全落在选手 API 权限与离线算力之内。

## 1. 旗舰深潜：UIP-01‴ · TRSM-V（Tabletop Reversible State Machine Verifier）

### 1.1 机制

- **真实账本** `ℓ`：只追加来自真实观测的签名事实 `w=(predicate,t,value,confidence,source)`；`source ∈ {stereo,wrist,proprio}`。`ℓ` 是唯一能决定"是否完成/是否被撤回"的账本。
- **信念账本** `b`：策略内部对进度的估计；允许错，但不能写 `ℓ`。
- **顾问账本** `σ`：Isaac 回放/可行性给出的意见；只读、只提示，永远不能写 `ℓ`。
- **状态机**：每个计分步 `g_i` 对应目标谓词 `P_i`。在块边界执行 `verify(o_t, g_i)`，返回 `done / ongoing / regressed / fail / unknown`。
- **反向迁移**：若 `ℓ` 曾有 `done(g_i)`，现在观测到 `¬P_i`（且置信度足够），则判定 `regressed`，用 RSM 计算最小重做后缀 `j*`，只重做 `g_{j*}..g_n`。
- **块尾安全**：`get_action` 返回的块最后 `m` 步必须是"保持/回撤/松开"的安全动作，确保下一块能重新观测且不把错误放大。

### 1.2 与 v2 的差异

| 维度 | v2 RHPV-D | v3 TRSM-V |
|---|---|---|
| 验证对象 | 语义/几何混合，单一验证器 | **对象谓词账本**，三账本隔离 |
| 撤回处理 | `regressed → 重做该子目标` | **最小重做后缀**，不是整段/整任务 |
| 感知 | 未指定 | **立体 2.5D 度量记忆** + 腕部/本体降级 |
| 仿真角色 | Gazebo 计分神谕 | **Isaac 几何/接触顾问**，只读 |
| 接口 | 伪代码返回单步（错误） | 固定 `T_a` 整块 + 块尾安全 |

### 1.3 可行性、资源、落地

- **可行性**：高。所有机制都在 `get_action/reset/metadata` 内；不需要额外传感器；立体标定可离线完成。
- **资源**：公开 32 数据集（写谓词/弱标注）；1 张推理卡；Isaac 离线 CPU/GPU 回放。
- **落地**：① 逐任务把计分点写成 2–5 个谓词；② 用官方标定做立体→2.5D；③ 用 UOF 编译撤回算子；④ 在块边界接状态机；⑤ 用 TGO 做离线可行性/不变性测试；⑥ 真机锚点校准。
- **风险**：谓词误判导致"反复重做"→ 用 SDC 置信门限 + CSG 最大重做次数/延迟预算。

## 3. Isaac 三件套：UIP-11″ TGO / UIP-12′ UOF / UIP-18 TSF

### 3.1 UIP-11″ · TGO（Tabletop Geometry Oracle）

- **机制**：用 `unitree_sim_isaaclab` 的 G1 29-DoF 固定底座 + Dex1、官方 `uniclib_calibration.json`、桌面物体资产，建立**查询接口**：
  - `label(scene)` → 对象谓词真值（用于训练/验证 TMM）；
  - `render(scene, δ)` → 改光照/相机/背景后的图像（`--modify_light`/`--modify_camera`/`--generate_data`）；
  - `replay(τ)` → 用真实关节/物体状态回放（避免用仿真动力学替代真实）；
  - `feasible(u, s)` → 撤回/恢复的物理可行性；
  - `step_reward(τ)` → `get_step_reward_value` 的离散步骤奖励。
- **与 v2 差异**：不再把仿真当"步骤分/成败裁判"；只做几何、接触、可行性、场景覆盖。修正 v2 的 Gazebo 前提（官方 G1 仿真栈是 Isaac Lab）。
- **可行性**：中高。官方仓库已提供 G1/Dex1、相机、回放、生成数据、policy 动作源；不需要自己搭 Gazebo 控制器。
- **风险**：接触/摩擦/形变仍与真机有 gap；只用于结构/可行性，结论标注 **TGO 代理**。

### 3.2 UIP-12′ · UOF（Undo-Operator Factory）

- **机制**：把 `human_*` 文本编译成类型化算子：

```text
u := VERB(OBJECT, [SUPPORT], [PARAM])
VERB ∈ {open, close, insert, remove, stack, unstack, fold, unfold, zip, unzip, relocate, spill}
pre: 已完成的谓词 + 可达性 + 夹爪空闲
eff: 谓词取反（可附带 pose 改变）
cls: R0 / R1 / R2 / R3
witness: stereo | wrist | proprio | temporal_diff
```

- 用 Isaac 的 `feasible(u, s)` 检查算子在该几何下是否可执行；用脚本化机械手/第二臂复现撤回，生成 `(前态 → 撤回 → 恢复)` 三元组。
- **与 v2 DRF 差异**：v2 是"按任务造扰动数据"；UOF 是**先编译算子、再验证算子、再生成数据**，可跨任务复用（`relocate` 一个算子覆盖 T08/T11/T12/T24/T25/T26 等）。
- **风险**：文本→算子有歧义（"挪一下底座"可能挪机器人底座或架子）→ 用任务上下文 + 首帧场景消歧，并保留人工审核。

### 3.3 UIP-18 · TSF（Tabletop Scene Fuzzer）

- **机制**：程序化生成桌面布局，覆盖四轴：物体位置、干扰物、背景/光照、未见物品；每个场景有精确谓词标签。用途是**测 TMM 的不变性** `I(V)`，不是训策略。
- **与 v2 差异**：v2 只知道 `unseen_object_*` 与 `human_*`；TSF 把未文本化的三轴变成可测分布。
- **风险**：仿真视觉分布与真机不同 → 只用于相对不变性排序，阈值 `τ_I` 用真机小样本校准。

## 4. 立体桌面度量记忆 TMM + 深度置信 SDC

### 4.1 官方标定与深度精度（推导，非实验）

由 `Z = fB/d`，`σ_Z = Z²/(fB)·σ_d`，取 `B=60.107653 mm`、`f=272 px`：

| 距离 | σ_Z（σ_d=0.25 px） | σ_Z（σ_d=1 px） | 可支撑的谓词 |
|---:|---:|---:|---|
| 0.30 m | 1.38 mm | 5.50 mm | 全部粗谓词 + 部分细谓词 |
| 0.40 m | 2.45 mm | 9.79 mm | 粗谓词 + `open(θ)` |
| 0.50 m | 3.82 mm | 15.29 mm | `on/in/stacked/clear/sorted` |
| 0.60 m | 5.50 mm | 22.02 mm | 粗谓词（需时间平滑） |
| 0.80 m | 9.79 mm | 39.15 mm | 仅 `on/clear`（需 ROI 裁剪） |
| 1.00 m | 15.29 mm | 61.16 mm | 不可用于细谓词 |

**结论**：头部双目在 0.3–0.6 m 的桌面工作区足以支撑**粗几何谓词**；`inserted(d)`、`zipped(f)`、`folded(f)` 等细谓词必须用腕部近景（手眼平移 RMS≈2.3 mm）+ 本体夹爪/关节，或时间差分。

### 4.2 算法：TMM 更新

```python
def update_tabletop(obs, calib, prev_memory):
    left, right = obs["cam_left_high"], obs["cam_right_high"]
    L, R = rectify(left, right, calib)          # 官方双目外参
    disp = stereo_match(L, R)                   # 亚像素
    Z = calib.f * calib.B / disp                # 米
    conf = disp_confidence(disp, L, R)          # 纹理/遮挡/边界
    P = backproject(L, Z, calib)                # 相机系点云
    P = transform(P, calib.T_table_cam)         # 桌面系（平面拟合+重力）
    H = rasterize_height(P, conf)               # 2.5D 高度图
    X = cluster_slots(H, prev_memory.X)         # 对象槽，带时序关联
    W = predicate_witnesses(H, X, conf)         # on/in/stacked/open/...
    return Memory(X=X, P=W.predicates, W=W, H=H, conf=conf)
```

### 4.3 算法：TRSM 状态机（固定 `T_a`，块边界验证）

```python
class TRSM_Policy:
    def __init__(self, base_policy, verifier, rsm, T_a, conf_thr=0.7,
                 max_redo=2, latency_budget_ms=200):
        self.base, self.V, self.rsm = base_policy, verifier, rsm
        self.T_a, self.conf_thr = T_a, conf_thr
        self.max_redo, self.latency_budget_ms = max_redo, latency_budget_ms

    def reset(self):
        self.base.reset(); self.ledger = Ledger(); self.belief = Belief()
        self.mem = None; self.g = 0; self.redo = 0

    def get_action(self, obs):
        self.mem = update_tabletop(obs, self.calib, self.mem)
        if self._at_block_boundary(obs):
            st, conf = self.V(self.mem, self.task, self.g)
            if conf >= self.conf_thr:
                self._apply(st)                  # done/regressed/fail
        block = self.base.get_action(obs, self.T_a)   # 形状 (T_a, …)
        block[-1] = self._safe_terminal(block[-1])    # 块尾安全保持/回撤
        return block

    def _apply(self, st):
        if st == "done":
            self.ledger.append(self.g, True); self.g += 1; self.redo = 0
        elif st == "regressed" and self.redo < self.max_redo:
            j = self.rsm.minimal_suffix(self.ledger, self.mem, self.task)
            self.g = j; self.redo += 1               # 只重做 j..n
        elif st == "fail" and self.redo < self.max_redo:
            self.redo += 1                           # 重试同一步
        # unknown/低置信：不写 ledger，下一块加大核验频率
```

### 4.4 算法：最小重做后缀 RSM

```python
def minimal_suffix(ledger, mem, task):
    # 从后往前找最小的 j，使得当前真实状态满足 g_j 的前置，
    # 且从 g_j 正向执行能到达目标链。
    for j in range(len(task.steps) - 1, -1, -1):
        pre = task.steps[j].preconditions
        if mem.satisfies(pre) and task.reachable(mem, j):
            return j
    return 0   # 无法在桌面内恢复：先 relocate/re-grasp，再重算
```

> 关键不变量：`mem`（真实观测）才能写 `ledger`；Isaac 的 `σ` 只影响 `reachable()` 的可行性判断，不影响"是否完成"。

### 5.2 撤回-恢复机制检查（合成，非榜单证据）

脚本：`exp/tt_trsm_sim.py`；输出：`exp/tt_trsm_results.json`。设置：32 个官方计分向量，每任务每策略 1500 episode；`p_fail=0.05`；预算=3×名义步数；撤回目标=当前步（35% 概率均匀回退到已完成前缀）。**这是机制检查，不是 benchmark 证据**。

关键行（undo=每完成一步的撤回概率；detect=块边界检出概率）：

| 设置 | 策略 | 成功率 | 平均步骤分 | 执行步数 | 浪费步数 | 超时率 |
|---|---|---:|---:|---:|---:|---:|
| undo=0.20, detect=0.80 | 开环 | 52.7% | 77.40 | 3.09 | 0.15 | 0.0% |
| | 整任务重跑 | 82.9% | 92.23 | 4.36 | 0.65 | 4.5% |
| | **最小后缀** | **86.2%** | **94.23** | **3.81** | **0.19** | **0.5%** |
| undo=0.30, detect=1.00 | 开环 | 36.3% | 66.41 | 3.09 | 0.15 | 0.0% |
| | 整任务重跑 | 80.3% | 88.11 | 5.67 | 1.16 | 19.7% |
| | **最小后缀** | **96.1%** | **97.86** | **4.68** | **0.23** | **3.9%** |
| undo=0.30, detect=0.50 | 开环 | 36.6% | 66.64 | 3.09 | 0.15 | 0.0% |
| | 整任务重跑 | 55.6% | 78.64 | 4.28 | 0.55 | 3.9% |
| | 最小后缀 | 57.3% | 79.97 | 3.75 | 0.19 | 0.4% |

**三条读数**：

1. **检出率是低检出下的瓶颈**：`detect=0.5` 时，最小后缀只比整任务重跑高 1.3 个百分点（79.97 vs 78.64）；`detect=1.0` 时差距拉到 9.8 个百分点（97.86 vs 88.11）。所以投资顺序必须是**先 TMM/SDC 把检出做稳，再谈恢复粒度**。
2. **最小后缀把"浪费步数"压到接近常数**（0.19–0.23），而整任务重跑随 undo 升高到 1.16；在 180 s 硬时限下，这直接转化为超时率（19.7% → 3.9%）。
3. **开环在 undo=0.3 时只剩 36% 成功率/66 分**——这解释了为什么"步骤分安全网"必须与"撤回检测"绑定，而不是各自为政。

> 所有数字均为合成机制检查；真机结论提测前一律标注 **TGO/TMM 代理**，不得当榜单结论。

## 6. 合规与风险（本轮重点）

- **单模型合规**：TMM/RSM/UOF 都是离线或规则/几何模块，不进在线提交；在线只用共享骨干 + 内部谓词头/规则，不调用外部 VLM。
- **Isaac 只离线**：不把仿真放进 `get_action` 的在线路径；不用 Isaac 当成败裁判；所有仿真结论标注代理。
- **接口红线**：固定 `T_a`、整块返回、`(T_a,…)` 形状、token 两处、N 端口隔离、每端口 `reset`/历史隔离。
- **立体标定漂移**：头部双目基线/外参可能随碰撞/温漂变化；用支撑平面/已知物体做在线自检，漂移超阈值则降级到腕部+本体。
- **薄/透明/遮挡**：网线、药瓶、容器内物体是立体深度的系统性盲区；SDC 必须显式降级，不能"几何自信地犯错"。
- **手册仍未取到**：位置/干扰物/背景三轴与评测轮次/时限/控制频率仍待飞书手册公开；TSF 的轴定义先用工作假设。

## 7. 资源与时间线（粗排）

- **第 1–2 周**：用官方标定搭 TMM（立体校正→深度→2.5D），在 5 个代表任务（T26 插网线、T27 叠碗、T19 拉链、T16 叠毛巾、T14 拧盖）上写谓词与置信。
- **第 3–4 周**：UOF 编译 13 个 undo 任务；Isaac `feasible` 检查 R1 算子；生成小规模恢复数据。
- **第 5–6 周**：RSM 最小后缀 + TRSM 状态机接入；块尾安全动作设计；E304 复现。
- **第 7–8 周**：TSF 四轴不变性测试；SDC 降级策略；与 v2 基线做 E307。
- **第 9 周起**：真机锚点校准 TMM/TGO；用真实步骤分迭代 `j*` 与置信阈值。

## 8. 本轮最大风险 & 押注

**一句话**：把 Isaac 当"更真的成败裁判"、把立体深度当"万能真值"，会在薄/透明/遮挡物体上系统性误判，让可逆状态机自信地重做错误步骤；必须把 Isaac 限定为几何/接触顾问、把立体深度限定为粗谓词，并为细接触谓词保留腕部+本体感觉的降级见证。

**→ 押注：UIP-16 TMM × UIP-17 RSM × UIP-12′ UOF 的"桌面可逆恢复闭环"**——用官方双目把"撤回"变成几何可证，用撤回算子把"恢复"变成最小后缀，用 Isaac 只做离线可行性与不变性校准。它对准的是规则里白纸黑字、公开数据完全空白、且选手权限内可闭环的最大得分缺口。
