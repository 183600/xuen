# 第 1 轮（新灵感循环第 1 轮；本轮灵感：「隐私保护」×「社会规范理解」）

> **基线**：上一循环产出 MetricVoiceGauge-NCD-HUTDH-v20 + IP-420–424（感知层：PCA/CTS/CFC/HPC/CFCtrl）。v20 及更早的 v19（DCM/OGCC/CCV/DRS/OGC）、v17（CLP/S2C/HCG/PSV/APS/AMC）全部保留。
> 本轮纪律：**隐私是信息流的硬规范，礼仪是行为流的软规范；规范可以改变机会，不能改变安全**。本轮只做一件事：给 v20 的联邦感知证书加上两层治理——**可披露性（privacy）**与**可共处性（social norm）**，使证书不仅“算得对”，还“说得清、处得来”。

## 0. 直觉与动机

### 灵感 1（隐私保护 → 证书的“可披露性”，而非数据的隐藏）

**直觉。** v20 的 PCA/CFC/HPC 把点云、几何特征、投票、Merkle 路径在机器人之间共享；这条管道同时是一条隐私管道：点云泄露人脸、住宅布局、他人身体；几何特征可反演出占据栅格；投票可被差分攻击还原出“谁在哪里”。经典联邦学习用安全聚合 + 差分隐私解决，但碰撞证书要求**精确**与**可审计**：给碰撞几何加噪可能让安全域缩水（活性损失），也可能让它膨胀（安全灾难）。关键反直觉点：**隐私与安全不必是零和，只要把信息流分层**——安全攸关的断言用**零知识/安全多方计算**做“只证明谓词、不泄露证据”的精确认证；差分隐私只用于**非安全攸关的社会推断**。再加一条：若某方需要更强的隐私，就引入**只收缩的隐私裕度** `δ_priv`，隐私只会花掉活性，永远不会花掉安全。

**严谨定义（直觉版）。** 证书不再是一张“θ 安全”的明文，而是一个**承诺 + 零知识证明 + 披露策略**：`Cert = (Commit(S), π, D_policy)`，其中 `π` 证明“存在局部几何与 v20 CCV 记录，使得查询域 `Q` 在裕度 `m` 下无碰撞”，验证者只学到这句话为真，学不到 `S`。重复查询会泄露边界，因此再加**查询披露预算**与**最小查询粒度**。

### 灵感 2（社会规范理解 → 证书的“可共处性”，而非几何上的不碰撞）

**直觉。** 零碰撞的轨迹仍可能 socially unacceptable：贴人太近、走错走廊一侧、插队、堵门、不礼让、盯着人看。v20 把所有非碰撞空间视为等价的自由空间（除 margin），这在社会场景里是“几何正确、社会错误”。规范的难点在于它是**上下文相关、置信不定、彼此冲突**的：窄走廊里“保持距离”与“靠右让行”可能冲突；不同文化、不同关系的人对个人空间半径的期望不同。关键反直觉点：**规范不能用来扩张几何安全集**——“我假设人会让我”正是“社会预期但物理危险”的事故来源。规范只做两件事：(a) 在已认证安全集内**重排计划**（更礼貌、更可读）；(b) 在有**可证逃逸管**时授权**条件性接近 (contingent approach)**——规范只决定“要不要试”，安全由逃逸保证，而不由规范正确性保证。

**严谨定义（直觉版）。** `Θ_n^soc = Θ_n^col ∪ Θ_n^cont`。`Θ_n^cont` 中的每个 θ 都必须附带一条**逃逸策略** `π_esc`：在最坏人类行为集合 `D`（速度/加速度/反应时延的硬物理界）下，于 `T_esc` 内回到 `Θ_n^col` 且全程无碰撞。规范置信度 `Conf(ν)` 只控制是否允许进入 `Θ_n^cont`；规范错了，最多是“白试一次再退回”，不会撞。

### 两条灵感如何统一

统一为 **隐私-规范双治理证书格 (Privacy–Norm Governed Certificate Lattice, PN-GCL)**：v20 回答“给定联邦感知，θ 是否零碰撞”，v21 回答“这个结论**能否被披露**（隐私）以及**能否被共处**（规范）”。两者其实是同一种东西的两面：**隐私是信息流的硬规范，礼仪是行为流的软规范**。共享状态 `ζ_pn = (commitments, zk_proofs, dp_budget, norm_posterior, escape_tubes, assumption_set, ledger, mode_pn)`。统一接口：

`PN-GCL(θ) = v20_CCV(θ) ∧ ZKCC(θ) ∧ NCL(θ)`，

其中 `NCL` 不扩张 v20 的安全集，只重排或附加带逃逸的条件域。任一组件失效 ⇒ 回退 v20（更保守、更少社交），`UnsafeExec_v21 ⊆ UnsafeExec_v20`。

## 2. 设计原则（在 P31–P33 基础上新增 P34–P37）

**P34 隐私-安全分层律（Privacy–Safety Stratification）**
安全攸关的几何量（碰撞域、CCV 采样、margin）**禁止**加双侧噪声；其隐私由 ZK/MPC 的“只证明谓词”保证。DP 仅允许作用于非安全攸关的社会统计量（规范后验、交互偏好）。若需要额外隐私裕度，只能**单向收缩**：`Θ_priv = Θ_col ⊖ δ_priv(ε)`，故 `Θ_priv ⊆ Θ_col`。**隐私可以花活性，不能花安全。**

**P35 规范不扩张律（Norm Non-Expansion）**
规范永远不扩大最坏情形几何安全集。规范只允许：(a) 在 `Θ_col` 内重排计划；(b) 在 `Θ_cont` 中授权条件性接近，且每个 θ ∈ `Θ_cont` 必须附一条经独立验证的逃逸策略 `π_esc`，在最坏人类行为 `D` 下可于 `T_esc` 内返回 `Θ_col` 且全程无碰撞。规范置信度只控制**是否进入** `Θ_cont`，不参与安全证明。**规范错误只能损失机会，不能制造碰撞。**

**P36 假设显式律（Explicit Assumption）**
每张证书都必须携带假设集 `A = (A_geom, A_priv, A_norm, A_time)`：传感器标定与 `D` 的物理界、披露策略与隐私预算、规范先验与置信校准、时间戳与 TTL。没有显式 `A` 的证书不得执行。任何假设被违反，依赖它的证书立即失效，而不是被静默信任。

**P37 治理可回滚律（Governed Rollback）**
隐私预算消耗、规范更新、假设失效都是哈希链台账上的一笔事务 `(pre_hash, post_hash, ΔA, Δε, Δη, source, τ)`。失效只沿依赖 DAG 传播到依赖该 `source` 的证书，其余证书保留；无法判定的情形整体回退 v20。**治理是定向回滚，不是全局重置。**

## 3. 与基线的接口（如何退化）

- SPA/ZKCC 失效（证明系统不可用/超时）⇒ 退回 v20 联邦路径（隐私性下降，但安全不变）；若披露策略不允许明文，则拒绝披露并只本地执行；
- 隐私预算耗尽 ⇒ 关闭 DP 社会推断与域外查询，退到 `EXACT_PRIVATE` 或 v20；安全不变，社交能力下降；
- NCL 失效（规范计算不可用）⇒ 只用 v20 纯几何证书；更不礼貌，但安全；
- SNE 置信度不足或 OOD ⇒ 规范门关闭，`Θ_cont = ∅`，退到最坏情形个人空间；
- 逃逸验证失败 ⇒ 禁止条件性接近，等价 v20；
- 全失效 ⇒ 完全回退 v20；
- **安全继承**：ZKCC 只证明不改变域，隐私裕度只收缩，NCL 不扩张（条件域由逃逸保证最坏情形安全），任一失效都只会更保守，`UnsafeExec_v21 ⊆ UnsafeExec_v20` 由引理 164 保证。

## 4. 预期贡献

1. **可披露的碰撞证书**：首次把联邦碰撞证书改写为“承诺 + 零知识证明 + 披露策略”，在可审计的同时不泄露原始点云/几何特征，给出“隐私不加噪于安全”的分层设计；
2. **隐私-安全分层定理**：证明安全攸关量的精确证明与非安全攸关量的 DP 可以共存，隐私裕度只收缩，给出 `ε → δ_priv` 校准与隐私预算组合/降级规则；
3. **规范不扩张原则**：发现“规范可以改变机会、不能改变安全”的可操作形式化，用条件性接近 + 逃逸管把社会规范与最坏情形安全解耦；
4. **规范推断与校准**：给出上下文条件规范后验、保形置信度、跨文化 OOD 检测与规范冲突解析，使“懂礼貌”成为可度量、可回退的能力；
5. **双治理证书格**：隐私（信息流硬规范）与礼仪（行为流软规范）统一为假设治理台账，实现“可披露、可共处、可回滚”的证书闭环。

## 5. 本轮最大风险

**一句话**：最大风险是**规范套利与预算洗白（norm arbitrage / budget laundering）**——掌握治理入口的一方可以策略性地报告规范置信度与隐私预算，把“社会可接受”变成可操纵的许可、把“已消耗的隐私”洗成合规，使证书在形式上通过台账审计，实质却把风险系统性地转嫁给人类或弱势交互者；密码学保证的是证明的可靠性，不是假设的正当性。

# IP-425 Secure Perception Aggregator (SPA)
class SecurePerceptionAggregator:
    def __init__(self, ccv, zk, n_robots):
        self.ccv = ccv                      # 复用 v20 CCV
        self.zk = zk                        # 承诺 + ZK 后端
        self.N = n_robots
        self.mask = PairwiseMaskProtocol(n_robots)  # 防合谋的成对掩码

    def commit_local(self, robot_id, points, theta_dom, margin, now):
        """本地只提交承诺与证明，不提交点云。"""
        verdicts = self.ccv.verify(points, theta_dom, margin)
        nonce = fresh_nonce()
        C = commit((conservative_hull(points), verdicts), nonce)
        pi = self.zk.prove(
            relation=REL_LOCAL,
            public=(robot_id, C, theta_dom, margin, now),
            witness=(points, verdicts, nonce),
        )
        return LocalContribution(robot_id, C, pi, theta_dom, margin, now)

    def secure_aggregate(self, contribs, theta_dom):
        """验证每个局部证明，再做安全聚合；聚合器只学到聚合值。"""
        for c in contribs:
            if not self.zk.verify(
                REL_LOCAL, (c.robot_id, c.C, c.theta_dom, c.margin, c.ts), c.pi
            ):
                return None, "LOCAL_PROOF_INVALID"
        if len({c.robot_id for c in contribs}) < self.N - self.N // 3:
            return None, "NOT_ENOUGH_VALID_CONTRIB"

        masked = self.mask.mask([c.features() for c in contribs])
        agg_C, agg_pi = self.zk.prove(
            relation=REL_AGG,
            public=(tuple(c.C for c in contribs), theta_dom),
            witness=masked,
        )
        return SecureColDom(commit=agg_C, proof=agg_pi, n_valid=len(contribs)), "OK"

# IP-426 Zero-Knowledge Collision Certificate (ZKCC)
class ZKCollisionCertificate:
    def __init__(self, zk, g_q=0.02, eps_q=64.0):
        self.zk = zk
        self.g_q = g_q          # 最小查询粒度，防止逐点二分安全集边界
        self.eps_q = eps_q      # 查询披露预算
        self.q_spent = 0.0

    def prove_domain(self, local_cert, query_domain, margin):
        """对一整个查询域做证明，而不是逐点查询。"""
        if query_domain.min_width() < self.g_q:
            return None, "QUERY_TOO_FINE"
        if not self.charge_query(query_domain):
            return None, "QUERY_BUDGET_EXHAUSTED"

        # 保守量化：距离一律向下取整，保证电路结论不弱于真实结论
        q_witness = conservative_quantize(local_cert.witness, self.g_q)
        pi = self.zk.prove(
            relation=REL_DOMAIN_SAFE,
            public=(local_cert.C, query_domain, margin),
            witness=q_witness,
        )
        return pi, "OK"

    def verify(self, C, query_domain, margin, pi):
        return self.zk.verify(REL_DOMAIN_SAFE, (C, query_domain, margin), pi)

    def charge_query(self, query_domain):
        # 披露成本按“可分辨单元数”计，限制边界信息泄露
        cost = query_domain.volume() / (self.g_q ** query_domain.dim)
        if self.q_spent + cost > self.eps_q:
            return False
        self.q_spent += cost
        return True
```

# IP-427 Normative Constraint Layer (NCL)
class NormativeConstraintLayer:
    def __init__(self, v20_cert, escape_verifier, conf_gate=0.8, eta_norm=0.2):
        self.cert = v20_cert                  # v20 认证域 Θ_n^col
        self.escape = escape_verifier         # 独立逃逸验证器（可 ZK）
        self.conf_gate = conf_gate
        self.eta_norm = eta_norm

    def reorder(self, plans, context, norm_posterior, lam=0.5):
        """只在 v20 认证域内重排，不扩张安全集。"""
        feasible = [p for p in plans if self.cert.contains(p.theta)]
        if not feasible:
            return None, "NO_CERTIFIED_PLAN"

        def score(p):
            return p.task_cost + lam * expected_norm_cost(
                p.trajectory, context, norm_posterior
            )

        return min(feasible, key=score), "OK"

    def authorize_contingent(self, plan, context, norm_posterior):
        """条件性接近：规范只决定是否尝试，安全由逃逸管保证。"""
        conf = credible_confidence(norm_posterior, plan.norm)
        if conf < self.conf_gate:
            return None, "NORM_GATE_CLOSED"

        esc = plan.escape_tube
        if esc is None or not self.escape.verify(
            relation=REL_ESC,
            public=(plan.entry_state, esc.T_esc, HUMAN_BOUND),
            proof=esc.proof,
        ):
            return None, "ESCAPE_UNVERIFIED"

        # 注意：这里不检查“规范是否会成真”，只检查逃逸是否最坏情形成立
        return ContingentAuthorization(plan, esc, conf), "OK"

    def resolve_conflict(self, norms):
        """硬规范（隐私/安全/法律）取交集，只会收缩；软规范按严重度+置信度。"""
        hard = [n for n in norms if n.tier == "HARD"]
        if hard:
            return meet(hard)
        return max(norms, key=lambda n: (n.severity, n.confidence))
```

# IP-428 Social Norm Estimator (SNE)
class SocialNormEstimator:
    def __init__(self, prior, dp_eps=None, calib_set=None):
        self.prior = prior
        self.dp_eps = dp_eps        # 仅作用于社会统计量，绝不作用于几何
        self.calib_set = calib_set

    def infer(self, demonstrations, context):
        stats = sufficient_stats(demonstrations)
        if self.dp_eps is not None:
            stats = dp_noise(stats, self.dp_eps)   # 安全不依赖规范，故可加噪
        return bayes_update(self.prior, stats, context)

    def calibrate(self, posterior):
        """保形预测：返回 1-alpha 覆盖的规范集 C_alpha。"""
        return conformal_set(posterior, self.calib_set)

    def ood_score(self, context):
        """跨文化/跨场景漂移检测；超阈值则关闭规范门。"""
        return mahalanobis(context, self.context_mean, self.context_cov)

    def gated_confidence(self, posterior, norm, ood_threshold=3.0, context=None):
        if context is not None and self.ood_score(context) > ood_threshold:
            return 0.0
        return credible_confidence(posterior, norm)

# IP-429 Assumption Governance Ledger (AGL)
class AssumptionGovernanceLedger:
    def __init__(self, eps_max=2.0):
        self.chain = []
        self.eps_max = eps_max
        self.deps = DependencyDAG()

    def append(self, cert, delta_assumption):
        tx = Tx(
            pre_hash=self.head(),
            cert_hash=hash(cert),
            delta=delta_assumption,
            tau=now(),
        )
        self.chain.append(tx)
        self.deps.add(cert.id, delta_assumption.sources)
        return tx

    def invalidate(self, violated_assumption):
        """只失效依赖该假设的证书，其余保留。"""
        ids = self.deps.descendants(violated_assumption)
        for cid in ids:
            mark_invalid(cid)
        return ids

    def check_privacy_budget(self, eps_new):
        spent = sum(tx.delta.eps for tx in self.chain)
        if spent + eps_new > self.eps_max:
            return "BUDGET_EXHAUSTED"
        return "OK"

    def head(self):
        return self.chain[-1].post_hash if self.chain else GENESIS_HASH

## 3. 推导

**引理 157（ZKCC 可靠性）** 若 `Verify(C, Q, m, π_domain)=1`，且承诺满足绑定性、证明系统满足可靠性、量化采用保守向下舍入，则 `∀θ∈Q`，θ 在 v20 CCV 下以 margin ≥ m 无碰撞，失败概率 ≤ `negl(λ)`。证明：可靠性保证存在见证使关系成立；绑定性保证见证对应唯一承诺；保守量化只会减小距离、不会把不安全判为安全。∎

**引理 158（隐私-安全分层）** SPA/ZKCC 不改变被证明的谓词，只隐藏见证；DP 仅作用于 `R_norm` 的充分统计量。若使用隐私裕度，则 `Θ_priv = Θ_col ⊖ δ_priv(ε) ⊆ Θ_col`。由引理 160，`Θ_cont` 的安全性与规范后验无关，故 DP 噪声不能增加碰撞风险。∎ 推论：**隐私只会降低活性，不会降低安全。**

**引理 159（查询披露有界）** ZK 隐藏见证但不隐藏命题；自适应逐点查询可逼近 `∂Θ_col`。ZKCC 要求 `min_width(Q) ≥ g_q` 并以 `ε_q` 限制可分辨单元数，故边界泄露被限制在 `O(vol(Θ_col)/g_q^d)` 个单元内；预算耗尽后拒绝新查询。∎

**引理 160（规范不扩张与逃逸安全）** 对任意 `θ ∈ Θ_n^cont`，存在 `π_esc` 使得 `∀d∈D`，闭环在 `T_esc` 内回到 `Θ_n^col` 且全程无碰撞。故条件性接近在最坏人类行为下安全，与规范 `ν` 是否正确无关。规范仅门控“是否进入”，故 `Θ_n^soc ⊆ Θ_true^wc`，其中 `Θ_true^wc` 为真实最坏情形安全集。∎

**引理 161（规范门安全）** 若 `Conf(ν) < η_norm` 或 OOD 分数超阈值，则 `Θ_n^cont = ∅`，v21 在 `Θ_n^col` 上退化为 v20。错误规范只能导致机会损失，不能导致碰撞。∎

**引理 162（假设相对可靠性）** 证书仅在假设集 `A` 成立时有效。若 `A_i` 被违反，AGL 只将 `descendants(A_i)` 标记为失效，非依赖证书保持有效；被失效的证书回退 v20 或拒绝执行。∎

**引理 163（隐私预算组合与降级）** 顺序组合满足 `ε_total = Σ ε_i`；`δ_priv(ε_total)` 单调不减。当 `ε_total > ε_max` 时关闭 DP 社会推断与域外查询，模式退到 `EXACT_PRIVATE` 或 `V20_FALLBACK`。活性单调下降，安全不变。∎

**引理 164（v21 整体安全继承）** 在同一几何快照与同一 `D` 下，`Exec_v21^cert ⊆ Exec_v20`；`Exec_v21^cont` 由引理 160 在最坏情形下安全；任一组件失效回退 v20。故 `UnsafeExec_v21 ⊆ UnsafeExec_v20`。∎

## 7. 已知风险与失效模式

1. **证明的是“错误几何”**：ZKCC 的可靠性上界是“承诺的几何为真”。若传感器被欺骗、标定被污染或本地 CCV 实现有漏洞，系统会以密码学强度为错误几何背书（garbage-in, proof-out）。缓解：多源交叉验证、标定指纹、独立审计的 CCV 实现、承诺绑定传感器身份。
2. **查询隐私的边界泄露**：ZK 隐藏见证但不隐藏命题；自适应查询仍可逼近安全集边界。缓解：域级证明、最小查询粒度、查询披露预算、差分隐私化的边界响应（仅收缩方向）。
3. **可信设置与承诺绑定**：zk-SNARK 的可信设置若被污染，可靠性失效。缓解：透明设置（zk-STARK）、多方仪式、可升级承诺。
4. **规范推断的文化偏差与公平性**：规范先验可能编码歧视性偏好，或少样本推断把“多数人习惯”强加给少数群体。缓解：显式文化先验、按群体校准、可申诉的规范覆盖、硬规范优先。
5. **逃逸管过度保守或为空**：在狭窄/高动态场景，`Θ_n^cont` 可能为空，导致规范能力退化为纯重排。缓解：在线可达性、分级 T_esc、与 v20 的 APS 时效对齐。
6. **DP 噪声降低规范质量**：隐私预算过小会使规范后验不可用，表现为“过度礼貌”或“社交僵化”。缓解：DP 只作用于充分统计量、预算自适应、在安全不敏感处才加噪。
7. **规范套利与预算洗白**：治理入口可被策略性操纵，使证书形式合规而实质转嫁风险。缓解：多方治理、假设来源签名、预算独立审计、规范置信度的外部校准。
8. **人类行为超出 D**：逃逸保证依赖 `D` 的物理界；超界行为（奔跑、突然横穿）会使最坏情形保证失效。缓解：在线行为异常检测、扩大 D、降速、增大 T_esc、必要时安全停。
9. **证明/验证延迟**：域级证明在复杂几何上可能超过离线预算。缓解：递归证明、增量证明、按几何哈希缓存、预认证常用查询域。
10. **台账膨胀与回滚风暴**：依赖 DAG 过大时定向失效成本上升。缓解：分层台账、检查点、按源聚合失效。

## 8. 本轮最大风险

**一句话**：ZKCC 的密码学可靠性只保证“承诺的几何为真”，一旦本地传感器被欺骗或标定被系统性污染，系统会以密码学强度为**错误几何**背书；而隐私设计（隐藏见证、限制外部审计）恰好削弱了发现这种错误的能力，形成“证明越强、越难质疑”的 **garbage-in, proof-out** 风险。
