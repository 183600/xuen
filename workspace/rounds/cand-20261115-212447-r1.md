# 第 10 轮（新灵感循环第 2 轮；本轮灵感：「同步定位与建图」×「电池管理」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：用「建图的回溯不确定性」治理 v9 的**证书信任域滞后债**，用「电池的状态估计与健康管理」治理 v9 的**静态预算债与反应式退化债**。两个灵感都必须经 v9 的中立元契约退化链接入：任一新估计器失效 ⇒ 注入中立元、严格退回 v9（再退回 v8），不改变安全语义、只改变算力分配与退化时机。

## 0. 直觉与动机

**灵感 1（同步定位与建图 → 证书误差地图与回环重审计）**
直觉：SLAM 最反直觉的一点不是"边跑边建图"，而是**过去的不确定性可以被未来的观测回溯修正**——回环闭合让后端重优化整条轨迹。v9 的块证书恰恰是"只向前、不回溯"：证书签发即冻结，前向模型误差界 β 是**全局标量**。于是它同时犯两个错：在熟悉区域 β 过保守（本可长块却退化为短块），在陌生区域 β 过乐观（正是 v9 风险句所指的"最需要安全时证书最不可靠"）。核心创新有三件套：**证书误差地图（CEM）**把 β 从标量升级为带后验方差的空间场 β_eff(x)=μ_β(x)+κσ_β(x)——未见区域先验方差大，进入前就自动缩块，不再等 Δ_dom 的 20 帧滑窗；**证书因子图（CFG）与回环重审计（LCA）**把每次回环/重定位当作一条约束边，残差超阈即回溯作废受影响的已签发证书并抬升该区域 β；**位姿协方差门控**用 tr(Σ_pose)/熵作为前向模型误差的**保守代理**，在域偏移被检测到之前就收缩 K_eff。一句话：**把"证书"从一次性凭证变成可被回环重优化的地图节点**。

**灵感 2（电池管理 → 算力预算的状态估计、健康管理与预测性退化）**
直觉：BMS 的精髓不是"测电压"，而是**用可观测代理量估计不可直接测的状态**（SoC/SoH/RUL）并做**预测性维护**。v9 的预算管理等价于"没有电量计、只在过放后断电"：WCET 是静态上界、EDF 按最坏情况预留、退化是超时后的反应式 strike。核心创新是**算力电池管理器（CBM）**：用库仑计数式递推 + 观测器校正估计**预算荷电状态 B(t)**；用超时历史、时延漂移、热状态估计每个模块的**健康度 h_m** 与**剩余寿命 R̂_m**；在 R̂_m 跌破安全视界时**预测性注入中立元 v_m^⊥**（先降级、后失效，而非先失效、后补救）；块证书扩展为**能量可行证书**，要求块内消耗 + 中止机动能量 ≤ 可用预算 − 安全储备；再用**均衡**（类比电芯均衡）与**热降额**把预算按健康度分配，避免单模块被"过放"。一句话：**把算力从"每周期抢最坏情况"变成"有电量计、有健康档案、有安全储备的可管理资源"**。

**灵感交叉（两者共同的软肋）**：CEM 的后验与 CBM 的健康观测器都是**自估不确定性的估计器**。若它们的协方差/置信区间被系统性低估，两个新安全门会同时"自信地"失效。故本轮必须并行引入**元不确定性审计**：用经验覆盖率反向校准 κ 与 h 的置信带，宁可保守也不允许安全边际静默收缩。

## 1. 研究问题（轮次升级版）

- **Q1（证书的可回溯性）**：如何把块证书组织成可被回环闭合重优化的因子图，使"证书签发后才发现位姿/障碍估计错误"的情形也能 fail-safe？重审计窗口 H_lc 与误报率如何权衡？
- **Q2（协方差的早期门控）**：位姿边际协方差（或其熵）在什么 Lipschitz/有界偏差假设下是前向模型误差的保守上界代理？它相对 Δ_dom 滑窗能提前多少，且不引入过多保守性？
- **Q3（算力作为可估资源）**：如何用库仑计数 + 观测器校正估计预算 SoC，并用健康度/RUL 把"超时后降级"前移为"失效前降级"，同时保证预测性退化仍落在 v8 退化格点内？
- **Q4（元不确定性）**：如何用覆盖率审计保证 CEM 与 CBM 的置信带永不被静默低估，从而两道新安全门不会同时 fail-open？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P15）

**P13 回环重审计律（Loop-Closure Re-Audit, LCA）**
证书是**可修正假设**而非终局事实。回环/重定位产生残差 r_lc 超阈 τ_lc 时，必须回溯作废空间支撑重叠且年龄 ≤ H_lc 的已签发证书，抬升受影响区域的 β_eff；若被作废证书对应仍在执行的块，立即切换到最近中止点安全停驻。禁止"证书一旦签发即不可质疑"。

**P14 预算-能量可行性律（Budget-Energy Feasibility, CBM）**
块被接受的前提从"指标可行"升级为"指标可行 ∧ 能量可行"：E_chunk + E_abort ≤ B_avail − B_reserve。预算状态由观测器估计而非静态假设；能量储备 B_reserve 永久不可透支，专门留给安全停驻。

**P15 预测性退化律（Prognostic Degradation, CBM）**
退化时机从"超时后"前移到"健康度/RUL 预测将超时前"：当 R̂_m < R_safe 时提前注入 v_m^⊥。预测性退化在行为上严格等于一次超时退化（同一中立元、同一端口语义，仅日志标签不同），因此安全性由 v9 引理 83 传递；误报只损失算力、不损失安全。

## 3. 与基线的接口（如何退化）

- CEM 失效 ⇒ β_eff(x) 退回 v9 全局标量 β₀，K_eff 公式退回定义 539；
- LCA/CFG 失效 ⇒ 关闭回环重审计，证书恢复为"签发即冻结"（v9 语义）；
- 协方差门控失效 ⇒ g_Σ ≡ 0，K_eff 仅由 Δ_dom/risk_SLAM 驱动（v9 语义）；
- CBM 失效 ⇒ B(t) ≡ B_max（静态满电），退回 v9 的 EDF + 静态 WCET；
- 预测性退化失效 ⇒ 退回 v9 反应式超时 strike（仍按定义 535 注入 v^⊥）；
- 上述全部失效 ⇒ 严格退回 v9；v9 的 AC/MW/ID 再失效 ⇒ 按 v9 定义 536 逐级退回 v8/v7/v6。

## 4. 预期贡献

1. **证书误差地图**：把前向模型误差界从全局标量升级为回环可修正的空间后验场，同时消除"熟悉区过保守 / 陌生区过乐观"；
2. **回环重审计 + 协方差门控**：为 v9 最致命的"检测滞后于分布跳变"提供几何上更早、可回溯的 fail-safe 机制；
3. **算力电池管理**：预算 SoC/SoH/RUL + 能量可行证书 + 预测性退化 + 均衡/热降额，把退化从"事后"变"事前"，并把安全储备显式化；
4. **元不确定性审计**：为所有"自估不确定性"的安全门提供覆盖率反向校准，防止双门同时 fail-open。

## 5. 本轮最大风险

**一句话**：本方案把安全寄托在两个自估不确定性的估计器（CEM 后验与 CBM 健康观测器）上——一旦它们的协方差/置信带被系统性低估（元不确定性失准），协方差门控与预测性退化会同时"自信地"放开安全边际，系统不是被未知打败，而是被自己错误的不确定性模型打败。

> 本轮灵感：「同步定位与建图」×「电池管理」
> **继承纪律**：MetricVoiceGauge 九不变式与 v9 的 AC（分块证书）/MW（中立元契约）/ID（创新点蒸馏）全部保留；DA-ML/SPR/Cal 原样继承。新增的 CEM/LCA/CBM 一律为**可选增强估计器**：任一失效即注入中立元、严格退回 v9 行为（引理 87–92 给出退化与保守性论证），而非行为漂移。

- Level-0：CEM 后验或健康观测器被元审计判定欠覆盖 ⇒ 抬升 κ、放大 β_prior、收紧 R_safe（只增保守，不减安全）；

- Level-5：全失效 ⇒ 退回 MetricVoiceGauge-ACMD v9，再按 v9 定义 536 退回 v8/v7/v6。

## 1. 符号体系增量（定义 540–549）

| 符号 | 含义 |
|---|---|
| X, x | 空间索引集合（关键帧局部栅格 / 拓扑节点）与其元素 |
| (μ_β(x), σ_β(x)) | CEM 在区域 x 的前向模型误差后验均值与标准差 |
| β_eff(x)=μ_β(x)+κσ_β(x) | 区域有效误差余量（κ 由元审计校准，默认 2） |
| r = \|m_true − m_pred\| | 证书残差（真实指标 vs F̂ 预测） |
| CFG=(V,E) | 证书因子图：节点为证书，边为前向残差边/回环约束边 |
| r_lc, τ_lc | 回环残差及其作废阈值 |
| H_lc | 回环重审计年龄窗口（默认 50 控制周期） |
| g_Σ(t) | 位姿协方差门控量 = max(tr(Σ_pose)/τ_Σ, H(Σ_pose)/τ_H) |
| B(t) ∈ [0,1] | 预算荷电状态（Budget-State-of-Charge） |
| B_max, B_reserve | 单周期预算上限（ms）与不可透支安全储备（默认 3ms） |
| h_m ∈ [h_min,1] | 模块健康度（State-of-Health），h_fail=0.3 |
| R̂_m | 剩余寿命：跌破 h_fail 前的预计控制周期数 |
| R_safe | 预测性退化的寿命视界（默认 300 周期） |
| Ĉ_t^E=(E_chunk,E_abort,B_reserve) | 能量可行块证书 |
| c_β, c_h | CEM 与健康带的经验覆盖率（元审计输入） |

**新增定义 540（证书误差地图 CertificateErrorMap）** 对每个空间单元 x 维护高斯后验 (μ_β(x), σ_β(x))。每当真实执行观测到证书残差 r（真实间隙/能耗 vs F̂ 预测）：
```
μ_β(x) ← (1−α)μ_β(x) + α·r
σ_β²(x) ← (1−α)σ_β²(x) + α·(r−μ_β(x))² + d·(⟨σ_β²⟩_N(x) − σ_β²(x))
β_eff(x) = μ_β(x) + κ·σ_β(x)
```
其中第三项为邻域扩散（让一次观测影响相邻单元），d∈[0,1] 为扩散率。未见单元取先验 (μ_β⁰, σ_β⁰)（σ_β⁰ 较大）⇒ 进入陌生区前 β_eff 已偏大、K_eff 自动缩短，**不依赖 Δ_dom 的 20 帧滑窗**。

**新增定义 541（证书因子图与回环重审计 CertFactorGraph / LoopClosureAuditor）** CFG 节点 v_t=Ĉ_t；边两类：(a) 前向残差边 e_t=(v_t, v_{t+1})，权重为预测一致性；(b) 回环边 e_lc=(v_i, v_j)，由地点识别给出变换 T_lc 与协方差。回环触发时计算
```
r_lc = | dist_corrected(s_j, O) − dist_predicted(v_j, O) |
```
若 r_lc>τ_lc，则作废集 I_t={v_k : supp(v_k)∩supp(T_lc)≠∅ ∧ age(v_k)≤H_lc}，并用 r_lc 回溯更新 CEM 对应单元；若存在 v_k∈I_t 对应仍在执行的块，立即选最近中止点 p* 安全停驻。

**新增定义 542（位姿协方差门控 PoseCovarianceGate）** 取代定义 539 的门控量：
```
g_Σ(t) = max( tr(Σ_pose(t))/τ_Σ , H(Σ_pose(t))/τ_H )
u(t)   = max( Δ_dom/τ_dom , risk_SLAM/τ_SLAM , g_Σ(t) )
K_eff(t) = 1                                        若 u(t) ≥ 1
         = max(1, ⌊K_max·(1−u(t))⌋)                 否则
```
g_Σ 单调于位姿不确定性；引理 87 给出它在 Lipschitz 前向模型下的保守代理性质。

**新增定义 543（预算荷电状态 BudgetSoC）**
```
B⁻(t+1) = B(t) − (Σ_m e_m(t) + e_guard(t) + E_chunk_amort)/B_max + ρ·1[idle]
B(t+1)  = clip( B⁻(t+1) + L·(y_t − ŷ_t), 0, 1 )
B_avail(t) = B(t)·B_max − B_reserve
```
e_m 为模块实测执行时间（能量代理），y_t 为可观测的执行时间/功耗，ŷ_t 为模型预测，L 为观测器增益；ρ 为闲时回充率。B_reserve 永久不可花。

**新增定义 544（模块健康度 StateOfHealth）**
```
h_m(t+1) = clip( h_m(t)
                 − γ·max(0, e_m(t)−Ŵ_m)/Ŵ_m
                 − δ·1[overrun_m(t)]
                 + ε·1[e_m(t) ≤ 0.5Ŵ_m],  h_min, 1 )
```
h_m=1 为新模块；hot 模块（长期满负荷、时延漂移、高温）单调下降。

**新增定义 545（剩余寿命 RemainingUsefulLife）** 由 Δh_m 的 EWMA 估计退化率 ĥ̇_m：
```
R̂_m(t) = (h_m(t) − h_fail) / max(ε, ĥ̇_m(t))
```
R̂_m<R_safe ⇒ 触发定义 547 的预测性退化。

**新增定义 546（能量可行块证书 EnergyFeasibleChunk）** 在定义 533 的指标证书上叠加能量约束：
```
Ĉ_t^E valid ⇔ Ĉ_t valid ∧ (E_chunk + E_abort ≤ B_avail(t))
```
E_abort=max_{p∈P_t} 从 p 步安全停驻的能量；P_t 为空则拒绝该块（沿用定义 534）。

**新增定义 547（预测性退化 PrognosticDegradation）** 若 R̂_m<R_safe 或 h_m<h_pre（默认 0.4），MW 在模块正常完成前即注入 v_m^⊥，日志标签为 `PROG`；其端口读数与"该模块在此时超时"逐位一致（引理 89），故对下游不可区分、仍属 v8 退化格点。恢复走 ID 的 Schmitt 迟滞，且需非退化证据。

**新增定义 548（预算均衡与热降额 BudgetBalancing / ThermalDerating）** 模块权重 w_m∝h_m，分配 B_m=B_avail·w_m/Σw 并设最小份额 B_min；请求超份额的模块按 π_m 从低到高降级（或由 ID 缩短块长）。温度 T 超阈时按 η(T)∈(0,1] 降额：B_max(T)=η·B_max，K_max(T)=max(1,⌈η·K_max⌉)，类比电池热管理。

**新增定义 549（元不确定性审计 MetaUncertaintyAudit）** 统计覆盖率
```
c_β = (1/n)Σ 1[ r_i ≤ β_eff(x_i) ]，  c_h = 健康带覆盖模块实际失效的比例
```
若 c_β < 1−δ_meta 或 c_h < 1−δ_meta，则单调抬升 κ ← κ(1+ρ_meta)、β_prior ← β_prior(1+ρ_meta)、R_safe ← R_safe/η_safe；只允许变保守，不允许放松。

## 2. 形式化定义（要点与升级）

**定义 533（块证书）升级** Ĉ_t=(ĝ_min,ê_max,γ̂_grasp) 的 β 由全局标量替换为**块空间支撑上的最坏 β_eff**：β_t=max_{x∈supp(chunk)} β_eff(x)。因此同一 K 公式在熟悉区自然取长块、陌生区自然取短块，无需额外调参。

**定义 535（契约表）升级** 每行新增 `h_m, R̂_m, B_m` 三个运行期字段；调度从纯 EDF 变为 "EDF + 预算可行 + 健康前置降级"：先按 D_m 排序，再对 h_m<h_pre 的模块直接注入 v^⊥，最后校验 Σ B_m ≤ B_avail。

**定义 536（中立元表）升级** 新增 CEM 中立元：β_eff(x)≡β₀（全局标量）；CBM 中立元：B(t)≡B_max、h_m≡1、R̂_m≡∞；PCG 中立元：g_Σ≡0。三者失效均等价 v9 对应行为。

**升级定义 531（软硬约束衔接）** 硬检查触发条件新增两项：块内能量可行性失效（E_chunk+E_abort>B_avail）与回环重审计作废。它们与 Ĉ_t 失效同尺度，直接进 M₀，无"块内软通过硬失"空洞。

# IP-357 CertificateErrorMap：空间后验误差场
class CertificateErrorMap:
    def __init__(self, mu0=0.02, sigma0=0.05, alpha=0.1, kappa=2.0, diff=0.2):
        self.mu, self.var = {}, {}
        self.mu0, self.sigma0 = mu0, sigma0
        self.alpha, self.kappa, self.diff = alpha, kappa, diff

    def beta_eff(self, region):
        if region not in self.mu:
            return self.mu0 + self.kappa * self.sigma0     # 未见区 ⇒ 大余量
        return self.mu[region] + self.kappa * self.var[region] ** 0.5

    def chunk_beta(self, cells):
        return max(self.beta_eff(x) for x in cells)        # 定义 533 升级

    def observe(self, region, residual):
        mu = self.mu.get(region, self.mu0)
        var = self.var.get(region, self.sigma0 ** 2)
        self.mu[region] = (1 - self.alpha) * mu + self.alpha * residual
        self.var[region] = ((1 - self.alpha) * var
                            + self.alpha * (residual - mu) ** 2)
        for nb in neighbors(region):                       # 邻域扩散
            v = self.var.get(nb, self.sigma0 ** 2)
            self.var[nb] = (1 - self.diff) * v + self.diff * self.var[region]


# IP-358 CertFactorGraph + LoopClosureAuditor
class LoopClosureAuditor:
    def __init__(self, cem, tau_lc=0.05, H_lc=50):
        self.cem, self.tau_lc, self.H_lc = cem, tau_lc, H_lc
        self.nodes = []                                    # (t, cell_support, cert)

    def add_cert(self, t, cells, cert):
        self.nodes.append((t, set(cells), cert))

    def on_loop_closure(self, t_now, T_lc, corrected_dist, pred_dist, live_chunk):
        r_lc = abs(corrected_dist - pred_dist)
        if r_lc <= self.tau_lc:
            return None
        affected = [n for n in self.nodes
                    if n[1] & support(T_lc) and (t_now - n[0]) <= self.H_lc]
        for _, cells, _ in affected:                       # 回溯抬升 CEM
            for x in cells:
                self.cem.observe(x, r_lc)
        for _, _, cert in affected:
            cert.invalidate(tag="LOOP_CLOSURE")
        if live_chunk is not None and live_chunk in [n[2] for n in affected]:
            return "safe_stop"                             # 定义 541 fail-safe
        return "audited"


# IP-359 PoseCovarianceGate
def covariance_gate(sigma_pose, tau_sigma=0.02, tau_H=0.5):
    tr = trace(sigma_pose)
    H = entropy(sigma_pose)
    return max(tr / tau_sigma, H / tau_H)                  # 定义 542


# IP-360 ComputeBatteryManager
class ComputeBatteryManager:
    def __init__(self, B_max=20.0, B_reserve=3.0, L=0.3, gamma=0.5,
                 delta=0.2, eps=0.02, h_fail=0.3, R_safe=300):
        self.B_max, self.B_reserve, self.L = B_max, B_reserve, L
        self.gamma, self.delta, self.eps = gamma, delta, eps
        self.h = {}; self.h_fail, self.R_safe = h_fail, R_safe
        self.dh = {}                                       # 退化率 EWMA

    def soc_update(self, B, e_used, y, y_hat, idle):
        B = B - (e_used + self.B_reserve * 0.0) / self.B_max
        B = B + (0.05 if idle else 0.0)                    # ρ 回充
        return min(1.0, max(0.0, B + self.L * (y - y_hat)))

    def soh_update(self, m, e, wcet, overrun):
        h = self.h.get(m, 1.0)
        h -= self.gamma * max(0.0, e - wcet) / wcet
        h -= self.delta * (1.0 if overrun else 0.0)
        h += self.eps * (1.0 if e <= 0.5 * wcet else 0.0)
        h = min(1.0, max(self.h_fail - 0.2, h))
        self.dh[m] = 0.9 * self.dh.get(m, 0.0) + 0.1 * (self.h.get(m, 1.0) - h)
        self.h[m] = h
        return h

    def rul(self, m):
        rate = max(1e-6, self.dh.get(m, 0.0))
        return max(0.0, (self.h.get(m, 1.0) - self.h_fail) / rate)

    def energy_feasible(self, E_chunk, E_abort, B):
        return E_chunk + E_abort <= B * self.B_max - self.B_reserve

    def balance(self, modules, B):
        avail = B * self.B_max - self.B_reserve
        w = {m: max(0.05, self.h.get(m, 1.0)) for m in modules}
        tot = sum(w.values())
        return {m: max(B_MIN, avail * w[m] / tot) for m in modules}

## 4. 推导

**引理 87（协方差门控的保守代理性）** 设前向模型误差可分解为有界偏差 b(x) 与 Lipschitz 位姿项：‖F̂(s,a)−F(s,a)‖ ≤ b(x)+L·‖δ_pose‖，且 E‖δ_pose‖ ≤ √tr(Σ_pose)。若 CEM 取 β_eff(x)=μ_β(x)+κσ_β(x) 且 μ_β 为 b 的上界估计、κσ_β ≥ L√tr(Σ_pose)（κ 由元审计校准），则 β_eff(x) ≥ ‖F̂−F‖ 以高概率成立。于是 g_Σ 越过阈值时 β_eff 必先将越过真实误差所需的余量，K_eff 的收缩发生在实际间隙违背之前。证：由三角不等式与 Cauchy–Schwarz，‖F̂−F‖ ≤ b+L√trΣ；代入 β_eff 定义即得。∎

**引理 88（回环重审计 fail-safe）** 设回环检测时延 ≤ H_lc，且任一中止点 p∈P_t 满足定义 534 的停车不变式。若 r_lc>τ_lc 触发作废集 I_t：(i) 仍在执行的受影响块必在最近中止点安全停驻（定义 541）；(ii) 已完成块被回溯作废并以 r_lc 抬升 CEM，使后续 β_eff 不低于真实残差。故回环发现的位姿/障碍错误不会导致已污染证书继续被信任。证：(i) 由定义 534 的停车不变式 + 引理 82(ii)；(ii) 由定义 540 的单调 α 更新与 β_eff 定义。∎

**引理 89（预测性退化的行为等价）** 预测性注入的 v_m^⊥ 与超时注入使用同一中立元、同一输出端口与同一聚合恒等律 (x⊕v^⊥=x)，故对下游逐位等价（v9 引理 83）；差异仅在日志标签 `PROG` 与注入时机更早。因此任意预测性退化状态仍属于 v8 退化格点，v9 引理 84 的安全传递成立；误报仅表现为算力浪费与块长收缩，不产生新安全风险。∎

**引理 90（能量可行性 ⇒ 中止可执行）** 若 E_chunk+E_abort ≤ B_avail=B(t)B_max−B_reserve，且 E_abort 覆盖从任意 p∈P_t 安全停驻的真实能量，则块执行途中触发中止时，停驻在预算耗尽前完成。证：能量单调消耗，E_chunk+E_abort 为最坏总消耗上界；B_reserve 不参与块内预算，故停止后仍有储备。结合引理 82(ii) 得轨迹安全。∎

**引理 91（预算守恒与无饥饿）** 在定义 543 的 clip 更新与定义 548 的最小份额 B_min 下：∀t, B(t)∈[0,1]，Σ_m B_m ≤ B_avail，且每个活跃模块获得 ≥B_min（或显式降级）。故预算不破产、模块不饥饿、EDF 可行性（v9 引理 86）保持。证：对 B 的更新做不变量归纳；均衡分配按 h_m 正比且裁剪到 B_min，总和上界由 avail 归一化保证。∎

**引理 92（元审计的保守性单调）** 元审计仅在覆盖率 c_β<1−δ_meta 时抬升 κ、μ_β⁰、σ_β⁰ 并收紧 R_safe，从不放松；故 β_eff 与健康保守性对欠覆盖事件单调不减，安全边际不会静默收缩。代价是保守性可能导致块长缩短与误降级，由覆盖率恢复后的离线重标定回收（E594 的 κ 扫描给出精度-保守 Pareto）。∎

## 8. 本轮最大风险

**一句话**：本方案把安全寄托在两个自估不确定性的估计器（CEM 后验与 CBM 健康观测器）上——一旦它们的协方差/置信带被系统性低估（元不确定性失准），协方差门控与预测性退化会同时"自信地"放开安全边际，系统不是被未知打败，而是被自己错误的不确定性模型打败。
