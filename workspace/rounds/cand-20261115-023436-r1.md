# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态策略 × 主动多模态交互」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「点云配准」×「竞赛策略」）

> R69 的定位是「不确定性不只是刹车踏板，也可以是一句提问」。它把 U 拆成 aleatoric / epistemic，用流匹配给出多模态动作，用 VoI 决定问不问。但这条链路里埋着两个从未被验证的前提。
>
> **前提 A（可分辨性）**：只要两个模态在策略分布里不同，就存在某个信息动作能把它们分开。R69 的 VoI 是用「自己相信的似然模型」算的，它没有问：**当前场景的几何，是否允许我从某个允许的视角/触点上观测到这个差异？** 走廊里，沿墙方向的平移在点云上是退化的（残差对它不敏感）；对称物体前，180° 旋转歧义在几何上不可分辨。此时 R69 会花预算去「看」，看了也分不开——预算被烧掉，噪声还可能被误读成证据。
>
> **前提 B（单主体）**：歧义是自然产生的，预算分配是一个人对自然的贪心优化。R69 的威胁模型 ℰ_poison 只覆盖「回答是假的」，没有覆盖「对手在研究你的探询策略」：投放**诱饵歧义**（表观熵很高、真实损失为零）烧掉预算；制造**歧义拒绝**（让真歧义看起来不可解）逼你退回保守；**反侦察**（你总先看左边，对手就把左边布置成与谎言一致）；**配准投毒**（注入离群点，让退化方向看起来可观测）。
>
> 本轮两个灵感正好各补一边：
> - **点云配准**把「可分辨性」从信念问题变成**几何证书**：配准信息矩阵（观测 Gramian / Fisher）的零空间，明确告诉你哪些方向根本看不见。**能不能分开，是可证的，不是猜的。**
> - **竞赛策略**把「预算分配」从贪心 VoI 变成**被对手研究的锦标赛**：先按「不解决会输多惨」排序（淘汰赛种子），再用 minimax / CVaR 而不是期望值分配预算，最后用混合策略（随机化）让对手无法预测你下一步探哪里。
>
> 核心命题：**先证「能不能分开」（RGD），再证「它是不是真的」（RMC/XF），最后在「对手会骗你」的假设下分预算（SAB/RRS）；三者任一不通过，就退回 R68 的保守。** 命名 **ARENA-RAS**（Adversarial Registration-grounded Epistemic Nash Allocation）——歧义不是等待被消解的噪声，而是一场有几何约束、有对手、有预算的锦标赛。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**这个歧义在几何上分得开吗？对手是不是正希望我去追它？**」。

## 0. 直觉与动机

**灵感 1（点云配准 → 歧义有几何，可分辨性有证书）**
直觉：人走到岔路口，两边走廊长得一模一样。他不是「相信左边」或「相信右边」，而是知道：**沿着走廊方向，我的传感器根本分不清**。这就是配准里的退化（degeneracy）——信息矩阵在某个方向上特征值接近零，点云残差对该方向的平移不敏感。R69 的 VoI 只看「模态后验熵」，不看「观测算子在这个方向上的增益」；它会把一个几何上不可分辨的歧义当成可解的题，浪费一次注视/探针，甚至把噪声当成证据去更新后验。
严谨地说：信息动作 g 诱导一个观测算子 H_g（预测观测对模态参数的雅可比），观测噪声协方差 Σ_y(g) 由配准协方差给出。Fisher 信息 I_g = H_gᵀ Σ_y(g)⁻¹ H_g。若区分两个模态的方向 δ_ij 落在 ∩_g null(H_g) 里，则对任意允许动作，两个模态产生**同分布**的观测，VoI 恒为 0。配准零空间给出了这个「不可分辨子空间」的可计算估计。这直接回应 R69 的最大风险：**幻觉模态若没有几何支撑，就不该进入交互候选**；真歧义若落在退化方向，也不该被「问」，而应直接并入保守 floor。

**灵感 2（多假设配准 → 模态证据来自全局-局部两阶段与部分重叠）**
直觉：配准从来不是「一次 ICP 定终身」。先做全局假设生成（FPFH/RANSAC/NDT），得到多个候选变换；再对每个候选做局部精化（ICP/NDT），得到各自的协方差、内点率与重叠率。这和 R69 的 K 个流采样聚类是**同构**的：多模态策略给动作假设，多假设配准给几何假设，二者按「预测观测一致性」关联。
关键增量：配准给每个模态一个**独立于流模型**的似然——内点率、重叠率、残差、协方差。R69 的模态权重完全来自流模型（因此可能幻觉），配准权重来自几何（因此可作第二意见）。二者不一致时不做加权平均，而是**证伪**：流说有、几何说没有 → 幻影；几何说有、流说没有 → 盲点。这把 R69 的「模态校准门 MCG」升级为**双通道校准**。

**灵感 3（竞赛策略 → 预算是被对手研究的锦标赛，不是贪心背包）**
直觉：R69 的 MINT 每一步选 argmax(VoI−成本)，像比赛里每一球都打「期望收益最高」的球。但真正的高手会：先看签表（哪个歧义不解决会直接输），保留体力（预算），不让对手读出固定套路（随机化），领先时打「不输」的球（CVaR 而非期望）。如果对手知道你总先探左边，他就把左边伪装好。
严谨地说：当多个歧义项 j（各有未解决损失 L_j、成本 c_j）竞争同一预算 B，且对手可在预算 η 内注入诱饵或遮蔽真歧义时，贪心 VoI 是**可被利用的**（exploitable）：对手只需让诱饵的**表观** VoI 最高，就能让你把预算烧在零损失项上。竞赛策略给出的正确目标是 **minimax / CVaR 的损失削减**，而不是贝叶斯期望 VoI；并且选择规则要**随机化**（混合策略），使对手无法预测探测顺序。R69 正是「无对手、单一信念」时的退化情形（minimax = 贝叶斯，随机化 = 确定）。

**灵感 4（对偶通道 → 配准似然 × 动作似然）**
直觉：R69 的 FMA 用「动作轨迹在策略密度下的似然」做第二意见，防的是标定把传感器残差吸收掉。但 FMA 仍然在流模型自己的通道里——流模型幻觉时，它可能给幻影动作一个高似然。配准似然是**另一条物理通道**：幻影模态预测的观测在真实点云里找不到支撑，配准残差会很大。两条通道做**合取证伪**（AND），而不是加权求和，避免一条通道的高分掩盖另一条的否决。

**灵感 5（新威胁模型 → 对抗性歧义）**
直觉：会问的系统，攻击面从「答案」扩展到「问题本身」。四类新攻击：
(a) **诱饵歧义**：投放廉价、高表观熵的歧义，烧预算；
(b) **歧义拒绝**：让真歧义看起来不可解，逼系统冻结/退回保守（拒绝服务）；
(c) **反侦察**：学习确定性探询顺序，布置一致的假证据；
(d) **配准投毒**：注入离群点或对抗扰动，让退化方向看起来可观测，骗取 RGD 证书。
四类都必须进入干扰集，并有对应鲁棒化：minimax 分配、随机化、鲁棒配准（RANSAC + 鲁棒核 + 协方差膨胀），以及「误差必须偏向安全」的不对称纪律。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ARENA-RAS 总览）** ARENA-RAS = (RGD, MHT, RMC, XF, SAB, RRS, RPR, RAS-WM†)。六不变式：
(i) 实时流零学习写操作（继承 R68 定义 276-i）；
(ii) 交互预算硬约束（继承 R69 定义 293-ii）；
(iii) 证据纪律（继承 R69 定义 293-iii）；
(iv) **几何可分辨性纪律**：未经 RGD 认证为可分辨的 U_epi 不得触发交互，直接并入 λ_floor；
(v) **策略鲁棒纪律**：预算分配必须是 minimax / CVaR 且带随机化熵下界，不得使用可被预测的确定性贪心；
(vi) **跨通道证伪纪律**：模态须同时通过配准似然与动作似然的证伪门（AND），单通道高分不得定案。

**定义 311（配准算子与信息矩阵）** 对模态 m_k 与信息动作 g，预测观测几何为 Ō_k(g)（模态预测状态投影到传感器视域/接触面），实际观测点云 P_t。鲁棒配准
T_k* = argmin_T Σ_{corr} ρ(‖T Ō_k(g) − P_t‖; σ_ρ)
给出残差 r_k、内点集 ℐ_k、内点率 ι_k、重叠率 o_k。在 T_k* 处的高斯-牛顿 Hessian Λ_k(g) = J_kᵀ W_k J_k；协方差 Σ_k(g) = Λ_k⁺（伪逆）；可观测子空间 O_k(g) = range(Λ_k)；退化子空间 N_k(g) = {v : vᵀΛ_k v ≤ τ_deg}；条件数 κ_k = λ_max/λ_min⁺。

**定义 312（几何可分辨性 RGD）** 设 δ_ij(g) 为模态 i、j 在观测空间中的区分方向（两模态预测观测之差投影到公共可观测参数）。模态对 (i,j) 在动作 g 下的可分辨距离
D_ij(g) = sqrt( δ_ij(g)ᵀ H_gᵀ Σ_y(g)⁻¹ H_g δ_ij(g) )，
H_g 为观测对模态参数的雅可比，Σ_y(g) 为配准观测噪声协方差。**最佳可分辨性** D_ij = max_{g∈𝒜_info, certified} D_ij(g)。若 D_ij ≤ τ_D，称 (i,j) **几何不可分辨**；特别地，若 δ_ij ∈ ∩_g null(H_g)，则 D_ij = 0。

**定义 313（可约/不可约细分）** 归一化可分辨度 D̃_ij = D_ij/(D_ij+τ_D) ∈ [0,1)，可分辨质量
ρ_res = (Σ_{i<j} w_i w_j D̃_ij) / (Σ_{i<j} w_i w_j)，
于是 U_epi^res = ρ_res · U_epi（可约部分，SAB 可花预算），U_epi^irr = (1−ρ_res) · U_epi（几何不可约，永久并入 λ_floor，视同 aleatoric）。R69 的 U_epi 是本定义在 ρ_res ≡ 1（全可观测假设）下的退化。

**定义 314（多假设配准 MHT）** 全局假设 H = {T_1,…,T_M}（RANSAC/FPFH/NDT），逐假设局部精化得 (T_m*, Σ_m, ι_m, o_m)。配准模式权重
q_m ∝ exp(−r_m/(2σ_m²)) · ι_m · o_m。
流模态 {m_k} 与配准假设 {T_m} 通过预测观测一致性做匈牙利匹配；未匹配的流模态标记为「候选幻影」，未匹配的配准假设标记为「候选盲点」。

**定义 315（配准-模式校准 RMC）** 设流权重 ŵ、配准权重 q（同一关联集合上归一化）。校准散度
D_RMC = KL(ŵ‖q) + KL(q‖ŵ)。
幻影指标 φ_k = 1[ŵ_k > τ_w ∧ q_k < τ_q]；盲点指标 β_k = 1[ŵ_k < τ_w ∧ q_k > τ_q]。若 D_RMC > τ_rmc，禁用 VoI 决策，退回「保守 + 继续被动观测」（与 MCG 同级，但由独立通道触发）。

**定义 316（跨通道证伪 XF）** 配准似然 ℓ_reg(m_k|P_t) = −r_k/(2σ_k²) − ½ log det Σ_k；动作似然 ℓ_flow = log p_θ(ξ_k|o)。证伪门（合取）：
Pass_XF(m_k) ⇔ ℓ_reg > τ_reg ∧ ℓ_flow > τ_flow ∧ ¬φ_k。
不做加权求和：任一通道否决即否决，避免「高流似然洗白无几何支撑的幻影」或「高配准似然洗白行为异常」。

**定义 317（战略分配 SAB）** 可分辨歧义项 j=1..J，未解决损失 L_j = Σ_{i<i'} w_i w_{i'} · ℓ_mis(i,i')（选错模态的代价），解决成本 c_j，预算 B。鲁棒分配
α* = argmin_{α∈Δ(B)} max_{P∈𝒫} Σ_j (1 − p_j(α)) L_j，
p_j(α) 为预算 α 下的解决概率（饱和/递减），𝒫 为与观测及 RMC 一致的信念集（由配准鲁棒协方差诱导）。非对抗且 𝒫={posterior} 时，α* 退化为 R69 的贪心 VoI/背包解。

**定义 318（对抗性歧义博弈 AMG）** 防御者选分配/探询策略 π，攻击者在预算 η_adv 内选扰动 η（诱饵注入、真歧义遮蔽、反侦察布置、配准离群点），使防御者损失最大。博弈值 V = min_π max_{η:‖η‖≤η_adv} J(π,η)。纯策略值 V_pure ≥ 混合策略值 V_mix；随机化价值 = V_pure − V_mix ≥ 0。

**定义 319（不输门 CVaR Gate）** 交互后损失随机变量 L_after。仅当 CVaR_β(L_after) < L_safe − margin 时释放 resolution bonus；否则走 R68 兜底。R69 的期望判据 E[L_after] < L_safe 是本定义在风险中性（β→0）时的退化。

**定义 320（随机化与反侦察 RRS）** 探询/分配策略为混合策略 σ，熵下界 H(σ) ≥ h_min，使攻击者的反侦察优势（可预测性）有界：确定性策略利用度 ≥ Δ_H，混合策略 ≤ Δ_H·e^{−h_min}（引理 21）。随机种子不进证书明文，只进交互日志哈希。

**定义 321（鲁棒配准 RPR）** 离群比例上界 ε_out、RANSAC 置信度、鲁棒核 ρ；协方差膨胀 Σ_reg ← Σ_reg + κ ε_out I_N（在弱支撑/退化方向额外膨胀）。认证条件：ι_k ≥ ι_min、o_k ≥ o_min、κ_k ≤ κ_max、零空间稳定性（点云有界扰动后 O_k 的主角度变化 ≤ θ_max）。不满足则 RGD 证书作废，U_epi 视为不可分辨（偏向安全）。

**定义 322（信息动作的几何认证）** g 可采纳 ⇔ 安全认证（继承定义 302）∧ 几何认证：D_ij(g) ≥ τ_D ∧ 预测重观测可配准（o ≥ o_min ∧ 非退化）。即使名义 VoI 很高，几何认证不过也不得执行——把 R69 的「安全认证」扩展为「信息认证」。

**定义 323（证书 J_ARENA）** J_ARENA = (J_FLUID, D_min, κ_reg, ι_reg, o_reg, D_RMC, φ/β 计数, CVaR_after, L_safe, h_σ, η_adv, arena_ver)。Valid ⇔ Valid(J_FLUID) ∧ RGD 证书有效 ∧ RMC 未越界 ∧ 分配满足 CVaR 门 ∧ 随机化熵达标。

**定义 324（战略审计与干扰集）** VQAuditor-S 审计：是否被诱饵主导、是否可被反侦察、随机化是否真随机（熵/种子审计）、配准是否被投毒、CVaR 门是否被绕过。ℰ_ARENA = ℰ_FLUID × ℰ_decoy × ℰ_denial × ℰ_counter-scout × ℰ_regpoison。

**定义 325（细化两级退避）** U_epi^irr 永久入 floor；U_epi^res 仅在 CVaR 门通过且 RGD 认证下释放。于是
λ = λ_floor(U_ale + U_epi^irr)（成功释放 bonus）或 λ_floor(U_ale + U_epi^irr + U_epi^res)（否则）。
R68 是「永不交互」边界，R69 是「ρ_res ≡ 1 且风险中性」边界。

**定义 326（重复博弈与无遗憾）** 每轮更新对手类型后验与分配策略，累计遗憾 Regret(T) = max_α Σ_t [J_t(α) − J_t(α_t)] = O(√(T J log J))（EXP3/FTRL 类）。保证长时程不被缓慢适应的对手拖垮。

## 2. 关键算法骨架

```python
# IP-264 RGD：几何可分辨性（配准信息矩阵的零空间）
def geometric_distinguishability(modes, i, j, obs, admissible_actions):
    best = 0.0
    for g in admissible_actions:
        H, Sy = obs.observation_jacobian(modes, g)       # ∂y/∂m，配准协方差
        lam   = H.T @ solve(Sy, H)                       # Fisher 信息
        delta = obs.mode_difference(modes, i, j)         # δ_ij
        P     = observable_projector(lam, TAU_DEG)       # 投影掉零空间
        best  = max(best, sqrt(max(0.0, delta @ (P @ lam @ P) @ delta)))
    return best                                          # ≤ τ_D ⇒ 不可分辨

# IP-265 MHT：全局假设 + 局部精化 + 协方差
def multi_hypothesis_registration(pred_cloud, P_t, max_hyp=8):
    H = global_hypotheses(pred_cloud, P_t)               # RANSAC / FPFH / NDT
    return [local_refine(h, P_t) for h in H]             # (T*, Σ, ι, o, r)

# IP-266 RMC：配准权重是流权重的独立第二意见
def registration_mode_calibration(w_flow, hyp):
    q = softmax([-h.r/(2*h.sigma**2) + log(h.inlier + EPS)
                 + log(h.overlap + EPS) for h in hyp])
    return divergence(w_flow, q)                         # KL 和 / ECE

# IP-267 XF：合取证伪（不是加权和）
def cross_channel_pass(mode, P_t, o):
    l_reg  = mode.registration_loglik(P_t)               # 几何通道
    l_flow = mode.action_loglik(o)                       # 行为通道（R69 FMA）
    return (l_reg > TAU_REG) and (l_flow > TAU_FLOW) and not mode.phantom

# IP-268 SAB：CVaR / minimax 的歧义锦标赛
def strategic_allocate(ambiguities, budget, belief_set):
    order = sorted(ambiguities, key=lambda a: a.worst_case_loss, reverse=True)
    alpha = robust_knapsack(order, budget, belief_set)   # min_α max_{P∈𝒫}
    return randomize(alpha, h_min=H_MIN)                 # 混合策略，防反侦察

# IP-269 AMG：诱饵 / 歧义拒绝检测
def adversarial_filter(ambiguities, history):
    return [a for a in ambiguities
            if not is_decoy(a, history)              # 高表观熵、低真实损失
            and not is_denial(a, history)]           # 真歧义被压成「不可解」

# IP-275 ARENA 主闭环（继承 R69，仅在「可分辨性与分配」处插入 ARENA 层）
def ARENA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 1) 几何证书：先证「能不能分开」
    hyp = M.mht.register(modes, obs.point_cloud)         # 可能为空（无几何支撑）
    d   = {(i, j): M.rgd.distinguishability(modes, i, j, obs)
           for i in range(len(modes)) for j in range(i + 1, len(modes))}
    rho_res = resolved_mass(d, modes, TAU_D)
    U_res, U_irr = rho_res * U_epi, (1.0 - rho_res) * U_epi
    # 2) 第二意见：配准似然 × 动作似然（合取证伪）
    M.rpr.robustify(hyp)                                 # 协方差膨胀 + 零空间稳定性
    M.rmc.calibrate(modes, hyp)                          # 幻影 / 盲点
    modes = [m for m in modes if M.xf.pass(m, obs)]
    # 3) 只有「可分辨 + 通过证伪 + 非诱饵」才进入分配
    amb = M.amg.filter(build_ambiguities(modes, d), M.history)
    g = (M.sab.allocate(amb, M.budget, M.rpr.belief_set())
         if (amb and not M.rmc.over_threshold) else None)
    # 4) 交互与信念更新（CVaR 门，不是期望门）
    cvar_ok = g is not None and M.cvar_gate.ok(g, U_res)
    if cvar_ok:
        ans = M.cia.execute(g)                           # 继承 R69：认证 + 证据纪律
        U_res = M.cia.update_belief(modes, ans)
    # 5) 风险缩放：不可分辨 + 未释放的 epistemic 都进 floor
    U_floor = U_ale + U_irr + (0.0 if cvar_ok else U_res)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(...)
    mode = select_mode(modes, U_floor, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    # 6) 战略审计 + 证书
    M.vqa_s.submit_async(g, d, rho_res, hyp, M.sab.last_alpha, M.rrs.entropy)
    return k, lam, mode, (U_ale, U_irr, U_res)
```

## 3. 推导

**引理 19（退化 ⇒ VoI 为零）** 若 δ_ij ∈ ∩_{g∈𝒜_info} null(H_g)，则对所有允许的 g，模态 i、j 的观测分布相同，p(y|m_i,g) = p(y|m_j,g)；故一次观测后的期望后验熵不变，VoI(g)=0，任何预算都只产生零信息。系：R69 的 VoI 从**学到的似然**估计，可能忽略零空间而给出正值；真实可分辨质量至多为 ρ_res，剩余的 (1−ρ_res) 部分是**纯浪费**（甚至因噪声更新而有害）。这解释了为什么「更主动」不总是「更聪明」：在没有几何信息的自由度上提问，等价于用噪声强化先验。

**引理 20（RMC 的幻影检测下界）** 设流模型幻觉出一个无几何支撑的模态 m_h（ŵ_h > τ_w，但真实点云中不存在对应结构）。当关联集合非空、iota_min 与 o_min 满足定义 321，配准残差 r_h 的期望 ≥ c·(缺失结构质量)/σ_ρ，故 q_h → 0，D_RMC ≥ ŵ_h log(ŵ_h/q_h) → ∞。检测功效随缺失结构在观测中的占比单调上升。系：R69 的最大风险（自信地追问幻影）在**交互之前**就被几何通道拦下；代价是地图过期会制造假阳性（真结构不在旧地图里），故须用在线局部地图 + 重叠率门限，且假阳性时退回 R68 而非判为幻影。

**引理 21（诱饵烧预算上界与随机化收益）** 设攻击者可在预算 η 内让诱饵项的表观 worst-case 损失排到前 k。确定性贪心下，攻击者只要让诱饵持续占据最高优先级，就能把至多 B 的预算全部导向零损失项（诱饵烧预算比例 → 1）。采用混合策略 σ（熵 ≥ h_min）后，攻击者必须猜测本轮实际分配，被猜中概率 ≤ e^{−h_min}；最优对抗下诱饵诱导的预算浪费比例 ≤ 1 − e^{−h_min} + O(η/B)。系：**随机化不是花哨，它是把对手的信息优势兑换成有界损失**；h_min 与实时预算构成显式 trade-off（E299）。

**引理 22（配准投毒的保守性）** 设真实信息矩阵 Λ，受 ε_out 比例离群点污染后的估计为 Λ̂。由 Davis–Kahan，可观测子空间 O 与 Ô 的主角度 ≤ c·‖Λ̂−Λ‖/σ_min(Λ) ≤ c'·ε_out/σ_min。RPR 的协方差膨胀使 D 的估计偏小、ρ_res 偏小，因此 U_epi^irr 被**高估**。于是投毒最多让系统「少拿 resolution bonus」，不会让它「在不可观测方向上自信交互」。这是本轮的关键不对称：**估计误差必须偏向不可分辨/保守一侧，安全才不会因攻击而变弱。**

**定理 18（ARENA 严格包含 R69）** 在 A99–A101（全可观测 ρ_res≡1、RMC 校准通过、无对手、配准正确）下，ARENA 的 RGD 全部通过、CVaR 门退化为期望门、minimax 退化为贝叶斯贪心、随机化不改变期望，故与 FLUID 逐指令相同。一般情形下，ARENA 只在「最坏情形损失严格优于 L_safe」时释放 bonus，且 U_epi^irr 永久入 floor，因此对任意实现的损失，ARENA 的已实现风险 ≤ FLUID；在良性场景二者相等。R69 是 ARENA 在「全可观测 + 风险中性 + 无对手」三个边界上的退化。

**定理 19（战略安全与无遗憾）** CVaR 门保证 worst-case 损失 ≤ L_safe + margin；混合策略 + 无遗憾更新（定义 326）给出 Regret(T)=O(√(T J log J)) 对自适应对手；交互只改变「选哪个模态/是否花预算」，不改变安全包络；失败/超时/投毒/被诱饵主导时 λ 单调不降地退化为 R68。提交/换装不变式（R68 定理 15）保持 ⇒ 控制连续、无突变。

## 6. 本轮最大风险

**一句话**：ARENA 把「可信性」从 R69 的流模型模态权重转移到了**配准协方差与可分辨性证书**上——一旦配准被过期地图、对抗点云或非刚性形变系统性骗过，RGD 会把不可分辨误判为可分辨（烧预算、把噪声当证据），或把真模式误判为幻影（系统冻结）；而 minimax 只在声明的对手类 𝒫_adv 内安全，一个会学习你随机种子/分配偏好的真实对手仍在保证之外。**最深的风险是：我们只是把「单点信任」从 R68 的标定层、R69 的流模型，搬到了 R70 的配准几何——每一层都用「更底层不可骗」来担保上一层，却没有人担保最底层。**

**次级风险与缓解**：
1. **地图过期制造假幻影** → 在线局部地图 + 重叠率门限 + 假阳性退回 R68（不判幻影）；
2. **配准投毒** → RPR 协方差膨胀/零空间稳定性认证 + 多模态交叉（深度/双目/IMU）+ 引理 22 的保守性；
3. **随机化被预测** → 熵下界 + 种子不进证书明文 + 定期重播种；
4. **CVaR 门过保守导致任务失败** → 分层 β（按风险等级）+ E309 拐点标定；
5. **对手类外攻击** → AIC-ARENA 持续红队 + 无遗憾更新 + 「误差偏向保守」的不对称兜底。

**定义 316（XF）** `Pass_XF ⇔ ℓ_reg>τ_reg ∧ ℓ_flow>τ_flow ∧ ¬φ_k`；合取而非加权和，任一通道可否决。

**定义 317–318（SAB 与 AMG）** `α* = argmin_α max_{P∈𝒫} Σ_j (1−p_j(α)) L_j`，`Σα≤B`；𝒫={posterior} 时退化为 R69 贪心/背包。对抗博弈 `V = min_π max_{‖η‖≤η_adv} J(π,η)`，`V_pure ≥ V_mix`。

**定义 319–320（CVaR 门与 RRS）** 仅当 `CVaR_β(L_after) < L_safe − margin` 才释放 resolution bonus；`β→0` 退化为 R69 期望门。混合策略熵 `H(σ) ≥ h_min`，反侦察优势 ≤ `Δ_H·e^{−h_min}`。

**定义 321–322（RPR 与信息动作几何认证）** 离群上界 `ε_out`、协方差膨胀 `Σ←Σ+κε_out I`、零空间稳定性；认证需 `ι≥ι_min, o≥o_min, κ≤κ_max, 主角度≤θ_max`。信息动作需同时通过安全认证与几何认证。

**定义 323–326（证书/审计/退避/重复博弈）** `J_ARENA` 增补 `D_min, κ, ι, o, D_RMC, φ/β, CVaR_after, h_σ, η_adv`；`ℰ_ARENA = ℰ_FLUID × ℰ_decoy × ℰ_denial × ℰ_counter-scout × ℰ_regpoison`；λ 退避见定义 325；无遗憾 `O(√(T J log J))`。

## 3. 关键算法伪代码

# IP-264 RGD：可分辨性证书（配准 Fisher 信息的零空间）
def distinguishability(modes, i, j, obs):
    best = 0.0
    for g in certified_info_actions(modes):
        H, Sy = obs.observation_jacobian(modes, g)
        lam   = H.T @ solve(Sy, H)
        P     = observable_projector(lam, TAU_DEG)       # 投影掉零空间
        delta = obs.mode_difference(modes, i, j)
        best  = max(best, sqrt(max(0.0, delta @ (P @ lam @ P) @ delta)))
    return best                                          # ≤ τ_D ⇒ 不可分辨

# IP-265 MHT：全局假设 + 局部精化
def register(pred_cloud, P_t):
    return [local_refine(h, P_t) for h in global_hypotheses(pred_cloud, P_t)]

# IP-266 RMC：独立几何第二意见
def mode_calibration(w_flow, hyp):
    q = softmax([-h.r/(2*h.sigma**2) + log(h.inlier + EPS)
                 + log(h.overlap + EPS) for h in hyp])
    return divergence(w_flow, q)                         # KL 和 / ECE

# IP-267 XF：合取证伪
def cross_channel_pass(mode, P_t, o):
    return (mode.registration_loglik(P_t) > TAU_REG
            and mode.action_loglik(o) > TAU_FLOW
            and not mode.phantom)

# IP-268 SAB：CVaR / minimax 的歧义锦标赛
def strategic_allocate(ambiguities, budget, belief_set):
    order = sorted(ambiguities, key=lambda a: a.worst_case_loss, reverse=True)
    alpha = robust_knapsack(order, budget, belief_set)   # min_α max_{P∈𝒫}
    return randomize(alpha, h_min=H_MIN)                 # 混合策略

# IP-275 主闭环（继承 R69，仅插入 ARENA 层）
def ARENA_RAS_round(M, obs):
    z, o = M.mtm.forward(...); c, U_cal, _ = M.cof.step(...)
    K = 1 if M.fmp.mode_head(z) < TAU_MODE else 4
    samples = M.fmp.sample(o, K)
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    hyp = M.mht.register(modes, obs.point_cloud)
    d   = {(i, j): M.rgd.distinguishability(modes, i, j, obs)
           for i in range(len(modes)) for j in range(i + 1, len(modes))}
    rho = resolved_mass(d, modes, TAU_D)
    U_res, U_irr = rho * U_epi, (1.0 - rho) * U_epi
    M.rpr.robustify(hyp); M.rmc.calibrate(modes, hyp)
    modes = [m for m in modes if M.xf.pass(m, obs)]
    amb = M.amg.filter(build_ambiguities(modes, d), M.history)
    g = (M.sab.allocate(amb, M.budget, M.rpr.belief_set())
         if (amb and not M.rmc.over_threshold) else None)
    cvar_ok = g is not None and M.cvar_gate.ok(g, U_res)
    if cvar_ok: U_res = M.cia.update_belief(modes, M.cia.execute(g))
    U_floor = U_ale + U_irr + (0.0 if cvar_ok else U_res)
    lam = max(M.efs.risk_scale(...), lam_floor(U_floor))
    k   = M.c_ras_wm.certified_prefix(...)
    mode = select_mode(modes, U_floor, lam)
    tau  = M.pi_sigma.prefix_dispatch(mode.a[:k]) * lam
    M.vqa_s.submit_async(g, d, rho, hyp, M.sab.last_alpha, M.rrs.entropy)
    return k, lam, mode, (U_ale, U_irr, U_res)

## 4. 推导

**引理 19（退化 ⇒ VoI 为零）** 若 `δ_ij ∈ ∩_g null(H_g)`，则对所有允许 g，`p(y|m_i,g)=p(y|m_j,g)`，观测后期望熵不变，`VoI(g)=0`。系：R69 从学到的似然估 VoI，可能忽略零空间而给出正值；真实可分辨质量 ≤ `ρ_res`，其余是纯浪费，甚至因噪声更新而有害。

**引理 20（幻影检测下界）** 无几何支撑的幻影模态 `r_h` 期望随缺失结构质量上升，`q_h→0`，`D_RMC ≥ ŵ_h log(ŵ_h/q_h) → ∞`；检测功效随缺失结构占比单调上升。系：R69 的最大风险在交互前被几何通道拦下；地图过期会制造假阳性，故须在线局部地图 + 重叠率门限，假阳性退回 R68 而非判幻影。

**引理 21（诱饵烧预算上界与随机化收益）** 确定性贪心下诱饵可占据最高优先级，烧预算比例 → 1；混合策略（熵 ≥ `h_min`）使被猜中概率 ≤ `e^{−h_min}`，诱饵浪费 ≤ `1−e^{−h_min}+O(η/B)`。系：随机化把对手信息优势兑换为有界损失，`h_min` 与实时预算是显式 trade-off（E299）。

**引理 22（配准投毒的保守性）** Davis–Kahan：`∠(O,Ô) ≤ c·‖Λ̂−Λ‖/σ_min(Λ) ≤ c'·ε_out/σ_min`。RPR 协方差膨胀使 `D` 偏小、`ρ_res` 偏小、`U_epi^irr` 被高估。故投毒最多让系统少拿 bonus，不会让它在不可观测方向上自信交互——**估计误差偏向保守一侧**。

**定理 18（ARENA 严格包含 R69）** 全可观测（`ρ_res≡1`）、RMC 校准、无对手、配准正确时，RGD 全通过、CVaR 门退化为期望门、minimax 退化为贝叶斯贪心、随机化不改变期望 ⇒ 与 FLUID 逐指令相同。一般情形只在「worst-case 损失严格优于 `L_safe`」时释放 bonus，且 `U_epi^irr` 永久入 floor ⇒ 对任意实现损失，ARENA 风险 ≤ FLUID；良性场景相等。R69 = 三个边界上的退化。

**定理 19（战略安全与无遗憾）** CVaR 门 ⇒ worst-case 损失 ≤ `L_safe+margin`；混合策略 + 无遗憾更新 ⇒ `Regret(T)=O(√(T J log J))`；交互只改模态选择、不改安全包络；失败/超时/投毒/被诱饵主导时 λ 单调不降地退回 R68 ⇒ 控制连续、无突变。

## 7. 本轮最大风险

**一句话**：ARENA 把「可信性」从 R69 的流模型模态权重转移到了**配准协方差与可分辨性证书**上——一旦配准被过期地图、对抗点云或非刚性形变系统性骗过，RGD 会把不可分辨误判为可分辨（烧预算、把噪声当证据），或把真模式误判为幻影（系统冻结）；而 minimax 只在声明的对手类 `𝒫_adv` 内安全，会学习你随机种子/分配偏好的真实对手仍在保证之外。**最深的风险是：我们只是把「单点信任」从 R68 的标定层、R69 的流模型，搬到了 R70 的配准几何——每一层都用「更底层不可骗」来担保上一层，却没有人担保最底层。**

**次级风险与缓解**：地图过期制造假幻影（在线局部地图 + 重叠门限 + 假阳性退回 R68）；配准投毒（RPR 协方差膨胀 + 零空间稳定性 + 多模态交叉 + 引理 22 保守性）；随机化被预测（熵下界 + 种子不进证书 + 定期重播种）；CVaR 门过保守（分层 β + E309 拐点）；对手类外攻击（持续红队 + 无遗憾更新 + 误差偏向保守的不对称兜底）。
