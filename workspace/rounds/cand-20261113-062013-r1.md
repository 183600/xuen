# 第 66 轮（承接第 65 轮「VISTA 视觉知情安全时序归因」IP-214~223；新灵感循环第 1 轮；本轮灵感：「可重构机构」×「扩散策略」）

> 第 65 轮 VISTA 自述的最大风险一针见血：**FIR 的归因能力依赖「故障属于有限假设集」与「视觉/几何失效相互独立」两个隐藏假设；真实故障是未知类型的组合，且透明/镜面/对抗 patch 会让视觉与几何共享同一个分布外失效源。此时 FIR 会把未知复合故障强行塞进最近假设、只膨胀错误的球，而系统因「已经归因」反而更自信地继续执行（A88）。** 本轮不再扩充假设表，也不假设三阶段总能被激励，而是启用一个更强的自由度：**让机器人改变自己的身体**。核心命题是：
>
> **把「固定本体上的有限假设归因」升级为「可重构本体上的可辨识性设计」：用机构重构把同一故障在多个位形下变成不同签名（配置差分抵消共模），用扩散策略生成多模态、可约束的「实验/动作」候选（引导去噪把安全注入生成，anytime 去噪对齐认证前缀），使未知复合故障从「被迫分类」变成「可判别、可隔离、或可安全降级」。**

## 0. 直觉与动机

**灵感 1（可重构机构 → 换一个身体再问一次）**
直觉：第 65 轮所有证据都来自**同一个固定本体**：视觉装在同一视角、力传感接在同一根连杆、接触几何只有一种映射。共因失效之所以致命，是因为同一个分布外源在两个通道里留下**共线**的痕迹，观测上不可分。可重构机构提供了一个被忽视的自由度：**改变本体，就改变了「故障如何耦合进观测」**。转动手腕，同一透明物体的视觉伪影与力偏置的映射就变了；换一个抓取位形，同一几何幻觉在接触落点上的投影就变了；切换欠驱动/全驱动的约束结构，同一接触模型错误在力矩上的表现就变了。于是「归因」从**在固定观测里做分类**，变成**主动设计一组让假设彼此分开的实验**——这正是科学方法里的「改变实验条件再看一次」。
必须诚实：重构不是免费的，它引入标定漂移、瞬态黑窗、可达性/自碰撞约束，且可能不可逆（换工具、切割）。所以重构本身必须被证书化，不能当作万能钥匙。

**灵感 2（可重构机构 → 配置差分 = 共模抑制）**
直觉：电子学里对抗共模噪声的标准手段不是「选一个更准的传感器」，而是**差分测量 / 斩波**：让共模项在两次测量中同号、在差分中相消。机构重构给出机器人版的「斩波」：在配置 c 与 c′ 下测同一故障，若共模源 β 的耦合 B_c 与 B_c′ 不同（甚至反号），则差分 Δρ=ρ(c)−ρ(c′) 会把 β 压低、把 θ 的相对差异放大。更一般地，把 β 当作 nuisance 参数，**多配置堆叠观测会提高 [S̄ B̄] 的列秩**，使 θ 与 β 从「共线不可分」变成「联合可辨识」。这是对第 65 轮 A88 的直接回应：**我们不再要求视觉与几何独立，而要求「重构能改变它们的共模耦合」**——这是一个可设计、可验证、可标定的条件，而不是一个祈祷式的独立性假设。

**灵感 3（扩散策略 → 生成式判别实验设计）**
直觉：第 65 轮的 AFA 在**有限探针集** A={press,rub,tap,lift,visual_probe,null_test} 里挑一个最大化互信息的动作。这仍是「有限假设 + 有限动作」的双重封闭：未知复合故障可能需要一个**没人枚举过的实验**（例如「先侧向转腕 30° 再轻触两次、沿接触斑做特定扫描」）。扩散策略天然生成多模态轨迹分布，把它条件在故障后验上，就得到**生成式实验提议器**：采样一批候选 (重构 c′, 探针轨迹 ξ)，用廉价代理估计期望信息增益与安全可行性，选最优且可行的。它不保证覆盖所有实验，但把「实验空间」从离散表扩展为连续、多峰、可约束的生成分布——这是对有限探针集的直接松绑。

**灵感 4（扩散策略 → 引导去噪 + anytime = 分辨率-前缀对齐）**
直觉：扩散/流匹配的去噪是迭代的，天然是 **anytime**：少量去噪步给出粗糙、高方差的块，更多步给出精细、低方差的块。这恰好与第 65 轮「长预测、短执行」同构：**去噪得越充分，才允许承诺越远**；计算紧张时早停，就只执行极短前缀。更关键的是**引导**：把安全证书与故障后验作为 guidance/投影注入每个去噪步，让生成过程本身偏向安全集，而不是「先生成再过滤」（后者在分布外会大量拒绝、甚至生成自信的危险样本）。这样「安全」从后置过滤器变成生成先验的一部分。
必须诚实：投影/引导会破坏原始扩散的精确采样保证，所以最终仍要用 CSC 兜底——引导降低违规率，证书兜住最坏情况。

**灵感 5（合流 → D-MORPH：Diffusion-guided Morphological Reconfiguration for out-of-hypothesis fault attribution；并原位升级 VISTA）**
闭环：在 VISTA 之上加三层——(i) **配置层**：维护配置索引签名族 {S_c,B_c} 与配置实验设计 CED；(ii) **生成层**：扩散块策略 DPP + 生成式判别实验 GPE + 约束引导去噪；(iii) **归因层**：两通道差分检验（共模 T_cm / 未知结构化 T_un）区分「共模源」与「未知复合故障」，只有可判别时才定向处置，否则重配置或安全降级。VISTA 组件原位升级：
- **FIR → CDF（配置差分归因）**：签名按配置索引；新增 H_common / H_reconf / H_unknown 的检验而非强行归类；归因不确定时优先「设计下一次重构实验」。
- **AFA → GPE（生成式判别实验）**：探针从枚举表升级为生成式 (c′,ξ) 提议，目标仍是故障假设互信息，但实验空间连续化。
- **ACH → DPP（扩散块策略）**：块由扩散策略生成，模式多样性同时提供语义不确定度与候选策略/重构分支。
- **CSC → CSC-D**：认证前缀与去噪步数 T′、重构黑窗对齐；黑窗内只保留硬限看护。
- **RSC-V → RSC-D**：新增 r_cm、r_reconf；共模只膨胀共模球，绝不误降级几何或误信力。
- **新增 RCC（重构安全证书）**：先决条件、可达/无自碰撞、瞬态黑窗、后重标定、回滚与不可逆阈值。
- **AIC-V → AIC-D**：用生成式对抗分布采样复合故障，并纳入重构故障（卡滞/标定漂移/拓扑错配）。
- **J_vista → J_dmorph**：证书增 config_trace、diff_signature、cm_test、unmodeled_flag、reconfig_cert、blackout_flag、denoise_steps、mode_diversity。

## 1. 形式化定义（增量：定义 233–249）

- **定义 233（D-MORPH 闭环）**：D-MORPH=(VISTA, 𝒞/ℛ, CDF, CED, DPP, GPE, RCC, CSC-D, RSC-D, AIC-D, J_dmorph)。定位：VISTA 的「可重构实验设计 + 生成式提议」升级。不变式：**配置实验设计、配置差分归因、扩散生成与证书只在语义流；实时流只执行经 RCC 认证的重构原语、硬限看护与短前缀，零学习写操作。**
- **定义 234（可重构机构与配置空间）**：机构 M(c) 由离散拓扑 τ∈𝒯（模块连接、手指布局、欠/全驱动、工具）与连续参数 η∈𝒩（关节零位、连杆长度、刚度/阻抗、相机位姿）参数化，c=(τ,η)∈𝒞。重构原语 r:c→c′ 带时长 Δt_r、代价 κ_r、能耗 E_r、可逆标志 rev_r∈{0,1}。有效重构需满足关节限位、自碰撞、负载与准静态稳定。按作用分三类：**传感重构**（改变观测矩阵 S_c）、**刚度/阻抗重构**（改变力耦合 B_c 与柔顺性）、**工具重构**（改变接触物理，常不可逆）。
- **定义 235（配置索引签名族）**：在配置 c 下，阶段化签名期望满足线性化模型 E[ρ|c,θ,β]=S_c θ + B_c β，ε∼N(0,Σ_ρ)。θ 为建模故障幅度；β 为**共模 nuisance**（同时污染视觉与力/几何的分布外源：透明/反光/对抗 patch/整机标定偏移）；S_c 与 B_c 由离线故障注入 + 真机标定拟合，且**必须携带标定版本与拟合不确定度**（后续差分完全依赖它，见定义 244/本轮风险）。
- **定义 236（配置差分与共模可剔除性）**：对配置序列 c_{1:L} 堆叠观测 ρ̄=S̄θ+B̄β+ε̄。记 P 为到 null(B̄ᵀ) 的正交投影（PB̄=0）。**投影可辨识** ⇔ P S̄ 列满秩且 J_cm=S̄ᵀPΣ_ρ⁻¹PS̄≻0；**联合可辨识** ⇔ [S̄ B̄] 列满秩。二者都只要求「配置改变了故障的耦合」，不要求视觉与几何独立。直白地说：换位形改变的是 B_c 的列空间，于是共模项要么被投影消掉，要么被显式估计掉。
- **定义 237（配置实验设计 CED）**：选择（可自适应）重构序列 π_c=(c_1,…,c_L) 最大化信息收益并惩罚成本：max_{π_c} logdet(Σ_l S_{c_l}ᵀΣ_ρ⁻¹S_{c_l}) − λ_kΣκ_r − λ_tΣΔt_r，s.t. 可达性、Valid(RCC)、时间预算；若某步不可逆则要求更高的证据阈值。非自适应版本用贪心边际增益/成本；自适应版本以当前后验熵为状态做一步前瞻。
- **定义 238（扩展故障假设）**：ℋ⁺=ℋ∪{H_common, H_reconf, H_unknown}。H_common 表示残差落在 range(B̄) 的**共模分布外源**；H_reconf 表示重构诱发的标定漂移/机构卡滞/拓扑错配；H_unknown 表示不属于任何建模列的复合未知故障。关键：**H_unknown 不需要被枚举**，它由定义 239 的残差通道被发现。
- **定义 239（共模/未知故障两通道差分检验）**：在投影空间拟合 θ̂ 后取残差 r=ρ̄−S̄θ̂，分解 r=r_∥+r_⊥，r_∥=P_{range(B̄)}r，r_⊥=P r。统计量 T_cm=‖r_∥‖²/σ² 与 T_un=‖r_⊥‖²/σ²。判据：T_un 超阈 → `unmodeled_structured`（未知结构化故障，非共模），升级重构以改变 B̄；仅 T_cm 超阈 → `common_mode`（拒绝强行归因，膨胀共模球或继续配置实验）；两者皆低 → 走标准 CDF 后验。**这一条直接替代第 65 轮「塞进最近假设」的失败模式。**
- **定义 240（扩散块策略 DPP）**：π_ψ(A_t|s_t,c) 为条件去噪扩散/流匹配策略，输出块 A_t∈ℝ^{H×d_a}。采样 M 个模式 {A^{(m)}}，模式间离散度 u_mode 作为语义不确定度与 H_policy 的补充证据；每个模式可对应不同策略/重构分支。块间一致性 d_chunk 沿用定义 219。
- **定义 241（约束引导去噪与安全投影）**：去噪步 t 在基础均值 μ_θ 外加入引导 g=λ_s∇_a g_safe(a;post,c)+λ_i∇_a g_info(a;post,c)，或直接做投影 a_{t−1}←Proj_{𝒮(post,c)}(a_{t−1})，𝒮 为力/速度/工作空间/形变约束的交集。引导只改变采样偏向，**不承担安全证明**；最终样本一律经定义 245 的 CSC-D 认证。
- **定义 242（分辨率-前缀对齐）**：去噪步数 T′≤T 给出块的分辨率；定义分辨率受限视界 k_res(T′)，关于 T′ 单调不减。认证前缀取 k*=min(m, k_res(T′), CSC 允许的最大值)。于是「算得越久 → 可承诺越远，但永不越过不可逆视界 m」；计算轴与安全轴第一次被显式对齐。
- **定义 243（生成式判别实验 GPE）**：条件生成分布 p_ψ(ξ|post)，ξ=(c′, 探针轨迹 a_{1:L})。采样 K 个候选，用廉价代理估计期望信息增益 I(ℋ⁺;ρ(ξ)|post) 与安全可行性（f_n≤f_safe、形变≤ε_strain、Valid(RCC)），取可行且增益最大者 ξ*；若最大增益<δ_fi 或无可行样本，退回枚举安全探针/被动观测。**实验空间从离散表变为可约束的连续生成分布。**
- **定义 244（重构安全证书 RCC）**：Valid(RCC(c→c′)) ⇔ (i) 准静态先决：f_n≤f_q、滑移裕度≥0、抓取稳定（或机构允许动态重构）；(ii) 可达且无自碰撞、负载/能耗在限；(iii) 规划**瞬态黑窗** [t_r,t_r+Δt_r]：期间仅硬限（力矩/力上限、看门狗、急停）生效，一切认证执行暂停；(iv) 后重标定：零力窗 + 视觉重配准完成前不得恢复 J 认证执行；(v) 不可逆重构需满足更高证据阈值（后验集中/熵上界）；(vi) 卡滞/超时有回滚方案。
- **定义 245（配置感知 CSC-D 与黑窗）**：CSC-D 在当前 c 与后验 post 上认证 k*；若前缀内将触发重构，则前缀截断在重构起点；黑窗写入证书 `blackout_flag=True`；后重构必须先跑零力窗 + 视觉重配准，避免 H_reconf 被误判为 H_force/H_geo。
- **定义 246（RSC-D 归因定向球扩展）**：球集 {r_geo,r_force,r_model,r_vis,r_cm,r_reconf}，只膨胀被归因者：H_common→r_cm↑ 且提高对应方向的 Σ_ρ；H_reconf→r_reconf↑ + 强制重标定；H_unknown→联合保守膨胀 + 要求配置实验或 safe_idle。融合 r=√(Σ r_i²) 进 WCV-D，避免「一坏全膨胀」的过度保守。
- **定义 247（AIC-D 生成式干扰认证）**：干扰不再只靠枚举 ℰ_V，而用生成式对抗 p_φ(ε)（扩散/流）采样复合 OOD，并叠加最坏情况搜索；新增 ℰ_reconf（标定漂移、卡滞、拓扑错配、黑窗传感器污染）。认证 = 采样估计 + 最坏包络，证书带 gen_adv_hash、reconf_calib_ver。
- **定义 248（J_dmorph 证书）**：J_dmorph=(J_vista, config_trace, diff_signature, cm_test, unmodeled_flag, reconfig_cert, blackout_flag, guidance_hash, denoise_steps, mode_diversity, aic_d_ver)。Valid ⇔ Valid(J_vista) ∧ config_trace 每步 Valid(RCC) ∧（若 unmodeled_flag 则未执行未经重构的归因）∧ 黑窗内只硬限 ∧ 后重构重标定完成 ∧ 未把 common_mode 当作建模故障 ∧ denoise_steps 与 k* 满足分辨率-前缀约束。
- **定义 249（D-MORPH 闭环算子）**：语义流 [VISTA 前段→配置索引签名→两通道差分检验→(ambiguous/unknown→CED 选配置 + GPE 生成实验)→RCC→执行重构(黑窗)→重标定→重归因→DPP 生成块+引导去噪→CSC-D→WCV-D→CSP-D 块规划→Shield→执行 k*→EV_exec→RSC-D→OLP→AIC-D]；实时流 [硬限看护→短前缀派发→黑窗看护→重标定触发→J_dmorph 构建]。

## 2. 关键算法骨架

```python
# CDF：配置差分 + 两通道检验（语义流）
rho_bar = stack([signature(c) for c in config_trace])      # 多配置堆叠
theta_hat = wls(rho_bar, S_bar, B_bar)                      # [S̄ B̄] 联合/投影拟合
r = rho_bar - S_bar @ theta_hat
T_cm, T_un = test_common_mode(r, B_bar), test_unmodeled(r, B_bar)
if T_un > chi2_un:      flag = 'unmodeled_structured'       # 未知复合故障 → 换 B̄
elif T_cm > chi2_cm:    flag = 'common_mode'               # 共模 → 不强行归类
else:                   post = cdf_posterior(rho_bar)       # 标准归因

# CED：配置实验设计（语义流，贪心 1-1/e）
J = zeros(d_theta, d_theta)
while budget > 0:
    c = argmax_{c in C_reach} (logdet(J + S_c.T @ inv(Sigma) @ S_c)
                               - logdet(J) - lambda_k * cost(c)) / time(c)
    if not RCC.valid(cur_c, c): continue
    J += S_c.T @ inv(Sigma) @ S_c;  config_trace.append(c);  budget -= time(c)

# GPE：扩散生成判别实验（语义流）
XI = diffusion_probe.sample(cond=post, c=cur_c, K=64)
xi_star = max((xi for xi in XI if safe(xi) and RCC.valid(cur_c, xi.c)),
              key=lambda xi: expected_info(post, xi), default=None)
if xi_star is None or expected_info(post, xi_star) < DELTA_FI:
    xi_star = enumerate_safe_probe(post) or None

# DPP + 引导去噪 + 分辨率-前缀（语义流规划，实时执行）
for t in reversed(range(T_denoise)):
    a = denoise_step(a, t, cond=(state, c, post))
    a = proj_safe(a, post, c)                     # 安全投影注入生成
k_res = resolution_horizon(T_exec)                # 实际去噪步数决定视界
k_star = min(m, k_res, csc_d.certified_prefix(a, post, c))
for act in a[:k_star]:
    dispatch(act)
    if blackout_guard.violated() or csc_d.monitor_step(act, post).abort: break
```

## 3. 保证概要与推导要点（完整推导见产物区）

- **引理 9（配置差分可辨识性）**：若多配置堆叠使 [S̄ B̄] 列满秩（联合可辨识），或使 PS̄ 列满秩且 J_cm≻0（投影可辨识），则未知复合故障与共模 nuisance 第一次可被**分开**，而不是挤在一个不可分的残差里。单配置下 θ 与 β 共线时秩坍缩——这正是第 65 轮 A88 的线性代数本质。
- **引理 10（共模抑制条件与 CMRR）**：差分 Δρ=ρ(c)−ρ(c′)=(S_c−S_c′)θ+(B_c−B_c′)β；共模抑制比 CMRR=‖(S_c−S_c′)θ‖/‖(B_c−B_c′)β‖。若 B_c=B_c′ 则差分严格消 β；若 B_c≠B_c′ 则用投影或联合估计。**重构的价值 = 让 B_c 随 c 变化且让 S_c 随 c 变化，从而把 CMRR 与可辨识性同时做大。**
- **引理 11（两通道检验的功效）**：在模型下 T_un 服从非中心 χ²，非中心度随「未知故障在 null(B̄ᵀ) 上的投影能量」增大；配置多样性通过缩小 null(B̄ᵀ) 或改变其方向提高功效。故 CED 不仅提高可辨识性，也提高**未知故障的检出率**。
- **定理 9（超出有限假设的安全）**：对任意（可能属于 ℋ⁺ 之外）故障 ζ，在 CED 选出的配置下必居其一：(i) 被 T_un/T_cm 检出 → 不强行归因，转重构或安全降级；(ii) 与某个 H∈ℋ⁺（含 H_common）观测等价 → 证书在该假设的支持集上取最坏，仍覆盖真实风险。故 Valid(J_dmorph) ⇒ 越界概率 ≤ α_chunk+δ_fi+α_vis+α_cm+α_reconf。**我们不再需要故障属于有限集，只需要「可检出或与已建模假设安全等价」。**
- **定理 10（重构不放大风险 + 可辨识性单调）**：若 Valid(RCC) 且黑窗只留硬限、后重标定完成后才恢复认证执行，则重构瞬态贡献有界风险 α_reconf；不可逆重构经证据阈值门控。且 J({c_1:L}) 是各配置 Fisher 之和（PSD 累加），**增加配置不会降低可辨识性**，只增加时间成本，故预算约束下的最优存在。
- **定理 11（引导扩散的近安全 + 分辨率-前缀）**：若安全集凸且投影非扩张，则末端投影后的样本落在安全集的概率 ≥1−α；非凸时用接受/拒绝并计入 α。且 k_res(T′) 关于 T′ 单调不减、k*≤min(k_res,m)，故早停只会缩短承诺、不会加深承诺——计算紧张时系统自动变得更保守。
- **命题（CED 贪心近似）**：logdet(J+·) 在配置集合上次模，基数/预算约束下贪心达到 (1−1/e) 的 oracle 近似；自适应版本以一步前瞻为代价换取对后验的利用。
- **实时性**：CDF 两通道检验 <0.2ms、黑窗看护 <0.1ms、CSC-D <1ms 均在语义/实时边界内；DPP/GPE/CED 全在语义流（GPU/低频），实时流目标 ≤2.6ms（A94 修订契约）。

## 2. 形式化定义（完整版）

**定义 233（D-MORPH 闭环）** D-MORPH 是 VISTA 的「可重构实验设计 + 生成式提议」升级：在 VISTA 的「语义流 ∘ 实时流」骨架上挂载配置层（CED/CDF）、生成层（DPP/GPE/引导去噪）与重构安全层（RCC/CSC-D/RSC-D/AIC-D），并把 J_vista 升级为 J_dmorph。不变式：**配置实验设计、配置差分归因、扩散生成、证书构建只发生在语义流与低频线程；实时路径只执行经 RCC 认证的重构原语、硬限看护、短前缀派发与黑窗看护，零学习写操作。**

**定义 234（可重构机构与配置空间）** 机构 M(c) 由离散拓扑 τ∈𝒯（模块连接、手指布局、欠/全驱动、末端工具）与连续参数 η∈𝒩（关节零位、连杆长度、刚度/阻抗、相机位姿）参数化，c=(τ,η)∈𝒞。重构原语 r:c→c′ 带时长 Δt_r、代价 κ_r、能耗 E_r、可逆标志 rev_r。有效重构需满足关节限位、自碰撞、负载与准静态稳定。按作用分三类：
- **传感重构**：改变观测矩阵 S_c（转腕改变视角、换指位改变接触斑投影、移动相机基线）；
- **刚度/阻抗重构**：改变力耦合 B_c 与柔顺性（切换串联弹性、改变阻抗增益）；
- **工具重构**：改变接触物理，通常不可逆（更换末端、切割、粘接）。
**关键**：重构不是"另一个动作"，它改变的是「故障如何进入观测」，因此是归因实验的自变量。

**定义 235（配置索引签名族）** 在配置 c 下，阶段化签名期望满足
E[ρ|c,θ,β]=S_cθ+B_cβ，ε∼N(0,Σ_ρ)，
其中 θ 为建模故障幅度（几何/力/模型/视觉/策略），β 为同时污染视觉与力/几何的共模 nuisance（透明、镜面、反光、对抗 patch、整机标定偏移、共因 OOD 物体）。S_c、B_c 由离线故障注入与真机标定台拟合，**每个矩阵携带标定版本号与参数不确定度 Σ_{S_c},Σ_{B_c}**。若标定不确定度大，定义 239 的检验阈值随之放宽，并把该不确定度计入 J_dmorph。

**定义 236（配置差分与共模可剔除性）** 对配置序列 c_{1:L}，堆叠观测
ρ̄=S̄θ+B̄β+ε̄，S̄=[S_{c_1};…;S_{c_L}]，B̄=[B_{c_1};…;B_{c_L}]。
记 P 为到 null(B̄ᵀ) 的正交投影（PB̄=0）。
- **投影可辨识**：PS̄ 列满秩且 J_cm=S̄ᵀPΣ_ρ⁻¹PS̄≻0；
- **联合可辨识**：[S̄ B̄] 列满秩。
二者的直觉：单配置下 θ 与 β 的列共线时秩坍缩（第 65 轮 A88 的线性代数本质）；多配置让 B_c 与 S_c 随 c 改变，列空间张开，θ 要么被投影净化、要么与 β 一起被估计。差分形式 Δρ=ρ(c)−ρ(c′)=(S_c−S_{c′})θ+(B_c−B_{c′})β；当 B_c=B_{c′} 时 β 被严格消掉。

**定义 237（配置实验设计 CED）** 选择（可自适应）重构序列 π_c=(c_1,…,c_L)：
max_{π_c} logdet(Σ_l S_{c_l}ᵀΣ_ρ⁻¹S_{c_l}) − λ_kΣκ_r − λ_tΣΔt_r
s.t. 可达、Valid(RCC)、时间预算；不可逆步骤要求后验集中度/熵阈值。
非自适应版本用贪心边际增益/成本：c_{l+1}=argmax_c [logdet(J_l+S_cᵀΣ⁻¹S_c)−logdet(J_l)−λ_kκ_r]/Δt_r。自适应版本以当前后验熵为状态做一步前瞻。**CED 的产物不是一个动作，而是一组让假设彼此分开的位形。**

**定义 238（扩展故障假设）** ℋ⁺=ℋ∪{H_common, H_reconf, H_unknown}：
- **H_common**：残差落在 range(B̄) 的共模分布外源（视觉与几何共享同一 OOD 源）；
- **H_reconf**：重构诱发的标定漂移、机构卡滞、拓扑错配、黑窗污染；
- **H_unknown**：不属于任何建模列的复合未知故障。
关键设计：**H_unknown 不被枚举**，它由定义 239 的残差通道被发现——这使系统不再需要"假设表完备"。

**定义 239（共模/未知故障两通道差分检验）** 在投影空间拟合 θ̂ 后取残差 r=ρ̄−S̄θ̂，分解
r_∥=P_{range(B̄)}r，r_⊥=Pr，T_cm=‖r_∥‖²/σ²，T_un=‖r_⊥‖²/σ²。
判据：
- T_un>χ²_{1−α_un} → `unmodeled_structured`：未知结构化故障（非共模），升级重构以改变 B̄；
- 仅 T_cm>χ²_{1−α_cm} → `common_mode`：拒绝强行归因，膨胀共模球 r_cm 或继续配置实验；
- 两者皆低 → 标准 CDF 后验。
**这一条直接替代第 65 轮「把未知复合故障塞进最近假设」的失败模式。**

**定义 240（扩散块策略 DPP）** π_ψ(A_t|s_t,c) 为条件去噪扩散/流匹配策略，输出块 A_t∈ℝ^{H×d_a}。采样 M 个模式 {A^{(m)}}，模式间离散度 u_mode 作为 H_policy 的补充证据；每个模式可对应不同策略或重构分支。块间一致性 d_chunk 沿用定义 219。与第 65 轮 ACH 的差别：ACH 是单峰块预测 + 集成，DPP 是**多峰生成**，天然覆盖"多种可能策略/位形"。

**定义 241（约束引导去噪与安全投影）** 去噪步 t 在基础均值 μ_θ 外加入引导
g=λ_s∇_a g_safe(a;post,c)+λ_i∇_a g_info(a;post,c)，
或直接投影 a_{t−1}←Proj_{𝒮(post,c)}(a_{t−1})，𝒮 为力/速度/工作空间/形变约束的交集。引导只改变采样偏向，**不承担安全证明**；最终样本一律经 CSC-D 认证。相比第 65 轮"先生成再过滤"，引导把安全注入生成分布，减少分布外拒绝与自信危险样本。

**定义 242（分辨率-前缀对齐）** 去噪步数 T′≤T 给出块的分辨率；分辨率受限视界 k_res(T′) 关于 T′ 单调不减。认证前缀
k*=min(m, k_res(T′), CSC-D 允许的最大值)。
于是「算得越久 → 可承诺越远，但永不越过不可逆视界 m」。这把第 65 轮"长预测、短执行"从空间轴扩展到**计算轴**：计算紧张时系统自动更保守。

**定义 243（生成式判别实验 GPE）** 条件生成分布 p_ψ(ξ|post)，ξ=(c′,探针轨迹 a_{1:L})。采样 K 个候选，用廉价代理估计期望信息增益 I(ℋ⁺;ρ(ξ)|post) 与安全可行性（f_n≤f_safe、形变≤ε_strain、Valid(RCC)），取可行且增益最大者 ξ*。若最大增益<δ_fi 或无可行样本，退回枚举安全探针/被动观测。**实验空间从离散表变为可约束的连续生成分布。**

**定义 244（重构安全证书 RCC）** Valid(RCC(c→c′)) ⇔
(i) 准静态先决：f_n≤f_q、滑移裕度≥0、抓取稳定（或机构允许动态重构）；
(ii) 可达且无自碰撞、负载/能耗在限；
(iii) 规划瞬态黑窗 [t_r,t_r+Δt_r]：期间仅硬限（力矩/力上限、看门狗、急停）生效，认证执行暂停；
(iv) 后重标定：零力窗 + 视觉重配准完成前不得恢复 J 认证执行；
(v) 不可逆重构需满足更高证据阈值（后验集中/熵上界）；
(vi) 卡滞/超时有回滚方案。
RCC 是"重构本身也要被安全带约束"的形式化，避免把重构当免费午餐。

**定义 245（配置感知 CSC-D 与黑窗）** CSC-D 在当前 c 与后验 post 上认证 k*；若前缀内将触发重构，则前缀截断在重构起点；黑窗写入证书 `blackout_flag=True`；后重构必须先跑零力窗 + 视觉重配准，避免 H_reconf 被误判为 H_force/H_geo。黑窗内的唯一安全保证是硬限看护，不声称任何语义归因。

**定义 246（RSC-D 归因定向球扩展）** 球集 {r_geo,r_force,r_model,r_vis,r_cm,r_reconf}，只膨胀被归因者：
- H_common→r_cm↑，并提高对应方向的 Σ_ρ（降低对差分证据的信任）；
- H_reconf→r_reconf↑ + 强制重标定；
- H_unknown→联合保守膨胀 + 要求配置实验或 safe_idle；
- 其余沿用第 65 轮 RSC-V。
融合 r=√(Σ r_i²) 进 WCV-D，避免「一坏全膨胀」的过度保守。**共模只膨胀共模球，几何与力仍保持各自的精度**——这是对第 65 轮误降级的进一步修复。

**定义 247（AIC-D 生成式干扰认证）** 干扰不再只靠枚举 ℰ_V，而用生成式对抗 p_φ(ε)（扩散/流）采样复合 OOD，并叠加最坏情况搜索；新增 ℰ_reconf（标定漂移、卡滞、拓扑错配、黑窗传感器污染）。认证 = 采样估计 + 最坏包络；证书带 gen_adv_hash、reconf_calib_ver。建模目标从"覆盖有限扰动列表"升级为"覆盖一个可采样的对抗分布"。

**定义 248（J_dmorph 证书）** J_dmorph=(J_vista, config_trace, diff_signature, cm_test, unmodeled_flag, reconfig_cert, blackout_flag, guidance_hash, denoise_steps, mode_diversity, aic_d_ver)。验证规则：
Valid(J_dmorph) ⇔ Valid(J_vista)
∧ config_trace 每步 Valid(RCC)
∧（若 unmodeled_flag 则未执行未经重构的归因）
∧ 黑窗内只硬限
∧ 后重构重标定完成
∧ 未把 common_mode 当作建模故障
∧ denoise_steps 与 k* 满足分辨率-前缀约束
∧ aic_d_ver 为当前版本。
审计链新增：为什么换这个位形（CED 信息增益）、差分检验怎么判（cm_test）、是否出现未知故障（unmodeled_flag）、重构是否安全（reconfig_cert）、黑窗是否干净（blackout_flag）。

**定义 249（D-MORPH 闭环算子）** 见 IP-233 伪代码。语义流：[VISTA 前段→配置索引签名→两通道差分检验→(ambiguous/unknown→CED 选配置 + GPE 生成实验)→RCC→执行重构(黑窗)→重标定→重归因→DPP 生成块+引导去噪→CSC-D→WCV-D→CSP-D 块规划→Shield-Skill→OCB-Skill→执行 k*→EV_exec→RSC-D→OLP→AIC-D]；实时流：[硬限看护→短前缀派发→黑窗看护→重标定触发→J_dmorph 构建]。

### IP-224/232 CDF 两通道差分归因

```python
class ConfigDifferentialAttribution:
    """多配置堆叠签名 → 投影/联合拟合 → 共模与未知结构化分离。语义流。"""

    def __init__(self, S_of, B_of, Sigma, alpha_cm=0.01, alpha_un=0.01,
                 delta_fi=0.15, kappa_infl=2.0):
        self.S_of, self.B_of, self.Sigma = S_of, B_of, Sigma
        self.alpha_cm, self.alpha_un, self.delta_fi = alpha_cm, alpha_un, delta_fi
        self.kappa_infl = kappa_infl

    def _stack(self, configs):
        S = np.vstack([self.S_of(c) for c in configs])
        B = np.vstack([self.B_of(c) for c in configs])
        return S, B

    def attribute(self, rhos, configs):
        S, B = self._stack(configs)
        # 联合最小二乘：θ, β 一起估计（共线时退化为投影解）
        A = np.hstack([S, B])
        theta_beta, *_ = np.linalg.lstsq(A, rhos, rcond=None)
        theta_hat = theta_beta[:S.shape[1]]
        r = rhos - S @ theta_hat
        # 共模方向子空间与正交补
        Pb = orthogonal_projector(B)              # range(B) 投影
        r_par, r_perp = Pb @ r, r - Pb @ r
        T_cm = float(r_par @ r_par / SIGMA2)
        T_un = float(r_perp @ r_perp / SIGMA2)
        if T_un > chi2_quantile(1 - self.alpha_un, dof_un):
            return {'flag': 'unmodeled_structured', 'T_un': T_un, 'T_cm': T_cm}
        if T_cm > chi2_quantile(1 - self.alpha_cm, dof_cm):
            return {'flag': 'common_mode', 'T_un': T_un, 'T_cm': T_cm}
        post = self._cdf_posterior(rhos, S, B, configs)
        h_star = max(post, key=post.get)
        return {'flag': 'attributed', 'post': post, 'h_star': h_star,
                'ambiguous': post[h_star] < 1.0 - self.delta_fi}

    def _cdf_posterior(self, rhos, S, B, configs):
        # 在配置索引似然下做贝叶斯归因；H_common 作为 nuisance 假设参与边缘化
        logp = {}
        for h in HYP_PLUS:
            mu = S @ theta_h(h) if h != 'H_common' else np.zeros_like(rhos)
            resid = rhos - mu
            logp[h] = -0.5 * float(resid @ inv(self.Sigma) @ resid) + np.log(prior(h))
        z = np.array(list(logp.values())); z -= z.max()
        return {h: float(np.exp(v) / np.exp(z).sum()) for h, v in logp.items()}
```

### IP-225 CED 配置实验设计

```python
def ced_select(configs_reachable, cur_c, Sigma, budget, rcc,
               S_of, cost_of, time_of, lam_k=1.0, lam_t=1.0):
    """贪心选择让可辨识性最大的重构序列；logdet 次模 → (1-1/e) 近似。"""
    J = np.zeros((d_theta, d_theta))
    seq, spend = [], 0.0
    while spend < budget:
        best, best_gain = None, -np.inf
        for c in configs_reachable:
            if not rcc.valid(cur_c, c):
                continue
            Sc = S_of(c)
            gain = (np.log(np.linalg.det(J + Sc.T @ inv(Sigma) @ Sc) + 1e-12)
                    - np.log(np.linalg.det(J) + 1e-12)
                    - lam_k * cost_of(c)) / max(time_of(c), 1e-6)
            if gain > best_gain:
                best, best_gain = c, gain
        if best is None:
            break
        J = J + S_of(best).T @ inv(Sigma) @ S_of(best)
        seq.append(best); spend += time_of(best); cur_c = best
    return seq, J
```

### IP-226/228 DPP + 引导去噪 + 分辨率-前缀

```python
class GuidedDiffusionPolicy:
    """条件扩散块策略；引导只改变偏向，安全由 CSC-D 兜底。"""

    def propose(self, state, c, post, T_denoise, T_exec):
        a = sample_gaussian_prior(H, d_a)
        for t in reversed(range(T_denoise)):
            eps = self.net(a, t, cond=(state, c, post))
            a = self.ddim_step(a, eps, t)
            a = a + LAMBDA_S * self.grad_safe(a, post, c) \
                  + LAMBDA_I * self.grad_info(a, post, c)
            a = project_safe(a, post, c)          # 力/速度/形变/工作空间
        k_res = self.resolution_horizon(T_exec)   # T_exec ≤ T_denoise
        return a, k_res, self.mode_diversity(a)
```

```python
class GenerativeProbeExperiment:

    def choose(self, post, cur_c, rcc, f_safe, object_fragile, K=64):
```

```python
class ReconfigurationCertificate:
    def valid(self, c_from, c_to, state, evidence):
        if not reachable(c_from, c_to):
            return False
        if not (no_self_collision(c_from, c_to)
                and payload_ok(c_to, state) and energy_ok(c_to)):
```

```python
class ChunkSafetyCertificateD:
    def certified_prefix(self, A, post, c, m, T_exec, alpha_chunk, reconfig_at=None):
        k_res = resolution_horizon(T_exec)
        k_max = min(len(A), m, k_res)
        if reconfig_at is not None:
            k_max = min(k_max, reconfig_at)       # 前缀不得跨入重构黑窗
        k_best = 0
        for k in range(1, k_max + 1):
            if all(safety_margin(A[s], c, h) >= 0
                   for s in range(k) for h in top_support(post, 2)):
                if violation_prob(A[:k], post, c) <= alpha_chunk:
                    k_best = k
        return k_best
```

## 4. 推导

**引理 9（配置差分可辨识性）** 设多配置堆叠模型 ρ̄=S̄θ+B̄β+ε̄。θ、β 联合可辨识当且仅当 [S̄ B̄] 列满秩；若只关心 θ 而对 β 不作推断，取 P 为到 null(B̄ᵀ) 的投影，则 Pρ̄=PS̄θ+Pε，θ 投影可辨识当且仅当 PS̄ 列满秩且 J_cm=S̄ᵀPΣ_ρ⁻¹PS̄≻0。单配置 c 时，若 S_c 与 B_c 的列共线（如视觉与力被同一源以相同符号污染），[S_c B_c] 秩亏，θ 与 β 不可分。**二维示例**：θ 在两模态载荷 [1,1]ᵀ，β 在 c_1 也载荷 [1,1]ᵀ → 单配置秩 1、不可辨识；在 c_2 令 β 的力分量反号、载荷 [1,−1]ᵀ（换载荷路径/相机位姿使共模偏移在力通道反号），堆叠列 [1,1,1,1]ᵀ 与 [1,1,1,−1]ᵀ 线性无关 → 联合可辨识。∎

**引理 10（共模抑制条件与 CMRR）** 差分 Δρ=ρ(c)−ρ(c′)=(S_c−S_{c′})θ+(B_c−B_{c′})β。若 B_c=B_{c′}，β 项严格消失，θ 由 (S_c−S_{c′}) 的可辨识性决定；若 B_c≠B_{c′}，定义共模抑制比
CMRR=‖(S_c−S_{c′})θ‖ / ‖(B_c−B_{c′})β‖，
CMRR>1 表示差分把故障信号放在共模残差之上。CED 的目标之一就是选 c,c′ 使 CMRR 与 J_cm 同时增大。**这把第 65 轮「视觉与几何必须独立」替换为「重构必须改变共模耦合」——一个可标定、可设计、可否证的条件。**∎

**引理 11（两通道检验的功效）** 在正确模型下，T_cm∼χ²_{rank(B̄)}，T_un∼χ²_{m−rank(B̄)}（m 为堆叠观测维数）。若真实故障含未被建模的 ζ，则 r 在 null(B̄ᵀ) 上的投影能量为非中心度 λ_un=‖P S̄ θ_ζ‖²/σ²；T_un 的检出功效随 λ_un 单调增。配置多样性通过缩小 null(B̄ᵀ) 的维数或旋转其方向提高 λ_un。因此 CED 不仅提高 θ 的可辨识性，也提高**未知复合故障的检出率**；反之若 ζ 完全落在 range(B̄) 内，则它与共模源观测等价，系统正确地判 `common_mode` 并膨胀 r_cm，而不是错误归因。∎

**定理 9（D-MORPH 超出有限假设的安全）** 对任意（可能属于 ℋ⁺ 之外的）故障 ζ，在 CED 选出的配置下必居其一：
(i) T_un 或 T_cm 超阈 → 不强行归因，转重构、GPE 或安全降级；
(ii) ζ 与某个 H∈ℋ⁺（含 H_common）观测等价 → CSC-D 在该假设的支持集上取最坏，证书仍覆盖真实风险。
由联合界，Valid(J_dmorph) ⇒ 单块越界概率 ≤ α_chunk+δ_fi+α_vis+α_cm+α_reconf。**核心：无需假设表完备；只需「可检出」或「与已建模假设安全等价」。**∎

**定理 10（重构不放大风险 + 可辨识性单调）** (a) 若 Valid(RCC) 且黑窗只保留硬限、后重标定完成后才恢复认证执行，则重构瞬态贡献的风险 ≤α_reconf，且黑窗内不存在任何错误的语义承诺；(b) 不可逆重构经证据阈值门控，避免在归因未定时做不可逆改变；(c) J({c_1:L})=Σ_l S_{c_l}ᵀΣ_ρ⁻¹S_{c_l} 是 PSD 之和，增加配置不会降低可辨识性（可能提高条件数），只增加时间成本，故预算约束下最优存在。∎

**定理 11（引导扩散的近安全 + 分辨率-前缀）** (a) 若安全集 𝒮 凸且 Proj_𝒮 非扩张，末端投影后样本落在 𝒮 的概率 ≥1−α（把引导误差计入 α）；非凸时用接受/拒绝并计入拒绝率。(b) k_res(T′) 关于去噪步数 T′ 单调不减，且 k*≤min(k_res,m)，故早停只缩短承诺、不会加深承诺——计算紧张时系统自动更保守。结合定理 8（VISTA），"长预测、短执行"扩展为"充分去噪、有限承诺"。∎

**命题（CED 贪心近似）** 目标 f(𝒮)=logdet(J_0+Σ_{c∈𝒮}S_cᵀΣ⁻¹S_c) 在配置集合上单调次模；在基数/预算约束下贪心达到 (1−1/e) 的 oracle 近似。自适应版本以一步前瞻换取对后验的利用，牺牲最坏近似保证但通常更省重构次数。∎

**命题（共模不误降级几何）** 第 65 轮在任意 CGG 拒绝时膨胀单一 r，几何被误降级；RSC-D 在 H_common 时只膨胀 r_cm，r_geo 与 r_force 保持，故几何搜索域不被共模污染。若真实故障确为共模而几何正确，VISTA 的条件数恶化被避免，同时共模不确定性被正确隔离到 r_cm。∎

**正确性定理（D-MORPH-Complete）** 见定理 9。核心是把第 65 轮"有限假设归因"升级为"**可检出或安全等价的配置差分归因**"：不再要求故障在表内，也不要求视觉与几何独立；只要求重构能改变共模耦合，且重构本身被 RCC 与黑窗约束。

## 7. 已知风险

**一句话**：D-MORPH 的配置差分归因依赖「各配置下的耦合矩阵 S_c、B_c 已知且标定可信」，而这两个矩阵恰恰是学习的/标定的——一次错误或漂移的重构标定会同时污染差分证据与共模检验，使系统把「重构诱发的共模故障」误读成「健康或已归因」，于是第 65 轮的虚假自信被升级为「用错误的身体证据为错误归因背书」，这是本轮可辨识性、RCC 与 J_dmorph 全部依赖的隐藏假设（A94）。

**次级风险与缓解**：
1. **重构标定漂移/错误**：S_c、B_c 可能过时；缓解：每次重构强制零力窗 + 视觉重配准 + 标定版本校验；把 Σ_{S_c},Σ_{B_c} 计入检验阈值；漂移检测触发重标定或拒绝差分归因。
2. **共模耦合不可区分**：若某共模源在所有可达配置下耦合不变（B_c≡B），差分无法消 β；缓解：CED 显式最大化 B_c 的变化，若可达集内无法改变耦合则判 `common_mode` 并保守膨胀，绝不强行归因。
3. **配置实验的成本/风险**：重构耗时、可能不可逆、瞬态不可控；缓解：RCC 门控 + 黑窗硬限 + 不可逆高阈值 + 预算化 CED；预算不足时退回被动观测。
4. **扩散实验/动作分布外**：生成模型可能自信地提出误导性探针或危险块；缓解：可行性与 RCC 先行过滤，CSC-D 后置认证，引导只降违规不作证明；保留枚举安全探针兜底。
5. **引导破坏采样保证**：投影/引导使扩散不再精确；缓解：只把它当提议器，最终安全由证书承担；必要时用拒绝采样并计入 α。
6. **分辨率-前缀的单调性假设**：k_res(T′) 需经验校准，可能非严格单调；缓解：保守取上包络，T′ 与 k* 联合标定，违规即回退到固定小 k。
7. **生成式对抗认证的覆盖幻觉**：采样对抗可能漏掉最坏；缓解：生成采样 + 最坏搜索双轨，证书同时记录 gen_adv_hash 与手工扰动版本。
8. **实时预算**：黑窗看护 + CSC-D 逼近 2.6ms；缓解：硬限做成独立看门狗线程、CSC-D 只在前缀边界计算、重构与扩散全部留在语义流。
9. **配置组合爆炸**：|𝒞| 随模块数指数增长；缓解：可达集剪枝 + 连续参数用梯度/贝叶斯优化 + 只保留与当前后验相关的候选。
