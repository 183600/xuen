### 第 2 轮灵感驱动研究记录

**灵感词**：双臂协作、意图识别

**直觉与动机**：
现有 v25（SRC-USC）把多机器人建模为「松散耦合的独立智能体」，靠分布式一致性/时空避障/纳什均衡协调。但双臂协作本质不同：两臂共同持物时形成**闭运动链**，被同一个刚性或柔性物体约束成单一机构，不再相互独立。单臂 USMC 与多机 MCC 都无法刻画：(1) 闭链相对位姿的硬约束（两臂末端相对位姿必须严格保持，否则物体被拉/压变形）；(2) 只加载物体、不产生物体合运动的**内力**（抓取矩阵零空间分量）；(3) 双机相对雅可比的奇异与可操作度；(4) 共享工作空间中的自碰撞与共享负载。另一方面，v25 默认语义目标已知，而真实协作中伙伴的**意图是隐变量**，必须从交互观测反推；证书链必须为「意图误判」这一统计风险定量兜底，并处理意图随时间的漂移与共享自治下的权限仲裁。核心洞见：**双臂协作是意图耦合的物理化身——两臂既要在语义上对共享意图达成一致（意图识别提供语义胶水），又要用位姿/力一致性持续证明这种一致（闭链证书提供物理胶水）。**

**形式化目标**：
1. 定义双臂协作证书（DACC）：闭链相对位姿 ‖log(T_rel⁻¹T_rel*)‖ ≤ ε_rel；内力投影 ‖N NᵀF‖ ≤ F_int_max（N 为抓取矩阵零空间正交基）；相对雅可比 σ_min(J_rel) ≥ ε_manip；协同无源性 ∫(F_Lᵀv_L + F_Rᵀv_R)dt ≥ −E₀
2. 定义意图识别证书（IRC）：校准意图后验 top-1 ∈ conformal 预测集且风险 ≤ α_int；逆最优性间隙 R_opt − R_obs ≤ ε_irl；意图漂移 Δposterior ≤ ε_drift；共享自治仲裁 a = α_arb·a_h + (1−α_arb)·a_r 落在安全包络
3. 构建双臂-意图统一准入门（BIUC）：USMC ∪ SMC ∪ RMC ∪ MCC ∪ DACC ∪ IRC 九证一体，Exec_v26 = Exec_v25 ∩ Fil_bimanual ∩ Fil_intent ⊆ Exec_v25
4. 证明单调退化链在闭链失配/内力超限/相对奇异/意图误判/意图漂移下的保持性

```python
# ============================================================
# IP-448 Dual-Arm Coordination Certificate (DACC) — 双臂协作证书
# ============================================================
@dataclass
class DualArmCoordinationCertificate:
    """闭链约束 + 内力分配 + 相对可操作度 + 协同无源性"""
    T_rel_des: Tensor            # [T,4,4] 期望相对位姿 T_L^{-1} T_R
    T_rel_act: Tensor            # [T,4,4] 实际相对位姿
    F_L: Tensor                  # [T,6] 左臂末端 wrench
    F_R: Tensor                  # [T,6] 右臂末端 wrench
    J_L: Tensor                  # [T,6,n_L] 左臂几何雅可比
    J_R: Tensor                  # [T,6,n_R] 右臂几何雅可比
    v_L: Tensor                  # [T,6] 左臂末端 twist
    v_R: Tensor                  # [T,6] 右臂末端 twist
    eps_rel: float = 1e-3        # 闭链相对位姿容差 (m/rad)
    F_int_max: float = 50.0      # 内力上界 (N)
    eps_manip: float = 0.05      # 相对雅可比最小奇异值下界
    E0: float = 1.0              # 协同无源储能上界 (J)

    def verify_closed_chain(self) -> bool:
        """‖log_SE3(T_rel_des^{-1} T_rel_act)‖ ≤ ε_rel, ∀t"""
        for t in range(len(self.T_rel_des)):
            err = se3_log(se3_inv(self.T_rel_des[t]) @ self.T_rel_act[t])
            if torch.norm(err) > self.eps_rel:
                return False
        return True

    def verify_internal_force(self, grasp_matrix: Tensor) -> bool:
        """内力落在抓取矩阵零空间：F_int = N N^T F，‖F_int‖ ≤ F_int_max
        G ∈ R^{6×12}，N 为 G 的零空间正交基（只加载物体、不产生合运动）"""
        for t in range(len(self.F_L)):
            G = grasp_matrix[t]                      # [6,12]
            N = null_space(G)                        # [12,k]
            F = torch.cat([self.F_L[t], self.F_R[t]])
            F_int = N @ (N.T @ F)
            if torch.norm(F_int) > self.F_int_max:
                return False
        return True

    def verify_relative_manipulability(self) -> bool:
        """J_rel = [−Ad(T_R^{-1}T_L) J_L, J_R]，σ_min(J_rel) ≥ ε_manip"""
        for t in range(len(self.J_L)):
            J_rel = self._relative_jacobian(t)
            if torch.linalg.svdvals(J_rel).min() < self.eps_manip:
                return False
        return True

    def verify_coordinated_passivity(self) -> bool:
        """∫(F_L^T v_L + F_R^T v_R) dt ≥ −E_0（耦合阻抗无源性）"""
        power = (self.F_L * self.v_L).sum(-1) + (self.F_R * self.v_R).sum(-1)
        energy = torch.cumsum(power, dim=0)
        return bool(energy.min() >= -self.E0)

    def _relative_jacobian(self, t: int) -> Tensor:
        Ad = adjoint(se3_inv(self.T_rel_act[t]))
        return torch.cat([-Ad @ self.J_L[t], self.J_R[t]], dim=1)

    def verify_all(self, grasp_matrix: Tensor) -> bool:
        return (self.verify_closed_chain() and
                self.verify_internal_force(grasp_matrix) and
                self.verify_relative_manipulability() and
                self.verify_coordinated_passivity())

# IP-449 Intent Recognition Certificate (IRC) — 意图识别证书
# ============================================================
@dataclass
class IntentRecognitionCertificate:
    """校准意图后验 + 逆最优性间隙 + 意图漂移 + 共享自治安全"""
    goals: list['Goal']                  # 候选意图集 𝒢
    posterior: Tensor                    # [T,|𝒢|] ℙ(g|𝒟_t)
    observations: Tensor                 # [T,d_obs] 交互观测序列
    alpha_int: float = 0.05              # 意图误判风险
    eps_irl: float = 0.1                 # 逆最优性间隙容差
    eps_drift: float = 0.2               # 后验漂移阈值
    authority: float = 0.5               # 人类权限 α_arb
    calibrator: 'ConformalCalibrator' = None

    def verify_intent_confidence(self) -> bool:
        """top-1 意图落入 conformal 预测集：ℙ(g* ∈ C(x_t)) ≥ 1-α_int"""
        if self.calibrator is None:
            return False
        for t in range(len(self.posterior)):
            C_t = self.calibrator.predict(self.observations[t])
            top = int(torch.argmax(self.posterior[t]))
            if top not in C_t:
                return False
        return True

    def verify_inverse_optimality(self, reward_model) -> bool:
        """R_opt(g*) − R_obs(τ_{≤t} | g*) ≤ ε_irl：观测近似 g* 的最优演示"""
        for t in range(1, len(self.observations) + 1):
            g_star = int(torch.argmax(self.posterior[t-1]))
            R_obs = reward_model.discounted_return(self.observations[:t], g_star)
            R_opt = reward_model.optimal_return(g_star)
            if R_opt - R_obs > self.eps_irl:
                return False
        return True

    def verify_intent_drift(self) -> bool:
        """相邻时刻后验 L1 变化 ≤ ε_drift；超阈须触发重识别/接管"""
        if len(self.posterior) < 2:
            return True
        delta = (self.posterior[1:] - self.posterior[:-1]).abs().sum(-1)
        return bool(delta.max() <= self.eps_drift)

    def verify_shared_autonomy_safety(self, a_human: Tensor,
                                      a_robot: Tensor, envelope) -> bool:
        """a = α_arb a_h + (1−α_arb) a_r ∈ 安全包络"""
        a = self.authority * a_human + (1 - self.authority) * a_robot
        return bool(envelope.contains(a))

    def verify_all(self, reward_model, a_human, a_robot, envelope) -> bool:
        return (self.verify_intent_confidence() and
                self.verify_inverse_optimality(reward_model) and
                self.verify_intent_drift() and
                self.verify_shared_autonomy_safety(a_human, a_robot, envelope))

# 辅助函数
def se3_inv(T: Tensor) -> Tensor:
    """SE(3) 逆：R^T, −R^T t"""
    R, t = T[:3, :3], T[:3, 3]
    Ti = torch.eye(4, device=T.device, dtype=T.dtype)
    Ti[:3, :3] = R.T
    Ti[:3, 3] = -R.T @ t
    return Ti

def se3_log(T: Tensor) -> Tensor:
    """SE(3) 对数映射到 6 维 twist（旋转用 axis-angle，平移用 V^{-1}）"""
    R, t = T[:3, :3], T[:3, 3]
    theta = torch.acos(torch.clamp((torch.trace(R) - 1) / 2, -1.0, 1.0))
    if theta.abs() < 1e-6:
        omega = torch.zeros(3, device=T.device, dtype=T.dtype)
        V_inv = torch.eye(3, device=T.device, dtype=T.dtype)
    else:
        omega = theta / (2 * torch.sin(theta)) * torch.stack(
            [R[2,1]-R[1,2], R[0,2]-R[2,0], R[1,0]-R[0,1]])
        K = hat(omega)
        V_inv = (torch.eye(3, device=T.device, dtype=T.dtype)
                 - 0.5 * K
                 + (1/theta - 0.5 / torch.tan(theta/2)) / theta * (K @ K))
    return torch.cat([V_inv @ t, omega])

def hat(w: Tensor) -> Tensor:
    return torch.tensor([[0, -w[2], w[1]],
                         [w[2], 0, -w[0]],
                         [-w[1], w[0], 0]], device=w.device, dtype=w.dtype)

def adjoint(T: Tensor) -> Tensor:
    """SE(3) 伴随矩阵 Ad_T = [[R, 0],[hat(t)R, R]]"""
    R, t = T[:3, :3], T[:3, 3]
    Ad = torch.zeros(6, 6, device=T.device, dtype=T.dtype)
    Ad[:3, :3] = R
    Ad[3:, 3:] = R
    Ad[3:, :3] = hat(t) @ R
    return Ad

def null_space(G: Tensor, eps: float = 1e-6) -> Tensor:
    """抓取矩阵零空间正交基（SVD 取近零奇异值对应右奇异向量）"""
    _, s, Vh = torch.linalg.svd(G)
    rank = int((s > eps).sum())
    return Vh[rank:].T   # [12, 12-rank]
```

## 3. 正确性论证（增量）

### 引理 13（双臂协作证书的闭链-内力-可操作-无源四重保证）
**陈述**：`DACC.verify_all(G) = True` ⟺ 双臂系统同时满足：
(1) 闭链相对位姿：‖log(T_rel⁻¹T_rel*)‖ ≤ ε_rel，物体不被拉压变形；
(2) 内力有界：‖N NᵀF‖ ≤ F_int_max，抓取不挤碎/滑脱；
(3) 相对可操作度：σ_min(J_rel) ≥ ε_manip，双机不进入相对奇异；
(4) 协同无源性：∫(F_Lᵀv_L+F_Rᵀv_R)dt ≥ −E₀，耦合阻抗不注入能量。

**证明**：
1. 闭链误差取 SE(3) 对数范数，是相对位姿偏离的等变度量；ε_rel 由物体刚度与允许应变反推（刚性物体 ε_rel→0，柔性物体按胡克定律放宽）。
2. 抓取矩阵 G 的列空间张成可产生物体合运动的 wrench 子空间，其零空间正交基 N 张成内力子空间；F_int=N NᵀF 恰为 F 中不改变物体合运动的分量，故上界直接约束挤压载荷。
3. J_rel 把关节速度映射到相对 twist；σ_min 是相对运动的最坏方向增益，低于阈值即相对奇异，闭链约束无法维持。
4. 无源性条件由耦合阻抗储能函数 V=½ΔxᵀKΔx 的时间导数给出，能量积分非负下界保证不向系统注入净能量，与引理 6（FCC）的端口哈密顿论证同构，只是端口扩展为双臂并联。
四条件分别对应「几何可行 / 载荷安全 / 运动可行 / 能量安全」，缺一不可。
∎

### 引理 14（意图识别证书的校准-逆最优-漂移-仲裁四重保证）
**陈述**：`IRC.verify_all(...) = True` ⟺ 意图推断同时满足：
(1) 校准置信：top-1 意图 ∈ conformal 预测集，误判风险 ≤ α_int；
(2) 逆最优性：R_opt(g*) − R_obs ≤ ε_irl，观测与推断意图自洽；
(3) 漂移可控：Δposterior ≤ ε_drift，意图在时间上稳定；
(4) 仲裁安全：a = α_arb a_h + (1−α_arb) a_r ∈ 安全包络。

**证明**：
1. conformal prediction 的边际覆盖定理（Vovk et al. 2005）保证 ℙ(g*∈C(x))≥1−α_int，前提是校准集与测试集可交换；`verify_intent_confidence` 逐时刻检验 top-1 是否被覆盖。
2. 逆最优性间隙是逆强化学习（IRL）的可辨识性判据：若观测轨迹显著劣于推断意图的最优回报，说明后验选错了意图或人类非理性，此时不应据此认证。
3. 后验 L1 漂移阈值把「意图突变」显式建模为切换点；超阈即触发重识别或人类接管，避免用旧意图认证新行为。
4. 仲裁动作是凸组合，α_arb∈[0,1] 保证落在人机动作的凸包内；再与安全包络取交，保证混合动作不越界。
四条件分别对应「统计正确 / 行为自洽 / 时序稳定 / 执行安全」。
∎

### 引理 15（九位一体单调退化链终极延伸）
**陈述**：任意单点/组合失效下，`Exec_v26 ⊆ Exec_v25 ⊆ … ⊆ Exec_v18` 恒成立。

**证明**：在引理 12 基础上增加四条退化路径：
- 闭链失配/内力超限/相对奇异 → `DACC.verify_all=false` → `BIUC` 拒证 → 退回 `Exec_v25`（放弃双臂协同，仅单臂抓取，另一臂退回安全位）；
- 意图误判（置信未覆盖/逆最优性破缺）→ `IRC.verify_all=false` → `BIUC` 拒证 → 退回 `Exec_v25`（冻结自主推断，切换全人控 α_arb=1 或保守停机）；
- 意图漂移超阈 → 触发重识别窗口，重识别期间按旧意图的保守包络运行，不进入 `Exec_v26`；
- 组合失效（双臂×意图×七证）→ 取交集，单调性保持。
∎

**陈述**：对任意双臂-意图计划 Π，`BIUC.admits(Π) = True` ⟺ Π 同时满足 v25 的十项条件（物理接地/云边一致/少样本覆盖/专利保护/结构/力控/轻量化/语义/重构/协同）以及：
(11) 闭链相对位姿、内力、相对可操作度、协同无源性四项达标，

**证明**：直接由 `BIUC.admits` 的连言结构与引理 1–3、5–7、9–11、13–14 可得。必要性：任一条件缺失即拒证，对应十二类风险之一未缓解。充分性：十二条件全满足，由引理 4、8、12、15 保证执行集单调链与统计覆盖，构成从单机物理 → 群体智能 → 双臂闭链 → 人机意图的完整闭环。

## 6. 本轮最大风险（最终确认）

**一句话**：**DACC 的刚性闭链假设在柔性/大形变物体下失效、IRC 的 conformal 意图覆盖在分布漂移或非理性伙伴下失准——当「柔性物体闭链」与「意图突变」同时发生时，闭链证书会因物体形变误报失配而拒绝一切协作，或反过来在慢形变中漏报内力超限，而意图证书可能仍用旧后验错误认证新意图，二者叠加使 BIUC 在「物理耦合已失稳 + 语义意图已漂移」的双重隐蔽故障下错误放行，击穿九位一体单调退化链的事前拦截承诺。**
