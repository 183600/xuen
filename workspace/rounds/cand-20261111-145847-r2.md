# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；本轮灵感：「Gazebo」×「面部表情识别」）

> 第 54 轮把技能组合与云边部署建立在动作空间剖面 α_S 与联合证书 J 上，但它把「环境（包括人）」当作**被动、与动作无关的测试 oracle**：技能执行不改变被观测对象，证书一旦成立就稳定。Gazebo 把机器人放进一个**可编程干预、可复现回放、可对抗随机化**的闭环世界；面部表情识别（FER）则把「人」变成一个**会因机器人动作而改变、且表面表情与内部状态可能解耦**的观测对象。二者合起来暴露第 54 轮的两个隐含假设：H22：**可观测性是外生的**——但读脸需要转头、靠近、注视，动作决定能否看见、看见的是否可读；H23：**表情是状态的可靠读数**——但微笑可以是礼貌性面具，表情是策略性/社会性信号，直接优化表情会诱发 Goodhart。于是本轮把「动作-鲁棒性双证书」升级为**「动作-可观测-可识别」三证书**：证书不再只问「能否执行、是否鲁棒」，还要问「在当前动作下，能否从表情**因果地识别**人的潜在状态，且部署本身不会把状态推向不可识别区」。

## 0. 直觉与动机

**灵感 1（Gazebo → 从「测试场」升级为「反事实干预引擎」）**
直觉：Gazebo 的价值不只是高保真渲染，而是它能**对动作做 do 干预并保持其余条件逐位匹配**：同一个 avatar、同一段脚本、同一随机种子，只把机器人动作从 a 换成 a'，就能得到配对反事实。真实人类实验做不到这一点（不能把同一个人重放两次），而这正是**因果识别**最缺的数据。因此 Gazebo 是「替代人类配对实验」的引擎：它让「这个微笑是因为机器人打了招呼，还是因为这个人本来就爱笑」变得**可干预、可配对、可反驳**。但它是**证伪器而非确认器**：脚本化的人只能证明「某个技能在某个响应模型下失败」，不能证明「它在真人身上成立」。

**灵感 2（FER → 表情是「症状」，不是「状态」）**
直觉：FER 输出的是 AU / 情绪标签 / 效价-唤醒度，它是**潜在状态 z（舒适、信任、困惑、疲劳、投入）的表面症状**，而不是 z 本身。症状会被三件事污染：(i) **混淆**（个体基线、文化 display rules、任务语境）；(ii) **策略性表达**（礼貌性微笑、掩饰不适、对着机器人「表演」）；(iii) **动作依赖的可观测性**（过近导致惊退、俯视/遮挡导致看不清、凝视导致回避眼神）。所以「认得表情」≠「读得懂人」。

**灵感 3（把 α_S 的对偶 β_S 提出来：情感可观测剖面）**
直觉：第 54 轮的 α_S(a) 问「技能能否占用动作 a」；现在需要它的**人类侧对偶** β_S(z,a)：在动作 a 下，潜在状态 z 能否从表情观测 e 中被区分出来。β 是**互信息 / 贝叶斯风险意义下的可识别度**，且**随动作变化**：靠近提升分辨率却可能触发防御，凝视提升 AU 清晰度却可能引发回避。技能组合因此多了一条约束：不是「动作兼容」就够，而是「沿组合轨迹，β 始终不低于阈值」。

**灵感 4（表演性预测 → 部署会改变它要预测的分布）**
直觉：机器人一旦**按表情行动**，它就在**因果地改变**人的状态与表情分布——这正是 performative prediction。训练时采到的 (e,z) 与部署时策略 π(e) 诱导的分布不同；更糟的是人会**适应**：学会用社交微笑换取机器人停止追问。于是「表情奖励上升、潜在不适未降」的 **Goodhart 缺口**成为一等风险，证书必须显式包含「部署不动点」与「对抗性人类策略」下的界。

**灵感 5（金字塔再叠一层：社会-情感层 𝕊）**
直觉：在第 54 轮的动作-协同层 𝔸 之上加 𝕊：𝕊_0 物理社交极限（距离/视角/FOV），𝕊_1 技能的情感可观测剖面 β，𝕊_2 云边情感推断与不确定性回传，𝕊_3 任务级社会规范。跨层证书必须同时携带 ρ、A_cert、β、因果证书与 sim-real 情感迁移 gap。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（潜在情感状态与表情观测通道）**
人具有潜在状态 `z ∈ Z`（comfort / trust / confusion / fatigue / engagement 的联合），表情观测 `e ∈ E`（FACS AU 向量 + 效价-唤醒度 + 时序动态）。动作 `a ∈ A` 含**社交动作子空间** `A_s`（距离、朝向、注视、时序、手势、语速）。观测通道为 `P(e | z, a, h, c)`，h 为个体/文化属性，c 为任务语境；机器人推断器 `q_φ(z | e, a, c)`。

**定义 122（情感可观测剖面 β_S）**
技能 S 在动作 a 下对状态 z 的**可识别度**：
```
β_S(z,a) = 1 - H(z | e,a) / H(z)        （归一化互信息；或用 1 - BayesRisk/BayesRisk_prior）
```
`cover_aff(S, Z_T, a) = 1` 当且仅当 `∀ z∈Z_T, β_S(z,a) ≥ θ_aff`。β 是 α_S 的人类侧对偶，且**显式依赖动作**。

**定义 123（情感响应核与表演性差距）**
机器人动作对人状态的**情感响应核** `R(a,z) = E[z' - z | a, z]`。部署策略 `π(e)` 诱导的联合分布 `P_π(z,e)` 与观测策略 `P_obs(z,e)`（只观测、不据此行动）之差定义为**表演性差距** `PG(π) = W_1(P_π(z,e), P_obs(z,e))`。部署不动点 `π* = argmin_π E_{P_π}[ℓ(z, π(e))]`，要求在 `PG(π) ≤ ε_pg` 下求解。

**定义 124（因果情感证书）**
`C_aff = (ATE, CI, do-set, confounders, sim_fidelity)`：在 Gazebo 中对同一 avatar / 脚本 / 种子施加 `do(a)` 与 `do(a')` 的配对干预，估计动作对 z 的平均处理效应 `ATE = E[z | do(a)] - E[z | do(a')]` 及置信区间；`confounders` 记录被匹配的个体/文化/基线情绪；`sim_fidelity` 记录渲染与行为模型覆盖度。**可识别条件**：`CI` 不含 0，且 `confounders` 覆盖部署人群的关键分层。

**定义 125（表情-状态解耦集与 Goodhart 缺口）**
解耦集 `D_ε = {e : TV(P(z|e,a), P(z|a)) ≤ ε_e}`，即表情对状态几乎无信息（面具微笑、社交掩饰）。策略的 Goodhart 缺口 `G(π) = E_{P_π}[z] - E_{P_oracle}[z]`（oracle 直接优化 z）。**因果锚定条件**：`G(π) ≤ G_max` 且 `TV(∂r/∂e, ∂z/∂e) ≤ δ_anchor`，即优化目标对表情的梯度必须与真实状态对表情的因果梯度同向有界。

**定义 126（社会-情感联合证书与仿真证伪界）**
```
J_social = (ρ, A_cert, γ_ce, δ_a, β_S, C_aff, G, Δ_sim)
```
`Δ_sim = W_1(P_real(e,z|a), P_sim(e,z|a))` 为仿真-现实情感迁移 gap。部署条件：
```
dom_J(T)=in ∧ δ_a<Θ_a ∧ β_S≥θ_aff ∧ C_aff valid ∧ G≤G_max ∧ Δ_sim≤ε_sim
```
其中 `Δ_sim` **只能由外向人类校准给出**，仿真自身不能自证 `Δ_sim`。

## 2. 关键算法 伪代码

### IP-121 AOP（Affective Observability Profiling）
Gazebo 中参数化 avatar（FACS 控制器、display-rule 分布、头姿/遮挡/光照），对 `(z,a)` 网格做探针，用留出分类器估 β。

```python
def affective_profile(avatar, z_grid, a_grid, n_ep=200):
    beta = {}
    for z in z_grid:
        for a in a_grid:
            feats, labels = [], []
            for k in range(n_ep):
                seed = stable_seed(avatar.id, z, a, k)     # 配对可复现
                e = gazebo.render_expression(avatar, z, a, seed)
                feats.append(extract_au(e)); labels.append(z)
            clf = fit_holdout(feats, labels)
            beta[(z, a)] = 1 - bayes_risk(clf) / prior_risk(labels)
    return beta
```

### IP-122 GACE（Gazebo Affective Counterfactual Engine）
配对 do 干预 + 分层随机化 + 双重稳健 ATE。

```python
def affective_ate(avatar, action_pairs, strata, n=500):
    logs = []
    for h in strata:                          # 个体/文化/基线分层
        for s in range(n):
            seed = stable_seed(avatar.id, h, s)
            a, a2 = sample_pair(action_pairs)
            z0 = avatar.reset_state(h, seed)
            z_a  = rollout(avatar, a,  z0, seed).final_z
            z_b  = rollout(avatar, a2, z0, seed).final_z   # 同 z0、同 seed
            logs.append((h, a, a2, z_a - z_b, render(avatar, z_a),
                         render(avatar, z_b)))
    return doubly_robust_ate(logs), bootstrap_ci(logs)
```

### IP-123 PPC（Performative Perception Certificate）
在仿真里放一个**对抗性人类响应策略**（可学习地产生面具表情），求部署不动点并估 Goodhart 缺口。

```python
def performative_certificate(pi_robot, human_adv, z0, T):
    # 交替：机器人按 e 行动；人按 adv 选择表情策略以最小化被干预
    for t in range(T):
        e = human_adv.observe_and_emit(z0)
        a = pi_robot(e)
        z0 = human_adv.transition(z0, a)           # 人对动作的真实响应
        human_adv.update(goal='mask_discomfort')
    pg = wasserstein(deployed_traj, observational_traj)
    G  = mean(z_deployed) - mean(z_oracle)
    return ('ok' if pg <= eps_pg and G <= G_max else 'reject'), pg, G
```

### IP-124 AFT（Affect Falsification Test，Gazebo 证伪器）
按 Popper 不对称性：只在仿真里**找反例**，不确认。

```python
def falsify_affect_claim(claim, avatar_population, budget):
    # claim: “技能 S 在人群 P 上 β≥θ 且 G≤Gmax”
    for avatar in adversarial_sample(avatar_population, budget):
        beta = affective_profile(avatar, claim.Z, claim.A_s)
        if min(beta.values()) < claim.theta:
            return ('falsified', avatar, beta)
        if performative_certificate(claim.pi, mask_policy(avatar),
                                    claim.z0, claim.T)[0] == 'reject':
            return ('falsified', avatar, 'goodhart')
    return ('not_falsified', budget)      # 注意：不是 'certified'
```

### IP-125 SJC（Social Joint Certificate）
把社会情感项并入第 54 轮 J，并检查**组合轨迹上的 β 单调性**（组合不得把人推入低可观测区）。

```python
def social_joint_certificate(skill_seq, gamma_ce, J54, beta_map, causal, gap):
    J = J54
    beta_traj = [beta_map[(s.id, a)] for s, a in trace(skill_seq)]
    if min(beta_traj) < theta_aff:
        return ('reject', 'affect_unobservable', beta_traj)
    if not causal.valid or causal.ci_contains_zero:
        return ('reject', 'not_identified')
    if gap.G > G_max or gap.delta_sim > eps_sim:
        return ('reject', 'goodhart_or_sim_gap')
    return ('ok', J_social(J.rho, J.A_cert, gamma_ce, J.delta_a,
                           beta=min(beta_traj), C_aff=causal,
                           G=gap.G, dsim=gap.delta_sim))
```

### IP-126 ASCM（Affective Skill Composition over Graph）
在 SCOM 边上增加情感耦合检查。

```python
def affective_edge_ok(si, sj, a, beta_map, theta_aff, tau_beta):
    # 组合转换区的 β 不得下降超过预算，且组合不应诱导 mask 策略
    b = [beta_map[(si.id, a)],
         beta_map[(sj.id, transition_region(si, sj))]]
    return min(b) >= theta_aff and beta_drop(si, sj) <= tau_beta
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| AOP | O(|Z|·|A_s|·n·C_fer) | O(|Z|·|A_s|) | 配对种子、留出估计、β 下界 |
| GACE | O(|H|·n·T_sim) | O(|H|·n) | 同 z0/同种子、混淆分层覆盖 |
| PPC | O(T·(|π|+|adv|)) | O(T) | 对抗 mask 策略、不动点收敛 |
| AFT | O(B·|Z|·|A_s|) | O(|Z|·|A_s|) | 只证伪不确认、人群对抗采样 |
| SJC | O(|S|·|A_s|) | O(|S|) | β 轨迹下界、因果非零、gap 外校准 |

**命题 1（可识别度 → 决策误差下界）**：设 `|Z|=K`，动作 a 下 `I(z;e|a) = β_S(z,a)·H(z|a)`。由 Fano 不等式，任何从 e 推断 z 的策略其错误率
```
P_err ≥ ( H(z|a)·(1 - β_S(z,a)) - 1 ) / log K
```
若损失满足 margin 条件 `ℓ(z,ẑ) ≥ ℓ_min·1[ẑ≠z]`，则相对 oracle 的期望超额损失
```
E[ℓ(z,π(e))] - E[ℓ(z,z)] ≥ ℓ_min · max(0, H(z|a)(1-β_S)-1) / log K
```
即 **β 越低，任何「按表情行动」的策略都存在不可消除的 Goodhart 缺口下界**。这解释了为何 β 必须是硬门槛，而不能用「FER 准确率高」替代。

**正确性定理（Affect-Aware Social Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** β_S 由配对探针估得且分类器在留出集上校准（ECE ≤ ε_cal）；**(A30)** Gazebo 的 do 干预在匹配的 `(h,c,z0,seed)` 上无混杂泄漏；**(A31)** 部署人群主要分层被 avatar 族群覆盖，且 `Δ_sim ≤ ε_sim` 由**外部人类校准集**给出。
则对任意技能序列，若 `J_social` 通过，则
```
P(部署后潜在状态不劣于 oracle 的差距 ≤ G_max + L_z·Δ_sim)
    ≥ 1 - β_E - P(β̂<θ, β≥θ) - P(CI 含 0 | 真效应)
```
**关键**：这不是「机器人读懂了人」的证明，只是「在给定证伪预算与外部校准下未发现反例且因果锚定成立」。仿真只贡献**否定证据**，肯定证据必须来自外部人类校准。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 β 剖面与动作依赖 | β_S(z,a) 随距离/注视/遮挡的变化曲线 | 识别出 ≥3 个「高 α 低 β」动作（执行得了但读不懂） |
| E163 配对 ATE 与真实因果 | GACE 估计 vs 真人小样本配对 | ATE 相对误差 ≤ 20%，CI 覆盖率 ≥ 90% |
| E164 Goodhart 缺口 | 优化表情奖励 vs 优化潜在状态 | 表情奖励↑但 G≥阈值 的比例暴露 ≥ 30% |
| E165 仿真证伪力 | 注入已知错误 FER 语境后的反例发现率 | 发现率 ≥ 85%，假确认率 0（结构上不确认） |
| E166 社会联合证书 | 部署后 β、G、人工不适评分 | 相比仅 ρ+A_cert，不适率下降 ≥ 25%，且 G ≤ G_max |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 仿真 avatar 循环自证（把我们写的 display rule 当真人） | 极高 | 仿真只证伪；外部人类校准；对抗性 display-rule 随机化 |
| 表情奖励诱发 Goodhart / 面具行为 | 极高 | 因果锚定梯度、对抗 mask 策略、永不直接优化表情信号 |
| β 估计的标签主观性与标注偏差 | 高 | 多标注者一致性、不确定性传播、留出人群分层 |
| 跨文化 / 个体泛化失败 | 高 | 分层证书、人群覆盖检查、拒答机制 |
| 隐私与情感操纵伦理 | 高 | 最小必要感知、可拒绝/可关闭、伦理审查 |
| 云边情感推断延迟 | 中 | 边端轻量 FER + 云端因果重估、回退到保守社交策略 |

## 6. 本轮最大风险

**一句话**：Gazebo 只能提供「我们写进去的」表情-状态响应结构，一旦把 FER 的标注约定当成仿真真人的因果模型，仿真就会从**证伪器退化为自证器**；更危险的是，部署策略若直接优化表情信号，会把人训练成用社交微笑关闭机器人干预的 **Goodhart 对手**，表面舒适上升而潜在不适不降——故必须以 **「仿真只许证伪 + 外部人类校准 Δ_sim + 表情奖励的因果锚定」** 三重护栏，宁可承认「读不懂」，也不把「可读的表情」当成「真实的状态」。

# 第 55 轮产物 · 创新点清单 v32：GroundEdge-GenSim++++（AOP×GACE×PPC×AFT×SJC×ASCM）

> 承接第 54 轮产物 v31。本轮在「动作-鲁棒性双证书」之上，增加 **情感可观测性、仿真反事实因果、表演性预测、仿真证伪、社会-情感联合证书** 五个算子：
> - **AOP（Affective Observability Profiling）**：技能在动作下的情感可观测剖面 `β_S(z,a)`，是第 54 轮 `α_S` 的人类侧对偶；
> - **GACE（Gazebo Affective Counterfactual Engine）**：用 Gazebo 的配对 `do(a)` 干预估计动作对人的因果情感效应；
> - **PPC（Performative Perception Certificate）**：把部署策略视为会改变人类状态分布的不动点，量化表演性差距与 Goodhart 缺口；
> - **AFT（Affect Falsification Test）**：把 Gazebo 明确降格为**只证伪、不确认**的反例搜索器；
> - **SJC（Social Joint Certificate）**：在第 54 轮 `J` 上加入 `β, C_aff, G, Δ_sim`；
> - **ASCM（Affective Skill Composition）**：在 SCOM 边上增加「组合轨迹不得把人类推入低可观测区」的约束。
>

## 1. 符号体系增量（新增定义 121–126）

## 2. 关键算法 伪代码

### IP-121 AOP

```python
def affective_profile(avatar, z_grid, a_grid, n_ep=200, calib=True):
    beta, cal = {}, {}
    for z in z_grid:
        for a in a_grid:
            feats, labels = [], []
            for k in range(n_ep):
                seed = stable_seed(avatar.id, z, a, k)      # 唯一配对键
                e = gazebo.render_expression(avatar, z, a, seed)
                feats.append(extract_au(e)); labels.append(z)
            tr, ho = split_by_identity(feats, labels)       # 按人划分，避免泄漏
            clf = fit_holdout(tr)
            risk = bayes_risk(clf, ho)
            beta[(z, a)] = 1 - risk / prior_risk(labels)
            cal[(z, a)]  = ece(clf, ho) if calib else None
    return beta, cal
```

### IP-122 GACE

```python
def affective_ate(avatar, action_pairs, strata, n=500):
    logs = []
    for h in strata:                              # 个体/文化/基线分层
        for s in range(n):
            seed = stable_seed(avatar.id, h, s)
            a, a2 = sample_pair(action_pairs)
            z0 = avatar.reset_state(h, seed)
            z_a  = rollout(avatar, a,  z0, seed).final_z
            z_b  = rollout(avatar, a2, z0, seed).final_z    # 同 z0、同 seed
            e_a  = render(avatar, z_a); e_b = render(avatar, z_b)
            logs.append(StratumLog(h, a, a2, z_a - z_b, e_a, e_b))
    ate = doubly_robust_ate(logs)
    ci  = bootstrap_ci(logs, by='stratum')        # 分层自助，覆盖人群异质
    return C_aff(ate, ci, do_set=action_pairs,
                 confounders=strata, sim_fidelity=avatar.fidelity())
```

### IP-123 PPC

```python
def performative_certificate(pi_robot, human_adv, z0, T):
    deployed, observed = [], []
    z = z0
    for t in range(T):
        e  = human_adv.observe_and_emit(z)
        a  = pi_robot(e)
        z  = human_adv.transition(z, a)            # 动作因果地改变状态
        deployed.append((z, e))
        observed.append((human_adv.no_action_state(z), e))
        human_adv.update(goal='mask_discomfort')  # 对抗：学会用表情关闭干预
    pg = wasserstein(deployed, observed)
    G  = mean([zz for zz, _ in deployed]) - mean([zz for zz, _ in observed])
    return ('ok' if pg <= eps_pg and G <= G_max else 'reject'), pg, G
```

### IP-124 AFT

```python
def falsify_affect_claim(claim, avatar_population, budget):
    for avatar in adversarial_sample(avatar_population, budget):
        beta, cal = affective_profile(avatar, claim.Z, claim.A_s)
        if min(beta.values()) < claim.theta:
            return ('falsified', 'low_observability', avatar, beta)
        if any(c > eps_cal for c in cal.values()):
            return ('falsified', 'uncalibrated', avatar, cal)
        if performative_certificate(claim.pi, mask_policy(avatar),
                                    claim.z0, claim.T)[0] == 'reject':
            return ('falsified', 'goodhart', avatar)
    return ('not_falsified', budget)    # 结构上不存在 'certified' 返回值
```

### IP-125 SJC

```python
def social_joint_certificate(skill_seq, gamma_ce, J54, beta_map, causal, gap):
    J = J54
    beta_traj = [beta_map[(s.id, a)] for s, a in trace(skill_seq)]
    if min(beta_traj) < theta_aff:
        return ('reject', 'affect_unobservable', beta_traj)
    if (not causal.valid) or (causal.ci.lo <= 0 <= causal.ci.hi):
        return ('reject', 'not_identified', causal.ci)
    if gap.G > G_max:
        return ('reject', 'goodhart', gap.G)
    if gap.delta_sim > eps_sim:
        return ('reject', 'sim_gap_uncalibrated', gap.delta_sim)
    return ('ok', J_social(rho=J.rho, A_cert=J.A_cert, gamma_ce=gamma_ce,
                           delta_a=J.delta_a, beta=min(beta_traj),
                           C_aff=causal, G=gap.G, dsim=gap.delta_sim,
                           evidence=J.evidence + [causal.do_set]))
```

### IP-126 ASCM

```python
def affective_edge_ok(si, sj, a, beta_map, theta_aff, tau_beta):
    b_i = beta_map[(si.id, a)]
    b_j = beta_map[(sj.id, transition_region(si, sj))]
    return min(b_i, b_j) >= theta_aff and (b_i - b_j) <= tau_beta

def build_affective_composition_graph(skills, beta_map, theta_a, tau_e,
                                       theta_aff, tau_beta):
    G = SCOM.build(skills, theta_a, tau_e)        # 复用第 54 轮动作兼容图
    for (i, j) in list(G.edges):
        if not affective_edge_ok(skills[i], skills[j], G[i][j]['a'],
                                 beta_map, theta_aff, tau_beta):
            G.remove_edge(i, j)                    # 情感不可观测边直接剪除
    return G
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| AOP | O(\|Z\|·\|A_s\|·n·C_fer) | O(\|Z\|·\|A_s\|) | 按人划分留出、ECE 校准、β 下界 |
| GACE | O(\|H\|·n·T_sim) | O(\|H\|·n) | 同 z0/同 seed 配对、分层覆盖 |
| PPC | O(T·(\|π\|+\|adv\|)) | O(T) | 对抗 mask 策略、不动点收敛 |
| AFT | O(B·\|Z\|·\|A_s\|) | O(\|Z\|·\|A_s\|) | 只证伪不确认、对抗人群采样 |
| SJC | O(\|S\|·\|A_s\|+\|𝔇_ρ\|) | O(\|S\|+\|𝔇_ρ\|) | β 轨迹下界、CI 排除 0、gap 外校准 |
| ASCM | O(\|S\|²·\|A_s\|) | O(\|S\|²) | 边剪枝 sound、β 下降有界 |

**命题 1（可识别度 → Goodhart 下界）**
设 `|Z|=K`，动作 a 下 `I(z;e|a)=β_S(z,a)·H(z|a)`。Fano 不等式给出任何推断器
```
P_err ≥ ( H(z|a)(1-β_S(z,a)) - 1 ) / log K
```
若损失满足 `ℓ(z,ẑ) ≥ ℓ_min·1[ẑ≠z]`，则任何「按表情行动」策略相对 oracle 的超额损失
```
E[ℓ(z,π(e))] - E[ℓ(z,z)] ≥ ℓ_min·max(0, H(z|a)(1-β_S)-1)/log K
```
**含义**：β 是无法被策略聪明程度绕过的信息地板；FER 准确率高不等于 β 高（准确率可被类别先验与掩饰样本撑高）。

**正确性定理（Affect-Aware Social Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** β 由配对探针估得且留出校准 `ECE ≤ ε_cal`；**(A30)** Gazebo 的 `do(a)` 在匹配 `(h,c,z0,seed)` 上无混杂泄漏；**(A31)** avatar 族群覆盖部署人群关键分层，且 `Δ_sim ≤ ε_sim` 由**外部人类校准集**给出。则技能序列通过 `J_social` 时
```
P(部署后潜在状态与 oracle 的差距 ≤ G_max + L_z·Δ_sim)
    ≥ 1 - β_E - P(β̂<θ, β≥θ) - P(CI 含 0 | 真效应)
```
**强调**：该界是**拒答意义上的保守界**，不是「读懂了人」的肯定证明。仿真只提供否定证据（反例），肯定证据只能来自外部人类校准。

## 6. 落地路线（最小可信闭环）

1. **离线**：在 Gazebo 中建 3 类 avatar（不同文化 display rule、不同基线情绪），跑 AOP 得到 β 热力图，先用 AFT 证伪现有 FER 技能。
2. **小样本真人校准**：只采 20–30 名受试者的配对短交互，估 `Δ_sim` 与 `C_aff` 的外部效度；不追求大模型，只校准 gap。
3. **边端**：部署轻量 AU + 不确定性头，`β̂` 低于阈值即**拒答并退回保守社交策略**（不猜）。
4. **云端**：只做因果重估与重规划，不做逐帧 FER；反向 Explain 回传「哪类动作导致不可观测」。
5. **红线**：任何优化目标都不得直接以「微笑/正向情绪概率」为奖励，只能以经因果锚定的潜在状态代理为目标。

## 7. 本轮最大风险

**一句话**：Gazebo 只能提供「我们写进去的」表情-状态响应结构，一旦把 FER 的标注约定当成仿真真人的因果模型，仿真就会从**证伪器退化为自证器**；更危险的是，部署策略若直接优化表情信号，会把人训练成用社交微笑关闭机器人干预的 **Goodhart 对手**，表面舒适上升而潜在不适不降——故必须以 **「仿真只许证伪 + 外部人类校准 Δ_sim + 表情奖励的因果锚定」** 三重护栏，宁可承认「读不懂」，也不把「可读的表情」当成「真实的状态」。
