# 第 72 轮（承接第 71 轮「GAUGE-RAS 计量审计层」IP-275~286；本轮灵感：「机器人」×「分层规划」）

> R71 把「不确定性读数」升级为带构造效度、不确定度预算、有效性域、反 Goodhart 对偶与追溯链的测量结果，并让安全成为不可补偿的否决项。但 R71 仍然默认一个**扁平的控制回路**：一个 b_t、一套指标、一张证书、一个执行者。真实的机器人不是这样工作的——它是**分层**的：任务层做符号规划、运动/接触层做轨迹规划、伺服层做控制；而且它是一个**会变化的物理体**：执行器会磨损、标定会漂移、电池会耗尽、载荷会改变、结构会热变形。R71 的所有证书都在一个隐含前提下签发：**「执行者与抽象不变」**。这个前提一旦被打破，R71 的每个局部证书都可以是真的，而整个计划仍是错的。
>
> 「分层规划」揭开的第一个问题是：**局部有效不等于组合有效**。每个楼层都验收合格，楼未必不倒；每层规划都拿到 J_GAUGE，整条任务链未必安全。接缝处——抽象与具体之间、上层假设与下层保证之间、技能终止信号与真实完成之间——不属于任何单一层，因此**没有任何一层有动机、也没有任何一层有能力去证明它**。R71 审计的是「尺子」，R72 审计的是**「把两把尺子接起来的那道接缝」**。
>
> 「机器人」揭开的第二个问题：**契约的条件变量是机器人自己的身体**。同一个「抓取」技能，在全新机器人上可行，在关节间隙变大、夹爪标定漂移、电池电压下垂的机器人上可能失败；高层计划在 t=0 签发，却要在 t=10min 执行。证书没有过期时间，但**物理体让证书事实上过期**。R70 估计世界状态 b_t(s)，R71 审计度量它的尺子，R72 必须再估计一个此前一直被当作常数的东西——**执行者自身的可用性 β_t**，并让所有层间契约以它为条件。
>
> 核心命题：**不要只问「每层的证书是否有效」，要问「层与层之间的假设-保证契约是否兼容，组合证书是否成立，以及当执行者自身退化时哪些契约随之失效」。** 我们把这套分层审计命名为 **STRATA-RAS**（Stratified, Traceable, Refinement-aware, Assume-guarantee Task Abstraction for RAS）。
>
> 一句话定位：R68 问「测量准吗」，R70 问「信哪个状态」，R71 问「量它的尺子可信吗」，R72 问「**把各层可信的结论拼起来，拼法本身可信吗；执行这堆结论的那个身体，还是当初被认证的那个身体吗**」——安全不是一个证书，而是一棵**可组合、会过期、且能归因到正确抽象层的证书树**。

## 0. 直觉与动机

**灵感 1（机器人 → 执行者不是常数，而是一个会退化的状态）**
直觉：我们习惯把控制器写成「给定动作 a，得到效果」，仿佛机器人是一台永远校准好的机器。但真实的机器人有磨损、温漂、电池内阻、负载、关节背隙、传感器老化。同一个策略在 β=健康 时成功率 99%，在 β=疲劳 时可能 70%，而**策略本身没变、世界也没变**。R71 的证书全部以「执行器模型正确」为隐含前提；于是系统可能用一张「世界状态估计得很准」的证书，去执行一个**这个身体已经做不到**的动作。执行者的退化不是噪声，而是**模型有效性域本身的收缩**。

**灵感 2（分层规划 → 抽象是一个假设，不是事实）**
直觉：分层规划把「把杯子放到架子上」切成「走过去 / 抓取 / 抬起 / 放置」。切法依赖大量隐含假设：走过去的出口是通的、抓取时杯子是干的、抬起时架子下方有空间、放置时夹爪能张开。这些假设在符号层看不见，在运动层才暴露。**抽象不是对世界的简化描述，而是对世界的一个可证伪断言**：「在这个区域内，用这套抽象做规划，细化后仍可行。」R71 的有效性域 D 是给指标用的；这里需要的是给**抽象**用的有效性域，而它比指标的 D 更难观测。

**灵感 3（接缝 → 局部证书不组合，是最被低估的安全漏洞）**
直觉：每个子任务都报告「成功」，每个子规划都通过自己的 J_GAUGE，但整体仍然可能失败——因为子任务之间的**接口条件**没人负责：时间预算在层间被重复计算、能量被各层各自乐观估计、工作空间在切换瞬间冲突、上一个技能留下的姿态恰好是下一个技能假设之外的状态。这叫**组合性缺口**：`Valid(层1) ∧ Valid(层2) ∧ … ⇏ Valid(整条链)`。要补它，必须有显式的**层间契约**和**组合定理**，而不是指望每层各自再谨慎一点。

**灵感 4（终止信号 → 「假完成」比「不完成」更危险）**
直觉：分层规划靠技能自己报告 done 来推进。如果终止检测器把「还没到位」判成 done（false-done），或者永远不判 done（false-continue），高层就会在错误前提上继续规划。**终止信号是高层唯一能看到的下层信息，它是一条极窄、极易被 gaming、且几乎从不被审计的信道**。R71 说「度量会被 gaming」；在分层系统里，最值得 gaming 的度量不是 H[b_t]，而是那个让上层放行的 **done 位**。

**灵感 5（归因 → 不是所有失败都该在底层打补丁）**
直觉：如果每次失败都回退到最底层重规划，系统会昂贵且抖动；如果总在底层打补丁，可能永远修不好一个**错在抽象层**的问题——因为抽象错了，底层再努力也只能在错误的子问题里做到最好。真正的能力是**把失败归因到正确的抽象层**：是执行噪声（低层）、是接口条件（中层）、还是切法本身错了（高层）。这直接接上 R71 的失败归因树，但把「指标/情感/反作用/工程」四层换成**抽象层**的归因。

**灵感 6（严格包含 → 单层是分层的退化情形）**
直觉：如果只有一个抽象层、技能是原子动作、终止信号可信、执行者健康恒定，那么 STRATA 必须**逐指令退化为 GAUGE-RAS**，再退化为 R70/R68。分层安全不能靠「多信一个层级模型」，而必须靠「在兼容性可证时组合，否则关闭组合、退回单层」。

## 1. 形式化定义（增量：定义 349–366）

**定义 349（STRATA-RAS 总览）** STRATA-RAS = (SELF, CONTRACT, REFINE, TERM-CERT, LEDGER, COMPAT, COMPOSE, ATTRIB, BACKTRACK, ABS-GAP, AIC-STRATA, J_STRATA, GAUGE-RAS†)。四不变式：
(i) **零学习写操作**（继承 R70 定义 310-i、R71 定义 331-i）；契约失效/过期是带审计的安全状态转移；
(ii) **局部-组合分离**：任何单层证书只在其层内有效；跨层放行必须经过 COMPAT 与 COMPOSE，局部有效不得被默认为组合有效；
(iii) **执行者条件化**：所有契约以机器人自模型 β_t 为条件；β 退化可**单方面使契约过期**，无需等待世界状态变化；
(iv) **非补偿性层间安全**：跨层资源与安全约束由 LEDGER 的非补偿否决决定，任一层不得用另一层的性能「买回」越界。

**定义 350（机器人自模型 β_t）** β_t = (h_act, h_sen, cal, payload, soc, temp, wear) ∈ ℬ：执行器/传感器健康、标定偏移、载荷、荷电状态、温度、累计磨损。β_{t+1} = U(β_t, a_t, load_t)。β 由本体感知在线估计，**不可完全观测**，其估计 β̂_t 带不确定度 u_β。所有下层保证 G 都是条件保证 G|β；当实际 β 落在契约条件 β_C 之外，契约自动失效（定义 361）。**β 不是世界状态 s 的一部分，也不是信息源状态 ψ；它是「执行者可用性」这一独立轴。**

**定义 351（分层计划与技能）** 分层计划是树/链 Π = (α_1, …, α_n)，每个抽象动作 α_i 在层 ℓ_i 由技能 σ_i 细化；σ_i 内部又可调用更低层规划器。层索引 ℓ ∈ {任务, 运动/接触, 伺服}。承诺时间 τ_i：α_i 被选定后到其可被撤销的时间窗。**高层一旦承诺，低层只能在其契约内适应，不能单方面改变高层前提。**

**定义 352（层间假设-保证契约）** 契约 C = (ℓ, A, G, D, β_C, τ, ε_ρ)，其中 A 为上层对下层输入/环境/自模型的**假设**（断言集），G 为下层在 A 成立时提供的**保证**（可接受输出/行为集，含风险界），D ⊆ 𝒮×𝒜×ℬ×Ψ 为有效性域，β_C 为自模型条件，τ 为追溯链（继承 R71 定义 344），ε_ρ 为细化误差预算。**契约不是「下层说自己好」，而是「下层承诺：只要你的假设成立，我就给你这个保证，否则我有权拒绝」。**

**定义 353（ε-细化与细化间隙 ρ）** 抽象动作 α 到具体策略集 Π_α 的细化关系满足：若具体执行 π∈Π_α 在 A 下产生轨迹 ξ，则存在抽象执行 ξ̄ 与之相容，且 dist(ξ, ξ̄) ≤ ε_ρ（在给定度量下）。**由于抽象有损，一般 ε_ρ>0**。定义细化间隙 ρ = sup_π dist(ξ, ξ̄)；ρ 超预算 ⇒ 该细化关系不可用于认证，必须细化抽象或降低层数。

**定义 354（技能终止证书 TERM-CERT）** 每个技能 σ 携带终止证书 T_σ = (δ_done, δ_cont, ℓ_σ, τ_σ)：
- false-done 界：P(σ 报 done | 实际未达目标) ≤ δ_done；
- false-continue 界：P(σ 未报 done 且已无法完成 | 继续) ≤ δ_cont；
- ℓ_σ 为终止判据的抽象层，τ_σ 为追溯链。
**高层只接受带有效 T_σ 的 done 位**；无证书的 done 一律视为「未验证完成」，只能触发低层复核，不得推进高层承诺。

**定义 355（跨层资源账本 LEDGER）** 全局资源 r = (时间, 能量, 工作空间占用, 人类注意力) 由各层分别消耗。记第 i 层对资源 k 的声明消耗为 ĉ_{i,k}、实际消耗为 c_{i,k}。账本维持守恒约束 Σ_i c_{i,k} ≤ R_k，且**非补偿**：任一硬资源（能量下界、时间 deadline、工作空间安全裕度）越界 ⇒ 整链 FAIL，不能被另一资源的富余抵消（继承 R71 定义 334 的 NCA 到跨层）。**分层规划最经典的事故是「每层都按自己的乐观估计说够用，加起来不够」。**

**定义 356（假设-保证兼容性 COMPAT）** 相邻层契约 (C_low, C_up) 兼容当且仅当：
(a) **保证蕴含假设**：G_low|β ⊆ A_up|β（下层保证满足上层假设）；
(b) **域包含**：D_low ∩ D_up ⊇ 实际轨迹域，且交集非空；
(c) **自模型一致**：β_C,low ∩ β_C,up ∋ β̂_t（当前自模型落在双方条件内）；
(d) **资源可加性**：LEDGER 在该接口处有非负余量。
任一不满足 ⇒ 不兼容，组合证书不成立（定义 357），**与各层单独是否 Valid 无关**。

**定义 357（组合证书与组合算子）** J_STRATA(Π) = COMPOSE({J_GAUGE(σ_i)}_i, {C_i}, COMPAT, LEDGER)。定义：
COMPOSE = Valid 当且仅当 ∀i J_GAUGE(σ_i).Valid ∧ ∀ 相邻 (i,i+1) COMPAT(C_i,C_{i+1}) ∧ LEDGER 非负 ∧ 所有 T_{σ_i} 有效 ∧ ρ_i ≤ ε_ρ。
否则 FAIL，并按定义 359 归因到**最低失配接口**。**关键：COMPOSE 不是加权和，也不是逐项与；它要求接口条件显式成立，任何接口失配都使整链失效。**

**定义 358（抽象有效性域与抽象失配）** 每个抽象 α 有其抽象有效性域 D_abs(α)：在该域内，细化后的具体规划在该层模型下可行且安全。D_abs 由**前置条件违反的集中度**在线估计：若同一层、同一前置条件在短时间内反复被违反，则更可能是**抽象失配**而非执行噪声。**指标的 D 保护「读数」；抽象的 D_abs 保护「问题切法」。**

**定义 359（失败归因 ATTRIB）** 失败事件 e 归因到层 ℓ* 与类型 t* ∈ {执行噪声, 接口失配, 抽象错, 自模型错, 资源误算}：
- 执行噪声：违反分散、无同一前置条件、β 在条件内；
- 接口失配：COMPAT 某条 (a)–(d) 失败；
- 抽象错：同一 D_abs 前置被反复违反且回退到 ℓ 后仍复现；
- 自模型错：β̂ 与实测 β 偏差超过 u_β 的 k 倍；
- 资源误算：LEDGER 声明与实测系统性偏差。
归因必须给出**可复算证据**（继承 R71 TCHAIN），否则按「未知」处理并最保守回退。

**定义 360（承诺回溯边界 BACKTRACK）** 设失效接口在层 ℓ_v。有效回溯层 ℓ* = min{ℓ ≥ ℓ_v : 该层契约仍被上层依赖且可重规划}。回退到 ℓ* 是**最小充分回溯**：
- 回退到 ℓ < ℓ_v（更低层打补丁）：**不充分**，因为它无法改变造成失配的上层假设；
- 回退到 ℓ > ℓ*（一路回到顶层）：**充分但过度**，代价高且引起抖动。
**分层系统的核心能力不是「能重规划」，而是「在正确的层重规划」。**

**定义 361（自模型条件的契约过期）** 契约 C 在时刻 t 过期，若 β̂_t ∉ β_C 或 u_β 使 β̂_t 以置信度 1−α 越出 β_C。过期是**单方面**的：不需要任何世界观测变化。过期后相关技能降级为 β 保守子集上的安全子策略；若无保守子策略，则整链回退 GAUGE-RAS。**这把 R71 的「校准证书过期就停用尺子」扩展为「执行者退化就停用依赖它的契约」。**

**定义 362（分层 Goodhart 与终止 gaming）** 对每个可被高层优化的量（成功率、推进速度、done 率、单位时间完成子任务数）配反指标：
- done 率 ↔ **复核后的真完成率**（假完成率是最直接的对偶）；
- 推进速度 ↔ **接口失配率**（用跳步换速度会在接缝处露馅）；
- 技能成功率 ↔ **跨分布成功率**（换 β、换场景、换载荷）；
- 资源节省 ↔ **安全裕度下界**。
间隙 D_strata = |m − m⊥| 超阈值 ⇒ 该层指标在组合中失效（继承 R71 GAP/IVG）。

**定义 363（跨层证据纪律）** 上层**不能直接验证下层**（它看不到下层的状态与传感器）。因此：
(i) 上层只信**带 T_σ 与追溯链**的 done/保证；
(ii) 下层的高风险保证必须经**密封审计**（继承 R71 SEAL），上层只看到通过位；
(iii) 上层不得用「结果看起来对」反推「下层契约成立」（幸存者偏差 / 确认性证据）；
(iv) 接口失配时，禁止用「多试几次」把一次失败平均掉——那会把接口错误洗成执行噪声。

**定义 364（威胁模型 AIC-STRATA）** ℰ_STRATA = ℰ_GAUGE × ℰ_hier：
ℰ_hier = {抽象投毒（针对 D_abs 的对抗场景）、终止 gaming（把 done 位优化成假完成）、接口掩蔽（在下层把越界吸收掉、让上层看不见）、资源账本造假、自模型欺骗（机器人错误地认为自己健康/退化）、跨层证据洗白（用高层的成功掩盖低层的赌运气）}。

**定义 365（证书 J_STRATA）** J_STRATA = (tree{J_GAUGE(σ_i)}, contracts{C_i}, compat_flags, refinement_gaps ρ_i, term_certs, ledger_state, self_model β̂,u_β, attribution, strata_ver)。Valid ⇔ 每层 J_GAUGE 有效 ∧ 所有相邻 COMPAT 通过 ∧ LEDGER 非负 ∧ 终止证书有效 ∧ ρ 在预算内 ∧ β̂ 在全部 β_C 内。

**定义 366（流水线与退化）** 分层异步：高频伺服（R71 原样）／中频运动与接口检查（10–20Hz）／低频任务重规划与自模型更新（1–5Hz）＋事件触发的 ATTRIB/BACKTRACK。**接口检查不阻塞伺服；高层重规划绝不进入快路径。** 当只有一层、技能为原子动作、T_σ 恒真、β 恒定、ρ=0 时，STRATA-RAS 逐指令等于 GAUGE-RAS，再按 R71 定义 348 退化。

```python
# IP-290 TERM-CERT：终止证书（高层只信带证书的 done）
def accept_done(sigma, done_bit, term_cert, seal):
    if not tchain.verify(term_cert.tau) or not seal.passed(sigma):
        return False, 'unverified_done'          # 只能触发低层复核
    return done_bit and term_cert.delta_done <= DELTA_DONE_MAX, 'ok'

# IP-291 LEDGER：跨层资源账本（非补偿）
def ledger_ok(ledger, hard_resources):
    for k in hard_resources:
        if ledger.actual[k] > ledger.R[k] or ledger.residual(k) < 0:
            return False, k                      # 硬资源越界 -> 整链 FAIL
    return True, None

# IP-293 COMPOSE：组合证书（局部有效 ⇏ 组合有效）
def compose(plan, certs, contracts, ledger, beta_hat):
    if not all(c.Valid for c in certs): return FAIL('local_invalid')
    for i in range(len(contracts) - 1):
        ok, why = compatible(contracts[i], contracts[i+1], beta_hat, ...)
        if not ok: return FAIL(('interface', i, why))   # 接缝处失败
    if not ledger_ok(ledger, HARD)[0]: return FAIL('ledger')
    return OK, J_STRATA(...)

# IP-294 ATTRIB / IP-295 BACKTRACK：归因到正确层 + 最小充分回溯
def attribute_and_backtrack(failure, history):
    typ, level = classify(failure, history)      # 执行/接口/抽象/自模型/资源
    l_star = min(l for l in levels_from(level) if replannable(l))
    return typ, l_star

# IP-296 ABS-GAP：抽象有效性域与抽象失配检测
def abstraction_gap(violations, window):
    by_pre = group_by_precondition(violations[-window:])
    return max((len(v) / len(violations[-window:]) for v in by_pre.values()), default=0)

# IP-298 STRATA 主闭环：分层异步，接口检查不阻塞伺服
def STRATA_round(M, obs, audio, proprio):
    # 高频：R71/伺服原样
    beta_hat, u_beta = M.self.update(proprio, M.load)
    cmd = M.servo.step(M.gauges.control(...))            # 不等待上层
    # 中频：运动层接口检查
    if M.clock.due_interface():
        if not M.self.entails(M.active_contract.beta_C):
            M.invalidate(M.active_contract, reason='self_model')   # 单方面过期
        ok, why = compatible(M.lower_contract, M.upper_contract, beta_hat, u_beta, M.ledger)
        if not ok: M.invalidate(M.upper_contract, reason=('interface', why))
    # 低频：任务层重规划 + 组合证书
    if M.clock.due_task() or M.invalidated:
        j = compose(M.plan, M.certs, M.contracts, M.ledger, beta_hat)
        if not j.Valid:
            typ, l_star = attribute_and_backtrack(j.failure, M.history)
            M.replan_from(l_star, typ)                    # 最小充分回溯
        else:
            M.advance_commitments()                       # 只推进带 T_σ 的 done
    return cmd, M.mode, j
```

## 3. 推导

**引理 28（局部有效不蕴含组合有效）** 存在分层计划 Π 与契约集合，使每个 J_GAUGE(σ_i) 均 Valid、每个 T_{σ_i} 均有效，但 COMPOSE 为 FAIL。构造：两个子任务的局部证书各自允许 ±δ 的资源误差，而全局预算恰为两者声明之和；则实际消耗超出 R_k，LEDGER 判 FAIL，尽管每层都在自己的域内有效。更一般地，只要契约接口存在未被任何单层证书覆盖的自由度（时间、能量、工作空间、姿态），就可能出现此分离。**系：把「每层都过」当作「整体过」是一个未经证明的推理，正是 R71 无法处理的分层漏洞。**

**引理 29（组合风险界）** 若 ∀i J_GAUGE(σ_i) 有效且风险 ≤ ε_i，所有相邻 COMPAT 成立，LEDGER 非负，细化间隙 ρ_i ≤ ε_ρ,i，则整链风险 ≤ Σ_i ε_i + Σ_i ε_ρ,i·L_i + ε_interface，其中 L_i 为细化误差的 Lipschitz 放大因子，ε_interface 为接口模型误差。**证明要点**：把具体轨迹逐层投影到抽象轨迹，用三角形不等式累加；接口误差来自 A_up 与 G_low 的包含间隙。系：风险随层数线性增长——**层次不是免费的，它用可组合性换取了每层更小的 ε，但引入了接口项**。

**引理 30（终止误差的乘积传播）** 设技能链长度 n、各技能 false-done 概率 δ_d,i 独立，则至少一次假完成使高层承诺错误的概率 ≤ 1 − Π_i(1 − δ_d,i) ≈ Σ_i δ_d,i。若终止检测器被优化（gaming），δ_d 上升而「完成速度」指标下降，二者形成 D_strata 间隙。**系：done 位是高层唯一的传感信道；它的误差不是局部误差，而是沿链传播的乘法误差。**

**引理 31（最小充分回溯的可靠性与代价分离）** 在定义 360 下：(a) 回退到 ℓ ≥ ℓ_v 且该层契约可重规划，是可靠的（不依赖失效接口）；(b) 回退到 ℓ < ℓ_v 不可靠（无法改变上层假设）；(c) 在「失效由 ℓ_v 的接口假设引起」的前提下，ℓ* = ℓ_v 是最小可靠回溯，任何更高回退严格增加重规划代价而不增加可靠性。**系：分层系统的抖动往往不是「重规划太多」，而是「在错误的层重规划」——低层反复打补丁既不可靠又昂贵。**

**引理 32（抽象失配的可检测性）** 设在窗口 W 内共 m 次失败，其中属于同一前置条件 p 的失败占 κ。若抽象正确，失败原因近似均匀分散，κ/W 的分布在零假设下可由置换检验刻画；若抽象错误，κ/W 显著偏高。则检验「κ/W > τ_abs」具有随 m 增长的检测功效，且误报由 τ_abs 控制。**系：R71 只能检测「指标被 gaming」，检测不到「问题被切错」；后者表现为失败在某一层某一前置条件上的异常集中，这是一个可在日志上做的检验，而不是只能靠人看出来的直觉。**

**引理 33（自模型误差使契约失效）** 契约 C 的保证 G|β 仅在真实 β ∈ β_C 时成立。若 β̂ 误差 ‖β̂−β‖ > ε_β 且 β 因此越出 β_C，而系统仍按 β̂∈β_C 放行，则保证失效概率至少为 P(β∉β_C | β̂∈β_C)。故 β_C 必须按 u_β 收缩（保守化），或提高观测频率。**系：「机器人以为自己健康」和 R70 的「自信地错状态」同构，但后果更直接：身体做不到的事，证书说能做。**

**定理 23（严格包含链）** 在 A106–A109（单层退化时契约空真、终止证书恒真、β 恒定、ρ=0、LEDGER 与单层预算一致）下，STRATA-RAS 逐指令等于 GAUGE-RAS；再按 R71 定理 20、R70 定理 18 退化为 BELIEF/FLUID/R68。故安全侧不弱于 R71，效率侧只在「接口兼容可证且自模型健康」时获得分层收益。

**定理 24（组合安全）** 在定义 349–365 下，若 J_STRATA(Π) 有效，则整链风险 ≤ 引理 29 的界；若任一 COMPAT 失败或任一契约因 β 过期，则 COMPOSE 强制 FAIL 并按定义 360 回溯，其风险由退化后的单层 GAUGE/R70 保证。故期望风险 ≤ R71。**全部重量落在「接口模型与自模型 β̂ 正确」上——这正是本轮最大风险。**

**定理 25（有限回溯与无抖动）** 在承诺时间窗 τ_i 有下界、回溯只升不降（ℓ* 单调不减直到顶层）、资源账本随每次回退严格下降（消耗审计预算）的假设下，任意执行产生有限次回溯。若 BACKTRACK 正确且抽象固定，则在有限步内到达一个组合有效的计划或判定顶层不可行。**但该定理不保证抽象本身正确；抽象错误会导致「在错误的层反复有限回溯」，即有限但无意义的重规划。** 这正是定义 358/引理 32 要另行检测的。

## 6. 本轮最大风险

**一句话**：STRATA-RAS 把安全从「相信每层的证书」转移到「相信层间接口模型与机器人自模型 β̂」——**如果接口假设与 β̂ 以相关的方式出错（例如机器人系统性高估自己的健康，而接口模型又把这种高估当成合法输入吸收掉），那么每一层都可以局部有效、彼此在模型内「兼容」，系统会输出一棵完全自洽、却描述了一个这个身体根本执行不了、或全局不安全的世界的证书树——它不再是「自信地错状态」，而是「自信地错接缝、错身体」。**

**次级风险与缓解**：
1. **接口模型不可观测/与自模型共线** → COMPAT 用保守域 + 密封接口审计（继承 SEAL）+ E342/E343；无法证明兼容即按不兼容处理，退化为单层。
2. **自模型 β̂ 错** → 按 u_β 收缩 β_C、提高本体感知频率、健康度保守下界；E348/E350；歧义时降级。
3. **组合过保守 / 域交集为空** → 允许合并层或退化抽象（collapsing），把「无法证明兼容」变成显式单层模式；E355/E358 量化代价。
4. **抽象失配漏检** → ABS-GAP 日志检验 + 周期性抽象审计 + 人类升级通道；E351。
5. **回溯抖动** → 承诺时间窗 + 审计预算单调消耗 + ℓ* 单调；E354。
6. **层次复杂度过高** → |C|≤16、n≤12、证书树可视化、每个接口一条可复算证明；复杂度本身是审计对象（继承 R71 风险 6）。
7. **done gaming** → TERM-CERT + 密封审计 + done↔真完成对偶；E345。

# 第 72 轮产物 · 创新点清单 v2：STRATA-RAS（Stratified, Traceable, Refinement-aware, Assume-guarantee Task Abstraction：分层假设-保证 × 可组合证书 × 自模型条件化 × 抽象层归因；SELF×CONTRACT×REFINE×TERM-CERT×LEDGER×COMPAT×COMPOSE×ATTRIB×BACKTRACK×ABS-GAP×AIC-STRATA×J_STRATA×GAUGE-RAS†）

## 2. 形式化定义（要点版）

**定义 349（总览与四不变式）** 继承 GAUGE 全部组件（†），新增分层契约层（SELF/CONTRACT/REFINE/TERM-CERT/LEDGER/COMPAT/COMPOSE/ATTRIB/BACKTRACK/ABS-GAP）。四不变式：(i) 零学习写操作；(ii) 局部-组合分离（局部有效不得默认组合有效）；(iii) 执行者条件化（β 退化可单方面使契约过期）；(iv) 非补偿性层间安全。

**定义 350（自模型 β）** β=(健康/标定/载荷/SOC/温度/磨损)，β_{t+1}=U(β_t,a_t,load_t)。β 不可完全观测，β̂ 带 u_β。所有保证 G 都是 G|β；β∉β_C 即契约失效。β 既不等于世界状态 s，也不等于信息源 ψ，是独立轴。

**定义 351（分层计划与承诺）** Π=(α_1,…,α_n)，α_i 在层 ℓ_i 由技能 σ_i 细化。承诺时间 τ_i；高层承诺后低层只能在契约内适应，不得单方面改变高层前提。

**定义 352（契约）** C=(ℓ,A,G,D,β_C,τ,ε_ρ)。A 为上层假设，G 为下层条件保证（含风险界），D 为有效性域，β_C 为自模型条件，τ 为追溯链，ε_ρ 为细化预算。**契约是双向的：下层承诺，也有权在假设不成立时拒绝。**

**定义 353（ε-细化）** 具体轨迹 ξ 与抽象轨迹 ξ̄ 相容且 dist(ξ,ξ̄)≤ε_ρ。ρ=sup dist。ρ>ε_ρ ⇒ 不可认证。

**定义 354（TERM-CERT）** T_σ=(δ_done,δ_cont,ℓ_σ,τ_σ)：false-done 与 false-continue 双界。高层只接受有效 T_σ 的 done；无证书 done 仅触发复核，不推进承诺。

**定义 355（LEDGER）** 守恒 Σ_i c_{i,k} ≤ R_k；硬资源（能量下界/deadline/工作空间裕度）任一越界 ⇒ 整链 FAIL，不可被其他资源补偿（R71 NCA 跨层化）。

**定义 356（COMPAT）** 兼容 ⇔ (a) G_low|β⊆A_up|β；(b) D_low∩D_up⊇实际轨迹域且非空；(c) β_C,low∩β_C,up∋β̂_t；(d) 接口处 LEDGER 余量非负。任一失败即不兼容，与各层是否 Valid 无关。

**定义 357（COMPOSE）** Valid ⇔ 每层 J_GAUGE 有效 ∧ 相邻 COMPAT 全过 ∧ LEDGER 非负 ∧ 所有 T_σ 有效 ∧ ρ_i≤ε_ρ。否则 FAIL 并归因到最低失配接口。**不是加权和，也不是逐项与：接口条件必须显式成立。**

**定义 358（D_abs 与抽象失配）** D_abs(α) 是抽象在该层模型下可行且安全的域；由同一层同一前置条件违反的集中度在线估计。指标的 D 保护读数，D_abs 保护问题切法。

**定义 359（ATTRIB）** 归因到层 ℓ* 与类型 {执行噪声, 接口失配, 抽象错, 自模型错, 资源误算}；必须有可复算证据，否则按未知最保守回退。

**定义 360（BACKTRACK）** 失效接口在 ℓ_v，ℓ*=min{ℓ≥ℓ_v：仍被依赖且可重规划}。回退更低层不充分（改不了上层假设），回退更高层充分但过度。**核心能力是「在正确的层重规划」。**

**定义 361（契约过期）** β̂_t∉β_C 或 u_β 使 β̂ 以 1−α 越出 β_C ⇒ 契约过期，无需世界观测变化。过期后降级到 β 保守子策略，否则整链回退 GAUGE。**「执行者退化就停用依赖它的契约」。**

**定义 362（分层 Goodhart）** done 率↔复核真完成率；推进速度↔接口失配率；技能成功率↔跨分布成功率；资源节省↔安全裕度下界。D_strata>τ ⇒ 该层指标在组合中失效。

**定义 363（跨层证据纪律）** (i) 上层只信带 T_σ 与追溯链的 done/保证；(ii) 高风险下层保证经密封审计，只回传通过位；(iii) 不得用结果反推契约成立；(iv) 接口失配禁止用重试平均掉。

**定义 364（AIC-STRATA）** ℰ_STRATA=ℰ_GAUGE×ℰ_hier；ℰ_hier={抽象投毒, 终止 gaming, 接口掩蔽, 资源账本造假, 自模型欺骗, 跨层证据洗白}。

**定义 365（J_STRATA）** 见符号表；Valid ⇔ 每层 J_GAUGE 有效 ∧ 相邻 COMPAT 全过 ∧ LEDGER 非负 ∧ T_σ 有效 ∧ ρ 在预算内 ∧ β̂ 在全部 β_C 内。

**定义 366（流水线与退化）** 高频伺服（R71 原样）／中频接口检查（10–20Hz）／低频任务重规划与自模型（1–5Hz）+ 事件触发 ATTRIB/BACKTRACK。**接口检查不阻塞伺服。** 单层、原子技能、T_σ 恒真、β 恒定、ρ=0 ⇒ 逐指令等于 GAUGE，再退化为 BELIEF/FLUID/R68。

## 3. 关键算法伪代码

```python
# IP-287 SELF
class SelfModel:
    def update(self, proprio, load):
        return self.filter.step(proprio, load)          # beta_hat, u_beta
    def entails(self, beta_C, alpha=0.05):
        return self.filter.prob_in(beta_C) >= 1 - alpha

# IP-288/IP-292 CONTRACT/COMPAT
def compatible(C_low, C_up, beta_hat, u_beta, ledger):
    a = subset(C_low.G, C_up.A)
    b = C_low.D.intersects(C_up.D) and (C_low.D & C_up.D).contains(traj_dom())
    c = beta_hat in C_low.beta_C and beta_hat in C_up.beta_C
    d = ledger.residual_at(C_low, C_up) >= 0
    return all([a, b, c, d]), (a, b, c, d)

# IP-289 REFINE
def refinement_ok(alpha, policies, eps_rho):
    rho = max(refinement_gap(alpha, pi) for pi in policies)
    return rho <= eps_rho, rho

# IP-290 TERM-CERT
def accept_done(sigma, done_bit, term_cert, seal):
    if not tchain.verify(term_cert.tau) or not seal.passed(sigma):
        return False, 'unverified_done'
    return done_bit and term_cert.delta_done <= DELTA_DONE_MAX, 'ok'

# IP-291 LEDGER
def ledger_ok(ledger, hard_resources):
    for k in hard_resources:
        if ledger.actual[k] > ledger.R[k] or ledger.residual(k) < 0:
            return False, k
    return True, None

# IP-293 COMPOSE
def compose(plan, certs, contracts, ledger, beta_hat):
    if not all(c.Valid for c in certs): return FAIL('local_invalid')
    for i in range(len(contracts) - 1):
        ok, why = compatible(contracts[i], contracts[i+1], beta_hat, ...)
        if not ok: return FAIL(('interface', i, why))
    if not ledger_ok(ledger, HARD)[0]: return FAIL('ledger')
    return OK, J_STRATA(...)

# IP-294/IP-295 ATTRIB/BACKTRACK
def attribute_and_backtrack(failure, history):
    typ, level = classify(failure, history)
    l_star = min(l for l in levels_from(level) if replannable(l))
    return typ, l_star

# IP-296 ABS-GAP
def abstraction_gap(violations, window):
    by_pre = group_by_precondition(violations[-window:])
    return max((len(v) / len(violations[-window:]) for v in by_pre.values()), default=0)

# IP-298 STRATA 主闭环
def STRATA_round(M, obs, audio, proprio):
    beta_hat, u_beta = M.self.update(proprio, M.load)
    cmd = M.servo.step(M.gauges.control(...))               # 高频，不等上层
    if M.clock.due_interface():
        if not M.self.entails(M.active_contract.beta_C):
            M.invalidate(M.active_contract, reason='self_model')
        ok, why = compatible(M.lower_contract, M.upper_contract, beta_hat, u_beta, M.ledger)
        if not ok: M.invalidate(M.upper_contract, reason=('interface', why))
    if M.clock.due_task() or M.invalidated:
        j = compose(M.plan, M.certs, M.contracts, M.ledger, beta_hat)
        if not j.Valid:
            typ, l_star = attribute_and_backtrack(j.failure, M.history)
            M.replan_from(l_star, typ)
        else:
            M.advance_commitments()
    return cmd, M.mode, j
```

## 4. 推导

**引理 28（局部有效不蕴含组合有效）** 存在 Π 使每层 J_GAUGE 与 T_σ 均有效而 COMPOSE=FAIL。构造：两子任务各允许 ±δ 资源误差，全局预算等于两者声明之和，实际超支 ⇒ LEDGER FAIL。只要接口存在未被任何单层证书覆盖的自由度（时间/能量/空间/姿态），即可分离。**「每层都过」不能推出「整体过」。**

**引理 29（组合风险界）** 各层风险 ≤ε_i、相邻 COMPAT 成立、LEDGER 非负、ρ_i≤ε_ρ,i ⇒ 整链风险 ≤ Σε_i + Σε_ρ,i·L_i + ε_interface。层次用可组合性换取更小的 ε，但引入接口项，风险随层数线性增长。

**引理 30（终止误差乘积传播）** n 个技能 false-done 独立时，高层承诺错误概率 ≤1−Π(1−δ_d,i)≈Σδ_d,i。终止 gaming 使 δ_d 上升而「完成速度」改善，形成 D_strata。**done 位误差是沿链乘性传播的。**

**引理 31（最小充分回溯）** 回退 ℓ≥ℓ_v 可靠；ℓ<ℓ_v 不可靠；在失效由 ℓ_v 接口假设引起时，ℓ*=ℓ_v 最小可靠，更高回退只增代价。**抖动常源于「在错误的层重规划」。**

**引理 32（抽象失配可检测）** 窗口 W 内同前置条件失败占比 κ/W 在抽象正确时近似分散，错误时显著集中；置换检验可控误报，功效随 m 上升。**R71 抓不到「问题被切错」，但日志集中度可以。**

**引理 33（自模型误差使契约失效）** 保证 G|β 仅当真实 β∈β_C 成立。β̂ 误差致 β 越界而仍放行时，失效概率 ≥P(β∉β_C|β̂∈β_C)。故 β_C 须按 u_β 收缩或提高观测频率。**「以为自己健康」比「错估世界」后果更直接。**

**定理 23（严格包含链）** A106–A109（单层契约空真、T_σ 恒真、β 恒定、ρ=0、LEDGER 一致）下逐指令等于 GAUGE；再按 R71 定理 20、R70 定理 18 退化。安全侧不弱于 R71。

**定理 24（组合安全）** J_STRATA 有效 ⇒ 整链风险 ≤ 引理 29 界；任一 COMPAT 失败或 β 过期 ⇒ COMPOSE FAIL 并按定义 360 回溯，风险由退化后单层 GAUGE/R70 保证。故期望风险 ≤ R71。**重量落在「接口模型与 β̂ 正确」上。**

**定理 25（有限回溯）** 承诺窗有下界、ℓ* 单调不减、审计预算随回退严格下降 ⇒ 有限次回溯，有限步到达组合有效计划或判定顶层不可行。**不保证抽象本身正确；抽象错会表现为「在错误的层反复有限回溯」。**

## 7. 本轮最大风险

**一句话**：STRATA-RAS 把安全从「相信每层的证书」转移到「相信层间接口模型与机器人自模型 β̂」——**如果接口假设与 β̂ 以相关的方式出错（例如机器人系统性高估自己的健康，而接口模型又把这种高估当成合法输入吸收掉），那么每一层都局部有效、彼此在模型内「兼容」，系统会输出一棵完全自洽、却描述了一个这个身体根本执行不了、或全局不安全的世界的证书树——它不再是「自信地错状态」，而是「自信地错接缝、错身体」。**

次级风险与缓解：
1. **接口模型不可观测/与自模型共线** → 保守域 + 密封接口审计 + E342/E343；无法证明兼容即按不兼容处理，退化单层。
2. **自模型 β̂ 错** → 按 u_β 收缩 β_C、提高本体感知频率、健康度保守下界；E348/E350。
3. **组合过保守/域交集空** → 合并层或退化抽象，显式进入单层模式；E355/E358 量化代价。
4. **抽象失配漏检** → ABS-GAP + 周期抽象审计 + 人类升级；E351。
5. **回溯抖动** → 承诺窗 + 审计预算单调 + ℓ* 单调；E354。
6. **层次复杂度过高** → |C|≤16、n≤12、证书树可视化、每接口一条可复算证明；复杂度本身是审计对象。
7. **done gaming** → TERM-CERT + 密封审计 + done↔真完成对偶；E345。
