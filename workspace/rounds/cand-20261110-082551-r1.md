# 第 43 轮（灵感循环第 1 轮） · 从「安全证书」到「任务证书」：意图条件化成功率证书（ICSC）与主动澄清闭环（四层架构 v8）

> 承接第 42 轮 v19（SCV × CKB × ECR）。第 42 轮把「安全」做成了可验证、可进化的闭环，却始终没有正面回答 UniBot 的评分维度——**任务成功率**；而成功率的最大杀手往往不是控制不安全，而是**意图理解错了**。本轮灵感词「成功率」「意图理解」正好补上这块短板：把成功率从「事后统计的排行榜数字」升级为**运行时可自查、带置信区间的证书**，把意图从「一次性解析出的单一指令」升级为**带覆盖保证的信念 + 契约集合**。两者耦合出「意图条件化成功率证书」（ICSC）：意图信念决定「要对哪一族任务证书负责」，成功率证书反过来决定「当前歧义值不值得先澄清」。安全证书（不可伤害）× 成功率证书（应当完成）构成二维验收面，证书飞轮从「保安全」扩展为「保安全且保完成」。

## 0. 直觉与动机

**灵感 1（成功率 → 可验证的「任务证书」，而非排行榜数字）**：第 42 轮的守卫/不变式只回答「会不会伤害」，不回答「能不能做成」。但成功率天然是一个**概率型性质**，而概率型性质最怕两件事：样本少、分布变。直觉上分三步把它证书化：(1) **结构化**——把「任务成功」定义在 CAR 接受集上，成功 = 在期限内到达接受集且全程不违约束，于是成功率沿自动机的边**可分解**；(2) **可证**——边成功率用层次 Beta 后验 + conformal 校准给出区间，再用 Fréchet 界做串联/并联的 sound 区间传播，得到任务级 `p_lo`；(3) **可省**——历史任务的边统计存入 CKB 作先验，新任务只需少量实机回合就能把区间收窄，避免「每个任务都从零跑一万次」。这样系统在**动手之前就知道自己大概率能不能成**，从而把「盲目尝试」换成「先澄清、先降级、或换策略」。

**灵感 2（意图理解 → 带覆盖保证的契约集合，而非单一指令）**：语言指令天然歧义（「把那个拿过来」）。第 42 轮的契约是按单一解析结果编译的，一旦解析错，安全证书再 sound 也没用——因为它证明的是「错误任务」的安全性。直觉上把意图理解改成**分布 + 集合**：多模态模型输出信念 `bel(i|u)`，用 conformal 校准得到覆盖概率 ≥ 1−α 的意图集 `I_α`；每个意图编译成一个任务契约（目标区、约束、成功谓词、期限），借用 CKB 模板只补差集。成功率证书于是有两种口径：**鲁棒口径** `min_{i∈I_α} p_i`（保守，保证「不管哪种合理解读都尽量成」）与**期望口径** `E_bel[p_i]`（进取，用于收益评估）。更重要的是，歧义本身变成一种**可决策的状态**：如果执行证书的 `p_lo` 太低、而澄清能显著抬高它，就值得先问一句。

**灵感 3（耦合 → 主动澄清是「用成功率证书定价的干预」）**：澄清不是免费的美德——它会消耗时间、压缩期限，甚至打断正在安全执行的动作。直觉上把澄清当成一个**认证动作**：`Clarify(q)` 也必须有安全守卫（澄清时慢速/停稳），其价值等于「澄清后成功率证书下界的期望提升」减去时间成本。于是「执行 vs 澄清 vs 安全停」的选择，变成在证书空间里比较三个可证下界。这把第 42 轮的「安全优先降级」扩展成「安全 + 成功率双阈值降级」，也让课程引擎可以按「成功率前沿」和「歧义难度」两个轴来排课。

**与第 42 轮的耦合**：第 42 轮是「Sim→RAG→Edge→Sim」的安全飞轮；本轮在其旁并联一条**成功率飞轮**——真实回合的 `(φ, ψ, 意图, 结果)` 回流入 CKB，更新边成功率后验与意图校准集；成功率漂移与分布漂移一起触发 SCV 重采样。安全证书管「下界不许破」，成功率证书管「下界够不够高」，二者共用同一套 L0/L1 边缘查表与监控基础设施，边际成本很低。

## 1. 形式化定义（增量：定义 38–43）

**定义 38（意图信念、契约编译与覆盖意图集）**：设意图空间 I，观测 `u = (语言指令, 对话历史, 场景图)`。**意图信念** `bel(i|u)` 为多模态 grounding 模型给出的后验。**契约编译器** `Γ: (i, E) ↦ C_i = (G_i, Ψ_i^{safe}, S_i, T_i)`，其中 G_i 为目标区、Ψ_i 为约束、S_i 为成功谓词、T_i 为期限。用带标注校准集做 split conformal，得**覆盖意图集** `I_α` 满足 `P(i* ∈ I_α) ≥ 1−α`；歧义度 `amb = H(bel)/log|I| ∈ [0,1]`；并定义 out-of-support 指示 `oos = [min_{i∈calib} d(embed(u), embed(u_i)) > d_max]`。

**定义 39（意图条件化成功率与成功率证书）**：对策略 π 与意图 i，`p_i(π) = P_{ξ∼M(π)}[S_i(ξ)=1]`。**成功率证书** `K_p = (p_lo, p_hi, 1−α)` 满足 `P[p_i ∈ [p_lo, p_hi]] ≥ 1−α`。**鲁棒成功率** `p_rob = min_{i∈I_α} p_i`；**期望成功率** `p_exp = E_{i∼bel}[p_i]`。给定自主执行门槛 `p_req`，仅当 `p_lo ≥ p_req` 才允许无澄清自主执行。

**定义 40（可靠度图与组合成功率下界）**：把 CAR 扩展为**随机自动机** `H = (Q, E, δ, q_0, F_i, X_fail)`，边 `e` 的通过概率 `p_e = P(安全通过 e)`；任务成功 = 在 T_i 内到达接受集 F_i 且从未进入失败集。串联（必经边序列）用 Fréchet 交下界 `p_lo(∩A_e) ≥ max(0, Σ p_e − (n−1))`；并联（任一路径成功）用并下界 `p_lo(∪A_e) ≥ max_e p_e`。沿 DAG 拓扑顺序或路径分解递归传播，得任务级 `p_succ^lo`；该下界对边成功率区间与相关性均 sound（不需要独立性假设）。上界 `p_hi` 仅作诊断，不用于放行。

**定义 41（主动澄清的证书价值与门控）**：状态 x、信念 bel。动作 `a ∈ {Exec(i), Clarify(q)}`。执行价值 `V_exec = min_{i∈I_α} p_succ^lo(bel, x; T_i)`；澄清 q 得观测 y、更新 `bel' = bel(·|y)`、消耗时间 Δt（期限压缩为 T_i−Δt），其价值 `V_clar(q) = E_y[p_succ^lo(bel', x; T_i−Δt)] − λ_c·c(q)`。**门控规则**：当 `max_q V_clar(q) ≥ V_exec + τ` 且澄清预算未耗尽时澄清，否则在 `V_exec ≥ p_req` 时执行、否则安全停。τ 为切换迟滞，防抖。

**定义 42（成功率飞轮与校准）**：每回合 `(φ, ψ, î, outcome)` 入 CKB；边通过统计用**层次 Beta-Binomial** 后验（按任务指纹 φ 分组、部分池化）更新。校准误差 `ECE = ∫ |P(success | p_lo = z) − z| dz`；意图集覆盖率由 conformal 边际覆盖保证。**成功率漂移** `D_t = |Ŝ_t − Ŝ_sim| / σ̂`，超 `τ_d` 触发 SCV 重采样与重校准（与第 42 轮的分布漂移并联）。

**定义 43（二维证书与联合预算）**：证书二元组 `(K_safe, K_succ)`，`K_safe: m_lo ≥ θ`，`K_succ: p_lo ≥ p_req`。**自主执行域** `A = {x : m_lo(x) ≥ θ ∧ p_lo(x) ≥ p_req}`；其补集按定义 41 进入 Clarify 或 SafeStop。LCS 预算拆为 `Γ = Γ_safe + Γ_succ`，L0 查表/L1 监控器同时输出安全边际与成功率下界两个字段。

## 2. 四大产出设计（增量 IP-57/58/59 + 升级既有 IP）

### 2.1 IP-57 INTENT-CONTRACT-COMPILER（意图契约编译器 ICC）
1. **多模态意图后验**：LLM 语义解析 + 场景图 grounding + 对话历史，输出 `bel(i|u)` 与候选实体绑定。
2. **覆盖意图集**：split conformal 用历史 `(u, i*)` 校准，输出 `I_α`；同时做 out-of-support 检测（嵌入距离 + 覆盖率下界），OOS 时强制人工确认。
3. **契约编译**：意图 → 目标区/约束/成功谓词（优先从 CKB 检索相似契约模板，仅在差集上跑 CEGAR grounding）。
4. **澄清问题生成**：按「期望证书提升 / 信息增益」排序候选问题（实体指代、目标二选一、约束确认）。
5. **歧义度量与门控**：输出 `amb`、`oos`、`I_α` 供成功率证书与澄清策略消费。

### 2.2 IP-58 SUCCESS-CERT-GRAPH（成功率证书图 SCG）
1. **随机自动机可靠度图**：边通过概率复用 IP-51 守卫；成功谓词 S_i 编译为接受集 F_i；失败集含安全违例与超时。
2. **边统计**：SCV（IP-54）仿真给先验、实机回合给似然；层次 Beta-Binomial 按 `(φ, ψ)` 分组部分池化，稀疏边优先借用相似任务。
3. **区间传播**：对每个意图做路径分解，串联 Fréchet 下界 + 并联 max 下界；路径数截断时**只保证下界 sound**（截断只损失紧致度，不破坏 soundness）。
4. **证书输出**：`(p_lo, p_hi)` + **最弱路径 / failure frontier** + 贡献分解（哪条边最拖后腿）。
5. **证书敏感度主动采样**：优先采样「对 `p_lo` 方差贡献最大 / 使区间最松」的边，用最少实机样本收窄证书。

### 2.3 IP-59 ACTIVE-CLARIFY-POLICY（主动澄清策略 ACP）
1. **VOI 门控**：基于定义 41 比较 `V_clar` 与 `V_exec`，带迟滞 τ 与最大澄清轮数 k。
2. **认证澄清模式**：Clarify 作为 CAR 的一个认证模式，进入时执行安全减速/停稳守卫，保证澄清期间不新增安全风险。
3. **CKB 复用**：相似 `(φ, ψ)` 的历史澄清问答直接检索复用（few-shot），减少重复提问。
4. **防骚扰**：问题池去重、冷却期、收益低于阈值直接执行；记录误澄清率用于课程与阈值调优。

## 4. 实验设计（E87–E94 硬门槛，承接 E79–E86）

| 实验 | 指标 | 门槛 |
|---|---|---|
| E87 意图校准与覆盖 | conformal 意图集覆盖率、ECE、OOS 召回 | 覆盖率 ∈ [1−α−0.02, 1−α+0.02]；ECE < 0.05；OOS 召回 ≥ 0.90 |
| E88 成功率证书有效性 | 真实 p 落在 `[p_lo,p_hi]` 的频率；区间宽度 | 覆盖率 ≥ 95%（α=0.05）；宽度 < 0.20 |
| E89 组合界紧致度 | 相对 Monte Carlo 真值的 soundness 与 gap | 下界 sound 100%；gap < 0.15 |
| E90 主动澄清收益 | 成功率 vs 全执行/全澄清；平均澄清轮数 | 成功率 +≥8pp；< 1.5 轮/任务 |
| E91 CKB 成功率迁移 | 达到目标区间宽度所需实机样本 vs 冷启动 | 样本数降 ≥ 5x |
| E92 成功率飞轮 | 多轮后成功率与校准随时间变化 | 每轮 +≥3pp 至 ≥85%；ECE 不升 |
| E93 双轴课程 | 学习速度/最终成功率 vs 均匀课程 | 收敛快 ≥1.5x 或最终 +≥5pp |
| E94 UniBot 端到端 | 任务成功率、安全违例、澄清轮数、误澄清率 | 成功率 ≥80%；0 安全违例；误澄清 <10% |

回退：E87 失准 → 关闭 conformal 集，改用固定阈值 + 人工确认；E88 覆盖不达标 → 增大样本/放宽 α，或退回纯安全证书 + 固定任务脚本；E89 界太松 → 引入边相关结构联合采样收紧；E90 澄清无收益 → 关闭主动澄清，默认执行 argmax；E91 无迁移 → 冷启动。

## 5. 本轮最大风险

**一句话**：整套成功率证书的 soundness 只相对于**假设的意图信念**成立——一旦真实意图落在 `I_α` 之外（意图模型错设或 OOS），系统会在「证书显示高成功率」时执行错误任务，形成比单纯控制失败更隐蔽的「自信地失败」；因此 E87（意图覆盖）与 E88（成功率覆盖）必须作为红线实验，任一不达标即禁用自主执行、退回澄清或安全停。

## 1. 符号体系（增量：定义 38–43）

| 符号 | 含义 | 定义 |
|---|---|---|
| `bel(i|u)` | 意图信念 | 多模态 grounding 对意图 i 的后验；u=(语言,对话,场景图) |
| `I_α` | 覆盖意图集 | split conformal：`P(i*∈I_α) ≥ 1−α` |
| `amb = H(bel)/log|I|` | 歧义度 | 归一化意图熵 ∈ [0,1] |
| `C_i = (G_i,Ψ_i,S_i,T_i)` | 任务契约 | 目标区/约束/成功谓词/期限，由 Γ 编译 |
| `p_i(π) = P_ξ[S_i(ξ)=1]` | 意图条件成功率 | 策略 π 下完成意图 i 的真实概率 |
| `K_p = (p_lo,p_hi,1−α)` | 成功率证书 | `P[p_i∈[p_lo,p_hi]] ≥ 1−α` |
| `p_rob = min_{i∈I_α} p_i` | 鲁棒成功率 | 覆盖集上的最坏情形口径 |
| `p_succ^lo(∩A_e) ≥ max(0,Σp_e−(n−1))` | 串联 Fréchet 下界 | 不依赖独立性的 sound 交下界 |
| `p_succ^lo(∪A_e) ≥ max_e p_e` | 并联并下界 | sound 并下界 |
| `V_exec / V_clar(q)` | 执行/澄清证书价值 | 定义 41；澄清扣除时间成本 λ_c·c(q) |
| `ECE` | 校准误差 | `∫|P(success|p_lo=z)−z|dz` |
| `D_t` | 成功率漂移 | `|Ŝ_t−Ŝ_sim|/σ̂`；超 τ_d 触发重采样 |
| `A = {x: m_lo≥θ ∧ p_lo≥p_req}` | 自主执行域 | 二维证书均达标才自主执行 |

## 2. 关键算法（伪代码）

### IP-57 ICC：意图解析、覆盖集与契约编译
```
def compile_intent(u, scene, KB, alpha=0.05):
    bel = intent_belief(u, scene)                  # LLM+VLM+对话, i -> prob
    I_alpha = conformal_set(bel, KB.intent_calib, alpha)   # 覆盖 >= 1-alpha
    oos = min_embed_dist(u, KB.intent_calib) > d_max
    contracts = {i: retrieve_or_compile_contract(i, scene, KB)
                 for i in I_alpha}
    amb = entropy(bel) / max(1e-6, log(len(bel)))
    qs = rank_questions(I_alpha, scene, KB)        # 按期望证书提升排序
    return IntentBundle(bel, I_alpha, contracts, amb, oos, qs)

def retrieve_or_compile_contract(i, scene, KB):
    phi = task_fingerprint(i)
    cand = KB.retrieve_contract(phi, scene.psi, k=3)
    C = merge_contracts(cand) if cand else Contract.empty()
    return cegar_ground(C, i, scene)               # 仅在差集 Delta 上补全
```

### IP-58 SCG：组合成功率证书（只对下界负责）
```
def certify_success(H, I_alpha, stats, alpha=0.05):
    # 1) 边通过概率区间（Bonferroni 保守，层次 Beta 后验）
    nE = len(H.E)
    plo, phi = {}, {}
    for e in H.E:
        plo[e], phi[e] = beta_interval(stats[e], conf=1 - alpha/nE)
    # 2) 每个意图：路径分解 + Fréchet 串并联下界
    certs = {}
    for i in I_alpha:
        paths = simple_paths(H, H.q0, H.F[i], k_max=64)   # 截断只损紧致度
        path_lo = [series_lower([plo[e] for e in P]) for P in paths]
        lo = parallel_lower(path_lo)                      # = max(path_lo)
        hi = min(1.0, sum(series_upper([phi[e] for e in P]) for P in paths))
        certs[i] = SuccessCert(lo, hi, 1-alpha)
    p_rob = min(c.p_lo for c in certs.values())
    return p_rob, certs, weakest_edges(H, certs)

def series_lower(ps):     # Frechet: P(intersection) >= max(0, sum - (n-1))
    return max(0.0, sum(ps) - (len(ps) - 1))

def series_upper(ps):     # 独立即乘积（仅用于诊断上界）
    return prod(ps)

def parallel_lower(ps):   # P(union) >= max
    return max(ps) if ps else 0.0

def weakest_edges(H, certs):
    # 对每个意图做最早失效边溯源：沿最弱路径的 min-plo 边
    return {i: min_path(H, certs[i]).argmin_edge() for i in certs}
```

### IP-59 ACP：证书定价的主动澄清
```
def act(bel, x, certs, budget, tau=0.02, lam=0.5):
    i_exec = argmax(bel, key=lambda i: bel[i] * certs[i].p_lo)
    V_exec = certs[i_exec].p_lo
    best_q, V_clar = None, -inf
    for q in rank_questions(bel, x):
        exp_lo = expected_success_after(q, bel, x, certs)  # 后验模拟
        val = exp_lo - lam * budget.cost_of(q)
        if val > V_clar:
            best_q, V_clar = q, val
    # 1) 澄清有正收益且未超预算
    if best_q is not None and V_clar >= V_exec + tau \
            and budget.clarify_left > 0:
        return Clarify(best_q)          # 进入安全减速/停稳的认证澄清模式
    # 2) 否则按成功率下界决定执行或停
    if V_exec >= budget.p_req:
        return Execute(i_exec)
    return SafeStop()
```

## 6. 本轮最大风险

**一句话**：整套成功率证书的 soundness 只相对于**假设的意图信念**成立——一旦真实意图落在 `I_α` 之外（意图模型错设或 OOS），系统会在「证书显示高成功率」时执行错误任务，形成比单纯控制失败更隐蔽的「自信地失败」；因此 E87（意图覆盖）与 E88（成功率覆盖）必须作为红线实验，任一不达标即禁用自主执行、退回澄清或安全停。
