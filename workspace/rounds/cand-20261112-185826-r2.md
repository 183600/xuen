# 第 61 轮（承接第 60 轮「场景感知闭环」SGEC IP-153~160；灵感循环第 2 轮；本轮灵感：「数据采集」×「腕部相机」）

> 第 60 轮用 SSM×CIEC×EPIR×SERC×PCE++++ 建成了「场景→意图→约束→阻抗→执行→EV-exec→场景更新」的认知闭环。但它的两个隐含假设，正好被本轮的两个灵感词戳破：
> 1. **先验是「免费且可信」的**：π_scene(K|z) 与意图映射 ϕ 被默认为已存在。真实中它们必须靠**数据采集**获得——而采集要花时间、耗预算、带风险，且采到的样本来自当前策略本身（幸存者偏差 / 协变量漂移）。第 60 轮的 SSM 只回答了「如何用先验」，没回答「先验从哪来、值不值得采」。
> 2. **场景识别是「接触后」的**：SSM 的观测是力/位遥测，必须碰到才更新，所谓「先认知后执行」在物理上退化为「先接触后认知」。**腕部相机（eye-in-hand）**提供了接触前的视觉通道，但视觉对机械阻抗只是**代理观测**：运动模糊、手眼标定漂移、末端遮挡、光照变化都会让「看起来软」不等于「按下去软」。
> 3. **数据与证据不分**：第 60 轮的 SIC 用 EV-exec 更新 scene_conf，但若同一批数据既训练 π_scene 又充当验证证据，就会形成**自证循环**——模型越自信，证书越漂亮，现实越危险。数据采集必须同时引入**谱系隔离**。
>
> 本轮的核心命题：**先看一眼，只在信息增益值得时才去采，采来的数据不能给自己发证书。**

## 0. 直觉与动机

**灵感 1（腕部相机 → 视觉接触先验 VCP）**
直觉：第 60 轮的机器人是「闭眼摸桌」。腕部相机让它低头看一眼：表面法向 n̂、纹理 c_tex、到面距离 d̂、高光 s_spec、模糊程度 b_blur。于是能在接触前预测「还有多久碰到（τ̂_touch）」与「接触瞬间大概该用多大阻抗（K̂_pre）」。但视觉是**间接观测**：高光强不等于硬，纹理细不等于滑。关键洞见：**视觉只能提供一个关于 (z,K) 的似然 p(o_vis|z,K)，不能直接给出 K**；而且这个似然的可辨识性随速度（模糊）与标定残差（漂移）急剧下降——必须把模糊/漂移/遮挡显式写进协方差，而不是被点估计吞掉。

**灵感 2（数据采集 → 风险约束下的主动信息采集 AIDC）**
直觉：采集不是「多拍几张」，而是一个**有代价、有风险的动作**。戳一下未知表面能获得阻抗信息，也可能把表面戳坏——这就是「探索安全悖论」：想学 K_safe 必须先行动，但行动前又不知道 K_safe。关键洞见：**用「单位风险的信息增益」而不是「信息增益」来选采集动作**：IG(a) 再大，只要风险 R(a) 超过可逆动作边界，就绝不执行；采集动作必须限制在**可回退动作集 A_rev**（限力、短时、可撤回）内。采集的终止条件不是「采够了」，而是「继续采的边际信息增益已低于风险 + 成本」。

**灵感 3（数据采集 × 腕部相机 → 数据谱系隔离 DPI）**
直觉：用来训练先验的数据，和用来证明「执行合规」的证据，必须**物理隔离**。否则就是「用同一份答案既学习又打分」。关键洞见：给每条样本打上 (来源, 采集策略, 标定版本, train/evidence 划分) 的**哈希链谱系**；训练集样本永远不能计入 SIC/EV-exec 验证；证据窗口必须**预注册**（采集前就固定策略与切分），并设置**新鲜度**——过期的标定/场景数据不能给当前的 K_safe 背书。

**灵感 4（三灵感合流 → 看-探-诺闭环 VACL）**
直觉：把执行决策拆成三个承诺级别递增的阶段：**看（look，几乎零风险，只获外观/几何信息）→ 探（probe，有界风险，获机械阻抗信息）→ 诺（commit，执行，风险由 K_safe 决定）**。每一阶段只在「下一阶段的期望效用超过当前阶段 + 风险/成本」时才升级承诺。形成闭环：**看→（必要时）探→更新先验→编译 K_safe→诺→EV-exec→（仅用独立证据）更新场景信念**。

**灵感 5（PCE+++++ → 采集预算 B_data）**
直觉：第 60 轮的认知预算漏了「数据」这一维。数据采集消耗带宽、存储、标注、**风险**与**新鲜度**：B_data = (B_bw, B_store, B_label, B_risk, B_fresh)。若 B_risk 耗尽 ⇒ 禁止再探，退回视觉先验或通用先验；若 B_bw 耗尽 ⇒ 降帧率 / 事件触发 / 降分辨率；若 B_fresh 过期 ⇒ 膨胀协方差或重新采集。

## 1. 形式化定义（增量：定义 161–168）

**定义 161（视觉接触先验 VCP）** 腕部相机在接触前给出观测 o_vis = (n̂, c_tex, d̂, s_spec, b_blur, m_occ)。视觉似然与先验：
- p(o_vis | z, K) = N(o_vis; g(z,K), Σ_vis)
- Σ_vis = σ_blur²(v, t_exp, d̂)·I + σ_cal²(ξ_cal)·J Jᵀ + σ_occ²·diag(m_occ)
  其中 σ_blur ∝ v·t_exp/d̂（运动模糊），σ_cal 为手眼标定残差，m_occ 为末端遮挡掩码。
- 视觉接触先验：π_vis(K|z) ∝ ∫ p(o_vis|z,K)·π_scene(K|z)·p(z) dz。
- 关键：π_vis 只有在通过定义 166 的可辨识证书后，才允许收窄 K_safe。

**定义 162（主动信息采集 AIDC）** 给定当前信念 b = p(z,K|history) 与候选采集动作集 A = {look, probe, ask, skip}：
- 期望信息增益：IG(a) = E_{o~p(o|b,a)}[ KL(p(z,K|o,a,b) ‖ b) ]
- 动作风险：R(a) = P(损伤/碰撞 | a, b)，且要求 R(a) ≤ R_max
- 采集效用：U(a) = IG(a) − λ_risk·R(a) − λ_cost·c(a) − λ_age·Age(b)
- 策略：a* = argmax_{a∈A_rev, R(a)≤R_max, c(a)≤B_data} U(a)
- 其中 A_rev 为可回退动作集（限力 F_probe ≤ F_safe、时长 ≤ T_probe、可撤回）。若不存在可行 a，则 skip 并回退保守先验。

**定义 163（数据谱系账本 DPL）** 每条样本 s 附带谱系记录 prov(s) = (source, policy_id, t, calib_version, scene_label, split ∈ {train, evidence}, h_prev)，账本为哈希链 H_t = SHA256(H_{t-1} ‖ prov(s_t) ‖ hash(content(s_t)))。
- **证据独立性规则**：split=train 的样本不得计入 SIC/EV-exec 验证；证据窗口在采集前预注册。
- **污染判定**：若证据集 E 满足 E ∩ Train ≠ ∅，或 calib_version(E) 与执行标定不兼容，或 Age(E) > T_fresh，则 evidence_weight(E) = 0。

**定义 164（看-探-诺闭环 VACL）** 算子 VACL(M, task, B_data)：
```
① LOOK:      o_vis ← wrist_camera.capture(); π_vis ← VCP(o_vis, π_scene)
② CERTIFY:   cert_vis ← VIC.identify(π_vis); K_cand ← (cert_vis ? narrow(π_vis) : π_scene)
③ DECIDE:    a* ← LPC.decide(K_cand, b, B_data)      # look / probe / commit / skip
④ if a*=probe:
     EV_probe ← safe_probe(F_probe ≤ F_safe, T_probe)  # 可回退
     DPL.append(EV_probe, split=train); π_scene ← update(π_scene, EV_probe); goto ①
⑤ if a*=commit:
     K_safe ← EEIS.compile_with_prior(K_cand, δ_f_req)
     ERTC.lock(C_intent); execute(K_safe)
⑥ EV_exec ← build_exec_evidence(...); EPIR.append(EV_exec)
     DPL.append(EV_exec, split=evidence)
⑦ SIC.update(only evidence-split); B_data.consume(...)
⑧ return (K_safe, Cert_vis, DPL.root, B_data.remaining)
```

**定义 165（采集预算 PCE+++++）** B_data = (B_bw, B_store, B_label, B_risk, B_fresh)。cost_data(a) = λ_bw·bytes(a) + λ_store·storage(a) + λ_label·labels(a) + λ_risk·R(a) + λ_fresh·Staleness(b)。
- 若 B_risk ≤ 0：禁止 probe，仅允许 look 或 skip。
- 若 B_bw ≤ 0：切事件触发 / 降采样。
- 若 B_fresh 过期：π_scene 方差膨胀 Σ ← Σ + Σ_age，且禁止用旧数据发证书。
- 若 B_label ≤ 0：禁止主动学习标注，退化为自监督视觉先验。

**定义 166（视觉可辨识证书 VIC）** 关于 K 的视觉 Fisher 信息 F_vis(K) = E[∇_K log p(o_vis|z,K) ∇_K log p(o_vis|z,K)ᵀ]。
- VIC_valid = λ_min(F_vis) ≥ τ_fisher ∧ cond(F_vis) ≤ κ_max ∧ σ_cal ≤ δ_cal ∧ b_blur ≤ b_max ∧ |m_occ| ≤ m_max。
- 若 VIC_valid：允许把 K_safe 收窄至 ΔK_vis = f(F_vis⁻¹)；否则**禁止任何视觉驱动的收窄**，仅保留 π_scene。

**定义 167（看-探-诺序贯决策 LPC）** 三阶段承诺递增，动作空间 A = {look, probe, commit, skip}：
```
commit_ok = VIC_valid ∧ U(commit) ≥ max(U(look), U(probe))
probe_ok  = (¬commit_ok) ∧ U(probe) > U(look) ∧ B_risk > 0 ∧ R(probe) ≤ R_max
look_ok   = (¬commit_ok ∧ ¬probe_ok) ∧ U(look) > 0
a* = commit if commit_ok else probe if probe_ok else look if look_ok else skip
```
- **不可逆性约束**：commit 可能造成不可逆损伤，因此只有 probe 阶段允许采集数据；probe 必须在 A_rev 内；commit 阶段不再以「学习」为名冒险。

**定义 168（采集-证据隔离协议 DPL-Protocol）** 样本消息头扩展为 (sample_id, prov_hash, split, calib_version, policy_id, timestamp)。
- **链校验**：云端按 H_t 逐条验证哈希链，断裂即标记「谱系失效」。
- **切分校验**：split=evidence 的样本若其 prov_hash 出现在训练更新事件的可达集中，标记「污染」，权重置 0。
- **重放保护**：sample_id 单调递增，重复样本不重复计证据。
- **新鲜度**：Age(sample) > T_fresh 的证据不参与当前 K_safe 认证。

### IP-161 VCP（视觉接触先验）

```python
class VisualContactPrior:
    def __init__(self, scene_model):
        self.scene_model = scene_model

    def observe(self, o_vis, v_ee, calib_residual, occ_mask):
        feats = o_vis.features                       # [n̂, c_tex, d̂, s_spec, b_blur]
        sigma_blur = self.k_blur * v_ee * o_vis.t_exp / max(o_vis.d_hat, 1e-3)
        sigma_cal = self.k_cal * calib_residual
        Sigma_vis = (sigma_blur**2 * np.eye(len(feats))
                     + sigma_cal**2 * self.calib_jacobian(o_vis)
                     + self.sigma_occ**2 * np.diag(occ_mask))
        prior = self.scene_model.get_prior(o_vis.z_hat)
        lik = gaussian_likelihood(feats, self.render(o_vis.z_hat, prior.mu), Sigma_vis)
        return normalize(prior * lik), Sigma_vis
```

### IP-162 AIDC（主动信息采集）

```python
class ActiveInformationCollector:
    def __init__(self, R_max=0.05, lam_risk=1.0, lam_cost=0.1, lam_age=0.05):
        self.R_max = R_max
        self.lam_risk, self.lam_cost, self.lam_age = lam_risk, lam_cost, lam_age

    def select(self, belief, actions, B_data):
        best, best_u = None, -np.inf
        for a in actions:
            if a.type == 'probe' and a not in REVERSIBLE_ACTIONS:
                continue
            if a.type == 'probe' and (not B_data.can_probe()
                                      or self.risk(a, belief) > self.R_max):
                continue
            u = (self.info_gain(a, belief)
                 - self.lam_risk * self.risk(a, belief)
                 - self.lam_cost * a.cost
                 - self.lam_age * belief.age)
            if u > best_u:
                best, best_u = a, u
        return best if best_u > 0 else SKIP

    def info_gain(self, a, belief):
        samples = [belief.sample() for _ in range(self.n_mc)]
        return np.mean([self._kl_after(belief, a, s) for s in samples])
```

### IP-163 DPL（数据谱系账本）

```python
class DataProvenanceLedger:
    def __init__(self):
        self.chain = []
        self.train_hashes = set()
        self.root = GENESIS_HASH

    def append(self, sample, split):
        prov = dict(source=sample.source, policy_id=sample.policy_id,
                    t=sample.t, calib_version=sample.calib_version,
                    scene_label=sample.scene_label, split=split,
                    h_prev=self.root)
        h = sha256(json.dumps(prov, sort_keys=True).encode()
                   + sample.content_hash().encode()).hexdigest()
        self.chain.append((prov, h))
        self.root = h
        if split == 'train':
            self.train_hashes.add(sample.content_hash())
        return h

    def evidence_weight(self, sample, exec_calib_version, now):
        if sample.content_hash() in self.train_hashes:
            return 0.0
        if sample.calib_version != exec_calib_version:
            return 0.0
        if now - sample.t > T_FRESH:
            return 0.0
        return 1.0
```

### IP-164 VACL（看-探-诺闭环）

```python
def visual_active_collection_loop(M, task, B_data):
    o_vis = M.wrist_cam.capture()
    pi_vis, Sigma_vis = M.vcp.observe(o_vis, M.v_ee, M.calib_residual, o_vis.occ)
    cert_vis = M.vic.identify(pi_vis, Sigma_vis)
    K_cand = M.eeis.narrow(pi_vis) if cert_vis.valid else M.scene_model.prior

    a = M.aidc.select(M.belief, [LOOK, PROBE, COMMIT, SKIP], B_data)
    if a is PROBE:
        ev = M.safe_probe(F_safe=M.F_safe, T_probe=M.T_probe)   # 可回退探针
        M.dpl.append(ev, split='train')
        M.scene_model.update(ev)
        return visual_active_collection_loop(M, task, B_data)

    if a is COMMIT:
        K_safe = M.eeis.compile_with_prior(K_cand, task.delta_f_req)
        M.ertc.lock(M.intent_ctrl.constraint)
        M.execute(K_safe)

    ev_exec = build_exec_evidence(M.telemetry)
    M.epir.append(ev_exec)
    M.dpl.append(ev_exec, split='evidence')
    M.sic.update(M.dpl.evidence_only())
    B_data.consume(a)
    return M, K_safe, cert_vis, M.dpl.root, B_data.remaining
```

### IP-165 PCE+++++（采集预算）

```python
class DataBudget:
    def __init__(self, bw=1e6, store=1e9, label=100, risk=1.0, fresh=600.0):
        self.B_bw, self.B_store = bw, store
        self.B_label, self.B_risk, self.B_fresh = label, risk, fresh

    def can_probe(self):
        return self.B_risk > 0 and self.B_bw > 0

    def consume(self, action):
        self.B_bw -= action.bytes
        self.B_store -= action.storage
        self.B_label -= action.labels
        self.B_risk -= action.risk

    def fallback(self):
        if self.B_risk <= 0: return 'visual_only'
        if self.B_bw <= 0: return 'event_triggered'
        if self.B_label <= 0: return 'self_supervised'
        return 'normal'
```

### IP-166 VIC（视觉可辨识证书）

```python
class VisualIdentifiabilityCertificate:
    def identify(self, pi_vis, Sigma_vis):
        F = self.fisher_information(pi_vis, Sigma_vis)
        lam_min = np.linalg.eigvalsh(F).min()
        cond = np.linalg.cond(F)
        valid = (lam_min >= self.tau_fisher and cond <= self.kappa_max
                 and Sigma_vis[0, 0] <= self.delta_cal**2
                 and Sigma_vis[1, 1] <= self.b_max**2)
        return Cert(valid=valid, lam_min=lam_min, cond=cond,
                    max_narrowing=self._narrowing(F) if valid else 0.0)
```

### IP-167 LPC（看-探-诺序贯决策）

```python
class LookProbeCommit:
    def decide(self, K_cand, belief, B_data):
        u_commit = self.utility(COMMIT, K_cand, belief)
        u_probe = self.utility(PROBE, K_cand, belief)
        u_look = self.utility(LOOK, K_cand, belief)
        if self.vic_valid and u_commit >= max(u_look, u_probe):
            return COMMIT
        if (u_probe > u_look and B_data.can_probe()
                and self.risk(PROBE, belief) <= self.R_max):
            return PROBE
        return LOOK if u_look > 0 else SKIP
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VCP | O(d_vis²) / 帧 | O(d_vis²) | 视觉似然校准误差 ≤ δ_vis；模糊/漂移进入协方差 |
| AIDC | O(|A|·N_mc) / 决策 | O(N_mc) | 仅选择可回退且 R(a) ≤ R_max 的动作 |
| DPL | O(1) 追加 / O(log N) 校验 | O(N) | 哈希链防篡改；训练/证据切分不相交 |
| VACL | O(闭环) | 复用 | 视觉收窄受 VIC 约束；证据独立 |
| PCE+++++ | O(1) | O(1) | 任一预算耗尽触发对应降级 |

**正确性定理（VACL）**：假设 A66–A70 成立：
- (A66) 视觉似然 p(o_vis|z,K) 校准，且 Σ_vis 正确包含模糊/标定/遮挡项；
- (A67) 所有 probe 动作属于可回退集 A_rev，且 R(a) ≤ R_max；
- (A68) DPL 哈希链防篡改，split 标注诚实；
- (A69) 证据集与训练集不相交，且证据窗口预注册；
- (A70) B_data 各分量单调消耗。

则：
1. **视觉不越权**：若 VIC_valid = false，则 K_safe 不收窄（ΔK_vis = 0）；若 valid，收窄量 ≤ f(F_vis⁻¹)，不会超过视觉可辨识信息。
2. **采集不越险**：任何 probe 满足 R(a) ≤ R_max 且消耗 B_risk；B_risk 耗尽后不再 probe。
3. **证据不自证**：用于 SIC 的证据与训练集不相交，污染样本权重为 0。
4. **降级可预期**：任一 B_data 分量耗尽，触发 visual_only / event_triggered / self_supervised 等确定性回退。

## 4. 实验设计 E192–E196

| 实验 | 指标 | 目标 |
|---|---|---|
| E192 VCP | 视觉先验 ECE；模糊/标定漂移下可辨识精度 | ECE ≤ 0.05；漂移 2mm 时精度 ≥ 80% |
| E193 AIDC | 单位风险信息增益；达到目标不确定度所需 probe 数 | 比随机采集少 ≥ 40% probe |

### IP-161 VCP（视觉接触先验）

```python
class VisualContactPrior:
    def __init__(self, scene_model):
        self.scene_model = scene_model

    def observe(self, o_vis, v_ee, calib_residual, occ_mask):
        feats = o_vis.features                       # [n̂, c_tex, d̂, s_spec, b_blur]
        sigma_blur = self.k_blur * v_ee * o_vis.t_exp / max(o_vis.d_hat, 1e-3)
        sigma_cal = self.k_cal * calib_residual
        Sigma_vis = (sigma_blur**2 * np.eye(len(feats))
                     + sigma_cal**2 * self.calib_jacobian(o_vis)
                     + self.sigma_occ**2 * np.diag(occ_mask))
        prior = self.scene_model.get_prior(o_vis.z_hat)
        lik = gaussian_likelihood(feats, self.render(o_vis.z_hat, prior.mu), Sigma_vis)
        return normalize(prior * lik), Sigma_vis
```

### IP-162 AIDC（主动信息采集）

```python
class ActiveInformationCollector:
    def __init__(self, R_max=0.05, lam_risk=1.0, lam_cost=0.1, lam_age=0.05):
        self.R_max = R_max
        self.lam_risk, self.lam_cost, self.lam_age = lam_risk, lam_cost, lam_age

    def select(self, belief, actions, B_data):
        best, best_u = None, -np.inf
        for a in actions:
            if a.type == 'probe' and a not in REVERSIBLE_ACTIONS:
                continue
            if a.type == 'probe' and (not B_data.can_probe()
                                      or self.risk(a, belief) > self.R_max):
                continue
            u = (self.info_gain(a, belief)
                 - self.lam_risk * self.risk(a, belief)
                 - self.lam_cost * a.cost
                 - self.lam_age * belief.age)
            if u > best_u:
                best, best_u = a, u
        return best if best_u > 0 else SKIP

    def info_gain(self, a, belief):
        samples = [belief.sample() for _ in range(self.n_mc)]
        return np.mean([self._kl_after(belief, a, s) for s in samples])
```

### IP-163 DPL（数据谱系账本）

```python
class DataProvenanceLedger:
    def __init__(self):
        self.chain = []
        self.train_hashes = set()
        self.root = GENESIS_HASH

    def append(self, sample, split):
        prov = dict(source=sample.source, policy_id=sample.policy_id,
                    t=sample.t, calib_version=sample.calib_version,
                    scene_label=sample.scene_label, split=split,
                    h_prev=self.root)
        h = sha256(json.dumps(prov, sort_keys=True).encode()
                   + sample.content_hash().encode()).hexdigest()
        self.chain.append((prov, h))
        self.root = h
        if split == 'train':
            self.train_hashes.add(sample.content_hash())
        return h

    def evidence_weight(self, sample, exec_calib_version, now):
        if sample.content_hash() in self.train_hashes:
            return 0.0
        if sample.calib_version != exec_calib_version:
            return 0.0
        if now - sample.t > T_FRESH:
            return 0.0
        return 1.0
```

```python
def visual_active_collection_loop(M, task, B_data):
    o_vis = M.wrist_cam.capture()
    pi_vis, Sigma_vis = M.vcp.observe(o_vis, M.v_ee, M.calib_residual, o_vis.occ)
    cert_vis = M.vic.identify(pi_vis, Sigma_vis)

    a = M.aidc.select(M.belief, [LOOK, PROBE, COMMIT, SKIP], B_data)
    if a is PROBE:

        M.scene_model.update(ev)

    if a is COMMIT:
        K_safe = M.eeis.compile_with_prior(K_cand, task.delta_f_req)
        M.ertc.lock(M.intent_ctrl.constraint)
        M.execute(K_safe)

    ev_exec = build_exec_evidence(M.telemetry)
    M.epir.append(ev_exec)
    M.dpl.append(ev_exec, split='evidence')
    M.sic.update(M.dpl.evidence_only())
    B_data.consume(a)
```

### IP-165 PCE+++++（采集预算）

```python
class DataBudget:
    def __init__(self, bw=1e6, store=1e9, label=100, risk=1.0, fresh=600.0):
        self.B_bw, self.B_store = bw, store
        self.B_label, self.B_risk, self.B_fresh = label, risk, fresh

    def can_probe(self):
        return self.B_risk > 0 and self.B_bw > 0

    def consume(self, action):
        self.B_bw -= action.bytes
        self.B_store -= action.storage
        self.B_label -= action.labels
        self.B_risk -= action.risk

    def fallback(self):
        if self.B_risk <= 0: return 'visual_only'
        if self.B_bw <= 0: return 'event_triggered'
        if self.B_label <= 0: return 'self_supervised'
        return 'normal'
```

### IP-166 VIC（视觉可辨识证书）

```python
class VisualIdentifiabilityCertificate:
    def identify(self, pi_vis, Sigma_vis):
        F = self.fisher_information(pi_vis, Sigma_vis)
        lam_min = np.linalg.eigvalsh(F).min()
        cond = np.linalg.cond(F)
        valid = (lam_min >= self.tau_fisher and cond <= self.kappa_max
                 and Sigma_vis[0, 0] <= self.delta_cal**2
                 and Sigma_vis[1, 1] <= self.b_max**2)
        return Cert(valid=valid, lam_min=lam_min, cond=cond,
                    max_narrowing=self._narrowing(F) if valid else 0.0)
```

```python
class LookProbeCommit:
    def decide(self, K_cand, belief, B_data):
        u_commit = self.utility(COMMIT, K_cand, belief)
        u_probe = self.utility(PROBE, K_cand, belief)
        u_look = self.utility(LOOK, K_cand, belief)
        if self.vic_valid and u_commit >= max(u_look, u_probe):
            return COMMIT
        if (u_probe > u_look and B_data.can_probe()
                and self.risk(PROBE, belief) <= self.R_max):
            return PROBE
        return LOOK if u_look > 0 else SKIP
```

| 组件 | 时间 | 空间 | 正确性 |

| PCE+++++ | O(1) | O(1) | 任一预算耗尽触发对应降级 |

**正确性定理（VACL）**：若 A66–A70 成立：
1. **视觉不越权**：VIC_valid=false ⇒ ΔK_vis=0；valid ⇒ 收窄量 ≤ f(F_vis⁻¹)。
2. **采集不越险**：probe ∈ A_rev 且 R(a) ≤ R_max；B_risk 耗尽后禁止 probe。
3. **证据不自证**：SIC 证据 ∩ 训练集 = ∅，污染样本权重为 0。
4. **降级可预期**：B_risk/B_bw/B_label/B_fresh 任一耗尽 ⇒ visual_only / event_triggered / self_supervised / 方差膨胀。
