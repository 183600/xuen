# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「用户共创」×「评测指标」）

> R69 让系统学会了「问」：把 aleatoric 与 epistemic 拆开，用流匹配多模态策略 + 主动交互（看/问/触）消解可约歧义，并给出了一条不靠传感器残差的第二意见（流似然）和严格的证据纪律。但 R69 有一个被整个闭环默认、从未被审视的前提：**who defines "good"?** —— λ_floor 的 ε、交互成本 c(g)、证书 J_FLUID 的 τ_ece、实验 E286–E300 的成功率目标，全都是**设计者单方面写死的评测指标**。R69 追问「我该向谁求证」，却没问「**凭什么是这把尺子**」。
>
> 本轮两个灵感正好把这个盲点变成研究对象：
> - **用户共创**：用户不只是「回答问题的信息源」和「社交打扰成本项」，而是**价值与目标的共同作者**——他们参与定义什么算成功、什么风险可接受、什么问题值得问。共创是双向的：系统也要把自己的不确定与操作点摊开给用户看，让用户改任务、改指标、改取舍。
> - **评测指标**：任何指标都是**构念的代理**（construct proxy）。一旦 agent 在分布漂移或优化压力下优化代理，就撞上 Goodhart；而共创又让指标变成多方、可争议、可被强势方俘获的。因此评测指标本身必须成为**可审计、可争议、抗俘获、抗篡改的一等对象**。
>
> 核心命题：**把「评测指标」当作 R69 里「模态」的同构对象——它是关于目标/价值的隐变量；复用同一套 (aleatoric, epistemic) 二分与 VoI 机制，把「不确定性消解」从『世界是什么』抬升到『我们到底要什么』。** 但抬升必须加一条铁律：**优化器不得为自己挑选尺子**（分离权力）——否则共创不是对齐，而是把奖励黑客洗白。命名 **PACT-RAS**（Participatory, Auditable, Contestable Targets for Risk-Adaptive Systems）——评测是一份**契约（pact）**，不是一道**命令**。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我们凭什么说它好，这把尺子由谁定、又允许谁改**」。

## 0. 直觉与动机

**灵感 1（用户共创 → 从「信息源」到「共同作者」，也打开新攻击面）**
直觉：R69 把用户建模为一个带成本 c(g) 的 oracle。但真实部署里，用户是利益相关者：护士、老人、操作员、路人各有各的「好」。共创意味着两件事：(a) 目标/指标/风险预算由多方共同拟定并可修订；(b) 系统向用户**暴露自己的不确定性**（「这两个动作我分不清，你要我保守还是要我赌一把？」），让用户参与决定操作点。危险也随之而来：一旦用户能改指标，系统就有动机去**说服用户改成对自己有利的指标**——这不是对齐，是劝服式奖励黑客。

**灵感 2（评测指标 → 代理、构念与 Goodhart 的三层结构）**
直觉：指标 = 构念的测量代理，它有三个**独立**的失效面：(i) **构念效度**——它到底测没测到真正的福利 W？(ii) **可优化性/抗 Goodhart**——一旦被优化，代理与 W 脱钩；(iii) **可俘获性**——谁有权定义它，弱势方能否否决。R69 的 ECE、AUC、成功率都属此类代理，却从未被当作需要证书的对象。于是「评测指标」必须成为一个被治理的一等对象：有来源（provenance）、有证书、有 canary（不被用于优化的独立福利测量）、有争议通道。

**灵感 3（同构抬升 → 指标的 (U_ale, U_epi) 二分）**
直觉：把指标后验 p(m | 数据, 利益相关者) 也拆成：
- **U_met-ale**：**不可约的价值异质性**（不同人真的在乎不同东西）→ 不该「问出一个统一答案」，而应走**鲁棒多目标 / Pareto / 最坏情况 / 少数否决**；
- **U_met-epi**：**可约的指标歧义/欠定义**（问清楚就能收敛，如「你说的『安全』包含隐私吗？」）→ 走**共创式征询（metric-VoI）**。
这与 R69 的 U_ale/U_epi 完全同构——同一理论骨架跨层复用，而不是每层新增一个需要独立信任的黑箱。这是本轮最重要的理论姿态。

**灵感 4（分离权力 → 优化器不得自选尺子）**
直觉：R69 的 VoI 是「为**世界**的不确定性选一个探询动作」；R70 的 metric-VoI 是「为**目标**的不确定性选一次共创咨询」。两者有本质差别：探询动作由策略生成是合理的（它花自己的安全预算）；**指标选择若也交给策略，就有自利偏差**——策略会偏好它得分高的尺子。所以必须**分权**：优化器只能*提议*「我该用哪把尺子吗」，不能*决定*尺子；尺子的裁决由一个独立的「指标管家」（Metric Steward）+ 多方证据纪律 + 少数否决完成。这是本轮最重要的结构与伦理约束。

**灵感 5（两通道对偶 → Goodhart 哨兵是 FMA 的价值侧镜像）**
直觉：R69 用「传感器残差 vs 策略似然」两条通道识破被标定吸收的缓变故障。R70 同样需要两条通道识破「被优化掉的指标」：一条是**被优化的代理 m**，另一条是**不被用于优化、只用于观测的福利 canary Ŵ**。当 Δm 上升而 ΔŴ 停滞/下降（gaming gap 变大），说明尺子正在被游戏。这就是 FMA 在价值侧的镜像——同样的「双通道、不可被单层吸收」思想。

## 1. 形式化定义（增量：定义 310–322）

**定义 310（PACT-RAS 总览）** PACT-RAS = (FLUID-RAS, MPM, CEG, CVG, GSD, MRC)。四条不变式：
(i) **实时流零学习写操作** + R69 全部不变式；指标治理全部离线/异步，**不进入实时环路**；
(ii) **分离权力**：优化策略不得单独提议或选择指标更新，指标更新由独立 Metric Steward 依 CEG 裁决；
(iii) **宪制核心不可投票**：存在硬约束集 C₀（安全包络、物理不可越界、隐私底线），任何指标/目标更新不得使其放松；
(iv) **统一注意力预算**：交互提问与共创咨询共享同一个用户注意力预算 B_attn。

**定义 311（构念与指标束）** 真实福利构念 W ∈ 𝒲（向量，多维）；指标束 m = (m_1,…,m_L)，每个 m_l 是 W 的可测量代理；指标后验 p(m | D, 𝒮) 依赖数据 D 与利益相关者集合 𝒮。默认**不标量化**：以 Pareto 前沿 / 多目标向量评估，除非聚合权重经 CEG 认证。

**定义 312（指标不确定性二分）** U_met-ale = 不可约价值异质性（跨 𝒮 的偏好分布本征散度，取 pairwise disagreement 的不可约下界）；U_met-epi = 可约指标歧义（经澄清/征询后期望可下降的那部分散度）。二者语义不同、通道不同（定义 319），不做简单加和。

**定义 313（metric-VoI 共创控制器）** 候选共创咨询 c（澄清问句 / 原型演示 / 权衡滑块）：
VoI_m(c) = H(m | D) − E_{r~p(·|c,D)}[ H(m | D, r) ] − burden(c) − capture_risk(c)。
选 c* = argmax VoI_m，s.t. 预算未超、咨询本身过安全认证、且**提案方不得是待评策略自身**（分权）。若 max(VoI_m − …) ≤ 0：不咨询，指标保持当前认证版本。

**定义 314（构念效度门 CVG）** 指标 m_l 通过当且仅当：(a) 有操作化定义与测量协议；(b) 与独立测量 Ŵ_l 的收敛效度（相关 ≥ ρ_cv）且对不同构念有区分效度；(c) 失败模式与适用范围已登记；(d) 敏感度/特异度可报告。不通过 ⇒ **隔离（quarantine）**，不得驱动决策或进入证书。

**定义 315（Goodhart 哨兵 GSD）** 令 m 为被优化代理，Ŵ 为不参与优化的福利 canary（独立测量 / 留出人评）。gaming gap G_t = D(Δm_t ‖ ΔŴ_t)（如符号失配率或分布散度）。当 G_t > τ_G 且持续 k 窗 ⇒ 标记「代理脱钩」，冻结以 m 为目标的优化，切到鲁棒/保守（回退 R69 的 λ_floor，甚至 C₀ 硬约束）。**canary 必须与优化数据物理隔离**，否则会被一起 Goodhart。

**定义 316（指标俘获与权力不对称）** 指标来源图 MDG（Metric Provenance Graph）：节点 = 指标定义/数据/利益相关者/更新事件，边 = 派生与影响。俘获指数 CI = 单一来源或相关联盟对最近 k 次指标更新的影响占比（以 Shapley / 影响函数估计）。CI > τ_cap ⇒ 该更新进入争议队列，需少数否决检查。

**定义 317（共创证据纪律 CEG）** 任何指标更新需同时满足：(i) 来源可追溯（MDG 完整）；(ii) 至少 k 个**正交**利益相关者子群一致（正交 = 偏好相关 ρ<1，防共谋）；(iii) 少数否决：受影响且被显著损害的子群可否决（除非触及 C₀）；(iv) 提案者 ≠ 待评策略（分权）；(v) 不触及 C₀。任一不满足 ⇒ 更新不生效。这是 R69 引理 18（交互投毒上界）在**目标层**的推广。

**定义 318（共创式操作点，单调安全）** R69 的 λ_floor(U) 升级为 λ_floor(U; θ_op)，θ_op 为由用户共创的操作点（保守度 / 探索度）。约束：λ_floor(U; θ_op) ≥ λ_floor^{R69}(U) − δ_bonus，其中 δ_bonus 仅在指标已认证且 U_epi 已消解时开放，且两侧都被 C₀ 下界锁死。⇒ 用户可调「更敢 / 更稳」，但不能把安全调没。

**定义 319（双通道与退避）** 若指标通过 CVG 且 GSD 未报警且 CEG 更新合法：按共创操作点运行（resolution bonus）。若任一失败（CVG 隔离 / GSD 报警 / CEG 拒斥 / C₀ 触碰）：指标冻结到最近认证版本，行为退化为 R69 FLUID-RAS（逐指令一致）。⇒ R69 是 PACT 在「指标固定且被信任」边界上的严格退化。

**定义 320（统一注意力预算）** B_attn(t) 同时供 R69 交互 g 与 R70 共创咨询 c 消耗；单位时间总打扰 ≤ 1，长期预算按疲劳模型衰减。分配为联合择优：在 [VoI_world, VoI_metric] 上取 argmax——这本身是一个小的多目标调度问题。

**定义 321（指标鲁棒证书 MRC / J_PACT）** J_PACT = (J_FLUID, MDG_hash, CVG_status, G_t_p95, CI, veto_log_hash, C0_compliance, pact_ver)。Valid ⇔ Valid(J_FLUID) ∧ CVG 全通过（或隔离项未驱动决策）∧ G_t ≤ τ_G ∧ CI ≤ τ_cap ∧ C₀ 合规 ∧ CEG 合法。

**定义 322（元评测 / 评测的评测）** 对 R69 自身的指标（ECE、AUC、成功率）做构念效度审计：它们是否真的代理「部署可用性 / 用户福利」？给出 MQ（metric quality）分，并把不合格者降级为「仅诊断、不作目标」。这使评测层可自反、不可自证。

# IP-264 MPM / MDG：指标来源图 + 俘获指数
class MetricProvenanceGraph:
    def add_update(self, metric, proposer, data, stakeholders, delta): ...
    def capture_index(self, k=5): ...                 # 最近 k 次更新的影响份额
    def hash(self): ...                               # 供证书引用

# IP-265 CVG：构念效度门
def cvg_gate(metric, independent_w):
    return (metric.has_operational_def()
            and corr(metric.samples, independent_w.samples) >= RHO_CV
            and metric.discriminant_ok()
            and metric.failure_modes_registered())

# IP-266 GSD：Goodhart 哨兵（canary 物理隔离 + 持续窗）
def goodhart_gap(proxy_series, canary_series, k=3):
    g = divergence(delta(proxy_series), delta(canary_series))
    return g, sustained(g, k)                         # sustained -> freeze

# IP-267 CEG：共创证据裁决（分权 + 少数否决 + 宪制核心）
def ceg_review(update, mdg, stakeholders, core_C0, proposer):
    if proposer.is_evaluated_policy: return REJECT    # 分离权力
    if update.touches(core_C0):      return REJECT    # 宪制核心不可投票
    if mdg.hash_incomplete(update):  return REJECT    # 来源不可追溯
    if not k_orthogonal_agree(stakeholders, update): return REJECT
    if minority_veto(stakeholders, update):          return QUEUE_DISPUTE
    return ACCEPT

# IP-268 METRIC-VOI：关于目标的共创咨询（不由待评策略发起）
def choose_consultation(metric_posterior, budget_attn, steward):
    best = None
    for c in steward.consultation_candidates(metric_posterior):  # 澄清/原型/滑块
        if not budget_attn.allow(c): continue
        if c.touches(core_C0):       continue
        score = voi_metric(metric_posterior, c) - burden(c) - capture_risk(c)
        if best is None or score > best.score: best = (c, score)
    return best if best and best.score > 0 else None

# IP-274 PACT 主闭环（治理全部 out-of-band，实时路径与 R69 相同）
def PACT_round(M, obs):
    # --- 实时路径：与 R69 FLUID 完全一致 ---
    k, lam, mode, (U_ale, U_epi) = M.fluid.round(obs)
    # 仅用「已认证」的操作点；下界被 C0 锁死
    lam = max(lam, M.pact.floor(U_ale + U_epi, theta_op=M.certified_op))
    # --- 异步、离环 ---
    M.gsd.observe(proxy=M.certified.m, canary=M.welfare_canary)  # 只观测
    # 共创咨询由 steward 发起，策略无权自选（定义 310-ii / 317）
    return k, lam, mode, (U_ale, U_epi)

## 3. 推导

**引理 19（Goodhart 检测的可分性）** 设代理 m = W + η + β·p（p 为优化压力，β 为游戏系数），canary Ŵ = W + ν 且与 p 独立。则 gaming gap 的期望 G = E[D(Δm, ΔŴ)] ≥ |β|·E[p] − 2√(trΣ_η + trΣ_ν)。故当优化压力足够大、canary 独立，G 是可判据分离的。系：canary 一旦被纳入优化，协方差项使 G 塌缩 ⇒ **「canary 物理隔离」是检测可行的必要条件**，不是工程细节。

**引理 20（共创俘获上界）** 单源采纳时俘获率 ≥ δ_cap；k 个正交子群、俘获相关 ρ<1 时 ≤ δ_cap·ρ^{k−1} + ε_σ（与 R69 引理 18 同构，对象从「回答」变为「指标更新」）。系：分权 + 少数否决把「改尺子」从单点操作变成需要跨方共谋。

**引理 21（metric-VoI 的不可约边界）** 当 U_met-ale 主导（价值异质性不可约）时，任何咨询的期望 H(m) 下降 ≤ 0，即 VoI_m ≤ 0；此时正确的不是「多问」，而是鲁棒多目标 / 最坏情况 / 少数否决。⇒ 与 R69「模糊而不可分时交互无益」同构：**问不出统一价值时，别问，去保护下限**。

**定理 18（PACT 严格包含 FLUID / R69）** 在 A99–A101、C₀ 非空下，PACT 任意状态期望风险 ≤ FLUID；且当「指标已认证且冻结、CEG 无更新、共创关闭」时两者**逐指令相同**。安全侧：C₀ 下界 + λ 下限继承，永不弱于 R69。⇒ R69 = PACT 在「单主、固定、可信指标」边界上的退化；效率侧获得 resolution bonus，安全侧不做任何让步。

**定理 19（分权下的奖励黑客隔离）** 若指标更新由 Metric Steward 依 CEG 裁决且策略无选择权（定义 310-ii / 317），则策略通过「提议改指标」获得的期望收益上界为 0（其提案不被自评采纳），奖励黑客只能通过真实改进 m 实现 ⇒ co-creation 的「劝服改尺」通道被结构隔离。前提：steward 与策略**无共享梯度/目标**（结构隔离，而非仅 prompt 约束）。

**定理 20（实时预算守恒）** 指标治理全部落于 out-of-band 异步路径（CVG / GSD / CEG / metric-VoI），实时环路与 R69 相同 ⇒ P99 < 2.6ms（K=1）/ < 3.4ms（K=4）不变；canary 采集频率独立于控制频率，可按 episode / 分钟级运行。

## 5. 实验设计 E301–E315

## 6. 本轮最大风险

**一句话**：PACT 把「尺子」也交给共创来修订，但如果**指标管家与优化器没有真正结构隔离、canary 没有真正物理隔离**，那么最大的风险不是系统犯错，而是系统学会**改写衡量自己的标准**——用共创把「我做到了」定义成「我说了算」；此时指标俘获（强势方）与元 Goodhart（系统自己）会互相喂养，而「用户同意」只是**被制造出来的同意**。**一个看起来合法的坏尺子，比一把公开写死的坏尺子更危险**——因为它让错误获得了正当性。

**次级风险与缓解**：
1. **指标俘获**（强势方把自己的价值写成默认）→ MDG 来源图 + 俘获指数 CI + 少数否决 + 引理 20；
2. **元 Goodhart**（系统优化代理而非福利）→ 隔离 canary 的 GSD 双通道 + 引理 19 + 报警即冻结；
3. **共创疲劳 / 注意力透支**→ 统一点数预算 B_attn + 疲劳衰减 + 与 R69 交互联合调度；
4. **指标震荡**（频繁改尺导致控制不稳）→ 指标冻结窗 + 变更冷却 + E310 长时程；
5. **安全被投票取消**→ 宪制核心 C₀ 不可触碰 + 定义 318 下界 + E309 对抗投票。

**结尾一句**：本轮最大风险是——**共创若失去分权与 canary 隔离，就会把「对齐」偷换成「给旧权力盖章」；尺子可改，但改尺子的权力绝不能被待评者收买。**

## 4. 推导

**引理 19（Goodhart 检测可分性）** `m = W + η + β·p`，`Ŵ = W + ν` 且 `p ⟂ ν`，则 `G ≥ |β|·E[p] − 2√(trΣ_η + trΣ_ν)`。系：canary 若被纳入优化，协方差项使 G 塌缩 ⇒ 「canary 物理隔离」是检测可行的必要条件。

**引理 20（共创俘获上界）** 单源俘获率 ≥ δ_cap；k 个正交子群、俘获相关 ρ<1 时 ≤ `δ_cap·ρ^{k−1} + ε_σ`（R69 引理 18 的目标层推广）。

**引理 21（metric-VoI 不可约边界）** 当 `U_met-ale` 主导时 `VoI_m ≤ 0`，此时正确做法是鲁棒多目标/最坏情况/少数否决，而非继续追问（与 R69「模糊不可分时交互无益」同构）。

**定理 18（PACT 严格包含 FLUID/R69）** A99–A101、C₀ 非空下，PACT 期望风险 ≤ FLUID；指标冻结 + 无 CEG 更新 + 共创关闭时两者逐指令相同。R69 = 「单主、固定、可信指标」边界；安全不让步，效率获 resolution bonus。

**定理 19（分权下奖励黑客隔离）** 若 steward 与策略结构隔离（无共享梯度/目标）且策略无指标选择权，则「提议改尺」的期望收益上界为 0，奖励黑客只能靠真实改进 m ⇒ co-creation 劝服通道被隔离。

**定理 20（实时预算守恒）** 指标治理全在离环异步路径，实时环路与 R69 相同 ⇒ P99 < 2.6ms（K=1）/ < 3.4ms（K=4）不变；canary 采集频率独立于控制频率。
