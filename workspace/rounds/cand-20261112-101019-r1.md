# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 1 轮；本轮灵感：「谐波减速器」×「VLA」）

> 第 57 轮把安全的赌注从"模型置信"一路换到"少样本可校准、跨模态可对账、个性化有界的证据承诺"，纵深五层，并把一切判定器送进隔离区。但它仍然默认了两件从未被正面认证的事：**(a) 物理转导通道是忠实且平稳的**——从"探针指令"到"实际接触力"之间的谐波减速器会把指令变成什么力，被当成"命令≈输出"；**(b) 意图转导通道是透明可审计的**——从"语言任务"到"动作"之间的 VLA 被当成一个可以说清、可以信任的策略。现实恰好在两个接口处失效：谐波减速器的柔轮在变形、迟滞环在耗散、空回虽近零却非零、刚度/效率/健康随温度与磨损漂移——**测量仪器本身在变**；VLA 的开放词汇泛化越强，其物理天真与自信幻觉越危险。本轮不加第七类证据堆在顶上，而是**给证据脚下的整条转导链做认证**：力证据必须携带运行时**力保真证书 φ_t**，语义必须经过**语义-物理对账 G(r)**，承诺必须按**实际会执行的动作**（而非想执行的动作）计算风险。核心命题由"少样本可校准、跨模态可对账、个性化有界的证据说可信"升级为 **"转导可保真、语义可证伪、动作按实际执行认证的证据说可信"**。

核心矛盾：
- **H32（语义先验 vs 物理执行）**：VLA 可以语义正确而物理错误（把玻璃当地面、把墙当门），力证据可以物理测得准而模型偏（减速器磨损使电流→力矩的映射系统性偏移）。二者串联，失败概率是乘积：再完美的语义计划穿过有偏的力估计仍是自信地错；再干净的力信号喂给误接地（mis-grounding）的计划仍会高效地推错对象。**强链不能救弱链**——这是本轮与"多模态一致即证据"最不同的地方：语义一致不构成物理可执行。
- **H33（近零背隙 vs 非平稳隐状态）**：谐波减速器赢得信任恰恰靠"近零背隙≈指令等于输出"；但近零不是零，且刚度 k_θ、迟滞 ℓ_hys、失动 ℓ_lm、效率 η、磨损 w 与健康 h 都是隐藏状态，随温度、载荷、疲劳漂移。于是**测量仪器是非平稳的**：昨天获得的力证据在今天的仪器上未必成立；认证传动器的又是传动器自己（无限回退）。
- **H34（开放词汇 vs 可审计证据）**：VLA 的价值是无界的语言/视觉泛化，而证据门需要**有界、可证伪、可审计**的谓词。语言一致性不是真值——一个 VLA 可以在复述扰动下既自信又一致地错。把"VLA 说这是稳的"当证据，等于把第 57 轮刚补上的幻觉洞重新打开。

## 0. 直觉与动机

**灵感 1（谐波减速器 → 传动自模型与力保真证书）**
直觉：谐波减速器是"意图"与"世界"之间的脚踝——波发生器把柔轮撑成椭圆，靠连续行波啮合把高速小力矩变成低速大力矩。它几乎无背隙，却也因此被工程师默认为"指令即输出"；真实链条里有扭转变形、迟滞、零附近的失动死区、随载荷与温度变化的效率，以及一个最阴险的失效：柔轮疲劳裂纹——**平时几乎无征兆，发生后刚度骤降、迟滞放大**。更麻烦的是，四足上很少装输出力矩传感器，输出力矩通常由电机电流/力矩反推，这个反推在磨损后会有系统偏差。于是力证据不是裸真相，而是"穿过一台有隐状态、会磨损的仪器的读数"。本轮给它配一个**传动自模型 TSM**：在**摆动相（腿不承重）或用已知标定面做 L1 轻触**时，施加力矩受限的**微幅双向 dither**，测出力-位移迟滞环——环的斜率给 k_θ、零力矩处环宽给 ℓ_lm、环面积给 ℓ_hys、准静态力矩比给 η、参数漂移给磨损 w；由此在线估计隐状态并输出一个**运行时力保真上界 φ_t**（真实输出力矩与估计值之差的最坏值）。力证据按 φ_t 折扣；φ_t 超限时，力证据对不可逆接触一律不可用。关键工程甜点：**用身体最安全的时刻（摆动相）去校准身体**，把校准本身变成非破坏性的 L1 探针。

**灵感 2（"lost motion" → 意图-执行失配预算：认证实际会执行的动作）**
直觉：减速器的失动是零力矩附近的死区——你发了指令，输出要先走完一段空程才动。语义到物理之间也有这样一段"空程"：策略的量化、VLA 的接地误差、减速器的迟滞、观测的偏差，叠加成"我想要的"与"实际发生的"之间的间隔。安全论证不应在**意图动作**上算风险，而应在**最坏情况下实际会被执行的动作集合**上算。于是定义**转导预算 B_t** 与最坏执行集 A_wc(a)=a⊕Ball(B_t)：承诺当且仅当对 A_wc 中每个动作风险都 ≤δ。这条同时约束 VLA 的**动作分块时域**：VLA 爱一次输出几十步的开环块（效率高），但块越长，隐藏的传动漂移与语义漂移累积越多；因此分块长度 T_chunk 必须由 B_t 封顶，健康告警或语义 OOD 时把"开环缰绳"缩到单步闭环。**背隙是零附近的死区；信任的背隙是语义与物理之间的死区。**

**灵感 3（VLA → 可证伪的提案者，而不是证据来源）**
直觉：VLA 最该做的不是"下结论"，而是"提假设"——它看图看字，能提出"这里像可承重平台""那扇门可能可推""该探这三个点"，这正是探询最缺的先验，能省大量探针。但它的一切输出只能当**提案**，不能当**裁决**。于是把 VLA 接成三件事：**(i) 语义 OOD 门**——复述集成/动作块分歧/指令新颖度超阈即判语义分布外，其声明一律降为不可用；**(ii) 声明编译器**——把开放词汇断言翻译成有界谓词集 𝒫（flat / load_bearing / slippery / obstacle / openable / clear_path…），每个谓词绑定一个物理探针与预期物理签名，翻不出来的断言直接拒绝；**(iii) 可证伪过滤器**——只有存在某个可能观测能反驳的断言才允许成为证据候选。VLA 提高效率、物理提供健全性，正好复刻第 57 轮"元先验给效率、共形给保底"的分工，只是把"元先验"换成了"语义先验"。

**灵感 4（合流 → 语义-物理对账 SPR 与 EV-sem 限 L0/L1）**
直觉：把 VLA 对动作效果的预测与物理实测放到同一张账上对账，得到**语义-物理间隙 G(r)**：预测接触力 vs 认证区间、预测可通行 vs 探针后验、预测滑动 vs 本体/声学。G 大即强制加宽/降速/降接触级；G 小且断言**确实被一次物理探针检验过**，才给效率信用。这里有一条比"多模态一致"更硬的纪律：**一致不构成证据，只有"经受了证伪而未死"才构成证据**。因此 EV-sem 仅限 L0/L1、仅限已接地且已证伪的谓词，且**永不进入不可逆接触的必要证据集**；物理与语义冲突时物理优先，并把该 VLA 声明回溯记为误接地，更新其语义可靠性。

**灵感 5（健康感知证据寿命 + 转导预算 → 算子 PCE-T）**
直觉：既然尺子会变，旧测量就有保质期。每条力证据盖上 (模型版本, 健康状态, 时间, 上次有效 ID) 的戳；保真告警一响，回溯隔离"上次有效 dither-ID 之后"的全部力证据，要求复验——这是第 57 轮"事后证伪回溯降权"从模态推广到**仪器**："尺子换了，所有旧读数都要重审。"PCE-T 在 PCE+ 的每个检查点前插入传动体检：φ_t 超阈或健康告警或 ID 过期 → 先做摆动相 dither-ID；再做语义-物理对账；再按折扣后的证据门判断；最后按转导预算封顶分块。所有新机制只经"信念更准（含加宽）"或"动作更保守（缩分块/升接触级/加佐证/缩超时）"两个通道起作用。

**灵感 6（合流 → 认证链 J_t：一切转导走隔离）**
直觉：第 56 轮说"地图证据走隔离"，第 57 轮推广到"一切判定器走隔离"；本轮再推一层——**一切转导器（含 VLA 与传动模型）走隔离**。云端可以下发更好的 VLA 或更准的传动模型，但它们必须先以影子模式在边端跑，且通过的不只是语义基准，而是**物理接地回归**（预测动作效果是否匹配实测）与 **dither-ID 真值回归**（估计的刚度/失动/迟滞是否匹配辨识真值）。一个语义榜单更高但物理接地更差的 VLA 必须被拒绝接管。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（谐波传动自模型 TSM 与力保真证书）** 关节 j 的减速器隐状态 m_j=(k_θ,ℓ_lm,ℓ_hys,η,w,h)，k_θ 扭转刚度、ℓ_lm 失动量、ℓ_hys 迟滞半宽、η 效率、w 磨损、h∈{H0 健康,H1 退化,H2 裂纹告警}。观测量：电机力矩 τ_m、电机角 θ_m、输出角 θ_o（或腿运动学/IMU 反解）、可选输出力矩 τ_o。标称模型 τ_o^ideal=Nητ_m，扭转变形 δ=τ_o/k_θ+δ_hys+δ_lm，力矩观测器
τ̂_o = k̂_θ(θ_m/N − θ_o − δ̂_hys − δ̂_lm)。
**dither-ID 探针**：在摆动相（无接触）或已知标定面上的 L1 轻触，施加力矩受限序列 {+τ_id,0,−τ_id,0}ⁿ（|τ_id|≤τ_id^max，低频），由迟滞环斜率估 k_θ、零力矩环宽估 ℓ_lm、环面积估 ℓ_hys、准静态比估 η、参数漂移估 w；辨识结果只在声明的**载荷/温度/幅值有效域**内有效，域外按区间外推并放大不确定度。
**力保真证书**：
φ_t(u)=sup_{m∈𝓜_t}|τ_o(m;u)−τ̂_o(u)|，
其中 𝓜_t 为由 ID 结果、有效域与健康先验构成的可信参数集；φ_t 是概率 ≥1−δ_tsm 的上界。健康由 CUSUM 监视残差 r_t=τ̂_o−τ_o（无 τ_o 时用腿端力/IMU 反解替代），h=H2 或参数漂移超阈即**保真告警**。**单向公理**：TSM 只能通过升高 φ_t、缩窄有效域、升级健康告警来影响系统，禁止用自模型去降低任何证据要求。

**定义 140（传动折扣证据 TDE 与健康感知寿命 HAL）** 力派生证据 e 携带认证区间 F_e=[τ̂_o−φ_t, τ̂_o+φ_t]。规则：(D1) EV-margin 仅在区间**最坏端点**仍满足裕度时成立；(D2) EV-probe 用区间似然/稳健贝叶斯，σ_e²←σ_e²+(φ_t/κ)²，等价地 w_e←w_e·κ(φ_t)，κ 非增；(D3) φ_t>φ_max ⇒ 力派生证据对不可逆接触**不可用**，仅可作 L1 弱先验。**健康感知寿命**：stamp(e)=(v_model,h,t,last_ID)；有效权 λ_e(Δt,Δh) 随健康漂移与时间非增；保真告警触发**回溯隔离**——上次有效 dither-ID 之后的所有力派生证据强制复验，未复验者不得支撑许可性结论（仍可支撑"更保守"的结论）。这条把"坏证据长寿"从证据层下移到仪器层。

**定义 141（语义-物理对账 SPR、语义 OOD 与 EV-sem）** VLA π_VLA:(o_instr,I)→(a, C)，C⊆𝒫 为有界谓词声明，每个 c∈𝒫 绑定探针算子 p(c) 与预期物理签名。**语义 OOD 门** s_sem=−log p̂_consist(复述集成、动作块分歧、指令新颖度)；s_sem>θ_sem ⇒ 语义分布外，C 不可用且 T_chunk→T_min。**语义-物理间隙** G(r)=Σ_c w_c d_c(ŷ_c(a), y_phys^cert(r))/Σ_c w_c，其中 y_phys^cert 为认证区间（含预测/实测接触力、可通行、滑动）。**EV-sem 成立 ⇔** c∈𝒫 ∧ **可证伪**（∃ 观测能反驳）∧ 已由 p(c) 物理执行接地 ∧ G≤θ_G ∧ s_sem≤θ_sem；EV-sem 仅限 L0/L1，可作为一次 L1 佐证或减少探针数，**不得进入不可逆接触必要证据集**；物理与语义冲突 ⇒ 物理优先并把该声明回溯为误接地、更新语义可靠性 ρ_sem^VLA（乘性降级、有界恢复）。

**定义 142（转导预算 TBC 与 VLA 分块时域）** 转导误差预算 B_t=ε_sem+ε_pol+ε_trans(φ_t)+ε_est，各项均为认证上界（或区间）。最坏执行集 A_wc(a)=a⊕Ball(B_t)（位置/力空间）。承诺 g 健全 ⇔ ∀a′∈A_wc(a_g): R(a′)≤δ_f(g) ∧ 证据门过。分块漂移界 B_t(T)≤B_0+ρ_semT+ρ_transT，要求 ≤B_max；T_chunk=min(T_VLA, T_max(B_t), T_reground)，其中 T_reground 为下一次强制物理重接地间隔；保真告警或语义 OOD ⇒ T_chunk=T_min（逐步闭环）。**认证实际执行的动作，不认证想执行的动作。**

**定义 143（转导认证链 J_t）** J_t=(J_p, m̂, φ_t, ID_log, health_log, alarm_log, grounding_map, G_log, B_ledger, chunk_log, vla_version, grounding_regression_log)，继承 J_p 全检。承诺须由 J_p 与 J_t 联签，任一缺失即拒。

**定义 144（算子 PCE-T）** 每检查点：①VLA 提出 (a,C,候选探针) 并过语义 OOD；②传动体检：φ_t>θ_φ ∨ h=H2 ∨ ID 过期 ⇒ 先做摆动相/L1 dither-ID；③SPR：算 G，执行证伪；④力证据按 φ_t 折扣，EV-sem 按定义 141 闸门；⑤承诺 ⇔ ∀a′∈A_wc(a): R≤δ 且证据门过；⑥否则按 候选探针（VLA 排序但物理裁决）→ 绕行 → 降接触级 → L2 协商/安全停 的顺序；⑦按 B_t 定 T_chunk 并强制重接地；⑧φ_t>φ_max 时力证据禁用于不可逆，强制 L0/L1 或改走他类证据。

## 2. 关键算法伪代码（完整版见产物区）

```python
def transmission_self_model(M, j, phase):            # IP-139：摆动相/L1 微幅辨识
    if phase == 'swing' or known_calibration_pad(j):
        loop = dither(j, tau_max=TAU_ID, freq=F_ID)   # 力矩受限、非破坏
        m = fit_hysteresis(loop)                      # k_theta, l_lm, l_hys, eta, wear
    else:
        m = M.mhat[j]                                 # 有效域外：沿用+放大不确定度
    phi = worst_case_fidelity(m, M.tau_hat[j], M.valid_domain[j])
    if cusum_residual(j) > h_alarm or drift(m) > drift_max:
        M.health[j] = 'H2'; M.alarm.log(j); M.hal.quarantine_force_evidence(j)
    return M, phi

def discount_force_evidence(e, phi):                 # IP-140：区间与折扣
    if phi > PHI_MAX: return e.with_status('unusable_irreversible')
    e.sigma2 += (phi / KAPPA) ** 2                    # 区间似然
    e.w *= kappa_discount(phi)                         # 非增折扣
    e.stamp = (model_ver, health, now, last_valid_id)
    return e

def semantic_physical_reconcile(a, C, M, r):          # IP-141：可证伪提案
    if semantic_ood_score(a, C) > THETA_SEM:
        return 'semantic_ood', None, None
    C_b = compile_claims(C, P_GRAMMAR)                # 不可编译→丢弃
    C_f = [c for c in C_b if falsifiable(c)]          # 不可证伪→不作证据
    G = sum(w[c] * dist(pred(c, a), phys_cert(c, M, r)) for c in C_f)
    C_ev = [c for c in C_f if grounded(c, M) and G <= THETA_G]
    return 'ok', G, C_ev                              # C_ev 仅可产 EV-sem（限 L0/L1）

def transduction_budget(a, M, phi, chunk_len):        # IP-142：认证实际动作
    B = eps_sem + eps_pol + eps_trans(phi) + eps_est
    A_wc = ball(a, B)
    T = min(chunk_len, t_max(B), M.t_reground)
    if M.health.active == 'H2' or M.sem_ood: T = 1
    return B, A_wc, T

def probe_commit_evolve_trans(x0, M, task, budget, personas):
    a, C, probe_props = vla_propose(task, M.obs)      # VLA 只提案
    M, phi = transmission_self_model(M, M.active_j, phase='swing')
    ok, G, C_ev = semantic_physical_reconcile(a, C, M, M.region)
    B, A_wc, T_chunk = transduction_budget(a, M, phi, task.chunk)
    for a_star in A_wc:                               # 最坏执行集逐一认证
        if schedule_risk(a_star, M) > budget.delta_f: break
    else:
        if evidence_gate_T(M, C_ev, phi)[0] == 'ok':
            return commit(a, M, J_t(M, phi, G, B, C_ev))
    return pce_t_fallback(M, probe_props, phi)        # 探询/绕行/降级/协商
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| TSM | O(n_dither·H_leg)/次，摆动相摊销 | O(\|关节\|) | φ_t 为有效上界、有效域显式、告警单向 |
| TDE | O(1)/证据 | O(\|E\|) | 区间保守、回溯隔离完整、折扣非增 |
| SPR | O(\|C\|·d_c+\|𝒫\|) | O(\|C\|) | 可证伪过滤、EV-sem 限 L0/L1、物理优先 |

**正确性定理（Certified Cross-Transduction Soundness, CCTS）**：在 A33–A40（第 56–57 轮）之上加 **(A41)** 传动自模型诚实：φ_t 以概率 ≥1−δ_tsm 上界真实力矩误差，dither-ID 非破坏且仅作用于 L1/摆动相，健康告警延迟以概率界表达；(A42) 语义关系：VLA 输出仅为提案，语义 OOD 漏检 ≤δ_sem，EV-sem 仅用于 L0/L1 且必含已执行物理探针、不可证伪声明一律不当证据、永不入不可逆必要集；(A43) 转导预算健全：B_t 以概率 ≥1−δ_trans 上界"意图→实际执行"的真实失配（含减速器失动/迟滞与策略量化），且 T_chunk 重接地被强制执行；(A44) 健康感知寿命：保真告警后无未复验力证据可支撑许可性结论，证据戳与回溯完整。则：
(i) **转导健全性**：ID 路径 P(fail) ≤ δ_f+ε_meta(k)+δ_probe+ε_h(w_max)+δ_tsm+δ_trans+δ_sem·1[EV-sem]+δ_ood·α_conf+δ_xm·1[L1]。
(ii) **无跨链救援（本轮核心）**：∂P(fail)/∂(语义置信)≡0——再好的 VLA 也不能降低 δ_tsm 或 δ_trans；反之再准的力矩观测也不能修正误接地的谓词；当 G>θ_G 或物理与语义冲突时承诺被拒，与 VLA 置信无关。
(iii) **交互单调性**：保真告警、语义 OOD、折扣、缩分块、升佐证、缩超时只会经"信念更准（含加宽）"或"动作更保守"影响系统，不存在升险路径。
(iv) **终止性**：每检查点 dither-ID ≤k_ID、共识探针 ≤k_cons，T_chunk≥1，PCE-T 终止于 {承诺, 绕行, L2 协商, 安全停}。
(v) **部署界**：对检查点与分块边界取联合界，P_safe ≥ 1−Σ(δ_f+ε_meta+δ_probe+ε_h+δ_tsm+δ_trans+δ_sem+δ_ood·α_conf)−P(𝓜 陈旧未检出)−P(τ_int∧τ_mm 超时∧安全停失效)。

```python
def dither_identify(joint, phase, tau_cap=TAU_ID, n=8):
    # 仅摆动相（无接触）或已知标定面（L1 轻触）：非破坏
    assert phase == 'swing' or is_known_calibration_pad(joint)
    seq = [+tau_cap, 0, -tau_cap, 0] * n
    loop = execute_torque_profile(joint, seq, freq=F_ID)
    k_theta = slope_at_origin(loop)                 # 迟滞环斜率
    l_lm    = zero_torque_loop_width(loop)          # 零力矩处环宽 → 失动
    l_hys   = loop_area(loop) / (2 * tau_cap)       # 环面积 → 迟滞半宽
    eta     = quasi_static_ratio(loop)              # 准静态力矩比
    wear    = drift_from_nominal(joint.nominal, k_theta, l_lm, l_hys)
    return latent(k_theta, l_lm, l_hys, eta, wear)

def transmission_self_model(M, j, phase):
    if phase == 'swing' or is_known_calibration_pad(j):
        m = dither_identify(j, phase)
        M.mhat[j] = m; M.id_log.append((j, m, now(), temp()))
    else:
        m = widen_for_domain(M.mhat[j], temp(), load(), amp())  # 有效域外放大
    phi = worst_case_fidelity(m, M.tau_hat[j], M.valid_domain[j])
    if cusum_residual(j, r=M.tau_hat[j] - output_torque_or_imu_proxy(j)) > H_ALARM \
       or drift(m) > DRIFT_MAX:
        M.health[j] = 'H2'; M.alarm_log.append((j, now(), phi))
        M.hal.quarantine_force_evidence(j, since=M.last_valid_id[j])
    return M, phi

def worst_case_fidelity(m, tau_hat, domain):
    # 区间算术：真值落在以 tau_hat 为中心、由参数不确定度诱导的区间内
    return sup_abs_error(m.k_theta, m.l_lm, m.l_hys, m.eta,
                         m.wear, domain.temp, domain.load, domain.amp)
```

```python
def compile_claims(C, grammar=PREDICATE_GRAMMAR):
    out = []
    for c in C:
        p = grammar.match(c)                 # open-vocab → 有界谓词
        if p is not None: out.append(p)      # 翻不出来：丢弃，不作证据
    return out

def falsifiable(predicate):
    return predicate.has_refuting_observation()   # Popper：无反驳可能→不当证据

def semantic_ood_score(a, C, vla):
    return -log(consistency(paraphrase_ensemble(vla, C)) *
                agreement(action_chunks(vla, a)) *
                novelty_prior(C))

def semantic_physical_reconcile(a, C, M, r):
    if semantic_ood_score(a, C, M.vla) > THETA_SEM:
        M.sem_ood = True; return 'semantic_ood', None, []
    C_b = compile_claims(C)
    C_f = [c for c in C_b if falsifiable(c)]
    G = sum(W[c] * dist(predict_effect(c, a), certified_physics(c, M, r))
            for c in C_f) / max(1, sum(W[c] for c in C_f))
    C_ev = [c for c in C_f if grounded_by_executed_probe(c, M) and G <= THETA_G]
    return ('ok' if G <= THETA_G else 'gap'), G, C_ev

def tag_semantic_evidence(C_ev, level):
    if level not in ('L0', 'L1'): return []      # 硬禁令：不可逆接触不用 EV-sem
    return [EV('EV-sem', c, corrob=1) for c in C_ev]

def falsify_semantics(M, c, physical_outcome):
    if contradicts(c, physical_outcome):
        M.rho_sem_vla = max(RHO_MIN, M.rho_sem_vla * GAMMA_DOWN)
        M.grounding_log.append(('misground', c, physical_outcome))
```

```python
def probe_commit_evolve_trans(x0, M, task, budget, personas):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        # ① VLA 提案 + 语义 OOD
        a, C, probe_props = vla_propose(task, M.obs[cp.region])
        # ② 传动体检（摆动相/L1；有效域外则放大 φ）

                                    tau_int=tau_int(personas.active.auth))

def evidence_gate_T(ev, cp, M, phi):

             (ev.inf.cls == 'OOD' and ev.region in M.ood_reg.certified)

    elif ev.cls == 'EV-margin':
        ok = margin_ok_worst_case(ev, phi)                 # 最坏端点
    elif ev.cls == 'EV-sem':
        ok = (ev.level in ('L0', 'L1') and ev.grounded
              and ev.falsifiable and ev.G <= THETA_G
              and not M.sem_ood)
    else:
        ok = round57_gate(ev, M)                           # visit/xmodal/human 继承
    if ev.irreversible and ev.cls in ('EV-sem', 'EV-xmodal'):
        return ('reject', 'semantic_or_xmodal_on_irreversible')
    return ('ok',) if ok else ('reject', 'evidence_insufficient')
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| TSM | O(n_dither·H_leg)/次（摆动相摊销，无额外支撑相） | O(\|关节\|) | φ_t 为概率 ≥1−δ_tsm 上界；有效域显式；告警单向 |
| TDE | O(1)/证据，告警时 O(\|E\|) 回溯 | O(\|E\|) | 区间保守、折扣非增、回溯隔离完整 |
| SPR | O(\|C\|·d_c+\|𝒫\|) | O(\|C\|) | 可证伪过滤、EV-sem 限 L0/L1、物理优先 |
| TBC | O(1)+\|A_wc\| | O(1) | B_t 上界、T_chunk 封顶、告警缩到单步 |
| J_t | O(\|J_p\|) | O(\|J_p\|) | 与 J_p 联签、缺一即拒 |
| PCE-T | O(\|CP\|·(k_p+k_c+k_ID·n_dither)·(C_VOI+d_φ)+\|CP\|·A\*) | O(\|V\|+\|σ\|) | dither 预算有限、四态完备、分块逐步可重接地 |

**正确性定理（Certified Cross-Transduction Soundness, CCTS）**
假设 A22–A32（第 53–55 轮）、A33–A36（第 56 轮）、A37–A40（第 57 轮）成立；**(A41)** 传动自模型诚实：φ_t 以概率 ≥1−δ_tsm 上界真实输出力矩误差，dither-ID 非破坏且仅作用于摆动相/已认证 L1 标定面，健康告警检测延迟以概率界给出；**(A42)** 语义关系：VLA 输出仅为提案，语义 OOD 漏检 ≤δ_sem，EV-sem 仅用于 L0/L1 且必含已执行物理探针、不可证伪声明一律不作证据、永不入不可逆必要集；**(A43)** 转导预算健全：B_t 以概率 ≥1−δ_trans 上界"意图→实际执行"的失配（含减速器失动/迟滞、策略量化、接地误差），且 T_chunk 边界强制重接地被执行；**(A44)** 健康感知寿命：保真告警后无未复验力证据可支撑许可性结论，证据戳与回溯完整。则：

1. **转导健全性**：ID 路径
   P(fail) ≤ δ_f + ε_meta(k) + δ_probe + ε_h(w_max) + δ_tsm + δ_trans + δ_sem·1[EV-sem] + δ_ood·α_conf + δ_xm·1[L1]。
2. **无跨链救援（核心）**：∂P(fail)/∂(语义置信)≡0——更好的 VLA 不能降低 δ_tsm 或 δ_trans；更准的力矩观测也不能修正误接地的谓词。当 G>θ_G 或物理与语义冲突时承诺被拒，与 VLA 置信无关。**强链不能救弱链，串联安全是乘积。**
3. **交互单调性**：保真告警/语义 OOD/折扣/缩分块/升佐证/缩超时只能经 (a) 校准信念更新（含强制加宽）或 (b) 更保守的动作参数影响系统，不存在升险路径。
4. **终止性**：每检查点 dither-ID ≤k_ID、共识探针 ≤k_cons，T_chunk≥1，PCE-T 终止于 {承诺, 绕行, L2 协商, 安全停}。
5. **部署界**（对检查点与分块边界取联合界）：
   P_safe ≥ 1 − Σ_cp (δ_f + ε_meta + δ_probe + ε_h + δ_tsm + δ_trans + δ_sem·1[EV-sem] + δ_ood·α_conf + δ_xm·1[L1])
            − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(τ_int ∧ τ_mm 超时 ∧ 安全停失效)。

关键设计取舍：**元先验给效率、共形给保底（第 57 轮）；语义先验给效率、物理可证伪给保底（本轮）**——两次都把"效率来源"与"安全来源"解耦，赌注不押在会漂移的模型上。**TSM 把仪器变成被认证对象**，**TDE 把力证据变成带认证区间的证据**，**SPR 把 VLA 从裁决者降格为可证伪提案者**，**TBC 把承诺对象从"想做的动作"改成"实际会做的动作"**。四个机制都只经"信念更准或动作更保守"两个安全通道起作用。

## 7. 本轮最大风险

**一句话**：本轮把安全的赌注一路下移到"传动自模型"与"语义接地"这两个**裁判的裁判**身上，而它们与被认证的对象共用同一具会磨损的身体和同一个不透明的 VLA——若自模型失准或柔轮裂纹快于检测器，系统会自信地认证一个从未交付的力、并讲述一个从未触碰的世界；因此必须保留被动机械力矩限制器作为独立的最后防线、φ_t 默认取最坏值，且永不许语义一致性替代物理可证伪性。
