# 第 41 轮 · 双灵感落地 v8：见证式碰撞检测 × 激光雷达自由空间证书 × 证书覆盖主动感知（四层架构 v6）

> 承接第 40 轮（v17：可认证流匹配执行 × 度量语义几何锚定 × 证书驱动课程引擎，四层架构 v5）。本轮灵感词「碰撞检测、激光雷达」。关键处在于**不重复 v17 对激光雷达的用法**：v17 用点云建 ESDF、测「离障碍多远」，本质是「有障碍物的负几何」；本轮把同一份激光数据翻转成**正几何**——每条射线在命中前都**证明了那段空间是空的**。碰撞检测补上 v17 的另一处结构性缺口：v17 的 h_min 只在离散采样时刻成立，连续运动下的隧穿（tunneling）没有证书；而碰撞检测天然提供**连续时间见证**与**分离/接触的几何证明**。二者对偶：碰撞检测给「负证据 + 可反驳见证」，激光雷达给「正证据 + 覆盖域」，合起来把证书从「相信一个标量场」变成「可独立复核的证明 + 明确标注的无知区」。四层架构 v6 只做增量，不推翻 v17。

## 0. 直觉与动机

**灵感 1（碰撞检测 → 从标量 clearance 到可复核见证）**：v17 的安全证书是 h_min = ESDF clearance − margin − 漂移球。它有两个隐含假设：(a) 只在采样状态上成立，采样间隔内的运动可能「穿过」薄障碍而不被任何采样点看见（隧穿）；(b) 证书是「相信 ESDF 这张图」，而不是「相信一个可复核的证明」。碰撞检测正好补这两点。连续碰撞检测（CCD）用 conservative advancement：距离沿运动是 Lipschitz 的，`d(t+h) ≥ d(t) − v_max·h`，于是可以在整个时间区间上给出**距离下界**，有界即无隧穿。更关键的是**见证对偶**：GJK 在给出最近点 $(p_B,p_O)$ 的同时给出分离法向 $n$，半空间 $\{n·x \le n·p_B\}$ 包住机器人、$\{n·x \ge n·p_O\}$ 包住障碍——这就是一张**分离超平面证书**（Farkas 型），任何人用支撑函数在 O(1) 内即可复核；反之检测到接触时，接触点对就是**反驳见证**。于是证书第一次同时具备「可证真」与「可证伪 + 可归责」。此外，碰撞检测自然给出**碰撞时间下界 TTC**，它比 clearance 更适合高速动态场景：`h(x) = TTC(x) − t_react` 才是「还来得及停」的正确安全裕度。

**灵感 2（激光雷达 → 把「没测到点」翻转为「射线证明为空」）**：v17 的 ESDF 在稀疏点云上会「插值说谎」，遮挡区被当成自由空间。但激光雷达的物理语义是：一条射线在距离 $\rho$ 处命中，则在 $[0,\rho-\varepsilon_r]$ 上**没有障碍**——这是**空无的正证据**，不是「没证据」。本轮不再先建稠密图再查询，而是直接携带**自由空间证书**：每条射线贡献一个保守锥形自由域，所有射线的并集 $F$ 是「已被证明为空」的集合。安全证书的要求从「对着 ESDF 查 h_min」变成**集合包含**：机器人的**连续扫掠体** $S$ 必须被 $F$ 覆盖，$S \subseteq F$。这带来一个 v17 没有的诚实维度——**覆盖 / 认知泄漏** $\mathrm{leak}(S)=|S\setminus F|/|S|$：证书只在被覆盖处有效，未覆盖处必须显式说「不知道」，而不是默认安全。遮挡（射线止于首次命中）意味着覆盖是**视角相关且可组合的**：$F(A\cup B)=F(A)\cup F(B)$，多视角可并集补齐，这为主动感知提供了严格的目标函数。

**灵感 3（对偶耦合 → 双侧证书与覆盖课程）**：碰撞检测给负几何（接触/分离见证），激光雷达给正几何（自由空间），二者缺一不可：只有正几何无法处理运动的连续性，只有负几何无法区分「安全」与「没看见」。因此证书变成**双侧面**：$F$ 证明「我看过且是空的」，见证集证明「在看过的地方我算过且不相交」，认知泄漏显式标注「没看过」。课程引擎随之获得一个新轴：**证书覆盖赤字**——优先采样「覆盖率低但代价高」的任务，并用**次模贪心**选下一最佳视角去最大化边际覆盖增益。这把 v17 的「课程即证书赤字」从策略能力维度扩展到**感知证据维度**：不是「策略不会」，而是「证据不够」。

**耦合句**：碰撞检测提供可反驳的「负证据」，激光雷达提供可组合的「正证据」，覆盖课程提供「去哪补证据」的闭环——三者把 v17 的静态几何证书升级为**可复核、可证伪、且诚实标注无知域**的两侧证明。

## 1. 形式化定义

**定义 27（连续时间碰撞证书 CertCCD）**：机器人刚体/凸分解 $B(q)=\bigcup_i B_i(q)$，障碍点集 $O$，轨迹 $q(t), t\in[0,T]$，相对速度界 $v_{max}$。有符号距离 $d(t)=\mathrm{dist}(B(q(t)),O)$。
- **见证**：一次 GJK 查询返回 $(d_k,p_B,p_O,n_k)$，$n_k=(p_O-p_B)/\|p_O-p_B\|$；分离半空间对 $(H_B=\{x:n_k·x\le n_k·p_B\}, H_O=\{x:n_k·x\ge n_k·p_O\})$ 满足 $B_i\subseteq H_B, O\subseteq H_O$ 时称**有效分离见证**。
- **连续下界**：由距离对运动的 Lipschitz 性，$d(t+h)\ge d_k-v_{max}h$；取安全推进步 $h_k=(d_k-m)/v_{max}$，得区间下界序列，$d_{lb}=\min_k(d_k-v_{max}h_k)$。
- **TTC 下界**：$ttc_{lb}=d_{lb}/v_{max}$。
- **证书**：CertCCD $=\{d_{lb},ttc_{lb},\mathcal{W}\}$，$\mathcal{W}$ 为见证集。
- **定理 1（无隧穿与可证伪）**：若 $\mathcal{W}$ 中每个见证有效且覆盖 $[0,T]$ 的连续推进，则 $\forall t, d(t)\ge d_{lb}$；反之若任一时刻发生接触，则存在接触点对见证使 CertCCD 被反驳。证明：归纳每个推进区间用 Lipschitz 下界；反驳性由接触点对构成的分离见证失效直接给出。独立复核复杂度 $O(|\mathcal{W}|)$，单见证 $O(1)$ 支撑函数检验。

**定义 28（激光雷达自由空间证书 FSC）**：扫描射线 $r=(\omega,r_\rho)$，距离噪声 $|r_\rho-\rho^*|\le\varepsilon_r$ 以概率 $1-\delta_r$ 成立（Bennett/共形标定）。射线的保守自由域为锥形
$$F_r=\{\,o+s\omega' : 0\le s\le r_\rho-\varepsilon_r-B_t,\ \angle(\omega',\omega)\le\Delta\theta/2\,\},$$
$B_t$ 为 IP-49 漂移球半径，$\Delta\theta$ 为角分辨率。自由空间证书 $F=\bigcup_r F_r$。
- **覆盖**：$\mathrm{cov}(S)=|S\cap F|/|S|$，**认知泄漏** $\mathrm{leak}(S)=1-\mathrm{cov}(S)$。
- **有效性域**：ValidRegion$_{FSC}=\{x:\mathrm{cov}(S_x)=1\}\cap\{x:B_t(x)\le B_{cert}\}$。
- **定理 2（正证据可靠性）**：若 $S\subseteq F$ 且所有射线噪声假设成立，则 $S$ 与真实障碍不相交，概率 $\ge1-\delta_r$；未被 $F$ 覆盖的部分**不可主张安全**（只能主张泄漏上界）。证明：每条射线独立证明 $F_r$ 为空，并集为空；未覆盖点不在任何证明内，故无保证。推论：覆盖对视角次模，$F(A\cup B)=F(A)\cup F(B)$。

**定义 29（双侧碰撞证书 Cert2 与组合）**：Cert2 $=\{F,\text{CertCCD},B_t,\mathrm{cov},\mathrm{leak}\}$。
- **轨迹证书**：轨迹在任务域内有效 $\iff \mathrm{cov}(S_{[0,T]})\ge1-\tau_{cov}$ 且 $d_{lb}\ge m$ 且 $ttc_{lb}\ge t_{react}$ 且 $B_t$ 已被裕度吸收。
- **组合**：技能串联 $h_1\circ h_2$ 的自由空间按并集 $F_{12}=F_1\cup F_2$（仅当共享同一坐标系与时戳），见证集按时间拼接 $\mathcal{W}_{12}=\mathcal{W}_1\oplus\mathcal{W}_2$，裕度取最弱环 $m_{12}=\min(m_1,m_2)$，$ttc_{12}=\min(ttc_1,ttc_2)$；时间戳相关性由 IP-49 漂移界显式传递。
- **定理 3（双侧组合健全且可归责）**：若各子证书在其域内有效，则组合有效；任一子证书被反驳，则组合被反驳且反驳见证可定位到具体技能与时刻。

**定义 30（证书覆盖赤字与主动感知课程）**：难度在 v17 的 $D(\tau)$ 上增加感知项：
$$D_{cov}(\tau)=D(\tau)+w_c\,(1-\mathrm{cov}(S_\tau))+w_t\,\max\!\Big(0,1-\frac{ttc_{lb}(\tau)}{t_{react}}\Big)+w_l\,\mathrm{leak}(S_\tau).$$
主动视角选择：候选视角集 $V$，成本 $c(v)$，预算 $\Gamma$，目标是 $\max_{A\subseteq V,\sum c\le\Gamma}\mathrm{cov}(S\setminus F(A))$；因覆盖次模，贪心 $\Delta(v|F)/c(v)$ 达 $(1-1/e)$ 近似。闭环：低覆盖任务 → 重采样 → 选视角补证据 → 重颁证书 → 契约热更新。

## 2. 三大产出设计

### 2.1 IP-51 PROOF-CARRYING-COLLISION（见证式连续碰撞检测）
1. 凸分解 + GJK/EPA：机器人按连杆/包围体分解，输出最近点、分离法向、接触流形。
2. CCD conservative advancement + 区间算术：把每段运动切成安全推进步，给出 $d_{lb}$ 与 $ttc_{lb}$，杜绝隧穿。
3. 见证打包：CertCCD 写入 CertBundle（IP-46），含法向、支撑点、下界；提供 O(1) 独立复核器与反驳见证。
4. TTC-CBF：以 $h(x)=ttc_{lb}(x)-t_{react}$ 作为 CBF 约束，替代纯 clearance，高速场景更保守且更少误刹。
5. 动态物体：对点云做时戳分桶，运动障碍用相对速度更新 $v_{max}$，TTC 证书带有效期。

### 2.2 IP-52 LIDAR-FREESPACE-CERT（激光雷达自由空间证书）
1. 射线→保守锥形自由域：扣噪声 $\varepsilon_r$ 与漂移 $B_t$，角向按 $\Delta\theta/2$ 膨胀，构建 BVH 加速的 $F$。
2. 扫掠体包含检验：对连续扫掠体 $S$（非采样点）做 $S\subseteq F$ 查询，输出 cov/leak 与未覆盖见证（泄漏体素）。
3. 多视角并集与时间衰减：$F(A\cup B)=F(A)\cup F(B)$；动态场景按时间窗切片，过期自由域自动失效。
4. 与 ESDF 分工：ESDF 仅作规划启发与平滑引导，**证书权威归 FSC**，避免「插值说谎」。
5. 共形标定：用回环/真值残差对 $\varepsilon_r,\delta_r$ 做 split-conformal，膨胀自由域并报告覆盖率。

### 2.3 IP-53 CERT-COVERAGE-ACTIVE-SENSING（证书覆盖主动感知与课程）
1. 覆盖赤字难度：定义 30 的四项难度，感知项在线估计（cov/leak/ttc 边际）。
2. 次模视角规划：预算约束下贪心选视角，最大化边际覆盖；anytime 可停，随时给当前证书。
3. 覆盖感知路由：IP-45 网关增加覆盖检查；cov 不足 → 降速/停走/切换「探索模式」并在契约标注 leak（第六熔断触发器）。
4. 反例驱动回放：碰撞/泄漏见证按赤字加权回放，形成「见证→课程→补视角→重颁」闭环。
5. 与 v17 步数/时延预算统一调度：证据不足且算力紧时，优先补感知而非提高采样步数。

## 5. 本轮最大风险

**一句话**：整套方案的最脆弱等价是「覆盖即安全」——自由空间覆盖是视角、角分辨率与噪声模型的函数，一旦把未观测区误记为已覆盖，或把相对速度界估小，证书就会在最需要它的杂乱/动态场景中给出**虚假安全**，故必须以 E73/E74 作为第一守门实验。

## 1. 符号体系（承接定义 27-30）

| 符号 | 含义 | 定义 |
|---|---|---|
| $B(q), O$ | 机器人凸分解 / 障碍点集 | $B=\bigcup_i B_i(q)$；$O$ 为点云或凸包 |
| $d(t)$ | 连续有符号距离 | $\mathrm{dist}(B(q(t)),O)$ |
| CertCCD | 连续碰撞证书 | $\{d_{lb},ttc_{lb},\mathcal{W}\}$ |
| $\mathcal{W}$ | 分离/接触见证集 | $(n,p_B,p_O,d)$，支撑函数 O(1) 复核 |
| $d_{lb}$ | 距离下界 | $\min_k(d_k-v_{max}h_k)$，conservative advancement |
| $ttc_{lb}$ | 碰撞时间下界 | $d_{lb}/v_{max}$ |
| $F$ | 自由空间证书 | $\bigcup_r F_r$，射线锥形自由域并集 |
| $F_r$ | 单射线自由域 | 扣 $\varepsilon_r$ 与 $B_t$、按 $\Delta\theta/2$ 膨胀的锥 |
| $\mathrm{cov}(S)/\mathrm{leak}(S)$ | 覆盖 / 认知泄漏 | $|S\cap F|/|S|$；$1-\mathrm{cov}$ |
| ValidRegion$_{FSC}$ | 覆盖有效域 | $\mathrm{cov}=1$ 且 $B_t\le B_{cert}$ |
| Cert2 | 双侧碰撞证书 | $\{F,\text{CertCCD},B_t,\mathrm{cov},\mathrm{leak}\}$ |
| $D_{cov}(\tau)$ | 覆盖赤字难度 | $D+w_c(1-\mathrm{cov})+w_t\max(0,1-ttc/t_{react})+w_l\,\mathrm{leak}$ |
| $\tau_{cov}$ | 允许泄漏阈值 | 轨迹证书要求 $\mathrm{cov}\ge1-\tau_{cov}$ |

## 2. 关键算法

### IP-51 见证式连续碰撞检测（伪代码）
```
def cert_ccd(B, q_traj, O, margin, v_max):
    t, W, d_lb = 0.0, [], +inf
    while t < T:
        q = q_traj(t)
        d, pB, pO, n = gjk_closest(convex_parts(B, q), O)   # witness
        if d <= margin:
            return REFUTED(contact_pair(pB, pO))            # 反驳见证
        h    = (d - margin) / v_max                          # safe advancement
        d_lo = d - v_max * h
        W.append(SepPlane(n, pB, pO, d_lo))
        d_lb = min(d_lb, d_lo)
        t   += h
    return CertCCD(d_lb, d_lb / v_max, W)

def verify_witness(w):                                       # O(1), model-independent
    return (support(B, w.n) <= dot(w.n, w.pB) + EPS and
            support(O, -w.n) <= -dot(w.n, w.pO) + EPS)
```

### IP-52 激光雷达自由空间证书（伪代码）
```
def build_fsc(scan, pose, B_t, delta):
    F = FreeSpaceComplex(bvh=True)
    for omega, rho in scan:
        r_free = rho - k_delta * sigma_r(delta) - B_t       # noise + drift shrink
        F.add_frustum(omega, half_angle=DELTA_THETA/2, r=r_free)
    return F                                                # positive evidence: empty

def cert2(q_traj, F, O, margin, t_react, tau_cov):
    S   = swept_volume(q_traj)                              # continuous, not sampled
    cov, leak = F.coverage(S, valid_region=True)
    ccd = cert_ccd(B, q_traj, O, margin, v_max)
    if cov < 1 - tau_cov:
        return UNKNOWN(leak_witness(F, S))                  # honest ignorance
    if ccd.d_lb < margin or ccd.ttc_lb < t_react:
        return REFUTED(ccd.witness)
    return Cert2(F, ccd, B_t, cov, leak)
```

### IP-53 证书覆盖主动感知（伪代码）
```
def coverage_curriculum(policy, F, budget, tau_cov):
    while budget > 0:
        tau = sample_from_deficit(F)                        # high leak / low ttc first
        V   = candidate_viewpoints(tau)
        v   = argmax(V, key=lambda v: marginal_cov(v, F) / cost(v))  # submodular
        F   = F.union(scan_from(v))
        if cov(swept(tau), F) >= 1 - tau_cov:
            replay.add(tau, weight=cert_deficit(tau))
        budget -= cost(v)
    RCA.reissue(coverage_cert(Cert2)); Registry.hot_reload(contracts)
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 正确性保证 |
|---|---|---|
| GJK/EPA 见证 | 每凸对 $O(\kappa)$，$\kappa$ 小 | 分离/接触见证，独立复核 O(1) |
| CCD 推进 | $O(v_{max}T/m)$ 步 | **定理 1**：$\forall t, d(t)\ge d_{lb}$，无隧穿；违约可由接触对反驳 |
| 自由空间构建 | 每帧 $O(M\log M)$，BVH 加速 | **定理 2**：$S\subseteq F\Rightarrow$ 无碰撞，概率 $\ge1-\delta_r$ |
| 扫掠体覆盖查询 | $O(\log M+k)$，$k$ 为命中体素 | cov/leak 精确到体素分辨率；未覆盖不可主张安全 |
| Cert2 组合 | $O(|\mathcal{W}|+\lvert F\rvert)$ | **定理 3**：健全组合 + 反驳可归责到技能/时刻 |
| 视角贪心 | 每步 $O(|V|\cdot|\text{cand}|)$ | 次模 $\Rightarrow (1-1/e)$ 近似，anytime 可停 |
| 覆盖课程采样 | $O(1)$/任务（按赤字预索引） | 难例优先；与 v17 随机逼近兼容 |

## 4. 实验设计（E73-E78，硬门槛）

| 实验 | 指标 | 门槛 |
|---|---|---|

| E74 自由空间可靠性 | 声称覆盖区的真实碰撞率（遮挡/稀疏/光照突变） | 假安全≤0.5%；覆盖标定误差≤5% |
| E75 见证组合与归责 | 组合违约检出率、反驳定位准确率、单见证复核时延 | 检出≥95%；定位≥90%；<0.2ms |

## 5. 风险与缓解

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| 覆盖高估：未观测区被当已覆盖 → 虚假安全 | 高 | 显式 leak 上报 + 保守锥膨胀 + 共形标定；E74 第一守门 |
| 速度界低估 / 未建模动态 → CCD 隧穿 | 高 | 在线速度观测 + 硬上限 + 短证书有效期；E73 守门 |
| 射线噪声模型错误 → 自由域不可靠 | 中 | Bennett/共形标定 $\varepsilon_r,\delta_r$，超阈值自动扩大膨胀 |
| 动态障碍不在静态点云中 | 中 | 时戳分桶 + 相对速度 TTC + 时间窗切片过期 |
| 见证数量过多导致复核变慢 | 低 | 单见证 O(1)、批量并行、见证抽稀（保留下界最紧者） |
| 主动视角规划与执行争用算力/时间 | 中 | anytime 贪心 + 预算感知 + 与 v17 步数调度统一 |

## 6. 本轮最大风险

**一句话**：整套方案的最脆弱等价是「覆盖即安全」——自由空间覆盖是视角、角分辨率与噪声模型的函数，一旦把未观测区误记为已覆盖，或把相对速度界估小，证书就会在最需要它的杂乱/动态场景中给出**虚假安全**，故必须以 E73/E74 作为本轮成败判据。
