# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「自适应控制」×「动态避障」）

> R69 把 epistemic 不确定性交给「主动交互」：看、问、触，用 VoI 选一次查询来消歧。它隐含了两个前提：**(P1) 被查询的隐变量是静态的**（一个固定的模态 M，问一次就少一点）；**(P2) 存在一个会回答的合作者**（人、标注者、静止场景）。动态避障把这两条同时打穿：
> - 障碍物的意图/策略、地面摩擦、负载、风扰是**持续漂移**的，不是「问一次就定」的模态；
> - 移动的障碍物**不会回答你**——它对你的「回答」是它的**反应**，而反应只在**你做出可被回应的动作**时才出现。你不先动，就永远看不出它让不让。
>
> 更尖锐的是：R69 的「零学习写操作」不变式，在面对非平稳世界时等价于「永远不更新世界模型」；而朴素地打开在线适应，又会落入自适应控制的经典陷阱——**没有持续性激励（PE）的适应会参数漂移，有未建模动态的适应会 bursting，被对手激励的适应会学到一个自洽但错误的世界**。
>
> 本轮两个灵感正好补上两块缺失：
> - **自适应控制**给出「在线学习何时安全」的严格语言：持续性激励、死区、σ-泄漏、集合投影、UUB；它把 R69 的「要不要问」升级为「**要不要学、学哪个方向、学多快**」。
> - **动态避障**给出非平稳、对抗、安全关键的试验场：障碍预测集必须随分布漂移而自适应，安全必须在「边学边动」时保持。
>
> 核心命题：**把 R69 的「静态交互消歧」升级为「运动中的对偶控制」——同一条安全轨迹既完成任务，又通过受控激励让世界暴露它的参数；适应只在持续性激励足够、且更新方向不降低安全裕度时被允许，否则冻结并回退到 R69/R68。** 命名 **ADEPT-RAS**（Adaptive Dual-control with Excitation-aware Probing and Temporal safety certification）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「测量还准吗」，R69 问「该向谁求证」，R70 问「**我该怎么动，才能让世界告诉我答案，同时不把自己动进危险里**」——在非平稳世界里，信息不是问出来的，是**动出来**的；但动本身必须被认证。

## 0. 直觉与动机

**灵感 1（自适应控制 → 不确定性还有一条「激励维度」）**
直觉：R69 把 epistemic 不确定性当作「信念不够尖」，于是去查。但参数辨识有一条铁律：**你只能辨识你激励过的东西**。若机器人从不进入某个速度/摩擦/间距区间，关于该区间的参数协方差就永远很大，估计会沿未激励方向漂移；一旦扰动或对手把状态推过去，模型立刻失真（bursting）。所以「不确定性」不只分 aleatoric / epistemic，还要问一句：**这个 epistemic 维度是否可被当前动作激励？** 不可激励的维度，问也问不出来，只能保守；可激励的维度，最好的查询往往是一次受控的「动」。

**灵感 2（动态避障 → 真正不确定的是「反应函数」，不是「位置」）**
直觉：预测一个行人下一帧在哪，远不如预测「我一靠近，它让还是不让」重要。人群里的协调是**隐式谈判**：你稍微探身，看对方是否减速；你让出内侧，看对方是否直行。被动观测在冲突发生前往往是**秩亏**的：让与不让在当前位置上的观测分布几乎相同，只有制造一个「冲突窗口」才能把两种意图分开。于是 R69 的「看/问/触」需要一个运动版：**探身、让行、试插、停等**，它们不是任务动作的附属，而是能同时产生安全收益和信息收益的对偶动作。

**灵感 3（对偶控制 → 控制与辨识是同一动作的两面）**
直觉：Feldbaum 的对偶控制说，最优动作既有控制效应又有信息效应。R69 的 MINT 把信息动作 g 与任务动作 a 显式分开，这在静态场景可行；在动态避障里，分开往往昂贵甚至不可能——你不能先停下来问完再走，因为「停下」本身改变了对方的策略。于是本轮把两者融合为 ξ=(a, q)，用**对偶价值 DV** 统一评分：任务收益 + 模态信息增益 + 安全相关参数激励增益 − 风险 − 成本。R69 的 MINT 成为「q=∅ 且只看信息项」的特例。

**灵感 4（安全适应 → 适应是一次写操作，必须被认证）**
直觉：R69 用「实时零学习写」换取安全，这是一根拐杖。面对漂移世界，正确做法不是永不写，而是**认证地写**：有界、投影到安全集、被激励门控、留 provenance、可回滚。定义**安全自适应包络 ASE**：更新方向必须使鲁棒 CBF 的安全裕度下降不超过 ε_slack；定义**冻结-回滚协议 FRP**：一旦检测到投毒或裕度异常下降，回滚到上一个认证参数并冻结。冻结即 R69 边界——新层把旧层包含为「不写」的退化情形。

**灵感 5（对抗 → 对手可以「教你」）**
直觉：R69 的最大风险是「问错比不问更危险」。R70 出现了一个更坏的东西：**教错**。一个对抗性障碍物可以故意制造激励来污染参数——假装会让、诱使你学到「这条走廊安全」、或在你探身时突然加速。错误一旦写入，会持续污染后续所有决策，还会以「我已适应」的自信姿态压制保守回退。所以本轮必须同时交付：分布漂移下仍有效的 coverage（自适应 conformal）、可信先验混合、适应速率上界、教学攻击干扰集、以及「单次运动证据不得单独定案」的证据纪律。

**灵感 6（严格包含 → 三层阶梯，而不是并列黑箱）**
直觉：R70 关掉适应与探询应逐指令等于 R69；R69 关掉交互应逐指令等于 R68。安全侧必须单调：L0 ADEPT → L1 冻结适应（R69）→ L2 禁交互（R68）→ L3 紧急制动。只有这样才能说「新层是旧层的严格泛化」，否则每加一层就多一个必须独立信任的黑箱。

## 1. 形式化定义（增量：定义 310–329）

**定义 310（ADEPT-RAS 总览）** ADEPT-RAS = (DCE, PEB, ASE, KIP, DV, ACP, RCBF, NCD, FRP, RAS-WM‡)。五不变式：
(i) **认证写操作**：任何在线参数/策略写入必须通过 ASE 投影与幅度界，附 provenance，且可回滚（替代 R69 的「零写」）；
(ii) **激励门控**：持续性激励低于阈值时 DCE 冻结，只保留上一个认证参数；
(iii) **安全非降**：任何信息/探询动作 q 先过 RCBF，且其诱导的参数更新不得使安全裕度下降超过 ε_slack；
(iv) **分层回退**：L0 ADEPT → L1 冻结适应（R69）→ L2 禁交互（R68）→ L3 紧急制动，安全侧逐层嵌套；
(v) **证据纪律升级**：运动探询得到的是「反应证据」，必须与被动观测、流似然、跨模态残差一起满足 k 源一致，单次探询不得单独定案。

**定义 311（非平稳世界）** 状态 x_t，控制 u_t，环境参数 θ_t ∈ Θ（含他者策略参数 φ_j、局部摩擦、负载/风扰）。动力学 x_{t+1} = f(x_t,u_t;θ_t) + w_t，‖w_t‖ ≤ w_max；漂移 θ_{t+1} = θ_t + Δθ_t，‖Δθ_t‖ ≤ δ_drift。障碍物 j 的策略 π_j(·|x,ctx;φ_j)，其 φ_j 同样有界漂移。安全集 𝒮 = {x : h_j(x) ≥ 0, ∀j}，h_j 含最小间距与速度约束。

**定义 312（递推估计器 DCE）** 回归量 Φ_t = Φ(x_t,u_t)，观测 y_t。递推最小二乘
θ̂_{t+1} = Proj_{Θ_safe}[ (1−σ_t)θ̂_t + σ_t θ_prior + clip(K_t e_t, ±Δ_max) ],
K_t = P_t Φ_t / (λ + Φ_tᵀP_tΦ_t)，e_t = y_t − Φ_tᵀθ̂_t，
P_{t+1} = (1/λ)(P_t − P_tΦ_tΦ_tᵀP_t/(λ+Φ_tᵀP_tΦ_t))。
**死区**：|e_t| ≤ ε_dz 时不更新（无信息不写）；**σ-泄漏**：向可信先验 θ_prior 收缩，σ_t 随投毒疑度上升；**幅度界**：单步 ‖Δθ‖ ≤ Δ_max。

**定义 313（持续性激励 PEB）** 滑动窗口 𝒲_t 内 Gram 矩阵 G_t = Σ_{τ∈𝒲_t} Φ_τΦ_τᵀ，激励水平 ρ_PE(t) = σ_min(G_t)/(σ_max(G_t)+ε)。PE 谓词：ρ_PE ≥ γ_PE。仅当 PE 成立且 e_t 超出死区时才允许非零更新；否则冻结。ρ_PE 本身是预算资源，可由探询动作主动提升。

**定义 314（运动探询动作空间 KIP）** 在 R69 的 𝒜_info 之外增广运动探询 q ∈ 𝒬，q 是时长 h 的微轨迹族：q_yield（减速让行）、q_weave（小幅侧向试探）、q_commit（加速通过冲突窗）、q_stop（停等观察）。约束 ‖q‖_∞ ≤ ε_probe、|Δv| ≤ a_max h、力/位包络不越界。增广动作 ξ = (a, g, q) ∈ 𝒜_task × 𝒜_info × 𝒬。q 与任务动作共享同一条前缀轨迹，不额外占用通道。

**定义 315（对偶价值 DV）** 对候选 ξ = (a,g,q)：
DV(ξ) = E[R_task(ξ)] + β_I·I(M; y | ξ) + β_E·[tr(P_θ^-) − tr(P_θ^+(ξ))]_{𝒮} − β_R·Risk(ξ) − c(ξ)，
其中第三项只在**安全相关子空间** 𝒮（h_j 敏感方向张成的子空间）上计激励增益；Risk 由 RCBF 给出；c 为时间/社交/能量成本。选 ξ* = argmax DV，s.t. Risk ≤ ε_probe 且预算未超。R69 的 MINT 是 q=∅、β_E=0 的特例。

**定义 316（安全自适应包络 ASE）** 令 J_h(x;θ) = ∂h(f(x,u;θ))/∂θ 为安全裕度对参数的敏感矩阵。ASE 约束集
𝒦(x) = { Δθ : J_h(x;θ)Δθ ≥ −ε_slack, ∀x ∈ ℛ(x_t) }，
其中 ℛ(x_t) 为短时可达集。DCE 的更新通过求解小 QP 投影到 𝒦(x)：
Δθ* = argmin_{Δθ∈𝒦} ‖Δθ − Δθ_nom‖²。
即「适应可以改变预测，但不能吃掉保留的安全裕度」。

**定义 317（自适应 conformal 障碍预测 ACP）** 对障碍物 j 的 h 步预测 ŷ_{j,t+h}，非一致性分数 s_{j,t} = ‖y_{j,t} − ŷ_{j,t|t−h}‖。维护分位 q_{j,t}，按自适应 conformal 更新
q_{j,t+1} = q_{j,t} + γ_c (α_j − 1{s_{j,t} > q_{j,t}})。
预测集 C_{j,t+h} = { y : ‖y − ŷ_{j,t+h}‖ ≤ q_{j,t} }。该更新不假设可交换性，在任意（含对抗）漂移序列下维持长期 coverage ≈ 1−α_j。

**定义 318（鲁棒 CBF / 安全滤波器 RCBF）** 对每个障碍物，鲁棒障碍函数
h_j(x_t) = min_{y ∈ C_{j,t+h}} ‖p_t − y‖ − d_safe，
并要求 ḣ_j + α_cbf h_j ≥ 0 对所有 y ∈ C_{j,t+h} 成立。控制 u 由标称 u_nom 经 QP 最小修正得到；QP 不可行时切入 L3 紧急制动（保底安全集）。h_j 只用预测集的下确界，因此不依赖障碍物「平均行为」。

**定义 319（非平稳变化检测 NCD）** 监控四路残差：(r_res) R68 标定残差、(Δa) R69 流似然差、(e_t) 适应预测残差、(|C_t|) conformal 集尺寸。用 CUSUM/Page–Hinkley 检测变点并分类：
- r_res↑ 单独 → 传感器故障（R68 处理）；
- Δa↑ 且 r_res 低 → 被标定吸收的缓变故障（R69 FMA 处理）；
- e_t↑ 且 ρ_PE ≥ γ_PE → 真参数漂移 → 允许 DCE 适应；
- e_t↑ 且 ρ_PE < γ_PE → 不可辨识漂移 → 冻结 + 探询；
- e_t↑ 且 |C_t|↑ 且残差方向与激励方向强相关 → 教学/投毒疑 → FRP 回滚。
NCD 输出类别 c_t ∈ {sensor, slow_fault, drift, unidentifiable, poison, nominal}。

**定义 320（冻结-回滚协议 FRP）** 维护认证参数环形缓冲 {(θ̂^(k), P^(k), t_k, cert_k)}。触发条件：c_t=poison，或安全裕度在窗口内下降 > ε_slack 且与 Δθ 的相关性 > ρ_trigger，或 ECE/coverage 越界。动作：回滚到最近认证快照、冻结 DCE、提升 σ_t、切 L1。回滚带滞回，避免抖动。

**定义 321（教学攻击与威胁模型 ℰ_teach）** 对抗障碍物可选择轨迹/反应以塑造回归量 Φ_t，从而诱导错误的 θ̂（假装让行、诱导进入窄道、冲突瞬间加速）。攻击者可控制激励方向与幅度，但受物理可行性约束。并入 AIC：ℰ_ADEPT = ℰ_FLUID × ℰ_teach × ℰ_drift（漂移/不可辨识/突发机动）。单次运动证据不得单独定案；至少两源一致或长期统计显著。

**定义 322（可信先验混合 TPM）** θ̂ ← (1−σ_t)θ̂ + σ_t θ_prior，σ_t = σ_0 + κ_p·poison_score(t)。先验来自离线安全数据与保守模型。σ_t 越大，适应越慢、越接近离线策略；σ_t=1 即完全冻结（R69 边界）。与死区共同给出参数误差的 UUB 界。

**定义 323（反应证据与证据纪律）** 探询 q 产生反应证据 r_resp（他者让行/减速/转向/加速），与 ℰ={r_geo,r_sync,r_zero,r_emo,r_wm,r_resp} 联合。意图后验更新需 k 个正交证据源一致；单源/单次探询只提供似然，不改变定案状态。运动探询的「回答」也可能沉默（无反应），沉默本身是弱证据，不得当作默认让行。

**定义 324（自适应预算调度 ABS）** 三层时标：快反/RCBF 1kHz（不可抢占）、适应与 NCD 10–100Hz、任务策略与探询规划 5–20Hz。PE 预算：每 N 步至多一次主动激励探询；激励强度计入社交/能量成本。value-density 贪心（按 DV/计算量排序）在可抢占独立任务下最优，用于在接触/冲突相位内分配慢层预算。

**定义 325（证书 J_ADEPT）** J_ADEPT = (J_FLUID, θ̂_hash, tr(P_θ), ρ_PE_p5, safety_slack_min, coverage_err, rollback_count, teaching_alert, adept_ver)。Valid ⇔ Valid(J_FLUID) ∧ ρ_PE 满足或已冻结 ∧ safety_slack ≥ 0 ∧ |coverage−α| ≤ τ_cov ∧ 回滚后重认证通过。

**定义 326（参与式审计 VQAuditor-A）** 审计对象新增：适应写入是否超界、探询是否越出安全包络、回滚是否正确、教学疑度是否被及时升级、单次探询是否被越权定案。结论回灌 AuditBuf，成为下一轮 TPM 先验与 DV 成本先验。

**定义 327（降级阶梯）** L0 正常 ADEPT；L1 冻结 DCE（等价 R69：静态交互 + 保守）；L2 禁交互/探询（等价 R68：纯保守）；L3 紧急制动（最大安全集）。谓词带滞回：从 Lk→Lk+1 由安全/信任事件触发，从 Lk+1→Lk 需连续 M 步满足恢复条件，保证无 Zeno 抖动。安全侧单调：𝒮_L0 ⊆ 𝒮_L1 ⊆ 𝒮_L2 ⊆ 𝒮_L3 的动作可达集，风险反向。

**定义 328（障碍物行为分类）** 依反应证据把他者分为 cooperative / neutral / non-cooperative / adversarial。互惠估计 ρ_recip = P(他者让行 | 我让行) − P(他者让行 | 我不让)。ρ_recip 高则优先 q_yield；低且冲突窗近则 q_commit 或 q_stop；持续负值且出现诱导模式则升 adversarial，冻结适应并升 L1。

**定义 329（三层严格包含）** 记 ADEPT(adapt, probe, interact) 为开关配置。则
ADEPT(0,0,1) ≡ R69（适应与探询关闭，仅静态交互），ADEPT(0,0,0) ≡ R68（再关交互）。
「≡」指在相同输入与随机种子下逐指令相同（含 λ、k、模式选择）。故 R68 ⊂ R69 ⊂ R70，且 J_ADEPT ⇒ J_FLUID ⇒ J_CALM。

# IP-264 DCE：死区 + σ-泄漏 + 安全投影的在线估计（认证写）
class DualControlEstimator:
    def update(self, phi, y, J_h, eps_slack):
        e = y - phi @ self.theta
        if abs(e) <= self.dz:                       # 无信息不写
            return self.theta, self.P, "frozen_dz"
        K = self.P @ phi / (self.lam + phi @ self.P @ phi)
        d_nom = K * e
        d_safe = project_qp(d_nom, J_h, eps_slack)  # ASE：不吃掉安全裕度
        d = clip(d_safe, -self.dmax, self.dmax)
        self.theta = (1-self.sigma)*self.theta + self.sigma*self.theta_prior + d
        self.P = rank1_p_update(self.P, phi)
        return self.theta, self.P, "written"

# IP-265 PEB：滑动窗口持续性激励
def pe_level(window_reg):
    G = sum(phi.T @ phi for phi in window_reg)
    return sigma_min(G) / (sigma_max(G) + EPS)

# IP-269 ACP：漂移下仍保 coverage 的自适应 conformal
def acp_update(q, score, alpha, gamma):
    return q + gamma * (alpha - (1.0 if score > q else 0.0))

# IP-268 DV：任务/信息/激励/风险/成本的对偶价值
def dual_value(xi, modes, P_theta, o, budget):
    task = expected_task_return(xi)
    info = mutual_info(mode_identity, obs_model(xi))
    exc  = trace(P_theta) - expected_post_trace(P_theta, xi, subspace="safety")
    risk = robust_cbf_risk(xi, acp_sets(o))
    return task + bI*info + bE*exc - bR*risk - cost(xi, budget)

# IP-278 主闭环：快层永远在线，慢层可冻结，R69/R68 为边界
def ADEPT_RAS_round(M, obs):
    x, o = M.mtm.forward(obs)
    # --- 快层 1kHz：反射 + RCBF 不依赖任何自适应结论 ---
    base = M.reflex.propose(x)                       # 已认证的保守反射
    # --- 慢层 10-100Hz：变化检测决定「学 / 探 / 冻 / 退」---
    rho  = M.peb.level(M.reg_window)
    c_t  = M.ncd.step(r_res=M.last_r_res, da=M.last_da,
                      e=M.last_e, set_size=M.last_acp_size)
    if c_t == "drift" and rho >= GAMMA_PE:
        theta, P, _ = M.dce.update(M.phi, M.y, M.J_h, EPS_SLACK)   # 认证写
    elif c_t == "unidentifiable":
        theta, P = M.theta, M.P
    elif c_t == "poison":
        theta, P = M.frp.rollback(); M.tpm.bump_sigma()            # 回滚 + 更信先验
    # --- R69 层：静态交互仍可选（与探询共享预算）---
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.k_for(U_epi_hint(x))), x, M.fmp.mode_head)
    cand = M.kip.candidates(modes, o)                 # {yield, weave, commit, stop}
    xi   = max(cand + [M.mint.candidate(modes, o)],
               key=lambda z: M.dv.dual_value(z, modes, P, o, M.budget))
    safe = M.rcbf.filter(xi.a, M.acp.sets(o))         # 安全滤波器把关
    if safe is None:
        return M.ladder.enter("L3")                   # 紧急制动
    # --- 执行与审计 ---
    M.acp.commit()                                    # 用真实观测更新 conformal
    M.vqa_a.submit_async(xi, theta, P, c_t, rho)      # 适应 provenance
    return safe, theta, P, c_t

## 3. 推导

**引理 19（秩亏下的探询优势）** 设隐变量为他者策略 φ。在当前状态下，若被动观测的回归量秩 r < dim(φ)（让/不让在当前状态产生近似相同的观测分布），则任何被动信息动作 g 对 I(φ; y|g) 的提升 ≤ Δ_passive < Δ_min；而存在运动探询 q，使冲突窗内两策略的观测分布 KL 散度 ≥ δ_probe > 0，于是 I(φ; y|q) ≥ I(φ; y) + c·δ_probe。系：**当不确定性关于他者反应、且当前状态不具判别性时，DV 会严格偏好「动一下」而不是「再看一眼」**——这正是 R69 的静态 VoI 在动态避障中的结构性盲区。

**引理 20（激励门控的 UUB 与无漂移）** 在 A99（有界漂移 δ_drift）与定义 312–313、322 下：
(i) 无 PE 时 DCE 因死区/冻结不写，参数误差保持在上一个认证界内，不产生新的漂移——**R69 的零写不变式是 ρ_PE=0 的边界**；
(ii) 有 PE 时，带 σ-泄漏的递推估计满足 ‖θ̂_t − θ_t‖ ≤ B(δ_drift/γ_PE + ε_dz + σ_t‖θ_prior−θ_t‖)，即 UUB，且收敛速率随 σ_min(G_t) 增大；
(iii) 因此「学得快」与「稳得住」由同一个 ρ_PE 门控，不能既无激励又快速更新。

**引理 21（漂移下的 conformal coverage）** 自适应 conformal 更新（定义 317）在任意（可对抗、非可交换）序列上满足长期 coverage 偏差
| (1/T)Σ_t 1{s_t > q_t} − α | ≤ O(1/(γ_c T) + γ_c)，
与分布漂移幅度无关。因此 RCBF 使用的预测集在长期意义下以 ≈1−α 覆盖真实障碍位置；结合定义 318 的下确界构造，安全滤波不依赖障碍物的平均行为，只依赖预测集半径 q_t。

**引理 22（教学攻击的可达偏差上界）** 若对抗者可塑造激励，定义投毒半径 r_poison = sup_{‖Δθ‖≤Δ_max} ‖∂e/∂θ‖·Δ_max。则在 T 步后参数偏差 ≤ r_poison·T·(1−σ̄) / (1 + L_h r_poison)，其中 σ̄ 为平均先验混合系数。系：**增大 σ（更信先验）与减小 Δ_max 把「可被教错的程度」压成有界量**；配合 ASE 的 ε_slack 预留，攻击可降低性能但不能吃掉认证安全裕度。

**定理 18（安全适应与不变集）** 在 A99–A101 下，若 (i) x_0 ∈ 𝒮；(ii) 初始 CBF 可行；(iii) 所有适应更新经 ASE 投影；(iv) RCBF 使用 ACP 预测集且 QP 不可行时切 L3 制动，则对任意 τ，P(x_t ∈ 𝒮, ∀t≤τ) ≥ 1−α−ε_reach。即**适应与探询都被关在安全不变集内**，安全不因「边学边动」而让步。

**定理 19（三层严格包含）** ADEPT(0,0,1) 与 R69 逐指令相同，ADEPT(0,0,0) 与 R68 逐指令相同（定义 329）。且 J_ADEPT ⇒ J_FLUID ⇒ J_CALM。故 R70 是 R69 在「允许认证写 + 允许运动探询」方向上的严格泛化，安全侧单调不退。

**定理 20（降级无 Zeno、控制连续）** 降级阶梯 L0–L3 的触发谓词带滞回与最小驻留时间，且每层动作集嵌套、安全侧单调；一旦进入 L1/L2 即复用 R69/R68 的连续换装不变式。故在有限时间内切换次数有限，控制信号无突变，冻结/回滚不会与快反环产生冲突。**冻结-回滚不是异常，而是本方案的一等公民。**

## 6. 本轮最大风险

**一句话**：ADEPT-RAS 把 R69 的「问错」升级为「学错」——**当对手（或分布漂移）能够塑造激励时，系统可能通过完全合法的 ASE 投影学到一个自洽但错误的世界模型，并因为「我已经适应了」而更自信地压缩安全裕度；冻结-回滚能兜住单次错误，却未必能识别长期、缓慢、低幅度的教学式投毒**——最危险的不是不知道，而是**被教会了一个错误的安全感**。

**次级风险与缓解**：
1. **无 PE 却强行适应**（参数漂移/bursting）→ 激励门控 + 死区 + σ-泄漏 + 引理 20 的 UUB；
2. **ASE 投影吃掉安全裕度** → ε_slack 硬预留 + 定理 18 的不变集 + L3 保底；
3. **ACP 长期 coverage 达标但单步漏检** → 加最坏情况缓冲 + 多步 reachability，不把长期保证当逐步保证；
4. **运动探询本身制造冲突**（探身诱发碰撞/社交不适）→ KIP 幅度界 + RCBF 预认证 + 预算与社交成本；
5. **变化检测误分类**（把投毒当漂移）→ 四路残差 + 相关方向检验 + k 源证据 + 审计回灌；
6. **慢层压垮实时** → 三层时标解耦 + 快反/RCBF 关键路径不含任何自适应结论 + E314。

**收束**：R70 的回答不是「更会学习」，而是「**知道什么时候不该学**」——适应的价值，只有在一个不会因适应而失去安全的包络里才成立。

**定义 322（TPM）** `θ̂←(1−σ_t)θ̂+σ_t θ_prior`；`σ_t=σ_0+κ_p·poison_score`；与死区共同给出 UUB。

**定义 323（反应证据）** `r_resp`（让行/减速/转向/加速/沉默）并入证据集；沉默是弱证据，不得默认为让行。

**定义 324（ABS）** 三层时标解耦 + PE 预算 + value-density 调度；快反/RCBF 关键路径不含自适应结论。

**定义 325–326（证书与审计）** `J_ADEPT` 并入参数轨迹、激励水平、安全裕度下界、coverage 误差、回滚与教学告警；VQAuditor-A 审计写入/探询/回滚/越权定案。

**定义 327（降级阶梯）** L0↔L1↔L2↔L3，带滞回与最小驻留；动作集嵌套、安全单调，无 Zeno。

**定义 328（行为分类）** cooperative/neutral/non-cooperative/adversarial，以互惠估计 `ρ_recip` 决定让行/试探/停等。

**定义 329（三层严格包含）** `ADEPT(0,0,1)≡R69`，`ADEPT(0,0,0)≡R68`（逐指令相同）；`J_ADEPT⇒J_FLUID⇒J_CALM`。

## 3. 关键算法伪代码

```python
# IP-264 DCE：认证写（死区 + σ-泄漏 + 安全投影）
class DualControlEstimator:
    def update(self, phi, y, J_h, eps_slack):
        e = y - phi @ self.theta
        if abs(e) <= self.dz: return self.theta, self.P, "frozen_dz"
        d = clip(project_qp((self.P @ phi) * e /
                            (self.lam + phi @ self.P @ phi),
                            J_h, eps_slack), -self.dmax, self.dmax)
        self.theta = (1-self.sigma)*self.theta + self.sigma*self.theta_prior + d
        self.P = rank1_p_update(self.P, phi)
        return self.theta, self.P, "written"

# IP-265 PEB
def pe_level(window_reg):
    G = sum(phi.T @ phi for phi in window_reg)
    return sigma_min(G) / (sigma_max(G) + EPS)

# IP-269 ACP
def acp_update(q, score, alpha, gamma):
    return q + gamma * (alpha - (1.0 if score > q else 0.0))

# IP-268 DV
def dual_value(xi, modes, P, o, budget):
    task = expected_task_return(xi)
    info = mutual_info(mode_identity, obs_model(xi))
    exc  = trace(P) - expected_post_trace(P, xi, subspace="safety")
    risk = robust_cbf_risk(xi, acp_sets(o))
    return task + bI*info + bE*exc - bR*risk - cost(xi, budget)

# IP-278 主闭环：快层不可抢占；慢层可冻结；R69/R68 是边界
def ADEPT_RAS_round(M, obs):
    x, o = M.mtm.forward(obs)
    base = M.reflex.propose(x)                       # 1kHz 已认证反射，先兜底
    rho  = M.peb.level(M.reg_window)
    c_t  = M.ncd.step(M.last_r_res, M.last_da, M.last_e, M.last_acp_size)
    if c_t == "drift" and rho >= GAMMA_PE:
        theta, P, _ = M.dce.update(M.phi, M.y, M.J_h, EPS_SLACK)
    elif c_t == "poison":
        theta, P = M.frp.rollback(); M.tpm.bump_sigma()
    else:
        theta, P = M.theta, M.P                     # 冻结 = R69 边界
    U_ale, U_epi, modes, _ = M.aud.decompose(M.fmp.sample(o, M.k_for(x)), x, M.fmp.mode_head)
    cand = M.kip.candidates(modes, o) + [M.mint.candidate(modes, o)]
    xi   = max(cand, key=lambda z: M.dv.dual_value(z, modes, P, o, M.budget))
    safe = M.rcbf.filter(xi.a, M.acp.sets(o))
    if safe is None: return M.ladder.enter("L3")
    M.acp.commit(); M.vqa_a.submit_async(xi, theta, P, c_t, rho)
    return safe, theta, P, c_t
```

## 4. 推导

**引理 19（秩亏下的探询优势）** 若被动回归量秩 `r<dim(φ)`（让/不让在当前状态观测近同），则被动信息动作增益 `≤Δ_passive<Δ_min`；存在运动探询 `q` 使冲突窗内两策略观测分布 `KL≥δ_probe`，故 `I(φ;y|q)≥I(φ;y)+c·δ_probe`。系：不确定性关于他者反应且当前状态无判别性时，DV 严格偏好「动一下」而非「再看一眼」。

**引理 20（激励门控的 UUB 与无漂移）** 无 PE 时不写，参数误差保持在上一认证界内（零写是 `ρ_PE=0` 边界）；有 PE 时，带 σ-泄漏的估计满足
`‖θ̂−θ‖ ≤ B(δ_drift/γ_PE + ε_dz + σ‖θ_prior−θ‖)`，即 UUB，收敛速率随 `σ_min(G)` 增大。故「学得快」与「稳得住」由同一 `ρ_PE` 门控。

**引理 21（漂移下 conformal coverage）** ACP 在任意（可对抗、非可交换）序列上长期 coverage 偏差 `≤O(1/(γ_c T)+γ_c)`，与漂移幅度无关；RCBF 用预测集下确界，故安全滤波不依赖障碍物平均行为，只依赖 `q_t`。

**引理 22（教学攻击的可达偏差上界）** 参数偏差 `≤ r_poison·T·(1−σ̄)/(1+L_h r_poison)`，`r_poison=sup‖∂e/∂θ‖Δ_max`。系：增大 σ、减小 Δ_max 把「可被教错的程度」压成有界量；配合 ASE 的 `ε_slack`，攻击可降性能但吃不掉认证安全裕度。

**定理 18（安全适应与不变集）** 若 `x_0∈𝒮`、初始 CBF 可行、更新经 ASE 投影、RCBF 用 ACP 集且不可行时切 L3，则 `P(x_t∈𝒮,∀t≤τ)≥1−α−ε_reach`。适应与探询都被关在安全不变集内。

**定理 19（三层严格包含）** `ADEPT(0,0,1)≡R69`，`ADEPT(0,0,0)≡R68`（逐指令相同），且 `J_ADEPT⇒J_FLUID⇒J_CALM`。R70 是 R69 在「认证写 + 运动探询」方向上的严格泛化，安全侧单调不退。

**定理 20（降级无 Zeno、控制连续）** 阶梯谓词带滞回与最小驻留，动作集嵌套；进入 L1/L2 复用 R69/R68 换装不变式；有限时间切换次数有限、控制无突变。冻结-回滚是一等公民，不是异常。

## 7. 本轮最大风险

**一句话**：ADEPT-RAS 把 R69 的「问错」升级为「学错」——**当对手或分布漂移能塑造激励时，系统可能通过合法的 ASE 投影学到一个自洽但错误的世界模型，并因「我已适应」而更自信地压缩安全裕度；冻结-回滚能兜住单次错误，却未必识破长期、缓慢、低幅度的教学式投毒**——最危险的不是不知道，而是被教会了一个错误的安全感。

**次级风险与缓解**：无 PE 强行适应（激励门控+死区+σ-泄漏+UUB）；ASE 投影吃裕度（ε_slack 硬预留+定理 18+L3）；ACP 长期 coverage 掩盖单步漏检（最坏情况缓冲+多步 reachability）；探询自造冲突（KIP 幅度界+RCBF 预认证+社交成本）；变化检测误分类（四路残差+方向相关+k 源+审计回灌）；慢层压实时（三时标解耦+关键路径不含自适应结论）。
