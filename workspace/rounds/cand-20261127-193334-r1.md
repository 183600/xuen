### 第 1 轮灵感驱动研究记录

**灵感词**：语义地图、状态机

**直觉与动机**：

先给直觉。现有 CADVS-v1 的证书体系（STCK 时空域、GCK 抓取域、DAKI 证据挖掘、TCVM 时序守护、MRCC 多机一致性）已经把「何时、何地、由谁」纳入证书，但它默认了两件从未被证明的事：

1. **指称同一性（referent identity）**：一条证书谈论的到底是「这个杯子」还是「那个杯子」？STCK 只给出以质心为原点的球域 R_cec，若场景里有两个外观相同的杯子，二者都落在同一球域内，则关于 A 的抓取证书会被错误地套用到 B 上。证书没有说谎，是它根本没有「对象身份」这一维。语义地图恰好提供持久实体 ID、类别、属性、空间关系与拓扑，使证书从「空间中的一个点」升级为「关于某个语义实体的断言」。

2. **行为同一性（mode identity）**：一条「抓取稳定」证书只在「已夹持」状态下有意义，在「接近」或「放置」状态下它是无关甚至误导的。现有 CertChecker 把十二证无差别聚合，等价于假设所有证书在所有行为模式下都可消费，这是一种**上下文坍缩（context collapse）**。状态机（更准确地说，混合自动机的离散模式）为证书提供 state_scope，使「哪条证书在当前阶段算数」成为显式、可验证的判据。

把两者合起来，本轮的核心洞见是：**证书不是命题，而是带索引的判断**。用类型论的话说，证书应从 `⊢ φ` 变成 `cert ⊢_{e,q} φ`：它同时索引到一个语义实体 e 与一个行为状态 q。语义地图提供 e 的指称，状态机提供 q 的指称；证书则是对 `(e,q)` 局部世界的证明对象。这比「再加两个模块」更根本：它把证书系统从「扁平证据列表」变成「依赖类型的证据索引」，也让「证据链断裂」从缺数据问题，细化为**索引错误（indexing error）**问题。

进一步，语义地图可以看作连续世界的离散抽象（实体、区域、关系），状态机是连续行为的离散抽象（模式、迁移）。证书则是「抽象在局部忠实于真实世界」的证明。于是整个 CADVS-v2 可被表述为一个**证书化混合自动机（Certified Hybrid Automaton, CHA）**：每个模式有不变式证书，每次迁移有迁移安全证书，每个实体有地图置信度。安全性由「局部证书 + 归纳」得到，而不是由「十二证全绿」这种无结构的与门得到。

**关键洞见**：语义地图修复「证书在说谁」，状态机修复「证书在何时算数」；二者共同把证书有效性从 (空间, 时间) 升级为 (实体, 状态, 空间, 时间) 四元索引。索引化带来的不是更强的单点证明，而是**可组合性**：只有同一 (e,q) 下的证书才能合取，跨 (e,q) 的证书默认不可交换、不可传递。

**创新点提炼（相对 CADVS-v1，可证伪）**：

- **C1 指称化（certificate indexing）**：证书携带 anchor ∈ E（持久实体 ID）与 state_scope ⊆ Q，`valid_SCert(c,p,t,q)` 要求四者同时命中。可证伪判据：双杯/遮挡重识别场景中，SCM 对错指称证书的拒绝率显著高于 STCK 球域，且不误伤正确指称。
- **C2 语义-几何投影（semantic projection）**：定义 π_sem: ℝ³ → 2^E 与反向 lift，用实体区域替代球域，把 R33「球体近似非球形空间」的保守性转为「对象区域覆盖」的保守性。可证伪判据：狭窄通道/贴桌作业下，语义投影的有效作业体积利用率高于球域 ≥ 25%，同时越界拒绝率不下降。
- **C3 状态条件化聚合（state-conditioned aggregation）**：CertChecker 从「十二证与门」变为「当前模式所需证书集 + 迁移证书」的时变谓词。可证伪判据：在接近→夹持→抬升的模式切换中，跨模式误用证书导致的误通过率降为 0（离线注入测试）。
- **C4 混合自动机安全（certified hybrid automaton）**：给出「模式不变式 + 迁移证书 + 归纳」的安全性定理，而非逐帧经验阈值。可证伪判据：随机注入状态误判/迁移抖动，安全不变式违反次数在 N=10⁵ 次仿真中为 0，且不显著降低任务成功率。
- **C5 地图-证书互证（anti-index-poisoning）**：语义地图不得自证；实体置信度需由独立观测与证书消费结果共同更新，发现「证书指向的实体已移动/消失」即撤销该锚点下的证书。可证伪判据：人为移动/替换物体后，幻影实体证书在 ≤ T_revoke 内被撤销的比例 ≥ 95%。

**形式化目标（增量）**：

1. 定义语义证书地图 M_s = (E, R, A, L, conf)，其中 E 为持久实体集，R 为空间/功能关系，A 为属性（位姿、范围、可供性、材质、可通行性），L 为拓扑布局，conf: E → [0,1] 为接地置信度。
2. 定义语义证书 SCert = (cid, anchor, state_scope, R_e, T_e, precond, payload, prov)，anchor ∈ E，state_scope ⊆ Q，R_e ⊆ ℝ³ 为锚定区域，T_e ⊆ 𝕋 为时窗。
3. 定义四元有效性谓词：valid_SCert(c,p,t,q) ⇔ p ∈ R_{c.anchor} ∧ t ∈ T_c ∧ q ∈ state_scope(c) ∧ precond_c(M_s) ∧ conf(c.anchor) ≥ γ_map ∧ ¬revoked(c)。
4. 定义语义-几何投影 π_sem 与提升 lift_sem，并证明在覆盖裕度 δ 下投影是保守的（引理 35）。
5. 定义证书门控状态机 G = (Q, q0, Σ, δ, Λ, G_in, G_out, G_inv, Dwell)，迁移 (q --σ--> q') 仅当 TSC(q,q') 与 CertBundle(q) 同时满足时允许；并给出停留时间与迟滞以抑制抖动。
6. 定义 CADVS-v2 执行关系与执行集：Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29；证明在 (A1)–(A6) 下可达状态满足安全不变式 I（定理）。
7. 给出可证伪实验设计：指称消歧、语义投影利用率、跨模式误用、迁移抖动、幻影实体撤销五组实验及阈值。

**本轮最大风险**：**索引投毒（index poisoning）**——语义地图把「杯子 A」的持久 ID 错误地绑定到「被移动后的杯子 B」，或状态机把「接近」误判为「已夹持」，于是所有证书都在**正确的类型、错误的索引**下通过；系统不是缺证据，而是把证据挂到了错误的对象/状态上，表现出「全绿却抓空」的虚假确定性。

## 2. 关键算法骨架

### IP-481 Semantic Certificate Map (SCM)

```python
@dataclass
class SemanticEntity:
    eid: str                      # 持久实体 ID（track ID，跨帧稳定）
    cls: str                      # cup / table / door / shelf / room ...
    pose: np.ndarray              # 6D 位姿
    extent: np.ndarray            # 占据区域（AABB 或椭球参数）
    attrs: dict                   # affordance / material / traversability ...
    conf: float                   # 接地置信度 [0,1]
    last_seen: float              # 最近直接观测时刻
    certs: set[str] = field(default_factory=set)  # 挂在该实体上的证书 ID
    ambiguous: bool = False       # 身份关联存在歧义


@dataclass
class SemanticCertificateMap:
    """SCM：把证书从『空间中的点』升级为『关于某实体的断言』。"""
    gamma_map: float = 0.6
    tau_stale: float = 2.0
    tau_decay: float = 10.0       # conf 时间衰减常数
    delta_assoc: float = 0.15     # 关联几何门（米）
    epsilon_ov: float = 0.05      # 投影欠覆盖容忍

    def __post_init__(self):
        self.E: dict[str, SemanticEntity] = {}
        self.R: dict[str, set[tuple[str, str]]] = defaultdict(set)
        self._index = SpatialIndex()       # KD-Tree / 体素哈希

    # ---------- 实体维护 ----------
    def associate(self, obs: dict) -> tuple[str | None, bool]:
        """数据关联：几何 + 外观 + 时序三重门控。
        歧义（多个候选得分接近）时返回 (None, True)，绝不擅自继承证书。"""
        cands = self._index.query(obs['pose'], radius=self.delta_assoc * 3)
        scored = [(self._assoc_score(self.E[e], obs), e) for e in cands]
        scored.sort(reverse=True)
        if not scored:
            return None, False
        if len(scored) >= 2 and (scored[0][0] - scored[1][0]) < 0.1:
            return None, True             # fail-closed：歧义不认领
        if scored[0][0] < 0.5:
            return None, False
        return scored[0][1], False

    def upsert(self, obs: dict, t: float) -> SemanticEntity:
        eid, ambiguous = self.associate(obs)
        if eid is None:
            eid = self._new_eid(obs['cls'])
            self.E[eid] = SemanticEntity(
                eid=eid, cls=obs['cls'], pose=obs['pose'],
                extent=obs['extent'], attrs=obs.get('attrs', {}),
                conf=obs.get('conf', 0.5), last_seen=t, ambiguous=ambiguous)
            self._index.insert(eid, obs['pose'])
            return self.E[eid]
        e = self.E[eid]
        # 已存在实体：只在无歧义时融合，且融合不抬高到超过独立证据上限
        if not ambiguous:
            e.pose = self._fuse_pose(e.pose, obs['pose'])
            e.extent = self._fuse_extent(e.extent, obs['extent'])
            e.conf = self._fuse_conf(e.conf, obs.get('conf', 0.5), t, e.last_seen)
            e.last_seen = t
            e.ambiguous = False
        else:
            e.ambiguous = True
            self.revoke_entity(eid, reason='association_ambiguous')
        return e

    # ---------- 置信度与指称有效性 ----------
    def conf_at(self, eid: str, t: float) -> float:
        e = self.E[eid]
        return e.conf * math.exp(-max(0.0, t - e.last_seen) / self.tau_decay)

    def anchor_valid(self, eid: str, t: float) -> bool:
        if eid not in self.E:
            return False
        e = self.E[eid]
        if e.ambiguous or eid in self.revoked:
            return False
        if t - e.last_seen > self.tau_stale:
            return False
        return self.conf_at(eid, t) >= self.gamma_map

    # ---------- 查询 ----------
    def resolve(self, p: np.ndarray, cls: str | None = None) -> list[str]:
        out = []
        for eid in self._index.query(p, radius=0.0):
            e = self.E[eid]
            if cls is not None and e.cls != cls:
                continue
            if self._point_in_extent(p, e.extent):
                out.append(eid)
        return out

    def lift(self, eid: str, margin: float = 0.0) -> np.ndarray:
        """实体 → 空间区域（保守：可加裕度，不加则严格子集）。"""
        return inflate(self.E[eid].extent, margin)

    def revoke_entity(self, eid: str, reason: str):
        self.revoked.add(eid)
        for cid in list(self.E[eid].certs):
            self.revoke_cert(cid, reason=f'anchor:{eid}:{reason}')

    def revoke_cert(self, cid: str, reason: str):
        self.revoked_certs[cid] = reason

    def cert_payload(self) -> dict:
        return {
            'cert_id': 'kc_semantic_grounded',
            'payload': {'n_entities': len(self.E),
                        'n_ambiguous': sum(e.ambiguous for e in self.E.values()),
                        'n_revoked': len(self.revoked)},
            't_stamp': time.time(),
            'validity_window': 0.2,
            'src_node': 'semantic_map'
        }
```

**设计要点**：实体身份不是假设而是**待证命题**。关联得分接近时 `associate` 返回歧义，SCM 既不新建也不继承证书，而是撤销该锚点下的全部证书。这条 fail-closed 规则是 C5 抗索引投毒的第一道闸。

### IP-482 Semantic-Spatial Certificate Projection (SSCP)

```python
@dataclass
class SemanticSpatialProjection:
    """SSCP：语义域与几何域的双向投影，投影采用『包含式』而非『重叠式』。"""
    epsilon_ov: float = 0.05
    margin: float = 0.02

    def project_region(self, region: np.ndarray, map_: SemanticCertificateMap,
                       t: float) -> dict[str, float]:
        """空间区域 → {eid: 覆盖率}。仅当 extent(e) 被 region 覆盖比例 ≥ 1−ε_ov
        时，才认为该区域『代表』实体 e；部分覆盖只产生受限区域，不产生全权证书。"""
        out = {}
        for eid, e in map_.E.items():
            if not map_.anchor_valid(eid, t):
                continue
            cov = coverage_fraction(e.extent, region)
            if cov >= 1.0 - self.epsilon_ov:
                out[eid] = cov
        return out

    def project_cert(self, cert: SCert, map_: SemanticCertificateMap,
                     t: float) -> tuple[set[str], dict[str, np.ndarray]]:
        """证书锚定区域 → 可用实体集合 + 每个实体的有效子区域。
        包含式：extent(e) ⊆ R_c 才把整实体纳入；否则只把交集作为受限区域。"""
        full, restricted = set(), {}
        for eid, e in map_.E.items():
            inter = region_intersect(cert.R_e, e.extent)
            cov = coverage_fraction(e.extent, inter)
            if cov >= 1.0 - self.epsilon_ov:
                full.add(eid)
            elif cov > 0.0:
                restricted[eid] = inter
        return full, restricted

    def lift_query(self, eid: str, map_: SemanticCertificateMap,
                   margin: float | None = None) -> np.ndarray:
        m = self.margin if margin is None else margin
        return map_.lift(eid, m)

    def region_certificate(self, eids: set[str], map_: SemanticCertificateMap,
                           t: float) -> dict:
        """把一组实体聚合成一张区域证书（供 STCK 消费）。"""
        region = union([map_.lift(e) for e in eids])
        conf = min((map_.conf_at(e, t) for e in eids), default=0.0)
        return {
            'cert_id': 'kc_semantic_region',
            'payload': {'entities': sorted(eids), 'conf': conf,
                        'region': region.tolist()},
            't_stamp': t,
            'validity_window': 0.2,
            'src_node': 'sscp'
        }
```

### IP-483 Certificate-Gated State Machine (CGSM)

```python
CERT_BUNDLE = {
    'stand':   {'kc_balance', 'kc_loc_valid'},
    'walk':    {'kc_balance', 'kc_loc_valid', 'kc_spatiotemporal_valid'},
    'reach':   {'kc_balance', 'kc_vs_active', 'kc_semantic_grounded'},
    'grasp':   {'kc_balance', 'kc_vs_active', 'kc_semantic_grounded',
                'kc_grab_stable'},
    'lift':    {'kc_balance', 'kc_grab_stable', 'kc_transition_safe'},
    'place':   {'kc_balance', 'kc_grab_stable', 'kc_semantic_grounded'},
    'recover': {'kc_balance', 'kc_loc_valid'},
    'estop':   set(),
}


@dataclass
class CertGatedStateMachine:
    """CGSM：模式 q 只消费 state_scope 覆盖 q 的证书；聚合随时变。"""
    q0: str = 'stand'
    dwell: dict[str, float] = field(default_factory=lambda: {
        'stand': 0.2, 'walk': 0.2, 'reach': 0.1, 'grasp': 0.2,
        'lift': 0.3, 'place': 0.2, 'recover': 0.5, 'estop': 1.0})
    h_switch: int = 3             # 连续 3 次满足才允许切换（迟滞）

    def __post_init__(self):
        self.q = self.q0
        self.t_enter = 0.0
        self._pending = None
        self._pending_count = 0

    def required(self, q: str) -> set[str]:
        return CERT_BUNDLE[q]

    def filter_certs(self, certs: dict[str, SCert], q: str) -> dict[str, SCert]:
        """状态条件化：只保留 state_scope 覆盖 q 的证书。"""
        return {cid: c for cid, c in certs.items()
                if q in c.state_scope}

    def aggregate(self, certs: dict[str, SCert], q: str,
                  p: np.ndarray, t: float) -> tuple[bool, list[str]]:
        allowed = self.filter_certs(certs, q)
        missing = []
        for cid in self.required(q):
            c = allowed.get(cid)
            if c is None or not valid_SCert(c, p, t, q):
                missing.append(cid)
        return len(missing) == 0, missing

    def step(self, event: str, certs: dict[str, SCert],
             map_: SemanticCertificateMap, p: np.ndarray, t: float):
        # 1) 当前模式不变式；一旦破坏立即回退，不等迁移事件
        ok, missing = self.aggregate(certs, self.q, p, t)
        if not ok and self.q not in ('estop', 'recover'):
            self._enter('recover', t)
            return self.q, f'invariant_violated:{missing}'

        # 2) 枚举候选迁移，逐条检查 TSC + 目标模式证书
        cands = []
        for (q, sigma, qp) in self.transitions:
            if q != self.q or sigma != event:
                continue
            if t - self.t_enter < self.dwell[self.q]:
                continue
            tsc = TransitionSafetyCertificate.check(
                self.q, qp, certs, map_, p, t)
            if not tsc:
                continue
            ok_qp, _ = self.aggregate(certs, qp, p, t)
            if ok_qp:
                cands.append(qp)

        if not cands:
            return self.q, 'hold'

        # 3) 迟滞：同一候选连续 h_switch 次才真正切换
        target = max(cands, key=lambda x: self.priority[x])
        if target != self._pending:
            self._pending, self._pending_count = target, 1
            return self.q, f'pending:{target}'
        self._pending_count += 1
        if self._pending_count >= self.h_switch:
            self._enter(target, t)
            return self.q, f'enter:{target}'
        return self.q, f'pending:{target}'

    def _enter(self, q: str, t: float):
        self.q, self.t_enter = q, t
        self._pending, self._pending_count = None, 0

    def cert_payload(self, t: float) -> dict:
        return {
            'cert_id': 'kc_state_consistent',
            'payload': {'state': self.q,
                        'required': sorted(self.required(self.q))},
            't_stamp': t,
            'validity_window': self.dwell[self.q] * 2,
            'src_node': 'state_machine'
        }
```

### IP-484 Transition Safety Certificate (TSC)

```python
@dataclass
class TransitionSafetyCertificate:
    """TSC：迁移 q→q' 的前置/后置/不变式三段式证书。"""
    pre: dict = field(default_factory=dict)
    post: dict = field(default_factory=dict)
    inv: dict = field(default_factory=dict)
    dwell_min: float = 0.05

    @staticmethod
    def check(q: str, qp: str, certs: dict[str, SCert],
              map_: SemanticCertificateMap, p: np.ndarray, t: float) -> bool:
        rule = TRANSITION_RULES.get((q, qp))
        if rule is None:
            return False
        # 1) 前置：源模式关键证书仍有效
        for cid in rule['pre']:
            c = certs.get(cid)
            if c is None or not valid_SCert(c, p, t, q):
                return False
        # 2) 后置：目标模式的关键证书已可建立（或可安全建立）
        for cid in rule['post']:
            c = certs.get(cid)
            if c is not None and not valid_SCert(c, p, t, qp):
                return False
        # 3) 不变式保持：I(q) ∧ pre ⇒ I(qp)
        if not implies(rule['inv'], rule['pre']):
            return False
        # 4) 迁移瞬态：接触力/重心/速度不越界
        if rule.get('force_limit') is not None:
            if certs.get('kc_grab_stable') is None:
                return False
            if not (certs['kc_grab_stable'].payload['force'] < rule['force_limit']):
                return False
        return True


TRANSITION_RULES = {
    ('stand', 'walk'):  {'pre': {'kc_balance'}, 'post': {'kc_loc_valid'},
                         'inv': {'com_in_support'}},
    ('walk', 'reach'):  {'pre': {'kc_balance', 'kc_loc_valid'},
                         'post': {'kc_vs_active'}, 'inv': {'com_in_support'}},
    ('reach', 'grasp'): {'pre': {'kc_vs_active', 'kc_semantic_grounded'},
                         'post': {'kc_grab_stable'}, 'inv': {'com_in_support'},
                         'force_limit': 50.0},
    ('grasp', 'lift'):  {'pre': {'kc_grab_stable'},
                         'post': {'kc_grab_stable'}, 'inv': {'com_in_support'},
                         'force_limit': 50.0},
    ('lift', 'place'):  {'pre': {'kc_grab_stable'},
                         'post': {'kc_semantic_grounded'},
                         'inv': {'com_in_support'}},
    ('place', 'stand'): {'pre': {'kc_balance'}, 'post': {'kc_balance'},
                         'inv': {'com_in_support'}},
}
```

### IP-485 Semantic Map Integrity Monitor (SMIM)

```python
@dataclass
class SemanticMapIntegrityMonitor:
    """SMIM：地图-证书-传感器三方互证，检测幻影实体与自证。"""
    tau_revoke: float = 0.5        # 幻影实体撤销时限
    delta_move: float = 0.10       # 实体位移告警阈值（米）
    tau_self_cert: float = 0.2     # 自证时间窗

    def __post_init__(self):
        self.violations: list[dict] = []

    def on_cert_consumed(self, cert: SCert, outcome: str,
                         map_: SemanticCertificateMap, t: float):
        """证书消费结果回流：失败/异常接触反证地图指称。"""
        if outcome in ('grasp_fail', 'unexpected_contact', 'target_missing'):
            self._flag('consumption_contradiction', cert.cid, t)
            map_.revoke_cert(cert.cid, reason=f'outcome:{outcome}')

    def audit(self, map_: SemanticCertificateMap, sensor_frame: dict,
              t: float) -> list[dict]:
        actions = []
        for eid, e in map_.E.items():
            # 1) 幻影：证书锚定但实体长时间无直接观测
            if t - e.last_seen > self.tau_revoke and e.certs:
                actions.append(self._revoke(map_, eid, 'stale_anchor', t))
            # 2) 位移：实体位置与证书锚定区域不再一致
            for cid in list(e.certs):
                c = map_.get_cert(cid)
                if c is not None and not region_contains(c.R_e, e.pose,
                                                         tol=self.delta_move):
                    actions.append(self._revoke(map_, eid, 'anchor_drift', t))
            # 3) 自证：实体由与其证书同源的传感器单独建立
            if self._self_certified(e, sensor_frame):
                actions.append(self._revoke(map_, eid, 'self_certified', t))
        return actions

    def _self_certified(self, e: SemanticEntity, frame: dict) -> bool:
        srcs = {p['src'] for p in e.provenance}
        if len(srcs) <= 1 and len(e.certs) > 0:
            cert_srcs = {p['src'] for cid in e.certs
                         for p in self._cert_provenance(cid)}
            return srcs == cert_srcs
        return False

    def cert_payload(self, t: float) -> dict:
        return {
            'cert_id': 'kc_map_integrity',
            'payload': {'violations': self.violations[-10:],
                        'healthy': len(self.violations) == 0},
            't_stamp': t,
            'validity_window': 0.5,
            'src_node': 'map_integrity'
        }
```

## 4. 正确性论证（增量更新）

### 引理 35（语义-几何投影的保守性）

**陈述**：设证书 c 的锚定区域为 R_c，实体 e 的占据区域为 extent(e)。若采用包含式投影，即仅当 `coverage_fraction(extent(e), R_c) ≥ 1 − ε_ov` 时将 e 纳入 c 的可用实体集，并将受限区域取为 `R_c ∩ extent(e)`，则对任意 `p ∈ extent(e)`，c 在 p 处的空间有效性判定不会比真实有效域更宽松。

**证明**：情形一，`extent(e) ⊆ R_c`，则 `p ∈ extent(e) ⇒ p ∈ R_c`，空间判定与真实一致。情形二，`extent(e) ⊄ R_c`，则有效区域被收缩为 `R_c ∩ extent(e) ⊆ R_c`，任何被判定为有效的点仍属于 R_c，故不会产生越界误通过。投影只做「收缩或保持」，从不扩张，故保守。∎

**工程含义**：SSCP 用对象区域替代 STCK 的球域，不会因为「球包含物体」而把证书外推到物体之外；这正是 R33 空间建模误差的语义化修复。

### 引理 36（状态条件化聚合的可靠性）

**陈述**：设模式 q 的必需证书集为 CertBundle(q)，聚合谓词为 `agg(q) = ⋀_{cid ∈ CertBundle(q)} valid_SCert(c_cid, p, t, q)`。若 `filter_certs` 仅保留 `q ∈ state_scope(c)` 的证书，则任何参与 q 聚合的证书都显式声明适用于 q；不存在「在模式 q' 生成、未声明 q 适用」的证书被计入 q 的证据。

**证明**：`aggregate` 先调用 `filter_certs(certs, q)`，后者按 `q ∈ c.state_scope` 过滤；随后只从过滤结果中查找 `CertBundle(q)` 的成员。因此任一被计入的证书 c 必满足 `q ∈ state_scope(c)`，跨模式证书在进入聚合前已被排除。∎

**工程含义**：这把「十二证静态与门」变成时变谓词，消除了 R32 中「模式切换时旧证书仍被消费」的上下文坍缩。

### 引理 37（迁移证书对不变式的保持）

**陈述**：设安全不变式 I(q) 为模式 q 的闭包条件（如 COM 在支撑多边形内、接触力在界内、速度在包络内）。若初始模式 q_0 满足 I(q_0)，且对每个允许迁移 (q→q')，TSC 检查满足 `I(q) ∧ pre(q,q') ⇒ I(q')`，则自动机的所有可达模式均满足 I。

**证明**：对迁移步数归纳。基础：q_0 满足 I(q_0)。归纳：设第 k 步处于 q 且 I(q) 成立；若发生允许迁移 q→q'，由 TSC 的不变式保持条件得 I(q')；若停留在 q，则 I(q) 继续成立。故所有可达模式满足 I。∎

**工程含义**：这是 C4 的核心——安全性不再依赖逐帧阈值碰运气，而由「局部迁移证书 + 归纳」保证；TSC 是归纳步的证明义务。

### 引理 38（锚点撤销的幻影窗口有界）

**陈述**：若 SMIM 以周期 T_a 审计、实体陈旧阈值 τ_stale、位移阈值 δ_move，且审计覆盖所有挂证实体，则从实体变为幻影（无直接观测或锚点漂移）到其证书被撤销的时间上界为 `τ_stale + T_a`（陈旧情形）或 `T_a + T_consume`（消费反证情形）。

**证明**：陈旧情形下，实体最后一次直接观测后经过 τ_stale 即被审计判为 stale；下一次审计最迟在 T_a 内发生，故撤销延迟 ≤ τ_stale + T_a。消费反证情形下，`on_cert_consumed` 在证书消费失败时立即撤销，最坏延迟为一次消费反馈链路时延 T_consume，加上审计周期 T_a。∎

**工程含义**：幻影实体不是永久污染，而是有界窗口内的污染；T_revoke 应设为该上界并纳入 SLO。

### 定理（CADVS-v2 执行集收缩与不变式安全）

**陈述**：在以下假设下：
(A1) SCM 的实体关联在无歧义时正确，歧义时 fail-closed（引理 36 的前置）；
(A2) 语义投影为包含式（引理 35）；
(A3) CGSM 的 `filter_certs` 与 `aggregate` 按实现执行（引理 36）；
(A4) 每个允许迁移都通过 TSC 的不变式保持检查（引理 37）；
(A5) SMIM 审计周期满足 SLO，幻影撤销有界（引理 38）；
(A6) 回退路径（recover/estop/教师）均为 Exec_CADVS-v1 子集。

则 `Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29`，且所有可达模式满足安全不变式 I。

**证明**：
- 执行集收缩：CADVS-v2 的每个单步要么是原 CADVS-v1 单步加上 (i) 状态条件化证书过滤、(ii) 语义锚定、(iii) 迁移安全证书、(iv) 地图完整性门控；四者都是**附加合取条件**，不新增控制原语，也不放宽任何既有守卫。故每一步在去掉附加条件后仍是合法的 CADVS-v1 步骤，即 Exec_CADVS-v2 ⊆ Exec_CADVS-v1。再由 CADVS-v1 ⊆ Exec_v29（既有结果）得传递性。
- 不变式安全：由 (A4) 与引理 37，所有可达模式满足 I；由 (A1)(A2)(A5)，证书不会因错误指称或幻影实体而虚假通过；由 (A3)，跨模式证书不会被误计入。综合得证。∎

**诚实声明**：上述假设在工程中**并非恒真**。(A1) 受遮挡、外观相似、重识别失败影响；(A2) 受实体分割/占据栅格误差影响；(A3) 依赖 state_scope 标注正确；(A4) 依赖迁移规则覆盖所有实际迁移，未建模迁移会绕过 TSC；(A5) 受审计算力与传感器遮挡影响；(A6) 依赖回退路径实现正确。CADVS-v2 通过 SMIM 的运行时撤销、CGSM 的停留/迟滞、以及教师路径兜底来管理这些风险，而不是宣称假设恒真。

| R37 | **索引投毒**（实体 ID 错误绑定/状态误判，证书类型正确、索引错误） | **极高** | 1) 关联三重门控 + 歧义 fail-closed；2) SMIM 三方互证 + 锚点撤销；3) 消费结果反证回流；4) 禁止证书自证 | 外观完全相同且无遮挡时，重识别仍可能长期错误；需主动感知或物理标记 |
| R38 | **语义地图漂移/陈旧**（动态环境、移动物体、地图更新滞后） | 高 | 1) conf 时间衰减 + τ_stale 硬门控；2) 地图差分触发重规划；3) 关键实体短周期主动复核 | 高频动态场景下地图维护成本高，可能频繁撤销导致任务停滞 |
| R39 | **状态误分类与抖动**（感知噪声导致模式判错，频繁切换） | 高 | 1) Dwell 最小停留；2) h_switch 迟滞；3) 模式信念 b(q) 阈值；4) 迁移需 TSC 全绿 | 迟滞带来切换延迟，紧急场景下可能响应偏慢 |
| R40 | **迁移规则不完备**（未建模的迁移绕过 TSC） | 高 | 1) 默认拒绝未声明迁移；2) 运行时记录未建模事件并告警；3) 形式化审查迁移表覆盖 | 开放世界中总存在未建模事件，需人工维护迁移表 |
| R41 | **语义标签错误**（类别/可供性误判，证书挂错类型） | 中 | 1) 类别置信度门槛；2) 多模态交叉验证；3) 关键操作前主动复核 | 细粒度可供性（如「可抓」vs「可推」）仍可能误判 |
| R42 | **地图-证书循环自证**（同一传感器既建图又发证） | 高 | 1) prov 记录来源；2) 自证检测；3) 至少一个独立模态锚 | 单一传感器配置下无法满足独立锚，需硬件冗余 |
| R43 | **语义层引入的实时性开销**（地图查询/审计进入控制环） | 中 | 1) 地图线程与控制环解耦；2) 证书摘要缓存；3) 审计周期化、非关键路径 | 共享 CPU/GPU 时仍可能与 200Hz 控制环争用 |

## 7. 本轮最大风险（最终确认）

**一句话**：**索引投毒（index poisoning）**——语义地图把「杯子 A」的持久 ID 错误地绑定到被移动后的「杯子 B」，或状态机把「接近」误判为「已夹持」，使所有证书都在**正确的类型、错误的索引**下通过；系统不是缺证据，而是把证据挂到了错误的对象/状态上，表现出「全绿却抓空」的虚假确定性，这是 CADVS-v2 从「有证书」走向「证书可信」的生死线。
