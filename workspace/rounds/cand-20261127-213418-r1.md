## 1. 直觉：为什么「动力学」和「场景泛化」必须一起谈

**直觉 1（5 条轴里 4 条是场景因子，1 条是纯动力学；但每条都改变动力学）**
- 位置泛化 → 改变可达性、抓取构型、遮挡关系：是**运动学/动力学边界**。
- 干扰物泛化 → 改变碰撞、遮挡、可行路径：是**接触动力学**。
- 背景泛化 → 改变外观与光照，也改变光流/运动线索：是**感知动力学**。
- 未见物品泛化 → 同类不同颜色/形状/**材质**：材质直接改变摩擦、质量、形变，是**动力学分布外**。
- 人为干扰泛化 → 外部手/物体轨迹：最直接的**外部力动力学**。

所以，**「场景泛化」的真正难点不在像素变化，而在像素变化背后「动作→结果」关系的改变。** 只做背景随机化、颜色抖动，最多覆盖 4 条轴的表层；决定成功率和步骤分的是接触段的动力学。

**直觉 2（v1.1 的三个盲点）**
- 盲点 A：增广只改首帧/静态帧，不改**转移动力学**。合成十万条「不同背景的同一段轨迹」，策略学到的是「背景无关」，不是「新材质怎么抓」。
- 盲点 B：检索（I9）给的是动作先验（开度/高度），不是**闭环动力学**。新杯子检索到最像的杯子，但摩擦不同，抓起来会滑。
- 盲点 C：世界模型（I7）被放在推理期做前瞻，延迟与 15Hz/66ms 预算冲突、收益不确定；但它真正的价值是**训练期的动力学教师**——用「动作会导致什么」约束表示，而不是用「画面长什么样」约束表示。

**直觉 3（统一命题）**
> 场景泛化 = 在场景因子分布偏移下，保持「动作→结果」映射的稳定性。
> 因此正确的训练目标不是「对场景不变」，而是「对**动力学充分**」：表示 φ 只需保留与任务动力学、得分点可达性相关的信息，其余因子（背景、干扰物外观、未见过的颜色）应被边缘化。

**严谨定义（本轮的分析骨架）**
- 场景分解：`S = (B, O, R, H)`，`B` 背景、`O={o_i}` 物体（目标/容器/干扰物，含外观 `a_i` 与位姿 `x_i`）、`R` 空间关系、`H` 人。
- 动力学：`S_{t+1} ~ f(S_t, a_t, ξ_t)`，`ξ_t` 为不可观物理参数（质量、摩擦、形变、流体黏度）。
- 观测：`o_t = h(S_t) + noise`（4 相机 + 本体），无触觉。
- 策略：`π(a_{t:t+T-1} | o_{≤t}, g)`，`g` 为语言指令，隐含得分点序列 `{s_1,…,s_K}`。
- 目标：在 180s 内最大化成功率与步骤分。

**误差分解（可操作的经验式，非定理）**
```
E_gen  ≤  E_perc(φ)      # 未见物品/背景：表示感知缺口
        + E_dyn(φ, f)     # 接触/材质/外部力：转移动力学缺口
        + E_comp(π)       # 因子新组合：组合泛化缺口
        + E_emb(reach)    # 位置超出工作空间：可达性/平衡缺口
```
四项分别由 D2、D1/D3、D2/D6、D7 主攻；D4 提供覆盖、D5 处理人因、D6 负责诊断。这个分解不是严格定理（它按因子偏移取上确界做三角不等式），但它的价值在于**把「泛化」拆成可分别度量的四个量**，从而让消融有靶子。

**直觉 4（相态路由为什么能降方差）**
接触任务的动作分布是多峰的：接近、接触、约束运动、释放四个相态的动作统计差异很大。若不分相，流匹配要在一个条件 `o_t` 下同时拟合多峰；按全方差公式：
```
Var(a | o) = E_z[ Var(a | o, z) ] + Var_z( E[a | o, z] )
```
相态路由消除的是第二项（相间方差）。这是 D1 的严格动机：**不是加模块，而是去掉一个可解释的方差源**。同时它给出可证伪判据：若相态后验在接触瞬间不可靠，第二项反而会被错误路由放大。

### 0.2 泛化误差的启发式分解

对场景因子偏移 `Δ`，用三角不等式把策略的 action-value 缺口拆成四项：

```
E_gen(Δ) ≤ E_perc(φ)      # 未见物品/背景：表示感知缺口
```

这不是严格定理（上确界与三角不等式的形式化需额外假设），但它把「泛化」拆成**可分别度量、可分别消融**的四个量。四项与 D 点、度量的映射：

## 1. D1 动力学相态路由（DPR）★★★★★

### 1.1 动机（直觉）

接触任务的动作分布是多峰的：接近、接触建立、约束运动（插入/拧/倒/拉链）、释放，四个相态的动作统计差异很大。单一流匹配头在同一个 `o_t` 下同时拟合多峰，会在相变附近产生**模式平均**（犹豫、抖动、过冲），而这正是步骤分最贵的时刻。D1 不改模型结构，只把「相态」作为条件变量显式化。

### 1.2 严谨定义

- 隐相态 `z_t ∈ {APPROACH, CONTACT, CONSTRAINED, RELEASE}`。
- 显式时长 HSMM：转移矩阵 `A`、时长分布 `D_k(·)`、观测模型 `p(ν_t | z_t)`，其中
  `ν_t = [EE 线速度, EE 角速度, 夹爪开合速度, 腕相机光流幅值, 关节速度范数]`。
- 离线：用 32k 示教按任务族 EM 拟合；弱标签初始化 = 夹爪闭合事件、EE 速度驻留（<阈值持续 k 帧）、腕部光流尖峰。
- 在线：前向滤波得后验 `p(z_t | ν_{≤t})`，加滞回（进入 >0.7 连续 2 帧、退出 <0.3、最短驻留 2 帧）。
- 策略：`π(a | o, g, z)`，相态嵌入用 AdaLN/FiLM 注入 action expert；相态决定 chunk 长度（APPROACH 8–16、CONTACT/CONSTRAINED 4–6、RELEASE 2–4）。

### 1.3 为什么可能有效（可证伪的方差论证）

按全方差公式：
```
Var(a | o) = E_z[Var(a | o, z)] + Var_z(E[a | o, z])
```
相态路由消除第二项（相间方差）。若相态推断可靠，条件目标熵下降，流匹配的积分误差与采样方差下降；若相态在接触瞬间不可靠，第二项会被**错误路由放大**，这是本点的核心风险，也是 L0 的 kill criterion。

```python
    ], axis=-1)                                    # (T, 5)

# offline: explicit-duration HSMM per task family
hsmm = ExplicitDurationHSMM(n_states=4, duration_prior="geometric")
hsmm.fit([phase_obs(ep) for ep in demos], weak_labels=contact_heuristics(demos))

# online
def infer_phase(hist, prev_post):
    post = hsmm.forward_filter(phase_obs(hist))
    z = hysteresis(post, prev_post, enter=0.7, exit=0.3, min_dwell=2)
    return z, post

def get_action(obs, state):
    z, post = infer_phase(obs["hist"], state.prev_post)
    T = {"APPROACH": 12, "CONTACT": 4, "CONSTRAINED": 5, "RELEASE": 3}[z]
    a = action_expert(obs, phase_emb=embed(z), chunk=T)   # one model, AdaLN
    return a
```

### 1.5 资源 / 落地 / 判据

- 资源：HSMM 拟合 CPU 数小时；相态嵌入训练随主训练，无额外推理显存；在线滤波 <1ms。
- 落地：①弱标签 + HSMM 拟合；②留出任务相态一致性检验；③相态嵌入 + 相态 chunk；④L0 消融；⑤单任务通道接触任务 A/B。
- **Kill criterion**：接触相 AUROC < 0.75（对手工相变标签），或 L0 相态后验在接触段熵 >0.8 → 降级为「辅助损失/辅助监督」，不做硬路由。

## 2. D2 场景图因子化泛化（SGF）★★★★★

### 2.1 动机（直觉）

5 条轴是**独立因子**：位置、干扰物、背景、外观、人。若在完整笛卡尔积上采样，成本是乘积级；但真实场景因子的交互通常是低阶的（位置×干扰物、外观×背景），因此可用「因子化生成 + 少量高阶交互」把覆盖成本从乘积级降到和级。同时，策略若以**物体 token** 而非整图作条件，就能在测试时重新绑定「新外观物体 → 同一技能」，而不是把外观当标签记住。

### 2.2 严谨定义

- 场景图：`G = (V, E, b)`，节点 `v_i = (crop_i, pose_i, affordance_i, class_i)`，边 `E` 为空间关系（left-of / on / inside / near），`b` 为背景 token。
- 因子化生成：`p(S) ≈ p(b) ∏ p(v_i) ∏ p(E)`；干预 `do(F=f)` 只重采样一个因子，其余保持。
- 平衡采样：每因子边际等概率；`85%` 单因子干预 + `15%` 两因子交互（位置×干扰物、外观×背景），以检验低阶交互假设。
- 策略：节点 token 交叉注意力到语言/得分点 token；背景 token 以 `p=0.3` dropout；物体 token 做 FAISS 检索（吸收 I9），命中则注入动作先验（夹爪开度/接近高度/朝向）。
- 组合泛化假设（可检验）：若因子对动作的影响近似**稀疏低阶交互**，则 `O(∑|F_i|)` 覆盖即可，无需 `O(∏|F_i|)`；D6 的因子析因直接检验该假设。

### 2.3 伪代码

```python
FACTORS = ["pose", "distractor", "background", "appearance", "human"]

def sample_intervention(scene, rng, syllabus):
    k = rng.choice([1, 2], p=[0.85, 0.15])
    fs = rng.choice(FACTORS, size=k, replace=False)
    S2 = scene
    for f in fs:
        S2 = do(S2, f, sample_from_syllabus(f, task))   # 考纲卡（I1 保留为采样先验）
    return S2

def scene_graph(obs, instruction):
    objs = open_vocab_detect(obs.images, instruction)
    nodes = [object_token(crop=o.crop, pose=estimate_pose(o),
                          aff=affordance(o, instruction)) for o in objs]
    bg = background_token(obs.images)                    # dropout p=0.3
    return Graph(nodes, edges=spatial_relations(nodes), bg=bg)

class GraphPolicy:
    def get_action(self, obs):
        g = scene_graph(obs, self.lang)
        tokens = self.encoder(g)                         # object-centric
        hit = self.index.search(g.target_token, k=3)     # 吸收 I9
        prior = hit.action_params if hit.dist < TAU else None
        return self.action_expert(tokens, prior=prior, bg=g.bg)
```

### 2.4 资源 / 落地 / 判据

- 资源：开放词汇检测 + 分割 + 位姿估计；离线场景图 1 GPU 日；训练随主训练。
- 落地：①32 任务场景图最小原型（4 相机，先单臂任务）；②因子化采样器；③物体 token 策略微调；④检索库；⑤L0 因子留出 + L2 未见物品/干扰物轴。
- **Kill criterion**：场景图绑定错误率 >15%（人工抽检 200 帧），或 L0 留出因子组合 Δprog<0 → 退回整图增广 + 物体裁剪检索，不做图策略。
- **部署注意**：检测器若在每步调用会破坏 p99 预算；仅在 `reset` + 每 K=4 步调用，或把 token 化蒸馏进 VLA。

## 3. D3 动力学一致性自监督（DCA）★★★★

### 3.1 动机（直觉）

世界模型（WMA-0）很贵，但它是唯一显式建模「动作→未来」的资产。v1.1 把它放在推理期做前瞻（I7），与 66ms 预算冲突。反过来用：**把 WMA-0 冻结成教师，在训练期约束 VLM 的视觉表示编码动力学**。背景、颜色等 nuisance 因子不能从动作预测，因此会被动力学目标自然压掉——这正好服务场景泛化。

### 3.2 严谨定义

- 表示 `φ = VLM.visual_encoder`；冻结教师 `φ_T = WMA0.encoder`（离线缓存 latent，避免训练时反复前向）。
- 动作条件预测损失：`L_dyn = ||P_ψ(φ(o_t), a_{t:t+k}) − sg(φ_T(o_{t+k}))||²`（或对齐 `φ` 与 `φ_T` 的投影）。
- 逆动力学损失：`L_inv = ||G_ω(φ(o_t), φ(o_{t+1})) − a_t||²`（强迫表示保留动作可解释性）。
- 防坍缩：VICReg 方差/协方差项，或 stop-gradient + EMA target。
- 总损失：`L = L_action + λ(t)·(L_dyn + L_inv) + β·L_reg`，`λ` 预热。
- 信息论直觉（非定理）：动力学目标最大化 `I(φ(o_t), a_t; φ(o_{t+k}))`，在因果充分性假设下近似保留动力学相关信息；nuisance `N` 与动作条件独立，故被压缩。

### 3.3 伪代码

```python
# offline: cache frozen teacher latents
for ep in corpus:
    cache[ep.id] = [wma0.encode(f) for f in ep.frames]   # fp16, ~1.6GB/32k eps

# train
for batch in loader:
    o_t, a, o_fut, z_fut = batch
    z_t = phi(o_t)
    L_dyn = mse(P(z_t, a), z_fut.detach())
    L_inv = mse(G(phi(o_t), phi(o_t1)), a_t)
    L = L_action + lam(step) * (L_dyn + L_inv) + beta * vicreg(z_t)
    L.backward()
```

### 3.4 资源 / 落地 / 判据

- 资源：latent 缓存 ~1.6GB（32k eps × ~100 帧 × 256 维 × fp16）；小预测头 1–2 GPU 日；**推理零额外成本**（教师不上线）。
- 落地：①WMA-0 编码器冒烟 + latent 缓存；②冻结教师 + 小预测头；③λ 预热；④L0 留出物品/背景；⑤与等算力数据增广对照（Q11）。
- **Kill criterion**：L0 留出轴成功率增益 <2% 或步骤分 <1 分 → 剪除；若只提升标称、恶化未见轴 → 说明表示学了背景捷径，立即剪除。

## 4. D4 物理一致反事实增广（PCA）★★★★

### 4.1 动机（直觉）

静态增广改的是「看起来怎样」，反事实增广改的是「如果…会怎样」：如果物体偏 2cm、如果前面多个干扰物、如果杯子更滑。关键是**物理一致**：只保留不穿模、加速度平滑、且确实推进得分点的反事实轨迹。

### 4.2 严谨定义

- 反事实：`(S', τ') = R(f, do(S, F=f), π_demo)`，`R` 为 rollout 引擎。
- 引擎优先级：①**真实扰动重放**（同任务示教从 t 重放 + 位姿/抓取点扰动 + inpaint 重渲染）——主力，避免 sim gap；②Isaac Lab（F14）——补足碰撞/摩擦；③WMA-0 仿真模式（F15）——短续写，仅作补充。
- 一致性分数：`C = w1·no_penetration + w2·smoothness(τ') + w3·progress(τ', score_steps)`；仅保留 `C>τ` 的段。
- 得分点门禁：沿用 I5 的里程碑检测器，只有达成下一得分点的段才入训（避免把「偏离但没修正」当正样本）。

### 4.3 伪代码

```python
def counterfactual(demo, factor, syllabus):
    S2 = do(demo.scene_at(t), factor, sample_from_syllabus(factor, task))
    engine = "real_replay" if can_replay(demo, factor) else \
             "isaac" if factor in {"pose", "distractor"} else "wma0"
    tau2 = rollout(demo.actions[t:], S2, engine=engine)
    C = (w1 * no_penetration(tau2) + w2 * smoothness(tau2)
         + w3 * progress(tau2, score_steps))
    return tau2 if C > TAU and reaches_next_step(tau2) else None
```

### 4.4 资源 / 落地 / 判据

- 资源：数据工程 2 人周；真实重放为主，Isaac/WMA-0 为辅；存储 +1–2TB。
- 落地：①3 个接触任务试点（PlugCharger / ZipUp / PourOutMedicine）；②一致性过滤；③混入 I2 数据引擎；④族级 L0；⑤单任务通道 A/B。
- **Kill criterion**：反事实接受率 <20%，或混训后标称退步 >2% → 剪除；sim 来源的样本若与真实重放分布差异大，降为 ≤20% 混比。

## 5. D5 人因动力学让位-恢复（HDR）★★★★

### 5.1 动机（直觉）

人为干扰是 5 轴里唯一的**纯动态**轴。v1.1 的 I4 只做「检测到手 → 暂停」，代价是浪费 180s 预算、丢失步骤分，且人手离开后还要重新对位。D5 把人手当作**可预测的外部轨迹**：预测未来 0.5–1s 的手部位置，提前让位到安全侧，人手离开后重新解析场景图并从当前进度续做。

### 5.2 严谨定义

- 增广状态：`s_t = (robot_state, scene_graph, hand_keypoints_{t-k:t})`。
- 手部短时预测：`Ĥ_{t+1:t+H} = f_H(hand_hist)`，`H≈8` 步（≈0.5s @15Hz）。
- 安全约束：EE–手距离的离散控制屏障 `h(s)=||p_ee−p_hand||²−d_safe²`，`h(s_{t+1}) ≥ (1−α)h(s_t)`。
- 状态机：`NOMINAL → YIELD → REASSESS → RESUME`；YIELD 沿安全方向后退并保持目标可见；REASSESS 重新解析场景图 + 目标位姿；RESUME 从当前进度续做，不重置 episode。
- 合规：这是反应式控制，不是在线学习；`reset` 语义不变（F24）。

### 5.3 伪代码

```python
def step(obs, st):
    hands = detect_hands(obs.images)
    pred = predict_hand(hands, H=8)
    if min_dist(pred, ee(obs)) < d_safe:
        return retreat_safe(obs, pred), st.set("YIELD")
    if st.state == "YIELD" and hands_clear(obs) and reparse_stable(obs):
        st.target = scene_graph(obs, st.lang).target
        st.state = "RESUME"
    return policy.get_action(obs), st
```

### 5.4 资源 / 落地 / 判据

- 资源：手部检测/关键点（现成模型）+ 小预测头；在线 <10ms。
- 落地：①手部检测 + 距离阈值；②短时预测；③状态机 + CBF；④L0 仿真回放；⑤单任务通道人为干扰 A/B。
- **Kill criterion**：手部检测延迟 >100ms 或误检率 >10% → 退回 I4 的简单暂停；任何让位动作触发关节限位/跌倒 → 立即降级为「原地停持」。

## 6. D6 动力学分层评测矩阵（DSM）★★★★

### 6.1 动机（直觉）

v1.1 的 L0/L1/L2 只按「模块」分层，没有按「动力学难度」分层。结果是：一个模块可能只在准静态任务上有效，却被平均分掩盖。D6 把评测做成 `5 轴 × 3 动力学regime` 的矩阵，并用分层贝叶斯模型做部分池化——因为 320 次总预算下，单格 n=2，根本做不了逐格显著性检验。

### 6.2 严谨定义

- 动力学 regime：`Q` 准静态（抓放/整理）、`C` 接触丰富（插入/拧/拉链/堆叠）、`D` 形变/流体/颗粒（折叠/倾倒/注射）。
- 指标：成功率、步骤分、time-to-success、恢复率；轴缺口 `gap_axis = perf_nominal − perf_axis`；动力学缺口 `gap_dyn = perf_Q − perf_C/D`。
- 统计：分层 logistic/ordinal 模型
  `logit(p_{task,axis}) = μ + a_task + b_axis + c_regime + (b×c) + …`，`a_task ~ N(0,σ²)` 部分池化；报告后验均值与 89% HDI。**不做事后逐格 p 值**。
- 功效说明：两比例检验在 `p≈0.3–0.4、Δ=0.1、α=0.05、power=0.8` 下每组约需 **353** 次；总预算 320 次，故 L2 只能做**配对/同初始条件**的效应量确认，不能做独立组显著性。步骤分是连续量，统计功效高于成功率，应作为主判据之一。

### 6.3 动力学分层任务表（示例；双臂/材质归属待任务 wiki 逐项核实）

| regime | 代表任务（示例） | 主要动力学 |
|---|---|---|
| Q 准静态 | ArrangePlates、ArrangeTestTubes、ColorArrangement、OrganizeBookshelf、OrganizePencilCase、StoreCups、FruitSorting | 抓放、排列、避碰 |
| C 接触丰富 | ZipUp、Unlock、PlugCharger、PlugInEthernet、DisconnectEthernet、PickOutBatteries、PaperCupStacking、StackBowls、RemovePinnedNote、ConveyorSorting | 插入、卡扣、堆叠、滑动 |
| D 形变/流体/颗粒 | FoldTowel、PackDoll、PackBag、PourOutMedicine、SyringeWaterTransfer、FruitCollection | 形变、倾倒、液量、软体 |

### 6.4 评测协议（L0/L1/L2 + 动力学分层）

| 级别 | 内容 | 通道/成本 | 通过判据 |
|---|---|---|---|

## 13. 本轮最值得押注（一句话）

**押「动力学相态 × 场景因子」双引擎：D1（相态路由，直接对齐接触任务的步骤分）+ D2（因子化场景图，把 5 轴从乘积级覆盖降为和级），并用 D3/D4 在训练期注入动力学与反事实数据、D6 用动力学分层矩阵做选型——在官方单卡可微调的成本结构下，这是把「场景泛化」从外观问题拉回动作-结果问题的最高杠杆组合。**

## 14. 本轮最大风险（一句话）

**D1/D2/D4 都依赖「从成功示教中无监督抽出可靠相态与场景因子标签」；相态最不可靠的时刻恰是遮挡最重、最关键的接触瞬间，一旦相态后验在接触段失效，路由与反事实过滤会同时把误差放大到所有接触任务——所以第一道闸必须是 L0 的相态一致性检验，而不是真机 A/B。**
