# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配主动交互不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「主动交互」×「可解释性」）

> R69 给闭环装上了一张「嘴」：它能区分 aleatoric 与 epistemic，能生成注视/探针/问句去消解歧义，并用流似然给标定层配了第二意见。但它自陈的最大风险恰好落在嘴上——**「问错，比不问更危险」**：如果流模型的模态分布本身不可信，VoI 就是在错误信念上计算，系统会自信地追问一个幻影，或把一个误导性回答盖上「已验证」的章。问题在于，R69 的「验证」是**单通道**的：它只问「我得到的证据是否让我更确定」，却从不问「我凭什么相信我这个确定是对的」。
>
> 更根本的缺口：R69 的交互决策对人是**不透明**的。人类看到系统停下来注视、发问、改道，却拿不到一个可检验的理由；而系统也拿不到人类「为什么这样答」的可检验理由。于是「主动交互」与「可解释性」在这里不是两个并列功能，而是同一个缺失的两面：
> - **可解释性**若只做事后热力图/流畅话术，就无法参与决策，只能是装饰；
> - **主动交互**若不携带可被反驳的解释，就无法被审计，只会放大自信。
>
> 核心命题：**把「解释」从后验渲染升级为「可证伪的因果契约」——每次选择模态/交互/减速，系统都要押一个可观测的注（反事实断言 + 预期观测 + 证伪集）；主动交互不再只用来消解模式歧义，更用来「证伪自己刚才的解释」；解释只有通过反事实忠实度回放、预测校准与人类质疑仲裁后才「生效」，否则一律退化为 R69。** 命名 **ECHO-RAS**（Explanation-as-Contract with Human-contestable Outcomes，可证伪解释契约的主动交互闭环）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**我凭什么这么问、你又怎么知道我没错**」——解释不是一张事后画出的图，而是一份可以被实验证伪、被人当面反驳的契约。

## 0. 直觉与动机

**灵感 1（可解释性 → 解释是一张「可兑现的期票」，不是一幅画）**
直觉：人类说「我减速是因为看到行人」时，这句话的真正含义是一个反事实承诺——**如果那个行人不在，我就不会减速**。这句话之所以有价值，不在于它听起来合理，而在于它可以被检验：挪走行人、重放一遍，看行为是否改变。R69 的解释（如果它有任何解释的话）是「我的模态权重显示绕左 0.7 / 绕右 0.3」——这是**描述**，不是**承诺**，无法被证伪。把解释定义为契约，等于给每一句「因为」都配上一个「如果…则不…」的对照实验和一组证伪观测。**解释的可信度不再由流畅度决定，而由它敢不敢被检验决定。**

**灵感 2（主动交互 → 解释的实验室，而不只是消歧的工具）**
直觉：R69 的信息动作是为「选出正确模态」服务的；但同一批动作（看、问、触、等）也可以为「检验我的解释是否为真」服务。二者目标不同、最优动作也不同：当模型其实**选错了模态**时，继续问「左还是右」只会强化错误先验；而问一个只有「解释为真」才成立的问题（「你左边看到的是门还是窗？」），才能在错的时候暴露错。于是 **VoI 有了第二个版本——证伪 VoI（value of falsification）**：选那个最能区分「我的解释真/假」的动作，而不是最能抬高我自信的动作。这把主动交互从「收集支持证据」改造成「主动寻找反例」。

**灵感 3（双向解释 → 言语会撒谎，示范不会免费撒谎）**
直觉：R69 会「问」，但人类回答是廉价的——可以撒谎、可以敷衍、可以被社交工程诱导。可解释性不只是系统向人解释，也包括**请人解释人自己**：与其问「是开心还是紧张」，不如说「请你在同样的处境下做一遍给我看」。示范（demonstration）与反事实选择（「如果刚才那杯是烫的，你还会递吗？」）要付出真实的行动/认知成本，因此比口头回答更难伪造，是更可信的因果证据。**把「问答」升级为「示范查询」，是 R70 对 R69「被证实的错误」最直接的反制。**

**灵感 4（标定 → 解释也会过时，需要解释校准与漂移检测）**
直觉：R69 已经懂得给传感器残差做标定；但解释从未被标定。一个在模型 v1 上忠实的解释，在 v2 上可能只是巧合；一个在训练分布内成立的「因为」，到了 OOD 就变成编造。因此必须像给概率做 ECE 一样给解释做校准：记录「解释→预测→观测」的账本，估计**解释校准误差 ECE_expl**与**反事实忠实度**的时间漂移；过时/漂移的解释强制失效，不得再换取任何「resolution bonus」。**没有时效性的解释，就是陈旧的借口。**

**灵感 5（双刃剑 → 可解释性本身是新的攻击面）**
直觉：让系统解释，等于给它一个「用流畅叙事掩盖错误」的通道（post-hoc rationalization）；让人反驳，等于给攻击者一个「用看似合理的质疑拖垮系统」的通道（contestation flooding）；把解释给出去，还可能泄露隐私与攻击面。更隐蔽的是**自证循环**：用同一个模型生成解释、又用同一个模型回放验证忠实度，得到的只是**自洽**，不是**正确**。所以 R70 必须同时交付：解释门（未校准不得生效）、质疑仲裁（k 源一致才可翻转）、最小披露（只暴露证伪所需的最小证据）、以及**独立审计通道**（用外部探针/集成打破自证循环）。

## 1. 形式化定义（增量：定义 310–326）

**定义 310（ECHO-RAS 总览）** ECHO-RAS = (ECG, CFX, FAP, HCR, XLL, FD, XG, EDR, RAS-WM‡)。三不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **解释不得削弱安全**：解释层的任何输出只能**保持或收紧** R69 的风险参数，且**不得新增** R69 本来不给的 resolution bonus；解释的作用是「为已有的宽松资格付费」，不是「为新的冒险背书」；
(iii) **可证伪性纪律**：不可证伪、未校准、过期或质疑未决的解释，不得作为证据定案，不得触发 bonus，只可写入日志。

**定义 311（解释契约 Explanation Contract）** 对任意决策 d ∈ {选中的模态 m, 风险缩放 λ, 前缀长度 k, 交互 g}，契约
e = (d, S, x_ref, Δ_pred, g_test, y_pred, F_e, τ_e, c_e)，
其中 S ⊆ 证据/模态/条件为**被引用的原因集**；x_ref 为对照干预（如 do(S := ∅)）；Δ_pred 为对照下决策变化的预测（反事实断言）；g_test ∈ 𝒜_info 为验证动作（复用 R69 定义 294 的看/问/触/等，并新增示范查询）；y_pred 为 g_test 下的预期观测；F_e 为**证伪观测集**（命中即判契约假）；τ_e 为有效窗口；c_e 为契约的认知/社交成本。自然语言渲染由冻结 LLM 从 e 解码，**不得引入 e 之外的新语义**（渲染是投影，不是创作）。

**定义 312（反事实忠实度 CFX）** 定义
faithfulness(e) = P_{o∼D_cal}[ d(o) ≠ d(do(S:=x_ref; o)) ]，
由**模型回放**（in-silico，精确、无真实世界成本）估计；要求 ≥ δ_f。注意：它陈述的是「模型机制」而非「世界真相」——这正是其力量（便宜、可穷举）与盲点（自洽≠正确，见定义 322）。

**定义 313（预测有效性 / 解释校准）** 对已执行契约，命中率
pred_valid(e) = P[y_obs ∈ y_pred | g_test 已执行]；
在账本上按置信分箱统计得**解释校准误差 ECE_expl**。ECE_expl > τ_expl ⇒ 该契约生成器被判定为「会编故事」，禁用其一切 bonus 资格。

**定义 314（证伪 VoI 与主动实验 FAP）** 设二元假设 H =「契约 e 为真」。候选测试动作 g ∈ 𝒜_info，定义
VF(g) = H(H|o) − E_{y∼p(·|g,o)}[H(H|o,y)]，
即 g 对**真伪判别**的信息增益。选 g* = argmax_g [VF(g) − c(g)]，s.t. R69 交互预算与 C-RAS-WM 认证。若 max[VF−c] ≤ 0：不测试，契约转「未验证」并按定义 317 计债。**与 R69 的关键区别：R69 最大化 I(M;y)，R70 最大化 I(H;y)；当先验押在错误模态上时，后者才会去问「能拆穿我」的问题。**

**定义 315（双向解释与示范查询 HCR）** 证据统一为 e_i = (source, content, cost_i, reliability_i)。除言语回答外，允许**示范查询** g_demo：请求人类在（可为反事实的）情境中给出动作示范。因示范需付出行动成本，其可靠性权重高于同源言语。人类对系统解释的反驳被解析为**结构化反契约** e′ = (¬d, S′, x_ref′, g_test′, y_pred′, F_{e′})，作为一条新证据进入更新，而**不直接采纳**。

**定义 316（解释账本 XLL）** 追加记录 (e, g_test, y_obs, outcome, timestamp, model_ver, context_hash)。用途：(a) 估计 ECE_expl；(b) 检测解释漂移（模型/环境变化后 faithfulness、pred_valid 下降）；(c) 提供人类可查的审计链。账本只追加、不原地改写。

**定义 317（证伪债与信任预算 FD）** 未验证契约承担
debt(e) = w₁(1 − faithfulness) + w₂·ECE_expl + w₃·age(e)/τ_e + w₄·contest_pending，
债 > τ_debt ⇒ 该解释不得支撑任何 bonus，系统等价走 R69「未消解」路径。**解释越流畅但越未验证，债越高**——这是对抗「合理化攻击」的核心定价。

**定义 318（最小披露与解释脱敏 EDR）** 对外解释须过最小披露过滤：只暴露证伪所需的最小证据，隐藏隐私、传感器指纹、精确探针力值等可被利用的信息；脱敏不得破坏 F_e 的可检验性（脱敏后仍须能判真伪），否则该解释降级为「不可证伪」。

**定义 319（解释投毒与合理化攻击 ℰ_expl）** 威胁集：模型后验合理化（解释与机制解耦）、人类用看似合理的解释反向操纵、解释注入（prompt injection 篡改 LLM 渲染）、示范投毒、质疑洪水（contestation flooding）、解释侧信道泄露。并入 AIC：ℰ_ECHO = ℰ_FLUID × ℰ_expl。

**定义 320（解释门 XG）** 只有当
faithfulness ≥ δ_f ∧ ECE_expl ≤ τ_expl ∧ debt(e) ≤ τ_debt ∧ confirmed(e)
四者同时成立，契约才「生效」，可用于：选择/触发测试、授予 resolution bonus、向人类定案。否则解释仅作日志，系统逐指令退化到 R69。

**定义 321（含解释的证书 J_ECHO）** J_ECHO = (J_FLUID, faithfulness_p05, ECE_expl, debt_mean, vf_ratio, test_count, contestation_quorum, explanation_log_hash, echo_ver)。Valid ⇔ Valid(J_FLUID) ∧ XG 生效纪律满足 ∧ 交互/解释预算未越界 ∧ 脱敏审计通过。

**定义 322（解释-测试对偶）** 解释对「模型机制」给出可由回放检验的反事实断言，测试对「世界/人类」给出真实观测；二者联合分布可分离两类失败：
(a) **合理化**：in-silico 忠实度高、但测试持续证伪（模型自洽于错误先验）；
(b) **世界漂移**：in-silico 忠实、测试也一度成立、随后 pred_valid 骤降（环境变了）。
这是 R69 (r_res, Δa) 对偶在解释层的镜像；也是**打破自证循环的操作化判据**——不能只看回放，必须看回放与真实测试的**不一致**。

**定义 323（质疑仲裁与 k-一致）** 人类质疑/反契约需 ≥ k_c 个**正交**证据源一致（如言语 + 示范 + 旁观者，R69 定义 293-iii）才可翻转解释结论；单次质疑只降低置信、追加 debt，不直接定案。防止「会哭的孩子有奶吃」式操纵。

**定义 324（时效与跨版本失效）** 契约有效窗口 τ_e；超时未测则 age 项计债；跨模型版本强制失效（解释漂移），必须重新回放与重新校准。

**定义 325（解释动作语义）** 向人类呈现契约本身是一个信息动作 g_expl，受 R69 预算与 C-RAS-WM 认证；解释**异步、可丢弃**，绝不阻塞安全动作；在实时环路上解释路径为零阻塞（zero-blocking）。

**定义 326（严格包含与降级链）** 当解释门关闭、预算耗尽、被投毒、质疑未决、契约过期、或脱敏破坏可证伪性 ⇒ 逐指令退化为 FLUID-RAS（R69），再退化为 CALM-RAS（R68）。安全侧单调不弱；效率侧的 bonus 仅在「R69 已给资格 ∧ R70 解释已验证」时授予。

## 2. 关键算法骨架

```python
# IP-264 ECG：解释契约生成（复用 R69 的 z_t 与模态，不新增主干）
class ExplanationContractGenerator:
    def build(self, decision, z, modes, evidence):
        S      = self.reason_set(decision, z, modes)        # 被引用的原因集（稀疏）
        x_ref  = self.counterfactual_ref(S)                 # do(S := ∅)
        d_ref  = self.replay_decision(z, x_ref)             # 反事实预测
        g_test = self.cheapest_test(S, modes)               # 初始候选，FAP 会改选
        y_pred = self.predict_observation(g_test, S)
        F_e    = self.falsifier_set(decision, S, g_test)    # 命中即判假
        return Contract(decision, S, x_ref, d_ref, g_test, y_pred, F_e,
                        tau=TAU_E, cost=self.cost(S, g_test))

# IP-265 CFX：反事实忠实度（in-silico 回放，精确且零真实成本）
def faithfulness(contract, fluid_policy, calib_obs):
    flips = sum(
        decide(fluid_policy, o) != decide_counterfactual(fluid_policy, o, contract.S, contract.x_ref)
        for o in calib_obs)
    return flips / len(calib_obs)                            # 机制自洽，非世界真相

# IP-266 FAP：证伪 VoI 选测试（与 R69 的 MINT 目标不同）
def choose_falsifying_test(contract, o_t, budget):
    best = None
    for g in info_action_candidates(contract):               # 看/问/触/等/示范
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t):
            continue
        vf = entropy(contract.truth_prior) - expected_entropy(contract.truth_prior, g, o_t)
        score = vf - contract_cost(g)                        # 可含社交/认知成本
        if best is None or score > best.score:
            best = (g, score)
    return best if best and best.score > 0 else None         # 无利可图 → 不测，计债

# IP-267 HCR：双向解释（言语 / 示范 / 反驳）→ 结构化证据
def resolve(contract, answer, source):
    if is_demonstration(answer):
        ev = Evidence(source="demo", content=answer, cost=answer.cost, reliability=W_DEMO)
    elif is_contestation(answer):
        ev = parse_counter_contract(answer)                  # 反契约，不直接采纳
    else:
        ev = Evidence(source=source, content=answer, cost=0, reliability=W_VERBAL)
    return bayes_update(contract, ev, discipline="k_orthogonal_agree")

# IP-270 XG：解释门（四条件；任一不满足即 R69 退化）
def explanation_gate(contract, f, ece_expl, debt, confirmed):
    if f < DELTA_F or ece_expl > TAU_EXPL or debt > TAU_DEBT or not confirmed:
        return False
    return True

# IP-274 主闭环（先跑 R69，再用解释层「付费」而非「冒险」）
def ECHO_RAS_round(M, obs):
    # 1) R69 原样给出安全决策（不变式 ii：解释层不改安全输出）
    k, lam, mode, (U_ale, U_epi) = M.fluid.round(obs)
    # 2) 为已做决策生成解释契约（低成本、可异步）
    e = M.ecg.build(decision=(mode, lam, k), z=M.z, modes=M.modes, evidence=M.ev)
    # 3) 机制自洽性回放 + 记入账本；不忠实 → 只记日志
    f = M.cfx.faithfulness(e, M.fluid, M.calib_obs)
    M.xll.log(e, f)
    # 4) 解释门：未校准/高债/过期/未证实 → 逐指令退回 R69
    if not M.xg.explanation_gate(e, f, M.xll.ece_expl(), M.fd.debt(e), e.confirmed):
        return k, lam, mode, "R69-identical"
    # 5) 若预算允许，选「最能证伪自己」的主动交互
    g = M.fap.choose_falsifying_test(e, obs, M.budget)
    if g is not None:
        ans = M.cia.execute(g)                               # 看/问/触/示范查询，带认证
        e2  = M.hcr.resolve(e, ans, source=M.cia.last_source)
        M.xll.record_outcome(e, g, ans)                      # 更新 ECE_expl / pred_valid
        # 6) bonus 仍受 R69 资格 + 验证 + 质疑仲裁三重约束（不新增冒险）
        if M.xg.explanation_gate(e2, f, M.xll.ece_expl(), M.fd.debt(e2), e2.confirmed) \
           and M.hcr.quorum(e2):
            M.fluid.grant_resolution_bonus(U_epi)            # 只解锁 R69 本可给的 bonus
    else:
        M.fd.charge(e)                                       # 未测试 → 证伪债
    # 7) 对外解释走最小披露 + 异步，零阻塞、可丢弃
    M.edr.publish_async(M.edr.redact(e), lane="safe")
    return k, lam, mode, e
```

## 3. 推导

**引理 19（反事实忠实度可回放）** 对确定性/固定随机种子的策略 d，faithfulness(e) 可由模型回放**精确**估计（误差仅来自数值与采样种子），无需真实世界查询。因此「解释是否忠实于模型机制」是一个**廉价可判**性质——但注意它**不**推出「解释是否忠实于世界」；后者必须由定义 313 的真实测试与定义 322 的对偶判据承担。

**引理 20（证伪测试的样本复杂度）** 设契约若为假，任一独立测试以概率 p 命中证伪集 F_e；则执行 n 次独立测试后，假契约仍未被拆穿的概率 ≤ (1−p)^n。故达到置信 1−ε 所需测试数 n ≤ log(1/ε)/p（系：p 越大、Δ_min 越可分、越该测；p→0 的不可分情形应立即计债而非浪费预算）。**关键推论**：当 R69 的先验把大部分质量压在错误模态上时，I(M;y) 会被错误先验拉偏，而 VF(g)=I(H;y) 仍能选中拆穿性测试——这是 R70 相对 R69 在「问错」场景下的可证明优势。

**引理 21（证伪债与信任泄漏上界）** 若只对 debt ≤ τ_debt 的契约授予 bonus，则单位时间内因「未验证解释」导致的错误放宽期望 ≤ τ_debt × N_bonus；取 τ_debt 为 R69 中 U_epi 已消解却仍被误判的基准率，则 R70 的额外放宽为 0。故**解释层不能凭空制造宽松**，只能把 R69 已有的「可放宽资格」以可验证方式兑现。

**定理 18（ECHO 严格包含 FLUID-RAS，且在忠实解释下占优）** 在 A95–A97 与 A99（契约可真伪、测试条件独立、解释生成与验证不共享同一错误先验的上界 ρ_c<1）下：
(a) **安全侧**：对任意状态，R70 的期望风险 ≤ R69，因为 bonus 需 R69 资格 ∧ XG ∧ 仲裁三重门，且 λ 与 k 只被保持或收紧；
(b) **逐指令退化**：XG 关闭 / debt>τ_debt / ECE_expl>τ_expl / ECE_expl 不可得 / 预算耗尽 / 契约过期 ⇒ 输出与 R69 **逐指令相同**；
(c) **效率侧**：当解释 δ_f-忠实且 FAP 采用 VF 时，期望消解率 ≥ R69，故期望任务成本 ≤ R69（不牺牲安全地收获「更会问」带来的 bonus）。因此 R69 是 R70 在「永不自证」边界上的严格退化，R68 再是其退化。

**定理 19（解释安全、最小披露与无突变）** 解释在独立异步通道执行且可丢弃（定义 325），故不增加控制环路阻塞；信息动作 g 仍由 C-RAS-WM 认证（定义 302），物理风险 ≤ ε_int；最小披露（定义 318）保证对外信息量不超过证伪所需，侧信道泄露上界由脱敏预算控制；解释失败/超时/被投毒时 λ 单调不降、bonus 不授予，退化为 R69 ⇒ 控制连续、无突变，换装不变式（R68 定理 15）保持。

# IP-264 ECG：把已做决策转成可证伪契约（复用 R69 的 z_t，不新增主干）
class ExplanationContractGenerator:
    def build(self, decision, z, modes, evidence):
        S      = self.reason_set(decision, z, modes)
        x_ref  = self.counterfactual_ref(S)                 # do(S := ∅)
        d_ref  = self.replay_decision(z, x_ref)
        g_test = self.cheapest_test(S, modes)               # FAP 会改选
        return Contract(decision, S, x_ref, d_ref, g_test,
                        self.predict_observation(g_test, S),
                        self.falsifier_set(decision, S, g_test),
                        tau=TAU_E, cost=self.cost(S, g_test))

# IP-265 CFX：in-silico 反事实忠实度（精确，零真实成本）
def faithfulness(c, fluid, calib_obs):
    return sum(decide(fluid, o) != decide_counterfactual(fluid, o, c.S, c.x_ref)
               for o in calib_obs) / len(calib_obs)        # 自洽≠正确

# IP-266 FAP：证伪 VoI 选测试（目标与 R69 的 MINT 不同）
def choose_falsifying_test(c, o_t, budget):
    best = None
    for g in info_action_candidates(c):                     # 看/问/触/等/示范
        if not budget.allow(g) or not c_ras_wm.certify_info(g, o_t): continue
        score = (entropy(c.truth_prior) - expected_entropy(c.truth_prior, g, o_t)) - cost(g)
        if best is None or score > best.score: best = (g, score)
    return best if best and best.score > 0 else None        # 不测 → 计债

# IP-267 HCR：双向解释（言语 / 示范 / 反驳）
def resolve(c, answer, source):
    if is_demonstration(answer):
        ev = Evidence("demo", answer, answer.cost, W_DEMO)
    elif is_contestation(answer):
        ev = parse_counter_contract(answer)                 # 反契约，不直接采纳
    else:
        ev = Evidence(source, answer, 0, W_VERBAL)
    return bayes_update(c, ev, discipline="k_orthogonal_agree")

# IP-270 XG：解释生效门（任一不满足即 R69 退化）
def explanation_gate(c, f, ece, debt, confirmed):
    return f >= DELTA_F and ece <= TAU_EXPL and debt <= TAU_DEBT and confirmed

# IP-274 主闭环：R69 先出安全决策，解释层只「付费」不「冒险」
def ECHO_RAS_round(M, obs):
    k, lam, mode, (U_ale, U_epi) = M.fluid.round(obs)       # R69 原样
    e = M.ecg.build((mode, lam, k), M.z, M.modes, M.ev)
    f = M.cfx.faithfulness(e, M.fluid, M.calib_obs)
    M.xll.log(e, f)
    if not M.xg.explanation_gate(e, f, M.xll.ece_expl(), M.fd.debt(e), e.confirmed):
        return k, lam, mode, "R69-identical"                # 逐指令退化
    g = M.fap.choose_falsifying_test(e, obs, M.budget)
    if g is not None:
        ans = M.cia.execute(g)                              # 看/问/触/示范，带认证
        e2  = M.hcr.resolve(e, ans, M.cia.last_source)
        M.xll.record_outcome(e, g, ans)
        if M.xg.explanation_gate(e2, f, M.xll.ece_expl(), M.fd.debt(e2), e2.confirmed) \
           and M.hcr.quorum(e2):
            M.fluid.grant_resolution_bonus(U_epi)           # 只解锁 R69 本可给的 bonus
    else:
        M.fd.charge(e)
    M.edr.publish_async(M.edr.redact(e), lane="safe")       # 异步、零阻塞、可丢弃
    return k, lam, mode, e

## 4. 推导

**引理 19（反事实忠实度可回放）** 对固定种子策略，`faithfulness(e)` 可由模型回放精确估计（误差仅数值/种子），无需真实世界查询。故「解释是否忠实于模型机制」廉价可判；但**不**推出「忠实于世界」（后者由定义 313 与 322 承担）。

**引理 20（证伪测试样本复杂度）** 假契约单次测试命中证伪集概率 p，则 n 次独立测试后仍未被拆穿概率 ≤ `(1−p)^n`；达 1−ε 置信需 `n ≤ log(1/ε)/p`。系：错误先验下 `I(M;y)` 被拉偏，而 `VF(g)=I(H;y)` 仍选拆穿性测试——R70「更会问」的可证明来源。

**引理 21（证伪债与信任泄漏上界）** 仅对 `debt ≤ τ_debt` 授予 bonus ⇒ 未验证解释导致的错误放宽期望 ≤ `τ_debt·N_bonus`；故解释层不凭空制造宽松，只把 R69 已有资格可验证地兑现。

**定理 18（ECHO 严格包含 FLUID-RAS，且忠实解释下占优）** A95–A97 + A99（契约可证伪、测试条件独立、生成/验证错误先验相关 ρ_c<1）下：
(a) 安全侧期望风险 ≤ R69（bonus 需 R69 资格 ∧ XG ∧ 仲裁三重门，λ/k 只保持或收紧）；
(b) `XG` 关闭 / `debt>τ_debt` / `ECE_expl>τ_expl` / 预算耗尽 / 契约过期 ⇒ 与 R69 **逐指令相同**；
(c) 解释 δ_f-忠实且 FAP 用 VF 时，期望消解率 ≥ R69，故期望任务成本 ≤ R69（不牺牲安全地获得「更会问」的 bonus）。R69 = 「永不自证」边界的退化，R68 再退化。

**定理 19（解释安全、最小披露与无突变）** 解释在独立异步可丢弃通道执行 ⇒ 不阻塞控制环；信息动作仍过 C-RAS-WM（物理风险 ≤ ε_int）；最小披露限制对外信息量、控制侧信道上界；失败/超时/投毒时 λ 单调不降、bonus 不授予 ⇒ 控制连续无突变，换装不变式（R68 定理 15）保持。

## 7. 本轮最大风险

**一句话**：ECHO-RAS 的全部信任押在「解释可被独立检验」上，而最廉价的检验——反事实回放——用的是**同一个模型**：当解释生成与忠实度验证共享同一套错误先验时，系统只能证明「我自洽」，不能证明「我正确」；此时流畅、忠实、被人类点头的解释，恰恰可能是一套把系统性错误包装成「已验证真相」的完美叙事——**自证越漂亮，越危险。**

**次级风险与缓解**：自证循环（定义 322 对偶判据 + 独立探针/集成审计 + E312）；合理化攻击（CFX + ECE_expl + 证伪债定价 + E307）；解释注入/侧信道（冻结 LLM 渲染只做投影 + 最小披露 + E311）；质疑洪水（k-正交一致仲裁 + debt 不直接翻转 + E306）；实时预算（解释全异步零阻塞 + 批量回放 + E314）。
