# 第 55 轮（承接第 54 轮 v16 GroundEdge-GenSim+++；灵感循环第 6 轮/新周期第 1 轮；本轮灵感：「视觉-语言-动作模型」×「轻量化结构」）

> 第 54 轮把技能组合建立在动作空间剖面 α_S、组合图 G_S 与云边联合证书 J 上。本轮引入 **视觉-语言-动作模型（VLA）作为技能的动作生成器**，以及 **轻量化结构作为边端部署的一等变量**。核心矛盾：H22：轻量化在平均动作保真度上通过，却在尾部动作空间改变 α_S，使既有组合证书在压缩后失效（**证书-压缩不相容**）；H23：云端完整 VLA 与边端轻量 VLA 的语义接地-动作映射不一致，静态 γ_ce 无法覆盖状态/指令依赖的漂移（**静态对齐失效**）。

## 0. 直觉与动机

**灵感 1（VLA 不是技能，而是动作剖面的生成器）**
直觉：第 54 轮把技能 S 看成动作剖面 α_S，但 α_S 从哪来？真实的来源是 VLA 策略 π_θ(a|v,l)：视觉 v 与语言指令 l 进入网络，动作分布出来。于是技能剖面不是静态表，而是
`α_{S,θ}(a) = E_{(v,l)~D_S}[π_θ(a|v,l)]`。
技能组合的第一性问题因此从“两个剖面是否相交”变成：**当生成器被替换或被压缩成 π_{θ,ς} 后，α_S 还成立吗？** 这把“技能”从能力清单升级为“策略 + 分布”的可迁移对象。

**灵感 2（轻量化结构是动作空间的形变，不是单纯的加速）**
直觉：剪枝、量化、蒸馏、MoE 路由、早退，表面是延迟/显存优化，实质是在参数空间做扰动 θ→θ_ς，并在动作空间诱导一个**分布形变** `D_A(π_θ,π_{θ,ς})`。若只盯平均成功率，尾部动作（罕见但关键的操作）会先崩塌：平均 KL 很小，尾部 Wasserstein 却可以很大。因此定义 **结构条件动作剖面 α_S(a|ς)**，并把结构 ς 作为组合规划的显式决策变量——不是“先压缩再验证”，而是**在证书约束下选择结构**。

**灵感 3（语义-动作锚点 → 让轻量化模型“携带证书”）**
直觉：VLA 的脆弱点在语义接地：同一句“把杯子挪到桌沿”在不同视角下可能对应不同动作。轻量化最容易破坏长尾接地。于是引入 **锚点集 𝒜 = {(v_i,l_i,a_i,ε_i)}**：一小撮（视觉、语言、动作）三元组，作为不可漂移的语义-动作枢轴。蒸馏/量化不仅拟合教师动作分布，还必须保持锚点动作；证书随权重一起分发，形成 **anchor-carrying 轻量化**。这样压缩后仍可判定 α_S 与组合兼容性。

**灵感 4（云边 VLA 协同 → 用云端做动作空间锚验证，而非只给粗动作）**
直觉：第 54 轮的 γ_ce 把云端粗动作映射到边端细动作。VLA 时代更自然的是：边端轻量 VLA **推测式生成动作**，云端完整 VLA 做**异步锚验证**（类似 speculative decoding，但被解码的是动作轨迹而非 token）。云端不必逐帧下发，只需在锚点邻域与高分歧区间做校正，回传**动作残差通道**。这把云边协同从“粗-细映射”升级为“提议-验证-残差回传”的动作级闭环。

**灵感 5（结构-保真 Pareto 前沿 + 证书迁移）**
直觉：轻量化不是单点，而是一条 Pareto 前沿：延迟 ℓ(ς)、显存 m(ς)、动作保真 φ(ς)、尾部漂移 D_A^tail(ς)。组合规划应在前沿上选点：在满足 ρ_ς≥ρ_min、compat_ς≥θ_a 与锚点保真的可行域内最小化 ℓ。更进一步，第 54 轮的 α_S、ρ、C_comp 可由**证书迁移算子 T_{ς→ς'}** 沿结构变化传播，并给出可证明的漂移上界，而不是每次从零重验。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（VLA 策略与技能动作剖面）**
VLA 策略 `π_θ: V×L → Δ(A)`，`π_θ(a|v,l)` 为动作分布。技能 S 在数据分布 D_S 上的动作剖面
`α_{S,θ}(a) = E_{(v,l)~D_S}[π_θ(a|v,l)]`，
动作覆盖 `cover_θ(S,A_T)=1 ⇔ ∀a∈A_T, α_{S,θ}(a) ≥ θ_cov`。

**定义 122（轻量化结构算子）**
结构描述子 `ς = (w,d,b,s,r,e)`，分别表示宽度、深度、位宽、稀疏度、MoE 路由、早退阈值。压缩算子 `C_ς: Θ→Θ_ς`，`π_{θ,ς}=C_ς(π_θ)`。结构代价 `c(ς)=(ℓ(ς),m(ς))`，可行域 `Σ_adm = {ς | ℓ(ς)≤τ_e, m(ς)≤M_e}`。

**定义 123（动作漂移与尾部漂移）**
动作漂移 `D_A(π,π') = sup_{(v,l)∈V×L} W_2(π(·|v,l), π'(·|v,l))`。给定分位 q，尾部漂移
`D_A^tail(π,π') = sup_{(v,l)∈Tail_q(D_S)} W_2(π(·|v,l), π'(·|v,l))`，
其中 Tail_q(D_S) 为 D_S 中动作密度最低的 q 分位样本集。**动作崩塌**：`D_A ≤ Θ_A` 但 `D_A^tail > Θ_tail`。

**定义 124（语义-动作锚点证书）**
锚点集 `𝒜 = {(v_i,l_i,a_i,ε_i)}_{i=1}^m`，锚点保真
`φ(π,𝒜) = max_i E_{a~π(·|v_i,l_i)}[d(a,a_i)]`。
若 `φ(π,𝒜) ≤ ε_max`，称 π **锚点保真**；锚点证书 `A_anchor = (𝒜, ε_max, coverage)`。

**定义 125（结构条件动作剖面与兼容性）**
`α_S(a|ς) = α_{S,θ_ς}(a)`，`A_i^ς = {a | α_{S_i}(a|ς) ≥ θ_cov}`，
`compat_ς(S_i,S_j) = |A_i^ς ∩ A_j^ς| / |A_i^ς ∪ A_j^ς|`。
组合在结构 ς 下可行当且仅当
```
compat_ς(S_i,S_j) ≥ θ_a ∧ c_trans(A_i^ς,A_j^ς) ≤ τ_e
∧ ρ_ς ≥ ρ_min ∧ φ(π_{θ,ς},𝒜) ≤ ε_max ∧ D_A^tail ≤ Θ_tail
```

**定义 126（结构感知联合证书与证书迁移算子）**
结构感知联合证书
`J_ς = (ρ_ς, α_{S,ς}, A_cert, γ_ce, δ_a, A_anchor, D_A^tail, evidence)`，
其中 `ρ_ς` 为压缩后鲁棒性谱、`α_{S,ς}` 为结构条件剖面、`A_cert` 为第 54 轮动作占用证书、`A_anchor` 为锚点证书、`D_A^tail` 为尾漂移上界。证书迁移算子 `T_{ς→ς'}: J_ς ↦ J_{ς'}` 满足
`||J_{ς'} − J_ς|| ≤ L_J · ||ς' − ς||`。
若 `dom_{J_ς}(T)=in ∧ δ_a<Θ_a ∧ φ≤ε_max ∧ D_A^tail≤Θ_tail`，则 `(S,ς)` 可部署。

## 2. 关键算法 伪代码

### IP-121 VPA（VLA Policy Action-profile）

```python
def vla_action_profile(pi_theta, D_S, A_grid, q=0.1):
    alpha = {a: 0.0 for a in A_grid}
    densities = []
    for (v, l) in D_S:
        dist = pi_theta.action_dist(v, l)
        for a in A_grid:
            alpha[a] += dist.prob(a) / len(D_S)
        densities.append(dist.entropy())
    order = argsort(densities)            # 低密度/低熵近似尾部
    tail = [D_S[i] for i in order[:max(1, int(q * len(D_S)))]]
    return alpha, tail
```

### IP-122 LSA（Lightweight Structure Adaptation）

```python
def select_structure(pi_theta, Sigma, D_S, anchors, budgets):
    front = pareto_front([(s, latency(s), memory(s)) for s in Sigma])
    feasible = []
    for s in front:
        if latency(s) > budgets.tau_e or memory(s) > budgets.M_e:
            continue
        pi_s = compress(pi_theta, s)
        phi = anchor_fidelity(pi_s, anchors)
        if phi > budgets.eps_max:
            continue
        alpha_s, tail = vla_action_profile(pi_s, D_S, A_grid)
        drift_tail = tail_drift(pi_theta, pi_s, tail)
        if drift_tail > budgets.theta_tail:
            continue
        feasible.append((s, alpha_s, drift_tail, phi))
    return argmin(feasible, key=lambda x: latency(x[0]))   # 证书约束下最小延迟
```

### IP-123 ACA（Anchor-Carrying Adaptation）

```python
def anchor_carrying_distill(teacher, student, D_S, anchors, lam=0.5):
    for batch in D_S:
        with no_grad():
            t_dist = teacher.action_dist(batch)
        s_dist = student.action_dist(batch)
        loss = kl(t_dist, s_dist) + lam * anchor_loss(student, anchors)
        update(student, loss)
    cert = A_anchor(anchors, eps_max=anchor_fidelity(student, anchors))
    return student, cert

def anchor_loss(student, anchors):
    return mean(E_{a ~ student.action_dist(v_i, l_i)}[d(a, a_i)]
                for (v_i, l_i, a_i, _) in anchors)
```

### IP-124 SEC（Speculative Edge-Cloud VLA co-inference）

```python
def speculative_vla_act(pi_edge, pi_cloud, obs, instr, anchor_bank, tau_loop):
    a0 = pi_edge.act(obs, instr)                  # 边端快速提议
    if anchor_bank.covers(obs, instr):            # 命中锚点邻域，直接信任
        return a0, AnchorCert()
    a_ref, conf = pi_cloud.verify(obs, instr, a0, deadline=tau_loop)
    if conf < theta_conf:
        r = residual(a_ref, a0)                   # 云端回传动作残差
        return correct(a0, r), ResidualCert(r)
    return a0, TentativeCert()
```

### IP-125 STA（Structure Transport of Certificates）

```python
def transport_certificate(J_src, s_src, s_dst, L_J, margin=0.1):
    d_sigma = structure_distance(s_src, s_dst)
    drift_bound = L_J * d_sigma
    J_dst = update(J_src, structure=s_dst, drift_bound=drift_bound)
    if drift_bound > (1 - margin) * J_src.budget:
        return ('recheck', J_dst)                 # 超出迁移预算，要求全量重验
    return ('ok', J_dst)
```

### IP-126 SJC（Structure-aware Joint Certificate）

```python
def structure_joint_certificate(skill_seq, s, pi_theta, anchors, budgets):
    pi_s = compress(pi_theta, s)
    A_anchor = anchor_fidelity(pi_s, anchors)
    if A_anchor > budgets.eps_max:
        return ('reject', 'anchor_drift', A_anchor)
    alpha = {sk: vla_action_profile(pi_s, D_sk, A_grid)[0] for sk in skill_seq}
    compat = min(jaccard(alpha[a], alpha[b]) for a, b in adjacent(skill_seq))
    if compat < budgets.theta_a:
        return ('reject', 'compat_fail', compat)
    rho_s = compose_robustness_chain([sk.rho for sk in skill_seq])
    tail = tail_drift(pi_theta, pi_s, tail_samples(D_S))
    if tail > budgets.theta_tail or min(rho_s.values()) < budgets.rho_min:
        return ('reject', 'tail_or_rho', tail, rho_s)
    return ('ok', J_sigma(rho_s, alpha, A_anchor, tail, s))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| VPA | O(N·\|A\|) | O(\|A\|) | 采样覆盖、尾部样本可识别 |
| LSA | O(\|Σ\|·N·\|A\|) | O(\|Σ\|·\|A\|) | Pareto 前沿完整、约束判定 sound |
| ACA | O(N·\|A\|·m)/epoch | O(\|A\|+m) | 锚点保真、蒸馏 KL 有界 |
| SEC | O(\|V\| log \|V\| + τ_loop) | O(\|V\|) | 残差有界、延迟闭合 |
| STA | O(\|J\|) | O(\|J\|) | Lipschitz 迁移上界成立 |
| SJC | O(\|S\|·\|A\|) | O(\|A\|) | 联合约束 sound、预算闭合 |

**正确性定理（Structure-Preserving VLA Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** π_θ 在参数扰动下 L_A-Lipschitz：`D_A(π_θ,π_{θ'}) ≤ L_A||θ−θ'||`；**(A30)** 压缩算子参数扰动有界 `||θ−θ_ς|| ≤ ε_ς`；**(A31)** 锚点集对尾部动作 (ε,δ)-覆盖：`φ≤ε_max ⇒ D_A^tail ≤ κ·φ`；**(A32)** 云端动作残差通道延迟 ≤ τ_loop 且残差有界 `||r||≤ρ_r`。
则结构 ς 下部署成功概率
```
P_success(ς) ≥ 1 − Σ_d (1−ρ_min(d)) − P(φ>ε_max)
                − P(D_A^tail>Θ_tail) − P(compat_ς<θ_a) − β_E·P(τ_loop miss)
```
关键：**先选结构、再发证书**；证书的 soundness 作用在“被压缩后的动作剖面”上，而不是教师模型的剖面上。

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| 结构 Pareto 前沿估计偏差，选到“账面可行”实则尾部崩塌的 ς | 高 | 尾部对抗采样 + 多随机种子前沿 + 尾部漂移硬闸 |
| 锚点集不具代表性，A_anchor 沦为“过拟合证书” | 高 | 覆盖度审计 + 主动锚点挖掘 + 红队指令 |
| 证书迁移 Lipschitz 常数 L_J 过松，迁移形同虚设 | 高 | 在线标定 L_J + 迁移后抽检 + 超预算强制重验 |
| 云端残差通道延迟抖动 | 中 | 异步验证 + 超时降级到保守动作 + hysteresis |
| VLA 动作分布多峰，W_2 估计方差大 | 中 | 分层采样 + 分位数自助法置信区间 |

## 6. 本轮最大风险

**一句话**：把 VLA 当作动作剖面生成器、把轻量化结构当作组合规划变量，使第 54 轮的证书第一次能“随压缩一起迁移”，但整套 soundness **同时押注在锚点集的代表性、尾部漂移的可估性、以及证书迁移 Lipschitz 常数的紧致性**上；一旦锚点只覆盖常见指令或 L_J 被低估，轻量模型会在尾部动作上静默崩塌，而 J_ς 仍报“可部署”——这正是最难发现的负迁移。故必须以**尾部硬闸 + 锚点覆盖审计 + 迁移后抽检**作为不可绕过的三重护栏，宁可牺牲一档压缩率，也不让“平均保真”冒充“证书保真”。

```python
        feasible.append((s, alpha_s, drift_tail, phi))
    return argmin(feasible, key=lambda x: latency(x[0]))
```

### IP-123 ACA

```python
def anchor_carrying_distill(teacher, student, D_S, anchors, lam=0.5):
    for batch in D_S:
        with no_grad():
            t_dist = teacher.action_dist(batch)
        s_dist = student.action_dist(batch)
        loss = kl(t_dist, s_dist) + lam * anchor_loss(student, anchors)
        update(student, loss)
    cert = A_anchor(anchors, eps_max=anchor_fidelity(student, anchors))
    return student, cert

def anchor_loss(student, anchors):
    return mean(E_{a ~ student.action_dist(v_i, l_i)}[d(a, a_i)]
                for (v_i, l_i, a_i, _) in anchors)
```

```python
def transport_certificate(J_src, s_src, s_dst, L_J, margin=0.1):
    d_sigma = structure_distance(s_src, s_dst)
    drift_bound = L_J * d_sigma
    J_dst = update(J_src, structure=s_dst, drift_bound=drift_bound)

    return ('ok', J_dst)
```

### IP-126 SJC

```python
def structure_joint_certificate(skill_seq, s, pi_theta, anchors, budgets):
    pi_s = compress(pi_theta, s)
    A_anchor = anchor_fidelity(pi_s, anchors)
    if A_anchor > budgets.eps_max:
        return ('reject', 'anchor_drift', A_anchor)
    alpha = {sk: vla_action_profile(pi_s, D_sk, A_grid)[0] for sk in skill_seq}
    compat = min(jaccard(alpha[a], alpha[b]) for a, b in adjacent(skill_seq))
    if compat < budgets.theta_a:
        return ('reject', 'compat_fail', compat)
    rho_s = compose_robustness_chain([sk.rho for sk in skill_seq])
    tail = tail_drift(pi_theta, pi_s, tail_samples(D_S))
    if tail > budgets.theta_tail or min(rho_s.values()) < budgets.rho_min:
        return ('reject', 'tail_or_rho', tail, rho_s)
    return ('ok', J_sigma(rho_s, alpha, A_anchor, tail, s))
```

## 3. 复杂度、推导与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| VPA | O(N·\|A\|) | O(\|A\|) | 采样覆盖 ≥ 95%，尾部可识别 |
| LSA | O(\|Σ\|·N·\|A\|) | O(\|Σ\|·\|A\|) | Pareto 前沿完整，约束判定 sound |
| ACA | O(N·\|A\|·m)/epoch | O(\|A\|+m) | 锚点保真，蒸馏 KL 有界 |
| SEC | O(\|V\| log \|V\| + τ_loop) | O(\|V\|) | 残差有界，延迟闭合 |
| STA | O(\|J\|) | O(\|J\|) | Lipschitz 迁移上界成立 |
| SJC | O(\|S\|·\|A\|) | O(\|A\|) | 联合约束 sound，δ_a 预算闭合 |

**命题 1（均值保真不蕴含尾部保真）**
设教师策略在尾部模式上携带 q 质量，压缩后该模式被并入主模态。则存在常数 `d_tail>0` 使 `D_A^tail ≥ (q/2)·d_tail`，而平均 KL 可任意小。故轻量化证书必须以尾部漂移为独立约束，不能用平均指标替代。

**命题 2（结构迁移的漂移上界）**
若 `J_{ς'}=T_{ς→ς'}(J_ς)` 且 `T` 关于结构描述子 L_J-Lipschitz，则
`||J_{ς'}−J_ς|| ≤ L_J·||ς'−ς||`。
当 `L_J·||ς'−ς|| > (1−margin)·budget` 时迁移不可信，必须回退到全量重验（STA 的 recheck 分支）。

**正确性定理（Structure-Preserving VLA Composition Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `D_A(π_θ,π_{θ'}) ≤ L_A||θ−θ'||`；**(A30)** `||θ−θ_ς|| ≤ ε_ς`；**(A31)** 锚点 (ε,δ)-覆盖：`φ≤ε_max ⇒ D_A^tail ≤ κ·φ`；**(A32)** 云端残差通道延迟 ≤ τ_loop 且 `||r||≤ρ_r`。
则
```
P_success(ς) ≥ 1 − Σ_d (1−ρ_min(d)) − P(φ>ε_max)
                − P(D_A^tail>Θ_tail) − P(compat_ς<θ_a) − β_E·P(τ_loop miss)
```
要点：**证书约束的是压缩后剖面 `α_{S,ς}`，不是教师剖面 `α_{S,θ}`**；结构选择发生在证书签发之前。

## 5. 本轮最大风险

**一句话**：把 VLA 当作动作剖面生成器、把轻量化结构当作组合规划变量，使第 54 轮的证书第一次能“随压缩一起迁移”，但整套 soundness **同时押注在锚点集的代表性、尾部漂移的可估性、以及证书迁移 Lipschitz 常数的紧致性**上；一旦锚点只覆盖常见指令或 L_J 被低估，轻量模型会在尾部动作上静默崩塌，而 J_ς 仍报“可部署”——这正是最难发现的负迁移。故必须以**尾部硬闸 + 锚点覆盖审计 + 迁移后抽检**作为不可绕过的三重护栏，宁可牺牲一档压缩率，也不让“平均保真”冒充“证书保真”。
