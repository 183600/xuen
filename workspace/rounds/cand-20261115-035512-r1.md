# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配多模态主动交互消歧」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「跌倒恢复」×「开源硬件」）

> R69 把不确定性拆成 aleatoric / epistemic，第一次让系统学会「问」。但它的整套 calculus 都站在一个没有写出来的前提上：**提问者还站着，而且提问者还是它自己**。它的所有信息动作（看/问/触）都在「未失效、未变形、可继续执行任务」的常态域内，所有证据都假设「回答者存在且身体不变」。一旦真的跌倒，这个前提同时碎掉三块：
> - **制度错位**：R68/R69 只有「预防」和「斟酌」两种逻辑，都默认失败尚未发生；而跌倒之后，目标不再是「避免失败」，而是「以最小的不可逆代价退出失败域」——有时**必须承担受控风险，才能降低总风险**。
> - **身体错位**：跌倒可能改变身体本身（连杆弯了、关节松了、模块脱了、摩擦变了）。R68 的标定只能吸收传感器偏置，吸收不了一根断掉的腿；R69 的流似然只能发现「行为不自洽」，说不出「哪里坏了」；而外部人**看不见你的齿轮箱**——这件事问也问不出来。
> - **身份错位**：开源硬件让身体成为一张可替换的物料清单——跌倒后可以换掉一个标准模块，也可能被别人换上一个「看起来一样」的模块。**「我还是不是我」于是成为一个需要证据、而不是需要假设的问题。**
>
> 本轮两个灵感正好补上这三块：
> - **跌倒恢复**给出第三种制度与一个漂亮的对偶：**跌倒是一场你不想要、但不能浪费的系统辨识实验**；而**起身的动作本身就是探针**——为了站起来，必须试探自己还能承受什么。
> - **开源硬件**给出身体的「户口」：签名 BOM、逐模块磨损/校准、固件哈希与来源链；同时它也降低了仿冒门槛——**原理图公开，不等于身份不可伪造**。溯源证明「我是正品」，物理一致性证明「我还能用」，二者缺一不可。
>
> 核心命题：**把不确定性从二维扩展到三维 (U_ale, U_epi, U_struct)；U_struct 是「哪一具身体 / 哪一个模型在起作用」的结构不确定性，它不能被外部提问消解，只能靠跌倒冲击、安全载荷探针、以及开源硬件的溯源-物理交叉检验来消解；恢复策略必须在「可信身体假设的行为等价类」上认证，并显式计入不作为危险率与不可逆预算。** 命名 **RISE-RAS**（Recovery-regime Identity-Shift Estimation for Resilient Autonomous Systems）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**跌倒之后，我还是原来那台机器吗；如果不是，我还剩什么、该先救哪一部分**」——不确定性不只是刹车踏板、一句提问，也可以是一次**试探性的起身**与一次**诚实的自我更换**。

## 0. 直觉与动机

**灵感 1（跌倒恢复 ≠ 更保守的预防：第三种制度）**
直觉：R68 的答案是「不确定就收紧」，R69 的答案是「可约就去问」。这两条都假设系统还在设计工作域内。跌倒之后，系统进入一个**非设计域**：姿态离开直立流形、执行器可能失效、接触拓扑改变、时间开始计费。此时「收紧」可能意味着永远躺着，「去问」可能意味着等人来扶——而躺着本身有危险率（二次损伤、环境暴露、通信中断、被踩踏）。恢复的目标函数因此不是「最小化动作风险」，而是 **最小化「动作风险 + 不作为风险 × 恢复时间 + 不可逆损伤」的期望总和**。这是与 R68/R69 完全不同的风险算术：**为了降低总风险，必须主动承担一段受控风险。**

**灵感 2（跌倒即辨识：一场不情愿但不可浪费的实验）**
直觉：系统辨识最贵的是激励。正常运行时你不敢给机器人足够大的激励去激发非线性与结构模态；而一次跌倒，恰好是一次**巨大的、宽带的、全身体的冲击激励**。冲击响应里编码了刚度、阻尼、间隙、松动、质量分布——只要在跌倒前后把高频本体感受、关节力矩、IMU 饱和、接触序列录下来，就拿到了一次**免费的（但代价惨痛的）模态实验**。所以 R70 的第一个反直觉结论是：**跌倒之后第一件该做的事不是立刻爬起来，而是先把这次跌倒「读完」**——判断这次冲击到底激发了哪些自由度、哪些损伤模式可辨识、哪些根本没说。把跌倒当噪声丢掉，是浪费了唯一一次真实的结构测试。

**灵感 3（开源硬件：身体是物料清单，不是常量）**
直觉：传统机器人学把 plant 当常量，坏了是「故障」，修是「维护」。开源硬件改变本体论：身体是 **BOM（物料清单）+ 装配公差 + 固件** 的一个具体实例，可以被 fork、被替换、被社区复现。于是「我的身体是什么」不再是不可知的形而上学，而是一个**可以被声明、被签名、被核验的构型**：这块舵机是哪一批、这个连杆的实测长度、这版固件的哈希、这个模块的磨损计数。R70 把「我是谁」变成一个带证书的工程问题。但也正因原理图公开，**仿冒者也能做出外形与协议一致的模块**——溯源因此不能只靠「它能报出正确序列号」，必须叠加**每实例不可克隆的制造指纹**与**跨模块物理冗余**。

**灵感 4（恢复-辨识对偶：起身就是探针）**
直觉：R69 的信息动作（注视/探针/问句）是「额外」的动作，与任务动作分开。跌倒恢复里没有这种奢侈：执行器有限、时间有限，**每一个恢复动作同时是任务动作和辨识动作**。撑地时那条手臂能不能承重，是对「肩关节是否损坏」的一次直接载荷测试；翻滚时哪一侧先失力，是对「哪根连杆先坏」的一次排序。这把 R69 的 VoI 升级为**带不可逆代价的 VoI**：探针会消耗结构寿命，问错问题的代价不是「白问」，而是「压断最后一根连杆」。核心工程姿态：**恢复动作可以双用，但授权必须分离**——物理上同一段轨迹，逻辑上要分别通过「任务收益」与「辨识收益」两道门，且共享一个不可逆预算账本。

**灵感 5（溯源 × 物理：两个都不够，合起来才是证据）**
直觉：跌倒之后，最危险的错觉是「模块自检通过，所以它没坏」。签名只能证明「这是我出厂时的那块」，不能证明「它现在还能承重」；物理一致性只能证明「读数自洽」，不能证明「它不是仿冒的、没有被中间人重放」。于是需要一张**信任格**：已认证且物理一致（可信）、已认证但物理不一致（疑似损坏或仿冒）、未认证但物理一致（观察期，折价使用）、未认证且不一致（拒用）。更进一步，仿冒者可以同时伪造签名和物理行为（自适应仿冒），所以最终锚点只能是 **PUF / 制造公差指纹 + 跨模块冗余的物理交叉验证**——这正是开源硬件必须自带的安全代价。

**灵感 6（不作为不是零风险：危险率与不可逆势）**
直觉：保守主义的隐藏假设是「不动 = 安全」。跌倒之后这不成立：躺着的危险率随时间上升（电池、温度、二次塌陷、人会被绊倒），而且某些损伤在持续载荷下会从可修复恶化为不可逆（裂纹扩展、齿轮彻底崩齿）。R70 因此引入两个新量：**不作为危险率 λ_in** 与 **不可逆势 Φ**。任何恢复动作都必须记账它消耗了多少 Φ；Φ 有硬上限，超过就禁止——**宁可承认站不起来，也不许把可修复的跌倒变成不可逆的破坏。**

**灵感 7（只在作者那台机上有效的恢复策略是负债）**
直觉：开源硬件的另一面是异质性。一个只在作者那一台样机上成功的恢复动作，在公差另一端的 fork 上可能直接把机器人摔回去。R70 要求恢复配方像开源硬件一样交付：**声明构型兼容包络 Θ，并在 Θ 上做 (Θ,q)-认证**——至少 q 比例的采样变体上成功且不越安全界，同时报告「作者机性能 − 最差变体性能」的**过拟合间隙**。这把「可复现」从口号变成可审计的安全属性，也把社区 fork 从负担变成分布外测试床。

## 1. 形式化定义（增量：定义 310–327）

**定义 310（RISE-RAS 总览与四不变式）** RISE-RAS = (FEB, BHS, CRID, TUD, SVOI, VIABLE, IRMA, PROV, PPX, SWAP, VCE, REGIME, J_RISE)。四不变式：
(i) **实时流零学习写操作**（继承 R69 定义 293-i）；
(ii) **单一身体假设**：任何控制指令必须绑定一个当前可信构型假设 h 或其行为等价类 [h]_π；若不存在可信 h，则不得进入恢复，回到 R69/R68 最保守；
(iii) **不可逆优先**：任何消耗不可逆势 Φ 的动作（含恢复与探针）必须记账并受硬上限约束；恢复不得以「可能造成不可逆损伤」换「可能站起来」；
(iv) **退化包含**：无跌倒事件 / U_struct ≤ τ_struct / 无可行恢复 / 溯源不可信 → 逐指令退化为 R69（再退 R68）。

**定义 311（跌倒事件与事件签名）** 跌倒事件 e = (t_e, a_imp, τ_imp, J_imp, o_e^−, o_e^+, Δattest)，其中 a_imp / τ_imp 为冲击加速度与关节力矩峰值，o_e^± 为跌倒前后本体感受窗口，Δattest 为模块在线状态变化。事件签名 s_e = Φ_e(e)（冲击方向与频谱、IMU 饱和模式、轮速骤降、接触序列、模块掉线）。跌倒定义为「离开直立流形超过 ρ_fall 且进入非设计接触域」的事件，而非单一路径。

**定义 312（身体假设空间 BHS）** h = (θ_geo, θ_in, θ_fric, θ_act, D, id)，θ 为几何/惯量/摩擦/执行器参数，D 为离散损伤拓扑（哪些连杆、关节、传感器退化/松动/开路），id 为模块身份。先验 p(h|e) 由 s_e 与跌倒前标定给出；可信集 H_ε = {h : p(h|e) ≥ ε}。

**定义 313（行为不可分辨商）** 给定探针策略 π，行为分布 P_π(y|h)。定义 h ∼_π h′ ⇔ KL(P_π(·|h) ‖ P_π(·|h′)) ≤ κ。等价类 [h]_π 表示「在可用探针下无法区分」的身体假设。恢复策略必须对整个 [h]_π 认证，而不是对一个点认证。

**定义 314（三分不确定性）** U_ale = Σ_k ŵ_k tr Σ_k（同 h、模态内，不可约）；U_epi = H_mode·g(Δ_min)（同 h、模态间，可被 R69 交互消解）；U_struct = H(h | e, o)（不同 h 之间，**不可被外部提问消解**，只能被冲击响应、载荷探针、溯源与更换消解）。三者语义不同，不做简单加和；分别进入不同通道（定义 325–327）。

**定义 315（跌倒即激励 CRID）** 冲击响应 y_e ~ P(y | h, e)，用状态空间/模态响应模型刻画。后验 p(h | e, y_e) ∝ p(h|e)·p(y_e | h, e)。核心推论：跌倒只激发其冲击谱覆盖到的模态；**没被激起的方向上的损伤保持先验**，不得假装已辨识。

**定义 316（结构探针与可辨识性）** 安全探针集 Π_safe（力/位包络内的低幅载荷测试、关节微动、支撑试探）。探针设计 π* = argmax_{π∈Π_safe} I(h; y | π)，s.t. Φ(π) ≤ φ_probe 且 risk(π) ≤ ε_probe。若 max_π I(h; y|π) < τ_id，则该损伤模式**在安全探针下不可辨识**，必须按最坏情形处理或触发更换/求助。

**定义 317（恢复-辨识动作空间）** ξ = (a_rec, π, g_repair, g_help)，a_rec ∈ 恢复动作（撑起、翻滚、跪立、借墙、爬行、退出到安全姿态），π 为嵌入恢复的载荷探针，g_repair 为模块更换/重配置/重标定，g_help 为请求人/社区协助。a_rec 与 π 允许物理共享（dual-use），但授权分离（定义 310-iii）。

**定义 318（恢复价值与可行核 VIABLE）** 信念 b = p(h|·)。对恢复序列 u，定义成功概率 P_succ(u|b)、期望恢复时间 T(u)、执行风险 R_exec(u)、不可逆代价 Φ(u)、信息增益 I(u)。恢复价值
RV(u|b) = E[C_in(T(u))] + R_exec(u) + λ_Φ·Φ(u) − λ_I·I(u)。
可行核 K_viable = {s : ∃u, P_succ ≥ p_req, R_exec ≤ ε_rec, Φ ≤ φ_cap}。若 s ∉ K_viable，禁止「英雄式恢复」，转 Safe-Down（认证过的「不使情况更糟」策略）。

**定义 319（不作为风险与危险率）** 不作为危险率 λ_in(s)（二次损伤、环境暴露、通信丢失、对人风险）。期望不作为代价 C_in(T) = ∫_0^T λ_in(s(t))·c_fail dt + c_hold·T。**「不动」不是零成本选项**，它只是另一种带风险的策略。

**定义 320（不可逆势与账本 IRMA）** 不可逆势 Φ(s) 单调不减，动作消耗 ΔΦ(a)。账本 Ledger 记录每次动作的 ΔΦ 及其证据（力矩、裂纹代理量、温度、磨损）。硬上限 Φ ≤ Φ_max；任何预计使 Φ 越界的动作被禁止，除非「不动作」的期望代价更高且已有不可逆授权。

**定义 321（构型溯源 PROV）** 构型证书 C* = (BOM_hash, {module_id_i}, {calib_i, wear_i}, {fw_hash_i}, {attest_i}, provenance_chain)。开源硬件使原理图公开，因此**认证不等于保密**；每实例身份依靠 PUF/制造公差指纹与签名挑战-响应。

**定义 322（溯源-物理交叉 PPX）** 对每个模块 i，trust_i = f(attest_i, phys_consistency_i, redundancy_agreement_i)，落在信任格：已认证+一致（可信）> 未认证+一致（观察期，折价）> 已认证+不一致（疑似损坏/仿冒，隔离）> 未认证+不一致（拒用）。**签名证明来源，物理证明功能，二者缺一不可。**

**定义 323（模块替换 SWAP）** g_repair 用标准模块替换可疑/损坏模块，把未知 h 变成已知 h′，但付出时间、备件可用性与停机成本；替换件同样要过 PROV/PPX。**更换是最终的消歧手段**：当探针不可辨识时，换掉比猜更诚实。

**定义 324（构型兼容包络与 (Θ,q)-认证 VCE）** 公差包络 Θ（连杆长度、质量、摩擦、执行器增益的允许区间）。恢复配方在 Θ 上 (Θ,q)-认证 ⇔ 至少 q 比例的采样变体 θ∈Θ 上成功且满足安全约束（或用 CVaR 约束）。过拟合间隙 G = J(author unit) − min_{θ∈Θ} J(θ)，要求 G ≤ g_max。

**定义 325（制度切换 REGIME）** 三制度：Prevention（常态，R68/R69）、Recovery（跌倒事件 + U_struct 高）、Re-baselining（更换/重辨识后重建标定）。切换用跌倒检测 + U_struct + 可行核的滞回阈值，防抖振；进入 Recovery 后，R69 的外部交互仅在**不消耗不可逆预算**时允许。

**定义 326（证书 J_RISE）** J_RISE = (J_FLUID, e_hash, BHS_summary, U_struct_before/after, viability_margin, inaction_cost, phi_ledger_hash, provenance_chain_hash, variant_coverage, rise_ver)。Valid ⇔ Valid(J_FLUID) ∧ 溯源可信 ∧ Φ ≤ Φ_max ∧ 恢复配方 (Θ,q)-认证 ∧ 制度切换一致。

**定义 327（退化边界）** 无跌倒事件，或 U_struct ≤ τ_struct，或 H_ε 为空，或溯源失败，或 K_viable 为空但用户选择不恢复 → RISE 逐指令让位给 R69（再让位 R68）。故 R69/R68 是 RISE 在「永不跌倒」与「不可恢复」边界上的严格退化。

```python
class FallEventBuffer:

        self.buf.append(Window(o, impact, attest_delta))

# IP-265/266 CRID：先读完这次冲击，再做安全探针；输出身体后验
def crash_identify(prior_BHS, fall_event, y_e):
    post = bayes_update(prior_BHS, P_fall_response, y_e, fall_event)
    for pi in design_probes(post, budget=PHI_PROBE):   # 仅安全、非破坏

def decompose_three(samples, post_h):

# IP-269/270 VIABLE + IRMA：恢复价值、可行核、不可逆账本
def recovery_value(u, b, ledger):
    P, T, R, Phi, I = rollout_recovery(u, b)
    if Phi + ledger.used > PHI_MAX: return -inf        # 硬上限，先于收益
    if R > EPS_REC:                return -inf
    return C_in(T) + R + LAM_PHI * Phi - LAM_I * I

def choose_recovery(b, ledger):
    viable = [u for u in recovery_candidates(b)
              if recovery_value(u, b, ledger) > -inf]
    return max(viable, key=lambda u: recovery_value(u, b, ledger)) \
           if viable else safe_down(b)                 # 不更糟，而非英雄式

# IP-271/272 PROV + PPX：溯源-物理交叉信任格
def provenance_physics(module, attest, phys, redund):
    if not attest.ok and not phys.ok: return REJECT
    if attest.ok  and not phys.ok:    return QUARANTINE      # 损坏或仿冒
    if not attest.ok and phys.ok:     return PROBATIONARY    # 折价使用
    return TRUSTED

# IP-276 REGIME + RISE 主闭环
def RISE_round(M, obs):
    ev = M.feb.push(obs)
    if not M.feb.detect():
        return M.r69.round(obs)                       # 退化：逐指令相同
    # 1) 跌倒即辨识：先读完冲击，再谈起身
    post_h, U_struct = M.crid.identify(M.bhs_prior, ev.signature(), ev.y_e)
    U_ale, U_epi, U_struct, _ = M.tud.decompose(
        M.fmp.sample(obs, K=4), post_h)
    # 2) 溯源-物理交叉：哪些模块还能信
    trust = {i: M.ppx.check(i, ev.attest_delta) for i in M.modules()}
    M.prov.assert_config(trust)
    # 3) 不可辨识则换件或求助；否则在可信等价类上算恢复价值
    if M.crid.unidentifiable(post_h) and M.swap.available():
        return M.swap.execute(M.swap.plan(post_h))    # 换件 = 最终消歧
    b = truncate(post_h, trust)
    if not M.viable.in_kernel(b, M.ledger):
        return M.safe_down.execute(b)                 # 认证的不变集
    u = M.viable.choose_recovery(b, M.ledger)
    # 4) 双用动作、分离授权：任务收益与辨识收益各自过门
    ok_task = M.cert.task_gate(u, b)                  # C-RAS-WM 前缀认证
    ok_id   = M.svoi.identify_gate(u, b, PHI_PROBE)
    if not (ok_task and ok_id):
        return M.safe_down.execute(b)
    M.ledger.commit(u, delta_phi=M.irma.estimate(u, b))  # 记不可逆账
    # 5) 执行、重辨识、按滞回回到 Prevention
    result = M.ctrl.execute(u)
    M.bhs_prior = M.crid.update(post_h, result.obs)
    M.regime = M.regime.next(result, M.bhs_prior)
    M.vqa.submit_async(ev, trust, M.ledger, U_struct)
    return result
```

## 3. 推导

**引理 19（跌倒激励的信息下界与盲区）** 在局部线性-高斯近似下，冲击响应关于 h 的 Fisher 信息为 J_e，则 I(h; y_e) = ½ log det(I + Σ_h^{1/2} J_eᵀ Σ_n^{-1} J_e Σ_h^{1/2})。若冲击谱在某个损伤方向上的灵敏度为零（未激发该模态），该方向的后验等于先验。系：**并非所有跌倒都同样可读**；系统必须先估计「这次跌倒读到了什么」，再决定 U_struct，而不能把跌倒当成全能证据。这是对「跌倒即辨识」的自我设限。

**引理 20（不作为-恢复盈亏平衡）** 设不恢复的期望代价为 C_in(T)，恢复成功概率 p、失败时代价 c_fail、不可逆代价 Φ，则尝试恢复当且仅当 p ≥ p* = (C_in(T) + Φ) / (C_in(T) + c_fail)。p* 随不作为危险率 λ_in 上升而下降，随 Φ 上升而上升。系：**「躺着更安全」只在 λ_in→0 且 Φ 很大时成立**；在火场、水下、交通场景，p* 会低到「冒险是理性的」。

**引理 21（跨构型泛化界与过拟合间隙）** 若恢复代价对 θ 的 Lipschitz 常数为 L_Θ，则 worst-case 间隙 ≤ L_Θ·diam(Θ) + 统计项；只在作者机上训练的策略，其期望间隙随 diam(Θ) 增长。用 N 个变体做 scenario optimization 时，P(违反率 > ε) ≤ δ 只需 N ≥ (2/ε)(log(1/δ) + d)。系：**开源硬件的异质性是资产也是负债**——它提供测试床，但要求声明的 Θ 与足够的变体覆盖，否则认证是自欺。

**引理 22（溯源-物理交叉的漏检界）** 若伪造模块通过认证的概率为 β_forge、物理一致性检验的误接受率为 α，则在两者条件独立时联合误接受 ≤ β_forge·α；若仿冒者自适应模仿物理行为，则上界退化，唯一稳健锚点是每实例不可克隆指纹 + 跨模块冗余（误接受率随冗余数指数下降）。系：**开源硬件必须把安全预算花在「实例不可克隆」，而不是「设计保密」上。**

**定理 18（RISE 严格包含 R69/R68）** 在 A99–A101 下，RISE 在任意状态的期望总代价 ≤ R69（R69 是 RISE 在「永不跌倒」边界上的特例）；当无跌倒事件、U_struct ≤ τ_struct、H_ε 为空，或 K_viable 为空且不恢复时，两者逐指令相同。安全侧不让步：恢复层任何动作都要过任务与辨识双门，且受 Φ 硬约束。

**定理 19（恢复-辨识对偶的单调退化与有界切换）** 在制度滞回、Φ 账本单调、且 Safe-Down 为认证不变集的条件下：无法辨识、无法更换、或双用动作任一授权失败时，系统单调退化为 Safe-Down，而不是退化为不受控跌倒；恢复动作的接触模式切换被 C-RAS-WM 前缀认证限制在认证过的转移图上，因而指令的 jerk 有界（而非「连续」——接触恢复本质上不连续，我们不假装它连续）。开放问题：接触丰富的恢复是否会引入认证图外的转移，是定理成立的边界条件，也是 E314 的检验对象。

## 6. 本轮最大风险

**一句话**：RISE 的全部收益押在「跌倒这场冲击足以辨识身体假设」这一前提上——**若损伤方向落在冲击谱的盲区、或安全探针也读不出，系统就会在错误的「新身体」模型上自信地起身，把可修复的跌倒变成不可逆的破坏；起身的那一下，可能正是压断最后一根连杆的那一下。**

**次级风险与缓解**：
1. **不可辨识损伤** → 定义 316 的诚实标注 + 最坏情形假设 + 定义 323 的更换/求助，绝不猜测；
2. **仿冒模块/自适应伪造** → PUF + 跨模块冗余、认证不保密（定义 321–322、引理 22）；
3. **接触丰富恢复越出认证图** → 双用分离授权 + Safe-Down 认证不变集（定理 19）；
4. **跨构型过拟合** → (Θ,q)-认证 + 过拟合间隙上限（定义 324、引理 21）；
5. **制度误切换/抖振** → 滞回切换 + 事件签名（定义 325）；
6. **Φ 账本本身不可观** → Φ 只是代理量，可能系统性低估；这是本方案最深的次级风险，必须用 E307 的破坏性抽检标定，并在低估时按最坏情形抬升。

**定义 326–327（证书与退化）** `J_RISE` 并入 `J_FLUID`、事件哈希、BHS、U_struct 前后、可行性裕度、不作为代价、Φ 账本、溯源链、变体覆盖；Valid ⇔ 全部成立。无跌倒或不可恢复时逐指令退化为 R69/R68。

```python
def recovery_value(u, b, ledger):
    P, T, R, Phi, I = rollout_recovery(u, b)
    if Phi + ledger.used > PHI_MAX or R > EPS_REC: return -inf
    return C_in(T) + R + LAM_PHI * Phi - LAM_I * I

def choose_recovery(b, ledger):
    viable = [u for u in recovery_candidates(b)
              if recovery_value(u, b, ledger) > -inf]
    return max(viable, key=lambda u: recovery_value(u, b, ledger)) \
           if viable else safe_down(b)

# IP-271/272 PROV + PPX：溯源-物理信任格
def provenance_physics(module, attest, phys, redund):
    if not attest.ok and not phys.ok: return REJECT
    if attest.ok  and not phys.ok:    return QUARANTINE
    if not attest.ok and phys.ok:     return PROBATIONARY
    return TRUSTED

# IP-276 REGIME + RISE 主闭环
def RISE_round(M, obs):
    ev = M.feb.push(obs)
    if not M.feb.detect():
        return M.r69.round(obs)                    # 退化：逐指令相同
    post_h, U_struct = M.crid.identify(M.bhs_prior, ev.signature(), ev.y_e)
    U_ale, U_epi, U_struct, _ = M.tud.decompose(
        M.fmp.sample(obs, K=4), post_h)
    trust = {i: M.ppx.check(i, ev.attest_delta) for i in M.modules()}
    M.prov.assert_config(trust)
    if M.crid.unidentifiable(post_h) and M.swap.available():
        return M.swap.execute(M.swap.plan(post_h)) # 换件 = 最终消歧
    b = truncate(post_h, trust)
    if not M.viable.in_kernel(b, M.ledger):
        return M.safe_down.execute(b)              # 认证不变集
    u = M.viable.choose_recovery(b, M.ledger)
    ok_task = M.cert.task_gate(u, b)               # C-RAS-WM 前缀认证
    ok_id   = M.svoi.identify_gate(u, b, PHI_PROBE)
    if not (ok_task and ok_id):
        return M.safe_down.execute(b)
    M.ledger.commit(u, delta_phi=M.irma.estimate(u, b))
    result = M.ctrl.execute(u)
    M.bhs_prior = M.crid.update(post_h, result.obs)
    M.regime = M.regime.next(result, M.bhs_prior)
    M.vqa.submit_async(ev, trust, M.ledger, U_struct)
    return result
```

## 4. 推导

**引理 19（跌倒激励的信息下界与盲区）** 线性-高斯近似下 `I(h; y_e) = ½ log det(I + Σ_h^{1/2} J_eᵀ Σ_n^{-1} J_e Σ_h^{1/2})`。冲击谱在损伤方向灵敏度为零 ⇒ 该方向后验等于先验。系：**并非所有跌倒都同样可读**；先把「这次读到了什么」算出来，才配谈 U_struct。

**引理 20（不作为-恢复盈亏平衡）** 恢复当且仅当 `p ≥ p* = (C_in(T)+Φ)/(C_in(T)+c_fail)`。`p*` 随 `λ_in` 上升而下降、随 `Φ` 上升而上升。系：**「躺着更安全」只在 `λ_in→0` 且 `Φ` 很大时成立**；火场/水下/交通场景里，冒险是理性的。

**引理 21（跨构型泛化界）** `worst-case gap ≤ L_Θ·diam(Θ) + 统计项`；scenario optimization 下 `N ≥ (2/ε)(log(1/δ)+d)` 即保证 `P(违反>ε) ≤ δ`。系：**开源硬件的异质性既是测试床也是负债**——不声明 Θ、不做变体覆盖，认证就是自欺。

**引理 22（溯源-物理交叉漏检界）** 独立时联合误接受 `≤ β_forge·α`；自适应仿冒下上界退化，唯一稳健锚点是每实例不可克隆指纹 + 跨模块冗余。系：**安全预算要花在「实例不可克隆」，不是「设计保密」。**

**定理 18（RISE 严格包含 R69/R68）** A99–A101 下，RISE 的期望总代价 ≤ R69；无跌倒 / `U_struct≤τ_struct` / `H_ε=∅` / `K_viable=∅` 且不恢复时逐指令相同。安全侧不让步：恢复动作过任务+辨识双门，且受 Φ 硬约束。

**定理 19（恢复-辨识对偶的单调退化与有界切换）** 制度滞回、Φ 单调、Safe-Down 为认证不变集时：无法辨识/更换/任一授权失败 ⇒ 单调退化为 Safe-Down，而非不受控跌倒；接触模式切换被 C-RAS-WM 前缀认证限制在认证转移图上，故 jerk 有界（接触恢复本就不连续，不假装连续）。开放问题：接触丰富恢复是否越出认证图，是定理边界，也是 E314 的检验对象。

## 7. 本轮最大风险

**一句话**：RISE 的全部收益押在「跌倒这场冲击足以辨识身体假设」这一前提上——**若损伤方向落在冲击谱的盲区、或安全探针也读不出，系统就会在错误的「新身体」模型上自信地起身，把可修复的跌倒变成不可逆的破坏；起身的那一下，可能正是压断最后一根连杆的那一下。**

**次级风险与缓解**：不可辨识损伤（定义 316 诚实标注 + 最坏情形 + 定义 323 更换/求助，不猜）；仿冒/自适应伪造（PUF + 跨模块冗余，认证不保密，引理 22）；接触恢复越出认证图（双用分离授权 + Safe-Down 不变集，定理 19）；跨构型过拟合（(Θ,q)-认证 + 过拟合间隙，引理 21）；制度误切换（滞回 + 事件签名）；Φ 账本不可观（代理量可能系统性低估，用 E307 破坏性抽检标定，低估时按最坏情形抬升）。
