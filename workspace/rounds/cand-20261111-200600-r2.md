# 第 55 轮（承接第 54 轮 v16++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「语音识别」×「实时控制」）

> 第 54 轮已把技能组合推进到动作空间剖面、组合图与云边协同双证书。本轮把视角前移到 **语言指令 → 动作** 的实时闭环：语音识别输出的是**带时延、带歧义的流式部分假设**，而实时控制要求**有界时延、安全承诺与可纠错性**。核心矛盾：
> - **H22（目标错配）**：ASR 以词错误率 WER 为优化目标，但控制系统只关心「转写差异是否改变动作」；WER 最优 ≠ 动作最优。
> - **H23（流式抖动）**：部分假设随时间反复改写，直接驱动控制会产生意图翻烧（intent flapping）与规划震荡。
> - **H24（时延-精度-安全三角）**：端到端「说完→首个动作」必须落在控制死线内，而云/边模型的精度与时延此消彼长，模型切换又引入语义漂移。

## 0. 直觉与动机

**灵感 1（控制等价性：从“听对词”到“做对事”）**
直觉：语音识别不必逐词正确，只需**动作充分**。若两段转写 `τ, τ'` 经同一控制策略 `π` 诱导出相同动作序列，则它们对控制是等价的；真正致命的是那些“只错一个词、却把抓取变成推倒”的错误。于是把解码目标从 WER 换成 **动作条件错误率 ACER = P(ASR 误差改变动作)**。这把感知指标锚定到下游控制，是典型的“任务驱动感知”。

**灵感 2（语义端点与意图承诺）**
直觉：ASR 有语音端点检测（VAD endpointing），控制也需要**语义端点**：只有当意图等价类在滑窗内稳定、且 top-k 假设在动作上不变时，才“承诺”执行；否则保持安全悬停或主动澄清。承诺必须带**迟滞**与**可逆性预算**——已经承诺的动作要能被后续修正，且修正代价有界。

**灵感 3（死线感知的 anytime 解码）**
直觉：实时控制有硬死线 `D`。ASR 应在死线前返回“当前最优意图 + 歧义证书”，而不是无休止地等更准结果。采用**模型级联**（边端小模型快 → 云端正则化/大模型准）：slack 足够时回云重打分，slack 不足则 early-exit 并在安全集内先行动作。这把第 54 轮的云边 `γ_ce` 从“动作映射”扩展为“意图映射 + 时延预算分配”。

**灵感 4（意图延迟补偿）**
直觉：ASR 时延等价于“意图传感器”的纯延迟。实时控制有 Smith 预测器补偿测量延迟，我们可引入**意图预测器**：用已稳定前缀外推用户将要表达的意图，在剩余死线内提前准备动作；但外推必须满足“动作不变 + 可逆”两道闸门，否则宁可等待。

**灵感 5（语音-控制契约与联合证书）**
直觉：把语音链路、控制策略与安全约束写成一份可验证契约：`C_sc = (意图格, 承诺意图, 死线, 安全回退集, 可逆性预算, 证据)`。跨层传递的证书同时记录 `ACER`、意图鲁棒性 `ρ_intent`、动作鲁棒性 `ρ_action`、实际时延 `T_act` 与安全集，与第 53/54 轮的 `ρ`、`Explain`、`A_cert` 对齐。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（流式意图格）**
在时刻 `t`，ASR 输出意图格 `L_t = {(h_i, p_i, t_i)}_{i=1}^{n}`：`h_i` 为部分转写或直接意图假设，`p_i` 为后验，`t_i` 为产生时间；映射 `μ: h_i → I` 给出意图原子序列（如 `grasp(cup)`、`move(left)`）。`L_t` 随 `t` 单调扩张假设集。

**定义 122（动作充分性与 ACER）**
给定控制策略 `π`，两假设控制等价 `h ~_π h'` 当且仅当 `π(μ(h)) = π(μ(h'))`。**动作条件错误率**：
```
ACER(π) = E_{h*~P}[ 1( π(μ(ĥ)) ≠ π(μ(h*)) ) ]
```
其中 `h*` 为真值、`ĥ = argmax_i p_i`。控制器真正关心的是 `ACER ≤ Θ_A`，而非 `WER ≤ Θ_W`。

**定义 123（语义承诺）**
承诺指示 `commit(t)=1` 当且仅当同时满足：
1. `argmax` 意图类在窗口 `W` 内不变（稳定性）；
2. top-k 假设中 `π(μ(h_i))` 的一致率 `≥ θ_inv`（动作不变性）；
3. `p_max ≥ θ_conf`（置信度）；
4. 剩余时延 `slack = D - T_act ≥ 0`（死线可行性）。

**定义 124（端到端时延预算）**
`T_act = T_ep + T_asr + T_plan + T_ctrl ≤ D`，其中 `T_ep` 为端点检测、`T_asr` 为识别（含回云重打分）、`T_plan/T_ctrl` 为规划与执行延迟；`P_miss = P(T_act > D)`。死线不满足时只能进入安全回退，不能“猜一个动作”。

**定义 125（语音-控制契约）**
`C_sc = (L_t, I*, prefix, D, SafeSet, Rev, evidence)`：
- `I*` 已承诺意图，`prefix` 已确认的意图前缀；
- `SafeSet` 在任何死线情形下均可安全执行的动作集；
- `Rev` 可逆性预算：承诺后纠正动作的最大代价上界；
- `evidence` 至少包含音频片段、意图格快照、时延轨迹与安全回退日志。

**定义 126（意图-动作联合证书）**
`J_sc = (ACER, ρ_intent, ρ_action, T_act, SafeSet, Rev, evidence)`。若
`ACER ≤ Θ_A ∧ P_miss ≤ Θ_T ∧ (∀ a∈π(I*), Rev(a) ≤ Rev_max) ∧ SafeSet ≠ ∅`，
则契约**可部署**；若存在不可逆动作落在未稳定意图类上，则直接否决。

## 2. 关键算法 伪代码

### IP-121 ACER-D（Action-Conditioned Error-aware Decoding）

```python
def acer_decode(lattice, policy, deadline, lam_lat=0.1):
    best, best_score = None, float('inf')
    for h in lattice.nbest(K):
        acer = expected_action_mismatch(h, lattice, policy)   # 关键：动作风险
        score = acer + lam_lat * h.latency
        if score < best_score and h.ready_by(deadline):
            best, best_score = h, score
    return best   # 返回动作风险最小的可行假设，而非最高分转写
```

### IP-122 SIC（Streaming Intent Commitment）

```python
class IntentCommitment:
    def __init__(self, W=5, theta_inv=0.9, theta_conf=0.8, safe_set=None):
        self.hist, self.W = [], W
        self.theta_inv, self.theta_conf, self.safe_set = theta_inv, theta_conf, safe_set

    def update(self, L_t, policy, D_remaining):
        classes = [policy.intent(h) for h in L_t.topk(self.k)]
        self.hist.append(classes[0])
        stable   = len(set(self.hist[-self.W:])) == 1
        invariant= Counter(classes).most_common(1)[0][1] / len(classes) >= self.theta_inv
        conf     = L_t.top1.p >= self.theta_conf
        slack    = D_remaining - L_t.top1.latency
        if slack < 0:
            return ('fallback', self.safe_set)      # 死线优先：安全动作兜底
        if stable and invariant and conf:
            return ('commit', classes[0])
        return ('wait', None)                        # 主动等待/要求澄清
```

### IP-123 DAS（Deadline-Aware Scheduler，级联 anytime）

```python
def deadline_pipeline(audio, policy, D):
    t0 = now()
    h_edge, _ = edge_asr.quick(audio)               # 边端低时延小模型
    budget = D - (now() - t0) - policy.plan_latency
    if budget > tau_cloud and edge_ambiguous(h_edge, policy):
        h_cloud = cloud_asr.refine(audio, timeout=budget)   # slack 足够才回云
        h = reconcile(h_edge, h_cloud)              # 漂移受控的融合
    else:
        h = h_edge                                   # early-exit
    return h, now() - t0
```

### IP-124 IDC（Intent Delay Compensation）

```python
def intent_delay_compensate(hist, horizon, policy, Rev_max):
    pred = intent_predictor(hist[-k:], horizon)
    if pred.confidence < theta_p:
        return None
    if not policy.action_invariant(pred):            # 外推必须动作不变
        return None
    if Rev(pred.action) > Rev_max:                   # 且必须可逆
        return None
    return pred.action                              # 否则宁可等待
```

### IP-125 VCC（Voice-Control Certificate）

```python
def voice_control_certificate(lattice, policy, D, safe_set, rev_budget):
    acer   = estimate_acer(lattice, policy)
    p_miss = estimate_deadline_miss(lattice, D)
    unstable_irreversible = any(
        (not policy.is_reversible(cls)) and cls not in stable_classes(lattice)
        for cls in policy.action_classes(lattice))
    if acer > THETA_A or p_miss > THETA_T or unstable_irreversible or not safe_set:
        return ('reject', acer, p_miss)             # 不可逆 + 不稳定 = 硬否决
    return ('ok', J_sc(acer, rho_intent, rho_action, D, safe_set, rev_budget))
```

### IP-126 CET（Control-Equivalent Transfer）

```python
def control_equivalent_transfer(src, tgt_policy, gamma_ce, delta_budget):
    drift        = acer_under_policy(src.lattice, tgt_policy)   # 换策略后的动作漂移
    action_drift = semantic_action_drift(gamma_ce)              # 云边意图→动作漂移
    if drift > delta_budget or action_drift > delta_budget:
        return ('reject', 'control_equivalence_broken', drift, action_drift)
    return ('ok', update_jsc(src, drift, action_drift))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| ACER-D | O(K·\|π\|·\|A\|) | O(K·\|A\|) | 动作风险估计校准、K 覆盖真值 |
| SIC | O(\|L_t\|·k + W) | O(W) | 窗口稳定、动作不变性阈值 sound |
| DAS | O(\|L\|·k + T_cloud) | O(\|L\|) | 死线硬约束、融合不放大漂移 |
| IDC | O(k·h·\|A\|) | O(k) | 外推动作不变 + 可逆双闸门 |
| VCC | O(\|L\|·\|π\|+\|A\|) | O(\|A\|) | ACER/P_miss 估计、不可逆硬否决 |
| CET | O(\|L\|·\|π\|+\|γ_ce\|) | O(\|A\|) | 控制等价类跨策略闭合 |

**正确性定理（Speech-Action Real-time Safety）**
假设第 54 轮 (A26)–(A28) 承接；**(A29)** `ACER` 估计经留出集校准，偏差 `≤ ε_A`；**(A30)** 调度器对 `T_act` 给出硬上界，`P_miss` 可估；**(A31)** `SafeSet` 在任意控制周期内可达；**(A32)** 承诺后修正代价 `≤ Rev_max`。则：
```
P_safe ≥ 1 - (ACER + ε_A) - P_miss - P(Rev > Rev_max) - P(commit_flip ∩ irreversible)
```
关键：**先保证死线与安全回退，再谈识别精度**；**不可逆动作只允许在稳定意图类上承诺**。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 ACER vs WER | 同延迟下动作错误率 | ACER-D 较 WER 最优降 ≥ 20%，ACER ≤ 5% |
| E163 承诺稳定性 | 计划翻转次数 / 承诺附加延迟 | 翻转降 ≥ 40%，附加延迟 ≤ 80ms |
| E164 死线满足率 | `T_act` 分布、`P_miss` | P95 ≤ D，`P_miss` ≤ 1% |
| E165 云边 ASR 切换漂移 | 切换前后 ACER 差 | `ΔACER` ≤ 3% |
| E166 噪声端到端 | 5dB SNR 下语音控制抓取成功率 | 较纯 WER 基线提升 ≥ 12% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| ACER 依赖当前策略，策略更新后失准 | 高 | 在线校准 + 策略版本化证书 + 漂移告警 |
| 意图预测器外推错误放大 | 高 | 动作不变/可逆双闸门 + 保守回退 |
| 死线压力下过早承诺 | 高 | 安全集兜底 + 可逆性预算硬约束 |
| 云边模型切换语义漂移 | 中 | 控制等价类对齐 + 切换绊线 |
| 澄清交互拖长时延 | 中 | 主动学习式最小澄清问题选择 |

## 6. 本轮最大风险

**一句话**：把 ASR 目标从 WER 改写为 ACER、并用死线与安全回退兜住实时性，方向正确，但 **ACER 与承诺稳定性都依赖“当前控制策略”与“真值动作分布”的先验，一旦策略迭代或部署域漂移，动作等价类会失准，系统可能在“自信地听错”时仍判为可承诺，从而在不可逆动作上触发安全违约**；故必须以 **策略版本化 ACER 校准 + 不可逆动作硬否决 + 安全集兜底** 三重护栏，宁可多问一句，也不把“动作等价”的统计假象当作实时安全的前提。

# 第 55 轮产物 · 创新点清单 v32：VoiceEdge-Control（ACER-D×SIC×DAS×IDC×VCC×CET）

> 承接第 54 轮产物 v31。本轮在动作空间/云边协同之上，增加 **语音识别到实时控制的闭环** 六个算子：
> - **ACER-D（Action-Conditioned Error-aware Decoding）**：以“动作是否被改变”为解码目标，替代 WER；
> - **SIC（Streaming Intent Commitment）**：流式部分意图的稳定承诺与迟滞；
> - **DAS（Deadline-Aware Scheduler）**：边端快模型 ↔ 云端准模型的 anytime 级联；
> - **IDC（Intent Delay Compensation）**：意图纯延迟的受限外推补偿；
> - **VCC（Voice-Control Certificate）**：语音-控制契约与联合证书；
> - **CET（Control-Equivalent Transfer）**：控制等价类跨策略/跨云边的迁移校验。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/116/117/118 以纳入意图流与实时死线维度。

| CET | O(\|L\|·\|π\|+\|γ_ce\|) | O(\|A\|) | 控制等价类跨策略闭合 |

**正确性定理（Speech-Action Real-time Safety）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `ACER` 经留出集校准，偏差 `≤ ε_A`；**(A30)** 调度器给出 `T_act` 硬上界；**(A31)** `SafeSet` 每个控制周期可达；**(A32)** 承诺修正代价 `≤ Rev_max`。则：
```
P_safe ≥ 1 - (ACER + ε_A) - P_miss - P(Rev > Rev_max) - P(commit_flip ∩ irreversible)
```
关键：**死线与安全回退优先于识别精度**；**不可逆动作只允许在稳定意图类上承诺**。

## 5. 本轮最大风险

**一句话**：把 ASR 目标从 WER 改写为 ACER、并用死线与安全回退兜住实时性，方向正确，但 **ACER 与承诺稳定性都依赖“当前控制策略”与“真值动作分布”的先验，一旦策略迭代或部署域漂移，动作等价类会失准，系统可能在“自信地听错”时仍判为可承诺，从而在不可逆动作上触发安全违约**；故必须以 **策略版本化 ACER 校准 + 不可逆动作硬否决 + 安全集兜底** 三重护栏，宁可多问一句，也不把“动作等价”的统计假象当作实时安全的前提。
