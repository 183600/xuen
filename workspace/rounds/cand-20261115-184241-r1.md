# 第 1 轮（新灵感循环 R1；本轮灵感：「路径规划」×「双足机器人」）
> **继承基线**：第 8 轮 MetricVoiceGauge-DA-SPR-Cal（定义 493–531；引理 77–81；实验 E531–E550）。
> 本轮纪律：**预测性 + 混合动力学**。路径规划把指标体系从「瞬时反应」升级为「路径级预测」；双足机器人把「静态支撑假设」升级为「相位索引的混合接触」。二者在「路径即落足序列」处合流。所有新模块均为可选增强，任一失效 ⇒ 退回 v8。

## 0. 直觉与动机

**灵感 1（路径规划 → 预测性指标视界）**
直觉：现有 MetricLadder 只看当前状态 s_t，是「后视镜」式安全——等到指标违背时，系统已经在危险边缘。路径规划天然提供未来 H 秒的状态序列 π(t)，于是可以问一个更强的问题：**「按当前规划，最早在哪一刻会违背指标？」** 记作 t*_viol。把触发条件从「当前违背」改为「预测违背时间 < 视界」，系统获得反应提前量；同时把路径本身（清障距离、运动学可行性、同伦类）做成可验证的证书对象 PathCertificate，使「重规划」也有证书，而不是黑箱换路。

**灵感 2（双足机器人 → 相位索引的混合动力学指标）**
直觉：轮式/静态机器人「支撑多边形始终存在」，而双足机器人在单支撑、双支撑、腾空之间切换，ZMP、捕获点（DCM）、接触力锥的可行性都随相位改变。若沿用单一指标集，会出现两类错误：相位切换瞬间的「指标空洞」（switch 期间无人在看）与「拿双支撑阈值判单支撑」的尺度错配。核心创新是**相位索引指标集 M_leg(σ)**：每个接触相位 σ 只激活物理上成立的约束，并在相位边界强制执行 M₀ 硬检查，保证无时间空洞。

**合流（路径 = 落足序列）**
直觉：对双足而言，几何路径 π 与落足序列 F={(f_k, t_k)} 是同一对象的两面。路径规划输出不再只是 waypoint，而是「落足-时机-质心」三元组；这使路径证书与稳定性证书共享同一时间轴，避免「路径可行但落足不可达」的经典断裂。

## 1. 研究问题（R1 升级版）

- **Q1（预测证书）**：如何定义路径级证书与有效视界 T_val，使 t*_viol 的估计在动态障碍下**保守**（不漏报），且计算满足 10Hz 重规划预算？
- **Q2（相位索引）**：如何设计 M_leg(σ)，使相位切换处指标激活集无缝衔接、不产生 soft-pass/hard-fail 空洞，且 ZMP/DCM/接触锥指标与现有 M₀–M_SLAM 同尺度？
- **Q3（安全不放松）**：在线自适应（DA-OTL）在双足混合接触下如何限制，使安全层阈值**只收紧不放松**，而效率层仍可自适应？

## 2. 设计原则（P10–P12）

**P10 路径证书化（PathCertificate）**
路径 π 连同其清障剖面 d_min(t)、运动学残差 ρ_kin、同伦签名 h(π)、有效视界 T_val 一起封装为证书：
```
Cert_path = (π, d_min(·), ρ_kin, h(π), T_val, t*_viol)
```
只有 Cert_path 通过才允许执行；重规划必须产出新证书，否则退回预认证刹车轨迹 π_stop。

**P11 相位索引指标（Phase-Indexed Metric Ladder, PIML）**
```
M_leg(σ) = { c_ZMP, c_DCM, c_CWC, c_step }   σ ∈ {DS, LS, RS}
```
每个约束仅在物理成立的相位激活；相位边界强制 M₀ 检查，并用连续安全包络 E(σ) 保证激活集在时间上覆盖整个步态周期。

**P12 安全单向棘轮（One-Way Safety Ratchet, OWSR）**
对安全相关层 i ∈ {0,1,path,leg}，在线调节只允许收紧：
```
τᵢ(t) = max( τᵢ(t−1), τᵢ(0) + κᵢ·Δ_dom(t) )   （τ 越大越严）
```
效率层 {2,3} 仍用 v8 的 DA-OTL 双向调节。这样域偏移/不确定性只能让系统更保守，不能借「自适应」放松安全。

## 3. 与基线的接口（如何退化）

- 路径规划模块失效（超时/无解/证书不通过）⇒ 执行**预认证** π_stop，等价安全停机，退回 v8 的瞬时指标触发；
- 双足稳定性模块失效（ZMP/DCM 传感器缺失）⇒ 冻结为双支撑站立（σ=DS），M_leg 仅保留 c_ZMP 静态检查；
- OWSR 失效 ⇒ 安全层冻结为 τᵢ(0)，效率层退回 v8 DA-OTL；
- 三者全失效 ⇒ 完整退回 MetricVoiceGauge-DA-SPR-Cal v8。

## 4. 预期贡献

1. **路径级预测证书**：把指标触发从「当前违背」推进到「预测最早违背时刻」，给出反应提前量；
2. **相位索引混合动力学指标**：为双足单/双支撑/腾空提供无空洞的指标激活语义；
3. **安全单向棘轮**：从机制上禁止在线自适应放松安全阈值，修复 v8 的「过度适应」风险；
4. **多速率协同架构**：1kHz 稳定内环 / 50Hz 指标中环 / 10Hz 规划外环，证书快照只读共享，保证 WCET。

## 5. 本轮最大风险

**一句话**：预测视界的动态障碍外推误差与双足相位判定抖动会在多速率耦合下同时污染 t*_viol 与 ZMP/DCM 指标——若二者同向误判，预认证刹车轨迹在真实接触序列下可能不可行，系统会在「以为还有提前量」时错过安全窗口。

**新增定义 532（时间路径 TimedPath）** 路径由状态-控制-驻留三元组给出，并在段间做连续插值：
```
π = { (s_k, u_k, Δ_k) }_{k=0}^{N-1},  T = Σ_k Δ_k,  s(t) = interp(π, t)
```

**新增定义 533（清障剖面与运动学残差 ClearanceProfile & KinematicResidual）**
```
d_min(t) = dist( s(t), O )                       # 有符号，ESDF 查询
ρ_kin(t) = max( ‖v(t)‖−v_max, ‖a(t)‖−a_max,
                |j(t)|−j_max, |ω(t)|−ω_max )_+   # 正部
```

**新增定义 534（路径证书 PathCertificate）**
```
Cert_path = ( π, d_min^H, max_t ρ_kin(t), h(π), T_val, t*_viol, λ_sig )
Cert_path.valid ⇔ d_min^H ≥ τ_clear ∧ max_t ρ_kin(t) ≤ 0 ∧ λ_sig 校验通过
```
其中 λ_sig 为证书签名/版本戳，防止执行过期证书。

**新增定义 535（规划有效视界 PlanValidityHorizon）** 在动态障碍预测 Ō(t) 下的可行保持时长：
```
T_val(π) = sup{ T ≥ 0 : ∀t∈[0,T], d_min(t; Ō(t)) ≥ τ_clear
                             ∧ ρ_kin(t) ≤ 0 }
```
若动态障碍预测不可得，则退化为静态障碍的 T_val = ∞（由 PC 模块缺失时的 Level-1 处理）。

**新增定义 536（最早预测违背时刻 EarliestPredictedViolation）**
```
t*_viol = inf{ t ≥ 0 : d_min(t; Ō(t)) < τ_clear
                        ∨ ρ_kin(t) > 0
                        ∨ risk_PATH(t) > τ_path }
```
约定路径天然有效至 T，故 t*_viol ∈ [0, T] ∪ {+∞}。

**新增定义 537（接触相位与支撑多边形 ContactPhase）**
```
σ(t) ∈ {DS, LS, RS, FLIGHT}
DS: 双脚着地；LS/RS: 单脚支撑；FLIGHT: 腾空（仅跑步/跳跃相）
P_S(σ) = conv(支撑足底面) 的并/交，按 σ 取对应足
```

**新增定义 538（ZMP 支撑裕度 ZMPMargin）**
```
p_zmp(t) = x_com(t) − (z_com(t)/g) · ẍ_com(t)
m_zmp(t) = sdist( p_zmp(t), ∂P_S(σ(t)) )     # 内正外负
c_ZMP: m_zmp(t) ≥ τ_zmp ≥ 0
```

**新增定义 539（DCM 捕获裕度 DCMMargin）**
```
ω = √(g / z_com),  ξ(t) = x_com(t) + ẋ_com(t)/ω
ξ̇(t) = ω·( ξ(t) − p_zmp(t) )
m_dcm(t) = sdist( ξ(t), ∂P_capture(σ(t)) )
c_DCM: m_dcm(t) ≥ τ_dcm
```

**新增定义 540（接触力锥可行性 ContactWrenchCone）**
```
CWC = { (f, τ_c) : f_n ≥ 0, ‖f_t‖ ≤ μ f_n, CoP(f,τ_c) ∈ P_foot }
ρ_cwc(t) = max( 0, ‖f_t‖ − μ f_n, sdist(CoP, P_foot) 的负部 )
c_CWC: ρ_cwc(t) ≤ 0
```

**新增定义 541（落足可达集 FootholdReachability）** 给定当前状态与步时 T_step：
```
R_f(f_k) = { f_{k+1} : ∃ u(·) 使 LIPM 可捕获 ∧ ‖f_{k+1}−f_k‖ ≤ L_max
                        ∧ IK(f_{k+1}) 在关节限位内 }
c_step: f_{k+1} ∈ R_f(f_k)
```

**新增定义 542（八层指标梯 EightLayerMetricLadder）**
```
M = (M₀, M₁, M₂, M₃, M_dom, M_SLAM, M_path, M_leg)
M_path: d_min^H ≥ τ_clear ∧ t*_viol ≥ τ_horizon
M_leg : 在相位 σ 下激活 M_leg(σ) = {c_ZMP, c_DCM, c_CWC, c_step}
```

**新增定义 543（七维风险向量 RiskVector7D）**
```
risk(s) = [risk_SEN, risk_SEM, risk_EFF, risk_PERF, risk_SLAM, risk_PATH, risk_LEG]
risk_PATH = w_c·max(0, τ_clear − d_min^H) + w_h·max(0, 1 − t*_viol/τ_horizon)
risk_LEG  = w_z·max(0, τ_zmp − m_zmp) + w_d·max(0, τ_dcm − m_dcm)
            + w_cwc·max(0, ρ_cwc)
```

**新增定义 544（安全单向棘轮 SafetyOneWayRatchet）**
```
i ∈ L_safe = {0, 1, path, leg}:
    τᵢ(t) = max( τᵢ(t−1), τᵢ(0) + κᵢ·Δ_dom(t) )        # 只增不减（τ 越大越严）
i ∈ L_eff  = {2, 3}:
    τᵢ(t) = clip( τᵢ(0) + η·θ(t) + κᵢ·Δ_dom(t), ε_min,i, ε_max,i )   # v8 DA-OTL
```

**新增定义 545（预测退化梯 PredictiveDegradationLadder）** 依 t*_viol 分级：
```
L0 正常:     t*_viol ≥ τ_horizon
L1 软降级:   τ_emerg ≤ t*_viol < τ_horizon   → 限速/收紧效率层
L2 硬降级:   t*_viol < τ_emerg               → 切换 π_stop，触发 M₀
L3 即时急停: t*_viol = 0（当前已违背）        → 立即急停
```
要求 τ_emerg < τ_horizon，且两阈值同一物理尺度（秒）。

**新增定义 546（预认证刹车轨迹 Pre-certified Braking）** π_stop 在离线阶段以最大加加速度、最坏摩擦下界验证：
```
Cert(π_stop).valid = true 且 d_min^H(π_stop) ≥ τ_clear + Δ_stop（安全余量）
```
在线仅做 O(1) 校验（签名 + 当前障碍增量），不重新规划。

**新增定义 547（多速率证书调度 MultiRateSchedule）**
```
内环   T_1 = 1 ms   : BSG 稳定守护（ZMP/DCM/CWC）
中环   T_2 = 20 ms  : MetricLadder 检查、PVT 触发、OWSR 更新
外环   T_3 = 100 ms : PathCertificate 重规划与证书签发
利用率约束: Σ_i C_i/T_i ≤ U_max (< 1)
```
各环之间只共享不可变证书快照（copy-on-write / atomic pointer），内环无锁、无阻塞。

**新增定义 548（系统标识 SystemIdentity）**
```
Φ_PathLeg = {τᵢ one-way-safe, risk 7-dim(+PATH,+LEG), cert path+leg, multi-rate}
Φ_v8      = {τᵢ DA-OTL,      risk 5-dim(+SLAM),      cert slam+calib, 50Hz}
```

## 2. 形式化定义（要点）

**定义 493′（八层指标闭合）** M 扩展为八层；M_path、M_leg 均定义为到 M₀ 的退化映射 δ_path, δ_leg，且其判据与 M₀ 同物理尺度（「违背上界/时间下界」）。

**定义 495′（奖励可逆向性，7 维版）** w'_i(s) = softmax(α·risk_i(s) + β·emo(s)·Ṽ_i)_{i=0..6}，risk ∈ ℝ⁷ 含 risk_PATH、risk_LEG。

**定义 496′（软证书，路径-腿版）**
```
δ_trigger = { σ < τ_safe ∧ γ_grasp valid ∧ Δ_dom < τ_dom
              ∧ risk_SLAM < τ_SLAM ∧ Cert_path.valid ∧ m_zmp ≥ τ_zmp }
```
六个合取项同尺度设计；任一触发 ⇒ 进入 M₀ 硬约束或 π_stop。

**定义 521′（DA-OTL，棘轮约束版）** 安全层用定义 544 的单向形式，效率层保持 v8 双向形式；两层共用同一 Δ_dom(t) 与 κᵢ。

# IP-354/355/356 PathCertificatePlanner：路径证书与预测触发
class PathCertificatePlanner:
    def __init__(self, esdf, kin_limits, tau_clear=0.25,
                 tau_horizon=2.0, tau_emerg=0.5, max_iters=2000):
        self.esdf = esdf
        self.lim = kin_limits          # {v_max, a_max, j_max, w_max}
        self.tau_clear = tau_clear
        self.tau_horizon = tau_horizon
        self.tau_emerg = tau_emerg
        self.max_iters = max_iters
        self.last_cert = None          # 只读快照，供中环读取

    def plan(self, start, goal, obstacles, dyn_pred=None, t_now=0.0):
        # 外环 10Hz：Hybrid A* / RRT* 产出时间参数化路径
        pi = self._search(start, goal, obstacles)
        if pi is None:
            return None
        return self.certify(pi, dyn_pred, t_now)

    def certify(self, pi, dyn_pred, t_now):
        H = pi.T
        d_min_H = min(self.esdf.distance(pi.s(t)) for t in samples(pi, H))
        rho_kin = max(self._kin_residual(pi, t) for t in samples(pi, H))
        h_sig = self._homotopy_signature(pi, self.esdf)
        t_star = self._earliest_violation(pi, dyn_pred, t_now)
        T_val = self._validity_horizon(pi, dyn_pred, t_now)
        cert = PathCertificate(pi, d_min_H, rho_kin, h_sig,
                               T_val, t_star, sig=self._sign(pi))
        cert.valid = (d_min_H >= self.tau_clear and rho_kin <= 0.0)
        self.last_cert = cert        # 原子发布只读快照
        return cert

    def _earliest_violation(self, pi, dyn_pred, t_now):
        # 定义 536：保守取最早越界时刻；无越界返回 +inf
        t_star = float('inf')
        for t in samples(pi, pi.T):
            obstacles = dyn_pred(t_now + t) if dyn_pred else None
            d = self.esdf.distance(pi.s(t), obstacles)
            if d < self.tau_clear or self._kin_residual(pi, t) > 0:
                t_star = min(t_star, t)
        return t_star

    def _validity_horizon(self, pi, dyn_pred, t_now):
        # 定义 535：与 _earliest_violation 互补；无动态预测 -> inf
        if dyn_pred is None:
            return float('inf')
        return self._earliest_violation(pi, dyn_pred, t_now)


class PredictiveViolationTrigger:

class BipedalStabilityGuard:
    def __init__(self, z_com=0.8, mu=0.6, tau_zmp=0.02, tau_dcm=0.03):
        self.z_com = z_com
        self.omega = math.sqrt(9.81 / z_com)
        self.mu = mu
        self.tau_zmp = tau_zmp
        self.tau_dcm = tau_dcm

    def update(self, com, com_vel, com_acc, phase, contacts):
        # 1kHz 内环：仅计算，不决策；写只读快照
        p_zmp = com - (self.z_com / 9.81) * com_acc          # 定义 538
        m_zmp = signed_distance(p_zmp, support_polygon(phase, contacts))
        xi = com + com_vel / self.omega                       # 定义 539
        m_dcm = signed_distance(xi, capture_polygon(phase, contacts))
        rho_cwc = self._cwc_residual(contacts, self.mu)       # 定义 540
        snapshot = LegSnapshot(p_zmp, m_zmp, xi, m_dcm, rho_cwc, phase, t=now())
        publish_atomic(self._snapshot, snapshot)
        return snapshot

    def _cwc_residual(self, contacts, mu):
        worst = -float('inf')
        for c in contacts:
            f_t = norm(c.force[:2]); f_n = c.force[2]
            worst = max(worst, f_t - mu * f_n)                 # >0 违反摩擦锥
        return worst

    def constraints(self, snap, phase):
        # 定义 542/537：按相位激活约束，避免尺度错配
        if phase == 'FLIGHT':
            return {'c_DCM': snap.m_dcm}                       # 仅捕获可行性
        if phase in ('LS', 'RS'):
            return {'c_ZMP': snap.m_zmp, 'c_DCM': snap.m_dcm,
                    'c_CWC': -snap.rho_cwc}
        return {'c_ZMP': snap.m_zmp, 'c_CWC': -snap.rho_cwc}   # DS


class PhaseIndexedMetricLadder:
    def __init__(self, guard, tau_zmp=0.02, tau_dcm=0.03):

        self.tau_zmp = tau_zmp
        self.tau_dcm = tau_dcm
        self.prev_phase = None

        violated = []

            violated.append('c_ZMP')

                violated.append('c_ZMP@boundary')
        self.prev_phase = phase
        return violated

class SafetyOneWayRatchet:
    def __init__(self, base_thresholds, kappa):
        self.base = dict(base_thresholds)
        self.tau = dict(base_thresholds)
        self.kappa = dict(kappa)

    def update(self, delta_dom, safe_layers=(0, 1, 'path', 'leg')):
        for i in safe_layers:
            tightened = self.base[i] + self.kappa.get(i, 0.5) * delta_dom
            self.tau[i] = max(self.tau[i], tightened)   # 只增不减

    def can_relax(self, layer):
        return layer not in (0, 1, 'path', 'leg')

## 4. 推导

**引理 82（预测保守性）** 令 d_min^H = min_{t∈[0,H]} d_min(t)。若 H₁ ≤ H₂，则 d_min^{H₂} ≤ d_min^{H₁}，故 t*_viol(H₂) ≤ t*_viol(H₁)。即增大预测视界只会更早（或同时）报警，不会更晚。证明：min 在更大集合上取，值单调不增；t*_viol 为首次低于阈值的时刻，集合越大首达时刻越早。因此用 H₂ 做证书不会漏报，只会更保守。这正是「预测触发」可以安全替代「瞬时触发」的基础。

**引理 83（LIPM 捕获有界性）** 在 LIPM 下 ξ̇ = ω(ξ − p_zmp)。若存在可行步序使 p_zmp(t) ∈ P_S(σ(t)) 且 m_zmp(t) ≥ τ_zmp > 0 对 t∈[0,T] 成立，并假设步序由 R_f 生成，则 ξ(t) 在 [0,T] 内有界，且 m_dcm ≥ τ_dcm 时存在下一步落足使其继续有界。证明：将 ξ 的动力学视为一阶稳定系统，p_zmp 为有界输入；支撑多边形紧致 ⇒ p_zmp 有界 ⇒ ξ 有界（输入-状态稳定性）。m_dcm > 0 保证 ξ 位于可捕获域内，R_f 的定义恰给出可继续的落足点。证毕。

**引理 84（接触锥无滑无倾）** 在准静态假设下，若每个接触点的力旋量满足 f_n ≥ 0、‖f_t‖ ≤ μ f_n 且 CoP ∈ P_foot，则接触不发生滑动与绕边倾覆。证明：摩擦锥约束直接给出切向力上界（库仑摩擦），CoP 在足底多边形内等价于法向合力矩不越过支撑边，故无倾覆。ρ_cwc ≤ 0 是该合取的等价残差形式。

**引理 85（相位无空洞）** 定义安全包络 E(σ) 为相位 σ 的激活约束集，并规定每次相位切换先检查 E(σ_prev) 再检查 E(σ_next)。若对每个 t 至少有一个相位约束被评估，且切换时刻两相位约束都被评估，则不存在「soft 通过而 hard 失败」的时间空洞。证明：反设存在空洞区间 (a,b)，其间无任何约束被评估；由相位函数 σ(t) 的完备性（DS/LS/RS/FLIGHT 覆盖全周期）与边界双检，该区间必属于某相位，矛盾。故激活集在时间上覆盖 [0,T]。

**引理 86（棘轮安全支配）** 记 V_i(τ) = {s : metric_i(s) 违背阈值 τ}。对安全层 i，OWSR 保证 τᵢ(t) ≥ τᵢ(0)（τ 越大越严），于是 V_i(τᵢ(t)) ⊇ V_i(τᵢ(0))。因此在线自适应只会扩大（或保持）报警集，绝不会缩小。特别地，v8 DA-OTL 若因 Δ_dom 误估而放松 τᵢ 的情形被机制性排除。证明：阈值单调不减 ⇒ 违背判据单调更严 ⇒ 违背集合单调包含。证毕。

**引理 87（预测退化可靠性）** 若触发 Level-2 时 π_stop 的证书满足 d_min^H(π_stop) ≥ τ_clear + Δ_stop 且 ρ_kin ≤ 0，则切换到 π_stop 后系统在 [0, T_val(π_stop)] 内保持可行，且不进入不可行状态。证明：由定义 546 的离线验证与定义 535 的有效视界，π_stop 在视界内清障与运动学均满足；切换时刻状态相同（轨迹拼接连续），故后续可行。Δ_stop 吸收切换延迟与状态估计误差。

**引理 88（多速率非干扰）** 若三环满足 Σ_i C_i/T_i ≤ U_max < 1，且跨环只传递不可变证书快照（无锁、无写回），则各环的最坏执行时间 C_i 不受其他环影响，内环 1kHz 截止期可保持。证明：只读共享消除优先级反转与锁竞争；固定优先级速率单调调度下，利用率条件给出可调度性充分条件。证书快照的原子发布保证读者永远看到完整版本（要么旧、要么新），不会撕裂。

**引理 89（证书-稳定性时间轴一致性）** 因 π 与落足序列 F 共享同一时间参数化，Cert_path 的 t*_viol 与 M_leg 的相位时刻 t_k 在同一时钟下定义；若 f_{k+1} ∉ R_f(f_k)，则 t*_viol ≤ t_k（在 t_k 处即触发），故不会出现「路径证书说可行、落足却在 t_k 不可达」的错位。证明：R_f 是该时刻的可行性判据，其否定直接进入定义 536 的 t*_viol 取最小；时间轴共享保证比较有意义。
