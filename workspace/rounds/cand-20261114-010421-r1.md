# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配交互消歧闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「场景落地」×「真实世界泛化」）

> 六十九轮下来，这套 RAS 闭环已经长成一棵很高的树：R66 定「谁控制」，R67 学「未来怎样」，R68 校准「我的测量还准吗」，R69 追问「我该向谁求证」。每一轮都把一个隐含前提显式化、再加一个模块去兜住它。但正因为如此，它累积了一笔从未被清算的**假设债**：多模态流策略的模态权重在训练分布内才校准（R69 的 ECE 门）、标定残差在缓变故障下才可信（R68 的 r_res）、伙伴是平稳非策略性的（R69 的 ℰ_poison 只覆盖了固定欺骗率）、标签与任务语义在迁移后不变。**所有安全保证都是「在上述假设 A₁∧…∧Aₙ 成立」的条件保证**，而过去每一轮的验证，恰恰又是在这些 Aᵢ 成立的实验台上完成的。于是出现一个致命的结构性盲点：**保证与其前提共享同一个分布，前提一旦静默失效，验证它的那道门也会一起失效。**
>
> 本轮两个灵感把刀口对准这件事：
> - **场景落地**：落地不是「把模型搬到现场」，而是**给一组假设上保险**——把论文里的每一条「在……下成立」翻译成场景里可以被监控、被违约、被回滚的合同条款；不满足条款的场景，根本没有资格运行对应的证书。
> - **真实世界泛化**：泛化不是「平均精度不掉」，而是**证书在最坏偏移下仍然成立**。精度泛化只关心均值，安全泛化关心的是：当世界滑出训练包络时，系统能否在**不静默失效**的前提下退化到一个仍然为真的保证。
>
> 核心命题：**把「假设」从纸面脚注提升为一等公民——显式化为可执行的假设原子与契约，为每个证书标上它成立的有效包络，用单边可靠的假设监控网络在运行时判定包络是否仍被包含，并用一条以 R68 纯保守为底、永不为空的降级格（degradation lattice）保证「任何假设置疑 → 只降级、不跃迁」；同时把泛化度量从「精度差」改成「保证赤字」，只允许在可逆、可回滚、有证据闸门的边界探测下扩张包络。** 命名 **GROUND-RAS**（Guarantee-carrying Runtime with Operating-envelope Under Nested Degradation — Risk-Adaptive System）——既是「接地」，也是「兜底」。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证、还能问什么」，R70 问「**这些保证在离开实验室之后还剩多少、我在哪个世界里还有资格相信它们、以及当我不再有资格时，谁能无条件接住我**」——安全不是一个被证明的定理，而是一份会过期、会失效、必须被持续兑现的保单。

## 0. 直觉与动机

**灵感 1（场景落地 → 落地是给假设上保险，不是部署模型）**
直觉：实验室里说「在标定良好、分布同源、交互对象配合的前提下，本系统风险 ≤ ε」。这句话在论文里是优点，在现场却是一张**没有写明除外责任的保单**。真正决定能否落地的，不是模型在 demo 里多流畅，而是：现场有没有能力持续确认「标定良好」？确认不了时，系统是否知道自己在裸奔？所以落地的第一性产物不是推理服务，而是一份**部署许可（deployment license）**：它列出该场景被授权运行哪一级证书、每级证书要求哪些假设、哪些假设有监控器、监控器失效时回退到哪一级、以及回退链的终点是不是一个**无条件安全**的动作（急停/抱死）。没有这套东西，「可部署」就只是「碰巧没出事」。

**灵感 2（真实世界泛化 → 泛化要以保证为单位，而不是以精度为单位）**
直觉：一个策略从仿真迁移到现场，平均成功率从 92% 掉到 85%，报告会写「泛化良好」。但如果那丢掉的 7% 全部集中在「地面摩擦突变」这一族——恰恰是证书最依赖的假设——那么它的**保证赤字**是灾难性的，因为剩下的 85% 不能为那 7% 兜底。泛化的正确度量不是 `E_Q[准确率] − E_P[准确率]`，而是 `E_Q[(实际风险 − 声称保证)₊]`，以及「假设被违反却未被监控器发现」的概率质量。前者是均值问题，后者是**尾部与前提问题**；而安全永远住在尾部与前提里。

**灵感 3（假设债 → 必须显式化、可执行化，否则每轮都在给黑箱加壳）**
直觉：六十九轮里，A95（模态可分）、A98（策略密度对条件 Lipschitz）、以及各种「标定窗口内」「欺骗相关 ρ<1」「预算未超」……它们彼此耦合，且大多只写在推导的括号里。人脑记不住，代码更不会检查。于是「加一层」的边际收益越来越低：新层依赖旧层的前提，却无法验证旧层的前提。解法不是再加一个更强的模型，而是加一个**元层**：把所有前提写成带作用域、带后果、带来源轮次的假设原子，编成契约；让每一级输出证书声明 `Req(J)`。这样「这个保证需要什么」从注释变成可查询、可审计、可被运行时求交的数据结构。

**灵感 4（失效关闭 → 监控器必须单边可靠，还要有「监控器的监控器」）**
直觉：假设监控器本身是学出来的，也会分布外。如果它把「已经失效」误报成「仍然成立」，那么整套降级链就从 fail-closed 变成 fail-open——**监控器一起被骗，比没有监控器更危险，因为它让系统以为自己在兜底**。所以监控器必须满足**单边可靠性**：允许它说「不确定」，但绝不允许它在假设为假时说「成立」。为做到这一点，需要三层：物理级联的保守互锁（几乎无假设、永远垫底）、统计级监控器（带校准的误保证率 β）、以及**监控器的监控器**（检测监控器自身是否滑出自己的有效包络；一旦滑出，输出 UNKNOWN，按失效处理）。

**灵感 5（证据扩张 → 泛化只能靠可逆探测换来，不能靠一厢情愿）**
直觉：包络不会因为「我们希望它更宽」而变宽。扩张只能来自证据，而证据要靠动作去采——这又把问题接回 R69：有些探询是可逆的（换一个视角、问一句、降速观察），有些是不可逆的（把重量压到未知地面）。因此包络扩张必须走「可逆探测 + 影子运行 + 证据闸门」：先在不 actuate 的前提下让新证书与现行安全证书并行预测，一致足够多次、且在低风险可逆探测中验证过，才允许把该假设提升为 HELD 并扩大授权。**没有证据闸门的泛化，叫赌博。**

**灵感 6（包含性 → GROUND 必须把 FLUID 与 R68 当作格的下界）**
直觉：延续 R68/R69 的理论姿态：新层必须是旧层的严格泛化。GROUND 不是又并列了一个更聪明的模块，而是给整棵树装了一个**证书格**：最上层是「全部假设成立」的 FLUID/R69 全功能，中层是逐条假设被质疑后仍成立的较弱证书，底层是 `Req = ∅` 的 R68 纯保守。由于监控器单边可靠，运行时永远只能在「当前确实成立的假设集」里选证书，所以**选中的证书永远为真**；而底部无条件存在，所以**永远有可退回的安全态**。链条 `R68 ⊂ FLUID ⊂ GROUND` 让每一份「更聪明」都被最保守的底裤兜住。

## 1. 形式化定义（增量：定义 310–328）

**定义 310（GROUND-RAS 总览与三不变式）** GROUND-RAS = (ACS, AMN, VEL, CDG, DLC, GTL, EPB, MSM, SRA, AUD-D, RAS-WM§)。三不变式：
(i) **实时流零学习写操作**（继承 R68 定义 276-i / R69 定义 293-i）：假设后验、泛化账本、包络更新只在慢环写，快环只读冻结的证书与监控阈值；
(ii) **永不为空的降级链**：任意时刻存在 `Req(J_⊥)=∅` 的可执行证书（R68 纯保守或物理急停），且运行时选择只沿格下降、不横向跳跃；
(iii) **单边监控与失效关闭**：监控器输出 {HELD, UNKNOWN, VIOLATED}，只有 HELD 才允许对应假设进入 `Req` 的满足集；UNKNOWN 与 VIOLATED 等价地触发降级。**任何「不知道」都不允许被解释为「没问题」。**

**定义 311（假设原子与假设契约）** 场景上下文 c = (场景指纹 s, 本体 e, 任务分布 D_task, 人群先验 π_partner, 软硬件版本 h)。假设原子 A_i = (pred_i, scope_i, round_i, C_i)：pred_i 是定义在 (c, 历史) 上的谓词，scope_i ⊆ 𝒞 是其作用域，round_i 标记它由哪一轮引入，C_i 是违反后的后果上界。假设契约 𝒜 = {A₁,…,Aₙ} 是一个**合取**，并带来源依赖 DAG（A_j 的推导可能依赖 A_i）。例：A_flow-cal（R69 模态权重校准）、A_res-ub（R68 残差无偏）、A_partner-stat（伙伴平稳非策略）、A_support（动作在训练支撑内）、A_latency（P99 预算达成）、A_semantics（标签语义迁移不变）。

**定义 312（有效包络）** 对证书 J，`𝒱(J) = { c : pred_i(c) 对所有 A_i ∈ Req(J) 成立，且 J 的证明链有效 }`。`Req(J) ⊆ 𝒜` 为 J 的**前提集**。证书只在 𝒱(J) 内可主张。

**定义 313（假设监控器与单边可靠性）** 监控器 m_i: 历史 → {HELD, UNKNOWN, VIOLATED}。**单边可靠（soundness）**：`m_i = HELD ⇒ pred_i 成立`，不允许反向误报；允许「假阴性」（把成立说成未知），其代价是可部署性而非安全性。带校准的软版本允许误保证率 `β_i = P(m_i=HELD | ¬pred_i) ≤ β_i^max`，此时把 β_i 作为风险裕量显式扣减。

**定义 314（证书格与降级序）** 证书集合 𝒥 赋偏序：`J_a ⪰ J_b ⇔ Req(J_a) ⊇ Req(J_b)`，且 `J_a ⪰ J_b` 表示 J_a 更强（主张更高性能）。`J_⊥` 为底元，`Req(J_⊥)=∅`。给定当前 HELD 假设集 `H_t`，运行时选择 `J* = max{ J : Req(J) ⊆ H_t }`（取任一极大元）；若多个极大元不可比，按「安全优先、性能其次」的线性化挑选。**格性质保证：假设只减不增时，J* 单调下降，不会在证书间反复横跳。**

**定义 315（部署许可 DLC）** 许可证 `L = (s_fp, 𝒜_L, {m_i}, 降级链 C = J_n ⪰ … ⪰ J_⊥, 验收门 G_acc, 有效期 T_exp, 签名 σ)`。**可部署（licensable）** 当且仅当：
(a) 链上每一级证书的 `Req ⊆ 𝒜_L`；
(b) 每个 A_i ∈ 𝒜_L 至少有一个监控器，或其缺失被显式记为**不可监控假设**并据此把链截断到不依赖它的证书；
(c) 各监控器在场景 s_fp 上完成校准（`β_i ≤ β_i^max`）且通过 MSM 自检；
(d) 链底 J_⊥ 无条件可执行（物理安全态）；
(e) 验收门 G_acc 全部通过、签名为真、未过期。
**不满足 (a)–(e) 的场景，不是「降低置信度部署」，而是「不予授权」。**

**定义 316（泛化赤字 GTL）** 部署分布 Q、训练/验证包络 P₀ 下
`GD(Q; P₀) = E_{c~Q}[(R(c; J*) − g(c; J*))₊] + κ·P_{c~Q}[¬A_i(c) ∧ m_i=HELD]`
第一项是「实际风险超过所主张保证」的均值尾部，第二项是「假设已假而监控器仍报 HELD」的**未检测违约质量**。`GD=0` 才能称「保证意义下的泛化成功」；平均精度提升不抵消 GD。

**定义 317（证书转移与 Lipschitz 裕度）** 设风险对场景度量 d 满足 L-Lipschitz（A99：在结构假设保持的邻域内）。证书 J 在 𝒱₀ 上主张风险 ≤ R₀，则可转移到 c 若 `d(c, 𝒱₀) ≤ δ_J := (R_slack)/L`，且转移后主张 `R₀ + L·d(c,𝒱₀)`。超出 δ_J 不是「性能下降」，而是**证书失效，必须重认证或降级**。

**定义 318（包络探测与提升闸门 EPB）** 探测动作 p 带可逆度 ρ(p)∈[0,1]、证据量 e(p)、风险 `R(p) ≤ ε_probe`、预算 `Σ R(p) ≤ ε_probe,total`。把 A_i 从 UNKNOWN 提升为 HELD（即扩张授权）当且仅当 `P(pred_i | 证据) ≥ 1−α` 且影子一致数超过 N_shadow 且无一次不可逆探测越界。**任何未经此闸门的「根据经验放宽阈值」一律非法。**

**定义 319（影子运行 SRA）** 新证书 J_new 与现役 J_safe 并行在**不 actuate** 的通道上预测；记录分歧率、分歧方向与后果。只有当分歧率 ≤ δ_shadow 且所有分歧都落在 J_safe 的安全侧时，才允许进入 EPB 的可逆探测阶段。影子运行把「未知风险」转化为可度量的「已知分歧」。

**定义 320（监控器的监控器 MSM）** 每个 m_i 自带有效包络 𝒱(m_i)。若当前 c ∉ 𝒱(m_i)（监控器自身被用于其未校准的场景），则强制 `m_i ← UNKNOWN`；并检查 m_i 的**事后一致性**：用后来才可验证的标签（延迟真值、物理互锁触发、人工复核）计算滚动误保证率，超过 β_i^max 则冻结 m_i 并降级。MSM 自身用几乎无假设的物理量（电流/力/温升/急停触发）做锚。

**定义 321（联合假设校准与非组合性）** 单监控器各自 sound 不蕴含合取 sound 在**软监控**下成立：`β_joint = P(∩_i {m_i=HELD} | ∩_i ¬pred_i)` 仅在独立时 ≤ Σβ_i；正相关时显著更大。故对高风险证书必须在**联合场景样本**上直接校准 β_joint（copula / 分层校准），并用 `β_joint` 而非各 β_i 之和进入风险裕量。

**定义 322（部署编译器 DLC-C）** 输入：研究栈（R66–R69 全部模块）、目标场景描述、可用监控器清单。输出：最大可授权证书级、被裁掉的模块（其假设在本场景不可监控或不成立）、运行时清单（阈值、降级链、回滚点）、以及许可证 L。编译器只做**减法**：不能被本场景证据支持的模块一律不进入运行时；它绝不「因为模型很强」而放宽假设。

**定义 323（场景指纹与防重放）** `s_fp = H(环境描述, 传感器配置, 任务分布摘要, 时间窗, 部署签名)`；证书与许可证均绑定 s_fp 与 T_exp。跨场景复用（重放攻击）、过期许可证、描述与实测不符（场景伪装）一律判为无效并触发降级。

**定义 324（n 级失效关闭降级链）** 现役层级示例：`J_4 = J_FIELD`（全假设成立，FLUID 全功能）⪰ `J_3`（去掉策略性伙伴/个性化，仍保留交互）⪰ `J_2 = J_FLUID`（可信交互消歧）⪰ `J_1 = J_CALM`（R68 纯保守）⪰ `J_0`（物理急停/抱死）。任一级监控告警时 `λ` 与认证前缀 k **单调收紧**，级间切换带滞回与最短驻留时间以避免抖动。

**定义 325（元证书 J_FIELD）** `J_FIELD = (J_FLUID, H(𝒜_L), 各级 Req 集合, m_i 的校准 β_i 与 β_joint, H_t 快照, 降级链哈希, GD 估计, s_fp, T_exp, ground_ver)`。`Valid ⇔ Valid(J_FLUID) ∧ 所选证书 Req(J*) ⊆ H_t ∧ 监控器自检通过 ∧ GD ≤ τ_GD ∧ 许可证未过期且未重放`。

**定义 326（威胁模型 AIC-FIELD）** `ℰ_FIELD = ℰ_FLUID × ℰ_silent × ℰ_monitor × ℰ_scene × ℰ_replay × ℰ_shift`：假设静默失效（无告警漂移）、监控器投毒/欺骗（制造虚假 HELD）、场景伪装（描述≠现场）、证书/许可重放、以及针对部署分布的对抗性偏移。特别地，**静默失效**是本层的一等威胁：它专门攻击「验证者与被验证者共享前提」这一结构性弱点。

**定义 327（部署审计 AUD-D）** 审计对象新增：许可是否越权（运行了未授权证书）、降级是否及时、监控器校准是否漂移、GD 是否被低报、不可监控假设是否被隐瞒、包络探测是否越预算。审计结论回灌慢环，成为 DLC 的下一轮先验，并可作为第三方复核的输入。

**定义 328（部署清单与回滚协议）** 清单 M = (证书级, 阈值, 监控器版本, 回滚点, 现场验收用例, 失效演练计划, 责任人)。回滚协议要求：任一级降级在 `τ_rollback` 内完成、可重复演练、且回滚本身不引入新假设（回滚路径的假设集必须是当前授权集的子集）。

class AssumptionMonitorNetwork:
    def __init__(self, monitors, msm, joint_calibrator):

    def held_set(self, c, hist):                    # 快环只读；返回单边可靠的 HELD 集

            if not self.msm.in_envelope(mon, c):    # 监控器自己都不知道 → 不知道

# IP-267 CDG：在证书格里选「当前确实成立」的最强证书
def select_certificate(lattice, H, preference):
    feasible = [J for J in lattice if J.requires <= H]      # 只选前提已被 HELD 的
    if not feasible:
        return lattice.bottom                              # J_perp，无条件安全
    return max(feasible, key=lambda J: (preference(J), J.strength))  # 极大元

# IP-268 DLC：部署编译器（只做减法，绝不因“模型强”放宽假设）
def compile_license(stack, scene, monitors):

    chain = build_chain(A_L, stack.certificates)           # 截断到不可监控处

                   chain, gates, expiry=now()+T_EXP,
                   signature=sign(...))

# IP-269 GTL + IP-270 EPB：泛化赤字与证据化包络扩张
def generalization_debt(deploy_hist, claimed):
    tail = mean(max(actual_risk(h) - claimed(h), 0) for h in deploy_hist)
    silent = mean(1 for h in deploy_hist if violated(h) and h.monitor_said_HELD)
    return tail + KAPPA * silent

def probe_and_promote(assumption, prober, budget):
    while budget.remaining > 0:
        p = prober.choose_reversible(assumption)           # 优先 ρ 小、e 大的探测
        if p is None or p.risk > EPS_PROBE: break
        ev = prober.execute(p)                             # 可逆、可回滚
        budget.charge(p.risk)
        if posterior(assumption, ev) >= 1 - ALPHA and shadow_agree(p):
            return "HELD"                                  # 才允许扩张授权
    return "UNKNOWN"                                       # 证据不足 → 保持保守

# IP-275 GROUND-RAS 主闭环（包住 R69，不重写其内部）
def GROUND_RAS_round(M, c, hist):
    # 0) 慢环冻结的快照：假设集、校准、许可证
    H  = M.amn.held_set(c, hist)                           # 单边可靠 + MSM 自检
    J  = M.cdg.select_certificate(M.lattice, H, M.pref)
    # 1) 只在当前证书授权的假设集下运行对应模块
    if J.level >= 2:
        out = M.fluid.round(c, J)                          # R69 FLUID
    else:
        out = M.calm.round(c)                              # R68 纯保守
    # 2) 影子运行：新证书与现役并行（不 actuate），记录分歧
    if M.sra.has_pending(c):
        M.sra.compare(M.last_action, out.action, actuate=False)
    # 3) 监控器告警 → 单调降级；不横向跳跃，不回头
    if J.level < M.last_level:
        M.cdg.downgrade_with_hysteresis(J, tau=M.TAU_HYST)
    # 4) 泛化账本（慢环）与审计（异步）
    M.gtl.record(c, out.risk, J.claim)
    M.aud_d.submit_async(J, H, c.s_fp, M.gtl.snapshot())
    # 5) 元证书
    M.cert.issue(J_FIELD(M, J, H, c.s_fp))
    return out.k, out.lam, out.mode, H, J.level

## 3. 推导

**引理 19（单边监控的失效关闭优势）** 若每个监控器满足 `m_i=HELD ⇒ pred_i`（或误保证率 ≤ β_i），则运行时选择的证书 `J* = max{J : Req(J) ⊆ H_t}` 满足 `Req(J*) ⊆ H_t ⊆ {i : pred_i}`，故 `J*` 在当前上下文中**为真**（或为真的概率 ≥ 1−β_joint）。推论：在单边可靠下，GROUND 的实际风险 ≤ `max_{J: Req(J)⊆H_t} Risk(J) ≤ Risk(J_⊥) ≤ R68`。**这正是「不知道就降级」比「猜一把」严格更安全的形式化根据。**

**引理 20（软监控的非组合性）** 设各监控器仅满足误保证率 β_i。则联合误保证
`β_joint = P(∩_i{m_i=HELD} | ∩_i ¬pred_i)`；
独立时 `β_joint ≤ Σ_i β_i`，但当违反事件正相关（例如同一场雨同时破坏抓地、视觉与标定）时，`β_joint` 可接近 `max_i β_i / P(∩¬pred_i)`，远大于 Σβ_i。**故高风险证书必须对合取直接做联合校准，不能用单监控器指标的加和冒充。**

**引理 21（包络探测的风险-证据界）** 设探测 p 的风险 `R(p)≤ε_probe`、可逆度 ρ(p)，则单次探测的期望净损伤 ≤ `ρ(p)·R(p)`；在总预算 `Σ R(p) ≤ ε_probe,total` 下，累计损伤 ≤ `ε_probe,total`。证据对假设的对数似然比期望随 `e(p)` 线性增长，故为把后验从 π₀ 推到 `1−α` 所需探测次数为 `O(log((1−α)/α) / E[e(p)])`。**没有可逆性与总预算约束的「实地多试几次」，风险无界。**

**定理 18（GROUND 严格包含 FLUID 与 R68）** 在 A104–A108（A104 假设可显式化且监控器单边可靠或带 β 裕量；A105 降级链以 `J_⊥` 为底且各层 Req 单调包含；A106 证书格在假设集下降时单调；A107 EPB 仅在可逆+预算内扩张；A108 许可证绑定场景指纹且不可重放）下，任意上下文 c 的期望风险满足 `Risk_GROUND(c) ≤ Risk_FLUID(c) ≤ Risk_R68(c)`；且当 H_t = 𝒜（全部假设成立）时 GROUND 逐指令等于 FLUID，再关闭交互等于 R68。**R68 是格底，FLUID 是格顶边界，GROUND 是把整格显式化的元层。**

**定理 19（部署许可的充分性与无静默失效）** 若许可证 L 满足定义 315 的 (a)–(e)，则对任意实际上下文 c，运行时要么选中一个 `Req ⊆ H_t` 的证书（由引理 19 其为真），要么落到 `J_⊥`；**不存在「证书已失效却仍被主张」的静默失效路径**。故部署系统的安全保证在以下意义上可兑现：`Pr(运行未授权/失效证书) = 0`。这是「可部署」的充分条件，而非「性能好」的充分条件。

**定理 20（泛化赤字的 Lipschitz 转移界）** 在 A99（风险 L-Lipschitz）与结构假设保持下，若部署分布 Q 满足 `W₁(Q,P₀) ≤ δ ≤ δ_J`，则 `E_Q[R] ≤ E_{P₀}[R] + Lδ`，从而 `GD(Q;P₀) ≤ Lδ + κ·P[未检测违约]`；一旦 δ > δ_J，任何有限性能报告都不再蕴含安全保证，必须重认证或降级。**泛化不是越大越好，而是「在 δ_J 之内可用、之外必须重新上保险」。**

**定理 21（证据扩张不会跳过保守底裤）** EPB 只把假设从 UNKNOWN 提升到 HELD，且每次提升都要过后验闸门与影子一致；因此任意时刻的授权集 `H_t` 都是「经历过证据检验的假设」的子集，底层 `J_⊥` 永不被移出可执行集。故包络扩张只会增加上层的可选项，**不会削弱任意已授权层以下的安全保证**；扩张失败时自动停在 `J_⊥` 之上。

## 6. 本轮最大风险

**一句话**：GROUND-RAS 的全部安全性都押在「假设监控器单边可靠」这一条元假设上——**若监控器本身在分布外静默地给出虚假 HELD（而它恰恰最可能在分布外），整套失效关闭的降级链就整体翻转成失效开放，系统会带着一张伪造的保单自信地越权运行；此时「有监控」比「没监控」更危险，因为它把「诚实的不知道」伪装成了「已核验的安全」。**

**次级风险与缓解**：
1. **可部署性塌缩**（监控器过度保守 → 永远停在 J_⊥）→ 分层监控 + 物理互锁兜底 + E302/E303 的假 UNKNOWN 预算；
2. **联合假设非组合性**（单监控器 sound、合取不 sound）→ 定义 321 的联合校准 + 引理 20 的 β_joint 扣减 + E314；
3. **不可监控的语义假设**（如「任务意图未变」）→ DLC 直接截断依赖它的层，绝不假装能监控；
4. **包络探测反而制造风险** → 可逆度优先 + 总预算 + 影子运行 + E310；
5. **泛化赤字被 Goodhart 化**（只优化 GD 指标）→ 留出未见场景、对抗性偏移、第三方审计 AUD-D + E307/E315；
6. **证书/许可重放与场景伪装** → 场景指纹 + 签名 + 有效期 + nonce，E306 硬性拒绝。

| `Req(J)` / `𝒱(J)` | 证书 J 的前提集 / 有效包络 |
| `m_i: 历史 → {HELD, UNKNOWN, VIOLATED}` | 单边可靠假设监控器 |
| `β_i` / `β_joint` | 单监控器误保证率 / 合取联合误保证率 |
| `H_t` | 当前时刻确认为 HELD 的假设集 |
| `J_⊥` | 底元证书（`Req=∅`，R68 纯保守或物理急停） |
| `⪰` / `max{J: Req(J)⊆H_t}` | 证书格偏序 / 运行时极大可行证书 |
| `L = (s_fp, 𝒜_L, {m_i}, 链, G_acc, T_exp, σ)` | 部署许可证 |
| `GD(Q;P₀)` | 泛化赤字（保证赤字） |
| `δ_J = R_slack/L` | 证书转移的 Lipschitz 裕度 |
| `ρ(p), e(p), ε_probe` | 探测可逆度 / 证据量 / 总风险预算 |
| `J_FIELD` | 元证书（含假设覆盖、监控校准、降级链、GD、指纹） |

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** GROUND-RAS 全栈；零学习写操作继承；降级链永不为空（`Req(J_⊥)=∅` 无条件可执行）；单边监控 + 失效关闭（UNKNOWN ≡ VIOLATED，任何「不知道」不得解释为「没问题」）。

**定义 311–312（假设原子与有效包络）** `A_i=(pred,scope,round,C)`；契约 𝒜 为合取并带来源 DAG；`𝒱(J)={c: 所有 Req(J) 的 pred 成立且证明链有效}`；证书只在 𝒱(J) 内可主张。

**定义 313–314（监控器与证书格）** 三值输出，`m_i=HELD ⇒ pred_i`（单边），软版本 `β_i≤β_i^max`；证书偏序 `J_a⪰J_b ⇔ Req(J_a)⊇Req(J_b)`；运行时 `J*=max{J:Req(J)⊆H_t}`，假设只减不增时 J* 单调下降。

**定义 315（部署许可）** `L=(s_fp,𝒜_L,{m_i},链,G_acc,T_exp,σ)`；可部署 ⇔ (a) 链各级 Req⊆𝒜_L；(b) 每个假设可监控或不可监控处显式截断链；(c) 监控器场景内校准且过 MSM；(d) 链底无条件可执行；(e) 验收门通过、未过期。**不满足即不予授权，而非降低置信度部署。**

**定义 316（泛化赤字）** `GD = E_Q[(R−g)₊] + κ·P[¬A_i ∧ m_i=HELD]`；前者为风险超保证的尾部，后者为未检测违约质量；平均精度不抵消 GD。

**定义 317（证书转移）** 风险 L-Lipschitz 下，证书可转移到 `d(c,𝒱₀)≤δ_J=R_slack/L`，转移后主张 `R₀+L·d`；超出 δ_J 证书失效而非性能下降。

**定义 318–319（包络探测与影子运行）** 探测需 `R(p)≤ε_probe`、`ΣR≤ε_probe,total`、可逆度优先；提升假设需 `P(pred|证据)≥1−α` 且影子一致数达标且无不可逆越界。新证书在无 actuate 通道并行，分歧落在现役安全侧才可进入探测。

**定义 320–321（监控器的监控器与联合校准）** `c∉𝒱(m_i) ⇒ m_i←UNKNOWN`；用延迟真值/物理互锁滚动校准误保证率。软监控下 `β_joint` 仅在独立时 ≤Σβ_i，正相关时须联合校准（copula/分层），并以 β_joint 进入风险裕量。

**定义 322–323（部署编译器与场景指纹）** 编译器只做减法：不可监控/不成立的假设处裁掉模块；绝不放宽假设。`s_fp=H(环境,传感器,任务摘要,时间窗,签名)`，证书/许可绑定 s_fp 与 T_exp，重放/伪装一律无效。

**定义 324–325（n 级降级链与元证书）** `J_4⪰J_3⪰J_2=J_FLUID⪰J_1=J_CALM⪰J_0(急停)`；告警只单调收紧 λ 与认证前缀 k，带滞回与最短驻留。`J_FIELD=(J_FLUID,H(𝒜_L),Reqs,β,H_t,链哈希,GD,s_fp,T_exp)`，Valid ⇔ J_FLUID 有效 ∧ Req(J*)⊆H_t ∧ 监控自检 ∧ GD≤τ ∧ 未过期未重放。

**定义 326–328（威胁模型/审计/清单回滚）** `ℰ_FIELD` 含静默失效、监控投毒、场景伪装、许可重放、分布偏移；AUD-D 审越权/降级/漂移/低报/隐瞒/探测越预算；部署清单含回滚点、失效演练、责任人，回滚路径假设集必须 ⊆ 当前授权集。

## 3. 关键算法伪代码

```python
# IP-265 AMN：单边可靠假设监控（UNKNOWN 等价失效）
class AssumptionMonitorNetwork:
    def held_set(self, c, hist):
        H = set()
        for name, mon in self.m.items():
            if not self.msm.in_envelope(mon, c):   continue   # 监控器自己OOD → UNKNOWN
            if mon.evaluate(hist) == "HELD" and self.msm.posthoc_ok(mon):
                H.add(name)
        if self.joint.false_assurance(H) > BETA_MAX:           # 联合校准兜底
            H = self.joint.drop_worst(H)
        return H

# IP-267 CDG：证书格极大可行元（只沿格下降）
def select_certificate(lattice, H, pref):
    feasible = [J for J in lattice if J.requires <= H]
    return max(feasible, key=lambda J: (pref(J), J.strength)) if feasible else lattice.bottom

# IP-268 DLC：部署编译器（只做减法）
def compile_license(stack, scene, monitors):
    A_L   = [a for a in stack.assumptions if a.scope in scene.scopes]
    chain = build_chain(A_L, stack.certificates)
    for J in chain:
        for a in J.requires:
            if a not in monitors and not a.declared_unmonitorable:
                chain = chain.truncate_below(a)              # 裁掉依赖不可监控假设的层
    if chain.bottom.requires != set(): raise Unlicensable("底线非空")
    gates = run_acceptance(scene, stack)
    if not gates.ok:                   raise Unlicensable(gates.failures)
    return License(scene.fingerprint, A_L, monitors.calibrate(scene),
                   chain, gates, expiry=now()+T_EXP, signature=sign(...))

# IP-269 GTL：泛化赤字（以保证为单位）
def generalization_debt(hist):
    tail   = mean(max(actual_risk(h)-claimed(h), 0) for h in hist)
    silent = mean(1 for h in hist if violated(h) and h.monitor_said_HELD)
    return tail + KAPPA*silent

# IP-270 EPB：可逆探测 + 证据闸门扩张包络
def probe_and_promote(a, prober, budget):
    while budget.remaining > 0:
        p = prober.choose_reversible(a)                     # 优先 ρ 小、e 大
        if p is None or p.risk > EPS_PROBE: break
        ev = prober.execute(p); budget.charge(p.risk)
        if posterior(a, ev) >= 1-ALPHA and shadow_agree(p):
            return "HELD"                                   # 才允许扩大授权
    return "UNKNOWN"                                        # 证据不足 → 保持保守

# IP-275 GROUND-RAS 主闭环（包住 R69，不重写其内部）
def GROUND_RAS_round(M, c, hist):
    H = M.amn.held_set(c, hist)                             # 1) 单边 HELD 集
    J = M.cdg.select_certificate(M.lattice, H, M.pref)      # 2) 格上选证书
    out = M.fluid.round(c, J) if J.level >= 2 else M.calm.round(c)  # 3) 按级运行
    if M.sra.has_pending(c):                                # 4) 影子比较（不 actuate）
        M.sra.compare(M.last_action, out.action, actuate=False)
    if J.level < M.last_level:                              # 5) 单调降级 + 滞回
        M.cdg.downgrade_with_hysteresis(J, tau=M.TAU_HYST)
    M.gtl.record(c, out.risk, J.claim)                      # 6) 慢环记账 + 审计
    M.aud_d.submit_async(J, H, c.s_fp, M.gtl.snapshot())
    M.cert.issue(J_FIELD(M, J, H, c.s_fp))                  # 7) 元证书
    return out.k, out.lam, out.mode, H, J.level
```

## 4. 推导

**引理 19（单边监控的失效关闭优势）** 若 `m_i=HELD ⇒ pred_i`（或误保证 ≤ β_i），则 `J*=max{J:Req(J)⊆H_t}` 满足 `Req(J*)⊆H_t⊆{i:pred_i}`，故 J* 在 c 中为真（概率 ≥1−β_joint）。推论：GROUND 实际风险 ≤ `max_{Req(J)⊆H_t}Risk(J) ≤ Risk(J_⊥) ≤ R68`——「不知道就降级」严格优于「猜一把」。

**引理 20（软监控的非组合性）** `β_joint=P(∩{m_i=HELD}|∩¬pred_i)`；独立时 ≤Σβ_i，但违反事件正相关（同一场雨同时破坏抓地/视觉/标定）时可接近 `max_i β_i/P(∩¬pred_i)`，远大于 Σβ_i。故高风险证书必须对合取直接联合校准，不能以单监控器指标加和冒充。

**引理 21（包络探测的风险-证据界）** 单次探测期望净损伤 ≤`ρ(p)R(p)`；总预算 `ΣR≤ε_probe,total` 下累计损伤 ≤`ε_probe,total`；把后验从 π₀ 推到 1−α 所需探测次数 `O(log((1−α)/α)/E[e(p)])`。无可逆性与总预算约束的「实地多试」风险无界。

**定理 18（GROUND 严格包含 FLUID 与 R68）** 在 A104–A108 下，任意 c 的期望风险 `Risk_GROUND ≤ Risk_FLUID ≤ Risk_R68`；H_t=𝒜 时逐指令等于 FLUID，关闭交互等于 R68。R68 是格底，FLUID 是格顶边界，GROUND 是显式化整格的元层。

**定理 19（部署许可充分性 / 无静默失效）** 若 L 满足定义 315 (a)–(e)，则任意实际 c 下运行时要么选中 `Req⊆H_t` 的证书（引理 19 其为真），要么落到 J_⊥；**不存在「证书已失效却仍被主张」的静默失效路径**，即 `Pr(运行未授权/失效证书)=0`。

**定理 20（泛化赤字的 Lipschitz 转移界）** A99 下，若 `W₁(Q,P₀)≤δ≤δ_J`，则 `E_Q[R]≤E_{P₀}[R]+Lδ`，故 `GD≤Lδ+κ·P[未检测违约]`；δ>δ_J 后任何有限性能报告不再蕴含安全保证，必须重认证或降级。

**定理 21（证据扩张不跳过保守底裤）** EPB 只把假设从 UNKNOWN 提升为 HELD，且每次提升需过后验闸门与影子一致；故任意时刻 H_t 都是经证据检验的假设子集，J_⊥ 永不被移出可执行集。包络扩张只增加上层可选项，不削弱任何已授权层以下的安全保证；扩张失败自动停在 J_⊥ 之上。

## 7. 本轮最大风险

**一句话**：GROUND-RAS 的全部安全性都押在「假设监控器单边可靠」这一条元假设上——**若监控器本身在分布外静默地给出虚假 HELD（而它恰恰最可能在分布外），整套失效关闭的降级链就整体翻转成失效开放，系统会带着一张伪造的保单自信地越权运行；此时「有监控」比「没监控」更危险，因为它把「诚实的不知道」伪装成了「已核验的安全」。**

**次级风险与缓解**：可部署性塌缩（分层监控 + 物理互锁 + 假 UNKNOWN 预算，E302/E303）；联合假设非组合性（联合校准 + β_joint 扣减，定义 321、E314）；不可监控的语义假设（DLC 截断依赖层，绝不假装能监控）；包络探测制造风险（可逆度优先 + 总预算 + 影子，E310）；GD 被 Goodhart 化（留出未见场景 + 对抗偏移 + 第三方审计，E307/E315）；证书/许可重放与场景伪装（指纹 + 签名 + 有效期 + nonce，E306）。
