# 第 58 轮（承接第 57 轮「少样本×跨模态×个性化」IP-133~138；灵感循环第 2 轮；本轮灵感：「差异化定位」×「多模态大模型」）

> 第 57 轮把安全的赌注从"模型置信"移到"证据质量"，并让 q_φ 摊销先验、让证据按模态分账、让信任按操作者演化。但它仍默认了两个未经检验的前提：**(a)** 元推断必须在一个**封闭标签集**上给出绝对后验——新区域若不属任何已知类，最近邻就会被当成答案；OOD 门只回答"不像任何已知类"，回答不了"它更像谁、差别在哪、该测什么"。**(b)** 语义理解必须由人手设计算特征提供；一旦引入多模态大模型，它的语言先验会自信地编故事，并把多模态证据融合成一个自洽叙事——恰好摧毁第 57 轮"分账对账"的独立性。本轮两个灵感互锁：**差异化定位**把知识从"绝对标签"改为"相对锚点 + 判别轴 + 未定位残留"，并进一步把模型/操作者也按生态位定位；**多模态大模型**不被当作裁判，而被当作**被隔离的差异化假设提议者**——它只提"该测什么来区分"，物理探针才有资格签字。核心命题升级为 **"可定位、可证伪、可拒绝的语义辅助承诺"**：先验只做导航，安全集先验自由；语言只提假设，物理才签合同。

核心矛盾：
- **H29（绝对标签 vs 差异定位）**：绝对后验把"最近"当"正确"，新类被吸入最近原型；标签空间一错，校准再好也只是在错误集合上校准。相对定位能表达"像 A 但不同于 A"，却要求判别轴本身被审计——轴错，则"分得很开"只是错觉。
- **H30（语义流畅 vs 物理证据 / 语言压过传感器）**：多模态大模型能给出流畅解释与自洽的多模态叙事，却可能幻觉、谄媚、被环境文本/二维码注入；若让它定义证据，它会把"没有证据"讲成"证据一致"。语言越强，越需要被剥夺签字权。
- **H31（异构互补 vs 共谋与覆盖空洞）**：多个模型各有所长可降共因误差，但同源模型只是"一个骗子换三套说辞"；按生态位分工又会留下边界空洞与"跨位越权"——在甲地攒的资历，被拿到乙地使用。

## 0. 直觉与动机

**灵感 1（差异化定位 → 从"是什么"到"更像谁、差在哪、怎么区分"）**
直觉：人类专家看新地形，很少直接报绝对类别，而会说"它像湿沙，但反光更像冰；差别在压实层厚度，踩一脚听声音就能分"。这是三层信息：**锚点**（更像谁）、**对比集**（不像谁）、**判别轴 + 测试**（怎么分）。绝对标签丢掉了后两层，而安全恰恰由后两层决定。于是把区域知识表示为**定位集**：一组在统计上仍不可区分的原型（歧义集），加上分离它们的判别轴。承诺不要求"识别出唯一标签"，只要求"歧义集在动作上等价"或"对所有候选都安全"——**定位到动作等价类，而不是定位到名字**。由此得到两个副产品：(i) 原型边界是风险预算的分配器——探针应花在动作相关的边界上，而不是均匀撒；(ii) 新类可以显式地"未定位"，系统绝不强迫最近邻。

**灵感 2（多模态大模型 → 被隔离的差异化假设提议者）**
直觉：大模型最危险的不是"不会"，而是"太会说话"。它能幻觉、会顺着人说（谄媚）、会把环境里的文字/二维码当成指令（注入），还会把视觉/触觉/语言揉成一个自洽故事（融合即抹账）。所以只允许它做三件无签字权的事：提出候选锚点与对比集、提名判别轴、提名**可执行且可证伪的测试**。模型报出的概率一律不进安全集；测试结果只有经物理执行、且测试来自白名单时才入账。模型输出只在一个 KL 球内调整**导航序**（先试哪个假设、先跑哪个探针），绝不改变歧义集成员——即使模型完全错，安全界不变，只是多花探针。

**灵感 3（合流 → 提议—定位—分离—签字 四拍）**
直觉：一次检查点变成四拍：①**提议**（MLA 给差异假设与测试）→②**定位**（DPL 算先验自由的歧义集）→③**分离**（DPX 选对"动作相关候选对"分离度最大的探针）→④**签字**（SEC 检查歧义集是否动作等价/全安全，再过证据门）。若分离度低于阈值，不是"再猜一个"，而是宣布**预算内不可分辨**，转绕行/降档/协商/安全停。探针不再服务于"确认我的标签"，而服务于"拆开我还没分开的两个候选"。

**灵感 4（对第 57 轮三个旧风险的修补）**
直觉：(a) 元语料盲区→歧义集用**先验自由共形**覆盖、新类显式未定位，q_φ 只做导航；(b) EV-xmodal 共谋→把"跨模态"推广到**跨模型异构公会**，只有声明失败模式不相交且有效证人数 K_eff≥2 才算佐证；(c) 个性化→信任也按生态位局部化，某生态位的授权不跨位迁移，防止"在一处攒资历、到另一处滥用"。

## 1. 形式化定义（增量：定义 139–144）

**定义 139（差异定位格 DPL）** 原型库 𝒜={a_i=(z_i,ℓ_i,𝒳_i)}（锚点嵌入/动作标签/已知判别轴）。证据 e 下非一致性分数
s(e|a_i) = −log p̂(e|a_i,r) + λ·u_i(e)，
其中 p̂ 为已校准物理观测模型，u_i 为 a_i 所需判别轴的缺失/超界比例；**s 刻意不含任何语义先验与 q_φ**。用分区域校准集的 s 值得分位 Q_{1−α_pos}，定义歧义集
𝒫_α(r,e) = {a_i : s(e|a_i) ≤ Q_{1−α_pos}(r.cluster)}，
空集或含"无主"标记时记 r 为**未定位**，只许物理证据。动作商 π_Σ:𝒜→Σ（安全动作类）。**已安全定位** ⇔ ∀a∈𝒫_α，拟执行动作在 a 下安全（集合鲁棒），或 π_Σ(𝒫_α) 单点且该动作安全。边界质量 B(r)=Σ_{i<j} w_iw_j·1[|s_i−s_j|≤τ_b]，探针预算 ∝ B。导航序 rank_r 由 q_φ/MLA 给，只用于排序，**不入安全集**。覆盖 P(a\*∈𝒫_α)≥1−α_pos 由共形保证，且**对先验自由**。

**定义 140（多模态大模型提议者 MLA）** 结构化假设 h=(A_h,C_h,d_h,ŷ_h,τ_h,N_h,prov_h)：候选锚点/对比集/判别轴/预测结果格/测试/生态位声明/来源。约束 A_h,C_h⊂𝒜，d_h∈𝒳（已知轴），τ_h∈𝒯_allow（白名单可执行非破坏探针）。隔离规则：(Q1) h 不得直接产生证据，也不得改变 𝒫_α 成员；(Q2) 只允许把导航序在 KL≤ε_llm 球内重加权，ε_llm=ε0·b_h 由该生态位的测试战绩有界更新；(Q3) 只允许提名 τ_h 与排序，测试必须物理执行且结果由观测模型评分；(Q4) 上下文含 `untrusted_text` 时禁用 Q2，且 τ_h 需 ≥2 独立佐证；(Q5) 模型版本更新走影子隔离区。

**定义 141（最大分离探针 DPX）** 对候选探针 q、动作相关候选对 (a,a')（π_Σ 不同），分离度
S(q) = min_{(a,a')} JSD(P_q(·|a), P_q(·|a'))，
其中 P_q 来自**物理探针模型**，禁止模型自报概率进入 S。选 q\*=argmax S(q) s.t. cost(q)≤剩余预算且非破坏；若 max S<θ_sep 返回 UNRESOLVABLE。与第 57 轮共识探针的区别：只针对**动作相关**候选对、用 min 而非 sum、且模型无权提供似然。

**定义 142（异构定位公会 HPG）** 公会 G={M_k,N_k,F_k}：生态位 N_k（覆盖的上下文集）与声明失败模式集 F_k。可咨询集 K(x)={k:x∈N_k}；为空则判 OOD，禁语义导航。一致佐证 ⇔ ∃k,l∈K(x) 使 F_k∩F_l=∅、实测共因相关 ρ_kl≤ρ_max、且有效证人数 K_eff=(Σw)²/Σ_{k,l}w_kw_lρ_kl≥2。分歧时取歧义集**并集**（不投票）；一致只在上述条件下算佐证，且只用于 L1/佐证计数。生态位并集须覆盖部署上下文，否则按 OOD 保守处理；操作者信任同样按生态位局部化（auth(n) 不跨界迁移）。

**定义 143（语义证据契约 SEC）** 证据类：EV-probe\*、**EV-dprobe（新）**、EV-visit、EV-margin、EV-xmodal、EV-human。EV-dprobe ⇔ 物理探针 q 满足 q∈𝒯_allow、S(q)≥θ_sep（对当前动作相关候选对）、结果裕度≥m_min；来源标签 prov∈{human,llm,…}，**来源只影响可用范围，不新增证据类**。门条件：(i) 语言不单独成证——任何仅由模型文本导出的主张不得进入必要证据集；(ii) EV-dprobe 可作 L1 佐证；L2/不可逆仍须 {EV-probe\*∨EV-margin}∪佐证，EV-dprobe 最多算一份佐证，prov=llm 时不得单独计数；(iii) 承诺前须**已安全定位**；(iv) 测试似然必须来自物理模型；(v) J_q=(M_core,…,𝒫_α,boundary_log,rank_log,test_log,prov_log,K_eff,injection_flags)。

**定义 144（定位版探-诺-演 DPC）** 每检查点：①MLA 提议差异假设（有界）；②DPL 算 𝒫_α 与 B(r)；③若已安全定位且证据门过则承诺；否则 ④DPX 选最大分离探针并执行，更新后重定位；⑤预算耗尽或 UNRESOLVABLE → 绕行/降档/L2 协商/安全停；⑥**重定位触发器**：top 锚点翻转或 |s_i−s_j| 跨越阈值，作废该区域缓存承诺并重入循环；⑦**边界巡逻**：B(r)>τ_b 的区域追加 k_d 探针预算。

## 2. 关键算法伪代码（完整版见产物区）

```python
def position_set(M, r, e, lib, alpha):                 # IP-139
    s = {a: -log(physical_likelihood(e, a, r)) + lam*axis_gap(e, a.axes)
         for a in lib.A}                               # 不含 q_phi / MLA 先验
    q = conformal_q(lib.cal[r.cluster], 1 - alpha)
    P = {a for a, sa in s.items() if sa <= q}
    if not P: P = {'__novel__'}                        # 显式未定位，不强制最近邻
    return Position(P, s, nav=M.nav[r])

def mllm_propose(M, r, e, guild, prov):                # IP-140
    k = route_niche(guild, r)                          # 生态位无覆盖 -> 无语义导航
    if k is None: return None
    h = parse(guild[k].infer(structured(e), tools=[]))  # 禁工具、禁动作
    if not schema_ok(h): return None
    h.axes  = [d for d in h.axes  if d in KNOWN_AXES]
    h.tests = [t for t in h.tests if t in ALLOWED_PROBES]
    return h

def dpx_select(P, M, cp, budget):                      # IP-141
    pairs = [(a,b) for a in P for b in P
             if a < b and action_class(a) != action_class(b)]
    if not pairs: return None                           # 动作已等价
    q = max(admissible_probes(cp, M),
            key=lambda q: min(jsd(probe_model(q,a), probe_model(q,b))
                              for a,b in pairs))
    return q if separation(q) >= theta_sep else 'UNRESOLVABLE'
```

## 3. 复杂度与正确性（要点）

| 组件 | 时间 | 空间 | 正确性关键 |
|---|---|---|---|
| DPL | O(\|𝒜\|·d_e)/检查点 | O(\|𝒜\|·\|V\|) | s 不含语义先验、共形覆盖 ≥1−α_pos |
| MLA | O(d_M)/检查点 | O(\|H\|) | 证据零贡献、KL 有界、白名单测试 |
| DPX | O(\|𝒬\|·\|𝒫\|²·d_o) | O(\|𝒫\|²) | 分离度由物理模型给、不可分辨诚实 |
| HPG | O(\|K\|·\|𝒜\|) | O(\|G\|·\|N\|) | 生态位诚实、K_eff 估计误差 ≤ε_K |
| SEC | O(\|σ\|) | O(\|σ\|) | 语言不单独成证、L2 不放宽 |
| DPC | O(\|CP\|·(k_d+k_re)·(\|𝒬\|·\|𝒫\|²+C_VOI)) | O(\|V\|+\|σ\|) | 每检查点探针有界、UNRESOLVABLE 即保守 |

**正确性定理（DPS 概要）**：在 A33–A40 之上加 (A41) DPL 分层共形覆盖 ≥1−α_pos 且判别轴经过审计；(A42) MLA 隔离（不产生证据、不改 𝒫、白名单测试、KL 有界导航、版本隔离）；(A43) 物理探针模型校准，JSD 估计误差 ≤ε_S，不可分辨声明诚实；(A44) HPG 生态位与失败模式声明诚实，ρ 估计误差 ≤ε_K；(A45) SEC 语义不单独成证、L2 必要证据集不放宽。则：
(i) **定位健全性**：放行承诺时 P(safe) ≥ 1−(α_pos+δ_test+δ_probe+δ_f+ε_h)；
(ii) **语言零安全贡献**：对任意 MLA 输出（含幻觉/注入/恶意），只要 A42/A43 成立，安全界不变，MLA 只改变探针数、拒绝率与时延；
(iii) **多样性只买效率**：K_eff 与失败模式独立性只影响 EV-dprobe 的佐证折扣，不进入安全界，共因语义错误不产生升险路径；
(iv) **终止性**：每检查点 ≤k_d 差异探针 + ≤k_re 重定位，UNRESOLVABLE 立即转保守出口；
(v) **部署界**：P_safe ≥ 1−Σ_cp[α_pos+δ_test+δ_probe+δ_f+ε_h]−P(护盾/安全停失效)，**语义项恒为 0**。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"标签先验"换成"判别轴先验"——歧义集与共形覆盖都是**相对原型/轴库**成立的；若危险恰在轴外，拟态地形可沿我们已知的判别轴模仿安全原型，被"合规地"定位进安全类，而模型越流畅越能把轴外差异讲成轴内一致。真正的保底不在语义定位多精细，而在"未定位/轴外"能否被主动探测，以及不可逆接触永不由定位单独签字。

# 第 58 轮产物 · 创新点清单 v34：DiffPosition-MLLM（差异化定位×被隔离的多模态大模型，DPL×MLA×DPX×HPG×SEC×DPC）

### IP-139 DPL（先验自由的差异定位格）

```python
def position_set(M, r, e, lib, alpha_pos):
    # 关键：s 只依赖物理似然与轴缺失度，不吸收 q_phi / MLA 任何先验
    s = {}
    for a in lib.A:
        ll = physical_likelihood(e, a, r, M)          # 已校准观测模型
        u  = axis_gap(e, a.axes)                     # 缺失/超界比例，[0,1]
        s[a] = -log(ll + 1e-12) + lam * u
    q = conformal_quantile(lib.cal[r.cluster], 1 - alpha_pos)
    P = {a for a, sa in s.items() if sa <= q}
    if not P:
        P = {'__novel__'}                            # 显式未定位，禁止最近邻冒充
    nav = navigation_order(M, r, e, lib)             # q_phi/MLA 仅排序
    return Position(P=P, scores=s, nav=nav,
                    B=boundary_mass(P, s, tau_b))

def safely_positioned(pos, action):
    if '__novel__' in pos.P: return False
    return all(action_is_safe(action, a) for a in pos.P)   # 集合鲁棒
    # 或等价：len({action_class(a) for a in pos.P}) == 1 and action_is_safe(action)
```

### IP-140 MLA（被隔离的多模态大模型提议者）

```python
def mllm_propose(M, r, e, guild, prov):
    k = route_niche(guild, r)                        # x in N_k 才可咨询
    if k is None: return None                        # 覆盖空洞 -> 无语义导航
    raw = guild[k].infer(structured_prompt(e), tools=[], act=False)
    h = parse_hypothesis(raw)
    if not schema_ok(h): return None
    h.axes  = [d for d in h.axes  if d in KNOWN_AXES]
    h.tests = [t for t in h.tests if t in ALLOWED_PROBES]
    if 'untrusted_text' in prov:
        h.allow_prior = False                        # 注入上下文禁用先验重加权
        h.min_corrob  = 2
    audit.log(h, prov, t_now); return h

def mllm_shape_navigation(nav, hs, eps_llm):
    if not hs: return nav
    p = nav
    for h in hs:
        if not h.allow_prior: continue
        p = reweight(p, support=h.anchors | h.contrast, w=exp(eps_llm * score(h)))
    return project_kl(p, nav, eps_llm)               # 只改导航序，不改 P

def update_model_budget(b_h, h, outcome):
    # 只有物理执行且结果匹配预测才记正分；错误有界扣分；按生态位独立记账
    b_h[h.N] = clip(b_h[h.N] + eta * (outcome.matches(h.pred) - base), 0, 1)
    return b_h
```

### IP-141 DPX（动作相关的最大分离探针）

```python
def dpx_select(pos, M, cp, budget):
    P = pos.P
    pairs = [(a, b) for a in P for b in P
             if a < b and action_class(a) != action_class(b)]
    if not pairs:
        return None                                  # 歧义集已动作等价
    best, best_S = None, -inf
    for q in admissible_probes(cp, M, F_abs):        # 非破坏性白名单（继承 A34）
        if cost(q) > budget.left: continue
        # 似然只能来自物理探针模型，禁止 MLA 自报
        S = min(jsd(probe_model(q, a), probe_model(q, b))
                for a, b in pairs)
        if S > best_S:
            best, best_S = q, S
    if best_S < theta_sep:
        return ('UNRESOLVABLE', best_S)              # 预算内不可分辨，转保守
    return best

def execute_and_account(M, r, q, h=None):
    o = execute_probe(q, cap=F_abs)
    M = observe(M, r, o)
    if h is not None and q in h.tests and outcome_in(o, h.pred):
        M.prov[r].credit(h.N, q)                     # 记模型战绩，仅影响导航
    return M
```

### IP-142 HPG（异构定位公会）

```python
def guild_consult(guild, M, r, e, libs):
    ks = [k for k in guild if r.ctx in guild[k].niche]
    if not ks:
        return ('OOD', [])                           # 覆盖空洞，禁语义导航
    P = set()
    for k in ks:
        P |= position_set(M, r, e, libs[k], alpha_pos).P   # 分歧取并，不投票
    return ('agree' if len(P) == 1 else 'disagree', ks)

def guild_witness_ok(ks, guild, corr_cal):
    if len(ks) < 2: return False, 1.0
    indep = all(guild[k].F.isdisjoint(guild[l].F)
                for k in ks for l in ks if k != l)
    w = {k: 1.0 for k in ks}
    num = sum(w.values()) ** 2
    den = sum(w[k] * w[l] * corr_cal.get((k, l), 1.0)
              for k in ks for l in ks)
    K_eff = num / max(den, 1e-9)
    return (indep and K_eff >= 2.0), K_eff
```

### IP-143 SEC（语义证据契约 + 定位证书 J_q）

```python
def semantic_evidence_gate(c, M, lib, guild, prov):
    pos = position_set(M, c.r, c.e, lib, alpha_pos)
    # (1) 承诺前必须已安全定位（动作等价或集合鲁棒）
    if not safely_positioned(pos, c.action):
        return ('reject', 'unpositioned', c)
    # (2) 证据类准入
    if c.ev == 'EV-dprobe':
        ok = (c.q in ALLOWED_PROBES and c.separation >= theta_sep
              and c.margin >= M_MIN)
        if c.prov == 'llm' and c.untrusted_only and c.corrob < 2:
            ok = False                               # 注入来源需独立佐证
    elif c.ev == 'EV-probe*':
        ok = c.inf.cls == 'ID' and c.inf.ece_k <= eps_meta(c.k)
    elif c.ev == 'EV-xmodal':
        ok = c.level == 'L1' and c.indep_declared
    elif c.ev == 'EV-human':
        ok = persona[c.op].auth(c.niche) >= 'A1' and \
             c.corrob >= quarantine_exit(persona[c.op].auth(c.niche))
    else:
        ok = round57_or_56_checks(c, M)
    if not ok: return ('reject', 'evidence_insufficient', c)
    # (3) 语言不单独成证；不可逆接触必要集不放宽
    if c.irreversible or c.level == 'L2':
        if c.ev in ('EV-dprobe', 'EV-xmodal') and c.sole_evidence:
            return ('reject', 'semantic_sole_evidence', c)
        if not (c.ev in ('EV-probe*', 'EV-margin')
                or c.has_physical_probe_star_or_margin()):
            return ('reject', 'necessary_set_violation', c)
    return ('ok', c)

def position_certificate_q(sched, M, libs, guild, corr_cal):
```

### IP-144 DPC（定位版探-诺-演）

```python
def differential_probe_commit_evolve(x0, M, task, budget, consent, guild, libs):
    route = plan_on_map(M, task, risk_model)
    sched, log = [], []
    for cp in route.checkpoints:
        r = cp.region
        # ⑦ 边界巡逻：歧义集靠近动作边界则追加差异探针预算
        pos0 = position_set(M, r, M.obs[r], libs[cp.niche], alpha_pos)
        budget.add_dp(k_d if pos0.B > tau_b else 0)
        for _ in range(k_d + k_c):
            prov = provenance(M.obs[r])
            hs = [h for h in (mllm_propose(M, r, M.obs[r], guild, prov),) if h]
            M.nav[r] = mllm_shape_navigation(M.nav[r], hs, eps_llm)
            pos = position_set(M, r, M.obs[r], libs[cp.niche], alpha_pos)
            # ②/③ 定位：先看能否直接安全签字
            g = select_gait(schedule_risk(foothold_schedule(x0, cp, M), M))
            if g != 'halt' and safely_positioned(pos, action_of(cp, g)) \
               and semantic_evidence_gate(core_contact(cp), M,
                                          libs[cp.niche], guild, prov)[0] == 'ok':
                sched.append(commit(sigma_of(cp), g)); log.append(pos); break
            # ④ 分离：只拆动作相关的候选对
            q = dpx_select(pos, M, cp, budget)
            if q is None: break                       # 已动作等价
            if isinstance(q, tuple):                  # UNRESOLVABLE
                break
            M = execute_and_account(M, r, q, hs[0] if hs else None)
            budget.spend(q)
            # ⑥ 重定位触发：top 翻转或分数跨越阈值 -> 作废该区域缓存承诺
            if reposition_trigger(pos, position_set(M, r, M.obs[r], libs[cp.niche],
                                                    alpha_pos)):
                invalidate_commitments(M, r)
            if not budget.probes_left > 0:
                break
        if commit_ready(M, cp, sched) and \
           semantic_evidence_gate(core_contact(cp), M, libs[cp.niche],
                                  guild, provenance(M.obs[r]))[0] == 'ok':
            sched.append(commit(sigma_of(cp), select_gait(
                schedule_risk(foothold_schedule(x0, cp, M), M))))
            continue
        alt = reroute(M, cp, risk_model)
        if alt and select_gait(schedule_risk(alt, M)) != 'halt':
            route = alt; continue
        return negotiate_or_stop(cp, M, consent,
                                 tau_int=tau_int(personas.active.auth(cp.niche)))
    return sched, log, M
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| DPL | O(\|𝒜\|·d_e)/检查点 | O(\|𝒜\|·\|V\|) | s 不含语义先验、分层共形覆盖 ≥1−α_pos（A41） |
| MLA | O(d_M)/检查点 | O(\|H\|) | 证据零贡献、KL 有界导航、白名单测试（A42） |
| DPX | O(\|𝒬\|·\|𝒫\|²·d_o) | O(\|𝒫\|²) | 分离度由物理模型给、不可分辨诚实（A43） |
| HPG | O(\|K\|·\|𝒜\|) | O(\|G\|·\|N\|) | 生态位/失败模式诚实、K_eff 误差 ≤ε_K（A44） |
| SEC | O(\|σ\|) | O(\|σ\|) | 语言不单独成证、L2 不放宽（A45） |
| DPC | O(\|CP\|·(k_d+k_re)·(\|𝒬\|·\|𝒫\|²+C_VOI)) | O(\|V\|+\|σ\|) | 每检查点探针有界、UNRESOLVABLE 即保守 |

**正确性定理（Differential Positional Soundness, DPS）**
在 A33–A40（第 55–57 轮）之上加：**(A41)** DPL 按区域簇分层共形，覆盖 P(a\*∈𝒫_α)≥1−α_pos（先验自由），判别轴经过审计且轴缺失被计入 s；**(A42)** MLA 隔离：不产生证据、不改变 𝒫_α 成员、导航重加权 KL≤ε_llm、测试仅来自 𝒯_allow 且必须物理执行、模型版本走影子隔离区、注入上下文禁用先验重加权；**(A43)** 物理探针模型校准，JSD/分离度估计误差 ≤ε_S，分离度不足时诚实返回 UNRESOLVABLE；**(A44)** HPG 生态位与失败模式声明诚实，共因相关 ρ 估计误差 ≤ε_K，K_eff 仅用于证据折扣；**(A45)** SEC 语义不单独成证，L2/不可逆接触必要证据集不放宽。则：

1. **定位健全性（Positional Soundness）**
   若承诺被放行，则真实行为原型 a\* ∈ 𝒫_α 且动作对 𝒫_α 集合鲁棒（或动作等价），故
   `P(fail) ≤ α_pos + δ_test + δ_probe + δ_f + ε_h`。
2. **语言零安全贡献（Language Monotonicity）**
   对任意 MLA 输出 h（含幻觉、谄媚、注入、恶意），只要 A42/A43 成立，承诺的失效率**不高于**移除 MLA 时；MLA 只改变探针数、拒绝率与时延。形式化：`P_fail(DPC with MLA) = P_fail(DPC without MLA)|_{same physical evidence} + 0`。
3. **多样性只买效率（Diversity-for-Efficiency）**
   HPG 的 K_eff 与失败模式独立性仅降低 EV-dprobe 的佐证折扣；语义共因错误最多导致效率回退与更多拒绝，不进入安全界。
4. **终止性**
   每检查点差异探针 ≤k_d、重定位 ≤k_re、常规探针 ≤k_c；UNRESOLVABLE 立即转 {绕行, 降档, L2 协商, 安全停}。
5. **部署联合界**

```
P_safe ≥ 1 − Σ_cp (α_pos + δ_test + δ_probe + δ_f + ε_h)
             − P(𝓜 陈旧未检出) − P(护盾回退失败) − P(安全停失效)
```

关键结构性结果：**语义项恒为 0**。第 57 轮的"坏先验普遍"在本轮被结构性拆除——q_φ/MLA 再错也不能改变共形集与必要证据集，只能让系统多探、多拒、多绕路。安全的第一性原理从"先验要多准"变成"**歧义集是否动作等价，以及不可分辨时是否肯认输**"。

## 6. 本轮最大风险

**一句话**：本轮把安全赌注从"标签先验"换成"判别轴先验"——歧义集与共形覆盖都是**相对原型/轴库**成立的；若危险恰在轴外，拟态地形可沿我们已知的判别轴模仿安全原型，被"合规地"定位进安全类，而模型越流畅越能把轴外差异讲成轴内一致。真正的保底不在语义定位多精细，而在"未定位/轴外"能否被主动探测，以及不可逆接触永不由定位单独签字。
