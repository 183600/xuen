### 第 6 轮灵感驱动研究记录

**灵感词**：碰撞避免、扩散策略

**继承关系**：第 5 轮 CADVS-v5（IP-493~496）在 v4 七硬门 fail-closed 框架上完成「认证的生成式执行（CGE）」：流匹配提议 FMPP、嵌入记忆与固化 LMEM-v2、面部情感调制 FAMK，执行集 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29。本轮不推翻 v5，而是补 v5 的两个结构性缺口：(a) 提议虽连续化，但仍是近似确定性的单条流，面对多模态接触与动态障碍时多样性不足，且没有利用生成模型在采样过程中的**可微引导**能力；(b) 安全证书中的「碰撞」仍由离散占位/有限采样近似承担，缺连续时间、可证明的几何分离证书，动态障碍更无结构保证。两个灵感词统一为主题「引导式碰撞认证生成」（Guided Collision-Certified Generation, GCCG），形成 CADVS-v6（IP-497~500）。自律不变：**硬门数量不增**（维持七门）——碰撞避免不是新门，而是把 3DCF（覆盖）从离散占位升级为连续 SDF 证书、把 BCK 的 QP 约束集加行（CBF 碰撞约束）；扩散策略替换/包含 FMPP 的提议器接口。执行集嵌套升级为 Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29。

**直觉与动机**：

1. **扩散策略 → 提议从「单条流」升级为「多模态分数场 + 采样时可微引导」**。直觉：流匹配像一条被拉直的传送带，把噪声直接送到动作；扩散策略像一团会分叉的雾，同一观测下可以自然保留「从左边绕」「从右边绕」等多个可行模态，且每个噪声层级都暴露 score ∇_x log p_t(x)，允许在采样过程中施加外部势场引导。形式化：用去噪分数匹配训练 ε_θ(x_t,t|c)，反向概率流 ODE 采样；流匹配是其在 g(t)≡0 的确定性极限下的特例，故 v6 提议类（在共享边缘路径的前提下）严格包含 v5。关键红线：**引导只改提议，不改门**（定理 9 强化 v5 定理 6）。

2. **碰撞避免 → 把「碰撞」从采样近似升级为连续时间可证明的几何证书，并折进既有门**。直觉：离散采样点都不碰，不代表两点之间的连续轨迹不碰；安全必须对「整段时间」成立，而不是对「有限个采样帧」成立。形式化：定义连续时间符号距离 d(t)=min_j SDF_O(p_j(t))−r_j，利用机器人关键点速度给出的 Lipschitz 界 L_d，在子区间 [t_k,t_{k+1}] 上给出下界 min_{t∈[t_k,t_{k+1}]} d(t) ≥ min(d(t_k),d(t_{k+1})) − L_d·Δ/2（保守）；若下界 ≥ r_safe 则整段无碰撞。动态障碍用相对速度 + 到达时间（TOI）做保守包络。该证书替换 3DCF 的离散占位判定，是**同一门的更强判定**（Gate_v6 ⊆ Gate_v5）。BCK 的 QP 追加离散 CBF 行 h(x_{k+1}) ≥ (1−α)h(x_k)，只缩可行域。

3. **把两者接起来：用碰撞势场做采样时引导，用碰撞证书做最终裁决**。引导项 −ζ·∇_x B_coll(x)（或分类器引导 ∇log p(safe|x_t)）把反向扩散轨迹推向高分离区域，显著降低到达硬门前的拒绝率；但**引导不承担正确性**——它只提高「提出好候选」的概率，正确性仍由 3DCF/BCK 的连续证书 fail-closed 裁决。这正好复用 v5 的「提议无关性」：生成器可以任意聪明、任意被引导，信任边界不动。

**关键洞见**：v5 回答「提议可换成任意生成器时证书边界如何不变」；v6 回答「当生成器能在采样中被安全势场主动引导、且碰撞证书必须覆盖连续时间与动态障碍时，如何既享受引导的样本效率、又不让引导污染信任边界」。核心是**分工定理**：引导优化提议（可能改变样本分布、甚至把样本推向门边界），证书判定正确性（固定谓词）；二者通过「门不变 + 阈值只紧 + BCK 约束只加」解耦。碰撞避免因此不是第八道门，而是 3DCF/BCK 的连续化强化；扩散策略不是新锚，而是 FMPP 的提议器超类。

**形式化目标（增量）**：
1. 扩散策略：去噪分数匹配 L_DSM(θ)=E‖ε−ε_θ(√ᾱ_t x_0+√(1−ᾱ_t)ε, t, c)‖²；score s_θ=−ε_θ/√(1−ᾱ_t)；反向概率流 ODE 采样；流匹配为 g(t)≡0 特例。
2. 引导：x ← ODE_step(x) − ζ·∇_x B_coll(x)，0 ≤ ζ ≤ ζ_max，引导只作用于提议分布 π_guided^diff。
3. 连续碰撞证书：d(t)=min_j SDF_O(p_j(t))−r_j；Lipschitz 子区间下界 d_lb；动态障碍 TOI 包络；kc_coll(x)=1[∀k, d_lb(t_k) ≥ r_safe]。
4. 定理 9（引导—提议不变性强化）、定理 10（SDF 连续证书单边可靠性）、定理 11（CBF 约束单调性）、定理 12（扩散-流统一与提议类包含）；引理 45（引导有界扰动与边界密度）、引理 46（SDF 下界保守性）。
5. EFA-v6：七门不变；3DCF 用连续 SDF；BCK 的 QP 追加 CBF 行；DPPK 采样 K 候选 + 引导 + 级联选证。
6. Exec_CADVS-v6 = {x ∈ supp(π_guided^diff) : ∧_i kc_i(x,c; τ_i^5)=1} ⊆ Gate_v6 ⊆ Gate_v5。

**本轮最大风险**：**证书与引导共享同一（学习到的）世界模型，导致「认证」退化为模型自证**——若 SDF/障碍预测与策略同源或同分布训练，引导会把样本推向证书边界，而边界又由同源模型判定，形成生成器—验证器共谋，形式无碰撞而实质未接地；解析 CAD SDF + 保守膨胀 + 独立传感复核 + 未知障碍 fail-closed 急停只能缓解，动态/可变形/未知障碍无解析证书时该风险无法根除。

```python
    """DPPK：多模态扩散提议器。流匹配是 g(t)≡0 的特例。

    K: int = 8

    def dsm_loss(self, batch) -> float:
        x0, c = batch.x1, batch.c
        t = randint(0, self.T, (x0.shape[0],))
        a = alpha_bar(t)[:, None]
        eps = randn_like(x0)
        xt = sqrt(a) * x0 + sqrt(1 - a) * eps
        return mse(self.eps_net(xt, t, c), eps)
```

### IP-498 SCCK：连续时间 SDF 碰撞证书核（折入 3DCF，不新增门）

```python
@dataclass
class SignedDistanceCollisionCertificate:
    """SCCK：连续时间 SDF 证书。可靠性单边：
    绝不把不安全判为安全（定理 10）；过保守可调"""
    sdf: Any                      # 解析 CAD SDF（+ 可选学习残差，需独立复核）
    keypoints: Callable           # q -> {p_j, r_j}
    r_safe: float
    Delta: float = 2e-3           # 2 ms 子区间

    def certify(self, x: Trajectory, obstacles) -> tuple[bool, float]:
        ts = x.sample_times(dt=self.Delta)
        d = [self.dist(t, x, obstacles) for t in ts]
        L = self.lipschitz(x, obstacles)
        d_lb = [min(d[k], d[k + 1]) - L * self.Delta / 2
                for k in range(len(d) - 1)]
        return all(v >= self.r_safe for v in d_lb), min(d_lb)

    def dist(self, t, x, obstacles) -> float:
        return min(self.sdf(o, p) - r
                   for p, r in self.keypoints(x.q(t)) for o in obstacles)

    def lipschitz(self, x, obstacles) -> float:
        v_robot = max_keypoint_speed(x)
        v_obs = max((o.v_max for o in obstacles), default=0.0)
        return v_robot + v_obs + x.accel_bound() * self.Delta
```

动态障碍保守包络（TOI）：

```python
def dynamic_lower_bound(d_k, v_robot, v_obs_max, Delta, L):
    """相对速度 + TOI：把障碍按 v_obs_max·Δ 膨胀后再判分离"""
    return d_k - (v_robot + v_obs_max) * Delta - L * Delta / 2
```

### IP-499 GSS：采样期碰撞引导（仅改提议）

```python
@dataclass
class GuidanceSafetySteering:
    """GSS：碰撞势场引导反向扩散。ζ 有界、早强晚弱；
    不参与裁决，因此无法放宽任何门（定理 9）"""
    zeta_max: float = 0.5
    margin: float = 0.02

    def zeta(self, t):
        return self.zeta_max * (t / self.T)     # 早强晚弱，保护数据流形

    def grad_B(self, x, t):
        # B_coll(x) = hinge(r_safe + margin - d(x))；对关键点解析/自动微分
        return grad(lambda z: hinge(self.r_safe + self.margin - sdf_dist(z)), x)
```

### IP-500 EFA-v6：七硬门 + 连续碰撞证书 + CBF-QP + 引导级联

```python
@dataclass
class EvidenceForgingAssemblerV6:
    """EFA-v6：七硬门不变；3DCF 连续 SDF；BCK 加 CBF 行；引导仅提议侧"""
    dppk: DiffusionPolicyProposalKernel
    scck: SignedDistanceCollisionCertificate
    gss: GuidanceSafetySteering
    v5: EvidenceForgingAssemblerV5

    def select(self, x0_state, t_now, rule_id, context):
        s_emo = self.v5.famk.observe(context.face, t_now)
        gamma = self.v5.famk.gamma(s_emo)
        c = build_ctx(context, s_emo, self.v5.lmem)
        cands = self.dppk.propose(c, guide=self.gss)      # 引导式多模态提议
        # 第 1 层：廉价门 + 连续碰撞证书（3DCF 强化）
        surv = []
        for x in cands:
            ok_coll, d_lb = self.scck.certify(x, context.obstacles)
            if ok_coll and self.v5._cheap_gates(x, gamma):
                surv.append((x, d_lb))
        if not surv:
            return self.v5._fallback_rule_proposal(gamma)  # fail-closed 回退 v5
        # 第 2 层：VACK（≤3，按分离边际排序）
        surv.sort(key=lambda t: t[1], reverse=True)
        finals = [x for x, _ in surv[:3]
                  if self.v5.v4.vack.kc_val(
                      self.v5.v4.vack.evaluate(x, context, t_now),
                      tau=gamma['val'] * TAU_VAL4)]
        # 第 3 层：BCK（原约束 + CBF 行）
        ok = [x for x in finals if self._bck_with_cbf(x, gamma)]
        if not ok:
            return False, None, 'ALL_CANDIDATES_REJECTED'
        return True, max(ok, key=certified_margin), 'FORGED_GCCG'

    def _bck_with_cbf(self, x, gamma) -> bool:
        # 在 BCK 的 QP 中追加：h(x_{k+1}) ≥ (1-α) h(x_k)，h = d - r_safe
        return self.v5.v4.bck.solve_with_extra_rows(
            x, cbf_rows=collision_cbf_rows(x, self.scck), tau=gamma)
```

```
  扩散训练：演示/铸证片段 ──▶ 去噪分数匹配 ε_θ（条件含检索记忆/情绪）
  SDF 构建：CAD 解析 SDF + 保守膨胀；学习残差需独立传感复核后合入
  引导标定：B_coll 的 ζ_max 网格搜索（以门拒绝率与过保守率联合目标）
  继承 v5：LMEM-v2 固化、FAMK 校准、FFA 联邦

在线准入（异步，秒级）：
  FAMK.observe ──▶ γ
  DPPK.propose(K=8, guide=GSS) ──▶ 连续 SDF 证书（3DCF）
       ├─ 全灭 ──▶ fail-closed 回退 v5 规则提议
       └─ 幸存 ≤3 ──▶ VACK ──▶ BCK+CBF ──▶ 取分离边际最大者

在线控制环（目标 ~0.52 ms）：
  EEK(kc_ee) + BCK（事件触发；接触拓扑不变 → 缓存证书 + 解析内插）
  CBF 行只在接触状态变更时重建；否则复用缓存约束矩阵
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|

## 4. 正确性论证（增量更新）

### 引理 45（引导有界扰动与边界密度）

**陈述**：若 B_coll 为 L_B-Lipschitz 且 ‖∇B‖ ≤ G_max，则单步引导位移 ≤ ζ·G_max，整条采样轨迹相对无引导轨迹的偏差 ≤ T·ζ_max·G_max，故 TV(π_guided, π) ≤ T·ζ_max·G_max。但引导把概率质量推向 ∂Gate（d_lb 小处），近边界提议比例随 ζ 上升。∎

**工程含义**：引导是「提议加速器」，不是「安全证明」；ζ 越大越省拒绝，但越需要硬门兜底。

### 引理 46（SDF 下界保守性）

**陈述**：若 d 为 L_d-Lipschitz，则 ∀t∈[t_k,t_{k+1}]，d(t) ≥ min(d_k,d_{k+1}) − L_d·Δ/2 = d_lb(t_k)。过保守幅度 ≤ L_d·Δ/2。∎

**证明**：对任意 t，d(t) ≥ d(t_k) − L_d(t−t_k) 且 d(t) ≥ d(t_{k+1}) − L_d(t_{k+1}−t)，两式取最大后在区间上取下确界即得。∎

### 定理 9（引导—提议不变性）

**陈述**：Gate_v6 是 (x,c) 的固定谓词，不含提议分布 π 与引导算子 G。对任意 G，Exec_v6 = Gate_v6 ∩ supp(π_guided^diff)。又 Gate_v6 ⊆ Gate_v5（3DCF 连续证书更强、BCK 加 CBF 行），故 Exec_v6 ⊆ Exec_v5。∎

**证明**：门是轨迹空间上的固定谓词，换提议/加引导不换谓词；门收紧给出包含。∎

### 定理 10（SDF 连续证书单边可靠性）

**陈述**：在 SDF 与 L_d 正确的前提下，kc_coll(x)=1 ⇒ 轨迹全程与障碍分离 ≥ r_safe。证书无假阴性；假阳性由引理 46 界定。∎

**证明**：由引理 46，每个子区间下界成立，逐段合并即得全程下界。∎

**诚实边界**：若 SDF 是学习近似、L_d 低估、或障碍未被感知，则前提失效，保证不成立。这正是本轮最大风险的结构来源。

### 定理 11（CBF 约束单调性）

**陈述**：BCK 原可行集 F，追加 CBF 行得 F' ⊆ F；投影 P_{F'} 幂等且只删动作；α∈(0,1] 时 h 非减，α→0 退化为硬约束。故 Exec 只缩不涨；不可行则 fail-closed 拒绝。∎

**证明**：可行集对约束单调；投影到子集不会新增点。∎

### 定理 12（扩散-流统一与提议类包含）

**陈述**：同一插值路径下，流匹配 ODE 是扩散概率流 ODE 在 g(t)≡0 的特例；若 DPPK 与 FMPP 共享同一条件与边缘，则 v6 提议类包含 v5。∎

**证明**：Fokker–Planck 方程在 g≡0 时退化为连续性方程，其速度场即流匹配目标场。∎

**诚实边界**：独立训练时包含关系仅在共享边缘路径的前提下成立，不是无条件包含。

### 定理 v6（总装）

**陈述**：在 v5 假设 (B1)~(B7) 及新增 (B8) SDF 与 L_d 正确（或保守）下：
(i) Exec_CADVS-v6 ⊆ Exec_CADVS-v5 ⊆ … ⊆ Exec_v29；
(ii) 引导不变：Exec_v6 = Gate_v6 ∩ supp(π_guided)，引导不改变门谓词（定理 9）；
(iii) 碰撞证书单边可靠：kc_coll=1 ⇒ 无碰撞（定理 10），假阳性由引理 46 界；
(iv) CBF 单调：BCK 加行只缩可行域（定理 11）；
(v) 提议包含：扩散提议类在共享边缘下包含流匹配（定理 12）；
(vi) 七锚完备性保持：碰撞避免折入 3DCF/BCK，不是第八锚。

**证明**：(i) 由 Gate_v6 ⊆ Gate_v5 + 支撑受限；(ii)(iii)(iv)(v) 分别由定理 9、10、11、12；(vi) 锚点集合不变。∎

**诚实声明**：(B8) 在动态/可变形/未知障碍下难以保证；学习 SDF 残差与策略同源时证书会退化；引导把样本推向门边界，硬门的测试分布随之偏移；扩散多步采样延迟高于流匹配。

## 7. 本轮最大风险（最终确认）

**一句话**：**证书与引导共享同一（学习到的）世界模型，导致「认证」退化为模型自证**——引导把样本推向证书边界，而边界又由与策略同源/同分布的 SDF 判定，形成生成器—验证器共谋，形式无碰撞而实质未接地，解析 CAD SDF + 独立传感复核只能缓解、无法根除。
