# 第 10 轮（本轮灵感：「创新点提炼」×「遥操作」）
> **基线**：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮纪律：**遥操作契约化 + 干预即证据 + 可监督性蒸馏**。v9 的最大残余风险是"最需要安全的时刻恰是块证书最不可靠的时刻"；v10 的答案不是造更强的模型，而是引入一个不同时间尺度的资源——人。但人慢、人缺、人只看得见界面上显示的东西。两个灵感合起来治 v9 的三笔残余债：**人机集成债**（遥操作是外部硬编码通道）、**归因证据债**（c_m 依赖离线全因子消融 E559）、**监督盲区债**（人能兜底的范围 ≠ 系统需要兜底的范围）。必须以**遥操作中立元**与**可监督谓词**保证：人缺席时逐位退回 v9，人看不见的模块永不被蒸馏。

## 0. 直觉与动机

**灵感 1（遥操作 → 慢时间尺度上的兜底资源）**
直觉：v9 的残余风险不可能由更快的自主模型消除——"检测到域偏移"必然滞后于"域偏移发生"。但人在场。关键约束：人慢（D_op ~ 100–300ms），故人不能接管**块内突变**（那仍是 AC 中块守卫的事），只能接管**持续性域漂移、任务意图与语义歧义**。核心设计：**遥操作契约（TeleopContract）**把操作员通道作为 MW 契约表中的一等模块 κ_op，其**中立元 v_op^⊥ = "无指令"**；指令老化超过 τ_age 即注入 v^⊥（丢弃而非保持），α=0 严格等价 v9 自主。人不是快安全网，是**慢流形上的权限与效率机制**。

**灵感 2（创新点提炼 → 干预即反事实标签）**
直觉：v9 的 ID 用块级任务分 J 做消融，但"模块该不该留"的黄金信号其实就在操作员手上——每一次接管/纠正，都是对"此刻自主性缺了哪块"的一次稀疏标注。核心创新：**干预归因器（InterventionAttributor, IA）**把干预事件 e_t 当作在线反事实标签，c_m^{op} = P(e|dormant) − P(e|active)。这把 E559 从"离线全因子消融"搬到"在线、分布内、零额外算力"，但引入新的致命偏差：人只对**看得见**的失败出手。

**灵感 3（创新点提炼 → 权限蒸馏与不可监督边界）**
直觉：既然人能提供标签，就该提炼**权限本身**——何时该把 α 交给人类、何时收回自主，即提炼"操作员的注意力该花在哪一段"。核心创新：**权限蒸馏器（AuthorityDistiller, AD）**：交接预测 h(s)=P(干预|s)，带迟滞的权限状态机与 α 回落。最关键的纪律：**P15 不可监督不蒸馏律**——o_m=0（HMI 上不可观察）的模块贡献下界记为 +∞，永不进入 dormant。因为蒸馏信号与人共享同一块 HMI 盲区；若不加此律，系统会系统性地剪掉"自己看不见的安全网"。

## 1. 研究问题（轮次升级版）

- **Q1（遥操作可选性）**：如何把操作员通道编码为带中立元的契约模块，使指令缺失/老化/超时/被拒时，动作路径逐位等价 v9，而非"半接管"的中间态？
- **Q2（干预标签的偏差与安全边界）**：操作员干预作为反事实标签时，其可监督性偏差如何界定？可监督谓词 o_m 与静默失效下界能否保证蒸馏只影响效率、绝不触碰安全不变式？
- **Q3（权限蒸馏的安全边界）**：权限混合在什么算子下保持安全集闭包？交接预测与迟滞能否在慢流形上消除权限抖动与"陈旧指令反转"？

## 2. 设计原则（在 P10–P12 基础上新增 P13–P16）

**P13 遥操作可选律（Teleop-Optional, TO）**
操作员通道是契约模块 κ_op，v_op^⊥ = 无指令；α=0 时动作路径逐位等价 v9。操作员不进入 EDF 临界路径，其超时/缺席不延长控制周期。

**P14 安全保序混合律（Safety-Monotone Blend, SB）**
a = B(a_auto, a_op, α)，B(·,·,0)=a_auto；混合结果必须落在当前认证安全集 S_t 内（M₀ ∧ SpatialCert ∧ 块证书），否则投影回 a_auto。**M₀ 硬检查在混合之后仍独立执行，α 不得绕过任何硬安全**。

**P15 不可监督不蒸馏律（Unsupervisable-Not-Distilled, UD）**
蒸馏资格 = φ^elig(v9) ∧ o_m。o_m=0（其失效在 HMI 上不可观察）⇒ c_m^{op} := +∞，永不 dormant/frozen。静默失效不得被"优化掉"。

**P16 双通道证据律（Dual-Channel Evidence, DE）**
c_m^{total} = max(c_m^{J}, c_m^{op})；两通道分歧（|c^J−c^op|>δ）时取保守（保持 active）。只有一个通道说"没用"不足以下调算力。

## 3. 与基线的接口（如何退化）

- 操作员缺席 / 无指令 / age(a_op) > τ_age ⇒ v_op^⊥ ⇒ α=0 ⇒ 逐位 v9（引理 87）；
- 混合动作未通过 M₀ / SpatialCert / 块证书 ⇒ 投影回 a_auto ⇒ 该周期等价 v9；
- 交接预测失效 ⇒ α 钉 0（不呼叫人类）⇒ v9；
- o_m 未知 ⇒ 视为 0 ⇒ 禁止干预式蒸馏，仅退回 v9 的 J 通道；
- IA/AD 失效 ⇒ c_m^{op}、α 冻结，退回 v9 全模块常开 + 纯自主；
- 全部失效 ⇒ 完整退回 v9 ACMD，再退 v8 → v7 → v6。

## 4. 预期贡献

1. **遥操作契约与中立元**：人机集成从硬编码通道变为可退化契约，人缺席零回退（不是"降级"，是逐位等价）；
2. **干预即反事实标签 + 可监督边界**：在线归因替代离线全因子消融，且把**安全性与归因偏差解耦**——偏差只损失效率，不损失安全；
3. **权限蒸馏**：安全保序混合 + 交接预测 + 迟滞，在慢流形上做共享自主，降低操作员负荷；
4. **时间尺度分离**：明确"块内突变归 AC、快漂移归 DA/SPR、慢语义/意图归遥操作"；E571–E590 覆盖中立元等价、时延扫描、静默失效对抗、混合认证、交接精度、双通道一致性与端到端。

## 5. 本轮最大风险

**一句话**：干预标签与蒸馏信号共享同一块 HMI 盲区——操作员只对界面可见的失败出手，ID 只按可见干预归因，于是系统会系统性地把"人看不见、但真正兜底"的模块判为低贡献并休眠，形成"越蒸馏越盲、越盲越蒸馏"的静默安全网坍缩。

# 第 10 轮产物 · 创新点清单 v10：**MetricVoiceGauge-TOAD**（Metric Voice Gauge with Teleoperation-guided Attribution & Authority Distillation）

> 背景：第 9 轮 MetricVoiceGauge-ACMD（定义 532–539；引理 82–86；实验 E551–E570）。
> 本轮灵感：「创新点提炼」×「遥操作」
> **继承纪律**：MetricVoiceGauge 九不变式（CVC-闭环、SpatialCert、RT-CVC、FaultCert、PrimitiveGraph、严格退化链、OTL、GCT、ER）与 v9 的 AC/MW/ID 全部保留。新增遥操作相关组件一律为**可选增强**：人缺席 / 指令老化 / 混合不可认证 ⇒ 注入中立元 ⇒ **逐位等价 v9**（引理 87），而非"半接管"的行为漂移。

- Level-0（**新增、最外层可选**）：遥操作缺席 / 指令老化 / 混合未认证 ⇒ α=0、v_op^⊥="无指令" ⇒ 逐位 v9；
- Level-1：AC 证书失效或信任域破坏（Δ_dom ≥ τ_dom ∨ risk_SLAM ≥ τ_SLAM）⇒ K_eff←1，逐步执行，等价 v8 决策粒度；
- Level-2：MW 失效 ⇒ 切换 v8 手写网关代码路径，等价 v8 集成方式；

- Level-4：v8 的 DA/SPR/Cal 任一失效 ⇒ 中立元注入（Δ_dom≡0 / risk_SLAM≡0 / sensor_weight≡1），等价 v7；

## 1. 符号体系增量（定义 540–547）

| 符号 | 含义 |
|---|---|
| κ_op = (D_op, τ_age, R_op, v_op^⊥, α_max, o_mask) | 遥操作契约：时延预算、指令老化阈值、速率、中立元、权限上限、可监督掩码 |
| v_op^⊥ = ⊘ | 操作员中立元："无指令"（不是"保持上一指令"） |
| age(a_op) = t − ts(a_op) | 指令年龄；> τ_age 即视为失效 |
| α ∈ [0, α_max] | 操作员权限占比；α=0 = 纯自主（v9） |
| B(a_auto, a_op, α) | 安全保序混合算子，B(·,·,0)=a_auto |
| S_t | 当前认证安全集：M₀ pass ∧ SpatialCert pass ∧（K_eff>1 ⇒ Ĉ valid） |
| e_t ∈ {0,1} | 干预事件：操作员在窗口 W_int 内接管/纠正 |
| c_m^{op}(t) | 干预反事实贡献 EMA：P(e\|dormant) − P(e\|active) |
| o_m(t) ∈ {0,1} | 可监督谓词：模块 m 的失效是否在 HMI 上可被人在 D_hmi 内察觉 |
| h(s) = P(e=1\|s) | 交接预测：当前状态需要人的概率 |
| c_m^{total} | 双通道归因：max(c_m^{J}, c_m^{op})（P16） |

**新增定义 540（遥操作契约 TeleopContract）** 操作员通道作为 MW 契约表的一行 κ_op。与 v9 其他模块不同，它**不进入 EDF 临界路径**（人不可被调度）：其"执行"只是读取最近指令并做年龄检查。运行期：
```
a_op^eff(t) = ⊘                      若无指令 ∨ age(a_op) > τ_age
            = a_op(t)                否则
```
关键设计：老化时注入 ⊘ 而非"保持上一指令"——保持会造成陈旧指令在状态突变后被继续执行，这正是"权限反转"的根源。

**新增定义 541（安全保序混合 Safety-Monotone Blend）** 对 α∈[0,α_max]：
```
a_t = B(a_auto, a_op^eff, α)
B(a, ·, 0) = a                                        # 左中立元：精确 v9
B(a_auto, a_op, α) = Proj_{S_t}( (1−α)·a_auto + α·a_op )
若 Proj 后仍 ∉ S_t 或 a_op^eff = ⊘：返回 a_auto
```
投影半径 ρ(α)=ρ₀·α（权限越大，允许偏离自主轨迹越远，但永不离开认证集）。M₀ 硬检查在混合**之后**独立执行，α 不能绕过硬安全。

**新增定义 542（干预事件与反事实贡献 Intervention-as-Label）** 干预事件 e_t=1 当操作员在 W_int 内接管、纠正或触发急停。对每个 φ^elig 模块维护 dormant/active 两组的干预率 Beta 后验：
```
c_m^{op}(t) = clip( p̂(e=1 | m dormant) − p̂(e=1 | m active), 0, 1 )
```
正贡献 = 模块在场显著降低干预率（即模块真的在兜底）；负值截断为 0。

**新增定义 543（可监督谓词 Observability Predicate）**
```
o_m(t) = 1  若 ∃ HMI 信号（v9 MetricVoice 仪表 / ER 面板）在 D_hmi 内随 m 的失效而可察觉，且灵敏度 ≥ s_min
       = 0  否则（含未知/未标定；保守默认 0）
```
蒸馏资格升级为 φ_m^{elig,v10} = φ_m^{elig,v9} ∧ o_m。

**新增定义 544（静默失效下界 Silent-Failure Floor）** 对 o_m=0：c_m^{op} := +∞。理由：其贡献不可由干预标签估计，任何有限估计都是"看得见的部分"的代理；把不可监督当低贡献，等于用盲区当证据。附带定义静默失效风险 R_silent(m)=P(fail_m | dormant, o_m=0)，视为无上界，禁止以任何统计理由休眠。

**新增定义 545（交接预测与权限状态机 HandoverPredictor & AuthorityFSM）**
```
请求：state=autonomous ∧ h(s)·unc(s) ≥ τ_ho
确认：state=requesting ∧ 操作员有指令（a_op^eff ≠ ⊘）
共享：state=shared，α 线性升到 1
回落：h < τ_ho/2 持续 T_idle ∧ state=shared ⇒ returning，α 线性降到 0
```
α 只在 requesting/returning 斜坡上连续变化，且相邻显著迁移间隔 ≥ τ_dwell。交接预测只**建议** α；安全由 SMB（定义 541）**强制**。

**新增定义 546（意图前推延迟补偿 Intent Forward-Compensation）** 操作员指令滞后 D_op。用 v9 的冻结前向模型 F̂_π 把指令前推到当前时刻：
```
â_op = comp(a_op(t−D_op), D_op; F̂_π)
接受条件：s ∈ U_t（v9 信任域） ∧ ‖â_op − a_op‖ ≤ ρ_comp
否则：不补偿（a_op^eff 直接用原指令，若老化则 ⊘）
```
补偿器失效/超界 ⇒ 退回无补偿 ⇒ 混合仍在 S_t 内被 SMB 保护，最坏退化为 α 生效延迟。

**新增定义 547（双通道归因与蒸馏资格 Dual-Channel Attribution）**
```
c_m^{total} = max( c_m^{J}(v9), c_m^{op} )    若 o_m=1
            = c_m^{J}(v9)                    若 o_m=0（此时 c^op=+∞ 已被 P15 拦截）
```
进入 dormant 的条件除 v9 的 Schmitt 迟滞外，新增：两通道均 < τ_off，或分歧时取 max 后仍 < τ_off。

## 2. 时间尺度分离（本轮的关键边界）

v10 不宣称用遥操作替代快安全。响应下界不同，责任必须分离：

| 时间尺度 | 典型事件 | 负责机制 | 依据 |
|---|---|---|---|
| < 200ms（块内） | 突然出现的障碍、抓取滑移 | **AC 中块守卫**（v9） | 引理 82；人来不及 |
| 200ms–1s（快漂移） | 传感器退化、SLAM 风险上升、域偏移初现 | DA-ML / SPR + K_eff 收缩（v9） | 定义 539 |
| > D_op + τ_dwell（慢流形，~1s+） | 任务意图变更、语义歧义、持续性域漂移、模式切换 | **遥操作权限**（v10） | 定义 540/545 |

因此，遥操作的安全性只对慢流形成立；任何块内安全主张仍由 v9 的 AC/证书承担（引理 91）。

## 3. 形式化定义（要点与升级）

**定义 493（六层指标层级）** 继承 v9：M=(M₀,M₁,M₂,M₃,M_dom,M_SLAM) 不变。
**定义 495/524（MetaWeight/情感，5 维）** 继承 v9 不变。
**定义 521（DA-OTL）** 继承 v9 不变；τᵢ(t) 的块级复核不变。
**升级定义 496（软证书，v10）** δ_trigger 增加遥操作项：
```
δ_trigger = {σ<τ_safe ∧ γ_grasp valid ∧ Δ_dom<τ_dom ∧ risk_SLAM<τ_SLAM
             ∧ Ĉ_t valid ∧ (α·¬cert(a_op^eff) ⇒ α←0)}
```
即操作员拟议动作若不可认证，不是"操作系统拒绝人类"，而是**权限退回 0、人继续以建议形式存在**（混合器不采用该动作）。
**升级定义 531（软硬约束衔接，v10）** M₀ 判据在 `execute(a_cmd)` 之前对**混合后**动作执行；α>0 不构成豁免。块级入口（v9）保持不变。

## 4. 关键算法骨架

```python
# IP-357：遥操作契约通道
@dataclass
class TeleopContract:
    deadline_ms: float = 300.0        # D_op：时延预算（不在 EDF 临界路径）
    max_age_ms: float = 150.0         # τ_age：指令老化阈值
    fail_value: object = NO_COMMAND   # v_op^⊥ = ⊘（无指令，非"保持"）
    priority: int = -1                # 低于一切安全硬检查
    distill_eligible: bool = False

class TeleopContractChannel:
    def __init__(self, contract=TeleopContract()):
        self.c = contract
    def resolve(self, a_op, ts_op, now):
        if a_op is None or (now - ts_op) > self.c.max_age_ms:
            return NO_COMMAND         # 老化即丢弃，防陈旧指令反转
        return a_op


# IP-358：安全保序混合器
class SafetyMonotoneBlender:
    def __init__(self, rho0=0.3):
        self.rho0 = rho0
    def blend(self, a_auto, a_op_eff, alpha, s, cert):
        if alpha <= 0.0 or a_op_eff is NO_COMMAND:
            return a_auto                          # B(a,·,0)=a：精确 v9
        raw = (1 - alpha) * a_auto + alpha * a_op_eff
        a = project(raw, a_auto, radius=self.rho0 * alpha)
        if not cert.ok(s, a):                      # 不在认证安全集 S_t
            return a_auto                          # 拒绝 → 该周期 v9
        return a


# IP-359：干预归因器
class InterventionAttributor:
    def __init__(self, eligible):
        self.eligible = eligible
        self.post = defaultdict(lambda: [1.0, 1.0])  # Beta 先验
    def observe(self, e, dormant_set):
        for m in self.eligible:
            key = (m, m in dormant_set)
            a, b = self.post[key]
            self.post[key] = [a + e, b + (1 - e)]
    def contrib(self, m, o_m):
        if o_m == 0:
            return math.inf                        # P15：静默失效下界
        def mean(k):
            a, b = self.post[k]; return a / (a + b)
        return max(0.0, mean((m, True)) - mean((m, False)))


# IP-360：权限蒸馏器
class AuthorityDistiller:
    def __init__(self, tau_ho=0.6, dwell=30, idle=150):
        self.tau_ho, self.dwell, self.idle = tau_ho, dwell, idle
        self.state, self.t = "autonomous", 0
    def step(self, s, h, unc, op_present):
        if self.state == "autonomous" and h * unc >= self.tau_ho:
            self.state, self.t = "requesting", 0
        elif self.state == "requesting" and op_present:
            self.state, self.t = "shared", 0
        elif self.state == "shared":
            self.t += 1
            if h < self.tau_ho / 2 and self.t > self.idle:
                self.state, self.t = "returning", self.dwell
        elif self.state == "returning":
            self.t -= 1
            if self.t <= 0:
                self.state = "autonomous"
    def alpha(self):
        return {"autonomous": 0.0, "requesting": 0.0,
                "shared": 1.0,
                "returning": max(0.0, self.t / self.dwell)}[self.state]
```

## 5. 推导

**引理 87（遥操作中立元与 v9 逐位等价）** 若 a_op=⊘（缺席或 age>τ_age），则 resolve 返回 v_op^⊥；blender 在 a_op^eff=⊘ 或 α=0 时返回 a_auto；κ_op 不进 EDF 临界路径，且其端口不写入 v9 的任何状态（ctx 中仅新增遥操作专用字段）。故动作序列、时序与可观测日志逐位等于 v9 ACMD。∎

**引理 88（安全保序闭包）** 令 S_t={a : M₀(s,a)=pass ∧ SpatialCert(s,a)=pass ∧ (K_eff>1 ⇒ Ĉ_t valid)}。blender 输出或为 a_auto∈S_t（v9 保证），或为经定义 541 投影且 cert.ok 成立的混合动作∈S_t，否则回退 a_auto。又 M₀ 硬检查在混合后独立执行。故 ∀α∈[0,α_max]：a_cmd∈S_t，α 不扩大不安全可达集；安全性由 v9 引理 82/81 传递。∎

**引理 89（可监督边界：归因偏差与安全解耦）** c_m^{op} 以干预率为代理，会因可监督性偏差高估"显著性"、低估"必要性"。但蒸馏资格限定 φ^elig ∧ o_m；o_m=0 时 c_m^{op}=+∞（定义 544），任何模块进入 dormant 必有 o_m=1，即其失效在 HMI 上可观察。o_m=1 但人漏看时，P16 取 max(c^J,c^{op})、分歧保守。因此归因误差只改变"哪些可监督模块被休眠"（效率），不改变"是否存在不可监督的安全网被剪除"（安全）。休眠态行为∈v9 行为集（v9 引理 84），安全性由 v9 引理 80–81 传递。∎

**引理 90（无陈旧指令反转 / 无权限抖动）** 执行序严格为 resolve（老化→⊘）→ comp → blend → M₀ → execute；老化指令不可能在 ⊘ 注入后仍被混合，故消除"一帧陈旧指令权限反转"。权限 FSM 迁移需 requesting 确认与 shared 的 T_idle，α 仅在 returning 线性回落；相邻显著迁移间隔 ≥ τ_dwell ⇒ 翻转率 ≤ 1/τ_dwell，有限时间迁移次数有限。∎

**引理 91（时间尺度分离的诚实边界）** 遥操作通道响应下界为 D_op + τ_dwell。任何时间尺度小于此下界的安全相关事件，其责任仍在 AC 中块守卫（v9 引理 82），遥操作既不能及时介入，也不被计入安全论证。故 v10 不宣称"以遥操作替代快安全"，只宣称在慢流形上做权限与效率蒸馏；端到端安全仍由 v9 的 AC/M₀ 证书层兜底。∎
