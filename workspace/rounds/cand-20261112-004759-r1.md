# 第 55 轮（承接第 54 轮 v16+++ GroundEdge-GenSim+++；灵感循环第 6 轮；本轮灵感：「VLA」×「视觉定位」）

> 第 54 轮已把技能组合提升为「动作空间剖面 + 云边协同 + 动作-鲁棒性联合证书」。本轮把镜头拉回**语义与度量的接缝**：VLA 用视觉-语言把指令落成动作，视觉定位用地图把观测落成位姿。两者各自都很强，却**互不担保**。核心矛盾：H22：VLA 的动作在语义上「说得通」，但在度量上未被锚定，语言指代与真实几何实体之间存在可漂移的指代鸿沟；H23：视觉定位在重复纹理/动态场景下产生感知混叠（perceptual aliasing），位姿假设多峰甚至错误，而 VLA 会把错误位姿当作可信上下文，形成「语义合理、几何致命」的闭环。

## 0. 直觉与动机

**灵感 1（分工直觉：VLA 提语义动作，视觉定位提度量锚点）**
直觉：VLA 回答「做什么、大致朝哪」，视觉定位回答「我在哪、那个东西在度量上在哪」。前者是**语义提议者**，后者是**度量裁判**。一个可部署的动作不该只由 VLA 说了算，而应满足一份**锚定契约**：VLA 指向的指代 r，必须被视觉定位在地图 M 中给出可接受的度量落点与置信度。直觉上，这把「模型会不会做」变成「模型指的和我定位到的是不是同一个东西」。

**灵感 2（指代升格为一等公民 → 可检查的指代-定位一致性）**
直觉：语言里的「红色椅子」「出口左边的箱子」在 VLA 内部只是一个注意力热图，天然不可审计。我们把**指代 r** 显式化：VLA 输出 grounding 分布 `g_π(L)`，视觉定位输出该指代在地图中的候选假设 `{(pose_i, Σ_i, c_i)}`。若二者在投影空间的重合度低于阈值，则**拒答（abstain）**而不是硬做。这把 VLA 的隐式 grounding 变成可判定的**指代-定位一致性 κ(r)**。

**灵感 3（定位不确定性传播 → 动作包络而不是单点动作）**
直觉：位姿从来不是点，而是带协方差的分布。VLA 却常把位姿当确定输入。正确做法是把 `Σ_pose` 经策略雅可比 `J_a = ∂π/∂s` 传播成**动作协方差 `Σ_a`**；当动作包络超出安全集时，系统应降速、扩大安全裕度或触发重定位。直觉：**不是问「这个动作对不对」，而是问「在定位不确定下这个动作还安不安全」**。

**灵感 4（主动重定位 → 用 VLA 的动作去换取定位信息）**
直觉：视觉定位混叠时，最有效的不是原地猜，而是**动一下去看清**。VLA 具备生成候选动作的能力，可把「重定位」当作一个显式子目标：选择使定位熵下降最大、代价最小的观察动作。形成 **VLA 提议 — 定位打分 — 主动换视角 — 熵下降** 的信息闭环。这把先前被动的「定位失败→拒答」升级为主动的「定位不清→去问环境」。

**灵感 5（锚定金字塔 → 在动作金字塔之上再叠一层语义-度量接缝）**
直觉：第 54 轮的 `𝔸` 层只覆盖动作，未覆盖「这个动作是为哪个实体、由哪句语言、落在哪个度量坐标」的接缝。新增 **锚定层 `𝔾`**：`𝔾0` 原始观测、`𝔾1` 指代 grounding、`𝔾2` 度量定位、`𝔾3` 语言-动作 grounding、`𝔾4` 任务级指代链。跨层证书必须同时携带 `ρ`、`A_cert` 与 **`G_cert`（锚定证书）**，形成三维证书体系。

## 1. 形式化定义（增量：定义 121–126）

**定义 121（VLA 策略与指代 grounding）**
VLA 策略 `π: (I, L, s) → (a, g_π)`，其中 `I` 为视觉观测，`L` 为语言指令，`s` 为定位状态，`a` 为动作，`g_π: Ω_I → [0,1]` 为**指代 grounding 分布**（Ω_I 为图像/点云域）。语言指代集合 `R(L) = {r_1,...,r_m}`，每个 `r` 对应 `g_π(·|r)`。

**定义 122（视觉定位算子与假设集）**
视觉定位 `Loc: (I, M) → H`，`M` 为先验地图，`H = {(pose_i, Σ_i, c_i)}_{i=1..n}` 为多峰位姿假设，`Σ_i` 为协方差，`c_i` 为置信度且 `Σ_i c_i = 1`。**混叠度** `alias(H) = 1 - max_i c_i`；**定位熵** `H_loc = -Σ_i c_i log c_i`。

**定义 123（指代-定位一致性 κ）**
对指代 `r`，把 grounding 投到地图坐标 `proj_M(g_π(·|r))`，与假设 `i` 的定位实体求重合 `ovl_i`，定义
`κ(r) = max_i c_i · ovl_i`，**一致**当且仅当 `κ(r) ≥ θ_g` 且 `n_eff = 1/Σ_i c_i² ≤ n_max`（避免「蒙对」式多峰平均）。`κ < θ_g` 时执行器必须 abstain。

**定义 124（定位不确定性的动作传播）**
策略对定位状态的雅可比 `J_a = ∂π/∂s`。动作协方差
`Σ_a = J_a Σ_pose J_a^T + Σ_π + Σ_model`，
**安全动作包络** `Env(a) = {a' : (a'-a)^T Σ_a^{-1} (a'-a) ≤ χ²_α}`。若 `Env(a) ⊄ SafeSet`，动作不可直接执行，须降速/重定位。

**定义 125（VLA 锚定证书）**
`G_cert = (R(L), g_π, H, κ, Σ_a, v_plan, evidence)`：
- `R(L)` 指代集合与 grounding；
- `H` 定位假设集；
- `κ` 一致性；
- `Σ_a` 动作协方差；
- `v_plan` 主动重定位视角计划；
- `evidence` 至少含混叠反例与重定位前后位姿轨迹。
可执行条件：`κ ≥ θ_g ∧ Env(a) ⊆ SafeSet ∧ (alias(H) ≤ a_max ∨ v_plan ≠ ∅)`。

**定义 126（主动重定位触发与信息增益）**
触发条件 `trigger = [κ < θ_g] ∨ [H_loc > H_max] ∨ [Env(a) ⊄ SafeSet]`。候选视角动作 `v` 的信息增益 `IG(v) ≈ H_loc(H) - E_{z~p(·|v)} H_loc(H|z)`，选择 `v* = argmax_v IG(v)/cost(v)`，约束 `cost(v) ≤ τ_look`。这是把 VLA 动作空间临时重定向为「信息采集动作」的机制。

## 2. 关键算法 伪代码

### IP-121 SGA（Semantic-Geometric Anchoring）

```python
def anchor_referent(pi_vla, loc, I, L, M):
    a, g_pi = pi_vla(I, L)            # VLA 提议动作与 grounding
    refs = parse_referents(L)         # 语言指代集合
    H = loc(I, M)                     # 多峰定位假设
    grounded = {r: project(g_pi, r, M) for r in refs}
    return a, grounded, H

def rlc_check(r, grounded, H, theta_g=0.75, n_max=3):
    kappa = max(c * overlap(grounded[r], pose) for pose, _, c in H)
    n_eff = 1.0 / sum(c * c for _, _, c in H)
    return (kappa >= theta_g and n_eff <= n_max), kappa, n_eff
```

### IP-122 LUP（Localization Uncertainty Propagation）

```python
def action_covariance(pi_vla, s, Sigma_pose, Sigma_pi, Sigma_model):
    J = jacobian(lambda st: pi_vla.act(st), s)   # ∂π/∂s
    return J @ Sigma_pose @ J.T + Sigma_pi + Sigma_model

def in_safe_envelope(a, Sigma_a, SafeSet, chi2):
    # 用马氏距离椭球对 SafeSet 做保守内近似，避免点到点采样漏检
    return ellipsoid_subset(a, Sigma_a, chi2, SafeSet)
```

### IP-123 RLC（一致性门控）

```python
def grounded_decide(pi_vla, loc, I, L, s, M, cfg):
    a, grounded, H = anchor_referent(pi_vla, loc, I, L, M)
    ok, kappa, n_eff = rlc_check_list(grounded, H)
    Sigma_a = action_covariance(pi_vla, s, H.cov, cfg.Sigma_pi, cfg.Sigma_model)
    safe = in_safe_envelope(a, Sigma_a, cfg.SafeSet, cfg.chi2)
    if ok and safe:
        return ('execute', a, grounding_certificate(grounded, H, kappa, Sigma_a))
    v = active_relocalize(pi_vla, loc, H, M, cfg)
    return ('relocalize', v, diagnostics(kappa, n_eff, Sigma_a))
```

### IP-124 ARL（主动重定位闭环）

```python
def active_relocalize(pi_vla, loc, H, M, cfg):
    best, best_ratio = None, -inf
    for v in pi_vla.propose_views(cfg.view_budget):
        ig = entropy(H) - expected_entropy(loc, v, H)
        ratio = ig / (cost(v) + EPS)
        if cost(v) <= cfg.tau_look and ratio > best_ratio:
            best, best_ratio = v, ratio
    return best

def relocalize_loop(pi_vla, loc, I, L, s, M, cfg):
    for _ in range(cfg.max_rounds):
        H = loc(I, M)
        if entropy(H) <= cfg.H_max and max_conf(H) >= cfg.theta_g:
            return ('localized', H)
        v = active_relocalize(pi_vla, loc, H, M, cfg)
        if v is None:
            return ('abstain', H)
        I = execute_view(v)          # 采集新观测
    return ('abstain', H)
```

### IP-125 VGC（锚定证书）

```python
def grounding_certificate(R, g_pi, H, kappa, Sigma_a, v_plan, evidence):
    if kappa < theta_g:
        return ('reject', 'referent_mismatch', kappa)
    if not in_safe_envelope(current_action, Sigma_a, SafeSet, chi2) and v_plan is None:
        return ('reject', 'envelope_unsafe', Sigma_a)
    return ('ok', GCert(R, g_pi, H, kappa, Sigma_a, v_plan, evidence))
```

### IP-126 GTC（锚定迁移证书）

```python
def grounding_transfer(G_source, site_target, delta_kappa, delta_sigma):
    kappa_t = recompute_kappa(G_source.R, site_target.loc, site_target.M)
    sigma_t = transport_covariance(G_source.Sigma_a, site_target.calib)
    if abs(kappa_t - G_source.kappa) > delta_kappa:
        return ('reject', 'grounding_drift', kappa_t)
    if trace(sigma_t) > delta_sigma:
        return ('reject', 'uncertainty_exceeded', sigma_t)
    return ('ok', GCert(G_source.R, G_source.g_pi, site_target.H,
                        kappa_t, sigma_t, G_source.v_plan, site_target.evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| SGA | O(|L|·|H|·|Ω_I|) | O(|Ω_I|+|H|) | grounding 校准、投影可逆 |
| LUP | O(|a|²·|s| + |a|³) | O(|a|²) | 雅可比局部有效、协方差半正定 |
| RLC | O(|R|·|H|) | O(|R|·|H|) | θ_g 保守、n_eff 抑制蒙对 |
| ARL | O(|V|·|H|·|Ω_I|) | O(|V|·|H|) | IG 估计单调、预算闭合 |
| VGC | O(|R|·|H|+|a|²) | O(|a|²) | 联合条件 sound、证据完备 |

**正确性定理（Grounded VLA Action Soundness）**
假设 (A29)–(A33)：**(A29)** `g_π` 在标定集上校准，`κ` 的判别 AUROC ≥ 0.9；**(A30)** 视觉定位假设集 `H` 以概率 `≥ 1-ε_loc` 覆盖真实位姿；**(A31)** `J_a` 在安全集邻域内 Lipschitz 且局部线性化误差 ≤ ε_J；**(A32)** 每次主动重定位在期望上使 `H_loc` 单调下降，幅度 ≥ δ_ig；**(A33)** `SafeSet` 凸且 `Env` 椭球内近似保守。
则在 `κ ≥ θ_g` 且 `Env(a) ⊆ SafeSet` 的条件下：
```
P(success | execute) ≥ 1 - ε_loc - P(alias > a_max) - ε_J - β_E
```
关键：**先锚定指代，再传播不确定性，最后才允许执行**；任何一步不闭合即切换为主动重定位或 abstain，而非以语义置信度替代度量置信度。

## 4. 实验设计 E162–E166

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 指代-定位一致性校准 | κ 的 AUROC / ECE | AUROC ≥ 0.90，ECE ≤ 0.05 |
| E163 混叠场景定位误差 | ATE / 峰值误配率 | ATE 降低 ≥ 25%，误配 ≤ 3% |
| E164 主动重定位效率 | 恢复率 / 平均观察步数 | 恢复率 ≥ 85%，步数 ≤ 3 |
| E165 带 G_cert vs 纯 VLA | 部署成功率（尤其混叠子集） | 提升 ≥ 18%，危险动作拦截 ≥ 95% |
| E166 跨站点锚定迁移 | κ 漂移 / 安全违例数 | 漂移 ≤ 0.08，违例为 0 |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|
| VLA grounding 热图与真实指代错位 | 高 | 校准集 + 多指代一致性投票 + 红队指代 |
| 感知混叠导致 κ 虚假一致 | 高 | n_eff 门控 + 地图先验 + 多视角验证 |
| 雅可比线性化在接触/急转处失效 | 高 | 局部验算 + 采样式协方差交叉验证 |
| 主动重定位震荡/耗尽预算 | 中 | hysteresis + IG 单调检查 + 步数上限 |
| 语义本体与地图要素错配 | 高 | 共享地图语义层 + 人工审计锚点 |

## 6. 本轮最大风险

**一句话**：把 VLA 的语义提议与视觉定位的度量锚定用 `κ`、`Σ_a`、`G_cert` 缝合，能显著压缩「语义合理但几何致命」的失败面，但其 soundness **同时押注于 grounding 热图的校准、定位假设集对真值的覆盖、以及局部雅可比线性化的有效性**；一旦重复纹理让 `κ` 在错误指代上虚假偏高、或急转动作使线性化严重失真，系统会在「一致性通过」的假象下执行危险动作，因此必须以 **混叠感知的 n_eff 门控 + 采样式不确定性交叉验证 + 主动重定位作为否决前置** 三重护栏，宁可多看一眼，绝不把语义置信度当作度量置信度。

# 第 55 轮产物 · 创新点清单 v32：GroundVLA-GenSim（SGA×LUP×RLC×ARL×VGC×GTC）

> 承接第 54 轮产物 v31。本轮在「动作空间剖面 + 云边协同 + 动作-鲁棒性联合证书」之上，增加 **语义-度量锚定、定位不确定性传播、指代一致性门控、主动重定位闭环、锚定证书与跨站点迁移** 六大算子：
> - **SGA（Semantic-Geometric Anchoring）**：把 VLA 的指代 grounding 投到地图度量坐标；
> - **LUP（Localization Uncertainty Propagation）**：把定位协方差经策略雅可比传播为动作协方差与安全包络；
> - **RLC（Referent-Localization Consistency）**：`κ` + `n_eff` 双门控，拒绝「蒙对」式一致；
> - **ARL（Active Relocalization Loop）**：以信息增益/代价选择观察动作，主动消解混叠；
> - **VGC（VLA Grounding Certificate）**：`G_cert=(R,g_π,H,κ,Σ_a,v_plan,evidence)`；
> - **GTC（Grounding Transfer Certificate）**：跨站点迁移时校验 `κ` 漂移与不确定度预算。
>
> IP 编号：IP-121~IP-126（共 6 个新增），升级 IP-115/117/118/120 以纳入锚定维度。

```python
        I = execute_view(v)
    return ('abstain', H)
```

### IP-125 VGC

```python
def grounding_certificate(R, g_pi, H, kappa, Sigma_a, v_plan, evidence):
    if kappa < theta_g:
        return ('reject', 'referent_mismatch', kappa)
    if not in_safe_envelope(current_action, Sigma_a, SafeSet, chi2) and v_plan is None:
        return ('reject', 'envelope_unsafe', Sigma_a)
    return ('ok', GCert(R, g_pi, H, kappa, Sigma_a, v_plan, evidence))
```

### IP-126 GTC

```python
def grounding_transfer(G_source, site_target, delta_kappa, delta_sigma):
    kappa_t = recompute_kappa(G_source.R, site_target.loc, site_target.M)
    sigma_t = transport_covariance(G_source.Sigma_a, site_target.calib)
    if abs(kappa_t - G_source.kappa) > delta_kappa:
        return ('reject', 'grounding_drift', kappa_t)
    if trace(sigma_t) > delta_sigma:
        return ('reject', 'uncertainty_exceeded', sigma_t)
    return ('ok', GCert(G_source.R, G_source.g_pi, site_target.H,
                        kappa_t, sigma_t, G_source.v_plan, site_target.evidence))
```

## 3. 复杂度与正确性

| 组件 | 时间 | 空间 | 正确性保证 |
|---|---|---|---|
| SGA | O(|L|·|H|·|Ω_I|) | O(|Ω_I|+|H|) | grounding 校准、投影一致 |
| LUP | O(|a|²·|s|+|a|³) | O(|a|²) | 协方差半正定、线性化误差有界 |
| RLC | O(|R|·|H|) | O(|R|·|H|) | `κ` 保守、`n_eff` 抑制多峰蒙对 |
| ARL | O(|V|·|H|·|Ω_I|) | O(|V|·|H|) | IG 估计单调、预算闭合 |
| VGC | O(|R|·|H|+|a|²) | O(|a|²) | 联合条件 sound、证据完备 |
| GTC | O(|R|·|H|+|a|²) | O(|a|²+|H|) | `κ` 漂移与 `Σ_a` 预算双闭合 |

**正确性定理（Grounded VLA Action Soundness）**
假设第 54 轮 (A26)–(A28) 成立；**(A29)** `g_π` 在标定集上校准，`κ` 判别 AUROC ≥ 0.9；**(A30)** `H` 以概率 `≥ 1-ε_loc` 覆盖真实位姿；**(A31)** `J_a` 在安全集邻域 Lipschitz，线性化误差 ≤ ε_J；**(A32)** 每次主动重定位期望上使 `H_loc` 下降 ≥ δ_ig；**(A33)** `SafeSet` 凸、`Env` 内近似保守。
则在 `κ ≥ θ_g` 且 `Env(a) ⊆ SafeSet` 条件下：
```
P(success | execute) ≥ 1 - ε_loc - P(alias > a_max) - ε_J - β_E
```
关键：**先锚定指代、再传播不确定度、最后才允许执行**；任一条件不闭合即转入主动重定位或 abstain，绝不以语义置信度替代度量置信度。

## 6. 本轮最大风险

**一句话**：把 VLA 的语义提议与视觉定位的度量锚定用 `κ`、`Σ_a`、`G_cert` 缝合，能显著压缩「语义合理但几何致命」的失败面，但其 soundness **同时押注于 grounding 热图的校准、定位假设集对真值的覆盖、以及局部雅可比线性化的有效性**；一旦重复纹理让 `κ` 在错误指代上虚假偏高、或急转动作使线性化严重失真，系统会在「一致性通过」的假象下执行危险动作，因此必须以 **混叠感知的 n_eff 门控 + 采样式不确定性交叉验证 + 主动重定位作为否决前置** 三重护栏，宁可多看一眼，绝不把语义置信度当作度量置信度。
