# 第 55 轮（承接第 54 轮 v31 GroundEdge-GenSim+++；新灵感循环第 2 轮；本轮灵感：「多语言支持」×「SLAM」）· PolyGround：跨语言语义回路 × 空间定位回路的联合接地证书

> 第 54 轮把技能组合推进到动作剖面 `α_S`、组合图 `G_S` 与云边联合证书 `J=(ρ,A_cert,γ_ce,δ_a)`。但该体系仍默认两个"单源真值"假设：**(i) 任务意图由单一语言、单次解析唯一确定**；**(ii) 空间指称绑定在一张已收敛、全局一致、无漂移的地图上**。本轮用两个灵感词正面击穿它们：**H22（语义单源假设）**——多语言/多复述不是同一句话的重复，而是对同一潜在意图的**独立含噪观测**；单语言管线的解析错误是静默的，因为没有任何第二个来源去反驳它。**H23（地图全局假设）**——SLAM 的可靠性是**地点相关**的：走廊、对称大厅、玻璃/反光面处可定位性退化，回路闭合只在校正过的子图上有效；一张证书若不带"空间有效域"，就会被跨区域、跨会话静默复用。核心命题：**语言提供语义回路、SLAM 提供空间回路，二者是"冗余观测—漂移累积—回路闭合"同一结构的两个实例；证书必须在联合残差与联合有效域内签发。**

## 0. 直觉与动机

**灵感 1（语言是冗余的语义传感器：翻译/复述 = 语义回路闭合）**
直觉：单条指令"把红色杯子放到左边"在一种语言里只有一个解析，错了也无人纠正。但如果同时拿到中文、英文、以及同语言的两种复述，它们是对同一个潜在意图 `z` 的多次观测。多数一致能纠错，分歧本身就是"此处有歧义"的报警器。更关键的是：长程任务里的指称会像里程计一样**累积语义漂移**（"刚才那个"、"the same one" 逐步指偏），而一句复述或一次翻译回译，正好像回到旧地标一样把漂移拉回——这就是**语义回路闭合**。
→ 把多语言解析看成对 `z` 的因子图观测，用回路残差 `r_sem` 与信息矩阵 `Ω_sem` 校正语义漂移；**语言多样性不是 i18n 成本，而是可证伪性的来源**。

**灵感 2（SLAM 回路闭合 = 空间一致性；可定位性是地点相关的鲁棒性维度）**
直觉：同一张地图，在开阔处位姿很准，在长走廊、旋转对称大厅、镜面墙处可能沿退化方向漂出几十厘米；一次跨会话重定位若落进另一个子图，旧证书的锚点就悄悄失效。可定位性不是全局常数，而是 `ρ_loc(x, v)`——随地点与任务方向变化的剖面。
→ 把 `ρ_loc, ρ_lc, ρ_map, ρ_ground` 作为第 53 轮鲁棒性谱 `ρ` 的**地点条件扩展** `ρ^+`，让"能不能在这里可靠地做这件事"进入证书，而不是只问"这个技能整体行不行"。

**灵感 3（接地是胶水：意图必须绑定到空间有效域，而非全局地图）**
直觉：语言说"去厨房拿杯子"，SLAM 给出厨房在 `(x,y)`、杯子在某个物体轨迹上。技能是否可行，取决于**指称是否真的落到那个物体/地点**，以及该地点是否在当前地图的可信区域内。若只校验"技能存在"和"地图存在"，中间这层接地就可能错位：语言指的是 A 杯，地图绑定到 B 杯，证书仍然"形式有效"。
→ 定义指称接地 `g(z,m)` 与**空间有效域** `D_spatial`；证书承诺"在 `D_spatial` 内、对语言集 `L_cert`、在参照系 `D_frame` 下，意图-指称-动作三者一致"。

**灵感 4（语义漂移与空间漂移同构且相乘：需要联合漂移预算）**
直觉：长任务返回"之前看到红杯子的地方"时，语义回指漂移与 SLAM 位姿漂移会叠加：语义把"那个地方"指歪一点，空间又把该位置估歪一点，最终落点误差是二者之和（经 Lipschitz 放大）。单独给 `δ_sem` 和 `δ_sp` 各设阈值，会漏掉"各自都合格、合起来失败"的组合。
→ 用三角不等式式的**联合漂移预算** `δ_joint ≤ δ_sem + L_sp·δ_sp + δ_ground`，并要求 `δ_joint ≤ Θ_LS`；证书同时报告两项，不能互相抵消。

**灵感 5（跨语言分歧是证伪信号：用语言多样性做主动消歧，而非平均）**
直觉：把多种语言平均，会把"一种语言说去左、另一种说去右"平均成"去中间"这个两边都错的解。正确做法是把分歧当作**需要购买信息的信号**：换视角重观测、重定位、做一次探针动作，或在允许交互时请人换一种说法复述。
→ 主动接地策略 `π_act` 在 `{重观测, 重定位, 探针, 复述校验}` 中按**联合信息价值** `VoI` 选择；分歧越大，越值得花时间，而不是被平均掩盖。

## 1. 形式化定义（增量：定义 121–130）

**定义 121（多语言指令集与潜在意图后验）**
多语言指令集 `I = {(L_k, u_k, w_k)}_{k=1}^N`，其中 `L_k∈𝔏` 为语言标签，`u_k∈U_{L_k}` 为表述，`w_k>0` 为可信权重；存在潜在意图 `z∈Z`（规范化的"技能序列 + 参指绑定 + 参照系选择"）。解析器 `f_L: U_L → 𝒟(Z)` 输出意图分布。跨语言后验
```
p(z | I) ∝ p(z) · Π_k p( f_{L_k}(u_k)=z )^{w_k}
```
**语言覆盖集** `L(I)={L_k}`。若各源独立，语义 Fisher 信息相加 `I_sem = Σ_k w_k J_k^T Ω_k J_k`；语言间常因同源翻译而相关，用**有效独立源数**折算：
```
N_eff = (Σ_k w_k)^2 / Σ_{i,j} w_i w_j ρ_{ij},   ρ_ij 为语言对的相关度
```
证书的语义置信只能按 `N_eff` 计，不能按语言条数计。

**定义 122（语义漂移与语义回路残差）**
长程任务链 `u_{1:T}` 逐步接地的意图链为 `ẑ_{1:T}`。**语义漂移** `δ_sem(t)=d_Z(ẑ_t, z_t^*)`，满足 `δ_sem(t) ≤ δ_sem(t-1)+ε_step`（类比里程计累积）。若表述 `u_i,u_j`（可跨语言、可为复述/回译/代词回指）指同一意图，则构成**语义回路**，残差
```
r_sem(i,j) = d_Z(ẑ_i, ẑ_j),   强度 Ω_sem(i,j)
```
计划距离 `d_Z` 取技能序列编辑距离与动作剖面 Wasserstein 距离的组合；只有通过**反向验证**（回译一致或第三语言一致）的回路才允许写入图。

**定义 123（可定位性谱与地点条件鲁棒性谱）**
设 SLAM 在状态 `x` 处的信息矩阵 `Λ(x)=J^T Ω J`。沿任务相关方向 `v∈T_x`（如插入方向、行进方向）的**可定位性**
```
ρ_loc(x,v) = λ_min(D_v^T Λ(x) D_v) / (λ_min(D_v^T Λ(x) D_v) + λ_0) ∈ [0,1]
```
`ρ_loc` 小即该方向退化。将鲁棒性谱扩展为地点条件版本
```
ρ^+(x) = ρ ∪ {ρ_loc(x,·), ρ_lc(x), ρ_map(x), ρ_ground(x)}
```
其中 `ρ_lc` 为回路闭合覆盖度、`ρ_map` 为地图新鲜度、`ρ_ground` 为接地置信度。第 54 轮的 `J` 中的 `ρ` 一律升级为 `ρ^+`。

**定义 124（空间有效域与锚点）**
证书的空间有效域
```
D_spatial(J) = ∪_{a∈Anc(J)} B(x_a, R_a)
```
`Anc(J)={(i, x_i, Σ_i)}` 为锚点键帧集合，`B(x_a,R_a)` 为置信椭球。判定 `in_spatial(J,x)=1` 当且仅当 `x` 落在某个 `B(x_a,R_a)` 的 Mahalanobis 半径内。重定位进入未被任何锚点覆盖的区域时，证书**立即失效**，必须重锚定。

**定义 125（指称接地与参照系残差）**
接地函数 `g: Z × M × 𝔏 → 𝒟(O×P)` 把（意图，地图，语言）映射为物体/地点分布。语言参照系 `fr(u)∈{relative, intrinsic, absolute}`，地图坐标系 `F_M`；对齐算子 `A_fr: F_fr → F_M`。**参照系残差**
```
r_frame(i,j) = ||A_{fr(u_i)} - A_{fr(u_j)}||_{F_M}
```
对同一指称，不同语言可能默认不同参照系（"车左边"是观察者左、车体左还是地图左），必须显式归一化，否则接地会在翻译间跳变。

**定义 126（语言-SLAM 一致性图，LSCG）**
`G_LS=(V,E)`，`V=X∪Z∪O`（键帧位姿、意图节点、指称实体）。边三类：
- **空间边** `e_sp(x_i,x_j; z_ij, Ω_sp)`：里程计与 SLAM 回路闭合；
- **语义边** `e_sem(z_i,z_j; r_sem, Ω_sem)`：翻译、复述、回指构成的语义回路；
- **接地边** `e_g(z,o; r_ground, Ω_g)` 与 **参照系边** `e_fr`。

联合 MAP：
```
(X*,Z*,O*) = argmin  Σ_sp ||e_sp||²_{Ω_sp} + Σ_sem ||e_sem||²_{Ω_sem}
                     + Σ_g  ||e_g||²_{Ω_g}  + Σ_fr ||e_fr||²_{Ω_fr}
```
记最优处**联合残差** `R_joint = χ²(X*,Z*,O*)`。`R_joint` 同时反映"语义说不通"和"空间对不上"。

**定义 127（接地条件动作剖面与兼容性）**
把第 54 轮动作剖面推广为对信念的期望：
```
α_S^{b,g}(a) = ∫∫ α_S(a | x, o) · b(x) · g(o) dx do
```
覆盖 `cover^{b,g}(S,A_T)=1 ⇔ ∀a∈A_T, α_S^{b,g}(a) ≥ θ_cov`。兼容性升级为 `compat_g(S_i,S_j)=E_{b,g}[ |A_i∩A_j| / |A_i∪A_j| ]`。只有 `compat_g ≥ θ_a` 且 `R_joint ≤ Θ_joint` 的边才允许进入 `G_S`。

**定义 128（语言-空间联合证书 J_LS）**
```
J_LS = ( J, z*, L_cert, D_spatial, Anc, ρ^+, δ_sem, δ_sp, R_joint, evidence )
```
其中 `J` 为第 54 轮联合证书，`z*` 为联合 MAP 的意图，`L_cert` 为**已验证语言集**。可部署条件：
```
J.valid ∧ R_joint ≤ Θ_joint
        ∧ L_task ⊆ L_cert
        ∧ in_spatial(J_LS, x_t)=1
        ∧ (δ_sem + L_sp·δ_sp + δ_ground) ≤ Θ_LS
```
任何一项不满足都必须降级到重接地/重规划，而不是签发"看起来有效"的证书。

**定义 129（证书有效域与域外检测）**
```
D(J_LS) = D_spatial × D_lang × D_frame × D_task
```
部署查询 `q=(x, L, fr, task)` 的域内谓词 `in_domain(J_LS,q)` 要求四项同时命中。定义**域外风险** `P_exit = P(q ∉ D(J_LS))`；域外复用是静默失效的主要来源，必须显式建模并监控。

**定义 130（主动接地消歧与联合信息价值）**
候选观测/动作集
```
O_act = { 重观测 o_reob, 重定位 o_reloc, 探针动作 o_probe, 复述校验 o_para }
```
联合信息价值
```
VoI(o|s) = E_{s'~P(·|s,o)}[ G(s') ] - G(s) - λ·τ(o)
```
`G(s)` 为在联合残差与不确定度下的期望代价（可用 `R_joint` 与 `Σ_loc` 的迹近似）。选择 `argmax_o VoI`；若交互允许，`o_para`（请操作者换一种语言复述）与机器人自己重观测同属合法感知动作。

## 2. 关键算法 伪代码

### IP-121 MLG（Multilingual Lexical-Spatial Grounding）

```python
def multilingual_intent(I, parsers, prior=None, corr=None):
    logpost = defaultdict(float)
    for (L, u, w) in I:
        for z, p in parsers[L].parse(u).items():
            logpost[z] += w * log(max(p, EPS))
    post = softmax(logpost)                       # 潜在意图后验
    N_eff = effective_sources(I, corr)            # 相关语言折算
    fisher = sum(Fisher(parsers[L], u) for (L,u,_) in I)
    return IntentPosterior(post, Fisher=fisher, N_eff=N_eff, langs={L for (L,_,_) in I})
```

### IP-122 SLD（Semantic Loop Detection）

```python
def semantic_loops(chain, parsers, theta_loop):
    loops = []
    for i in range(len(chain)):
        for j in near_neighbors(i, chain, top_k=8):   # 向量索引召回候选
            r = plan_distance(chain[i].z, chain[j].z)  # 技能编辑 + 动作剖面 Wasserstein
            if r <= theta_loop and referent_compatible(chain[i], chain[j]):
                if third_source_agrees(chain, i, j) or backtranslate_agrees(chain, i, j):
                    loops.append((i, j, r, omega_sem(r)))
    return loops
```

### IP-123 LSCG（Language-SLAM Consistency Graph）

```python
def build_lscg(slam_graph, intent_chain, groundings, semantic_loops, frame_edges):
    g = FactorGraph()
    for x in slam_graph.poses:        g.add_var(x)
    for z in intent_chain:            g.add_var(z)
    for o in groundings.entities:     g.add_var(o)
    for e in slam_graph.odom + slam_graph.loops:
        g.add_factor(SpatialFactor(e.pose_i, e.pose_j, e.z, e.omega))
    for (i, j, r, w) in semantic_loops:
        g.add_factor(SemanticFactor(intent_chain[i].z, intent_chain[j].z, r, w))
    for (z, o, c) in groundings.edges:
        g.add_factor(GroundingFactor(z, o, c.omega))
    for e in frame_edges:
        g.add_factor(FrameFactor(e.u, e.v, e.A_fr, e.omega))
    X, Z, O = g.optimize(num_iters=20)
    return LSCG(X, Z, O, residual=g.chi2(), anchors=slam_graph.anchors)
```

### IP-124 GAC（Grounding-Aware Certificate）

```python
def grounding_aware_certificate(skill_seq, I, slam, mapM, budget):
    ip = multilingual_intent(I, parsers, corr=language_correlation)
    z  = ip.map
    lscg = build_lscg(slam.graph, z.chain, ground_object(z, mapM),
                      semantic_loops(z.chain, parsers, budget.theta_loop),
                      frame_edges(z.chain))
    if lscg.residual > budget.Theta_joint:
        return ('reject', 'joint_residual', lscg.residual)
    if not (I.languages <= budget.L_cert):
        return ('reject', 'lang_out_of_domain', I.languages - budget.L_cert)
    rho_plus = {**compose_robustness([s.rho for s in skill_seq], K),
                **localizability(slam, z.task_dirs),
                'ground': ip.conf, 'lc': loop_closure_coverage(slam)}
    A_core = joint_action_core(skill_seq, belief=slam.belief, intent=ip)
    delta_sem = semantic_drift_bound(z.chain, lscg)
    delta_sp  = spatial_drift_bound(slam, lscg)
    if delta_sem + L_sp * delta_sp + delta_ground > budget.Theta_LS:
        return ('reject', 'joint_drift', delta_sem, delta_sp)
    return ('ok', JointLS(J=joint_certificate(skill_seq, gamma_ce, budget),
                          z=z, L_cert=ip.langs, D_spatial=domain(lscg),
                          Anc=lscg.anchors, rho_plus=rho_plus,
                          delta_sem=delta_sem, delta_sp=delta_sp,
                          R_joint=lscg.residual))
```

### IP-125 ALD（Active Localization-Disambiguation）

```python
def active_disambiguate(state, budget, O_act):
    best, best_gain = None, -inf
    for o in O_act:
        if cost(o) > budget.remaining_time:   continue
        post = predict_state(state, o)        # 贝叶斯更新 + LSCG 增量优化
        gain = expected_cost_drop(post, state) - lam * cost(o)
        if gain > best_gain:
            best, best_gain = o, gain
    return best if best_gain > 0 else None    # 负收益则不做，避免抖动
```

def in_domain(J_LS, q):

## 3. 复杂度与正确性

| 组件 | 时间复杂度 | 空间复杂度 | 正确性关键 |
|---|---|---|---|
| MLG | O(N·|Z|·parse) | O(|Z|·N) | 解析器校准、`N_eff` 相关折算 |
| SLD | O(T·k·d_Z)（ANN 召回） | O(T·k) | 回路反向验证、误报可控 |
| LSCG | O((|X|+|Z|+|O|) 迭代)（稀疏 Cholesky） | O(|V|+|E|) | 残差可归因、锚点不越域 |
| GAC | O(|S|·|A| + LSCG) | O(|A|+|V|) | 联合预算闭合、语言覆盖 |
| ALD | O(|O_act|·rollout) | O(|O_act|) | VoI 校准、避免震荡 |
| CDC | O(log |Anc|) | O(|Anc|) | 域判定单调、重锚定触发 |

**正确性定理（Language-Spatial Grounding Soundness）**
承接第 53/54 轮 (A22)–(A28)，新增：
**(A29)** 跨语言解析器校准：`P(z*∈supp p(·|I)) ≥ 1-β_L`；
**(A30)** 语义回路检测的漏检率 `≤ β_lc`，且每条漂移段至少被一条经反向验证的回路覆盖；
**(A31)** 可定位性估计 sound：沿任务方向 `ρ_loc` 与真实误差满足 Lipschitz 关系；
**(A32)** 参照系归一化在 `D_frame` 内误差 `≤ δ_frame`；
**(A33)** LSCG 优化达到可接受驻点（`R_joint` 与全局最优差 `≤ ε_opt`）。
则在域内、且证书有效时：
```
P_success ≥ 1 - Σ_d (1-ρ_min(d)) - β_E - β_L - β_lc
              - P(R_joint > Θ_joint) - P(exit D) - P(δ_joint > Θ_LS)
δ_joint ≤ δ_sem + L_sp·δ_sp + δ_ground + δ_frame
```
关键：**语义冗余必须按有效独立源计**、**空间证书必须带有效域**、**两类漂移必须联合预算**。任何一项单独成立都不足以签发联合证书。

## 4. 实验设计 E162–E167

| 实验 | 指标 | 目标 |
|---|---|---|
| E162 跨语言意图一致率 | 同意图多语言/复述的计划一致率、歧义检出率 | 一致率 ≥ 95%，歧义召回 ≥ 70% |

## 5. 风险与缓解

| 风险 | 等级 | 缓解 |
|---|---|---|

## 6. 本轮最大风险

### IP-121 MLG

```python
def multilingual_intent(I, parsers, prior=None, corr=None):
    logpost = defaultdict(float)
    for (L, u, w) in I:
        for z, p in parsers[L].parse(u).items():
            logpost[z] += w * log(max(p, EPS))
    post = softmax(logpost)
    N_eff = (sum(w for _,_,w in I) ** 2) / correlated_mass(I, corr)
    fisher = sum(w * Fisher(parsers[L], u) for (L,u,w) in I)
    return IntentPosterior(post, Fisher=fisher, N_eff=N_eff,
                           langs={L for (L,_,_) in I})
```

def semantic_loops(chain, parsers, theta_loop, top_k=8):
    loops = []
    for i in range(len(chain)):
        for j in vector_index.neighbors(chain[i].z, k=top_k):
            if j <= i: continue
            r = plan_distance(chain[i].z, chain[j].z)
            if r <= theta_loop and referent_compatible(chain[i], chain[j]):
                if backtranslate_agrees(chain, i, j) or third_lang_agrees(chain, i, j):
                    loops.append((i, j, r, omega_sem(r)))
    return loops

### IP-123 LSCG

```python
def build_lscg(slam_graph, intent_chain, groundings, loops, frame_edges):
    g = FactorGraph()
    for x in slam_graph.poses:     g.add_var(x)
    for z in intent_chain:         g.add_var(z)
    for o in groundings.entities:  g.add_var(o)
    for e in slam_graph.odom + slam_graph.loops:
        g.add_factor(SpatialFactor(e.i, e.j, e.z, e.omega))
    for (i, j, r, w) in loops:
        g.add_factor(SemanticFactor(intent_chain[i].z, intent_chain[j].z, r, w))
    for (z, o, c) in groundings.edges:
        g.add_factor(GroundingFactor(z, o, c.omega))
    for e in frame_edges:
        g.add_factor(FrameFactor(e.u, e.v, e.A_fr, e.omega))
    X, Z, O = g.optimize(num_iters=20)
    return LSCG(X, Z, O, residual=g.chi2(), anchors=slam_graph.anchors)
```

def grounding_aware_certificate(skill_seq, I, slam, mapM, budget):
    ip = multilingual_intent(I, parsers, corr=language_correlation)
