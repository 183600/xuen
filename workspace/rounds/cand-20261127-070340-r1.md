### 第 1 轮灵感驱动研究记录

**灵感词**：抓取、数据标注

**直觉与动机**：

前几轮把证书链一路推到「结构-力控-轻量化」（USMC）与「语义-重构-协同」（SRC-USC），但整条链始终悬在半空：所有证书都是「关于世界的断言」，却缺少一个让物理世界亲自签字确认的环节。**抓取就是证书链的物理着陆点**——当接触力闭合的那一瞬间，语义标签、位姿估计、能量预算、力控无源性全部被压缩成一次二值的物理判决：抓住或没抓住。抓取成功是物理世界对上游感知与规划投的一张赞成票，抓取失败则是一张免费的负样本。

另一侧的灵感词「数据标注」恰好补上了证书链缺失的信任根。conformal 覆盖、语义标签、抓取质量标签、力控参数辨识，全部以标注数据为校准源；**标注噪声是覆盖率的隐形预算消耗**，而标注集与部署分布的偏移会直接击穿 exchangeability 假设。现有 v25 只证「标签是否落在预测集」，却从不证「标签本身从哪来、有多可信、是否与部署同分布」。

把两个灵感词咬合起来，得到本轮核心洞见：**抓取即物理标注（grasp-as-annotation），标注即证书校准（annotation-as-calibration），证书即抓取准入（certificate-as-admission）**。一次抓取结果天然携带三类物理标注——成功/失败（任务标签）、是否打滑（接触标签）、在何种位姿下成功（几何标签）。这使数据标注从离线人工成本，变成在线可再生的可证资产；感知→抓取→结果→新标注→重校准→新证书构成闭环。

但闭环立刻带来最危险的循环依赖：我们用抓取结果去校准「决定抓取是否成功」的感知模型，又用该校准后的模型去证明抓取证书。若存在选择偏差（只有够得着、摆得正的物体才会被尝试抓取），系统会形成**自我确认证书（self-confirming certificate）**：在一小撮被反复抓取的物体上越来越自信，却在部署分布上系统性失效。因此本轮不是简单地「把抓取成功率加进证书」，而是要把**标注过程本身**纳入证书——证的不是标签值，而是标签的生成机制、噪声上界、以及校准集与部署集的可迁移性。

**形式化目标**：

1. 定义抓取证书（GrC）：在接触集 C={(c_i,n_i,μ_i)} 与抓取映射 G 上，给出位姿不确定集 U 内的 ε-鲁棒力闭合证书 ε_rob>0、摩擦锥接触稳定裕度 γ_c，以及抓取成功率的 conformal 下界 ℙ(success)≥1-α_g。
2. 定义标注证书（AnC）：标注溯源 DAG 无环且无测试泄漏、标注者一致性 Krippendorff α 的置信下界、金标准审计给出的噪声率上界 η_U，以及**噪声修正 conformal 覆盖** ℙ(Y∈C) ≥ 1-α/(1-η_U)。
3. 定义物理自标注证书（PSAC）：把「抓取成功」形式化为对「位姿误差 > ε」这一假设的物理检验（成功即拒绝，误拒率 ≤ β_g）；给出打滑检测器的漏检/误检上界；用倾向得分加权 conformal 修正删失与选择偏差。
4. 构建抓取-标注统一准入门（GGA-UC）：SRC-USC ∪ GrC ∪ AnC ∪ PSAC，Exec_v26 = Exec_v25 ∩ Fil_grasp ∩ Fil_annot ⊆ Exec_v25。
5. 证明「标注噪声 → 覆盖退化」的显式定量关系，并证明只要任一证书失败即冻结闭环、退回 v25，则单调退化链在闭环自标注下仍逐轮保持。
6. 给出闭环安全的充分条件（噪声预算 η≤η_c、密度比上界 W<∞、有效样本量 ESS≥n_min），并明确把闭环收敛性列为开放问题而非已证结论。

## 1. 直觉先行：三个定义如何咬合

**直觉 1（抓取 = 物理判决）**：一个抓取计划本质上是一组关于世界的断言——「物体在 p̂」「表面法向是 n̂」「摩擦系数至少 μ̂」「接触力在能量预算内」。只有当这些断言同时成立，力闭合才可能发生。因此 `ε_rob>0` 不只是抓取质量，它是对上游位姿/几何证书的一次物理复核。

**直觉 2（标注 = 校准预算）**：conformal 的 1-α 保证建立在「校准集与部署集可交换」之上。标注噪声把一部分校准样本换成「假样本」，等价于偷偷缩小了有效校准集。噪声率 η 不是数据质量问题，而是覆盖率预算的直接扣减项；本轮的定量结论是覆盖下界从 1-α 退化为 1-α/(1-η)。

**直觉 3（自标注 = 有偏采样器）**：抓取只发生在「够得着、放得稳、值得抓」的物体上，这是一个强选择偏差采样器；而失败样本又常常被丢弃（删失）。把抓取结果直接倒进校准集，等价于用有偏样本估计无偏分位数，覆盖保证必然破裂。必须用倾向得分/密度比对样本重加权，并证明 ESS 足够。

**严谨定义 1201（抓取证书 GrC）**：对抓取计划 π_grasp 与接触集 C，GrC 通过当且仅当
(1) **鲁棒力闭合**：`ε_rob = min_{p∈U_p} ε(C(p)) > 0`；
(2) **接触稳定**：存在接触力 f 使 `Gf = -w_ext` 且 `‖f_{i,t}‖ ≤ (1-γ_c) μ_i f_{i,n}`，γ_c>0；
(3) **统计成功**：在可交换校准集上，conformal 阈值 q 满足 `ℙ(s_g(x) ≤ q) ≥ 1-α_g`。

**严谨定义 1202（标注证书 AnC）**：对标注数据集 D 与审计集 D_audit，AnC 通过当且仅当
(1) **溯源完整**：标注记录构成有向无环图，每条标签可追溯到传感器/标注者/模型版本，且测试集标签不在校准溯源祖先集中；
(2) **一致性**：`α_L ≥ α_min`（如 0.67）；
(3) **噪声受控**：`η_U ≤ η_budget(α, α_target) = 1 - α/α_target`，其中 α_target 为可接受的最低覆盖损失；
(4) **覆盖修正**：以噪声修正阈值 `q_η` 执行 conformal，保证 `ℙ(Y∈C(x)) ≥ 1 - α/(1-η_U)`。

**严谨定义 1203（物理自标注证书 PSAC）**：对物理自标注集 D_phys、打滑检测器与选择倾向 e(x)，PSAC 通过当且仅当
(1) **假设检验有效**：在 H_ε 下抓取成功率 ≤ β_g，故观测到成功时以 ≥1-β_g 置信拒绝 H_ε；
(2) **检测器可靠**：`η_FN ≤ η_FN^max`，`η_FP ≤ η_FP^max`；
(3) **去偏可行**：密度比满足 `W < ∞` 且 `ESS ≥ n_min`，加权 conformal 覆盖 ≥ 1-α-δ_w（δ_w 为权重估计误差）。

**严谨定义 1204（GGA-UC）**：`GGA-UC.admits(Π) = True` 当且仅当 SRC-USC v25 通过，且对每个含接触的子计划 π 有 GrC(π)，且其校准源满足 AnC，且其物理标注源满足 PSAC。

```python
# ============================================================
# IP-448 Grasp Certificate (GrC) — 抓取证书
# ============================================================
@dataclass
class Contact:
    c: Tensor          # 接触点 (3,)
    n: Tensor          # 内法向 (3,)
    mu: float          # 摩擦系数

@dataclass
class GraspCertificate:
    contacts: list[Contact]
    grasp_map: Tensor                 # G: (6, 3k)
    pose_uncertainty: 'Ellipsoid'     # U_p
    alpha_g: float = 0.05
    gamma_c: float = 0.2
    beta_g: float = 0.01
    calibrator: 'ConformalCalibrator' = None

    def epsilon_quality(self, G: Tensor, contacts: list[Contact],
                        n_edges: int = 16) -> float:
        """Ferrari–Canny ε：min_{‖w‖=1} max{ρ : ρw ∈ GWS}，用摩擦锥多面体线性化 + LP。"""
        eps = float('inf')
        for w in sample_unit_sphere(n=64):          # 方向离散化
            # f_i = Σ_j λ_ij d_ij, λ_ij≥0；G f = ρ w
            A, b = self._build_cone_lp(G, contacts, w, n_edges)
            rho = solve_lp_max_rho(A, b)            # 线性规划
            eps = min(eps, rho)
        return eps

    def epsilon_robust(self) -> float:
        """ε_rob = min_{p∈U_p} ε(C(p))：位姿不确定集上的最坏情形。"""
        worst = float('inf')
        for p in self.pose_uncertainty.sample_extremes(n=32):
            contacts_p = transform_contacts(self.contacts, p)
            G_p = build_grasp_map(contacts_p)
            worst = min(worst, self.epsilon_quality(G_p, contacts_p))
        return worst

    def verify_contact_stability(self, w_ext: Tensor) -> bool:
        """存在 f 使 Gf=-w_ext 且 ‖f_t‖≤(1-γ_c)μ f_n（线性化摩擦锥内点）。"""
        return self._solve_contact_force(self.contacts, self.grasp_map,
                                         w_ext, self.gamma_c) is not None

    def verify_conformal_success(self, obs: Tensor) -> bool:
        """抓取成功率下界：ℙ(s_g(x)≤q) ≥ 1-α_g（可交换校准集）。"""
        if self.calibrator is None:
            return False
        q = self.calibrator.threshold(self.alpha_g)
        return bool(torch.all(self.calibrator.score(obs) <= q))

    def verify_all(self, w_ext: Tensor, obs: Tensor) -> bool:
        return (self.epsilon_robust() > 0.0
                and self.verify_contact_stability(w_ext)
                and self.verify_conformal_success(obs))

# IP-449 Annotation Certificate (AnC) — 标注证书
# ============================================================
@dataclass
class AnnotationRecord:
    x_id: str
    label: Any
    annotator_id: str
    model_version: str
    timestamp: float
    parents: list[str]            # 溯源 DAG 的父节点
    split: str                    # train / cal / test

@dataclass
class AnnotationCertificate:
    records: list[AnnotationRecord]
    audit: 'AuditSet'             # 金标准审计集 (m 条人工复核)
    alpha: float = 0.05
    alpha_target: float = 0.94    # 可接受的最低覆盖
    delta: float = 0.05           # 噪声上界的置信水平
    alpha_min: float = 0.67       # Krippendorff 一致性下限

    def verify_provenance(self) -> bool:
        """溯源 DAG 无环；测试标签不在任何校准样本的祖先集中。"""
        if not is_dag(self.records):
            return False
        test_ids = {r.x_id for r in self.records if r.split == 'test'}
        for r in self.records:
            if r.split == 'cal':
                if ancestors(r, self.records) & test_ids:
                    return False
        return True

    def verify_agreement(self, bootstrap: int = 1000) -> bool:
        """Krippendorff α 的 bootstrap 置信下界 α_L ≥ α_min。"""
        alpha_hat, alpha_lcb = krippendorff_alpha_lcb(
            self.records, n_boot=bootstrap, conf=1 - self.delta)
        return alpha_lcb >= self.alpha_min

    def noise_upper_bound(self) -> float:
        """金标准审计：Clopper–Pearson 单侧上界 η_U。"""
        m = self.audit.n
        e = self.audit.errors
        return float(beta.ppf(1 - self.delta, e + 1, m - e)) if m > e else 1.0

    def eta_budget(self) -> float:
        """覆盖不跌破 α_target 所需 η 预算：1-α/(1-η) ≥ α_target。"""
        return 1.0 - self.alpha / self.alpha_target

    def noise_corrected_threshold(self, scores: Tensor) -> float:
        """在噪声预算内把 α 放大为 α_eff = α/(1-η_U)，得到保守阈值。"""
        eta_u = self.noise_upper_bound()
        alpha_eff = min(1.0, self.alpha / max(1e-12, 1.0 - eta_u))
        return conformal_quantile(scores, alpha_eff)

    def verify_noise_control(self) -> bool:
        return self.noise_upper_bound() <= self.eta_budget()

    def verify_all(self) -> bool:
        return (self.verify_provenance()
                and self.verify_agreement()
                and self.verify_noise_control())

# IP-450 Physical Self-Annotation Certificate (PSAC)
# ============================================================
@dataclass
class PhysicalSelfAnnotationCertificate:
    phys: 'PhysicalDataset'          # 抓取结果/接触力/打滑标记
    slip_detector: 'SlipDetector'
    propensity: 'PropensityModel'    # e(x)=P(被尝试抓取|x)
    alpha: float = 0.05
    beta_g: float = 0.01
    eta_fn_max: float = 0.02
    eta_fp_max: float = 0.05
    n_min: int = 200
    W_max: float = 20.0

    def verify_slip_reliability(self) -> bool:
        """用留出集估计打滑检测的漏检/误检，Clopper–Pearson 上界须低于预算。"""
        eta_fn_u = clopper_pearson_upper(
            self.phys.slip_false_negative, self.phys.slip_positives, 0.05)
        eta_fp_u = clopper_pearson_upper(
            self.phys.slip_false_positive, self.phys.slip_negatives, 0.05)
        return eta_fn_u <= self.eta_fn_max and eta_fp_u <= self.eta_fp_max

    def certify_pose_hypothesis(self, eps: float) -> bool:
        """H_ε: ‖p_true-p̂‖>ε 下抓取成功率 ≤ β_g；成功数超过二项阈值才拒绝 H_ε。"""
        n = self.phys.n_attempts_under_H
        s = self.phys.n_success_under_H
        if n == 0:
            return False
        # 单侧二项检验：P(S≥s | p=β_g) ≤ δ
        return binom_sf(s - 1, n, self.beta_g) <= 0.05

    def selection_weights(self) -> Tensor:
        """倾向得分逆概率加权：w_sel(x)=1/e(x)，截断到 W_max。"""
        e = self.propensity.predict(self.phys.x)
        w = 1.0 / torch.clamp(e, min=1.0 / self.W_max)
        return w

    def verify_debias_feasible(self) -> bool:
        """密度比有界且有效样本量足够，否则加权 conformal 无保证。"""
        w = self.selection_weights()
        ess = (w.sum() ** 2) / (w ** 2).sum()
        return float(w.max()) <= self.W_max and float(ess) >= self.n_min

    def weighted_conformal_threshold(self, scores: Tensor) -> float:
        """加权 split-conformal：按 w 归一化后的加权分位数。"""
        w = self.selection_weights()
        return weighted_quantile(scores, w / w.sum(), 1 - self.alpha)

    def verify_all(self, eps: float) -> bool:
        return (self.verify_slip_reliability()
                and self.certify_pose_hypothesis(eps)
                and self.verify_debias_feasible())

# IP-451 GGA-UC 抓取-标注统一准入门

@dataclass
class GraspGroundedAnnotationUnifiedCertificate:
    src_usc: 'SemanticReconfigCoordUnifiedCertificate'   # v25
    grc: GraspCertificate
    anc: AnnotationCertificate
    psac: PhysicalSelfAnnotationCertificate

    def admits(self, multi_plan, sensor_data: dict, eps_pose: float) -> bool:
        if not self.src_usc.admits(
                multi_plan, sensor_data,
                gt_entities=sensor_data.get('gt_entities'),
                queries=sensor_data.get('queries'),
                retrieved=sensor_data.get('retrieved')):
            return False
        for plan_i in multi_plan.robot_plans:
            if plan_i.has_contact:
                if not self.grc.verify_all(plan_i.w_ext, plan_i.grasp_obs):
                    return False
        if not self.anc.verify_all():
            return False
        if not self.psac.verify_all(eps_pose):
            return False
        return True


class GraspAnnotationLoop:
    """感知→抓取→物理标注→重校准→新证书 的闭环执行器。"""

    def __init__(self, gga: GraspGroundedAnnotationUnifiedCertificate,
                 freeze_on_fail: bool = True):
        self.gga = gga
        self.freeze_on_fail = freeze_on_fail

    def step(self, plan, sensor_data, eps_pose):
        admitted = self.gga.admits(plan, sensor_data, eps_pose)
        if not admitted:
            return False, {'degrade_to': 'Exec_v25'}
        outcome = execute_grasp(plan)
        self.gga.psac.phys.add(outcome)
        # 仅在 AnC/PSAC 仍通过时才把物理标签并入校准集
        if self.gga.anc.verify_noise_control() and self.gga.psac.verify_debias_feasible():
            self.gga.anc.records.extend(labels_from(outcome))
        else:
            return False, {'freeze_loop': True, 'reason': 'annotation_budget_exceeded'}
        return True, {'outcome': outcome}
```

## 3. 正确性论证（增量）

### 引理 13（ε-鲁棒力闭合的位姿保持性）
**陈述**：若抓取计划在不确定集 U_p 上的鲁棒质量 `ε_rob = min_{p∈U_p} ε(C(p)) > 0`，则对任意真实位姿 p∈U_p，GWS 均包含以原点为心、半径 ε_rob 的球，从而在该位姿下力闭合，且可抵抗任意 ‖w_ext‖≤ε_rob 的外旋量。

**证明**：GWS 是摩擦锥（凸）在线性抓取映射下的像的 Minkowski 和，故为凸锥。ε(C)=dist(0,∂GWS) 是原点到边界的最小距离；ε>0 等价于 0 在 GWS 内部，即力闭合。对 p 取 min 后，球 B_{ε_rob} 被每个 GWS(p) 包含，故对 U_p 内任意 p 成立；旋量 w_ext 满足 ‖w_ext‖≤ε_rob 时 w_ext∈B_{ε_rob}⊂GWS，可被接触力平衡。∎

**注**：离散化 64 个方向 + 16 边摩擦锥线性化会带来方向/锥近似误差；工程上以 `ε_rob - δ_disc` 作为下界，δ_disc 由离散化误差界给出，绝不使用点估计。

### 引理 14（抓取即假设检验：成功对位姿误差的物理否决）
**陈述**：考虑半径 r、摩擦系数 μ 的圆形物体上的双指对跖抓取。设真实接触法向相对规划法向的角误差为 δ，摩擦锥半角 φ=atan(μ)。若 δ ≥ φ，则该对跖抓取不满足力闭合（切向分量滑出摩擦锥）。在小误差下 δ ≈ ‖p_true-p̂‖/r。取 ε = r·φ，则在 H_ε:‖p_true-p̂‖>ε 下抓取必然失败；因此观测到一次成功即以误拒率 0（确定性情形）拒绝 H_ε；存在扰动/柔顺时误拒率 ≤ β_g。

**证明**：对跖接触的两摩擦锥在旋量空间中的可行交集为空当且仅当两锥轴线夹角 ≥ 2φ 的对偶条件失效；单侧接触保持力闭合要求法向误差 δ<φ。若 δ≥φ，所需切向力分量超出 μ f_n，接触进入滑动，力闭合破坏。由 δ≈e/r 得 e≥rφ 时失败，故成功否决 H_ε。扰动用引理 13 的 ε 裕度吸收，失败概率上界 β_g 由裕度/扰动之比经 Chebyshev 或实测标定给出。∎

**意义**：这把一次成功抓取变成一条**物理几何标注**——它以 ≥1-β_g 的置信声明「位姿误差小于 ε」。这正是 PSAC 能把物理结果回灌给感知证书的合法性来源。

### 引理 15（标注噪声下的 conformal 覆盖下界）
**陈述**：设校准样本的观测标签以概率 ≤η 被任意污染（最坏情形：污染样本的非一致性分数被置为 0），干净分数与测试分数可交换，分数取值于 [0,1]。则 split-conformal 的实际覆盖满足
`ℙ(Y∈C(X)) ≥ 1 - α/(1-η) = (1-α-η)/(1-η)`，
有限样本下再有 O(1/n) 的修正。

**证明**：设干净分数 CDF 为 F，污染后分数 CDF 为 `F_η(t) = (1-η)F(t) + η·G(t)`，其中最坏情形 G(t)=1[t≥0]（污染分数恒为 0，最有利于「看起来合规」，从而把阈值 q 压到最低）。分位数 q 满足 `F_η(q) = 1-α`，即 `(1-η)F(q) + η = 1-α`，解得 `F(q) = (1-α-η)/(1-η) = 1 - α/(1-η)`。测试样本覆盖概率为 `F(q)`，故下界成立；其余污染分布 G 只会使 q 更大、覆盖更高，故该式是下确界。有限样本由 conformal 分位数 `⌈(n+1)(1-α)⌉/n` 的 DKW 型界给出 O(1/√n) 修正。∎

**推论 15.1（噪声预算）**：若要求覆盖不低于 α_target，则必须 `η ≤ 1 - α/α_target`。例如 α=0.05、α_target=0.945 时 η≤0.091；α_target=0.94 时 η≤0.167。这把「标注质量」翻译成了一条可审计的数值红线。

### 引理 16（选择偏差下的加权覆盖）
**陈述**：物理自标注只覆盖被尝试抓取的样本，且失败样本可能删失。以倾向得分 `w(x)=1/e(x)`（或密度比 dP_test/dP_cal）对校准分数加权，若权重精确且 `W=sup w<∞`，则加权 conformal 覆盖 ≥1-α；若权重估计误差为 δ_w，则覆盖 ≥1-α-δ_w。若 `ESS=(Σw)²/Σw² < n_min`，证书拒绝发放（无有效保证）。

**证明**：加权 conformal 的交换性由重要性采样恢复：在权重精确时，加权经验分布依分布收敛到测试分布，故分位数阈值给出 ≥1-α 覆盖（Tibshirani et al., 2019）。权重误差经总变差耦合，最多使覆盖再降 δ_w。ESS 刻画权重退化：ESS 过小时少数样本主导分位数，方差爆炸，任何有限样本保证失效，故必须显式拒绝。∎

### 定理（GGA-UC 的可靠性与单调退化链保持）
**陈述**：对任意多机计划 Π，`GGA-UC.admits(Π)=True` ⟺ Π 同时满足 v25 的十项条件，且每个含接触子计划满足 GrC，且其校准源满足 AnC，且其物理标注源满足 PSAC。并且，若闭环在任一证书失败时冻结/退回 v25，则对每一轮 t 有 `Exec_v26^(t) ⊆ Exec_v25^(t) ⊆ … ⊆ Exec_v18`。

**证明**：充分性由 `admits` 的连言结构直接得到。必要性：任一项缺失即对应一类未被缓解的风险（抓取力学、标注噪声、选择偏差、上游十类），`admits` 返回 False。单调性：`Exec_v26` 被定义为 `Exec_v25` 与三个过滤器的交集，集合交恒为子集；闭环冻结规则保证失败轮不会把未验证的物理标签并入校准集，因此不会出现「用坏标注放宽证书」的逆向更新。∎

### 命题（闭环安全的充分条件，非收敛性定理）
**陈述**：若每一轮满足 (i) `η_t ≤ η_budget`，(ii) `W_t ≤ W_max` 且 `ESS_t ≥ n_min`，(iii) 每次成功抓取满足引理 14 的假设检验，则闭环的每轮覆盖承诺均成立，且不会因自标注而单调恶化。反之，任一条件破裂时证书冻结。
**说明**：本命题只保证「逐轮安全」，不保证闭环收敛到更高覆盖率；收敛性依赖抓取分布对部署分布的覆盖速度，属于开放问题（见 R19）。我们不把「越抓越准」当作已证结论。

| η | 实测覆盖均值 | 实测覆盖 5% 分位 | 理论下界 1-α/(1-η) | 名义 1-α |
|---|---|---|---|---|
| 0.00 | 0.9509 | 0.9403 | 0.9500 | 0.9500 |
| 0.05 | 0.9491 | 0.9361 | 0.9474 | 0.9500 |
| 0.10 | 0.9449 | 0.9314 | 0.9444 | 0.9500 |
| 0.15 | 0.9427 | 0.9284 | 0.9412 | 0.9500 |
| 0.20 | 0.9389 | 0.9236 | 0.9375 | 0.9500 |
| 0.30 | 0.9315 | 0.9141 | 0.9286 | 0.9500 |

结论：实测覆盖始终不低于理论下界，且随 η 增大平滑退化；最坏替换下 30% 噪声仍保有 ~93.2% 覆盖，但已低于 94% 任务红线——这正说明 AnC 的噪声预算必须显式拒绝而非默默接受。作为对照，若污染分数改为均匀分布或「标签翻转」型（通常抬高阈值），实测覆盖会**高于**名义值（0.97–0.99），说明引理 15 的下界是保守但正确的。

### 5.3 预期结果与判据
- 若 GrC 的 ε_rob 与真实抓取成功率单调相关（Spearman ρ≥0.6），则力闭合证书具备预测力；
- 若噪声修正阈值相对名义阈值的实测覆盖差 <1%，说明该任务下标注噪声主要是「抬高阈值」型而非「压低阈值」型，可放宽 η_budget；
- 若 PSAC 的加权 ESS < n_min 频繁触发，说明选择偏差过强，必须扩大探索性抓取（随机化倾向）而非强行加权。

## 7. 本轮最大风险（最终确认）

**一句话**：**「抓取即标注」把物理执行变成了校准源，却同时引入了选择偏差与自我确认——当感知系统在一小撮可反复抓取的可达物体上系统性错误但仍能抓成功时，GrC、AnC、PSAC 会互相背书并通过 GGA-UC，而独立人工校准集的分布偏移又不足以揭穿它，最终在部署分布上出现「证书全绿、抓取全败」的群体级失效。**
