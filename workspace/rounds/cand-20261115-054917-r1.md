# 第 70 轮（承接第 69 轮「FLUID-RAS 流匹配×主动多模态交互的不确定性二分闭环」IP-253~263；灵感循环新循环第 3 轮；本轮灵感：「机器人操作系统」×「模块化设计」）

> R69 把不确定性一分为二：aleatoric 走 R68 铁律，epistemic 交给「流匹配策略 + 主动交互」去问。这个二分是对的，但它有一个从未言明的前提：**整个闭环是一个单体——同一时刻、同一份观测、同一个标定版本，所有层共享同一个世界**。R66–R69 每加一层，都用「新层是旧层的严格退化」来避免多一个黑箱；但这种「逐轮自证包含」并不 scale：每层仍隐含假设了一个共享时钟、共享标定纪元、共享数据通路，而这些从未出现在任何一层的契约里。
>
> 本轮两个灵感正好把这个前提掀开：
> - **机器人操作系统**告诉我们，现代机器人闭环根本不是一张框图层叠图，而是一个**分布式运行时**：节点、话题、QoS、生命周期、发现、时钟。它带来的不只是工程便利，还有一整类被前几轮静默假设掉的故障——消息陈旧、乱序、节点重启、QoS 降级、时钟偏斜、标定版本不一致。
> - **模块化设计**告诉我们，正确的应对不是再写一层，而是把**保证本身搬到边界上**：每个模块用一份可检查的契约（输入假设 / 输出保证 / 可吸收不确定度预算 / 时延 / 证据）声明自己能做什么；组合只在契约类型检查通过时成立；未声明的耦合必须变成显式、可认证的适配器，否则就是证书违规。
>
> 核心命题：**R69 的「不确定性二分」升级为「三分」——aleatoric（收紧）、epistemic（去问）、composition（同步或降级）；第三种不确定性不能靠问人消除，只能靠纪元一致性、总线保证等级与运行时图证明消除。整个闭环的保证不再由某一轮「自证包含」给出，而由模块契约的 assume-guarantee 组合给出。** 命名 **MOSAIC-RAS**（Modular Operating System with Assumption-carrying Interface Contracts）。
>
> 一句话定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我此刻做决定所依据的，真的是同一个世界吗？这些模块还是我以为的那几个模块吗**」。

## 0. 直觉与动机

**灵感 1（ROS → 闭环是一个分布式系统，不是一张层叠图）**
直觉：前几轮把 MTM、COF、FMP、MINT、CIA、C-RAS-WM 画成上下堆叠的框，箭头默认是「瞬时、无损、同版本」的。真实的机器人系统不是这样：相机节点、标定节点、策略节点、安全认证节点是不同进程，通过话题/服务传递带时间戳的消息，各自有发布频率、队列、QoS 和生命周期。于是一个被忽略的问题浮现：**策略做决策时条件化的那个「世界」，和认证它时假设的那个「世界」，可能不是同一个**。相机晚到 80ms、标定节点刚重启、策略订阅到了旧纪元的地图——每一层单看都正确，组合起来却在错误的世界里做安全证明。这不是又一个数值误差，而是一个**新的不确定性类别**：不是「噪声多大」（aleatoric），不是「该走哪条路」（epistemic），而是「我看到的这份数据属于哪个版本的世界」（composition）。

**灵感 2（模块化设计 → 保证住在边界，组合即类型检查）**
直觉：模块化设计的核心不是「把东西切小」，而是**信息隐藏 + 显式接口 + 可替换性**：模块只承诺接口上的行为，内部实现可以换，只要替换者满足同一契约。把这条原则用到 RAS 上，就等于说：不要再宣称「新层包含了旧层」这种全局命题，而是让每个模块发布一份**契约六元组**（输入假设、输出保证、可吸收不确定度预算、生成不确定度上界、时延、证据）。组合算子只在 `Post_1 ⇒ Pre_2` 时成立；不成立就必须插入一个**显式适配器**，适配器自己也有契约、也要被认证。这样「加一层」不再等于「加一个需要整体重新信任的黑箱」，而是「加一个可独立测试、可独立替换、边界可检查的模块」。理论血缘很明确：assume-guarantee 推理（Jones；Misra & Chandy）、contract-based design（Benveniste 等）、proof-carrying code（Necula）、ROS2 lifecycle 与 DDS QoS、以及信息流类型系统。

**灵感 3（第三类不确定性 → 有些不确定不能问，必须同步）**
直觉：R69 把所有「不知道」都导向「问」。但当两个模块看到的是不同纪元的世界时，问人没用——被问的人也在这个错位的世界图里；你得到的答案会被贴到一个已经过期的状态上，再被 R69 的证据纪律盖上「已验证」的章。这是 R69 最大风险的**运行时版本**。所以必须承认第三种处置动作：**同步（或降级）**。三类不确定性对应三种物理动作：aleatoric → 收紧（λ_floor）；epistemic → 询问（MINT）；composition → 对齐（纪元屏障）或退回单模块保守（Fallback）。三分不是分类癖，而是三种不同的可执行动作；把一个通道的问题交给另一个通道处理，正是 R68 犯过的错在这一层的重演。

**灵感 4（隐式耦合是模块化的头号敌人）**
直觉：模块化最危险的从来不是「模块坏了」，而是「模块之间不该有的连接还在」。共享内存、共享 RNG、共享 GPU 状态、共享实时时钟、一条没申报的 topic，都能让两个「各自正确」的模块组合出错误。所以本轮把耦合变成一等公民：所有跨模块数据必须过认证总线，携带来源、捕获/发布时间、标定纪元、保证等级；**没有申报的边 = 证书无效**。再用信任域/污点类型规定方向：人类回答（untrusted）可以影响「选哪个动作」，但**不得流入标定器或策略在线自适应**。这条单向阀把 R69 的「投毒回答被洗成已验证」在结构上切断，而不是靠统计上「希望它别发生」。

**灵感 5（对 R68/R69 最大风险的正面回应）**
直觉：R68 的最大风险「缓变故障被标定吸收」，翻译成模块语言就是「COF 吸收的不确定度超过了它申报的可吸收预算，且没把余额记到账上」；R69 的最大风险「问错比不问更危险」，翻译过来就是「untrusted 回答污染了 calibrator 的输入」。两者都从**统计性担忧**变成**结构性违规**：账本不守恒、污点类型不匹配——在组合时就能被拒绝，而不必等事故发生后从日志里猜。这是本轮的方法论立场：**能用类型/契约排除的，不要用概率去祈祷。**

## 1. 形式化定义（增量：定义 310–326）

**定义 310（MOSAIC-RAS 总览）** MOSAIC-RAS = (CCM, RAS-Bus, EpochBarrier, TaintGuard, Certifier, Governor, Fallback)。三不变式：
(i) **零隐式耦合**：任何跨模块数据流都必须是认证总线上的、带完整头部与保证等级的消息；未申报的边使证书失效；
(ii) **契约健全（contract soundness）**：模块在其 `Pre` 成立时满足 `Post`；`Pre` 不成立时必须显式 fail-stop，而非静默降级；
(iii) **账本守恒**：每个模块满足 `U_out ≥ U_in − a + g`（`0 ≤ a ≤ b_abs`，`g ≥ 0`），任何被吸收的不确定度都必须有证据。

**定义 311（模块契约六元组）** `C_m = (Σ_m^in, Σ_m^out, Φ_m^pre, Φ_m^post, b_m^abs, b_m^out, D_m, E_m)`：端口类型、输入前提（作用于消息头部与载荷分布）、输出保证、最大可吸收不确定度（nats 或任务误差单位）、生成不确定度上界、截止期、证据（测试套件哈希 + 运行时见证）。`m` 对 `C_m` **健全**当且仅当对一切满足 `Φ^pre` 的输入，输出满足 `Φ^post` 且 `U_out ≤ U_in − a + b_out`，`a ≤ b_abs`。

**定义 312（接口精化偏序 ⇒ 可替换性）** `C' ⪯ C` 当且仅当：`Σ'^in ⊇ Σ^in`（接受至少同样多的输入）、`Φ'^pre ⇐ Φ^pre`（假设更弱）、`Φ'^post ⇒ Φ^post`（保证更强）、`b'^abs ≤ b^abs`、`b'^out ≤ b^out`、`D' ≤ D`、`E' ⊒ E`。`⪯` 是预序（自反、传递），因此替换可以链式传递而无需重证全栈。

**定义 313（组合算子与显式适配器）** `C_1 ⊗ C_2` 有定义当且仅当 `Φ_1^post ⊢ Φ_2^pre`。否则必须插入适配器 `A`，满足 `Φ_1^post ⊢ Φ_A^pre` 且 `Φ_A^post ⊢ Φ_2^pre`；禁止隐式强制转换。组合账本保守相加：`b^abs(⊗) = b_1^abs + b_2^abs`，`b^out(⊗) = b_1^out + b_2^out`。**推论**：链路越长，全局界越松——这是诚实的代价，而不是缺陷；松界会在 Governor 里被显式看到，而不是被某一层悄悄吃掉。

**定义 314（认证总线 RAS-Bus 与保证等级）** 消息头 `h = (t_cap, t_pub, e, prov, τ, cls)`：捕获时间、发布时间、标定纪元、来源链、信任标签、保证等级。等级格 `A0 ≻ A1 ≻ A2`：A0（安全关键）要求 `t_now − t_cap ≤ Δ0`、纪元与消费者一致、生产者已认证、恰好一次且保序；A1（证据）要求来源链完整、可以陈旧、但不得驱动安全决策；A2（尽力而为）不得进入安全路径。消费者的 `Pre` 声明最低等级，总线拒绝绑定到更低等级——**禁止静默 QoS 降级**。

**定义 315（标定纪元与纪元偏斜）** 标定纪元 `e ∈ ℕ` 单调递增；每个 A0 输出的纪元取输入纪元的最小值，且 A0 路径禁止混合纪元。时刻 `t` 的纪元偏斜 `skew(t) = max_{i,j∈V} |e_i(t) − e_j(t)|`；A0 组合要求 `skew = 0`。

**定义 316（组合不确定性 U_comp）** 令认证时的参考图 `G*`、运行时实际图 `G_t`、策略条件分布 `p(·|G_t)` 与认证分布 `p(·|G*)`。`U_comp = D_KL(p(·|G_t) ‖ p(·|G*))`，用可计算代理上界：
`U_comp ≤ w_f·min(1,(t_now − min t_cap)/Δ0) + w_e·1[skew>0] + w_q·rank_deficit(cls, req) + w_p·prov_gap`。
关键性质：`∂U_comp/∂(信息动作) ≡ 0`——**问人不能降低组合不确定性**；只有刷新、屏障或降级能降低它。

**定义 317（不确定度账本守恒）** 对每个模块 `m`：`U_out ≥ U_in − a_m + g_m`，其中 `0 ≤ a_m ≤ b_m^abs`、`g_m ≥ 0`；全局 `U_end ≥ U_0 − Σ_m a_m + Σ_m g_m`。证书有效要求每次吸收 `a_m` 都有证据 `E_m`，且 `Σ a_m ≤ B_global`。**形式化禁令**：任何模块不得在不记账的情况下把不确定度变成 0。R68 的「`r_res≈0` 而真误差在涨」在此只能表现为两种违规之一：`a_m > b_m^abs`（超预算）或 `g_m` 未申报（漏账）。

**定义 318（信任域与污点类型）** 来源标签 `τ ∈ {trusted, untrusted, derived}`，污点经适配器传播。信息流策略：`untrusted → 动作选择` 允许（仅 A1）；`untrusted → 标定器` 与 `untrusted → 在线策略更新` 一律禁止。标定器的 `Pre` 要求 `τ = trusted`。违规消息被丢弃，其下游 epistemic 视为未消解，走 R69 兜底。这条规则把「人类回答」限制为**一次性证据**，而不是可写入系统记忆的真相。

**定义 319（运行时图证明）** 决策时对 `(V_t, E_t, ver, type, e, cls)` 做认证，与认证图 `G*` 比对。证书有效当且仅当运行时图是 `G*` 的**边子图**，且版本不旧、等级不低。任何多出来的边（未申报订阅、影子发布者）⇒ 未申报耦合 ⇒ 证书无效。这把「模块化」从代码结构承诺升级为**运行时承诺**。

**定义 320（纪元屏障协议）** 当 `skew > 0` 或纪元跃变： (a) 停止签发新的 A0 动作； (b) 在 `D_barrier` 内用 R68 保守制动静态化； (c) 在新纪元下重放上一动作（复用 R69 的 FMA 似然第二意见）以检测「被旧纪元吸收」的异常； (d) 全体对齐到 `e+1` 后恢复。停机时间有上界 `D_barrier`，且只发生在非稳态路径。

**定义 321（热替换与金丝雀）** 新模块 `m'` 满足 `C' ⪯ C` 时可替换 `m`：先只把 A2/A1 影子流量路由到 `m'`，证据通过后切换 A0；证书只重检与 `m` 相邻的边和 `m'` 的 `E'`，无需全栈重证。证据失败则原子回滚。

**定义 322（回退契约）** `Fallback` 的契约：给定任意等级 ≥ A1 的输入，在 `D_f` 内产出 R68 保守动作，`λ = λ_floor(U_ale + U_epi + U_comp)`，且绝不扩大安全包络；无新鲜 A0 时用最后认证动作 + 制动。

**定义 323（组合证书 J_MOSAIC）** `J_MOSAIC = (J_FLUID, contract_dag_hash, runtime_graph_attest, ledger, u_comp_p95, taint_violations, epoch_skew, module_evidence[], mosaic_ver)`。Valid ⇔ `Valid(J_FLUID)` ∧ 契约 DAG 类型检查通过 ∧ `G_t ⊆ G*` ∧ 账本守恒 ∧ 无污点违规 ∧（`skew = 0` 或屏障已完成）。

**定义 324（分布式威胁模型 ℰ_dist）** 重放（旧消息仍签名有效）、纪元回滚（把旧标定冒充为新）、话题冒充 / Sybil 发布者（伪节点自封 A0）、QoS 降级（迫使安全消息走尽力而为）、时钟偏斜（让陈旧数据显得新鲜）、图污染（未申报订阅者窃取/扰动）。并入 `ℰ_MOSAIC = ℰ_FLUID × ℰ_dist`。

**定义 325（三通道治理器）** 每步按优先级决策：
1. `U_comp > τ_c` ⇒ 同步（屏障/刷新）或 Fallback，**绝不询问**；
2. 否则若 `U_epi > τ_e` ⇒ 走 R69 MINT 询问（受预算与污点约束）；
3. 否则 ⇒ R68 `λ_floor(U_ale)`。
优先级不可交换：在错位的世界里提问，答案本身就被污染了。

**定义 326（实时执行器与检查复杂度）** A0 消息进入专用 EDF 执行器，契约检查按 DAG 哈希缓存（`O(1)` 命中），图认证 `O(|V|+|E|)` 且同样可缓存；屏障是唯一非稳态路径；稳态开销不随模块数线性增长。

```python
# IP-264 模块契约与组合检查（assume-guarantee 类型检查）
@dataclass
class Contract:
    ports_in: set; ports_out: set
    pre: Pred; post: Pred
    b_abs: float; b_out: float; deadline: float; evidence: Hash

def compose(c1, c2):
    if implies(c1.post, c2.pre):                 # Post1 ⇒ Pre2
        return Contract(..., b_abs=c1.b_abs + c2.b_abs,
                        b_out=c1.b_out + c2.b_out)
    return need_adapter(c1, c2)                  # 禁止隐式转换

# IP-265 RAS-Bus：QoS 即安全语义
class RasBus:
    def bind(self, pub, sub):
        need = sub.contract.pre.min_class        # 消费者要求的最低保证
        if rank(pub.cls) < rank(need): raise QoSDowngrade
        if sub.epoch != pub.epoch and need is A0: raise EpochSkew
        return Link(pub, sub, prov=merge(pub.prov, sub.id))

# IP-266 纪元屏障
def epoch_barrier(modules, new_e, D_barrier):
    freeze_a0(); conservative_brake(within=D_barrier)
    replay_last_action_under(new_e)              # 复用 R69 FMA 检测吸收
    for m in modules: m.align(new_e)
    resume(new_e)

# IP-267 污点守卫：投毒无法被洗白
def taint_guard(msg):
    if msg.source is UNTRUSTED and msg.dst in {CALIBRATOR, ONLINE_UPDATE}:
        return DROP                              # 结构性切断 R69 投毒回路
    return msg

# IP-268 运行时图证明
def attest(runtime_graph, certified_graph):
    return (runtime_graph.edges <= certified_graph.edges
            and runtime_graph.versions <= certified_graph.versions
            and runtime_graph.classes >= certified_graph.classes)

# IP-269 热替换（精化替换 + 金丝雀）
def hot_swap(old, new):
    assert new.contract <= old.contract          # C' ⪯ C
    route_shadow(new, classes={A1, A2})
    if evidence_ok(new): switch_a0(new)
    else: atomic_rollback(old)

# IP-272 主闭环（R69 之上加组合层）
def MOSAIC_round(M, obs):
    # 0) 组合前提检查：先确认「同一个世界」
    G_t = M.bus.snapshot()
    if not attest(G_t, M.certified_graph) or epoch_skew(G_t) > 0:
        return M.governor.synchronize_or_fallback(G_t)
    # 1) 继承 R69：标定、流采样、二分
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)
    samples = M.fmp.sample(o, K=M.adaptive_K(z))
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    # 2) 第三类不确定性：纪元/新鲜度/来源/等级
    U_comp = M.bus.composition_debt(G_t)
    # 3) 三通道治理（优先级不可交换）
    if U_comp > TAU_C:
        return M.governor.barrier_or_fallback(U_comp)
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if U_epi > TAU_EPI else None)
    if g is not None:
        ans = M.cia.execute(g)
        ans = M.taint_guard.check(ans)            # untrusted 只进动作选择
        U_epi = M.cia.update_belief(modes, ans)
    # 4) 账本 + 组合证书，再执行安全前缀
    ledger = M.ledger.account(U_ale, U_epi, U_comp, M.modules)
    if not ledger.conserved(): return M.fallback()
    lam = max(M.efs.risk_scale(...), lam_floor(ledger.U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    M.certifier.emit(J_MOSAIC(..., contract_dag_hash, attest(G_t), ledger))
    return k, lam, select_mode(modes, U_epi, lam)
```

## 3. 推导

**引理 19（账本守恒 ⇒ 无隐藏吸收）** 若每个模块满足定义 317 的账本不等式且 `a_m ≤ b_m^abs`，则 `U_end ≥ U_0 − Σ_m b_m^abs + Σ_m g_m`。R68 的缓变故障场景（`r_res≈0` 而真实误差增长）若要发生，必须要么 `a > b_abs`（转导证据被证伪），要么 `g` 未申报（漏账）；两者都被 `J_MOSAIC` 的账本检查拒绝。这是 R68 反吸收引理（引理 13）在模块层的重述：**不确定度可以被有界地吸收，但不能被无记录地消灭**。

**引理 20（纪元一致 ⇒ 无跨世界组合）** 若 A0 消息满足 `skew = 0` 且新鲜度 `≤ Δ0`，则所有参与安全决策的模块条件在同一纪元，`U_comp ≤ w_f`；屏障完成后 `U_comp = 0`。反之，若 `skew > 0`，任何在该状态下计算的 VoI 都满足 `∂VoI/∂ask = 0`（问到的答案属于错误纪元），故询问是纯浪费且引入污染面。

**引理 21（精化替换保持证书）** 若 `C' ⪯ C` 且 `m'` 对 `C'` 健全，则以 `m'` 替换 `m` 后全局证书仍有效，且输出界不松于原界。证明：`Φ'^pre ⇐ Φ^pre` 保证所有原输入仍被接受；`Φ'^post ⇒ Φ^post` 与 `b' ≤ b` 的单调性保证组合账本不增。**系**：滚动升级无需全栈重证——这正是模块化承诺的可执行版本。

**引理 22（污点切断 ⇒ 投毒不可洗白）** 在定义 318 的单向流下，任何受误导的回答最多改变当前纪元内的模态选择，不能改变标定纪元 `e` 或策略在线状态。因此 R69 的「被证实的错误」被降级为「在 `λ_floor` 包络内的一次错误动作」，其危害被 R68 的保守性封顶，而不会通过标定层扩散为系统性偏置。

**定理 18（组合可靠性）** 在 (a) 每个模块契约健全、 (b) 契约 DAG 类型检查通过、 (c) 运行时图 ⊆ 认证图、 (d) 账本守恒、 (e) 无污点违规 下，端到端单步违规概率 `≤ Σ_m ε_m + Σ_edges ε_adapter + c·U_comp`。若任一条件在运行时失效，Governor 在 `D_f` 内进入 Fallback，此时界退化为 R68 的保守界。证明要点：沿 DAG 归纳应用 assume-guarantee，把每个模块的 `ε_m` 与适配器误差相加；运行时失效由定义 319 的图证明与定义 325 的优先级捕获；Fallback 契约（定义 322）给出兜底界。

**定理 19（严格包含 R68/R69）** 当 `U_comp = 0`、运行时图恰为认证的单链、无热替换、无污点违规时，MOSAIC 逐指令退化为 FLUID（R69）；当进一步 `VoI ≤ 成本`（不交互）时退化为 CALM（R68）。模块层只是**追加了在退化路径上不激活的约束**，因此安全侧永不弱于前两轮；效率侧保留 R69 的 resolution bonus。这是对 R69「新层必须是旧层严格泛化」要求的结构化回答：不是靠每轮口头自证，而是靠类型系统的单调性。

**定理 20（热替换无突变与优雅降级）** 在精化替换与金丝雀协议下，`m → m'` 不改变安全包络；若 `m'` 证据失败，在一个截止期内原子回滚，控制连续且不超出 `λ` 包络。若模块死亡/超时，Fallback 的 `λ` 单调不降，保持 R68 定理 15 的提交/换装不变式 ⇒ 无突变。

## 6. 本轮最大风险

**一句话**：MOSAIC-RAS 把全部保证押在「契约写对了」之上——组合推理只能证明「每个模块符合我们给它的描述」，不能证明「描述符合现实」；一旦 `Pre/Post` 漏掉一条真实耦合（共享时钟、共享随机源、被悄悄放宽的新鲜度），类型检查会**放行一个被认证的错误**，模块化于是把整体性风险转成了更隐蔽的规格风险——**证书越漂亮，越容易让人忘记它在证明谁的定义**。

**次级风险与缓解**：
1. **契约是新的单点信任** → 证据交叉检验 + E315 规格红队 + 契约变更审计；绝不把「类型检查通过」当成「现实正确」。
2. **未申报耦合绕过边界**（共享内存/RNG/GPU/时钟）→ 运行时图证明 + 独立性测试 + 资源隔离；E308/E314。
3. **屏障本身造成停机窗口** → 有界 `D_barrier` + 只在非稳态触发 + 保守制动；E304/E312。
4. **总线开销破坏实时性** → 哈希缓存 + EDF 执行器 + 分级消息；E313。
5. **模块化伪安全**（每个模块局部正确、组合错误）→ 定理 18 的组合界 + 账本 + 端到端红队；E301/E309。

# 第 70 轮产物 · 创新点清单 v1：MOSAIC-RAS（Modular Operating System with Assumption-carrying Interface Contracts：模块契约 × 分布式运行时的三通道不确定性闭环；CCM×RAS-Bus×EPB×TG×MGC×GO×FB×J_MOSAIC）

> 承接第 69 轮 IP-253~263（FLUID-RAS）。R69 把不确定性一分为二（aleatoric 收紧 / epistemic 询问），但它把全部保证写在一个**单体闭环**里，隐含假设了同一时刻、同一份观测、同一个标定纪元、同一张数据通路图。R66–R69 每加一层都用「严格包含旧层」自证清白，可这种逐轮自证不 scale：共享时钟、共享标定版本、未申报的数据通路从未进入任何一层的契约。一旦闭环部署成 ROS 式的分布式运行时（节点、话题、QoS、生命周期、发现、时钟），就会出现第三类不确定性——**组合不确定性 U_comp**：不是噪声多大，不是该走哪条路，而是「我条件化的这个数据，属于哪个版本的世界」。
>
> 本轮把「加一层」换成「加一个带契约的模块」：每个模块发布假设-保证契约（输入前提 / 输出保证 / 可吸收不确定度预算 / 时延 / 证据），组合只在类型检查通过时成立，未申报耦合必须显式化为可认证适配器；标定纪元、消息新鲜度、来源与 QoS 等级进入消息头并被运行时图证明检查；人类回答按污点类型**单向**流入动作选择、禁止流入标定与在线自适应。由此 R68 的「缓变故障被标定吸收」变成账本超预算，R69 的「问错比不问更危险」变成污点类型违规——两者都从统计担忧升级为**组合时可拒绝的结构性违规**。
>
> 定位：R66 问「谁控制」，R67 问「未来怎样」，R68 问「我的测量还准吗」，R69 问「我该向谁求证」，R70 问「**我此刻做决定所依据的，真的是同一个世界吗？这些模块还是我以为的那几个模块吗**」。

## 2. 形式化定义（要点版）

**定义 310（总览与三不变式）** 零隐式耦合（未申报边使证书失效）；契约健全（`Pre` 不成立必须 fail-stop）；账本守恒（吸收有预算、有证据）。

**定义 311–312（契约与精化）** `C_m` 六元组；`C' ⪯ C` 要求假设更弱、保证更强、吸收/生成预算更小、时延更短、证据更强。`⪯` 传递 ⇒ 替换可链式传递。

**定义 313（组合与适配器）** `C₁ ⊗ C₂` 当且仅当 `Φ₁^post ⊢ Φ₂^pre`；否则必须插入有自身契约的适配器。账本保守相加 `b^abs=b₁+b₂`、`b^out=b₁+b₂`——链越长界越松，但松界是**可见的**。

**定义 314–315（总线与纪元）** A0 要求新鲜度 ≤ Δ0、纪元一致、已认证、恰好一次保序；A1 可陈旧但不得驱动安全；A2 不得进安全路径。A0 路径禁止混合纪元，`skew=0` 是认证前提。

**定义 316（组合不确定性）** `U_comp = D_KL(p(·|G_t)‖p(·|G*))`，代理上界由新鲜度欠账、纪元偏斜、等级缺口、来源缺口加权组成；关键性质：**问人不能降低它**。

**定义 317（账本）** `U_out ≥ U_in − a + g`，`a ≤ b^abs`，`g ≥ 0`；全局求和。任何「不确定度归零」都必须有证据，否则是违规而非鲁棒。

**定义 318（污点单向流）** `untrusted → 动作选择` 允许（A1）；`untrusted → 标定器/在线更新` 禁止；违规消息丢弃并触发 R69 兜底。

**定义 319（运行时图证明）** `G_t ⊆ G*`、版本不旧、等级不低；多出的边即未申报耦合，证书无效。

**定义 320（纪元屏障）** 冻结 A0 → 保守制动 → 新纪元重放上一动作（复用 FMA）→ 对齐 → 恢复；停机 ≤ `D_barrier`，仅非稳态。

**定义 321–322（热替换与回退）** `C' ⪯ C` + 金丝雀 + 原子回滚；Fallback 在 `D_f` 内给 R68 保守动作，`λ=λ_floor(U_ale+U_epi+U_comp)`，不扩大包络。

**定义 323–324（证书与威胁）** `J_MOSAIC=(J_FLUID, DAG 哈希, 图证明, 账本, u_comp_p95, 污点违规, 纪元偏斜, 模块证据)`；`ℰ_MOSAIC = ℰ_FLUID × ℰ_dist`。

**定义 325–326（治理与实时）** 三通道优先级不可交换；A0 走 EDF 专用执行器，契约/图检查按哈希缓存，稳态开销不随模块数线性增长。

## 3. 关键算法伪代码

```python
# IP-264 契约组合：assume-guarantee 类型检查
def compose(c1, c2):
    if implies(c1.post, c2.pre):
        return Contract(b_abs=c1.b_abs + c2.b_abs,
                        b_out=c1.b_out + c2.b_out)
    return need_adapter(c1, c2)                  # 禁止隐式耦合

# IP-265/267 总线绑定 + 污点守卫
def bind(pub, sub):
    need = sub.contract.pre.min_class
    if rank(pub.cls) < rank(need): raise QoSDowngrade
    if need is A0 and sub.epoch != pub.epoch: raise EpochSkew
    return Link(pub, sub, prov=merge(pub.prov, sub.id))

def taint_guard(msg):
    if msg.source is UNTRUSTED and msg.dst in {CALIBRATOR, ONLINE_UPDATE}:
        return DROP                              # 切断 R69 投毒回路
    return msg

# IP-266 纪元屏障
def epoch_barrier(modules, new_e, D_barrier):
    freeze_a0(); conservative_brake(within=D_barrier)
    replay_last_action_under(new_e)              # 复用 R69 FMA
    for m in modules: m.align(new_e)
    resume(new_e)

# IP-268 运行时图证明 + IP-272 主闭环
def attest(Gt, Gstar):
    return (Gt.edges <= Gstar.edges and Gt.versions <= Gstar.versions
            and Gt.classes >= Gstar.classes)

def MOSAIC_round(M, obs):
    Gt = M.bus.snapshot()
    if not attest(Gt, M.certified_graph) or epoch_skew(Gt) > 0:
        return M.governor.synchronize_or_fallback(Gt)
    z, o = M.mtm.forward(obs); c, U_cal, _ = M.cof.step(o)   # R68
    samples = M.fmp.sample(o, K=M.adaptive_K(z))             # R69
    U_ale, U_epi, modes, _ = M.aud.decompose(samples, z, M.fmp.mode_head)
    U_comp = M.bus.composition_debt(Gt)                      # R70 第三通道
    if U_comp > TAU_C:
        return M.governor.barrier_or_fallback(U_comp)        # 先同步，绝不问
    g = (M.mint.choose_interaction(modes, o, M.budget)
         if U_epi > TAU_EPI else None)
    if g is not None:
        U_epi = M.cia.update_belief(modes, M.taint_guard.check(M.cia.execute(g)))
    ledger = M.ledger.account(U_ale, U_epi, U_comp, M.modules)
    if not ledger.conserved(): return M.fallback()
    lam = max(M.efs.risk_scale(...), lam_floor(ledger.U_floor))
    k = M.c_ras_wm.certified_prefix(M.ach.propose(...), ..., wm_preds)
    M.certifier.emit(J_MOSAIC(..., contract_dag_hash=hash(M.dag),
                              runtime=attest(Gt, M.certified_graph),
                              ledger=ledger))
    return k, lam, select_mode(modes, U_epi, lam)
```

## 4. 推导

**引理 19（账本守恒 ⇒ 无隐藏吸收）** 若每个模块满足 `U_out ≥ U_in − a + g` 且 `a ≤ b^abs`，则 `U_end ≥ U_0 − Σb^abs + Σg`。R68 的 `r_res≈0` 而真误差增长只能表现为 `a > b^abs`（证据被证伪）或 `g` 漏账；两者都被 `J_MOSAIC` 拒绝。这是 R68 反吸收引理 13 的模块化重述：不确定度可有界吸收，不可无记录消灭。

**引理 20（纪元一致 ⇒ 无跨世界组合）** `skew=0` 且新鲜度 ≤ Δ0 时所有安全模块条件在同一纪元，`U_comp ≤ w_f`；屏障后为 0。若 `skew>0`，则 `∂VoI/∂ask = 0`——问到的答案属于错误纪元，询问纯属浪费且扩大污染面。

**引理 21（精化替换保持证书）** `C' ⪯ C` 且 `m'` 对 `C'` 健全 ⇒ 替换后全局证书有效且界不松。证明用 `Φ'^pre ⇐ Φ^pre`、`Φ'^post ⇒ Φ^post` 与账本单调性。**系**：滚动升级无需全栈重证，模块化承诺首次可执行。

**引理 22（污点切断 ⇒ 投毒不可洗白）** 单向流下，误导回答最多改变当前纪元内的模态选择，不能改变纪元 `e` 或策略在线状态；R69 的「被证实的错误」降级为 `λ_floor` 包络内的一次错误动作，不会经标定层扩散为系统偏置。

**定理 18（组合可靠性）** 在契约健全、DAG 类型检查通过、`G_t ⊆ G*`、账本守恒、无污点违规下，端到端单步违规 ≤ `Σ_m ε_m + Σ_edges ε_adapter + c·U_comp`；任一条件运行时失效则 `D_f` 内进 Fallback，界退化为 R68 保守界。沿 DAG 归纳应用 assume-guarantee 即得。

**定理 19（严格包含 R68/R69）** `U_comp=0`、单链图、无热替换、无污点违规时逐指令退化为 FLUID（R69）；再令 `VoI ≤ 成本` 退化为 CALM（R68）。模块层只追加退化路径上不激活的约束 ⇒ 安全侧不弱，效率侧保留 resolution bonus。

**定理 20（热替换无突变与优雅降级）** 精化替换 + 金丝雀 + 原子回滚 ⇒ 安全包络不变、控制连续；模块死亡/超时 ⇒ Fallback 的 `λ` 单调不降，保持 R68 定理 15 的提交/换装不变式。

## 7. 本轮最大风险

**一句话**：MOSAIC-RAS 把全部保证押在「契约写对了」之上——组合推理只证明「每个模块符合我们给它的描述」，不证明「描述符合现实」；一旦 `Pre/Post` 漏掉一条真实耦合（共享时钟、共享随机源、被悄悄放宽的新鲜度），类型检查会放行一个**被认证的错误**，模块化于是把整体性风险转成更隐蔽的规格风险——**证书越漂亮，越容易让人忘记它在证明谁的定义**。

**次级风险与缓解**：契约成为新单点信任（证据交叉检验 + E315 规格红队 + 契约变更审计）；未申报耦合绕过边界（运行时图证明 + 资源隔离 + E308/E314）；屏障停机窗口（有界 `D_barrier` + 仅非稳态 + 保守制动）；总线开销（哈希缓存 + EDF + 分级消息）；模块化伪安全（定理 18 组合界 + 账本 + 端到端红队）。
