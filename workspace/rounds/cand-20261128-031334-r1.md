### 第 5 轮灵感驱动研究记录

**灵感词**：关节空间控制、激光雷达

**继承关系**：第 4 轮 CADVS-v4（IP-489~492）在 v3 五锚点之上追加价值锚 VACK（kc_val）与平衡锚 BCK（kc_bal），形成七硬门 kc_evidence_forged_v4 = kc_coverage ∧ kc_physics ∧ kc_human ∧ kc_ee ∧ kc_mem ∧ kc_val ∧ kc_bal，fail-closed；软评分 ECS_v4 = ECS_v3·η_val·η_bal；执行集嵌套 Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。本轮不推翻 v4，而是沿「关节空间控制」与「激光雷达」两个方向补强，形成 CADVS-v5（IP-493~496），执行集嵌套升级为 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ Exec_CADVS-v3 ⊆ Exec_CADVS-v2 ⊆ Exec_CADVS-v1 ⊆ Exec_v29。

**直觉与动机**：

1. **关节空间控制：任务空间证书的「可执行性」缺口**。v4 的 EEK/BCK 都在操作空间/接触空间作证（末端位姿、力/力矩、Wrench 锥、ZMP）。但真正出力的是关节：一条规则可以在任务空间全部通过，却在关节空间不可行——某关节逼近限位、力矩饱和、速度超限，或经过运动学奇异点使 J 降秩、关节速度爆炸、控制权限丧失。直觉上，任务空间证书回答「想做的是否合理」，关节空间证书回答「关节是否真的做得到、且留有余量」。引入关节空间可行性核 JSFK，证书 JFC = (ξ_lim, ξ_vel, ξ_tau, ξ_manip, ρ_joint, t)，硬门 kc_joint。它是 EEK/BCK 的「对偶锚」，不是重复。

2. **激光雷达：空间覆盖的「几何落地」缺口**。v3/v4 的空间锚 3DCF 以抽象覆盖场 Γ_3D 表示，可能由相机/深度/先验地图估计，未直接约束「关键区域是否被真实测到」。激光雷达提供直接米制几何，但有其特有失效：远距稀疏、遮挡、镜面/透明表面、雨雾尘、运动畸变、配准漂移、动态物体。直觉上，LiDAR 证书回答「我声称看得见的区域，是否真被足够密度的回波覆盖，且没有漏掉会动的障碍」。引入激光雷达几何证据核 LGEK，证书 LEC = (r_reg, γ_cov, ξ_occ, h_lidar, ξ_dyn, t)，硬门 kc_lidar。

3. **时标耦合：用证书演算的时序投影统一两个新锚**。关节核在 1 kHz 控制环内，LiDAR 核在 10–20 Hz 感知环内，二者不能硬同步。复用 v4 CERTCALC 的时序投影 □_T：把 LEC 封装为 □_{T_stale} kc_lidar，控制环只消费「未过期」的几何证书，过期即 fail-closed。这把「感知-控制时标失配」显式变成证书语义，而不是隐式的数据竞争。

**关键洞见**：v4 的七锚点回答「覆盖/物理/人因/末点/记忆/价值/平衡」；v5 追加关节锚回答「关节级可实现性与控制权限」（JSFK）与激光雷达锚回答「几何证据的真实度量基础」（LGEK），并用时序投影把跨时标证书缝合成统一证据链。九硬门 kc_evidence_forged_v5 = kc_evidence_forged_v4 ∧ kc_joint ∧ kc_lidar，fail-closed；软评分 ECS_v5 = ECS_v4·η_joint·η_lidar。两个新锚分别补上「任务空间→关节空间」与「抽象覆盖→米制几何」两处推理断点，理论上是非冗余的（见对偶一致性定理与几何接地定理）。

**形式化目标（增量）**：
1. 定义关节可行性证书 JFC = (ξ_lim, ξ_vel, ξ_tau, ξ_manip, ρ_joint, t) 与硬门 kc_joint，软因子 η_joint。
2. 定义激光雷达几何证书 LEC = (r_reg, γ_cov, ξ_occ, h_lidar, ξ_dyn, t) 与硬门 kc_lidar，软因子 η_lidar，并以 □_{T_stale} 给出时效语义。
3. 证明关节-任务对偶一致性定理：任务空间可行 ∧ 关节空间可行 ⇒ 存在满足限位/速度/力矩/奇异约束的关节实现；反向不成立（构造近奇异反例，任务空间力矩有界而关节力矩发散）。
4. 证明激光雷达几何接地定理：在 3DCF 声明关键区覆盖的前提下，若 LiDAR 覆盖不足，则存在对非 LiDAR 模态不可见的对抗障碍，故 kc_lidar 严格收缩执行集。
5. 定义 EFA-v5 九硬门与软评分 ECS_v5 = ECS_v4·η_joint·η_lidar，并证明 Exec_CADVS-v5 ⊆ Exec_CADVS-v4 严格收缩。

**本轮最大风险**：激光雷达证书的时标（10–20 Hz、20–100 ms 延迟、点云运动畸变）与 1 kHz 关节控制环严重失配；强制同步会破坏实时性，而使用过期证书则可能在快速运动下让 kc_lidar 基于滞后几何误判动态障碍，造成漏检或频繁误停。

| 符号 | 含义 |
|---|---|
| q, q̇, τ ∈ R^n | 关节位置/速度/力矩，n 为自由度 |

| Δ_i | 关节 i 的限位归一化尺度（取 min(q_i^max−q_i^min, 2·安全行程)） |

| ξ_vel = min_i (q̇_i^max−|q̇_i|)/q̇_i^max | 关节速度余量 |

| T_t ∈ SE(3) | 点云到地图的配准变换 |

### IP-493 JSFK：关节空间可行性核（控制环内，目标 < 0.2 ms）

```python
@dataclass
class JointSpaceFeasibilityKernel:
    """JSFK：限位/速度/力矩余量、可操作度、关节通过性；kc_joint 硬门"""
    eps_lim: float = 0.05
    eps_vel: float = 0.05
    eps_tau: float = 0.05
    eps_manip: float = 0.10
    sigma_ref: float = 0.05
    q_min: np.ndarray = None
    q_max: np.ndarray = None
    dq_max: np.ndarray = None
    tau_max: np.ndarray = None

    def observe(self, q, qd, tau, J, t_now) -> JFC:
        """q/qd/tau 为关节状态估计；J 为任务雅可比；全部 O(n)~O(n^3)"""
        # 1) 限位余量（逐关节归一化，取最小）
        xi_lim = float(np.min(np.minimum(
            (q - self.q_min) / self._delta(), (self.q_max - q) / self._delta())))
        # 2) 速度余量
        xi_vel = float(np.min((self.dq_max - np.abs(qd)) / self.dq_max))
        # 3) 力矩余量（饱和裕度）
        xi_tau = float(np.min((self.tau_max - np.abs(tau)) / self.tau_max))
        # 4) 奇异余量：最小奇异值 / 参考值（SVD O(n^3)，n=7~14）
        sigma_min = float(np.linalg.svd(J, compute_uv=False)[-1])
        xi_manip = sigma_min / self.sigma_ref
        # 5) 关节通过性：单关节导纳实部下界（离线表 + 在线插值）
        rho_joint = self._joint_passivity(q, qd, tau)
        return JFC(xi_lim=xi_lim, xi_vel=xi_vel, xi_tau=xi_tau,
                   xi_manip=xi_manip, rho_joint=rho_joint, t=t_now)

    def kc_joint(self, jfc: JFC) -> bool:
        """引理 43：通过 ⟹ 全关节限位内、未饱和、远离奇异、严格被动"""
        return (jfc.xi_lim >= self.eps_lim
                and jfc.xi_vel >= self.eps_vel
                and jfc.xi_tau >= self.eps_tau
                and jfc.xi_manip >= self.eps_manip
                and jfc.rho_joint >= 0.0)

    def _delta(self) -> np.ndarray: ...
    def _joint_passivity(self, q, qd, tau) -> float: ...
```

### IP-494 LGEK：激光雷达几何证据核（感知环内，10–20 Hz，~20–100 ms）

```python
@dataclass
class LiDARGeometricEvidenceKernel:
    """LGEK：配准残差、遮挡感知覆盖、健康度、动态障碍净空；kc_lidar 硬门 + □_T"""
    eps_reg: float = 0.03       # m，配准残差上限
    gamma_min: float = 0.95     # 关键区最小覆盖比
    eps_occ: float = 0.90       # 遮挡净空下限
    h_min: float = 0.80         # LiDAR 健康度下限
    eps_dyn: float = 1.0        # 动态障碍净空下限
    T_stale: float = 0.10       # s，证书最大时滞
    k_hits: int = 2             # 体素被判定为「已覆盖」的最少回波数

    def observe(self, P_t, map_M, V_crit, O_dyn, t_now) -> LEC:
        # 1) 配准：GICP/NDT 求 T_t 与鲁棒残差
        T_t, r_reg = self._register(P_t, map_M)
        # 2) 遮挡感知覆盖：体素回波计数 + 从传感器出发的可见性射线
        gamma_cov, occ = self._coverage(P_t, V_crit, T_t, self.k_hits)
        # 3) 健康度：回波率、强度分布、距离噪声、天气/污损退化检测
        h_lidar = self._health(P_t)
        # 4) 动态障碍：聚类/跟踪得到 O_dyn，计算扫掠体净空
        xi_dyn = self._dynamic_clearance(P_t, O_dyn, T_t)
        return LEC(r_reg=r_reg, gamma_cov=gamma_cov, xi_occ=1.0 - occ,
                   h_lidar=h_lidar, xi_dyn=xi_dyn, t=t_now)

    def kc_lidar(self, lec: LEC) -> bool:
        """引理 44：通过 ⟹ 配准可信、关键区被覆盖、无未建模动态障碍"""
        return (lec.r_reg <= self.eps_reg
                and lec.gamma_cov >= self.gamma_min
                and lec.xi_occ >= self.eps_occ
                and lec.h_lidar >= self.h_min
                and lec.xi_dyn >= self.eps_dyn)

    def valid(self, lec: LEC, t_now: float) -> bool:
        """□_{T_stale} kc_lidar：控制环消费时的时效语义，过期即 ⊥"""
        return (t_now - lec.t) <= self.T_stale

    def _register(self, P_t, M): ...
    def _coverage(self, P_t, V_crit, T_t, k): ...
    def _health(self, P_t) -> float: ...
    def _dynamic_clearance(self, P_t, O_dyn, T_t) -> float: ...
```

### IP-496 EFA-v5：九硬门 + 软评分 + 证据铸造流水线 v5

```python
@dataclass
class EvidenceForgingAssemblerV5:
    """EFA-v5：九硬门 fail-closed；软评分 ECS_v5 = ECS_v4 · η_joint · η_lidar"""
    scf: SpatialCoverageFieldKernel
    msrg_cache: dict
    hic: HumanIntentCertificateKernel
    eek: EndEffectorFidelityKernel
    ltem: LongTermEpisodicMemory
    vack: ValueAlignmentCertificateKernel
    bck: BalanceControlKernel
    jsfk: JointSpaceFeasibilityKernel      # 新增
    lgek: LiDARGeometricEvidenceKernel     # 新增
    mu_S: float = 0.75
    w: tuple = (0.4, 0.4, 0.2)

    def hard_gate(self, x, t_now, rule_id, hic, eec, bcc, jfc, lec,
                  object_class, geo_sig, theta_domain_fp, traj, context):
        # 优先级：HIC veto > 其余八硬门（并行评估，任一失败即拒）
        if self.hic.veto_active(hic):            return False, 'HIC_STOP'
        if not self.scf.kc_coverage(x, t_now):   return False, 'COVERAGE_BLIND'
        s2rc = self.msrg_cache.get(rule_id)
        if s2rc is None or s2rc.verdict != 'accept' or s2rc.mu_pass < self.mu_S:
            return False, 'PHYSICS_UNPROVEN'
        if not self.eek.kc_ee(eec):              return False, 'EE_UNPROVEN'
        if not self.bck.kc_bal(bcc):             return False, 'BALANCE_UNSTABLE'
        pass_mem, eta_mem, novelty = self.ltem.query(
            object_class, geo_sig, theta_domain_fp, rule_id)
        if not pass_mem:                         return False, 'MEMORY_REJECT'
        vac = self.vack.evaluate(traj, context, t_now)
        if not self.vack.kc_val(vac):            return False, 'VALUE_MISALIGNED'
        # ---- v5 新增两门 ----
        if not self.jsfk.kc_joint(jfc):          return False, 'JOINT_INFEASIBLE'
        if not (self.lgek.kc_lidar(lec) and self.lgek.valid(lec, t_now)):
            return False, 'LIDAR_UNGROUNDED'
        return True, 'FORGED' + ('|NOVELTY' if novelty else '')

    def ecs_v5(self, x, t_now, rule_id, A_att=0.0, eta_mem=0.5,
               eta_val=0.5, eta_bal=0.5, eta_joint=0.5, eta_lidar=0.5) -> float:
        base = (self.scf.gamma3d(x, t_now)**self.w[0]
                * getattr(self.msrg_cache.get(rule_id), 'mu_pass', 0.0)**self.w[1]
                * (1 + self.w[2]*A_att))
        return base * eta_mem * eta_val * eta_bal * eta_joint * eta_lidar
```

### 集成流水线（v4 → v5）

```
离线/慢时域（建图 + 标定 + 限位辨识，不在控制环）：
  LiDAR-IMU 外参标定、先验地图 M、关节限位/摩擦/力矩常数辨识
       ──▶ 下发：M、T_extrinsic、q_min/q_max、dq_max、τ_max、σ_ref

感知环（10–20 Hz，~20–100 ms）：
  P_t ──▶ LGEK.observe(P_t, M, V_crit, O_dyn) ──▶ LEC
       ──▶ kc_lidar ──▶ 发布 □_{T_stale} kc_lidar + LEC 缓存（带时间戳 t）

控制环（1 kHz，目标 < 0.2 ms 增量）：
  每周期：
    EEK 读力/力矩/触觉 → EEC → kc_ee
    BCK 读全身状态/接触 → BCC → kc_bal
    JSFK 读 q/q̇/τ/J → JFC → kc_joint          ← 新增，轻量
    读取缓存 LEC → kc_lidar ∧ valid(lec, t)   ← 新增，O(1) 时效检查
  证书消费前：EFA-v5.hard_gate(...)
      ├─ HIC_STOP           → S_stop
      ├─ COVERAGE_BLIND     → 回退 STCK + 教师
      ├─ PHYSICS_UNPROVEN   → 规则降权
      ├─ EE_UNPROVEN        → 末端复位/重触 + 教师
      ├─ BALANCE_UNSTABLE   → 阻抗软化/回退姿态 + 教师
      ├─ MEMORY_REJECT      → 教师介入或重新 MSRG
      ├─ VALUE_MISALIGNED   → 价值对齐修正/教师介入
      ├─ JOINT_INFEASIBLE   → 关节限速/退奇异/降载 + 教师   ← 新增
      └─ LIDAR_UNGROUNDED   → 减速/重定位/补扫/回退保守策略  ← 新增
```

## 3. 复杂度分析（增量更新）

| 模块 | 时间复杂度 | 空间复杂度 | 关键参数 | 实时性指标 |
|---|---|---|---|---|
| JSFK observe | O(n³)（SVD）/ O(n²) 近似 | O(n²) | n=7~14 | ~0.05–0.2 ms/周期 |
| JSFK kc_joint | **O(1)** | O(1) | — | < 0.01 ms |
| LGEK observe | O(N_pc log N_pc + |V_crit|) | O(N_pc + |M|) | N_pc≈10⁵ | ~20–100 ms（10–20 Hz，不在控制环） |
| LGEK kc_lidar / valid | **O(1)** | O(1) | — | < 0.01 ms |
| EFA-v5 硬门 | **O(1)** | O(1) | — | < 0.04 ms（不含各锚观测） |
| 控制环端到端增量 | ~0.1–0.3 ms（JSFK + 缓存 LEC 检查） | — | — | 目标 < 1 ms，可行 |

**通信开销**：JFC 每周期约 40 B（仅异常上报）；LEC 10–20 Hz 约 300 B/帧（点云不离机，仅证书与统计）；LiDAR 原始点云仅在本机感知环内处理，跨站联邦只传覆盖/健康统计量（延续 FFA 隐私约束）。

**时标隔离**：
- LiDAR 永不进 1 kHz 控制环：LGEK 在感知环异步运行，控制环只做 O(1) 的 `kc_lidar ∧ valid` 检查。
- 用 □_{T_stale} 显式建模时滞：T_stale 可按速度自适应（高速时收紧，低速时放宽），避免「过期证书继续放行」。
- JSFK 的 SVD 可降级：用 J Jᵀ 条件数或预计算网格查表近似 σ_min，或仅在 J 变化超阈值时重算。

## 4. 正确性论证（增量更新）

### 引理 43（关节可行性硬门的误差包容界）

**陈述**：设关节编码器噪声 |δq|≤ε_q、力矩估计误差 |δτ|≤ε_τ、雅可比 Lipschitz 常数 L_J（‖J(q+δq)−J(q)‖≤L_J‖δq‖）。若 kc_joint 以余量 ε_lim、ε_tau、ε_manip 通过，则真实状态满足
ξ_lim^true ≥ ε_lim − ε_q/Δ_min，ξ_tau^true ≥ ε_tau − ε_τ/τ^max_min，σ_min(J(q+δq)) ≥ (ε_manip σ_ref) − L_J ε_q。
当 ε_lim ≥ ε_q/Δ_min 等条件成立时，真实关节仍在限位内、未饱和、且 σ_min>0（非奇异），概率 ≥ 1−δ。

**证明**：逐项由三角不等式与 Lipschitz 连续性放大误差；编码器/力矩噪声由给定界吸收；σ_min 的扰动界由 Weyl 不等式（奇异值 1-Lipschitz 于矩阵 2-范数）给出。∎

**工程含义**：把「任务空间可执行」落到「关节级可执行」，且余量阈值可按硬件噪声与模型误差标定，避免阈值凭经验拍脑袋。

### 引理 44（激光雷达几何证书的漏检界）

**陈述**：设关键区 V_crit 内每个被占据体素的单次扫描检测概率 ≥ p_d，体素被判「已覆盖」需 ≥k 次回波，kc_lidar 通过即 γ_cov ≥ γ_min 且 h_lidar ≥ h_min。则关键区内存在未被发现障碍的概率 ≤
(1−γ_min) + γ_min·(1−p_d·h_min)^k。
若再要求动态障碍净空 ξ_dyn ≥ ε_dyn，则已跟踪动态物体与扫掠体保持 ε_dyn·R_safe 距离。

**证明**：未覆盖体素比例 ≤ 1−γ_min（由 γ_cov 定义）；已覆盖体素仍漏检的概率由 k 次独立回波均失败给出 (1−p_d·h_min)^k；两者加权即得。动态项由净空定义直接给出。∎

**工程含义**：kc_lidar 不是「相信 LiDAR 一切正常」的二元开关，而是把覆盖比、健康度、回波次数换算成可量化的漏检上界，便于按任务风险选 γ_min、k、T_stale。

### 定理 v5（执行集严格收缩与九锚点完备）

**陈述**：在 (B1)~(B8)（继承 v4 的 B1~B6，追加 B7 关节模型准确、B8 LiDAR 外参准确）下：
(i) Exec_CADVS-v5 ⊆ Exec_CADVS-v4 ⊆ … ⊆ Exec_v29，且由 kc_joint、kc_lidar 非恒真知包含严格；
(ii) 关节不可行通过率由引理 43 界；
(iii) LiDAR 漏检通过率由引理 44 界；
(iv) 关节-任务对偶一致性（定理 5）：任务+关节双通过 ⇒ 存在满足约束的关节实现，反向不成立；
(v) 几何接地（定理 6）：3DCF 声明覆盖但 LiDAR 覆盖不足时，存在对非 LiDAR 模态不可见的对抗障碍，故 kc_lidar 非冗余；
(vi) 九锚点互补完备（定理 7）。

**证明**：(i) v5 在 v4 每条路径上追加 kc_joint（控制环）与 □_T kc_lidar（感知环写、控制环读），合取只缩不涨；非恒真性由「关节越限」「LiDAR 关键区遮挡」两个可实现反例保证严格性。(ii)(iii) 分由引理 43、44。(iv) 由定理 5 的正向构造与近奇异反例。(v) 由定理 6 的对抗构造。(vi) 由定理 7 逐锚反例。∎

**诚实声明**：(B7) 关节模型的间隙/回差/柔性在重载与磨损下会漂移，σ_min 与力矩余量的标定需在线更新；(B8) LiDAR 外参在振动与温漂下失准，会同时污染 r_reg 与 γ_cov，且 LiDAR 在雨雾/镜面/透明物体上的漏检不满足引理 44 的独立同分布假设，实际漏检率可能高于界。缓解：在线外参自标定 + 健康度退化检测 + 多模态（深度/触觉）交叉校验；T_stale 自适应收紧。

## 7. 本轮最大风险（最终确认）

**一句话**：**激光雷达证书的时标（10–20 Hz、20–100 ms 延迟、点云运动畸变）与 1 kHz 关节控制环严重失配**——强制同步会破坏实时性，使用过期证书则可能在快速运动下让 kc_lidar 基于滞后几何误判动态障碍，造成漏检或频繁误停。
